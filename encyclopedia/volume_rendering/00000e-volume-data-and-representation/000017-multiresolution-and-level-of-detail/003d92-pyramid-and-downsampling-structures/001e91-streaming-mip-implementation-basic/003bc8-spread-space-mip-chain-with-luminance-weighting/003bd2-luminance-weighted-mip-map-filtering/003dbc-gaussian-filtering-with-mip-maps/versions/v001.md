# Gaussian Filtering with MIP Maps

Also called: Lee et al. MIP map blurring, MIP map Gaussian blur

## Overview
Gaussian Filtering with MIP Maps is an efficient approximation for spatially varying Gaussian blurring using a MIP map pyramid, where each level is generated by convolving the previous level with a fixed Gaussian kernel, allowing logarithmic mapping of standard deviation to texture level [S1, unofficial]. It differs from its parent [Luminance Weighted MIP Map Filtering](9099-luminance-weighted-mip-map-filtering.md) by providing the underlying blurring mechanism; the parent adds a luminance-weighted mask to prevent illumination leaking artifacts that can occur when naively applying this blur to high-contrast scenes.

## How it works
**Inputs:**
- Original image $L^{[0]}$ (resolution $W_0 \times H_0$).
- Desired standard deviation $W$ (or spatially varying field $W(\mathbf{x})$).
- Maximum MIP level $K$.
- Scaling constant $c$ dependent on kernel size.

**Outputs:**
- Filtered image $L'$.

**Data Structures:**
- MIP Pyramid: An array of textures $\mathbb{L}^{[0 \dots K]}$.
- Level $k$ resolution: $\lfloor W_0 / 2^k \rfloor \times \lfloor H_0 / 2^k \rfloor$.
- Kernel: Fixed 2D Gaussian kernel $\mathcal{G}$ derived from 1D weights.

**Steps:**

1. **Build MIP Pyramid:**
   For $k > 0$, compute level $k$ by convolving level $k-1$ with the discrete 2D Gaussian kernel $\mathcal{G}$:
   $$ \mathbb{L}^{[k]} = \mathbb{L}^{[k-1]} * \mathcal{G} \quad (3.6) $$
   The kernel $\mathcal{G}$ is constructed from 1D weights. For a 4x4 kernel (even size to halve resolution), weights are $\{0.13, 0.37, 0.37, 0.13\}$ [S1, unofficial]. The 2D kernel is the outer product of these weights. The kernel is assumed normalized [S1, unofficial].

2. **Calculate Continuous MIP Level:**
   For a desired standard deviation $W$, calculate the continuous MIP level $k$:
   $$ k(W) \approx \text{clamp}\left(\log_2 \frac{W}{c}, 0, K\right) \quad (3.8) $$
   where $c$ is the scaling constant. Typical values for $c$:
   - $c = 0.56$ for 5x5 kernel
   - $c = 0.8$ for 4x4 kernel
   - $c = 1.5$ for 3x3 kernel [S1, unofficial]

3. **Fetch Pixel Value:**
   Since $k(W)$ is continuous, perform 1D interpolation between the two nearest integer MIP levels ($\lfloor k \rfloor$ and $\lceil k \rceil$), followed by 2D interpolation within the selected texture level to obtain the pixel value [S1, unofficial]. Elek et al. [2013] suggest linear 1D interpolation and bicubic 2D interpolation [S1, unofficial].

**Pseudocode:**

    kernel_weights_1d: list of floats, e.g., [0.13, 0.37, 0.37, 0.13]
    """
    # Create 2D kernel from 1D weights
    kernel_2d = [[w1 * w2 for w2 in kernel_weights_1d] 
                 for w1 in kernel_weights_1d]
    
    pyramid = [L0]
    current_level = L0
    
    for k in range(1, K + 1):

        # Note: Downsampling is implicit in the kernel application 
        # if the kernel is designed to halve resolution (even size).
        next_level = convolve_2d(current_level, kernel_2d)
        pyramid.append(next_level)
        current_level = next_level
        
    return pyramid

def get_mip_level(W, c, K):
    """
    Calculates the continuous MIP level for a given standard deviation W.
    """
    if c == 0:
        return 0
    log_val = log2(W / c)
    return clamp(log_val, 0, K)

def fetch_pixel(pyramid, x, y, W, c, K):
    """
    Fetches a pixel value using MIP map interpolation.
    """
    k = get_mip_level(W, c, K)
    k_floor = floor(k)
    k_ceil = ceil(k)
    
    # Handle boundary cases where k_ceil > K
    if k_ceil > K:
        k_ceil = K
        
    # Get texture coordinates for the two levels
    # Assuming x, y are in the coordinate space of the highest resolution
    # We need to scale x, y down for lower MIP levels
    scale_floor = 1.0 / (2 ** k_floor)
    scale_ceil = 1.0 / (2 ** k_ceil)
    
    x_floor = x * scale_floor
    y_floor = y * scale_floor
    x_ceil = x * scale_ceil
    y_ceil = y * scale_ceil
    
    # 2D interpolation for floor level
    val_floor = bicubic_interpolate(pyramid[k_floor], x_floor, y_floor)
    
    # 2D interpolation for ceil level
    val_ceil = bicubic_interpolate(pyramid[k_ceil], x_ceil, y_ceil)
    
    # 1D interpolation between levels
    t = k - k_floor
    return lerp(val_floor, val_ceil, t)

**Edge Cases and Pitfalls:**
- **Spatially Varying Artifacts:** Naively computing the MIP level for each pixel individually ($L'(\mathbf{x}) = L^{[k(W(\mathbf{x}))]}$) causes visual artifacts because the MIP pyramid is built assuming spatially invariant blur. In high MIP levels, pixels from large neighborhoods are blurred together and their information cannot be separated [S1, unofficial]. This is the primary motivation for the parent method's luminance weighting.
- **Kernel Size:** Even-sized kernels (e.g., 4x4) are preferred to ensure the output has exactly half the resolution of the input [S1, unofficial].
- **Scaling Constant:** The value of $c$ must be chosen based on the kernel size used during pyramid construction. Using an incorrect $c$ leads to mismatched standard deviations [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Building the pyramid takes $O(N)$ where $N$ is the total number of pixels in all levels. Fetching a pixel is $O(1)$ after pyramid construction.
- **Memory Complexity:** $O(N)$ where $N$ is the number of pixels in the base image (sum of geometric series $1 + 1/4 + 1/16 + \dots \approx 4/3$).
- **Performance:** Significantly faster than naive gathering. Elek et al. [2013] measured enhanced MIP map filtering at 2 milliseconds compared to 30 seconds for gathering and 15 hours for path-tracing reference on a sample image [S1, unofficial].
- **Strengths:** Efficient approximation of spatially varying Gaussian blur; logarithmic mapping allows easy control of blur radius.
- **Limitations:** Naive spatially varying application causes artifacts; requires pre-computation of pyramid.

## Background
Originated from Lee et al. [2009] and Elek et al. [2013], as cited in [S1, unofficial]. It is used in real-time light transport calculations in participating media to approximate multiple scattering efficiently.
