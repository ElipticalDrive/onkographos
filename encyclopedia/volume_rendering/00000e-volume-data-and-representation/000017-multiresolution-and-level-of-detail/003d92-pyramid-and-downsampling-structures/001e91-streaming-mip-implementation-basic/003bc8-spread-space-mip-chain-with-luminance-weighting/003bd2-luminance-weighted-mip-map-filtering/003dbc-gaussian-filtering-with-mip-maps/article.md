# Gaussian Filtering with MIP Maps

Also called: Lee et al. MIP map blurring, MIP map Gaussian blur

## Overview
Gaussian Filtering with MIP Maps is an efficient approximation for spatially varying Gaussian blurring using a MIP map pyramid, where each level is generated by convolving the previous level with a fixed Gaussian kernel, allowing logarithmic mapping of standard deviation to texture level [S1, unofficial]. It differs from its parent [Luminance Weighted MIP Map Filtering](9099-luminance-weighted-mip-map-filtering.md) by providing the underlying blurring mechanism; the parent adds a luminance-weighted mask to prevent illumination leaking artifacts that can occur when naively applying this blur to high-contrast scenes [G].

## How it works
**Inputs:**
- Original image $L^{[0]}$ (resolution $W_0 \times H_0$) [S1, unofficial].
- Desired standard deviation $W$ (or spatially varying field $W(\mathbf{x})$) [S1, unofficial].
- Maximum MIP level $K$ [S1, unofficial].
- Scaling constant $c$ dependent on kernel size [S1, unofficial].

**Outputs:**
- Filtered image $L'$ [S1, unofficial].

**Data Structures:**
- MIP Pyramid: An array of textures $\mathbb{L}^{[0 \dots K]}$ [S1, unofficial].
- Level $k$ resolution: $\lfloor W_0 / 2^k \rfloor \times \lfloor H_0 / 2^k \rfloor$ [S1, unofficial].
- Kernel: Fixed 2D Gaussian kernel $\mathcal{G}$ derived from 1D weights [S1, unofficial].

**Steps:**

1. **Build MIP Pyramid:**
   For $k > 0$, compute level $k$ by convolving level $k-1$ with the discrete 2D Gaussian kernel $\mathcal{G}$:
   $$ \mathbb{L}^{[k]} = \mathbb{L}^{[k-1]} * \mathcal{G} \quad (3.6) $$
   The kernel $\mathcal{G}$ is constructed from 1D weights. For a 4x4 kernel (even size to halve resolution), weights are $\{0.13, 0.37, 0.37, 0.13\}$ [S1, unofficial]. The 2D kernel is the outer product of these weights [S1, unofficial]. The kernel is assumed normalized [S1, unofficial].

2. **Calculate Continuous MIP Level:**
   For a desired standard deviation $W$, calculate the continuous MIP level $k$:
   $$ k(W) \approx \text{clamp}\left(\log_2 \frac{W}{c}, 0, K\right) \quad (3.8) $$
   where $c$ is the scaling constant. Typical values for $c$:
   - $c = 0.56$ for 5x5 kernel
   - $c = 0.8$ for 4x4 kernel
   - $c = 1.5$ for 3x3 kernel [S1, unofficial]

3. **Fetch Pixel Value:**
   Since $k(W)$ is continuous, perform 1D interpolation between the two nearest integer MIP levels ($\lfloor k \rfloor$ and $\lceil k \rceil$), followed by 2D interpolation within the selected texture level to obtain the pixel value [S1, unofficial]. Elek et al. [2013] suggest linear 1D interpolation and bicubic 2D interpolation [S1, unofficial].

```python
def build_mip_pyramid(L0, K, kernel_weights_1d):
    """
    Builds the MIP pyramid by convolving each level with the Gaussian kernel.
    kernel_weights_1d: list of floats, e.g., [0.13, 0.37, 0.37, 0.13]
    """
    kernel_2d = [[w1 * w2 for w2 in kernel_weights_1d] for w1 in kernel_weights_1d]
    pyramid = [L0]
    current = L0
    for k in range(1, K + 1):
        current = convolve_2d(current, kernel_2d)
        pyramid.append(current)
    return pyramid

def convolve_2d(image, kernel):
    """
    Performs 2D convolution with stride 2 to halve resolution.
    """
    H, W = len(image), len(image[0])
    kh, kw = len(kernel), len(kernel[0])
    out_h, out_w = (H - kh) // 2 + 1, (W - kw) // 2 + 1
    out = [[0.0] * out_w for _ in range(out_h)]
    for y in range(out_h):
        for x in range(out_w):
            val = 0.0
            for ky in range(kh):
                for kx in range(kw):
                    val += image[y + ky][x + kx] * kernel[ky][kx]
            out[y][x] = val
    return out

def get_mip_level(W, c, K):
    """
    Calculates the continuous MIP level for a given standard deviation W.
    """
    if c == 0:
        return 0
    return clamp(log2(W / c), 0, K)

def fetch_pixel(pyramid, x, y, W, c, K):
    """
    Fetches a pixel value using MIP map interpolation.
    """
    k = get_mip_level(W, c, K)
    k_f = int(k)
    k_c = min(int(k) + 1, K)
    t = k - k_f
    
    scale_f = 1.0 / (2 ** k_f)
    scale_c = 1.0 / (2 ** k_c)
    
    val_f = bicubic_interpolate(pyramid[k_f], x * scale_f, y * scale_f)
    val_c = bicubic_interpolate(pyramid[k_c], x * scale_c, y * scale_c)
    
    return lerp(val_f, val_c, t)
```

**Edge Cases and Pitfalls:**
- **Spatially Varying Artifacts:** Naively computing the MIP level for each pixel individually ($L'(\mathbf{x}) = L^{[k(W(\mathbf{x}))]}$) causes visual artifacts because the MIP pyramid is built assuming spatially invariant blur. In high MIP levels, pixels from large neighborhoods are blurred together and their information cannot be separated [S1, unofficial].
- **Kernel Size:** Even-sized kernels (e.g., 4x4) are preferred to ensure the output has exactly half the resolution of the input [S1, unofficial].
- **Scaling Constant:** The value of $c$ must be chosen based on the kernel size used during pyramid construction. The exact value should be found by experimenting and comparing the results to the correct non-approximated convolution [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** Significantly faster than naive gathering. Elek et al. [2013] measured enhanced MIP map filtering at 2 milliseconds compared to 30 seconds for gathering and 15 hours for path-tracing reference on a sample image [S1, unofficial].
- **Strengths:** Efficient approximation of spatially varying Gaussian blur; logarithmic mapping allows easy control of blur radius [S1, unofficial].
- **Limitations:** Naive spatially varying application causes artifacts; requires pre-computation of pyramid [G].

## Background
Originated from Lee et al. [2009] and Elek et al. [2013], as cited in [S1, unofficial]. It is used in real-time light transport calculations in participating media to approximate multiple scattering efficiently [S1, unofficial].
