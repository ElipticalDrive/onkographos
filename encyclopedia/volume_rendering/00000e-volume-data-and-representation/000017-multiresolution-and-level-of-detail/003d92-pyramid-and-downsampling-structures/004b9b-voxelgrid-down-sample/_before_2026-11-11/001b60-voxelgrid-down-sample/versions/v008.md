# VoxelGrid Down Sample
## Overview
VoxelGrid Down Sample reduces a volumetric voxel grid's resolution by an integer factor using max pooling [S1, unofficial]. It differs from [Pre-processing for Half Resolution](6436-pre-processing-for-half-resolution.md), which fills transparent holes with median values, by strictly applying block-wise maximums without hole-filling [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A `VoxelGrid` object containing a 3D data array `data` of shape $(N_x, N_y, N_z)$ and spatial metadata (`loc`, `scale`) [S1, unofficial].
- Parameter: An integer downsampling `factor` $f$.
- Output: A new `VoxelGrid` object with resolution $(N_x/f, N_y/f, N_z/f)$ and the same `loc` and `scale` [S1, unofficial].

**Data Structures:**
- `VoxelGrid`: Contains `data` (numeric array) and spatial attributes `loc`, `scale` [S1, unofficial].

**Steps:**
1. **Validate Divisibility:** Check if the current resolution dimensions are divisible by the `factor` [S1, unofficial]. If $N_x \% f \neq 0$ or $N_y \% f \neq 0$ or $N_z \% f \neq 0$, raise a `ValueError` [S1, unofficial].
2. **Downsample Data:** Apply max pooling over non-overlapping $f \times f \times f$ blocks [S1, unofficial]. The value of each new voxel is the maximum value found in the corresponding block of the input grid [S1, unofficial].
   $$ V_{\text{new}}(i, j, k) = \max_{\substack{0 \le dx < f \\ 0 \le dy < f \\ 0 \le dz < f}} V_{\text{old}}(i \cdot f + dx, j \cdot f + dy, k \cdot f + dz) $$
   for $0 \le i < N_x/f$, $0 \le j < N_y/f$, $0 \le k < N_z/f$ [S1, unofficial].
3. **Construct Output:** Create a new `VoxelGrid` instance using the downsampled data array and copy the original `loc` and `scale` attributes [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

class VoxelGrid:
    def __init__(self, data, loc=None, scale=None):
        self.data = data
        self.loc = loc
        self.scale = scale

def voxelgrid_down_sample(voxel_grid, factor):
    data = voxel_grid.data
    shape = data.shape
    if not (shape[0] % factor == 0 and shape[1] % factor == 0 and shape[2] % factor == 0):
        raise ValueError(f"Resolution {shape} is not divisible by factor {factor}")
    new_shape = (shape[0] // factor, factor, shape[1] // factor, factor, shape[2] // factor, factor)
    reshaped = data.reshape(new_shape)
    downsampled_data = reshaped.max(axis=(1, 3, 5))
    return VoxelGrid(data=downsampled_data, loc=voxel_grid.loc, scale=voxel_grid.scale)
```

**Parameters:**
- `factor`: Integer downsampling factor. Not given in the sources.

**Edge Cases and Pitfalls:**
- **Non-divisible Resolution:** If the grid dimensions are not multiples of the factor, the method raises a `ValueError` [S1, unofficial].
- **Max Pooling Artifacts:** Max pooling preserves high-intensity features but discards low-intensity information [S1, unofficial].

## Subtopics

### [Volume Resampling and Overflow Guard](1772-volume-resampling-and-overflow-guard.md)
Resamples a candidate volume grid to a target shape while enforcing a maximum voxel count to prevent downstream memory overflow. It differs from sibling methods by combining a strict safety cap with precise trilinear interpolation and a fallback dimension-decrement mechanism to guarantee reduction even when rounding constraints interfere.

### [Grid Deformation](5372-grid-deformation.md)
A preprocessing technique applied prior to data reduction in volume rendering compression. It transforms the input data grid according to user-defined regions to better preserve salient features during subsequent downsampling. It is an orthogonal approach to hierarchical models like wavelets, reporting improved visual results compared to pure downsampling and wavelet-based methods.

### [Optimization-based Downsampling](5825-optimization-based-downsampling.md)
Reduces the resolution of microflake volumes by iteratively optimizing scattering parameters so that the rendered appearance of the lower-resolution level of detail matches a high-resolution reference. It solves the problem of geometric aliasing and shadowing artifacts in aggregated microgeometry, distinguishing itself from naive averaging or simple SGGX approximation by explicitly accounting for shadowing effects through image-space error minimization.

### [Pre-processing for Half Resolution](6436-pre-processing-for-half-resolution.md)
Constructs a half-resolution volumetric representation from a full-resolution input to reduce data size while preserving visual quality and avoiding the information loss associated with direct subsampling. It differs from its sibling [VoxelGrid Down Sample](1014-voxelgrid-down-sample.md), which uses max pooling, by explicitly filling "holes" (transparent voxels in the downsampled grid) with median values from adjacent full-resolution neighbors to prevent occlusion artifacts. Unlike [Frequency-Domain Downsampling](6578-frequency-domain-downsampling.md), which relies on low-pass filtering in the frequency domain, this approach operates directly in the spatial domain using a specific subsampling pattern and local median replacement.

### Max-Pooling Layer
A layer that applies a max filter to non-overlapping sub-regions of the input to downsample the input and reduce parameters in subsequent encoder layers [S2, unofficial]. It contains no trainable parameters [S2, unofficial]. Typical parameters include a filter size of $2 \times 2$ and a stride of 2, applied in layers with input channels 64, 32, and 8 [S2, unofficial].

## Operating characteristics
- Time complexity: $O(N)$, where $N$ is the number of input voxels, as each voxel is processed once [G].
- Memory complexity: $O(N/f^3)$ for the output grid, plus $O(N)$ temporary memory for reshaping [G].
- Strengths: Preserves high-intensity features and sharp boundaries within each pooling block [S1, unofficial].
- Limitations: Requires grid dimensions to be exact multiples of the factor [S1, unofficial]. Discards non-maximum values within each block, which may lose low-intensity details [S1, unofficial].
- When to use: Choose when preserving peak values and computational speed are prioritized, and input dimensions are divisible by the factor [S1, unofficial]. Avoid when low-intensity details must be preserved or dimensions are not divisible [S1, unofficial].
