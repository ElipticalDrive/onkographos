# Texel Allocation via Rate-Distortion

Also called: Atlas Baking, Bake and Texel Allocation, Stage 2, Support-Aware Extent and Rate-Distortion Allocation, Texel Allocation

## Overview
This method optimizes the spatial footprint and texel count of surfels in a texture atlas by excluding zero-support regions and allocating texels based on visual importance rather than strict Nyquist limits [S1, unofficial]. It addresses the inefficiency of uniform atlas sizing where distant surfels consume excessive memory for negligible visual contribution [S1, unofficial]. It differs from its parent [Atlas Mipmapping](2639-atlas-mipmapping.md) by actively reducing the atlas size through rate-distortion optimization, and from its sibling [Anisotropic Texture Atlas Packing](2670-anisotropic-texture-atlas-packing.md) by focusing on per-surfel size allocation via error probing rather than geometric packing constraints [S1, unofficial].

## How it works
The method consists of two phases: baking the neural representation into a high-resolution atlas, and allocating texel counts per surfel using a rate-distortion probe [S1, unofficial].

### Inputs and Outputs
**Inputs:**
- Trained hash grid and MLP parameters [S1, unofficial].
- Surfel positions, orientations, and scales [S1, unofficial].
- Training view data for accumulated visibility weights [S1, unofficial].
- Target distortion threshold set to the BC7 codec error floor [S1, unofficial].

**Outputs:**
- A shelf-packed texture atlas compressed with BC7 [S1, unofficial].
- Per-surfel rectangle dimensions (width $w$, height $h$) [S1, unofficial].
- Surfel-to-texel mapping [S1, unofficial].

### Data Structures
- **Surfel Rectangle:** Defined by width $w$ and height $h$ in texels [S1, unofficial]. Dimensions are powers of two, halved from a maximum cap ($r_{\text{max}}=64$) down to a minimum of 4, or zero (no texture) [S1, unofficial].
- **Halving Ladder:** For each surfel, a sequence of candidate sizes: $(r_x, r_y) \rightarrow (r_x/2, r_y/2) \rightarrow \dots$, clamped at 4 [S1, unofficial].
- **Visibility Weight ($\alpha_T$):** Accumulated opacity-weighted visibility of the surfel across training views [S1, unofficial].

### Steps
1. **Support-Aware Extent Reduction:** Reduce the baking extent $e$ from 4 to 3 [S1, unofficial]. The compact Beta kernel is identically zero for $r > 3\sigma$, so baking over $e=3$ removes texels that are never fetched, saving approximately 50.5% of texels in representative indoor scenes [S1, unofficial].
2. **Baking:** Evaluate the trained hash grid and MLP on each surfel's tile over the kernel support [S1, unofficial]. UV coordinates range from $[-3, 3]^2$ at texel centers, with a maximum size of $64 \times 64$ texels per surfel in FP16 precision [S1, unofficial]. This produces a raw bake that is band-limited by the hash grid [S1, unofficial].
3. **Rate-Distortion Probe:** For every surfel and every size on its halving ladder, downsample the full-resolution bake to the candidate size, upsample it back to full resolution, and calculate the kernel- and opacity-weighted error between the original and reconstructed versions [S1, unofficial]. Weight this error by the surfel's accumulated visibility $\alpha_T$ to obtain the importance-weighted distortion $D_i(s)$ for surfel $i$ at size $s$ [S1, unofficial].
4. **Allocation via Lagrange Multiplier:** Define a global Lagrange multiplier $\lambda$ [S1, unofficial]. For each surfel $i$, select the size $s_i$ that minimizes $J_i(s_i) = D_i(s_i) + \lambda \cdot \text{texels}(s_i)$ [S1, unofficial]. Bisect $\lambda$ such that the total importance-weighted distortion equals the target distortion (set to the error introduced by BC7 compression) [S1, unofficial]. Surfels assigned zero texture render from their spherical Voronoi color alone [S1, unofficial].
5. **Re-baking and Compression:** Re-evaluate the hash grid and MLP at the allocated sizes, shelf-pack the resulting rectangles into a single atlas, and compress the atlas using BC7 [S1, unofficial].

### Pseudocode
```python
def texel_allocation(surfels, hash_grid, mlp, training_views):
    # Step 1 & 2: Bake
    full_bakes = {}
    for surfel in surfels:
        full_bakes[surfel.id] = evaluate_hash_mlp(surfel, hash_grid, mlp, uv_range=(-3, 3), max_size=64, dtype='FP16')

    # Step 3: Rate-Distortion Probe
    visibility_weights = compute_accumulated_alpha(surfels, training_views)
    distortions = {}
    for surfel in surfels:
        fid = surfel.id
        full_bake = full_bakes[fid]
        sizes = []
        w, h = 64, 64
        while w >= 4 and h >= 4:
            sizes.append((w, h))
            w //= 2
            h //= 2
        sizes.append((0, 0))
        surfel_distortions = {}
        for (w, h) in sizes:
            if w == 0 or h == 0:
                surfel_distortions[(w, h)] = float('inf')
                continue
            small_bake = downsample(full_bake, w, h)
            reconstructed_bake = upsample(small_bake, 64, 64)
            raw_error = calculate_weighted_mse(full_bake, reconstructed_bake)
            surfel_distortions[(w, h)] = raw_error * visibility_weights[fid]
        distortions[fid] = surfel_distortions

    # Step 4: Allocation
    target_distortion = get_bc7_floor_error()
    lambda_min, lambda_max = 0.0, 1e9
    for _ in range(50):
        lambda_mid = (lambda_min + lambda_max) / 2
        total_distortion = 0.0
        allocations = {}
        for surfel in surfels:
            fid = surfel.id
            best_size, best_cost = None, float('inf')
            for (w, h), d in distortions[fid].items():
                texel_count = w * h if w > 0 else 0
                cost = d + lambda_mid * texel_count
                if cost < best_cost:
                    best_cost = cost
                    best_size = (w, h)
            allocations[fid] = best_size
            total_distortion += distortions[fid][best_size]
        if total_distortion > target_distortion:
            lambda_max = lambda_mid
        else:
            lambda_min = lambda_mid
    return allocations

def re_bake_and_pack(surfels, allocations, hash_grid, mlp):
    atlas_rects = []
    for surfel in surfels:
        w, h = allocations[surfel.id]
        if w == 0 or h == 0:
            continue
        bake = evaluate_hash_mlp(surfel, hash_grid, mlp, uv_range=(-3, 3), target_size=(w, h), dtype='FP16')
        atlas_rects.append({'id': surfel.id, 'width': w, 'height': h, 'data': bake})
    atlas = shelf_pack(atlas_rects)
    return bc7_compress(atlas)
```

### Parameters and Edge Cases
- **Extent $e$:** Set to 3 [S1, unofficial]. Using $e=4$ includes zero-support regions, wasting ~50.5% of texels [S1, unofficial].
- **Target Distortion:** Set to the error floor of BC7 compression [S1, unofficial]. This ensures the allocation cost does not exceed the quantization error [S1, unofficial].
- **Halving Ladder:** Sizes are halved until clamped at 4 [S1, unofficial]. Sizes below 4 are treated as "no texture" [S1, unofficial].
- **Probe Source:** Probing the raw bake (before finetuning) keeps 45% of texels [S1, unofficial]. Probing the finetuned atlas keeps 60% but costs a second finetune, yields 0.05 dB less PSNR, and uses 23% more bytes [S1, unofficial]. The raw bake is preferred as it is band-limited by the hash grid, making downsampling lossless in terms of high-frequency content [S1, unofficial].

## Operating characteristics
- **Memory Reduction:** The sized atlas achieves significant memory savings with minimal quality loss [S1, unofficial]. On Mip-NeRF 360, it reduces size from 388 MB to 173 MB (0.44×) with a slight PSNR increase (27.31 vs 27.23) [S1, unofficial]. On Tanks & Temples, it reduces size from 284 MB to 132 MB (0.46×) with comparable PSNR (24.11 vs 24.10) [S1, unofficial]. On Deep Blending, it reduces size from 228 MB to 73 MB (0.32×) with increased PSNR (30.05 vs 29.87) [S1, unofficial].
- **Quality Trade-offs:** The distortion target is MSE-based [S1, unofficial]. Deepest cuts (e.g., playroom at −52% bytes) may increase LPIPS by 0.002–0.010 [S1, unofficial].
- **Performance:** The method adds a baking and probing phase but eliminates neural network inference costs during rendering [S1, unofficial].
- **Limitations:** The method assumes the use of BC7 compression [S1, unofficial]. The probe runs on the raw bake, which is band-limited by the hash grid, so halving it loses little [S1, unofficial].

## Background
This method is part of the "Bake It Till You Make It" pipeline for ultrafast spatial texture-atlas splatting [S1, unofficial]. It was introduced to address the inefficiencies of Nyquist-based sizing in neural texture atlases, where surfel sizes are determined by the hash grid resolution rather than their visual contribution to the rendered image [S1, unofficial]. The approach combines support-aware extent reduction with a Lagrange multiplier-based allocation strategy to optimize the trade-off between texel count and visual fidelity [S1, unofficial].
