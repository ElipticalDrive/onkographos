# Residual Neural Texture Baking
Also called: Hash Grid Residual Baking, Residual Baking
## Overview
Residual Neural Texture Baking converts a trained neural implicit representation (hash grid + MLP) into a static texture atlas, eliminating the need for network inference during rendering [S1, unofficial]. It differs from standard neural baking by predicting a residual color added to a fixed baseline, allowing the texture to subtract from the base color and carry high-frequency detail without surfel splitting [S1, unofficial].
## How it works
**Inputs and outputs:**
- Input: Trained hash grid features $E_\theta$, trained view-dependent color function $f_{SV}$, surfel geometry (position, tangent basis, scale), and atlas constraints ($r_{\min}, r_{\max}$).
- Output: A static RGB texture atlas where each surfel occupies an anisotropic rectangular region.

**Data structures:**
- **Hash Grid:** Four levels of features. Each level stores 4-D feature vectors. Features are queried at fragment coordinates and trilinearly interpolated [S1, unofficial].
- **MLP Decoder:** Two hidden layers, each with width 16 [S1, unofficial].
- **Surfel Resolution:** Anisotropic resolution $r_g = (r_x, r_y)$ per surfel $g$, calculated to match the Nyquist rate of the finest hash voxel [S1, unofficial].

**Formulas:**
The fragment color $\mathbf{c}(\mathbf{x}, \mathbf{d})$ at position $\mathbf{x}$ and view direction $\mathbf{d}$ is:
$$
\mathbf{c}(\mathbf{x}, \mathbf{d}) = \text{ReLU}\left(\text{ReLU}(f_{SV}(\mathbf{d}) + b_{SV}) + f_\theta(\mathbf{E}_\theta(\mathbf{x}))\right)
$$
where:
- $f_{SV}(\mathbf{d})$ is the view-dependent color output.
- $b_{SV} = 0.5$ is a neutral gray baseline offset [S1, unofficial].
- $f_\theta(\mathbf{E}_\theta(\mathbf{x}))$ is the spatial residual decoded from the hash grid features [S1, unofficial].
- The outer ReLU ensures non-negative final color [S1, unofficial].

**Parameters:**
- Hash grid levels: 4 [S1, unofficial].
- Feature dimension: 4 [S1, unofficial].
- MLP hidden layers: 2 [S1, unofficial].
- MLP hidden width: 16 [S1, unofficial].
- Minimum atlas resolution $r_{\min}$: 4 [S1, unofficial].
- Maximum atlas resolution $r_{\max}$: 64 [S1, unofficial].

**Steps:**
1. **Train the model:** Optimize the hash grid and MLP to predict residuals, while $f_{SV}$ captures low-frequency view dependence [S1, unofficial].
2. **Calculate surfel resolution:** For each surfel $g$ and tangent axis $a \in \{u, v\}$, compute:
   $$
   r_{g,a} = \text{clamp} \left( 2^{\lceil \log_2(4es_{g,a}/\delta) \rceil}, r_{\min}, r_{\max} \right)
   $$
   where $s_{g,a}$ is the surfel scale, $\delta$ is the finest hash voxel size, and $e$ is the UV half-extent in units of scale [S1, unofficial].
3. **Evaluate residual:** For each surfel, rasterize its surface. At each fragment $\mathbf{x}$, query the hash grid, interpolate features, and decode the residual $f_\theta(\mathbf{E}_\theta(\mathbf{x}))$ [S1, unofficial].
4. **Bake to atlas:** Store the computed residual (or final color) in the atlas region allocated for surfel $g$ with resolution $r_g$ [S1, unofficial].
5. **Pack atlas:** Pack the anisotropic rectangular regions into a fixed-width atlas using a shelf-packing algorithm [S1, unofficial].

**Edge cases and pitfalls:**
- The residual is unbounded, allowing subtraction from the base color. This is a feature, not a bug, as it allows one surfel to carry detail that positive-only textures would require splitting to reproduce [S1, unofficial].
- Precision issues may arise if the hash grid resolution $\delta$ is too coarse relative to surfel scale, causing aliasing [S1, unofficial].
- The baseline $b_{SV}=0.5$ must be maintained to ensure the residual builds on a neutral gray, preventing color bias [S1, unofficial].

## Subtopics
## Operating characteristics
- **Time complexity:** Baking is $O(N)$ where $N$ is the number of surfel fragments. Training is the dominant cost.
- **Memory complexity:** $O(A)$ where $A$ is the atlas size. The hash grid and MLP are discarded after baking [S1, unofficial].
- **Performance:** Enables ultrafast rendering by replacing neural inference with simple texture lookups [S1, unofficial].
- **Strengths:** High fidelity with fewer surfels due to residual subtraction; anisotropic packing reduces wasted space [S1, unofficial].
- **Limitations:** Requires prior training; static texture cannot adapt to dynamic scenes [S1, unofficial].
- **When to use:** Static scenes requiring high-performance rendering with neural-level detail [S1, unofficial].
- **When not to use:** Dynamic scenes or scenes requiring runtime appearance changes [S1, unofficial].

## Background
Originated in "Bake It Till You Make It: Ultrafast Spatial Texture-Atlas Splatting" [S1, unofficial]. The method leverages the observation that view dependence is low-frequency and can be separated from high-frequency spatial detail, allowing the latter to be baked into a texture atlas [S1, unofficial].
