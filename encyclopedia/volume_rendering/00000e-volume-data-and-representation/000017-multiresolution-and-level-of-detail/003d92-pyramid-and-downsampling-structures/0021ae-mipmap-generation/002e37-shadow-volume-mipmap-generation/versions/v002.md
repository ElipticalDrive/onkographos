# Shadow Volume Mipmap Generation
Also called: Bitwise OR Mipmap Accumulation
## Overview
Shadow Volume Mipmap Generation creates a multiresolution hierarchy for 3D shadow volume textures to enable efficient rendering at varying distances or resolutions [S1, unofficial]. It solves the problem of preserving shadow presence information during downsampling by using bitwise OR accumulation, ensuring that if any voxel in a parent block is shadowed, the corresponding voxel in the child block remains shadowed [S1, unofficial].
## How it works
### Inputs and Outputs
**Inputs:**
- `shadow_volume_mip0`: A 3D array of `uint8_t` representing the base level (mip 0) of the shadow volume [S1, unofficial].
- `width_mip0`, `height_mip0`, `depth_mip0`: Integer dimensions of the base level [S1, unofficial].

**Outputs:**
- A 3-level mipmap chain (`mip0`, `mip1`, `mip2`) uploaded to a 3D OpenGL texture [S1, unofficial].
- `mip0`: The original input data.
- `mip1`: Downsampled version of `mip0` (half dimensions).
- `mip2`: Downsampled version of `mip1` (half dimensions).

### Data Structures
- `uint8_t* shadow_volume_mip0`: Pointer to the base level data [S1, unofficial].
- `uint8_t* shadow_volume_mip1`: Pointer to mip 1 data, size `width_mip1 * height_mip1 * depth_mip1` [S1, unofficial].
- `uint8_t* shadow_volume_mip2`: Pointer to mip 2 data, size `width_mip2 * height_mip2 * depth_mip2` [S1, unofficial].
- All `uint8_t` values are 0 (unshadowed) or 1 (shadowed) [G].

### Steps
1. **Calculate Mip 1 Dimensions:**
   $$ width_{mip1} = \lfloor width_{mip0} / 2 \rfloor $$
   $$ height_{mip1} = \lfloor height_{mip0} / 2 \rfloor $$
   $$ depth_{mip1} = \lfloor depth_{mip0} / 2 \rfloor $$
   $$ volume_{mip1} = width_{mip1} \times height_{mip1} \times depth_{mip1} $$ [S1, unofficial]

2. **Allocate and Initialize Mip 1:**
   Allocate `shadow_volume_mip1` of size `volume_mip1` bytes [S1, unofficial].
   Set all bytes to 0 [S1, unofficial].

3. **Downsample Mip 0 to Mip 1:**
   Iterate $x$ from 0 to $width_{mip0}-1$, $y$ from 0 to $height_{mip0}-1$, $z$ from 0 to $depth_{mip0}-1$ [S1, unofficial].
   Calculate linear index in mip 0:
   $$ index = x + width_{mip0} \times (y + height_{mip0} \times z) $$ [S1, unofficial]
   Calculate linear index in mip 1:
   $$ index_{mip1} = \lfloor x / 2 \rfloor + width_{mip1} \times (\lfloor y / 2 \rfloor + height_{mip1} \times \lfloor z / 2 \rfloor) $$ [S1, unofficial]
   Update mip 1 using bitwise OR:
   $$ shadow\_volume\_mip1[index_{mip1}] \ |= \ shadow\_volume\_mip0[index] $$ [S1, unofficial]

4. **Calculate Mip 2 Dimensions:**
   $$ width_{mip2} = \lfloor width_{mip1} / 2 \rfloor $$
   $$ height_{mip2} = \lfloor height_{mip1} / 2 \rfloor $$
   $$ depth_{mip2} = \lfloor depth_{mip1} / 2 \rfloor $$
   $$ volume_{mip2} = width_{mip2} \times height_{mip2} \times depth_{mip2} $$ [S1, unofficial]

5. **Allocate and Initialize Mip 2:**
   Allocate `shadow_volume_mip2` of size `volume_mip2` bytes [S1, unofficial].
   Set all bytes to 0 [S1, unofficial].

6. **Downsample Mip 1 to Mip 2:**
   Iterate $x$ from 0 to $width_{mip1}-1$, $y$ from 0 to $height_{mip1}-1$, $z$ from 0 to $depth_{mip1}-1$ [S1, unofficial].
   Calculate linear index in mip 1:
   $$ index = x + width_{mip1} \times (y + height_{mip1} \times z) $$ [S1, unofficial]
   Calculate linear index in mip 2:
   $$ index_{mip2} = \lfloor x / 2 \rfloor + width_{mip2} \times (\lfloor y / 2 \rfloor + height_{mip2} \times \lfloor z / 2 \rfloor) $$ [S1, unofficial]
   Update mip 2 using bitwise OR:
   $$ shadow\_volume\_mip2[index_{mip2}] \ |= \ shadow\_volume\_mip1[index] $$ [S1, unofficial]

7. **Upload to GPU:**
   Bind the 3D volume texture [S1, unofficial].
   Set `glPixelStorei(GL_UNPACK_ALIGNMENT, 1)` [S1, unofficial].
   Upload `mip0` using `glTexSubImage3D` with format `GL_RED_INTEGER`, type `GL_UNSIGNED_BYTE`, and data `shadow_volume_mip0` [S1, unofficial].
   Upload `mip1` using `glTexSubImage3D` with format `GL_RED_INTEGER`, type `GL_UNSIGNED_BYTE`, and data `shadow_volume_mip1` [S1, unofficial].
   Upload `mip2` using `glTexSubImage3D` with format `GL_RED_INTEGER`, type `GL_UNSIGNED_BYTE`, and data `shadow_volume_mip2` [S1, unofficial].
   Unbind the texture [S1, unofficial].
   Free memory for `shadow_volume_mip1` and `shadow_volume_mip2` [S1, unofficial].

### Pseudocode
```python
def generate_shadow_volume_mipmaps(shadow_volume_mip0, width_mip0, height_mip0, depth_mip0):
    # Step 1: Calculate Mip 1 Dimensions
    width_mip1 = width_mip0 // 2
    height_mip1 = height_mip0 // 2
    depth_mip1 = depth_mip0 // 2
    volume_mip1 = width_mip1 * height_mip1 * depth_mip1

    # Step 2: Allocate and Initialize Mip 1
    shadow_volume_mip1 = [0] * volume_mip1

    # Step 3: Downsample Mip 0 to Mip 1
    for z in range(depth_mip0):
        for y in range(height_mip0):
            for x in range(width_mip0):
                index = x + width_mip0 * (y + height_mip0 * z)
                index_mip1 = (x // 2) + width_mip1 * ((y // 2) + height_mip1 * (z // 2))
                if index_mip1 < volume_mip1:
                    shadow_volume_mip1[index_mip1] |= shadow_volume_mip0[index]

    # Step 4: Calculate Mip 2 Dimensions
    width_mip2 = width_mip1 // 2
    height_mip2 = height_mip1 // 2
    depth_mip2 = depth_mip1 // 2
    volume_mip2 = width_mip2 * height_mip2 * depth_mip2

    # Step 5: Allocate and Initialize Mip 2
    shadow_volume_mip2 = [0] * volume_mip2

    # Step 6: Downsample Mip 1 to Mip 2
    for z in range(depth_mip1):
        for y in range(height_mip1):
            for x in range(width_mip1):
                index = x + width_mip1 * (y + height_mip1 * z)
                index_mip2 = (x // 2) + width_mip2 * ((y // 2) + height_mip2 * (z // 2))
                if index_mip2 < volume_mip2:
                    shadow_volume_mip2[index_mip2] |= shadow_volume_mip1[index]

    # Step 7: Upload to GPU
    # glBindTexture(GL_TEXTURE_3D, texture_id)
    # glPixelStorei(GL_UNPACK_ALIGNMENT, 1)
    # glTexSubImage3D(GL_TEXTURE_3D, 0, 0, 0, 0, width_mip0, height_mip0, depth_mip0, GL_RED_INTEGER, GL_UNSIGNED_BYTE, shadow_volume_mip0)
    # glTexSubImage3D(GL_TEXTURE_3D, 1, 0, 0, 0, width_mip1, height_mip1, depth_mip1, GL_RED_INTEGER, GL_UNSIGNED_BYTE, shadow_volume_mip1)
    # glTexSubImage3D(GL_TEXTURE_3D, 2, 0, 0, 0, width_mip2, height_mip2, depth_mip2, GL_RED_INTEGER, GL_UNSIGNED_BYTE, shadow_volume_mip2)
    # glDeleteTexture(texture_id) # Unbind/cleanup handled by caller

    del shadow_volume_mip1, shadow_volume_mip2
    return shadow_volume_mip0, shadow_volume_mip1, shadow_volume_mip2
```

### Parameters and Edge Cases
- **Parameters:** The method generates exactly 3 levels (mip 0, 1, 2) [S1, unofficial]. The downsampling factor is always 2 per dimension [S1, unofficial].
- **Edge Cases:** Not given in the sources.
- **Pitfalls:** Not given in the sources.

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of voxels in the base level, as each voxel is visited a constant number of times (once for mip1, once for mip2) [G].
- **Memory Complexity:** $O(N)$ for storing the mipmap chain. The total memory is $N + N/8 + N/64 \approx 1.14N$ bytes [G].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Linear with respect to the number of voxels [G].
- **Strengths:** Simple to implement on CPU; preserves shadow presence accurately; low memory overhead [G].
- **Limitations:** Only generates 3 levels; requires CPU processing; not suitable for dynamic volumes without regeneration [G].
- **When to use:** Static shadow volumes where CPU preprocessing is acceptable [G].
- **When not to use:** Dynamic scenes requiring real-time mipmap generation; scenes requiring more than 3 levels [G].

## Background
This method is described in the unofficial source [S1, unofficial] from the TTFH/Voxel-Render repository. It is used in voxel-based rendering systems to optimize shadow volume rendering by using lower-resolution shadow volumes for distant or less critical areas [S1, unofficial].
