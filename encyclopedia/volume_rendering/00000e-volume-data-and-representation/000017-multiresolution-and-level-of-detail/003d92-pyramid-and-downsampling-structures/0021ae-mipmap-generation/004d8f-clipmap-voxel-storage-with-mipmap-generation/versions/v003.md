# Clipmap Voxel Storage with Mipmap Generation

Also called: Clipmap Voxel Storage

## Overview
A voxel storage structure using clipmaps that generates mipmaps for inner clipmaps and the largest clipmap via compute shaders, copying regions between textures to handle axis-aligned downsampling [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input:** Source voxel textures (`ClipMaps`), configuration parameters (`ClipMapResolution`, `ClipMapCount`, `LayoutSize`, `MipmapInner`) [S1, unofficial].
- **Output:** Downsampled mipmap levels stored in `ClipMaps` (for the largest clipmap) and `TempMipMaps` (intermediate buffers for inner clipmaps) [S1, unofficial].

**Data Structures**
The storage structure `VoxelStorageTextureClipmap` holds the following fields [S1, unofficial]:
- `ClipMapResolution`: `Vector3` defining the resolution of individual clipmaps.
- `ClipMapCount`: `int` count of clipmaps.
- `LayoutSize`: `int` defining the layout dimension for axis copying.
- `VoxelMatrix`: `Matrix` transformation matrix.
- `VoxelSize`: `float` size of a single voxel.
- `MipmapInner`: `bool` flag to enable inner clipmap mipmap generation.
- `ClipMaps`: `Texture` array holding the primary clipmap data.
- `MipMaps`: `Texture` array holding generated mipmaps.
- `TempMipMaps`: `Texture[]` array of temporary textures used for intermediate mipmap calculations.
- Shader references: `VoxelMipmapSimple` and `VoxelMipmapSimpleGroups` (array of compute shaders) [S1, unofficial].

**Parameters**
- `ClipMapResolution`: `Vector3` defining the base resolution $(R_x, R_y, R_z)$ of a single clipmap layer [S1, unofficial].
- `ClipMapCount`: `int` count of clipmaps $N$ [S1, unofficial].
- `LayoutSize`: `int` defining the layout dimension for axis copying [S1, unofficial].
- `MipmapInner`: `bool` flag. If true, inner clipmaps are downsampled; otherwise, only the largest clipmap is processed [S1, unofficial].

**Algorithm Steps**
1. Initialize or update the `VoxelMipmapSimple` compute shader if `curMipMapShader` differs from the active shader or if the shader is null [S1, unofficial].
2. Initialize the `VoxelMipmapSimpleGroups` array with length equal to `TempMipMaps.Length` if it is null, length mismatched, or the shader changed [S1, unofficial].
3. Calculate `totalResolution` as `ClipMapResolution` multiplied by $(1, \text{LayoutSize}, 1)$ [S1, unofficial].
   $$ \text{totalResolution} = (R_x, R_y \times \text{LayoutSize}, R_z) $$
4. Set `threadGroupCounts` to $\text{Int3}(32, 32, 32)$ [S1, unofficial].
5. If `MipmapInner` is true, loop $i$ from $0$ to $\text{ClipMapCount} - 2$. Set thread group counts and numbers based on `totalResolution` divided by `threadGroupCounts`. Set `ReadTex` to `ClipMaps`, `WriteTex` to `TempMipMaps[0]`, and `ReadOffset` to $(0, \text{totalResolution}.Y \times i, 0)$. Execute the draw call [S1, unofficial].
6. For each axis from $0$ to $\text{LayoutSize} - 1$, calculate `offset` as $\text{axis} \times \text{ClipMapResolution}.Y$. Copy a region from `TempMipMaps[0]` to `ClipMaps` using `ResourceRegion` with dimensions halved $(X/2, Z/2)$ and Y offset adjusted by $/2 + 1$, copying to a destination offset of $(\text{int})\text{totalResolution}.Y \times (i + 1) + \text{offset} + (\text{int})\text{ClipMapResolution}.Y / 4 + 1$ with destination Z dimension halved [S1, unofficial].
7. For the largest clipmap, set `resolution` to `ClipMapResolution`. Set `threadGroupCounts` to `resolution / 4`. Multiply `resolution.Y` by `LayoutSize`. Loop $i$ from $0$ to `TempMipMaps.Length - 2`. Get the mipmap shader from `VoxelMipmapSimpleGroups[i]`. Divide `resolution` by 2. Clamp `resolution.X`, `resolution.Y`, `resolution.Z` to a minimum of 1. Handle appropriately if resolution dimensions fall below `threadGroupCounts` [S1, unofficial].

    threadGroupCounts = (32, 32, 32)

    # 5. Inner Clipmap Mipmap Generation
    if MipmapInner:
        for i in range(ClipMapCount - 1):

                totalResolution[1] // threadGroupCounts[1],
                totalResolution[2] // threadGroupCounts[2]

            VoxelMipmapSimple.ThreadGroupCounts = threadGroupCounts

            VoxelMipmapSimple.Parameters.Set("ReadTex", ClipMaps)
            VoxelMipmapSimple.Parameters.Set("WriteTex", TempMipMaps[0])
            VoxelMipmapSimple.Parameters.Set("ReadOffset", (0, int(totalResolution[1] * i), 0))
            VoxelMipmapSimple.Draw()

            # 6. Axis-Aligned Region Copying
            for axis in range(LayoutSize):
                offset = axis * ClipMapResolution[1]
                srcWidth = ClipMapResolution[0] // 2
                srcDepth = ClipMapResolution[2] // 2
                srcYOffset = ClipMapResolution[1] // 2 + 1
                destYOffset = int(totalResolution[1] * (i + 1)) + offset + int(ClipMapResolution[1] // 4) + 1

                copy_region(TempMipMaps[0], ClipMaps, srcWidth, srcDepth, srcYOffset, destYOffset, destDepth)

    # 7. Largest Clipmap Mipmap Generation
    resolution = (ClipMapResolution[0], ClipMapResolution[1], ClipMapResolution[2])
    threadGroupCounts = (resolution[0] // 4, resolution[1] // 4, resolution[2] // 4)
    resolution = (resolution[0], resolution[1] * LayoutSize, resolution[2])

    for i in range(len(TempMipMaps) - 1):
        shader = VoxelMipmapSimpleGroups[i]
        resolution = (resolution[0] // 2, resolution[1] // 2, resolution[2] // 2)
        resolution = (max(1, resolution[0]), max(1, resolution[1]), max(1, resolution[2]))

        shader.ThreadGroupCounts = threadGroupCounts

            resolution[0] // threadGroupCounts[0],

**Edge Cases and Pitfalls**
- **Memory Leaks:** If `ThreadGroupCounts` or `ThreadNumbers` change due to shader recompilation, memory leaks can occur. The implementation caches thread group configurations as separate shaders to avoid this [S1, unofficial].
- **Boundary Conditions:** The source code snippet cuts off when resolution dimensions fall below thread group counts [S1, unofficial].
