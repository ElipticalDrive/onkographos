# Level-of-detail texture mapping

Also called: Level-of-Detail Texture Blocks, Low-resolution texture blocks, Raster-based LOD texture

## Overview
Level-of-detail texture mapping reduces fragment shader load by rasterizing lower-resolution texture blocks whenever local volume detail or projected resolution allows [S1, unofficial][S2, book]. It differs from brute-force volume rendering by adapting the sampling density to the visual significance of the region, rather than processing every voxel at full resolution.

## How it works
Inputs: A 3D volume dataset, camera parameters (position, orientation, projection), and a threshold for acceptable detail loss or projected pixel size.
Outputs: A rendered image with optimized fragment shader execution.

Data structures:
- Volume data: 3D array of scalar or vector values.
- Texture blocks: Sub-volumes mapped to 2D texture objects. Each block has a resolution level (e.g., $16^3$, $8^3$).
- LOD map: A 3D grid or hierarchical structure indicating the appropriate resolution level for each spatial region.

Numbered steps:
1. Determine the projected size of volume elements (voxels) on the screen for the current camera view.
2. For each region of the volume, calculate the local detail requirement based on gradient magnitude or opacity variance.
3. Select the lowest resolution texture block that satisfies the projected resolution constraint and local detail threshold.
4. Rasterize the selected texture blocks. Lower-resolution blocks require fewer fragment shader invocations per unit area.
5. Composite the fragments to produce the final image.

Formulas:
Let $P$ be the projected size of a voxel in pixels. Let $T$ be the threshold for minimum projected size. If $P < T$, a lower-resolution block is used.
The reduction in fragment shader load is proportional to the ratio of the original voxel count to the reduced block count.

Parameters:
- Threshold $T$: Not given in the sources.
- Block sizes: Not given in the sources.

Edge cases and pitfalls:
- Precision issues may arise when transitioning between resolution levels, causing visible seams.
- Degenerate input: Regions with no detail may still be processed if the LOD map is not correctly initialized.

Pseudocode:
```python
def render_with_lod(volume, camera, threshold):
    # Determine projected voxel size
    projected_size = calculate_projected_size(volume, camera)
    
    # Select LOD for each region
    lod_map = []
    for region in volume.regions:
        if projected_size[region] < threshold:
            lod_map.append(region.get_low_res_block())
        else:
            lod_map.append(region.get_high_res_block())
            
    # Rasterize and composite
    image = empty_image()
    for block in lod_map:
        fragments = rasterize_block(block, camera)
        image = composite(image, fragments)
    return image
```

## Subtopics

### Texture Box Approximation
An alternative approach by Li and Kaufman that approximates the object by a set of texture boxes, efficiently clipping empty space from rasterization [S1, unofficial][S2, book].

## Operating characteristics
Time and memory complexity: Reduced fragment shader load compared to brute-force rendering. Memory usage depends on the number of texture blocks and their resolutions.
Measured performance: Not given in the sources.
Scaling: Scales with the complexity of the volume and the number of LOD levels.
Strengths: Reduces computational load on fragment shaders.
Limitations: May introduce visual artifacts if LOD transitions are not smooth.
When to use: When fragment shader load is a bottleneck and volume detail varies spatially.
When not: When high fidelity is required everywhere or when hardware supports efficient brute-force rendering.

## Background
Origin: Developed to reduce the load for fragment shaders on volume rendering hardware such as the VolumePro500 and VolumePro 1000 [S1, unofficial][S2, book].
History: Research efforts concentrated on reducing fragment shader load by devising level-of-detail methods [S1, unofficial][S2, book].
Usage: Used in volume rendering on commodity graphics hardware.
