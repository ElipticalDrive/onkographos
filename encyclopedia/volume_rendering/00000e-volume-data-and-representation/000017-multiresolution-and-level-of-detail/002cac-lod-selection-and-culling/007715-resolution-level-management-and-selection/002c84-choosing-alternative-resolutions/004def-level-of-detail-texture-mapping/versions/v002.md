# Level-of-detail texture mapping

Also called: Level-of-Detail Texture Blocks, Low-resolution texture blocks, Raster-based LOD texture

## Overview
Level-of-detail texture mapping reduces fragment shader load by rasterizing lower-resolution texture blocks whenever local volume detail or projected resolution allows [S1, unofficial][S2, book].

## How it works
Inputs: 3D volume dataset, camera parameters, and a criterion for projected resolution or local detail [S1, unofficial][S2, book].
Outputs: Rendered image with optimized fragment shader execution [S1, unofficial][S2, book].

Data structures: Texture blocks representing sub-volumes at varying resolutions [S1, unofficial][S2, book]. LOD selection criteria based on projected size or local detail [S1, unofficial][S2, book]. Exact layouts and bit packing are Not given in the sources.

Numbered steps:
1. Evaluate the projected size of volume elements or local detail for the current camera view.
2. Identify regions where projected resolution or local detail permits lower sampling.
3. Select lower-resolution texture blocks for those regions.
4. Rasterize the selected blocks, reducing fragment shader invocations per unit area.
5. Composite fragments to produce the final image.

Formulas: Not given in the sources.

Parameters: Thresholds for projected size or detail, and block resolution levels are Not given in the sources.

Edge cases and pitfalls: Not given in the sources.

Pseudocode:
```python
def render_with_lod(volume_blocks, camera_focal_length, camera_distance, criterion):
    rasterize_list = []
    for block in volume_blocks:
        projected_size = (block.physical_size * camera_focal_length) / camera_distance
        local_detail = block.gradient_magnitude
        if projected_size < criterion or local_detail < criterion:
            rasterize_list.append(block.low_res_data)
        else:
            rasterize_list.append(block.high_res_data)
    image = [0.0] * (width * height * 4)
    for block_data in rasterize_list:
        for sample in block_data.samples:
            color = sample.color
            alpha = sample.alpha
            for i in range(4):
                image[i] += color[i] * alpha
    return image
```

## Subtopics

### Texture Box Approximation
An alternative approach by Li and Kaufman that approximates the object by a set of texture boxes, efficiently clipping empty space from rasterization [S1, unofficial][S2, book].

## Operating characteristics
Time and memory complexity: Reduces fragment shader load compared to brute-force rendering [S1, unofficial][S2, book]. Measured performance: Not given in the sources. Scaling: Not given in the sources. Strengths: Reduces computational load on fragment shaders [S1, unofficial][S2, book]. Limitations: Not given in the sources. ## Background
Origin: Developed to reduce the load for fragment shaders on volume rendering hardware such as the VolumePro500 and VolumePro 1000 [S1, unofficial][S2, book]. History: Research efforts concentrated on reducing fragment shader load by devising level-of-detail methods [S1, unofficial][S2, book]. Usage: Used in volume rendering on commodity graphics hardware [S1, unofficial][S2, book].
