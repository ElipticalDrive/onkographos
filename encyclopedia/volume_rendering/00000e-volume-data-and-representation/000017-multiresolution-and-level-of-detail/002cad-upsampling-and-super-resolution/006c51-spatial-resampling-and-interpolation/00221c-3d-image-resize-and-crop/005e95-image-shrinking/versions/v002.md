# Image Shrinking

Also called: Trilinear Downsampling, Trilinear interpolation resize, Volume downsampling, vtkImageShrink3D

## Overview
Image Shrinking reduces the resolution of a volume image by sampling at a lower grid density using trilinear interpolation to preserve data continuity [G]. It differs from [Zero Padding for Aliasing Reduction](6382-zero-padding-for-aliasing-reduction.md) by not explicitly applying a low-pass filter before sampling, and from [3D Pixel Shuffle](19803-3d-pixel-shuffle.md) by using spatial interpolation rather than channel rearrangement [G]. It builds on [3D Image Resize and Crop](2703-3d-image-resize-and-crop.md) [G].

## How it works
**Inputs and Outputs:**
- Input: A 3D volume data array of size $S = (S_x, S_y, S_z)$ with spacing $\Delta = (\Delta_x, \Delta_y, \Delta_z)$ [G].
- Output: A 3D volume data array of size $S' = (S'_x, S'_y, S'_z)$ with spacing $\Delta' = (\Delta'_x, \Delta'_y, \Delta'_z)$ [G].

**Data Structures:**
- Input data: A contiguous array of length $S_x \times S_y \times S_z$ [G].
- Output data: A contiguous array of length $S'_x \times S'_y \times S'_z$ [G].

**Steps:**
1. Calculate the downsampling factor $F$. Let $M$ be the target maximum dimension.
   $$ F = \max \left( \frac{S_x}{M}, \frac{S_y}{M}, \frac{S_z}{M} \right) $$
   If $F \le 1$, return the original image unchanged [G].
2. Calculate the new dimensions:
   $$ S'_i = \lceil S_i / F \rceil \quad \text{for } i \in \{x, y, z\} $$
3. Calculate the new spacing:
   $$ \Delta'_i = \Delta_i \times F \quad \text{for } i \in \{x, y, z\} $$
4. Allocate a new data array for the output volume [G].
5. Iterate through each voxel $(x, y, z)$ in the new smaller volume ($0 \le x < S'_x$, etc.) [G].
6. Calculate the corresponding floating-point coordinates in the original image:
   $$ X = x \times F, \quad Y = y \times F, \quad Z = z \times F $$
7. Determine the integer grid coordinates and their neighbors for interpolation:
   $$ x_0 = \lfloor X \rfloor, \quad x_1 = \min(S_x - 1, x_0 + 1) $$
   $$ y_0 = \lfloor Y \rfloor, \quad y_1 = \min(S_y - 1, y_0 + 1) $$
   $$ z_0 = \lfloor Z \rfloor, \quad z_1 = \min(S_z - 1, z_0 + 1) $$
8. Calculate the interpolation weights (alphas):
   $$ \alpha_x = X - x_0, \quad \alpha_y = Y - y_0, \quad \alpha_z = Z - z_0 $$
9. Fetch the 8 neighboring voxel values from the original data array using the calculated grid coordinates $(x_i, y_j, z_k)$ where $i,j,k \in \{0,1\}$ [G].
10. Perform trilinear interpolation:
    - Interpolate along X for the two Z planes (values $v_{00}, v_{01}, v_{10}, v_{11}$):
      $$ v_{00} = \text{linearInterpolate}(V_{x_0,y_0,z_0}, V_{x_1,y_0,z_0}, \alpha_x) $$
      $$ v_{01} = \text{linearInterpolate}(V_{x_0,y_0,z_1}, V_{x_1,y_0,z_1}, \alpha_x) $$
      $$ v_{10} = \text{linearInterpolate}(V_{x_0,y_1,z_0}, V_{x_1,y_1,z_0}, \alpha_x) $$
      $$ v_{11} = \text{linearInterpolate}(V_{x_0,y_1,z_1}, V_{x_1,y_1,z_1}, \alpha_x) $$
    - Interpolate along Y (values $v_0, v_1$):
      $$ v_0 = \text{linearInterpolate}(v_{00}, v_{10}, \alpha_y) $$
      $$ v_1 = \text{linearInterpolate}(v_{01}, v_{11}, \alpha_y) $$
    - Interpolate along Z (final value $v$):
      $$ v = \text{linearInterpolate}(v_0, v_1, \alpha_z) $$
11. Assign the interpolated value $v$ to the new pixel data at $(x, y, z)$ [G].

**Formula:**
$$ \text{linearInterpolate}(c_0, c_1, \alpha) = c_0 \times (1 - \alpha) + c_1 \times \alpha \quad [G] $$

**Parameters:**
- Shrink factors along X, Y, Z dimensions are set to $(3, 3, 1)$ in the VTK implementation [S1, unofficial].
- Target maximum dimension $M$: Not given in the sources.

**Edge Cases and Pitfalls:**
- If $F \le 1$, the original image is returned unchanged [G].
- Boundary handling: The neighbor indices $x_1, y_1, z_1$ are clamped to $S_i - 1$ to prevent out-of-bounds access [G].
- Precision: Floating-point coordinates are used for sampling; integer truncation is handled by `floor` [G].

**Pseudocode:**
```python
import math

def image_shrinking(input_data, input_size, input_spacing, target_max_dim):
    # input_data: list or array of values
    # input_size: tuple (Sx, Sy, Sz)
    # input_spacing: tuple (dx, dy, dz)
    # target_max_dim: integer M
    
    Sx, Sy, Sz = input_size
    dx, dy, dz = input_spacing
    
    # Step 1: Calculate downsampling factor
    max_factor = max(Sx / target_max_dim, Sy / target_max_dim, Sz / target_max_dim)
    
    if max_factor <= 1:
        return input_data, input_size, input_spacing
    
    # Step 2 & 3: Calculate new dimensions and spacing
    new_size = (
        math.ceil(Sx / max_factor),
        math.ceil(Sy / max_factor),
        math.ceil(Sz / max_factor)
    )
    new_spacing = (
        dx * max_factor,
        dy * max_factor,
        dz * max_factor
    )
    
    # Step 4: Allocate output
    new_data = [0.0] * (new_size[0] * new_size[1] * new_size[2])
    
    # Helper for linear interpolation
    def lerp(c0, c1, alpha):
        return c0 * (1 - alpha) + c1 * alpha

    # Step 5-11: Iterate and interpolate
    for x in range(new_size[0]):
        for y in range(new_size[1]):
            for z in range(new_size[2]):
                # Step 6: Original coordinates
                orig_x = x * max_factor
                orig_y = y * max_factor
                orig_z = z * max_factor
                
                # Step 7: Grid coordinates and neighbors
                x0 = math.floor(orig_x)
                x1 = min(Sx - 1, x0 + 1)
                y0 = math.floor(orig_y)
                y1 = min(Sy - 1, y0 + 1)
                z0 = math.floor(orig_z)
                z1 = min(Sz - 1, z0 + 1)
                
                # Step 8: Weights
                alpha_x = orig_x - x0
                alpha_y = orig_y - y0
                alpha_z = orig_z - z0
                
                # Step 9: Fetch 8 neighbors
                # Indices in flat array: x + Sx * (y + Sy * z)
                def get_val(ix, iy, iz):
                    return input_data[ix + Sx * (iy + Sy * iz)]
                
                v00 = get_val(x0, y0, z0)
                v01 = get_val(x0, y0, z1)
                v10 = get_val(x1, y0, z0)
                v11 = get_val(x1, y0, z1)
                v20 = get_val(x0, y1, z0)
                v21 = get_val(x0, y1, z1)
                v30 = get_val(x1, y1, z0)
                v31 = get_val(x1, y1, z1)
                
                # Step 10: Trilinear interpolation
                # Interpolate along X
                vx0z0 = lerp(v00, v10, alpha_x)
                vx0z1 = lerp(v01, v11, alpha_x)
                vx1z0 = lerp(v20, v30, alpha_x)
                vx1z1 = lerp(v21, v31, alpha_x)
                
                # Interpolate along Y
                vy0 = lerp(vx0z0, vx1z0, alpha_y)
                vy1 = lerp(vx0z1, vx1z1, alpha_y)
                
                # Interpolate along Z
                final_val = lerp(vy0, vy1, alpha_z)
                
                # Step 11: Assign
                new_data[x + new_size[0] * (y + new_size[1] * z)] = final_val
                
    return new_data, new_size, new_spacing
```

## Subtopics

### [Zero Padding for Aliasing Reduction](6382-zero-padding-for-aliasing-reduction.md)
Applies a low-pass filter before downsampling to prevent aliasing artifacts. Choose when high-frequency content must be preserved without moiré patterns.

### [Resized Slice Centering](12150-resized-slice-centering.md)
Adjusts the sampling grid to align the center of the new voxel with the center of the original voxel. Choose when geometric alignment is critical.

### [Cosine Projection via Upsampling](13919-cosine-projection-via-upsampling.md)
Upsamples first, then projects. Choose when smooth transitions are needed at the cost of higher memory.

### [3D Pixel Shuffle](19803-3d-pixel-shuffle.md)
Rearranges channels to increase spatial resolution. Choose for learned super-resolution, not for simple downsampling.

## Operating characteristics
- **Time Complexity:** $O(S'_x \times S'_y \times S'_z)$, proportional to the output volume size [G].
- **Memory Complexity:** $O(S'_x \times S'_y \times S'_z)$ for the output array [G].
- **Measured Performance:** Not given in the sources.
- **Strengths:** Simple to implement; preserves data continuity via interpolation [G]; efficient for moderate downsampling factors [G].
- **Limitations:** Does not explicitly filter high frequencies, potentially causing aliasing artifacts if the downsampling factor is large [G]; interpolation artifacts (blurring) may occur [G].
- **When to use:** When texture size limits are exceeded and a quick, continuous reduction is needed [G].
- **When not to use:** When aliasing artifacts are unacceptable without pre-filtering [G].

## Background
Image Shrinking is implemented in VTK as `vtkImageShrink3D` [S1, unofficial]. It is used in 3D medical imaging and volume rendering pipelines to reduce data size for visualization or texture upload [G]. The method was popularized by VTK's image processing filters [S1, unofficial].
