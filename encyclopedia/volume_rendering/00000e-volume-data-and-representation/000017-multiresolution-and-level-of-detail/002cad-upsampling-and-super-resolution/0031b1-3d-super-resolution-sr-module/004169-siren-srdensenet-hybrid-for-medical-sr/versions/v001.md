# SIREN + SRDenseNet Hybrid for Medical SR

Also called: SIREN with Lanczos downsampling and SRDenseNet upsampling, SIREN with our architecture, Sheibanifard and Yu Medical SR, our architecture

## Overview
This method compresses and reconstructs volumetric medical images by training a Sinusoidal Representation Network (SIREN) on downsampled data and applying a separate SRDenseNet super-resolution module for reconstruction [S1]. It addresses the high GPU memory consumption and low training speed associated with training SIRENs on full-resolution data [S1]. It outperforms direct SIREN approaches in quality, speed, and GPU memory efficiency, though the performance gap narrows with increased network depth [S1].

## How it works
**Inputs:** High-resolution volumetric medical data (e.g., CT scans, 512×512×463 voxels, 12-bit grayscale, 0.5 mm slice thickness) [S1].
**Outputs:** Reconstructed high-resolution volume [S1].

**Data Structures:**
The SIREN is a Multi-Layer Perceptron (MLP) with linear layers and sinusoidal activation. The architecture varies by depth (2, 3, or 4 layers), but the width is fixed at 128 neurons per hidden layer [S1].
*   **Input:** 3D coordinates $(x, y, z)$ [S1].
*   **Hidden Layers:** Linear transformation followed by sinusoidal activation. Output shape per layer is $[-1, 1, 128]$ [S1].
*   **Output Layer:** Linear transformation. Output shape is $[-1, 1, 1]$ (scalar intensity) [S1].
*   **Parameter Counts:**
    *   2 Layers: Total 17,153 parameters [S1].
    *   3 Layers: Total 33,665 parameters [S1].
    *   4 Layers: Total 50,177 parameters [S1] [S1].

**Steps:**
1.  **Downsampling:** Apply Lanczos resampling to the high-resolution volume to generate a low-resolution volume. For example, 512×512×463 is downsampled to 128×128×115, reducing voxel count from 121,372,672 to 1,884,160 [S1].
2.  **SIREN Training:** Train the SIREN MLP on the low-resolution data.
    *   **Optimizer:** Adam [S1].
    *   **Learning Rate:** 0.0015 [S1].
    *   **Batch Size:** 216 [S1].
    *   **Loss Function:** Mean Squared Error (MSE) [S1].
3.  **SIREN Reconstruction:** Query the trained SIREN at the low-resolution grid points to reconstruct the low-resolution volume [S1].
4.  **Super-Resolution:** Apply a pre-trained SRDenseNet to the SIREN-reconstructed low-resolution output to generate the final high-resolution image [S1]. The SRDenseNet is trained in advance on the specific class of CT data [S1].

        self.linear = nn.Linear(in_features, out_features)

        # Initialize weights for sinusoidal activation
        self.linear.weight.data.uniform_(-1.0 / in_features, 1.0 / in_features)

    def forward(self, x):
        return torch.sin(self.linear(x) * self.w0)

**Edge Cases and Pitfalls:**
*   **Precision:** The source notes 12-bit grayscale for input data [S1].
*   **Boundaries:** The method is demonstrated on 2D slices but expanded to 3D [S1].
*   **Memory:** Direct SIREN on full resolution causes high GPU memory consumption [S1].

## Operating characteristics
*   **Time and Memory Complexity:** The method reduces GPU memory consumption and increases training speed compared to training SIREN on full-resolution data [S1].
*   **Measured Performance:** Achieves 35.14 dB PSNR [S2, unofficial].
*   **Compression Ratio:** 1.3–3.7× (excluding decoder model size) [S2, unofficial].
*   **Strengths:** Outperforms direct SIREN in quality, speed, and GPU memory efficiency [S1].
*   **Limitations:** The PSNR gap between this hybrid approach and direct SIREN decreases as the number of SIREN layers increases, though the hybrid still wins [S1]. The compression ratio is relatively low [S2, unofficial].
*   **When to use:** Medical volume compression where GPU memory is a constraint and high-quality reconstruction is needed [S1].
*   **When not:** When very high compression ratios are required [S2, unofficial].

## Background
Originated from Sheibanifard and Yu [126], published in *Applied Sciences* in 2023 [S1]. It extends Implicit Neural Representation (INR) techniques to medical imaging by combining downsampling, SIREN training, and deep learning-based super-resolution [S1].
