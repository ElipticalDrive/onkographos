# 3D Convolutional Neural Networks (3D CNNs)
Also called: 3D CNN

## Overview
3D CNNs extend the 2D sliding window operation to volumetric grids to extract and reconstruct spatial features [S1, unofficial]. They are the dominant architectures for volume Super-Resolution (SR) and segmentation, where their local receptive fields naturally match the spatial locality of volumetric features [S1, unofficial]. Unlike 2D CNNs, they process depth as a spatial dimension, allowing them to capture volumetric context directly.

## How it works
**Inputs and Outputs:**
- Input: A 3D volume tensor $V_{in} \in \mathbb{R}^{D \times H \times W \times C_{in}}$, where $D, H, W$ are depth, height, and width, and $C_{in}$ is the number of input channels.
- Output: A 3D volume tensor $V_{out} \in \mathbb{R}^{D' \times H' \times W' \times C_{out}}$. In SR contexts, $D' > D, H' > H, W' > W$.

**Data Structures:**
- Weights: A 5D tensor $W \in \mathbb{R}^{k_d \times k_h \times k_w \times C_{in} \times C_{out}}$, where $k_d, k_h, k_w$ are kernel dimensions.
- Bias: A 1D vector $b \in \mathbb{R}^{C_{out}}$.

**Numbered Steps:**
1. **Convolution:** For each output channel $c_{out}$ and spatial position $(d, h, w)$, compute the dot product of the kernel weights with the input patch.
   $$
   V_{out}[d, h, w, c_{out}] = \sum_{c_{in}=0}^{C_{in}-1} \sum_{z=0}^{k_d-1} \sum_{y=0}^{k_h-1} \sum_{x=0}^{k_w-1} V_{in}[d+z, h+y, w+x, c_{in}] \cdot W[z, y, x, c_{in}, c_{out}] + b[c_{out}]
   $$
   Padding and stride parameters determine the output dimensions $D', H', W'$.
2. **Activation:** Apply a non-linear activation function (e.g., ReLU) element-wise to the result.
3. **Stacking:** Repeat steps 1-2 with multiple layers. Encoder stages typically use strided convolutions or pooling to downsample; decoder stages use transposed convolutions or upsampling to increase resolution.

**Parameters:**
- Kernel size ($k_d, k_h, k_w$): Typically $3 \times 3 \times 3$ or $5 \times 5 \times 5$.
- Stride: Typically 1 for feature extraction, 2 for downsampling.
- Padding: 'Same' or 'Valid'.

**Edge Cases and Pitfalls:**
- Memory usage grows cubically with resolution. High-resolution volumes require careful batch sizing or tiling.
- Boundary effects at volume edges if padding is not handled correctly.

**Pseudocode:**
```python
def conv3d(input_volume, weights, bias, stride=1, padding=0):
    """
    Performs a 3D convolution.
    input_volume: Tensor of shape (D, H, W, C_in)
    weights: Tensor of shape (k_d, k_h, k_w, C_in, C_out)
    bias: Tensor of shape (C_out,)
    """
    D, H, W, C_in = input_volume.shape
    k_d, k_h, k_w, _, C_out = weights.shape
    
    # Calculate output dimensions
    D_out = (D + 2 * padding - k_d) // stride + 1
    H_out = (H + 2 * padding - k_h) // stride + 1
    W_out = (W + 2 * padding - k_w) // stride + 1
    
    output_volume = zeros((D_out, H_out, W_out, C_out))
    
    for d_out in range(D_out):
        for h_out in range(H_out):
            for w_out in range(W_out):
                for c_out in range(C_out):
                    sum_val = bias[c_out]
                    for c_in in range(C_in):
                        for z in range(k_d):
                            for y in range(k_h):
                                for x in range(k_w):
                                    d_in = d_out * stride + z - padding
                                    h_in = h_out * stride + y - padding
                                    w_in = w_out * stride + x - padding
                                    
                                    # Handle boundary checks if padding is manual
                                    if 0 <= d_in < D and 0 <= h_in < H and 0 <= w_in < W:
                                        sum_val += input_volume[d_in, h_in, w_in, c_in] * weights[z, y, x, c_in, c_out]
                    output_volume[d_out, h_out, w_out, c_out] = sum_val
    return output_volume
```

## Subtopics

### [U-Net](10523-u-net.md)
The U-Net variant is an encoder-decoder convolutional neural network architecture designed for volumetric segmentation and super-resolution. It extends standard 3D CNNs by adding skip connections between corresponding encoder and decoder stages, allowing the network to combine high-level semantic context with low-level spatial details. This structure distinguishes it from plain 3D CNNs by mitigating the loss of fine-grained spatial information during downsampling, making it particularly effective for tasks requiring precise boundary localization in 3D volumes.

## Operating characteristics
- **Time Complexity:** $O(D \cdot H \cdot W \cdot k_d \cdot k_h \cdot k_w \cdot C_{in} \cdot C_{out})$ per layer.
- **Memory Complexity:** Proportional to the volume of the input and intermediate feature maps. High-resolution 3D volumes can exhaust GPU memory quickly.
- **Strengths:** Local receptive fields match volumetric spatial locality [S1, unofficial]. Effective for SR and segmentation.
- **Limitations:** Computationally expensive for large volumes. Fixed receptive field size limits global context capture compared to attention mechanisms.

## Background
3D convolutions extend the 2D sliding window operation to volumetric grids [S1, unofficial]. They are widely used in scientific volume analysis, medical imaging, and video processing. The architecture is framed by the volumetric tasks they address rather than as generic definitions [S1, unofficial]. For comprehensive treatment of these architectures, see Goodfellow et al. [40].
