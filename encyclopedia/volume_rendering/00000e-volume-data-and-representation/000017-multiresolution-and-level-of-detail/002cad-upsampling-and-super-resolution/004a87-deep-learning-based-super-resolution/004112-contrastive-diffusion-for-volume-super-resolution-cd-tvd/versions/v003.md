# Contrastive Diffusion for Volume Super-Resolution (CD-TVD)
Also called: CD-TVD, Contrastive Diffusion for Volume SR

## Overview
CD-TVD is the first diffusion-based approach for scientific volume super-resolution, designed to upscale low-resolution volumetric data to higher resolutions [S1, unofficial]. It distinguishes itself from prior GAN-based methods by combining contrastive pre-training on historical simulation data with fine-tuning from as few as one high-resolution timestep, achieving 43–48 dB PSNR on four fluid dynamics datasets at 4× upscaling [S1, unofficial]. Unlike standard image SR methods that rely on VGG-based perceptual losses, CD-TVD employs a contrastive encoding module to learn degradation-aware features in latent space, providing domain-specific representations better suited for scientific data [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Low-resolution (LR) 3D volume data (e.g., fluid dynamics simulations).
*   **Output:** High-resolution (HR) 3D volume data.
*   **Scaling:** Typically 4× upscaling in spatial dimensions [S1, unofficial].

**Data Structures:**
*   **Latent Space:** A compressed representation of the volume where degradation-aware features are learned via contrastive encoding [S1, unofficial].
*   **Denoising Network:** A 3D Swin Transformer-based architecture that operates in the latent space to predict the clean signal from noisy inputs [S1, unofficial].

**Formulas:**
Not given in the sources.

**Algorithm Steps:**
1.  **Contrastive Pre-training:** Train a contrastive encoding module on historical simulation data [S1, unofficial]. The goal is to learn degradation-aware features in the latent space [S1, unofficial]. This replaces the VGG-based perceptual losses typically used in image SR with representations specific to the scientific domain [S1, unofficial].
2.  **Fine-tuning:** Adapt the pre-trained model to a new simulation scenario using as few as one high-resolution timestep as an exemplar [S1, unofficial].
3.  **Entropy-based Key-Timestep Selection:** Select a key timestep from the new simulation data based on entropy metrics [S1, unofficial]. This selection identifies the most informative timestep for adaptation [S1, unofficial].
4.  **Diffusion Upsampling:** Use the Swin Transformer-based 3D denoising network to upscale the LR volume [S1, unofficial]. The network iteratively denoises the latent representation to recover the HR volume [S1, unofficial].

**Parameters:**
*   **Upscaling Factor:** 4× (spatial) [S1, unofficial].
*   **Training Data:** Historical simulation data for pre-training; single HR timestep for fine-tuning [S1, unofficial].
*   **Selection Metric:** Entropy-based for key-timestep selection [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Single Exemplar Adaptation:** The method relies on the quality of the single high-resolution timestep used for fine-tuning [S1, unofficial].
*   **Volume Size Limitations:** Like other methods in this family, CD-TVD is limited to volumes up to $1024^3$ [S1, unofficial].

def compute_entropy(tensor):
    """Computes Shannon entropy for a flattened tensor."""
    # [G] Standard entropy calculation from probability distribution
    probs = np.histogram(tensor.flatten(), bins=256, density=True)[0]

def cd_tvd_upsample(lr_volume, pre_trained_model, single_hr_timestep):
    """Upsamples a low-resolution volume using CD-TVD."""
    # Step 1: Select key timestep based on entropy
    key_timestep = select_key_timestep(single_hr_timestep)
    
    # Step 2: Fine-tune the pre-trained model
    fine_tuned_model = fine_tune_model(pre_trained_model, lr=1e-4, epochs=10, data=key_timestep)
    
    # Step 3: Encode LR volume into latent space using contrastive encoder
    latent_lr = fine_tuned_model.contrastive_encoder(lr_volume)
    
    # Step 4: Apply diffusion process with Swin Transformer denoising
    latent_hr = diffusion_denoise(latent_lr, fine_tuned_model.swin_denoiser)
    
    # Step 5: Decode latent HR volume back to spatial domain
    hr_volume = fine_tuned_model.decoder(latent_hr)
    
    return hr_volume

An alternative formulation recovers grid-based vector fields from representative streamlines via gradient vector flow diffusion followed by CNN-based denoising with recurrent residual blocks [S1, unofficial]. This two-stage approach achieved 31–36 dB PSNR with compression rates of 12–51× on supercurrent, supernova, and tornado data [S1, unofficial]. ## Background
CD-TVD was introduced as the first diffusion-based approach for scientific volume super-resolution [S1, unofficial]. It outperforms GAN-based methods [S1, unofficial]. The method builds on the trend of moving from single-modality CNNs to diffusion models in spatial scalar SR [S1, unofficial]. It was developed to handle the specific challenges of scientific volume data, such as the need for domain-specific representations and the scarcity of high-resolution simulation data [S1, unofficial].
