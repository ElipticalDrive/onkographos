# Deep Learning Super Sampling (DLSS)
Also called: DLSS (Deep Learning Super Sampling)

## Overview
Deep Learning Super Sampling (DLSS) is a deep learning-based super-resolution technique that constructs clearer, higher-resolution images while reducing pixel rendering [S1, unofficial]. It addresses performance bottlenecks by rendering games at a reduced resolution and upscaling them using transformer models [S2]. On GeForce RTX 50 Series GPUs, it additionally generates intermediate frames to increase the output frame rate [S2].

## How it works
**Inputs and Outputs:**
The method takes game frames and auxiliary data to produce upscaled frames and, optionally, interpolated frames [S1, unofficial].
*   **Inputs:**
    1.  Current game frame ($F_{curr}$).
    2.  Previous game frame ($F_{prev}$).
    3.  Optical flow field ($V_{flow}$), generated by a motion vector accelerator [S1, unofficial].
    4.  Game engine data, including motion vectors and depth buffers [S1, unofficial].
*   **Outputs:**
    1.  Upscaled high-resolution frame.
    2.  (On RTX 50 Series) Generated intermediate frames [S2].

**Data Structures:**
The specific internal memory layout of the transformer models or the optical flow field is not given in the sources [S1, unofficial]. The optical flow field is a vector field representing pixel displacement between frames [S1, unofficial].

**Steps:**
1.  **Input Aggregation:** The DLSS convolutional autoencoder frame generator receives the four input data types: $F_{curr}$, $F_{prev}$, $V_{flow}$, and engine data (motion vectors, depth) [S1, unofficial].
2.  **Feature Extraction:** The network processes these inputs to extract spatial and temporal features [G]. The sources describe the use of a "convolutional autoencoder" for frame generation and "transformer models" for upscaling [S1, unofficial][S2].
3.  **Upsampling:** The model upscales the lower-resolution input frame to the target resolution using transformer models [S2].
4.  **Frame Generation (Optional):** For GeForce RTX 50 Series GPUs, the DLSS frame generation network determines how to use information from $V_{flow}$, $F_{curr}$, and $F_{prev}$ to generate intermediate frames [S1, unofficial]. This allows the system to generate up to five frames for every single frame rendered by the game engine [S2].

## Operating characteristics
*   **Performance:** Reduces pixel rendering load by rendering at a lower resolution [S1, unofficial]. On RTX 50 Series, it can multiply the effective frame rate by generating up to 5 frames per rendered frame [S2].
*   **Hardware:** Requires NVIDIA hardware with specific accelerators for motion vectors and frame generation [S1, unofficial][S2].
*   **Strengths:** Alleviates the burden on the rendering pipeline by offloading upscaling and interpolation to neural networks [S1, unofficial].
*   **Limitations:** Specific latency, memory overhead, or scaling factors are not given in the sources.

## Background
DLSS was introduced by NVIDIA in 2019 and updated to version 3.0 [S1, unofficial]. It falls under the category of image-space neural rendering, where a conventional renderer is used and networks finish or extend its output [S2]. It is grouped with neural rendering techniques because it is optimized in the same way, operating in post-processing to restore target resolution and frame rate [S1, unofficial][S2].
