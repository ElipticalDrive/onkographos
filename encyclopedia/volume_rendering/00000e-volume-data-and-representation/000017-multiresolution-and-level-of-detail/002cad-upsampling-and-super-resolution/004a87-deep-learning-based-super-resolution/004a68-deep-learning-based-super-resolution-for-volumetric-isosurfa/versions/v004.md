# Deep Learning-Based Super-Resolution for Volumetric Isosurface Rendering

Also called: Learning-based Isosurface Upscaling, SR for Isosurfaces

## Overview
This method reduces the computational cost of isosurface ray-casting by rendering a low-resolution unshaded image of the isosurface geometry and using a fully convolutional neural network to upscale it to a high-resolution image with ambient occlusion (AO) and shading [S1]. It differs from traditional super-resolution by operating on 3D geometric fields (depth and normals) rather than color images, allowing it to infer AO at runtime without explicit ray-tracing [S1]. It builds on [Deep Learning-Based Super-Resolution](12769-deep-learning-based-super-resolution.md).

## How it works
**Inputs and Outputs:**
*   **Input:** Low-resolution depth field $D_{LR}$ and normal field $N_{LR}$ of the isosurface, rendered from a volumetric scalar field.
*   **Output:** High-resolution depth field $D_{HR}$, normal field $N_{HR}$, and ambient occlusion map $A_{HR}$.

**Data Structures:**
The input and output are 2D image arrays.
*   $D_{LR}, N_{LR}$: Dimensions $W_{LR} \times H_{LR}$. Each pixel contains a depth value and a 3D normal vector $(n_x, n_y, n_z)$.
*   $D_{HR}, N_{HR}, A_{HR}$: Dimensions $W_{HR} \times H_{HR}$. The upsampling factor is $k = W_{HR}/W_{LR} = H_{HR}/H_{LR}$.

**Network Architecture:**
The method uses a fully convolutional neural network based on FRVSRNet [S1]. The network takes $D_{LR}$ and $N_{LR}$ as input channels and outputs $D_{HR}$, $N_{HR}$, and $A_{HR}$. The network is trained to anticipate the influence of screen-space shading [S1].

**Training:**
The network is trained using pairs of low-resolution geometric fields and high-resolution ground truth data. The ground truth includes high-resolution depth, normals, and AO maps computed via ray-casting with $N_{AO}$ samples per point [S1]. The loss function includes a frame-to-frame motion loss to ensure temporal coherence during interactive navigation [S1].

**Runtime Steps:**
1.  **Low-Resolution Rendering:** Render the isosurface at low resolution $W_{LR} \times H_{LR}$. Obtain the depth field $D_{LR}$ and normal field $N_{LR}$. Do not compute AO or shading at this stage [S1].
2.  **Network Inference:** Pass $D_{LR}$ and $N_{LR}$ into the trained fully convolutional network. The network upsamples the fields by factor $k$ and infers the high-resolution ambient occlusion map [S1].
3.  **Shading Application:** Apply screen-space shading to the high-resolution geometry ($D_{HR}, N_{HR}$) and modulate by the inferred AO map $A_{HR}$ to produce the final color image [S1].

**Pseudocode:**
```python
def render_isosurface_sr(volumetric_field, camera, lr_width, lr_height, hr_width, hr_height, network):
    """
    Renders an isosurface using deep learning-based super-resolution.
    
    Args:
        volumetric_field: 3D scalar field (e.g., 1024^3 grid).
        camera: Camera parameters for ray-casting.
        lr_width, lr_height: Low-resolution image dimensions.
        hr_width, hr_height: High-resolution target dimensions.
        network: Trained fully convolutional neural network.
        
    Returns:
        final_image: High-resolution color image.
    """
    # Step 1: Low-resolution geometric rendering
    # Render depth and normals without AO or shading
    depth_lr, normals_lr = ray_cast_isosurface(volumetric_field, camera, lr_width, lr_height)
    
    # Step 2: Super-resolution inference
    # The network upsamples depth and normals and infers AO
    depth_hr, normals_hr, ao_map = network.forward(depth_lr, normals_lr)
    
    # Step 3: Screen-space shading
    # Apply shading using high-res geometry and inferred AO
    final_image = apply_screen_space_shading(depth_hr, normals_hr, ao_map, camera)
    
    return final_image

def ray_cast_isosurface(field, camera, width, height):
    """
    Renders the isosurface at the given resolution.
    Returns depth and normal fields. No AO is computed.
    """
    depth_map = zeros((height, width))
    normal_map = zeros((height, width, 3))
    
    for y in range(height):
        for x in range(width):
            ray = camera.get_ray(x, y)
            # Find intersection with isosurface in field
            hit = find_isosurface_intersection(field, ray)
            if hit is not None:
                depth_map[y, x] = hit.distance
                normal_map[y, x] = hit.normal
            else:
                depth_map[y, x] = 0.0
                normal_map[y, x] = [0.0, 0.0, 0.0]
                
    return depth_map, normal_map

def apply_screen_space_shading(depth, normals, ao, camera):
    """
    Applies shading to the high-resolution geometry.
    """
    height, width = depth.shape
    image = zeros((height, width, 3))
    
    for y in range(height):
        for x in range(width):
            if depth[y, x] > 0:
                # Simple shading model modulated by AO
                # In practice, this might be a more complex lighting model
                # The network is trained to anticipate this shading influence
                shading = compute_shading(normals[y, x], camera)
                image[y, x] = shading * ao[y, x]
            else:
                image[y, x] = [0.0, 0.0, 0.0]
                
    return image
```

**Parameters:**
*   **Input Resolution:** e.g., $320 \times 240$ pixels [S1].
*   **Output Resolution:** e.g., $1280 \times 960$ pixels [S1].
*   **Upscaling Factor:** 4x in the example, reducing volumetric samples by a factor of 16 ($4 \times 4$) [S1].
*   **Volumetric Grid Size:** e.g., $1024^3$ [S1].
*   **AO Samples per Point ($N_{AO}$):** Number of secondary rays for AO in ground truth. The speedup factor with AO is $16 \times N_{AO}$ compared to full-resolution ray-casting [S1].

**Edge Cases and Pitfalls:**
*   The network does not learn specific isosurfaces but general geometric properties of isocontours, allowing it to work on unseen isosurfaces [S1].
*   It is not possible in general to quantify the reconstruction error introduced by the network, making fidelity loss hard to measure precisely [S1].

## Operating characteristics
*   **Time Complexity:** The method achieves a performance gain of one to two orders of magnitude compared to full-resolution ray-casting [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** In the paper's example (Fig. 1), ground truth render time is 0.16 seconds (without AO) and 18.6 seconds (with AO) at $1280 \times 960$ resolution. The super-resolution step takes 0.07 seconds [S1].
*   **Scaling:** The method reduces samples by a factor of 16 without AO, and $16 \times N_{AO}$ with AO [S1].
*   **Strengths:** Avoids runtime AO simulation; works on unseen isosurfaces; maintains temporal coherence with motion loss [S1].
*   **Limitations:** Reconstruction error is hard to quantify; relies on the quality of the trained network [S1].
*   **When to use:** Remote visualization, in-situ visualization, and focus+context visualization for complex isosurfaces [S1].

## Background
The method was introduced by Sebastian Weiss, Mengyu Chu, Nils Thuerey, and Rüdiger Westermann from the Technical University of Munich, published on arXiv on June 15, 2019 (arXiv:1906.06520v1) [S1]. It builds on recent developments in image and video super-resolution via artificial neural networks to further reduce the number of data access operations in volumetric ray-casting [S1].
