# Deep Learning-Based Super-Resolution for Volumetric Isosurface Rendering

Also called: Learning-based Isosurface Upscaling, SR for Isosurfaces

## Overview
This method reduces the computational cost of isosurface ray-casting by rendering a low-resolution unshaded image of the isosurface geometry and using a fully convolutional neural network to upscale it to a high-resolution image with ambient occlusion (AO) and shading [S1]. It differs from traditional super-resolution by operating on 3D geometric fields (depth and normals) rather than color images, allowing it to infer AO at runtime without explicit ray-tracing [S1]. It builds on [Deep Learning-Based Super-Resolution](12769-deep-learning-based-super-resolution.md) [G].

## How it works
**Inputs and Outputs:**
*   **Input:** Low-resolution depth field $D_{LR}$ and normal field $N_{LR}$ of the isosurface, rendered from a volumetric scalar field [S1].
*   **Output:** High-resolution depth field $D_{HR}$, normal field $N_{HR}$, and ambient occlusion map $A_{HR}$ [S1].

**Data Structures:**
The input and output are 2D image arrays [S1].
*   $D_{LR}$ and $N_{LR}$ have dimensions $W_{LR} \times H_{LR}$, where each pixel contains a depth value and a 3D normal vector $(n_x, n_y, n_z)$ [S1].
*   $D_{HR}$, $N_{HR}$, and $A_{HR}$ have dimensions $W_{HR} \times H_{HR}$ [S1].
*   The upsampling factor is $k = W_{HR}/W_{LR} = H_{HR}/H_{LR}$ [S1].

**Network Architecture:**
The method uses a fully convolutional neural network based on FRVSRNet [S1]. The network takes $D_{LR}$ and $N_{LR}$ as input channels and outputs $D_{HR}$, $N_{HR}$, and $A_{HR}$ [S1]. The network is trained to anticipate the influence of screen-space shading [S1].

**Training:**
The network is trained using pairs of low-resolution geometric fields and high-resolution ground truth data [S1]. The ground truth includes high-resolution depth, normals, and AO maps computed via ray-casting with $N_{AO}$ samples per point [S1]. The loss function includes a frame-to-frame motion loss to achieve improved temporal coherence [S1].

**Runtime Steps:**
1.  **Low-Resolution Rendering:** Render the isosurface at low resolution $W_{LR} \times H_{LR}$ to obtain the depth field $D_{LR}$ and normal field $N_{LR}$ without computing AO or shading [S1].
2.  **Network Inference:** Pass $D_{LR}$ and $N_{LR}$ into the trained fully convolutional network [S1]. The network upsamples the fields by factor $k$ and infers the high-resolution ambient occlusion map [S1].
3.  **Shading Application:** Apply screen-space shading to the high-resolution geometry ($D_{HR}, N_{HR}$) and modulate by the inferred AO map $A_{HR}$ to produce the final color image [S1].

**Pseudocode:**
```python
def render_isosurface_sr(volumetric_field, camera, lr_width, lr_height, hr_width, hr_height, network):
    # Step 1: Low-resolution geometric rendering
    depth_lr, normals_lr = ray_cast_isosurface(volumetric_field, camera, lr_width, lr_height)
    # Step 2: Super-resolution inference
    depth_hr, normals_hr, ao_map = network.forward(depth_lr, normals_lr)
    # Step 3: Screen-space shading
    final_image = apply_screen_space_shading(depth_hr, normals_hr, ao_map, camera)
    return final_image

def zeros(shape):
    if len(shape) == 2:
        return [[0.0] * shape[1] for _ in range(shape[0])]
    return [[[0.0] * shape[2] for _ in range(shape[1])] for _ in range(shape[0])]

def normalize(v):
    mag = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    if mag == 0: return [0.0, 0.0, 0.0]
    return [v[0]/mag, v[1]/mag, v[2]/mag]

def ray_cast_isosurface(field, camera, width, height):
    depth_map = zeros((height, width))
    normal_map = zeros((height, width, 3))
    for y in range(height):
        for x in range(width):
            ray_origin = camera.get_ray_origin(x, y)
            ray_direction = camera.get_ray_direction(x, y)
            t = 0.0
            while t < 100.0:
                pos = [ray_origin[i] + t * ray_direction[i] for i in range(3)]
                val = field.sample(pos)
                if val >= 0.0:
                    grad = field.compute_gradient(pos)
                    normal_map[y, x] = normalize(grad)
                    depth_map[y, x] = t
                    break
                t += 0.01
    return depth_map, normal_map

def apply_screen_space_shading(depth, normals, ao, camera):
    height, width = len(depth), len(depth[0])
    image = zeros((height, width, 3))
    light_dir = [0.0, 1.0, 0.5]
    light_dir = normalize(light_dir)
    for y in range(height):
        for x in range(width):
            if depth[y, x] > 0:
                n = normals[y, x]
                diff = max(0.0, n[0]*light_dir[0] + n[1]*light_dir[1] + n[2]*light_dir[2])
                shading = [0.2 + 0.8 * diff] * 3
                image[y, x] = [shading[i] * ao[y, x] for i in range(3)]
    return image
```

**Parameters:**
*   **Input Resolution:** e.g., $320 \times 240$ pixels [S1].
*   **Output Resolution:** e.g., $1280 \times 960$ pixels [S1].
*   **Upscaling Factor:** 4x in the example, reducing volumetric samples by a factor of 16 ($4 \times 4$) [S1].
*   **Volumetric Grid Size:** e.g., $1024^3$ [S1].
*   **AO Samples per Point ($N_{AO}$):** Number of secondary rays for AO in ground truth. The speedup factor with AO is $16 \times N_{AO}$ compared to full-resolution ray-casting [S1].

**Edge Cases and Pitfalls:**
*   The network does not learn specific isosurfaces but general geometric properties of isocontours, allowing it to work on unseen isosurfaces [S1].
*   It is not possible in general to quantify the reconstruction error introduced by the network, making fidelity loss hard to measure precisely [S1].

## Operating characteristics
*   **Time Complexity:** The method achieves a performance gain of one to two orders of magnitude compared to full-resolution ray-casting [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** In the paper's example (Fig. 1), ground truth render time is 0.16 seconds (without AO) and 18.6 seconds (with AO) at $1280 \times 960$ resolution. The super-resolution step takes 0.07 seconds [S1].
*   **Scaling:** The method reduces samples by a factor of 16 without AO, and $16 \times N_{AO}$ with AO [S1].
*   **Strengths:** Avoids runtime AO simulation; works on unseen isosurfaces; maintains temporal coherence with motion loss [S1].
*   **Limitations:** Reconstruction error is hard to quantify; relies on the quality of the trained network [S1].
*   **When to use:** Remote visualization, in-situ visualization, and focus+context visualization for complex isosurfaces [S1].

## Background
The method was introduced by Sebastian Weiss, Mengyu Chu, Nils Thuerey, and Rüdiger Westermann from the Technical University of Munich, published on arXiv on June 15, 2019 (arXiv:1906.06520v1) [S1]. It builds on recent developments in image and video super-resolution via artificial neural networks to further reduce the number of data access operations in volumetric ray-casting [S1].
