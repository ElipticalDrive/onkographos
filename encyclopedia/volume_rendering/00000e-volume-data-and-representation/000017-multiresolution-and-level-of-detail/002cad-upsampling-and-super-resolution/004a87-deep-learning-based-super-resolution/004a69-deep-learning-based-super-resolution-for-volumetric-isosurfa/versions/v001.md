# Deep Learning-Based Super-Resolution for Volumetric Isosurfaces

Also called: FRVSR, FRVSR-Net, FRVSR-Net / Deep Learning-Based Super-Resolution for Volumetric Isosurfaces, Neural Super-Resolution for Isosurfaces, SRNet, SRNet Architecture, Super-Resolution Network

## Overview
This method upsamples low-resolution volumetric isosurface renderings to high resolution using a trained fully convolutional neural network, leveraging temporal coherence via screen-space flow warping [S1]. It predicts intermediate surface attributes (mask, normal, depth, ambient occlusion) rather than direct color, which prevents the color bleeding and shifts associated with direct image super-resolution [S1]. It sets itself apart from siblings like [3D Super-Resolution (SR) Module](6577-3d-super-resolution-sr-module.md) by operating in screen-space on 2D attribute maps derived from ray-casting, and from [Contrastive Diffusion for Volume Super-Resolution (CD-TVD)](10411-contrastive-diffusion-for-volume-super-resolution-cd-tvd.md) by using a deterministic CNN with temporal warping rather than a diffusion process [S1].

## How it works
**Inputs and Outputs:**
*   **Low-Resolution Input ($I_{t}^{LR}$):** A 5-channel tensor of size $[5, H, W]$. Channels are: Mask $M_{t}^{LR} \in [-1, +1]$, Normal $N_{t}^{LR} \in [-1, +1]^3$, Depth $D_{t}^{LR} \in [0, 1]$, and Screen-Space Flow $F_{t}^{LR} \in [-1, +1]^2$ [S1].
*   **Previous High-Resolution Output ($O_{t-1}$):** A 6-channel tensor of size $[6, 4H, 4W]$ from the previous frame, containing Mask, Normal, Depth, and Ambient Occlusion (AO) [S1].
*   **Output ($O_{test}$):** A 6-channel tensor of size $[6, 4H, 4W]$ containing predicted Mask ($M_{test}$), Normal ($N_{test}$), Depth ($D_{test}$), and Ambient Occlusion ($AO_{test}$) [S1].

**Data Structures and Layout:**
The network input consists of the current low-resolution image ($I_{t}^{LR}$) and a flattened representation of the warped previous high-resolution output ($O_{f}$).
*   $I_{t}^{LR}$ has 5 channels.
*   $O_{f}$ is created by warping $O_{t-1}$ and applying a space-to-depth transformation, resulting in $16 \times 6 = 96$ channels at resolution $H \times W$ [S1].
*   Total input channels to the network: $5 + 96 = 101$ [S1].

**Numbered Steps:**

1.  **Generate Ground Truth AO (Training Only):** For high-resolution ray-casting, spawn 512 secondary rays per surface point to simulate Ambient Occlusion. An AO value of 1 indicates no occlusion, and 0 indicates total occlusion [S1].
2.  **Compute Screen-Space Flow ($F_{t}^{LR}$):** For each hit pixel at world position $x_t$ in the current frame $t$, project $x_t$ using the current Model-View-Projection (MVP) matrix $M_t$ to screen space $x_t^0$ and the previous MVP matrix $M_{t-1}$ to $x_{t-1}^0$. Compute flow $f_t = x_t^0 - x_{t-1}^0$ [S1].
3.  **Densify Flow Field:** Use Navier-Stokes-based image inpainting (e.g., via OpenCV) to fill empty areas in $F_{t}^{LR}$ where no surface hit occurred, creating a dense, incompressible displacement field [S1].
4.  **Warp Previous High-Res Output:** Upscale the current flow $F_{t}^{LR}$ via bilinear interpolation to high resolution. Use inverse flow vectors in a semi-Lagrangian manner to retrieve values from the previous high-res output $O_{t-1}$, producing the warped output $\tilde{O}_{t-1}$ [S1].
5.  **Flatten Warped Output:** Apply space-to-depth transformation $S_s$ to $\tilde{O}_{t-1}$. Map every $4 \times 4$ block of the high-res image to a single low-res pixel. Concatenate channels of the 16 pixels to create flattened tensor $O_f$ with $16 \times 6 = 96$ channels [S1].
6.  **Network Inference:** Input current low-res $I_{t}^{LR}$ (5 channels) and flattened warped previous $O_f$ (96 channels) into SRNet. Output predicted high-res $O_{test}$ (6 channels: Mask, Normal, Depth, AO) [S1].
7.  **Post-Process Mask:** Clamp test mask $M_{test}$ to $[-1, +1]$, then rescale to $[0, 1]$ to create $M_{t}^{0, est}$. Use this as an alpha channel for blending [S1].
8.  **Screen-Space Shading (Post-Process):** Compute final color $C_{rgb}$ using Phong shading with ambient occlusion: $C_{rgb} = \text{Phong}(c_a, c_d, c_s, c_m, N_{test}) * AO_{test}$, where $c_a, c_d, c_s, c_m$ are ambient, diffuse, specular, and material colors [S1]. Blend with background $c_{bg}$ using the processed mask: $C_{test} = \text{lerp}(c_{bg}, C_{rgb}, M_{t}^{0, est})$ [S1].

**Network Architecture (SRNet):**
The network is a fully convolutional residual network [S1].
1.  **Input Layer:** One convolution layer reduces 101 input channels to 64 channels.
2.  **Residual Blocks:** 10 residual blocks are applied. Each block contains 2 convolutional layers (3x3 kernel, stride 1) with ReLU activations [S1].
3.  **Upscaling:** Two upscaling blocks are applied. Each consists of 2x bilinear upscaling, a convolution (3x3, stride 1), and a ReLU, arriving at 4x resolution with 64 channels [S1].
4.  **Output Layer:** Two convolutions reduce the latent feature space to 6 output channels [S1].
5.  **Residual Connection:** The 5 channels of the input ($I_{t}^{LR}$) are bilinearly upsampled and added to the first five channels of the output ($M_{test}, N_{test}, D_{test}$). $AO_{test}$ is inferred from scratch as there is no low-resolution input for it [S1].

**Formulas:**
*   **Spatial L1 Loss:** $L_{X,l1} = ||X_{test} - X_{t}^{GT}||_1$
*   **Spatial L2 Loss:** $L_{X,l2} = ||X_{test} - X_{t}^{GT}||_2^2$
    Where $X$ is Mask, Normal, AO, or Color [S1].
*   **Perceptual Loss:** $L_{X,P} = ||\phi(X_{test}) - \phi(X_{t}^{GT})||_2^2$. $\phi$ is the VGG-19 feature extractor. Inputs to $\phi$ must be transformed: Normals rescaled to $[0, 1]^3$, Depth/Mask to grayscale RGB [S1].
*   **Temporal Loss:** $L_{X,temp} = ||X_{test} - \tilde{X}_{t-1}||_2^2$. $\tilde{X}_{t-1}$ is the warped previous high-res output [S1].

**Parameters:**
*   **Upscaling Factor:** 4x. Input size $H \times W$, output size $4H \times 4W$. Other factors are possible by adapting the architecture [S1].
*   **Kernel Size:** 3x3 for all convolutions.
*   **Stride:** 1 for all convolutions.
*   **Upsampling Method:** Bilinear interpolation [S1].

def compute_screen_space_flow(world_pos, mvp_current, mvp_previous):
    """
    Compute screen-space flow vector for a world position.
    world_pos: (N, 3) array of world coordinates.
    mvp_current: 4x4 matrix.
    mvp_previous: 4x4 matrix.
    Returns: (N, 2) flow vectors.
    """
    # Project to current screen space
    h_current = np.dot(mvp_current, np.hstack([world_pos, np.ones((world_pos.shape[0], 1))]).T).T
    # Perspective division

def space_to_depth(input_tensor, block_size=4):
    """
    Apply space-to-depth transformation.
    input_tensor: (C, H, W) array.
    block_size: int.
    Returns: (C * block_size^2, H/block_size, W/block_size) array.
    """
    C, H, W = input_tensor.shape
    new_H = H // block_size
    new_W = W // block_size
    
    # Reshape and permute
    # (C, H, W) -> (C, new_H, block_size, new_W, block_size)
    reshaped = input_tensor.reshape(C, new_H, block_size, new_W, block_size)
    # Permute to (C, new_H, new_W, block_size, block_size)
    permuted = reshaped.transpose(0, 1, 3, 2, 4)
    # Reshape to (C, new_H, new_W, block_size^2)
    final = permuted.reshape(C, new_H, new_W, block_size**2)
    # Permute to (C * block_size^2, new_H, new_W)
    output = final.transpose(0, 3, 1, 2).reshape(C * block_size**2, new_H, new_W)
    return output

def depth_to_space(input_tensor, block_size=4):
    """
    Inverse of space_to_depth.
    """
    C, H, W = input_tensor.shape
    new_C = C // (block_size**2)

**Edge Cases and Pitfalls:**
*   **Color Bleeding:** Upscaling color images directly causes artifacts. The method avoids this by predicting surface attributes and applying screen-space shading in post-process [S1].
*   **Artificial Details:** Texture or style loss terms introduce unwanted roughness in smooth isosurface renderings. These should not be used [S1].
*   **Loss Masking:** Pixels where the mask is -1 (no hit) have irrelevant normal and AO values. Loss terms for normals and AO should be masked out in these regions to prevent the network from learning noise in empty space [S1].

## Operating characteristics
*   **Time Complexity:** The network inference is $O(H \cdot W)$ for the convolutional operations. The flow warping and space-to-depth operations are also linear in the number of pixels. The overall complexity is dominated by the convolutional layers, which are efficient on GPUs.
*   **Memory Complexity:** The network stores weights for 101 input channels, 64 intermediate channels, and 6 output channels. The input tensor size is $101 \cdot H \cdot W$. The output tensor size is $6 \cdot 4H \cdot 4W$.
*   **Measured Performance:** The method achieves good temporal coherence with a simple temporal L2 loss, avoiding the training difficulties of spatio-temporal discriminators used in TecoGAN [S1].
*   **Strengths:** Prevents color bleeding, maintains temporal coherence, handles smooth isosurfaces well without artificial details.
*   **Limitations:** Requires pre-computed low-resolution attributes (mask, normal, depth, flow). Performance depends on the quality of the low-resolution input.
*   **When to use:** Interactive navigation or focus+context visualization where error is acceptable or intentionally integrated [S1].
*   **When not to use:** When high-fidelity texture details are required, or when temporal coherence is not a concern and simpler interpolation suffices.

## Background
The method was introduced in the paper "Volumetric Isosurface Rendering with Deep Learning-Based Super-Resolution" [S1]. It builds on the principles of deep learning-based super-resolution [12769-deep-learning-based-super-resolution.md] and specifically addresses the challenges of volumetric isosurface rendering, such as temporal coherence and color artifacts. It compares favorably to TecoGAN [7] by using a simpler temporal loss instead of a spatio-temporal discriminator [S1].
