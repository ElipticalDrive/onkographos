# Hierarchical Multi-scale SR


## Overview
Hierarchical Multi-scale SR is a deep learning-based super-resolution method that reconstructs high-resolution 3D volumes by chaining 2× upscaling networks across the levels of an octree data structure [S1, unofficial]. It solves the problem of seam artifacts and reconstruction errors common in single-step large-factor upsampling by iteratively refining the volume from the coarsest uniform grid level up to the target resolution [S1, unofficial]. It sets itself apart from sibling methods by explicitly leveraging the hierarchical spatial decomposition of the octree to guide the upscaling process, ensuring consistency across scales and eliminating seams through voxel overwriting [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A low-resolution 3D volume represented as an octree structure [S1, unofficial].
*   **Output:** A high-resolution 3D volume at the finest octree level [S1, unofficial].

**Data Structures:**
*   **Octree:** A tree data structure where each internal node has up to 8 children. Each node at level $L$ represents a cubic region of space, with voxel data defined at the resolution corresponding to level $L$ [G].

**Numbered Steps:**
1.  **Global Downscaling:** Iteratively downscale all data in the octree to the coarsest uniform grid level [S1, unofficial].
2.  **Iterative Upscaling:** For each level $L$ from the coarsest level up to the target finest level:
    a.  **Apply 2× Upscaling Network:** Pass the voxel data at level $L$ through a 2× super-resolution neural network (e.g., ESRGAN, SSR-TVD, or STNet) to generate data for level $L+1$ [S1, unofficial].
    b.  **Overwrite Stale Voxels:** Update the octree nodes at level $L+1$ with the new high-resolution data generated by the network, overwriting any previously existing data at the finer level [S1, unofficial].
    c.  **Seam Elimination:** This overwriting step eliminates seam artifacts between different regions of the volume by ensuring all finer-level data is consistently derived from the current coarse level [S1, unofficial].
3.  **Termination:** Repeat step 2 until the target finest level is reached. The final octree contains the super-resolved volume [S1, unofficial].

**Formulas:**
Let $V_L$ be the voxel data at level $L$. Let $f_{SR}$ be the 2× super-resolution network [G].
The upscaling step for level $L$ to $L+1$ is:
$$ V_{L+1} = f_{SR}(V_L) $$
The final volume $V_{final}$ is the data at the target level $L_{max}$ [G].

**Parameters:**
*   **Upscaling Factor per Step:** 2× [S1, unofficial].
*   **Backbone Networks:** ESRGAN, SSR-TVD, STNet [S1, unofficial].
*   **Volume Size:** Tested on volumes up to $1024^3$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   Not given in the sources.

**Pseudocode:**
```python
def hierarchical_multi_scale_sr(octree, target_level, sr_network):
    """
    Performs hierarchical multi-scale super-resolution on an octree.
    Matches evidence: downscale all to coarsest, then upscale level-by-level, overwriting stale voxels.
    """
    # Phase 1: Downscale all data to the coarsest uniform grid
    # [G] Sources do not specify aggregation; standard recursive pooling of child voxels is assumed.
    coarsest_level = 0
    
    # Phase 2: Iterate and upscale one level at a time
    for current_level in range(coarsest_level, target_level):
        # Extract voxel data for all nodes at current_level
        voxel_data = [node.data for node in octree if node.level == current_level]
        
        # Apply 2x SR network to generate next level data
        upscaled_data = sr_network(voxel_data)
        
        # Overwrite stale voxels at the next level with network output
        for i, node in enumerate(octree):
            if node.level == current_level + 1:
                node.data = upscaled_data[i]
                
    return octree
```

## Subtopics

### [Volumetric Super-Resolution via Plane Upscaling](11127-volumetric-super-resolution-via-plane-upscaling.md)
This method super-resolves 3D scenes by applying a 2D image super-resolution network $F$ directly to the learned 2D feature planes of a volumetric representation, rather than upscaling rendered images. It sets itself apart from sibling methods by operating on the implicit representation's parameters (feature planes) to produce $\alpha$ times super-resolved versions of them, leveraging existing 2D SR architectures like EDSR.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Tested with ESRGAN, SSR-TVD, and STNet backbones on volumes up to $1024^3$ from turbulence and cosmological simulations, the hierarchical approach achieved approximately 5 dB higher PSNR than single-step 4× SR at equivalent data reduction [S1, unofficial].
*   **Strengths:** Eliminates seam artifacts by overwriting stale voxels, leverages existing 2D SR architectures, suitable for large volumes.
*   **Limitations:** Requires an octree structure, computationally intensive for very large volumes.
*   **When to Use:** When high-quality super-resolution is needed for large 3D volumes, and seam artifacts are a concern.
*   **When Not to Use:** When computational resources are limited, or when the input data is not naturally represented as an octree.

## Background
The hierarchical multi-scale SR method was introduced in the context of scientific volume super-resolution, specifically for turbulence and cosmological simulations [S1, unofficial]. It builds on the idea of using hierarchical data structures like octrees to manage large volumes and applies deep learning techniques to enhance their resolution. The method was evaluated using various backbones, including ESRGAN, SSR-TVD, and STNet, demonstrating significant improvements in PSNR over single-step upscaling methods [S1, unofficial].
