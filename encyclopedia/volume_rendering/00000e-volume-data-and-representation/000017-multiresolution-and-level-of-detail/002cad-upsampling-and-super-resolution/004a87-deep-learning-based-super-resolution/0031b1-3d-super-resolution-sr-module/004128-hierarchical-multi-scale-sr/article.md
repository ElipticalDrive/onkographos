# Hierarchical Multi-scale SR

Also called: Hierarchical Octree SR, Multi-scale Octree Upsampling

## Overview
Hierarchical Multi-scale SR is a deep learning-based super-resolution method that reconstructs high-resolution 3D volumes by chaining 2× upscaling networks across the levels of an octree data structure [S1, unofficial]. It solves the problem of seam artifacts and reconstruction errors common in single-step large-factor upsampling by iteratively refining the volume from the coarsest uniform grid level up to the target resolution [S1, unofficial]. It sets itself apart from sibling methods like [SSR-VFD](10422-ssr-vfd.md) and [3D Convolutional Neural Networks (3D CNNs)](10439-3d-convolutional-neural-networks-3d-cnns.md) by explicitly leveraging the hierarchical spatial decomposition of the octree to guide the upscaling process, ensuring consistency across scales [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A low-resolution 3D volume represented as an octree structure, where each node contains voxel data (e.g., scalar values) at its respective resolution level.
*   **Output:** A high-resolution 3D volume at the finest octree level, with all voxels updated to the target resolution.

**Data Structures:**
*   **Octree:** A tree data structure where each internal node has up to 8 children. Each node $N$ at level $L$ represents a cubic region of space. The voxel data associated with node $N$ is defined at the resolution corresponding to level $L$.
    *   **Fields:** `level` (integer, depth in tree), `children` (array of 8 nodes or null), `data` (tensor of voxel values).
    *   **Layout:** The octree is stored such that the root represents the coarsest uniform grid. Leaves at the deepest level represent the finest resolution.

**Numbered Steps:**
1.  **Initialization:** Start with the input low-resolution octree. Identify the coarsest uniform grid level (typically the root or a specified coarse level).
2.  **Iterative Upscaling:** For each level $L$ from the coarsest level up to the target finest level:
    a.  **Downscale to Current Level:** Ensure all data in the octree is represented at the current level $L$. This may involve interpolating or aggregating data from finer levels if they exist, or simply using the existing coarse data if the volume is being built up. The method description states it "iteratively downscales all data to the coarsest uniform grid," implying a global re-sampling or aggregation step to establish a consistent base before upscaling [S1, unofficial].
    b.  **Apply 2× Upscaling Network:** Pass the voxel data at level $L$ through a 2× super-resolution neural network (e.g., ESRGAN, SSR-TVD, or STNet) to generate data for level $L+1$ [S1, unofficial].
    c.  **Overwrite Stale Voxels:** Update the octree nodes at level $L+1$ with the new high-resolution data generated by the network. This step overwrites any previously existing (stale) data at the finer level, ensuring that the most recent, higher-fidelity information is used [S1, unofficial].
    d.  **Seam Artifact Elimination:** By overwriting the finer level data with the network output derived from the consistent coarse level, seam artifacts between different regions of the volume are minimized [S1, unofficial].
3.  **Termination:** Repeat step 2 until the target finest level is reached. The final octree contains the super-resolved volume.

**Formulas:**
Let $V_L$ be the voxel data at level $L$. Let $f_{SR}$ be the 2× super-resolution network.
The upscaling step for level $L$ to $L+1$ is:
$$ V_{L+1} = f_{SR}(V_L) $$
The final volume $V_{final}$ is the data at the target level $L_{max}$.

**Parameters:**
*   **Upscaling Factor per Step:** 2× [S1, unofficial].
*   **Backbone Networks:** ESRGAN, SSR-TVD, STNet [S1, unofficial].
*   **Octree Levels:** Determined by the input volume size and target resolution. For a $1024^3$ volume, multiple levels are required [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Floating-point precision in voxel data storage may affect the quality of the upscaling, especially for scientific data with wide dynamic ranges [S1, unofficial].
*   **Boundaries:** Boundary conditions at the edges of the volume must be handled consistently during the downscaling and upscaling steps to avoid edge artifacts [S1, unofficial].
*   **Degenerate Input:** If the input octree is not balanced or has missing nodes, the downscaling step must handle sparse data appropriately [S1, unofficial].

## Subtopics

### [Volumetric Super-Resolution via Plane Upscaling](11127-volumetric-super-resolution-via-plane-upscaling.md)
This method super-resolves 3D scenes by applying a 2D image super-resolution network $F$ directly to the learned 2D feature planes of a volumetric representation, rather than upscaling rendered images. It sets itself apart from sibling methods by operating on the implicit representation's parameters (feature planes) to produce $\alpha$ times super-resolved versions of them, leveraging existing 2D SR architectures like EDSR.

## Operating characteristics
*   **Time Complexity:** The method involves multiple upscaling steps, one for each level of the octree. If there are $L$ levels, the time complexity is $O(L \cdot N)$, where $N$ is the number of voxels at the coarsest level, assuming the SR network has constant time complexity per voxel.
*   **Memory Complexity:** The memory usage is dominated by the octree structure and the voxel data at each level. The hierarchical approach may require storing intermediate results during the upscaling process.
*   **Measured Performance:** Tested with ESRGAN, SSR-TVD, and STNet backbones on volumes up to $1024^3$ from turbulence and cosmological simulations, the hierarchical approach achieved approximately 5 dB higher PSNR than single-step 4× SR at equivalent data reduction [S1, unofficial].
*   **Strengths:** Eliminates seam artifacts, leverages existing 2D SR architectures, suitable for large volumes.
*   **Limitations:** Requires an octree structure, may be computationally intensive for very large volumes.
*   **When to Use:** When high-quality super-resolution is needed for large 3D volumes, and seam artifacts are a concern.
*   **When Not to Use:** When computational resources are limited, or when the input data is not naturally represented as an octree.

## Background
The hierarchical multi-scale SR method was introduced in the context of scientific volume super-resolution, specifically for turbulence and cosmological simulations [S1, unofficial]. It builds on the idea of using hierarchical data structures like octrees to manage large volumes and applies deep learning techniques to enhance their resolution. The method was evaluated using various backbones, including ESRGAN, SSR-TVD, and STNet, demonstrating significant improvements in PSNR over single-step upscaling methods [S1, unofficial].
