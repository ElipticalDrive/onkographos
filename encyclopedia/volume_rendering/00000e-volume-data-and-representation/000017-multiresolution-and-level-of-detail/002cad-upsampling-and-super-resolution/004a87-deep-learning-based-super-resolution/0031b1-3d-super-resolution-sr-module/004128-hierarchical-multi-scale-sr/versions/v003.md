# Hierarchical Multi-scale SR
## Overview
Hierarchical Multi-scale SR is a deep learning-based super-resolution method that reconstructs high-resolution 3D volumes by chaining 2× upscaling networks across the levels of an octree data structure [S1, unofficial]. It solves the problem of seam artifacts and reconstruction errors common in single-step large-factor upsampling by iteratively refining the volume from the coarsest uniform grid level up to the target resolution [S1, unofficial]. It sets itself apart from sibling methods by explicitly leveraging the hierarchical spatial decomposition of the octree to guide the upscaling process, ensuring consistency across scales and eliminating seams through voxel overwriting [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A low-resolution 3D volume represented as an octree structure [S1, unofficial].
*   **Output:** A high-resolution 3D volume at the finest octree level [S1, unofficial].

**Data Structures:**
*   **Octree:** A tree data structure where each internal node has up to 8 children. Each node at level $L$ represents a cubic region of space, with voxel data defined at the resolution corresponding to level $L$ [G].

**Numbered Steps:**
1.  **Global Downscaling:** Iteratively downscale all data in the octree to the coarsest uniform grid level [S1, unofficial].
2.  **Iterative Upscaling:** For each level $L$ from the coarsest level up to the target finest level:
    a.  **Apply 2× Upscaling Network:** Pass the voxel data at level $L$ through a 2× super-resolution neural network (e.g., ESRGAN, SSR-TVD, or STNet) to generate data for level $L+1$ [S1, unofficial].
    b.  **Overwrite Stale Voxels:** Update the octree nodes at level $L+1$ with the new high-resolution data generated by the network, overwriting any previously existing data at the finer level [S1, unofficial].
    c.  **Seam Elimination:** This overwriting step eliminates seam artifacts between different regions of the volume by ensuring all finer-level data is consistently derived from the current coarse level [S1, unofficial].
3.  **Termination:** The loop terminates when the target finest level is reached, yielding the final super-resolved volume [S1, unofficial].

**Formulas:**
Let $V_L$ be the voxel data at level $L$. Let $f_{SR}$ be the 2× super-resolution network [S1, unofficial].
The upscaling step for level $L$ to $L+1$ is:
$$ V_{L+1} = f_{SR}(V_L) $$
The final volume $V_{final}$ is the data at the target level $L_{max}$ [S1, unofficial].

**Parameters:**
*   **Upscaling Factor per Step:** 2× [S1, unofficial].
*   **Backbone Networks:** ESRGAN, SSR-TVD, STNet [S1, unofficial].
*   **Volume Size:** Tested on volumes up to $1024^3$ [S1, unofficial].

**Edge Cases and Pitfalls:**

**Pseudocode:**
```python
def hierarchical_multi_scale_sr(octree, target_level, sr_network):
    """
    Performs hierarchical multi-scale super-resolution on an octree.
    Matches evidence: downscale all to coarsest, then upscale level-by-level, overwriting stale voxels.
    """
    # Phase 1: Downscale all data to the coarsest uniform grid
    # [G] Standard recursive pooling or averaging of child voxels to the coarsest level.
    coarsest_level = octree.coarsest_level
    
    # Phase 2: Iterate and upscale one level at a time
    for current_level in range(coarsest_level, target_level):
        # Collect all nodes at the current level
        current_nodes = [node for node in octree.nodes if node.level == current_level]
        
        # Apply 2x SR network to generate next level data
        # [G] Assuming sr_network processes a batch of voxel grids and returns upscaled grids
        upscaled_grids = sr_network([node.grid for node in current_nodes])
        
        # Overwrite stale voxels at the next level with network output
        next_level = current_level + 1
        for node, grid in zip(current_nodes, upscaled_grids):
            # Update child nodes at next_level with the new data
            for child in node.children:
                child.grid = grid
            # Fallback for flat level storage
            if next_level in octree.level_nodes:
                for next_node in octree.level_nodes[next_level]:
                    if next_node.parent == node:
                        next_node.grid = grid
    return octree
```

## Background
The hierarchical multi-scale SR method was introduced in the context of scientific volume super-resolution, specifically for turbulence and cosmological simulations [S1, unofficial]. It builds on the idea of using hierarchical data structures like octrees to manage large volumes and applies deep learning techniques to enhance their resolution [S1, unofficial]. The method was evaluated using various backbones, including ESRGAN, SSR-TVD, and STNet, demonstrating significant improvements in PSNR over single-step upscaling methods [S1, unofficial].
