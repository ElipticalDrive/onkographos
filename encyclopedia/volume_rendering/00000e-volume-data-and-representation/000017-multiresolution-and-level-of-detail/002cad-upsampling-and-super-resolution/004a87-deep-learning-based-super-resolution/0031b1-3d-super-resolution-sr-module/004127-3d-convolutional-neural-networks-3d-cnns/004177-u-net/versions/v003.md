# U-Net
Also called: U-Net Architecture, U-Net variant
## Overview
The U-Net variant is an encoder-decoder convolutional neural network architecture designed for volumetric segmentation and super-resolution [S1, unofficial]. It extends standard 3D CNNs by adding skip connections between corresponding encoder and decoder stages, allowing the network to combine high-level semantic context with low-level spatial details [S1, unofficial]. It builds on the architecture of [3D Convolutional Neural Networks (3D CNNs)](10439-3d-convolutional-neural-networks-3d-cnns.md) [G].

## How it works
**Inputs and Outputs:**
- Input: A 3D volumetric grid or tensor. Not given in the sources.
- Output: A segmentation map or super-resolved volumetric grid. Not given in the sources.

**Data Structures:**
- The network consists of an encoder (contracting path) and a decoder (expansive path) [S1, unofficial].
- Skip connections link corresponding stages of the encoder and decoder [S1, unofficial].
- Internal block configurations (e.g., exact convolutional layer counts, activation functions, pooling/upsampling methods) are Not given in the sources. [G] (Standard 3D convolutional blocks apply: convolutions, non-linearities, and pooling/upsampling operations.)

**Steps:**
1. **Encoding:** The input volume passes through successive downsampling stages in the encoder to extract hierarchical features [G].
2. **Skip Connections:** Feature maps from each encoder stage are stored and passed directly to the corresponding decoder stage via skip connections [S1, unofficial].
3. **Decoding:** The decoder upsamples features from deeper stages and concatenates them with the corresponding encoder feature maps from the skip connections [G].
4. **Refinement:** The concatenated features pass through convolutional layers to produce the final output [G].
5. **Output:** A final convolution maps features to the target output channels [G].

**Formulas:**
Let $E_i$ denote the feature map at encoder level $i$, and $D_i$ denote the feature map at decoder level $i$. The skip connection operation is defined as:
$$ D_i = \text{Concat}(\text{Upsample}(D_{i+1}), E_i) $$
where $\text{Concat}$ denotes channel-wise concatenation [G].

**Edge Cases and Pitfalls:**
- Memory usage scales with input resolution due to storing intermediate feature maps for skip connections [G].
- Boundary artifacts may occur if padding is not handled consistently during convolution and pooling [G].

## Subtopics

### VC-Net
VC-Net is a hybrid architecture for microvascular segmentation in cerebrovascular micro-MRI [S1, unofficial]. It combines a 3D U-Net operating on raw volumes with a 2D U-Net operating on Maximum Intensity Projections (MIPs) [S1, unofficial]. The two streams are fused via a volume-composition module that projects 2D contextual predictions back into 3D space [S1, unofficial]. On three cerebrovascular segmentation tasks, VC-Net achieved Dice scores of 82.98% (major arteries), 76.46% (major veins), and 74.40% (microvasculature) [S1, unofficial]. These scores outperformed both single-stream 3D U-Net and intensity-based baselines [S1, unofficial]. The design embeds a volume rendering step directly into the learning pipeline [S1, unofficial].

## Background
The U-Net variant builds on the encoder-decoder structure of 3D CNNs, which stack downsampling and upsampling stages to extract and reconstruct spatial features [S1, unofficial]. The addition of skip connections allows the network to preserve high-resolution information, addressing the blurring effects often seen in standard convolutional networks for volumetric data [G]. It has become a standard architecture for tasks such as microvascular segmentation in cerebrovascular micro-MRI [S1, unofficial].
