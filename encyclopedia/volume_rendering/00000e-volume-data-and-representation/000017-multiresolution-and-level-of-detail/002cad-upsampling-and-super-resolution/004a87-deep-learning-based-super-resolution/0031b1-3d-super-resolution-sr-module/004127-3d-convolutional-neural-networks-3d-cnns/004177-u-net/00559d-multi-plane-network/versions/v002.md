# Multi-Plane Network

Also called: Network Architecture for Multi-Plane Output, U-Net with Transposed Convolutions

## Overview
The Multi-Plane Network (MPN) is a 3D U-Net variant that processes neural point features through a sequence of 3D convolutions, pooling, and transposed convolutions with skip connections [S1]. It outputs two feature maps: one with 3 channels and one with 1 channel [S1].

## How it works
### Inputs and Outputs
Input: neural point features with 11 channels [S1].
Output: two $1\times1\times1$ convolution results applied to the final decoder features: one with 3 channels using Leaky ReLU, and one with 1 channel using Softmax [S1].

### Data Structures
The architecture consists of an encoder path, a bottleneck, and a decoder path with skip connections [S1]. The layer specifications are [S1]:
1. **conv0**: $1\times1\times1$ kernel, stride $1\times1\times1$, dilation $1$, in 11, out 16, lrelu.
2. **conv1**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 16, out 32, lrelu.
3. **maxpool1**: $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 32, out 32, lrelu.
4. **conv2**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 32, out 32, lrelu.
5. **maxpool2**: $2\times1\times1$ kernel, stride $2\times1\times1$, dilation $1$, in 32, out 32, lrelu.
6. **conv3**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 32, out 64, lrelu.
7. **maxpool3**: $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 64, out 64, lrelu.
8. **conv4**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 64, out 64, lrelu.
9. **maxpool4**: $2\times1\times1$ kernel, stride $2\times1\times1$, dilation $1$, in 64, out 64, lrelu.
10. **conv5**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 64, out 128, lrelu.
11. **maxpool5**: $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 128, out 128, lrelu.
12. **conv6**: $1\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 128, out 128, lrelu.
13. **up1**: Transposed convolution, $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 128, out 64, lrelu.
14. **conv7**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 128, out 64, lrelu.
15. **up2**: Transposed convolution, $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 64, out 64, lrelu.
16. **conv8**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 128, out 64, lrelu.
17. **up3**: Transposed convolution, $2\times1\times1$ kernel, stride $2\times1\times1$, dilation $1$, in 64, out 64, lrelu.
18. **conv9**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 128, out 32, lrelu.
19. **up4**: Transposed convolution, $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 32, out 32, lrelu.
20. **conv10**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 64, out 32, lrelu.
21. **up5**: Transposed convolution, $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 32, out 32, lrelu.
22. **conv11**: $1\times1\times1$ kernel, stride $1\times1\times1$, dilation $1$, in 32, out 3, lrelu.
23. **conv11**: $1\times1\times1$ kernel, stride $1\times1\times1$, dilation $1$, in 32, out 1, softmax.

Skip connections concatenate the decoder output with the corresponding encoder output before each decoder convolution: `up1` output concatenates with `conv5` output, `up2` with `conv4`, `up3` with `conv3`, `up4` with `conv2`, and `up5` with `conv1` [S1].

### Pseudocode
```python
import torch
import torch.nn as nn

class MultiPlaneNetwork(nn.Module):
    def __init__(self):
        super(MultiPlaneNetwork, self).__init__()
        
        # Encoder
        self.conv0 = nn.Conv3d(11, 16, kernel_size=1, stride=1)
        self.conv1 = nn.Conv3d(16, 32, kernel_size=3, stride=1)
        self.maxpool1 = nn.MaxPool3d(kernel_size=2, stride=2)
        self.conv2 = nn.Conv3d(32, 32, kernel_size=3, stride=1)
        self.maxpool2 = nn.MaxPool3d(kernel_size=(2,1,1), stride=(2,1,1))
        self.conv3 = nn.Conv3d(32, 64, kernel_size=3, stride=1)
        self.maxpool3 = nn.MaxPool3d(kernel_size=2, stride=2)
        self.conv4 = nn.Conv3d(64, 64, kernel_size=3, stride=1)
        self.maxpool4 = nn.MaxPool3d(kernel_size=(2,1,1), stride=(2,1,1))
        self.conv5 = nn.Conv3d(64, 128, kernel_size=3, stride=1)
        self.maxpool5 = nn.MaxPool3d(kernel_size=2, stride=2)
        self.conv6 = nn.Conv3d(128, 128, kernel_size=(1,3,3), stride=1)
        
        # Decoder
        self.up1 = nn.ConvTranspose3d(128, 64, kernel_size=2, stride=2)
        self.conv7 = nn.Conv3d(128, 64, kernel_size=3, stride=1)
        self.up2 = nn.ConvTranspose3d(64, 64, kernel_size=2, stride=2)
        self.conv8 = nn.Conv3d(128, 64, kernel_size=3, stride=1)
        self.up3 = nn.ConvTranspose3d(64, 64, kernel_size=(2,1,1), stride=(2,1,1))
        self.conv9 = nn.Conv3d(128, 32, kernel_size=3, stride=1)
        self.up4 = nn.ConvTranspose3d(32, 32, kernel_size=2, stride=2)
        self.conv10 = nn.Conv3d(64, 32, kernel_size=3, stride=1)
        self.up5 = nn.ConvTranspose3d(32, 32, kernel_size=3, stride=1)
        
        # Outputs
        self.conv11_rgb = nn.Conv3d(32, 3, kernel_size=1, stride=1)
        self.conv11_density = nn.Conv3d(32, 1, kernel_size=1, stride=1)
        
        self.lrelu = nn.LeakyReLU(negative_slope=0.2)
        self.softmax = nn.Softmax(dim=1)

    def forward(self, x):
        # x shape: [B, 11, D, H, W]
        
        # Encoder
        e0 = self.lrelu(self.conv0(x))
        e1 = self.lrelu(self.conv1(e0))
        e2 = self.lrelu(self.maxpool1(e1))
        e3 = self.lrelu(self.conv2(e2))
        e4 = self.lrelu(self.maxpool2(e3))
        e5 = self.lrelu(self.conv3(e4))
        e6 = self.lrelu(self.maxpool3(e5))
        e7 = self.lrelu(self.conv4(e6))
        e8 = self.lrelu(self.maxpool4(e7))
        e9 = self.lrelu(self.conv5(e8))
        e10 = self.lrelu(self.maxpool5(e9))
        e11 = self.lrelu(self.conv6(e10))
        
        # Decoder with Skip Connections
        d1 = self.up1(e11)
        d1 = torch.cat([d1, e9], dim=1)
        d1 = self.lrelu(self.conv7(d1))
        
        d2 = self.up2(d1)
        d2 = torch.cat([d2, e7], dim=1)
        d2 = self.lrelu(self.conv8(d2))
        
        d3 = self.up3(d2)
        d3 = torch.cat([d3, e5], dim=1)
        d3 = self.lrelu(self.conv9(d3))
        
        d4 = self.up4(d3)
        d4 = torch.cat([d4, e3], dim=1)
        d4 = self.lrelu(self.conv10(d4))
        
        d5 = self.up5(d4)
        d5 = torch.cat([d5, e1], dim=1)
        d5 = self.lrelu(self.conv11(d5))
        
        # Final Outputs
        rgb = self.lrelu(self.conv11_rgb(d5))
        density = self.softmax(self.conv11_density(d5))
        
        return rgb, density
```

### Parameters and Edge Cases
- **Activation**: Leaky ReLU is used for all layers except the final density output, which uses Softmax [S1].
- **Padding**: Not given in the sources.
- **Skip Connections**: The decoder concatenates the upsampled feature map with the corresponding encoder feature map before each decoder convolution [S1].
- **Degenerate Input**: Not given in the sources.

## Background
The Multi-Plane Network was introduced in the paper "Neural Point Cloud Rendering via Multi-Plane Projection" by Kara-Ali Aliev, Dmitry Ulyanov, and Victor Lempitsky, published in CVPR 2020 [S1]. It is a 3D U-Net variant that processes neural point features [S1]. It builds on [U-Net](10523-u-net.md).
