# Multi-Plane Network

Also called: Network Architecture for Multi-Plane Output, U-Net with Transposed Convolutions

## Overview
The Multi-Plane Network (MPN) is a 3D U-Net variant that processes neural point features through a sequence of 3D convolutions, pooling, and transposed convolutions with skip connections [S1]. It outputs two feature maps: one with 3 channels and one with 1 channel [S1].

## How it works
### Inputs and Outputs
Input: neural point features with 11 channels [S1].
Output: two $1\times1\times1$ convolution results applied to the final decoder features: one with 3 channels using Leaky ReLU, and one with 1 channel using Softmax [S1].

### Data Structures
The architecture consists of an encoder path, a bottleneck, and a decoder path with skip connections [S1]. The layer specifications are [S1]:
1. **conv0**: $1\times1\times1$ kernel, stride $1\times1\times1$, dilation $1$, in 11, out 16, lrelu [S1].
2. **conv1**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 16, out 32, lrelu [S1].
3. **maxpool1**: $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 32, out 32, lrelu [S1].
4. **conv2**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 32, out 32, lrelu [S1].
5. **maxpool2**: $2\times1\times1$ kernel, stride $2\times1\times1$, dilation $1$, in 32, out 32, lrelu [S1].
6. **conv3**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 32, out 64, lrelu [S1].
7. **maxpool3**: $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 64, out 64, lrelu [S1].
8. **conv4**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 64, out 64, lrelu [S1].
9. **maxpool4**: $2\times1\times1$ kernel, stride $2\times1\times1$, dilation $1$, in 64, out 64, lrelu [S1].
10. **conv5**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 64, out 128, lrelu [S1].
11. **maxpool5**: $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 128, out 128, lrelu [S1].
12. **conv6**: $1\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 128, out 128, lrelu [S1].
13. **up1**: Transposed convolution, $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 128, out 64, lrelu [S1].
14. **conv7**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 128, out 64, lrelu [S1].
15. **up2**: Transposed convolution, $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 64, out 64, lrelu [S1].
16. **conv8**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 128, out 64, lrelu [S1].
17. **up3**: Transposed convolution, $2\times1\times1$ kernel, stride $2\times1\times1$, dilation $1$, in 64, out 64, lrelu [S1].
18. **conv9**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 128, out 32, lrelu [S1].
19. **up4**: Transposed convolution, $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$, in 32, out 32, lrelu [S1].
20. **conv10**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 64, out 32, lrelu [S1].
21. **up5**: Transposed convolution, $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$, in 32, out 32, lrelu [S1].
22. **conv11**: $1\times1\times1$ kernel, stride $1\times1\times1$, dilation $1$, in 32, out 3, lrelu [S1].
23. **conv11**: $1\times1\times1$ kernel, stride $1\times1\times1$, dilation $1$, in 32, out 1, softmax [S1].

Skip connections concatenate the decoder output with the corresponding encoder output before each decoder convolution: `up1` output concatenates with `conv5` output, `up2` with `conv4`, `up3` with `conv3`, `up4` with `conv2`, and `up5` with `conv1` [S1].

### Pseudocode
```python
def MultiPlaneNetwork(features):
    # Encoder
    e0 = lrelu(conv3d(features, in_channels=11, out_channels=16, kernel_size=1, stride=1))
    e1 = lrelu(conv3d(e0, in_channels=16, out_channels=32, kernel_size=3, stride=1))
    e2 = lrelu(maxpool3d(e1, kernel_size=2, stride=2))
    e3 = lrelu(conv3d(e2, in_channels=32, out_channels=32, kernel_size=3, stride=1))
    e4 = lrelu(maxpool3d(e3, kernel_size=(2,1,1), stride=(2,1,1)))
    e5 = lrelu(conv3d(e4, in_channels=32, out_channels=64, kernel_size=3, stride=1))
    e6 = lrelu(maxpool3d(e5, kernel_size=2, stride=2))
    e7 = lrelu(conv3d(e6, in_channels=64, out_channels=64, kernel_size=3, stride=1))
    e8 = lrelu(maxpool3d(e7, kernel_size=(2,1,1), stride=(2,1,1)))
    e9 = lrelu(conv3d(e8, in_channels=64, out_channels=128, kernel_size=3, stride=1))
    e10 = lrelu(maxpool3d(e9, kernel_size=2, stride=2))
    e11 = lrelu(conv3d(e10, in_channels=128, out_channels=128, kernel_size=(1,3,3), stride=1))

    # Decoder with Skip Connections
    d1 = lrelu(conv3d(concatenate(transpose_conv3d(e11, kernel_size=2, stride=2), e9, dim=1), in_channels=128, out_channels=64, kernel_size=3, stride=1))
    d2 = lrelu(conv3d(concatenate(transpose_conv3d(d1, kernel_size=2, stride=2), e7, dim=1), in_channels=128, out_channels=64, kernel_size=3, stride=1))
    d3 = lrelu(conv3d(concatenate(transpose_conv3d(d2, kernel_size=(2,1,1), stride=(2,1,1)), e5, dim=1), in_channels=128, out_channels=32, kernel_size=3, stride=1))
    d4 = lrelu(conv3d(concatenate(transpose_conv3d(d3, kernel_size=2, stride=2), e3, dim=1), in_channels=64, out_channels=32, kernel_size=3, stride=1))
    d5 = lrelu(conv3d(concatenate(transpose_conv3d(d4, kernel_size=3, stride=1), e1, dim=1), in_channels=64, out_channels=32, kernel_size=3, stride=1))

    # Final Outputs
    rgb = lrelu(conv3d(d5, in_channels=32, out_channels=3, kernel_size=1, stride=1))
    density = softmax(conv3d(d5, in_channels=32, out_channels=1, kernel_size=1, stride=1), dim=1)

    return rgb, density
```

### Parameters and Edge Cases
- **Activation**: Leaky ReLU is used for all layers except the final density output, which uses Softmax [S1].
- **Padding**: Not given in the sources.
- **Skip Connections**: The decoder concatenates the upsampled feature map with the corresponding encoder feature map before each decoder convolution [S1].
- **Degenerate Input**: Not given in the sources.

## Background
The Multi-Plane Network was introduced in the paper "Neural Point Cloud Rendering via Multi-Plane Projection" by Kara-Ali Aliev, Dmitry Ulyanov, and Victor Lempitsky, published in CVPR 2020 [S1]. It is a 3D U-Net variant that processes neural point features [S1]. It builds on [U-Net](10523-u-net.md).
