# Multi-Plane Network

Also called: Network Architecture for Multi-Plane Output, U-Net with Transposed Convolutions

## Overview
The Multi-Plane Network (MPN) is a 3D U-Net variant designed to process neural point features and output multi-plane representations for volume rendering [S1]. It solves the problem of learning spatially coherent volumetric properties from sparse, unstructured point clouds by projecting features onto 2D planes and aggregating them through a deep convolutional encoder-decoder structure [S1]. Unlike standard 3D CNNs that operate on dense voxel grids, MPN operates on the projected multi-plane feature maps, allowing for efficient handling of large-scale scenes while preserving high-frequency details through skip connections [S1].

## How it works
The MPN takes neural point features as input and outputs a set of multi-plane feature maps. The architecture follows a symmetric U-Net structure with an encoder path (downsampling) and a decoder path (upsampling), connected by skip connections [S1].

### Data Structures
The input is a set of 2D feature maps corresponding to the projections of the 3D scene onto the XY, YZ, and XZ planes. The network processes these planes jointly or sequentially, but the architecture description implies a unified 3D convolutional processing flow where the "planes" are the spatial dimensions of the 3D tensor [S1].

**Layer Specifications:**
All convolutional layers use Leaky ReLU (lrelu) activation unless specified otherwise. Transposed convolutions are used for upsampling.

1.  **conv0**: $1\times1\times1$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 11, Output channels: 16. Activation: lrelu.
2.  **conv1**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 16, Output channels: 32. Activation: lrelu.
3.  **maxpool1**: $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$. Input channels: 32, Output channels: 32. Activation: lrelu.
4.  **conv2**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 32, Output channels: 32. Activation: lrelu.
5.  **maxpool2**: $2\times1\times1$ kernel, stride $2\times1\times1$, dilation $1$. Input channels: 32, Output channels: 32. Activation: lrelu.
6.  **conv3**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 32, Output channels: 64. Activation: lrelu.
7.  **maxpool3**: $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$. Input channels: 64, Output channels: 64. Activation: lrelu.
8.  **conv4**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 64, Output channels: 64. Activation: lrelu.
9.  **maxpool4**: $2\times1\times1$ kernel, stride $2\times1\times1$, dilation $1$. Input channels: 64, Output channels: 64. Activation: lrelu.
10. **conv5**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 64, Output channels: 128. Activation: lrelu.
11. **maxpool5**: $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$. Input channels: 128, Output channels: 128. Activation: lrelu.
12. **conv6**: $1\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 128, Output channels: 128. Activation: lrelu.
13. **up1**: Transposed convolution, $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$. Input channels: 128, Output channels: 64. Activation: lrelu.
14. **conv7**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 128 (concatenated), Output channels: 64. Activation: lrelu.
15. **up2**: Transposed convolution, $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$. Input channels: 64, Output channels: 64. Activation: lrelu.
16. **conv8**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 128 (concatenated), Output channels: 64. Activation: lrelu.
17. **up3**: Transposed convolution, $2\times1\times1$ kernel, stride $2\times1\times1$, dilation $1$. Input channels: 64, Output channels: 64. Activation: lrelu.
18. **conv9**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 128 (concatenated), Output channels: 32. Activation: lrelu.
19. **up4**: Transposed convolution, $2\times2\times2$ kernel, stride $2\times2\times2$, dilation $1$. Input channels: 32, Output channels: 32. Activation: lrelu.
20. **conv10**: $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 64 (concatenated), Output channels: 32. Activation: lrelu.
21. **up5**: Transposed convolution, $3\times3\times3$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 32, Output channels: 32. Activation: lrelu.
22. **conv11**: $1\times1\times1$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 32, Output channels: 3. Activation: lrelu.
23. **conv11**: $1\times1\times1$ kernel, stride $1\times1\times1$, dilation $1$. Input channels: 32, Output channels: 1. Activation: softmax.

*Note: The source lists two layers named `conv11`. The first outputs 3 channels (likely RGB or color features), and the second outputs 1 channel with softmax (likely density or opacity). In implementation, these should be distinct layers, e.g., `conv11_rgb` and `conv11_density`.*

### Pseudocode

```python
import torch
import torch.nn as nn

class MultiPlaneNetwork(nn.Module):
    def __init__(self):
        super(MultiPlaneNetwork, self).__init__()
        
        # Encoder
        self.conv0 = nn.Conv3d(11, 16, kernel_size=1, stride=1, padding=0)
        self.conv1 = nn.Conv3d(16, 32, kernel_size=3, stride=1, padding=1)
        self.maxpool1 = nn.MaxPool3d(kernel_size=2, stride=2)
        self.conv2 = nn.Conv3d(32, 32, kernel_size=3, stride=1, padding=1)
        self.maxpool2 = nn.MaxPool3d(kernel_size=(2,1,1), stride=(2,1,1))
        self.conv3 = nn.Conv3d(32, 64, kernel_size=3, stride=1, padding=1)
        self.maxpool3 = nn.MaxPool3d(kernel_size=2, stride=2)
        self.conv4 = nn.Conv3d(64, 64, kernel_size=3, stride=1, padding=1)
        self.maxpool4 = nn.MaxPool3d(kernel_size=(2,1,1), stride=(2,1,1))
        self.conv5 = nn.Conv3d(64, 128, kernel_size=3, stride=1, padding=1)
        self.maxpool5 = nn.MaxPool3d(kernel_size=2, stride=2)
        self.conv6 = nn.Conv3d(128, 128, kernel_size=(1,3,3), stride=1, padding=(0,1,1))
        
        # Decoder
        self.up1 = nn.ConvTranspose3d(128, 64, kernel_size=2, stride=2)
        self.conv7 = nn.Conv3d(128, 64, kernel_size=3, stride=1, padding=1) # 64 from up1 + 64 from skip
        self.up2 = nn.ConvTranspose3d(64, 64, kernel_size=2, stride=2)
        self.conv8 = nn.Conv3d(128, 64, kernel_size=3, stride=1, padding=1) # 64 from up2 + 64 from skip
        self.up3 = nn.ConvTranspose3d(64, 64, kernel_size=(2,1,1), stride=(2,1,1))
        self.conv9 = nn.Conv3d(128, 32, kernel_size=3, stride=1, padding=1) # 64 from up3 + 64 from skip
        self.up4 = nn.ConvTranspose3d(32, 32, kernel_size=2, stride=2)
        self.conv10 = nn.Conv3d(64, 32, kernel_size=3, stride=1, padding=1) # 32 from up4 + 32 from skip
        self.up5 = nn.ConvTranspose3d(32, 32, kernel_size=3, stride=1, padding=1)
        
        # Outputs
        self.conv11_rgb = nn.Conv3d(32, 3, kernel_size=1, stride=1, padding=0)
        self.conv11_density = nn.Conv3d(32, 1, kernel_size=1, stride=1, padding=0)
        
        self.lrelu = nn.LeakyReLU(negative_slope=0.2)
        self.softmax = nn.Softmax(dim=1)

    def forward(self, x):
        # x shape: [B, 11, D, H, W]
        
        # Encoder
        e0 = self.lrelu(self.conv0(x))
        e1 = self.lrelu(self.conv1(e0))
        e2 = self.lrelu(self.maxpool1(e1))
        e3 = self.lrelu(self.conv2(e2))
        e4 = self.lrelu(self.maxpool2(e3))
        e5 = self.lrelu(self.conv3(e4))
        e6 = self.lrelu(self.maxpool3(e5))
        e7 = self.lrelu(self.conv4(e6))
        e8 = self.lrelu(self.maxpool4(e7))
        e9 = self.lrelu(self.conv5(e8))
        e10 = self.lrelu(self.maxpool5(e9))
        e11 = self.lrelu(self.conv6(e10))
        
        # Decoder with Skip Connections
        d1 = self.up1(e11)
        # Concatenate with e7 (conv4 output)
        d1 = torch.cat([d1, e7], dim=1)
        d1 = self.lrelu(self.conv7(d1))
        
        d2 = self.up2(d1)
        # Concatenate with e5 (conv3 output)
        d2 = torch.cat([d2, e5], dim=1)
        d2 = self.lrelu(self.conv8(d2))
        
        d3 = self.up3(d2)
        # Concatenate with e3 (conv2 output)
        d3 = torch.cat([d3, e3], dim=1)
        d3 = self.lrelu(self.conv9(d3))
        
        d4 = self.up4(d3)
        # Concatenate with e1 (conv1 output)
        d4 = torch.cat([d4, e1], dim=1)
        d4 = self.lrelu(self.conv10(d4))
        
        d5 = self.up5(d4)
        # Concatenate with e0 (conv0 output)
        d5 = torch.cat([d5, e0], dim=1)
        d5 = self.lrelu(self.conv11_rgb(d5)) # Intermediate feature for RGB
        
        # Final Outputs
        # Note: The source lists conv11 twice. Assuming the last conv11 is for density.
        # The input to the final conv11 is d5 (32 channels).
        rgb = self.lrelu(self.conv11_rgb(d5)) # Output 3 channels
        density = self.softmax(self.conv11_density(d5)) # Output 1 channel
        
        return rgb, density
```

### Parameters and Edge Cases
- **Activation**: Leaky ReLU is used throughout the encoder and decoder, except for the final density output which uses Softmax [S1].
- **Padding**: Standard `padding=1` is used for $3\times3\times3$ convolutions to maintain spatial dimensions. `padding=0` for $1\times1\times1$ and `padding=(0,1,1)` for $1\times3\times3$ [S1].
- **Skip Connections**: The decoder upsamples and concatenates with the corresponding encoder feature maps. The channel dimensions must match for concatenation. For example, `up1` outputs 64 channels, and `conv4` (e7) outputs 64 channels, resulting in 128 channels input to `conv7` [S1].
- **Degenerate Input**: The network expects input features of dimension 11. If the input dimension differs, the first layer `conv0` must be adjusted [S1].

## Background
The Multi-Plane Network was introduced in the paper "Neural Point Cloud Rendering via Multi-Plane Projection" by Kara-Ali Aliev, Dmitry Ulyanov, and Victor Lempitsky, published in CVPR 2020 [S1]. It builds upon the concept of neural point-based graphics, where 3D points are associated with learned features that are projected onto 2D planes for rendering [S1]. The architecture is a variant of the U-Net, adapted for 3D convolutional processing of these projected features [S1].
