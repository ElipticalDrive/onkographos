# SIREN + SRDenseNet Hybrid for Medical SR

Also called: Proposed INR Architecture, SIREN with Lanczos downsampling and SRDenseNet upsampling, SIREN with Our Architecture, SIREN-based Volume Compression with Pre/Post-Processing Architecture, Sheibanifard and Yu Medical SR, our architecture

## Overview
This method addresses the high GPU memory consumption and slow training speeds associated with training Implicit Neural Representations (INRs) directly on high-resolution volumetric medical data [S1][S3, unofficial]. It solves this by decoupling the representation into two stages: a SIREN MLP trained on heavily downsampled low-resolution (LR) data to capture the global structure, followed by a Super-Resolution DenseNet (SRDenseNet) to reconstruct the high-resolution (HR) details [S1][S3, unofficial]. It sets itself apart from direct SIREN training [S1][S3, unofficial] by significantly reducing the optimization burden on the MLP, and from pure deep learning SR [Siblings] by leveraging the continuous, coordinate-based nature of INRs for the base geometry.

## How it works
**Inputs:**
* High-resolution volumetric medical data (e.g., CT scans) [S3, unofficial].
* Target low-resolution dimensions for the SIREN training (e.g., $128 \times 128 \times 115$) [S3, unofficial].

**Outputs:**
* A trained SIREN MLP [S1][S3, unofficial].
* A trained SRDenseNet model [S1][S3, unofficial].
* A reconstructed high-resolution volume [S1][S3, unofficial].

**Data Structures:**
1. **SIREN MLP:** A Multi-Layer Perceptron with sinusoidal activation [S1][S3, unofficial].
   * Architecture: $L$ linear layers (where $L \in \{2, 3, 4\}$) [S1][S3, unofficial].
   * Hidden layers: Each hidden layer has 128 neurons [S1][S3, unofficial].
   * Output layer: 1 neuron (scalar intensity) [S1][S3, unofficial].
   * Parameter counts for specific depths [S1]:
     * 2 Layers: Total 17,153 params. Linear-1: 512 params; Linear-2: 16,512 params; Linear-3 (Output): 129 params.
     * 3 Layers: Total 33,665 params. Linear-1: 512; Linear-2: 16,512; Linear-3: 16,512; Linear-4 (Output): 129.
     * 4 Layers: Total 50,177 params. Linear-1: 512; Linear-2: 16,512; Linear-3: 16,512; Linear-4: 16,512; Linear-5 (Output): 129.
   * Input shape: Coordinates $(x, y, z)$ [S1][S3, unofficial].
   * Output shape: Scalar intensity [S1][S3, unofficial].
2. **SRDenseNet:** A pre-trained super-resolution network [S3, unofficial]. Specific internal architecture details are "Not given in the sources."

**Numbered Steps:**
1. **Downsampling:** Take the original high-resolution volume (e.g., $512 \times 512 \times 463$) [S3, unofficial]. Apply Lanczos resampling to downsample the volume to the target low-resolution dimensions (e.g., $128 \times 128 \times 115$) [S1][S3, unofficial]. This reduces the voxel count from 121,372,672 to 1,884,160 [S3, unofficial].
2. **SIREN Training:** Initialize the SIREN MLP with the specified depth ($L$) and width (128 neurons) [S1][S3, unofficial]. Use the Adam optimizer with a learning rate of 0.0015 and a batch size of 216 [S1][S3, unofficial]. Define the loss function as Mean Squared Error (MSE) between the SIREN output and the downsampled LR volume values [S1][S3, unofficial]. Train the network for 50,000 iterations [S3, unofficial]. The training is performed on the low-resolution data only [S1][S3, unofficial].
3. **SRDenseNet Training (Pre-processing):** Train the SRDenseNet on the same class of CT data [S1][S3, unofficial]. The source states it is trained "in advance" [S1][S3, unofficial]. Specific loss functions or training hyperparameters for the SRDenseNet are "Not given in the sources."
4. **Reconstruction:** Query the trained SIREN MLP at the low-resolution coordinate grid points to generate a low-resolution reconstruction [S1][S3, unofficial]. Pass the SIREN-reconstructed low-resolution image through the pre-trained SRDenseNet [S1][S3, unofficial]. The output of the SRDenseNet is the final high-resolution reconstruction [S1][S3, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.optim as optim

class SIRENLayer(nn.Module):
    def __init__(self, in_features, out_features, w0=30.0):
        super().__init__()
        self.linear = nn.Linear(in_features, out_features)
        self.w0 = w0
        nn.init.uniform_(self.linear.weight, -1 / in_features, 1 / in_features)
        nn.init.zeros_(self.linear.bias)

    def forward(self, x):
        return torch.sin(self.w0 * self.linear(x))

class SIREN(nn.Module):
    def __init__(self, depth=4, hidden_dim=128, input_dim=3):
        super().__init__()
        layers = []
        layers.append(SIRENLayer(input_dim, hidden_dim))
        for _ in range(depth - 2):
            layers.append(SIRENLayer(hidden_dim, hidden_dim))
        layers.append(nn.Linear(hidden_dim, 1))
        self.network = nn.Sequential(*layers)

    def forward(self, coords):
        return self.network(coords).squeeze(-1)

def train_siren(lr_volume_values, lr_coords, depth=4, lr=0.0015, batch_size=216, iterations=50000):
    model = SIREN(depth=depth)
    optimizer = optim.Adam(model.parameters(), lr=lr)
    criterion = nn.MSELoss()
    
    for i in range(iterations):
        indices = torch.randperm(len(lr_coords))[:batch_size]
        batch_coords = lr_coords[indices]
        batch_values = lr_volume_values[indices]
        
        optimizer.zero_grad()
        predictions = model(batch_coords)
        loss = criterion(predictions, batch_values)
        loss.backward()
        optimizer.step()
        
    return model

def reconstruct_hr_volume(siren_model, srdensenet_model, lr_coords, lr_volume_shape):
    siren_lr_output = siren_model(lr_coords)
    h_lr, w_lr = lr_volume_shape[1], lr_volume_shape[2]
    siren_lr_image = siren_lr_output.detach().cpu().numpy().reshape(1, 1, h_lr, w_lr)
    siren_lr_tensor = torch.from_numpy(siren_lr_image).float()
    hr_reconstruction = srdensenet_model(siren_lr_tensor)
    return hr_reconstruction
```

**Parameters:**
* **SIREN Depth:** 2, 3, or 4 linear layers [S1][S3, unofficial].
* **SIREN Width:** 128 neurons per hidden layer [S1][S3, unofficial].
* **Optimizer:** Adam [S1][S3, unofficial].
* **Learning Rate:** 0.0015 [S1][S3, unofficial].
* **Batch Size:** 216 [S1][S3, unofficial].
* **Loss Function:** Mean Squared Error (MSE) [S1][S3, unofficial].
* **Downsampling Method:** Lanczos resampling [S1][S3, unofficial].
* **Training Iterations:** 50,000 [S3, unofficial].

**Edge Cases and Pitfalls:**
* **Precision:** The input data is 12-bit grey tone [S3, unofficial]. The SIREN output is a float. Care must be taken to normalize inputs and outputs appropriately during training and inference [G].
* **Boundaries:** The method relies on Lanczos resampling for downsampling. Artifacts from resampling may propagate to the SIREN training [S1][S3, unofficial].
* **Degenerate Input:** The method is designed for volumetric medical images (CT) [S3, unofficial]. Performance on non-medical or non-volumetric data is not discussed [S1][S3, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
* **GPU Memory:** Significantly reduced compared to training SIREN on full-resolution data [S3, unofficial].
  * 2-Layer SIREN: 1,038 KB [S3, unofficial].
  * 3-Layer SIREN: 1,296 KB [S3, unofficial].
  * 4-Layer SIREN: 1,554 KB [S3, unofficial].
  * Comparison: SIREN without architecture (full res) uses 10,254 KB (2-layer), 10,512 KB (3-layer), 10,770 KB (4-layer) [S3, unofficial].
* **Training Time:** Reduced compared to full-resolution SIREN [S3, unofficial].
  * 2-Layer: 55.76s / 50k iters [S3, unofficial].
  * 3-Layer: 74.80s / 50k iters [S3, unofficial].
  * 4-Layer: 99.61s / 50k iters [S3, unofficial].
  * Comparison: SIREN without architecture uses 664.92s (2-layer), 1004.21s (3-layer), 1336.53s (4-layer) [S3, unofficial].

**Measured Performance:**
* **Dataset:** Visible Human Project, 463 DICOM axial CT slices, 512x512 resolution, 12-bit grey tone, 0.5mm slice thickness [S3, unofficial].
* **Compression Ratio:**
  * 2-Layer: 3.65x [S3, unofficial].
  * 3-Layer: 1.96x [S3, unofficial].
  * 4-Layer: 1.28x [S3, unofficial].
  * Note: Compression ratio excludes decoder model size [S2, unofficial].
* **PSNR (Peak Signal-to-Noise Ratio):**
  * 2-Layer: 34.670 dB [S3, unofficial].
  * 3-Layer: 34.865 dB [S3, unofficial].
  * 4-Layer: 35.140 dB [S3, unofficial].
  * Comparison: SIREN without architecture achieves 25.269 dB (2-layer), 28.800 dB (3-layer), 30.689 dB (4-layer) [S3, unofficial].

**Strengths and Limitations:**
* **Strengths:** Drastic reduction in GPU memory and training time compared to direct SIREN training. Higher PSNR than direct SIREN training [S1][S3, unofficial].
* **Limitations:** Compression ratios are relatively low (1.3–3.7x) compared to other methods [S2, unofficial]. Requires pre-training of SRDenseNet. The PSNR gap between different layer counts decreases as layers increase, but the architecture consistently outperforms direct SIREN [S1][S3, unofficial].

**When to Use:**
* When GPU memory is a constraint for training INRs on high-resolution medical volumes [S3, unofficial].
* When training speed is critical [S3, unofficial].
* When high reconstruction quality (PSNR) is required compared to direct SIREN [S1][S3, unofficial].

**When Not to Use:**
* When very high compression ratios are needed (this method offers low compression) [S2, unofficial].
* When a fully end-to-end differentiable pipeline from raw data to HR is required without a separate pre-trained SR module [S1][S3, unofficial].

## Background
The method addresses the limitations of applying SIREN directly to high-resolution volumetric data, which leads to high GPU memory consumption and low training speed [S1][S3, unofficial]. It is based on the Visible Human Project dataset [S3, unofficial]. The authors introduced a hybrid architecture combining SIREN with Lanczos downsampling and SRDenseNet upsampling [S1][S3, unofficial].
