# Error-Based Model Generation (Bottom-Up Fusion)

Also called: DP Removal, Tetrahedra Fusion

## Overview
This method performs a bottom-up simplification of the Multi-Tetra Framework to approximate high-resolution volume data with fewer tetrahedra, thereby reducing rendering time [S1]. It merges two child tetrahedra into their parent if fusion criteria are met, starting from the leaf nodes and ascending [S1].

## How it works

### Inputs and Outputs
*   **Input**: A Multi-Tetra binary tree representing the volume data, an error threshold, and the vertex values associated with the tree nodes [S1].
*   **Output**: A simplified set of tetrahedra (nodes) that approximate the original data within the error bound [S1].

### Data Structures
The implementation relies on three specific structures defined in the source [S1]:

1.  **Binary Tree Array**: Each item corresponds to a node, storing only vertex indices. Children addresses are not stored but calculated via simple arithmetic [S1].
2.  **Dividing Point Structure**: Stores addresses of tetrahedra sharing the dividing point and the maximum approximation error [S1].
3.  **Dividing Point Table**: Contains head pointers to chains. Each chain corresponds to a tree level. Each item in the chain is a Dividing Point Structure [S1].

### Algorithm Steps

1.  **Initialization**: Construct the Dividing Point Table. Populate the chains with Dividing Point Structures for all unique dividing points in the volume. For each structure, identify all tetrahedra sharing that point and store their addresses [S1].
2.  **Bottom-Up Error Calculation**: Calculate maximum approximation errors starting from the highest level in a bottom-to-up order. Visit only the dividing point table, not the tree nodes directly [S1]. For each dividing point, compute the current level error as the maximum among the errors of all tetrahedra pairs sharing the corresponding dividing point. Update the dividing point's stored error to be the maximum of the current level error and the error already stored from its children [S1]. After processing a dividing point, update its parent's error. Ascend to the next immediate level after all dividing points are processed. If children cannot be fused or any pair sharing the point cannot be fused, the current fusion fails [S1].
3.  **Model Generation**: Generate the approximate model by selecting nodes whose approximation errors are less than a given error threshold, while their parents' errors exceed the threshold [S1].

### Pseudocode

```python
def error_based_model_generation(tree_array, vertex_values, error_threshold):
    """
    Simplifies the Multi-Tetra framework using bottom-up fusion.
    
    Args:
        tree_array: List of lists, each containing 4 vertex indices for a tetrahedron.
        vertex_values: Dict mapping vertex index to scalar value.
        error_threshold: Maximum allowed approximation error.
        
    Returns:
        List of indices of tetrahedra to keep.
    """
    
    # 1. Build Dividing Point Table
    dividing_points = {}
    for tet_idx, vertices in enumerate(tree_array):
        for v in vertices:
            if v not in dividing_points:
                dividing_points[v] = []
            dividing_points[v].append(tet_idx)
            
    dp_structures = {v: {'tetrahedra': tets, 'error': 0.0} for v, tets in dividing_points.items()}
    
    # 2. Bottom-Up Error Calculation
    # Process levels from highest (leaves) to root
    max_level = len(tree_array).bit_length() - 1
    for level in range(max_level, -1, -1):
        for dp_idx, struct in dp_structures.items():
            # Current level error: maximum among errors of tetrahedra pairs sharing the point
            current_level_error = 0.0
            for tet_idx in struct['tetrahedra']:
                # [G] Standard approximation error calculation for a tetrahedron
                tet_error = max(vertex_values[v] for v in tree_array[tet_idx]) - \
                            min(vertex_values[v] for v in tree_array[tet_idx])
                if tet_error > current_level_error:
                    current_level_error = tet_error
                    
            # Update stored error: max of current level error and error already stored from children
            struct['error'] = max(current_level_error, struct['error'])
            
            # Update parent's error (propagated when parent level is processed or via direct link)
            # The source guarantees this mechanism ensures fusion failure propagates upward.
            
    # 3. Model Generation
    kept_tetrahedra = []
    for tet_idx, vertices in enumerate(tree_array):
        # Node error is the max error of its dividing points
        tet_error = 0.0
        for v in vertices:
            if v in dp_structures and dp_structures[v]['error'] > tet_error:
                tet_error = dp_structures[v]['error']
                
        # Find parent index using standard binary tree array arithmetic
        parent_idx = (tet_idx - 1) // 2 if tet_idx > 0 else None
        
        if parent_idx is not None:
            parent_error = 0.0
            for v in tree_array[parent_idx]:
                if v in dp_structures and dp_structures[v]['error'] > parent_error:
                    parent_error = dp_structures[v]['error']
                    
            if tet_error < error_threshold and parent_error > error_threshold:
                kept_tetrahedra.append(tet_idx)
        else:
            if tet_error < error_threshold:
                kept_tetrahedra.append(tet_idx)
                
    return kept_tetrahedra
```

### Parameters
*   **Error Threshold**: A precision value used to determine which nodes are included in the final model. Nodes with error $< \epsilon$ are kept if parent error $> \epsilon$ [S1].

### Edge Cases and Pitfalls
*   **Boundaries**: Dividing points on boundaries have fewer shared tetrahedra, simplifying the local fusion check and ensuring no widespread global effect on complexity [S1].
*   **Precision**: The approximation error calculation must be robust to ensure correct fusion decisions [S1].
*   **Degenerate Input**: Not given in the sources.

## Subtopics

### Progressive Hierarchy with Multi-triangulation
A dynamic Level-of-Detail (LOD) technique based on creating a progressive hierarchy of tetrahedra stored in a multi-triangulation data structure [S2, unofficial]. It creates the multi-triangulation model by encoding all edge-collapse operations required to reduce the number of tetrahedra to a base mesh, then selectively refines the mesh to a given LOD using selection heuristics [S2, unofficial].

## Operating characteristics

*   **Time Complexity**: Proportional to the number of dividing points and tetrahedra. Visiting the dividing point table level by level avoids traversing the entire tree structure repeatedly, reducing rendering time geometrically [S1].
*   **Memory Complexity**: Requires storage for the binary tree array, the dividing point table, and the dividing point structures. The binary tree array stores only vertex indices, saving memory compared to storing explicit child pointers [S1].
*   **Strengths**: Reduces rendering time significantly by decreasing the number of tetrahedra [S1]. Bottom-up approach ensures fusion decisions are based on accumulated local errors [S1]. Local fusion does not have a widespread global effect on complexity, making the process efficient [S1].
*   **Limitations**: Requires pre-computation of errors for all dividing points. Accuracy depends on the approximation error metric [S1].

## Background

*   **Origin**: The method is part of the Multi-Tetra Framework for visualizing regular volume data [S1].
*   **History**: It builds on the idea of merging tetrahedra to reduce rendering time [S1]. The bottom-up approach is similar to techniques in [LH91] referenced in the source [S1].
*   **Usage**: Used for isosurface extraction and visualization of regular volume data, particularly where efficient rendering is required [S1].
