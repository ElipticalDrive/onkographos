# Multiresolution B-Spline Volume Rendering

Also called: Image order direct volume rendering with spline wavelets, Spline wavelet decomposition volume rendering

## Overview
Multiresolution B-Spline Volume Rendering is an image-order direct volume rendering algorithm that utilizes spline wavelet decomposition of the underlying volume data [S1, unofficial]. It improves rendering quality and image accuracy while reducing memory requirements and allowing for error bound calculation [S1, unofficial]. It is distinguished from sibling methods by its specific use of cardinal B-spline basis functions for the wavelet decomposition and a two-level linked list data structure for efficient traversal and level-of-detail control [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A volume dataset represented via spline wavelet decomposition. The dataset consists of coefficients for color (R, G, B) and opacity ($\alpha$) channels.
*   **Output:** A rendered 2D image.

**Data Structures:**
The implementation uses a two-level list system to manage the wavelet coefficients [S1, unofficial].
1.  **First Level List:** Acts as the primary container.
2.  **Second Level List:** Each element in the first level list points to a second level list. The header of each second level list contains information and methods for its underlying list elements [S1, unofficial].
3.  **List Elements:** The elements within the second level lists store specific information required for rendering, such as parameter values and leaving parameters ($t_L$) [S1, unofficial]. The internal structure is defined by the source as illustrated in the original figures (Figure 13a and 13b), but exact field sizes and bit-packing are not given in the text [S1, unofficial].

**Parameters:**
*   **Basis Function Degree ($d$):** Different cardinal B-spline functions are used for R, G, B, and $\alpha$ values. Tested degrees include 0 (Haar), 1, 3, and 5 [S1, unofficial].
*   **Global Threshold ($M$):** Applied to R, G, B, and $\alpha$ coefficients to control approximation and neglect insignificant coefficients. A threshold of $M=2$ is cited in the results [S1, unofficial].

**Algorithm Steps:**
The rendering process involves traversing the data structure and evaluating the volume along rays. The specific traversal logic for the linked lists is defined as follows [S1, unofficial]:

1.  **Ray Casting:** For each pixel, cast a ray through the volume.
2.  **Traversal:** Iterate through the wavelet coefficients using the two-level list structure.
3.  **Element Management:**
    *   **Removal:** A second list element is removed if the actual parameter $t$ (position along the ray or parameterization) is greater than the stored leaving parameter $t_L$ associated with that element [S1, unofficial].
    *   **Insertion:** An element is inserted if the actual point lies within the support region of a new wavelet [S1, unofficial].
4.  **Evaluation:** Evaluate the volume density and color using the selected cardinal B-spline basis functions.
5.  **Thresholding:** Apply the global threshold $M$ to neglect coefficients below the threshold magnitude, or use a localized Gaussian filter for level-of-detail control [S1, unofficial].
6.  **Compositing:** Composite the evaluated values along the ray to produce the final pixel color [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Degree 0 (Haar):** Using Haar functions (degree 0) does not allow for gradient calculation, meaning shading models cannot be applied [S1, unofficial].
*   **Precision:** The source does not specify floating-point precision requirements.
*   **Boundary Conditions:** The source does not specify how boundary conditions are handled for the B-spline basis functions.

## Operating characteristics
**Time and Memory Complexity:**
*   **Memory:** The method reduces required memory by neglecting insignificant wavelet coefficients [S1, unofficial].
*   **Time:** The two-level list structure provides fast data access [S1, unofficial]. The specific time complexity is not given in the sources.

**Measured Performance:**
*   **Hydrogen Dataset (Global Threshold $M=2$):** With linear B-spline functions, the percentages of neglected coefficients were 63.3%, 91.3%, 94.8%, 96.8%, 97.8%, and 98.5% for Figures 16a-f respectively [S1, unofficial].
*   **Hydrogen Dataset (Local Level-of-Detail):** With linear B-spline functions and local level-of-detail control using a localized Gaussian filter, the percentages of neglected coefficients were 0%, 43.9%, 52.3%, 62.9%, 76.7%, and 87.6% for Figures 17a-f respectively [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Improves rendering quality and image accuracy; reduces memory requirements; allows error bound calculation; supports multiresolution and hierarchical data structures; offers freedom to modify compression, speed, and accuracy [S1, unofficial].
*   **Limitations:** Degree 0 (Haar) basis functions do not support shading models [S1, unofficial].

**When to Use:**
*   Use when memory reduction and error bound calculation are priorities.
*   Use when smooth appearance is desired (higher degree B-splines).
*   Do not use if shading models are required and Haar functions are the only option (use degree > 0).
