# Wavelet-Based Adaptive Grid Volume Rendering

Also called: Direct summation of wavelet coefficients during volumetric ray casting, Volume rendering in compression domain, Volumetric ray casting of multi-scale datasets in wavelet space

## Overview
This method visualizes volume data represented by a superposition of scaling functions on a coarse regular grid and wavelets on an adaptive mesh, capitalizing on sparse data representation and wavelet compression [S1][S2, unofficial]. It differs from existing techniques by performing visualization directly in wavelet space on the same adaptive grid, rather than reconstructing a uniform grid [S2, unofficial]. This approach is particularly suited for time-dependent data on space-time varying adaptive meshes [S1][S2, unofficial].

## How it works
**Inputs:**
*   Wavelet coefficients representing the volume data on an adaptive mesh.
*   A wavelet threshold for coefficient retention.
*   User-prescribed resolution for the coarse scaling function grid.
*   Camera parameters for ray casting.

**Outputs:**
*   Rendered image of the volume.

**Data Structures:**
*   **Adaptive Mesh:** A list of active wavelet coefficients. Only coefficients with magnitude greater than the wavelet threshold are retained [S2, unofficial].
*   **Coarse Grid:** A uniform grid storing scaling function values at a user-prescribed resolution [S1][S2, unofficial].

**Steps:**
1.  **Preprocessing (Partial Inverse Transform):** Perform a partial inverse wavelet transform to obtain scaling functions on a uniform grid at the user-prescribed resolution [S1][S2, unofficial]. This creates the base representation in physical space [S2, unofficial].
2.  **Representation:** Represent the solution in physical space as a superposition of scaling functions on the coarse regular grid and wavelets on the adaptive mesh [S1][S2, unofficial].
3.  **Ray Casting Initialization:** Execute an efficient and accurate ray casting algorithm based on the coarse scaling functions [S2, unofficial]. This provides the base rendering [S2, unofficial].
4.  **Detail Addition:** Add additional details during ray tracing by including wavelets based on the following criteria [S2, unofficial]:
    *   Support overlap with the interpolation point.
    *   Wavelet coefficient magnitude.
    *   Opacity accumulation (front to back ordering).
    *   Deviation from frontal viewing direction.

**Parameters:**
*   **Wavelet Threshold:** Coefficients greater than this threshold are retained for the adaptive mesh [S2, unofficial]. This controls the compression factor, which is typically 10–10^2 relative to a uniform grid of the same effective resolution [S2, unofficial].

**Pseudocode:**
```python
def render_wavelet_volume(wavelet_coeffs, coarse_scaling_grid, camera, threshold):
    """
    Renders volume using wavelet-based adaptive grid.
    
    Args:
        wavelet_coeffs: List of active wavelet coefficients (magnitude > threshold).
        coarse_scaling_grid: Uniform grid of scaling function values.
        camera: Camera parameters for ray generation.
        threshold: Wavelet threshold for coefficient retention.
        
    Returns:
        Rendered image.
    """
    # Step 1 & 2: Preprocessing and Representation
    # The coarse_scaling_grid is assumed to be precomputed via partial inverse transform.
    # The wavelet_coeffs are already filtered by threshold.
    
    image = empty_image()
    
    for ray in generate_rays(camera):
        color = vec3(0.0)
        opacity = 0.0
        
        # Step 3: Base Ray Casting on Coarse Scaling Functions
        # Evaluate the coarse scaling functions along the ray
        base_value = evaluate_coarse_scaling(ray, coarse_scaling_grid)
        
        # Apply transfer function to get base color and opacity
        base_color, base_opacity = apply_transfer_function(base_value)
        
        # Step 4: Add Details from Wavelets
        # Iterate through relevant wavelets based on support overlap, magnitude, 
        # opacity accumulation, and viewing direction.
        # Note: The exact selection criteria for "deviation from frontal viewing direction" 
        # and "opacity accumulation" interaction are not fully specified in sources [S2, unofficial].
        # We assume a simplified selection based on magnitude and support overlap.
        
        for wavelet in wavelet_coeffs:
            if not supports_overlap(ray, wavelet):
                continue
            if wavelet.magnitude < threshold:
                continue
                
            # Evaluate wavelet contribution at ray intersection point
            wavelet_value = evaluate_wavelet(ray, wavelet)
            wavelet_color, wavelet_opacity = apply_transfer_function(wavelet_value)
            
            # Composite wavelet contribution (front-to-back)
            # Note: Standard front-to-back compositing is assumed [S2, unofficial]
            alpha = wavelet_opacity * (1.0 - opacity)
            color += wavelet_color * alpha
            opacity += alpha
            
            if opacity >= 1.0:
                break
        
        # Composite base color with wavelet details
        # Note: The exact combination of base and wavelet contributions is not fully specified [S2, unofficial].
        # We assume the base color is the background or initial estimate, and wavelets add detail.
        final_color = color + base_color * (1.0 - opacity)
        
        set_pixel(image, ray, final_color)
        
    return image

def supports_overlap(ray, wavelet):
    """Check if ray intersects the support of the wavelet."""
    # Implementation depends on wavelet support definition [S2, unofficial]
    return ray.intersects(wavelet.support)

def evaluate_coarse_scaling(ray, grid):
    """Evaluate scaling functions on the coarse grid along the ray."""
    # Implementation depends on grid interpolation method [S1][S2, unofficial]
    return grid.interpolate(ray)

def evaluate_wavelet(ray, wavelet):
    """Evaluate the wavelet function at the ray's current position."""
    # Implementation depends on wavelet basis function [S2, unofficial]
    return wavelet.basis_function(ray.position)

def apply_transfer_function(value):
    """Apply transfer function to map scalar value to color and opacity."""
    # Implementation depends on user-defined transfer function [S2, unofficial]
    return color_map(value), opacity_map(value)
```

## Background
This technique was developed to address the limitations of existing volumetric visualization techniques that do not take full advantage of multi-resolution wavelet analysis [S1][S2, unofficial]. It is tailored for visualization of compressed solutions on wavelet-based adaptive computational meshes [S1][S2, unofficial]. The method was illustrated and compared to existing volume visualization software for Rayleigh-Benard thermal convection and electron density data sets [S2, unofficial].
