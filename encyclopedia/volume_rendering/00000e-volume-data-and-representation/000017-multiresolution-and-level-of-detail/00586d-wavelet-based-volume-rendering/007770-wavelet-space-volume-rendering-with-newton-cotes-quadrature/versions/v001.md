# Wavelet-space Volume Rendering with Newton-Cotes Quadrature


## Overview
A volume rendering technique where attenuation $\alpha$ and color source $q$ are decomposed into wavelet bases (B-splines), allowing for multiresolution analysis and exact gradient computation for shading, while using Newton-Cotes quadrature for numerical integration of the rendering equation [S1, unofficial]. It sets itself apart from sibling methods by performing the integration directly in the wavelet coefficient domain without explicit spatial reconstruction, utilizing specific error-bounded Newton-Cotes rules (Trapezoid and Simpson's) to approximate the volumetric integral [S1, unofficial].

## How it works
**Inputs:**
*   Sampled attenuation values $\alpha_{sampled}^3(x_p, y_q, z_r)$ and color values $q_{sampled}^{3,RGB}(x_p, y_q, z_r)$ on a grid $p, q, r \in \mathbf{Z}$ [S1, unofficial].
*   Ray defined by initial position $(ray_{initial,x}, ray_{initial,y}, ray_{initial,z})$ and direction $(ray_{direction,x}, ray_{direction,y}, ray_{direction,z})$ [S1, unofficial].
*   Wavelet decomposition parameters: coarsest level $M$, finest level $m_0$, and B-spline order $l$ (or $j$) [S1, unofficial].
*   Quadrature parameter $N$: number of sub-intervals per ray segment [S1, unofficial].

**Outputs:**
*   Final pixel intensity $I(t_0, t_{end})$ [S1, unofficial].
*   Surface normal $N(t)$ for shading [S1, unofficial].

**Data Structures:**
*   **Two-level linked list** for managing relevant basis functions [S1, unofficial].
    *   **Level 1:** List of levels $m$ and wavelet types.
    *   **Level 2:** Linked list of basis function elements for a specific level/type, sorted by $t_L$ (the ray parameter where the ray leaves the basis function's support) [S1, unofficial].
    *   **Element Fields:** Coefficient value, $t_L$ [S1, unofficial].
    *   **Management:** Elements are removed from the list when the current ray parameter $t > t_L$ [S1, unofficial].

**Steps:**

1.  **Projection into Scaling Functions:**
    Construct continuous functions $\alpha^3(x, y, z)$ and $q_{RGB}^3(x, y, z)$ by projecting sampled data onto 3D B-spline scaling functions $\phi_{m_0 p q r}^{3,[l]}$ [S1, unofficial]:
    $$ \alpha^3(x, y, z) := \sum_{p,q,r \in \mathbf{Z}} \alpha_{sampled}^3(x_p, y_q, z_r) \phi_{m_0 p q r}^{3,[l]}(x, y, z) $$
    $$ q_{RGB}^3(x, y, z) := \sum_{p,q,r \in \mathbf{Z}} q_{sampled}^{3,RGB}(x_p, y_q, z_r) \phi_{m_0 p q r}^{3,[l]}(x, y, z) $$
    [S1, unofficial]

2.  **Wavelet Decomposition:**
    Decompose the scaling function representations into wavelet coefficients $d$ for detail levels $m > m_0$ and scaling coefficients $c$ for the coarsest level $M$ [S1, unofficial]:
    $$ \alpha^3(x, y, z) = \sum_{m=m_0+1}^M \sum_{type=1}^7 \sum_{p,q,r \in \mathbf{Z}} d_{mpqr}^\alpha \psi_{mpqr}^{3,type,[l]}(x, y, z) + \sum_{p,q,r \in \mathbf{Z}} c_{Mpqr}^\alpha \phi_{Mpqr}^{3,[l]}(x, y, z) $$
    $$ q_{RGB}^3(x, y, z) = \sum_{m=m_0+1}^M \sum_{\text{type}=1}^7 \sum_{p,q,r \in \mathbf{Z}} d_{mpqr}^{q_{RGB}} \psi_{mpqr}^{3,\text{type},[i]}(x, y, z) + \sum_{p,q,r \in \mathbf{Z}} c_{Mpqr}^{q_{RGB}} \phi_{Mpqr}^{3,[i]}(x, y, z) $$
    [S1, unofficial]

3.  **Ray Tracing Setup:**
    For each ray segment $[t_{i-1}, t_i]$, define $N+1$ evenly spaced parameters $t_i^j$ where $t_i^j := t_{i-1} + j \cdot \Delta t$ and $\Delta t := \frac{t_i - t_{i-1}}{N}$ [S1, unofficial].

4.  **Identify Relevant Basis Functions:**
    For the current ray position $(x(t), y(t), z(t))$, identify all basis functions $f_{mpqr}$ (where $f \in \{\phi, \psi\}$) such that the position lies within their support [S1, unofficial].
    The support for a 1D basis function with dilation $m$ and translation $p$ is:
    $$ \text{supp}(f_{mp}) = \left[ (l_f + p)2^m, (r_f + p)2^m \right] $$
    where $[l_f, r_f]$ is the support of the prototype function $f_{m000}$ [S1, unofficial].
    The translation indices $p, q, r$ must satisfy:
    $$ \lfloor x/2^m - r_f \rfloor \leq p \leq \lfloor x/2^m - l_f \rfloor $$
    $$ \lfloor y/2^m - r_f \rfloor \leq q \leq \lfloor y/2^m - l_f \rfloor $$
    $$ \lfloor z/2^m - r_f \rfloor \leq r \leq \lfloor z/2^m - l_f \rfloor $$
    [S1, unofficial]

5.  **Compute Leaving Parameters ($t_L$):**
    For each identified basis function, compute the intersection parameter $t_{leaving,i}$ for each axis $i \in \{x, y, z\}$ where the ray leaves the prototype support region [S1, unofficial]:
    $$ t_{leaving,i} = \begin{cases} \frac{b_i - ray_{initial,i}}{ray_{direction,i}} & \text{if } ray_{direction,i} > 0 \\ \infty & \text{if } ray_{direction,i} = 0 \\ \frac{a_i - ray_{initial,i}}{ray_{direction,i}} & \text{if } ray_{direction,i} < 0 \end{cases} $$
    $$ dt_i := \begin{cases} \frac{b_i - a_i}{ray_{direction,i}} & \text{if } ray_{direction,i} \neq 0 \\ 0 & \text{if } ray_{direction,i} = 0 \end{cases} $$
    where $[a_i, b_i]$ is the support of the prototype function along axis $i$ [S1, unofficial].
    The intersection parameters for the specific basis function indexed by $p, q, r$ are:
    $$ t_x := t_{leaving,x} + p \cdot dt_x $$
    $$ t_y := t_{leaving,y} + q \cdot dt_y $$
    $$ t_z := t_{leaving,z} + r \cdot dt_z $$
    The leaving parameter $t_L$ is the minimum of these:
    $$ t_L = \min(t_x, t_y, t_z) $$
    [S1, unofficial]
    Insert the basis function into the two-level linked list sorted by $t_L$ [S1, unofficial].

6.  **Iterative Integration (Newton-Cotes Quadrature):**
    The rendering integral is solved iteratively. The intensity at step $i$ is:
    $$ I(t_0, t_i) = I(t_0, t_{i-1}) + e^{-A(t_0, t_{i-1})} \int_{t_{i-1}}^{t_i} q(t) \alpha(t) e^{-A(t_{i-1}, t)} dt $$
    where accumulated attenuation $A(t_k, t_l) := \int_{t_k}^{t_l} \alpha(s) ds$ [S1, unofficial].
    
    **Accumulated Attenuation $A$:**
    Compute $A(t_{i-1}, t_i^j)$ using the chosen quadrature rule on the wavelet-expanded $\alpha$ function.
    
    **Intensity $I$:**
    Compute the integral term using the chosen quadrature rule on the product $q \alpha e^{-A}$.

    **Trapezoid Rule:**
    Approximation for intensity:
    $$ I(t_0, t_i) \approx I(t_0, t_{i-1}) + e^{-A(t_0, t_{i-1})} \left[ q(t_i^0) \alpha(t_i^0) + 2 \sum_{j=1}^{N-1} q(t_i^j) \alpha(t_i^j) e^{-A(t_{i-1}, t_i^j)} + q(t_i^N) \alpha(t_i^N) e^{-A(t_{i-1}, t_i^N)} \right] \cdot \frac{\Delta t}{2} $$
    Remainder bound $R_I$:
    $$ R_I = \frac{(\Delta t)^2}{12} e^{-A(t_0, t_{i-1})} (q(\xi) \alpha(\xi) e^{-A(t_{i-1}, \xi)})^{(2)} \quad \xi \in (t_{i-1}, t_i) $$
    Approximation for attenuation:
    $$ A(t_{i-1}, t_i^j) \approx \left[ \alpha(t_{i-1}) + 2 \sum_{k=1}^{j-1} \alpha(t_i^k) + \alpha(t_i^j) \right] \cdot \frac{\Delta t}{2} $$
    Remainder bound $R_A$:
    $$ R_A = (\Delta t)^2 \frac{t_i^j - t_{i-1}}{12} \alpha^{(2)}(\xi) \quad \xi \in (t_{i-1}, t_i^j) $$
    [S1, unofficial]

    **Simpson's Rule:**
    Requires $N$ to be even. Define $P(t) := q(t) \alpha(t) e^{-A(t_{i-1}, t)}$.
    Approximation for intensity:
    $$ I(t_0, t_i) \approx I(t_0, t_{i-1}) + \frac{\Delta t}{3} e^{-A(t_0, t_{i-1})} \left[ P(t_{i-1}) + 4 \sum_{k=1}^{N/2} P(t_i^{2k-1}) + 2 \sum_{k=1}^{N/2} P(t_i^{2k}) + P(t_i) \right] $$
    Remainder bound $R_I$:
    $$ R_I = e^{-A(t_0, t_{i-1})} (\Delta t)^4 \frac{t_i - t_{i-1}}{180} (q(\xi) \alpha(\xi) e^{-A(t_{i-1}, \xi)})^{(4)} \quad \xi \in (t_{i-1}, t_i) $$
    Approximation for attenuation:
    $$ A(t_{i-1}, t_j^i) \approx \left[ \alpha(t_{i-1}) + 4 \sum_{k=1}^{j/2} \alpha(t_{2k-1}^i) + 2 \sum_{k=1}^{j/2-1} \alpha(t_{2k}^i) + \alpha(t_j^i) \right] \cdot \frac{\Delta t}{3} $$
    Remainder bound $R_A$:
    $$ R_A = (\Delta t)^4 \frac{t_i^j - t_{i-1}}{180} \alpha^{(4)}(\xi) \quad \xi \in (t_{i-1}, t_i^j) $$
    [S1, unofficial]

    **Derivative Calculation:**
    The $n$-th derivative of a product of three functions $f, g, h$ is computed using the Leibniz rule:
    $$ \frac{d^n}{dx} f g h = \sum_{k=0}^n \sum_{i=0}^k \binom{n}{k} \binom{k}{i} f^{(i)} g^{(k-i)} h^{(n-k)} $$
    [S1, unofficial]

7.  **Gradient and Shading:**
    Compute the surface normal $N(t)$ by normalizing the gradient of the opacity function $\alpha$, computed analytically from the wavelet coefficients [S1, unofficial]:
    $$ N(t) := \frac{\nabla \alpha(t)}{|\nabla \alpha(t)|} $$
    The partial derivatives are computed by differentiating the wavelet expansion (Eq. 36/37) analytically [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of relevant wavelet basis functions per ray and the number of quadrature points $N$. The use of linked lists sorted by $t_L$ allows for efficient removal of inactive bases [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of wavelet coefficients. The two-level linked list structure optimizes memory access for active bases [S1, unofficial].
*   **Precision:** Trapezoid Rule has an error bound proportional to $(\Delta t)^2$ and requires the second derivative of the integrand. Simpson's Rule has an error bound proportional to $(\Delta t)^4$ and requires the fourth derivative, offering higher precision for smooth functions [S1, unofficial].
*   **Strengths:** Exact gradient computation for shading; no explicit reconstruction step required before integration; multiresolution analysis allows LOD [S1, unofficial].
*   **Limitations:** Requires computation of derivatives for error bounds; complex data structure management for basis functions [S1, unofficial].

Originated in the work on ray-tracing of multiresolution B-spline volumes [S1, unofficial]. The method leverages the properties of B-splines and wavelet transforms to enable efficient volume rendering of large datasets [S1, unofficial].
