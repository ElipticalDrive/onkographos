# 3D Wavelet Construction via Tensor Product

Also called: Separable 3D Wavelet Construction, Tensor Product Wavelet Construction

## Overview
This method constructs a multiresolution analysis (MRA) for three-dimensional functions by extending one-dimensional cardinal B-spline wavelets into 3D space using the tensor product. It solves the problem of representing volumetric data in a hierarchical basis that allows for efficient decomposition and reconstruction. It differs from non-separable 3D wavelets by relying on the direct product of 1D scaling and wavelet functions, resulting in a basis that is separable along the x, y, and z axes. This approach builds on [Cardinal B-spline wavelets](11756-cardinal-b-spline-wavelets.md).

## How it works

### Inputs and Outputs
*   **Input:** A 1D scaling function $\phi$ and a 1D wavelet function $\psi$ (typically cardinal B-splines of order $j$).
*   **Output:** A set of 3D scaling functions $\phi_{mpqr}^3$ spanning approximation subspaces $V_m^3$, and 7 sets of 3D wavelet functions $\psi_{mpqr}^{3,i}$ spanning detail subspaces $U_m^{3,i}$ for $i \in \{1, \dots, 7\}$.

### Data Structures
The method relies on the mathematical definition of the basis functions rather than a specific binary data layout. However, for implementation, the coefficients for the 1D basis functions ($\phi$ and $\psi$) must be stored.
*   **1D Coefficients:** Arrays representing the filter taps or analytic samples of $\phi^{[j]}$ and $\psi^{[j]}$.
*   **3D Basis Representation:** The 3D functions are not stored as dense 3D arrays but are defined by the tensor product of 1D components.

### Formulas and Definitions

**1. 3D Scaling Functions**
The scaling functions at resolution level $m$ are defined as the tensor product of three 1D scaling functions:
$$ \phi_{mpqr}^3(x, y, z) := 2^{-\frac{3m}{2}} \phi(2^{-m}x - p) \phi(2^{-m}y - q) \phi(2^{-m}z - r) $$
where $m, p, q, r \in \mathbf{Z}$. These functions span the subspace $V_m^3 \subset L^2(\mathbb{R}^3)$ [S1, unofficial].

**2. 3D Wavelet Functions (Detail Subspaces)**
The complement subspace $U_m^3$ of $V_m^3$ in $V_{m-1}^3$ is spanned by 7 separable wavelet functions. These are formed by replacing one or more $\phi$ terms in the tensor product with $\psi$. The 7 functions are:

1.  $\psi_{mpqr}^{3,1}(x, y, z) := 2^{-\frac{3m}{2}}\phi(2^{-m}x - p)\phi(2^{-m}y - q)\psi(2^{-m}z - r)$
2.  $\psi_{mpqr}^{3,2}(x, y, z) := 2^{-\frac{3m}{2}}\phi(2^{-m}x - p)\psi(2^{-m}y - q)\phi(2^{-m}z - r)$
3.  $\psi_{mpqr}^{3,3}(x, y, z) := 2^{-\frac{3m}{2}}\phi(2^{-m}x - p)\psi(2^{-m}y - q)\psi(2^{-m}z - r)$
4.  $\psi_{mpqr}^{3,4}(x, y, z) := 2^{-\frac{3m}{2}}\psi(2^{-m}x - p)\phi(2^{-m}y - q)\phi(2^{-m}z - r)$
5.  $\psi_{mpqr}^{3,5}(x, y, z) := 2^{-\frac{3m}{2}}\psi(2^{-m}x - p)\psi(2^{-m}y - q)\phi(2^{-m}z - r)$
6.  $\psi_{mpqr}^{3,6}(x, y, z) := 2^{-\frac{3m}{2}}\psi(2^{-m}x - p)\phi(2^{-m}y - q)\psi(2^{-m}z - r)$
7.  $\psi_{mpqr}^{3,7}(x, y, z) := 2^{-\frac{3m}{2}}\psi(2^{-m}x - p)\psi(2^{-m}y - q)\psi(2^{-m}z - r)$

The full space $L^2(\mathbb{R}^3)$ is the direct sum of all detail spaces:
$$ \bigoplus_{\substack{m \in \mathbf{Z} \\ 1 \leq i \leq 7}} \mathbf{U}_m^{3,i} = L^2(\mathbb{R}^3) $$
where $\mathbf{U}_m^{3,i}$ is the closure of the span of $\psi_{mpqr}^{3,i}$ [S1, unofficial].

**3. Projection Operators (Decomposition and Reconstruction)**
For semi-orthogonal systems, primary functions ($\phi, \psi$) and dual functions ($\tilde{\phi}, \tilde{\psi}$) are used.

*   **Approximation Projection:**
    $$ \mathcal{P}_{\phi_m^3} f(x) = \sum_{p,q,r} \langle f, \phi_{mpqr}^3 \rangle \tilde{\phi}_{mpqr}^3 = \sum_{p,q,r} \langle f, \tilde{\phi}_{mpqr}^3 \rangle \phi_{mpqr}^3 $$
*   **Detail Projection:**
    $$ \mathcal{Q}_{\psi_m^{3,i}} f(x) = \sum_{p,q,r} \langle f, \psi_{mpqr}^{3,i} \rangle \tilde{\psi}_{mpqr}^{3,i} = \sum_{p,q,r} \langle f, \tilde{\psi}_{mpqr}^{3,i} \rangle \psi_{mpqr}^{3,i} $$

In the orthonormal case, primary and dual functions are identical ($\tilde{\phi}=\phi, \tilde{\psi}=\psi$) [S1, unofficial].

def tensor_product_3d_wavelet_basis(phi_1d, psi_1d, m, p, q, r):
    """
    Constructs the 7 3D wavelet functions and 1 3D scaling function 
    at resolution level m and indices p, q, r using tensor products.
    
    Args:
        phi_1d: Function object or array representing 1D scaling function phi.
        psi_1d: Function object or array representing 1D wavelet function psi.
        m: Resolution level (integer).
        p, q, r: Translation indices (integers).
        
    Returns:
        phi_3d: The 3D scaling function.
        psi_3d_list: A list of 7 3D wavelet functions.
    """
    # Precompute the scaling factor
    scale_factor = 2.0 ** (-1.5 * m)
    
    # Define helper for 1D component evaluation
    # Note: In implementation, phi_1d and psi_1d should support 
    # evaluation at scaled and shifted coordinates.
    def eval_phi(x_val):
        return phi_1d(2**(-m) * x_val - p)
    
    def eval_psi(x_val):
        return psi_1d(2**(-m) * x_val - p)

    # 1. Construct 3D Scaling Function
    # phi_3d(x,y,z) = scale * phi(x) * phi(y) * phi(z)
    def phi_3d(x, y, z):
        return scale_factor * eval_phi(x) * eval_phi(y) * eval_phi(z)

    # 2. Construct 7 3D Wavelet Functions
    # The indices i=1..7 correspond to the position of psi in the tensor product.
    # i=1: psi in z (phi, phi, psi)
    # i=2: psi in y (phi, psi, phi)
    # i=3: psi in y and z (phi, psi, psi)
    # i=4: psi in x (psi, phi, phi)
    # i=5: psi in x and y (psi, psi, phi)
    # i=6: psi in x and z (psi, phi, psi)
    # i=7: psi in x, y, z (psi, psi, psi)
    
    def eval_phi_y(y_val):
        return phi_1d(2**(-m) * y_val - q)
        
    def eval_psi_y(y_val):
        return psi_1d(2**(-m) * y_val - q)
        
    def eval_phi_z(z_val):
        return phi_1d(2**(-m) * z_val - r)
        
    def eval_psi_z(z_val):
        return psi_1d(2**(-m) * z_val - r)

    psi_3d_list = [None] * 7
    
    # i=1: phi(x) phi(y) psi(z)
    psi_3d_list[0] = lambda x, y, z: scale_factor * eval_phi(x) * eval_phi_y(y) * eval_psi_z(z)
    
    # i=2: phi(x) psi(y) phi(z)
    psi_3d_list[1] = lambda x, y, z: scale_factor * eval_phi(x) * eval_psi_y(y) * eval_phi_z(z)
    
    # i=3: phi(x) psi(y) psi(z)
    psi_3d_list[2] = lambda x, y, z: scale_factor * eval_phi(x) * eval_psi_y(y) * eval_psi_z(z)
    
    # i=4: psi(x) phi(y) phi(z)
    psi_3d_list[3] = lambda x, y, z: scale_factor * eval_psi(x) * eval_phi_y(y) * eval_phi_z(z)
    
    # i=5: psi(x) psi(y) phi(z)
    psi_3d_list[4] = lambda x, y, z: scale_factor * eval_psi(x) * eval_psi_y(y) * eval_phi_z(z)
    
    # i=6: psi(x) phi(y) psi(z)
    psi_3d_list[5] = lambda x, y, z: scale_factor * eval_psi(x) * eval_phi_y(y) * eval_psi_z(z)
    
    # i=7: psi(x) psi(y) psi(z)
    psi_3d_list[6] = lambda x, y, z: scale_factor * eval_psi(x) * eval_psi_y(y) * eval_psi_z(z)

    return phi_3d, psi_3d_list

def decompose_volume_f(f_3d, phi_1d, psi_1d, tilde_phi_1d, tilde_psi_1d, m):
    """
    Computes the projection coefficients for a 3D function f using 
    the tensor product basis. Uses quadrature mirror pair filter cascades 
    for efficient computation [S1, unofficial].
    
    Args:
        f_3d: The input 3D volume data.
        phi_1d, psi_1d: 1D primary basis functions.
        tilde_phi_1d, tilde_psi_1d: 1D dual basis functions.
        m: Resolution level.
        
    Returns:
        approx_coeffs: Coefficients for the approximation space V_m.
        detail_coeffs: Dictionary mapping i (1-7) to detail coefficients for U_m^i.
    """
    # Implementation note: Direct integration is expensive.
    # The source specifies that inner products are computed using 
    # quadrature mirror pair filter cascades [S1, unofficial].
    # This implies a fast wavelet transform (FWT) structure.
    
    # Step 1: Project onto approximation space V_m
    # P_phi_m^3 f = sum <f, phi_mpqr^3> tilde_phi_mpqr^3
    # In separable form, this is a 3D convolution with filter banks.
    approx_coeffs = apply_separable_filter_bank(f_3d, phi_1d, tilde_phi_1d, m)
    
    # Step 2: Project onto detail spaces U_m^i for i=1..7

    for i in range(1, 8):
        # Q_psi_m^3,i f = sum <f, psi_mpqr^3,i> tilde_psi_mpqr^3,i

        detail_coeffs[i] = apply_separable_filter_bank_variant(f_3d, phi_1d, psi_1d, tilde_phi_1d, tilde_psi_1d, m, wavelet_index=i)
        
    return approx_coeffs, detail_coeffs

    result = apply_1d_filter(temp_y, phi_1d, axis=2)
    
    # Apply dual filters for projection coefficients
    # Note: The exact order of primal/dual application depends on the 
    # semi-orthogonal definition. Typically, one applies the analysis filters 
    # to get coefficients and synthesis filters for reconstruction.
    # Here we assume the coefficients are obtained by correlating with duals.
    coeff_x = apply_1d_filter(result, tilde_phi_1d, axis=0)

### Parameters
*   **Resolution Level ($m$):** Integer. Controls the scale of the basis functions.
*   **Indices ($p, q, r$):** Integers. Control the spatial translation of the basis functions.
*   **Dual Functions:** Required for semi-orthogonal systems. The dual functions $\tilde{\phi}$ and $\tilde{\psi}$ have global support even if the primary functions have local support [S1, unofficial].

### Edge Cases and Pitfalls
*   **Semi-orthogonality:** If the basis is semi-orthogonal (not orthonormal), the dual functions must be used for projection. Using only primary functions for projection will yield incorrect coefficients [S1, unofficial].
*   **Support:** While the primary wavelets have strict local support, their dual counterparts have global support. This can impact computational efficiency if not handled via filter cascades [S1, unofficial].
*   **Boundary Conditions:** The tensor product construction assumes the domain is $\mathbb{R}^3$. For finite volumes, boundary handling (extension, truncation, or periodic) must be defined, which is not specified in the core mathematical definition [S1, unofficial].

## Operating characteristics

*   **Time Complexity:** The decomposition and reconstruction can be performed in $O(N)$ time using quadrature mirror pair filter cascades, where $N$ is the number of voxels, due to the separability of the basis [S1, unofficial].
*   **Memory Complexity:** The storage requirement is proportional to the number of coefficients, which is $O(N)$ for the full resolution. The hierarchical structure allows for compression by discarding small detail coefficients.
*   **Strengths:**
    *   **Separability:** The 3D operations decompose into three 1D operations, simplifying implementation and optimization.
    *   **Local Support:** The primary basis functions have strict local support, which is beneficial for localized features and sparse representations.
    *   **Smoothness:** Cardinal B-splines provide smooth basis functions with good frequency localization.
*   **Limitations:**
    *   **Dual Support:** The global support of dual functions in semi-orthogonal systems can complicate fast implementations if not carefully managed.
    *   **Anisotropy:** The basis is aligned with the coordinate axes. It may not capture directional features as efficiently as non-separable or directional wavelets.
*   **When to Use:** Suitable for volumetric data where separability is advantageous, such as in multiresolution ray tracing or compression, and when the data exhibits smoothness consistent with B-spline approximations.
*   **When Not to Use:** When directional features are dominant and non-separable wavelets would provide better sparsity, or when strict orthogonality is required and the dual function complexity is prohibitive.

## Background

This method is based on the extension of 1D wavelet theory to 3D using tensor products, a standard technique in wavelet analysis. The specific application to cardinal B-spline wavelets for volume rendering is detailed in the context of ray-tracing multiresolution B-spline volumes. The mathematical foundations rely on the multiresolution analysis (MRA) of $L^2(\mathbb{R}^3)$ established by Mallat [S1, unofficial]. The use of semi-orthogonal B-spline wavelets allows for analytic expressions of the basis functions and their duals, facilitating efficient computation.
