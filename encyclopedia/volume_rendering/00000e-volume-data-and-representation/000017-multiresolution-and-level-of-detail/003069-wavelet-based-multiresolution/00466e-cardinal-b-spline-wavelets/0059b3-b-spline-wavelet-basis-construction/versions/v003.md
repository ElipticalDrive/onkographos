# B-spline Wavelet Basis Construction

Also called: Cardinal B-spline wavelet construction, Chui and Wang B-spline wavelets

## Overview
This method constructs the spatial and frequency-domain basis functions for Chui and Wang B-spline wavelets of order $j$, which are used for volume data compression and rendering [S1, unofficial]. It differs from orthogonal wavelet bases by employing semi-orthogonal duals to ensure perfect reconstruction while maintaining the smoothness and vanishing moments of B-splines [S1, unofficial].

## How it works
**Inputs and outputs:**
*   **Input:** Order of the B-spline wavelet $j$ (integer, $j \ge 1$) [S1, unofficial].
*   **Outputs:** Scaling function $\phi^{[j]}(x)$ in the spatial domain [S1, unofficial]. Wavelet function $\psi^{[j]}(x)$ in the spatial domain [S1, unofficial]. Frequency-domain representation $\Phi^{[j]}(f)$ [S1, unofficial]. Dual functions (required for decomposition, explicit construction formulas not provided in the source) [S1, unofficial].

**Data structures:**
*   Coefficients $q_{j,k}$: Array of size $3j-1$ with indices $k=0$ to $3j-2$ [S1, unofficial].
*   Binomial coefficients: Standard combinatorial values computed as $\binom{j}{l}$ [G].

**Numbered steps:**
1.  Define the base scaling function for $j=1$ (Haar scaling function) [S1, unofficial].
2.  Recursively generate scaling functions for orders $j > 1$ using cardinal B-spline relations [S1, unofficial].
3.  Compute the frequency-domain representation as a sinc-polynomial [S1, unofficial].
4.  Construct the wavelet function as a linear combination of scaled and shifted scaling functions [S1, unofficial].
5.  Calculate the wavelet coefficients $q_{j,k}$ using the recursive scaling function of order $2j$ [S1, unofficial].
6.  Extend the 1D wavelets to three dimensions via non-standard tensor-product extensions [S1, unofficial].
7.  Perform volume decomposition using the dual wavelet functions and reconstruction using the primary scaling and wavelet functions [S1, unofficial].

**Formulas (symbols defined inline):**
*   Base scaling function: $\phi^{[1]}(x) = 1$ for $0 \leq x < 1$, and $0$ otherwise [S1, unofficial].
*   Recursive scaling function: $\phi^{[j]}(x) = \frac{x}{j-1} \phi^{[j-1]}(x) + \frac{j-x}{j-1} \phi^{[j-1]}(x-1)$, where $x$ is the spatial coordinate and $j$ is the order [S1, unofficial].
*   Frequency-domain representation: $\Phi^{[j]}(f) = \left( \frac{1 - e^{-i2\pi f}}{i2\pi f} \right)^j$, where $f$ is the frequency and $i$ is the complex operator [S1, unofficial].
*   Wavelet function: $\psi^{[j]}(x) = \sum_{k=0}^{3j-2} q_{j,k} \phi^{[j]}(2x-k)$, with support $[0, 2j-1]$ [S1, unofficial].
*   Wavelet coefficients: $q_{j,k} = \frac{(-1)^k}{2^{j-1}} \sum_{l=0}^j \binom{j}{l} \phi^{[2j]}(k+1-l)$, requiring the scaling function of order $2j$ [S1, unofficial].

**Parameters:**
*   Order $j$: Integer, $j \ge 1$ [S1, unofficial].

**Edge cases and pitfalls:**
*   **Precision:** The recursive calculation of scaling functions may suffer from numerical instability for high orders $j$ [G]. The frequency-domain formula involves division by $f$, requiring explicit handling of $f=0$ [S1, unofficial].
*   **Dual functions:** The source states that decomposition requires dual functions, but does not provide their explicit construction formulas [S1, unofficial].
*   **3D extension:** The "non-standard tensor-product extension" is not defined in the source [S1, unofficial].

**Pseudocode:**
```python
import cmath
import math
from typing import List

def binomial(n: int, k: int) -> int:
    """Compute binomial coefficient C(n, k)."""
    if k < 0 or k > n:
        return 0
    if k == 0 or k == n:
        return 1
    if k > n // 2:
        k = n - k
    res = 1
    for i in range(k):
        res = res * (n - i) // (i + 1)
    return res

def scaling_function_1d(x: float, order: int) -> float:
    """Compute the B-spline scaling function of given order at x."""
    if order == 1:
        return 1.0 if 0 <= x < 1 else 0.0
    prev = order - 1
    return (x / prev) * scaling_function_1d(x, prev) + ((order - x) / prev) * scaling_function_1d(x - 1, prev)

def compute_wavelet_coefficients(order: int) -> List[float]:
    """Compute coefficients q_{j,k} for wavelet function of order j."""
    j = order
    num_coeffs = 3 * j - 1
    coeffs = []
    for k in range(num_coeffs):
        sum_val = 0.0
        for l in range(j + 1):
            arg = k + 1 - l
            phi_val = scaling_function_1d(arg, 2 * j)
            sum_val += binomial(j, l) * phi_val
        q_jk = ((-1) ** k) / (2 ** (j - 1)) * sum_val
        coeffs.append(q_jk)
    return coeffs

def wavelet_function_1d(x: float, order: int) -> float:
    """Compute the B-spline wavelet function of order j at x."""
    j = order
    coeffs = compute_wavelet_coefficients(j)
    result = 0.0
    for k, q in enumerate(coeffs):
        result += q * scaling_function_1d(2 * x - k, j)
    return result

def frequency_domain_scaling(order: int, f: float) -> complex:
    """Compute the frequency domain representation Phi^[j](f)."""
    if f == 0.0:
        return complex(1.0, 0.0)
    numerator = 1.0 - cmath.exp(-1j * 2 * math.pi * f)
    denominator = 1j * 2 * math.pi * f
    base = numerator / denominator
    return base ** order
```

## Operating characteristics
*   **Time Complexity:** Not given in the sources. The source notes that linear time algorithms can be more challenging due to additional basis transforms [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Smoothness, vanishing moments, analytic expressions in frequency and spatial domains, semi-orthogonality for $j>1$, linear phase for primary and dual functions, and rational coefficients for fast wavelet transform [S1, unofficial].
*   **Limitations:** Requires dual functions for decomposition, which are not explicitly constructed here. Linear time implementations are complex [S1, unofficial].
*   **When to use:** When volume data compression and rendering require smooth bases with analytic frequency-domain representations for splatting [S1, unofficial].

## Background
*   **Origin:** The method is based on Chui and Wang B-spline wavelet bases [S1, unofficial].
*   **History:** The source cites Chui and Wang [3] as the origin of the B-spline wavelet bases used for volume data compression and rendering [S1, unofficial].
*   **Usage:** Used in compression domain volume rendering, specifically in wavelet splatting [S1, unofficial].
