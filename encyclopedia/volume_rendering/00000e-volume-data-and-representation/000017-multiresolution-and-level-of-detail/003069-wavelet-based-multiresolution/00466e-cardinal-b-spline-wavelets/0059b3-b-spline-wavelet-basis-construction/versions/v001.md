# B-spline Wavelet Basis Construction

Also called: Cardinal B-spline wavelet construction, Chui and Wang B-spline wavelets

## Overview
This method constructs the semi-orthogonal B-spline wavelet basis of order $j$ used for multiresolution volume data representation [S1, unofficial]. It defines the scaling functions and wavelet functions in both spatial and frequency domains, enabling efficient decomposition and reconstruction of volumetric data [S1, unofficial]. It is distinguished from orthogonal wavelets by its semi-orthogonality, which allows for compactly supported dual bases and linear-phase properties, making it suitable for applications like wavelet splatting where smoothness and vanishing moments are required [S1, unofficial].

## How it works
**Inputs:**
*   Order of the B-spline wavelet $j$ (integer, $j \geq 1$).

**Outputs:**
*   Scaling function $\phi^{[j]}(x)$.
*   Wavelet function $\psi^{[j]}(x)$.
*   Dual functions (implicitly defined via semi-orthogonality, used for decomposition).

**Data Structures:**
*   Coefficients $q_{j,k}$: Array of size $3j-1$ (indices $k=0$ to $3j-2$).
*   Scaling function values: Evaluated on demand or precomputed on a grid.

**Steps:**

1.  **Define the Mother Scaling Function (Order 1):**
    The base case is the Haar scaling function:
    $$
    \phi^{[1]}(x) = \begin{cases} 
    1 & \text{if } 0 \leq x < 1 \\
    0 & \text{otherwise}
    \end{cases}
    $$
    [S1, unofficial]

2.  **Generate Scaling Functions of Order $j$:**
    For $j > 1$, compute $\phi^{[j]}(x)$ recursively using the cardinal B-spline recurrence:
    $$
    \phi^{[j]}(x) = \frac{x}{j-1} \phi^{[j-1]}(x) + \frac{j-x}{j-1} \phi^{[j-1]}(x-1)
    $$
    [S1, unofficial]
    The support of $\phi^{[j]}(x)$ is $[0, j]$.

3.  **Compute Frequency Domain Representation (Optional but Fundamental):**
    The Fourier transform of the scaling function is given by the sinc-polynomial:
    $$
    \Phi^{[j]}(f) = \left( \frac{1 - e^{-i2\pi f}}{i2\pi f} \right)^j
    $$
    where $f$ is the frequency and $i$ is the imaginary unit. This form is critical for Fourier-domain splatting computations [S1, unofficial].

4.  **Construct the Wavelet Function:**
    The wavelet $\psi^{[j]}(x)$ is a linear combination of scaled scaling functions:
    $$
    \psi^{[j]}(x) = \sum_{k=0}^{3j-2} q_{j,k} \phi^{[j]}(2x-k)
    $$
    [S1, unofficial]
    The support of $\psi^{[j]}(x)$ is $[0, 2j-1]$ [S1, unofficial].

5.  **Calculate Wavelet Coefficients $q_{j,k}$:**
    The coefficients are determined by:
    $$
    q_{j,k} = \frac{(-1)^k}{2^{j-1}} \sum_{l=0}^j \binom{j}{l} \phi^{[2j]}(k+1-l)
    $$
    [S1, unofficial]
    Note that this requires evaluating the scaling function of order $2j$.

6.  **Handle Dual Functions for Decomposition:**
    Because the basis is semi-orthogonal for $j > 1$, dual functions $\tilde{\phi}$ and $\tilde{\psi}$ exist and have linear phase [S1, unofficial]. Volume decomposition (analysis) uses these dual functions, while reconstruction (synthesis) uses the primary functions defined in steps 2 and 4 [S1, unofficial].

**Pseudocode:**

```python
import math
from math import comb

def scaling_function_1d(x, order):
    """
    Computes the cardinal B-spline scaling function phi^[order](x).
    Uses recursive definition.
    """
    if order == 1:
        if 0 <= x < 1:
            return 1.0
        else:
            return 0.0
    
    # Recursive step: phi^[j](x) = (x/(j-1)) * phi^[j-1](x) + ((j-x)/(j-1)) * phi^[j-1](x-1)
    # Note: The source formula uses phi^[j-1](x-1). 
    # Standard B-spline recurrence often involves convolution, but the source explicitly gives:
    # phi^[j](x) = (x/(j-1)) * phi^[j-1](x) + ((j-x)/(j-1)) * phi^[j-1](x-1)
    
    term1 = (x / (order - 1)) * scaling_function_1d(x, order - 1)
    term2 = ((order - x) / (order - 1)) * scaling_function_1d(x - 1, order - 1)
    
    return term1 + term2

def compute_wavelet_coefficients(order):
    """
    Computes the coefficients q_{j,k} for the wavelet of order j.
    Returns a list of coefficients for k = 0 to 3j-2.
    """
    j = order
    num_coeffs = 3 * j - 1  # k goes from 0 to 3j-2
    coefficients = []
    
    # We need phi^[2j] for the coefficient calculation
    # Note: phi^[2j] is the scaling function of order 2j
    order_2j = 2 * j
    
    for k in range(num_coeffs):
        sum_val = 0.0
        for l in range(j + 1):  # l from 0 to j
            # binom(j, l)
            binom = comb(j, l)
            
            # Evaluate phi^[2j](k + 1 - l)
            # The argument is (k + 1 - l)
            arg = k + 1 - l
            phi_val = scaling_function_1d(arg, order_2j)
            
            sum_val += binom * phi_val
            
        # q_{j,k} = ((-1)^k / 2^(j-1)) * sum
        sign = (-1) ** k
        denominator = 2 ** (j - 1)
        
        q_k = (sign / denominator) * sum_val
        coefficients.append(q_k)
        
    return coefficients

def wavelet_function_1d(x, order, coefficients):
    """
    Computes the wavelet psi^[order](x) using precomputed coefficients.
    psi^[j](x) = sum_{k=0}^{3j-2} q_{j,k} * phi^[j](2x - k)
    """
    j = order
    result = 0.0
    
    for k, q_k in enumerate(coefficients):
        # Evaluate phi^[j](2x - k)
        arg = 2 * x - k
        phi_val = scaling_function_1d(arg, j)
        result += q_k * phi_val
        
    return result

def construct_basis(order):
    """
    Main construction routine.
    Returns the scaling function evaluator and wavelet function evaluator.
    """
    # 1. Get coefficients
    coeffs = compute_wavelet_coefficients(order)
    
    # 2. Return closures or objects that use these coefficients
    # In a real implementation, one might cache phi values or use the frequency domain form
    # for efficiency, but this follows the spatial domain definition from the source.
    
    return coeffs

# Example usage for order 2
# coeffs = construct_basis(2)
# psi_val = wavelet_function_1d(0.5, 2, coeffs)
```

**Edge Cases and Pitfalls:**
*   **Precision:** The recursive definition of $\phi^{[j]}$ can suffer from numerical instability for large $j$ due to the accumulation of floating-point errors. The frequency domain representation $\Phi^{[j]}(f)$ is more stable for high orders [S1, unofficial].
*   **Support Boundaries:** The support of $\psi^{[j]}(x)$ is $[0, 2j-1]$. Evaluations outside this range should return 0.
*   **Dual Functions:** The source states that decomposition uses duals, but does not provide the explicit formula for the duals in this article. Implementers must refer to the specific dual construction method (often involving solving a system for the dual scaling function $\tilde{\phi}$ such that $\langle \phi, \tilde{\phi} \rangle = \delta$) [S1, unofficial]. The source notes that "additional basis transforms might be required" for linear time algorithms [S1, unofficial].

## Operating characteristics
*   **Complexity:** The construction of coefficients is $O(j^2)$ or $O(j^3)$ depending on implementation, but $j$ is typically small (e.g., 2, 3, 4). The transform itself can be implemented in linear time $O(N)$ if efficient algorithms are used, though the source notes this can be challenging due to the need for basis transforms [S1, unofficial].
*   **Memory:** The basis functions have compact support, leading to sparse representation in the wavelet domain. The number of coefficients per dimension is proportional to the data size.
*   **Strengths:** Smoothness, vanishing moments ($j-1$), symmetry/anti-symmetry, and compact support make them excellent for compression and rendering [S1, unofficial]. The semi-orthogonality allows for fast transforms.
*   **Limitations:** Semi-orthogonality requires dual functions for decomposition, adding complexity compared to orthogonal wavelets. The support width increases with $j$, which may affect locality.

## Background
This method is based on the work of Chui and Wang, who developed B-spline wavelet bases [S1, unofficial]. It was applied to volume data compression and rendering in the late 1990s, notably by Gross et al. in the context of wavelet splatting [S1, unofficial]. The approach leverages the analytic expressions of B-splines in both spatial and frequency domains to facilitate efficient rendering and compression.
