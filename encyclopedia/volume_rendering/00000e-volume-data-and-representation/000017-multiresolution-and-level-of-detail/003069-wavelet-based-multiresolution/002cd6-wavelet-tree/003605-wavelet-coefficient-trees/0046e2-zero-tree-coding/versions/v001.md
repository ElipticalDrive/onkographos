# Zero Tree Coding

Also called: Embedded Block Coding with Zero Trees, SPIHT, Set Splitting in Hierarchical Trees

## Overview
Zero Tree Coding is a progressive wavelet compression method that encodes the most significant bits of wavelet coefficients first, leveraging the spatial hierarchy of the transform [S1, S2]. It distinguishes itself from sibling methods by using a "zero tree" symbol to efficiently skip entire hierarchies of insignificant coefficients, making it particularly effective for distance-based thresholding where significant regions are spatially contiguous [S1, S2].

## How it works
**Inputs:** A set of wavelet coefficients $C$ organized in a hierarchical structure.
**Outputs:** A progressive bitstream.

**Data Structures:**
The coefficients are organized in a hierarchy based on subband ordering. In 2D, this is a quadtree-like structure; in 3D, an octree-like structure [S1, S2]. The hierarchy is defined by parent-child relationships where a parent coefficient in a coarser subband has children in finer subbands. For example, in 2D, hierarchies may follow the x-direction (subbands 1, 3, 5) or y-direction (subbands 2, 4) [S1, S2]. Each coefficient $c$ is tracked in one of two states:
1.  **Insignificant:** Not yet determined to be significant.
2.  **Significant:** Determined to be significant in the current or a preceding traversal.

**Definitions:**
A **zero tree** is a hierarchy of coefficients where every coefficient $c$ in the hierarchy satisfies $|c| \leq T$, where $T$ is the current significance threshold [S1, S2].

**Algorithm Steps:**
1.  **Initialization:** Find the maximum absolute value $M$ among all wavelet coefficients. Set the initial threshold $T = M / 2$ [S1, S2].
2.  **Traversal Loop:** While $T$ is greater than a minimum precision limit:
    a.  **Zero Tree Check:** Traverse the coefficient hierarchy in a predefined order (e.g., raster scan of roots). For each root of a zero tree hierarchy:
        i.  Check if all coefficients in the hierarchy are insignificant with respect to $T$.
        ii. If yes, encode a "zero tree" symbol (indicating all coefficients in this hierarchy are $< T$) and skip to the next hierarchy [S1, S2].
        iii. If no, recursively traverse the children. If a child is a root of a zero tree, encode the symbol and skip it. If a child is a single coefficient:
            - If $|c| \leq T$, it is insignificant. Encode a symbol indicating insignificance (or implicitly handled by the traversal logic) [S1, S2].
            - If $|c| > T$, it is significant. Encode a "significant" symbol. Transmit the sign bit of $c$. Transmit the most significant bit (MSB) of $c$ relative to the current threshold (typically 1 if $|c| \geq T$) [S2]. Add $c$ to the set of significant coefficients [S1, S2].
    b.  **Refinement Pass:** For each coefficient $c$ already in the significant set:
        i.  Transmit the next most significant bit of $c$ (the bit at position $\log_2(T)$) [S2].
    c.  **Threshold Update:** Divide $T$ by 2 ($T = T / 2$) [S1, S2].

**Pseudocode:**
```python
def zero_tree_coding(coefficients, hierarchy_roots):
    # coefficients: dict mapping coefficient_id -> value
    # hierarchy_roots: list of root nodes for each hierarchy
    # state: dict mapping coefficient_id -> 'insignificant' or 'significant'
    
    # Initialize state
    state = {cid: 'insignificant' for cid in coefficients}
    
    # Find max coefficient to initialize threshold
    max_val = max(abs(c) for c in coefficients.values())
    if max_val == 0:
        return []
    
    threshold = max_val / 2.0
    bitstream = []
    
    while threshold > 0:
        # Main Pass: Sort and encode significant/insignificant
        for root in hierarchy_roots:
            encode_zero_tree(root, coefficients, state, threshold, bitstream)
            
        # Refinement Pass: Encode additional bits for significant coefficients
        for cid, val in coefficients.items():
            if state[cid] == 'significant':
                # Determine the bit to encode at current threshold level
                # The bit position corresponds to floor(log2(threshold))
                # In practice, this is often the bit immediately below the MSB
                # encoded in the main pass.
                bit = get_bit_at_level(val, threshold)
                bitstream.append(bit)
                
        threshold /= 2.0
        
    return bitstream

def encode_zero_tree(node, coefficients, state, threshold, bitstream):
    # Check if node is a leaf (single coefficient)
    if node.is_leaf():
        cid = node.coefficient_id
        if state[cid] == 'insignificant':
            if abs(coefficients[cid]) <= threshold:
                # Insignificant
                bitstream.append(0) # Symbol for insignificant
            else:
                # Significant
                bitstream.append(1) # Symbol for significant
                bitstream.append(1 if coefficients[cid] >= 0 else 0) # Sign bit
                bitstream.append(1) # MSB (since |c| > threshold)
                state[cid] = 'significant'
        else:
            # Already significant, handled in refinement pass
            pass
    else:
        # Check if entire subtree is a zero tree
        if is_zero_tree(node, coefficients, state, threshold):
            bitstream.append(0) # Symbol for zero tree
        else:
            # Recurse
            for child in node.children:
                encode_zero_tree(child, coefficients, state, threshold, bitstream)

def is_zero_tree(node, coefficients, state, threshold):
    # Returns True if all insignificant coefficients in the subtree are <= threshold
    # and no significant coefficients are present (they are handled separately)
    for cid in node.get_coefficients():
        if state[cid] == 'insignificant':
            if abs(coefficients[cid]) > threshold:
                return False
    return True
```

**Parameters:**
-   Initial Threshold $T_0 = \max(|c|) / 2$ [S1, S2].
-   Threshold decay factor: 2 (halved each iteration) [S1, S2].

**Edge Cases:**
-   If all coefficients are zero, the threshold remains zero or the loop terminates immediately [G].
-   Precision limits: The loop continues until $T$ is smaller than the desired reconstruction precision [G].

## Operating characteristics
-   **Complexity:** Time complexity is proportional to the number of coefficients and the number of threshold levels, which is logarithmic in the dynamic range of the coefficients. Memory complexity is linear in the number of coefficients to store the state and hierarchy [S1, S2].
-   **Performance:** Efficiently compresses data with sparse significant coefficients. Particularly effective for distance-based thresholding where significant coefficients are spatially contiguous, allowing large zero trees to be skipped [S1, S2].
-   **Strengths:** Progressive bitstream generation; efficient encoding of insignificant regions; simple implementation [S1, S2].
-   **Limitations:** Performance depends on the decay property of the wavelet transform; less effective if child coefficients are not consistently smaller than parents [S1, S2].

## Background
Zero Tree Coding was introduced by Shapiro in 1993 as part of the Embedded Zerotree Wavelet (EZW) algorithm [S1, S2]. It is a foundational technique in image and volume compression, later extended in SPIHT and other embedded coding schemes. It is used in progressive surface compression and volume rendering applications where multiresolution data is available [S1, S2].
