# Approximation Dimension Selection

Also called: Approximation Order and Bit-Length Selection

## Overview
Approximation Dimension Selection determines the optimal approximation order $D$, number of polynomial pieces $K$, and integer bit length $\text{INT\_MAX}$ for quantized higher-order SPH field approximations by minimizing a combined error measure [S1]. It sets apart from its sibling [Coefficient Quantization Error Estimate](3334-coefficient-quantization-error-estimate.md) by integrating quantization error $Q_D$ with the analytical per-particle approximation error $E_{K,D}$ to select the global configuration $(D, K, \text{INT\_MAX})$ [S1].

## How it works
**Inputs:**
- The SPH kernel function (e.g., cubic B-Spline).
- The data variance ratio $a_{\max}/\phi_{\text{repr}}$ [S1].
- The representative particle parameters $\mu_{\text{repr}}, \alpha_{\text{repr}}, \rho_{\text{repr}}, \zeta_{\text{repr}}$ used to derive the field value quantum $\zeta$ [S1].
- The search range for $D$ (e.g., $0 \le D \le 6$) and $K$ (e.g., $1 \le K \le 4$) [S1].

**Outputs:**
- Optimal tuple $(D^*, K^*, \text{INT\_MAX}^*)$ minimizing the combined error [S1].

**Data Structures:**
- Lookup table for $Q_D(a_{\max}/\phi_{\text{repr}})$ precomputed for each $D$ and $\text{INT\_MAX}$ [S1].
- Precomputed values for $E_{K,D}$ (computed at compile time) [S1].

**Steps:**
1. **Compute Approximation Error $E_{K,D}$:**
   For each candidate pair $(K, D)$, compute the per-particle relative approximation error:
   $$E_{K,D} = \frac{1}{\kappa} \left( 2\pi \int_0^q \Lambda E_\Lambda^2(S_\Lambda) d\Lambda \right)^{\frac{1}{2}}$$
   where $\kappa$ is the $L^2$ norm of a normalized particle’s contribution, $q$ is the integration limit, and $S_\Lambda$ is the optimal approximation at distance $\Lambda$ with optimal knot positions [S1].
   Since $S_\Lambda$ is obtained implicitly via minimization, compute the integral approximately as a Riemann sum [S1].

2. **Retrieve Quantization Error $Q_D$:**
   For the current $\text{INT\_MAX}$ and data variance ratio, retrieve $Q_D$ from the precomputed lookup table [S1]. The table is derived by minimizing $Q_D(\frac{\tau}{\zeta_{\text{repr}}}, \frac{\varsigma}{\phi_{\text{repr}}})$ with respect to the length quantum $\tau$ [S1].

3. **Compute Combined Error:**
   Calculate the overall approximation error by treating approximation and quantization errors as perpendicular sources:
   $$E_{\text{combined}} = \sqrt{E_{K,D}^2 + Q_D^2}$$
   This $L^2$ norm avoids the overestimation bias of simple summation [S1].

4. **Select Optimal Configuration:**
   Iterate over all valid $(K, D, \text{INT\_MAX})$ combinations. Select the tuple that yields the minimum $E_{\text{combined}}$ [S1].

**Parameters:**
- Typical $K$: 3 or 4 for cubic B-Spline kernels [S1].
- Typical $\text{INT\_MAX}$: 64 for data variance ratios of $10^5$ [S1].
- Limit on $D$: For cubic B-Splines with $K=3$ or $4$, raising $D$ above 4 is not worthwhile [S1].

**Edge Cases and Pitfalls:**
- **Precision:** $E_{K,D}$ requires numerical integration (Riemann sum) which may introduce approximation errors if the grid is too coarse [S1].
- **Performance:** Higher $\text{INT\_MAX}$ increases computational cost significantly due to software emulation of large integers [S1].

**Pseudocode:**
```python
def select_approximation_dimensions(kernel, data_variance_ratio, int_max_candidates):
    """
    Selects optimal D, K, and INT_MAX by minimizing combined error.
    """
    best_error = infinity
    best_config = None
    
    # Precomputed E_KD table for the specific kernel
    # E_KD[K][D] = value
    E_KD_table = precompute_approximation_error(kernel)
    
    # Precomputed QD lookup table
    # QD[D][int_max][variance_ratio_bin] = value
    QD_table = precompute_quantization_error_lookup(kernel, int_max_candidates)
    
    for K in range(1, 5):  # Typical range for K
        for D in range(0, 7):  # Typical range for D
            if K == 3 or K == 4:
                if D > 4:
                    continue  # Not worthwhile for cubic B-Spline
            
            E_KD = E_KD_table[K][D]
            
            for INT_MAX in int_max_candidates:
                # Retrieve QD from lookup table based on variance ratio
                Q_D = QD_table[D][INT_MAX].get(data_variance_ratio, None)
                
                if Q_D is None:
                    continue
                
                # Combined error
                combined_error = math.sqrt(E_KD**2 + Q_D**2)
                
                if combined_error < best_error:
                    best_error = combined_error
                    best_config = (D, K, INT_MAX)
                    
    return best_config
```

## Subtopics

### [Quantum Value Specification](5047-quantum-value-specification.md)
Determines the optimal length quantum $\tau$ and field value quantum $\zeta$ by minimizing $Q_D$. It sets apart by analytically deriving $\tau$ through convexity and coupling $\zeta$ to integer overflow constraints.

## Operating characteristics
- **Time Complexity:** Linear in $K$ (linearithmic overall due to search sweep); Quadratic in $D$ (number of coefficients and operations per update grow linearly with $D$) [S1].
- **Memory Complexity:** Depends on the size of the lookup tables for $Q_D$ and precomputed $E_{K,D}$ [S1].
- **Performance:** 32-bit integer addition throughput is comparable to 32-bit float; multiplication is ~5x slower. 64-bit integers are emulated in software, costing ~9x more than 32-bit; 96-bit ~24x; 128-bit ~45x [S1].
- **Strengths:** Provides a theoretical basis for configuration selection; allows precomputation of $E_{K,D}$ at compile time [S1].
- **Limitations:** Requires thorough testing for final evaluation; complex to implement due to numerical integration and lookup table generation [S1].
- **When to Use:** When balancing quality and speed in visualization tools using higher-order SPH fields [S1].

## Background
Originated in the context of Particle-Wise Higher-Order SPH Field Approximation for DVR [S1]. The method addresses the need to select fundamental parameters ($D, K, \text{INT\_MAX}$) that impact both approximation accuracy and performance [S1].
