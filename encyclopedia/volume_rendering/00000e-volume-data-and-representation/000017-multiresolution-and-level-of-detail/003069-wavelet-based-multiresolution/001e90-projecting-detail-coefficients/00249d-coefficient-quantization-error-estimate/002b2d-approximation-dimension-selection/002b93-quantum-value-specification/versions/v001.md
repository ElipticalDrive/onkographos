# Quantum Value Specification

Also called: Optimal Length Quantum Minimization

## Overview
Quantum Value Specification determines the optimal length quantum $\tau$ and field value quantum $\zeta$ for quantized higher-order SPH field approximations by minimizing a relative quantization error estimate $Q_D$ [S1]. It sets apart from sibling methods by analytically deriving $\tau$ through the convexity of the squared error derivative, ensuring a unique global minimum, while explicitly coupling $\zeta$ to integer overflow constraints via a representative particle model [S1].

## How it works
**Inputs:**
- Approximation order $D$ (integer $\ge 0$).
- Kernel support upper bound $q$ (scalar).
- SPH kernel function $w(t)$ (scalar function).
- Representative particle attributes: mass $\mu_{\text{repr}}$, density $\rho_{\text{repr}}$, volume quantum $\zeta_{\text{repr}}$, and weight $\alpha_{\text{repr}}$ (scalars).
- Upper bound of expected approximation values $a_{\max}$ (scalar).
- Maximum representable integer INT\_MAX (integer, e.g., $2^{31}-1$).

**Outputs:**
- Optimal length quantum $\tau$ (scalar).
- Field value quantum $\zeta$ (scalar).

**Data Structures:**
- No persistent data structures. All computations are scalar or simple summations.

**Steps:**

1. **Compute Kernel Constant $\kappa$:**
   Calculate the constant $\kappa$ which depends only on the SPH kernel $w(t)$:
   $$ \kappa = \left( 4\pi \int_{t=0}^{\infty} [t w(t)]^2 dt \right)^{1/2} $$
   [S1]

2. **Set Field Value Quantum $\zeta$:**
   To guard against integer overflow, set $\zeta$ to the optimal lower bound:
   $$ \zeta = \frac{a_{\max}}{\text{INT\_MAX}} $$
   [S1]

3. **Compute Representative Scaling Factor $\phi_{\text{repr}}$:**
   Calculate the scaling factor based on representative particle attributes:
   $$ \phi_{\text{repr}} = \frac{\mu_{\text{repr}}\alpha_{\text{repr}}}{\rho_{\text{repr}}\zeta_{\text{repr}}^3} $$
   [S1]

4. **Define the Relative Quantization Error Estimate $Q_D$:**
   The error estimate to be minimized is:
   $$ Q_D(\tau, \varsigma) = \frac{1}{4\kappa} \sqrt{\kappa^2 \tau^2 + \sum_{d=0}^D \frac{2q^{2d+3}}{(2d+1)(2d+3)} \cdot \frac{\varsigma^2}{\tau^{2d}}} $$
   where $\varsigma$ is the field value quantum and $\tau$ is the length quantum. Note that in the minimization step, the arguments to $Q_D$ are scaled: $Q_D\left(\frac{\tau}{\zeta_{\text{repr}}}, \frac{\varsigma}{\phi_{\text{repr}}}\right)$ [S1].

5. **Minimize $Q_D$ with respect to $\tau$:**
   Since $Q_D(\tau, \varsigma)$ is convex and has a unique global minimum, find the optimal $\tau$ by solving for the root of the first derivative of the squared error estimate with respect to $\tau$.
   
   The squared error estimate is $Q_D^2(\tau, \varsigma)$. Its first derivative is:
   $$ \frac{d}{d\tau} Q_D^2(\tau, \varsigma) = \frac{\kappa^2 \tau}{8\kappa^2} - \sum_{d=1}^D \frac{dq^{2d+3}}{4\kappa^2 (2d+1)(2d+3)} \cdot \frac{\varsigma^2}{\tau^{2d+1}} $$
   Simplifying the first term:
   $$ \frac{d}{d\tau} Q_D^2(\tau, \varsigma) = \frac{\tau}{8} - \sum_{d=1}^D \frac{dq^{2d+3}}{4\kappa^2 (2d+1)(2d+3)} \cdot \frac{\varsigma^2}{\tau^{2d+1}} $$
   [S1]
   
   The second derivative is:
   $$ \frac{d^2}{d\tau^2} Q_D^2(\tau, \varsigma) = \frac{1}{8} + \sum_{d=1}^D \frac{dq^{2d+3}}{4\kappa^2 (2d+3)} \cdot \frac{\varsigma^2}{\tau^{2d+2}} > 0 $$
   This proves convexity and the existence of a unique global minimum [S1].
   
   Solve $\frac{d}{d\tau} Q_D^2\left(\frac{\tau}{\zeta_{\text{repr}}}, \frac{\varsigma}{\phi_{\text{repr}}}\right) = 0$ for $\tau$ using a root-finding method (e.g., Newton-Raphson or Brent's method). Let the solution be $\tau^*$.

**Pseudocode:**

```python
import math
from scipy.optimize import brentq

def compute_kappa(w_func):
    """
    Computes kappa = sqrt(4 * pi * integral_0^inf (t * w(t))^2 dt)
    w_func: callable w(t)
    """
    # Numerical integration from 0 to a sufficiently large upper bound
    # For SPH kernels, support is finite, e.g., [0, 2h]. 
    # Here we assume w(t) is 0 for t > q.
    # Using a simple quadrature for demonstration.
    # In practice, use a robust integrator.
    from scipy.integrate import quad
    
    def integrand(t):
        return (t * w_func(t))**2
    
    integral_val, _ = quad(integrand, 0, float('inf'))
    return math.sqrt(4 * math.pi * integral_val)

def compute_zeta(a_max, int_max):
    """
    Computes field value quantum zeta.
    """
    return a_max / int_max

def compute_phi_repr(mu_repr, alpha_repr, rho_repr, zeta_repr):
    """
    Computes representative scaling factor phi_repr.
    """
    return (mu_repr * alpha_repr) / (rho_repr * zeta_repr**3)

def derivative_of_squared_error(tau, kappa, q, zeta, D):
    """
    Computes d/dtau Q_D^2(tau, zeta).
    Note: The formula in the source uses scaled arguments in the minimization step.
    This function computes the derivative for the unscaled Q_D^2(tau, zeta).
    The caller will pass scaled tau and zeta.
    
    Formula: tau/8 - sum_{d=1}^D [ d * q^(2d+3) / (4 * kappa^2 * (2d+1)(2d+3)) * zeta^2 / tau^(2d+1) ]
    """
    term1 = tau / 8.0
    
    term2 = 0.0
    kappa_sq = kappa * kappa
    for d in range(1, D + 1):
        numerator = d * (q ** (2 * d + 3))
        denominator = 4 * kappa_sq * (2 * d + 1) * (2 * d + 3)
        term2 += (numerator / denominator) * (zeta ** 2) / (tau ** (2 * d + 1))
        
    return term1 - term2

def find_optimal_tau(D, kappa, q, zeta_scaled, tau_min=1e-9, tau_max=1e9):
    """
    Finds optimal tau by root-finding on the derivative of squared error.
    """
    # The derivative is strictly increasing (convex), so root finding is stable.
    # We look for the root of derivative_of_squared_error(tau) = 0
    try:
        tau_opt = brentq(
            derivative_of_squared_error, 
            tau_min, 
            tau_max, 
            args=(kappa, q, zeta_scaled, D)
        )
    except ValueError:
        # If no root found in interval, fallback or error.
        # Given convexity and limits (0->inf, inf->inf), a root should exist.
        tau_opt = (tau_min + tau_max) / 2.0
        
    return tau_opt

def quantum_value_specification(D, w_func, q, mu_repr, rho_repr, zeta_repr, alpha_repr, a_max, int_max):
    """
    Main function to compute Quantum Value Specification.
    """
    # Step 1: Compute kappa
    kappa = compute_kappa(w_func)
    
    # Step 2: Set zeta (field value quantum)
    zeta = compute_zeta(a_max, int_max)
    
    # Step 3: Compute phi_repr
    phi_repr = compute_phi_repr(mu_repr, alpha_repr, rho_repr, zeta_repr)
    
    # Step 4: Determine scaled arguments for minimization
    # We minimize Q_D(tau/zeta_repr, zeta/phi_repr)
    # Let tau_scaled = tau / zeta_repr
    # Let zeta_scaled = zeta / phi_repr
    # The derivative is with respect to tau.
    # d/dtau Q_D^2(tau/zeta_repr, zeta/phi_repr) 
    # = d/d(tau_scaled) Q_D^2(tau_scaled, zeta_scaled) * d(tau_scaled)/dtau
    # = d/d(tau_scaled) Q_D^2(...) * (1/zeta_repr)
    # Setting this to 0 is equivalent to setting d/d(tau_scaled) Q_D^2(...) = 0.
    # So we find tau_scaled_opt, then tau_opt = tau_scaled_opt * zeta_repr.
    
    zeta_scaled = zeta / phi_repr
    
    # Find optimal tau_scaled
    tau_scaled_opt = find_optimal_tau(D, kappa, q, zeta_scaled)
    
    # Convert back to optimal tau
    tau_opt = tau_scaled_opt * zeta_repr
    
    return tau_opt, zeta
```

**Parameters:**
- $D$: Approximation order. Typical values depend on desired smoothness; higher $D$ increases computational cost but reduces approximation error.
- $q$: Kernel support upper bound. Depends on the specific SPH kernel used (e.g., $q=2$ for many standard kernels).
- $a_{\max}$: Upper bound of expected approximation values. Determined by a short analysis of the dataset.
- INT\_MAX: Maximum representable integer for the chosen bit-length (e.g., $2^{31}-1$ for 32-bit signed integers).

**Edge Cases and Pitfalls:**
- **Integer Overflow:** Smaller $\zeta$ allows more precise quantization but requires larger integer coefficients $\tilde{a}_{kd}$. This is mitigated by setting $\zeta = a_{\max} / \text{INT\_MAX}$ [S1].
- **Root Finding Bounds:** The derivative $\frac{d}{d\tau} Q_D^2(\tau, \varsigma)$ goes from $-\infty$ to $+\infty$ as $\tau$ goes from $0$ to $\infty$. Ensure the root-finding interval $[\tau_{\min}, \tau_{\max}]$ is wide enough to bracket the root.
- **Kernel Integral:** The computation of $\kappa$ requires numerical integration of the kernel function. Ensure the integration range covers the full support of the kernel.

## Operating characteristics
- **Time Complexity:** The computation of $\kappa$ is done once per kernel. The minimization of $\tau$ requires iterative root-finding, where each iteration involves a summation over $D$ terms. Thus, the complexity is $O(D)$ per iteration of the root-finder.
- **Memory Complexity:** $O(1)$ auxiliary space, as only scalar values are stored.
- **Strengths:** Provides an analytical, convex objective for $\tau$, ensuring a unique global minimum. Explicitly handles integer overflow constraints.
- **Limitations:** Requires representative particle attributes, which may not capture local variations in the dataset. The error estimate $Q_D$ is data-independent and ray-independent, so it may not reflect local quantization errors accurately.
- **When to Use:** When quantizing higher-order SPH field approximations for volume rendering, especially when integer precision is a constraint.
- **When Not to Use:** When local error adaptation is required, or when representative attributes are not available or misleading.

## Background
Quantum Value Specification was introduced in the context of particle-wise higher-order SPH field approximation for direct volume rendering (DVR) [S1]. It addresses the challenge of balancing quantization error against integer overflow constraints in the representation of smooth particle hydrodynamics (SPH) fields. The method builds on the relative quantization error estimate $Q_D$ derived in the same work [S1].
