# Pre-processing for Half Resolution
Also called: Half-resolution volume construction
## Overview
This method constructs a half-resolution volumetric grid from a full-resolution source to reduce data size while preserving structural integrity, specifically addressing the information loss inherent in direct subsampling. It differs from its sibling [VoxelGrid Down Sample](1014-voxelgrid-down-sample.md), which uses max pooling, by employing a median-based fill strategy for transparent regions to maintain edge sharpness and prevent occlusion artifacts in downstream rendering.
## How it works
**Inputs and Outputs:**
- Input: A full-resolution volumetric grid $V_{full}$ of dimensions $H \times W \times D$. Each voxel contains a density/opacity value and potentially color. A voxel is considered "transparent" if its opacity is zero (or below a negligible threshold); otherwise, it is "opaque" or "occupied".
- Output: A half-resolution volumetric grid $V_{half}$ of dimensions $\lceil H/2 \rceil \times \lceil W/2 \rceil \times \lceil D/2 \rceil$.

**Data Structures:**
- $V_{full}$: 3D array. Access $V_{full}[x, y, z]$ for $1 \le x \le H$, $1 \le y \le W$, $1 \le z \le D$.
- $V_{half}$: 3D array. Indices $\hat{i}, \hat{j}, \hat{k}$ correspond to logical positions in the downsampled grid.

**Algorithm Steps:**
1. **Initialization**: Create $V_{half}$ with dimensions $\lceil H/2 \rceil \times \lceil W/2 \rceil \times \lceil D/2 \rceil$. Initialize all voxels to transparent.
2. **Subsampling**: For each logical position $(\hat{i}, \hat{j}, \hat{k})$ in $V_{half}$ where $\hat{i}, \hat{j}, \hat{k} \in \{1, 2, ...\}$:
   - Calculate the corresponding full-resolution coordinates:
     $$ x = 2\hat{i} - 1 $$
     $$ y = 2\hat{j} - 1 $$
     $$ z = 2\hat{k} - 1 $$
   - If $1 \le x \le H$, $1 \le y \le W$, and $1 \le z \le D$:
     - Copy the value of $V_{full}[x, y, z]$ to $V_{half}[\hat{i}, \hat{j}, \hat{k}]$.
3. **Transparent Fill**: Iterate through every voxel $V_{half}[\hat{i}, \hat{j}, \hat{k}]$ that is currently transparent.
   - Identify the eight adjacent voxels in the full-resolution grid surrounding the subsampled point $(x, y, z)$. These are the voxels at coordinates:
     $$ (x+\delta_x, y+\delta_y, z+\delta_z) $$
     where $\delta_x, \delta_y, \delta_z \in \{-1, 1\}$.
   - Collect the values of these eight neighbors from $V_{full}$.
   - If any of these eight neighbors is not transparent:
     - Compute the median value of the non-transparent neighbors. If all eight are transparent, the voxel remains transparent.
     - Replace $V_{half}[\hat{i}, \hat{j}, \hat{k}]$ with this median value.
4. **Boundary Removal**: Identify any voxels in $V_{half}$ that were filled in Step 3 but correspond to spatial locations outside the original object's bounding volume in $V_{full}$. Remove these voxels (set to transparent) to ensure they do not occlude or affect points of the original full-resolution volume during rendering.

**Pseudocode:**
```python
def preprocess_half_resolution(V_full, H, W, D):
    # Dimensions of half-resolution grid
    H_half = (H + 1) // 2
    W_half = (W + 1) // 2
    D_half = (D + 1) // 2
    
    V_half = create_3d_array(H_half, W_half, D_half, value=TRANSPARENT)
    
    # Step 2: Subsampling
    for i_hat in range(1, H_half + 1):
        for j_hat in range(1, W_half + 1):
            for k_hat in range(1, D_half + 1):
                x = 2 * i_hat - 1
                y = 2 * j_hat - 1
                z = 2 * k_hat - 1
                
                # Check bounds for full resolution
                if 1 <= x <= H and 1 <= y <= W and 1 <= z <= D:
                    V_half[i_hat-1, j_hat-1, k_hat-1] = V_full[x-1, y-1, z-1]
    
    # Step 3: Transparent Fill
    for i_hat in range(1, H_half + 1):
        for j_hat in range(1, W_half + 1):
            for k_hat in range(1, D_half + 1):
                if is_transparent(V_half[i_hat-1, j_hat-1, k_hat-1]):
                    x = 2 * i_hat - 1
                    y = 2 * j_hat - 1
                    z = 2 * k_hat - 1
                    
                    neighbors = []
                    # Check 8 adjacent voxels in full resolution
                    for dx in [-1, 1]:
                        for dy in [-1, 1]:
                            for dz in [-1, 1]:
                                nx, ny, nz = x + dx, y + dy, z + dz
                                if 1 <= nx <= H and 1 <= ny <= W and 1 <= nz <= D:
                                    if not is_transparent(V_full[nx-1, ny-1, nz-1]):
                                        neighbors.append(V_full[nx-1, ny-1, nz-1])
                    
                    if neighbors:
                        median_val = compute_median(neighbors)
                        V_half[i_hat-1, j_hat-1, k_hat-1] = median_val
    
    # Step 4: Boundary Removal
    # Note: The source implies removing voxels that are "outside the volume".
    # In practice, this often means checking if the filled voxel's position 
    # is geometrically outside the object's bounding box or if it creates 
    # artifacts. The source states: "Remove new voxels located outside the volume".
    # Implementation detail: If the original V_full has a known bounding box,
    # remove V_half voxels that map to coordinates outside this box.
    # If no explicit bounding box is provided, this step may be implicit 
    # in the rendering engine or defined by the object's extent.
    # [G] Assuming a simple bounding box check for implementation completeness.
    remove_outside_voxels(V_half, H, W, D)
    
    return V_half

def is_transparent(voxel):
    return voxel.opacity <= 0.0

def compute_median(values):
    sorted_vals = sorted(values, key=lambda v: v.density)
    n = len(sorted_vals)
    if n % 2 == 1:
        return sorted_vals[n // 2]
    else:
        return (sorted_vals[n // 2 - 1] + sorted_vals[n // 2]) / 2.0
```

**Parameters:**
- Transparency threshold: Not given in the sources. [G] Typically a small epsilon (e.g., $10^{-6}$) or zero.
- Median calculation: Arithmetic mean of the two middle values for even counts, middle value for odd counts.

**Edge Cases and Pitfalls:**
- **Boundary Conditions**: The subsampling formula $2\hat{i}-1$ maps to odd indices. If the full resolution dimensions $H, W, D$ are even, the last row/column/layer in $V_{full}$ is never directly subsampled. The transparent fill step may need to account for neighbors at the grid boundaries. The source notes do not specify behavior for neighbors outside the $H \times W \times D$ bounds; [G] these should be ignored or treated as transparent.
- **Degenerate Input**: If all eight neighbors are transparent, the voxel remains transparent.
- **Precision**: Median calculation should use sufficient precision to avoid quantization artifacts, though the source does not specify.

## Subtopics
## Operating characteristics
- **Performance**: The pre-processed half-resolution volume achieves a PSNR of 32.08 dB for full-resolution reconstruction. This is significantly higher than direct subsampling (22.75 dB), linear interpolation (27.44 dB), and nearest interpolation (26.03 dB) [S1].
- **Complexity**: Time complexity is $O(H \cdot W \cdot D)$ as each voxel in the half-resolution grid requires checking up to 8 neighbors in the full-resolution grid. Memory complexity is $O(H \cdot W \cdot D)$ for the input and $O(H \cdot W \cdot D / 8)$ for the output.
- **Strengths**: Eliminates holes in synthesized views and improves image quality by preserving edge information that subsampling would lose.
- **Limitations**: The pre-processing step adds computational overhead before rendering. The method is specific to volumetric representations and may not directly apply to other data structures.
- **When to use**: When high-quality view synthesis from a half-resolution model is required, and direct subsampling results in unacceptable quality loss.
- **When not to use**: When computational resources for pre-processing are constrained and lower quality is acceptable, or when the data structure does not support efficient neighbor access.

## Background
The method was introduced in the context of colour volumetric compression for realistic view synthesis applications. It addresses the problem of information loss when reducing the resolution of volumetric data for storage or transmission. The approach is part of a broader strategy to balance data size and visual quality in 3D image/video coding.
