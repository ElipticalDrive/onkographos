# VoxelGrid Down Sample

## Overview
VoxelGrid Down Sample reduces the resolution of a volumetric voxel grid by a specified integer factor using max pooling [S1, unofficial]. It solves the problem of managing memory and computational load for high-resolution volumes by creating coarser representations that preserve high-intensity features, which is critical for Maximum Intensity Projection (MIP) rendering [S1, unofficial]. It differs from its siblings by using a strict, non-overlapping block reduction with a divisibility check, whereas methods like [Pre-processing for Half Resolution](6436-pre-processing-for-half-resolution.md) use median filling to handle transparent holes, and [Optimization-based Downsampling](5825-optimization-based-downsampling.md) iteratively adjusts scattering parameters [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: A `VoxelGrid` object containing a 3D data array `data` of shape $(N_x, N_y, N_z)$ and metadata (location, scale).
*   Input: An integer downsampling `factor` $f$.
*   Output: A new `VoxelGrid` object with data shape $(N_x/f, N_y/f, N_z/f)$, retaining the original location and scale metadata.

**Data Structures:**
The input `VoxelGrid` is assumed to have a contiguous 3D numpy array or tensor `data` of type float or int. The output is a new instance of the same class.

**Steps:**
1.  **Validation:** Check if the dimensions of the input data are divisible by the factor. If $N_x \% f \neq 0$ or $N_y \% f \neq 0$ or $N_z \% f \neq 0$, raise a `ValueError` [S1, unofficial].
2.  **Block Reduction:** Apply a max pooling operation over non-overlapping blocks of size $f \times f \times f$. For each output voxel at index $(i, j, k)$, the value is the maximum of the input voxels in the block defined by $x \in [i \cdot f, (i+1) \cdot f)$, $y \in [j \cdot f, (j+1) \cdot f)$, $z \in [k \cdot f, (k+1) \cdot f)$ [S1, S2, unofficial].
3.  **Reconstruction:** Create a new `VoxelGrid` instance. Assign the reduced data array to the new instance. Copy the original `location` and `scale` attributes from the input grid to the output grid [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def voxelgrid_down_sample(voxel_grid: VoxelGrid, factor: int) -> VoxelGrid:
    """
    Downsample a VoxelGrid by a factor using max pooling.
    
    Args:
        voxel_grid: Input VoxelGrid with data shape (Nx, Ny, Nz).
        factor: Integer downsampling factor.
        
    Returns:
        New VoxelGrid with shape (Nx/f, Ny/f, Nz/f).
    """
    data = voxel_grid.data
    shape = data.shape
    
    # Step 1: Validate divisibility
    if shape[0] % factor != 0 or shape[1] % factor != 0 or shape[2] % factor != 0:
        raise ValueError(f"Resolution {shape} is not divisible by factor {factor}")
    
    # Step 2: Downsample using block_reduce (max pooling)
    # Reshape to group voxels into blocks of size (factor, factor, factor)
    # Then take the max over the block dimensions
    new_shape = (shape[0] // factor, factor,
                 shape[1] // factor, factor,
                 shape[2] // factor, factor)
    
    # Reshape the data to separate block indices and block coordinates
    reshaped_data = data.reshape(new_shape)
    
    # Max pool over the last 3 dimensions (the block coordinates)
    # Resulting shape: (Nx/f, Ny/f, Nz/f)
    downsampled_data = reshaped_data.max(axis=(1, 3, 5))
    
    # Step 3: Return new VoxelGrid with same loc and scale
    new_grid = VoxelGrid(data=downsampled_data)
    new_grid.location = voxel_grid.location
    new_grid.scale = voxel_grid.scale
    
    return new_grid
```

**Parameters:**
*   `factor`: Integer $\ge 1$. Typical values are powers of 2 (e.g., 2, 4) to align with hierarchical LOD structures [S1, S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Divisibility:** The method requires exact divisibility. If the grid dimensions are not multiples of the factor, it fails rather than truncating [S1, unofficial].
*   **Precision:** Max pooling preserves the maximum value, which is suitable for density or opacity but may not be appropriate for scalar fields requiring averaging [S1, unofficial].
*   **Memory:** The output grid uses $1/f^3$ the memory of the input [S1, unofficial].

## Subtopics

### Max-Pooling Layer
A layer that applies a max filter to non-overlapping sub-regions of the input to downsample the input and reduce parameters in subsequent encoder layers. It contains no trainable parameters [S2, unofficial]. Typical configuration uses a filter size of $2 \times 2$ and a stride of 2, applied in layers with input channels 64, 32, and 8 [S2, unofficial].

### [Volume Resampling and Overflow Guard](1772-volume-resampling-and-overflow-guard.md)
This method resamples a candidate volume grid to a target shape while enforcing a maximum voxel count to prevent downstream memory overflow. It differs from sibling methods by combining a strict safety cap with precise trilinear interpolation and a fallback dimension-decrement mechanism to guarantee reduction even when rounding constraints interfere.

### [Grid Deformation](5372-grid-deformation.md)
Grid Deformation is a preprocessing technique applied prior to data reduction in volume rendering compression. It transforms the input data grid according to user-defined regions to better preserve salient features during subsequent downsampling. It is an orthogonal approach to hierarchical models like wavelets, reporting improved visual results compared to pure downsampling and wavelet-based methods.

### [Optimization-based Downsampling](5825-optimization-based-downsampling.md)
Optimization-based downsampling is a method for reducing the resolution of microflake volumes that preserves appearance by iteratively optimizing scattering parameters to match a high-resolution reference. It solves the problem of geometric aliasing and shadowing artifacts in aggregated microgeometry, distinguishing itself from naive averaging or simple SGGX approximation by explicitly accounting for shadowing effects through image-space error minimization.

### [Pre-processing for Half Resolution](6436-pre-processing-for-half-resolution.md)
This method constructs a half-resolution volumetric representation from a full-resolution input to reduce data size while preserving visual quality and avoiding the information loss associated with direct subsampling. It differs from its sibling VoxelGrid Down Sample, which uses max pooling, by explicitly filling "holes" (transparent voxels in the downsampled grid) with median values from adjacent full-resolution neighbors to prevent occlusion artifacts. Unlike Frequency-Domain Downsampling, which relies on low-pass filtering in the frequency domain, this approach operates directly in the spatial domain using a specific subsampling pattern and local median replacement.

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of input voxels, as each voxel is visited once during the block reduction [S1, unofficial].
*   **Memory Complexity:** $O(N/f^3)$ for the output grid [S1, unofficial].
*   **Strengths:** Simple, fast, and preserves high-intensity features ideal for MIP [S1, S2, unofficial].
*   **Limitations:** Requires exact divisibility; not suitable for scalar fields where averaging is preferred; does not handle transparent holes as well as median-based methods [S1, S2, unofficial].
*   **When to use:** When creating LOD levels for MIP rendering or when computational speed is critical and grid dimensions are powers of 2 [S1, S2, unofficial].
*   **When not to use:** When grid dimensions are not divisible by the factor, or when preserving average intensity is more important than peak intensity [S1, unofficial].

## Background
The method originates from the implementation of differentiable volumetric rendering pipelines, where efficient resolution management is required for gradient-based optimization [S1, unofficial]. It is also a standard component in deep learning autoencoders for volume compression, where max-pooling layers are used to reduce spatial dimensions and parameter counts [S2, unofficial].
