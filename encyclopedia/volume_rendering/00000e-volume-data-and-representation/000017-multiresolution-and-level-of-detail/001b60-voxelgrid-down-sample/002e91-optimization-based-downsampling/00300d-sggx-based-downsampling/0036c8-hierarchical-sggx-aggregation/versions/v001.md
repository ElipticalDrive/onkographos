# Hierarchical SGGX Aggregation

Also called: SGG-H, SGGX-H

## Overview
Hierarchical SGGX Aggregation is a method for progressively reducing the number of Scalable Generalized Gaussian eXtension (SGGX) distributions within a Level of Detail (LoD) block, preserving high-frequency orientation details better than naive averaging or single-representative fitting [S1]. It solves the problem of information loss when downsampling complex microgeometry by treating distribution reduction as a hierarchical clustering problem, where the most similar distributions are merged iteratively [S1]. Unlike naive aggregation which collapses tangents into perpendicular directions and loses accuracy, this method evaluates samples of multiple distributions without averaging them, preserving anisotropy [S1].

## How it works
**Inputs:** A set of SGGX distributions $D_L = \{S_1, S_2, \dots, S_L\}$ representing a specific LoD level $L$.
**Outputs:** A reduced set of distributions $D_{L-1}$ for the next lower resolution level.

**Data Structures:**
*   **SGGX Distribution ($S_i$):** Defined by a rotation matrix $O$ and a diagonal scaling matrix $S$. The matrix $S$ is defined by eigenvectors $\omega_1, \omega_2, \omega_3$ and eigenvalues $\lambda_1, \lambda_2, \lambda_3$ (where $\lambda_k = \sigma(\omega_k)$) [S1].
*   **Histogram ($H(S_i)$):** A 3D histogram with 5 bins in each spatial dimension (total 125 bins) representing the sampled orientation distribution of $S_i$ [S1].

**Parameters:**
*   $N = 5000$: Number of samples drawn from each SGGX distribution [S1].
*   $K = 3$: Maximum number of distributions allowed per LoD block [S1].
*   Distance Metric: $\chi$-Wasserstein distance [S1].

**Algorithm Steps:**
1.  **Sampling:** For each SGGX distribution $S_i \in D_L$, draw $N$ samples from the distribution. The sampling process generates uniform samples in the whole sphere, which are projected from the whole space to the underlying ellipsoid to ensure distribution in the whole Normal Distribution Function (NDF) [S1].
2.  **Binning:** Bin the $N$ samples into a histogram $H(S_i)$ with 5 bins per spatial dimension [S1].
3.  **Distance Calculation:** Compute the pairwise distance between all histograms $H(S_i)$ and $H(S_j)$ using the $\chi$-Wasserstein distance [S1].
4.  **Pair Selection:** Find the pair $(i, j)$ with $i \neq j$ that minimizes the distance:
    $$ \arg \min_{i,j} \text{dist}(H(S_i), H(S_j)) $$
    where $S_i, S_j \in D_L$ [S1].
5.  **Aggregation:** Aggregate the samples of the selected $S_i$ and $S_j$. Fit the resulting combined histogram into a new SGGX distribution $S_n$ using the fitting algorithm described in [S1] (Section 4.1).
6.  **Update Set:** Form the next LoD set $D_{L-1}$ by removing $S_i$ and $S_j$ from $D_L$ and adding $S_n$:
    $$ D_{L-1} = (D_L \setminus \{S_i, S_j\}) \cup \{S_n\} $$
7.  **Iteration:** Repeat steps 1-6 until the number of distributions in the block reaches the maximum limit (3) or the target LoD level is reached [S1].

**Pseudocode:**

```python
def hierarchical_sggx_aggregation(distributions_L, max_distributions_per_block=3):
    """
    Reduces the number of SGGX distributions in a block hierarchically.
    
    Args:
        distributions_L: List of SGGX distribution objects.
        max_distributions_per_block: Target number of distributions for the next LoD.
        
    Returns:
        List of SGGX distribution objects for LoD L-1.
    """
    current_distributions = list(distributions_L)
    
    # Continue merging until we reach the desired number of distributions
    while len(current_distributions) > max_distributions_per_block:
        n_samples = 5000
        bins_per_dim = 5
        
        # Step 1 & 2: Sample and bin each distribution
        histograms = []
        for s in current_distributions:
            # Draw N samples from SGGX distribution s
            samples = s.sample(n_samples)
            # Bin samples into a 3D histogram
            hist = create_histogram(samples, bins_per_dim)
            histograms.append(hist)
            
        # Step 3 & 4: Compute pairwise Wasserstein distances and find min
        min_dist = float('inf')
        pair_indices = (None, None)
        
        num_dist = len(histograms)
        for i in range(num_dist):
            for j in range(i + 1, num_dist):
                # Compute chi-Wasserstein distance between histograms
                dist = chi_wasserstein_distance(histograms[i], histograms[j])
                if dist < min_dist:
                    min_dist = dist
                    pair_indices = (i, j)
                    
        i, j = pair_indices
        
        # Step 5: Aggregate samples and fit new SGGX
        # Combine samples from the two selected distributions
        combined_samples = current_distributions[i].sample(n_samples) + \
                           current_distributions[j].sample(n_samples)
                           
        # Fit new SGGX Sn from combined histogram
        new_histogram = create_histogram(combined_samples, bins_per_dim)
        s_new = fit_sggx_from_histogram(new_histogram)
        
        # Step 6: Update distribution list
        # Remove the two merged distributions and add the new one
        # Note: Remove larger index first to avoid shifting issues
        current_distributions.pop(j)
        current_distributions.pop(i)
        current_distributions.append(s_new)
        
    return current_distributions

def create_histogram(samples, bins_per_dim):
    """
    Bins 3D direction vectors into a 3D histogram.
    Assumes samples are normalized vectors in [-1, 1]^3.
    """
    # Initialize histogram
    hist = np.zeros((bins_per_dim, bins_per_dim, bins_per_dim))
    
    for sample in samples:
        # Map vector component from [-1, 1] to [0, bins_per_dim - 1]
        # Using floor and clamp to handle boundaries
        bin_x = int((sample[0] + 1) / 2 * (bins_per_dim - 1))
        bin_y = int((sample[1] + 1) / 2 * (bins_per_dim - 1))
        bin_z = int((sample[2] + 1) / 2 * (bins_per_dim - 1))
        
        # Clamp to valid range
        bin_x = max(0, min(bin_x, bins_per_dim - 1))
        bin_y = max(0, min(bin_y, bins_per_dim - 1))
        bin_z = max(0, min(bin_z, bins_per_dim - 1))
        
        hist[bin_x, bin_y, bin_z] += 1
        
    # Normalize histogram to represent probability distribution
    total = np.sum(hist)
    if total > 0:
        hist = hist / total
        
    return hist

def chi_wasserstein_distance(hist1, hist2):
    """
    Computes the chi-squared Wasserstein distance between two histograms.
    Simplified implementation for 3D histograms.
    """
    # Calculate bin centers for 3D grid
    bins_per_dim = hist1.shape[0]
    centers = np.linspace(-1, 1, bins_per_dim)
    
    # Create meshgrid of centers
    cx, cy, cz = np.meshgrid(centers, centers, centers, indexing='ij')
    centers_3d = np.stack([cx, cy, cz], axis=-1).reshape(-1, 3)
    
    # Flatten histograms
    h1_flat = hist1.flatten()
    h2_flat = hist2.flatten()
    
    # Compute Euclidean distance between bin centers
    # Wasserstein distance approximation using bin centers and probabilities
    # Note: True 1-Wasserstein requires optimal transport. 
    # The source cites "chiWasserstein" which often refers to Chi-squared distance 
    # or a specific Earth Mover's Distance variant. 
    # Given the context of "probability distribution distance function", 
    # and common implementations in this domain, we approximate with 
    # a weighted Euclidean distance or Chi-squared distance if OT is too heavy.
    # However, Wasserstein usually implies OT. 
    # For the purpose of this implementation article, we use a standard 
    # 1D/3D Wasserstein approximation or Chi-squared if specified.
    # The source explicitly says "chiWasserstein". 
    # We will implement a simplified Chi-squared distance as a proxy 
    # if exact OT is not defined, but note that true Wasserstein is preferred.
    # Given the constraint to be implementable, we use Chi-squared distance 
    # as a common proxy for distribution similarity in this specific paper's context 
    # (often used interchangeably in loose terminology or specific variants).
    
    # Chi-squared distance: sum((h1 - h2)^2 / (h1 + h2))
    denom = h1_flat + h2_flat
    denom = np.where(denom == 0, 1, denom) # Avoid division by zero
    dist = np.sum((h1_flat - h2_flat)**2 / denom)
    
    return dist

def fit_sggx_from_histogram(histogram):
    """
    Fits an SGGX distribution to a histogram.
    This involves computing the covariance matrix of the underlying samples 
    that generated the histogram, or using the histogram moments directly.
    Based on Section 4.1 of [S1], we compute the covariance matrix E 
    from the orientation data X.
    """
    # Reconstruct sample points from histogram bins
    # This is an approximation. Ideally, we fit to the raw samples.
    # Since we don't have raw samples here, we estimate the mean and covariance 
    # from the histogram centers weighted by probability.
    
    bins_per_dim = histogram.shape[0]
    centers = np.linspace(-1, 1, bins_per_dim)
    cx, cy, cz = np.meshgrid(centers, centers, centers, indexing='ij')
    points = np.stack([cx, cy, cz], axis=-1).reshape(-1, 3)
    probs = histogram.flatten()
    
    # Compute weighted mean
    mean = np.sum(points * probs[:, np.newaxis], axis=0)
    
    # Compute covariance matrix
    diff = points - mean
    cov = np.zeros((3, 3))
    for k in range(len(points)):
        cov += probs[k] * np.outer(diff[k], diff[k])
        
    # Eigen decomposition
    eigenvalues, eigenvectors = np.linalg.eigh(cov)
    
    # Sort eigenvalues and eigenvectors
    idx = eigenvalues.argsort()[::-1]
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]
    
    # Handle ill-defined case (all orientations aligned)
    if np.all(eigenvalues < 1e-6):
        # Use uniform distribution to introduce deviation
        # Return a default isotropic SGGX
        return SGGX(isotropic=True)
        
    # SGGX Matrix S = (w1, w2, w3) * diag(sigma(w1), sigma(w2), sigma(w3))
    # sigma(w) is the standard deviation corresponding to the eigenvector direction
    sigmas = np.sqrt(eigenvalues)
    
    # Construct SGGX object
    sggx = SGGX()
    sggx.eigenvectors = eigenvectors
    sggx.sigmas = sigmas
    
    return sggx

class SGGX:
    def __init__(self, isotropic=False):
        if isotropic:
            self.eigenvectors = np.eye(3)
            self.sigmas = np.array([1.0, 1.0, 1.0])
        else:
            self.eigenvectors = np.eye(3)
            self.sigmas = np.array([1.0, 1.0, 1.0])
            
    def sample(self, n):
        """
        Sample n directions from the SGGX distribution.
        Uses the VNDF approach modified for the whole sphere.
        """
        # Simplified sampling: sample from a Gaussian in the tangent space 
        # and project to sphere, or use rejection sampling.
        # For implementation completeness, we use a standard Gaussian sample 
        # in the local frame defined by eigenvectors.
        samples_local = np.random.randn(n, 3)
        # Scale by sigmas
        samples_local = samples_local * self.sigmas[np.newaxis, :]
        # Rotate to world frame
        samples_world = samples_local @ self.eigenvectors.T
        # Normalize to unit vectors
        samples_world = samples_world / np.linalg.norm(samples_world, axis=1, keepdims=True)
        return samples_world
```

## Subtopics

### SGGX Distribution Fitting
Fits arbitrary orientation histograms to a single SGGX distribution at the leaf-voxel level to aggregate multiple samples per voxel into a better representation than a single random value [S1]. It extracts eigenvectors $(\omega_1, \omega_2, \omega_3)$ and eigenvalues $\{\lambda_1, \lambda_2, \lambda_3\}$ from the covariance matrix $E$, where $\lambda_k = \sigma(\omega_k)$ [S1]. The SGGX matrix $S$ is defined as $S = (\omega_1, \omega_2, \omega_3) \text{diag}(\sigma(\omega_1), \sigma(\omega_2), \sigma(\omega_3))$ [S1]. If all input orientations align to almost the exact same orientation, the SGGX becomes ill-defined; this is handled by using a uniform distribution to introduce a small deviation to the original data, yielding a noisier but unbiased SGGX [S1].

### GPU-CPU Data Flow for SGGX-H
The current implementation requires moving data from GPU to CPU to use the original GPU-computed histogram for leaf nodes, which is necessary for aggregated SGGX distributions but incurs transfer costs [S1]. The histogram is generated using the SGGX itself on the CPU to build the SGGX-H representation [S1].

## Operating characteristics
**Time Complexity:** The method involves sampling $N$ points for each distribution, computing pairwise distances, and fitting new distributions. The distance matrix computation is $O(M^2)$ where $M$ is the number of distributions in the block. With $N=5000$ and 5 bins per dimension, the histogram operations are constant but expensive per distribution. The hierarchical merging reduces $M$ by 1 in each step, requiring $M_{initial} - M_{final}$ iterations.

**Memory Complexity:** Requires storing $N$ samples per distribution for histogram generation and the histograms themselves. The final storage is limited to 3 distributions per LoD block [S1].

**Measured Performance:** On the Helmet scene at 256x256 resolution, Hierarchical SGGX achieved lower FLIP errors than Naive SGGX at all LoD levels: Level 1 (64 res): 0.098 vs 0.100; Level 2 (32 res): 0.151 vs 0.163; Level 3 (16 res): 0.179 vs 0.201 [S1]. On the Scarf scene (approx 1024 res), Hierarchical SGGX achieved lower FLIP errors than Naive SGGX: Level 1 (approx 800 res): 0.0641 vs 0.0642; Level 2 (approx 400 res): 0.101 vs 0.103; Level 3 (approx 200 res): 0.202 vs 0.281 [S1].

**Strengths and Limitations:** The method consistently outperforms naive SGGX fitting across all LoD levels. The performance gap increases as resolution decreases, particularly on pixel-wise metrics, suggesting additional benefits when aggregating more orientations [S1]. However, the hierarchical distribution merging method requires re-fitting some SGGX distributions, which may reduce the accuracy of the orientation distribution for that node [S1]. Voxelizing complex fabrics can produce artifacts due to limited per-voxel accuracy with complex geometries in density data [S1].

## Background
Hierarchical SGGX Aggregation was introduced in the paper "Fast Voxelization and Level of Detail for Microgeometry Rendering" [S1]. It builds on the SGGX-based Downsampling method introduced by Heitz et al. [HDCD15] [S1]. The method draws inspiration from classical unsupervised learning algorithms in machine learning, specifically hierarchical clustering, to build a dendrogram of LoDs [S1].
