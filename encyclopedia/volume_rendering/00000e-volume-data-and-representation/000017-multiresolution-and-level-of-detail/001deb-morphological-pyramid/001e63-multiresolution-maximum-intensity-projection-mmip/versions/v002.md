# Multiresolution Maximum Intensity Projection (MMIP)

Also called: MIP Volume Rendering with Morphological Pyramids, Multiresolution MIP, Multiresolution MIP based on detail pyramid, Progressive refinement from detail pyramid, level-by-level MMIP

## Overview
Multiresolution Maximum Intensity Projection (MMIP) is a progressive rendering algorithm for 3-D volume data that computes the maximum value along lines through the data set [S1, S2]. It solves the problem of interactive rendering latency by using a morphological pyramid to provide coarse approximations during user interaction and progressively refining the image with detail coefficients once interaction ceases [S1]. Unlike linear pyramid-based MIP methods which rely on additive reconstruction, MMIP exploits the commutativity of the MIP operator with morphological dilation and upsampling, allowing the projection to be performed on coarse levels and expanded in 2-D, thereby avoiding expensive 3-D reconstruction for certain pyramid types [S1, S2].

## How it works
**Inputs:**
1. A detail pyramid sequence $d_0, d_1, \dots, d_{L-1}$ and the coarsest approximation $f_L$ of the input volume data set $f$ [S1].
2. A viewing orientation $\Theta$, defined by angles $\theta, \phi$ (projection direction perpendicular to the view plane) and $\alpha$ (orientation of the view plane) [S1].
3. A structuring element $A$ for the morphological operations [S1, S2].

**Outputs:**
A sequence of progressively refined 2-D approximation images $M_\Theta^{(j)}(f)$ for $j = L, L-1, \dots, 0$ [S1, S2].

**Data Structures:**
*   **Pyramid Levels:** The volume is decomposed into levels $j=0 \dots L$ [S1, S2]. Level $L$ is the coarsest approximation $f_L$ [S2]. Levels $0 \dots L-1$ contain detail signals $d_j$ [S1, S2].
*   **Storage:** For efficient voxel projection, 'interesting' voxels are sorted by grey value using a histogram-based scheme. This involves a value-sorted array of voxel positions and an additional array containing cumulative histogram values [S1].
*   **Structuring Element:** The 2-D expand operator uses a structuring element $\tilde{A}$, defined as the MIP of the original 3-D structuring element $A$: $\tilde{A} := M_\Theta(A)$ [S2].

**Definitions:**
*   **MIP Operator ($M_\Theta$):** Computes the maximum value along rays defined by $\Theta$ [S1, S2].
*   **Upsample ($\text{UPSAMPLE}$):** Increases resolution by a factor of 2 in each spatial dimension, inserting zeros at new positions [S1, S2].
*   **Dilation ($\delta_A$):** $\delta_A(f)(x) = \max_{a \in A} (f(x-a))$ [S1, S2].
*   **2-D Expand Operator ($\tilde{\psi}_A^\downarrow$):** $\tilde{\psi}_A^\downarrow(f) = \delta_{\tilde{A}}(\text{UPSAMPLE}(f))$ [S2].
*   **Generalized Subtraction (Adjunction only):** $t \dot{-} s = \begin{cases} t, & \text{if } t > s \\ 0, & \text{if } t = s \end{cases}$, where 0 is the smallest possible voxel value [S2].

**Algorithm Steps:**
1. **Pyramid Construction:** Recursively apply the REDUCE operator to compute approximations $f_j$ and detail signals $d_j$ until level $L$ is reached. The original volume data can be discarded after construction due to the perfect reconstruction property [S1].
    * For Adjunction Pyramids: $\Psi_A^\downarrow(f) = \text{DOWNSAMPLE}(\epsilon_A(f))$ and $d_j = f_j \dot{-} \Psi_A^\downarrow \Psi_A^\uparrow (f_j)$ [S2].
    * For Sun-Maragos Pyramids: $\Psi_A^\downarrow(f) = \text{DOWNSAMPLE}(\alpha_A(f))$ [S1].
2. **Coarsest Approximation:** Compute the MIP of the coarsest volume level $f_L$, then expand it to the full image resolution using the 2-D expand operator applied $L$ times:
    $$M_\Theta^{(L)}(f) = \tilde{\psi}_A^{\downarrow L}(M_\Theta(f_L))$$
    where $\tilde{\psi}_A^{\downarrow L}$ denotes $L$-fold composition of $\tilde{\psi}_A^\downarrow$ [S1, S2].
3. **Progressive Refinement:** Iterate from $j = L$ down to $1$ to refine the image:
    * **For Adjunction Pyramids (2D-only refinement):** Compute the next approximation by taking the maximum of the expanded MIP of the detail signal and the previous approximation:
        $$M_\Theta^{(j-1)}(f) = \tilde{\psi}_A^{\downarrow (j-1)}(M_\Theta(d_{j-1})) \vee M_\Theta^{(j)}(f)$$
        Since detail signals $d_j$ are non-negative, the projections increase pointwise: $M_\Theta^{(j-1)}(f) \ge M_\Theta^{(j)}(f)$ [S2].
    * **For Sun-Maragos Pyramids (3D reconstruction required):** Reconstruct the volume at level $j-1$ from level $j$ and the detail $d_{j-1}$, then project and expand:
        $$f_{j-1} = \psi_A^\uparrow(f_j) \dot{+} d_{j-1}$$
        $$M_\Theta^{(j-1)}(f) = \tilde{\psi}_A^{\downarrow (j-1)}(M_\Theta(f_{j-1}))$$
        This requires a 3-D dilation for reconstruction, which is less efficient for value-sorted arrays [S1].

**Pseudocode (Adjunction Pyramid Variant):**
```python
def mmip_adjunction(f_L, details, L, theta, structuring_element_A, img_h, img_w):
    """
    Perform Multiresolution MIP using an adjunction pyramid.
    Args:
        f_L: Coarsest approximation volume (level L).
        details: List of detail volumes [d_0, d_1, ..., d_{L-1}].
        L: Decomposition depth.
        theta: Viewing orientation parameters.
        structuring_element_A: 3D structuring element for morphological ops.
        img_h, img_w: Output image dimensions.
    Returns:
        List of 2D images [M_L, M_{L-1}, ..., M_0] representing progressive refinement.
    """
    # Precompute 2D structuring element for expansion: A_tilde = M_theta(A)
    structuring_element_A_2d = ray_cast_max(structuring_element_A, theta, img_h, img_w)

    # Step 1: Coarsest approximation
    # Project coarse volume f_L along theta
    mip_coarse = ray_cast_max(f_L, theta, img_h, img_w)
    # Expand L times to full resolution
    current_image = mip_coarse
    for _ in range(L):
        current_image = expand_2d(current_image, structuring_element_A_2d)

    results = [current_image]

    # Step 2: Progressive refinement from j=L down to 1
    # details[j-1] corresponds to d_{j-1}
    for j in range(L, 0, -1):
        detail_volume = details[j-1]

        # Project detail volume
        mip_detail = ray_cast_max(detail_volume, theta, img_h, img_w)

        # Expand (j-1) times
        expanded_detail = mip_detail
        for _ in range(j-1):
            expanded_detail = expand_2d(expanded_detail, structuring_element_A_2d)

        # Take maximum with previous approximation
        current_image = elementwise_max(current_image, expanded_detail)

        results.append(current_image)

    return results

def ray_cast_max(volume_3d, theta, img_h, img_w):
    """
    Compute the Maximum Intensity Projection along viewing direction theta.
    Traverses rays through the 3D volume and returns the maximum value per pixel.
    Standard ray-casting routine [G].
    """
    # Implementation: for each pixel (y, x) in the image plane,
    # trace the ray defined by theta through volume_3d,
    # sample voxel values, and store the maximum in result[y, x].
    result = [[0.0] * img_w for _ in range(img_h)]
    # (Detailed ray traversal omitted as it is a standard graphics primitive [G])
    return result

def expand_2d(image, structuring_element_2d):
    """
    Perform 2D expansion: Upsample by 2 in each dimension, then dilate.
    """
    upscaled = upsample_2d(image, factor=2)
    dilated = dilate_2d(upscaled, structuring_element_2d)
    return dilated

def upsample_2d(image, factor):
    """
    Upsample image by inserting zeros at new positions.
    """
    new_h, new_w = len(image) * factor, len(image[0]) * factor
    new_image = [[0.0] * new_w for _ in range(new_h)]
    for y in range(len(image)):
        for x in range(len(image[0])):
            new_image[y * factor][x * factor] = image[y][x]
    return new_image

def dilate_2d(image, structuring_element):
    """
    2D Morphological Dilation.
    """
    h, w = len(image), len(image[0])
    result = [[0.0] * w for _ in range(h)]
    for y in range(h):
        for x in range(w):
            max_val = 0.0
            for dy, dx in structuring_element:
                ny, nx = y + dy, x + dx
                if 0 <= ny < h and 0 <= nx < w:
                    max_val = max(max_val, image[ny][nx])
            result[y][x] = max_val
    return result

def elementwise_max(img1, img2):
    """Element-wise maximum of two 2D images."""
    return [[max(a, b) for a, b in zip(row1, row2)] for row1, row2 in zip(img1, img2)]
```

## Subtopics

### [Multiresolution MIP based on adjunction pyramid](1898-multiresolution-mip-based-on-adjunction-pyramid.md)
This method performs progressive Maximum Intensity Projection (MIP) volume rendering by refining the image directly in the 2D plane using an adjunction pyramid, avoiding 3D volume reconstruction. It leverages the commutativity of MIP and dilation to update the projection by taking the maximum of the expanded detail projection and the previous approximation. Unlike general detail pyramids that require 3D reconstruction, this variant exploits the specific properties of adjunction pyramids where detail signals are non-negative, allowing for simpler, purely 2D progressive refinement.

## Operating characteristics
*   **Time Complexity:** The complexity depends on the pyramid type [S1, S2]. For adjunction pyramids, the refinement is purely 2D, making it significantly faster as it avoids 3D reconstruction [S1, S2]. For Sun-Maragos pyramids, each refinement step requires a 3D dilation for reconstruction, which is computationally expensive, especially with value-sorted arrays [S1].
*   **Memory Complexity:** Requires storage for the pyramid levels ($f_L$ and $d_0 \dots d_{L-1}$) [S1]. The original volume can be discarded after pyramid construction [S1].
*   **Performance:** Interactive rendering is fast because only coarse levels are used during interaction [S1]. Progressive refinement adds detail incrementally [S1]. The adjunction variant is more efficient for streaming or interactive use due to the 2D-only update [S2].
*   **Strengths:** Perfect reconstruction capability; compatibility with MIP due to commutativity of dilation/upsampling with maximum; reduced data size for interaction; integer computations only (for flat pyramids) [S1].
*   **Limitations:** Image quality is lower in preview mode due to loss of detail; Sun-Maragos variant is inefficient for certain data structures due to 3D reconstruction requirements [S1].
*   **When to use:** Interactive visualization of large volumetric datasets (e.g., MRA, ultrasound) where user interaction speed is critical and progressive detail addition is acceptable [S1].
*   **When not to use:** When high-fidelity static rendering is required without progressive refinement, or when the overhead of 3D reconstruction for Sun-Maragos pyramids is prohibitive [S1].

## Background
MMIP was introduced in the context of multiresolution algorithms for Maximum Intensity Projection volume rendering, widely used in magnetic resonance angiography (MRA) and ultrasound data display [S1]. The method builds on the properties of morphological pyramids, specifically the commutativity of morphological operators with the MIP operator [S1]. The adjunction pyramid variant was detailed in works by Roe et al. [S2], while the Sun-Maragos pyramid variant was formally defined and analyzed in comparison studies [S1]. The approach addresses the major problem of data size in interactive rendering by allowing coarse previews and progressive refinement [S1].
