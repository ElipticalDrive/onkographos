# Haar Wavelet Transform

Also called: 1D Haar wavelet, 2D Haar wavelet, 3D Haar wavelet, Haar Wavelet Transformation for Multi-resolution Volumetric Data

## Overview
The Haar Wavelet Transform is a method for generating multi-resolution (MR) data models by applying low-pass and high-pass filters to discrete data, yielding summary (approximation) and detail coefficients [S1]. It decomposes the signal into a family of functions, which are the translation and dilation of unique $\psi(x)$ [Parent]. Unlike the nearest alternative, the Discrete Wavelet Transform (DWT) which uses arbitrary mother wavelets, the Haar transform uses the simplest step-function wavelet, making it computationally trivial but less smooth [S1]. It is primarily used to create hierarchical representations of volumetric or grid-based data for efficient storage and rendering [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A discrete data set of values. For 1D, a vector of size $s$. For 2D, a matrix of size $m \times n$. For 3D, a tensor of size $m \times n \times l$.
*   **Output:** A set of approximation coefficients (summary) and detail coefficients.
    *   1D: $s/2$ summary coefficients, $s/2$ detail coefficients.
    *   2D: $(m/2 \times n/2)$ summary coefficients, 3 quadrants of detail data.
    *   3D: $(m/2 \times n/2 \times l/2)$ summary coefficients, 7 octants of detail coefficients.

**Data Structures:**
The output is typically stored as a hierarchy of arrays. The approximation coefficients form the next level of the hierarchy. The detail coefficients are stored separately, often organized by orientation (e.g., horizontal, vertical, diagonal for 2D; and their 3D equivalents).

**Algorithm Steps:**
The transform is applied iteratively to obtain the MR hierarchy [S1].

1.  **1D Transform:**
    For a 1D data set with $s$ values, apply the 1D Haar wavelet. The data is paired into adjacent elements $(x_{2i}, x_{2i+1})$.
    *   Summary coefficient $A_i = \frac{x_{2i} + x_{2i+1}}{2}$
    *   Detail coefficient $D_i = \frac{x_{2i} - x_{2i+1}}{2}$
    This yields $s/2$ summary and $s/2$ detail coefficients [S1].

2.  **2D Transform:**
    For a 2D data set with $m \times n$ values:
    *   Apply the 1D Haar transform along each row. This produces row-wise summary and detail coefficients.
    *   Apply the 1D Haar transform along each column of the resulting data.
    *   This results in a summary block of size $m/2 \times n/2$ and 3 quadrants of detail data [S1]. The quadrants typically correspond to horizontal, vertical, and diagonal details.

3.  **3D Transform:**
    For a 3D data set with $m \times n \times l$ values:
    *   Apply the 1D Haar transform along each row (x-axis).
    *   Apply the 1D Haar transform along each column (y-axis).
    *   Apply the 1D Haar transform along each slice (z-axis).
    *   This results in a summary block of size $m/2 \times n/2 \times l/2$ and 7 octants of various detail coefficients [S1].

4.  **Multi-resolution Hierarchy:**
    To obtain the full MR hierarchy, multiple passes of the Haar wavelet transformation are applied iteratively on the summary coefficients from the previous pass [S1]. For example, in a 2D $8 \times 8$ dataset, one pass yields a $4 \times 4$ approximation, and a second pass yields a $2 \times 2$ approximation [S1].

def haar_1d(data):
    """
    Applies 1D Haar wavelet transform to a list of numbers.
    Returns (approximations, details).
    """
    n = len(data)
    if n % 2 != 0:
        # Pad with zero if odd length, though standard Haar assumes even
        data = data + [0]
        n += 1
    
    approx = []
    details = []
    
    for i in range(0, n, 2):
        x1 = data[i]
        x2 = data[i+1]
        # Summary (Low-pass)
        approx.append((x1 + x2) / 2.0)
        # Detail (High-pass)
        details.append((x1 - x2) / 2.0)
        
    return approx, details

*   **Number of passes:** Determines the depth of the multi-resolution hierarchy. Typically 1-3 passes for visualization [S1].

## Subtopics

### Haar Wavelet Denoiser
A variant where the Haar wavelet decomposition is used for noise removal. The approximation coefficients represent low-frequency information, while detail coefficients capture high-frequency features (noise) [S2, unofficial]. Thresholding is applied to eliminate detail coefficients below a certain value, preserving significant image details while removing noise. Reconstruction is performed by inverting the wavelet transform [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ for a single pass, where $N$ is the number of data points. Each pass reduces the data size by half (in each dimension), so subsequent passes are faster.
*   **Memory Complexity:** $O(N)$ to store the original and all detail coefficients. The approximation coefficients are a subset of the original size.
*   **Performance:** The Haar transform is one of the simplest wavelet-based algorithms, making it computationally very efficient [S1].
*   **Strengths:** Simplicity, speed, and effective generation of multi-resolution hierarchies for regular grids [S1].
*   **Limitations:** The step-function nature of the Haar wavelet leads to blocky artifacts in the reconstructed signal compared to smoother wavelets (e.g., Daubechies). It is less suitable for data requiring smooth transitions.
*   **When to use:** When computational efficiency is critical and the data is regular (e.g., medical grids) [S1]. When a coarse multi-resolution hierarchy is needed for visualization or uncertainty visualization [S1].
*   **When not to use:** When smoothness is required or when the data has complex high-frequency structures that the Haar wavelet cannot capture well.

## Background
The Haar wavelet transform is one of the earliest wavelet transforms, developed by Alfred Haar in 1910. It is defined by Monet Morlet [Parent] to avoid the fixed resolution limit of windowed Fourier transforms. It decomposes the signal into a family of functions, which are the translation and dilation of unique $\psi(x)$ [Parent]. In the context of volume rendering, it has been used to visualize uncertainty in multi-resolution volumetric data using marching cubes [S1].
