# Coarsening Compression

Also called: Wavelet pruning

## Overview
Coarsening compression is a lossy compression step that prunes small wavelet detail coefficients to reduce the number of leaf nodes in a hierarchical omnitree, while preserving the integral of the represented function [S1, unofficial]. It differs from sibling methods like [Downsplit](3404-downsplit.md) by operating directly on coefficient magnitudes to merge nodes, whereas downsplit restructures the tree topology to expose new coarsening opportunities [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A hierarchized omnitree with wavelet coefficients $w_\tau^v$ associated with each node $v$ and dimension subset $\tau \subseteq \sigma(v)$, and an error density threshold $\varepsilon \ge 0$ [S1, unofficial].
*   **Output:** A modified omnitree with fewer leaf nodes and a corresponding set of wavelet coefficients [S1, unofficial].

**Data Structures:**
The omnitree consists of nodes $v$. Each node $v$ has:
*   $\sigma(v)$: The set of active dimensions at node $v$.
*   $\text{rect}(v)$: The spatial bounding box (hyperrectangle) of node $v$.
*   $w_\tau^v$: Wavelet coefficients for each non-empty subset $\tau \subseteq \sigma(v)$.
*   Children: A list of child nodes.

**Steps:**
1.  **Identify Candidate Nodes:** Iterate through the tree bottom-up, starting from the parents of leaves (last-level parents) [S1, unofficial]. Identify nodes $v$ where all children are leaves [S1, unofficial].
2.  **Check Coefficient Bounds:** For a candidate node $v$, determine the set of dimensions $C \subseteq \sigma(v)$ in which the node can be coarsened [S1, unofficial]. A dimension $j$ is included in $C$ if all detail coefficients $w_\tau^v$ where $\tau \cap \{j\} \neq \emptyset$ satisfy the bound:
    $$ |w_\tau^v| \leq \varepsilon \quad \forall \tau \cap C \neq \emptyset \quad (16) $$
    [S1, unofficial]
3.  **Perform Coarsening:** If all detail coefficients satisfy the criterion, set $C = \sigma(v)$ and fully coarsen the node into a leaf [S1, unofficial]. Otherwise, perform partial coarsening for individual dimensions $j$ where the bound is met [S1, unofficial]. The detail coefficients $w_\tau^v$ with $\tau \cap C \neq \emptyset$ are pruned (set to zero) [S1, unofficial]. The remaining coefficients become the coefficient vector of the coarsened node $v'$ with $\sigma(v') = \sigma(v) \setminus C$ [S1, unofficial]. Coarsening preserves the integral of the function because the discarded wavelet functions have an integral of exactly zero due to orthogonality against constant functions [S1, unofficial].
4.  **Iterate:** Apply coarsening bottom-up from last-level parents and repeat until no further coarsening passes are possible [S1, unofficial].

**Error Bound:**
The total error incurred by all coarsening passes is bounded by a function of the threshold $\varepsilon$, domain volume, dimension $d$, and source tree height $\ell$:
$$ \|\tilde{f} - f\|_1 \leq \sum_{v \text{ nonleaf}} (2^{|\sigma(v)|} - 1) \cdot \varepsilon |\text{rect}(v)| \leq (2^d - 1) \cdot \varepsilon |\Omega| \cdot \ell \quad (17) $$
[S1, unofficial]

**Pseudocode:**
```python
def coarsen_omnitree(root, epsilon):
    """
    Performs coarsening compression on an omnitree.
    root: The root node of the omnitree.
    epsilon: Error density threshold.
    """
    # Helper to check if a node is a leaf
    def is_leaf(node):
        return node.is_leaf

    # Helper to collect leaf parents in bottom-up order
    # The sources do not specify the exact traversal algorithm, 
    # so a standard post-order traversal is used here [G].
    def get_leaf_parents(node):
        parents = []
        if node.is_leaf:
            return parents
        children_are_leaves = all(is_leaf(c) for c in node.children)
        if children_are_leaves:
            parents.append(node)
        else:
            for child in node.children:
                parents.extend(get_leaf_parents(child))
        return parents

    changed = True
    while changed:
        changed = False
        nodes_to_process = get_leaf_parents(root)
        for v in nodes_to_process:
            # Step 1: Identify nodes whose children are all leaves
            if not all(is_leaf(child) for child in v.children):
                continue
            
            # Step 2: Determine dimensions C that can be coarsened
            C = []
            for dim in v.sigma:
                can_coarsen_dim = True
                for tau in v.coefficients.keys():
                    if dim in tau:
                        if abs(v.coefficients[tau]) > epsilon:
                            can_coarsen_dim = False
                            break
                if can_coarsen_dim:
                    C.append(dim)
            
            if not C:
                continue
            
            # Step 3: Prune coefficients associated with dimensions in C
            coeffs_to_remove = [tau for tau in v.coefficients.keys() if any(dim in tau for dim in C)]
            for tau in coeffs_to_remove:
                del v.coefficients[tau]
            
            # Update sigma for the coarsened node v'
            v.sigma = [dim for dim in v.sigma if dim not in C]
            
            # If sigma is empty, the node becomes a leaf
            if not v.sigma:
                v.is_leaf = True
                v.children = []
            
            changed = True

    return root
```

**Parameters:**
*   $\varepsilon$: Error density threshold [S1, unofficial]. If $\varepsilon = 0$, only nodes with exactly zero detail coefficients are coarsened, yielding lossless compression [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Overestimation of Error:** The a priori bound (Eq. 17) greatly overestimates the actual L1 error when $\varepsilon > 0$ [S1, unofficial]. A tighter a posteriori estimate should be obtained by aggregating coefficient magnitudes from nodes actually selected for coarsening [S1, unofficial].
*   **Heuristic Scope:** In practice, focusing only on parents and grandparents of leaves can yield significant savings, but may not exploit all redundancy [S1, unofficial].

## Subtopics

### Downsplit-Coarsening Loop
An iterative compression strategy that alternates between downsplitting to expose redundancy and coarsening to prune coefficients [S1, unofficial]. After plain coarsening converges, the algorithm enters the loop: 1. Downsplit. For each multi-dimensional node $v$ ($|\sigma(v)| \ge 2$) with at least two leaf children, select dimension $j^* \in \sigma(v)$ whose pure one-dimensional detail coefficient has the smallest magnitude: $j^* = \arg \min_{j \in \sigma(v)} |w_{T_j}^v|$ [S1, unofficial]. Downsplit the single dimension $\{j^*\}$ and update all coefficients using the standard transformation equations [S1, unofficial]. 2. Coarsen. Apply the coarsening criterion (Eq. 16) to all nodes whose children are all leaves [S1, unofficial]. 3. Normalize. Resolve any uniqueness violations introduced by the combination of downsplit and coarsening, restoring a canonical omnitree [S1, unofficial]. Repeat steps 1-3 until no coarsenings occur in a round [S1, unofficial]. The dimension selection heuristic assumes the dominance of first-order effects, so that when $w_{v}^{\tau_j}$ is near zero, all intermediates along $j$ will have negligible detail [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1, unofficial].
*   **Memory Complexity:** Not given in the sources [S1, unofficial].
*   **Strengths:** Preserves the integral of the function exactly [S1, unofficial]. Can be combined with [Downsplit](3404-downsplit.md) to expose more redundancy [S1, unofficial].
*   **Limitations:** The a priori error bound is loose [S1, unofficial]. May not exploit all redundancy if used alone [S1, unofficial].

## Background
Coarsening compression is part of the wavelet-based volume rendering compression strategy on omnitrees, introduced in the paper "Towards Fully Dynamic Omnitrees: Moment-Conserving Anisotropic Compression With Wavelets" [S1, unofficial]. It operates in the wavelet domain, allowing reconstruction of nodal function values only at the end for output file writing and error evaluation [S1, unofficial].
