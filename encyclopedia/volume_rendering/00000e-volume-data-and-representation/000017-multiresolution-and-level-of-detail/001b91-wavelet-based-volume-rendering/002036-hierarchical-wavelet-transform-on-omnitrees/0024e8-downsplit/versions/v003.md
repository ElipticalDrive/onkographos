# Downsplit

Also called: Dimensional downsplit, inverse normalization, split rotation

## Overview
Downsplit is a tree restructuring operation in hierarchical wavelet-based volume compression that factors a multi-dimensional split into a cascade of lower-dimensional splits [S1, unofficial]. It restructures an omnitree without modifying the set of leaf boxes, serving as the inverse to normalization [S1, unofficial]. By moving parent refinements down to children, it exposes new coarsening opportunities that multi-dimensional splits would otherwise obscure, enabling more efficient pruning of wavelet coefficients [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** An internal node $v$ of an omnitree $T$ with splitting label $\vec{b}(v)$ and dimension set $\sigma(v)$ where $|\sigma(v)| \ge 2$ [S1, unofficial]. The node has children $u_k$ for $k \in \{0, 1\}^{\sigma(v)}$ [S1, unofficial].
*   **Output:** A target tree $T'$ containing a new two-level structure replacing $v$, and a mapping $M$ from initial to target tree nodes [S1, unofficial].

**Data Structures:**
*   **Splitting Label $\sigma(v)$:** A set of dimensions along which node $v$ is refined [S1, unofficial].
*   **Split Dimensions:** Two disjoint subsets $S_1 \subset \sigma(v)$ and $S_2 = \sigma(v) \setminus S_1$, where $\emptyset \neq S_1 \neq \sigma(v)$ [S1, unofficial]. $S_1$ are the dimensions to be "split down" (moved to children), and $S_2$ are the dimensions to be retained at the parent level [S1, unofficial].
*   **Nodalization Matrix $R_{|S_2|}$:** A matrix used to redistribute wavelet coefficients [S1, unofficial]. It is a Kronecker product over the dimensions in $S_2$ [S1, unofficial]. Rows are indexed by the children of the new residual node $v'$ in Z-order; columns are indexed by the power set $2^{S_2}$ [S1, unofficial].

**Numbered Steps:**
1.  **Select Split Dimensions:** Choose a non-empty proper subset $S_1 \subset \sigma(v)$ and define $S_2 = \sigma(v) \setminus S_1$ [S1, unofficial].
2.  **Create Residual Node:** Create a new node $v'$ in the target tree $T'$ at the same spatial location as $v$ [S1, unofficial]. Set its splitting label $\sigma(v') = S_2$ [S1, unofficial]. Consequently, $v'$ has $2^{|S_2|}$ children [S1, unofficial].
3.  **Create Intermediate Children:** For each child index $r \in \{0, 1\}^{S_2}$, create a new intermediate child node $u_r$ of $v'$ [S1, unofficial]. Set its splitting label $\sigma(u_r) = S_1$ [S1, unofficial]. Consequently, each $u_r$ has $2^{|S_1|}$ children [S1, unofficial].
4.  **Link Original Children:** The children of $u_r$ are exactly the original children $u_k$ of $v$ whose $S_2$-coordinates equal $r$ [S1, unofficial]. This preserves the spatial position of all leaves [S1, unofficial].
5.  **Redistribute Wavelet Coefficients:** The wavelet coefficients $w^v_\tau$ associated with node $v$ are redistributed to $v'$ and $\{u_r\}$ as follows [S1, unofficial]:
    *   **Residual Coefficients:** Coefficients associated purely with $S_2$ are transferred directly to $v'$:
        $$ w^{v'}_{\tau_2} = w^v_{\tau_2}, \quad \emptyset \neq \tau_2 \subset S_2 $$
    *   **Intermediate Coefficients:** Coefficients involving $S_1$ are redistributed to the intermediate children using the nodalization matrix $R_{|S_2|}$:
        $$ w^{\{u_r\}}_{\tau_1} = \sum_{\tau_2 \subset S_2} (R_{|S_2|})_{\tau_2}^{\{r\}} \cdot w^v_{\tau_2 \sqcup \tau_1}, \quad \emptyset \neq \tau_1 \subset S_1 $$
        Here, $\tau_1 \subset S_1$ and $\tau_2 \subset S_2$ [S1, unofficial]. The term $w^v_{\tau_2 \sqcup \tau_1}$ refers to the source coefficient with indices from both sets [S1, unofficial].
6.  **Construct Mapping:** If $v$ has index $i$, $v'$ has index $i'$, and $u_r$ has index $i_r$, the mapping entry $M[i]$ consists of the union of $\{i\}$ and all $\{i_r\}$ [S1, unofficial].

**Pseudocode:**
```python
import itertools

def kronecker_product(A, B):
    """Computes the Kronecker product of two matrices."""
    return [[a * b for b in row_b] for row_a in A for row_b in B]

def downsplit(node_v, split_dims_S1):
    """
    Performs a downsplit on node v.
    
    Args:
        node_v: The internal node to split.
        split_dims_S1: A set of dimensions to move to children (S1).
        
    Returns:
        node_v_prime: The new residual parent node.
        intermediate_children: A list of new intermediate child nodes.
        mapping_update: Dictionary mapping old index to new indices.
    """
    sigma_v = node_v.splitting_label
    S1 = split_dims_S1
    S2 = sigma_v - S1
    k1 = len(S1)
    k2 = len(S2)

    # 1. Create residual node v' with S2 splits
    node_v_prime = Node(location=node_v.location, splitting_label=S2)

    # 2. Create intermediate children u_r for each combination of S2 coordinates
    intermediate_children = []
    mapping_update = {node_v.index: [node_v_prime.index]}

    # Precompute S2 coordinate extraction mapping
    s2_dims = sorted(S2)
    s2_dim_indices = {d: i for i, d in enumerate(s2_dims)}

    for r in itertools.product([0, 1], repeat=k2):
        u_r = Node(location=node_v.location, splitting_label=S1)
        intermediate_children.append(u_r)

        # Reassign original children u_k to u_r based on S2 coordinates
        for k in itertools.product([0, 1], repeat=len(sigma_v)):
            k_S2 = 0
            for idx, dim in enumerate(sigma_v):
                if dim in S2:
                    k_S2 |= (k[idx] << s2_dim_indices[dim])
            if k_S2 == r:
                u_k = node_v.children[k]
                u_r.add_child(u_k)

        mapping_update[node_v.index].append(u_r.index)

    # 3. Redistribute wavelet coefficients
    # Generate non-empty subsets of S2 and S1
    subsets_S2 = list(itertools.chain.from_iterable(itertools.combinations(S2, r_len) for r_len in range(1, len(S2) + 1)))
    subsets_S1 = list(itertools.chain.from_iterable(itertools.combinations(S1, r_len) for r_len in range(1, len(S1) + 1)))

    # Transfer pure S2 coefficients to v'
    for tau_2 in subsets_S2:
        node_v_prime.coefficients[tau_2] = node_v.coefficients[tau_2]

    # Construct Nodalization Matrix R_|S2| as Kronecker product over S2 dimensions
    # Rows indexed by r in Z-order, columns by tau_2 subsets of S2
    tau2_to_col = {tau2: i for i, tau2 in enumerate(subsets_S2)}
    r_to_row = {r: i for i, r in enumerate(itertools.product([0, 1], repeat=k2))}

    # Base 1D nodalization matrix (standard Haar-like basis)
    base_matrix = [[1.0, 1.0], [1.0, -1.0]]
    R_current = [[1.0]]
    for _ in range(k2):
        R_current = kronecker_product(R_current, base_matrix)

    R = [[0.0] * (2**k2) for _ in range(2**k2)]
    for r in itertools.product([0, 1], repeat=k2):
        row_idx = r_to_row[r]
        for tau_2 in subsets_S2:
            col_idx = tau2_to_col[tau_2]
            R[row_idx][col_idx] = R_current[row_idx][col_idx]

    # Apply redistribution formula
    for tau_1 in subsets_S1:
        for r in itertools.product([0, 1], repeat=k2):
            row_idx = r_to_row[r]
            coeff_sum = 0.0
            for tau_2 in subsets_S2:
                col_idx = tau2_to_col[tau_2]
                source_tau = tuple(sorted(list(tau_2) + list(tau_1)))
                coeff_sum += R[row_idx][col_idx] * node_v.coefficients[source_tau]
            intermediate_children[row_idx].coefficients[tau_1] = coeff_sum

    # Apply identical inverse Haar butterflies to all child sets [S1, unofficial]
    # Implementation details for the butterfly step are not provided in the sources [G]
    for u_r in intermediate_children:
        apply_inverse_haar_butterfly(u_r.coefficients, S1)

    return node_v_prime, intermediate_children, mapping_update
```

**Parameters and Edge Cases:**
*   **Scaling Coefficients:** The scaling coefficients $w_\emptyset$ are entirely omitted from these computations [S1, unofficial].
*   **Leaf Constraints:** The children of $v'$ (the $u_r$ nodes) are not necessarily leaves [S1, unofficial]. Removing all splits cannot occur in a downsplit [S1, unofficial].
*   **Canonical Omnitrees:** Technically, if the omnitree is not canonical, refinements might need to be swept down the tree if they cannot be realized at the original node, though this is a secondary concern [S1, unofficial].
*   **Implementation:** Can be implemented by reusing the refinement algorithm from [29] and group resolution from Section 3.2 of the source [S1, unofficial].

## Operating characteristics
*   **Complexity:** The downsplit decouples $2^k - 1$ source coefficients into one parent set of size $2^{k_2} - 1$ and $2^{k_2}$ child sets of size $2^{k_1} - 1$, where $k_1 = |S_1|$ and $k_2 = |S_2|$ [S1, unofficial]. It applies identical inverse Haar butterflies to all child sets [S1, unofficial].
*   **Performance:** The operation preserves the function and leaf rectangles, changing only the basis used for coefficients [S1, unofficial]. Its primary benefit is exposing coarsening opportunities, which reduces the total number of coefficients stored [S1, unofficial].
*   **Limitations:** Selecting the optimal omnitree discretization is computationally infeasible at fine resolutions in 3D; heuristics focusing on parents and grandparents of leaves are used instead [S1, unofficial].

## Background
Downsplit is part of the "Towards Fully Dynamic Omnitrees" framework for moment-conserving anisotropic compression with wavelets [S1, unofficial]. It is defined as the inverse to normalization, where normalization absorbs a common child refinement into the parent, and downsplit moves a parent refinement down to the children [S1, unofficial]. The method relies on the nodalization matrix and Kronecker products to handle multi-dimensional wavelet spaces [S1, unofficial].
