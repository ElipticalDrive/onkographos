# Vertex Clustering Simplification

Also called: Vertex Clustering

## Overview
Vertex Clustering is a technique for precomputing static levels of detail (LOD) for large datasets, primarily used in out-of-core visualization systems where memory constraints necessitate simplified representations [S1, unofficial]. It differs from error-driven edge-collapse methods by using a fixed spatial grid to merge vertices [G]. It is particularly effective for creating multiresolution representations of isosurfaces [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangular mesh $M = (V, F)$, where $V$ is the vertex set and $F$ is the face set, and a grid resolution parameter $R$ (cells per axis) or cell size $\Delta$ [G].
*   **Output:** A simplified mesh $M' = (V', F')$ with reduced vertex count [G].

**Data Structures:**
1.  **Grid:** A hash map or 3D array mapping grid coordinates $(i, j, k)$ to a single representative vertex [G].
2.  **Vertex Map:** A lookup structure storing the correspondence between original vertices and their new representatives for face reconstruction [G].

**Steps:**
1.  **Compute Bounding Box:** Determine the axis-aligned bounding box (AABB) of $M$, yielding $\mathbf{b}_{\min}$ and $\mathbf{b}_{\max}$ [G].
2.  **Initialize Grid:** Create a grid structure with resolution $R$ [G].
3.  **Assign Vertices to Cells:** For each vertex $\mathbf{v} \in V$:
    *   Compute grid coordinates:
        $$ i = \left\lfloor \frac{v_x - b_{\min,x}}{b_{\max,x} - b_{\min,x}} \cdot R \right\rfloor, \quad j = \left\lfloor \frac{v_y - b_{\min,y}}{b_{\max,y} - b_{\min,y}} \cdot R \right\rfloor, \quad k = \left\lfloor \frac{v_z - b_{\min,z}}{b_{\max,z} - b_{\min,z}} \cdot R \right\rfloor $$
    *   Clamp $i, j, k$ to $[0, R-1]$ to handle boundary vertices [G].
    *   If cell $(i, j, k)$ is empty, store $\mathbf{v}$ as the representative; otherwise, retain the existing representative (standard implementations keep the first encountered vertex to avoid averaging artifacts) [G].
4.  **Reconstruct Faces:** For each face $(v_1, v_2, v_3) \in F$:
    *   Map each vertex to its representative using the grid [G].
    *   If the three representatives are distinct, add the new face to $F'$; otherwise, discard the degenerate face [G].
5.  **Remove Duplicates:** Deduplicate $F'$ to remove identical triangles [G].

**Parameters:**
*   **Grid Resolution ($R$):** Controls the level of detail. Higher $R$ yields higher fidelity. Typical values depend on dataset size and target memory budget [G].

**Edge Cases and Pitfalls:**
*   **Boundary Precision:** Vertices exactly on grid boundaries require consistent clamping or floor/ceil logic to avoid gaps or overlaps [G].
*   **Topology Preservation:** Standard vertex clustering may merge distinct topological components; topology-preserving variants address this [S2, unofficial].
*   **Degenerate Faces:** Excessively coarse grids cause widespread face collapse, leading to holes or missing geometry [G].

```python
def vertex_clustering(mesh, R):
    V, F = mesh.vertices, mesh.faces
    b_min, b_max = compute_aabb(V)  # [G]
    cell_size = (b_max - b_min) / R
    grid = {}  # [G] Maps (i,j,k) -> vertex
    for v in V:
        i = int((v.x - b_min.x) / cell_size.x)
        j = int((v.y - b_min.y) / cell_size.y)
        k = int((v.z - b_min.z) / cell_size.z)
        i, j, k = clamp(i, 0, R-1), clamp(j, 0, R-1), clamp(k, 0, R-1)  # [G]
        if (i, j, k) not in grid:
            grid[(i, j, k)] = v  # [G] Retains first vertex
    V_new = list(grid.values())
    F_new = []
    for f in F:
        v1, v2, v3 = f.vertices
        r1 = grid[compute_cell(v1, b_min, cell_size, R)]
        r2 = grid[compute_cell(v2, b_min, cell_size, R)]
        r3 = grid[compute_cell(v3, b_min, cell_size, R)]
        if r1 != r2 and r2 != r3 and r1 != r3:
            F_new.append((r1, r2, r3))  # [G] Discards degenerate faces
    return Mesh(V_new, F_new)
```

## Subtopics

### Selective Clustering
A topology-preserving vertex clustering algorithm used for creating a multiresolution ICM representation [S2, unofficial]. It specifically handles up to four intersection points on a cell edge to preserve disconnected surface components during simplification [S2, unofficial]. It is chosen when maintaining the topological integrity of isosurfaces is critical [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ for vertex-to-cell assignment and $O(F)$ for face reconstruction, where $N$ and $F$ are the vertex and face counts [G].
*   **Memory Complexity:** $O(R^3)$ for the grid structure, which can be mitigated with sparse implementations [G].
*   **Strengths:** Suitable for out-of-core processing of large datasets with limited memory [S1, unofficial]. Deterministic spatial partitioning avoids complex priority queues [G].
*   **Limitations:** Standard implementation may alter topology by merging distinct components; quality depends heavily on grid resolution [S2, unofficial][G].
*   **When to use:** Precomputing static LODs for large datasets where memory is limited [S1, unofficial].
*   **When not to use:** When dynamic, error-driven simplification is required [G].

## Background
Vertex Clustering was introduced by Rossignac and Borrel as a method for precomputing static levels of detail [S1, unofficial]. It has been adopted in out-of-core visualization systems to manage memory constraints for large datasets [S1, unofficial]. Variants like Selective Clustering have been developed to preserve topology in isosurface rendering contexts [S2, unofficial].
