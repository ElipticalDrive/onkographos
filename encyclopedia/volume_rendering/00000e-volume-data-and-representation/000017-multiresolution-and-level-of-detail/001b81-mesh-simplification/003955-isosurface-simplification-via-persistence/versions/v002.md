# Isosurface Simplification via Persistence

Also called: Simplification using isovalue range persistence

## Overview
Isosurface Simplification via Persistence is a mesh simplification technique for topological objects modeled as meshes, used for noise removal and feature selection in volume visualization [S1, unofficial]. It addresses the problem of identifying and removing insignificant topological features based on their persistence [S1, unofficial]. It sets itself apart from raw histogram analysis by incorporating geometric metrics (area, volume) and topological persistence to provide a truer distribution of the scalar field [S1, unofficial].

## How it works
**Inputs:** A triangular mesh representing topological features of the data, typically derived from a contour tree or Reeb graph [S1, unofficial].
**Outputs:** A simplified mesh with insignificant features removed [S1, unofficial].

**Data Structures:**
The method operates on the superarcs of a contour tree or Reeb graph [S1, unofficial]. Each superarc is defined by two critical vertices: a Top Critical Vertex and a Bottom Critical Vertex [S1, unofficial].

**Parameters:**
- **Terminating level of simplification:** A user-defined threshold that determines when the iterative removal process stops [S1, unofficial]. No specific numerical value is given; it depends on domain knowledge [S1, unofficial].

**Steps:**
1. Compute topological objects (e.g., from contour spectrum) [S1, unofficial].
2. Calculate a persistence measure for each object [S1, unofficial]. The persistence is defined as the isovalue range:
   $$ \text{Persistence} = | \text{Isovalue}(\text{Top Critical Vertex}) - \text{Isovalue}(\text{Bottom Critical Vertex}) | $$
   Where 'Top Critical Vertex' and 'Bottom Critical Vertex' are the two critical vertices defining the superarc in the contour tree [S1, unofficial].
3. Queue objects in ascending order of the selected measure (persistence) [S1, unofficial].
4. Iteratively remove the object with the lowest measure [S1, unofficial].
5. Stop when a terminating level of simplification is achieved [S1, unofficial].

**Pseudocode:**
```python
def isosurface_simplification_via_persistence(mesh, contour_tree, termination_threshold):
    """
    Simplifies a mesh by removing topological features based on persistence.
    
    Args:
        mesh: The triangular mesh representing the isosurface.
        contour_tree: The contour tree or Reeb graph structure containing superarcs.
        termination_threshold: The user-defined threshold for stopping simplification.
        
    Returns:
        The simplified mesh.
    """
    # Step 1: Compute topological objects (already in contour_tree)
    superarcs = contour_tree.get_superarcs()
    
    # Step 2: Calculate persistence for each superarc
    for superarc in superarcs:
        top_vertex = superarc.top_critical_vertex
        bottom_vertex = superarc.bottom_critical_vertex
        top_isovalue = top_vertex.isovalue
        bottom_isovalue = bottom_vertex.isovalue
        superarc.persistence = abs(top_isovalue - bottom_isovalue)
        
    # Step 3: Queue objects in ascending order of persistence
    sorted_superarcs = sorted(superarcs, key=lambda s: s.persistence)
    
    # Step 4 & 5: Iteratively remove lowest persistence objects until threshold is met
    # Note: The exact mesh modification operation (e.g., edge collapse, vertex merging) 
    # corresponding to "removing the object" is not specified in the sources [G].
    # The implementation must define how a superarc's removal affects the mesh topology.
    
    for superarc in sorted_superarcs:
        if superarc.persistence >= termination_threshold:
            break
            
        # Remove the topological feature associated with this superarc from the mesh
        remove_feature_from_mesh(mesh, superarc)
        
    return mesh
```

**Edge Cases and Pitfalls:**
- Simplification is sensitive to the source data [S1, unofficial]. Using isovalue range persistence can incorrectly remove important features (e.g., eyes in skull X-ray data) [S1, unofficial]. Domain-specific knowledge is required to choose the correct simplification technique [S1, unofficial].
- For time-varying data, connectivity between time steps must be considered during simplification, requiring additional considerations beyond static simplification [S1, unofficial].

## Subtopics

### [Topological Persistence and Simplification](9310-topological-persistence-and-simplification.md)
Topological Persistence and Simplification, commonly known as the Contour Spectrum, is a method for extracting quantitative information about individual contours in scalar data, specifically surface area and enclosed volume. It addresses the problem of identifying "salient" isovalues for extracting main structures and removing noise by performing connected-component topological analysis. It sets itself apart from raw histogram analysis by incorporating geometric metrics (area, volume) and topological persistence to provide a truer distribution of the scalar field.

### [Topology Simplification via Volumetric Modification](9327-topology-simplification-via-volumetric-modification.md)
This method removes extraneous topological handles from isosurfaces extracted from volumetric data (e.g., CT, MRI) by modifying the scalar volume values rather than performing mesh surgery, ensuring the resulting isosurface remains a manifold. It addresses the problem of identifying and removing insignificant topological features based on their persistence, specifically targeting handles with small geometric sizes. It builds on [Isosurface Simplification via Persistence](8470-isosurface-simplification-via-persistence.md) by providing a specific algorithmic strategy for the volumetric modification step using loop closure and Reeb graph analysis. Unlike mesh-based approaches that perform surgery on extracted meshes, this method operates directly on the volume representation, allowing for out-of-core execution and preserving the manifold property of the final isosurface.
