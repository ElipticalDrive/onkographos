# Simple Point Detection via Euler Characteristic

Also called: Euler Characteristic-based Simple Point Detection, Euler-based thinning criterion, Lobregt et al. approach, Lobregt simple point test, Tsao & Fu method

## Overview
Simple Point Detection via Euler Characteristic identifies boundary voxels that can be safely deleted during 3-D thinning by verifying that their removal preserves the local Euler characteristic of the neighborhood [S1, unofficial]. It distinguishes itself from persistence-based simplification by relying on a topological invariant rather than a critical point measure, and from pure connectivity tests by explicitly constructing an analogous surface representation for discrete voxel data [S1, unofficial].

## How it works
**Inputs:** A binary voxel volume where object voxels are black (1) and background voxels are white (0), and a candidate boundary voxel $P$ [S1, unofficial].
**Outputs:** A boolean flag indicating whether $P$ is a simple point (deletable without changing topology) [S1, unofficial].

**Data Structures:**
1. **Voxel Grid:** Binary representation of the object and background [S1, unofficial].
2. **Neighborhood Window:** A $3 \times 3 \times 3$ cube centered on $P$, denoted $N_{26}'(P)$, containing 27 voxels [S1, unofficial].
3. **Octant Decomposition:** The window is divided into 8 overlapping $2 \times 2 \times 2$ octants, each sharing $P$ and extending into 7 specific corner neighbors [S1, unofficial].
4. **Lookup Table (LUT):** A pre-computed table of 256 entries storing the Euler characteristic contribution for every possible binary configuration of a single $2 \times 2 \times 2$ octant [S1, unofficial].

**Connectivity Rules:**
Different connectivities are assigned to prevent topological paradoxes in digital space: object voxels use 26-connectivity (vertex-adjacent), while background voxels use 6-connectivity (face-adjacent) [S1, unofficial].

**Algorithm Steps:**
1. **Construct Analogous Surface:** Represent the discrete voxel model as a set of surface patches; for a 26-connected object, represent each 6-connected background component as a polyhedron [S1, unofficial].
2. **Extract Neighborhood:** Identify the $3 \times 3 \times 3$ window $N_{26}'(P)$ centered on $P$ [S1, unofficial].
3. **Decompose into Octants:** Divide the 27 voxels of $N_{26}'(P)$ into 8 overlapping $2 \times 2 \times 2$ octants [S1, unofficial].
4. **Compute Local Euler Characteristic:** For each octant, determine its 8-voxel binary configuration, retrieve its pre-computed contribution from the LUT, and sum all 8 contributions to obtain $\chi_{local}(P)$ [S1, unofficial].
5. **Evaluate Simplicity:** Apply the simplified Euler conditions: (a) $P$ is adjacent to exactly one black component of $N_{25}(P) \cap (S - \{P\})$; (b) $P$ is adjacent to exactly one white component of $N_{25}(P) - S$; (c) $\chi(S \cap N_{26}(P)) = \chi(\emptyset \cap N_{26}(P))$ [S1, unofficial]. If the local Euler characteristic remains unchanged after deletion, $P$ is a candidate simple point [S1, unofficial].

**Pseudocode:**
```python
def is_simple_point(P, voxel_grid, LUT):
    # Step 2: Extract 3x3x3 neighborhood N26'(P)
    # P is at grid coordinates (x, y, z); window spans [x-1:x+2, y-1:y+2, z-1:z+2]
    window = voxel_grid[P.z-1:P.z+2, P.y-1:P.y+2, P.x-1:P.x+2]
    
    # Step 3 & 4: Decompose into 8 overlapping 2x2x2 octants and sum LUT contributions
    chi_local = 0
    for dx in (0, 1):
        for dy in (0, 1):
            for dz in (0, 1):
                # Extract 2x2x2 octant starting at offset (dx, dy, dz)
                octant = window[dx:dx+2, dy:dy+2, dz:dz+2]
                # Convert binary octant to integer index 0-255
                index = 0
                for i in range(2):
                    for j in range(2):
                        for k in range(2):
                            index = (index << 1) | octant[i, j, k]
                # Accumulate pre-computed Euler contribution
                chi_local += LUT[index]
                
    # Step 5: Check condition (c) - local Euler characteristic must remain zero (baseline)
    # if chi_local == 0, the neighborhood topology is preserved
    return chi_local == 0
```

**Formula:**
The Euler characteristic $\chi(S)$ for a set of polyhedra $S$ is defined as [S1, unofficial]:
$$ \chi(S) = O(S) - H(S) + C(S) $$
Where:
* $O(S)$: Number of objects (connected components of black voxels).
* $H(S)$: Number of holes (tunnels).
* $C(S)$: Number of cavities (white components completely surrounded by black voxels).

For a closed surface polyhedron, the classical Euler formula applies [S1, unofficial]:
$$ V - E + F = 2 - 2G $$
Where:
* $V$: Number of vertices.
* $E$: Number of edges.
* $F$: Number of faces.
* $G$: Genus (maximum number of non-intersecting simple closed curves on the surface without separating it).

**Parameters:**
* **Neighborhood Size:** $3 \times 3 \times 3$ window [S1, unofficial].
* **Object Connectivity:** 26-connectivity [S1, unofficial].
* **Background Connectivity:** 6-connectivity [S1, unofficial].

**Edge Cases and Pitfalls:**
* **Global Topology Preservation:** Using the Euler characteristic alone cannot guarantee preservation of global topology; removing a center voxel may separate the object into two components even if the Euler characteristic is unchanged, because the number of objects and holes may increase by the same amount while local cavities remain zero [S1, unofficial].
* **Connectivity Mismatch:** Using identical connectivity for object and background causes topological paradoxes; the 26-connected object / 6-connected background pairing is required for consistent digital topology [S1, unofficial].
* **Cavity Detection:** Care must be taken to correctly distinguish cavities from tunnels, as misclassification directly corrupts the $C(S)$ term in the Euler formula [S1, unofficial].

## Subtopics

### [3-D Thinning Skeleton](20389-3-d-thinning-skeleton.md)
A topology-preserving data compression technique that reduces a binary voxel object to a compact skeleton by iteratively deleting non-critical boundary points. It is chosen when geometric simplification must maintain the original object's topological structure without introducing excessive sub-branches.

## Operating characteristics
* **Time Complexity:** $O(1)$ per voxel evaluation due to the fixed $3 \times 3 \times 3$ neighborhood and pre-computed LUT [S1, unofficial].
* **Memory Complexity:** Requires storage for the voxel grid plus a 256-entry lookup table [S1, unofficial].
* **Strengths:** Computationally efficient for local topology checks; preserves the Euler characteristic, a fundamental topological invariant [S1, unofficial].
* **Limitations:** Does not guarantee global topological preservation without additional connectivity verification; requires strict adherence to 26/6 connectivity rules [S1, unofficial].

## Background
The method originates from digital topology research by Lobregt et al. (1980) and Tsao & Fu (1981), who established the analogous surface representation for discrete voxel models to compute topological invariants [S1, unofficial]. It was subsequently applied to 3-D thinning algorithms for die casting part visualization to enable efficient topological data compression while preserving structural validity [S1, unofficial].
