# Topology Simplification via Leaf Pruning and Node Collapses

Also called: Carr et al. simplification

## Overview
This method suppresses insignificant topological features in scalar data by removing or cancelling pairs of critical points based on a specified measure [S1]. It operates by simplifying the contour tree through two fundamental operations: leaf pruning and node collapses [S1]. Unlike its sibling [Topology Simplification via Branch Decomposition](11673-topology-simplification-via-branch-decomposition.md), which focuses on hierarchical storage and efficient simplification queries, this approach defines the explicit geometric operations for modifying the tree structure and the underlying data [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A contour tree representing the scalar field, where nodes are critical points (minima, maxima, saddles) and arcs connect them. A priority measure (hypervolume, volume, or persistence) [S1].
*   **Output:** A simplified contour tree and, optionally, a modified scalar field where regions corresponding to pruned arcs are "flattened" [S1].

**Data Structures:**
The contour tree is represented as a graph where nodes store their type (minimum, maximum, saddle) and scalar value, and arcs store connectivity. The priority measure is precomputed for each arc or critical point pair to determine simplification order [S1].

**Steps:**
1.  **Compute Priority:** Calculate the priority measure for all candidate arcs/nodes. The measure can be:
    *   **Hypervolume:** The integral of the scalar field over the enclosed volume [S1].
    *   **Volume:** The geometric volume associated with the feature [S1].
    *   **Persistence:** The difference in scalar values between a critical point and its associated saddle [S1].
2.  **Select Operation:** Identify the feature with the lowest priority (least significant).
3.  **Execute Node Collapse (Priority):** If the selected feature involves a degree-two vertex, perform a node collapse. This removes the degree-two vertex and merges its incident arcs. This operation does not affect the extracted contours or the values in the dataset [S1].
4.  **Execute Leaf Pruning:** If the selected feature is a leaf, perform leaf pruning. Remove the leaf node and the incident arc from the contour tree [S1].
    *   **Pitfall:** Deleting an arc discards the corresponding contours from further consideration, as contours are extracted from seeds stored in the tree [S1].
5.  **Modify Data (Optional):** For visualization methods other than isosurface extraction, modify the scalar field to match the simplified topology. Assign the scalar value of the saddle to all points corresponding to the pruned arc ("flattening") [S1].
6.  **Repeat:** Update the tree structure and re-evaluate priorities until the desired simplification level is reached.

**Ordering Constraint:**
Node collapses must be performed with priority over leaf pruning to maintain structural integrity and minimize error [S1].

**Pseudocode:**
```python
def simplify_contour_tree(contour_tree, priority_measure, target_complexity):
    """
    Simplifies a contour tree using leaf pruning and node collapses.
    
    Args:
        contour_tree: Graph structure with nodes (critical points) and arcs.
        priority_measure: Function or precomputed values for hypervolume, volume, or persistence.
        target_complexity: Number of nodes/arcs to retain or error threshold.
        
    Returns:
        Simplified contour tree and optionally modified scalar field.
    """
    # Precompute priorities for all arcs/nodes
    priorities = compute_priorities(contour_tree, priority_measure)
    
    while contour_tree.is_complexity_above(target_complexity):
        # Find the least significant feature
        feature = find_min_priority_feature(contour_tree, priorities)
        
        if feature.type == "degree_two_node":
            # Node Collapse: Remove degree-two vertex
            perform_node_collapse(contour_tree, feature)
            # Update priorities for affected arcs
            update_priorities(contour_tree, priorities, feature)
        elif feature.type == "leaf":
            # Leaf Pruning: Remove leaf and incident arc
            perform_leaf_pruning(contour_tree, feature)
            
            # Optional: Flatten data for non-iso surface visualization
            if modify_scalar_field:
                saddle_value = feature.incident_arc.saddle_value
                flatten_region(contour_tree, feature, saddle_value)
            
            # Update priorities
            update_priorities(contour_tree, priorities, feature)
        else:
            # Fallback or error handling for other node types
            break
            
    return contour_tree
```

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Strengths:** Provides explicit control over topological features by removing insignificant critical points. Node collapses preserve the extracted contours and dataset values, while leaf pruning allows for significant simplification of the tree structure [S1].
*   **Limitations:** Leaf pruning discards contours associated with the pruned arcs, which may be undesirable for isosurface extraction if those contours are significant [S1]. The method relies on a priority measure, and the choice of measure (hypervolume, volume, persistence) can impact the visual result [S1].
*   **When to use:** When the goal is to remove noise-induced topological features while preserving the overall shape and significant structures, especially when using visualization methods other than strict isosurface extraction where data flattening is acceptable [S1].

## Background
This method is based on the work of Carr et al. [34], who introduced leaf pruning and node collapses as basic operations for simplifying contour trees [S1]. It builds upon earlier topology simplification methods by Takahashi et al. [29] and Pascucci et al. [35] [S1]. The approach is widely used in volume rendering and scientific visualization to handle noise and reduce complexity in scalar data [S1].
