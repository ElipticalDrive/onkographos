# 3-D Thinning Skeleton

Also called: Thinning algorithm, Topology-preserving data compression

## Overview
3-D Thinning Skeleton is a topology-preserving data compression technique that reduces a binary voxel object to a compact skeleton along its medial surface or axis [S1, unofficial]. It solves the problem of excessive sub-branches found in Medial Axis Transform (MAT) skeletons, making it more suitable for applications like diecastability evaluation [S1, unofficial]. It differs from MAT by iteratively deleting non-critical boundary points rather than computing geometric centers, and it relies on [Simple Point Detection via Euler Characteristic](20385-simple-point-detection-via-euler-characteristic.md) to ensure topological validity during deletion.

## How it works
**Inputs and Outputs:**
*   **Input:** A binary 3D volume where object voxels are black (1) and background voxels are white (0).
*   **Output:** A 3D skeleton representing the medial axis of the object.

**Data Structures:**
*   **Voxel Grid:** A 3D array of binary values.
*   **Connectivity Definitions:**
    *   **Object Connectivity:** 26-connectivity (vertex-adjacent). Two voxels $A$ and $B$ are 26-connected if there exists a path of 26-neighbors between them. This ensures the continuity of the black component [S1, unofficial].
    *   **Background Connectivity:** 6-connectivity (face-adjacent). This prevents ambiguity in the white component (background) [S1, unofficial].

**Parameters:**
*   **Object Connectivity:** 26 [S1, unofficial].
*   **Background Connectivity:** 6 [S1, unofficial].
*   **Termination Condition:** No more non-critical boundary points can be deleted.

**Steps:**
1.  **Classify Boundary Voxels:** Identify voxels belonging to the object (black) that have at least one 6-neighbor in the background (white). These are the candidate points for deletion.
2.  **Identify Non-Critical Points:** For each boundary voxel, determine if it is a "simple point." A simple point is one whose deletion preserves the topology of the object. This check is performed using [Simple Point Detection via Euler Characteristic](20385-simple-point-detection-via-euler-characteristic.md), which verifies that the Euler characteristic remains unchanged upon removal [S1, unofficial].
3.  **Protect End Points:** Identify geometric end points (termini) of the skeleton. These points must be protected from deletion to preserve the geometric features of the object [S1, unofficial].
4.  **Iterative Deletion:** Delete all identified non-critical points that are not end points. Repeat steps 1-4 until no more non-critical points can be deleted.

**Pitfalls:**
*   **Topological Paradoxes:** Using identical connectivity for both object and background can lead to topological paradoxes where the object appears disconnected or the background is incorrectly interpreted [S1, unofficial]. The method mandates 26-connectivity for the object and 6-connectivity for the background to avoid this [S1, unofficial].
*   **Post-Pruning:** The resulting skeleton may contain undesirable artifacts or short branches that require a post-pruning operation to be useful for specific applications like diecastability evaluation [S1, unofficial].

## Subtopics

### [Directional Parallel Thinning](23079-directional-parallel-thinning.md)
A parallel thinning algorithm that processes border voxels in specific directions (sub-cycles) to skeletonize a 3D volume. It suffers from 'annihilation' of voxels (deleting all N-type border voxels in one sub-cycle) and sensitivity to processing order, leading to boundary noise.

## Operating characteristics
*   **Time Complexity:** Not given in the sources. Generally depends on the number of boundary voxels and the number of iterations required for convergence.
*   **Memory Complexity:** Not given in the sources. Requires storage for the volume and potentially temporary structures for connectivity checks.
*   **Strengths:** Produces a skeleton along the medial surface/axis without the excessive sub-branches of MAT, making it more suitable for diecastability evaluation [S1, unofficial]. It is a topological data compression technique [S1, unofficial].
*   **Limitations:** The skeleton may require post-pruning to remove undesirable artifacts [S1, unofficial]. It is sensitive to the connectivity definitions; incorrect connectivity leads to topological paradoxes [S1, unofficial].
*   **When to use:** When a topological skeleton is needed for analysis (e.g., diecastability) and MAT is too noisy or complex.
*   **When not to use:** When geometric precision of the medial axis is critical and post-pruning is not feasible, or when real-time performance is required without parallelization strategies.

## Background
Thinning is a topology-preserving data compression technique commonly used for digital images [S1, unofficial]. While many algorithms were proposed for 2-D, attention has recently been devoted to 3-D thinning skeletons (e.g., Ma, 1994; Saha and Chaudhuri, 1994; Lee et al., 1994; Kong and Rosenfeld, 1989) [S1, unofficial]. The specific approach described here uses 26-connectivity for the object and 6-connectivity for the background to avoid topological paradoxes [S1, unofficial].
