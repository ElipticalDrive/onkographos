# Edge Split

Also called: Vertex Split

## Overview
Edge split is a topological refinement operation that increases mesh density in regions with high geometric variation, specifically where normal deviation exceeds a user-defined threshold. It serves as the inverse of edge collapse, expanding a single vertex into an edge to provide additional degrees of freedom for subsequent vertex relocation or geometry adaptation. Unlike edge collapse, which reduces complexity in smooth regions, edge split is chosen when the mesh lacks sufficient resolution to capture curvature or creases accurately.

## How it works
**Inputs:**
- A triangular or tetrahedral mesh $M$.
- A maximum normal deviation threshold $\sigma_{max}$ [S1].
- An optional minimum edge length parameter $L_{min}$ [S1].

**Outputs:**
- A modified mesh $M'$ with increased vertex count in refined regions.

**Data Structures:**
- The mesh is represented as a collection of elements (triangles or tetrahedra) with connectivity information.
- For each triangle $t$, the normal deviation $\sigma(t)$ is computed. This metric compares the triangle normal to offset normals at sample points within the triangle, typically using an acceleration structure like an AABB tree for projection [S1].

**Steps:**
1. **Candidate Identification:** Iterate through all triangles $t$ in the mesh. Compute $\sigma(t)$. If $\sigma(t) > \sigma_{max}$, identify the longest edge of $t$ as a candidate for splitting [S1].
2. **Length Filtering:** For each candidate edge $e$, check its length $|e|$. If $|e| < L_{min}$, discard the candidate to avoid refining features smaller than the user's interest [S1].
3. **Vertex Splitting:** For each valid candidate edge, perform the split:
   - **For Triangular Meshes:** The edge is split into two edges meeting at a new vertex $v_{new}$. The new vertex position is determined by a vertex relocation step (e.g., using Quadratic Error Metrics) to minimize normal deviation [S1].
   - **For Tetrahedral Meshes:** The operation is defined as a vertex split expanding a vertex $v$ into an edge $e$ with endpoints $v'$ and $v''$ [S2].
     - Partition the tetrahedra incident at $v$ into two subsets based on their spatial relationship to the split plane [S2].
     - Separate these subsets by a fan of triangles incident at $v$ [S2].
     - Deform the tetrahedra in the first subset to become incident at $v'$, and those in the second subset to become incident at $v''$ [S2].
     - Transform the triangles belonging to the fan into tetrahedra incident at the new edge $e$ [S2].
4. **Batch Execution:** Perform only a single batch of edge split operations. Newly created edges are **not** considered as candidates for recursive splitting in the same pass [S1]. This ensures the operation adds flexibility without immediately triggering further splits, leaving the reduction of normal deviation to subsequent vertex relocation steps [S1].

**Pseudocode:**
```python
def edge_split(mesh, sigma_max, L_min=None):
    """
    Performs a single batch of edge splits on the mesh.
    
    Args:
        mesh: The input mesh object containing triangles/tetrahedra.
        sigma_max: Maximum allowed normal deviation.
        L_min: Optional minimum edge length for refinement.
        
    Returns:
        Modified mesh with new vertices added.
    """
    candidates = []
    
    # Step 1 & 2: Identify candidates
    for triangle in mesh.triangles:
        # Compute normal deviation sigma(t)
        # This requires projecting sample points onto the input geometry
        sigma_t = compute_normal_deviation(triangle)
        
        if sigma_t > sigma_max:
            # Find the longest edge of the triangle
            longest_edge = max(triangle.edges, key=lambda e: e.length)
            
            # Check minimum length constraint
            if L_min is None or longest_edge.length >= L_min:
                candidates.append(longest_edge)
    
    # Step 3: Execute splits
    # Note: In a real implementation, one must handle connectivity updates
    # and ensure no two splits modify the same vertex/edge simultaneously
    # without conflict resolution. The sources specify a single batch,
    # implying simultaneous or ordered application without recursion.
    
    for edge in candidates:
        # Locate new vertex using vertex relocation (e.g., QEM)
        new_vertex = relocate_vertex(edge, mesh)
        
        # Perform the topological split
        # For triangles: split edge, create new vertex, update faces
        # For tetrahedra: partition incident tetrahedra, create edge e=(v', v'')
        split_edge_topology(edge, new_vertex, mesh)
        
    return mesh
```

**Edge Cases and Pitfalls:**
- **Recursive Splitting:** The method explicitly avoids recursive splitting in the same batch to prevent uncontrolled mesh growth and to allow vertex relocation to stabilize the geometry first [S1].
- **Precision:** Computing exact normal deviation is time-consuming as it may require optimization for local mapping [S1]. Approximations or acceleration structures (like AABB trees) are necessary for performance [S1].
- **Boundary Conditions:** The operation must maintain conforming updates, meaning it does not split the simplexes in the combinatorial boundary of the update [S2].

## Operating characteristics
- **Time Complexity:** Dominated by the computation of normal deviation for all triangles, which involves geometric queries (e.g., ray casting or projection) [S1]. The splitting itself is linear in the number of candidate edges.
- **Memory Complexity:** Increases linearly with the number of split vertices and edges.
- **Strengths:** Effectively increases mesh flexibility in high-curvature regions, allowing subsequent relocation steps to better approximate the target geometry [S1]. It detects concave creases implicitly [S1].
- **Limitations:** Does not guarantee a reduction in normal deviation on its own; it only adds degrees of freedom [S1]. Requires a subsequent vertex relocation step to realize the geometric improvement [S1].

## Background
Edge split is a fundamental operation in adaptive mesh refinement and multiresolution mesh generation. It is widely used in feature-preserving offset mesh generation and multiresolution tetrahedral mesh frameworks. The concept of vertex splitting as the inverse of edge collapse is central to maintaining mesh quality and adaptivity in both triangular and tetrahedral meshes.
