# Mesh Simplification


## Overview
Mesh simplification reduces the triangle count of a 3D mesh to a target number while minimizing geometric error, primarily through iterative edge collapses [S3, unofficial]. It solves the computational bottleneck of processing high-resolution isosurfaces in real-time 3D reconstruction and volume visualization [S1, unofficial]. Unlike general mesh simplification techniques that may prioritize topological correctness or specific error metrics, this method is often integrated as a preprocessing step for isosurface extraction (e.g., Marching Cubes) to balance reconstruction accuracy and interactive rotation speed [S1, unofficial]. It sets itself apart from siblings like [Wavelet-based Volume Rendering](1052-wavelet-based-volume-rendering.md) by operating directly on the mesh topology rather than the scalar field, and from [Multi-Tetra Framework](1183-multi-tetra-framework.md) by using edge collapses rather than tetrahedral decomposition [S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A mesh defined by vertices and faces, a target triangle count (or percentage), and simplification parameters [S3, unofficial].
*   **Output:** A simplified mesh with reduced vertex and face counts, preserving the original topology where possible [S1, unofficial].

**Data Structures:**
*   `MeshBuffer`: Contains `numVertices`, `numTriangles`, `vertices` (array of `MeshVertex`), and `triangles` (array of `MeshTriangle`) [S3, unofficial].
*   `MeshVertex`: Contains `xyz` (vec3/vec4), `normal` (vec3/vec4), and `colour` (vec3/vec4) [S3, unofficial].
*   `MeshTriangle`: Contains `indices_` (array of 3 ints) [S3, unofficial].
*   `Edge`: A union containing `uint64_t idx_` and a struct with two `uint32_t` fields `min_` and `max_`. Used to store edge indices and sort them [S3, unofficial].
*   `LinearBuffer<T>`: A template class with private fields `T* base_`, `T* end_`, `int size_`. Provides methods `push_back`, `resize`, `clear`, `begin`, `end`, `operator[]` [S3, unofficial].

**Parameters:**
*   `reduction_factor`: An integer specifying the target reduction factor for triangles. Value 0 disables simplification. Example: 100 [S1, unofficial].
*   `max_error`: The maximum tolerable error in physical distance. If not set, it defaults to one voxel along the smallest dimension [S1, unofficial].
*   `voxel_centered`: A boolean determining if meshes are centered in the voxel at (0,0,0) [False] or (0.5,0.5,0.5) [True]. Default is False [S1, unofficial].
*   `targetPercentage`: Float specifying the target triangle count as a fraction of the initial count [S3, unofficial].
*   `maxIterations`: Integer limiting the maximum number of simplification iterations [S3, unofficial].
*   `agressiveness`: A parameter controlling the simplification behavior, default 7.0 [S4, unofficial].
*   `quality`: If > 0, performs lossless simplification after lossy; default 1 [S4, unofficial].
*   `COLLAPSE_MAX_DEGREE`: Maximum allowed sum of triangle counts for the two vertices involved in a collapse, set to 16 [S3, unofficial].
*   `edgeFraction`: Fraction of total edges to sample for potential collapses, used to improve performance by avoiding full mesh scan [S3, unofficial].
*   `minAngleCosine`: Minimum cosine of the angle between vertex normals to allow a collapse; prevents collapsing across sharp creases [S3, unofficial].
*   `maxEdgeSize`: Maximum squared length of an edge allowed for collapse [S3, unofficial].
*   `maxError`: Maximum acceptable QEF error for a collapse; collapses exceeding this are rejected [S3, unofficial].

**Steps:**
1.  **Precondition Check:** If `mesh->numTriangles < 100` or `mesh->numVertices < 100`, return immediately without modification [S3, unofficial].
2.  **Local Space Translation:** Translate vertices to local space by subtracting `worldSpaceOffset` from each vertex's xyz [S3, unofficial].
3.  **Initialization:** Initialize mesh counters to zero [S3, unofficial].
4.  **Build Candidate Edges:**
    *   Iterate over all triangles, extracting three edges per triangle [S3, unofficial].
    *   Normalize edge indices (min, max) and sort edges by index [S3, unofficial].
    *   Filter to keep only unique edges [S3, unofficial].
    *   Mark vertices as boundary if an edge appears only once (count == 1) [S3, unofficial].
    *   Discard boundary edges from the final candidate list [S3, unofficial].
5.  **Allocate Buffers:** Allocate buffers for `collapsePosition`, `collapseNormal`, `collapseValid`, `collapseEdgeID`, `collapseTarget`, `edgeBuffer`, and `triBuffer` [S3, unofficial].
6.  **Compute Vertex Triangle Counts:** Iterate all triangles and increment count for each vertex index [S3, unofficial].
7.  **Simplification Loop:** While `triangle count > target` and `iterations < maxIterations`:
    *   Reset `collapseEdgeID` and `collapseTarget` to -1, clear `collapseValid` [S3, unofficial].
    *   **Find Valid Collapses:**
        *   Seed PRNG with 42 [S3, unofficial].
        *   Calculate `numRandomEdges = edges.size() * options.edgeFraction` [S3, unofficial].
        *   Generate random indices into the edges array and sort them for locality [S3, unofficial].
        *   For each sampled edge:
            1.  Check normal dot product (`cosAngle`) against `options.minAngleCosine`; skip if lower [S3, unofficial].
            2.  Calculate squared edge length; skip if `> options.maxEdgeSize^2` [S3, unofficial].
            3.  Calculate degree (sum of triangle counts for both vertices); skip if `> COLLAPSE_MAX_DEGREE` [S3, unofficial].
            4.  Solve QEF for the two vertices using `qef_solve_from_points_4d_interleaved` [S3, unofficial].
            5.  If error > 0, invert it (`error = 1.f / error`) [S3, unofficial].
            6.  Apply penalty: `penalty = max(0, degree - 10)`; `error += penalty * (options.maxError * 0.1f)` [S3, unofficial].
            7.  Skip if `error > options.maxError` [S3, unofficial].
            8.  Store valid edge index in `collapseValid` [S3, unofficial].
            9.  Compute collapse normal as average of vertex normals [S3, unofficial].
            10. Compute collapse position from QEF solution [S3, unofficial].
            11. Update `minEdgeCost` for both vertices if current error is lower, storing the edge index in `collapseEdgeID` [S3, unofficial].
        *   **Pitfall:** If `countValidCollapse == 0`, break the loop to prevent infinite iteration [S3, unofficial].
    *   **Collapse Edges:** Perform the collapses, updating vertices and setting `collapseTarget` mappings [S3, unofficial].
    *   **Remove Triangles:**
        *   Iterate over all triangles. For each vertex index, if `collapseTarget[index] != -1`, replace index with target [S3, unofficial].
        *   If the resulting triangle has duplicate indices (degenerate), increment `removedCount` and skip [S3, unofficial].
        *   Otherwise, add to `triBuffer` and increment `vertexTriangleCounts` for the new indices [S3, unofficial].
        *   Swap tris with `triBuffer` [S3, unofficial].
    *   **Remove Edges:** Update edge endpoints based on `collapseTarget`, removing self-loops (where `min_ == max_`) [S3, unofficial].
8.  **Finalize:**
    *   Copy remaining triangles back to `mesh->triangles` [S3, unofficial].
    *   Call `CompactVertices` to remove unused vertices and remap triangle indices [S3, unofficial].
    *   Translate vertices back to world space by adding `worldSpaceOffset`, then copy to `mesh->vertices` with position, normal, and colour [S3, unofficial].
    *   Reconstruct mesh object from simplified vertices and faces using `trimesh.Trimesh` [S1, unofficial].

**Pseudocode:**
```python
def mesh_simplify(vertices, faces, target_count, agressiveness=7.0, max_iterations=100, 
                  edge_fraction=0.1, min_angle_cosine=0.0, max_edge_size=1e9, max_error=1e9):
    import random
    import math

    # Precondition check
    if len(faces) < 100 or len(vertices) < 100:
        return vertices, faces

    # Local space translation (worldSpaceOffset assumed 0 for this implementation)
    # In practice: vertices -= worldSpaceOffset

    num_vertices = len(vertices)
    num_faces = len(faces)

    # Build candidate edges
    edges = []
    edge_counts = {}
    vertex_triangle_counts = [0] * num_vertices

    for face in faces:
        for i in range(3):
            v1, v2 = face[i], face[(i + 1) % 3]
            edge = (min(v1, v2), max(v1, v2))
            edge_counts[edge] = edge_counts.get(edge, 0) + 1
            vertex_triangle_counts[v1] += 1
            vertex_triangle_counts[v2] += 1

    # Filter unique edges, mark boundary, discard boundary edges
    unique_edges = []
    boundary_vertices = set()
    for edge, count in edge_counts.items():
        if count == 1:
            boundary_vertices.add(edge[0])
            boundary_vertices.add(edge[1])
        unique_edges.append(edge)

    candidate_edges = [e for e in unique_edges if e[0] not in boundary_vertices and e[1] not in boundary_vertices]

    # Allocate buffers
    collapse_position = [None] * num_vertices
    collapse_normal = [None] * num_vertices
    collapse_valid = [False] * len(candidate_edges)
    collapse_edge_id = [-1] * num_vertices
    collapse_target = [-1] * num_vertices
    tri_buffer = []

    # Simplification loop
    for iteration in range(max_iterations):
        if num_faces <= target_count:
            break

        # Reset buffers
        for i in range(num_vertices):
            collapse_edge_id[i] = -1
            collapse_target[i] = -1
        for i in range(len(candidate_edges)):
            collapse_valid[i] = False

        # Find valid collapses
        random.seed(42)
        num_random_edges = int(len(candidate_edges) * edge_fraction)
        random_indices = sorted(random.sample(range(len(candidate_edges)), num_random_edges))

        min_edge_cost = [float('inf')] * num_vertices

        for idx in random_indices:
            v1, v2 = candidate_edges[idx]
            degree = vertex_triangle_counts[v1] + vertex_triangle_counts[v2]

            # Check degree
            if degree > 16:
                continue

            # Solve QEF for the two vertices [G]
            # error = qef_solve_from_points_4d_interleaved(...)
            error = 0.0
            if error > 0:
                error = 1.0 / error

            # Apply penalty
            penalty = max(0, degree - 10)
            error += penalty * (max_error * 0.1)

            # Skip if error too high
            if error > max_error:
                continue

            collapse_valid[idx] = True
            collapse_position[idx] = (0.0, 0.0, 0.0) # QEF solution [G]
            collapse_normal[idx] = (0.0, 0.0, 0.0)   # Avg normals [G]

            if error < min_edge_cost[v1]:
                min_edge_cost[v1] = error
                collapse_edge_id[v1] = idx
            if error < min_edge_cost[v2]:
                min_edge_cost[v2] = error
                collapse_edge_id[v2] = idx

        # Pitfall: break if no valid collapses
        if not any(collapse_valid):
            break

        # Collapse edges & Remove triangles
        new_faces = []
        for face in faces:
            new_indices = []
            for v in face:
                if collapse_target[v] != -1:
                    new_indices.append(collapse_target[v])
                else:
                    new_indices.append(v)
            # Check degenerate
            if len(set(new_indices)) == 3:
                new_faces.append(new_indices)
                for v in new_indices:
                    vertex_triangle_counts[v] += 1
            # Degenerate triangles are skipped

        faces = new_faces
        num_faces = len(faces)

        # Update collapse targets
        for i in range(num_vertices):
            if collapse_edge_id[i] != -1:
                v1, v2 = candidate_edges[collapse_edge_id[i]]
                collapse_target[v1] = v2
                collapse_target[v2] = v2

        # Remove edges with self-loops
        candidate_edges = [e for e in candidate_edges if e[0] != e[1]]

    # Compact vertices and remap indices [G]
    old_to_new = {}
    new_vertices = []
    new_faces = []
    new_idx = 0
    for i in range(num_vertices):
        if collapse_target[i] == -1:
            old_to_new[i] = new_idx
            new_vertices.append(vertices[i])
            new_idx += 1

    for face in faces:
        new_faces.append([old_to_new[v] for v in face])

    # Translate back to world space
    # new_vertices += worldSpaceOffset

    return new_vertices, new_faces
```

**Pitfalls:**
*   Vertex range limit: The maximum vertex range supported after converting to voxel space is $2^{20}$ (approx 1M) due to the packed 64-bit vertex format [S1, unofficial].
*   Hub formation: Collapses can create vertices with very high degree. The algorithm penalizes collapses that would result in a degree > 10 by adding to the error metric [S3, unofficial].
*   If no valid collapses are found (`countValidCollapse == 0`), the loop breaks to prevent infinite iteration [S3, unofficial].

## Subtopics

### [Mesh simplification via valence pattern removal](1931-mesh-simplification-via-valence-pattern-removal.md)
This method reduces the element count of quad-dominant meshes, specifically those generated by the Dual Marching Cubes (DMC) algorithm, by identifying and removing specific quadrilateral valence patterns: 3-X-3-Y and 3-3-3-3. It solves the problem of excessive mesh complexity and poor element quality caused by transitions between volume data layers. Unlike general decimation methods, this approach is optional, parallelized using face coloring to avoid race conditions, and specifically targets topological artifacts inherent to the DMC representation. It improves mesh quality and repositions vertices while reducing element count by approximately 10% for datasets like human skulls and skeletons.

### [Linear Spline Simplification](3483-linear-spline-simplification.md)
Linear Spline Simplification is an iterative knot removal algorithm that reduces the number of control points (knots) in a 1D linear spline by merging consecutive segments when internal knots lie within a pre-chosen vertical distance (scalar domain) from the candidate merged segment. It solves the problem of redundant data storage in Piecewise Linear Representations (PRI) by identifying spans of nearly collinear scalar values and removing intermediate samples while preserving endpoints. The resulting list of knots is a subset of the original list.

### [GPU-based Mesh Decimation via Edge Collapse](3505-gpu-based-mesh-decimation-via-edge-collapse.md)
GPU-based Mesh Decimation via Edge Collapse is a postprocessing technique that reduces the polygon count of a triangular mesh while preserving sharp geometric features. It solves the problem of excessive face counts in meshes generated by analytic marching or other high-resolution methods, which hinder rendering and texturing efficiency. Unlike CPU-based greedy decimation which iterates until a target is reached, this method uses a limited number of parallel iterations (typically 2) combined with Thrust utilities for sorting and scanning, trading absolute optimality for significant speedups on GPU hardware. It builds on [Mesh Simplification](1032-mesh-simplification.md) by implementing the Quadric Error Metric (QEM) specifically for GPU architectures.

### [Grid-based LOD Simplification](4423-grid-based-lod-simplification.md)
Grid-based LOD Simplification renders large-scale voxel or blocky meshes at multiple levels of detail by quantizing vertex coordinates to a coarse grid and implicitly managing primitive visibility. It solves the problem of rendering distant geometry efficiently without storing multiple explicit mesh copies on the GPU by sorting primitives into a Progressively Ordered Primitive (POP) buffer. Unlike [Mesh simplification via valence pattern removal](1931-mesh-simplification-via-valence-pattern-removal.md) which modifies topology, or [GPU-based Mesh Decimation via Edge Collapse](3505-gpu-based-mesh-decimation-via-edge-collapse.md) which requires complex graph operations, this method relies on simple coordinate rounding and sorting. It is distinct from [Linear Spline Simplification](3483-linear-spline-simplification.md) as it operates on discrete integer grids rather than continuous spline approximations.

### [Octree Simplification](4641-octree-simplification.md)
Octree Simplification reduces the geometric complexity of an octree-based isosurface representation by collapsing leaf nodes into pseudo-leaf nodes. It controls the trade-off between geometric fidelity and rendering performance during volume rendering.

### [Sample-based Simplification](7814-sample-based-simplification.md)
Sample-based simplification reduces geometric complexity for unstructured tetrahedral meshes during volume rendering by selectively removing triangle primitives instead of resampling the domain. It differs from domain-based simplification, which resamples the domain via edge-collapses, by operating directly on the rendered primitives and preserving the original mesh topology. The method is designed for interactive rendering within the HAVS volume rendering system.

### [Isosurface Simplification via Persistence](8470-isosurface-simplification-via-persistence.md)
Isosurface Simplification via Persistence is a mesh simplification technique for topological objects modeled as meshes, used for noise removal and feature selection in volume visualization. It addresses the problem of identifying and removing insignificant topological features based on their persistence. It sets itself apart from raw histogram analysis by incorporating geometric metrics (area, volume) and topological persistence to provide a truer distribution of the scalar field.

### [Vertex Clustering Simplification](9046-vertex-clustering-simplification.md)
Vertex Clustering is a technique for precomputing static levels of detail (LOD) for large datasets, primarily used in out-of-core visualization systems where memory constraints necessitate simplified representations. It differs from error-driven edge-collapse methods by using a fixed spatial grid to merge vertices, and is used for creating multiresolution representations of isosurfaces.

### [Triangular Mesh Simplification](9103-triangular-mesh-simplification.md)
Triangular Mesh Simplification reduces the polygon count of a 3D surface mesh to improve rendering performance or storage efficiency while preserving the overall geometric shape. It solves the trade-off between visual fidelity and computational cost in real-time 3D reconstruction and visualization. This method differs from its siblings by focusing on general mesh decimation techniques, often serving as a preprocessing step for algorithms like Marching Cubes to enhance interactivity.

### [Streaming Simplification Algorithm](14448-streaming-simplification-algorithm.md)
The Streaming Simplification Algorithm simplifies large tetrahedral meshes by processing them sequentially from disk through a fixed-size in-core buffer, minimizing memory usage to handle datasets exceeding available RAM. Unlike in-core methods that require the entire connectivity graph in memory, this method performs edge collapses on localized portions using a quadric error metric while preserving the coherent stream order of the mesh for downstream processing. It distinguishes itself from other streaming approaches by ensuring the output stream remains coherent and by using a randomized edge selection strategy that avoids the "locked state" issues common in greedy priority-queue methods.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Performance scales with the number of edges and the aggressiveness of the simplification. Using `edgeFraction` allows for faster convergence at the cost of potential sub-optimality [S3, unofficial].
*   **Strengths:** Preserves topology, minimizes geometric error via QEF, handles sharp features via normal checks [S3, unofficial].
*   **Limitations:** Can create "hub" vertices with high degree if not penalized. May fail to find valid collapses if the mesh is too constrained or the target is too low [S3, unofficial].

## Background
The method originates from the work on fast dual contouring and mesh simplification, as implemented in repositories like `nickgildea/fast_dual_contouring` [S3, unofficial] and `TRTUZ8/TRTUZ8.github.io` [S4, unofficial]. It is often used in conjunction with Marching Cubes for isosurface extraction from volume data [S3, unofficial]. The use of Quadric Error Functions (QEF) for error measurement is a key component, derived from earlier work on mesh decimation [S3, unofficial].
