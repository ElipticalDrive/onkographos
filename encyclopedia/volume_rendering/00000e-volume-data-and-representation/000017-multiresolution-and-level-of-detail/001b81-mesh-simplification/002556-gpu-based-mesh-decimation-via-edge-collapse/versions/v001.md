# GPU-based Mesh Decimation via Edge Collapse

Also called: CUDA Mesh Decimation, CUDA QEM Decimation, GPU Quadric Simplification, GPU-based Mesh Decimation with Quadric Error Metrics, Mesh Decimation using QEM Edge Collapse

## Overview
This method decimates a triangular mesh by iteratively collapsing edges to minimize geometric error, implemented on the GPU using CUDA kernels and Thrust utilities [S1, unofficial]. It reduces vertex count while preventing degenerate faces and normal flipping by enforcing topological validity checks and boundary preservation penalties on the device [S1, unofficial]. Unlike typical greedy decimation which iterates until the target is reached, this implementation uses a fixed, small number of iterations (typically 2), trading absolute quality for speed and stability [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** `vertices` (Float tensor, shape `[V, 3]`, dtype `float32`), `faces` (Integer tensor, shape `[F, 3]`, dtype `int32`), `target_vertex_count` (Integer, positive).
- **Output:** `new_vertices` (Float tensor, shape `[V', 3]`), `new_faces` (Integer tensor, shape `[F', 3]`).

**Data Structures:**
- **Tri:** Struct with fields `v0`, `v1`, `v2` (int). Represents a triangular face. Invalid faces are marked by setting `v0 = -1` (and consequently `v1, v2 = -1`).
- **Edge:** Struct with fields `v0`, `v1` (int). Enforces canonical ordering `v0 < v1`.
- **Quadricf:** Struct with 10 float fields: `a00`, `a01`, `a02`, `a11`, `a12`, `a22`, `b0`, `b1`, `b2`, `c`. Represents the symmetric matrix $Q$ and vector $b$ of the Quadric Error Metric.
- **Adjacency:** Host-side CSR-like structures `vertex_to_face_map` (flat array of face indices) and `vertex_to_face_offsets` (array of size `num_vertices + 1`).

**Parameters:**
- `MAX_ITERATIONS`: Integer, set to 2 [S1, unofficial].
- `THREADS_PER_BLOCK`: Integer, set to 256 [S1, unofficial].
- `Boundary penalty multiplier`: Float, 1000.0 [S1, unofficial].
- `Degeneracy threshold`: Float, $10^{-11}$ (one-ring check) [S1, unofficial].
- `Singular matrix threshold`: Float, $10^{-8}$ (determinant check) [S1, unofficial].

**Algorithm Steps:**
1. **Transfer and Initialize:** Copy input `vertices` and `faces` to device vectors. Initialize host-side adjacency structures (`vertex_to_face_map`, `vertex_to_face_offsets`) by iterating over all faces. Transfer these adjacency structures to the device.
2. **Iteration Loop:** Repeat up to `MAX_ITERATIONS` times, while `num_vertices > target_vertex_count` and `num_faces > 0`:
    a. **Rebuild Adjacency:** Copy current `d_faces` to host, rebuild `vertex_to_face_adjacency`, and transfer back to device vectors `d_v_to_f_map` and `d_v_to_f_offsets`.
    b. **Calculate Vertex Quadrics:** Zero-initialize `d_vertex_quadrics`. Launch `kernel_calculate_vertex_quadrics` with grid size `(num_faces + THREADS_PER_BLOCK - 1) / THREADS_PER_BLOCK`. Each thread processes one face, computes its quadric, and atomically adds it to the three vertex quadrics.
    c. **Extract Edges:** Launch `kernel_extract_face_edges`. For each face, generate 3 edges as normalized pairs `{min(v_i, v_j), max(v_i, v_j)}` into `d_all_edges`.
    d. **Identify Unique and Boundary Edges:** Sort `d_all_edges`. Use `thrust::unique` to get `d_unique_edges`. Use `thrust::reduce_by_key` on `d_all_edges` with a constant iterator `1` to count occurrences of each unique edge. An edge is a boundary edge if its count is 1.
    e. **Calculate Edge Costs:** Launch `kernel_calculate_edge_costs`. For each unique edge, sum the quadrics of its two vertices to get $Q$. Solve $Q \times pos = -b$ for the collapse position. If $|det(Q)| \le 10^{-8}$, fallback to midpoint. Check for normal flips and degeneracy in the one-ring neighborhood. Apply penalties for boundary edges or invalid collapses. Store cost and position.
    f. **Select Collapses:** Sort edges by cost (ascending). Transfer sorted indices and costs to host. Iterate through sorted edges, selecting an edge if neither of its vertices has been used in a previous collapse in this iteration. Mark vertices as used.
    g. **Update Mesh:** Launch `kernel_resolve_remap_table` to find final destination vertices. Launch `kernel_update_faces` to remap vertex indices; mark faces with duplicate vertices as invalid `{-1, -1, -1}`. Launch `kernel_update_vertex_positions` to write new positions to destination vertices.
    h. **Compact:** Remove invalid faces and unused vertices. Re-index active vertices and faces. Update `num_vertices` and `num_faces`. If `num_valid_faces == 0`, terminate.

**Formulas:**
- **Face Normal and Area:** $n = (v_1 - v_0) \times (v_2 - v_0)$, $area = 0.5 \times ||n||$.
- **Plane Distance:** $d = -n \cdot v_0$ (using normalized $n$).
- **Quadric Construction:**
  $$q_{a00} = n_x^2 \times area, \quad q_{a01} = n_x n_y \times area, \quad q_{a02} = n_x n_z \times area$$
  $$q_{a11} = n_y^2 \times area, \quad q_{a12} = n_y n_z \times area, \quad q_{a22} = n_z^2 \times area$$
  $$q_{b0} = n_x d \times area, \quad q_{b1} = n_y d \times area, \quad q_{b2} = n_z d \times area$$
  $$q_c = d^2 \times area$$
- **Collapse Position:** Solve $Q \times pos = -b$. If singular, $pos = (v_0 + v_1)/2$.
- **Cost Function:**
  $$cost = pos^T Q pos + 2 b^T pos + c$$
  $$= q_{a00}pos_x^2 + 2q_{a01}pos_x pos_y + 2q_{a02}pos_x pos_z + q_{a11}pos_y^2 + 2q_{a12}pos_y pos_z + q_{a22}pos_z^2 + 2q_{b0}pos_x + 2q_{b1}pos_y + 2q_{b2}pos_z + q_c$$

**Pseudocode:**
```python
def decimate_mesh(vertices, faces, target_vertex_count):
    # 1. Transfer to device
    d_vertices = to_device(vertices)
    d_faces = to_device(faces)
    num_vertices = len(vertices)
    num_faces = len(faces)
    
    if num_vertices <= target_vertex_count:
        return vertices, faces

    # 2. Build initial adjacency on host
    h_v_to_f_map, h_v_to_f_offsets = build_vertex_to_face_adjacency(faces, num_vertices)
    d_v_to_f_map = to_device(h_v_to_f_map)
    d_v_to_f_offsets = to_device(h_v_to_f_offsets)

    MAX_ITERATIONS = 2
    THREADS_PER_BLOCK = 256

    for iter in range(MAX_ITERATIONS):
        if num_vertices <= target_vertex_count or num_faces == 0:
            break

        # 2a. Rebuild adjacency
        h_faces = to_host(d_faces)
        h_v_to_f_map, h_v_to_f_offsets = build_vertex_to_face_adjacency(h_faces, num_vertices)
        d_v_to_f_map = to_device(h_v_to_f_map)
        d_v_to_f_offsets = to_device(h_v_to_f_offsets)

        # 2b. Calculate Vertex Quadrics
        d_vertex_quadrics = zero_init(num_vertices, Quadricf)
        grid_size = (num_faces + THREADS_PER_BLOCK - 1) // THREADS_PER_BLOCK
        kernel_calculate_vertex_quadrics<<<grid_size, THREADS_PER_BLOCK>>>(
            d_vertices, d_faces, num_faces, d_vertex_quadrics
        )

        # 2c. Extract Edges
        d_all_edges = empty(num_faces * 3, Edge)
        kernel_extract_face_edges<<<grid_size, THREADS_PER_BLOCK>>>(
            d_faces, num_faces, d_all_edges
        )

        # 2d. Identify Unique and Boundary Edges
        sort(d_all_edges)
        d_unique_edges = unique(d_all_edges)
        num_unique_edges = len(d_unique_edges)
        
        d_edge_counts = reduce_by_key(d_all_edges, constant(1))
        d_is_boundary = (d_edge_counts == 1)

        # 2e. Calculate Edge Costs
        d_edge_costs = empty(num_unique_edges, float)
        d_collapse_pos = empty(num_unique_edges, V3f)
        kernel_calculate_edge_costs<<<grid_size, THREADS_PER_BLOCK>>>(
            d_unique_edges, num_unique_edges,
            d_vertices, d_vertex_quadrics, d_faces,
            d_is_boundary, d_v_to_f_map, d_v_to_f_offsets,
            d_edge_costs, d_collapse_pos
        )

        # 2f. Select Collapses
        d_edge_indices = argsort(d_edge_costs)
        h_sorted_indices = to_host(d_edge_indices)
        h_unique_edges = to_host(d_unique_edges)
        h_collapse_pos = to_host(d_collapse_pos)

        vertex_used = [False] * num_vertices
        collapses = []
        new_positions_batch = []
        collapse_v0_indices_batch = []
        
        num_collapses_this_iteration = num_vertices - target_vertex_count
        if num_collapses_this_iteration <= 0:
            num_collapses_this_iteration = 1
        if num_collapses_this_iteration <= 0:
            break

        for i in range(num_unique_edges):
            if len(collapses) >= num_collapses_this_iteration:
                break
            original_edge_idx = h_sorted_indices[i]
            e = h_unique_edges[original_edge_idx]
            if not vertex_used[e.v0] and not vertex_used[e.v1]:
                vertex_used[e.v0] = True
                vertex_used[e.v1] = True
                # Collapse v1 into v0 (or vice versa, implementation dependent)
                # Here we assume v0 is kept, v1 is removed, but remap handles it
                collapses.append((e.v1, e.v0)) 
                new_positions_batch.append(h_collapse_pos[original_edge_idx])
                collapse_v0_indices_batch.append(e.v0)

        if not collapses:
            break

        # 2g. Update Mesh
        # Create remap table: initially identity
        d_remap_table = identity(num_vertices)
        # Mark removed vertices to point to kept vertices
        # Note: Implementation details vary on how remap is built. 
        # Based on notes, kernel_resolve_remap_table uses path compression.
        # We assume a preliminary remap is set up where v_to_remove -> v_to_keep
        for v_remove, v_keep in collapses:
            d_remap_table[v_remove] = v_keep
        
        kernel_resolve_remap_table<<<grid_size, THREADS_PER_BLOCK>>>(
            d_remap_table, num_vertices
        )

        kernel_update_faces<<<grid_size, THREADS_PER_BLOCK>>>(
            d_faces, num_faces, d_remap_table
        )

        kernel_update_vertex_positions<<<grid_size, THREADS_PER_BLOCK>>>(
            d_vertices, d_remap_table, 
            to_device(new_positions_batch), 
            to_device(collapse_v0_indices_batch), 
            len(collapses)
        )

        # 2h. Compact
        d_valid_faces = copy_if(d_faces, lambda f: f.v0 != -1)
        num_valid_faces = len(d_valid_faces)
        d_faces = d_valid_faces
        num_faces = num_valid_faces

        if num_faces == 0:
            num_vertices = 0
            break

        # Compact vertices
        d_active_vertices = mark_active(d_faces, num_vertices)
        d_new_indices = exclusive_scan(d_active_vertices)
        # ... compact vertices logic ...
        num_vertices = sum(d_active_vertices)

    return to_host(d_vertices), to_host(d_faces)
```

## Operating characteristics
- **Time Complexity:** Dominated by sorting and adjacency rebuilding in each iteration. With `MAX_ITERATIONS=2`, it is significantly faster than iterative greedy approaches.
- **Memory Complexity:** Requires storage for vertices, faces, quadrics, edges, and adjacency structures. Thrust vectors add overhead.
- **Measured Performance:** Optimized for GPU memory bandwidth and parallelism using Thrust for sorting/scanning and CUDA kernels for computation [S1, unofficial].
- **Strengths:** Fast, parallelizable, handles boundary preservation and topological validity checks on-device.
- **Limitations:** Fixed iteration count may not reach exact target vertex count. Actual output vertex count may vary slightly due to mesh topology and invalid collapses [S1, unofficial]. Numerical instability can cause spikes, mitigated by clamping to midpoint [S1, unofficial].
- **When to Use:** When speed is prioritized over absolute geometric fidelity, and the mesh is triangular.
- **When Not to Use:** When exact vertex count is required, or for non-triangular meshes.

## Background
Originating from the Quadric Error Metrics (QEM) method by Garland and Heckbert, this GPU-accelerated implementation adapts the technique for parallel execution on CUDA architectures [S1, unofficial]. It leverages Thrust for efficient data parallel operations and CUDA kernels for fine-grained control over mesh updates. The method is used in real-time rendering and geometry processing pipelines where rapid mesh simplification is required.
