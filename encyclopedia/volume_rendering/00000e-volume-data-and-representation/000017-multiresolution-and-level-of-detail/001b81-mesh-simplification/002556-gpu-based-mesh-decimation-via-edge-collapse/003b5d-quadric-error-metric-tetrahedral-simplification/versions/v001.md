# Quadric Error Metric Tetrahedral Simplification

Also called: Garland and Zhou simplification, QEM Tetrahedral Decimation, Quadric error metric simplification, Quadric-Based Simplification, Tetrahedral QEM Simplification

## Overview
Quadric Error Metric Tetrahedral Simplification is a mesh decimation algorithm that reduces the vertex count of a tetrahedral mesh by iteratively collapsing edges, minimizing geometric and field approximation errors using quadric metrics [S2]. It distinguishes itself from sibling methods by supporting volumetric (tetrahedral) meshes rather than just surface triangles, and by incorporating a positional correction term to ensure numerical stability during collapse operations [S1, S2]. It builds on [GPU-based Mesh Decimation via Edge Collapse](3505-gpu-based-mesh-decimation-via-edge-collapse.md) but extends the error metric to handle 3D volume elements and scalar field data.

## How it works
**Inputs:** A tetrahedral mesh consisting of vertices, edges, and tetrahedra; optionally, a scalar field function $f$ defined over the mesh domain.
**Outputs:** A simplified tetrahedral mesh with reduced vertex count.

**Data Structures:**
*   **Quadric Matrix $A$:** A symmetric $n \times n$ matrix, where $n$ is the dimension of the embedding space (typically 3 for geometry, 4 if including field data).
*   **Vector $b$:** An $n$-dimensional vector.
*   **Scalar $c$:** A scalar value.
*   **Vertex Data:** Each vertex stores its accumulated quadric $(A, b, c)$ and its current position.

**Formulas:**
The quadric error metric represents the squared distance from a point $x$ to a set of hyperplanes. For a single hyperplane defined by normal $n$ and distance $d$ (equation $n^T x + d = 0$), the squared distance is $(n^T x + d)^2$. This can be expanded to the quadratic form:
$$ Q(x) = x^T A x + 2b^T x + c $$
where:
*   $A = n n^T$
*   $b = n d$
*   $c = d^2$

For a vertex incident to multiple hyperplanes (tetrahedra faces), the total quadric is the sum of individual quadrics:
$$ A_{total} = \sum A_i, \quad b_{total} = \sum b_i, \quad c_{total} = \sum c_i $$

If field data is included, vertices are treated as points in $\mathbb{R}^4$: $p = [x, y, z, f]^T$. The hyperplanes are extended to 4D to represent the field function approximation [S2].

**Steps:**
1.  **Initialization:** For each vertex, compute the initial quadric $(A, b, c)$ by summing the contributions from all incident tetrahedra (and boundary faces if applicable) [S2].
2.  **Edge Selection:** Iterate through all edges. For each edge, calculate the cost of collapsing it to a single vertex.
3.  **Cost Calculation:**
    a. Combine the quadrics of the two vertices connected by the edge by component-wise addition:
       $$ A_{new} = A_1 + A_2 $$
       $$ b_{new} = b_1 + b_2 $$
       $$ c_{new} = c_1 + c_2 $$
    b. Solve the linear system $A_{new} x = b_{new}$ to find the optimal position $x$ that minimizes the quadric error [S2].
    c. Calculate the error value $E = x^T A_{new} x + 2b_{new}^T x + c_{new}$ [S2].
4.  **Stability Check:** Apply a positional correction term to the computed position $x$ to maintain numerical stability during the collapse [S1].
5.  **Validity Check:** Test if collapsing the edge to position $x$ causes any adjacent tetrahedra to flip (i.e., change the sign of their volume). If a flip occurs, disallow the edge collapse [S2].
6.  **Collapse:** Select the edge with the minimum valid error cost. Collapse the edge by merging the two vertices into one at position $x$, updating the connectivity, and recomputing quadrics for affected vertices.
7.  **Repeat:** Continue until the target vertex count or error threshold is reached.

**Pseudocode:**
```python
def compute_quadric_from_hyperplane(normal, distance):
    """
    Computes the quadric components (A, b, c) for a single hyperplane.
    normal: vector [nx, ny, nz]
    distance: scalar d
    """
    # A = n * n^T
    A = outer_product(normal, normal)
    # b = n * d
    b = scale(normal, distance)
    # c = d^2
    c = distance * distance
    return A, b, c

def accumulate_vertex_quadric(vertex):
    """
    Accumulates quadrics from all incident tetrahedra for a vertex.
    """
    A = zero_matrix(3, 3)
    b = zero_vector(3)
    c = 0.0
    
    for tet in vertex.incident_tetrahedra:
        for face in tet.faces:
            normal, distance = get_hyperplane_params(face)
            A_face, b_face, c_face = compute_quadric_from_hyperplane(normal, distance)
            A = add_matrices(A, A_face)
            b = add_vectors(b, b_face)
            c = c + c_face
            
    return A, b, c

def solve_quadric(A, b):
    """
    Solves Ax = b for x. Uses a numerically stable solver since A may not be invertible.
    """
    # Use a stable linear solver (e.g., Cholesky if positive definite, or SVD/Pseudo-inverse)
    # [G] Standard library linear algebra solver is assumed available.
    x = linear_solve(A, b)
    return x

def check_tetrahedron_flip(tetrahedron, new_vertex_position):
    """
    Checks if replacing the old vertices with new_vertex_position causes volume sign change.
    """
    # Recompute volume of affected tetrahedra with new position
    # If any volume changes sign (becomes negative), return True (flip detected)
    for tet in affected_tetrahedra:
        if tet.volume_sign_changes(new_vertex_position):
            return True
    return False

def simplify_tetrahedral_mesh(mesh, target_vertices):
    """
    Main simplification loop.
    """
    # Initialize quadrics for all vertices
    for vertex in mesh.vertices:
        vertex.quadric = accumulate_vertex_quadric(vertex)
        
    edge_queue = PriorityQueue()
    for edge in mesh.edges:
        cost = calculate_edge_collapse_cost(edge)
        edge_queue.push(edge, cost)
        
    while mesh.vertex_count > target_vertices and not edge_queue.empty():
        edge = edge_queue.pop_min()
        
        # Check if edge is still valid (not already collapsed)
        if not edge.is_valid():
            continue
            
        # Calculate optimal position
        A_new = add_matrices(edge.v1.quadric.A, edge.v2.quadric.A)
        b_new = add_vectors(edge.v1.quadric.b, edge.v2.quadric.b)
        
        # [G] Positional correction term is applied here as per [S1]
        optimal_pos = solve_quadric(A_new, b_new)
        optimal_pos = apply_positional_correction(optimal_pos)
        
        # Check for tetrahedron flips
        if check_tetrahedron_flip(edge, optimal_pos):
            continue
            
        # Perform collapse
        collapse_edge(edge, optimal_pos)
        
        # Update quadrics for affected vertices and re-queue edges
        update_quadrics_and_queue(mesh, edge)
```

**Parameters:**
*   **Target Vertex Count:** The desired number of vertices in the simplified mesh. Not given in the sources.
*   **Error Threshold:** Maximum allowable quadric error per collapse. Not given in the sources.
*   **Boundary Weighting:** Weight applied to boundary face errors to preserve volume boundaries. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Non-invertible Matrix:** The matrix $A$ is not necessarily invertible. A numerically stable linear solver must be chosen [S2].
*   **Tetrahedron Flips:** Collapsing to the optimal point may cause tetrahedra to flip (change volume sign). This must be tested and disallowed if it occurs [S2].
*   **Numerical Stability:** A positional correction term is incorporated during vertex/edge collapse to maintain stability [S1].

## Subtopics

### Streaming Simplification
An out-of-core technique for simplifying large tetrahedral meshes by combining streaming meshes with quadric-based simplification, allowing processing of meshes larger than memory [S2].

### Field-Aware Simplification
Extends the quadric metric to 4D to optimize field approximation along with geometric position, treating vertices as points on a 3D manifold embedded in $\mathbb{R}^4$ [S2].

*   **Limitations:** Requires robust linear solver, flip detection adds overhead.
*   **When to use:** When simplifying tetrahedral meshes for volume rendering or simulation where field data preservation is important.
*   **When not to use:** For surface-only meshes where triangular simplification is sufficient.

## Background
The quadric error metric was proposed by Garland and Zhou [14] (Garland and Zhou, 2005) [S2]. The specific implementation for tetrahedral meshes with streaming capabilities was described in "Streaming Simplification of Tetrahedral Meshes" (2007) [S2]. It is used in segment-based tetrahedral meshing and rendering [S1].
