# Adaptive Clustering

Also called: Data-dependent hierarchical clustering, Hierarchical Adaptive Clustering

## Overview
Adaptive clustering is a technique for generating a data-dependent hierarchy that represents the inherent topological and geometric structures of scattered data by recursively partitioning a set of samples into smaller groups (clusters) based on spatial adjacency or correlation of associated function values [S1, unofficial]. It solves the problem of multiresolution representation for scattered data without requiring a pre-existing grid structure or connectivity between points [S1, unofficial]. Unlike mesh-reduction algorithms that rely on explicit connectivity, this method builds a "top-down" hierarchy where coarse levels require less computation, allowing for efficient approximation of smooth surfaces or volumetric data [S1, unofficial]. It serves as the foundational framework for specific variants like [PCA-based Clustering](5048-pca-based-clustering.md) and [Adaptive Clustering with Error-Bisector Splitting](6211-adaptive-clustering-with-error-bisector-splitting.md).

## How it works
**Inputs and Outputs**
*   **Input:** A set $P$ of $n$ points in $s$-dimensional space with associated $t$-dimensional function values:
    $$P = \{(\mathbf{p}_i, f_i) \mid \mathbf{p}_i \in \mathbb{R}^s, f_i \in \mathbb{R}^t, i = 1, \dots, n\}$$
    The domain $D \subset \mathbb{R}^s$ is a compact region containing all $\mathbf{p}_i$. The dimension $s$ is typically at most 4 (e.g., for time-varying volumetric data), while $t$ can be large [S1, unofficial].
*   **Output:** A hierarchy of levels $L_j$ for $j = 0, 1, \dots$, where each level is defined as:
    $$L_j = \{(\tau_k^j, \tilde{f}_k^j, \varepsilon_k^j) \mid k = 1, \dots, n_j\}$$
    Here, $\tau_k^j$ are tiles forming a partition of domain $D$, $\tilde{f}_k^j: \tau_k^j \to \mathbb{R}^t$ are approximating functions, and $\varepsilon_k^j$ are estimated approximation errors [S1, unofficial].

**Data Structures**
*   **Point Set:** List of tuples $(\mathbf{p}_i, f_i)$.
*   **Level Structure:** List of cluster objects. Each cluster object contains:
    *   $\tau_k^j$: The geometric tile (e.g., Voronoi cell or convex hull).
    *   $\tilde{f}_k^j$: The approximation function (e.g., polynomial, constant, or interpolant).
    *   $\varepsilon_k^j$: The scalar residual error.
    *   $n_k^j$: The count of points within $\tau_k^j$.

**Algorithm Steps**
1.  **Initialization:** Start with a coarse approximation level $L_0$. This typically involves a single tile covering the entire domain $D$ or a small number of initial clusters [S1, unofficial].
2.  **Approximation:** For each tile $\tau_k^j$ in the current level $L_j$, compute the approximating function $\tilde{f}_k^j$ such that it satisfies the condition:
    $$\tilde{f}_k^j(\mathbf{p}_i) \approx f_i \quad \forall \mathbf{p}_i \in \tau_k^j$$
    The specific form of $\tilde{f}_k^j$ depends on the variant (e.g., Sibson's interpolant for Voronoi-based clustering, quadratic polynomials for error-bisector splitting) [S1, unofficial].
3.  **Residual Calculation:** Compute the local residual $\varepsilon_k^j$ for each tile using the $L_p$ norm:
    $$\varepsilon_k^j = \left( \frac{1}{n_k^j} \sum_{\mathbf{p}_i \in \tau_k^j} \|\tilde{f}_k^j(\mathbf{p}_i) - f_i\|^p \right)^{\frac{1}{p}}$$
    where $n_k^j = |\{\mathbf{p}_i \in \tau_k^j\}|$, $p \in [1, \infty]$, and $\|\cdot\|$ is the Euclidean norm in $\mathbb{R}^t$. For $p=\infty$, $\varepsilon_k^j$ is the maximal error in the tile [S1, unofficial].
4.  **Global Error Check:** Calculate the global error for level $L_j$:
    $$\varepsilon^j = \left( \frac{1}{n} \sum_{k=1}^{n_j} n_k^j (\varepsilon_k^j)^p \right)^{\frac{1}{p}}$$
    If $\varepsilon^j$ is below a prescribed error bound or the number of clusters $n_j$ meets a limit, terminate [S1, unofficial].
5.  **Refinement:** Identify tiles with large residuals. Generate the next level $L_{j+1}$ by refining these tiles. The refinement strategy splits tiles into smaller sub-tiles, ensuring that the approximation improves in regions with high error [S1, unofficial].
6.  **Iteration:** Repeat steps 2–5 until convergence. Convergence is reached when every tile contains exactly one data point or when the number of points in every tile is sufficiently low to provide zero residuals [S1, unofficial].

**Parameters**
*   **$p$:** The norm exponent for error calculation. Typical values are $p=2$ (mean squared error) or $p=\infty$ (max error) [S1, unofficial].
*   **$n_{max}$:** In optimized variants, the maximum number of points used to determine an approximating function. If a tile contains more than $n_{max}$ points, $n_{max}$ points are selected randomly [S1, unofficial].

## Subtopics

### [PCA-based Clustering](5048-pca-based-clustering.md)
Partitions points by aligning splitting hyperplanes with principal axes of the point distribution. It is chosen when cluster shape quality is critical for surface reconstruction, ensuring splits are orthogonal to the longest axis of the point cloud.

### [Adaptive Clustering with Error-Bisector Splitting](6211-adaptive-clustering-with-error-bisector-splitting.md)
Uses quadratic polynomial approximations to guide subdivision based on approximation residuals. It is chosen for efficiently approximating smooth surfaces with minimal clusters for a given error tolerance, outperforming PCA-based splitting on data with directional curvature.

### [Hierarchical Density-based Clustering](10952-hierarchical-density-based-clustering.md)
Generates a hierarchy of nested clusters based on density estimates in multi-dimensional feature space. It is chosen for interactive exploration in cluster space, scaling better to high dimensionality than parallel coordinates and providing an explicit cluster tree visualization.

### Hierarchy Interaction Framework
A framework enabling real-time interaction with the cluster hierarchy, allowing users to change hierarchy levels, similarity measures, and apply constraints (fixing, splitting, joining) without re-running the algorithm [S2]. It is chosen when intuitive exploration and manual adjustment of the hierarchy are required [S2].

### Adaptive Clustering Optimization
Modifications to reduce computational cost from $O(n \log m)$ to expected linear time for large-scale datasets [S1, unofficial]. It is chosen when processing large datasets where standard clustering is too slow, using batch refinement and random point sampling [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The standard computational cost for both hierarchical Voronoi and BSP-tree-based adaptive clustering is $O(n \log m)$ for $n$ data points and $m$ clusters [S1, unofficial]. Optimized variants reduce this to expected linear time for large-scale datasets [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** The method is efficient for smooth two-manifold geometries and terrain modeling [S1, unofficial]. It allows coarse levels to be computed quickly, making it suitable for progressive visualization [S1, unofficial].
*   **Strengths:** Does not require a grid structure; supports "top-down" construction; allows for real-time interaction with the hierarchy; efficient for smooth surfaces [S1, unofficial][S2].
*   **Limitations:** Standard variants may be slow for very large datasets ($O(n \log m)$); the choice of error norm impacts efficiency and quality; residuals might not exactly satisfy prescribed error bounds in optimized variants [S1, unofficial][S2].
*   **When to Use:** When dealing with scattered data without connectivity; when multiresolution representation is needed for visualization or compression; when interactive exploration of the data hierarchy is beneficial [S1, unofficial][S2].
*   **When Not to Use:** When a regular grid structure is already available and efficient; when strict error bounds are required without approximation [S1, unofficial].

## Background
Adaptive clustering was introduced as a general concept for multiresolution modeling, providing a wavelet transform for smooth two-manifold geometries [S1, unofficial]. It was applied to recover topological structures of two-manifold surfaces from scattered data points in 3D space [S1, unofficial]. The method is used in isosurface compression and visualization, terrain modeling, and automating transfer function design for volume rendering by clustering material boundaries [S1, unofficial][S2]. The foundational work is attributed to the author of "Multiresolution modeling for scientific visualization" [S1, unofficial].
