# Adaptive Resolution Data Generation

Also called: AR Data Generation

## Overview
Adaptive Resolution Data Generation creates a multiresolution volume representation by recursively sampling and pruning data based on local variance [S1, unofficial]. It solves the problem of storing and rendering large volume datasets by eliminating redundant or uninteresting regions, thereby reducing memory usage and rendering time [S1, unofficial]. It differs from static multiresolution methods by dynamically omitting octree nodes where the scalar value range is below a threshold, rather than storing all levels of detail [S1, unofficial].

## How it works
**Inputs:**
- A 3D volume dataset of size $N^3$ (e.g., $128^3$) [S1, unofficial].
- A scalar threshold $\Delta$ for pruning [S1, unofficial].

**Outputs:**
- An octree structure where leaf nodes represent the finest resolution or pruned regions [S1, unofficial].
- Error data associated with coarse representations (see [Adaptive-Resolution Data Representation and Description](7175-adaptive-resolution-data-representation-and-description.md)) [S1, unofficial].

**Data Structures:**
- **Octree:** Each node represents a cubic region [S1, unofficial].
- **Level Index:** $L=0$ is the finest level (original data), $L_{max}$ is the coarsest root [S1, unofficial]. For $N=128$, $L_{max}=7$ [S1, unofficial].
- **Vertex Values:** Each cube at level $L>0$ has 8 vertices sampled from level $L-1$ [S1, unofficial].

**Steps:**
1. **Initial Sampling:** Start with Level 0 containing the full $N^3$ dataset [S1, unofficial].
2. **Recursive Coarsening:** For each node at level $L$, generate the parent node at level $L+1$ by sampling every other data point in each dimension [S1, unofficial]. This reduces the resolution by a factor of 2 in each axis [S1, unofficial]. A cube at level $L+1$ contains 8 vertices derived from level $L$ [S1, unofficial].
3. **Pruning Check:** For each node at level $L+1$, calculate the difference between the maximum and minimum scalar values among its 8 vertices:
   $$ \delta = \max(v_i) - \min(v_i) $$
   where $v_i$ are the vertex values [S1, unofficial].
4. **Pruning Decision:** If $\delta < \Delta$, prune all children of the current node from the octree structure [S1, unofficial]. The node becomes a leaf, and no further subdivision or storage of finer details occurs for that region [S1, unofficial].
5. **Termination:** Repeat until the root node (Level 7 for $128^3$) is reached [S1, unofficial].

**Parameters:**
- $\Delta$: Pruning threshold. Not given in the sources.
- $N$: Initial resolution. Typically $128^3$ in the source example [S1, unofficial].

**Edge Cases:**
- **Zero Variance:** If all vertex values are identical, $\delta=0$, and the node is pruned if $\Delta > 0$ [S1, unofficial].
- **Boundary Conditions:** Sampling every other point assumes a regular grid [S1, unofficial]. Irregular grids require different sampling strategies [G].

**Pseudocode:**
```python
import math

def generate_ar_data(volume, threshold):
    """
    volume: 3D array of shape (N, N, N)
    threshold: float, delta for pruning
    Returns: Octree root node
    """
    N = volume.shape[0]
    max_level = int(math.log2(N))  # 7 for N=128

    class OctreeNode:
        def __init__(self, level, x, y, z, size):
            self.level = level
            self.x, self.y, self.z = x, y, z
            self.size = size
            self.vertex_values = []
            self.children = None
            self.is_leaf = True

    def build(level, x, y, z, size):
        node = OctreeNode(level, x, y, z, size)
        if level == 0:
            node.vertex_values = [volume[x, y, z]]
            return node

        half = size // 2
        # Sample every other data point in each dimension to get 8 vertices
        vertex_values = []
        for dx in (0, 1):
            for dy in (0, 1):
                for dz in (0, 1):
                    vx, vy, vz = x + dx * half, y + dy * half, z + dz * half
                    vertex_values.append(volume[vx, vy, vz])

        delta = max(vertex_values) - min(vertex_values)
        if delta < threshold:
            node.vertex_values = vertex_values
            node.is_leaf = True
            return node

        node.vertex_values = vertex_values
        node.is_leaf = False
        node.children = []
        for dx in (0, 1):
            for dy in (0, 1):
                for dz in (0, 1):
                    cx, cy, cz = x + dx * half, y + dy * half, z + dz * half
                    node.children.append(build(level - 1, cx, cy, cz, half))
        return node

    return build(max_level, 0, 0, 0, N)
```

## Subtopics

### [Hierarchical Voronoi Diagrams](4112-hierarchical-voronoi-diagrams.md)
Hierarchical Voronoi Diagrams is an adaptive clustering method for the multiresolution representation of scattered data. It constructs a hierarchy of Voronoi diagrams from nested subsets of the original set of points. Unlike mesh-reduction algorithms, it does not require a grid structure connecting the given data points, making it suitable for unstructured datasets.

## Operating characteristics
- **Time Complexity:** Generation is $O(N^3)$ for the initial sampling, with pruning reducing the number of nodes stored [S1, unofficial]. The pruning check is $O(1)$ per node [G].
- **Memory Complexity:** Reduced compared to full multiresolution storage due to pruning [S1, unofficial]. The amount of memory saved depends on the threshold $\Delta$ and data redundancy [G].
- **Performance:** Saves memory space and computation time during rendering by eliminating uninteresting cubes [S1, unofficial].
- **Strengths:** Simple to implement; effective for data with high redundancy [G].
- **Limitations:** Requires regular grid structure; threshold selection is critical [G].

## Background
Originated in the context of scientific volume data analysis, specifically for IsoSurface Rendering of Adaptive Resolution Data [S1, unofficial]. The method was developed to handle large volume datasets by exploiting data redundancy and focusing on areas of interest [S1, unofficial].
