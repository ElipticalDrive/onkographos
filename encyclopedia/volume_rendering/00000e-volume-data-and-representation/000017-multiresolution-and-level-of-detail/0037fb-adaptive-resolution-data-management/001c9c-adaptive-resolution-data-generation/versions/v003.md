# Adaptive Resolution Data Generation

Also called: AR Data Generation

## Overview
Adaptive Resolution Data Generation creates a multiresolution representation of volume data by combining hierarchical subsampling with error-based pruning. It solves the problem of storing and rendering large volume datasets efficiently by discarding redundant or low-detail regions. Unlike uniform multiresolution approaches, it adapts the grid density to local data variance, storing only octree nodes where the scalar range exceeds a threshold [S1, unofficial].

## How it works
**Inputs:**
- A uniform volume dataset of size $N^3$ (e.g., $128^3$).
- A scalar threshold $\Delta$ for pruning.

**Outputs:**
- An octree data structure where leaf nodes represent volume regions at varying resolutions.
- Error data associated with coarse representations (see [S1, unofficial]).

**Data Structures:**
- **Octree Node:** Represents a cubic region. Contains scalar min/max values for its region.
- **Levels:** Level 0 is the finest resolution ($N^3$). Level $k$ has resolution $(N/2^k)^3$. Level 7 is the root for $N=128$.

**Steps:**
1. **Generate Coarse Levels:** Create uniform subsampled grids for levels $1$ to $L_{max}$. For each dimension, sample every second data point from the finer level to generate the coarser level [S1, unofficial].
   - Level 0: Original data ($128^3$).
   - Level $k$: Data from Level $k-1$ sampled at stride 2.
   - A cube at level $k$ represents $2 \times 2 \times 2 = 8$ cubes from level $k-1$.
2. **Build Octree:** Traverse the hierarchy. For each node at level $k$, calculate the difference between the maximum and minimum scalar vertex values in its region [S1, unofficial].
3. **Prune:** If the difference is less than $\Delta$, prune all children of the current node. The node becomes a leaf at the current resolution [S1, unofficial].
4. **Store:** If the difference is $\ge \Delta$, keep the children and recurse. Store the coarse data for the node if it is a leaf.

**Pseudocode:**
```python
def generate_ar_data(volume, threshold):
    """
    volume: 3D array of shape (N, N, N)
    threshold: scalar delta for pruning
    Returns: Octree structure
    """
    N = volume.shape[0]
    levels = [volume]
    
    # Step 1: Generate uniform coarse levels
    current_vol = volume
    while current_vol.shape[0] > 1:
        # Sample every other point in each dimension
        next_vol = current_vol[::2, ::2, ::2]
        levels.append(next_vol)
        current_vol = next_vol
        
    # levels[0] is finest, levels[-1] is coarsest (root)
    
    # Step 2 & 3: Build octree and prune
    # Root is at level 7 for N=128
    root = build_octree(levels, 0, (0,0,0), N, threshold)
    return root

def build_octree(levels, level_idx, origin, size, threshold):
    """
    Recursively build octree.
    level_idx: index in levels list (0 is finest)
    origin: (x, y, z) start of this block
    size: side length of this block
    """
    if level_idx >= len(levels):
        return None # Should not happen for valid N=2^k
    
    # Get the coarse data for this level
    # Note: levels[level_idx] contains the data for this resolution
    # We need to extract the specific block defined by origin and size
    # However, the source implies we check the scalar range of the 
    # region represented by the node.
    
    # Extract region from the coarsest available level that covers this node?
    # The source says "difference between max and min vertex scalar values".
    # We use the finest level (0) to compute exact min/max for the region,
    # or the level corresponding to the node's resolution.
    # The source implies checking the node's content against the threshold.
    
    # Let's assume we check the scalar range of the region in the finest level
    # to determine if it needs further subdivision.
    # Region bounds:
    x0, y0, z0 = origin
    x1, y1, z1 = x0 + size, y0 + size, z0 + size
    
    region_data = levels[0][x0:x1, y0:y1, z0:z1]
    scalar_min = region_data.min()
    scalar_max = region_data.max()
    
    # Step 3: Prune condition
    if (scalar_max - scalar_min) < threshold:
        # Prune children. This node is a leaf.
        # Store the coarse representation if needed, or just the min/max
        return NodeLeaf(min=scalar_min, max=scalar_max, level=level_idx)
    
    # Step 4: Keep children
    children = []
    half_size = size // 2
    if half_size == 0:
        # Leaf at finest level
        return NodeLeaf(min=scalar_min, max=scalar_max, level=level_idx)
        
    # Generate 8 children
    for dx in [0, 1]:
        for dy in [0, 1]:
            for dz in [0, 1]:
                child_origin = (x0 + dx * half_size, 
                                y0 + dy * half_size, 
                                z0 + dz * half_size)
                child = build_octree(levels, level_idx, child_origin, half_size, threshold)
                if child is not None:
                    children.append(child)
                    
    return NodeInternal(children=children, min=scalar_min, max=scalar_max, level=level_idx)
```

**Parameters:**
- $\Delta$: Pruning threshold. Typical value not given in sources.
- $N$: Volume dimension. Example: $128^3$.

**Edge Cases:**
- If $N$ is not a power of 2, subsampling logic may require adjustment [G].
- If $\Delta = 0$, no pruning occurs, resulting in full resolution storage.
- If $\Delta$ is very large, only the root node is kept.

## Subtopics

### [Hierarchical Voronoi Diagrams](4112-hierarchical-voronoi-diagrams.md)
Hierarchical Voronoi Diagrams is an adaptive clustering method for the multiresolution representation of scattered data. It constructs a hierarchy of Voronoi diagrams from nested subsets of the original set of points. Unlike mesh-reduction algorithms, it does not require a grid structure connecting the given data points, making it suitable for unstructured datasets.

## Operating characteristics
- **Time Complexity:** Generating coarse levels is $O(N^3)$. Building the octree is $O(N^3)$ in the worst case (no pruning).
- **Memory Complexity:** Depends on the threshold. Can be significantly less than $O(N^3)$ if pruning is effective.
- **Performance:** Saves memory and computation time by eliminating uninteresting cubes [S1, unofficial].
- **Strengths:** Simple generation; adapts to data redundancy.
- **Limitations:** Uniform subsampling may introduce aliasing; threshold selection is critical.

## Background
Originated in the context of scientific volume visualization. The method is described in "IsoSurface Rendering of Adaptive Resolution Data" [S1, unofficial]. It addresses the need for efficient storage and rendering of large volume datasets by exploiting data redundancy.
