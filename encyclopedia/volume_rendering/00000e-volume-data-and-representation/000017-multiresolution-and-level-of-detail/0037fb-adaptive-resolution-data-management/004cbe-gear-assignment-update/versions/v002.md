# Gear Assignment Update

Also called: Adaptive Gear Assignment, Gear Level Update

## Overview
Gear Assignment Update is an alternating optimization step that identifies poorly rendered regions in a spatio-temporal volume and increments their gear level to increase sampling density [S1]. It differs from sibling methods by using a semantic segmentation model (SAM) guided by photometric and feature loss maps to generate precise upshift masks, rather than relying solely on geometric error or fixed thresholds [S1].

## How it works
**Inputs:**
*   Current radiance field parameters $\Theta$ (embedding functions $h'_i, k'_i$).
*   Current gear assignment $g(x, t)$.
*   Ground truth RGB images and SAM encoder features $S(r)$ for sampled viewpoints and time steps.
*   Parameters: $\lambda$ (SAM loss weight), $k$ (top patches count), $\alpha$ (learning rate).

**Outputs:**
*   Updated radiance field parameters $\Theta$.
*   Updated gear assignment $g(x, t)$.

**Data Structures:**
*   **Gear Assignment:** A function $g(x, t)$ mapping spatial-temporal coordinates to discrete gear levels. Initialized to $g(x, t) = 1$ for all $x, t$ [S1].
*   **Rendering Loss Map:** A 2D map $L(r)$ per viewpoint/time step.
*   **Upshift Mask:** A binary mask $\hat{S}(r)$ indicating regions to increment gear.

**Steps:**
1.  **Sample and Render:** Sample a set of viewpoints and time steps. Render 2D RGB images and SAM semantic features for each [S1].
2.  **Compute Loss Map:** For each rendered view $r$, compute the rendering loss map $L(r)$ [S1]:
    $$L(r) := L_{\text{pho}}(r) + \lambda L_{\text{SAM}}(r)$$
    where $L_{\text{pho}}(r)$ is the photometric loss and $L_{\text{SAM}}(r)$ is the semantic embedding loss [S1]. The SAM loss is defined as:
    $$L_{\text{SAM}} = \sum_{r \in R} \| \hat{S}(r) - S(r) \|_2^2$$
    where $\hat{S}(r) = \sum_{i=1}^{N} \alpha_i s_i$ is the predicted 4D SAM embedding field [S1].
3.  **Patchify and Select Prompts:** Patchify the loss map $L(r)$. Identify patches with the top-$k$ largest average loss (positive prompts) and top-$k$ smallest average loss (negative prompts) [S1]. Use the center coordinates of these patches as prompts [S1].
4.  **Estimate Upshift Mask:** Feed the ground truth RGB images and the positive/negative prompts into the SAM decoder to estimate an upshift mask $\hat{S}(r)$ [S1].
5.  **Sample Points:**
    *   For each pixel in the upshift mask, trace a ray from camera center $o$ in direction $d$.
    *   Sample points along these rays to form the set $S_{\text{upshift}} = \{(x_i, t_i)\}_{i=1}^{N_{\text{upshift}}}$ [S1].
    *   Sample points from unmasked regions (rays not in the upshift mask) to form the set $S_{\text{stay}} = \{(x_i, t_i)\}_{i=1}^{N_{\text{stay}}}$ [S1].
6.  **Update Parameters:** Update $\Theta$ via gradient descent to minimize the gear assignment objective $L_{\text{upshift}}$ [S1]:
    $$\Theta \leftarrow \Theta - \alpha \nabla_\Theta L_{\text{upshift}}$$
    The objective function is:
    $$L_{\text{upshift}} = \frac{1}{N_{\text{upshift}}} \sum_{(x,t) \in S_{\text{upshift}}} \| g(x, t; \Theta) - (p(x, t) + 1) \|^2_2 + \frac{\lambda_{\text{stay}}}{N_{\text{stay}}} \sum_{(x,t) \in S_{\text{stay}}} \| g(x, t; \Theta) - p(x, t) \|^2_2$$
    where $p(x, t)$ is the current gear value [S1]. This pushes $g(x, t)$ for upshift points towards incremented values and keeps $g(x, t)$ for stay points unchanged [S1].

**Pseudocode:**
```python
def gear_assignment_update(radiance_field_params, gear_assignment, ground_truth_images, sam_features, lambda_val, k, alpha):
    # 1. Sample viewpoints and time steps
    sampled_views = sample_views_and_times()
    
    upshift_points = []
    stay_points = []
    
    for view in sampled_views:
        # 2. Render 2D images and SAM features
        rendered_rgb, rendered_sam = render_radiance_field(radiance_field_params, view)
        gt_rgb = ground_truth_images[view]
        gt_sam = sam_features[view]
        
        # 3. Compute rendering loss map
        # L_pho is typically MSE between rendered and GT RGB
        l_pho = mean_squared_error(rendered_rgb, gt_rgb)
        # L_sam is MSE between predicted and GT SAM embeddings
        l_sam = mean_squared_error(rendered_sam, gt_sam)
        loss_map = l_pho + lambda_val * l_sam
        
        # 4. Patchify and find top-k patches
        patches = patchify(loss_map)
        top_k_large = get_top_k_patches(patches, k, 'largest')
        top_k_small = get_top_k_patches(patches, k, 'smallest')
        
        # 5. Get prompts from patch centers
        positive_prompts = [patch.center for patch in top_k_large]
        negative_prompts = [patch.center for patch in top_k_small]
        
        # 6. Estimate upshift mask using SAM decoder
        # Note: SAM decoder requires specific input format for prompts
        upshift_mask = sam_decoder_decode(gt_rgb, positive_prompts, negative_prompts)
        
        # 7. Sample points for upshift and stay sets
        for pixel in pixels_in_mask(upshift_mask):
            ray_direction = get_ray_direction(view, pixel)
            ray_points = sample_along_ray(view.camera_center, ray_direction)
            upshift_points.extend(ray_points)
            
        for pixel in pixels_outside_mask(upshift_mask):
            ray_direction = get_ray_direction(view, pixel)
            ray_points = sample_along_ray(view.camera_center, ray_direction)
            stay_points.extend(ray_points)
            
    # 8. Compute loss and update parameters
    # L_upshift calculation
    loss_upshift = 0.0
    if upshift_points:
        for x, t in upshift_points:
            current_gear = gear_assignment(x, t)
            # Target is current_gear + 1
            target = current_gear + 1
            # g(x, t; Theta) is the predicted gear from embedding functions
            predicted_gear = predict_gear(radiance_field_params, x, t)
            loss_upshift += squared_error(predicted_gear, target)
        loss_upshift /= len(upshift_points)
        
    if stay_points:
        lambda_stay = 1.0 # Not given in sources, assumed 1.0 for balance or default
        for x, t in stay_points:
            current_gear = gear_assignment(x, t)
            target = current_gear
            predicted_gear = predict_gear(radiance_field_params, x, t)
            loss_upshift += lambda_stay * squared_error(predicted_gear, target)
        loss_upshift /= len(stay_points)
        
    # Gradient descent step
    gradients = compute_gradients(loss_upshift, radiance_field_params)
    updated_params = radiance_field_params - alpha * gradients
    
    return updated_params
```

**Parameters:**
*   $\lambda$: Weight for SAM loss. Typical value: 0.01 [S1].
*   $k$: Number of top patches for prompts. Typical value: 3 [S1].
*   $\alpha$: Learning rate. Typical value: 0.02 [S1].

**Edge Cases:**
*   Precision: The gear assignment $g(x, t)$ is derived from embedding functions, so updates to $\Theta$ indirectly modify the gear levels [S1].
*   Boundaries: The method assumes rays can be traced from camera centers through pixels [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of sampled viewpoints, time steps, and the cost of SAM inference and ray sampling. Training takes approximately 2.5 hours per 100-frame chunk on a system with 24 GB RAM [S1].
*   **Memory Complexity:** Requires storing 4D feature volumes with embedding dimension $M=32$ [S1].
*   **Strengths:** Adapts sampling density to motion and rendering error, improving quality in dynamic regions [S1].
*   **Limitations:** Requires SAM inference, adding computational overhead. Performance depends on the quality of the SAM decoder and prompts [S1].
*   **When to use:** When rendering dynamic scenes with varying motion complexity where fixed sampling is inefficient [S1].
