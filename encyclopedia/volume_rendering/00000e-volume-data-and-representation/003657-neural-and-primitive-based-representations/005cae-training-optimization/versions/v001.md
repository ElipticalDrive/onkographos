# Training Optimization
Also called: Joint Optimization of Network Weights, Feature Grids, and Latent Codes

## Overview
This method jointly optimizes neural network weights, feature grids, and shape-specific latent codes to reconstruct 3D geometry and appearance from input data. It distinguishes itself from standard implicit field training by treating the latent codes as learnable parameters alongside the network and grid, enabling a single shared network to represent multiple distinct shapes without retraining the encoder or network weights for each instance.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Training data consisting of $J$ shapes, each represented by depth maps with object masks and known camera poses.
*   **Outputs:** Optimized SDF network weights $\Theta_s$, DDF network weights $\Theta_d$, feature grids $M$, and latent codes $Z$.

**Data Structures:**
*   $\Theta_s$: Learnable parameters of the Signed Distance Function (SDF) model.
*   $\Theta_d$: Learnable parameters of the Directional Difference Function (DDF) model.
*   $M$: Feature grids, defined as $M = (M_s, M_d)$.
    *   $M_s$: SDF feature grids, $M_s = \{M^s_i \mid i \in \{xy, yz, zx\}\}$.
    *   $M_d$: DDF feature grids, $M_d = \{M^d_i \mid i \in \{pxpy, \dots, rzrx\}\}$.
*   $Z$: Set of latent codes for the $J$ training shapes, $Z = \{z_i \mid i = 1 \dots J\}$.

**Loss Function:**
The total loss combines several components with weights $w_s, w_d, w_\sigma, w_{tv}, w_{ts}, w_l$:
$$ \mathcal{L}_{total} = w_s \mathcal{L}_{SDF} + w_d \mathcal{L}_{DDF} + w_\sigma \mathcal{L}_{\sigma} + w_{tv} \mathcal{L}_{TV} + w_{ts} \mathcal{L}_{TS} + w_l \mathcal{L}_{latent} $$

Specific silhouette losses are defined as:
$$ \mathcal{L}_{S_{s_+}}(m) = \| \langle s, m \rangle \|_1 $$
$$ \mathcal{L}_{S_{s_-}}(m) = \| |\langle s, 1-m \rangle| - \tau \|_1 $$

**Algorithm:**
1.  Initialize $\Theta_s, \Theta_d, M, Z$ randomly or via standard initialization.
2.  For each training iteration:
    a. Sample a shape index $j \in \{1 \dots J\}$.
    b. Retrieve latent code $z_j$ and corresponding depth map/mask.
    c. Sample points $\mathbf{x}$ along rays from the camera pose.
    d. Query SDF and DDF models using $\Theta_s, \Theta_d, M, z_j$ to get predictions.
    e. Compute $\mathcal{L}_{total}$ based on predictions and ground truth.
    f. Update $\Theta_s, \Theta_d, M, z_j$ using gradient descent.
3.  Repeat until convergence.

**Inference (Reconstruction):**
For a new single-view depth map:
1.  Keep $\Theta_s, \Theta_d, M$ fixed.
2.  Optimize only the latent code $z$ to minimize the reconstruction loss.
3.  No sphere tracing is required during optimization [S1].

## Operating characteristics
**Time and Memory Complexity:**
Joint optimization increases memory usage due to the storage of latent codes $Z$ and the simultaneous gradient updates for network weights, grids, and codes. Time complexity per iteration is higher than single-shape training due to the larger parameter set.

**Strengths and Limitations:**
*   **Strengths:** Enables few-shot or single-shot reconstruction of new shapes by optimizing only the latent code. Avoids the need for per-shape network retraining or complex encoder networks.
*   **Limitations:** Requires careful tuning of regularization weights ($w_{tv}, w_{ts}, w_l$) to prevent overfitting or degenerate latent codes. Performance depends on the capacity of the shared network and grids to represent diverse shapes.

## Background
Originated in the context of fast inverse rendering and 3D reconstruction from single-view depth maps. The method leverages an autodecoder framework where the network acts as a prior, and latent codes capture shape-specific variations.
