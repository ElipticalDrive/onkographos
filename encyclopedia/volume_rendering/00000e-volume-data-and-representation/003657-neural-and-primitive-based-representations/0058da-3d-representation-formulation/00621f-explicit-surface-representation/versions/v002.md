# Explicit Surface Representation

Also called: Parametric surface

## Overview
Explicit surface representation defines a 3D surface as the graph of a function mapping a 2D domain directly to 3D Euclidean space [S1, unofficial]. It associates each point in the domain with a corresponding 3D coordinate [S1, unofficial]. Unlike implicit representations that define volume occupancy or density, explicit representations directly output coordinates [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A set of 2D domain coordinates $\mathbf{u} = (u, v)$ or $\mathbf{x} = (x, y)$ within a defined domain $\tilde{\mathbf{D}}$ [G].
- Output: A 3D coordinate vector $\mathbf{p} \in \mathbb{R}^3$ representing the point on the surface [S1, unofficial].

**Data Structures:**
- The surface $S_{explicit}$ is defined mathematically as a set of points [S1, unofficial]. In implementation, this is typically realized as a function $f_{explicit}$ or a parametric function $f_{parametric}$ that computes $\mathbf{p}$ from $\mathbf{u}$ [G].
- For discrete approximations (e.g., heightmaps), the domain is discretized into a grid, and the output is a 2D array of height values or 3D vertex positions [G].

**Formulas:**
The explicit surface using an explicit function $f_{explicit}(\cdot) \in \mathbb{R}$ in Euclidean space is defined as [S1, unofficial]:
$$
S_{explicit} = \left\{ \begin{pmatrix} x \\ y \\ f_{explicit}(x, y) \end{pmatrix} \in \mathbb{R}^3 \right\}
$$
This can be generalized as a parametric function $f_{parametric}(\cdot) \in \mathbb{R}^3$ [S1, unofficial]:
$$
S_{explicit}^* = \left\{ \begin{pmatrix} u \\ v \\ f_{parametric}(u, v) \end{pmatrix} \in \mathbb{R}^2 \right\}
$$
Note: The source notation $\in \mathbb{R}^2$ in the second formula refers to the domain dimensionality [S1, unofficial].

**Steps:**
1. Define the 2D domain $\tilde{\mathbf{D}}$ (e.g., a square $[0,1]^2$ or a rectangular grid) [G].
2. For each point $\mathbf{u} = (u, v)$ in the domain:
   a. Evaluate the explicit function $f_{explicit}(u, v)$ or parametric function $f_{parametric}(u, v)$ [G].
   b. Construct the 3D point $\mathbf{p} = (u, v, f(u, v))$ or $\mathbf{p} = f_{parametric}(u, v)$ [G].
3. Store or render the resulting set of points $\mathbf{p}$ [G].

**Parameters:**
- Domain resolution: The granularity of the input grid $(u, v)$ [G].
- Function type: Linear, polynomial, or neural network-based $f$ [G].

**Edge Cases and Pitfalls:**
- The domain $\tilde{\mathbf{D}}$ can be restricted for all representations [S1, unofficial].
- Not given in the sources.

**Pseudocode:**
```python
def compute_explicit_surface(f_explicit, domain_grid):
    """
    Computes 3D points for an explicit surface given a function and domain grid.
    
    Args:
        f_explicit: A callable function f(x, y) -> z.
        domain_grid: A tuple of two 2D lists (x_coords, y_coords) of shape (H, W).
                     
    Returns:
        points: A 3D list of shape (H, W, 3) containing [x, y, z] coordinates.
    """
    x_coords, y_coords = domain_grid
    h = len(x_coords)
    w = len(x_coords[0])
    points = []
    for i in range(h):
        row = []
        for j in range(w):
            x = x_coords[i][j]
            y = y_coords[i][j]
            z = f_explicit(x, y)
            row.append([x, y, z])
        points.append(row)
    return points
```

## Subtopics

### [Ray Representation](19057-ray-representation.md)
Ray Representation (Ray-Rep) encodes 3D solid objects as a set of "rods" (rays) penetrating the object along each of the three principal coordinate directions, storing intersection points (surfels) and unit normals at these points. It solves the problem of performing fast constructive solid geometry (CSG) and boolean operations on complex meshes by reducing them to simple segment operations on rays, while preserving sharp corners and edges that standard voxel grids often smooth out. Unlike voxel grids, which require checking all cells, Ray-Rep allows skipping empty space and identifying only cells intersecting the surface, making it superior for adaptive triangulation and real-time editing of high-resolution details.

### Noise Jittering for Training Stability
Adds Gaussian noise to input points during training to jitter albedo and BRDF property predictions, improving robustness and preventing overfitting to exact surface locations [S2, unofficial]. If `noise_std > 0`, generate Gaussian noise tensor scaled by `noise_std` and add it to original points [S2, unofficial]. Query the implicit surface for noise-augmented points [S2, unofficial]. Compute albedo and BRDF properties for both original and noisy points [S2, unofficial]. Return all four tensors [S2, unofficial]. Parameters include `noise_std` (standard deviation of Gaussian noise), `albedo_scale` (multiplicative scaling factor for albedo), and `albedo_bias` (additive bias for albedo) [S2, unofficial].

### Point Cloud Representation
A representation using collections of points to model shapes in the 3D space [S3]. Their major downside is that they do not contain any topological information [S3]. They can be integrated into neural networks and are a common choice for data representation [S3]. Point cloud-based approaches have lower computation cost than volumetric methods but fail to properly render surface information such as the color of a rendered pixel in case of occlusion [S3].

### Parametric Surface Terrain
Using parametric surfaces such as NURBS to create smooth terrains with little permanent storage requirements [S4, unofficial].

## Operating characteristics
- **Time Complexity:** Evaluation of $f_{explicit}$ is $O(1)$ per point [G]. Generating a dense surface requires $O(N)$ evaluations for $N$ domain points [G].
- **Memory Complexity:** $O(N)$ to store the resulting points or mesh vertices [G].
- **Strengths:** Direct coordinate output [S1, unofficial].
- **Limitations:** Not given in the sources.
- **When to use:** Not given in the sources.

## Background
Explicit surface representations are a fundamental concept in computer graphics and geometric modeling [G]. They are contrasted with implicit representations (zero-level sets) and parametric surfaces in general literature [S1, unofficial]. The distinction between explicit $z=f(x,y)$ and general parametric $\mathbf{p}(u,v)$ clarifies the domain and range of the defining functions [S1, unofficial].
