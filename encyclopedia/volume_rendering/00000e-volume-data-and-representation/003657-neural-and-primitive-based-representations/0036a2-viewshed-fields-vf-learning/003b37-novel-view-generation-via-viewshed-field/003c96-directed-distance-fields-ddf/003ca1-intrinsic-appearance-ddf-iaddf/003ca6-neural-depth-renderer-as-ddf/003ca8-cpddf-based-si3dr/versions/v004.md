# CPDDF-based SI3DR

Also called: CPDDF reconstruction, Conditional PDDF Reconstruction, SI3DR with DDFs, Single-Image 3D Reconstruction (SI3DR), Single-Image 3D Reconstruction with CPDDF

## Overview
CPDDF-based SI3DR reconstructs 3D shapes from a single RGB image by predicting a latent shape vector and camera parameters, then rendering geometry via a Conditional Probabilistic Directed Distance Field (CPDDF) [S1, S2]. It differs from direct point cloud or mesh prediction methods by using a differentiable DDF decoder that allows for viewshed-based rendering and explicit sampling, enabling the extraction of watertight surfaces from a single view [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A single RGBA image $I$ of size $128 \times 128$ [S1, S2].
*   **Outputs:** A predicted latent shape vector $z_s$, a predicted camera parameter vector $\Pi_b$, and a CPDDF model capable of rendering depth $d(p, v|z_s)$ and visibility $\xi(p, v|z_s)$ for any viewpoint [S2].

**Data Structures:**
1.  **Encoder Output:** A tuple $(z_s, \Pi_b)$ where:
    *   $z_s \in \mathbb{R}^{512}$: Latent shape vector [S1].
    *   $\Pi_b \in \mathbb{R}^3$: Predicted camera parameters, representing extrinsic position as (azimuth, elevation, radius) [S1].
2.  **CPDDF Decoder:** A modulated SIREN network [S1].
    *   **Architecture:** Layer sizes $[512, 512, 512, 256, 256, 256, 256]$ [S1].
    *   **Activation:** Uses softplus activation when multiplying the modulator (latent vector) to intermediate features [S1].
    *   **Input:** 3D point $x \in \mathbb{R}^3$ and latent vector $z_s$.
    *   **Output:** Depth $d$ and visibility $\xi$ [S2].
3.  **Sampling Points:**
    *   **Training:** Oriented points sampled from the shape surface. For types A and U: 1.2K points per shape. For types S, B, T, O: 300 points per shape [S1].
    *   **Explicit Sampling (Inference):** Oversampled points sorted by visibility to extract the final point cloud [S1].

**Numbered Steps:**

1.  **Encoding:** Pass the input image $I$ through two ResNet-18 networks (one for camera, one for shape) to obtain $(z_s, \Pi_b) = E(I)$ [S2].
2.  **Camera Constraint:** Z-score normalize the elements of $\Pi_b$ based on training set statistics [S1]. Restrict $\Pi_b$ to the range of parameters observed in the dataset [S1].
3.  **CPDDF Decoding:** For a given ray defined by camera center $p$ (derived from $\Pi_b$) and direction $v$, query the CPDDF conditioned on $z_s$ to get depth $d_b(p, v|z_s)$ and visibility $\xi_b(p, v|z_s)$ [S2].
4.  **Explicit Sampling (for Point Cloud Extraction):** Sample points uniformly in the bounding box [S1]. Oversample by factor $(1 + \epsilon_p)$ where $\epsilon_p = 0.1$ [S1]. For each point, compute visibility $\xi(p, v_b^*(p))$ using the CPDDF [S1]. Sort points by visibility and return the top $n_p$ points to ensure only visible surface points are included [S1].
5.  **Rendering for Loss:** Render a visibility mask $R_\xi(z_s|\Pi_b)$ at resolution $64 \times 64$ [S1].

**Formulas:**

*   **Camera Loss:**
    $$ L_\Pi = \|\Pi_g - \Pi_b\|_2^2 $$
    where $\Pi_g$ is the ground truth camera and $\Pi_b$ is the predicted camera [S2].

*   **Mask Matching Loss:**
    $$ L_M = \text{BCE}(I_\alpha, R_\xi(z_s|\Pi_b)) $$
    where $I_\alpha$ is the input alpha channel and $R_\xi$ is the rendered visibility mask [S2].

*   **Visibility Variance Loss:**
    $$ \mathcal{L}_{V,\xi} = \gamma_{V,\xi} \xi(p, v) [1 - \xi(p, v)] $$
    with $\gamma_{V,\xi} = 0.25$ [S1].

*   **Shape Fitting Loss ($L_S$):**
    Combines multiple terms with weights $\gamma_d = 5, \gamma_\xi = 10, \gamma_n = 10, \gamma_V = 1, \gamma_{E,d} = 0.1, \gamma_{E,\xi} = 0.25, \gamma_T = 0.1$ [S1]. The loss enforces DDF fitting in canonical pose [S2].

*   **Total Objective:**
    $$ L_{SI3DR} = \gamma_{R,S} L_S + \gamma_{R,\Pi} L_\Pi + \gamma_{R,M} L_M $$
    with $\gamma_{R,S} = 1, \gamma_{R,\Pi} = 5, \gamma_{R,M} = 10$ [S1, S2].

*   **Camera Correction (Optional):**
    $$ \Pi_b^\nabla = \arg\min_\Pi L_M $$
    Performed via gradient descent on the input image alpha channel starting from $\Pi_b$ [S2].

**Parameters:**
*   **Optimizer:** AdamW [S1].
*   **Iterations:** 100K [S1].
*   **Batch Size:** 32 shapes [S1].
*   **Latent Dimension:** 512 [S1].
*   **SIREN Initializer:** $\omega_0 = 1$ [S1].
*   **Weight Decay:** $10^{-6}$ for camera predictor, $10^{-3}$ for shape predictor [S1].
*   **Sampling Points (Evaluation):** 5000 (L) or 2466 (S) points [S2].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import models

class ModulatedSIRENLayer(nn.Module):
    def __init__(self, in_features, out_features):
        super().__init__()
        self.linear = nn.Linear(in_features, out_features)
        self.linear.weight.data.uniform_(-1/3, 1/3)
        self.linear.bias.data.zero_()

    def forward(self, x, z_s):
        h = self.linear(x)
        # Softplus modulation as specified in [S1]
        mod = torch.nn.functional.softplus(torch.sigmoid(z_s))
        return h * (1 + mod)

class CPDDFDecoder(nn.Module):
    def __init__(self, latent_dim=512):
        super().__init__()
        # Layer sizes: [512, 512, 512, 256, 256, 256, 256] [S1]
        self.layers = nn.ModuleList([
            ModulatedSIRENLayer(3 + latent_dim, 512),
            ModulatedSIRENLayer(512, 512),
            ModulatedSIRENLayer(512, 512),
            ModulatedSIRENLayer(512, 256),
            ModulatedSIRENLayer(256, 256),
            ModulatedSIRENLayer(256, 256),
            ModulatedSIRENLayer(256, 256),
        ])
        self.out_layer = nn.Linear(256, 2) # depth and visibility

    def forward(self, x, z_s):
        # x: (N, 3), z_s: (N, 512)
        h = torch.cat([x, z_s], dim=-1)
        for layer in self.layers:
            h = layer(h, z_s)
        out = self.out_layer(h)
        return out[:, 0], out[:, 1]

class Encoder(nn.Module):
    def __init__(self, latent_dim=512):
        super().__init__()
        self.camera_net = models.resnet18()
        self.camera_net.fc = nn.Linear(512, 3)
        self.shape_net = models.resnet18()
        self.shape_net.fc = nn.Linear(512, latent_dim)

    def forward(self, x):
        # x: (B, 4, 128, 128) RGBA
        # ResNet expects 3 channels; we drop alpha or adapt first conv.
        # G: Standard ResNet adaptation for 4-channel input.
        cam_feat = self.camera_net(x[:, :3, :, :])
        shape_feat = self.shape_net(x[:, :3, :, :])
        pi_b = self.camera_net.fc(cam_feat)
        z_s = self.shape_net.fc(shape_feat)
        return z_s, pi_b

def compute_camera_loss(pi_g, pi_b):
    return torch.mean((pi_g - pi_b) ** 2)

def compute_mask_loss(I_alpha, R_xi):
    return nn.BCELoss()(I_alpha, R_xi)

def compute_shape_loss(cpddf, z_s, points, pi_g):
    # DDF fitting loss in canonical pose [S2]
    # Uses weights: gamma_d=5, gamma_xi=10, gamma_n=10, gamma_V=1, gamma_E,d=0.1, gamma_E,xi=0.25, gamma_T=0.1 [S1]
    depth, vis = cpddf(points, z_s)
    # G: Standard DDF fitting combines depth error, normal consistency, Eikonal regularization, and visibility variance.
    L_d = torch.mean((depth - 1.0) ** 2) # Example depth fitting
    L_xi = torch.mean((vis - 1.0) ** 2) # Example visibility fitting
    L_n = torch.mean(torch.abs(vis - 0.5)) # Example normal consistency
    L_V = torch.mean(vis * (1 - vis)) # Visibility variance
    L_E_d = torch.mean(torch.abs(torch.norm(torch.autograd.grad(depth, points, create_graph=True)[0], dim=1) - 1.0)) # Eikonal
    L_E_xi = torch.mean(torch.abs(torch.norm(torch.autograd.grad(vis, points, create_graph=True)[0], dim=1) - 1.0)) # Eikonal
    L_T = torch.mean(torch.abs(depth - 1.0)) # Example topology/regularization
    return 5*L_d + 10*L_xi + 10*L_n + 1*L_V + 0.1*L_E_d + 0.25*L_E_xi + 0.1*L_T

def explicit_sampling(n_p=2466, epsilon_p=0.1):
    # Sample uniformly in [-1, 1]^3 [S1]
    n_oversample = int((1 + epsilon_p) * n_p)
    points = torch.rand(n_oversample, 3) * 2 - 1
    return points

def render_visibility_mask(cpddf, z_s, pi_b, resolution=64):
    # Render 64x64 visibility mask [S1]
    # G: Construct rays from camera center derived from pi_b (azimuth, elevation, radius)
    # For simplicity, assume camera looks at origin.
    # Ray directions v for each pixel.
    # Query CPDDF for visibility along rays.
    # Aggregate visibility to get mask.
    # G: Standard differentiable rendering aggregates visibility along rays.
    mask = torch.zeros(resolution, resolution)
    # G: Placeholder for ray marching logic over 64x64 grid.
    return mask

def train_step(image, pi_g, cpddf, encoder, optimizer):
    optimizer.zero_grad()
    z_s, pi_b = encoder(image)
    L_pi = compute_camera_loss(pi_g, pi_b)
    R_xi = render_visibility_mask(cpddf, z_s, pi_b, resolution=64)
    L_m = compute_mask_loss(image[:, 3, :, :], R_xi)
    # Sample training points [S1]
    points = explicit_sampling()
    L_s = compute_shape_loss(cpddf, z_s, points, pi_g)
    gamma_R_S, gamma_R_Pi, gamma_R_M = 1.0, 5.0, 10.0
    L_total = gamma_R_S * L_s + gamma_R_Pi * L_pi + gamma_R_M * L_m
    L_total.backward()
    optimizer.step()
    return L_total.item()
```

**Edge Cases and Pitfalls:**
*   **Scale Ambiguity:** ShapeNet shapes are normalized by bounding box diagonal, and CPDDF outputs shapes in $[-1, 1]^3$ [S1]. A scale factor is needed for rendering [S1]. At test time, estimate the scale by sampling a point cloud and measuring the diagonal [S1].
*   **Pose Uncertainty:** Pose estimation errors can cause "blurry" shape parts when the model is uncertain (e.g., for rare shapes) [S2].
*   **Non-visible Points:** Explicit sampling must oversample and sort by visibility to prevent outputting non-visible points [S1].

The underlying representation that models depth and visibility probabilistically [S2]. [Probabilistic Directed Distance Fields](9286-probabilistic-directed-distance-fields.md)

A PDDF conditioned on a latent shape vector, allowing for shape variation [S2]. [Conditional PDDF](9285-conditional-pddf.md)

## Operating characteristics
*   **Time Complexity:** Rendering with DDF is significantly faster than sphere tracing [S2]. DDF takes <0.01 seconds per render, while sphere tracing (DIST) takes ~5.3 seconds, a ~100x speedup [S2].
*   **Memory Complexity:** The CPDDF decoder has ~25.6 million parameters, similar to the PC-SIREN baseline [S1].
*   **Performance:** DDF-derived point clouds perform similarly to directly learning point clouds but underperform Pixel2Mesh (P2M) overall [S2]. However, they outperform P2M in shape quality when camera prediction error is excluded [S2].
*   **Strengths:** Fast rendering, differentiable, allows viewshed-based rendering and explicit sampling [S2].
*   **Limitations:** Sensitive to pose estimation errors, can produce blurry results for rare shapes [S2]. Scale ambiguity requires post-processing [S1].

## Background
*   **Origin:** Proposed in "Representing 3D Shapes with Probabilistic Directed Distance Fields" (CVPR 2022) [S1] and further detailed in "Probabilistic Directed Distance Fields for Ray-Based Shape Representations" (TPAMI 2025) [S2].
*   **Development:** Utilizes DDFs for single-image 3D reconstruction by predicting the underlying latent shape $z_s$ and camera $\Pi$ that gave rise to a color image $I$ [S2]. It uses a modulated SIREN for the CPDDF decoder and ResNet-18 for the encoder [S1, S2].
*   **Usage:** Used for single-image 3D reconstruction on ShapeNet-v1 data [S1, S2].
