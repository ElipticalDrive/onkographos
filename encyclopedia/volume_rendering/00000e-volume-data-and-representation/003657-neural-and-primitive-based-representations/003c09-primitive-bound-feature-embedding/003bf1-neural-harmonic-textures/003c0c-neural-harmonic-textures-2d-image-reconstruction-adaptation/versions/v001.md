# Neural Harmonic Textures (2D Image Reconstruction Adaptation)

Also called: NHT 2D adaptation, NHT for image fitting

## Overview
This method adapts Neural Harmonic Textures for high-resolution 2D image fitting, replacing 3D volumetric primitives with a connected 2D triangle mesh to eliminate alpha blending and spatially decaying kernels [S1]. It distinguishes itself from its parent method by using Clough-Tocher cubic interpolation to ensure feature continuity across triangle edges, thereby removing high-frequency artifacts common in standard barycentric interpolation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single high-resolution 2D image (e.g., 45.7 MP, 14-bit HDR RAW) and a 2D triangle mesh topology covering the image domain [S1].
*   **Output:** Reconstructed pixel colors and semantic features [S1].

**Data Structures:**
*   **Mesh:** A connected 2D triangle mesh. Vertices store latent feature vectors [S1].
*   **Features:** Each vertex holds a set of feature vectors. In the reported configuration, 80 feature vectors are stored per primitive (vertex) [S1].
*   **Feature Dimension:** The semantic features are 512-dimensional [S1].

**Algorithm:**
1.  **Mesh Initialization:** Construct a connected 2D triangle mesh covering the image plane. The mesh is treated as fully opaque [S1].
2.  **Rasterization:** For each pixel in the target image, identify the triangle containing the pixel [S1].
3.  **Feature Interpolation:** Compute the barycentric coordinates of the pixel within the triangle [S1].
4.  **Clough-Tocher Interpolation:** Instead of standard linear barycentric interpolation, apply Clough-Tocher cubic interpolation to the feature vectors stored at the triangle vertices [S1]. This ensures that the interpolated features are continuous across triangle edges, removing high-frequency artifacts [S1].
5.  **Decoding:** Pass the interpolated feature vector through a neural decoder (MLP) to produce the final output (color and/or semantic features) [S1].

**Parameters:**
*   **Features per Primitive:** 80 [S1].
*   **Decoder Architecture:** A Multi-Layer Perceptron (MLP) with dimensions $128 \times 3$ (implying 3 layers with 128 hidden units, or similar configuration as cited in comparison with Feature 3DGS which uses $512 \times 128$) [S1].
*   **Feature Dimension:** 512 [S1].

**Edge Cases and Pitfalls:**
*   **Overfitting:** The method can overfit to individual views when supervision is very sparse, which degrades novel view synthesis performance [S1].
*   **Rendering Speed:** The neural decoder introduces a slight rendering speed penalty compared to pure 3DGS methods [S1].
*   **Precision:** Floating-point precision of implicit features can be aggressively reduced to compress the representation by a factor of 3 without noticeable quality loss [S1].

## Operating characteristics
*   **Time Complexity:** Inference performance consistently exceeds 140 frames per second (FPS) on an RTX A6000 Ada GPU [S1].
*   **Memory Complexity:** Uses fewer primitives and a smaller MLP than Feature 3DGS, resulting in a significantly lower memory footprint. Feature 3DGS uses 176 features/primitive, a $512 \times 128$ CNN, and 1.5× the number of primitives, yielding ~3× higher memory [S1].
*   **Performance:** At 100× compression, NHT achieves an LPIPS of 0.048 on tonemapped images, a 38% relative improvement over Instant NGP's 0.078, while maintaining comparable pixel-error quality (PSNR/SSIM) [S1].
*   **Strengths:** High inference speed, low memory footprint compared to Feature 3DGS, superior perceptual quality (LPIPS) compared to Instant NGP at high compression ratios [S1].
*   **Limitations:** Slightly slower than pure 3DGS methods due to the neural decoder; potential for overfitting with sparse supervision; JPEG-XL outperforms NHT in perceptual metrics due to human-perception-based inductive biases [S1].
*   **When to use:** High-resolution 2D image reconstruction, semantic field lifting, radiance caching, neural physically-based rendering, and geometric reconstruction [S1].
*   **When not to use:** When maximum perceptual quality is required and JPEG-XL is an acceptable alternative; when extremely sparse supervision is available and novel view synthesis is critical [S1].

## Background
Neural Harmonic Textures (NHT) is a primitive-based neural representation that increases the expressive power of individual primitives by anchoring latent feature vectors on a virtual scaffold around each primitive, applying periodic activations to interpolated features, and decoding the accumulated signal via a single deferred MLP pass [Parent]. The 2D adaptation was introduced to handle high-resolution image fitting by replacing 3D primitives with a 2D mesh and modifying the interpolation scheme [S1]. The method is compatible with deferred-shading rendering pipelines [S1].
