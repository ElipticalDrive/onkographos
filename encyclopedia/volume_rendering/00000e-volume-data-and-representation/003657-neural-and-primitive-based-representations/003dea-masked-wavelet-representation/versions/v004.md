# Masked Wavelet Representation

Also called: VM-192, VM-384

## Overview
Masked Wavelet Representation (MWR) is a compact representation for grid-based neural fields that utilizes a multi-level discrete wavelet transform (DWT) combined with a novel masking strategy to remove more than 95% of grid parameters without significant visual quality loss [S1]. It builds on [Neural and primitive-based representations](10-neural-and-primitive-based-representations.md) by transforming the spatial domain grid coefficients into a wavelet domain where sparsity is higher, allowing for aggressive pruning via learned alpha masks [S1]. Unlike standard grid methods or Discrete Cosine Transform (DCT) approaches, MWR is specifically designed to handle the non-repeating, non-smooth information typical in neural field grids, achieving superior compression and representation performance [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scene represented as a grid-based neural field, typically initialized from a baseline like TensoRF VM-192 or VM-384 [S1].
*   **Output:** A sparse set of wavelet coefficients and a binary mask indicating which coefficients are retained, enabling reconstruction of the scene function $F_\Theta$ with a memory footprint under 2 MB [S1].

**Data Structures:**
1.  **Grid Parameters ($\phi$):** The original dense grid coefficients [S1]. The base model VM-192 uses 192 channels; the larger backbone VM-384 uses 384 channels [S1].
2.  **Wavelet Coefficients:** The result of applying a 4-level DWT to the grid parameters [S1].
3.  **Alpha Masks ($M$):** A soft mask of the same shape as the wavelet coefficients, used to prune insignificant coefficients [S1]. Initial values of $M$ are set to one [S1].
4.  **Quantization:** All coefficients and masks are stored using 8-bit quantization [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize grid parameters $\phi$ and alpha masks $M$ to one [S1]. Set initial learning rates for $\phi$ and $M$ [S1].
2.  **Wavelet Transform:** Apply a 4-level DWT to the grid parameters [S1]. Apply level-wise scaling to the resulting coefficients by multiplying them by scales proportional to the inverse of frequency [S1].
3.  **Training Loop:** Iterate for 30,000 iterations [S1]. In each iteration, sample a minibatch of 4,096 rays [S1]. Render the scene using the current wavelet coefficients and masks [S1]. Compute the reconstruction loss [S1]. Update parameters using the Adam optimizer with exponential learning rate decay [S1].
4.  **Mask Update Schedule:** Explicitly update the alpha masks at iterations 2000, 4000, 6000, 11000, 16000, 21000, and 26000 [S1].
5.  **Pruning:** After training, the alpha masks $M$ determine which wavelet coefficients are retained [S1]. Raw mask values reflect wavelet coefficient characteristics, showing vertical, horizontal, and diagonal patterns corresponding to the respective coefficient types [S1].
6.  **Quantization:** Apply 8-bit quantization to the remaining coefficients and masks for final storage [S1].

**Formulas:**
*   **Mask Regularization:** The sparsity of the representation is controlled by a regularization weight $\lambda_m$ [S1]. The loss function includes a term $\mathcal{L}_{mask} = \lambda_m \sum |M|$ to encourage sparsity [S1].
*   **Level-wise Scaling:** Wavelet coefficients $c$ are multiplied by scales proportional to the inverse of their frequency $f$: $c_{scaled} = c \times \frac{1}{f}$ [S1].

**Parameters:**
*   **Mask Regularization Weight ($\lambda_m$):** Controls sparsity [S1]. Set to $1 \times 10^{-10}$ for high parameter sparsity, and $5 \times 10^{-11}$ or $2.5 \times 10^{-11}$ for relatively lower sparsity [S1].
*   **Learning Rates:** Grid-related parameters ($\phi$) initial learning rate is $0.02$ [S1]. MLP-related parameters initial learning rate is $0.001$ [S1]. Mask parameters ($M$) initial learning rate matches grid parameters $\phi$ [S1]. Final learning rates are set at $1/10$ of the initial learning rates [S1].
*   **Optimizer:** Adam optimizer with exponential learning rate decay [S1].
*   **Wavelet Function:** Biorthogonal 4.4 is the default, chosen for best performance among tested functions (Haar, Coiflets 1, Daubechies 4, reverse biorthogonal 4.4) [S1].

**Edge Cases and Pitfalls:**
*   **VQAD Comparison Limitation:** VQAD requires depth maps to prune vacant areas in advance [S1]. Without depth maps, memory exceeds 40 GB Tesla A100 capacity [S1]. Since the evaluated datasets do not provide depth maps, VQAD was not compared [S1].
*   **Computational Cost:** Adjusting $\lambda_m$ controls size and quality with no effect on computational costs, time, or memory requirements during inference [S1]. However, increasing network size (e.g., VM-192 to VM-384) increases computational costs and time for training and testing [S1].
*   **Wavelet Function Choice:** The choice of wavelet function affects performance [S1]. Biorthogonal 4.4 is recommended [S1]. Other functions like Haar, Coiflets 1, Daubechies 4, and reverse biorthogonal 4.4 perform worse [S1].
*   **DWT vs DCT:** DWT shows superior compression and representation performance to DCT because DWT is more appropriate for non-repeating, non-smooth information in grids [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim

def dwt3(tensor, levels=4):
    """Applies a 4-level 3D Discrete Wavelet Transform using separable Haar filters."""
    lo = torch.tensor([0.5, 0.5], dtype=tensor.dtype, device=tensor.device)
    coeffs = tensor
    for _ in range(levels):
        coeffs = F.conv3d(coeffs, lo.view(1,1,2,1,1), stride=2, padding=0)
        coeffs = F.conv3d(coeffs, lo.view(1,1,1,2,1), stride=2, padding=0)
        coeffs = F.conv3d(coeffs, lo.view(1,1,1,1,2), stride=2, padding=0)
    return coeffs

def apply_level_wise_scaling(coeffs, levels=4):
    """Multiplies wavelet coefficients by scales proportional to the inverse of frequency."""
    scaled = coeffs.clone()
    for l in range(levels):
        scale = 1.0 / (l + 1)
        scaled = scaled * scale
    return scaled

def render_rays(grid, origins, directions, num_samples=64):
    """Standard volume rendering via ray marching and alpha compositing."""
    t_vals = torch.linspace(0.0, 1.0, num_samples, device=origins.device)
    points = origins.unsqueeze(1) + directions.unsqueeze(1) * t_vals.unsqueeze(2)
    density = torch.sigmoid(grid[points])
    color = torch.rand_like(points)
    alphas = 1.0 - torch.exp(-density)
    weights = alphas * torch.cumprod(torch.ones_like(alphas) + 1e-10 - alphas, dim=1)
    rendered = torch.sum(weights.unsqueeze(-1) * color, dim=1)
    return rendered

def compute_loss(rendered, ground_truth):
    return torch.mean((rendered - ground_truth) ** 2)

def quantize_8bit(tensor):
    min_val, max_val = tensor.min(), tensor.max()
    normalized = (tensor - min_val) / (max_val - min_val + 1e-8)
    quantized = torch.round(normalized * 255) / 255.0
    return quantized

def masked_wavelet_representation_training(grid_params_init, num_iterations=30000, batch_size=4096):
    phi = nn.Parameter(grid_params_init.clone().detach(), requires_grad=True)
    wavelet_shape = phi.shape
    M = nn.Parameter(torch.ones(wavelet_shape), requires_grad=True)

    optimizer_phi = optim.Adam([phi], lr=0.02)
    optimizer_mask = optim.Adam([M], lr=0.02)

    scheduler_phi = optim.lr_scheduler.ExponentialLR(optimizer_phi, gamma=0.1**(1/num_iterations))
    scheduler_mask = optim.lr_scheduler.ExponentialLR(optimizer_mask, gamma=0.1**(1/num_iterations))

    lambda_m = 1e-10
    wavelet_levels = 4
    mask_update_iterations = [2000, 4000, 6000, 11000, 16000, 21000, 26000]

    for iteration in range(1, num_iterations + 1):
        origins = torch.randn(batch_size, 3)
        directions = torch.randn(batch_size, 3)
        directions = directions / torch.norm(directions, dim=1, keepdim=True)
        gt_colors = torch.rand(batch_size, 3)

        wavelet_coeffs = dwt3(phi, levels=wavelet_levels)
        wavelet_coeffs_scaled = apply_level_wise_scaling(wavelet_coeffs, levels=wavelet_levels)
        masked_coeffs = wavelet_coeffs_scaled * M

        reconstructed_grid = wavelet_coeffs_scaled
        rendered_colors = render_rays(reconstructed_grid, origins, directions)

        loss = compute_loss(rendered_colors, gt_colors)
        mask_reg_loss = lambda_m * torch.sum(torch.abs(M))
        total_loss = loss + mask_reg_loss

        optimizer_phi.zero_grad()
        optimizer_mask.zero_grad()
        total_loss.backward()

        optimizer_phi.step()
        optimizer_mask.step()

        scheduler_phi.step()
        scheduler_mask.step()

        if iteration in mask_update_iterations:
            # The exact update operation for masks at these iterations is not specified in the sources.
            pass

    alpha_mask = (M > 0.5).float()
    pruned_wavelet_coeffs = quantize_8bit(wavelet_coeffs_scaled * alpha_mask)

    return pruned_wavelet_coeffs, alpha_mask
```

## Operating characteristics
*   **Time and Memory Complexity:** The method achieves a memory footprint of less than 2 MB for the representation [S1]. Adjusting the mask regularization weight $\lambda_m$ controls the size and quality without affecting computational costs, time, or memory requirements during inference [S1]. However, training time and computational costs increase with larger network sizes (e.g., VM-384 vs VM-192) [S1].
*   **Measured Performance:** On the NeRF synthetic dataset, the method achieved a PSNR of 31.949 with DWT and level-wise scaling, compared to 31.325 with DCT [S1]. The base model VM-192 consistently outperforms other baselines under a small memory budget of 2 MB [S1].
*   **Scaling:** Increasing the network size (doubling channels and resolution) pushes the performance boundary further, but at the cost of increased computational resources [S1].
*   **Strengths:** High compression ratio (>95% parameter removal), state-of-the-art performance under tight memory budgets, effective handling of non-smooth grid information [S1].
*   **Limitations:** Requires careful tuning of $\lambda_m$ and mask update schedule [S1]. Training time increases with network size [S1]. Not comparable to methods requiring depth maps (like VQAD) on datasets without depth information [S1].

## Background
Masked Wavelet Representation was proposed in the paper "Masked Wavelet Representation for Compact Neural Radiance Fields" [S1]. It builds on the TensoRF baseline models (CP and VM) and aims to address the memory limitations of grid-based neural fields [S1]. The method was evaluated on datasets including the NeRF synthetic dataset, TensoRF VM-192 dataset, TanksAndTemples dataset, and LLFF dataset [S1]. It was compared against quantized NeRF, TensoRF models, cNeRF, and CCNeRF [S1].
