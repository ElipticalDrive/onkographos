# Learning from Noisy Tracker Outputs

Also called: Noisy Tracker Scene Graph Learning

## Overview
This method enables the automatic construction of neural scene graphs for dynamic scenes by leveraging outputs from existing object tracking pipelines, thereby avoiding the prohibitive cost of manual annotation [S1]. It differs from sibling methods by focusing specifically on the *data acquisition* phase for scene graph nodes (objects) using multi-modal tracking (LiDAR+camera) versus monocular tracking, whereas siblings like [Scene Graph Manipulation and Illumination Preservation](14707-scene-graph-manipulation-and-illumination-preservation.md) focus on post-construction manipulation and [Novel Scene Composition and View Synthesis](14710-novel-scene-composition-and-view-synthesis.md) focus on rendering applications [S1].

## How it works
The method constructs scene graphs by mapping tracking outputs to scene graph nodes. It supports two primary tracking backends: a multi-modal LiDAR-camera stack and a monocular camera-only stack [S1].

**Inputs:**
1.  Raw sensor data (LiDAR point clouds and/or RGB video frames) [S1].
2.  Tracking pipeline parameters (detection thresholds, association costs) [S1].

**Outputs:**
A scene graph $G = (V, E)$ where nodes $V$ represent tracked objects and edges $E$ represent temporal or spatial relationships, ready for neural scene graph training [S1].

**Data Structures:**
*   **Object Track:** A sequence of 3D bounding boxes or poses over time, generated by the tracker.
*   **Scene Graph Node:** Corresponds to a specific object instance across frames.

**Steps:**
1.  **Detection and Tracking:**
    *   *Multi-modal approach:* Apply PointRCNN [30] to LiDAR point clouds for object detection, then feed detections into the AB3DMOT [41] 3D tracker to generate consistent object trajectories [S1].
    *   *Monocular approach:* Apply CenterTrack [47] to unannotated video frames to generate object detections and tracks using only camera data [S1].
2.  **Scene Graph Construction:** Map each tracked object instance to a node in the scene graph. The temporal consistency provided by the tracker serves as the implicit supervision for node identity [S1].
3.  **Training:** Train the neural scene graph representation using the node assignments derived from the tracker outputs. The quality of the resulting representation is evaluated against ground-truth manual annotations [S1].

**Parameters:**
*   Detection/Tracking thresholds: Not specified in the sources.
*   Tracker-specific hyperparameters (e.g., AB3DMOT association costs): Not specified in the sources.

**Edge Cases and Pitfalls:**
*   **Long-distance degradation:** Monocular camera-only tracking (e.g., CenterTrack) degrades significantly for objects at long distances. The detection and tracking stack fails to provide accurate depth information, leading to poor node localization [S1].
*   **Tracker Noise:** While temporally filtered human labels have low noise, tracker outputs contain noise. However, the method demonstrates that neural scene graphs learned from noisy tracker outputs achieve comparable quality to those trained from manual annotations [S1].

## Subtopics

### SG-NeRF Confidence Estimation
This variant uses a scene graph derived from Structure-from-Motion (SfM) to guide confidence estimation for robust neural surface reconstruction [S2]. It constructs a scene graph $G = (V, E)$ where nodes $V$ correspond to input images $I$ and edges $E$ contain matching/co-visibility information [S2]. To handle the dense and noisy nature of original SfM graphs, it sparsifies the graph by applying an angular threshold $\tau$ to estimated relative rotations, removing edges that exceed $\tau$ [S2]. It then computes a confidence score $CS(v_i)$ for each node $v_i$ as the mean number of matching pairs:
$$ CS(v_i) = \frac{\sum_{M_{i,j} \in M_i} |M_{i,j}|}{|M_i|} $$
where $|M_{i,j}|$ is the number of matched keypoint pairs between images $I_i$ and $I_j$, and $|M_i|$ is the total number of edges connected to $v_i$ [S2]. This score is normalized into a probability distribution to guide ray sampling during training [S2]. The angular threshold $\tau$ is a critical parameter, though its typical value is not specified [S2]. A key pitfall is that without sparsification, the original scene graph contains many incorrect matches, leading to unreliable confidence estimates [S2].

## Operating characteristics
*   **Accuracy:** Neural scene graphs learned from tracker outputs (both LiDAR-camera and monocular) offer representation quality comparable to those trained from manual annotations [S1].
*   **Limitations:** Monocular tracking performance is heavily dependent on distance; accuracy drops for distant objects due to depth ambiguity [S1].
*   **Cost:** Significantly reduces labeling cost compared to manual annotation, as it relies on unannotated video frames or standard sensor data [S1].
*   **Hardware:** Requires LiDAR and camera for the high-accuracy variant; only camera for the monocular variant [S1].

## Background
The method originates from the work on "Neural Scene Graphs for Dynamic Scenes" [S1], which introduced the concept of learning scene graphs from noisy tracker outputs to enable novel view synthesis in dynamic environments. It builds on the premise that manual annotation is too costly for large-scale dynamic scenes [S1]. The variant "SG-NeRF Confidence Estimation" extends scene graph usage to static surface reconstruction, focusing on robustness against incorrect SfM matches [S2].
