# SG-NeRF Confidence Estimation

Also called: Mean Matching Pairs Confidence, Scene Graph Confidence

## Overview
SG-NeRF Confidence Estimation is a method for initializing and weighting the training of neural surface reconstruction models when input camera poses are noisy [S1]. It constructs a scene graph from input images, sparsifies it using an angular threshold to remove incorrect matches, and assigns a confidence score to each image based on the mean number of valid matching pairs [S1]. This score forms a probability distribution that guides ray sampling, prioritizing images with higher matching quality [S1]. It differs from static SfM-based approaches by providing a dynamic initialization strategy that can be updated during training, as detailed in its variants [S1].

## How it works
**Inputs:** A set of input images $I = \{I_1, \dots, I_N\}$, initial camera poses (rotation $R$ and translation $t$) estimated via Structure-from-Motion (SfM), and matched keypoint pairs between image pairs [S1].
**Outputs:** A normalized confidence score $CS(v_i)$ for each image node $v_i$ in the scene graph [S1].

**Data Structures:**
*   **Scene Graph $G = (V, E)$:**
    *   $V$: Set of nodes, where each node $v_i$ corresponds to image $I_i$.
    *   $E$: Set of edges representing co-visibility and matching information.
    *   $M$: Set of all matched keypoint pairs. $M_{i,j}$ is the set of matched pairs between $I_i$ and $I_j$.
*   **Parameters:**
    *   $\tau$: Angular threshold for relative rotations (typical values: 70 for SG-NeRF dataset, 45 for DTU dataset) [S1].

**Steps:**
1.  **Construct Scene Graph:** Initialize $G=(V,E)$ where nodes are images. Identify all matched keypoint pairs $M_{i,j}$ between image pairs [S1].
2.  **Sparsify Graph:** For every edge $(v_i, v_j)$, calculate the angle of the estimated relative rotation. If the angle exceeds $\tau$, remove the edge $(v_i, v_j)$ and all associated matches $M_{i,j}$ from the graph [S1]. This step is critical because the original SfM graph is dense and contains many incorrect matches [S1].
3.  **Compute Raw Confidence:** For each node $v_i$, compute the raw confidence score $CS_{raw}(v_i)$ as the mean number of matching pairs across all its remaining edges:
    $$CS_{raw}(v_i) = \frac{\sum_{M_{i,j} \in M_i} |M_{i,j}|}{|M_i|}$$
    where $|M_{i,j}|$ is the number of matched pairs between $I_i$ and $I_j$, and $|M_i|$ is the number of edges connected to $v_i$ in the sparsified graph [S1]. A higher score indicates better matching quality and a higher likelihood of being an inlier [S1].
4.  **Normalize Confidence:** Normalize the scores to form a probability distribution:
    $$CS(v_i) = \frac{CS_{raw}(v_i)}{\sum_{v \in V} CS_{raw}(v)}$$
    This distribution guides the training process to sample more rays from poses with higher confidence [S1].

**Pseudocode:**
```python
import math
import numpy as np

def compute_sg_nerf_confidence(images, poses, matches, tau):
    """
    Compute confidence scores for SG-NeRF initialization.
    
    Args:
        images: List of input images.
        poses: List of initial camera poses (R, t) from SfM.
        matches: Dictionary mapping (i, j) to list of matched keypoints.
        tau: Angular threshold for edge removal (in degrees).
        
    Returns:
        confidence_scores: Normalized confidence scores for each image.
    """
    n = len(images)
    valid_edges = {}
    
    # Step 1 & 2: Construct graph and sparsify by angular threshold
    for (i, j), match_list in matches.items():
        if i >= j: continue  # Avoid duplicate undirected edges
        
        # Compute angle of the estimated relative rotation matrix R_rel = R_j * R_i^T
        R_rel = poses[j].R @ poses[i].R.T
        # Rotation angle theta = arccos((trace(R) - 1) / 2)
        angle = math.degrees(math.acos(max(-1.0, min(1.0, (np.trace(R_rel) - 1) / 2))))
        
        if angle <= tau:
            valid_edges[(i, j)] = match_list
            
    # Step 3: Compute raw confidence (mean matching pairs per node)
    raw_confidence = [0.0] * n
    edge_counts = [0] * n
    
    for (i, j), match_list in valid_edges.items():
        num_matches = len(match_list)
        raw_confidence[i] += num_matches
        raw_confidence[j] += num_matches
        edge_counts[i] += 1
        edge_counts[j] += 1
        
    final_raw_confidence = [0.0] * n
    for i in range(n):
        if edge_counts[i] > 0:
            final_raw_confidence[i] = raw_confidence[i] / edge_counts[i]
            
    # Step 4: Normalize to probability distribution
    total_confidence = sum(final_raw_confidence)
    if total_confidence == 0:
        return [1.0 / n] * n  # Fallback to uniform if no valid edges
        
    confidence_scores = [c / total_confidence for c in final_raw_confidence]
    return confidence_scores
```

## Subtopics

### Scene Graph Updating
A periodic update of the scene graph based on current geometry and pose estimations to remove wrong matches [S1]. It extends the initial confidence estimation by refining the graph during training [S1]. It removes edges exceeding the angular threshold $\tau$ and further removes keypoint matching pairs with a re-projection loss surpassing $\tau_{rep}$, which is gradually reduced throughout training [S1]. This strategy dynamically updates matching pairs during the pose-NeRF joint training process, whereas previous works typically use static scene graphs from SfM [S1].

### Scene Graph Updating Strategy
A specific implementation of the updating process that leverages the current Signed Distance Function (SDF) to eliminate incorrectly matched pairs [S1]. It uses the updated scene graph to provide more accurate information throughout the training process [S1]. This is described as the first study to update matching pairs dynamically during the pose-NeRF joint training process [S1].

## Background
SG-NeRF Confidence Estimation is part of the Robust SG-NeRF method, introduced in 2024 by researchers from Omnispace AI [S1]. It builds on the SG-NeRF framework, which was the first to utilize a scene graph to guide joint optimization in neural surface reconstruction [S1]. The method addresses the problem of noisy tracker outputs in Structure-from-Motion (SfM) by providing a robust confidence estimation and updating strategy [S1]. It is used for object-level 3D surface reconstruction from unorganized images captured in an inward-facing configuration [S1]. The method has been validated on the SG-NeRF and DTU datasets [S1].
