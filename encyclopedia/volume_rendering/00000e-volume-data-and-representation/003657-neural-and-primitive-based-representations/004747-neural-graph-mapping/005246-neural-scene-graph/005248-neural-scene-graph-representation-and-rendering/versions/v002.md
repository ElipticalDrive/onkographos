# Neural Scene Graph Representation and Rendering

Also called: Neural Scene Graphs for Dynamic Scenes

## Overview
This method renders dynamic scenes by decomposing them into a hierarchical graph of individual object nodes, separating static background from dynamic foreground elements [S1]. Unlike Single Representation Networks (SRNs) that optimize a single static representation for all frames, or Neural Radiance Fields (NeRF) which suffer from ghosting due to camera pose changes, this approach reconstructs each object individually to ensure temporal consistency and accurate dynamic modeling [S1]. It builds on the [Neural Scene Graph](14682-neural-scene-graph.md) structure, utilizing its directed acyclic graph definition to manage scene hierarchy.

## How it works
**Inputs and Outputs:**
*   **Input:** A sequence of images from a stereo camera setup (e.g., KITTI dataset), typically up to 90 time steps (9 seconds) at 1242×375 resolution [S1]. The scene graph structure is defined as $S = (W, C, F, L, E)$, where $C$ is the camera leaf node, $F$ are representation leaf nodes (static and dynamic), $L$ are latent object code leaf nodes, and $E$ are edges [S1].
*   **Output:** Rendered images of the full scene, isolated static components, isolated dynamic components, or novel compositions [S1].

**Data Structures:**
The scene is represented as a directed acyclic graph. Key node types include:
*   **Camera Node ($C$):** Defines the viewing parameters.
*   **Background Node:** Represents static scene components.
*   **Dynamic Object Nodes:** Represent individual moving objects. Each node implicitly encodes the relationship between object location, viewing direction, and scene lighting, including shadows and specular highlights [S1].
*   **Edges ($E$):** Define the hierarchy and relationships between nodes.

**Algorithm Steps:**
1.  **Graph Construction:** Initialize the scene graph with a camera node, a background node, and dynamic object nodes. The structure naturally decomposes the scene into dynamic and static components without additional supervision [S1].
2.  **Shadow Assignment:** Assign the shadow of each object to its corresponding dynamic representation node. This ensures shadows are visible when rendering dynamic-only components [S1].
3.  **Rendering Full Scene:** Render the complete image by traversing the graph, combining the background node and all dynamic object nodes according to the hierarchy defined by edges $E$ [S1].
4.  **Rendering Isolated Static Components:** To render only the static background, remove all dynamic nodes from the graph. Render the image from the scene graph containing only the camera node and the background node [S1].
5.  **Rendering Isolated Dynamic Components:** To render only the dynamic foreground, exclude the static background node. Render the remaining graph, which includes the camera and all dynamic object nodes (including their assigned shadows) [S1].
6.  **Novel Composition:** Sample new transformations on object trajectories or road lanes to generate novel scene compositions, ensuring no collisions between objects [S1].

**Parameters and Edge Cases:**
*   **Resolution:** Evaluated on 1242×375 images [S1].
*   **Object Count:** Up to 12 unique dynamic objects per sequence [S1].
*   **Pitfalls:** The method relies on the accuracy of the graph structure. If the decomposition fails to separate static and dynamic elements correctly, isolation rendering will produce artifacts. The sources do not specify numerical hyperparameters for the neural network optimization.

**Pseudocode:**
```python
def render_scene_graph(scene_graph, camera_pose):
    """
    Renders the scene based on the graph structure.
    scene_graph: Dict containing 'camera', 'background_node', and 'dynamic_nodes'.
    camera_pose: Current camera transformation.
    """
    # Initialize color buffer
    color_buffer = zeros_like(image_shape)
    
    # 1. Render Background (Static)
    # The background node captures static scene components.
    # It is rendered first or composited appropriately.
    bg_color = render_node(scene_graph['background_node'], camera_pose)
    color_buffer = composite(color_buffer, bg_color)
    
    # 2. Render Dynamic Objects
    # Each dynamic node includes its own shadow.
    for obj_node in scene_graph['dynamic_nodes']:
        # Get object pose from graph structure or tracker
        obj_pose = get_object_pose(obj_node, camera_pose)
        
        # Render the object and its assigned shadow
        obj_color = render_node(obj_node, obj_pose)
        
        # Composite onto buffer
        color_buffer = composite(color_buffer, obj_color)
        
    return color_buffer

def render_isolated_static(scene_graph, camera_pose):
    """
    Renders only the static background by excluding dynamic nodes.
    """
    # Create a temporary graph with only camera and background
    static_graph = {
        'camera': scene_graph['camera'],
        'background_node': scene_graph['background_node']
    }
    return render_scene_graph(static_graph, camera_pose)

def render_isolated_dynamic(scene_graph, camera_pose):
    """
    Renders only dynamic components by excluding the static background.
    """
    # Create a temporary graph with camera and dynamic nodes only
    dynamic_graph = {
        'camera': scene_graph['camera'],
        'dynamic_nodes': scene_graph['dynamic_nodes']
    }
    return render_scene_graph(dynamic_graph, camera_pose)
```

## Operating characteristics
*   **Performance:** The method outperforms baseline methods (vanilla SRN, NeRF) on all metrics for dynamic scenes [S1].
*   **Strengths:** Accurately reconstructs dynamic scenes without ghosting or blurring associated with NeRF or SRNs. It naturally decomposes scenes into static and dynamic components without additional supervision [S1].
*   **Limitations:** Requires a stereo camera setup for training data [S1]. The quality depends on the ability to correctly identify and separate dynamic objects from the background.
*   **Scaling:** Evaluated on sequences with up to 12 unique dynamic objects. Scaling to more complex scenes with higher object counts is not detailed in the sources.

## Background
The method was introduced in "Neural Scene Graphs for Dynamic Scenes" [S1]. It addresses the limitations of existing neural rendering techniques for dynamic environments, specifically the inability of SRNs to handle temporal changes and the ghosting artifacts of NeRF when camera poses vary. The work demonstrates the flexibility of the neural scene graph representation by manipulating edges and nodes to preserve illumination cues and compose novel scenes.
