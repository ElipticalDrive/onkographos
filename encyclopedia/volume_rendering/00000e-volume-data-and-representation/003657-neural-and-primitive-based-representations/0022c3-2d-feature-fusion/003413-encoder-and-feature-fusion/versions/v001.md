# Encoder and Feature Fusion

Also called: Deep Convolution Feature Fusion, Semantic Feature Fusion

## Overview
Encoder and Feature Fusion methods address the semantic gap in neural volume rendering by extracting deep convolutional features from input images and fusing them to represent 3D points, rather than relying solely on raw coordinate queries [S1, unofficial]. Unlike standard NeRF where inputs are point coordinates without scene-specific features, this approach uses deep convolution features to eliminate the semantic gap of implicit mapping and enhance generalization to unseen scenes [S1, unofficial]. It builds on [2D Feature Fusion](2907-2d-feature-fusion.md) by providing the detailed 3D geometry and multi-view ensemble required to render high-resolution 2D features.

## How it works
The method involves extracting per-pixel features from input views and projecting or fusing them into a 3D representation for rendering.

**Inputs:**
*   Set of $N$ input RGB images $I_i \in [0, 1]^{H \times W \times 3}$ with known camera poses (extrinsics and intrinsics) [S1, unofficial][S4].
*   Query points $x_j$ in 3D space and view directions $r$ [S1, unofficial].

**Outputs:**
*   Color $c$ and opacity $\sigma$ for each query point [S1, unofficial].
*   Refined object-centric features $f_{h,w,d}^+$ for selected voxels [S3, unofficial].

**Data Structures:**
*   **Image Feature Map:** $M_i \in \mathbb{R}^{H \times W \times Z}$, where $Z$ is the feature channel dimension (e.g., 64 or 128 depending on the specific network) [S1, unofficial][S4].
*   **Multi-view Aware Features:** $W_n$, generated by integrating local and global information from fused features [S1, unofficial].
*   **Voxel Features:** Unified coarse feature $\tilde{v}_{h,w,d}$, fine detail feature $\hat{v}_{h,w,d}$, and position-encoded skeletal primitive position $\gamma(\mu_{crs_{h,w,d}})$ [S3, unofficial].

**Steps:**

1.  **Feature Extraction:**
    *   For each input image $I_i$, extract deep convolution features representing geometry, shape, and texture using an encoder module (e.g., U-ResNet or ResNet34) [S1, unofficial][S2].
    *   Optionally, stack the camera $xyz$ location to each pixel of the input RGB image to make pixel features explicitly aware of their relative position in 3D space [S4].
    *   Use skip connections between encoder and decoder to preserve high-frequency local features [S4].
    *   *Note:* Stacking additional camera rotation and intrinsics does not noticeably improve performance [S4].

2.  **Feature Fusion / Aggregation:**
    *   **Global Fusion (GARF/DBARF):** Concatenate the image feature $M_i$ with its mean and variance map. Feed this into a PointNet-like MLP to integrate local and global information, generating multi-view aware features $W_n$ [S1, unofficial].
    *   **Selective Refinement (VS-Splat):** For selected voxels, concatenate the unified coarse feature $\tilde{v}_{h,w,d}$, fine detail feature $\hat{v}_{h,w,d}$, and position-encoded skeletal primitive position $\gamma(\mu_{crs_{h,w,d}})$ in a channel-wise manner [S3, unofficial].

3.  **3D Reprojection / Query:**
    *   Reproject the 2D pixel features back to 3D space along the light ray from the camera center to the 3D surface point $p$ [S4].
    *   Query the fused feature representation at point $x_j$ to obtain feature $F(x_j)$ [S1, unofficial].

4.  **Rendering:**
    *   Map the point $x_j$, feature $F(x_j)$, and view direction $r$ to color $c$ and opacity $\sigma$ using a function $f_{GARF}$ [S1, unofficial]:
        $$ f_{GARF}: F(x_j), x_j, r \mapsto (c, \sigma) $$
    *   For voxel-based methods, pass the concatenated features through residual convolutional blocks to generate the refined object-centric feature $f_{h,w,d}^+$ [S3, unofficial].

**Pseudocode:**

```python
def encoder_and_feature_fusion(input_images, camera_poses, query_points, view_directions):
    """
    input_images: List of RGB images, shape (N, H, W, 3)
    camera_poses: List of camera extrinsic/intrinsic parameters
    query_points: 3D points to render, shape (P, 3)
    view_directions: View vectors for each query point, shape (P, 3)
    """
    # Step 1: Extract 2D Features
    # Using a CNN backbone like ResNet34 or U-ResNet
    # Input to CNN: Stack camera xyz to each pixel
    # Shape: (H, W, 3 + 3) -> (H, W, 128) or similar
    image_features = []
    for img, pose in zip(input_images, camera_poses):
        # Stack camera xyz location to each pixel
        # Note: Camera rotation/intrinsics stacking is optional and not recommended
        pixel_coords = get_pixel_coords(img.shape)
        camera_xyz = pose.camera_xyz
        stacked_input = stack(camera_xyz, pixel_coords, img) # (H, W, 9)
        
        # Extract features using CNN with skip connections
        features = cnn_encoder(stacked_input) # (H, W, Z)
        image_features.append(features)

    # Step 2: Fuse Multi-View Features
    # Method A: GARF/DBARF style (Global/PointNet)
    fused_features_global = []
    for features in image_features:
        # Concatenate with mean and variance
        mean_map = mean(features, axis=(0, 1))
        var_map = variance(features, axis=(0, 1))
        concat_feat = concatenate([features, mean_map, var_map], axis=-1)
        
        # PointNet-like MLP to generate multi-view aware features
        multi_view_feat = pointnet_mlp(concat_feat)
        fused_features_global.append(multi_view_feat)

    # Method B: VS-Splat style (Voxel-Selective)
    # For selected voxels (h, w, d)
    voxel_features = []
    for voxel in selected_voxels:
        # Retrieve coarse and fine features
        v_coarse = get_coarse_feature(voxel)
        v_fine = get_fine_feature(voxel)
        # Position encoding of skeletal primitive
        pos_enc = position_encode(voxel.position)
        
        # Concatenate channel-wise
        concat_voxel = concatenate([v_coarse, v_fine, pos_enc], axis=-1)
        
        # Refine using SFR module (R=2 residual blocks, output 512)
        refined_feat = sfr_module(concat_voxel)
        voxel_features.append(refined_feat)

    # Step 3: Render
    # Map query point, fused feature, and view direction to color/opacity
    colors = []
    opacities = []
    for i, (point, direction) in enumerate(zip(query_points, view_directions)):
        # Get feature at point (via reproject or voxel lookup)
        feat = get_feature_at_point(point, fused_features_global, voxel_features)
        
        # Decode to color and opacity
        c, sigma = decode_radiance(feat, point, direction)
        colors.append(c)
        opacities.append(sigma)
        
    return colors, opacities
```

**Parameters:**
*   **Residual Blocks (R):** 2 in the SFR module [S3, unofficial].
*   **Output Channel Dimension:** 512 in the SFR module [S3, unofficial].
*   **Input Dimension for CNN:** $H \times W \times (3 + 3)$, where 3 is RGB and 3 is the stacked camera xyz location [S4].
*   **Depth Sampling:** 64 inverse-depth samples (used in GeNeRF/IBRNet context) [S2].

**Edge Cases and Pitfalls:**
*   **Shape Mismatch:** After up-convolution, the shape of the resulting feature map may not match the shape of the feature map to be concatenated. Use bilinear interpolation to rescale them to the same shape [S2].
*   **Camera Info:** Stacking additional camera rotation and intrinsics to each pixel does not noticeably improve performance [S4].
*   **Lighting Sensitivity:** Raw RGB values are sensitive to lighting conditions; using a CNN encoder helps learn more general and robust patterns [S4].

## Subtopics

### [ResNet Architecture](8378-resnet-architecture.md)
Basic building block for residual connections in 3D and 2D convolutions. Used as the backbone for feature extraction networks (e.g., ResNet34) in DBARF and other variants.

### Feature Extraction Network
Network architecture for extracting features from input images, based on ResNet34 with specific convolutional and up-convolutional layers for feature fusion [S2]. The backbone is ResNet34. The architecture involves: Input -> [Conv]x3 -> MaxPool (omitted) -> Residual Blocks. Path 1: [Conv]x3 -> UpConv (3x3 256) -> UpConv (3x3 128) -> [Conv]x3 (3x3 64) -> [Conv]x3 (3x3 64) -> 7x7 64. Path 2: [Conv]x6 -> [Conv]x3. Concatenation of features occurs after up-convolution steps. If shapes mismatch after up-convolution, bilinear interpolation is used to rescale to the same shape [S2].

### Selective Feature Refinement (SFR) Module
A module that operates exclusively on selected voxels to refine features, using sparse 3D convolutional layers [S3, unofficial]. For each selected voxel $(h, w, d)$, it concatenates the unified coarse feature $\tilde{v}_{h,w,d}$, fine detail feature $\hat{v}_{h,w,d}$, and position-encoded skeletal primitive position $\gamma(\mu_{crs_{h,w,d}})$ in a channel-wise manner. It contains $R=2$ residual convolutional blocks and produces a refined object-centric feature with a channel dimension of 512 [S3, unofficial].

### CNN-based 2D Feature Extraction
A convolutional neural network (CNN) module extracts robust per-pixel features from input RGB images to learn general patterns for each pixel [S4]. It stacks the camera $xyz$ location to each pixel of the input RGB image to make pixel features explicitly aware of their relative position in 3D space. It uses skip connections between the encoder and decoder to preserve high-frequency local features for each pixel, and optionally integrates fully connected (fc) layers in the middle of the CNN module to learn global features. The input dimension is $H \times W \times (3 + 3)$, where 3 is RGB and 3 is the stacked camera xyz location. Stacking additional camera rotation and intrinsics to each pixel does not noticeably improve performance [S4].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** VS-Splat (using SFR) is faster than LaRa across benchmark datasets (GObjaverse, GSO, CO3D), achieving about a 1.3× speedup with the GObjaverse dataset [S3, unofficial].
*   **Strengths:** Eliminates the semantic gap of implicit mapping; enhances generalization to unseen scenes; robust to lighting conditions and environmental noise compared to raw RGB [S1, unofficial][S4].
*   **Limitations:** Requires training a CNN encoder; performance may not improve with additional camera rotation/intrinsic stacking [S4].
*   **When to use:** When generalizing to unseen scenes or handling lighting variations is critical; when semantic information from input images is needed to guide 3D reconstruction [S1, unofficial][S4].
*   **When not to use:** When computational resources for training a CNN encoder are limited; when camera poses are noisy without extension modules (e.g., SHARE) [S3, unofficial].

## Background
The concept of using deep convolution features for volume rendering was introduced to address the limitations of NeRF, which relies on point coordinates without scene-specific features [S1, unofficial]. GARF (Geometry-Aware Generalized Neural Radiance Field) proposed using a U-ResNet to extract features and fuse them for semantic representation [S1, unofficial]. DBARF extended this with deep bundle-adjusting capabilities [S2]. VS-Splat introduced voxel-selective feature refinement for sparse-view reconstruction [S3, unofficial]. GRF used CNN-based 2D feature extraction with camera position stacking for general radiance fields [S4].
