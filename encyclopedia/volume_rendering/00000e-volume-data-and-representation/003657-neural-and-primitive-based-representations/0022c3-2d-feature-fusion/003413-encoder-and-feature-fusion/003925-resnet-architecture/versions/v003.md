# ResNet Architecture

Also called: 2D residual block, 3D residual block, ResNet, Residual Block

## Overview
The ResNet architecture serves as the basic building block for residual connections in 3D and 2D convolutions [S1, unofficial]. It sets itself apart from standard convolutional layers by introducing shortcut connections that add the input directly to the output, allowing the network to learn residual functions [S1, unofficial]. In volume rendering and feature fusion pipelines, it acts as a core component for encoding 3D volumetric data or processing 2D feature maps [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A tensor $X$ with spatial dimensions and an input channel count $C_{in}$ [G].
- Output: A tensor $Y$ with the same spatial dimensions and an output channel count $C_{out}$ [G].

**Data Structures and Layout:**
1. **3D Residual Block:** Consists of a $3 \times 3 \times 3$ 3D convolution, a PReLU activation function, and another $3 \times 3 \times 3$ 3D convolution [S1, unofficial]. The input tensor is added to the output of the second convolution via a shortcut connection [S1, unofficial].
2. **2D Residual Block:** Identical structure to the 3D block but replaces 3D convolutions with 2D convolutions [S1, unofficial].
3. **Dropout:** A dropout probability of 0.5 is applied after every convolution during training, except for convolutions inside the residual blocks [S1, unofficial].
4. **Network Output:** While residual blocks use PReLU, the final layer of the network uses a sigmoid activation function [S1, unofficial].

**Numbered Steps:**
1. Pass input $X$ through the first convolutional layer ($3 \times 3 \times 3$ for 3D or $3 \times 3$ for 2D) [S1, unofficial].
2. Apply PReLU activation: $A_1 = \text{PReLU}(Conv_1(X))$ [S1, unofficial].
3. Pass $A_1$ through the second convolutional layer [S1, unofficial].
4. Add the original input $X$ to the output of the second convolution via the shortcut connection: $Y = Conv_2(A_1) + X$ [S1, unofficial].

**Pseudocode:**
```python
def residual_block_forward(x, conv1, conv2, prelu, shortcut):
    """
    Forward pass for a 3D or 2D ResNet residual block.
    x: input tensor
    conv1, conv2: convolution layers
    prelu: PReLU activation
    shortcut: identity or projection layer
    """
    residual = shortcut(x)
    out = conv1(x)
    out = prelu(out)
    out = conv2(out)
    out = out + residual
    return out
```

**Parameters:**
- Kernel Size: $3 \times 3 \times 3$ (3D) or $3 \times 3$ (2D) [S1, unofficial].
- Dropout Probability: 0.5 applied after convolutions outside residual blocks [S1, unofficial].
- Activation: PReLU inside blocks, sigmoid in the final output layer of the network [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Dimension Mismatch:** If the number of input and output channels differs, the shortcut connection must include a $1 \times 1$ convolution to match dimensions before addition [G].
- **Boundary Conditions:** Padding must be configured to preserve spatial dimensions when stride is 1 [G].

## Subtopics

### ResNet_Grad Architecture
A variant used in inverse problem reconstruction for CT scans [S2, unofficial]. It consists of a sequential model with 4 layers [S2, unofficial]. Each layer comprises a GradBlock (taking operator A) followed by a ResBlock with `in_channels=2` and `out_channels=1` [S2, unofficial]. The forward pass involves passing input $x$ through `self.model` to get $f_{recon}$, and returning $f_{recon}$ and `self.head(f_recon)` [S2, unofficial].

## Background
The architecture was used in RenderNet, a deep convolutional network for differentiable rendering from 3D shapes [S1, unofficial]. RenderNet utilized 3D residual blocks for the volumetric encoder and 2D residual blocks for the feature fusion and projection stages [S1, unofficial]. A variant called ResNet_Grad is applied in inverse problem solvers for CT scans [S2, unofficial].
