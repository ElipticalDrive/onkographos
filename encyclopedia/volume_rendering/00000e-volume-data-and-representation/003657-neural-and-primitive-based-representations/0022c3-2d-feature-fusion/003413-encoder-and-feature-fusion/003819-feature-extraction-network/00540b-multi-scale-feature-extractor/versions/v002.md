# Multi-Scale Feature Extractor

Also called: ResNet-34 with FPN

## Overview
The Multi-Scale Feature Extractor processes reference images to produce multi-scale semantic features for semantic field aggregation [S1]. It combines a shared ResNet-34 encoder with a Feature Pyramid Network (FPN) module to capture hierarchical features at multiple scales [S1].

## How it works
The method processes reference images to produce multi-scale semantic features used for semantic field aggregation [S1].

**Inputs:**
- A set of reference images $\{I_i\}$, where $i$ indexes the image [S1].

**Outputs:**
- Multi-scale semantic features $\boldsymbol{F}^{sem}_i$ for each reference image $I_i$ [S1].

**Data Structures:**
- The architecture consists of a shared ResNet-34 encoder followed by an FPN module [S1].
- ResNet-34: A residual network with 34 layers, producing feature maps at various depths (typically stages 1–4) [G].
- FPN: A top-down pathway with lateral connections that fuses high-level semantic features with low-level spatial details [G].

**Steps:**
1. **Image Encoding:** For each reference image $I_i$, pass the image through a shared ResNet-34 encoder [S1]. The encoder extracts hierarchical features [G]. Let $R(I_i)$ denote the output feature maps from the ResNet-34 backbone [G].
2. **Feature Pyramid Construction:** Pass the output $R(I_i)$ through a Feature Pyramid Network (FPN) module [S1]. The FPN combines features from different stages of the ResNet to produce a pyramid of feature maps at multiple scales [G].
3. **Output Generation:** The output of the FPN is the multi-scale semantic feature set $\boldsymbol{F}^{sem}_i$ [S1]. These features are subsequently used in the Context-Aware Perception Head [S1].

**Pseudocode:**
```python
def multi_scale_feature_extractor(reference_images):
    """
    Extracts multi-scale semantic features from reference images.
    
    Args:
        reference_images: List of input images I_i.
        
    Returns:
        F_sem: List of multi-scale semantic feature sets F^{sem}_i for each image.
    """
    # Shared ResNet-34 encoder: standard 34-layer residual network [G]
    def resnet34_encoder(image):
        # Applies convolutional blocks and downsampling to produce feature maps at stages C2, C3, C4, C5
        # Sources do not specify exact channel dimensions or block configurations [G]
        return [conv_block(image, stage=2), conv_block(image, stage=3), conv_block(image, stage=4), conv_block(image, stage=5)]

    # FPN module: top-down pathway with lateral connections [G]
    def fpn_module(resnet_features):
        top_down = resnet_features[-1]
        pyramid = [top_down]
        # Iterate from C4 down to C2
        for i in range(len(resnet_features) - 2, -1, -1):
            lateral = conv1x1(resnet_features[i])
            top_down = upsample(top_down)
            top_down = lateral + top_down
            pyramid.append(top_down)
        # Reverse to match standard FPN output order (low to high resolution)
        return list(reversed(pyramid))

    F_sem = []
    for I_i in reference_images:
        R_I_i = resnet34_encoder(I_i)
        F_sem_i = fpn_module(R_I_i)
        F_sem.append(F_sem_i)
    return F_sem
```

**Parameters:**
- ResNet-34 depth: 34 layers [S1].
- FPN: Standard FPN configuration with lateral connections and top-down upsampling [G].
- Typical values for FPN channels are not specified in the sources [S1].
- The method assumes the availability of reference images with consistent resolution [G].

**Edge Cases and Pitfalls:**
- Precision issues may arise if the FPN upsampling operations are not implemented with care, though standard bilinear or nearest-neighbor interpolation is typically used [G].
- Degenerate input (e.g., single-channel images) may require channel expansion before ResNet-34 [G].

## Subtopics

### Multi-Scale Tri-Plane Architecture
This is a baseline architecture used for comparison against the Self-Attention Convolution (SAC) method in PET-NeuS [S2]. It uses tri-planes at different resolutions to mimic multi-frequency bands, serving as an alternative to SAC for handling different frequencies [S2]. It is chosen when a multi-resolution data structure is preferred over self-attention mechanisms for frequency separation [S2]. The architecture uses four tri-planes with resolutions: 512x512 (highest frequency), 256x256, 128x128, and 64x64 (lowest frequency) [S2]. Features generated by these four tri-planes are concatenated to obtain multi-scale tri-plane features [S2]. This approach was found to be less effective than SAC in the PET-NeuS experiments, likely because the smoothing kernel in SAC handles noise influence more effectively [S2].

- **Strengths:** Captures multi-scale semantic information effectively for 3D scene understanding [G].
- **Limitations:** Relies on 2D image features, which may not capture 3D geometric details as directly as 3D-based methods like tri-planes or SAC [G].

- **When not to use:** When high-frequency 3D geometric details are critical and 2D features are insufficient, or when self-attention mechanisms are preferred for frequency separation [G].

## Background
The Multi-Scale Feature Extractor was introduced in the GP-NeRF paper [S1]. It builds on the ResNet-34 architecture and the Feature Pyramid Network (FPN) [S1] to enhance the semantic awareness of semantic-embedding fields [S1]. The method is designed to support the Context-Aware Perception Head, which decomposes semantic features into high-level and low-level parts for novel view synthesis and semantic labeling [S1].
