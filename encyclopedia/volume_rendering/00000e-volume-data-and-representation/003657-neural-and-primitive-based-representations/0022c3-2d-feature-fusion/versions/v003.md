# 2D Feature Fusion

Also called: Volume Fusion, Voxel Pooling

## Overview
2D Feature Fusion integrates 2D semantic segmentation and high-dimensional foundation features into a 3D sparse voxel representation using Voxel Pooling and Volume Fusion [S1]. It solves the semantic gap in neural volume rendering by replacing raw coordinate queries with deep convolutional features, enhancing generalization to unseen scenes [S1]. Unlike standard NeRF which relies solely on implicit mapping from coordinates, this method leverages multi-view ensembles to smooth inconsistent 2D predictions while using detailed 3D geometry to enable higher-resolution rendering of these features [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of input images (for 2D feature extraction), a sparse voxel grid representing the scene geometry, and camera poses.
*   **Outputs:** A 3D feature volume where each active voxel contains fused 2D features (semantic and/or high-dimensional foundation features) [S1].

**Data Structures:**
*   **Sparse Voxel Grid:** A 3D grid storing features. The layout is not explicitly defined in the sources, but it is described as "sparse" and "multi-level" [S1].
*   **2D Features:** Extracted from input images using a foundation model or encoder.

**Method Steps:**
1.  **2D Feature Extraction:** Extract semantic segmentation maps and high-dimensional foundation features from input images [S1].
2.  **Voxel Pooling:** Project the 2D features onto the 3D sparse voxel grid. This step aggregates 2D information into 3D voxels [S1].
3.  **Volume Fusion:** Fuse the pooled features to create a consistent 3D feature representation. This involves a multi-view ensemble to smooth inconsistent 2D predictions [S1].
4.  **Rendering:** Use the detailed 3D geometry of the sparse voxel grid to render the fused 2D features at high resolution [S1].

## Subtopics

### 2D to 3D Merging Strategy
A strategy to achieve pervoxel features that match similar structures throughout the whole volume by merging features from multiple slicing directions (X, Y, Z) [S2]. It alleviates topological inconsistencies found in single-direction approaches [S2]. Using only a single slicing direction (e.g., Z) fails to preserve the topology of complex shapes like a torus, resulting in topological inconsistencies and errors inside structures [S2]. The merged approach correctly predicts the full 3D structure and avoids these artifacts [S2].

**When to Use:**
When semantic information or high-dimensional features from 2D images need to be integrated into a 3D neural volume rendering system [S1].

**When Not to Use:**
When surface smoothness is critical and the geometric bumps produced by the method are unacceptable without further refinement [S1].
