# 2D Feature Fusion

Also called: Volume Fusion, Voxel Pooling

## Overview
2D Feature Fusion integrates 2D semantic segmentation and high-dimensional foundation features into a sparse 3D voxel representation to enable higher-resolution rendering of 2D features [S1]. It addresses the problem of inconsistent 2D predictions across multiple views by using multi-view ensemble smoothing, while leveraging detailed 3D geometry to maintain feature fidelity [S1]. It differs from sibling methods that rely solely on implicit fields or single-direction propagation by explicitly fusing 2D priors into a discrete sparse voxel structure [S1].

## How it works
**Inputs:**
*   Sparse voxel grid representing the 3D scene geometry.
*   2D semantic segmentation maps from multiple camera views.
*   High-dimensional foundation features extracted from 2D images.

**Outputs:**
*   Pervoxel features stored in the sparse voxel grid.

**Data Structures:**
*   **Sparse Voxel Grid:** A hash map or sparse array where keys are voxel coordinates $(x, y, z)$ and values are feature vectors. The specific bit-packing or field layout is not detailed in the sources [S1].

**Steps:**
1.  **Voxel Pooling:** For each voxel in the sparse grid, identify the set of 2D pixels (from multiple views) that project into the voxel's volume. Aggregate the 2D features associated with these pixels. This step maps 2D image space features to 3D voxel space [S1].
2.  **Volume Fusion:** Combine the pooled features from multiple views. The multi-view ensemble smooths inconsistent 2D predictions, ensuring that the final 3D feature representation is robust to view-dependent artifacts [S1].
3.  **Integration:** Store the fused features into the sparse voxel grid for subsequent rendering [S1].

**Parameters:**
*   Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Topological Inconsistencies:** Using only a single slicing direction (e.g., Z-axis) for feature extraction can fail to preserve the topology of complex shapes, such as a torus, leading to errors inside structures [S2].
*   **Refinement Artifacts:** If the input similarity map used for refinement lacks sufficient detection of relevant structures, block artifacts may occur [S2].

## Subtopics

### 2D to 3D Merging Strategy
A strategy to achieve pervoxel features that match similar structures throughout the whole volume by merging features from multiple slicing directions (X, Y, Z) [S2]. It alleviates topological inconsistencies found in single-direction approaches [S2]. Simply using slice-wise features (e.g., from a single slicing direction like Z) results in topological inconsistencies and errors inside structures (e.g., the torus), whereas the merged approach correctly predicts the full 3D structure and avoids these artifacts [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** The method achieves a good balance of accuracy and training time on large-scale datasets like Tanks&Temples and object-scale DTU datasets [S1].
*   **Strengths:** Multi-view ensemble smooths inconsistent 2D predictions; detailed 3D geometry enables higher-resolution rendering of 2D features [S1].
*   **Limitations:** The current method tends to produce unnecessary geometric bumps for texture details [S1].
*   **When to use:** When integrating 2D semantic and foundation features into a sparse voxel representation for radiance field rendering [S1].
*   **When not to use:** When high surface smoothness is required without post-processing, as the method may produce geometric bumps [S1].

## Background
