# Feature Grid as Radiance Field

Also called: Chen et al. 2022, EgoNeRF representation, Tensor Factorization

## Overview
Feature Grid as Radiance Field represents a scene using explicit, low-rank tensor-decomposed feature grids for density and appearance, replacing the implicit multi-layer perceptron (MLP) regression used in standard Neural Radiance Fields [S2]. It solves the memory bottleneck of dense 3D grids by factorizing the feature tensors into lower-dimensional components, reducing space complexity from cubic to quadratic relative to resolution [S2]. Unlike sibling methods that rely on hash grids [Hash Grid Neural Fields](3855-hash-grid-neural-fields.md) or Gaussian primitives [Gaussian Head Avatar (GHA)](1478-gaussian-head-avatar-gha.md), this method maintains a regular grid structure optimized for spherical parameterization, specifically targeting egocentric view synthesis [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of egocentric images with corresponding camera parameters (position $\mathbf{x}$ and viewing direction $\mathbf{d}$) [S2].
*   **Output:** Volume density $\sigma(\mathbf{x})$ and color $c(\mathbf{x}, \mathbf{d})$ for any continuous 3D coordinate and direction [S2].

**Data Structures:**
The representation uses two primary grids, $\mathcal{G}_\sigma$ and $\mathcal{G}_a$, defined on a "balanced spherical grid" with resolution $2N_y^r \times N_y^\theta \times N_y^\phi$ [S2].
1.  **Density Grid ($\mathcal{G}_\sigma$):** A 3D tensor of size $2N_y^r \times N_y^\theta \times N_y^\phi$ with a single channel storing explicit volume density values [S2].
2.  **Appearance Grid ($\mathcal{G}_a$):** A 4D tensor of size $2N_y^r \times N_y^\theta \times N_y^\phi \times C$ storing $C$-dimensional neural appearance features [S2].

Both grids are decomposed into "Yin" and "Yang" components ($y \in Y = \{\text{Yin, Yang}\}$), where the final grid is the union of these components: $\mathcal{G} = \bigcup_{y \in Y} \mathcal{G}^y$ [S2].

**Tensor Factorization:**
To reduce memory, the feature tensors are decomposed into vectors and matrices using low-rank tensor factorization [S2].

For the density grid $\mathcal{G}_\sigma^y$, the decomposition is:
$$ \mathcal{G}_\sigma^y = \sum_{n=1}^{N_\sigma} \left( \mathbf{v}_{\sigma,n}^{y,R} \otimes \mathbf{M}_{\sigma,n}^{y,\Theta\Phi} + \mathbf{v}_{\sigma,n}^{y,\Theta} \otimes \mathbf{M}_{\sigma,n}^{y,\Phi R} + \mathbf{v}_{\sigma,n}^{y,\Phi} \otimes \mathbf{M}_{\sigma,n}^{y,R\Theta} \right) $$
where:
*   $N_\sigma$ is the number of factorization terms [S2].
*   $\otimes$ denotes the outer product [S2].
*   $\mathbf{v}$ represents vector factors (e.g., $\mathbf{v}_{\sigma,n}^{y,R}$ is a vector along the radial axis $R$) [S2].
*   $\mathbf{M}$ represents matrix factors (e.g., $\mathbf{M}_{\sigma,n}^{y,\Theta\Phi}$ is a matrix spanning the $\Theta$ and $\Phi$ axes) [S2].
*   The indices $R, \Theta, \Phi$ correspond to the radial, polar, and azimuthal dimensions of the spherical grid [S2].

For the appearance grid $\mathcal{G}_a^y$, the decomposition is:
$$ \mathcal{G}_a^y = \sum_{n=1}^{N_a} \left( \mathcal{A}_{a,n}^{y,R} \otimes \mathbf{b}_{3n-2}^y + \mathcal{A}_{a,n}^{y,\Theta} \otimes \mathbf{b}_{3n-1}^y + \mathcal{A}_{a,n}^{y,\Phi} \otimes \mathbf{b}_{3n}^y \right) $$
where:
*   $N_a$ is the number of factorization terms [S2].
*   $\mathcal{A}$ represents matrix factors (e.g., $\mathcal{A}_{a,n}^{y,R}$ spans the $\Theta$ and $\Phi$ axes) [S2].
*   $\mathbf{b}$ represents vector factors (e.g., $\mathbf{b}_{3n-2}^y$ is a vector along the radial axis $R$) [S2].

**Lookup and Decoding:**
Given a query point $\mathbf{x}$ and direction $\mathbf{d}$:
1.  Perform trilinear interpolation $\mathcal{T}$ on the decomposed grids to retrieve the density and appearance features [S2].
2.  Compute density: $\sigma(\mathbf{x}) = \mathcal{T}(\mathcal{G}_\sigma, \mathbf{x})$ [S2].
3.  Compute color: $c(\mathbf{x}, \mathbf{d}) = f_{\text{MLP}}(\mathcal{T}(\mathcal{G}_a, \mathbf{x}), \mathbf{d})$, where $f_{\text{MLP}}$ is a small neural network decoding the appearance features and viewing direction into color [S2].

**Pseudocode:**
```python
def query_feature_grid(x, d, grids, mlp):
    """
    Query density and color from the decomposed feature grids.
    
    Args:
        x: Continuous 3D coordinate vector (r, theta, phi) in spherical space.
        d: Viewing direction vector.
        grids: Dictionary containing decomposed factors for Yin and Yang components.
        mlp: A small neural network function f_MLP(features, direction) -> color.
    
    Returns:
        sigma: Scalar volume density.
        c: Color vector.
    """
    
    def eval_tensor_at(x, factors):
        """Evaluate the decomposed density tensor at continuous coordinate x."""
        r, theta, phi = x
        total = 0.0
        for n in range(len(factors['v_R'])):
            # Term 1: v_R(n) outer M_ThetaPhi(n)
            v_r = interpolate_1d(factors['v_R'][n], r)
            m_tp = interpolate_2d(factors['M_ThetaPhi'][n], theta, phi)
            total += v_r * m_tp
            
            # Term 2: v_Theta(n) outer M_PhiR(n)
            v_t = interpolate_1d(factors['v_Theta'][n], theta)
            m_pr = interpolate_2d(factors['M_PhiR'][n], phi, r)
            total += v_t * m_pr
            
            # Term 3: v_Phi(n) outer M_RTheta(n)
            v_p = interpolate_1d(factors['v_Phi'][n], phi)
            m_rt = interpolate_2d(factors['M_RTheta'][n], r, theta)
            total += v_p * m_rt
        return total

    def eval_appearance_at(x, factors):
        """Evaluate the decomposed appearance tensor at continuous coordinate x."""
        r, theta, phi = x
        total_features = []
        for n in range(len(factors['A_R'])):
            # Term 1: A_R(n) outer b_0(n)
            a_r = interpolate_2d(factors['A_R'][n], theta, phi)
            b_0 = interpolate_1d(factors['b_0'][n], r)
            total_features.append(a_r * b_0)
            
            # Term 2: A_Theta(n) outer b_1(n)
            a_t = interpolate_2d(factors['A_Theta'][n], r, phi)
            b_1 = interpolate_1d(factors['b_1'][n], theta)
            total_features.append(a_t * b_1)
            
            # Term 3: A_Phi(n) outer b_2(n)
            a_p = interpolate_2d(factors['A_Phi'][n], r, theta)
            b_2 = interpolate_1d(factors['b_2'][n], phi)
            total_features.append(a_p * b_2)
            
        return sum(total_features)

    # 1. Reconstruct Density
    sigma_yin = eval_tensor_at(x, grids['sigma']['Yin'])
    sigma_yang = eval_tensor_at(x, grids['sigma']['Yang'])
    sigma = sigma_yin + sigma_yang
    
    # 2. Reconstruct Appearance Features
    feat_yin = eval_appearance_at(x, grids['appearance']['Yin'])
    feat_yang = eval_appearance_at(x, grids['appearance']['Yang'])
    features = feat_yin + feat_yang
    
    # 3. Decode Color
    c = mlp(features, d)
    
    return sigma, c

def interpolate_1d(vec, coord):
    """Trilinear interpolation helper for 1D vector."""
    idx = coord * (len(vec) - 1)
    i = int(idx)
    w = idx - i
    i = max(0, min(i, len(vec) - 2))
    return vec[i] * (1 - w) + vec[i + 1] * w

def interpolate_2d(mat, u, v):
    """Bilinear interpolation helper for 2D matrix."""
    idx_u = u * (mat.shape[0] - 1)
    idx_v = v * (mat.shape[1] - 1)
    i, j = int(idx_u), int(idx_v)
    w_u, w_v = idx_u - i, idx_v - j
    i, j = max(0, min(i, mat.shape[0] - 2)), max(0, min(j, mat.shape[1] - 2))
    return (mat[i, j] * (1 - w_u) * (1 - w_v) +
            mat[i+1, j] * w_u * (1 - w_v) +
            mat[i, j+1] * (1 - w_u) * w_v +
            mat[i+1, j+1] * w_u * w_v)
```

**Parameters:**
*   $N_y^r, N_y^\theta, N_y^\phi$: Grid resolutions for radial, polar, and azimuthal dimensions [S2].
*   $N_\sigma, N_a$: Number of factorization terms for density and appearance [S2].
*   $C$: Dimension of appearance features [S2].

**Edge Cases:**
*   **Boundary Conditions:** Trilinear interpolation $\mathcal{T}$ requires handling coordinates outside the grid bounds. Standard clamping or periodic boundary conditions should be applied [G].
*   **Precision:** The decomposition involves summing multiple outer products. Numerical stability should be monitored, especially for large $N_\sigma$ or $N_a$ [G].

## Subtopics

### [Masked Wavelet Representation for Compact Neural Radiance Fields](9619-masked-wavelet-representation-for-compact-neural-radiance-fi.md)
Masked Wavelet Representation (MW-NeRF) reduces the memory footprint of grid-based neural radiance fields by transforming spatial grid coefficients into the wavelet domain, applying a trainable binary mask to induce sparsity, and compressing the result. It sets itself apart from standard grid-based methods like [Feature Grid as Radiance Field](5508-feature-grid-as-radiance-field.md) by leveraging the compactness of wavelet coefficients for smooth signals and per-scene optimized masking, achieving state-of-the-art performance within a 2 MB memory budget.

### [3D Bilateral Grid Slicing](10529-3d-bilateral-grid-slicing.md)
3D Bilateral Grid Slicing is a method for approximating continuous, view-dependent color transformations (such as Image Signal Processing or ISP) in neural radiance fields by storing affine transformation matrices in a 3D grid indexed by spatial coordinates $(x, y)$ and a color guidance coordinate (typically grayscale intensity). It solves the problem of applying non-linear, spatially-varying color corrections to rendered images by learning a mapping from pixel position and color to an affine matrix, avoiding the need for explicit per-pixel parameter networks. It differs from sibling methods like Masked Wavelet Representation by focusing on explicit color-space transformations via grid lookup rather than compacting the underlying radiance field features.

## Operating characteristics
*   **Time Complexity:** Query time is $O(1)$ per sample, dominated by the trilinear interpolation and the small MLP evaluation. The reconstruction from factors adds a constant overhead proportional to the number of factorization terms $N_\sigma$ and $N_a$ [S2].
*   **Memory Complexity:** The low-rank tensor factorization reduces space complexity from $O(n^3)$ to $O(n^2)$, where $n$ is the grid resolution [S2].
*   **Strengths:** Efficient memory usage for high-resolution spherical grids; regular grid structure simplifies implementation and interpolation; suitable for egocentric scenes with spherical symmetry [S2].
*   **Limitations:** The spherical parameterization may not be optimal for non-spherical or planar scenes; the decomposition introduces hyperparameters ($N_\sigma, N_a$) that require tuning [S2].
*   **When to Use:** Egocentric view synthesis where the scene exhibits spherical symmetry and memory is a constraint [S2].
*   **When Not to Use:** Scenes with strong planar structures or non-spherical geometry where hash grids or voxel grids might be more efficient [G].

## Background
The method was introduced in the paper "Balanced Spherical Grid for Egocentric View Synthesis" (EgoNeRF) [S2]. It addresses the limitations of MLP-based radiance fields in terms of memory and training speed for egocentric data, which often covers a large spherical field of view. By using explicit feature grids with low-rank factorization, it achieves a balance between the flexibility of neural fields and the efficiency of grid-based methods [S2].
