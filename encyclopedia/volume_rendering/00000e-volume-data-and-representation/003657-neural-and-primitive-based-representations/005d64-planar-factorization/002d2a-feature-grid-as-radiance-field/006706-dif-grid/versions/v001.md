# DiF-Grid

Also called: Two-Factor Neural Field with 3D Grids

## Overview
DiF-Grid is a two-factor neural field representation that decomposes a radiance field into a local coefficient field and a global basis field, both implemented as 3D feature grids [S1, unofficial]. It solves the problem of balancing reconstruction quality, training speed, and memory efficiency in single-scene radiance field reconstruction. It sets itself apart from single-factor baselines (like Instant-NGP or Plenoxels) by jointly optimizing local and global factors, achieving superior compactness and quality, while using standard PyTorch instead of custom CUDA frameworks [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A set of $N$ images with known camera poses and intrinsics.
- Output: A radiance field function $F(\mathbf{x})$ parameterized by two 3D grids, capable of predicting density $\sigma$ and color $\mathbf{c}$ for any 3D coordinate $\mathbf{x}$.

**Data Structures:**
The model consists of two factors, both stored as 3D grids.
1.  **Local Coefficient Grid ($G_c$):** A 3D grid storing local coefficients.
2.  **Global Basis Grid ($G_b$):** A 3D grid storing global basis vectors.
3.  **Coordinate Transformation:** Both factors use the Sawtooth coordinate transformation $\gamma(\mathbf{x})$ to handle periodicity and aliasing [S1, unofficial].

**Formulas:**
The radiance field is computed by the element-wise product (Field Connector) of the two factors [S1, unofficial]:
$$ F(\mathbf{x}) = G_c(\gamma(\mathbf{x})) \odot G_b(\gamma(\mathbf{x})) $$
Where $\odot$ denotes the element-wise product. The Sawtooth transformation $\gamma(\mathbf{x})$ maps input coordinates $\mathbf{x}$ to a periodic domain suitable for grid lookup [S1, unofficial].

**Parameters:**
- Grid Resolution: 4096 (implied by comparison table dimensions) [S1, unofficial].
- Number of Factors: 2 [S1, unofficial].
- Factor Types: 3D Grids for both [S1, unofficial].

```python
        nn.init.uniform_(self.grid_b.weight, -0.01, 0.01)

        """

    def forward(self, x):
        """
        x: [N, 3] tensor of 3D coordinates
        Returns: [N, feature_dim] tensor of features
        """
        # Transform coordinates
        idx_c = self.sawtooth_transform(x)
        idx_b = self.sawtooth_transform(x)
        
        # Flatten indices for embedding lookup
        # Not given in the sources: how 3D indices are flattened to 1D
        # Assuming row-major order: i * H * W + j * W + k
        flat_idx_c = idx_c[:, 0] * self.grid_size * self.grid_size + \
                     idx_c[:, 1] * self.grid_size + idx_c[:, 2]
        flat_idx_b = idx_b[:, 0] * self.grid_size * self.grid_size + \
                     idx_b[:, 1] * self.grid_size + idx_b[:, 2]
        
        # Lookup features
        feat_c = self.grid_c(flat_idx_c)
        feat_b = self.grid_b(flat_idx_b)
        
        # Element-wise product (Field Connector)
        out = feat_c * feat_b
        
        return out
```

**Edge Cases and Pitfalls:**
- **Precision:** The Sawtooth transformation requires careful handling of boundary conditions to avoid discontinuities [S1, unofficial].
- **Degenerate Input:** The method assumes well-defined camera poses and intrinsics.

## Operating characteristics
- **Time Complexity:** Training time on Synthetic-NeRF is 12.2 minutes [S1, unofficial]. Faster than TensoRF (17.4m) and DVGO (15.0m), but slower than Instant-NGP (3.9m) [S1, unofficial].
- **Memory Complexity:** Model size is 5.1M parameters on Synthetic-NeRF [S1, unofficial]. More compact than Instant-NGP (11.64M) and TensoRF-VM (17.95M) [S1, unofficial].
- **Measured Performance:**
    - Synthetic-NeRF: 33.14 PSNR, 0.961 SSIM [S1, unofficial].
    - 2D Images: 39.51 PSNR, 0.963 SSIM [S1, unofficial].
    - Few-shot RF: 25.41 PSNR, 0.915 SSIM [S1, unofficial].
- **Strengths:** State-of-the-art quality and efficiency for single-scene reconstruction; uses standard PyTorch, making it easily extendable [S1, unofficial].
- **Limitations:** For few-shot radiance field reconstruction, representations with stronger inductive biases (like Vectors in TensoRF-VM or MLPs in DiF-MLP-B) lead to better quality [S1, unofficial].
- **When to use:** Single-scene radiance field reconstruction where high quality and moderate training speed are required, and custom CUDA kernels are undesirable.
- **When not to use:** Few-shot or generalizable radiance field reconstruction where inductive biases are critical.

## Background
DiF-Grid was introduced in "Factor Fields: A Unified Framework for Neural Fields and Beyond" [S1, unofficial]. It is part of the Factor Fields framework, which unifies various neural field representations by decomposing them into local and global factors. The method was developed to address the limitations of single-factor models that optimize signals separately, lacking the ability to model multiple signals jointly or learn useful priors [S1, unofficial].
