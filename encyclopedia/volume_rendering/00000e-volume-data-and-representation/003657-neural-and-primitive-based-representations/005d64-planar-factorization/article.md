# Planar Factorization

## Overview
Planar Factorization methods represent continuous volumetric or spatiotemporal fields by decomposing high-dimensional feature tensors into a set of lower-dimensional 2D planes [G]. This approach solves the memory and computational bottlenecks of dense 3D/4D voxel grids and the black-box nature of pure MLP fields by using explicit, learnable planar structures [G]. Unlike sibling methods that aggregate features via concatenation or summation, this family typically employs element-wise multiplication (Hadamard product) of plane features to achieve spatial localization, enabling efficient decoding [S1, S2].

## Shared principles
All methods in this family define a scene function $F_\Theta: \mathbb{R}^d \rightarrow \mathbb{R}^k$ using a set of parameterized 2D feature planes [G]. The input is a continuous coordinate vector $\mathbf{q} \in \mathbb{R}^d$ (typically spatial $\mathbf{x}$, viewing direction $\mathbf{d}$, or time $t$) [G]. The output is a signal vector (e.g., density $\sigma$ and color $\mathbf{c}$) [G].

The core mechanism involves projecting the $d$-dimensional query point onto $k = \binom{d}{2}$ orthogonal 2D planes [S2]. For each plane $c$, features are retrieved via interpolation (bilinear or trilinear) from the plane grid $\mathbf{P}_c$ [S1, S2]. These features are then combined, typically via element-wise multiplication (Hadamard product) $\mathbf{f}(\mathbf{q}) = \prod_{c \in C} \mathbf{f}_c(\mathbf{q})$, to form a fused feature vector [S1, S2]. This product operation ensures that the resulting feature is non-zero only if the point lies within the active regions of all constituent planes, providing spatial localization [S2]. The fused features are then decoded into density and color, either via a linear decoder with a learned basis or a small MLP [S2].

## Subtopics

### [K-planes](3317-k-planes.md)
A white-box hybrid representation for volumetric rendering in arbitrary dimensions $d$ that factorizes the scene function into $k = \binom{d}{2}$ learned 2D feature planes. It solves the scalability and black-box nature of implicit neural fields by using explicit planar grids combined with a decoder, achieving high compression (e.g., 1000x over 4D grids) and fast optimization. Unlike sibling methods that add features from planes, K-planes multiplies them element-wise, which enables spatial localization and allows the use of a linear decoder with a learned color basis instead of a non-linear MLP.

### [Forplane](5177-forplane.md)
A neural implicit representation method designed for efficient 4D (spatiotemporal) reconstruction of deformable scenes, specifically targeting surgical video where tools cause occlusions and tissues deform. It solves the high computational cost of 4D volume traversal by factorizing the 4D volume into a static 3D field and a dynamic 3D field, both represented by 2D orthogonal planes. Unlike methods that treat time steps as independent static volumes or rely on displacement fields, Forplane separates static scene priors from dynamic deformations, reducing computational complexity from $O(N^4)$ to $O(N^2)$ while maintaining reconstruction quality. It builds on [Neural and primitive-based representations](10-neural-and-primitive-based-representations.md) by using a factorized grid structure instead of a monolithic MLP or voxel grid.

### [Feature Grid as Radiance Field](5508-feature-grid-as-radiance-field.md)
Represents a scene using explicit, low-rank tensor-decomposed feature grids for density and appearance, replacing the implicit multi-layer perceptron (MLP) regression used in standard Neural Radiance Fields. It solves the memory bottleneck of dense 3D grids by factorizing the feature tensors into lower-dimensional components, reducing space complexity from cubic to quadratic relative to resolution. Unlike sibling methods that rely on hash grids [Hash Grid Neural Fields](3855-hash-grid-neural-fields.md) or Gaussian primitives [Gaussian Head Avatar (GHA)](1478-gaussian-head-avatar-gha.md), this method maintains a regular grid structure optimized for spherical parameterization, specifically targeting egocentric view synthesis.

### Factor Aggregation
A permutation-invariant factor blending scheme using self-attention to predict weights for selected core and basis factors and blend them [S1]. Given $\hat{C}$ selected shared core and $\hat{L}$ basis factors for each query point, the method predicts a weight for each factor and blends factors of the same groups using a self-attention mechanism [S1]. The aggregated tensor value at location $\mathbf{x}$ is computed as $\mathcal{G}(\mathbf{x}) = \ddot{\mathcal{V}} \circ \ddot{\mathcal{M}} \circ \mathcal{M}$, where $\ddot{\mathcal{V}} = \sum_{i=1}^{\hat{C}} w_i^{\ddot{V}} \ddot{V}_i(\ddot{t}_i)$, $\ddot{\mathcal{M}} = \sum_{i=1}^{\hat{C}} w_i^{\ddot{M}} \ddot{M}_i(\ddot{v}_i)$, and $\mathcal{M} = \sum_{j=1}^{\hat{L}} w_j^{M} M_j(v_j)$ [S1]. The blending weights $w$ are obtained via a trainable linear transformation with sigmoid activation [S1].

### Occupancy-Guided RGB-DINO Field
A neural representation that integrates color and semantic fields by sharing a single ground feature plane $M_{\text{rgb-dino}}$, guided by scene density features to decode 3D-aware features, solving the issue of vertical displacement causing feature divergence [S2]. For a query point at $(x, y, z)$, the method retrieves density feature $m_\sigma$ and vertical axis feature $h_\sigma$ [S2]. These are mapped to a color feature $v_{\text{rgb}}$ and a semantic feature $v_{\text{dino}}$ via two MLPs [S2]. The color feature $v_{\text{rgb}}$ and semantic feature $v_{\text{dino}}$ are then decoded along with the RGB-DINO plane feature $m_{\text{rgb-dino}} = \text{Interp}(M_{\text{rgb-dino}}, (x, y))$ using decoders $\text{Dec}_{\text{rgb}}$ and $\text{Dec}_{\text{dino}}$ to produce scene color $\mathbf{c}$ and semantic output $f_{\text{dino}}$ [S2].

## Background
Planar factorization emerged as a solution to the high memory costs of 3D/4D neural fields [G]. K-planes introduced the concept of factorizing 3D/4D fields into 2D planes using Hadamard products to enable linear decoding [S2]. Forplane adapted this for dynamic surgical scenes, separating static and dynamic components [S1]. Feature Grid as Radiance Field applied tensor factorization to spherical grids for egocentric views [S2].
