# Forplane

Also called: Factorized Implicit Representation, Fast Orthogonal Plane Representation, Orthogonal Neural Plane

## Overview
Forplane is a neural implicit representation method for efficient 4D (spatiotemporal) reconstruction of deformable scenes, specifically targeting surgical video where tools cause occlusions and tissues deform [S1]. It solves the high computational cost of 4D volume traversal by factorizing the 4D volume into a static 3D field and a dynamic 3D field, both represented by 2D orthogonal planes [S1]. Unlike methods that treat time steps as independent static volumes or rely on displacement fields, Forplane separates static scene priors from dynamic deformations, reducing computational complexity from $O(N^4)$ to $O(N^2)$ while maintaining reconstruction quality [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Monocular or binocular endoscopy video frames at various time steps $\tau$ [S1].
*   **Output:** Predicted color $\hat{C}$ and density $\sigma$ for any 3D spatial coordinate $\mathbf{x}$ at a specific time $\tau$, enabling volume rendering of the scene [S1].
*   Camera intrinsics and extrinsics are required for ray casting [G].

**Data Structures:**
The representation consists of two sets of 2D feature planes, each with dimensions $N \times N \times D$ (space) or $N \times M \times D$ (space-time), where $N$ is spatial resolution, $M$ is temporal resolution, and $D$ is the feature dimension [S1].
1.  **Static Field ($V_s^{3d}$):** Composed of three orthogonal space planes: $G_{XY}, G_{YZ}, G_{XZ}$ [S1].
2.  **Dynamic Field ($V_d^{3d}$):** Composed of three orthogonal space-time planes: $G_{TX}, G_{TY}, G_{TZ}$ [S1].
3.  **MLP ($\theta$):** A lightweight network with 2 fully connected layers, each having 64 channels [S1].

**Algorithm Steps:**
1.  **Ray Casting:** For a target tissue pixel $p_{ij}$ at time step $\tau$, cast a ray $\mathbf{r}(t)$ from the camera origin $\mathbf{x}_o$ through the pixel [S1].
2.  **Spatiotemporal Sampling:** Sample points along the ray to obtain 4D coordinates $(x, y, z, \tau)$ [S1]. The method employs spatiotemporal importance sampling to prioritize pixels that are occluded by tools or exhibit significant motion, addressing the issue of infrequent representation of occluded tissues and redundant training on stationary tissues [S1].
3.  **Feature Querying:** For each sampled point $\mathbf{P}(x, y, z, \tau)$, query features from the six planes using bilinear interpolation $\mathcal{B}$ [S1]. Static features are queried from $G_{XY}, G_{YZ}, G_{XZ}$ using spatial coordinates, while dynamic features are queried from $G_{TX}, G_{TY}, G_{TZ}$ using spatial and temporal coordinates [S1]. The fused feature vector $\mathbf{v}$ is computed by element-wise multiplication ($\odot$) of the interpolated features:
    $$
    \mathbf{v}(x, y, z, \tau) = \mathcal{B}(G_{XY}, x, y) \odot \mathcal{B}(G_{YZ}, y, z) \odot \mathcal{B}(G_{XZ}, x, z) \odot \mathcal{B}(G_{TX}, x, \tau) \odot \mathcal{B}(G_{TY}, y, \tau) \odot \mathcal{B}(G_{TZ}, z, \tau)
    $$
    The source formula contains a typo ($G_{YT}, G_{ZT}$ instead of $G_{TY}, G_{TZ}$) and omits $G_{XZ}$ and $G_{TX}$ in the snippet, but the text explicitly defines the six planes and their coordinate mappings [S1].
4.  **MLP Prediction:** Concatenate the fused feature vector $\mathbf{v}$ with positional encoded coordinates and time embeddings, then pass this combined vector through the MLP $\theta$ to predict density $\sigma$ and color $\mathbf{c}$ [S1].
5.  **Volume Rendering:** Compute the predicted color $\hat{C}(\mathbf{r})$ for the ray using volume rendering integration:
    $$
    \hat{C}(\mathbf{r}) = \int_{t_n}^{t_f} w(t) \mathbf{c}(\mathbf{r}(t), \mathbf{d}) dt
    $$
    where $w(t)$ is the weight determined by density and transmittance, $t_n$ and $t_f$ are near and far clipping planes, and $\mathbf{d}$ is the viewing direction [S1].

**Pseudocode:**
```python
import numpy as np

def bilinear_interp(plane, u, v):
    u = np.clip(u, 0, plane.shape[0] - 1)
    v = np.clip(v, 0, plane.shape[1] - 1)
    u0, v0 = np.floor(u).astype(int), np.floor(v).astype(int)
    u1, v1 = np.minimum(u0 + 1, plane.shape[0] - 1), np.minimum(v0 + 1, plane.shape[1] - 1)
    du, dv = u - u0, v - v0
    q00, q10 = plane[u0, v0, :], plane[u1, v0, :]
    q01, q11 = plane[u0, v1, :], plane[u1, v1, :]
    return (q00 * (1 - du) + q10 * du) * (1 - dv) + (q01 * (1 - du) + q11 * du) * dv

def query_forplane(G_static, G_dynamic, x, y, z, tau):
    v_xy = bilinear_interp(G_static['XY'], x, y)
    v_yz = bilinear_interp(G_static['YZ'], y, z)
    v_xz = bilinear_interp(G_static['XZ'], x, z)
    v_tx = bilinear_interp(G_dynamic['TX'], x, tau)
    v_ty = bilinear_interp(G_dynamic['TY'], y, tau)
    v_tz = bilinear_interp(G_dynamic['TZ'], z, tau)
    return v_xy * v_yz * v_xz * v_tx * v_ty * v_tz

def predict_sigma_color(v, pos_enc, W1, b1, W2, b2):
    input_vec = np.concatenate([v, pos_enc])
    h = np.maximum(0, input_vec @ W1 + b1)
    out = h @ W2 + b2
    return out[0], out[1:]

def render_ray(G_static, G_dynamic, ray_origin, ray_direction, tau, near, far, num_samples, W1, b1, W2, b2):
    t_vals = np.linspace(near, far, num_samples)
    points = ray_origin + ray_direction * t_vals[:, np.newaxis]
    x, y, z = points[:, 0], points[:, 1], points[:, 2]
    features = query_forplane(G_static, G_dynamic, x, y, z, tau)
    pos_enc = np.ones_like(x) # Positional encoding generation [G]
    sigmas, colors = predict_sigma_color(features, pos_enc, W1, b1, W2, b2)
    deltas = np.diff(t_vals)
    deltas = np.append(deltas, 1e-10)
    alphas = 1.0 - np.exp(-sigmas * deltas)
    transmittance = np.exp(-np.cumsum(sigmas * deltas))
    weights = alphas * transmittance
    return np.sum(weights[:, np.newaxis] * colors, axis=0)
```

**Parameters:**
*   **MLP Architecture:** 2 fully connected layers, 64 channels each [S1].
*   **Plane Dimensions:** $N \times N \times D$ for static, $N \times M \times D$ for dynamic. $N$ is spatial resolution, $M$ is temporal resolution, $D$ is feature size [S1].
*   **Multi-resolution:** Both static and dynamic fields use multi-resolution planes, inspired by hybrid representations [S1].

**Edge Cases and Pitfalls:**
*   **Tool Occlusion:** Tools occlude tissues, leading to infrequent representation in training data and inaccurate reconstruction of occluded areas [S1]. The method uses spatiotemporal importance sampling to mitigate this by prioritizing these difficult pixels [S1].
*   **Stationary Tissues:** Repeated training on stationary tissues yields minimal convergence impact and reduces efficiency [S1]. Importance sampling also addresses this by reducing redundant updates [S1].
*   **Precision:** Bilinear interpolation is used for feature querying. Ensure coordinate normalization matches the plane dimensions [S1].

## Operating characteristics
*   **Complexity:** Reduces computational cost from $O(N^4)$ (traversing all spacetime positions) to $O(N^2)$ (querying 2D planes) [S1].
*   **Memory:** Memory usage is determined by the size of the six planes ($6 \times N^2 \times D$ or $6 \times N \times M \times D$) plus the small MLP [S1].
*   **Performance:** Faster convergence and inference compared to methods treating time steps independently or using displacement fields [S1].
*   **Strengths:** Efficient handling of 4D data, ability to model arbitrary deformations without topology changes, sharing of static scene priors across time steps [S1].
*   **Limitations:** Relies on the assumption that deformations can be factorized into static and dynamic components [S1]. Performance may degrade if the factorization assumption is violated or if occlusions are severe and not well-handled by the sampling strategy [S1].

## Background
Forplane was introduced in "Efficient Deformable Tissue Reconstruction via Orthogonal Neural Plane" (2024) [S1]. It addresses challenges in surgical scene reconstruction, specifically deformable tissue and tool occlusion [S1]. It builds on techniques from NeRF and EndoNeRF [S1]. The method is designed for medical imaging applications, particularly endoscopy [S1].
