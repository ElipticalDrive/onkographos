# Forplane

Also called: Factorized Implicit Representation, Fast Orthogonal Plane Representation, Orthogonal Neural Plane

## Overview
Forplane is a neural implicit representation method designed for efficient 4D reconstruction of deformable scenes, specifically targeting surgical endoscopy videos [S1]. It solves the problem of reconstructing dynamic, deformable tissues from monocular or binocular video by factorizing the 4D volume into a static 3D field and a dynamic 3D field, both represented by orthogonal 2D neural planes [S1]. Unlike methods that treat time steps as independent static volumes or rely on displacement fields that struggle with topological changes, Forplane uses space-time planes to model arbitrary deformations while sharing scene priors across time [S1]. It distinguishes itself from its sibling [K-planes](3317-k-planes.md) by explicitly separating static and dynamic components into distinct plane sets (space vs. space-time) and from [Feature Grid as Radiance Field](5508-feature-grid-as-radiance-field.md) by its specific application to deformable tissue reconstruction with spatiotemporal importance sampling [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A sequence of endoscopic images (monocular or binocular) at various time steps $\tau$ [S1].
*   **Output:** A continuous function predicting density $\sigma$ and color $\mathbf{c}$ for any 4D coordinate $(x, y, z, \tau)$, enabling volume rendering of the tissue surface [S1].

**Data Structures:**
The representation consists of two fields: a static field $V_{s3d}$ and a dynamic field $V_{d3d}$ [S1]. Both use multi-resolution planes [S1].

1.  **Static Field $V_{s3d}$:** Composed of three orthogonal space planes: $G_{XY}, G_{YZ}, G_{XZ}$ [S1].
    *   Layout: Each plane is a 3D tensor of size $N \times N \times D$ [S1].
    *   $N$: Spatial resolution [S1].
    *   $D$: Feature size (dimensionality of the feature vector) [S1].
2.  **Dynamic Field $V_{d3d}$:** Composed of three orthogonal space-time planes: $G_{TX}, G_{TY}, G_{TZ}$ [S1].
    *   Layout: Each plane is a 3D tensor of size $N \times M \times D$ [S1].
    *   $N$: Spatial resolution [S1].
    *   $M$: Temporal resolution [S1].
    *   $D$: Feature size [S1].

**Algorithm Steps:**

1.  **Ray Casting:** For a target tissue pixel $p_{ij}$ at time step $\tau$, cast a ray $\mathbf{r}(t)$ from the camera origin $\mathbf{x}_o$ through the pixel [S1].
2.  **Spatiotemporal Sampling:** Sample points along the ray to obtain 4D coordinates $\mathbf{q} = (x, y, z, \tau)$ [S1]. The method employs a spatiotemporal importance sampling strategy to prioritize pixels occluded by tools or exhibiting extensive motion, and to reduce redundant training on stationary tissues [S1].
3.  **Feature Query:** For each sampled point $\mathbf{q}=(x,y,z,\tau)$, query features from the six planes using bilinear interpolation $\mathcal{B}$ [S1]. The fused feature vector is computed as:
    $$ \mathbf{v}(x, y, z, \tau) = \mathcal{B}(G_{XY}, x, y) \odot \mathcal{B}(G_{YZ}, y, z) \odot \mathcal{B}(G_{XZ}, x, z) \odot \mathcal{B}(G_{TX}, \tau, x) \odot \mathcal{B}(G_{TY}, \tau, y) \odot \mathcal{B}(G_{TZ}, \tau, z) $$
    where $\odot$ denotes element-wise multiplication [S1].
4.  **Decoding:** Concatenate $\mathbf{v}$ with positional encoded coordinates and time embeddings, then pass the result through a lightweight MLP $\theta$ to predict density $\sigma$ and color $\mathbf{c}$ [S1]. The MLP architecture consists of 2 fully connected layers, each with 64 channels [S1].
5.  **Volume Rendering:** Compute the predicted color $\hat{C}(\mathbf{r})$ for the ray using volume rendering integration:
    $$ \hat{C}(\mathbf{r}) = \int_{t_n}^{t_f} w(t) \mathbf{c}(\mathbf{r}(t), \mathbf{d}) dt $$
    where $w(t)$ is the accumulated weight along the ray [S1].

**Pseudocode:**

```python
import numpy as np

def bilinear_interp(grid, u, v):
    """Standard bilinear interpolation on a 2D grid slice (H, W, D).
    Args:
        grid: numpy array of shape (H, W, D)
        u, v: continuous coordinates in [0, H-1] and [0, W-1]
    Returns:
        feature vector of shape (D,)
    """
    # Clamp coordinates to valid range
    u = np.clip(u, 0.0, grid.shape[0] - 1.0)
    v = np.clip(v, 0.0, grid.shape[1] - 1.0)
    
    # Floor and ceil indices
    u0, v0 = np.floor(u).astype(int), np.floor(v).astype(int)
    u1, v1 = u0 + 1, v0 + 1
    
    # Handle boundary cases
    u1 = np.clip(u1, 0, grid.shape[0] - 1)
    v1 = np.clip(v1, 0, grid.shape[1] - 1)
    
    # Interpolation weights
    du, dv = u - u0, v - v0
    
    # Fetch 4 corners
    q00 = grid[u0, v0, :]
    q01 = grid[u0, v1, :]
    q10 = grid[u1, v0, :]
    q11 = grid[u1, v1, :]
    
    # Bilinear combination
    return (1 - du) * (1 - dv) * q00 + (1 - du) * dv * q01 + du * (1 - dv) * q10 + du * dv * q11

def positional_encoding(x, y, z, tau, num_freqs=10):
    """Standard NeRF-style positional encoding [G].
    Args:
        x, y, z, tau: scalar coordinates
        num_freqs: number of frequency bands
    Returns:
        concatenated sin/cos encoded vector
    """
    coords = np.array([x, y, z, tau])
    scales = 2.0 ** np.arange(num_freqs)
    encoded = []
    for coord in coords:
        for freq in scales:
            val = coord * freq * np.pi
            encoded.extend([np.sin(val), np.cos(val)])
    return np.array(encoded)

def query_forplane(q_xyz, tau, G_XY, G_YZ, G_XZ, G_TX, G_TY, G_TZ, MLP):
    """Query the Forplane representation for a single 4D point.
    Args:
        q_xyz: numpy array of shape (3,), coordinates (x, y, z).
        tau: float, time coordinate.
        G_XY, G_YZ, G_XZ: numpy arrays of shape (N, N, D), static space planes.
        G_TX, G_TY, G_TZ: numpy arrays of shape (N, M, D), dynamic space-time planes.
        MLP: callable taking a feature vector and returning [sigma, r, g, b].
    Returns:
        sigma: float, predicted density.
        c: numpy array of shape (3,), predicted color.
    """
    x, y, z = q_xyz
    
    # Query all six planes
    f_xy = bilinear_interp(G_XY, x, y)
    f_yz = bilinear_interp(G_YZ, y, z)
    f_xz = bilinear_interp(G_XZ, x, z)
    f_tx = bilinear_interp(G_TX, tau, x)
    f_ty = bilinear_interp(G_TY, tau, y)
    f_tz = bilinear_interp(G_TZ, tau, z)
    
    # Fused feature vector via element-wise multiplication
    v = f_xy * f_yz * f_xz * f_tx * f_ty * f_tz
    
    # Concatenate with positional encodings
    pos_enc = positional_encoding(x, y, z, tau)
    input_vector = np.concatenate([v, pos_enc])
    
    # Decode
    output = MLP(input_vector)
    
    sigma = output[0]
    c = output[1:4]
    
    return sigma, c

def render_forplane(ray_origin, ray_direction, tau, G_XY, G_YZ, G_XZ, G_TX, G_TY, G_TZ, MLP, t_near, t_far, num_samples):
    """Render a single ray using Forplane [G]."""
    t_vals = np.linspace(t_near, t_far, num_samples)
    points = ray_origin + ray_direction * t_vals[:, np.newaxis]
    
    color_acc = np.zeros(3)
    alpha_acc = 0.0
    transmittance = 1.0
    
    for i in range(num_samples):
        sigma, c = query_forplane(points[i], tau, G_XY, G_YZ, G_XZ, G_TX, G_TY, G_TZ, MLP)
        
        delta_t = t_vals[i+1] - t_vals[i] if i < num_samples - 1 else t_far - t_vals[i]
        alpha = 1.0 - np.exp(-sigma * delta_t)
        
        weight = transmittance * alpha
        color_acc += weight * c
        transmittance *= (1.0 - alpha)
        
        if transmittance < 1e-4:
            break
            
    return color_acc
```

**Parameters:**
*   $N$: Spatial resolution of planes [S1].
*   $M$: Temporal resolution of dynamic planes [S1].
*   $D$: Feature size (dimensionality) [S1].
*   MLP: 2 fully connected layers, 64 channels each [S1].

**Edge Cases and Pitfalls:**
*   **Tool Occlusion:** Tools occlude tissues, leading to infrequent representation in training sets and inaccurate reconstruction of occluded areas [S1].
*   **Stationary Tissues:** Repeated training on stationary tissues yields minimal impact on convergence and reduces efficiency [S1].
*   **Topology Changes:** Unlike displacement fields, Forplane's dynamic field can model complex deformations and topology changes, which is a strength, but requires sufficient dynamic plane capacity [S1].

### [HUGS](17288-hugs.md)
A method for animating virtual human avatars using 3D Gaussian Splatting. It builds on the tri-plane representation to factorize canonical space, enabling reconstruction from monocular video. It distinguishes itself by bypassing inverse skinning, allowing for loose clothing and real-time rendering.

## Operating characteristics
*   **Complexity:** Reduces computational cost from $O(N^4)$ (traversing all spacetime positions) to $O(N^2)$ (querying planes) [S1].
*   **Performance:** Enables faster optimization and inference compared to treating time steps as independent static volumes or using complex displacement fields [S1].
*   **Strengths:**
    *   Efficient representation of 4D deformable scenes [S1].
    *   Shares learned scene priors across time steps via the static field [S1].
    *   Models arbitrary deformations without topology constraints [S1].
    *   Lightweight MLP (2 layers, 64 channels) reduces burden compared to methods like EndoNeRF (8 layers, 256 channels) [S1].
*   **Limitations:**
    *   Struggles with accurately reconstructing tissues occluded by tools due to lack of training data [S1].
    *   Efficiency can be degraded if not using importance sampling for stationary regions [S1].
*   **When to use:** Suitable for reconstructing deformable tissues from endoscopy videos where computational efficiency and handling of deformation are critical [S1].
*   **When not to use:** Not suitable for scenes with heavy tool occlusion where accurate reconstruction of occluded regions is required without additional strategies [S1].

## Background
Forplane was introduced in the paper "Efficient Deformable Tissue Reconstruction via Orthogonal Neural Plane" [S1]. It addresses challenges in surgical scene reconstruction, specifically the difficulty of modeling deformable tissues from monocular or binocular endoscopy videos [S1]. It builds on the principles of Planar Factorization [17382-planar-factorization.md] and improves upon previous methods like EndoNeRF [S1] by factorizing the 4D volume into static and dynamic fields using orthogonal planes.
