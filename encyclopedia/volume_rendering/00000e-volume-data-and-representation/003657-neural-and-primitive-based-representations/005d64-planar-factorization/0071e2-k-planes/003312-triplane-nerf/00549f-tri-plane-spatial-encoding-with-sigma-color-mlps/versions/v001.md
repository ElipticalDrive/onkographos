# Tri-plane Spatial Encoding with Sigma/Color MLPs

Also called: KFD-NeRF Spatial Model, Spatial Neural Architecture

## Overview
This method is the spatial representation component of the KFD-NeRF pipeline, designed to encode canonical 3D points for dynamic neural radiance fields. It solves the problem of balancing high-fidelity 3D reconstruction with computational efficiency and model size, which are critical for dynamic scenes. It sets itself apart from pure MLPs by avoiding convergence difficulties and from multi-scale voxel grids by achieving significantly smaller memory footprints while maintaining comparable or superior rendering quality [S1]. It builds on the TriPlane NeRF representation by adding a specific multi-scale feature aggregation strategy and a two-MLP decoding architecture (Sigma and Color) [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Warped 3D points $\mathbf{p}$ in canonical space, view directions $\mathbf{v}$, and time $t$ (for dynamic scenes, though the spatial encoding focuses on $\mathbf{p}$).
*   **Output:** Volume density $\sigma$ and RGB color $\mathbf{c}$.

**Data Structures:**
1.  **Tri-plane Grids:** Three axis-aligned planes ($c \in \{xy, yz, xz\}$) at four spatial scales ($s \in \{1, 2, 3, 4\}$).
    *   Resolutions: $64^2, 128^2, 256^2, 512^2$.
    *   Feature dimension per plane per scale: $d_{feat} = 32$.
    *   Total encoded feature dimension: $32 \times 4 = 128$.
2.  **Sigma Net:** Single-hidden-layer MLP.
    *   Input dimension: $128$ (encoded features) + $D_{pos}$ (positional encoded raw inputs).
    *   Hidden dimension: $64$.
    *   Output: Volume density $\sigma$ (scalar) and geometry features $\mathbf{g}$ (15-dimensional vector).
3.  **Color Net:** Two-hidden-layer MLP.
    *   Input dimension: $15$ (geometry features) + $D_{SH}$ (spherical harmonics encoded view directions).
    *   Hidden dimensions: $64, 64$.
    *   Output: RGB color $\mathbf{c}$.

**Parameters:**
*   Positional encoding frequency: $K=5$ for spatial inputs [S1].
*   Optimizer: Adam, learning rate $1 \times 10^{-3}$ [S1].
*   Ray batch size: 4096 [S1].

**Algorithm:**

1.  **Positional Encoding:** Apply positional encoding to the raw canonical 3D point coordinates $\mathbf{p}$. Let $PE(\mathbf{p})$ denote this vector. The frequency is set to 5 [S1].
2.  **Tri-plane Feature Extraction:** For each scale $s \in \{1, \dots, 4\}$:
    a. Project the 3D point $\mathbf{p}$ onto the three axis-aligned planes ($xy, yz, xz$) to obtain 2D coordinates $\mathbf{u}_{xy}, \mathbf{u}_{yz}, \mathbf{u}_{xz}$.
    b. Sample the feature grid at each plane for scale $s$ at the projected coordinates using bilinear interpolation. Let $F_{c,s}(\mathbf{u}_c)$ be the feature vector of dimension 32 for plane $c$ and scale $s$.
    c. Multiply the features across the three planes: $\mathbf{f}_{s} = F_{xy,s}(\mathbf{u}_{xy}) \odot F_{yz,s}(\mathbf{u}_{yz}) \odot F_{xz,s}(\mathbf{u}_{xz})$, where $\odot$ is element-wise multiplication.
3.  **Feature Aggregation:** Concatenate the features from all four scales: $\mathbf{f}_{tri} = [\mathbf{f}_1; \mathbf{f}_2; \mathbf{f}_3; \mathbf{f}_4]$. The resulting vector has dimension 128 [S1].
4.  **Coordinate Shift Mitigation:** Concatenate the aggregated tri-plane features with the positional encoded raw inputs to mitigate coordinate shifts caused by limited grid resolution and interpolation errors: $\mathbf{f}_{in} = [\mathbf{f}_{tri}; PE(\mathbf{p})]$ [S1].
5.  **Sigma Net Forward Pass:** Pass $\mathbf{f}_{in}$ through the Sigma Net (1 hidden layer, dim 64) to obtain volume density $\sigma$ and geometry features $\mathbf{g}$ (dim 15) [S1].
6.  **View Direction Encoding:** Encode the view direction $\mathbf{v}$ using spherical harmonics (SH) [S1].
7.  **Color Net Forward Pass:** Concatenate geometry features $\mathbf{g}$ with the SH-encoded view directions. Pass this concatenation through the Color Net (2 hidden layers, dim 64) to compute the final RGB color $\mathbf{c}$ [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class TriPlaneSpatialEncoder:
    def __init__(self, num_scales=4, base_res=64, feat_dim=32, sh_degree=3):
        """
        Initialize the Tri-plane Spatial Encoder.
        
        Args:
            num_scales (int): Number of scales (4).
            base_res (int): Base resolution (64). Resolutions are 64, 128, 256, 512.
            feat_dim (int): Feature dimension per plane per scale (32).
            sh_degree (int): Degree of spherical harmonics.
        """
        super().__init__()
        self.num_scales = num_scales
        self.feat_dim = feat_dim
        self.sh_degree = sh_degree
        
        # Tri-plane grids: 3 planes (xy, yz, xz) x num_scales
        # Each grid has shape (3, num_scales, feat_dim, H, W)
        # However, the paper describes multiplying across planes and concatenating across scales.
        # We store them as separate parameters for clarity.
        self.planes = nn.ParameterList([
            nn.Parameter(torch.randn(3, num_scales, feat_dim, base_res * (2**i), base_res * (2**i)))
            for i in range(num_scales)
        ])
        
        # Sigma Net: 1 hidden layer, dim 64
        # Input: 128 (tri-plane features) + PE_dim (raw coords PE)
        # PE frequency is 5, so for 3D coords, PE_dim = 3 * 2 * 5 = 30
        pe_dim = 3 * 2 * 5
        self.sigma_net = nn.Sequential(
            nn.Linear(128 + pe_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 16) # Output: 1 sigma + 15 geometry features
        )
        
        # Color Net: 2 hidden layers, dim 64
        # Input: 15 (geometry) + SH_dim
        # SH dim for degree 3 is (3+1)^2 = 16 per channel, 3 channels -> 48
        sh_dim = (sh_degree + 1) ** 2 * 3
        self.color_net = nn.Sequential(
            nn.Linear(15 + sh_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 64),
            nn.ReLU(),
            nn.Linear(64, 3) # Output: RGB
        )
        
        # Spherical Harmonics basis function
        self.sh_basis = self._get_sh_basis(sh_degree)

    def _get_sh_basis(self, degree):
        """Generate spherical harmonics basis vectors for a given degree."""
        # Simplified SH basis generation. 
        # In practice, this maps view direction (3,) to SH coefficients.
        # For degree 3, output is 48 dimensions.
        # This is a placeholder for the actual SH math, assumed to be a standard function.
        def sh_func(v):
            # v: (3,)
            # Returns: (48,)
            # Standard SH implementation omitted for brevity, assumed available.
            pass
        return sh_func

    def positional_encoding(self, x, freq=5):
        """
        Standard positional encoding for coordinates.
        x: (N, 3)
        Returns: (N, 3 * 2 * freq)
        """
        # x is in range [-1, 1] or similar. 
        # PE(x) = [sin(2^0 pi x), cos(2^0 pi x), ..., sin(2^(freq-1) pi x), cos(2^(freq-1) pi x)]
        scales = 2.0 ** torch.arange(0, freq, device=x.device)
        x = x.unsqueeze(-1) * scales.unsqueeze(0) # (N, 3, freq)
        x = torch.cat([torch.sin(x), torch.cos(x)], dim=-1) # (N, 3, 2*freq)
        return x.view(x.size(0), -1)

    def sample_tri_plane(self, points, plane_idx, scale_idx):
        """
        Sample features from a specific plane at a specific scale.
        points: (N, 3)
        plane_idx: 0 (xy), 1 (yz), 2 (xz)
        scale_idx: 0..3
        Returns: (N, feat_dim)
        """
        # Project points to 2D
        if plane_idx == 0: # xy
            coords = points[:, :2]
        elif plane_idx == 1: # yz
            coords = points[:, 1:3]
        else: # xz
            coords = torch.stack([points[:, 0], points[:, 2]], dim=1)
            
        # Normalize to [-1, 1] assuming input is in [-1, 1]
        # If input is not normalized, scaling is required.
        # Assuming input points are already normalized to [-1, 1] for grid sampling.
        
        grid = self.planes[scale_idx][plane_idx] # (feat_dim, H, W)
        # grid shape: (feat_dim, H, W)
        # We need to sample at coords.
        # coords shape: (N, 2)
        
        # Unsqueeze for grid_sample: (N, 1, 2)
        coords_norm = coords.unsqueeze(1) # (N, 1, 2)
        
        # grid_sample expects input (N, C, H, W) or (C, H, W) with grid (N, H_out, W_out, 2)
        # Here we treat feat_dim as C.
        # grid is (feat_dim, H, W). We need to permute to (1, feat_dim, H, W) for grid_sample if N=1?
        # Actually, grid_sample works on batches.
        # Let's reshape grid to (1, feat_dim, H, W)
        grid_4d = grid.unsqueeze(0) # (1, feat_dim, H, W)
        
        # grid_sample output: (N, feat_dim, 1, 1)
        features = F.grid_sample(grid_4d, coords_norm, align_corners=True) # (1, feat_dim, 1, 1) -> wait, grid_sample output shape is (N, C, H_out, W_out)
        # If coords is (N, 1, 2), output is (1, feat_dim, N, 1)? No.
        # grid_sample(input, grid) where grid is (N, H_out, W_out, 2).
        # We have N points. So grid should be (N, 1, 1, 2).
        
        coords_grid = coords_norm.view(1, 1, 1, 2).expand(N, 1, 1, 2) # This is wrong if N varies.
        
        # Correct approach for batch N:
        # grid_sample(input, grid)
        # input: (N, C, H, W)
        # grid: (N, H_out, W_out, 2)
        
        # We have 3 planes. We need to sample all 3 planes for a scale.
        # Let's assume we pass all 3 planes at once.
        pass

    def forward(self, points, view_dirs):
        """
        points: (N, 3) canonical 3D points
        view_dirs: (N, 3) view directions
        
        Returns:
        sigma: (N,)
        color: (N, 3)
        """
        N = points.shape[0]
        
        # 1. Positional Encoding of raw points
        pe_points = self.positional_encoding(points, freq=5) # (N, 30)
        
        # 2. Tri-plane Feature Extraction
        # For each scale, multiply features across 3 planes
        tri_features = []
        for s in range(self.num_scales):
            # Sample all 3 planes for this scale
            # planes[s] is (3, feat_dim, H, W)
            # We need to sample at points for all 3 planes.
            
            # Project points to 2D for all 3 planes
            # xy: (x, y), yz: (y, z), xz: (x, z)
            pts_xy = points[:, :2]
            pts_yz = points[:, 1:3]
            pts_xz = torch.stack([points[:, 0], points[:, 2]], dim=1)
            
            # Normalize to [-1, 1] if necessary. Assuming points are in [-1, 1].
            
            # Sample from grid
            # grid_sample(input, grid)
            # input: (N, C, H, W)
            # grid: (N, 1, 1, 2)
            
            # For plane 0 (xy)
            grid_xy = self.planes[s][0].unsqueeze(0).expand(N, -1, -1, -1) # (N, feat_dim, H, W)
            grid_coords_xy = pts_xy.unsqueeze(1).unsqueeze(1) # (N, 1, 1, 2)
            feat_xy = F.grid_sample(grid_xy, grid_coords_xy, align_corners=True) # (N, feat_dim, 1, 1)
            
            # For plane 1 (yz)
            grid_yz = self.planes[s][1].unsqueeze(0).expand(N, -1, -1, -1)
            grid_coords_yz = pts_yz.unsqueeze(1).unsqueeze(1)
            feat_yz = F.grid_sample(grid_yz, grid_coords_yz, align_corners=True)
            
            # For plane 2 (xz)
            grid_xz = self.planes[s][2].unsqueeze(0).expand(N, -1, -1, -1)
            grid_coords_xz = pts_xz.unsqueeze(1).unsqueeze(1)
            feat_xz = F.grid_sample(grid_xz, grid_coords_xz, align_corners=True)
            
            # Multiply across planes: element-wise
            feat_s = feat_xy * feat_yz * feat_xz # (N, feat_dim, 1, 1)
            feat_s = feat_s.squeeze(-1).squeeze(-1) # (N, feat_dim)
            tri_features.append(feat_s)
            
        # Concatenate across scales
        tri_features_cat = torch.cat(tri_features, dim=1) # (N, 128)
        
        # 3. Concatenate with PE
        f_in = torch.cat([tri_features_cat, pe_points], dim=1) # (N, 128 + 30)
        
        # 4. Sigma Net
        sigma_out = self.sigma_net(f_in) # (N, 16)
        sigma = sigma_out[:, 0] # (N,)
        geo_features = sigma_out[:, 1:] # (N, 15)
        
        # 5. Color Net
        # Encode view directions with SH
        sh_coeffs = self.sh_basis(view_dirs) # (N, 48) for degree 3
        color_in = torch.cat([geo_features, sh_coeffs], dim=1) # (N, 15 + 48)
        color = self.color_net(color_in) # (N, 3)
        
        return sigma, color
```

## Operating characteristics
*   **Time Complexity:** Training time for the spatial model is 150 minutes, significantly faster than the voxel grid baseline (60 mins for voxel grid construction but total training time comparison is complex; the paper states Tri-plane 150 mins vs Voxel Grid 60 mins in Table 3, but notes voxel grid converges faster. The pure MLP takes 43 hours) [S1].
*   **Memory Complexity:** Model size is 31.5 MB, significantly smaller than the multi-scale voxel grid (2336 MB) and slightly larger than the pure MLP (0.5 MB) [S1].
*   **Performance:** Achieves high rendering quality (PSNR 38.92, SSIM 0.990, LPIPS 0.037 on the tested dataset) [S1].
*   **Strengths:** Avoids convergence difficulties of pure MLPs; much smaller memory footprint than voxel grids; fast convergence compared to MLPs.
*   **Limitations:** Coordinate shifts can occur due to limited grid resolution and linear interpolation errors, mitigated by concatenating raw positional encodings [S1].

## Background
This method was introduced in the KFD-NeRF paper (2024) by the authors of the source [S1]. It is part of the KFD-NeRF pipeline, which rethinks dynamic NeRF using a Kalman Filter. The spatial representation is chosen to balance the trade-offs between pure MLPs (slow convergence, low memory) and voxel grids (fast convergence, high memory) [S1].
