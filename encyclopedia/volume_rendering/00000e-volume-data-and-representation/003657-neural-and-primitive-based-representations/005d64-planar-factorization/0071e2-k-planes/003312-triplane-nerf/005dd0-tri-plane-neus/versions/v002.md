# Tri-Plane NeuS

Also called: TP-NeuS (Baseline)

## Overview
Tri-Plane NeuS is a neural surface reconstruction method that models the Signed Distance Function (SDF) using tri-plane features and a multi-layer perceptron (MLP) [S1]. It serves as the baseline for the PET-NeuS framework [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of multi-view images with known camera poses [G].
*   **Output:** A reconstructed 3D mesh and texture [G].

**Data Structures:**
*   **Tri-Planes ($T$):** Three 2D feature planes $T_{xy}, T_{yz}, T_{zx}$, each of size $H \times W \times C$ [G].
*   **MLP:** A multi-layer perceptron mapping concatenated features to SDF values [S1].

**Method Steps:**
1.  **Feature Query:** For a 3D point $\mathbf{x} = (x, y, z)$, project it onto the three axis-aligned planes to obtain 2D coordinates, then sample features from $T_{xy}, T_{yz}, T_{zx}$ at these coordinates [G].
2.  **Concatenation:** Concatenate the sampled features from the three planes: $\mathbf{f} = [T_{xy}(\mathbf{x}), T_{yz}(\mathbf{x}), T_{zx}(\mathbf{x})]$ [G].
3.  **SDF Prediction:** Pass $\mathbf{f}$ through the MLP to predict the SDF value $S(\mathbf{x})$ [S1].
    $$ S(\mathbf{x}) = \text{MLP}([\mathbf{T}(\mathbf{x})]) $$
    where $[\mathbf{T}(\mathbf{x})]$ denotes the concatenated tri-plane features [S1].
4.  **Rendering:** Use volumetric rendering with the SDF to render images and compute photometric loss [G].
5.  **Surface Extraction:** Extract the mesh using the marching cubes algorithm on the learned SDF field [G].

**Parameters:**
*   Tri-plane resolution: Not given in the sources.
*   Feature dimension $C$: Not given in the sources.
*   MLP architecture: 3-layer MLP [S1].

**Edge Cases and Pitfalls:**
*   **Foreground/Background Sticking:** Without geometric initialization, the SDF may fail to separate foreground and background, leading to incorrect topology on complex geometry like a belly [S1].
*   **High-Frequency Artifacts:** Standard MLP initialization combined with random tri-plane initialization can introduce high-frequency artifacts on the surface [S1].

**Pseudocode:**
```python
def predict_sdf(xyz, tri_planes, mlp):
    """
    Predicts SDF for a batch of 3D points using Tri-Plane NeuS.
    
    Args:
        xyz: Array of shape (N, 3), 3D coordinates normalized to [-1, 1].
        tri_planes: Dictionary containing 'xy', 'yz', 'zx' arrays of shape (H, W, C).
        mlp: Function mapping (N, 3C) -> (N, 1).
        
    Returns:
        sdf: Array of shape (N, 1), predicted SDF values.
    """
    # 1. Extract 2D coordinates for each plane
    xy_coords = xyz[:, :2]
    yz_coords = xyz[:, 1:3]
    zx_coords = xyz[:, [2, 0]]
    
    # 2. Sample features via bilinear interpolation
    feat_xy = bilinear_sample(tri_planes['xy'], xy_coords)
    feat_yz = bilinear_sample(tri_planes['yz'], yz_coords)
    feat_zx = bilinear_sample(tri_planes['zx'], zx_coords)
    
    # 3. Concatenate features along channel dimension
    features = concatenate([feat_xy, feat_yz, feat_zx], axis=1)
    
    # 4. Predict SDF
    sdf = mlp(features)
    
    return sdf

def bilinear_sample(feature_grid, coords):
    """
    Samples features from a 2D grid using bilinear interpolation.
    
    Args:
        feature_grid: Array of shape (H, W, C).
        coords: Array of shape (N, 2), normalized to [-1, 1].
        
    Returns:
        features: Array of shape (N, C).
    """
    h, w, c = feature_grid.shape
    # Convert normalized coordinates to pixel indices
    x = (coords[:, 0] * 0.5 + 0.5) * (w - 1)
    y = (coords[:, 1] * 0.5 + 0.5) * (h - 1)
    x = clamp(x, 0, w - 1)
    y = clamp(y, 0, h - 1)
    x0, y0 = floor(x).astype(int), floor(y).astype(int)
    x1, y1 = x0 + 1, y0 + 1
    x1 = clamp(x1, 0, w - 1)
    y1 = clamp(y1, 0, h - 1)
    # Interpolation weights
    wx = x - x0
    wy = y - y0
    # Gather corner features
    f00 = feature_grid[y0, x0, :]
    f01 = feature_grid[y0, x1, :]
    f10 = feature_grid[y1, x0, :]
    f11 = feature_grid[y1, x1, :]
    # Bilinear interpolation
    top = f00 * (1 - wx)[:, None] + f01 * wx[:, None]
    bot = f10 * (1 - wx)[:, None] + f11 * wx[:, None]
    out = top * (1 - wy)[:, None] + bot * wy[:, None]
    return out
```

## Subtopics

### Geometric Initialization for Tri-Planes
A method to initialize tri-plane features to prevent foreground/background sticking and high-frequency artifacts [S1]. It is compared against random noise initialization and standard MLP geometric initialization [S1]. On the DTU dataset, the mean Chamfer Distance for "No Geo Init" is 1.86, "MLP Geo Init" is 1.34, and "Our Geo Init" is 1.05 [S1]. "No Geo Init" (random noise $\mathcal{N}(0,1)$ for tri-planes, standard init for MLP) causes foreground/background sticking and inconsistent reconstruction on complex geometry like a belly [S1]. "MLP Geo Init" (random noise for tri-planes, standard init for MLP) results in high-frequency detail artifacts on the generated surface model [S1]. "Our Geo Init" leads to more consistent surface reconstruction results [S1].

## Operating characteristics
**Time and Memory Complexity:**
Not given in the sources.

**Measured Performance:**
On the DTU dataset, the mean Chamfer Distance for the baseline Tri-Plane NeuS with geometric initialization is 1.05 [S1].

**Strengths and Limitations:**
*   **Strengths:** Prevents foreground/background sticking and reduces high-frequency artifacts compared to naive initialization [S1].
*   **Limitations:** The baseline model relies on positional encoding for fine details when extended, suggesting the tri-planes alone may lack high-frequency capacity without additional encoding [S1].

**When to Use:**
Use when a baseline neural surface reconstruction method with explicit tri-plane features is required, particularly when geometric initialization is critical for stable training on complex geometries [S1].

## Background
Tri-Plane NeuS is the baseline model described in PET-NeuS, which uses tri-planes and MLPs to model the SDF [S1]. It builds on the TriPlane NeRF representation [6932-triplane-nerf.md] and the NeuS implicit surface formulation [G]. The method was introduced in PET-NeuS: Positional Encoding Tri-Planes for Neural Surfaces [S1].
