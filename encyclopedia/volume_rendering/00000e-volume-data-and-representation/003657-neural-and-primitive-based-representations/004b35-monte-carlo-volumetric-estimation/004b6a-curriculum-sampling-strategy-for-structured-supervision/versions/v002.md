# Curriculum Sampling Strategy for Structured Supervision
Also called: Planar sampling, Slice-based supervision

## Overview
This method provides structured spatial supervision for neural volumetric representations by blending sparse voxel-based Monte Carlo estimation with planar slice-based constraints [S1]. It solves the issue of isolated voxel samples lacking spatial coherence by enforcing consistency along 2D planes, which directly improves the fidelity of slices used in shear-warp rendering [S1]. It sets itself apart from pure voxel supervision by introducing geometric structure through random plane orientations, and from dense image supervision by maintaining sparsity and memory efficiency through selective pixel sampling on those planes [S1].

## How it works
The method optimizes a set of Gaussian kernels $\Theta = \{\mu_i, \Sigma_i, C_i, \alpha_i\}_{i=1}^m$ representing a volumetric field $f_\Theta(x)$ [S1]. It combines two loss terms: the Monte Carlo volumetric loss $\hat L_{MC}$ (from the parent method) and a slice-based loss $L_{slice}$ [S1].

**Inputs:**
- Training iteration $t$.
- Gaussian parameters $\Theta$.
- Ground-truth voxel colors $y(x)$.
- Hyperparameters: $\lambda_{s,\max}$, $\gamma_s$, $\beta_s$.

**Outputs:**
- Gradients $\nabla_\Theta \mathcal{L}(t)$ for updating $\Theta$.

**Data Structures:**
- **Gaussian Set $G$**: A list of $m$ Gaussians. Each Gaussian $G_i$ contains:
  - $\mu_i \in \mathbb{R}^3$: Mean (spatial location).
  - $\Sigma_i \in \mathbb{R}^{3 \times 3}$: Covariance matrix (spread and orientation).
  - $C_i \in \mathbb{R}^3$: RGB color.
  - $\alpha_i \in \mathbb{R}$: Opacity.
- **Sample Set $S$**: A set of 2D pixel coordinates on a sampled plane. Each pixel maps to a 3D coordinate $x$ in the volume.

**Numbered Steps:**
1. **Sample Plane**: In each iteration $t$, sample a plane with an arbitrary orientation in 3D space [S1].
2. **Select Pixels**: Select a sparse set of 2D pixel locations $S$ on that plane. Each pixel corresponds to a specific 3D coordinate $x$ within the volume [S1].
3. **Compute Slice Loss**: Calculate the mean squared error between the predicted color $f_\Theta(x)$ and the ground-truth color $y(x)$ for all pixels in $S$:
   $$ L_{slice} = \frac{1}{|S|} \sum_{x \in S} \| f_\Theta(x) - y(x) \|_2^2 $$
   where $|S|$ is the number of sampled pixels [S1].
4. **Calculate Weights**: Compute time-varying weights $\lambda_s(t)$ and $\lambda_v(t)$ based on the current iteration $t$ [S1]:
   $$ \lambda_s(t) = \lambda_{s,\max} \sigma \left( \frac{t - \gamma_s}{\beta_s} \right) $$
   $$ \lambda_v(t) = 1 - \lambda_s(t) $$
   where $\sigma(\cdot)$ is the sigmoid function [S1].
5. **Combine Losses**: Compute the total loss $\mathcal{L}(t)$ by blending the Monte Carlo loss $\hat L_{MC}$ and the slice loss $L_{slice}$:
   $$ \mathcal{L}(t) = \lambda_v(t) \hat L_{MC} + \lambda_s(t) L_{slice} $$
   [S1].
6. **Update Parameters**: Perform gradient descent on $\Theta$ using $\nabla_\Theta \mathcal{L}(t)$ [S1].

**Parameters:**
- $\lambda_{s,\max}$: Maximum weight for the slice loss. Not given in the sources.
- $\gamma_s$: Iteration at which slice supervision becomes significant. Not given in the sources.
- $\beta_s$: Controls the smoothness of the transition. Not given in the sources.

**Edge Cases and Pitfalls:**
- **Abrupt Switching**: Switching supervision abruptly between voxel and slice modes can be detrimental to training stability. This is handled by using the sigmoid schedule to gradually introduce slice supervision [S1].
- **Precision**: The method relies on the accuracy of mapping 2D pixel coordinates to 3D voxel locations. If the plane orientation or pixel sampling is imprecise, the structured constraint may not align with the ground truth geometry [G].

**Pseudocode:**
```python
import math
import random

def sigmoid(x):
    """Standard sigmoid function."""
    return 1.0 / (1.0 + math.exp(-x))

def sample_plane_and_pixels():
    """Sample a plane with arbitrary orientation and select sparse 2D pixel locations on it [G]."""
    # Generate random plane normal and origin
    n = [random.uniform(-1, 1), random.uniform(-1, 1), random.uniform(-1, 1)]
    norm = math.sqrt(sum(c**2 for c in n))
    n = [c / norm for c in n]
    o = [random.uniform(-10, 10), random.uniform(-10, 10), random.uniform(-10, 10)]
    # Generate sparse 2D pixel coordinates on the plane
    pixels = []
    for _ in range(100):
        u, v = random.uniform(-1, 1), random.uniform(-1, 1)
        # Map to 3D coordinate x on the plane
        x = o[0] + u * 1.0 + v * 0.0
        y = o[1] + u * 0.0 + v * 1.0
        z = o[2]
        pixels.append((x, y, z))
    return pixels

def evaluate_gaussian_field(Gaussians, x):
    """Evaluate predicted color f_theta(x) from Gaussian parameters [G]."""
    color = [0.0, 0.0, 0.0]
    for g in Gaussians:
        dx, dy, dz = x[0]-g['mu'][0], x[1]-g['mu'][1], x[2]-g['mu'][2]
        weight = math.exp(-(dx**2 + dy**2 + dz**2) / (2 * g['sigma']))
        color[0] += g['C'][0] * g['alpha'] * weight
        color[1] += g['C'][1] * g['alpha'] * weight
        color[2] += g['C'][2] * g['alpha'] * weight
    return color

def compute_slice_loss(Gaussians, pixels_S, ground_truth_voxels):
    total_error = 0.0
    count = 0
    for x in pixels_S:
        predicted_color = evaluate_gaussian_field(Gaussians, x)
        true_color = ground_truth_voxels.get_color(x)
        diff = [predicted_color[i] - true_color[i] for i in range(3)]
        total_error += sum(d**2 for d in diff)
        count += 1
    return total_error / count if count > 0 else 0.0

def compute_weights(t, gamma_s, beta_s, lambda_s_max):
    lambda_s = lambda_s_max * sigmoid((t - gamma_s) / beta_s)
    lambda_v = 1.0 - lambda_s
    return lambda_v, lambda_s

def compute_gradients(loss, params):
    """Compute gradients via standard automatic differentiation [G]."""
    return [p.grad for p in params]

def train_step(Gaussians, t, gamma_s, beta_s, lambda_s_max, 
               ground_truth_voxels, learning_rate, L_MC):
    # 1. Sample plane and pixels
    pixels_S = sample_plane_and_pixels()
    
    # 2. Compute Slice Loss
    L_slice = compute_slice_loss(Gaussians, pixels_S, ground_truth_voxels)
    
    # 3. Calculate Weights
    lambda_v, lambda_s = compute_weights(t, gamma_s, beta_s, lambda_s_max)
    
    # 4. Combine Losses
    L_total = lambda_v * L_MC + lambda_s * L_slice
    
    # 5. Update Parameters
    gradients = compute_gradients(L_total, Gaussians)
    for g in Gaussians:
        g['mu'] = [g['mu'][i] - learning_rate * gradients[i] for i in range(3)]
        # Other parameters updated similarly
    return L_total
```

## Subtopics

### Monte Carlo Volumetric Estimation
The parent method providing the voxel-based loss component. It uses importance sampling to estimate the volume rendering integral efficiently. Choose this when memory efficiency for large volumes is critical and spatial coherence is less important than global energy conservation. [12926-monte-carlo-volumetric-estimation.md]

## Background
The method was introduced in "Gaussian Volumetric Representation for Efficient Shear-Warp Visualization" [S1]. It addresses the limitations of sparse voxel supervision by incorporating planar constraints to better support the shear-warp rendering pipeline, which composites stacks of 2D slices [S1]. The curriculum learning aspect, using a sigmoid schedule to blend losses, is adapted from general curriculum learning practices [37] to ensure stable training [S1].
