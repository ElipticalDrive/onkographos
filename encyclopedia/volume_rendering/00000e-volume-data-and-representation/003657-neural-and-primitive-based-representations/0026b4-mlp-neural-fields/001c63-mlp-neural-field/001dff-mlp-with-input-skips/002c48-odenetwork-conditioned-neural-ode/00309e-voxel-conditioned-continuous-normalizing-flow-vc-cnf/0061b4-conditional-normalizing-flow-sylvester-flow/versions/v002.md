# Conditional Normalizing Flow (Sylvester Flow)

Also called: CNF, Sylvester Flows

## Overview
Conditional Normalizing Flows (CNFs) using Sylvester transformations map samples from a latent prior distribution to radiance and density values, conditioned on 5D location-direction pairs [S1]. This method serves as the invertible transformation layer within the Voxel-Conditioned Continuous Normalizing Flow (VC-CNF) framework [6313-voxel-conditioned-continuous-normalizing-flow-vc-cnf.md]. It replaces deterministic MLP outputs with a structured, invertible mapping conditioned on spatial and viewing directions [S1].

## How it works
**Inputs and Outputs**
The input consists of a latent sample $z_{k-1}$ and a 64-dimensional conditional feature vector derived from a 5D location-direction pair [S1]. The output is the transformed sample $z_k$ [S1].

**Data Structures**
The conditional feature is a fixed 64-dimensional vector [S1]. The flow parameters $A$, $B$, and $b$ are conditional functions of the 5D location-direction pair [S1].

**Algorithm**
The transformation is applied sequentially through $K$ flow steps [S1]. In the CF-NeRF implementation, $K=4$ for both radiance and density CNFs [S1]. During training, a single sample from the latent prior distribution is shared across different spatial-location and viewing-direction inputs within the same batch to prevent overfitting on sparse training views [S1].

1. Initialize the latent sample $z_0$ from the prior distribution [G].
2. For each flow step $k$ from 1 to $K$:
   a. Compute the conditional feature $c$ from the 5D location-direction pair [S1].
   b. Generate flow parameters $A$, $B$, $b$ from $c$ using a conditional network [G].
   c. Apply the Sylvester transformation:
      $$z_k = z_{k-1} + A h(B z_{k-1} + b)$$
      where $h$ is the hyperbolic tangent activation function [S1].
   d. Set $z_{k-1} \leftarrow z_k$ for the next iteration [G].
3. After $K$ steps, the final $z_K$ is used to decode radiance and density [S1].

**Parameters**
*   **Number of flow steps ($K$):** 4 [S1].
*   **Conditional feature dimension:** 64 [S1].
*   **MLP Hidden Units:** 512 for all layers in the backbone network [S1].
*   **Entropy Loss Weight:** 0.01 [S1].
*   **Depth Loss Weight:** $1 \times 10^{-2}$ (0.01) [S1].

**Pseudocode**
```python
import numpy as np

def sylvester_flow_step(z_prev, conditional_feature):
    """
    Performs one step of the Sylvester Normalizing Flow.
    Args:
        z_prev: Previous latent vector of dimension d.
        conditional_feature: 64-dimensional vector derived from 5D location-direction [S1].
    Returns:
        z_next: Transformed latent vector.
    """
    d = len(z_prev)
    # [G] Sources do not specify the exact architecture for generating A, B, b.
    # We assume a conditional network maps the 64-dim feature to parameters.
    # For a self-contained implementation, we use linear projections:
    A = conditional_feature[:d].reshape(d, d)
    B = conditional_feature[d:2*d].reshape(d, d)
    b = conditional_feature[2*d:3*d]
    # Apply Sylvester transformation: z_k = z_{k-1} + A tanh(B z_{k-1} + b) [S1]
    inner = B @ z_prev + b
    transformed = np.tanh(inner)
    z_next = z_prev + A @ transformed
    return z_next

def conditional_normalizing_flow(z_0, conditional_features, num_flows=4):
    """
    Applies K sequential Sylvester flows.
    Args:
        z_0: Initial sample from latent prior [G].
        conditional_features: List of K conditional feature vectors.
        num_flows: Number of flow steps K=4 [S1].
    Returns:
        z_K: Final transformed latent vector [S1].
    """
    z = z_0
    for k in range(num_flows):
        z = sylvester_flow_step(z, conditional_features[k])
    return z
```

**Edge Cases and Pitfalls**
Overfitting with sparse training views is mitigated by sharing latent samples across batch inputs and adding a depth loss [S1].

## Operating characteristics
**Time and Memory Complexity**
The complexity is linear with respect to the number of flow steps $K$ and the dimensionality of the latent vector [G]. Each step involves matrix-vector multiplications and a non-linear activation [G]. The memory overhead is minimal because the parameters $A$, $B$, $b$ are generated on-the-fly from the conditional feature [G].

**Measured Performance**
On the LF dataset, CF-NeRF with 4 Sylvester flows achieves the following metrics [S1]:
*   **PSNR:** 24.78
*   **SSIM:** 0.86
*   **LPIPS:** 0.168
*   **AUSE RMSE:** 0.051
*   **AUSE MAE:** 0.026
*   **NLL:** -0.710
*   **Depth RMSE:** 0.118
*   **Depth MAE:** 0.074
*   **Depth $\delta_3$:** 0.81

**Ablation Studies**
*   **Without Entropy Term:** Removing the entropy term (weight 0.01) degrades performance to PSNR: 23.82, SSIM: 0.83, NLL: -0.578 [S1].
*   **Single Flow:** Using only one flow step degrades performance further to PSNR: 23.40, SSIM: 0.81, NLL: -0.448 [S1].

**Strengths and Limitations**
*   **Strengths:** Provides accurate 3D modeling with uncertainty quantification [S1].
*   **Limitations:** Requires tuning loss weights to avoid overfitting on sparse data [S1]. The conditional network adds computational overhead compared to static MLPs [G].

## Background
Conditional Normalizing Flows, specifically Sylvester Flows, were introduced for density estimation and generative modeling [G]. In neural radiance fields, they were adapted by Shen et al. in "Conditional-Flow NeRF: Accurate 3D Modelling with Reliable Uncertainty Quantification" to provide uncertainty-aware rendering [S1]. This approach builds on the original NeRF architecture [36] and integrates with the VC-CNF framework [6313-voxel-conditioned-continuous-normalizing-flow-vc-cnf.md] to condition the latent distribution on voxel features [S1].
