# ODENetwork (Conditioned Neural ODE)

Also called: Neural ODE with Skip Connections

## Overview
ODENetwork is a neural field architecture that computes the derivative of a latent state over a scalar time parameter, conditioned on a voxel embedding. It serves as the core differentiable function for continuous normalizing flows in voxel-conditioned generation, transforming a base latent distribution into a target distribution by integrating the ODE from $t=0$ to $t=1$. It builds on [MLP with Input Skips](1643-mlp-with-input-skips.md) by explicitly incorporating time and voxel conditions into the skip connections.

## How it works
**Inputs:**
- `latent`: Latent state vector of size `latent_dim`.
- `voxel_embedding`: Voxel condition embedding of size `voxel_embedding_dim`.
- `t`: Scalar time parameter.

**Outputs:**
- `dz_dt`: The derivative of the latent state with respect to time, same shape as `latent`.

**Data Structures:**
- The network consists of a sequence of linear layers.
- `skip_layers`: A list of integer indices indicating which layers receive skip connections.
- `hidden_dim`: The dimensionality of the hidden layers (and output).

**Parameters:**
- `latent_dim`: Size of the latent state. Default: 512 [S1, unofficial].
- `hidden_dim`: Size of hidden layers. Default: 512 [S1, unofficial].
- `skip_layers`: List of layer indices for skip connections. Default: `[1, 3]` [S1, unofficial].
- `voxel_embedding_dim`: Dimension of the voxel condition embedding. Default: 128 [S1, unofficial].

**Algorithm:**
1. For each layer $i$ in the network:
   a. If $i$ is in `skip_layers`:
      i. Concatenate `latent`, `voxel_embedding`, and `t` (reshaped to column vector) along the feature dimension.
      ii. The concatenated input size is `latent_dim + voxel_embedding_dim + 1`.
      iii. Pass through a linear layer mapping to `hidden_dim`.
      iv. Apply ReLU activation.
   b. If $i$ is not in `skip_layers`:
      i. Pass the current `latent` state through a linear layer mapping to `hidden_dim`.
      ii. Apply ReLU activation.
2. The final layer applies a linear transformation followed by a Tanh activation to produce the output derivative.

**Formula:**
For skip layers $i \in \text{skip\_layers}$:
$$ z_{i+1} = \text{ReLU}(\text{Linear}_i([z_i; \text{voxel\_emb}; t])) $$
For non-skip layers:
$$ z_{i+1} = \text{ReLU}(\text{Linear}_i(z_i)) $$
Output:
$$ \frac{dz}{dt} = \tanh(\text{Linear}_{\text{last}}(z_{\text{last}})) $$
Where $[;]$ denotes concatenation.

**Edge Cases and Pitfalls:**
- **Time Scaling:** The integration range is typically $t \in [0, 1]$. Ensure $t$ is normalized.
- **Dimension Mismatch:** `voxel_embedding` and `latent` must have compatible batch dimensions.
- **Skip Layer Indices:** Ensure `skip_layers` indices are within the range of defined layers.

## Subtopics

### Voxel-Conditioned Continuous Normalizing Flow (VC-CNF)
VC-CNF is a generative method that uses ODENetwork to transform a base latent distribution into a target distribution conditioned on a voxel grid. It integrates the ODE defined by ODENetwork from $t=0$ to $t=1$ using the Runge-Kutta 4 (RK4) method. It is chosen when explicit likelihood estimation or flow-based generation is required for voxel-conditioned shape synthesis. Parameters include `num_hidden_layers` (default 4) and `integrated_time` (default 1.0). The ODE function is defined as $dz/dt = f(z, t, \text{voxel\_embedding})$.

## Operating characteristics
- **Time Complexity:** Depends on the number of layers and the integration steps (RK4 requires 4 evaluations per step).
- **Memory Complexity:** Linear in the number of layers and latent dimension.
- **Strengths:** Allows for continuous-time modeling and explicit likelihood computation via flow matching.
- **Limitations:** Requires numerical integration, which can be slower than direct MLP evaluation. Sensitive to the choice of integration method and step size.

## Background
ODENetwork is used in the context of Voxel-Conditioned SDF Generation (VC-SDFGen) [S1, unofficial]. It enables the generation of 3D shapes by conditioning a neural ODE on voxel embeddings, allowing for flexible and continuous latent space manipulation.
