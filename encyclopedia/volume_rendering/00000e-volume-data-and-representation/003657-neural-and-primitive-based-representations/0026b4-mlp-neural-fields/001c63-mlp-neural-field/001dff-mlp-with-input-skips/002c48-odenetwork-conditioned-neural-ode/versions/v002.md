# ODENetwork (Conditioned Neural ODE)

Also called: Neural ODE with Skip Connections

## Overview
ODENetwork is a neural field architecture that computes the derivative of a latent state over a scalar time parameter, conditioned on a voxel embedding [S1, unofficial]. It serves as the core differentiable function for continuous normalizing flows in voxel-conditioned generation, transforming a base latent distribution into a target distribution by integrating the ODE from $t=0$ to $t=1$ [S1, unofficial]. It builds on [MLP with Input Skips](1643-mlp-with-input-skips.md) by explicitly incorporating time and voxel conditions into the skip connections [S1, unofficial].

## How it works
**Inputs:**
- `latent`: Latent state vector of size `latent_dim` [S1, unofficial].
- `voxel_embedding`: Voxel condition embedding of size `voxel_embedding_dim` [S1, unofficial].
- `t`: Scalar time parameter [S1, unofficial].

**Outputs:**
- `dz_dt`: The derivative of the latent state with respect to time, same shape as `latent` [S1, unofficial].

**Data Structures:**
- A sequence of linear layers mapping to `hidden_dim` [S1, unofficial].
- `skip_layers`: A list of integer indices indicating which layers receive skip connections [S1, unofficial].
- `hidden_dim`: The dimensionality of the hidden layers and output [S1, unofficial].

**Parameters:**
- `latent_dim`: Size of the latent state. Default: 512 [S1, unofficial].
- `hidden_dim`: Size of hidden layers. Default: 512 [S1, unofficial].
- `skip_layers`: List of layer indices for skip connections. Default: `[1, 3]` [S1, unofficial].
- `voxel_embedding_dim`: Dimension of the voxel condition embedding. Default: 128 [S1, unofficial].

**Algorithm:**
1. Initialize hidden state $z_0 = \text{latent}$ [S1, unofficial].
2. Iterate through layers $i = 0, \dots, N-1$ [S1, unofficial].
3. If $i \in \text{skip\_layers}$, concatenate $z_i$, `voxel_embedding`, and $t$ (reshaped to a column vector) along the feature dimension, yielding size `latent_dim + voxel_embedding_dim + 1` [S1, unofficial].
4. Pass the concatenated input through a linear layer mapping to `hidden_dim` [S1, unofficial].
5. Apply ReLU activation after each linear layer except the last, which applies Tanh [S1, unofficial].

**Formula:**
For skip layers $i \in \text{skip\_layers}$:
$$ z_{i+1} = \text{ReLU}(\text{Linear}_i([z_i; \text{voxel\_emb}; t])) $$
For non-skip layers:
$$ z_{i+1} = \text{ReLU}(\text{Linear}_i(z_i)) $$
Output:
$$ \frac{dz}{dt} = \tanh(\text{Linear}_{\text{last}}(z_{\text{last}})) $$
Where $[;]$ denotes concatenation [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class ODENetwork(nn.Module):
    def __init__(self, latent_dim=512, hidden_dim=512, voxel_embedding_dim=128, skip_layers=(1, 3)):
        super().__init__()
        self.latent_dim = latent_dim
        self.hidden_dim = hidden_dim
        self.voxel_embedding_dim = voxel_embedding_dim
        self.skip_layers = set(skip_layers)
        self.num_layers = max(skip_layers) + 1 if skip_layers else 1
        self.layers = nn.ModuleList()
        for i in range(self.num_layers):
            if i in self.skip_layers:
                in_features = latent_dim + voxel_embedding_dim + 1
            else:
                in_features = latent_dim
            self.layers.append(nn.Linear(in_features, hidden_dim))

    def forward(self, latent, voxel_embedding, t):
        z = latent
        t_expanded = t.unsqueeze(1) if t.dim() == 1 else t
        for i, layer in enumerate(self.layers):
            if i in self.skip_layers:
                input_cat = torch.cat([z, voxel_embedding, t_expanded], dim=1)
                z = layer(input_cat)
            else:
                z = layer(z)
            if i == len(self.layers) - 1:
                z = torch.tanh(z)
            else:
                z = torch.relu(z)
        return z
```

**Edge Cases and Pitfalls:**
- Skip layer indices must be within the range of defined layers [S1, unofficial].
- Batch dimensions of `latent` and `voxel_embedding` must match [G].

## Subtopics

### Voxel-Conditioned Continuous Normalizing Flow (VC-CNF)
VC-CNF is a generative method that uses ODENetwork to transform a base latent distribution into a target distribution conditioned on a voxel grid [S1, unofficial]. It integrates the ODE defined by ODENetwork from $t=0$ to $t=1$ using the Runge-Kutta 4 (RK4) method [S1, unofficial]. It is chosen when explicit likelihood estimation or flow-based generation is required for voxel-conditioned shape synthesis [S1, unofficial]. Parameters include `num_hidden_layers` (default 4), `integrated_time` (default 1.0), `latent_dim` (512), `hidden_dim` (512), `skip_layers` (`[1, 3]`), and `voxel_embedding_dim` (128) [S1, unofficial]. The ODE function is defined as $dz/dt = f(z, t, \text{voxel\_embedding})$ [S1, unofficial]. Integration code: `def ode_func(t, latent): return self.ode_network(voxel_embedding, t, latent) return odeint(ode_func, latent, self.integrated_time, method="rk4")[-1]` [S1, unofficial].

## Operating characteristics
- Time complexity depends on the number of layers and the integration steps (RK4 requires 4 evaluations per step) [G].
- Memory complexity is linear in the number of layers and latent dimension [G].
- Sensitive to the choice of integration method and step size [G].

## Background
ODENetwork originates from the VC-SDFGen repository [S1, unofficial]. It enables the generation of 3D shapes by conditioning a neural ODE on voxel embeddings, allowing for flexible and continuous latent space manipulation [S1, unofficial].
