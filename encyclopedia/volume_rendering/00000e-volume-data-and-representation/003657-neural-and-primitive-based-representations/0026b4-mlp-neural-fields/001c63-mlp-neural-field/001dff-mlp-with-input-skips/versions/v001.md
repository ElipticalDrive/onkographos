# MLP with Input Skips

Also called: Skip Connection MLP

## Overview
An MLP architecture that concatenates the original input $z$ to intermediate layers specified in `input_skips`, allowing the network to access low-level features at deeper layers [S1, S2, unofficial]. It differs from the parent [MLP Neural Field](1256-mlp-neural-field.md) by explicitly preserving high-frequency input information in hidden representations, a technique popularized by NeRF [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A coordinate vector $z \in \mathbb{R}^{in_{dim}}$ [S1, S2, unofficial].
- Output: A value vector $v \in \mathbb{R}^{output_{dim}}$ [S1, unofficial].

**Data Structures:**
- `input_skips`: A list of integers representing layer indices where the skip connection is applied [S1, S2, unofficial].
- Weights $W_i$ and biases $b_i$ for each linear layer $i$ [S2, unofficial].

**Parameters:**
- $in_{dim}$: Dimensionality of the input vector $z$ [S1, S2, unofficial].
- $hidden_{dim}$: Dimensionality of the hidden layers [S1, S2, unofficial].
- $output_{dim}$: Dimensionality of the output vector [S1, unofficial].
- $n_{layers}$: Total number of linear layers in the MLP [S1, S2, unofficial].
- $skip_{dim}$: Dimensionality of the vector $z$ to be skipped. Typically equal to $in_{dim}$ [S1, S2, unofficial].

**Algorithm:**
1. Initialize the hidden state $y$ as the input $z$ [S2, unofficial].
2. Iterate through each layer index $i$ from $0$ to $n_{layers} - 1$:
   a. If $i$ is in `input_skips` and $i > 0$:
      - Concatenate the original input $z$ to the current hidden state $y$:
        $$y = [y, z]$$
        where $[ \cdot, \cdot ]$ denotes concatenation along the feature dimension [S1, S2, unofficial].
      - Note: For layer 0, no skip is applied as there is no previous hidden state to concatenate to [G].
   b. Apply the linear transformation:
      $$y = W_i y + b_i$$
   c. Apply the ReLU activation function:
      $$y = \text{ReLU}(y)$$
3. After the final layer, apply a final linear transformation (if $output_{dim} \neq hidden_{dim}$) or return $y$ directly [G]. The final output is $v = y$ (assuming the last layer maps to $output_{dim}$) [S1, unofficial].

**Initialization:**
- Layer 0: Input dimension $in_{dim}$, output dimension $hidden_{dim}$ [S2, unofficial].
- Layers $i \notin \text{input\_skips}$: Input dimension $hidden_{dim}$, output dimension $hidden_{dim}$ [S2, unofficial].
- Layers $i \in \text{input\_skips}$: Input dimension $hidden_{dim} + skip_{dim}$, output dimension $hidden_{dim}$ [S2, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MLPWithInputSkips(nn.Module):
    def __init__(self, in_dim, hidden_dim, output_dim, n_layers, input_skips):
        super().__init__()
        self.in_dim = in_dim
        self.hidden_dim = hidden_dim
        self.output_dim = output_dim
        self.n_layers = n_layers
        self.input_skips = set(input_skips)
        
        # Build layers
        self.layers = nn.ModuleList()
        
        # Layer 0
        self.layers.append(nn.Linear(in_dim, hidden_dim))
        
        # Intermediate layers
        for i in range(1, n_layers):
            if i in self.input_skips:
                # Input is hidden_dim from previous layer + in_dim from skip
                in_features = hidden_dim + in_dim
            else:
                in_features = hidden_dim
            self.layers.append(nn.Linear(in_features, hidden_dim))
            
        # Final output layer
        # Assuming the last layer is not in input_skips for simplicity, 
        # or if it is, it still outputs hidden_dim before final projection?
        # Standard NeRF usually has a final linear layer.
        # Let's assume the last layer in self.layers maps to hidden_dim,
        # and we add a final linear layer for output_dim.
        self.final_layer = nn.Linear(hidden_dim, output_dim)

    def forward(self, z):
        # z shape: (..., in_dim)
        y = z
        
        for i, layer in enumerate(self.layers):
            if i in self.input_skips and i > 0:
                # Concatenate original input z to current feature map y
                # y shape: (..., hidden_dim)
                # z shape: (..., in_dim)
                y = torch.cat([y, z], dim=-1)
            
            # Linear transformation
            y = layer(y)
            
            # ReLU activation
            y = F.relu(y)
            
        # Final output
        out = self.final_layer(y)
        return out
```

**Edge Cases and Pitfalls:**
- If `input_skips` contains 0, the skip is effectively ignored as there is no previous hidden state [G].
- Precision issues may arise if $in_{dim}$ is very large compared to $hidden_{dim}$, causing the skip connection to dominate the gradient [G].
- Boundary conditions: Ensure that the concatenation dimension is consistent across all layers [G].

## Operating characteristics
- **Time Complexity:** $O(n_{layers} \cdot hidden_{dim}^2)$ for standard layers, $O(n_{layers} \cdot hidden_{dim} \cdot (hidden_{dim} + in_{dim}))$ for skip layers [G].
- **Memory Complexity:** $O(n_{layers} \cdot hidden_{dim}^2)$ for weights, plus $O(hidden_{dim} + in_{dim})$ for activations [G].
- **Strengths:** Improves convergence and detail preservation by allowing low-frequency information to bypass non-linear transformations [S1, S2, unofficial].
- **Limitations:** Increases the number of parameters and computational cost slightly due to concatenation [G].
- **When to use:** When high-frequency details are important, such as in NeRF-based rendering [S1, unofficial].
- **When not to use:** When computational resources are extremely limited and high-frequency details are not critical [G].

## Background
This method was introduced in the original NeRF paper [S1, unofficial]. It has since become a standard component in many neural field architectures [S2, unofficial].
