# MLP with Input Skips

Also called: Skip Connection MLP

## Overview
An MLP architecture that concatenates the original input $z$ to intermediate layers specified in `input_skips`, allowing the network to access low-level features at deeper layers [S1, S2, unofficial]. It builds on [MLP Neural Field](1256-mlp-neural-field.md) by modifying the hidden state propagation to preserve direct access to the input coordinate information, which helps mitigate the spectral bias problem where standard MLPs struggle to learn high-frequency details [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A vector $z \in \mathbb{R}^{skip\_dim}$ (typically 3D spatial coordinates).
- Output: A vector $y_{out} \in \mathbb{R}^{output\_dim}$ (e.g., density and color).

**Data Structures:**
- `input_skips`: A list of integers representing the indices of layers that receive the skip connection.
- `hidden_dim`: The dimensionality of the hidden layers.
- `n_layers`: Total number of linear layers.

**Parameters:**
- `input_dim`: Dimension of the input vector $z$.
- `hidden_dim`: Dimensionality of the hidden layers.
- `output_dim`: Dimension of the output vector.
- `n_layers`: Total number of linear layers in the MLP.
- `input_skips`: List of layer indices where the input $z$ is concatenated.

**Algorithm:**
1. Initialize the hidden state $y = z$.
2. Iterate through each layer $i$ from $0$ to $n\_layers - 1$:
   a. If $i$ is in `input_skips`, concatenate the original input $z$ to the current hidden state: $y = [y, z]$.
   b. Apply the linear transformation: $y = W_i y + b_i$.
   c. Apply ReLU activation: $y = \text{ReLU}(y)$.
3. After the final layer, apply a final linear transformation (without activation) to produce the output.

**Pseudocode:**
```python
import torch
import torch.nn as nn

class MLPWithInputSkips(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim, n_layers, input_skips):
        super().__init__()
        self.input_skips = set(input_skips)
        self.layers = nn.ModuleList()
        
        # Layer 0
        self.layers.append(nn.Linear(input_dim, hidden_dim))
        
        # Intermediate layers
        for i in range(1, n_layers):
            if i in self.input_skips:
                # Concatenation happens in forward pass, so input size is hidden_dim + input_dim
                self.layers.append(nn.Linear(hidden_dim + input_dim, hidden_dim))
            else:
                self.layers.append(nn.Linear(hidden_dim, hidden_dim))
                
        # Output layer
        self.layers.append(nn.Linear(hidden_dim, output_dim))

    def forward(self, x):
        y = x
        for i, layer in enumerate(self.layers):
            if i in self.input_skips:
                y = torch.cat([y, x], dim=-1)
            y = layer(y)
            if i < len(self.layers) - 1: # ReLU applied to all but the last layer
                y = torch.relu(y)
        return y
```

**Edge Cases and Pitfalls:**
- `input_skips` must contain indices less than `n_layers - 1` (the output layer does not typically receive a skip connection in this formulation, or if it does, the output dimension must account for it).
- Precision issues may arise if `input_dim` is significantly larger than `hidden_dim`, causing the concatenated vector to be dominated by the input signal.

## Subtopics
## Operating characteristics
- **Time Complexity:** $O(n\_layers \cdot hidden\_dim^2)$ for standard layers, $O(n\_layers \cdot hidden\_dim \cdot (hidden\_dim + input\_dim))$ for skip layers.
- **Memory Complexity:** $O(n\_layers \cdot hidden\_dim^2)$ for weights.
- **Strengths:** Improves learning of high-frequency details compared to plain MLPs [S1, S2, unofficial].
- **Limitations:** Increases the input dimension for skip layers, potentially increasing computation and memory usage slightly.

## Background
This architecture is commonly used in Neural Radiance Fields (NeRF) and related neural implicit representations to address the slow convergence of standard MLPs on high-frequency signals [S1, S2, unofficial]. It was popularized by the original NeRF paper and is a standard component in many neural field implementations.
