# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data sample into a single latent vector $z \in \mathcal{Z}$ [S2, unofficial]. This vector represents global properties such as scene identity or modality, distinguishing it from local conditioning which distributes information across spatial coordinates [S2, unofficial]. It serves as the primary input to the mapping network, which transforms this global code into an intermediate non-linear latent space suitable for conditioning the radiance field [S1].

## How it works
**Inputs and Outputs:**
*   Input: Global latent code $z$.
*   Output: Transformed latent code $z'$ with shape 128.

**Data Structures:**
The mapping network is a simple feedforward MLP. No complex data structures are required beyond the latent vector itself.

**Steps:**
1.  **Normalization:** Normalize the input vector $z$. The specific normalization method (e.g., LayerNorm) is not detailed in the sources, but it is a required step before the linear layers [S1].
2.  **Linear Transformation 1:** Apply a linear layer to the normalized $z$.
3.  **Activation 1:** Apply LeakyReLU with negative slope 0.2.
4.  **Linear Transformation 2:** Apply a second linear layer.
5.  **Activation 2:** Apply LeakyReLU with negative slope 0.2.
6.  **Linear Transformation 3:** Apply a third linear layer.
7.  **Activation 3:** Apply LeakyReLU with negative slope 0.2.
8.  **Output:** The result is the output vector $z'$ of shape 128 [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class MappingNetwork(nn.Module):
    def __init__(self, latent_dim: int = 512):
        super().__init__()
        # Note: Input dimension is not explicitly stated in sources, 
        # but standard StyleGAN uses 512. We assume latent_dim.
        self.norm = nn.LayerNorm(latent_dim)
        self.linear1 = nn.Linear(latent_dim, 128)
        self.linear2 = nn.Linear(128, 128)
        self.linear3 = nn.Linear(128, 128)
        self.activation = nn.LeakyReLU(negative_slope=0.2)

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        # Step 1: Normalize
        z = self.norm(z)
        # Step 2-3: Linear + Activation
        z = self.activation(self.linear1(z))
        # Step 4-5: Linear + Activation
        z = self.activation(self.linear2(z))
        # Step 6-7: Linear + Activation
        z = self.activation(self.linear3(z))
        # Step 8: Output shape is 128
        return z
```

**Parameters:**
*   Output dimension: 128 [S1].
*   Activation: LeakyReLU(0.2) [S1].

**Edge Cases:**
*   Input dimension: The source does not specify the input dimension of $z$. Implementers must ensure the input $z$ matches the expected dimension of the first linear layer [G].

## Subtopics

### Global Generator
The Global Generator extends global conditioning by mapping a single global latent code $z$ to a 2D grid of local latent codes $W$, representing the spatial layout of the scene [S1]. It is chosen when the scene requires spatially varying global properties rather than a single uniform code [S1].

**Definition:** Maps $z$ to a 2D grid $W$ [S1].

**Steps:**
1.  **Initialization:** Initialize with a learnable constant input tensor [S1].
2.  **First Layer:** Apply a 3×3 modulated convolution conditioned on $z$.
3.  **Upsampling Pairs:** For subsequent layers, apply pairs of modulated convolutions. Each pair upsamples the resolution by 2× using a transposed convolution (stride 2) followed by bilinear filtering [S1].
4.  **Activation:** Apply LeakyReLU(0.2) after each convolution [S1].

**Parameters:**
*   Output resolution: 32×32 [S1]. This controls the spatial granularity of the local codes [S1].
*   Channel depth: Starts at 256, ending at 32 (see Table 8 in [S1]).

**Pseudocode:**
```python
import torch
import torch.nn as nn

class GlobalGenerator(nn.Module):
    def __init__(self, latent_dim: int = 512, out_res: int = 32):
        super().__init__()
        # Constant input initialization
        self.const_input = nn.Parameter(torch.randn(256, 4, 4))
        
        # First modulated conv (3x3)
        self.conv1 = ModulatedConv2d(256, 256, 3, latent_dim)
        
        # Upsampling pairs
        # 4x4 -> 8x8
        self.conv2 = ModulatedConv2d(256, 256, 3, latent_dim)
        self.conv3 = ModulatedConv2d(256, 256, 3, latent_dim)
        
        # 8x8 -> 16x16
        self.conv4 = ModulatedConv2d(256, 256, 3, latent_dim)
        self.conv5 = ModulatedConv2d(256, 256, 3, latent_dim)
        
        # 16x16 -> 32x32
        self.conv6 = ModulatedConv2d(256, 32, 3, latent_dim)
        self.conv7 = ModulatedConv2d(32, 32, 3, latent_dim)
        
        self.activation = nn.LeakyReLU(negative_slope=0.2)
        self.out_res = out_res

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        x = self.const_input
        x = self.activation(self.conv1(x, z))
        
        # Upsample 4->8
        x = nn.functional.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False)
        x = self.activation(self.conv2(x, z))
        x = self.activation(self.conv3(x, z))
        
        # Upsample 8->16
        x = nn.functional.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False)
        x = self.activation(self.conv4(x, z))
        x = self.activation(self.conv5(x, z))
        
        # Upsample 16->32
        x = nn.functional.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False)
        x = self.activation(self.conv6(x, z))
        x = self.activation(self.conv7(x, z))
        
        return x
```
*Note: `ModulatedConv2d` is a standard StyleGAN component not defined in the source text, so it is referenced by name [G].*

## Operating characteristics
*   **Time Complexity:** The mapping network is $O(1)$ with respect to spatial resolution, as it processes a single vector. The global generator is $O(N^2)$ where $N$ is the output resolution (32×32) [S1].
*   **Memory Complexity:** The mapping network uses minimal memory. The global generator stores the output grid $W$ of size $C \times H \times W$ (e.g., $32 \times 32 \times 32$) [S1].
*   **Strengths:** Captures global scene properties efficiently. The global generator allows for spatial variation of global features [S1].
*   **Limitations:** The global generator has significantly higher computational cost than the simple mapping network [S1].
*   **When to use:** Use the mapping network for uniform global conditioning. Use the global generator when the scene requires spatially varying global attributes [S1].
