# Conditional Radiance Field Training

Also called: Conditional NeRF, Instance-conditioned NeRF

## Overview
Conditional Radiance Field Training is a method for modeling shape and appearance variations across multiple 3D instances by training a single conditional neural radiance field [S1]. It solves the problem of efficiently representing a dataset of objects with varying geometries and materials without training separate independent models for each instance [S1]. It differs from independent NeRF training by sharing network weights across instances while using learned latent codes to encode instance-specific properties, and it differs from shared-branch approaches by injecting these codes directly into the positional and directional embeddings [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A dataset of $K$ object instances. For each instance $k$, a set of training rays $R_k$ is available, where each ray $r$ has a corresponding ground truth color $C(r)$.
*   **Output:** A conditional radiance field model consisting of two networks ($F_{coarse}$ and $F_{fine}$) and learned latent codes for each instance.

**Data Structures:**
*   **Shape Code ($z_k^{(s)}$):** A 32-dimensional learned vector for instance $k$.
*   **Color Code ($z_k^{(c)}$):** A 32-dimensional learned vector for instance $k$.
*   **Coarse Network ($F_{coarse}$):** A Multi-Layer Perceptron (MLP) with 4 layers, 256 channels width, and ReLU activations. It outputs density and features.
*   **Fine Network ($F_{fine}$):** A Multi-Layer Perceptron (MLP) with 4 layers, 256 channels width, and ReLU activations. It outputs color.
*   **Architecture Details:** The model uses skip connections from the shape code and embedded inputs to the network layers, similar to the original NeRF architecture [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize $F_{coarse}$, $F_{fine}$, and the set of shape codes $\{z_k^{(s)}\}_{k=1}^K$ and color codes $\{z_k^{(c)}\}_{k=1}^K$. Each code is 32-dimensional.
2.  **Instance Sampling:** For each training iteration, sample an object instance index $k$ uniformly from $\{1, \dots, K\}$ [S1].
3.  **Code Retrieval:** Retrieve the shape code $z_k^{(s)}$ and color code $z_k^{(c)}$ corresponding to instance $k$ [S1].
4.  **Ray Sampling:** Sample a batch of training rays $R_k$ from the set of all rays belonging to instance $k$ [S1].
5.  **Coarse Network Forward Pass:**
    *   For each ray $r \in R_k$, use stratified sampling to sample points along the ray [S1].
    *   Inject the shape code $z_k^{(s)}$ and color code $z_k^{(c)}$ wherever positional or directional embeddings are injected in the original NeRF model [S1].
    *   Pass the embedded points and codes through $F_{coarse}$ to estimate density and features [S1].
    *   Compute the rendered color $\hat{C}_{coarse}(r, z_k^{(s)}, z_k^{(c)})$ using the density outputs [S1].
6.  **Hierarchical Sampling:** Use the density outputs from $F_{coarse}$ to sample a hierarchical volume of points for the fine network [S1].
7.  **Fine Network Forward Pass:**
    *   Pass the hierarchically sampled points and codes through $F_{fine}$ [S1].
    *   Compute the rendered color $\hat{C}_{fine}(r, z_k^{(s)}, z_k^{(c)})$ [S1].
8.  **Loss Calculation:** Compute the training loss $L_{train}$ using the photometric loss defined below [S1].
9.  **Optimization:** Update the parameters of $F_{coarse}$, $F_{fine}$, $z_k^{(s)}$, and $z_k^{(c)}$ using the Adam optimizer [S1].
10. **Convergence:** Repeat steps 2-9 until convergence, which averages around 1 million iterations [S1].

**Formulas:**
The training loss is the sum of squared Euclidean distances between predicted and ground truth colors for both coarse and fine networks [S1]:

$$
L_{train} = \sum_{k=1}^{K} \sum_{r \in R_k} \left( \|\hat{C}_{coarse}(r, z_k^{(s)}, z_k^{(c)}) - C(r)\|_2^2 + \|\hat{C}_{fine}(r, z_k^{(s)}, z_k^{(c)}) - C(r)\|_2^2 \right)
$$

Where:
*   $K$ is the total number of instances.
*   $R_k$ is the set of training rays for instance $k$.
*   $\hat{C}_{coarse}$ and $\hat{C}_{fine}$ are the predicted colors from the coarse and fine networks, respectively.
*   $C(r)$ is the ground truth color for ray $r$.
*   $z_k^{(s)}$ and $z_k^{(c)}$ are the shape and color codes for instance $k$.

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $10^{-4}$ for training [S1].
*   **Beta1:** 0.9 [S1].
*   **Beta2:** 0.999 [S1].
*   **Epsilon:** $10^{-8}$ [S1].
*   **Training Duration:** Until convergence, averaging 1 million iterations [S1].
*   **Code Dimension:** 32 dimensions for both shape and color codes [S1].
*   **Network Width:** 256 channels [S1].
*   **Network Depth:** 4 layers [S1].

**Edge Cases and Pitfalls:**
*   **Parameter Count:** In ablation studies, layer widths are increased to keep the number of parameters approximately equal across experiments, ensuring fair comparison with independent NeRF baselines [S1].
*   **Editing vs. Training:** During editing, the coarse network is kept fixed, and only the fine network $F_{fine}$ and codes are optimized with a higher learning rate of $10^{-2}$ for 100 iterations [S1]. This distinction is critical if the method is extended to editing tasks.
*   **Regularization:** For single-view training scenarios (e.g., CARLA dataset), view-dependence regularization may be required to ensure color consistency across views, though the standard multi-view training formulation does not explicitly include this term in the primary loss equation [S1].

def train_conditional_nerf(instances, rays_per_instance, num_iterations=1000000):
    """
    Train a conditional radiance field on K instances.
    
    Args:
        instances: List of K instance objects. Each instance has a method 
                   get_training_rays(batch_size) returning rays.
        rays_per_instance: Number of rays to sample per instance per iteration.
        num_iterations: Total training iterations.
        
    Returns:
        F_coarse, F_fine, shape_codes, color_codes
    """
    K = len(instances)

    F_coarse = MLP(depth=4, width=256, activation='relu')
    F_fine = MLP(depth=4, width=256, activation='relu')
    
    # Initialize learned codes (32-dimensional)
    shape_codes = np.random.randn(K, 32)
    color_codes = np.random.randn(K, 32)
    
    # Optimizer setup (Adam)
    optimizer = Adam(params=list(F_coarse.parameters()) + 
                     list(F_fine.parameters()) + 
                     list(shape_codes) + 
                     list(color_codes), 
                     lr=1e-4, beta1=0.9, beta2=0.999, eps=1e-8)
    
    for iteration in range(num_iterations):
        # Step 2: Sample instance k
        k = np.random.randint(0, K)
        
        # Step 3: Retrieve codes
        z_s = shape_codes[k]
        z_c = color_codes[k]
        
        # Step 4: Sample rays for instance k
        rays = instances[k].get_training_rays(rays_per_instance)
        
        # Initialize loss accumulator
        total_loss = 0.0
        
        for ray in rays:
            # Step 5: Coarse network forward pass
            # Stratified sampling for coarse network
            points_coarse = stratified_sample_ray(ray)
            
            # Inject codes into embeddings
            # Note: Implementation detail [G] - codes are concatenated or added 
            # to positional/directional embeddings before network input
            inputs_coarse = embed_inputs(ray, points_coarse, z_s, z_c)
            
            # Get density and features from coarse network
            density_coarse, features_coarse = F_coarse(inputs_coarse)
            
            # Render coarse color
            color_coarse = render_volume(ray, density_coarse, features_coarse)
            
            # Step 6: Hierarchical sampling for fine network
            # Sample points based on coarse density
            points_fine = hierarchical_sample(ray, density_coarse)
            
            # Step 7: Fine network forward pass
            inputs_fine = embed_inputs(ray, points_fine, z_s, z_c)
            
            # Get color from fine network
            color_fine = F_fine(inputs_fine)
            
            # Step 8: Compute loss
            # Ground truth color for the ray
            c_gt = ray.get_ground_truth_color()
            
            loss_coarse = np.sum((color_coarse - c_gt) ** 2)
            loss_fine = np.sum((color_fine - c_gt) ** 2)
            
            total_loss += loss_coarse + loss_fine
            
        # Step 9: Optimization
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
    return F_coarse, F_fine, shape_codes, color_codes

    Embed ray direction, point positions, and latent codes.

    """

    dir_enc = directional_encoding(ray.direction)

## Operating characteristics
*   **Time Complexity:** Training time is proportional to the number of iterations (average 1M) and the number of instances $K$. Each iteration processes a batch of rays from one instance.
*   **Memory Complexity:** Memory usage scales with the number of instances $K$ due to the storage of $2 \times 32$-dimensional codes per instance, plus the fixed memory for the two MLPs ($F_{coarse}$ and $F_{fine}$).
*   **Measured Performance:** On the PhotoShapes dataset, the method matches the performance of training independent NeRF models for each instance in terms of PSNR and LPIPS metrics [S1].
*   **Scaling:** The method scales well to more training instances; experiments with all 626 instances of the PhotoShapes dataset showed successful reconstruction [S1].
*   **Strengths:** Efficiently models shape and appearance differences across instances using a single model; matches independent model performance; scales to large numbers of instances.
*   **Limitations:** Requires joint optimization of codes and network weights, which may be sensitive to initialization; separate shape and color codes are required for best performance, increasing parameter count compared to a single code approach [S1].
*   **When to Use:** When you have a dataset of multiple instances with varying shapes and appearances and want a unified model that generalizes across them.
*   **When Not to Use:** When instances are completely unrelated and do not share underlying structural priors, or when computational resources are extremely limited and independent models are preferred for simplicity.

## Background
The method was introduced in the paper "Editing Conditional Radiance Fields" [S1]. It builds upon the original NeRF architecture [45] and the concept of conditional radiance fields. The authors evaluated the method on the PhotoShapes [51] and Aubry chairs [5] datasets. The approach was developed to enable accurate editing of 3D instances by first training a conditional model that captures the variation across the dataset [S1].
