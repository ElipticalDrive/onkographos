# Autoencoder/Autodecoder Conditioning

Also called: Auto-decoder training setup for shape space learning, Conditional Neural Field, Latent vector optimization, Multi-shape architecture

## Overview
This method conditions a shared neural field decoder on instance-specific latent vectors to represent multiple shapes or signals within a single model. It solves the problem of multi-instance representation by either optimizing a learnable latent vector per sample jointly with the decoder weights (autodecoder) or using an encoder to produce these vectors (autoencoder) [S2, unofficial]. It differs from concatenation conditioning by treating the latent code as a separate optimization variable or encoder output rather than a static input feature, and from HyperNetwork conditioning by using a fixed decoder architecture where the latent code modulates the output directly rather than generating weights [S12582-concatenation-conditioning.md][S12585-hypernetwork-conditioning.md].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of training examples $J$ (e.g., point clouds or images). For each example $j$, input data $D_j$ (e.g., points and normals).
*   **Output:** A trained shared decoder $f_\theta$ and, for each instance $j$, a latent vector $z_j \in \mathbb{R}^L$.

**Data Structures:**
*   **Latent Vector $z_j$:** A learnable parameter vector of size $L$.
    *   For shape reconstruction, $L=0$ (no latent code) [S1, unofficial].
    *   For shape space learning, $L=256$ [S1, unofficial].
    *   Initialized to zero: $z_j \leftarrow \mathbf{0} \in \mathbb{R}^L$ [S1, unofficial].
*   **Decoder Network $f_\theta$:** An MLP that takes coordinates $x \in \mathbb{R}^3$ and latent code $z_j \in \mathbb{R}^L$ as input.
    *   Input dimension: $3 + L$.
    *   Architecture (for $L=256$):
        1.  Layer 1: FC+ (Fully Connected + Softplus)
        2.  Layer 2: FC+
        3.  Layer 3: FC+
        4.  Layer 4: FC+
        5.  Layer 5: FC (Linear, 512 units)
        6.  Layer 6: FC+
        7.  Layer 7: FC+
        8.  Layer 8: FC (Linear, output units)
    *   Skip connection: Input $(x, z_j)$ is concatenated directly to the output of Layer 4 [S1, unofficial].
    *   Activation: Softplus $\sigma(x) = \frac{1}{\beta} \ln(1 + e^{\beta x})$ with $\beta = 100$ [S1, unofficial].

**Numbered Steps:**
1.  **Initialization:** For each training example $j \in J$, initialize latent vector $z_j = \mathbf{0} \in \mathbb{R}^L$ [S1, unofficial].
2.  **Batch Sampling:** Sample a batch $B \subset J$. For each $j \in B$, sample query points from $D_j$.
3.  **Forward Pass:** Compute prediction $y_j = f_\theta(x, z_j)$ for sampled points $x$ [S2, unofficial].
4.  **Loss Calculation:** Compute loss $\mathcal{L}(\theta, z_j)$ based on the task (e.g., reconstruction error) [S1, unofficial].
5.  **Regularization:** Add L2 regularization term $\alpha \|z_j\|_2$ to the loss [S1, unofficial].
6.  **Optimization:** Update $\theta$ and $z_j$ jointly using gradient descent [S2, unofficial].
7.  **Test-Time Inference:** For a new test shape, optimize $z_j$ for 800 iterations using the trained $\theta$ and the test data loss $\ell$ [S1, unofficial].

**Formulas:**
*   **Total Loss:**
    $$ \mathcal{L} = \frac{1}{|B|} \sum_{j \in B} \left( \ell(\theta, z_j) + \alpha \|z_j\|_2 \right) $$
    Where $\ell$ is the task-specific loss (e.g., Chamfer distance, SDF loss) [S1, unofficial].
*   **Latent Regularizer:**
    $$ \mathcal{L}_l(z) = \|z\|_2 $$
    This penalizes large magnitudes to keep latent codes close to zero, ensuring similarity between different shapes in the autodecoder framework [S3].
*   **Softplus Activation:**
    $$ \text{FC}^+(x) = \text{FC}\left(\frac{1}{\beta} \ln(1 + e^{\beta x})\right) $$
    With $\beta = 100$ [S1, unofficial].

**Parameters:**
*   $L$: Latent vector size. $L=256$ for shape space learning [S1, unofficial].
*   $\alpha$: Regularization weight. $\alpha = 0.01$ [S1, unofficial].
*   $\beta$: Softplus smoothness. $\beta = 100$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Shared Latent Code for Multi-Output:** In some frameworks (e.g., FIRe), the SDF and DDF models share the same latent code $z$ for a given shape, which may limit independent control over geometry and directionality [S3].
*   **Optimization Stability:** Autodecoder training requires joint optimization of weights and latent codes, which can be sensitive to learning rates and initialization [S2, unofficial].
*   **Test-Time Optimization:** Test shapes require iterative optimization of $z_j$, which is computationally expensive compared to encoder-based methods [S1, unofficial].

## Subtopics

### Latent Code Regularizer
An L2 norm regularizer applied to latent codes to keep them close to zero, ensuring that latent codes for different shapes remain similar in the autodecoder framework [S3]. It is defined as $\mathcal{L}_l(z) = \|z\|_2$ [S3]. A pitfall is that in some implementations, the SDF and DDF models share the same latent code for a given shape, which may constrain the representation [S3].

## Operating characteristics
*   **Time Complexity:** Training involves joint optimization of $\theta$ and $z_j$, which is more expensive than fixed-latent methods. Test-time inference requires iterative optimization of $z_j$ (e.g., 800 iterations) [S1, unofficial].
*   **Memory Complexity:** Requires storing one latent vector $z_j$ per instance, adding $O(L \cdot |J|)$ memory overhead [S1, unofficial].
*   **Strengths:** Enables learning a continuous shape space and generalizing to unseen shapes via interpolation of latent vectors [S1, unofficial].
*   **Limitations:** Test-time inference is slow due to iterative optimization; requires careful tuning of regularization $\alpha$ [S1, unofficial].
*   **When to Use:** When learning a continuous latent space of shapes is desired, or when encoder-based methods are not feasible [S1, unofficial].
*   **When Not to Use:** When real-time inference is required, or when the number of instances is very large (memory overhead) [S1, unofficial].

## Background
The auto-decoder setup was introduced by Park et al. (2019) for learning shapes from raw scans [S1, unofficial]. It builds on the concept of neural fields where a shared MLP is conditioned on latent codes [S2, unofficial]. The method has been used in shape reconstruction and shape space learning experiments on datasets like D-Faust [S1, unofficial].
