# HyperNetwork Conditioning
Also called: Hypernetwork-based conditioning, HyperNet conditioning

## Overview
HyperNetwork Conditioning is a method for conditioning a Neural Field by using a secondary network (the HyperNetwork) to predict the weights of the primary Neural Field decoder from a latent code [S1, unofficial]. Unlike concatenation-based conditioning, which shares decoder parameters across all instances, this approach creates a distinct Neural Field (with unique weights) for each input instance, allowing the primary network to maintain lower complexity [S1, unofficial].

## How it works
**Inputs:**
- Spatial coordinate $x \in \Omega$ [S1, unofficial].
- Latent code $z \in \mathcal{Z}$ encoding the specific identity or variation of the data sample [S1, unofficial].

**Outputs:**
- Field value $v \in \mathcal{X}$ (e.g., density, color) [S1, unofficial].

**Data Structures:**
1. **HyperNetwork ($H$):** A neural network that takes $z$ as input and outputs the weight parameters $\theta$ for the decoder.
2. **Decoder ($D$):** A neural network parameterized by $\theta$, which takes $x$ as input.

**Steps:**
1. Encode the input instance into a latent code $z$.
2. Pass $z$ through the HyperNetwork $H$ to generate the decoder weights $\theta = H(z)$.
3. Construct the decoder network $D_\theta$ using the predicted weights $\theta$.
4. Evaluate the decoder at the spatial coordinate: $v = D_\theta(x)$.

**Pseudocode:**
```python
def hypernetwork_conditioning(x, z, hypernet, decoder_template):
    """
    x: spatial coordinate
    z: latent code
    hypernet: function mapping z -> theta (decoder weights)
    decoder_template: function defining the architecture of the decoder
    """
    # Step 1 & 2: Predict decoder weights from latent code
    theta = hypernet(z)
    
    # Step 3: Instantiate decoder with predicted weights
    # Note: In practice, this involves setting the weights of the decoder network
    decoder = decoder_template(weights=theta)
    
    # Step 4: Evaluate the decoder at the spatial coordinate
    output = decoder(x)
    
    return output
```

## Subtopics

### Hybrid Conditioning
Uses one global code to encode basic information shared between instances and several local codes to encode instance-specific details [S1, unofficial].

## Operating characteristics
- **Complexity:** The complexity of the primary network (Neural Field decoder) can be much lower compared to concatenation-based methods, hinting at a more compact representation [S1, unofficial].
- **Comparison:** Unlike concatenation, this creates a different Neural Field for each input instance [S1, unofficial].

## Background
The concept utilizes a HyperNetwork [Ha et al., 2016] to predict the parameters of the Neural Field decoder from the latent code [S1, unofficial]. Recent basic research in the area of HyperNetworks suggests that the complexity of the primary network can be much lower, hinting at a more compact representation [Galanti & Wolf, 2020].
