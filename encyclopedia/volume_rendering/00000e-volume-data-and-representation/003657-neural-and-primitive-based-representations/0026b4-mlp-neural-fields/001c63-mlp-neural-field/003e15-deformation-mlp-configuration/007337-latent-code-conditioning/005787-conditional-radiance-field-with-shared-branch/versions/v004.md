# Conditional Radiance Field with Shared Branch

Also called: CRF with Shared Branch, Modular Conditional Radiance Field

## Overview
The Conditional Radiance Field with Shared Branch is a neural radiance field architecture designed for shape and color disentanglement, enabling efficient editing by allowing specific submodules to be finetuned independently. It maps a 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and instance-specific shape code $\mathbf{z}^{(s)}$ and color code $\mathbf{z}^{(c)}$ to radiance $\mathbf{c}$ and scalar density $\sigma$. It sets itself apart from standard conditional radiance fields by introducing a shared shape network that captures category-specific geometry, improving view synthesis quality and scalability to multiple instances compared to models without this shared branch.

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D position $\mathbf{x}$, viewing direction $\mathbf{d}$, instance-specific shape latent code $\mathbf{z}^{(s)} \in \mathbb{R}^{32}$, instance-specific color latent code $\mathbf{z}^{(c)} \in \mathbb{R}^{32}$.
*   **Outputs:** Scalar density $\sigma \in \mathbb{R}$, RGB radiance $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The network consists of five Multi-Layer Perceptrons (MLPs), all 4 layers deep with 256 channels width and ReLU activations, outputting 256-dimensional features unless specified otherwise:
1.  $F_{\text{share}}$: Shared shape network.
2.  $F_{\text{inst}}$: Instance-specific shape network.
3.  $F_{\text{fuse}}$: Fusion shape network.
4.  $F_{\text{dens}}$: Output density network (Linear layer).
5.  $F_{\text{rad}}$: Output radiance network (2-layer MLP).

**Positional Encoding:**
Standard positional encoding $\gamma(\cdot)$ is applied to input coordinates and directions as per Mildenhall et al. [S1].

**Algorithm:**
1.  **Compute Shared Shape Representation:**
    Pass the positional encoding of the position, $\gamma(\mathbf{x})$, through the shared shape network:
    $$ \mathbf{h}_{\text{share}} = F_{\text{share}}(\gamma(\mathbf{x})) $$
2.  **Compute Instance-Specific Shape Representation:**
    Concatenate the shape code $\mathbf{z}^{(s)}$ and the positional encoding $\gamma(\mathbf{x})$. Pass the result through the instance-specific shape network:
    $$ \mathbf{h}_{\text{inst}} = F_{\text{inst}}([\mathbf{z}^{(s)}; \gamma(\mathbf{x})]) $$
3.  **Fuse Representations:**
    Add the outputs of the shared and instance-specific networks, then pass the sum through the fusion shape network:
    $$ \mathbf{h}_{\text{fuse}} = F_{\text{fuse}}(\mathbf{h}_{\text{share}} + \mathbf{h}_{\text{inst}}) $$
4.  **Predict Density:**
    Pass the fused representation through the linear density network to obtain scalar density:
    $$ \sigma = F_{\text{dens}}(\mathbf{h}_{\text{fuse}}) $$
5.  **Predict Radiance:**
    Concatenate the fused representation $\mathbf{h}_{\text{fuse}}$, the color code $\mathbf{z}^{(c)}$, and the encoded viewing direction $\gamma(\mathbf{d})$. Pass this concatenation through the two-layer radiance network:
    $$ \mathbf{c} = F_{\text{rad}}([\mathbf{h}_{\text{fuse}}; \mathbf{z}^{(c)}; \gamma(\mathbf{d})]) $$

**Parameters:**
*   Shape and color code dimension: 32 [S1].
*   MLP depth for $F_{\text{share}}, F_{\text{inst}}, F_{\text{fuse}}$: 4 layers [S1].
*   MLP width: 256 channels [S1].
*   Feature dimension: 256-dimensional features output by $F_{\text{share}}, F_{\text{inst}}, F_{\text{fuse}}$ [S1].
*   Optimizer: Adam [S1].
*   Training learning rate: $10^{-4}$ [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ConditionalRadianceFieldSharedBranch(nn.Module):
    def __init__(self, pos_enc_dim, view_enc_dim, latent_dim=32, hidden_dim=256, depth=4):
        super().__init__()
        self.latent_dim = latent_dim
        
        # Shared shape network: 4 layers, 256 channels
        self.F_share = nn.Sequential(*[
            nn.Linear(pos_enc_dim, hidden_dim), nn.ReLU()
        ] + [
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU()
        ] * (depth - 2) + [
            nn.Linear(hidden_dim, hidden_dim)
        ])
        
        # Instance-specific shape network: 4 layers, 256 channels
        # Input: latent_dim + pos_enc_dim
        self.F_inst = nn.Sequential(*[
            nn.Linear(latent_dim + pos_enc_dim, hidden_dim), nn.ReLU()
        ] + [
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU()
        ] * (depth - 2) + [
            nn.Linear(hidden_dim, hidden_dim)
        ])
        
        # Fusion shape network: 4 layers, 256 channels
        # Input: hidden_dim
        self.F_fuse = nn.Sequential(*[
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU()
        ] + [
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU()
        ] * (depth - 2) + [
            nn.Linear(hidden_dim, hidden_dim)
        ])
        
        # Density network: Linear layer
        self.F_dens = nn.Linear(hidden_dim, 1)
        
        # Radiance network: 2-layer MLP
        # Input: hidden_dim + latent_dim + view_enc_dim
        self.F_rad = nn.Sequential(
            nn.Linear(hidden_dim + latent_dim + view_enc_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 3) # RGB output
        )

    def forward(self, x, d, z_s, z_c):
        """
        Args:
            x: (N, 3) positions
            d: (N, 3) viewing directions
            z_s: (N, 32) shape codes
            z_c: (N, 32) color codes
        Returns:
            sigma: (N,) scalar density
            c: (N, 3) radiance
        """
        # Note: Positional encoding gamma is assumed to be applied to x and d 
        # before this function call or within a wrapper. 
        # For self-containment, we assume x and d are already encoded or 
        # the input dimensions match the encoded dimensions.
        # Here we assume x_enc and d_enc are passed in or handled externally.
        # To be strictly self-contained based on the note "Pass positional encoding gamma(x)",
        # we assume the inputs x and d here are the raw coordinates and we must encode them.
        # However, standard NeRF implementations handle gamma externally. 
        # We will assume x and d are already positional encoded to match the layer sizes.
        
        # 1. Compute shared shape representation
        h_share = self.F_share(x)
        
        # 2. Compute instance-specific shape representation
        # Concatenate shape code z_s and positional encoding gamma(x)
        x_inst_input = torch.cat([z_s, x], dim=-1)
        h_inst = self.F_inst(x_inst_input)
        
        # 3. Fuse representations
        h_fuse = self.F_fuse(h_share + h_inst)
        
        # 4. Predict density
        sigma = self.F_dens(h_fuse).squeeze(-1)
        
        # 5. Predict radiance
        # Concatenate h_fuse, color code z_c, and encoded viewing direction gamma(d)
        rad_input = torch.cat([h_fuse, z_c, d], dim=-1)
        c = self.F_rad(rad_input)
        
        return sigma, c
```

**Edge Cases and Pitfalls:**
*   **Optimization Stability:** The latent codes $\mathbf{z}^{(s)}$ and $\mathbf{z}^{(c)}$ are learned parameters optimized jointly with the network weights. Using a learning rate of $10^{-4}$ for training and $10^{-2}$ for editing is critical [S1].
*   **Caching:** Because the set of training rays is small during optimization, caching computed latent codes is computationally feasible and accelerates edits [S1].

## Operating characteristics
*   **Performance:** On the PhotoShapes dataset, the shared shape branch improves PSNR from 33.91 (without shared branch) to 35.79 [S1].
*   **Efficiency:** The modular design allows for efficient editing. Acceleration factors of 3.2× for color edits and 1.9× for shape edits are reported due to selective updates [S1].
*   **Scalability:** The shared shape branch helps the model scale to more instances compared to models without it [S1].
*   **Comparison:** The model outperforms single-instance NeRF models trained on individual objects [S1].

## Background
The method was introduced in "Editing Conditional Radiance Fields" (ICCV 2021) [S1]. It builds on the inductive biases of positional encodings and stage-wise network design found in NeRF [S1]. The architecture is designed to separate shape and color representations to facilitate editing, where only a subset of network components need to be updated during the editing process.
