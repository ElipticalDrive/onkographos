# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data sample into a single latent vector $z$, allowing the model to distinguish between samples that share underlying geometry but differ in appearance or instance-specific details [S2, unofficial]. It maps this global code to an intermediate non-linear latent space to modulate the decoder network [S1]. It is distinguished from [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md) by using a fixed-size vector for the entire sample rather than generating network weights or parameters dynamically.

## How it works
**Inputs and Outputs:**
*   Input: Global latent code $z \in \mathbb{R}^{d_z}$.
*   Output: Intermediate latent representation $w \in \mathbb{R}^{128}$ (for the Mapping Network) or a spatial grid $W$ (for the Global Generator variant).

**Data Structures:**
*   $z$: 1D vector.
*   $w$: 1D vector of size 128.
*   $W$: 2D grid of local latent codes.

**Steps (Mapping Network):**
1.  Normalize input $z$. [S1]
2.  Pass through three linear layers. [S1]
3.  Apply LeakyReLU(0.2) activation after each linear layer. [S1]
4.  Output shape is 128. [S1]

**Pseudocode:**
```python
import torch
import torch.nn as nn

class MappingNetwork(nn.Module):
    def __init__(self, input_dim: int):
        super().__init__()
        # Three linear layers, output dim 128 for each
        self.linear1 = nn.Linear(input_dim, 128)
        self.linear2 = nn.Linear(128, 128)
        self.linear3 = nn.Linear(128, 128)
        self.leaky_relu = nn.LeakyReLU(negative_slope=0.2)

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        # Normalize input z
        # Note: Specific normalization method (e.g., LayerNorm) is not detailed in sources [G: Assume LayerNorm or standard normalization]
        z = torch.nn.functional.layer_norm(z, (z.size(-1),))
        
        x = self.linear1(z)
        x = self.leaky_relu(x)
        
        x = self.linear2(x)
        x = self.leaky_relu(x)
        
        x = self.linear3(x)
        x = self.leaky_relu(x)
        
        return x
```

**Parameters:**
*   Activation: LeakyReLU with negative slope 0.2 [S1].
*   Output dimension: 128 [S1].

**Edge Cases:**
*   Input dimension $d_z$ must match the encoder output or specified latent size. [G]

## Subtopics

### Global Generator
Maps a single global latent code $z$ to a 2D grid of local latent codes $W$ representing the spatial layout of the scene [S1]. It uses successive modulated convolutional layers conditioned on $z$ [S1]. The first layer uses a constant input and a 3×3 modulated convolution [S1]. Subsequent pairs upsample resolution by 2× using a transposed convolution (stride 2) followed by bilinear filtering [S1]. LeakyReLU(0.2) is applied after each convolution [S1]. The output resolution is a hyperparameter controlling the spatial region per local code; typically set to 32×32 [S1].

## Background
Originated in the context of unconstrained scene generation with locally conditioned radiance fields [S1]. The mapping network concept builds on StyleGAN's use of a mapping network to map latent codes to an intermediate space [S1][S2, unofficial].
