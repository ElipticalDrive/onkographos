# Autoencoder/Autodecoder Conditioning

Also called: Auto-decoder training setup for shape space learning, Conditional Neural Field, Latent vector optimization, Multi-shape architecture

## Overview
Autoencoder/Autodecoder Conditioning assigns a unique learnable latent vector $z_i$ to each data instance, which is concatenated with spatial coordinates and fed into a shared decoder network $f_\theta$ to reconstruct instance-specific geometry or appearance [S1, unofficial][S2, unofficial]. It differs from Concatenation Conditioning by optimizing the latent codes themselves as trainable parameters rather than deriving them from a fixed encoder or context, and from HyperNetwork Conditioning by using direct vector concatenation instead of generating network weights [S1, unofficial][S2, unofficial]. This method enables the model to learn a continuous shape or appearance space where interpolation of latent vectors yields smooth transitions between instances [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A batch of training instances $J$, where each instance $j$ has associated target data (e.g., point clouds, depth maps, or images).
- **Output:** A trained decoder network $f_\theta$ and a set of optimized latent vectors $\{z_j\}_{j \in J}$.

**Data Structures:**
- **Latent Vector ($z_j$):** A learnable parameter vector of dimension $D$. For shape reconstruction, $D$ may be 0 (effectively removing conditioning) or a fixed size like 256 [S1, unofficial].
- **Decoder Network ($f_\theta$):** A Multi-Layer Perceptron (MLP) with specific architecture details defined below.

**Network Architecture:**
The decoder accepts an input vector of size $3 + L$, where 3 represents spatial coordinates $(x, y, z)$ and $L$ is the latent vector size [S1, unofficial].
- **Layers:** The sequence is `FC+` $\rightarrow$ `FC+` $\rightarrow$ `FC+` $\rightarrow$ `FC+` $\rightarrow$ `512` $\rightarrow$ `FC+` $\rightarrow$ `FC+` $\rightarrow$ `FC` [S1, unofficial].
- **Definitions:**
    - `FC`: Fully connected linear layer.
    - `FC+`: `FC` followed by Softplus activation [S1, unofficial].
    - `512`: A fully connected layer with 512 units, no activation specified in the sequence list but implied as part of the hidden block [S1, unofficial].
    - **Skip Connection:** A direct connection from the input layer to the 4th layer (the first `512` layer) [S1, unofficial].
    - **Activation:** Softplus is defined as $x \mapsto \frac{1}{\beta} \ln(1 + e^{\beta x})$ with $\beta = 100$ [S1, unofficial].

**Optimization Steps:**
1. **Initialization:** For each training example $j \in J$, initialize the latent vector $z_j \in \mathbb{R}^{256}$ to zero [S1, unofficial].
2. **Forward Pass:** For a query point $x$ and instance $j$, compute the output $y = f_\theta([x; z_j])$, where $[x; z_j]$ denotes concatenation [S2, unofficial].
3. **Loss Calculation:** Compute the reconstruction loss $l(\theta, z_j)$ based on the target data for instance $j$ [S1, unofficial].
4. **Regularization:** Apply an L2 norm regularizer to the latent code: $\mathcal{L}_l(z_j) = \|z_j\|_2$ [S3]. This keeps latent codes close to zero, ensuring similarity between different shapes in the autodecoder framework [S3].
5. **Update:** Optimize the total loss for a batch $B \subset J$:
   $$ \mathcal{L} = \frac{1}{|B|} \sum_{j \in B} \left( l(\theta, z_j) + \alpha \|z_j\|_2 \right) $$
   where $\alpha = 0.01$ [S1, unofficial]. The parameters $\theta$ and vectors $z_j$ are updated jointly using an optimizer (e.g., Adam) [S1, unofficial].

**Inference (Test Time):**
For a test shape, the decoder weights $\theta$ are fixed. The latent vector $z$ is optimized from scratch (or from a prior) for 800 iterations using the reconstruction loss $l$ to obtain the final reconstruction [S1, unofficial].

**Pitfalls:**
- **Shared Latent Codes:** In multi-output setups (e.g., predicting both SDF and DDF), the same latent code $z$ must be used for all outputs of a given shape to maintain consistency [S3].
- **Precision:** The Softplus approximation with $\beta=100$ is a smooth ReLU; ensure numerical stability in implementation [S1, unofficial].

## Subtopics

### Latent Code Regularizer
An L2 norm regularizer applied to the latent codes $z$ during autodecoder training. It penalizes large magnitudes to keep codes close to zero, enforcing similarity between different shapes in the learned space [S3]. It is a critical component for preventing overfitting to individual shapes and ensuring a well-behaved latent manifold [S3].

## Operating characteristics
- **Time Complexity:** Training time scales with the number of instances and the optimization iterations required for convergence. Inference requires additional optimization time (e.g., 800 iterations) per test instance to find the optimal latent code [S1, unofficial].
- **Memory Complexity:** Memory usage increases linearly with the number of instances $J$ due to the storage of latent vectors $z_j \in \mathbb{R}^D$ [S1, unofficial]. For $J=10$ humans and $D=256$, this is negligible compared to the network weights.
- **Performance:** Demonstrated effective learning of shape spaces from raw scans (e.g., D-Faust dataset) and generalization to unseen humans [S1, unofficial].
- **Strengths:** Enables flexible representation of multiple shapes with a single network; allows interpolation in latent space [S1, unofficial].
- **Limitations:** Requires per-instance optimization at test time, which is slower than direct evaluation [S1, unofficial].

## Background
The method originates from the "Auto-Decoder" setup introduced by Park et al. (2019) in "Implicit Geometric Regularization for Learning Shapes" [S1, unofficial]. It was applied to learning shape spaces from raw scans and demonstrated state-of-the-art results on datasets like D-Faust [S1, unofficial]. The concept of conditioning neural fields with latent codes is also discussed in broader introductions to neural fields [S2, unofficial].
