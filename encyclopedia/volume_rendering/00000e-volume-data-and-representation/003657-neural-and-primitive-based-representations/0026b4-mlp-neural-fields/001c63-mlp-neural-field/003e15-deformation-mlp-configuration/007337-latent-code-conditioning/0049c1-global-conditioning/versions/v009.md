# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data sample into a single latent vector $z$, allowing a neural field to represent distinct instances [S2, unofficial]. It maps this global code to an intermediate non-linear latent space to modulate the radiance field, distinguishing itself from local conditioning which distributes information across spatial coordinates [S2, unofficial]. It serves as the foundational step for [Latent Code Conditioning](16345-latent-code-conditioning.md), preceding variants like the [Global Generator](#global-generator) or [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md).

## How it works
**Inputs and Outputs:**
- Input: Global latent code $z \in \mathbb{R}^D$. Typical dimensionality $D=512$ [S1][S2, unofficial], though specific applications may use $D=64$ [S1].
- Output: Transformed latent vector $z' \in \mathbb{R}^{128}$ [S1].

**Data Structures:**
- The mapping network consists of three sequential linear layers.
- Activation: LeakyReLU with negative slope 0.2 [S1].

**Steps:**
1. Normalize the input vector $z$. The specific normalization method (e.g., LayerNorm) is not detailed in the source, but is applied before the first linear layer [S1].
2. Pass $z$ through the first linear layer.
3. Apply LeakyReLU(0.2) to the output of the first linear layer.
4. Pass the result through the second linear layer.
5. Apply LeakyReLU(0.2) to the output of the second linear layer.
6. Pass the result through the third linear layer.
7. Apply LeakyReLU(0.2) to the output of the third linear layer.
8. The final output has a shape of 128 [S1].

## Subtopics

### Global Generator
**Definition:** Maps a single global latent code $z$ to a 2D grid of local latent codes $W$ representing the spatial layout of the scene [S1].
**Steps:**
1. Initialize with a constant input tensor [S1].
2. Apply a $3 \times 3$ modulated convolution conditioned on $z$ [S1].
3. Apply LeakyReLU(0.2) [S1].
4. For subsequent layers, apply pairs of modulated convolutions. Each pair upsamples resolution by $2\times$ using a transposed convolution (stride 2) followed by bilinear filtering [S1].
5. Apply LeakyReLU(0.2) after each convolution [S1].
**Parameters:**
- Output resolution: $32 \times 32$ [S1]. This controls the spatial region size per local latent code [S1].
- Intermediate channels: 256 for early layers, reducing to 32 at the final output [S1].
**When to choose:** Use when spatial variation of latent codes is required, as opposed to a single global code [S1].

**Strengths and Limitations:**
- Global conditioning encodes all sample information in one vector, simplifying the representation but potentially limiting spatial detail compared to local conditioning [S2, unofficial].
- The mapping network adds computational overhead compared to using $z$ directly [S1].
**When to use:** When a single latent code is sufficient to represent the global context of a data sample [S2, unofficial].

## Background
**Origin:** The mapping network architecture is described in "Unconstrained Scene Generation with Locally Conditioned Radiance Fields" [S1]. It builds on StyleGAN's use of a mapping network to map latent codes to an intermediate space [S1][S2, unofficial].
**History:** The concept of global vs. local conditioning is discussed in the context of neural fields [S2, unofficial]. The specific implementation with three linear layers and LeakyReLU(0.2) is detailed in [S1].
