# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data sample into a single latent vector $z$ [S2, unofficial]. It maps this global code to an intermediate non-linear latent space, allowing a shared decoder to interpret instance-specific details [S1]. It differs from local conditioning, which distributes information across multiple latent codes assigned to specific spatio-temporal coordinates [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: Global latent code $z \in \mathbb{R}^D$.
*   Output: Intermediate latent representation (shape 128 for the Mapping Network; spatial grid $W$ for the Global Generator).

**Data Structures:**
*   **Mapping Network:** A sequence of linear transformations.
*   **Global Generator:** A 2D grid of local latent codes $W$.

**Steps (Mapping Network):**
1.  Normalize the input $z$.
2.  Pass through three linear layers.
3.  Apply LeakyReLU(0.2) activation after each linear layer.
4.  The output shape is 128 [S1].

**Steps (Global Generator):**
1.  Initialize with a constant input tensor.
2.  Apply a $3 \times 3$ modulated convolution conditioned on $z$.
3.  Apply LeakyReLU(0.2).
4.  For subsequent layers, apply pairs of modulated convolutions.
5.  Upsample resolution by $2\times$ using a transposed convolution with stride 2, followed by bilinear filtering.
6.  Apply LeakyReLU(0.2) after each convolution.
7.  The output resolution is a hyperparameter, typically $32 \times 32$ [S1].

**Parameters:**
*   Mapping Network: Output dimension 128 [S1].
*   Global Generator: Output spatial resolution $32 \times 32$ [S1].

## Subtopics

### Global Generator
Maps a single global latent code $z$ to a 2D grid of local latent codes $W$ representing the spatial layout of the scene [S1]. It uses successive modulated convolutional layers conditioned on $z$, starting with a constant input and $3 \times 3$ modulated convolutions, followed by upsampling via transposed convolutions and bilinear filtering [S1]. The output resolution (e.g., $32 \times 32$) controls the spatial region size per local latent code [S1].

## Background
Originated in the context of unconstrained scene generation with locally conditioned radiance fields [S1]. The concept of global conditioning contrasts with local conditioning, where information is spread over multiple latent codes [S2, unofficial].
