# Latent Code Conditioning

Also called: Global Conditioning, Local Conditioning, Autoencoder/Autodecoder Conditioning

## Overview
Latent Code Conditioning enables a single Neural Field to represent multiple distinct instances or conditions (such as different volume modalities, dynamic objects, or editing styles) by injecting a low-dimensional latent vector $z$ into the network's evaluation process [S1, unofficial][S2]. It solves the problem of instance-specific variation by providing global or local context alongside local spatial data, allowing the model to distinguish between different samples without retraining the entire architecture [S1, unofficial][S2]. It is distinguished from sibling methods by its fundamental approach to integration: [Concatenation Conditioning](12582-concatenation-conditioning.md) appends the code to inputs, [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md) predicts decoder weights, and [Global Conditioning](12589-global-conditioning.md) uses a dedicated mapping network to transform the code [S2].

## Shared principles
The core mechanism of Latent Code Conditioning involves mapping a data sample to a latent vector $z \in \mathcal{Z}$ and using this vector to modulate the output of a Neural Field $f: (\Omega, \mathcal{Z}) \mapsto \mathcal{X}$, where $\Omega$ is the spatial domain and $\mathcal{X}$ is the output space (e.g., density, color) [S1, unofficial].

**Latent Space and Dimensionality:**
The latent code $z$ is typically a low-dimensional vector. A common dimensionality observed in implementations is 512 [S1, unofficial][S2]. In specific applications like edit code mapping, dimensions such as 64 are used [S4].

**Training Paradigms:**
The latent codes can be acquired through two primary training paradigms:
1.  **Autoencoder:** An encoder network processes the input data to produce the latent code $z$ [S1, unofficial].
2.  **Autodecoder:** The latent code $z$ is treated as a learnable parameter optimized jointly with the decoder weights for each sample [S1, unofficial].

**Conditioning Granularity:**
*   **Global Conditioning:** The entire information of a data sample is encoded into a single latent vector $z$ [S2]. This is the standard approach for instance-specific variation [S2].
*   **Local Conditioning:** Information is spread over multiple latent codes assigned to specific subsets of spatio-temporal coordinates (regions or time steps) [S1, unofficial].
*   **Hybrid Conditioning:** A combination where one global code encodes shared basic information and several local codes encode instance-specific details [S1, unofficial].

**Integration Mechanisms:**
The latent code is integrated into the Neural Field via one of the sibling methods:
*   Concatenation with input features or descriptors [S1, unofficial][S2].
*   Prediction of network weights via a HyperNetwork [S1, unofficial].
*   Transformation via a Mapping Network (Global Conditioning) [S1, unofficial].

## Subtopics

### [Concatenation Conditioning](12582-concatenation-conditioning.md)
Concatenation Conditioning injects latent codes by appending the latent vector $z$ to the input features or descriptors before processing. It is distinguished by its simplicity: it modifies the input tensor directly rather than predicting weights or modulating intermediate features. It is chosen when computational efficiency is prioritized and the condition can be effectively represented as an additive feature to the spatial input or explicit descriptors.

### [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md)
HyperNetwork Conditioning uses a secondary network (the HyperNetwork) to predict the weights of the primary Neural Field decoder from a latent code. Unlike Concatenation Conditioning, which shares decoder parameters across all instances, HyperNetwork Conditioning generates a distinct set of decoder weights for each input instance. This allows the primary network to maintain lower complexity while still representing distinct instances. It is chosen when instance-specific structural variations require distinct network parameters rather than just feature modulation.

### [Global Conditioning](12589-global-conditioning.md)
Global conditioning encodes the entire information of a data sample into a single latent vector $z$, allowing the neural field to distinguish between different instances. It serves as the primary mechanism for instance-specific variation in latent code conditioning, contrasting with local conditioning which distributes information across spatial regions. It is distinct from sibling methods by using a dedicated network (Mapping Network) to transform the raw latent code into a suitable intermediate representation, rather than directly concatenating $z$ or using a HyperNetwork to generate weights.

### Autoencoder/Autodecoder Conditioning
*   **Step:** Train the model in an autoencoder manner (using an encoder to produce latent codes) or an autodecoder manner (optimizing a learnable latent vector per sample jointly with decoder weights) [S1, unofficial].

### Local Conditioning
*   **Definition:** Spreading information about a data sample over multiple latent codes assigned to specific subsets of spatio-temporal coordinates (regions or time steps) [S1, unofficial].

### Dynamic Object Radiance Field Conditioning
*   **Definition:** A radiance field $\psi$ for dynamic objects conditioned by separate shape and appearance latent vectors [S2].
*   **Step:**
    1.  Concatenate a shape code with the input coordinate $x$ at the network input [S2].
    2.  Concatenate an appearance code with the direction $d$ at the bottleneck after density prediction [S2].
    3.  Concatenate sequence and object appearance latent vectors to propagate sequence appearance to individual objects [S2].

### Image Encoding
*   **Definition:** Passes the appearance source image $A$ through a network to generate a latent code, which is then appended to the input voxels [S3].
*   **Comparison:** Captures overall color but fails to assign it correctly to individual parts [S3].

### Edit Code Mapping
*   **Definition:** A process to map each edited 2D image $S_i^j$ into a latent feature vector $z_i^j \in \mathbb{R}^{64}$ named edit code to characterize diverse edits and solve the inconsistency problem in 3D scenes caused by 2D image-to-image translation generating different content for the same target [S4].
*   **Step:**
    1.  Extract feature from edited image $S_i^j$ using an off-the-shelf VAE encoder $\mathcal{E}$ from stable diffusion [30] [S4].
    2.  Apply a tiny MLP network $\mathcal{M}$ to produce the edit code $z_i^j$ [S4].
    3.  Keep the pre-trained encoder fixed and only optimize the parameters of the tiny MLP network during training [S4].
*   **Formula:** $\mathbf {z}_i^j = \mathcal {D}(\mathbf {S}_i^j) = \mathcal {M}(\mathcal {E}(\mathbf {S}_i^j))$, where $\mathcal{D}$ represents the mapping process, $\mathcal{E}$ is the fixed encoder, and $\mathcal{M}$ is the learnable tiny MLP [S4].
*   **Parameter:** Edit code dimension: $\mathbb{R}^{64}$ [S4].

## Background
Latent Code Conditioning originated from the need to extend Neural Fields beyond single-instance representation. Early work demonstrated that conditioning the prediction of a Neural Field on additional variables encoding context allows the representation of many images, either through autoencoder or autodecoder formulations [S1, unofficial]. The concept of "global conditioning" was introduced to describe the practice of providing one latent vector per data sample to encode the whole information about the sample [S1, unofficial]. Subsequent developments introduced "local conditioning" to spread information over multiple latent codes assigned to spatio-temporal coordinates [S1, unofficial]. More recent applications have adapted these principles to dynamic urban environments using separate shape and appearance latent vectors [S2], and to generative NeRF-to-NeRF translation using edit codes derived from 2D image translations [S4].
