# HyperNetwork Conditioning

Also called: HyperNet, Hyper-Decoder

## Overview
HyperNetwork Conditioning generates the parameters (weights) of the Neural Field decoder directly from a latent code $z$ using a secondary network, the HyperNetwork [S1, unofficial]. Unlike Concatenation Conditioning, which shares a single set of decoder weights across all instances and relies on the latent code to modulate features, HyperNetwork Conditioning creates a distinct Neural Field for each input instance [S1, unofficial]. This separation allows the primary decoder network to maintain a lower complexity, resulting in a more compact representation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A latent code vector $z \in \mathbb{R}^D$ encoding global instance information.
- Output: The weight tensors $W_{decoder}$ and bias vectors $b_{decoder}$ for the Neural Field decoder.

**Data Structures:**
- $z$: Latent vector of dimension $D$.
- $H_{hyper}$: The HyperNetwork, typically a Multi-Layer Perceptron (MLP).
- $W_{decoder}$: The weight matrices of the target Neural Field.
- $b_{decoder}$: The bias vectors of the target Neural Field.

**Steps:**
1. Encode the input instance into a latent code $z$. This may be done via an encoder network or optimized during inference [S1, unofficial].
2. Pass $z$ through the HyperNetwork $H_{hyper}$.
   $$ [W_{decoder}, b_{decoder}] = H_{hyper}(z) $$
   The HyperNetwork maps the latent vector to the flattened or structured parameters of the decoder.
3. Use the generated parameters $W_{decoder}, b_{decoder}$ to evaluate the Neural Field at query coordinates $x$.
   $$ y = f_{W_{decoder}, b_{decoder}}(x) $$

**Parameters:**
- $D$: Latent dimension. Typically 512, though smaller dimensions like 64 or 256 are used in specific applications [S1, unofficial].
- HyperNetwork Depth/Width: Not given in the sources.

**Edge Cases and Pitfalls:**
- The HyperNetwork must be capable of generating valid weights for the decoder. Degenerate outputs (e.g., exploding gradients in generated weights) can destabilize training [G].
- The size of the HyperNetwork's output must exactly match the parameter count of the decoder.

## Subtopics

### Hybrid Conditioning
Hybrid Conditioning combines global and local latent codes. It uses one global code to encode basic information shared between instances and several local codes to encode instance-specific details assigned to subsets of spatio-temporal coordinates [S1, unofficial]. This approach allows for both instance-level variation and local detail modulation within the same framework.

## Operating characteristics
- **Complexity:** The primary Neural Field decoder can be significantly smaller and less complex than in concatenation-based methods because it does not need to encode instance-specific variations internally [S1, unofficial].
- **Memory:** Requires storing the HyperNetwork parameters in addition to the decoder parameters. The decoder weights are generated per-instance, so they are not shared across all queries in the same way as fixed weights, but the decoder itself is smaller.
- **Performance:** Not given in the sources.
- **Strengths:** Enables distinct Neural Fields per instance; reduces decoder complexity.
- **Limitations:** Requires training the HyperNetwork; generation of weights adds computational overhead during inference compared to fixed weights.

## Background
The concept of HyperNetworks was introduced by Ha et al. in 2016 [S1, unofficial]. In the context of Neural Fields, it was highlighted as a method to allow each layer or neuron to utilize the condition by predicting decoder parameters from the latent code [S1, unofficial]. Recent research suggests this approach hints at a more compact representation due to the reduced complexity of the primary network [S1, unofficial].
