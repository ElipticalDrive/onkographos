# Conditional Radiance Field Training

Also called: Conditional NeRF, Instance-conditioned NeRF

## Overview
Conditional Radiance Field Training is a method for modeling shape and appearance variations across multiple 3D instances by training a single neural radiance field conditioned on per-instance latent codes [S1]. It solves the problem of efficiently representing a dataset of objects with varying geometry and texture without training separate models for each instance, matching the reconstruction accuracy of independent NeRFs while sharing a common network backbone [S1]. It differs from sibling methods like [Conditional Radiance Field with Shared Branch](15964-conditional-radiance-field-with-shared-branch.md) by explicitly decoupling shape and color codes and injecting them into the embedding layers, whereas the sibling method typically shares the branch earlier in the network [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset of $K$ object instances. For each instance $k$, a set of training rays $R_k$ with corresponding ground truth colors $C(r)$.
*   **Outputs:** A conditional radiance field model consisting of two networks ($F_{coarse}, F_{fine}$) and learned per-instance codes ($z_k^{(s)}, z_k^{(c)}$).

**Data Structures:**
*   **Shape Code ($z_k^{(s)}$):** A 32-dimensional learned vector for instance $k$.
*   **Color Code ($z_k^{(c)}$):** A 32-dimensional learned vector for instance $k$.
*   **Networks:** Two Multi-Layer Perceptrons (MLPs), $F_{coarse}$ and $F_{fine}$.
    *   Depth: 4 layers.
    *   Width: 256 channels.
    *   Activation: ReLU.
    *   Architecture: Uses skip connections from the input position/direction embeddings to the output layers, similar to the original NeRF [S1].
    *   $F_{coarse}$: Outputs density $\sigma$ and color $C$.
    *   $F_{fine}$: Outputs color $C$ (uses density from $F_{coarse}$ for sampling).

**Numbered Steps:**
1.  **Initialization:** Initialize $F_{coarse}$, $F_{fine}$, and the set of $K$ shape codes $\{z_k^{(s)}\}_{k=1}^K$ and color codes $\{z_k^{(c)}\}_{k=1}^K$.
2.  **Instance Sampling:** For each training iteration, sample an object instance index $k$ uniformly from $\{1, \dots, K\}$ [S1].
3.  **Code Retrieval:** Retrieve the shape code $z_k^{(s)}$ and color code $z_k^{(c)}$ for the sampled instance [S1].
4.  **Ray Sampling:** Sample a batch of training rays $R_k$ from the set of all rays belonging to instance $k$ [S1].
5.  **Coarse Network Forward Pass:**
    *   For each ray $r \in R_k$, sample points using stratified sampling.
    *   Inject $z_k^{(s)}$ and $z_k^{(c)}$ wherever positional or directional embeddings are injected in the original NeRF model (concatenated with embedded coordinates) [S1].
    *   Pass the embedded inputs through $F_{coarse}$ to estimate density and color.
6.  **Hierarchical Sampling:** Use the density outputs from $F_{coarse}$ to sample a hierarchical volume of points for the fine network [S1].
7.  **Fine Network Forward Pass:**
    *   Inject $z_k^{(s)}$ and $z_k^{(c)}$ into the embeddings for the fine network inputs.
    *   Pass the embedded inputs through $F_{fine}$ to render the final color.
8.  **Loss Calculation:** Compute the photometric loss using the sum of squared Euclidean distances between predicted and ground truth colors for both coarse and fine networks [S1].
9.  **Optimization:** Update the network parameters and the codes $z_k^{(s)}, z_k^{(c)}$ using the Adam optimizer [S1].

**Formulas:**
The training loss $L_{train}$ is defined as [S1]:

$$
L_{train} = \sum_{k=1}^{K} \sum_{r \in R_k} \left( \left\| \hat{C}_{coarse}(r, z_k^{(s)}, z_k^{(c)}) - C(r) \right\|_2^2 + \left\| \hat{C}_{fine}(r, z_k^{(s)}, z_k^{(c)}) - C(r) \right\|_2^2 \right)
$$

Where:
*   $K$ is the total number of instances.
*   $R_k$ is the set of training rays for instance $k$.
*   $\hat{C}_{coarse}$ and $\hat{C}_{fine}$ are the predicted colors from the coarse and fine networks, respectively.
*   $C(r)$ is the ground truth color for ray $r$.
*   $z_k^{(s)}$ and $z_k^{(c)}$ are the shape and color codes for instance $k$.

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $10^{-4}$ for training [S1].
*   **Beta1:** 0.9 [S1].
*   **Beta2:** 0.999 [S1].
*   **Epsilon:** $10^{-8}$ [S1].
*   **Training Duration:** Until convergence, averaging around 1 million iterations [S1].
*   **Code Dimension:** 32 dimensions for both shape and color codes [S1]. (Note: An ablation used a 64-dimensional code, but the final method uses 32 [S1]).

**Edge Cases and Pitfalls:**
*   **Parameter Count:** In ablation studies, layer widths were increased to keep the number of parameters approximately equal across experiments, ensuring fair comparison [S1].
*   **Editing vs. Training:** During editing, the coarse network is kept fixed, and only the fine network and codes are optimized with a higher learning rate ($10^{-2}$) for 100 iterations [S1].
*   **Regularization:** Without regularization, the model may exhibit inconsistent color across views for the same instance; regularization techniques (e.g., viewing direction consistency) are required for single-view training scenarios [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.optim as optim

class ConditionalNeRF:
    def __init__(self, num_instances, code_dim=32, hidden_dim=256, num_layers=4):
        """
        Initialize the Conditional NeRF model.
        
        Args:
            num_instances (int): Total number of instances K.
            code_dim (int): Dimensionality of shape and color codes (default 32).
            hidden_dim (int): Width of MLP layers (default 256).
            num_layers (int): Depth of MLPs (default 4).
        """
        self.K = num_instances
        self.code_dim = code_dim
        
        # Learnable per-instance codes
        # Shape codes: (K, code_dim)
        self.shape_codes = nn.Parameter(torch.randn(num_instances, code_dim))
        # Color codes: (K, code_dim)
        self.color_codes = nn.Parameter(torch.randn(num_instances, code_dim))
        
        # Two MLPs: Coarse and Fine
        # Both have 4 layers, 256 channels, ReLU activation
        self.F_coarse = self._build_mlp(hidden_dim, num_layers)
        self.F_fine = self._build_mlp(hidden_dim, num_layers)
        
        # Optimizer for training
        self.optimizer = optim.Adam(
            list(self.F_coarse.parameters()) + 
            list(self.F_fine.parameters()) + 
            [self.shape_codes, self.color_codes],
            lr=1e-4,
            betas=(0.9, 0.999),
            eps=1e-8
        )

    def _build_mlp(self, hidden_dim, num_layers):
        """Build a 4-layer MLP with skip connections."""
        layers = []
        for i in range(num_layers):
            in_dim = hidden_dim if i > 0 else hidden_dim + 2 * self.code_dim # Input includes embeddings + codes
            out_dim = hidden_dim
            layers.append(nn.Linear(in_dim, out_dim))
            layers.append(nn.ReLU())
        return nn.Sequential(*layers)

    def _inject_codes(self, pos_embed, dir_embed, z_s, z_c):
        """
        Inject shape and color codes into positional and directional embeddings.
        Concatenates codes to the embeddings as per the original NeRF injection strategy.
        """
        # pos_embed: (N, D_pos), dir_embed: (N, D_dir)
        # z_s: (1, code_dim), z_c: (1, code_dim)
        # Broadcast codes to match batch size N
        z_s = z_s.unsqueeze(0).expand(pos_embed.size(0), -1)
        z_c = z_c.unsqueeze(0).expand(pos_embed.size(0), -1)
        
        # Concatenate codes to embeddings
        # Note: Exact injection point (pos vs dir) is described as "wherever positional or directional embeddings are injected"
        # We assume concatenation to both for generality, or specifically to position for shape and direction for color.
        # Based on "separate shape and color codes", we inject z_s to pos and z_c to dir.
        combined_pos = torch.cat([pos_embed, z_s], dim=-1)
        combined_dir = torch.cat([dir_embed, z_c], dim=-1)
        return combined_pos, combined_dir

    def forward_coarse(self, pos_embed, dir_embed, z_s, z_c):
        """Forward pass for the coarse network."""
        combined_pos, combined_dir = self._inject_codes(pos_embed, dir_embed, z_s, z_c)
        # Concatenate pos and dir for MLP input
        input_tensor = torch.cat([combined_pos, combined_dir], dim=-1)
        return self.F_coarse(input_tensor)

    def forward_fine(self, pos_embed, dir_embed, z_s, z_c):
        """Forward pass for the fine network."""
        combined_pos, combined_dir = self._inject_codes(pos_embed, dir_embed, z_s, z_c)
        input_tensor = torch.cat([combined_pos, combined_dir], dim=-1)
        return self.F_fine(input_tensor)

    def train_step(self, rays, ground_truth_colors):
        """
        Perform one training iteration.
        
        Args:
            rays: Dictionary containing 'pos', 'dir', 'instance_idx' for a batch of rays.
            ground_truth_colors: Tensor of shape (batch_size, 3) with target RGB values.
        """
        self.optimizer.zero_grad()
        
        # 1. Sample instance k
        # rays['instance_idx'] contains the instance index for each ray in the batch
        # We assume the batch is already sampled from a single instance k for the loss calculation
        # Or we handle multiple instances in the batch. The formula sums over k and R_k.
        # For simplicity, assume batch corresponds to a single instance k for this step,
        # or iterate over unique instances in the batch.
        
        unique_instances = torch.unique(rays['instance_idx'])
        total_loss = 0.0
        
        for k in unique_instances:
            # 2. Get codes for instance k
            z_s = self.shape_codes[k] # Shape: (code_dim,)
            z_c = self.color_codes[k] # Shape: (code_dim,)
            
            # 3. Get rays for instance k
            mask = rays['instance_idx'] == k
            pos_embed = rays['pos'][mask]
            dir_embed = rays['dir'][mask]
            gt_colors = ground_truth_colors[mask]
            
            if pos_embed.numel() == 0:
                continue

            # 4. Coarse Network
            # Stratified sampling is handled by the ray generation step, 
            # producing pos_embed and dir_embed for points along the ray.
            coarse_out = self.forward_coarse(pos_embed, dir_embed, z_s, z_c)
            # Assume coarse_out contains color prediction C_coarse
            C_coarse = coarse_out[:, :3] # Assuming first 3 channels are color
            
            # 5. Fine Network
            # Hierarchical sampling uses coarse density. 
            # For this pseudocode, we assume pos_embed for fine network is already sampled hierarchically.
            fine_out = self.forward_fine(pos_embed, dir_embed, z_s, z_c)
            C_fine = fine_out[:, :3]
            
            # 6. Loss Calculation
            loss_coarse = torch.mean((C_coarse - gt_colors) ** 2)
            loss_fine = torch.mean((C_fine - gt_colors) ** 2)
            
            total_loss += loss_coarse + loss_fine
            
        # 7. Backpropagation
        total_loss.backward()
        self.optimizer.step()
        
        return total_loss.item()
```

## Subtopics

### Conditional Radiance Field with Shared Branch
A variant where the shape and color information is processed through a shared branch earlier in the network, rather than injecting separate codes into the embedding layers. Choose this when memory is constrained and shape/appearance are highly correlated. See [Conditional Radiance Field with Shared Branch](15964-conditional-radiance-field-with-shared-branch.md).

## Operating characteristics
*   **Time Complexity:** Training time is proportional to the number of instances $K$ and the number of iterations (approx. 1M) [S1]. Each iteration involves forward passes through two MLPs for a batch of rays.
*   **Memory Complexity:** Memory usage scales with $K \times \text{code\_dim}$ for the codes, plus the memory for the two MLPs ($F_{coarse}, F_{fine}$) [S1].
*   **Measured Performance:** On the PhotoShapes dataset, the method matches the performance of training independent NeRF models for each instance in terms of PSNR and LPIPS [S1].
*   **Scalability:** The method scales well to more training instances; training with all 626 instances of the PhotoShape dataset achieves reconstruction comparable to independent models [S1].
*   **Strengths:** Efficiently models shape and appearance differences across instances; avoids training separate models; generalizes to unseen views.
*   **Limitations:** Requires a dataset with multiple instances; performance depends on the quality of the learned codes; editing requires careful learning rate adjustment [S1].

## Background
Conditional Radiance Field Training was introduced in the paper "Editing Conditional Radiance Fields" [S1]. It builds upon the original NeRF architecture [45] and extends it to handle multiple instances by introducing per-instance latent codes. The method was evaluated on the PhotoShapes and Aubry chairs datasets [S1]. It addresses the limitation of standard NeRF, which models a single scene, by enabling the representation of a family of objects with shared structural priors but varying details.
