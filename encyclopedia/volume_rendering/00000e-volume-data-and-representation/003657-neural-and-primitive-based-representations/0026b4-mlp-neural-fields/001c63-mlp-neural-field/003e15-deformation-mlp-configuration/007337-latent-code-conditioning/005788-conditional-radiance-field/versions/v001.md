# Conditional Radiance Field

Also called: Auto-decoder NeRF, Prior Learning, category-level NeRF

## Overview
A Conditional Radiance Field extends the standard NeRF representation to model an entire object class (e.g., chairs) rather than a single static scene, using instance-specific latent vectors for shape and appearance to enable editing and interpolation [S1, S2]. It differs from standard NeRF by decoupling instance-specific details into latent codes $z$ while storing shared class information in the network parameters, allowing the radiance field characteristics to be altered via latent variable manipulation [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A 3D location $\mathbf{x} = (x, y, z)$, a viewing direction $\mathbf{d} = (\phi, \theta)$, and instance-specific latent vectors $\mathbf{z}^{(s)}$ (shape) and $\mathbf{z}^{(c)}$ (color/appearance) [S1]. Optionally, an input image $I$ is encoded into a latent code $\mathbf{z}$ via an encoder $E$ [S2].
*   **Outputs:** Radiance $\mathbf{c} = (r, g, b)$ and scalar density $\sigma$ [S1].

**Data Structures:**
*   **Network $F$:** A multi-layer perceptron (MLP) parametrized by $\Theta$ [S1].
*   **Latent Codes:** $\mathbf{z}^{(s)}$ and $\mathbf{z}^{(c)}$ are vectors encapsulating higher-level semantic characteristics such as shape, type, size, and color [S2].

**Steps:**
1.  **Latent Code Generation (Optional):** If conditioning on an input image $I$, generate the latent code $\mathbf{z} = E(I)$ using an encoder network $E$ [S2].
2.  **Ray Sampling:** For a desired camera location, cast a ray $r$ from a pixel location. Sample $N_c$ 3D points $\{t_i\}_{i=1}^{N_c}$ along the ray, ordered from near to far [S1].
3.  **Field Evaluation:** Compute radiance $\mathbf{c}_i$ and density $\sigma_i$ at each sampled point $t_i$ using the conditional network:
    $$
    (\mathbf{c}_i, \sigma_i) = F_\Theta(\mathbf{x}_i, \mathbf{d}_i, \mathbf{z}^{(s)}, \mathbf{z}^{(c)})
    $$
    where $\mathbf{x}_i$ is the position $t_i$ and $\mathbf{d}_i$ is the viewing direction [S1, S2]. The density output $\sigma$ is designed to be independent of the viewing direction, while radiance $\mathbf{c}$ depends on both position and direction [S1].
4.  **Alpha Compositing:** Compute the pixel color $\hat{C}$ using the "over" compositing operation [S1]:
    $$
    \hat{C}(r, \mathbf{z}^{(s)}, \mathbf{z}^{(c)}) = \sum_{i=1}^{N_c} \mathbf{c}_i \alpha_i \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)
    $$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the alpha compositing value and $\delta_i = t_{i+1} - t_i$ is the distance between adjacent sampled points [S1].

**Pseudocode:**
```python
def conditional_radiance_field_eval(x, d, z_shape, z_color, network_F):
    """
    Evaluates the conditional radiance field for a single point.
    
    Args:
        x: 3D location vector (x, y, z).
        d: Viewing direction vector (phi, theta).
        z_shape: Latent shape vector.
        z_color: Latent color/appearance vector.
        network_F: The MLP model F_Theta.
        
    Returns:
        c: Radiance vector (r, g, b).
        sigma: Scalar density.
    """
    # The network F takes x, d, z(s), z(c) and returns c and sigma.
    # Density sigma is independent of viewing direction d.
    # Radiance c depends on both position x and viewing direction d.
    c, sigma = network_F(x, d, z_shape, z_color)
    return c, sigma

def render_conditional_ray(ray_origin, ray_direction, z_shape, z_color, network_F, num_samples=128):
    """
    Renders a single pixel using conditional volume rendering.
    
    Args:
        ray_origin: Origin of the ray.
        ray_direction: Direction of the ray.
        z_shape: Latent shape vector for the instance.
        z_color: Latent color vector for the instance.
        network_F: The MLP model F_Theta.
        num_samples: Number of points Nc to sample along the ray.
        
    Returns:
        pixel_color: The computed color C_hat.
    """
    # 1. Sample Nc 3D points {ti} along the cast ray r, ordered near to far.
    # [G] Assuming a standard sampling strategy (e.g., uniform or stratified)
    # between near and far bounds along the ray direction.
    t_values = sample_along_ray(ray_origin, ray_direction, num_samples)
    
    pixel_color = [0.0, 0.0, 0.0]
    accumulated_transmittance = 1.0
    
    for i in range(num_samples):
        t_i = t_values[i]
        t_next = t_values[i+1] if i + 1 < num_samples else t_i + 0.01 # [G] Default step if not defined
        
        # Position x_i and direction d_i
        x_i = ray_origin + t_i * ray_direction
        d_i = ray_direction
        
        # 2. Compute radiance ci and density sigmai using network F
        c_i, sigma_i = conditional_radiance_field_eval(x_i, d_i, z_shape, z_color, network_F)
        
        # 3. Compute alpha and delta
        delta_i = t_next - t_i
        alpha_i = 1.0 - math.exp(-sigma_i * delta_i)
        
        # 4. Compositing
        # Weighted sum: ci * alpha_i * exp(-sum(sigma_j * delta_j))
        # accumulated_transmittance holds exp(-sum(sigma_j * delta_j))
        contribution = c_i * alpha_i * accumulated_transmittance
        pixel_color += contribution
        
        # Update transmittance for next sample
        accumulated_transmittance *= (1.0 - alpha_i)
        
    return pixel_color
```

**Parameters:**
*   $N_c$: Number of sampled points along the ray. Not given in the sources.
*   $\mathbf{x}$: 3D location vector $(x, y, z)$ [S1].
*   $\mathbf{d}$: Viewing direction vector $(\phi, \theta)$ [S1].
*   $\mathbf{z}^{(s)}$: Latent shape vector [S1].
*   $\mathbf{z}^{(c)}$: Latent color (appearance) vector [S1].
*   $\mathbf{z}$: Latent variable encapsulating higher-level semantic characteristics (shape, type, size, color, text/audio embeddings) [S2].

**Edge Cases and Pitfalls:**
*   **Disentanglement:** The density output $\sigma$ must be independent of the viewing direction $\mathbf{d}$, while radiance $\mathbf{c}$ depends on both $\mathbf{x}$ and $\mathbf{d}$ [S1]. Architectural separation or deformation networks are used to ensure this [S1].
*   **Editing:** The disentanglement of shape and appearance allows modifying certain parts of the network during editing (e.g., updating only shape code $\mathbf{z}^{(s)}$ or only color code $\mathbf{z}^{(c)}$) [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of sampled points $N_c$ and the depth of the MLP $F$. Not given in the sources.
*   **Memory Complexity:** Requires storing the latent codes $\mathbf{z}^{(s)}$ and $\mathbf{z}^{(c)}$ for each instance, in addition to the network parameters $\Theta$. Not given in the sources.
*   **Strengths:** Enables editing and interpolation of an entire object class by manipulating latent variables mapped to a semantic or smoothly varying space [S2]. Allows instance-specific details to be encoded in $z$ while shared information is stored in network parameters [S2].
*   **Limitations:** Requires training over a set of shapes belonging to a class [S1]. The quality of editing depends on the disentanglement of shape and appearance [S1].
*   **When to use:** When the goal is to model a category of objects (e.g., chairs) and enable editing or interpolation of shape and appearance [S1, S2].
*   **When not to use:** When modeling a single, static scene without the need for instance-specific editing or class-level generalization [S1].

## Background
*   **Origin:** The Conditional Radiance Field was introduced in "Editing Conditional Radiance Fields" (ICCV 2021) [S1].
*   **History:** It builds upon the neural radiance field (NeRF) representation [45] to enable editing over an entire shape class, such as "chairs" [S1].
*   **Usage:** Used in applications requiring category-level 3D understanding, editing, and interpolation, leveraging semantic richness from image feature spaces [S2].
