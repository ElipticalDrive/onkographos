# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data sample into a single latent vector $z$, which is then used to condition a shared neural field decoder [S2, unofficial]. It serves as the foundational mechanism for instance association in neural field representations, distinguishing itself from local conditioning methods that distribute latent codes across spatial or temporal coordinates [S2, unofficial]. It is typically implemented via a mapping network that transforms the raw latent code into an intermediate non-linear latent space [S1].

## How it works
**Inputs and Outputs:**
- Input: A global latent code $z \in \mathbb{R}^D$.
- Output: A transformed latent representation $z'$ used to condition the decoder.

**Data Structures:**
The mapping network is a multi-layer perceptron (MLP) consisting of normalization and linear layers.

**Steps:**
1.  **Normalization**: Normalize the input vector $z$. The specific normalization technique (e.g., LayerNorm) is not detailed in the primary source, but it is a required step before the linear layers [S1].
2.  **Linear Transformation 1**: Apply a linear layer to the normalized $z$.
3.  **Activation 1**: Apply LeakyReLU with negative slope 0.2 to the output of the first linear layer [S1].
4.  **Linear Transformation 2**: Apply a second linear layer.
5.  **Activation 2**: Apply LeakyReLU(0.2) [S1].
6.  **Linear Transformation 3**: Apply a third linear layer.
7.  **Activation 3**: Apply LeakyReLU(0.2) [S1].

**Parameters:**
-   Output dimension of each linear layer: 128 [S1].
-   Activation function: LeakyReLU with slope 0.2 [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class MappingNetwork(nn.Module):
    def __init__(self, latent_dim: int):
        super().__init__()
        # Note: The specific normalization layer type is not specified in [S1].
        # We assume a standard LayerNorm for implementation completeness [G].
        self.norm = nn.LayerNorm(latent_dim)
        self.linear1 = nn.Linear(latent_dim, 128)
        self.linear2 = nn.Linear(128, 128)
        self.linear3 = nn.Linear(128, 128)
        self.leaky_relu = nn.LeakyReLU(negative_slope=0.2)

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        # Step 1: Normalize
        z = self.norm(z)
        # Step 2-3: Linear + Activation
        z = self.leaky_relu(self.linear1(z))
        # Step 4-5: Linear + Activation
        z = self.leaky_relu(self.linear2(z))
        # Step 6-7: Linear + Activation
        z = self.leaky_relu(self.linear3(z))
        return z
```

## Subtopics

### Global Generator
A variant that maps a single global latent code $z$ to a 2D grid of local latent codes $W$, representing the spatial layout of the scene [S1]. It is chosen when the scene requires spatially varying local details rather than a single global context [S1].
-   **Definition**: Maps $z$ to a grid $W$ of local latent codes [S1].
-   **Steps**:
    1.  Initialize with a constant input tensor [S1].
    2.  Apply a $3 \times 3$ modulated convolutional layer conditioned on $z$ [S1].
    3.  Apply LeakyReLU(0.2) [S1].
    4.  For subsequent layers, upsample resolution by $2\times$ using a transposed convolution with stride 2, followed by bilinear filtering [S1].
    5.  Apply a $3 \times 3$ modulated convolutional layer conditioned on $z$ [S1].
    6.  Apply LeakyReLU(0.2) [S1].
    7.  Repeat steps 4-6 until the target resolution is reached [S1].
-   **Parameters**:
    -   Output resolution of $W$: $32 \times 32$ [S1]. This controls the spatial region size represented by each local latent code [S1].
    -   Intermediate feature map channels: 256 for resolutions $4\times4$ to $16\times16$, and 32 for the final $32\times32$ output [S1].

## Operating characteristics
Global conditioning is computationally efficient in terms of memory per instance compared to storing large local grids, as it only requires one vector $z$ per sample [S2, unofficial]. However, it may lack the capacity to model highly localized, instance-specific geometric details compared to local conditioning methods [S2, unofficial]. The mapping network adds negligible computational overhead during inference [S1].

## Background
Global conditioning was introduced in the context of unconstrained scene generation with locally conditioned radiance fields [S1]. It builds on the concept of mapping networks used in StyleGAN [S1][S2, unofficial], where a latent code is mapped to an intermediate space to improve training stability and representational power [S1]. The term "global" distinguishes it from "local" conditioning, where latent codes are assigned to specific spatial regions [S2, unofficial].
