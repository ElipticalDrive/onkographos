# Conditional Radiance Field with Shared Branch

Also called: CRF with Shared Branch, Modular Conditional Radiance Field

## Overview
The Conditional Radiance Field with Shared Branch is a neural radiance field architecture designed for shape and color disentanglement, enabling efficient instance-specific editing by allowing specific submodules to be fine-tuned independently [S1]. It differs from standard NeRF  and other conditional variants by explicitly separating the geometric representation into a shared category-specific backbone and instance-specific deviations, whereas siblings like [DoF-NeRF](9432-dof-nerf.md) focus on depth-of-field or [NeRF-VPT](11770-nerf-vpt.md) on view-point transformations without this specific modular shape/color split.

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D position $\mathbf{x}$, viewing direction $\mathbf{d}$, instance-specific shape code $\mathbf{z}^{(s)}$, and instance-specific color code $\mathbf{z}^{(c)}$.
*   **Outputs:** Scalar volume density $\sigma$ and radiance (color) $\mathbf{c}$.

**Data Structures:**
*   **Positional Encoding:** $\gamma(\mathbf{x})$ and $\gamma(\mathbf{d})$ follow the standard NeRF definition .
*   **Latent Codes:** $\mathbf{z}^{(s)} \in \mathbb{R}^{32}$ and $\mathbf{z}^{(c)} \in \mathbb{R}^{32}$ [S1].
*   **Network Components:** All MLPs ($F_{share}, F_{inst}, F_{fuse}, F_{dens}, F_{rad}$) are 4-layer deep, 256-channel wide, with ReLU activations, outputting 256-dimensional features [S1]. $F_{dens}$ is a linear layer mapping 256-dim features to scalar $\sigma$ [S1].

**Steps:**
1.  **Shared Shape Representation:** Compute the shared geometric feature $\mathbf{h}_{share}$ by passing the positional encoding of the position through the shared shape network:
    $$ \mathbf{h}_{share} = F_{share}(\gamma(\mathbf{x})) $$
2.  **Instance-Specific Shape Representation:** Concatenate the shape code $\mathbf{z}^{(s)}$ with the positional encoding $\gamma(\mathbf{x})$ and pass through the instance-specific shape network:
    $$ \mathbf{h}_{inst} = F_{inst}([\mathbf{z}^{(s)}, \gamma(\mathbf{x})]) $$
3.  **Fusion:** Add the shared and instance-specific features and pass through the fusion network:
    $$ \mathbf{h}_{fuse} = F_{fuse}(\mathbf{h}_{share} + \mathbf{h}_{inst}) $$
4.  **Density Prediction:** Pass the fused feature through the density network to obtain scalar density:
    $$ \sigma = F_{dens}(\mathbf{h}_{fuse}) $$
5.  **Radiance Prediction:** Concatenate the fused feature $\mathbf{h}_{fuse}$, the color code $\mathbf{z}^{(c)}$, and the encoded viewing direction $\gamma(\mathbf{d})$. Pass this concatenation through the radiance network:
    $$ \mathbf{c} = F_{rad}([\mathbf{h}_{fuse}, \mathbf{z}^{(c)}, \gamma(\mathbf{d})]) $$

**Parameters:**
*   Shape and color code dimension: 32 [S1].
*   MLP depth: 4 layers for $F_{share}, F_{inst}, F_{fuse}$ [S1].
*   MLP width: 256 channels [S1].
*   Feature dimension: 256 [S1].
*   Optimizer: Adam [S1].
*   Training learning rate: $10^{-4}$ [S1].
*   Edit learning rate: $10^{-2}$ [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SharedBranchCRF(nn.Module):
    def __init__(self, dim_position=3, dim_direction=3, dim_code=32, width=256, depth=4):
        super().__init__()
        # F_share: 4 layers, 256 width, ReLU
        self.F_share = self._build_mlp(dim_position, width, depth)
        # F_inst: 4 layers, 256 width, ReLU, input dim = dim_code + dim_position
        self.F_inst = self._build_mlp(dim_code + dim_position, width, depth)
        # F_fuse: 4 layers, 256 width, ReLU, input dim = width
        self.F_fuse = self._build_mlp(width, width, depth)
        # F_dens: Linear layer, input dim = width, output dim = 1
        self.F_dens = nn.Linear(width, 1)
        # F_rad: 2-layer MLP (as per source [S1] "two-layer MLP"), input dim = width + dim_code + dim_direction
        # Note: Source says F_share/inst/fuse are 4 layers. F_rad is specified as two-layer.
        self.F_rad = self._build_mlp(width + dim_code + dim_direction, width, 2)
        
        self.dim_position = dim_position
        self.dim_direction = dim_direction
        self.dim_code = dim_code

    def _build_mlp(self, input_dim, hidden_dim, num_layers):
        layers = []
        for i in range(num_layers):
            in_dim = input_dim if i == 0 else hidden_dim
            layers.append(nn.Linear(in_dim, hidden_dim))
            if i < num_layers - 1:
                layers.append(nn.ReLU())
        return nn.Sequential(*layers)

    def forward(self, x, d, z_s, z_c):
        """
        x: (N, 3) position
        d: (N, 3) view direction
        z_s: (N, 32) shape code
        z_c: (N, 32) color code
        """
        # 1. Shared shape representation
        # gamma(x) is assumed to be handled by the positional encoding layer 
        # or passed as pre-encoded x. Here we assume x is pre-encoded or 
        # the network expects raw coordinates. Standard NeRF uses positional encoding.
        # For implementation completeness, we assume x and d are raw coordinates 
        # and apply positional encoding if not already done. 
        # However, the pseudocode must be self-contained. We will assume 
        # positional encoding is applied externally or the input 'x' is already gamma(x).
        # Given the constraint "no placeholders", we assume x and d are the 
        # positional encoded vectors as per the parent article's definition of inputs.
        
        h_share = self.F_share(x)
        
        # 2. Instance-specific shape representation
        z_s_expanded = z_s.unsqueeze(1) if z_s.dim() == 2 else z_s
        # Concatenate z_s and x
        x_inst_input = torch.cat([z_s, x], dim=-1)
        h_inst = self.F_inst(x_inst_input)
        
        # 3. Fuse representations
        h_fuse_input = h_share + h_inst
        h_fuse = self.F_fuse(h_fuse_input)
        
        # 4. Predict density
        sigma = self.F_dens(h_fuse).squeeze(-1)
        
        # 5. Predict radiance
        # Concatenate h_fuse, z_c, and d
        rad_input = torch.cat([h_fuse, z_c, d], dim=-1)
        c = self.F_rad(rad_input)
        
        return sigma, c
```

**Edge Cases and Pitfalls:**
*   **Code Initialization:** The latent codes $\mathbf{z}^{(s)}$ and $\mathbf{z}^{(c)}$ are jointly optimized with the network parameters [S1]. They must be initialized appropriately (e.g., random normal) and treated as learnable parameters per instance [G].
*   **Caching:** During optimization, the set of training rays is small, allowing caching of intermediate representations to accelerate editing [S1].

## Subtopics

### Editing via Modular Updates
This method allows for efficient editing by optimizing only a subset of network components (e.g., $\mathbf{z}^{(s)}$ for shape, $\mathbf{z}^{(c)}$ for color) rather than the entire network [S1]. See [Conditional Radiance Field Training](15963-conditional-radiance-field-training.md) for training procedures.

### Comparison to Non-Shared Branch
The shared branch improves PSNR from 33.91 to 35.79 on the PhotoShapes dataset compared to a model without the shared shape branch [S1].

## Operating characteristics
*   **Performance:** Achieves a PSNR of 35.79 on the PhotoShapes dataset, outperforming models without the shared branch (33.91 PSNR) and even single-instance NeRF models [S1].
*   **Efficiency:** Accelerates color edits by $3.2\times$ and shape edits by $1.9\times$ compared to non-modular approaches by avoiding unnecessary computation during optimization [S1].
*   **Scalability:** The shared shape branch helps the model scale to more instances by learning a category-specific geometric representation [S1].
*   **Complexity:** Time complexity is dominated by the forward pass through the MLPs. Memory complexity includes storing the latent codes per instance [S1].

## Background
The method was introduced in "Editing Conditional Radiance Fields" [S1]. It builds on the standard NeRF architecture  and Mildenhall et al.'s training procedures [S1]. The work focuses on disentangling shape and color to facilitate editing, addressing limitations in standard NeRF where shape and color are entangled in the latent features [S1].
