# HyperNetwork Conditioning

Also called: Hypernetwork-based conditioning, HyperNet conditioning

## Overview
HyperNetwork Conditioning extends the standard Neural Field mapping by using a secondary network (the HyperNetwork) to predict the weights of the primary Neural Field decoder from a latent code [S1, unofficial]. Unlike Concatenation Conditioning, which shares decoder parameters across all instances and relies on the latent code to distinguish them, HyperNetwork Conditioning generates a distinct set of decoder weights for each input instance [S1, unofficial]. This allows the primary network to maintain lower complexity while still representing distinct instances [S1, unofficial].

## How it works
**Inputs:**
1.  Spatial input coordinates $x \in \Omega$ (e.g., 3D position).
2.  Latent code $z \in \mathcal{Z}$ (low-dimensional vector, e.g., length 512) [S1, unofficial].

**Outputs:**
1.  Field value $y \in \mathcal{X}$ (e.g., density, color).

**Data Structures:**
*   **HyperNetwork ($H$):** A neural network with parameters $\theta_H$. It takes $z$ as input and outputs the weight vectors $W$ and biases $b$ of the decoder.
*   **Decoder ($D$):** The Neural Field itself, defined by weights $W$ and biases $b$ predicted by $H$. It takes $x$ as input.

**Steps:**
1.  Encode or retrieve the latent code $z$ for the specific instance.
2.  Pass $z$ through the HyperNetwork $H$ to generate the decoder parameters:
    $$ (W, b) = H(z; \theta_H) $$
    The output $(W, b)$ constitutes the specific weights for the decoder corresponding to instance $z$.
3.  Evaluate the decoder $D$ using the generated parameters and the spatial input $x$:
    $$ y = D(x; W, b) $$
    This involves standard neural network forward propagation using the dynamically generated weights.

**Parameters:**
*   Latent code dimension: Typically 512 [S1, unofficial].
*   HyperNetwork architecture: Not specified in sources [G].
*   Decoder architecture: Not specified in sources [G].

**Edge Cases and Pitfalls:**
*   **Precision:** Generating weights dynamically requires careful handling of numerical stability during the forward pass of the decoder, as weights are not fixed constants [G].
*   **Complexity:** While the decoder can be simpler, the total parameter count includes both the HyperNetwork and the Decoder [S1, unofficial].

## Subtopics

### Hybrid Conditioning
Hybrid Conditioning combines global and local latent codes. It uses one global code to encode basic information shared between instances and several local codes to encode instance-specific details [S1, unofficial]. This approach allows for the assignment of latent codes to specific subsets of spatio-temporal coordinates [S1, unofficial].

## Operating characteristics
*   **Complexity:** The primary network (decoder) complexity can be much lower compared to concatenation-based methods, hinting at a more compact representation [S1, unofficial].
*   **Distinctness:** Each instance has a unique Neural Field (decoder weights), whereas concatenation shares weights [S1, unofficial].
*   **Performance:** Not given in the sources.
*   **Scaling:** Not given in the sources.

## Background
The concept utilizes HyperNetworks, originally introduced by Ha et al. in 2016 [S1, unofficial]. Recent research by Galanti & Wolf (2020) suggested that HyperNetworks could allow for lower primary network complexity [S1, unofficial]. Feature-wise transformations by Dumoulin et al. (2018) are mentioned as a related technique for feature conditioning [S1, unofficial].
