# Autoencoder/Autodecoder Conditioning

Also called: Auto-decoder training setup for shape space learning, Conditional Neural Field, Latent vector optimization, Multi-shape architecture

## Overview
Autoencoder/Autodecoder Conditioning enables a single neural field to represent multiple distinct geometric instances by associating each instance with a unique latent vector $z$. Unlike concatenation conditioning which injects $z$ into the coordinate stream, this method treats $z$ as a global context parameter optimized per-shape, allowing the network to learn a structured shape space rather than just overfitting a single geometry [S1, unofficial][S2, unofficial]. It is chosen when the goal is to learn a manifold of shapes or to generalize across a dataset of similar objects, as opposed to rendering a single static scene [S2, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A set of training shapes $\{S_j\}_{j \in J}$, where each shape is represented by sampled points (and optionally normals or depth).
*   **Output:** A trained MLP $f(x; \theta, z_j)$ and optimized latent vectors $\{z_j\}$ that define the geometry of each shape $j$.

**Data Structures**
*   **Latent Vector ($z_j$):** A learnable parameter vector for each shape $j$.
    *   Dimension: $L$. Typically $L=256$ for shape space learning experiments [S1, unofficial]. For standard single-shape reconstruction, $L=0$ is used, effectively removing the latent code [S1, unofficial].
    *   Initialization: $z_j \leftarrow \mathbf{0} \in \mathbb{R}^L$ [S1, unofficial].
*   **MLP Architecture:**
    *   Input dimension: $3 + L$ (3 for spatial coordinates $x$, $L$ for latent code $z$) [S1, unofficial].
    *   Layer Sequence:
        1.  $FC^+$ (Fully Connected + Softplus)
        2.  $FC^+$
        3.  $FC^+$
        4.  $FC^+$
        5.  $FC$ (Linear, output 512)
        6.  $FC^+$
        7.  $FC^+$
        8.  $FC$ (Linear, final output)
    *   Skip Connection: Direct connection from the input $(x, z)$ to the 4th layer [S1, unofficial].
    *   Activation: Softplus, defined as $\text{softplus}(x) = \frac{1}{\beta} \ln(1 + e^{\beta x})$ with $\beta = 100$ [S1, unofficial].

**Algorithm**
The method operates in two phases: training and inference.

1.  **Training Phase:**
    For each batch $B \subset J$:
    a. Sample spatial points $x$ from the shapes in $B$.
    b. Compute the reconstruction loss $\ell(\theta, z_j)$ for each $j \in B$ based on the MLP output $f(x; \theta, z_j)$ compared to ground truth (e.g., SDF values, normals, or depth) [S1, unofficial].
    c. Compute the total loss:
       $$ \mathcal{L} = \frac{1}{|B|} \sum_{j \in B} \left( \ell(\theta, z_j) + \alpha \|z_j\|_2 \right) $$
       where $\alpha = 0.01$ is the regularization weight [S1, unofficial].
    d. Update parameters $\theta$ and latent vectors $z_j$ using an optimizer (e.g., Adam) [S1, unofficial].

2.  **Inference Phase (Test Shapes):**
    For a test shape $k$:
    a. Initialize $z_k \leftarrow \mathbf{0}$ [S1, unofficial].
    b. Optimize $z_k$ for 800 iterations using the loss $\ell(\theta, z_k)$ with fixed $\theta$ [S1, unofficial].
    c. Use the final $z_k$ and $\theta$ to evaluate $f(x; \theta, z_k)$ for rendering or reconstruction.

## Subtopics

### Latent Code Regularizer
A specific regularization term $\mathcal{L}_l(z) = \|z\|_2$ applied to the latent codes in the autodecoder framework. It penalizes large magnitudes of $z$, keeping codes close to zero and enforcing similarity between different shapes in the learned space [S3]. A pitfall is that SDF and DDF (Directional Distance Function) models share the same latent code for a given shape, so the regularizer applies to both simultaneously [S3].

## Operating characteristics
*   **Time Complexity:** Training requires joint optimization of network weights $\theta$ and latent vectors $z_j$. Inference for a new shape requires iterative optimization of $z$ (e.g., 800 iterations) [S1, unofficial].
*   **Memory Complexity:** $O(N \cdot L)$ to store $N$ latent vectors of dimension $L$. For $N=10$ shapes and $L=256$, this is negligible.
*   **Performance:** On a single Nvidia V-100 GPU, training for 100k iterations takes significant time but produces high-quality reconstructions [S1, unofficial].
*   **Strengths:** Enables learning a continuous shape space; allows interpolation of shapes via latent vector averaging [S1, unofficial].
*   **Limitations:** Inference is slow due to per-shape optimization; requires careful tuning of $\alpha$ and learning rates [S1, unofficial].

## Background
The method originates from the "Auto-Decoder" setup introduced by Park et al. (2019) in "Implicit Geometric Regularization for Learning Shapes" [S1, unofficial]. It was further popularized in works like SAL (Atzmon & Lipman, 2020) and applied to datasets like D-Faust for learning shape spaces of human meshes [S1, unofficial]. The concept of using latent codes to condition neural fields is also discussed in broader introductions to neural fields [S2, unofficial].
