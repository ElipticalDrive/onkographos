# Latent Code Conditioning

Also called: Conditional Neural Fields, Instance-Specific Neural Fields

## Overview
Latent Code Conditioning enables a single Neural Field architecture to represent multiple distinct data samples (e.g., different images, shapes, or scenes) by conditioning the field's output on an instance-specific latent code $z$ [S1, unofficial]. It solves the problem of overfitting a single representation by allowing the model to generalize across a dataset while maintaining instance identity [S1, unofficial]. It differs from sibling methods by defining the mechanism of injection: [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md) dynamically generates decoder weights, [Global Conditioning](12589-global-conditioning.md) maps $z$ to intermediate representations or grids, and [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md) uses fixed linear projections [S1, unofficial].

## Shared principles
The core mechanism maps a function $f: (\Omega, \mathcal{Z}) \mapsto \mathcal{X}$, where $\Omega$ is the spatial/temporal domain, $\mathcal{Z}$ is the latent space, and $\mathcal{X}$ is the output space (e.g., color, density) [S1, unofficial]. The decoder network $D$ accepts two inputs: the query coordinate $x \in \Omega$ and the latent code $z \in \mathcal{Z}$ [S1, unofficial]. The latent code $z$ is either produced by an encoder or optimized directly (autodecoder) per sample [S1, unofficial]. Conditioning allows the model to distinguish between samples that share the same underlying geometry or structure but differ in appearance or instance-specific details [S1, unofficial].

## Subtopics

### [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md)
[HyperNetwork Conditioning](12585-hypernetwork-conditioning.md) uses a secondary network (HyperNetwork) to predict the decoder's weights $W$ from $z$, creating a unique Neural Field instance for each $z$. It is chosen when instance-specific weight variation is required without increasing the base decoder complexity.

### [Global Conditioning](12589-global-conditioning.md)
[Global Conditioning](12589-global-conditioning.md) encodes the entire sample information into a single latent vector $z$ or a grid derived from it. It is distinguished by mapping $z$ to an intermediate latent space or local code grid rather than directly predicting decoder weights.

### Concatenation Conditioning
Concatenation conditioning is the simplest method where the latent code is concatenated with input coordinates [S1, unofficial].
#### step
- Concatenate the latent code with the input coordinates/features [S1, unofficial].
- Feed the concatenated tensor into the Neural Field decoder [S1, unofficial].
#### pitfall
- Only the first layer directly incorporates the condition; remaining layers operate only on internal feature representations, requiring the network to distinguish samples based on input alone [S1, unofficial].

### Autoencoder/Autodecoder Conditioning
This refers to the training regime for generating $z$ [S1, unofficial].
#### step
- Train the model in an autoencoder manner (using an encoder to produce latent codes) or an autodecoder manner (optimizing a learnable latent vector per sample jointly with decoder weights) [S1, unofficial].

### Local Conditioning
Local conditioning distributes information across multiple latent codes assigned to specific spatio-temporal coordinates [S1, unofficial].
#### definition
- Spreading information about a data sample over multiple latent codes assigned to specific subsets of spatio-temporal coordinates (regions or time steps) [S1, unofficial].

## Background
The concept was introduced in the context of Neural Fields for representing multiple images or scenes [S1, unofficial]. The formulation extends the standard mapping $f: \Omega \mapsto \mathcal{X}$ to $f: (\Omega, \mathcal{Z}) \mapsto \mathcal{X}$ [S1, unofficial]. The approach allows for overfitting a single image or generalizing to many images by conditioning on context variables [S1, unofficial]. The term "global conditioning" was used to describe encoding the whole sample information in one latent code, contrasting with "local conditioning" [S1, unofficial].
