# Concatenation Conditioning

Also called: Latent Code Concatenation

## Overview
Concatenation Conditioning is a method for injecting a latent code $z$ into a Neural Field decoder by appending it to the input feature vector. It solves the problem of conditioning a generative model on global data properties (such as volume modality or transfer function descriptors) by providing the decoder with a unified representation of both the spatial input and the conditioning signal [S1][S2, unofficial]. It is distinguished from HyperNetwork Conditioning by modifying inputs rather than weights, and from Global Conditioning by its simplicity of implementation at the cost of requiring the network to propagate the condition through internal layers [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input spatial coordinate: $x \in \Omega$ [S2, unofficial].
- Input latent code: $z \in \mathcal{Z}$, typically a low-dimensional vector (e.g., length 512) extracted from an encoder [S1].
- Input explicit descriptor: $d$, such as a Transfer Function (TF) descriptor [S1].
- Output: Predicted value $\mathcal{X}$ (e.g., illumination, density) [S1][S2, unofficial].

**Data Structures:**
- Latent Vector $z$: A fixed-size vector (e.g., 512 dimensions) containing compressed global information about the input volume [S1].
- Concatenated Tensor: The result of $[d; z]$ or $[x; z]$, depending on the specific injection point, where $[;]$ denotes concatenation along the feature dimension [S1][S2, unofficial].

**Steps:**
1. **Encode:** Process the input volume with an encoder (e.g., convolutional feature extractor) to extract the latent vector $z$ [S1]. This step is performed once per volume and the result remains constant even if the transfer function changes [S1].
2. **Prepare Descriptor:** Obtain the explicit descriptor $d$ (e.g., TF descriptor) [S1].
3. **Concatenate:** Combine the latent vector $z$ with the descriptor $d$ (or spatial features) via concatenation: $c = [d; z]$ [S1]. This creates a vector containing global information from both the volume and the conditioning signal [S1].
4. **Decode:** Feed the concatenated tensor $c$ into the Neural Field decoder (generative network) [S1][S2, unofficial]. The decoder uses this combined input to predict the output $\mathcal{X}$ (e.g., volumetric ambient occlusion) [S1].

**Pitfalls:**
- **Layer Isolation:** Only the first layer of the decoder directly incorporates the condition $z$. Remaining layers operate only on internal feature representations, requiring the network to distinguish samples based on the input alone [S2, unofficial].
- **Re-execution Cost:** While the encoder output $z$ is constant, the TF extractor and decoder must be re-executed upon transfer function updates [S1].

**Pseudocode:**
```python
def concatenate_conditioning(volume, transfer_function):
    # Step 1: Extract latent vector from volume (constant per volume)
    # Encoder processes input volume to extract low-dimensional latent vector
    latent_vector = encoder(volume) # e.g., length 512
    
    # Step 2: Extract explicit descriptor from transfer function
    # This changes if the transfer function changes
    tf_descriptor = tf_extractor(transfer_function)
    
    # Step 3: Concatenate latent vector with descriptor
    # Combines global volume info with TF info
    concatenated_input = concatenate(latent_vector, tf_descriptor)
    
    # Step 4: Feed into generative decoder
    # Predicts illumination coherent with both volume and TF
    output = decoder(concatenated_input)
    
    return output
```

## Operating characteristics
- **Complexity:** The encoding step is performed once per volume, making inference efficient for multiple transfer functions on the same volume [S1]. The concatenation operation is $O(1)$ relative to spatial resolution but adds to the input dimension of the decoder [S1][S2, unofficial].
- **Strengths:** Simple to implement; beneficial during inference when multiple conditions (e.g., TFs) are applied to a single volume, as the expensive encoder pass is reused [S1].
- **Limitations:** The condition is only directly visible to the first decoder layer; deeper layers must infer the condition from propagated features, which may limit expressiveness compared to weight-modulation methods [S2, unofficial].

## Background
The method is applied in the context of deep volumetric ambient occlusion, where it is used to condition a generative network on both the input volume modality and the transfer function [S1]. It draws from conditional generative modeling practices [S1]. The general concept of latent code concatenation in Neural Fields is discussed in broader introductions to the field [S2, unofficial].
