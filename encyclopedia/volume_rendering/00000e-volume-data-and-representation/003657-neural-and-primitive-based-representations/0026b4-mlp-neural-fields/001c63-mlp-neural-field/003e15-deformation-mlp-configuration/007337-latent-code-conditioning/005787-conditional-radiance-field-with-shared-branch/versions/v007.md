# Conditional Radiance Field with Shared Branch

Also called: CRF with Shared Branch, Modular Conditional Radiance Field

## Overview
The Conditional Radiance Field with Shared Branch is a neural radiance field architecture designed for shape and color disentanglement, enabling efficient editing by allowing specific submodules to be finetuned [S1]. It maps a 3D location $\mathbf{x}$, viewing direction $\mathbf{d}$, and instance-specific shape code $\mathbf{z}^{(s)}$ and color code $\mathbf{z}^{(c)}$ to radiance $\mathbf{c}$ and scalar density $\sigma$ [S1]. It sets itself apart from standard NeRF [Parent](3065-nerf-hyperparameters.md) by introducing a modular structure with a shared shape branch and instance-specific branches, rather than a single monolithic MLP or simple input concatenation [S1].

## How it works
**Inputs:**
*   3D position $\mathbf{x} \in \mathbb{R}^3$.
*   Viewing direction $\mathbf{d} \in \mathbb{R}^3$.
*   Instance-specific shape code $\mathbf{z}^{(s)} \in \mathbb{R}^{32}$.
*   Instance-specific color code $\mathbf{z}^{(c)} \in \mathbb{R}^{32}$.

**Outputs:**
*   Scalar volume density $\sigma \in \mathbb{R}$.
*   Radiance (color) $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The network consists of five Multi-Layer Perceptrons (MLPs), all configured with 4 layers, 256 channels width, and ReLU activations [S1].
1.  $F_{\text{share}}$: Shared shape network.
2.  $F_{\text{inst}}$: Instance-specific shape network.
3.  $F_{\text{fuse}}$: Fusion shape network.
4.  $F_{\text{dens}}$: Output density network (linear layer).
5.  $F_{\text{rad}}$: Output radiance network (2-layer MLP).

All intermediate feature vectors output by $F_{\text{share}}$, $F_{\text{inst}}$, and $F_{\text{fuse}}$ are 256-dimensional [S1].

**Steps:**
1.  **Compute Shared Shape Representation:** Apply positional encoding $\gamma(\mathbf{x})$ to the input position $\mathbf{x}$ [14428-sparse-view-and-few-shot-optimization.md]. Pass the result through $F_{\text{share}}$ to obtain the shared shape feature $\mathbf{h}_{\text{share}}$:
    $$ \mathbf{h}_{\text{share}} = F_{\text{share}}(\gamma(\mathbf{x})) $$
2.  **Compute Instance-Specific Shape Representation:** Concatenate the shape code $\mathbf{z}^{(s)}$ with the positional encoding $\gamma(\mathbf{x})$. Pass the concatenated vector through $F_{\text{inst}}$ to obtain the instance-specific shape feature $\mathbf{h}_{\text{inst}}$:
    $$ \mathbf{h}_{\text{inst}} = F_{\text{inst}}([\mathbf{z}^{(s)}, \gamma(\mathbf{x})]) $$
3.  **Fuse Representations:** Add the shared and instance-specific shape features, then pass the sum through $F_{\text{fuse}}$ to obtain the fused shape feature $\mathbf{h}_{\text{fuse}}$:
    $$ \mathbf{h}_{\text{fuse}} = F_{\text{fuse}}(\mathbf{h}_{\text{share}} + \mathbf{h}_{\text{inst}}) $$
4.  **Predict Density:** Pass $\mathbf{h}_{\text{fuse}}$ through the linear layer $F_{\text{dens}}$ to obtain the scalar density $\sigma$:
    $$ \sigma = F_{\text{dens}}(\mathbf{h}_{\text{fuse}}) $$
5.  **Predict Radiance:** Concatenate the fused shape feature $\mathbf{h}_{\text{fuse}}$, the color code $\mathbf{z}^{(c)}$, and the positional encoding of the viewing direction $\gamma(\mathbf{d})$. Pass this concatenated vector through the two-layer MLP $F_{\text{rad}}$ to obtain the radiance $\mathbf{c}$:
    $$ \mathbf{c} = F_{\text{rad}}([\mathbf{h}_{\text{fuse}}, \mathbf{z}^{(c)}, \gamma(\mathbf{d})]) $$

**Parameters:**
*   Shape code dimension: 32 [S1].
*   Color code dimension: 32 [S1].
*   MLP depth for $F_{\text{share}}, F_{\text{inst}}, F_{\text{fuse}}$: 4 layers [S1].
*   MLP width: 256 channels [S1].
*   Feature dimension: 256 [S1].
*   Optimizer: Adam [S1].
*   Training learning rate: $10^{-4}$ [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ConditionalRadianceFieldSharedBranch(nn.Module):
    def __init__(self, pos_enc_dim=6, latent_dim=32, hidden_dim=256):
        super().__init__()
        # Positional encoding function as defined in Parent
        # gamma(x) returns a tensor of size pos_enc_dim * 2 * 3 = 36 for 3D coords
        # Note: Standard NeRF uses 6 frequencies, resulting in 36 dims.
        # The source [S1] references Mildenhall et al. [45] for training details.
        
        # Shared shape network: 4 layers, 256 channels
        self.F_share = nn.Sequential(
            nn.Linear(pos_enc_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim) # Output 256-dim feature
        )
        
        # Instance-specific shape network: 4 layers, 256 channels
        # Input: latent_dim + pos_enc_dim
        self.F_inst = nn.Sequential(
            nn.Linear(latent_dim + pos_enc_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim) # Output 256-dim feature
        )
        
        # Fusion shape network: 4 layers, 256 channels
        # Input: hidden_dim (from sum of share and inst)
        self.F_fuse = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim) # Output 256-dim feature
        )
        
        # Output density network: Linear layer
        # Input: hidden_dim
        self.F_dens = nn.Linear(hidden_dim, 1)
        
        # Output radiance network: 2-layer MLP
        # Input: hidden_dim + latent_dim + pos_enc_dim
        self.F_rad = nn.Sequential(
            nn.Linear(hidden_dim + latent_dim + pos_enc_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, 3) # Output RGB
        )

    def forward(self, x, d, z_s, z_c):
        """
        x: (N, 3) position
        d: (N, 3) viewing direction
        z_s: (N, 32) shape code
        z_c: (N, 32) color code
        """
        # Apply positional encoding
        gamma_x = positional_encoding(x)
        gamma_d = positional_encoding(d)
        
        # 1. Shared shape representation
        h_share = self.F_share(gamma_x)
        
        # 2. Instance-specific shape representation
        x_inst_input = torch.cat([z_s, gamma_x], dim=-1)
        h_inst = self.F_inst(x_inst_input)
        
        # 3. Fuse representations
        h_fuse = self.F_fuse(h_share + h_inst)
        
        # 4. Predict density
        sigma = self.F_dens(h_fuse).squeeze(-1)
        
        # 5. Predict radiance
        rad_input = torch.cat([h_fuse, z_c, gamma_d], dim=-1)
        c = self.F_rad(rad_input)
        
        return sigma, c

def positional_encoding(x, min_deg=0, max_deg=6):
    """
    Standard NeRF positional encoding.
    x: (..., 3)
    Returns: (..., 3 * 2 * max_deg)
    """
    scales = [2**i for i in range(min_deg, max_deg)]
    xb = torch.reshape((x[..., None, :] * scales), (*x.shape[:-1], len(scales), x.shape[-1]))
    xb = torch.reshape(torch.cat([xb, xb + torch.pi/2.0], -1), (*x.shape[:-1], len(scales) * 2 * x.shape[-1]))
    encoding = torch.cat([torch.sin(xb), torch.cos(xb)], -1)
    return encoding
```

## Operating characteristics
*   **Performance:** On the PhotoShapes dataset, the shared shape branch improves PSNR from 33.91 (model without shared branch) to 35.79 [S1].
*   **Efficiency:** The modular design allows for caching during optimization because the set of training rays is small [S1]. This accelerates color edits by $3.2\times$ and shape edits by $1.9\times$ compared to non-modular approaches [S1].
*   **Scalability:** The shared shape branch helps the model scale to more instances [S1].
*   **Limitations:** The method requires jointly optimizing latent codes for each instance, which increases memory usage compared to a single-instance NeRF if many instances are stored simultaneously [S1].

## Background
The method was introduced in "Editing Conditional Radiance Fields" [S1]. It builds on the inductive biases of NeRF [Parent](3065-nerf-hyperparameters.md) and Mildenhall et al. [45], specifically the use of positional encodings and stage-wise network design [S1]. The architecture was designed to facilitate shape and color editing by disentangling these attributes into separate network branches and latent codes [S1].
