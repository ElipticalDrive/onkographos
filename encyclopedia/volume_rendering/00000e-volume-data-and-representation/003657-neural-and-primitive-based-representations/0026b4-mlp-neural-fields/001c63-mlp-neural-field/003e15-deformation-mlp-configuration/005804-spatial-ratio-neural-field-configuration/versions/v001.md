# Spatial-Ratio Neural Field Configuration

Also called: Gaussian Transform Field, Multi-Head Predictor, Spatial-Ratio Neural Field

## Overview
The Spatial-Ratio Neural Field (SRNF) is a module that predicts position, scaling, and rotation transformations for selected 3D Gaussians to patch missing areas caused by masking, mapping them from an "all-selected" state to an adapted state under a given elastic ratio $e$ [S1]. It serves as the core component of the Gaussian Transform Field, enabling flexible 3D Gaussian Splatting (FlexGS) to maintain rendering quality when the number of Gaussians is reduced [S1]. It is distinguished from sibling methods like [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md) by its use of a multi-plane implicit representation conditioned on a continuous elastic ratio, rather than static linear projections or latent codes [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D Gaussian with position $X \in \mathbb{R}^3$, scaling $s$, rotation $q$, and an elastic ratio scalar $e \in [0, 1]$.
*   **Output:** Transformed attributes $X', s', q'$ representing the Gaussian in the adapted state for ratio $e$ [S1].

**Data Structures:**
The Spatial-Ratio Neural Field $\psi$ is a multi-resolution 4D volume modeling the space $(x, y, z, e)$ [S1].
*   **Structure:** $\psi = \{\psi_l \in \mathbb{R}^4\}_{l \in \{1, 2\}}$, where $l$ denotes the resolution level [S1].
*   **Factorization:** Each resolution plane $\psi_l$ is factorized into 6 2D planes $\psi_l(k_1, k_2) \in \mathbb{R}^{d_{k1} \times d_{k2}}$ for efficiency [S1].
*   **Plane Pairs:** The pairs $(k_1, k_2)$ are $\{(x, y), (x, z), (x, e), (y, z), (y, e), (z, e)\}$ [S1]. Note: The text initially lists $(x,t)$ etc., but clarifies in implementation details that $t$ corresponds to the elastic ratio $e$ [S1].
*   **Resolutions:** The resolutions for dimensions $\{x, y, z, e\}$ are $\{64, 64, 64, 100\}$ respectively [S1].
*   **Feature Storage:** Each vertex in the volume stores multi-channel features [S1].

**Parameters:**
*   **Hidden Feature Dimension ($D$):** Set to 64 for the Multi-Head Predictor and GsNet [S1].

**Steps:**
1.  **Feature Querying:** For a given Gaussian position $X$ and elastic ratio $e$, query the spatial-ratio feature $f$. This involves bilinear interpolation ($BiInterp$) of the factorized planes at coordinates $(X, e)$ and fusing features across resolutions using an MLP $F_m$ [S1].
    $$f_m = BiInterp(\psi_l(X, e))$$
    $$f = F_m(f_m)$$
    Here, $f_m$ is the fused feature vector from the multi-resolution planes [S1].

2.  **Transformation Prediction:** The queried feature $f$ is passed through three separate Multi-Layer Perceptrons (MLPs), denoted as $\phi_X, \phi_s, \phi_q$, to predict displacement vectors for position, scaling, and rotation [S1].
    $$T_X = \phi_X(f)$$
    $$T_s = \phi_s(f)$$
    $$T_q = \phi_q(f)$$
    The hidden dimension of these MLPs is $D=64$ [S1].

3.  **Attribute Transformation:** Apply the predicted displacement vectors to the original Gaussian attributes to obtain the transformed state [S1].
    $$X' = X + T_X$$
    $$s' = s + T_s$$
    $$q' = q + T_q$$

**Pseudocode:**
```python
import numpy as np

class SpatialRatioNeuralField:
    def __init__(self, resolutions=(64, 64, 64, 100), hidden_dim=64):
        """
        Initialize the SRNF.
        resolutions: Tuple (x_res, y_res, z_res, e_res)
        hidden_dim: Dimension of the feature vector D
        """
        self.x_res, self.y_res, self.z_res, self.e_res = resolutions
        self.hidden_dim = hidden_dim
        
        # Initialize 6 planes for each of the 2 resolutions
        # Plane pairs: (x,y), (x,z), (x,e), (y,z), (y,e), (z,e)
        # Dimensions for each plane depend on the specific pair
        self.planes = {}
        for l in [1, 2]:
            self.planes[l] = {}
            # (x, y)
            self.planes[l]['xy'] = np.random.randn(self.x_res, self.y_res, hidden_dim)
            # (x, z)
            self.planes[l]['xz'] = np.random.randn(self.x_res, self.z_res, hidden_dim)
            # (x, e)
            self.planes[l]['xe'] = np.random.randn(self.x_res, self.e_res, hidden_dim)
            # (y, z)
            self.planes[l]['yz'] = np.random.randn(self.y_res, self.z_res, hidden_dim)
            # (y, e)
            self.planes[l]['ye'] = np.random.randn(self.y_res, self.e_res, hidden_dim)
            # (z, e)
            self.planes[l]['ze'] = np.random.randn(self.z_res, self.e_res, hidden_dim)
            
        # MLPs for fusion and prediction
        # Fm: MLP for fusing multi-resolution features
        self.Fm = MLP(hidden_dim, hidden_dim)
        # Predictors
        self.phi_X = MLP(hidden_dim, 3)
        self.phi_s = MLP(hidden_dim, 3)
        self.phi_q = MLP(hidden_dim, 4) # Quaternion rotation

    def query(self, X, e):
        """
        Query feature f for position X and ratio e.
        X: numpy array (3,)
        e: float
        """
        # Normalize coordinates to [0, 1] for interpolation
        # Assuming X is in world space, needs normalization based on scene bounds
        # For this implementation, we assume X is already normalized or bounds are implicit
        x, y, z = X
        
        # Bilinear interpolation helper
        def interp_2d(plane, u, v):
            # u, v in [0, 1]
            # Map to grid indices
            h, w = plane.shape[:2]
            u_idx = u * (w - 1)
            v_idx = v * (h - 1)
            
            # Floor and ceil indices
            u0, u1 = int(np.floor(u_idx)), int(np.ceil(u_idx))
            v0, v1 = int(np.floor(v_idx)), int(np.ceil(v_idx))
            
            # Wrap around if necessary (clamp or wrap)
            u0 = np.clip(u0, 0, w-1)
            u1 = np.clip(u1, 0, w-1)
            v0 = np.clip(v0, 0, h-1)
            v1 = np.clip(v1, 0, h-1)
            
            # Interpolate
            fu = u_idx - u0
            fv = v_idx - v0
            
            val00 = plane[v0, u0]
            val01 = plane[v0, u1]
            val10 = plane[v1, u0]
            val11 = plane[v1, u1]
            
            top = val00 * (1 - fu) + val01 * fu
            bottom = val10 * (1 - fu) + val11 * fu
            return top * (1 - fv) + bottom * fv

        # Query all 6 planes for both resolutions
        features = []
        for l in [1, 2]:
            p = self.planes[l]
            # Query (x, y)
            f_xy = interp_2d(p['xy'], x, y)
            # Query (x, z)
            f_xz = interp_2d(p['xz'], x, z)
            # Query (x, e)
            f_xe = interp_2d(p['xe'], x, e)
            # Query (y, z)
            f_yz = interp_2d(p['yz'], y, z)
            # Query (y, e)
            f_ye = interp_2d(p['ye'], y, e)
            # Query (z, e)
            f_ze = interp_2d(p['ze'], z, e)
            
            # Fuse features from the 6 planes for this resolution
            # Simple sum or concat? Source says "fusing across resolutions via MLP Fm"
            # It implies f_m is the result of interpolation, then Fm processes it.
            # Usually, features from different planes are concatenated or summed.
            # Given the output of interp is (D,), we likely concatenate them or sum them.
            # Let's assume concatenation of the 6 plane outputs for one resolution
            f_l = np.concatenate([f_xy, f_xz, f_xe, f_yz, f_ye, f_ze])
            features.append(f_l)
            
        # Fuse across resolutions
        # f_m is the input to Fm. If features are from two resolutions, we might concat them
        f_m = np.concatenate(features)
        
        # Apply MLP Fm
        f = self.Fm.forward(f_m)
        return f

    def transform(self, X, s, q, e):
        """
        Transform Gaussian attributes.
        X: numpy array (3,)
        s: numpy array (3,)
        q: numpy array (4,)
        e: float
        """
        f = self.query(X, e)
        
        # Predict displacements
        T_X = self.phi_X.forward(f)
        T_s = self.phi_s.forward(f)
        T_q = self.phi_q.forward(f)
        
        # Apply transformations
        X_new = X + T_X
        s_new = s + T_s
        q_new = q + T_q
        
        return X_new, s_new, q_new

class MLP:
    def __init__(self, in_dim, out_dim):
        self.W = np.random.randn(in_dim, out_dim)
        self.b = np.zeros(out_dim)
        
    def forward(self, x):
        return np.dot(x, self.W) + self.b
```

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Bilinear interpolation requires coordinates to be within the valid range of the planes. If $X$ or $e$ falls outside the normalized bounds, clamping or wrapping must be applied [S1].
*   **Ratio Accuracy:** During inference, the number of activated entries may not exactly match the target ratio $e$ due to sparsity supervision nuances. For example, a target ratio of 0.20 might result in 19.5% selection. An additional step to attain an accurate elastic ratio is required during inference [S1].
*   **Opacity Handling:** During training, unselected Gaussians are rendered transparent by updating opacity $\alpha_i = \alpha_i \cdot \hat{M}_i$. During inference, unselected Gaussians are directly discarded [S1].

## Operating characteristics
*   **Time Complexity:** The query time depends on the number of planes (6) and resolutions (2), plus the cost of bilinear interpolation and MLP forward passes. It is efficient compared to dense 4D volume lookups due to the factorization into 2D planes [S1].
*   **Memory Complexity:** The memory footprint is determined by the size of the 6 planes per resolution. With resolutions $\{64, 64, 64, 100\}$ and hidden dimension 64, the memory usage is manageable for real-time applications [S1].
*   **Strengths:** Enables flexible Gaussian count adjustment while preserving rendering quality by adapting spatial distribution [S1].
*   **Limitations:** Requires careful handling of the elastic ratio to ensure exact sparsity levels during inference [S1].

## Background
The Spatial-Ratio Neural Field was introduced in the context of FlexGS (Flexible 3D Gaussian Splatting) to address the issue of missing details and holes when simply masking out Gaussians for compression or efficiency [S1]. It builds on previous work in dynamic scene representation using multi-plane implicit representations [S1]. The method allows a single model to handle multiple elastic ratios, making it suitable for deployment across various hardware constraints [S1].
