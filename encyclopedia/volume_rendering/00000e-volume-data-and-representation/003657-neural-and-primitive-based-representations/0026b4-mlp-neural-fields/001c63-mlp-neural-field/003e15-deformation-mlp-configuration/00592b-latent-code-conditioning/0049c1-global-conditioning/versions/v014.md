# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data instance into a single fixed-size latent vector $z$, which modulates a shared neural field decoder to produce instance-specific outputs [S2, unofficial]. It is distinguished from local conditioning, which distributes information across multiple latent codes assigned to specific spatial regions or time steps [S2, unofficial]. In practice, this global vector is often passed through a "Mapping Network" to transform it into an intermediate non-linear latent space before conditioning the decoder [S1].

## How it works
**Inputs and outputs:**
*   **Input:** A global latent code $z \in \mathbb{R}^D$.
*   **Output:** A transformed latent vector $z'$ (for the Mapping Network) or a spatial grid of local latent codes $W$ (for the Global Generator variant).

**Data structures:**
*   **Mapping Network:** A sequence of linear layers.
*   **Global Generator:** A convolutional neural network producing a 3D tensor $W$ of shape $H \times W \times C$, representing a 2D spatial grid of latent codes.

**Steps (Mapping Network):**
The Mapping Network maps the global latent code $z$ to an intermediate non-linear latent space [S1]. The architecture consists of a normalization step followed by three linear layers with LeakyReLU activations [S1].

1.  **Normalize:** Apply normalization to the input vector $z$. [S1]
2.  **Linear Layer 1:** Apply a linear transformation to the normalized $z$.
3.  **Activation 1:** Apply LeakyReLU with negative slope 0.2.
4.  **Linear Layer 2:** Apply a linear transformation.
5.  **Activation 2:** Apply LeakyReLU with negative slope 0.2.
6.  **Linear Layer 3:** Apply a linear transformation.
7.  **Activation 3:** Apply LeakyReLU with negative slope 0.2.

The output shape of each layer is 128 [S1].

**Pseudocode (Mapping Network):**

```python
import torch
import torch.nn as nn

class MappingNetwork(nn.Module):
    def __init__(self, input_dim: int):
        super().__init__()
        # Normalization step [S1]
        self.norm = nn.LayerNorm(input_dim)
        
        # Three linear layers with LeakyReLU(0.2) [S1]
        self.fc1 = nn.Linear(input_dim, 128)
        self.fc2 = nn.Linear(128, 128)
        self.fc3 = nn.Linear(128, 128)
        
        self.leaky_relu = nn.LeakyReLU(negative_slope=0.2)

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        # Input z shape: (batch_size, input_dim)
        x = self.norm(z)
        x = self.fc1(x)
        x = self.leaky_relu(x)
        x = self.fc2(x)
        x = self.leaky_relu(x)
        x = self.fc3(x)
        x = self.leaky_relu(x)
        # Output shape: (batch_size, 128) [S1]
        return x
```

**Steps (Global Generator Variant):**
The Global Generator maps a single global latent code $z$ to a 2D grid of local latent codes $W$ representing the spatial layout of the scene [S1].

1.  **Initialize:** Start with a learnable constant input tensor. [S1]
2.  **First Layer:** Apply a $3 \times 3$ modulated convolution conditioned on $z$.
3.  **Activation:** Apply LeakyReLU with negative slope 0.2.
4.  **Upsampling Pairs:** For subsequent layers, apply pairs of modulated convolutions. Each pair upsamples the feature map resolution by $2\times$ using a transposed convolution with stride 2, followed by bilinear filtering [S1].
5.  **Activation:** Apply LeakyReLU with negative slope 0.2 after each convolution.
6.  **Final Layer:** The final output resolution is a hyperparameter, typically $32 \times 32$ [S1].

**Parameters:**
*   **Output Resolution:** The spatial resolution of $W$ is a hyperparameter controlling the size of the spatial region represented by each local latent code. The standard value is $32 \times 32$ [S1].
*   **Activation:** LeakyReLU with negative slope 0.2 is used throughout [S1].

**Edge cases and pitfalls:**
*   The constant input initialization in the Global Generator follows StyleGAN conventions [S1].
*   The resolution of $W$ directly impacts the granularity of spatial conditioning; higher resolutions increase computational cost [S1].

## Subtopics

### Global Generator
A variant that maps a single global latent code $z$ to a 2D grid of local latent codes $W$ [S1]. It uses successive modulated convolutional layers conditioned on $z$, starting with a constant input and upsampling via transposed convolutions and bilinear filtering [S1]. It is chosen when spatial layout information needs to be explicitly represented as a grid of local codes rather than a single global vector. The output resolution is typically $32 \times 32$ [S1].

## Operating characteristics
*   **Time Complexity:** The Mapping Network is lightweight, consisting of only three linear layers [S1]. The Global Generator is more expensive due to convolutional operations and upsampling [S1].
*   **Memory Complexity:** The Mapping Network output is a fixed-size vector (128 dimensions) [S1]. The Global Generator output is a tensor of size $H \times W \times C$ (e.g., $32 \times 32 \times 32$), which is significantly larger [S1].
*   **Strengths:** Global conditioning is simple and efficient for encoding instance-level information [S2, unofficial]. The Mapping Network provides a non-linear transformation that can improve optimization [S1].
*   **Limitations:** A single global code may struggle to capture complex spatial variations compared to local conditioning [S2, unofficial]. The Global Generator increases computational cost significantly [S1].

## Background
Global conditioning and the Mapping Network architecture were introduced in "Unconstrained Scene Generation with Locally Conditioned Radiance Fields" [S1]. The Mapping Network follows the approach of StyleGAN [S1, citing 24, 31]. The concept of global vs. local conditioning is discussed in general neural field literature [S2, unofficial].
