# Autoencoder/Autodecoder Conditioning

Also called: Auto-decoder training setup for shape space learning, Conditional Neural Field, Latent vector optimization, Multi-shape architecture

## Overview
Autoencoder/Autodecoder Conditioning is a method for training neural fields to represent multiple data instances (e.g., shapes or images) by associating a unique, learnable latent vector $z_j$ with each instance $j$ [S1, unofficial][S2, unofficial]. It solves the problem of multi-instance representation without requiring a separate encoder network during inference, distinguishing itself from Concatenation Conditioning (which concatenates $z$ to input coordinates) and HyperNetwork Conditioning (which uses a secondary network to generate weights) [S1, unofficial][S2, unofficial]. The method optimizes the latent vectors jointly with the network weights during training and, for test shapes, optimizes $z$ per-instance to achieve reconstruction [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of training examples $J$ (e.g., point clouds or images). For each example $j \in J$, a latent vector $z_j \in \mathbb{R}^L$ is required.
*   **Output:** A trained neural field $f(x; \theta, z_j)$ that predicts volumetric properties (e.g., SDF, density, color) for query coordinates $x$, conditioned on the specific latent code $z_j$.

**Data Structures:**
*   **Latent Vector $z_j$:** A learnable parameter tensor of size $L$. In shape reconstruction, $L$ may be 0 (effectively a shared network), but for shape space learning, $L=256$ is typical [S1, unofficial].
*   **Network Architecture:** A Multi-Layer Perceptron (MLP) where the input dimension is $3 + L$ (3 for spatial coordinates $x$, $L$ for latent code $z_j$) [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** For each training example $j \in J$, initialize the latent vector $z_j$ to zero: $z_j \leftarrow \mathbf{0} \in \mathbb{R}^L$ [S1, unofficial].
2.  **Network Definition:** Define the MLP $f$ with input dimension $3+L$. The architecture typically consists of fully connected (FC) layers with skip connections. Specifically, a skip connection connects the input directly to the 4th layer [S1, unofficial].
3.  **Loss Calculation:** For a batch $B \subset J$, compute the total loss:
    $$ \mathcal{L} = \frac{1}{|B|} \sum_{j \in B} \ell(\theta, z_j) + \alpha \|z_j\|_2 $$
    where $\ell$ is the task-specific loss (e.g., Chamfer distance, depth loss, silhouette loss) [S1, unofficial][S3], and $\alpha$ is the regularization weight [S1, unofficial].
4.  **Optimization:** Update both the network weights $\theta$ and the latent vectors $\{z_j\}_{j \in B}$ using an optimizer (e.g., Adam) to minimize $\mathcal{L}$ [S1, unofficial].
5.  **Test-Time Inference:** For a new test shape, obtain the final reconstruction by optimizing the latent vector $z$ for 800 iterations using the task-specific loss $\ell$ [S1, unofficial].

**Network Architecture Details:**
The MLP uses Fully Connected (FC) layers. An "FC+" layer is defined as an FC layer followed by a Softplus activation [S1, unofficial].
*   **Activation:** Softplus with $\beta = 100$:
    $$ \text{Softplus}(x) = \frac{1}{\beta} \ln(1 + e^{\beta x}) $$
*   **Layer Sequence:**
    1.  Input ($3+L$) $\to$ FC+
    2.  FC+
    3.  FC+
    4.  FC+ (Skip connection from Input)
    5.  FC+ (Hidden size 512)
    6.  FC+
    7.  FC+
    8.  FC (Output)
    [S1, unofficial]

**Parameters:**
*   $L$: Latent vector size. $L=256$ for shape space experiments [S1, unofficial].
*   $\alpha$: Regularization weight. Typical value $\alpha = 0.01$ [S1, unofficial].
*   $\beta$: Softplus smoothness parameter. $\beta = 100$ [S1, unofficial].

**Pseudocode:**

import torch.nn as nn
import torch.optim as optim

class Softplus(nn.Module):
    def __init__(self, beta=100):
        super().__init__()
        self.beta = beta

    def forward(self, x):
        return (1.0 / self.beta) * torch.log(1 + torch.exp(self.beta * x))

    def __init__(self, latent_dim=256):
        super().__init__()
        self.latent_dim = latent_dim
        input_dim = 3 + latent_dim
        
        # Layer sequence: FC+ -> FC+ -> FC+ -> FC+ -> 512 -> FC+ -> FC+ -> FC
        # Skip connection from input to 4th layer
        self.fc1 = nn.Linear(input_dim, 512)
        self.fc2 = nn.Linear(512, 512)
        self.fc3 = nn.Linear(512, 512)
        self.fc4 = nn.Linear(512, 512)
        self.fc5 = nn.Linear(512, 512)
        self.fc6 = nn.Linear(512, 512)
        self.fc7 = nn.Linear(512, 1) # Output dimension depends on task (e.g., SDF)
        
        self.softplus = Softplus(beta=100)

    def forward(self, x, z):
        # x: (N, 3), z: (N, L)
        # Concatenate x and z
        input_vec = torch.cat([x, z], dim=1)
        
        h = self.softplus(self.fc1(input_vec))
        h = self.softplus(self.fc2(h))
        h = self.softplus(self.fc3(h))
        
        # Skip connection to 4th layer
        h = self.softplus(self.fc4(torch.cat([h, input_vec], dim=1)))
        
        h = self.softplus(self.fc5(h))
        h = self.softplus(self.fc6(h))
        out = self.fc7(h)
        return out

        batch_points, batch_labels = next(data_loader)

## Subtopics

### Latent Code Regularizer
A specific regularization term $\mathcal{L}_l(z) = \|z\|_2$ applied to the latent codes in the autodecoder framework [S3]. It penalizes large magnitudes of $z$ to keep latent codes close to zero, ensuring similarity between different shapes in the learned space [S3]. A pitfall is that SDF and DDF models must share the same latent code for a given shape to maintain consistency [S3].

## Operating characteristics
*   **Time Complexity:** Training requires joint optimization of network weights and latent vectors. Test-time inference requires iterative optimization of $z$ (e.g., 800 iterations) per shape [S1, unofficial].
*   **Memory Complexity:** Memory usage scales linearly with the number of shapes $|J|$ due to the storage of $|J|$ latent vectors of size $L$ [S1, unofficial].
*   **Strengths:** Enables representation of multiple shapes with a single network; allows interpolation of latent vectors to explore shape space [S1, unofficial].
*   **Limitations:** Test-time inference is slow due to per-shape optimization; requires careful tuning of regularization parameter $\alpha$ [S1, unofficial].
*   **When to use:** When learning a shared shape space from multiple scans or when a single network must represent multiple instances without an explicit encoder [S1, unofficial][S2, unofficial].

## Background
The method originates from the auto-decoder setup introduced by Park et al. (2019) for learning shape spaces from raw scans [S1, unofficial]. It was applied to datasets like D-Faust for learning human shape and pose variations [S1, unofficial]. The approach is a variant of conditional neural fields where the condition is a learnable latent vector rather than a fixed input or generated weights [S2, unofficial].
