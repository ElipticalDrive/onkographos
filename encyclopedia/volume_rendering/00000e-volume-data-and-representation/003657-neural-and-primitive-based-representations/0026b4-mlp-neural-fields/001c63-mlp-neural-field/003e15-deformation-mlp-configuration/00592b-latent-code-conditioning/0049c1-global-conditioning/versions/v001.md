# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data sample into a single latent vector $z$, as opposed to local conditioning which distributes information across multiple latent codes assigned to specific spatio-temporal coordinates [S2, unofficial]. It serves as the primary mechanism for injecting sample-specific identity into neural radiance fields. It is distinguished from [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md) by generating weights or biases directly, whereas global conditioning typically maps $z$ to an intermediate latent space or a grid of local codes [S1].

## How it works
**Inputs and Outputs:**
*   Input: A global latent code vector $z$.
*   Output: An intermediate non-linear latent representation (for Mapping Network) or a 2D grid of local latent codes $W$ (for Global Generator).

**Data Structures:**
*   **Mapping Network:** A sequence of three linear layers. The output shape for each layer is 128.
*   **Global Generator:** A 2D grid of latent codes $W$ with spatial resolution $H \times W$. The standard output resolution is $32 \times 32$ [S1].

**Steps (Mapping Network):**
1.  **Normalize:** Normalize the input vector $z$. [S1]
2.  **Linear Layer 1:** Apply a linear transformation to the normalized $z$.
3.  **Activation 1:** Apply LeakyReLU with negative slope 0.2. [S1]
4.  **Linear Layer 2:** Apply a linear transformation.
5.  **Activation 2:** Apply LeakyReLU(0.2). [S1]
6.  **Linear Layer 3:** Apply a linear transformation.
7.  **Activation 3:** Apply LeakyReLU(0.2). [S1]
8.  **Output:** The result is a vector of shape 128. [S1]

**Steps (Global Generator):**
1.  **Initialize:** Start with a learnable constant input tensor. [S1]
2.  **First Layer:** Apply a $3 \times 3$ modulated convolutional layer conditioned on $z$.
3.  **Activation:** Apply LeakyReLU(0.2). [S1]
4.  **Upsampling Pairs:** For subsequent layers, apply pairs of modulated convolutional layers. Each pair upsamples the feature map resolution by $2\times$.
5.  **Upsampling Implementation:** The upsampling is implemented as a transposed convolution with stride 2, followed by bilinear filtering. [S1]
6.  **Activation:** Apply LeakyReLU(0.2) after each convolution. [S1]
7.  **Output:** The final grid $W$ has resolution $32 \times 32$ (in standard configurations). [S1]

**Parameters:**
*   **Mapping Network:** Output dimension is 128. Activation is LeakyReLU(0.2). [S1]
*   **Global Generator:** Output spatial resolution is $32 \times 32$. This hyperparameter controls the size of the spatial region represented by each individual local latent code. [S1]

**Pseudocode (Mapping Network):**
```python
def mapping_network(z):
    # z: input latent vector
    # Normalize input
    z_norm = normalize(z)
    
    # Three linear layers with LeakyReLU(0.2)
    # Layer 1
    x = linear_layer_1(z_norm)
    x = leaky_relu(x, negative_slope=0.2)
    
    # Layer 2
    x = linear_layer_2(x)
    x = leaky_relu(x, negative_slope=0.2)
    
    # Layer 3
    x = linear_layer_3(x)
    x = leaky_relu(x, negative_slope=0.2)
    
    return x
```

**Pseudocode (Global Generator):**
```python
def global_generator(z, target_resolution=32):
    # z: global latent code
    # Initialize with learnable constant input
    x = learnable_constant_input()
    
    # First layer: 3x3 modulated convolution
    x = modulated_conv_3x3(x, z)
    x = leaky_relu(x, negative_slope=0.2)
    
    # Subsequent layers: pairs of modulated convolutions with upsampling
    # Note: Exact number of layers depends on achieving target_resolution from initial 4x4
    # Assuming initial constant input is 4x4, we need 3 upsampling steps to reach 32x32
    # Each step consists of two modulated conv layers
    
    # Upsample 1: 4x4 -> 8x8
    x = modulated_conv_3x3(x, z)
    x = leaky_relu(x, negative_slope=0.2)
    x = transposed_conv_2x2(x, stride=2)
    x = bilinear_filter(x)
    x = modulated_conv_3x3(x, z)
    x = leaky_relu(x, negative_slope=0.2)
    
    # Upsample 2: 8x8 -> 16x16
    x = transposed_conv_2x2(x, stride=2)
    x = bilinear_filter(x)
    x = modulated_conv_3x3(x, z)
    x = leaky_relu(x, negative_slope=0.2)
    x = transposed_conv_2x2(x, stride=2)
    x = bilinear_filter(x)
    x = modulated_conv_3x3(x, z)
    x = leaky_relu(x, negative_slope=0.2)
    
    # Upsample 3: 16x16 -> 32x32
    x = transposed_conv_2x2(x, stride=2)
    x = bilinear_filter(x)
    x = modulated_conv_3x3(x, z)
    x = leaky_relu(x, negative_slope=0.2)
    x = transposed_conv_2x2(x, stride=2)
    x = bilinear_filter(x)
    x = modulated_conv_3x3(x, z)
    x = leaky_relu(x, negative_slope=0.2)
    
    return x
```

## Subtopics

### Global Generator
Maps a single global latent code $z$ to a 2D grid of local latent codes $W$ representing the spatial layout of the scene [S1]. It uses successive modulated convolutional layers conditioned on $z$, starting with a constant input and $3\times3$ modulated convolutions, followed by upsampling via transposed convolutions (stride 2) and bilinear filtering [S1]. The output resolution (e.g., $32\times32$) controls the spatial granularity of the local latent codes [S1].

## Background
The concept of global conditioning, where a single latent vector encodes the whole information about a data sample, is discussed in the context of neural fields [S2, unofficial]. The specific implementation of the Mapping Network (normalization followed by three linear layers with LeakyReLU) and the Global Generator (modulated convolutions) is detailed in "Unconstrained Scene Generation with Locally Conditioned Radiance Fields" [S1].
