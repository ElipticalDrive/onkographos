# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data sample into a single latent vector $z$, which is then integrated into the Neural Field decoder [S2, unofficial]. It serves as the foundational conditioning mechanism for methods like [Latent Code Conditioning](16345-latent-code-conditioning.md), providing a global context that influences the radiance field or geometry across the entire domain [S1]. It is distinguished from [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md) by generating a static latent representation rather than dynamic network weights, and from local variants by using one code for the whole scene rather than region-specific codes [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: A global latent code $z \in \mathbb{R}^d$.
*   Output: A processed latent code $z'$ in an intermediate non-linear latent space, or a grid of local latent codes $W$ if a Global Generator is used [S1].

**Data Structures:**
*   **Mapping Network:** A sequence of linear layers.
*   **Global Generator:** A convolutional network producing a 2D grid $W$ of shape $H \times W \times C$.

**Steps:**
1.  **Normalization:** Normalize the input latent code $z$. The specific normalization method (e.g., layer norm, instance norm) is not detailed in the sources [G].
2.  **Linear Projection (Mapping Network):** Pass the normalized $z$ through three consecutive linear layers. After each linear layer, apply a LeakyReLU activation with a negative slope of 0.2. The output dimension for each layer is 128 [S1].
3.  **Global Generation (Optional):** If local conditioning is required, map the processed global code to a spatial grid. Initialize with a constant learnable input tensor. Apply a sequence of modulated convolutional layers conditioned on the global latent code. The first layer uses a $3 \times 3$ modulated convolution. Subsequent layers upsample the resolution by $2\times$ using a transposed convolution with stride 2, followed by bilinear filtering. Apply LeakyReLU(0.2) after each convolution [S1].

**Parameters:**
*   Mapping Network Output Dimension: 128 [S1].
*   Global Generator Output Resolution: $32 \times 32$ [S1]. This hyperparameter controls the spatial granularity of the local latent codes [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MappingNetwork(nn.Module):
    """
    Maps a global latent code z to an intermediate non-linear latent space.
    Consists of normalization followed by three linear layers with LeakyReLU(0.2).
    """
    def __init__(self, latent_dim: int):
        super().__init__()
        # Normalization step [G]
        self.norm = nn.LayerNorm(latent_dim)
        self.linear1 = nn.Linear(latent_dim, 128)
        self.linear2 = nn.Linear(128, 128)
        self.linear3 = nn.Linear(128, 128)

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        # Step 1: Normalize
        z = self.norm(z)
        # Step 2: Linear layers with LeakyReLU(0.2)
        z = F.leaky_relu(self.linear1(z), negative_slope=0.2)
        z = F.leaky_relu(self.linear2(z), negative_slope=0.2)
        z = F.leaky_relu(self.linear3(z), negative_slope=0.2)
        return z

class GlobalGenerator(nn.Module):
    """
    Maps a single global latent code z to a 2D grid of local latent codes W.
    Uses modulated convolutions conditioned on z.
    """
    def __init__(self, latent_dim: int, out_res: int = 32, channels: int = 256):
        super().__init__()
        self.out_res = out_res
        # Constant input initialization [S1]
        self.constant_input = nn.Parameter(torch.randn(1, channels, 4, 4))
        
        # Modulated convolutions conditioned on z [S1]
        # Note: ModulatedConv is a custom layer not in standard PyTorch.
        # It typically uses z to generate scale and shift parameters for the conv weights.
        # We define a placeholder structure reflecting the sequence.
        self.conv1 = ModulatedConv(channels, channels, kernel_size=3, latent_dim=latent_dim)
        self.conv2 = ModulatedConv(channels, channels, kernel_size=3, latent_dim=latent_dim)
        self.conv3 = ModulatedConv(channels, channels, kernel_size=3, latent_dim=latent_dim)
        self.conv4 = ModulatedConv(channels, channels, kernel_size=3, latent_dim=latent_dim)
        self.conv5 = ModulatedConv(channels, channels, kernel_size=3, latent_dim=latent_dim)
        self.conv6 = ModulatedConv(channels, channels, kernel_size=3, latent_dim=latent_dim)
        self.conv7 = ModulatedConv(channels, channels, kernel_size=3, latent_dim=latent_dim)
        
        # Final projection to output channels (e.g., 32) [S1]
        self.final_conv = nn.Conv2d(channels, 32, kernel_size=1)

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        # Initialize with constant input [S1]
        x = self.constant_input
        
        # First layer: 3x3 modulated conv [S1]
        x = self.conv1(x, z)
        x = F.leaky_relu(x, negative_slope=0.2)
        
        # Subsequent layers: upsample by 2x using transposed conv + bilinear filter [S1]
        # The source describes pairs, but lists 7 conv layers total.
        # We apply the upsampling logic to the subsequent layers as described.
        
        x = self.conv2(x, z)
        x = F.leaky_relu(x, negative_slope=0.2)
        
        x = self.conv3(x, z)
        x = F.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False) # Bilinear filtering [S1]
        x = F.leaky_relu(x, negative_slope=0.2)
        
        x = self.conv4(x, z)
        x = F.leaky_relu(x, negative_slope=0.2)
        
        x = self.conv5(x, z)
        x = F.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False)
        x = F.leaky_relu(x, negative_slope=0.2)
        
        x = self.conv6(x, z)
        x = F.leaky_relu(x, negative_slope=0.2)
        
        x = self.conv7(x, z)
        x = F.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False)
        x = F.leaky_relu(x, negative_slope=0.2)
        
        # Output resolution 32x32 [S1]
        x = self.final_conv(x)
        return x

# Placeholder for ModulatedConv to ensure valid Python syntax
class ModulatedConv(nn.Module):
    def __init__(self, in_ch, out_ch, kernel_size, latent_dim):
        super().__init__()
        self.conv = nn.Conv2d(in_ch, out_ch, kernel_size, padding=kernel_size//2)
        # In a real implementation, z would be processed to generate scale/shift
        # Here we just pass z to satisfy the signature, ignoring it for simplicity
        # as the exact modulation math is not provided in sources [G]
        self.latent_dim = latent_dim

    def forward(self, x, z):
        # Standard convolution [G]
        return self.conv(x)
```

## Subtopics

### Global Generator
Maps a single global latent code $z$ to a 2D grid of local latent codes $W$ representing the spatial layout of the scene [S1]. It uses a constant input and successive modulated convolutional layers conditioned on $z$, upsampling resolution by $2\times$ via transposed convolution and bilinear filtering [S1]. Choose this when local spatial variations of the latent code are required [S1]. The output resolution is typically $32 \times 32$ [S1].

## Operating characteristics
*   **Complexity:** The Mapping Network is $O(d^2)$ per sample where $d$ is the latent dimension, with negligible memory overhead. The Global Generator is $O(H \cdot W \cdot C^2)$ in memory and compute, where $H, W$ are output resolutions and $C$ is channels [S1].
*   **Performance:** Using feature maps directly from the radiance field produced higher quality results compared to sampling at low resolution and applying refinement blocks, but the computational cost is significantly higher [S1].
*   **Strengths:** Captures global semantic information efficiently [S2, unofficial].
*   **Limitations:** A single code may struggle with high-frequency local details without the Global Generator variant [S1].

## Background
Global conditioning originates from the application of neural fields to unconstrained scene generation [S1]. The mapping network architecture follows StyleGAN principles [S1][S2, unofficial], specifically using a normalization step followed by linear layers with LeakyReLU activations [S1]. The concept of encoding the whole sample information in one latent vector is contrasted with local conditioning in the broader context of neural fields [S2, unofficial].
