# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data sample into a single latent vector $z$, allowing the neural field to distinguish between different instances [S2, unofficial]. It serves as the primary mechanism for instance-specific variation in latent code conditioning, contrasting with local conditioning which distributes information across spatial regions [S2, unofficial]. It is distinct from sibling methods by using a dedicated network (Mapping Network) to transform the raw latent code into a suitable intermediate representation, rather than directly concatenating $z$ or using a HyperNetwork to generate weights [S1].

## How it works
**Inputs and Outputs:**
*   Input: Global latent code $z \in \mathbb{R}^d$ (typically $d=512$) [S1].
*   Output: Intermediate latent code $w \in \mathbb{R}^{128}$ [S1].

**Data Structures:**
The Mapping Network is a Multi-Layer Perceptron (MLP) consisting of:
1.  A normalization layer.
2.  Three linear layers.
3.  Activation functions applied after each linear layer.

**Steps:**
1.  **Normalize:** Apply normalization to input $z$. The specific normalization method (e.g., LayerNorm) is not detailed in the source, but it is a required preprocessing step [S1].
2.  **Linear Layer 1:** Compute $h_1 = \text{Linear}_1(z)$.
3.  **Activation 1:** Apply LeakyReLU with negative slope 0.2: $a_1 = \text{LeakyReLU}(h_1, \alpha=0.2)$ [S1].
4.  **Linear Layer 2:** Compute $h_2 = \text{Linear}_2(a_1)$.
5.  **Activation 2:** Apply LeakyReLU: $a_2 = \text{LeakyReLU}(h_2, \alpha=0.2)$ [S1].
6.  **Linear Layer 3:** Compute $h_3 = \text{Linear}_3(a_2)$.
7.  **Activation 3:** Apply LeakyReLU: $w = \text{LeakyReLU}(h_3, \alpha=0.2)$ [S1].
8.  **Output:** The result $w$ has shape 128 [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class MappingNetwork(nn.Module):
    def __init__(self, input_dim=512, output_dim=128):
        super().__init__()
        # Normalization layer is required but type not specified in source [S1]
        # Using LayerNorm as a standard default for latent codes [G]
        self.norm = nn.LayerNorm(input_dim)
        self.linear1 = nn.Linear(input_dim, output_dim)
        self.linear2 = nn.Linear(output_dim, output_dim)
        self.linear3 = nn.Linear(output_dim, output_dim)
        
    def forward(self, z):
        # Step 1: Normalize
        z_norm = self.norm(z)
        
        # Step 2-3: Linear 1 + LeakyReLU(0.2)
        h1 = self.linear1(z_norm)
        a1 = torch.nn.functional.leaky_relu(h1, negative_slope=0.2)
        
        # Step 4-5: Linear 2 + LeakyReLU(0.2)
        h2 = self.linear2(a1)
        a2 = torch.nn.functional.leaky_relu(h2, negative_slope=0.2)
        
        # Step 6-7: Linear 3 + LeakyReLU(0.2)
        h3 = self.linear3(a2)
        w = torch.nn.functional.leaky_relu(h3, negative_slope=0.2)
        
        # Step 8: Output shape is 128
        return w
```

**Parameters:**
*   Input dimension: 512 (typical for StyleGAN-based architectures) [S1].
*   Output dimension: 128 [S1].
*   Activation: LeakyReLU with $\alpha=0.2$ [S1].

**Edge Cases:**
*   If $z$ is not normalized, the linear layers may suffer from unstable gradients or saturation [S1].
*   The source does not specify the weight initialization scheme [S1].

## Subtopics

### Global Generator
A variant that maps the global latent code $z$ to a 2D grid of local latent codes $W$, representing the spatial layout of the scene [S1]. It is chosen when spatial variation of the latent code is required, unlike the standard Mapping Network which outputs a single vector [S1].
*   **Definition:** Maps $z$ to a grid $W$ of size $H \times W \times C$ [S1].
*   **Steps:**
    1.  Initialize with a learnable constant input tensor [S1].
    2.  Apply a $3 \times 3$ modulated convolution conditioned on $z$ [S1].
    3.  Apply LeakyReLU(0.2) [S1].
    4.  For subsequent layers, apply pairs of modulated convolutions. Each pair upsamples resolution by $2\times$ using a transposed convolution (stride 2) followed by bilinear filtering [S1].
    5.  Apply LeakyReLU(0.2) after each convolution [S1].
*   **Parameters:**
    *   Output resolution: $32 \times 32$ [S1]. This controls the spatial granularity of the local latent codes [S1].
    *   Channel depth: Starts at 256, ends at 32 [S1].
*   **Architecture Details:**
    *   Input: Constant tensor [S1].
    *   Layer 1: ModulatedConv ($3 \times 3$) $\rightarrow$ Output: $256 \times 4 \times 4$ [S1].
    *   Layer 2: ModulatedConv ($3 \times 3$) $\rightarrow$ Output: $256 \times 8 \times 8$ [S1].
    *   Layer 3: ModulatedConv ($3 \times 3$) $\rightarrow$ Output: $256 \times 8 \times 8$ [S1].
    *   Layer 4: ModulatedConv ($3 \times 3$) $\rightarrow$ Output: $256 \times 16 \times 16$ [S1].
    *   Layer 5: ModulatedConv ($3 \times 3$) $\rightarrow$ Output: $256 \times 16 \times 16$ [S1].
    *   Layer 6: ModulatedConv ($3 \times 3$) $\rightarrow$ Output: $256 \times 32 \times 32$ [S1].
    *   Layer 7: ModulatedConv ($3 \times 3$) $\rightarrow$ Output: $256 \times 32 \times 32$ [S1].
    *   Final Layer: Output: $32 \times 32 \times 32$ [S1].

## Operating characteristics
*   **Time Complexity:** The Mapping Network is a small MLP (3 linear layers), making it computationally inexpensive compared to the Global Generator [S1]. The Global Generator involves multiple convolutional layers, increasing cost [S1].
*   **Memory Complexity:** The Mapping Network stores weights for 3 linear layers ($512 \times 128 \times 3$). The Global Generator stores convolutional weights and the constant input tensor [S1].
*   **Strengths:** Global conditioning is simple and effective for encoding instance-level variations [S2, unofficial]. The Mapping Network ensures the latent code is in a suitable non-linear space for the decoder [S1].
*   **Limitations:** A single global code may struggle to encode complex spatial variations without the Global Generator [S1]. The Global Generator increases computational cost significantly compared to sampling at low resolution and refining [S1].
*   **When to use:** Use Global Conditioning (Mapping Network) for instance-specific variation. Use the Global Generator variant when spatial layout of latent codes is needed [S1].

## Background
Global conditioning was introduced in the context of unconstrained scene generation with locally conditioned radiance fields [S1]. The Mapping Network architecture is inspired by StyleGAN [24, 31] [S1]. The concept of global vs. local conditioning is discussed in broader neural field literature [S2, unofficial].
