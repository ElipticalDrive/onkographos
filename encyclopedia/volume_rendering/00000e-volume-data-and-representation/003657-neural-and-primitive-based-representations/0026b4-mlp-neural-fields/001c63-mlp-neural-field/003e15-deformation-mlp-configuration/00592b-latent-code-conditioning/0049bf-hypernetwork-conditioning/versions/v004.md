# HyperNetwork Conditioning

Also called: HyperNet Conditioning, Hypernetwork-based Conditioning

## Overview
HyperNetwork Conditioning is a method for conditioning a Neural Field decoder where a secondary network (the HyperNetwork) predicts the decoder's weights directly from a latent code [S1, unofficial]. Unlike concatenation-based conditioning which shares decoder parameters across all instances, this approach creates a distinct Neural Field for each input instance, allowing the primary decoder network to maintain lower complexity [S1, unofficial].

## How it works
**Inputs:**
1.  Query coordinate $x \in \Omega$ (spatial/temporal).
2.  Latent code $z \in \mathcal{Z}$ (instance-specific condition).

**Outputs:**
*   Signal value $y \in \mathcal{X}$ (e.g., density, color).

**Data Structures:**
*   **Decoder Network $D$**: A standard MLP parameterized by weights $W$. The weights are not fixed constants but are generated dynamically.
*   **HyperNetwork $H$**: A neural network that takes $z$ as input and outputs the weight tensor $W$.

**Steps:**
1.  **Encode Condition**: Obtain the latent code $z$ for the specific instance.
2.  **Generate Weights**: Pass $z$ through the HyperNetwork $H$ to predict the decoder weights $W$:
    $$ W = H(z) $$
    The HyperNetwork $H$ maps the latent vector $z$ to the flattened vector of all parameters in the decoder $D$.
3.  **Decode Signal**: Evaluate the decoder $D$ using the generated weights $W$ and the query coordinate $x$:
    $$ y = D_W(x) $$
    Here, $D_W$ denotes the decoder network with parameters fixed to $W$.

**Parameters:**
*   **HyperNetwork Architecture**: Not specified in sources. Typically an MLP.
*   **Decoder Architecture**: Not specified in sources.

**Edge Cases and Pitfalls:**
*   **Complexity**: While the decoder complexity can be lower, the total parameter count includes the HyperNetwork [S1, unofficial].
*   **Training Stability**: Predicting weights directly can be sensitive to initialization and learning rates compared to fixed-weight architectures [G].

## Subtopics

### Hybrid Conditioning
Hybrid Conditioning combines global and local latent codes. It uses one global code to encode basic information shared between instances and several local codes to encode instance-specific details [S1, unofficial]. This allows the model to capture both common structural features and unique variations simultaneously.

## Operating characteristics
*   **Complexity**: The primary network (decoder) complexity can be much lower than in shared-parameter models because it does not need to encode instance-specific variations in its weights [S1, unofficial].
*   **Flexibility**: Each instance gets a unique set of weights, providing a distinct Neural Field for each input [S1, unofficial].
*   **Comparison**: In concatenation-based conditioning, the same decoder parameters are shared across all input examples, and distinction between samples must be inferred from the latent conditioning code alone [S1, unofficial].

## Background
The method utilizes the concept of HyperNetworks [Ha et al., 2016], where a neural network predicts the parameters of another network. Recent research suggests that using HyperNetworks for Neural Fields can lead to more compact representations due to the reduced complexity of the primary network [Galanti & Wolf, 2020].
