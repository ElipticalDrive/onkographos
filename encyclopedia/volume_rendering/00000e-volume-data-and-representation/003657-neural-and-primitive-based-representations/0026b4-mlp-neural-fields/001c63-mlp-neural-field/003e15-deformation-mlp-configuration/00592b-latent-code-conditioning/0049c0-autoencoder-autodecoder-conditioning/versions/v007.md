# Autoencoder/Autodecoder Conditioning

Also called: Auto-decoder training setup for shape space learning, Conditional Neural Field, Latent vector optimization, Multi-shape architecture

## Overview
Autoencoder and Autodecoder conditioning are methods for representing multiple distinct instances (e.g., shapes or images) using a single shared neural field decoder $f_\theta$. The method maps each instance $i$ to a fixed-size latent vector $z_i \in \mathbb{R}^D$, which modulates the decoder to produce instance-specific outputs for query points $x$ [S1, unofficial][S2, unofficial]. Unlike sibling methods that may use hypernetworks or global conditioning vectors derived from external features, this approach explicitly optimizes or encodes a dedicated latent code per instance. The key distinction is the training regime: **Autodecoder** variants treat $z$ as a learnable parameter optimized jointly with the decoder weights for each instance, while **Autoencoder** variants use an encoder network to map instance data to $z$ [S2, unofficial]. This allows the shared decoder to learn a generalizable shape or signal manifold [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of training instances $J$. For each instance $j \in J$, input data may include point clouds, normals, or images.
*   **Output:** A shared decoder network $f_\theta$ and a set of latent codes $\{z_j\}_{j \in J}$. For a new query point $x$ and instance $j$, the output is $y = f_\theta(x, z_j)$.

**Data Structures:**
*   **Latent Code ($z_j$):** A vector of dimension $D$. Typical values are $D=256$ for shape space learning [S1, unofficial]. In reconstruction tasks where no shape space is learned, $L=0$ [S1, unofficial].
*   **Decoder Input:** Concatenation of the query coordinate $x \in \mathbb{R}^3$ and the latent code $z_j \in \mathbb{R}^D$. Input dimension is $3 + D$ [S1, unofficial].

**Network Architecture (Autodecoder Example):**
The decoder $f_\theta$ is a Multi-Layer Perceptron (MLP). A standard configuration [S1, unofficial] is:
1.  Input layer: $3 + L$ dimensions.
2.  Layer 1: Fully Connected (FC) + Softplus activation.
3.  Layer 2: FC + Softplus.
4.  Layer 3: FC + Softplus.
5.  Layer 4: FC + Softplus. **Skip connection** from input to this layer.
6.  Layer 5: FC (512 units) + Softplus.
7.  Layer 6: FC + Softplus.
8.  Output Layer: FC (final output dimension, e.g., 1 for SDF).

Activation function: Softplus, defined as $\text{softplus}(x) = \frac{1}{\beta} \ln(1 + e^{\beta x})$ with $\beta = 100$ [S1, unofficial].

**Optimization Steps:**
1.  **Initialization:** Initialize latent vectors $z_j \in \mathbb{R}^D$ to zero for all training examples $j \in J$ [S1, unofficial]. Initialize decoder weights $\theta$ randomly.
2.  **Loss Definition:** Define instance-specific loss $l(\theta, z_j)$ based on the task (e.g., Chamfer distance, SDF loss) [S1, unofficial].
3.  **Regularization:** Add an L2 norm penalty on the latent code to encourage similarity between shapes and prevent overfitting: $\mathcal{L}_l(z) = \|z\|_2$ [S3].
4.  **Training Loop:**
    For each batch $B \subset J$:
    a. Compute loss for each $j \in B$:
       $$ \mathcal{L}_{total} = \frac{1}{|B|} \sum_{j \in B} \left( l(\theta, z_j) + \alpha \|z_j\|_2 \right) $$
       where $\alpha = 0.01$ is the regularization weight [S1, unofficial].
    b. Update decoder weights $\theta$ and latent codes $z_j$ using gradient descent (e.g., Adam optimizer) [S1, unofficial].
5.  **Inference (Autodecoder):** For a test shape, optimize the latent vector $z$ from scratch using the loss $l$ for a fixed number of iterations (e.g., 800 iterations) [S1, unofficial].
6.  **Inference (Autoencoder):** Encode the test instance using the trained encoder $E$ to obtain $z = E(\text{instance})$, then query the decoder [S2, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.optim as optim

def softplus(x, beta=100):
    return (1 / beta) * torch.log(1 + torch.exp(beta * x))

class ConditionalDecoder(nn.Module):
    def __init__(self, latent_dim):
        super().__init__()
        self.latent_dim = latent_dim
        # Architecture: FC+ -> FC+ -> FC+ -> FC+ (skip) -> FC+ -> FC+ -> FC
        # Input dim: 3 (coords) + latent_dim
        self.fc1 = nn.Linear(3 + latent_dim, 512)
        self.fc2 = nn.Linear(512, 512)
        self.fc3 = nn.Linear(512, 512)
        self.fc4 = nn.Linear(512 + 3 + latent_dim, 512) # Skip connection adds input dim
        self.fc5 = nn.Linear(512, 512)
        self.fc6 = nn.Linear(512, 512)
        self.fc_out = nn.Linear(512, 1) # Output: SDF value or similar

    def forward(self, x, z):
        # x: [B, 3], z: [B, latent_dim]
        concat = torch.cat([x, z], dim=1)
        h = softplus(self.fc1(concat))
        h = softplus(self.fc2(h))
        h = softplus(self.fc3(h))
        h = softplus(self.fc4(torch.cat([h, concat], dim=1)))
        h = softplus(self.fc5(h))
        h = softplus(self.fc6(h))
        return self.fc_out(h)

def train_autodecoder(decoder, latent_codes, points, targets, optimizer, alpha=0.01, epochs=1000):
    decoder.train()
    for epoch in range(epochs):
        optimizer.zero_grad()
        # Forward pass
        preds = decoder(points, latent_codes)
        # Instance loss (e.g., L2 distance to target SDF)
        instance_loss = torch.mean((preds - targets) ** 2)
        # Latent regularizer
        reg_loss = torch.mean(torch.norm(latent_codes, dim=1))
        # Total loss
        loss = instance_loss + alpha * reg_loss
        loss.backward()
        optimizer.step()
    return decoder, latent_codes

def infer_autodecoder(decoder, points, targets, latent_dim, num_iter=800, lr=1e-4):
    """Optimize latent code for a single test instance."""
    decoder.eval()
    z = torch.zeros(1, latent_dim, requires_grad=True)
    optimizer = optim.Adam([z], lr=lr)
    
    for _ in range(num_iter):
        optimizer.zero_grad()
        pred = decoder(points, z)
        loss = torch.mean((pred - targets) ** 2)
        loss.backward()
        optimizer.step()
    return z.detach()
```

## Subtopics

### Latent Code Regularizer
An L2 norm regularizer applied to the latent codes in the autodecoder framework. It penalizes large magnitudes of $z$, keeping codes close to zero and ensuring similarity between different shapes in the learned space [S3]. A typical weight is $\alpha = 0.01$ [S1, unofficial]. A pitfall is that SDF and DDF (Directional Distance Function) models may share the same latent code for a given shape, requiring careful loss weighting if trained jointly [S3].

## Operating characteristics
*   **Time Complexity:** Training time scales with the number of instances and the depth of the MLP. Inference for autodecoders requires iterative optimization (e.g., 800 iterations) per test shape, making it slower than autoencoders or direct prediction methods [S1, unofficial].
*   **Memory Complexity:** Requires storing one latent vector $z_j$ per instance. For $N$ instances and dimension $D$, memory is $O(N \cdot D)$. The decoder weights are shared $O(1)$ relative to $N$.
*   **Strengths:** Enables learning a continuous shape space; allows interpolation between shapes by interpolating latent codes [S1, unofficial]; robust to varying input resolutions.
*   **Limitations:** Slow inference for autodecoders due to per-shape optimization; requires careful tuning of regularization $\alpha$ to balance shape fidelity and latent space smoothness.
*   **When to use:** When learning a manifold of shapes or when the number of instances is moderate and inference latency is not critical. Use autoencoder variant if fast inference is needed.

## Background
The autodecoder setup was popularized by Park et al. (2019) for learning implicit geometric representations [S1, unofficial]. It builds on the concept of neural fields where a single network represents a signal, extended to multi-instance scenarios by introducing instance-specific latent codes. The method has been used for shape reconstruction, shape space learning (e.g., on D-Faust dataset), and inverse rendering [S1, unofficial][S3].
