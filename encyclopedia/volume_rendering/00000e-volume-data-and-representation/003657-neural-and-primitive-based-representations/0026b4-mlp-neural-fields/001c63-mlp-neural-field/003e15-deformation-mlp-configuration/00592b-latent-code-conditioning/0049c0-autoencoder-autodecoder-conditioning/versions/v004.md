# Autoencoder/Autodecoder Conditioning

Also called: Auto-decoder training setup for shape space learning, Conditional Neural Field, Latent vector optimization, Multi-shape architecture

## Overview
Autoencoder/Autodecoder Conditioning is a method for representing multiple distinct shapes or instances using a single shared neural field by associating each instance with a unique learnable latent vector [S1, unofficial][S2, unofficial]. It solves the problem of generalizing neural fields to multi-shape datasets where a single global parameter set cannot capture diverse geometries [S2, unofficial]. It differs from Concatenation Conditioning by optimizing the latent code as a separate learnable parameter per instance rather than concatenating it as input to a static encoder, and from HyperNetwork Conditioning by using a fixed decoder architecture rather than generating weights dynamically [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of training examples $J$ (e.g., point clouds or meshes). For each example $j$, a latent vector $z_j \in \mathbb{R}^D$ is associated.
*   **Output:** A neural field $f(x; \theta, z_j)$ that maps 3D coordinates $x$ to volumetric properties (e.g., SDF, density) conditioned on $z_j$ [S1, unofficial][S2, unofficial].

**Data Structures:**
*   **Latent Vector ($z_j$):** A learnable tensor of size $D$. In shape reconstruction, $D=0$ (no latent code) or effectively bypassed; in shape space learning, $D=256$ [S1, unofficial].
*   **Neural Field ($f$):** An MLP with parameters $\theta$. The input dimension is $3 + L$, where $L$ is the latent vector size [S1, unofficial].

**Network Architecture:**
The decoder MLP consists of fully connected (FC) layers.
*   **Activation:** `FC+` denotes a fully connected linear layer followed by a Softplus activation. `FC` is a linear layer without activation [S1, unofficial].
*   **Softplus Formula:** $\text{Softplus}(x) = \frac{1}{\beta} \ln(1 + e^{\beta x})$ with $\beta = 100$ [S1, unofficial].
*   **Layer Sequence:**
    1.  Input ($3+L$) $\to$ `FC+`
    2.  `FC+`
    3.  `FC+`
    4.  `FC+` (Skip connection from input connects here)
    5.  `512` (Linear layer, no activation specified, likely ReLU or similar standard, but source lists "512" as a layer type distinct from FC/FC+; assuming linear projection to 512 units)
    6.  `FC+`
    7.  `FC+`
    8.  `FC` (Output layer)
    *Note: The source describes the sequence as "FC+ → FC+ → FC+ → FC+ → 512 → FC+ → FC+ → FC" with a skip connection to the 4th layer [S1, unofficial].*

**Algorithm Steps:**

1.  **Initialization:** For each training example $j \in J$, initialize the latent vector $z_j \in \mathbb{R}^{256}$ to zero [S1, unofficial].
2.  **Batch Sampling:** Sample a batch $B \subset J$ of training examples.
3.  **Forward Pass:** For each $j \in B$, query the neural field $f(x; \theta, z_j)$ at sampled coordinates $x$ to predict volumetric properties.
4.  **Loss Computation:** Compute the loss $\mathcal{L}$ for the batch:
    $$ \mathcal{L} = \frac{1}{|B|} \sum_{j \in B} \ell(\theta, z_j) + \alpha \|z_j\|_2 $$
    Where:
    *   $\ell(\theta, z_j)$ is the task-specific loss (e.g., SDF loss, depth loss, silhouette loss) defined in the parent context or specific application [S1, unofficial][S3].
    *   $\|z_j\|_2$ is the L2 norm of the latent vector, acting as a regularizer [S3].
    *   $\alpha = 0.01$ is the regularization weight [S1, unofficial].
5.  **Optimization:** Update both the network weights $\theta$ and the latent vectors $z_j$ using an optimizer (e.g., Adam) to minimize $\mathcal{L}$ [S1, unofficial].
6.  **Inference (Test Time):** For a new test shape, the latent vector $z$ is not provided. Instead, perform optimization of $z$ for 800 iterations using the loss $\ell$ (with fixed $\theta$) to find the best reconstruction [S1, unofficial].

**Pitfalls:**
*   **Shared Latent Codes:** In some frameworks (e.g., FIRe), SDF and DDF models for the same shape share the same latent code $z$, which may constrain the representation if the two fields require distinct features [S3].
*   **Precision:** Initializing $z_j$ to zero is critical for stability in the autodecoder setup [S1, unofficial].

## Subtopics

### Latent Code Regularizer
A specific regularization term $\mathcal{L}_l(z) = \|z\|_2$ applied to the latent codes in the autodecoder framework [S3]. It penalizes large magnitudes to keep latent codes close to zero, ensuring similarity between different shapes in the learned space [S3]. It is used to prevent overfitting to individual shapes and encourage a compact latent space [S3].

### Auto-Decoder Network Architecture
The specific MLP structure used to process the concatenated input $(x, z)$ [S1, unofficial]. It uses Softplus activations ($\beta=100$) and skip connections from the input to the 4th layer [S1, unofficial]. The latent dimension $L$ is 0 for single-shape reconstruction (effectively removing conditioning) and 256 for shape space learning [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training requires joint optimization of network weights and latent vectors. Inference for a new shape requires iterative optimization of $z$ (e.g., 800 iterations), making it slower than encoder-based methods [S1, unofficial].
*   **Memory Complexity:** Stores one latent vector $z_j$ per shape in the dataset. For $N$ shapes and dimension $D$, memory is $O(N \cdot D)$ [S1, unofficial].
*   **Strengths:** Enables learning a continuous shape space; allows interpolation of shapes by interpolating latent vectors [S1, unofficial].
*   **Limitations:** Requires per-shape optimization at test time; sensitive to initialization [S1, unofficial].
*   **When to use:** When learning a manifold of shapes from a dataset and interpolation is desired [S1, unofficial].
*   **When not to use:** When real-time inference for unseen shapes is required without optimization [S1, unofficial].

## Background
Originated in the context of implicit geometric regularization for learning shapes, specifically the "auto-decoder" setup described by Park et al. (2019) [S1, unofficial]. It was applied to tasks such as shape reconstruction from point clouds and learning shape spaces from raw scans (e.g., D-Faust dataset) [S1, unofficial]. The approach contrasts with encoder-based methods by optimizing latent codes directly rather than predicting them [S2, unofficial].
