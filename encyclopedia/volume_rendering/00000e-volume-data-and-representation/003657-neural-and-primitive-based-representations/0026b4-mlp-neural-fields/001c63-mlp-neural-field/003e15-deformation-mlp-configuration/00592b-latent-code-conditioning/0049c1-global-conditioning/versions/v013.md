# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data instance into a single latent vector $z$, which modulates a shared neural field decoder [S2, unofficial]. It is distinguished from local conditioning, where information is distributed across multiple latent codes assigned to specific spatial regions or time steps [S2, unofficial]. This method serves as the foundational injection mechanism for instance-specific features in neural radiance fields and implicit representations.

## How it works
**Inputs and Outputs:**
*   **Input:** A global latent code $z \in \mathbb{R}^D$.
*   **Output:** A transformed latent representation used to modulate the decoder. The output dimension is typically 128 [S1].

**Data Structures:**
The implementation uses a standard Multi-Layer Perceptron (MLP) structure. No complex data structures are required beyond the latent vector itself.

**Steps:**
1.  **Normalization:** Normalize the input latent code $z$. The specific normalization technique (e.g., LayerNorm, InstanceNorm) is not explicitly defined in the primary source, but is a prerequisite step [S1]. [G] Standard practice suggests LayerNorm or InstanceNorm for stability.
2.  **Linear Transformation:** Pass the normalized $z$ through three sequential linear layers.
3.  **Activation:** Apply LeakyReLU with a negative slope of 0.2 after each linear layer.
4.  **Result:** The final output has a shape of 128 [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class GlobalConditioningNetwork(nn.Module):
    def __init__(self, input_dim: int = 512, output_dim: int = 128):
        super().__init__()
        # Three linear layers as specified in [S1]
        self.linear1 = nn.Linear(input_dim, output_dim)
        self.linear2 = nn.Linear(output_dim, output_dim)
        self.linear3 = nn.Linear(output_dim, output_dim)
        
        # LeakyReLU with negative slope 0.2
        self.activation = nn.LeakyReLU(negative_slope=0.2)
        
        # Normalization layer. Specific type not given in [S1].
        # [G] Using LayerNorm as a standard default for latent codes.
        self.norm = nn.LayerNorm(input_dim)

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        """
        Maps global latent code z to an intermediate non-linear latent space.
        
        Args:
            z: Global latent code of shape (..., input_dim)
            
        Returns:
            Transformed latent code of shape (..., output_dim)
        """
        # Step 1: Normalize input
        z_norm = self.norm(z)
        
        # Step 2 & 3: Linear layers with LeakyReLU(0.2)
        x = self.activation(self.linear1(z_norm))
        x = self.activation(self.linear2(x))
        x = self.activation(self.linear3(x))
        
        return x
```

**Parameters:**
*   **Input Dimension ($D$):** Typically 64, 256, or 512 [S2, unofficial].
*   **Output Dimension:** 128 [S1].
*   **Activation:** LeakyReLU(0.2) [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** Standard float32 is sufficient.
*   **Boundaries:** The normalization step handles varying scales of $z$.

## Subtopics

### Global Generator
A variant that maps a single global latent code $z$ to a 2D grid of local latent codes $W$, representing the spatial layout of the scene [S1]. It is chosen when spatial variation of latent features is required, unlike standard global conditioning which produces a single vector.

**Definition:**
Maps a single global latent code $z$ to a 2D grid of local latent codes $W$ [S1].

**Steps:**
1.  **Initialization:** Initialize with a constant input tensor (learned parameters), following StyleGAN [S1].
2.  **First Layer:** Apply a $3 \times 3$ modulated convolutional layer conditioned on $z$.
3.  **Upsampling:** For subsequent pairs of layers, upsample the feature map resolution by $2\times$ using a transposed convolution with stride 2, followed by bilinear filtering [S1].
4.  **Activation:** Apply LeakyReLU(0.2) after each convolutional layer [S1].
5.  **Output:** The final grid $W$ has a spatial resolution of $32 \times 32$ [S1].

**Parameters:**
*   **Output Resolution:** $32 \times 32$ [S1]. This hyperparameter controls the size of the spatial region represented by each individual local latent code.
*   **Channels:** The intermediate channel count is 256 for most layers, reducing to 32 in the final layer (see Table 8 in [S1]).

**Pseudocode:**
```python
import torch
import torch.nn as nn

class GlobalGenerator(nn.Module):
    def __init__(self, z_dim: int = 512, output_res: int = 32):
        super().__init__()
        # [G] Assuming standard modulated conv implementation details 
        # are handled by a helper, but structure follows [S1].
        
        # Constant input initialization
        self.constant_input = nn.Parameter(torch.randn(1, 256, 4, 4))
        
        # First layer: 3x3 modulated conv
        self.conv1 = ModulatedConv2d(256, 256, kernel_size=3, z_dim=z_dim)
        
        # Subsequent layers: Upsample by 2x using transposed conv + bilinear filter
        # Layers 2-3: 4x4 -> 8x8
        self.conv2 = ModulatedConv2d(256, 256, kernel_size=3, z_dim=z_dim)
        self.conv3 = ModulatedConv2d(256, 256, kernel_size=3, z_dim=z_dim)
        
        # Layers 4-5: 8x8 -> 16x16
        self.conv4 = ModulatedConv2d(256, 256, kernel_size=3, z_dim=z_dim)
        self.conv5 = ModulatedConv2d(256, 256, kernel_size=3, z_dim=z_dim)
        
        # Layers 6-7: 16x16 -> 32x32
        self.conv6 = ModulatedConv2d(256, 256, kernel_size=3, z_dim=z_dim)
        self.conv7 = ModulatedConv2d(256, 32, kernel_size=3, z_dim=z_dim) # Final channel reduction
        
        self.activation = nn.LeakyReLU(negative_slope=0.2)
        
        # Bilinear upsampling kernel
        self.bilinear_filter = nn.Upsample(scale_factor=2, mode='bilinear', align_corners=False)

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        """
        Maps global latent code z to a 2D grid of local latent codes W.
        
        Args:
            z: Global latent code of shape (..., z_dim)
            
        Returns:
            Grid W of shape (..., 32, 32, 32)
        """
        x = self.constant_input
        
        # First layer
        x = self.conv1(x, z)
        x = self.activation(x)
        
        # Pair 1: Upsample 4x4 -> 8x8
        x = self.bilinear_filter(x)
        x = self.conv2(x, z)
        x = self.activation(x)
        x = self.conv3(x, z)
        x = self.activation(x)
        
        # Pair 2: Upsample 8x8 -> 16x16
        x = self.bilinear_filter(x)
        x = self.conv4(x, z)
        x = self.activation(x)
        x = self.conv5(x, z)
        x = self.activation(x)
        
        # Pair 3: Upsample 16x16 -> 32x32
        x = self.bilinear_filter(x)
        x = self.conv6(x, z)
        x = self.activation(x)
        x = self.conv7(x, z)
        x = self.activation(x)
        
        return x

# [G] Placeholder for ModulatedConv2d which is not standard PyTorch.
# In practice, this would be implemented using affine transformations 
# of weights and biases conditioned on z, as described in StyleGAN [S1].
class ModulatedConv2d(nn.Module):
    def __init__(self, in_channels, out_channels, kernel_size, z_dim):
        super().__init__()
        self.weight = nn.Parameter(torch.randn(out_channels, in_channels, kernel_size, kernel_size))
        self.bias = nn.Parameter(torch.zeros(out_channels))
        # [G] Simplified modulation logic. Real implementation uses z to 
        # generate scale and shift for weights/biases.
        
    def forward(self, x, z):
        # [G] Placeholder for actual modulation logic
        return nn.functional.conv2d(x, self.weight, self.bias)
```

## Operating characteristics
*   **Time Complexity:** The mapping network is $O(D \cdot L)$ where $L$ is the number of layers (3) and $D$ is the latent dimension. The global generator is $O(R^2 \cdot C^2 \cdot K^2)$ where $R$ is resolution, $C$ is channels, and $K$ is kernel size.
*   **Memory Complexity:** The mapping network requires minimal memory. The global generator requires memory proportional to the output grid size ($32 \times 32 \times 32$ in the example) [S1].
*   **Strengths:** Global conditioning is simple to implement and efficient for single-instance encoding. The global generator allows for spatially varying features without increasing the number of decoder parameters.
*   **Limitations:** The global generator has significantly higher computational cost compared to sampling at low resolution and applying refinement blocks [S1]. It requires careful tuning of the output resolution hyperparameter.

## Background
Global conditioning was introduced in the context of unconstrained scene generation with locally conditioned radiance fields [S1]. The mapping network architecture follows standard practices from StyleGAN [S1][S2, unofficial]. The concept of global vs. local conditioning is discussed in broader introductions to neural fields [S2, unofficial].
