# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data sample into a single latent vector $z$ [S2, unofficial]. It maps this global code to an intermediate non-linear latent space to modulate the neural field [S1]. It differs from [Concatenation Conditioning](12582-concatenation-conditioning.md) by injecting information via modulation rather than concatenation, and from [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md) by generating modulation parameters through a dedicated mapping network rather than a weight-generating network [S1].

## How it works
**Inputs and Outputs:**
- Input: Global latent code $z \in \mathbb{R}^D$.
- Output: Intermediate latent representation $z' \in \mathbb{R}^{128}$ (for the standard mapping network).

**Data Structures:**
- $z$: Vector of dimension $D$.
- $z'$: Vector of dimension 128.

**Steps:**
1. Normalize the input $z$. [S1]
2. Pass $z$ through three sequential linear layers. [S1]
3. Apply LeakyReLU(0.2) activation after each linear layer. [S1]

**Pseudocode:**
```python
def mapping_network(z):
    # Step 1: Normalize input z
    # [G] Assuming standard normalization (e.g., LayerNorm or normalization to unit sphere)
    z = normalize(z)
    
    # Step 2 & 3: Three linear layers with LeakyReLU(0.2)
    # [G] Weights and biases are learned parameters, not defined in source
    z = linear_layer_1(z)
    z = leaky_relu(z, negative_slope=0.2)
    
    z = linear_layer_2(z)
    z = leaky_relu(z, negative_slope=0.2)
    
    z = linear_layer_3(z)
    z = leaky_relu(z, negative_slope=0.2)
    
    return z
```

**Parameters:**
- Output dimension: 128 [S1].
- Activation: LeakyReLU with negative slope 0.2 [S1].

**Edge Cases and Pitfalls:**
- The normalization step is critical for stable training but the specific normalization method (e.g., LayerNorm vs. normalization to unit norm) is not explicitly defined in the source beyond the term "Normalize" [S1].

## Subtopics

### Global Generator
Maps a single global latent code $z$ to a 2D grid of local latent codes $W$ representing the spatial layout of the scene [S1]. It uses successive modulated convolutional layers conditioned on $z$ [S1]. The first layer uses a constant input and a 3×3 modulated convolution [S1]. Subsequent pairs upsample resolution by 2× using a transposed convolution (stride 2) followed by bilinear filtering [S1]. LeakyReLU(0.2) is applied after each convolution [S1]. The output resolution is a hyperparameter, typically set to 32×32 [S1].

## Background
Originated in the context of unconstrained scene generation with locally conditioned radiance fields [S1]. The mapping network concept is based on StyleGAN [S1][S2, unofficial].
