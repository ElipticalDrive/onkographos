# HyperNetwork Conditioning

Also called: Hypernetwork-based conditioning, HyperNet conditioning

## Overview
HyperNetwork Conditioning generates a unique set of weights for the Neural Field decoder for each input instance by using a secondary network (the HyperNetwork) to predict these parameters from a latent code [S1, unofficial]. Unlike Concatenation Conditioning, which shares decoder weights across all instances and relies on the latent code to distinguish them, this method creates a distinct Neural Field per instance, potentially allowing the primary decoder network to have lower complexity [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Spatial coordinate $x \in \Omega$ and latent code $z \in \mathcal{Z}$.
- Output: Field value $v \in \mathcal{X}$ (e.g., density, color).

**Data Structures:**
- Primary Network ($N_{primary}$): The Neural Field decoder. Its weights $W$ are not fixed constants but are generated dynamically.
- HyperNetwork ($N_{hyper}$): A neural network that takes $z$ as input and outputs the weight tensors $W$ for $N_{primary}$.

**Steps:**
1. Encode the input instance into a latent code $z$ (via an encoder or optimization) [S1, unofficial].
2. Pass $z$ through the HyperNetwork $N_{hyper}$ to generate the weight parameters $W$ for the primary network:
   $$ W = N_{hyper}(z) $$
3. Evaluate the primary network using the generated weights and the spatial coordinate:
   $$ v = N_{primary}(x; W) $$

**Parameters:**
- The architecture of $N_{hyper}$ and $N_{primary}$ is not specified in the sources.
- The dimensionality of $z$ is not specified.

**Edge Cases and Pitfalls:**
- The sources note that this approach hints at a more compact representation because the primary network complexity can be lower [S1, unofficial].
- Precision issues related to the generation of weights are not detailed.

**Pseudocode:**
```python
def hypernetwork_conditioning(x, z, hyper_net, primary_net):
    """
    x: spatial coordinate
    z: latent code
    hyper_net: function mapping z -> weights W
    primary_net: function mapping (x, W) -> value v
    """
    # Generate weights for the primary network based on the latent code
    W = hyper_net(z)
    
    # Evaluate the primary network with the generated weights
    v = primary_net(x, W)
    
    return v
```

## Subtopics

### Hybrid Conditioning
Uses one global code to encode basic information shared between instances and several local codes to encode instance-specific details [S1, unofficial]. This combines global consistency with local variation.

## Operating characteristics
- **Complexity:** The primary network complexity can be much lower compared to concatenation-based methods, suggesting a more compact representation [S1, unofficial].
- **Performance:** Specific performance metrics, hardware, or resolution data are not provided in the sources.
- **Scaling:** Not given in the sources.
- **Strengths:** Allows for a different Neural Field for each input instance, potentially reducing the burden on the primary network's capacity to encode instance-specific variations [S1, unofficial].
- **Limitations:** Requires the HyperNetwork to accurately predict valid weights for the primary network.

## Background
The concept utilizes HyperNetworks, originally introduced by Ha et al. in 2016 [S1, unofficial]. Recent basic research in the area of HyperNetworks suggests that the complexity of the primary network can be significantly reduced when used in this context [S1, unofficial].
