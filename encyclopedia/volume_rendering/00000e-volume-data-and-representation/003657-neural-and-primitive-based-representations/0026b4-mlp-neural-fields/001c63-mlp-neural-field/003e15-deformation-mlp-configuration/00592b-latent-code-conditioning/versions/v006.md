# Latent Code Conditioning

Also called: Conditional Neural Fields, Instance-Specific Neural Fields

## Overview
Latent Code Conditioning enables a single Neural Field architecture to represent multiple distinct data instances (e.g., different volumes, scenes, or objects) by injecting instance-specific information via a latent vector $z$ [S1, unofficial]. It solves the problem of parameter sharing across heterogeneous data by allowing the network to adapt its output based on $z$ without requiring separate weight sets for each instance [S1, unofficial]. It differs from **Multi-MLP Linear Layer** [15116-multi-mlp-linear-layer.md], which uses fixed linear projections for different modalities, and **Spatial-Ratio Neural Field Configuration** [16086-spatial-ratio-neural-field-configuration.md], which conditions on spatial coordinates directly, by relying on a global or local latent code to encode instance identity [S1, unofficial].

## Shared principles
The core mechanism involves extending the standard Neural Field mapping $f: \Omega \mapsto \mathcal{X}$ to accept an additional input from a latent space $\mathcal{Z}$, resulting in $f: (\Omega, \mathcal{Z}) \mapsto \mathcal{X}$ [S1, unofficial]. The latent code $z \in \mathcal{Z}$ is typically a low-dimensional vector (e.g., length 512) [S1, unofficial]. This code is derived either from an encoder processing the input data (autoencoder setting) or optimized directly as a learnable parameter per instance (autodecoder setting) [S1, unofficial]. The conditioning is applied by combining $z$ with the spatial input $x$ or intermediate features, allowing the network to distinguish between instances [S1, unofficial].

## Subtopics

### [Concatenation Conditioning](12582-concatenation-conditioning.md)
Concatenation Conditioning injects global latent information by appending the latent code $z$ to the input feature vector before the first decoder layer. It is chosen when a simple, weight-sharing decoder is preferred over generating unique weights per instance. It differs from HyperNetwork Conditioning by sharing decoder weights and from Global Conditioning by explicitly combining inputs at the network boundary rather than just encoding the sample globally.

### [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md)
HyperNetwork Conditioning generates a unique set of weights for the Neural Field decoder for each input instance using a secondary HyperNetwork. It is chosen when instance-specific complexity varies significantly, potentially allowing the primary decoder to be smaller. It differs from Concatenation Conditioning by creating a distinct Neural Field per instance rather than sharing weights.

### [Global Conditioning](12589-global-conditioning.md)
Global conditioning encodes the entire information of a data sample into a single latent vector $z$. It serves as the primary input to a mapping network that transforms $z$ into an intermediate non-linear latent space suitable for conditioning the radiance field. It differs from Local Conditioning by representing global properties (e.g., scene identity) rather than distributing information across spatial coordinates.

### Autoencoder/Autodecoder Conditioning
*   **Step:** Train the model in an autoencoder manner (using an encoder to produce latent codes) or an autodecoder manner (optimizing a learnable latent vector per sample jointly with decoder weights) [S1, unofficial].

### Local Conditioning
*   **Definition:** Spreading information about a data sample over multiple latent codes assigned to specific subsets of spatio-temporal coordinates (regions or time steps) [S1, unofficial].

### Dynamic Object Radiance Field Conditioning
*   **Definition:** A radiance field $\psi$ for dynamic objects conditioned by separate shape and appearance latent vectors [S2].
*   **Step:** Concatenate a shape code with the input coordinate $x$ at the network input [S2]. Concatenate an appearance code with the direction $d$ at the bottleneck after density prediction [S2]. Concatenate sequence and object appearance latent vectors to propagate sequence appearance to individual objects [S2].

### Image Encoding
*   **Definition:** Passes the appearance source image $A$ through a network to generate a latent code, which is then appended to the input voxels [S3].
*   **Comparison:** Captures overall color but fails to assign it correctly to individual parts [S3].

## Background
The concept of conditioning Neural Fields on latent codes was introduced to extend single-image overfitting to multi-image representation [S1, unofficial]. The foundational work describes both autoencoder and autodecoder formulations, where the decoder accepts coordinates and a latent code from $\mathcal{Z}$ [S1, unofficial]. Global conditioning was explicitly named to distinguish it from local conditioning strategies [S1, unofficial]. Later works applied these principles to dynamic urban environments, using separate shape and appearance codes for radiance fields [S2]. Image-based conditioning variants were also explored in neural voxel rendering, noting limitations in texture assignment [S3].
