# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entire information of a data sample into a single latent vector $z \in \mathbb{R}^D$, which is then used to condition the neural field [S2, unofficial]. It serves as the foundational mechanism for instance-specific representation in latent code conditioning, distinguishing itself from local conditioning methods that distribute information across spatial or temporal regions [S2, unofficial]. It is typically implemented via a mapping network that transforms the raw latent code into a non-linear latent space suitable for downstream conditioning [S1].

## How it works
**Inputs and outputs:**
- Input: Global latent code $z \in \mathbb{R}^D$.
- Output: Transformed latent code $z' \in \mathbb{R}^{128}$ (for the standard mapping network) or a spatial grid of local latent codes $W$ (for the global generator variant).

**Data structures:**
- The mapping network uses a sequence of linear transformations.
- The global generator uses a 2D tensor representing a grid of local latent codes.

**Steps:**
1. **Normalization:** The input latent code $z$ is normalized. The specific normalization method (e.g., layer norm, instance norm) is not detailed in the sources [G].
2. **Linear Projection:** The normalized $z$ is passed through three consecutive linear layers.
3. **Activation:** After each linear layer, a LeakyReLU activation with a negative slope of 0.2 is applied.
4. **Output:** The final output has a dimensionality of 128.

**Pseudocode for Mapping Network:**
```python
import torch
import torch.nn as nn

class MappingNetwork(nn.Module):
    def __init__(self, input_dim: int):
        super().__init__()
        # Three linear layers, each outputting 128 dimensions
        self.linear1 = nn.Linear(input_dim, 128)
        self.linear2 = nn.Linear(128, 128)
        self.linear3 = nn.Linear(128, 128)
        
    def forward(self, z: torch.Tensor) -> torch.Tensor:
        # Step 1: Normalize input z
        # Note: Specific normalization technique not specified in sources [G]
        z = normalize(z) 
        
        # Step 2 & 3: Linear layers with LeakyReLU(0.2)
        x = self.linear1(z)
        x = torch.nn.functional.leaky_relu(x, negative_slope=0.2)
        
        x = self.linear2(x)
        x = torch.nn.functional.leaky_relu(x, negative_slope=0.2)
        
        x = self.linear3(x)
        x = torch.nn.functional.leaky_relu(x, negative_slope=0.2)
        
        # Step 4: Output shape is 128
        return x
```

**Parameters:**
- Output dimension: 128 [S1].
- Activation: LeakyReLU with negative slope 0.2 [S1].

**Edge cases and pitfalls:**
- The normalization step is critical but unspecified in the source [G]. Implementers must choose a standard normalization (e.g., LayerNorm) and ensure it is consistent with the training setup.
- The input dimension $D$ is not fixed by the mapping network architecture itself but is determined by the upstream latent code generation (typically 512, though 64 or 256 are used) [S2, unofficial].

## Subtopics

### Global Generator
A variant that maps a single global latent code $z$ to a 2D grid of local latent codes $W$, representing the spatial layout of the scene [S1]. It is chosen when spatial variation of the latent code is required, unlike the standard mapping network which outputs a single vector [S1].

**Definition:** Maps $z$ to a 2D grid $W$ [S1].

**Steps:**
1. Initialize with a constant input tensor [S1].
2. Apply a 3×3 modulated convolutional layer conditioned on $z$ [S1].
3. For subsequent layers, apply pairs of modulated convolutions. Each pair upsamples the resolution by 2× using a transposed convolution (stride 2) followed by bilinear filtering [S1].
4. Apply LeakyReLU(0.2) after each convolution [S1].

**Parameters:**
- Output resolution: 32×32 [S1]. This controls the spatial granularity of the local latent codes [S1].
- Channel depth: 256 for intermediate layers, reducing to 32 at the final output layer [S1].

**Pseudocode for Global Generator:**
```python

    def __init__(self, latent_dim: int, output_res: int = 32):
        super().__init__()
        # Constant input initialization
        self.constant_input = nn.Parameter(torch.randn(1, 256, 4, 4))
        
        # First modulated conv (3x3)
        self.conv1 = ModulatedConv2d(256, 256, kernel_size=3, latent_dim=latent_dim)
        
        # Upsampling pairs
        # 4x4 -> 8x8
        self.conv2 = ModulatedConv2d(256, 256, kernel_size=3, latent_dim=latent_dim)
        self.conv3 = ModulatedConv2d(256, 256, kernel_size=3, latent_dim=latent_dim)
        
        # 8x8 -> 16x16
        self.conv4 = ModulatedConv2d(256, 256, kernel_size=3, latent_dim=latent_dim)
        self.conv5 = ModulatedConv2d(256, 256, kernel_size=3, latent_dim=latent_dim)
        
        # 16x16 -> 32x32
        self.conv6 = ModulatedConv2d(256, 32, kernel_size=3, latent_dim=latent_dim)
        self.conv7 = ModulatedConv2d(32, 32, kernel_size=3, latent_dim=latent_dim)
        
    def forward(self, z: torch.Tensor) -> torch.Tensor:
        x = self.constant_input
        x = self.conv1(x, z)
        x = torch.nn.functional.leaky_relu(x, negative_slope=0.2)
        
        x = self.conv2(x, z)
        x = torch.nn.functional.leaky_relu(x, negative_slope=0.2)
        x = torch.nn.functional.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False)
        
        x = self.conv3(x, z)
        x = torch.nn.functional.leaky_relu(x, negative_slope=0.2)
        x = torch.nn.functional.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False)
        
        x = self.conv4(x, z)
        x = torch.nn.functional.leaky_relu(x, negative_slope=0.2)
        x = torch.nn.functional.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False)
        
        x = self.conv5(x, z)
        x = torch.nn.functional.leaky_relu(x, negative_slope=0.2)
        x = torch.nn.functional.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False)
        
        x = self.conv6(x, z)
        x = torch.nn.functional.leaky_relu(x, negative_slope=0.2)
        x = torch.nn.functional.interpolate(x, scale_factor=2, mode='bilinear', align_corners=False)
        
        x = self.conv7(x, z)
        x = torch.nn.functional.leaky_relu(x, negative_slope=0.2)
        
        return x
```

## Operating characteristics
- **Time Complexity:** The mapping network is computationally lightweight, consisting only of linear layers [S1]. The global generator is significantly more expensive due to convolutional operations and upsampling [S1].
- **Memory Complexity:** The mapping network requires minimal memory [S1]. The global generator requires memory proportional to the output grid size ($32 \times 32 \times C$) [S1].
- **Strengths:** Global conditioning provides a compact, instance-specific representation [S2, unofficial]. The global generator variant allows for spatially varying details [S1].
- **Limitations:** The global generator's computational cost is significantly higher than low-resolution sampling with refinement blocks [S1].
- **When to use:** Use the standard mapping network for global instance conditioning. Use the global generator when spatial layout of latent codes is needed [S1].

## Background
