# Concatenation Conditioning

Also called: Latent Code Concatenation

## Overview
Concatenation Conditioning is a method for injecting latent codes into Neural Fields by appending the latent vector to the input features or descriptors before processing [S1][S2, unofficial]. It solves the problem of enabling a single neural network to represent multiple distinct instances or conditions (such as different transfer functions or volume modalities) by providing global context alongside local spatial data [S1][S2, unofficial]. It is distinguished from [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md) and [Global Conditioning](12589-global-conditioning.md) by its simplicity: it modifies the input tensor directly rather than predicting weights or modulating intermediate features [S2, unofficial].

## How it works
**Inputs:**
1.  **Spatial Input ($x$):** Coordinates or features from the domain $\Omega$ (e.g., 3D position).
2.  **Latent Code ($z$):** A low-dimensional vector from latent space $\mathcal{Z}$, typically of length 512 [S1][S2, unofficial]. This code is extracted via an encoder or optimized as a learnable parameter [S1][S2, unofficial].
3.  **Explicit Descriptor ($d$):** Optional explicit features (e.g., Transfer Function descriptor) if the method conditions on external parameters [S1].

**Outputs:**
*   Predicted value $y \in \mathcal{X}$ (e.g., illumination, density, color) conditioned on both $x$ and $z$ [S1][S2, unofficial].

**Data Structures:**
*   **Latent Vector:** Fixed-size 1D tensor of length 512 [S1].
*   **Concatenated Tensor:** A 1D tensor formed by joining $z$ and $d$ (or $x$). If $d$ is present, the input to the decoder is $[d; z]$ [S1]. If conditioning on spatial input directly, the input is $[x; z]$ [S2, unofficial].

**Steps:**
1.  **Encode:** Process the input volume or instance data with an encoder network to extract the latent vector $z$ [S1].
2.  **Concatenate:** Append the latent vector $z$ to the relevant input descriptor.
    *   If conditioning on Transfer Function (TF): Concatenate $z$ with the TF descriptor $d$ to form $c = [d; z]$ [S1].
    *   If conditioning on spatial input: Concatenate $z$ with the spatial coordinate $x$ to form $c = [x; z]$ [S2, unofficial].
3.  **Decode:** Feed the concatenated tensor $c$ into the first layer of the Neural Field decoder [S1][S2, unofficial].
4.  **Predict:** The decoder processes $c$ through subsequent layers to predict the output $\mathcal{X}$ [S1][S2, unofficial].

    """

**Edge Cases and Pitfalls:**
*   **Layer Isolation:** Only the first layer of the decoder directly incorporates the condition $z$ [S2, unofficial]. Remaining layers operate only on internal feature representations, requiring the network to propagate the condition through non-linear transformations [S2, unofficial].
*   **Inference Cost:** When the transfer function changes, the TF extractor and decoder must be re-executed, but the compressed volume representation from the encoder remains constant [S1]. This is more efficient than methods requiring full volume re-processing [S1].
*   **Dimensionality:** The latent code size (e.g., 512) must be compatible with the decoder's input dimension [S1].

## Operating characteristics
*   **Time Complexity:** $O(N)$ for encoding (once per instance) and $O(D + L)$ for decoding per query, where $D$ is descriptor dimension and $L$ is latent length [S1][S2, unofficial].
*   **Memory Complexity:** Requires storing the latent vector $z$ per instance [S1].
*   **Strengths:** Simple to implement; efficient inference when only the condition (e.g., TF) changes, as the encoder output is cached [S1].
*   **Limitations:** The condition is only directly visible to the first layer, potentially limiting the network's ability to use global context in deeper layers [S2, unofficial].
*   **When to Use:** When a single network must handle multiple instances or conditions with minimal architectural change [S1][S2, unofficial].

## Background
Concatenation Conditioning is a standard injection strategy in conditional generative modeling [S1]. It was applied to volumetric ambient occlusion prediction by combining latent volume information with transfer function descriptors [S1]. The approach is also referenced in general Neural Field literature as a straightforward conditioning method [S2, unofficial].
