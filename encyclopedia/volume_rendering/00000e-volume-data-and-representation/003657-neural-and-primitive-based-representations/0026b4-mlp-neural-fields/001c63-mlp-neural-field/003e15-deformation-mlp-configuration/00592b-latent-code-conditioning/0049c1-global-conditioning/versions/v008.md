# Global Conditioning

Also called: Mapping Network

## Overview
Global conditioning encodes the entirety of a data sample's information into a single latent vector $z$ [S2, unofficial]. It serves as the standard approach for instance-specific variation in neural fields [S2, unofficial]. Unlike concatenation or hypernetwork conditioning, global conditioning transforms the input latent code into an intermediate non-linear latent space before integration [S1].

## How it works
**Inputs and Outputs:**
*   Input: A global latent code $z$.
*   Output: An intermediate latent representation used to modulate the neural field.

**Data Structures:**
The mapping network processes $z$ through a fixed sequence of linear transformations. The internal state is a vector of size 128.

**Steps:**
1.  **Normalization:** Normalize the input vector $z$. [S1]
2.  **Linear Layer 1:** Apply a linear transformation to $z$. [S1]
3.  **Activation 1:** Apply LeakyReLU with negative slope 0.2. [S1]
4.  **Linear Layer 2:** Apply a linear transformation to the result. [S1]
5.  **Activation 2:** Apply LeakyReLU with negative slope 0.2. [S1]
6.  **Linear Layer 3:** Apply a linear transformation to the result. [S1]
7.  **Activation 3:** Apply LeakyReLU with negative slope 0.2. [S1]
8.  **Output:** The final vector has shape 128. [S1]

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MappingNetwork(nn.Module):
    def __init__(self, latent_dim: int):
        super().__init__()
        # Three linear layers, output dimension 128 for each
        self.linear1 = nn.Linear(latent_dim, 128)
        self.linear2 = nn.Linear(128, 128)
        self.linear3 = nn.Linear(128, 128)

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        # Step 1: Normalize input z
        # Note: Specific normalization method (e.g., LayerNorm, InstanceNorm) 
        # is not detailed in the source, but is required for implementation [G].
        z_norm = F.layer_norm(z, (z.size(-1),))
        
        # Step 2-3: Linear 1 + LeakyReLU(0.2)
        x = self.linear1(z_norm)
        x = F.leaky_relu(x, negative_slope=0.2)
        
        # Step 4-5: Linear 2 + LeakyReLU(0.2)
        x = self.linear2(x)
        x = F.leaky_relu(x, negative_slope=0.2)
        
        # Step 6-7: Linear 3 + LeakyReLU(0.2)
        x = self.linear3(x)
        x = F.leaky_relu(x, negative_slope=0.2)
        
        # Step 8: Output shape is 128
        return x
```

**Parameters:**
*   Output dimension: 128 [S1].
*   Activation: LeakyReLU with slope 0.2 [S1].

**Edge Cases:**
*   Input dimensionality of $z$ must match the input size of the first linear layer. [S1]

## Subtopics

### Global Generator
The Global Generator is a variant that maps a single global latent code $z$ to a 2D grid of local latent codes $W$, representing the spatial layout of the scene [S1]. It is chosen when spatial variation of the latent code is required [S1].

**Steps:**
1.  Initialize with a constant input tensor. [S1]
2.  Apply a 3×3 modulated convolutional layer conditioned on $z$. [S1]
3.  Apply LeakyReLU(0.2). [S1]
4.  For subsequent layers, apply pairs of operations:
    a. Transposed convolution with stride 2 (upsampling resolution by 2×). [S1]
    b. Bilinear filtering. [S1]
    c. Modulated convolutional layer conditioned on $z$. [S1]
    d. LeakyReLU(0.2). [S1]
5.  Repeat until the target output resolution is reached. [S1]

**Parameters:**
*   Output resolution of $W$: 32×32 [S1]. This hyperparameter controls the size of the spatial region represented by each individual local latent code [S1].
*   Initial layer kernel size: 3×3 [S1].

## Operating characteristics
Global conditioning compresses all sample-specific information into a single vector, which limits the model's ability to represent high-frequency spatial variations within a single instance compared to local conditioning [S2, unofficial]. The mapping network adds minimal computational overhead (three linear layers) but enables non-linear transformation of the latent space [S1].

## Background
Global conditioning and the mapping network architecture were introduced in the context of unconstrained scene generation with locally conditioned radiance fields [S1]. The mapping network design follows the style of StyleGAN, utilizing normalization and non-linear activations to map latent codes to an intermediate space [S1].
