# Autoencoder/Autodecoder Conditioning

Also called: Auto-decoder training setup for shape space learning, Conditional Neural Field, Latent vector optimization, Multi-shape architecture

## Overview
Autoencoder/Autodecoder Conditioning is a method for representing a collection of distinct data instances (e.g., 3D shapes or images) using a shared neural field decoder $f_\theta$ and a unique latent code $z_i$ per instance [S1, unofficial][S2, unofficial]. It solves the problem of multi-instance representation by optimizing either an encoder to produce $z_i$ (autoencoder) or directly optimizing $z_i$ as a learnable parameter alongside $\theta$ (autodecoder) [S2, unofficial]. It differs from sibling methods by its specific optimization strategy for the latent code: in the autodecoder variant, $z_i$ is treated as an independent trainable variable optimized via gradient descent for each instance, rather than being computed by a separate encoder network or injected via hypernetwork weights [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A dataset of instances $J$. For each instance $j \in J$, training data consists of target observations (e.g., point clouds with normals, depth maps, or image pixels).
*   **Output:** A trained decoder network $f_\theta$ and a set of latent codes $\{z_j\}_{j \in J}$.

**Data Structures:**
*   **Latent Code $z_j$:** A vector in $\mathbb{R}^L$.
    *   For shape reconstruction: $L=0$ (no latent code, effectively a standard MLP field).
    *   For shape space learning/multi-shape: $L=256$ [S1, unofficial].
*   **Decoder Network $f_\theta$:** A Multi-Layer Perceptron (MLP) taking concatenated input $[x; z_j]$ where $x \in \mathbb{R}^3$ is the spatial coordinate.

**Network Architecture:**
The decoder uses Fully Connected (FC) layers with Softplus activation.
*   **Activation:** Softplus with $\beta=100$: $\text{Softplus}(x) = \frac{1}{\beta} \ln(1 + e^{\beta x})$ [S1, unofficial].
*   **Layer Sequence:**
    1.  Input: $3 + L$ dimensions.
    2.  FC+ (Fully Connected + Softplus)
    3.  FC+
    4.  FC+
    5.  FC+ (Skip connection from input to this layer)
    6.  FC (Linear, 512 units)
    7.  FC+
    8.  FC+
    9.  FC (Linear, output dimension depends on task, e.g., 1 for SDF)
    *   *Note:* The skip connection connects the raw input $[x; z_j]$ directly to the 4th layer (the 4th FC+ layer) [S1, unofficial].

**Optimization Steps:**

1.  **Initialization:**
    *   Initialize decoder weights $\theta$ randomly.
    *   Initialize latent codes $z_j = \mathbf{0} \in \mathbb{R}^L$ for all $j \in J$ [S1, unofficial].

2.  **Training Loop (Joint Optimization):**
    For each batch $B \subset J$:
    *   Sample target data for each $j \in B$.
    *   Compute loss $\mathcal{L}_j(\theta, z_j)$ based on reconstruction error (e.g., Chamfer distance, depth loss, silhouette loss) [S1, unofficial][S3].
    *   Add latent regularizer $\mathcal{L}_l(z_j) = \|z_j\|_2$ to encourage codes to stay near zero [S3].
    *   Total loss for batch:
        $$ \mathcal{L}_{batch} = \frac{1}{|B|} \sum_{j \in B} \left( \mathcal{L}_j(\theta, z_j) + \alpha \|z_j\|_2 \right) $$
        where $\alpha = 0.01$ [S1, unofficial].
    *   Update $\theta$ and $z_j$ for $j \in B$ using an optimizer (e.g., Adam) [S1, unofficial].

3.  **Inference/Test-Time Optimization (Autodecoder Specific):**
    For a new test instance $k$ with target data:
    *   Initialize $z_k = \mathbf{0} \in \mathbb{R}^L$ [S1, unofficial].
    *   Fix $\theta$ to the trained weights.
    *   Optimize $z_k$ by minimizing the reconstruction loss $\mathcal{L}_k(\theta, z_k)$ for a fixed number of iterations (e.g., 800 iterations) [S1, unofficial].
    *   The final reconstruction is obtained by evaluating $f_\theta(x; z_k)$.

**Parameters:**
*   $\alpha$: Latent regularizer weight. Default: $0.01$ [S1, unofficial].
*   $\beta$: Softplus smoothness. Default: $100$ [S1, unofficial].
*   $L$: Latent dimension. Default: $256$ for shape space, $0$ for reconstruction [S1, unofficial].
*   Learning Rate: $0.0001$ (reconstruction) or $0.0005$ (shape space) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **SDF/DDF Latent Sharing:** In inverse rendering contexts, Signed Distance Fields (SDF) and Directional Distance Fields (DDF) must share the same latent code $z$ for a given shape to ensure geometric consistency [S3].
*   **Precision:** The Softplus approximation with $\beta=100$ is used to avoid numerical instability of standard ReLU while maintaining smoothness [S1, unofficial].
*   **Test-Time Optimization:** The autodecoder requires iterative optimization at test time, which is computationally expensive compared to encoder-based methods [S1, unofficial].

## Subtopics

### Latent Code Regularizer
A specific regularization term $\mathcal{L}_l(z) = \|z\|_2$ applied in the autodecoder framework to penalize large latent code magnitudes, keeping codes close to zero and ensuring similarity between different shapes [S3]. Pitfall: SDF and DDF models must share the same latent code for a given shape to maintain consistency [S3].

### [Two-Stage Unpaired Generative Modelling](17908-two-stage-unpaired-generative-modelling.md)
A two-stage architecture for 3D-to-2D translation using unpaired data. Stage 1 uses a Variational Autoencoder (VAE) with a Conditional Probabilistic Directed Distance Field (CPDDF) to map 3D point clouds to a latent shape vector. Stage 2 uses a GAN to render RGB images from surface normals, conditioned on a separate latent texture vector. It is distinguished by handling unpaired datasets and providing explicit 3D-aware geometry unlike pure 2D GANs.

## Operating characteristics
*   **Time Complexity:** Training is $O(N \cdot I \cdot D)$ where $N$ is batch size, $I$ is iterations, and $D$ is decoder depth. Test-time inference for autodecoders requires $O(I_{test} \cdot D)$ per instance due to latent optimization [S1, unofficial].
*   **Memory Complexity:** $O(|J| \cdot L)$ to store latent codes for all instances, plus standard MLP memory [S1, unofficial].
*   **Performance:** On Nvidia V-100 GPUs, shape reconstruction trains for 100k iterations (128k points sampled per iteration) [S1, unofficial]. Shape space learning uses 4 V-100s for 1k epochs [S1, unofficial].
*   **Strengths:** Enables learning a continuous shape space; allows interpolation of latent vectors to generate novel shapes [S1, unofficial].
*   **Limitations:** Test-time optimization is slow; requires careful tuning of $\alpha$ to prevent code collapse or explosion [S1, unofficial][S3].

## Background
Originated in the context of implicit geometric regularization for learning shapes, specifically the "auto-decoder" setup popularized by Park et al. (2019) [S1, unofficial]. It was applied to tasks like learning shape spaces from raw scans (e.g., D-Faust dataset) and inverse rendering (FIRe) [S1, unofficial][S3]. The method decouples instance identity (latent code) from the shared geometric prior (decoder weights) [S2, unofficial].
