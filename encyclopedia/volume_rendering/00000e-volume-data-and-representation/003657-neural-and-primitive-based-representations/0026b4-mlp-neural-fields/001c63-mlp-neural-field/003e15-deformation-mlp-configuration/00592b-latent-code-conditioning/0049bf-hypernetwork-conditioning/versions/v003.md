# HyperNetwork Conditioning

Also called: Hypernetwork-based conditioning, HyperNet conditioning

## Overview
HyperNetwork Conditioning generates instance-specific neural field parameters by using a secondary network (the HyperNetwork) to predict the weights of the primary decoder from a latent code [S1, unofficial]. Unlike concatenation-based conditioning, which shares decoder weights across all instances and forces the network to infer distinctions from the input code, this method creates a distinct Neural Field for each input instance [S1, unofficial]. This separation allows the primary network complexity to be significantly lower, offering a more compact representation [S1, unofficial].

## How it works
**Inputs:**
- Latent code $z \in \mathbb{R}^d$ representing the specific instance or condition.
- Query coordinate $x \in \Omega$ (spatial/temporal domain).

**Outputs:**
- Neural field output (e.g., density, color) computed by the decoder $D$ with weights $\theta$ predicted from $z$.

**Data Structures:**
- **HyperNetwork ($H$):** A neural network with parameters $\phi$. It maps $z \to \theta$.
- **Decoder ($D$):** A neural network with parameters $\theta$. It maps $(x, \theta) \to \text{output}$. Note that $D$ does not store $\theta$ as fixed weights; $\theta$ is dynamically generated.

**Steps:**
1. **Encode Condition:** Obtain the latent code $z$ for the target instance.
2. **Predict Weights:** Pass $z$ through the HyperNetwork $H$ to generate the weight vector $\theta$ for the decoder:
   $$ \theta = H(z; \phi) $$
   The HyperNetwork outputs all parameters required by the decoder, including weights and biases for every layer [S1, unofficial].
3. **Instantiate Decoder:** Construct the decoder network $D$ using the predicted parameters $\theta$. The architecture of $D$ is fixed, but its parameters are instance-specific.
4. **Query Field:** Evaluate the decoder at the query coordinate $x$:
   $$ \text{output} = D(x; \theta) $$

**Parameters:**
- **HyperNetwork Architecture:** Not specified in sources. Typically a small MLP.
- **Decoder Architecture:** Standard MLP for Neural Fields. Complexity can be lower than in shared-weight models [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Memory:** Storing or transmitting $\theta$ for every instance can be memory-intensive if $z$ is large or the decoder is deep. However, the source notes that the primary network complexity can be lower, potentially offsetting this [S1, unofficial].
- **Precision:** The HyperNetwork must accurately predict weights that allow the decoder to generalize. Poor prediction leads to artifacts specific to that instance.

## Subtopics

### Hybrid Conditioning
Hybrid Conditioning combines global and local latent codes to balance shared structure and instance-specific detail [S1, unofficial].
- **Mechanism:** One global code encodes basic information shared between instances, while several local codes encode instance-specific details assigned to subsets of spatio-temporal coordinates [S1, unofficial].
- **Choice:** Use this when instances share a common underlying geometry or appearance but require localized variations (e.g., texture changes in specific regions) [S1, unofficial].

## Operating characteristics
- **Complexity:** The primary network (decoder) complexity can be much lower than in concatenation-based methods because it does not need to encode instance diversity [S1, unofficial].
- **Representation:** Offers a more compact representation for the primary network [S1, unofficial].
- **Distinctness:** Each input instance gets a completely different Neural Field (different weights), whereas concatenation shares weights [S1, unofficial].
- **Performance:** Not given in the sources.

## Background
The concept utilizes HyperNetworks [Ha et al., 2016], where a neural network predicts the parameters of another network [S1, unofficial]. Recent basic research suggests that using HyperNetworks allows the primary network complexity to be lower, hinting at a more compact representation [Galanti & Wolf, 2020][S1, unofficial]. This approach is contrasted with Feature-wise transformations [Dumoulin et al., 2018] [S1, unofficial].
