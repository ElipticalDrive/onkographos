# ObjectNet Training

Also called: ObjectNet, Object-Level Priors, category-specific object priors

## Overview
ObjectNet Training introduces a category-specific prior by inserting a dedicated network (ObjectNet) before PatchNet to regress patch latent codes and extrinsics from a shared object latent code [S1]. This architecture increases network capacity and establishes coarse geometric correspondences across different instances of the same category [S1]. It is distinct from standard PatchNet training by decoupling object-level identity from patch-level details via a three-phase latent regression process [S1].

## How it works

### Inputs and Outputs
* **Inputs**: Object latent code $z_{obj} \in \mathbb{R}^{256}$ [S1]. Pretrained PatchNet parameters (fixed) [S1]. Category-specific initialization data containing the extrinsics of an arbitrary object from the target category [S1].
* **Outputs**: Patch latent codes for all patches [S1]. Regressed extrinsics (position and scale) for all patches [S1].

### Data Structures
* **ObjectNet**: Multi-Layer Perceptron (MLP) with 4 fully connected layers [S1]. Hidden dimension: 1024 [S1]. Activation: ReLU [S1]. Input dimension: 256 [S1]. Output dimension: concatenated patch latent codes and extrinsics [S1].
* **Object Latent Codes**: Fixed-size vector of 256 dimensions [S1].
* **Patch Extrinsics**: Regressed position and scale parameters [S1].

### Parameters
* $\omega_{var}$: L2 regularization weight for object latent codes. Value: 5 [S1].
* $\omega_{scl}$: Scale regularization weight. Phase I: 2 [S1]. Phase III: 0.02 [S1].
* Scale Multiplier (Phase II): 1.3 [S1].
* L2 Loss Weights (Phase II): Reconstruction ($L_{recon}$): 1 [S1]. Position consistency: 3 [S1]. Scale consistency: 30 [S1].
* Batch Size: 128 [S1].
* Epochs per Phase: 1000 [S1].
* Learning Rate: Matches PatchNet's initial learning rate, reduced by a factor of 5 in Phase III [S1].

### Initialization
1. Initialize all object latent codes $z_{obj}$ with zeros [S1].
2. Initialize ObjectNet’s last layer weights with very small numbers [S1].
3. Initialize ObjectNet’s last layer bias: zeros for patch latent codes, and the extrinsics of an arbitrary object from the target category (computed via the method in Section 3.2 of the source) for extrinsics [S1].
4. Pretrain PatchNet on ShapeNet and keep it fixed for the duration of ObjectNet training [S1].
5. Remove the rotation loss term $L_{rot}$ completely [S1].
6. Apply L2 regularization only to the object latent codes [S1].

### Loss Formulas
The training objective combines reconstruction, extrinsic consistency, and regularization [S1].
* Extrinsic Loss ($L_{ext}$): Measures deviation of regressed extrinsics from ground truth, incorporating a scale term weighted by $\omega_{scl}$ [S1].
* Reconstruction Loss ($L_{recon}$): Measures rendering error using the fixed PatchNet and regressed patch latent codes [S1].
* Complete Loss ($L$): Combines all training terms with $\omega_{scl} = 0.02$ [S1].
* Regularization: $L_{reg} = \omega_{var} \|z_{obj}\|_2^2$, applied exclusively to object latent codes [S1].

### Training Phases
Training proceeds in three sequential phases, each lasting 1000 epochs [S1].

**Phase I: Pretrain for Extrinsics**
* **Goal**: Ensure good initial patch extrinsics [S1].
* **Loss**: $L_{ext}$ plus $L_{reg}$ [S1].
* **Parameter**: $\omega_{scl} = 2$ [S1].

**Phase II: Regress Patch Latent Codes**
* **Goal**: Learn to regress patch latent codes while maintaining consistency with initial extrinsics [S1].
* **Preparation**: Multiply regressed scales by 1.3, then store these modified extrinsics as a target reference [S1].
* **Loss**: $1 \cdot L_{recon} + 3 \cdot \| \text{position} - \text{stored\_position} \|_2^2 + 30 \cdot \| \text{scale} - \text{stored\_scale} \|_2^2$ [S1].

**Phase III: Final Refinement**
* **Goal**: Optimize the complete model [S1].
* **Loss**: Complete loss $L$ plus $L_{reg}$ [S1].
* **Parameter**: $\omega_{scl} = 0.02$ [S1].
* **Learning Rate**: Reduced by a factor of 5 compared to previous phases [S1].

### Pseudocode
```python
def train_object_net(category_data, category_init_extrinsics, patch_net, initial_lr):
    # ObjectNet: 4 FC layers, hidden 1024, ReLU
    object_net = MLP(num_layers=4, input_dim=256, hidden_dim=1024, activation=relu)
    # Object latent codes: size 256
    object_latents = zeros(len(category_data), 256)
    
    # Initialize ObjectNet last layer weights with very small numbers
    object_net.set_last_layer_weights(small_values)
    # Initialize bias: zeros for patch latent codes, category_init_extrinsics for extrinsics
    object_net.set_last_layer_bias(patch_latent_zeros=True, extrinsics_bias=category_init_extrinsics)
    
    # PatchNet is pretrained on ShapeNet and kept fixed
    patch_net.freeze()
    
    batch_size = 128
    epochs_per_phase = 1000
    omega_var = 5
    omega_scl = 2.0
    scale_multiplier = 1.3
    lr = initial_lr
    
    # Phase I: Pretrain for Extrinsics
    for epoch in range(epochs_per_phase):
        batch_indices = sample_random_indices(len(category_data), batch_size)
        z_obj = object_latents[batch_indices]
        patch_latents, extrinsics = object_net(z_obj)
        loss = compute_extrinsic_loss(extrinsics, category_data[batch_indices], omega_scl=omega_scl)
        loss += omega_var * l2_norm(object_latents[batch_indices])
        update_parameters(object_net, loss, lr)
        
    # Phase II: Regress Patch Latent Codes
    # Add a layer that multiplies regressed scales by 1.3
    object_net.apply_scale_multiplier(scale_multiplier)
    # Store these extrinsics
    with no_grad():
        stored_latents, stored_extrinsics = object_net(object_latents)
        
    for epoch in range(epochs_per_phase):
        batch_indices = sample_random_indices(len(category_data), batch_size)
        z_obj = object_latents[batch_indices]
        patch_latents, extrinsics = object_net(z_obj)
        loss = compute_reconstruction_loss(patch_net, patch_latents, category_data[batch_indices])
        loss += 3.0 * l2_norm(extrinsics.position - stored_extrinsics.position[batch_indices])
        loss += 30.0 * l2_norm(extrinsics.scale - stored_extrinsics.scale[batch_indices])
        update_parameters(object_net, loss, lr)
        
    # Phase III: Final Refinement
    lr = initial_lr / 5.0
    omega_scl = 0.02
    object_net.remove_scale_multiplier()
    
    for epoch in range(epochs_per_phase):
        batch_indices = sample_random_indices(len(category_data), batch_size)
        z_obj = object_latents[batch_indices]
        patch_latents, extrinsics = object_net(z_obj)
        loss = compute_complete_loss(patch_net, patch_latents, extrinsics, category_data[batch_indices], omega_scl=omega_scl)
        loss += omega_var * l2_norm(object_latents[batch_indices])
        update_parameters(object_net, loss, lr)
        
    return object_net, object_latents

# Helper definitions (framework-agnostic)
def MLP(num_layers, input_dim, hidden_dim, activation):
    layers = [Linear(input_dim, hidden_dim, activation=activation)]
    for _ in range(num_layers - 2):
        layers.append(Linear(hidden_dim, hidden_dim, activation=activation))
    layers.append(Linear(hidden_dim, output_dim)) # output_dim matches PatchNet requirements
    return Sequential(layers)

def sample_random_indices(total, batch_size):
    return random.sample(range(total), batch_size)

def compute_extrinsic_loss(extrinsics, ground_truth, omega_scl):
    # Computes Eq. 3 from source, applying scale weight omega_scl
    return l2_norm(extrinsics - ground_truth) + omega_scl * l2_norm(extrinsics.scale - ground_truth.scale)

def compute_reconstruction_loss(patch_net, patch_latents, geometry):
    # Renders geometry using fixed PatchNet and regressed latents
    return l2_norm(patch_net.forward(patch_latents) - geometry)

def compute_complete_loss(patch_net, patch_latents, extrinsics, geometry, omega_scl):
    # Computes Eq. 1 from source with given omega_scl
    return l2_norm(patch_net.forward(patch_latents) - geometry) + omega_scl * l2_norm(extrinsics.scale)

def update_parameters(network, loss, lr):
    grads = compute_gradients(loss, network.parameters())
    for param, grad in zip(network.parameters(), grads):
        param -= lr * grad

def l2_norm(x):
    return sqrt(sum(x_i**2 for x_i in x))

def compute_gradients(loss, params):
    # Standard backpropagation step
    return [loss.backward() for _ in params]
```

### Edge Cases and Pitfalls
* **Rotation Loss**: $L_{rot}$ must be removed completely; keeping it significantly lowers quality [S1].
* **Regularization Scope**: L2 regularization is applied *only* to object latent codes, not to network weights or patch latents [S1].
* **PatchNet Fixation**: PatchNet must be pretrained on ShapeNet and kept fixed; training it jointly is not described [S1].
* **Initialization Sensitivity**: The bias initialization for extrinsics uses a specific arbitrary object from the category; incorrect initialization may hinder convergence [S1].

## Operating characteristics

* **Time Complexity**: Training is divided into three phases of 1000 epochs each, totaling 3000 epochs. This is longer than standard PatchNet training [S1].
* **Memory Complexity**: Requires storage for object latent codes (256 dimensions per object) and the ObjectNet parameters [S1].
* **Strengths**:
  * Enables coarse correspondences across objects within a category [S1].
  * Allows interpolation of latent codes to generate smooth morphs between shapes [S1].
  * Can be turned into a generative model [S1].
* **Limitations**:
  * Higher training time compared to baselines [S1].
  * Requires a full training split of the target category [S1].
* **When to Use**: When category-specific priors and inter-object correspondence are required, and training time is not a critical constraint [S1].

## Background

ObjectNet Training was introduced by E. Tretschk et al. in the paper "PatchNets: Patch-Based Generalizable Deep Implicit 3D Shape Representations" (2020) [S1]. It extends the PatchNet architecture by adding object-level priors to improve generalization and consistency across instances of the same shape category [S1].
