# Multi-Head MLP Decoder

Also called: Ensemble MLP Heads, RMDSRN

## Overview
The Multi-Head MLP Decoder is an uncertainty-aware neural field configuration that attaches multiple lightweight MLP decoders to a shared feature grid encoder [S1, unofficial]. It solves the problem of estimating reconstruction uncertainty in implicit neural representations without the prohibitive parameter cost of full ensemble methods [S1, unofficial]. It sets itself apart from siblings like [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md) by using distinct, lightweight MLP heads rather than a single linear layer with multiple outputs, and from [Latent Code Conditioning](16345-latent-code-conditioning.md) by relying on architectural diversity rather than latent variable conditioning to model uncertainty [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Spatial coordinates $\mathbf{x}$ and a shared feature vector $\mathbf{z}$ extracted from a shared feature grid encoder [S1, unofficial].
*   **Output:** A set of $H$ predicted values $\{y_1, y_2, \dots, y_H\}$ and an associated uncertainty estimate (variance) derived from the spread of these predictions [S1, unofficial].

**Data Structures:**
*   **Shared Feature Grid Encoder:** A single neural network that maps input coordinates $\mathbf{x}$ to a shared latent feature vector $\mathbf{z}$ [S1, unofficial]. The layout of $\mathbf{z}$ is determined by the encoder's output dimension $D_z$ [G].
*   **Multi-Head Decoder:** A collection of $H$ independent MLP decoders [S1, unofficial].
    *   **Head Structure:** Each head $h \in \{1, \dots, H\}$ is an MLP with $L$ layers [S1, unofficial].
    *   **Parameters:** For a head with layer dimensions $D_z \to d_1 \to \dots \to d_{L-1} \to 1$, the parameters are the weight matrices and bias vectors for each layer [G].
    *   **Typical Configuration:** The source specifies $H=5$ heads, each with $L=2$ layers [S1, unofficial].

**Numbered Steps:**
1.  **Feature Extraction:** Compute the shared feature vector $\mathbf{z} = E(\mathbf{x})$ using the shared encoder $E$ [S1, unofficial].
2.  **Parallel Decoding:** For each head $h \in \{1, \dots, H\}$, compute the prediction $y_h = D_h(\mathbf{z})$, where $D_h$ is the $h$-th MLP decoder [S1, unofficial].
3.  **Uncertainty Estimation:** Calculate the variance $\sigma^2$ of the predictions $\{y_1, \dots, y_H\}$ [S1, unofficial]. This variance serves as the model's uncertainty estimate [S1, unofficial].
4.  **Variance Regularization:** Apply a variance regularization term to the loss function to encourage the model's uncertainty to concentrate where reconstruction errors are largest [S1, unofficial]. The specific formula for the regularization term is not provided in the sources [S1, unofficial].
5.  **Training:** Optimize the parameters of the shared encoder and all $H$ heads jointly using a loss function that includes the standard reconstruction loss and the variance regularization term [S1, unofficial].

**Pseudocode:**
```python
def multi_head_mlp_decoder(x, encoder, heads, num_heads=5):
    z = encoder(x)
    predictions = []
    for h in range(num_heads):
        predictions.append(heads[h](z))
    predictions = list(zip(*predictions))
    mean_pred = [sum(p) / len(p) for p in predictions]
    var_pred = [sum((p - m)**2 for p in predictions) / len(predictions) for m in mean_pred]
    return mean_pred, var_pred, predictions

def train_step(x, y_true, encoder, heads, loss_fn, var_reg_weight=1.0):
    mean_pred, var_pred, all_preds = multi_head_mlp_decoder(x, encoder, heads)
    recon_loss = loss_fn(mean_pred, y_true)
    error = [abs(m - y) for m, y in zip(mean_pred, y_true)]
    # Exact regularization formula not provided in sources [S1, unofficial]
    # [G] Heuristic: correlate variance with reconstruction error
    var_reg = sum(v * e for v, e in zip(var_pred, error)) / len(var_pred)
    total_loss = recon_loss + var_reg_weight * var_reg
    # Backward pass and optimization handled by external framework
    return total_loss
```

**Parameters with Typical Values:**
*   Number of heads ($H$): 5 [S1, unofficial].
*   Number of layers per head ($L$): 2 [S1, unofficial].
*   Volume resolution: Up to $1024^3$ (4 GB) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** The source does not specify precision requirements [S1, unofficial]. [G] Standard float32 is typically used for INR training.
*   **Boundaries:** No specific boundary handling is mentioned [S1, unofficial]. [G] Standard coordinate normalization (e.g., to $[-1, 1]$) is assumed.
*   **Degenerate Input:** If all heads produce identical outputs, variance will be zero, potentially failing to capture uncertainty [G]. The variance regularization helps mitigate this by encouraging diversity in high-error regions [S1, unofficial].

## Subtopics

### Aggregation MLP
A lightweight MLP used to denoise perturbed responses by mapping $K$-dimensional perturbation responses to $K$-dimensional segmentation logits, trained under an aggregation loss [S2]. It is used in the context of JacobiNeRF for view synthesis with mutual information gradients [S2]. The aggregation MLP has 3 linear layers with ReLU activation, with parameters $K \times 256 + 256 \times 128 + 128 \times K$ [S2]. It is trained from scratch under aggregation loss $L_{agg}$ after adaptively selecting gradients and getting responses on the source view by perturbing along the selected gradients [S2]. The aggregation loss $L_{agg}$ is a multi-class cross-entropy loss to encourage the denoised predicted label to be consistent with the given ground-truth dense labels [S2]. It is optimized with the Adam optimizer with an initial learning rate of $1 \times 10^{-3}$ for 200,000 iterations (approximately 30 minutes) [S2].

## Operating characteristics
*   **Time Complexity:** Training takes 2–3× longer than a deterministic INR due to the evidential loss computation (variance regularization) [S1, unofficial]. Inference speed is comparable to a deterministic INR [S1, unofficial].
*   **Memory Complexity:** The parameter cost is amortized across the shared encoder and lightweight heads [S1, unofficial]. The source does not provide exact memory usage figures [S1, unofficial].
*   **Measured Performance:** On volumes up to $1024^3$ (4 GB), RMDSRN achieved the highest reconstruction PSNR among all uncertainty-aware methods [S1, unofficial]. It produced variance maps identifying high-error regions without access to ground truth [S1, unofficial].
*   **Scaling:** The method scales to large volumes ($1024^3$) [S1, unofficial].
*   **Strengths:** High reconstruction PSNR, efficient uncertainty estimation, no need for ground truth during inference for uncertainty maps [S1, unofficial].
*   **Limitations:** Slower training time (2–3×) compared to deterministic INRs [S1, unofficial].
*   **When to Use:** When uncertainty estimation is required for scientific volume data, and computational resources allow for slightly longer training times [S1, unofficial].
*   **When Not to Use:** When real-time inference is critical and uncertainty estimation is not needed, or when training time is severely constrained [G].

## Background
The Multi-Head MLP Decoder, also known as RMDSRN, was introduced as an orthogonal approach to uncertainty in neural implicit representations [S1, unofficial]. It was proposed to address the limitations of existing uncertainty-aware INR variants, which often suffer from high parameter costs or lower reconstruction accuracy [S1, unofficial]. The method leverages the diversity of multiple lightweight heads to model uncertainty while sharing the computational burden of feature extraction via a common encoder [S1, unofficial]. It is particularly relevant for scientific volume data, where understanding reconstruction confidence is crucial [S1, unofficial].
