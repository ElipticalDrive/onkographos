# Multi-Head MLP Decoder

Also called: Ensemble MLP Heads, RMDSRN

## Overview
The Multi-Head MLP Decoder is an uncertainty-aware neural field configuration that attaches multiple lightweight MLP decoders (heads) to a shared feature grid encoder [S1, unofficial]. It solves the problem of estimating reconstruction uncertainty in implicit neural representations (INRs) without the prohibitive parameter cost of full ensemble methods [S1, unofficial]. It sets itself apart from siblings like [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md) by using distinct, lightweight MLP heads rather than a single linear layer with multiple outputs, and from [Latent Code Conditioning](16345-latent-code-conditioning.md) by relying on architectural diversity (multiple heads) rather than latent variable conditioning to model uncertainty [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Spatial coordinates $\mathbf{x}$ (and potentially time/other dimensions) and a shared feature vector $\mathbf{z}$ extracted from a shared feature grid encoder.
*   **Output:** A set of $H$ predicted values $\{y_1, y_2, \dots, y_H\}$ and an associated uncertainty estimate (variance) derived from the spread of these predictions.

**Data Structures:**
*   **Shared Feature Grid Encoder:** A single neural network (e.g., a standard MLP or grid-based encoder) that maps input coordinates $\mathbf{x}$ to a shared latent feature vector $\mathbf{z}$. The layout of $\mathbf{z}$ is determined by the encoder's output dimension $D_z$.
*   **Multi-Head Decoder:** A collection of $H$ independent MLP decoders.
    *   **Head Structure:** Each head $h \in \{1, \dots, H\}$ is an MLP with $L$ layers.
    *   **Parameters:** For a head with layer dimensions $D_z \to d_1 \to \dots \to d_{L-1} \to 1$, the parameters are the weight matrices and bias vectors for each layer.
    *   **Typical Configuration:** The source specifies $H=5$ heads, each with $L=2$ layers [S1, unofficial].

**Numbered Steps:**
1.  **Feature Extraction:** Compute the shared feature vector $\mathbf{z} = E(\mathbf{x})$ using the shared encoder $E$.
2.  **Parallel Decoding:** For each head $h \in \{1, \dots, H\}$, compute the prediction $y_h = D_h(\mathbf{z})$, where $D_h$ is the $h$-th MLP decoder.
3.  **Uncertainty Estimation:** Calculate the variance $\sigma^2$ of the predictions $\{y_1, \dots, y_H\}$. This variance serves as the model's uncertainty estimate.
4.  **Variance Regularization:** Apply a variance regularization term to the loss function. This term encourages the model's uncertainty (variance) to concentrate in regions where the reconstruction error is largest [S1, unofficial]. The specific formula for the regularization term is not provided in the sources.
5.  **Training:** Optimize the parameters of the shared encoder and all $H$ heads jointly using a loss function that includes the standard reconstruction loss and the variance regularization term.

    """
    x: Input coordinates (tensor)
    encoder: Shared feature grid encoder function
    heads: List of H MLP decoder functions
    num_heads: Number of heads (default 5)
    """
    # Step 1: Feature Extraction
    z = encoder(x)
    
    # Step 2: Parallel Decoding
    predictions = []
    for h in range(num_heads):
        y_h = heads[h](z)
        predictions.append(y_h)
    
    # Stack predictions to shape (batch_size, num_heads)
    predictions = torch.stack(predictions, dim=-1)
    
    # Step 3: Uncertainty Estimation (Variance)

    mean_pred = torch.mean(predictions, dim=-1, keepdim=True)
    # Variance prediction
    var_pred = torch.var(predictions, dim=-1, keepdim=True, unbiased=False)
    
    return mean_pred, var_pred, predictions

**Parameters with Typical Values:**
*   Number of heads ($H$): 5 [S1, unofficial].
*   Number of layers per head ($L$): 2 [S1, unofficial].
*   Volume resolution: Up to $1024^3$ (4 GB) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** The source does not specify precision requirements. [G] Standard float32 is typically used for INR training.
*   **Boundaries:** No specific boundary handling is mentioned. [G] Standard coordinate normalization (e.g., to $[-1, 1]$) is assumed.
*   **Degenerate Input:** If all heads produce identical outputs, variance will be zero, potentially failing to capture uncertainty. The variance regularization helps mitigate this by encouraging diversity in high-error regions.

## Subtopics

### Aggregation MLP
A lightweight MLP used to denoise perturbed responses by mapping $K$-dimensional perturbation responses to $K$-dimensional segmentation logits, trained under an aggregation loss [S2]. It is used in the context of JacobiNeRF for view synthesis with mutual information gradients [S2]. The aggregation MLP has 3 linear layers with ReLU activation, with parameters $K \times 256 + 256 \times 128 + 128 \times K$ [S2]. It is trained from scratch under aggregation loss $L_{agg}$ after adaptively selecting gradients and getting responses on the source view by perturbing along the selected gradients [S2]. The aggregation loss $L_{agg}$ is a multi-class cross-entropy loss to encourage the denoised predicted label to be consistent with the given ground-truth dense labels [S2]. It is optimized with the Adam optimizer with an initial learning rate of $1 \times 10^{-3}$ for 200,000 iterations (approximately 30 minutes) [S2].

## Operating characteristics
*   **Time Complexity:** Training takes 2–3× longer than a deterministic INR due to the evidential loss computation (variance regularization) [S1, unofficial]. Inference speed is comparable to a deterministic INR [S1, unofficial].
*   **Memory Complexity:** The parameter cost is amortized across the shared encoder and lightweight heads. The source does not provide exact memory usage figures, but notes it is more efficient than full ensemble methods [S1, unofficial].
*   **Measured Performance:** On volumes up to $1024^3$ (4 GB), RMDSRN achieved the highest reconstruction PSNR among all uncertainty-aware methods [S1, unofficial]. It produced variance maps identifying high-error regions without access to ground truth [S1, unofficial].
*   **Scaling:** The method scales to large volumes ($1024^3$) [S1, unofficial].
*   **Strengths:** High reconstruction PSNR, efficient uncertainty estimation, no need for ground truth during inference for uncertainty maps.
*   **Limitations:** Slower training time (2–3×) compared to deterministic INRs.
*   **When to Use:** When uncertainty estimation is required for scientific volume data, and computational resources allow for slightly longer training times.
*   **When Not to Use:** When real-time inference is critical and uncertainty estimation is not needed, or when training time is severely constrained.

## Background
The Multi-Head MLP Decoder, also known as RMDSRN, was introduced as an orthogonal approach to uncertainty in neural implicit representations [S1, unofficial]. It was proposed to address the limitations of existing uncertainty-aware INR variants, which often suffer from high parameter costs or lower reconstruction accuracy [S1, unofficial]. The method leverages the diversity of multiple lightweight heads to model uncertainty while sharing the computational burden of feature extraction via a common encoder [S1, unofficial]. It is particularly relevant for scientific volume data, where understanding reconstruction confidence is crucial [S1, unofficial].
