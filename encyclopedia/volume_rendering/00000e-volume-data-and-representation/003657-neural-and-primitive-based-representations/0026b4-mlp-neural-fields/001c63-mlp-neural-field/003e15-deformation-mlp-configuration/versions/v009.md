# Deformation MLP Configuration

Also called: Conditional Batch Normalization, Deformation MLP Setup, Feature-wise Linear Modulation (FiLM), Feature-wise transformations, MLP setup

## Overview
Deformation MLP Configuration defines the architecture, initialization, and conditioning mechanisms for a Multi-Layer Perceptron (MLP) used to predict spatial or temporal deformations in neural volume representations. It solves the problem of mapping canonical coordinates to deformed coordinates (or vice versa) by applying feature-wise linear modulations or direct displacement predictions. It is distinguished from sibling methods like [MLP with Input Skips](1643-mlp-with-input-skips.md) by its specific focus on deformation dynamics (e.g., Gaussian splatting motion) and [Residual Block with Shortcut (ReLU MLP Extension)](10016-residual-block-with-shortcut-relu-mlp-extension.md) by its use of conditional scaling/biasing or specific initialization strategies for delta predictions rather than standard residual learning.

## How it works
The method configures an MLP to output deformation vectors (e.g., $\delta\mathbf{x}$) based on input coordinates and optional conditioning signals. The configuration varies by application, ranging from standard dense networks for dynamic Gaussians to hash-encoded networks for LiDAR/NeRF fusion.

### Inputs and Outputs
*   **Inputs**: Spatial coordinates $\mathbf{x}$, time $t$ (optional), and/or latent codes $\mathbf{z}$ or grid features.
*   **Outputs**: Deformation vector $\delta\mathbf{x}$, scaled/shifted features, or density/color attributes derived from deformed positions.

### Data Structures and Layouts
The specific layout depends on the variant. The primary configuration for dynamic Gaussian splatting [S1] is:
*   **Structure**: 8 fully connected layers.
*   **Width**: 256 neurons per layer.
*   **Input Encoding**: Positional encoding applied to spatial coordinates $\mathbf{x}$ with frequency $L_x = 10$ and time $t$ with frequency $L_t = 10$ [S1].
*   **Output**: Delta position $\delta\mathbf{x}_k$ for each Gaussian $k$.

For hash-encoded variants [S3]:
*   **Structure**: "Fused" MLPs employing hash encoding.
*   **Hash Grid**: Minimum resolution 16, 5 levels, 2-dim features per level [S3].
*   **MLP Layers**: 2 hidden layers with 16 hidden features each [S3].

### Initialization and Parameters
1.  **Standard Weights**: Initialize weights using Xavier normal initialization [S1].
2.  **Biases**: Initialize all biases to zero [S1].
3.  **Final Layer**: For deformation output (mapping 256 features to $\delta\mathbf{x}$), initialize weights from a normal distribution with standard deviation $\sigma = 10^{-5}$ [S1]. This ensures small initial deformations for stable optimization [S1].
4.  **Conditional Scaling (FiLM/CBN)**: If using Feature-wise Linear Modulation, small networks $\boldsymbol{\beta_i}(\mathbf{z})$ and $\boldsymbol{\gamma_i}(\mathbf{z})$ predict scale and bias vectors matching the layer's output size [S2, unofficial]. The transformation is:
    $$ \hat{\mathbf{x}}_i = L_i(\mathbf{x}) \odot \boldsymbol{\gamma_i}(\mathbf{z}) + \boldsymbol{\beta_i}(\mathbf{z}) $$
    where $L_i$ is the layer output, $\odot$ is element-wise multiplication, and $\mathbf{z}$ is the conditioning latent code [S2, unofficial].

### Pseudocode
The following pseudocode implements the standard 8-layer deformation MLP for dynamic Gaussians [S1] and the static grid-based deformation [S5, unofficial].

```python
import math
import torch
import torch.nn as nn
import torch.nn.functional as F

class PositionalEncoding(nn.Module):
    """
    Standard positional encoding for coordinates.
    """
    def __init__(self, num_frequencies):
        super().__init__()
        self.num_frequencies = num_frequencies

    def forward(self, x):
        # x shape: (..., D)
        # Output shape: (..., D * (2 * num_frequencies + 1))
        # Includes original x, sin(2^i * pi * x), cos(2^i * pi * x)
        freq_bands = 2.0 ** torch.linspace(0, self.num_frequencies - 1, self.num_frequencies).to(x.device)
        x_expanded = x.unsqueeze(-1) * freq_bands.unsqueeze(0)
        x_encoded = torch.cat([x, torch.sin(x_expanded), torch.cos(x_expanded)], dim=-1)
        return x_encoded

class DeformationMLP(nn.Module):
    """
    8-layer MLP for predicting delta position in dynamic Gaussian Splatting [S1].
    """
    def __init__(self, input_dim=3, hidden_dim=256, num_layers=8, freq_x=10, freq_t=10):
        super().__init__()
        self.freq_x = freq_x
        self.freq_t = freq_t
        
        # Positional encoders
        self.pe_x = PositionalEncoding(freq_x)
        self.pe_t = PositionalEncoding(freq_t)
        
        # Calculate input size after PE
        # x: 3 dims -> 3 + 2*3*10 = 63
        # t: 1 dim -> 1 + 2*1*10 = 21
        # Total input: 63 + 21 = 84
        self.input_dim_pe = (input_dim * (2 * freq_x + 1)) + (1 * (2 * freq_t + 1))
        
        # Layers
        layers = []
        for i in range(num_layers):
            in_size = self.input_dim_pe if i == 0 else hidden_dim
            out_size = hidden_dim
            linear = nn.Linear(in_size, out_size)
            
            # Initialization [S1]
            if i == num_layers - 1:
                # Final layer: normal distribution with std 10^-5 [S1]
                nn.init.normal_(linear.weight, mean=0, std=1e-5)
            else:
                # Other layers: Xavier normal [S1]
                nn.init.xavier_normal_(linear.weight)
            
            layers.append(linear)
            layers.append(nn.ReLU()) # Assuming ReLU as standard activation unless specified otherwise
            
        self.network = nn.Sequential(*layers)
        
        # Final bias init to zero [S1]
        self.network[-1].bias.data.zero_()

    def forward(self, x, t):
        """
        x: (N, 3) Gaussian positions
        t: (N,) Time steps
        Returns: delta_x (N, 3)
        """
        # Encode inputs
        x_enc = self.pe_x(x)
        t_enc = self.pe_t(t.unsqueeze(1)) # t is scalar per point, expand to (N,1)
        
        # Concatenate
        input_vec = torch.cat([x_enc, t_enc], dim=-1)
        
        # Pass through MLP
        delta_x = self.network(input_vec)
        return delta_x

class StaticDeformationMLP(nn.Module):
    """
    Static deformation using grid features [S5, unofficial].
    """
    def __init__(self, grid_feature_dim=256, hidden_dim=256):
        super().__init__()
        self.grid = None # Placeholder for external grid lookup
        self.static_mlp = nn.Sequential(
            nn.Linear(grid_feature_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 3) # Output 3D displacement
        )
        # Initialize weights [S1]
        for layer in self.static_mlp:
            if isinstance(layer, nn.Linear):
                nn.init.xavier_normal_(layer.weight)
                layer.bias.data.zero_()

    def forward(self, rays_pts_emb):
        """
        rays_pts_emb: (N, 3) 3D coordinates
        Returns: deformed points (N, 3)
        """
        # Query grid feature [S5, unofficial]
        # Note: 'self.grid' is assumed to be a hash grid or similar structure
        # defined outside this MLP class.
        grid_feature = self.grid(rays_pts_emb) 
        
        # Compute displacement [S5, unofficial]
        dx = self.static_mlp(grid_feature)
        
        # Return deformed points [S5, unofficial]
        return rays_pts_emb + dx
```

### Edge Cases and Pitfalls
*   **Precision**: The final layer initialization with $\sigma=10^{-5}$ [S1] is critical; larger initial values can cause unstable optimization of Gaussian positions.
*   **Boundary Conditions**: Deformation fields must handle points outside the training domain gracefully, often by clamping or extrapolating grid features.
*   **Overfitting**: In LiDAR/NeRF fusion, MLPs with limited capacity (e.g., 3 hidden layers) may underperform compared to 3D convolutions in complex lane shift scenarios [S3].

## Subtopics

### [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md)
The Multi-MLP Linear Layer enables parallel training of multiple independent MLPs within a single computational graph using 3D tensors indexed by an MLP identifier [15116-multi-mlp-linear-layer.md]. It solves the inefficiency of managing distinct weight sets for different MLP instances by leveraging hardware parallelism without complex control flow. It is a core component of the Efficient Compressive Neural Representation (ECNR) framework. Choose this when training multiple distinct neural fields simultaneously requires shared memory access patterns.

### [Spatial-Ratio Neural Field Configuration](16086-spatial-ratio-neural-field-configuration.md)
The Spatial-Ratio Neural Field predicts position and shape transformations for 3D Gaussians to patch missing areas caused by masking, mapping them from an "all-selected" state to an adapted state under a given elastic ratio $e$ [16086-spatial-ratio-neural-field-configuration.md]. It serves as the core of the Gaussian Transform Field, enabling dynamic adjustment of Gaussian counts without degrading quality. It is distinguished by its use of a multi-plane implicit representation conditioned on a scalar elastic ratio, rather than static latent codes. Choose this when dynamic Gaussian density adjustment is required.

### [Latent Code Conditioning](16345-latent-code-conditioning.md)
Latent Code Conditioning injects instance-specific information via a latent vector $\mathbf{z}$ into a single Neural Field architecture, allowing it to represent multiple distinct data instances (e.g., different volumes or scenes) [16345-latent-code-conditioning.md]. It solves parameter sharing across heterogeneous data by adapting network output based on $\mathbf{z}$ without separate weights per instance. It differs from Multi-MLP Linear Layer [15116-multi-mlp-linear-layer.md] (fixed linear projections) and Spatial-Ratio Neural Field [16086-spatial-ratio-neural-field-configuration.md] (spatial coordinate conditioning) by relying on global or local latent codes. Choose this for multi-object or multi-scene representation.

### Fused Hash Encoding MLP Architecture
This variant composes a sampler from two consecutive neural density fields represented by "fused" MLPs employing hash encoding [S3]. It processes 3D positions via hash grids (min resolution 16, 5 levels, 2-dim features/level) followed by density prediction using an MLP with 2 hidden layers and 16 hidden features [S3]. The primary distinction between the two fused MLPs is their maximum hash grid resolution (512 vs 1024) [S3]. Choose this for efficient LiDAR/NeRF fusion in street scenes [S3].

### MLP Lidar Encoding
This variant processes LiDAR features using an MLP with three hidden layers of sizes 64, 96, and 128, outputting a 64-dim feature vector [S3]. It is used to extract high-dimensional features for LiDAR points in neural radiance fields [S3]. Note that this approach may underperform compared to sparse UNet-based methods in complex scenarios [S3]. Choose this for lightweight LiDAR feature extraction when 3D convolutions are too costly.

### CoDeF
CoDeF (Canonical Deformation Field) allows direct application of image processing algorithms to a canonical image, propagating results across time via a temporal deformation field [S4]. It enables efficient video processing but is limited by optical flow accuracy and struggles with complex motion [S4]. Choose this for video editing tasks where temporal consistency is derived from 2D image operations.

### Deformation Network (Static)
This variant queries a grid field for features at 3D point coordinates and computes displacement using a static MLP [S5, unofficial]. The deformed points are returned by adding the displacement to the original coordinates [S5, unofficial]. It is used in static deformation contexts within 4D Gaussian Splatting pipelines [S5, unofficial]. Choose this when deformation is static or pre-computed.

### Multi-Head MLP Decoder
An orthogonal approach to uncertainty that attaches multiple lightweight MLP decoders (heads) to a shared feature grid encoder [S6, unofficial]. It typically uses five heads, each with two layers [S6, unofficial]. Variance regularization encourages uncertainty to concentrate where reconstruction errors are largest [S6, unofficial]. On volumes up to $1024^3$ (4 GB), it achieved the highest reconstruction PSNR among uncertainty-aware methods and produced variance maps without ground truth [S6, unofficial]. Training takes 2–3× longer due to evidential loss computation [S6, unofficial]. Choose this for uncertainty-aware volume reconstruction.

## Operating characteristics
*   **Time Complexity**: Depends on the MLP depth and width. The standard 8-layer, 256-neuron MLP [S1] has $O(L \cdot W^2)$ complexity per query. Hash-encoded variants [S3] add $O(1)$ lookup time but require hash grid management.
*   **Memory Complexity**: The standard MLP [S1] requires $8 \times 256 \times 256$ weights plus biases, roughly 4 MB. Hash-encoded variants [S3] require memory proportional to the hash grid size (e.g., $16 \times 2^5 \times 2$ features per level).
*   **Performance**: The standard deformation MLP [S1] is optimized for dynamic Gaussian splatting, providing stable optimization via small initial deformations. The Multi-Head Decoder [S6, unofficial] offers high PSNR for large volumes but at the cost of 2–3× longer training time.
*   **Strengths**: Flexible conditioning (FiLM, latent codes, hash grids); stable initialization strategies for deformation.
*   **Limitations**: MLPs may underperform 3D convolutions in complex spatial contexts (e.g., LiDAR encoding [S3]); limited by optical flow accuracy in temporal deformation fields (CoDeF [S4]).

## Background
The concept of conditioning MLPs via feature-wise linear modulation (FiLM) or Conditional Batch Normalization (CBN) was introduced to allow neural networks to adapt to different conditions or instances [S2, unofficial]. The specific configuration for deformation MLPs in dynamic Gaussian Splatting, including the 8-layer structure and $10^{-5}$ final layer initialization, was detailed in the "Time of the Flight of the Gaussians" paper [S1]. Hash-encoded MLPs for LiDAR/NeRF fusion were explored in LidaRF [S3]. The use of multi-head MLP decoders for uncertainty in scientific volumes was proposed in the AREA-202603 report [S6, unofficial].
