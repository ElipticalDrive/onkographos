# Deformation MLP Configuration

Also called: Conditional Batch Normalization, Deformation MLP Setup, Feature-wise Linear Modulation (FiLM), Feature-wise transformations, MLP setup

## Overview
The Deformation MLP Configuration defines the architecture, initialization, and conditioning mechanism for a Multi-Layer Perceptron (MLP) that predicts spatial or temporal deformations (displacements) for volumetric primitives, such as 3D Gaussians, within a neural field. It solves the problem of mapping canonical coordinates to deformed coordinates by learning a continuous displacement field $\delta\mathbf{x}$. It is distinguished from sibling methods like [MLP with Input Skips](1643-mlp-with-input-skips.md) by its specific focus on outputting delta positions rather than raw density or color, and from [Residual Block with Shortcut (ReLU MLP Extension)](10016-residual-block-with-shortcut-relu-mlp-extension.md) by its use of conditional scaling and biasing (FiLM) or specific initialization strategies to stabilize optimization of small deformations [S1][S2, unofficial].

## How it works
The method configures an MLP to predict a displacement vector $\delta\mathbf{x}$ given input coordinates and optional conditioning variables.

**Inputs and Outputs:**
*   **Input:** Spatial coordinates $\mathbf{x}$ (and optionally time $t$ or other latent codes $\mathbf{z}$).
*   **Output:** Displacement vector $\delta\mathbf{x}$ (e.g., delta position for a Gaussian).

**Data Structures and Layout:**
The standard configuration consists of an 8-layer MLP with 256 neurons per hidden layer [S1].
*   **Positional Encoding:** Input coordinates are encoded using sinusoidal positional encoding.
    *   Spatial frequency $L_x = 10$ [S1].
    *   Temporal frequency $L_t = 10$ [S1].
*   **Layer Dimensions:**
    *   Input dimension: Determined by the positional encoding of $\mathbf{x}$ and $t$.
    *   Hidden layers: 8 layers, each mapping 256 features to 256 features.
    *   Output layer: Maps 256 features to the dimension of the displacement vector (e.g., 3 for 3D position) [S1].

**Initialization:**
1.  **Hidden Layers:** Weights are initialized using Xavier normal initialization. Biases are initialized to zero [S1].
2.  **Output Layer:** The final linear layer's weights are initialized from a normal distribution with standard deviation $\sigma = 10^{-5}$. Biases are typically zero [S1]. This small initialization ensures that the network starts with near-zero deformations ($\delta\mathbf{x} \approx 0$), promoting stable optimization [S1].

**Conditioning (FiLM/CBN):**
In configurations utilizing Feature-wise Linear Modulation (FiLM) or Conditional Batch Normalization (CBN), the MLP layers are conditioned on a latent vector $\mathbf{z}$ [S2, unofficial].
*   For each layer $i$, two small networks (or linear projections) predict scale $\boldsymbol{\gamma_i}(\mathbf{z})$ and bias $\boldsymbol{\beta_i}(\mathbf{z})$ vectors.
*   The size of $\boldsymbol{\gamma_i}$ and $\boldsymbol{\beta_i}$ matches the output size of layer $i$ [S2, unofficial].
*   The transformation is applied as:
    $$ \hat{\mathbf{x}}_i = L_i(\mathbf{x}) \odot \boldsymbol{\gamma_i}(\mathbf{z}) + \boldsymbol{\beta_i}(\mathbf{z}) $$
    where $L_i(\mathbf{x})$ is the output of the $i$-th linear/activation block, $\odot$ is element-wise multiplication, and $\hat{\mathbf{x}}_i$ is the conditioned output [S2, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import math

class DeformationMLP(nn.Module):
    def __init__(self, in_dim, out_dim=3, hidden_dim=256, num_layers=8, 
                 use_film=False, cond_dim=0):
        super().__init__()
        self.num_layers = num_layers
        self.hidden_dim = hidden_dim
        self.use_film = use_film
        
        # Hidden layers
        self.layers = nn.ModuleList()
        for i in range(num_layers):
            in_f = in_dim if i == 0 else hidden_dim
            out_f = hidden_dim
            linear = nn.Linear(in_f, out_f)
            
            # Xavier normal initialization for weights
            nn.init.xavier_normal_(linear.weight)
            # Zero initialization for biases
            nn.init.zeros_(linear.bias)
            
            self.layers.append(linear)
            
            if use_film:
                # FiLM parameters: scale and bias networks
                # These map cond_dim -> hidden_dim
                self.layers.append(nn.Linear(cond_dim, hidden_dim)) # gamma
                self.layers.append(nn.Linear(cond_dim, hidden_dim)) # beta

        # Output layer
        self.output_layer = nn.Linear(hidden_dim, out_dim)
        # Small std dev initialization for stable optimization of deltas
        nn.init.normal_(self.output_layer.weight, mean=0, std=1e-5)
        nn.init.zeros_(self.output_layer.bias)

    def forward(self, x, cond=None):
        """
        x: (B, in_dim) - Input coordinates (possibly pre-encoded)
        cond: (B, cond_dim) - Conditioning latent vector (optional)
        """
        h = x
        layer_idx = 0
        
        for i in range(self.num_layers):
            # Linear transformation
            linear = self.layers[layer_idx]
            h = linear(h)
            layer_idx += 1
            
            # Apply FiLM conditioning if enabled
            if self.use_film and cond is not None:
                gamma = self.layers[layer_idx](cond)
                layer_idx += 1
                beta = self.layers[layer_idx](cond)
                layer_idx += 1
                # Element-wise modulation
                h = h * gamma + beta
            
            # Activation (e.g., ReLU or SIREN, not specified in core config, 
            # assuming standard ReLU for baseline MLP unless SIREN is specified)
            # Note: The parent article [MLP Neural Field] mentions configurable activation.
            # We assume a standard activation here as per general MLP definition.
            h = torch.relu(h)

        # Output layer
        delta_x = self.output_layer(h)
        return delta_x
```

## Subtopics

### [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md)
A specialized linear transformation module enabling parallel training of multiple independent MLPs within a single computational graph using 3D tensors indexed by an MLP identifier. It is a core component of the Efficient Compressive Neural Representation (ECNR) framework.

### [Spatial-Ratio Neural Field Configuration](16086-spatial-ratio-neural-field-configuration.md)
A module predicting position and shape transformations for 3D Gaussians to patch missing areas, mapping them from an "all-selected" state to an adapted state under an elastic ratio $e$. It uses a multi-plane implicit representation conditioned on the scalar elastic ratio, distinguishing it from static latent codes.

### Fused Hash Encoding MLP Architecture
Uses "fused" MLPs with hash encoding to process 3D positions for density prediction. It composes a sampler from two consecutive neural density fields. Parameters include a minimum hash grid resolution of 16, 5 levels of hash encoding, and 2-dim features per level. The MLPs have 2 layers with 16 hidden features [S3].

### MLP Lidar Encoding
Processes LiDAR features using an MLP with three hidden layers. Hidden layer feature sizes are 64, 96, and 128. The output layer produces a 64-dim feature vector [S3].

### CoDeF
Allows direct application of image processing algorithms to a canonical image, propagating results across time via a temporal deformation field. It is limited by optical flow accuracy and struggles with complex motion [S4].

### Deformation Network (Static)
Queries a grid field for features at 3D point coordinates and computes displacement using a static MLP. The deformed points are returned by adding the displacement to the original coordinates: `return rays_pts_emb[:, :3] + dx` [S5, unofficial].

### Multi-Head MLP Decoder
Attaches multiple lightweight MLP decoders (heads) to a shared feature grid encoder to amortize parameter cost for ensemble diversity. It uses five heads, each with two layers. Variance regularization encourages uncertainty to concentrate where reconstruction errors are largest. It achieves high reconstruction PSNR on volumes up to $1024^3$ [S6, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of MLP layers and the input dimensionality. The use of positional encoding adds a constant factor overhead per query.
*   **Memory Complexity:** Proportional to the number of parameters in the MLP ($8 \times 256 \times 256 + 256 \times 3$ for the standard config [S1]). FiLM conditioning adds parameters proportional to the number of layers and the conditioning dimension.
*   **Strengths:** The specific initialization ($10^{-5}$ std dev for output weights) ensures stable training by starting deformations near zero, preventing large initial errors [S1]. FiLM conditioning allows flexible adaptation to different scenes or time steps without retraining the entire network [S2, unofficial].
*   **Limitations:** Standard MLPs lack spatial locality, requiring high-dimensional inputs (positional encoding) and potentially suffering from spectral bias (preferring low frequencies) unless SIREN or input skips are used [S1, 1643-mlp-with-input-skips.md].
*   **When to use:** When modeling continuous deformations of volumetric primitives (e.g., dynamic 3D Gaussians) where the deformation field is smooth and global.
*   **When not to use:** For highly discontinuous or local deformations where grid-based or hash-based methods (like [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md) or [Spatial-Ratio Neural Field Configuration](16086-spatial-ratio-neural-field-configuration.md)) might be more efficient.

## Background
The Deformation MLP Configuration originates from methods optimizing dynamic radiance fields and 3D Gaussian Splatting for time-of-flight (ToF) data or dynamic scenes. The specific architecture (8 layers, 256 neurons, $L_x=10, L_t=10$) and initialization strategy ($10^{-5}$ std dev) are detailed in the "Time of the Flight of the Gaussians" paper [S1]. The conditioning mechanism (FiLM/CBN) is based on the work by de Vries et al. [S2, unofficial].
