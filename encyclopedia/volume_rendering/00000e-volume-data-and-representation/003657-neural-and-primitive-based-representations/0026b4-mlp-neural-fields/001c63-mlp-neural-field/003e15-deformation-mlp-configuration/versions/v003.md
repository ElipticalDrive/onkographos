# Deformation MLP Configuration

Also called: Conditional Batch Normalization, Deformation MLP Setup, Feature-wise Linear Modulation (FiLM), Feature-wise transformations, MLP setup

## Overview
Deformation MLP Configuration refers to the architectural setup and conditioning mechanisms used to map spatial-temporal coordinates to deformation fields (displacements) within neural volume representations. It solves the problem of representing dynamic or variable-volume data by allowing a single neural field to adapt its output based on external context (such as time, identity, or elastic ratios) rather than learning a static mapping. It is distinguished from standard MLP Neural Fields by its explicit handling of conditional inputs—either via concatenation, feature-wise modulation, or hypernetworks—to generate instance-specific deformations [S1][S2, unofficial].

## How it works
The method configures a Multi-Layer Perceptron (MLP) to predict displacement vectors ($\delta\mathbf{x}$) or transformation parameters based on input coordinates and optional conditioning codes.

### Inputs and Outputs
*   **Inputs:**
    *   Spatial coordinates $\mathbf{x} \in \mathbb{R}^3$ (often positional encoded).
    *   Temporal coordinate $t \in \mathbb{R}$ (often positional encoded) [S1].
    *   Optional latent code $\mathbf{z}$ for conditioning (identity, elastic ratio, etc.) [S2, unofficial][S5].
*   **Outputs:**
    *   Delta position $\delta\mathbf{x} \in \mathbb{R}^3$ [S1].
    *   Transformation parameters (e.g., scale, rotation) for Gaussian splats [S5].

### Data Structures and Layout
The standard deformation MLP configuration consists of the following structure [S1]:
*   **Layers:** 8 fully connected linear layers.
*   **Neurons:** 256 neurons per hidden layer.
*   **Input Encoding:**
    *   Spatial frequencies $L_x = 10$.
    *   Temporal frequencies $L_t = 10$.
    *   Input vector combines encoded $\mathbf{x}$ and $t$.
*   **Output Layer:** Final linear layer maps 256 features to 3 dimensions (delta position).

### Initialization and Parameters
1.  **Weights:** Initialized using Xavier normal initialization [S1].
2.  **Biases:** Initialized to zero [S1].
3.  **Final Layer Weights:** The weights of the final linear layer (mapping 256 features to $\delta\mathbf{x}$) are initialized from a normal distribution with standard deviation $\sigma = 10^{-5}$ [S1]. This ensures small initial deformations for stable optimization.
4.  **Learning Rate:** Typically starts at $\gamma_{MLP} = 0.0008$ and decays exponentially [S1].

### Conditioning Mechanisms
Conditioning allows the MLP to represent multiple instances or dynamic states.

#### 1. Concatenation Conditioning
*   **Method:** The latent code $\mathbf{z}$ is concatenated with the input coordinates/features before entering the MLP [S2, unofficial].
*   **Pitfall:** Only the first layer directly incorporates the condition; subsequent layers operate on internal feature representations, requiring the network to propagate the condition through non-linearities [S2, unofficial].

#### 2. Feature-wise Linear Modulation (FiLM) / Conditional Batch Normalization
*   **Method:** Small neural networks $\boldsymbol{\beta_i}$ and $\boldsymbol{\gamma_i}$ predict scale and bias vectors based on the latent code $\mathbf{z}$. These are applied to the layer outputs $\mathbf{x}_i$ as [S2, unofficial]:
    $$ \hat{\mathbf{x}}_i = L_i(\mathbf{x}) \odot \boldsymbol{\gamma_i}(\mathbf{z}) + \boldsymbol{\beta_i}(\mathbf{z}) $$
*   **Parameter:** The size of $\boldsymbol{\gamma_i}$ and $\boldsymbol{\beta_i}$ matches the output size of layer $i$ [S2, unofficial].

#### 3. HyperNetwork Conditioning
*   **Method:** A secondary network (HyperNetwork) predicts the weights of the deformation MLP decoder from the latent code [S2, unofficial]. This creates a distinct MLP for each instance [S2, unofficial].

#### 4. Spatial-Ratio Conditioning (Multi-Plane)
*   **Method:** Uses six 2D planes to model a 4D voxel space $(x, y, z, e)$, where $e$ is an elastic ratio [S5].
*   **Layout:** Planes correspond to pairs $\{(x, y), (x, z), (y, z), (x, e), (y, e), (z, e)\}$ [S5].
*   **Parameters:**
    *   Resolutions: $\{64, 64, 64, 100\}$ for dimensions $\{x, y, z, e\}$ respectively [S5].
    *   Hidden feature dimension $D = 64$ for the GsNet and Multi-Head Predictor [S5].

import torch.nn as nn
import math

class DeformationMLP(nn.Module):
    def __init__(self, input_dim=3, hidden_dim=256, num_layers=8, 
                 L_x=10, L_t=10, use_conditioning=False, cond_dim=0):
        super().__init__()
        self.num_layers = num_layers
        self.hidden_dim = hidden_dim
        self.use_conditioning = use_conditioning
        
        # Positional Encoding parameters
        self.L_x = L_x
        self.L_t = L_t
        
        # Linear layers
        self.layers = nn.ModuleList()
        for i in range(num_layers):
            if i == 0:
                # Input dimension depends on PE and conditioning
                pe_dim = 2 * input_dim * (L_x + L_t) # Simplified PE dim calculation
                if use_conditioning:
                    in_features = pe_dim + cond_dim
                else:
                    in_features = pe_dim
            else:
                in_features = hidden_dim
            
            out_features = hidden_dim
            self.layers.append(nn.Linear(in_features, out_features))
            
        # Final layer: maps to delta position (3D)
        self.final_layer = nn.Linear(hidden_dim, 3)
        
        self._init_weights()

    def positional_encode(self, x, t):

        # Concatenate x and t

## Subtopics

### [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md)
HyperNetwork Conditioning uses a secondary neural network to predict the weights of the deformation MLP decoder from a latent code. Unlike concatenation, which shares decoder parameters across all instances, this approach creates a distinct Neural Field (with unique weights) for each input instance. This separation allows the primary decoder to maintain lower complexity, resulting in a more compact representation.

### [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md)
The Multi-MLP Linear Layer is a specialized linear transformation module designed to enable the parallel training of multiple independent MLPs within a single computational graph. It solves the problem of efficiently managing distinct weight and bias parameters for different MLP instances by using 3D tensors indexed by an MLP identifier. Unlike conventional linear layers that use 2D matrices for a single MLP, this method allows batch processing of multiple MLPs simultaneously, leveraging hardware parallelism without complex control flow. It is a core component of the Efficient Compressive Neural Representation (ECNR) framework.

### Concatenation Conditioning
Concatenation Conditioning involves concatenating the latent code with the input coordinates or features before feeding them into the Neural Field decoder [S2, unofficial].
*   **Pitfall:** Only the first layer directly incorporates the condition; remaining layers operate only on internal feature representations, requiring the network to distinguish samples based on input alone [S2, unofficial].

### Autoencoder/Autodecoder Conditioning
*   **Autoencoder:** The model is trained using an encoder to produce latent codes from the input data [S2, unofficial].
*   **Autodecoder:** The latent vector is optimized jointly with the decoder weights for each sample, without an explicit encoder [S2, unofficial].

### Global Conditioning
Global Conditioning encodes the whole information about a data sample in one single latent vector [S2, unofficial].

### Local Conditioning
Local Conditioning spreads information about a data sample over multiple latent codes assigned to specific subsets of spatio-temporal coordinates (regions or time steps) [S2, unofficial].

### Fused Hash Encoding MLP Architecture
*   **Step:** Compose the sampler from two consecutive neural density fields [S3]. Represent each density field using 'fused' MLPs that employ hash encoding to process 3D positions [S3]. Predict density using an MLP following the hash encoding [S3].
*   **Parameters:** Minimum hash grid resolution: 16 [S3]. Number of hash encoding levels: 5 [S3]. Hash feature dimension: 2-dim features per level [S3].

### MLP Lidar Encoding
*   **Step:** Process LiDAR features using an MLP with three hidden layers [S3].
*   **Parameters:** Hidden layer feature sizes: 64, 96, 128 [S3]. Output layer feature size: 64-dim feature vector [S3].

### CoDeF
*   **Step:** Allow the direct application of image processing algorithms to the canonical image [S4]. Propagate results across time via the temporal deformation field [S4]. Enable efficient video processing [S4].
*   **Pitfall:** Limited by optical flow accuracy and has difficulty in modeling complex motion [S4].

### Spatial-Ratio Neural Field Configuration
*   **Definition:** A multi-plane implicit representation modeling a 4D voxel space $(x, y, z, e)$ using six 2D planes to predict Gaussian transformations conditioned on an elastic ratio $e$ [S5].
*   **Parameters:** $D$: hidden feature dimension for GsNet and Multi-Head Predictor; set to 64 [S5]. $D$: hidden feature dimension of the Multi-Head Predictor for predicting transformations under a given ratio; set to 64 [S5].
*   **Layout:** Planes: $\{(x, y), (x, z), (y, z), (x, e), (y, e), (z, e)\}$ [S5]. Resolutions: $\{64, 64, 64, 100\}$ for dimensions $\{x, y, z, e\}$ respectively [S5].

### Deformation Network (Static)
*   **Step:** Query the grid field for features at the 3D point coordinates: `grid_feature = self.grid(rays_pts_emb[:,:3])` [S6, unofficial]. Compute displacement using the static MLP: `dx = self.static_mlp(grid_feature)` [S6, unofficial]. Return deformed points by adding displacement to original coordinates: `return rays_pts_emb[:, :3] + dx` [S6, unofficial].

### Multi-Head MLP Decoder
*   **Definition:** An orthogonal approach to uncertainty that attaches multiple lightweight MLP decoders (heads) to a shared feature grid encoder to amortize parameter cost of ensemble diversity [S7, unofficial].
*   **Step:** 1. Attach multiple lightweight MLP decoders (five heads, two layers each) to a shared feature grid encoder [S7, unofficial]. 2. Apply variance regularization to encourage the model’s uncertainty to concentrate where reconstruction errors are largest [S7, unofficial].
*   **Performance:** On volumes up to $1024^3$ (4 GB), RMDSRN achieved the highest reconstruction PSNR among all uncertainty-aware methods and produced variance maps identifying high-error regions without ground truth [S7, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of layers (typically 8) and hidden dimensions (256). Conditioning via concatenation adds negligible overhead. Hypernetworks add the cost of the secondary network.
*   **Memory Complexity:** Proportional to the number of parameters in the MLP ($8 \times 256 \times 256$ weights + biases) plus any conditioning parameters. Hash encoding variants add memory for the hash grid.
*   **Strengths:** Flexible conditioning allows representation of dynamic scenes or multiple objects. Small initial deformation weights ($10^{-5}$) aid convergence [S1].
*   **Limitations:** Concatenation conditioning may struggle to propagate conditions through deep networks [S2, unofficial]. Hypernetworks increase training complexity.
*   **When to use:** When representing dynamic volumes or multiple instances with a single model.
*   **When not to use:** For static, single-instance volumes where a standard MLP suffices.

## Background
The Deformation MLP Configuration originates from methods for dynamic neural radiance fields and 3D Gaussian Splatting, where static representations are extended to handle motion. Key implementations include the deformation MLP in "Time of the Flight of the Gaussians" [S1] and various conditioning techniques described in "Introduction to Neural Fields" [S2, unofficial]. The use of hash encoding in MLPs for density prediction appears in "LidaRF" [S3]. The spatial-ratio configuration is detailed in "FlexGS" [S5]. Static deformation networks are used in "4DGS" [S6, unofficial]. Uncertainty-aware multi-head decoders are described in "PDF Deep Learning Methods..." [S7, unofficial].
