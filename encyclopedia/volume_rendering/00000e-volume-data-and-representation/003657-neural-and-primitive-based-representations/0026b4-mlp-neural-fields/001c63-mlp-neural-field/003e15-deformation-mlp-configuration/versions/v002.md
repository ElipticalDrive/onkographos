# Deformation MLP Configuration

Also called: Conditional Batch Normalization, Deformation MLP Setup, Feature-wise Linear Modulation (FiLM), Feature-wise transformations, MLP setup

## Overview
Deformation MLP Configuration defines the architecture, initialization, and conditioning mechanisms for a Multi-Layer Perceptron (MLP) used to predict spatial or temporal deformations (delta positions) in neural volume rendering. It solves the problem of mapping canonical coordinates to deformed coordinates by configuring the MLP's weights, biases, and input processing to ensure stable optimization and effective conditioning on latent codes or external features [S1][S2, unofficial]. It is distinguished from standard MLP Neural Fields by its specific focus on deformation outputs and the integration of conditioning strategies like FiLM or concatenation to handle dynamic or multi-instance scenes [S1][S2, unofficial].

## How it works
### Inputs and Outputs
*   **Inputs:** Spatial coordinates $\mathbf{x}$, time $t$, and optionally a latent code $\mathbf{z}$ or LiDAR features [S1, S3].
*   **Outputs:** Delta position $\delta\mathbf{x}$ (deformation vector) or high-dimensional feature vectors [S1, S3].

### Data Structures and Layout
The core deformation MLP typically follows a fixed architecture:
*   **Structure:** 8 hidden layers with 256 neurons per layer [S1].
*   **Input Encoding:** Positional encoding is applied to spatial coordinates $\mathbf{x}$ and time $t$ with frequencies $L_x = 10$ and $L_t = 10$ respectively [S1].
*   **Final Layer:** Maps the final 256 features to the delta position $\delta\mathbf{x}$ [S1].

### Initialization Steps
1.  **Hidden Layers:** Initialize all weights using Xavier normal initialization [S1].
2.  **Biases:** Initialize all biases to zero [S1].
3.  **Final Layer:** Initialize weights of the final linear layer (mapping 256 features to $\delta\mathbf{x}$) from a normal distribution with standard deviation $\sigma = 10^{-5}$ [S1]. This ensures small initial deformations for stable optimization [S1].

### Conditioning Mechanisms
The MLP can be conditioned via several methods to incorporate context (e.g., identity, time, or scene variations):

#### 1. Concatenation Conditioning
*   **Step:** Concatenate the latent code $\mathbf{z}$ with the input coordinates/features [S2, unofficial].
*   **Step:** Feed the concatenated tensor into the Neural Field decoder [S2, unofficial].
*   **Pitfall:** Only the first layer directly incorporates the condition; remaining layers operate only on internal feature representations, requiring the network to distinguish samples based on input alone [S2, unofficial].

#### 2. Feature-wise Linear Modulation (FiLM) / Conditional Batch Normalization
*   **Definition:** Uses small neural networks $\boldsymbol{\beta_i}$ and $\boldsymbol{\gamma_i}$ to predict scale and bias vectors for each layer $i$, conditioned on the latent code $\mathbf{z}$ [S2, unofficial].
*   **Formula:**
    $$ \hat{\boldsymbol{x}}_i = L_i(\boldsymbol{x}) \odot \boldsymbol{\gamma_i}(\boldsymbol{z}) + \boldsymbol{\beta_i}(\boldsymbol{z}) $$
    where $L_i(\boldsymbol{x})$ is the output of the $i$-th linear layer, $\odot$ is element-wise multiplication, and $\boldsymbol{\gamma_i}, \boldsymbol{\beta_i}$ are vectors matching the layer's output size [S2, unofficial].

#### 3. HyperNetwork Conditioning
*   **Step:** Use a secondary network (HyperNetwork) to predict the decoder's weights from the latent code [S1].
*   **Effect:** Creates a distinct Neural Field (unique weights) for each input instance, allowing the primary decoder to maintain lower complexity [S1].

#### 4. Autoencoder/Autodecoder Conditioning
*   **Step:** Train the model in an autoencoder manner (using an encoder to produce latent codes) or an autodecoder manner (optimizing a learnable latent vector per sample jointly with decoder weights) [S2, unofficial].
*   **Definition:** The mapping becomes $f: (\Omega, \mathcal{Z}) \mapsto \mathcal{X}$, where $\mathcal{Z}$ is the latent space [S2, unofficial].

#### 5. Global vs. Local Conditioning
*   **Global Conditioning:** Encodes the whole information about a data sample in one single latent vector [S2, unofficial].
*   **Local Conditioning:** Spreads information about a data sample over multiple latent codes assigned to specific subsets of spatio-temporal coordinates (regions or time steps) [S2, unofficial].

### Specialized Architectures

#### Fused Hash Encoding MLP
*   **Step:** Compose the sampler from two consecutive neural density fields [S3].
*   **Step:** Represent each density field using 'fused' MLPs that employ hash encoding to process 3D positions [S3].
*   **Step:** Predict density using an MLP following the hash encoding [S3].
*   **Parameters:** Minimum hash grid resolution: 16; Number of hash encoding levels: 5; Hash feature dimension: 2-dim features per level [S3].

#### MLP LiDAR Encoding
*   **Step:** Process LiDAR features using an MLP with three hidden layers [S3].
*   **Parameters:** Hidden layer feature sizes: 64, 96, 128; Output layer feature size: 64-dim feature vector [S3].

#### CoDeF (Canonical Deformation Field)
*   **Step:** Allow direct application of image processing algorithms to the canonical image [S4].
*   **Step:** Propagate results across time via the temporal deformation field [S4].
*   **Pitfall:** Limited by optical flow accuracy and has difficulty in modeling complex motion [S4].

## Subtopics

### [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md)
HyperNetwork Conditioning is a method for conditioning a Neural Field decoder by using a secondary neural network (the HyperNetwork) to predict the decoder's weights from a latent code. Unlike concatenation-based conditioning, which shares decoder parameters across all instances and relies on the latent code to distinguish them, this approach creates a distinct Neural Field (with unique weights) for each input instance. This separation allows the primary decoder network to maintain lower complexity, resulting in a more compact representation. See [HyperNetwork Conditioning](12585-hypernetwork-conditioning.md).

### [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md)
The Multi-MLP Linear Layer is a specialized linear transformation module designed to enable the parallel training of multiple independent Multi-Layer Perceptrons (MLPs) within a single computational graph. It solves the problem of efficiently managing distinct weight and bias parameters for different MLP instances by using 3D tensors indexed by an MLP identifier. Unlike conventional linear layers that use 2D matrices for a single MLP, this method allows batch processing of multiple MLPs simultaneously, leveraging hardware parallelism without complex control flow. It is a core component of the Efficient Compressive Neural Representation (ECNR) framework. See [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md).

### Concatenation Conditioning
A conditioning method where the latent code is concatenated with the input coordinates/features before being fed into the Neural Field decoder [S2, unofficial]. The primary limitation is that only the first layer directly incorporates the condition, forcing subsequent layers to rely on internal feature representations to distinguish samples [S2, unofficial].

### Autoencoder/Autodecoder Conditioning
A training paradigm where the Neural Field is conditioned via latent codes. In the autoencoder manner, an encoder produces the latent codes from input data. In the autodecoder manner, a learnable latent vector is optimized jointly with the decoder weights for each sample [S2, unofficial].

### Global Conditioning
Encoding the whole information about a data sample in one single latent vector [S2, unofficial].

### Local Conditioning
Spreading information about a data sample over multiple latent codes assigned to specific subsets of spatio-temporal coordinates (regions or time steps) [S2, unofficial].

### Fused Hash Encoding MLP Architecture
An architecture using 'fused' MLPs with hash encoding to process 3D positions for density prediction. It typically uses a minimum hash grid resolution of 16, 5 levels of hash encoding, and 2-dim features per level [S3].

### MLP Lidar Encoding
An MLP configuration for processing LiDAR features, consisting of three hidden layers with feature sizes 64, 96, and 128, outputting a 64-dim feature vector [S3].

### CoDeF
A method that allows direct application of image processing algorithms to a canonical image, propagating results across time via a temporal deformation field. It is limited by optical flow accuracy and struggles with complex motion [S4].

## Operating characteristics
*   **Complexity:** The standard deformation MLP (8 layers, 256 neurons) has moderate memory requirements but can be computationally expensive if evaluated at high frequencies [S1].
*   **Stability:** Initializing the final layer weights with a small standard deviation ($10^{-5}$) is critical for stable optimization of deformation fields [S1].
*   **Conditioning Trade-offs:** Concatenation is simple but may limit the network's ability to distinguish complex variations in deeper layers [S2, unofficial]. FiLM/HyperNetwork approaches offer more expressive conditioning but increase parameter count or computational overhead [S1][S2, unofficial].
*   **Performance:** LiDAR encoding with MLPs may underperform compared to 3D convolutional networks in global context learning scenarios [S3].

## Background
The Deformation MLP Configuration originates from research into dynamic neural radiance fields and time-of-flight (ToF) signal optimization. Key implementations include the "Time of the Flight of the Gaussians" method, which uses an 8-layer, 256-neuron MLP with specific positional encoding frequencies ($L_x=10, L_t=10$) and specialized initialization for deformation prediction [S1]. Conditioning techniques like FiLM and HyperNetworks were adapted from generative modeling literature (e.g., [Ha et al., 2016], [de Vries et al., 2018]) to allow neural fields to represent multiple instances or dynamic scenes [S2, unofficial]. Hash encoding and LiDAR-specific MLPs were introduced to improve efficiency and handle sparse sensor data in large-scale scenes [S3].
