# Deformation MLP Configuration

Also called: Conditional Batch Normalization, Deformation MLP Setup, Feature-wise Linear Modulation (FiLM), Feature-wise transformations, MLP setup

## Overview
The Deformation MLP Configuration defines the architecture, initialization, and conditioning strategy for a Multi-Layer Perceptron (MLP) used to predict spatial or temporal deformations in neural field representations, such as dynamic 3D Gaussian Splatting or time-varying radiance fields. It solves the problem of mapping static canonical coordinates to deformed world coordinates by learning a displacement field $\delta\mathbf{x}$. It is distinguished from sibling methods like [MLP with Input Skips](1643-mlp-with-input-skips.md) by its specific focus on conditional modulation (often via FiLM or bias initialization) to handle dynamic scenes, and from [Residual Block with Shortcut (ReLU MLP Extension)](10016-residual-block-with-shortcut-relu-mlp-extension.md) by its typical use of standard fully connected layers with specific initialization schemes for stability in optimization [S1][S2, unofficial].

## How it works
### Inputs and Outputs
*   **Inputs:** Canonical coordinates $\mathbf{x}_c$ (e.g., 3D position $\mathbf{x}_k$) and optional conditioning variables such as time $t$ or a latent code $\mathbf{z}$ [S1][S2, unofficial].
*   **Outputs:** Deformed coordinates $\mathbf{x}_d = \mathbf{x}_c + \delta\mathbf{x}$, where $\delta\mathbf{x}$ is the predicted displacement vector [S1][S5, unofficial].

### Data Structures
The MLP consists of a sequence of linear layers with non-linear activations.
*   **Structure:** Typically 8 layers with 256 neurons per layer [S1].
*   **Input Encoding:** Positional encoding is applied to spatial coordinates ($L_x = 10$ frequencies) and time ($L_t = 10$ frequencies) [S1].
*   **Weights:** $W_l \in \mathbb{R}^{d_{out} \times d_{in}}$ for layer $l$.
*   **Biases:** $b_l \in \mathbb{R}^{d_{out}}$ for layer $l$.

### Initialization
1.  **Hidden Layers:** Weights are initialized using Xavier normal initialization. Biases are initialized to zero [S1].
2.  **Final Layer:** The final linear layer (mapping 256 features to the dimension of $\delta\mathbf{x}$, typically 3) has weights initialized from a normal distribution with standard deviation $\sigma = 10^{-5}$. Biases are initialized to zero [S1]. This ensures small initial deformations for stable optimization [S1].

### Algorithm
The deformation field is computed as follows:

1.  **Encode Input:** Apply positional encoding to the input coordinates $\mathbf{x}_{in}$ (combining spatial and temporal components if applicable) to produce $\mathbf{x}_{enc}$ [S1].
2.  **Forward Pass:** Iterate through layers $l = 1$ to $L$:
    $$ \mathbf{h}_l = \sigma_{act}(W_l \mathbf{h}_{l-1} + b_l) $$
    where $\mathbf{h}_0 = \mathbf{x}_{enc}$, $\sigma_{act}$ is the activation function (e.g., ReLU), and $\mathbf{h}_L$ is the final hidden representation [S1].
3.  **Predict Displacement:** Compute $\delta\mathbf{x} = W_{final} \mathbf{h}_L + b_{final}$ [S1].
4.  **Deform:** Compute output $\mathbf{x}_{out} = \mathbf{x}_{in} + \delta\mathbf{x}$ [S5, unofficial].

### Conditional Modulation (FiLM/CBN)
When conditioning on a latent code $\mathbf{z}$ (global or local), the method employs Feature-wise Linear Modulation (FiLM) or Conditional Batch Normalization [S2, unofficial].
1.  **Generate Parameters:** Small networks $\boldsymbol{\gamma_i}(\mathbf{z})$ and $\boldsymbol{\beta_i}(\mathbf{z})$ predict scale and bias vectors matching the layer output size [S2, unofficial].
2.  **Apply Modulation:**
    $$ \hat{\mathbf{x}}_i = L_i(\mathbf{x}) \odot \boldsymbol{\gamma_i}(\mathbf{z}) + \boldsymbol{\beta_i}(\mathbf{z}) $$
    where $L_i$ is the linear transformation of layer $i$, $\odot$ is element-wise multiplication, and $\mathbf{x}$ is the layer input [S2, unofficial].

### Parameters
*   **Layer Size:** Output size of scale/bias vectors matches the layer's output dimension [S2, unofficial].
*   **Optimizer:** Adam with $\beta=(0.9, 0.999)$, $\epsilon=10^{-15}$ [S1].
*   **Learning Rate:** Starts at $\gamma_{MLP} = 0.0008$, decays exponentially to $1.6 \times 10^{-6}$ over 60K iterations [S1].

### Edge Cases and Pitfalls
*   **Precision:** The final layer's small weight initialization ($10^{-5}$) prevents large initial gradients that could destabilize training [S1].
*   **Boundary Conditions:** Deformations must be bounded to prevent Gaussians or points from moving outside the scene bounds or causing self-intersection [S1][S5, unofficial].
*   **Optical Flow Limitation:** In video processing contexts, deformation fields are limited by the accuracy of the underlying optical flow or motion estimation, struggling with complex motion [S4].

## Subtopics

### [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md)
The Multi-MLP Linear Layer enables parallel training of multiple independent MLPs within a single computational graph using 3D tensors indexed by an MLP identifier. It solves the problem of managing distinct weights for different MLP instances efficiently. It is chosen when batch processing multiple MLPs simultaneously is required, leveraging hardware parallelism. It is a core component of the Efficient Compressive Neural Representation (ECNR) framework.

### [Spatial-Ratio Neural Field Configuration](16086-spatial-ratio-neural-field-configuration.md)
The Spatial-Ratio Neural Field predicts position and shape transformations for 3D Gaussians to patch missing areas caused by masking, mapping them from an "all-selected" state to an adapted state under an elastic ratio $e$. It serves as the core of the Gaussian Transform Field, enabling dynamic adjustment of Gaussian counts without quality degradation. It is distinguished by using a multi-plane implicit representation conditioned on a scalar elastic ratio, rather than static latent codes.

### [Latent Code Conditioning](16345-latent-code-conditioning.md)
Latent Code Conditioning injects global or local context into a Neural Field by associating a latent vector $\mathbf{z}$ with query evaluation. It enables a single network to represent multiple data instances (shapes, transfer functions, dynamic scenes). Unlike Concatenation Conditioning, which appends $\mathbf{z}$ to the input, or HyperNetwork Conditioning, which generates weights, this family includes strategies ranging from direct input injection to weight generation and spatial grid expansion.

#### Fused Hash Encoding MLP Architecture
Composes a sampler from two consecutive neural density fields using "fused" MLPs with hash encoding [S3].
*   **Steps:** Process 3D positions with hash encoding, then predict density using an MLP [S3].
*   **Parameters:** Minimum hash grid resolution: 16; Levels: 5; Feature dimension: 2-dim per level; MLP layers: 2 with 16 hidden features [S3].
*   **Distinction:** The two fused MLPs differ in maximum hash grid resolution (512 vs 1024) [S3].

#### MLP Lidar Encoding
Processes LiDAR features using an MLP with three hidden layers [S3].
*   **Steps:** Input LiDAR points, output high-dimensional features [S3].
*   **Parameters:** Hidden layer sizes: 64, 96, 128; Output size: 64-dim feature vector [S3].
*   **Performance:** Underperforms compared to sparse UNet-based methods in street scene reconstruction [S3].

#### CoDeF
Allows direct application of image processing algorithms to a canonical image, propagating results via a temporal deformation field [S4].
*   **Steps:** Apply image processing to canonical image, propagate via deformation field [S4].
*   **Pitfall:** Limited by optical flow accuracy; difficult to model complex motion [S4].

#### Deformation Network (Static)
Queries a grid field for features and computes displacement using a static MLP [S5, unofficial].
*   **Steps:** 1. `grid_feature = self.grid(rays_pts_emb[:,:3])`; 2. `dx = self.static_mlp(grid_feature)`; 3. `return rays_pts_emb[:, :3] + dx` [S5, unofficial].

#### Multi-Head MLP Decoder
Attaches multiple lightweight MLP decoders (heads) to a shared feature grid encoder to amortize parameter cost of ensemble diversity [S6, unofficial].
*   **Steps:** 1. Attach multiple heads (e.g., five heads, two layers each); 2. Apply variance regularization to concentrate uncertainty where reconstruction errors are largest [S6, unofficial].
*   **Performance:** On volumes up to $1024^3$ (4 GB), achieved highest reconstruction PSNR among uncertainty-aware methods and produced variance maps without ground truth [S6, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of MLP layers and hidden units. Hash encoding variants add logarithmic complexity with respect to grid resolution [S3].
*   **Memory Complexity:** Proportional to the number of parameters in the MLP ($L \times d^2$) plus any hash grids or latent codes [S1, S3].
*   **Performance:** The specific initialization (small final weights) ensures stable convergence in dynamic scenes [S1]. Multi-head variants incur 2–3× longer training time due to evidential loss computation but maintain inference speeds comparable to deterministic INRs [S6, unofficial].
*   **Strengths:** Flexible conditioning (FiLM), stable optimization via initialization, efficient parallel training (Multi-MLP) [S1][S2, S6, unofficial].
*   **Limitations:** Dependent on the accuracy of underlying motion estimation (optical flow) for video tasks [S4]. LiDAR-specific MLPs may underperform compared to 3D convolutional networks for global context [S3].

## Background
The Deformation MLP Configuration originates from the need to model dynamic scenes in neural radiance fields and 3D Gaussian Splatting. Key developments include the use of positional encoding with MLPs for dynamic fields [S1], the application of Conditional Batch Normalization/FiLM for latent conditioning [S2, unofficial], and the integration of hash encoding for efficiency [S3]. The static deformation network approach is seen in implementations like 4DGS [S5, unofficial], while uncertainty-aware multi-head decoders extend this to scientific volume rendering [S6, unofficial].
