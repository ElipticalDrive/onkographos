# Deformation MLP Configuration

Also called: Conditional Batch Normalization, Deformation MLP Setup, Feature-wise Linear Modulation (FiLM), Feature-wise transformations, MLP setup

## Overview
The Deformation MLP Configuration defines the architecture, initialization, and hyperparameter settings for a Multi-Layer Perceptron (MLP) used to predict spatial or temporal deformations in neural volume representations, such as dynamic 3D Gaussians or radiance fields. It solves the problem of mapping canonical coordinates to deformed coordinates by providing a stable optimization landscape through specific weight initialization and layer sizing. It sets itself apart from sibling methods like [MLP with Input Skips](1643-mlp-with-input-skips.md) by focusing on the configuration of the deformation network itself rather than architectural modifications for frequency learning, and from [Residual Block with Shortcut (ReLU MLP Extension)](10016-residual-block-with-shortcut-relu-mlp-extension.md) by utilizing a standard feedforward structure with specific initialization strategies for stability [S1].

## How it works
### Inputs and Outputs
*   **Inputs:** Time $t$ and 3D position $\mathbf{x}_k$ (or other spatial coordinates).
*   **Outputs:** Delta position $\delta\mathbf{x}_k$, representing the displacement from the canonical coordinate.

### Data Structures and Layout
The MLP consists of 8 fully connected layers, each containing 256 neurons [S1]. The input to the network is the concatenation of positional encodings for spatial coordinates and time.
*   **Positional Encoding Frequencies:** $L_x = 10$ for spatial coordinates, $L_t = 10$ for time [S1].
*   **Layer Dimensions:** All 8 layers map 256 features to 256 features, except the final layer which maps 256 features to the dimension of the output delta (typically 3 for position) [S1].
*   **Bias Initialization:** All biases are initialized to zero [S1].
*   **Weight Initialization:** Weights are initialized using Xavier normal initialization [S1].
*   **Final Layer Exception:** The weights of the final linear layer (mapping 256 features to delta position) are initialized from a normal distribution with a standard deviation of $10^{-5}$ [S1]. This ensures that initial deformations $\delta\mathbf{x}_k$ are small, promoting stable optimization [S1].

### Parameters
*   **Optimizer:** Adam [S1].
*   **Optimizer Hyperparameters:** $\beta = (0.9, 0.999)$, $\epsilon = 10^{-15}$ [S1].
*   **Learning Rate:** The MLP learning rate starts at $\gamma_{MLP} = 0.0008$ and decays exponentially to $1.6 \times 10^{-6}$ over 60,000 iterations [S1].
*   **Loss Coefficients:** In the associated loss function, $\alpha = 5$ (or 1 for synthetic scenes) and $\beta = 0.0008$ [S1].

### Steps
1.  **Input Encoding:** Compute positional encodings for the input time $t$ and position $\mathbf{x}_k$ using frequencies $L_t=10$ and $L_x=10$ [S1].
2.  **Forward Pass:** Pass the concatenated encoded input through the 8-layer MLP.
    *   For layers $i=1$ to $7$: $\mathbf{h}_i = \text{ReLU}(\mathbf{W}_i \mathbf{h}_{i-1} + \mathbf{b}_i)$, where $\mathbf{h}_0$ is the encoded input.
    *   For layer $i=8$: $\delta\mathbf{x}_k = \mathbf{W}_8 \mathbf{h}_7 + \mathbf{b}_8$.
3.  **Deformation Application:** The output $\delta\mathbf{x}_k$ is added to the original coordinate to obtain the deformed position: $\mathbf{x}'_k = \mathbf{x}_k + \delta\mathbf{x}_k$ [S1].

### Edge Cases and Pitfalls
*   **Initialization Stability:** The final layer's small weight standard deviation ($10^{-5}$) is critical. Without it, large initial deformations can destabilize the training of the Gaussian or radiance field parameters [S1].
*   **Background Signal:** In dynamic scenes, if the background signal is insufficient, it may create low-contributing Gaussians. A pitfall is failing to randomize background signals (uniformly between -1 and 1) at each optimization iteration to ensure proper gradient flow for deformation [S1].

## Subtopics

### [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md)
The Multi-MLP Linear Layer is a specialized linear transformation module designed to enable the parallel training of multiple independent Multi-Layer Perceptrons (MLPs) within a single computational graph. It solves the problem of efficiently managing distinct weight and bias parameters for different MLP instances by using 3D tensors indexed by an MLP identifier. Unlike conventional linear layers that use 2D matrices for a single MLP, this method allows batch processing of multiple MLPs simultaneously, leveraging hardware parallelism without complex control flow. It is a core component of the Efficient Compressive Neural Representation (ECNR) framework.

### [Spatial-Ratio Neural Field Configuration](16086-spatial-ratio-neural-field-configuration.md)
The Spatial-Ratio Neural Field is a module that predicts position and shape transformations for selected 3D Gaussians to patch missing areas caused by masking, mapping them from an "all-selected" state to an adapted state under a given elastic ratio $e$. It serves as the core component of the Gaussian Transform Field, enabling flexible 3D Gaussian Splatting where the number of Gaussians can be adjusted dynamically without degrading rendering quality. It is distinguished from sibling methods like [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md) by its use of a multi-plane implicit representation conditioned on a scalar elastic ratio, rather than static latent codes or simple linear projections.

### [Latent Code Conditioning](16345-latent-code-conditioning.md)
Latent Code Conditioning extends a base Neural Field to represent multiple distinct instances (e.g., different objects, shapes, or textures) by conditioning the field's output on an additional latent variable $z$. It solves the problem of overfitting a single instance by allowing a single model architecture to encode a distribution of data. It sets itself apart from sibling methods by defining the family of techniques used to inject this latent information into the decoder, ranging from simple concatenation to dynamic weight generation.

### Fused Hash Encoding MLP Architecture
This variant composes the sampler from two consecutive neural density fields. Each density field is represented by 'fused' MLPs that employ hash encoding to process 3D positions, followed by density prediction using an MLP [S3].
*   **Parameters:** Minimum hash grid resolution: 16. Number of hash encoding levels: 5. Hash feature dimension: 2-dim features per level. Both fused MLPs share common parameters including two MLP layers and 16 hidden features in the MLP layers. The primary distinction between the two fused MLPs lies in their maximum hash grid resolution, set at 512 for the first and 1024 for the second [S3].

### MLP Lidar Encoding
This variant processes LiDAR features using an MLP with three hidden layers.
*   **Parameters:** Hidden layer feature sizes: 64, 96, 128. Output layer feature size: 64-dim feature vector [S3].

### CoDeF
CoDeF allows the direct application of image processing algorithms to the canonical image, with results propagated across time via the temporal deformation field, enabling efficient video processing [S4].
*   **Pitfall:** It is limited by optical flow accuracy and has difficulty in modeling complex motion [S4].

### Deformation Network (Static)
This variant queries a grid field for features at 3D point coordinates and computes displacement using a static MLP.
*   **Steps:**
    1.  Query the grid field for features: `grid_feature = self.grid(rays_pts_emb[:,:3])`.
    2.  Compute displacement: `dx = self.static_mlp(grid_feature)`.
    3.  Return deformed points: `return rays_pts_emb[:, :3] + dx` [S5, unofficial].

### Multi-Head MLP Decoder
An orthogonal approach to uncertainty that attaches multiple lightweight MLP decoders (heads) to a shared feature grid encoder to amortize parameter cost of ensemble diversity [S6, unofficial].
*   **Steps:**
    1.  Attach multiple lightweight MLP decoders (five heads, two layers each) to a shared feature grid encoder.
    2.  Apply variance regularization to encourage the model’s uncertainty to concentrate where reconstruction errors are largest [S6, unofficial].
*   **Performance:** On volumes up to $1024^3$ (4 GB), it achieved the highest reconstruction PSNR among all uncertainty-aware methods and produced variance maps identifying high-error regions without ground truth [S6, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** The specific configuration (8 layers, 256 neurons) is used in the context of optimizing depth indirectly in dynamic radiance fields [S1].
*   **Scaling:** The exponential decay of the learning rate over 60,000 iterations suggests the method is designed for long-duration optimization runs [S1].
*   **Strengths:** The specific initialization of the final layer weights ($10^{-5}$ std dev) ensures stable optimization by starting deformations from small values [S1].
*   **Limitations:** The method relies on positional encoding frequencies ($L_x=10, L_t=10$) which may limit high-frequency detail capture compared to methods using SIREN or input skips [S1].
*   **When to use:** Use when training dynamic neural fields where stable deformation learning is critical and the scene dynamics are not excessively high-frequency [S1].
*   **When not:** Use when high-frequency spatial details are required without the overhead of hash encoding or when uncertainty quantification is the primary goal (use Multi-Head MLP Decoder instead) [S6, unofficial].

## Background
The Deformation MLP Configuration originates from the work on "Time of the Flight of the Gaussians," which optimizes depth indirectly in dynamic radiance fields [S1]. It builds on the general concept of using MLPs for neural fields [S2, unofficial] and specifically adapts them for deformation tasks in 3D Gaussian Splatting contexts. The initialization strategy (Xavier for hidden layers, small normal for output) is a common practice in neural network training to prevent vanishing or exploding gradients, adapted here for the specific sensitivity of deformation fields [S1].
