# Deformation MLP Configuration

Also called: Conditional Batch Normalization, Deformation MLP Setup, Feature-wise Linear Modulation (FiLM), Feature-wise transformations, MLP setup

## Overview
Deformation MLP Configuration refers to the architectural setup and initialization strategies used in Multi-Layer Perceptrons (MLPs) that map spatial or spatio-temporal coordinates to deformation fields (e.g., delta positions or feature transformations) within neural volume representations. It solves the problem of stably training implicit deformation networks by ensuring that initial deformations are small and controlled, preventing gradient explosion or collapse during early optimization stages [S1]. It is distinct from standard MLPs by its specific focus on outputting displacement vectors or conditional modulation parameters rather than direct density or color values, and it differs from sibling methods like Input Skips or Residual Blocks by focusing on the initialization and conditioning mechanics (such as FiLM) rather than connectivity patterns [S2, unofficial].

## How it works
The method configures an MLP to predict a deformation field $\delta\mathbf{x}$ or a set of transformation parameters based on input coordinates. The configuration involves specific architectural choices, initialization protocols, and conditioning mechanisms.

### Inputs and Outputs
*   **Inputs:** Spatial coordinates $\mathbf{x} \in \mathbb{R}^3$, and optionally time $t \in \mathbb{R}$ or a latent code $\mathbf{z}$ for conditional deformation [S1][S2, unofficial].
*   **Outputs:** A delta position $\delta\mathbf{x} \in \mathbb{R}^3$ representing the displacement from the canonical position, or a set of scale and bias vectors for feature modulation [S1][S2, unofficial].

### Data Structures and Layout
The core structure is a feedforward MLP. A common baseline configuration consists of:
*   **Layers:** 8 fully connected linear layers [S1].
*   **Neurons:** 256 neurons per hidden layer [S1].
*   **Input Encoding:** Positional encoding is applied to spatial coordinates $\mathbf{x}$ with frequency $L_x = 10$ and to time $t$ with frequency $L_t = 10$ [S1]. The input vector is thus $2 \cdot 3 \cdot L_x + 2 \cdot 1 \cdot L_t + 3 + 1$ dimensions (assuming standard sin/cos encoding) or similar, depending on the specific encoding scheme [S1].
*   **Conditioning (FiLM):** In conditional setups, small networks $\boldsymbol{\beta_i}(\mathbf{z})$ and $\boldsymbol{\gamma_i}(\mathbf{z})$ predict scale and bias vectors of size equal to the layer's output dimension [S2, unofficial].

### Initialization
Proper initialization is critical for deformation fields to ensure stable optimization [S1].
1.  **Hidden Layers:** Weights are initialized using Xavier normal initialization. Biases are initialized to zero [S1].
2.  **Final Layer:** The final linear layer, which maps the last 256 features to the output dimension (e.g., 3 for delta position), uses weights initialized from a normal distribution with a standard deviation of $\sigma = 10^{-5}$ [S1]. This ensures that the initial predicted deformation $\delta\mathbf{x}$ is close to zero, starting the optimization from the canonical space [S1].

### Conditioning Mechanism (FiLM)
When the deformation is conditional on a latent code $\mathbf{z}$ (Global Conditioning), Feature-wise Linear Modulation (FiLM) is applied [S2, unofficial]. For each layer $i$:
$$ \hat{\mathbf{x}}_i = L_i(\mathbf{x}) \odot \boldsymbol{\gamma_i}(\mathbf{z}) + \boldsymbol{\beta_i}(\mathbf{z}) $$
where $L_i(\mathbf{x})$ is the output of the $i$-th linear layer, $\odot$ is element-wise multiplication, and $\boldsymbol{\gamma_i}, \boldsymbol{\beta_i}$ are the scale and bias vectors predicted by small networks conditioned on $\mathbf{z}$ [S2, unofficial].

### Pseudocode
The following Python-like pseudocode implements the standard Deformation MLP with FiLM conditioning and specific initialization.

```python
import torch
import torch.nn as nn
import math

class DeformationMLP(nn.Module):
    def __init__(self, in_dim=66, hidden_dim=256, num_layers=8, out_dim=3, 
                 cond_dim=0, use_film=False):
        """
        in_dim: Input dimension (e.g., encoded position + time)
        hidden_dim: Number of neurons per hidden layer
        num_layers: Number of hidden layers
        out_dim: Output dimension (e.g., 3 for delta position)
        cond_dim: Dimension of the conditioning latent vector z. 
                  If 0, no FiLM conditioning is used.
        use_film: Boolean flag to enable Feature-wise Linear Modulation.
        """
        super().__init__()
        self.use_film = use_film
        self.cond_dim = cond_dim
        
        # Define hidden layers
        self.layers = nn.ModuleList()
        for i in range(num_layers):
            input_size = in_dim if i == 0 else hidden_dim
            output_size = hidden_dim
            linear = nn.Linear(input_size, output_size)
            
            # Initialize weights with Xavier normal
            nn.init.xavier_normal_(linear.weight)
            # Initialize biases to zero
            nn.init.zeros_(linear.bias)
            
            self.layers.append(linear)
            
            # If FiLM is enabled, add conditioning networks for this layer
            if use_film:
                # Small networks to predict scale and bias
                self.scale_net = nn.Linear(cond_dim, hidden_dim)
                self.bias_net = nn.Linear(cond_dim, hidden_dim)
                # Initialize conditioning networks
                nn.init.xavier_normal_(self.scale_net.weight)
                nn.init.zeros_(self.scale_net.bias)
                nn.init.xavier_normal_(self.bias_net.weight)
                nn.init.zeros_(self.bias_net.bias)

        # Define final output layer
        self.final_layer = nn.Linear(hidden_dim, out_dim)
        
        # Special initialization for the final layer: 
        # Weights from normal distribution with std 1e-5
        nn.init.normal_(self.final_layer.weight, mean=0, std=1e-5)
        nn.init.zeros_(self.final_layer.bias)

    def forward(self, x, z=None):
        """
        x: Input tensor of shape (..., in_dim)
        z: Conditioning latent vector of shape (..., cond_dim). 
           Required if use_film is True.
        """
        if self.use_film and z is None:
            raise ValueError("z must be provided when use_film is True")

        h = x
        for i, layer in enumerate(self.layers):
            h = layer(h)
            
            if self.use_film:
                # Predict scale and bias from latent code z
                # Note: In practice, z might need broadcasting to match batch dims
                gamma = self.scale_net(z)
                beta = self.bias_net(z)
                
                # FiLM modulation
                h = h * gamma + beta
                
            # Activation function (e.g., ReLU or SIREN) is typically applied here.
            # The source [S1] does not specify the activation, but standard MLPs use ReLU.
            # SIREN uses Sin. We assume a generic activation for the hidden layers.
            # [G] Assuming ReLU as a common default for non-SIREN MLPs unless specified.
            h = torch.relu(h)

        # Final layer produces the deformation delta
        delta_x = self.final_layer(h)
        return delta_x
```

### Edge Cases and Pitfalls
*   **Initialization Magnitude:** Failing to use the small standard deviation ($10^{-5}$) for the final layer can lead to large initial deformations, causing instability or divergence in the optimization [S1].
*   **Conditioning Mismatch:** If FiLM is used, the latent code $\mathbf{z}$ must be provided for every forward pass. Mismatched dimensions between $\mathbf{z}$ and the predicted scale/bias vectors will cause runtime errors [S2, unofficial].
*   **Precision:** Using standard float32 is generally sufficient, but the small initialization values ($10^{-5}$) may be sensitive to underflow in lower precision formats like float16 without mixed precision training techniques [G].

## Subtopics

### [Multi-MLP Linear Layer](15116-multi-mlp-linear-layer.md)
The Multi-MLP Linear Layer is a specialized linear transformation module designed to enable the parallel training of multiple independent Multi-Layer Perceptrons (MLPs) within a single computational graph. It solves the problem of efficiently managing distinct weight and bias parameters for different MLP instances by using 3D tensors indexed by an MLP identifier. Unlike conventional linear layers that use 2D matrices for a single MLP, this method allows batch processing of multiple MLPs simultaneously, leveraging hardware parallelism without complex control flow. It is a core component of the Efficient Compressive Neural Representation (ECNR) framework.

### [Latent Code Conditioning](16345-latent-code-conditioning.md)
Latent Code Conditioning involves using a latent vector $\mathbf{z}$ to modulate the MLP's behavior, allowing a single network to represent a family of deformations or scenes. This can be global (one $\mathbf{z}$ per sample) or local (multiple $\mathbf{z}$s assigned to spatial regions).

### Fused Hash Encoding MLP Architecture
This variant composes the sampler from two consecutive neural density fields. Each density field is represented by 'fused' MLPs that employ hash encoding to process 3D positions, followed by density prediction using an MLP. Both fused MLPs share common parameters: a minimum hash grid resolution of 16, five levels of hash encoding, 2-dim features for each hash encoding level, two MLP layers, and 16 hidden features in the MLP layers. The primary distinction between these two fused MLPs lies in their maximum hash grid resolution, with the first set at 512 and the second at 1024 [S3].

### MLP Lidar Encoding
This variant processes LiDAR features using an MLP with three hidden layers. The hidden layer feature sizes are 64, 96, and 128. The output layer produces a 64-dim feature vector. This method is used for encoding LiDAR points into high-dimensional features for neural radiance fields on street scenes [S3].

### CoDeF
CoDeF (Canonical Deformation Field) allows the direct application of image processing algorithms to the canonical image, with results propagated across time via the temporal deformation field, enabling efficient video processing. It uses a content field and a 3D temporal deformation field, both using multiresolution hash tables. It is limited by optical flow accuracy and has difficulty in modeling complex motion [S4].

### Spatial-Ratio Neural Field Configuration
This is a multi-plane implicit representation modeling a 4D voxel space (x, y, z, e) using six 2D planes to predict Gaussian transformations conditioned on an elastic ratio e. The planes are {(x, y), (x, z), (y, z), (x, e), (y, e), (z, e)} with resolutions {64, 64, 64, 100} for dimensions {x, y, z, e} respectively. The hidden feature dimension D for GsNet and Multi-Head Predictor is set to 64 [S5].

### Deformation Network (Static)
This variant queries a grid field for features at 3D point coordinates (`grid_feature = self.grid(rays_pts_emb[:,:3])`) and computes displacement using a static MLP (`dx = self.static_mlp(grid_feature)`). The deformed points are returned by adding the displacement to the original coordinates (`return rays_pts_emb[:, :3] + dx`) [S6, unofficial].

### Multi-Head MLP Decoder
This is an orthogonal approach to uncertainty that attaches multiple lightweight MLP decoders (heads) to a shared feature grid encoder to amortize parameter cost of ensemble diversity. It typically uses five heads, each with two layers. Variance regularization is applied to encourage the model’s uncertainty to concentrate where reconstruction errors are largest. On volumes up to $1024^3$ (4 GB), this method achieved the highest reconstruction PSNR among all uncertainty-aware methods and produced variance maps identifying high-error regions without ground truth [S7, unofficial].

## Operating characteristics
*   **Time Complexity:** The forward pass is $O(L \cdot D^2)$ where $L$ is the number of layers and $D$ is the hidden dimension. With FiLM, an additional $O(C \cdot D)$ cost is incurred for the conditioning networks, where $C$ is the latent dimension [S1][S2, unofficial].
*   **Memory Complexity:** $O(L \cdot D^2)$ for weights. With FiLM, additional memory for the conditioning networks is required. The Multi-MLP Linear Layer variant increases memory usage by a factor of $N$ (number of MLPs) but allows parallel processing [S1].
*   **Performance:** The specific initialization ($10^{-5}$ std for final layer) leads to stable convergence in dynamic radiance fields [S1]. The Multi-Head MLP Decoder achieves high PSNR on large volumes (up to 4 GB) but requires 2-3x longer training time due to evidential loss computation [S7, unofficial].
*   **Strengths:** Stable optimization due to careful initialization; flexible conditioning via FiLM; efficient parallel training with Multi-MLP layers.
*   **Limitations:** Standard MLPs may struggle with high-frequency details compared to SIRENs or hash-based methods without sufficient depth or encoding [S1, S3]. CoDeF is limited by optical flow accuracy [S4].

## Background
The Deformation MLP Configuration originated in the context of dynamic neural radiance fields and 3D Gaussian Splatting, where modeling temporal deformation is crucial. The specific initialization strategy (Xavier for hidden layers, small normal for final layer) was introduced in "Time of the Flight of the Gaussians: Optimizing Depth Indirectly in Dynamic Radiance Fields" [S1]. The use of FiLM for conditional deformation is based on the general Neural Fields framework described by inovex GmbH [S2, unofficial]. Variants like Fused Hash Encoding and Lidar Encoding were developed for specific applications like street scene reconstruction [S3]. The Multi-Head MLP Decoder approach for uncertainty was proposed in the context of scientific volume rendering [S7, unofficial].
