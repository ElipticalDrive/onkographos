# MLP Neural Field
Also called: Baseline MLP, Coordinate MLP, Plain MLP, Plain MLP Neural Field, ReLU-MLP

## Overview
A plain MLP neural field maps continuous coordinates to signal values using a standard multi-layer perceptron with configurable activations, typically ReLU [S1, unofficial]. It serves as the primary baseline for comparing neural implicit representations, particularly against SIREN, to demonstrate the impact of activation functions on spectral bias and high-frequency reconstruction [S1, unofficial]. Unlike [SIREN Neural Field](1250-siren-neural-field.md), which uses sine activations to capture fine details, the plain MLP struggles with high-frequency signals due to its smooth activation properties [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A tensor of continuous coordinates $z \in \mathbb{R}^{in\_features}$ [S1, unofficial].
*   **Output:** A tensor of signal values $y \in \mathbb{R}^{out\_features}$ [S1, unofficial].

**Data Structures:**
The network is a sequential stack of linear layers and activations [S1, unofficial].
*   **Layer 0:** `Linear(in_features, hidden_features)` with bias [S1, unofficial].
*   **Layers 1 to $H-1$:** `Linear(hidden_features, hidden_features)` with bias, followed by an activation function [S1, unofficial].
*   **Layer $H$:** `Linear(hidden_features, out_features)` with bias [S1, unofficial].
*   **Activation:** Default is ReLU. Other options include Tanh or GELU [S1, unofficial].

**Parameters:**
*   `in_features`: int; dimensionality of input coordinates [S1, unofficial].
*   `out_features`: int; dimensionality of output values [S1, unofficial].
*   `hidden_features`: int; width of hidden layers [S1, unofficial].
*   `hidden_layers`: int; number of hidden layers [S1, unofficial].
*   `bias`: bool = True; whether linear layers carry a bias [S1, unofficial].
*   `activation`: str = "ReLU"; name of the activation function (e.g. ReLU/Tanh/GELU) [S1, unofficial].
*   `steps`: int = 2000; number of training steps for fitting an image with ReLU-MLP [S1, unofficial].

**Algorithm:**
1.  **Input Preparation:** Clone the input coordinate tensor $z$ and enable gradient tracking on the copy to allow differentiation with respect to coordinates [S1, unofficial].
2.  **Forward Pass:** Pass the gradient-enabled coordinates through the sequential MLP layers defined above [S1, unofficial].
3.  **Output:** Return the computed signal values and the gradient-enabled coordinates [S1, unofficial].

**Pseudocode:**
```python
import torch

class MLPNeuralField:
    def __init__(self, in_features, out_features, hidden_features, hidden_layers, bias=True, activation="ReLU"):
        self.in_features = in_features
        self.out_features = out_features
        self.hidden_features = hidden_features
        self.hidden_layers = hidden_layers
        self.bias = bias
        self.activation = activation
        # Initialize weights and biases [G]
        self.W0 = torch.randn(in_features, hidden_features)
        self.b0 = torch.zeros(hidden_features) if bias else None
        self.Wh = torch.randn(hidden_features, hidden_features)
        self.bh = torch.zeros(hidden_features) if bias else None
        self.Wout = torch.randn(hidden_features, out_features)
        self.bout = torch.zeros(out_features) if bias else None

    def _activate(self, x):
        if self.activation == "ReLU":
            return torch.relu(x)
        elif self.activation == "Tanh":
            return torch.tanh(x)
        elif self.activation == "GELU":
            return torch.nn.functional.gelu(x)
        raise ValueError(f"Unsupported activation: {self.activation}")

    def forward(self, z):
        # 1. Clone input and enable gradients [S1, unofficial]
        z_grad = z.clone().detach().requires_grad_(True)
        x = z_grad

        # 2. Layer 0: Linear + Activation [S1, unofficial]
        x = torch.matmul(x, self.W0) + (self.b0 if self.bias else 0)
        x = self._activate(x)

        # 3. Hidden layers: Linear + Activation [S1, unofficial]
        for _ in range(self.hidden_layers - 1):
            x = torch.matmul(x, self.Wh) + (self.bh if self.bias else 0)
            x = self._activate(x)

        # 4. Output layer: Linear [S1, unofficial]
        out = torch.matmul(x, self.Wout) + (self.bout if self.bias else 0)

        return out, z_grad
```

**Edge Cases and Pitfalls:**
*   **Coordinate Convention:** Inputs typically follow the $[-1, 1]$ convention [S1, unofficial].
*   **Spectral Bias:** The network exhibits spectral bias, meaning it learns low-frequency functions faster than high-frequency ones, leading to blurry reconstructions compared to SIREN [S1, unofficial].
*   **Gradient Computation:** Gradients must be explicitly enabled on the input copy to compute derivatives like the Laplacian for visualization or regularization [S1, unofficial].

## Subtopics

### [MLP with Input Skips](1643-mlp-with-input-skips.md)
An MLP architecture that concatenates the original input $z$ to intermediate layers specified in `input_skips`, allowing the network to access low-level features at deeper layers. It differs from the parent [MLP Neural Field](1256-mlp-neural-field.md) by explicitly preserving high-frequency input information in hidden representations.

## Operating characteristics
*   **Training Performance:** Fitting a simple image requires 2000 steps for ReLU-MLP, whereas SIREN reaches a sharp reconstruction in ~100 steps and the ReLU-MLP never reaches it in 2000 steps due to spectral bias [S1, unofficial].
*   **Limitations:** Poor at representing high-frequency details due to spectral bias; requires significantly more training steps to converge on complex scenes compared to sine-based activations [S1, unofficial].

## Background
The plain MLP neural field was introduced as a baseline method in the context of differentiable rendering and neural implicit representations [S1, unofficial]. It is commonly used to contrast with SIREN (Sinusoidal Representation Networks) to highlight the importance of activation functions in capturing high-frequency signals [S1, unofficial]. The method is implemented in various open-source differentiable rendering frameworks, such as the one by Yonghao Lee [S1, unofficial].
