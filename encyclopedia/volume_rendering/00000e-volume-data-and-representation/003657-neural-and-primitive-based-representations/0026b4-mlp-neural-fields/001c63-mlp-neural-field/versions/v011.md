# MLP Neural Field

Also called: Baseline MLP, Coordinate MLP, Plain MLP, Plain MLP Neural Field, ReLU-MLP

## Overview
A plain MLP neural field maps continuous spatial coordinates to signal values (such as density and color) using a standard Multi-Layer Perceptron with ReLU activations [S1, unofficial]. It serves as the fundamental baseline for coordinate-based neural representations, contrasting with specialized architectures like SIREN that use sinusoidal activations to overcome spectral bias [S1, unofficial]. Unlike voxel-based methods, it offers constant memory usage relative to spatial resolution, enabling infinite-resolution reconstruction [S1, unofficial].

## How it works
The method defines a scene function $F_\Theta: \mathbb{R}^d \rightarrow \mathbb{R}^k$ where the input is a continuous coordinate vector $\mathbf{x}$ (typically 3D position) and the output is a signal vector (e.g., density $\sigma$ and color $\mathbf{c}$) [G]. The network is trained by minimizing a loss between rendered observations and ground truth images [G].

**Inputs and Outputs:**
*   **Input:** A tensor of coordinates $\mathbf{X} \in \mathbb{R}^{N \times d}$, where $N$ is the number of sample points and $d$ is the input dimensionality (typically 3). Coordinates follow the $[-1, 1]$ convention [S1, unofficial].
*   **Output:** A tensor of signal values $\mathbf{Y} \in \mathbb{R}^{N \times k}$, where $k$ is the output dimensionality (e.g., 4 for RGB + density) [S1, unofficial].

**Data Structures:**
The network is implemented as a sequential stack of linear layers and activation functions [S1, unofficial].
*   **Layer 0:** Linear layer mapping $d$ inputs to `hidden_features` outputs.
*   **Layers 1 to `hidden_layers`-1:** Linear layers mapping `hidden_features` to `hidden_features`, followed by an activation function.
*   **Final Layer:** Linear layer mapping `hidden_features` to `out_features` outputs.
*   **Bias:** Each linear layer includes a bias term if `bias=True` [S1, unofficial].

**Parameters:**
*   `in_features`: Dimensionality of input coordinates [S1, unofficial].
*   `out_features`: Dimensionality of output values [S1, unofficial].
*   `hidden_features`: Width of hidden layers [S1, unofficial].
*   `hidden_layers`: Number of hidden layers [S1, unofficial].
*   `bias`: Boolean, default `True` [S1, unofficial].
*   `activation`: String, default `"ReLU"` (e.g., "ReLU", "Tanh", "GELU") [S1, unofficial].
*   `steps`: Number of training steps, typically 2000 for fitting an image with ReLU-MLP [S1, unofficial].

**Algorithm:**
1.  Clone the input coordinate tensor $\mathbf{X}$ to create $\mathbf{X}_{grad}$ and enable gradient tracking on $\mathbf{X}_{grad}$ [S1, unofficial].
2.  Pass $\mathbf{X}_{grad}$ through the sequential network layers:
    *   Apply Linear transformation: $\mathbf{h}_0 = \mathbf{W}_0 \mathbf{X}_{grad} + \mathbf{b}_0$.
    *   Apply Activation: $\mathbf{a}_0 = \text{Activation}(\mathbf{h}_0)$.
    *   For $i$ from 1 to `hidden_layers` - 2:
        *   $\mathbf{h}_i = \mathbf{W}_i \mathbf{a}_{i-1} + \mathbf{b}_i$.
        *   $\mathbf{a}_i = \text{Activation}(\mathbf{h}_i)$.
    *   Final output: $\mathbf{Y} = \mathbf{W}_{last} \mathbf{a}_{last} + \mathbf{b}_{last}$.
3.  Return $\mathbf{Y}$ and $\mathbf{X}_{grad}$ to allow differentiation with respect to coordinates [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class MLPNeuralField(nn.Module):
    def __init__(self, in_features, out_features, hidden_features, hidden_layers, bias=True, activation="ReLU"):
        super().__init__()
        layers = []
        # First layer: in_features -> hidden_features
        layers.append(nn.Linear(in_features, hidden_features, bias=bias))
        layers.append(get_activation(activation))
        
        # Hidden layers: hidden_features -> hidden_features
        for _ in range(hidden_layers - 1):
            layers.append(nn.Linear(hidden_features, hidden_features, bias=bias))
            layers.append(get_activation(activation))
            
        # Final layer: hidden_features -> out_features
        layers.append(nn.Linear(hidden_features, out_features, bias=bias))
        
        self.network = nn.Sequential(*layers)

    def forward(self, points):
        # Clone input and enable gradients for backpropagation to coordinates
        points_grad = points.clone().detach().requires_grad_(True)
        output = self.network(points_grad)
        return output, points_grad

def get_activation(name):
    if name == "ReLU":
        return nn.ReLU()
    elif name == "Tanh":
        return nn.Tanh()
    elif name == "GELU":
        return nn.GELU()
    else:
        raise ValueError(f"Unsupported activation: {name}")
```

**Edge Cases and Pitfalls:**
*   **Spectral Bias:** The ReLU-MLP suffers from spectral bias, meaning it struggles to represent high-frequency details compared to sinusoidal networks like SIREN [S1, unofficial]. It may fail to reach sharp reconstructions within standard training steps (e.g., 2000 steps) [S1, unofficial].
*   **Coordinate Convention:** Inputs must follow the $[-1, 1]$ convention to ensure proper normalization and gradient behavior [S1, unofficial].
*   **Gradient Tracking:** The input coordinates must be cloned with gradients enabled; otherwise, the network cannot compute derivatives with respect to spatial position, which is required for rendering and optimization [S1, unofficial].

## Subtopics

### [MLP with Input Skips](1643-mlp-with-input-skips.md)
An MLP architecture that concatenates the original input vector to intermediate layers, allowing the network to access low-level features at deeper layers. It serves as the baseline for standard NeRF-style neural fields, contrasting with SIREN by using ReLU activations and explicit skip connections rather than sinusoidal embeddings.

### [Deformation MLP Configuration](9661-deformation-mlp-configuration.md)
Defines the architecture, initialization, and conditioning mechanisms for an MLP used to predict spatial or temporal deformations in neural volume representations. It solves the problem of mapping canonical coordinates to deformed coordinates by applying feature-wise linear modulations or direct displacement predictions. It is distinguished from sibling methods like [MLP with Input Skips](1643-mlp-with-input-skips.md) by its specific focus on deformation dynamics and [Residual Block with Shortcut (ReLU MLP Extension)](10016-residual-block-with-shortcut-relu-mlp-extension.md) by its use of conditional scaling/biasing or specific initialization strategies for delta predictions rather than standard residual learning.

### [Residual Block with Shortcut (ReLU MLP Extension)](10016-residual-block-with-shortcut-relu-mlp-extension.md)
Extends the analytic marching algorithm for implicit surface reconstruction to MLPs constructed with residual blocks containing shortcut connections. It enables the theoretical analysis and exact linear region partitioning of such architectures, allowing for efficient meshing via analytic marching.

### MLP Decomposition Baseline
An alternative decomposition method where a neural network (MLP) with a softmax activation outputs the weights $w_{\phi n}(\mathbf{x})$. It is used as a baseline to demonstrate the efficiency of Voronoi decomposition [S2]. While it has similar theoretical operation counts to Voronoi decomposition, it suffers from random memory access during integration, leading to much faster runtime growth as the number of heads increases [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of hidden layers and the width of the network. Rendering time scales with the number of samples per ray and the number of rays [S1, unofficial].
*   **Memory Complexity:** Constant with respect to spatial resolution, depending only on the number of network parameters [S1, unofficial].
*   **Performance:** The ReLU-MLP is slower to converge than SIREN for high-frequency details, often failing to reach sharp reconstructions in standard training steps (e.g., 2000 steps) due to spectral bias [S1, unofficial].
*   **Strengths:** Simple architecture, easy to implement, constant memory usage regardless of scene complexity or resolution.
*   **Limitations:** Spectral bias limits high-frequency detail reconstruction; requires careful initialization and potentially more training steps compared to sinusoidal networks.
*   **When to Use:** As a baseline for comparison, or for scenes with low-frequency content where high-frequency detail is not critical.
*   **When Not to Use:** For scenes requiring high-frequency details or sharp edges, where SIREN or other specialized architectures are preferred [S1, unofficial].

## Background
The MLP neural field, specifically using ReLU activations, serves as a baseline for coordinate-based neural representations [S1, unofficial]. It was introduced in the context of differentiable rendering to map continuous coordinates to signal values, contrasting with the SIREN architecture which uses sine activations to handle high-frequency details [S1, unofficial]. The method is part of the broader family of neural and primitive-based representations for volume data [G].
