# DiF-Hash-B


## Overview
DiF-Hash-B is a two-factor neural field model within the Factor Fields framework that extends the single-factor Instant-NGP (iNGP) architecture [S1, unofficial]. It alleviates feature collision by introducing a localized coefficient field and a global basis field, utilizing periodic hashing transformations to enable spatially coherent information sharing [S1, unofficial]. It achieves higher reconstruction quality than iNGP and other single-factor models, at the cost of increased model size and training time [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: 3D coordinates $\mathbf{x}$ [S1, unofficial].
- Output: Radiance field values (color/density) [S1, unofficial].

**Data Structures:**
The model uses two factors, $N_{fi}=2$ [S1, unofficial]:
1. **Coefficient Field:** Localized, implemented as 3D grids [S1, unofficial].
2. **Basis Field:** Global, implemented as 3D grids [S1, unofficial].
Both fields use the **Hashing** coordinate transformation $\gamma_i(\mathbf{x})$ [S1, unofficial].

**Numbered Steps:**
1. Transform input coordinate $\mathbf{x}$ using the hashing function $\gamma(\mathbf{x})$ to determine indices in the coefficient and basis grids [S1, unofficial].
2. Lookup values from the coefficient grid and basis grid at the transformed indices [S1, unofficial].
3. Combine the coefficient and basis factors to produce the output [S1, unofficial].

**Formulas:**
- Coordinate transformation: $\gamma_i(\mathbf{x})$ maps continuous input coordinates $\mathbf{x}$ to discrete grid indices via a hashing function [S1, unofficial].

**Parameters:**
- Number of factors: 2 [S1, unofficial].
- Transformation: Hashing [S1, unofficial].
- Grid dimensionality: 3D for both factors [S1, unofficial].

**Edge Cases and Pitfalls:**
- Hashing collisions may occur if the hash table size is insufficient, though the two-factor structure mitigates this compared to single-factor models [S1, unofficial].
- Precision issues are not explicitly detailed, but hashing relies on integer index mapping [G].

**Pseudocode:**
```python
def dif_hash_b_forward(x, coeff_grid, basis_grid, hash_table_size):
    """
    x: (N, 3) input coordinates
    coeff_grid: 3D tensor of coefficients
    basis_grid: 3D tensor of basis vectors
    hash_table_size: size of the hash table for coordinate mapping
    """
    # 1. Hash the coordinates to get grid indices
    # Note: The exact hash function and table size are not provided in the sources [G].
    # A standard deterministic modular hash is used here.
    indices = []
    for coord in x:
        h = int(sum(c * 31**i for i, c in enumerate(coord))) % hash_table_size
        indices.append(h)
    
    # 2. Lookup values from the grids
    # Assuming indices are valid and within bounds
    coeff_values = coeff_grid[indices]
    basis_values = basis_grid[indices]
    
    # 3. Combine factors
    output = coeff_values * basis_values
    
    return output
```

## Subtopics

### DiF-Hash-B-SL
A single-level version of DiF-Hash-B, using only a single transformation level [S1, unofficial]. Single-level DiF models are consistently worse than multi-level models in speed and reconstruction quality, though the drop is not as severe as in purely MLP-based representations [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- Training Time: 00:55 / 13:10 / 04:45 (for 2D Images / Radiance Field / Few-shot RF) [S1, unofficial].
- Model Size: 1.09 / 4.37 / 3.28 (units not specified) [S1, unofficial].
- Compared to iNGP (single factor), DiF-Hash-B has longer training time and larger model size [S1, unofficial].

**Measured Performance:**
- 2D Images: 37.53 PSNR / 0.949 SSIM [S1, unofficial].
- Radiance Field: 32.80 PSNR / 0.960 SSIM [S1, unofficial].
- Few-shot RF: 26.62 PSNR / 0.919 SSIM [S1, unofficial].

**Strengths and Limitations:**
- Strengths: Superior reconstruction quality compared to single-factor models (iNGP, EG3D, DiF-no-C) and other two-factor models like TensoRF-VM [S1, unofficial]. Effective utilization of learned data priors when combined with pre-trained basis factors [S1, unofficial].
- Limitations: Higher computational cost (time and memory) than single-factor models [S1, unofficial].

**When to Use:**
- When high reconstruction quality is prioritized over training speed and memory footprint [S1, unofficial].
- When compared to iNGP, DiF-Hash-B is chosen for its ability to alleviate feature collision and improve PSNR/SSIM scores [S1, unofficial].

## Background
DiF-Hash-B was introduced in the paper "Factor Fields: A Unified Framework for Neural Fields and Beyond" [S1, unofficial]. It is part of the Factor Fields framework, which generalizes NeRF, Instant-NGP, DVGO, and TensoRF [S1, unofficial]. The model extends the single-factor Instant-NGP by adding a second factor (basis field) to improve representation capacity [S1, unofficial].
