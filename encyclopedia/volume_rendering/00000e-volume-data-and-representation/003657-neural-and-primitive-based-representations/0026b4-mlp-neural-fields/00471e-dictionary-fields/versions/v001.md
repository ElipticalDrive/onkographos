# Dictionary Fields

Also called: DiF (Dictionary Factorization), Dictionary Factorization, Factor Fields

## Overview
Dictionary Fields (DiF) is a neural field representation that factorizes a continuous signal into the element-wise product of a spatially varying coefficient field and a shared global basis field, using periodic coordinate warping [S2, unofficial]. It solves the problem of balancing reconstruction quality with memory and training efficiency by separating reusable global structures (basis) from scene-specific local details (coefficients) [S1][S2, unofficial]. Unlike its siblings such as [Instant-NGP](910-nerf-mlp-architecture.md) which uses a single hash-based factor, or [DVGO](1150-scene-representation-networks-srn.md) which uses only coefficients, DiF jointly optimizes both factors, halving the parameter count of Instant-NGP while achieving superior reconstruction quality [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A query coordinate $\mathbf{x} \in \mathbb{R}^D$ (e.g., 2D image pixel or 3D spatial point).
*   **Output:** An approximated signal value $\hat{\mathbf{s}}(\mathbf{x}) \in \mathbb{R}^Q$ (e.g., RGB color, SDF value, or radiance).

**Data Structures:**
The method relies on two primary learnable fields and a projection function:
1.  **Coefficient Field $\mathbf{c}(\mathbf{x})$:** A spatially varying field mapping $\mathbb{R}^D \rightarrow \mathbb{R}^K$. In the default "DiF-Grid" implementation, this is stored as a uniform 3D grid (for 3D signals) or 2D map (for 2D signals) with resolution $M^c$. The resolution is constant across all pyramid levels.
2.  **Basis Field $\mathbf{b}(\cdot)$:** A global basis function mapping $\mathbb{R}^B \rightarrow \mathbb{R}^K$. In the default implementation, this is stored as a set of uniform grids with linearly increasing resolutions $M^b_l$ across $L$ levels.
3.  **Projection Function $\mathcal{P}$:** A mapping $\mathbb{R}^K \rightarrow \mathbb{R}^Q$. Typically implemented as a small Multi-Layer Perceptron (MLP) or a linear layer $A \in \mathbb{R}^{Q \times K}$.

**Parameters:**
*   $D$: Input dimension (2 for images, 3 for 3D space).
*   $Q$: Output dimension (1 for scalar, 3 for RGB, 4 for radiance).
*   $K$: Number of feature channels per factor.
*   $L$: Number of pyramid levels for the basis.
*   $\eta$: Scaling factor for feature channels.
*   $\mu$: Dropout probability for regularization.
*   $f_l$: Frequency for level $l$.
*   $M^b_l$: Resolution of basis grid at level $l$.
*   $M^c$: Resolution of coefficient grid.

**Numbered Steps:**
1.  **Coordinate Transformation (Basis):** For each level $l \in \{1, \dots, L\}$, compute the scaled coordinate $\mathbf{x}'_l = f_l \cdot \mathbf{x}$. Apply the periodic coordinate transformation $\gamma$ (default: Sawtooth) to obtain transformed coordinates $\boldsymbol{\gamma}_l(\mathbf{x}) = \mathbf{x}'_l \pmod 1.0$.
2.  **Basis Evaluation:** Sample the basis field $\mathbf{b}$ at the transformed coordinates. For grid-based basis, this involves trilinear/trilinear interpolation from the basis grids at resolutions $M^b_l$. Concatenate the outputs from all $L$ levels to form the basis vector $\mathbf{b}_{total}(\mathbf{x}) \in \mathbb{R}^{K_{total}}$.
3.  **Coefficient Evaluation:** Evaluate the coefficient field $\mathbf{c}$ at the original coordinate $\mathbf{x}$ (identity transformation $\gamma_1(\mathbf{x}) = \mathbf{x}$). Sample from the coefficient grid to obtain $\mathbf{c}(\mathbf{x}) \in \mathbb{R}^{K_{total}}$.
4.  **Hadamard Product:** Compute the element-wise product of the coefficient and basis vectors: $\mathbf{v}(\mathbf{x}) = \mathbf{c}(\mathbf{x}) \circ \mathbf{b}_{total}(\mathbf{x})$.
5.  **Regularization (Optional):** During training, randomly drop features in $\mathbf{v}(\mathbf{x})$ to zero with probability $\mu$ to encourage sparsity and prevent co-adaptation [S2, unofficial].
6.  **Projection:** Pass $\mathbf{v}(\mathbf{x})$ through the projection function $\mathcal{P}$ to obtain the final signal: $\hat{\mathbf{s}}(\mathbf{x}) = \mathcal{P}(\mathbf{v}(\mathbf{x}))$.

**Formulas:**
The general Factor Fields framework with $N$ factors is:
$$ \hat{\mathbf{s}}(\mathbf{x}) = \mathcal{P} \left( \prod_{i=1}^N \mathbf{f}_i \left( \boldsymbol{\gamma}_i(\mathbf{x}) \right) \right) $$
where $\prod$ denotes the Hadamard product [S2, unofficial].

For Dictionary Fields (DiF), $N=2$, with $\mathbf{f}_1 = \mathbf{c}$, $\boldsymbol{\gamma}_1(\mathbf{x}) = \mathbf{x}$, $\mathbf{f}_2 = \mathbf{b}$, and $\boldsymbol{\gamma}_2(\mathbf{x}) = \gamma(\mathbf{x})$:
$$ \hat{\mathbf{s}}(\mathbf{x}) = \mathcal{P}(\mathbf{c}(\mathbf{x}) \circ \mathbf{b}(\gamma(\mathbf{x}))) $$
If $\mathcal{P}$ is linear with $A = (1, \dots, 1)$ and $Q=1$, this reduces to the scalar product:
$$ \hat{s}(\mathbf{x}) = \mathbf{c}(\mathbf{x})^\top \mathbf{b}(\gamma(\mathbf{x})) $$
[S2, unofficial]

**Pseudocode:**
```python
import torch
import torch.nn as nn

class DictionaryField(nn.Module):
    def __init__(self, D=3, Q=3, L=6, eta=0, M_c=64, M_b_range=(32, 128), 
                 freq_range=(2.0, 8.0), mu=0.0, use_linear_proj=False):
        super().__init__()
        self.D = D
        self.Q = Q
        self.L = L
        self.mu = mu
        
        # Frequencies for L levels, linearly increasing
        self.frequencies = torch.linspace(freq_range[0], freq_range[1], L)
        
        # Feature channels per level
        # Base channels from paper: [4, 4, 4, 2, 2, 2] for L=6
        base_channels = [4, 4, 4, 2, 2, 2]
        self.K_levels = [int(k * (2 ** eta)) for k in base_channels[:L]]
        self.K_total = sum(self.K_levels)
        
        # Coefficient Grid: Uniform resolution M_c across all levels
        # Shape: (L, M_c, M_c, M_c, K_total) for 3D
        self.coeff_grid = nn.Parameter(torch.randn(L, M_c, M_c, M_c, self.K_total))
        
        # Basis Grids: Linearly increasing resolutions
        # Assuming bounding box size 1.0 for simplicity, scale factor min(v-u)/1024 is 1/1024
        # Resolutions: 32 to 128 linearly spaced
        self.M_b_levels = torch.linspace(M_b_range[0], M_b_range[1], L).int()
        self.basis_grids = nn.ModuleList([
            nn.Parameter(torch.randn(L, int(m), int(m), int(m), k)) 
            for l, m, k in zip(range(L), self.M_b_levels, self.K_levels)
        ])
        
        # Projection Function
        if use_linear_proj:
            self.proj = nn.Linear(self.K_total, Q)
        else:
            self.proj = nn.Sequential(
                nn.Linear(self.K_total, self.K_total // 2),
                nn.ReLU(),
                nn.Linear(self.K_total // 2, Q)
            )

    def forward(self, x):
        """
        x: Tensor of shape (..., D)
        Returns: Tensor of shape (..., Q)
        """
        # 1. Coordinate Transformation and Basis Evaluation
        basis_outputs = []
        for l in range(self.L):
            # Scale coordinates by frequency
            x_scaled = x * self.frequencies[l]
            
            # Apply Sawtooth transformation: x mod 1.0
            # Ensure x is in [0, 1) for grid indexing if necessary, 
            # but standard mod works for periodicity.
            x_transformed = x_scaled % 1.0
            
            # Sample basis grid
            # Note: In implementation, grid_sample or similar is used.
            # Here we assume a helper function `sample_grid(grid, coords)`
            # which handles interpolation.
            basis_val = sample_grid(self.basis_grids[l], x_transformed)
            basis_outputs.append(basis_val)
            
        # Concatenate basis outputs from all levels
        # Shape: (..., K_total)
        b_total = torch.cat(basis_outputs, dim=-1)
        
        # 2. Coefficient Evaluation
        # Identity transformation: gamma(x) = x
        # Sample coefficient grid
        c_val = sample_grid(self.coeff_grid, x)
        
        # 3. Hadamard Product
        v = c_val * b_total
        
        # 4. Regularization (Dropout)
        if self.training and self.mu > 0:
            mask = torch.rand_like(v) > self.mu
            v = v * mask
        
        # 5. Projection
        s_hat = self.proj(v)
        
        return s_hat
```

## Subtopics

### [Factor Fields Framework](19669-factor-fields-framework.md)
A unified framework that generalizes DiF by allowing $N$ factors with arbitrary transformations and field representations (MLPs, grids, vectors), enabling the modeling of NeRF, Instant-NGP, and TensoRF as special cases. Choose this when you need a flexible architecture to experiment with different factor combinations beyond the basis/coeff split.

## Operating characteristics
*   **Time Complexity:** Faster than purely MLP-based representations (like [SIREN](1250-siren-neural-field.md)) because the basis field uses grid lookups instead of network evaluations. However, slightly slower than single-factor grid methods like [DVGO](1150-scene-representation-networks-srn.md) due to the additional basis sampling and Hadamard product.
*   **Memory Complexity:** More compact than Instant-NGP. DiF halves the total number of model parameters for SDF and radiance field reconstruction compared to Instant-NGP [S2, unofficial]. Memory is dominated by the basis and coefficient grids.
*   **Performance:** Achieves state-of-the-art reconstruction quality on 2D image regression, 3D SDF, and radiance field tasks, often better or on par with Instant-NGP and Plenoxels [S2, unofficial].
*   **Strengths:** Implicit regularization via factorization; fast optimization; compact size; enables multi-signal learning (shared basis across scenes).
*   **Limitations:** Single-level DiF models are significantly worse than multi-level models in speed and quality [S2, unofficial]. Requires careful tuning of pyramid levels and frequencies.
*   **When to use:** When high-quality reconstruction is needed with limited memory, or when training across multiple similar scenes to share a basis.
*   **When not to use:** For very simple signals where a single MLP or grid suffices, or when real-time inference on extremely constrained hardware where even grid lookups are too heavy.

## Background
Dictionary Fields were introduced in February 2023 by the authors of the "Factor Fields" paper [S2, unofficial]. The method was developed to address the limitations of existing neural field representations, which either relied on slow MLPs (NeRF) or memory-heavy grids (DVGO) or lacked the ability to share structure across signals (Instant-NGP). DiF was designed to unify these approaches by explicitly separating global basis functions from local coefficients, enabling efficient and generalizable signal representation. It has been used in 2D image regression, 3D SDF geometry reconstruction, and radiance field reconstruction for novel view synthesis [S2, unofficial].
