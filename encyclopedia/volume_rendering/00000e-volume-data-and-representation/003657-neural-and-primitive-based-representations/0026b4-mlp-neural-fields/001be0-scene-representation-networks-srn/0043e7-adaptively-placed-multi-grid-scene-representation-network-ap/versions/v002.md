# Adaptively Placed Multi-Grid Scene Representation Network (APMGSRN)

Also called: AP-MGSRN, Adaptively placed multi-grid SRN, our model

## Overview
APMGSRN is a Scene Representation Network (SRN) architecture that represents continuous volumetric data using multiple spatially adaptive feature grids, dynamically allocating neural network resources to regions of high reconstruction error [S1]. Unlike sibling methods that rely on expensive octree structures or hash collisions to handle sparsity, APMGSRN uses learnable transformation matrices to migrate grid positions and scales, avoiding tree traversal and pruning while maintaining high accuracy for somewhat sparse scientific data [S1].

## How it works

### Inputs and Outputs
*   **Input:** A 3D global coordinate $\mathbf{x}_g \in [-1, 1]^3$.
*   **Output:** A scalar value $f(\mathbf{x}_g)$ representing the volume property (e.g., density, temperature) at that coordinate [S1].

### Data Structures
The model consists of two main components: the encoder (feature grids) and the decoder (MLP) [S1].

1.  **Feature Grids Tensor ($\mathbf{F}$):**
    *   Shape: $[M, C, D, H, W]$ [S1].
    *   $M$: Number of grids.
    *   $C$: Feature dimension (channels) per grid.
    *   $D, H, W$: Spatial resolution of each grid [S1].
    *   Layout: Dense tensor storing learnable feature vectors.

2.  **Transformation Matrices ($\mathbf{G}$):**
    *   Count: $M$ matrices, one per grid.
    *   Shape: $4 \times 4$ learnable parameters per grid [S1].
    *   Layout:
        $$
        \mathbf{G}_i = \begin{bmatrix}
        G_{i,0,1} & G_{i,0,2} & G_{i,0,3} & T_{i,x} \\
        G_{i,1,0} & G_{i,1,1} & G_{i,1,2} & T_{i,y} \\
        G_{i,2,0} & G_{i,2,1} & G_{i,2,2} & T_{i,z} \\
        0 & 0 & 0 & 1
        \end{bmatrix}
        $$
        *   The top-left $3 \times 3$ submatrix handles scale, rotation, and shearing [S1].
        *   The 4th column handles translation [S1].
        *   The bottom row is fixed as $[0, 0, 0, 1]$ for affine transformation in homogeneous coordinates [S1].

3.  **Decoder MLP ($m$):**
    *   Structure: 2-layer fully connected network [S1].
    *   Neurons: 64 per layer [S1].
    *   Bias: None [S1].
    *   Activation: ReLU after the first layer; linear output [S1].

### Parameters
*   **Grid Extents:** Local coordinates are assumed to lie within the unit cube $[-1, 1]^3$ [S1].
*   **Optimizer:** Adam [S1].
    *   Network weights (MLP): Learning rate $0.01$, $\beta_1=0.9$, $\beta_2=0.99$ [S1].
    *   Transformation matrices ($\mathbf{G}$): Learning rate $0.001$, $\beta_1=0.9$, $\beta_2=0.99$ [S1].
*   **Batch Size:** 100,000 coordinates sampled uniformly from $[-1, 1]^3$ per iteration [S1].
*   **Flat-top Gaussian Strength ($p$):** Controls the box-like shape of the density approximation [S1].
*   **Scaling Parameters:** Pre-computed global minimum ($min$) and maximum ($max$) of the training volume [S1].

### Numbered Steps

1.  **Grid Initialization:** Initialize $M$ grids at global scale with small random perturbations [S1]. (See Pitfalls for initialization details).
2.  **Coordinate Transformation:** For a query global coordinate $\mathbf{x}_g$, transform it into the local coordinate system $\mathbf{x}_l$ of each grid $i$ using $\mathbf{G}_i$:
    $$
    \begin{bmatrix} x_l \\ y_l \\ z_l \\ 1 \end{bmatrix} = \mathbf{G}_i \begin{bmatrix} x_g \\ y_g \\ z_g \\ 1 \end{bmatrix}
    $$
    Specifically, the local coordinates are computed as:
    $$
    \begin{aligned}
    x_l &= G_{i,0,1}x_g + G_{i,0,2}y_g + G_{i,0,3}z_g + T_{i,x} \\
    y_l &= G_{i,1,0}x_g + G_{i,1,1}y_g + G_{i,1,2}z_g + T_{i,y} \\
    z_l &= G_{i,2,0}x_g + G_{i,2,1}y_g + G_{i,2,2}z_g + T_{i,z}
    \end{aligned}
    $$
    [S1]
3.  **Feature Encoding (Trilinear Interpolation):** For each grid $i$, retrieve the feature vector $\mathbf{e}_i$ by trilinearly interpolating $\mathbf{F}_i$ at $\mathbf{x}_l$. If $\mathbf{x}_l$ is outside $[-1, 1]^3$, return a zero vector of size $C$ [S1]:
    $$
    \mathbf{e}_i(\mathbf{x}_l) = \begin{cases} 
    \text{trilinear}(\mathbf{F}_i, \mathbf{x}_l) & \text{if } -1 \leq x_l, y_l, z_l \leq 1 \\
    \mathbf{0}_C & \text{otherwise}
    \end{cases}
    $$
    [S1]
4.  **Concatenation:** Concatenate the feature vectors from all $M$ grids to form a single feature vector $\mathbf{y}$ of size $M \cdot C$:
    $$
    \mathbf{y} = \mathbf{e}_0(\mathbf{x}_{l,0}) \oplus \mathbf{e}_1(\mathbf{x}_{l,1}) \oplus \dots \oplus \mathbf{e}_{M-1}(\mathbf{x}_{l,M-1})
    $$
    where $\oplus$ denotes concatenation [S1].
5.  **Decoding:** Pass $\mathbf{y}$ through the shallow MLP $m$ to get the normalized output $\hat{v} \in [0, 1]$:
    $$
    \hat{v} = m(\mathbf{y})
    $$
    [S1]
6.  **Scaling:** Map the normalized output back to the original data range:
    $$
    f(\mathbf{x}_g) = \hat{v} \cdot (max - min) + min
    $$
    [S1]

### Feature Density Loss and Training
To adaptively move grids, a feature density loss is used [S1]. The true feature density $\rho(\mathbf{x})$ is defined by the determinant of the transformation matrix, but this is non-differentiable at boundaries [S1]. It is approximated by a flat-top Gaussian [S1].

1.  **Determinant Calculation:** For grid $i$, calculate the determinant of the top-left $3 \times 3$ submatrix of $\mathbf{G}_i$, denoted $\det(\mathbf{G}_{i,0:3,0:3})$ [S1]. This represents the feature density contribution if the point is inside the grid [S1].
2.  **Flat-top Gaussian Approximation:** Approximate the box function of the grid boundary using:
    $$
    g_i(\mathbf{x}_g) = \det(\mathbf{G}_{i,0:3,0:3}) \cdot \exp \left( - \sum_{d=0}^2 (x_{l,d})^{2p} \right)
    $$
    where $x_{l,d}$ are the local coordinates $x_l, y_l, z_l$, and $p$ is the flat-top strength [S1].
3.  **Total Feature Density:** Sum the contributions:
    $$
    \rho(\mathbf{x}_g) = \sum_{i=0}^{M-1} g_i(\mathbf{x}_g)
    $$
    [S1]
4.  **Loss Calculation:** Compute the relative entropy between the current feature density $\rho$ and a target feature density $\rho^*$ (derived from reconstruction error) [S1]. Higher feature density is encouraged in high-error regions [S1].
5.  **Optimization:** Update $\mathbf{G}$ and MLP weights using the combined reconstruction loss and feature density loss [S1].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class APMGSRN(nn.Module):
    def __init__(self, M, C, D, H, W, min_val, max_val):
        """
        M: Number of grids
        C: Feature channels per grid
        D, H, W: Grid resolution
        min_val, max_val: Data range for scaling
        """
        super().__init__()
        self.M = M
        self.C = C
        self.min_val = min_val
        self.max_val = max_val
        
        # Feature grids: [M, C, D, H, W]
        self.grids = nn.Parameter(torch.randn(M, C, D, H, W))
        
        # Transformation matrices: [M, 4, 4]
        # Initialize at global scale with small random perturbations [S1]
        self.G = nn.Parameter(torch.eye(4).unsqueeze(0).repeat(M, 1, 1))
        self.G.data += torch.randn_like(self.G) * 0.01
        
        # Decoder MLP: 2 layers, 64 neurons, no bias [S1]
        self.decoder = nn.Sequential(
            nn.Linear(M * C, 64, bias=False),
            nn.ReLU(),
            nn.Linear(64, 1, bias=False)
        )

    def transform_to_local(self, x_g, G):
        """
        x_g: [N, 3] global coordinates
        G: [M, 4, 4] transformation matrices
        Returns: [M, N, 3] local coordinates
        """
        # x_g: [N, 3] -> [N, 4] homogeneous
        x_h = torch.cat([x_g, torch.ones(x_g.shape[0], 1, device=x_g.device)], dim=1) # [N, 4]
        
        # G: [M, 4, 4]
        # We want local coords for each grid for each point
        # Result shape: [M, 4, N]
        x_local_h = torch.bmm(G, x_h.transpose(0, 1).unsqueeze(0).expand(M, -1, -1))
        x_local = x_local_h[:, :, :3].transpose(1, 2) # [M, N, 3]
        return x_local

    def trilinear_interpolate(self, grids, x_local):
        """
        grids: [M, C, D, H, W]
        x_local: [M, N, 3] local coordinates in [-1, 1]
        Returns: [M, N, C] features
        """
        M, N, _ = x_local.shape
        # grid_sample expects coordinates in [-1, 1]
        # padding_mode='zeros' returns 0 for out-of-bounds coordinates
        grids_flat = grids.view(M * N, self.C, self.D, self.H, self.W)
        x_grid_flat = x_local.view(M * N, 1, 1, 1, 3)
        sampled = F.grid_sample(grids_flat, x_grid_flat, mode='trilinear', padding_mode='zeros', align_corners=False)
        features = sampled.squeeze(-1).squeeze(-1).squeeze(-1).view(M, N, self.C)
        return features

    def forward(self, x_g):
        """
        x_g: [N, 3] global coordinates
        Returns: [N] scalar values
        """
        # 1. Transform to local space
        x_local = self.transform_to_local(x_g, self.G) # [M, N, 3]
        
        # 2. Interpolate features
        features = self.trilinear_interpolate(self.grids, x_local) # [M, N, C]
        
        # 3. Concatenate features
        # features shape: [M, N, C] -> [N, M*C]
        features = features.permute(1, 0, 2).reshape(x_g.shape[0], -1)
        
        # 4. Decode
        normalized_output = self.decoder(features) # [N, 1]
        
        # 5. Scale
        output = normalized_output.squeeze(-1) * (self.max_val - self.min_val) + self.min_val
        
        return output

    def compute_feature_density(self, x_g, p=2.0):
        """
        Computes the differentiable feature density approximation for loss calculation.
        x_g: [N, 3]
        p: flat-top strength
        Returns: [N] density values
        """
        x_local = self.transform_to_local(x_g, self.G) # [M, N, 3]
        
        # Determinants of top-left 3x3
        G_3x3 = self.G[:, :3, :3] # [M, 3, 3]
        det_G = torch.linalg.det(G_3x3) # [M]
        
        # Local coords raised to 2p
        x_local_pow = torch.pow(torch.abs(x_local), 2 * p) # [M, N, 3]
        sum_pow = torch.sum(x_local_pow, dim=2) # [M, N]
        
        # Exponential term
        exp_term = torch.exp(-sum_pow) # [M, N]
        
        # Density contribution per grid
        density = det_G.unsqueeze(1) * exp_term # [M, N]
        
        # Sum over grids
        total_density = torch.sum(density, dim=0) # [N]
        
        return total_density
```

### Edge Cases and Pitfalls
*   **Out of Bounds:** If a transformed coordinate is outside $[-1, 1]^3$, the feature contribution is zero [S1].
*   **Initialization:** Initializing grids at small scales with random positions leads to near-zero gradients if grids do not cover data, causing poor learning. Mitigation: Initialize at global scale with small perturbations [S1].
*   **Gradient Vanishing for G:** The true feature density is a step function with zero gradient outside the grid. The flat-top Gaussian approximation is required to provide gradients for updating $\mathbf{G}$ based on errors outside the local domain [S1].
*   **Sparsity:** APMGSRN underperforms NGP on highly sparse datasets (e.g., asteroid) because NGP handles hash collisions better, while APMGSRN is dominant in somewhat sparse data (e.g., plume, supernova) [S1].
*   **Performance:** Slower to render than NGP and fVSRN due to transformation operations and pure PyTorch implementation of multigrid encoding (unless using TCNN for decoding only) [S1].

## Operating characteristics

*   **Time Complexity:** Encoding requires $M$ transformations and interpolations per query point [S1]. Decoding is $O(M \cdot C)$ for the MLP.
*   **Memory Complexity:** $O(M \cdot C \cdot D \cdot H \cdot W)$ for the feature grids plus $O(M)$ for transformation matrices and MLP weights [S1].
*   **Performance:**
    *   Decoding speed: on the order of 500 million points per second [S1].
    *   Training: 5 minutes on 8 GPUs for 250GB data [S1].
    *   Compression: 1432x compression ratio on 250GB rotstrat data with 44.29 dB PSNR [S1].
*   **Strengths:**
    *   Adaptive resource allocation to high-error regions without tree structures [S1].
    *   High compression ratios for large scientific volumes [S1].
    *   Efficient arbitrary point evaluation [S1].
*   **Limitations:**
    *   Slower rendering than hash-based methods (NGP) due to transformation overhead [S1].
    *   Poor performance on highly sparse data compared to NGP [S1].
    *   Requires careful initialization of transformation matrices [S1].
*   **When to Use:** Suitable for somewhat sparse scientific volumes where high compression and adaptive accuracy are needed, and tree-based methods are too complex or slow to construct [S1].
*   **When Not to Use:** Highly sparse datasets (use NGP) or when maximum rendering speed is critical and sparsity is extreme [S1].

## Background

*   **Origin:** Introduced by [S1].
*   **Context:** Developed to address the lack of adaptivity in state-of-the-art SRNs for large-scale scientific data visualization, which often have static surfaces and high sparsity [S1].
*   **Development:** Builds on the concept of feature grid SRNs (like fVSRN) but replaces the single dense grid with multiple adaptive grids [S1]. It avoids octree-based methods (like NGLOD) by using learned transformation matrices [S1].
*   **Usage:** Used for visualizing large-scale scientific data (e.g., rotstrat, supernova, plume) and compression [S1].
