# E-SCRNet

Also called: Evidential Scene Coordinate Regression Network

## Overview
E-SCRNet is a scene coordinate regression (SCR) network that utilizes deep evidential learning to predict 3D scene coordinates along with the hyperparameters of a Normal Inverse-Gamma (NIG) distribution, enabling closed-form estimation of epistemic uncertainty without sampling [S1]. Unlike standard regression networks that output point estimates, E-SCRNet models the uncertainty of predictions to evaluate information gain for novel view selection and to filter unreliable correspondences in downstream tasks like RANSAC-PnP [S1]. It builds on [REV-INR](10472-rev-inr.md) by applying similar evidential principles specifically to the coordinate regression task within a pipeline that augments training data using uncertainty-aware NeRF synthesis.

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D position (or 2D pixel coordinate mapped to a ray) and potentially viewing direction or positional encoding features.
*   **Output:** Four scalar values representing the NIG hyperparameters: $(\gamma, v, \alpha, \beta)$ [S1].

**Data Structures:**
The network architecture is based on a standard SCRNet (e.g., the baseline from [1] in [S1]). The modification is strictly in the final layer:
*   The final layer outputs a vector of size 4.
*   The values correspond to:
    *   $\gamma$: The predicted mean scene coordinate.
    *   $v$: The precision scaling factor for the mean.
    *   $\alpha$: The shape parameter for the variance.
    *   $\beta$: The scale parameter for the variance.
*   All parameters are constrained to be positive (except $\gamma$, which is unconstrained) to maintain valid probability distributions [S1].

**Training and Inference Steps:**
1.  **Initial Training:** Train an initial version of E-SCRNet on a small set of real posed RGB-D images, denoted as $S_{real}$ [S1].
2.  **Synthetic Data Generation:** Use an uncertainty-aware NeRF (U-NeRF) to generate a dataset of synthetic novel views, $S_{new}$, within the scene boundary [S1].
3.  **Uncertainty Prediction:** Feed $S_{new}$ into the trained E-SCRNet to predict scene coordinates and their associated epistemic uncertainties [S1].
4.  **Filtering and Selection:**
    *   Use U-NeRF's color and depth uncertainties to filter out poorly rendered images from $S_{new}$ [S1].
    *   Use the predicted epistemic uncertainties from E-SCRNet as a proxy for information gain.
    *   Select views with high information gain to form the set $S_{high}$ [S1].
5.  **Finetuning:** Augment the training dataset with the selected high-information views: $S_{aug} = S_{real} \cup S_{high}$. Finetune E-SCRNet on $S_{aug}$ to improve localization performance [S1].
6.  **Deployment:** For novel views, E-SCRNet outputs coordinates and uncertainty. The uncertainty can be used to filter unreliable 2D-3D correspondences in RANSAC-PnP [S1].

**Formulas:**
The NIG distribution is defined by the prior assumptions that observed scene coordinates $q_i$ are drawn i.i.d. from a Gaussian distribution with unknown mean $\mu_q$ and variance $\sigma_q^2$. The priors are:
$$ \mu_q \sim \mathcal{N}(\gamma, \sigma_q^2 v^{-1}) $$
$$ \sigma_q^2 \sim \text{Inv-Gamma}(\alpha, \beta) $$

The predicted mean and epistemic uncertainty (variance of the mean) are calculated as [S1]:
$$ E[\mu] = \gamma $$
$$ Var[\mu] = \frac{\beta}{v(\alpha - 1)} $$

The coordinate loss $L_{coord}$ used to train the network to output the correct hyperparameters is derived from maximizing the model fit while minimizing evidence on errors [S1]:
$$ L_{coord} = \sum_{q \in S} \left[ (\alpha + 1/2) \log \left( (q - \gamma)^2 \nu + 2\beta (1 + \nu) \right) + \frac{1}{2} \log \frac{\pi}{\nu} - \alpha \log (2\beta (1 + \nu)) + \log \frac{\Gamma(\alpha)}{\Gamma(\alpha + 1/2)} + |q - \gamma| \cdot (2\nu + \alpha) \right] $$

*Note on $\nu$:* The source text uses the symbol $\nu$ in the loss formula [S1]. The context suggests $\nu$ is a scaling factor or a typo for $v$ (the precision parameter), as $v$ is the other precision-related hyperparameter. The formula is reproduced exactly as presented in the source structure involving Gamma functions and log terms [S1].

**Pseudocode:**
```python
import numpy as np
from scipy.special import gammaln

def compute_nig_uncertainty(gamma, v, alpha, beta):
    """
    Computes the predicted mean and epistemic uncertainty (variance of the mean)
    from the NIG hyperparameters.
    
    Args:
        gamma (float): Predicted mean coordinate.
        v (float): Precision scaling factor (must be > 0).
        alpha (float): Shape parameter (must be > 1 for variance to be defined).
        beta (float): Scale parameter (must be > 0).
        
    Returns:
        mean (float): E[mu]
        var_mu (float): Var[mu]
    """
    mean = gamma
    # Variance of the mean is beta / (v * (alpha - 1))
    # Requires alpha > 1
    if alpha <= 1:
        # Handle degenerate case where variance is undefined or infinite
        var_mu = np.inf 
    else:
        var_mu = beta / (v * (alpha - 1))
    return mean, var_mu

def compute_coord_loss(q, gamma, v, alpha, beta, nu):
    """
    Computes the coordinate loss L_coord for a single observation q.
    
    Args:
        q (float): Ground truth scene coordinate.
        gamma (float): Predicted mean.
        v (float): Precision scaling factor.
        alpha (float): Shape parameter.
        beta (float): Scale parameter.
        nu (float): Scaling factor from the loss formula (likely typo for v or distinct constant).
        
    Returns:
        loss (float): The computed loss value.
    """
    # Term 1: (alpha + 1/2) * log((q - gamma)^2 * nu + 2*beta*(1 + nu))
    term1 = (alpha + 0.5) * np.log((q - gamma)**2 * nu + 2 * beta * (1 + nu))
    
    # Term 2: (1/2) * log(pi / nu)
    term2 = 0.5 * np.log(np.pi / nu)
    
    # Term 3: -alpha * log(2*beta*(1 + nu))
    term3 = -alpha * np.log(2 * beta * (1 + nu))
    
    # Term 4: log(Gamma(alpha) / Gamma(alpha + 1/2))
    # Using log-gamma for numerical stability
    term4 = gammaln(alpha) - gammaln(alpha + 0.5)
    
    # Term 5: |q - gamma| * (2*nu + alpha)
    term5 = np.abs(q - gamma) * (2 * nu + alpha)
    
    loss = term1 + term2 + term3 + term4 + term5
    return loss

def train_e_scrnet_step(dataset, model, nu):
    """
    Simulates one training step for E-SCRNet.
    
    Args:
        dataset: List of (q, gamma_pred, v_pred, alpha_pred, beta_pred) tuples.
                 In practice, gamma, v, alpha, beta are outputs of the model.
        model: The neural network returning gamma, v, alpha, beta.
        nu: The scaling factor used in the loss function.
        
    Returns:
        total_loss: The sum of losses over the batch.
    """
    total_loss = 0.0
    for q in dataset:
        # Forward pass to get predictions
        # Note: In a real implementation, gamma, v, alpha, beta are tensors
        # from the model output. Here we assume they are provided for the formula.
        # The model must enforce v, alpha, beta > 0.
        gamma, v, alpha, beta = model(q)
        
        # Compute loss for this sample
        loss = compute_coord_loss(q, gamma, v, alpha, beta, nu)
        total_loss += loss
    return total_loss
```

**Edge Cases and Pitfalls:**
*   **Alpha Constraint:** The epistemic uncertainty formula $Var[\mu] = \beta / (v(\alpha - 1))$ requires $\alpha > 1$. If the network predicts $\alpha \le 1$, the uncertainty is undefined or infinite [S1]. The training loss or output layer should enforce $\alpha > 1$ (e.g., via softplus or shift) [G].
*   **Positive Constraints:** $v, \alpha, \beta$ must be positive. The network output layer should use activation functions (e.g., softplus) to ensure positivity [G].
*   **Symbol $\nu$:** The presence of $\nu$ in the loss formula is ambiguous. It may be a typo for $v$ or a fixed hyperparameter. Implementers should verify this against the original implementation or treat it as a tunable hyperparameter if not specified [S1].

## Operating characteristics
*   **Time Complexity:** Training involves standard backpropagation through the NIG loss. The complexity is dominated by the neural network forward and backward passes, similar to standard SCRNet, with minor overhead for computing the log-Gamma terms in the loss [S1].
*   **Memory Complexity:** The model stores the same number of parameters as the baseline SCRNet, plus the output dimension is 4 instead of 1 or 3 (depending on baseline). Memory usage is comparable to standard SCRNet [S1].
*   **Performance:** E-SCRNet allows for data-efficient training. By selecting only high-information synthetic views, it achieves comparable or better performance than training on the full synthetic dataset, using only a small portion of real data ($S_{real}$) [S1].
*   **Strengths:**
    *   Provides closed-form epistemic uncertainty without sampling [S1].
    *   Enables effective novel view selection and data augmentation [S1].
    *   Improves robustness in RANSAC-PnP by filtering unreliable correspondences [S1].
*   **Limitations:**
    *   Relies on the quality of the initial U-NeRF for synthetic data generation [S1].
    *   The ambiguity of the $\nu$ parameter in the loss function may require empirical tuning [S1].
*   **When to use:** When training data is scarce and synthetic data is available, but not all synthetic views are equally informative. Also useful when uncertainty-aware correspondences are needed for robust pose estimation [S1].

## Background
E-SCRNet was introduced in the paper "Leveraging Neural Radiance Fields for Uncertainty-Aware Visual Localization" by Le Chen, Weirong Chen, Rui Wang, and Marc Pollefeys [S1]. The work was presented at ICRA 2024 [S1]. It extends the concept of evidential deep learning to scene coordinate regression, building on prior work in uncertainty-aware NeRFs (U-NeRF) and standard SCR methods [S1]. The method addresses challenges in visual localization by improving data efficiency and reliability of 2D-3D correspondences [S1].
