# Self-Attention Convolutions

Also called: SAC

## Overview
Self-Attention Convolutions (SAC) generate features across multiple frequency scales to complement positional encoding in neural surface reconstruction, specifically addressing discretization discontinuities and noise in tri-plane representations [S1]. Unlike static positional encodings that map coordinates to a fixed basis, SAC dynamically produces multi-frequency feature maps by applying self-attention mechanisms with varying window sizes, effectively smoothing noise while preserving high-frequency details [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Tri-plane feature maps $T \in \mathbb{R}^{H \times W \times C}$, where $H, W$ are spatial dimensions and $C$ is the channel dimension [S1].
*   **Output:** Enhanced tri-plane feature maps $T' \in \mathbb{R}^{H \times W \times C}$ containing multi-frequency information [S1].

**Data Structures:**
The method operates on standard floating-point tensor data structures [G].

**Parameters:**
*   **Window size ($k$):** Controls the frequency scale. Larger $k$ captures lower frequencies, while smaller $k$ captures higher frequencies [S1]. A typical value cited is $k=3$ [S1].

**Algorithm:**
The SAC mechanism processes the input tri-plane features through a self-attention convolution block [S1]. The process is defined as follows:
1. Use different window sizes as kernels to capture multi-frequency features from tri-planes [S1].
2. Produce convolved features for each window size kernel using a self-attention mechanism [S1].
3. Add the original tri-plane features to the convolved features to obtain the final output feature maps with multiple frequencies [S1].

**Pseudocode:**
The following Python-like pseudocode implements the SAC block as described in [S1], following the exact operation sequence provided in the source diagram. Standard tensor operations (`Linear`, `Matmul`, `Transpose`, `Softmax`, `Add`) are assumed.

```python
def SelfAttentionConvolution(features, k):
    # features: input tensor of shape (B, C, H, W)
    # k: window size controlling frequency scale
    # Step 1: Linear projection
    x_proj = Linear(features)
    # Step 2: Matrix multiplication for attention scores
    attn_scores = Matmul(x_proj, Transpose(x_proj))
    # Step 3: Linear projection
    attn_scores = Linear(attn_scores)
    # Step 4: Softmax normalization
    attn_weights = Softmax(attn_scores)
    # Step 5: Multiply attention weights with features
    attn_output = Matmul(attn_weights, features)
    # Step 6: Sum with original input tensor
    summed = Add(attn_output, features)
    # Step 7: Final Linear projection
    output = Linear(summed)
    return output
```

## Subtopics

### Self-Attention Convolution (SAC)
This variant uses self-attention with varying window sizes to capture multi-frequency features from tri-planes [S1]. Larger window sizes represent lower frequencies, and smaller window sizes represent higher frequencies [S1]. It is chosen when multi-scale feature extraction is needed to complement positional encoding in neural surface reconstruction, specifically to handle noise and discretization discontinuities [S1]. It is used in the PET-NeuS architecture [S1].

## Operating characteristics
**Time and Memory Complexity:**
The source does not provide explicit time or memory complexity analysis [S1]. Standard self-attention complexity is $O(N^2)$ where $N$ is the number of spatial tokens ($H \times W$), which can be prohibitive for high-resolution tri-planes [G].

**Measured Performance:**
In experiments on the DTU dataset, SAC outperforms multi-scale tri-plane architectures ("MSA") [S1]. It significantly reduces geometric error compared to using only positional encoding ("TP-NeuS + PE") [S1]. On the CO3D dataset, it demonstrates robustness to noise from portable device captures [S1].

**Strengths and Limitations:**
*   **Strengths:** Effective at smoothing noise and handling discretization discontinuities [S1]. Outperforms multi-scale tri-plane representations [S1].
*   **Limitations:** Not given in the sources.

**When to Use:**
Use SAC when integrating positional encoding with tri-plane representations in neural surface reconstruction to improve robustness to noise and high-frequency detail preservation [S1].

## Background
Self-Attention Convolutions were introduced in the PET-NeuS paper [S1]. The method builds on the concept of using positional encoding with tri-planes for neural surface reconstruction [S1]. It was proposed to address the limitations of standard positional encoding, which suffers from discretization discontinuities [S1]. The specific SAC mechanism is adapted from a vanilla SAC mechanism described in reference [32] of the PET-NeuS paper [S1].
