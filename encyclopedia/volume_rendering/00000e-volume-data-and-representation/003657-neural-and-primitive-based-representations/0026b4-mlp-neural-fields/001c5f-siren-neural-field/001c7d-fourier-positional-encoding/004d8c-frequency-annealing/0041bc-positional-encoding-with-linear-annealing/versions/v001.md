# Positional Encoding with Linear Annealing

Also called: Linear Annealing Positional Encoding

## Overview
Positional Encoding with Linear Annealing is a frequency scheduling technique that progressively exposes higher-frequency bands of a positional encoding during training [S1, unofficial]. It solves the problem of optimization instability in high-frequency neural fields by masking low frequencies at the start and linearly unmasking them as training progresses [S1, unofficial]. It differs from standard Fourier Positional Encoding by introducing a time-dependent mask, and from other Frequency Annealing methods by using a simple linear clamp function rather than a smooth windowing kernel [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** `positions` (tensor of shape `[..., D]`), `freqs` (integer, number of frequency bands), `progress` (float in `[0, 1]`, current training progress).
- **Output:** `encoded` (tensor of shape `[..., freqs * 2 * D]`).

**Data Structures:**
- `levels`: 1D tensor of integers `[0, 1, ..., freqs-1]`.
- `freq_bands`: 1D tensor of floats `[2^0, 2^1, ..., 2^(freqs-1)]`.
- `mask`: 1D tensor of floats in `[0, 1]`, same shape as `levels`.

**Steps:**
1. Generate frequency levels: $L = [0, 1, \dots, \text{freqs}-1]$.
2. Compute frequency bands: $F_i = 2^{L_i}$.
3. Compute the annealing mask for each level $i$:
   $$ m_i = \text{clamp}(\text{progress} \times \text{freqs} - L_i, 0.0, 1.0) $$
   where $\text{clamp}(x, a, b) = \max(a, \min(b, x))$ [S1, unofficial].
4. Scale positions by frequency bands: $P_{i,j} = \text{positions}_j \times F_i$.
5. Apply mask to sine and cosine components:
   $$ S_{i,j} = \sin(P_{i,j}) \times m_i $$
   $$ C_{i,j} = \cos(P_{i,j}) \times m_i $$
6. Concatenate sine and cosine along the last dimension and reshape to `[..., freqs * 2 * D]` [S1, unofficial].

**Pseudocode:**
```python
import torch
import math

def positional_encoding_linear_annealing(positions, freqs, progress=1.0):
    """
    Compute positional encoding with linear annealing.
    
    Args:
        positions: Tensor of shape [..., D].
        freqs: Integer, number of frequency bands.
        progress: Float in [0, 1], controls frequency exposure.
        
    Returns:
        Tensor of shape [..., freqs * 2 * D].
    """
    # 1. Create frequency levels
    levels = torch.arange(freqs, device=positions.device)
    
    # 2. Compute frequency bands as powers of 2
    freq_bands = 2 ** levels
    
    # 3. Compute mask using linear annealing
    # mask_i = clamp(progress * freqs - i, 0.0, 1.0)
    mask = (progress * freqs - levels).clamp_(min=0.0, max=1.0)
    
    # 4. Scale positions by frequency bands
    # pts shape: [..., freqs]
    pts = positions[..., None] * freq_bands
    
    # 5. Apply mask to sine and cosine components
    pts_sin = torch.sin(pts) * mask
    pts_cos = torch.cos(pts) * mask
    
    # 6. Concatenate and reshape
    # Concatenate along the last dimension: [..., freqs, 2]
    pts = torch.cat([pts_sin, pts_cos], dim=-1)
    
    # Reshape to [..., freqs * 2 * D]
    # Note: positions.shape[-1] is D
    final_dim = freqs * 2 * positions.shape[-1]
    pts = pts.reshape(positions.shape[:-1] + (final_dim,))
    
    return pts
```

**Parameters:**
- `progress`: Controls the exposure of positional encoding. `0` means fully masked (all zeros), `1` means fully exposed (all frequencies active) [S1, unofficial].

**Edge Cases and Pitfalls:**
- If `progress` is outside `[0, 1]`, the clamp ensures the mask stays within `[0, 1]`, but the behavior may be unintended [S1, unofficial].
- Precision issues may arise if `freqs` is very large, causing `progress * freqs - levels` to have significant floating-point error.
- The method assumes `freqs` is an integer. Non-integer values will result in incorrect level alignment [S1, unofficial].

## Subtopics

### Geometrical Granularity Regularization
A regularization technique that enforces a progressive coarse-to-fine geometry-learning scheme by applying a bitmask to the positional encoding frequencies only, not directional encoding [S2]. It calculates a bitmask $\alpha_i(t, T, L)$ for iteration $t$, final iteration $T$, and max frequency $L$: $\alpha_i = 1$ if $i < 2(t \cdot L/T + b)$, else $0$. The regularized encoding is $\gamma'(x, t) = \gamma(x) \odot \alpha(t, T, L)$ [S2]. Parameters: Positional encoding frequency range $L_p = 10$, Regularization window $T = \lfloor 0.10 \times \text{total iterations} \rfloor$, Bias $b = L_p / 2$ [S2]. It is similar to Yang et al. (2023) who propose a coarse-to-fine strategy by gradually increasing the number of frequencies used in the input encoding during training [S2].

## Operating characteristics
**Time and Memory Complexity:**
- Time: $O(N \cdot \text{freqs} \cdot D)$, where $N$ is the number of points, $\text{freqs}$ is the number of frequency bands, and $D$ is the input dimension. The mask computation is $O(\text{freqs})$.
- Memory: $O(N \cdot \text{freqs} \cdot D)$ for the output tensor. The mask and frequency bands are small auxiliary tensors.

**Measured Performance:**
- Not given in the sources.

**Scaling:**
- Scales linearly with the number of frequencies and input dimensions.

**Strengths and Limitations:**
- Strengths: Simple to implement, effective at stabilizing training by preventing high-frequency oscillations early on [S1, unofficial].
- Limitations: The linear mask may be too abrupt compared to smooth windowing functions. It does not account for directional encoding [S2].

**When to use it and when not:**
- Use when training neural fields with Fourier positional encoding and experiencing high-frequency artifacts or instability [S1, unofficial].
- Do not use if smooth frequency transitions are required or if directional encoding also needs annealing [S2].

## Background
Originated in the context of neural radiance fields (NeRF) and related neural representations to address optimization difficulties with high-frequency positional encodings [S1, unofficial]. The specific implementation using linear annealing via a clamp function is documented in an unofficial GitHub repository [S1, unofficial]. A variant, Geometrical Granularity Regularization, was proposed for satellite imagery reconstruction in SatGeo-NeRF [S2].
