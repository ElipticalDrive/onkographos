# Positional Encoding with Linear Annealing

Also called: Linear Annealing Positional Encoding

## Overview
Positional Encoding with Linear Annealing is a frequency scheduling technique that progressively exposes frequency bands of a positional encoding based on a progress parameter, masking lower frequencies at progress=0 and exposing all at progress=1 [S1, unofficial]. It differs from standard Fourier Positional Encoding by introducing a progress-dependent mask applied to the sine and cosine components [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** `positions` (tensor of shape `[..., D]`), `freqs` (integer, number of frequency bands), `progress` (float in `[0, 1]`, controls frequency exposure) [S1, unofficial].
- **Output:** `encoded` (tensor of shape `[..., freqs * 2 * D]`) [S1, unofficial].

**Data Structures:**
- `levels`: 1D tensor of integers `[0, 1, ..., freqs-1]` [S1, unofficial].
- `freq_bands`: 1D tensor of floats `[2^0, 2^1, ..., 2^(freqs-1)]` [S1, unofficial].
- `mask`: 1D tensor of floats in `[0, 1]`, same shape as `levels` [S1, unofficial].

**Steps:**
1. Generate frequency levels: $L = [0, 1, \dots, \text{freqs}-1]$ [S1, unofficial].
2. Compute frequency bands: $F_i = 2^{L_i}$ [S1, unofficial].
3. Compute the annealing mask for each level $i$: $m_i = \text{clamp}(\text{progress} \times \text{freqs} - L_i, 0.0, 1.0)$ [S1, unofficial].
4. Scale positions by frequency bands: $P_{i,j} = \text{positions}_j \times F_i$ [S1, unofficial].
5. Apply mask to sine and cosine components: $S_{i,j} = \sin(P_{i,j}) \times m_i$, $C_{i,j} = \cos(P_{i,j}) \times m_i$ [S1, unofficial].
6. Concatenate sine and cosine along the last dimension and reshape to `[..., freqs * 2 * D]` [S1, unofficial].

**Pseudocode:**
```python
import torch

def positional_encoding(positions, freqs, progress=1.0):
    levels = torch.arange(freqs, device=positions.device)
    freq_bands = 2 ** levels
    mask = (progress * freqs - levels).clamp_(min=0.0, max=1)
    pts = positions[..., None] * freq_bands
    pts_sin = torch.sin(pts) * mask
    pts_cos = torch.cos(pts) * mask
    pts = torch.cat([pts_sin, pts_cos], dim=-1)
    pts = pts.reshape(positions.shape[:-1] + (freqs * 2 * positions.shape[-1],))
    return pts
```

**Parameters:**
- `progress`: Controls the exposure of positional encoding. `0` means fully masked, `1` means fully exposed [S1, unofficial].

## Subtopics

### Geometrical Granularity Regularization
A regularization technique that enforces a progressive coarse-to-fine geometry-learning scheme by applying a bitmask to the positional encoding frequencies only, not directional encoding [S2]. It calculates a bitmask $\alpha_i(t, T, L)$ for iteration $t$, final iteration $T$, and max frequency $L$: $\alpha_i = 1$ if $i < 2(t \cdot L/T + b)$, else $0$ [S2]. The regularized encoding is $\gamma'(x, t) = \gamma(x) \odot \alpha(t, T, L)$ [S2]. Parameters: Positional encoding frequency range $L_p = 10$, Regularization window $T = \lfloor 0.10 \times \text{total iterations} \rfloor$, Bias $b = L_p / 2$ [S2]. It is similar to Yang et al. (2023) who propose a coarse-to-fine strategy by gradually increasing the number of frequencies used in the input encoding during training [S2].
