# Frequency Annealing

Also called: Dynamic High-Pass Filtering, Progressive Frequency Regularization

## Overview
Frequency Annealing is a regularization technique for 3D Gaussian Splatting that mitigates over-reconstruction and artifacts by gradually shifting optimization focus from low-frequency (global structure) to high-frequency (local detail) components [S1]. It distinguishes itself from naive frequency regularization, which applies amplitude and phase discrepancies uniformly across all frequencies, by employing a dynamic high-pass filter that expands its spectral range over time to enable coarse-to-fine densification [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Rendered image frequency spectrum $F(u, v)$, ground truth image frequency spectrum $\hat{F}(u, v)$, current training iteration $t$, start iteration for high-frequency introduction $T_0$, end iteration $T$, low-pass filter max range $D_0$, max frequency spectrum range $D$, low-frequency weight $w_l$, high-frequency weight $w_h$.
*   **Output:** Progressive frequency loss $L_f$.

**Data Structures**
*   **Frequency Spectrum:** Complex-valued 2D array of size $H \times W$, where $H$ and $W$ are image height and width. The coordinate origin $(0,0)$ for distance calculations is the center point $(H/2, W/2)$ [S1].
*   **Filters:**
    *   $H_l(u, v)$: Low-pass filter mask.
    *   $H_h(u, v)$: Dynamic high-pass filter mask, dependent on iteration $t$.

**Formulas**
1.  **Frequency Extraction:**
    $$LF(u, v) = F(u, v)H_l(u, v)$$
    $$HF(u, v) = F(u, v)H_h(u, v)$$
    where $LF$ and $HF$ are the low and high-frequency components, respectively [S1].

2.  **Discrepancy Metrics:**
    The amplitude and phase discrepancies are computed using the Euclidean metric over the $H \times W$ grid [S1]:
    $$d_{la} = \sqrt{\frac{1}{HW} \sum_{x=0}^{H-1} \sum_{y=0}^{W-1} (|LF(u, v)| - |\hat{LF}(u, v)|)^2}$$
    $$d_{lp} = \sqrt{\frac{1}{HW} \sum_{x=0}^{H-1} \sum_{y=0}^{W-1} (\angle LF(u, v) - \angle \hat{LF}(u, v))^2}$$
    $$d_{ha} = \sqrt{\frac{1}{HW} \sum_{x=0}^{H-1} \sum_{y=0}^{W-1} (|HF(u, v)| - |\hat{HF}(u, v)|)^2}$$
    $$d_{hp} = \sqrt{\frac{1}{HW} \sum_{x=0}^{H-1} \sum_{y=0}^{W-1} (\angle HF(u, v) - \angle \hat{HF}(u, v))^2}$$
    where $d_{la}, d_{lp}$ are low-frequency amplitude and phase discrepancies, and $d_{ha}, d_{hp}$ are high-frequency counterparts [S1].

3.  **Dynamic High-Pass Filter Range:**
    The allowed frequency band range $D_t$ for the high-pass filter at iteration $t$ is defined as [S1]:
    $$D_0 < D_t < \frac{(t - T_0)(D - D_0)}{T - T_0} + D_0$$
    where $D_t$ is the dynamic cutoff, $D_0$ is the initial low-pass max range, and $D$ is the max spectrum range [S1].

4.  **Progressive Frequency Loss:**
    $$L_f = \begin{cases} w_l(d_{la} + d_{lp}), & 0 < t \le T_0 \\ w_l(d_{la} + d_{lp}) + w_h(d_{ha} + d_{hp}), & t > T_0 \end{cases}$$
    where $w_l$ and $w_h$ are training weights for low and high frequencies [S1].

**Pseudocode**
```python
def compute_frequency_annealing_loss(rendered_spectrum, gt_spectrum, t, T0, T, D0, D, wl, wh):
    """
    Compute the progressive frequency regularization loss.
    
    Args:
        rendered_spectrum: Complex 2D array (H, W) of rendered image in Fourier space.
        gt_spectrum: Complex 2D array (H, W) of ground truth image in Fourier space.
        t: Current training iteration.
        T0: Iteration start for high-frequency regularization.
        T: Iteration end for high-frequency regularization.
        D0: Max range of the low-pass filter (initial cutoff).
        D: Max frequency spectrum range.
        wl: Weight for low-frequency loss.
        wh: Weight for high-frequency loss.
        
    Returns:
        L_f: Scalar loss value.
    """
    H, W = rendered_spectrum.shape
    center_h, center_w = H // 2, W // 2
    
    # 1. Create coordinate grid centered at (H/2, W/2)
    # y corresponds to rows (0 to H-1), x to columns (0 to W-1)
    y_coords = np.arange(H) - center_h
    x_coords = np.arange(W) - center_w
    Y, X = np.meshgrid(y_coords, x_coords)
    
    # 2. Compute distance from center for each frequency component
    # Distance D_uv for each (u,v)
    D_uv = np.sqrt(X**2 + Y**2)
    max_D = np.max(D_uv)
    
    # 3. Define Low-Pass Filter H_l
    # H_l is 1 where distance <= D0, 0 otherwise
    # Note: D0 must be scaled relative to max_D if D0 is given in absolute frequency units
    # Assuming D0 and D are in the same units as D_uv (pixels in freq domain)
    H_l = (D_uv <= D0).astype(np.float32)
    
    # 4. Define Dynamic High-Pass Filter H_h
    # Calculate current dynamic cutoff D_t
    if t > T0:
        # Linear interpolation of cutoff from D0 to D
        # Formula: D_t = D0 + (t - T0) * (D - D0) / (T - T0)
        # The source gives inequality D0 < D_t < ..., implying D_t is the boundary.
        # We use the upper bound formula for the cutoff threshold.
        D_t = D0 + (t - T0) * (D - D0) / (T - T0)
        # High-pass filter is 1 where distance > D_t
        H_h = (D_uv > D_t).astype(np.float32)
    else:
        # Before T0, high-frequency loss is not applied, but we still need HF for consistency
        # or simply set H_h to 0 to nullify high-freq terms
        H_h = np.zeros((H, W), dtype=np.float32)
        
    # 5. Extract Low and High Frequency Components
    LF = rendered_spectrum * H_l
    LF_gt = gt_spectrum * H_l
    
    HF = rendered_spectrum * H_h
    HF_gt = gt_spectrum * H_h
    
    # 6. Compute Amplitude and Phase Discrepancies
    # Amplitude
    LF_amp = np.abs(LF)
    LF_gt_amp = np.abs(LF_gt)
    HF_amp = np.abs(HF)
    HF_gt_amp = np.abs(HF_gt)
    
    d_la = np.sqrt(np.mean((LF_amp - LF_gt_amp)**2))
    d_ha = np.sqrt(np.mean((HF_amp - HF_gt_amp)**2))
    
    # Phase
    LF_phase = np.angle(LF)
    LF_gt_phase = np.angle(LF_gt)
    HF_phase = np.angle(HF)
    HF_gt_phase = np.angle(HF_gt)
    
    d_lp = np.sqrt(np.mean((LF_phase - LF_gt_phase)**2))
    d_hp = np.sqrt(np.mean((HF_phase - HF_gt_phase)**2))
    
    # 7. Compute Total Loss
    if t <= T0:
        L_f = wl * (d_la + d_lp)
    else:
        L_f = wl * (d_la + d_lp) + wh * (d_ha + d_hp)
        
    return L_f
```

**Parameters**
*   $T_0$: Start iteration for high-frequency components. Not given in the sources.
*   $T$: End iteration. Not given in the sources.
*   $D_0$: Max range of the low-pass filter. Not given in the sources.
*   $D$: Max frequency spectrum range. Not given in the sources.
*   $w_l, w_h$: Training weights for low and high frequency discrepancies. Not given in the sources.

**Edge Cases and Pitfalls**
*   **Coordinate Origin:** The frequency calculations must use the image center $(H/2, W/2)$ as the origin $(0,0)$ for distance metrics. Using $(0,0)$ as the origin will result in incorrect filter masks [S1].
*   **Naive Regularization Artifacts:** Applying amplitude and phase discrepancies without frequency separation (naive regularization) restricts Gaussian densification and biases the model toward artifacts [S1].
*   **Precision:** The discrepancy metrics use square roots of mean squared errors. Ensure numerical stability when computing phase differences, as phase wrapping can cause discontinuities. The source uses standard Euclidean metric on phase values, which may require handling phase wrapping (e.g., using circular distance) if not handled by the library, though the source does not specify this guard [G].

### Scale Regularization
A sibling method that regularizes the scale of Gaussians. It is chosen when controlling the physical size of Gaussians is prioritized over frequency-domain constraints. See [Scale Regularization](9855-scale-regularization.md).

## Operating characteristics
*   **Time Complexity:** Adds $O(HW)$ overhead per iteration for FFT/IFFT and filter application. The dynamic filter calculation is $O(1)$ per iteration if precomputed or updated incrementally.
*   **Memory Complexity:** Requires storing $O(HW)$ complex arrays for $LF, HF, LF_{gt}, HF_{gt}$ and their amplitudes/phases.
*   **Performance:** Improves reconstruction quality in over-reconstruction regions by increasing pixel gradients and reduces artifacts compared to naive frequency regularization [S1].
*   **Strengths:** Enables coarse-to-fine densification; mitigates over-reconstruction.
*   **Limitations:** Requires careful tuning of $T_0, T, D_0, D, w_l, w_h$. Not given in the sources.
*   **When to Use:** When naive frequency regularization causes artifacts or restricted densification.
*   **When Not to Use:** When computational budget is extremely tight and the overhead of frequency domain operations is prohibitive.

## Background
Frequency Annealing was introduced in the FreGS (3D Gaussian Splatting with Progressive Frequency Regularization) paper [S1]. It addresses the limitations of naive frequency regularization in 3D Gaussian Splatting, which directly employs amplitude and phase discrepancies without distinguishing between low and high frequencies, leading to restricted densification and artifacts [S1]. The method builds on the observation that low frequencies relate to large-scale features and high frequencies to small-scale details, allowing for progressive regularization [S1].
