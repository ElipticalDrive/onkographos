# Spatially Collaged Coordinate Networks

Also called: SCONE, Spatially Collaged Fourier Bases

## Overview
Spatially Collaged Coordinate Networks (SCONE) is an Implicit Neural Representation (INR) architecture that overcomes the limitation of global Fourier basis functions by using learnable spatial masks to dispatch distinct Fourier bases into respective regions [S1]. Unlike parent methods like Fourier Feature Networks which apply global bases universally, SCONE iteratively generates spatial masks from previous-stage latent features to collaging Fourier features with different frequencies, resulting in a linear combination of collaged Random Fourier Features (RFFs) [S1]. This approach decouples geometry-dependent masks from Fourier features, allowing one RFF to be used at multiple regions with irregular shapes, thereby avoiding the artifacts (e.g., ringing, noise, poor saturation) common in SIREN, MFN, and WIRE [S1].

## How it works
**Inputs and Outputs:**
- Input: A set of data points $D = \{(x_i, y_i)\}_{i=1}^n$, where $x_i \in \mathbb{R}^d$ are coordinates (normalized to $[-1, 1]^d$) and $y_i \in \mathbb{R}^c$ are target features (e.g., RGB values, signed distance functions) [S1].
- Output: A continuous function $f_\theta: \mathbb{R}^d \to \mathbb{R}^c$ parameterized by $\theta$, representing the signal [S1].

**Data Structures:**
- Latent features: $z_l \in \mathbb{R}^{D_l}$, the output of layer $l$.
- Weights: $W_l \in \mathbb{R}^{D_l \times D_{l-1}}$ for linear transformations.
- Biases: $b_l \in \mathbb{R}^{D_l}$.
- Spatial Masks: $M_l \in \mathbb{R}^{D_l \times H \times W}$ (for 2D) or $\mathbb{R}^{D_l \times H \times W \times D}$ (for 3D), where $H, W, D$ are spatial dimensions. In the general formulation, $M_l$ is a spatially varying mask applied element-wise to the feature channel dimension [S1].
- Fourier Bases: Independent random matrices $B_l$ for each layer.

**Parameters:**
- $L$: Number of hidden layers. Typical value: 5 for SCONE/SIREN [S1].
- $D_l$: Hidden units. Typical value: 250 for SCONE (to align parameter count with 256-unit baselines) [S1].
- $\omega_l$: Frequency scaling parameter for the $l$-th layer's Fourier basis.
- $\omega_0$: Global hyperparameter controlling the frequency of the mask-generating process in the first layer [S1].
- Activation function $\sigma$: Used for mask generation. Default is $\sin^2$ due to output range $[0, 1]$ and periodicity. Robust to sigmoid, $\exp(-x^2)$, $\sin$, $\cos$, $\tanh$ (normalized to $[0,1]$ via min-max) [S1].
- Trainable scaler: Optional postfix '-L' indicating input multiplication by a trainable scalar before activation [S1].

**Algorithm:**
The network consists of $L$ layers. The process iteratively generates masks from latent features to collaging RFFs.

1. **Initialization and Input Mapping:**
   Normalize input coordinates $x$ to $[-1, 1]^d$.
   Compute the initial latent feature $z_0$ using a global frequency parameter $\omega_0$:
   $$ z_0 = \omega_0 (W_0 x) $$
   where $W_0$ is the weight matrix for the first layer [S1].

2. **Iterative Mask Generation and Collaging (for $l = 1$ to $L$):**
   a. **Generate Spatial Mask:**
      Compute the spatial mask $M_l$ for layer $l$ using the previous layer's latent feature $z_{l-1}$:
      $$ M_l = \sigma(W_{l-1} z_{l-1} + b_{l-1}) $$
      Here, $\sigma$ is the activation function (e.g., $\sin^2$). The weight matrix $W_{l-1}$ is initialized using SIREN's scheme (spectral normalization) [S1].
      
   b. **Generate Fourier Features:**
      Compute the Random Fourier Features $g_l(x; \omega_l)$ for layer $l$:
      $$ g_l(x; \omega_l) = \frac{\sin(\omega_l (B_l x))}{\sqrt{2}} $$
      where $B_l \sim U(-1/2, 1/2)$ is a random matrix sampled uniformly, resulting in $L$ independent Fourier bases [S1]. Note: Some sources describe Gaussian RFFs for FFNs, but SCONE specifically uses this sine-based RFF formulation for its bases [S1].

   c. **Spatial Collaging:**
      Apply the spatial mask $M_l$ to the Fourier features $g_l$ via element-wise multiplication. This creates "Fourier patches" where specific frequencies are active only in specific spatial regions:
      $$ z_l = M_l \odot g_l(x; \omega_l) $$
      where $\odot$ denotes element-wise multiplication. The mask $M_l$ effectively dispatches the global basis $g_l$ to its proper spatial positions [S1].

   d. **Linear Transformation (Implicit in Structure):**
      The output $z_l$ serves as the input for the next layer's mask generation. The final output is derived from the last layer's collaged features.

3. **Final Output:**
   The final output $y$ is a linear combination of the last layer's collaged features:
   $$ y = W_L z_{L-1} + b_L $$
   (Note: The source formula $z_L = W_L z_{L-1} + b_L$ implies the final layer is a standard linear readout from the collaged features of the previous stage, or potentially the collaging happens up to $L-1$ and $L$ is the readout. The text states "The final SCONE output is derived as a linear combination of the collaged RFFs" and gives $z_L = W_L z_{L-1} + b_L$. We interpret $z_{L-1}$ as the result of the collaging step at layer $L-1$, or that the collaging is part of the hidden layers and the final layer aggregates them. Based on "z_l = M_l * g_l... for l=1...L" and "z_L = W_L z_{L-1} + b_L", it seems the collaging happens for layers $1$ to $L-1$, and layer $L$ is the readout, or the collaging is applied and then passed through. Let's stick to the explicit formulas: $z_l$ is the collaged feature. The final output is $W_L z_{L-1} + b_L$ [S1]).

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SCONE(nn.Module):
    def __init__(self, input_dim, output_dim, hidden_dim=250, num_layers=5, 
                 omega_0=1.0, activation='sin2'):
        super(SCONE, self).__init__()
        self.input_dim = input_dim
        self.output_dim = output_dim
        self.num_layers = num_layers
        self.hidden_dim = hidden_dim
        self.omega_0 = omega_0
        
        # Initialize random Fourier bases for each layer
        # B_l ~ U(-1/2, 1/2)
        self.B = nn.ParameterList([
            nn.Parameter(torch.rand(input_dim, hidden_dim) * 1.0 - 0.5) 
            for _ in range(num_layers)
        ])
        
        # Weights and biases for mask generation and linear layers
        # Layer 0: z0 = omega_0 * (W0 * x)
        self.W0 = nn.Linear(input_dim, hidden_dim)
        
        # Layers 1 to L-1: Mask generation and collaging
        # M_l = sigma(W_{l-1} * z_{l-1} + b_{l-1})
        # z_l = M_l * g_l(x)
        self.W_mask = nn.ModuleList([
            nn.Linear(hidden_dim, hidden_dim) for _ in range(num_layers - 1)
        ])
        self.b_mask = nn.ModuleList([
            nn.Parameter(torch.zeros(hidden_dim)) for _ in range(num_layers - 1)
        ])
        
        # Final linear readout
        self.W_out = nn.Linear(hidden_dim, output_dim)
        
        # Activation function for mask
        self.activation = activation
        
        # Initialize weights using SIREN's scheme (spectral normalization)
        self._init_weights()

    def _init_weights(self):
        # SIREN initialization: W ~ U(-1/d, 1/d)
        for W in self.W_mask:
            bound = 1.0 / W.in_features
            nn.init.uniform_(W.weight, -bound, bound)
        nn.init.uniform_(self.W0.weight, -1.0/self.input_dim, 1.0/self.input_dim)
        nn.init.uniform_(self.W_out.weight, -1.0/self.hidden_dim, 1.0/self.hidden_dim)

    def get_mask(self, z_prev):
        # M = sigma(W * z_prev + b)
        x = self.W_mask(z_prev) # Note: W_mask is a list, need to index by layer
        # This pseudocode assumes a single mask generator for simplicity or iterative application.
        # In reality, each layer l has its own W_{l-1}.
        pass

    def forward(self, x):
        # Normalize input to [-1, 1]
        x = x * 2.0 - 1.0
        
        # Layer 0: Initial feature mapping
        z_prev = self.omega_0 * self.W0(x)
        
        for l in range(1, self.num_layers):
            # Generate spatial mask M_l
            # M_l = sigma(W_{l-1} * z_{l-1} + b_{l-1})
            mask_input = self.W_mask[l-1](z_prev) + self.b_mask[l-1]
            
            if self.activation == 'sin2':
                M_l = torch.sin(mask_input) ** 2
            elif self.activation == 'sigmoid':
                M_l = torch.sigmoid(mask_input)
            elif self.activation == 'tanh':
                # Normalize tanh output to [0, 1]
                M_l = 0.5 * torch.tanh(mask_input) + 0.5
            elif self.activation == 'exp':
                M_l = torch.exp(-mask_input ** 2)
            else:
                # Default to sin2
                M_l = torch.sin(mask_input) ** 2
                
            # Generate Fourier Features g_l(x)
            # g_l(x) = sin(omega_l * (B_l * x)) / sqrt(2)
            # Note: omega_l is not explicitly defined as a parameter in the notes, 
            # but B_l is sampled from U(-1/2, 1/2). 
            # The formula uses omega_l. If omega_l is not a learned parameter, 
            # it might be absorbed into B_l or set to 1. 
            # The notes say "omega_l as depicted in the bottom part of Fig 2", 
            # implying it might be a parameter. However, no initialization is given.
            # We assume omega_l is a scalar or vector. For simplicity, if not provided, 
            # we treat B_l as the scaled matrix. 
            # Let's assume omega_l is 1.0 or part of B_l scaling.
            # The source says: g_l(x; omega_l) = sin(omega_l (B_l x)) / sqrt(2)
            # and B_l ~ U(-1/2, 1/2).
            
            # Compute B_l * x
            # x shape: (batch, input_dim)
            # B_l shape: (input_dim, hidden_dim)
            # z_fourier shape: (batch, hidden_dim)
            z_fourier = torch.matmul(x, self.B[l-1]) # B_l is stored as (input, hidden)
            
            # Apply sine and scaling
            # Assuming omega_l is 1 for now if not specified as a parameter
            g_l = torch.sin(z_fourier) / torch.sqrt(torch.tensor(2.0))
            
            # Spatial Collaging: z_l = M_l * g_l
            # M_l shape: (batch, hidden_dim) ? 
            # The notes say M_l in R^{D_l x H x W}. 
            # This implies the mask is spatially varying.
            # In a standard MLP forward pass for INR, we process points individually.
            # If M_l is spatially varying, it must be computed per point.
            # However, the formula M_l = sigma(W_{l-1} z_{l-1} + b_{l-1}) 
            # suggests M_l depends on z_{l-1}, which depends on x.
            # So M_l is a function of x.
            
            # Element-wise multiplication
            z_l = M_l * g_l
            
            z_prev = z_l
            
        # Final output
        y = self.W_out(z_prev)
        return y
```

**Edge Cases and Pitfalls:**
- **Naive Layer Increase:** Naively increasing the number of layers in related methods like WIRE leads to inferior performance [S1].
- **Artifact Types:** Gaussian RFF exhibits high-frequency noise on flat surfaces; MFN displays severe ringing artifacts around edges; WIRE struggles with color saturation [S1].
- **Mask Initialization:** Weights $W_l$ must be initialized using SIREN's scheme to ensure proper learning dynamics [S1].
- **Activation Normalization:** For activations with infinite range (sin, cos, tanh), output must be normalized to $[0, 1]$ (e.g., $0.5 \tanh(\cdot) + 0.5$) to act as a valid soft mask [S1].

## Subtopics

### Random Binary Mask (RBM) Baseline
A baseline method that uses randomly generated binary masks $M_l \in \{0, 1\}^{D_l \times H \times W}$ instead of learnable soft masks to collage Fourier bases [S1]. The mask is randomly initialized for each layer and fixed during training [S1]. The formula is $z_l = M_l \odot W_{l-1} z_{l-1} \odot g_l(x; \omega_l)$ [S1]. RBM has much lower PSNR scores compared to SCONE and SIREN, justifying that SCONE's performance gain comes from the learnable nature of the spatial masks [S1].

## Operating characteristics
**Time and Memory Complexity:**
- Not explicitly given in the sources. However, SCONE uses standard MLP operations with element-wise masking, suggesting complexity similar to standard MLPs but with additional mask generation steps [S1].
- Memory usage is comparable to SIREN and other baselines when aligned for parameter count (~200k params) [S1].

**Measured Performance:**
- **Image Fitting:** SCONE improves image fitting PSNR by over 3dB compared to existing baselines (e.g., SIREN, MFN, WIRE) on the Kodak dataset [S1]. On the Siemens star test image, SCONE achieves 38.47dB PSNR, compared to 34.10dB for WIRE and 28.26dB for MFN [S1].
- **3D Shape Representation:** SCONE achieves a state-of-the-art performance of 98.81% Intersection over Union (IoU) and 0.0011 Chamfer Distance on the Stanford 3D scan dataset, surpassing the second-best method by 0.98% IoU and 63% Chamfer Distance [S1].
- **Video Representation:** On 512x512 video with 300 frames, SCONE achieves the best PSNR and ties SIREN in SSIM with smaller variance [S1].

**Strengths and Limitations:**
- **Strengths:** Superior reconstruction quality, ability to represent complex local structures without artifacts, robustness to different activation functions, faster convergence compared to MFN [S1].
- **Limitations:** Requires learnable masks, which adds a small computational overhead for mask generation. The method relies on the assumption that spatial collaging is beneficial, which may not hold for all signal types (though not explicitly stated as a limitation, the comparison with RBM shows the necessity of learnability) [S1].

**When to Use:**
- Use SCONE for image fitting, video representation, and 3D shape representation tasks where high-frequency details and local structures are important [S1].
- Avoid if computational resources are extremely limited and the signal is smooth and low-frequency, as the overhead of learnable masks may not be justified [G].

## Background
SCONE was introduced in the paper "Learning Spatially Collaged Fourier Bases for Implicit Neural Representation" published at the Thirty-Eighth AAAI Conference on Artificial Intelligence (AAAI-24) [S1]. It addresses the limitations of existing Implicit Neural Representations (INRs) like SIREN and Fourier Feature Networks, which use universal global basis functions that can lead to subpar performance and artifacts in local regions [S1]. The method builds on the concept of Fourier Feature Networks but introduces spatially aware combination of Fourier bases [S1].
