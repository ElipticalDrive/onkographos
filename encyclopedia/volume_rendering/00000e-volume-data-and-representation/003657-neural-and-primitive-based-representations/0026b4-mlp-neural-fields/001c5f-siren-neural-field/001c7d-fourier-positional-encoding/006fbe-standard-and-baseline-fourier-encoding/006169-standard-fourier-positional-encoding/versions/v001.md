# Standard Fourier Positional Encoding

Also called: Fourier Features, Implicit MLP for Feature Initialization, Mildenhall et al. Positional Encoding, Sinusoidal Positional Encoding

## Overview
Standard Fourier Positional Encoding maps low-dimensional input coordinates (typically 3D spatial positions) into a higher-dimensional space using interleaved sine and cosine functions at exponentially increasing frequencies. This technique addresses the spectral bias of Multi-Layer Perceptrons (MLPs), which naturally struggle to learn high-frequency details, by providing a richer, band-limited representation that facilitates the optimization of implicit neural fields [S1]. It differs from its siblings by using fixed, deterministic frequencies rather than learned or randomized ones, serving as a static feature initialization layer for subsequent neural processing.

## How it works
**Inputs and Outputs:**
- Input: A coordinate vector $\mathbf{x} \in \mathbb{R}^D$ (e.g., $D=3$ for spatial coordinates).
- Output: A feature vector $\mathbf{z} \in \mathbb{R}^{2LD}$, where $L$ is the number of frequency bands.

**Data Structures:**
- Frequencies: A set of $L$ scalar values $\{\gamma_0, \gamma_1, \dots, \gamma_{L-1}\}$.
- Feature Vector: A concatenated array of sine and cosine evaluations.

**Parameters:**
- $L$: Number of frequency bands. In the reference implementation, $L=10$ [S1].
- $\mathbf{B}$: The basis matrix or frequency vector. In the standard formulation, frequencies are typically generated as $\gamma_l = 2^l$ for $l=0,\dots,L-1$ [G]. The source specifies "ten frequencies" but does not explicitly define the base or scaling factor, implying the standard exponential progression [S1].

**Steps:**
1.  For each dimension $d$ of the input $\mathbf{x}$ and each frequency index $l \in \{0, \dots, L-1\}$:
    a. Compute the scaled coordinate: $s_{l,d} = \gamma_l \cdot x_d$.
    b. Compute the sine component: $u_{l,d} = \sin(s_{l,d})$.
    c. Compute the cosine component: $v_{l,d} = \cos(s_{l,d})$.
2.  Concatenate all components in the order: $[\sin(\gamma_0 \mathbf{x}), \cos(\gamma_0 \mathbf{x}), \sin(\gamma_1 \mathbf{x}), \cos(\gamma_1 \mathbf{x}), \dots, \sin(\gamma_{L-1} \mathbf{x}), \cos(\gamma_{L-1} \mathbf{x})]$.

**Pseudocode:**
```python
import math

def standard_fourier_encoding(x, num_frequencies):
    """
    Applies standard Fourier positional encoding to input coordinates.
    
    Args:
        x: List or array of coordinates (e.g., [x, y, z]).
        num_frequencies: Integer L, the number of frequency bands.
        
    Returns:
        List of floats representing the encoded feature vector.
    """
    encoded = []
    for l in range(num_frequencies):
        # Standard exponential frequency scaling: gamma_l = 2^l [G]
        gamma = math.pow(2, l)
        for coord in x:
            scaled = gamma * coord
            encoded.append(math.sin(scaled))
            encoded.append(math.cos(scaled))
    return encoded
```

**Edge Cases and Pitfalls:**
- Precision: High frequencies can lead to numerical instability if coordinates are large. Normalization of input coordinates to $[-1, 1]$ is recommended [G].
- Degenerate Input: If input coordinates are zero, all sine components are zero and cosine components are one, providing no gradient signal for the sine terms initially.

## Operating characteristics
- Time Complexity: $O(L \cdot D)$, where $L$ is the number of frequencies and $D$ is the input dimension.
- Memory Complexity: $O(L \cdot D)$ to store the output feature vector.
- Strengths: Simple to implement; effectively mitigates spectral bias in MLPs; deterministic.
- Limitations: Fixed frequencies may not adapt to specific scene complexities; requires careful frequency range selection to avoid aliasing or underfitting.
- When to use: As a standard initialization for implicit neural fields where high-frequency detail recovery is needed.
- When not to use: When adaptive frequency learning is preferred (see [Fourier Feature Networks](2765-fourier-feature-networks.md)) or when rotational invariance is critical without additional modifications.

## Background
Originating from the SIREN framework and popularized by Mildenhall et al. in the context of NeRF, this method uses sinusoidal functions to embed coordinates. It is commonly used in neural radiance fields and implicit surface representations to enable MLPs to capture fine geometric details. The reference implementation uses this encoding for corner coordinates in a shared feature grid architecture [S1].
