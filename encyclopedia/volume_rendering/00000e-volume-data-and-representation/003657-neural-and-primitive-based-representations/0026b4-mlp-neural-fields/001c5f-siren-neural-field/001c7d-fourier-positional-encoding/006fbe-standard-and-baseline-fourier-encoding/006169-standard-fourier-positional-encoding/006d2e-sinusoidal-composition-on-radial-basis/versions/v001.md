# Sinusoidal Composition on Radial Basis

Also called: Multi-channel RBF with Sinusoidal Transform, Sinusoidal RBF Composition

## Overview
Sinusoidal Composition on Radial Basis is a technique to extend a scalar radial basis function (RBF) into a multi-channel vector representation by composing it with a multi-frequency sinusoid, allowing each channel to linearly combine with a different frequency variant of the RBF [S1]. It differs from positional encoding and random Fourier features because the sine transform is applied to the radial basis values rather than the input coordinates, resulting in elliptical periodic patterns instead of linear ones [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Input point $\mathbf{x}$; set of neighbor RBF centers $U(\mathbf{x})$; for each neighbor $i \in U(\mathbf{x})$, the center $\mathbf{c}_i$, shape parameter $\Sigma_i$, and weight vector $\mathbf{w}_i \in \mathbb{R}^F$; global multiplier vector $\mathbf{m} \in \mathbb{R}^F$ and bias vector $\mathbf{b} \in \mathbb{R}^F$.
*   **Outputs:** Field value $\mathbf{g}_b(\mathbf{x}) \in \mathbb{R}^F$.

**Data Structures:**
*   $\mathbf{m}$: Fixed parameter vector of size $F$.
*   $\mathbf{b}$: Learnable parameter vector of size $F$, globally shared across all RBFs [S1].
*   $\mathbf{w}_i$: Weight vector for RBF $i$, size $F$ [S1].

**Steps:**
1.  **Compute Normalized Radial Basis:** For each neighbor $i \in U(\mathbf{x})$, compute the normalized radial basis value $\tilde{\varphi}(\mathbf{x}, \mathbf{c}_i, \Sigma_i)$ [S1]:
    $$ \tilde{\varphi}(\mathbf{x}, \mathbf{c}_i, \Sigma_i) = \frac{\varphi(\mathbf{x}, \mathbf{c}_i, \Sigma_i)}{\sum_{k \in U(\mathbf{x})} \varphi(\mathbf{x}, \mathbf{c}_k, \Sigma_k)} $$
    where $\varphi$ is the scalar radial basis function (e.g., Gaussian) [S1].

2.  **Determine Multiplier Vector $\mathbf{m}$:** Specify lowest frequency $m_l$ and highest frequency $m_h$. Generate $F$ elements by log-linearly dividing the range between $m_l$ and $m_h$ [S1].
    *   Typical values for 2D image experiments (DIV2K): $m_l = 2^{-3}, m_h = 2^{12}$ [S1].
    *   Typical values for SDF experiments: $m_l = 2^0, m_h = 2^3$ [S1].

3.  **Compute Multi-Channel Basis:** For each neighbor $i \in U(\mathbf{x})$, compute the multi-channel basis vector $\boldsymbol{\varphi}(\mathbf{x}, \mathbf{c}_i, \Sigma_i) \in \mathbb{R}^F$ [S1]:
    $$ \boldsymbol{\varphi}(\mathbf{x}, \mathbf{c}_i, \Sigma_i) = \sin(\tilde{\varphi}(\mathbf{x}, \mathbf{c}_i, \Sigma_i) \cdot \mathbf{m} + \mathbf{b}) $$
    Here, $\cdot$ denotes scalar multiplication of the scalar $\tilde{\varphi}$ with vector $\mathbf{m}$, and $\sin$ is applied element-wise [S1].

4.  **Compute Field Value:** Sum the Hadamard product of the multi-channel basis and the weight vector for all neighbors [S1]:
    $$ \mathbf{g}_b(\mathbf{x}) = \sum_{i \in U(\mathbf{x})} \boldsymbol{\varphi}(\mathbf{x}, \mathbf{c}_i, \Sigma_i) \odot \mathbf{w}_i $$
    where $\odot$ is the Hadamard (element-wise) product [S1].

**Pseudocode:**
```python
import numpy as np

def compute_sin_composition_rbf(x, neighbors, centers, shapes, weights, m, b, phi_func):
    """
    Compute field value using Sinusoidal Composition on Radial Basis.
    
    Args:
        x: Input point (scalar or vector, depending on phi_func).
        neighbors: List of indices i in U(x).
        centers: Array of centers c_i for neighbors.
        shapes: Array of shape parameters Sigma_i for neighbors.
        weights: Array of weight vectors w_i for neighbors, shape (N, F).
        m: Global multiplier vector, shape (F,). Fixed.
        b: Global bias vector, shape (F,). Learnable.
        phi_func: Function phi(x, c, Sigma) returning scalar RBF value.
        
    Returns:
        g_b: Field value vector, shape (F,).
    """
    F = m.shape[0]
    g_b = np.zeros(F)
    
    # Step 1: Compute normalized radial basis values
    phi_values = np.array([phi_func(x, centers[i], shapes[i]) for i in neighbors])
    phi_sum = np.sum(phi_values)
    
    # Avoid division by zero
    if phi_sum == 0:
        return g_b
        
    tilde_phi = phi_values / phi_sum
    
    # Step 3: Compute multi-channel basis for each neighbor
    # tilde_phi is scalar per neighbor, m and b are vectors
    # Result: basis_vectors shape (N, F)
    basis_vectors = np.sin(tilde_phi[:, np.newaxis] * m + b)
    
    # Step 4: Sum Hadamard product of basis and weights
    # weights shape (N, F), basis_vectors shape (N, F)
    weighted_bases = basis_vectors * weights
    g_b = np.sum(weighted_bases, axis=0)
    
    return g_b
```

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If $\sum_{k \in U(\mathbf{x})} \varphi(\mathbf{x}, \mathbf{c}_k, \Sigma_k) = 0$, normalization is undefined. A guard (e.g., returning zero vector) is required [G].
*   **Precision:** The log-linear spacing of $\mathbf{m}$ can result in very large frequency values ($m_h$), potentially causing numerical instability in the sine argument if $\tilde{\varphi}$ is not well-scaled [S1].
*   **Boundary Conditions:** The method relies on neighbor set $U(\mathbf{x})$. If $U(\mathbf{x})$ is empty, the field value is zero [G].

## Subtopics

### Sinusoidal Composition on Feature Vector
Application of sinusoidal composition to the output features $\mathbf{h}_0$ of the first fully-connected layer in the MLP $g_m$, using a residual connection [S1]. It differs from sinusoid activation because it produces features of a wide frequency range with one sine transform and does not require specialized initialization for FC layers [S1].
*   **Definition:** Apply sine transform to Hadamard product of $\mathbf{h}_0$ and $\mathbf{m}_0$, then add $\mathbf{h}_0$ as residual [S1].
*   **Formula:** $\mathbf{f}_0 = \sin(\mathbf{h}_0 \odot \mathbf{m}_0) + \mathbf{h}_0$, where $\mathbf{h}_0, \mathbf{m}_0, \mathbf{f}_0 \in \mathbb{R}^{F_0}$ and $\odot$ is Hadamard product [S1].
*   **Parameters:** $\mathbf{m}_0$ is set by specifying lowest frequency $m_{l0}$ and highest frequency $m_{h0}$ [S1].
    *   2D image experiments (DIV2K): $m_{l0} = 1, m_{h0} = 1000$ [S1].
    *   SDF experiments: $m_{l0} = 30, m_{h0} = 300$ [S1].
*   **Pseudocode:**
```python
def compute_sin_composition_feature(h0, m0):
    """
    Compute sinusoidal composition on feature vector.
    
    Args:
        h0: Input feature vector from first FC layer, shape (F0,).
        m0: Multiplier vector, shape (F0,).
        
    Returns:
        f0: Output feature vector, shape (F0,).
    """
    return np.sin(h0 * m0) + h0
```

## Operating characteristics
*   **Time Complexity:** Linear in the number of neighbors $|U(\mathbf{x})|$ and feature dimension $F$ [S1].
*   **Memory Complexity:** Proportional to $F$ for storing $\mathbf{m}$ and $\mathbf{b}$, plus storage for neighbor weights $\mathbf{w}_i$ [S1].
*   **Performance:** Achieves higher performance under radial basis framework compared to positional encoding or sinusoid activation [S1].
*   **Strengths:** Increases representation ability by encoding $F$ bases per RBF pair $(\mathbf{c}_i, \Sigma_i)$ [S1]. Produces elliptical periodic patterns [S1].
*   **Limitations:** Improvement is small in NeRF tasks, so it is not applied there [S1].
*   **When to Use:** When high-frequency representation is needed within an RBF-based neural field, particularly for image reconstruction or SDFs [S1].
*   **When Not to Use:** In NeRF tasks where improvement is negligible [S1].

## Background
Originated in "NeuRBF: A Neural Fields Representation with Adaptive Radial Basis Functions" (2023) [S1]. It is used in neural field representations for image reconstruction (DIV2K dataset) and Signed Distance Function (SDF) modeling [S1]. The technique is related to Gabor filters but produces elliptical rather than linear patterns [S1].
