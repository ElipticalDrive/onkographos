# Standard Fourier Positional Encoding

Also called: Fourier Features, Implicit MLP for Feature Initialization, Mildenhall et al. Positional Encoding, Sinusoidal Positional Encoding

## Overview
Standard Fourier Positional Encoding maps input coordinates to a higher-dimensional feature space using deterministic sinusoidal basis functions, serving as a static initialization layer for subsequent neural processing [G]. It builds on the shared principles of the Fourier Encoding family [Standard and Baseline Fourier Encoding](21924-standard-and-baseline-fourier-encoding.md) and differs from [Fourier Feature Networks](2765-fourier-feature-networks.md) by using fixed frequencies rather than learned ones [G].

## How it works
**Inputs and Outputs:**
- Input: A coordinate vector $\mathbf{x} \in \mathbb{R}^D$.
- Output: A feature vector $\mathbf{z} \in \mathbb{R}^{2LD}$, where $L$ is the number of frequency bands.

**Data Structures:**
- Frequencies: A set of $L$ scalar values $\{\gamma_0, \gamma_1, \dots, \gamma_{L-1}\}$.
- Feature Vector: A concatenated array of sine and cosine evaluations.

**Numbered Steps:**
1. For each dimension $d$ of the input $\mathbf{x}$ and each frequency index $l \in \{0, \dots, L-1\}$:
   a. Compute the scaled coordinate: $s_{l,d} = \gamma_l \cdot x_d$.
   b. Compute the sine component: $u_{l,d} = \sin(s_{l,d})$.
   c. Compute the cosine component: $v_{l,d} = \cos(s_{l,d})$.
2. Concatenate all components in the order: $[\sin(\gamma_0 \mathbf{x}), \cos(\gamma_0 \mathbf{x}), \sin(\gamma_1 \mathbf{x}), \cos(\gamma_1 \mathbf{x}), \dots, \sin(\gamma_{L-1} \mathbf{x}), \cos(\gamma_{L-1} \mathbf{x})]$.

**Formulas:**
The mapping for a single dimension $x_d$ and frequency index $l$ is defined as:
$$ u_{l,d} = \sin(\gamma_l \cdot x_d) $$
$$ v_{l,d} = \cos(\gamma_l \cdot x_d) $$
The final feature vector is constructed by concatenating these components [G].

**Parameters:**
- $L$: Number of frequency bands. In the reference implementation, $L=10$ is applied to corner coordinates [S1].
- $\{\gamma_l\}$: Frequency values. The generation rule is not specified in the sources [S1].

**Pseudocode:**
```python
import math

def standard_fourier_encoding(x, num_frequencies):
    """
    Applies standard Fourier positional encoding to input coordinates.
    
    Args:
        x: List or array of coordinates (e.g., [x, y, z]).
        num_frequencies: Integer L, the number of frequency bands.
        
    Returns:
        List of floats representing the encoded feature vector.
    """
    encoded = []
    # Frequency generation rule not given in the sources [G]
    frequencies = [math.pow(2, l) for l in range(num_frequencies)]
    for l in range(num_frequencies):
        gamma = frequencies[l]
        for coord in x:
            scaled = gamma * coord
            encoded.append(math.sin(scaled))
            encoded.append(math.cos(scaled))
    return encoded
```

**Edge Cases and Pitfalls:**
- Precision: High frequencies can lead to numerical instability if coordinates are large. Normalization of input coordinates to $[-1, 1]$ is recommended [G].
- Degenerate Input: If input coordinates are zero, all sine components are zero and cosine components are one, providing no gradient signal for the sine terms initially [G].

## Background
The method is used in the NeRFLight architecture to encode corner coordinates before passing them through an MLP consisting of one input layer, eight hidden layers of 512 neurons with ReLU activation, and an output layer of 32 neurons without activation [S1].
