# Intrinsic Neural Fields Training Pipeline

Also called: Intrinsic Neural Fields, Laplace-Beltrami Eigenfunction Embedding

## Overview
The Intrinsic Neural Fields Training Pipeline learns functions on discrete 2-manifolds by embedding surface points into the first $d$ eigenfunctions of the Laplace-Beltrami operator and predicting properties (e.g., RGB color) via a neural network [S1]. It differs from [Fourier Positional Encoding](1267-fourier-positional-encoding.md) by embedding points into the eigenfunctions of the Laplace-Beltrami operator rather than fixed-frequency trigonometric functions, adapting to the manifold's intrinsic geometry [S1].

## How it works
**Inputs:**
- A discrete 2-manifold represented as a triangle mesh or point cloud [S1].
- Ground-truth data associated with surface points (e.g., RGB color values) [S1].
- A set of training rays sampled from the entire training split [S1].

**Outputs:**
- A trained neural network $F_\theta$ that maps intrinsic coordinates to output properties [S1].

**Data Structures:**
- **Eigenfunctions:** A matrix or set of vectors representing the first $d$ eigenfunctions of the Laplace-Beltrami operator [S1]. For a mesh with $V$ vertices, this is typically stored as a $V \times d$ matrix where each row corresponds to a vertex and each column to an eigenfunction [S1].
- **Mesh Topology:** Adjacency information (vertices, edges, faces) required for interpolation and Laplacian computation [S1].
- **Barycentric Coordinates:** Weights $(\lambda_1, \lambda_2, \lambda_3)$ used to interpolate eigenfunctions within a triangle face [S1].

**Steps:**

1.  **Precompute Eigenfunctions:**
    Solve the generalized eigenvalue problem for the first $d$ eigenvalues of the Laplace-Beltrami operator using the robust Laplacian formulation [S1].
    - If the input is a triangle mesh, compute the eigenfunctions directly on the mesh vertices [S1].
    - If the input is a point cloud, either create a local triangulation around each point to enable normal ray-mesh intersection or use the robust Laplacian which natively supports point clouds [S1].

2.  **Ray Sampling:**
    During training, randomly sample preprocessed rays from the entire training split [S1].

3.  **Point Embedding:**
    For each sampled point $p$ on the surface:
    - If $p$ is a mesh vertex, retrieve its precomputed eigenfunction values directly [S1].
    - If $p$ is not a vertex, identify the triangle face $(v_i, v_j, v_k)$ spanning $p$ [S1]. Compute the barycentric coordinates of $p$ with respect to this face [S1]. Linearly interpolate the eigenfunctions of the vertices $v_i, v_j, v_k$ using these barycentric coordinates to obtain the intrinsic embedding of $p$ [S1].

4.  **View Direction Encoding (Optional):**
    If the model is view-dependent, embed the unit viewing direction $\mathbf{d} \in \mathbb{R}^3$ using sine/cosine positional encoding [S1]. This step builds on [Fourier Positional Encoding](1267-fourier-positional-encoding.md).

5.  **Network Forward Pass:**
    Feed the intrinsic embedding of $p$ (and the encoded viewing direction $\mathbf{d}$ if applicable) into the neural network $F_\theta$ to predict the property value (e.g., RGB color) [S1].

6.  **Loss Computation:**
    Compute the mean L1 loss over the batch of sampled rays $\mathcal{B}$:
    $$
    L_1 = \frac{1}{|\mathcal{B}|} \sum_{p \in \mathcal{B}} \| F_\theta(p) - c_{gt}(p) \|_1
    $$
    where $F_\theta(p)$ is the predicted value, $c_{gt}(p)$ is the ground-truth RGB color, and $|\mathcal{B}|$ is the number of rays in the batch [S1].

7.  **Optimization:**
    Update the network parameters $\theta$ using the Adam optimizer [S1].

class Linear:
    def __init__(self, in_features, out_features):
        self.weight = np.random.randn(in_features, out_features) * 0.02

        return x @ self.weight + self.bias

        self.fc2 = Linear(hidden_dim, output_dim)

        x = np.maximum(0, x @ self.fc1.weight + self.fc1.bias)

**Parameters:**

- **Optimizer:** Adam with $\beta_1 = 0.9$, $\beta_2 = 0.999$, $\epsilon = 10^{-8}$ [S1].

**Edge Cases and Pitfalls:**
- **Non-vertex points:** Points sampled on the surface may not coincide with mesh vertices [S1]. Linear interpolation using barycentric coordinates is required to obtain the correct eigenfunction embedding [S1].
- **Point Clouds:** If the input is a point cloud, local triangulation must be created around each point to support ray-mesh intersection, or the robust Laplacian must be used which natively supports point clouds [S1].
- **UV Seams:** When exporting the learned field to a UV texture map, small seams may appear [S1]. These are artifacts of the inverse UV lookup conversion process and not discontinuities in the intrinsic neural field itself [S1].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Adapts to the intrinsic geometry of the manifold [S1].
- **Limitations:** Requires precomputation of eigenfunctions [S1]. The method is specific to 2-manifolds [S1].
- **When to use:** High-resolution intrinsic neural texture fields on human models and other 2-manifolds for view-dependent rendering [S1].

## Background
The method was introduced in [S1]. It builds upon spectral geometry concepts for shape analysis, such as the Wave Kernel Signature [S1, Ref 1]. The approach combines this geometric prior with modern neural network architectures for rendering [S1].
