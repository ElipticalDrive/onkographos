# Positional Encoding

Also called: Fourier Features, Sinusoidal Positional Encoding

## Overview
Positional Encoding is an input encoding method for spatial coordinates in neural fields, originally introduced in NeRF [S1, S2]. It maps low-dimensional coordinates into a high-dimensional space using sine and cosine functions with exponentially increasing frequencies, enabling MLPs to learn high-frequency details [S1, S2]. It is distinct from its sibling [Expected Sine/Cosine Encoding](12852-expected-sine-cosine-encoding.md) by its specific use of fixed, exponentially spaced frequencies rather than learned or expected statistical properties.

## How it works
**Inputs:** Spatial coordinates $\mathbf{x} \in \mathbb{R}^D$ (typically $D=3$ for volume rendering).
**Outputs:** Encoded vector $\gamma(\mathbf{x}) \in \mathbb{R}^{2DL}$.

**Data Structures:**
The output is a concatenated vector. For each dimension $d$ of $\mathbf{x}$ and each frequency band $l$, two values are computed.

**Parameters:**
- $L$: Number of frequency bands. Default value is 6 [S1].
- $\omega$: Scaling factor. Default value is 1.5 for single-category, category-agnostic ShapeNet experiments and DTU experiments [S1]. Value is 2.0 for multi-object experiments [S1].
- Base: The exponent base is fixed at 2 [S1].

**Formula:**
The positional encoding $\gamma(\mathbf{x})$ is defined as:
$$
\gamma(\mathbf{x}) = \begin{pmatrix} \sin(2^0 \omega \mathbf{x}) \\ \cos(2^0 \omega \mathbf{x}) \\ \sin(2^1 \omega \mathbf{x}) \\ \cos(2^1 \omega \mathbf{x}) \\ \vdots \\ \sin(2^{L-1} \omega \mathbf{x}) \\ \cos(2^{L-1} \omega \mathbf{x}) \end{pmatrix}
$$
where the operations are applied element-wise to $\mathbf{x}$ [S1].

**Steps:**
1. Initialize an empty output vector $\mathbf{v}$.
2. For each dimension $d$ from $0$ to $D-1$:
   a. For each frequency band $l$ from $0$ to $L-1$:
      i. Compute frequency $f = 2^l \cdot \omega$.
      ii. Append $\sin(f \cdot \mathbf{x}_d)$ to $\mathbf{v}$.
      iii. Append $\cos(f \cdot \mathbf{x}_d)$ to $\mathbf{v}$.
3. Concatenate the original coordinates $\mathbf{x}$ to the end of $\mathbf{v}$ [S1].
4. Return $\mathbf{v}$.

**Pitfalls:**
- Positional encoding is NOT applied to view directions [S1].
- The scaling factor $\omega$ is set "rather arbitrarily" in the source; tuning the exponent base is possible but 2 is standard [S1].

```python
import math

def positional_encoding(x, L=6, omega=1.5):
    """
    Computes the positional encoding for spatial coordinates x.
    
    Args:
        x: List or array of spatial coordinates (e.g., [x, y, z]).
        L: Number of frequency bands (default 6).
        omega: Scaling factor (default 1.5).
        
    Returns:
        Concatenated vector of original coordinates and encoded frequencies.
    """
    encoded = []
    # Iterate over each dimension of the input coordinate
    for coord in x:
        # Iterate over each frequency band
        for l in range(L):
            # Calculate frequency: 2^l * omega
            freq = (2 ** l) * omega
            # Append sine and cosine components
            encoded.append(math.sin(freq * coord))
            encoded.append(math.cos(freq * coord))
    
    # Concatenate original coordinates along the encoding
    # Note: The source specifies concatenating input coordinates along the encoding [S1]
    # This implies the original x values are appended to the end of the encoded vector.
    result = encoded + list(x)
    return result
```

## Subtopics

### [Expected Sine/Cosine Encoding](12852-expected-sine-cosine-encoding.md)
Uses expected statistical properties of sine/cosine bases rather than fixed exponential spacing. Choose when statistical optimality is preferred over fixed spectral coverage.

## Operating characteristics
- **Time Complexity:** $O(D \cdot L)$, where $D$ is input dimension and $L$ is number of bands.
- **Memory Complexity:** $O(D \cdot L)$ for the output vector.
- **Strengths:** Enables MLPs to capture high-frequency details by lifting inputs to a space where high frequencies are linearly separable [S1].
- **Limitations:** The choice of $\omega$ is somewhat arbitrary and dataset-dependent [S1]. View directions are not encoded, which may limit directional modeling if not handled separately [S1].
- **When to use:** When training neural fields (SDF, DDF, NeRF) that require high-frequency spatial detail reconstruction [S1, S2].

## Background
Positional Encoding was introduced in NeRF (Neural Radiance Fields) [S1]. It is used as an input encoding method for SDF and DDF models in subsequent works like FIRe [S2]. The method leverages the observation that MLPs struggle with high-frequency functions, and positional encoding helps mitigate this by providing a richer input representation [S1].
