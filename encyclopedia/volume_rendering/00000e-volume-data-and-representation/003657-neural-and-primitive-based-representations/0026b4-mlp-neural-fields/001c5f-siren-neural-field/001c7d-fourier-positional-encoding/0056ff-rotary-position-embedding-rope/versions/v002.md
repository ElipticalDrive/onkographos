# Rotary Position Embedding (RoPE)

Also called: RoPE2D, Rotary Position Embedding 2D, Rotary Positional Embedding, cuRoPE2D

## Overview
Rotary Position Embedding (RoPE) is a positional encoding method that modifies token representations using rotational transformations [G]. This article describes the 2D variant (RoPE2D), which applies 1D RoPE independently to split feature halves based on 2D spatial positions (y and x) [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input tokens: Tensor of shape `[batch_size, nheads, ntokens, dim]` [S1, unofficial].
- Input positions: Tensor of shape `[batch_size, ntokens, 2]`, where the last dimension contains `(y, x)` coordinates [S1, unofficial].
- Output: Transformed tokens of the same shape as input tokens.

**Data Structures and Parameters:**
- `dim`: Feature dimension. Must be a multiple of two for the chunk operation to work correctly [S1, unofficial].
- `base`: Base frequency for the inverse frequency calculation. Default value: 100.0 [S1, unofficial].
- `inv_freq`: Precomputed tensor of shape `[dim // 2]` [S1, unofficial].

**Steps:**

1.  **Calculate inverse frequencies:** `inv_freq = 1.0 / (base ** (torch.arange(0, D, 2).float() / D))` [S1, unofficial].
2.  **Calculate frequencies:** `freqs = einsum('i,j->ij', t, inv_freq)`, where `t` is the array of position indices (e.g., `arange(seq_len)`) [S1, unofficial].
3.  **Concatenate `freqs` with itself along the last dimension to double the dimensionality:** `freqs = cat(freqs, freqs, dim=-1)` [S1, unofficial].
4.  **Compute cosine and sine of frequencies:** `cos = freqs.cos()`, `sin = freqs.sin()` [S1, unofficial].
5.  **Define a helper function `rotate_half(x)`** that splits the input tensor `x` along the last dimension into two equal halves, $x_1$ and $x_2$, and returns `cat(-x2, x1)` [S1, unofficial].
6.  **Apply 1D RoPE to tokens using position indices:** `encoded = (tokens * cos) + (rotate_half(tokens) * sin)` [S1, unofficial].
7.  **In the forward pass, split tokens into y and x halves** along the feature dimension (`dim=-1`) [S1, unofficial].
8.  **Apply 1D RoPE to y** using `positions[:,:,0]` (y-positions) and **to x** using `positions[:,:,1]` (x-positions) [S1, unofficial].
9.  **Concatenate the transformed y and x halves** back together along the feature dimension [S1, unofficial].

**Pseudocode:**

```python
import torch

def precompute_freqs(base: float, dim: int, positions: torch.Tensor) -> tuple[torch.Tensor, torch.Tensor]:
    """Precompute cosine and sine frequencies for given positions."""
    # Step 1: Calculate inverse frequencies
    inv_freq = 1.0 / (base ** (torch.arange(0, dim, 2).float() / dim))
    # Step 2: Calculate frequencies using outer product
    # positions shape: [batch_size, ntokens]
    # inv_freq shape: [dim // 2]
    freqs = torch.einsum('ij,k->ijk', positions, inv_freq)
    # Step 3: Concatenate freqs with itself along the last dimension
    freqs_full = torch.cat((freqs, freqs), dim=-1)
    # Step 4: Compute cosine and sine
    cos = freqs_full.cos()
    sin = freqs_full.sin()
    return cos, sin

def rotate_half(x: torch.Tensor) -> torch.Tensor:
    """Split x into two halves along the last dimension and return cat(-x2, x1)."""
    x1, x2 = x.chunk(2, dim=-1)
    return torch.cat((-x2, x1), dim=-1)

def apply_rope2d(tokens: torch.Tensor, positions: torch.Tensor, base: float = 100.0) -> torch.Tensor:
    """Apply 2D Rotary Position Embedding."""
    # tokens shape: [batch_size, nheads, ntokens, dim]
    # positions shape: [batch_size, ntokens, 2]
    
    # Step 7: Split tokens into y and x halves along the feature dimension
    tokens_y, tokens_x = tokens.chunk(2, dim=-1)
    
    # Extract y and x positions
    y_pos = positions[:, :, 0] # [batch_size, ntokens]
    x_pos = positions[:, :, 1] # [batch_size, ntokens]
    
    # Precompute frequencies for y and x
    cos_y, sin_y = precompute_freqs(base, tokens_y.shape[-1] * 2, y_pos)
    cos_x, sin_x = precompute_freqs(base, tokens_x.shape[-1] * 2, x_pos)
    
    # Reshape for broadcasting: [batch_size, ntokens, dim] -> [batch_size, 1, ntokens, dim]
    cos_y = cos_y.unsqueeze(1)
    sin_y = sin_y.unsqueeze(1)
    cos_x = cos_x.unsqueeze(1)
    sin_x = sin_x.unsqueeze(1)
    
    # Slice to match the half-dimension of tokens_y and tokens_x
    half_dim = tokens_y.shape[-1]
    cos_y_half = cos_y[:, :, :, :half_dim]
    sin_y_half = sin_y[:, :, :, :half_dim]
    cos_x_half = cos_x[:, :, :, :half_dim]
    sin_x_half = sin_x[:, :, :, :half_dim]
    
    # Step 6: Apply 1D RoPE to y using y-positions
    encoded_y = (tokens_y * cos_y_half) + (rotate_half(tokens_y) * sin_y_half)
    # Step 6: Apply 1D RoPE to x using x-positions
    encoded_x = (tokens_x * cos_x_half) + (rotate_half(tokens_x) * sin_x_half)
    
    # Step 9: Concatenate the transformed halves back together
    encoded_tokens = torch.cat((encoded_y, encoded_x), dim=-1)
    return encoded_tokens
```

**Edge Cases and Pitfalls:**
- The feature dimension `dim` must be a multiple of two [S1, unofficial].
- Positions must be 3D with shape `[Batch, Seq, 2]` [S1, unofficial].
- Precision issues may arise with very large position indices or very small/large base values due to floating-point limitations in trigonometric functions [G].

## Operating characteristics
- **Time Complexity:** $O(N \cdot D)$, where $N$ is the number of tokens and $D$ is the feature dimension. The computation involves element-wise multiplication and addition [G].
- **Memory Complexity:** $O(N \cdot D)$ for storing the frequency tensors [G].
- **Strengths:** Provides relative positional information naturally through rotation, which is beneficial for tasks requiring understanding of relative distances [G]. It is differentiable and integrates seamlessly with attention mechanisms [G].
- **Limitations:** Requires even feature dimensions [S1, unofficial]. Performance may degrade if the position indices are out of the range seen during training [G]. Not inherently designed for 3D or higher-dimensional spatial data without extension [G].
