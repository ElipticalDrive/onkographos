# Fourier Positional Encoding

Also called: Fourier Feature Embedding, Fourier Feature Mappings, Fourier Feature Positional Encoding, Fourier Features, Sinusoidal Embedding, Sinusoidal Encoding, Sinusoidal Positional Encoding

## Overview
Fourier Positional Encoding (FPE) maps low-dimensional input coordinates (such as 3D positions or 2D viewing directions) into a higher-dimensional space using a multi-resolution sequence of sine and cosine functions at exponentially increasing frequencies [S1][S2, S3, unofficial]. It solves the problem of spectral bias in standard Multi-Layer Perceptrons (MLPs), which inherently prioritize learning low-frequency, smooth signals and fail to capture high-frequency scene details [S7]. Unlike [Uncertainty-Aware SIREN](10449-uncertainty-aware-siren.md), which relies on learned sine activations within the network layers, FPE uses fixed (or pre-optimized) external mappings to lift inputs, enabling the MLP to represent fine spatial variations more effectively [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A tensor of coordinates $x \in \mathbb{R}^d$ (typically $d=3$ for position, $d=2$ or $3$ for direction).
- **Output:** A tensor of encoded features $z \in \mathbb{R}^{d_{out}}$, where $d_{out}$ depends on the number of frequency bands and whether the original input is included.

**Data Structures:**
- **Frequency Bands:** A 1D array of frequencies $f_k$.
- **Embedding Tensor:** A tensor of shape `(*batch, d_out)` storing the concatenated sine and cosine values.

**Parameters:**
- `input_dims` ($d$): Dimensionality of the input (e.g., 3).
- `num_freqs` ($N$ or $L$): Number of frequency bands (octaves). Default is 10 for position, 4 for direction [S9, S12, unofficial].
- `log_sampling` (bool): If True, frequencies are spaced logarithmically ($2^k$); if False, linearly. Default is True [S4, S5, unofficial].
- `include_input` (bool): If True, the original input $x$ is concatenated to the output. Default is True [S5, S8, unofficial].
- `omega0` (float): A scaling factor for frequencies. Default is 1.0 [S4, S8, unofficial].
- `max_freq_log2` (float): The maximum frequency exponent. If `log_sampling` is True, the max frequency is $2^{\text{max\_freq\_log2}}$ [S6, S15, unofficial].

**Formulas:**
The encoding for a scalar input $p$ with $L$ frequency bands is defined as [S1][S9, S11, unofficial]:
$$
\gamma(p) = (\sin(2^0 \pi p), \cos(2^0 \pi p), \dots, \sin(2^{L-1} \pi p), \cos(2^{L-1} \pi p))
$$
If `include_input` is True, the output is [S12, S18, unofficial]:
$$
\gamma_{total}(p) = (p, \sin(2^0 \pi p), \cos(2^0 \pi p), \dots, \sin(2^{L-1} \pi p), \cos(2^{L-1} \pi p))
$$
The output dimension $d_{out}$ is [S4, S8, S20, unofficial]:
$$
d_{out} = d \times (2 \times N + \text{include\_input})
$$
where $N$ is the number of frequency bands.

**Steps:**
1. **Generate Frequencies:**
   - If `log_sampling` is True: $f_k = 2^k$ for $k \in [0, N-1]$ [S4, S8, unofficial].
   - If `log_sampling` is False: $f_k$ is linearly spaced between $1.0$ and $2^{N-1}$ [S4, S8, unofficial].
   - Scale frequencies by `omega0` and $\pi$ (if not included in the base generation) [S8, S15, unofficial]. Note: Some implementations use $2\pi f_k$ [S1][S15, unofficial], others use $f_k$ directly where $f_k$ includes the $2\pi$ or $\pi$ factor [S2, S8, unofficial]. The standard NeRF implementation uses $2^k$ as the multiplier for the coordinate [S2, S17, unofficial]. We follow the standard NeRF definition where the argument is $2^k \pi x$ or $2^k x$ depending on normalization. The most common form in code is $2^k \pi x$ [S1][S9, unofficial] or $2^k x$ [S2, S8, unofficial]. We define the frequency bands as $B = [2^0, 2^1, \dots, 2^{N-1}]$. The argument to sin/cos is $x \cdot B \cdot \pi$ (if using $\pi$) or $x \cdot B$ (if $\pi$ is absorbed or not used). The sources show both. We will use the explicit $\pi$ form as it is mathematically standard for "Fourier" features [S1][S9, unofficial][S13], but note that code often omits $\pi$ if the input is normalized to $[0,1]$ or if $\pi$ is part of the frequency definition [S2, S8, unofficial]. To be precise: $f_k = 2^k$. The embedding is $\sin(2\pi f_k x)$ and $\cos(2\pi f_k x)$ [S1][S15, unofficial] OR $\sin(f_k x)$ and $\cos(f_k x)$ [S2, S8, unofficial]. The difference is a scaling of the input. We will use the form $\sin(2^k \pi x)$ as it appears in the original NeRF equation [S1][S17, unofficial] and is cited as the standard [S9, unofficial].

2. **Scale and Reshape:**
   - For each dimension $i$ of input $x$, compute the scaled values $x_i \cdot f_k$ for all $k$.
   - Reshape to allow broadcasting across batch dimensions.

3. **Apply Sinusoids:**
   - Compute $\sin(x_i \cdot f_k \cdot \pi)$ and $\cos(x_i \cdot f_k \cdot \pi)$ for each frequency $k$ and dimension $i$.

4. **Concatenate:**
   - Concatenate all sine and cosine terms along the last dimension.
   - If `include_input` is True, concatenate the original input $x$ to the result.

**Pseudocode:**
```python
import torch
import math

def fourier_positional_encoding(x, num_freqs=10, include_input=True, log_sampling=True, omega0=1.0):
    """
    x: Tensor of shape (*, d) containing input coordinates.
    num_freqs: Number of frequency bands (L).
    include_input: Whether to concatenate original x.
    log_sampling: Whether to use exponential frequency spacing.
    omega0: Frequency scaling factor.
    """
    d = x.shape[-1]
    
    # 1. Generate frequencies
    if log_sampling:
        # Powers of 2: 2^0, 2^1, ..., 2^(num_freqs-1)
        freq_bands = 2.0 ** torch.arange(num_freqs, device=x.device, dtype=x.dtype)
    else:
        # Linear spacing from 1.0 to 2^(num_freqs-1)
        freq_bands = torch.linspace(1.0, 2.0 ** (num_freqs - 1), num_freqs, device=x.device, dtype=x.dtype)
        
    # Scale by omega0 and pi (standard NeRF uses 2^k * pi * x)
    # Note: Some implementations absorb pi into the frequency or omit it.
    # We follow the explicit formula from [S1][S9, unofficial]: sin(2^k * pi * x)
    freq_bands = freq_bands * math.pi * omega0
    
    # 2. Reshape for broadcasting
    # x shape: (*, d)
    # freq_bands shape: (num_freqs,)
    # We want to compute sin(x[..., None, :] * freq_bands[None, None, :])
    # Result shape: (*, d, num_freqs)
    
    # Expand x to (*, d, 1) and freq_bands to (1, 1, num_freqs)
    x_expanded = x.unsqueeze(-1)  # (*, d, 1)
    freq_expanded = freq_bands.unsqueeze(0).unsqueeze(0)  # (1, 1, num_freqs)
    
    # 3. Compute scaled values
    scaled = x_expanded * freq_expanded  # (*, d, num_freqs)
    
    # 4. Apply sin and cos
    sin_vals = torch.sin(scaled)  # (*, d, num_freqs)
    cos_vals = torch.cos(scaled)  # (*, d, num_freqs)
    
    # 5. Concatenate sin and cos along the last dimension
    # Result shape: (*, d, 2 * num_freqs)
    encoded = torch.cat([sin_vals, cos_vals], dim=-1)
    
    # 6. Include original input if requested
    if include_input:
        encoded = torch.cat([x, encoded], dim=-1)
        
    return encoded
```

**Edge Cases and Pitfalls:**
- **Lambda Closure Issue:** When implementing FPE as a list of lambda functions (e.g., in TensorFlow or older PyTorch patterns), variables `p_fn` and `freq` must be bound as default arguments (`p_fn=p_fn, freq=freq`) to avoid capturing the final loop values [S20, unofficial].
- **Spectral Bias:** Without FPE, ReLU MLPs fail to reproduce fine-scale variations [S7].
- **Aliasing:** Standard FPE treats rays as infinitely thin lines, causing aliasing at varying resolutions [S7]. This is addressed by variants like [Integrated Positional Encoding](5255-integrated-positional-encoding.md).
- **Derivatives:** The derivative of the encoding is continuous across space, allowing for second-order derivative computations (e.g., curvature regularization) [S13]. The derivative of the $l$-th band is $\partial \gamma_l(x) / \partial x = (2^l \pi \cos(2^l \pi x), -2^l \pi \sin(2^l \pi x))$ [S13].

## Subtopics

### [Fourier Feature Networks](2765-fourier-feature-networks.md)
Replaces the learned featurizer with a fixed, high-dimensional Fourier embedding to remedy spectral bias in ReLU MLPs.

### [Off-Axis Positional Encoding](3503-off-axis-positional-encoding.md)
Uses a non-identity basis matrix (icosahedron-derived) to disambiguate anisotropic Gaussians with identical marginal distributions.

### [Coordinate-Time Encoding](5105-coordinate-time-encoding.md)
A continuous, single-scale variant (One-Blob Encoding) that rasterizes a kernel for localized representation.

### [Integrated Positional Encoding](5255-integrated-positional-encoding.md)
Computes the closed-form integral of sinusoidal features over a Gaussian frustum to anti-alias high-frequency details.

### [Integrated Positional Encoding (Diagonal Covariance)](12189-integrated-positional-encoding-diagonal-covariance.md)
Computes the expected value of sinusoidal encodings for Gaussian random variables, acting as a low-pass filter.

### [2D Positional Embedding](12829-2d-positional-embedding.md)
Uses fixed, predefined frequencies for 2D grid inputs, unlike the learned frequencies in FFN.

### [Frequency Annealing](13443-frequency-annealing.md)
Gradually activates higher-frequency bands during training to prevent optimization instability.

### [Truncated Dynamic Low-pass Filter](14016-truncated-dynamic-low-pass-filter.md)
Initializes frequency threshold at a non-zero value to ensure valid color info while suppressing high-frequency instability.

### [Rotary Position Embedding (RoPE)](15851-rotary-position-embedding-rope.md)
Applies relative rotational transformations to token embeddings, preserving inner products as a function of relative distance.

### Scale Featurization
A method to provide scale information to the MLP by averaging and concatenating a featurized version of downweighting factors [S30]. It ensures features have consistent magnitude regardless of training progression. The featurized scale input is calculated as $(2 \cdot \operatorname{mean}_j(\downweight_{j, \ell}) - 1)\sqrt{\initval^2 + \stopgrad(\operatorname{mean}(\grid_\ell^2))}$, where $\downweight_{j, \ell}$ is the downweighting factor, $\initval$ is the initialization magnitude, and $\grid_\ell$ represents grid values [S30]. The `erf` approximation $\operatorname{sign}(x) \sqrt{1 - \exp(-(\frac{4}{\pi})x^2)}$ is used for speed [S30].

### Conditional Positional Encoding
Applies phase shifts based on time index to sampled features, inspired by Fourier transformation phase information retention [S31]. It applies positional encoding to 6D attributes (x, y, z, t, θ, ϕ) and sampled features, explicitly assigning phase shifts to different frequencies using time index $t$ [S31]. It is not applied to density field features to maintain zero initialization [S31].

### Fixed Sine/Cosine Positional Encoding
A baseline variant using fixed sine/cosine positional encoding for 3D Gaussian centers [S32]. On the Brandenburg Gate scene, it achieves PSNR 18.66, SSIM 0.763, LPIPS 0.347. On the Trevi Fountain scene, it achieves PSNR 19.91, SSIM 0.741, LPIPS 0.305 [S32].

## Operating characteristics
- **Time Complexity:** $O(d \cdot N)$ per coordinate, where $d$ is input dimension and $N$ is number of frequency bands. The computation is vectorizable and fast on GPUs [S3, S8, unofficial].
- **Memory Complexity:** $O(d \cdot N)$ for the output tensor. No additional memory for learned parameters if frequencies are fixed [S2, unofficial][S25].
- **Performance:** Requires a larger network (e.g., 8 hidden layers, 256 wide) compared to Multiresolution Hash Encoding to achieve similar quality, and trains slower [S2, unofficial][S25]. However, it provides continuous derivatives suitable for higher-order derivative computations like curvature regularization [S13].
- **Strengths:** Simple to implement, differentiable, continuous derivatives, effective at breaking spectral bias [S7, S13].
- **Limitations:** Suffers from aliasing when rendering at varying resolutions [S7]. Requires careful frequency selection (annealing) for stable training [S1][S4, unofficial].

## Background
Fourier Positional Encoding was introduced in the NeRF paper (Mildenhall et al., ECCV 2020) [S9, S17, unofficial]. It was inspired by positional encodings used in natural language processing (Vaswani et al., 2017) [S2, unofficial][S7]. The technique maps 3D positions and viewing directions to a higher-dimensional space using sinusoidal functions to help the MLP learn high-frequency details [S6, S12, unofficial]. It is widely adopted in neural radiance fields and implicit representations [S2, unofficial][S25].
