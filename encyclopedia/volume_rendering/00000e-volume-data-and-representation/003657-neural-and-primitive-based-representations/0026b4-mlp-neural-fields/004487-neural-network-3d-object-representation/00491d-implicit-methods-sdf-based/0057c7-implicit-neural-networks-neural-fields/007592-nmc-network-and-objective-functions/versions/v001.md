# NMC Network and Objective Functions

Also called: NMC loss functions, NMC training

## Overview
The NMC (Neural Marching Cubes) network and objective functions define the architecture and training losses for predicting discrete boolean occupancy and continuous float vertex offsets from an implicit field input [S1]. It solves the problem of generating high-quality meshes from neural implicit representations by decoupling the prediction of topology (boolean) and geometry (float) into two separate networks, avoiding the need for manual loss weighting [S1]. It differs from standard implicit neural fields by explicitly predicting the parameters required for the Marching Cubes tessellation algorithm rather than just a scalar field value [S1].

## How it works
**Inputs and Outputs**
*   **Input:** An array of implicit field values $I_s$ for a shape $s$. This can be either Signed Distance Field (SDF) values or binary voxel (occupancy) values [S1].
*   **Outputs:**
    *   Boolean array $D_s = f_B(I_s)$, representing the occupancy status of voxels [S1].
    *   Float array $H_s = f_F(I_s)$, representing the vertex offsets for the Marching Cubes tessellation [S1].
*   **Ground Truth:**
    *   Boolean array $B_s$ [S1].
    *   Float array $F_s$ [S1].
    *   Masks $M_{B_s}$ and $M_{F_s}$ indicating valid values in the ground truth arrays [S1].

**Data Structures**
The network uses two distinct 3D convolutional neural networks (backbones) [S1]:
1.  **Boolean Network ($f_B$):** Predicts $D_s$.
2.  **Float Network ($f_F$):** Predicts $H_s$.

Both networks are variants of 3D ResNet [S1].
*   **SDF Input Configuration:** Receptive field size is $7^3$ [S1].
*   **Binary Voxel Input Configuration:** Receptive field size is enlarged to $15^3$ to reduce ambiguity [S1].

**Objective Functions**
The method avoids summing losses with a weighting parameter, which is described as tedious to tune [S1]. Instead, it trains the two networks independently using specific loss functions [S1].

1.  **Boolean Loss ($L_{bool}$):** Binary Cross Entropy (BCE) [S1].
    $$L_{bool} = \mathbb{E}_{s \sim \mathcal{S}} \| - M_{B_s}(B_s \log(D_s) + (1 - B_s) \log(1 - D_s)) \|_1$$
    Where:
    *   $\mathcal{S}$ is the shape dataset [S1].
    *   $\log$ is the natural logarithm [S1].
    *   Multiplication is element-wise [S1].
    *   $\| \cdot \|_1$ is the L1 norm (sum of absolute values) [S1].

2.  **Float Loss ($L_{float}$):** Mean Squared Error (MSE) [S1].
    $$L_{float} = \mathbb{E}_{s \sim \mathcal{S}} \| M_{F_s}(F_s - H_s) \|_2^2$$
    Where:
    *   $\| \cdot \|_2^2$ is the squared L2 norm (sum of squared differences) [S1].

3.  **Smooth Float Loss ($L_{float}^*$):** Used only when inputs are binary voxels [S1].
    $$L_{float}^* = L_{float} + \gamma L_{smooth}$$
    Where $\gamma = 10$ [S1].

4.  **Smoothness Term ($L_{smooth}$):** Encourages output surfaces to align with coordinate axes [S1].
    $$L_{smooth} = \mathbb{E}_{s \sim \mathcal{S}} \sum_{(u,v) \in E_s} \| \mathbb{1}(|F_s^u - F_s^v| < \sigma) \cdot (H_s^u - H_s^v) \|_2^2$$
    Where:
    *   $E_s$ is the set of all edges $(u, v)$ in the ground truth mesh for shape $s$ [S1].
    *   $F_s^u \in \mathbb{R}^3$ is the coordinate of vertex $u$ in the ground truth mesh [S1].
    *   $H_s^u \in \mathbb{R}^3$ is the coordinate of vertex $u$ in the predicted mesh [S1].
    *   $\mathbb{1}(\cdot)$ is an indicator function converting true to 1 and false to 0 [S1].
    *   $\sigma = 0.0002$ is the threshold for the indicator function [S1].
    *   The tessellation of the predicted mesh is assumed to be identical to the ground truth tessellation during training, determined solely by the boolean part [S1].

**Parameters**
*   $\sigma = 0.0002$ [S1].
*   $\gamma = 10$ [S1].

**Pitfalls and Edge Cases**
*   **Binary Voxel Ambiguity:** Binary voxel inputs have considerable ambiguities regarding the possible shapes represented [S1]. This is mitigated by using the larger $15^3$ receptive field and the smoothness term [S1].
*   **Loss Weighting:** Summing $L_{bool}$ and $L_{float}$ with a single weighting parameter is discouraged due to the difficulty in finding appropriate weights [S1].

**Pseudocode**

```python
import numpy as np

def compute_boolean_loss(D_s, B_s, M_B_s):
    """
    Computes the boolean loss L_bool for a batch of shapes.
    D_s: Network output boolean predictions (logits or probabilities depending on implementation, 
         assuming log(D_s) is valid, these are likely probabilities or logits passed to log).
         Note: The formula uses log(D_s). In standard BCE, inputs to log are probabilities.
         If D_s are logits, one would typically use sigmoid first. The source formula 
         implies D_s are in (0,1).
    B_s: Ground truth boolean array.
    M_B_s: Mask for valid values.
    """
    # Element-wise multiplication
    # log(D_s) assumes D_s > 0. In practice, clamp D_s to avoid log(0).
    D_clamped = np.clip(D_s, 1e-7, 1 - 1e-7)
    
    term1 = B_s * np.log(D_clamped)
    term2 = (1 - B_s) * np.log(1 - D_clamped)
    
    # Apply mask
    masked_loss = M_B_s * (-1 * (term1 + term2))
    
    # L1 norm (sum of absolute values)
    loss = np.sum(np.abs(masked_loss))
    
    # Expectation over dataset S is handled by averaging over the batch in training
    return loss / B_s.size # Or batch size normalization depending on implementation

def compute_float_loss(H_s, F_s, M_F_s):
    """
    Computes the float loss L_float for a batch of shapes.
    H_s: Network output float predictions (vertex offsets).
    F_s: Ground truth float array (vertex offsets).
    M_F_s: Mask for valid values.
    """
    # Element-wise difference
    diff = F_s - H_s
    
    # Apply mask
    masked_diff = M_F_s * diff
    
    # Squared L2 norm (sum of squared differences)
    loss = np.sum(np.square(masked_diff))
    
    return loss / F_s.size

def compute_smoothness_term(H_s, F_s, E_s, sigma=0.0002):
    """
    Computes the smoothness term L_smooth.
    H_s: Predicted vertex coordinates.
    F_s: Ground truth vertex coordinates.
    E_s: List of edges, where each edge is a tuple (u, v) of vertex indices.
    sigma: Threshold for the indicator function.
    """
    smooth_loss = 0.0
    
    for (u, v) in E_s:
        # Get coordinates for vertices u and v
        F_u = F_s[u]
        F_v = F_s[v]
        H_u = H_s[u]
        H_v = H_s[v]
        
        # Calculate difference in ground truth coordinates
        diff_gt = np.abs(F_u - F_v)
        
        # Indicator function: 1 if diff < sigma, else 0
        # Note: The source uses |F_s^u - F_s^v| < sigma. 
        # This checks if the GT edge is short.
        indicator = 1.0 if np.all(diff_gt < sigma) else 0.0
        
        if indicator > 0:
            # Difference in predicted coordinates
            diff_pred = H_u - H_v
            
            # Squared L2 norm of the predicted difference
            term = np.sum(np.square(diff_pred))
            smooth_loss += term
            
    return smooth_loss

def train_nmc_network(input_implicit_field, ground_truth_bool, ground_truth_float, 
                      ground_truth_mesh_edges, is_binary_voxel_input=False):
    """
    Simulates the training step for NMC network.
    """
    # 1. Define Network Architectures
    # f_B: 3D ResNet variant
    # f_F: 3D ResNet variant
    
    # 2. Set Receptive Field
    if is_binary_voxel_input:
        receptive_field = 15**3
    else:
        receptive_field = 7**3
        
    # 3. Forward Pass
    # D_s = f_B(input_implicit_field)
    # H_s = f_F(input_implicit_field)
    # Note: In a real implementation, these would be tensor operations.
    
    # 4. Compute Losses
    # L_bool
    loss_bool = compute_boolean_loss(D_s, ground_truth_bool, M_B_s)
    
    # L_float
    loss_float = compute_float_loss(H_s, ground_truth_float, M_F_s)
    
    # L_smooth (only for binary voxel inputs)
    if is_binary_voxel_input:
        gamma = 10
        sigma = 0.0002
        loss_smooth = compute_smoothness_term(H_s, ground_truth_float, ground_truth_mesh_edges, sigma)
        total_loss = loss_bool + loss_float + gamma * loss_smooth
    else:
        total_loss = loss_bool + loss_float
        
    # 5. Backpropagation
    # Update f_B weights using gradient of loss_bool
    # Update f_F weights using gradient of total_loss (or loss_float if not binary)
    
    return total_loss
```

## Operating characteristics
*   **Time and Memory Complexity:** Training directly with dense point clouds for optimization is intractable in terms of computational time and memory cost [S1]. The NMC network approach avoids this by predicting voxel-level parameters, making it more efficient than dense point cloud optimization [S1].
*   **Strengths:** Decoupling boolean and float predictions eliminates the need for manual loss weighting [S1]. The smoothness term effectively reduces ambiguities in binary voxel inputs [S1].
*   **Limitations:** The method requires ground truth mesh edges for the smoothness term calculation [S1]. It is specifically designed for the Marching Cubes tessellation context [S1].
*   **When to use:** When generating meshes from implicit fields using Marching Cubes, especially with binary voxel inputs where ambiguity is a concern [S1].
*   **When not to use:** When using SDF inputs with small receptive fields ($7^3$) and not requiring the specific smoothness alignment with coordinate axes [S1].

## Background
The NMC network and objective functions were introduced in the paper "Neural Marching Cubes" [S1]. The method addresses the limitations of training neural networks directly with optimization objectives on dense point clouds, which are computationally expensive [S1].
