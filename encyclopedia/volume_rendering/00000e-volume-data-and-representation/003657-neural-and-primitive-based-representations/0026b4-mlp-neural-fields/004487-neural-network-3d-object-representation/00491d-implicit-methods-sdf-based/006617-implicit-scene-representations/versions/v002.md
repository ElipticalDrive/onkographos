# Implicit Scene Representations

Also called: Neural Implicit Surfaces (SDF), SDF-based Implicit Representations

## Overview
Implicit Scene Representations model 3D geometry by parameterizing a Signed Distance Function (SDF) as a continuous function mapping any 3D point to its distance from the nearest surface [S1]. It builds on [Implicit methods (SDF-based)](12421-implicit-methods-sdf-based.md) by specifying the SDF functional form and common parameterization strategies [G].

## How it works
**Inputs:** 3D coordinates $\mathbf{x} \in \mathbb{R}^3$ [S1].
**Outputs:** Scalar SDF value $s \in \mathbb{R}$ [S1].

**Data Structures:**
The SDF function $f$ is parameterized by learnable parameters $\theta$ [S1]. Common implementations include:
1.  **Dense Grid:** A 3D volume $G_\theta$ with resolution $R_H \times R_W \times R_D$ storing learnable SDF values [S1].
2.  **MLP:** A multi-layer perceptron with weights $\theta$ [S1].
3.  **Hybrid:** An MLP combined with single- or multi-resolution feature grids [S1].

**Steps:**
1.  **Query:** For a given 3D point $\mathbf{x}$, compute the SDF value $s$.
    *   If using a **Dense Grid**, interpolate $G_\theta$ at location $\mathbf{x}$ [S1].
    *   If using an **MLP**, evaluate the network defined by $\theta$ [S1].
2.  **Output:** Return $s$. The surface is defined at the zero-level set $s = 0$ [G].

**Formulas:**
The SDF is defined as:
$$ f : \mathbb{R}^3 \rightarrow \mathbb{R} $$
$$ \mathbf{x} \mapsto s = \text{SDF}(\mathbf{x}) \quad (1) $$
where $\mathbf{x}$ is the 3D point and $s$ is the distance to the closest surface [S1].

**Parameters:**
*   $\theta$: Learnable parameters. For grids, these are the values in $G_\theta$. For MLPs, these are weights and biases [S1].
*   Resolution $R_H \times R_W \times R_D$: Defines the granularity of the dense grid representation [S1].

**Edge Cases and Pitfalls:**
*   **Interpolation:** When using dense grids, the choice of interpolation (e.g., trilinear) affects smoothness and accuracy [S1].
*   **Degenerate Input:** Points far from any surface may yield large $s$ values, potentially causing numerical issues in downstream rendering or marching cubes if not clamped [G].
*   **Boundary Conditions:** Grid-based methods require handling points outside the defined volume bounds [G].
