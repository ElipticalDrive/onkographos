# View-Dependent Effects Preservation

Also called: Neuron Freezing for View-Dependence

## Overview
View-Dependent Effects Preservation is a technique used during the editing of pre-trained Neural Radiance Fields (NeRFs) to retain existing specularities and other view-dependent appearance effects that would otherwise be lost or distorted by global recoloring operations [S1]. It distinguishes itself from standard NeRF editing methods by automatically identifying and freezing specific neurons in the final color prediction layer that encode angular variation, thereby isolating geometry information from view-dependent appearance [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A pre-trained NeRF model (specifically the color MLP $V_{rgb}$), an input edited view image $I_{edit}$, and scene parameters (azimuth sweep range) [S1].
*   **Output:** A mask or set of indices identifying which neurons in the last layer of the color MLP are "view-dependent" and should be frozen during subsequent training [S1].

**Data Structures**
*   **Neuron Activations ($h_\theta$):** A tensor of shape $\mathbb{R}^{W \times H \times 64}$, where $W$ and $H$ are the image dimensions, and 64 is the dimensionality of the output vector from the penultimate layer of the color MLP [S1].
*   **Angular Profile ($A$):** A matrix of shape $\mathbb{R}^{64 \times Q}$, where $Q$ is the number of sampled view angles [S1]. Each row $A_k \in \mathbb{R}^Q$ represents the activation profile of neuron $k$ across the sampled views [S1].

**Parameters**
*   $\tau_1$: Threshold for the coefficient of variation. Default value: $0.5$ [S1].
*   $\tau_2$: Threshold for minimum activation magnitude. Default value: $100$ [S1].
*   $Q$: Number of view angles to sample. Default value: $30$ [S1].
*   $\psi$: Angular sweep step. For omnidirectional scenes (e.g., Blender, MIP360), the full azimuth is swept. For forward-facing scenes (e.g., LLFF), only half the azimuth is considered [S1].

**Algorithm Steps**
1.  **Sample View Directions:** Generate a set of $Q$ view directions $\{\theta_0, \theta_1, ..., \theta_{Q-1}\}$ by uniformly sweeping the azimuth angle according to $\psi$ [S1]. For forward-facing datasets, restrict the sweep to 180 degrees; for others, sweep 360 degrees [S1].
2.  **Compute Activations:** For each sampled view direction $\theta_i$, render the edited view $I_{edit}$ (or query the MLP at the corresponding pixel coordinates) to obtain the neuron activations $h_{\theta_i} \in \mathbb{R}^{W \times H \times 64}$ from the last layer of the color MLP [S1].
3.  **Aggregate Spatially:** For each neuron index $k \in \{0, ..., 63\}$, aggregate the activations across all spatial pixels $(w, h)$ and all view angles to form the angular profile $A_k$ [S1]. Specifically, $A_k[i] = h_{\theta_i}[w, h, k]$ for all $w, h$ [S1]. This results in $A \in \mathbb{R}^{64 \times Q}$ [S1]. [G] Mean aggregation is used to reduce the spatial dimensions to a single representative value per view angle.
4.  **Identify View-Dependent Neurons:** For each neuron $k$, calculate the mean $\mu(A_k)$ and standard deviation $\sigma(A_k)$ of its activation profile [S1]. Label neuron $k$ as view-dependent if either of the following conditions is met:
    *   The coefficient of variation is low: $\frac{\sigma(A_k)}{\mu(A_k)} < \tau_1$ [S1].
    *   The minimum activation is low: $\min(A_k) \le \tau_2$ [S1].
    [G] Note: The source formula uses a less-than inequality for the coefficient of variation, which typically indicates low variation; the source explicitly states this condition identifies view-dependent neurons, so the formula is reproduced exactly as cited [S1].
5.  **Freeze Weights:** During the subsequent training phase for editing, the weights connecting the identified view-dependent neurons to the output are frozen, preserving their original values [S1].

**Pseudocode**
```python
import numpy as np

def identify_view_dependent_neurons(nerf_model, edited_view_image, Q=30, tau1=0.5, tau2=100, is_forward_facing=False):
    """
    Identifies neurons in the last layer of the color MLP that exhibit view-dependent behavior.
    """
    W, H = edited_view_image.shape[:2]
    num_neurons = 64
    azimuth_range = np.linspace(0, np.pi, Q) if is_forward_facing else np.linspace(0, 2 * np.pi, Q)
    h_theta = np.zeros((Q, W, H, num_neurons))

    for i, theta in enumerate(azimuth_range):
        # [G] Standard MLP forward pass for all pixels at camera orientation theta
        h_theta[i] = nerf_model.forward_activations(edited_view_image, theta)

    A = np.zeros((num_neurons, Q))
    for k in range(num_neurons):
        # [G] Mean aggregation over spatial dimensions (W, H)
        A[k, :] = np.mean(h_theta[:, :, :, k], axis=(1, 2))

    view_dependent_mask = np.zeros(num_neurons, dtype=bool)
    for k in range(num_neurons):
        Ak = A[k, :]
        mu_Ak = np.mean(Ak)
        std_Ak = np.std(Ak)
        min_Ak = np.min(Ak)

        # Guard against division by zero [G]
        cv = std_Ak / mu_Ak if mu_Ak != 0 else 0.0
        cond1 = cv < tau1
        cond2 = min_Ak <= tau2

        if cond1 or cond2:
            view_dependent_mask[k] = True
    return view_dependent_mask
```

**Edge Cases and Pitfalls**
*   **Zero Mean:** If $\mu(A_k) = 0$, the coefficient of variation is undefined. The source does not specify handling for this case [S1]. [G] The implementation guards against division by zero by defaulting the condition to false.
*   **Sweep Range:** The method assumes a specific angular sweep strategy for forward-facing scenes (LLFF) versus omnidirectional scenes [S1].
*   **Threshold Sensitivity:** The choice of $\tau_1$ and $\tau_2$ directly impacts which neurons are frozen [S1].

## Operating characteristics
*   **Time Complexity:** The identification step requires $Q$ forward passes through the color MLP for every pixel in the edited view [S1].
*   **Memory Complexity:** Requires storing the activation tensor $h_\theta$ of size $\mathbb{R}^{Q \times W \times H \times 64}$ and the aggregated matrix $A$ of size $\mathbb{R}^{64 \times Q}$ [S1].
*   **Strengths:** Preserves high-frequency view-dependent effects (specularities) without requiring explicit separation of diffuse and specular components during editing [S1].
*   **Limitations:** Relies on the assumption that view-dependent and geometry information are separable in the last layer's neurons, which may not hold for all NeRF architectures or scenes [S1].

## Background
The method was introduced in the context of **IReNe** (Instant Recoloring of Neural Radiance Fields) by Mazzucchelli et al. in 2024 [S1]. It addresses the issue that global recoloring operations in NeRFs can distort existing view-dependent effects like specular highlights [S1]. The approach builds on the observation that the last layer of the color MLP contains neurons with distinct behaviors: some vary with view direction (view-dependent), while others remain constant (geometry information) [S1].
