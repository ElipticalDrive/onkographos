# InstantNGP Network Architecture

Also called: Instant Neural Graphics Primitives, Instant Neural Graphics Primitives Network, Instant Neural Graphics Primitives Network Architecture, InstantNGP MLP, InstantNGP MLP Architecture

## Overview
InstantNGP is a neural field architecture designed for real-time training and rendering of 3D scenes by replacing traditional positional encoding with a multiresolution hash grid [S1][S3, unofficial]. It solves the bottleneck of MLP evaluation latency in NeRF by leveraging hardware-accelerated memory locality and bilinear interpolation [S1][S3, unofficial]. Unlike the parent [NeRF MLP Architecture](910-nerf-mlp-architecture.md) which maps raw coordinates to density and color, InstantNGP first encodes spatial positions into a high-dimensional feature vector via hash lookups, which are then processed by a lightweight MLP [S1][S3, unofficial]. This approach enables training convergence in seconds rather than hours, distinguishing it from standard NeRF variants [S2, S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in \mathbb{R}^3$.
*   **Output:** Volume density $\sigma \in \mathbb{R}$ and view-dependent color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The core data structure is a multiresolution hash grid consisting of $L=16$ levels [S1]. For each level $l \in \{0, \dots, 15\}$, the grid resolution ranges from $32^3$ to $2048^3$ [S1]. Each entry in the hash table stores a learnable feature vector $\mathbf{f} \in \mathbb{R}^8$ [S1]. The hash dictionary size is $2^{22}$ [S1]. Features from the 8 neighboring grid vertices of $\mathbf{x}$ at level $l$ are retrieved and interpolated using trilinear interpolation to produce the level-specific feature vector $\mathbf{f}_l(\mathbf{x})$ [S1]. The features from all levels are concatenated: $\mathbf{f}_{\text{total}} = [\mathbf{f}_0(\mathbf{x}); \dots; \mathbf{f}_{15}(\mathbf{x})]$ [S1]. The viewing direction $\mathbf{d}$ is encoded using 3 degrees of spherical harmonics [S1][S3, unofficial].

**Numbered Steps:**
1.  **Position Hash Encoding:** Discretize $\mathbf{x}$ to the grid resolution $N_l$ at each level $l$, compute hash indices for the 8 corners, retrieve features, and perform trilinear interpolation to obtain $\mathbf{f}_l(\mathbf{x})$ [S1].
2.  **Feature Concatenation:** Concatenate the interpolated features from all 16 levels into $\mathbf{f}_{\text{total}}$ [S1].
3.  **Direction Encoding:** Encode $\mathbf{d}$ using 3rd-degree spherical harmonics to produce $\mathbf{d}_{\text{encoded}}$ [S1][S3, unofficial].
4.  **Density Prediction:** Pass $\mathbf{f}_{\text{total}}$ through the SDF/RGB network (1 hidden layer, 256 units, softplus activation) to predict $\sigma$ [S1].
5.  **Color Prediction:** Concatenate $\mathbf{f}_{\text{total}}$ with $\mathbf{d}_{\text{encoded}}$ and pass through the RGB network (4 hidden layers, 256 units, ReLU activation) to predict $\mathbf{c}$ [S1].

**Formulas:**
*   Trilinear interpolation at level $l$: $\mathbf{f}_l(\mathbf{x}) = \sum_{i=0}^{7} w_i \cdot \mathbf{f}_{\text{grid}}[h(\mathbf{x}, l, i)]$, where $w_i$ are interpolation weights and $h$ is the hash function [S1].
*   Feature concatenation: $\mathbf{f}_{\text{total}} = \text{concat}(\mathbf{f}_0, \dots, \mathbf{f}_{15})$ [S1].
*   Density output: $\sigma = \text{Softplus}(\text{MLP}_{\text{density}}(\mathbf{f}_{\text{total}}))$ [S1].
*   Color output: $\mathbf{c} = \text{MLP}_{\text{color}}(\text{concat}(\mathbf{f}_{\text{total}}, \mathbf{d}_{\text{encoded}}))$ [S1].

**Parameters:**
*   **Hash Map Size:** $2^{22}$ entries [S1].
*   **Optimizer:** Adam [S2, unofficial].
*   **Learning Rate Schedule:** $10^{-2} \to 10^{-4}$ [S2, unofficial].
*   **Iterations:** 20k [S2, unofficial].
*   **Occupancy Grid:** Utilized to skip empty space during training [S2, unofficial].
*   **Loss Function:** Huber loss with $\delta=0.1$ [S3, unofficial].
*   **Density Grid Sampler Update Frequency:** 16 [S3, unofficial].
*   **Training Speed:** Approximately 133 iterations per second on JNeRF [S3, unofficial].

**Pseudocode:**
```python
def instantngp_forward(x, d, hash_grids, density_weights, density_biases, 
                       color_weights, color_biases):
    """
    x: (3,) float tensor, 3D position
    d: (3,) float tensor, viewing direction
    hash_grids: list of 16 tensors, each shape [2^22, 8]
    density_weights: list of 2 weight matrices for 1-hidden-layer MLP
    density_biases: list of 2 bias vectors
    color_weights: list of 5 weight matrices for 4-hidden-layer MLP
    color_biases: list of 5 bias vectors
    """
    # 1. Hash Encoding & Trilinear Interpolation
    f_total = []
    for l in range(16):
        grid_size = 32 * (2 ** l)  # Resolutions: 32^3 to 2048^3
        # Compute fractional coordinates and corner indices
        frac = x * grid_size
        corners = floor(frac) % grid_size
        weights = frac - corners
        
        # Compute 8 corner hash indices
        indices = []
        for i in range(8):
            c = corners + ((i >> 0) & 1) + ((i >> 1) & 1) * grid_size + ((i >> 2) & 1) * grid_size**2
            indices.append(c % (2**22))  # Hash map size 2^22
        
        # Gather features
        features = gather(hash_grids[l], indices)  # Shape: [8, 8]
        
        # Trilinear interpolation weights
        w000 = (1-weights[0])*(1-weights[1])*(1-weights[2])
        w100 = weights[0]*(1-weights[1])*(1-weights[2])
        w010 = (1-weights[0])*weights[1]*(1-weights[2])
        w110 = weights[0]*weights[1]*(1-weights[2])
        w001 = (1-weights[0])*(1-weights[1])*weights[2]
        w101 = weights[0]*(1-weights[1])*weights[2]
        w011 = (1-weights[0])*weights[1]*weights[2]
        w111 = weights[0]*weights[1]*weights[2]
        
        f_l = (w000*features[0] + w100*features[1] + w010*features[2] + w110*features[3] +
               w001*features[4] + w101*features[5] + w011*features[6] + w111*features[7])
        f_total.append(f_l)
    
    f_concat = concatenate(f_total, axis=0)  # Shape: [128]
    
    # 2. Density Prediction (1 hidden layer, 256 units, softplus)
    h1 = relu(f_concat @ density_weights[0] + density_biases[0])
    sigma = softplus(h1 @ density_weights[1] + density_biases[1])
    
    # 3. Direction Encoding (3rd-degree spherical harmonics)
    d_encoded = spherical_harmonic_encode(d, degree=3)  # [27]
    
    # 4. Color Prediction (4 hidden layers, 256 units, ReLU)
    x_color = concatenate([f_concat, d_encoded], axis=0)  # Shape: [155]
    h1_c = relu(x_color @ color_weights[0] + color_biases[0])
    h2_c = relu(h1_c @ color_weights[1] + color_biases[1])
    h3_c = relu(h2_c @ color_weights[2] + color_biases[2])
    h4_c = relu(h3_c @ color_weights[3] + color_biases[3])
    color = h4_c @ color_weights[4] + color_biases[4]  # Shape: [3]
    
    return sigma, color
```

**Edge Cases and Pitfalls:**
*   **Implementation Coupling:** The original Instant-NGP source code is written entirely in CUDA, making it difficult for Python users to use and hard to modify due to severe coupling between functions for extreme efficiency [S3, unofficial].
*   **Precision:** Trilinear interpolation requires careful handling of floating-point precision to avoid artifacts at grid boundaries [G].

## Subtopics

### [Tiny MLP for Density and Color Estimation](8555-tiny-mlp-for-density-and-color-estimation.md)
The Tiny MLP is a lightweight neural network component used in Rip-NeRF to estimate the density $\tau$ and view-dependent color $c$ of a sampled sphere $S$. It builds on [InstantNGP Network Architecture](5049-instantngp-network-architecture.md) by mapping the Ripmap-Encoding feature vector $f$ and the encoded view direction $d$ to radiance properties. It sets itself apart from sibling methods like [iNGP Texture Storage](5826-ingp-texture-storage.md) by using a dedicated small MLP for density/color prediction rather than relying solely on texture lookups for these specific outputs, and differs from [HyperINR](10461-hyperinr.md) by using a fixed-width MLP with specific activation constraints rather than hypernetworks.

### [HyperINR](10461-hyperinr.md)
HyperINR is a hypernetwork architecture that directly predicts the weights of a compact Implicit Neural Representation (INR) conditioned on scene parameters, enabling interactive volumetric path tracing with inference times less than 1ms. It differs from standard INRs, which require millions of operations per forward pass and are too slow for interactive visualization, and from data interpolation methods, which operate on data values rather than network weights and are less accurate for unseen parameters. By using a shared synthesis function and interpolating encoding weights via an ensemble of multi-resolution hash encoders organized in a KD-tree, HyperINR achieves up to 100× faster inference than teacher models like CoordNet while maintaining high reconstruction quality.

### [Hybrid Fourier-Hash Encoding](13021-hybrid-fourier-hash-encoding.md)
Hybrid Fourier-Hash Encoding is a neural geometry representation technique that combines low-dimensional Fourier positional encoding with learnable multi-scale hash features to improve the continuity of the signed distance function (SDF) and satisfy eikonal constraints. It addresses the non-smooth solutions and poor gradient continuity produced by hash encoding alone, which arises from the discontinuous nature of features on discrete grids. Unlike the baseline InstantNGP architecture which uses only hash encoding, this method decouples geometry from appearance by extracting features from an intermediate connected layer, ensuring hash encoding encodes only geometry.

### [INGP-NeRF](13366-ingp-nerf.md)
INGP-NeRF is a spike-based neural radiance field implementation that integrates the Instant Neural Graphics Primitives (InstantNGP) hash-grid encoding with Leaky Integrate-and-Fire (LIF) neuron dynamics for density and color estimation. It distinguishes itself from standard NeRF MLPs by replacing continuous activations with spiking neurons to accumulate temporal estimates of radiance, enabling adaptive time-step training for enhanced reconstruction quality.

### [Unbounded Hash-Grid with Negative Integer Mapping](13889-unbounded-hash-grid-with-negative-integer-mapping.md)
This method extends the Instant-NGP hash-grid encoding to support unbounded input domains by modifying the hash function to handle negative integers without structured collisions. It solves the problem of applying neural field representations, originally designed for normalized $[0, 1]^d$ inputs, to large-scale scenes with arbitrary coordinate ranges. It differs from its parent [InstantNGP Network Architecture](5049-instantngp-network-architecture.md) by replacing the bounded hash lookup with a negative-integer-aware mapping and by computing positional gradients directly from interpolation weights rather than assuming non-differentiable sample positions.

### [INGeo](15132-ingeo.md)
INGeo is a method that accelerates 3D scene reconstruction training by leveraging noisy geometry priors (e.g., from RGB-D sensors or COLMAP) converted into an occupancy grid, aiming for instant reconstruction on edge devices. It builds on [InstantNGP Network Architecture](5049-instantngp-network-architecture.md) by initializing the occupancy grid with prior geometry and applying density scaling to ensure rays terminate quickly at the surface, addressing the slow convergence of randomly initialized weights.

### [Scene Scale Consistency Scoring](15618-scene-scale-consistency-scoring.md)
Scene Scale Consistency Scoring (SSCS) is a post-processing heuristic used to detect and remove floating artifacts in neural radiance fields by comparing occupancy grids from models trained with different bounding box scales. It distinguishes itself from sibling methods like Occupancy Clustering by exploiting the geometric invariance of real scene structures against the scale-dependent manifestation of artifacts, thereby filtering out inconsistent density before clustering is applied.

### [Unrestricted Color Network (UCN) Distillation](16596-unrestricted-color-network-ucn-distillation.md)
Unrestricted Color Network (UCN) Distillation is a knowledge distillation method that trains a student network to replicate the diffuse color output of a Palette Color Network (PCN) teacher model without enforcing palette constraints, enabling Non-Photorealistic Style Editing (NPSE). Unlike traditional NeRF stylization that discards view-dependent color to maintain consistency, UCN optimizes diffuse color during training and combines it with specular color during inference to preserve lighting effects.

#### Flash Cache Implementation
The Flash Cache implementation uses a fast cache NGP with a maximum grid resolution of 256 and a 4-layer 128-hidden-unit MLP to predict $S=8$ sample-point distances [S5]. The hash maps for all NGPs have a size of $2^{19}$ [S5]. This variant is used for predicting distances and features in the cache, differing from the main architecture by its specific MLP depth and hidden units optimized for cache prediction [S5].

#### Upsampling Activations
This extension reduces processing time by computing intermediate network activations at a lower resolution and upsampling them to full resolution before density proposal [S6]. Intermediate activations $A^{(\ell)}$ are recorded at a reduced resolution of $w/2 \times h/2 \times N_c/2 \times N_h$, then upsampled using nearest neighbor interpolation [S6]. Best performance is observed at layer index $\ell = 1$ with function configuration $f_2$ [S6]. On the Blender dataset, this achieves PSNR 23.69, SSIM 0.704, LPIPS 0.267 with a 44% speedup over the baseline [S6]. It differs from full-resolution activation extraction by trading negligible visual quality loss for significant speedup, whereas DONeRF filters along depth and neighboring rays for smoothing [S6]. Applied to NeRF and Mip-NeRF architectures on Blender and LLFF datasets [S6].

#### Instant-NGP adapted NeuS
An adaptation of the NeuS implicit SDF geometry learning method optimized with Instant-NGP for efficient training [S7]. The entire pipeline employs CUDA backends for computation and Python interfaces for interaction, with the path tracing algorithm implemented using CUDA embedded in Instant-NGP’s ray-marching procedures [S7]. It is trained using the default configuration of Instant-NGP [S7].

## Operating characteristics
*   **Time Complexity:** Training converges in ~20k iterations, significantly faster than standard NeRF's 200–400k iterations [S2, unofficial]. Hash grid lookups are $O(1)$ on average, but memory bandwidth can become a bottleneck due to random access patterns [S1][S3, unofficial].
*   **Memory Complexity:** The hash grid size is fixed at $2^{22}$ entries [S1].
*   **Measured Performance:** Training speed reaches approximately 133 iterations per second on JNeRF [S3, unofficial]. The upsampling activations variant achieves a 44% speedup on the Blender dataset with PSNR 23.69, SSIM 0.704, and LPIPS 0.267 [S6].
*   **Strengths:** Extremely fast training and rendering; hardware-friendly hash lookups; scalable to high resolutions [S2, S3, unofficial].
*   **Limitations:** Original implementation is CUDA-only and tightly coupled, hindering modification [S3, unofficial].
*   **When to Use:** Real-time training and rendering; large-scale scenes [S2, S3, unofficial].
*   **When Not to Use:** When strict gradient continuity is required without hybrid encoding; when unbounded domains are needed without negative integer mapping [S1][S3, unofficial].

## Background
InstantNGP was introduced by Müller et al. in 2022 as a method for fast training and rendering of neural radiance fields using multiresolution hash encoding [S1]. It builds on the NeRF MLP Architecture by optimizing the feature extraction step [S1]. The method has been widely adopted and extended, including variants like MonoSDF [S4, unofficial], Flash Cache [S5], and INGP-NeRF [S5]. JNeRF successfully reproduced the speed and point count of the original paper, achieving approximately 133 iterations per second [S3, unofficial].
