# Scene Scale Consistency Scoring


## Overview
Scene Scale Consistency Scoring (SSCS) is a post-processing heuristic that detects and removes floating artifacts in neural radiance fields by comparing occupancy grids from models trained with different bounding box scales [S1]. It distinguishes itself from sibling methods like Occupancy Clustering by exploiting the geometric invariance of real scene structures against the scale-dependent manifestation of artifacts, thereby filtering out inconsistent density before clustering is applied [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of trained Instant-NGP models, each associated with a specific `aabb_scale` value $s \in S$ [S1]. The standard set is $S = [8, 16, 32]$ [S1]. An occupancy grid representation for each model [S1].
*   **Outputs:** A filtered occupancy grid where cells identified as inconsistent are set to 0 [S1].

**Data Structures:**
The method operates on a 3D occupancy grid [S1]. Each cell $C_k$ is indexed by integer coordinates $(x_I, y_I, z_I)$ [S1]. The grid stores binary occupancy values: 1 if occupied, and 0 otherwise [S1].

**Algorithm Steps:**
1.  **Training:** Train separate Instant-NGP models using different `aabb_scale` values from the set $S$ [S1]. The `aabb_scale` defines the scaling factor of the unit cube in which ray marching is performed [S1]. Powers of 2 are recommended to align grid borders [S1].
2.  **Iteration:** For each cell $C_k(x_I, y_I, z_I)$ in the grid:
    a.  Retrieve the occupancy status $C_{k,s}(x_I, y_I, z_I)$ from each trained model corresponding to scale $s \in S$ [S1]. This value is 1 if the cell is occupied in that model, and 0 otherwise [S1].
    b.  Calculate $N(S, C_{k,s})$, the number of scales $s \in S$ for which the cell $C_k$ lies within the training volume extent defined by scale $s$ [S1]. This represents the number of scaled scenes in which the cell is theoretically settable [S1].
    c.  Compute the SSCS score using the formula below [S1].
3.  **Filtering:** If $SSCS(C_k) < 1$, the cell is considered inconsistently set (meaning at least one scaled model does not carry density there) [S1]. Set the occupancy of this cell to 0 [S1].
4.  **Execution Order:** Perform SSCS filtering **before** Occupancy Clustering [S1]. This step interferes with the coherence between relevant scene geometry and floaters, enabling subsequent clustering to detect remaining artifacts more reliably [S1].

**Formula:**
The SSCS score for a cell is the fraction of scaled scenes in which the occupancy of the cell is set, normalized by the number of scenes where the cell is theoretically valid:

$$
SSCS(C_k(x_I, y_I, z_I)) = \frac{\sum_{s \in S} C_{k,s}(x_I, y_I, z_I)}{N(S, C_{k,s}(x_I, y_I, z_I))}
$$

Where:
*   $S$ is the set of scales, typically $[8, 16, 32]$ [S1].
*   $C_{k,s}(x_I, y_I, z_I)$ is the occupancy of cell $k$ in the model trained with scale $s$ (1 if occupied, 0 otherwise) [S1].
*   $N(S, C_{k,s}(x_I, y_I, z_I))$ is the count of scales $s \in S$ whose corresponding extents contain the cell [S1].

**Pseudocode:**

```python
def compute_sscs_filtering(occupancy_grids, scales, grid_shape):
    """
    Filters occupancy grids using Scene Scale Consistency Scoring.
    
    Args:
        occupancy_grids: A dictionary mapping scale s to a 3D list of lists of lists 
                         representing the occupancy grid (1 for occupied, 0 for empty).
        scales: A list of aabb_scale values used for training (e.g., [8, 16, 32]).
        grid_shape: A tuple (D, H, W) representing the dimensions of the occupancy grid.
        
    Returns:
        A filtered 3D list of lists of lists representing the combined occupancy grid.
    """
    filtered_grid = [[[0 for _ in range(grid_shape[2])] for _ in range(grid_shape[1])] for _ in range(grid_shape[0])]
    
    for x in range(grid_shape[0]):
        for y in range(grid_shape[1]):
            for z in range(grid_shape[2]):
                occupied_count = 0
                valid_scale_count = 0
                
                for s in scales:
                    grid = occupancy_grids[s]
                    
                    # Check if the cell is within the theoretical extent of this scale.
                    # [G] Assumes the grid covers the maximum scale and scales are powers of 2.
                    # The extent check maps grid indices to world coordinates and verifies
                    # bounds. For a fixed grid covering the max extent, all cells are
                    # theoretically settable for all scales in S.
                    if is_cell_in_extent(x, y, z, s, grid_shape):
                        valid_scale_count += 1
                        if grid[x][y][z] == 1:
                            occupied_count += 1
                
                # Calculate SSCS score
                if valid_scale_count > 0:
                    sscs_score = occupied_count / valid_scale_count
                else:
                    sscs_score = 0.0
                
                # Filter: Keep cell only if it is occupied in ALL valid scales (score == 1.0)
                if sscs_score == 1.0:
                    filtered_grid[x][y][z] = 1
                else:
                    filtered_grid[x][y][z] = 0
                    
    return filtered_grid

def is_cell_in_extent(x, y, z, scale, grid_shape):
    """
    Determines if a grid cell is within the theoretical extent of a given aabb_scale.
    [G] Implementation detail: Typically, the grid covers a fixed world volume. 
    The 'extent' refers to whether the cell's world position falls within the 
    bounding box defined by the aabb_scale. If the grid is fixed and covers 
    the maximum possible scene size (e.g., scale 32), then all cells are 
    theoretically settable for all scales if the grid resolution is sufficient.
    """
    return True
```

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Cells near the edge of the training volume may have different $N(S, C_{k,s})$ values depending on how the `aabb_scale` affects the grid's effective coverage [S1].
*   **Degenerate Input:** If a cell is outside the extent of all scales, $N(S, C_{k,s}) = 0$, leading to division by zero [S1]. Such cells are treated as empty (occupancy set to 0) [S1].

## Subtopics

### Occupancy Clustering
A subsequent step that groups connected occupied cells to identify and remove small, isolated clusters (floaters) that survived SSCS [S1]. It relies on SSCS to break coherence between geometry and artifacts [S1]. [Link](5049-instantngp-network-architecture.md)

### Instant-NGP Network Architecture
The base method that SSCS post-processes [S1]. It uses hash grids and a tiny MLP [S1]. SSCS operates on the output occupancy grids of this architecture [S1]. [Link](5049-instantngp-network-architecture.md)

## Operating characteristics
*   **Time Complexity:** $O(|S| \cdot N)$, where $|S|$ is the number of scales (typically 3) and $N$ is the number of cells in the occupancy grid [S1]. The filtering step is linear in the number of cells [S1].
*   **Memory Complexity:** $O(|S| \cdot N)$ to store the occupancy grids for all scales [S1].
*   **Performance:** Effectively removes floaters that are coherent with scene geometry, which clustering alone cannot remove [S1]. It is most effective on scenes with sparse input data where artifacts manifest differently across scales (e.g., the "garbage" dataset) [S1].
*   **Strengths:** Simple to implement; does not require additional training; improves the effectiveness of subsequent clustering [S1].
*   **Limitations:** Requires training multiple models (increasing training time and memory) [S1]. Relies on the assumption that real geometry is invariant to scale, which may not hold for all scene types [S1].
*   **When to Use:** When floaters are present and appear coherent with the scene geometry, making them resistant to simple clustering [S1].
*   **When Not to Use:** When computational resources are limited and multiple training runs are prohibitive [S1].

## Background
SSCS was introduced in "A Post Processing Technique to Automatically Remove Floater Artifacts in Neural Radiance Fields" (2023) as a method to improve the quality of NeRF reconstructions by leveraging the properties of Instant-NGP's scale-dependent training [S1]. It addresses the limitation of occupancy clustering, which fails when artifacts are connected to the main geometry [S1].
