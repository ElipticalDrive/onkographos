# INGP-NeRF

Also called: INGP, INGP-NeRF with PATA, Instant Neural Graphics Primitives with NeRF

## Overview
INGP-NeRF is a spike-based neural radiance field implementation that integrates the Instant Neural Graphics Primitives (InstantNGP) hash-grid encoding with Leaky Integrate-and-Fire (LIF) neuron dynamics for density and color estimation [S1, unofficial]. It distinguishes itself from standard NeRF MLPs by replacing continuous activations with spiking neurons to accumulate temporal estimates of radiance, enabling adaptive time-step training for enhanced reconstruction quality [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D spatial coordinates $\mathbf{x}$, view direction $\mathbf{v}$, and a discrete time step index $t$.
*   **Output:** Volume density $\sigma$ and color $\mathbf{c}$.

**Data Structures:**
1.  **Multiresolution Hash-Grid:** The spatial encoding backbone from InstantNGP, mapping coordinates to feature vectors across multiple resolutions [S1, unofficial].
2.  **Density Network:** A lightweight Multi-Layer Perceptron (MLP) with 1 hidden layer and 128 units [S1, unofficial].
3.  **Color Network:** A lightweight MLP with 2 hidden layers and 128 units [S1, unofficial].
4.  **PLIF Neurons:** Leaky Integrate-and-Fire neurons used as activation functions and output accumulators [S1, unofficial].

**Parameters:**
*   $T$: Maximum time step, set to 8 [S1, unofficial].
*   $t^*$: Initial target time step, set to 7 after the pretraining phase [S1, unofficial].

**Method Steps:**
1.  **Encoding:** Map input coordinates $\mathbf{x}$ and view direction $\mathbf{v}$ through the multiresolution hash-grid to obtain feature vectors.
2.  **Density Estimation:** Pass the spatial features through the density network. Replace all nonlinear activations with PLIF neurons. The output layer uses a PLIF neuron to accumulate the temporal estimate of density $\sigma$ [S1, unofficial].
3.  **Color Estimation:** Concatenate the view-dependent features with the density features. Pass them through the color network. Replace all nonlinear activations with PLIF neurons. The output layer uses a PLIF neuron to accumulate the temporal estimate of color $\mathbf{c}$ [S1, unofficial].
4.  **Temporal Accumulation:** The PLIF output layers integrate the spike trains over the time steps $t \in [0, T]$ to produce the final density and color values [S1, unofficial].

**Pseudocode:**
```python
def ingp_nerf_forward(x, v, t_current, T_max=8):
    """
    Forward pass for INGP-NeRF.
    x: 3D coordinates (3,)
    v: View direction (3,)
    t_current: Current time step index (int)
    T_max: Maximum time step (int)
    """
    # 1. Hash-grid encoding
    # Assumes hash_grid_encode is defined in parent InstantNGP article
    features = hash_grid_encode(x, v)
    
    # 2. Density Network
    # 1 hidden layer, 128 units
    h1 = linear_layer_1(features)
    # PLIF activation replaces standard non-linearities
    h1_spike = plif_activate(h1, t_current, T_max)
    density_raw = linear_layer_out_density(h1_spike)
    # Output PLIF layer accumulates temporal estimate
    sigma = plif_output_accumulate(density_raw, t_current, T_max)
    
    # 3. Color Network
    # Concatenate view and density features
    color_input = concatenate(features, sigma)
    # 2 hidden layers, 128 units
    h1_color = linear_layer_1_color(color_input)
    h1_color_spike = plif_activate(h1_color, t_current, T_max)
    h2_color = linear_layer_2_color(h1_color_spike)
    h2_color_spike = plif_activate(h2_color, t_current, T_max)
    color_raw = linear_layer_out_color(h2_color_spike)
    # Output PLIF layer accumulates temporal estimate
    c = plif_output_accumulate(color_raw, t_current, T_max)
    
    return sigma, c
```

**Edge Cases and Pitfalls:**
*   **Time Step Initialization:** The target time step $t^*$ must be initialized to 7 after pretraining; using a different initial value may degrade convergence [S1, unofficial].
*   **PLIF Integration:** The accumulation logic in the output PLIF layers is critical for converting spike trains into continuous density and color values [S1, unofficial].

## Subtopics

### [iNGP Texture Storage](5826-ingp-texture-storage.md)
Replaces hash-table-based feature storage with explicit 3D grid and triplane textures to leverage hardware-accelerated memory locality and texture interpolation. It reduces the number of texture fetches per neural network evaluation by storing presummed multi-resolution features, enabling a 3× reduction in fetch overhead compared to the original InstantNGP approach.

## Background
INGP-NeRF is an implementation of spike-based neural radiance fields built upon the `torch-ngp` framework [S1, unofficial]. It was introduced in the context of adaptive time-step training for enhancing spike-based neural radiance fields, aiming to improve reconstruction quality by leveraging the temporal dynamics of spiking neurons within the InstantNGP architecture [S1, unofficial].
