# Neural Volume Rendering with SDF and Background

Also called: RISE-SDF Forward Pass

## Overview
This method performs neural volume rendering by combining a Signed Distance Field (SDF) for geometry with a radiance field for appearance, explicitly handling background compositing. It differs from standard NeRF by using the SDF gradient to derive surface normals and opacity, enabling explicit surface reconstruction and normal-based shading, while extending the output to include a learned or constant background layer [S1, unofficial].

## How it works
The method implements a differentiable volume rendering pipeline where geometry is defined by an SDF network and appearance by a texture network. The rendering process samples points along rays, queries the SDF for distance and gradient, derives opacity from the distance and viewing geometry, and accumulates color and normal information. A background component is composited at the end.

### Inputs and Outputs
**Inputs:**
- `rays`: A batch of rays, typically containing origin and direction vectors.
- `positions`: 3D coordinates sampled along the rays for querying the neural fields.
- `t_dirs`: Ray directions (normalized).
- `dists`: Distances between sample points along the rays.
- `ray_indices`: Indices mapping samples to their parent rays.
- `n_rays`: Total number of rays in the batch.

**Outputs:**
- `comp_rgb`: Composite foreground RGB color.
- `opacity`: Composite foreground opacity.
- `depth`: Composite depth.
- `comp_normal`: Composite normal (normalized).
- `rays_valid`: Boolean mask for rays with non-zero opacity.
- Auxiliary data (if training): `sdf_samples`, `sdf_grad_samples`, `weights`, `points`, `intervals`.
- Background outputs: `comp_rgb_bg`, `opacity_bg` (if learned background is enabled).
- Full composite outputs: `comp_rgb_full` (foreground + background).

### Data Structures
The implementation relies on the `sdf_radiance_field` structure [S1, unofficial], which encapsulates:
- `geometry`: An MLP neural field mapping 3D positions to signed distance, gradient, and feature vectors.
- `texture`: An MLP neural field mapping features, ray direction, and normal to RGB color.
- `config`: Configuration object containing `learned_background` (boolean) and `ray_chunk` (integer for chunked batching).

### Steps
1. **Query Geometry:** For each sample position, query the geometry network to obtain the signed distance ($sdf$), its gradient ($sdf\_grad$), and intermediate features ($feature$).
   $$ sdf, sdf\_grad, feature = \text{geometry}(positions, \text{with\_grad}=True, \text{with\_feature}=True) $$
2. **Compute Normals:** Normalize the SDF gradient to obtain the surface normal ($normal$).
   $$ normal = \frac{sdf\_grad}{\|sdf\_grad\|_2} $$
3. **Compute Opacity:** Calculate the opacity ($\alpha$) for each sample using the SDF value, the surface normal, the ray direction ($t\_dirs$), and the distance intervals ($dists$). The specific formula for `get_alpha` is not detailed in the source, but it typically involves a sigmoid or similar function of the SDF value modulated by the viewing angle or distance [S1, unofficial].
   $$ \alpha = \text{get\_alpha}(sdf, normal, t\_dirs, dists) $$
4. **Compute Color:** Calculate the RGB color ($rgb$) for each sample using the features, ray direction, and surface normal.
   $$ rgb = \text{texture}(feature, t\_dirs, normal) $$
5. **Compute Weights:** Compute the ray weights ($weights$) from the opacity values using standard volume rendering accumulation logic (e.g., $w_i = \alpha_i \prod_{j<i} (1-\alpha_j)$).
   $$ weights, \_ = \text{render\_weight\_from\_alpha}(\alpha, \text{ray\_indices}, n\_rays) $$
6. **Accumulate Fields:** Accumulate opacity, depth, RGB, and normal along the rays using the computed weights.
   - Opacity: $opacity = \sum w_i$
   - Depth: $depth = \sum w_i \cdot midpoints_i$
   - RGB: $comp\_rgb = \sum w_i \cdot rgb_i$
   - Normal: $comp\_normal = \sum w_i \cdot normal_i$
7. **Normalize Composite Normal:** Normalize the accumulated normal vector.
   $$ comp\_normal = \frac{comp\_normal}{\|comp\_normal\|_2} $$
8. **Valid Ray Mask:** Identify rays with valid foreground content.
   $$ rays\_valid = opacity > 0 $$
9. **Background Handling:**
   - If `config.learned_background` is true, query the background network: `out_bg = forward_bg_(rays)`.
   - Otherwise, use a constant background color expanded to match the RGB shape.
10. **Composite Background:** Combine the foreground and background results.
    $$ comp\_rgb\_full = comp\_rgb + comp\_rgb\_bg \cdot (1.0 - opacity) $$
11. **Training Auxiliary Data:** If in training mode, attach auxiliary data (`sdf_samples`, `sdf_grad_samples`, `weights`, `points`, `intervals`, `ray_indices`) to the output for loss computation.
12. **Inference Batching:** During inference, process rays in chunks of size `config.ray_chunk` to manage memory.

### Pseudocode

```python
def forward(self, rays, training=False):
    """
    Forward pass for Neural Volume Rendering with SDF and Background.
    
    Args:
        rays: Batch of rays (origin, direction).
        training: Boolean flag for training mode.
        
    Returns:
        Dictionary containing rendered fields.
    """
    # Chunked batching for inference to manage memory
    if not training:
        return self._forward_chunked(rays)
    
    # 1. Query Geometry Network
    # positions: (N_samples, 3)
    # sdf: (N_samples, 1)
    # sdf_grad: (N_samples, 3)
    # feature: (N_samples, D_feature)
    sdf, sdf_grad, feature = self.geometry(positions=rays.positions, 
                                           with_grad=True, 
                                           with_feature=True)
    
    # 2. Compute Surface Normals
    # normal: (N_samples, 3)
    normal = F.normalize(sdf_grad, p=2, dim=-1)
    
    # 3. Compute Opacity
    # alpha: (N_samples, 1)
    # t_dirs: (N_samples, 3) - ray directions at sample points
    # dists: (N_samples, 1) - distance intervals
    alpha = self.get_alpha(sdf=sdf, 
                           normal=normal, 
                           t_dirs=rays.directions, 
                           dists=rays.dists)
    
    # 4. Compute Color
    # rgb: (N_samples, 3)
    rgb = self.texture(feature=feature, 
                       t_dirs=rays.directions, 
                       normal=normal)
    
    # 5. Compute Ray Weights
    # weights: (N_samples, 1)
    weights, _ = render_weight_from_alpha(alpha=alpha, 
                                          ray_indices=rays.indices, 
                                          n_rays=rays.n_rays)
    
    # 6. Accumulate Fields
    # opacity: (N_rays, 1)
    opacity = accumulate_along_rays(weights=weights, values=None, 
                                    ray_indices=rays.indices, n_rays=rays.n_rays)
    
    # depth: (N_rays, 1)
    depth = accumulate_along_rays(weights=weights, values=rays.midpoints, 
                                  ray_indices=rays.indices, n_rays=rays.n_rays)
    
    # comp_rgb: (N_rays, 3)
    comp_rgb = accumulate_along_rays(weights=weights, values=rgb, 
                                     ray_indices=rays.indices, n_rays=rays.n_rays)
    
    # comp_normal: (N_rays, 3)
    comp_normal = accumulate_along_rays(weights=weights, values=normal, 
                                        ray_indices=rays.indices, n_rays=rays.n_rays)
    
    # 7. Normalize Composite Normal
    comp_normal = F.normalize(comp_normal, p=2, dim=-1)
    
    # 8. Valid Ray Mask
    rays_valid = opacity > 0
    
    # 9. Background Handling
    if self.config.learned_background:
        out_bg = self.forward_bg_(rays)
        comp_rgb_bg = out_bg['comp_rgb']
        opacity_bg = out_bg['opacity']
    else:
        # Constant background color (e.g., white)
        comp_rgb_bg = torch.ones_like(comp_rgb)
        opacity_bg = torch.ones_like(opacity)
        
    # 10. Composite Background
    # comp_rgb_full: (N_rays, 3)
    comp_rgb_full = comp_rgb + comp_rgb_bg * (1.0 - opacity)
    
    # 11. Construct Output
    output = {
        'comp_rgb': comp_rgb,
        'opacity': opacity,
        'depth': depth,
        'comp_normal': comp_normal,
        'rays_valid': rays_valid,
        'comp_rgb_bg': comp_rgb_bg,
        'opacity_bg': opacity_bg,
        'comp_rgb_full': comp_rgb_full
    }
    
    # 12. Training Auxiliary Data
    if training:
        output['sdf_samples'] = sdf
        output['sdf_grad_samples'] = sdf_grad
        output['weights'] = weights
        output['points'] = positions
        output['intervals'] = dists
        output['ray_indices'] = rays.indices
        
    return output

def export_mesh(self, mesh_vertices):
    """
    Export mesh with vertex colors.
    
    Args:
        mesh_vertices: (N_vertices, 3)
        
    Returns:
        vertex_colors: (N_vertices, 3)
    """
    # Query SDF gradient and feature at mesh vertices
    sdf, sdf_grad, feature = self.geometry(positions=mesh_vertices, 
                                           with_grad=True, 
                                           with_feature=True)
    
    # Normalize gradient for normal
    normal = F.normalize(sdf_grad, p=2, dim=-1)
    
    # Compute RGB using normal as viewing direction for albedo
    # Note: Using -normal as viewing direction to simulate front-facing light
    rgb = self.texture(feature=feature, 
                       t_dirs=-normal, 
                       normal=normal)
    
    return rgb
```

### Parameters and Typical Values
- `config.learned_background`: Boolean. If true, a separate background network is used. If false, a constant color is used. [S1, unofficial]
- `config.ray_chunk`: Integer. Size of the chunk for batching rays during inference. Not given in the sources.

### Edge Cases and Pitfalls
- **Precision:** SDF gradients can be noisy near the surface, affecting normal estimation. Normalization helps but may amplify noise if the gradient magnitude is very small.
- **Boundaries:** Rays that do not intersect the object will have zero opacity. The `rays_valid` mask handles this.
- **Degenerate Input:** If `sdf_grad` is zero, normalization will fail. A small epsilon should be added to the denominator in normalization. [G]

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of samples and rays. Chunked batching reduces peak memory usage at the cost of increased overhead.
- **Memory Complexity:** Proportional to the number of samples and the feature dimension.
- **Strengths:** Explicit surface representation via SDF allows for mesh extraction and normal-based shading. Background handling is integrated.
- **Limitations:** Requires careful tuning of the SDF-to-opacity conversion. Learning background adds complexity.
- **When to Use:** When explicit surface geometry and normals are required, or when background modeling is necessary.
- **When Not to Use:** When computational efficiency is paramount and background is simple or absent.

## Background
This method is derived from the RISE-SDF implementation [S1, unofficial], which builds on the SDF NSVF models family. It utilizes the `nerf2nope_architecture` for the underlying MLP structure [S1, unofficial]. The approach integrates concepts from neural implicit representations and volume rendering, specifically leveraging the SDF for geometry and a radiance field for appearance.
