# Neural Textures


## Overview
Neural Textures is a deferred neural rendering technique that achieves novel view synthesis, scene editing, animation synthesis, or free viewpoint relighting by optimizing a high-dimensional neural texture jointly with a neural renderer [S1]. Unlike methods that optimize implicit neural fields directly in 3D space, Neural Textures maps the texture to a simple 3D proxy surface, sampling it via the standard graphics pipeline to produce features which are then decoded into an image [S1]. This approach produces standard physically based textures that are readily usable in traditional renderers, distinguishing it from pure implicit representations [S1].

## How it works
**Inputs:**
- A 3D mesh proxy representing the scene geometry.
- A neural renderer (decoder) capable of mapping texture features to pixel colors.
- A differentiable path tracer (e.g., Mitsuba 2) for gradient computation [S1].

**Outputs:**
- Optimized neural texture parameters.
- Rendered images for novel views or edited scenes.

**Data Structures:**
- **Neural Texture:** A high-dimensional feature map stored on the UV coordinates of the 3D proxy mesh. The exact dimensionality is not specified in the sources [S1].
- **Proxy Mesh:** A simplified 3D surface geometry used for texturing.

**Steps:**
1. **Proxy Mapping:** Map the high-dimensional neural texture to the UV coordinates of the simple 3D proxy surface [S1].
2. **Standard Sampling:** Sample the neural texture at the UV coordinates corresponding to the visible surface points of the proxy mesh, following the standard graphics pipeline rasterization or ray-mesh intersection steps [S1].
3. **Feature Extraction:** Retrieve the high-dimensional feature vectors from the neural texture at the sampled UV locations [S1].
4. **Neural Decoding:** Pass the extracted features into the neural renderer (decoder) to predict the final pixel color [S1].
5. **Differentiable Rendering:** Use a differentiable path tracer (such as Mitsuba 2) to render the scene and compute gradients with respect to the neural texture parameters and other unknown scene parameters (e.g., lighting, material properties) [S1].
6. **Optimization:** Update the neural texture parameters using gradient descent to minimize the difference between rendered and target images, or to achieve specific editing goals [S1].

**Parameters:**
- Learning rate for optimization: Not given in the sources.
- Neural renderer architecture: Not given in the sources.

**Edge Cases and Pitfalls:**
- **Proxy Geometry Accuracy:** The quality of the reconstruction depends heavily on the fidelity of the 3D proxy surface. If the proxy does not accurately represent the scene geometry, artifacts may occur during sampling [S1].
- **UV Distortion:** Severe UV distortion on the proxy mesh can lead to sampling artifacts in the neural texture [S1].
- **Precision:** Standard floating-point precision is assumed for the differentiable path tracer and neural network operations [S1].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.

- **Strengths:** Produces standard physically based textures usable in traditional renderers [S1]. Allows for scene editing, animation synthesis, and free viewpoint relighting [S1].
- **Limitations:** Relies on a 3D proxy surface, which may not capture complex geometry perfectly [S1].
- **When to Use:** When physically based textures are required for downstream traditional rendering pipelines [S1].
- **When Not to Use:** When high-fidelity geometry without a proxy is needed, or when real-time rendering is required without optimization [S1].

## Background
Neural Textures is part of the broader field of deferred neural rendering [S1]. The method was introduced in the paper "Material and Lighting Reconstruction for Complex Indoor Scenes with Texture-space Differentiable Rendering" [S1]. It builds upon the concept of optimizing neural textures jointly with a neural renderer [S1]. The approach leverages differentiable path tracing (e.g., Mitsuba 2) to enable gradient-based optimization of the texture and scene parameters [S1].
