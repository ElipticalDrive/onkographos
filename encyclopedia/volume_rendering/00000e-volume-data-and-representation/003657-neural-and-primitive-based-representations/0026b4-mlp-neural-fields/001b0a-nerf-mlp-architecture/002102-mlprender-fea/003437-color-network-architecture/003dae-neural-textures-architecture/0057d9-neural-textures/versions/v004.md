# Neural Textures

Also called: NeuTex

## Overview
Neural Textures is a deferred neural rendering technique that optimizes a high-dimensional neural texture jointly with a neural renderer to achieve novel view synthesis, scene editing, animation synthesis, or free viewpoint relighting [S2]. Unlike volumetric implicit fields, it maps the texture to a simple 3D proxy surface, samples it via the standard graphics pipeline to produce features, and decodes them into an image [S2]. This yields standard physically based textures compatible with traditional renderers [S2].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D proxy mesh approximating the scene geometry, initial neural texture parameters, and camera poses [S2].
- **Output:** Optimized neural texture parameters and rendered images for specified camera views [S2].

**Data Structures:**
- **Neural Texture:** A high-dimensional feature map stored on the 3D proxy surface [S2].
- **Proxy Mesh:** A simplified 3D surface with UV unwrapping that serves as the domain for the neural texture [S2].

**Steps:**
1. Recover a NeuTex model of the scene by optimizing the neural texture jointly with the renderer [S2].
2. Use the learned surface parameterization network to map 3D volume coordinates to 2D texture coordinates [S1, unofficial].
3. Sample the neural texture at the resulting UV coordinates to produce features, decode them into an image, and optimize parameters by minimizing the difference against reference images [S2].
4. After recovery, the 2D texture can be edited or replaced directly [S1, unofficial].

**Formulas:**
Let $T(u, v)$ be the neural texture function mapping UV coordinates to a feature vector $\mathbf{f}$ [G].
Let $R(\mathbf{f}, \boldsymbol{\theta})$ be the neural renderer function mapping the feature vector and camera pose $\boldsymbol{\theta}$ to a color $\mathbf{c}$ [G].
The rendered color for a pixel is:
$$ \mathbf{c} = R(T(u, v), \boldsymbol{\theta}) $$
where $(u, v)$ are the UV coordinates of the point on the proxy surface intersected by the pixel's ray [S2].

**Parameters:**
- **Optimization Method:** Stochastic gradient descent using a differentiable path tracer (e.g., Mitsuba 2) [S2].
- **Sampling:** Stratified sampling is used to reduce variance during optimization [S2].

**Edge Cases and Pitfalls:**
- **Proxy Mesh Accuracy:** The method requires a suitable proxy mesh that approximates the scene geometry [S2].
- **UV Distortion:** Not given in the sources.
- **Ambiguity:** Not given in the sources.

**Pseudocode:**
```python
import numpy as np

def optimize_neural_textures(proxy_mesh, reference_images, camera_poses, neural_renderer, learning_rate, num_iterations):
    # Initialize neural texture parameters as a learnable array
    texture_params = np.zeros(128)  # Typical feature dimension [G]
    
    for iteration in range(num_iterations):
        # Select a random reference image and its camera pose
        idx = np.random.randint(0, len(reference_images))
        ref_img = reference_images[idx]
        cam_pose = camera_poses[idx]
        
        # Render the scene using the current neural texture
        # 1. Intersect rays from camera with proxy mesh
        # 2. Get UV coordinates for intersection points
        # 3. Sample neural texture at UV coordinates to get feature vectors
        # 4. Decode feature vectors using neural renderer to get colors
        # 5. Compose colors into image
        rendered_img = neural_renderer.render(proxy_mesh, texture_params, cam_pose)
        
        # Compute loss (L2 loss between rendered and reference image)
        loss = np.mean((rendered_img - ref_img) ** 2)
        
        # Backpropagate and update texture parameters
        gradients = compute_gradients(loss, texture_params)  # Automatic differentiation [G]
        texture_params = texture_params - learning_rate * gradients
        
    return texture_params
```

## Subtopics

### [Global NTS](18021-global-nts.md)
Global NTS is a Neural Texture Stack (NTS) variant that achieves novel view synthesis by directly conditioning texture generation on the global camera pose $\boldsymbol{\theta}$, replacing the local texture embedding used in the base Neural Textures method. Unlike Local NTS, which relies on local geometric correspondence and deformation fields, Global NTS models the entire texture variation globally, allowing it to generate new topological spaces (e.g., reconstructing occluded objects like a belt on pants) but suffering from ambiguous textures due to poor information reuse across different observation spaces.

## Background
Neural Textures was introduced in the paper "Material and Lighting Reconstruction for Complex Indoor Scenes with Texture-space Differentiable Rendering" [S2]. The method builds on deferred neural rendering techniques [S2] and aims to produce physically based textures that can be used in traditional rendering pipelines [S2]. It utilizes a differentiable path tracer (Mitsuba 2) for optimization [S2].
