# Neural Textures

Also called: NeuTex

## Overview
Neural Textures is a deferred neural rendering technique that optimizes a high-dimensional neural texture jointly with a neural renderer to achieve novel view synthesis, scene editing, animation synthesis, or free viewpoint relighting [S2]. Unlike volumetric implicit fields, it maps the texture to a simple 3D proxy surface, samples it via the standard graphics pipeline to produce features, and decodes them into an image [S2]. This yields standard physically based textures compatible with traditional renderers [S2].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D proxy mesh approximating the scene geometry, initial neural texture parameters, and camera poses [S2].
- **Output:** Optimized neural texture parameters and rendered images for specified camera views [S2].

**Data Structures:**
- **Neural Texture:** A high-dimensional feature map stored on the 3D proxy surface [S2].
- **Proxy Mesh:** A simplified 3D surface with UV unwrapping that serves as the domain for the neural texture [S2].

**Steps:**
1. Define a simple 3D proxy surface that approximates the scene's geometry [S2].
2. For each pixel, determine the corresponding point on the proxy surface and sample the neural texture at the resulting UV coordinates to produce a feature vector [S2].
3. Decode the feature vector into color (and optionally transparency or other attributes) using a neural renderer [S2].
4. Compose the decoded colors into the final image, optionally integrating contributions over the pixel area using a differentiable path tracer [S2].
5. Optimize the neural texture parameters jointly with the renderer by minimizing the difference between the rendered image and reference images [S2].

**Formulas:**
Let $T(u, v)$ be the neural texture function mapping UV coordinates to a feature vector $\mathbf{f}$.
Let $R(\mathbf{f}, \boldsymbol{\theta})$ be the neural renderer function mapping the feature vector and camera pose $\boldsymbol{\theta}$ to a color $\mathbf{c}$.
The rendered color for a pixel is:
$$ \mathbf{c} = R(T(u, v), \boldsymbol{\theta}) $$
where $(u, v)$ are the UV coordinates of the point on the proxy surface intersected by the pixel's ray [S2].

## Subtopics

### [Global NTS](18021-global-nts.md)
Global NTS is a Neural Texture Stack (NTS) variant that achieves novel view synthesis by directly conditioning texture generation on the global camera pose $\boldsymbol{\theta}$, replacing the local texture embedding used in the base Neural Textures method. Unlike Local NTS, which relies on local geometric correspondence and deformation fields, Global NTS models the entire texture variation globally, allowing it to generate new topological spaces (e.g., reconstructing occluded objects like a belt on pants) but suffering from ambiguous textures due to poor information reuse across different observation spaces.

## Background
Neural Textures was introduced in the paper "Material and Lighting Reconstruction for Complex Indoor Scenes with Texture-space Differentiable Rendering" [S2]. The method builds on deferred neural rendering techniques [S2] and aims to produce physically based textures that can be used in traditional rendering pipelines [S2]. It utilizes a differentiable path tracer (Mitsuba 2) for optimization [S2].
