# CrfModel

Also called: Color Response Function Model

## Overview
The CrfModel is a color network component that applies independent, learned transformations to each RGB channel of an input color vector [S1, unofficial]. It processes the three color channels separately rather than jointly [S1, unofficial].

## How it works
**Inputs and Outputs**
- Input: A tensor `x` of shape `(batch_size, 3)` containing raw RGB values [S1, unofficial].
- Output: A tensor `rgb_out` of shape `(batch_size, 3)` containing the transformed RGB values [S1, unofficial].

**Data Structures**
The model is implemented as a class with the following parameters [S1, unofficial]:
- `net_depth`: Integer, depth of the first MLP part. Default: 1.
- `net_width`: Integer, width of the first MLP part. Default: 256.
- `net_activation`: Activation function for the first part. Default: `nn.relu`.
- `rgb_activation`: Activation function for the final output. Default: `nn.sigmoid`.
- `one_rgb_channels`: Integer, number of output channels per RGB channel. Default: 1.

**Steps**
1. Initialize a dense layer factory `dense_layer` as `functools.partial(nn.Dense, kernel_init=jax.nn.initializers.glorot_uniform())` [S1, unofficial].
2. Set `inputs_rgb = x` [S1, unofficial].
3. Extract individual channel slices: `r_e = inputs_rgb[:, 0:1]`, `g_e = inputs_rgb[:, 1:2]`, `b_e = inputs_rgb[:, 2:3]` [S1, unofficial].
4. Process the Red channel: Loop `i` from 0 to `net_depth - 1`: apply `dense_layer(net_width)(r_e)`, then `net_activation(r_e)` [S1, unofficial]. Apply `dense_layer(one_rgb_channels)(r_e)`, then `rgb_activation(r_e)` [S1, unofficial].
5. Process the Green channel: Loop `i` from 0 to `net_depth - 1`: apply `dense_layer(net_width)(g_e)`, then `net_activation(g_e)` [S1, unofficial]. Apply `dense_layer(one_rgb_channels)(g_e)`, then `rgb_activation(g_e)` [S1, unofficial].
6. Process the Blue channel: Loop `i` from 0 to `net_depth - 1`: apply `dense_layer(net_width)(b_e)`, then `net_activation(b_e)` [S1, unofficial]. Apply `dense_layer(one_rgb_channels)(b_e)`, then `rgb_activation(b_e)` [S1, unofficial].
7. Concatenate `r_e`, `g_e`, and `b_e` along axis -1 to form `rgb_out` [S1, unofficial].
8. Return `rgb_out` [S1, unofficial].

**Pseudocode**
```python
import functools
import jax
import jax.nn as nn
import jax.numpy as jnp

class CrfModel:
    def __init__(self, net_depth=1, net_width=256, net_activation=nn.relu,
                 rgb_activation=nn.sigmoid, one_rgb_channels=1):
        self.net_depth = net_depth
        self.net_width = net_width
        self.net_activation = net_activation
        self.rgb_activation = rgb_activation
        self.one_rgb_channels = one_rgb_channels
        self.dense_layer = functools.partial(
            nn.Dense,
            kernel_init=jax.nn.initializers.glorot_uniform()
        )

    def __call__(self, x):
        inputs_rgb = x
        r_e = inputs_rgb[:, 0:1]
        g_e = inputs_rgb[:, 1:2]
        b_e = inputs_rgb[:, 2:3]

        for _ in range(self.net_depth):
            r_e = self.dense_layer(self.net_width)(r_e)
            r_e = self.net_activation(r_e)
        r_e = self.dense_layer(self.one_rgb_channels)(r_e)
        r_e = self.rgb_activation(r_e)

        for _ in range(self.net_depth):
            g_e = self.dense_layer(self.net_width)(g_e)
            g_e = self.net_activation(g_e)
        g_e = self.dense_layer(self.one_rgb_channels)(g_e)
        g_e = self.rgb_activation(g_e)

        for _ in range(self.net_depth):
            b_e = self.dense_layer(self.net_width)(b_e)
            b_e = self.net_activation(b_e)
        b_e = self.dense_layer(self.one_rgb_channels)(b_e)
        b_e = self.rgb_activation(b_e)

        rgb_out = jnp.concatenate([r_e, g_e, b_e], axis=-1)
        return rgb_out
```

**Parameters**
- `net_depth`: 1 [S1, unofficial].
- `net_width`: 256 [S1, unofficial].
- `net_activation`: `nn.relu` [S1, unofficial].
- `rgb_activation`: `nn.sigmoid` [S1, unofficial].
- `one_rgb_channels`: 1 [S1, unofficial].

**Edge Cases and Pitfalls**
- The model assumes the input tensor has at least 3 channels; slicing beyond available dimensions will raise an error [G].
- The `rgb_activation` uses a sigmoid function, which constrains output values to the range $[0, 1]$ [G]. This is suitable for normalized RGB values but requires input scaling if values fall outside this range [G].
