# Hybrid View-dependent Color Modeling

Also called: Feature Voxel Grid + Shallow MLP

## Overview
This method models view-dependent color emissions by combining a sparse feature voxel grid with a shallow Multi-Layer Perceptron (MLP) [S1]. It addresses the trade-off between the slow convergence of pure neural fields and the limited expressivity of static voxel grids [S1].

## How it works
**Inputs and Outputs:**
- Query position $\mathbf{x} \in \mathbb{R}^3$ [S1].
- View direction $\mathbf{v} \in \mathbb{R}^3$ (normalized) [S1].
- Grid resolution parameter $D$ [S1].
- Output: RGB color vector $\mathbf{c} \in \mathbb{R}^3$ [S1].

**Data Structures:**
1. **Feature Voxel Grid:** A 3D grid of dimensions $D \times D \times D$ storing feature vectors $\mathbf{f}$ [S1]. The exact channel count $C_f$ of the grid entries is not given in the sources.
2. **Shallow MLP:** A 2-layer network with 128 channels per hidden layer [S1]. The input dimension is $C_f + 3$ (features concatenated with view direction) [S1]. Positional encoding is applied to features and view direction, but not position, as specified by the parent module [G]. Activation is ReLU [G]. The output layer produces 3 channels (RGB) [G].

**Numbered Steps:**
1. **Grid Lookup:** Trilinearly interpolate the feature vector $\mathbf{f}$ from the voxel grid at position $\mathbf{x}$ and resolution $D$ [S1].
2. **Encoding:** Apply positional encoding to $\mathbf{f}$ and $\mathbf{v}$ [G].
3. **Concatenation:** Form the input vector $\mathbf{z} = [\text{PE}(\mathbf{f}), \text{PE}(\mathbf{v})]$ [G].
4. **MLP Forward Pass:** Compute $\mathbf{c}$ by passing $\mathbf{z}$ through the 2-layer MLP [S1].

**Formulas:**
- Grid lookup: $\mathbf{f} = \text{TrilinearInterpolate}(\text{Grid}, \mathbf{x}, D)$ [G].
- Concatenation: $\mathbf{z} = [\text{PE}(\mathbf{f}), \text{PE}(\mathbf{v})]$ [G].
- Hidden layer 1: $\mathbf{h}_1 = \text{ReLU}(\mathbf{W}_1 \mathbf{z} + \mathbf{b}_1)$ [G].
- Hidden layer 2: $\mathbf{h}_2 = \text{ReLU}(\mathbf{W}_2 \mathbf{h}_1 + \mathbf{b}_2)$ [G].
- Output: $\mathbf{c} = \mathbf{W}_3 \mathbf{h}_2 + \mathbf{b}_3$ [G].
- Where $\mathbf{W}_1, \mathbf{W}_2 \in \mathbb{R}^{128 \times (C_f + 3)}$, $\mathbf{W}_3 \in \mathbb{R}^{3 \times 128}$, and $\mathbf{b}_1, \mathbf{b}_2, \mathbf{b}_3$ are bias vectors [G].

**Parameters:**
- $D$: Feature grid dimension. Typical values: 12 (baseline), 24 (high-res) [S1].
- MLP Layers: 2 [S1].
- MLP Channels: 128 [S1].

**Edge Cases and Pitfalls:**
- **Free Space Skipping:** To prevent out-of-memory (OOM) errors during training, a free space skipping strategy is applied using thresholds $\tau^{(c)} = 10^{-3}$ (coarse) and $\tau^{(f)} = 10^{-4}$ (fine) [S1]. Without skipping ($\tau=0$), training runs out of memory at the fine stage [S1].
- **Model Composition:** Using only the shallow MLP yields worse quality due to its shallow depth compared to deeper NeRF MLPs [S1]. Using only the voxel grid converges faster but degrades rendering quality [S1].
- **Precision:** Higher $D$ increases memory usage significantly [S1].

**Pseudocode:**
```python
def hybrid_view_dependent_color(x, v, grid, D, W1, b1, W2, b2, W3, b3):
    # 1. Grid lookup (trilinear interpolation)
    f = trilinear_interpolate(grid, x, D)
    # 2. Positional encoding (handled by parent module [G])
    f_enc = positional_encoding(f)
    v_enc = positional_encoding(v)
    # 3. Concatenation
    z = concat(f_enc, v_enc)
    # 4. MLP forward pass (2 layers, 128 channels, ReLU activation)
    h1 = relu(W1 @ z + b1)
    h2 = relu(W2 @ h1 + b2)
    c = W3 @ h2 + b3
    return c
```

## Subtopics

### Signed Residual Activation
A variant used in texture atlas baking pipelines where a signed residual is added to a per-primitive base color inside the outer ReLU of the color equation [S2, unofficial].
- **Formula:** $\text{ReLU}(\text{base} + b_{SV})$ [S2, unofficial].
- **Positive-Only Variant:** $\text{ReLU}(\text{base} + b_{SV}) + \text{ReLU}(\rho)$ [S2, unofficial].
- **Comparison:** The signed model allows both darkening and brightening, reproducing all non-negative corrections and handling darkening textures. The positive-only variant restricts correction to addition only, yielding a strictly smaller function class that fails where texture must darken the base [S2, unofficial].
- **Performance:** Signed residual improves LPIPS on 10/11 scenes and PSNR on 10/11 by 0.31 dB (Mip-NeRF 360) and 0.19 dB (Deep Blending) [S2, unofficial]. Positive-only loses ~0.5 dB PSNR and 0.01 LPIPS on indoor scenes [S2, unofficial].
- **Pitfall:** Positive-only optimization is unreliable; seed spread across runs is an order of magnitude larger than signed (e.g., stump spread 0.0773 vs 0.0042) [S2, unofficial].
- **Usage:** Used in the texture atlas baking pipeline for view-dependent color representation [S2, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- **Memory:** Scales with $D^3$ for the voxel grid. Higher $D$ increases memory usage significantly [S1].
- **Time:** Training time increases with $D$ and MLP channels. Baseline ($D=12$) takes 7.3 minutes; High-res ($D=24$) takes 8.8 minutes [S1]. Free space skipping reduces training time compared to no skipping [S1].

**Measured Performance:**
- **Baseline ($D=12$, 2 layers, 128 ch):** PSNR 35.54, Training 7.3 min [S1].
- **High-res ($D=24$, 2 layers, 128 ch):** PSNR 35.90, Training 8.8 min [S1].
- **Free Space Skipping Impact:** Skipping with $\tau^{(c)}=10^{-3}, \tau^{(f)}=10^{-4}$ yields PSNR 35.54 in 7.3 min, compared to 34.89 PSNR in 7.8 min with only $\tau^{(f)}$ applied, and OOM with no skipping [S1].

**Strengths and Limitations:**
- **Strengths:** Super-fast convergence compared to pure neural fields [S1]. Better quality than voxel-grid-only methods [S1]. Efficient memory usage via free space skipping [S1].
- **Limitations:** Shallower MLP yields worse quality than deeper NeRF MLPs if used alone [S1]. Larger $D$ and channels improve quality at higher computational cost [S1].

**When to Use:**
- Use when fast convergence is required and view-dependent effects are moderate [S1].

**When Not to Use:**
- Do not use if high-fidelity complex view-dependent effects are required and training time is not a constraint, as deeper MLPs or spherical harmonics may be preferred [S1].
- Do not use without free space skipping on scenes with large empty volumes, as it leads to out-of-memory errors [S1].

## Background
The method is part of the MLPRender_Fea module family [S1]. It addresses the limitation of shallow MLPs in neural rendering by offloading spatial invariance to a voxel grid while retaining the MLP for view-dependent details [S1].
