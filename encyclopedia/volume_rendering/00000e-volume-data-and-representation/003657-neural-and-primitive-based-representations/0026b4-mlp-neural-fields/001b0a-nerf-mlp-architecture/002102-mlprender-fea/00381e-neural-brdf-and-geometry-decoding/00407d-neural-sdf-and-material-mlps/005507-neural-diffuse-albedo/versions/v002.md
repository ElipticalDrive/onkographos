# Neural diffuse albedo
Also called: MLP Diffuse Albedo Representation
## Overview
Neural diffuse albedo predicts the spatially-varying diffuse reflectance ($\rho_d$) of a surface point using a multi-layer perceptron (MLP) [S2]. It recovers physically-based material properties from inverse rendering pipelines by mapping 3D geometry and local features to albedo values [S2]. It is distinguished from sibling material decoders by its specific input composition, which includes surface normals and geometric features, and its higher-frequency positional encoding for coordinates compared to specular or roughness predictors [S2].
## How it works
**Inputs and Outputs:**
*   **Input:** A 3D point coordinate $\mathbf{x} \in \mathbb{R}^3$, a surface normal $\mathbf{n} \in \mathbb{R}^3$, and a geometric feature vector $\mathbf{f}$ [S2].
*   **Output:** The diffuse albedo $\rho_d \in \mathbb{R}^3$ (RGB) [S2].
**Data Structures:**
The method uses an 8-layer MLP with a hidden dimension of 256 [S2]. A skip connection is added from the input to the 4th hidden layer [S2]. The input coordinate $\mathbf{x}$ is encoded using 10 frequencies [S2]. The normal $\mathbf{n}$ and geometric features $\mathbf{f}$ are concatenated directly with the encoded coordinates [S2].
**Algorithm:**
1. **Encode Coordinates:** Apply positional encoding $\gamma(\mathbf{x})$ to $\mathbf{x}$ using 10 frequencies [S2]. This expands $\mathbf{x}$ into a 20-dimensional vector [G].
2. **Prepare Input Vector:** Concatenate the encoded coordinates $\gamma(\mathbf{x})$, the surface normal $\mathbf{n}$, and the geometric features $\mathbf{f}$ to form the input vector $\mathbf{v}_{\text{in}}$ [S2].
3. **Forward Pass:** Pass $\mathbf{v}_{\text{in}}$ through the 8-layer MLP [S2].
    *   Let $W_i, b_i$ be the weights and biases for layer $i$ [S2].
    *   For layers $i=1$ to $3$: $h_i = \text{ReLU}(W_i h_{i-1} + b_i)$, where $h_0 = \mathbf{v}_{\text{in}}$ [S2].
    *   For layer $i=4$: $h_4 = \text{ReLU}(W_4 h_3 + b_4 + h_0)$ [S2].
    *   For layers $i=5$ to $8$: $h_i = \text{ReLU}(W_i h_{i-1} + b_i)$ [S2].
4. **Output:** The final layer outputs $\rho_d$ [S2]. The output is typically linear or sigmoid-normalized depending on the rendering pipeline's color space assumptions [G].
**Pseudocode:**
```python
def neural_diffuse_albedo(x, n, f_geo, weights):
    # x: (3,), n: (3,), f_geo: (D,), weights: list of (in_dim, out_dim) tuples
    x_enc = positional_encoding(x, num_frequencies=10)  # [G]
    v_in = concatenate([x_enc, n, f_geo])
    h = v_in
    for i in range(1, 9):
        W, b = weights[i-1]
        h = linear(h, W, b)
        if i == 4:
            h = h + v_in  # Skip connection
        if i < 8:
            h = relu(h)
    return h  # rho_d
```
**Parameters:**
*   Hidden dimension: 256 [S2].
*   Network depth: 8 layers [S2].
*   Skip connection: After 4th layer [S2].
*   Coordinate encoding frequency: 10 [S2].
**Edge Cases:**
*   **Normal Definition:** The method requires a valid surface normal $\mathbf{n}$ [S2]. In inverse rendering pipelines, normals are typically derived from the gradient of the Neural SDF [G]. Degenerate SDF regions may produce unstable normals [G].
*   **Feature Availability:** The geometric features $\mathbf{f}$ are output by the Neural SDF network [S2]. If the SDF is not initialized or trained, these features may be meaningless [G].
## Subtopics

### Roughplastic Material Representation
This variant integrates the neural diffuse albedo into a broader roughplastic BRDF model [S2]. It decomposes the scene's BRDF into diffuse ($\rho_d$), specular ($\rho_s$), and roughness ($\rho_r$) components using the roughplastic model for microfacet specular reflection [S2]. Spatially-varying parameters are encoded by MLPs with a positional encoding function and optimizable parameters $\Theta_d, \Theta_s, \Theta_r$ [S2]. The diffuse albedo MLP shares architectural principles with the specular and roughness predictors but is optimized separately [S2]. This approach allows for spatially-varying rough plastic materials where diffuse and specular properties are decoupled but co-located [S2].

## Operating characteristics
*   **Complexity:** The computational cost is dominated by the forward pass of an 8-layer MLP with 256 hidden units [S2]. This is lightweight compared to full rasterization but adds overhead to ray marching steps [G].
*   **Memory:** The MLP weights are stored in memory. With 8 layers, 256 hidden units, and inputs of size $(2 \times 10 + 3 + D_{\text{geo}})$, the parameter count is moderate [S2].
*   **Performance:** The use of 10 frequencies for coordinate encoding allows for high-frequency detail recovery in albedo but increases the input dimension significantly, requiring more computation per sample than lower-frequency encodings [S2].
*   **Limitations:** The method assumes the existence of a surface normal and geometric features [S2]. It does not predict albedo in free space or non-surface regions directly; it is a surface property predictor [S2].
## Background
The neural diffuse albedo decoder was introduced in PIR (Photometric Inverse Rendering with Shading Cues Modeling and Surface Reflectance Regularization) [S2]. It builds upon the Neural SDF architecture, which uses an 8-layer MLP with 256 hidden units and a skip connection at the 4th layer [S2]. The specific design choices (8 layers, 256 width, 10 frequencies for albedo vs 6 for SDF/specular) are tailored to capture the spatial variations of diffuse color while maintaining consistency with the underlying geometry [S2].
