# TensoRF Feature Decoding Architecture

Also called: TensoRF Feature Decoding Ablation

## Overview
The TensoRF Feature Decoding Architecture maps compressed feature vectors to final radiance values in the TensoRF framework [S1, unofficial]. It solves the problem of efficiently decoding appearance information from low-rank tensor factors without the computational overhead of large MLPs [S1, unofficial]. It is distinguished from its parent, Neural BRDF and Geometry Decoding, by decoding standard radiance field outputs (color) rather than explicit BRDF or normal estimation [S1, unofficial]. The architecture uses a minimal depth of 3 linear layers, which ablation studies show balances reconstruction quality with training speed [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A feature vector of dimension $mlpC$ [S1, unofficial].
*   **Output:** A vector of size 3 for color (RGB) [S1, unofficial].

**Data Structures**
The architecture consists of a sequence of linear layers with ReLU activations [S1, unofficial]. The specific layer dimensions are defined by the parameters $mlpC$ (input feature size) and $featureC$ (hidden feature size) [S1, unofficial].

**Numbered Steps**
1.  **Layer 1:** Apply a linear transformation from input dimension $mlpC$ to hidden dimension $featureC$, followed by ReLU [S1, unofficial].
    $$ h_1 = \text{ReLU}(W_1 x + b_1) $$
    where $W_1 \in \mathbb{R}^{featureC \times mlpC}$ and $b_1 \in \mathbb{R}^{featureC}$ [S1, unofficial].
2.  **Layer 2:** Apply a linear transformation from $featureC$ to $featureC$, followed by ReLU [S1, unofficial].
    $$ h_2 = \text{ReLU}(W_2 h_1 + b_2) $$
    where $W_2 \in \mathbb{R}^{featureC \times featureC}$ and $b_2 \in \mathbb{R}^{featureC}$ [S1, unofficial].
3.  **Layer 3:** Apply a linear transformation from $featureC$ to the output dimension 3 [S1, unofficial].
    $$ y = W_3 h_2 + b_3 $$
    where $W_3 \in \mathbb{R}^{3 \times featureC}$ and $b_3 \in \mathbb{R}^{3}$ [S1, unofficial].

**Parameters**
*   $mlpC$: Input feature dimension. Not given in the sources.
*   $featureC$: Hidden layer dimension. Not given in the sources.
*   Activation: ReLU [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Depth Sensitivity:** Increasing the depth beyond 3 layers (e.g., adding 3 more linear layers) did not yield significant improvements in PSNR [S1, unofficial].
*   **Residual Connections:** Adding residual connections from the initial input or alternate layers did not significantly improve performance compared to the default 3-layer architecture [S1, unofficial].
*   **Convolutional Layers:** Replacing linear layers with 1D convolutional layers reduced trainable parameters and training time but was not the default configuration [S1, unofficial].

**Pseudocode**
```python
def relu(x):
    return [max(0.0, v) for v in x]

def linear_layer(input_vec, weights, bias):
    out_dim = len(bias)
    in_dim = len(input_vec)
    result = [0.0] * out_dim
    for i in range(out_dim):
        s = bias[i]
        for j in range(in_dim):
            s += weights[i][j] * input_vec[j]
        result[i] = s
    return result

def tensoff_decoder(x, mlpC, featureC):
    # Layer 1: Linear(mlpC, featureC), ReLU
    W1 = [[0.0]*mlpC for _ in range(featureC)]
    b1 = [0.0]*featureC
    h1 = relu(linear_layer(x, W1, b1))

    # Layer 2: Linear(featureC, featureC), ReLU
    W2 = [[0.0]*featureC for _ in range(featureC)]
    b2 = [0.0]*featureC
    h2 = relu(linear_layer(h1, W2, b2))

    # Layer 3: Linear(featureC, 3)
    W3 = [[0.0]*featureC for _ in range(3)]
    b3 = [0.0]*3
    out = linear_layer(h2, W3, b3)
    return out
```

## Operating characteristics
**Time and Memory Complexity**
*   The shallow 3-layer design enables fast training, achieving results in less than 10 minutes for 2,500 iterations on downsampled data [S1, unofficial].
*   Downsampling by a factor of 4 was necessary to fit training within the hardware memory budget [S1, unofficial].

**Measured Performance**
*   On the synthetic Lego scene (100 training views, 200 test views), the default architecture achieved a Train PSNR of 31.11 and Test PSNR of 31.297 after 2,500 iterations on 4x downsampled data [S1, unofficial].
*   This performance matches NeRF's PSNR of around 31 but trains much faster [S1, unofficial].

**Strengths and Limitations**
*   **Strengths:** Fast training and sufficient reconstruction quality [S1, unofficial].
*   **Limitations:** Further depth or residual connections do not significantly improve PSNR [S1, unofficial].

**When to Use**
*   Use for standard static scene reconstruction in TensoRF where training speed and memory efficiency are priorities [S1, unofficial].

## Background
The TensoRF Feature Decoding Architecture was introduced in the TensoRF paper, which proposed low-rank tensor decomposition for efficient neural radiance fields [S1, unofficial]. An ablation study evaluated the effect of input downsampling and architectural variations on reconstruction quality [S1, unofficial]. The study found that the default 3-layer linear architecture was optimal for the given constraints [S1, unofficial].
