# Edge-aware surface rendering for neural SDFs

Also called: Edge-aware rendering for neural SDFs

## Overview
Edge-aware surface rendering for neural Signed Distance Fields (SDFs) is a technique that correctly computes gradients at edge pixels by detecting 3D edge points, reparameterizing their location to allow back-propagation along the surface normal, and blending colors from disconnected surface pieces based on subpixel edge geometry [S1]. It solves the problem where standard differentiable rendering assumes smooth surfaces within each pixel footprint, causing neural SDFs to fail to deform or converge to valid silhouettes when geometric discontinuities are present [S1]. Unlike mesh-based differentiable rendering which degrades topology without intermediate remeshing, this method allows neural SDFs to change topology readily while handling silhouettes correctly [S1].

## How it works
The method operates on a neural SDF $S_{\Theta_s}(x)$ parameterized by weights $\Theta_s$ [S1]. It processes each pixel by first determining if it contains a depth discontinuity, then localizing the edge, reparameterizing the intersection for gradient flow, and finally blending colors based on subpixel geometry [S1].

### Inputs and Outputs
*   **Inputs**: Camera origin $o$, viewing direction, neural SDF $S_{\Theta_s}$, neural material/shading function, image resolution [S1].
*   **Outputs**: Rendered color $C$ for each pixel, gradients with respect to $\Theta_s$ [S1].

### Data Structures
*   **Edge Mask**: A boolean mask of the same resolution as the image, marking pixels identified as containing depth discontinuities [S1].
*   **Subpixel Edge Coordinates**: For each edge pixel, a 2D vector $[u, v]$ representing the projected location of the 3D edge point in continuous image space [S1].
*   **2D Edge Normal**: For each edge pixel, a 2D vector $[du, dv]$ representing the projection of the 3D surface normal at the edge point [S1].

### Parameters
*   $\tau$: Threshold for depth Sobel gradient magnitude to identify depth discontinuity pixels. Value not specified in sources [S1].
*   Max Steps: Maximum iterations for the surface walk. Typical value cited as 3 to 7 [S1].

### Algorithm Steps

1.  **Localize Subpixel-Accurate 2D Edges**
    *   Perform sphere tracing on the center ray of each pixel to find the initial ray-surface intersection point $x$ and surface normal $n$ [S1].
    *   Compute the depth Sobel gradient magnitude for the current depth map. Identify pixels where this magnitude exceeds the threshold $\tau$ as depth discontinuity pixels [S1].
    *   For each depth discontinuity pixel, perform a "surface walk" starting from the intersection point $x$. Walk along a defined direction (typically tangent to the surface) for up to `Max Steps` iterations. The goal is to find a 3D edge point where the surface geometry creates a silhouette or discontinuity relative to the camera [S1].
    *   Project the detected 3D edge point to image space to obtain subpixel-accurate 2D coordinates $[u, v]$ [S1].
    *   Project the 3D surface normal $n$ at the edge point to 2D to obtain the 2D edge normal direction $[du, dv]$ [S1].
    *   Mark these pixels in the Edge Mask [S1].

2.  **Reparameterize Edge Points**
    *   For pixels marked in the Edge Mask, the standard differentiable ray-surface intersection equation only captures movement along the camera ray, which is insufficient for edge gradients [S1].
    *   Replace the viewing direction $(o - x)$ in the intersection equation with the surface normal $n$ to capture movement along the surface normal [S1].
    *   Calculate the reparameterized edge point location $x_{\Theta_s}$ using:
        $$x_{\Theta_s} = x - n \cdot S_{\Theta_s}(x)$$
        Here, $n$ is the surface normal and $S_{\Theta_s}(x)$ is the SDF value [S1]. This allows gradients to back-propagate correctly through the SDF weights for edge perturbations [S1].

3.  **Compute Shading at Edge Pixels**
    *   For an edge pixel with subpixel coordinates $[u, v]$ and 2D normal $[du, dv]$:
        *   Calculate the pixel center coordinates $[u_c, v_c]$:
            $$[u_c, v_c] = [\lfloor u \rfloor, \lfloor v \rfloor] + 0.5$$
        *   Approximate the square pixel footprint with a circle of radius $r = \frac{\sqrt{2}}{2}$ centered at $[u_c, v_c]$ [S1].
        *   Identify two 2D locations, $A$ and $B$, on this circle on either side of the edge line defined by the normal $[du, dv]$ passing through $[u, v]$ [S1].
        *   Raytrace and shade locations $A$ and $B$ using the neural SDF and material to obtain colors $C_A$ and $C_B$ [S1].
        *   Calculate the angle $\alpha$ derived from the dot product of the 2D normal and the vector from the center to the edge:
            $$\alpha = 2 \cdot \arccos\left(\sqrt{2} \cdot [du, dv] \cdot [u - u_c, v - v_c]^T\right)$$
        *   Calculate the weight $w_A$, representing the fraction of the segment area on the same side as point $A$:
            $$w_A = 1 - \frac{1}{2\pi} \cdot (\alpha - \sin \alpha)$$
        *   Blend the colors:
            $$C = w_A \cdot C_A + (1 - w_A) \cdot C_B$$
    *   For non-edge pixels, use standard differentiable ray-surface intersection and shading [S1].

### Pseudocode

```python
import math
import numpy as np

def edge_aware_rendering(camera_origin, camera_focal_length, principal_point, neural_sdf, neural_material, image_width, image_height, tau, max_steps):
    """
    Renders an image using edge-aware surface rendering for neural SDFs.
    
    Args:
        camera_origin: 3D vector, camera origin o.
        camera_focal_length: float, focal length of the camera.
        principal_point: 2D vector, principal point (cx, cy).
        neural_sdf: Function S_theta(x) returning SDF value and gradient (normal).
        neural_material: Function shading(normal, view_dir, point) returning color.
        image_width: int, width of the image.
        image_height: int, height of the image.
        tau: float, threshold for depth discontinuity detection.
        max_steps: int, maximum steps for surface walk.
        
    Returns:
        rendered_image: 2D array of shape (H, W, 3), rendered colors.
    """
    rendered_image = np.zeros((image_height, image_width, 3))
    edge_mask = np.zeros((image_height, image_width), dtype=bool)
    depth_map = np.zeros((image_height, image_width))

    # Step 0: Initial sphere tracing for all pixels to get depth and normals
    for y in range(image_height):
        for x in range(image_width):
            ray_dir = unproject_2d_to_ray(x, y, camera_origin, camera_focal_length, principal_point, image_width, image_height)
            t, point, normal = sphere_trace(camera_origin, ray_dir, neural_sdf)
            depth_map[y, x] = t

    # Detect depth discontinuities
    depth_grad_mag = compute_sobel_gradient_magnitude(depth_map)
    discontinuity_pixels = np.where(depth_grad_mag > tau)

    for y, x in zip(discontinuity_pixels[0], discontinuity_pixels[1]):
        ray_dir = unproject_2d_to_ray(x, y, camera_origin, camera_focal_length, principal_point, image_width, image_height)
        t, point, normal = sphere_trace(camera_origin, ray_dir, neural_sdf)

        # Step 1: Localize Edge via surface walk
        edge_point = point
        edge_normal = normal
        for _ in range(max_steps):
            # Walk along surface tangent direction
            walk_dir = compute_tangent(normal, ray_dir)
            # Move along tangent and project back to surface (Newton step)
            new_point = edge_point + walk_dir * 0.01
            sdf_val, grad = neural_sdf(new_point)
            edge_point = new_point - grad * sdf_val / (np.linalg.norm(grad)**2 + 1e-8)
            edge_normal = grad / (np.linalg.norm(grad) + 1e-8)

        # Project 3D edge point to 2D subpixel coordinates
        u, v = project_3d_to_2d(edge_point, camera_origin, camera_focal_length, principal_point, image_width, image_height)
        # Project 3D normal to 2D
        du, dv = project_normal_to_2d(edge_normal, camera_origin, camera_focal_length, principal_point, image_width, image_height)

        edge_mask[y, x] = True

        # Step 3: Compute Shading at Edge Pixel
        uc = math.floor(u) + 0.5
        vc = math.floor(v) + 0.5
        r = math.sqrt(2) / 2

        vec_to_edge = np.array([u - uc, v - vc])
        edge_normal_2d = np.array([du, dv])

        # Calculate angle alpha
        dot_product = np.dot(edge_normal_2d, vec_to_edge)
        arg = math.sqrt(2) * dot_product
        arg = np.clip(arg, -1.0, 1.0)
        alpha = 2 * math.acos(arg)

        # Calculate weight wA
        wA = 1 - (1 / (2 * math.pi)) * (alpha - math.sin(alpha))

        # Pick points A and B on the circle on either side of the edge
        # Tangent direction to the edge line in 2D
        tangent_dir = np.array([-dv, du])
        tangent_len = np.linalg.norm(tangent_dir)
        if tangent_len > 1e-8:
            tangent_dir /= tangent_len
        else:
            tangent_dir = np.array([1.0, 0.0])

        A_2d = np.array([uc, vc]) + r * tangent_dir
        B_2d = np.array([uc, vc]) - r * tangent_dir

        # Convert 2D to 3D rays and shade
        ray_A = unproject_2d_to_ray(A_2d[0], A_2d[1], camera_origin, camera_focal_length, principal_point, image_width, image_height)
        t_A, point_A, normal_A = sphere_trace(camera_origin, ray_A, neural_sdf)
        C_A = neural_material(normal_A, ray_A, point_A)

        ray_B = unproject_2d_to_ray(B_2d[0], B_2d[1], camera_origin, camera_focal_length, principal_point, image_width, image_height)
        t_B, point_B, normal_B = sphere_trace(camera_origin, ray_B, neural_sdf)
        C_B = neural_material(normal_B, ray_B, point_B)

        # Blend
        C = wA * C_A + (1 - wA) * C_B
        rendered_image[y, x] = C

    # Render non-edge pixels
    for y in range(image_height):
        for x in range(image_width):
            if not edge_mask[y, x]:
                ray_dir = unproject_2d_to_ray(x, y, camera_origin, camera_focal_length, principal_point, image_width, image_height)
                t, point, normal = sphere_trace(camera_origin, ray_dir, neural_sdf)
                C = neural_material(normal, ray_dir, point)
                rendered_image[y, x] = C

    return rendered_image

def sphere_trace(origin, direction, sdf, max_steps=64, max_dist=100.0):
    """Standard sphere tracing."""
    t = 0.0
    point = origin
    for _ in range(max_steps):
        dist = sdf(point)
        if dist < 1e-4:
            return t, point, sdf.gradient(point)
        if dist > max_dist:
            return t, point, sdf.gradient(point)
        t += dist
        point = origin + direction * t
    return t, point, sdf.gradient(point)

def compute_sobel_gradient_magnitude(depth_map):
    """Compute Sobel gradient magnitude."""
    kx = np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]])
    ky = np.array([[-1, -2, -1], [0, 0, 0], [1, 2, 1]])
    gx = np.convolve(depth_map.ravel(), kx.ravel(), mode='same').reshape(depth_map.shape)
    gy = np.convolve(depth_map.ravel(), ky.ravel(), mode='same').reshape(depth_map.shape)
    return np.sqrt(gx**2 + gy**2)

def compute_tangent(normal, view_dir):
    """Compute a direction tangent to the surface."""
    tangent = np.cross(normal, view_dir)
    norm = np.linalg.norm(tangent)
    if norm < 1e-8:
        tangent = np.array([1.0, 0.0, 0.0])
        if abs(np.dot(tangent, normal)) > 0.9:
            tangent = np.array([0.0, 1.0, 0.0])
    return tangent / norm

def project_3d_to_2d(point, origin, focal_length, principal_point, width, height):
    """Project 3D point to 2D image coordinates."""
    relative = point - origin
    if relative[2] <= 0:
        return 0.0, 0.0
    u = focal_length * relative[0] / relative[2] + principal_point[0]
    v = focal_length * relative[1] / relative[2] + principal_point[1]
    return u, v

def project_normal_to_2d(normal, origin, focal_length, principal_point, width, height):
    """Project 3D normal to 2D image coordinates [G]."""
    # Standard projection: align normal with camera frame and take image plane components
    view_dir = origin - normal
    view_dir = view_dir / np.linalg.norm(view_dir)
    up = np.array([0.0, 1.0, 0.0])
    if abs(np.dot(view_dir, up)) > 0.9:
        up = np.array([1.0, 0.0, 0.0])
    right = np.cross(view_dir, up)
    right = right / np.linalg.norm(right)
    up = np.cross(right, view_dir)
    n_cam_x = np.dot(normal, right)
    n_cam_y = np.dot(normal, up)
    return n_cam_x, n_cam_y

def unproject_2d_to_ray(u, v, origin, focal_length, principal_point, width, height):
    """Unproject 2D coordinates to 3D ray."""
    x = (u - principal_point[0]) / focal_length
    y = (v - principal_point[1]) / focal_length
    z = 1.0
    dir = np.array([x, y, z])
    return dir / np.linalg.norm(dir)
```

### Edge Cases and Pitfalls
*   **Precision**: The calculation of $\alpha$ involves `arccos` of a dot product. Ensure the dot product is clamped to $[-1, 1]$ to avoid numerical errors [S1].
*   **Degenerate Input**: If the surface normal is parallel to the view direction, the walk direction computation may fail. A fallback tangent must be provided [G].
*   **Topology Changes**: Unlike mesh-based methods, this method handles topology changes (e.g., holes) naturally because it relies on the SDF zero level set [S1].

## Operating characteristics
*   **Time Complexity**: The method adds overhead for edge detection (Sobel filter) and surface walking for discontinuity pixels. The surface walk is limited to `Max Steps` (3-7) and only performed on edge pixels, making it efficient [S1].
*   **Measured Performance**: The method allows convergence to valid silhouettes where IDR fails and avoids mesh degradation issues of PSDR [S1].
*   **Strengths**: Correctly handles geometric discontinuities, allows in-plane deformations, and supports topology changes [S1].
*   **Limitations**: Requires careful tuning of the threshold $\tau$ and `Max Steps` [S1].
*   **When to Use**: Use when rendering neural SDFs with complex silhouettes or topology changes [S1].

## Background
The method was introduced in the IRON (Inverse Rendering by Optimizing Neural SDFs and Materials from Photometric Images) paper [S1]. It addresses the limitations of prior neural surface rendering methods like IDR and DVR, which ignore geometric discontinuities [S1]. The method builds on the concept of differentiable rendering but extends it to handle edge pixels specifically for neural SDFs [S1].
