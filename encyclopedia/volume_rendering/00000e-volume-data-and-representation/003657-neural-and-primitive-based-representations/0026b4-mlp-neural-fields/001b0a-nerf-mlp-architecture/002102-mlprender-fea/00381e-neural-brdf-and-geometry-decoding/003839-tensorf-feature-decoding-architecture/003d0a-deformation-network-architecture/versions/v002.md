# Deformation Network Architecture
Also called: Deformation
## Overview
The Deformation Network Architecture is a lightweight multi-layer perceptron (MLP) used within the TensoRF framework to predict spatial displacements and occlusion weights for dynamic scenes [S1]. It differs from its parent, the TensoRF Feature Decoding Architecture, by explicitly handling temporal dynamics with a compact 4-layer structure to maintain computational efficiency [S1].

## How it works
**Inputs and Outputs:** The network takes a concatenated input vector consisting of position $\gamma(p) \in \mathbb{R}^3$ (3D spatial coordinates), time $\gamma(t) \in \mathbb{R}^1$ (scalar timestamp), and feature $f \in \mathbb{R}^4$ (interpolated feature vector from the voxel grid) [S1]. The network outputs displacement $\Delta p \in \mathbb{R}^3$ (offset vector) and occlusion weight $w_{occ} \in \mathbb{R}^1$ (scalar probability) [S1].

**Data Structures:** The architecture consists of four fully connected (FC) layers with a fixed width of 64 neurons [S1]. The input layer accepts 8 dimensions ($3+1+4$) and the output layer produces 4 dimensions ($3+1$) [S1].

**Activation Functions:** Hidden layers use the Rectified Linear Unit (ReLU) [S1]. The output layer applies the sigmoid function to constrain all outputs to the range $(0, 1)$ [S1].

**Algorithm:** Let $x_0 = [\gamma(p), \gamma(t), f]$. The transformation for layer $i$ is $x_i = \sigma(W_i x_{i-1} + b_i)$, where $W_i$ is the weight matrix and $b_i$ is the bias vector [S1].
1. Layer 1: $x_1 = \text{ReLU}(W_1 x_0 + b_1)$, where $W_1 \in \mathbb{R}^{64 \times 8}$ [S1].
2. Layer 2: $x_2 = \text{ReLU}(W_2 x_1 + b_2)$, where $W_2 \in \mathbb{R}^{64 \times 64}$ [S1].
3. Layer 3: $x_3 = \text{ReLU}(W_3 x_2 + b_3)$, where $W_3 \in \mathbb{R}^{64 \times 64}$ [S1].
4. Layer 4: $x_4 = \text{ReLU}(W_4 x_3 + b_4)$, where $W_4 \in \mathbb{R}^{64 \times 64}$ [S1].
5. Output: $[\Delta p, w_{occ}] = \text{Sigmoid}(W_5 x_4 + b_5)$, where $W_5 \in \mathbb{R}^{4 \times 64}$ [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class DeformationNetwork(nn.Module):
    def __init__(self):
        super(DeformationNetwork, self).__init__()
        self.fc1 = nn.Linear(8, 64)
        self.fc2 = nn.Linear(64, 64)
        self.fc3 = nn.Linear(64, 64)
        self.fc4 = nn.Linear(64, 64)
        self.fc_out = nn.Linear(64, 4)
        self.relu = nn.ReLU()
        self.sigmoid = nn.Sigmoid()

    def forward(self, pos, time, feature):
        x = torch.cat([pos, time, feature], dim=-1)
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        x = self.relu(self.fc3(x))
        x = self.relu(self.fc4(x))
        out = self.fc_out(x)
        displacement = out[:, :3]
        occlusion_weight = out[:, 3:]
        return self.sigmoid(displacement), self.sigmoid(occlusion_weight)
```

**Parameters:** Hidden width is 64 and the network has 4 hidden layers [S1]. Training uses a loss function with weights $w_{ptc}=0.1$, $w_{bg}=0.01$, $w_{d\_norm}=0.1$, and $w_{d\_tv}$ (value not given in the sources) [S1].

**Edge Cases:** The sigmoid activation on the output layer ensures $w_{occ}$ remains strictly between 0 and 1 [S1]. The displacement $\Delta p$ is also bounded to $(0, 1)$ by the same sigmoid activation, which may constrain large deformations [S1]. Progressive scale training doubles the voxel resolution after some iterations to aid convergence [S1].

## Operating characteristics
The lightweight 4-layer design makes it significantly faster to evaluate than the companion color network, which uses three layers of width 128 [S1]. Memory complexity is low due to the small parameter count [S1]. The architecture supports fast optimization of dynamic view synthesis [S1].

## Background
The Deformation Network Architecture was introduced in the paper "Neural Deformable Voxel Grid for Fast Optimization of Dynamic View Synthesis" [S1]. It is part of the TensoRF family of neural rendering methods, specifically designed to handle temporal dynamics in 3D scenes by predicting displacements from a static voxel grid representation [S1].
