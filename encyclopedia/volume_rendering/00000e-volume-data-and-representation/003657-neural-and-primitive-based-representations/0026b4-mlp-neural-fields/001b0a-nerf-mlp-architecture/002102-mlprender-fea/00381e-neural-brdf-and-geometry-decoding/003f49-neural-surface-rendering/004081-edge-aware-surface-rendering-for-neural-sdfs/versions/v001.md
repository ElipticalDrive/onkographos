# Edge-aware surface rendering for neural SDFs

Also called: Edge-aware rendering for neural SDFs

## Overview
Edge-aware surface rendering for neural Signed Distance Fields (SDFs) is a technique that correctly computes gradients at edge pixels by detecting 3D edge points, reparameterizing their location to allow back-propagation along the surface normal, and blending colors from disconnected surface pieces based on subpixel edge geometry [S1]. It solves the problem where standard differentiable rendering assumes smooth surfaces within each pixel footprint, causing neural SDFs to fail to deform or converge to valid silhouettes when geometric discontinuities are present [S1]. Unlike mesh-based differentiable rendering which degrades topology, this method allows neural SDFs to change topology readily while handling silhouettes correctly [S1].

## How it works
The method operates on a neural SDF $S_{\Theta_s}(x)$ parameterized by weights $\Theta_s$. It processes each pixel by first determining if it contains a depth discontinuity, then localizing the edge, reparameterizing the intersection for gradient flow, and finally blending colors based on subpixel geometry.

### Inputs and Outputs
*   **Inputs**: Camera origin $o$, viewing direction, neural SDF $S_{\Theta_s}$, neural material/shading function, image resolution.
*   **Outputs**: Rendered color $C$ for each pixel, gradients with respect to $\Theta_s$.

### Data Structures
*   **Edge Mask**: A boolean mask of the same resolution as the image, marking pixels identified as containing depth discontinuities.
*   **Subpixel Edge Coordinates**: For each edge pixel, a 2D vector $[u, v]$ representing the projected location of the 3D edge point in continuous image space.
*   **2D Edge Normal**: For each edge pixel, a 2D vector $[du, dv]$ representing the projection of the 3D surface normal at the edge point.

### Parameters
*   $\tau$: Threshold for depth Sobel gradient magnitude to identify depth discontinuity pixels. Value not specified in sources [S1].
*   Max Steps: Maximum iterations for the surface walk. Typical value cited as 3 to 7 [S1].

### Algorithm Steps

1.  **Localize Subpixel-Accurate 2D Edges**
    *   Perform sphere tracing on the center ray of each pixel to find the initial ray-surface intersection point $x$ and surface normal $n$ [S1].
    *   Compute the depth Sobel gradient magnitude for the current depth map. Identify pixels where this magnitude exceeds the threshold $\tau$ as depth discontinuity pixels [S1].
    *   For each depth discontinuity pixel, perform a "surface walk" starting from the intersection point $x$. Walk along a defined direction (typically tangent to the surface) for up to `Max Steps` iterations. The goal is to find a 3D edge point where the surface geometry creates a silhouette or discontinuity relative to the camera [S1].
    *   Project the detected 3D edge point to image space to obtain subpixel-accurate 2D coordinates $[u, v]$ [S1].
    *   Project the 3D surface normal $n$ at the edge point to 2D to obtain the 2D edge normal direction $[du, dv]$ [S1].
    *   Mark these pixels in the Edge Mask.

2.  **Reparameterize Edge Points**
    *   For pixels marked in the Edge Mask, the standard differentiable ray-surface intersection equation only captures movement along the camera ray, which is insufficient for edge gradients [S1].
    *   Replace the viewing direction $(o - x)$ in the intersection equation with the surface normal $n$ to capture movement along the surface normal [S1].
    *   Calculate the reparameterized edge point location $x_{\Theta_s}$ using:
        $$x_{\Theta_s} = x - n \cdot S_{\Theta_s}(x)$$
        Here, $n$ is the surface normal and $S_{\Theta_s}(x)$ is the SDF value [S1]. This allows gradients to back-propagate correctly through the SDF weights for edge perturbations [S1].

3.  **Compute Shading at Edge Pixels**
    *   For an edge pixel with subpixel coordinates $[u, v]$ and 2D normal $[du, dv]$:
        *   Calculate the pixel center coordinates $[u_c, v_c]$:
            $$[u_c, v_c] = [\lfloor u \rfloor, \lfloor v \rfloor] + 0.5$$
        *   Approximate the square pixel footprint with a circle of radius $r = \frac{\sqrt{2}}{2}$ centered at $[u_c, v_c]$ [S1].
        *   Identify two 2D locations, $A$ and $B$, on this circle on either side of the edge line defined by the normal $[du, dv]$ passing through $[u, v]$ [S1].
        *   Raytrace and shade locations $A$ and $B$ using the neural SDF and material to obtain colors $C_A$ and $C_B$ [S1].
        *   Calculate the angle $\alpha$ derived from the dot product of the 2D normal and the vector from the center to the edge:
            $$\alpha = 2 \cdot \arccos\left(\sqrt{2} \cdot [du, dv] \cdot [u - u_c, v - v_c]^T\right)$$
        *   Calculate the weight $w_A$, representing the fraction of the segment area on the same side as point $A$:
            $$w_A = 1 - \frac{1}{2\pi} \cdot (\alpha - \sin \alpha)$$
        *   Blend the colors:
            $$C = w_A \cdot C_A + (1 - w_A) \cdot C_B$$
    *   For non-edge pixels, use standard differentiable ray-surface intersection and shading [S1].

import math
import numpy as np

def edge_aware_rendering(camera_origin, viewing_direction, neural_sdf, neural_material, image_width, image_height, tau, max_steps):
    """
    Renders an image using edge-aware surface rendering for neural SDFs.
    
    Args:
        camera_origin: 3D vector, camera origin o.
        viewing_direction: 2D array of shape (H, W, 3), viewing directions for each pixel.
        neural_sdf: Function S_theta(x) returning SDF value and gradient (normal).
        neural_material: Function shading(normal, view_dir, point) returning color.
        image_width: int, width of the image.
        image_height: int, height of the image.
        tau: float, threshold for depth discontinuity detection.
        max_steps: int, maximum steps for surface walk.
        
    Returns:
        rendered_image: 2D array of shape (H, W, 3), rendered colors.
    """
    rendered_image = np.zeros((image_height, image_width, 3))
    edge_mask = np.zeros((image_height, image_width), dtype=bool)
    
    # Precompute depth map for Sobel filter
    depth_map = np.zeros((image_height, image_width))
    for y in range(image_height):
        for x in range(image_width):
            # Standard sphere tracing for center ray
            ray_dir = viewing_direction[y, x]
            t, point, normal = sphere_trace(camera_origin, ray_dir, neural_sdf)
            depth_map[y, x] = t

            # Here we just store depth for edge detection
            
    # Detect depth discontinuities
    # Compute Sobel gradient magnitude on depth_map
    depth_grad_mag = compute_sobel_gradient_magnitude(depth_map)
    discontinuity_pixels = np.where(depth_grad_mag > tau)
    
    for y, x in zip(discontinuity_pixels[0], discontinuity_pixels[1]):
        ray_dir = viewing_direction[y, x]
        
        # Step 1: Localize Edge
        # Initial intersection
        t, point, normal = sphere_trace(camera_origin, ray_dir, neural_sdf)
        
        # Surface walk to find 3D edge point
        edge_point = point
        edge_normal = normal
        for step in range(max_steps):
            # Walk along surface tangent direction
            # Define tangent direction perpendicular to normal and view direction
            # Or use a predefined walk direction as per Alg 1 in source
            # Assuming a generic walk direction 'walk_dir' derived from normal and view
            walk_dir = compute_walk_direction(normal, ray_dir)

            # We approximate by moving along the tangent plane

            new_point = edge_point + walk_dir * step_size

            # The source says "walk on the surface along the direction defined"
            # We assume the walk direction keeps us on the zero level set or close to it
            # For implementation, one might use Newton-Raphson to project back to surface
            sdf_val, grad = neural_sdf(new_point)
            # Project back to surface
            edge_point = new_point - grad * sdf_val / np.linalg.norm(grad)**2
            edge_normal = grad / np.linalg.norm(grad)
            
            # Check for edge condition (e.g., silhouette)
            # Source implies reaching a 3D edge point. 
            # In practice, this might be detected by the depth discontinuity logic 
            # or by checking if the point is on the silhouette.
            # Since we started from a discontinuity pixel, we assume the walk finds the edge.
            if is_edge_point(edge_point, edge_normal, camera_origin):
                break
        
        # Project 3D edge point to 2D subpixel coordinates
        u, v = project_to_image(edge_point, camera_origin, viewing_direction[y, x])
        
        # Project 3D normal to 2D
        du, dv = project_normal_to_2d(edge_normal, camera_origin, viewing_direction[y, x])
        
        edge_mask[y, x] = True
        
        # Step 2: Reparameterize (Implicit in shading for edge pixels)
        # The reparameterization x_theta = x - n * S(x) is used for gradient flow.
        # In shading, we use the edge point location.
        
        # Step 3: Compute Shading
        # Pixel center
        uc = math.floor(u) + 0.5
        vc = math.floor(v) + 0.5
        
        # Circle radius
        r = math.sqrt(2) / 2
        
        # Define edge line in 2D: passing through (u, v) with normal (du, dv)
        # Points A and B are on the circle on either side of the edge
        # Vector from center to edge
        vec_to_edge = np.array([u - uc, v - vc])
        
        # Normalize vec_to_edge
        vec_to_edge_norm = vec_to_edge / np.linalg.norm(vec_to_edge)

        # Note: The source formula uses sqrt(2) * dot product.

        dot_product = np.dot(edge_normal_2d_norm, vec_to_edge_norm)

        dot_product = np.clip(dot_product, -1.0, 1.0)
        
        alpha = 2 * math.acos(math.sqrt(2) * dot_product)

        # For implementation, we can pick A and B as the intersections of the circle with the line

        # The source implies A and B are specific points. 
        # Let's assume A and B are chosen such that the line segment AB is the chord defined by the edge line?
        # No, A and B are points on the circle.
        # Let's pick A and B as the points on the circle that are furthest from the edge line?
        # Or simply pick two points symmetric with respect to the edge normal?
        # Given the ambiguity, we pick A and B as the points on the circle where the edge line intersects?
        # No, the edge line passes through (u,v) which is inside the circle.
        # The edge line divides the circle into two segments.
        # A and B are likely the midpoints of the arcs? Or just any two points on opposite sides.
        # The source says "Pick 2D locations A and B on the circle on either side of the edge."
        # And "Raytrace and shade these locations".
        # To be deterministic, let's pick A and B as the points on the circle along the direction 
        # perpendicular to the edge normal, i.e., along the tangent of the edge.
        # Tangent direction in 2D: (-dv, du)
        tangent_dir = np.array([-dv, du])
        tangent_dir_norm = tangent_dir / np.linalg.norm(tangent_dir)
        
        A_2d = np.array([uc, vc]) + r * tangent_dir_norm
        B_2d = np.array([uc, vc]) - r * tangent_dir_norm
        
        # Convert 2D coordinates back to 3D rays
        ray_A = unproject_2d_to_ray(A_2d, camera_origin, viewing_direction)
        ray_B = unproject_2d_to_ray(B_2d, camera_origin, viewing_direction)
        
        # Raytrace and shade
        t_A, point_A, normal_A = sphere_trace(camera_origin, ray_A, neural_sdf)
        C_A = neural_material(normal_A, ray_A, point_A)
        
        t_B, point_B, normal_B = sphere_trace(camera_origin, ray_B, neural_sdf)
        C_B = neural_material(normal_B, ray_B, point_B)
        
        # Blend
        C = wA * C_A + (1 - wA) * C_B
        rendered_image[y, x] = C

    # Render non-edge pixels
    for y in range(image_height):
        for x in range(image_width):
            if not edge_mask[y, x]:
                ray_dir = viewing_direction[y, x]
                t, point, normal = sphere_trace(camera_origin, ray_dir, neural_sdf)
                # Standard differentiable intersection
                # x_theta = x - (o - x) / (n^T(o - x)) * S(x)
                # But for shading, we just use the point
                C = neural_material(normal, ray_dir, point)
                rendered_image[y, x] = C
                
    return rendered_image

### Edge Cases and Pitfalls
*   **Precision**: The calculation of $\alpha$ involves `arccos` of a dot product. Ensure the dot product is clamped to $[-1, 1]$ to avoid numerical errors [S1].
*   **Boundaries**: The surface walk must handle cases where the edge is not found within `Max Steps`. In such cases, fallback to standard rendering or mark as non-edge [S1].
*   **Degenerate Input**: If the surface normal is parallel to the view direction, the walk direction computation may fail. A fallback tangent must be provided [G].
*   **Topology Changes**: Unlike mesh-based methods, this method handles topology changes (e.g., holes) naturally because it relies on the SDF zero level set [S1].

## Subtopics

### Neural Surface Rendering
The parent method that uses a neural shader to approximate PBR. Edge-aware rendering is a specific technique within this family to handle silhouettes [9960-neural-surface-rendering.md].

### IDR (Implicit Depth Representation)
A prior neural surface rendering method that assumes smooth surfaces and fails to deform SDFs to match silhouettes [S1].

### PSDR (Pixel-Space Differentiable Rendering)
A mesh-based differentiable rendering method that can handle silhouettes but degrades mesh quality without intermediate remeshing [S1].

## Operating characteristics
*   **Time Complexity**: The method adds overhead for edge detection (Sobel filter) and surface walking for discontinuity pixels. The surface walk is limited to `Max Steps` (3-7) and only performed on edge pixels, making it efficient [S1].
*   **Memory Complexity**: Requires storing the depth map, edge mask, and subpixel edge coordinates. Memory usage is linear with image resolution [S1].
*   **Measured Performance**: The method allows convergence to valid silhouettes where IDR fails and avoids mesh degradation issues of PSDR [S1].
*   **Strengths**: Correctly handles geometric discontinuities, allows in-plane deformations, and supports topology changes [S1].
*   **Limitations**: Requires careful tuning of the threshold $\tau$ and `Max Steps`. The surface walk may not always find the exact edge point if the initial intersection is far from the edge [S1].
*   **When to Use**: Use when rendering neural SDFs with complex silhouettes or topology changes. Avoid if performance is critical and scenes are simple [S1].

## Background
The method was introduced in the IRON (Inverse Rendering by Optimizing Neural SDFs and Materials from Photometric Images) paper [S1]. It addresses the limitations of prior neural surface rendering methods like IDR and DVR, which ignore geometric discontinuities [S1]. The method builds on the concept of differentiable rendering but extends it to handle edge pixels specifically for neural SDFs [S1].
