# TensoRF Feature Decoding Architecture

Also called: TensoRF Feature Decoding Ablation

## Overview
The TensoRF Feature Decoding Architecture maps compressed feature tensors to volume density (sigma) and RGB color values [S1, unofficial]. It distinguishes itself from sibling methods by relying on a shallow, ablation-verified sequence of linear layers optimized for rapid training and low memory overhead on synthetic scenes, rather than explicit BRDF parameterization [S1, unofficial].

## How it works
**Inputs and Outputs:**
The decoder takes a feature vector of dimension $mlpC$ and outputs a 3-channel color vector and a scalar density [S1, unofficial].

**Data Structures:**
The architecture consists of a sequence of fully connected linear layers [S1, unofficial].

**Default Architecture Steps:**
1. Input feature vector $x_0 \in \mathbb{R}^{mlpC}$ [S1, unofficial].
2. $x_1 = \text{ReLU}(W_1 x_0 + b_1)$, where $W_1 \in \mathbb{R}^{featureC \times mlpC}$ [S1, unofficial].
3. $x_2 = \text{ReLU}(W_2 x_1 + b_2)$, where $W_2 \in \mathbb{R}^{featureC \times featureC}$ [S1, unofficial].
4. $c = W_3 x_2 + b_3$, where $W_3 \in \mathbb{R}^{3 \times featureC}$ [S1, unofficial].

**Parameters:**
$featureC$ denotes the hidden layer width [S1, unofficial]. Training used 2,500 iterations on data downsampled by a factor of 4 [S1, unofficial].

**Pseudocode:**
```python
def linear(x, W, b):
    """Matrix-vector multiplication and bias addition."""
    return [sum(x[j] * W[i][j] for j in range(len(x))) + b[i] for i in range(len(W))]

def relu(x):
    """Element-wise ReLU activation."""
    return [max(0.0, v) for v in x]

def decode_feature_default(feature_vector, featureC, mlpC, W1, b1, W2, b2, W3, b3):
    """Default TensoRF feature decoding architecture."""
    x = linear(feature_vector, W1, b1)
    x = relu(x)
    x = linear(x, W2, b2)
    x = relu(x)
    color = linear(x, W3, b3)
    return color
```

**Variants from Ablation:**
1. **Convolutional Layers:** Replaced linear layers with 1D convolutional layers with small kernel sizes to reduce parameters and speed up training [S1, unofficial].
2. **Residual from Initial Input:** Added residual connections from the initial input to each subsequent layer in sigma and color MLPs by concatenating a part of the input to each following layer [S1, unofficial].
3. **Residual from Alternate Layers:** Added residual connections from 2 layers before each layer to preserve information while tuning parameters [S1, unofficial].
4. **Deeper Network:** Added 3 linear layers along with residuals from sigma layers to increase parameters for better color output [S1, unofficial].

**Edge Cases:**
Adding/removing linear layers or changing depths (e.g., 5 layers with sizes 64, 32, 16, 8) did not make significant improvements in PSNR [S1, unofficial].

## Subtopics

### Deformation Network Architecture
It takes position (33), time (11), and feature (44) as input [S2]. It consists of four fully connected layers with width 64 [S2]. Activations are ReLU between layers, and Sigmoid for the outputs [S2]. The output is a 3D displacement vector and a 1D occlusion weight [S2].

## Operating characteristics
*   **Time Complexity:** The shallow 3-layer design enables fast training (less than 10 minutes on downsampled data) [S1, unofficial].
*   **Memory Complexity:** Low parameter count; downsampling by factor 4 was required to fit within memory budgets [S1, unofficial].
*   **Performance:** On the synthetic Lego scene (100 train, 200 test views), the default architecture achieved a Test PSNR of 31.297 in 2,500 iterations, comparable to NeRF's ~31 PSNR but with faster convergence [S1, unofficial].
*   **Strengths:** Fast training, low parameter count, sufficient reconstruction quality for synthetic scenes [S1, unofficial].
*   **Limitations:** Ablation showed that deeper networks or residual connections did not significantly improve PSNR, suggesting the default 3-layer linear setup is near-optimal for this specific representation [S1, unofficial].
*   **When to use:** When computational efficiency is prioritized and the scene is static or can be approximated with the default feature decoding [S1, unofficial].
*   **When not to use:** If higher fidelity is required and the ablation results suggest diminishing returns from added complexity [S1, unofficial].

## Background
The architecture was evaluated in an ablation study to probe the underlying decoder design of TensoRF [S1, unofficial]. The study aimed to determine the optimal depth and connectivity for the feature decoding MLP [S1, unofficial]. The default 3-layer linear configuration was found to be sufficient, achieving performance comparable to the original NeRF but with significantly reduced training time [S1, unofficial]. The deformation network variant was introduced in subsequent work on dynamic view synthesis to handle temporal deformations [S2].
