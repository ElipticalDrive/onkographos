# Affine Generative Latent Optimization

Also called: Affine GLO, Affine transformation of bottleneck vector

## Overview
Affine Generative Latent Optimization (Affine GLO) is a technique for modeling per-image appearance variation in neural radiance fields by learning an affine transformation of a latent bottleneck vector. It addresses the problem of synthesizing novel views of large-scale outdoor scenes where appearance changes significantly across different viewpoints or time. It distinguishes itself from vanilla NeRF [1] and multi-stage methods like BungeeNeRF [7] by using an attention-based feature fusion module to integrate features from a set of $V$ source images, enabling end-to-end training that converges significantly faster (1 day vs. 5 days on RTX 4090) while achieving higher reconstruction quality (approx. 6 dB PSNR gain over BungeeNeRF).

## How it works
**Inputs and Outputs:**
*   **Input:** A set of training images. For each image, a latent vector is allocated.
*   **Output:** A transformed latent vector used as input to the view-dependent MLP for color prediction.

**Data Structures:**
*   **Latent Vector:** A 128-length vector allocated for each image in the training set [S1].
*   **Transformation MLP:** A two-layer Multi-Layer Perceptron (MLP) with 128 hidden units [S1].
    *   **Input:** The 128-length latent vector.
    *   **Hidden Layer:** 128 units, ReLU activation [S1].
    *   **Output:** Two vectors, `scale` and `shift`, each of length 128 (same length as the bottleneck vector) [S1].
    *   **Final Activation:** The `scale` output uses an exponential (`exp`) activation function; the `shift` output uses linear activation [S1].

**Parameters:**
*   Latent vector length: 128 [S1].
*   MLP hidden units: 128 [S1].

**Steps:**
1.  Allocate a 128-length latent vector for each image in the training set [S1].
2.  Pass the latent vector through the two-layer MLP (128 hidden units, ReLU activation) to produce `scale` and `shift` vectors [S1].
3.  Apply the affine transformation to the bottleneck vector $z$ using the outputs:
    $$ z' = \text{scale} \odot z + \text{shift} $$
    where $\odot$ denotes element-wise multiplication [S1].
4.  Use the transformed vector $z'$ as input to the view-dependent MLP for color prediction [S1].

**Pitfalls:**
*   This technique is only used for video results and does not improve quantitative performance on metrics [S1].

## Subtopics
## Operating characteristics
*   **Training Speed:** Faster training than the GLO baseline, allowing the model to more easily explain per-image appearance variation without placing floaters in front of training cameras [S1].
*   **Convergence:** End-to-end training converges significantly faster (1 day vs. 5 days on RTX 4090) [S1].
*   **Quality:** Achieves higher reconstruction quality (approx. 6 dB PSNR gain over BungeeNeRF) [S1].
*   **Limitations:** Does not improve quantitative performance on metrics for static scene reconstruction [S1].

## Background
Affine Generative Latent Optimization is part of the Zip-NeRF framework, which introduces anti-aliased grid-based neural radiance fields. The method was proposed in the paper "Zip-NeRF: Anti-Aliased Grid-Based Neural Radiance Fields" [S1]. It builds on prior techniques in the literature for modulating activations to control “style” and appearance [S1].
