# Generator (NeRF Wrapper with Latent Code & Near/Far Adjustment)

Also called: Latent Code NeRF Generator, NeRF Wrapper with Latent Code

## Overview
This module wraps a Neural Radiance Field (NeRF) network to render images conditioned on a latent code $z$, enabling generative modeling of 3D scenes via GAN training [S1, unofficial]. It differs from standard NeRF renderers by dynamically adjusting near and far clipping planes based on the camera's distance from the origin and injecting the latent code into the network's feature space [S1, unofficial]. It builds on [AG-NeRF Training Objective](8502-ag-nerf-training-objective.md) by providing the forward pass mechanism required for the generator's training loop.

## How it works
**Inputs:**
- $z$: Latent code tensor of shape $(N, z_{dim})$.
- $y$: Optional class label or condition tensor.
- $H, W$: Image height and width.
- $focal$: Camera focal length.
- $radius$: Float or tuple $(r_{min}, r_{max})$ defining the spherical sampling range for camera poses.
- $render\_kwargs$: Dictionary containing rendering parameters (e.g., `near`, `far`, `chunk`, `raw_noise_std`).

**Outputs:**
- Rendered RGB image tensor (normalized to $[-1, 1]$).
- Optional depth, accumulation, and auxiliary maps in test mode.

**Data Structures:**
- `render_kwargs`: A dictionary passed to the underlying NeRF renderer. Key fields include:
  - `near`: Near plane distance (float or tensor).
  - `far`: Far plane distance (float or tensor).
  - `features`: The latent code $z$ injected into the network.
  - `chunk`: Integer batch size for chunked rendering.
  - `raw_noise_std`: Standard deviation for noise added to raw density values.

**Steps:**
1. **Initialization**: Store image dimensions ($H, W$), focal length, radius configuration, ray sampler, and render kwargs. Initialize validation coordinate buffers [S1, unofficial].
2. **Ray Generation**: If rays are not provided, generate them using `sample_rays()`. This involves sampling camera poses within the specified spherical ranges (`range_u`, `range_v`) and computing ray origins and directions via the camera intrinsics [S1, unofficial].
3. **Kwargs Selection**: Select training or testing render kwargs based on the current mode (`use_test_kwargs`). Create a copy to avoid mutating shared state [S1, unofficial].
4. **Near/Far Adjustment**: If `radius` is a tuple $(r_{min}, r_{max})$, adjust the clipping planes to ensure the scene remains within bounds relative to the camera's distance:
   - Compute the norm of each ray origin: $r_o = \|o\|$ [S1, unofficial].
   - Compute the shift: $shift = (r_{max} - r_o) \cdot \mathbf{1}$ [S1, unofficial].
   - Update planes: $near_{new} = near_{old} - shift$, $far_{new} = far_{old} - shift$ [S1, unofficial].
   - Assert $near_{new} \ge 0$ and $far_{new} \ge 0$ [S1, unofficial].
5. **Latent Injection**: Set `render_kwargs['features'] = z` [S1, unofficial].
6. **Rendering**: Call the underlying NeRF renderer with the adjusted kwargs and rays [S1, unofficial].
7. **Post-processing**: Apply the transformation $x_{out} = x_{in} \cdot 2 - 1$ to map outputs from $[0, 1]$ to $[-1, 1]$ [S1, unofficial].
8. **Noise Decay**: During training, linearly decay `raw_noise_std` from `initial_raw_noise_std` to $0$ over the first 5000 iterations [S1, unofficial].

import torch.nn as nn

class NeRFGenerator(nn.Module):
    def __init__(self, nerf_network, H, W, focal, radius, ray_sampler, 
                 render_kwargs_train, render_kwargs_test, chunk=1024*3, 
                 initial_raw_noise_std=0.0, end_it=5000):
        super().__init__()
        self.nerf = nerf_network
        self.H = H
        self.W = W
        self.focal = focal
        self.radius = radius
        self.ray_sampler = ray_sampler
        self.render_kwargs_train = render_kwargs_train
        self.render_kwargs_test = render_kwargs_test
        self.chunk = chunk
        self.initial_raw_noise_std = initial_raw_noise_std
        self.end_it = end_it
        self.current_it = 0
        
    def decrease_nerf_noise(self):
        """Linearly decay raw_noise_std from initial to 0 over end_it iterations."""
        if self.current_it < self.end_it:
            decay_factor = 1.0 - (self.current_it / self.end_it)
            noise_std = self.initial_raw_noise_std * decay_factor
        else:
            noise_std = 0.0
        return noise_std

    def forward(self, z, y=None, rays=None, is_training=True):
        """
        Render image conditioned on latent code z.
        """
        # 1. Generate rays if not provided
        if rays is None:
            rays = self.sample_rays()
            
        # 2. Select render kwargs
        if is_training:
            render_kwargs = self.render_kwargs_train.copy()
        else:
            render_kwargs = self.render_kwargs_test.copy()
            
        # 3. Adjust near/far planes if radius is a tuple
        if isinstance(self.radius, tuple):
            r_min, r_max = self.radius
            # Compute norm of ray origins
            # rays[0] is typically the origin tensor
            rays_radius = rays[0].norm(dim=-1) # Shape: (N_rays,)
            
            # Compute shift
            # shift = (r_max - rays_radius)
            shift = (r_max - rays_radius).view(-1, 1).float()
            
            # Update near and far
            # Note: render_kwargs['near'] and ['far'] might be scalars or tensors
            # Assuming they are broadcastable or scalars
            render_kwargs['near'] = render_kwargs['near'] - shift
            render_kwargs['far'] = render_kwargs['far'] - shift
            
            # Assert bounds
            assert torch.all(render_kwargs['near'] >= 0), "Near plane became negative"
            assert torch.all(render_kwargs['far'] >= 0), "Far plane became negative"
            
        # 4. Inject latent code
        render_kwargs['features'] = z
        
        # 5. Handle noise decay for training
        if is_training:
            current_noise = self.decrease_nerf_noise()
            render_kwargs['raw_noise_std'] = current_noise
            self.current_it += 1
            
        # 6. Render
        # Assuming render function signature: render(H, W, focal, chunk, rays, **kwargs)
        rgb, disp, acc, extras = render(
            self.H, self.W, self.focal, self.chunk, rays, **render_kwargs
        )
        
        # 7. Post-process
        # Map from [0, 1] to [-1, 1]
        # rays_to_output = lambda x: x.view(len(x), -1) * 2 - 1
        # Note: The source snippet suggests reshaping for batch output
        rgb_out = rgb.view(rgb.shape[0], -1) * 2 - 1
        
        if not is_training:
            return rgb_out, disp, acc, extras
        else:
            return rgb_out

**Parameters:**
- `radius`: Controls the camera sampling distance. If a tuple, it triggers dynamic near/far adjustment [S1, unofficial].
- `raw_noise_std`: Controls the magnitude of noise added to the raw density output of the NeRF, aiding in sharpness during GAN training [S1, unofficial].
- `chunk`: Batch size for chunked rendering to manage GPU memory usage [S1, unofficial].

**Edge Cases:**
- **Negative Planes**: If the camera is too close to the origin relative to `r_max`, the adjusted `near` plane may become negative. The implementation asserts against this [S1, unofficial].
- **Ray Origin Norm**: The calculation assumes ray origins are normalized or scaled consistently with the radius definition [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of pixels ($H \times W$) and the number of sampled points per ray. Chunked rendering adds overhead but prevents OOM errors.
- **Memory Complexity**: Dominated by the NeRF network weights and the intermediate activation maps for the chunked rays. The latent code $z$ adds negligible memory overhead.
- **Strengths**: Enables conditional generation of 3D-consistent images. Dynamic near/far adjustment ensures robust rendering across varying camera distances without manual clipping plane tuning.
- **Limitations**: Performance is bound by the underlying NeRF's MLP evaluation speed. The noise decay schedule is fixed and may not be optimal for all datasets.
- **When to use**: When training a GAN for 3D-aware image synthesis where the generator needs to output consistent 3D structures conditioned on latent codes.

## Background
This method is part of the GRAF (Generative Radiance Fields) framework and its variants, specifically adapted for single X-ray to 3D CT reconstruction in the DeepScan3D project [S1, unofficial]. It extends the standard NeRF architecture by integrating generative latent codes and GAN-specific training techniques such as raw noise injection and dynamic clipping [S1, unofficial].
