# Fast NeRF Composition Pipeline

Also called: Deferred Shading with NeDF, NeDF Rendering Pipeline

## Overview
The Fast NeRF Composition Pipeline is a three-step rendering framework that replaces traditional ray marching with a single-sample evaluation per pixel to achieve interactive-level speeds for previewing composed NeRF scenes [S1]. It builds on Neural Depth Fields (NeDF) to generate depth and object ID buffers, enabling deferred shading and shadow casting without querying complex spatial structures [S1].

## How it works
The pipeline consists of three sequential stages: NeDF Generation, Deferred Shading, and Shadow Casting [S1].

### Inputs and Outputs
*   **Inputs:** Camera origin $\mathbf{o}$, ray directions $\mathbf{d}$, affine transformation parameters $G(R, T, s)$ for each object, and the trained NeRF models $\mathcal{F}_\Theta$ and intersection networks $\mathcal{F}_\Phi$ [S1].
*   **Outputs:** Color buffer $\mathbf{C}$, Depth buffer $\hat{D}$, Object ID buffer, and Shadow buffer [S1].

### Data Structures
*   **Depth Buffer:** A 2D array where each element corresponds to a pixel, storing the estimated global depth $\hat{D}(\mathbf{r})$ [S1].
*   **Object ID Buffer:** A 2D array storing the identifier of the object intersected by the ray at that pixel [S1].
*   **Color Buffer:** A 2D array storing the raw color $\mathbf{c}$ without shadow information [S1].
*   **Shadow Buffer:** A 2D array storing shadow intensity information [S1].

### Steps

1.  **NeDF Generation:**
    For each ray $\mathbf{r}$ originating from $\mathbf{o}$ with direction $\mathbf{d}$, compute the depth $\hat{D}(\mathbf{r})$ in global space using the inverse affine transformation $\mathcal{G}^{-1}$ and the intersection network $\mathcal{F}_\Phi$ [S1]. The formula is:
    $$
    \hat{D}(\mathbf{r}) = |\mathbf{o} - \mathbf{p}_\perp| - s \left( \mathcal{S}^{-1} \circ \mathcal{F}_\Phi \right) (\mathcal{G}^{-1}(\mathbf{r}))
    $$
    where $\mathcal{G}^{-1}$ transforms the ray to canonical space, $s$ is the scale factor, $\mathbf{p}_\perp$ is the projection of the object's local origin onto the ray direction, and $\mathcal{S}^{-1}$ is the inverse of the signed distance function mapping [S1]. Store $\hat{D}(\mathbf{r})$ in the Depth Buffer and the corresponding object ID in the Object ID Buffer [S1].

2.  **Deferred Shading:**
    Using the depth $\hat{D}(\mathbf{r})$ and object ID from the previous step, compute the color $\mathbf{c}$ and density $\sigma$ by evaluating the NeRF model $\mathcal{F}_\Theta$ at the intersection point [S1]:
    $$
    \mathbf{c}, \sigma = \mathcal{F}_\Theta \left( \mathcal{G}^{-1}(\mathbf{o} + \hat{D}(\mathbf{r})\mathbf{d}), \mathcal{G}^{-1}(\mathbf{d}) \right)
    $$
    The color $\mathbf{c}$ is stored in the Color Buffer [S1]. The density $\sigma$ is used to validate the depth estimate [S1].

3.  **Shadow Step:**
    Generate shadow information using shadow rays, the depth buffer $\hat{D}(\mathbf{r})$, and the original rays $\mathbf{r}$ [S1]. (Specific shadow casting algorithm details are not provided in the sources, but it utilizes the depth information to determine occlusion) [S1].

### Parameters and Edge Cases
*   **Density Threshold:** If $\sigma$ is extremely small, $\hat{D}$ is considered invalid because the ray did not reach the object surface [S1].
*   **Outlier Processing:** An optional step can resample pixels with invalid depth using the primary volume render equation for better quality, at a speed penalty [S1].
*   **Lighting:** The pipeline simplifies lighting by shading only with primary color, ignoring complex lighting conditions from the original object collection space [S1].

### Pseudocode

```python
import math

def fast_nerf_composition_pipeline(camera_origin, ray_directions, objects):
    """
    Executes the Fast NeRF Composition Pipeline.
    
    Args:
        camera_origin: 3D tuple (x, y, z), origin of the camera.
        ray_directions: List of 3D tuples, one per pixel.
        objects: List of dicts, each containing:
            - 'id': Unique integer identifier.
            - 'G_inv': Function taking (origin, direction) -> (canonical_origin, canonical_direction).
            - 's': Scale factor.
            - 'F_Phi': Intersection network function.
            - 'F_Theta': NeRF model function.
            - 'local_origin': 3D tuple, object's origin in world space.
            
    Returns:
        color_buffer: List of 3D color tuples.
        depth_buffer: List of float depths.
        id_buffer: List of integer object IDs.
        shadow_buffer: List of float shadow intensities.
    """
    num_pixels = len(ray_directions)
    depth_buffer = [0.0] * num_pixels
    id_buffer = [-1] * num_pixels
    color_buffer = [None] * num_pixels
    shadow_buffer = [1.0] * num_pixels
    
    # Step 1: NeDF Generation
    for i, d in enumerate(ray_directions):
        best_depth = float('inf')
        best_id = -1
        
        for obj in objects:
            # Transform ray to canonical space
            c_o, c_d = obj['G_inv'](camera_origin, d)
            
            # Compute p_perp: projection of object's local origin onto the ray
            t = dot(obj['local_origin'] - camera_origin, d)
            p_perp = vector_add(camera_origin, vector_scale(d, t))
            dist_o_p_perp = norm(camera_origin - p_perp)
            
            # Query intersection network
            # [S1] The exact form of S^-1 is not specified in the sources.
            # We assume F_Phi outputs a value that S^-1 maps to depth.
            phi_output = obj['F_Phi'](c_o, c_d)
            depth_component = phi_output 
            
            # Apply formula: D_hat(r) = |o - p_perp| - s * (S^-1 o F_Phi)(G^-1(r))
            depth = dist_o_p_perp - obj['s'] * depth_component
            
            if depth < best_depth:
                best_depth = depth
                best_id = obj['id']
        
        depth_buffer[i] = best_depth
        id_buffer[i] = best_id

    # Step 2: Deferred Shading
    for i, d in enumerate(ray_directions):
        depth = depth_buffer[i]
        obj_id = id_buffer[i]
        
        if obj_id == -1:
            color_buffer[i] = (0.0, 0.0, 0.0) # Default background
            continue
            
        # Find object by ID
        obj = next(o for o in objects if o['id'] == obj_id)
        
        # Compute intersection point in global space
        intersection_point = vector_add(camera_origin, vector_scale(d, depth))
        
        # Transform to canonical space
        c_p, c_d = obj['G_inv'](intersection_point, d)
        
        # Evaluate NeRF model
        color, sigma = obj['F_Theta'](c_p, c_d)
        
        # Check validity of depth based on density
        if sigma < 1e-3: # [G] Standard threshold for NeRF density validation
            # Optional: Resample using volume rendering equation for better quality
            # [S1] Implementation details for resampling are not provided in the sources.
            pass
            
        color_buffer[i] = color

    # Step 3: Shadow Step
    # Generate shadows using shadow rays, depth buffer, and original rays
    # [S1] Specific shadow casting algorithm details are not provided in the sources.
    # This step would typically involve casting shadow rays from intersection points
    # to light sources and checking occlusion against the depth buffer.
    for i in range(num_pixels):
        # Placeholder for shadow calculation logic per source limitation
        shadow_buffer[i] = 1.0 
        
    return color_buffer, depth_buffer, id_buffer, shadow_buffer

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def norm(v):
    return math.sqrt(dot(v, v))

def vector_add(a, b):
    return (a[0]+b[0], a[1]+b[1], a[2]+b[2])

def vector_scale(v, s):
    return (v[0]*s, v[1]*s, v[2]*s)
```

## Operating characteristics
*   **Speed:** Provides interactive-level speed for previewing by replacing ray marching with a single sample evaluation per pixel [S1].
*   **Quality:** Limits quality compared to full ray marching, as it uses a degenerated ray casting form [S1]. High-quality re-rendering is available after object adjustment [S1].
*   **Memory:** Requires storage for depth, object ID, color, and shadow buffers [S1].
*   **Use Cases:** Suitable for previewing and interactive manipulation where speed is prioritized over perfect quality [S1]. Not suitable for final high-quality rendering without re-rendering [S1].

## Background
The Fast NeRF Composition Pipeline was introduced in "A General Implicit Framework for Fast NeRF Composition and Rendering" [S1]. It builds on Neural Depth Fields (NeDF) to enable fast composition and rendering of NeRF objects [S1].
