# NeDF Intersection Network
Also called: Intersection Network, Neural Distance Field

## Overview
The NeDF Intersection Network is a multi-level classifier that predicts the signed distance parameter $\mu$ and a binary intersection indicator $\hat{\alpha}$ for a given ray $\mathbf{r}$, replacing direct regression to avoid depth discontinuity artifacts and floating artifacts at object edges [S1]. It differs from standard NeRF depth regression by discretizing the distance range into coarse and fine bins, enabling stable surface intersection estimation for fast NeRF composition [S1].

## How it works
**Inputs and Outputs**
*   **Input:** An oriented ray $\mathbf{r}$, represented by a set of 16 points sampled along the ray within a specific local range [S1].
*   **Output:** A tuple $(\hat{v}_c, \hat{v}_f, \hat{\alpha})$, where $\hat{v}_c$ and $\hat{v}_f$ are 1D vectors representing coarse- and fine-level target bins, and $\hat{\alpha}$ is a binary indicator for surface intersection [S1].

**Data Structures**
The network is an MLP with the following layout [S1]:
*   **Head:** A single linear layer.
*   **Body:** 16 residual blocks. Each block consists of two fully connected layers followed by ReLU activation.
*   **Tail:** Two branches producing the outputs. One branch produces $\hat{\alpha}$, and the other produces $\hat{v}_c$ and $\hat{v}_f$.

**Parameters**
*   **Classifier Resolution:** $N_c = 64$ (coarse bins), $N_f = 128$ (fine bins) [S1].
*   **Distance Range:** $\mu \in [-l, l]$, centered at the tangency point $p_\perp$ [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $5 \times 10^{-4}$ [S1].
*   **Batch Size:** 4,096 rays [S1].
*   **Training Iterations:** 60,000 (60W) [S1].
*   **Supervision Views:** 500 random views [S1].

**Formulas**
The network maps the ray to the bin indicators:
$$ \mathcal{F}_\Phi : \mathbf{r} \mapsto (\hat{v}_c, \hat{v}_f, \hat{\alpha}) $$
where $\hat{v}_c \in \mathbb{R}^{N_c}$ and $\hat{v}_f \in \mathbb{R}^{N_f}$ [S1].

The distance parameter $\mu$ is calculated from the predicted bins as [S1]:
$$ \mu = \lambda_1 p_c(\hat{v}_c) + \lambda_2 p_f(\hat{v}_f) - l $$
where:
*   $p_c(\hat{v}_c) = \text{argmax}(\hat{v}_c) / N_c$
*   $p_f(\hat{v}_f) = \text{argmax}(\hat{v}_f) / N_f$
*   $\lambda_1 = 2l$
*   $\lambda_2 = 2l / N_c$

The depth $D(\mathbf{r})$ from the ray origin $\mathbf{o}$ to the intersection point is calculated as [S1]:
$$ D(\mathbf{r}) = |\mathbf{o} - \mathbf{p}_\perp| - \mu $$
where $\mathbf{p}_\perp$ is the tangency point of the ray to the object [S1].

**Ground Truth Generation**
Ground truth depth is measured from a pre-trained NeRF model using the render equation [S1]:
$$ D(\mathbf{r}) = \sum_{i=1}^N w_i (t_i \mathbf{d}) $$
where $w_i$ is the weight of the $i$-th sample, $t_i \in [t_n, t_f]$ are the near and far clip ranges, and $\mathbf{d}$ is the ray direction [S1]. This depth is converted to $\mu$ using the inverse of the depth formula for supervision [S1].

**Training Loss**
The total training loss uses Binary Cross-Entropy (BCE) to handle the non-differentiable argmax operation during training [S1]:
$$ \mathcal{L}_{NeDF} = \text{BCE}(\hat{v}_c, v_c) + \text{BCE}(\hat{v}_f, v_f) + 0.1 \times \text{BCE}(\hat{\alpha}, \alpha) $$
where $v_c$ and $v_f$ are one-hot vectors derived from the ground truth $\mu$ via the segment operator, and $\alpha$ is the ground truth intersection mask [S1].

**Pseudocode**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class NeDFIntersectionNetwork(nn.Module):
    def __init__(self, N_c=64, N_f=128, l=1.0):
        super().__init__()
        self.N_c = N_c
        self.N_f = N_f
        self.l = l
        
        # Head: single linear layer
        # Assuming input dimension is 16 points * 3 coords = 48, plus ray direction if used.
        # Source specifies "set of points sampled along rays... 16 points in total".
        # We assume input is flattened coordinates of these 16 points.
        self.head = nn.Linear(48, 256) # Dimension not explicitly given, using standard default [G]
        
        # Body: 16 residual blocks
        self.blocks = nn.ModuleList([
            ResidualBlock(256) for _ in range(16)
        ])
        
        # Tail: branches for alpha, v_c, v_f
        self.alpha_head = nn.Linear(256, 1)
        self.coarse_head = nn.Linear(256, N_c)
        self.fine_head = nn.Linear(256, N_f)

    def forward(self, ray_points):
        """
        ray_points: Tensor of shape (B, 16, 3) representing 16 points along the ray.
        """
        # Flatten points to (B, 48)
        x = ray_points.view(ray_points.size(0), -1)
        
        # Head
        x = self.head(x)
        x = F.relu(x)
        
        # Body
        for block in self.blocks:
            x = block(x)
            
        # Tail
        alpha_logit = self.alpha_head(x)
        v_c_logit = self.coarse_head(x)
        v_f_logit = self.fine_head(x)
        
        # Predictions
        alpha_hat = torch.sigmoid(alpha_logit)
        v_c_hat = F.softmax(v_c_logit, dim=-1)
        v_f_hat = F.softmax(v_f_logit, dim=-1)
        
        return v_c_hat, v_f_hat, alpha_hat

    def predict_mu(self, v_c_hat, v_f_hat):
        """
        Calculate mu from predicted bin probabilities.
        v_c_hat: (B, N_c)
        v_f_hat: (B, N_f)
        """
        # argmax indices
        idx_c = torch.argmax(v_c_hat, dim=-1)
        idx_f = torch.argmax(v_f_hat, dim=-1)
        
        # Normalize to [0, 1]
        p_c = idx_c.float() / self.N_c
        p_f = idx_f.float() / self.N_f
        
        # Calculate mu
        lambda_1 = 2 * self.l
        lambda_2 = 2 * self.l / self.N_c
        
        mu = lambda_1 * p_c + lambda_2 * p_f - self.l
        return mu

    def compute_loss(self, v_c_hat, v_f_hat, alpha_hat, v_c_gt, v_f_gt, alpha_gt):
        """
        v_c_gt: (B, N_c) one-hot ground truth coarse bin
        v_f_gt: (B, N_f) one-hot ground truth fine bin
        alpha_gt: (B, 1) ground truth intersection mask
        """
        loss_c = F.binary_cross_entropy(v_c_hat, v_c_gt)
        loss_f = F.binary_cross_entropy(v_f_hat, v_f_gt)
        loss_alpha = F.binary_cross_entropy(alpha_hat, alpha_gt)
        
        total_loss = loss_c + loss_f + 0.1 * loss_alpha
        return total_loss

class ResidualBlock(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.fc1 = nn.Linear(dim, dim)
        self.fc2 = nn.Linear(dim, dim)
        
    def forward(self, x):
        out = F.relu(self.fc1(x))
        out = self.fc2(out)
        return x + out # Residual connection
```

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Trained on a single Nvidia A100 GPU [S1].
*   **Strengths:** Avoids depth discontinuity issues and floating artifacts at edges that occur with direct regression [S1].
*   **Limitations:** Requires a pre-trained NeRF model to generate supervision data (depth and masks) [S1].
*   **When to use:** When fast NeRF composition is required and accurate surface intersection estimation is needed to avoid rendering artifacts [S1].
*   **When not to use:** When direct regression is sufficient and the overhead of multi-level classification is unnecessary [S1].

## Background
The NeDF Intersection Network was introduced in "A General Implicit Framework for Fast NeRF Composition and Rendering" (2024) [S1]. It addresses the issue of inaccurate depth estimation around edges in NeRF composition, which leads to floating artifacts [S1]. The method replaces direct regression of the distance parameter $\mu$ with a multi-level classifier supervised by a pre-trained NeRF [S1].
