# Tiny NeRF

Also called: TinyNeRF, TinyNeRF-S, TinyNeRF-w/o block, TinyNeRF-w/o fine tuning

## Overview
Tiny NeRF is a compression pipeline for voxel-based neural radiance fields that transforms voxel grids into the frequency domain via block-wise Discrete Cosine Transformation (DCT), then prunes and quantizes the resulting coefficients to reduce storage by over 100x with minimal quality loss [S1]. Unlike sibling methods that prune empty spatial voxels (e.g., [Unbounded inward-facing scene parameterization](957-unbounded-inward-facing-scene-parameterization.md), [Position-Only NeRF Field](1253-position-only-nerf-field.md)), Tiny NeRF operates on frequency coefficients, allowing higher pruning rates by overcoming foreground-background ratio limitations [S1]. It differs from [MLPRender_Fea](2414-mlprender-fea.md) and [View-Dependent MLP](2444-view-dependent-mlp.md) by compressing the explicit voxel grid representation rather than optimizing the MLP architecture itself.

## How it works
**Inputs:** Original voxel grid $V \in \mathbb{R}^{C \times N_x \times N_y \times N_z}$ containing density and feature values [S1].
**Outputs:** Compressed representation consisting of pruned and quantized DCT coefficients, a global scaling factor $\alpha$, and metadata (block size, pruning ratios) [S1].

**Data Structures:**
1.  **Input Grid:** $V \in \mathbb{R}^{C \times N_x \times N_y \times N_z}$ [S1].
2.  **Blocks:** The grid is divided into $\frac{N_x}{B_x} \times \frac{N_y}{B_y} \times \frac{N_z}{B_z}$ blocks, each of size $C \times B_x \times B_y \times B_z$ [S1]. Default block size is $4 \times 4 \times 4$ [S1].
3.  **DCT Coefficients:** $\bar{V} \in \mathbb{R}^{C \times B_x \times B_y \times B_z}$ per block [S1].
4.  **Pruned Coefficients:** $\bar{V}_P$, where low-magnitude coefficients are set to zero [S1].
5.  **Quantized Coefficients:** $\bar{V}_Q$, containing low-bit integers [S1].
6.  **Scaling Factor:** $\alpha \in \mathbb{R}$, a single floating-point scalar [S1].

**Formulas:**
*   **DCT:** For a block $V \in \mathbb{R}^{C \times B_x \times B_y \times B_z}$, the transformed coefficient $\bar{\mathcal{V}}_{c,i,j,k}$ is:
    $$ \bar{\mathcal{V}}_{c,i,j,k} = \sum_{x,y,z} \frac{u_i u_j u_k}{\sqrt{B_x B_y B_z}} \mathcal{V}_{c,x,y,z} \times \cos\left(\frac{\pi}{B_x} i(x + \frac{1}{2})\right) \cos\left(\frac{\pi}{B_y} j(y + \frac{1}{2})\right) \cos\left(\frac{\pi}{B_z} k(z + \frac{1}{2})\right) $$
    where $x, y, z$ and $i, j, k$ span from $[1, 1, 1]$ to $[B_x, B_y, B_z]$, and $u_i = 1$ if $i=0$ else $\sqrt{2}$ [S1].
*   **IDCT:**
    $$ \mathcal{V}_{c,x,y,z} = \sum_{i,j,k} \frac{u_i u_j u_k}{\sqrt{B_x B_y B_z}} \bar{\mathcal{V}}_{c,i,j,k} \times \cos\left(\frac{\pi}{B_x} i(x + \frac{1}{2})\right) \cos\left(\frac{\pi}{B_y} j(y + \frac{1}{2})\right) \cos\left(\frac{\pi}{B_z} k(z + \frac{1}{2})\right) $$
    [S1].
*   **Quantization Bounds (b-bit):** $Q_{min} = -2^{b-1}$, $Q_{max} = 2^{b-1} - 1$ [S1].
*   **Quantization Approximation:** $\bar{V}_P \approx \alpha \bar{V}_Q$ [S1].

**Parameters:**
*   **Grid Resolution:** $160^3$ [S1].
*   **Total Iterations:** 20,000 [S1].
*   **Batch Size:** 8,192 camera rays [S1].
*   **Pruning Aware Training Start:** Iteration 5,000 [S1].
*   **Quantization Aware Training Start:** Iteration 12,000 [S1].
*   **Pruning Ratios:** Density: 0.3, 0.15; Features: 0.03, 0.015 [S1].
*   **Quantization Bit Widths:** 4, 8, 16 [S1].

**Steps:**
1.  **Block-wise DCT:** Divide the input grid $V$ into blocks of size $B_x \times B_y \times B_z$. Apply DCT to each block independently to obtain $\bar{V}$ [S1].
2.  **Pruning:** Sort DCT coefficients in each block by absolute value. Retain the top $K$ coefficients (where $K$ is determined by the pruning ratio) and set the rest to zero to obtain $\bar{V}_P$ [S1].
3.  **Pruning-Aware Training (Optional/Default):**
    *   Recover grid $\mathcal{V}_P = \text{IDCT}(\bar{V}_P)$ [S1].
    *   Render rays using $\mathcal{V}_P$ [S1].
    *   Compute loss $\mathcal{L}$ [S1].
    *   Approximate gradients w.r.t. original grid $V$ using Straight-Through Estimator (STE): $\frac{\partial \mathcal{L}}{\partial V} \approx \frac{\partial \mathcal{L}}{\partial \mathcal{V}_P}$ [S1].
    *   Update $V$ [S1].
4.  **Quantization Initialization:**
    *   Initialize $\alpha$ and $\bar{V}_Q$ by iterating:
        1.  $\bar{V}_Q = \text{clip}(\text{round}(\frac{\bar{V}_P}{\alpha}), Q_{min}, Q_{max})$ [S1].
        2.  $\alpha = \frac{\langle \bar{V}_P, \bar{V}_Q \rangle}{\langle \bar{V}_Q, \bar{V}_Q \rangle}$ [S1].
    *   Repeat until convergence [S1].
5.  **Quantization-Aware Training (Optional/Default):**
    *   Freeze $\alpha$ [S1].
    *   Compute $\bar{V}_Q$ using Eq. (9a) [S1].
    *   Recover grid $\mathcal{V}_Q = \text{IDCT}(\alpha \bar{V}_Q)$ [S1].
    *   Render rays using $\mathcal{V}_Q$ [S1].
    *   Compute loss $\mathcal{L}$ [S1].
    *   Approximate gradients w.r.t. $V$ using STE: $\frac{\partial \mathcal{L}}{\partial V} \approx \frac{\partial \mathcal{L}}{\partial \mathcal{V}_Q}$ [S1].
    *   Update $V$ [S1].
6.  **Inference:**
    *   Recover grid $\mathcal{V} = \text{IDCT}(\alpha \bar{V}_Q)$ [S1].
    *   Perform standard volume rendering [S1].

**Subtopics:**
*   **TinyNeRF-S:** A variant that applies pruning and quantization in the spatial domain instead of the frequency domain. It is chosen when frequency domain transformation is not desired, but it performs significantly worse than TinyNeRF, especially at small model sizes (e.g., 0.5 dB lower PSNR at 2MB) [S1].
*   **TinyNeRF-w/o block:** A variant that applies DCT to the whole grid without blocking. It performs worse than both TinyNeRF and TinyNeRF-S, suffers from more numerical errors, and converges slower [S1].
*   **TinyNeRF-w/o fine tuning:** A variant that compresses a pre-trained model without retraining. It achieves 50x compression with minimal PSNR drop (31.95 to 31.68) and takes seconds to compress, but is less optimal than fine-tuned versions [S1].

## Operating characteristics
*   **Time Complexity:** Training time increases from 3 minutes (DVGO baseline) to 6.5 minutes on an NVIDIA A100 GPU for a 2MB model [S1]. Pruning-aware training consumes 3.97 minutes of the additional 4.96 minutes [S1]. Inference time increases by 5ms (total 209ms) due to IDCT and dequantization [S1].
*   **Memory Complexity:** Model size is reduced from 203MB (DVGO) to 2MB, a >100x compression [S1].
*   **Performance:** On the synthetic NeRF dataset, TinyNeRF(2MB) achieves 31.72 PSNR and 0.954 SSIM, with only 0.2 PSNR and 0.003 SSIM degradation compared to the uncompressed baseline [S1].
*   **Strengths:** High compression ratio with minimal quality loss; fast training (<10 mins); effective on inward-facing scenes; handles foreground-background ratios better than spatial pruning [S1].
*   **Limitations:** Runtime computation and memory requirements are not reduced during inference because original voxel grids must be recovered via IDCT [S1]; numerical errors increase with block size [S1].
*   **When to use:** When storage or transmission bandwidth is limited, and training time is acceptable. Suitable for inward-facing synthetic scenes.
*   **When not to use:** When real-time inference speed is critical and IDCT overhead is unacceptable; when the scene has high-frequency details that do not compress well in the frequency domain.

## Background
Tiny NeRF was introduced by Sun et al. in 2023 in the paper "TinyNeRF: Towards 100x Compression of Voxel Radiance Fields" [S1]. It builds on the DVGO (Direct Voxel Grid Optimization) framework [S1]. The method leverages the sparsity of visual signals in the frequency domain, a property widely used in image compression (e.g., JPEG) [S1]. It addresses the high storage demand of voxel-based NeRF methods like NSVF, Plenoxels, and DVGO, which typically prune empty voxels but are limited by foreground-background ratios [S1].
