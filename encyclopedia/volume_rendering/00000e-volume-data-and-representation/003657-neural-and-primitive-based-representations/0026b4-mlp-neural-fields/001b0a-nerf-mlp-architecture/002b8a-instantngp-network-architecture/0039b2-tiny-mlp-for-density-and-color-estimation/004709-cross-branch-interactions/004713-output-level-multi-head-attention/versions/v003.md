# Output-level Multi-head Attention

Also called: III. Output-level Multi-head Attention

## Overview
Output-level Multi-head Attention is a module applied to concatenated preliminary densities and colors to learn their interactions before producing final predictions [S1, unofficial]. It sets itself apart from sibling methods by operating on the raw output vectors of the neural branches rather than on input encodings, ensuring that the final density and color estimates are mutually consistent [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Preliminary density $\sigma$ and preliminary color $c$ produced by the preceding MLP branches [S1, unofficial].
*   **Output:** Final density $\sigma'$ and final color $c'$ [S1, unofficial].

**Data Structures:**
The module operates on a single tensor $\zeta$ formed by concatenating the scalar density and the 3-channel color vector [S1, unofficial].
*   $\zeta = [\sigma, c]$
*   Shape: $[1, 4]$ per point (1 for density, 3 for RGB) [S1, unofficial].

**Steps:**
1.  **Concatenation:** Combine the preliminary density $\sigma$ and color $c$ into a single vector $\zeta = [\sigma, c]$ [S1, unofficial].
2.  **Attention Setup:** Set the Query ($Q$), Key ($K$), and Value ($V$) matrices to $\zeta$ [S1, unofficial].
3.  **Attention Application:** Apply multi-head attention to $\zeta$ to produce an attended output $\zeta'$ [S1, unofficial].
4.  **Un-concatenation:** Split $\zeta'$ back into its components: $\sigma'$ is the first dimension of $\zeta'$, and $c'$ consists of the remaining three dimensions of $\zeta'$ [S1, unofficial].

**Pseudocode:**
```python
def output_level_multi_head_attention(preliminary_sigma, preliminary_color, num_heads=2):
    # Step 1: Concatenate density and color
    zeta = concatenate([preliminary_sigma, preliminary_color], axis=-1)
    
    # Step 2: Set Q, K, V to zeta
    Q, K, V = zeta, zeta, zeta
    
    # Step 3: Apply multi-head attention
    d_model = zeta.shape[-1]
    d_k = d_model // num_heads
    
    # Learnable projection matrices (initialized externally)
    W_Q = [zeros((d_model, d_k)) for _ in range(num_heads)]
    W_K = [zeros((d_model, d_k)) for _ in range(num_heads)]
    W_V = [zeros((d_model, d_k)) for _ in range(num_heads)]
    W_O = zeros((d_model, d_model))
    
    heads = []
    for i in range(num_heads):
        q_proj = matmul(Q, W_Q[i])
        k_proj = matmul(K, W_K[i])
        v_proj = matmul(V, W_V[i])
        # Standard attention layer implementation [G]
        scores = matmul(q_proj, transpose(k_proj))
        attn_weights = softmax(scores, axis=-1)
        head_out = matmul(attn_weights, v_proj)
        heads.append(head_out)
        
    concat_heads = concatenate(heads, axis=-1)
    attended_zeta = matmul(concat_heads, W_O)
    
    # Step 4: Un-concatenate attended output
    final_sigma = attended_zeta[..., 0:1]
    final_color = attended_zeta[..., 1:4]
    
    return final_sigma, final_color
```

**Parameters:**
*   **Number of attention heads ($H$):** 2 for the LLFF dataset; 1 for the NeRF-Synthetic dataset [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Dimension Mismatch:** The un-concatenation step assumes the attention output preserves the channel structure (1 density, 3 color) [S1, unofficial]. If the attention mechanism alters the output dimensionality, this step fails [G].

## Subtopics

### Input-level Multi-head Attention
A multi-head attention module applied to hybrid encodings to learn interactions between view directions and hash encoding dimensions, and among neighboring rays [S1, unofficial]. It sets itself apart by operating on the input feature space before the density/color split [S1, unofficial]. Choose it when modeling view-dependent effects and ray correlations early in the pipeline [S1, unofficial]. It uses $H=2$ heads for LLFF and $H=1$ for NeRF-Synthetic [S1, unofficial]. The input tensor $\gamma''(d, x)$ has size $|R| \times (N_x - 1 + N_d)$, where $|R|$ is batch size, $N_x$ is hash encoding dimension, and $N_d$ is view encoding dimension [S1, unofficial]. The hash encoding for density is trimmed to $\gamma'_0(x)$ to avoid over-parameterization, while the hybrid encoding retains all but the first dimension [S1, unofficial].

### Concurrent Weight and Offset Network Evaluation
A network architecture modification where the weight and offset networks are evaluated concurrently, splitting the model instead of using two subsequent MLPs for density and color [S3]. The input for the weight network is padded with ones [S3].

## Background
Originating from the DWTNeRF paper, this method is part of a broader approach using multi-head attention for cross-branch interactions in neural radiance fields [S1, unofficial]. It was developed to learn interactions between preliminary density and color outputs before final prediction [S1, unofficial].
