# Unrestricted Color Network (UCN) Distillation

Also called: UCN Distillation

## Overview
Unrestricted Color Network (UCN) Distillation is a knowledge distillation method that trains a student network to replicate the diffuse color output of a Palette Color Network (PCN) teacher model without enforcing palette constraints, enabling Non-Photorealistic Style Editing (NPSE) [S1]. Unlike traditional NeRF stylization that discards view-dependent color to maintain consistency, UCN optimizes diffuse color during training and combines it with specular color during inference to preserve lighting effects [S1].

## How it works
**Inputs and Outputs**
- **Input:** A pre-trained PCN teacher model, a set of reference styles $S = \{S_1, \dots, S_{N_P}\}$, and randomly sampled camera views.
- **Output:** A distilled UCN student model consisting of a hash-grid encoder $E_u$ and an unrestricted MLP, capable of outputting diffuse color $c_u(x)$ [S1].

**Data Structures**
- **UCN Structure:** Comprises one hash-grid encoder $E_u$ followed by an unrestricted MLP [S1].
- **Average Palette $\bar{P}$:** Extracted average colors from reference styles, replacing original palette colors $P$ to ensure style matching [S1].

**Parameters**
- **Optimizer:** Adam with learning rate $0.01$, $\beta_1=0.9$, $\beta_2=0.999$ [S1].
- **Batch Size:** 4096 rays [S1].
- **Learning Rate Decay:** Exponential decay until 0 for base NeRF, PCN, and UCN during Knowledge Distillation (KD) [S1].
- **Iterations:** 150 for volume-aligned loss initialization; 500 for color loss optimization [S1].

**Steps**
1. **Style Preparation:** Extract average palette colors $\bar{P}$ from each reference style to replace original palette colors $P$ [S1].
2. **Initialization:** Randomly sample camera views from the scene. Optimize the hash-grid encoder $E_u$ using the volume-aligned loss $L_{VOLUME}$ for 150 iterations to initialize $E_u(x)$ and accelerate subsequent distillation [S1].
3. **Distillation:** Optimize both $E_u(x)$ and the unrestricted MLP for 500 iterations using the color loss $L_{COLOR}$ [S1].
4. **Inference:** Output the sum of diffuse color $c_u(x)$ and specular color $c_s(x, d)$ to preserve specular lighting [S1].

**Formulas**
The volume-aligned loss $L_{VOLUME}$ is defined as:
$$ L_{VOLUME} = ||E_p(x) - E_u(x)||_2^2 $$
where $E_p(x)$ and $E_u(x)$ are the output features from the palette encoder and unrestricted encoder for sample point $x$ [S1].

The color loss $L_{COLOR}$ is defined as:
$$ L_{COLOR} = ||\bar{c}_d(x) - c_u(x)||_2^2 $$
where $\bar{c}_d(x)$ is the diffuse color output from the PCN using the average palette $\bar{P}$, and $c_u(x)$ is the color output from the UCN at $x$ [S1].

**Pseudocode**
```python
def ucn_distillation(pcn_teacher, reference_styles, camera_views):
    # Step 1: Extract average palette colors
    P_bar = extract_average_palette(reference_styles)
    
    # Initialize UCN components
    E_u = HashGridEncoder()
    mlp_unrestricted = MLP()
    
    # Step 2: Initialize E_u with volume-aligned loss
    for i in range(150):
        # Randomly sample rays from camera views
        rays = sample_rays(camera_views)
        
        # Get teacher features
        features_p = pcn_teacher.get_encoder_features(rays)
        
        # Get student features
        features_u = E_u(rays)
        
        # Compute L_VOLUME
        loss_volume = mean_squared_error(features_p, features_u)
        
        # Backpropagate to update E_u only
        update(E_u, loss_volume)
        
    # Step 3: Optimize E_u and MLP with color loss
    for i in range(500):
        rays = sample_rays(camera_views)
        
        # Get teacher diffuse color with average palette
        color_teacher = pcn_teacher.get_diffuse_color(rays, P_bar)
        
        # Get student color
        color_student = mlp_unrestricted(E_u(rays))
        
        # Compute L_COLOR
        loss_color = mean_squared_error(color_teacher, color_student)
        
        # Backpropagate to update both E_u and MLP
        # Note: Deferred backpropagation used for GPU memory efficiency [S1]
        update(E_u, loss_color)
        update(mlp_unrestricted, loss_color)
        
    return UCN(E_u, mlp_unrestricted)
```

**Edge Cases and Pitfalls**
- **GPU Memory:** Limited GPU memory requires deferred backpropagation to update UCN parameters for the entire image [S1].
- **Background Transparency:** Varying background colors can impact stylization results due to inherent transparency in DVR scenes; this must be accounted for during training [S1].

## Operating characteristics
- **Time Complexity:** Optimization involves 150 iterations for initialization and 500 iterations for distillation, with each iteration processing 4096 rays [S1].
- **Memory Complexity:** Limited by GPU memory, requiring deferred backpropagation for full-image updates [S1].
- **Strengths:** Preserves specular lighting while enabling non-photorealistic style editing; avoids discarding view-dependent color [S1].
- **Limitations:** Sensitive to background colors due to scene transparency; requires careful handling of GPU memory [S1].
- **When to Use:** Suitable for NPSE tasks where preserving specular effects is critical [S1].
- **When Not to Use:** Not ideal for photorealistic stylization that requires discarding view-dependent color [S1].

## Background
UCN Distillation was introduced in StyleRF-VolVis for expressive volume visualization, addressing the limitations of palette constraints in Non-Photorealistic Style Editing (NPSE) [S1]. It builds on the PCN architecture and utilizes knowledge distillation to transfer style information without losing specular lighting details [S1].
