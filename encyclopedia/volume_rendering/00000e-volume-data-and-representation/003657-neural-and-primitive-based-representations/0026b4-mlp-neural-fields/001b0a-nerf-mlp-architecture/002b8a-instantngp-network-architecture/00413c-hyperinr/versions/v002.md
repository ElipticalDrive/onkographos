# HyperINR

Also called: Hypernetwork-based INR prediction, KD-tree ensemble INR

## Overview
HyperINR is a method for instantiating Neural Implicit Representations (INRs) for specific scene parameters by predicting the network weights directly, thereby bypassing per-volume optimization [S1, unofficial]. It solves the latency bottleneck of training or optimizing an INR for every new parameter set by using a hypernetwork conditioned on those parameters [S1, unofficial]. It sets itself apart from standard NeRF-like approaches by generating a compact INR for any query parameter in 0.07–0.28 ms, achieving 100× the inference bandwidth of the teacher model it distills from [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Scene parameters $\theta$ (e.g., simulation parameters, physical constants) [S1, unofficial].
*   **Output:** A compact INR (specifically, the weights of a coordinate-based network) capable of evaluating the scalar or vector field at any query point $x$ given $\theta$ [S1, unofficial].

**Data Structures:**
1.  **KD-Tree:** Organizes an ensemble of pre-trained multi-resolution hash encoders (or INR weight sets) over the parameter space $\Theta$ [S1, unofficial].
2.  **Hypernetwork:** A neural network that takes $\theta$ as input and outputs the weights for the target INR [S1, unofficial].

**Steps:**
1.  Organize an ensemble of multi-resolution hash encoders in a KD-tree over the parameter space [S1, unofficial].
2.  For a query parameter $\theta_q$, locate the nearest neighbors in the KD-tree and interpolate their weights via inverse-distance weighting to produce a compact INR [S1, unofficial].
3.  Train the hypernetwork using knowledge distillation from a large CoordNet teacher to match the teacher’s reconstruction quality [S1, unofficial].

**Formulas:**
*   Inverse-distance weighting for ensemble interpolation:
    $$ W_{\text{final}} = \frac{\sum_{i=1}^{k} w_i W_i}{\sum_{i=1}^{k} w_i} $$
    where $W_i$ are the weights of the $k$ nearest INR models in the KD-tree, $w_i = \frac{1}{d(\theta_q, \theta_i)}$ is the inverse distance weight, $d$ is the distance metric in parameter space, and $k$ is the number of neighbors [S1, unofficial].

**Parameters:**
*   $k$ (nearest neighbors): Not given in the sources.
*   KD-Tree depth/branching: Not given in the sources.
*   Teacher Model: Large CoordNet [S1, unofficial].

**Edge Cases and Pitfalls:**
*   Quality is upper-bounded by the teacher model [S1, unofficial].
*   Extrapolation outside the parameter space coverage of the ensemble is not supported by the sources [S1, unofficial].

**Pseudocode:**
```python
def instantiate_inr(query_params, kd_tree, k):
    # Step 1: Locate k nearest neighbors in the KD-tree based on parameter distance
    # (Standard KD-tree search algorithm; sources do not specify implementation details)
    neighbors = kd_tree.search_k_nearest(query_params, k)
    
    # Step 2: Retrieve weights and compute distances
    neighbor_weights = []
    distances = []
    for neighbor in neighbors:
        neighbor_weights.append(neighbor.model_weights)
        distances.append(neighbor.distance)
        
    # Step 3: Compute inverse-distance weights
    weights = [1.0 / dist for dist in distances]
    
    # Step 4: Normalize weights
    total_weight = sum(weights)
    normalized_weights = [w / total_weight for w in weights]
    
    # Step 5: Interpolate weights to produce compact INR
    final_weights = [0.0] * len(neighbor_weights[0])
    for i, w in enumerate(normalized_weights):
        for j, val in enumerate(neighbor_weights[i]):
            final_weights[j] += w * val
            
    return final_weights
```

## Subtopics

### HyperFLINT
HyperFLINT combines a hypernetwork conditioned on simulation parameters with a flow interpolation network for temporal super-resolution of ensemble data [S1, unofficial]. By generating parameter-specific network weights, it achieves sub-second inference times [S1, unofficial]. It achieved 52.70 dB PSNR on cosmological Nyx data at 5× temporal interpolation, a substantial margin over CoordNet (44.02 dB) and STSR-INR (44.21 dB) [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Instantiation time is 0.07–0.28 ms per query parameter [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Achieves 20–30 FPS with volumetric path tracing at 800 × 600 resolution [S1, unofficial].
*   **Inference Bandwidth:** 100× the inference bandwidth of the teacher model [S1, unofficial].
*   **Strengths:** Enables real-time temporal super-resolution, novel-view synthesis, and dynamic shadow computation from compressed representations [S1, unofficial].
*   **Limitations:** Quality is upper-bounded by the teacher model [S1, unofficial].
*   **When to use:** Real-time temporal super-resolution, novel-view synthesis, and dynamic shadow computation from compressed representations [S1, unofficial].
*   **When not to use:** When reconstruction quality exceeding the teacher model's quality is required [S1, unofficial].

## Background
HyperINR was proposed to sidestep per-volume optimization by predicting INR weights from scene parameters via a hypernetwork [S1, unofficial]. It builds on [InstantNGP Network Architecture](5049-instantngp-network-architecture.md) and meta-learning concepts for INRs, generalizing across parameter spaces rather than optimizing for a single instance [S1, unofficial]. The method uses knowledge distillation from a large CoordNet teacher to enable the hypernetwork to match the teacher’s reconstruction quality [S1, unofficial].
