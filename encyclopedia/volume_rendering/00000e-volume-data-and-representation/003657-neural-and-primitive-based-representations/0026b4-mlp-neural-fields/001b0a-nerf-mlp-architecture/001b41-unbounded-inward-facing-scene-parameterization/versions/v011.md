# Unbounded inward-facing scene parameterization

Also called: Mip-NeRF 360 parameterization, Mip-NeRF 360 Scene Contraction, Contracted space parameterization, Mip-NeRF 360 contraction

## Overview
This method parameterizes unbounded 3D scenes into a bounded coordinate space, enabling the use of voxel grids or hash-based encodings that require finite domains [S1][S2, unofficial][S4, unofficial]. It solves the problem where infinite coordinate values break hash tables or MLPs by compressing distant background geometry into a finite ball or cube [S2, unofficial][S6]. It differs from standard normalization by preserving the angular direction vector $\mathbf{x}/\|\mathbf{x}\|_p$ while non-linearly scaling the radial distance, ensuring points at infinity map to the boundary of the bounded space [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: 3D world coordinates $\mathbf{x} \in \mathbb{R}^3$ [S1].
- Output: Contracted coordinates $\mathbf{x}'$ within a bounded domain (typically $[-2, 2]^3$ or a unit sphere/cube) [S1][S2, unofficial].

**Data Structures:**
- The method operates on scalar or vector coordinates [S1]. No persistent data structures are required for the transformation itself, though it is often used in conjunction with a voxel grid or occupancy grid [S4, unofficial].

**Steps:**
1. **Preprocessing (Optional but recommended for grid allocation):**
   - Rotate the world coordinate system to align the first two Principal Component Analysis (PCA) directions of the camera positions with the grid's XY axis [S2, unofficial].
   - Shift the world coordinate to align with the centroid of the camera positions [S2, unofficial].
   - Scale the world coordinate so that all cameras lie near the planes of a unit sphere [S2, unofficial].
2. **Apply Contraction Function:**
   - Evaluate the contraction function $\operatorname{contract}(\mathbf{x})$ based on the chosen norm and parameterization variant [S1][S2, unofficial].

**Formulas:**

The standard spherical contraction (from Mip-NeRF 360) maps $\mathbb{R}^3$ to a sphere of radius 2 [S1][S3]:
$$
\operatorname{contract}(\mathbf{x}) = \begin{cases} 
\mathbf{x} & \|\mathbf{x}\| \leq 1 \\ 
\left(2 - \frac{1}{\|\mathbf{x}\|}\right)\left(\frac{\mathbf{x}}{\|\mathbf{x}\|}\right) & \|\mathbf{x}\| > 1 
\end{cases}
$$
where $\|\mathbf{x}\|$ is the Euclidean norm ($L_2$) [S1][S3].

The generalized cuboid contraction (used in DVGOv2) allows control over the background proportion via a hyperparameter $b$ [S2, unofficial]:
$$
\mathbf{x}' = \begin{cases} 
\mathbf{x} & \|\mathbf{x}\|_p \leq 1 \\ 
\left(1 + b - \frac{b}{\|\mathbf{x}\|_p}\right) \left(\frac{\mathbf{x}}{\|\mathbf{x}\|_p}\right) & \|\mathbf{x}\|_p > 1 
\end{cases}
$$
where $\|\mathbf{x}\|_p$ is the $L_p$ norm and $b > 0$ controls the proportion of voxel grid points allocated to the background [S2, unofficial].

**Jacobian for Scale Contraction (Isotropic Gaussians):**
When contracting isotropic Gaussians, the scale $\sigma_j$ in contracted space is computed using the geometric mean of the eigenvalues of the Jacobian $J_C(\mathbf{x}_j)$ [S1]:
$$
\operatorname{contract}(\sigma_j) = \sigma_j \left| \det(J_C(\mathbf{x}_j)) \right|^{1/d}
$$
where $d=3$ is the dimensionality [S1]. For the spherical contraction, the determinant simplifies to $\det(J_C) = \left(\frac{2}{r} - \frac{1}{r^2}\right)^2 \frac{1}{r^2}$ where $r = \|\mathbf{x}\|$ [S1].

**Parameters:**
- $b$: Hyperparameter controlling background voxel proportion. $b > 0$ [S2, unofficial].
- $p$: Norm type. $p=2$ (Euclidean) or $p=\infty$ (Chebyshev/Cuboid). $p=\infty$ is preferred for voxel grids to avoid wasting ~50% of grid points on empty corners of a cube bounding a sphere [S2, unofficial].
- Grid Resolution: $320^3$ for unbounded inward-facing scenes in DVGOv2 [S2, unofficial].
- Initial Alpha: $\alpha_{\text{init}} = 10^{-4}$ [S2, unofficial].
- Voxel Step Size: $0.5$ (in contracted space) [S2, unofficial].

**Pitfalls:**
- Using $p=2$ with a cuboid voxel grid wastes approximately 50% of grid points because a sphere occupies only a fraction of a cube [S2, unofficial].
- Standard Occupancy Grids (e.g., from Instant-NGP) only support bounded scenes; scene contraction is required to extend them to unbounded scenes [S4, unofficial].
- Spherical contraction maps straight lines to curves, making ray-AABB intersections challenging for empty space skipping [G].

**Pseudocode:**

```python
import math

def contract_spherical(x):
    """
    Standard Mip-NeRF 360 spherical contraction.
    Maps R^3 to a sphere of radius 2.
    """
    norm_x = math.sqrt(x[0]**2 + x[1]**2 + x[2]**2)
    if norm_x <= 1.0:
        return x
    factor = (2.0 - 1.0 / norm_x) / norm_x
    return [x[0] * factor, x[1] * factor, x[2] * factor]

def contract_cuboid(x, p_norm_type='L2', b=0.0):
    """
    Generalized cuboid contraction from DVGOv2.
    Maps R^3 to a bounded region.
    p_norm_type: 'L2' for Euclidean, 'Linfty' for Chebyshev.
    b: Hyperparameter for background proportion.
    """
    if p_norm_type == 'L2':
        norm_x = math.sqrt(x[0]**2 + x[1]**2 + x[2]**2)
    elif p_norm_type == 'Linfty':
        norm_x = max(abs(x[0]), abs(x[1]), abs(x[2]))
    else:
        raise ValueError("Unsupported norm type")

    if norm_x <= 1.0:
        return x
    scale_factor = (1.0 + b - b / norm_x) / norm_x
    return [x[0] * scale_factor, x[1] * scale_factor, x[2] * scale_factor]

def contract_isotropic_scale(sigma, x, p_norm_type='L2'):
    """
    Computes the contracted isotropic scale for a Gaussian at x with scale sigma.
    Uses the determinant of the Jacobian of the contraction.
    """
    if p_norm_type == 'L2':
        norm_x = math.sqrt(x[0]**2 + x[1]**2 + x[2]**2)
    elif p_norm_type == 'Linfty':
        # L_inf Jacobian determinant not provided in sources [G]
        norm_x = math.sqrt(x[0]**2 + x[1]**2 + x[2]**2)
    else:
        norm_x = 0.0

    if norm_x <= 1.0 or norm_x == 0.0:
        det_J = 1.0
    else:
        # Spherical contraction determinant: det(J) = (2/r - 1/r^2)^2 * (1/r^2) [S1]
        inv_r = 1.0 / norm_x
        inv_r2 = inv_r * inv_r
        tangential = 2.0 * inv_r - inv_r2
        radial = inv_r2
        det_J = (tangential ** 2) * radial
        
    scale_multiplier = abs(det_J) ** (1.0 / 3.0)
    return sigma * scale_multiplier
```

## Subtopics

### [Scene Contraction](9762-scene-contraction.md)
A coordinate transformation method that maps unbounded 3D space into a bounded region, enabling the use of hash-based encodings or voxel grids for large-scale neural radiance fields. It solves the problem of infinite coordinate values breaking hash tables or MLPs by compressing distant background geometry into a finite ball or cube. It differs from standard normalization by preserving angular direction while non-linearly compressing radial distance, ensuring points at infinity map to the boundary of the bounded space. Choose when using bounded data structures for unbounded scenes.

### [Piecewise-Projective Contraction](10198-piecewise-projective-contraction.md)
A coordinate transformation that maps unbounded 3D space into a bounded unit cube while preserving straight lines within specific regions, enabling efficient ray-AABB intersection tests for empty space skipping in voxel-based volume rendering. Unlike spherical contraction methods (e.g., mip-NeRF 360) that map lines to curves, this method maps lines to piecewise-linear segments, allowing standard ray-box intersection algorithms to be applied directly in the contracted space. Choose when empty space skipping and ray-box intersection efficiency are critical.

### [Scene Parameterization Radius](15160-scene-parameterization-radius.md)
Constrains large-scale unbounded street-view scenes into a bounded range using a piecewise distance mapping function controlled by a radius parameter $r$ to preserve details for close objects. It differs from standard Normalized Device Coordinates (NDC) by decoupling near-field resolution from far-field bounds, which is necessary for ego-vehicle scenarios with complex camera motion. Choose for dynamic street-view or ego-vehicle rendering.

### Forward-facing scene parameterization
A method to handle unbounded forward-facing scenes by warping the frustum to a bounded volume using a dense voxel grid allocation similar to Multiplane Images (MPIs) [S2, unofficial]. It places $D$ RGB-density images at fixed depths, each with $X \times Z$ resolution, and traces every ray from the first to the $D$-th images with a step size of $s$ image, resulting in $2D - 1$ sampled points if $s = 0.5$ [S2, unofficial]. Choose for forward-facing or indoor corridor scenes where depth layers align with camera motion.

### Initial Meshes for Scene Types
Coordinate system definitions and transformations for different scene types [S5]. Synthetic 360° scenes apply scaling $p' = w p$ where $w=2.4$ or $3$ depending on object size [S5]. Forward-facing scenes apply exponential transformation to concentrate voxels near the camera [S5]. Unbounded 360° scenes use no transformation to the regular grid but add $L+1$ concentric boxes around the grid to model surrounding environments [S5]. Choose when initializing voxel grids or occupancy structures for specific scene topologies.

### Scene Parameterization
For forward-facing scenes, parameterize scenes with normalized device coordinates (NDC). For unbounded scenes, parameterize using contraction parameterization [S6]. Decompose the voxel grid using VM-decomposition in TensoRF for model compactness [S6]. Add distortion loss to encourage solid surface scene reconstruction and prevent floaters [S6]. Choose when using TensoRF-style decomposition for unbounded wild video scenes.

## Operating characteristics
- **Time Complexity:** The contraction function itself is $O(1)$ per sample [S1]. The cost is dominated by the subsequent voxel grid lookup or MLP query [S4, unofficial].
- **Memory Complexity:** Depends on the underlying representation (voxel grid size or hash table size) [S4, unofficial]. The contraction allows these structures to be bounded and finite [S4, unofficial].
- **Measured Performance:** DVGOv2 using this parameterization achieved comparable quality to Plenoxels and TensoRF with less training time on low-spec GPUs (RTX 2080Ti) [S2, unofficial].
- **Strengths:** Enables the use of efficient voxel grids and hash encodings for unbounded scenes; allocates model capacity proportional to disparity (inverse distance), giving more resolution to nearby content [S1].
- **Limitations:** Spherical contraction distorts straight lines, complicating ray-AABB intersection tests for empty space skipping [G]. Using $L_2$ norm with cuboid grids wastes ~50% of grid points [S2, unofficial].
- **When to use:** When rendering large-scale unbounded scenes (e.g., street view, 360° indoor) with voxel-based or hash-based neural fields [S1][S4, unofficial].
- **When not to use:** When bounded scenes are sufficient, or when real-time empty space skipping is critical and piecewise-projective contraction is not available [S5].

## Background
The scene contraction idea originates from Mip-NeRF 360 [S4, unofficial][S1]. It was introduced to parameterize unbounded scenes with bounded coordinates, mapping $[-\infty, \infty]^d$ to $[-2, 2]^d$ [S1]. It has been adopted by various subsequent methods including DVGOv2 [S2, unofficial], Zip-NeRF [S1], NerfAcc [S4, unofficial], and MERF [S5].
