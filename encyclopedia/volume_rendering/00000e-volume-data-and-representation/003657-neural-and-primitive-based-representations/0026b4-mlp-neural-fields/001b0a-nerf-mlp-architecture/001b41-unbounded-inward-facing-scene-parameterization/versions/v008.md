# Unbounded inward-facing scene parameterization

Also called: Mip-NeRF 360 parameterization, Mip-NeRF 360 Scene Contraction, Contracted space parameterization, Mip-NeRF 360 contraction

## Overview
This method parameterizes unbounded 3D scenes into a bounded volume by mapping coordinates from $[-\infty, \infty]^d$ to a finite domain (typically $[-2, 2]^d$ or a unit sphere), enabling neural radiance fields to handle large-scale environments where distant content would otherwise be sparsely sampled [S1][S2, unofficial]. It differs from standard bounding-box parameterizations by preserving the radial direction of input vectors while non-linearly compressing their magnitude, ensuring that points at infinity map to the surface of the sphere, thereby allocating model capacity proportional to disparity (inverse distance) for distant content [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D world coordinates $\mathbf{x} \in \mathbb{R}^3$.
*   **Output:** Contracted coordinates $\mathbf{x}'$ within a bounded domain.

**Data Structures:**
*   **Hyperparameters:**
    *   $p$: The norm used for contraction (typically $p=2$ for spherical, $p=\infty$ for cuboid) [S2, unofficial].
    *   $b$: A positive hyperparameter ($b > 0$) controlling the proportion of the voxel grid allocated to the background/outer regions [S2, unofficial].
    *   $d$: Dimensionality of the space (default $d=3$) [S1].

**Steps:**
1.  **Preprocessing (Optional but recommended for street-view/ego-vehicle scenes):**
    *   Compute the centroid of the camera positions and shift the world coordinates so the centroid is at the origin [S2, unofficial].
    *   Perform Principal Component Analysis (PCA) on the camera positions. Rotate the world coordinates to align the first two principal components with the grid's XY axes [S2, unofficial].
    *   Scale the coordinates such that the camera near-planes are contained within a unit sphere [S2, unofficial].

2.  **Coordinate Contraction:**
    Apply the contraction function to map $\mathbf{x}$ to $\mathbf{x}'$. The specific formula depends on the norm $p$ and the presence of the background parameter $b$.

    **Standard Mip-NeRF 360 Contraction ($p=2$, no $b$):**
    Maps $\mathbb{R}^3$ to a sphere of radius 2 [S1][S3]:
    $$
    \operatorname{contract}(\mathbf{x}) = \begin{cases} 
    \mathbf{x} & \text{if } \|\mathbf{x}\| \leq 1 \\
    \left(2 - \frac{1}{\|\mathbf{x}\|}\right)\left(\frac{\mathbf{x}}{\|\mathbf{x}\|}\right) & \text{if } \|\mathbf{x}\| > 1
    \end{cases}
    $$
    Here, $\|\mathbf{x}\|$ denotes the Euclidean norm ($L_2$ norm) [S1][S3].

    **DVGOv2 / Generalized Contraction (with $p$ and $b$):**
    Used to allocate specific grid proportions to the background [S2, unofficial]:
    $$
    \mathbf{x}' = \begin{cases} 
    \mathbf{x} & \text{if } \|\mathbf{x}\|_p \leq 1 \\
    \left(1 + b - \frac{b}{\|\mathbf{x}\|_p}\right) \left(\frac{\mathbf{x}}{\|\mathbf{x}\|_p}\right) & \text{if } \|\mathbf{x}\|_p > 1
    \end{cases}
    $$
    Here, $\|\mathbf{x}\|_p$ is the $L_p$ norm [S2, unofficial].

3.  **Scale Contraction (for Gaussian-based representations):**
    If the representation uses isotropic Gaussians with scale $\sigma_j$ at mean $\mathbf{x}_j$, the scale in contracted space is computed using the Jacobian of the contraction $J_C(\mathbf{x}_j)$ [S1]:
    $$
    \operatorname{contract}(\sigma_j) = \sigma_j \left| \det(J_C(\mathbf{x}_j)) \right|^{1/d}
    $$
    For the standard Mip-NeRF 360 contraction ($p=2$), the determinant term simplifies to:
    $$
    \left| \det(J_C(\mathbf{x}_j)) \right|^{1/3} = \left( \frac{\sqrt[3]{2} \|\mathbf{x}_j\|^3 + 1}{\|\mathbf{x}_j\|^3} \right)^{1/3} \quad \text{for } \|\mathbf{x}_j\| > 1
    $$
    [S1]. For $\|\mathbf{x}_j\| \leq 1$, the Jacobian is the identity, so the scale remains unchanged [S1].

**Pseudocode:**

```python
import numpy as np

def contract_mipnerf360(x):
    """
    Standard Mip-NeRF 360 contraction mapping R^3 to sphere of radius 2.
    x: numpy array of shape (..., 3)
    Returns: contracted coordinates of same shape
    """
    norm = np.linalg.norm(x, axis=-1, keepdims=True)
    # Avoid division by zero for points at origin
    norm = np.maximum(norm, 1e-8)
    
    # Condition: ||x|| <= 1
    inside = norm <= 1.0
    
    # Inside: identity
    x_out = np.where(inside, x, np.zeros_like(x))
    
    # Outside: (2 - 1/||x||) * (x / ||x||)
    scale = 2.0 - 1.0 / norm
    direction = x / norm
    x_out = np.where(inside, x_out, scale * direction)
    
    return x_out

def contract_dvgo(x, p=2.0, b=0.0):
    """
    Generalized contraction with Lp norm and background parameter b.
    x: numpy array of shape (..., 3)
    p: norm order (2.0 for Euclidean, np.inf for L-infinity)
    b: background proportion hyperparameter (b > 0)
    Returns: contracted coordinates
    """
    if p == np.inf:
        norm = np.max(np.abs(x), axis=-1, keepdims=True)
    else:
        norm = np.linalg.norm(x, axis=-1, keepdims=True, ord=p)
        
    norm = np.maximum(norm, 1e-8)
    
    inside = norm <= 1.0
    
    x_out = np.where(inside, x, np.zeros_like(x))
    
    # Formula: (1 + b - b/||x||_p) * (x / ||x||_p)
    scale = 1.0 + b - b / norm
    direction = x / norm
    x_out = np.where(inside, x_out, scale * direction)
    
    return x_out
```

**Parameters with typical values:**
*   $p=2$ (Euclidean) is standard for spherical contraction [S1][S3].
*   $p=\infty$ (L-infinity) is used to create a cuboid contracted space to avoid wasting grid points [S2, unofficial].
*   $b > 0$: Controls background voxel proportion. Not given in sources for standard Mip-NeRF 360, but used in DVGOv2 [S2, unofficial].
*   Grid resolution: $320^3$ for unbounded inward-facing scenes in DVGOv2 [S2, unofficial].
*   Initial alpha $\alpha_{init} = 10^{-4}$ [S2, unofficial].
*   Voxel step size: $0.5$ (in contracted space) [S2, unofficial].

**Edge cases and pitfalls:**
*   **Norm Selection:** Using $p=2$ (Euclidean norm) with a cuboid voxel grid wastes approximately 50% of grid points because a sphere occupies only a fraction of a cube. Using $p=\infty$ creates a cuboid contracted space, aligning the grid boundaries with the contraction boundaries [S2, unofficial].
*   **Straight Lines:** Standard spherical contraction maps straight rays to curves, making ray-AABB intersection tests for empty space skipping difficult [S5]. Variants like Piecewise-Projective Contraction preserve straight lines within regions to enable efficient skipping [S5].
*   **Boundedness:** Standard Occupancy Grids (e.g., from Instant-NGP) only support bounded scenes; scene contraction is required to extend these to unbounded scenes [S4, unofficial].

## Subtopics

### [Scene Contraction](9762-scene-contraction.md)
Scene contraction is a coordinate transformation technique that maps unbounded 3D space into a bounded volume, enabling neural radiance fields to handle large-scale or infinite environments. It solves the problem of sparse sampling in distant regions by compressing far-field coordinates into a finite ball, allowing the network to learn a compact representation of the entire scene. It differs from standard bounding-box parameterizations by preserving the radial direction of input vectors while non-linearly compressing their magnitude, ensuring that points at infinity map to the surface of the sphere.

### [Scene Parameterization Radius](15160-scene-parameterization-radius.md)
Constrains large-scale unbounded street-view scenes into a bounded unit sphere volume to enable efficient voxel grid allocation and position encoding, avoiding the heavy range compression of close objects inherent in standard Normalized Device Coordinates (NDC) or basic contraction methods. It sets apart from its siblings by using a piecewise mapping function controlled by a radius parameter $r$ to preserve high-frequency details for nearby objects while mapping distant geometry, specifically tailored for ego-vehicle scenarios where camera motion complicates standard NDC assumptions.

### Forward-facing scene parameterization
A method to handle unbounded forward-facing scenes by warping the frustum to a bounded volume using a dense voxel grid allocation similar to Multiplane Images (MPIs) [S2, unofficial]. It places $D$ RGB-density images at fixed depths, each with $X \times Z$ resolution, and traces every ray from the first to the $D$-th images with a step size of $s$ image, resulting in $2D - 1$ sampled points if $s = 0.5$ [S2, unofficial]. Typical parameters include $D=256$ depth layers, $XZ=384^2$ voxel resolution per layer, and sampling step size $s=1.0$ layer [S2, unofficial]. TV loss weights are $10^{-5}$ for density and $10^{-6}$ for features, with distortion loss weight $10^{-2}$ [S2, unofficial].

### Piecewise-Projective Contraction
A contraction function that maps unbounded space into a finite domain while preserving straight lines (piecewise-linear), allowing for efficient ray-AABB intersection tests for empty space skipping [S5]. It consists of seven regions (unit cube + 6 outer regions) [S5]. The $j$-th coordinate of a contracted point is defined as:
$$
\operatorname{contract}_{\pi}(\mathbf{x})_j = \begin{cases} 
x_j & \text{if } \|\mathbf{x}\|_{\infty} \leq 1 \\
\frac{x_j}{\|\mathbf{x}\|_{\infty}} & \text{if } x_j \neq \|\mathbf{x}\|_{\infty} > 1, \\
\left(2 - \frac{1}{|x_j|}\right) & \text{if } x_j = \|\mathbf{x}\|_{\infty} > 1 
\end{cases}
$$
where $\|\mathbf{x}\|_{\infty} = \max_i |x_i|$ [S5]. Unlike spherical contraction which maps to a radius-2 ball, this contraction preserves the unit cube and maps other regions via projective transformations. It performs on par with spherical contraction but enables efficient empty space skipping [S5]. Mip-NeRF 360's spherical contraction maps straight lines to curves, making ray-AABB intersections challenging, whereas MERF's contraction preserves straight lines within regions, with discontinuities only at region boundaries [S5].

## Operating characteristics
*   **Time Complexity:** The contraction function itself is $O(1)$ per sample. Computing the Jacobian determinant for scale contraction adds a constant number of arithmetic operations [S1].
*   **Memory Complexity:** The method itself is memoryless, but it enables the use of bounded voxel grids (e.g., $320^3$) for unbounded scenes, significantly reducing memory compared to naive bounding boxes that must encompass the entire unbounded world [S2, unofficial][S4, unofficial].
*   **Measured Performance:** DVGOv2 using this parameterization on unbounded inward-facing scenes achieved competitive PSNR/SSIM on Tanks&Temples and BlendedMVS datasets with a grid resolution of $320^3$ on an RTX 2080Ti [S2, unofficial].
*   **Strengths:** Allocates higher representational capacity to points near the cameras (high disparity) and proportional capacity to distant content, preventing aliasing and blurring in far-field regions [S1][S3]. Compatible with bounded data structures like Occupancy Grids [S4, unofficial].
*   **Limitations:** Standard spherical contraction distorts straight lines, complicating ray-AABB intersection tests for empty space skipping in real-time rendering pipelines [S5].
*   **When to use:** When rendering unbounded, large-scale scenes (e.g., street view, 360-degree environments) where distant geometry must be represented without excessive memory usage or sparse sampling artifacts [S1][S2, unofficial].
*   **When not to use:** For bounded scenes where standard NDC or simple bounding box parameterization suffices, or when real-time empty space skipping is critical and the distortion of straight lines by spherical contraction is unacceptable (consider Piecewise-Projective Contraction instead) [S5].

## Background
The scene contraction idea originates from Mip-NeRF 360 [S4, unofficial][S1]. Mip-NeRF 360 introduced this parameterization to support unbounded scenes by applying a non-linear function to coordinates when querying the Occupancy Grid, mapping unbounded space into a finite grid [S4, unofficial]. The specific formula is cited as Eq. 10 in the Mip-NeRF 360 paper [S4, unofficial]. It has since been adapted in various forms for Direct Voxel Grid Optimization (DVGOv2) [S2, unofficial], Zip-NeRF [S1], and MERF [S5].
