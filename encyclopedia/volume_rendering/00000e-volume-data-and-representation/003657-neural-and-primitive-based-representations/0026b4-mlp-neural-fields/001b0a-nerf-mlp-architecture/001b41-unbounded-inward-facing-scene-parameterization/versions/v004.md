# Unbounded inward-facing scene parameterization

Also called: Mip-NeRF 360 parameterization, Scene Contraction, Mip-NeRF 360 Scene Contraction, Contracted space parameterization, Mip-NeRF 360 contraction

## Overview
This method parameterizes unbounded 360-degree scenes into a bounded coordinate space, enabling the use of bounded data structures like voxel grids and neural fields for large-scale scene reconstruction [S1][S2, unofficial]. It solves the problem of infinite scene extent by mapping $\mathbb{R}^3$ to a finite domain (typically a sphere or cube of radius 2), allocating model capacity proportional to disparity (inverse distance) so that distant content receives appropriate resolution [S1]. It sets itself apart from standard NeRF by explicitly handling the unbounded nature of indoor/outdoor 360° captures, whereas siblings like [Position-Only NeRF Field](1253-position-only-nerf-field.md) assume bounded or forward-facing constraints.

## How it works
**Inputs and Outputs:**
*   **Input:** 3D world coordinates $\mathbf{x} \in \mathbb{R}^3$ (and optionally viewing direction $\mathbf{d}$, though the contraction applies to position).
*   **Output:** Contracted coordinates $\mathbf{x}'$ within a bounded domain (e.g., $[-2, 2]^3$ or unit sphere).

**Data Structures:**
*   **Voxel Grid:** A cuboid or spherical grid centered at the origin. For $L_p$ contraction with parameter $b$, the grid length is $2+2b$ [S2, unofficial].
*   **Camera Preprocessing:** Camera positions are rotated to align the first two Principal Component Analysis (PCA) directions with the grid's XY axis, shifted to the centroid, and scaled to fit near planes in a unit sphere [S2, unofficial].

**Contraction Functions:**
There are two primary variants of the contraction function, depending on the norm used and the desired grid shape.

1.  **Spherical Contraction ($L_2$ norm):**
    Maps $\mathbb{R}^3$ to a sphere of radius 2 [S3].
    $$
    \operatorname{contract}(\mathbf{x}) = \begin{cases} 
    \mathbf{x} & \|\mathbf{x}\| \leq 1 \\ 
    \left(2 - \frac{1}{\|\mathbf{x}\|}\right)\left(\frac{\mathbf{x}}{\|\mathbf{x}\|}\right) & \|\mathbf{x}\| > 1 
    \end{cases}
    $$
    This maps values from $[-\infty, \infty]^d$ to $[-2, 2]^d$ [S1].

2.  **Cuboid/Generalized Contraction ($L_p$ norm):**
    Adapts the spherical contraction using an arbitrary $L_p$ norm and a hyperparameter $b > 0$ to control the background voxel proportion [S2, unofficial].
    $$
    \mathbf{x}' = \begin{cases} 
    \mathbf{x} & \|\mathbf{x}\|_p \leq 1 \\ 
    \left(1 + b - \frac{b}{\|\mathbf{x}\|_p}\right) \left(\frac{\mathbf{x}}{\|\mathbf{x}\|_p}\right) & \|\mathbf{x}\|_p > 1 
    \end{cases}
    $$
    Here, $\|\mathbf{x}\|_p$ is the $L_p$ norm. If $p=\infty$, this creates a cuboid contracted space, avoiding the ~50% waste of grid points inherent in using $p=2$ (where a sphere occupies only a fraction of a cube) [S2, unofficial].

**Gaussian Scale Contraction (for 3D Gaussians):**
When contracting isotropic Gaussians, the mean $\mathbf{x}_j$ is contracted directly. The scale $\sigma_j$ is contracted by linearizing the contraction function around $\mathbf{x}_j$ to compute the Jacobian $J_C(\mathbf{x}_j)$ [S1]. The new isotropic scale is the geometric mean of the eigenvalues of the Jacobian:
$$
\operatorname{contract}(\sigma_j) = \sigma_j \left| \det(J_C(\mathbf{x}_j)) \right|^{1/d}
$$
where $d=3$ [S1]. This approach is preferred over multivariate Gaussian contraction as it is less expensive and sufficiently expressive for isotropic scales [S1].

**Pseudocode:**
```python
import numpy as np

def contract_spherical(x):
    """
    Contracts 3D coordinates to a sphere of radius 2.
    Args:
        x: numpy array of shape (..., 3)
    Returns:
        contracted coordinates of same shape
    """
    norm = np.linalg.norm(x, axis=-1, keepdims=True)
    # Avoid division by zero for origin
    norm = np.maximum(norm, 1e-8)
    
    # Condition: ||x|| <= 1
    inside = norm <= 1.0
    
    # Linear interpolation or mask application
    # For ||x|| > 1: (2 - 1/||x||) * (x / ||x||)
    # Note: x / ||x|| is the unit vector
    unit_x = x / norm
    
    # Calculate contracted magnitude for outside points
    # r' = (2 - 1/r)
    r_prime = 2.0 - 1.0 / norm
    
    # Combine
    # If inside, x' = x
    # If outside, x' = r_prime * unit_x
    # We can compute r_prime * unit_x for all, then mask
    x_outside = r_prime * unit_x
    
    # Select based on condition
    # np.where(condition, x_if_true, x_if_false)
    # x_if_true is x, x_if_false is x_outside
    x_contracted = np.where(inside, x, x_outside)
    
    return x_contracted

def contract_cuboid(x, b=0.0, p=np.inf):
    """
    Contracts 3D coordinates using Lp norm and background parameter b.
    Args:
        x: numpy array of shape (..., 3)
        b: hyperparameter controlling background voxel proportion (b > 0)
        p: norm order (e.g., 2, np.inf)
    Returns:
        contracted coordinates
    """
    # Compute Lp norm
    if p == np.inf:
        norm = np.max(np.abs(x), axis=-1, keepdims=True)
    else:
        norm = np.linalg.norm(x, axis=-1, ord=p, keepdims=True)
        
    norm = np.maximum(norm, 1e-8)
    
    inside = norm <= 1.0
    unit_x = x / norm
    
    # For ||x||_p > 1: (1 + b - b/||x||_p) * (x / ||x||_p)
    factor = 1.0 + b - b / norm
    x_outside = factor * unit_x
    
    x_contracted = np.where(inside, x, x_outside)
    return x_contracted

def contract_gaussian_scale(x, sigma):
    """
    Contracts the scale of an isotropic Gaussian.
    Approximation for spherical contraction (p=2, b=1 effectively maps to radius 2).
    For spherical contraction, the determinant of the Jacobian has a closed form.

    The source [S1] mentions a closed form acceleration but doesn't explicitly write the final simplified scalar factor in the snippet provided, 
    but gives the general formula: sigma * |det(J)|^(1/3).
    We will implement the general Jacobian determinant calculation for the spherical case.
    
    Jacobian of spherical contraction C(x):

    If ||x|| > 1:

    C(x) = (2 - 1/r) * u, where u = x/r.
    dC/dx = (2 - 1/r) * (I/r - x x^T / r^3) + (1/r^2 * dr/dx) * u ... 
    Actually, simpler to use the property that for radial contraction f(r)x/r, 
    det(J) = f(r)^2 * (f'(r) * r + f(r)) / r^2 ?

    lambda_1 = 2 - 1/r - (1/r^2)*r ?

    norm = np.maximum(norm, 1e-8)
    
    # Only contract if outside unit sphere
    outside = norm > 1.0
    
    # Jacobian determinant for spherical contraction
    # Eigenvalues: lambda_tan = 2/norm - 1/norm^2, lambda_rad = 1/norm^2
    # Det = lambda_tan^2 * lambda_rad
    lambda_tan = 2.0 / norm - 1.0 / (norm**2)
    lambda_rad = 1.0 / (norm**2)
    
    det_J = (lambda_tan ** 2) * lambda_rad
    
    # Scale factor
    scale_factor = np.abs(det_J) ** (1.0/3.0)
    
    sigma_contracted = sigma.copy()
    sigma_contracted[outside] = sigma[outside] * scale_factor[outside]
    
    return sigma_contracted
```

**Parameters:**
*   **$b$ (background proportion):** $b > 0$. Controls the proportion of voxel grid points allocated to the background [S2, unofficial].
*   **$p$ (norm):** $2$ (spherical) or $\infty$ (cuboid). $p=\infty$ is preferred for voxel grids to avoid wasting ~50% of points [S2, unofficial].
*   **Grid Resolution:** $320^3$ is a common setting [S2, unofficial].
*   **Initialization:** $\alpha_{init} = 10^{-4}$ [S2, unofficial].
*   **Loss Weights:** TV loss for density grid $10^{-6}$, feature grid $10^{-7}$, distortion loss $10^{-2}$ [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Norm Selection:** Using $p=2$ with a cuboid voxel grid wastes ~50% of grid points because a sphere occupies only a fraction of a cube [S2, unofficial]. Use $p=\infty$ for cuboid grids.
*   **Boundedness:** Standard Occupancy Grids (e.g., from Instant-NGP) only support bounded scenes; scene contraction is required to extend them to unbounded scenes [S4, unofficial].
*   **Gaussian Contraction:** Using the full multivariate Gaussian contraction is needlessly expensive; the isotropic Jacobian method is preferred [S1].

## Subtopics

### [Scene Scaling and Contraction](11280-scene-scaling-and-contraction.md)
This method adapts unbounded 360-degree scene data into a bounded unit sphere volume, enabling efficient voxel grid allocation and neural field training [Parent]. It combines a global scaling step to fit the region of interest into a unit cube with a non-linear contraction function that maps points outside a specific radius into a bounded space. This parameterization is critical for preventing training failure in unbounded scenes, as models without it "hardly learned anything".

### Forward-facing scene parameterization
A method to handle unbounded forward-facing scenes by warping the frustum to a bounded volume using a dense voxel grid allocation similar to Multiplane Images (MPIs) [S2, unofficial]. It places $D$ RGB-density images at fixed depths, each with $X \times Z$ resolution, and traces rays with a step size $s$ [S2, unofficial]. It is chosen for forward-facing (non-360°) unbounded scenes. Parameters: $D=256$ layers, $XZ=384^2$ resolution, step size $s=1.0$ layer [S2, unofficial].

### Mip-NeRF 360 Contraction and Skybox Handling
A method to handle unbounded backgrounds in the Mip-NeRF 360 dataset by contracting far objects into a sphere and using a skybox for distant areas [S5]. It warps far objects from original space ($t$-space) into contracted space ($s$-space, radius 1.2), applies DiffMC for watertight manifold generation in $t$-space, and contracts points back to $s$-space for color computation [S5]. Distant background outside the $[-4, 4]$ box is represented by a skybox [S5]. It uses multi-resolution in $t$-space (340 for foreground, 56 for background) [S5].

### Piecewise-Projective Contraction
A contraction function that maps unbounded space into a finite domain while preserving straight lines (piecewise-linear), allowing for efficient ray-AABB intersection tests for empty space skipping [S6]. It consists of seven regions (unit cube + 6 outer regions) and uses projective transformations [S6]. Unlike spherical contraction, it preserves the unit cube and maps other regions via projective transformations, enabling efficient empty space skipping with performance on par with spherical contraction [S6]. Formula:
$$
\operatorname{contract}_{\pi}(\mathbf{x})_j = \begin{cases} 
x_j & \text{if } \|\mathbf{x}\|_{\infty} \leq 1 \\ 
\frac{x_j}{\|\mathbf{x}\|_{\infty}} & \text{if } x_j \neq \|\mathbf{x}\|_{\infty} > 1, \\ 
\left(2 - \frac{1}{|x_j|}\right) & \text{if } x_j = \|\mathbf{x}\|_{\infty} > 1 
\end{cases}
$$
where $\|\mathbf{x}\|_{\infty} = \max_i |x_i|$ [S6].

## Operating characteristics
*   **Time Complexity:** The contraction function itself is $O(1)$ per sample. However, it enables the use of voxel grids, which reduces the number of MLP queries from infinite/unbounded to a finite, sparse set, significantly speeding up training and inference for large scenes.
*   **Memory Complexity:** Depends on the voxel grid resolution. For a $320^3$ grid, memory is proportional to $320^3$ voxels [S2, unofficial]. The cuboid contraction ($p=\infty$) is more memory-efficient than spherical ($p=2$) for grid-based representations as it utilizes the grid volume without the ~50% waste [S2, unofficial].
*   **Measured Performance:** On the Tanks&Temples dataset (bounded ver.), small models use $160^3$ voxels and large models $256^3$ voxels on an RTX 2080Ti [S2, unofficial]. On LLFF (forward-facing), effective grid resolution is $\approx 384^2 \times 256$ [S2, unofficial].
*   **Strengths:** Enables training on unbounded 360° scenes; allocates capacity proportional to disparity; compatible with voxel grids and hash encodings.
*   **Limitations:** Requires pre-processing (PCA alignment, scaling); spherical contraction is inefficient for cuboid grids; piecewise-projective contraction is more complex to implement but enables ray-AABB skipping.
*   **When to use:** Unbounded inward-facing (360°) scenes.
*   **When not to use:** Forward-facing scenes (use Forward-facing parameterization) or bounded scenes (standard NeRF).

## Background
The scene contraction idea originates from Mip-NeRF 360 [S4, unofficial][S1], specifically Eq. 10 in that paper [S4, unofficial]. It was introduced to parameterize unbounded scenes with bounded coordinates, allowing neural radiance fields to handle large-scale environments where traditional bounded assumptions fail [S1]. It has since been adopted by various acceleration frameworks like NerfAcc [S4, unofficial] and adapted for different grid structures and forward-facing scenarios [S2, unofficial][S6].
