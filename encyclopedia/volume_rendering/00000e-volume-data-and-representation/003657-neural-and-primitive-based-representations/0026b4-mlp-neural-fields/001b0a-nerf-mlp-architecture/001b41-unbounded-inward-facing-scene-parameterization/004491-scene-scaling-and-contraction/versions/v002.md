# Scene Scaling and Contraction

Also called: Contracted space parameterization, Scene Contraction

## Overview
This method preprocesses 3D scene coordinates to enable efficient training of neural radiance fields on unbounded, inward-facing scenes. It solves the problem of infinite ray sampling by first scaling the scene to fit a unit cube, then mapping the entire 3D space into a bounded unit sphere. This allows the neural network to learn a compact representation where points at infinity are mapped to the sphere's surface. It differs from other contraction methods by using a specific L2-norm-based scaling factor that preserves the direction of the input vector while compressing its magnitude [S1].

## How it works
**Inputs and Outputs:**
*   Input: Raw 3D coordinates $x \in \mathbb{R}^3$.
*   Output: Transformed coordinates $x' \in \mathbb{R}^3$ within a bounded domain.

**Data Structures:**
No persistent data structures are required. The transformation is applied point-wise during ray sampling or coordinate encoding.

**Steps:**
1.  **Scaling:** Scale the scene frames with a factor such that the region of interest falls within a unit cube [S1]. This ensures the primary scene content is normalized before contraction.
2.  **Contraction:** Apply the parameterization function to map the scaled coordinates into a bounded unit sphere [S1].

**Formula:**
The contraction function is defined as [S1]:

$$
\text{contract}(x) = \begin{cases} 
\frac{x}{r}, & \text{if } \|x\| \le r, \\
\frac{x}{b(1 + b - \|x\|)/\|x\|}, & \text{otherwise}.
\end{cases}
$$

Where:
*   $x$ is the input coordinate vector.
*   $\|x\|$ is the L2 norm (Euclidean length) of $x$.
*   $r$ is the radius parameter defining the boundary of the inner region.
*   $b$ is the radius parameter defining the mapping boundary for the outer region.

**Parameters:**
*   $r = 10$: Radius for the inner region [S1].
*   $b = 1$: Radius parameter for the outer region [S1].

**Pitfalls:**
*   Without the parameterization function, the model hardly learns anything [S1]. This is critical for unbounded scenes where coordinates can extend to infinity.
*   Precision issues may arise when $\|x\|$ is very close to $r$ or when $\|x\|$ is very large, though the formula is continuous.

**Pseudocode:**

```python
import math

def contract(x, r=10.0, b=1.0):
    """
    Contract 3D coordinates into a bounded unit sphere.
    
    Args:
        x: List or tuple of 3 floats [x, y, z].
        r: Inner radius parameter.
        b: Outer radius parameter.
        
    Returns:
        List of 3 floats representing the contracted coordinates.
    """
    # Calculate L2 norm
    norm_x = math.sqrt(x[0]**2 + x[1]**2 + x[2]**2)
    
    # Handle edge case where norm is 0 to avoid division by zero
    if norm_x == 0:
        return [0.0, 0.0, 0.0]
    
    if norm_x <= r:
        # Inner region: simple scaling
        scale = 1.0 / r
        return [x[0] * scale, x[1] * scale, x[2] * scale]
    else:
        # Outer region: non-linear contraction
        # Formula: x / (b * (1 + b - ||x||) / ||x||)
        # Simplified: x * ||x|| / (b * (1 + b - ||x||))
        denominator = b * (1.0 + b - norm_x)
        # Note: denominator can be negative if norm_x > 1 + b, 
        # but typically b=1 and r=10, so for ||x|| > 10, 
        # 1 + 1 - ||x|| becomes negative. 
        # The original formula in [S1] is: x / (b(1 + b - ||x||)/||x||)
        # Let's stick strictly to the source formula structure.
        
        # Source: x / (b(1 + b - ||x||)/||x||)
        # This is equivalent to: x * ||x|| / (b * (1 + b - ||x||))
        
        factor = norm_x / (b * (1.0 + b - norm_x))
        return [x[0] * factor, x[1] * factor, x[2] * factor]
```

## Subtopics

## Operating characteristics
*   **Time Complexity:** $O(1)$ per coordinate, as it involves basic arithmetic operations and a square root.
*   **Memory Complexity:** $O(1)$, no additional memory required.
*   **Strengths:** Enables training on unbounded scenes by mapping infinite space to a bounded domain. Prevents the model from failing to learn due to unbounded coordinates [S1].
*   **Limitations:** Requires careful selection of $r$ and $b$. The choice of $r=10$ and $b=1$ is specific to the scene point clouds in the cited work [S1].
*   **When to use:** When dealing with unbounded, inward-facing scenes where standard bounded parameterizations fail.

## Background
Originating from LiDAR-NeRF [S1], this method builds on parameterization functions used in prior works [42, 5] (cited in [S1]). It was introduced to handle the challenges of novel LiDAR view synthesis via neural radiance fields. The method was found to be critical for stable training, with ablation studies showing that without it, the model hardly learned anything [S1].
