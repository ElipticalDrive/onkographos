# Mip-NeRF 360 Contraction and Skybox Handling

Also called: Mip-NeRF 360 Contraction, Mip-NeRF 360 Scene Contraction, Scene Contraction, Unbounded Scene Parameterization with Skybox

## Overview
This method handles unbounded 360-degree scenes by contracting distant geometry into a bounded unit sphere and using a skybox for the remaining background. It sets itself apart from standard NeRF by explicitly warping infinite t-space coordinates into a finite s-space to enable efficient voxel grid allocation and watertight mesh extraction, while maintaining visual fidelity for distant backgrounds via a skybox representation.

## How it works
**Inputs and Outputs:**
*   **Input:** Camera poses, unbounded scene coordinates in original space ($t$-space), and a geometry network (e.g., SDF or density field).
*   **Output:** Rendered images with antialiased distant backgrounds and watertight foreground meshes.

**Data Structures:**
*   **Coordinate Space:** Two coordinate systems are used:
    *   $t$-space: The original unbounded Euclidean space.
    *   $s$-space: The contracted bounded space, defined as a sphere with radius $R=1.2$ [S2].
*   **Voxel Grid:** Multi-resolution grid in $t$-space.
    *   Foreground resolution: 340 [S2].
    *   Background resolution: 56 [S2].
*   **Skybox:** A static texture or environment map representing the region outside the $[-4, 4]$ bounding box in $t$-space [S2].

**Steps:**
1.  **Coordinate Contraction (t-space to s-space):**
    Map unbounded coordinates $t$ to bounded coordinates $s$ using a contraction function. The specific function is not detailed in the provided notes, but it maps the infinite $t$-space into the sphere of radius 1.2 in $s$-space [S2].
    *   Note: The inverse mapping (s-space to t-space) is required for rendering and mesh extraction.

2.  **Multi-Resolution Sampling:**
    Sample the scene in $t$-space using a multi-resolution voxel grid.
    *   High resolution (340) is used for the foreground region.
    *   Low resolution (56) is used for the background region [S2].
    *   A proposal MLP is used to accelerate sampling by predicting density distributions [S1, unofficial].

3.  **Watertight Mesh Generation (DiffMC):**
    To ensure the mesh is a watertight manifold before contraction:
    *   Apply Differential Marching Cubes (DiffMC) on the geometry network **within t-space** [S2].
    *   This step is critical because contracting a non-watertight mesh would break the manifold property [S2].

4.  **Color Computation:**
    *   Extract points on the mesh surface in $t$-space.
    *   Contract these points back to $s$-space using the contraction function.
    *   Compute color in $s$-space [S2].

5.  **Skybox Handling:**
    *   For rays that do not intersect the foreground geometry (i.e., points falling outside the $[-4, 4]$ box range in $t$-space), sample the skybox [S2].
    *   Use antialiasing (e.g., via nvdiffrast) when rendering the skybox to prevent aliasing artifacts [S2].

**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, geometry_net, skybox, contraction_fn, inverse_contraction_fn):
    # 1. Determine if ray intersects foreground
    # This requires marching in t-space or using the proposal MLP
    hit_point_t, hit_normal_t = march_in_t_space(ray_origin, ray_direction, geometry_net)
    
    if hit_point_t is not None:
        # 2. Contract hit point to s-space
        hit_point_s = contraction_fn(hit_point_t)
        
        # 3. Compute color in s-space
        color = geometry_net.compute_color(hit_point_s, ray_direction)
        return color
    else:
        # 4. Ray misses foreground; sample skybox
        # Skybox is defined outside [-4, 4] box in t-space
        # Extend ray to skybox distance
        skybox_point_t = ray_origin + ray_direction * skybox_distance
        skybox_point_s = contraction_fn(skybox_point_t)
        
        # Sample skybox texture/environment map
        color = skybox.sample(skybox_point_s)
        
        # Apply antialiasing if necessary
        color = antialias(color)
        return color

def generate_mesh(geometry_net, contraction_fn, inverse_contraction_fn):
    # 1. Apply DiffMC in t-space to get watertight mesh
    mesh_t = differential_marching_cubes(geometry_net, space='t')
    
    # 2. Contract mesh vertices to s-space for rendering/visualization
    mesh_s = contraction_fn(mesh_t.vertices)
    
    return mesh_t, mesh_s
```

**Parameters:**
*   Contraction sphere radius: 1.2 [S2].
*   Foreground voxel resolution: 340 [S2].
*   Background voxel resolution: 56 [S2].
*   Skybox bounding box: $[-4, 4]$ in $t$-space [S2].

**Edge Cases and Pitfalls:**
*   **Non-watertight mesh:** If DiffMC is not applied in $t$-space before contraction, the resulting mesh may not be a watertight manifold [S2].
*   **Precision:** Contraction involves non-linear mapping; precision issues may arise near the boundary of the contraction sphere [S2].
*   **Skybox Aliasing:** Without antialiasing, the skybox may exhibit aliasing artifacts [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Multi-resolution grid uses higher memory for foreground (340) and lower for background (56) [S2].
*   **Performance:** Effective on all unbounded scenes, particularly indoor scenes [S2].
*   **Strengths:** Generates watertight manifold foreground meshes, enabling simulation algorithms (e.g., soft-body simulation) [S2].
*   **Limitations:** Requires careful handling of the contraction function and skybox integration [S2].
*   **When to use:** For unbounded 360-degree scenes where watertight mesh extraction and efficient background handling are required.
*   **When not to use:** For bounded scenes where contraction is unnecessary.

## Background
*   **Origin:** Proposed in the context of the Mip-NeRF 360 dataset [S2].
*   **History:** The method builds on the contraction function from Mip-NeRF 360 [S1, unofficial][S2]. It integrates Differential Marching Cubes (DiffMC) for watertight mesh generation [S2].
*   **Usage:** Used for unbounded real scenes in the Mip-NeRF 360 dataset [S2].
