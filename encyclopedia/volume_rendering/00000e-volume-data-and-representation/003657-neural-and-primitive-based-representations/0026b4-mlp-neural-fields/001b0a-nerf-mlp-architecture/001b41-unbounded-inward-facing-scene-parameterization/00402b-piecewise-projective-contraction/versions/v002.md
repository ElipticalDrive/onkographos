# Piecewise-Projective Contraction

Also called: MERF Contraction, Projective Contraction

## Overview
Piecewise-projective contraction maps unbounded 3D space into a bounded volume while preserving straight lines within seven regions, enabling efficient ray-AABB intersection tests for empty space skipping in voxel-based volume rendering [S1]. Unlike spherical contraction methods that map lines to curves, this method maps lines to piecewise-linear segments, allowing standard ray-box intersection algorithms to be applied directly in the contracted space [S1][S2, abstract only, unofficial].

## How it works
**Inputs and Outputs**
- Input: A 3D point $\mathbf{x} \in \mathbb{R}^3$ in unbounded world coordinates [S1].
- Output: A 3D point $\mathbf{x}'$ in the bounded contracted space [S1].

**Data Structures**
No complex data structures are required for the transformation itself; it relies solely on the $\ell_\infty$ norm and component-wise arithmetic operations [S1].

**Formula**
The contraction function $\text{contract}_\pi(\mathbf{x})$ is defined component-wise for each coordinate $j \in \{1, 2, 3\}$ [S1]:

$$
\text{contract}_\pi(\mathbf{x})_j = \begin{cases} 
x_j & \text{if } \|\mathbf{x}\|_{\infty} \leq 1 \\ 
\frac{x_j}{\|\mathbf{x}\|_{\infty}} & \text{if } |x_j| \neq \|\mathbf{x}\|_{\infty} > 1, \\ 
\text{sign}(x_j) \left(2 - \frac{1}{|x_j|}\right) & \text{if } |x_j| = \|\mathbf{x}\|_{\infty} > 1 
\end{cases}
$$

where $\|\mathbf{x}\|_{\infty} = \max_i |x_i|$ is the $\ell_\infty$ norm [S1]. The condition $|x_j| = \|\mathbf{x}\|_{\infty} > 1$ and the explicit $\text{sign}(x_j)$ factor correct the sign preservation implied by the source's description of regions defined by coordinate magnitude and sign [S1, G].

**Parameters**
- No tunable parameters. The boundaries are fixed at $\|\mathbf{x}\|_{\infty} = 1$ and the transformation logic is deterministic [S1].

**Steps**
1. Compute the $\ell_\infty$ norm of the input point: $n_\infty = \max(|x_1|, |x_2|, |x_3|)$ [S1].
2. If $n_\infty \leq 1$, the point lies inside the preserved unit cube. Return $\mathbf{x}' = \mathbf{x}$ [S1].
3. If $n_\infty > 1$, identify the coordinate index $k$ where $|x_k| = n_\infty$ (break ties by choosing the smallest index) [S1, G].
4. For each coordinate $j \in \{1, 2, 3\}$:
   - If $j \neq k$, compute $x'_j = x_j / n_\infty$ [S1].
   - If $j = k$, compute $x'_j = \text{sign}(x_j) \left(2 - \frac{1}{|x_j|}\right)$ [S1, G].
5. Return $\mathbf{x}'$ [S1].

**Pseudocode**
```python
def piecewise_projective_contraction(x):
    """
    Maps unbounded 3D point x to bounded contracted space.
    x: array-like of length 3
    Returns: array of length 3
    """
    import numpy as np
    
    x = np.asarray(x, dtype=float)
    abs_x = np.abs(x)
    n_inf = np.max(abs_x)
    
    # Case 1: Inside unit cube (identity mapping)
    if n_inf <= 1.0:
        return x
    
    # Case 2: Outside unit cube
    # Find the index of the maximum absolute value (first occurrence on tie)
    k = int(np.argmax(abs_x))
    
    x_prime = np.zeros(3)
    
    for j in range(3):
        if j != k:
            # Non-maximum coordinate: projective scaling
            x_prime[j] = x[j] / n_inf
        else:
            # Maximum coordinate: projective transformation preserving sign
            sign_xj = 1.0 if x[j] >= 0 else -1.0
            x_prime[j] = sign_xj * (2.0 - 1.0 / abs_x[j])
            
    return x_prime
```

**Edge Cases and Pitfalls**
- **Precision and Range:** As $|x_j| \to \infty$, the term $1/|x_j| \to 0$, so $x'_j \to \pm 2$ [S1]. The transformation maps the entire unbounded space into the bounded box $[-2, 2]^3$, with the central unit cube $[-1, 1]^3$ preserved exactly [S1]. Implementers must allocate voxel grids to cover this $[-2, 2]^3$ domain rather than just $[-1, 1]^3$ [S1, G].
- **Discontinuities:** The derivative is discontinuous at the boundaries of the seven regions (where $\|\mathbf{x}\|_\infty = 1$ and where the maximum coordinate index changes) [S1]. This is acceptable for rendering but may require careful handling during gradient-based optimization [S1, G].

## Operating characteristics
- **Time Complexity:** $O(1)$ per point evaluation, requiring only max, absolute value, and a few arithmetic operations [S1].
- **Memory Complexity:** $O(1)$ auxiliary memory [S1].
- **Measured Performance:** Performs on par with spherical contraction in terms of reconstruction quality [S1].
- **Strengths:** Enables efficient empty space skipping by allowing standard ray-AABB intersection tests in contracted space, which is critical for real-time rendering with discretized voxels [S1][S2, abstract only, unofficial].
- **Limitations:** The output domain extends to $\pm 2$ in the dominant coordinate direction, requiring appropriately sized voxel grids. Derivative discontinuities exist at region boundaries [S1].
- **When to use:** Real-time volume rendering of unbounded scenes using voxel grids where empty space skipping is necessary for performance [S1].
- **When not to use:** When the rendering pipeline does not use voxel grids or does not require empty space skipping, or when a simpler spherical contraction suffices and performance is not critical [S1].

## Background
Piecewise-projective contraction was introduced in the MERF (Memory-Efficient Radiance Fields) paper by Christian Reiser et al. in 2023 [S1]. It was developed to address the limitation of mip-NeRF 360's spherical contraction, which maps straight lines to curves, making ray-AABB intersections intractable for empty space skipping in real-time voxel-based rendering pipelines [S1]. The method preserves straight lines within seven regions (the unit cube and six outer regions defined by the coordinate with maximum magnitude), allowing rays to be represented as piecewise-linear segments in contracted space [S1].
