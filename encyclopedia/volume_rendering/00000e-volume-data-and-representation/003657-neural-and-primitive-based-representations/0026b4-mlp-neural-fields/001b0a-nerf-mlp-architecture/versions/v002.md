# NeRF MLP Architecture

Also called: 5D MLP, Fully-connected neural radiance field network, NeRF Network Architecture, Neural Radiance Field (NeRF) MLP Architecture, Neural Radiance Field MLP, Standard NeRF

## Overview
The NeRF MLP Architecture is a fully-connected deep neural network that represents a static scene as a continuous 5D volumetric function, mapping a 3D spatial location $\mathbf{x}$ and a 2D viewing direction $\mathbf{d}$ to volume density $\sigma$ and view-dependent emitted radiance $\mathbf{c}$ [S1]. It solves the problem of view synthesis by optimizing a compact neural representation directly from sparse input images, avoiding the need for explicit geometry reconstruction or large voxel grids [S1]. Unlike its siblings, it explicitly models view-dependent effects (such as specularities) via a separate direction-processing branch, and uses positional encoding to overcome the spectral bias of standard MLPs [S1].

## How it works
The method implements the scene function $F_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\mathbf{c}, \sigma)$ using a multi-layer perceptron (MLP) with specific architectural constraints to enforce multiview consistency and handle high-frequency details [S1].

### Inputs and Outputs
*   **Input**: A batch of 5D coordinates. Each coordinate consists of a 3D position $\mathbf{x} = (x, y, z)$ and a 3D Cartesian unit vector $\mathbf{d}$ representing the viewing direction (derived from spherical coordinates $\theta, \phi$) [S1].
*   **Output**: For each input, the network outputs a scalar volume density $\sigma \in [0, \infty)$ and a 3D RGB color vector $\mathbf{c} = (r, g, b) \in [0, 1]$ [S1].

### Data Structures and Layout
The network is composed of two main blocks: a position network and a color network, connected by a skip connection and a feature vector [S1].

1.  **Positional Encoding**: Inputs $\mathbf{x}$ and $\mathbf{d}$ are transformed using a positional encoding function $\gamma(\cdot)$ [S1][S2, unofficial].
    *   For a coordinate $v \in \{x, y, z\}$ or direction component, the encoding is:
        $$ \gamma(v) = [\sin(2^0 \pi v), \cos(2^0 \pi v), \dots, \sin(2^{L-1} \pi v), \cos(2^{L-1} \pi v)] $$
    *   The total input dimension for position is $3 \times 2 \times L$ [S2, unofficial].
    *   The total input dimension for direction is $3 \times 2 \times L_{dir}$ [S2, unofficial].
2.  **Position Network (Block 1)**:
    *   Takes $\gamma(\mathbf{x})$ as input.
    *   Consists of 8 fully-connected (linear) layers [S1].
    *   Hidden layers 1–8 have 256 channels each [S1].
    *   Activations are ReLU for all layers except the final output of this block [S1].
    *   **Skip Connection**: The original encoded position $\gamma(\mathbf{x})$ is concatenated with the output of the 5th layer [S1].
3.  **Density and Feature Output**:
    *   The output of the 8th layer is passed through a final linear layer to produce two outputs:
        *   Volume density $\sigma$: A scalar.
        *   Feature vector $\mathbf{f}$: A 256-dimensional vector [S1].
    *   $\sigma$ is passed through a ReLU activation to ensure non-negativity [S1].
4.  **Directional Encoding**:
    *   The viewing direction $\mathbf{d}$ is encoded using $\gamma(\mathbf{d})$ with $L_{dir}$ frequency bands [S2, unofficial].
5.  **Color Network (Block 2)**:
    *   Takes the concatenation of the feature vector $\mathbf{f}$ and the encoded direction $\gamma(\mathbf{d})$ as input [S1].
    *   Consists of 1 fully-connected layer with 128 channels and ReLU activation [S1].
    *   Followed by a final linear layer with Sigmoid activation to output $\mathbf{c} = (r, g, b)$ [S1].

### Numbered Steps (Forward Pass)
1.  **Encode Position**: Compute $\gamma(\mathbf{x})$ for input position $\mathbf{x}$ using $L$ frequency bands [S1].
2.  **Process Position**: Pass $\gamma(\mathbf{x})$ through 8 fully-connected layers (256 channels each) [S1].
    *   Let $h_i$ be the output of layer $i$.
    *   For $i=1$ to 4: $h_i = \text{ReLU}(W_i h_{i-1} + b_i)$, with $h_0 = \gamma(\mathbf{x})$ [S1].
    *   For $i=5$: $h_5 = \text{ReLU}(W_5 h_4 + b_5)$, then concatenate $\gamma(\mathbf{x})$ to $h_5$ along the feature axis [S1].
    *   For $i=6$ to 8: $h_i = \text{ReLU}(W_i h_{i-1} + b_i)$ [S1].
3.  **Output Density and Feature**:
    *   $\sigma_{raw} = W_\sigma h_8 + b_\sigma$ [S1].
    *   $\mathbf{f} = W_f h_8 + b_f$ [S1].
    *   $\sigma = \text{ReLU}(\sigma_{raw})$ [S1].
4.  **Encode Direction**: Compute $\gamma(\mathbf{d})$ for input direction $\mathbf{d}$ using $L_{dir}$ frequency bands [S2, unofficial].
5.  **Concatenate**: Form input for color network: $h_{color\_in} = \text{Concat}(\mathbf{f}, \gamma(\mathbf{d}))$ [S1].
6.  **Process Color**:
    *   $h_{color\_1} = \text{ReLU}(W_{c1} h_{color\_in} + b_{c1})$ (128 channels) [S1].
    *   $\mathbf{c}_{raw} = W_{c2} h_{color\_1} + b_{c2}$ [S1].
    *   $\mathbf{c} = \text{Sigmoid}(\mathbf{c}_{raw})$ [S1].

### Formulas and Definitions
*   **Scene Function**: $F_\Theta(\mathbf{x}, \mathbf{d}) = (\sigma, \mathbf{c})$ [S1].
*   **Positional Encoding**: $\gamma(v) = [\sin(2^0 \pi v), \cos(2^0 \pi v), \dots, \sin(2^{L-1} \pi v), \cos(2^{L-1} \pi v)]$ [S2, unofficial].
*   **Weight Initialization**: Weights $w \sim \text{Uniform}(-1/\sqrt{\text{out\_features}}, 1/\sqrt{\text{out\_features}})$, biases $b = 0$ [S2, unofficial].

### Parameters and Typical Values
*   **Position Encoding Length ($L$)**: 10 [S2, unofficial]. Input dimension: $3 \times 2 \times 10 = 60$ [S2, unofficial].
*   **Direction Encoding Length ($L_{dir}$)**: 6 [S2, unofficial]. Input dimension: $3 \times 2 \times 6 = 36$ [S2, unofficial].
*   **Hidden Dimension (Position)**: 256 channels [S1].
*   **Hidden Dimension (Color)**: 128 channels [S1].
*   **Network Size**: Approximately 5 MB for weights [S1].

### Edge Cases and Pitfalls
*   **View Dependence**: Removing the viewing direction input (predicting color only from $\mathbf{x}$) prevents the model from recreating specular reflections [S1].
*   **Density Non-Negativity**: Volume density $\sigma$ must be non-negative. This is enforced by applying a ReLU activation to the density output layer [S1].
*   **Color Range**: RGB radiance must be in $[0, 1]$. This is enforced by applying a Sigmoid activation to the final color output layer [S1].
*   **High-Frequency Representation**: Directly operating on raw coordinates results in poor high-frequency representation due to spectral bias. Positional encoding is required [S1].
*   **Frequency Limits**: Increasing positional encoding frequencies beyond 10 (for the tested datasets) does not improve performance, as $2^L$ exceeds the maximum frequency present in the sampled input images [S1].

### Pseudocode

```python
import torch
import torch.nn as nn
import math

class PositionalEncoding(nn.Module):
    def __init__(self, num_bands):
        super().__init__()
        self.num_bands = num_bands

    def forward(self, x):
        # x shape: (..., 3) for position or direction
        # Output shape: (..., 3 * 2 * num_bands)
        freq_bands = 2.0 ** torch.arange(self.num_bands, device=x.device).float()
        x = x.unsqueeze(-2).unsqueeze(-1)
        freq_bands = freq_bands.unsqueeze(0).unsqueeze(0).unsqueeze(0)
        
        scaled_x = x * freq_bands * math.pi
        sin_vals = torch.sin(scaled_x)
        cos_vals = torch.cos(scaled_x)
        
        out = torch.cat([sin_vals, cos_vals], dim=-1)
        out = out.view(out.shape[0], -1)
        return out

class NeRFMLP(nn.Module):
    def __init__(self, L=10, L_dir=6, hidden_dim=256, color_hidden_dim=128):
        super().__init__()
        self.pos_enc = PositionalEncoding(L)
        self.dir_enc = PositionalEncoding(L_dir)
        
        # Position Network: 8 layers of 256
        self.pos_layers = nn.ModuleList()
        input_dim = 3 * 2 * L
        for i in range(8):
            self.pos_layers.append(nn.Linear(input_dim, hidden_dim))
            input_dim = hidden_dim
            
        # Output layers for density and feature
        self.density_layer = nn.Linear(hidden_dim, 1)
        self.feature_layer = nn.Linear(hidden_dim, hidden_dim)
        
        # Color Network
        color_input_dim = hidden_dim + 3 * 2 * L_dir
        self.color_layer1 = nn.Linear(color_input_dim, color_hidden_dim)
        self.color_layer2 = nn.Linear(color_hidden_dim, 3)

    def forward(self, x, d):
        # x: (N, 3), d: (N, 3)
        
        # 1. Encode Position
        gamma_x = self.pos_enc(x)
        
        # 2. Process Position
        h = gamma_x
        # Layers 1-4
        for i in range(4):
            h = torch.relu(self.pos_layers[i](h))
        # Layer 5
        h = torch.relu(self.pos_layers[4](h))
        # Skip connection: concatenate gamma_x to h (5th layer activation)
        h = torch.cat([h, gamma_x], dim=-1)
        # Layers 6-8
        for i in range(5, 8):
            h = torch.relu(self.pos_layers[i](h))
        
        # 3. Output Density and Feature
        sigma_raw = self.density_layer(h)
        feature_vec = self.feature_layer(h)
        sigma = torch.relu(sigma_raw) # Ensure non-negative
        
        # 4. Encode Direction
        gamma_d = self.dir_enc(d)
        
        # 5. Concatenate Feature and Direction
        color_input = torch.cat([feature_vec, gamma_d], dim=-1)
        
        # 6. Process Color
        h_color = torch.relu(self.color_layer1(color_input))
        color_raw = self.color_layer2(h_color)
        color = torch.sigmoid(color_raw) # Clamp to [0, 1]
        
        return sigma, color
```

## Subtopics

### [Unbounded inward-facing scene parameterization](957-unbounded-inward-facing-scene-parameterization.md)
Adapts the mip-NeRF 360 parameterization to warp unbounded 360-degree scenes into a bounded unit sphere volume for voxel grid allocation.

### [Position-Only NeRF Field](1253-position-only-nerf-field.md)
A neural field that maps a 3D point to a color and a density using a coordinate MLP with Fourier encoding and skip connections. It is position-only (no view-dependent effects) to keep the model small.

### Tiny NeRF
A compact neural network architecture for NeRF, consisting of three linear layers with ReLU activations, designed to reduce model size compared to the standard NeRF [S3, unofficial].
*   **Layout**: `model_tinyNeRF` contains three layers: `l1` (Linear, input 39, output 128), `l2` (Linear, input 128, output 128), `l3` (Linear, input 128, output 4) [S3, unofficial].
*   **Forward Pass**: Input `gamma` is passed through `l1`. The output is passed through `l2`. The result is passed through `l3` to produce the final output [S3, unofficial].
*   **Input Dimension**: 39, corresponding to 3 (position) + 3 * 2 * 6 (positional encoding, assuming dim_encode=6) [S3, unofficial].

## Operating characteristics
*   **Time Complexity**: Training requires optimizing the network weights $\Theta$ using gradient descent to minimize the error between rendered images and observed input images [S1]. Training takes at least 12 hours per scene [S1]. Rendering a single frame requires 150–200 million network queries, taking approximately 30 seconds per frame on an NVIDIA V100 [S1].
*   **Memory Complexity**: The network weights require only 5 MB, which is a 3000× compression compared to LLFF and less memory than the input images alone for a single scene [S1].
*   **Performance**: Outperforms NV, SRN, and LLFF quantitatively and qualitatively across most scenarios, except for one metric (LPIPS) where LLFF achieves slightly better results [S1].
*   **Strengths**: High-quality novel view synthesis, compact storage, multiview consistency [S1].
*   **Limitations**: Slow training time [S1].
*   **When to use**: When high-quality view synthesis from sparse images is required and storage is a constraint [S1].
*   **When not to use**: When real-time rendering is required [S1].

## Background
The NeRF MLP Architecture was introduced by Mildenhall et al. in 2020 [S1]. It represents a static scene as a continuous 5D function optimized using a fully-connected deep network. The method addresses the long-standing problem of view synthesis by directly optimizing parameters of a continuous 5D scene representation to minimize the error of rendering a set of captured images [S1]. It builds on the concept of neural radiance fields and uses positional encoding to handle high-frequency details, overcoming the spectral bias of standard MLPs [S1].
