# NeRF MLP Architecture

Also called: NeRF MLP, Neural Radiance Field MLP

## Overview
The NeRF MLP Architecture is a multi-layer perceptron (MLP) that maps 3D spatial coordinates and viewing directions to volume density and view-dependent color, serving as the core implicit representation in Neural Radiance Fields [S1, S2, S3]. It differs from its siblings, such as [Scene Representation Networks (SRN)](1150-scene-representation-networks-srn.md) which uses a single network for both geometry and appearance without explicit view-direction conditioning in the same manner, and [SIREN Neural Field](1250-siren-neural-field.md) which uses periodic sine activations, by employing a two-stage fully-connected architecture with ReLU activations, positional encoding, and specific skip connections to model high-frequency details and view-dependent effects [S2][S6, S18, unofficial].

## How it works
**Inputs and Outputs:**
The network $F_\Theta$ takes a 5D input vector consisting of a 3D spatial position $\mathbf{x} = (x, y, z)$ and a 3D viewing direction $\mathbf{d}$ (derived from spherical coordinates $(\theta, \phi)$) [S2][S11, unofficial]. The output is a volume density $\sigma$ and a 3D RGB color vector $\mathbf{c} = (r, g, b)$ [S2][S11, unofficial].

**Data Structures and Layout:**
The architecture consists of two main branches: a position branch (density backbone) and a color branch (view-dependent head) [S12, unofficial].
1.  **Positional Encoding:** Inputs are expanded using a harmonic embedding (positional encoding) [S5, S16, unofficial]. For position $\mathbf{x}$, the encoding $\gamma(\mathbf{x})$ concatenates the original coordinates with $\sin(2^i \pi \mathbf{x})$ and $\cos(2^i \pi \mathbf{x})$ for $i \in [0, L_{pos}-1]$ [S3][S16, unofficial]. For direction $\mathbf{d}$, $\gamma(\mathbf{d})$ uses $L_{dir}$ frequencies [S16, unofficial].
2.  **Position MLP (Density Backbone):** An MLP with $D$ hidden layers (default $D=8$) [S2][S6, unofficial]. Each hidden layer has width $W$ (default 256) and uses ReLU activation [S2][S18, unofficial]. A skip connection concatenates the original encoded position $\gamma(\mathbf{x})$ to the output of the 5th layer (index 4, 0-based) [S2][S9, S18, unofficial].
3.  **Output Heads:** The final layer of the Position MLP outputs a scalar $\sigma$ and a feature vector $\mathbf{e}$ of size $W$ [S2].
    *   **Density:** $\sigma$ is passed through a linear layer (or directly taken) and rectified. The original paper uses $\sigma = \text{softplus}(h - 1)$ where $h$ is the raw output, ensuring sparser initialization [S9, unofficial]. Other implementations use ReLU [S2][S16, unofficial].
    *   **Feature:** The feature vector $\mathbf{e}$ is projected (often via a linear layer) to size $W$ [S9, unofficial].
4.  **Color MLP (View-Dependent Head):** The feature vector $\mathbf{e}$ is concatenated with the encoded direction $\gamma(\mathbf{d})$ [S2]. This combined vector is passed through a single hidden layer of width $W/2$ (default 128) with ReLU activation [S2][S12, unofficial]. A final linear layer outputs 3 RGB values, passed through a Sigmoid activation to clamp values to $[0, 1]$ [S2][S16, unofficial].

**Parameters:**
*   $L_{pos}$: Positional encoding depth for position. Default: 10 [S11, S16, unofficial]. Input dimension: $3 \times (1 + 2L_{pos}) = 63$ [S12, unofficial].
*   $L_{dir}$: Positional encoding depth for direction. Default: 4 or 6 [S11, S16, unofficial]. Input dimension: $3 \times (1 + 2L_{dir}) = 27$ (for $L=4$) or $39$ (for $L=6$) [S11, S16, unofficial].
*   $D$: Number of hidden layers in position MLP. Default: 8 [S6, S7, unofficial].
*   $W$: Hidden layer width. Default: 256 [S2][S15, unofficial].
*   $W_{dir}$: Width of color head hidden layer. Default: 128 [S2][S12, unofficial].
*   Skip indices: Typically `[4]` [S9, S10, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class NeRFMLP(nn.Module):
    def __init__(self, L_pos=10, L_dir=4, D=8, W=256, skip_indices=[4]):
        super().__init__()
        self.L_pos = L_pos
        self.L_dir = L_dir
        
        # Input dimensions after positional encoding
        # 3 coords + 2 * L * 3 sin/cos terms
        self.input_ch = 3 + 2 * L_pos * 3
        self.input_ch_views = 3 + 2 * L_dir * 3
        
        # Position MLP layers
        # First layer: input_ch -> W
        # Layers in skip_indices: (W + input_ch) -> W
        # Other layers: W -> W
        self.pos_linears = nn.ModuleList()
        
        # Layer 0
        self.pos_linears.append(nn.Linear(self.input_ch, W))
        
        for i in range(1, D):
            if i in skip_indices:
                self.pos_linears.append(nn.Linear(W + self.input_ch, W))
            else:
                self.pos_linears.append(nn.Linear(W, W))
                
        # Output heads
        # Density head: W -> 1
        self.sigma_head = nn.Linear(W, 1)
        # Feature projection: W -> W (optional in some impls, but standard to keep dim consistent)
        self.feature_proj = nn.Linear(W, W)
        
        # Color head
        # Input: W (feature) + input_ch_views (direction)
        self.color_head1 = nn.Linear(W + self.input_ch_views, W // 2)
        self.color_head2 = nn.Linear(W // 2, 3)
        
    def forward(self, x, d):
        """
        x: (N, 3) spatial coordinates
        d: (N, 3) viewing directions
        """
        # 1. Positional Encoding
        x_enc = positional_encoding(x, self.L_pos)
        d_enc = positional_encoding(d, self.L_dir)
        
        # 2. Position MLP (Density Backbone)
        h = x_enc
        for i, layer in enumerate(self.pos_linears):
            if i in [idx for idx in self.pos_linears if idx in [0]]: # Logic handled in init, but here we track index
                pass
            
            # Apply layer
            h = layer(h)
            
            # Skip connection: concatenate original encoded position at specific layers
            # Note: In the standard NeRF paper, skip is at layer 4 (5th layer, index 4)
            # The concatenation happens BEFORE the activation in some descriptions, 
            # but typically the layer output is concatenated with input, then activated.
            # Based on [S2][S9, S18, unofficial]: "concatenate this input to the fifth layer's activation"
            # However, standard PyTorch impls [S6, S9, unofficial] often do:
            # if i in skip_indices: h = torch.cat([h, x_enc], dim=-1)
            # h = F.relu(layer(h))
            # Let's follow the explicit code in [S9, unofficial]:
            # if i == self.skip_layer: x = torch.cat([x, pos_enc], dim=-1)
            # x = F.relu(layer(x))
            
            # Re-implementing loop logic to match [S9, unofficial] exactly:
            pass 
            
        # Correct loop based on [S9, unofficial] code snippet:
        h = x_enc
        for i, layer in enumerate(self.pos_linears):
            if i in [4]: # Default skip index
                h = torch.cat([h, x_enc], dim=-1)
            h = F.relu(layer(h))
            
        # 3. Density and Feature Extraction
        # Density: softplus(h - 1) as per [S9, unofficial], or ReLU as per [S2]
        # We use softplus for fidelity to the specific "shift for sparser init" detail in [S9, unofficial]
        sigma_raw = self.sigma_head(h)
        sigma = F.softplus(sigma_raw - 1)
        
        # Feature
        feat = self.feature_proj(h)
        
        # 4. Color Head
        # Concatenate feature and direction encoding
        feat_dir = torch.cat([feat, d_enc], dim=-1)
        
        # Pass through color head
        h_color = F.relu(self.color_head1(feat_dir))
        rgb = torch.sigmoid(self.color_head2(h_color))
        
        return sigma, rgb

def positional_encoding(x, L):
    """
    x: (N, 3)
    Returns: (N, 3 + 6*L)
    """
    # Original coordinates
    out = [x]
    
    # Sin/Cos frequencies
    for i in range(L):
        freq = 2**i * torch.pi
        out.append(torch.sin(freq * x))
        out.append(torch.cos(freq * x))
        
    return torch.cat(out, dim=-1)
```

**Edge Cases and Pitfalls:**
*   **Precision:** The use of `softplus` with a shift of -1 for density initialization helps prevent the network from predicting zero density everywhere initially [S9, unofficial].
*   **Boundaries:** Spatial coordinates are typically normalized to $[-1, 1]$ or mapped via unbounded parameterizations for large scenes [S2][S9, unofficial].
*   **View Independence:** Density $\sigma$ is predicted solely from position $\mathbf{x}$ to enforce multiview consistency [S2, S13].

## Subtopics

### [Unbounded inward-facing scene parameterization](957-unbounded-inward-facing-scene-parameterization.md)
Parameterizes unbounded 3D scenes into a bounded volume by mapping coordinates from $[-\infty, \infty]^d$ to a finite domain, preserving radial direction while compressing magnitude.

### [Position-Only NeRF Field](1253-position-only-nerf-field.md)
Omits viewing direction input to reduce model size, assuming isotropic appearance.

### [Tiny NeRF](1275-tiny-nerf.md)
Compresses voxel-based NeRFs via DCT and pruning, operating on frequency coefficients rather than MLP weights.

### [MLPRender_Fea](2414-mlprender-fea.md)
Applies positional encoding only to features and view directions, not position, separating positional info from appearance decoding.

### [View-Dependent MLP](2444-view-dependent-mlp.md)
Uses a larger hidden dimension and specific skip connections to model complex view-dependent effects like specularities.

### [NeUDF Network Architecture](3732-neudf-network-architecture.md)
Uses two distinct MLPs to represent Unsigned Distance Field (geometry) and radiance field (color) separately.

### [InstantNGP Network Architecture](5049-instantngp-network-architecture.md)
Combines a multiresolution hash grid with a lightweight MLP for instant training and rendering.

### Recursive Neural Field
A sub-network $F_{\Phi_i}$ that takes its parent branch's output $y_{p_i}$ and viewing direction $d$ as inputs, predicting color $c_i$, density $\sigma_i$, uncertainty $\delta_i$, and a latent vector $y_i$ [S22]. It consists of an MLP module, a Branch module (predicting uncertainty and distributing points), and an Out module (decoding features) [S22]. The root network $F_{\Phi_1}$ takes the query coordinate $(x, y, z)$ as input [S22].

### VFR Network Architecture
Uses a Multiresolution Hash Grid (MHG) for feature representation. The Color NN consists of a Spatial MLP (2 layers, 256 hidden neurons) and a Directional MLP (4 layers, 256 hidden neurons) with GELU activation and a 256-dimensional bottleneck feature [S23].

### CT-NeRF Network Architecture
Follows the BARF approach, using a single 8-layer MLP network with a width of 128 [S24, unofficial].

### Soft Zero-Skipping Gate
A component added to the MLP to ensure that a feature compressed to 0 translates to a zero density. It applies a differentiable gate $\hat{g}(v) = \tanh(\alpha \|v\|_2)$ to the MLP output $M(v)$, such that $\hat{M}(v) = \hat{g}(v) M(v)$ [S25]. The parameter $\alpha$ is scheduled from $10^4$ to $10^5$ [S25]. This allows smooth transitions and non-zero gradients for pruning, unlike hard gates [S25].

### DoubleField Network
A joint implicit function represented by MLPs that fits a surface field and radiance field simultaneously, conditioned on pixel-aligned image features [S26]. It uses a Shared MLP ($E_{db}$) to produce a double embedding, a Geometry MLP ($E_g$) for surface field $s$ and density $\sigma$, and a Texture MLP ($E_c$) for color $c$ [S26].

## Operating characteristics
*   **Time Complexity:** Training is computationally expensive, requiring millions of network queries per image. On an NVIDIA V100, rendering a single frame takes approximately 30 seconds [S2].
*   **Memory Complexity:** Memory usage is constant with respect to spatial resolution, determined by the number of MLP weights (e.g., ~5 MB for the network weights) [S2]. This is significantly less than voxel-based methods like LLFF (over 15 GB) [S2].
*   **Performance:** Achieves state-of-the-art view synthesis quality on complex scenes, outperforming SRN and NV [S2].
*   **Strengths:** Continuous representation, infinite resolution, compact storage, handles view-dependent effects [S2, S1].
*   **Limitations:** Slow training and rendering times compared to explicit methods [S2, S26]. Sensitive to positional encoding frequencies; too few reduce high-frequency detail, too many offer diminishing returns [S2].

## Background
The NeRF MLP Architecture was introduced by Mildenhall et al. in the paper "NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis" (2020) [S2]. It represents a static scene as a continuous 5D function optimized using gradient descent to minimize the photometric error between rendered and observed images [S2, S3]. It builds on the principles of implicit neural representations [S1] and positional encoding techniques [S2].
