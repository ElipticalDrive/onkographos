# NeRF MLP Architecture

Also called: NeRF MLP, Neural Radiance Field MLP, NeRF Network, Neural Radiance Field Network, NeRF Architecture, NeRF Network Architecture, NeRF Model Architecture

## Overview
The NeRF MLP Architecture is a multi-layer perceptron (MLP) that maps 5D coordinates—3D spatial location $\mathbf{x}$ and viewing direction $\mathbf{d}$—to volume density $\sigma$ and view-dependent emitted color $\mathbf{c}$ [S1]. It solves the problem of representing complex 3D scenes as continuous volumetric functions for novel view synthesis [S1]. It differs from its siblings by enforcing a specific two-branch topology: a view-independent density backbone and a view-dependent color head, combined with positional encoding to overcome spectral bias [S1][S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A batch of 5D coordinates. Spatial position $\mathbf{x} = (x, y, z)$ and viewing direction $\mathbf{d}$ (represented as a 3D Cartesian unit vector derived from spherical coordinates $(\theta, \phi)$) [S1].
*   **Output:** Volume density $\sigma \in [0, \infty)$ and RGB color $\mathbf{c} \in [0, 1]$ [S1].

**Data Structures:**
The network consists of two main components:
1.  **Positional Encoding:** A function $\gamma(\cdot)$ that maps a 1D input $v$ to a vector of size $2L+1$: $[v, \sin(2^0 \pi v), \cos(2^0 \pi v), \dots, \sin(2^{L-1} \pi v), \cos(2^{L-1} \pi v)]$ [S13, unofficial].
2.  **MLP Layers:** Fully connected linear layers with ReLU activations, except for specific output heads.

**Parameters:**
*   $L_{pos}$: Number of frequency bands for position encoding. Default: 10 [S13, unofficial]. Input dimension $D_{pos} = 3(1 + 2L_{pos}) = 63$ [S10, unofficial].
*   $L_{dir}$: Number of frequency bands for direction encoding. Default: 4 [S9, unofficial] or 6 [S13, unofficial]. Input dimension $D_{dir} = 3(1 + 2L_{dir})$. With $L_{dir}=4$, $D_{dir}=27$ [S9, unofficial]; with $L_{dir}=6$, $D_{dir}=39$ [S13, unofficial].
*   $W$: Hidden layer width. Default: 256 [S1].
*   $D$: Number of hidden layers in the position backbone. Default: 8 [S1].
*   $S$: Index of the skip connection layer. Default: 4 (0-indexed, so the 5th layer) [S1].
*   $W_{dir}$: Hidden width of the view-dependent branch. Default: 128 [S1].

**Algorithm:**
1.  **Encode Inputs:** Apply positional encoding to $\mathbf{x}$ and $\mathbf{d}$:
    $$ \mathbf{x}_{enc} = \gamma(\mathbf{x}), \quad \mathbf{d}_{enc} = \gamma(\mathbf{d}) $$
2.  **Process Position (Density Backbone):**
    *   Initialize hidden state $\mathbf{h} = \mathbf{x}_{enc}$.
    *   Iterate through layers $i = 0$ to $D-1$:
        *   If $i == S$, concatenate $\mathbf{x}_{enc}$ to $\mathbf{h}$: $\mathbf{h} = [\mathbf{h}, \mathbf{x}_{enc}]$.
        *   Apply linear layer $L_i$: $\mathbf{h} = L_i(\mathbf{h})$.
        *   Apply ReLU activation: $\mathbf{h} = \text{ReLU}(\mathbf{h})$.
3.  **Extract Density and Features:**
    *   The output of the backbone $\mathbf{h}$ has dimension $W$.
    *   Compute raw density $\sigma_{raw}$ using a linear layer $L_{\sigma}$ (output dim 1): $\sigma_{raw} = L_{\sigma}(\mathbf{h})$ [S7, unofficial].
    *   Compute feature vector $\mathbf{f}$ using a linear layer $L_{f}$ (output dim $W$): $\mathbf{f} = L_{f}(\mathbf{h})$ [S7, unofficial].
    *   *Note on Density Activation:* The original paper [S1] and some implementations [S10, unofficial] use ReLU: $\sigma = \text{ReLU}(\sigma_{raw})$. However, the official implementation [S7, unofficial] uses softplus with a shift for sparser initialization: $\sigma = \text{softplus}(\sigma_{raw} - 1)$. Both ensure $\sigma \ge 0$.
4.  **Process Direction (Color Head):**
    *   Concatenate the feature vector $\mathbf{f}$ with the encoded direction $\mathbf{d}_{enc}$: $\mathbf{v} = [\mathbf{f}, \mathbf{d}_{enc}]$.
    *   Apply a linear layer $L_{dir1}$ (input dim $W + D_{dir}$, output dim $W_{dir}$): $\mathbf{h}_{dir} = L_{dir1}(\mathbf{v})$.
    *   Apply ReLU: $\mathbf{h}_{dir} = \text{ReLU}(\mathbf{h}_{dir})$.
    *   Apply a final linear layer $L_{rgb}$ (input dim $W_{dir}$, output dim 3): $\mathbf{c}_{raw} = L_{rgb}(\mathbf{h}_{dir})$.
    *   Apply Sigmoid activation to clamp RGB to $[0, 1]$: $\mathbf{c} = \text{Sigmoid}(\mathbf{c}_{raw})$ [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class PositionalEncoding(nn.Module):
    def __init__(self, num_freq_bands):
        super().__init__()
        self.num_freq_bands = num_freq_bands

    def forward(self, x):
        # x shape: (..., 3)
        # Output shape: (..., 3 * (1 + 2 * num_freq_bands))
        freq_bands = 2.0 ** torch.arange(self.num_freq_bands, device=x.device).float()
        # Expand dimensions for broadcasting
        # x: (..., 3) -> (..., 1, 3)
        # freq_bands: (num_freq_bands,) -> (num_freq_bands, 1)
        # pi: scalar
        # Result: (..., num_freq_bands, 3) for sin and cos
        s = torch.sin(x.unsqueeze(-2) * freq_bands.unsqueeze(-1) * torch.pi)
        c = torch.cos(x.unsqueeze(-2) * freq_bands.unsqueeze(-1) * torch.pi)
        # Concatenate original x, sin, cos along the last dimension
        # x: (..., 3)
        # s, c: (..., num_freq_bands, 3)
        # Reshape s, c to (..., num_freq_bands * 3)
        s = s.view(*x.shape[:-1], -1)
        c = c.view(*x.shape[:-1], -1)
        return torch.cat([x, s, c], dim=-1)

class NeRFMLP(nn.Module):
    def __init__(self, 
                 pos_encoding_len=10, 
                 dir_encoding_len=4, 
                 hidden_dim=256, 
                 num_layers=8, 
                 skip_layer=4,
                 dir_hidden_dim=128):
        super().__init__()
        
        self.pos_enc = PositionalEncoding(pos_encoding_len)
        self.dir_enc = PositionalEncoding(dir_encoding_len)
        
        # Position Backbone
        # Layer 0: Input dim -> hidden_dim
        self.layers = nn.ModuleList([
            nn.Linear(3 * (1 + 2 * pos_encoding_len), hidden_dim)
        ])
        
        # Layers 1 to num_layers-1
        for _ in range(num_layers - 1):
            self.layers.append(nn.Linear(hidden_dim, hidden_dim))
            
        # Skip connection logic is handled in forward, but we need to know input dims
        # Actually, standard NeRF implementation keeps layer dims fixed at hidden_dim
        # except for the skip connection which increases input dim temporarily.
        # The linear layers themselves are defined as hidden_dim -> hidden_dim.
        # The concatenation happens before the linear layer.
        
        # Output Heads
        self.sigma_head = nn.Linear(hidden_dim, 1)
        self.feature_head = nn.Linear(hidden_dim, hidden_dim)
        
        # Color Head
        # Input: hidden_dim + dir_encoded_dim
        dir_encoded_dim = 3 * (1 + 2 * dir_encoding_len)
        self.color_head_1 = nn.Linear(hidden_dim + dir_encoded_dim, dir_hidden_dim)
        self.color_head_2 = nn.Linear(dir_hidden_dim, 3)
        
        self.skip_layer = skip_layer
        self.hidden_dim = hidden_dim

    def forward(self, x, d):
        """
        x: (..., 3) Spatial coordinates
        d: (..., 3) Viewing directions
        """
        # 1. Encode inputs
        x_enc = self.pos_enc(x)
        d_enc = self.dir_enc(d)
        
        # 2. Process Position Backbone
        h = x_enc
        for i, layer in enumerate(self.layers):
            if i == self.skip_layer:
                # Concatenate original encoded position
                h = torch.cat([h, x_enc], dim=-1)
            h = layer(h)
            h = F.relu(h)
            
        # 3. Extract Density and Features
        # Note: Original paper [S1] uses ReLU for sigma. 
        # Official code [S7, unofficial] uses softplus(h - 1). We follow [S7, unofficial] as it is the reference implementation.
        sigma_raw = self.sigma_head(h)
        sigma = F.softplus(sigma_raw - 1)
        
        features = self.feature_head(h)
        
        # 4. Process Color Head
        # Concatenate features with encoded direction
        color_input = torch.cat([features, d_enc], dim=-1)
        
        h_color = self.color_head_1(color_input)
        h_color = F.relu(h_color)
        
        rgb_raw = self.color_head_2(h_color)
        rgb = torch.sigmoid(rgb_raw)
        
        return sigma, rgb
```

## Subtopics

### [Unbounded inward-facing scene parameterization](957-unbounded-inward-facing-scene-parameterization.md)
Parameterizes unbounded 360-degree scenes by mapping coordinates to a bounded domain, enabling voxel grid acceleration.

### [Position-Only NeRF Field](1253-position-only-nerf-field.md)
Omits viewing direction input to reduce model size, assuming isotropic appearance.

### [Tiny NeRF](1275-tiny-nerf.md)
Compresses voxel-based NeRFs via DCT and quantization.

### [MLPRender_Fea](2414-mlprender-fea.md)
Predicts RGB from pre-computed spatial features and view directions, excluding position from the MLP input.

### [View-Dependent MLP](2444-view-dependent-mlp.md)
Expands the view-dependent color decoding stage of iNGP to reduce floaters.

### [InstantNGP Network Architecture](5049-instantngp-network-architecture.md)
Uses multi-resolution hash encoding for real-time rendering.

### Recursive Neural Field
A sub-network $F_{\Phi_i}$ that takes its parent branch's output $y_{p_i}$ and viewing direction $d$ as inputs, predicting color $c_i$, density $\sigma_i$, uncertainty $\delta_i$, and a latent vector $y_i$ [S17]. The root sub-network $F_{\Phi_1}$ takes the query coordinate $(x, y, z)$ as $y_{p_i}$ [S17]. It consists of an MLP module, a Branch module (predicting uncertainty and routing high-uncertainty points to sub-networks), and an Out module (decoding features) [S17].

### NeUDF Network Architecture
Uses two separate MLPs: a UDF network (8 layers, 256 hidden, Softplus activation, skip connection at layer 4) and a Color network (4 layers, 256 hidden) [S18]. The Color network inputs spatial location, view direction, the normalized gradient of the UDF, and the 256-dim feature vector from the UDF network [S18].

### VFR Network Architecture
Uses a Multiresolution Hash Grid for feature representation [S19]. The Color NN consists of a Spatial MLP (2 layers, 256 hidden) and a Directional MLP (4 layers, 256 hidden) with GELU activation [S19].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot D \cdot W)$ per ray sample, where $N$ is the number of samples per ray, $D$ is the number of hidden layers, and $W$ is the hidden dimension [S1].
*   **Memory Complexity:** $O(D \cdot W^2)$ for weights. The original NeRF model requires approximately 5 MB for network weights [S1].
*   **Performance:** On an NVIDIA V100, rendering one frame (querying ~150-200 million rays) takes approximately 30 seconds [S1].
*   **Strengths:** High-quality view synthesis, compact storage (5 MB vs GBs for voxel grids) [S1], handles complex geometry and appearance [S1].
*   **Limitations:** Slow rendering speed without acceleration structures [S16], struggles with high-frequency details without positional encoding [S1], requires significant training time (12+ hours per scene) [S1].
*   **When to use:** When high-quality novel view synthesis is required and computational resources for training are available, but storage for explicit geometry is limited [S1].
*   **When not to use:** When real-time rendering is required without acceleration structures [S16], or when view-dependent effects are negligible and a simpler position-only model suffices [S12, unofficial].

## Background
The NeRF MLP Architecture was introduced by Mildenhall et al. in the paper "NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis" (ECCV 2020) [S1]. It addresses the limitations of previous neural rendering methods like SRN and NV by using a fully-connected MLP with positional encoding and a specific two-branch architecture to enforce multiview consistency for density while allowing view-dependent color [S1]. The method optimizes the network weights by minimizing the difference between rendered and ground truth images using differentiable volume rendering [S1].
