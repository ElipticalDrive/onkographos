# Neural Volume Construction

Also called: Sparse 3D ConvNet Feature Aggregation, Sparse Tensor Construction

## Overview
Neural Volume Construction is the process of generating a dense, spatially aligned neural feature volume from sparse, noisy 3D primitives (such as Gaussian centers or point clouds). It solves the problem of initializing a generalizable 3D latent representation that integrates local and global scene information, which is required for subsequent decoding of geometry and appearance parameters [S1]. It differs from sibling methods by explicitly constructing a 3D tensor via a sparse 3D ConvNet, whereas [TensoRF Vector-Matrix Decomposition](9759-tensorf-vector-matrix-decomposition.md) uses factorized matrices and [DINO ViT Feature Extraction](6425-dino-vit-feature-extraction.md) relies on 2D image-based encoders [S1].

## How it works
**Inputs:**
*   $\mathcal{P}$: A set of initialized noisy 3D primitives (e.g., Gaussian centers or point cloud points).
*   $H, W, D$: Spatial resolution of the target feature volume.
*   $C$: Feature dimension of the output volume.

**Outputs:**
*   $\mathbf{F} \in \mathbb{R}^{H \times W \times D \times C}$: The aggregated neural feature volume aligned with the world coordinate system.

**Data Structures:**
*   **Sparse Tensor:** The input $\mathcal{P}$ is represented as a sparse tensor to handle large scenes efficiently. The structure retains only non-empty voxels or primitive locations, reducing memory usage compared to a dense grid.
*   **Feature Volume:** A dense 4D tensor $\mathbf{F}$ where each voxel $(x, y, z)$ contains a $C$-dimensional feature vector.

**Algorithm:**
1.  **Sparse Tensor Initialization:** Construct a sparse tensor from the input primitives $\mathcal{P}$. This involves mapping the 3D coordinates of the primitives to the sparse tensor indices.
2.  **Sparse 3D ConvNet Processing:** Pass the sparse tensor through a sparse 3D ConvNet $\psi^{3D}$. The network architecture follows an encoder-decoder structure with a bottleneck of low spatial dimension. Skip connections are added between encoder and decoder layers to preserve both local and global information [S1].
3.  **Feature Aggregation:** The network aggregates features from the sparse primitives into the dense volume $\mathbf{F}$. The output $\mathbf{F}$ is aligned with the world coordinate system, meaning voxel $(i, j, k)$ corresponds to a specific world position [S1].

**Formula:**
$$ \mathbf{F} = \psi^{3D}(\mathcal{P}) $$
Where:
*   $\mathbf{F}$ is the output feature volume.
*   $\psi^{3D}$ is the sparse 3D ConvNet.
*   $\mathcal{P}$ is the input sparse tensor of primitives.

**Parameters:**
*   $H, W, D$: Spatial resolution. Not given in the sources.
*   $C$: Feature dimension. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Precision:** Trilinear interpolation is used later to query features from $\mathbf{F}$, so the volume must be sufficiently dense to avoid aliasing artifacts during querying [S1].
*   **Boundaries:** The volume is aligned with the world coordinate system, so boundary handling depends on the coordinate system definition. Not given in the sources.

**Pseudocode:**
```python
def construct_neural_volume(primitives: List[Primitive], 
                            spatial_res: Tuple[int, int, int], 
                            feature_dim: int) -> Tensor:
    """
    Constructs a neural feature volume from sparse primitives using a sparse 3D ConvNet.
    
    Args:
        primitives: List of 3D primitives (e.g., Gaussian centers) with associated attributes.
        spatial_res: Tuple (H, W, D) defining the spatial resolution of the output volume.
        feature_dim: Integer C, the dimensionality of the feature vector per voxel.
        
    Returns:
        F: Tensor of shape (H, W, D, C) representing the neural feature volume.
    """
    # Step 1: Construct sparse tensor from primitives
    # Map primitive coordinates to sparse tensor indices.
    # This step handles the conversion from a list of points to a sparse data structure.
    sparse_tensor = build_sparse_tensor(primitives)
    
    # Step 2: Define the sparse 3D ConvNet architecture
    # The network is an encoder-decoder with a bottleneck and skip connections.
    # The specific architecture details (kernel sizes, strides) are not provided in the sources.
    conv_net = Sparse3DConvNet(
        input_channels=primitives.feature_channels, # Assumed from primitive attributes
        output_channels=feature_dim,
        spatial_res=spatial_res,
        has_skip_connections=True
    )
    
    # Step 3: Aggregate features using the sparse 3D ConvNet
    # The output F is aligned with the world coordinate system.
    F = conv_net(sparse_tensor)
    
    return F
```

### Precomputed Sampling Features
Precomputed sampling features are used to accelerate neural network input generation by storing pre-calculated transmission and phase features in a table [S2, unofficial]. This involves performing 4129 template samplings for each volume of medium using a uniform sampling strategy [S2, unofficial]. For each sample, 254 sampled transmission features and 254 phase transmission features are generated [S2, unofficial].

**Phase Features:**
1.  Find the volume phase of all template points using formula 6 (MHG/HG) [S2, unofficial].
2.  Set all possible angles between incident light and camera direction [S2, unofficial].
3.  Find phase features using formulas 2, 3, 4, and 5 [S2, unofficial].
4.  Pre-calculate all sampling points and save to a table [S2, unofficial].

**Transmission Features:**
1.  Obtain a graded density field by downsampling the density field to get a graded transmission field [S2, unofficial].
2.  Generate transmission features through a 3D-CNN [S2, unofficial].
3.  Obtain sampling transmission features through a sampling template [S2, unofficial].
4.  Pre-calculate and store all sampling points in a pre-calculation table [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Integrates local and global information in different network layers for faithful reconstructions [S1]. Efficiently handles large scenes via sparse tensor representation [S1].
*   **Limitations:** Requires a 3D ConvNet, which may be more computationally intensive than 2D image-to-image networks [S1].
*   **When to use:** When a generalizable 3D latent neural volume is needed for modeling prior knowledge across scenes [S1].
*   **When not to use:** When 2D image-based encoding is sufficient or when memory constraints prevent storing a dense 3D volume [S1].

## Background
Neural Volume Construction was introduced in the context of efficient volume-based Gaussian Splatting for urban view synthesis [S1]. It draws inspiration from previous works on generalizable 3D latent neural volumes [S1]. The method was developed to address the limitations of feed-forward Gaussian Splatting works that use 2D image-to-image neural networks, by providing a 3D latent representation that better integrates local and global information [S1].
