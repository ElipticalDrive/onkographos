# Domain Decomposition with Ghost Cells

Also called: Data Partitioning with Ghost Cells, Domain Decomposition Network

## Overview
This method extends the Domain Decomposition Training and Inference strategy by extending each network's spatial extent with overlapping ghost cells to mitigate boundary artifacts and visible seams during visualization [S1]. It distinguishes itself from the parent method by explicitly adding redundant boundary layers, which trades a slight reduction in learning capacity for improved visual continuity [S1].

## How it works
**Inputs and Outputs:**
- **Input:** Global volume domain dimensions, decomposition grid resolution ($I, J, K$), internal feature grid resolution per SRN, and ghost cell count ($G$) [S1].
- **Output:** A set of trained SRN models and feature grids, where each model's effective domain includes ghost cell extensions [S1].

**Data Structures:**
Each SRN maintains its own decoder and feature grids [S1]. The global domain is divided into an $I \times J \times K$ grid of bricks [S1]. Each SRN's feature grid is typically cubic (e.g., $32^3$) [S1]. The effective volume processed by an SRN comprises its core assigned brick plus $G$ overlapping ghost cells along each axis [S1].

**Numbered Steps:**
1. **Determine Decomposition Grid:** Choose integers $I, J, K$ for the number of networks along width, height, and depth [S1]. Select $I, J, K$ so the aspect ratio of the volume assigned to each network matches the aspect ratio of the SRN's internal feature grids (e.g., if feature grids are $32^3$, assign roughly cube-shaped volumes) [S1].
2. **Calculate Extents with Ghost Cells:** Pre-calculate the spatial extent for each network within the global volume, extending the boundaries of each assigned brick by $G$ cells along each axis to create overlaps with adjacent networks [S1].
3. **Data Partitioning:** Assign volumetric data to each network based on its extended extent, duplicating data within ghost cell regions across adjacent networks [S1].
4. **Parallel Training:** Train each SRN independently on its assigned data partition (including ghost cells) in parallel across available GPUs [S1].
5. **Inference/Rendering:** Query the appropriate SRN for a given 3D coordinate [S1]. If a coordinate falls within the ghost cell region of multiple networks, the implementation must define a resolution strategy (e.g., using the network whose core volume contains the point) [G]. Ghost cells ensure adjacent network outputs are more similar at boundaries, reducing visible seams [S1].

**Formulas:**
- Core extent per axis: $E_{core} = \frac{D}{N}$, where $D$ is the global dimension and $N$ is the grid count ($I, J, K$) [S1].
- Effective extent per axis: $E_{eff} = E_{core} + 2G$, where $G$ is the number of ghost cells along that axis [S1].

**Parameters:**
- **Ghost Cell Count ($G$):** Number of overlapping cells along each axis [S1].
    - **Default:** 1 ghost cell for corner alignment [S1].
    - **Isosurface Extraction:** Up to 16 ghost cells to reduce seams [S1].
    - **Experimental Range:** 1 to 16 ghost cells [S1].

**Edge Cases and Pitfalls:**
- **Learning Capacity Reduction:** Increasing ghost cells increases the redundant volume each network must learn (e.g., from $256^3$ to $288^3$), reducing effective learning capacity and causing a PSNR drop of -1 dB when increasing from 1 to 16 ghost cells [S1].
- **Seam Removal:** Ghost cells do not guarantee complete seam removal; they only tend to reduce their effect by ensuring networks learn beyond the actual boundary [S1].

**Pseudocode:**
```python
def setup_domain_decomposition(global_dims, I, J, K, ghost_cells):
    """
    Sets up the domain decomposition with ghost cells.
    Args:
        global_dims: Tuple (W, H, D) of the global volume dimensions.
        I, J, K: Integers, number of networks along width, height, depth.
        ghost_cells: Integer, number of overlapping cells per axis.
    Returns:
        List of network configurations with core and effective extents.
    """
    base_res_w = global_dims[0] / I
    base_res_h = global_dims[1] / J
    base_res_d = global_dims[2] / K
    
    networks = []
    for i in range(I):
        for j in range(J):
            for k in range(K):
                x_start = i * base_res_w
                x_end = (i + 1) * base_res_w
                y_start = j * base_res_h
                y_end = (j + 1) * base_res_h
                z_start = k * base_res_d
                z_end = (k + 1) * base_res_d
                
                effective_x_start = x_start - ghost_cells
                effective_x_end = x_end + ghost_cells
                effective_y_start = y_start - ghost_cells
                effective_y_end = y_end + ghost_cells
                effective_z_start = z_start - ghost_cells
                effective_z_end = z_end + ghost_cells
                
                networks.append({
                    'id': (i, j, k),
                    'core_extent': (x_start, x_end, y_start, y_end, z_start, z_end),
                    'effective_extent': (effective_x_start, effective_x_end, 
                                         effective_y_start, effective_y_end, 
                                         effective_z_start, effective_z_end),
                    'ghost_cells': ghost_cells
                })
    return networks

def query_network(networks, point):
    """
    Queries the appropriate network for a given point.
    Note: The source does not specify the exact tie-breaking rule for 
    points in ghost cell regions. A common implementation is to use 
    the network where the point is in the core volume, or the first 
    network that contains the point.
    """
    for network in networks:
        ext = network['effective_extent']
        if (ext[0] <= point[0] < ext[1] and
            ext[2] <= point[1] < ext[3] and
            ext[4] <= point[2] < ext[5]):
            return network
    return None
```

## Operating characteristics
- **Time Complexity:** Training time scales with the number of networks ($I \cdot J \cdot K$) [S1]. Training is slower on a single GPU due to serial execution, but scales efficiently across multiple GPUs [S1].
- **Memory Complexity:** Total memory is the sum of feature grids and decoder weights for all networks [S1]. Ghost cells increase the data volume each network processes during training, which reduces effective learning capacity per unique voxel [S1].
- **Performance:** Outperforms a single large model at the same storage size because each sub-model has its own decoder and feature grids [S1].
- **Strengths:** Handles data exceeding single-GPU memory without out-of-core I/O overhead; reduces boundary artifacts [S1].
- **Limitations:** Serial training on one GPU is slower; increasing ghost cells degrades PSNR due to reduced learning capacity [S1].

## Background
Introduced in the TVCG 2023 paper "Adaptively Placed Multi-Grid Scene Representation Networks for Large-Scale Data Visualization" [S1]. Developed to enable training on large-scale datasets (e.g., rotstrat at 250GB and channel at 450GB) that exceed standard GPU memory limits [S1]. Provides an efficient alternative to out-of-core training routines by partitioning data into bricks trained in parallel [S1].
