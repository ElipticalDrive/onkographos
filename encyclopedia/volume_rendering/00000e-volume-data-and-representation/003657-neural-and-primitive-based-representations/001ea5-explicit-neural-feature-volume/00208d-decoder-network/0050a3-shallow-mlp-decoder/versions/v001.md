# Shallow MLP Decoder

Also called: Color Decoder, Decoder Architectures, Density Decoder, Implicit MLP, Volume Density and Color Decoder

## Overview
The Shallow MLP Decoder is a neural network component that transforms a concatenated feature embedding vector into volume density and per-point color values [S1, unofficial]. It serves as the final stage in explicit neural feature volume pipelines, acting as a regularizer to improve reconstruction quality in difficult conditions [S1, 2301-decoder-network.md, unofficial]. It is distinguished from deeper implicit MLPs (like standard NeRF) by its shallow depth and its reliance on pre-computed feature embeddings rather than raw coordinates, offering a trade-off between performance and resource utilization [S1, unofficial].

## How it works
The decoder takes a feature vector $F$ as input and outputs a scalar density $\sigma$ and a color vector $c$ [S1, unofficial].

**Inputs and Outputs:**
*   **Input:** Feature vector $F$ of size $L \cdot F$, where $L$ is the number of resolution levels and $F$ is the feature dimension per level [S1, unofficial]. For example, with 16 levels and 4 dimensions, $F$ has size 64 [S1, unofficial].
*   **Output:** Scalar density $\sigma$ and vector color $c$ (typically 3 channels) [S1, unofficial].

**Data Structures and Layout:**
The implementation varies based on the specific variant (Combined, Density-only, Color-only, or Implicit) [S1, unofficial][S2].

1.  **Combined Shallow MLP (SCALAR-NeRF default):**
    *   **Architecture:** 5 layers (depth), 128 neurons per layer (width) [S1, unofficial].
    *   **Activation:** ReLU for hidden layers; no activation for output layers [S1, unofficial].
    *   **Input:** Concatenated hash features $F \in \mathbb{R}^{L \cdot F}$ [S1, unofficial].
    *   **Output:** $\sigma$ and $c$ [S1, unofficial].

2.  **Density Decoder (NeRFLight):**
    *   **Architecture:** Input layer $\rightarrow$ Hidden layer (32 neurons) $\rightarrow$ Output layer (33 neurons) [S2].
    *   **Activation:** ReLU for hidden layers; no activation for output [S2].
    *   **Input:** 32-dimensional feature vector [S2].
    *   **Output:** 33-dimensional vector (likely containing density and auxiliary data) [S2].

3.  **Color Decoder (NeRFLight):**
    *   **Architecture:** Input layer $\rightarrow$ Output layer (3 neurons) [S2].
    *   **Activation:** Sigmoid for output layer; ReLU for hidden layers (if any, though described as input-to-output) [S2].
    *   **Input:** 32-dimensional feature vector [S2].
    *   **Output:** 3-dimensional color vector [S2].

4.  **Implicit MLP (NeRFLight):**
    *   **Architecture:** 1 input layer, 8 hidden layers (512 neurons each), 1 output layer (32 neurons) [S2].
    *   **Activation:** ReLU for hidden layers; no activation for output [S2].
    *   **Input:** Vertex coordinates with positional encoding concatenated to the output of the 4th hidden layer [S2].
    *   **Output:** 32-dimensional feature vector [S2].

**Formulas:**
The decoding operation is defined as:
$$ \sigma, c = \text{Decoder}(F) $$
[S1, unofficial]

**Pseudocode:**
The following implements the default SCALAR-NeRF combined decoder [S1, unofficial].

```python
import math

def shallow_mlp_decoder(features, num_layers=5, width=128):
    """
    Decodes feature embedding into density and color.
    
    Args:
        features: Input feature vector F of size L*F.
        num_layers: Depth of the MLP (default 5).
        width: Number of neurons per layer (default 128).
        
    Returns:
        sigma: Scalar density.
        color: Vector color (3 channels).
    """
    # Initialize weights and biases
    # Note: In a real implementation, weights are learned parameters.
    # Here we assume initialized weights W and biases b are available.
    
    current_input = features
    
    for i in range(num_layers):
        # Linear transformation
        # W shape: (width, current_input_size) for i=0, else (width, width)
        # b shape: (width,)
        current_input = linear_layer(current_input, W[i], b[i])
        
        # Activation
        if i < num_layers - 1:
            # Hidden layers use ReLU
            current_input = relu(current_input)
        else:
            # Output layer has no activation
            pass
            
    # Split output into density and color
    # Assuming the final layer outputs a vector of size 4 (1 for sigma, 3 for color)
    # This split logic depends on the specific output dimension configuration.
    # Based on [S1, unofficial], the decoder outputs sigma and c directly.
    
    # If the final layer width is 128, we need to map to 4 values.
    # The source [S1, unofficial] states "depth of 5 with a width of 128" and outputs sigma, c.
    # It does not specify if the last layer is 128->4 or if sigma/c are derived differently.
    # However, standard practice for such decoders is a final linear projection.
    # We assume a final projection layer W_out (4, 128) and b_out (4,)
    
    final_output = linear_layer(current_input, W_out, b_out)
    
    sigma = final_output[0]
    color = final_output[1:4]
    
    return sigma, color

def linear_layer(x, W, b):
    return x @ W.T + b

def relu(x):
    return [max(0, val) for val in x]
```

**Parameters:**
*   **Depth:** Default 5 layers [S1, unofficial].
*   **Width:** Default 128 neurons per layer [S1, unofficial].
*   **Hash Table Size:** Default $2^{19}$ for coarse global and local models [S1, unofficial].
*   **Levels:** 16 levels of resolution [S1, unofficial].
*   **Feature Dimension:** 4 per level [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Unbounded Scenes:** For unbounded scenes, the 3D point $x$ must be contracted before encoding to ensure features are sampled correctly [S1, unofficial]. The contraction method from Mip-NeRF360 is used [S1, unofficial]:
    $$ \text{contract}(x) = \begin{cases} x, & \|x\| \le 1 \\ \frac{x}{2 - \frac{1}{\|x\|}}, & \|x\| > 1 \end{cases} $$
    [S1, unofficial]
*   **Precision:** The hash table size and feature dimensions significantly impact memory and performance [S1, unofficial].

## Subtopics

### Density Decoder
A specialized decoder outputting only density (or density + auxiliary data). Used when color is handled separately or not needed. [S2]

### Color Decoder
A specialized decoder outputting only color. Often paired with a density decoder. Uses sigmoid activation for color bounds. [S2]

### Implicit MLP
A deeper MLP (8 layers, 512 neurons) that takes raw coordinates with positional encoding. Used for higher fidelity but higher cost. [S2]

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of layers and width. The decoding step is fast compared to the hash table lookup and interpolation.
*   **Memory Complexity:** Depends on the number of parameters in the MLP ($L_{layers} \times W_{width}^2$). With default settings (5 layers, 128 width), this is manageable.
*   **Performance:** Provides a good trade-off between performance and resource utilization [S1, unofficial]. Tested on NVIDIA A5000 GPU with 24GB memory [S1, unofficial].
*   **Strengths:** Efficient for large-scale scenes; allows for shared decoders across multiple local models [S1, unofficial].
*   **Limitations:** Less flexible than deeper implicit MLPs for complex geometry [S2].
*   **When to use:** Large-scale scene reconstruction where memory and speed are critical [S1, unofficial].
*   **When not to use:** When high-frequency detail requires deeper networks or raw coordinate encoding [S2].

## Background
The Shallow MLP Decoder was introduced in SCALAR-NeRF (2023) as part of a scalable large-scale neural radiance field method [S1, unofficial]. It builds on the concept of hash feature embeddings [S1, unofficial]. Variants like the Density/Color decoders and Implicit MLP were explored in NeRFLight (2023) for fast and light neural radiance fields [S2].
