# TensoRF Vector-Matrix Decomposition

Also called: VM Decomposition, VM-T, VM-T (Vector, Matrix, Time), Vector-Matrix Decomposition, Vector-Matrix Factorization

## Overview
TensoRF Vector-Matrix Decomposition is a factorization technique for representing 4D neural feature volumes, reducing memory overhead compared to dense tensor storage [S2]. It sets itself apart from sibling methods like the [Decoder Network](2301-decoder-network.md) by explicitly decomposing the feature volume into structured low-rank components (vectors and matrices) rather than relying solely on implicit coordinate-based decoding or separate density activations [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D spatial coordinates $\mathbf{x}$, viewing direction $\mathbf{d}$.
*   **Output:** Radiance color $c$.

**Data Structures:**
The 4D feature volume is factorized using Vector-Matrix (VM) decomposition. The feature tensor $\mathcal{G}_c$ is represented as the sum of three outer products between a matrix and a vector along different axes [S2].
*   **Feature Dimension ($D_f$):** 48 (input to decoder) [S2].
*   **Output Dimension ($D_o$):** 12 (high-quality) or 27 (fast, SH coefficients) [S2].
*   **Decoder:** A Multi-Layer Perceptron (MLP) $S$ [S2].

**Parameters:**
*   **High-quality model:** 48-dim input features, 12-dim output features, 3-layer MLP decoder [S2].
*   **Fast model:** 48-dim input features, 27-dim output (Spherical Harmonics coefficients) [S2].
*   **Frequency Encoding:** Sin/Cos functions applied to features $\mathcal{G}_c(\mathbf{x})$ and direction $\mathbf{d}$ [S2].
    *   NeRF-Synthetic: 2 frequencies for features, 6 for viewing direction [S2].
    *   Mip-NeRF 360/LLFF: No frequency encodings [S2].

**Steps:**
1.  Query the factorized 4D feature volume $\mathcal{G}_c(\mathbf{x})$ at position $\mathbf{x}$ using the VM decomposition [S2].
2.  Apply frequency encodings (Sin/Cos) to $\mathcal{G}_c(\mathbf{x})$ and $\mathbf{d}$ if specified by the dataset configuration [S2].
3.  Concatenate the encoded features $\mathcal{G}_c(\mathbf{x})$ with the viewing direction $\mathbf{d}$ [S2].
4.  Pass the concatenated vector into the MLP decoder $S$ to compute the output color $c$ [S2].

**Formula:**
$$c = S(\mathcal{G}_c(\mathbf{x}), \mathbf{d}) \quad (3)$$
Where:
*   $c$ is the output color [S2].
*   $S$ is the MLP decoder [S2].
*   $\mathcal{G}_c(\mathbf{x})$ is the feature generated by VM decomposition [S2].
*   $\mathbf{d}$ is the viewing direction [S2].

**Pseudocode:**
```python
def tensoRF_VM_decode(x, d, config):
    """
    Decode color using TensoRF Vector-Matrix Decomposition.
    
    Args:
        x: 3D spatial coordinates (float32, shape [3])
        d: Viewing direction (float32, shape [3])
        config: Dictionary containing model configuration
            - 'feature_dim': Input feature dimension (default 48)
            - 'output_dim': Output dimension (12 for HQ, 27 for Fast)
            - 'freq_enc_features': Number of frequencies for features (0 if none)
            - 'freq_enc_direction': Number of frequencies for direction (0 if none)
            - 'mlp_decoder': The MLP function S
            
    Returns:
        c: Output color (float32)
    """
    # Step 1: Generate feature Gc(x) using VM decomposition
    # Note: The exact tensor contraction logic for VM decomposition 
    # (sum of outer products) is defined in the TensoRF paper [S2].
    # Here we assume a function `query_vm_volume` implements Eq 3 from TensoRF.
    features = query_vm_volume(x, config)
    
    # Step 2: Apply frequency encodings if configured
    if config['freq_enc_features'] > 0:
        features = apply_freq_encoding(features, config['freq_enc_features'])
        
    if config['freq_enc_direction'] > 0:
        d = apply_freq_encoding(d, config['freq_enc_direction'])
        
    # Step 3: Concatenate features and direction
    input_to_decoder = concatenate(features, d)
    
    # Step 4: Pass through MLP decoder S
    c = config['mlp_decoder'](input_to_decoder)
    
    return c

def apply_freq_encoding(v, num_freqs):
    """
    Apply Sin/Cos frequency encoding to a vector.
    """
```

## Subtopics

### Volume Basis
Represents 4D volumes as weighted summation of shared 3D volumes [S1]. Chosen when higher spatial coherence in 3D is needed, but generally slower than VM-T [S1].

### CANDECOMP/PARAFAC (CP) Decomposition
Factorizes the tensor into a sum of rank-1 components (three vectors) [S2]. Chosen for maximum compression but potentially lower representational power compared to VM for certain anisotropic features [S2].

## Operating characteristics
*   **Memory:** Significantly reduced compared to dense 4D tensors due to factorization into vectors and matrices [S2].
*   **Speed:** Faster training and inference than dense volume representations [S1]. The "Fast" variant using 27-dim SH coefficients offers higher throughput [S2].
*   **Quality:** High-quality models (12-dim output) achieve competitive PSNR/SSIM [S2]. Performance scales with grid resolution, plateauing around 400 for DiffMC applications [S2].
*   **Limitations:** Requires careful tuning of basis numbers ($R$) and frequency encodings depending on the dataset (e.g., NeRF-Synthetic vs. Mip-NeRF 360) [S2].

## Background
TensoRF was introduced to address the high memory cost of neural radiance fields by factorizing the feature volume [S2]. The Vector-Matrix (VM) decomposition specifically leverages the structure of the 4D volume by combining matrix and vector outer products [S2]. It is widely used in differentiable rendering pipelines and neural manifold reconstruction [S2].
