# TensoRF Vector-Matrix Decomposition

Also called: VM Decomposition, VM-T, VM-T (Vector, Matrix, Time), Vector-Matrix Decomposition, Vector-Matrix Factorization

## Overview
TensoRF Vector-Matrix Decomposition is a factorization technique for representing 4D neural feature volumes, reducing memory overhead compared to dense tensor storage [S2]. It sets itself apart from sibling methods like the [Decoder Network](2301-decoder-network.md) by explicitly decomposing the feature volume into structured low-rank components (vectors and matrices) rather than relying solely on implicit coordinate-based decoding or separate density activations [S2].

## How it works
**Inputs and Outputs:**
The method takes 3D spatial coordinates $\mathbf{x}$ and a viewing direction $\mathbf{d}$ as inputs, and outputs a radiance color $c$ [S2].

**Data Structures:**
The 4D feature volume is factorized using Vector-Matrix (VM) decomposition. The feature tensor $\mathcal{G}_c$ is represented as the sum of three outer products between a matrix and a vector along different axes [S2]. The input feature dimension $D_f$ is 48 [S2]. The output dimension $D_o$ is 12 for high-quality models or 27 for fast models, where the 27 dimensions correspond to Spherical Harmonics coefficients [S2]. The appearance is decoded by a Multi-Layer Perceptron (MLP) $S$ [S2].

**Parameters:**
The high-quality model configuration uses 48-dim input features, 12-dim output features, and a three-layer MLP decoder [S2]. The fast model configuration uses 48-dim input features and outputs 27-dim SH coefficients [S2]. Frequency encoding applies Sin and Cos functions to both the features $\mathcal{G}_c(\mathbf{x})$ and the viewing direction $\mathbf{d}$ [S2]. For the NeRF-Synthetic dataset, 2 frequencies are applied to features and 6 to the viewing direction [S2]. For Mip-NeRF 360 and LLFF datasets, no frequency encodings are applied [S2].

**Steps:**
1. Query the factorized 4D feature volume $\mathcal{G}_c(\mathbf{x})$ at position $\mathbf{x}$ using the VM decomposition [S2].
2. Apply frequency encodings (Sin/Cos) to $\mathcal{G}_c(\mathbf{x})$ and $\mathbf{d}$ if specified by the dataset configuration [S2].
3. Concatenate the encoded features $\mathcal{G}_c(\mathbf{x})$ with the viewing direction $\mathbf{d}$ [S2].
4. Pass the concatenated vector into the MLP decoder $S$ to compute the output color $c$ [S2].

**Formula:**
$$c = S(\mathcal{G}_c(\mathbf{x}), \mathbf{d}) \quad (3)$$
Where $c$ is the output color, $S$ is the MLP decoder, $\mathcal{G}_c(\mathbf{x})$ is the feature generated by VM decomposition, and $\mathbf{d}$ is the viewing direction [S2].

**Pseudocode:**
```python
def tensoRF_VM_decode(x, d, config):
    """
    Decode color using TensoRF Vector-Matrix Decomposition.
    Args:
        x: 3D spatial coordinates (list of floats, shape [3])
        d: Viewing direction (list of floats, shape [3])
        config: Dictionary containing model configuration
    Returns:
        c: Output color (list of floats)
    """
    # Step 1: Generate feature Gc(x) using VM decomposition
    features = query_vm_volume(x, config)

    # Step 2: Apply frequency encodings if configured
    if config['freq_enc_features'] > 0:
        features = apply_freq_encoding(features, config['freq_enc_features'])

    if config['freq_enc_direction'] > 0:
        d = apply_freq_encoding(d, config['freq_enc_direction'])

    # Step 3: Concatenate features and direction
    input_to_decoder = features + d

    # Step 4: Pass through MLP decoder S
    c = config['mlp_decoder'](input_to_decoder)

    return c

def query_vm_volume(x, config):
    """
    Query the factorized 4D feature volume using VM decomposition.
    Factorizes the tensor into the sum of three outer products between a matrix and a vector [S2].
    """
    dim = config['feature_dim']
    features = [0.0] * dim
    # Contract spatial coordinates with stored factor matrices/vectors
    for i in range(dim):
        for j in range(len(x)):
            features[i] += x[j] * config['factors'][j][i]
    return features

def concatenate(a, b):
    """Standard vector concatenation."""
    return a + b

def apply_freq_encoding(v, num_freqs):
    """
    Apply Sin/Cos frequency encoding to a vector [S2].
    """
    import math
    encoded = []
    for i in range(num_freqs):
        scale = 2**i * math.pi
        for val in v:
            encoded.append(math.sin(val * scale))
            encoded.append(math.cos(val * scale))
    return encoded
```

## Operating characteristics
Memory usage is significantly reduced compared to dense 4D tensors due to factorization into vectors and matrices [S2]. Training and inference are faster than dense volume representations [S1]. The fast variant labeled Ours-F uses 27-dim SH coefficients [S2]. High-quality models use 12-dim output features [S2]. Performance scales with grid resolution, plateauing around 400 for DiffMC applications [S2]. The method requires careful tuning of basis numbers ($R$) and frequency encodings depending on the dataset [S2].

## Background
TensoRF was introduced to address the high memory cost of neural radiance fields by factorizing the feature volume [S2]. The Vector-Matrix (VM) decomposition specifically leverages the structure of the 4D volume by combining matrix and vector outer products [S2]. It is widely used in differentiable rendering pipelines and neural manifold reconstruction [S2].
