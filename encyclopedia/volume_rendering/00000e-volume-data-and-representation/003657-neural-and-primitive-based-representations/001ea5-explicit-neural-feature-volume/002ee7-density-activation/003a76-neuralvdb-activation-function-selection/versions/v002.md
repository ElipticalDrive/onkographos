# NeuralVDB Activation Function Selection

Also called: Activation Function Selection for NeuralVDB, NeuralVDB Activation Heuristics

## Overview
This method selects the activation function for the hierarchical neural networks in NeuralVDB to balance reconstruction quality and convergence speed [S1, unofficial]. It distinguishes itself by mapping specific geometric properties of the input volume (smoothness versus structure) to specific activation types, rather than using a fixed default [S1, unofficial]. It operates within the Density Activation stage of the NeuralVDB pipeline [S1, unofficial].

## How it works
**Inputs:**
- The geometric characteristics of the input volume (classified as "smooth/unstructured" or "flat/structured/artificial") [S1, unofficial].
- The presence of Fourier Feature Mapping (FFM) [S1, unofficial].

**Outputs:**
- The selected activation function type (`sin`, `tanh`, or `ReLU`) [S1, unofficial].
- If `sin` is selected, the frequency parameter $\omega$ [S1, unofficial].

**Data Structures:**
- No persistent data structures. This is a configuration step performed during network initialization or hyperparameter tuning [S1, unofficial].

**Steps:**
1. **Analyze Input Geometry:** Determine if the input volume contains primarily smooth, unstructured surfaces or flat, structured, artificial surfaces [S1, unofficial].
2. **Select Activation Type:** If the volume is flat, structured, or artificial, select ReLU [S1, unofficial]. If the volume is smooth or unstructured, select sin or tanh [S1, unofficial].
3. **Configure sin Frequency:** If sin is selected, set the frequency $\omega$ within the range $1.5 \le \omega \le 3.0$ [S1, unofficial]. The default starting point is $\omega = 1.5$ [S1, unofficial].
4. **Consider Convergence Needs:** If faster convergence is prioritized for smooth or unstructured models, prefer sin over tanh [S1, unofficial]. Note that sin is redundant with Fourier Feature Mapping but accelerates convergence [S1, unofficial].

**Formulas:**
- None. The selection is heuristic.

**Parameters:**
- `sin_frequency` ($\omega$): Float. Range $[1.5, 3.0]$. Default $1.5$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- High-Frequency Noise: Using ReLU on smooth geometry can introduce high-frequency noise [S1, unofficial].
- Edge Smoothing: Using sin on geometry with sharp edges (from coarse input meshes) may smooth out those sharp edges [S1, unofficial].
- Redundancy: Using sin with Fourier Feature Mapping is redundant but beneficial for convergence speed [S1, unofficial].

**Pseudocode:**
```python
def select_activation(volume_type: str, need_fast_convergence: bool = False) -> dict:
    """
    Select activation function for NeuralVDB based on volume characteristics.
    
    Args:
        volume_type: 'flat_structured' or 'smooth_unstructured'
        need_fast_convergence: If True, prefer sin for smooth types
        
    Returns:
        dict with keys 'activation' and optionally 'frequency'
    """
    if volume_type == 'flat_structured':
        return {'activation': 'relu'}
    
    # volume_type == 'smooth_unstructured'
    if need_fast_convergence:
        # sin accelerates convergence compared to ReLU/tanh [S1, unofficial]
        return {'activation': 'sin', 'frequency': 1.5}
    else:
        # tanh is a valid alternative for smooth models [S1, unofficial]
        # sin is also valid but may smooth sharp edges [S1, unofficial]
        # Defaulting to sin as it is noted to accelerate convergence
        return {'activation': 'sin', 'frequency': 1.5}
```

## Subtopics

### [NeuralVDB](9050-neuralvdb.md)
A hybrid data structure replacing lower VDB tree nodes with hierarchical neural networks to encode topology and values, reducing memory while maintaining spatial adaptivity. It differs from statistical compression methods by deliberately over-fitting to memorize arbitrary inputs rather than learning statistical priors. Choose it when handling inherently sparse 3D data requiring compression ratios an order of magnitude higher than NanoVDB. See [NeuralVDB](9050-neuralvdb.md).

## Operating characteristics
Selection time complexity is $O(1)$ [G]. The choice affects training time because sin accelerates convergence [S1, unofficial]. Memory complexity involves no additional overhead for selection [G]. ReLU performs best on flat or structured models, while sin and tanh perform better on smooth or unstructured models [S1, unofficial]. Strengths include adapting to input geometry and sin speeding up convergence [S1, unofficial]. Limitations include ReLU causing noise on smooth geometry and sin blurring sharp edges [S1, unofficial]. Use this method when initializing NeuralVDB networks for known geometry types [S1, unofficial]. Avoid it when the geometry type is unknown or highly mixed without preprocessing [G].

## Background
This heuristic was developed for the NeuralVDB system, which uses hierarchical neural networks to encode sparse 3D volumes [S1, unofficial]. The method addresses the observation that different activation functions significantly impact reconstruction quality and convergence rates in this specific hybrid data structure context [S1, unofficial].
