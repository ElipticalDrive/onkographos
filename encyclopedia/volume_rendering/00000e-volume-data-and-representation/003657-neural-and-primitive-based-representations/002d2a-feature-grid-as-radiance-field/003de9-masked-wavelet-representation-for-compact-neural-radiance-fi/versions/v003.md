# Masked Wavelet Representation for Compact Neural Radiance Fields

Also called: MW-NeRF, Masked Wavelet NERF, Masked Wavelet TensoRF

## Overview
Masked Wavelet Representation (MW-NeRF) reduces the memory footprint of grid-based neural radiance fields by applying a Discrete Wavelet Transform (DWT) to grid coefficients, using a trainable binary mask to zero out unnecessary coefficients, and compressing the result with run-length and Huffman encoding [S1]. It sets itself apart from standard grid-based methods like [Feature Grid as Radiance Field](5508-feature-grid-as-radiance-field.md) by leveraging the higher sparsity of wavelet coefficients compared to spatial coefficients and per-scene optimized masking, achieving state-of-the-art performance within a 2 MB memory budget [S1].

## How it works
**Inputs:**
The method takes training images and corresponding camera poses as inputs [S1]. Grid resolution parameters ($H, W, D$) and the number of ranks ($N_r$) are also provided as inputs [S1].

**Outputs:**
The method outputs compressed wavelet coefficients and binary masks [S1]. It also provides a rendering pipeline that reconstructs spatial grids from these coefficients at test time [S1].

**Data Structures:**
The 3D grid is decomposed into 2D matrices and 1D vectors using matrix-vector decomposition (TensoRF) [S1]. For density (subscript $\sigma$, omitted for brevity), the set is defined as:
$$ \gamma_\sigma = \{W_{x,\sigma,r}, W_{y,\sigma,r}, W_{z,\sigma,r}, v_{x,\sigma,r}, v_{y,\sigma,r}, v_{z,\sigma,r}\}_{r=1}^{N_\sigma} $$
- $W_{x,r} \in \mathbb{R}^{H \times W}$, $W_{y,r} \in \mathbb{R}^{W \times D}$, $W_{z,r} \in \mathbb{R}^{H \times D}$ are 2D matrices [S1].
- $v_{x,r} \in \mathbb{R}^{D}$, $v_{y,r} \in \mathbb{R}^{H}$, $v_{z,r} \in \mathbb{R}^{W}$ are 1D vectors [S1].
- $H, W, D$ are grid resolutions [S1].
- $N_r$ is the number of ranks [S1].

**Trainable Masks:**
Element-wise trainable masks are defined for each component:
$$ M = \{M_{x,r}, M_{y,r}, M_{z,r}, m_{x,r}, m_{y,r}, m_{z,r}\}_{r=1}^{N_r} $$
These masks are optimized jointly with grid parameters [S1].

**Numbered Steps:**
1. **Decomposition:** Decompose the 3D grid into 2D matrices and 1D vectors as defined in TensoRF [S1].
2. **Multi-level DWT:** Apply a multi-level Discrete Wavelet Transform (DWT) to the 2D matrices only [S1]. Do not apply DWT to 1D vectors, as it causes significant quality degradation [S1]. For a 2-level DWT, coefficients are grouped by level: $\{HL_1, LH_1, HH_1\}$, $\{HL_2, LH_2, HH_2\}$, and $\{LL_2\}$ [S1]. Apply scaling factors $s$ proportional to the inverse of frequency to handle varying gradient scales: $s=1/2$ for $HL_2, LH_2, HH_2$; $s=1/3$ for $HL_1, LH_1, HH_1$; $s=1$ for $LL_2$ [S1].
3. **Masking (Training):** Multiply wavelet coefficients by binarized masks using the Straight-Through Estimator (STE) to allow gradient flow [S1]. The masked matrix parameters $\widehat{\mathcal{W}}_r$ are computed as:
   $$ \widehat{\mathcal{W}}_r = \text{sg}((\mathcal{H}(\mathcal{M}_r) - \sigma(\mathcal{M}_r)) \odot \mathcal{W}_r) + \sigma(\mathcal{M}_r) \odot \mathcal{W}_r $$
   where $\text{sg}(\cdot)$ is stop-gradient, $\sigma(\cdot)$ is sigmoid, $\mathcal{H}(\cdot)$ is Heaviside step, and $\odot$ is Hadamard product [S1].
4. **Optimization:** Train the network end-to-end [S1]. The loss function is $\mathcal{L} = \mathcal{L}_r + \lambda_m \mathcal{L}_m$, where $\mathcal{L}_r$ is the rendering loss and $\mathcal{L}_m$ is the sum of all mask values (to enforce sparsity) [S1].
5. **Compression Pipeline:** Group wavelet coefficient masks by decomposition level [S1]. Cast binary mask values to $n$-bit unsigned integers (default $n=8$) to avoid inefficient bit allocation from repeating zeros in RLE [S1]. Apply Run-Length Encoding to the $n$-bit mask streams [S1]. Apply Huffman encoding to the RLE outputs for entropy coding [S1]. Store the compressed masks and the non-zero wavelet coefficients [S1].
6. **Inference (Test Time):** Decompress masks and coefficients [S1]. Apply one Inverse DWT (IDWT) per grid to transform wavelet grids back into spatial grids [S1]. Render using the reconstructed spatial grids, identical to standard grid-based NeRF [S1].

**Pseudocode:**
```python
import numpy as np
import heapq

def nearest_neighbor_upscale(x, factor=2):
    """Upscales a 2D array by factor using nearest neighbor interpolation [G]."""
    return np.repeat(np.repeat(x, factor, axis=0), factor, axis=1)

def cross_correlate_2d(x, kernel):
    """Performs 2D cross-correlation with zero-padding [G]."""
    kh, kw = kernel.shape
    ph, pw = kh // 2, kw // 2
    padded = np.pad(x, ((ph, ph), (pw, pw)), mode='constant')
    h, w = x.shape
    out = np.zeros((h, w))
    for i in range(h):
        for j in range(w):
            out[i, j] = np.sum(padded[i:i+kh, j:j+kw] * kernel)
    return out

def idwt_2d(W, phi, psi_hl, psi_lh, psi_hh):
    """Reconstructs spatial grid from wavelet coefficients using biorthogonal 4.4 filters [G]."""
    m, n = W.shape
    h_m, h_n = m // 2, n // 2
    LL = W[:h_m, :h_n]
    HL = W[:h_m, h_n:]
    LH = W[h_m:, :h_n]
    HH = W[h_m:, h_n:]
    LL_up = nearest_neighbor_upscale(LL)
    HL_up = nearest_neighbor_upscale(HL)
    LH_up = nearest_neighbor_upscale(LH)
    HH_up = nearest_neighbor_upscale(HH)
    return (cross_correlate_2d(LL_up, phi) +
            cross_correlate_2d(HL_up, psi_hl) +
            cross_correlate_2d(LH_up, psi_lh) +
            cross_correlate_2d(HH_up, psi_hh))

def apply_ste_mask(mask_logit, weight):
    """Straight-Through Estimator for binary masking [S1]."""
    mask_bin = (mask_logit > 0).astype(weight.dtype)
    mask_grad = 1.0 / (1.0 + np.exp(-mask_logit))
    return mask_bin * weight, mask_grad

def rle_encode(data):
    """Run-length encoding for 1D array [G]."""
    if len(data) == 0: return []
    rle = []
    current_val = data[0]
    count = 1
    for val in data[1:]:
        if val == current_val:
            count += 1
        else:
            rle.append((current_val, count))
            current_val = val
            count = 1
    rle.append((current_val, count))
    return rle

def huffman_encode(rle_stream):
    """Assigns variable-length codes based on frequency using Huffman tree [G]."""
    freq = {}
    for val, count in rle_stream:
        freq[val] = freq.get(val, 0) + count
    heap = [[weight, [symbol, ""]] for symbol, weight in freq.items()]
    heapq.heapify(heap)
    while len(heap) > 1:
        lo = heapq.heappop(heap)
        hi = heapq.heappop(heap)
        for pair in lo[1:]:
            pair[1] = '0' + pair[1]
        for pair in hi[1:]:
            pair[1] = '1' + pair[1]
        heapq.heappush(heap, [lo[0] + hi[0]] + lo[1:] + hi[1:])
    codes = dict(sorted(heapq.heappop(heap)[1:], key=lambda p: (len(p[-1]), p)))
    bit_stream = ""
    for val, count in rle_stream:
        bit_stream += codes[val] + format(count, '08b')
    return bit_stream

def train_mw_nerf(scene_data, num_ranks, grid_res, lambda_m=0.01, num_epochs=1000):
    """Training loop for MW-NeRF [S1]."""
    # Initialize TensoRF grids and mask logits
    W_x = np.random.randn(grid_res[0], grid_res[1], num_ranks)
    W_y = np.random.randn(grid_res[1], grid_res[2], num_ranks)
    W_z = np.random.randn(grid_res[0], grid_res[2], num_ranks)
    v_x = np.random.randn(grid_res[2], num_ranks)
    v_y = np.random.randn(grid_res[0], num_ranks)
    v_z = np.random.randn(grid_res[1], num_ranks)
    M_x = np.zeros_like(W_x)
    M_y = np.zeros_like(W_y)
    M_z = np.zeros_like(W_z)
    m_x = np.zeros_like(v_x)
    m_y = np.zeros_like(v_y)
    m_z = np.zeros_like(v_z)

    # Biorthogonal 4.4 filters [G]
    phi = np.array([[0.25, 0.5, 0.25], [0.5, 1.0, 0.5], [0.25, 0.5, 0.25]])
    psi_hl = np.array([[-0.25, -0.5, -0.25], [0.0, 0.0, 0.0], [0.25, 0.5, 0.25]])
    psi_lh = np.array([[-0.25, 0.0, 0.25], [-0.5, 0.0, 0.5], [-0.25, 0.0, 0.25]])
    psi_hh = np.array([[0.25, 0.0, -0.25], [0.0, 0.0, 0.0], [-0.25, 0.0, 0.25]])

    for epoch in range(num_epochs):
        # 1. Multi-level DWT & Scaling [S1]
        # Group coefficients by decomposition level and apply inverse frequency scaling
        W_x_scaled = W_x.copy()
        # Level 1 high-pass (HL1, LH1, HH1) scaled by 1/3
        W_x_scaled[:, :, 1:] *= 1.0/3.0
        # Level 2 high-pass would be in deeper splits; scaling logic applies per quadrant group [S1]
        
        # 2. Masking with STE [S1]
        W_x_hat, _ = apply_ste_mask(M_x, W_x_scaled)
        v_x_hat, _ = apply_ste_mask(m_x, v_x)

        # 3. Reconstruct spatial grid via IDWT [S1]
        spatial_x = idwt_2d(W_x_hat, phi, psi_hl, psi_lh, psi_hh)
        grid_x = np.einsum('ij,k->ijk', v_x_hat, spatial_x)

        # 4. Render and compute loss [S1]
        # Standard grid-based NeRF forward pass [G]
        images = forward_pass_grids(grid_x, scene_data.cameras)
        loss_r = np.mean((images - scene_data.targets) ** 2)

        # 5. Mask regularization loss [S1]
        loss_m = np.sum(np.sigmoid(M_x)) + np.sum(np.sigmoid(m_x))
        total_loss = loss_r + lambda_m * loss_m

        # 6. Update parameters (gradient descent step) [G]
        grad_W_x = np.gradient(total_loss, W_x)
        grad_M_x = np.gradient(total_loss, M_x)
        W_x -= 0.01 * grad_W_x
        M_x -= 0.01 * grad_M_x
```

**Parameters:**
- **Memory Budget:** 2 MB [S1].
- **Scaling Factors ($s$):** For 2-level DWT, $s=1/2$ for HL2, LH2, HH2; $s=1/3$ for HL1, LH1, HH1; $s=1$ for LL2 [S1].
- **$\lambda_m$:** Mask regularization weight. Value not specified, adjusted to control size [S1].
- **$n$:** Bit depth for mask casting before RLE. Default 8 [S1].

**Edge Cases and Pitfalls:**
- **IDWT on Vectors:** Applying IDWT to 1D vectors causes significant quality degradation. IDWT is applied only to 2D matrices [S1].
- **Multi-level DWT Optimization:** Naive multi-level DWT degrades quality due to varying gradient scales of high-pass coefficients. Scaling coefficients by the inverse of their frequency mitigates this [S1].
- **Smooth Signals:** Wavelet transforms can be less efficient than Fourier-based transforms for smooth signals, but this is mitigated in grid-based neural fields because grid resolutions are constrained to depict detailed scenes [S1].

## Subtopics

### TensoRF
A method that decomposes 3D grids into 2D planes and 1D vectors. MW-NeRF builds on this structure. [TensoRF](5508-feature-grid-as-radiance-field.md)

### NeRF
The foundational neural radiance field method. MW-NeRF replaces the MLP with explicit grids. [NeRF](5508-feature-grid-as-radiance-field.md)

## Operating characteristics
- **Time Complexity:** Negligible increase at test time. Requires one IDWT per grid during initialization, then rendering is identical to spatial grid-based NeRF [S1].
- **Memory Complexity:** Significantly reduced. Achieves >95% sparsity in grid parameters. State-of-the-art performance within 2 MB budget [S1].
- **Strengths:** High compression ratio, maintains reconstruction quality, fast inference [S1].
- **Limitations:** Requires per-scene optimization of masks. Wavelet transform may be less efficient for very smooth signals (though rare in NeRF grids) [S1].
- **When to use:** When memory is constrained (e.g., <2 MB) and high-quality novel view synthesis is required [S1].

## Background
MW-NeRF was proposed by Daniel et al. [S1]. It addresses the high memory usage of explicit grid-based neural fields by combining wavelet transforms with trainable masking [S1]. It builds on TensoRF's decomposition strategy and standard image compression techniques (RLE, Huffman) [S1].
