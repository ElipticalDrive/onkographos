# Occupancy Evaluation Function

Also called: Occupancy Evaluation, Occupancy Query

## Overview
The Occupancy Evaluation Function computes the importance weight (occupancy) at a given position in the occupancy grid, which is used by the sampling estimator to determine where to place samples [S1, unofficial]. It transforms a raw neural field output (typically log-density) into a bounded occupancy probability [G].

## How it works
**Inputs and Outputs:**
* Input: A coordinate vector $\mathbf{x}$ (in AABB space), and model parameters (`aabb_scale`, `clamp`, `log_ne_min`, `log_ne_max`, `occ_eval_fn_ne_mid`, `occ_eval_fn_ne_width`) [S1, unofficial].
* Output: A scalar occupancy value $occ \in [0, 1]$ [S1, unofficial].

**Data Structures:**
* `ne_field`: Neural network or lookup structure returning log10 density [S1, unofficial].
* `aabb_scale`: Scaling factor mapping AABB coordinates to physical coordinates [S1, unofficial].
* `clamp`: Boolean flag indicating whether to clamp the intermediate log10 value [S1, unofficial].
* `log_ne_min`, `log_ne_max`: Lower and upper bounds for clamping [S1, unofficial].
* `occ_eval_fn_ne_mid`, `occ_eval_fn_ne_width`: Midpoint and width parameters for the sigmoid function [S1, unofficial].

**Steps:**
The evaluation follows one of two paths depending on whether ground truth neural fields are available and used [S1, unofficial].
1. **Ground Truth Path:** If `use_gt_ne` is true and `ne_field` is not None:
   a. Map the input AABB coordinate $\mathbf{x}_{AABB}$ to physical coordinates: $\mathbf{x}_{xyz} = \mathbf{x}_{AABB} \times \text{aabb\_scale}$ [S1, unofficial].
   b. Query the neural field: $\text{log10\_ne} = \text{ne\_field}(\mathbf{x}_{xyz})$ [S1, unofficial].
   c. If `clamp` is true, clamp the value: $\text{log10\_ne} = \max(\text{log\_ne\_min}, \min(\text{log10\_ne}, \text{log\_ne\_max}))$ [S1, unofficial].
   d. Compute linear density: $ne = 10.0^{\text{log10\_ne}}$ [S1, unofficial].
2. **Training Path:** Else:
   a. Call the learned fields predictor: $(\_, \text{log10\_ne}, \_, \_) = \text{predict\_learned\_fields}(\mathbf{x}_{AABB})$ [S1, unofficial]. The `log10_ne` is already clamped if `clamp` is true [S1, unofficial].
3. **Occupancy Calculation:** Compute occupancy using the sigmoid function:
   $$ occ = \sigma\left(\frac{\text{log10\_ne} - \text{occ\_eval\_fn\_ne\_mid}}{\text{occ\_eval\_fn\_ne\_width}}\right) $$
   where $\sigma(z) = \frac{1}{1 + e^{-z}}$ [S1, unofficial].

**Pseudocode:**
```python
import math

def evaluate_occupancy(x_AABB, use_gt_ne, ne_field, aabb_scale, clamp, 
                       log_ne_min, log_ne_max, occ_eval_fn_ne_mid, 
                       occ_eval_fn_ne_width, predict_learned_fields):
    """Evaluates the occupancy at a given AABB coordinate."""
    if use_gt_ne and ne_field is not None:
        x_xyz = x_AABB * aabb_scale
        log10_ne = ne_field(x_xyz)
        if clamp:
            log10_ne = max(log_ne_min, min(log10_ne, log_ne_max))
        ne = 10.0 ** log10_ne
    else:
        _, log10_ne, _, _ = predict_learned_fields(x_AABB)

    exponent = (log10_ne - occ_eval_fn_ne_mid) / occ_eval_fn_ne_width
    occ = 1.0 / (1.0 + math.exp(-exponent))
    return occ
```

**Parameters:**
* `occ_eval_fn_ne_mid`: Midpoint of the sigmoid. Typical value: Not given in the sources.
* `occ_eval_fn_ne_width`: Width of the sigmoid. Typical value: Not given in the sources.
* `log_ne_min`, `log_ne_max`: Clamping bounds. Typical value: Not given in the sources.

**Edge Cases and Pitfalls:**
* **Precision:** The source code computes $ne = 10.0^{\text{log10\_ne}}$ but applies the sigmoid directly to `log10_ne` [S1, unofficial]. Implementers must follow this exact formula to match the reference implementation [S1, unofficial].
* **Clamping:** If `clamp` is enabled, values outside `[log_ne_min, log_ne_max]` are truncated before the sigmoid calculation [S1, unofficial].

## Subtopics

### Dichotomy-based Triggering for Occupancy Field
A triggering strategy for Occupancy Fields (OF) using Bolzano's theorem to find zero-crossings via bisection, as SGD is ineffective for relaxed binary OFs [S2]. It is more effective than SGD for OFs, especially when the initial point is far from the surface [S2].
1. Randomly sample seed points in the implicit OF until a pair $\{x_0^+, x_0^-\}$ is found such that $F(x_0^+) > 0$ and $F(x_0^-) < 0$ [S2].
2. Assert a zero-crossing exists on the segment between $x_0^+$ and $x_0^-$ based on Bolzano's theorem [S2].
3. Repeatedly bisect the line segment. At iteration $t$, select the subinterval $[x_t^+, x_t^-]$ whose endpoints have opposite signs of occupancy [S2].
4. Continue until $F(x_t^+) - F(x_t^-) \le \epsilon$ for a specified tolerance $\epsilon$ [S2].
