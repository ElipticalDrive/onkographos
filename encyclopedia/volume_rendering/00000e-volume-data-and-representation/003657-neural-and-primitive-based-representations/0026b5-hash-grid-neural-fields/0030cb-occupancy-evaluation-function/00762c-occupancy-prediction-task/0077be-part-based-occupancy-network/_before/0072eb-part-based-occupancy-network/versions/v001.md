# Part-based Occupancy Network

Also called: NASA

## Overview
Part-based Occupancy Network (NASA) is a method for representing articulated human bodies using Implicit Neural Representations (INR) by decomposing the body into bone-specific occupancy fields [S1]. It solves the problem of modeling dynamic human shape and pose by learning rigid bone transformations and local non-rigid deformations separately, distinguishing itself from monolithic occupancy networks like O-Net and trajectory-based methods like O-Flow [S1].

## How it works
**Inputs:** Pose parameters (defining the articulated configuration), 3D spatial coordinates.
**Outputs:** Occupancy value indicating whether a point is inside the human body.

**Data Structures:**
The method maintains separate neural networks for each bone in the skeleton hierarchy.
1.  **Rigid Network:** A neural network that outputs the rigid transformation (rotation and translation) of a specific bone based on the global pose parameters.
2.  **Non-Rigid Deformation Network:** A neural network associated with each bone that outputs a linear subspace projection operator. This operator projects the pose into a low-dimensional space to generate local deformation correction vectors.

**Steps:**
1.  **Rigid Transformation:** For a given query point and current pose, the rigid network computes the transformation of the bone to which the point belongs. This adjusts the point's position in the canonical space according to the bone's posture [S1].
2.  **Local Deformation Projection:** The pose parameters are projected into a low-dimensional space using the linear subspace projection operator learned by the non-rigid deformation network. This projection serves as local deformation information for shape correction [S1].
3.  **Occupancy Prediction:** The non-rigid deformation network uses the projected pose information to predict local non-rigid deformations. These deformations are applied to correct the shape of the bone beyond the rigid transformation. The occupancy value is then predicted for the deformed point [S1].
4.  **Aggregation:** The predicted occupancy values from all bones are combined using a maximum operator to produce the final occupancy value for the query point [S1].

**Formulas:**
Let $p$ be a query point in 3D space.
Let $B$ be the set of bones.
For each bone $b \in B$:
1.  Rigid transformation $T_{rigid}^b(\theta)$ is computed by the rigid network, where $\theta$ is the pose parameter.
2.  Local deformation correction $d_{local}^b$ is computed by the non-rigid network, which involves projecting $\theta$ into a low-dimensional subspace: $d_{local}^b = f_{non-rigid}^b(\text{Project}(\theta))$.
3.  The deformed point $p'$ is obtained by applying the rigid transformation and local deformation to $p$.
4.  The occupancy value $o_b(p)$ is predicted for bone $b$.

The final occupancy $O(p)$ is:
$$ O(p) = \max_{b \in B} o_b(p) $$

**Parameters:**
*   **Pose Parameters:** Typically derived from a skeleton representation such as SMPL or the parent method's skeleton representation [S1, Parent].
*   **Subspace Dimension:** The dimension of the low-dimensional space for local deformation is a hyperparameter, described as "low dimensional" in sources [S1].

**Edge Cases and Pitfalls:**
*   **Boundary Handling:** The maximum operator assumes that the union of bone occupancies correctly represents the body. Overlaps between bones are handled by the max, which is standard for occupancy networks but may cause artifacts if bone boundaries are not well-defined [S1].
*   **Precision:** The separation of rigid and non-rigid components requires accurate pose estimation; errors in pose parameters will propagate to both rigid and non-rigid predictions [S1].

## Subtopics

### O-Flow
O-Flow is an INR method for dynamic human modeling that extends O-Net [S1]. It generates the body shape for the first frame using O-Net, then uses a velocity network to learn a deformation gradient field for subsequent frames [S1]. It maps points from material space to deformation space via an ordinary differential equation to achieve continuous motion representation [S1]. A fixed mesh is difficult to stably represent large-scale action changes because it is formed only in the first frame [S1].

**Strengths and Limitations:**
*   **Strengths:** Separates rigid and non-rigid deformations, allowing for more flexible modeling of articulated motion compared to monolithic networks [S1].
*   **Limitations:** The method relies on a part-based decomposition, which may require careful definition of bone boundaries [S1].

**When to Use:**
Use when modeling dynamic human bodies with articulated motion where separating rigid bone movement from local soft-tissue deformation is beneficial [S1].

## Background
NASA was introduced as a part-based occupancy method that treats the human body as an object hinged by multiple bones [S1]. It was developed in the context of Implicit Neural Representation (INR) for human 3D avatar modeling, following earlier works like O-Net and O-Flow [S1]. The method is cited as [15] in the source survey [S1].
