# SparseOcc

Also called: Uncertainty-based Occupancy Field extraction

## Overview
SparseOcc (referred to as RibPull in the source text) is a method for learning neural implicit shape representations from point clouds using binary occupancy fields rather than Signed Distance Fields (SDFs) [S1]. It stabilizes training by avoiding the eikonal equation constraints required by SDFs, making it suitable for sparse or noisy data such as medical CT scans [S1]. It differs from SDF-based methods by optimizing the zero-crossings of a margin uncertainty function via Newton-Raphson iteration, and from other occupancy methods by introducing an entropy-based regularization to guide the field toward minimal entropy in free space and maximal entropy at the surface [S1].

## How it works
**Inputs:**
- A point cloud $P$ representing the target shape [S1].
- A neural network parameterized by $\theta$ that outputs a scalar value for any query point $x \in \mathbb{R}^3$ [S1].

**Outputs:**
- A trained neural occupancy field $U_\theta(x)$ [S1].
- A reconstructed point cloud sampled from the zero-level set of $U_\theta(x)$ [S1].

**Data Structures:**
- The neural network takes a 3D coordinate $x$ as input and outputs a scalar [S1].
- The margin uncertainty function $U_\theta(x)$ is defined as the difference between the probability of a point being outside and the probability of it being inside the shape [S1].

**Algorithm Steps:**

1.  **Define Margin Uncertainty:**
    For a query point $x$, compute the margin uncertainty $U_\theta(x)$ [S1].

2.  **Sample Surface Points:**
    Obtain samples from the surface of the occupancy function by finding the zeros of $U_\theta(x)$ using Newton-Raphson iteration [S1].
    
    The Newton-Raphson update for a query point $q$ to find a surface point $s$ is:
    $$ s = q - U_\theta(q) \frac{\nabla U_\theta(q)}{\|\nabla U_\theta(q)\|_2} $$
    where $\nabla U_\theta(q)$ is the gradient of the network output with respect to the input coordinates [S1].

3.  **Construct Training Pairs:**
    Create a set of pairs $Q = \{(q, p)\}$, where $q$ is a query point sampled around the input point cloud $P$, and $p$ is the closest point in $P$ to $q$ [S1].

4.  **Compute Sampling Loss:**
    Minimize the distance between the Newton-Raphson sampled points and the input point cloud using the loss $L_{samp}$ [S1]:
    $$ L_{samp} (\theta, Q) = \mathbb{E}_{(q,p)\sim Q} \left\| q - U_\theta(q) \frac{\nabla U_\theta(q)}{\|\nabla U_\theta(q)\|_2} - p \right\|_2^2 $$

5.  **Compute Entropy Regularization:**
    Introduce an entropy-based regularization loss $\lambda L_{entr}$ to stabilize training [S1]. This loss guides the occupancy field toward minimal entropy almost everywhere in space and maximizes entropy at the input point cloud [S1]. The specific formula for $L_{entr}$ is not provided in the sources [S1].

6.  **Optimize:**
    Minimize the total loss with respect to $\theta$ [S1]:
    $$ \min_\theta L_{samp} (\theta, Q) + \lambda L_{entr} (\theta, \Omega, P) $$
    where $\lambda$ is a weighting parameter and $\Omega$ represents the domain [S1].

def norm(v):
    return sum(x**2 for x in v)**0.5

def compute_gradient(network, x):
    # Computes gradient of network output w.r.t. input x using automatic differentiation
    x.requires_grad = True
    output = network(x)
    output.backward(gradient=output.clone(), create_graph=True)
    return x.grad

def newton_raphson_step(network, q, max_iter=10, tol=1e-6):
    x_curr = q
    for _ in range(max_iter):
        u_val = network(x_curr)
        grad = compute_gradient(network, x_curr)
        grad_norm = norm(grad)
        if grad_norm < 1e-8:
            break
        x_new = [x_curr[i] - u_val * (grad[i] / grad_norm) for i in range(len(x_curr))]
        if norm([x_new[i] - x_curr[i] for i in range(len(x_curr))]) < tol:
            break
        x_curr = x_new
    return x_curr

def train_sparseocc(point_cloud, network, num_samples, num_epochs, lambda_entr):

        # Entropy regularization loss formula not provided in sources [S1]

**Parameters:**
- $\lambda$: Weight for the entropy regularization term [S1]. Value not given in the sources [S1].
- Newton-Raphson iterations: Not specified, but implied to be iterative until convergence or max steps [S1].

**Edge Cases and Pitfalls:**
- Gradient vanishing: If $\|\nabla U_\theta(q)\|_2$ is near zero, the Newton-Raphson step becomes unstable [G]. A guard (e.g., clamping or fallback) is required [G].
- Boundary conditions: The method relies on sampling query points $q$ around the input point cloud $P$ [S1]. If $q$ is too far from the surface, convergence may fail [G].

## Operating characteristics
- **Performance:** On the RibSeg dataset (20 medical scans), SparseOcc achieved a Chamfer-L1 of $1.55 \pm 0.24$, Chamfer-L2 of $1.04 \pm 0.16$, and Hausdorff distance of $12.6 \pm 4.39$ [S1].
- **Comparison:** SparseOcc outperforms DiGS and NeuralPull in Chamfer-L1 and Chamfer-L2 metrics [S1]. However, NeuralPull is superior in Hausdorff Distance [S1].
- **Strengths:** Stabilizes training without requiring dense ground-truth supervision or satisfying the eikonal equation [S1]. Robust to noise and sparsity inherent in medical imaging data [S1].
- **Limitations:** Performance in Hausdorff Distance is lower than NeuralPull [S1].

## Background
SparseOcc, also referred to as RibPull in the source text, was introduced by Ouasfi et al. [S1]. It is the first implicit surface reconstruction methodology for medical imaging that leverages occupancy fields to reconstruct complex anatomical structures from CT scans [S1]. The method was designed to handle the challenging thin structures characteristic of skeletal anatomy, such as ribcages [S1].
