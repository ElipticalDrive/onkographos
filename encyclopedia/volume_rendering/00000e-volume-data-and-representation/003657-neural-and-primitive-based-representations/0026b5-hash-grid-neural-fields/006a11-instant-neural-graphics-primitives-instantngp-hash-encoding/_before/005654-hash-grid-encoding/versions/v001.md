# Hash Grid Encoding

Also called: Instant Neural Graphics Primitives (iNGP) hash encoding, Multiresolution Hash Encoding

## Overview
Hash Grid Encoding maps 3D spatial coordinates to a high-dimensional feature space using a learnable, sparse multiresolution hash grid, enabling significantly faster training and interactive rendering compared to dense voxel grids or fixed positional encodings [S1, unofficial]. It differs from standard NeRF positional encoding by replacing expensive, fixed-frequency sinusoidal transformations with trainable embeddings stored in a hash table, allowing the network to capture high-frequency details with fewer queries [S1, unofficial].

## Shared principles
The method constructs a pyramid of $L$ hash tables, where each level $i$ corresponds to a specific spatial resolution $R_i$. For a given input coordinate $\mathbf{x}$, the encoding process proceeds as follows for each level $i$:

1.  **Grid Mapping:** The coordinate $\mathbf{x}$ is scaled by the resolution $R_i$ and floored to determine the integer coordinates of the surrounding voxel corners.
2.  **Hashing:** A spatial hash function $h$ maps the integer coordinates of each corner to an index in a fixed-size hash table of size $H$.
3.  **Lookup:** The learnable feature vector $\mathbf{e}$ is retrieved from the hash table at the computed index.
4.  **Interpolation:** The feature vectors from the $2^d$ corners (where $d$ is the dimensionality, typically 3) are combined using trilinear interpolation to produce the level-specific feature vector $\mathbf{f}_i$.

The final encoded feature vector $\gamma(\mathbf{x})$ is the concatenation of the feature vectors from all $L$ levels:
$$ \gamma(\mathbf{x}) = [\mathbf{f}_0, \mathbf{f}_1, \dots, \mathbf{f}_{L-1}] $$

This concatenated vector is then passed to a neural network (typically an MLP) to predict density and color. The hash function is fixed and non-learnable, while the embedding vectors in the hash table are optimized during training [S1, unofficial].

## Subtopics

### [HashNeRF Parameters](3068-hashnerf-parameters.md)
Configures the training loop, optimizer, and model architecture for HashNeRF, solving the trade-off between training speed and reconstruction fidelity by replacing expensive positional encoding with a learnable, sparse hash grid [3068-hashnerf-parameters.md]. It differs from standard NeRF by using a multi-resolution hash grid pyramid for input encoding, allowing for significantly faster convergence and rendering [3068-hashnerf-parameters.md]. Key parameters include a grid pyramid with 10 levels, a growth factor of $b=2$, and resolutions ranging from 16 to 8192 [3068-hashnerf-parameters.md]. The hashmap size is typically $2^{19}$ (or $2^{21}$ in RING-NeRF), with 8 features per level in RING-NeRF [3068-hashnerf-parameters.md]. Training uses RAdam optimizer with an initial learning rate of $1e-2$ decaying to $1e-3$ over 25,000 iterations [3068-hashnerf-parameters.md].

### [Vanishing Point Aided Hash-Frequency Encoding](13623-vanishing-point-aided-hash-frequency-encoding.md)
A hybrid input encoding scheme for Neural Radiance Fields (NeRF) that combines multi-resolution hash encoding with deterministic frequency encoding aligned to scene structure via estimated vanishing points [13623-vanishing-point-aided-hash-frequency-encoding.md]. It solves the problem of poor reconstruction quality and instability when training NeRFs from sparse 360° inputs or imperfectly centered scenes, where standard hash encoding fails due to lack of learnable explicit structure [13623-vanishing-point-aided-hash-frequency-encoding.md]. Unlike standard hash encoding which relies solely on learnable features, this method adds deterministic frequency features to improve generalizability and robustness to imperfect scene positioning without requiring additional depth information or pre-training [13623-vanishing-point-aided-hash-frequency-encoding.md].

### Instant Neural Graphics Primitives with a Hash Encoding
- **Definition:** A method using a multiresolution hash grid encoding to enable fast training (minutes) and interactive rendering (tens of fps) by skipping empty space and using fewer network queries [S1, unofficial].
- **Steps:** Skips all empty space until the object surface is hit, utilizing 10-100x fewer steps than naive dense stepping [S1, unofficial]. Builds a multi-resolution hash grid where instead of allocating $R^3$ vectors, a smaller table of size $T$ is allocated [S1, unofficial]. Uses a spatial hash function to map each grid cell coordinate to one of $T$ 'buckets', where each bucket stores a learned feature vector [S1, unofficial]. Makes input encoding trainable along with the weight of the network [S1, unofficial].
- **Pitfalls:** Hash collisions cause grainy noise in outputs (e.g., SDFs), requiring filtering or smoothness priors for mitigation [S1, unofficial]. Simple hashing lacks coherence, while advanced methods (e.g., PCG32) add overhead without clear quality improvements [S1, unofficial].

## Background
The method was introduced by Thomas Mueller, Alex Evans, Christoph Schied, and Alexander Keller in the paper "Instant Neural Graphics Primitives with a Multiresolution Hash Encoding" (2022) [S1, unofficial]. It was developed to address the limitations of standard NeRF, specifically the slow training times (hours to days) and non-real-time inference [S1, unofficial]. The approach builds on the concept of neural graphics primitives, aiming to make them instant by optimizing the input encoding stage [S1, unofficial]. It is widely used in modern NeRF implementations, such as NerfStudio, to achieve interactive training speeds [3068-hashnerf-parameters.md].
