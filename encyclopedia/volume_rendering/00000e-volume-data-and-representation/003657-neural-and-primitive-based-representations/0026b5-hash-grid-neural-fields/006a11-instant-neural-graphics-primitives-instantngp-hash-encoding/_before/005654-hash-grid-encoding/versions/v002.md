# Hash Grid Encoding
Also called: Multi-resolution Hash Encoding, Instant Neural Graphics Primitives (INGP) Encoding

## Overview
Hash Grid Encoding maps 3D spatial coordinates to a high-dimensional feature vector using a sparse, learnable multi-resolution hash table, replacing dense voxel grids or fixed positional encodings to enable fast training and interactive rendering [S1, unofficial]. It sets itself apart from siblings like [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md) by introducing trainable, sparse embeddings that skip empty space, and from [Binary Radiance Fields](13622-binary-radiance-fields.md) by supporting continuous, high-frequency detail capture through trilinear interpolation of hash buckets [S1, unofficial].

## Shared principles
All methods in this family map a 3D point $\mathbf{x} \in \mathbb{R}^3$ to a feature vector $\mathbf{f} \in \mathbb{R}^D$ via a hierarchy of $L$ hash grids. For each level $l \in \{0, \dots, L-1\}$:
1.  **Resolution:** The spatial resolution is $R_l = R_0 \cdot b^l$, where $R_0$ is the base resolution and $b$ is the growth factor (typically $b=2$) [S1, unofficial].
2.  **Coordinate Mapping:** The input coordinate $\mathbf{x}$ is normalized to the bounding box $[0, 1]^3$ and scaled by $R_l$ to obtain continuous grid coordinates $\mathbf{c}_l = \mathbf{x} \cdot R_l$.
3.  **Voxel Identification:** The integer voxel indices $\mathbf{i} \in \mathbb{Z}^3$ are computed as $\lfloor \mathbf{c}_l \rfloor$. The 8 corner vertices of the voxel are identified by adding binary offsets $\mathbf{o} \in \{0, 1\}^3$ to $\mathbf{i}$.
4.  **Hashing:** Each corner coordinate $\mathbf{i} + \mathbf{o}$ is hashed to a bucket index $h \in \{0, \dots, T-1\}$ using a hash function $H_l(\mathbf{i} + \mathbf{o})$, where $T$ is the hash table size (e.g., $2^{19}$) [S1, unofficial].
5.  **Feature Lookup:** The feature vector for each corner is retrieved from a learnable embedding table $E_l$ at index $h$: $\mathbf{e}_{corner} = E_l[H_l(\mathbf{i} + \mathbf{o})]$.
6.  **Interpolation:** The features from the 8 corners are combined using trilinear interpolation based on the fractional part of $\mathbf{c}_l$ to produce the level-specific feature vector $\mathbf{f}_l$.
7.  **Concatenation:** The final encoded feature is the concatenation of all levels: $\mathbf{f} = [\mathbf{f}_0, \dots, \mathbf{f}_{L-1}]$ [S1, unofficial].

## Subtopics

### [HashNeRF Parameters](3068-hashnerf-parameters.md)
Details the specific hyperparameters for HashNeRF, including a 10-level hash grid pyramid with resolutions from 16 to 8192, a hash map size of $2^{19}$, and RAdam optimizer with $\epsilon=1e-15$. It distinguishes itself by its specific initialization and training loop configuration for synthetic and real-world datasets, balancing memory and quality.

### [Vanishing Point Aided Hash-Frequency Encoding](13623-vanishing-point-aided-hash-frequency-encoding.md)
A hybrid encoding that concatenates multi-resolution hash features with deterministic frequency encoding aligned to scene structure via estimated vanishing points. It solves reconstruction instability in sparse 360° inputs by adding explicit structural priors that standard hash encoding lacks, without requiring depth information.

### Instant Neural Graphics Primitives with a Hash Encoding
#### definition
- [S1, unofficial] A method using a multiresolution hash grid encoding to enable fast training (minutes) and interactive rendering (tens of fps) by skipping empty space and using fewer network queries.
#### step
- [S1, unofficial] Skips all empty space until the object surface is hit, utilizing 10-100x fewer steps than naive dense stepping.
- [S1, unofficial] Builds a multi-resolution hash grid where instead of allocating $R^3$ vectors, a smaller table of size $T$ is allocated.
- [S1, unofficial] Uses a spatial hash function to map each grid cell coordinate to one of $T$ 'buckets', where each bucket stores a learned feature vector.
- [S1, unofficial] Makes input encoding trainable along with the weight of the network.
#### pitfall
- [S1, unofficial] Hash collisions cause grainy noise in outputs (e.g., SDFs), requiring filtering or smoothness priors for mitigation.
- [S1, unofficial] Simple hashing lacks coherence, while advanced methods (e.g., PCG32) add overhead without clear quality improvements.

## Background
Originated in the 2022 paper "Instant Neural Graphics Primitives with a Multiresolution Hash Encoding" by Thomas Mueller, Alex Evans, Christoph Schied, and Alexander Keller [S1, unofficial]. It was developed to address the slow training and inference speeds of original NeRF by replacing dense positional encoding with a sparse, trainable hash grid, enabling neural graphics primitives to run in minutes rather than days [S1, unofficial]. It is widely used in real-time rendering applications and modern NeRF variants like Instant-NGP and ZipNeRF.
