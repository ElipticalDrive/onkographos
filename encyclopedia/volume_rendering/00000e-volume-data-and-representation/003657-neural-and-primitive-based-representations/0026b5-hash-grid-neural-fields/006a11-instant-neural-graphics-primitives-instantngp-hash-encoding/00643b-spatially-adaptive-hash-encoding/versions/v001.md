# Spatially-Adaptive Hash Encoding

Also called: Progressive Encoding, Progressive Spatial Mask Hash Encoding, Progressive Spatially-Adaptive Hash Encoding, SDF-based Spatially Adaptive Hash Encoding, Spatial Mask Hash Encoding

## Overview
Spatially-Adaptive Hash Encoding is a learned feature encoding method that allows a neural network to dynamically select its encoding basis as a function of space by masking the contribution of features stored at separate grid resolutions [S1]. It solves the problem of balancing high-frequency detail recovery with noise suppression in surface reconstruction, where fixed global grid resolutions often introduce artifacts in smooth regions or fail to capture fine details in complex areas [S1]. Unlike fixed multi-resolution hash encodings, this method splits the feature grids into an SDF representation and a smaller spatial mask hash grid, enabling the network to fit a wider range of frequencies without introducing noise [S1].

## How it works
The method builds on Neuralangelo [9], utilizing volume rendering SDFs and numerical gradients [S1]. It augments the standard multi-resolution hash grid by introducing a learned spatial mask that weights the contribution of each resolution level based on local scene complexity [S1].

### Inputs and Outputs
*   **Input:** A 3D coordinate $\mathbf{x} = (x, y, z)$.
*   **Output:** A concatenated feature vector $\mathbf{h}(\mathbf{x})$ used by the SDF network.

### Data Structures
The method maintains two distinct hash grid structures:

1.  **SDF Multi-Resolution Hash Grid:**
    *   Contains $N$ levels of resolution.
    *   Stores feature vectors $\mathbf{f}_l$ for each level $l \in [1, N]$.
    *   Standard hash grid parameters (resolution range, dictionary size) are inherited from the base InstantNGP/Neuralangelo configuration [S1].

2.  **Spatial Mask Hash Grid:**
    *   A smaller, dedicated hash grid used to compute the spatial mask.
    *   **Levels:** 8 levels.
    *   **Resolution Range:** $32^3$ to $2048^3$ units [S1].
    *   **Feature Dimension:** 4 [S1].
    *   **Hash Dictionary Size:** $2^{18}$ [S1].

### Spatial Mask Network
A shallow Multi-Layer Perceptron (MLP) processes the features from the Spatial Mask Hash Grid to produce the mask values.
*   **Input:** Feature vector $\mathbf{g}$ from the spatial mask hash grid.
*   **Architecture:** 1 hidden layer with 16 units [S1].
*   **Activation:** Softplus [S1].
*   **Output:** A scalar value per resolution level. Note: The source text states the mask is produced with "sigmoid activation" in the methodology description but specifies "softplus activation" in the implementation details. The final mask values $s_l(\mathbf{x})$ are constrained to $(0, 1)$ [S1].

### Numbered Steps
1.  **Feature Retrieval:** Given input coordinate $\mathbf{x}$, retrieve interpolated feature vectors $\mathbf{f} = [\mathbf{f}_1, \dots, \mathbf{f}_N]$ from the SDF multi-resolution hash grid and feature vector $\mathbf{g}$ from the spatial mask hash grid [S1].
2.  **Mask Computation:** Feed $\mathbf{g}$ into the Spatial Mask Network MLP to produce a spatial mask vector $\mathbf{s}(\mathbf{x}) = [s_1(\mathbf{x}), \dots, s_N(\mathbf{x})]$, where each $s_l(\mathbf{x}) \in (0, 1)$ represents the weight for resolution level $l$ [S1].
3.  **Adaptive Weighting:** Compute the final hash encoding $\mathbf{h}(\mathbf{x})$ by element-wise multiplying the features from each resolution level by their corresponding mask value [S1].
4.  **Progressive Unveiling (Training):** During optimization, progressively unveil finer grids to the SDF network. Initially, only coarse grids are active. As training progresses, finer grids are enabled [S1].
5.  **Gradient Blocking:** When a grid resolution is inactive (masked out or not yet unveiled), block gradients to the spatial masks of those inactive resolutions to prevent the mask network from learning to permanently mask out finer grids prematurely [S1].

### Formulas
The final hash encoding $\mathbf{h}(\mathbf{x})$ is computed as [S1]:

$$
\mathbf{h}(\mathbf{x}) = [s_1(\mathbf{x}) \cdot \mathbf{f}_1, \dots, s_N(\mathbf{x}) \cdot \mathbf{f}_N]
$$

Where:
*   $\mathbf{f}_l$ is the feature vector from the SDF hash grid at level $l$.
*   $s_l(\mathbf{x})$ is the scalar mask value for level $l$ at coordinate $\mathbf{x}$.
*   $N$ is the total number of levels in the SDF hash-grid [S1].

### Parameters
*   **$N$:** Number of levels in the SDF hash-grid. Not given in the sources.
*   **Spatial Mask Grid Levels:** 8 [S1].
*   **Spatial Mask Feature Dim:** 4 [S1].
*   **Spatial Mask Hash Size:** $2^{18}$ [S1].
*   **MLP Hidden Units:** 16 [S1].

### Edge Cases and Pitfalls
*   **Hash-Compression Artifacts:** These occur most frequently in the finest grids [S1]. The spatially-adaptive nature of the method incentivizes the network to ignore the usage of finest grids in smooth regions, thereby mitigating these artifacts [S1].
*   **Initialization and Smoothing:** If all resolutions are active at initialization, fine grids are smoothed by the large $\epsilon$ used in numerical gradients (from Neuralangelo) and may need to "relearn" details later. This can prevent fine details from ever being learned [S1].
*   **Premature Masking:** If all grid resolutions are active from the start, the spatial mask network may converge to masking out finer grids permanently because they are not required for early-stage coarse optimization. This is prevented by blocking gradients to inactive grid resolutions [S1].

### Pseudocode

```python
import torch
import torch.nn as nn

class SpatialMaskMLP(nn.Module):
    """
    Shallow MLP for computing spatial masks.
    Input: feature vector g from spatial mask hash grid.
    Output: scalar mask values for each resolution level.
    """
    def __init__(self, feature_dim=4, hidden_units=16, num_levels=8):
        super().__init__()
        # Source specifies 1 hidden layer of 16 units with softplus activation [S1]
        self.fc1 = nn.Linear(feature_dim, hidden_units)
        self.softplus = nn.Softplus()
        # Output layer to produce one scalar per resolution level
        self.fc2 = nn.Linear(hidden_units, num_levels)
        # Note: Source mentions sigmoid activation in text but softplus in details.
        # We apply a sigmoid here to ensure output is in (0, 1) as stated [S1].
        self.sigmoid = nn.Sigmoid()

    def forward(self, g):
        x = self.fc1(g)
        x = self.softplus(x)
        x = self.fc2(x)
        return self.sigmoid(x)

class SpatiallyAdaptiveHashEncoding:
    def __init__(self, sdf_hash_grid, spatial_mask_hash_grid, num_levels):
        """
        Args:
            sdf_hash_grid: Multi-resolution hash grid for SDF features.
            spatial_mask_hash_grid: Hash grid for spatial mask features.
            num_levels: Number of resolution levels N.
        """
        self.sdf_hash_grid = sdf_hash_grid
        self.spatial_mask_hash_grid = spatial_mask_hash_grid
        self.num_levels = num_levels
        self.mask_mlp = SpatialMaskMLP(
            feature_dim=4, 
            hidden_units=16, 
            num_levels=num_levels
        )
        # Track which levels are currently active for gradient blocking
        self.active_levels = [True] * num_levels

    def get_sdf_features(self, x):
        """
        Retrieve interpolated features f from SDF multi-resolution hash grid.
        Returns list of feature vectors [f_1, ..., f_N].
        """
        # Implementation depends on specific hash grid library (e.g., tiny-cuda-nn)
        # This is a placeholder for the retrieval logic [S1]
        features = []
        for l in range(self.num_levels):
            # Assuming get_features returns a tensor of shape [batch, feature_dim]
            f_l = self.sdf_hash_grid.get_features(x, level=l)
            features.append(f_l)
        return features

    def get_mask_features(self, x):
        """
        Retrieve interpolated feature vector g from spatial mask hash grid.
        """
        # Spatial mask grid has fixed 8 levels, but we only need one feature vector g
        # to feed into the MLP. The MLP handles the resolution weighting.
        # Source says "g from the spatial mask hash grid" [S1]
        # We assume we sample from a representative level or aggregate.
        # Given the small size, we might just use the coarsest or finest, 
        # or the source implies a single grid structure feeding the MLP.
        # For implementation, we assume a method to get 'g' from the grid.
        g = self.spatial_mask_hash_grid.get_features(x, level=0) 
        return g

    def forward(self, x):
        """
        Compute spatially-adaptive hash encoding.
        
        Args:
            x: Input coordinate tensor of shape [batch, 3].
            
        Returns:
            h: Concatenated adaptive feature vector.
        """
        # 1. Retrieve features
        f_list = self.get_sdf_features(x) # List of tensors [f_1, ..., f_N]
        g = self.get_mask_features(x)     # Tensor [batch, 4]
        
        # 2. Compute mask
        # g is passed through the MLP to get s(x)
        s = self.mask_mlp(g) # Shape: [batch, N]
        
        # 3. Progressive Encoding & Gradient Blocking
        # If a level is inactive, we block gradients to its mask value.
        # In PyTorch, this is done by detaching or zeroing gradients.
        # We create a mask tensor for gradient blocking.
        active_mask_tensor = torch.tensor(self.active_levels, device=x.device).unsqueeze(0).unsqueeze(-1) # [1, 1, N]
        
        # Detach inactive levels' mask values to block gradients
        # s_detached will have gradients only for active levels
        s_detached = s.clone().detach()
        s_detached.requires_grad_(True)
        
        # Zero out gradients for inactive levels
        # Note: s is a leaf tensor or result of operations. 
        # A cleaner way in autograd is to multiply by a mask that doesn't require grad,
        # but here we want to block gradients TO the mask network.
        # The source says "block gradients to the spatial masks of inactive grid resolutions".
        # This implies the mask values s_l for inactive l should not update the MLP weights.
        
        # We can achieve this by masking the loss contribution or modifying the tensor.
        # Here we modify s to have zero gradient for inactive levels.
        s_grad_mask = torch.tensor(self.active_levels, device=x.device).float().unsqueeze(0).unsqueeze(-1) # [1, 1, N]
        s_grad_mask = s_grad_mask.detach()
        
        # Apply gradient mask: s_final = s * s_grad_mask
        # Since s_grad_mask is detached, gradients won't flow back through inactive indices.
        s_final = s * s_grad_mask
        
        # 4. Compute final encoding
        # h(x) = [s_1 * f_1, ..., s_N * f_N]
        # We need to concatenate the weighted features.
        weighted_features = []
        for l in range(self.num_levels):
            f_l = f_list[l]
            s_l = s_final[:, l:l+1] # Shape [batch, 1]
            # Broadcast s_l to match f_l dimensions
            weighted_f_l = f_l * s_l
            weighted_features.append(weighted_f_l)
            
        # Concatenate along the feature dimension
        # Assuming f_l are shape [batch, dim], result is [batch, N * dim]
        h = torch.cat(weighted_features, dim=-1)
        
        return h
```

## Subtopics

### Progressive Training
A training strategy that gradually introduces higher-frequency details or finer grid resolutions during optimization to prevent early convergence to smooth solutions. [Progressive Training](9142-progressive-training.md)

### Dense Grid Encoding
A method using dense voxel grids instead of sparse hash grids, offering different memory and access characteristics. [Dense Grid Encoding](9335-dense-grid-encoding.md)

A method for adaptive coordinate-based representations, potentially offering alternative ways to handle spatial adaptivity. [ACORN](9336-acorn.md)

The foundational technique of using hash grids at multiple resolutions, which Spatially-Adaptive Hash Encoding extends with learned masks. [Multi-resolution Hash Encoding](10200-multi-resolution-hash-encoding.md)

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** The method adds a small spatial mask hash grid (8 levels, $2^{18}$ dictionary size, feature dim 4) and a small MLP (16 units) to the base Neuralangelo model. The total parameter count increases marginally from 366M (Neuralangelo) to 374M [S1].
*   **Measured Performance:** Achieves state-of-the-art performance on standard benchmark surface reconstruction datasets (DTU) [S1].
*   **Strengths:**
    *   Dynamically adjusts encoding bias based on scene complexity, allowing fine features in high-detail regions while preserving lower frequency embeddings in smoother regions [S1].
    *   Mitigates hash-compression artifacts in finest grids by allowing the network to ignore them in smooth areas [S1].
*   **Limitations:**
    *   Requires careful scheduling of grid activation (progressive encoding) to avoid premature masking or smoothing of fine details [S1].
    *   Adds slight computational overhead due to the additional hash grid lookup and MLP inference [S1].
*   **When to Use:** Suitable for surface reconstruction tasks requiring high-fidelity details in complex regions while maintaining clean surfaces in smooth areas, particularly when using hash-grid-based neural fields [S1].
*   **When Not to Use:** If the scene is uniformly simple or uniformly complex, the overhead of learning spatial masks may not be justified compared to fixed multi-resolution encodings.

## Background
The method was proposed by Octave Mariotti, Amir Vaxman, Thomas Walker, and others from the University of Edinburgh [S1]. It builds directly on the Neuralangelo framework [9], which introduced volume rendering SDFs and numerical gradients for surface reconstruction [S1]. The work addresses limitations of NeRF's density-based representation and fixed multi-resolution hash encodings, aiming to provide a more flexible and precise surface reconstruction method [S1]. The paper was published in 2025 [S1].
