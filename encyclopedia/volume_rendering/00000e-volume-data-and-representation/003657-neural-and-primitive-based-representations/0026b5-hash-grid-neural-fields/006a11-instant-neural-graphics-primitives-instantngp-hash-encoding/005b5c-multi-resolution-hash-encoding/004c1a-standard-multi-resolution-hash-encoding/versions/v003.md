# Standard Multi-resolution Hash Encoding

Also called: Instant-NGP Hash Encoding, MERF Hash Encoding

## Overview
Standard Multi-resolution Hash Encoding (SMHE) maps 3D spatial coordinates to a high-dimensional feature vector using a set of trainable hash tables at multiple resolutions, enabling efficient neural scene representation [S2]. It distinguishes itself from traditional positional encoding by replacing fixed basis functions with learnable parameters stored in sparse hash grids, significantly reducing memory usage and training time while maintaining high reconstruction quality [S1, unofficial].

## Shared principles
The method relies on a family of $L$ hash tables, indexed by resolution level $l \in \{0, \dots, L-1\}$. Each table $l$ has a fixed size $T_l$ (number of entries) and stores feature vectors of dimension $F$ [S2].

**Coordinate Mapping and Hashing:**
For an input 3D coordinate $\mathbf{x} = (x, y, z)$, the coordinate is scaled by a factor of $2^l$ for each level $l$:
$$ \mathbf{x}_l = 2^l \mathbf{x} $$
The scaled coordinate is mapped to a voxel grid. The integer voxel indices $\mathbf{v}_l = (v_x, v_y, v_z)$ are obtained by flooring the scaled coordinates:
$$ v_i = \lfloor (\mathbf{x}_l)_i \rfloor, \quad i \in \{x, y, z\} $$
The fractional part $\mathbf{u}_l = (u_x, u_y, u_z)$ determines the interpolation weights:
$$ u_i = (\mathbf{x}_l)_i - v_i $$
To retrieve features, the voxel indices are hashed to table indices. A standard hash function $H_l$ maps the voxel coordinates to an index in $[0, T_l)$:
$$ i_l = H_l(v_x, v_y, v_z) \pmod{T_l} $$
Common implementations use a simple sum or XOR-based hash, though the specific collision resolution strategy (e.g., chaining or open addressing) is implementation-dependent [G].

**Trilinear Interpolation:**
To ensure smoothness and differentiability, features from the 8 neighboring voxels are retrieved and interpolated. Let $\mathbf{f}_{l, \mathbf{v}}$ be the feature vector at voxel $\mathbf{v}$ in table $l$. The interpolated feature $\hat{\mathbf{f}}_l$ is computed as:
$$ \hat{\mathbf{f}}_l = \sum_{\mathbf{v}' \in \text{neighbors}(\mathbf{v}_l)} w(\mathbf{v}') \cdot \mathbf{f}_{l, \mathbf{v}'} $$
where the weight $w(\mathbf{v}')$ for a neighbor $\mathbf{v}' = (v'_x, v'_y, v'_z)$ is:
$$ w(\mathbf{v}') = \prod_{i \in \{x,y,z\}} \begin{cases} u_i & \text{if } v'_i = v_i + 1 \\ 1 - u_i & \text{if } v'_i = v_i \end{cases} $$

**Feature Concatenation:**
The final feature vector $\mathbf{F}$ is the concatenation of the interpolated features from all levels:
$$ \mathbf{F} = [\hat{\mathbf{f}}_0; \hat{\mathbf{f}}_1; \dots; \hat{\mathbf{f}}_{L-1}] $$
The total dimensionality is $L \times F$.

**Initialization and Optimization:**
Feature vectors are typically initialized with small random values or zeros [G]. The parameters are optimized using stochastic gradient descent (SGD) or Adam, updating the hash table entries directly [S2].

### Grid-NeRF
Grid-NeRF uses plane grid features and a small MLP network to represent the 3D scene [S1, unofficial]. It utilizes a NeRF branch to guide the optimization process of the scene [S1, unofficial].

### Instant-NGP Depth Rendering
Instant-NGP bounds the scene into an axis-aligned bounding box using a multi-resolution hash table of trainable feature vectors, optimized via stochastic gradient descent [S2]. It renders depth similarly to vanilla NeRF using standard volume rendering equations [S2].

### UrbanIR Scene Representation
UrbanIR uses two separate multi-scale hash tables for geometry and appearance to improve convergence stability and rendering quality [S3]. For a point $\mathbf{x} \in \mathbb{R}^3$, it retrieves and interpolates parameters using hash functions $F_g(\mathbf{x}, \theta_g)$ and $F_a(\mathbf{x}, \theta_a)$ [S3]. The density field $\sigma$ is used for volume rendering, visibility estimation, and normal loss calculation, requiring accuracy for multiple purposes [S3]. The implementation uses tiny-cuda-nn [S3].

## Background
The concept of multi-resolution hash encoding was introduced in the context of Instant-NGP [S2]. Instant-NGP proposed a novel scene representation that bounds an actual scene into an axis-aligned bounding box and uses a small neural network augmented by a multi-resolution hash table of trainable feature vectors whose values are optimized through stochastic gradient descent [S2]. This approach was later adopted and adapted by various other methods, including HashNeRF [S1, unofficial] and UrbanIR [S3], to accelerate training and improve scalability for large-scale scenes.
