# ACORN

Also called: Auxiliary Coordinate Encoder, ACORN, Adaptive Coordinate Encoder

## Overview
ACORN is a parametric feature encoding method that uses a tree subdivision of the input domain to output dense feature grids in leaf nodes, which are then linearly interpolated [S1, unofficial][S2]. It yields a greater degree of adaptivity compared with previous parametric encodings, albeit at greater computational cost [S1, unofficial][S2].

## How it works
**Inputs and outputs:**
- Input: A coordinate vector $\mathbf{x} \in \mathbb{R}^d$ (typically $d=3$ for 3D scenes) [S1, unofficial][S2].
- Output: A feature vector $\mathbf{f}$ representing the encoded features for $\mathbf{x}$ [S1, unofficial][S2].

**Data structures:**
- **Tree Structure:** A hierarchical subdivision of the domain $\mathbb{R}^d$ [S1, unofficial][S2]. The specific tree topology is not detailed in the sources [S1, unofficial][S2].
- **Leaf Node Feature Grids:** Each leaf node contains a dense feature grid of approximately 10,000 entries [S1, unofficial][S2].
- **Neural Network (ACORN):** A large neural network trained to output the parameters for these dense feature grids [S1, unofficial][S2].

**Steps:**
1. **Tree Traversal:** Determine the leaf node in the tree subdivision that contains the input coordinate $\mathbf{x}$ [S1, unofficial][S2].
2. **Feature Grid Retrieval:** Retrieve the dense feature grid associated with the identified leaf node [S1, unofficial][S2].
3. **Interpolation:** Linearly interpolate the values within the dense feature grid at the local position of $\mathbf{x}$ relative to the leaf node, as in Liu et al. [2020] [S1, unofficial][S2].
4. **Output:** The result of the interpolation is the encoded feature vector $\mathbf{f}$ [S1, unofficial][S2].

**Pseudocode:**
```python
def acorn_encode(x, tree, acorn_network):
    # Step 1: Traverse tree to find leaf node containing x
    # (Exact traversal logic depends on unspecified tree topology)
    leaf_node = tree.root
    while not leaf_node.is_leaf:
        split_val = leaf_node.split_value
        leaf_node = leaf_node.left if x < split_val else leaf_node.right
    
    # Step 2: Forward pass through ACORN network to retrieve feature grid
    feature_grid = acorn_network.forward(leaf_node.id)
    
    # Step 3: Linearly interpolate within the feature grid at x's local position
    x_local = (x - leaf_node.min_bound) / (leaf_node.max_bound - leaf_node.min_bound)
    x_local = max(0.0, min(1.0, x_local))
    f = linear_interpolate(feature_grid, x_local)
    
    return f

def linear_interpolate(grid, local_pos):
    # Standard linear interpolation between adjacent grid values
    idx = local_pos * (len(grid) - 1)
    i = int(idx)
    w = idx - i
    if i + 1 < len(grid):
        return grid[i] * (1 - w) + grid[i + 1] * w
    return grid[i]
```

**Parameters:**
- **Tree Subdivision:** Not specified in the sources [S1, unofficial][S2].
- **Feature Grid Size:** On the order of 10,000 entries per leaf node [S1, unofficial][S2].
- **Neural Network Size:** Described as "large" [S1, unofficial][S2].

**Edge cases and pitfalls:**
- **Computational Cost:** ACORN has greater computational cost compared to hash or grid encodings [S1, unofficial][S2].
- **Amortization:** The computational cost is only amortized when sufficiently many inputs $\mathbf{x}$ fall into each leaf node [S1, unofficial][S2].

## Operating characteristics
- **Time Complexity:** Not explicitly given, but described as having "greater computational cost" than hash or grid encodings [S1, unofficial][S2].
- **Memory Complexity:** Dense grids of trainable features consume much more memory than neural network weights [S1, unofficial][S2].
- **Measured Performance:** Not given in the sources [S1, unofficial][S2].
- **Scaling:** Not given in the sources [S1, unofficial][S2].
- **Strengths:** Yields a larger degree of adaptivity compared with previous parametric encodings [S1, unofficial][S2].
- **Limitations:** Greater computational cost, which can only be amortized when sufficiently many inputs fall into each leaf node [S1, unofficial][S2]. Dense grids consume more memory than neural network weights [S1, unofficial][S2].
- **When to use:** When adaptivity is prioritized over computational efficiency and memory usage [S1, unofficial][S2].
- **When not to use:** When inputs are sparse or computational resources are limited [S1, unofficial][S2].

## Background
ACORN (Auxiliary Coordinate Encoder) was introduced by Martel et al. in 2021 [S1, unofficial][S2]. It is a parametric approach that uses a tree subdivision of the domain $\mathbb{R}^d$ [S1, unofficial][S2]. The method was motivated by the downsides of existing parametric encodings, such as high memory consumption due to dense grids of trainable features [S1, unofficial][S2]. ACORN aims to provide greater adaptivity while maintaining a parametric structure [S1, unofficial][S2].
