# HollowNeRF


## Overview
HollowNeRF is a compression method for Neural Radiance Fields (NeRF) that automatically sparsifies the feature grid during training by using a trainable 3D saliency mask to guide efficient feature pruning, redistributing hash collisions to improve rendering quality with fewer parameters [S1, S2]. It sets itself apart from standard hash-grid NeRFs like Instant-NGP by explicitly learning which spatial regions are necessary for rendering, thereby suppressing features in empty or invisible areas rather than relying on static priors or post-hoc pruning [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D coordinate $x = (x, y, z)$, ground truth images for loss computation.
*   **Outputs:** Density $\sigma$ and color $c$ for volume rendering.

**Data Structures:**
1.  **Multi-level Hash Grid ($H$):** The standard feature hash grid from Instant-NGP, storing dense feature vectors [S1].
2.  **Trainable 3D Saliency Grid ($G$):** A coarse 3D tensor of resolution $T \times T \times T$ [S1]. It stores trainable scalar values representing the saliency of features near each grid voxel [S1]. $T$ is typically much smaller than the resolution of the dense feature grid [S1].
3.  **MLP:** A shallow neural network (fully connected layers) that decodes features into density and color [S1].

**Numbered Steps:**
1.  **Feature Fetch:** Given input coordinate $x$, fetch the corresponding feature vector $f$ from the multi-level hash grid $H$, following the Instant-NGP method [S1].
2.  **Saliency Prediction:** Determine the 8 voxels in the saliency grid $G$ surrounding $x$ [S1]. Perform trilinear interpolation on the values of these 8 voxels to obtain a smoothed saliency distribution value $p_{\text{raw}}$ [S1]. Apply a sigmoid function to $p_{\text{raw}}$ to predict the saliency weight $p$:
    $$ p = \sigma_{\text{sigmoid}}(p_{\text{raw}}) $$
    where $p \in [0, 1]$ [S1].
3.  **Feature Scaling:** Scale the fetched feature $f$ by the saliency weight $p$ to get the weighted feature $v$:
    $$ v = p \cdot f $$
    This suppresses features in regions where $p \approx 0$ (empty or invisible regions) [S1].
4.  **Zero-Skipping Gate:** Feed the weighted feature $v$ into the MLP [S1]. The MLP is designed or gated such that if $v = 0$, the output density $\sigma = 0$ [S1]. This ensures that pruned regions do not contribute to the volume rendering integral [S1].
5.  **Rendering and Loss:** Use the predicted density $\sigma$ and color to perform volume rendering [S1]. Compare the rendered image to the ground truth to obtain a loss $L$ [S1].
6.  **ADMM Pruning:** During training, use an Alternating Direction Method of Multipliers (ADMM) pruner to sparsify the saliency value distribution [S1]. The ADMM pruner enforces a sparsity constraint on the saliency grid $G$ when optimizing the loss $L$, explicitly driving the saliency weights to 0 [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class HollowNeRF:
    def __init__(self, saliency_resolution_T, mlp):
        """
        saliency_resolution_T: int, resolution T of the 3D saliency grid G
        mlp: nn.Module, the decoder network taking feature vector v
        """
        self.T = saliency_resolution_T
        self.mlp = mlp
        
        # Initialize trainable 3D saliency grid G
        self.G = nn.Parameter(torch.zeros(1, 1, T, T, T))
        
        # ADMM auxiliary variables for sparsity constraint
        self.Z = nn.Parameter(torch.zeros(1, 1, T, T, T))
        self.Y = nn.Parameter(torch.zeros(1, 1, T, T, T))
        self.lambda_param = 1.0  # Sparsity penalty weight

    def get_saliency_weight(self, x):
        """
        x: Tensor of shape (N, 3), coordinates in [0, 1]^3
        Returns: Tensor of shape (N, 1), saliency weights p
        """
        # Scale coordinates to grid indices [0, T-1]
        x_grid = x * (self.T - 1)
        
        # Normalize to [-1, 1] for standard 3D interpolation
        x_norm = (x_grid / (self.T - 1)) * 2 - 1
        x_norm = x_norm.unsqueeze(0).unsqueeze(0).unsqueeze(0)  # (1, 1, 1, N, 3)
        
        # Trilinear interpolation of G at x_grid
        G_expanded = self.G  # (1, 1, T, T, T)
        p_raw_sampled = F.grid_sample(G_expanded, x_norm, mode='trilinear', align_corners=True)
        p_raw = p_raw_sampled.squeeze()  # (N,)
        
        # Sigmoid activation
        p = torch.sigmoid(p_raw)
        return p.unsqueeze(-1)  # (N, 1)

    def forward(self, x):
        """
        x: Tensor of shape (N, 3)
        Returns: density (N, 1), color (N, 3)
        """
        # 1. Fetch feature from hash grid H following Instant-NGP [S1]
        # (Implementation of multi-level hash grid lookup is external to this module)
        f = self.hash_grid_lookup(x)  # (N, D)
        
        # 2. Predict saliency weight
        p = self.get_saliency_weight(x)  # (N, 1)
        
        # 3. Scale feature
        v = p * f  # (N, D)
        
        # 4. Decode via MLP
        out = self.mlp(v)  # (N, 1 + C)
        sigma = out[..., 0:1]
        color = out[..., 1:]
        
        # 5. Zero-skipping gate: ensure v=0 maps to sigma=0
        mask = (torch.abs(v) > 1e-6).float()
        sigma = sigma * mask
        
        return sigma, color

    def admm_step(self):
        """
        Perform one ADMM iteration to enforce sparsity on G.
        Minimizes ||G - Z||^2 + lambda * ||Z||_0 subject to G = Z.
        """
        # 1. Update Z (proximal operator for L0 sparsity)
        Z_update = self.G + self.Y
        self.Z.data = torch.where(torch.abs(Z_update) > self.lambda_param, Z_update, torch.zeros_like(Z_update))
        
        # 2. Update G (quadratic subproblem)
        self.G.data = self.Z - self.Y
        
        # 3. Update Y (dual ascent)
        self.Y.data = self.Y + (self.G - self.Z)

    def train_step(self, x, y_gt, optimizer, admm_optimizer):
        sigma, color = self.forward(x)
        # Volume rendering and loss computation L(image, y_gt) are external to the feature decoding pipeline [S1].
        # loss = compute_loss(render(sigma, color, rays), y_gt)
        # optimizer.zero_grad()
        # loss.backward()
        # optimizer.step()
        
        # ADMM step to prune saliency grid
        admm_optimizer.step(self.admm_step)
```

**Parameters:**
*   $T$: Resolution of the trainable 3D saliency grid $G$. Typically much smaller than the resolution of the dense feature grid [S1].
*   $\lambda$: Sparsity penalty weight in the ADMM pruner. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Reflective Surfaces:** HollowNeRF encounters difficulties in handling objects with reflective surfaces, which are rendered inadequately [S2].
*   **Precision:** The zero-skipping gate relies on $p$ reaching exactly 0 or sufficiently close to 0 to ensure $\sigma=0$. The ADMM pruner explicitly drives the saliency weights to 0 to satisfy this condition [S1].

## Operating characteristics
*   **Parameter Count:** HollowNeRF uses 31% of the parameters of Instant-NGP while delivering comparable rendering quality [S1].
*   **Accuracy:** It can achieve up to 1dB PSNR accuracy gain using only 56% of the parameters compared to Instant-NGP [S1].
*   **Strengths:** Automatically sparsifies the feature grid during training without requiring prior knowledge of object shape [S1]. Reduces parameter count significantly while maintaining or improving rendering quality [S1, S2].
*   **Limitations:** Struggles with reflective surfaces [S2].

## Background
HollowNeRF was proposed in 2023 as a novel compression solution for hashgrid-based NeRFs [S1]. It addresses the issue that existing solutions rely on prior knowledge of object shape or costly repeated model evaluations to estimate object shape during training [S1]. The method leverages the sparsity in 3D scenes to redistribute hash collisions, improving the cost-accuracy tradeoff [S1].
