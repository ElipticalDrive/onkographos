# Multi-Resolution Feature Grids with MLP Decoder

Also called: Multi-resolution feature grids, MERF with MLP decoder

## Overview
This method enhances neural implicit representations by replacing a single feature grid with a set of multi-resolution feature grids $\{\Phi_l^\theta\}$, indexed via spatial hash functions at finer levels to manage memory [S1]. It solves the problem of capturing multi-scale geometric details without the cubic memory explosion associated with dense grids [S1]. It sets itself apart from [Standard Multi-resolution Hash Encoding](13152-standard-multi-resolution-hash-encoding.md) by explicitly conditioning an MLP decoder on the concatenated interpolated features from all resolution levels, rather than using the hash encoding solely as a positional encoding input [S1].

## How it works
**Inputs:**
- 3D point $x \in \mathbb{R}^3$.
- Number of resolution levels $L$.
- Coarsest resolution $R_{min}$ and finest resolution $R_{max}$.
- Feature grids $\{\Phi_l^\theta\}_{l=1}^L$, where each grid stores learnable feature vectors.
- MLP decoder $f_\theta$.
- Positional encoding function $\gamma(\cdot)$.

**Outputs:**
- Predicted scalar value $\hat{s}$ (e.g., SDF or density).

**Data Structures:**
- **Feature Grids $\Phi_l^\theta$**: For coarse levels, these are dense tensors. For finer levels, they are sparse structures indexed by a spatial hash function $h_l: \mathbb{R}^3 \to \mathbb{Z}^+$, storing a fixed number of parameters (feature vectors) [S1].
- **MLP $f_\theta$**: A multi-layer perceptron that takes the positional encoding of $x$ and the concatenated interpolated features as input.

**Steps:**
1. **Calculate Resolutions**: Compute the resolution $R_l$ for each level $l \in \{1, \dots, L\}$ using geometric spacing:
   $$ R_l = \left\lfloor R_{min} \left( \frac{R_{max}}{R_{min}} \right)^{\frac{l-1}{L-1}} \right\rfloor $$
   This ensures resolutions are sampled in geometric space to combine features at different frequencies [S1].

2. **Interpolate Features**: For each level $l$, extract the feature vector $z_l$ by interpolating the feature grid $\Phi_l^\theta$ at point $x$:
   $$ z_l = \text{interp}(x, \Phi_l^\theta) $$
   The interpolation method (e.g., trilinear) depends on the grid structure (dense or hash-indexed) [S1].

3. **Concatenate Features**: Combine the feature vectors from all levels into a single vector $Z$:
   $$ Z = \text{concat}(z_1, z_2, \dots, z_L) $$

4. **Encode Position**: Apply positional encoding to the input point:
   $$ \gamma(x) $$

5. **Decode**: Pass the positional encoding and concatenated features through the MLP decoder:
   $$ \hat{s} = f_\theta(\gamma(x), Z) $$

**Parameters:**
- $R_{min}, R_{max}$: Define the range of spatial frequencies. Typical values depend on the scene scale.
- $L$: Number of resolution levels.
- Fixed number of parameters: Used to bound memory usage for fine-level hash grids [S1].

**Edge Cases and Pitfalls:**
- **Memory Growth**: Total grid cells grow cubically with resolution. This is mitigated by using a fixed number of parameters and spatial hash functions for indexing at finer levels [S1].
- **Hash Collisions**: Spatial hash functions may cause collisions at fine resolutions. The implementation must handle collision resolution (e.g., chaining or probing) [S1].

## Subtopics

### [Hierarchical Implicit Grids (HIGS)](21083-hierarchical-implicit-grids-higs.md)
Distinguishes between dense and sparse grid indexing for geometric vs. semantic features and uses a fixed decoder to prevent catastrophic forgetting.

## Operating characteristics
- **Memory**: Linear in the number of active cells, but bounded by the fixed parameter count for fine levels, avoiding cubic growth [S1].
- **Compute**: Requires interpolation at multiple resolutions and MLP evaluation. More expensive than single-grid methods but captures finer details.
- **Strengths**: Captures multi-scale features efficiently; scalable to large scenes via hashing.
- **Limitations**: Hash collisions may affect accuracy; requires careful tuning of $R_{min}, R_{max}, L$.

## Background
Originated in the context of neural implicit surface reconstruction, specifically in MonoSDF, which explores monocular geometric cues [S1]. It builds on the idea of multi-resolution feature grids introduced in prior works [10, 22, 45, 69, 92] as cited in [S1].
