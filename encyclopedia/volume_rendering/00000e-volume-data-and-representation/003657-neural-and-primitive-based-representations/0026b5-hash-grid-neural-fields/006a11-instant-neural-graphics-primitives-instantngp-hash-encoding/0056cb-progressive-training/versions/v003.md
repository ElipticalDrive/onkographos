# Progressive Training

Also called: Coarse-to-Fine Hash Training, Incremental layer training, Layered model training, Level Activation Schedule, Multi-level Supervision Training, Progressive Training Strategy, Progressive Training for Hash Encodings

## Overview
Progressive training is a strategy for optimizing multi-resolution hash encodings that gradually activates higher resolution levels over the course of training [S1, S3]. It solves the problem of training instability inherent in hash-based neural fields: using only low-resolution grids leads to underfitting (smooth geometry lacking details), while using all high-resolution grids from the start causes overfitting to specific camera views, resulting in noise, artifacts, and view inconsistency [S1, S4]. By starting with coarse levels and incrementally introducing finer details, the method ensures view consistency and efficient convergence [S1, S5].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $L$ multi-resolution hash grids (typically $L=6$), a total number of training iterations $maxiter$, an activation interval $active\_iter$, and initial loss weights $\lambda_1, \lambda_2, \alpha_l$ [S1, S3].
*   **Outputs:** Trained residual feature grids $R_t$ and reconstructed features $\hat{F}_t$ for the target frame or scene [S3].

**Data Structures:**
*   **Residual Feature Grids ($R_t^l$):** For each resolution level $l \in \{1, \dots, L\}$, a grid storing residual features [S3]. In the HPC framework, these are initialized and trained sequentially [S3].
*   **Reference Frame Buffer:** Stores reconstructed features $\hat{F}_t^{l-1}$ from previous frames or iterations to compute residuals [S3].
*   **Bandwidth Parameter ($\lambda$):** An integer scalar controlling the active resolution bandwidth [S1].

**Parameters:**
*   $L$: Number of resolution levels. Optimal value is 6 [S3].
*   $\lambda$: Initial value 2. Increases by 1 every 2.5% of total training steps [S1].
*   $\alpha_l$: MSE loss weight. $\alpha_6 = 1$, all other $\alpha_l = 0.25$ [S3].
*   $\lambda_1$: Rate loss weight. Set to $0.000001$ [S3].
*   $\lambda_2$: Regularization loss weight. Set to $0.000001$ [S3].
*   $active\_iter$: Iteration step determining activation timing. Set to 2,500 in HPC [S3].
*   $maxiter$: Total iterations. Set to 40,000 in HPC [S3].

**Algorithm:**
The method operates in two primary variants: the bandwidth-modulated approach (NeuS2) and the iterative residual activation approach (HPC) [S1, S3].

```python
def progressive_training(L, maxiter, active_iter, total_steps, is_keyframe):
    # 1. Initialization
    R_t = [Grid() for _ in range(L + 1)]  # Residual grids, 1-indexed
    lambda1, lambda2 = 0.000001, 0.000001
    alpha = [0.25] * (L + 1)
    alpha[6] = 1.0
    lam = 2  # Bandwidth parameter
    F_hat_prev = [None] * (L + 1)
    L_l_prev = 0.0

    # 2. Training Loop
    for it in range(1, maxiter + 1):
        # NeuS2 variant: Bandwidth update
        if it % (total_steps // 40) == 0:  # Every 2.5% of steps
            lam += 1

        # HPC variant: Level activation & freezing
        for l in range(1, L):
            if it == l * active_iter:
                R_t[l + 1].requires_grad = True
                start_entropy_estimation(R_t[l + 1])
            if it == maxiter - l * active_iter:
                R_t[L - l].requires_grad = False
                if is_keyframe():
                    lambda1, lambda2 = 0, 0

        # Feature Reconstruction
        F_hat_curr = [None] * (L + 1)
        for l in range(1, L + 1):
            if l == 1:
                F_hat_curr[l] = R_t[l]
            else:
                F_hat_curr[l] = F_hat_prev[l - 1] + R_t[l]

        # Loss Calculation and Optimization
        L_mse = compute_mse(F_hat_curr, ground_truth)
        L_reg = compute_l1_norm(R_t[l])
        L_rate = compute_rate_loss(R_t[l])
        L_l = L_l_prev + alpha[l] * L_mse + lambda1 * L_rate + lambda2 * L_reg
        L_l.backward()
        update_learning_rates()

        # Buffer Update
        F_hat_prev = F_hat_curr
```

**Edge Cases and Pitfalls:**
*   **Underfitting:** Using only low-resolution grids results in smooth geometry lacking high-frequency details [S1].
*   **Overfitting:** Using high-resolution grids from the start induces noise and artifacts, and causes the strong capacity of the grid to overfit predefined camera views, leading to inconsistent geometry across different views [S1, S4].
*   **View Consistency:** Starting with high-resolution grids produces inconsistent results across views; coarse-to-fine training mitigates this [S1, S5].

## Subtopics

### Progressive Levels of Details (Coarse-to-Fine Optimization)
A variant used in Neuralangelo that progressively activates finer hash grids as the numerical gradient step size $\epsilon$ decreases [S6]. It avoids the need for fine grids to "unlearn" coarse features by linking grid activation to the smoothing effect of numerical gradients [S6].
*   **Steps:** 1. Initialize with a subset of coarse hash grids (4 for DTU, 8 for Tanks and Temples) [S6]. 2. Exponentially decrease step size $\epsilon$ [S6]. 3. Enable a new hash resolution every 5000 iterations when $\epsilon$ equals the spatial size of that resolution [S6].
*   **Parameters:** Hash grid resolution spans $2^5$ to $2^{11}$ with 16 levels. Max hash entries per resolution is $2^{22}$ [S6]. Channel size is 8. Weight decay is applied to all parameters to prevent single-resolution features from dominating [S6].
*   **When to choose:** When using numerical gradients for surface normal computation and requiring high-fidelity surface reconstruction without auxiliary data [S6].

### Hierarchical Compensation Mechanism
A strategy that divides training into three levels, progressively increasing the resolution of tri-plane feature maps and context grids to capture fine scene details [S7].
*   **Steps:** Refine scene representation using structural features, then merge refined features $f_h = \sum f_{hi}$ from each level [S7].
*   **When to choose:** For large-scale unbounded scenes where structural similarity and global coherence are critical, such as in SplatCo [S7].

## Operating characteristics
*   **Time Complexity:** Training time is distributed across levels. By freezing higher-resolution grids until their activation step, computational cost per iteration is lower in early stages [S3]. However, the total training time is longer than single-resolution training due to the sequential nature [S1].
*   **Memory Complexity:** Memory usage scales with the number of active levels. Since only levels $1$ to $\lambda$ (or $l$) are active at any time, peak memory is lower than training all levels simultaneously, though residual grids for all levels are often initialized [S1, S3].
*   **Performance:** Achieves faster convergence and higher quality than static multi-resolution training. On the DTU dataset, it yields better Chamfer Distance (CD) and Peak Signal-to-Noise Ratio (PSNR) compared to non-progressive methods [S3].
*   **Strengths:** Prevents overfitting to camera views, ensures view consistency, and efficiently captures high-frequency details [S1, S4].
*   **Limitations:** Requires careful tuning of activation intervals ($active\_iter$) and loss weights ($\lambda_1, \lambda_2$) [S3]. Not given in the sources for specific scaling laws beyond $L=6$ [S3].
*   **When to use:** When training hash-based neural fields on consumer GPUs where overfitting is a concern and view consistency is required [S1, S4].
*   **When not to use:** When real-time inference is the only concern and training time is prohibitive, or when the scene is extremely simple and low-resolution grids suffice [S1].

## Background
Progressive training for hash encodings originated in the context of fast neural implicit surface reconstruction and volumetric video coding [S1, S3]. The bandwidth-modulated approach was introduced in NeuS2 (2023) to improve training convergence and speed for multi-view reconstruction [S1]. The iterative residual activation approach with multi-rate-distortion loss was proposed in HPC (2024) for hierarchical progressive coding of volumetric video, leveraging temporal coherence [S3]. The concept of coarse-to-fine optimization using numerical gradient step sizes was adopted in Neuralangelo (2023) for high-fidelity surface reconstruction [S6]. The strategy addresses the empirical observation that static multi-resolution training suffers from underfitting at low levels and overfitting at high levels [S1, S4].
