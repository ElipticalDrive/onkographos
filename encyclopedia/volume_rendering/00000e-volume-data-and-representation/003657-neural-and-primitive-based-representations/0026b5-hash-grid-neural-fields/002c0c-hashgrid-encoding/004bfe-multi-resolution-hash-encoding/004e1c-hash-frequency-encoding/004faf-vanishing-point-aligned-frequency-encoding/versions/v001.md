# Vanishing Point Aligned Frequency Encoding

Also called: VP-aligned encoding, Vanishing point alignment

## Overview
Vanishing Point Aligned Frequency Encoding is a technique that aligns sinusoidal positional encoding with scene structures by using estimated vanishing points, ensuring points on the same spatial line share the same mapping of specific encoding levels [S1]. Unlike standard frequency encoding, this method aligns encoding levels with scene geometry (vanishing points), improving reconstruction of axis-aligned structures, especially for frequency-based methods like MIP-NeRF 360 [S1].

## How it works
**Inputs and Outputs**
- **Input**: Original input coordinates $u$ (2D for image regression, 3D for NeRF), estimated vanishing points $v_i$.
- **Output**: Aligned coordinates $u_{aligned}$ suitable for frequency encoding.

**Data Structures**
- **Vanishing Points**: A set of 3 vanishing points $v_1, v_2, v_3$ forming an orthonormal basis $V = [v_1, v_2, v_3]^T$ [S1].
- **Frequency Levels**: The number of frequency levels should be a multiple of the number of vanishing points. In experiments, 255 levels were used [S1].

**Steps**
The process differs based on the task: Perspective Image Regression, ERP Image Regression, or 3D NeRF.

1. **Perspective Image Regression**:
   - Given a vanishing point $v_i = (x_i, y_i)$, establish a polar coordinate system with origin at $v_i$ [S1].
   - For any pixel $p = (x, y)$, calculate the polar radius $r_i$ and angle $\alpha_i$:
     $$ r_i = \sqrt{(x - x_i)^2 + (y - y_i)^2} $$
     $$ \alpha_i = \text{arctan2}(y - y_i, x - x_i) $$
   - Set the aligned coordinate $u_{i,aligned} = \alpha_i$ [S1].

2. **ERP Image Regression**:
   - Given a vanishing point $v_i = (\lambda_{0i} + \pi/2, \theta_i)$, calculate $\phi_{0i}$ for any pixel $p = (\lambda, \phi)$ [S1].
   - The formula for $\phi_0(\lambda, \phi)$ is:
     $$ \phi_0(\lambda, \phi) = \arctan\left( \tan(\phi) \sqrt{1 + \tan^2(\lambda - \lambda_0) - \tan(\theta) \tan(\lambda - \lambda_0)} \right) $$
   - All pixels on the same spatial line have the same $\phi_0$ values [S1].
   - The aligned coordinate is $u_{aligned} = (\phi_{01}, ..., \phi_{0n})^T$ [S1].

3. **3D NeRF**:
   - Convert the 2D vanishing point $v_i$ to Cartesian coordinates $v_i \in \mathbb{R}^3$:
     $$ v_i = [\sin(\theta_i)\sin(\lambda_{0i} + \pi/2), \cos(\theta_i), -\sin(\theta_i)\cos(\lambda_{0i} + \pi/2)]^T $$
   - Estimate 3 vanishing points forming an orthonormal basis $V = [v_1, v_2, v_3]^T$ based on the Manhattan world assumption [S1].
   - Compute the global transform for aligned coordinates $u_{aligned}$ using the camera rotation $R$ and the orthonormal basis $V$:
     $$ u_{aligned} = V R^T u $$
     where $u$ is the original input coordinate [S1].

**Pseudocode**

```python
import math
import numpy as np

def perspective_image_regression_encode(p, v_i):
    """
    Encode a pixel p for perspective image regression using vanishing point v_i.
    p: tuple (x, y)
    v_i: tuple (xi, yi)
    Returns: alpha_i (aligned coordinate)
    """
    x, y = p
    xi, yi = v_i
    # Calculate polar angle
    alpha_i = math.atan2(y - yi, x - xi)
    return alpha_i

def erp_image_regression_encode(p, v_i):
    """
    Encode a pixel p for ERP image regression using vanishing point v_i.
    p: tuple (lambda, phi) in radians
    v_i: tuple (lambda_0_i, theta_i) in radians
    Returns: phi_0_i (aligned coordinate)
    """
    lam, phi = p
    lam_0, theta = v_i
    
    # Calculate phi_0 using the derived formula
    # phi_0 = arctan( tan(phi) * sqrt(1 + tan^2(lam - lam_0) - tan(theta) * tan(lam - lam_0)) )
    
    tan_phi = math.tan(phi)
    tan_lam_diff = math.tan(lam - lam_0)
    tan_theta = math.tan(theta)
    
    # Handle potential division by zero or invalid sqrt arguments if necessary
    # Based on source, this is the direct formula
    term = 1 + tan_lam_diff**2 - tan_theta * tan_lam_diff
    
    # Guard against negative term inside sqrt due to numerical precision
    if term < 0:
        term = 0
        
    phi_0_i = math.atan(tan_phi * math.sqrt(term))
    return phi_0_i

def nerf_encode(u, V, R):
    """
    Encode a 3D point u for NeRF using vanishing point basis V and camera rotation R.
    u: numpy array (3,) representing the 3D coordinate
    V: numpy array (3, 3) orthonormal basis matrix where rows are vanishing points
    R: numpy array (3, 3) camera rotation matrix
    Returns: u_aligned (numpy array (3,))
    """
    # u_aligned = V * R^T * u
    # Note: In the source, V is defined as [v1, v2, v3]^T, so it is a 3x3 matrix.
    # R maps from camera space to world space.
    # The formula is u_aligned = V * R^T * u
    
    R_T = R.T
    # Matrix multiplication: V @ (R_T @ u)
    u_aligned = V @ (R_T @ u)
    return u_aligned
```

**Parameters**
- **Number of vanishing points**: 3, forming an orthonormal basis $V$ [S1].
- **Frequency levels**: Should be a multiple of the number of vanishing points. In experiments, 255 levels (FE255 + VP) were used [S1].

**Edge Cases and Pitfalls**
- **Numerical Stability**: The ERP formula involves `tan` and `arctan`. Care must be taken with angles near $\pi/2$ or $-\pi/2$ where tangent is undefined. The source provides the formula directly, but implementers should handle potential numerical instability [S1].
- **Manhattan World Assumption**: The 3D NeRF method relies on the Manhattan world assumption to estimate 3 orthogonal vanishing points. If the scene does not adhere to this, the orthonormal basis $V$ may not accurately represent the scene structure [S1].

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Not given in the sources.
- **Measured Performance**: The method improves reconstruction quality of axis-aligned structures, especially for MIP-NeRF 360 [S1]. In experiments on the LLFF dataset, it showed competitive results compared to other sparse input NeRF methods [S1].
- **Strengths**: Aligns encoding with scene geometry, improving reconstruction of axis-aligned structures [S1].
- **Limitations**: Relies on accurate vanishing point estimation and the Manhattan world assumption for 3D NeRF [S1].
- **When to use**: When dealing with scenes that have strong axis-aligned structures and sparse input, particularly when using frequency-based encoding schemes like MIP-NeRF 360 [S1].
- **When not to use**: When the scene does not adhere to the Manhattan world assumption or when vanishing points are difficult to estimate accurately [S1].

- **Usage**: Used in neural radiance fields (NeRF) for sparse input scenarios, particularly for perspective and ERP image regression tasks [S1].
