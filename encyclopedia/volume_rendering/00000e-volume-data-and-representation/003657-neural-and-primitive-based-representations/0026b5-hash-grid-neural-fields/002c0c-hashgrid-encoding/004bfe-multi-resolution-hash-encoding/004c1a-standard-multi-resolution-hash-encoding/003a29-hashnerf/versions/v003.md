# HashNeRF

Also called: Instant Neural Graphics Primitives, Instant Neural Graphics Primitives with a Multiresolution Hash Encoding

## Overview
HashNeRF is a method for representing 3D scenes as Neural Radiance Fields (NeRF) that utilizes a multiresolution hash encoding to map spatial coordinates to a high-dimensional feature space, followed by a shallow multi-layer perceptron (MLP) to decode density and color [S1, unofficial]. It solves the problem of slow training and high memory consumption associated with traditional NeRF models by replacing expensive positional encoding with a trainable, compact hash grid representation [S1, unofficial]. Unlike its siblings, it achieves faster convergence and reduced training times by using a generic, trainable encoding that works with various neural graphics primitives, while maintaining high rendering quality through multi-resolution detail [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D spatial coordinates $\mathbf{x} = (x, y, z)$ and viewing direction $\mathbf{d}$.
*   **Output:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$.

**Data Structures:**
The method relies on a set of $L$ hash tables (grids), one for each resolution level $l \in \{0, \dots, L-1\}$.
*   Each hash table $H_l$ maps input coordinates to feature vectors.
*   The hash table has a fixed size $T_l$ (number of entries).
*   Each entry stores a learnable feature vector of dimension $F$.
*   The hash function $h_l(\mathbf{x})$ maps the coordinate to an index in $H_l$.

**Numbered Steps:**
1.  **Multi-resolution Hash Encoding:** For each resolution level $l$, compute the hash index $i_l = h_l(\mathbf{x})$. Retrieve the feature vector $\mathbf{f}_l = H_l[i_l]$.
2.  **Linear Interpolation:** To ensure smoothness, perform trilinear interpolation of the features from the 8 neighboring voxels in the hash grid at each resolution level. This produces a smoothed feature vector $\mathbf{v}_l$ for each level $l$.
3.  **Feature Concatenation:** Concatenate the interpolated feature vectors from all resolution levels: $\mathbf{v} = [\mathbf{v}_0; \mathbf{v}_1; \dots; \mathbf{v}_{L-1}]$.
4.  **Density MLP:** Pass the concatenated feature vector $\mathbf{v}$ through a shallow MLP (Density MLP) to output the log-space density $\sigma$. The output is typically passed through an exponential function to ensure positivity: $\sigma = \exp(\text{MLP}_{\sigma}(\mathbf{v}))$.
5.  **Color MLP:** Pass the concatenated feature vector $\mathbf{v}$ and the viewing direction $\mathbf{d}$ (optionally encoded) through another shallow MLP (Color MLP) to output the view-dependent color $\mathbf{c} = \text{MLP}_{\mathbf{c}}(\mathbf{v}, \mathbf{d})$.
6.  **Volume Rendering:** Use the density $\sigma$ and color $\mathbf{c}$ in a standard volume rendering pipeline to synthesize the final image pixel color.

**Formulas:**
*   Hash Index: $i_l = h_l(\mathbf{x}) \pmod{T_l}$
*   Interpolated Feature: $\mathbf{v}_l = \text{TrilinearInterpolate}(H_l, \mathbf{x})$
*   Concatenated Feature: $\mathbf{v} = \bigoplus_{l=0}^{L-1} \mathbf{v}_l$
*   Density: $\sigma = \exp(\text{MLP}_{\sigma}(\mathbf{v}))$
*   Color: $\mathbf{c} = \text{MLP}_{\mathbf{c}}(\mathbf{v}, \mathbf{d})$

**Parameters:**
*   **Hardware:** NVIDIA GeForce RTX 3090 Ti GPUs [S1, unofficial].
*   **Training Iterations:** Evaluated at 500 and 1,000 iterations [S1, unofficial].
*   **Dataset:** 100 training, 100 validation, 200 test images (RGB + depth) [S1, unofficial].
*   **Network Depth:** Shallow MLPs (number of layers not explicitly specified in sources, but described as "shallow" with "fewer parameters") [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Hash Collisions:** Multiple coordinates may map to the same hash index. The method relies on the multi-resolution structure and training to mitigate artifacts from collisions [S1, unofficial].
*   **Vanishing Gradients:** The architecture includes residual connections between pipelines to ensure communication and avoid vanishing gradients [S1, unofficial].

## Subtopics

### [HashNeRF Architectural Variants](8688-hashnerf-architectural-variants.md)
This variant explores modifications to the standard HashNeRF color and density networks, specifically evaluating the impact of residual connections, convolutional layers, and network depth on reconstruction quality and training time. It addresses the limitations of the standard shallow MLP decoder by altering the internal connectivity and layer types of the feature-decoding stage, such as introducing convolutional and dilated convolutional layers into the color generation pipeline to provide context from surrounding pixels.

### HollowNeRF
HollowNeRF is a compression method that automatically sparsifies the feature grid during training using a trainable 3D saliency mask to guide efficient feature pruning, redistributing hash collisions to improve rendering quality with fewer parameters [S2]. It uses 31% of the parameters of Instant-NGP while delivering comparable rendering quality, and achieves up to 1dB PSNR accuracy gain using only 56% of the parameters [S2]. The method involves:
1.  Fetching feature $f$ from the multi-level hashgrid for input coordinate $x=(x,y,z)$ [S2].
2.  Predicting saliency weight $p$ by processing information from a trainable 3D saliency grid $G$ (resolution $T \times T \times T$) through trilinear interpolation and a sigmoid function [S2].
3.  Scaling feature $f$ by $p$ to get weighted feature $v = pf$ [S2].
4.  Feeding $v$ into an MLP to decode density $\sigma$ and color [S2].
5.  Using a zero-skipping gate to ensure $v=0$ maps to $\sigma=0$ [S2].
6.  Using an ADMM pruner to sparsify the saliency value distribution by enforcing a sparsity constraint when optimizing the loss $L$ [S2].

## Operating characteristics
*   **Time Complexity:** HashNeRF trains faster and converges in fewer iterations than NeRF because the encoding is generic, trainable, and the network is shallow with fewer parameters [S1, unofficial].
*   **Memory Complexity:** The multiresolution hash encoding reduces memory usage during training by parameterizing the compressed representation of grids as MLPs, which requires storing intermediate activations and optimizer statistics [Parent].
*   **Measured Performance:** Evaluated on NVIDIA GeForce RTX 3090 Ti GPUs with 500 and 1,000 training iterations on a dataset of 100 training, 100 validation, and 200 test images (RGB + depth) [S1, unofficial].
*   **Strengths:** Faster training, fewer iterations to converge, generic applicability to various neural graphics primitives, reduced memory footprint compared to dense grids [S1, unofficial].
*   **Limitations:** Potential for hash collisions, reliance on shallow MLPs which may limit representational capacity for very complex scenes compared to deeper networks [S1, unofficial].
*   **When to Use:** When fast training and low memory usage are critical, and high-quality novel view synthesis is required [S1, unofficial].
*   **When Not to Use:** When extremely high fidelity is required and training time is not a constraint, or when the scene complexity exceeds the capacity of the shallow MLP and hash encoding [S1, unofficial].

## Background
HashNeRF, also known as Instant Neural Graphics Primitives with a Multiresolution Hash Encoding, was proposed by Thomas Müller, Alex Evans, Christoph Schied, and Alexander Keller in 2022 [S1, unofficial]. It builds on the NeRF framework [S1, unofficial] and aims to reduce training times for NeRF models. The method has applications in gigapixel approximation, generating signed distance functions, and Neural Radiance Caching [S1, unofficial].
