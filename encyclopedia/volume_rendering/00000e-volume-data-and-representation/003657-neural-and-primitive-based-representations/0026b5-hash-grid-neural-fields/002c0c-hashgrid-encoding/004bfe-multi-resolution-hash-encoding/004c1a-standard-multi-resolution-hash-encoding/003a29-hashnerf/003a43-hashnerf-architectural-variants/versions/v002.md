# HashNeRF Architectural Variants

Also called: HashNeRF Network Architecture Variants

## Overview
This article details four architectural modifications to the HashNeRF color and density networks, evaluating residual connections, convolutional layers, and network depth on reconstruction quality and training time [S1, unofficial]. These variants modify the standard shallow multi-layer perceptron (MLP) decoder by altering internal connectivity and layer types [S1, unofficial].

## How it works
The base HashNeRF method [8678-hashnerf.md] maps spatial coordinates to a high-dimensional feature vector using multi-resolution hash encoding, which is then processed by a shallow MLP [S1, unofficial]. The variants below modify this MLP structure [S1, unofficial]. All variants use the Mean Squared Error (MSE) loss over rendered rays [S1, unofficial]. The variants are evaluated under matched iteration budgets (1,000 iterations) on synthetic scenes (e.g., Lego) with reduced view counts (100 training views) [S1, unofficial].

### Variant 1: Convolutional Layers
This variant replaces the standard linear layers with 1D convolutional layers to reduce trainable parameters [S1, unofficial].

**Pipeline 1 (Density/Feature Network):**
1. Input: Feature vector of size 48.
2. Apply `Conv1d(48, 32, kernel_size=3)` [S1, unofficial].
3. Apply `Conv1d(32, 16, kernel_size=3)` [S1, unofficial].
4. Apply `Conv1d(16, 8, kernel_size=3)` [S1, unofficial].
5. Apply `Conv1d(8, 4, kernel_size=3)` [S1, unofficial].

**Performance:** PSNR 15.831, Training Time 363.415 [S1, unofficial].

### Variant 2: Residual Connections from Initial Input
This variant adds residual connections from the initial input to each subsequent layer in the sigma and color MLPs to preserve spatial information from the first layer [S1, unofficial].

**Pipeline 1 (Sigma/Feature Network):**
1. Input: Feature vector of size 32.
2. Apply `Linear(32, 64, bias=False)` [S1, unofficial].
3. Apply `ReLU` [S1, unofficial].
4. Concatenate original input views with the output of step 3, resulting in size 79 [S1, unofficial].
5. Apply `Linear(79, 16, bias=False)` [S1, unofficial].
6. Apply `ReLU` [S1, unofficial].
7. Concatenate original input views with the output of step 6 [S1, unofficial].

**Pipeline 2 (Color Network):**
1. Input: Feature vector of size 31.
2. Apply `Linear(31, 64, bias=False)` [S1, unofficial].
3. Apply `ReLU` [S1, unofficial].
4. Concatenate original input views with the output of step 3 [S1, unofficial].
5. Apply `Linear(79, 64, bias=False)` [S1, unofficial].
6. Apply `ReLU` [S1, unofficial].
7. Concatenate original input views with the output of step 6 [S1, unofficial].
8. Apply `Linear(79, 3, bias=False)` to produce RGB color [S1, unofficial].

**Performance:** PSNR 25.873, Training Time 306.751 [S1, unofficial].

### Variant 3: Residual Connections from Alternate Layers
This variant adds residual connections from two layers prior to the current layer to preserve information from previous layers while tuning parameters [S1, unofficial].

**Pipeline 1 (Sigma/Feature Network):**
1. Input: Feature vector of size 32.
2. Apply `Linear(32, 64, bias=False)` [S1, unofficial].
3. Apply `ReLU` [S1, unofficial].
4. Apply `Linear(79, 16, bias=False)` [S1, unofficial].
5. Apply `ReLU` [S1, unofficial].
6. Concatenate input views with the output of step 5 [S1, unofficial].

**Pipeline 2 (Color Network):**
1. Input: Feature vector of size 31.
2. Apply `Linear(31, 64, bias=False)` [S1, unofficial].
3. Apply `ReLU` [S1, unofficial].
4. Concatenate output of step 3 with output of step 1 [S1, unofficial].
5. Apply `Linear(79, 64, bias=False)` [S1, unofficial].
6. Apply `ReLU` [S1, unofficial].
7. Concatenate output of step 6 with output of step 4 [S1, unofficial].
8. Apply `Linear(79, 3, bias=False)` to produce RGB color [S1, unofficial].

**Performance:** PSNR 26.547, Training Time 305.208 [S1, unofficial].

### Variant 4: Deeper Network with Residuals
This variant increases network depth by adding three linear layers and residual connections from the sigma layers to improve color output precision [S1, unofficial].

**Pipeline 1 (Sigma/Feature Network):**
1. Input: Feature vector of size 32.
2. Apply `Linear(32, 64, bias=False)` [S1, unofficial].
3. Apply `ReLU` [S1, unofficial].
4. Apply `Linear(64, 16, bias=False)` [S1, unofficial].
5. Concatenate input views with the output of step 4 [S1, unofficial].

**Pipeline 2 (Color Network):**
1. Input: Feature vector of size 20 (result of previous concatenation).
2. Apply `Linear(20, 64, bias=False)` [S1, unofficial].
3. Apply `ReLU` [S1, unofficial].
4. Apply `Linear(64, 64, bias=False)` [S1, unofficial].
5. Concatenate input views with the output of step 4 [S1, unofficial].
6. Apply `Linear(50, 128, bias=False)` [S1, unofficial].
7. Apply `ReLU` [S1, unofficial].
8. Apply `Linear(128, 64, bias=False)` [S1, unofficial].
9. Apply `ReLU` [S1, unofficial].
10. Apply `Linear(64, 3, bias=False)` to produce RGB color [S1, unofficial].

**Performance:** PSNR 27.119, Training Time 319.669 [S1, unofficial].

## Subtopics

### HashNeRF Variant 2
A specific configuration of the residual connection strategy where the network explicitly concatenates the original input views to intermediate layer outputs in a two-pipeline structure for sigma and color networks [S1, unofficial]. It achieves a PSNR of 25.873 with a training time of 306.751 [S1, unofficial].

### HashNeRF Variant 1
A configuration replacing linear layers with 1D convolutions (kernel size 3) to reduce parameters [S1, unofficial]. It consists of a single pipeline with four convolutional layers [S1, unofficial]. It yields the lowest PSNR (15.831) among the variants but has a longer training time (363.415) [S1, unofficial].

### HashNeRF Variant 3
A configuration using residual connections from alternate layers (2 layers prior) in a two-pipeline structure [S1, unofficial]. It aims to balance information preservation and parameter tuning [S1, unofficial]. It achieves a PSNR of 26.547 with a training time of 305.208 [S1, unofficial].

### HashNeRF Variant 4
A deeper configuration adding 3 linear layers and residual connections from sigma layers [S1, unofficial]. It achieves the highest PSNR (27.119) among the variants with a training time of 319.669 [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training times range from 305.208 to 363.415 for 1,000 iterations [S1, unofficial]. Variant 1 is the slowest; Variants 2 and 3 are the fastest.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** PSNR ranges from 15.831 (Variant 1) to 27.119 (Variant 4) on the Lego scene with 100 training views [S1, unofficial].
*   **Strengths:** Variants 2-4 offer improved PSNR over the baseline or Variant 1 by better preserving input information or increasing capacity [S1, unofficial].
*   **Limitations:** None of the extensions conclusively outperform published baselines under iso-time evaluation [S1, unofficial]. Variant 1 performs poorly [S1, unofficial].
*   **When to use:** Use Variant 4 for highest quality under constrained iterations. Use Variant 2 or 3 for faster convergence. Avoid Variant 1 unless parameter reduction is critical and quality is secondary [S1, unofficial].

## Background
These variants were proposed in a study evaluating low-cost Neural Radiance Fields, specifically ablation studies on the feature-decoding MLP of HashNeRF [S1, unofficial]. The work was conducted to understand the effect of input downsampling and architectural changes on PSNR and runtime under reduced view counts (100 training views) [S1, unofficial]. The experiments were performed on the synthetic Lego scene from the NeRF dataset [S1, unofficial].
