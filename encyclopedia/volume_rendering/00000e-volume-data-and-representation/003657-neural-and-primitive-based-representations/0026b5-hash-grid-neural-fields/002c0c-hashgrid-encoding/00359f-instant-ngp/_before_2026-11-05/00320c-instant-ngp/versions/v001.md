# Instant-NGP
Also called: Instant Neural Graphics Primitives, Instant-NGP Implementation, VFR Implementation Details

## Overview
Instant-NGP is a method for fast neural radiance field (NeRF) reconstruction that utilizes a multiresolution hash grid encoding to map spatial coordinates to feature vectors, which are then processed by small multi-layer perceptrons (MLPs) to predict density and color [S1][S2, unofficial]. It distinguishes itself from standard NeRF by replacing the large, static voxel grid or pure MLP with a learnable, sparse hash table structure, enabling training on consumer GPUs in minutes rather than hours [S2, unofficial]. While it builds on [HashGrid Encoding](3866-hashgrid-encoding.md), Instant-NGP specifically defines the network architecture, density mapping, and sampling strategies required to achieve real-time rendering capabilities [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Camera ray parameters (origin, direction), training images, and camera poses.
*   **Output:** Rendered color and alpha values for each pixel.

**Data Structures:**
1.  **Multiresolution Hash Grid (MHG):**
    *   Stores learnable feature vectors.
    *   Organized into multiple resolution levels (layers).
    *   Each layer has a fixed number of feature channels.
    *   Voxels at each resolution are hashed to a one-dimensional table if the number of voxels exceeds $2^{19}$ [S1].
    *   The number of levels and total parameters vary by dataset (see Operating characteristics) [S1].
2.  **Neural Network (MLPs):**
    *   **Spatial MLP:** 2 layers, 256 hidden neurons per layer [S1].
    *   **Directional MLP:** 4 layers, 256 hidden neurons per layer [S1].
    *   **Bottleneck Feature Size:** 256 dimensions [S1].
    *   **Activation Function:** GELU (chosen over ReLU for slightly better quality) [S1].
3.  **Density Mapping Layer:**
    *   Maps the queried feature vector $F(x_i)$ to density $\sigma$ [S1].
    *   **Real-world 360 dataset:** Linear transform from feature vector to density [S1].
    *   **NeRF synthetic dataset:** Tiny network with one hidden layer and 64 neurons [S1].
4.  **Sampling Structures:**
    *   **NeRF Synthetic:** Occupancy grid for efficient sampling [S1].
    *   **Real-world 360:** Two levels of importance sampling (following Zip-NeRF), each with 64 samples [S1].

**Algorithm Steps:**
1.  **Feature Query:** For a sample point $x_i$ along a ray, query the MHG to retrieve the feature vector $F(x_i)$. This involves hashing the coordinate to the appropriate resolution levels and aggregating features via trilinear interpolation [S1][S2, unofficial].
2.  **Density Prediction:** Pass $F(x_i)$ through the density mapping layer to obtain the volume density $\sigma(x_i)$ [S1].
3.  **Color Prediction:** Concatenate $F(x_i)$ with the view direction vector. Pass this concatenated vector through the Spatial MLP and Directional MLP to predict the view-dependent color $c(x_i)$ [S1].
4.  **Hierarchical Importance Sampling:**
    *   Generate sample points along the ray using the sampling strategy appropriate for the dataset (Occupancy grid for synthetic; two-level importance sampling for 360) [S1].
    *   The number of final samplings on the radiance field is 32 [S1].
5.  **Volume Rendering:** Composite the color and density values along the ray using standard volume rendering integration to produce the final pixel color [S1].

**Pseudocode:**
```python
def instant_ngp_forward(ray_origin, ray_direction, mhg, spatial_mlp, directional_mlp, density_mapper, sampling_strategy):
    # 1. Sample points along the ray based on dataset-specific strategy
    if sampling_strategy == "occupancy_grid":
        # Use occupancy grid for NeRF synthetic dataset
        sample_points = sample_from_occupancy_grid(ray_origin, ray_direction)
    elif sampling_strategy == "hierarchical_importance":
        # Use two levels of importance sampling for real-world 360 dataset
        sample_points = sample_hierarchical_importance(ray_origin, ray_direction, num_samples=64)
    
    # 2. Query features and predict density/color for each sample
    colors = []
    densities = []
    
    for point in sample_points:
        # Query MHG for feature vector F(point)
        # MHG hashes point to 1D table if voxel count > 2^19
        feature_vector = mhg.query(point)
        
        # Predict density
        density = density_mapper(feature_vector)
        densities.append(density)
        
        # Predict color
        # Concatenate feature vector with view direction
        view_direction = normalize(ray_direction)
        concat_input = concatenate(feature_vector, view_direction)
        
        # Pass through Spatial MLP (2 layers, 256 hidden, GELU)
        spatial_features = spatial_mlp(concat_input)
        
        # Pass through Directional MLP (4 layers, 256 hidden, GELU)
        color = directional_mlp(spatial_features)
        colors.append(color)
        
    # 3. Volume Rendering
    # Standard alpha compositing using densities and colors
    final_color = volume_render(sample_points, densities, colors)
    
    return final_color
```

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** 0.01 [S1].
*   **Scheduler:** Default in NerfAcc [S1].
*   **Feature Channels per Layer:** 2 [S1].

## Operating characteristics
*   **Training Time:** Significantly faster than standard NeRF, enabling training on consumer GPUs (e.g., RTX 3090) in minutes [S1][S2, unofficial].
*   **Model Size:** Reduced by using a hash table and multi-resolution encoding [S2, unofficial].
    *   **NeRF Synthetic:** 13M parameters, 18 levels [S1].
    *   **Real-world 360:** 34M parameters, 16 levels [S1].
*   **Performance:** Achieves best rendering quality with minimum training time compared to state-of-the-art fast methods on the NeRF synthetic dataset [S1].
*   **Strengths:** Fast training, real-time rendering capability, efficient memory usage via sparse hashing [S1][S2, unofficial].
*   **Limitations:** Quality may vary slightly depending on the density mapping layer choice (linear vs. tiny network) [S1]. Performance depends on the hash table size and collision handling [S1].
*   **When to use:** When fast training and real-time rendering are prioritized over absolute maximum quality or when hardware resources are limited [S1][S2, unofficial].
*   **When not to use:** When maximum possible image quality is required regardless of training time, or when dealing with scenes that do not benefit from the specific sampling strategies (e.g., highly dynamic scenes not covered by the occupancy grid) [S1].

## Background
Instant-NGP was introduced in the paper "Instant Neural Graphics Primitives with a Multiresolution Hash Encoding" at SIGGRAPH 2022 [S2, unofficial]. It was developed to address the slow training times of traditional NeRF methods by leveraging a multiresolution hash grid encoding [S2, unofficial]. The method has been implemented in libraries such as NerfAcc, which is based on PyTorch [S1]. It is widely used for fast neural radiance field reconstruction in both synthetic and real-world datasets [S1].
