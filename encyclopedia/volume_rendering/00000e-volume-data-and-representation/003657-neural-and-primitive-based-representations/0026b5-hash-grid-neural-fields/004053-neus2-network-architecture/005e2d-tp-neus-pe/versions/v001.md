# TP-NeuS + PE

Also called: TP-NeuS with Positional Encoding

## Overview
TP-NeuS + PE is a neural surface reconstruction method that augments the Tri-Plane NeuS baseline with positional encoding to improve frequency representation. It solves the issue of high-frequency detail loss in standard MLP-based SDF regression by explicitly injecting high-frequency positional information alongside learned tri-plane features. It differs from the baseline [NeuS2 Network Architecture](10215-neus2-network-architecture.md) by adding a fixed-frequency encoding step before the MLP, and from the full PET-NeuS architecture by lacking the modulation (MPE) and self-attention convolution (SAC) components.

## How it works
**Inputs and Outputs:**
*   Input: 3D point coordinates $\mathbf{x} = (x, y, z)$.
*   Output: Signed Distance Function (SDF) value $S(\mathbf{x})$ and volume density $\sigma(\mathbf{x})$ (inherited from the parent NeuS2 architecture's output contract).

**Data Structures:**
*   **Tri-Plane Features ($T$):** A set of learnable feature planes. For a point $\mathbf{x}$, features are sampled from the three orthogonal projections (XY, YZ, XZ) and concatenated. Let $T(\mathbf{x})$ denote this concatenated feature vector.
*   **Positional Encoding ($PE$):** A fixed function mapping coordinates to a higher-dimensional space using sinusoidal functions.

**Method Steps:**
1.  **Tri-Plane Sampling:** Compute the feature vector $T(\mathbf{x})$ by projecting $\mathbf{x}$ onto the three tri-planes and interpolating the learned features.
2.  **Positional Encoding:** Compute the positional encoding vector $PE(\mathbf{x})$. The source defines the input to the MLP as the concatenation of $PE(\mathbf{x})$ and $T(\mathbf{x})$.
3.  **MLP Regression:** Pass the concatenated vector through a Multi-Layer Perceptron (MLP) to predict the SDF.

**Formula:**
The SDF is defined as:
$$ S(\mathbf{x}) = \text{MLP}([PE(\mathbf{x}), T(\mathbf{x})]) $$
where $[\cdot, \cdot]$ denotes concatenation.

**Parameters:**
*   The specific frequency range or number of bands for $PE$ is not explicitly defined in the provided notes, though standard NeuS implementations typically use frequencies up to 10 or 15. Not given in the sources.
*   MLP architecture (layer sizes, activation functions) is inherited from the parent [NeuS2 Network Architecture](10215-neus2-network-architecture.md).

**Pseudocode:**
```python
def tp_neus_plus_pe(xyz, tri_plane_features, mlp):
    """
    Predicts SDF using Tri-Plane features and Positional Encoding.
    
    Args:
        xyz: Tensor of shape (N, 3) containing 3D coordinates.
        tri_plane_features: Learnable parameters for the tri-planes.
        mlp: The neural network module for regression.
        
    Returns:
        sdf: Tensor of shape (N,) containing predicted SDF values.
    """
    # 1. Sample features from tri-planes
    # This step is inherited from the parent architecture's tri-plane sampling logic.
    # It involves projecting xyz onto XY, YZ, XZ planes and interpolating.
    t_features = sample_tri_plane_features(xyz, tri_plane_features)
    
    # 2. Compute Positional Encoding
    # Standard PE uses sinusoidal functions at different frequencies.
    # The exact frequency bounds are not specified in the source notes.
    pe_features = positional_encoding(xyz)
    
    # 3. Concatenate features
    combined_features = concatenate([pe_features, t_features], dim=-1)
    
    # 4. Pass through MLP
    sdf = mlp(combined_features)
    
    return sdf
```

**Edge Cases and Pitfalls:**
*   **Discretization Discontinuities:** The source notes that using only TP-NeuS + PE results in large geometric error due to discretization discontinuities. This is a known limitation of this specific variant.
*   **Noise Interference:** Without modulation (MPE), the positional encoding may introduce noise interference that the MLP struggles to filter, leading to suboptimal reconstruction quality compared to the full PET-NeuS.

## Subtopics

### PET-NeuS (Full)
The full proposed architecture combining TP-NeuS, PE, MPE, and SAC. It extends the baseline by modulating tri-plane features with positional encoding (MPE) and using self-attention convolution (SAC) to match positional encoding frequencies and smooth noise. It is superior to the baseline and the multi-scale tri-plane (MSA) variant. [PET-NeuS](10216-pet-neus-full.md)

## Operating characteristics
*   **Time Complexity:** Determined by the tri-plane sampling and MLP inference. Not given in the sources.
*   **Memory Complexity:** Determined by the tri-plane feature storage and MLP weights. Not given in the sources.
*   **Performance:** On the DTU dataset, the "TP-NeuS + PE" variant results in a large geometric error compared to the full PET-NeuS. It is considered a baseline rather than the final optimal solution.
*   **Strengths:** Simpler than the full PET-NeuS; explicitly handles high frequencies via PE.
*   **Limitations:** Suffers from discretization discontinuities and noise interference due to the lack of MPE and SAC.
*   **When to use:** As a baseline for ablation studies or when computational resources are limited and the full PET-NeuS is too expensive.
*   **When not to use:** When high geometric accuracy is required, as it underperforms the full PET-NeuS.

## Background
The method was introduced in the paper "PET-NeuS: Positional Encoding Tri-Planes for Neural Surfaces" by the authors of the PET-NeS framework. It serves as an intermediate step in the ablation study of the full PET-NeS architecture, demonstrating the necessity of modulation and self-attention convolution beyond simple positional encoding injection.
