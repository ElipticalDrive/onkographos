# TP-NeuS + PE

Also called: TP-NeuS with Positional Encoding

## Overview
TP-NeuS + PE is a neural surface reconstruction method that augments the Tri-Plane NeuS baseline with positional encoding to improve frequency representation [S1]. It solves the issue of high-frequency detail loss in standard MLP-based SDF regression by explicitly injecting high-frequency positional information alongside learned tri-plane features [S1]. It differs from the baseline [NeuS2 Network Architecture](10215-neus2-network-architecture.md) by adding a fixed-frequency encoding step before the MLP, and from the full PET-NeuS architecture by lacking the modulation (MPE) and self-attention convolution (SAC) components [S1].

## How it works
**Inputs and Outputs:**
*   Input: 3D point coordinates $\mathbf{x} = (x, y, z)$ [S1].
*   Output: Signed Distance Function (SDF) value $S(\mathbf{x})$ [S1].

**Data Structures:**
*   **Tri-Plane Features ($T$):** A set of learnable feature planes sampled from three orthogonal projections (XY, YZ, XZ) and concatenated [S1].
*   **Positional Encoding ($PE$):** A fixed function mapping coordinates to a higher-dimensional space using sinusoidal functions [G].

**Method Steps:**
1.  **Tri-Plane Sampling:** Compute the feature vector $T(\mathbf{x})$ by projecting $\mathbf{x}$ onto the three tri-planes and interpolating the learned features [G].
2.  **Positional Encoding:** Compute the positional encoding vector $PE(\mathbf{x})$ [G].
3.  **MLP Regression:** Pass the concatenated vector through a Multi-Layer Perceptron (MLP) to predict the SDF [S1].

**Formula:**
The SDF is defined as:
$$ S(\mathbf{x}) = \text{MLP}([PE(\mathbf{x}), T(\mathbf{x})]) $$
where $[\cdot, \cdot]$ denotes concatenation [S1].

**Parameters:**
*   The specific frequency range or number of bands for $PE$ is not explicitly defined in the provided notes [S1].
*   MLP architecture (layer sizes, activation functions) is inherited from the parent [NeuS2 Network Architecture](10215-neus2-network-architecture.md) [S1].

**Pseudocode:**
```python
def tp_neus_plus_pe(xyz, tri_plane_features, mlp):
    # 1. Sample tri-plane features T(x) by projecting xyz onto XY, YZ, XZ planes and interpolating [G]
    t_features = sample_tri_plane_features(xyz, tri_plane_features)
    # 2. Compute positional encoding PE(x) using sinusoidal functions [G]
    pe_features = positional_encoding(xyz)
    # 3. Concatenate PE and T features
    combined = concatenate_along_last_dim(pe_features, t_features)
    # 4. Predict SDF via MLP
    sdf = mlp(combined)
    return sdf

def sample_tri_plane_features(xyz, planes):
    # Project xyz onto XY, YZ, XZ planes and bilinearly interpolate features [G]
    xy_feat = bilinear_interpolate(planes['xy'], xyz[:, 0], xyz[:, 1])
    yz_feat = bilinear_interpolate(planes['yz'], xyz[:, 1], xyz[:, 2])
    xz_feat = bilinear_interpolate(planes['xz'], xyz[:, 0], xyz[:, 2])
    return concatenate_along_last_dim(xy_feat, yz_feat, xz_feat)

def positional_encoding(xyz, num_frequencies=10):
    # Standard sinusoidal positional encoding [G]
    encoded = []
    for i in range(num_frequencies):
        scale = 2.0 ** i
        encoded.append(scale * xyz)
    # Concatenate sin and cos of scaled coordinates
    sin_vals = [math.sin(v) for v in encoded]
    cos_vals = [math.cos(v) for v in encoded]
    return concatenate_along_last_dim(sin_vals, cos_vals)

def concatenate_along_last_dim(*tensors):
    # Standard tensor concatenation along the last dimension [G]
    return concatenate(tensors, axis=-1)
```

**Edge Cases and Pitfalls:**
*   **Discretization Discontinuities:** Using only TP-NeuS + PE results in large geometric error due to discretization discontinuities [S1].
*   **Noise Interference:** Without modulation (MPE), the positional encoding may introduce noise interference that the MLP struggles to filter, leading to suboptimal reconstruction quality compared to the full PET-NeuS [S1].

## Subtopics

### PET-NeuS (Full)
The full proposed architecture combining TP-NeuS, PE, MPE, and SAC [S1]. It extends the baseline by modulating tri-plane features with positional encoding (MPE) and using self-attention convolution (SAC) to match positional encoding frequencies and smooth noise [S1]. It is superior to the baseline and the multi-scale tri-plane (MSA) variant [S1]. [PET-NeuS](10216-pet-neus-full.md)

## Operating characteristics
*   **Time Complexity:** Determined by the tri-plane sampling and MLP inference. Not given in the sources [S1].
*   **Memory Complexity:** Determined by the tri-plane feature storage and MLP weights. Not given in the sources [S1].
*   **Performance:** On the DTU dataset, the "TP-NeuS + PE" variant results in a large geometric error compared to the full PET-NeuS [S1].
*   **Strengths:** Simpler than the full PET-NeuS; explicitly handles high frequencies via PE [S1].
*   **Limitations:** Suffers from discretization discontinuities and noise interference due to the lack of MPE and SAC [S1].
*   **When to use:** As a baseline for ablation studies [S1].
*   **When not to use:** When high geometric accuracy is required, as it underperforms the full PET-NeuS [S1].

## Background
The method was introduced in the paper PET-NeuS: Positional Encoding Tri-Planes for Neural Surfaces [S1]. It serves as an intermediate step in the ablation study of the full PET-NeuS architecture, demonstrating the necessity of modulation and self-attention convolution beyond simple positional encoding injection [S1].
