# Forplane

Also called: Factorized Implicit Representation, Fast Orthogonal Plane Representation, Orthogonal Neural Plane

## Overview
Forplane is a method for reconstructing deformable 4D scenes (3D space + time) from monocular or binocular video by factorizing the volume into a static 3D field and a dynamic 3D field, both represented by 2D neural planes [S1]. It solves the problem of efficient reconstruction of deformable tissues in surgical scenes, where tool occlusion and complex deformations make standard 3D NeRF approaches slow and inaccurate [S1]. Unlike sibling methods that treat time as an independent static volume per step or use displacement fields, Forplane uses orthogonal space-time planes to reduce computational complexity from $O(N^4)$ to $O(N^2)$ while maintaining high reconstruction quality [S1].

## How it works
**Inputs:** A sequence of endoscopic video frames (images) with known camera poses and timestamps.
**Outputs:** A continuous 4D scene function $F_\Theta(\mathbf{x}, \tau)$ that predicts density $\sigma$ and color $\mathbf{c}$ for any spatial coordinate $\mathbf{x}=(x,y,z)$ and time $\tau$.

**Data Structures:**
The representation consists of two sets of feature planes:
1.  **Static Field ($V_s^{3d}$):** Composed of three orthogonal space planes: $G_{XY}, G_{YZ}, G_{XZ}$.
    *   Layout: Each plane is a 2D grid of size $N \times N \times D$.
    *   $N$: Spatial resolution.
    *   $D$: Feature size (dimensionality of the feature vector).
2.  **Dynamic Field ($V_d^{3d}$):** Composed of three orthogonal space-time planes: $G_{TX}, G_{TY}, G_{TZ}$.
    *   Layout: Each plane is a 2D grid of size $N \times M \times D$.
    *   $N$: Spatial resolution.
    *   $M$: Temporal resolution.
    *   $D$: Feature size.
3.  **MLP ($\theta$):** A lightweight multi-layer perceptron.
    *   Architecture: 2 fully connected layers.
    *   Channels: 64 channels per layer.

**Algorithm Steps:**

1.  **Spatiotemporal Importance Sampling:**
    Prior to rendering, identify high-priority tissue pixels. This step addresses tool occlusion (infrequent representation) and stationary tissues (redundant training) by assigning higher sampling probabilities to occluded or highly dynamic pixels [S1].

2.  **Ray Casting:**
    For a target tissue pixel $p_{ij}$ at time step $\tau$, cast a ray $\mathbf{r}(t)$ from the camera origin $\mathbf{x}_o$ through the pixel [S1].

3.  **Spatial-Temporal Sampling:**
    Sample points along the ray to obtain 4D coordinates $(x, y, z, \tau)$ [S1]. The sampling is performed near the tissue surface using an efficient ray marching algorithm [S1].

4.  **Feature Querying (Factorized Representation):**
    For each sampled point $\mathbf{p} = (x, y, z, \tau)$, query features from the six planes using bilinear interpolation $\mathcal{B}$. The features are combined via element-wise multiplication ($\odot$) [S1].
    
    The fused feature vector $\mathbf{v}$ is computed as:
    $$
    \mathbf{v}(x, y, z, \tau) = \mathcal{B}(G_{XY}, x, y) \odot \mathcal{B}(G_{YZ}, y, z) \odot \mathcal{B}(G_{XZ}, x, z) \odot \mathcal{B}(G_{TX}, \tau, x) \odot \mathcal{B}(G_{TY}, \tau, y) \odot \mathcal{B}(G_{TZ}, \tau, z)
    $$
    *(Note: The source formula [S1] explicitly lists $G_{XY}, G_{YZ}$ and $G_{YT}, G_{ZT}$, but the text defines the dynamic planes as $G_{TX}, G_{TY}, G_{TZ}$. The standard orthogonal decomposition for 4D $(x,y,z,t)$ requires pairing each spatial dimension with the time dimension or other spatial dimensions. Based on the definition of $V_d^{3d}$ using $G_{TX}, G_{TY}, G_{TZ}$, the query must include these. The static planes cover $xy, yz, xz$. The dynamic planes cover $tx, ty, tz$. The formula below reflects the complete set of 6 planes defined in the text.)*

5.  **Prediction:**
    Concatenate the fused feature vector $\mathbf{v}$ with positional encoded coordinates and time embeddings. Pass this concatenated vector through the lightweight MLP $\theta$ to predict density $\sigma$ and color $\mathbf{c}$ [S1].

6.  **Volume Rendering:**
    Compute the predicted color $\hat{C}(\mathbf{r})$ for the ray $\mathbf{r}$ using standard volume rendering integration:
    $$
    \hat{C}(\mathbf{r}) = \int_{t_n}^{t_f} w(t) \mathbf{c}(\mathbf{r}(t), \mathbf{d}) \, dt
    $$
    where $w(t)$ is the accumulated weight, $t_n$ and $t_f$ are the near and far clipping planes, and $\mathbf{d}$ is the viewing direction [S1].

**Edge Cases and Pitfalls:**
*   **Tool Occlusion:** Tissues occluded by surgical tools are infrequently represented in training data, leading to inaccurate reconstruction [S1]. The method uses spatiotemporal importance sampling to mitigate this by prioritizing these pixels [S1].
*   **Stationary Tissues:** Stationary tissues are trained repeatedly with minimal impact on convergence, reducing efficiency [S1]. Importance sampling also addresses this by down-weighting redundant static regions [S1].

## Operating characteristics
*   **Complexity:** Reduces computational cost from $O(N^4)$ (traversing all spacetime positions) to $O(N^2)$ (querying planes) [S1].
*   **Performance:** Faster convergence and inference compared to EndoNeRF, which uses a complex MLP (8 layers, 256 channels) [S1].
*   **Strengths:** Efficient representation of deformable tissues; handles arbitrary deformations better than displacement fields; shares scene priors across time steps via the static field [S1].
*   **Limitations:** Relies on accurate spatiotemporal sampling; performance degrades if occlusion is severe and importance sampling fails to prioritize occluded regions [S1].

## Background
Forplane was introduced in "Efficient Deformable Tissue Reconstruction via Orthogonal Neural Plane" (2024) [S1]. It builds on the principles of NeRF [26] and EndoNeRF [46], adapting them for surgical scenes. It is inspired by hybrid representations of static fields [29] and orthogonal plane representations [5, 29]. The method addresses specific challenges in robotic surgery, such as tool occlusion and tissue deformation, which are not well-handled by static 3D volumes or displacement fields [S1].
