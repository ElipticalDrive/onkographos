# Patch-Grid

Also called: Modeling of Thin Geometric Features

## Overview
Patch-Grid is a compositional neural implicit representation that converts a Boundary Representation (B-Rep) into a neural implicit form by representing each surface patch as a zero-level set of a neural signed distance field (SDF) [S1]. It solves the problem of representing sharp geometric features, open surface boundaries, and thin geometric features (slender tubes/narrow gaps) while maintaining high training efficiency (seconds), addressing the smoothing and long training times of standard MLP-based neural implicit representations [S1]. Unlike global CSG approaches like NH-Rep, Patch-Grid uses localized patch-grids to avoid interference between unrelated patches, and unlike NGLOD, it avoids sampling density issues by learning individual SDFs for separate patches [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D shape $S$ defined as a Boundary Representation (B-Rep), composed of a collection of surface patches $\{S_p\}_{p=1}^K$ and the connectivity types (concave, convex, or smooth) between adjacent patches [S1].
*   **Output:** A neural implicit surface $Z$ composed of a collection of neural SDFs $\{Z_p\}_{p=1}^K$ merged via a merge grid [S1].

**Data Structures:**
1.  **Patch Volume ($V_p$):** For each surface patch $S_p$, an axis-aligned bounding box is determined and partitioned into a grid of regular rectangular cells. Cells are pruned to keep only those enclosing part of $S_p$. The union of remaining nonempty cells forms $V_p$ [S1].
2.  **Patch Feature Volume ($FV_p$):** A learnable feature vector $\mathbf{f}_{i,j,k} \in \mathbb{R}^D$ is assigned to each grid point $(i,j,k)$ of $V_p$ [S1].
3.  **Merge Grid ($G$):** An octree structure that adaptively subdivides the spatial domain into cubic cells. Each leaf cell ideally contains no more than one sharp feature to simplify CSG operations [S1].

**Algorithm Steps:**

1.  **Decomposition:** Decompose the input B-Rep shape $S$ into individual surface patches $\{S_p\}_{p=1}^K$ [S1].
2.  **Patch Volume Construction:** For each patch $S_p$:
    a. Determine its axis-aligned bounding box [S1].
    b. Partition the bounding box into a grid of regular rectangular cells. The grid resolution is determined adaptively based on the averaged shape diameter function of the patch [S1].
    c. Prune grid cells to keep only those enclosing part of $S_p$. The union of these cells forms the patch volume $V_p$ [S1].
3.  **Feature Field Definition:** Define a continuous feature field $F_p(\mathbf{x})$ over $V_p$. For any query point $\mathbf{x} \in V_p$, identify the cubic cell containing $\mathbf{x}$ and obtain the feature vector via trilinear interpolation of the feature vectors at the 8 corner points of that cell [S1].
4.  **SDF Decoding:** Decode the interpolated feature vector using a Multi-Layer Perceptron (MLP) decoder $f$ with one hidden layer to output a signed distance value [S1]. The surface patch $S_p$ is approximated by the zero-level set:
    $$ S_p \subset Z_p = \{ \mathbf{x} \mid f(F_p(\mathbf{x})) = 0 \} $$
    [S1].
5.  **Connectivity Determination:** Determine connectivity between adjacent patches as concave, convex, or smooth based on the dihedral angles of patches adjacent to a common boundary curve [S1].
6.  **Merge Grid Initialization:** Initialize the merge grid $G$ as an octree grid [S1].
7.  **Merge Grid Subdivision:** Subdivide the octree based on two criteria:
    a. Whether the cell contains a patch feature volume with a finer resolution [S1].
    b. Whether the adjacency graph of the patches in the cell is a complete graph (clique). If it is a clique, the cell cannot be further simplified by subdivision [S1].
    *Note:* A maximum depth constraint is imposed for computational practicality [S1].
8.  **Local CSG Merging:** Perform CSG operations (merging learned SDFs) locally within the merge grid cells to form sharp edges and corners [S1].
9.  **Open Boundary Handling (Optional):** For open surface boundaries, model the boundary curve as the result of a trimming operation:
    a. Train a neural surface patch $Z_o$ that reconstructs the open surface $S_o$ with some extraneous part [S1].
    b. Sample points $\mathbf{x}_b$ from the boundary curve $\partial S_o$ [S1].
    c. Compute the gradient direction vector $\mathbf{N}_s$ at each $\mathbf{x}_b$ as the cross product of the surface normal $\mathbf{N}_n$ and the tangent $\mathbf{N}_t$ along the boundary curve: $\mathbf{N}_s = \mathbf{N}_n \times \mathbf{N}_t$ [S1].
    d. Train a trimming surface implicit function using the same loss as the patch, supervised by $\mathbf{x}_b$ and $\mathbf{N}_s$ [S1].
    e. Implement the trimming operation as a Boolean max operation between the open surface and the trimming surface, assuming they form a sharp convex feature at the boundary [S1].
10. **Thin Feature Handling:** Place spatially proximal but disjoint surface patches in different, potentially overlapping patch volumes to prevent distance field interference [S1].

import torch.nn as nn

class PatchGrid:
    def __init__(self, patches, connectivity):
        """
        Initialize Patch-Grid representation.
        :param patches: List of surface patches S_p.
        :param connectivity: Connectivity types between adjacent patches.
        """
        self.patches = patches
        self.connectivity = connectivity
        self.patch_volumes = []
        self.patch_feature_volumes = []
        self.merge_grid = OctreeGrid()
        self.decoder = MLPDecoder(hidden_layers=1)
        
        # Pretrain decoder if possible [S1]

    def build_patch_volume(self, patch_idx):
        """
        Construct patch volume V_p for a specific patch.
        """
        S_p = self.patches[patch_idx]
        
        # 1. Determine axis-aligned bounding box
        bbox = S_p.get_axis_aligned_bounding_box()
        
        # 2. Partition into grid cells
        # Resolution determined by averaged shape diameter function [S1]
        resolution = self.get_adaptive_resolution(S_p)
        cells = bbox.partition_into_cells(resolution)
        
        # 3. Prune cells
        # Keep only cells enclosing part of S_p
        nonempty_cells = []
        for cell in cells:
            if cell.intersects(S_p):
                nonempty_cells.append(cell)
                
        V_p = Union(nonempty_cells)
        self.patch_volumes.append(V_p)
        
        # 4. Initialize learnable feature vectors
        # D is the feature dimension
        D = 16 # Example dimension, not given in sources
        grid_points = V_p.get_grid_points()
        feature_vectors = torch.randn(len(grid_points), D, requires_grad=True)
        self.patch_feature_volumes.append(feature_vectors)
        
        return V_p

    def query_sdf(self, x, patch_idx):
        """
        Query the SDF for a specific patch at point x.
        """
        V_p = self.patch_volumes[patch_idx]
        feature_vectors = self.patch_feature_volumes[patch_idx]
        
        # Find cell containing x
        cell = V_p.find_cell_containing(x)
        
        # Get corner feature vectors
        corner_indices = cell.get_corner_indices()
        corner_features = feature_vectors[corner_indices]
        
        # Trilinear interpolation
        # x_rel is the relative position of x within the cell [0,1]^3
        x_rel = (x - cell.min_corner) / cell.size
        F_p_x = trilinear_interpolate(corner_features, x_rel)
        
        # Decode to SDF
        sdf = self.decoder(F_p_x)
        return sdf

    def train_patch(self, patch_idx, samples):
        """
        Train the feature volume and decoder for a single patch.
        """
        S_p = self.patches[patch_idx]
        V_p = self.patch_volumes[patch_idx]
        
        # Sample points from patch volume [S1]
        # samples is a set of points Omega_p
        loss_sdf = 0.0
        loss_eikonal = 0.0
        
        for x in samples:
            sdf = self.query_sdf(x, patch_idx)
            
            # SDF Loss: sdf should be 0 on surface, signed distance elsewhere
            # Ground truth distance d_gt(x) is assumed available from B-Rep
            d_gt = S_p.get_signed_distance(x)
            loss_sdf += (sdf - d_gt)**2
            
            # Eikonal Loss: |grad sdf| = 1 [S1]
            grad_sdf = torch.autograd.grad(sdf, x, create_graph=True)[0]
            loss_eikonal += (torch.norm(grad_sdf) - 1)**2
            
        # Offset distance d for sampling near surface [S1]
        # d is in range (0, 0.1) of grid cell size
        
        total_loss = loss_sdf + loss_eikonal
        return total_loss

    def build_merge_grid(self):
        """
        Build and subdivide the merge grid G.
        """
        # Initialize as octree [S1]
        self.merge_grid = OctreeGrid()
        
        # Subdivide based on criteria [S1]
        while self.merge_grid.can_subdivide():
            cell = self.merge_grid.get_cell_to_subdivide()
            
            # Criterion 1: Contains patch feature volume with finer resolution
            has_finer_resolution = cell.contains_finer_resolution_patch()
            
            # Criterion 2: Adjacency graph is a complete graph (clique)
            adjacency_graph = self.get_adjacency_graph_in_cell(cell)
            is_clique = is_complete_graph(adjacency_graph)
            
            if has_finer_resolution or is_clique:
                self.merge_grid.subdivide(cell)
            else:
                break # Or stop if max depth reached
        
        # Max depth constraint for practicality [S1]
        self.merge_grid.enforce_max_depth()

    def merge_patches(self):
        """
        Assemble individual neural surface patches into final representation Z.
        """
        # Perform CSG operations locally within merge grid cells [S1]
        for cell in self.merge_grid.get_leaf_cells():
            patches_in_cell = self.get_patches_in_cell(cell)
            connectivity = self.get_connectivity_in_cell(cell)

            # based on connectivity (concave/convex) [S1]
            merged_sdf = local_csg_merge(patches_in_cell, connectivity)
            cell.set_merged_sdf(merged_sdf)

    def get_global_sdf(self, x):

        cell = self.merge_grid.find_cell_containing(x)
        
        # If x is in a merged cell, use merged SDF

            return cell.query_merged_sdf(x)

class MLPDecoder(nn.Module):
    def __init__(self, hidden_layers=1):
        super().__init__()
        # One hidden layer as per sources [S1]
        # Input dim D, Output dim 1 (SDF)
        self.hidden_dim = 64 # Not given, typical value
        self.linear1 = nn.Linear(16, self.hidden_dim) # Input dim D=16 assumed
        self.relu = nn.ReLU()
        self.linear2 = nn.Linear(self.hidden_dim, 1)
        
    def forward(self, x):
        x = self.linear1(x)
        x = self.relu(x)
        x = self.linear2(x)
        return x

def trilinear_interpolate(corner_features, x_rel):
    """
    Trilinear interpolation of 8 corner features.
    corner_features: [8, D]
    x_rel: [3] (x, y, z in [0, 1])
    """
    x, y, z = x_rel
    # Indices of corners: 000, 100, 010, 110, 001, 101, 011, 111
    # Assuming standard ordering
    f000 = corner_features[0]
    f100 = corner_features[1]
    f010 = corner_features[2]
    f110 = corner_features[3]
    f001 = corner_features[4]
    f101 = corner_features[5]
    f011 = corner_features[6]
    f111 = corner_features[7]
    
    # Interpolate along x
    f00 = lerp(f000, f100, x)
    f10 = lerp(f010, f110, x)
    f01 = lerp(f001, f101, x)
    f11 = lerp(f011, f111, x)
    
    # Interpolate along y
    f0 = lerp(f00, f10, y)
    f1 = lerp(f01, f11, y)
    
    # Interpolate along z
    result = lerp(f0, f1, z)
    return result

def lerp(a, b, t):
    return a + t * (b - a)

**Parameters:**
*   **Grid Resolution:** Determined adaptively according to the shape complexity of individual patches, based on the averaged shape diameter function [S1].
*   **MLP Decoder Architecture:** One hidden layer [S1].
*   **Offset Distance ($d$):** A small offset distance within a range of $(0, 0.1)$ of the grid cell size, used for sampling [S1].
*   **Loss Weight ($\lambda_{merge}$):** Weight for the merge loss term [S1].

**Edge Cases and Pitfalls:**
*   **Global CSG Failure:** Global CSG merging of multiple learned SDFs can fail in highly concave and narrow regions due to interference between zero-level sets [S1]. Patch-Grid avoids this by using local merge grids [S1].
*   **Sampling Density:** Methods like NGLOD fail due to insufficient samples and MLP difficulty with sharp SDF changes. Patch-Grid avoids excessively dense sampling by learning individual SDFs for separate patches [S1].
*   **Disjoint Patches:** NH-Rep struggles to disentangle disconnected but overlapping patches via a global CSG tree. Patch-Grid enables local evaluation within patch volumes, allowing individual extraction of disconnected patches [S1].

## Subtopics

### [Patch-Grid Composite Loss](14460-patch-grid-composite-loss.md)
A composite training objective combining surface, normal, merge, SDF, and Eikonal terms to supervise the neural implicit representation. The total loss is defined as:
$$ L_{total} = \frac{1}{K} \sum_{p=1}^{K} L_{patch}^p + \lambda_{merge} \frac{1}{K} \sum_{p=1}^{K} L_{merge}^p $$
where $K$ is the number of patches. The patch loss $L_{patch}^p$ includes SDF loss and Eikonal regularization.

### Modeling of Open Surface Boundaries
A trimming process where an open surface patch is formed by trimming away an extended surface at the boundary curve using a trimming surface represented as a zero-level set of a neural implicit function [S1]. The gradient direction vector $\mathbf{N}_s$ of the target implicit function at sampled points $\mathbf{x}_b$ on the boundary curve is computed as the cross product of the surface normal $\mathbf{N}_n$ and the tangent $\mathbf{N}_t$ along the boundary curve: $\mathbf{N}_s = \mathbf{N}_n \times \mathbf{N}_t$ [S1]. The trimming operation is implemented as a Boolean max operation, assuming the trimming surface and open surface form a sharp convex feature at the boundary curve [S1].

## Operating characteristics
*   **Time Complexity:** Training time is extremely fast. Average fitting time for a 3D CAD model is 5 seconds [S1]. Local shape updates take within 2 seconds [S1].
*   **Memory Complexity:** Memory usage is constant with respect to spatial resolution, as it uses implicit representations [G]. The memory is proportional to the number of patches and the size of their patch volumes and the merge grid [S1].
*   **Measured Performance:** Implemented solely in PyTorch, achieving state-of-the-art fitting quality within a few seconds, outperforming most existing methods [S1].
*   **Strengths:** Efficient training (seconds), robust modeling of sharp features, thin geometric features, and open boundaries, local evaluation flexibility [S1].
*   **Limitations:** Requires B-Rep input (decomposition into patches), may struggle with extremely complex global topology if merge grid subdivision is insufficient [S1].
*   **When to use:** When high-fidelity reconstruction of CAD-like shapes with sharp features and thin details is required, and training speed is critical [S1].
*   **When not to use:** For unstructured point clouds without clear patch decomposition, or when global smoothness is preferred over sharp features [S1].

## Background
Patch-Grid was proposed by Guying Lin, Lei Yang, Congyi Zhang, Hao Pan, Yuhan Ping, Guodong Wei, Taku Komura, John Keyser, and Wenping Wang [S1]. It was published in ACM Transactions on Graphics (SIGGRAPH Asia) in 2024 [S1]. The method addresses limitations of previous neural implicit representations like NH-Rep and NGLOD, which struggle with sharp features and thin details due to global CSG operations or sampling density issues [S1]. It builds on the principles of neural implicit representations and constructive solid geometry (CSG) [S1].
