# VoISDF Volume Rendering and Adaptive Sampling

Also called: VolSDF Training, Volume Rendering of Neural Implicit Surfaces, Volume Rendering of Neural Implicit Surfaces training

## Overview
VoISDF (Volume Rendering of Neural Implicit Surfaces) is a neural volume rendering method that models volume density as a transformed Signed Distance Function (SDF) to improve geometry reconstruction [S3, unofficial]. Unlike prior methods that extract geometry from an arbitrary level set of a generic density MLP, VoISDF extracts the surface as the zero level-set of the learned SDF, providing a well-defined surface and inductive bias [S3, unofficial]. It employs an adaptive sampling algorithm based on a theoretical error bound for the opacity approximation, avoiding the need for a second network or random sampling artifacts [S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of images with camera parameters. For each pixel $p$, the input is a triplet $(I_p, \mathbf{c}_p, \mathbf{v}_p)$, where $I_p \in \mathbb{R}^3$ is the intensity, $\mathbf{c}_p \in \mathbb{R}^3$ is the camera location, and $\mathbf{v}_p \in \mathbb{R}^3$ is the viewing direction [S3, unofficial].
*   **Outputs:** Rendered image intensity $I(\mathbf{c}, \mathbf{v})$ and reconstructed geometry (SDF) [S3, unofficial].

**Data Structures:**
The system consists of two Multi-Layer Perceptrons (MLPs) and two scalar learnable parameters [S3, unofficial]:
1.  **Geometry Network ($f_\varphi$):** Approximates the SDF $d(\mathbf{x})$ and a global geometry feature $\mathbf{z} \in \mathbb{R}^{256}$. Output: $(d(\mathbf{x}), \mathbf{z}(\mathbf{x})) \in \mathbb{R}^{1+256}$ [S3, unofficial].
2.  **Radiance Network ($L_\psi$):** Represents the scene's radiance field. Input: position $\mathbf{x}$, normal $\mathbf{n}$, view direction $\mathbf{v}$, and feature $\mathbf{z}$. Output: color $\in \mathbb{R}^3$ [S3, unofficial].
3.  **Parameters:** $\alpha, \beta \in \mathbb{R}$ (scalar learnable parameters). In implementation, $\alpha = \beta^{-1}$ is often chosen [S3, unofficial].

**Formulas:**
*   **SDF Definition:** $d_\Omega(\mathbf{x}) = (-1)^{\mathbf{1}_\Omega(\mathbf{x})} \min_{\mathbf{y} \in \mathcal{M}} \|\mathbf{x} - \mathbf{y}\|$, where $\mathbf{1}_\Omega$ is the indicator function for object space $\Omega$ and $\mathcal{M}$ is its boundary [S3, unofficial].
*   **Density from SDF:** $\sigma(\mathbf{x}) = \alpha \Psi_\beta(-d_\Omega(\mathbf{x}))$, where $\Psi_\beta$ is the CDF of the Laplace distribution [S3, unofficial]:
    $$
    \Psi_\beta(s) = \begin{cases} \frac{1}{2} \exp\left(-\frac{s}{\beta}\right) & \text{if } s \leq 0 \\ 1 - \frac{1}{2} \exp\left(-\frac{s}{\beta}\right) & \text{if } s > 0 \end{cases}
    $$
*   **Transmittance and Opacity:** $T(t) = \exp\left(-\int_0^t \sigma(\mathbf{x}(s)) ds\right)$ and $O(t) = 1 - T(t)$ [S3, unofficial].
*   **Rendering Equation:** $I(\mathbf{c}, \mathbf{v}) = \int_0^\infty L(\mathbf{x}(t), \mathbf{n}(t), \mathbf{v}) \tau(t) dt$, where $\tau(t) = \sigma(\mathbf{x}(t))T(t)$ is the PDF of opacity and $\mathbf{n}(t) = \nabla_{\mathbf{x}} d_\Omega(\mathbf{x}(t))$ [S3, unofficial].
*   **Rectangle Rule Approximation:** For samples $\mathcal{S} = \{s_i\}_{i=1}^m$, $\hat{I}_{\mathcal{S}}(\mathbf{c}, \mathbf{v}) = \sum_{i=1}^{m-1} \hat{\tau}_i L_i$, where $\hat{\tau}_i \approx \tau(s_i) \Delta s$ [S3, unofficial].
*   **Integral Approximation:** $\hat{R}(t) = \sum_{i=1}^{k-1} \delta_i \sigma_i + (t - t_k) \sigma_k$, where $\delta_i = t_{i+1} - t_i$ and $\sigma_i = \sigma(\mathbf{x}(t_i))$ for $t \in [t_k, t_{k+1}]$ [S3, unofficial].
*   **Approximated Opacity:** $\widehat{O}(t) = 1 - \exp\left(-\widehat{R}(t)\right)$ [S3, unofficial].
*   **Error Bound on Density Derivative:** $\left| \frac{d}{ds} \sigma(\mathbf{x}(s)) \right| \leq \frac{\alpha}{2\beta} \exp\left(-\frac{d_i^*}{\beta}\right)$, where $d_i^* = \min_{s \in [t_i, t_{i+1}], \mathbf{y} \notin B_i \cup B_{i+1}} \|\mathbf{x}(s) - \mathbf{y}\|$ and $B_i = \{\mathbf{x} \mid \|\mathbf{x} - \mathbf{x}(t_i)\| < |d_i|\}$ with $d_i = d_\Omega(\mathbf{x}(t_i))$ [S3, unofficial].
*   **Error Bound on Integral Approximation:** $|E(t)| \leq \widehat{E}(t) = \frac{\alpha}{4\beta} \left( \sum_{i=1}^{k-1} \delta_i^2 e^{-\frac{d_i^*}{\beta}} + (t - t_k)^2 e^{-\frac{d_k^*}{\beta}} \right)$ [S3, unofficial].
*   **Opacity Error Bound:** $|O(t) - \widehat{O}(t)| \leq \exp\left(-\widehat{R}(t)\right) \left( \exp\left(\widehat{E}(t)\right) - 1 \right)$ [S3, unofficial].
*   **Global Error Bound:** $B_{\mathcal{T}, \beta} = \max_{k \in [n-1]} \left\{ \exp\left(-\widehat{R}(t_k)\right) \left( \exp(\widehat{E}(t_{k+1})) - 1 \right) \right\}$, with $\widehat{R}(t_0)=0$ [S3, unofficial].
*   **Sufficient $\beta$ for Fixed $n$:** $\beta \geq \frac{\alpha M^2}{4(n-1) \log(1 + \epsilon)}$ [S3, unofficial].

**Parameters:**
*   $\alpha, \beta$: Learnable positive parameters. $\alpha$ represents constant density inside the volume; $\beta$ controls smoothing near the boundary. Typical $\beta = 0.001$ [S3, unofficial].
*   $\epsilon$: Error threshold hyper-parameter. Typical value is 0.1 [S3, unofficial].
*   $n$: Number of initial uniform samples. Default is 128 [S3, unofficial].
*   $m$: Number of final samples for rendering via inverse CDF. Default is 64 [S3, unofficial].
*   $M$: Large constant representing maximum ray length [S3, unofficial].

**Steps:**
1.  **Initialize:** Set uniform sampling $\mathcal{T} = \mathcal{T}_0$ with $n=128$ points: $t_k = (k-1)\frac{M}{n-1}$ for $k \in [n]$ [S3, unofficial].
2.  **Initialize $\beta_+$:** Find $\beta_+ > \beta$ such that $B_{\mathcal{T},\beta_+} \leq \epsilon$ using Lemma 2 (the sufficient $\beta$ formula) [S3, unofficial].
3.  **Iterative Upsampling:** While $B_{\mathcal{T},\beta} > \epsilon$ and not max_iter (typically 5 iterations):
    a.  Upsample $\mathcal{T}$ by adding $n$ points. The number of points per interval is proportional to its current error bound (Eq 14) [S3, unofficial].
    b.  If $B_{\mathcal{T},\beta_+} < \epsilon$, find $\beta_\star \in (\beta, \beta_+)$ such that $B_{\mathcal{T},\beta_\star} = \epsilon$ using bisection (max 10 iterations), then update $\beta_+ \leftarrow \beta_\star$ [S3, unofficial].
4.  **Estimate Opacity:** Estimate $\hat{O}$ using the final $\mathcal{T}$ and $\beta_+$ [S3, unofficial].
5.  **Final Sampling:** Return $\mathcal{S}$ by generating $m=64$ fresh samples using inverse transform sampling with $\hat{O}^{-1}$ [S3, unofficial].

**Pseudocode:**
```python
def compute_sdf_to_density(sdf_value, alpha, beta):
    """Converts SDF value to volume density using Laplace CDF."""
    # Psi_beta(s)
    if sdf_value <= 0:
        psi = 0.5 * math.exp(-(-sdf_value) / beta) # Note: formula uses -d_Omega, so s = -d_Omega
        # If sdf_value is d_Omega, then s = -sdf_value.
        # If sdf_value <= 0 (inside), -sdf_value >= 0.
        # Wait, formula: sigma = alpha * Psi_beta(-d_Omega).
        # Let s = -d_Omega.
        # If d_Omega <= 0 (inside), s >= 0. Psi_beta(s) = 1 - 0.5 * exp(-s/beta).
        # If d_Omega > 0 (outside), s <= 0. Psi_beta(s) = 0.5 * exp(-s/beta).
        pass 
    
    s = -sdf_value
    if s <= 0:
        psi = 0.5 * math.exp(-s / beta)
    else:
        psi = 1.0 - 0.5 * math.exp(-s / beta)
    return alpha * psi

def compute_error_bound_terms(t, samples_T, sigmas, alpha, beta):
    """Computes R_hat(t) and E_hat(t) for a given t."""
    # Find interval k such that t in [t_k, t_{k+1}]
    # This requires searching samples_T
    k = find_interval(t, samples_T)
    
    # Compute R_hat(t)
    R_hat = 0.0
    for i in range(k - 1):
        delta_i = samples_T[i+1] - samples_T[i]
        R_hat += delta_i * sigmas[i]
    
    # Add partial interval
    delta_k = t - samples_T[k]
    R_hat += delta_k * sigmas[k]
    
    # Compute E_hat(t)
    # Requires d_i_star for each interval
    E_hat = 0.0
    for i in range(k):
        # Calculate d_i_star
        # d_i_star = min distance from ray segment [t_i, t_{i+1}] to any point y not in B_i U B_{i+1}
        # B_i = {x | ||x - x(t_i)|| < |d_i|}
        # This is complex to compute exactly without geometry. 
        # Approximation: d_i_star is related to the distance at endpoints.
        # For implementation, we might use the minimum unsigned distance at endpoints 
        # or a simplified bound if exact geometry is unavailable.
        # Source says: "explicit formula for d_i_star is a bit cumbersome"
        # We assume a helper function exists or approximate.
        d_i_star = compute_d_i_star(t, samples_T, i) 
        
        delta_i = samples_T[i+1] - samples_T[i]
        term = delta_i**2 * math.exp(-d_i_star / beta)
        E_hat += term
        
    # Last partial interval term
    d_k_star = compute_d_i_star(t, samples_T, k)
    E_hat += (t - samples_T[k])**2 * math.exp(-d_k_star / beta)
    
    E_hat = (alpha / (4 * beta)) * E_hat
    
    return R_hat, E_hat

def compute_global_error_bound(samples_T, sigmas, alpha, beta):
    """Computes B_{T, beta}."""
    max_bound = 0.0
    for k in range(len(samples_T) - 1):
        t_k = samples_T[k]
        t_k1 = samples_T[k+1]
        
        R_k, E_k = compute_error_bound_terms(t_k, samples_T, sigmas, alpha, beta)
        R_k1, E_k1 = compute_error_bound_terms(t_k1, samples_T, sigmas, alpha, beta)
        
        # Bound for interval [t_k, t_{k+1}]
        # max |O(t) - O_hat(t)| <= exp(-R(t_k)) * (exp(E(t_{k+1})) - 1)
        bound = math.exp(-R_k) * (math.exp(E_k1) - 1)
        
        if bound > max_bound:
            max_bound = bound
            
    return max_bound

def adaptive_sampling(ray_origin, ray_direction, sdf_net, alpha, beta, epsilon, max_iter=5):
    """
    VoISDF Adaptive Sampling Algorithm.
    """
    M = 10.0 # Large constant for max ray length
    n = 128  # Initial samples
    m = 64   # Final samples
    
    # 1. Initialize uniform sampling
    samples_T = [(k-1) * M / (n-1) for k in range(1, n+1)]
    
    # 2. Initialize beta_plus
    # Lemma 2: beta >= alpha * M^2 / (4 * (n-1) * log(1 + epsilon))
    beta_plus = (alpha * M**2) / (4 * (n-1) * math.log(1 + epsilon))
    
    # 3. Iterative upsampling
    for iteration in range(max_iter):
        # Compute sigmas for current samples_T
        sigmas = [compute_sdf_to_density(sdf_net(ray_origin + t * ray_direction), alpha, beta) for t in samples_T]
        
        # Check if bound is satisfied for beta
        B_beta = compute_global_error_bound(samples_T, sigmas, alpha, beta)
        if B_beta <= epsilon:
            break
            
        # Upsample T
        # Add n points, proportional to error bound of each interval
        # This requires calculating error bounds per interval
        interval_bounds = []
        for k in range(len(samples_T) - 1):
            R_k, E_k = compute_error_bound_terms(samples_T[k], samples_T, sigmas, alpha, beta)
            R_k1, E_k1 = compute_error_bound_terms(samples_T[k+1], samples_T, sigmas, alpha, beta)
            bound = math.exp(-R_k) * (math.exp(E_k1) - 1)
            interval_bounds.append(bound)
            
        total_bound = sum(interval_bounds)
        new_points = []
        for k in range(len(samples_T) - 1):
            # Number of points proportional to bound
            num_points = int(n * (interval_bounds[k] / total_bound))
            if num_points < 1:
                num_points = 1
            t_start = samples_T[k]
            t_end = samples_T[k+1]
            for j in range(num_points):
                t_new = t_start + (t_end - t_start) * (j + 1) / (num_points + 1)
                new_points.append(t_new)
                
        samples_T = sorted(samples_T + new_points)
        
        # Recompute sigmas
        sigmas = [compute_sdf_to_density(sdf_net(ray_origin + t * ray_direction), alpha, beta) for t in samples_T]
        
        # Check if beta_plus needs update
        B_beta_plus = compute_global_error_bound(samples_T, sigmas, alpha, beta_plus)
        if B_beta_plus < epsilon:
            # Find beta_star in (beta, beta_plus) such that B_{T, beta_star} = epsilon
            # Bisection
            low = beta
            high = beta_plus
            for _ in range(10):
                mid = (low + high) / 2
                # Recompute bound with mid
                # Note: sigma depends on beta, so sigmas change with beta
                sigmas_mid = [compute_sdf_to_density(sdf_net(ray_origin + t * ray_direction), alpha, mid) for t in samples_T]
                B_mid = compute_global_error_bound(samples_T, sigmas_mid, alpha, mid)
                if B_mid > epsilon:
                    low = mid
                else:
                    high = mid
            beta_plus = (low + high) / 2
            
    # 4. Estimate O_hat
    # Use final samples_T and beta_plus
    sigmas_final = [compute_sdf_to_density(sdf_net(ray_origin + t * ray_direction), alpha, beta_plus) for t in samples_T]
    # Compute O_hat(t) for all t in samples_T
    O_hat_values = []
    for t in samples_T:
        R, _ = compute_error_bound_terms(t, samples_T, sigmas_final, alpha, beta_plus)
        O_hat = 1.0 - math.exp(-R)
        O_hat_values.append(O_hat)
        
    # 5. Return m fresh samples using inverse transform sampling
    # Inverse CDF of O_hat
    # This requires interpolating O_hat and finding t such that O_hat(t) = u
    final_samples = []
    for _ in range(m):
        u = random.uniform(0, 1)
        # Find t such that O_hat(t) approx u
        # Linear interpolation between samples_T
        t_sample = inverse_sample(O_hat_values, samples_T, u)
        final_samples.append(t_sample)
        
    return final_samples
```

## Operating characteristics
*   **Time Complexity:** The adaptive sampling algorithm iteratively upsamples the ray, requiring multiple evaluations of the SDF network and error bound calculations. The error bound calculation is $O(n^2)$ per ray if naive, but can be optimized. The final rendering uses $m=64$ samples.
*   **Memory Complexity:** Constant with respect to spatial resolution, determined by the MLP size and the number of samples per ray.
*   **Performance:** On the BlendedMVS dataset, VolSDF improves Chamfer distance by a mean of 51.8% compared to NeRF++. VolSDF's mean PSNR is 27.08, compared to NeRF++'s 27.55 [S3, unofficial].
*   **Strengths:** Avoids salt and pepper artifacts caused by random sampling in NeRF and artifacts from fixed uniform sampling. Disentangles geometry and appearance effectively. Does not require object masks for training, unlike IDR [S3, unofficial].
*   **Limitations:** High $\beta$ makes training harder but potentially more accurate; low $\beta$ makes training easier but potentially less accurate [S1, unofficial]. Using a second network for inverse sampling (if not using VoISDF's method) can result in density mismatch [S3, unofficial].

## Background
VoISDF was introduced in the paper "Volume Rendering of Neural Implicit Surfaces" [S3, unofficial]. It addresses the limitations of previous neural volume rendering techniques that modeled geometry as a function of density, leading to noisy reconstructions. By modeling density as a function of SDF, it provides a useful inductive bias for geometry and a principled way to reconstruct the surface as the zero level-set [S3, unofficial].
