# Chunk Loading/Unloading Scanner

Also called: Chunk Load/Unload Distance Culling, Render Distance Chunk Management, Scanner, ScannerPlugin, Spatial Chunk Culling

## Overview
The Chunk Loading/Unloading Scanner is a spatial management technique that determines which chunks of a volume dataset need to be loaded into memory or unloaded based on the camera's current and previous positions [S1, unofficial][S2, unofficial]. It solves the problem of efficiently streaming large voxel worlds by identifying a load area and an unload area using offset grids, then computing the symmetric difference between these areas to generate precise queue updates [S1, unofficial]. It differs from [Chunk Visibility Culling](5031-chunk-visibility-culling.md) by operating on loaded chunks and using distance thresholds rather than frustum intersection tests [S1, unofficial][S2, unofficial].

## How it works
**Inputs:** Camera world position, camera transform, previous camera chunk position, chunk grid dimensions, render distance radius, and data/mesh sampling offsets [S1, unofficial][S2, unofficial].
**Outputs:** Four queues of chunk coordinates: `unresolved_data_load`, `unresolved_mesh_load`, `unresolved_data_unload`, `unresolved_mesh_unload` [S1, unofficial].

**Data Structures:**
The core state is held in a `Scanner` struct containing:
- `prev_chunk_pos`: `IVec3`, storing the chunk coordinates of the camera in the previous frame [S1, unofficial].
- `checks_per_frame`: `usize`, the number of chunks visited per frame. Default: $32 \times 32 \times 32$ [S1, unofficial].
- `data_offset`: `usize`, radius for data loading offsets. Calculated as `distance + 1` [S1, unofficial].
- `mesh_offset`: `usize`, radius for mesh loading offsets. Calculated as `distance` [S1, unofficial].
- `data_sampling_offsets`: `Vec<IVec3>`, precomputed list of relative chunk offsets within the data loading radius [S1, unofficial].
- `mesh_sampling_offsets`: `Vec<IVec3>`, precomputed list of relative chunk offsets within the mesh loading radius [S1, unofficial].
- `unresolved_data_load`: `Vec<IVec3>`, chunks to load data for [S1, unofficial].
- `unresolved_mesh_load`: `Vec<IVec3>`, chunks to load mesh geometry for [S1, unofficial].
- `unresolved_data_unload`: `VecDeque<IVec3>`, chunks to unload data from [S1, unofficial].
- `unresolved_mesh_unload`: `VecDeque<IVec3>`, chunks to unload mesh from [S1, unofficial].

**Parameters:**
- `CHUNK_RENDER_DISTANCE` (or `distance`): The number of chunks to load around the player. Used as base for loading radius and unload threshold multiplier [S2, unofficial].
- Unloading Threshold Multiplier: A scalar of 8. Chunks are unloaded when their axis-aligned distance exceeds `CHUNK_RENDER_DISTANCE * 8` [S2, unofficial].

**Algorithm Steps:**

1. **Calculate Current Chunk Position:** Determine the chunk index containing the camera. Method A scales and translates the camera transform: $\text{chunk\_pos} = \lfloor (\text{camera\_transform.translation} - \text{Vec3}(16.0)) \times \frac{1}{32.0} \rfloor$ [S1, unofficial]. Method B uses floor division: $\text{current\_chunk\_index} = \left( \lfloor \frac{\text{camera\_position}.x}{\text{Chunk::CHUNK\_LENGTH}} \rfloor, \lfloor \frac{\text{camera\_position}.y}{\text{Chunk::CHUNK\_LENGTH}} \rfloor, \lfloor \frac{\text{camera\_position}.z}{\text{Chunk::CHUNK\_LENGTH}} \rfloor \right)$ [S2, unofficial].
2. **Check for Movement:** Compare `current_chunk_pos` with `prev_chunk_pos`. If unchanged, skip processing [S1, unofficial].
3. **Generate Sampling Offsets:** Precompute relative offsets for load/unload areas. Iterate $x, y, z$ from $-\text{offset}$ to $+\text{offset}$. Collect offsets where at least one coordinate is at the boundary of the offset radius [S2, unofficial].
4. **Define Load and Unload Areas:** Create sets of chunk coordinates: `load_data_area` = `current_chunk_pos` + `data_sampling_offsets`, `unload_data_area` = `previous_chunk_pos` + `data_sampling_offsets` [S1, unofficial].
5. **Compute Differences:** Calculate the set difference between the current load area and the previous unload area to find chunks that need state changes: $\text{data\_load} = \text{load\_data\_area} \setminus \text{unload\_data\_area}$, $\text{data\_unload} = \text{unload\_data\_area} \setminus \text{load\_data\_area}$. Repeat for mesh areas using `mesh_sampling_offsets` [S1, unofficial].
6. **Update Queues:** Add chunks in `data_load` to `unresolved_data_load`. Add chunks in `mesh_load` to `unresolved_mesh_load`. Add chunks in `data_unload` to `unresolved_data_unload`. Add chunks in `mesh_unload` to `unresolved_mesh_unload`. Remove unloaded chunks from load queues. Remove loaded chunks from unload queues [S1, unofficial].
7. **Sort Load Queues:** Sort `unresolved_data_load` and `unresolved_mesh_load` by squared Euclidean distance from the `current_chunk_pos` to prioritize loading nearby chunks first [S1, unofficial].
8. **Limit Processing:** If `checks_per_frame` is set, only process the first $N$ chunks from the sorted load queues and the first $N$ chunks from the unload queues [S1, unofficial].

**Pseudocode:**

```python
import math
from collections import deque
from typing import List, Set

class IVec3:
    def __init__(self, x: int, y: int, z: int):
        self.x = x
        self.y = y
        self.z = z

    def __add__(self, other):
        return IVec3(self.x + other.x, self.y + other.y, self.z + other.z)

    def __sub__(self, other):
        return IVec3(self.x - other.x, self.y - other.y, self.z - other.z)

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y and self.z == other.z

    def __hash__(self):
        return hash((self.x, self.y, self.z))

    def squared_dist(self, other: 'IVec3') -> int:
        dx = self.x - other.x
        dy = self.y - other.y
        dz = self.z - other.z
        return dx*dx + dy*dy + dz*dz

    def axis_dist(self, other: 'IVec3') -> int:
        return max(abs(self.x - other.x), abs(self.y - other.y), abs(self.z - other.z))

def generate_offsets(radius: int) -> List[IVec3]:
    """
    Generates offsets within a radius.
    From [S2, unofficial]: iterate x,y,z from -radius to radius, collect where at least one coord is at boundary.
    """
    offsets = []
    for x in range(-radius, radius + 1):
        for y in range(-radius, radius + 1):
            for z in range(-radius, radius + 1):
                if abs(x) == radius or abs(y) == radius or abs(z) == radius:
                    offsets.append(IVec3(x, y, z))
    return offsets

def chunk_position_from_camera(camera_pos: IVec3, chunk_length: int) -> IVec3:
    """
    From [S2, unofficial]: floor division.
    """
    return IVec3(
        int(math.floor(camera_pos.x / chunk_length)),
        int(math.floor(camera_pos.y / chunk_length)),
        int(math.floor(camera_pos.z / chunk_length))
    )

class ChunkScanner:
    def __init__(self, chunk_length: int, render_distance: int):
        self.chunk_length = chunk_length
        self.render_distance = render_distance
        self.prev_chunk_pos = None
        
        # Parameters from [S1, unofficial]
        self.data_offset = render_distance + 1
        self.mesh_offset = render_distance
        
        # Precompute offsets
        self.data_sampling_offsets = generate_offsets(self.data_offset)
        self.mesh_sampling_offsets = generate_offsets(self.mesh_offset)
        
        # Unload threshold multiplier from [S2, unofficial]
        self.unload_threshold_multiplier = 8
        
        # Queues
        self.unresolved_data_load: List[IVec3] = []
        self.unresolved_mesh_load: List[IVec3] = []
        self.unresolved_data_unload: deque = deque()
        self.unresolved_mesh_unload: deque = deque()
        
        # Limit from [S1, unofficial]
        self.checks_per_frame = 32 * 32 * 32

    def update(self, camera_pos: IVec3) -> None:
        current_chunk_pos = chunk_position_from_camera(camera_pos, self.chunk_length)
        
        # Step 2: Check for movement
        if self.prev_chunk_pos is not None and current_chunk_pos == self.prev_chunk_pos:
            return
            
        # Step 4: Define Areas
        load_data_area = {current_chunk_pos + off for off in self.data_sampling_offsets}
        load_mesh_area = {current_chunk_pos + off for off in self.mesh_sampling_offsets}
        prev_pos = self.prev_chunk_pos if self.prev_chunk_pos else current_chunk_pos
        unload_data_area = {prev_pos + off for off in self.data_sampling_offsets}
        unload_mesh_area = {prev_pos + off for off in self.mesh_sampling_offsets}

        # Step 5: Compute Differences
        data_load = load_data_area - unload_data_area
        data_unload = unload_data_area - load_data_area
        mesh_load = load_mesh_area - unload_mesh_area
        mesh_unload = unload_mesh_area - load_mesh_area

        # Step 6: Update Queues
        for chunk in data_load:
            self.unresolved_data_load.append(chunk)
        for chunk in mesh_load:
            self.unresolved_mesh_load.append(chunk)
        for chunk in data_unload:
            if chunk.axis_dist(current_chunk_pos) > self.render_distance * self.unload_threshold_multiplier:
                self.unresolved_data_unload.append(chunk)
        for chunk in mesh_unload:
            if chunk.axis_dist(current_chunk_pos) > self.render_distance * self.unload_threshold_multiplier:
                self.unresolved_mesh_unload.append(chunk)
                
        # Remove unloaded chunks from load queues. Remove loaded chunks from unload queues.
        self.unresolved_data_load = [c for c in self.unresolved_data_load if c not in data_unload]
        self.unresolved_mesh_load = [c for c in self.unresolved_mesh_load if c not in mesh_unload]
        self.unresolved_data_unload = deque([c for c in self.unresolved_data_unload if c not in data_load])
        self.unresolved_mesh_unload = deque([c for c in self.unresolved_mesh_unload if c not in mesh_load])
        
        # Step 7: Sort Load Queues
        self.unresolved_data_load.sort(key=lambda c: c.squared_dist(current_chunk_pos))
        self.unresolved_mesh_load.sort(key=lambda c: c.squared_dist(current_chunk_pos))
        
        # Step 8: Limit Processing
        self.unresolved_data_load = self.unresolved_data_load[:self.checks_per_frame]
        self.unresolved_mesh_load = self.unresolved_mesh_load[:self.checks_per_frame]
        
        self.prev_chunk_pos = current_chunk_pos
```

**Edge Cases and Pitfalls:**
- **Unloading Overhead:** Unloading freed resources (e.g., `ID3D12Resource`) has high overhead. The implementation may queue indices for later processing rather than unloading immediately every frame [S2, unofficial].
- **Precision:** Chunk position calculation must handle negative coordinates correctly using floor division rather than truncation [S2, unofficial].
- **Degenerate Input:** If the camera does not move, the scanner skips processing, which is correct but requires careful handling of the initial frame where `prev_chunk_pos` is null [S1, unofficial].

## Subtopics

### [Chunk Visibility Culling](5031-chunk-visibility-culling.md)
Determines visibility via frustum tests on a flat list of chunks. Choose this when you need to exclude chunks outside the view volume before distance-based loading. It is a binary filter, unlike the distance-based loading of the Scanner.

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** Not given in the sources.
- **Strengths:** Simple logic, low overhead for small camera movements, easy to implement [G].
- **Limitations:** Does not account for occlusion [G]. Unloading freed resources has high overhead, so the code comments out the actual unloading loop and only queues indices for later processing [S2, unofficial].

## Background
The Chunk Loading/Unloading Scanner is a technique used in voxel engines and out-of-core volume rendering systems to manage memory for large spatial datasets [G]. It is implemented in projects such as the Binary Greedy Voxel Meshing Algorithm demo [S1, unofficial] and the rtarun9 voxel engine [S2, unofficial]. The method relies on the principle that only chunks near the camera boundary need to be updated when the camera moves, reducing the need to scan the entire world grid every frame [G].
