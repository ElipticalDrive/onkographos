# Dynamic Channel & Timepoint Switching

Also called: Atlas & Renderer Rebuild, Channel & Timepoint Switching, Selective Brick Reload

## Overview
Dynamic Channel & Timepoint Switching allows changing the active source channels or timepoint of an OME-Zarr dataset without reopening the file or resetting the camera and display settings [S1, unofficial]. It distinguishes itself from sibling methods by selectively reloading only the bricks associated with changed channels or all bricks if the timepoint changes, while handling the structural rebuild of the GPU atlas when the channel count changes [S1, unofficial].

## How it works
**Inputs:** Current renderer state, new `sourceChannels` (array of integers), new `timepoint` (integer), and dataset metadata [S1, unofficial].
**Outputs:** Updated GPU resources, streaming manager, and brick cache [S1, unofficial].

**Data Structures:**
*   **Bitmasks:**
    *   `changedChannels`: Bitmask where bit $i$ is set if channel $i$ is new or removed [S1, unofficial].
    *   `stale`: Bitmask of channels/timepoints requiring brick reload [S1, unofficial].
*   **Renderer State (Preserved across rebuild):**
    *   `channelColors`: `float[4][4]` (RGBA per channel) [S1, unofficial].
    *   `channelWindowCenter`: `float[4]` [S1, unofficial].
    *   `channelWindowWidth`: `float[4]` [S1, unofficial].
    *   `windowCenter`: `float` [S1, unofficial].
    *   `windowWidth`: `float` [S1, unofficial].
    *   `volumeRenderMode`: `enum` [S1, unofficial].
    *   `useIndirection`: `bool` [S1, unofficial].
    *   `enableJitter`: `bool` [S1, unofficial].
    *   `enableTAA`: `bool` [S1, unofficial].
    *   `densityScale`: `float` [S1, unofficial].
    *   `shading`: `bool` [S1, unofficial].
    *   `gradientOpacity`: `bool` [S1, unofficial].
    *   `isoValue`: `float` [S1, unofficial].
    *   `floatMin`: `float` [S1, unofficial].
    *   `floatMax`: `float` [S1, unofficial].
    *   `clipMin`: `vec3` [S1, unofficial].
    *   `clipMax`: `vec3` [S1, unofficial].
    *   `sliceX`, `sliceY`, `sliceZ`: `float` [S1, unofficial].
    *   `showSliceX`, `showSliceY`, `showSliceZ`: `bool` [S1, unofficial].
    *   `showWireframe`: `bool` [S1, unofficial].
    *   `showAxis`: `bool` [S1, unofficial].
    *   `transferFunction`: `object` [S1, unofficial].
    *   `renderScale`: `float` [S1, unofficial].

**Steps:**
1. Validate selection via `dataProvider.setSourceSelection(new_source_channels, new_timepoint)` [S1, unofficial].
2. Compute `changedChannels` bitmask by comparing the current `sourceChannels` with the new selection [S1, unofficial].
3. Compute `stale` bitmask: if `timepoint` changed, `stale = (1 << numChannels) - 1`; otherwise `stale = changedChannels` [S1, unofficial].
4. If `stale` is zero and the channel count is unchanged, return early [S1, unofficial].
5. Update `emptyBrickThreshold` based on the new data characteristics [S1, unofficial].
6. If the channel count changed, call `rebuildGpu` [S1, unofficial]. Otherwise, call `applyChannelDefaults`, set `floatMin` and `floatMax`, update visible channels, and call `streamingManager.reload(stale)` to fetch only changed bricks [S1, unofficial].
7. Reset accumulation buffers and mark the scene as dirty for redraw [S1, unofficial].

**Pseudocode:**
```python
def switch_source_selection(renderer, data_provider, new_source_channels, new_timepoint):
    # 1. Validate selection
    data_provider.set_source_selection(new_source_channels, new_timepoint)

    # 2. Compute bitmasks
    current_channels = renderer.source_channels
    changed_channels = 0
    max_len = max(len(current_channels), len(new_source_channels))
    for i in range(max_len):
        in_old = i < len(current_channels)
        in_new = i < len(new_source_channels)
        if in_old != in_new:
            changed_channels |= 1 << i

    if new_timepoint != renderer.current_timepoint:
        stale = (1 << renderer.num_channels) - 1
    else:
        stale = changed_channels

    if stale == 0 and len(current_channels) == len(new_source_channels):
        return  # No changes needed

    # 3. Update thresholds
    # Not given in the sources.
    renderer.empty_brick_threshold = compute_empty_brick_threshold(data_provider)

    # 4. Check capacity if channel count changed
    if len(new_source_channels) != len(current_channels):
        # assertBaseFits: throws if nextCount > renderer.numChannels and doesn't fit
        if len(new_source_channels) > renderer.num_channels:
            # Not given in the sources.
            if not fits_atlas_budget(renderer, len(new_source_channels)):
                raise ValueError("New channel count exceeds atlas capacity")

        # 5a. Rebuild GPU
        saved_max_pixel_error = renderer.max_pixel_error
        # Not given in the sources.
        dispose_old_resources(renderer)

        # Not given in the sources.
        new_renderer = build_gpu(data_provider, new_source_channels, new_timepoint)

        # Copy preserved state
        new_renderer.channel_colors = renderer.channel_colors
        new_renderer.channel_window_center = renderer.channel_window_center
        new_renderer.channel_window_width = renderer.channel_window_width
        new_renderer.window_center = renderer.window_center
        new_renderer.window_width = renderer.window_width
        new_renderer.volume_render_mode = renderer.volume_render_mode
        new_renderer.use_indirection = renderer.use_indirection
        new_renderer.enable_jitter = renderer.enable_jitter
        new_renderer.enable_taa = renderer.enable_taa
        new_renderer.density_scale = renderer.density_scale
        new_renderer.shading = renderer.shading
        new_renderer.gradient_opacity = renderer.gradient_opacity
        new_renderer.iso_value = renderer.iso_value
        new_renderer.float_min = renderer.float_min
        new_renderer.float_max = renderer.float_max
        new_renderer.clip_min = renderer.clip_min
        new_renderer.clip_max = renderer.clip_max
        new_renderer.slice_x = renderer.slice_x
        new_renderer.slice_y = renderer.slice_y
        new_renderer.slice_z = renderer.slice_z
        new_renderer.show_slice_x = renderer.show_slice_x
        new_renderer.show_slice_y = renderer.show_slice_y
        new_renderer.show_slice_z = renderer.show_slice_z
        new_renderer.show_wireframe = renderer.show_wireframe
        new_renderer.show_axis = renderer.show_axis
        new_renderer.transfer_function = renderer.transfer_function
        new_renderer.render_scale = renderer.render_scale

        renderer.resources = new_renderer.resources
        renderer.views[0].renderer = new_renderer

        # Not given in the sources.
        build_view_renderers(renderer.views[1:])
        resize_views(renderer.views)
        attach_new_streaming_manager(renderer)
        renderer.max_pixel_error = saved_max_pixel_error
    else:
        # 5b. Reload bricks
        # Not given in the sources.
        apply_channel_defaults(renderer)
        # Not given in the sources.
        renderer.float_min = compute_float_min(data_provider)
        # Not given in the sources.
        renderer.float_max = compute_float_max(data_provider)
        # Not given in the sources.
        update_visible_channels(renderer, new_source_channels)
        renderer.streaming_manager.reload(stale)

    # 6. Finalize
    # Not given in the sources.
    reset_accumulation(renderer)
    # Not given in the sources.
    mark_dirty(renderer)
```

**Parameters:**
*   `stale`: Bitmask indicating which channels/timepoints need brick reloading. All bits are set if the timepoint changed; otherwise, only changed channels are set [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Atlas Capacity:** Growing the channel count may exceed the GPU atlas VRAM budget. The method mitigates this by calling `assertBaseFits` before making changes, which throws an error if the new configuration does not fit [S1, unofficial].
*   **Precision:** Window center and width normalization depends on the data type (float versus integer) and the data range [S1, unofficial].
