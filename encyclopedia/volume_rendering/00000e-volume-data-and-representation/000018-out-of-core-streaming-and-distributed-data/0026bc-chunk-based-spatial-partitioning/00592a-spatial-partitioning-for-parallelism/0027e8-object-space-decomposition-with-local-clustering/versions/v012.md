# Object-space decomposition with local clustering

Also called: Graph-based clustering for unstructured grids, Local clustering via MeTiS

## Overview
Object-space decomposition with local clustering is a view-independent preprocessing method for parallel volume rendering on unstructured grids that partitions the domain into cell-clusters to minimize communication and load imbalance during rendering [S1, unofficial]. It differs from sibling methods like [MPI-based Volume Partitioning](1093-mpi-based-volume-partitioning.md) by performing local partitioning on each processor using MeTiS before global synchronization, and from [ShardedVolume](12593-shardedvolume.md) by explicitly constructing a contracted visualization graph to support the subsequent [Remapping Phase](4250-remapping-phase.md) for dynamic view adaptation [S1, unofficial].

## How it works
**Inputs:**
- Global visualization graph $Q_v = (N_v, E_v)$ representing the unstructured grid connectivity [S1, unofficial].
- Number of processors $A$ [S1, unofficial].
- Viewing parameter $v$ for subsequent remapping [S1, unofficial].

**Outputs:**
- Global clustering solution $C = [C_1, C_2, \dots, C_K]$, where $K$ is the total number of clusters [S1, unofficial].
- Global mapping function $M_e$ mapping each cluster to a processor [S1, unofficial].
- Local data structures `ClusterData` and `ClusterMapArray` on each processor [S1, unofficial].
- Contracted visualization graph $Q_c = (N_c, E_c)$ and migration cost function $T_c$ [S1, unofficial].

**Data Structures:**
1. **`ClusterData`**: Maintained by each processor for its local cell-clusters [S1, unofficial].
   - `VertexArray`: List of vertices belonging to the cluster, using local indexing [S1, unofficial].
   - `CellArray`: List of tetrahedral cells belonging to the cluster, using local indexing [S1, unofficial].
   - **Connectivity**: For each cell in `CellArray`, the four global neighbor-cell identifiers are replaced by a tuple `(global_cluster_id, local_index_of_neighbor_cell)` to maintain connectivity between cell-clusters within the local indexing scheme [S1, unofficial].
   - `TotalVolume`: The sum of the volumes (in WSC) of all constituent cells in the cluster [S1, unofficial].
2. **`ClusterMapArray`**: Maintained by each processor for all clusters in the global environment [S1, unofficial].
   - For each global cluster $C_i$:
     - `Mapping`: The current processor assignment $M_e(C_i)$ [S1, unofficial].
     - `Pointer`: A pointer to the `ClusterData` structure if $C_i$ is local to this processor; otherwise null [S1, unofficial].

**Numbered Steps:**
1. **Local Graph Construction**: Each processor $P_k$ ($k=1 \dots A$) constructs its local view-independent visualization graph $Q_k$, which is the subgraph of $Q_v$ induced by the node subset corresponding to the local cells owned by $P_k$ [S1, unofficial].
2. **Local Clustering**: Each processor $P_k$ concurrently performs a partitioning of $Q_k$ into $q_k$ clusters using MeTiS [S1, unofficial]. The local number of resulting clusters $q_k$ is selected to be proportional to the total node weight in its local graph such that $\sum_{k=1}^{A} q_k = c \cdot a$, where $c$ and $a$ are constants defined by the system configuration [S1, unofficial]. This scheme reduces variations in cluster weights to improve the efficiency of the subsequent graph-partitioning based remapping [S1, unofficial]. The local $q_k$-way partitioning performed in each processor $P_k$ effectively constitutes a $K$-way global clustering solution $C = [C_1, C_2, \dots, C_K]$ [S1, unofficial].
3. **Global Identifier Assignment**: Each cluster in the overall environment is assigned a unique global cluster identifier, and the global mapping function $M_e$ for these clusters is determined [S1, unofficial].
4. **Connectivity Update**: In the `CellArray` structure of each local `ClusterData`, the four global neighbor-cell identifiers of each cell are replaced by the global-cluster identifiers and local indices of the respective neighbor cells [S1, unofficial].
5. **Contracted Graph Construction ($Q_c$)**: The contracted visualization graph $Q_c = (N_c, E_c)$ is the contraction of the global graph according to the global clustering solution $C$ for a given viewing parameter $v$ [S1, unofficial]. There exists an edge $C_{ij}$ between clusters $C_i$ and $C_j$ if these clusters share at least one face through two neighbor cells in these two clusters [S1, unofficial]. The topology of the view-dependent visualization graph does not change with changing viewing parameter $v$, and is identical to the topology of the view-independent contracted visualization graph $Q_c$; all contracted graphs differ only in node and edge weights [S1, unofficial]. Each processor constructs its local portion of $Q_c$ [S1, unofficial].
6. **Global Graph Replication**: A copy of the global graph $Q_c$ is replicated in each processor by performing an all-to-all-broadcast operation [S1, unofficial]. This allows the construction of the view-dependent contracted graph to involve only the computation of node and edge weights according to $v$ [S1, unofficial].
7. **Migration Cost Calculation ($T_c$)**: $T_c$ denotes the cluster-migration-cost function [S1, unofficial]. The migration cost of a cell-cluster is taken to be equal to the ratio of the size of its associated `ClusterData` structure to the size of an individual ray-segment information [S1, unofficial]. Since each processor only knows the migration costs of its local clusters, an all-to-all broadcast operation is performed to let each processor become aware of the migration costs of all clusters [S1, unofficial].

**Pseudocode:**
```python
class VertexArray:
    def __init__(self, vertices):
        self.vertices = vertices

class CellArray:
    def __init__(self, cells):
        self.cells = cells
        self.neighbor_info = [None] * 4  # Stores (global_cluster_id, local_index)

class ClusterData:
    def __init__(self, vertex_array, cell_array):
        self.vertex_array = vertex_array
        self.cell_array = cell_array
        self.total_volume = sum(cell.volume for cell in cell_array.cells)
        self.data_size = estimate_struct_size(self)  # [G] Computes memory footprint in bytes

class ClusterMapEntry:
    def __init__(self, mapping, pointer):
        self.mapping = mapping
        self.pointer = pointer

def build_subgraph(global_graph_Qv, local_cell_indices):
    """Returns subgraph induced by local_cell_indices."""
    local_nodes = [n for n in global_graph_Qv.nodes if n.cell_id in local_cell_indices]
    local_edges = [(u, v) for u, v in global_graph_Qv.edges if u in local_nodes and v in local_nodes]
    return {'nodes': local_nodes, 'edges': local_edges}

def metis_partition(graph_Qk, num_clusters_qk):
    """Returns a list of cluster assignments for each node in graph_Qk."""
    # [G] Standard graph partitioning algorithm. Returns list of cluster indices per node.
    partition = [0] * len(graph_Qk.nodes)
    # ... partitioning logic ...
    return partition

def get_cells_in_partition(partition, cluster_idx, local_cells):
    return [cell for cell, cluster in zip(local_cells, partition) if cluster == cluster_idx]

def get_vertices_in_partition(partition, cluster_idx, local_vertices):
    return [v for v, cluster in zip(local_vertices, partition) if cluster == cluster_idx]

def get_ray_segment_size():
    return 64  # [G] Typical size in bytes for ray-segment metadata

def all_to_all_broadcast(local_data, num_processors):
    """Replicates local_data across all processors."""
    # [G] Standard MPI_Alltoallv or broadcast semantics
    return local_data

def object_space_local_clustering(global_graph_Qv, num_processors_A, local_cells_per_processor):
    local_clusters_per_processor = {}
    local_cluster_ids = {}
    global_cluster_id_counter = 0
    global_clustering_C = []
    global_mapping_Me = {}
    local_migration_costs = {}

    for proc_id in range(num_processors_A):
        # Step 1: Local Graph Construction
        local_graph_Qk = build_subgraph(global_graph_Qv, local_cells_per_processor[proc_id])

        # Step 2: Local Clustering
        total_cells = len(local_cells_per_processor[proc_id])
        # [G] Proportional split based on node weight/cell count
        q_k = max(1, total_cells // num_processors_A)

        partition = metis_partition(local_graph_Qk, q_k)

        local_clusters = []
        local_global_ids = []
        for cluster_idx in range(q_k):
            cluster_cells = get_cells_in_partition(partition, cluster_idx, local_cells_per_processor[proc_id])
            cluster_vertices = get_vertices_in_partition(partition, cluster_idx, local_cells_per_processor[proc_id])

            cluster_data = ClusterData(VertexArray(cluster_vertices), CellArray(cluster_cells))

            # Step 4: Connectivity Update
            for cell in cluster_data.cell_array.cells:
                for neighbor_idx in range(4):
                    neighbor_global_id = cell.get_neighbor_global_id(neighbor_idx)
                    if neighbor_global_id is not None:
                        neighbor_proc = get_processor_for_cell(neighbor_global_id, local_cells_per_processor)
                        neighbor_cluster_id = get_cluster_id_for_cell(neighbor_global_id, partition)
                        neighbor_local_index = cluster_cells.index(neighbor_global_id)
                        cell.neighbor_info[neighbor_idx] = (neighbor_cluster_id, neighbor_local_index)

            local_clusters.append(cluster_data)
            local_global_ids.append(global_cluster_id_counter)
            global_cluster_id_counter += 1

        local_clusters_per_processor[proc_id] = local_clusters
        local_cluster_ids[proc_id] = local_global_ids

        # Step 7: Migration Cost Calculation (local)
        ray_seg_size = get_ray_segment_size()
        for gid in local_global_ids:
            cost = local_clusters_per_processor[proc_id][gid % q_k].data_size / ray_seg_size
            local_migration_costs[gid] = cost

    # Step 3: Global Identifier Assignment & Mapping
    for proc_id in range(num_processors_A):
        for gid in local_cluster_ids[proc_id]:
            global_clustering_C.append(local_clusters_per_processor[proc_id][gid % q_k])
            global_mapping_Me[gid] = proc_id

    # Step 5 & 6: Contracted Graph Construction & Replication
    local_portions_Qc = {}
    for proc_id in range(num_processors_A):
        local_portions_Qc[proc_id] = build_local_contracted_graph(global_clustering_C, global_mapping_Me, proc_id)
    global_Qc = all_to_all_broadcast(local_portions_Qc, num_processors_A)

    # Step 7: Migration Cost Broadcast
    global_migration_costs_Tc = all_to_all_broadcast(local_migration_costs, num_processors_A)

    return global_clustering_C, global_mapping_Me, global_Qc, global_migration_costs_Tc

def build_local_contracted_graph(global_clustering_C, global_mapping_Me, proc_id):
    local_clusters = [c for c in global_clustering_C if global_mapping_Me[global_clustering_C.index(c)] == proc_id]
    local_edges = []
    for i, c_i in enumerate(global_clustering_C):
        for j, c_j in enumerate(global_clustering_C):
            if i >= j: continue
            if share_face(c_i, c_j):
                local_edges.append((global_clustering_C.index(c_i), global_clustering_C.index(c_j)))
    return {'nodes': [global_clustering_C.index(c) for c in local_clusters], 'edges': local_edges}

def share_face(cluster_i, cluster_j):
    for cell in cluster_i.cell_array.cells:
        for neighbor_info in cell.neighbor_info:
            if neighbor_info and neighbor_info[0] == global_clustering_C.index(cluster_j):
                return True
    return False

def get_processor_for_cell(cell_id, local_cells_per_processor):
    for p, cells in local_cells_per_processor.items():
        if cell_id in cells: return p
    return -1

def get_cluster_id_for_cell(cell_id, partition):
    # [G] Assumes partition maps cell indices to cluster indices
    return partition[local_cells_per_processor[get_processor_for_cell(cell_id, local_cells_per_processor)].index(cell_id)]
```

## Subtopics

### [Remapping Phase](4250-remapping-phase.md)
The Remapping Phase is a view-dependent preprocessing step in chunk-based spatial partitioning for parallel volume rendering, designed to reassign data clusters to processors based on the current viewing parameters. It solves load imbalance and communication overhead when the camera changes, ensuring clusters with high interaction remain co-located. It adapts the static clustering solution from Object-space decomposition with local clustering to the current view via a dynamic graph-partitioning loop.

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Requires storing `ClusterData` for local clusters, `ClusterMapArray` for all global clusters, and a full copy of the contracted graph $Q_c$ on each processor [S1, unofficial].
- **Measured Performance**: Not given in the sources.
- **Strengths**: Minimizes view-independent preprocessing overhead by performing clustering locally [S1, unofficial]. The contracted graph topology is view-independent, reducing recomputation during view changes [S1, unofficial]. The migration cost function is also view-independent [S1, unofficial].
- **Limitations**: Requires significant communication (all-to-all broadcasts) to synchronize cluster mappings and migration costs [S1, unofficial]. The local clustering may not produce a globally optimal partition without further refinement (handled in the Remapping Phase) [S1, unofficial].
- **When to use**: Suitable for unstructured grid volume rendering where view-dependent load balancing is critical, and the overhead of global graph partitioning is too high [S1, unofficial]. Best used in conjunction with the Remapping Phase [S1, unofficial].
- **When not**: Not suitable for static views where a single global partition would suffice, or for systems with very high communication latency where all-to-all broadcasts are prohibitive.

## Background
Originated in the context of parallel direct volume rendering of unstructured grids [S1, unofficial]. The method was proposed to address the limitations of global partitioning approaches by leveraging local clustering with MeTiS to reduce preprocessing overhead [S1, unofficial]. It is part of a broader framework that includes a Remapping Phase for dynamic adaptation to viewing parameters [S1, unofficial].
