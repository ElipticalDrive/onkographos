# Improved Reading Algorithm with Pre-processing

Also called: Algorithm for Improved Reading of Volume Datasets from Storage

## Overview
This method extends the base Priority-Based Volume Dataset Rearrangement algorithm by introducing pre-processing steps that segment voxels into foreground/background and surface/interior categories before assigning priorities [S1]. It enables the immediate visualization of the surface (Segment $S_0$) with full interaction while less important segments load in the background, significantly reducing the time to first surface view compared to loading the whole dataset [S1].

## How it works
**Inputs:**
1. Volume dataset $R[X, Y, Z]$, a regular 3D grid of voxels where $X, Y, Z \in \mathbb{N}$ [S1].
2. Voxel value $v[x, y, z] \in R$ for $x \in [0, X-1], y \in [0, Y-1], z \in [0, Z-1]$, with $v \in [0, \nu_{max}]$ [S1].
3. Data block dimensions $B_x \in [1, X], B_y \in [1, Y], B_z \in [1, Z]$ [S1].
4. Number of priority levels $\rho_{max} = 4$ [S1].
5. Threshold $\tau \in [0, \nu_{max}]$ [S1].

**Outputs:**
1. Segmentation metadata $R''$ [S1].
2. Linearized rearranged volume dataset $R'$ [S1].

**Data Structures:**
*   **Grid $R_s[X, Y, Z]$**: Binary grid storing segmentation results from Step P1. Values are 0 or 1 [S1].
*   **Segments $\Phi = \{U_0, U_1, U_2, U_3\}$**: Partition of $R$ where each voxel belongs to exactly one set [S1].
    *   $U_0$: Surface of the region of interest (foreground) [S1].
    *   $U_1$: Important interior voxels (foreground) [S1].
    *   $U_2$: Unimportant interior voxels (foreground) [S1].
    *   $U_3$: Background voxels [S1].
*   **Segments $S_0, S_1, S_2, S_3$**: Sets of data blocks assigned priority levels 0, 1, 2, and 3 respectively [S1].

**Steps:**

1.  **Step P1 (Binarization):** Decompose $R$ into two segments $T_0$ (unimportant/background) and $T_1$ (important/foreground) using threshold $\tau$ [S1]. Create grid $R_s$ [S1]:
    $$
    R_s[x, y, z] = \begin{cases} 
    0 & \text{if } R[x, y, z] < \tau \\
    1 & \text{if } R[x, y, z] \ge \tau 
    \end{cases}
    $$
    Define segments:
    $$
    T_0 = \{ (x,y,z) \mid R_s[x, y, z] = 0 \}
    $$
    $$
    T_1 = \{ (x,y,z) \mid R_s[x, y, z] = 1 \}
    $$
    $$
    R = T_0 \cup T_1
    $$
    [S1]

2.  **Step P2 (Detailed Segmentation):** Segment $R$ into $\Phi = \{U_0, U_1, U_2, U_3\}$ [S1].
    *   **Step P2a (Border Examination):** Examine border voxels: $z=0, z=Z-1, y=0, y=Y-1, x=0, x=X-1$ [S1].
        *   If a border voxel is in $T_0$, add it to $U_3$ and mark it as a flood fill start point [S1].
        *   If a border voxel is in $T_1$, add it to $U_0$ [S1].
    *   **Step P2b (Flood Fill):** Perform flood fill from all start points identified in P2a [S1].
        *   For each reached voxel in $T_0$ not already in $U_3$, add it to $U_3$ and use it as a new start point for further flood fill [S1].
        *   For each reached voxel in $T_1$ not already in $U_0$, add it to $U_0$ (do not use as start point) [S1].
        *   Stop when all reached voxels are in $U_0$ or $U_3$ and no start points remain [S1].
    *   **Step P2c (Remaining Assignment):**
        *   Voxels in $T_0$ not in $U_3$ are added to $U_2$ [S1].
        *   Voxels in $T_1$ not in $U_0$ are added to $U_1$ [S1].

3.  **Step 1 (Identical to Base Algorithm):** Perform the segmentation and metadata generation steps defined in the parent article [S1].

4.  **Step 2 (Priority Assignment):** Map voxel segments to data block priorities using function $f$ [S1]:
    *   **Segment $S_0$ (Priority 0):** Data blocks containing at least one voxel from $U_0$ [S1].
    *   **Segment $S_1$ (Priority 1):** Data blocks containing at least one voxel from $U_1$, containing no voxels from $U_0$ or $U_3$, and may contain voxels from $U_2$ [S1].
    *   **Segment $S_2$ (Priority 2):** Data blocks homogeneously filled with voxels from $U_2$ [S1].
    *   **Segment $S_3$ (Priority 3):** Data blocks homogeneously filled with voxels from $U_3$ [S1].

5.  **Step 3-5 (Identical to Base Algorithm):** Perform the remaining rearrangement steps from the parent article to produce $R'$ [S1].

**Pseudocode:**

```python
def improved_reading_algorithm(R, X, Y, Z, Bx, By, Bz, tau):
    # Step P1: Binarization
    Rs = zeros((X, Y, Z), dtype=int)
    T0 = set()
    T1 = set()
    
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                val = R[x, y, z]
                if val < tau:
                    Rs[x, y, z] = 0
                    T0.add((x, y, z))
                else:
                    Rs[x, y, z] = 1
                    T1.add((x, y, z))
                    
    # Step P2: Detailed Segmentation
    U0 = set()
    U1 = set()
    U2 = set()
    U3 = set()
    
    # Step P2a: Border Examination
    start_points = []
    
    # Define border coordinates
    border_coords = []
    for x in range(X):
        border_coords.append((x, 0, 0))
        border_coords.append((x, Y-1, 0))
        border_coords.append((x, 0, Z-1))
        border_coords.append((x, Y-1, Z-1))
    for y in range(1, Y-1):
        border_coords.append((0, y, 0))
        border_coords.append((X-1, y, 0))
        border_coords.append((0, y, Z-1))
        border_coords.append((X-1, y, Z-1))
    for z in range(1, Z-1):
        border_coords.append((0, 0, z))
        border_coords.append((X-1, 0, z))
        border_coords.append((0, Y-1, z))
        border_coords.append((X-1, Y-1, z))
        
    for coord in border_coords:
        x, y, z = coord
        if Rs[x, y, z] == 0:
            U3.add(coord)
            start_points.append(coord)
        else:
            U0.add(coord)
            
    # Step P2b: Flood Fill
    queue = list(start_points)
    visited_start_points = set(start_points)
    
    while queue:
        curr = queue.pop(0)
        cx, cy, cz = curr
        
        # Check neighbors (6-connectivity)
        neighbors = [
            (cx+1, cy, cz), (cx-1, cy, cz),
            (cx, cy+1, cz), (cx, cy-1, cz),
            (cx, cy, cz+1), (cx, cy, cz-1)
        ]
        
        for nx, ny, nz in neighbors:
            if 0 <= nx < X and 0 <= ny < Y and 0 <= nz < Z:
                if Rs[nx, ny, nz] == 0:
                    if (nx, ny, nz) not in U3:
                        U3.add((nx, ny, nz))
                        queue.append((nx, ny, nz))
                else: # Rs == 1
                    if (nx, ny, nz) not in U0:
                        U0.add((nx, ny, nz))
                        
    # Step P2c: Remaining Assignment
    for coord in T0:
        if coord not in U3:
            U2.add(coord)
            
    for coord in T1:
        if coord not in U0:
            U1.add(coord)
            
    # Step 2: Priority Assignment
    # Note: Implementation of block mapping requires iterating over data blocks
    # defined by Bx, By, Bz. This is a conceptual representation.
    S0 = [] # Priority 0
    S1 = [] # Priority 1
    S2 = [] # Priority 2
    S3 = [] # Priority 3
    
    # Iterate through all data blocks
    for bx in range(0, X, Bx):
        for by in range(0, Y, By):
            for bz in range(0, Z, Bz):
                block_voxels = []
                for x in range(bx, min(bx+Bx, X)):
                    for y in range(by, min(by+By, Y)):
                        for z in range(bz, min(bz+Bz, Z)):
                            block_voxels.append((x, y, z))
                            
                has_u0 = any(v in U0 for v in block_voxels)
                has_u1 = any(v in U1 for v in block_voxels)
                has_u2 = any(v in U2 for v in block_voxels)
                has_u3 = any(v in U3 for v in block_voxels)
                
                if has_u0:
                    S0.append((bx, by, bz))
                elif has_u1 and not has_u0 and not has_u3:
                    S1.append((bx, by, bz))
                elif has_u2 and not has_u0 and not has_u1 and not has_u3:
                    S2.append((bx, by, bz))
                elif has_u3 and not has_u0 and not has_u1 and not has_u2:
                    S3.append((bx, by, bz))
                else:
                    # Fallback for mixed blocks not fitting strict homogeneous criteria
                    # The source specifies S2/S3 as homogeneously filled.
                    # If a block has mixed U1/U2 without U0/U3, it falls into S1 logic 
                    # if it has U1. If it has only U2, it is S2.
                    # The source says S1: "contains at least one U1... and can contain U2".
                    # So if has_u1 is true, it is S1 (provided no U0/U3).
                    pass 
                    
    # Return metadata and rearranged dataset structure
    return metadata, rearranged_dataset
```

**Parameters:**
*   $\tau$: Threshold value for binarization. Range: $[0, \nu_{max}]$ [S1].
*   $\nu_{max}$: Maximal voxel value in the dataset [S1].

**Edge Cases and Pitfalls:**
*   The flood fill in Step P2b stops when all reached voxels are in $U_0$ or $U_3$ [S1].
*   Data blocks in $S_1$ may contain voxels from $U_2$ but must not contain $U_0$ or $U_3$ [S1].
*   Data blocks in $S_2$ and $S_3$ must be homogeneously filled with $U_2$ and $U_3$ voxels respectively [S1].

## Background
The algorithm was proposed by B. Madoš et al. in 2021 [S1]. It is an extension of the base rearrangement algorithm described in the same paper, designed to enhance user experience by prioritizing surface voxels [S1].
