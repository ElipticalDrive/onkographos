# Hardware-Assisted Volume Streaming

Also called: HAVS (Hardware-Assisted Volume Streaming), HAVS2, HAVS6

## Overview
Hardware-Assisted Volume Streaming (HAVS) is an irregular volume rendering technique that streams volumetric data to the GPU to perform rendering, addressing the memory limitations of storing entire large-scale volumes in GPU memory [S1, unofficial]. It distinguishes itself from sibling methods like HAPT by performing more accurate visibility sorting, while maintaining a flexible pipeline that does not require multiple rendering passes [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A large irregular volume dataset (e.g., tetrahedral meshes) that exceeds available GPU memory [S1, unofficial].
*   **Output:** A rendered image with correct alpha compositing [G].

**Data Structures:**
The method relies on streaming primitives (primitives or chunks) to the GPU [G]. Specific internal data structure layouts (e.g., exact byte packing of tetrahedra attributes) are not given in the sources [S1, unofficial]. The method avoids the high memory footprint of storing the whole volume (e.g., 144 bytes/tet for HARCn or 96 bytes/tet for HARCp) [S1, unofficial].

**Steps:**
1.  **Streaming:** The volume is partitioned and streamed to the GPU [G]. This allows rendering datasets that would otherwise require significant data transfer overhead if chunks were uploaded/downloaded repeatedly [S1, unofficial].
2.  **Visibility Sorting:** HAVS performs accurate visibility sorting on the GPU [G]. Unlike HAPT's centroid sort methods (HAPTQ, HAPTB, HAPTS), HAVS ensures correct fragment ordering for non-convex unstructured meshes [S1, unofficial].
3.  **Rendering:** The sorted fragments are rasterized and composited [G]. The implementation offers a flexible pipeline [S1, unofficial].

**Parameters:**
*   **HAVS2/HAVS6:** Variants exist (HAVS2, HAVS6) with different performance characteristics, but specific parameter definitions (e.g., sorting buffer sizes, stream chunk sizes) are not given in the sources [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Memory Limits:** Methods relying on storing the whole volume (like PTINT or HARC) suffer performance loss due to uploading/downloading animation frame chunks [S1, unofficial]. HAVS mitigates this via streaming [G].
*   **Sorting Accuracy:** HAVS provides more accurate visibility sorting than centroid-based approaches, which is critical for correct alpha compositing on irregular grids [S1, unofficial].

## Subtopics

### [Hardware Assisted Visibility Sorting (HAVS)](2918-hardware-assisted-visibility-sorting-havs.md)
Hardware Assisted Visibility Sorting (HAVS) is a hybrid volume rendering algorithm for unstructured grids that combines object-space sorting on the CPU with image-space fragment sorting on the GPU using a k-buffer. It is distinguished from its siblings by its reliance on a fixed-depth sorting network to handle visibility, offering a robust compromise between implementation complexity, image quality, and performance. It should be chosen when robust visibility handling for non-convex meshes is required, though it may produce artifacts if fragments are highly out of order.

## Operating characteristics
*   **Performance:** On a torso dataset, HAVS2 achieves 3.7 FPS and 4.01 M Tet/s. On a fighter dataset, HAVS2 achieves 2.9 FPS and 4.12 M Tet/s [S1, unofficial].
*   **Comparison:** HAVS methods gain approximately 50% in frame rates compared to HAPTQ x HAVS6 configurations and do not require multiple rendering passes [S1, unofficial].
*   **Memory:** HAVS avoids the high memory footprint of methods like HARCn (144 bytes/tet) and HARCp (96 bytes/tet) [S1, unofficial]. It is more efficient than PTINT for large datasets (e.g., turbulent jet sequence) which would require 3 GB of GPU memory to fit entirely [S1, unofficial].
*   **Strengths:** Accurate visibility sorting; flexible pipeline; no multiple passes; handles large volumes via streaming [S1, unofficial][G].
*   **Limitations:** Performance is lower than some other methods (e.g., HAPTS 3.9 FPS on torso) but offers better sorting accuracy [S1, unofficial].

## Background
HAVS is an irregular volume renderer that streams volume data [S1, unofficial]. It is one of the most popular irregular volume renderers [S1, unofficial]. It is related to the HAPT (Hardware-Assisted Projected Tetrahedra) family of algorithms [S1, unofficial].
