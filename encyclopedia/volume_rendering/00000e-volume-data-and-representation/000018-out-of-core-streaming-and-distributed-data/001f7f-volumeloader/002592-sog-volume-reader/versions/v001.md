# SOG Volume Reader

Also called: Recursive SOG Loader, Spherical Octree Grid Reader

## Overview
The SOG Volume Reader is a recursive algorithm that loads a hierarchical volumetric format (SOG) into a dense 3D grid, utilizing internal, empty, leaf, and pseudo-leaf node types to efficiently store and retrieve data [S1, S2, unofficial]. It differs from standard raw readers by parsing a binary header and recursively traversing an octree structure to populate the output array, allowing for sparse or compressed representations within the SOG format [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A binary file in SOG format.
- **Output:** A 3D `Volume` array of dimensions $(sx+1) \times (sy+1) \times (sz+1)$, where $sx, sy, sz$ are read from the header. The array is filled with voxel values.

**Data Structures:**
- **Header:** A single integer `sx` representing the base dimension. The volume is cubic with $sy = sx$ and $sz = sx$ [S1, S2, unofficial].
- **Node Types:** Defined by a `char type` read from the file:
    - `0`: Internal node.
    - `1`: Empty node.
    - `2`: Leaf node.
    - `3`: Pseudo-leaf node.
- **Volume Interface:**
    - `setDataAt(int x, int y, int z, float val)`: Sets the voxel value at coordinates $(x, y, z)$ [S1, unofficial].

**Parameters:**
- `off[3]`: The 3D offset of the current node's top-left corner in the global grid [S1, unofficial].
- `len`: The side length of the current node's sub-volume. It halves at each recursion level ($nlen = len / 2$) [S1, unofficial].
- `sg`: A signed char encoding the state for empty or leaf nodes [S1, unofficial].
- `writeData`: A boolean flag. If `false`, data writing is skipped during pseudo-leaf traversal [S1, unofficial].
- **Spacing:** Hardcoded to 1.0 for x, y, and z axes [S2, unofficial].

**Algorithm Steps:**
1. Open the file in binary mode.
2. Read the header integer `sx`.
3. Set `sy = sx` and `sz = sx`.
4. Allocate a `Volume` array of size $(sx+1, sy+1, sz+1)$ [S1, S2, unofficial].
5. Call the recursive function `readSOG(fin, vol, {0, 0, 0}, sx)` [S1, S2, unofficial].
6. Inside `readSOG(fin, vol, off, len, writeData = true)`:
    a. Read `type` (char) from the file [S1, unofficial].
    b. If `type == 0` (Internal):
        i. Calculate `nlen = len / 2` [S1, unofficial].
        ii. Loop `i, j, k` from 0 to 1:
            1. Compute `noff[0] = off[0] + i * nlen`, `noff[1] = off[1] + j * nlen`, `noff[2] = off[2] + k * nlen` [S1, unofficial].
            2. Recursively call `readSOG(fin, vol, noff, nlen, writeData)` [S1, unofficial].
    c. If `type == 1` (Empty):
        i. Read `sg` (char) [S1, unofficial].
        ii. If `writeData` is true:
            1. Loop `i, j, k` from 0 to `len` (Note: Source code implies iteration over the sub-volume, but the loop bound in the source snippet for empty nodes is `len`, which may cover the entire sub-block depending on implementation specifics. The source explicitly states `loop i,j,k from 0 to len` [S1, unofficial]).
            2. Call `vol->setDataAt(off[0]+i, off[1]+j, off[2]+k, -sg)` [S1, unofficial].
    d. If `type == 2` (Leaf):
        i. Read `sg` (char) [S1, unofficial].
        ii. Read `coord[3]` (float array) [S1, unofficial].
        iii. If `writeData` is true:
            1. Initialize bit counter `t = 0` [S1, unofficial].
            2. Loop `i, j, k` from 0 to 1:
                1. Compute `noff[0] = off[0] + i`, `noff[1] = off[1] + j`, `noff[2] = off[2] + k` [S1, unofficial].
                2. Set `vol->setDataAt(noff[0], noff[1], noff[2], -((sg >> t) & 1))` [S1, unofficial].
                3. Increment `t` [S1, unofficial].
    e. If `type == 3` (Pseudo-leaf):
        i. Read `sg` (char) [S1, unofficial].
        ii. Read `coord[3]` (float array) [S1, unofficial].
        iii. Loop `i, j, k` from 0 to 1:
            1. Compute `noff[0] = off[0] + i * nlen`, `noff[1] = off[1] + j * nlen`, `noff[2] = off[2] + k * nlen` [S1, unofficial].
            2. Recursively call `readSOG(fin, vol, noff, nlen, false)` [S1, unofficial].
    f. If `type` is not 0-3, handle error (e.g., print "Wrong! Type: %d") [S1, unofficial].

**Pseudocode:**
```python
def read_sog(fin, vol, off, length, write_data=True):
    """
    Recursively reads an SOG node.
    :param fin: File object, current position is at the node type byte.
    :param vol: Volume object with method setDataAt(x, y, z, val).
    :param off: Tuple (x, y, z) offset of the current node's top-left corner.
    :param length: Side length of the current node's sub-volume.
    :param write_data: Boolean flag to skip data writing for pseudo-leaves.
    """
    # Read node type
    type_byte = fin.read(1)
    if not type_byte:
        raise EOFError("Unexpected end of file")
    node_type = type_byte[0]

    if node_type == 0:  # Internal node
        nlen = length // 2
        for i in range(2):
            for j in range(2):
                for k in range(2):
                    noff = (off[0] + i * nlen, off[1] + j * nlen, off[2] + k * nlen)
                    read_sog(fin, vol, noff, nlen, write_data)

    elif node_type == 1:  # Empty node
        sg_byte = fin.read(1)
        if not sg_byte:
            raise EOFError("Unexpected end of file")
        sg = sg_byte[0]
        if write_data:
            # Note: Source specifies loop from 0 to len. 
            # Assuming this fills the sub-volume defined by 'length'.
            for i in range(length):
                for j in range(length):
                    for k in range(length):
                        vol.set_data_at(off[0] + i, off[1] + j, off[2] + k, -sg)

    elif node_type == 2:  # Leaf node
        sg_byte = fin.read(1)
        if not sg_byte:
            raise EOFError("Unexpected end of file")
        sg = sg_byte[0]
        
        # Read 3 floats for coordinates
        coord = []
        for _ in range(3):
            coord_bytes = fin.read(4)
            if not coord_bytes:
                raise EOFError("Unexpected end of file")
            coord.append(struct.unpack('f', coord_bytes)[0])

        if write_data:
            t = 0
            for i in range(2):
                for j in range(2):
                    for k in range(2):
                        noff = (off[0] + i, off[1] + j, off[2] + k)
                        # Extract bit t from sg, negate it
                        val = -((sg >> t) & 1)
                        vol.set_data_at(noff[0], noff[1], noff[2], val)
                        t += 1

    elif node_type == 3:  # Pseudo-leaf node
        sg_byte = fin.read(1)
        if not sg_byte:
            raise EOFError("Unexpected end of file")
        sg = sg_byte[0]
        
        # Read 3 floats for coordinates
        coord = []
        for _ in range(3):
            coord_bytes = fin.read(4)
            if not coord_bytes:
                raise EOFError("Unexpected end of file")
            coord.append(struct.unpack('f', coord_bytes)[0])

        nlen = length // 2
        for i in range(2):
            for j in range(2):
                for k in range(2):
                    noff = (off[0] + i * nlen, off[1] + j * nlen, off[2] + k * nlen)
                    # Recurse without writing data
                    read_sog(fin, vol, noff, nlen, False)

    else:
        raise ValueError(f"Wrong! Type: {node_type}")

def load_sog(filename):
    import struct
    
    with open(filename, 'rb') as fin:
        # Read header
        sx_bytes = fin.read(4)
        if not sx_bytes:
            raise EOFError("Empty file")
        sx = struct.unpack('i', sx_bytes)[0]
        
        sy = sx
        sz = sx
        
        # Allocate volume (size sx+1, sy+1, sz+1)
        # Note: Implementation of Volume class is assumed to exist externally
        vol = Volume(sx + 1, sy + 1, sz + 1)
        
        # Start recursive read
        read_sog(fin, vol, (0, 0, 0), sx)
        
    return vol
```

**Edge Cases and Pitfalls:**
- **Precision:** The coordinates in leaf and pseudo-leaf nodes are stored as `float`. The voxel values are derived from bit manipulation of a `char`, resulting in binary values (0 or 1) negated.
- **Boundaries:** The volume array is allocated with size `sx+1`. The offsets and loops must respect this boundary.
- **Degenerate Input:** If the file ends prematurely, an EOF error should be raised. Invalid node types trigger an error.
- **Empty Node Loop:** The source specifies looping `0` to `len` for empty nodes. This behavior fills the sub-volume. If `len` is large, this is computationally expensive compared to internal nodes.

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the total number of voxels in the output grid, as every voxel is eventually visited and set. However, the traversal overhead depends on the tree depth and branching factor.
- **Memory Complexity:** $O(N)$ for the output volume array. The recursion depth is $O(\log_2(sx))$.
- **Strengths:** Efficiently handles hierarchical data; supports sparse representations via empty and pseudo-leaf nodes.
- **Limitations:** Requires the entire output grid to be allocated in memory. The recursive nature may cause stack overflow for very deep trees if not optimized.
- **When to use:** When loading data specifically in the SOG format. Not suitable for other formats.

## Background
The SOG Volume Reader is part of the dual contouring library by Tao Ju [S1, S2, unofficial]. It was developed to support the loading of volumetric data for surface reconstruction algorithms, specifically dual contouring [S1, S2, unofficial]. The format and reader are associated with Tao Ju's work on implicit modeling and surface reconstruction [S1, S2, unofficial].
