# MinkowskiBroadcastAddition

Also called: BroadcastAddition, MinkowskiBroadcastBase with BroadcastMode.ELEMENTWISE_ADDITON

## Overview
MinkowskiBroadcastAddition broadcasts reduced global features to all input coordinates by adding them element-wise to the input sparse tensor features [S2, unofficial]. It solves the problem of injecting global context into a sparse tensor's local features while preserving the original coordinate structure [S2, unofficial]. It sets itself apart from [MinkowskiBroadcastMultiplication](8929-minkowskibroadcastmultiplication.md) by using addition instead of multiplication, and from [MinkowskiBroadcastConcatenation](8933-minkowskibroadcastconcatenation.md) by maintaining the original feature dimensionality rather than expanding it [S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A sparse tensor with features $\mathbf{x}_1$ and a coordinate map key [S2, unofficial].
- **Input Glob:** A sparse tensor with features $\mathbf{x}_2$ reduced to the origin [S2, unofficial].
- **Output:** A sparse tensor with the same coordinate map key as the input, containing the broadcasted features [S2, unofficial].

**Data Structures:**
- **SparseTensor:** Holds a feature tensor and coordinate metadata (coordinate map key, coordinate manager) [S2, unofficial].
- **Coordinate Map Key:** Identifies the coordinate system and resolution [S2, unofficial].
- **Coordinate Manager:** Manages the mapping between batch indices and coordinate rows [S2, unofficial].

**Parameters:**
- **operation_type:** Set to `BroadcastMode.ELEMENTWISE_ADDITON` [S2, unofficial].

**Steps:**
1. Initialize the output feature tensor with the same shape as the input features $\mathbf{x}_1$ [S2, unofficial].
2. Retrieve the batch indices and corresponding row indices for the input coordinates from the coordinate manager's origin map using the input's coordinate map key [S2, unofficial].
3. For each batch index $b$ and its associated rows:
   - Extract the global feature vector $\mathbf{x}_2$ for batch $b$ from the `input_glob` sparse tensor [S2, unofficial].
   - Add $\mathbf{x}_2$ element-wise to the input features $\mathbf{x}_{1, \mathbf{u}}$ for all coordinates $\mathbf{u}$ in the current batch [S2, unofficial].
4. Construct and return a new sparse tensor with the computed features, the original coordinate map key, and the original coordinate manager [S2, unofficial].

**Formula:**
$$ \mathbf{y}_\mathbf{u} = \mathbf{x}_{1, \mathbf{u}} + \mathbf{x}_2 \; \text{for} \; \mathbf{u} \in \mathcal{C}^\text{in} $$
Where:
- $\mathbf{y}_\mathbf{u}$ is the output feature vector at coordinate $\mathbf{u}$ [S2, unofficial].
- $\mathbf{x}_{1, \mathbf{u}}$ is the input feature vector at coordinate $\mathbf{u}$ [S2, unofficial].
- $\mathbf{x}_2$ is the global feature vector reduced to the origin [S2, unofficial].
- $\mathcal{C}^\text{in}$ is the set of input coordinates [S2, unofficial].

**Pseudocode:**
```python
from typing import List, Tuple, Any

class SparseTensor:
    def __init__(self, features: List[List[float]], coordinate_map_key: Any, coordinate_manager: Any):
        self.F = features
        self.coordinate_map_key = coordinate_map_key
        self.coordinate_manager = coordinate_manager

class CoordinateManager:
    def origin_map(self, key: Any) -> Tuple[List[int], List[List[int]]]:
        # Returns batch_indices and batch_rows mapping
        pass

def MinkowskiBroadcastAddition(input: SparseTensor, input_glob: SparseTensor) -> SparseTensor:
    # Initialize output features with the same shape as input features
    broadcast_feat = [[0.0] * len(input_glob.F[0]) for _ in range(len(input.F))]

    # Get batch indices and row indices for the input coordinates
    batch_indices, batch_rows = input.coordinate_manager.origin_map(input.coordinate_map_key)

    # Iterate over each batch and its corresponding rows
    for b, rows in zip(batch_indices, batch_rows):
        # Extract global feature vector for batch b
        global_feat = input_glob.F[b]

        # Add global feature to input features for all coordinates in this batch
        for i, row_idx in enumerate(rows):
            broadcast_feat[row_idx] = [x + y for x, y in zip(input.F[row_idx], global_feat)]

    # Return new SparseTensor with broadcasted features
    return SparseTensor(
        broadcast_feat,
        coordinate_map_key=input.coordinate_map_key,
        coordinate_manager=input.coordinate_manager,
    )
```

**Edge Cases and Pitfalls:**
- **Precision:** Ensure that the addition operation does not suffer from numerical instability, especially if feature values are very large or small [G].
- **Boundaries:** The output coordinates are identical to the input coordinates, so no boundary checks are needed for coordinate validity [S2, unofficial].
- **Degenerate Input:** If `input_glob` is empty or has incorrect dimensions, the operation will fail [G].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of input coordinates, as each coordinate's features are updated once [G].
- **Memory Complexity:** Linear with respect to the number of input coordinates, as a new feature tensor of the same size is created [G].
- **Strengths:** Simple and efficient way to inject global context; preserves coordinate structure [S2, unofficial].
- **Limitations:** Only supports element-wise addition; does not expand feature dimensions [S2, unofficial].
- **When to Use:** When global context needs to be added to local features without changing dimensionality [S2, unofficial].
- **When Not to Use:** When multiplicative interaction or feature expansion is required [G].

## Background
MinkowskiBroadcastAddition implements the addition variant of the Minkowski Broadcast operation [S2, unofficial]. It was introduced in the context of 4D Spatio-Temporal ConvNets, as described in "4D Spatio-Temporal ConvNets: Minkowski Convolutional Neural Networks" (CVPR'19) [S2, unofficial]. Source [S1, unofficial] provides a code snippet for `ELEMENTWISE_MULTIPLICATION`, while Source [S2, unofficial] specifies `ELEMENTWISE_ADDITION` for this method.
