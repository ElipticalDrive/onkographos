# MinkowskiBroadcast

Also called: Copy Broadcast

## Overview
MinkowskiBroadcast is a scattered assignment operation that propagates a single global feature vector, reduced to the origin, to all coordinates in a sparse tensor [S1, unofficial]. It attaches global context to local sparse features while preserving the original coordinate structure $\mathcal{C}^\text{in} = \mathcal{C}^\text{out}$ [S1, unofficial]. It differs from sibling methods like [MinkowskiBroadcastAddition](4204-scattered-assignment.md#minkowskibroadcastaddition) and [MinkowskiBroadcastMultiplication](4204-scattered-assignment.md#minkowskibroadcastmultiplication) by performing a pure copy operation, whereas those variants apply element-wise arithmetic [S1, unofficial]. It is distinct from [MinkowskiBroadcastConcatenation](4204-scattered-assignment.md#minkowskibroadcastconcatenation), which expands the feature dimension rather than replacing it [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input 1: `input`, a sparse tensor with coordinates $\mathcal{C}^\text{in}$ and features $\mathbf{x}_1$ [S1, unofficial].
- Input 2: `input_glob`, a sparse tensor containing global features $\mathbf{x}_2$ reduced to the origin [S1, unofficial].
- Output: A sparse tensor with coordinates $\mathcal{C}^\text{out} = \mathcal{C}^\text{in}$ and broadcast features $\mathbf{y}$ [S1, unofficial].

**Data Structures:**
- `SparseTensor`: A container holding a features tensor `F`, a `coordinate_map_key`, and a `coordinate_manager` [S1, unofficial].
- `broadcast_feat`: A dense tensor of shape `(len(input), input_glob.size()[1])` [S1, unofficial].

**Steps:**
1. Assert that both `input` and `input_glob` are sparse tensors [S1, unofficial].
2. Allocate `broadcast_feat` with the same dtype and device as `input.F`, sized `(len(input), input_glob.size()[1])` [S1, unofficial].
3. Retrieve batch indices and corresponding row indices for the origin from the input's coordinate manager: `batch_indices, batch_rows = input.coordinate_manager.origin_map(input.coordinate_map_key)` [S1, unofficial].
4. Iterate through each batch index `b` and its associated rows `rows`, assigning the global feature vector for batch `b` (`input_glob.F[b]`) to the corresponding rows in `broadcast_feat` [S1, unofficial].
5. Construct and return a new sparse tensor using `broadcast_feat`, the original `input.coordinate_map_key`, and `input.coordinate_manager` [S1, unofficial].

**Formula:**
For all input coordinates $\mathbf{u} \in \mathcal{C}^\text{in}$:
$$ \mathbf{y}_\mathbf{u} = \mathbf{x}_2 \; \text{for} \; \mathbf{u} \in \mathcal{C}^\text{in} $$
where $\mathbf{x}_2$ is the global feature vector reduced to the origin per batch index [S1, unofficial].

**Pseudocode:**
```python
class SparseTensor:
    def __init__(self, F, coordinate_map_key, coordinate_manager):
        self.F = F
        self.coordinate_map_key = coordinate_map_key
        self.coordinate_manager = coordinate_manager

class CoordinateManager:
    def origin_map(self, key):
        # Returns (batch_indices, batch_rows) mapping each batch to its coordinate rows
        pass

def minkowski_broadcast(input: SparseTensor, input_glob: SparseTensor) -> SparseTensor:
    assert isinstance(input, SparseTensor)
    assert isinstance(input_glob, SparseTensor)

    broadcast_feat = input.F.new(len(input), input_glob.size()[1])
    batch_indices, batch_rows = input.coordinate_manager.origin_map(input.coordinate_map_key)

    for b, rows in zip(batch_indices, batch_rows):
        broadcast_feat[rows] = input_glob.F[b]

    return SparseTensor(
        broadcast_feat,
        coordinate_map_key=input.coordinate_map_key,
        coordinate_manager=input.coordinate_manager,
    )
```

**Parameters and Edge Cases:**
- `input_glob` must contain exactly one feature vector per batch index present in `input` [S1, unofficial].
- The output coordinates are identical to the input coordinates: $\mathcal{C}^\text{in} = \mathcal{C}^\text{out}$ [S1, unofficial].

## Subtopics

### MinkowskiBroadcastAddition
Broadcasts reduced global features to all input coordinates by adding them element-wise to the input sparse tensor features [S1, unofficial]. The output coordinates are identical to the input coordinates [S1, unofficial]. It is chosen when global context should be added as a bias or residual to local features [S1, unofficial]. Formula: $\mathbf{y}_\mathbf{u} = \mathbf{x}_{1, \mathbf{u}} + \mathbf{x}_2 \; \text{for} \; \mathbf{u} \in \mathcal{C}^\text{in}$ [S1, unofficial].

### MinkowskiBroadcastMultiplication
Broadcasts reduced global features to all input coordinates by multiplying them element-wise with the input sparse tensor features [S1, unofficial]. The output coordinates are identical to the input coordinates [S1, unofficial]. It is chosen when global context should modulate local features (e.g., attention-like gating) [S1, unofficial]. Formula: $\mathbf{y}_\mathbf{u} = \mathbf{x}_{1, \mathbf{u}} \times \mathbf{x}_2 \; \text{for} \; \mathbf{u} \in \mathcal{C}^\text{in}$ [S1, unofficial].

### MinkowskiBroadcastConcatenation
Broadcasts reduced global features to all input coordinates and concatenates them to the input features along the feature dimension [S1, unofficial]. It is chosen when both local and global features need to be preserved and processed jointly in subsequent layers [S1, unofficial]. Formula: $\mathbf{y}_\mathbf{u} = [\mathbf{x}_{1,\mathbf{u}}, \mathbf{x}_2] \; \text{for} \; \mathbf{u} \in \mathcal{C}^\text{in}$ [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of active coordinates in the input sparse tensor, $O(|\mathcal{C}^\text{in}|)$, due to the iteration over batch rows [S1, unofficial].
- **Memory Complexity:** $O(|\mathcal{C}^\text{in}| \cdot d)$, where $d$ is the dimension of the global feature vector, for the `broadcast_feat` allocation [S1, unofficial].
- **Strengths:** Efficiently attaches global context to sparse data without changing coordinate topology [S1, unofficial].
- **Limitations:** Requires the global features to be pre-computed and aligned with the batch indices of the input [S1, unofficial].

## Background
MinkowskiBroadcast is part of the MinkowskiEngine library, which implements sparse tensor operations for 3D deep learning [S1, unofficial]. It is designed to work with sparse tensors where features are reduced to the origin (global pooling) and then broadcast back to the original sparse coordinates [S1, unofficial]. The method is commonly used in conjunction with [MinkowskiGlobalPooling](4204-scattered-assignment.md#minkowskiglobalpooling) to provide global context to local sparse features [S1, unofficial].
