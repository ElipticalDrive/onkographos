# Dual Grid Traversal for Adaptive Octree


## Overview
This method recursively traverses an adaptive octree to generate the vertices, edges, and faces of a dual grid structure [S1, unofficial]. It solves the problem of creating a manifold traversal mesh from non-uniform voxel data by explicitly handling boundaries between octree nodes of different refinement levels [S1, unofficial]. It differs from uniform grid duals by using a set of 2–8 surrounding octree nodes to define each dual vertex, allowing it to bridge gaps where large nodes abut smaller ones [S1, unofficial]. It builds on [Dual Grid Traversal](1233-dual-grid-traversal.md) by adapting the dual grid construction to the hierarchical nature of an octree [G].

## How it works
The algorithm generates `DualCell` objects by recursively visiting nodes in the octree [S1, unofficial]. It handles varying node depths by treating parent nodes as stand-ins for missing children [S1, unofficial]. The traversal is initiated from the root and proceeds through faces, edges, and vertices [S1, unofficial].

### Inputs and Outputs
*   **Input**: An adaptive octree root node (`OctreeNode`).
*   **Output**: A sequence of `DualCell` objects representing the dual grid cells (vertices in the dual grid, which correspond to junction points in the octree) [S1, unofficial].

### Data Structures
**OctreeNode**: Represents a node in the adaptive octree [G].
*   `Children`: An array of 8 `OctreeNode` pointers (or `null` if this is a leaf) [S1, unofficial].
*   (Implicit) Leaf status: Determined by `Children == null` [S1, unofficial].

**DualCell**: Represents a single cell in the dual grid [S1, unofficial].
*   `n0` through `n7`: Fields of type `OctreeNode` [S1, unofficial]. Each field stores a reference to one of the 8 octree nodes that surround the dual vertex [S1, unofficial].

### Algorithm Steps

#### 1. TraverseFace(n0, n1, axis)
Traverses the dual cells on the face between two adjacent octree nodes `n0` (min side) and `n1` (max side) perpendicular to `axis` [S1, unofficial].

1.  **Base Case**: If `n0.Children == null` AND `n1.Children == null`, both are leaves [S1, unofficial]. Yield break (no dual cells on this face between two leaves) [S1, unofficial].
2.  **Identify Child Nodes**: Determine the 4 child nodes on the 'min' side (`cA0`–`cA3`) and 4 on the 'max' side (`cB0`–`cB3`) touching the face [S1, unofficial].
    *   If a parent has no children (`Children == null`), all its corresponding child pointers are set to the parent itself [S1, unofficial].
    *   **Map indices for n0 (Side A)** based on `axis`:
        *   Axis 0 (X): `cA0=Children[1]`, `cA1=Children[2]`, `cA2=Children[6]`, `cA3=Children[5]` [S1, unofficial]
        *   Axis 1 (Y): `cA0=Children[4]`, `cA1=Children[5]`, `cA2=Children[6]`, `cA3=Children[7]` [S1, unofficial]
        *   Axis 2 (Z): `cA0=Children[3]`, `cA1=Children[2]`, `cA2=Children[6]`, `cA3=Children[7]` [S1, unofficial]
    *   **Map indices for n1 (Side B)** based on `axis`:
        *   Axis 0 (X): `cB0=Children[0]`, `cB1=Children[4]`, `cB2=Children[7]`, `cB3=Children[3]` [S1, unofficial]
        *   Axis 1 (Y): `cB0=Children[0]`, `cB1=Children[1]`, `cB2=Children[2]`, `cB3=Children[3]` [S1, unofficial]
        *   Axis 2 (Z): `cB0=Children[0]`, `cB1=Children[1]`, `cB2=Children[5]`, `cB3=Children[4]` [S1, unofficial]
3.  **Recursive Face Traversal**: Recursively call `TraverseFace` for the 4 sub-faces formed by child pairs: `(cA0,cB0)`, `(cA1,cB1)`, `(cA2,cB2)`, `(cA3,cB3)` [S1, unofficial].
4.  **Internal Edge and Vertex Traversal**: Traverse the internal edges and the central vertex of the face [S1, unofficial].
    *   **Axis 0 (X)**:
        *   Edges: `TraverseEdge(cA0,cB0,cB3,cA3, 1)`, `TraverseEdge(cA1,cB1,cB2,cA2, 1)`, `TraverseEdge(cA0,cB0,cB1,cA1, 2)`, `TraverseEdge(cA3,cB3,cB2,cA2, 2)` [S1, unofficial]
        *   Vertex: `TraverseVertex(cA0,cB0,cB3,cA3, cA1,cB1,cB2,cA2)` [S1, unofficial]
    *   **Axis 1 (Y)**:
        *   Edges: `TraverseEdge(cA0,cA3,cB3,cB0, 0)`, `TraverseEdge(cA1,cA2,cB2,cB1, 0)`, `TraverseEdge(cA0,cA1,cB1,cB0, 2)`, `TraverseEdge(cA3,cA2,cB2,cB3, 2)` [S1, unofficial]
        *   Vertex: `TraverseVertex(cA0,cA1,cA2,cA3, cB0,cB1,cB2,cB3)` [S1, unofficial]
    *   **Axis 2 (Z)**:
        *   Edges: `TraverseEdge(cA0,cB0,cB3,cA3, 0)`, `TraverseEdge(cA1,cB1,cB2,cA2, 0)`, `TraverseEdge(cA0,cA1,cB1,cB0, 1)`, `TraverseEdge(cA3,cA2,cB2,cB3, 1)` [S1, unofficial]
        *   Vertex: `TraverseVertex(cA0,cA1,cB1,cB0, cA3,cA2,cB2,cB3)` [S1, unofficial]

#### 2. TraverseEdge(n00, n10, n11, n01, axis)
Traverses the dual cells on the edge shared by four octree nodes. The nodes are ordered relative to the edge axis [S1, unofficial].
*   For X edges: `(MinYZ, MinYMaxZ, MaxYZ, MaxYMinZ)` [S1, unofficial]
*   For Y edges: `(MinXZ, MaxXMinZ, MaxXZ, MinXMaxZ)` [S1, unofficial]
*   For Z edges: `(MinXY, MaxXMinY, MaxXY, MinXMaxY)` [S1, unofficial]

1.  **Base Case**: If `n00.Children == null` AND `n01.Children == null` AND `n10.Children == null` AND `n11.Children == null`, all are leaves [S1, unofficial]. Yield break [S1, unofficial].
2.  **Identify Child Nodes**: Gather 8 child nodes (`cA0,cA1` for `n00`/A; `cB0,cB1` for `n10`/B; `cC0,cC1` for `n11`/C; `cD0,cD1` for `n01`/D) [S1, unofficial].
    *   If a parent has no children, both its child pointers are set to the parent [S1, unofficial].
    *   **Map indices for n00 (A)** based on `axis`:
        *   Axis 0 (X): `cA0=Children[7]`, `cA1=Children[6]` [S1, unofficial]
        *   Axis 1 (Y): `cA0=Children[2]`, `cA1=Children[6]` [S1, unofficial]
        *   Axis 2 (Z): `cA0=Children[5]`, `cA1=Children[6]` [S1, unofficial]
    *   **Map indices for n10 (B)** based on `axis`:
        *   Axis 0 (X): `cB0=Children[4]`, `cB1=Children[5]` [S1, unofficial]
        *   Axis 1 (Y): `cB0=Children[3]`, `cB1=Children[7]` [S1, unofficial]
        *   Axis 2 (Z): `cB0=Children[4]`, `cB1=Children[7]` [S1, unofficial]
    *   **Map indices for n11 (C)** based on `axis`:
        *   Axis 0 (X): `cC0=Children[0]`, `cC1=Children[1]` [S1, unofficial]
        *   Axis 1 (Y): `cC0=Children[0]`, `cC1=Children[4]` [S1, unofficial]
        *   Axis 2 (Z): `cC0=Children[0]`, `cC1=Children[3]` [S1, unofficial]
    *   **Map indices for n01 (D)** based on `axis`:
        *   Axis 0 (X): `cD0=Children[3]`, `cD1=Children[2]` [S1, unofficial]
        *   Axis 1 (Y): `cD0=Children[1]`, `cD1=Children[5]` [S1, unofficial]
        *   Axis 2 (Z): `cD0=Children[1]`, `cD1=Children[2]` [S1, unofficial]
3.  **Recursive Edge Traversal**: Recursively call `TraverseEdge` for the two child edges: `(cA0, cB0, cC0, cD0)` and `(cA1, cB1, cC1, cD1)` [S1, unofficial].
4.  **Central Vertex Traversal**: Traverse the central vertex of the edge [S1, unofficial].
    *   **Axis 0 (X)**: `TraverseVertex(cA0, cA1, cB1, cB0, cD0, cD1, cC1, cC0)` [S1, unofficial]
    *   **Axis 1 (Y)**: `TraverseVertex(cA0, cB0, cC0, cD0, cA1, cB1, cC1, cD1)` [S1, unofficial]
    *   **Axis 2 (Z)**: `TraverseVertex(cA0, cB0, cB1, cA1, cD0, cC0, cC1, cD1)` [S1, unofficial]

#### 3. TraverseVertex(n0..n7)
Traverses the dual cell at the vertex where 8 octree nodes meet [S1, unofficial].

1.  **Recursive Check**: If any of the 8 nodes (`n0` through `n7`) has children (`Children != null`), recursively call `TraverseVertex` on the specific child indices: `n0` -> `Children[6]`, `n1` -> `Children[7]`, `n2` -> `Children[4]`, `n3` -> `Children[5]`, `n4` -> `Children[2]`, `n5` -> `Children[3]`, `n6` -> `Children[0]`, `n7` -> `Children[1]` [S1, unofficial].
2.  **Yield Cell**: If all 8 nodes are leaves (`Children == null`), create a `DualCell` object, assign the 8 nodes to fields `n0` through `n7`, and yield the cell [S1, unofficial].

### Pseudocode
```python
def traverse_octree(root):
    """
    Initiates the dual grid traversal from the root of the octree.
    Calls the recursive functions on the root's 8 children following standard octree topology [G].
    """
    if root.Children is None:
        return

    # Internal faces
    yield from traverse_face(root.Children[0], root.Children[1], 0)
    yield from traverse_face(root.Children[2], root.Children[3], 0)
    yield from traverse_face(root.Children[4], root.Children[5], 0)
    yield from traverse_face(root.Children[6], root.Children[7], 0)
    yield from traverse_face(root.Children[0], root.Children[2], 1)
    yield from traverse_face(root.Children[1], root.Children[3], 1)
    yield from traverse_face(root.Children[4], root.Children[6], 1)
    yield from traverse_face(root.Children[5], root.Children[7], 1)
    yield from traverse_face(root.Children[0], root.Children[4], 2)
    yield from traverse_face(root.Children[1], root.Children[5], 2)
    yield from traverse_face(root.Children[2], root.Children[6], 2)
    yield from traverse_face(root.Children[3], root.Children[7], 2)

    # Internal edges
    yield from traverse_edge(root.Children[0], root.Children[1], root.Children[2], root.Children[3], 1)
    yield from traverse_edge(root.Children[4], root.Children[5], root.Children[6], root.Children[7], 1)
    yield from traverse_edge(root.Children[3], root.Children[2], root.Children[6], root.Children[7], 2)
    yield from traverse_edge(root.Children[0], root.Children[1], root.Children[5], root.Children[4], 2)
    yield from traverse_edge(root.Children[0], root.Children[2], root.Children[4], root.Children[6], 0)
    yield from traverse_edge(root.Children[1], root.Children[3], root.Children[5], root.Children[7], 0)
    yield from traverse_edge(root.Children[0], root.Children[4], root.Children[1], root.Children[5], 0)
    yield from traverse_edge(root.Children[2], root.Children[6], root.Children[3], root.Children[7], 0)

    # Central vertex
    yield from traverse_vertex(root.Children[0], root.Children[1], root.Children[2], root.Children[3],
                               root.Children[4], root.Children[5], root.Children[6], root.Children[7])

def traverse_face(n0, n1, axis):
    if n0.Children is None and n1.Children is None:
        return

    if n0.Children is None:
        cA0 = cA1 = cA2 = cA3 = n0
    else:
        if axis == 0: cA0, cA1, cA2, cA3 = n0.Children[1], n0.Children[2], n0.Children[6], n0.Children[5]
        elif axis == 1: cA0, cA1, cA2, cA3 = n0.Children[4], n0.Children[5], n0.Children[6], n0.Children[7]
        elif axis == 2: cA0, cA1, cA2, cA3 = n0.Children[3], n0.Children[2], n0.Children[6], n0.Children[7]

    if n1.Children is None:
        cB0 = cB1 = cB2 = cB3 = n1
    else:
        if axis == 0: cB0, cB1, cB2, cB3 = n1.Children[0], n1.Children[4], n1.Children[7], n1.Children[3]
        elif axis == 1: cB0, cB1, cB2, cB3 = n1.Children[0], n1.Children[1], n1.Children[2], n1.Children[3]
        elif axis == 2: cB0, cB1, cB2, cB3 = n1.Children[0], n1.Children[1], n1.Children[5], n1.Children[4]

    yield from traverse_face(cA0, cB0, axis)
    yield from traverse_face(cA1, cB1, axis)
    yield from traverse_face(cA2, cB2, axis)
    yield from traverse_face(cA3, cB3, axis)

    if axis == 0:
        yield from traverse_edge(cA0, cB0, cB3, cA3, 1)
        yield from traverse_edge(cA1, cB1, cB2, cA2, 1)
        yield from traverse_edge(cA0, cB0, cB1, cA1, 2)
        yield from traverse_edge(cA3, cB3, cB2, cA2, 2)
        yield from traverse_vertex(cA0, cB0, cB3, cA3, cA1, cB1, cB2, cA2)
    elif axis == 1:
        yield from traverse_edge(cA0, cA3, cB3, cB0, 0)
        yield from traverse_edge(cA1, cA2, cB2, cB1, 0)
        yield from traverse_edge(cA0, cA1, cB1, cB0, 2)
        yield from traverse_edge(cA3, cA2, cB2, cB3, 2)
        yield from traverse_vertex(cA0, cA1, cA2, cA3, cB0, cB1, cB2, cB3)
    elif axis == 2:
        yield from traverse_edge(cA0, cB0, cB3, cA3, 0)
        yield from traverse_edge(cA1, cB1, cB2, cA2, 0)
        yield from traverse_edge(cA0, cA1, cB1, cB0, 1)
        yield from traverse_edge(cA3, cA2, cB2, cB3, 1)
        yield from traverse_vertex(cA0, cA1, cB1, cB0, cA3, cA2, cB2, cB3)

def traverse_edge(n00, n10, n11, n01, axis):
    if n00.Children is None and n01.Children is None and n10.Children is None and n11.Children is None:
        return

    if n00.Children is None: cA0 = cA1 = n00
    else:
        if axis == 0: cA0, cA1 = n00.Children[7], n00.Children[6]
        elif axis == 1: cA0, cA1 = n00.Children[2], n00.Children[6]
        elif axis == 2: cA0, cA1 = n00.Children[5], n00.Children[6]

    if n10.Children is None: cB0 = cB1 = n10
    else:
        if axis == 0: cB0, cB1 = n10.Children[4], n10.Children[5]
        elif axis == 1: cB0, cB1 = n10.Children[3], n10.Children[7]
        elif axis == 2: cB0, cB1 = n10.Children[4], n10.Children[7]

    if n11.Children is None: cC0 = cC1 = n11
    else:
        if axis == 0: cC0, cC1 = n11.Children[0], n11.Children[1]
        elif axis == 1: cC0, cC1 = n11.Children[0], n11.Children[4]
        elif axis == 2: cC0, cC1 = n11.Children[0], n11.Children[3]

    if n01.Children is None: cD0 = cD1 = n01
    else:
        if axis == 0: cD0, cD1 = n01.Children[3], n01.Children[2]
        elif axis == 1: cD0, cD1 = n01.Children[1], n01.Children[5]
        elif axis == 2: cD0, cD1 = n01.Children[1], n01.Children[2]

    yield from traverse_edge(cA0, cB0, cC0, cD0, axis)
    yield from traverse_edge(cA1, cB1, cC1, cD1, axis)

    if axis == 0: yield from traverse_vertex(cA0, cA1, cB1, cB0, cD0, cD1, cC1, cC0)
    elif axis == 1: yield from traverse_vertex(cA0, cB0, cC0, cD0, cA1, cB1, cC1, cD1)
    elif axis == 2: yield from traverse_vertex(cA0, cB0, cB1, cA1, cD0, cC0, cC1, cD1)

def traverse_vertex(n0, n1, n2, n3, n4, n5, n6, n7):
    if n0.Children is not None: n0 = n0.Children[6]
    if n1.Children is not None: n1 = n1.Children[7]
    if n2.Children is not None: n2 = n2.Children[4]
    if n3.Children is not None: n3 = n3.Children[5]
    if n4.Children is not None: n4 = n4.Children[2]
    if n5.Children is not None: n5 = n5.Children[3]
    if n6.Children is not None: n6 = n6.Children[0]
    if n7.Children is not None: n7 = n7.Children[1]

    if n0.Children is None and n1.Children is None and n2.Children is None and n3.Children is None and \
       n4.Children is None and n5.Children is None and n6.Children is None and n7.Children is None:
        yield DualCell(n0, n1, n2, n3, n4, n5, n6, n7)
    else:
        yield from traverse_vertex(n0, n1, n2, n3, n4, n5, n6, n7)
```

### Parameters
*   `axis`: Integer 0, 1, or 2 representing X, Y, or Z respectively [S1, unofficial].

### Edge Cases and Pitfalls
*   **Missing Children**: When a node is a leaf, its "children" are treated as the node itself in the mapping logic. This ensures that the dual grid structure remains connected across boundaries of different refinement levels [S1, unofficial].
*   **Shared Z Edge Orientation**: In `TraverseEdge` for shared Z edges, the Y order of child nodes is flipped compared to some reference implementations because the reference was deemed incorrect [S1, unofficial].
*   **Leaf Leaves**: If all 8 nodes surrounding a dual vertex are leaves, the recursion stops, and a `DualCell` is yielded. If any node has children, the recursion continues deeper [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Not given in the sources. The algorithm is recursive and visits nodes based on the octree structure. The complexity depends on the number of nodes and the depth of the octree [G].
*   **Memory Complexity**: Not given in the sources. The algorithm yields cells one by one, so memory usage is proportional to the recursion depth and the number of active cells in the traversal stack [G].
*   **Strengths**: Handles adaptive octrees with varying levels of detail seamlessly. Generates a manifold dual grid structure [S1, unofficial].
*   **Limitations**: The recursive nature may lead to deep recursion stacks for very deep octrees. The complexity of child index mapping is high and error-prone to implement [G].
*   **When to use**: When rendering or processing data stored in an adaptive octree and a dual grid representation is needed for isosurface extraction or other geometric operations [G].
*   **When not to use**: For uniform grids, a simpler dual grid traversal is more efficient. For non-manifold requirements, this method may be overkill [G].
