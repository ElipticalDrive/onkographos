# Compact Volume Rendering with Page-Table Indirection and Masked Storage

Also called: Brick-based rendering, Compact mode

## Overview
Compact Volume Rendering is a rendering mode that stores only selected groups of voxels (bricks) in a packed 2D array texture, using a page table for spatial indexing and an optional bitmask for sparse storage, to fit within a 1024 MiB GPU memory budget [S1, unofficial]. It differs from the original mode, which loads the full volume into a single 3D texture, by enabling rendering of datasets that exceed `MAX_3D_TEXTURE_SIZE` or the available GPU memory through spatial partitioning and indirection [S1, unofficial]. It builds on [Brick-based volume rendering with packed textures](7106-brick-based-volume-rendering-with-packed-textures.md) [G].

## How it works
**Inputs and Outputs:**
*   **Input:** A volume dataset, a memory budget (default 1024 MiB), and rendering parameters (`stepSize`, `cutoff`, `windowMax`) [S1, unofficial].
*   **Output:** GPU textures (`packed`, `pages`, `maskTexture`) and shader uniforms for ray marching [S1, unofficial].

**Data Structures:**
1.  **Packed Density Texture (`packed`):** `TEXTURE_2D_ARRAY` [S1, unofficial]. Dimensions `[packedWidth, packedHeight, layers]` [S1, unofficial]. Internal format `R16UI` or `R8UI` depending on `meta.bytes_per_voxel` [S1, unofficial]. Type `UNSIGNED_SHORT` or `UNSIGNED_BYTE` [S1, unofficial]. Bound to texture unit 0 [S1, unofficial].
2.  **Page Table Texture (`pages`):** `TEXTURE_3D` [S1, unofficial]. Dimensions `[meta.grid_xyz]` [S1, unofficial]. Internal format `RGBA32UI` [S1, unofficial]. Type `UNSIGNED_INT` [S1, unofficial]. Bound to texture unit 1 [S1, unofficial]. Each texel stores indices into the packed texture and mask texture [S1, unofficial].
3.  **Mask Texture (`maskTexture`):** `TEXTURE_2D_ARRAY` [S1, unofficial]. Dimensions `[maskWidth, maskHeight, maskLayers]` [S1, unofficial]. Internal format `RG32UI` [S1, unofficial]. Type `UNSIGNED_INT` [S1, unofficial]. Bound to texture unit 3 [S1, unofficial]. Used for sparse storage optimization [S1, unofficial].
4.  **Original Texture (`original`):** `TEXTURE_3D` placeholder `[1,1,1]` [S1, unofficial].

**Parameters:**
*   `budget`: Maximum GPU memory allocation, set to $1024 \times 1048576$ bytes (1024 MiB) [S1, unofficial].
*   `stepSize`: Step size for ray marching, passed from UI input [S1, unofficial].
*   `cutoff`: Display cutoff value for volume rendering [S1, unofficial].
*   `windowMax`: Window maximum for normalization [S1, unofficial].

**Algorithm Steps:**
1.  **Calculate Required Memory:** Sum `density_bytes` and `mask_bytes` for each selected group. Add `meta.page_bytes` and a fixed overhead of 131072 bytes. If the total exceeds `budget`, throw an error [S1, unofficial].
2.  **Determine Packed Texture Dimensions:** `packedWidth = min(MAX_TEXTURE_SIZE, total_voxel_count)`, `Layers = max(1, ceil(total_voxels / (MAX_TEXTURE_SIZE^2)))`, `Height = max(1, ceil(total_voxels / (packedWidth * Layers)))`, `packedHeight = Height` [S1, unofficial].
3.  **Allocate Arrays:** Allocate `padded` array of type `ArrayType` with size `packedWidth * height * layers`. Allocate `maskValues` array of type `Uint32Array` with size `maskWidth * maskHeight * maskLayers * 2`. Check if `padded.byteLength + maskValues.byteLength + meta.page_bytes > budget`. If so, throw an error [S1, unofficial].
4.  **Initialize Page Table and Populate Data:** Initialize `table` as `Uint32Array` of size `meta.page_bytes / 4`. Initialize `offset = 0` and `maskOffset = 0`. For each chosen group: load density values and index entries. If `storage_encoding` is `'masked32'`, load mask records and add `offset` to the first column of records. Write density values to `padded[offset]`. Update `table` entries: `table[cell] = entries[i+1] + (masked ? maskOffset : offset)`, `table[cell+1] = entries[i+2]`, `table[cell+2] = entries[i+3]`. Increment `offset` by `values.length`. If masked, increment `maskOffset` by `records.length / 2` [S1, unofficial].
5.  **Create GPU Textures:** Bind `packed` as `TEXTURE_2D_ARRAY` with dimensions `[packedWidth, height, layers]`. Bind `maskTexture` as `TEXTURE_2D_ARRAY` with dimensions `[maskWidth, maskHeight, maskLayers]`. Bind `pages` as `TEXTURE_3D` with dimensions `[meta.grid_xyz]`. Bind `original` as `TEXTURE_3D` `[1,1,1]` placeholder [S1, unofficial].
6.  **Fragment Shader Execution:** If `useTransfer` is true, compute factor $f$: if $d < 0.5$, $f = d \times 2$; else $f = (d - 0.5) \times 2$. Compute tint: if $d < 0.5$, `tint = mix(tfLow, tfMid, f)`; else `tint = mix(tfMid, tfHigh, f)`. Compute extinction: if $d < 0.5$, `extinction = mix(tfOpacity.x, tfOpacity.y, f)`; else `extinction = mix(tfOpacity.y, tfOpacity.z, f)`. Compute alpha: `alpha = 1.0 - exp(-extinction * stepSize)`. Update RGB: `rgb += remaining * alpha * tint`. Update remaining: `remaining *= 1.0 - alpha`. Increment `sampleIndex` [S1, unofficial].

**Pseudocode:**
```python
def compact_volume_rendering_setup(volume_meta, budget=1024 * 1048576):
    # Step 1: Calculate total bytes
    total_bytes = 0
    for group in volume_meta.selected_groups:
        total_bytes += group.density_bytes + group.mask_bytes
    total_bytes += volume_meta.page_bytes + 131072
    if total_bytes > budget:
        raise MemoryError("Exceeds budget")

    # Step 2: Determine dimensions
    total_voxels = volume_meta.total_voxels
    packed_width = min(volume_meta.max_texture_size, total_voxels)
    layers = max(1, (total_voxels + volume_meta.max_texture_size**2 - 1) // (volume_meta.max_texture_size**2))
    height = max(1, (total_voxels + packed_width * layers - 1) // (packed_width * layers))
    packed_height = height

    # Step 3: Allocate arrays
    padded = [0] * (packed_width * height * layers)
    mask_values = [0] * (volume_meta.mask_width * volume_meta.mask_height * volume_meta.mask_layers * 2)
    if len(padded) * volume_meta.bytes_per_voxel + len(mask_values) * 4 + volume_meta.page_bytes > budget:
        raise MemoryError("Allocation exceeds budget")

    # Step 4: Populate data
    table = [0] * (volume_meta.page_bytes // 4)
    offset = 0
    mask_offset = 0
    cell = 0
    for i, group in enumerate(volume_meta.selected_groups):
        density_values = group.load_density()
        entries = group.load_index_entries()
        masked = group.storage_encoding == 'masked32'
        if masked:
            mask_records = group.load_mask_records()
            for record in mask_records:
                record[0] += offset
        table[cell] = entries[1] + (mask_offset if masked else offset)
        table[cell + 1] = entries[2]
        table[cell + 2] = entries[3]
        for val in density_values:
            padded[offset] = val
            offset += 1
        if masked:
            mask_offset += len(mask_records) // 2
        cell += 3

    # Step 5: Create GPU textures
    # Allocate packed texture: TEXTURE_2D_ARRAY, [packed_width, packed_height, layers], R16UI/R8UI, UNSIGNED_SHORT/UNSIGNED_BYTE, unit 0 [G]
    packed_texture = allocate_texture_2d_array(packed_width, packed_height, layers, padded)
    # Allocate pages texture: TEXTURE_3D, [meta.grid_xyz], RGBA32UI, UNSIGNED_INT, unit 1 [G]
    pages_texture = allocate_texture_3d(volume_meta.grid_xyz, table)
    # Allocate mask texture: TEXTURE_2D_ARRAY, [mask_width, mask_height, mask_layers], RG32UI, UNSIGNED_INT, unit 3 [G]
    mask_texture = allocate_texture_2d_array(volume_meta.mask_width, volume_meta.mask_height, volume_meta.mask_layers, mask_values)
    # Allocate original texture: TEXTURE_3D, [1, 1, 1] placeholder [G]
    original_texture = allocate_texture_3d([1, 1, 1])
    return packed_texture, pages_texture, mask_texture, original_texture

def fragment_shader(d, step_size, tf_low, tf_mid, tf_high, tf_opacity, use_transfer):
    remaining = 1.0
    rgb = [0.0, 0.0, 0.0]
    sample_index = 0
    while sample_index < 1000: # Standard ray march limit [G]
        if use_transfer:
            if d < 0.5:
                f = d * 2.0
                tint = mix(tf_low, tf_mid, f)
                extinction = mix(tf_opacity[0], tf_opacity[1], f)
            else:
                f = (d - 0.5) * 2.0
                tint = mix(tf_mid, tf_high, f)
                extinction = mix(tf_opacity[1], tf_opacity[2], f)
        else:
            tint = [1.0, 1.0, 1.0]
            extinction = d
        alpha = 1.0 - exp(-extinction * step_size)
        rgb[0] += remaining * alpha * tint[0]
        rgb[1] += remaining * alpha * tint[1]
        rgb[2] += remaining * alpha * tint[2]
        remaining *= 1.0 - alpha
        sample_index += 1
        if remaining < 1e-4:
            break
    return rgb
```

**Edge Cases and Pitfalls:**
*   **Budget Exceedance:** If the calculated memory exceeds 1024 MiB, the method fails. This requires careful selection of voxels or reduction of resolution [S1, unofficial].
*   **Precision:** The use of `R16UI` or `R8UI` depends on the source data precision. Loss of precision may occur if `R8UI` is used for high-dynamic-range data [S1, unofficial].
*   **Boundary Conditions:** The page table must correctly map grid coordinates to packed texture coordinates. Errors in `meta.grid_xyz` or index calculations will lead to artifacts or crashes [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of selected groups and the ray marching step size. Page table lookups are $O(1)$ per sample.
*   **Memory Complexity:** Bounded by the 1024 MiB budget. Scales with the number of selected voxels and the overhead of the page table and mask textures [S1, unofficial].
*   **Strengths:** Fits large volumes into limited GPU memory; supports sparse data via masking [S1, unofficial].
*   **Limitations:** Requires pre-processing to select and pack bricks; page table indirection adds complexity [S1, unofficial].
*   **When to use:** When the volume size exceeds `MAX_3D_TEXTURE_SIZE` or available GPU memory, and the data can be partitioned into static bricks [S1, unofficial].
*   **When not to use:** For small volumes that fit in a single 3D texture, or for highly dynamic data [S1, unofficial].
