# Compact Volume Rendering with Page-Table Indirection and Masked Storage

Also called: Brick-based rendering, Compact mode

## Overview
Compact Volume Rendering is a rendering mode that stores only selected groups of voxels (bricks) in a packed 2D array texture, using a page table for spatial indexing and an optional bitmask for sparse storage, to fit within a 1024 MiB GPU memory budget [S1, unofficial]. It differs from the original mode, which loads the full volume into a single 3D texture, by enabling rendering of datasets that exceed `MAX_3D_TEXTURE_SIZE` or the available GPU memory through spatial partitioning and indirection [S1, unofficial]. It builds on [Brick-based volume rendering with packed textures](7106-brick-based-volume-rendering-with-packed-textures.md).

## How it works
**Inputs and Outputs:**
*   **Input:** A volume dataset, a memory budget (default 1024 MiB), and rendering parameters (`stepSize`, `cutoff`, `windowMax`).
*   **Output:** GPU textures (`packed`, `pages`, `maskTexture`) and shader uniforms for ray marching.

**Data Structures:**
1.  **Packed Density Texture (`packed`):** `TEXTURE_2D_ARRAY`. Dimensions `[packedWidth, packedHeight, layers]`. Internal format `R16UI` or `R8UI` depending on `meta.bytes_per_voxel`. Type `UNSIGNED_SHORT` or `UNSIGNED_BYTE`. Bound to texture unit 0.
2.  **Page Table Texture (`pages`):** `TEXTURE_3D`. Dimensions `[meta.grid_xyz]`. Internal format `RGBA32UI`. Type `UNSIGNED_INT`. Bound to texture unit 1. Each texel stores indices into the packed texture and mask texture.
3.  **Mask Texture (`maskTexture`):** `TEXTURE_2D_ARRAY`. Dimensions `[maskWidth, maskHeight, maskLayers]`. Internal format `RG32UI`. Type `UNSIGNED_INT`. Bound to texture unit 3. Used for sparse storage optimization.
4.  **Original Texture (`original`):** `TEXTURE_3D` placeholder `[1,1,1]`.

**Parameters:**
*   `budget`: Maximum GPU memory allocation, set to $1024 \times 1048576$ bytes (1024 MiB) [S1, unofficial].
*   `stepSize`: Step size for ray marching, passed from UI input [S1, unofficial].
*   `cutoff`: Display cutoff value for volume rendering [S1, unofficial].
*   `windowMax`: Window maximum for normalization [S1, unofficial].

**Algorithm Steps:**

1.  **Calculate Required Memory:**
    Sum `density_bytes` and `mask_bytes` for each selected group. Add `meta.page_bytes` and a fixed overhead of 131072 bytes. If the total exceeds `budget`, throw an error [S1, unofficial].

2.  **Determine Packed Texture Dimensions:**
    *   `packedWidth = min(MAX_TEXTURE_SIZE, total_voxel_count)`
    *   `Layers = max(1, ceil(total_voxels / (MAX_TEXTURE_SIZE^2)))`
    *   `Height = max(1, ceil(total_voxels / (packedWidth * Layers)))`
    *   `packedHeight = Height` [S1, unofficial].

3.  **Allocate Arrays:**
    *   Allocate `padded` array of type `ArrayType` with size `packedWidth * height * layers`.
    *   Allocate `maskValues` array of type `Uint32Array` with size `maskWidth * maskHeight * maskLayers * 2`.
    *   Check if `padded.byteLength + maskValues.byteLength + meta.page_bytes > budget`. If so, throw an error [S1, unofficial].

4.  **Initialize Page Table and Populate Data:**
    *   Initialize `table` as `Uint32Array` of size `meta.page_bytes / 4`.
    *   Initialize `offset = 0` and `maskOffset = 0`.
    *   For each chosen group:
        *   Load density values and index entries.
        *   If `storage_encoding` is `'masked32'`, load mask records and add `offset` to the first column of records.
        *   Write density values to `padded[offset]`.
        *   Update `table` entries:
            *   `table[cell] = entries[i+1] + (masked ? maskOffset : offset)`
            *   `table[cell+1] = entries[i+2]`
            *   `table[cell+2] = entries[i+3]`
        *   Increment `offset` by `values.length`.
        *   If masked, increment `maskOffset` by `records.length / 2` [S1, unofficial].

5.  **Create GPU Textures:**
    *   Bind `packed` as `TEXTURE_2D_ARRAY` with dimensions `[packedWidth, height, layers]`.
    *   Bind `maskTexture` as `TEXTURE_2D_ARRAY` with dimensions `[maskWidth, maskHeight, maskLayers]`.
    *   Bind `pages` as `TEXTURE_3D` with dimensions `[meta.grid_xyz]`.
    *   Bind `original` as `TEXTURE_3D` `[1,1,1]` placeholder [S1, unofficial].

6.  **Fragment Shader Execution:**
    *   **Transfer Function Interpolation:** If `useTransfer` is true, compute factor $f$:
        *   If $d < 0.5$, $f = d \times 2$.
        *   Else, $f = (d - 0.5) \times 2$.
    *   **Compute Tint:**
        *   If $d < 0.5$, `tint = mix(tfLow, tfMid, f)`.
        *   Else, `tint = mix(tfMid, tfHigh, f)`.
    *   **Compute Extinction:**
        *   If $d < 0.5$, `extinction = mix(tfOpacity.x, tfOpacity.y, f)`.
        *   Else, `extinction = mix(tfOpacity.y, tfOpacity.z, f)`.
    *   **Ray Marching Update:**
        *   `alpha = 1.0 - exp(-extinction * stepSize)`
        *   `rgb += remaining * alpha * tint`
        *   `remaining *= 1.0 - alpha`
        *   Increment `sampleIndex` [S1, unofficial].

**Pseudocode:**

```python
def compact_volume_rendering(volume_meta, budget=1024 * 1048576):
    # Step 1: Calculate total bytes
    total_bytes = 0
    for group in volume_meta.selected_groups:
        total_bytes += group.density_bytes + group.mask_bytes
    total_bytes += volume_meta.page_bytes + 131072
    
    if total_bytes > budget:
        raise MemoryError("Exceeds budget")

    # Step 2: Determine dimensions
    total_voxels = volume_meta.total_voxels
    packed_width = min(MAX_TEXTURE_SIZE, total_voxels)
    layers = max(1, (total_voxels + MAX_TEXTURE_SIZE**2 - 1) // (MAX_TEXTURE_SIZE**2))
    height = max(1, (total_voxels + packed_width * layers - 1) // (packed_width * layers))
    packed_height = height

    # Step 3: Allocate arrays
    padded = [0] * (packed_width * height * layers)
    mask_values = [0] * (volume_meta.mask_width * volume_meta.mask_height * volume_meta.mask_layers * 2)
    
    if len(padded) * 4 + len(mask_values) * 4 + volume_meta.page_bytes > budget:
        raise MemoryError("Allocation exceeds budget")

    # Step 4: Populate data
    table = [0] * (volume_meta.page_bytes // 4)
    offset = 0
    mask_offset = 0
    
    for i, group in enumerate(volume_meta.selected_groups):
        # Load density values and index entries
        density_values = group.load_density()
        entries = group.load_index_entries()
        
        masked = group.storage_encoding == 'masked32'
        
        if masked:
            mask_records = group.load_mask_records()
            for record in mask_records:
                record[0] += offset
        
        # Write density
        for val in density_values:
            padded[offset] = val
            offset += 1
            
        # Update page table
        # Assuming entries structure: [cell, next_offset, ...]
        # Note: Exact mapping of entries[i+1] to table indices depends on meta.grid_xyz layout
        # This is a simplified representation based on the note's logic
        table[group.cell_index] = entries[1] + (mask_offset if masked else offset - len(density_values))
        table[group.cell_index + 1] = entries[2]
        table[group.cell_index + 2] = entries[3]
        
        if masked:
            mask_offset += len(mask_records) // 2

    # Step 5: Create GPU textures
    # Implementation details for GPU driver calls omitted as per standard graphics API usage
    create_texture_2d_array('packed', packed_width, packed_height, layers, padded)
    create_texture_3d('pages', volume_meta.grid_xyz, table)
    create_texture_2d_array('maskTexture', volume_meta.mask_width, volume_meta.mask_height, volume_meta.mask_layers, mask_values)
    create_texture_3d('original', [1, 1, 1])

def fragment_shader(d, step_size, tf_low, tf_mid, tf_high, tf_opacity, remaining):
    # Step 6: Shader execution
    if d < 0.5:
        f = d * 2
        tint = mix(tf_low, tf_mid, f)
        extinction = mix(tf_opacity.x, tf_opacity.y, f)
    else:
        f = (d - 0.5) * 2
        tint = mix(tf_mid, tf_high, f)
        extinction = mix(tf_opacity.y, tf_opacity.z, f)
        
    alpha = 1.0 - exp(-extinction * step_size)
    rgb = remaining * alpha * tint
    remaining = remaining * (1.0 - alpha)
    
    return rgb, remaining, alpha
```

**Edge Cases and Pitfalls:**
*   **Budget Exceedance:** If the calculated memory exceeds 1024 MiB, the method fails. This requires careful selection of voxels or reduction of resolution [S1, unofficial].
*   **Precision:** The use of `R16UI` or `R8UI` depends on the source data precision. Loss of precision may occur if `R8UI` is used for high-dynamic-range data [S1, unofficial].
*   **Boundary Conditions:** The page table must correctly map grid coordinates to packed texture coordinates. Errors in `meta.grid_xyz` or index calculations will lead to artifacts or crashes [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of selected groups and the ray marching step size. Page table lookups are $O(1)$ per sample.
*   **Memory Complexity:** Bounded by the 1024 MiB budget. Scales with the number of selected voxels and the overhead of the page table and mask textures [S1, unofficial].
*   **Measured Performance:** Benchmarks show significant memory savings compared to loading the full volume, enabling rendering of larger datasets on GPUs with limited memory [S1, unofficial].
*   **Strengths:** Fits large volumes into limited GPU memory; supports sparse data via masking.
*   **Limitations:** Requires pre-processing to select and pack bricks; page table indirection adds complexity; not suitable for dynamic volumes that change frequently [S1, unofficial].
*   **When to use:** When the volume size exceeds `MAX_3D_TEXTURE_SIZE` or available GPU memory, and the data can be partitioned into static bricks.
*   **When not to use:** For small volumes that fit in a single 3D texture, or for highly dynamic data [S1, unofficial].

## Background
Compact Volume Rendering was developed as part of the VolumeSegmenter project by Winson-L [S1, unofficial]. It addresses the limitation of traditional volume rendering methods that require loading the entire volume into GPU memory, which is often impractical for large datasets. The method was introduced in the GitHub repository `Winson-L/VolumeSegmenter` [S1, unofficial].
