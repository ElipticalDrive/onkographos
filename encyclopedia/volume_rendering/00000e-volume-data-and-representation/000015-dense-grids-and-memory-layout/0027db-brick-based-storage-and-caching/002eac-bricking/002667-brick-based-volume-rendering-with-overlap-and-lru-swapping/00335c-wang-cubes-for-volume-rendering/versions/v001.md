# Wang Cubes for Volume Rendering
Also called: Wang Cubes, Wang Cubes Memory Optimization

## Overview
Wang Cubes is a memory optimization technique for volume rendering that utilizes non-periodic 3D Wang Cubes to store volume data and segmentation masks, significantly reducing texture memory usage compared to storing full volumetric textures [S1, unofficial]. It distinguishes itself from sibling methods like [Bricking with Boundary Voxel Duplication](4198-bricking-with-boundary-voxel-duplication.md) by combining cube tiling with volume data and segmentation masks into a single texture unit, thereby avoiding the need for extra texture units [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A volumetric dataset of resolution $V \times V \times V$ (or rectangular $V_x \times V_y \times V_z$), segmentation masks, and a desired cube side length $C$.
*   **Output:** A set of non-periodic 3D Wang Cubes textures that can be used for surface-based rendering or direct volume rendering [S1, unofficial].

**Data Structures:**
The method organizes data into "cube sets." Each set consists of 16 Wang Cubes. The texture memory is allocated based on the number of cube sets $M$ and the cube side length $C$.

**Formulas:**
*   **Texture Space with Wang Cubes:** $M \times 16 \times C^3$ [S1, unofficial].
*   **Texture Space without Wang Cubes:** $M \times V^3$ [S1, unofficial].
*   **Space Difference Ratio:** $\frac{16C^3}{V^3}$ [S1, unofficial].

**Parameters:**
*   $M$: Number of cube sets.
*   $C$: Cube side length.
*   $V$: Dataset size dimension.
*   Typical values from source: Dataset resolution $256 \times 256 \times 128$, Cube size $16^3$ [S1, unofficial].

**Steps:**
1.  **Synthesize Cube Sets:** Generate non-periodic 3D Wang Cubes from the volume data and segmentation masks. The source notes that once a cube set is synthesized, arbitrary sized 3D textures can be composed quickly [S1, unofficial].
2.  **Combine into Single Texture Unit:** Combine the cube tiling with the volume data and segmentation masks into one texture unit. This step is critical to avoid using an extra texture unit [S1, unofficial].
3.  **Render:** Use the synthesized Wang Cubes for rendering. The method supports both surface-based methods and direct volume rendering [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
*   **Memory:** The texture memory required with Wang Cubes is $M \times 16 \times C^3$, whereas without Wang Cubes it is $M \times V^3$ [S1, unofficial].
*   **Space Difference Ratio:** The ratio of space required with Wang Cubes to that without is $\frac{16C^3}{V^3}$ [S1, unofficial].

**Measured Performance:**
*   For a dataset of size $256 \times 256 \times 128$ and cubes of size $16^3$, the required texture memory with Wang Cubes is $1/128$ of that required without Wang Cubes [S1, unofficial].

**Scaling:**
*   The memory savings scale with the ratio of cube size to dataset size. Larger datasets relative to cube size yield greater memory savings.

**Strengths and Limitations:**
*   **Strengths:** Significantly reduces texture memory usage; combines volume data and segmentation masks into one texture unit, saving texture units; allows arbitrary sized 3D textures to be composed quickly once cube sets are synthesized [S1, unofficial].
*   **Limitations:** The source does not detail the computational cost of synthesizing the Wang Cubes. The method is specific to the described synthesis and tiling approach.

**When to Use:**
*   Use when texture memory is a bottleneck and the dataset is large.
*   Suitable for medical datasets (e.g., abdomen, lung, liver, kidneys) and educational applications [S1, unofficial].
*   Can be used in both surface-based methods and direct volume rendering [S1, unofficial].

## Background
**Origin:**
The Wang Cubes method was introduced in the paper "Example-based volume illustrations" [S1, unofficial].

**History and Development:**
The method was developed to address the issue of limited texture space in volume rendering, particularly for generating illustrative styles. It leverages non-periodic 3D Wang Cubes to store volume data and segmentation masks, allowing for the generation of high-resolution 3D textures from small 2D examples with little user effort [S1, unofficial].

**Usage:**
The method is useful for educational applications, as it can generate expressive and pleasing illustrations similar to those found in medical anatomy textbooks and atlases [S1, unofficial]. It can be extended to other areas of 3D texturing and color transfer, including video synthesis and texture generation for other types of models [S1, unofficial].
