# Wang Cubes for Volume Rendering

Also called: 3D Wang Tiles, Wang Cube tiling, Wang Cubes, Wang Cubes Memory Optimization, Wang Cubes Texture Synthesis

## Overview
Wang Cubes is a texture synthesis method that creates non-periodic 3D textures using cubes with colored faces to overcome the memory and time limits of storing high-resolution volumetric data [S1, unofficial]. It reduces texture memory usage by storing a small set of synthesized cube templates rather than the full volume, allowing the generation of arbitrary-sized textures on the fly [S1, unofficial]. Unlike [Bricking with Boundary Voxel Duplication](4198-bricking-with-boundary-voxel-duplication.md) which duplicates boundary voxels for continuity, Wang Cubes enforce continuity through face-color matching and explicit edge-volume synthesis [S1, unofficial].

## How it works
**Inputs:** A 3D sample volume (source data) and a target resolution [S1, unofficial].
**Outputs:** A set of synthesized Wang Cubes and a tiling map, which can be composed into a large 3D texture [S1, unofficial].

**Data Structures:**
*   **Wang Cube:** A cube with 6 faces: North (N), South (S), West (W), East (E), Front (F), Back (B) [S1, unofficial].
*   **Face Colors:** Each face has a discrete color identifier [S1, unofficial]. Faces in the same direction (N/S, W/E, F/B) share the same color set [S1, unofficial]. Colors on different axes are independent [S1, unofficial].
*   **Face Volume:** A 3D sub-volume of the same size as a Wang Cube, randomly selected from the sample volume, corresponding to a specific face color [S1, unofficial].
*   **Edge Volume:** A 3D sub-volume tied to a specific direction (NS, WE, or FB), used to enforce edge continuity [S1, unofficial].

**Parameters:**
*   $C$: Cube side length (e.g., 16) [S1, unofficial].
*   $M$: Number of cube sets (minimum 16 cubes per set) [S1, unofficial].
*   $V$: Dataset dimension size (e.g., 256) [S1, unofficial].
*   $\pi_i, \pi_e$: Weight factors for inside and edge errors [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:** Select a random cube from the sample volume as the initial seed [G]. Define the set of available face colors for each direction (N/S, W/E, F/B) [S1, unofficial].
2.  **Face Synthesis (Inside Cube):** For each face of the cube: select a random "face volume" from the sample volume corresponding to the required face color [S1, unofficial]. Define the quilting region between the current cube face and the face volume using two half elliptical spheroids [S1, unofficial]. Use a graph cut algorithm (max-flow/min-cut) to synthesize the texture on the face, minimizing the synthesis error $E_i$ along the cutting surface [S1, unofficial]. Repeat for all faces of all cubes in the set until the accumulated inside error $E_i$ is below a threshold [S1, unofficial].
3.  **Edge Continuity Correction:** The initial synthesis causes discontinuities at cube edges because adjacent faces sharing a color may come from different random samples [S1, unofficial]. For each direction (NS, WE, FB), select a random "edge volume" from the sample volume [S1, unofficial]. For face volumes corresponding to a specific direction (e.g., WE), use the edge volumes of the other two directions (NS and FB) to modify the 4 edge regions of the face's middle plane [S1, unofficial]. Search for a quilting surface within two half cylinders between the face volume and the edge volumes [S1, unofficial]. Synthesize the face volumes using these edge constraints [S1, unofficial]. Regenerate the cubes using the corrected face volumes [S1, unofficial].
4.  **Alternative Edge Handling (Soft Boundaries):** For textures without sharp boundaries, introduce an edge error factor $E_e$ [S1, unofficial]. The total error is $E_s = \pi_i E_i + \pi_e E_e$, where $E_e$ measures average edge discontinuities [S1, unofficial].
5.  **Tiling:** Place the synthesized cubes in a grid such that adjacent cubes have matching face colors [S1, unofficial]. This creates a non-periodic 3D texture [S1, unofficial].

**Pseudocode:**

```python
import random

def synthesize_wang_cubes(sample_volume, cube_size, num_cubes, target_resolution):
    # 1. Define color sets for each axis direction
    color_sets = {
        'NS': list(range(2)),
        'WE': list(range(2)),
        'FB': list(range(2))
    }
    
    # 2. Initialize cube set
    cubes = []
    for _ in range(num_cubes):
        cube = {
            'colors': {
                'N': random.choice(color_sets['NS']),
                'S': random.choice(color_sets['NS']),
                'W': random.choice(color_sets['WE']),
                'E': random.choice(color_sets['WE']),
                'F': random.choice(color_sets['FB']),
                'B': random.choice(color_sets['FB'])
            },
            'texture': None
        }
        cubes.append(cube)
        
    # 3. Synthesize face volumes and cubes
    # Step 3a: Initial face synthesis using elliptical spheroids
    for cube in cubes:
        for face in ['N', 'S', 'W', 'E', 'F', 'B']:
            face_vol = random_patch_from_sample(sample_volume, cube_size)
            quilting_region = define_elliptical_spheroid_region(cube, face, face_vol)
            synthesized_face = graph_cut_synthesis(cube['colors'][face], face_vol, quilting_region)
            cube['texture'] = combine_cube_texture(cube['texture'], synthesized_face, face)
            
    # 3b: Edge continuity correction
    edge_volumes = {
        'NS': random_patch_from_sample(sample_volume, cube_size),
        'WE': random_patch_from_sample(sample_volume, cube_size),
        'FB': random_patch_from_sample(sample_volume, cube_size)
    }
    
    for cube in cubes:
        modify_face_edges(cube, 'WE', edge_volumes['NS'], edge_volumes['FB'])
        modify_face_edges(cube, 'NS', edge_volumes['WE'], edge_volumes['FB'])
        modify_face_edges(cube, 'FB', edge_volumes['NS'], edge_volumes['WE'])
        
    # 4. Tile the cubes
    tiling_map = generate_tiling_map(cubes, target_resolution)
    
    # 5. Compose final texture
    final_texture = compose_texture(cubes, tiling_map, target_resolution)
    return final_texture
```

**Edge Cases and Pitfalls:**
*   **Edge Discontinuity:** Textures are discontinuous on cube edges along cube faces because adjacent faces share colors but come from randomly selected samples [S1, unofficial]. This is mitigated by the edge volume modification step [S1, unofficial].
*   **Repetitive Appearance:** Since a set of Wang Cubes has a limited number of samples, they will inevitably repeat themselves somewhere in the volume [S1, unofficial]. This can be improved by using larger cube sets [S1, unofficial].
*   **Minimum Cube Set Size:** To ensure continuity for the whole space, the minimum cube set size increases to 128 cubes if corner colors are also constrained [S1, unofficial].

## Operating characteristics
*   **Memory Reduction:** The required texture memory with Wang Cubes is significantly lower than without [S1, unofficial]. For a dataset of size $256 \times 256 \times 128$ and cubes of size $16^3$, the required texture memory is $1/128$ of that required without Wang Cubes [S1, unofficial].
*   **Formula:** The space requirement difference ratio is $16C^3 / V^3$, where $M$ is the number of cube sets, $C$ is the cube side length, and $V$ is the dataset size dimension [S1, unofficial].
    *   Texture memory with Wang Cubes: $M \times 16 \times C^3$ [S1, unofficial].
    *   Texture memory without Wang Cubes: $M \times V^3$ [S1, unofficial].
*   **Performance:** Synthesis time is limited by the graph cut algorithm and the number of cubes [S1, unofficial]. However, once synthesized, composing arbitrary-sized 3D textures is fast [S1, unofficial].
*   **Strengths:** Reduces texture memory usage [S1, unofficial]. Allows non-periodic textures [S1, unofficial]. Combines volume data and segmentation masks into one texture unit [S1, unofficial].
*   **Limitations:** Repetitive appearance [S1, unofficial]. Edge discontinuity if not properly corrected [S1, unofficial]. Requires careful tuning of error thresholds and edge volumes [S1, unofficial].

## Background
Wang Cubes are the 3D extension of 2D Wang Tiles, which are square tiles with colored edges [S1, unofficial]. The method was introduced to address the memory and time limitations of high-resolution 3D textures in volume rendering applications [S1, unofficial]. It is particularly useful for medical datasets (e.g., abdomen, lung, liver, kidneys) and can be used in both surface-based methods and direct volume rendering [S1, unofficial]. The technique allows for the generation of illustrative styles and high-resolution textures from small sample volumes [S1, unofficial].
