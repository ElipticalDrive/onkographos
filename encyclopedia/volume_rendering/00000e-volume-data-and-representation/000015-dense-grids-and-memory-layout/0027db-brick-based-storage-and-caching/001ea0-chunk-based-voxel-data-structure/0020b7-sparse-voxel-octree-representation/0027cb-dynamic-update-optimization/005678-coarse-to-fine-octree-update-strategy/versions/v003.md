# Coarse-to-Fine Octree Update Strategy

Also called: Down-sampled projection update, Multi-scale octree update

## Overview
This strategy accelerates sparse voxel octree updating and reduces noise sensitivity by decoupling structural changes from density optimization [S1]. It initially updates the octree topology using low-resolution (down-sampled) projections to mitigate high-frequency noise, then fixes the tree structure to optimize only the density grids using original high-resolution projections [S1]. It builds on [Dynamic Update Optimization](4120-dynamic-update-optimization.md).

## How it works
**Inputs:**
*   Initial octree structure.
*   Down-sampled projection images (low resolution) [S1].
*   Original projection images (high resolution) [S1].
*   Number of coarse epochs ($N_{coarse}$). Not given in the sources.
*   Number of fine epochs ($N_{fine}$). Not given in the sources.

**Outputs:**
*   Final octree structure.
*   Optimized density grids for all leaf nodes [S1].

**Data Structures:**
*   **Octree Node:** Contains pointers to children (if internal) and a density grid (if leaf) [G].
*   **Density Grid:** A 3D array of scalar values associated with a leaf node [G].

**Algorithm Steps:**

1.  **Initialization:** Initialize the octree update using down-sampled projections [S1].
2.  **Coarse Update Phase (Topology & Density):** During the down-sampled update step, optimize the densities of the density grid inside each node [S1]. Use low-resolution projections to reduce the impact of high noise during octree updating [S1].
3.  **Structure Locking:** After several epochs, fix the structure of the octree [S1].
4.  **Fine Update Phase (Density Only):** Use the original projections to optimize only the density grid of each node [S1].
5.  **Density Initialization:** Initialize the density grids for the final optimization step from their down-sampled version [S1].
6.  **Loss Metric:** Use the standard deviation (SD) of each node as the octree-update loss metric [S1].

**Pseudocode:**

```python
import math

def coarse_to_fine_update(octree, downsampled_projections, original_projections, N_coarse, N_fine):
    # Step 1: Initialize octree update using down-sampled projections [S1]
    octree.initialize(downsampled_projections)
    
    # Step 2: Coarse Update Phase (Topology & Density)
    for i in range(N_coarse):
        # Render using down-sampled projections [G]
        rendered_coarse = render_octree(octree, downsampled_projections)
        
        # Compute loss: SD of each node as octree-update loss [S1]
        residuals = [r - t for r, t in zip(rendered_coarse, downsampled_projections)]
        mean_r = sum(residuals) / len(residuals)
        loss = math.sqrt(sum((x - mean_r)**2 for x in residuals) / len(residuals))
        
        # Compute gradients for structure and density via differentiable rendering [G]
        grad_structure, grad_density = backpropagate_loss(loss, octree, downsampled_projections)
        
        # Update octree structure and density grids [G]
        octree.update_structure(grad_structure)
        octree.update_density_grids(grad_density)
        
    # Step 3: Structure Locking
    # After several epochs, fix the structure of the octree [S1]
    octree.lock_structure()
    
    # Step 4: Fine Update Phase (Density Only)
    # Initialize density grids for the final optimization step from their down-sampled version [S1]
    octree.initialize_density_from_coarse()
    
    for j in range(N_fine):
        # Render using original projections [G]
        rendered_fine = render_octree(octree, original_projections)
        
        # Compute loss using original projections [G]
        residuals_fine = [r - t for r, t in zip(rendered_fine, original_projections)]
        loss_fine = sum(x**2 for x in residuals_fine) / len(residuals_fine)
        
        # Compute gradients for density only via differentiable rendering [G]
        grad_density_fine = backpropagate_density_only(loss_fine, octree, original_projections)
        
        # Update density grids [G]
        octree.update_density_grids(grad_density_fine)
        
    return octree

def render_octree(octree, projections):

    return rendered_image_buffer

def backpropagate_loss(loss, octree, projections):
    # Backpropagate loss through differentiable renderer to get structure and density gradients [G]
    return grad_structure, grad_density

def backpropagate_density_only(loss, octree, projections):
    # Backpropagate loss through differentiable renderer to get density gradients only [G]
    return grad_density
```

**Parameters:**
*   $N_{coarse}$: Number of epochs for the coarse phase. Not given in the sources.
*   $N_{fine}$: Number of epochs for the fine phase. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **High Noise:** Using original projections in the coarse phase can lead to instability due to high-frequency noise [S1].
*   **Structure Locking:** Once the structure is fixed, it cannot be refined further [G].
*   **Initialization:** Density grids must be initialized from the down-sampled version to ensure continuity between phases [S1].

## Subtopics

### Deferred Refining and Coarsening
A multi-step strategy to ease the expense of painting deep octrees by deferring tree adjustments [S2, unofficial]. It operates in two steps: (1) Paint on the existing tree without adjustment and update on GPU for immediate visual feedback; (2) Tree-adjustment stage where cells are marked for refinement/coarsening and one-level refinement or coarsening is performed per frame [S2, unofficial]. GPU textures are split into sub-blocks, marked dirty when CPU modifies them, and only dirty blocks are updated [S2, unofficial]. This approach is designed for interactive VR painting interfaces rather than reconstruction from projections [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Robust to high noise in projection data (e.g., cryo-ET) [S1]. Accelerates octree updating by avoiding premature high-resolution structural changes [S1].
*   **Limitations:** Requires two sets of projections (down-sampled and original) [S1]. The fixed structure in the fine phase may not adapt to new information if the coarse phase was insufficient [G].
*   **When to Use:** Suitable for reconstructing volumes from noisy projection data where topology convergence is critical [S1].

## Background
The coarse-to-fine octree update strategy was introduced in the context of cryo-electron tomography (cryo-ET) reconstruction and denoising [S1]. It addresses the challenge of high noise in cryo-ET projections, which can destabilize standard differentiable rendering updates [S1]. By using down-sampled projections for initial topology optimization, the method accelerates updating and reduces noise impact [S1].
