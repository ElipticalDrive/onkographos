# Sparse Voxel Octree Node Structure

Also called: SVONode, SparseVoxelOctreeNode struct

## Overview
The Sparse Voxel Octree (SVO) node structure defines the memory layout, connectivity, and state management for individual nodes within a sparse voxel octree [S2, unofficial]. It solves the problem of efficiently representing volumetric data by storing only occupied regions, using spatial bounds, parent/child links, and directional neighbor pointers to enable fast traversal and ray casting [S2, unofficial]. Unlike static octrees, this implementation dynamically splits leaves when a minimum dimension threshold is reached and merges identical children via simplification, reducing memory overhead for uniform regions [S1, unofficial].

## How it works
### Inputs and Outputs
- **Input**: A target 3D position (integer coordinates), a data value of type $T$, and a minimum leaf dimension parameter $d_{min}$ [S1, unofficial].
- **Output**: A modified octree structure where the node at the specified position contains the data, or an error/`None` if the position is out of bounds [S1, unofficial].

### Data Structures
**Implementation A (`Node<T>`)** [S1, unofficial]:
1. `ty`: `NodeType<T>` enum.
2. `bounds`: `Bounds`, an array of two `Vector3<u32>` representing the inclusive lower bound and exclusive upper bound of the node's spatial extent [S1, unofficial].
3. `children`: Array of 8 `Box<Option<Node<T>>>`, representing the 8 octant children [S1, unofficial].

**`NodeType<T>` Enum**:
- `Leaf(T)`: Stores the data value $T$ [S1, unofficial].
- `Internal`: Marks a split node with children [S1, unofficial].
- `Simplified`: Marks a compressed node (implementation detail for merging) [S1, unofficial].

**`Octant` Enum**:
Maps 8 spatial subdivisions to integers 0–7: 0: LeftRearBase, 1: RightRearBase, 2: LeftRearTop, 3: RightRearTop, 4: LeftFrontBase, 5: RightFrontBase, 6: LeftFrontTop, 7: RightFrontTop [S1, unofficial].

**Implementation B (`SparseVoxelOctreeNode`)** [S2, unofficial]:
1. `position`: `UVec3` [S2, unofficial].
2. `size`: `u32` [S2, unofficial].
3. `parent`: `Option<SparseVoxelOctreeLink>` [S2, unofficial].
4. `first_child`: `Option<SparseVoxelOctreeLink>` [S2, unofficial].
5. `is_leaf`: `bool` [S2, unofficial].
6. `neighbors`: Array of 6 `Option<SparseVoxelOctreeLink>` (directional neighbors) [S2, unofficial].

Implementation A uses embedded bounds and an array of child pointers, while Implementation B uses explicit position/size and linked pointers with neighbor caching [S2, unofficial]. The algorithmic steps below follow Implementation A [S1, unofficial].

### Parameters
- `min_dimension` ($d_{min}$): `u32`. The minimum spatial extent (in voxels/units) for a leaf node. Controls tree depth and granularity. Typical value: 1 [S1, unofficial].

### Numbered Steps
1. **Insertion**: Check if the target `position` is within the node's `bounds` [S1, unofficial]. Calculate the current node `dimension` as $|bounds[0].x - bounds[1].x|$ [S1, unofficial]. If `dimension` equals `min_dimension`, set `ty` to `Leaf(data)` [S1, unofficial]. Otherwise, compute `child_info`: calculate half-dimension $d_{half} = dimension / 2$, calculate midpoint $P_{mid} = bounds[0] + (d_{half}, d_{half}, d_{half})$, and determine `octant` by comparing `position` to $P_{mid}$ using `vector_diff` [S1, unofficial]. Retrieve or create the child node at the calculated `octant` index [S1, unofficial]. Recursively insert the data into the child node [S1, unofficial].
2. **Splitting**: When a leaf node reaches `min_dimension` during insertion, it splits into 8 children [S1, unofficial]. The existing leaf data is copied to all 8 children [S1, unofficial]. The child corresponding to the target octant receives the new data [S1, unofficial]. The parent node's `ty` is set to `Internal` [S1, unofficial].
3. **Simplification**: Iterates over all 8 children to merge identical leaves [S1, unofficial]. Initialize `data` as `None`. For each child $i$ from 0 to 7: if child exists and is a leaf, if `data` is `None`, set `data` to the child's leaf data; if `data` is not `None` and differs from the child's data, return `false` [S1, unofficial]. If child is missing and `ty` is `Internal`, return `false` [S1, unofficial]. If `data` is not `None`, set `ty` to `Leaf(data)`, clear the `children` array (set all to `None`), and return `true` [S1, unofficial].
4. **Level of Detail (LOD)**: Iterates over all 8 children [S1, unofficial]. For each child: if it is a leaf, collect its data into an array; if it is not a leaf, recursively call `lod()` on it; if any child is missing, return early without modifying the node [S1, unofficial]. Count frequencies of each data value in the collected array using a hash map [S1, unofficial]. Sort the counts in descending order [S1, unofficial]. Select the most frequent value [S1, unofficial]. Set `ty` to `Leaf(most_frequent_value)` and clear the `children` array [S1, unofficial].

### Pseudocode
```python
class Vector3:
    def __init__(self, x, y, z):
        self.x = x
        self.y = y
        self.z = z

class Bounds:
    def __init__(self, min_pos, max_pos):
        self.min = min_pos  # Inclusive
        self.max = max_pos  # Exclusive

class NodeType:
    LEAF = 0
    INTERNAL = 1
    SIMPLIFIED = 2

class Node:
    def __init__(self, bounds, data=None):
        self.ty = NodeType.LEAF if data is not None else NodeType.INTERNAL
        self.bounds = bounds
        self.children = [None] * 8
        self.data = data

    def dimension(self):
        return abs(self.bounds.max.x - self.bounds.min.x)

    def min_position(self):
        return self.bounds.min

    def contains(self, position):
        return (position.x >= self.bounds.min.x and position.x < self.bounds.max.x and
                position.y >= self.bounds.min.y and position.y < self.bounds.max.y and
                position.z >= self.bounds.min.z and position.z < self.bounds.max.z)

    def leaf_data(self):
        if self.ty == NodeType.LEAF:
            return self.data
        return None

    def is_leaf(self):
        return self.ty == NodeType.LEAF

    def child_info(self, position):
        if self.contains(position):
            dim = self.dimension() // 2
            dim_3d = Vector3(dim, dim, dim)
            midpoint = Vector3(
                self.min_position().x + dim,
                self.min_position().y + dim,
                self.min_position().z + dim
            )
            octant = 0
            if position.x >= midpoint.x: octant |= 1
            if position.y >= midpoint.y: octant |= 2
            if position.z >= midpoint.z: octant |= 4
            return {'dimension': dim, 'dimension_3d': dim_3d, 'octant': octant}
        return None

    def child_bounds(self, dim_3d, octant):
        lower = Vector3(
            self.min_position().x + (dim_3d.x if octant & 1 else 0),
            self.min_position().y + (dim_3d.y if octant & 2 else 0),
            self.min_position().z + (dim_3d.z if octant & 4 else 0)
        )
        upper = Vector3(lower.x + dim_3d.x, lower.y + dim_3d.y, lower.z + dim_3d.z)
        return Bounds(lower, upper)

    def insert(self, position, data, min_dimension):
        if not self.contains(position):
            return False
        dim = self.dimension()
        if dim == min_dimension:
            self.ty = NodeType.LEAF
            self.data = data
            return True
        info = self.child_info(position)
        if info is None:
            return False
        octant = info['octant']
        if self.children[octant] is None:
            child_bounds = self.child_bounds(info['dimension_3d'], octant)
            self.children[octant] = Node(child_bounds)
        if self.is_leaf():
            self.ty = NodeType.INTERNAL
            for i in range(8):
                if self.children[i] is None:
                    child_bounds = self.child_bounds(info['dimension_3d'], i)
                    self.children[i] = Node(child_bounds)
                self.children[i].data = self.data
                self.children[i].ty = NodeType.LEAF
        return self.children[octant].insert(position, data, min_dimension)

    def simplify(self):
        data = None
        for i in range(8):
            child = self.children[i]
            if child is not None:
                if child.is_leaf():
                    child_data = child.leaf_data()
                    if data is None:
                        data = child_data
                    elif data != child_data:
                        return False
            elif self.ty == NodeType.INTERNAL:
                return False
        if data is not None:
            self.ty = NodeType.LEAF
            self.data = data
            self.children = [None] * 8
            return True
        return False

    def lod(self):
        all_data = [None] * 8
        for i in range(8):
            c = self.children[i]
            if c is None:
                return
            if c.is_leaf():
                all_data[i] = c.leaf_data()
            else:
                c.lod()
        counts = {}
        for d in all_data:
            if d is not None:
                counts[d] = counts.get(d, 0) + 1
        if counts:
            sorted_counts = sorted(counts.items(), key=lambda x: x[1], reverse=True)
            self.ty = NodeType.LEAF
            self.data = sorted_counts[0][0]
        self.children = [None] * 8
```

### Edge Cases and Pitfalls
- **Missing Children in Simplify**: If a node is marked `Internal` but has missing children, `simplify()` immediately returns `false`, preventing invalid compression [S1, unofficial].
- **Missing Children in LOD**: `lod()` returns early without modifying the node if any child is missing or is not a leaf, preserving tree integrity during downsampling [S1, unofficial].
- **Precision**: Coordinates are stored as `u32`. The initial root dimension must be a power of 2 to ensure integer midpoints and valid octant splits [S1, unofficial].

The lowest-level block of a VDB grid at a fixed tree depth, tiling index space into nonoverlapping subdomains and encoding both active voxel topology and numerical values self-containedly. Choose when dense data storage at fixed depth is required, as it embeds global origin in flags to minimize memory overhead.

### [VDB RootNode Structure](22350-vdb-rootnode-structure.md)
The topmost, sparse, dynamically resizable node in a VDB structure serving as the entry point for all tree operations. Choose when supporting unbounded grid domains with minimal memory overhead via hash maps for child pointers or tile values.

## Operating characteristics
- **Time Complexity**: Insertion requires $O(\log N)$ time where $N$ is the total number of voxels in the root domain, assuming balanced splits [S1, unofficial]. Simplification and LOD operations run in $O(1)$ time per node due to the fixed 8-child structure [S1, unofficial].
- **Memory Complexity**: Implementation A stores 8 pointers per internal node plus data per leaf node [S1, unofficial]. Implementation B stores explicit position, size, parent, child, and 6 neighbor links, adding traversal overhead but accelerating ray marching [S2, unofficial]. Memory usage is proportional to the number of nodes, which is significantly less than a dense grid for sparse data [S1, unofficial].
- **Strengths**: Efficient for sparse data, dynamic splitting and merging allow adaptive resolution, and neighbor links enable fast ray marching without recursive traversal [S1, unofficial].
- **Limitations**: Pointer overhead degrades performance for dense data, and maintaining neighbor links adds implementation complexity [S1, unofficial]. Specific performance metrics on hardware are not given in the sources.

## Background
The Sparse Voxel Octree is a fundamental data structure in volume rendering, enabling efficient storage and traversal of large volumetric datasets [S1, unofficial]. The implementation described here originates from the `svo-rs` library [S1, S2, unofficial]. It builds on the general [Octree Data Structure Layout](4518-octree-data-structure-layout.md) by providing concrete operational semantics for node mutation, including dynamic splitting and simplification [S1, unofficial].
