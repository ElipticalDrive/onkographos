# Morton Code Generation for Octrees

Also called: Morton key construction, Z-order curve encoding

## Overview
This method generates unique hierarchical spatial keys for octree cells by recursively concatenating binary octant indices to a parent key [S1, unofficial]. It solves the problem of identifying cells both spatially and hierarchically within a dense or sparse octree structure, enabling efficient neighbor and parent lookups [S1, unofficial]. Unlike standard Morton encoding which interleaves global coordinates, this approach builds keys based on the tree's traversal path, where each level adds exactly three bits to the key length [S1, unofficial].

## How it works
**Inputs and Outputs:**
The method takes the octree structure (or traversal path) and the octant index (0–7) for each child node as input, and outputs an integer key (Morton code) for each node [S1, unofficial].

**Data Structures:**
Keys are stored as integers, and their bit-length corresponds to the depth of the node in the octree [S1, unofficial]. Each octant index is represented by a 3-bit binary value [S1, unofficial].

**Steps:**
1. **Initialize Root:** Set the key of the root node to the integer $1$ [S1, unofficial].
2. **Recursive Construction:** For any child node, compute its key by concatenating the parent's key with the 3-bit binary representation of the child's octant index [S1, unofficial].
3. **Bit Expansion:** Each level of the octree adds exactly 3 bits to the key length relative to the parent level [S1, unofficial].

**Formulas:**
Let $k_{parent}$ be the key of the parent node and $o$ be the octant index of the child ($0 \le o \le 7$) [S1, unofficial].
The child's key $k_{child}$ is:
$$ k_{child} = k_{parent} \cdot 2^3 + o $$
Or equivalently, using bitwise operations:
$$ k_{child} = (k_{parent} \ll 3) \ | \ o $$
To find the parent key $k_{parent}$ from a child key $k_{child}$:
$$ k_{parent} = k_{child} \gg 3 $$ [S1, unofficial].

**Parameters:**
- Root Key: The initial key for the octree root is the integer $1$ [S1, unofficial].

**Pseudocode:**
```python
def generate_morton_key(parent_key, octant_index):
    """Generates the Morton key for a child node given its parent's key and octant index."""
    return (parent_key << 3) | octant_index

def get_parent_key(child_key):
    """Retrieves the parent key from a child's Morton key."""
    return child_key >> 3
```

**Edge Cases and Pitfalls:**
- **Key Size:** Keys grow linearly with depth [S1, unofficial].
- **Root Definition:** The root key is explicitly defined as $1$ [S1, unofficial].

## Background
This method is based on Morton coding [Morton, 1966], adapted for octree hierarchical structures [S1, unofficial]. It is used in volume rendering and isosurface extraction to identify cells spatially and hierarchically [S1, unofficial]. The specific recursive construction is detailed in Lewiner et al. [2010] [S1, unofficial].
