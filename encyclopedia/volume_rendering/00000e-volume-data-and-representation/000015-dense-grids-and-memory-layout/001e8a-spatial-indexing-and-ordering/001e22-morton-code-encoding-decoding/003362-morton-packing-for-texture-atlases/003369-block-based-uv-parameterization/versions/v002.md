# Block-based UV Parameterization

Also called: Block-based charting, Texture parametrization

## Overview
Block-based UV Parameterization is a fast parametrization method based on block-based charting that generates coherent texture maps for efficient compression using existing video compression algorithms, without tracking or UV coordinate compression [S1]. It solves the problem of efficiently encoding high-quality textures (e.g., 4096×4096 pixels) alongside compressed geometry without the computational overhead of tracking features over time or transmitting UV coordinates [S1]. Unlike methods that sacrifice spatial coherence for efficiency (e.g., Motion2Fusion) or require expensive temporal tracking for consistency, this approach inherently encourages spatio-temporal coherence by deriving UVs deterministically from the local block structure [S1].

## How it works
**Inputs:**
- Reconstructed TSDF block (volume data) [S1].
- Texture encoder $T_{enc}$ and decoder $T_{dec}$ blocks [S1].

**Outputs:**
- Morton packed chart $M_x$ (2D texture representation) [S1].
- Encoded bitstream for the chart [S1].

**Data Structures:**
- **TSDF Block:** A 3D grid of voxel values representing the signed distance field [S1].
- **Mesh:** Extracted surface geometry from the TSDF block using Marching Cubes [S1].
- **Morton Packed Chart ($M_x$):** A 2D texture atlas region where vertices and faces are ordered according to Morton codes derived from their 3D spatial positions [S1].

**Steps:**
1. **TSDF Reconstruction:** Obtain the TSDF block $\mathbf{x}$ for the current spatial region [S1].
2. **Mesh Extraction:** Apply the Marching Cubes algorithm to the TSDF block $\mathbf{x}$ to extract the surface mesh [S1].
3. **Morton Ordering:** Assign a 3D Morton code to each vertex in the mesh based on its spatial coordinates and sort the vertices and faces according to these codes [G].
4. **Chart Generation:** Map the sorted mesh to a 2D texture chart $M_x$ while preserving the Morton order to ensure spatially adjacent vertices in 3D are likely adjacent in the 2D chart [G].
5. **Encoding:** Code the Morton packed chart $M_x$ separately using the texture encoder $T_{enc}$ [S1]. The resulting bitstream is transmitted alongside the geometry data [S1].
6. **Decoding:** The receiver decodes the bitstream using $T_{dec}$ to reconstruct $M_x$ and independently generates the same Morton codes from the decoded geometry to interpret the UV coordinates correctly [G].

**Formulas:**
- **Morton Code:** For a vertex with 3D coordinates $(x, y, z)$, the Morton code $m$ is formed by interleaving the bits of $x, y, z$:
  $$ m = \text{interleave}(x, y, z) $$
- **Texture Mapping:** The UV coordinate $(u, v)$ for a vertex is determined by its rank in the sorted list of vertices based on $m$ [G].

**Parameters:**
- **Texture Resolution:** Typically 4096×4096 pixels for high-quality compression [S1].
- **Block Size:** Not given in the sources.

## Subtopics

### [Block-level Charting](8424-block-level-charting.md)
A UV parametrization method for texture compression that creates one 2D chart per occupied 3D block, ensuring deterministic UV coordinates inferred on the receiver side without transmitting UVs.

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** Enables efficient compression of textures using existing image-based techniques (e.g., video codecs) [S1].
- **Strengths:** Inherently encourages temporal consistency without tracking; removes the need for UV coordinate compression and streaming; maintains spatial coherence better than arbitrary mapping methods [S1].
- **Limitations:** May not achieve the same level of temporal consistency as methods that explicitly track features over time, though it avoids their high computational cost [S1].
- **When to use:** Suitable for real-time applications where computational efficiency is critical, and high-quality texture compression is needed alongside geometry compression [S1].
- **When not to use:** Not suitable for applications requiring the highest possible temporal consistency if the computational cost of tracking is acceptable [S1].

## Background
Block-based UV Parameterization was introduced in the context of deep 3D compression methods, specifically in the paper "Deep Implicit Volume Compression" [S1]. It addresses the challenge of compressing high-quality texture maps alongside TSDF geometry. The method was developed to complement TSDF compression algorithms by providing a fast, coherent texture parametrization that works well with existing image compression standards. It is part of a broader effort to create end-to-end learnable compression models for 3D data [S1].
