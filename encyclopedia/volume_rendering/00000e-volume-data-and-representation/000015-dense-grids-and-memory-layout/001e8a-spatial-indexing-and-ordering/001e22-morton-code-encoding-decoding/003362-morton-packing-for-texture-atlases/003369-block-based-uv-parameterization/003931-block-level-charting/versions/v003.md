# Block-level Charting


## Overview
Block-level charting is a deterministic UV parametrization method for texture compression that generates one 2D chart per occupied 3D block, ensuring UV coordinates can be inferred on the receiver side without transmitting them [S1]. It differs from traditional UV mapping by partitioning the surface into fixed-size blocks matching the geometry compression structure, rather than using few large charts like UVAtlas or one chart per triangle like PTEX [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A reconstructed 3D volume mesh (identical on sender and receiver), block size (fixed), and block occupancy status [S1].
*   **Output:** A global UV atlas and per-vertex UV coordinates relative to that atlas [S1].

**Data Structures:**
*   **Block:** A fixed-size 3D voxel grid cell [S1].
*   **Chart:** A 2D texture region containing projected vertices from one block [S1].
*   **Atlas:** A 2D texture containing all charts [S1].

**Steps:**
1.  **Reconstruction Sync:** Decompress the signal on the sender side so the sender and receiver have identical reconstructed volumes [S1].
2.  **Block Processing:** For each occupied 3D block:
    a. Extract triangles belonging to the block [S1].
    b. Group triangles by their normals. Most blocks have one group; complex areas may have more [S1].
    c. For each group:
        i. Calculate the average normal $\mathbf{n}_{avg}$ of the group [S1].
        ii. Determine a tangent space from $\mathbf{n}_{avg}$ [S1].
        iii. Project vertices of the group onto this tangent space [S1].
        iv. Rotate the projections using rotating calipers to fit into an axis-aligned rectangle with minimum area [S1].
        v. Compute the bounding box of the rotated projections [S1].
    d. Sort the bounding boxes of all groups in the block by size [S1].
    e. Pack the bounding boxes into a 2D chart using a quadtree-like algorithm [S1].
    f. Offset vertex UV coordinates to be relative to the chart [S1].
3.  **Atlas Packing:** Pack all block charts into a global atlas [S1]. Offset vertex UV coordinates again to be relative to the atlas [S1].

**Pseudocode:**
```python
def block_level_charting(reconstructed_volume):
    atlas = []
    for block in reconstructed_volume.occupied_blocks:
        # 1. Extract triangles belonging to the block
        triangles = [t for t in reconstructed_volume.mesh if block.contains(t)]
        
        # 2. Group triangles by normals
        groups = []
        for t in triangles:
            n = normalize(cross(t.v2 - t.v1, t.v3 - t.v1))
            assigned = False
            for g in groups:
                if dot(n, g.normal) > 0.9:
                    g.vertices.extend(t.vertices)
                    g.normal = normalize(g.normal + n)
                    assigned = True
                    break
            if not assigned:
                groups.append({'normal': n, 'vertices': t.vertices})
        
        chart = {'regions': []}
        
        for group in groups:
            # 3. Average normal determines tangent space
            avg_normal = normalize(group.normal)
            # Standard basis vector orthogonal to normal
            tangent = cross(avg_normal, (0.0, 0.0, 1.0))
            if norm(tangent) < 1e-6:
                tangent = cross(avg_normal, (1.0, 0.0, 0.0))
            tangent = normalize(tangent)
            bitangent = cross(avg_normal, tangent)
            
            # 4. Project vertices onto tangent space
            origin = group.vertices[0]
            projections = []
            for v in group.vertices:
                p = v - origin
                projections.append((dot(p, tangent), dot(p, bitangent)))
            
            # 5. Rotate projections using rotating calipers to fit into minimum area axis-aligned rectangle
            # [G] Standard rotating calipers algorithm iterates over convex hull edges to track 
            # min/max coordinates in the rotated frame, yielding the minimum area bounding rectangle.
            hull = convex_hull(projections)
            min_rect = compute_min_area_rect(hull)
            rotated_projections = [rotate_point(p, min_rect.angle) for p in projections]
            
            # 6. Compute bounding box
            min_u = min(p[0] for p in rotated_projections)
            max_u = max(p[0] for p in rotated_projections)
            min_v = min(p[1] for p in rotated_projections)
            max_v = max(p[1] for p in rotated_projections)
            bbox = (min_u, min_v, max_u - min_u, max_v - min_v)
            chart['regions'].append(bbox)
        
        # 7. Sort bounding boxes by size
        chart['regions'].sort(key=lambda b: b[2] * b[3])
        
        # 8. Pack into chart using quadtree-like algorithm
        # The sources do not specify the exact quadtree packing algorithm.
        # A standard implementation recursively subdivides the chart space to place non-overlapping regions.
        pack_quadtree(chart['regions'])
        
        # 9. Offset vertex UV coordinates to be relative to the chart
        for v in block.vertices:
            v.uv = map_to_chart_region(v, chart)
        
        atlas.append(chart)
    
    # 10. Pack all block charts into a global atlas
    # The sources do not specify the exact atlas packing algorithm.
    # A standard implementation uses a greedy or shelf-based bin-packing strategy.
    pack_atlas(atlas)
    
    # 11. Offset vertex UV coordinates again to be relative to the atlas
    for block in reconstructed_volume.occupied_blocks:
        for v in block.vertices:
            v.uv = atlas.global_uv(v)
            
    return atlas
```

**Parameters:**
*   Block size: Fixed, determined by geometry compression structure [S1].
*   Rotating calipers: Used for minimum area rectangle fitting [S1].

**Edge Cases:**
*   Complex areas (e.g., fingers) may have multiple normal groups per block [S1].
*   Deterministic process ensures no UV transmission needed [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [G]
*   **Memory Complexity:** Not given in the sources. [G]
*   **Strengths:** Deterministic, no UV transmission, matches geometry compression structure, encourages global spatial coherence [S1].
*   **Limitations:** Non-trivial packing due to varying block positions across frames [S1].
*   **When to use:** When combined with block-level geometry compression [S1].

## Background
Introduced in [S1], it addresses the need for efficient texture compression in dynamic volumes by leveraging the block-based structure of the geometry representation [S1].
