# Gradient-Based Surface Shading

Also called: Gradient-Based Shading (Levoy), Gray-Scale Gradient Shading, Gray-level Shading, Grey-level gradient shading, Hohne shading, Object space shading, Phong Shading + Depth Cueing

## Overview
Gradient-Based Surface Shading is a local illumination technique for volume rendering that approximates surface normals using the gradient of the scalar field to apply Phong-style lighting (diffuse, specular, and ambient) [S2, unofficial][S4]. Unlike standard emission/absorption models, it makes surface details and boundaries more prominent by calculating lighting based on local orientation [S4]. It builds on [Gradient Estimation from Samples](2180-gradient-estimation-from-samples.md) by directly driving a shading model with these gradients, and differs from [Gradient-based Pre-computed Shading](3159-gradient-based-pre-computed-shading.md) by typically computing gradients on-the-fly or trading memory for time via precomputation [S4].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scalar volume $V$ with dimensions $W \times H \times D$, where each voxel $v_{i,j,k}$ holds an intensity value [S2, unofficial][S9]. A transfer function $\tau$ mapping intensity to opacity/color [S3, unofficial]. Light parameters: light direction $\omega_i$, view direction $\omega_o$, light intensity $L_l$, and material coefficients ($k_a, k_d, k_s$) [S2, unofficial].
*   **Output:** A shaded 2D image or ray-cast color value for each sample point [S3, unofficial].

**Data Structures:**
*   **Volume Grid:** Dense array of scalar values [S2, unofficial].
*   **Gradient Vector:** A 3D vector $\nabla f(x) = (G_x, G_y, G_z)$ computed at the sample location [S9].
*   **Normal Vector:** The normalized gradient $\mathbf{n} = \frac{\nabla f(x)}{|\nabla f(x)|}$ [S5, unofficial].

**Gradient Computation:**
The surface normal is approximated by the gradient of the scalar field [S5, unofficial]. The gradient is computed numerically using finite differences [S5, unofficial]. For a voxel at indices $(i, j, k)$ with value $v_{i,j,k}$ and physical spacing $(D_x, D_y, D_z)$, central differences are commonly used [S2, unofficial][S9]:

$$
G_x = \frac{v_{i+1,j,k} - v_{i-1,j,k}}{2 D_x}, \quad
G_y = \frac{v_{i,j+1,k} - v_{i,j-1,k}}{2 D_y}, \quad
G_z = \frac{v_{i,j,k+1} - v_{i,j,k-1}}{2 D_z}
$$

Alternative schemes include forward/backward differences or the Sobel Operator [S7, unofficial]. Forward difference for $G_x$: $v_{i+1,j,k} - v_{i,j,k}$ [S7, unofficial]. Backward difference: $v_{i,j,k} - v_{i-1,j,k}$ [S7, unofficial].

**Shading Model:**
The method substitutes the geometric surface normal in the Blinn-Phong illumination model with the normalized gradient derived from the volumetric data [S2, unofficial]. The total shading function $s(\tilde{x}, \omega_i, \omega_o)$ at position $\tilde{x}$ is the sum of ambient, diffuse, and specular components, modulated by the transfer function $\tau(\tilde{x})$ and depth cueing [S2, unofficial][S4]:

$$
s(\tilde{x}, \omega_i, \omega_o) = \tau(\tilde{x}) \cdot \left(1 + \frac{k_1}{d(\tilde{x})} + \frac{k_2}{d(\tilde{x})^2}\right) \cdot (L_{amb} + L_{diff} + L_{spec})
$$

Where:
1.  **Ambient:**
    $$ L_{amb} = L_l \cdot k_a $$
    This ensures voxels with gradients pointing away from the light source do not appear pitch black [S4].

2.  **Diffuse:**
    $$ L_{diff}(\tilde{x}, \omega_i) = L_l \cdot k_d \cdot \max(\mathbf{n} \cdot \omega_i, 0) $$
    The diffuse term modulates the initial light intensity based on the incident angle and the voxel's diffuse color [S4].

3.  **Specular:**
    $$ L_{spec}(\tilde{x}, \omega_i, \omega_o) = L_l \cdot k_s \cdot \max(\mathbf{n} \cdot \mathbf{h}, 0)^\alpha $$
    Where $\mathbf{h}$ is the normalized half-vector between light and view directions, and $\alpha$ is the shininess exponent [S2, unofficial][S4]. Large $\alpha$ results in small sharp highlights; smaller $\alpha$ results in bigger smoother highlights [S4].

**Parameters:**
*   $k_a, k_d, k_s$: Ambient, diffuse, and specular coefficients [S2, unofficial].
*   $\alpha$: Shininess exponent [S4].
*   $L_l$: Initial light intensity [S4].
*   $D_x, D_y, D_z$: Physical spacing between samples [S12, unofficial].
*   $k_1, k_2$: Depth cueing fall-off constants [S2, unofficial].
*   $d(\tilde{x})$: Distance from the sample to the picture plane [S2, unofficial].

**Pseudocode:**
```python
def compute_gradient(volume, i, j, k, dx, dy, dz):
    """
    Computes the gradient vector at voxel (i, j, k) using central differences.
    Handles boundary conditions by clamping indices to the volume bounds.
    """
    def get_voxel(ii, jj, kk):
        ii = max(0, min(ii, volume.width - 1))
        jj = max(0, min(jj, volume.height - 1))
        kk = max(0, min(kk, volume.depth - 1))
        return volume[ii, jj, kk]

    gx = (get_voxel(i + 1, j, k) - get_voxel(i - 1, j, k)) / (2.0 * dx)
    gy = (get_voxel(i, j + 1, k) - get_voxel(i, j - 1, k)) / (2.0 * dy)
    gz = (get_voxel(i, j, k + 1) - get_voxel(i, j, k - 1)) / (2.0 * dz)
    
    return (gx, gy, gz)

def gradient_shading_sample(volume, i, j, k, dx, dy, dz, 
                            L_l, L_vec, V_vec, k_a, k_d, k_s, alpha, k1, k2, d_x):
    """
    Computes the shaded color for a single sample point in the volume.
    """
    # 1. Compute gradient and normalize to get surface normal
    grad = compute_gradient(volume, i, j, k, dx, dy, dz)
    grad_mag = (grad[0]**2 + grad[1]**2 + grad[2]**2)**0.5
    
    if grad_mag < 1e-6:
        # Fallback for homogeneous regions where gradient is zero
        normal = (0.0, 0.0, 1.0)
    else:
        normal = (grad[0]/grad_mag, grad[1]/grad_mag, grad[2]/grad_mag)
        
    # 2. Compute lighting components
    # Ambient
    L_amb = L_l * k_a
    
    # Diffuse
    dot_nl = max(normal[0]*L_vec[0] + normal[1]*L_vec[1] + normal[2]*L_vec[2], 0.0)
    L_diff = L_l * k_d * dot_nl
    
    # Specular
    hx = L_vec[0] + V_vec[0]
    hy = L_vec[1] + V_vec[1]
    hz = L_vec[2] + V_vec[2]
    h_mag = (hx**2 + hy**2 + hz**2)**0.5
    if h_mag < 1e-6:
        h_vec = (0.0, 0.0, 0.0)
    else:
        h_vec = (hx/h_mag, hy/h_mag, hz/h_mag)
        
    dot_nh = max(normal[0]*h_vec[0] + normal[1]*h_vec[1] + normal[2]*h_vec[2], 0.0)
    L_spec = L_l * k_s * (dot_nh ** alpha)
    
    # 3. Combine with transfer function and depth cueing
    voxel_val = volume[i, j, k]
    tau = volume.transfer_function(voxel_val)
    depth_factor = 1.0 + k1 / d_x + k2 / (d_x ** 2)
    
    total_light = L_amb + L_diff + L_spec
    return tau * depth_factor * total_light
```

**Edge Cases and Pitfalls:**
*   **Homogeneous Regions:** If the gradient magnitude is very low or zero, the normal is undefined or noisy [S8, book].
*   **Noise Sensitivity:** Gradients are sensitive to noise; high-frequency noise emphasizes artifacts, making this method unsuitable for low SNR modalities like MRI, 3D ultrasound, or seismic data [S4][S8, book].
*   **Object Edges:** Central differences may smooth out sharp edges if adjacent pixels belong to different objects; backward differences provide better approximation at these boundaries [S12, unofficial].
*   **Clipping Surfaces:** When using clipping geometry, the computed gradient must be replaced with the clipping surface normal to avoid rendering artifacts [S4].
*   **Multivariate Fields:** The method is unsuitable for multivariate fields because the eigenvector representing the direction of greatest change only indicates orientation, not absolute direction, leading to sign flips and interpolation issues [S8, book].
*   **Thin Objects:** The technique may fail to display thin objects if the grey-level is inappropriate for locating the surface [S11, unofficial].

## Subtopics

### [Gradient Estimation Methods](15931-gradient-estimation-methods.md)
Focuses on the accuracy of the gradient vector itself rather than just the surface location. The choice of method (e.g., Sobel vs. Central Difference) significantly impacts visual artifacts like ripple effects when sample distances are large.

### Normal Influence Shading
A shading technique that reduces brightness based on the spatial frequency (gradient magnitude) of the intensity, simulating a normal-like effect without computing explicit normals [S15, unofficial]. It computes fine-grained screen-space derivatives of the intensity, calculates a shading factor as $\max(1.0 - \text{length}(dLum) \cdot \text{normal\_influence}, 0.0)$, and multiplies the layer color by this factor [S15, unofficial].

### Per-Volume Phong Shading with Gradient Textures
A volume shading technique used to enhance depth perception for all datasets by calculating gradients and storing them in an additional texture for every dataset [S16]. The shader program uses these gradient textures to calculate Phong shading individually for each dataset [S16].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample for gradient computation if precomputed, or $O(1)$ with a small constant for on-the-fly central differences (requires 6 neighbor lookups) [S4].
*   **Memory Complexity:** $O(1)$ additional memory if computed on-the-fly [S4]. If precomputed, $O(N)$ where $N$ is the number of voxels, requiring storage of 3 floats per voxel [S5, unofficial]. For a $256 \times 256 \times 256$ dataset, precomputing gradients requires more than 200 MB [S5, unofficial].
*   **Performance:** Highly dependent on the Signal-to-Noise Ratio (SNR) of the data. It is widely used in interactive volume rendering due to its simplicity and effectiveness in enhancing surface details [S4].
*   **Strengths:** Makes surface details prominent; computationally inexpensive per sample; easy to implement; supports arbitrary numbers of point and directional light sources [S4].
*   **Limitations:** Not robust for homogeneous regions; sensitive to noise; unsuitable for multivariate fields; does not support shadows or global illumination effects (local shading only) [S4][S8, book].
*   **When to Use:** High-quality CT data with high SNR where surface detail enhancement is desired [S4].
*   **When Not to Use:** Low SNR data (MRI, ultrasound), multivariate fields, or when global illumination/shadows are required [S4][S8, book].

## Background
Gradient-based shading was published by Hohne and Bernstein in 1986, using gray-level gradients to perform shading of surfaces rendered from 3D CT data [S10, unofficial]. It was further popularized by Levoy in 1988 with volume raycasting [S2, unofficial][S10, unofficial]. It remains one of the most widely used shading techniques in interactive volume rendering [S4].
