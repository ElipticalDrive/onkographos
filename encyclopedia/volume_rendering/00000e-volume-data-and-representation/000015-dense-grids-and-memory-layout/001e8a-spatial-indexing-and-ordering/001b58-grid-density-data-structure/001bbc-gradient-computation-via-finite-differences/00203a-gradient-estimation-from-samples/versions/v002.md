# Gradient Estimation from Samples

Also called: Gradient-based Volume Shading, Multi-Volume Ray Casting Gradient Estimation and Shading, vtkGPUMultiVolumeRayCastMapper shading logic

## Overview
This method computes gradient vectors for volume shading by sampling the 3D texture at positions offset from the current reconstruction sample, thereby avoiding the expensive computation of a separate pre-calculated gradient field [S2]. It performs the finite difference approximation implicitly during the ray-casting shading pass rather than storing the result in a dedicated array [G]. It differs from the Sobel Operator by using simple forward/backward offsets along axes rather than a 3x3x3 kernel, and from Jacobian Estimation via Central Differences by relying on specific hardware texture sampling offsets provided by the rendering pipeline context [G].

## How it works
**Inputs and Outputs:**
*   **Input:** Current sample position in texture coordinates (`posX[volNumber-1]`), the 3D volume texture (`dataSetTexture`), color mapping texture (`colorTexture`), light source parameters (position, attenuation, spot cutoff/exponent/direction), material parameters (shininess), and transformation matrices (`eyeToTexture4`, `transposeTextureToEye`) [S1].
*   **Output:** A `vec4` final color value for the sample [S1].

**Data Structures:**
*   `dataSetTexture`: Array of `sampler3D` objects. Index `volNumber` accesses the texture for the current volume [S1].
*   `colorTexture`: Array of `sampler1D` objects. Max size is 4 on Apple platforms and 5 otherwise [S1].
*   `xvec`, `yvec`, `zvec`: Vectors defining the sampling offsets for the gradient components [S1].
*   `cellScale`: Scalar scaling factor for coordinate conversion [S1].
*   `transposeTextureToEye`: Matrix for transforming normals from texture space to eye space [S1].

**Steps:**

1.  **Gradient Sampling (Forward):** Compute the gradient vector `g1` by sampling the volume data at positions offset by `xvec`, `yvec`, and `zvec` from the current sample position `posX[volNumber-1]` [S1].
    $$ g1.x = \text{texture3D}(dataSetTexture[volNumber], posX[volNumber-1] + xvec[volNumber]).x $$
    $$ g1.y = \text{texture3D}(dataSetTexture[volNumber], posX[volNumber-1] + yvec[volNumber]).x $$
    $$ g1.z = \text{texture3D}(dataSetTexture[volNumber], posX[volNumber-1] + zvec[volNumber]).x $$

2.  **Gradient Sampling (Backward):** Compute the gradient vector `g2` by sampling the volume data at positions offset by the negative of `xvec`, `yvec`, and `zvec` [S1].
    $$ g2.x = \text{texture3D}(dataSetTexture[volNumber], posX[volNumber-1] - xvec[volNumber]).x $$
    $$ g2.y = \text{texture3D}(dataSetTexture[volNumber], posX[volNumber-1] - yvec[volNumber]).x $$
    $$ g2.z = \text{texture3D}(dataSetTexture[volNumber], posX[volNumber-1] - zvec[volNumber]).x $$

3.  **Scale Gradient:** Convert the gradient from texture coordinates to eye coordinates by scaling `g2` with `cellScale` [S1].
    $$ g2 = g2 \times cellScale $$

4.  **Normalize and Transform Gradient:**
    *   Calculate length: $L = \text{length}(g2)$ [S1].
    *   If $L > 0.0$:
        *   Normalize: $g2_{norm} = \text{normalize}(g2)$ [S1].
        *   Transform to eye space: $g2 = \text{transposeTextureToEye} \times g2_{norm}$ [S1].
    *   Else:
        *   Set $g2 = (0.0, 0.0, 0.0)$ [S1].

5.  **Initialize Color:** Set `finalColor` to $(0.0, 0.0, 0.0, 0.0)$ [S1].

6.  **Light Direction Calculation:**
    *   If the light is positional (`gl_LightSource[0].position.w != 0.0`):
        *   Transform vertex position `hPos` to texture coordinates: $tmp = eyeToTexture4 \times hPos$ [S1].
        *   Convert to eye coordinates: $ldir = tmp.xyz / tmp.w$ [S1].
        *   Calculate light direction: $ldir = lightPos - ldir$ [S1].
        *   Calculate squared distance: $sqrDistance = \text{dot}(ldir, ldir)$ [S1].
        *   Normalize: $ldir = \text{normalize}(ldir)$ [S1].
        *   Calculate half vector: $h = \text{normalize}(ldir + wReverseRayDir)$ [S1].
    *   Else (directional light):
        *   $ldir$ is derived directly from the light source direction (implementation detail: typically `gl_LightSource[0].position.xyz` normalized) [G].
        *   $sqrDistance = 0.0$ (or irrelevant) [G].
        *   $h = \text{normalize}(ldir + wReverseRayDir)$ [S1].

7.  **Attenuation:**
    *   If positional:
        $$ att = \frac{1.0}{C + L\sqrt{sqrDistance} + Q \cdot sqrDistance} $$
        Where $C, L, Q$ are `gl_LightSource[0].constantAttenuation`, `linearAttenuation`, and `quadraticAttenuation` respectively [S1].
    *   Else:
        $$ att = 1.0 $$ [S1].

8.  **Spot Illumination:**
    *   If `gl_LightSource[0].spotCutoff == 180.0`:
        $$ spot = 1.0 $$ [S1].
    *   Else:
        $$ coef = -\text{dot}(ldir, gl\_LightSource[0].spotDirection) $$ [S1].
        *   If $coef \ge gl\_LightSource[0].spotCosCutoff$:
            $$ spot = coef^{gl\_LightSource[0].spotExponent} $$ [S1].
        *   Else:
            $$ spot = 0.0 $$ [S1].

9.  **Shading Calculation:**
    *   If $spot > 0.0$:
        *   Calculate dot products:
            $$ nDotL = \text{dot}(g2, ldir) $$ [S1].
            $$ nDotH = \text{dot}(g2, h) $$ [S1].
        *   **Two-sided shading:** If $nDotL < 0.0$, negate $nDotL$. If $nDotH < 0.0$, negate $nDotH$ [S1].
        *   **Ambient:**
            $$ finalColor += gl\_FrontLightProduct[0].ambient $$ [S1].
        *   **Diffuse:** If $nDotL > 0.0$:
            $$ finalColor += (gl\_FrontLightProduct[0].diffuse \times nDotL) \times color $$ [S1].
            Where `color` is obtained from `colorFromValue(volNumber, value)` [S1].
        *   **Specular:**
            $$ shininessFactor = nDotH^{gl\_FrontMaterial.shininess} $$ [S1].
            $$ finalColor += gl\_FrontLightProduct[0].specular \times shininessFactor $$ [S1].
        *   **Apply Light Factors:**
            $$ finalColor *= att \times spot $$ [S1].
        *   **Scene Ambient:**
            $$ finalColor += gl\_FrontLightModelProduct.sceneColor \times color $$ [S1].

10. **Clamping:**
    $$ finalColor = \text{clamp}(finalColor, clampMin, clampMax) $$ [S1].

**Pseudocode:**

```python
def shade_volume_sample(vol_number, value, pos_texture, h_pos, light_source, front_material, 
                        eye_to_texture, transpose_texture_to_eye, cell_scale, 
                        xvec, yvec, zvec, clamp_min, clamp_max, w_reverse_ray_dir, 
                        is_one_component, volume_data, color_texture):
    """
    Computes the shaded color for a volume sample using gradient estimation from samples.
    """
    
    # 1. Sample Gradient Components (Forward)
    g1_x = sample_3d_texture(vol_number, pos_texture + xvec[vol_number], volume_data)
    g1_y = sample_3d_texture(vol_number, pos_texture + yvec[vol_number], volume_data)
    g1_z = sample_3d_texture(vol_number, pos_texture + zvec[vol_number], volume_data)
    
    # 2. Sample Gradient Components (Backward)
    g2_x = sample_3d_texture(vol_number, pos_texture - xvec[vol_number], volume_data)
    g2_y = sample_3d_texture(vol_number, pos_texture - yvec[vol_number], volume_data)
    g2_z = sample_3d_texture(vol_number, pos_texture - zvec[vol_number], volume_data)
    
    # 3. Construct and Scale Gradient
    g2 = vec3(g2_x, g2_y, g2_z) * cell_scale[vol_number]
    
    # 4. Normalize and Transform Gradient
    normal_length = length(g2)
    if normal_length > 0.0:
        g2_normalized = normalize(g2)
        # Transform to eye coordinates
        g2 = transpose_texture_to_eye[vol_number] @ g2_normalized
    else:
        g2 = vec3(0.0, 0.0, 0.0)
        
    # 5. Initialize Final Color
    final_color = vec4(0.0, 0.0, 0.0, 0.0)
    
    # 6. Light Direction and Properties
    light_pos = light_source.position
    is_positional = light_pos.w != 0.0
    
    if is_positional:
        # Transform vertex position to texture coords then to eye coords
        tmp = eye_to_texture[vol_number] @ h_pos
        ldir = tmp.xyz / tmp.w
        ldir = light_pos.xyz - ldir
        sqr_distance = dot(ldir, ldir)
        ldir = normalize(ldir)
    else:
        # Directional light
        ldir = normalize(light_pos.xyz)
        sqr_distance = 0.0
        
    # Half vector calculation
    h = normalize(ldir + w_reverse_ray_dir)
    
    # 7. Attenuation
    att = 1.0
    if is_positional:
        c = light_source.constant_attenuation
        l = light_source.linear_attenuation
        q = light_source.quadratic_attenuation
        att = 1.0 / (c + l * sqrt(sqr_distance) + q * sqr_distance)
        
    # 8. Spot Illumination
    spot = 1.0
    if light_source.spot_cutoff != 180.0:
        coef = -dot(ldir, light_source.spot_direction)
        if coef >= light_source.spot_cos_cutoff:
            spot = pow(coef, light_source.spot_exponent)
        else:
            spot = 0.0
            
    # 9. Shading
    if spot > 0.0:
        # Get color from value
        color = get_color_from_value(vol_number, value, is_one_component, color_texture)
        
        nDotL = dot(g2, ldir)
        nDotH = dot(g2, h)
        
        # Two-sided shading
        if nDotL < 0.0:
            nDotL = -nDotL
        if nDotH < 0.0:
            nDotH = -nDotH
            
        # Ambient
        final_color += light_source.front_ambient
        
        # Diffuse
        if nDotL > 0.0:
            final_color += light_source.front_diffuse * nDotL * color
            
        # Specular
        shininess_factor = pow(nDotH, front_material.shininess)
        final_color += light_source.front_specular * shininess_factor
        
        # Apply attenuation and spot
        final_color *= att * spot
        
        # Scene Ambient
        final_color += light_source.scene_ambient * color
        
    # 10. Clamping
    final_color = clamp(final_color, clamp_min, clamp_max)
    
    return final_color

def sample_3d_texture(vol_number, coords, volume_data):
    """
    Helper to simulate texture3D lookup.
    Returns the scalar value (x component) at the given coordinates.
    """
    # In a real implementation, this calls the GPU texture sampler
    # For the purpose of this algorithm description, we assume access to the volume data
    # at 'coords' for 'vol_number'.
    return volume_data[vol_number].sample(coords)

def get_color_from_value(vol_number, value, is_one_component, color_texture):
    """
    Converts the raw volume value to a color.
    Handles 1-component (uses color map) and 4-component (uses RGBA directly) datasets.
    """
    if is_one_component:
        scalar = value.x
        return texture_1d(color_texture[vol_number], scalar)
    else:
        # Four-component dataset
        return vec4(value.x, value.y, value.z, 1.0)

def texture_1d(texture, coord):
    """
    Helper to simulate texture1D lookup.
    Returns the vec4 color at the given 1D coordinate.
    """
    return texture.sample(coord)
```

**Parameters:**
*   `clampMin`, `clampMax`: Float values defining the lower and upper bounds for clamping the final color to prevent black spots [S1].
*   `cellScale`: Scalar used to scale the gradient vector from texture coordinates to eye coordinates [S1].
*   `transposeTextureToEye`: Matrix used to transform the normalized gradient from texture space to eye coordinates [S1].

**Edge Cases and Pitfalls:**
*   **Black Spots:** Occur if the final color is not clamped or if negative dot products are not handled for two-sided shading [S1]. The algorithm mitigates this by negating `nDotL` and `nDotH` if negative and clamping the result [S1].
*   **Zero Gradient:** If the gradient length is zero, the normal is set to `(0,0,0)`, resulting in no diffuse/specular contribution (only ambient) [S1].
*   **Texture Boundaries:** Sampling at `posX ± vec` may go out of bounds. The behavior depends on the texture sampler's wrap mode (e.g., clamp, repeat). Not explicitly defined in sources, but standard OpenGL/Vulkan texture sampling rules apply [G].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample, as it requires a fixed number of texture lookups (6 for gradient, plus shading calculations).
*   **Memory Complexity:** $O(1)$ additional memory per sample, as gradients are computed on-the-fly and not stored.
*   **Performance:** Efficient for interactive visualization on GPU workstations, as it avoids pre-computing and storing large gradient fields [S2].
*   **Strengths:** Low memory footprint, simple implementation, suitable for adaptive mesh refinement (AMR) data where gradient fields might be complex to pre-calculate [S2].
*   **Limitations:** Gradient accuracy depends on the sampling offsets (`xvec`, `yvec`, `zvec`). May be noisier than Sobel or central difference methods if offsets are not carefully chosen.
*   **When to use:** Interactive volume rendering where memory is constrained or data is adaptive (AMR) [S2].
*   **When not to use:** When high-precision gradient information is critical for physical accuracy, or when post-processing effects require smooth gradients.

## Background
This method was described in the context of ray tracing structured AMR (Adaptive Mesh Refinement) data using ExaBricks [S2]. It was introduced to support high-quality cell interpolation and interactive visualization on individual GPU workstations for highly complex models [S2]. The implementation details are found in the VTK source code for `vtkOpenGLGPUMultiVolumeRayCastMapper` [S1, unofficial].
