# Laplacian Grid Computation via Finite Differences

Also called: First Derivative and Laplacian Operators, Laplacian Field Transformation, applyDx, applyDy

## Overview
Computes the discrete Laplacian of a scalar field on a 2D grid using finite difference operators. It differs from standard central difference implementations by constructing the Laplacian matrix as the sum of the transpose of the forward difference operator applied to the forward difference operator ($D^T D$), which implicitly enforces specific boundary conditions (zero-padding with reflected signs for the transpose). This method is primarily used in inverse problems and regularization contexts where the adjoint structure is required for optimization solvers like GMRES.

## How it works
**Inputs:**
- `f`: A 2D numpy array of shape $(H, W)$ representing the scalar field values.
- `gamma` (optional): A weighting matrix or scalar. If provided, it is used to weight the derivatives. If not an ndarray, it defaults to an identity matrix of size $H \times H$ [S1, unofficial].

**Outputs:**
- `laplace_f`: A 1D numpy array of shape $(H \times W,)$ containing the flattened Laplacian values.

**Data Structures:**
- The method operates directly on the input array `f`. No auxiliary grid structures are built; the operators are applied via array slicing and summation.

**Steps:**
1. **Compute Forward X-Derivative ($D_x$):**
   Apply the forward difference along axis 0 (rows).
   $$ D_x = \text{diff}(f, \text{axis}=0) $$
   Append a zero row at the bottom to maintain shape $(H, W)$:
   $$ D_x = \text{vstack}(D_x, \text{zeros}((1, W))) $$
   [S1, unofficial]

2. **Compute Forward Y-Derivative ($D_y$):**
   Apply the forward difference along axis 1 (columns).
   $$ D_y = \text{diff}(f, \text{axis}=1) $$
   Append a zero column at the right to maintain shape $(H, W)$:
   $$ D_y = \text{hstack}(D_y, \text{zeros}((H, 1))) $$
   [S1, unofficial]

3. **Compute Transpose X-Derivative ($D_x^T$):**
   The transpose operator is constructed explicitly to satisfy the adjoint property of the forward difference with zero-boundary conditions.
   $$ D_x^T = \text{vstack}(-f[0:1, :], -\text{diff}(f[:-1, :], \text{axis}=0), f[-2:-1, :]) $$
   [S1, unofficial]
   *Note:* The first row is the negative of the first row of `f`. The middle rows are the negative forward differences of `f` excluding the last row. The last row is the second-to-last row of `f`.

4. **Compute Transpose Y-Derivative ($D_y^T$):**
   Similarly, the transpose for the Y-direction is:
   $$ D_y^T = \text{hstack}(-f[:, 0:1], -\text{diff}(f[:, :-1], \text{axis}=1), f[:, -2:-1]) $$
   [S1, unofficial]
   *Note:* The first column is the negative of the first column of `f`. The middle columns are the negative forward differences of `f` excluding the last column. The last column is the second-to-last column of `f`.

5. **Compute Laplacian Components:**
   - **Unweighted:**
     $$ d_{xx} = D_x^T (D_x f) $$
     $$ d_{yy} = D_y^T (D_y f) $$
     $$ \Delta f = d_{xx} + d_{yy} $$
     [S1, unofficial]
   - **Weighted (with $\gamma$):**
     If $\gamma$ is provided:
     $$ d_{xx} = \sqrt{\gamma} D_x^T (\sqrt{\gamma} D_x f) $$
     $$ d_{yy} = \sqrt{\gamma} D_y^T (\sqrt{\gamma} D_y f) $$
     $$ \Delta f = d_{xx} + d_{yy} $$
     [S1, unofficial]
     Here, $\sqrt{\gamma}$ denotes element-wise square root if $\gamma$ is a matrix, or scalar square root. The multiplication `@` denotes matrix multiplication.

6. **Flatten:**
   Return $\Delta f$ flattened to 1D.

**Pseudocode:**
```python
import numpy as np

def applyDx(u):
    """Applies the first derivative along the first dimension (rows)"""
    Dx = np.diff(u, axis=0)
    # Append a zero row at the bottom
    Dx = np.vstack([Dx, np.zeros((1, u.shape[1]))])
    return Dx

def applyDy(u):
    """Applies the first derivative along the second dimension (columns)"""
    Dy = np.diff(u, axis=1)
    # Append a zero column at the right
    Dy = np.hstack([Dy, np.zeros((u.shape[0], 1))])
    return Dy

def applyDxTrans(u):
    """Applies the transpose of the first derivative along the first dimension (rows)"""
    # First row: negative of the first row of u
    # Middle rows: negative forward diff of u excluding last row
    # Last row: second-to-last row of u
    DxT = np.vstack([-u[0:1, :], -np.diff(u[:-1, :], axis=0), u[-2:-1, :]])
    return DxT

def applyDyTrans(u):
    """Applies the transpose of the first derivative along the second dimension (columns)"""
    # First col: negative of the first col of u
    # Middle cols: negative forward diff of u excluding last col
    # Last col: second-to-last col of u
    DyT = np.hstack([-u[:, 0:1], -np.diff(u[:, :-1], axis=1), u[:, -2:-1]])
    return DyT

def laplacian(f, gamma=0):
    """
    Computes the Laplacian of f.
    If gamma is not 0, computes the weighted Laplacian.
    """
    if not isinstance(gamma, np.ndarray):
        gamma = np.eye(f.shape[0])
    
    sqrt_gamma = np.sqrt(gamma)
    
    # Weighted forward derivatives
    Dx_f = applyDx(f)
    Dy_f = applyDy(f)
    
    # Apply sqrt(gamma) to the derivatives
    # Note: In the source, sqrt(gamma) @ applyDx(f) implies matrix multiplication.
    # If gamma is diagonal, this scales rows. If gamma is identity, it's unchanged.
    Dx_f_weighted = sqrt_gamma @ Dx_f
    Dy_f_weighted = sqrt_gamma @ Dy_f
    
    # Apply transpose derivatives
    DxT = applyDxTrans(f)
    DyT = applyDyTrans(f)
    
    # Apply sqrt(gamma) to the transpose derivatives
    DxT_weighted = sqrt_gamma @ DxT
    DyT_weighted = sqrt_gamma @ DyT
    
    # Compute components
    dxx = DxT_weighted @ Dx_f_weighted
    dyy = DyT_weighted @ Dy_f_weighted
    
    laplace_f = dxx + dyy
    
    return laplace_f.flatten()

def laplacian_unweighted(f):
    """Computes the unweighted Laplacian"""
    dxx = applyDxTrans(applyDx(f))
    dyy = applyDyTrans(applyDy(f))
    laplace_f = dxx + dyy
    return laplace_f.flatten()
```

**Parameters:**
- `gamma`: Default 0 (unweighted). If provided, must be compatible with matrix multiplication with the derivative outputs. [S1, unofficial]

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** The explicit construction of $D^T$ implies specific boundary handling. The first row/col of the output depends on the first row/col of the input, and the last row/col depends on the second-to-last. This is not a standard Neumann or Dirichlet zero-boundary Laplacian but rather the adjoint of the forward difference with zero-padding. [S1, unofficial]
- **Gamma Type:** If `gamma` is a scalar, it is converted to an identity matrix. If it is a matrix, it must be square and compatible with the height of `f`. [S1, unofficial]
- **Shape Mismatch:** The transpose operators assume `f` is 2D. Applying to higher dimensions requires adaptation not present in the source. [S1, unofficial]

## Subtopics

### Time Smoothness Regularization via Second Derivative
A regularizer that enforces smoothness over the time dimension of spatiotemporal grids by penalizing the second derivative. It identifies "time grids" (indices [2, 4, 5] if grid length is not 3, otherwise empty) and computes plane smoothness. The smoothness for a time grid $t$ is calculated as $\frac{1}{N} \sum (t_{i+2} - 2t_{i+1} + t_i)^2$, where the second difference is computed along the time dimension. [S2, unofficial]

## Operating characteristics
- **Time Complexity:** $O(H \times W)$ for the unweighted case, as it involves a constant number of passes over the grid. The weighted case adds matrix multiplication cost $O(H^2 W)$ if $\gamma$ is dense, or $O(H W)$ if $\gamma$ is diagonal. [S1, unofficial]
- **Memory Complexity:** $O(H \times W)$ for storing intermediate derivative arrays. [S1, unofficial]
- **Strengths:** Provides the exact adjoint of the forward difference operator, which is crucial for gradient-based optimization in inverse problems (e.g., CT reconstruction) where the forward operator is $D_x$. [S1, unofficial]
- **Limitations:** The boundary conditions are implicit and non-standard compared to central differences. It is specific to 2D grids in the provided implementation. [S1, unofficial]

## Background
This method originates from implementations in inverse problems for CT scans, specifically in the context of regularization using total variation or similar norms where the Laplacian matrix is constructed via finite differences. The specific `applyDx`/`applyDxTrans` pattern is documented in the `inverse-problems-CT-scans` repository. [S1, unofficial]
