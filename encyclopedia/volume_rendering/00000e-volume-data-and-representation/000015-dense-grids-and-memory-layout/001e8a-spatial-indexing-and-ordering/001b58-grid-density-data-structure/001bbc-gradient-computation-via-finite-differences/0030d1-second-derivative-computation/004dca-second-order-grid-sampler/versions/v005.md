# Second-order Grid Sampler

Also called: Double back-propagation for grid sampler, Hessian computation for SDF, Hessian computation for SDF via double backprop, Second-order derivative computation for SDF regularization, Second-order derivatives via double backpropagation

## Overview
The Second-order Grid Sampler computes the Hessian matrix of a Signed Distance Field (SDF) with respect to 3D query coordinates and feature grid parameters by manually implementing the second-order derivatives of trilinear interpolation. It solves the problem that standard automatic differentiation frameworks (e.g., PyTorch) do not support double back-propagation through the grid sampling operation [S1]. Unlike [Second Derivative Computation](6353-second-derivative-computation.md), which uses finite differences on discrete grids, this method operates on continuous coordinates within a learned feature grid, providing exact analytical second derivatives required for gradient regularization in neural surface reconstruction [S1].

## How it works
**Inputs and Outputs:**
- **Input:**
  - Query point coordinates $x = [x, y, z]^T \in \mathbb{R}^3$, normalized to $[0, 1]$ within the voxel containing the point.
  - Feature vector $\theta \in \mathbb{R}^8$, representing the values at the 8 vertices of the enclosing voxel, ordered as $[\theta_{000}, \theta_{001}, \theta_{010}, \theta_{011}, \theta_{100}, \theta_{101}, \theta_{110}, \theta_{111}]^T$.
  - (Optional) Geometry network parameters $\omega$ and feature dimension $C$. Note: The core Hessian blocks w.r.t $x$ and $\theta$ are independent of $\omega$ and $C$ due to the linearity of the interpolation step.
- **Output:**
  - The $3 \times 3$ Hessian matrix $H = \frac{\partial^2 f}{\partial x \partial x^T}$ of the interpolated feature value $f$ with respect to $x$.
  - The $3 \times 8$ mixed derivative matrix $\frac{\partial^2 f}{\partial x \partial \theta}$.

**Data Structures:**
- **Coefficient Vector $w(x)$:** An 8-element vector of trilinear interpolation weights.
- **Jacobian Matrix $J_w$:** An $8 \times 3$ matrix containing the first derivatives of $w(x)$ with respect to $x, y, z$.
- **Hessian Matrix $H$:** A $3 \times 3$ symmetric matrix.

**Step-by-Step Method:**

1.  **Compute Interpolation Weights $w(x)$:**
    Calculate the 8 coefficients for the vertices of the voxel enclosing $x$. The indices correspond to the binary representation of the vertex offsets $(dx, dy, dz)$ where $dx, dy, dz \in \{0, 1\}$.
    $$
    \begin{aligned}
    w_0 &= (1-x)(1-y)(1-z) \\
    w_1 &= (1-x)(1-y)z \\
    w_2 &= (1-x)y(1-z) \\
    w_3 &= (1-x)yz \\
    w_4 &= x(1-y)(1-z) \\
    w_5 &= x(1-y)z \\
    w_6 &= xy(1-z) \\
    w_7 &= xyz
    \end{aligned}
    $$
    The interpolated feature value is $f = \theta^T w(x) = \sum_{i=0}^7 \theta_i w_i$.

2.  **Compute Jacobian Columns $J_1, J_2, J_3$:**
    The Jacobian $\frac{\partial w}{\partial x}$ is an $8 \times 3$ matrix with columns $J_1 = \frac{\partial w}{\partial x}$, $J_2 = \frac{\partial w}{\partial y}$, and $J_3 = \frac{\partial w}{\partial z}$.
    
    Column $J_1$ (derivatives w.r.t $x$):
    $$
    J_1 = \begin{bmatrix} -(1-y)(1-z) \\ -(1-y)z \\ -y(1-z) \\ -yz \\ (1-y)(1-z) \\ (1-y)z \\ y(1-z) \\ yz \end{bmatrix}
    $$
    
    Column $J_2$ (derivatives w.r.t $y$):
    $$
    J_2 = \begin{bmatrix} -(1-x)(1-z) \\ -(1-x)z \\ (1-x)(1-z) \\ (1-x)z \\ -x(1-z) \\ -xz \\ x(1-z) \\ xz \end{bmatrix}
    $$
    
    Column $J_3$ (derivatives w.r.t $z$):
    $$
    J_3 = \begin{bmatrix} -(1-x)(1-y) \\ (1-x)(1-y) \\ -(1-x)y \\ (1-x)y \\ -x(1-y) \\ x(1-y) \\ -xy \\ xy \end{bmatrix}
    $$

3.  **Compute Mixed Derivative $\frac{\partial^2 f}{\partial x \partial \theta}$:**
    This block is the transpose of the Jacobian of the weights with respect to $x$.
    $$
    \frac{\partial^2 f}{\partial x \partial \theta} = \left( \frac{\partial w}{\partial x} \right)^T = \begin{bmatrix} J_1^T \\ J_2^T \\ J_3^T \end{bmatrix}
    $$
    This results in a $3 \times 8$ matrix.

4.  **Compute Hessian $\frac{\partial^2 f}{\partial x^2}$:**
    The Hessian $H$ is a $3 \times 3$ symmetric matrix.
    
    **Diagonal Elements:**
    The diagonal elements are zero because the derivative of $w_i$ with respect to a coordinate (e.g., $x$) depends only on the other two coordinates ($y, z$), which are treated as constants when differentiating again with respect to $x$.
    $$
    h_{11} = h_{22} = h_{33} = 0
    $$
    
    **Off-Diagonal Elements:**
    The off-diagonal elements are computed using the feature values $\theta$ and the coordinates.
    
    $h_{12} = h_{21}$:
    $$
    h_{12} = (1-z)(\theta_{000} + \theta_{110} - \theta_{010} - \theta_{100}) + z(\theta_{001} + \theta_{111} - \theta_{011} - \theta_{101})
    $$
    
    $h_{13} = h_{31}$:
    $$
    h_{13} = (1-y)(\theta_{000} + \theta_{101} - \theta_{001} - \theta_{100}) + y(\theta_{010} + \theta_{111} - \theta_{011} - \theta_{110})
    $$
    
    $h_{23} = h_{32}$:
    $$
    h_{23} = (1-x)(\theta_{000} + \theta_{011} - \theta_{001} - \theta_{010}) + x(\theta_{100} + \theta_{111} - \theta_{101} - \theta_{110})
    $$

5.  **Assemble Full SDF Hessian (if required):**
    If the SDF $\phi$ is defined as $\phi(x, \theta, \omega) = f_\omega(z(\theta, x))$, where $f_\omega$ is a geometry network (MLP) taking the interpolated feature vector $z$, the full Hessian blocks required for regularization are:
    - $\frac{\partial^2 \phi}{\partial x^2} = \sum_{i=1}^C \left( \frac{\partial^2 f_\omega}{\partial z_i^2} \left(\frac{\partial z_i}{\partial x}\right)^2 + \frac{\partial f_\omega}{\partial z_i} \frac{\partial^2 z_i}{\partial x^2} \right)$ [S1]. Here $\frac{\partial z_i}{\partial x}$ is the $i$-th row of $\frac{\partial^2 f}{\partial x \partial \theta}$, and $\frac{\partial^2 z_i}{\partial x^2}$ is the $i$-th row of $H$.
    - $\frac{\partial^2 \phi}{\partial x \partial \theta} = \sum_{i=1}^C \frac{\partial^2 f_\omega}{\partial z_i^2} \frac{\partial z_i}{\partial \theta} \frac{\partial z_i}{\partial x}$ [S1]. Note that $\frac{\partial z_i}{\partial \theta}$ is the $i$-th column of the identity matrix (since $z_i$ is the $i$-th feature component), simplifying to $\sum_{i=1}^C \frac{\partial^2 f_\omega}{\partial z_i^2} \frac{\partial z_i}{\partial x}$.
    
    *Note: The implementation of Eq. 5 ($\frac{\partial^2 \phi}{\partial x \partial \omega}$) is not required as PyTorch supports double back-propagation through the MLP $f_\omega$ [S1].*

**Pseudocode:**

```python
import torch

def second_order_grid_sampler(theta, x):
    """
    Computes the Hessian of the interpolated feature value f w.r.t. x
    and the mixed derivative w.r.t. x and theta.
    
    Args:
        theta: Tensor of shape (8,) or (N, 8), feature values at voxel corners.
               Order: [000, 001, 010, 011, 100, 101, 110, 111]
        x: Tensor of shape (3,) or (N, 3), query coordinates in [0, 1].
           Order: [x, y, z]
           
    Returns:
        H: Tensor of shape (3, 3) or (N, 3, 3), Hessian d^2f/dx^2.
        H_x_theta: Tensor of shape (3, 8) or (N, 3, 8), Mixed derivative d^2f/dxdtheta.
    """
    # Ensure x is 2D for batch processing: (N, 3)
    if x.dim() == 1:
        x = x.unsqueeze(0)
        theta = theta.unsqueeze(0)
        
    x_coord, y_coord, z_coord = x[:, 0], x[:, 1], x[:, 2]
    
    # 1. Compute Jacobian Columns J1, J2, J3 (Shape: N, 8)
    # J1: d/dx
    J1 = torch.stack([
        -(1-y_coord)*(1-z_coord), -(1-y_coord)*z_coord, -y_coord*(1-z_coord), -y_coord*z_coord,
        (1-y_coord)*(1-z_coord), (1-y_coord)*z_coord, y_coord*(1-z_coord), y_coord*z_coord
    ], dim=1)
    
    # J2: d/dy
    J2 = torch.stack([
        -(1-x_coord)*(1-z_coord), -(1-x_coord)*z_coord, (1-x_coord)*(1-z_coord), (1-x_coord)*z_coord,
        -x_coord*(1-z_coord), -x_coord*z_coord, x_coord*(1-z_coord), x_coord*z_coord
    ], dim=1)
    
    # J3: d/dz
    J3 = torch.stack([
        -(1-x_coord)*(1-y_coord), (1-x_coord)*(1-y_coord), -(1-x_coord)*y_coord, (1-x_coord)*y_coord,
        -x_coord*(1-y_coord), x_coord*(1-y_coord), -x_coord*y_coord, x_coord*y_coord
    ], dim=1)
    
    # H_x_theta is the transpose of the Jacobian matrix [J1, J2, J3]
    # J_w is (N, 8, 3). H_x_theta is (N, 3, 8).
    J_w = torch.stack([J1, J2, J3], dim=2) # (N, 8, 3)
    H_x_theta = J_w.permute(0, 2, 1)      # (N, 3, 8)
    
    # 2. Compute Hessian H (Shape: N, 3, 3)
    # Diagonals are 0
    H = torch.zeros(x.shape[0], 3, 3, device=x.device)
    
    # Off-diagonals
    # h12 = h21
    term1_12 = (1-z_coord) * (theta[:, 0] + theta[:, 6] - theta[:, 2] - theta[:, 4])
    term2_12 = z_coord * (theta[:, 1] + theta[:, 7] - theta[:, 3] - theta[:, 5])
    h12 = term1_12 + term2_12
    
    # h13 = h31
    term1_13 = (1-y_coord) * (theta[:, 0] + theta[:, 5] - theta[:, 1] - theta[:, 4])
    term2_13 = y_coord * (theta[:, 2] + theta[:, 7] - theta[:, 3] - theta[:, 6])
    h13 = term1_13 + term2_13
    
    # h23 = h32
    term1_23 = (1-x_coord) * (theta[:, 0] + theta[:, 3] - theta[:, 1] - theta[:, 2])
    term2_23 = x_coord * (theta[:, 4] + theta[:, 7] - theta[:, 5] - theta[:, 6])
    h23 = term1_23 + term2_23
    
    # Fill symmetric matrix
    H[:, 0, 1] = h12
    H[:, 1, 0] = h12
    H[:, 0, 2] = h13
    H[:, 2, 0] = h13
    H[:, 1, 2] = h23
    H[:, 2, 1] = h23
    
    # Reshape if input was 1D
    if x.dim() == 1:
        H = H.squeeze(0)
        H_x_theta = H_x_theta.squeeze(0)
        
    return H, H_x_theta
```

**Parameters:**
- **Feature Dimension:** The derivation assumes 1-D features for simplicity but generalizes to any feature dimension $C$ as the derivation is equivalent for all dimensions [S1].
- **Coordinate Normalization:** Coordinates $x, y, z$ must be normalized to $[0, 1]$ relative to the voxel boundaries [S1].

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** The method assumes the query point $x$ lies strictly within a voxel $[0,1]^3$. If $x$ is outside, the weights $w(x)$ may become negative or exceed 1, leading to extrapolation artifacts. Standard implementations assume zero-padding or clamping for neighbors outside the active domain, but the analytical derivatives derived here are local to the voxel [S1, Parent].
- **Higher-Order Tensors:** The method explicitly avoids constructing higher-order tensors (e.g., $N \times 8 \times 3$ for gradients of gradients) by summing over feature dimensions $z_i$ as per Eq. 2, which is crucial for memory efficiency [S1].
- **PyTorch Limitations:** Standard `grid_sampler` does not support second-order gradients. Manual implementation of Eq. 3 and 4 is required; Eq. 5 can rely on PyTorch's autograd if the geometry network $f_\omega$ is differentiable [S1].

## Subtopics

### Mean Curvature Grid Computation
Computes the mean curvature from the trace of the Hessian. Chooses this when surface smoothness is prioritized over exact Hessian values. [Mean Curvature Grid Computation](3126-mean-curvature-grid-computation.md)

### Laplacian Grid Computation
Computes the Laplacian (sum of diagonal second derivatives). Chooses this for diffusion-based smoothing. [Laplacian Grid Computation](3160-laplacian-grid-computation.md)

### Second Derivative Computation
General finite difference approach for discrete grids. Chooses this when working with voxelized SDFs rather than continuous feature grids. [Second Derivative Computation](6353-second-derivative-computation.md)

## Operating characteristics
- **Time Complexity:** $O(1)$ per query point, as it involves a fixed number of arithmetic operations (8 multiplications/additions for weights, constant time for Jacobian and Hessian elements).
- **Memory Complexity:** $O(1)$ auxiliary memory per query point. No large tensors are stored.
- **Performance:** Significantly faster than numerical differentiation or automatic differentiation through grid sampling (which is unsupported). It enables real-time gradient regularization during training of neural surface reconstruction models [S1].
- **Strengths:** Exact analytical derivatives; memory efficient; compatible with standard deep learning frameworks (via manual implementation).
- **Limitations:** Limited to trilinear interpolation; does not handle higher-order interpolation schemes without re-derivation; requires coordinates to be within voxel bounds for valid weights.

## Background
The Second-order Grid Sampler was introduced in the context of "GO-Surf: Neural Feature Grid Optimization for Fast, High-Fidelity RGB-D Surface Reconstruction" by Jingwen Wang, Tymoteusz Bleja, and Lourdes Agapito (UCL, 2022) [S1]. It was developed to address the need for gradient regularization in learning geometry priors on large datasets. The method allows double back-propagation through the grid sampler to compute the Hessian of the SDF, which is used to regularize the gradient term in the loss function, improving reconstruction fidelity [S1].
