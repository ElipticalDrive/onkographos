# Laplacian Grid Computation via Finite Differences

Also called: First Derivative and Laplacian Operators, Laplacian Field Transformation, applyDx, applyDy

## Overview
This method computes the discrete Laplacian of a 2D grid by applying forward and backward finite difference operators along each axis. It constructs the Laplacian matrix implicitly via matrix-vector multiplication, supporting both uniform and weighted (gamma) formulations. It differs from standard stencil-based approaches by explicitly handling boundary conditions through zero-padding and transpose operations, making it suitable for optimization problems where the Laplacian acts as a regularizer [S1, unofficial].

## How it works
**Inputs:**
- `f`: A 2D numpy array of shape $(H, W)$ representing the scalar field.
- `gamma` (optional): A weighting matrix or scalar. If scalar, it is treated as a uniform weight. If not provided, uniform Laplacian is computed.

**Outputs:**
- A flattened 1D array of shape $(H \times W,)$ containing the Laplacian values.

**Data Structures:**
- The method operates on dense 2D arrays. No sparse matrix structures are explicitly constructed; the operation is performed via dense matrix multiplication or array broadcasting.

**Steps:**

1. **Define Forward Difference Operators:**
   The forward difference along an axis is computed using `np.diff`, and a zero row/column is appended to maintain dimensions.
   - Along rows (axis 0): $D_x f$ is computed, then a zero row is appended at the bottom.
   - Along columns (axis 1): $D_y f$ is computed, then a zero column is appended at the right.

2. **Define Backward Difference Operators (Transposes):**
   The backward difference is the transpose of the forward difference. It is computed by taking negative differences and handling boundaries with negative edge values and a trailing positive edge value.
   - Along rows (axis 0): $D_x^T f$ is computed.
   - Along columns (axis 1): $D_y^T f$ is computed.

3. **Compute Laplacian Components:**
   The Laplacian $\nabla^2 f$ is approximated as $D_x^T D_x f + D_y^T D_y f$.

4. **Apply Gamma Weighting (Optional):**
   If a gamma matrix is provided, the operators are weighted by $\sqrt{\gamma}$ before and after the derivative application.

**Formulas:**

For the unweighted case:
$$ D_x f = \begin{bmatrix} f_{1,0}-f_{0,0} & \dots & f_{1,W-1}-f_{0,W-1} \\ \vdots & \ddots & \vdots \\ f_{H-1,W-1}-f_{H-2,W-1} & \dots & f_{H-1,W-1}-f_{H-2,W-1} \\ 0 & \dots & 0 \end{bmatrix} $$
$$ D_x^T u = \begin{bmatrix} -u_{0,0} & \dots & -u_{0,W-1} \\ -(u_{1,0}-u_{0,0}) & \dots & -(u_{1,W-1}-u_{0,W-1}) \\ \vdots & \ddots & \vdots \\ -(u_{H-1,0}-u_{H-2,0}) & \dots & -(u_{H-1,W-1}-u_{H-2,W-1}) \\ u_{H-2,0} & \dots & u_{H-2,W-1} \end{bmatrix} $$
Note: The source implementation for $D_x^T$ uses `np.vstack([-u[0:1, :], -np.diff(u[:-1, :], axis=0), u[-2:-1, :]])`. This results in:
- Row 0: $-u_{0,:}$
- Rows $1$ to $H-2$: $-(u_{i,:} - u_{i-1,:})$
- Row $H-1$: $u_{H-2,:}$

The Laplacian is then:
$$ \mathcal{L}(f) = \text{flatten}(D_x^T D_x f + D_y^T D_y f) $$

For the weighted case with $\Gamma$:
$$ \mathcal{L}_\gamma(f) = \text{flatten}(\sqrt{\Gamma} D_x^T \sqrt{\Gamma} D_x f + \sqrt{\Gamma} D_y^T \sqrt{\Gamma} D_y f) $$
If $\gamma$ is not an ndarray, it is set to the identity matrix $I$ of size $H \times H$ (assuming $H=W$ or broadcasting rules apply, though the source code `np.eye(f.shape[0])` implies square or row-wise identity) [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def applyDx(u):
    """
    Applies the first derivative along the first dimension (rows).
    Returns a matrix of the same shape as u.
    """
    # Forward difference along axis 0
    Dx = np.diff(u, axis=0)
    # Append a zero row at the bottom to maintain shape (H, W)
    zero_row = np.zeros((1, u.shape[1]))
    Dx = np.vstack([Dx, zero_row])
    return Dx

def applyDy(u):
    """
    Applies the first derivative along the second dimension (columns).
    Returns a matrix of the same shape as u.
    """
    # Forward difference along axis 1
    Dy = np.diff(u, axis=1)
    # Append a zero column at the right to maintain shape (H, W)
    zero_col = np.zeros((u.shape[0], 1))
    Dy = np.hstack([Dy, zero_col])
    return Dy

def applyDxTrans(u):
    """
    Applies the transpose of the first derivative along the first dimension (rows).
    Returns a matrix of the same shape as u.
    """
    # Row 0: -u[0, :]
    # Rows 1 to H-2: -(u[i, :] - u[i-1, :])
    # Row H-1: u[H-2, :]
    # Note: np.diff(u[:-1, :], axis=0) computes u[1:]-u[0:-1]
    # So -np.diff(u[:-1, :], axis=0) is -(u[1:]-u[0:-1]) = u[0:-1]-u[1:]
    # The source code: np.vstack([-u[0:1, :], -np.diff(u[:-1, :], axis=0), u[-2:-1, :]])
    
    term1 = -u[0:1, :]  # Shape (1, W)
    term2 = -np.diff(u[:-1, :], axis=0)  # Shape (H-1, W)
    term3 = u[-2:-1, :]  # Shape (1, W)
    
    DxT = np.vstack([term1, term2, term3])
    return DxT

def applyDyTrans(u):
    """
    Applies the transpose of the first derivative along the second dimension (columns).
    Returns a matrix of the same shape as u.
    """
    # Column 0: -u[:, 0]
    # Columns 1 to W-2: -(u[:, j] - u[:, j-1])
    # Column W-1: u[:, W-2]
    
    term1 = -u[:, 0:1]  # Shape (H, 1)
    term2 = -np.diff(u[:, :-1], axis=1)  # Shape (H, W-1)
    term3 = u[:, -2:-1]  # Shape (H, 1)
    
    DyT = np.hstack([term1, term2, term3])
    return DyT

def laplacian(f, gamma=0):
    """
    Computes the Laplacian of grid f.
    
    Args:
        f: 2D numpy array of shape (H, W)
        gamma: Weighting matrix or scalar. If 0, uniform Laplacian.
        
    Returns:
        Flattened 1D numpy array of shape (H*W,)
    """
    if not isinstance(gamma, np.ndarray):
        # If gamma is not an array, treat as uniform or identity
        # Source sets gamma = np.eye(f.shape[0]) if not ndarray
        # This implies gamma is applied row-wise or as a diagonal matrix
        # If gamma is a scalar, np.sqrt(gamma) is a scalar
        if gamma == 0:
            # Uniform Laplacian
            dxx = applyDxTrans(applyDx(f))
            dyy = applyDyTrans(applyDy(f))
            laplace_f = dxx + dyy
            return laplace_f.flatten()
        else:
            # Scalar gamma, treated as uniform weight
            # Source code: gamma = np.eye(f.shape[0])
            # This creates a square identity matrix. If f is not square, 
            # this might cause broadcasting issues or errors depending on context.
            # Assuming square grid for identity matrix application.
            gamma_mat = np.eye(f.shape[0])
    else:
        gamma_mat = gamma

    sqrt_gamma = np.sqrt(gamma_mat)
    
    # Weighted Laplacian
    # dxx = sqrt(gamma) @ applyDxTrans(sqrt(gamma) @ applyDx(f))
    # Note: The source uses matrix multiplication @. 
    # If f is 2D (H, W), applyDx(f) is (H, W).
    # sqrt(gamma) is (H, H).
    # sqrt(gamma) @ applyDx(f) is (H, W).
    # applyDxTrans(...) is (H, W).
    # sqrt(gamma) @ ... is (H, W).
    
    # Inner term: sqrt(gamma) @ applyDx(f)
    inner_dx = np.dot(sqrt_gamma, applyDx(f))
    # Apply transpose derivative
    trans_dx = applyDxTrans(inner_dx)
    # Outer term: sqrt(gamma) @ trans_dx
    dxx = np.dot(sqrt_gamma, trans_dx)
    
    inner_dy = np.dot(sqrt_gamma, applyDy(f))
    trans_dy = applyDyTrans(inner_dy)
    dyy = np.dot(sqrt_gamma, trans_dy)
    
    laplace_f = dxx + dyy
    return laplace_f.flatten()
```

**Edge Cases and Pitfalls:**
- **Non-square grids:** The source code sets `gamma = np.eye(f.shape[0])` if `gamma` is not an ndarray. If `f` is not square, `np.eye(f.shape[0])` creates a square matrix that may not broadcast correctly with `applyDx` or `applyDy` results if not handled carefully. The matrix multiplication `@` requires compatible dimensions.
- **Boundary Conditions:** The method uses zero-padding for forward differences and specific edge handling for backward differences. This is not a standard central difference stencil and may introduce boundary artifacts.
- **Gamma Matrix Dimensions:** If `gamma` is provided as an ndarray, it must be compatible with the grid dimensions for matrix multiplication.

## Subtopics

### Time Smoothness Regularization via Second Derivative
A variant used in spatiotemporal grids (e.g., 4DGS) to enforce smoothness over the time dimension. It identifies time grids (indices [2, 4, 5] for grid length not 3) and computes plane smoothness using second differences along the time dimension. The regularizer is $\frac{1}{N} \sum (t_{i+2} - 2t_{i+1} + t_i)^2$ [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(H \times W)$ for the derivative operations. Matrix multiplication with gamma adds $O(H^2 W)$ if gamma is dense and applied via dot product.
- **Memory Complexity:** $O(H \times W)$ for storing the grid and intermediate derivatives.
- **Strengths:** Explicitly handles boundaries via transpose operations; supports weighted regularization; simple implementation using standard numpy operations.
- **Limitations:** Not a standard central difference stencil; boundary handling is specific to the implementation; gamma weighting requires careful dimension matching.

## Background
This method is derived from implementations in inverse problems and CT scan reconstruction, where the Laplacian is used as a regularizer [S1, unofficial]. It is also referenced in the context of 4D Gaussian Splatting for time smoothness regularization [S2, unofficial].
