# Second-order Grid Sampler

Also called: Double back-propagation for grid sampler, Hessian computation for SDF, Hessian computation for SDF via double backprop, Second-order derivative computation for SDF regularization, Second-order derivatives via double backpropagation

## Overview
The Second-order Grid Sampler is a method for computing the Hessian matrix of a Signed Distance Field (SDF) with respect to 3D query coordinates and feature grid parameters, specifically within the context of neural feature grid optimization [S1]. It solves the problem of obtaining second-order derivatives (regularization terms) for SDFs that are defined by trilinearly interpolated feature grids, a task for which standard automatic differentiation frameworks (like PyTorch) do not support double back-propagation through the grid sampling operation [S1]. It sets itself apart from sibling methods like [Mean Curvature Grid Computation](3126-mean-curvature-grid-computation.md) and [Laplacian Grid Computation](3160-laplacian-grid-computation.md) by deriving the exact analytical Hessian blocks for the trilinear interpolation kernel itself, rather than relying on finite difference stencils on the resulting scalar field [S1].

## How it works
The method computes the second-order derivatives of the SDF $\phi$ with respect to the query position $x$, the feature grid parameters $\theta$, and the geometry network parameters $\omega$ [S1]. The SDF is defined as $\phi(x, \theta, \omega) = f_\omega(z(\theta, x))$, where $z = V_\theta(x)$ is the tri-linearly interpolated feature vector at query point $x$ [S1].

### Inputs and Outputs
*   **Inputs**:
    *   Query point $x = [x, y, z]^T \in \mathbb{R}^3$, normalized to the voxel space $[0,1]^3$.
    *   Feature grid parameters $\theta \in \mathbb{R}^8$ (for 1-D features; generalizes to $C$ dimensions) corresponding to the 8 vertices of the enclosing voxel.
    *   Geometry network parameters $\omega$ (handled via standard auto-diff).
*   **Outputs**:
    *   Hessian block $\frac{\partial^2 \phi}{\partial x^2}$ (3x3 matrix).
    *   Hessian block $\frac{\partial^2 \phi}{\partial x \partial \theta}$ (3x8 matrix).
    *   Hessian block $\frac{\partial^2 \phi}{\partial x \partial \omega}$ (3xN matrix, where N is the number of network parameters).

### Data Structures
*   **Coefficient Vector $w(x)$**: An 8-dimensional vector representing the trilinear interpolation weights for the 8 vertices of the voxel enclosing $x$. The vertices are indexed by binary coordinates $(v_x, v_y, v_z) \in \{0,1\}^3$.
    $$ w(x) = \begin{bmatrix} (1-x)(1-y)(1-z) \\ (1-x)(1-y)z \\ (1-x)y(1-z) \\ (1-x)yz \\ x(1-y)(1-z) \\ x(1-y)z \\ xy(1-z) \\ xyz \end{bmatrix} $$
*   **Jacobian Matrix $\frac{\partial w}{\partial x}$**: An $8 \times 3$ matrix containing the first derivatives of the weights with respect to $x, y, z$.

### Formulas
The derivation assumes 1-D features for simplicity but generalizes to any feature dimension $C$ [S1].

1.  **First-Order Gradient**:
    The first-order gradient of the SDF w.r.t. $x$ is computed via the chain rule:
    $$ \frac{\partial \phi}{\partial x} = \sum_{i=1}^C \frac{\partial f_\omega(z)}{\partial z_i} \frac{\partial z_i}{\partial x} $$
    For the feature grid part ($z_i = \theta_i^T w(x)$), $\frac{\partial z_i}{\partial x} = \theta_i^T \frac{\partial w}{\partial x}$ [S1].

2.  **Hessian Block $\frac{\partial^2 \phi}{\partial x^2}$**:
    This corresponds to the first row of the Hessian. It requires the second derivative of the interpolated feature $f$ w.r.t $x$:
    $$ \frac{\partial^2 f}{\partial x^2} = \sum_{i=1}^C \left( \frac{\partial^2 f_\omega(z)}{\partial z_i^2} \left(\frac{\partial z_i}{\partial x}\right)^2 + \frac{\partial f_\omega(z)}{\partial z_i} \frac{\partial^2 z_i}{\partial x^2} \right) $$
    The term $\frac{\partial^2 z_i}{\partial x^2}$ is derived from the second derivative of the trilinear interpolation. For the specific case where $f_\omega$ is linear in $z$ (or considering the Hessian of the interpolation kernel itself), the second derivative of the feature value w.r.t $x$ is given by the matrix $H_f = \frac{\partial^2 f}{\partial x \partial x^T}$:
    $$ H_f = \begin{bmatrix} h_{11} & h_{12} & h_{13} \\ h_{21} & h_{22} & h_{23} \\ h_{31} & h_{32} & h_{33} \end{bmatrix} $$
    *   **Diagonal Elements**: $h_{11} = h_{22} = h_{33} = 0$. This is because each column of the Jacobian $\frac{\partial w}{\partial x}$ only contains variables from the other two dimensions, making the second derivative with respect to a single dimension zero [S1].
    *   **Off-Diagonal Elements**:
        $$ h_{12} = h_{21} = (1-z)(\theta_{000} + \theta_{110} - \theta_{010} - \theta_{100}) + z(\theta_{001} + \theta_{111} - \theta_{011} - \theta_{101}) $$
        $$ h_{13} = h_{31} = (1-y)(\theta_{000} + \theta_{101} - \theta_{001} - \theta_{100}) + y(\theta_{010} + \theta_{111} - \theta_{011} - \theta_{110}) $$
        $$ h_{23} = h_{32} = (1-x)(\theta_{000} + \theta_{011} - \theta_{001} - \theta_{010}) + x(\theta_{100} + \theta_{111} - \theta_{101} - \theta_{110}) $$
        Here, $\theta_{v_x v_y v_z}$ denotes the feature value at the voxel vertex with binary coordinates $(v_x, v_y, v_z)$ [S1].

3.  **Hessian Block $\frac{\partial^2 \phi}{\partial x \partial \theta}$**:
    This corresponds to the mixed second derivative w.r.t. $x$ and feature parameters $\theta$:
    $$ \frac{\partial^2 \phi}{\partial x \partial \theta} = \sum_{i=1}^C \frac{\partial^2 f_\omega(z)}{\partial z_i^2} \frac{\partial z_i}{\partial \theta} \frac{\partial z_i}{\partial x} $$
    For the interpolation kernel itself, this block is simply the transpose of the Jacobian of the weights w.r.t $x$:
    $$ \frac{\partial^2 f}{\partial x \partial \theta} = \left( \frac{\partial w}{\partial x} \right)^T $$
    The Jacobian $\frac{\partial w}{\partial x}$ is an $8 \times 3$ matrix with columns $J_1, J_2, J_3$:
    $$ J_1 = \begin{bmatrix} -(1-y)(1-z) \\ -(1-y)z \\ -y(1-z) \\ -yz \\ (1-y)(1-z) \\ (1-y)z \\ y(1-z) \\ yz \end{bmatrix}, \quad J_2 = \begin{bmatrix} -(1-x)(1-z) \\ -(1-x)z \\ (1-x)(1-z) \\ (1-x)z \\ -x(1-z) \\ -xz \\ x(1-z) \\ xz \end{bmatrix}, \quad J_3 = \begin{bmatrix} -(1-x)(1-y) \\ (1-x)(1-y) \\ -(1-x)y \\ (1-x)y \\ -x(1-y) \\ x(1-y) \\ -xy \\ xy \end{bmatrix} $$
    Thus, $\frac{\partial^2 f}{\partial x \partial \theta}$ is a $3 \times 8$ matrix where the $i$-th column is $J_i$ [S1].

4.  **Hessian Block $\frac{\partial^2 \phi}{\partial x \partial \omega}$**:
    This term involves the geometry network parameters $\omega$. It is computed as:
    $$ \frac{\partial^2 \phi}{\partial x \partial \omega} = \sum_{i=1}^C \left( \frac{\partial^2 f_\omega(z)}{\partial z_i^2} \frac{\partial z_i}{\partial \omega} \frac{\partial z_i}{\partial x} + \frac{\partial f_\omega(z)}{\partial z_i} \frac{\partial^2 z_i}{\partial x \partial \omega} \right) $$
    The sources state that this term does not need to be implemented manually because PyTorch's automatic differentiation supports double back-propagation through the MLP (geometry network) [S1].

### Pseudocode
```python
import torch

def compute_trilinear_hessian_blocks(x, theta):
    """
    Computes the Hessian blocks for the trilinear interpolation kernel.
    
    Args:
        x: Tensor of shape (..., 3) containing query points [x, y, z] in [0, 1].
        theta: Tensor of shape (..., 8) containing feature values at the 8 voxel vertices.
               Vertices are ordered: 000, 001, 010, 011, 100, 101, 110, 111.
               
    Returns:
        h_xx: Tensor of shape (..., 3, 3) representing d^2f / dx^2.
        h_xtheta: Tensor of shape (..., 3, 8) representing d^2f / dx dtheta.
    """
    # Extract coordinates
    x_coord = x[..., 0:1] # Shape (..., 1)
    y_coord = x[..., 1:2]
    z_coord = x[..., 2:3]
    
    # Compute off-diagonal elements of the Hessian w.r.t x
    # h12 = h21
    term1_12 = (1 - z_coord) * (theta[..., 0] + theta[..., 5] - theta[..., 2] - theta[..., 3])
    term2_12 = z_coord * (theta[..., 1] + theta[..., 7] - theta[..., 3] - theta[..., 4])
    h12 = term1_12 + term2_12
    
    # h13 = h31
    term1_13 = (1 - y_coord) * (theta[..., 0] + theta[..., 4] - theta[..., 1] - theta[..., 3])
    term2_13 = y_coord * (theta[..., 2] + theta[..., 7] - theta[..., 4] - theta[..., 6])
    h13 = term1_13 + term2_13
    
    # h23 = h32
    term1_23 = (1 - x_coord) * (theta[..., 0] + theta[..., 6] - theta[..., 1] - theta[..., 2])
    term2_23 = x_coord * (theta[..., 3] + theta[..., 7] - theta[..., 5] - theta[..., 6])
    h23 = term1_23 + term2_23
    
    # Construct the 3x3 Hessian matrix
    # Diagonals are zero
    h_xx = torch.zeros_like(x_coord)
    h_xx = h_xx.expand_as(x_coord) # Shape (..., 1)
    
    # Reshape for matrix construction
    # h_xx shape: (..., 3, 3)
    h_xx = torch.zeros((*x.shape[:-1], 3, 3), device=x.device, dtype=x.dtype)
    
    # Set off-diagonals
    h_xx[..., 0, 1] = h12.squeeze(-1)
    h_xx[..., 1, 0] = h12.squeeze(-1)
    h_xx[..., 0, 2] = h13.squeeze(-1)
    h_xx[..., 2, 0] = h13.squeeze(-1)
    h_xx[..., 1, 2] = h23.squeeze(-1)
    h_xx[..., 2, 1] = h23.squeeze(-1)
    
    # Compute h_xtheta = (dw/dx)^T
    # dw/dx is 8x3. We want 3x8.
    # J1 (deriv w.r.t x)
    J1 = torch.stack([
        -(1-y_coord)*(1-z_coord), -(1-y_coord)*z_coord, -y_coord*(1-z_coord), -y_coord*z_coord,
        (1-y_coord)*(1-z_coord), (1-y_coord)*z_coord, y_coord*(1-z_coord), y_coord*z_coord
    ], dim=-1) # Shape (..., 8)
    
    # J2 (deriv w.r.t y)
    J2 = torch.stack([
        -(1-x_coord)*(1-z_coord), -(1-x_coord)*z_coord, (1-x_coord)*(1-z_coord), (1-x_coord)*z_coord,
        -x_coord*(1-z_coord), -x_coord*z_coord, x_coord*(1-z_coord), x_coord*z_coord
    ], dim=-1) # Shape (..., 8)
    
    # J3 (deriv w.r.t z)
    J3 = torch.stack([
        -(1-x_coord)*(1-y_coord), (1-x_coord)*(1-y_coord), -(1-x_coord)*y_coord, (1-x_coord)*y_coord,
        -x_coord*(1-y_coord), x_coord*(1-y_coord), -x_coord*y_coord, x_coord*y_coord
    ], dim=-1) # Shape (..., 8)
    
    # Stack to get dw/dx: (..., 8, 3)
    dw_dx = torch.stack([J1, J2, J3], dim=-2)
    
    # Transpose to get h_xtheta: (..., 3, 8)
    h_xtheta = dw_dx.transpose(-2, -1)
    
    return h_xx, h_xtheta
```

### Parameters
*   **Feature Dimension**: The derivation assumes 1-D features, but the method generalizes to any feature dimension $C$ by summing the contributions over each dimension [S1].

### Edge Cases and Pitfalls
*   **PyTorch Limitations**: Standard PyTorch `grid_sampler` does not support second-order gradients (double back-propagation) through the sampling operation. Therefore, the Hessian blocks w.r.t $x$ and $\theta$ must be implemented manually as shown above [S1].
*   **Zero Diagonals**: The diagonal elements of the Hessian w.r.t $x$ are identically zero for trilinear interpolation. Implementers must ensure these are explicitly set to zero and not computed via finite differences or auto-diff which might introduce numerical noise [S1].
*   **Vertex Ordering**: The formulas for off-diagonal elements depend strictly on the ordering of $\theta$ corresponding to the binary indices $(000, 001, 010, 011, 100, 101, 110, 111)$. Incorrect ordering will yield wrong Hessian values [S1].

Computes mean curvature from the Hessian trace. It uses the Hessian computed here but normalizes by the gradient magnitude. Choose when surface smoothness is required. [Link](3126-mean-curvature-grid-computation.md)

## Operating characteristics
*   **Time Complexity**: $O(1)$ per query point, as it involves a fixed number of arithmetic operations on the 8 vertices of the enclosing voxel.
*   **Memory Complexity**: $O(1)$ auxiliary memory per query point.
*   **Strengths**: Provides exact analytical second derivatives for trilinear interpolation, enabling precise regularization of SDF gradients in neural rendering pipelines. Avoids the numerical instability of finite differences.
*   **Limitations**: Only applicable to trilinearly interpolated feature grids. Does not handle non-linear interpolation kernels. Requires manual implementation in frameworks lacking double back-prop support for grid samplers.
*   **When to use**: When optimizing neural feature grids for SDFs (e.g., in GO-Surf) and gradient regularization is needed.
*   **When not to use**: When using other interpolation methods (e.g., bilinear, cubic) or when the SDF is defined by a neural network without a feature grid.

## Background
The method was introduced in the paper "GO-Surf: Neural Feature Grid Optimization for Fast, High-Fidelity RGB-D Surface Reconstruction" by Jingwen Wang, Tymoteusz Bleja, and Lourdes Agapito (2022) [S1]. It was developed to address the lack of support for double back-propagation through PyTorch's grid sampler, which is essential for regularizing the gradient term of the SDF during the optimization of neural feature grids. The technique is specific to the GO-Surf architecture and has not been widely adopted in other volume rendering methods, which typically rely on finite differences or auto-diff on the final scalar field.
