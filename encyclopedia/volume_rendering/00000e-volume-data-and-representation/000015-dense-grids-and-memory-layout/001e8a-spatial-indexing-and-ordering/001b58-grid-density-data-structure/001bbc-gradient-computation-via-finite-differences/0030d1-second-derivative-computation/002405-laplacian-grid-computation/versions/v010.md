# Laplacian Grid Computation
Also called: Divergence of Gradient, Laplacian Field Transformation, Laplacian of Gaussian (LoG) Scale Detection, Normalized Laplacian Detection, Second Derivative Field

## Overview
Laplacian Grid Computation transforms a scalar volume field $f(x,y,z)$ into a new scalar field representing the Laplacian $\nabla^2 f$, which is the divergence of the gradient [S1]. This operation highlights boundaries and structural features while suppressing homogeneous interiors where the gradient change is constant [S1]. It differs from sibling methods like [Mean Curvature Grid Computation](3126-mean-curvature-grid-computation.md) by computing the trace of the Hessian (sum of second derivatives) rather than the mean curvature, and from [Divergence Grid Computation](3151-divergence-grid-computation.md) by specifically targeting the scalar Laplacian of a gradient field rather than a general vector field [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar volume grid $f$ defined on a 3D lattice.
*   **Output:** A scalar volume grid $L$ where $L(x,y,z) = \nabla^2 f(x,y,z)$.

**Data Structures:**
*   **Input Grid:** A sparse or dense grid tree storing voxel values $f(x,y,z)$.
*   **Output Grid:** A grid tree of the same topology as the input, storing the computed Laplacian values. Background voxels (inactive in input) are typically set to zero in the output.

**Stencils and Offsets:**
The method relies on the 6-point central difference stencil for the Laplacian in index space (unit voxel spacing) [S2, unofficial]. The Laplacian is the sum of the pure second derivatives along the three axes [S1]:
$$ \nabla^2 f(x, y, z) = \frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2} + \frac{\partial^2 f}{\partial z^2} $$
Using the central difference approximation for each axis:
$$ \frac{\partial^2 f}{\partial x^2} \approx f(x+1, y, z) - 2f(x, y, z) + f(x-1, y, z) $$
$$ \frac{\partial^2 f}{\partial y^2} \approx f(x, y+1, z) - 2f(x, y, z) + f(x, y-1, z) $$
$$ \frac{\partial^2 f}{\partial z^2} \approx f(x, y, z+1) - 2f(x, y, z) + f(x, y, z-1) $$
Summing these yields the 6-point stencil formula for unit spacing:
$$ \nabla^2 f(x, y, z) \approx f(x+1, y, z) + f(x-1, y, z) + f(x, y+1, z) + f(x, y-1, z) + f(x, y, z+1) + f(x, y, z-1) - 6f(x, y, z) $$

**Parameters:**
*   **Voxel Spacing:** If the grid has non-unit spacing $(\Delta x, \Delta y, \Delta z)$, the result must be scaled by the inverse square of the spacing for each axis [S1][S2, unofficial]. The general formula becomes:
    $$ \nabla^2 f \approx \frac{f_{xx}}{\Delta x^2} + \frac{f_{yy}}{\Delta y^2} + \frac{f_{zz}}{\Delta z^2} $$
*   **Boundary Handling:** Stencils require neighbors outside the active domain. Standard strategies include zero-padding (assuming background value is 0), clamping, or reflecting. Inactive voxels in the output are typically set to zero [S2, unofficial].

**Algorithm Steps:**
1.  Initialize a stencil structure with the input grid tree.
2.  Iterate over all active voxels $c$ in the input grid.
3.  For each voxel $c=(x,y,z)$, move the stencil to coordinate $c$.
4.  Sample the 6 neighboring voxels and the center voxel.
5.  Compute the Laplacian value using the 6-point stencil formula (scaled by spacing if necessary).
6.  Store the computed value in the output grid at coordinate $c$.
7.  Build the result grid using the computed data, a background value of zero, and the original grid's voxel size.

**Pseudocode:**
```python
def compute_laplacian_grid(input_grid, voxel_spacing=(1.0, 1.0, 1.0)):
    """
    Computes the Laplacian grid for a scalar volume.
    
    Args:
        input_grid: A grid structure supporting iteration over active voxels
                    and lookup by coordinate (x, y, z).
        voxel_spacing: Tuple (dx, dy, dz) representing the physical size of a voxel.
    
    Returns:
        output_grid: A new grid containing the Laplacian values.
    """
    dx, dy, dz = voxel_spacing
    scale_x = 1.0 / (dx * dx)
    scale_y = 1.0 / (dy * dy)
    scale_z = 1.0 / (dz * dz)
    
    output_grid = create_empty_grid_like(input_grid, background_value=0.0)
    
    # Iterate over all active voxels in the input grid
    for coord in input_grid.active_voxels():
        x, y, z = coord
        
        # Sample neighbors. If a neighbor is inactive/out of bounds, treat as 0.0
        # This implements zero-padding boundary handling.
        val_center = input_grid.get_value(x, y, z)
        val_xp = input_grid.get_value(x + 1, y, z)
        val_xm = input_grid.get_value(x - 1, y, z)
        val_yp = input_grid.get_value(x, y + 1, z)
        val_ym = input_grid.get_value(x, y - 1, z)
        val_zp = input_grid.get_value(x, y, z + 1)
        val_zm = input_grid.get_value(x, y, z - 1)
        
        # Compute pure second derivatives scaled by spacing
        # f_xx = (f(x+1) - 2f(x) + f(x-1)) / dx^2
        f_xx = (val_xp - 2.0 * val_center + val_xm) * scale_x
        f_yy = (val_yp - 2.0 * val_center + val_ym) * scale_y
        f_zz = (val_zp - 2.0 * val_center + val_zm) * scale_z
        
        # Sum to get Laplacian
        laplacian = f_xx + f_yy + f_zz
        
        output_grid.set_value(coord, laplacian)
        
    return output_grid
```

**Edge Cases and Pitfalls:**
*   **Noise Sensitivity:** Second derivatives amplify high-frequency noise. The method is often applied to smoothed fields or used in conjunction with scale-space detection to mitigate this [S1][S3, unofficial].
*   **Homogeneous Regions:** In areas where the gradient change is constant, $\nabla^2 f$ is zero, transforming the area to be homogeneous [S1]. This suppresses interior details but may also suppress valid structural information if not interpreted correctly.
*   **First Derivative Input:** Using the first derivative field $f'(x)$ as input to the Laplacian is less appropriate for general cases because extrema are not clear boundary indicators and it fails to distinguish objects with similar intensities and surroundings [S1].

## Subtopics

### [GPU Laplacian Scale-Space Maxima Detection](5852-gpu-laplacian-scale-space-maxima-detection.md)
Detects local maxima of the Laplacian across a scale space to identify blob-like structures. It merges scale-space diffusion and maxima detection into a single per-iteration pass, avoiding the storage of the full scale-space pyramid in GPU memory.

### [Scale Field Computation](6538-scale-field-computation.md)
Estimates a 3D scalar field $S$ encoding local feature size using iterative non-linear diffusion. It allows for sub-voxel scale detection and better localization than subsampled pyramids.

### [Scale Space Construction](8275-scale-space-construction.md)
Generates a continuous multi-scale representation by solving the linear diffusion equation. It avoids discretization artifacts in maxima detection by providing a continuous solution via Gaussian convolution.

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of active voxels, as each voxel requires a constant number of lookups and arithmetic operations (6 neighbors + center).
*   **Memory Complexity:** $O(N)$ for the output grid, assuming a sparse representation similar to the input. If dense, $O(V)$ where $V$ is the total volume of the bounding box.
*   **Strengths:** Efficiently extracts boundaries and structural features; simple stencil implementation; works well with sparse grid data structures.
*   **Limitations:** Highly sensitive to noise; linear diffusion can cause nearby objects to merge into a single blob before detection, leading to inaccurate scale maxima localization [S3, unofficial].
*   **When to use:** When boundary detection or structural feature extraction is required, particularly as a precursor to scale-space analysis or blob detection.
*   **When not to use:** When noise is high and smoothing is not applied; when distinguishing between objects with similar intensities but different internal structures is critical without scale context.

## Background
The Laplacian operator is a fundamental concept in vector calculus, defined as the divergence of the gradient [S1]. In the context of volume rendering and scientific visualization, it has been used for boundary-structure-aware transfer functions to classify objects based on their second derivative properties [S1]. The application of the Laplacian in scale-space for blob detection (Laplacian of Gaussian) was formalized in the context of scale-space theory [S3, unofficial]. The method builds on [Second Derivative Computation](6353-second-derivative-computation.md) by specifically summing the second derivatives to form the Laplacian field.
