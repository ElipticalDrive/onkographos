# Progressive Scale-Space Construction


## Overview
Progressive Scale-Space Construction is a method for computing the scale field $S$ by leveraging the semigroup property of diffusion-based scale-space operators. It allows the scale field at a target scale to be computed from an already smoothed version of the data, rather than the original volume, ensuring that intermediate results are valid approximations. This property distinguishes it from non-progressive methods by enabling multi-resolution analysis, which is critical for interactive exploration of large datasets ($> 512^3$) where full-resolution computation is infeasible due to memory constraints.

## How it works
The method relies on the mathematical property that the transformation from an original image to any scale is identical whether applied directly or via an intermediate coarser scale. This allows the scale-space to be built incrementally.

**Inputs and Outputs:**
- Input: A scalar volume $V$ (or a previously smoothed version $V_{smooth}$), and a target scale $t$.
- Output: A scale field $S$ mapping each voxel to a local scale value.

**Data Structures:**
- The scale field $S$ is typically stored as a 3D grid. For large datasets, $S$ may be stored at a lower resolution than $V$ to fit in GPU texture memory.
- If subsampling is used, the scale field resolution is reduced by a factor $k$.

**Steps:**
1. **Initial Smoothing (Optional):** If starting from the original volume $V$, apply a diffusion operator (e.g., Gaussian blur) to obtain a smoothed volume $V_{smooth}$. If $V$ is already smoothed from a previous step, use it directly.
2. **Scale Field Computation:** Compute the scale field $S$ from $V_{smooth}$ using the scale-space construction algorithm (e.g., fitting a continuous function to salient points derived from second derivatives).
   - *Note:* The result $S$ at scale $t$ is identical whether computed from $V$ or $V_{smooth}$.
3. **Multi-Resolution Handling (for large datasets):**
   - If the dataset exceeds available memory (e.g., $> 512^3$), compute $S$ at a lower resolution.
   - Subsample the volume by a factor $k$ (e.g., $k=4$).
   - Compute the scale field on the subsampled grid.
   - To detect sub-voxel sizes lost by subsampling, analyze sub-regions of the data sequentially, ensuring each sub-region fits in texture memory, and aggregate the results.

**Parameters:**
- **Resolution:** For datasets $> 512^3$, the scale field resolution can be reduced. The detectable sizes are restricted to the granularity of the scale field resolution.
- **Subsampling Factor:** Commonly 4. A factor of 4 means features of sizes 1 to 4 voxels wide cannot be discerned individually and are collectively detected as the smallest size.

**Pitfalls:**
- **Granularity Loss:** Subsampling by a factor of $k$ limits the smallest detectable feature size to $k$ voxels. Features smaller than $k$ are merged.
- **Memory Constraints:** Full-resolution scale fields for large datasets may not fit in GPU memory. Subsampling is necessary but reduces detail.
- **Boundary Effects:** When analyzing sub-regions, boundary conditions must be handled to ensure continuity of the scale field across region boundaries.

**Pseudocode:**
```python
def compute_scale_field_progressive(volume, target_scale, subsample_factor=1):
    """
    Compute scale field using progressive scale-space construction.
    
    Args:
        volume: 3D array of scalar values.
        target_scale: The target scale t for the scale field.
        subsample_factor: Factor by which to reduce resolution (1 for full res).
        
    Returns:
        scale_field: 3D array of scale values.
    """
    # Step 1: Handle subsampling for large datasets
    if subsample_factor > 1:
        # Subsample the volume to fit in memory
        # Implementation detail: average pooling or similar downsampling
        volume_coarse = subsample(volume, subsample_factor)
        
        # Step 2: Compute scale field on coarse volume
        # The scale field at target_scale is the same as if computed on original volume
        scale_field_coarse = compute_scale_field_single_scale(volume_coarse, target_scale)
        
        # Step 3: Upsample scale field if needed, or return coarse field
        # Note: Subsampling loses sub-voxel detail. 
        # For sub-voxel detection, analyze sub-regions sequentially.
        # Here we return the coarse field as a valid approximation.
        return scale_field_coarse
    else:
        # Full resolution computation
        scale_field = compute_scale_field_single_scale(volume, target_scale)
        return scale_field

def compute_scale_field_single_scale(volume, scale):
    """
    Compute scale field for a given volume and scale.
    This function encapsulates the specific scale-space construction algorithm
    (e.g., fitting to salient points).
    """
    # Apply diffusion/smoothing if not already done
    smoothed_volume = apply_diffusion(volume, scale)
    
    # Extract salient points (e.g., local maxima of scale space)
    salient_points = extract_salient_points(smoothed_volume)
    
    # Fit continuous scale field to salient points
    scale_field = fit_scale_field(salient_points)
    
    return scale_field
```

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels in the processed volume. Subsampling reduces the number of voxels by $k^3$, significantly speeding up computation.
- **Memory Complexity:** Proportional to the size of the volume and scale field. Subsampling reduces memory usage by $k^3$.
- **Performance:** Enables interactive exploration of large datasets ($> 512^3$) by allowing lower-resolution scale field computation.
- **Strengths:** Valid approximations at intermediate scales; efficient for large datasets; supports multi-scale exploration.
- **Limitations:** Subsampling reduces granularity; features smaller than the subsampling factor are lost; requires careful handling of sub-regions for sub-voxel detection.

## Background
Progressive Scale-Space Construction is based on the semigroup property of diffusion-based scale-space operators, as described in the work of Correa and Ma (2008) [S1, S2]. This property states that the transformation from an original image to any scale is the same from a finer scale to any coarser scale. This insight allows for the progressive construction of the scale-space, where intermediate results are valid approximations. The method is particularly useful for Size-Based Transfer Functions (SBTF), where the scale field is used to classify volume data based on local feature sizes.
