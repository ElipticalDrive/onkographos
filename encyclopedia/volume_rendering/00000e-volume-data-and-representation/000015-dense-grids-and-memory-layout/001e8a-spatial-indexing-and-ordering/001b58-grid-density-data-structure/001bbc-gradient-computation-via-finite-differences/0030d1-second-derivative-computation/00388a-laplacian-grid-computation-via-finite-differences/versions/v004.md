# Laplacian Grid Computation via Finite Differences

Also called: First Derivative and Laplacian Operators, Laplacian Field Transformation, applyDx, applyDy

## Overview
This method computes the discrete Laplacian of a 2D grid field using adjoint finite difference operators, specifically designed for optimization-based inverse problems and regularization. Unlike standard central difference methods [Parent](6353-second-derivative-computation.md) that assume zero-padding or periodic boundaries, this approach constructs the Laplacian matrix as the product of forward and backward difference operators ($D^T D$), implicitly defining specific boundary conditions where the boundary values are determined by the interior gradient. It supports both unweighted (standard Laplacian) and weighted (gamma-weighted) variants for anisotropic regularization.

## How it works
**Inputs and Outputs:**
- Input: A 2D grid $f$ of shape $(H, W)$ containing scalar field values. An optional weighting matrix $\Gamma$ of shape $(H, W)$ or scalar.
- Output: A flattened 1D array of shape $(H \times W,)$ representing the Laplacian $\nabla^2 f$.

**Data Structures:**
- $f$: `numpy.ndarray` of shape $(H, W)$, dtype `float`.
- $\Gamma$: `numpy.ndarray` of shape $(H, W)$ or scalar. If scalar, treated as identity scaling.

**Steps:**
1. **Forward Difference in Rows (Axis 0):** Compute the forward difference along the first dimension.
   $$ D_x f_{i,j} = f_{i+1,j} - f_{i,j} \quad \text{for } i < H-1 $$
   The result $D_x f$ has shape $(H-1, W)$. A zero row is appended at the bottom to maintain shape $(H, W)$, effectively setting the boundary condition for the transpose operation.
2. **Forward Difference in Columns (Axis 1):** Compute the forward difference along the second dimension.
   $$ D_y f_{i,j} = f_{i,j+1} - f_{i,j} \quad \text{for } j < W-1 $$
   The result $D_y f$ has shape $(H, W-1)$. A zero column is appended at the right to maintain shape $(H, W)$.
3. **Adjoint (Transpose) Difference in Rows:** Apply the transpose of the row difference operator to the result of step 1.
   $$ D_x^T g_{i,j} = \begin{cases} -g_{0,j} & i=0 \\ -(g_{i,j} - g_{i-1,j}) & 0 < i < H-1 \\ g_{H-2,j} & i=H-1 \end{cases} $$
   Implementation: Stack $-f_{0,:}$, $-(f_{i,:} - f_{i-1,:})$ for $i=1 \dots H-2$, and $f_{H-2,:}$ vertically.
4. **Adjoint (Transpose) Difference in Columns:** Apply the transpose of the column difference operator to the result of step 2.
   $$ D_y^T h_{i,j} = \begin{cases} -h_{i,0} & j=0 \\ -(h_{i,j} - h_{i,j-1}) & 0 < j < W-1 \\ h_{i,W-2} & j=W-1 \end{cases} $$
   Implementation: Stack $-f_{:,0}$, $-(f_{:,j} - f_{:,j-1})$ for $j=1 \dots W-2$, and $f_{:,W-2}$ horizontally.
5. **Combine:** Sum the results of the row and column adjoint operations.
   $$ \nabla^2 f = D_x^T D_x f + D_y^T D_y f $$
6. **Flatten:** Return the result as a 1D array.

**Weighted Variant:**
If a weight matrix $\Gamma$ is provided:
1. Scale the input: $f' = \sqrt{\Gamma} \odot f$.
2. Compute $D_x f'$ and $D_y f'$ as in steps 1-2.
3. Scale the forward differences: $D_x f'' = \sqrt{\Gamma} \odot D_x f'$ and $D_y f'' = \sqrt{\Gamma} \odot D_y f'$.
4. Apply adjoints $D_x^T$ and $D_y^T$ to $D_x f''$ and $D_y f''$ respectively.
5. Sum and flatten.

**Pseudocode:**
```python
import numpy as np

def apply_dx(u):
    """Forward difference along axis 0 (rows)."""
    dx = np.diff(u, axis=0)  # Shape (H-1, W)
    # Append zero row at bottom to maintain shape (H, W)
    zero_row = np.zeros((1, u.shape[1]), dtype=u.dtype)
    return np.vstack([dx, zero_row])

def apply_dy(u):
    """Forward difference along axis 1 (columns)."""
    dy = np.diff(u, axis=1)  # Shape (H, W-1)
    # Append zero column at right to maintain shape (H, W)
    zero_col = np.zeros((u.shape[0], 1), dtype=u.dtype)
    return np.hstack([dy, zero_col])

def apply_dx_trans(u):
    """Adjoint of forward difference along axis 0."""
    # Top row: -u[0, :]
    top = -u[0:1, :]
    # Middle rows: -(u[i, :] - u[i-1, :]) for i in 1..H-2
    # np.diff(u[:-1, :], axis=0) computes u[1:]-u[0:], u[2:]-u[1:], ...
    # We need negative of this.
    middle = -np.diff(u[:-1, :], axis=0)
    # Bottom row: u[-2, :]
    bottom = u[-2:-1, :]
    return np.vstack([top, middle, bottom])

def apply_dy_trans(u):
    """Adjoint of forward difference along axis 1."""
    # Left col: -u[:, 0]
    left = -u[:, 0:1]
    # Middle cols: -(u[:, j] - u[:, j-1])
    middle = -np.diff(u[:, :-1], axis=1)
    # Right col: u[:, -2]
    right = u[:, -2:-1]
    return np.hstack([left, middle, right])

def laplacian_unweighted(f):
    """Compute Laplacian without gamma weighting."""
    dxx = apply_dx_trans(apply_dx(f))
    dyy = apply_dy_trans(apply_dy(f))
    return (dxx + dyy).flatten()

def laplacian_weighted(f, gamma):
    """Compute Laplacian with gamma weighting."""
    # If gamma is not an ndarray, treat as scalar identity scaling
    if not isinstance(gamma, np.ndarray):
        gamma = np.eye(f.shape[0]) * gamma
    
    sqrt_gamma = np.sqrt(gamma)
    
    # Scale input
    f_scaled = sqrt_gamma * f
    
    # Forward differences
    dx_f = apply_dx(f_scaled)
    dy_f = apply_dy(f_scaled)
    
    # Scale forward differences
    dx_f_scaled = sqrt_gamma * dx_f
    dy_f_scaled = sqrt_gamma * dy_f
    
    # Adjoint differences
    dxx = apply_dx_trans(dx_f_scaled)
    dyy = apply_dy_trans(dy_f_scaled)
    
    return (dxx + dyy).flatten()
```

**Parameters:**
- `gamma`: Regularization weight. Default 0 (unweighted). If scalar, applied uniformly. If matrix, element-wise weighting [S1, unofficial].

**Edge Cases:**
- **Grid Size < 2:** `np.diff` returns empty arrays. The code may fail or return empty results. Not explicitly handled in source [S1, unofficial].
- **Gamma Shape Mismatch:** If `gamma` is provided as a matrix, it must match `f.shape`. If not, behavior is undefined in source [S1, unofficial].

## Subtopics

### Time Smoothness Regularization via Second Derivative
A regularizer for spatiotemporal grids that enforces smoothness over the time dimension by penalizing the second derivative. It identifies time grids (indices [2, 4, 5] for grid length > 3) and applies plane smoothness computation. The smoothness for a time grid $t$ is computed as $\frac{1}{N} \sum (t_{i+2} - 2t_{i+1} + t_i)^2$, using second differences along the time dimension [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(H \times W)$ for both forward and adjoint operations, as each element is accessed a constant number of times.
- **Memory Complexity:** $O(H \times W)$ for intermediate arrays ($D_x f, D_y f, D_x^T D_x f$, etc.).
- **Strengths:** Implicitly handles boundary conditions via the adjoint structure, suitable for optimization problems where boundary gradients are constrained by interior values. Supports anisotropic weighting via $\Gamma$.
- **Limitations:** Not a standard central difference Laplacian; boundary values are not zero-padded in the same way as [Parent](6353-second-derivative-computation.md). Requires 2D grids; 3D extension not described in source [S1, unofficial].
- **When to Use:** Inverse problems, CT reconstruction, and regularization tasks where the Laplacian matrix must be symmetric positive semi-definite and derived from a forward-backward difference pair [S1, unofficial].
- **When Not to Use:** When standard central difference boundary conditions (zero-padding) are required, or for 3D volumetric data without modification.

## Background
This method originates from implementations in inverse problems and CT scan reconstruction, specifically using NumPy for efficient matrix-free operations. It is cited in the context of solving linear systems involving Laplacian regularization [S1, unofficial]. The time smoothness variant is used in 4D Gaussian Splatting for dynamic scene rendering [S2, unofficial].
