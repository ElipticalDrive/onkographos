# Laplacian Grid Computation
Also called: Divergence of Gradient, Laplacian Field Transformation, Laplacian of Gaussian (LoG) Scale Detection, Normalized Laplacian Detection, Second Derivative Field

## Overview
Laplacian Grid Computation transforms a scalar input field $f(x,y,z)$ into a new scalar field $\nabla^2 f$ by applying the Laplace operator, which is defined as the divergence of the gradient [S1]. This operation highlights boundaries and structural features while suppressing homogeneous interior regions where the gradient change is constant [S1]. It differs from its siblings, such as [Mean Curvature Grid Computation](3126-mean-curvature-grid-computation.md) and [Divergence Grid Computation](3151-divergence-grid-computation.md), by specifically computing the trace of the Hessian matrix (the sum of second pure partial derivatives) rather than mean curvature or the divergence of an arbitrary vector field [S1][S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar field $f$ defined on a grid topology (dense or sparse) with voxel spacing $\Delta x, \Delta y, \Delta z$.
*   **Output:** A scalar field $L = \nabla^2 f$ with the same grid topology and voxel size as the input.

**Data Structures:**
*   **Input Grid:** A collection of active voxels. Each voxel $v$ at coordinate $(x,y,z)$ holds a scalar value $f(x,y,z)$.
*   **Output Grid:** A dictionary or sparse grid keyed by coordinate $(x,y,z)$, storing the computed Laplacian value. Background values are implicitly zero [S2, unofficial].

**Formulas:**
The Laplacian is the sum of the second pure partial derivatives [S1][S3, unofficial]:
$$ \nabla^2 f(x, y, z) = \frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2} + \frac{\partial^2 f}{\partial z^2} $$

Using central differences for unit voxel spacing ($\Delta x = \Delta y = \Delta z = 1$), the second derivatives are:
$$ f_{xx} = f(x+1, y, z) - 2f(x, y, z) + f(x-1, y, z) $$
$$ f_{yy} = f(x, y+1, z) - 2f(x, y, z) + f(x, y-1, z) $$
$$ f_{zz} = f(x, y, z+1) - 2f(x, y, z) + f(x, y, z-1) $$

For non-unit spacing, these terms are scaled by $1/\Delta x^2$, $1/\Delta y^2$, and $1/\Delta z^2$ respectively [G].

The divergence of a vector field $\mathbf{V}$ is defined as the limit of the surface integral over a volume $V$ [S1]:
$$ \nabla \cdot \mathbf{V} \equiv \lim_{V \to 0} \frac{\oint_S \mathbf{V} \cdot d\mathbf{s}}{V} $$
In the context of the Laplacian, $\mathbf{V}$ is the gradient $\nabla f$.

**Steps:**
1.  Initialize a stencil object (`GradStencil`) configured with the input grid tree's topology and spacing [S2, unofficial].
2.  Iterate over all active voxels in the input grid. For each voxel at coordinate $c$:
    a. Move the stencil to coordinate $c$ [S2, unofficial].
    b. Access the center value $f(c)$ and its 6 face neighbors (Left, Right, Bottom, Top, Down, Up) [S2, unofficial].
    c. Compute the second pure partial derivatives $f_{xx}, f_{yy}, f_{zz}$ using the central difference formulas.
    d. Sum the derivatives to compute the Laplacian scalar $L(c) = f_{xx} + f_{yy} + f_{zz}$ [S2, unofficial].
    e. Store $L(c)$ in the result dictionary keyed by $c$ [S2, unofficial].
3.  Build the result grid from the computed data, using a background value of zero and the original grid's voxel size [S2, unofficial].

**Pseudocode:**
```python
def compute_laplacian_grid(input_grid):
    """
    Computes the Laplacian grid from a scalar field.
    input_grid: An iterable of (coord, value) tuples or a sparse grid structure.
    Returns: A list of (coord, laplacian_value) tuples.
    """
    # Helper to get value at coordinate, returning 0.0 for out-of-bounds or inactive voxels
    def get_value(grid, coord):
        return grid.get(coord, 0.0)

    output_data = []
    
    # Iterate over all active voxels in the input grid
    for coord, f_center in input_grid.active_voxels():
        x, y, z = coord
        
        # Access 6 face neighbors
        f_right = get_value(input_grid, (x + 1, y, z))
        f_left  = get_value(input_grid, (x - 1, y, z))
        f_top   = get_value(input_grid, (x, y + 1, z))
        f_bottom= get_value(input_grid, (x, y - 1, z))
        f_up    = get_value(input_grid, (x, y, z + 1))
        f_down  = get_value(input_grid, (x, y, z - 1))
        
        # Compute second derivatives (assuming unit spacing for simplicity; 
        # scale by 1/dx^2 etc. if non-unit spacing is provided)
        f_xx = f_right - 2.0 * f_center + f_left
        f_yy = f_top   - 2.0 * f_center + f_bottom
        f_zz = f_up    - 2.0 * f_center + f_down
        
        # Compute Laplacian
        laplacian = f_xx + f_yy + f_zz
        
        output_data.append((coord, laplacian))
        
    return output_data
```

**Parameters and Edge Cases:**
*   **Spacing:** If $\Delta x, \Delta y, \Delta z \neq 1$, the derivatives must be divided by the square of the respective spacing [G].
*   **Boundaries:** Neighbors outside the active domain require handling. Strategies include zero-padding (implicit in the `get_value` helper above), clamping, or substituting obstacle velocities, which vary by child method [S2, G, unofficial].
*   **Homogeneous Regions:** In areas where the gradient change is constant, $\nabla^2 f$ approaches zero, effectively suppressing homogeneous interiors [S1].

### [Scale Field Computation](6538-scale-field-computation.md)
Estimates a 3D scalar field encoding local feature size using iterative non-linear diffusion. It allows for sub-voxel scale detection and better localization than subsampled pyramids.

### [Scale Space Construction](8275-scale-space-construction.md)
Generates a continuous multi-scale representation by solving the linear diffusion equation. It avoids discretization artifacts by providing a continuous solution via Gaussian convolution, building on the Laplacian operator.

## Operating characteristics
*   **Complexity:** Time complexity is $O(N)$ where $N$ is the number of active voxels, as each voxel requires a constant number of memory accesses (6 neighbors) and arithmetic operations. Memory complexity is $O(N)$ for the output grid.
*   **Strengths:** Efficiently highlights boundaries and structural features while suppressing homogeneous regions [S1]. Computationally inexpensive compared to higher-order or non-linear methods.
*   **Limitations:** Linear diffusion can cause nearby objects to merge into a single blob before detection, leading to inaccurate scale maxima localization [S3, unofficial]. Using the first derivative field as input is less appropriate for general cases as extrema are not clear boundary indicators [S1].
*   **When to use:** When boundary detection or feature extraction in volumetric data is required, particularly as a precursor to scale-space analysis [S1][S3, unofficial].

## Background
The Laplacian operator is a fundamental differential operator in vector calculus. In the context of volume rendering and scientific visualization, it was utilized in techniques such as "Size-based Transfer Functions: A New Volume Exploration Technique" (2008) for blob detection and scale estimation [S3, unofficial]. The definition of divergence as a limit of a surface integral is a standard mathematical formulation [S1]. The method is implemented in libraries such as Lyr.jl [S2, unofficial].
