# Laplacian Grid Computation

Also called: Divergence of Gradient, Laplacian Field Transformation, Laplacian of Gaussian (LoG) Scale Detection, Normalized Laplacian Detection, Second Derivative Field

## Overview
Laplacian Grid Computation transforms a scalar volume field $f(x,y,z)$ into a new scalar field representing the Laplacian $\nabla^2 f$, which is the divergence of the gradient [S1]. This operation highlights boundaries and structural features while suppressing homogeneous interiors where the gradient change is constant [S1]. It differs from sibling methods like [Mean Curvature Grid Computation](3126-mean-curvature-grid-computation.md) by computing the trace of the Hessian (sum of pure second derivatives) rather than the mean curvature, and from [Divergence Grid Computation](3151-divergence-grid-computation.md) by operating on the gradient of a scalar field rather than an arbitrary vector field [S1].

## How it works
**Inputs and Outputs:**
- Input: A scalar grid $f$ with active voxels, voxel spacing $\Delta x$ (assumed isotropic for standard index-space computation), and a background value (typically 0).
- Output: A scalar grid $L$ containing $\nabla^2 f$ at every active voxel, with the same geometry and background value as the input.

**Data Structures:**
- `Grid`: A sparse or dense container mapping coordinates $(x,y,z)$ to scalar values.
- `Stencil`: A 6-point cross stencil accessing neighbors $(x\pm1, y, z), (x, y\pm1, z), (x, y, z\pm1)$.

**Formulas:**
The Laplacian is defined as the sum of pure second partial derivatives [S1]:
$$ \nabla^2 f(x, y, z) = \frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2} + \frac{\partial^2 f}{\partial z^2} $$
Using central differences with unit index spacing [S2, unofficial]:
$$ \frac{\partial^2 f}{\partial x^2} \approx f(x+1, y, z) - 2f(x, y, z) + f(x-1, y, z) $$
If physical voxel spacing $\Delta x$ is used, the result is scaled by $1/\Delta x^2$ [Parent].

**Steps:**
1. Initialize a result grid $L$ with the same topology as input $f$, filling inactive voxels with the background value (0).
2. Iterate over all active voxels $c = (x,y,z)$ in the input grid.
3. For each voxel, compute the Laplacian using the 6-point stencil:
   $$ L[c] = (f[x+1,y,z] - 2f[x,y,z] + f[x-1,y,z]) + (f[x,y+1,z] - 2f[x,y,z] + f[x,y-1,z]) + (f[x,y,z+1] - 2f[x,y,z] + f[x,y,z-1]) $$
   Simplified:
   $$ L[c] = \sum_{n \in \text{neighbors}(c)} f[n] - 6f[c] $$
   Where neighbors are the 6 adjacent voxels in index space.
4. Handle boundary conditions: For voxels on the grid boundary, neighbors outside the active domain are assumed to be the background value (0) [Parent].
5. Store $L[c]$ in the result grid.

**Pseudocode:**
```python
def compute_laplacian_grid(input_grid, background_value=0.0):
    """
    Computes the Laplacian grid from a scalar input grid.
    input_grid: dict mapping (x,y,z) -> float, or a sparse grid structure.
    Returns: dict mapping (x,y,z) -> float for the Laplacian field.
    """
    output_grid = {}
    
    # Get all active coordinates
    active_coords = input_grid.keys()
    
    for c in active_coords:
        x, y, z = c
        center_val = input_grid[c]
        
        # Sum of neighbors (6-point stencil)
        # Neighbors outside the grid are treated as background_value
        neighbor_sum = 0.0
        neighbor_sum += input_grid.get((x+1, y, z), background_value)
        neighbor_sum += input_grid.get((x-1, y, z), background_value)
        neighbor_sum += input_grid.get((x, y+1, z), background_value)
        neighbor_sum += input_grid.get((x, y-1, z), background_value)
        neighbor_sum += input_grid.get((x, y, z+1), background_value)
        neighbor_sum += input_grid.get((x, y, z-1), background_value)
        
        # Laplacian formula: sum(neighbors) - 6 * center
        laplacian_val = neighbor_sum - 6.0 * center_val
        
        output_grid[c] = laplacian_val
        
    return output_grid
```

**Parameters:**
- `background_value`: Default 0.0. Determines the value of non-existent neighbors [Parent].
- `voxel_spacing`: If physical units are required, divide the index-space result by $\Delta x^2$ [Parent]. Not given in sources for the basic index-space implementation [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Boundaries:** Standard implementations assume zero-padding for neighbors outside the active domain [Parent].
- **Noise:** The Laplacian is sensitive to noise; homogeneous interiors are suppressed, but noise may create false boundaries [S1].
- **Input Choice:** Using the first derivative field as input is less appropriate for general cases because extrema are not clear boundary indicators [S1].

Generates a continuous multi-scale representation by solving the linear diffusion equation. Avoids discretization artifacts of pyramids by providing a continuous Gaussian convolution solution.

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of active voxels, as each voxel is processed once with a constant number of neighbor lookups.
- **Memory Complexity:** $O(N)$ for the output grid.
- **Performance:** Computation is lightweight and suitable for real-time or pre-processing stages. Single precision (`float`) is standard [Parent].
- **Strengths:** Effectively extracts boundaries and structural features; suppresses homogeneous regions; simple to implement [S1].
- **Limitations:** Sensitive to noise; linear diffusion can cause nearby objects to merge into a single blob before detection, leading to inaccurate scale maxima localization [S3, unofficial]. Non-linear conductivity filters can mitigate this [S3, unofficial].

## Background
The Laplacian operator is defined as the divergence of the gradient, originally expressed as a limit of a surface integral [S1]. In volume rendering, it is used for boundary-structure-aware transfer functions to classify objects based on their second derivative properties [S1]. The method is foundational for scale-space analysis and blob detection in volumetric data [S3, unofficial].
