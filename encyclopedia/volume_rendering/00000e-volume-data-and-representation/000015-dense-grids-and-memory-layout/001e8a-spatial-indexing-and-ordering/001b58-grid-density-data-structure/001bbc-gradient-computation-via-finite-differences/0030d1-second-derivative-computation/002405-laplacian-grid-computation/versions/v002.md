# Laplacian Grid Computation
Also called: Divergence of Gradient, Laplacian Field Transformation, Laplacian of Gaussian (LoG) Scale Detection, Normalized Laplacian Detection, Second Derivative Field

## Overview
Laplacian Grid Computation transforms a scalar volume field $f(x,y,z)$ into a new scalar field representing the Laplacian $\nabla^2 f$, which is the divergence of the gradient [S1]. This operation highlights boundaries and suppresses homogeneous interiors, making it useful for extracting material interfaces and classifying objects based on their structural properties [S1]. It differs from sibling methods like [Mean Curvature Grid Computation](3126-mean-curvature-grid-computation.md) by providing a simpler, isotropic second-derivative measure that is computationally cheaper but lacks directional sensitivity to surface shape [S1]. Unlike [Divergence Grid Computation](3151-divergence-grid-computation.md) which operates on vector fields, this method operates directly on the scalar intensity field [S1].

## How it works
**Inputs and Outputs**
- Input: A scalar volume field $f$ defined on a grid with voxel size $\Delta x, \Delta y, \Delta z$.
- Output: A scalar grid containing values $\nabla^2 f$ at each active voxel, with a background value of zero [S2, unofficial].

**Data Structures**
- The input is a grid tree or dense array of scalar values [S2, unofficial].
- The output is a grid of the same topology, storing floating-point values [S2, unofficial].
- A stencil is used to access neighboring voxels [S2, unofficial].

**Formulas**
The Laplacian is defined as the sum of the second partial derivatives [S1]:
$$
\nabla^2 f(x, y, z) = \frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2} + \frac{\partial^2 f}{\partial z^2}
$$
In discrete space, this is computed using a 6-point stencil (central differences) [S2, unofficial]. The divergence of a vector field $F$ is formally defined as [S1]:
$$
\nabla \cdot F \equiv \lim_{V \to 0} \frac{\oint_S F \cdot ds}{V}
$$
where $S$ is the closed infinitesimal boundary surface surrounding volume $V$ [S1].

**Parameters**
- Stencil type: 6-point (nearest neighbors) [S2, unofficial].
- Background value: 0 [S2, unofficial].

**Steps**
1. Initialize a gradient stencil (`GradStencil`) with the input grid tree [S2, unofficial].
2. Create an empty dictionary or output grid to store computed Laplacian values [S2, unofficial].
3. Iterate over all active voxels in the grid tree [S2, unofficial].
4. For each voxel at coordinate $c$:
   a. Move the stencil to coordinate $c$ [S2, unofficial].
   b. Compute the Laplacian scalar using the stencil values (sum of second derivatives along x, y, z) [S2, unofficial].
   c. Store the result in the output dictionary keyed by $c$ [S2, unofficial].
5. Build the result grid using the computed data, a background value of zero, and the original grid's voxel size [S2, unofficial].

**Pseudocode**
```python
def compute_laplacian_grid(input_grid):
    """
    Computes the Laplacian grid for a scalar volume.
    Uses a 6-point stencil for second derivatives.
    """
    # Initialize output structure with same topology as input
    output_grid = Grid(topology=input_grid.topology, background_value=0.0)
    
    # Define 6-point stencil offsets (neighbors in x, y, z)
    # Assuming unit spacing for simplicity; scale by voxel size if needed
    neighbors = [
        (-1, 0, 0), (1, 0, 0),  # x-axis
        (0, -1, 0), (0, 1, 0),  # y-axis
        (0, 0, -1), (0, 0, 1)   # z-axis
    ]
    
    # Iterate over all active voxels
    for coord in input_grid.active_voxels():
        center_val = input_grid.get_value(coord)
        
        laplacian_sum = 0.0
        
        # Compute second derivative along each axis
        # d2f/dx2 = f(x+1) - 2*f(x) + f(x-1)
        # We sum this for x, y, z
        
        # X-axis contribution
        p_x = coord + (-1, 0, 0)
        n_x = coord + (1, 0, 0)
        val_p_x = input_grid.get_value(p_x) if input_grid.is_active(p_x) else center_val
        val_n_x = input_grid.get_value(n_x) if input_grid.is_active(n_x) else center_val
        laplacian_sum += (val_p_x - 2.0 * center_val + val_n_x)
        
        # Y-axis contribution
        p_y = coord + (0, -1, 0)
        n_y = coord + (0, 1, 0)
        val_p_y = input_grid.get_value(p_y) if input_grid.is_active(p_y) else center_val
        val_n_y = input_grid.get_value(n_y) if input_grid.is_active(n_y) else center_val
        laplacian_sum += (val_p_y - 2.0 * center_val + val_n_y)
        
        # Z-axis contribution
        p_z = coord + (0, 0, -1)
        n_z = coord + (0, 0, 1)
        val_p_z = input_grid.get_value(p_z) if input_grid.is_active(p_z) else center_val
        val_n_z = input_grid.get_value(n_z) if input_grid.is_active(n_z) else center_val
        laplacian_sum += (val_p_z - 2.0 * center_val + val_n_z)
        
        # Store result
        output_grid.set_value(coord, laplacian_sum)
        
    return output_grid
```

**Edge Cases and Pitfalls**
- **Homogeneous Regions**: If $\nabla^2 f$ is 0 in an area, the gradient change is constant, transforming the area to be homogeneous [S1].
- **Input Choice**: Using the first derivative field $f'(x)$ as input to standard deviation operators is less appropriate for general cases because extrema are not clear boundary indicators and fail to distinguish objects with similar intensities [S1].
- **Boundary Handling**: The pseudocode above clamps to the center value for inactive neighbors. In practice, boundary conditions (e.g., zero-gradient or mirroring) should be consistent with the application [G].

## Subtopics

### [GPU Laplacian Scale-Space Maxima Detection](5852-gpu-laplacian-scale-space-maxima-detection.md)
Detects local maxima of the Laplacian $\nabla^2 f$ across a scale space to identify blob-like structures. It differs from siblings by merging scale-space diffusion and maxima detection into a single per-iteration pass, avoiding the storage of the full scale-space pyramid in GPU memory.

### [Scale Field Computation](6538-scale-field-computation.md)
Estimates a 3D scalar field $S$ encoding local feature size using iterative non-linear diffusion. It differs from pyramid-based approaches by allowing sub-voxel scale detection and better localization without subsampling granularity.

## Operating characteristics
- **Time Complexity**: $O(N)$ where $N$ is the number of active voxels, as each voxel is processed once with a constant-size stencil [S2, unofficial].
- **Memory Complexity**: $O(N)$ to store the output grid [S2, unofficial].
- **Strengths**: Simple to implement; effectively highlights boundaries and suppresses homogeneous interiors [S1].
- **Limitations**: Linear diffusion can cause nearby objects to merge into a single blob before detection, leading to inaccurate scale maxima localization [S3, unofficial].
- **When to use**: When boundary extraction or homogeneous region suppression is required [S1].
- **When not to use**: When directional surface shape information is needed (use Mean Curvature) or when scale-space analysis is required (use Scale Field Computation) [S1].

## Background
The Laplacian operator is the divergence of the gradient, originally defined via the limit of a surface integral [S1]. It has been used in volume rendering for boundary-structure-aware transfer functions to classify objects based on their second derivatives [S1]. The method is foundational for scale-space analysis in volumetric data, where normalized Laplacian maxima are used for blob detection [S3, unofficial].
