# Depth and Image Gradient Regularization

Also called: Curvature Regularization with Gradient Masking, Depth Regularization with Image Gradient Weighting

## Overview
This method applies a spatial regularization loss to a predicted depth map by penalizing second-order derivatives (curvature) weighted by the local image gradient magnitude. It solves the problem of noisy or inconsistent depth predictions in regions of high texture by suppressing curvature penalties where image gradients are strong, thereby preserving sharp edges while smoothing flat regions. It differs from standard Laplacian regularization by introducing an adaptive weighting mechanism based on the input image intensity, rather than applying a uniform smoothness prior.

## How it works
The method operates on a 2D depth map $D$ and a corresponding 2D image intensity map $\mathbf{I}$, both defined on a pixel grid with coordinates $\mathbf{u} = (u_x, u_y)$. The output is a scalar regularization loss value $\mathcal{L}_{\text{reg. depth}}$ for each pixel, which can be summed for global optimization.

**Inputs:**
- $D$: A 2D grid of depth values.
- $\mathbf{I}$: A 2D grid of image intensities (grayscale or per-channel magnitude).
- $\alpha$: The exponential weighting scale factor (default 8.0).

**Data Structures:**
- The grids are treated as dense arrays. Boundary handling for neighbors outside the grid is not explicitly defined in the source; standard practice implies clamping or ignoring, but the source does not specify [G].

**Steps:**

1.  **Compute Horizontal Depth Curvature ($D_x^{\Delta}$):**
    For each pixel $\mathbf{u}$, calculate the second-order finite difference along the x-axis:
    $$ D_x^{\Delta}[\mathbf{u}] = D[\mathbf{u}_{x-1}, \mathbf{u}_y] - 2D[\mathbf{u}_x, \mathbf{u}_y] + D[\mathbf{u}_{x+1}, \mathbf{u}_y] $$
    where $\mathbf{u}_{x-1}$ and $\mathbf{u}_{x+1}$ are the left and right neighbors.

2.  **Compute Vertical Depth Curvature ($D_y^{\Delta}$):**
    For each pixel $\mathbf{u}$, calculate the second-order finite difference along the y-axis:
    $$ D_y^{\Delta}[\mathbf{u}] = D[\mathbf{u}_x, \mathbf{u}_{y-1}] - 2D[\mathbf{u}_x, \mathbf{u}_y] + D[\mathbf{u}_x, \mathbf{u}_{y+1}] $$
    where $\mathbf{u}_{y-1}$ and $\mathbf{u}_{y+1}$ are the top and bottom neighbors.

3.  **Compute Horizontal Image Gradient Magnitude ($\mathbf{I}_x^{\Delta}$):**
    Calculate the L-infinity norm of the first-order differences along the x-axis:
    $$ \mathbf{I}_x^{\Delta}[\mathbf{u}] = \max\left(|\mathbf{I}[\mathbf{u}_{x-1}, \mathbf{u}_y] - \mathbf{I}[\mathbf{u}_x, \mathbf{u}_y]|, |\mathbf{I}[\mathbf{u}_{x+1}, \mathbf{u}_y] - \mathbf{I}[\mathbf{u}_x, \mathbf{u}_y]|\right) $$

4.  **Compute Vertical Image Gradient Magnitude ($\mathbf{I}_y^{\Delta}$):**
    Calculate the L-infinity norm of the first-order differences along the y-axis:
    $$ \mathbf{I}_y^{\Delta}[\mathbf{u}] = \max\left(|\mathbf{I}[\mathbf{u}_x, \mathbf{u}_{y-1}] - \mathbf{I}[\mathbf{u}_x, \mathbf{u}_y]|, |\mathbf{I}[\mathbf{u}_x, \mathbf{u}_{y+1}] - \mathbf{I}[\mathbf{u}_x, \mathbf{u}_y]|\right) $$

5.  **Compute Regularization Loss:**
    Combine the curvatures and gradient weights using an exponential function:
    $$ \mathcal{L}_{\text{reg. depth}}[\mathbf{u}] = D_x^{\Delta}[\mathbf{u}] \exp\left(\alpha \cdot \mathbf{I}_x^{\Delta}[\mathbf{u}]\right) + D_y^{\Delta}[\mathbf{u}] \exp\left(\alpha \cdot \mathbf{I}_y^{\Delta}[\mathbf{u}]\right) $$

**Pseudocode:**

```python
def depth_gradient_regularization(D: Grid2D, I: Grid2D, alpha: float = 8.0) -> Grid2D:
    """
    Computes the depth regularization loss weighted by image gradients.
    
    Args:
        D: 2D grid of depth values.
        I: 2D grid of image intensities.
        alpha: Exponential weighting factor (default 8.0).
        
    Returns:
        2D grid of regularization loss values.
    """
    H, W = D.shape
    loss_grid = zeros((H, W))
    
    for y in range(1, H - 1):
        for x in range(1, W - 1):
            # 1. Horizontal Depth Curvature
            d_x = D[y, x-1] - 2 * D[y, x] + D[y, x+1]
            
            # 2. Vertical Depth Curvature
            d_y = D[y-1, x] - 2 * D[y, x] + D[y+1, x]
            
            # 3. Horizontal Image Gradient Magnitude (L-infinity)
            grad_x = max(
                abs(I[y, x-1] - I[y, x]),
                abs(I[y, x+1] - I[y, x])
            )
            
            # 4. Vertical Image Gradient Magnitude (L-infinity)
            grad_y = max(
                abs(I[y-1, x] - I[y, x]),
                abs(I[y+1, x] - I[y, x])
            )
            
            # 5. Weighted Loss
            loss_grid[y, x] = d_x * exp(alpha * grad_x) + d_y * exp(alpha * grad_y)
            
    return loss_grid
```

**Parameters:**
- $\alpha = 8.0$: The scaling factor for the exponential weight. This value is taken directly from the source [S1].

**Edge Cases and Pitfalls:**
- **Boundary Pixels:** The stencil requires neighbors at $x \pm 1$ and $y \pm 1$. The source does not specify how to handle pixels at the grid boundary ($x=0, x=W-1, y=0, y=H-1$). Implementation must define a strategy (e.g., zero-padding, clamping, or skipping) [G].
- **Sign of Curvature:** The formula uses the raw second derivative $D_x^{\Delta}$, not its absolute value. This means the regularization penalizes positive and negative curvature differently depending on the sign of the derivative. If the goal is to minimize "roughness" regardless of direction, the absolute value $|D_x^{\Delta}|$ might be intended, but the source explicitly writes $D_x^{\Delta}$ [S1].
- **Exponential Overflow:** If image gradients are large, $\exp(\alpha \cdot \mathbf{I})$ can overflow. Clamping gradients or the exponent is recommended [G].

## Subtopics

### Mean Curvature Grid Computation
Computes the sum of principal curvatures (trace of the Hessian) without image gradient weighting. Use when uniform smoothness is desired across the entire depth map, regardless of texture. [Mean Curvature Grid Computation](3126-mean-curvature-grid-computation.md)

### Divergence Grid Computation
Computes the divergence of a vector field. Use when regularizing flow fields or velocity vectors rather than scalar depth maps. [Divergence Grid Computation](3151-divergence-grid-computation.md)

### Laplacian Grid Computation
Computes the standard Laplacian (sum of second derivatives) with uniform weights. Use when image information is unavailable or when a simple isotropic smoothness prior is sufficient. [Laplacian Grid Computation](3160-laplacian-grid-computation.md)

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of pixels, as it requires a constant number of operations per pixel.
- **Memory Complexity:** $O(N)$ to store the input grids and the output loss grid.
- **Strengths:** Preserves sharp edges in depth maps corresponding to object boundaries in the image, preventing "bleeding" of depth values across edges.
- **Limitations:** Only applicable to 2D depth maps derived from images. Sensitive to noise in the image intensity map $\mathbf{I}$, which can cause erratic weighting.
- **When to use:** In differentiable rendering pipelines (e.g., 3D Gaussian Splatting) where depth consistency with the input image is critical.
- **When not to use:** When the depth map is not aligned with the image, or when the image is grayscale and lacks sufficient gradient information.

## Background
This method was introduced in the context of "PixelSplat," a technique for scalable generalizable 3D reconstruction from image pairs using 3D Gaussian splats [S1]. The regularization is applied to the predicted depth map to ensure it remains consistent with the input image structure, leveraging the fact that depth discontinuities often align with image gradients.
