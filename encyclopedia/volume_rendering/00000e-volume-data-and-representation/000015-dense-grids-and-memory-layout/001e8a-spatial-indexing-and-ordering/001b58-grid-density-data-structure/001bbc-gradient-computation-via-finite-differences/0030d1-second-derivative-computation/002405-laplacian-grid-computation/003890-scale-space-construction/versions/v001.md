# Scale Space Construction

Also called: Continuous Scale Space, Diffusion-based Scale Space, Gaussian Scale Space, Linear Scale Space, Linear continuous scale space

## Overview
Scale Space Construction generates a continuous multi-scale representation of a scalar volume by solving the linear diffusion equation, producing a family of signals $L$ parameterized by scale $t$ [S1][S2, unofficial]. Unlike pyramid representations that subsample space and scale, this method avoids discretization artifacts in maxima detection by providing a continuous solution via Gaussian convolution [S1][S2, unofficial]. It builds on [Laplacian Grid Computation](3160-laplacian-grid-computation.md) by extending the Laplacian operator into a temporal diffusion process.

## How it works
**Inputs and Outputs:**
*   Input: A scalar field $f: \mathbb{R}^N \rightarrow \mathbb{R}$ defined on the volume domain.
*   Output: A scale space representation $L: \mathbb{R}^N \times \mathbb{R}^+ \rightarrow \mathbb{R}$, where each $L(\cdot; t)$ is the signal at scale $t$.

**Data Structures:**
The implementation requires storing the input volume $f$ and computing $L$ for a range of scale parameters $t$. Since $L$ is continuous in $t$, it is typically evaluated at discrete steps for storage or on-the-fly. No specific bit-packing is mandated by the theory; standard floating-point grids are used.

**Mathematical Formulation:**
The linear continuous scale space is defined as the solution to the diffusion equation [S1][S2, unofficial]:

$$
\frac{\partial L}{\partial t} = \frac{1}{2} \nabla^2 L
$$

with the initial condition [S1][S2, unofficial]:

$$
L(\mathbf{x}; 0) = f(\mathbf{x})
$$

where:
*   $L(\mathbf{x}; t)$ is the scale space signal at spatial coordinate $\mathbf{x}$ and scale parameter $t$.
*   $\nabla^2$ is the Laplacian operator.
*   $t$ is the scale parameter, representing the size of the Gaussian kernel [S1][S2, unofficial].

The analytical solution to this equation is the convolution of the input signal with a Gaussian kernel $g(\mathbf{x}; t)$ [S1][S2, unofficial]:

$$
L(\mathbf{x}; t) = g(\mathbf{x}; t) * f(\mathbf{x})
$$

The Gaussian kernel is defined as [S1][S2, unofficial]:

$$
g(\mathbf{x}; t) = \frac{1}{(2\pi t)^{N/2}} e^{-\frac{\|\mathbf{x}\|^2}{2t}}
$$

Note: Source [S1] provides the 2D kernel form $\frac{1}{2\pi t} e^{\frac{-\|\mathbf{x}\|^2}{2t}}$, while [S2, unofficial] provides the general $N$-dimensional form $\frac{1}{(2\sqrt{\pi t})^N} e^{\frac{-\|\mathbf{x}\|^2}{2t}}$. For 3D volumes ($N=3$), the normalization factor is $\frac{1}{(2\pi t)^{3/2}}$.

**Algorithm Steps:**
1.  Define the input volume $f$ on a discrete grid.
2.  Select a range of scale parameters $t > 0$.
3.  For each $t$, compute the Gaussian kernel $g(\mathbf{x}; t)$ centered at the origin.
4.  Convolve $f$ with $g(\mathbf{x}; t)$ to obtain $L(\mathbf{x}; t)$.
    *   In practice, this is often implemented by applying a Gaussian filter with standard deviation $\sigma = \sqrt{t}$ to the volume [G].
5.  Store or process $L(\mathbf{x}; t)$ for the desired scales.

**Pseudocode:**
```python
import numpy as np
from scipy.ndimage import gaussian_filter

def construct_scale_space(volume: np.ndarray, scales: np.ndarray) -> np.ndarray:
    """
    Constructs the linear continuous scale space for a given volume.
    
    Args:
        volume: Input scalar field f(x). Shape (D, H, W).
        scales: Array of scale parameters t.
        
    Returns:
        scale_space: Array of shape (len(scales), D, H, W) containing L(x; t).
    """
    scale_space = np.zeros((len(scales), *volume.shape))
    
    for i, t in enumerate(scales):
        # The standard deviation sigma of the Gaussian kernel is sqrt(t)
        sigma = np.sqrt(t)
        
        # Convolve the volume with the Gaussian kernel
        # gaussian_filter applies the convolution L(x;t) = g(x,t) * f(x)
        # mode='constant' handles boundaries; 'reflect' or 'nearest' may be used
        # depending on volume boundary conditions [G]
        L_t = gaussian_filter(volume, sigma=sigma, mode='constant')
        
        scale_space[i] = L_t
        
    return scale_space
```

**Edge Cases and Pitfalls:**
*   **Pyramid Artifacts:** Discrete pyramid representations subsample space and scale, leading to poor localization of Laplacian maxima for higher scales and missing true maxima due to discrete scale steps (e.g., detecting max at scale 32 instead of 40) [S1][S2, unofficial]. Continuous scale space avoids this by not subsampling [S1][S2, unofficial].
*   **Scale Parameter $t$:** Must be positive. $t=0$ corresponds to the original signal.
*   **Boundary Conditions:** The convolution requires handling volume boundaries. Standard implementations use padding or reflection, which may introduce artifacts near the edges [G].

## Operating characteristics
*   **Time Complexity**: Computing $L(\mathbf{x}; t)$ for a single scale $t$ via Gaussian convolution is $O(N \cdot K^D)$, where $N$ is the number of voxels, $K$ is the kernel support size, and $D$ is the dimensionality. For large $t$, the kernel support grows, increasing cost. Separable filtering reduces this to $O(N \cdot K \cdot D)$.
*   **Memory Complexity**: $O(N \cdot S)$, where $S$ is the number of scales stored. If computed on-the-fly, $O(N)$.
*   **Strengths**: Provides a continuous representation of scale, avoiding the discretization errors of pyramids. Guarantees non-creation of local extrema as scale increases (axiom of scale space) [S1][S2, unofficial].
*   **Limitations**: Computationally expensive for large volumes and many scales. Requires careful handling of boundary conditions.
*   **When to use**: When accurate scale detection is critical, especially for large-scale features where pyramid subsampling fails.
*   **When not to use**: When real-time performance is required and approximate scale detection is acceptable.

## Background
Scale space theory was developed in the computer vision community to analyze the multi-scale nature of data [S1][S2, unofficial]. The linear continuous scale space is based on the axioms that Gaussian smoothing is the only filter satisfying linearity, isotropy, shift and scale invariance, and non-creation of local extrema [S1][S2, unofficial]. This framework has been extended to nonlinear and anisotropic scale spaces [S1][S2, unofficial]. In volume rendering, it is used for size-based transfer functions and feature detection [S1][S2, unofficial].
