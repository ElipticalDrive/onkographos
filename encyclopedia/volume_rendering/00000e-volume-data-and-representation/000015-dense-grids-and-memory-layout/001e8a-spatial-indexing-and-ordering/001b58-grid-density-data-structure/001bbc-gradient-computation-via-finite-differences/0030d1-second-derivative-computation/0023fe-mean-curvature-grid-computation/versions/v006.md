# Mean Curvature Grid Computation

Also called: Mean Curvature via BoxStencil, Divergence of Normalized Gradient

## Overview
Computes the mean curvature $\kappa$ of a scalar field $f$ at every active voxel by evaluating the divergence of the normalized gradient field, $\kappa = \nabla \cdot (\nabla f / |\nabla f|)$ [S1, unofficial]. It distinguishes itself from sibling methods by combining first and second derivative computations into a single stencil pass, avoiding the creation of intermediate gradient or Hessian grids [S1, unofficial].

## How it works
**Inputs:** A scalar field grid $f$ defined on a voxel grid with coordinates $(x, y, z)$.
**Outputs:** A grid of mean curvature values $\kappa$ with the same spatial layout as the input.

**Data Structures:**
The method uses a `BoxStencil` object [S1, unofficial]. This stencil provides access to voxel values at relative offsets from a center coordinate. It encapsulates the logic for retrieving values at neighbors required for finite difference approximations.

**Parameters:**
- `eps(T)`: The machine epsilon for the floating-point type $T$ of the grid data, used to prevent division by zero [S1, unofficial].
- Multipliers: $0.5$ for first derivatives, $0.25$ for mixed second derivatives [S1, unofficial].

**Algorithm Steps:**
1. Initialize a `BoxStencil` with the input grid tree [S1, unofficial].
2. Iterate over all active voxels in the grid. For each voxel at coordinate $c$:
    a. Move the stencil to position $c$ [S1, unofficial].
    b. Retrieve the center value $f_c = \text{value\_at}(s, 0, 0, 0)$ [S1, unofficial].
    c. Compute first partial derivatives using central differences with a $0.5$ multiplier:
       $$ f_x = (f(x+1, y, z) - f(x-1, y, z)) \times 0.5 $$
       $$ f_y = (f(x, y+1, z) - f(x, y-1, z)) \times 0.5 $$
       $$ f_z = (f(x, y, z+1) - f(x, y, z-1)) \times 0.5 $$
    d. Compute the squared gradient magnitude:
       $$ \text{grad\_sq} = f_x^2 + f_y^2 + f_z^2 $$
    e. **Edge Case:** If $\text{grad\_sq} < \text{eps}(T)$, set $\kappa(c) = 0$ and continue to the next voxel [S1, unofficial]. This avoids division by zero in flat regions or singularities.
    f. Compute pure second partial derivatives using the center value and a $-2$ multiplier:
       $$ f_{xx} = f(x+1, y, z) + f(x-1, y, z) - 2f_c $$
       $$ f_{yy} = f(x, y+1, z) + f(x, y-1, z) - 2f_c $$
       $$ f_{zz} = f(x, y, z+1) + f(x, y, z-1) - 2f_c $$
    g. Compute mixed second partial derivatives using a $0.25$ multiplier:
       $$ f_{xy} = (f(x+1, y+1, z) - f(x-1, y+1, z) - f(x+1, y-1, z) + f(x-1, y-1, z)) \times 0.25 $$
       $$ f_{xz} = (f(x+1, y, z+1) - f(x-1, y, z+1) - f(x+1, y, z-1) + f(x-1, y, z-1)) \times 0.25 $$
       $$ f_{yz} = (f(x, y+1, z+1) - f(x, y-1, z+1) - f(x, y+1, z-1) + f(x, y-1, z-1)) \times 0.25 $$
    h. Compute the numerator of the curvature formula:
       $$ \text{numer} = f_x^2(f_{yy} + f_{zz}) + f_y^2(f_{xx} + f_{zz}) + f_z^2(f_{xx} + f_{yy}) - 2(f_x f_y f_{xy} + f_x f_z f_{xz} + f_y f_z f_{yz}) $$
    i. Compute the final mean curvature:
       $$ \kappa = \frac{\text{numer}}{\text{grad\_sq} \times \sqrt{\text{grad\_sq}}} $$
    j. Store $\kappa$ in the output grid at $c$ [S1, unofficial].
3. Build the result grid using the computed data, a background value of zero, and the original grid's voxel size [S1, unofficial].

**Pseudocode:**
```python
def compute_mean_curvature(grid):
    # Initialize output grid with zeros
    output_grid = GridLike(grid, background=0.0)
    
    # Initialize stencil with the input grid
    stencil = BoxStencil(grid)
    
    # Iterate over all active voxels
    for c in grid.active_voxels():
        # Move stencil to current coordinate
        stencil.move_to(c)
        
        # Retrieve center value
        f_c = stencil.value_at(0, 0, 0)
        
        # Compute first derivatives (central difference, multiplier 0.5)
        fx = (stencil.value_at(1, 0, 0) - stencil.value_at(-1, 0, 0)) * 0.5
        fy = (stencil.value_at(0, 1, 0) - stencil.value_at(0, -1, 0)) * 0.5
        fz = (stencil.value_at(0, 0, 1) - stencil.value_at(0, 0, -1)) * 0.5
        
        # Compute squared gradient magnitude
        grad_sq = fx*fx + fy*fy + fz*fz
        
        # Handle near-zero gradient to avoid division by zero
        if grad_sq < eps(type(fx)):
            output_grid.set(c, 0.0)
            continue
            
        # Compute pure second derivatives (multiplier -2 for center)
        fxx = stencil.value_at(1, 0, 0) + stencil.value_at(-1, 0, 0) - 2.0 * f_c
        fyy = stencil.value_at(0, 1, 0) + stencil.value_at(0, -1, 0) - 2.0 * f_c
        fzz = stencil.value_at(0, 0, 1) + stencil.value_at(0, 0, -1) - 2.0 * f_c
        
        # Compute mixed second derivatives (multiplier 0.25)
        fxy = (stencil.value_at(1, 1, 0) - stencil.value_at(-1, 1, 0) - 
               stencil.value_at(1, -1, 0) + stencil.value_at(-1, -1, 0)) * 0.25
        fxz = (stencil.value_at(1, 0, 1) - stencil.value_at(-1, 0, 1) - 
               stencil.value_at(1, 0, -1) + stencil.value_at(-1, 0, -1)) * 0.25
        fyz = (stencil.value_at(0, 1, 1) - stencil.value_at(0, -1, 1) - 
               stencil.value_at(0, 1, -1) + stencil.value_at(0, -1, -1)) * 0.25
        
        # Compute numerator of curvature formula
        numer = (fx*fx * (fyy + fzz) + 
                 fy*fy * (fxx + fzz) + 
                 fz*fz * (fxx + fyy) - 
                 2.0 * (fx*fy*fxy + fx*fz*fxz + fy*fz*fyz))
        
        # Compute final curvature: numer / |grad|^3
        # |grad|^3 = grad_sq * sqrt(grad_sq)
        curvature = numer / (grad_sq * sqrt(grad_sq))
        
        # Store result
        output_grid.set(c, curvature)
        
    return output_grid
```

## Operating characteristics
**Time Complexity:** $O(N)$, where $N$ is the number of active voxels. Each voxel requires a constant number of arithmetic operations and stencil lookups.
**Memory Complexity:** $O(N)$ for the output grid. The method avoids intermediate grids, reducing memory overhead compared to computing gradients and Hessians separately.
**Strengths:** Efficient single-pass computation; avoids memory allocation for intermediate fields; robust handling of zero-gradient regions.
**Limitations:** Accuracy depends on the grid resolution and the validity of the central difference approximation. Not suitable for non-uniform grids without scaling adjustments (scaling factors are not explicitly handled in the core formula, assuming unit spacing or pre-scaled data).

## Background
The method is implemented in the Lyr.jl library [S1, unofficial]. It leverages the `BoxStencil` abstraction to provide a concise and efficient implementation of the mean curvature operator on sparse or dense voxel grids. The formula used is the standard discrete approximation of the divergence of the normalized gradient.
