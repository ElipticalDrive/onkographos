# Depth and Image Gradient Regularization

Also called: Curvature Regularization with Gradient Masking, Depth Regularization with Image Gradient Weighting

## Overview
This method applies a spatial regularization loss to predicted depth maps by penalizing second-order derivatives (curvature) weighted by local image gradient magnitudes. It solves the problem of noisy or inconsistent depth predictions in textureless regions by enforcing smoothness where the input image is flat, while allowing depth discontinuities to persist at object boundaries where the image gradient is high. It differs from standard Laplacian smoothing [Laplacian Grid Computation](3160-laplacian-grid-computation.md) by introducing an adaptive weighting factor derived from the input image intensity, rather than applying uniform smoothing.

## How it works
The method operates on a predicted depth map $D$ and an input image $\mathbf{I}$, both defined on a 2D grid of pixel coordinates $\mathbf{u} = (u_x, u_y)$. The output is a scalar regularization loss value $\mathcal{L}_{\text{reg. depth}}$ for each pixel, which can be summed for optimization.

**Inputs:**
- $D$: A 2D grid of depth values, where $D[\mathbf{u}]$ is the depth at pixel $\mathbf{u}$.
- $\mathbf{I}$: A 2D grid of image intensities (grayscale or per-channel magnitude), where $\mathbf{I}[\mathbf{u}]$ is the intensity at pixel $\mathbf{u}$.

**Data Structures:**
- The grids $D$ and $\mathbf{I}$ share the same dimensions $W \times H$.
- Values are typically floating-point numbers.

**Steps:**

1.  **Compute Horizontal Depth Curvature:**
    Calculate the second-order derivative of depth in the horizontal direction using a central difference stencil. For a pixel $\mathbf{u} = (u_x, u_y)$:
    $$ D_x^{\Delta}[\mathbf{u}] = D[\mathbf{u}_{x-1}, \mathbf{u}_y] - 2D[\mathbf{u}_x, \mathbf{u}_y] + D[\mathbf{u}_{x+1}, \mathbf{u}_y] $$
    where $\mathbf{u}_{x-1} = (u_x-1, u_y)$ and $\mathbf{u}_{x+1} = (u_x+1, u_y)$.

2.  **Compute Vertical Depth Curvature:**
    Calculate the second-order derivative of depth in the vertical direction:
    $$ D_y^{\Delta}[\mathbf{u}] = D[\mathbf{u}_x, \mathbf{u}_{y-1}] - 2D[\mathbf{u}_x, \mathbf{u}_y] + D[\mathbf{u}_x, \mathbf{u}_{y+1}] $$
    where $\mathbf{u}_{y-1} = (u_x, u_y-1)$ and $\mathbf{u}_{y+1} = (u_x, u_y+1)$.

3.  **Compute Horizontal Image Gradient Magnitude:**
    Compute the magnitude of the image gradient in the horizontal direction using the L-infinity norm (maximum absolute difference) over horizontal neighbors:
    $$ \mathbf{I}_x^{\Delta}[\mathbf{u}] = \max\left(|\mathbf{I}[\mathbf{u}_{x-1}, \mathbf{u}_y] - \mathbf{I}[\mathbf{u}_x, \mathbf{u}_y]|, |\mathbf{I}[\mathbf{u}_{x+1}, \mathbf{u}_y] - \mathbf{I}[\mathbf{u}_x, \mathbf{u}_y]|\right) $$

4.  **Compute Vertical Image Gradient Magnitude:**
    Compute the magnitude of the image gradient in the vertical direction using the L-infinity norm over vertical neighbors:
    $$ \mathbf{I}_y^{\Delta}[\mathbf{u}] = \max\left(|\mathbf{I}[\mathbf{u}_x, \mathbf{u}_{y-1}] - \mathbf{I}[\mathbf{u}_x, \mathbf{u}_y]|, |\mathbf{I}[\mathbf{u}_x, \mathbf{u}_{y+1}] - \mathbf{I}[\mathbf{u}_x, \mathbf{u}_y]|\right) $$

5.  **Compute Regularization Loss:**
    Combine the depth curvatures and image gradient magnitudes. The loss for pixel $\mathbf{u}$ is:
    $$ \mathcal{L}_{\text{reg. depth}}[\mathbf{u}] = D_x^{\Delta}[\mathbf{u}] \exp\left(8 \cdot \mathbf{I}_x^{\Delta}[\mathbf{u}]\right) + D_y^{\Delta}[\mathbf{u}] \exp\left(8 \cdot \mathbf{I}_y^{\Delta}[\mathbf{u}]\right) $$
    The total loss is typically the sum or mean of $\mathcal{L}_{\text{reg. depth}}[\mathbf{u}]$ over all valid pixels.

**Parameters:**
- The exponential scaling factor is fixed at $8$ [S1].

**Edge Cases and Pitfalls:**
- **Boundary Handling:** The stencils require neighbors at $x \pm 1$ and $y \pm 1$. Pixels on the image border (where $u_x=0, u_x=W-1, u_y=0, u_y=H-1$) do not have all required neighbors. The source does not specify the boundary handling strategy (e.g., clamping, zero-padding, or exclusion) [G]. Implementers must choose a consistent strategy, such as skipping boundary pixels or padding the depth/image grids.
- **Numerical Stability:** The term $\exp(8 \cdot \mathbf{I}^{\Delta})$ can grow very large if image gradients are high, potentially causing overflow or dominating the loss. However, in practice, image gradients are bounded by the intensity range (e.g., $[0, 1]$ or $[0, 255]$). If intensities are normalized to $[0, 1]$, the maximum exponent is $8$, which is stable. If intensities are not normalized, scaling is required.
- **Sign of Curvature:** The depth curvature $D_x^{\Delta}$ can be positive or negative. The loss does not take the absolute value of the curvature, meaning it penalizes both concave and convex curvatures equally in the linear combination. This is consistent with the source formula [S1].

**Pseudocode:**

```python
def depth_gradient_regularization(depth_map, image_map):
    """
    Computes the depth and image gradient regularization loss.
    
    Args:
        depth_map: 2D numpy array of shape (H, W) containing depth values D.
        image_map: 2D numpy array of shape (H, W) containing image intensities I.
        
    Returns:
        total_loss: scalar float representing the sum of regularization losses.
    """
    H, W = depth_map.shape
    
    # Initialize loss grid
    loss_grid = np.zeros((H, W))
    
    # Iterate over interior pixels to avoid boundary checks
    # Boundary pixels are excluded from the loss calculation as per standard stencil application
    # where neighbors are undefined.
    for y in range(1, H - 1):
        for x in range(1, W - 1):
            # 1. Horizontal depth curvature
            d_x = depth_map[y, x-1] - 2 * depth_map[y, x] + depth_map[y, x+1]
            
            # 2. Vertical depth curvature
            d_y = depth_map[y-1, x] - 2 * depth_map[y, x] + depth_map[y+1, x]
            
            # 3. Horizontal image gradient magnitude (L-infinity norm)
            i_x = max(abs(image_map[y, x-1] - image_map[y, x]), 
                      abs(image_map[y, x+1] - image_map[y, x]))
            
            # 4. Vertical image gradient magnitude (L-infinity norm)
            i_y = max(abs(image_map[y-1, x] - image_map[y, x]), 
                      abs(image_map[y+1, x] - image_map[y, x]))
            
            # 5. Compute loss for this pixel
            # Exponential scaling factor is 8
            loss_grid[y, x] = d_x * np.exp(8 * i_x) + d_y * np.exp(8 * i_y)
            
    # Sum all valid pixel losses
    total_loss = np.sum(loss_grid)
    
    return total_loss
```

## Operating characteristics
- **Time Complexity:** $O(W \times H)$, where $W$ and $H$ are the width and height of the depth map. Each pixel requires a constant number of arithmetic operations and memory accesses.
- **Memory Complexity:** $O(W \times H)$ to store the intermediate gradient and curvature values if computed explicitly, or $O(1)$ if computed on-the-fly during the loss summation.
- **Strengths:** Effectively preserves sharp depth edges corresponding to object boundaries in the input image, while smoothing depth in textureless regions. This leads to more visually plausible depth maps in challenging scenes.
- **Limitations:** Sensitive to noise in the image gradient computation. If the input image is noisy, the gradient magnitude may be high in textureless regions, leading to insufficient smoothing. The choice of the exponential factor (8) is fixed and may not be optimal for all intensity ranges.
- **When to use:** When optimizing depth maps from image pairs or monocular predictions where preserving edge fidelity is critical.
- **When not to use:** When the input image is very noisy or when uniform smoothing is desired regardless of image content.

## Background
This method was introduced in the context of 3D Gaussian Splatting for scalable generalizable 3D reconstruction. It is used in the PixelSplat model to regularize the predicted depth maps derived from 3D Gaussian parameters. The approach leverages the correlation between image gradients and depth discontinuities to guide the smoothing process.
