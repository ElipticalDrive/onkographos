# Laplacian Grid Computation via Finite Differences

Also called: First Derivative and Laplacian Operators, Laplacian Field Transformation, applyDx, applyDy

## Overview
This method computes the discrete Laplacian of a scalar field defined on a 2D grid by applying finite difference operators. It constructs the Laplacian matrix implicitly by composing forward and transpose first-derivative operators, allowing for weighted (gamma) regularization. It differs from standard central-difference Laplacians by using a specific boundary-aware forward-difference formulation that preserves matrix symmetry properties in the resulting operator application, often used in inverse problems and regularization [S1, unofficial].

## How it works
**Inputs:**
- $f$: A 2D numpy array of shape $(H, W)$ representing the scalar field values.
- $\gamma$: (Optional) A weighting matrix or scalar. If scalar, it is treated as a uniform weight. If not provided or scalar, the unweighted Laplacian is computed. If an ndarray, it must match the row dimension of $f$ for the weighted variant [S1, unofficial].

**Outputs:**
- $L_f$: A 1D numpy array of shape $(H \times W,)$ containing the flattened Laplacian values.

**Data Structures:**
- The method operates directly on NumPy arrays. No explicit sparse matrix storage is used; the operator is applied via dense array operations.

**Steps:**

1. **Define Forward Derivative along Rows ($x$-axis):**
   Compute the forward difference along axis 0 (rows). For a grid $u$ of shape $(H, W)$:
   $$ D_x u = \begin{bmatrix} u_{1,0}-u_{0,0} & \dots & u_{1,W-1}-u_{0,W-1} \\ \vdots & \ddots & \vdots \\ u_{H-1,W-1}-u_{H-2,W-1} \end{bmatrix} $$
   Append a zero row at the bottom to maintain shape $(H, W)$ [S1, unofficial]:
   $$ \text{applyDx}(u) = \text{vstack}(D_x u, \mathbf{0}_{1 \times W}) $$

2. **Define Forward Derivative along Columns ($y$-axis):**
   Compute the forward difference along axis 1 (columns).
   $$ D_y u = \begin{bmatrix} u_{0,1}-u_{0,0} & \dots & u_{0,W-1}-u_{0,W-2} \\ \vdots & \ddots & \vdots \\ u_{H-1,1}-u_{H-1,0} & \dots & u_{H-1,W-1}-u_{H-1,W-2} \end{bmatrix} $$
   Append a zero column at the right to maintain shape $(H, W)$ [S1, unofficial]:
   $$ \text{applyDy}(u) = \text{hstack}(D_y u, \mathbf{0}_{H \times 1}) $$

3. **Define Transpose Derivative along Rows ($x$-axis):**
   The transpose operator $\text{applyDx}^T$ is computed as [S1, unofficial]:
   $$ \text{applyDx}^T(u) = \text{vstack}\left( -u_{0,:}, -\text{diff}(u_{1:H-1,:}, \text{axis}=0), u_{H-2,:} \right) $$
   Specifically:
   - First row: $-u_{0, :}$
   - Middle rows ($i=1 \dots H-2$): $-(u_{i+1, :} - u_{i-1, :})$? No, the code uses `np.diff(u[:-1, :], axis=0)`. Let's trace carefully.
     `u[:-1, :]` is rows $0$ to $H-2$. `np.diff(..., axis=0)` computes $u_{i+1} - u_i$ for $i=0 \dots H-3$.
     The result is stacked with $-u_{0,:}$ at top and $u_{H-2,:}$ at bottom.
     Wait, the code is: `np.vstack([-u[0:1, :], -np.diff(u[:-1, :], axis=0), u[-2:-1, :]])`.
     Let $v = \text{applyDx}^T(u)$.
     $v_{0,:} = -u_{0,:}$
     $v_{i,:} = -(u_{i,:} - u_{i-1,:})$ for $i=1 \dots H-2$?
     `np.diff(u[:-1], axis=0)` produces a matrix of size $(H-2, W)$ where entry $(i, j)$ is $u_{i+1, j} - u_{i, j}$.
     So $- \text{diff}$ is $u_{i, j} - u_{i+1, j}$.
     This is stacked between $-u_{0,:}$ and $u_{H-2,:}$.
     This formulation corresponds to the negative adjoint of the forward difference with zero-padding boundary conditions [S1, unofficial].

4. **Define Transpose Derivative along Columns ($y$-axis):**
   Similarly, $\text{applyDy}^T$ is computed as [S1, unofficial]:
   $$ \text{applyDy}^T(u) = \text{hstack}\left( -u_{:, 0}, -\text{diff}(u_{:, :-1}, \text{axis}=1), u_{:, W-2} \right) $$

5. **Compute Laplacian:**
   - **Unweighted:**
     $$ L_f = \text{flatten}(\text{applyDx}^T(\text{applyDx}(f)) + \text{applyDy}^T(\text{applyDy}(f))) $$
   - **Weighted (with $\gamma$):**
     If $\gamma$ is not an ndarray, set $\gamma = I_H$ (identity matrix of size $H \times H$) [S1, unofficial].
     $$ L_f = \text{flatten}\left( \sqrt{\gamma} \cdot \text{applyDx}^T(\sqrt{\gamma} \cdot \text{applyDx}(f)) + \sqrt{\gamma} \cdot \text{applyDy}^T(\sqrt{\gamma} \cdot \text{applyDy}(f)) \right) $$
     Note: The multiplication $\sqrt{\gamma} @ \dots$ implies matrix-vector multiplication if the inner result is flattened, or element-wise if shapes align. Given `applyDx` returns $(H, W)$, and $\gamma$ is $(H, H)$, the operation `np.sqrt(gamma) @ applyDx(f)` is invalid if `applyDx(f)` is 2D. However, the source code shows `np.sqrt(gamma)@ applyDxTrans(np.sqrt(gamma)@applyDx(f))`.
     Let's re-read the source snippet:
     `dxx = np.sqrt(gamma)@ applyDxTrans(np.sqrt(gamma)@applyDx(f))`
     `applyDx(f)` is $(H, W)$.
     `np.sqrt(gamma)` is $(H, H)$.
     Matrix multiplication `(H,H) @ (H,W)` results in $(H, W)$. This is valid.
     Then `applyDxTrans` takes $(H, W)$ and returns $(H, W)$.
     Then `np.sqrt(gamma) @ ...` results in $(H, W)$.
     Finally, sum and flatten [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def applyDx(u):
    """Applies the forward derivative along the first dimension (rows)."""
    # u shape: (H, W)
    Dx = np.diff(u, axis=0)  # Shape: (H-1, W)
    # Append a zero row at the bottom
    zero_row = np.zeros((1, u.shape[1]), dtype=u.dtype)
    return np.vstack([Dx, zero_row])

def applyDy(u):
    """Applies the forward derivative along the second dimension (columns)."""
    # u shape: (H, W)
    Dy = np.diff(u, axis=1)  # Shape: (H, W-1)
    # Append a zero column at the right
    zero_col = np.zeros((u.shape[0], 1), dtype=u.dtype)
    return np.hstack([Dy, zero_col])

def applyDxTrans(u):
    """Applies the transpose of the first derivative along the first dimension (rows)."""
    # u shape: (H, W)
    # Top row: -u[0, :]
    top = -u[0:1, :]  # Shape: (1, W)
    
    # Middle rows: -diff(u[:-1, :], axis=0)
    # u[:-1, :] is rows 0 to H-2. diff computes u[i+1] - u[i].
    # Result shape: (H-2, W)
    mid = -np.diff(u[:-1, :], axis=0)
    
    # Bottom row: u[-2, :]
    bottom = u[-2:-1, :]  # Shape: (1, W)
    
    return np.vstack([top, mid, bottom])

def applyDyTrans(u):
    """Applies the transpose of the first derivative along the second dimension (columns)."""
    # u shape: (H, W)
    # Left col: -u[:, 0]
    left = -u[:, 0:1]  # Shape: (H, 1)
    
    # Middle cols: -diff(u[:, :-1], axis=1)
    # u[:, :-1] is cols 0 to W-2. diff computes u[:, j+1] - u[:, j].
    # Result shape: (H, W-2)
    mid = -np.diff(u[:, :-1], axis=1)
    
    # Right col: u[:, -2]
    right = u[:, -2:-1]  # Shape: (H, 1)
    
    return np.hstack([left, mid, right])

def laplacian(f, gamma=None):
    """
    Computes the Laplacian of f.
    If gamma is provided and is an ndarray, computes weighted Laplacian.
    """
    if gamma is not None and not isinstance(gamma, np.ndarray):
        # If gamma is a scalar, treat as uniform weight (identity matrix for weighting)
        # However, the source sets gamma = np.eye(f.shape[0]) if not ndarray.
        # If it is a scalar, we might need to broadcast or treat as identity.
        # The source logic: "If gamma is not an ndarray, set gamma = np.eye(f.shape[0])"
        gamma = np.eye(f.shape[0])
    
    if gamma is None or (isinstance(gamma, np.ndarray) and gamma.shape[0] == f.shape[0] and np.allclose(gamma, np.eye(f.shape[0]))):
        # Unweighted case
        dxx = applyDxTrans(applyDx(f))
        dyy = applyDyTrans(applyDy(f))
        laplace_f = dxx + dyy
        return laplace_f.flatten()
    else:
        # Weighted case
        sqrt_gamma = np.sqrt(gamma)
        
        # dxx = sqrt_gamma @ applyDxTrans(sqrt_gamma @ applyDx(f))
        # Note: applyDx(f) is (H, W). sqrt_gamma is (H, H).
        # sqrt_gamma @ applyDx(f) is (H, W).
        temp_x = applyDx(f)
        weighted_x = sqrt_gamma @ temp_x
        dxx = sqrt_gamma @ applyDxTrans(weighted_x)
        
        # dyy = sqrt_gamma @ applyDyTrans(sqrt_gamma @ applyDy(f))
        temp_y = applyDy(f)
        weighted_y = sqrt_gamma @ temp_y
        dyy = sqrt_gamma @ applyDyTrans(weighted_y)
        
        laplace_f = dxx + dyy
        return laplace_f.flatten()
```

**Edge Cases and Pitfalls:**
- **Grid Dimensions:** If $H=1$ or $W=1$, `np.diff` returns empty arrays. The slicing `u[-2:-1]` may behave unexpectedly if dimensions are too small. The source assumes standard image-like dimensions $H, W \ge 2$ [S1, unofficial].
- **Gamma Shape:** The weighted Laplacian requires $\gamma$ to be a square matrix of size $H \times H$. Broadcasting rules in NumPy apply to the matrix multiplication `@` [S1, unofficial].
- **Boundary Conditions:** The zero-padding in `applyDx` and `applyDy` and the specific boundary handling in `applyDxTrans` and `applyDyTrans` define the implicit boundary conditions. These are not standard Neumann or Dirichlet but specific to the adjoint formulation [S1, unofficial].

## Subtopics

### Time Smoothness Regularization via Second Derivative
A regularizer that enforces smoothness over the time dimension of spatiotemporal grids by penalizing the second derivative. It identifies "time grids" based on the grid length (if length is 3, no time grids; otherwise indices [2, 4, 5] are time grids). For each time grid, it computes plane smoothness using the formula $\frac{1}{N} \sum (t_{i+2} - 2t_{i+1} + t_i)^2$, where the second difference is computed along the time dimension [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(H \times W)$ for the unweighted case. The weighted case involves matrix-vector multiplications with $\gamma$, which is $O(H^2 \times W)$ if $\gamma$ is dense, or $O(H \times W)$ if $\gamma$ is diagonal.
- **Memory Complexity:** $O(H \times W)$ for the input and output arrays. Intermediate arrays also require $O(H \times W)$ space.
- **Strengths:** Simple implementation using standard NumPy operations. Handles weighted regularization naturally.
- **Limitations:** The boundary conditions are implicit and may not match all physical boundary conditions. The weighted version can be computationally expensive if $\gamma$ is dense.
- **When to use:** When implementing inverse problems or regularization in 2D image/volume processing where the specific adjoint boundary conditions are desired [S1, unofficial].

## Background
This method is derived from implementations in inverse problems for CT scans, specifically using finite difference operators to construct Laplacian matrices for regularization [S1, unofficial]. It is also referenced in the context of 4D Gaussian Splatting for time-smoothness regularization [S2, unofficial].
