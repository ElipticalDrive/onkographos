# Scale Space Construction

Also called: Continuous Scale Space, Diffusion-based Scale Space, Gaussian Scale Space, Linear Scale Space, Linear continuous scale space

## Overview
Scale Space Construction generates a continuous multi-scale representation of a scalar volume by solving the linear diffusion equation, producing a family of signals $L$ parameterized by scale $t$ [S1][S2, unofficial]. Unlike pyramid representations that subsample space and scale, this method avoids discretization artifacts in maxima detection by providing a continuous solution via Gaussian convolution [S1][S2, unofficial]. It builds on [Laplacian Grid Computation](3160-laplacian-grid-computation.md) by extending the Laplacian operator into a temporal diffusion process [G].

## How it works
**Inputs and Outputs:**
*   Input: A scalar field $f: \mathbb{R}^N \rightarrow \mathbb{R}$ defined on the volume domain [S1][S2, unofficial].
*   Output: A scale space representation $L: \mathbb{R}^N \times \mathbb{R}^+ \rightarrow \mathbb{R}$, where each $L(\cdot; t)$ is the signal at scale $t$ [S1][S2, unofficial].

**Data Structures:**
The implementation requires storing the input volume $f$ and computing $L$ for a range of scale parameters $t$ [G]. Since $L$ is continuous in $t$, it is typically evaluated at discrete steps for storage or on-the-fly [G]. No specific bit-packing is mandated by the theory; standard floating-point grids are used [G].

**Mathematical Formulation:**
The linear continuous scale space is defined as the solution to the diffusion equation [S1][S2, unofficial]. The sources disagree on the diffusion constant: [S1] states $\frac{1}{2} \frac{\partial L}{\partial t} = \nabla^2 L$, while [S2, unofficial] states $\frac{\partial L}{\partial t} = \frac{1}{2} \nabla^2 L$ [S1][S2, unofficial]. Both use the initial condition $L(\mathbf{x}; 0) = f(\mathbf{x})$ [S1][S2, unofficial]. Here, $L(\mathbf{x}; t)$ is the scale space signal at spatial coordinate $\mathbf{x}$ and scale parameter $t$ [S1][S2, unofficial], $\nabla^2$ is the Laplacian operator [S1][S2, unofficial], and $t$ is the scale parameter representing the size of the Gaussian kernel [S1][S2, unofficial]. The analytical solution to this equation is the convolution of the input signal with a Gaussian kernel $g(\mathbf{x}; t)$ [S1][S2, unofficial]:
$$
L(\mathbf{x}; t) = g(\mathbf{x}; t) * f(\mathbf{x})
$$
The Gaussian kernel is defined as [S1][S2, unofficial]:
$$
g(\mathbf{x}; t) = \frac{1}{(2\pi t)^{N/2}} e^{-\frac{\|\mathbf{x}\|^2}{2t}}
$$

**Algorithm Steps:**
1. Define the input volume $f$ on a discrete grid [G].
2. Select a range of scale parameters $t > 0$ [S1][S2, unofficial].
3. For each $t$, compute the Gaussian kernel $g(\mathbf{x}; t)$ centered at the origin [G].
4. Convolve $f$ with $g(\mathbf{x}; t)$ to obtain $L(\mathbf{x}; t)$ [S1][S2, unofficial]. In practice, this is implemented by applying a Gaussian filter with standard deviation $\sigma = \sqrt{t}$ to the volume [G].
5. Store or process $L(\mathbf{x}; t)$ for the desired scales [G].

**Pseudocode:**
```python
import numpy as np

def convolve_1d(signal, kernel):
    """1D convolution with zero-padding."""
    out = np.zeros_like(signal)
    k_len = len(kernel)
    pad = k_len // 2
    padded = np.pad(signal, pad, mode='constant')
    for i in range(len(signal)):
        out[i] = np.sum(padded[i:i+k_len] * kernel)
    return out

def construct_scale_space(volume: np.ndarray, scales: np.ndarray) -> np.ndarray:
    """
    Constructs the linear continuous scale space for a given volume.
    
    Args:
        volume: Input scalar field f(x). Shape (D, H, W).
        scales: Array of scale parameters t.
        
    Returns:
        scale_space: Array of shape (len(scales), D, H, W) containing L(x; t).
    """
    scale_space = np.zeros((len(scales), *volume.shape))
    
    for i, t in enumerate(scales):
        sigma = np.sqrt(t)
        # Generate 1D Gaussian kernel
        x = np.arange(-3*sigma, 3*sigma + 1)
        kernel_1d = np.exp(-x**2 / (2 * t))
        kernel_1d /= kernel_1d.sum()
        
        # Apply separable convolution along each axis
        L_t = volume
        for axis in range(volume.ndim):
            L_t = convolve_1d(L_t, kernel_1d)
            
        scale_space[i] = L_t
        
    return scale_space
```

**Edge Cases and Pitfalls:**
*   **Pyramid Artifacts:** Discrete pyramid representations incorrectly detect maxima due to poor sampling of higher scales in space and scale, whereas continuous scale-space avoids this by not subsampling [S1][S2, unofficial].
*   **Scale Parameter $t$:** Must be positive. $t=0$ corresponds to the original signal [S1][S2, unofficial].
*   **Boundary Conditions:** The convolution requires handling volume boundaries. Standard implementations use padding or reflection, which may introduce artifacts near the edges [G].

## Operating characteristics
*   **Time Complexity**: Computing $L(\mathbf{x}; t)$ for a single scale $t$ via Gaussian convolution is $O(N \cdot K^D)$, where $N$ is the number of voxels, $K$ is the kernel support size, and $D$ is the dimensionality [G]. For large $t$, the kernel support grows, increasing cost [G]. Separable filtering reduces this to $O(N \cdot K \cdot D)$ [G].
*   **Memory Complexity**: $O(N \cdot S)$, where $S$ is the number of scales stored [G]. If computed on-the-fly, $O(N)$ [G].
*   **Strengths**: Provides a continuous representation of scale, avoiding the discretization errors of pyramids [S1][S2, unofficial]. Guarantees non-creation of local extrema as scale increases, satisfying the scale space axioms [S1][S2, unofficial].
*   **Limitations**: Computationally expensive for large volumes and many scales [G]. Requires careful handling of boundary conditions [G].
*   **When to use**: When accurate scale detection is critical, especially for large-scale features where pyramid subsampling fails [S1][S2, unofficial].
*   **When not to use**: When real-time performance is required and approximate scale detection is acceptable [G].

## Background
Scale space theory was developed in the computer vision community to analyze the multi-scale nature of data [S1][S2, unofficial]. The linear continuous scale space is based on the axioms that Gaussian smoothing is the only filter satisfying linearity, isotropy, shift and scale invariance, and non-creation of local extrema [S1][S2, unofficial]. This framework has been extended to nonlinear and anisotropic scale spaces [S1][S2, unofficial]. In volume rendering, it is used for size-based transfer functions and feature detection [S1][S2, unofficial].
