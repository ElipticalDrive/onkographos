# Mean Curvature Grid Computation

Also called: Mean Curvature via Divergence of Normalized Gradient

## Overview
Computes the mean curvature $\kappa$ of a scalar field $f$ at every active voxel by evaluating the divergence of the normalized gradient, $\kappa = \nabla \cdot (\frac{\nabla f}{|\nabla f|})$. It differs from [Laplacian Grid Computation](3160-laplacian-grid-computation.md) by normalizing the gradient vector, making it sensitive to the shape of the isosurfaces rather than just the local density variation. It avoids intermediate grids by computing all derivatives in a single pass.

## How it works
**Inputs:** A scalar grid tree containing active voxels.
**Outputs:** A new grid of the same topology, containing mean curvature values, with background initialized to zero.

**Data Structures:**
*   `BoxStencil`: A helper structure that caches values of $f$ at the center and immediate neighbors ($\delta \in \{-1, 0, 1\}$) for a given coordinate.

**Parameters:**
*   `eps(T)`: Machine epsilon for the grid's value type $T$, used to prevent division by zero.
*   `half`: Multiplier $0.5$ for first derivatives.
*   `quarter`: Multiplier $0.25$ for mixed second derivatives.

**Steps:**
1.  Initialize a `BoxStencil` with the input grid tree.
2.  Iterate over all active voxels $(c, \text{value})$ in the grid tree.
3.  Move the stencil to coordinate $c$.
4.  Retrieve the center value $f_{000} = \text{center\_value}(s)$.
5.  Compute first derivatives using central differences:
    *   $f_x = (f_{100} - f_{-100}) \times 0.5$
    *   $f_y = (f_{010} - f_{0-10}) \times 0.5$
    *   $f_z = (f_{001} - f_{00-1}) \times 0.5$
6.  Compute the squared gradient magnitude: $g^2 = f_x^2 + f_y^2 + f_z^2$.
7.  If $g^2 < \text{eps}(T)$, set the output at $c$ to $0$ and continue to the next voxel.
8.  Compute second derivatives:
    *   $f_{xx} = f_{100} + f_{-100} - 2f_{000}$
    *   $f_{yy} = f_{010} + f_{0-10} - 2f_{000}$
    *   $f_{zz} = f_{001} + f_{00-1} - 2f_{000}$
    *   $f_{xy} = (f_{110} - f_{-110} - f_{1-10} + f_{-1-10}) \times 0.25$
    *   $f_{xz} = (f_{101} - f_{-101} - f_{10-1} + f_{-10-1}) \times 0.25$
    *   $f_{yz} = (f_{011} - f_{0-11} - f_{01-1} + f_{0-1-1}) \times 0.25$
9.  Compute the numerator of the curvature formula:
    $$ \text{num} = f_x^2(f_{yy} + f_{zz}) + f_y^2(f_{xx} + f_{zz}) + f_z^2(f_{xx} + f_{yy}) - 2(f_x f_y f_{xy} + f_x f_z f_{xz} + f_y f_z f_{yz}) $$
10. Compute the final curvature: $\kappa = \frac{\text{num}}{g^2 \sqrt{g^2}}$.
11. Store $\kappa$ in the output grid at $c$.
12. Build the result grid using the computed data, a background value of $0$, and the original grid's voxel size.

**Pseudocode:**
```python
def compute_mean_curvature(input_grid):
    output_grid = Grid(topology=input_grid.topology, value_type=input_grid.value_type)
    output_grid.set_background(0.0)
    
    stencil = BoxStencil(input_grid)
    eps = epsilon(input_grid.value_type)
    
    for coord, _ in input_grid.active_voxels():
        stencil.move_to(coord)
        
        # First derivatives
        fx = (stencil.value(1, 0, 0) - stencil.value(-1, 0, 0)) * 0.5
        fy = (stencil.value(0, 1, 0) - stencil.value(0, -1, 0)) * 0.5
        fz = (stencil.value(0, 0, 1) - stencil.value(0, 0, -1)) * 0.5
        
        grad_sq = fx*fx + fy*fy + fz*fz
        
        # Handle near-zero gradient
        if grad_sq < eps:
            output_grid.set_value(coord, 0.0)
            continue
            
        # Second derivatives
        center = stencil.center_value()
        fxx = stencil.value(1, 0, 0) + stencil.value(-1, 0, 0) - 2.0 * center
        fyy = stencil.value(0, 1, 0) + stencil.value(0, -1, 0) - 2.0 * center
        fzz = stencil.value(0, 0, 1) + stencil.value(0, 0, -1) - 2.0 * center
        
        fxy = (stencil.value(1, 1, 0) - stencil.value(-1, 1, 0) - 
               stencil.value(1, -1, 0) + stencil.value(-1, -1, 0)) * 0.25
        fxz = (stencil.value(1, 0, 1) - stencil.value(-1, 0, 1) - 
               stencil.value(1, 0, -1) + stencil.value(-1, 0, -1)) * 0.25
        fyz = (stencil.value(0, 1, 1) - stencil.value(0, -1, 1) - 
               stencil.value(0, 1, -1) + stencil.value(0, -1, -1)) * 0.25
               
        # Numerator
        num = (fx*fx * (fyy + fzz) + 
               fy*fy * (fxx + fzz) + 
               fz*fz * (fxx + fyy) - 
               2.0 * (fx*fy*fxy + fx*fz*fxz + fy*fz*fyz))
               
        # Final curvature: num / |grad|^3
        curvature = num / (grad_sq * sqrt(grad_sq))
        output_grid.set_value(coord, curvature)
        
    return output_grid
```

## Operating characteristics
*   **Complexity:** $O(N)$ where $N$ is the number of active voxels. Each voxel requires a fixed number of memory accesses and arithmetic operations.
*   **Memory:** Requires one additional grid of the same size as the input. The stencil uses constant auxiliary memory.
*   **Strengths:** Single-pass computation avoids the overhead of intermediate grids. Accurate for smooth scalar fields.
*   **Limitations:** Sensitive to noise in the input field due to the normalization and division by gradient magnitude. Degenerate cases (zero gradient) must be handled explicitly to avoid NaNs.
*   **When to use:** When surface shape analysis is required, such as in level-set methods or surface reconstruction.
*   **When not to use:** For noisy data without prior smoothing, or when computational resources are extremely limited and only Laplacian is sufficient.

## Background
The method is implemented in the Lyr.jl library [S1, unofficial]. It relies on the standard definition of mean curvature as the divergence of the unit normal vector.
