# Gradient Magnitude Modulation

Also called: Gradient Magnitude Approximation, Gradient Magnitude Illumination Modulation, Gradient Magnitude Opacity Modulation

## Overview
Gradient Magnitude Modulation is a post-processing step in volume rendering that uses the computed gradient magnitude to modulate sample opacity and illumination values [S1]. It emphasizes surface boundaries by increasing opacity and brightness where gradients are high, while de-emphasizing homogeneous regions and noise where gradients are small [S1]. It differs from the underlying [Sobel Gradient Magnitude Approximation](1429-sobel-gradient-magnitude-approximation.md) by adding a lookup-based mapping and the final multiplication step, rather than just computing the raw magnitude value.

## How it works
**Inputs:**
- Gradient magnitude approximation $M$, an 8-bit integer in the range $[0, 2^{20}]$ (derived from the previous stage) [S1].
- Current sample opacity $\alpha$ and illumination $I$ (diffuse/specular) [S1].
- Three control registers: `Gmimd` (Gradient Magnitude Illumination Modulation for diffuse), `Gmims` (for specular), and `Gmom` (Gradient Magnitude Opacity Modulation) [S1].
- Gradient Magnitude Lookup Table (GmLUT) [S1].

**Outputs:**
- Modulated opacity $\alpha'$ and illumination $I'$ [S1].
- Modulation value $m \in [0, 1]$ [S1].

**Data Structures:**
- **GmLUT**: A table of eight entries. Each entry specifies a point on a piece-wise linear function. The entries are spaced at equal intervals along the gradient magnitude axis (input domain) [S1]. The output values of the table entries represent the modulation factor [S1].

**Steps:**
1. **Compute Squared Magnitude**: Calculate the sum of the squares of the gradient components $(g_x, g_y, g_z)$. Each component has signed 8-bit precision (range $[-127, 127]$) [S1].
   $$ S = g_x^2 + g_y^2 + g_z^2 $$
2. **Approximate Square Root**: Use a Newton-Raphson iteration to compute the square root of $S$, resulting in an 8-bit approximation $M$ in the range $[0, 2^{20}]$ [S1].
3. **Map to Lookup Index**: Map the magnitude $M$ into the range $[0, 255]$ using the piece-wise linear function defined by GmLUT. Since GmLUT has 8 entries at equal intervals, the input domain $[0, 2^{20}]$ is divided into 7 segments. The index $i$ for the table is determined by scaling $M$ to $[0, 255]$ and identifying the segment [S1].
4. **Interpolate Modulation Value**: Perform linear interpolation between the two nearest table values in GmLUT to compute the 8-bit repeating-fraction modulation value $m$ [S1]. This value represents a float in the range $[0, 1]$ [S1].
5. **Apply Modulation**:
   - If `Gmom` is enabled, compute $\alpha' = \alpha \times m$ [S1].
   - If `Gmimd` is enabled, compute $I'_{diffuse} = I_{diffuse} \times m$ [S1].
   - If `Gmims` is enabled, compute $I'_{specular} = I_{specular} \times m$ [S1].
   - If a register is disabled, the corresponding value remains unchanged [S1].

**Pseudocode:**
```python
def gradient_magnitude_modulation(gx, gy, gz, alpha, I_diffuse, I_specular, 
                                  Gmimd, Gmims, Gmom, GmLUT):
    """
    gx, gy, gz: signed 8-bit integers representing gradient components.
    alpha: current sample opacity.
    I_diffuse, I_specular: current illumination values.
    Gmimd, Gmims, Gmom: boolean flags enabling modulation for diffuse, specular, and opacity respectively.
    GmLUT: list of 8 floats representing the piece-wise linear function values.
    Returns: modulated_alpha, modulated_I_diffuse, modulated_I_specular
    """
    # Step 1: Compute squared magnitude
    # Note: Components are signed 8-bit, so values are in [-127, 127]
    S = gx*gx + gy*gy + gz*gz
    
    # Step 2: Newton-Raphson square root approximation
    # Result M is an 8-bit approximation in range [0, 2^20]
    # Implementation of Newton-Raphson for sqrt(S)
    # Initial guess x0
    x = S / 2.0 if S > 0 else 0.0
    # Iterate a few times for 8-bit precision
    for _ in range(4):
        if x == 0:
            break
        x = 0.5 * (x + S / x)
    M = x # M is now the magnitude approximation
    
    # Step 3 & 4: Map M to [0, 255] and interpolate using GmLUT
    # GmLUT has 8 entries at equal intervals along the gradient magnitude axis.
    # The input domain [0, 2^20] is mapped to [0, 255].
    # Let's assume linear scaling for the index calculation.
    max_mag = 2**20
    normalized_m = M / max_mag
    index_float = normalized_m * 255.0
    
    # Determine table indices
    # 8 entries mean 7 intervals. 
    # Index 0 corresponds to 0, Index 7 corresponds to 255.
    # We need to find which interval index_float falls into.
    table_size = 8
    interval_width = 255.0 / (table_size - 1)
    
    idx = int(index_float / interval_width)
    # Clamp idx to valid range [0, 7]
    idx = max(0, min(idx, table_size - 2))
    
    # Fractional part for interpolation
    frac = (index_float - idx * interval_width) / interval_width
    
    # Get table values
    val_low = GmLUT[idx]
    val_high = GmLUT[idx + 1]
    
    # Linear interpolation
    m = val_low + frac * (val_high - val_low)
    
    # Clamp m to [0, 1]
    m = max(0.0, min(1.0, m))
    
    # Step 5: Apply modulation
    mod_alpha = alpha
    mod_I_diffuse = I_diffuse
    mod_I_specular = I_specular
    
    if Gmom:
        mod_alpha = alpha * m
        
    if Gmimd:
        mod_I_diffuse = I_diffuse * m
        
    if Gmims:
        mod_I_specular = I_specular * m
        
    return mod_alpha, mod_I_diffuse, mod_I_specular
```

**Parameters:**
- `GmLUT`: 8-entry table defining the piece-wise linear mapping [S1].
- `Gmimd`, `Gmims`, `Gmom`: Boolean registers enabling the modulation [S1].

**Edge Cases:**
- Zero gradient: Results in $m=0$ (if LUT maps 0 to 0) or the base LUT value, effectively removing the sample from view if opacity is modulated [S1].
- Noise: Small gradients in noisy data result in low modulation values, reducing visual impact [S1].

## Operating characteristics
- **Time Complexity**: Constant time per sample, involving a few arithmetic operations and a table lookup/interpolation [S1].
- **Memory Complexity**: Requires storage for the GmLUT (8 entries) and 3 control registers [S1].
- **Strengths**: Effectively emphasizes surface boundaries and reduces noise artifacts by attenuating samples with small gradients [S1].
- **Limitations**: Relies on the accuracy of the gradient magnitude approximation; incorrect LUT configuration can lead to over- or under-emphasis of features [S1].
- **When to use**: When surface definition is critical and noise reduction is desired [S1].
- **When not to use**: When homogeneous regions need to be visible or when gradient information is unreliable [S1].

## Background
Gradient Magnitude Modulation is part of the VolumePro real-time ray-casting system [S1]. It was introduced in the VolumePro architecture to provide flexible control over surface appearance and noise handling [S1]. The method builds on the Sobel Gradient Magnitude Approximation to provide a computationally efficient way to modulate rendering parameters [S1].
