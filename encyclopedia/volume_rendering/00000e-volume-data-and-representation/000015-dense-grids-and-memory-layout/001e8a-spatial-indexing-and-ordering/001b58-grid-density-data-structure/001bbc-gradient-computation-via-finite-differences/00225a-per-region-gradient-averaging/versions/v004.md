# Per-Region Gradient Averaging


## Overview
Per-Region Gradient Averaging computes the gradient magnitude for each voxel in a scalar volume by aggregating directional gradients across multiple defined scalar regions [S1, unofficial]. It distinguishes itself from standard finite difference methods by using a binary neighbor check to detect region boundaries, assigning high weights to neighbors within the same region to enforce spatial coherence [S1, unofficial]. This method is primarily used to smooth learned volume representations and prevent high-frequency noise, serving as a preprocessing step for regularization techniques like Total Variation Gradient Addition [S1, unofficial][2877-total-variation-gradient-addition.md].

## How it works
**Inputs and Outputs:**
- Input: A 3D volume grid of scalar values representing multiple regions, and a list of defined regions [S1, unofficial].
- Output: A 3D grid of gradient magnitudes, one per voxel [S1, unofficial].

**Data Structures:**
- `self.data`: A flat list or array of `VoxelGradient` objects, with size $dim_x \times dim_y \times dim_z$ [S1, unofficial].
- `VoxelGradient`: A structure containing `prev_gx`, `prev_gy`, `prev_gz` (floats storing the running average of directional gradients) and `magnitude` (computed) [S1, unofficial].

**Numbered Steps:**
1. Initialize the volume data structure `self.data` with `VoxelGradient` objects for each voxel [S1, unofficial].
2. Replace the original volume scalar data with a boolean mask indicating region membership for each voxel [S1, unofficial].
3. For each voxel $(x, y, z)$ in the grid:
   a. Initialize `prev_gx = 0`, `prev_gy = 0`, `prev_gz = 0`, and counter `n = 0` [S1, unofficial].
   b. Iterate through each region in the `regions` list:
      i. Check the 6 spatial neighbors (±x, ±y, ±z) [S1, unofficial].
      ii. For each neighbor, determine if it belongs to the current region [S1, unofficial].
      iii. Assign a directional weight: $1000$ if the neighbor is in the region, $0$ otherwise [S1, unofficial].
      iv. Compute the directional gradient components ($g_x, g_y, g_z$) using the weighted neighbors [S1, unofficial].
      v. If the gradient is non-zero, update the running average: $new\_gx = (prev\_gx \times n + g_x) / (n + 1)$, repeating for $y$ and $z$ [S1, unofficial].
      vi. Update `prev_gx`, `prev_gy`, `prev_gz` with the new averages and increment `n` [S1, unofficial].
   c. After processing all regions, set the voxel's gradient vector to $(prev\_gx, prev\_gy, prev\_gz)$ [S1, unofficial].
   d. Compute the magnitude: $\sqrt{prev\_gx^2 + prev\_gy^2 + prev\_gz^2}$ [S1, unofficial].
4. Store the magnitude in the `VoxelGradient` object [S1, unofficial].
5. Implement lazy evaluation for `get_max_gradient_magnitude`: On the first call, scan `self.data` to find the maximum magnitude [S1, unofficial].

**Formulas:**
The directional gradient in the x-direction is computed as:
$$g_x = \frac{x_{plus} - x_{minus}}{2}$$
Where:
- $x_{plus} = 1000$ if $V(x+1, y, z) \in \text{region}$, else $0$ [S1, unofficial].
- $x_{minus} = 1000$ if $V(x-1, y, z) \in \text{region}$, else $0$ [S1, unofficial].
- Similar definitions apply for $g_y$ and $g_z$ using $y_{\pm}$ and $z_{\pm}$ [S1, unofficial].

**Parameters:**
- Weight $W = 1000$: A binary weight assigned to neighbors belonging to the current region to amplify boundary detection [S1, unofficial].

**Edge Cases and Pitfalls:**
- Boundary voxels access neighbors outside the volume bounds [S1, unofficial]. This is handled by a helper function `get_volume_voxel` which is assumed to clamp coordinates or return $0$ for out-of-bounds access [S1, unofficial].

**Pseudocode:**
```python
class VoxelGradient:
    prev_gx: float
    prev_gy: float
    prev_gz: float
    magnitude: float

def get_volume_voxel(volume_data, x, y, z, dim_x, dim_y, dim_z):
    if 0 <= x < dim_x and 0 <= y < dim_y and 0 <= z < dim_z:
        return volume_data[x][y][z]
    return 0.0

def compute_per_region_gradients(volume_data, regions, dim_x, dim_y, dim_z):
    # Initialize data structure [S1, unofficial]
    self_data = [VoxelGradient() for _ in range(dim_x * dim_y * dim_z)]

    # Replace volume data with boolean mask of regions [S1, unofficial]
    # We assume volume_data contains scalar values representing region IDs.

    for x in range(dim_x):
        for y in range(dim_y):
            for z in range(dim_z):
                prev_gx = 0.0
                prev_gy = 0.0
                prev_gz = 0.0
                n = 0

                for region in regions:
                    gx = 0.0
                    gy = 0.0
                    gz = 0.0

                    # Check 6 neighbors [S1, unofficial]
                    x_plus_val = get_volume_voxel(volume_data, x + 1, y, z, dim_x, dim_y, dim_z)
                    x_minus_val = get_volume_voxel(volume_data, x - 1, y, z, dim_x, dim_y, dim_z)
                    y_plus_val = get_volume_voxel(volume_data, x, y + 1, z, dim_x, dim_y, dim_z)
                    y_minus_val = get_volume_voxel(volume_data, x, y - 1, z, dim_x, dim_y, dim_z)
                    z_plus_val = get_volume_voxel(volume_data, x, y, z + 1, dim_x, dim_y, dim_z)
                    z_minus_val = get_volume_voxel(volume_data, x, y, z - 1, dim_x, dim_y, dim_z)

                    # Binary weight: 1000 if neighbor belongs to region, else 0 [S1, unofficial]
                    w_plus_x = 1000.0 if x_plus_val == region else 0.0
                    w_minus_x = 1000.0 if x_minus_val == region else 0.0
                    gx = (w_plus_x - w_minus_x) / 2.0

                    w_plus_y = 1000.0 if y_plus_val == region else 0.0
                    w_minus_y = 1000.0 if y_minus_val == region else 0.0
                    gy = (w_plus_y - w_minus_y) / 2.0

                    w_plus_z = 1000.0 if z_plus_val == region else 0.0
                    w_minus_z = 1000.0 if z_minus_val == region else 0.0
                    gz = (w_plus_z - w_minus_z) / 2.0

                    # Update running average if gradient is non-zero [S1, unofficial]
                    if gx != 0.0 or gy != 0.0 or gz != 0.0:
                        prev_gx = (prev_gx * n + gx) / (n + 1)
                        prev_gy = (prev_gy * n + gy) / (n + 1)
                        prev_gz = (prev_gz * n + gz) / (n + 1)
                        n += 1

                # After regions loop, set voxel gradient and compute magnitude [S1, unofficial]
                idx = x * dim_y * dim_z + y * dim_z + z
                self_data[idx].prev_gx = prev_gx
                self_data[idx].prev_gy = prev_gy
                self_data[idx].prev_gz = prev_gz
                self_data[idx].magnitude = (prev_gx**2 + prev_gy**2 + prev_gz**2)**0.5

    return self_data
```

## Subtopics

### [Total Variation Gradient Addition](2877-total-variation-gradient-addition.md)
Applies TV regularization to specific scalar fields using the aggregated gradient magnitudes from this method to enforce spatial coherence.

## Operating characteristics
- **Time Complexity:** $O(V \cdot R)$, where $V$ is the number of voxels and $R$ is the number of regions. Each voxel iterates through all regions and checks 6 neighbors [S1, unofficial].
- **Memory Complexity:** $O(V)$ for storing the gradient magnitudes and the region mask [S1, unofficial].
- **Strengths:** Effective at smoothing noise in learned volume representations by enforcing coherence within regions. Simple to implement [S1, unofficial].
- **Limitations:** Computationally expensive for volumes with many regions. The binary weight approach may oversimplify gradient information at complex boundaries [S1, unofficial].
- **When to use:** When using learned volume representations (e.g., NeRFs) that require regularization to prevent artifacts [S1, unofficial].
- **When not to use:** For standard physical volumes where accurate directional gradients are required for lighting or surface reconstruction [G].

## Background
Originated in the context of raycasting rendering implementations for learned volume representations, specifically in the `faviasono/raycastingrendering` repository [S1, unofficial]. It is used as a preprocessing step to compute gradient magnitudes for regularization purposes [S1, unofficial].
