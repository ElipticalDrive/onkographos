# Jacobian Estimation via Central Differences

Also called: Central Difference Jacobian, Finite Difference Jacobian

## Overview
This method estimates the 3x3 Jacobian matrix of a vector-valued deformation field (or displacement field) by computing central finite differences of the field's component functions. It solves the problem of obtaining the local linear transformation (stretch, shear, rotation) at a specific point in space, which is required for coordinate transformations in adaptive meshing or ray marching. It differs from raw gradient estimation by outputting a full matrix rather than a vector, and from analytical differentiation by relying on numerical approximation of the field function [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A point $\mathbf{p} = (x, y, z)$ in the domain, a deformation field function $F(\mathbf{p})$ that returns a 3D vector, and a step size $\epsilon$ (EPSILON).
- Output: A 3x3 Jacobian matrix $J$, where each column is the gradient of one component of $F$ with respect to the spatial coordinates.

**Data Structures:**
- The deformation field $F$ is treated as a black-box function returning a 3D vector.
- The Jacobian $J$ is a 3x3 matrix. In column-major storage (common in graphics APIs like OpenGL), the columns correspond to the partial derivatives with respect to $x$, $y$, and $z$ respectively.

**Steps:**
1. Define the central difference vectors for each axis:
   $$ \mathbf{d}_x = (\epsilon, 0, 0) $$
   $$ \mathbf{d}_y = (0, \epsilon, 0) $$
   $$ \mathbf{d}_z = (0, 0, \epsilon) $$
2. Evaluate the deformation field at the perturbed points for the x-axis:
   $$ \mathbf{v}_{x+} = F(\mathbf{p} + \mathbf{d}_x) $$
   $$ \mathbf{v}_{x-} = F(\mathbf{p} - \mathbf{d}_x) $$
3. Compute the first column of the Jacobian (gradient of $F$ with respect to $x$) by subtracting the backward evaluation from the forward evaluation and dividing by $2\epsilon$:
   $$ \mathbf{c}_x = \frac{\mathbf{v}_{x+} - \mathbf{v}_{x-}}{2\epsilon} $$
4. Repeat for the y-axis:
   $$ \mathbf{v}_{y+} = F(\mathbf{p} + \mathbf{d}_y) $$
   $$ \mathbf{v}_{y-} = F(\mathbf{p} - \mathbf{d}_y) $$
   $$ \mathbf{c}_y = \frac{\mathbf{v}_{y+} - \mathbf{v}_{y-}}{2\epsilon} $$
5. Repeat for the z-axis:
   $$ \mathbf{v}_{z+} = F(\mathbf{p} + \mathbf{d}_z) $$
   $$ \mathbf{v}_{z-} = F(\mathbf{p} - \mathbf{d}_z) $$
   $$ \mathbf{c}_z = \frac{\mathbf{v}_{z+} - \mathbf{v}_{z-}}{2\epsilon} $$
6. Construct the Jacobian matrix $J$ using $\mathbf{c}_x, \mathbf{c}_y, \mathbf{c}_z$ as columns:
   $$ J = \begin{bmatrix} | & | & | \\ \mathbf{c}_x & \mathbf{c}_y & \mathbf{c}_z \\ | & | & | \end{bmatrix} $$

**Parameters:**
- $\epsilon$ (EPSILON): The step size for finite differences. The source uses a small constant value, but does not specify a default numerical value [S1, unofficial].

**Pseudocode:**
```python
def estimate_jacobian_central_diff(p: Vector3, field_func: Callable[[Vector3], Vector3], epsilon: float) -> Matrix3x3:
    """
    Estimates the 3x3 Jacobian matrix of a deformation field at point p using central differences.
    
    Args:
        p: The 3D point at which to estimate the Jacobian.
        field_func: A function F(p) that returns a 3D vector (the deformation/displacement).
        epsilon: The step size for the finite difference approximation.
        
    Returns:
        A 3x3 Matrix where columns are the partial derivatives of the field components.
    """
    # Define perturbation vectors
    dx = Vector3(epsilon, 0.0, 0.0)
    dy = Vector3(0.0, epsilon, 0.0)
    dz = Vector3(0.0, 0.0, epsilon)
    
    # Evaluate field at perturbed positions
    # Forward differences
    p_plus_x = p + dx
    p_plus_y = p + dy
    p_plus_z = p + dz
    
    # Backward differences
    p_minus_x = p - dx
    p_minus_y = p - dy
    p_minus_z = p - dz
    
    # Compute field values
    f_plus_x = field_func(p_plus_x)
    f_minus_x = field_func(p_minus_x)
    f_plus_y = field_func(p_plus_y)
    f_minus_y = field_func(p_minus_y)
    f_plus_z = field_func(p_plus_z)
    f_minus_z = field_func(p_minus_z)
    
    # Compute central differences (gradients of components)
    # Column 1: dF/dx
    col_x = (f_plus_x - f_minus_x) / (2.0 * epsilon)
    
    # Column 2: dF/dy
    col_y = (f_plus_y - f_minus_y) / (2.0 * epsilon)
    
    # Column 3: dF/dz
    col_z = (f_plus_z - f_minus_z) / (2.0 * epsilon)
    
    # Construct matrix from columns
    # Assuming Matrix3x3 has a constructor taking 3 Vector3 columns
    J = Matrix3x3(col_x, col_y, col_z)
    
    return J
```

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** If $\mathbf{p} \pm \mathbf{d}_i$ falls outside the valid domain of the deformation field, the function evaluation may fail or return undefined values. Standard boundary handling (clamping, zero-padding) must be applied to the field function or the point coordinates before evaluation [G].
- **Step Size Selection:** If $\epsilon$ is too large, the approximation error (truncation error) increases. If $\epsilon$ is too small, floating-point cancellation errors may dominate. The source does not specify an optimal value [S1, unofficial].

## Subtopics

### [Jacobian Normalization for ODE Step](2946-jacobian-normalization-for-ode-step.md)
This method computes the normalized direction vector for an Ordinary Differential Equation (ODE) solver by applying the inverse of an estimated Jacobian matrix to a base direction vector. It differs from raw Jacobian estimation by performing the matrix inversion and vector normalization required for stable stepping. It assumes the Jacobian has already been estimated via central differences.

### [Flow Jacobian Decomposition](10525-flow-jacobian-decomposition.md)
Flow Jacobian Decomposition splits the 3x3 Jacobian matrix of a displacement field into symmetric and antisymmetric parts to isolate local geometric deformation (strain) from rigid-body rotation. It uses the Jacobian estimated via central differences as its input to analyze the local flow characteristics.

## Operating characteristics
**Time and Memory Complexity:**
- Time: Requires 6 evaluations of the deformation field function $F$ per point. Each evaluation is $O(1)$ relative to the stencil size, but depends on the cost of $F$ itself (e.g., texture lookup, grid traversal).
- Memory: $O(1)$ auxiliary memory for storing the perturbed points and intermediate vectors.

**Strengths and Limitations:**
- **Strengths:** Simple to implement; does not require analytical derivatives of the field function; works with any black-box deformation field [S1, S2, unofficial].
- **Limitations:** Numerical noise can be significant if the field is not smooth or if $\epsilon$ is poorly chosen; requires 6 function evaluations, which can be expensive for complex fields [S1, unofficial].

**When to Use:**
- Use when the deformation field is defined numerically or as a black-box function (e.g., a neural network output, a complex procedural shader) and analytical derivatives are unavailable.
- Use in contexts requiring local linearization, such as adaptive mesh refinement or ray marching step size control [S2, unofficial].

## Background
The method originates from the application of finite difference methods to estimate derivatives of vector fields in computational geometry and volume rendering. It is specifically cited in the context of interactive volume rendering with ray tracing, where it is used to approximate the Jacobian of the mapping between computational and physical space for sliding interfaces [S2, unofficial]. It is also implemented in graphics engines for material deformation, such as the NtslGraphics library, where it estimates the Jacobian of a "simpleBrush" deformation function [S1, unofficial].
