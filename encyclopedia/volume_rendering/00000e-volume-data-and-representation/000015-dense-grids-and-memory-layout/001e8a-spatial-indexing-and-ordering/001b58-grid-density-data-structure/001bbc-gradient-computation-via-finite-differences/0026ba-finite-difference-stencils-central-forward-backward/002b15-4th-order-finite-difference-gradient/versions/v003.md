# 4th-Order Finite Difference Gradient

Also called: 4th-Order Accurate Finite Difference Scheme, Grid Normal Computation via 4th-Order Finite Differences

## Overview
This method computes the gradient (normal vector) of a Signed Distance Function (SDF) grid at every voxel center using a 4th-order accurate finite difference scheme [S1, unofficial]. It provides smooth normals for ray marching and shading, distinguishing itself from lower-order methods like the Sobel Operator [1416-sobel-operator.md] or standard central differences by maintaining high accuracy even at volume boundaries through specific extrapolation techniques.

## How it works
**Inputs and Outputs:**
- Input: A 3D scalar grid $V$ of size $N_x \times N_y \times N_z$ containing SDF values, and a scalar `voxel_size` $h$ representing the physical spacing between voxels.
- Output: Three 3D grids $G_x, G_y, G_z$ representing the partial derivatives $\frac{\partial V}{\partial x}, \frac{\partial V}{\partial y}, \frac{\partial V}{\partial z}$ at each voxel center.

**Data Structures:**
The input grid is stored as a dense 3D array. The output grids share the same dimensions and memory layout as the input.

**Algorithm Steps:**
The gradient along each axis is computed by approximating the derivative using a central difference stencil. To achieve 4th-order accuracy at the boundaries, the stencil extends one voxel beyond the grid bounds using a polynomial extrapolation formula.

1.  **Boundary Extrapolation Formula:**
    For a grid dimension with indices $0$ to $n$, the value at index $n+1$ (outside the grid) is extrapolated as:
    $$ V_{n+1} = 3V_n - 3V_{n-1} + V_{n-2} $$
    Similarly, the value at index $-1$ is extrapolated as:
    $$ V_{-1} = 3V_0 - 3V_1 + V_2 $$
    This ensures the central difference approximation remains 4th-order accurate at the boundaries [S1, unofficial].

2.  **X-Axis Gradient:**
    - Compute forward difference term $X_1$: Concatenate the interior values $V[1:N_x, :, :]$ with the extrapolated boundary value at $N_x$.
      $$ X_1 = [V[1, :, :], \dots, V[N_x-1, :, :], V_{N_x+1}] $$
      where $V_{N_x+1} = 3V_{N_x} - 3V_{N_x-1} + V_{N_x-2}$.
    - Compute backward difference term $X_2$: Concatenate the extrapolated boundary value at $-1$ with the interior values $V[0:N_x-1, :, :]$.
      $$ X_2 = [V_{-1}, V[0, :, :], \dots, V[N_x-2, :, :]] $$
      where $V_{-1} = 3V_0 - 3V_1 + V_2$.
    - Calculate $G_x$:
      $$ G_x = \frac{X_1 - X_2}{2h} $$

3.  **Y-Axis Gradient:**
    - Compute $Y_1$: Concatenate $V[:, 1:N_y, :]$ with extrapolated value at $N_y$ along the y-dimension.
    - Compute $Y_2$: Concatenate extrapolated value at $-1$ with $V[:, 0:N_y-1, :]$.
    - Calculate $G_y$:
      $$ G_y = \frac{Y_1 - Y_2}{2h} $$

4.  **Z-Axis Gradient:**
    - Compute $Z_1$: Concatenate $V[:, :, 1:N_z]$ with extrapolated value at $N_z$ along the z-dimension.
    - Compute $Z_2$: Concatenate extrapolated value at $-1$ with $V[:, :, 0:N_z-1]$.
    - Calculate $G_z$:
      $$ G_z = \frac{Z_1 - Z_2}{2h} $$

**Pseudocode:**
```python
def compute_4th_order_gradient(grid, voxel_size):
    """
    Computes the gradient of a 3D grid using 4th-order finite differences.
    
    Args:
        grid: 3D numpy array of shape (Nx, Ny, Nz) containing SDF values.
        voxel_size: Float, physical size of a voxel.
        
    Returns:
        Tuple of 3D arrays (gx, gy, gz) representing the gradient components.
    """
    Nx, Ny, Nz = grid.shape
    
    # --- X-Axis Gradient ---
    # Extrapolate boundary values for x-axis
    # V[-1] = 3*V[0] - 3*V[1] + V[2]
    v_neg_1_x = 3 * grid[0, :, :] - 3 * grid[1, :, :] + grid[2, :, :]
    # V[Nx+1] = 3*V[Nx-1] - 3*V[Nx-2] + V[Nx-3]
    # Note: Indices in source are 0-based. Last index is Nx-1.
    # Source uses n_x = Nx-1. V_{n_x+1} = 3*V_{n_x} - 3*V_{n_x-1} + V_{n_x-2}
    v_pos_1_x = 3 * grid[Nx-1, :, :] - 3 * grid[Nx-2, :, :] + grid[Nx-3, :, :]
    
    # Construct X1: [V[1], ..., V[Nx-1], V[Nx+1]]
    # Source: grid[1:,:,:] is V[1] to V[Nx-1]
    # Then append V[Nx+1]
    X1_x = np.concatenate([grid[1:, :, :], v_pos_1_x[np.newaxis, :, :]], axis=0)
    
    # Construct X2: [V[-1], V[0], ..., V[Nx-2]]
    # Source: prepend V[-1], then grid[:Nx-1, :, :] is V[0] to V[Nx-2]
    X2_x = np.concatenate([v_neg_1_x[np.newaxis, :, :], grid[:Nx-1, :, :]], axis=0)
    
    gx = (X1_x - X2_x) / (2 * voxel_size)
    
    # --- Y-Axis Gradient ---
    # Extrapolate boundary values for y-axis
    v_neg_1_y = 3 * grid[:, 0, :] - 3 * grid[:, 1, :] + grid[:, 2, :]
    v_pos_1_y = 3 * grid[:, Ny-1, :] - 3 * grid[:, Ny-2, :] + grid[:, Ny-3, :]
    
    # Construct Y1: [V[:,1], ..., V[:,Ny-1], V[:,Ny+1]]
    Y1_y = np.concatenate([grid[:, 1:, :], v_pos_1_y[:, np.newaxis, :]], axis=1)
    
    # Construct Y2: [V[:,-1], V[:,0], ..., V[:,Ny-2]]
    Y2_y = np.concatenate([v_neg_1_y[:, np.newaxis, :], grid[:, :Ny-1, :]], axis=1)
    
    gy = (Y1_y - Y2_y) / (2 * voxel_size)
    
    # --- Z-Axis Gradient ---
    # Extrapolate boundary values for z-axis
    v_neg_1_z = 3 * grid[:, :, 0] - 3 * grid[:, :, 1] + grid[:, :, 2]
    v_pos_1_z = 3 * grid[:, :, Nz-1] - 3 * grid[:, :, Nz-2] + grid[:, :, Nz-3]
    
    # Construct Z1: [V[:,:,1], ..., V[:,:,Nz-1], V[:,:,Nz+1]]
    Z1_z = np.concatenate([grid[:, :, 1:], v_pos_1_z[:, :, np.newaxis]], axis=2)
    
    # Construct Z2: [V[:,:,-1], V[:,:,0], ..., V[:,:,Nz-2]]
    Z2_z = np.concatenate([v_neg_1_z[:, :, np.newaxis], grid[:, :, :Nz-1]], axis=2)
    
    gz = (Z1_z - Z2_z) / (2 * voxel_size)
    
    return (gx, gy, gz)
```

**Parameters:**
- `voxel_size`: The physical size of a single voxel in the grid. Used to normalize the finite difference result to physical units [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Grid Size:** The extrapolation formula requires at least 3 voxels in each dimension to access $V_{n-2}$ and $V_{n-3}$ (or equivalent indices). If the grid is smaller than 3 voxels in any dimension, the method fails.
- **Boundary Continuity:** The choice of extrapolation affects gradient continuity at edges. The 4th-order extrapolation ensures smoothness but assumes the SDF is well-behaved near the boundary [G].

## Operating characteristics
**Time and Memory Complexity:**
- Time: $O(N_x N_y N_z)$, as each voxel is processed a constant number of times.
- Memory: $O(N_x N_y N_z)$ for the input and output grids. Temporary arrays for extrapolated boundaries are negligible.

**Measured Performance:**
- Performance depends on the hardware and implementation. The method is vectorizable and efficient on GPUs.
- Scaling: Linear with respect to the number of voxels.

**Strengths and Limitations:**
- Strengths: High accuracy (4th-order) even at boundaries. Smooth normals improve ray marching stability and shading quality.
- Limitations: Requires a minimum grid size of 3 voxels per dimension. More complex to implement than 2nd-order central differences.

**When to Use:**
- Use when high-quality normals are required for SDF-based rendering or physics.
- Avoid when grid resolution is very low (<3 voxels) or when computational resources are extremely constrained and lower accuracy is acceptable.

## Background
The method originates from the SDFDiff project, which uses 4th-order finite differences to compute gradients of SDF grids for differentiable rendering [S1, unofficial]. It is used in computer graphics for generating smooth normals from voxelized SDF data.
