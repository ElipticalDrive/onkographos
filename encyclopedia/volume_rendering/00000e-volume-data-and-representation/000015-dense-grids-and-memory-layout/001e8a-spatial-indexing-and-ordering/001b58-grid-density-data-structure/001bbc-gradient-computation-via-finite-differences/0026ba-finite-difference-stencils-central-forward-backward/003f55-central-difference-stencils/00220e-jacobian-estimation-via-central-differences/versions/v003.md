# Jacobian Estimation via Central Differences

Also called: Central Difference Jacobian, Finite Difference Jacobian

## Overview
This method estimates the $3 \times 3$ Jacobian matrix of a vector-valued deformation field by computing central differences for each component of the field [S1, unofficial]. It differs from sibling methods like the Sobel Operator by providing a full matrix of partial derivatives rather than just gradient magnitudes or edge detection, and from 4th-order stencils by using a lower-accuracy, 2-sample-per-axis approach [S1, unofficial][1416-sobel-operator.md][4889-4th-order-finite-difference-gradient.md]. It is primarily used when the Jacobian is required for downstream operations such as ODE stepping or coordinate transformation [S1, unofficial].

## How it works
**Inputs:**
- A point $\mathbf{p} \in \mathbb{R}^3$ where the Jacobian is estimated.
- A deformation field function $f: \mathbb{R}^3 \to \mathbb{R}^3$, denoted as `simpleBrush` in the source [S1, unofficial].
- A step size parameter $\epsilon$ (EPSILON) [S1, unofficial].

**Outputs:**
- A $3 \times 3$ matrix $J$ where the columns are the partial derivatives of $f$ with respect to $x, y, z$ [S1, unofficial].

**Data Structures:**
- The matrix $J$ is stored as three column vectors $\mathbf{g}_x, \mathbf{g}_y, \mathbf{g}_z \in \mathbb{R}^3$ [S1, unofficial].

**Steps:**
1. Define the displacement vectors for each axis:
   $$ \mathbf{d}_x = (\epsilon, 0, 0) $$
   $$ \mathbf{d}_y = (0, \epsilon, 0) $$
   $$ \mathbf{d}_z = (0, 0, \epsilon) $$
2. Compute the partial derivative with respect to $x$ ($\mathbf{g}_x$) using central differences:
   $$ \mathbf{g}_x = \frac{f(\mathbf{p} + \mathbf{d}_x) - f(\mathbf{p} - \mathbf{d}_x)}{2\epsilon} $$
3. Compute the partial derivative with respect to $y$ ($\mathbf{g}_y$) using central differences:
   $$ \mathbf{g}_y = \frac{f(\mathbf{p} + \mathbf{d}_y) - f(\mathbf{p} - \mathbf{d}_y)}{2\epsilon} $$
4. Compute the partial derivative with respect to $z$ ($\mathbf{g}_z$) using central differences:
   $$ \mathbf{g}_z = \frac{f(\mathbf{p} + \mathbf{d}_z) - f(\mathbf{p} - \mathbf{d}_z)}{2\epsilon} $$
5. Construct the Jacobian matrix $J$ by setting its columns to $\mathbf{g}_x, \mathbf{g}_y, \mathbf{g}_z$:
   $$ J = \begin{bmatrix} | & | & | \\ \mathbf{g}_x & \mathbf{g}_y & \mathbf{g}_z \\ | & | & | \end{bmatrix} $$

**Parameters:**
- $\epsilon$: The step size for finite differences. The source uses a variable named `EPSILON` [S1, unofficial]. Typical values are not specified in the source.

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** If $\mathbf{p} \pm \mathbf{d}_i$ falls outside the domain of $f$, the evaluation fails. The source does not specify boundary handling [S1, unofficial].
- **Precision:** Small $\epsilon$ may lead to numerical instability due to floating-point cancellation; large $\epsilon$ increases truncation error. The source does not specify a recommended range [S1, unofficial].

**Pseudocode:**
```python
def estimate_jacobian_central(p: Vector3, f, epsilon: float) -> Matrix3:
    """
    Estimates the 3x3 Jacobian matrix of vector field f at point p using central differences.
    
    Args:
        p: Point in 3D space.
        f: Function mapping Vector3 to Vector3.
        epsilon: Step size for finite differences.
        
    Returns:
        3x3 Matrix where columns are partial derivatives.
    """
    # Define displacement vectors
    dx = Vector3(epsilon, 0.0, 0.0)
    dy = Vector3(0.0, epsilon, 0.0)
    dz = Vector3(0.0, 0.0, epsilon)
    
    # Compute partial derivatives (columns of the Jacobian)
    # g_x = (f(p + dx) - f(p - dx)) / (2 * epsilon)
    g_x = (f(p + dx) - f(p - dx)) / (2.0 * epsilon)
    
    # g_y = (f(p + dy) - f(p - dy)) / (2 * epsilon)
    g_y = (f(p + dy) - f(p - dy)) / (2.0 * epsilon)
    
    # g_z = (f(p + dz) - f(p - dz)) / (2 * epsilon)
    g_z = (f(p + dz) - f(p - dz)) / (2.0 * epsilon)
    
    # Construct matrix from columns
    J = Matrix3(g_x, g_y, g_z)
    
    return J
```

## Operating characteristics
- **Time Complexity:** Requires 6 evaluations of the deformation field $f$ per Jacobian estimate (2 per axis).
- **Memory Complexity:** $O(1)$ auxiliary memory for storing the 6 sample points and 3 gradient vectors.
- **Accuracy:** Second-order accurate ($O(\epsilon^2)$) for smooth fields [G].
- **Strengths:** Simple to implement; symmetric error distribution compared to forward/backward differences [G].
- **Limitations:** Requires 6 function evaluations; sensitive to the choice of $\epsilon$; not suitable for non-differentiable or noisy fields without smoothing [G].
- **When to use:** When a full Jacobian matrix is needed for coordinate transformations or ODE solvers and the field is smooth.
- **When not to use:** When memory bandwidth is extremely constrained (use forward differences) or when higher accuracy is required (use 4th-order stencils).

## Background
The method is implemented in the `ntsl-graphics` project by tink-expo, where it is used to estimate the Jacobian of a deformation field (`simpleBrush`) for graphics applications [S1, unofficial]. The technique is a standard application of finite difference methods in numerical analysis.
