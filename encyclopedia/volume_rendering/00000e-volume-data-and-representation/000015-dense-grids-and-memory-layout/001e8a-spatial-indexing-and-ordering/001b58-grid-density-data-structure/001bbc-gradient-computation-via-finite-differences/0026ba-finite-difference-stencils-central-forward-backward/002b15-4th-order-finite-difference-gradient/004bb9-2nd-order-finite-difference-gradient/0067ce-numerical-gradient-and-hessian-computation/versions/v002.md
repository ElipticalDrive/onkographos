# Numerical Gradient and Hessian Computation


## Overview
Computes the gradient (normal) and optionally the Hessian of a Signed Distance Function (SDF) field at specified query points using finite differences or automatic differentiation [S1, unofficial]. It differs from its parent [2nd-Order Finite Difference Gradient](13052-2nd-order-finite-difference-gradient.md) by supporting both numerical finite differences and automatic differentiation, and by providing the Hessian matrix in addition to the gradient [S1, unofficial].

## How it works
**Inputs:**
- `points`: Tensor of shape $(N, 3)$ containing $N$ query points [S1, unofficial].
- `get_sdf`: Function that evaluates the SDF at given points [S1, unofficial].
- `delta`: Step size for numerical differentiation [S1, unofficial].
- `_numerical_grad`: Boolean flag. `True` uses finite differences; `False` uses automatic differentiation [S1, unofficial].
- `_heissian`: Boolean flag. `True` computes and returns the Hessian matrix [S1, unofficial].

**Outputs:**
- `gradient`: Tensor of shape $(N, 3)$ containing the gradient vectors [S1, unofficial].
- `hessian`: Tensor of shape $(N, 3, 3)$ containing the Hessian matrices (only if `_heissian` is `True`) [S1, unofficial].

**Data Structures:**
- `offsets`: List of 6 offset vectors for central differences: `[(delta, 0, 0), (-delta, 0, 0), (0, delta, 0), (0, -delta, 0), (0, 0, delta), (0, 0, -delta)]` [S1, unofficial].
- `points_sdf`: Tensor of shape $(6, N, 1)$ storing SDF values at the 6 offset points [S1, unofficial].

**Steps:**

1. **Numerical Gradient Mode (`_numerical_grad` is `True`):**
   a. Define offset vectors: $\text{offsets} = \{ (\delta, 0, 0), (-\delta, 0, 0), (0, \delta, 0), (0, -\delta, 0), (0, 0, \delta), (0, 0, -\delta) \}$ [S1, unofficial].
   b. Compute SDF values at the 6 offset points for all $N$ query points: $\text{points\_sdf} = \text{get\_sdf}(\text{points} \oplus \text{offsets})$, where $\oplus$ denotes broadcasting addition, resulting in a tensor of shape $(6, N, 1)$ [S1, unofficial].
   c. Calculate the gradient using central differences: $\nabla f = 0.5 \cdot \frac{1}{\delta} \cdot \text{concat}(\text{points\_sdf}[0] - \text{points\_sdf}[1], \text{points\_sdf}[2] - \text{points\_sdf}[3], \text{points\_sdf}[4] - \text{points\_sdf}[5], \text{dim}=1)$ [S1, unofficial].
   d. If `_heissian` is `True`, calculate the Hessian using second-order central differences: $\text{hessian} = \text{hessian\_coef} \cdot (\text{concat}(\text{points\_sdf}[0] + \text{points\_sdf}[1], \text{points\_sdf}[2] + \text{points\_sdf}[3], \text{points\_sdf}[4] + \text{points\_sdf}[5], \text{dim}=1) - 2 \cdot \text{sdf\_center})$, where $\text{hessian\_coef} = \frac{1}{\delta^2}$ [S1, unofficial]. The source implementation computes only the diagonal elements of the Hessian in numerical mode [S1, unofficial]. [G] For a full Hessian, off-diagonal terms would require additional evaluations, but the source restricts numerical mode to the diagonal.

2. **Automatic Differentiation Mode (`_numerical_grad` is `False`):**
   a. Enable gradient computation mode and ensure the input points `_xyz` require gradients [S1, unofficial].
   b. Compute the SDF value: $s = \text{get\_sdf}(\text{points})$ [S1, unofficial].
   c. Compute the gradient using backpropagation: $\nabla f = \frac{\partial s}{\partial \text{points}}$ [S1, unofficial].
   d. If `_heissian` is `True`, compute the Hessian by differentiating the gradients: $H = \frac{\partial \nabla f}{\partial \text{points}}$ [S1, unofficial].

**Parameters:**
- `delta`: Step size for numerical differentiation. Typical value: Not given in the sources.
- `_numerical_grad`: Boolean flag. Default: Not given in the sources.
- `_heissian`: Boolean flag. Default: Not given in the sources.

**Edge Cases and Pitfalls:**
- **Precision:** Numerical differentiation is sensitive to the choice of `delta`. Too small a delta leads to cancellation errors; too large a delta leads to truncation errors [G].
- **Boundaries:** If query points are near the boundary of the SDF domain, offset points may fall outside. The `get_sdf` function must handle out-of-bounds queries (e.g., by clamping or returning a large value) [G].
- **Degenerate Input:** If `points` is empty, the output should be empty tensors of the correct shape [G].

**Pseudocode:**

```python
def compute_gradient_and_hessian(points, get_sdf, delta, numerical_grad=True, heissian=True):
    """
    Compute gradient and optionally Hessian of SDF at given points.
    
    Args:
        points: List of tuples (x, y, z) of length N
        get_sdf: Function that takes a list of points and returns a list of SDF values
        delta: Step size for numerical differentiation
        numerical_grad: Boolean, True for finite differences, False for autograd
        heissian: Boolean, True to compute Hessian
        
    Returns:
        gradient: List of tuples (gx, gy, gz) of length N
        hessian: List of 3x3 matrices of length N, or None
    """
    N = len(points)
    
    if numerical_grad:
        # Define offsets for central differences [S1, unofficial]
        offsets = [
            (delta, 0, 0), (-delta, 0, 0),
            (0, delta, 0), (0, -delta, 0),
            (0, 0, delta), (0, 0, -delta)
        ]
        
        # Compute SDF at offset points [S1, unofficial]
        points_sdf = []
        for offset in offsets:
            offset_points = [(p[0] + offset[0], p[1] + offset[1], p[2] + offset[2]) for p in points]
            points_sdf.append(get_sdf(offset_points))
            
        # Transpose to (6, N) layout [S1, unofficial]
        points_sdf = list(zip(*points_sdf))
        
        # Compute gradient using central differences [S1, unofficial]
        grad_x = [(points_sdf[0][i] - points_sdf[1][i]) / (2 * delta) for i in range(N)]
        grad_y = [(points_sdf[2][i] - points_sdf[3][i]) / (2 * delta) for i in range(N)]
        grad_z = [(points_sdf[4][i] - points_sdf[5][i]) / (2 * delta) for i in range(N)]
        gradient = list(zip(grad_x, grad_y, grad_z))
        
        hessian = None
        if heissian:
            # Compute Hessian diagonal elements using second-order central differences [S1, unofficial]
            sdf_center = get_sdf(points)
            hessian_coef = 1.0 / (delta * delta)
            
            h_xx = [(points_sdf[0][i] + points_sdf[1][i] - 2 * sdf_center[i]) * hessian_coef for i in range(N)]
            h_yy = [(points_sdf[2][i] + points_sdf[3][i] - 2 * sdf_center[i]) * hessian_coef for i in range(N)]
            h_zz = [(points_sdf[4][i] + points_sdf[5][i] - 2 * sdf_center[i]) * hessian_coef for i in range(N)]
            
            # Construct diagonal Hessian matrices [S1, unofficial]
            hessian = [[h_xx[i], 0.0, 0.0], [0.0, h_yy[i], 0.0], [0.0, 0.0, h_zz[i]] for i in range(N)]
            
    else:
        # Automatic differentiation mode [S1, unofficial]
        # The source uses an external AD engine (e.g., PyTorch).
        # Pure Python cannot natively perform reverse-mode autodiff.
        # Implementation requires an external framework:
        #   points.requires_grad = True
        #   sdf = get_sdf(points)
        #   gradients = torch.autograd.grad(sdf, points, grad_outputs=torch.ones_like(sdf), create_graph=True, retain_graph=True)[0]
        #   if heissian:
        #       hessian = torch.autograd.grad(gradients, points, grad_outputs=torch.ones_like(gradients), create_graph=True, retain_graph=True)[0]
        raise NotImplementedError("Automatic differentiation requires an external AD framework.")
        
    return gradient, hessian
```

## Operating characteristics
- **Time Complexity:** $O(N)$ SDF evaluations for numerical mode (6 per point for the gradient, plus 1 center evaluation for the Hessian diagonal) [S1, unofficial]. Autograd mode requires 1 SDF evaluation for the gradient and additional passes for the Hessian [S1, unofficial].
- **Memory Complexity:** $O(N)$ for storing SDF values and gradients [G].
- **Strengths:** Numerical mode is simple to implement and does not require the SDF function to be differentiable [G]. Autograd mode provides exact gradients (up to machine precision) and can compute the Hessian efficiently [S1, unofficial].
- **Limitations:** Numerical mode is sensitive to the choice of `delta` [G]. Autograd mode requires the SDF function to be implemented using a framework that supports automatic differentiation [G]. Computing the Hessian via autograd can be memory-intensive for large $N$ [G].
