# Gauss-Seidel with Successive Over-Relaxation (SOR)
Also called: Gauss-Seidel SOR, Gauss-Seidel with Successive Over-Relaxation (SOR) for 3D Heat Conduction, Iterative Laplace Solver

## Overview
Gauss-Seidel with Successive Over-Relaxation (SOR) is an iterative numerical method used to solve the steady-state heat equation (Laplace equation $\nabla^2 T = 0$) on a 3D grid [S1, unofficial]. It solves for the scalar field values at interior grid points by iteratively averaging neighbor values, accelerated by an over-relaxation parameter $\omega$ [S1, unofficial]. Unlike direct solvers or Jacobi iteration, it updates the grid in-place using the most recently computed values and converges faster by extrapolating the update step [S1, unofficial]. It is distinct from standard finite difference gradient estimation (e.g., [Central Differences](3858-finite-difference-stencils-central-forward-backward.md)) because it does not compute a gradient directly but rather finds the equilibrium scalar field that satisfies the Laplace constraint, which may be used as a pre-processing step for smoothing or boundary condition enforcement in volume rendering pipelines.

## How it works
**Inputs and Outputs:**
- **Input:** A 3D scalar field (temperature) $T$ of shape $(n_x, n_y, n_z)$, boundary conditions (Dirichlet and Neumann), the SOR relaxation parameter $\omega$, convergence tolerance $\epsilon$, and maximum iterations $N_{max}$.
- **Output:** The converged 3D scalar field $T$ satisfying the Laplace equation in the interior and boundary conditions.

**Data Structures:**
- **Temperature Field:** A 3D array of shape $(n_x, n_y, n_z)$ with floating-point dtype. Indices $(i, j, k)$ correspond to grid points in $x, y, z$ directions respectively [S1, unofficial].

**Parameters:**
- $\omega$: SOR relaxation parameter. Typical value is 1.5, with an optimal range of $1 < \omega < 2$ (specifically ~1.5–1.9) [S1, unofficial].
- $\epsilon$: Convergence tolerance based on max residual. Typical value is $10^{-5}$ [S1, unofficial].
- $N_{max}$: Maximum iterations. Typical value is 5000 [S1, unofficial].

**Steps:**
1. **Initialization:** Initialize the temperature field $T$ with a linear interpolation between the hot and cold boundaries to reduce iteration count [S1, unofficial].
   $$ T[i, j, k] = T_{hot} + (T_{cold} - T_{hot}) \cdot \frac{k}{n_z - 1} $$
2. **Boundary Conditions:** Apply Dirichlet conditions to the top and bottom faces ($k=0$ and $k=n_z-1$) and Neumann (adiabatic, zero-gradient) conditions to the side walls ($i=0, i=n_x-1, j=0, j=n_y-1$) [S1, unofficial].
   - Dirichlet: $T[i, j, 0] = T_{hot}$, $T[i, j, n_z-1] = T_{cold}$.
   - Neumann: Copy values from adjacent interior cells (e.g., $T[0, j, k] = T[1, j, k]$) [S1, unofficial].
3. **Iteration Loop:** For each iteration from 1 to $N_{max}$:
   a. Initialize `max_residual` to 0.
   b. Loop over interior points $i \in [1, n_x-2]$, $j \in [1, n_y-2]$, $k \in [1, n_z-2]$:
      i. Calculate the sum of the six immediate neighbors:
         $$ S = T[i+1, j, k] + T[i-1, j, k] + T[i, j+1, k] + T[i, j-1, k] + T[i, j, k+1] + T[i, j, k-1] $$
      ii. Calculate the tentative new value from the Laplace equation (average of neighbors):
         $$ T_{new} = \frac{S}{6} $$
      iii. Calculate the residual for this point:
         $$ r = |T_{new} - T[i, j, k]| $$
      iv. Update `max_residual`:
         $$ \text{max\_residual} = \max(\text{max\_residual}, r) $$
      v. Apply the SOR update:
         $$ T[i, j, k] = (1 - \omega) T[i, j, k] + \omega T_{new} $$
   c. Re-apply boundary conditions to ensure Dirichlet values remain fixed and Neumann conditions are maintained [S1, unofficial].
   d. Check convergence: If `max_residual` < $\epsilon$, terminate and return the current iteration count.
4. **Termination:** If $N_{max}$ is reached without convergence, return the current field and iteration count.

**Pseudocode:**
```python
def solve_sor(nx, ny, nz, t_hot, t_cold, omega, max_iterations, tolerance):
    # Initialize temperature field with linear profile
    temperature = np.zeros((nx, ny, nz))
    for k in range(nz):
        z_ratio = k / (nz - 1)
        temperature[:, :, k] = t_hot + (t_cold - t_hot) * z_ratio

    def apply_boundary_conditions():
        # Dirichlet: fixed temperature on top and bottom
        temperature[:, :, 0] = t_hot
        temperature[:, :, -1] = t_cold
        # Neumann: zero gradient on side walls (adiabatic)
        temperature[0, :, :] = temperature[1, :, :]
        temperature[-1, :, :] = temperature[-2, :, :]
        temperature[:, 0, :] = temperature[:, 1, :]
        temperature[:, -1, :] = temperature[:, -2, :]

    apply_boundary_conditions()

    for iteration in range(1, max_iterations + 1):
        max_residual = 0.0
        for i in range(1, nx - 1):
            for j in range(1, ny - 1):
                for k in range(1, nz - 1):
                    neighbor_sum = (
                        temperature[i + 1, j, k] +
                        temperature[i - 1, j, k] +
                        temperature[i, j + 1, k] +
                        temperature[i, j - 1, k] +
                        temperature[i, j, k + 1] +
                        temperature[i, j, k - 1]
                    )
                    t_new = neighbor_sum / 6.0
                    residual = abs(t_new - temperature[i, j, k])
                    if residual > max_residual:
                        max_residual = residual
                    temperature[i, j, k] = (1 - omega) * temperature[i, j, k] + omega * t_new
        
        apply_boundary_conditions()
        
        if max_residual < tolerance:
            return iteration, temperature
            
    return max_iterations, temperature
```

## Operating characteristics
- **Time Complexity:** $O(N \cdot I)$, where $N = n_x n_y n_z$ is the number of grid points and $I$ is the number of iterations to convergence. Convergence speed depends heavily on $\omega$ and grid size.
- **Memory Complexity:** $O(N)$ for storing the 3D temperature field.
- **Performance:** Convergence is faster than Jacobi iteration due to in-place updates and Gauss-Seidel ordering. SOR further accelerates convergence compared to standard Gauss-Seidel when $\omega$ is near optimal [S1, unofficial].
- **Strengths:** Simple to implement, low memory overhead, effective for smooth scalar fields satisfying Laplace equations.
- **Limitations:** Convergence slows significantly for large grids or poor $\omega$ choices. Not suitable for non-linear problems or problems with complex boundary conditions that cannot be easily enforced via copying [S1, unofficial].
- **When to use:** When solving for equilibrium scalar fields (e.g., temperature, pressure) on regular grids with simple boundary conditions.
- **When not to use:** For gradient estimation where direct finite differences are sufficient, or for non-linear PDEs.

## Background
The method originates from numerical analysis for solving partial differential equations, specifically the steady-state heat equation (Laplace equation) [S1, unofficial]. It combines the Gauss-Seidel iterative method, which uses updated values immediately, with Successive Over-Relaxation (SOR), a technique to accelerate convergence by over-correcting the update step [S1, unofficial]. In the context of volume rendering, it is used to solve for temperature distributions that can then be visualized using transfer functions mapping temperature to color and opacity [S1, unofficial].
