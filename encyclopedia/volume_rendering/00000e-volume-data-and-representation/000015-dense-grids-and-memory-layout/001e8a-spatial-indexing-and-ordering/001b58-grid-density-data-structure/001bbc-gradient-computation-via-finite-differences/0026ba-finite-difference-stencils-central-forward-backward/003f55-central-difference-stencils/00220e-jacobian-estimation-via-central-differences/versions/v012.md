# Jacobian Estimation via Central Differences

Also called: Central Difference Jacobian, Finite Difference Jacobian

## Overview
This method estimates the 3x3 Jacobian matrix of a vector field or deformation map by computing central finite differences of the field's components. It builds on [Central Difference Stencils](9968-central-difference-stencils.md) to provide the local linear transformation required for coordinate mapping, ray marching, or flow analysis. Unlike forward or backward differences, the central difference approach is second-order accurate, offering higher precision for smooth fields at the cost of requiring samples from both sides of the evaluation point.

## How it works
**Inputs and Outputs:**
- Input: A vector-valued function $\mathbf{F}(\mathbf{p})$ (or scalar field $V(\mathbf{p})$ if estimating gradient as a column), a query position $\mathbf{p} \in \mathbb{R}^3$, and a step size $\epsilon$.
- Output: A 3x3 Jacobian matrix $\mathbf{J} \in \mathbb{R}^{3 \times 3}$.

**Data Structures:**
- The Jacobian is stored as a 3x3 matrix. In column-major layout (common in graphics APIs like OpenGL), the columns correspond to the partial derivatives with respect to $x$, $y$, and $z$.
- $\mathbf{J} = [\frac{\partial \mathbf{F}}{\partial x} | \frac{\partial \mathbf{F}}{\partial y} | \frac{\partial \mathbf{F}}{\partial z}]$.

**Steps:**
1. Define the perturbation vectors for each axis:
   $$ \mathbf{d}_x = (\epsilon, 0, 0) $$
   $$ \mathbf{d}_y = (0, \epsilon, 0) $$
   $$ \mathbf{d}_z = (0, 0, \epsilon) $$
2. Evaluate the field at the perturbed positions:
   $$ \mathbf{F}_+^x = \mathbf{F}(\mathbf{p} + \mathbf{d}_x) $$
   $$ \mathbf{F}_-^x = \mathbf{F}(\mathbf{p} - \mathbf{d}_x) $$
   $$ \mathbf{F}_+^y = \mathbf{F}(\mathbf{p} + \mathbf{d}_y) $$
   $$ \mathbf{F}_-^y = \mathbf{F}(\mathbf{p} - \mathbf{d}_y) $$
   $$ \mathbf{F}_+^z = \mathbf{F}(\mathbf{p} + \mathbf{d}_z) $$
   $$ \mathbf{F}_-^z = \mathbf{F}(\mathbf{p} - \mathbf{d}_z) $$
3. Compute the central difference approximations for the partial derivatives (columns of the Jacobian):
   $$ \mathbf{c}_x = \frac{\mathbf{F}_+^x - \mathbf{F}_-^x}{2\epsilon} $$
   $$ \mathbf{c}_y = \frac{\mathbf{F}_+^y - \mathbf{F}_-^y}{2\epsilon} $$
   $$ \mathbf{c}_z = \frac{\mathbf{F}_+^z - \mathbf{F}_-^z}{2\epsilon} $$
4. Construct the Jacobian matrix $\mathbf{J}$ using $\mathbf{c}_x, \mathbf{c}_y, \mathbf{c}_z$ as columns.

**Parameters:**
- $\epsilon$ (EPSILON): The step size for finite differences. Typical values depend on the scale of the field and floating-point precision. If the field is defined on a grid with spacing $h$, $\epsilon$ is often set to $h$ or a small multiple thereof. [S1, unofficial]

**Pseudocode:**
```python
def estimate_jacobian_central(F, p, epsilon):
    """
    Estimate the 3x3 Jacobian matrix of vector field F at position p.
    
    Args:
        F: Function that takes a 3D vector and returns a 3D vector.
        p: 3D vector (x, y, z) where the Jacobian is evaluated.
        epsilon: Step size for finite differences.
        
    Returns:
        J: 3x3 matrix (list of lists or array) representing the Jacobian.
           Columns are dF/dx, dF/dy, dF/dz.
    """
    # Define perturbation vectors
    dx = (epsilon, 0.0, 0.0)
    dy = (0.0, epsilon, 0.0)
    dz = (0.0, 0.0, epsilon)
    
    # Evaluate field at perturbed positions
    F_p_plus_x = F((p[0] + dx[0], p[1] + dx[1], p[2] + dx[2]))
    F_p_minus_x = F((p[0] - dx[0], p[1] - dx[1], p[2] - dx[2]))
    
    F_p_plus_y = F((p[0] + dy[0], p[1] + dy[1], p[2] + dy[2]))
    F_p_minus_y = F((p[0] - dy[0], p[1] - dy[1], p[2] - dy[2]))
    
    F_p_plus_z = F((p[0] + dz[0], p[1] + dz[1], p[2] + dz[2]))
    F_p_minus_z = F((p[0] - dz[0], p[1] - dz[1], p[2] - dz[2]))
    
    # Compute central differences for each column
    # Column 0: dF/dx
    col_x = (
        (F_p_plus_x[0] - F_p_minus_x[0]) / (2.0 * epsilon),
        (F_p_plus_x[1] - F_p_minus_x[1]) / (2.0 * epsilon),
        (F_p_plus_x[2] - F_p_minus_x[2]) / (2.0 * epsilon)
    )
    
    # Column 1: dF/dy
    col_y = (
        (F_p_plus_y[0] - F_p_minus_y[0]) / (2.0 * epsilon),
        (F_p_plus_y[1] - F_p_minus_y[1]) / (2.0 * epsilon),
        (F_p_plus_y[2] - F_p_minus_y[2]) / (2.0 * epsilon)
    )
    
    # Column 2: dF/dz
    col_z = (
        (F_p_plus_z[0] - F_p_minus_z[0]) / (2.0 * epsilon),
        (F_p_plus_z[1] - F_p_minus_z[1]) / (2.0 * epsilon),
        (F_p_plus_z[2] - F_p_minus_z[2]) / (2.0 * epsilon)
    )
    
    # Construct Jacobian matrix (column-major)
    J = [col_x, col_y, col_z]
    
    return J
```

**Edge Cases and Pitfalls:**
- **Boundary Handling:** If $\mathbf{p} \pm \mathbf{d}_i$ lies outside the domain of $\mathbf{F}$, values must be obtained via clamping, zero-padding, or extrapolation [G]. Failure to handle boundaries leads to incorrect derivatives at the edges of the volume.
- **Step Size Selection:** If $\epsilon$ is too small, numerical noise (floating-point precision errors) dominates the difference. If $\epsilon$ is too large, the approximation deviates from the true derivative due to non-linearity. [S1, unofficial]

## Subtopics

### [Jacobian Normalization for ODE Step](2946-jacobian-normalization-for-ode-step.md)
This method computes the normalized direction vector for an Ordinary Differential Equation (ODE) solver by applying the inverse of an estimated Jacobian matrix to a base direction vector. It differs from raw Jacobian estimation by performing the matrix inversion and vector normalization required for stable stepping [G].

### [Flow Jacobian Decomposition](10525-flow-jacobian-decomposition.md)
Flow Jacobian Decomposition splits the 3x3 Jacobian matrix of a displacement field into symmetric and antisymmetric parts to isolate local geometric deformation (strain) from rigid-body rotation. It distinguishes itself from sibling methods like [Jacobian Normalization for ODE Step](2946-jacobian-normalization-for-ode-step.md) by focusing on physical interpretation of flow kinematics rather than numerical stability for integration.

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation, requiring 6 field evaluations (2 per axis) and constant arithmetic operations.
- **Memory Complexity:** $O(1)$ auxiliary memory.
- **Accuracy:** Second-order accurate ($O(\epsilon^2)$ error), making it more accurate than forward/backward differences for the same step size.
- **Strengths:** Simple to implement, symmetric error distribution, widely applicable to any differentiable field.
- **Limitations:** Requires field evaluations on both sides of the point, which can be problematic near boundaries or discontinuities. Sensitive to the choice of $\epsilon$.

## Background
The method originates from standard numerical analysis techniques for approximating derivatives. In the context of volume rendering and graphics, it is used for tasks such as ray marching in deformed spaces, flow visualization, and texture coordinate mapping. The specific implementation using a `simpleBrush` function and `EPSILON` parameter is documented in the `ntsl-graphics` repository [S1, unofficial]. It is also referenced in literature on interactive volume rendering with sliding interfaces, where it is used to approximate the Jacobian of the transformation between computational and physical space [S2, unofficial].
