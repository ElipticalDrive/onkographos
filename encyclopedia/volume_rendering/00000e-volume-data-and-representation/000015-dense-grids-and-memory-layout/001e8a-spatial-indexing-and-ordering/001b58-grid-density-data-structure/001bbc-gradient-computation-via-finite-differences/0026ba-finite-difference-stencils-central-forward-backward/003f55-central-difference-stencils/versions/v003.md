# Central Difference Stencils

Also called: Central Finite Differences, Symmetric Differences

## Overview
Central Difference Stencils compute the gradient vector $\nabla V = (G_x, G_y, G_z)$ at a voxel center $\mathbf{p}$ by evaluating the scalar field $V$ at two neighbors along each axis, symmetrically displaced by $\pm h$. This method is distinguished from its siblings, [Forward Difference Gradient](3362-forward-difference-gradient.md) and [Backward Difference Gradient](3362-forward-difference-gradient.md), by its second-order accuracy ($O(h^2)$ truncation error) and symmetry, which reduces directional bias at the cost of requiring two samples per axis instead of one. It serves as the foundational mechanism for [Jacobian Estimation via Central Differences](2650-jacobian-estimation-via-central-differences.md) and is used in [Clamped Central Differences](#clamped-central-differences) for efficient AMR gradient estimation.

## Shared principles
The method computes the partial derivative along axis $i$ ($x, y, z$) using the standard central difference formula. For a voxel at integer coordinates $\mathbf{p} = (x, y, z)$ with isotropic voxel spacing $h$:

$$ G_i = \frac{V(\mathbf{p} + h \mathbf{e}_i) - V(\mathbf{p} - h \mathbf{e}_i)}{2h} $$

where $\mathbf{e}_i$ is the unit vector for axis $i$. The stencil offsets are $\delta_{+} = +1$ and $\delta_{-} = -1$ in index space. The weights are $w_{+} = 1$ and $w_{-} = -1$. The normalization factor is $1/(2h)$. Boundary handling is critical; if $\mathbf{p} \pm h \mathbf{e}_i$ lies outside the volume domain, values must be obtained via clamping, zero-padding, or extrapolation [G].

## Subtopics

### [Jacobian Estimation via Central Differences](2650-jacobian-estimation-via-central-differences.md)
This method extends the scalar central difference stencil to vector-valued deformation fields $\mathbf{u}(\mathbf{x})$. It computes the 3x3 Jacobian matrix $\mathbf{J}$ by applying the central difference formula to each component of $\mathbf{u}$ along each axis. It differs from the parent [Central Difference Stencils](9968-central-difference-stencils.md) by operating on a vector field to produce a matrix rather than a scalar field to produce a vector, and from [Jacobian Normalization for ODE Step](2946-jacobian-normalization-for-ode-step.md) by providing the raw matrix without subsequent inversion or normalization [G].

**Pseudocode:**
```python
def estimate_jacobian_central_difference(u_func, pos, epsilon):
    # Define perturbation vectors
    dx = (epsilon, 0.0, 0.0)
    dy = (0.0, epsilon, 0.0)
    dz = (0.0, 0.0, epsilon)
    
    # Evaluate field at perturbed positions
    u_plus_x = u_func((pos[0] + dx[0], pos[1] + dx[1], pos[2] + dx[2]))
    u_minus_x = u_func((pos[0] - dx[0], pos[1] - dx[1], pos[2] - dx[2]))
    
    u_plus_y = u_func((pos[0] + dy[0], pos[1] + dy[1], pos[2] + dy[2]))
    u_minus_y = u_func((pos[0] - dy[0], pos[1] - dy[1], pos[2] - dy[2]))
    
    u_plus_z = u_func((pos[0] + dz[0], pos[1] + dz[1], pos[2] + dz[2]))
    u_minus_z = u_func((pos[0] - dz[0], pos[1] - dy[1], pos[2] - dz[2]))
    
    # Compute partial derivatives (columns of the Jacobian)
    j_x = [
        (u_plus_x[0] - u_minus_x[0]) / (2.0 * epsilon),
        (u_plus_x[1] - u_minus_x[1]) / (2.0 * epsilon),
        (u_plus_x[2] - u_minus_x[2]) / (2.0 * epsilon)
    ]
    
    j_y = [
        (u_plus_y[0] - u_minus_y[0]) / (2.0 * epsilon),
        (u_plus_y[1] - u_minus_y[1]) / (2.0 * epsilon),
        (u_plus_y[2] - u_minus_y[2]) / (2.0 * epsilon)
    ]
    
    j_z = [
        (u_plus_z[0] - u_minus_z[0]) / (2.0 * epsilon),
        (u_plus_z[1] - u_minus_z[1]) / (2.0 * epsilon),
        (u_plus_z[2] - u_minus_z[2]) / (2.0 * epsilon)
    ]
    
    # Construct Jacobian matrix (columns are j_x, j_y, j_z)
    jacobian = [
        [j_x[0], j_y[0], j_z[0]],
        [j_x[1], j_y[1], j_z[1]],
        [j_x[2], j_y[2], j_z[2]]
    ]
    
    return jacobian
```

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** If $\mathbf{x} \pm \mathbf{d}_i$ falls outside the domain of the field $\mathbf{u}$, the value must be determined via clamping, zero-padding, or extrapolation [G]. This affects the accuracy of the Jacobian at the volume boundaries [G].
- **Step Size Selection:** If $\epsilon$ is too large, the approximation error (truncation error) increases. If $\epsilon$ is too small, numerical noise (round-off error) dominates [G].
- **Singularity:** If the deformation field is not differentiable at $\mathbf{x}$, the Jacobian may not exist or may be ill-conditioned [G].

### Clamped Central Differences
- **Definition:** A variant of central differencing for gradient computation that clamps offset positions to the current region to avoid additional ray traversals [S1].
- **Step:** Compute six additional basis reconstruction samples at positions offset from the current sample by a distance proportional to the region's sample rate. Clamp the offset positions to the current region before evaluating them [S1].
- **Pitfall:** Gradients are not necessarily continuous at level boundaries because the offset size can change [S1].
- **Comparison:** Accurate central differencing requires tracing 6 additional rays per sample via infinitesimal rays to find containing regions, which is expensive. Clamped version removes ray traversals but reduces quality [S1].

### Curl Grid Computation
- **Definition:** Computes the curl $\nabla \times \mathbf{F}$ at every active voxel of a vector grid using central differences [S2, unofficial].
- **Step:** Initialize a `GradStencil` with the grid tree. Iterate over all active voxels $(c, \_)$ in the grid tree. Move the stencil to the current coordinate $c$. Compute the $x, y,$ and $z$ components of the curl using the formulas and store the tuple $(c_x, c_y, c_z)$ in a dictionary keyed by coordinate. Build the result grid using the computed data, a background value of zero vector $(0,0,0)$, and the original grid's voxel size [S2, unofficial].
- **Formula:**
  $$ c_x = (v[4][3] - v[5][3] - v[6][2] + v[7][2]) \times 0.5 $$
  $$ c_y = (v[6][1] - v[7][1] - v[2][3] + v[3][3]) \times 0.5 $$
  $$ c_z = (v[2][2] - v[3][2] - v[4][1] + v[5][1]) \times 0.5 $$
- **Parameter:** `half`: The scalar multiplier 0.5, representing $1/(2 \times \text{voxel\_size})$ in index space [S2, unofficial].

### Hessian-Vector Product via Central Differences
- **Definition:** An approximation of the Hessian-vector product $H(\theta)v$ that avoids computing the full Hessian matrix [S3]. It estimates the directional gradient of the gradient, resulting in an $n$-dimensional vector [S3].
- **Step:** Evaluate the first-order gradient estimator at positions shifted from the current solution along the direction $v$ by $\pm \epsilon$ [S3].
- **Formula:**
  $$ H(\theta)v \approx \lim_{\epsilon \to 0} \frac{g(\theta + \epsilon v) - g(\theta - \epsilon v)}{2\epsilon} $$
  The smooth HVP kernel is estimated using directional central differences of the gradient estimator:
  $$ D_{HVP} \kappa(\tau) = \frac{D_G \kappa(\tau - \epsilon v) - D_G \kappa(\tau + \epsilon v)}{2\epsilon} $$
- **Complexity:** Time complexity: $O(n)$ function evaluations without IS, $O(n)$ with IS, $O(1)$ with Aggregate IS. Space complexity for Aggregate IS is $O(n)$ [S3].

## Background
Central differences are a standard numerical analysis technique for approximating derivatives. In the context of volume rendering and structured AMR data, they are used to compute gradient vectors as stand-ins for nonexistent surface normals [S1]. The accurate implementation requires tracing infinitesimal rays to find containing regions for offset samples, incurring significant cost [S1]. Variants like clamped central differences were introduced to improve performance by removing ray traversals at the cost of quality [S1]. The method is also foundational in differentiable rendering for estimating Jacobians and Hessian-vector products for optimization tasks [S3].
