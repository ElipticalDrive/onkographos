# Jacobian Estimation via Central Differences
Also called: Central Difference Jacobian, Finite Difference Jacobian
## Overview
Estimates the 3x3 Jacobian matrix of a deformation field by computing central differences of the underlying displacement function [S1, unofficial]. It differs from [Gradient Computation via Finite Differences](1077-gradient-computation-via-finite-differences.md) by returning the full matrix of partial derivatives rather than a single gradient vector, and from [Sobel Operator](1416-sobel-operator.md) by using isotropic central differences on the raw function rather than convolution kernels on sampled data.
## How it works
**Inputs and outputs:**
- Input: A position vector $pos$ and a force/deformation parameter $force$ passed to the deformation function `simpleBrush`.
- Output: A 3x3 matrix $J$ where columns are the partial derivatives with respect to $x, y, z$.

**Data structures:**
- `mat3`: A 3x3 matrix stored as three column vectors `grad_x`, `grad_y`, `grad_z`.
- `vec3`: 3D vectors for positions and differences.

**Parameters:**
- `EPSILON`: The step size for finite differences. Not given in the sources.

**Steps:**
1. Define the difference vectors along each axis:
   $$diff\_x = (\epsilon, 0, 0)$$
   $$diff\_y = (0, \epsilon, 0)$$
   $$diff\_z = (0, 0, \epsilon)$$
2. Compute the partial derivative with respect to $x$ by evaluating the deformation function at $pos + diff\_x$ and $pos - diff\_x$:
   $$grad\_x = \frac{simpleBrush(pos + diff\_x, force) - simpleBrush(pos - diff\_x, force)}{2 \cdot \epsilon}$$
3. Compute the partial derivative with respect to $y$:
   $$grad\_y = \frac{simpleBrush(pos + diff\_y, force) - simpleBrush(pos - diff\_y, force)}{2 \cdot \epsilon}$$
4. Compute the partial derivative with respect to $z$:
   $$grad\_z = \frac{simpleBrush(pos + diff\_z, force) - simpleBrush(pos - diff\_z, force)}{2 \cdot \epsilon}$$
5. Construct and return the Jacobian matrix $J$ using these vectors as columns:
   $$J = \begin{bmatrix} | & | & | \\ grad\_x & grad\_y & grad\_z \\ | & | & | \end{bmatrix}$$

**Pseudocode:**
```python
def estimate_jacobian(pos, force, epsilon):
    # Define difference vectors
    diff_x = vec3(epsilon, 0.0, 0.0)
    diff_y = vec3(0.0, epsilon, 0.0)
    diff_z = vec3(0.0, 0.0, epsilon)

    # Evaluate deformation function at perturbed positions
    # simpleBrush is assumed to return a vec3 displacement
    pos_plus_x = pos + diff_x
    pos_minus_x = pos - diff_x
    pos_plus_y = pos + diff_y
    pos_minus_y = pos - diff_y
    pos_plus_z = pos + diff_z
    pos_minus_z = pos - diff_z

    disp_plus_x = simpleBrush(pos_plus_x, force)
    disp_minus_x = simpleBrush(pos_minus_x, force)
    disp_plus_y = simpleBrush(pos_plus_y, force)
    disp_minus_y = simpleBrush(pos_minus_y, force)
    disp_plus_z = simpleBrush(pos_plus_z, force)
    disp_minus_z = simpleBrush(pos_minus_z, force)

    # Compute central differences
    grad_x = (disp_plus_x - disp_minus_x) / (2.0 * epsilon)
    grad_y = (disp_plus_y - disp_minus_y) / (2.0 * epsilon)
    grad_z = (disp_plus_z - disp_minus_z) / (2.0 * epsilon)

    # Construct matrix from columns
    # Assuming mat3 takes column vectors or a list of columns
    jacobian = mat3(grad_x, grad_y, grad_z)
    return jacobian
```

**Edge cases and pitfalls:**
- If `EPSILON` is too small, numerical precision errors may dominate the subtraction.
- If `EPSILON` is too large, the approximation deviates from the true derivative due to non-linearity.
- Boundary conditions for `simpleBrush` must handle positions outside the valid domain.

## Subtopics

### Jacobian Normalization for ODE Step
Evaluates the derivative for an ODE solver by normalizing the result of multiplying the inverse Jacobian by a direction vector $w$ [S1, unofficial]. It is chosen when a normalized direction is required for integration steps. The formula is:
$$ \text{result} = \text{normalize}(\text{inverse}(J) \cdot w) $$
where $J$ is the Jacobian estimated by the parent method.

## Operating characteristics
- **Time complexity:** $O(1)$ per evaluation, requiring 6 calls to `simpleBrush`.
- **Memory complexity:** $O(1)$, storing only temporary vectors and the resulting matrix.
- **Strengths:** Simple to implement; isotropic accuracy for small steps.
- **Limitations:** Requires the deformation function to be differentiable; sensitive to step size choice.
- **When to use:** When the full deformation gradient is needed for physics or ray marching adjustments.
- **When not to use:** When the function is not smooth or when performance is critical and approximate gradients suffice.

## Background
Originated in the context of real-time graphics deformation, specifically within the `ntsl-graphics` project [S1, unofficial]. It is used to compute local deformation properties for interactive applications.
