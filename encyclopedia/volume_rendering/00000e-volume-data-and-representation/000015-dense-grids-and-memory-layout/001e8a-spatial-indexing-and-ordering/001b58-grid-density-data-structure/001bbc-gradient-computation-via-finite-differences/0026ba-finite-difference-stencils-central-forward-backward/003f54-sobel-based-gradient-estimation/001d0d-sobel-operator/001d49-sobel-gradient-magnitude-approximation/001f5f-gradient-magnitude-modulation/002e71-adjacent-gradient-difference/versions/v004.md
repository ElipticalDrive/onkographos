# Adjacent Gradient Difference

Also called: Gradient Magnitude Increase Measure

## Overview
Adjacent Gradient Difference is a volume rendering modulation technique that calculates an importance difference by comparing the gradient magnitudes of two adjacent samples along a viewing ray [S1]. It increases accumulated transparency whenever an increase in gradient magnitude is detected, distinguishing it from methods that rely on absolute gradient magnitude or scalar intensity changes [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The gradient magnitude of the current sample, $\text{grad}_i$, and the gradient magnitude of the previous sample along the ray, $\text{grad}_{i-1}$ [S1].
*   **Output:** A modulation factor $\beta$ used to adjust accumulated transparency [S1].

**Data structures:** Not given in the sources.

**Steps:**
1.  Retrieve $\text{grad}_i$ and $\text{grad}_{i-1}$ during ray marching [S1].
2.  Compare $\text{grad}_i$ and $\text{grad}_{i-1}$ [S1].
3.  Compute $\beta$ using the piecewise function below [S1].

**Formula:**
The modulation factor $\beta$ is calculated as [S1]:

$$
\beta = B(\Delta_{imp}(\text{grad}_i, \text{grad}_{i-1})) = 
\begin{cases} 
1 - (\text{grad}_i - \text{grad}_{i-1}) & \text{if } \text{grad}_i > \text{grad}_{i-1} \\
1 & \text{otherwise}
\end{cases}
$$

Where:
*   $\text{grad}_i$ is the current sample's gradient magnitude [S1].
*   $\text{grad}_{i-1}$ is the previous sample's gradient magnitude [S1].
*   The term $(\text{grad}_i - \text{grad}_{i-1})$ represents the increase in gradient magnitude [S1].

**Parameters:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Dynamic Range:** The method tends to produce a wider dynamic range output, particularly if the dataset contains many non-transparent voxels [S1]. Tone-mapping (e.g., brightness/contrast and gamma curve) is required to map the high dynamic range output to the normal display range [S1].
*   **Transparency:** Because more samples along the viewing ray contribute to the final result, the rendered image has a more transparent look compared to maximum gradient magnitude measures [S1].

**Pseudocode:**
```python
def adjacent_gradient_difference(grad_i, grad_prev):
    """Calculate the modulation factor beta based on adjacent gradient magnitudes."""
    if grad_i > grad_prev:
        beta = 1.0 - (grad_i - grad_prev)
        # [G] Clamp to [0, 1] in practice to prevent negative weights if the difference exceeds 1.
        return max(0.0, beta)
    else:
        return 1.0
```

## Subtopics

### [Scalar Intensity Increase Measure](6014-scalar-intensity-increase-measure.md)
A method using scalar intensity as the importance measure, considering only the difference between two adjacent samples, increasing accumulated transparency whenever there is an increase of scalar intensity. It sets itself apart from its sibling [Adjacent Gradient Difference](5787-adjacent-gradient-difference.md) by operating on raw scalar values rather than gradient magnitudes, making it sensitive to absolute intensity changes rather than rate-of-change changes.

## Operating characteristics
**Time and Memory Complexity:** Not given in the sources.

**Measured Performance:** Not given in the sources.

**Scaling:** Not given in the sources.

**Strengths and Limitations:**
*   **Strengths:** It produces a more transparent look than maximum gradient magnitude measures, allowing more samples along the viewing ray to contribute to the final result [S1]. It can better reveal sharp features of datasets compared to direct volume rendering [S1].
*   **Limitations:** It tends to have a wider dynamic range, requiring tone-mapping for display [S1].

**When to use it and when not:**
Use it when a more transparent visualization is desired and sharp features need to be highlighted without the opacity saturation of maximum gradient magnitude projection [S1]. It is suitable for fast data exploration when combined with tone-mapping [S1].

## Background
The method was introduced in the context of importance-based accumulated transparency modulation for fast volumetric data exploration [S1]. It is derived from the observation that calculating importance difference by two adjacent samples provides distinct visual characteristics compared to maximum gradient magnitude projection [S1].
