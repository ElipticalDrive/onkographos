# 4th-Order Finite Difference Gradient

Also called: 4th-Order Accurate Finite Difference Scheme, Grid Normal Computation via 4th-Order Finite Differences

## Overview
This method computes the gradient (normal vector) of a Signed Distance Function (SDF) grid at every voxel center using a 4th-order accurate finite difference scheme [S1, unofficial]. It provides smooth normals essential for accurate ray marching and shading in volume rendering. It distinguishes itself from lower-order siblings like [Finite Difference Stencils (Central/Forward/Backward)](3858-finite-difference-stencils-central-forward-backward.md) by maintaining high accuracy even at grid boundaries through specific extrapolation, avoiding the noise or bias introduced by standard 2nd-order central differences near edges.

## How it works
**Inputs:**
- `grid`: A 3D tensor of shape $(N_x, N_y, N_z)$ containing SDF values at voxel centers.
- `voxel_size`: Scalar physical size of a single voxel.
- `grid_res_x`, `grid_res_y`, `grid_res_z`: Integer dimensions of the grid.

**Outputs:**
- A list of three 3D tensors `[grid_normal_x, grid_normal_y, grid_normal_z]`, each of shape $(N_x, N_y, N_z)$, representing the partial derivatives $\frac{\partial S}{\partial x}, \frac{\partial S}{\partial y}, \frac{\partial S}{\partial z}$.

**Data Structures:**
- The grid is stored as a dense 3D array. Indices are 0-based.
- Boundary extrapolation uses a 3-point stencil to estimate values outside the domain.

**Steps:**
1. Define boundary indices: $n_x = N_x - 1$, $n_y = N_y - 1$, $n_z = N_z - 1$.
2. Compute the x-axis gradient components:
   - Calculate forward difference approximation $X_1$ by concatenating the interior forward differences with a boundary term.
   - Calculate backward difference approximation $X_2$ by concatenating a boundary term with the interior backward differences.
   - Compute $grid\_normal_x = (X_1 - X_2) / (2 \cdot \text{voxel\_size})$.
3. Repeat step 2 for y and z axes, adjusting tensor dimensions and indexing.

**Formulas:**
The core central difference for interior points is:
$$ \frac{\partial S}{\partial x} \approx \frac{S_{i+1,j,k} - S_{i-1,j,k}}{2 \Delta x} $$

At the boundaries, 4th-order accuracy is maintained using extrapolation. For the last element in a dimension with index $n$, the virtual value $V_{n+1}$ is:
$$ V_{n+1} = 3V_n - 3V_{n-1} + V_{n-2} $$
Similarly, for the first element (index 0), the virtual value $V_{-1}$ is derived from the symmetry of the stencil logic applied to $X_2$. Specifically, the term used in $X_2$ for the first element corresponds to $S_{-1}$, calculated as:
$$ V_{-1} = -3V_0 + 3V_1 + V_2 $$

**Pseudocode:**
```python
def compute_4th_order_gradient(grid, voxel_size, nx, ny, nz):
    """
    Computes 4th-order accurate gradients for a 3D SDF grid.
    grid: Tensor of shape (nx, ny, nz)
    """
    # Initialize output tensors
    grad_x = torch.zeros_like(grid)
    grad_y = torch.zeros_like(grid)
    grad_z = torch.zeros_like(grid)

    # --- X-axis Gradient ---
    # Interior points: i from 1 to nx-2
    # X1 corresponds to S[i+1] for i in 0..nx-2 (indices 1..nx-1)
    # X2 corresponds to S[i-1] for i in 1..nx-1 (indices 0..nx-2)
    
    # Forward part (X1): grid[1:, :, :] are S[i+1] for i=0..nx-2
    # Boundary term for i=nx-1: S[nx] = 3*S[nx-1] - 3*S[nx-2] + S[nx-3]
    interior_x1 = grid[1:, :, :]
    boundary_x1 = 3 * grid[nx-1, :, :] - 3 * grid[nx-2, :, :] + grid[nx-3, :, :]
    boundary_x1 = boundary_x1.unsqueeze(0) # Shape (1, ny, nz)
    X1 = torch.cat((interior_x1, boundary_x1), dim=0)

    # Backward part (X2): grid[:-1, :, :] are S[i-1] for i=1..nx-1
    # Boundary term for i=0: S[-1] = -3*S[0] + 3*S[1] + S[2]
    interior_x2 = grid[:-1, :, :]
    boundary_x2 = -3 * grid[0, :, :] + 3 * grid[1, :, :] + grid[2, :, :]
    boundary_x2 = boundary_x2.unsqueeze(0) # Shape (1, ny, nz)
    X2 = torch.cat((boundary_x2, interior_x2), dim=0)

    grad_x = (X1 - X2) / (2.0 * voxel_size)

    # --- Y-axis Gradient ---
    interior_y1 = grid[:, 1:, :]
    boundary_y1 = 3 * grid[:, ny-1, :] - 3 * grid[:, ny-2, :] + grid[:, ny-3, :]
    boundary_y1 = boundary_y1.unsqueeze(1) # Shape (nx, 1, nz)
    Y1 = torch.cat((interior_y1, boundary_y1), dim=1)

    interior_y2 = grid[:, :-1, :]
    boundary_y2 = -3 * grid[:, 0, :] + 3 * grid[:, 1, :] + grid[:, 2, :]
    boundary_y2 = boundary_y2.unsqueeze(1) # Shape (nx, 1, nz)
    Y2 = torch.cat((boundary_y2, interior_y2), dim=1)

    grad_y = (Y1 - Y2) / (2.0 * voxel_size)

    # --- Z-axis Gradient ---
    interior_z1 = grid[:, :, 1:]
    boundary_z1 = 3 * grid[:, :, nz-1] - 3 * grid[:, :, nz-2] + grid[:, :, nz-3]
    boundary_z1 = boundary_z1.unsqueeze(2) # Shape (nx, ny, 1)
    Z1 = torch.cat((interior_z1, boundary_z1), dim=2)

    interior_z2 = grid[:, :, :-1]
    boundary_z2 = -3 * grid[:, :, 0] + 3 * grid[:, :, 1] + grid[:, :, 2]
    boundary_z2 = boundary_z2.unsqueeze(2) # Shape (nx, ny, 1)
    Z2 = torch.cat((boundary_z2, interior_z2), dim=2)

    grad_z = (Z1 - Z2) / (2.0 * voxel_size)

    return [grad_x, grad_y, grad_z]
```

**Parameters:**
- `voxel_size`: Physical size of a voxel. Typical values depend on the scene scale (e.g., 0.01 to 1.0 meters). [S1, unofficial]

**Edge Cases:**
- Grid resolution must be at least 3 in each dimension ($N \ge 3$) to compute the boundary extrapolation terms involving $V_{n-2}$ and $V_2$. [G]
- If the grid is smaller than 3 voxels, the method fails. [G]

## Operating characteristics
- **Time Complexity:** $O(N_x N_y N_z)$, as it performs a constant number of operations per voxel.
- **Memory Complexity:** $O(N_x N_y N_z)$ for storing the input grid and three output gradient tensors.
- **Strengths:** Maintains 4th-order accuracy at boundaries, reducing artifacts in ray marching compared to 2nd-order schemes. Smooth normals improve shading quality.
- **Limitations:** Requires a minimum grid resolution of 3. More complex to implement than 2nd-order stencils due to boundary handling.
- **When to use:** High-quality SDF rendering where boundary artifacts are visible with lower-order methods.
- **When not to use:** Real-time applications with very low resolution grids where the overhead of boundary logic is disproportionate, or when $N < 3$.

## Background
This method is implemented in the SDFDiff repository, associated with research on differentiable rendering of SDFs [S1, unofficial]. It addresses the need for accurate surface normals in volume rendering pipelines that rely on Signed Distance Functions, particularly when using ray marching techniques that are sensitive to gradient noise.
