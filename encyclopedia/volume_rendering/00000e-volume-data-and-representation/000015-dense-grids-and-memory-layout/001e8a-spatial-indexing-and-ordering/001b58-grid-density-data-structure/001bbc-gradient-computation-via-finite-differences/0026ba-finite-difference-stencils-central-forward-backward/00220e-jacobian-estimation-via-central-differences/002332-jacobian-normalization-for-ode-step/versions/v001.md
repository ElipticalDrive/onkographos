# Jacobian Normalization for ODE Step
Also called: Normalize Inverse Jacobian Step, ODE Evaluation
## Overview
This method computes the normalized direction vector for an Ordinary Differential Equation (ODE) solver by applying the inverse of the estimated Jacobian matrix to a base direction vector. It serves as the core evaluation step for ray marching or path tracing in deformable volume rendering, ensuring that the integration step respects the local geometric distortion of the field [S1, unofficial]. It differs from raw Jacobian estimation by performing the matrix inversion and vector normalization required for stable stepping.
## How it works
**Inputs:**
- `pos`: The current 3D position in the volume (vector).
- `w`: The base direction vector for the ODE step (vector).
- `force`: A parameter passed to the Jacobian estimator (scalar or vector, context-dependent).

**Outputs:**
- `step_dir`: The normalized direction vector for the next ODE step (vector).

**Data Structures:**
- The Jacobian matrix $J$ is a $3 \times 3$ matrix estimated by the parent method [Jacobian Estimation via Central Differences](2650-jacobian-estimation-via-central-differences.md).
- $J^{-1}$ is the inverse of this matrix.

**Steps:**
1. Estimate the Jacobian matrix $J$ at the current position `pos` using the parent method. This involves computing central differences of the underlying deformation field (e.g., `simpleBrush`) [S1, unofficial].
2. Compute the inverse of the Jacobian matrix, $J^{-1}$. If $J$ is singular or near-singular, numerical stability techniques (such as regularization) are required [G].
3. Multiply the inverse Jacobian by the direction vector $w$: $v = J^{-1} w$.
4. Normalize the resulting vector $v$ to obtain the final step direction: $step\_dir = \frac{v}{\|v\|}$.

**Formula:**
$$ step\_dir = \text{normalize}\left( J^{-1}(pos, force) \cdot w \right) $$

Where:
- $J(pos, force)$ is the $3 \times 3$ Jacobian matrix estimated at `pos`.
- $J^{-1}$ is the matrix inverse.
- $\text{normalize}(v) = \frac{v}{\|v\|_2}$.

**Pseudocode:**
```python
def jacobian_normalization_ode_step(pos, w, force):
    # Step 1: Estimate Jacobian using parent method
    # The parent method computes central differences of the deformation field
    J = estimate_jacobian_central_differences(pos, force)
    
    # Step 2: Invert the Jacobian
    # Note: In practice, check for singularity. 
    # If det(J) is near zero, regularization may be needed [G].
    J_inv = invert_matrix_3x3(J)
    
    # Step 3: Multiply inverse Jacobian by direction vector
    v = matrix_vector_multiply(J_inv, w)
    
    # Step 4: Normalize the result
    norm_v = vector_length(v)
    if norm_v < 1e-8:
        # Fallback for degenerate cases [G]
        return w
    
    step_dir = vector_divide(v, norm_v)
    return step_dir
```

**Parameters:**
- `force`: Passed to the Jacobian estimator. Typical values depend on the specific deformation field implementation. Not given in the sources.

**Edge Cases:**
- **Singular Jacobian:** If the determinant of $J$ is zero, the inverse does not exist. This occurs at critical points of the deformation field. A small epsilon regularization or fallback to the unnormalized direction may be required [G].
- **Zero Vector:** If $J^{-1} w$ results in a zero vector, normalization fails. This implies the direction is collapsed by the deformation.

## Operating characteristics
- **Time Complexity:** Dominated by the Jacobian estimation (parent method) and matrix inversion. Central difference estimation requires multiple function evaluations (typically 6 for a 3x3 Jacobian). Matrix inversion is $O(1)$ for fixed $3 \times 3$ size.
- **Memory Complexity:** $O(1)$ auxiliary memory for the matrix and vector operations.
- **Strengths:** Provides geometrically correct stepping directions in deformed spaces, improving convergence and accuracy in ray marching.
- **Limitations:** Computationally expensive due to multiple function evaluations for finite differences. Sensitive to noise in the deformation field, which can lead to unstable Jacobian estimates.
- **When to use:** When rendering deformable volumes or fields where the metric space is non-Euclidean.
- **When not to use:** For static, Euclidean volumes where standard ray marching suffices.

## Background
