# Flow Jacobian Decomposition
Also called: Strain-Rate Decomposition

## Overview
Flow Jacobian Decomposition splits the 3x3 Jacobian matrix of a displacement field into symmetric and antisymmetric parts to isolate local geometric deformation (strain) from rigid-body rotation. It distinguishes itself from sibling methods like [Jacobian Normalization for ODE Step](2946-jacobian-normalization-for-ode-step.md) by focusing on physical interpretation of flow kinematics rather than numerical stability for integration.

## How it works
**Inputs and Outputs:**
*   Input: The 3x3 Jacobian matrix $J$ of the displacement field $\mathbf{u}$, computed via [Jacobian Estimation via Central Differences](2650-jacobian-estimation-via-central-differences.md).
*   Output: The Infinitesimal Strain Tensor $\boldsymbol{\varepsilon}$ and the Infinitesimal Rotation Tensor $\mathbf{r}$.

**Data Structures:**
*   $J$: A $3 \times 3$ matrix where $J_{ij} = \frac{\partial u_i}{\partial x_j}$.
*   $\boldsymbol{\varepsilon}$: A $3 \times 3$ symmetric matrix.
*   $\mathbf{r}$: A $3 \times 3$ antisymmetric matrix.

**Steps:**
1.  Compute the symmetric part of $J$ to obtain the Infinitesimal Strain Tensor $\boldsymbol{\varepsilon}$.
2.  Compute the antisymmetric part of $J$ to obtain the Infinitesimal Rotation Tensor $\mathbf{r}$.

**Formulas:**
The decomposition is defined as:
$$ J_{ij} = \varepsilon_{ij} + r_{ij} $$
where:
$$ \varepsilon_{ij} = \frac{1}{2} \left( \frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i} \right) $$
$$ r_{ij} = \frac{1}{2} \left( \frac{\partial u_i}{\partial x_j} - \frac{\partial u_j}{\partial x_i} \right) $$
Here, $\varepsilon_{ij}$ represents the symmetric strain component, and $r_{ij}$ represents the antisymmetric rotation component [S1, unofficial].

**Pseudocode:**
```python
def flow_jacobian_decomposition(J):
    """
    Decomposes the Jacobian matrix J into strain and rotation tensors.
    J: 3x3 matrix, J[i][j] = du_i/dx_j
    """
    # Initialize 3x3 matrices with zeros
    epsilon = [[0.0 for _ in range(3)] for _ in range(3)]
    r = [[0.0 for _ in range(3)] for _ in range(3)]

    for i in range(3):
        for j in range(3):
            # Symmetric part: Infinitesimal Strain Tensor
            epsilon[i][j] = 0.5 * (J[i][j] + J[j][i])
            
            # Antisymmetric part: Infinitesimal Rotation Tensor
            r[i][j] = 0.5 * (J[i][j] - J[j][i])
            
    return epsilon, r
```

**Edge Cases:**
*   If $J$ is not square or dimensions mismatch, the decomposition is undefined.
*   For large deformations where $\|\nabla \mathbf{u}\| \not\ll 1$, this linear approximation becomes inaccurate [S1, unofficial].

## Subtopics

### [Infinitesimal Rotation Tensor](10633-infinitesimal-rotation-tensor.md)
Isolates the rotational component related to the curl of the vector field, distinguishing pure orientation changes from geometric distortion. Choose this when analyzing rigid-body motion within a flow.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per voxel, as it involves a fixed number of arithmetic operations on a $3 \times 3$ matrix.
*   **Memory Complexity:** $O(1)$ additional storage per voxel for the two resulting tensors.
*   **Strengths:** Provides immediate physical insight into local flow behavior (stretching vs. rotation).
*   **Limitations:** Valid only for infinitesimal deformations. Not suitable for large strain scenarios without modification.

## Background
Originating from continuum mechanics, this decomposition is standard in fluid dynamics and solid mechanics to analyze displacement gradients. It is used in volume rendering to visualize flow fields by coloring voxels based on strain or rotation magnitudes.
