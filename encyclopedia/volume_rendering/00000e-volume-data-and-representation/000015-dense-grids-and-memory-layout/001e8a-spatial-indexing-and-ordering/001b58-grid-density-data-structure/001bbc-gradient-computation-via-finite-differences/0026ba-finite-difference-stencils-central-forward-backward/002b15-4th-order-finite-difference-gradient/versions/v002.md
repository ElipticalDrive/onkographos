# 4th-Order Finite Difference Gradient

Also called: 4th-Order Accurate Finite Difference Scheme, Grid Normal Computation via 4th-Order Finite Differences

## Overview
This method computes the gradient (normal vector) of a Signed Distance Function (SDF) grid at every voxel center using a 4th-order accurate finite difference scheme [S1, unofficial]. It distinguishes itself from lower-order stencils by maintaining 4th-order accuracy at grid boundaries through specific extrapolation, avoiding the noise or bias introduced by standard 2nd-order central differences near edges [G].

## How it works
**Inputs:**
- `grid`: A 3D array of shape $(N_x, N_y, N_z)$ containing SDF values at voxel centers [S1, unofficial].
- `voxel_size`: Scalar physical size of a single voxel [S1, unofficial].
- `grid_res_x`, `grid_res_y`, `grid_res_z`: Integer dimensions of the grid [S1, unofficial].

**Outputs:**
- A list of three 3D arrays `[grad_x, grad_y, grad_z]`, each of shape $(N_x, N_y, N_z)$, representing the partial derivatives $\frac{\partial S}{\partial x}, \frac{\partial S}{\partial y}, \frac{\partial S}{\partial z}$ [S1, unofficial].

**Data Structures:**
- The grid is stored as a dense 3D array with 0-based indexing [S1, unofficial].
- Boundary extrapolation uses a 3-point stencil to estimate values outside the domain [S1, unofficial].

**Steps:**
1. Define boundary indices: $n_x = N_x - 1$, $n_y = N_y - 1$, $n_z = N_z - 1$ [S1, unofficial].
2. Compute the x-axis gradient components:
   - Calculate forward difference approximation $X_1$ by concatenating the interior forward differences with a boundary term [S1, unofficial].
   - Calculate backward difference approximation $X_2$ by concatenating a boundary term with the interior backward differences [S1, unofficial].
   - Compute $grad\_x = (X_1 - X_2) / (2 \cdot \text{voxel\_size})$ [S1, unofficial].
3. Repeat step 2 for y and z axes, adjusting tensor dimensions and indexing [S1, unofficial].

**Formulas:**
The core central difference for interior points is:
$$ \frac{\partial S}{\partial x} \approx \frac{S_{i+1,j,k} - S_{i-1,j,k}}{2 \Delta x} $$ [G]

At the boundaries, 4th-order accuracy is maintained using extrapolation. For the last element in a dimension with index $n$, the virtual value $V_{n+1}$ is:
$$ V_{n+1} = 3V_n - 3V_{n-1} + V_{n-2} $$ [S1, unofficial]

For the first element (index 0), the virtual value $V_{-1}$ is derived from the symmetry of the stencil logic applied to $X_2$:
$$ V_{-1} = -3V_0 + 3V_1 + V_2 $$ [S1, unofficial]

**Pseudocode:**
```python
def compute_4th_order_gradient(grid, voxel_size, nx, ny, nz):
    # grid: 3D array of shape (nx, ny, nz)
    # Returns three 3D arrays of shape (nx, ny, nz)
    
    grad_x = [[0.0] * ny * nz for _ in range(nx)]
    grad_y = [[0.0] * ny * nz for _ in range(nx)]
    grad_z = [[0.0] * ny * nz for _ in range(nx)]

    # X-axis gradient
    for i in range(nx):
        if i == 0:
            s_plus = grid[1]
            s_minus = -3 * grid[0] + 3 * grid[1] + grid[2]
        elif i == nx - 1:
            s_plus = 3 * grid[nx-1] - 3 * grid[nx-2] + grid[nx-3]
            s_minus = grid[nx-2]
        else:
            s_plus = grid[i+1]
            s_minus = grid[i-1]
        for j in range(ny):
            for k in range(nz):
                grad_x[i][j][k] = (s_plus[j][k] - s_minus[j][k]) / (2.0 * voxel_size)

    # Y-axis gradient
    for j in range(ny):
        if j == 0:
            s_plus = grid[:, 1, :]
            s_minus = -3 * grid[:, 0, :] + 3 * grid[:, 1, :] + grid[:, 2, :]
        elif j == ny - 1:
            s_plus = 3 * grid[:, ny-1, :] - 3 * grid[:, ny-2, :] + grid[:, ny-3, :]
            s_minus = grid[:, ny-2, :]
        else:
            s_plus = grid[:, j+1, :]
            s_minus = grid[:, j-1, :]
        for i in range(nx):
            for k in range(nz):
                grad_y[i][j][k] = (s_plus[i][k] - s_minus[i][k]) / (2.0 * voxel_size)

    # Z-axis gradient
    for k in range(nz):
        if k == 0:
            s_plus = grid[:, :, 1]
            s_minus = -3 * grid[:, :, 0] + 3 * grid[:, :, 1] + grid[:, :, 2]
        elif k == nz - 1:
            s_plus = 3 * grid[:, :, nz-1] - 3 * grid[:, :, nz-2] + grid[:, :, nz-3]
            s_minus = grid[:, :, nz-2]
        else:
            s_plus = grid[:, :, k+1]
            s_minus = grid[:, :, k-1]
        for i in range(nx):
            for j in range(ny):
                grad_z[i][j][k] = (s_plus[i][j] - s_minus[i][j]) / (2.0 * voxel_size)

    return [grad_x, grad_y, grad_z]
```

**Parameters:**
- `voxel_size`: Physical size of a voxel. Used to normalize the finite difference result to physical units [S1, unofficial].

**Edge Cases:**
- Grid resolution must be at least 3 in each dimension ($N \ge 3$) to compute the boundary extrapolation terms involving $V_{n-2}$ and $V_2$ [G].
- If the grid is smaller than 3 voxels, the method fails [G].

## Operating characteristics
- **Time Complexity:** $O(N_x N_y N_z)$, as it performs a constant number of operations per voxel [G].
- **Memory Complexity:** $O(N_x N_y N_z)$ for storing the input grid and three output gradient tensors [G].
- **Strengths:** Maintains 4th-order accuracy at boundaries, reducing artifacts in ray marching compared to 2nd-order schemes [G].
- **Limitations:** Requires a minimum grid resolution of 3. More complex to implement than 2nd-order stencils due to boundary handling [G].
- **When to use:** High-quality SDF rendering where boundary artifacts are visible with lower-order methods [G].
- **When not to use:** Real-time applications with very low resolution grids where the overhead of boundary logic is disproportionate, or when $N < 3$ [G].

## Background
This method is implemented in the SDFDiff repository, associated with research on differentiable rendering of SDFs [S1, unofficial]. It addresses the need for accurate surface normals in volume rendering pipelines that rely on Signed Distance Functions [G].
