# Finite Difference Stencils (Central/Forward/Backward)

Also called: Finite Difference Gradient, FD Gradient, Numerical Gradient

## Overview
Finite difference stencils compute the spatial gradient vector of a scalar volume field by approximating partial derivatives using discrete voxel values and their immediate neighbors. This method solves the problem of estimating surface normals for shading and opacity modulation in volume rendering when analytic derivatives are unavailable or too expensive to compute. It sets itself apart from [Analytic Gradient Computation](2167-analytic-gradient-computation.md) by requiring additional sample evaluations (typically 6 for central differences) rather than deriving gradients from the basis functions themselves, and from [Gradient Estimation from Samples](2180-gradient-estimation-from-samples.md) by relying on structured grid topology rather than unstructured ray sampling statistics.

## Shared principles
All finite difference gradient methods approximate the partial derivative $\frac{\partial f}{\partial x_i}$ at a point $\mathbf{p}$ using a linear combination of function values at neighboring points. The general form for a stencil is:
$$ \nabla f(\mathbf{p}) \approx \sum_{k} c_k f(\mathbf{p} + \mathbf{d}_k) $$
where $\mathbf{d}_k$ are displacement vectors to neighbor voxels and $c_k$ are coefficients determined by the order of accuracy and the specific stencil type.

**Voxel Spacing:**
The physical gradient magnitude depends on the voxel spacing $h$. For isotropic grids, $h$ is a scalar. For anisotropic grids, axis-specific spacings $h_x, h_y, h_z$ must be used in the normalization step [G]. The derivative with respect to axis $i$ is scaled by $1/h_i$.

**Boundary Conditions:**
Stencils extending beyond the volume bounds require boundary handling. Common strategies include:
1.  **Clamping:** Using the value of the nearest boundary voxel.
2.  **Zero-padding:** Assuming values outside are 0.
3.  **Reflection:** Mirroring values across the boundary.
4.  **Extrapolation:** Using higher-order schemes to predict outside values (e.g., for 4th-order accuracy) [S1].

**Accuracy:**
-   **Forward/Backward Differences:** First-order accurate ($O(h)$). Biased in the direction of the difference.
-   **Central Differences:** Second-order accurate ($O(h^2)$). Unbiased, but requires neighbors on both sides.

## Subtopics

### [Sobel Operator](1416-sobel-operator.md)
The Sobel Operator is a gradient estimation method that combines differentiation with smoothing. It uses a $3 \times 3 \times 3$ separable kernel to weight neighbors, emphasizing edges while suppressing high-frequency noise. It is less sensitive to noise than simple central differences but has higher computational complexity due to the 27-tap kernel. Choose this when noise reduction is prioritized over strict geometric accuracy.

### [Jacobian Estimation via Central Differences](2650-jacobian-estimation-via-central-differences.md)
This method estimates the full $3 \times 3$ Jacobian matrix of a vector-valued function (e.g., a deformation field) by computing central differences along each axis. It provides the local linear transformation matrix, enabling applications like inverse mapping for ODE solvers. It differs from scalar gradient methods by outputting a matrix rather than a vector.

### [Forward Difference Gradient](3362-forward-difference-gradient.md)
A first-order method approximating partial derivatives by subtracting the current voxel value from its immediate neighbor in the positive direction. It uses only two voxels per axis, resulting in lower computational cost ($O(1)$ samples) but reduced accuracy ($O(h)$) and directional bias. It is primarily used in direct volume rendering for Phong or Blinn-Phong lighting models where performance is critical.

### [4th-Order Finite Difference Gradient](4889-4th-order-finite-difference-gradient.md)
Computes the gradient of a Signed Distance Function (SDF) grid using a 4th-order accurate scheme. It maintains high accuracy at volume boundaries through specific extrapolation formulas ($V_{n+1} = 3V_n - 3V_{n-1} + V_{n-2}$), whereas standard central differences degrade to lower orders at boundaries. Choose this for smooth ray marching and shading of SDF volumes.

### [Gauss-Seidel with Successive Over-Relaxation (SOR)](6904-gauss-seidel-with-successive-over-relaxation-sor.md)
An iterative solver for the steady-state heat equation (Laplace equation $\nabla^2 T = 0$) on a 3D grid. It updates grid points using the most recent neighbor values (Gauss-Seidel) and accelerates convergence with a relaxation factor $\omega > 1$. It is used to smooth scalar fields or solve for equilibrium states in volume rendering, exploiting data locality to reduce iteration counts compared to Jacobi iteration.

### Clamped Central Differences
**Definition:** A variant of central differencing for gradient computation that clamps offset positions to the current region to avoid additional ray traversals [S1].
**Step:** Compute six additional basis reconstruction samples at positions offset from the current sample by a distance proportional to the region's sample rate. Clamp the offset positions to the current region before evaluating them [S1].
**Pitfall:** Gradients are not necessarily continuous at level boundaries because the offset size can change [S1].
**Comparison:** Accurate central differencing requires tracing 6 additional rays per sample via infinitesimal rays to find containing regions, which is expensive. Clamped version removes ray traversals but reduces quality [S1].

### Curl Grid Computation
**Definition:** Computes the curl $\nabla \times \mathbf{F}$ at every active voxel of a vector grid using central differences [S2, unofficial].
**Step:** Initialize a GradStencil with the grid tree. Iterate over all active voxels $(c, \_)$ in the grid tree. Move the stencil to the current coordinate $c$. Compute the x, y, and z components of the curl using the formulas and store the tuple $(c_x, c_y, c_z)$ in a dictionary keyed by coordinate. Build the result grid using the computed data, a background value of zero vector $(0,0,0)$, and the original grid's voxel size [S2, unofficial].
**Formula:**
$$ \text{curl}_x = (v[4][3] - v[5][3] - v[6][2] + v[7][2]) \cdot 0.5 $$
$$ \text{curl}_y = (v[6][1] - v[7][1] - v[2][3] + v[3][3]) \cdot 0.5 $$
$$ \text{curl}_z = (v[2][2] - v[3][2] - v[4][1] + v[5][1]) \cdot 0.5 $$
**Parameter:** `half`: The scalar multiplier 0.5, representing $1/(2 \cdot \text{voxel\_size})$ in index space [S2, unofficial].

### WENO5 Interpolation
**Definition:** Implementation of nominally fifth-order finite-difference WENO that returns the numerical flux for interpolation [S3].
**Formula:** Given $v_1 = f(x-2dx)$, $v_2 = f(x-dx)$, $v_3 = f(x)$, $v_4 = f(x+dx)$ and $v_5 = f(x+2dx)$, return an interpolated value $f(x+dx/2)$ with the special property that $( f(x+dx/2) - f(x-dx/2) ) / dx = df/dx (x) + \text{error}$, where the error is fifth-order in smooth regions: $O(dx) \le \text{error} \le O(dx^5)$ [S3].
**Parameter:** `scale2`: A scaling factor for the weights, default value is 1.0. `v1` through `v5`: Five input values for the stencil. `RealT`: Type for scale2, defaults to ValueType [S3].
**History:** Introduced by Chi-Wang Shu. Referenced in 'High Order Finite Difference and Finite Volume WENO Schemes and Discontinuous Galerkin Methods for CFD' (ICASE Report No 2001-11, page 6) and ICASE No 97-65 (Shu, 1997) [S3].

### Zucker-Hummel Operator
**Definition:** Advanced gradient operators that use 54 voxels to produce softer and clearer gradients compared to the Central-Difference operator [S4, unofficial].
**Step:** 1. Apply operator masks in X, Y, and Z planes at positions one voxel before, at, and one voxel after the sampling point. 2. Multiply voxel values by mask coefficients. 3. Sum the results for each plane to get gradient components [S4, unofficial].
**Comparison:** Unlike the Central-Difference operator which uses 6 voxels, Zucker-Hummel and Sobel 3D use 54 voxels, providing a better description of local surface structure. More complex calculation than Central-Difference, requiring 54 sampling points, but offers significantly improved image quality [S4, unofficial].

### Hessian-Vector Product via Central Differences
**Definition:** An approximation of the Hessian-vector product $H(\theta)\mathbf{v}$ that avoids computing the full Hessian matrix [S5].
**Step:** Evaluate the first-order gradient estimator at positions shifted from the current solution along the direction $\mathbf{v}$ by $\pm \epsilon$ [S5].
**Formula:** Approximation using central differences: $H(\theta)\mathbf{v} \approx \lim_{\epsilon \to 0} \frac{g(\theta + \epsilon \mathbf{v}) - g(\theta - \epsilon \mathbf{v})}{2\epsilon}$. The smooth HVP kernel is estimated using directional central differences of the gradient estimator: $D_{HVP} \kappa(\tau) = \frac{D_G \kappa(\tau - \epsilon \mathbf{v}) - D_G \kappa(\tau + \epsilon \mathbf{v})}{2\epsilon}$ [S5].
**Complexity:** Time complexity: $O(n)$ function evaluations without IS, $O(n)$ with IS, $O(1)$ with Aggregate IS. Space complexity for Aggregate IS is $O(n)$ [S5].

## Background
Finite difference methods are a cornerstone of numerical analysis for approximating derivatives of functions defined on discrete grids. In the context of volume rendering, they were adopted to provide surface normals for lighting calculations (such as Phong shading) when the volume data was represented as a dense grid of scalar values without explicit surface extraction. The central difference scheme is the most common due to its second-order accuracy and symmetry. Variants like the Sobel operator were introduced to mitigate noise inherent in discrete voxel data. The method is widely used in direct volume rendering and is a fundamental component in differentiable rendering pipelines for gradient-based optimization [S1, S5].
