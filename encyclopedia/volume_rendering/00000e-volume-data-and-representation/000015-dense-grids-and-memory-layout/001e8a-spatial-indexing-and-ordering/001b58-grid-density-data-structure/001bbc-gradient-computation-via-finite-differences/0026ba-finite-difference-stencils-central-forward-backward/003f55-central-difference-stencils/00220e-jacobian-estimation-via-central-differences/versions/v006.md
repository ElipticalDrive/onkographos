# Jacobian Estimation via Central Differences

Also called: Central Difference Jacobian, Finite Difference Jacobian

## Overview
This method estimates the $3 \times 3$ Jacobian matrix of a vector-valued deformation field by computing central differences of the field's component functions. It solves the problem of obtaining the local linear transformation (stretch, shear, rotation) at a specific point in space, which is required for tasks such as normalizing directions for Ordinary Differential Equation (ODE) solvers [S1, unofficial]. It is distinguished from sibling methods like the Sobel Operator by its direct application to arbitrary deformation fields rather than image intensity gradients, and from Forward Difference methods by its second-order accuracy and unbiased nature [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A point $\mathbf{p} = (x, y, z)$ in the domain of the deformation field $\mathbf{F}: \mathbb{R}^3 \to \mathbb{R}^3$, and a step size $\epsilon$.
- Output: A $3 \times 3$ matrix $\mathbf{J}$ representing the Jacobian $\frac{\partial \mathbf{F}}{\partial \mathbf{p}}$.

**Data Structures:**
- The deformation field $\mathbf{F}$ is accessed via a function `simpleBrush(pos, force)` which returns a 3D vector [S1, unofficial].
- The Jacobian is stored as a $3 \times 3$ matrix, constructed from three column vectors corresponding to the partial derivatives with respect to $x, y, z$.

**Steps:**
1. Define the displacement vectors for the three axes:
   $$ \mathbf{d}_x = (\epsilon, 0, 0), \quad \mathbf{d}_y = (0, \epsilon, 0), \quad \mathbf{d}_z = (0, 0, \epsilon) $$
2. Compute the partial derivative with respect to $x$ by evaluating the field at $\mathbf{p} + \mathbf{d}_x$ and $\mathbf{p} - \mathbf{d}_x$:
   $$ \mathbf{grad}_x = \frac{\mathbf{F}(\mathbf{p} + \mathbf{d}_x) - \mathbf{F}(\mathbf{p} - \mathbf{d}_x)}{2\epsilon} $$
3. Compute the partial derivative with respect to $y$:
   $$ \mathbf{grad}_y = \frac{\mathbf{F}(\mathbf{p} + \mathbf{d}_y) - \mathbf{F}(\mathbf{p} - \mathbf{d}_y)}{2\epsilon} $$
4. Compute the partial derivative with respect to $z$:
   $$ \mathbf{grad}_z = \frac{\mathbf{F}(\mathbf{p} + \mathbf{d}_z) - \mathbf{F}(\mathbf{p} - \mathbf{d}_z)}{2\epsilon} $$
5. Construct the Jacobian matrix $\mathbf{J}$ using these gradient vectors as columns:
   $$ \mathbf{J} = \begin{bmatrix} | & | & | \\ \mathbf{grad}_x & \mathbf{grad}_y & \mathbf{grad}_z \\ | & | & | \end{bmatrix} $$

**Parameters:**
- $\epsilon$: The step size for finite differences. The source uses a small constant value, typically determined by the scale of the deformation field [S1, unofficial].

**Pseudocode:**
```python
def estimate_jacobian_central_diff(p: Vector3, epsilon: float, field_func) -> Matrix3:
    """
    Estimates the 3x3 Jacobian matrix of a deformation field at point p.
    
    Args:
        p: The point (x, y, z) at which to estimate the Jacobian.
        epsilon: The step size for central differences.
        field_func: A function F(pos) -> Vector3 representing the deformation field.
        
    Returns:
        A 3x3 Matrix where columns are the partial derivatives grad_x, grad_y, grad_z.
    """
    # Define displacement vectors
    dx = Vector3(epsilon, 0.0, 0.0)
    dy = Vector3(0.0, epsilon, 0.0)
    dz = Vector3(0.0, 0.0, epsilon)
    
    # Evaluate field at perturbed points
    # Note: field_func is assumed to return a Vector3
    f_plus_x = field_func(p + dx)
    f_minus_x = field_func(p - dx)
    
    f_plus_y = field_func(p + dy)
    f_minus_y = field_func(p - dy)
    
    f_plus_z = field_func(p + dz)
    f_minus_z = field_func(p - dz)
    
    # Compute central differences
    # grad_x, grad_y, grad_z are Vector3 objects
    grad_x = (f_plus_x - f_minus_x) / (2.0 * epsilon)
    grad_y = (f_plus_y - f_minus_y) / (2.0 * epsilon)
    grad_z = (f_plus_z - f_minus_z) / (2.0 * epsilon)
    
    # Construct Jacobian matrix from columns
    # Assuming Matrix3 has a constructor or setter that takes column vectors
    jacobian = Matrix3(grad_x, grad_y, grad_z)
    
    return jacobian
```

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** If $\mathbf{p} \pm \mathbf{d}_i$ falls outside the valid domain of the deformation field, the evaluation will fail or return undefined values. Standard boundary handling (clamping, zero-padding) must be applied within `field_func` or the caller must ensure $\mathbf{p}$ is sufficiently interior [G].
- **Precision:** If $\epsilon$ is too small, subtractive cancellation errors in floating-point arithmetic may dominate. If $\epsilon$ is too large, the approximation error (truncation error) increases. The source does not specify a robust adaptive strategy [S1, unofficial].

## Subtopics

### [Jacobian Normalization for ODE Step](2946-jacobian-normalization-for-ode-step.md)
This method computes the normalized direction vector for an Ordinary Differential Equation (ODE) solver by applying the inverse of an estimated Jacobian matrix to a base direction vector. It differs from raw Jacobian estimation by performing the matrix inversion and vector normalization required for stable stepping [G].

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation, requiring 6 evaluations of the deformation field $\mathbf{F}$ and a constant number of vector operations.
- **Memory Complexity:** $O(1)$ auxiliary space.
- **Accuracy:** Second-order accurate ($O(\epsilon^2)$) for smooth fields, as it uses central differences [S1, unofficial].
- **Strengths:** Unbiased estimate; simple to implement; no need for analytical derivatives.
- **Limitations:** Requires the field function to be callable at arbitrary points; sensitive to boundary conditions; computationally expensive if the field evaluation is costly (e.g., ray marching through a volume).
- **When to use:** When analytical derivatives are unavailable and the field is smooth enough for central differences to be valid.
- **When not to use:** Near boundaries where neighbors are missing; for non-smooth fields where truncation error dominates.

## Background
The method is implemented in the `ntsl-graphics` project by tink-expo, where it is used to estimate the Jacobian of a deformation field (`simpleBrush`) for graphics applications [S1, unofficial]. The specific implementation constructs the Jacobian matrix from central difference gradients to support downstream operations such as ODE stepping.
