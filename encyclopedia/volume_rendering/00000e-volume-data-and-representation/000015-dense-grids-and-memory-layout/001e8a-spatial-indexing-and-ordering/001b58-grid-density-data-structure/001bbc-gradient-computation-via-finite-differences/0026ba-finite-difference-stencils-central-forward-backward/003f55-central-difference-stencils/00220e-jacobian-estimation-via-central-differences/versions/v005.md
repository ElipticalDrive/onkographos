# Jacobian Estimation via Central Differences

Also called: Central Difference Jacobian, Finite Difference Jacobian

## Overview
This method estimates the 3x3 Jacobian matrix of a vector-valued function (typically a deformation field or displacement map) at a specific point by computing central differences along each coordinate axis. It differs from its siblings by providing the full local linear transformation matrix rather than just a gradient vector, enabling applications such as inverse mapping for ODE solvers or local affine approximation. It builds on [Finite Difference Stencils (Central/Forward/Backward)](3858-finite-difference-stencils-central-forward-backward.md).

## How it works
**Inputs:**
- A point $\mathbf{p} = (x, y, z)$ in 3D space.
- A vector-valued function $f: \mathbb{R}^3 \to \mathbb{R}^3$, denoted as $f(\mathbf{p}) = (f_x(\mathbf{p}), f_y(\mathbf{p}), f_z(\mathbf{p}))$.
- A step size $\epsilon$ (EPSILON).

**Outputs:**
- A 3x3 Jacobian matrix $J$, where the $i$-th column is the central difference approximation of the partial derivative with respect to the $i$-th axis.

**Data Structures:**
- The Jacobian matrix $J$ is stored as a 3x3 array or matrix structure.
- Temporary vectors for gradient components.

**Steps:**
1. Define the displacement vectors for each axis:
   $$ \mathbf{d}_x = (\epsilon, 0, 0) $$
   $$ \mathbf{d}_y = (0, \epsilon, 0) $$
   $$ \mathbf{d}_z = (0, 0, \epsilon) $$
2. Compute the central difference for the x-axis partial derivatives. This involves evaluating the function at $\mathbf{p} + \mathbf{d}_x$ and $\mathbf{p} - \mathbf{d}_x$:
   $$ \mathbf{g}_x = \frac{f(\mathbf{p} + \mathbf{d}_x) - f(\mathbf{p} - \mathbf{d}_x)}{2\epsilon} $$
   Here, $\mathbf{g}_x$ is a 3D vector representing the column $\frac{\partial f}{\partial x}$.
3. Compute the central difference for the y-axis partial derivatives:
   $$ \mathbf{g}_y = \frac{f(\mathbf{p} + \mathbf{d}_y) - f(\mathbf{p} - \mathbf{d}_y)}{2\epsilon} $$
   $\mathbf{g}_y$ represents the column $\frac{\partial f}{\partial y}$.
4. Compute the central difference for the z-axis partial derivatives:
   $$ \mathbf{g}_z = \frac{f(\mathbf{p} + \mathbf{d}_z) - f(\mathbf{p} - \mathbf{d}_z)}{2\epsilon} $$
   $\mathbf{g}_z$ represents the column $\frac{\partial f}{\partial z}$.
5. Construct the Jacobian matrix $J$ using these vectors as columns:
   $$ J = \begin{bmatrix} | & | & | \\ \mathbf{g}_x & \mathbf{g}_y & \mathbf{g}_z \\ | & | & | \end{bmatrix} $$

**Pseudocode:**
```python
def estimate_jacobian_central_diff(f, p, epsilon):
    """
    Estimate the 3x3 Jacobian matrix of function f at point p using central differences.
    
    Args:
        f: A callable that takes a 3D vector and returns a 3D vector.
        p: A 3D vector (x, y, z).
        epsilon: The step size for finite differences.
        
    Returns:
        A 3x3 matrix (list of lists or similar structure) representing the Jacobian.
    """
    # Define displacement vectors
    dx = (epsilon, 0.0, 0.0)
    dy = (0.0, epsilon, 0.0)
    dz = (0.0, 0.0, epsilon)
    
    # Helper to add vectors
    def add(v1, v2):
        return (v1[0] + v2[0], v1[1] + v2[1], v1[2] + v2[2])
    
    # Helper to subtract vectors
    def sub(v1, v2):
        return (v1[0] - v2[0], v1[1] - v2[1], v1[2] - v2[2])
    
    # Helper to scale vector
    def scale(v, s):
        return (v[0] * s, v[1] * s, v[2] * s)
    
    # Evaluate function at perturbed points
    p_plus_x = add(p, dx)
    p_minus_x = sub(p, dx)
    p_plus_y = add(p, dy)
    p_minus_y = sub(p, dy)
    p_plus_z = add(p, dz)
    p_minus_z = sub(p, dz)
    
    f_plus_x = f(p_plus_x)
    f_minus_x = f(p_minus_x)
    f_plus_y = f(p_plus_y)
    f_minus_y = f(p_minus_y)
    f_plus_z = f(p_plus_z)
    f_minus_z = f(p_minus_z)
    
    # Compute gradient columns
    # g_x = (f(p + dx) - f(p - dx)) / (2 * epsilon)
    diff_x = sub(f_plus_x, f_minus_x)
    g_x = scale(diff_x, 1.0 / (2.0 * epsilon))
    
    # g_y = (f(p + dy) - f(p - dy)) / (2 * epsilon)
    diff_y = sub(f_plus_y, f_minus_y)
    g_y = scale(diff_y, 1.0 / (2.0 * epsilon))
    
    # g_z = (f(p + dz) - f(p - dz)) / (2 * epsilon)
    diff_z = sub(f_plus_z, f_minus_z)
    g_z = scale(diff_z, 1.0 / (2.0 * epsilon))
    
    # Construct Jacobian matrix (columns are g_x, g_y, g_z)
    # J = [[g_x[0], g_y[0], g_z[0]],
    #      [g_x[1], g_y[1], g_z[1]],
    #      [g_x[2], g_y[2], g_z[2]]]
    return [
        [g_x[0], g_y[0], g_z[0]],
        [g_x[1], g_y[1], g_z[1]],
        [g_x[2], g_y[2], g_z[2]]
    ]
```

**Parameters:**
- $\epsilon$ (EPSILON): The step size for finite differences. [S1, unofficial]

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** If $\mathbf{p} \pm \mathbf{d}_i$ falls outside the domain of $f$, the evaluation fails. This requires boundary handling (clamping, extrapolation, or zero-padding) as noted in the parent article [G].
- **Precision:** If $\epsilon$ is too small, subtractive cancellation errors may dominate. If $\epsilon$ is too large, truncation error increases. The optimal $\epsilon$ depends on the scale of the function and floating-point precision.

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation, requiring 6 function evaluations and a constant number of arithmetic operations.
- **Memory Complexity:** $O(1)$, storing only temporary vectors and the resulting 3x3 matrix.
- **Accuracy:** Second-order accurate $O(\epsilon^2)$ for smooth functions, assuming the function is differentiable.
- **Strengths:** Simple to implement; provides full directional derivative information; symmetric stencil reduces bias compared to forward/backward differences.
- **Limitations:** Requires function evaluations at 6 distinct points; sensitive to noise in $f$; fails if $f$ is not differentiable at $\mathbf{p}$.
- **When to use:** When the local linear transformation (Jacobian) is needed for inverse mapping, deformation analysis, or ODE stepping.
- **When not to use:** When only the gradient vector is needed (use [Forward Difference Gradient](3362-forward-difference-gradient.md) or [Sobel Operator](1416-sobel-operator.md) for efficiency); when the function is noisy (consider smoothing first); when boundary effects are significant and cannot be handled.

## Background
This method is a standard application of central difference finite differences to vector fields. It is commonly used in computer graphics for deformation fields, fluid dynamics, and physics simulations where local affine transformations are required. The specific implementation cited here is from a graphics engine context involving marching cubes and deformation brushes [S1, unofficial].
