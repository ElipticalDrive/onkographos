# Local Linear Fitting via PCA

Also called: Local PCA, Local linear fitting

## Overview
Local Linear Fitting via PCA estimates local geometric structure (gradients and orientations) in multivariate volume data by performing Principal Component Analysis on a spatial neighborhood of samples [S1]. It solves the problem of accurate direction reconstruction in sparse or noisy regions where central-sample data is insufficient [S1]. It is distinguished from sibling methods by its use of spatial-domain Monte Carlo sampling to filter spurious correlations, ensuring that fitted directions reflect local spatial continuity rather than global data distribution [S1].

## How it works
**Inputs:** Multivariate volume data $\tau$ with $m$ attributes; spatial domain neighborhood $D$ around central point $x$.
**Outputs:** Local fitting information $f(x)$, consisting of a central point $\xi$ and eigenvectors $\{e_1, \dots, e_m\}$; Saliency map $S_f(x)$ for octree subdivision.

**Data Structures:**
*   **Eigenvectors:** $E = [e_1, e_2, \dots, e_m]$, sorted by descending component variance.
*   **Local Fit:** $f(x) = (\xi, e_1)$ for 1-flat, or $f(x) = (\xi, e_1, e_2)$ for 2-flat [S1].
*   **Saliency Map:** $S_f(x)$, a scalar field used for adaptive octree subdivision.

**Parameters:**
*   $t_s$: Subdivision threshold. A node is subdivided if $\max(S_f) - \min(S_f) > t_s$ [S1].
*   $t_e$: Variance threshold for interpolation. If leaf node variance $< t_e$, use node's linear fit directly. If $t_e \le \text{variance} \le t_s$, interpolate from coarser level [S1].

**Steps:**

1.  **Compute Gradient Magnitude Sum:**
    For each voxel $x$, compute the sum of gradient magnitudes across all $m$ attributes:
    $$ S(x) = \sum_{i=1}^{m} \|\nabla \tau_i(x)\| $$
    where $\tau_i(x)$ is the $i$-th attribute at $x$ [S1].

2.  **Filter Saliency Map:**
    Convolve $S(x)$ with a low-pass filter $\zeta(x)$ to model local neighborhood impact:
    $$ S_f(x) = \zeta(x) * S(x) $$
    This filtered map guides octree subdivision [S1].

3.  **Monte Carlo Sampling:**
    Sample points in the continuous spatial domain neighborhood $D$ of $x$ to approximate volumetric integration [S1].

4.  **Perform PCA:**
    Collect multivariate data values $\tau(D_c)$ from the sampled points. Compute the covariance matrix and derive eigenvectors. Sort eigenvectors $E = [e_1, e_2, \dots, e_m]$ in descending order of component variance [S1].

5.  **Define Local Fitting Information:**
    Extract the central point $\xi$ and the top eigenvectors:
    $$ f(x) = \begin{cases} (\xi, e_1) & \text{for 1-flat} \\ (\xi, e_1, e_2) & \text{for 2-flat} \end{cases} $$
    [S1].

6.  **Handle Interpolation (Octree Context):**
    *   If leaf node variance $< t_e$: Assign the computed linear fit $f(x)$ to all samples in the node [S1].
    *   If $t_e \le \text{variance} \le t_s$: Interpolate local fitting information from a coarser level using extended spectrum-sine interpolation [S1].

7.  **Spectrum-Sine Interpolation:**
    Compute weights for interpolation based on distance $d_i$ and angle $\theta$:
    $$ \theta = \max_{i,j=1,\dots,8, i \neq j, k=1,2} \arccos(e_{ki}, e_{kj}) $$
    where $e_{ki}$ is the $k$-th component of the $i$-th eigenvector [S1]. Use $d_i$ (distance to neighbors) and $\theta$ to compute weights, avoiding component-wise interpolation which is error-prone [S1].

    """
    Sf(x) = zeta(x) * S(x)
    """
    return np.convolve(grad_sum, filter_kernel, mode='same')

def monte_carlo_sample_neighborhood(center_pos, neighborhood_radius, num_samples):
    """
    Samples points in continuous spatial domain D around center_pos.
    """
    # Generate random points within bounding box of neighborhood
    samples = np.random.uniform(
        center_pos - neighborhood_radius, 
        center_pos + neighborhood_radius, 
        (num_samples, 3)
    )
    return samples

    Performs PCA on data values at sampled locations.
    Returns sorted eigenvectors E.
    """

    # Center data
    mean = np.mean(data_values, axis=0)
    centered = data_values - mean
    
    # Covariance matrix
    cov = np.cov(centered.T)
    
    # Eigendecomposition
    eigenvalues, eigenvectors = np.linalg.eigh(cov)
    
    # Sort by descending eigenvalue (variance)
    sorted_indices = np.argsort(eigenvalues)[::-1]
    sorted_eigenvectors = eigenvectors[:, sorted_indices]
    
    return sorted_eigenvectors

def compute_angle_theta(eigenvectors):
    """
    theta = max arccos(e_ki, e_kj) for k=1,2 and i!=j
    """
    # Take top 2 eigenvectors
    top_eigs = eigenvectors[:, :2]
    max_theta = 0.0
    for i in range(top_eigs.shape[1]):
        for j in range(top_eigs.shape[1]):
            if i != j:
                # Dot product of columns
                dot = np.dot(top_eigs[:, i], top_eigs[:, j])
                # Clamp for numerical stability
                dot = np.clip(dot, -1.0, 1.0)
                angle = np.arccos(dot)
                if angle > max_theta:
                    max_theta = angle
    return max_theta

## Operating characteristics
*   **Time Complexity:** Dominated by Monte Carlo sampling and PCA per voxel/node. PCA is $O(m^3)$ or $O(m^2 n)$ depending on implementation, where $m$ is attributes and $n$ is samples. Spatial sampling adds overhead compared to direct stencil methods.
*   **Memory Complexity:** Requires storing the saliency map $S_f$ and the local fitting information $(\xi, e_1, e_2)$ for each voxel or octree leaf. The resulting volume size may differ from input but is typically full-sized for visualization [S1].
*   **Strengths:** Filters spurious correlations by enforcing spatial constraints, resulting in clearer, less cluttered visualizations than data-domain PCA [S1]. Handles multivariate data naturally.
*   **Limitations:** Direction information $(e_1, e_2)$ is sensitive; using only central sample data is insufficient, requiring interpolation or larger neighborhoods [S1]. Computationally more expensive than simple finite differences.
*   **When to use:** When accurate local orientation and gradient estimation is critical for multivariate volume visualization, especially in regions with complex spatial structures.
*   **When not to use:** When computational resources are severely limited and approximate gradients suffice.

## Background
Originated in the context of continuous indexed points for multivariate volume visualization [S1]. The method leverages PCA's ability to minimize the L2-norm of fitted data, offering good explainability [S1]. It addresses limitations of data-domain computation by introducing spatial neighborhood constraints, which are essential for analyzing spatial data [S1]. The approach extends spectrum-sine interpolation to handle eigenvector interpolation, avoiding errors associated with component-wise interpolation [S1].
