# Gradient Selection — Central/Forward/Backward

Also called: Finite Difference Gradient Selection, Gradient Calculation

## Overview
This method selects the appropriate finite difference stencil to estimate the gradient (slope) of a scalar volume field at a specific axis index, adapting to boundary conditions. It distinguishes itself from precomputed gradient storage by computing the derivative on-the-fly and from Sobel operators by using 1D stencils rather than 3D kernels. It serves as the core logic for the `gradientMode` selection in parent [Gradient Selection](5889-gradient-selection.md).

## How it works
**Inputs:**
- `i`: The integer axis index being evaluated (typically $z$).
- `min`: The minimum valid axis value (typically $0$).
- `max`: The maximum valid axis value (typically $N-1$, where $N$ is the axis length).
- `V`: The volume data array.
- `getVoxel(idx)`: A function returning the scalar value at integer index `idx`.
- `getRealVoxel(pos)`: A function returning the interpolated scalar value at a non-integer position `pos` (used for non-integer axis positions) [S1, unofficial].

**Outputs:**
- `gradient`: The estimated 1D derivative value along the specified axis.

**Data Structures:**
- The volume data $V$ is assumed to be accessible via indexing. No explicit gradient storage structure is created by this specific selection logic; the gradient is computed and returned immediately.

**Steps:**
1. Determine the stencil type based on the position of `i` relative to the boundaries `min` and `max`.
2. If `i` is strictly interior ($min < i < max - 1$), apply the **Central Difference** stencil.
3. If `i` is at or below the lower boundary ($i \le min$), apply the **Forward Difference** stencil.
4. If `i` is at or above the upper boundary ($i \ge max - 1$), apply the **Backward Difference** stencil.
5. For non-integer axis positions, replace integer voxel accesses with `getRealVoxel` calls to support interpolation [S1, unofficial].

**Formulas:**
Let $V_i$ denote the value at index $i$. The step size $h$ is assumed to be $1$ for discrete indices.

- **Central Difference** (Interior):
  $$ \nabla V_i = V_{i+1} - V_{i-1} $$
  Condition: $min < i < max - 1$

- **Forward Difference** (Lower Boundary):
  $$ \nabla V_i = V_{i+1} - V_i $$
  Condition: $i \le min$

- **Backward Difference** (Upper Boundary):
  $$ \nabla V_i = V_i - V_{i-1} $$
  Condition: $i \ge max - 1$

**Parameters:**
- `i`: Axis index.
- `min`: Minimum valid index (default $0$) [S1, unofficial].
- `max`: Maximum valid index (default axis length - 1) [S1, unofficial].

**Pseudocode:**
```python
def compute_gradient_selection(i, min_val, max_val, get_voxel, get_real_voxel, is_integer=True):
    """
    Selects and computes the gradient using central, forward, or backward differences.
    
    Args:
        i: The axis index (float or int).
        min_val: Minimum valid axis value.
        max_val: Maximum valid axis value.
        get_voxel: Function to get value at integer index.
        get_real_voxel: Function to get interpolated value at float position.
        is_integer: Boolean flag indicating if i is an integer index.
        
    Returns:
        The estimated gradient value.
    """
    # Helper to get value based on interpolation mode
    def get_val(idx):
        if is_integer:
            return get_voxel(idx)
        else:
            return get_real_voxel(idx)

    # Check boundaries
    # Note: max_val is typically the last valid index (N-1).
    # The condition i >= max - 1 implies the last two indices use backward difference.
    
    if i <= min_val:
        # Forward difference at lower boundary
        # V[i+1] - V[i]
        val_next = get_val(i + 1)
        val_curr = get_val(i)
        return val_next - val_curr
        
    elif i >= max_val - 1:
        # Backward difference at upper boundary
        # V[i] - V[i-1]
        val_curr = get_val(i)
        val_prev = get_val(i - 1)
        return val_curr - val_prev
        
    else:
        # Central difference for interior points
        # V[i+1] - V[i-1]
        val_next = get_val(i + 1)
        val_prev = get_val(i - 1)
        return val_next - val_prev
```

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** The choice of forward/backward difference at boundaries reduces accuracy from $O(h^2)$ to $O(h)$ [S1, unofficial].
- **Non-Integer Positions:** If `i` is not an integer, `getVoxel` must be replaced by `getRealVoxel` to maintain continuity, as specified in the source [S1, unofficial].
- **Index Bounds:** Ensure `i+1` and `i-1` do not exceed array bounds. The logic `i <= min` and `i >= max - 1` handles the edges, but `max` must be defined as the last valid index.

## Subtopics

### [Gradient Estimation via On-the-Fly Interpolation](13587-gradient-estimation-via-on-the-fly-interpolation.md)
Estimates gradients at arbitrary sample points during ray casting using on-the-fly central differences, avoiding precomputation. Chosen when memory bandwidth for precomputed gradients is a bottleneck and arbitrary point evaluation is required.

## Operating characteristics
- **Time Complexity:** $O(1)$ per gradient evaluation.
- **Memory Complexity:** $O(1)$ auxiliary space (no precomputed gradient grid).
- **Strengths:** Low memory overhead; simple implementation; adapts to boundaries without special padding.
- **Limitations:** Lower accuracy at boundaries ($O(h)$ vs $O(h^2)$); requires repeated computation if the same gradient is needed multiple times.
- **When to use:** When memory is constrained or when gradients are needed only at specific, sparse points.
- **When not to use:** When high accuracy at boundaries is critical or when gradients are needed densely across the volume (precomputation or Sobel may be better).

## Background
This method is derived from standard finite difference techniques for numerical differentiation. The specific selection logic (central for interior, forward/backward for boundaries) is implemented in the `CTViewer` class of the `joshcodd/volume-rendering` project [S1, unofficial]. It is a fundamental component of gradient-based volume rendering techniques, such as those used in transfer function design and shading.
