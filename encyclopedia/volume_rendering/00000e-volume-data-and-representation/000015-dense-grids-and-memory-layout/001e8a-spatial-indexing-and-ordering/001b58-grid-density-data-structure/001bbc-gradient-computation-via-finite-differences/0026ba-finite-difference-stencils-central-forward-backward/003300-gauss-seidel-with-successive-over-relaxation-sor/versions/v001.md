# Gauss-Seidel with Successive Over-Relaxation (SOR)

Also called: Gauss-Seidel SOR, Gauss-Seidel with Successive Over-Relaxation (SOR) for 3D Heat Conduction, Iterative Laplace Solver

## Overview
Gauss-Seidel with Successive Over-Relaxation (SOR) is an iterative numerical method used to solve the steady-state heat equation (Laplace equation $\nabla^2 T = 0$) on a 3D uniform Cartesian grid [S1, unofficial]. It updates grid points using the most recently computed neighbor values (Gauss-Seidel) and accelerates convergence by applying a relaxation factor $\omega > 1$ (Successive Over-Relaxation) [S1, unofficial]. Unlike direct solvers or Jacobi iteration, SOR exploits data locality and sequential dependency to reduce the number of iterations required for convergence, making it suitable for dense grid representations in volume rendering where smooth scalar fields are assumed [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D scalar field (temperature) $T$ of shape $(n_x, n_y, n_z)$, boundary conditions (Dirichlet and Neumann), and solver parameters ($\omega$, tolerance, max iterations).
- **Output:** The converged scalar field $T$ satisfying the Laplace equation within the specified tolerance.

**Data Structures:**
- **Temperature Field:** A 3D array of shape $(n_x, n_y, n_z)$ with floating-point dtype. Indices $(i, j, k)$ correspond to grid points in the x, y, and z directions respectively [S1, unofficial].

**Algorithm Steps:**
1. **Initialization:** Initialize the temperature field with a linear profile between the hot and cold boundaries to reduce iteration count [S1, unofficial].
   $$ T[i, j, k] = T_{hot} + (T_{cold} - T_{hot}) \cdot \frac{k}{n_z - 1} $$
2. **Boundary Conditions:** Apply Dirichlet conditions on the top and bottom faces ($k=0$ and $k=n_z-1$) and Neumann (adiabatic, zero-gradient) conditions on the side walls ($i=0, i=n_x-1, j=0, j=n_y-1$) by copying values from adjacent interior cells [S1, unofficial].
3. **Iteration Loop:** For each iteration up to `max_iterations`:
   a. Initialize `max_residual` to 0.0.
   b. Iterate over all interior points $i \in [1, n_x-2]$, $j \in [1, n_y-2]$, $k \in [1, n_z-2]$.
   c. Compute the sum of the six immediate neighbors:
      $$ \text{neighbor\_sum} = T[i+1,j,k] + T[i-1,j,k] + T[i,j+1,k] + T[i,j-1,k] + T[i,j,k+1] + T[i,j,k-1] $$
   d. Compute the tentative new value from the Laplace equation (average of neighbors):
      $$ T_{new} = \frac{\text{neighbor\_sum}}{6.0} $$
   e. Compute the residual for this point:
      $$ \text{residual} = |T_{new} - T[i,j,k]| $$
   f. Update `max_residual`:
      $$ \text{max\_residual} = \max(\text{max\_residual}, \text{residual}) $$
   g. Apply the SOR update:
      $$ T[i,j,k] = (1 - \omega) \cdot T[i,j,k] + \omega \cdot T_{new} $$
4. **Boundary Re-application:** After updating all interior points, re-apply boundary conditions to ensure Dirichlet values remain fixed and Neumann conditions are maintained [S1, unofficial].
5. **Convergence Check:** If `max_residual` < `tolerance`, terminate and return the current iteration count. Otherwise, continue.

**Pseudocode:**
```python
def solve_gauss_seidel_sor(T, nx, ny, nz, t_hot, t_cold, omega, tolerance, max_iterations):
    """
    Solve the 3D steady-state heat equation using Gauss-Seidel with SOR.
    
    Args:
        T: 3D numpy array of shape (nx, ny, nz)
        nx, ny, nz: Dimensions of the grid
        t_hot: Temperature at bottom boundary (k=0)
        t_cold: Temperature at top boundary (k=nz-1)
        omega: SOR relaxation parameter (1 < omega < 2)
        tolerance: Convergence threshold for max residual
        max_iterations: Maximum number of iterations
        
    Returns:
        T: Converged temperature field
        iterations: Number of iterations performed
    """
    # Step 1: Initialize with linear profile
    for k in range(nz):
        z_ratio = k / (nz - 1)
        T[:, :, k] = t_hot + (t_cold - t_hot) * z_ratio
        
    # Step 2: Apply initial boundary conditions
    apply_boundary_conditions(T, nx, ny, nz, t_hot, t_cold)
    
    iterations = 0
    for iteration in range(1, max_iterations + 1):
        max_residual = 0.0
        
        # Step 3: Iterate over interior points
        for i in range(1, nx - 1):
            for j in range(1, ny - 1):
                for k in range(1, nz - 1):
                    # Calculate neighbor sum
                    neighbor_sum = (
                        T[i + 1, j, k] + T[i - 1, j, k] +
                        T[i, j + 1, k] + T[i, j - 1, k] +
                        T[i, j, k + 1] + T[i, j, k - 1]
                    )
                    
                    # Calculate tentative new value
                    t_new = neighbor_sum / 6.0
                    
                    # Calculate residual
                    residual = abs(t_new - T[i, j, k])
                    if residual > max_residual:
                        max_residual = residual
                        
                    # Apply SOR update
                    T[i, j, k] = (1 - omega) * T[i, j, k] + omega * t_new
        
        # Step 4: Re-apply boundary conditions
        apply_boundary_conditions(T, nx, ny, nz, t_hot, t_cold)
        
        iterations = iteration
        
        # Step 5: Check convergence
        if max_residual < tolerance:
            break
            
    return T, iterations

def apply_boundary_conditions(T, nx, ny, nz, t_hot, t_cold):
    """Apply Dirichlet and Neumann boundary conditions."""
    # Dirichlet: Fixed temperature on top and bottom
    T[:, :, 0] = t_hot
    T[:, :, -1] = t_cold
    
    # Neumann: Zero gradient on side walls (copy from interior)
    T[0, :, :] = T[1, :, :]
    T[-1, :, :] = T[-2, :, :]
    T[:, 0, :] = T[:, 1, :]
    T[:, -1, :] = T[:, -2, :]
```

**Parameters:**
- **$\omega$ (omega):** SOR relaxation parameter. Typical value is 1.5. Optimal range is 1.5–1.9. Must be $1 < \omega < 2$ for over-relaxation [S1, unofficial].
- **tolerance:** Convergence criterion based on max equation residual. Typical value is $10^{-5}$ [S1, unofficial].
- **max_iterations:** Maximum number of iterations allowed. Typical value is 5000 [S1, unofficial].

**Edge Cases and Pitfalls:**
- Boundary conditions must be reapplied after each iteration to maintain fixed Dirichlet values and zero-gradient Neumann conditions [S1, unofficial].
- If $\omega \ge 2$, the method may diverge. If $\omega \le 1$, it reduces to standard Gauss-Seidel or under-relaxation, which converges slower [S1, unofficial].
- The stencil assumes a uniform grid with spacing $h$ in all directions. Non-uniform grids require modified coefficients [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ per iteration, where $N = n_x \cdot n_y \cdot n_z$ is the number of grid points. Total time depends on the number of iterations required for convergence, which is reduced by SOR compared to Jacobi or standard Gauss-Seidel.
- **Memory Complexity:** $O(N)$ for storing the 3D temperature field. No additional large data structures are required.
- **Performance:** Convergence speed is highly dependent on the choice of $\omega$. Optimal $\omega$ can reduce iterations significantly compared to non-relaxed methods. For a $50 \times 50 \times 50$ grid, convergence to $10^{-5}$ tolerance typically takes fewer than 5000 iterations with $\omega \approx 1.5$ [S1, unofficial].
- **Strengths:** Simple to implement, low memory footprint, exploits data locality, faster convergence than Jacobi.
- **Limitations:** Sequential nature limits parallelization. Convergence can be slow for large grids or ill-conditioned problems. Sensitive to the choice of $\omega$.
- **When to use:** Suitable for small to medium-sized dense grids where smooth scalar fields are expected and parallelization is not critical. Not ideal for very large grids or real-time applications requiring immediate results.
- **When not to use:** For large-scale problems, multigrid methods or direct solvers may be more efficient. For non-uniform grids, specialized stencils are required.

## Background
The method originates from the numerical solution of the steady-state heat equation (Laplace equation) in 3D domains. It combines the Gauss-Seidel iterative method, which uses updated values immediately, with Successive Over-Relaxation (SOR), a technique to accelerate convergence by extrapolating the update step [S1, unofficial]. The specific implementation described here is adapted for volume rendering contexts, where the scalar field represents temperature or another physical quantity that needs to be smoothed or solved for equilibrium [S1, unofficial].
