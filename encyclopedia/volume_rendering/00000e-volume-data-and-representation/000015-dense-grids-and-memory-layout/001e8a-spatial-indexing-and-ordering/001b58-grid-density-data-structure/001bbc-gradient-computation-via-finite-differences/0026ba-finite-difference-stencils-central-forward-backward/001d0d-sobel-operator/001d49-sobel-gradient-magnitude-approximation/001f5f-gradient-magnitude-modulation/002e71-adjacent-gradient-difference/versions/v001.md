# Adjacent Gradient Difference

Also called: Gradient Magnitude Increase Measure

## Overview
Adjacent Gradient Difference is a volume rendering modulation technique that calculates importance by comparing the gradient magnitudes of two adjacent samples along a viewing ray. It increases accumulated transparency whenever an increase in gradient magnitude is detected, distinguishing itself from Maximum Gradient Magnitude measures by producing a more transparent look with a wider dynamic range [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The current sample's gradient magnitude ($\text{grad}_i$) and the previous sample's gradient magnitude ($\text{grad}_{i-1}$).
*   **Output:** A modulation factor $\beta$ used to adjust accumulated transparency.

**Data Structures:**
No specific complex data structures are required beyond the scalar values of the gradient magnitudes at the current and previous ray marching steps.

**Steps:**
1.  Retrieve the gradient magnitude of the current sample, $\text{grad}_i$.
2.  Retrieve the gradient magnitude of the previous sample, $\text{grad}_{i-1}$.
3.  Calculate the modulation factor $\beta$ using the piecewise function defined below.
4.  Apply $\beta$ to the accumulated transparency update.

**Formula:**
The modulation factor $\beta$ is calculated as [S1]:

$$
\beta = B(\Delta_{imp}(\text{grad}_i, \text{grad}_{i-1})) = 
\begin{cases} 
1 - (\text{grad}_i - \text{grad}_{i-1}) & \text{if } \text{grad}_i > \text{grad}_{i-1} \\ 
1 & \text{otherwise} 
\end{cases}
$$

Where:
*   $\text{grad}_i$ is the gradient magnitude of the current sample.
*   $\text{grad}_{i-1}$ is the gradient magnitude of the previous sample.

**Parameters:**
Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Clamping:** The term $1 - (\text{grad}_i - \text{grad}_{i-1})$ can theoretically exceed 1 or drop below 0 if the difference is large. The sources do not explicitly specify clamping behavior, but standard practice for modulation factors implies a range of $[0, 1]$. [G]
*   **Boundary Conditions:** For the first sample in a ray, $\text{grad}_{i-1}$ is undefined. [G] Typically initialized to 0 or the value of the first sample.

**Pseudocode:**
```python
def compute_modulation_factor(grad_current, grad_previous):
    """
    Computes the modulation factor beta for Adjacent Gradient Difference.
    
    Args:
        grad_current (float): Gradient magnitude of the current sample.
        grad_previous (float): Gradient magnitude of the previous sample.
        
    Returns:
        float: Modulation factor beta.
    """
    if grad_current > grad_previous:
        beta = 1.0 - (grad_current - grad_previous)
        # [G] Clamp to [0, 1] to prevent invalid transparency values
        beta = max(0.0, min(1.0, beta))
    else:
        beta = 1.0
    return beta
```

## Subtopics

### [Scalar Intensity Increase Measure](6014-scalar-intensity-increase-measure.md)
Uses scalar intensity differences between adjacent samples instead of gradient magnitudes. Choose this when gradient computation is too expensive or when scalar intensity jumps are more relevant to the features of interest.

## Operating characteristics
**Time and Memory Complexity:**
The method requires constant time $O(1)$ per sample and constant memory $O(1)$ to store the previous gradient magnitude.

**Measured Performance:**
Compared to the maximum gradient magnitude measure, this method produces a more transparent look because more samples along the viewing ray contribute to the final result [S1]. It tends to have a wider dynamic range, particularly if the dataset contains many non-transparent voxels [S1].

**Strengths and Limitations:**
*   **Strengths:** Reveals sharp features effectively (similar to maximum gradient magnitude projection) while maintaining a more natural, transparent appearance [S1]. The wider dynamic range allows for effective tone-mapping (brightness/contrast, gamma curve) for fast data exploration [S1].
*   **Limitations:** The wider dynamic range may require additional post-processing (tone-mapping) to fit standard display ranges [S1].

**When to Use:**
Use when a balance between feature sharpness and overall scene transparency is desired, and when the dataset benefits from a wider dynamic range that can be tone-mapped.

**When Not to Use:**
Avoid if a highly opaque, maximum-intensity-like projection is required, or if the dynamic range cannot be handled by the display pipeline.

## Background
Originating from the work on Fast Volumetric Data Exploration with Importance-Based Accumulated Transparency Modulation, this method was introduced to improve upon direct volume rendering and maximum gradient magnitude projection techniques [S1]. It was developed to better reveal sharp features of datasets while addressing the opacity issues of maximum gradient magnitude measures.
