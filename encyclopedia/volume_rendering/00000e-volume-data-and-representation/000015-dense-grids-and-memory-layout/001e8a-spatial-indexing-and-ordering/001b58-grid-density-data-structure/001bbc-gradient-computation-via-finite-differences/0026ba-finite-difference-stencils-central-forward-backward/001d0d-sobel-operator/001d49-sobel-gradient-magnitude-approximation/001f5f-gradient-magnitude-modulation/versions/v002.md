# Gradient Magnitude Modulation

Also called: Gradient Magnitude Approximation, Gradient Magnitude Illumination Modulation, Gradient Magnitude Opacity Modulation

## Overview
Gradient Magnitude Modulation is a post-processing step in volume rendering that uses the computed gradient magnitude to modulate sample opacity and illumination values [S1, unofficial]. It emphasizes surface boundaries by increasing opacity and brightness where gradients are high, while de-emphasizing homogeneous regions and noise where gradients are small [S1, unofficial]. It differs from the underlying [Sobel Gradient Magnitude Approximation](1429-sobel-gradient-magnitude-approximation.md) by adding a lookup-based mapping and the final multiplication step, rather than just computing the raw magnitude value [S1, unofficial].

## How it works
**Inputs:**
- Gradient magnitude approximation $M$, an 8-bit approximation in the range $[0, 2^{20}]$ derived from the previous stage [S1, unofficial].
- Current sample opacity $\alpha$ and illumination $I$ (diffuse/specular) [S1, unofficial].
- Three control registers: `Gmimd` (Gradient Magnitude Illumination Modulation for diffuse), `Gmims` (for specular), and `Gmom` (Gradient Magnitude Opacity Modulation) [S1, unofficial].
- Gradient Magnitude Lookup Table (GmLUT) [S1, unofficial].

**Outputs:**
- Modulated opacity $\alpha'$ and illumination $I'$ [S1, unofficial].
- Modulation value $m \in [0, 1]$ [S1, unofficial].

**Data Structures:**
- **GmLUT**: A table of eight entries specifying points of a piece-wise linear function at equal intervals along the gradient magnitude axis [S1, unofficial]. The output values of the table entries represent the modulation factor [S1, unofficial].

**Steps:**
1. **Compute Squared Magnitude**: Calculate the sum of the squares of the gradient components $(g_x, g_y, g_z)$ [S1, unofficial]. Each component has signed 8-bit precision in the range $[-127, 127]$ [S1, unofficial].
   $$ S = g_x^2 + g_y^2 + g_z^2 $$
2. **Approximate Square Root**: Use a Newton-Raphson iteration to compute the square root of $S$, resulting in the 8-bit approximation $M$ in the range $[0, 2^{20}]$ [S1, unofficial].
3. **Map to Lookup Index**: Map the magnitude $M$ into the range $[0, 255]$ using the piece-wise linear function defined by GmLUT [S1, unofficial]. Since GmLUT has 8 entries at equal intervals, the input domain $[0, 2^{20}]$ is divided into 7 segments [S1, unofficial]. The index $i$ for the table is determined by scaling $M$ to $[0, 255]$ and identifying the segment [S1, unofficial].
4. **Interpolate Modulation Value**: Perform linear interpolation between the two nearest table values in GmLUT to compute the 8-bit repeating-fraction modulation value $m$ [S1, unofficial]. This value represents a float in the range $[0, 1]$ [S1, unofficial].
5. **Apply Modulation**:
   - If `Gmom` is enabled, compute $\alpha' = \alpha \times m$ [S1, unofficial].
   - If `Gmimd` is enabled, compute $I'_{diffuse} = I_{diffuse} \times m$ [S1, unofficial].
   - If `Gmims` is enabled, compute $I'_{specular} = I_{specular} \times m$ [S1, unofficial].

**Pseudocode:**
```python
def gradient_magnitude_modulation(gx, gy, gz, alpha, I_diffuse, I_specular, 
                                  Gmimd, Gmims, Gmom, GmLUT):
    """
    gx, gy, gz: signed 8-bit integers representing gradient components in [-127, 127].
    alpha: current sample opacity.
    I_diffuse, I_specular: current illumination values.
    Gmimd, Gmims, Gmom: boolean flags enabling modulation for diffuse, specular, and opacity respectively.
    GmLUT: list of 8 floats representing the piece-wise linear function values.
    Returns: modulated_alpha, modulated_I_diffuse, modulated_I_specular
    """
    # Step 1: Compute squared magnitude
    S = gx*gx + gy*gy + gz*gz
    
    # Step 2: Newton-Raphson square root approximation
    # Result M is an 8-bit approximation in range [0, 2^20]
    x = S / 2.0 if S > 0 else 0.0
    for _ in range(4):
        if x == 0:
            break
        x = 0.5 * (x + S / x)
    M = x
    
    # Step 3 & 4: Map M to [0, 255] and interpolate using GmLUT
    # GmLUT has 8 entries at equal intervals along the gradient magnitude axis.
    max_mag = 2**20
    num_entries = 8
    step = max_mag / (num_entries - 1)
    
    idx = int(M / step)
    idx = min(idx, num_entries - 2)  # Clamp to valid interpolation pair
    frac = (M - idx * step) / step
    
    val_low = GmLUT[idx]
    val_high = GmLUT[idx + 1]
    
    # Linear interpolation yields the 8-bit repeating-fraction value in [0, 1]
    m = val_low + frac * (val_high - val_low)
    m = max(0.0, min(1.0, m))
    
    # Step 5: Apply modulation
    mod_alpha = alpha
    mod_I_diffuse = I_diffuse
    mod_I_specular = I_specular
    
    if Gmom:
        mod_alpha = alpha * m
    if Gmimd:
        mod_I_diffuse = I_diffuse * m
    if Gmims:
        mod_I_specular = I_specular * m
        
    return mod_alpha, mod_I_diffuse, mod_I_specular
```

**Parameters:**
- `GmLUT`: 8-entry table defining the piece-wise linear mapping [S1, unofficial].
- `Gmimd`, `Gmims`, `Gmom`: Boolean registers enabling the modulation [S1, unofficial].

**Edge Cases:**
- Zero gradient: Results in $m=0$ (if LUT maps 0 to 0) or the base LUT value, effectively removing the sample from view if opacity is modulated [S1, unofficial].
- Noise: Small gradients in noisy data result in low modulation values, reducing visual impact [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Constant time per sample, involving a few arithmetic operations and a table lookup/interpolation [S1, unofficial].
- **Memory Complexity**: Requires storage for the GmLUT (8 entries) and 3 control registers [S1, unofficial].
- **Strengths**: Effectively emphasizes surface boundaries and reduces noise artifacts by attenuating samples with small gradients [S1, unofficial].
- **Limitations**: Relies on the accuracy of the gradient magnitude approximation; incorrect LUT configuration can lead to over- or under-emphasis of features [S1, unofficial].
- **When to use**: When surface definition is critical and noise reduction is desired [S1, unofficial].

## Background
Gradient Magnitude Modulation is part of the VolumePro real-time ray-casting system [S1, unofficial]. It was introduced in the VolumePro architecture to provide flexible control over surface appearance and noise handling [S1, unofficial]. The method builds on the Sobel Gradient Magnitude Approximation to provide a computationally efficient way to modulate rendering parameters [S1, unofficial].
