# Sharded Gradient Computation
## Overview
Sharded Gradient Computation computes the spatial gradients ($g_x, g_y, g_z$) of a volumetric dataset partitioned into shards across multiple devices, specifically handling boundary conditions between shards in the z-dimension [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A volume $V$ partitioned into $N$ shards along the z-dimension. Each shard $i$ contains a 3D array $A_i$ [S1, unofficial].
- Output: Three gradient shards $G_x, G_y, G_z$, each matching the input volume structure (same number of shards and local shapes) [S1, unofficial].

**Data Structures:**
- `shards`: A list of 3D arrays representing the partitioned volume.
- `xp`: The array library (e.g., NumPy, CuPy) used for computation.
- `devices`: A list of device contexts corresponding to each shard [G].

**Steps:**
1. Initialize output gradient shards $G_x, G_y, G_z$ with zeros matching the input volume structure [S1, unofficial].
2. Iterate over each shard index $i$ from $0$ to $N-1$ and its corresponding array $A$ [S1, unofficial].
3. Compute $G_x$ for the current shard using forward differences on the last dimension: $G_x[i, :, :, :-1] = A[:, :, 1:] - A[:, :, :-1]$ [S1, unofficial].
4. Compute $G_y$ for the current shard using forward differences on the middle dimension: $G_y[i, :, :-1, :] = A[:, 1:, :] - A[:, :-1, :]$ [S1, unofficial].
5. Compute $G_z$ for internal rows of the current shard using forward differences on the first dimension: $G_z[i, :-1, :, :] = A[1:, :, :] - A[:-1, :, :]$ (only if $A.shape[0] > 1$) [S1, unofficial].
6. Handle the boundary between the current shard and the next shard for the $G_z$ gradient: if $i + 1 < N$, switch device context to the next shard's device, extract the first row of the next shard ($A_{next\_first} = \text{shards}[i+1][0, :, :]$), and compute the last row of the current shard's $G_z$ as $G_z[i, -1, :, :] = A_{next\_first} - A[-1, :, :]$ [S1, unofficial].

**Pseudocode:**
```python
def compute_sharded_gradients(shards, xp, devices):
    """
    shards: list of 3D arrays [z, y, x]
    xp: array library (e.g., numpy, cupy)
    devices: list of device contexts corresponding to each shard
    """
    num_shards = len(shards)
    # Initialize output gradient shards with zeros matching input volume structure
    gx_shards = [xp.zeros_like(s) for s in shards]
    gy_shards = [xp.zeros_like(s) for s in shards]
    gz_shards = [xp.zeros_like(s) for s in shards]

    for i in range(num_shards):
        A = shards[i]
        gx = gx_shards[i]
        gy = gy_shards[i]
        gz = gz_shards[i]

        # Compute gx using forward differences on the last dimension
        if A.shape[2] > 1:
            gx[..., :-1] = A[..., 1:] - A[..., :-1]

        # Compute gy using forward differences on the middle dimension
        if A.shape[1] > 1:
            gy[:, :-1, :] = A[:, 1:, :] - A[:, :-1, :]

        # Compute gz for internal rows using forward differences on the first dimension
        if A.shape[0] > 1:
            gz[:-1, :, :] = A[1:, :, :] - A[:-1, :, :]

        # Handle boundary between current shard and next shard for gz
        if i + 1 < num_shards:
            with devices[i + 1]:
                next_first = xp.asarray(shards[i + 1][0, :, :])
            # next_first is now accessible on the current device (or via unified memory)
            gz[-1, :, :] = next_first - A[-1, :, :]

    return gx_shards, gy_shards, gz_shards
```

**Parameters:**
- Shard count: Configurable via `config.zsharded_admm.shard_count` [S1, unofficial].
