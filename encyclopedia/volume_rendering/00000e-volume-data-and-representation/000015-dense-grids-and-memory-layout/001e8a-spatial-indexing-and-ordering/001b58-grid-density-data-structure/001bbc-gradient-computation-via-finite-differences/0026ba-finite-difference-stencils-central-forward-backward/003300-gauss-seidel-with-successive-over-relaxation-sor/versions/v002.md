# Gauss-Seidel with Successive Over-Relaxation (SOR)
Also called: Gauss-Seidel SOR, Gauss-Seidel with Successive Over-Relaxation (SOR) for 3D Heat Conduction, Iterative Laplace Solver

## Overview
Gauss-Seidel with Successive Over-Relaxation (SOR) is an iterative numerical method used to solve the steady-state heat equation (Laplace equation $\nabla^2 T = 0$) on a 3D grid [S1, unofficial]. It updates grid points using the latest available neighbor values (Gauss-Seidel) and accelerates convergence by over-relaxing the update step (SOR) [S1, unofficial]. It is distinct from standard Jacobi iteration by using in-place updates and from standard Gauss-Seidel by the inclusion of a relaxation parameter $\omega > 1$ to reduce the number of iterations required for convergence [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D grid of dimensions $n_x \times n_y \times n_z$, boundary conditions (Dirichlet and/or Neumann), an initial temperature field $T$, the SOR relaxation parameter $\omega$, a convergence tolerance $\epsilon$, and a maximum iteration count $N_{max}$.
- **Output:** The converged temperature field $T$ satisfying the Laplace equation within the specified tolerance.

**Data Structures:**
- **Temperature Field:** A 3D array of shape $(n_x, n_y, n_z)$ with floating-point dtype. Indices $(i, j, k)$ correspond to grid points in the x, y, and z directions respectively [S1, unofficial].

**Parameters:**
- $\omega$: SOR relaxation parameter. Typical value is 1.5, with an optimal range of $1.5 \le \omega < 2.0$ [S1, unofficial].
- $\epsilon$: Convergence criterion based on the maximum equation residual. Typical value is $10^{-5}$ [S1, unofficial].
- $N_{max}$: Maximum number of iterations. Typical value is 5000 [S1, unofficial].

**Steps:**
1. **Initialization:** Initialize the temperature field $T$. A linear interpolation between boundary temperatures is recommended to reduce iterations: $T[i, j, k] = T_{hot} + (T_{cold} - T_{hot}) \frac{k}{n_z - 1}$ [S1, unofficial].
2. **Boundary Conditions:** Apply boundary conditions.
   - **Dirichlet:** Set fixed values on specific faces (e.g., bottom face $k=0$ to $T_{hot}$, top face $k=n_z-1$ to $T_{cold}$) [S1, unofficial].
   - **Neumann:** Apply zero-gradient conditions on side walls by copying values from adjacent interior cells (e.g., $T[0, :, :] = T[1, :, :]$) [S1, unofficial].
3. **Iteration Loop:** For each iteration $iter$ from 1 to $N_{max}$:
   a. Initialize `max_residual` to 0.
   b. Loop over interior points $i \in [1, n_x-2]$, $j \in [1, n_y-2]$, $k \in [1, n_z-2]$:
      i. Calculate the sum of the six immediate neighbors:
         $$ S = T[i+1, j, k] + T[i-1, j, k] + T[i, j+1, k] + T[i, j-1, k] + T[i, j, k+1] + T[i, j, k-1] $$
      ii. Calculate the tentative new value from the Laplace equation (average of neighbors):
         $$ T_{new} = \frac{S}{6} $$
      iii. Calculate the residual for this point:
         $$ r = |T_{new} - T[i, j, k]| $$
      iv. Update `max_residual`:
         $$ \text{max\_residual} = \max(\text{max\_residual}, r) $$
      v. Apply the SOR update:
         $$ T[i, j, k] = (1 - \omega) T[i, j, k] + \omega T_{new} $$
   c. Re-apply boundary conditions to ensure Dirichlet values remain fixed and Neumann conditions are maintained [S1, unofficial].
   d. Check for convergence: If `max_residual` $< \epsilon$, terminate and return $T$.
4. **Termination:** If $N_{max}$ is reached without convergence, return the current $T$ [S1, unofficial].

**Pseudocode:**
```python
def solve_sor(nx, ny, nz, t_hot, t_cold, omega, max_iterations, tolerance):
    # Initialize temperature field with linear interpolation
    T = np.zeros((nx, ny, nz))
    for k in range(nz):
        z_ratio = k / (nz - 1)
        T[:, :, k] = t_hot + (t_cold - t_hot) * z_ratio

    def apply_boundary_conditions():
        # Dirichlet: fixed temperature on top and bottom
        T[:, :, 0] = t_hot
        T[:, :, -1] = t_cold
        # Neumann: zero gradient on side walls
        T[0, :, :] = T[1, :, :]
        T[-1, :, :] = T[-2, :, :]
        T[:, 0, :] = T[:, 1, :]
        T[:, -1, :] = T[:, -2, :]

    apply_boundary_conditions()

    for iteration in range(1, max_iterations + 1):
        max_residual = 0.0
        for i in range(1, nx - 1):
            for j in range(1, ny - 1):
                for k in range(1, nz - 1):
                    neighbor_sum = (
                        T[i + 1, j, k] + T[i - 1, j, k] +
                        T[i, j + 1, k] + T[i, j - 1, k] +
                        T[i, j, k + 1] + T[i, j, k - 1]
                    )
                    t_new = neighbor_sum / 6.0
                    residual = abs(t_new - T[i, j, k])
                    if residual > max_residual:
                        max_residual = residual
                    T[i, j, k] = (1 - omega) * T[i, j, k] + omega * t_new
        
        apply_boundary_conditions()
        
        if max_residual < tolerance:
            return T, iteration
            
    return T, max_iterations
```

**Edge Cases and Pitfalls:**
- Boundary conditions must be reapplied after each iteration to maintain fixed Dirichlet values and zero-gradient Neumann conditions [S1, unofficial].
- The relaxation parameter $\omega$ must be chosen carefully; $\omega > 2$ leads to divergence, and $\omega \le 1$ reduces to standard Gauss-Seidel or Jacobi-like behavior [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Each iteration requires $O(n_x n_y n_z)$ operations. Convergence speed depends heavily on $\omega$ and the grid size.
- **Memory Complexity:** $O(n_x n_y n_z)$ to store the temperature field.
- **Strengths:** Faster convergence than Jacobi iteration due to immediate use of updated values; SOR further accelerates this compared to standard Gauss-Seidel [S1, unofficial].
- **Limitations:** Sequential dependency in Gauss-Seidel makes parallelization difficult; convergence can be slow for large grids if $\omega$ is not optimal [S1, unofficial].
- **When to use:** Suitable for solving elliptic PDEs like the steady-state heat equation on regular grids where high parallelism is not the primary constraint or when using domain decomposition [S1, unofficial].

## Background
The method originates from the numerical solution of the steady-state heat equation (Laplace equation) in 3D domains [S1, unofficial]. It combines the Gauss-Seidel iterative solver, which updates variables in-place using the most recent values, with Successive Over-Relaxation (SOR), a technique introduced to accelerate convergence by extrapolating the update step [S1, unofficial]. It is commonly used in volume rendering contexts to pre-compute smooth scalar fields or solve physical simulations before visualization [S1, unofficial].
