# Forward Difference Gradient

Also called: Gradient Estimation for Lighting, Intermediate Difference Gradient, Simple Forward Differencing Gradient

## Overview
The Forward Difference Gradient is a first-order finite difference method for estimating the spatial gradient of a scalar volume field at each voxel. It approximates the partial derivatives by subtracting the current voxel value from its immediate neighbor in the positive direction along each axis. It is distinguished from the [Jacobian Estimation via Central Differences](2650-jacobian-estimation-via-central-differences.md) by its use of only two voxels per axis (vs. three), resulting in lower computational cost but reduced accuracy ($O(h)$ vs. $O(h^2)$) and directional bias. It is primarily used in direct volume rendering to compute surface normals for Phong or Blinn-Phong lighting models [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D scalar volume grid $V$ of dimensions $W \times H \times D$, where $V_{x,y,z}$ is the scalar value at integer coordinates $(x,y,z)$.
- Output: A 3D vector field $G$ of the same dimensions, where $G_{x,y,z} = \nabla V(x,y,z)$. Optionally, a normalized gradient field $n$ and gradient magnitude field $M$.

**Data Structures:**
- $V$: Array of scalars (e.g., `float` or `uint16_t`).
- $G$: Array of 3-component vectors (e.g., `vec3`).
- $n$: Array of 3-component unit vectors.
- $M$: Array of scalars.

**Parameters:**
- Voxel spacing $h$: The physical distance between adjacent voxels. If the grid is uniform and isotropic, $h_x = h_y = h_z = h$. If not, use $h_x, h_y, h_z$. The sources assume uniform spacing $h=1$ for the discrete difference formula, requiring division by $h$ for physical correctness [S1, unofficial].

**Steps:**
1. Iterate over all valid voxel coordinates $(x,y,z)$ where $0 \le x < W-1$, $0 \le y < H-1$, $0 \le z < D-1$.
2. Compute the unnormalized gradient components using forward differences:
   $$ \nabla_x = V_{x+1,y,z} - V_{x,y,z} $$
   $$ \nabla_y = V_{x,y+1,z} - V_{x,y,z} $$
   $$ \nabla_z = V_{x,y,z+1} - V_{x,y,z} $$
3. Normalize the gradient vector to obtain the surface normal:
   $$ n(x,y,z) = \frac{(\nabla_x, \nabla_y, \nabla_z)}{\sqrt{\nabla_x^2 + \nabla_y^2 + \nabla_z^2}} $$
4. Compute the gradient strength (magnitude):
   $$ ||N(x,y,z)|| = \sqrt{\nabla_x^2 + \nabla_y^2 + \nabla_z^2} $$

**Pseudocode:**
```python
def compute_forward_difference_gradient(V, W, H, D, h=1.0):
    """
    V: 3D array of scalar values [W][H][D]
    Returns: G (vector field), n (normalized vector field), M (magnitude field)
    """
    G = [[(0,0,0) for _ in range(D)] for _ in range(H)]
    n = [[(0,0,0) for _ in range(D)] for _ in range(H)]
    M = [[0.0 for _ in range(D)] for _ in range(H)]

    # Iterate only up to W-1, H-1, D-1 to avoid out-of-bounds access for forward difference
    for x in range(W - 1):
        for y in range(H - 1):
            for z in range(D - 1):
                # Forward differences
                dx = (V[x+1][y][z] - V[x][y][z]) / h
                dy = (V[x][y+1][z] - V[x][y][z]) / h
                dz = (V[x][y][z+1] - V[x][y][z]) / h
                
                # Store unnormalized gradient
                G[x][y][z] = (dx, dy, dz)
                
                # Compute magnitude
                mag = (dx*dx + dy*dy + dz*dz) ** 0.5
                M[x][y][z] = mag
                
                # Normalize
                if mag > 1e-8: # Avoid division by zero
                    n[x][y][z] = (dx/mag, dy/mag, dz/mag)
                else:
                    n[x][y][z] = (0, 0, 0) # [G] Default to zero vector if gradient is zero

    return G, n, M
```

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** The forward difference stencil requires the voxel at $(x+1, y, z)$, $(x, y+1, z)$, and $(x, y, z+1)$. Therefore, gradients cannot be computed for the last slice along any axis ($x=W-1$, $y=H-1$, $z=D-1$). These boundary voxels must be handled separately (e.g., clamped, mirrored, or set to zero) [G].
- **Zero Gradient:** If all neighboring values are identical, the magnitude is zero. Normalization fails; a default normal (e.g., $(0,0,0)$ or $(0,0,1)$) must be chosen [G].
- **Anisotropy:** If voxel spacing is not uniform ($h_x \neq h_y \neq h_z$), the division by $h$ must be axis-specific to preserve physical units [S1, unofficial].

## Subtopics

### Central Difference Gradient
Uses $V_{x+1} - V_{x-1}$, providing second-order accuracy and symmetry. Choose when higher precision is needed and boundary effects are manageable. [Link](2650-jacobian-estimation-via-central-differences.md)

### Backward Difference Gradient
Uses $V_{x,y,z} - V_{x-1,y,z}$. Symmetric to forward difference in bias. Choose when data is causal or when forward boundary is problematic. [Link](3858-finite-difference-stencils-central-forward-backward.md)

### Sobel Operator
Uses a $3 \times 3$ kernel for smoothing and differentiation. Choose when noise reduction is critical alongside gradient estimation. [Link](1416-sobel-operator.md)

## Operating characteristics
- **Time Complexity:** $O(W \cdot H \cdot D)$, with a constant factor of 3 subtractions and 1 square root per voxel. It is faster than central differences (which require 6 reads) and Sobel (which require 9 reads and more arithmetic).
- **Memory Complexity:** $O(W \cdot H \cdot D)$ for storing the gradient field. No additional temporary storage is required if computed in-place or streamed.
- **Strengths:** Minimal memory access pattern (sequential), extremely fast, simple to implement.
- **Limitations:** First-order accuracy ($O(h)$), biased in the positive axis direction, cannot compute gradients at the outer boundaries of the volume without special handling.
- **When to use:** Real-time rendering where performance is critical and visual artifacts from gradient bias are acceptable or masked by lighting.
- **When not to use:** Scientific visualization requiring precise surface normals or high-fidelity edge detection.

## Background
The forward difference gradient is a fundamental technique in numerical analysis applied to volume rendering. It is cited in early volume rendering literature as a simple method for gradient estimation [S1, unofficial]. It appears in lecture notes on Direct Volume Rendering, where it is used to compute normals for lighting models in CT data visualization [S2, unofficial]. The term "Intermediate difference gradient" is also used in some literature to describe this specific 4-voxel stencil (current + 3 neighbors) [S1, unofficial].
