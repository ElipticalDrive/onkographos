# Jacobian Estimation via Central Differences

Also called: Central Difference Jacobian, Finite Difference Jacobian

## Overview
This method estimates the full 3x3 Jacobian matrix of a vector-valued function (such as a deformation field or velocity field) by computing the central difference gradient for each component of the output vector with respect to each component of the input position. It builds on [Finite Difference Stencils (Central/Forward/Backward)](3858-finite-difference-stencils-central-forward-backward.md) by extending the scalar gradient estimation to a matrix form. It is distinguished from sibling methods like the [Sobel Operator](1416-sobel-operator.md) (which targets edge detection in images) and [Forward Difference Gradient](3362-forward-difference-gradient.md) (which is first-order and biased) by providing a second-order accurate, unbiased approximation of the local linear transformation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A vector-valued function $f: \mathbb{R}^3 \to \mathbb{R}^3$, denoted as $f(\mathbf{p})$, where $\mathbf{p} = (x, y, z)$ is the position vector. A scalar step size $\epsilon$ (EPSILON).
- **Output:** A 3x3 Jacobian matrix $J$, where the $j$-th column is the gradient of the $j$-th component of $f$ with respect to the input coordinates.

**Data Structures:**
- The Jacobian is stored as a 3x3 matrix. In column-major layout (common in graphics APIs like OpenGL/GLM), the matrix is an array of 9 floats. The columns correspond to the partial derivatives $\frac{\partial f}{\partial x}$, $\frac{\partial f}{\partial y}$, and $\frac{\partial f}{\partial z}$.

**Steps:**
1. Define the perturbation vectors for the three axes:
   $$ \mathbf{d}_x = (\epsilon, 0, 0) $$
   $$ \mathbf{d}_y = (0, \epsilon, 0) $$
   $$ \mathbf{d}_z = (0, 0, \epsilon) $$
2. Evaluate the function $f$ at the perturbed positions for the x-axis:
   $$ \mathbf{g}_x = \frac{f(\mathbf{p} + \mathbf{d}_x) - f(\mathbf{p} - \mathbf{d}_x)}{2\epsilon} $$
   Here, $\mathbf{g}_x$ is a 3D vector representing the partial derivatives of all output components with respect to $x$.
3. Evaluate the function $f$ at the perturbed positions for the y-axis:
   $$ \mathbf{g}_y = \frac{f(\mathbf{p} + \mathbf{d}_y) - f(\mathbf{p} - \mathbf{d}_y)}{2\epsilon} $$
4. Evaluate the function $f$ at the perturbed positions for the z-axis:
   $$ \mathbf{g}_z = \frac{f(\mathbf{p} + \mathbf{d}_z) - f(\mathbf{p} - \mathbf{d}_z)}{2\epsilon} $$
5. Construct the Jacobian matrix $J$ using $\mathbf{g}_x, \mathbf{g}_y, \mathbf{g}_z$ as its columns:
   $$ J = \begin{bmatrix} | & | & | \\ \mathbf{g}_x & \mathbf{g}_y & \mathbf{g}_z \\ | & | & | \end{bmatrix} $$

**Parameters:**
- **EPSILON ($\epsilon$):** The step size for finite differences. Typical values depend on the scale of the input domain and the precision of the function evaluation. In the reference implementation, a small float value is used [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** If $\mathbf{p} \pm \mathbf{d}_i$ falls outside the valid domain of $f$, clamping, zero-padding, or reflection must be applied [G].
- **Precision:** If $\epsilon$ is too small, subtractive cancellation errors may dominate. If $\epsilon$ is too large, the approximation error (truncation error) increases.

**Pseudocode:**
```python
def estimate_jacobian_central(f, p, epsilon):
    """
    Estimate the 3x3 Jacobian matrix of vector function f at position p.
    
    Args:
        f: A function taking a 3D vector and returning a 3D vector.
        p: A 3D vector (x, y, z).
        epsilon: Scalar step size.
        
    Returns:
        A 3x3 matrix (list of lists or array) representing the Jacobian.
    """
    # Define perturbation vectors
    dx = (epsilon, 0.0, 0.0)
    dy = (0.0, epsilon, 0.0)
    dz = (0.0, 0.0, epsilon)
    
    # Compute gradients for each axis
    # grad_x is the partial derivative of f with respect to x
    f_plus_x = f((p[0] + dx[0], p[1] + dx[1], p[2] + dx[2]))
    f_minus_x = f((p[0] - dx[0], p[1] - dx[1], p[2] - dx[2]))
    grad_x = ((f_plus_x[0] - f_minus_x[0]) / (2.0 * epsilon),
              (f_plus_x[1] - f_minus_x[1]) / (2.0 * epsilon),
              (f_plus_x[2] - f_minus_x[2]) / (2.0 * epsilon))
              
    # grad_y is the partial derivative of f with respect to y
    f_plus_y = f((p[0] + dy[0], p[1] + dy[1], p[2] + dy[2]))
    f_minus_y = f((p[0] - dy[0], p[1] - dy[1], p[2] - dy[2]))
    grad_y = ((f_plus_y[0] - f_minus_y[0]) / (2.0 * epsilon),
              (f_plus_y[1] - f_minus_y[1]) / (2.0 * epsilon),
              (f_plus_y[2] - f_minus_y[2]) / (2.0 * epsilon))
              
    # grad_z is the partial derivative of f with respect to z
    f_plus_z = f((p[0] + dz[0], p[1] + dz[1], p[2] + dz[2]))
    f_minus_z = f((p[0] - dz[0], p[1] - dz[1], p[2] - dz[2]))
    grad_z = ((f_plus_z[0] - f_minus_z[0]) / (2.0 * epsilon),
              (f_plus_z[1] - f_minus_z[1]) / (2.0 * epsilon),
              (f_plus_z[2] - f_minus_z[2]) / (2.0 * epsilon))
              
    # Construct Jacobian matrix with columns grad_x, grad_y, grad_z
    # Matrix layout:
    # [ grad_x[0] grad_y[0] grad_z[0] ]
    # [ grad_x[1] grad_y[1] grad_z[1] ]
    # [ grad_x[2] grad_y[2] grad_z[2] ]
    jacobian = [
        [grad_x[0], grad_y[0], grad_z[0]],
        [grad_x[1], grad_y[1], grad_z[1]],
        [grad_x[2], grad_y[2], grad_z[2]]
    ]
    
    return jacobian
```

It differs from raw Jacobian estimation by performing the matrix inversion and vector normalization required for stable stepping [G].

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation, requiring 6 function evaluations (2 per axis) and constant arithmetic operations.
- **Memory Complexity:** $O(1)$, storing only the perturbed positions and the resulting 3x3 matrix.
- **Accuracy:** Second-order accurate ($O(\epsilon^2)$) for smooth functions, providing a more accurate gradient than forward or backward differences [S1, unofficial].
- **Strengths:** Unbiased estimation; captures full local linear transformation (rotation, scaling, shear) of the vector field.
- **Limitations:** Requires the function to be differentiable; sensitive to noise in the function values; boundary handling can introduce errors if not managed carefully.
- **When to use:** When the full Jacobian matrix is needed for tasks like inverse kinematics, deformation, or ODE integration.
- **When not to use:** When only the scalar gradient magnitude is needed (use [Finite Difference Stencils](3858-finite-difference-stencils-central-forward-backward.md) directly); when the function is noisy (consider smoothing first); when performance is critical and only approximate direction is needed (consider [Forward Difference Gradient](3362-forward-difference-gradient.md)).

## Background
The method is derived from the standard definition of the Jacobian matrix in multivariable calculus, approximated using central finite differences. The specific implementation shown in the source code is used in the context of a graphics engine (NtslGraphics) for estimating deformation fields, likely for interactive modeling or physics simulation [S1, unofficial].
