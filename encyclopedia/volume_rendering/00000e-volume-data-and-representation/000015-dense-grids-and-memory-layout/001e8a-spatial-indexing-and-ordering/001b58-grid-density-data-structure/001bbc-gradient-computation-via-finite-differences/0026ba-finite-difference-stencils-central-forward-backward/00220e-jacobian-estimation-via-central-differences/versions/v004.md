# Jacobian Estimation via Central Differences

Also called: Central Difference Jacobian, Finite Difference Jacobian

## Overview
This method estimates the full $3 \times 3$ Jacobian matrix of a vector-valued deformation field by applying the central difference stencil to each component of the field independently. It builds on [Finite Difference Stencils (Central/Forward/Backward)](3858-finite-difference-stencils-central-forward-backward.md) by extending the scalar gradient computation to a matrix output, capturing local linear transformations (rotation, scaling, shear) of the field. It differs from the [Sobel Operator](1416-sobel-operator.md) by using a symmetric two-point stencil rather than a weighted cross-product kernel, and from [4th-Order Finite Difference Gradient](4889-4th-order-finite-difference-gradient.md) by using a 2nd-order accurate approximation with minimal computational overhead.

## How it works
**Inputs and Outputs:**
- Input: A query point $\mathbf{p} = (x, y, z)$ in the domain of a vector field $\mathbf{F}(\mathbf{p}) = (F_x, F_y, F_z)$, and a step size $\epsilon$.
- Output: A $3 \times 3$ Jacobian matrix $\mathbf{J}$, where the $j$-th column is the gradient of the $j$-th component of $\mathbf{F}$ with respect to the spatial coordinates.

**Data Structures:**
- The Jacobian matrix $\mathbf{J}$ is a $3 \times 3$ array of floating-point numbers.
- The field evaluation function $\mathbf{F}(\mathbf{p})$ returns a 3D vector.

**Steps:**
1. Define the displacement vectors for the three axes:
   $$ \Delta_x = (\epsilon, 0, 0), \quad \Delta_y = (0, \epsilon, 0), \quad \Delta_z = (0, 0, \epsilon) $$
2. Evaluate the field at the perturbed points for the x-axis:
   $$ \mathbf{F}_+ = \mathbf{F}(\mathbf{p} + \Delta_x) $$
   $$ \mathbf{F}_- = \mathbf{F}(\mathbf{p} - \Delta_x) $$
3. Compute the first column of the Jacobian (gradient of $\mathbf{F}$ with respect to $x$):
   $$ \mathbf{J}_{:,0} = \frac{\mathbf{F}_+ - \mathbf{F}_-}{2\epsilon} $$
4. Evaluate the field at the perturbed points for the y-axis:
   $$ \mathbf{F}_+ = \mathbf{F}(\mathbf{p} + \Delta_y) $$
   $$ \mathbf{F}_- = \mathbf{F}(\mathbf{p} - \Delta_y) $$
5. Compute the second column of the Jacobian (gradient of $\mathbf{F}$ with respect to $y$):
   $$ \mathbf{J}_{:,1} = \frac{\mathbf{F}_+ - \mathbf{F}_-}{2\epsilon} $$
6. Evaluate the field at the perturbed points for the z-axis:
   $$ \mathbf{F}_+ = \mathbf{F}(\mathbf{p} + \Delta_z) $$
   $$ \mathbf{F}_- = \mathbf{F}(\mathbf{p} - \Delta_z) $$
7. Compute the third column of the Jacobian (gradient of $\mathbf{F}$ with respect to $z$):
   $$ \mathbf{J}_{:,2} = \frac{\mathbf{F}_+ - \mathbf{F}_-}{2\epsilon} $$
8. Construct the matrix $\mathbf{J}$ using the computed columns.

**Parameters:**
- $\epsilon$: The step size for finite differences. Typical values depend on the scale of the field and floating-point precision. In the reference implementation, a small constant `EPSILON` is used [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** If $\mathbf{p} \pm \Delta_i$ falls outside the domain of $\mathbf{F}$, boundary handling (e.g., clamping, mirroring) must be applied [G].
- **Precision:** If $\epsilon$ is too small, subtractive cancellation errors may dominate. If $\epsilon$ is too large, truncation error increases.

**Pseudocode:**
```python
def estimate_jacobian_central_diff(field_func, p, epsilon):
    """
    Estimates the 3x3 Jacobian matrix of a vector field at point p.
    
    Args:
        field_func: A function F(p) -> (fx, fy, fz)
        p: A 3D vector (x, y, z)
        epsilon: Step size for finite differences
        
    Returns:
        A 3x3 matrix represented as a list of 3 lists (columns)
    """
    # Define displacement vectors
    dx = (epsilon, 0.0, 0.0)
    dy = (0.0, epsilon, 0.0)
    dz = (0.0, 0.0, epsilon)
    
    # Helper to add vectors
    def add_vec(a, b):
        return (a[0] + b[0], a[1] + b[1], a[2] + b[2])
    
    # Helper to subtract vectors
    def sub_vec(a, b):
        return (a[0] - b[0], a[1] - b[1], a[2] - b[2])
    
    # Helper to scale vector
    def scale_vec(v, s):
        return (v[0] * s, v[1] * s, v[2] * s)
    
    # Compute column 0 (gradient w.r.t x)
    p_plus_x = add_vec(p, dx)
    p_minus_x = sub_vec(p, dx)
    f_plus_x = field_func(p_plus_x)
    f_minus_x = field_func(p_minus_x)
    col_x = scale_vec(sub_vec(f_plus_x, f_minus_x), 1.0 / (2.0 * epsilon))
    
    # Compute column 1 (gradient w.r.t y)
    p_plus_y = add_vec(p, dy)
    p_minus_y = sub_vec(p, dy)
    f_plus_y = field_func(p_plus_y)
    f_minus_y = field_func(p_minus_y)
    col_y = scale_vec(sub_vec(f_plus_y, f_minus_y), 1.0 / (2.0 * epsilon))
    
    # Compute column 2 (gradient w.r.t z)
    p_plus_z = add_vec(p, dz)
    p_minus_z = sub_vec(p, dz)
    f_plus_z = field_func(p_plus_z)
    f_minus_z = field_func(p_minus_z)
    col_z = scale_vec(sub_vec(f_plus_z, f_minus_z), 1.0 / (2.0 * epsilon))
    
    # Return matrix as list of columns
    return [col_x, col_y, col_z]
```

## Subtopics

### [Jacobian Normalization for ODE Step](2946-jacobian-normalization-for-ode-step.md)
This method computes the normalized direction vector for an Ordinary Differential Equation (ODE) solver by applying the inverse of an estimated Jacobian matrix to a base direction vector. It differs from raw Jacobian estimation by performing the matrix inversion and vector normalization required for stable stepping [G].

## Operating characteristics
- **Time Complexity:** $O(1)$ per query, requiring 6 evaluations of the field function $\mathbf{F}$ and a constant number of arithmetic operations.
- **Memory Complexity:** $O(1)$, storing only the current point and the resulting matrix.
- **Accuracy:** 2nd-order accurate ($O(\epsilon^2)$ truncation error).
- **Strengths:** Simple to implement, symmetric, and provides a full local linear approximation.
- **Limitations:** Sensitive to the choice of $\epsilon$; noisy if the field is not smooth or if $\epsilon$ is too small relative to machine precision.

## Background
This method is a standard application of numerical differentiation to vector fields. It is used in graphics and physics simulations to estimate local deformation, as seen in the `ntsl-graphics` repository where it is applied to a `simpleBrush` deformation field [S1, unofficial].
