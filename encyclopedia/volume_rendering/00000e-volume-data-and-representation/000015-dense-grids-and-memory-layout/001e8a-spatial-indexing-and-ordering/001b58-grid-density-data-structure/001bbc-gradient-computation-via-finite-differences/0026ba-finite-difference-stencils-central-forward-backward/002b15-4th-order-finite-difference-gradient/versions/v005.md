# 4th-Order Finite Difference Gradient

Also called: 4th-Order Accurate Finite Difference Scheme, Grid Normal Computation via 4th-Order Finite Differences

## Overview
Computes the gradient (normal vector) of a Signed Distance Function (SDF) grid at every voxel center using a 4th-order accurate finite difference scheme [S1, unofficial]. This method provides smooth normals for ray marching and shading, distinguishing itself from lower-order stencils by maintaining high accuracy even at volume boundaries through specific extrapolation techniques [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D grid of scalar values $V$ (typically an SDF) with dimensions $N_x \times N_y \times N_z$, and a scalar `voxel_size` $h$ representing the physical spacing between voxels.
- **Output:** Three 3D grids representing the gradient components $\nabla f = [\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}]$.

**Data Structures:**
The grid is stored as a dense 3D array. For implementation, it is treated as a tensor where indexing $V[i, j, k]$ corresponds to the value at voxel coordinates $(i, j, k)$.

**Algorithm Steps:**
The gradient is computed component-wise. For each axis, two approximations are generated: one shifted forward ($X_1$) and one shifted backward ($X_2$). The final gradient is the central difference of these two approximations.

1.  **X-Axis Gradient:**
    -   Compute forward approximation $X_1$: Concatenate the interior slice $V[1:N_x, :, :]$ with a boundary extrapolation term at the last index $N_x-1$.
    -   Compute backward approximation $X_2$: Concatenate a boundary extrapolation term at the first index $0$ with the interior slice $V[0:N_x-1, :, :]$.
    -   Calculate $G_x = (X_1 - X_2) / (2h)$.

2.  **Y-Axis Gradient:**
    -   Compute forward approximation $Y_1$: Concatenate $V[:, 1:N_y, :]$ with a boundary extrapolation term at index $N_y-1$ along the second dimension.
    -   Compute backward approximation $Y_2$: Concatenate a boundary extrapolation term at index $0$ with $V[:, 0:N_y-1, :]$.
    -   Calculate $G_y = (Y_1 - Y_2) / (2h)$.

3.  **Z-Axis Gradient:**
    -   Compute forward approximation $Z_1$: Concatenate $V[:, :, 1:N_z]$ with a boundary extrapolation term at index $N_z-1$ along the third dimension.
    -   Compute backward approximation $Z_2$: Concatenate a boundary extrapolation term at index $0$ with $V[:, :, 0:N_z-1]$.
    -   Calculate $G_z = (Z_1 - Z_2) / (2h)$.

**Boundary Extrapolation Formula:**
To maintain 4th-order accuracy at the boundaries, values outside the grid are extrapolated using a quadratic fit derived from the last (or first) three interior points. For the last element in a dimension with index $n$ (where $n = N-1$), the extrapolated value $V_{n+1}$ is:
$$ V_{n+1} = 3V_n - 3V_{n-1} + V_{n-2} $$
For the first element (index $0$), the extrapolated value $V_{-1}$ is:
$$ V_{-1} = -3V_0 + 3V_1 + V_2 $$

**Pseudocode:**
```python
def compute_4th_order_gradient(grid, voxel_size):
    """
    Computes the gradient of a 3D grid using 4th-order finite differences.
    
    Args:
        grid: 3D numpy array or tensor of shape (Nx, Ny, Nz).
        voxel_size: Scalar float, the physical spacing h.
        
    Returns:
        Tuple of 3 arrays (grad_x, grad_y, grad_z) of the same shape as grid.
    """
    Nx, Ny, Nz = grid.shape
    
    # --- X-Axis ---
    # Interior slices
    interior_x = grid[1:Nx-1, :, :]
    
    # Boundary extrapolation for the end (index Nx-1)
    # V_{Nx} = 3*V_{Nx-1} - 3*V_{Nx-2} + V_{Nx-3}
    # Note: grid indices are 0-based. Last index is Nx-1.
    # We need the value at index Nx (virtual) to complete the forward shift
    # The source code uses grid[n_x] where n_x = Nx-1.
    # X_1 = cat(grid[1:], extrapolated_end)
    # X_2 = cat(extrapolated_start, grid[:-1])
    
    # End boundary extrapolation for X
    # grid[n_x] is grid[Nx-1], grid[n_x-1] is grid[Nx-2], grid[n_x-2] is grid[Nx-3]
    end_x = 3 * grid[Nx-1, :, :] - 3 * grid[Nx-2, :, :] + grid[Nx-3, :, :]
    end_x = end_x.reshape(1, Ny, Nz) # Reshape for concatenation
    
    # Start boundary extrapolation for X
    # grid[0] is grid[0], grid[1] is grid[1], grid[2] is grid[2]
    start_x = -3 * grid[0, :, :] + 3 * grid[1, :, :] + grid[2, :, :]
    start_x = start_x.reshape(1, Ny, Nz)
    
    # Construct X_1 and X_2
    # X_1: shift left, pad right with extrapolated end
    X_1 = np.concatenate((grid[1:, :, :], end_x), axis=0)
    # X_2: shift right, pad left with extrapolated start
    X_2 = np.concatenate((start_x, grid[:-1, :, :]), axis=0)
    
    grad_x = (X_1 - X_2) / (2 * voxel_size)
    
    # --- Y-Axis ---
    interior_y = grid[:, 1:Ny-1, :]
    
    # End boundary extrapolation for Y
    end_y = 3 * grid[:, Ny-1, :] - 3 * grid[:, Ny-2, :] + grid[:, Ny-3, :]
    end_y = end_y.reshape(Nx, 1, Nz)
    
    # Start boundary extrapolation for Y
    start_y = -3 * grid[:, 0, :] + 3 * grid[:, 1, :] + grid[:, 2, :]
    start_y = start_y.reshape(Nx, 1, Nz)
    
    Y_1 = np.concatenate((grid[:, 1:, :], end_y), axis=1)
    Y_2 = np.concatenate((start_y, grid[:, :-1, :]), axis=1)
    
    grad_y = (Y_1 - Y_2) / (2 * voxel_size)
    
    # --- Z-Axis ---
    interior_z = grid[:, :, 1:Nz-1]
    
    # End boundary extrapolation for Z
    end_z = 3 * grid[:, :, Nz-1] - 3 * grid[:, :, Nz-2] + grid[:, :, Nz-3]
    end_z = end_z.reshape(Nx, Ny, 1)
    
    # Start boundary extrapolation for Z
    start_z = -3 * grid[:, :, 0] + 3 * grid[:, :, 1] + grid[:, :, 2]
    start_z = start_z.reshape(Nx, Ny, 1)
    
    Z_1 = np.concatenate((grid[:, :, 1:], end_z), axis=2)
    Z_2 = np.concatenate((start_z, grid[:, :, :-1]), axis=2)
    
    grad_z = (Z_1 - Z_2) / (2 * voxel_size)
    
    return grad_x, grad_y, grad_z
```

**Parameters:**
- `voxel_size`: The physical size of a single voxel in the grid. Used to normalize the finite difference result to physical units [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Grid Size:** The extrapolation formula requires at least 3 voxels in each dimension ($N \ge 3$) to access indices $n, n-1, n-2$ and $0, 1, 2$. If $N < 3$, the method fails or requires fallback to lower-order schemes [G].
- **Precision:** Using floating-point arithmetic for extrapolation may introduce small errors at boundaries, potentially affecting normal smoothness in critical regions [G].

## Subtopics

### [Sobel Operator](1416-sobel-operator.md)
A 3x3 convolution-based gradient estimator. Simpler to implement but lower order of accuracy and sensitive to noise compared to 4th-order finite differences.

### [Jacobian Estimation via Central Differences](2650-jacobian-estimation-via-central-differences.md)
Uses 2nd-order central differences. Less accurate than 4th-order but requires fewer neighboring points and is computationally cheaper.

### [Forward Difference Gradient](3362-forward-difference-gradient.md)
First-order accurate. Biased and less smooth, but useful for real-time applications where speed is prioritized over normal quality.

### [Gauss-Seidel with Successive Over-Relaxation (SOR)](6904-gauss-seidel-with-successive-over-relaxation-sor.md)
An iterative solver for Poisson equations, not a direct gradient stencil. Used for integrating gradients, not computing them from a grid.

## Operating characteristics
- **Time Complexity:** $O(N_x N_y N_z)$, as each voxel is processed a constant number of times.
- **Memory Complexity:** $O(N_x N_y N_z)$ for storing the input grid and three output gradient grids.
- **Performance:** Provides higher quality normals than Sobel or 2nd-order central differences, reducing artifacts in ray marching. The boundary extrapolation adds minimal computational overhead compared to the benefit of maintaining accuracy at edges.
- **Strengths:** High accuracy (4th-order) throughout the volume, including boundaries. Smooth normals improve shading and ray marching stability.
- **Limitations:** Requires at least 3 voxels per dimension. More complex to implement than simple central differences due to boundary handling.

## Background
The method is implemented in the SDFDiff repository, which focuses on differentiable rendering of Signed Distance Functions [S1, unofficial]. It is used to compute normals for SDF grids to enable gradient-based optimization in neural rendering pipelines.
