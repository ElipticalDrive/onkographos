# Gradient Selection — Central/Forward/Backward

Also called: Finite Difference Gradient Selection

## Overview
This method estimates the gradient or slope at a specified position using central, forward, or backward finite differences depending on boundary conditions [S1, unofficial]. It selects the appropriate 1D stencil for a given axis index, serving as the core logic for the `gradientMode` selection in the parent [Gradient Selection](5889-gradient-selection.md) article.

## How it works
**Inputs:**
- `i`: The axis index being evaluated (typically $z$) [S1, unofficial].
- `min`: The minimum valid axis value (normally $0$) [S1, unofficial].
- `max`: The maximum valid axis value (normally axis length $- 1$) [S1, unofficial].
- `getVoxel(idx)`: A function returning the scalar value at integer index `idx` [S1, unofficial].
- `getRealVoxel(pos)`: A function returning the interpolated scalar value at a non-integer position `pos` [S1, unofficial].

**Outputs:**
- `gradient`: The estimated 1D derivative value along the specified axis [S1, unofficial].

**Data Structures:**
- The volume data is accessed via direct indexing; no explicit gradient storage structure is created by this selection logic [S1, unofficial].

**Steps:**
1. Determine whether the position `i` is an integer or non-integer [S1, unofficial].
2. If `i` is an integer, fetch neighbor values using `getVoxel`; otherwise, use `getRealVoxel` for interpolation [S1, unofficial].
3. If `min < i < max - 1`, return `next - prev` (central difference) [S1, unofficial].
4. If `i <= min`, return `next - current` (forward difference) [S1, unofficial].
5. If `i >= max - 1`, return `current - prev` (backward difference) [S1, unofficial].

**Formulas:**
Let $V_i$ denote the value at index $i$. The step size $h$ is $1$ for discrete indices [S1, unofficial].
- **Central Difference** (Interior): $\nabla V_i = V_{i+1} - V_{i-1}$ for $min < i < max - 1$ [S1, unofficial].
- **Forward Difference** (Lower Boundary): $\nabla V_i = V_{i+1} - V_i$ for $i \le min$ [S1, unofficial].
- **Backward Difference** (Upper Boundary): $\nabla V_i = V_i - V_{i-1}$ for $i \ge max - 1$ [S1, unofficial].

**Parameters:**
- `i`: Axis index [S1, unofficial].
- `min`: Minimum valid index (default $0$) [S1, unofficial].
- `max`: Maximum valid index (default axis length $- 1$) [S1, unofficial].

**Pseudocode:**
```python
def compute_gradient_selection(i, min_val, max_val, get_voxel, get_real_voxel, is_integer=True):
    """
    Selects and computes the gradient using central, forward, or backward differences.
    """
    def get_val(idx):
        return get_voxel(idx) if is_integer else get_real_voxel(idx)

    if i <= min_val:
        return get_val(i + 1) - get_val(i)
    elif i >= max_val - 1:
        return get_val(i) - get_val(i - 1)
    else:
        return get_val(i + 1) - get_val(i - 1)
```

**Edge Cases and Pitfalls:**
- Non-integer positions require `getRealVoxel` instead of `getVoxel` to maintain continuity [S1, unofficial].
- Boundary conditions use forward or backward differences, which the source specifies explicitly for the given index ranges [S1, unofficial].

## Subtopics

### [Gradient Estimation via On-the-Fly Interpolation](13587-gradient-estimation-via-on-the-fly-interpolation.md)
Estimates gradients at arbitrary sample points during ray casting using on-the-fly central differences, avoiding precomputation. Chosen when memory bandwidth for precomputed gradients is a bottleneck and arbitrary point evaluation is required.

### Compiler Gradient Averaging for Single Discontinuity Assumption
Averages the gradient between two smaller non-overlapping pre-filtering kernels: $[-\Delta x, 0]$ and $[0, \Delta x]$, where $\Delta x$ is the sample spacing on the regular grid [S2]. In the case of a single sampling axis, it draws 3 samples along the sampling axis for each location where the gradient is approximated, and samples may be shared between neighboring locations [S2]. It nullifies the contribution (outputs zero gradient) if multiple discontinuities represented by different continuous functions are sampled [S2].
