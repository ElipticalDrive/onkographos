# Cube-4/VolumePro

Also called: RT-Vis, VolumePro/vg500

## Overview
Cube-4/VolumePro is a dedicated hardware architecture for real-time volume rendering, implemented as a single-board solution by Mitsubishi Electric [S1, unofficial]. It solves the problem of interactive visualization of large volumetric datasets by delivering 500 million shaded volume samples per second, enabling 30Hz rendering with full Phong shading [S1, unofficial]. It distinguishes itself from general-purpose GPU implementations by using fixed-point arithmetic and a specific gradient magnitude approximation via Newton-Raphson iteration to drive Phong illumination at every sample point [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 8- or 12-bit scalar voxel data [S1, unofficial].
*   **Output:** Final RGB image with accumulated opacity, supporting front-to-back compositing, weighted summation, minimum intensity projection, and maximum intensity projection (MIP) [S1, unofficial].

**Data Structures:**
*   **Internal Formats:** Fixed-point arithmetic is used throughout [S1, unofficial].
*   **Precision:** Accumulated opacity and shaded RGB values utilize 12 or more bits of precision to preserve accuracy [S1, unofficial].
*   **Supersampling:** Supports supersampling in x, y, and z dimensions in powers of two. This is implemented by rendering the volume from the same viewpoint shifted by subvoxel amounts, then interlacing the resulting images [S1, unofficial].

**Gradient Magnitude Computation:**
The system computes central difference gradients [S1, unofficial]. To approximate the magnitude of the gradient vector $\mathbf{g} = (g_x, g_y, g_z)$, it does not compute the Euclidean norm directly [S1, unofficial]. Instead, it performs the following steps [S1, unofficial]:
1.  Compute the sum of the absolute values of the gradient components: $S = |g_x| + |g_y| + |g_z|$ [S1, unofficial].
2.  Perform a single Newton-Raphson iteration to approximate the magnitude $\|\mathbf{g}\|$ from $S$ [S1, unofficial].

*Note: The exact Newton-Raphson formula or initial guess used for this approximation is not specified in the sources [G].*

**Sample Modulation and Shading:**
The computed gradient magnitude serves as a measure of surface "strength," where high magnitude indicates a high probability of surface crossing [S1, unofficial]. This magnitude is used in two ways [S1, unofficial]:
1.  **Opacity Modulation:** A gradient magnitude lookup table selects the amount of modulation to strengthen or weaken the sample's contribution, highlighting surfaces in low-opacity data [S1, unofficial].
2.  **Illumination Coefficient Modulation:** Diffuse ($G_d$) and specular ($G_s$) shading coefficients are derived from the gradient magnitude to modulate illumination [S1, unofficial].

**Final Color Calculation:**
The final sample color $C_{out}$ is calculated using a complete Phong illumination equation [S1, unofficial]:

$$
C_{out} = (k_e + (I_d G_d - k_d))C_{sample} + (I_s G_s k_s)C_{specular}
$$

Where:
*   $k_e$: Emissive coefficient [S1, unofficial].
*   $k_d$: Diffuse coefficient [S1, unofficial].
*   $k_s$: Specular coefficient [S1, unofficial].
*   $I_d$: Diffuse illumination value [S1, unofficial].
*   $I_s$: Specular illumination value [S1, unofficial].
*   $G_d$: Diffuse shading coefficient derived from gradient magnitude [S1, unofficial].
*   $G_s$: Specular shading coefficient derived from gradient magnitude [S1, unofficial].
*   $C_{sample}$: Sample color from the color classification lookup table [S1, unofficial].
*   $C_{specular}$: Specular light color [S1, unofficial].

**Pseudocode:**
```python
def cube4_volume_pro_render(voxel_data, origin, direction, step_size, resolution):
    accumulated_opacity = 0.0
    accumulated_color = [0.0, 0.0, 0.0]
    k_e, k_d, k_s = 0.0, 0.5, 0.5
    I_d, I_s = 1.0, 1.0
    C_specular = [1.0, 1.0, 1.0]

    t = 0.0
    while t < 1.0:
        pos = [origin[i] + direction[i] * t for i in range(3)]
        sample_val = sample_voxel(voxel_data, pos)
        sample_color = classify_color(sample_val)
        sample_opacity = 1.0

        gx, gy, gz = compute_central_difference_gradient(voxel_data, pos)
        s = abs(gx) + abs(gy) + abs(gz)
        magnitude = newton_raphson_approximate_magnitude(s, gx, gy, gz)

        opacity_mod = lookup_opacity_modulation(magnitude)
        sample_opacity *= opacity_mod

        G_d = lookup_diffuse_shading(magnitude)
        G_s = lookup_specular_shading(magnitude)

        term_diffuse = (k_e + (I_d * G_d - k_d)) * sample_color
        term_specular = (I_s * G_s * k_s) * C_specular
        C_out = [term_diffuse[i] + term_specular[i] for i in range(3)]

        alpha = sample_opacity
        accumulated_color = [accumulated_color[i] + (1.0 - accumulated_opacity) * C_out[i] * alpha for i in range(3)]
        accumulated_opacity = accumulated_opacity + alpha * (1.0 - accumulated_opacity)

        t += step_size

    return accumulated_color + [accumulated_opacity]

def sample_voxel(data, pos):
    ix, iy, iz = [int(p) for p in pos]
    fx, fy, fz = [p - ix for p in pos]
    v000 = data[ix][iy][iz]
    v100 = data[ix+1][iy][iz]
    v010 = data[ix][iy+1][iz]
    v110 = data[ix+1][iy+1][iz]
    v001 = data[ix][iy][iz+1]
    v101 = data[ix+1][iy][iz+1]
    v011 = data[ix][iy+1][iz+1]
    v111 = data[ix+1][iy+1][iz+1]
    lerp = lambda a, b, t: a + t * (b - a)
    c00 = lerp(v000, v100, fx)
    c10 = lerp(v010, v110, fx)
    c01 = lerp(v001, v101, fx)
    c11 = lerp(v011, v111, fx)
    c0 = lerp(c00, c10, fy)
    c1 = lerp(c01, c11, fy)
    return lerp(c0, c1, fz)

def classify_color(val):
    return [val / 255.0, val / 255.0, val / 255.0]

def compute_central_difference_gradient(data, pos):
    ix, iy, iz = [int(p) for p in pos]
    gx = data[ix+1][iy][iz] - data[ix-1][iy][iz]
    gy = data[ix][iy+1][iz] - data[ix][iy-1][iz]
    gz = data[ix][iy][iz+1] - data[ix][iy][iz-1]
    return gx, gy, gz

def newton_raphson_approximate_magnitude(s, gx, gy, gz):
    # Single Newton-Raphson iteration to approximate magnitude from L1 sum [G]
    sum_sq = gx*gx + gy*gy + gz*gz
    if s == 0: return 0.0
    return 0.5 * (s + sum_sq / s)

def lookup_opacity_modulation(mag):
    return min(1.0, mag * 0.1)

def lookup_diffuse_shading(mag):
    return min(1.0, mag * 0.5)

def lookup_specular_shading(mag):
    return min(1.0, mag * 0.8)
```

## Operating characteristics
*   **Performance:** The vg500 chip delivers 500 million shaded volume samples per second [S1, unofficial].
*   **Frame Rate:** Capable of 30Hz rendering for datasets with full Phong shading and interactive classification [S1, unofficial].
*   **Memory:** Uses fixed-point internal data formats. Supports 8- and 12-bit scalar voxels [S1, unofficial].
*   **Strengths:** High throughput for real-time interaction; dedicated hardware optimization for Phong shading; cost-effective single-board implementation [S1, unofficial].
*   **Limitations:** Fixed-point arithmetic may limit precision compared to floating-point GPU implementations; specific Newton-Raphson approximation for gradient magnitude may introduce artifacts or inaccuracies compared to exact Euclidean norms [G].
*   **When to use:** Real-time medical visualization (e.g., 3D ultrasound) and interactive classification where high frame rates are critical [S1, unofficial].

## Background
Cube-4 was an earlier architecture by Mitsubishi Electric [S1, unofficial]. Cube-4/VolumePro is a cost-effective single-board implementation of Cube-4, developed by Mitsubishi Electric [S1, unofficial]. A close derivative was implemented by Japan Radio Co. for 3D ultrasound machines [S1, unofficial]. The system is supported by the Volume Rendering Library (VLI) [S1, unofficial].
