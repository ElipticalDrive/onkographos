# Volume Gradient Computation and Light Propagation Compute Shader

Also called: Gradient Computation & Light Propagation Compute Shader

## Overview
This method is a compute shader pass that samples a 3D volume texture, computes spatial gradients using central differences, transforms gradients between world and view spaces, and initiates a per-pixel light propagation pass across volume layers [S1, unofficial]. It builds on [Gradient Map Generation](1204-gradient-map-generation.md) by extending the gradient calculation to include light propagation logic within the same shader invocation, allowing for efficient view-space gradient transformation and layer-wise accumulation [S1, unofficial].

## How it works
**Inputs and Outputs:**
The shader takes a 3D volume texture as input and produces multiple output images (lighting, depth, color, etc.) via storage images. It operates on a per-pixel basis for a specific layer of the volume, dispatched via a compute shader.

**Data Structures:**
*   **Uniform Buffer Object (UBO)** (binding 0, `std140` layout):
    *   `mat4 view_matrix`: View transformation matrix.
    *   `mat4 inverse_view_matrix`: Inverse view transformation matrix.
    *   `vec3 middle_of_front_plane_vs`: View-space Z coordinate of the front plane base.
    *   `vec3 light_color`: Color of the light source.
    *   `ivec2 plane_pixel_size`: Resolution of the output plane in pixels.
    *   `vec2 plane_extent_vs`: Extent of the plane in view space.
    *   `vec3 lightVSPos`: View-space position of the light.
    *   `float voxelDepth`: Scaling factor for X and Y dimensions when transforming world positions to volume texture coordinates.
    *   `float distance_between_planes`: Spacing between volume layers in world space, used as the step size for central difference gradient computation.
    *   `int plane_count`: Total number of planes/layers.
*   **Push Constants** (binding 0):
    *   `int layer_index`: The current layer index being processed.
*   **Input Samplers** (binding 1-6):
    *   `lb_in`, `ldb_in`, `cb_in`, `mb_in`, `vpb_in`, `vdb_in`: All `sampler2D`. These are likely ping-pong buffers for previous layer data.
*   **Output Images** (binding 7-12):
    *   `lb_out`, `ldb_out`, `cb_out`, `mb_out`, `vpb_out`, `vdb_out`: All `rgba32f image2D`. These store the computed results for the current layer.
*   **Volume Texture** (binding 13):
    *   `sampler3D volume`: The 3D volume texture to sample.
*   **Transfer Functions** (binding 14-16):
    *   `sampler2D volume_transfer`: Transfer function for volume data.
    *   `sampler2D medium_transfer`: Transfer function for medium data.
    *   `sampler1D refraction_transfer_tex`: Transfer function for refraction data.

**Numbered Steps:**
1.  **Thread Dispatch Setup:** The shader uses a local group size of 2x2 with derivative group quads enabled for efficient gradient computation.
    ```glsl
    layout(local_size_x = 2, local_size_y = 2) in;
    layout(derivative_group_quadsNV) in;
    ```
2.  **UV Coordinate Computation:** Compute the UV coordinates for the current pixel based on the global invocation ID and plane pixel size.
    ```glsl
    vec2 uv = (gl_GlobalInvocationID.xy + vec2(0.5)) / vec2(ubo.plane_pixel_size);
    ```
3.  **Layer Z Position Computation:** Determine the current layer's Z position in view space.
    ```glsl
    float current_z = ubo.middle_of_front_plane_vs.z - float(pc.layer_index) * ubo.distance_between_planes;
    ```
4.  **World Space Position Computation:** Convert the plane UV and Z position to world space.
    ```glsl
    vec3 plane_position = vec3(uv, current_z);
    vec3 pos_vs = vec3(2.0 * ubo.plane_extent_vs * (ubo.middle_of_front_plane_vs.xy + plane_position - 0.5), plane_z);
    vec3 pos_ws = (ubo.inverse_view_matrix * vec4(pos_vs, 1.0)).xyz;
    pos_ws += vec3(0.5); // Adjust for texture coordinate origin
    ```
5.  **Volume Texture Sampling:** Sample the volume texture at the computed world position, applying the necessary coordinate transformation.
    ```glsl
    vec3 coord = (pos_ws - vec3(0.5)) * vec3(ubo.voxelDepth, ubo.voxelDepth, 1.0) + vec3(0.5);
    float density = texture(volume, coord).r;
    ```
6.  **Central Difference Gradient Computation:** Compute spatial gradients using central differences along the X, Y, and Z axes.
    ```glsl
    // Sample neighbors for X, Y, Z
    float s1_x = texture(volume, coord + vec3(-ubo.distance_between_planes, 0, 0)).r;
    float s2_x = texture(volume, coord + vec3(ubo.distance_between_planes, 0, 0)).r;
    float s1_y = texture(volume, coord + vec3(0, -ubo.distance_between_planes, 0)).r;
    float s2_y = texture(volume, coord + vec3(0, ubo.distance_between_planes, 0)).r;
    float s1_z = texture(volume, coord + vec3(0, 0, -ubo.distance_between_planes)).r;
    float s2_z = texture(volume, coord + vec3(0, 0, ubo.distance_between_planes)).r;

    // Compute gradients
    vec3 grad_ws = vec3(
        (s2_x - s1_x) / (2.0 * ubo.distance_between_planes),
        (s2_y - s1_y) / (2.0 * ubo.distance_between_planes),
        (s2_z - s1_z) / (2.0 * ubo.distance_between_planes)
    );
    ```
7.  **Gradient Transformation:** Transform the world-space gradient to view space.
    ```glsl
    vec3 grad_vs = mat3(ubo.view_matrix) * grad_ws;
    ```
8.  **Refraction Gradient Computation:** Compute the refraction gradient by transforming the difference vector to view space and normalizing it.
    ```glsl
    vec3 diff = vec3(s2_x - s1_x, s2_y - s1_y, s2_z - s1_z);
    diff = inverse(transpose(mat3(ubo.view_matrix))) * diff;
    diff = safe_normalize(diff);
    ```
9.  **Light Propagation:** Initiate the per-pixel light propagation pass across volume layers. This step likely involves accumulating lighting information based on the computed gradients and transfer functions. The exact implementation details for light propagation are not fully specified in the provided notes, but it typically involves integrating light along the view ray or using precomputed lighting data. **Parameters:**
*   `ubo.voxelDepth`: Scaling factor applied to X and Y dimensions when transforming world positions to volume texture coordinates.
*   `ubo.distance_between_planes`: Spacing between volume layers in world space, used as the step size for central difference gradient computation.
*   `ubo.plane_pixel_size`: Resolution of the output plane in pixels, used to normalize `gl_GlobalInvocationID.xy` to UV coordinates.
*   `ubo.middle_of_front_plane_vs.z`: View-space Z coordinate of the front plane, used as the base Z for layer indexing.

**Edge Cases and Pitfalls:**
*   **Division by Zero in Intersect Plane:** When the direction vector's Z component is near zero, division by zero can occur. This is handled by clamping the denominator to `1e-5` with sign preservation.
*   **Zero-Length Vector Normalization:** When normalizing vectors, if the length is less than `1e-6`, the function returns `vec3(0.0)` to avoid division by zero.

**Pseudocode:**
```glsl

layout(derivative_group_quadsNV) in;

layout(std140, binding = 0) uniform UniformBufferObject {
    mat4 view_matrix;
    mat4 inverse_view_matrix;
    vec3 middle_of_front_plane_vs;
    vec3 light_color;
    ivec2 plane_pixel_size;
    vec2 plane_extent_vs;
    vec3 lightVSPos;
    float voxelDepth;
    float distance_between_planes;
    int plane_count;
} ubo;

layout(push_constant) uniform PushConstants {
    int layer_index;
} pc;

layout(binding = 13) uniform sampler3D volume;
layout(binding = 14) uniform sampler2D volume_transfer;
layout(binding = 15) uniform sampler2D medium_transfer;
layout(binding = 16) uniform sampler1D refraction_transfer_tex;

layout(binding = 1) uniform sampler2D lb_in;
layout(binding = 2) uniform sampler2D ldb_in;
layout(binding = 3) uniform sampler2D cb_in;
layout(binding = 4) uniform sampler2D mb_in;
layout(binding = 5) uniform sampler2D vpb_in;
layout(binding = 6) uniform sampler2D vdb_in;

layout(binding = 7) uniform image2D lb_out;
layout(binding = 8) uniform image2D ldb_out;
layout(binding = 9) uniform image2D cb_out;
layout(binding = 10) uniform image2D mb_out;
layout(binding = 11) uniform image2D vpb_out;
layout(binding = 12) uniform image2D vdb_out;

vec3 safe_normalize(vec3 v) {
    float len = length(v);
    if (len < 1e-6) {
        return vec3(0.0);
    }
    return v / len;
}

void main() {
    // 1. Compute UV coordinates
    vec2 uv = (gl_GlobalInvocationID.xy + vec2(0.5)) / vec2(ubo.plane_pixel_size);

    // 2. Compute current layer Z position
    float current_z = ubo.middle_of_front_plane_vs.z - float(pc.layer_index) * ubo.distance_between_planes;

    // 3. Convert plane UV and Z to world space
    vec3 plane_position = vec3(uv, current_z);
    vec3 pos_vs = vec3(2.0 * ubo.plane_extent_vs * (ubo.middle_of_front_plane_vs.xy + plane_position - 0.5), plane_position.z);
    vec3 pos_ws = (ubo.inverse_view_matrix * vec4(pos_vs, 1.0)).xyz;
    pos_ws += vec3(0.5);

    // 4. Sample volume texture with coordinate transform
    vec3 coord = (pos_ws - vec3(0.5)) * vec3(ubo.voxelDepth, ubo.voxelDepth, 1.0) + vec3(0.5);
    float density = texture(volume, coord).r;

    // 5. Compute central differences for x, y, z axes
    float dist = ubo.distance_between_planes;
    float s1_x = texture(volume, coord + vec3(-dist, 0, 0)).r;
    float s2_x = texture(volume, coord + vec3(dist, 0, 0)).r;
    float s1_y = texture(volume, coord + vec3(0, -dist, 0)).r;
    float s2_y = texture(volume, coord + vec3(0, dist, 0)).r;
    float s1_z = texture(volume, coord + vec3(0, 0, -dist)).r;
    float s2_z = texture(volume, coord + vec3(0, 0, dist)).r;

    // 6. Compute refraction gradient
    vec3 grad_ws = vec3(
        (s2_x - s1_x) / (2.0 * dist),
        (s2_y - s1_y) / (2.0 * dist),
        (s2_z - s1_z) / (2.0 * dist)
    );
    vec3 grad_vs = mat3(ubo.view_matrix) * grad_ws;

    // 7. Compute volume gradient
    vec3 diff = vec3(s2_x - s1_x, s2_y - s1_y, s2_z - s1_z);
    diff = inverse(transpose(mat3(ubo.view_matrix))) * diff;
    diff = safe_normalize(diff);

    imageStore(ldb_out, ivec2(gl_GlobalInvocationID.xy), vec4(grad_vs, 1.0));
```

## Operating characteristics
*   **Time Complexity:** $O(N \cdot L)$, where $N$ is the number of pixels in the output plane and $L$ is the number of layers. Each pixel requires 7 texture samples for gradient computation.
*   **Memory Complexity:** $O(N \cdot L)$ for storing the output images. The input volume texture is accessed but not stored in memory by the shader.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with the number of pixels and layers. The use of compute shaders allows for parallel processing of pixels and layers.
*   **Strengths:** Efficient gradient computation using central differences and derivative group quads. Flexible transformation between world and view spaces.
*   **Limitations:** Requires careful handling of edge cases (division by zero, zero-length vectors). The light propagation logic is not fully detailed, which may limit understanding of its performance characteristics.
*   **When to Use:** Suitable for real-time volume rendering where gradient-based lighting and refraction effects are desired.
*   **When Not to Use:** Not suitable for offline rendering where higher accuracy and more complex lighting models are required.
