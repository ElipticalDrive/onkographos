# Volume Gradient Computation and Light Propagation Compute Shader

Also called: Gradient Computation & Light Propagation Compute Shader

## Overview
This method is a compute shader pass that samples a 3D volume texture, computes spatial gradients using central differences, transforms gradients between world and view spaces, and initiates a per-pixel light propagation pass across volume layers [S1, unofficial]. It builds on [Gradient Map Generation](1204-gradient-map-generation.md) by extending the gradient calculation to include light propagation logic within the same shader invocation, allowing for efficient view-space gradient transformation and layer-wise accumulation [S1, unofficial].

## How it works
**Inputs and Outputs:**
The shader takes a 3D volume texture as input and produces multiple output images (lighting, depth, color, etc.) via storage images [S1, unofficial]. It operates on a per-pixel basis for a specific layer of the volume, dispatched via a compute shader [S1, unofficial].

**Data Structures:**
*   **Uniform Buffer Object (UBO)** (binding 0, `std140` layout):
    *   `mat4 view_matrix`: View transformation matrix [S1, unofficial].
    *   `mat4 inverse_view_matrix`: Inverse view transformation matrix [S1, unofficial].
    *   `vec3 middle_of_front_plane_vs`: View-space Z coordinate of the front plane base [S1, unofficial].
    *   `vec3 light_color`: Color of the light source [S1, unofficial].
    *   `ivec2 plane_pixel_size`: Resolution of the output plane in pixels [S1, unofficial].
    *   `vec2 plane_extent_vs`: Extent of the plane in view space [S1, unofficial].
    *   `vec3 lightVSPos`: View-space position of the light [S1, unofficial].
    *   `float voxelDepth`: Scaling factor applied to X and Y dimensions when transforming world positions to volume texture coordinates [S1, unofficial].
    *   `float distance_between_planes`: Spacing between volume layers in world space, used as the step size for central difference gradient computation [S1, unofficial].
    *   `int plane_count`: Total number of planes/layers [S1, unofficial].
*   **Push Constants** (binding 0):
    *   `int layer_index`: The current layer index being processed [S1, unofficial].
*   **Input Samplers** (binding 1-6):
    *   `lb_in`, `ldb_in`, `cb_in`, `mb_in`, `vpb_in`, `vdb_in`: All `sampler2D` [S1, unofficial].
*   **Output Images** (binding 7-12):
    *   `lb_out`, `ldb_out`, `cb_out`, `mb_out`, `vpb_out`, `vdb_out`: All `rgba32f image2D` [S1, unofficial].
*   **Volume Texture** (binding 13):
    *   `sampler3D volume`: The 3D volume texture to sample [S1, unofficial].
*   **Transfer Functions** (binding 14-16):
    *   `sampler2D volume_transfer`: Transfer function for volume data [S1, unofficial].
    *   `sampler2D medium_transfer`: Transfer function for medium data [S1, unofficial].
    *   `sampler1D refraction_transfer_tex`: Transfer function for refraction data [S1, unofficial].

**Numbered Steps:**
1.  **Thread Dispatch Setup:** The shader uses a local group size of 2x2 with derivative group quads enabled for efficient gradient computation [S1, unofficial].
2.  **UV Coordinate Computation:** Compute the UV coordinates for the current pixel based on the global invocation ID and plane pixel size [S1, unofficial].
3.  **Layer Z Position Computation:** Determine the current layer's Z position in view space [S1, unofficial].
4.  **World Space Position Computation:** Convert the plane UV and Z position to world space [S1, unofficial].
5.  **Volume Texture Sampling:** Sample the volume texture at the computed world position, applying the necessary coordinate transformation [S1, unofficial].
6.  **Central Difference Gradient Computation:** Compute spatial gradients using central differences along the X, Y, and Z axes [S1, unofficial].
7.  **Gradient Transformation:** Transform the world-space gradient to view space [S1, unofficial].
8.  **Refraction Gradient Computation:** Compute the refraction gradient by transforming the difference vector to view space and normalizing it [S1, unofficial].
9.  **Light Propagation:** Initiate the per-pixel light propagation pass across volume layers [S1, unofficial].

**Parameters:**
*   `ubo.voxelDepth`: Scaling factor applied to X and Y dimensions when transforming world positions to volume texture coordinates [S1, unofficial].
*   `ubo.distance_between_planes`: Spacing between volume layers in world space, used as the step size for central difference gradient computation [S1, unofficial].
*   `ubo.plane_pixel_size`: Resolution of the output plane in pixels, used to normalize `gl_GlobalInvocationID.xy` to UV coordinates [S1, unofficial].
*   `ubo.middle_of_front_plane_vs.z`: View-space Z coordinate of the front plane, used as the base Z for layer indexing [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Division by Zero in Intersect Plane:** When the direction vector's Z component is near zero, division by zero can occur. This is handled by clamping the denominator to `1e-5` with sign preservation [S1, unofficial].
*   **Zero-Length Vector Normalization:** When normalizing vectors, if the length is less than `1e-6`, the function returns `vec3(0.0)` to avoid division by zero [S1, unofficial].

**Pseudocode:**
```python
def compute_gradient_and_light_propagation():
    # 1. Thread dispatch uses 2x2 local groups with derivative group quads
    # layout(local_size_x = 2, local_size_y = 2) in; layout(derivative_group_quadsNV) in;

    # 2. Compute UV coordinates
    uv = (gl_GlobalInvocationID.xy + 0.5) / ubo.plane_pixel_size

    # 3. Compute current layer Z position
    current_z = ubo.middle_of_front_plane_vs.z - pc.layer_index * ubo.distance_between_planes

    # 4. Convert plane UV and Z to world space
    plane_position = Vector3(uv, current_z)
    pos_vs = Vector3(2.0 * ubo.plane_extent_vs * (ubo.middle_of_front_plane_vs.xy + plane_position.xy - 0.5), current_z)
    pos_ws = (ubo.inverse_view_matrix * Vector4(pos_vs, 1.0)).xyz
    pos_ws += 0.5

    # 5. Sample volume texture with coordinate transform
    coord = (pos_ws - 0.5) * Vector3(ubo.voxelDepth, ubo.voxelDepth, 1.0) + 0.5
    density = sample(volume, coord).r

    # 6. Compute central differences for x, y, z axes
    dist = ubo.distance_between_planes
    s1_x = sample(volume, coord + Vector3(-dist, 0, 0)).r
    s2_x = sample(volume, coord + Vector3(dist, 0, 0)).r
    s1_y = sample(volume, coord + Vector3(0, -dist, 0)).r
    s2_y = sample(volume, coord + Vector3(0, dist, 0)).r
    s1_z = sample(volume, coord + Vector3(0, 0, -dist)).r
    s2_z = sample(volume, coord + Vector3(0, 0, dist)).r

    # 7. Compute refraction gradient
    grad_ws = Vector3((s2_x - s1_x), (s2_y - s1_y), (s2_z - s1_z)) / (2.0 * dist)
    grad_vs = Matrix3(ubo.view_matrix) * grad_ws

    # 8. Compute volume gradient
    diff = Vector3(s2_x - s1_x, s2_y - s1_y, s2_z - s1_z)
    diff = inverse(transpose(Matrix3(ubo.view_matrix))) * diff
    diff = safe_normalize(diff)

    # 9. Light propagation pass across volume layers
    # The sources do not specify the exact light propagation logic. [G]
    store(lb_out, ivec2(gl_GlobalInvocationID.xy), Vector4(density, 0.0, 0.0, 1.0))
    store(ldb_out, ivec2(gl_GlobalInvocationID.xy), Vector4(grad_vs, 1.0))
    store(cb_out, ivec2(gl_GlobalInvocationID.xy), Vector4(diff, 1.0))
    # Other outputs (mb_out, vpb_out, vdb_out) would be populated similarly.

def safe_normalize(v):
    length = vector_length(v)
    if length < 1e-6:
        return Vector3(0.0)
    return v / length
```
