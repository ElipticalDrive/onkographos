# Mean Curvature Grid Computation

Also called: Mean Curvature via BoxStencil, Divergence of Normal Field

## Overview
Computes the mean curvature $\kappa = \nabla \cdot (\frac{\nabla f}{|\nabla f|})$ for every active voxel in a scalar volume grid. It differs from sibling methods by calculating this second-order differential quantity directly in a single pass using a `BoxStencil`, avoiding the creation of intermediate gradient or normal grids. This builds on [Gradient Computation via Finite Differences](1077-gradient-computation-via-finite-differences.md) by extending finite difference operations to the divergence of the normalized gradient field.

## How it works
**Inputs:** A scalar volume grid (e.g., VDB or dense array) containing the function values $f$.
**Outputs:** A new grid of the same topology and voxel size, containing the mean curvature $\kappa$ at each active voxel. Background values are set to zero.

**Data Structures:**
*   **Input Grid:** Scalar values $f(x,y,z)$.
*   **BoxStencil:** A temporary structure holding values of $f$ at the current voxel and its neighbors (up to distance 1 in each axis).
*   **Output Grid:** Float array storing $\kappa$.

**Parameters:**
*   `eps(T)`: Machine epsilon for the data type $T$ (e.g., `Float32` or `Float64`). Used to prevent division by zero.
*   Multipliers: `0.5` for first derivatives, `0.25` for cross second derivatives, `1.0` (implicit) for diagonal second derivatives.

**Algorithm Steps:**
1.  Initialize a `BoxStencil` with the input grid tree.
2.  Iterate over all active voxels in the grid. Let the current coordinate be $c$.
3.  Move the stencil to coordinate $c$.
4.  Retrieve the center value $f_{center} = \text{value\_at}(s, 0, 0, 0)$.
5.  Compute first derivatives (gradient components) using central differences with multiplier $0.5$:
    $$ f_x = (f(1,0,0) - f(-1,0,0)) \times 0.5 $$
    $$ f_y = (f(0,1,0) - f(0,-1,0)) \times 0.5 $$
    $$ f_z = (f(0,0,1) - f(0,0,-1)) \times 0.5 $$
6.  Compute the squared gradient magnitude:
    $$ \text{grad\_sq} = f_x^2 + f_y^2 + f_z^2 $$
7.  **Edge Case:** If $\text{grad\_sq} < \text{eps}(T)$, set $\kappa(c) = 0$ and continue to the next voxel. This avoids division by zero in flat regions or noise.
8.  Compute second derivatives:
    *   Diagonal ($f_{xx}, f_{yy}, f_{zz}$) using multiplier $1.0$ (implicit in formula):
        $$ f_{xx} = f(1,0,0) + f(-1,0,0) - 2 f_{center} $$
        $$ f_{yy} = f(0,1,0) + f(0,-1,0) - 2 f_{center} $$
        $$ f_{zz} = f(0,0,1) + f(0,0,-1) - 2 f_{center} $$
    *   Cross ($f_{xy}, f_{xz}, f_{yz}$) using multiplier $0.25$:
        $$ f_{xy} = (f(1,1,0) - f(-1,1,0) - f(1,-1,0) + f(-1,-1,0)) \times 0.25 $$
        $$ f_{xz} = (f(1,0,1) - f(-1,0,1) - f(1,0,-1) + f(-1,0,-1)) \times 0.25 $$
        $$ f_{yz} = (f(0,1,1) - f(0,-1,1) - f(0,1,-1) + f(0,-1,-1)) \times 0.25 $$
9.  Compute the numerator of the mean curvature formula:
    $$ \text{numer} = f_x^2(f_{yy} + f_{zz}) + f_y^2(f_{xx} + f_{zz}) + f_z^2(f_{xx} + f_{yy}) - 2(f_x f_y f_{xy} + f_x f_z f_{xz} + f_y f_z f_{yz}) $$
10. Compute the final curvature:
    $$ \kappa = \frac{\text{numer}}{\text{grad\_sq} \times \sqrt{\text{grad\_sq}}} $$
11. Store $\kappa$ in the output grid at $c$.
12. After iteration, build the result grid using the computed data, a background value of $0$, and the original grid's voxel size.

**Pseudocode:**
```python
def compute_mean_curvature(input_grid):
    """
    Computes mean curvature kappa = div(grad(f)/|grad(f)|) for all active voxels.
    """
    output_grid = create_empty_grid_like(input_grid, background=0.0)
    stencil = BoxStencil(input_grid)
    eps = get_epsilon(input_grid.dtype)

    for voxel in input_grid.active_voxels():
        c = voxel.coordinate
        stencil.move_to(c)
        
        # Retrieve center value
        f_center = stencil.value_at(0, 0, 0)
        
        # First derivatives (central differences, multiplier 0.5)
        fx = (stencil.value_at(1, 0, 0) - stencil.value_at(-1, 0, 0)) * 0.5
        fy = (stencil.value_at(0, 1, 0) - stencil.value_at(0, -1, 0)) * 0.5
        fz = (stencil.value_at(0, 0, 1) - stencil.value_at(0, 0, -1)) * 0.5
        
        # Squared gradient magnitude
        grad_sq = fx*fx + fy*fy + fz*fz
        
        # Handle degenerate cases (flat regions/noise)
        if grad_sq < eps:
            output_grid.set_value(c, 0.0)
            continue
            
        # Second derivatives
        # Diagonal (multiplier 1.0)
        fxx = stencil.value_at(1, 0, 0) + stencil.value_at(-1, 0, 0) - 2.0 * f_center
        fyy = stencil.value_at(0, 1, 0) + stencil.value_at(0, -1, 0) - 2.0 * f_center
        fzz = stencil.value_at(0, 0, 1) + stencil.value_at(0, 0, -1) - 2.0 * f_center
        
        # Cross (multiplier 0.25)
        fxy = (stencil.value_at(1, 1, 0) - stencil.value_at(-1, 1, 0) - 
               stencil.value_at(1, -1, 0) + stencil.value_at(-1, -1, 0)) * 0.25
        fxz = (stencil.value_at(1, 0, 1) - stencil.value_at(-1, 0, 1) - 
               stencil.value_at(1, 0, -1) + stencil.value_at(-1, 0, -1)) * 0.25
        fyz = (stencil.value_at(0, 1, 1) - stencil.value_at(0, -1, 1) - 
               stencil.value_at(0, 1, -1) + stencil.value_at(0, -1, -1)) * 0.25
               
        # Numerator of curvature formula
        numer = (fx*fx * (fyy + fzz) + 
                 fy*fy * (fxx + fzz) + 
                 fz*fz * (fxx + fyy) - 
                 2.0 * (fx*fy*fxy + fx*fz*fxz + fy*fz*fyz))
                 
        # Denominator: |grad|^3 = (grad_sq)^(3/2)
        denom = grad_sq * sqrt(grad_sq)
        
        kappa = numer / denom
        output_grid.set_value(c, kappa)
        
    return output_grid
```

## Subtopics

### Sobel Operator
Uses separable 3x3x3 kernels for gradient estimation. Simpler but less accurate for curvature than the full BoxStencil approach. Choose when memory is constrained and high-order accuracy is not required. [Sobel Operator](1416-sobel-operator.md)

### Analytic Gradient Computation
Computes gradients from explicit mathematical functions rather than sampled grids. Choose when the volume is defined analytically. [Analytic Gradient Computation](2167-analytic-gradient-computation.md)

### Divergence Grid Computation
Computes $\nabla \cdot \mathbf{V}$ for a vector field. Mean curvature is a specific case where $\mathbf{V} = \nabla f / |\nabla f|$. [Divergence Grid Computation](3151-divergence-grid-computation.md)

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of active voxels. Each voxel requires a fixed number of memory accesses (13 values for the stencil) and arithmetic operations.
*   **Memory Complexity:** $O(N)$ for the output grid. The `BoxStencil` uses constant extra memory per voxel.
*   **Strengths:** Single-pass computation avoids intermediate grid allocations. High accuracy for smooth surfaces.
*   **Limitations:** Sensitive to noise in the input grid due to second-order derivatives. Requires careful handling of zero-gradient regions.
*   **When to use:** When surface curvature is needed for shading, filtering, or feature extraction in volume rendering.
*   **When not to use:** If the input data is very noisy, pre-smoothing is required. If only first-order gradients are needed, use [Gradient Computation via Finite Differences](1077-gradient-computation-via-finite-differences.md).

## Background
The method is implemented in the Lyr.jl library by Tobias Osborne. It leverages the `BoxStencil` abstraction to efficiently access neighborhood data in sparse grid structures like VDB. The formula for mean curvature is a standard differential geometry result applied to discrete grid data.
