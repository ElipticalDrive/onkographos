# Analytic Normal Computation for SDF Grids
Also called: Analytic Normal

## Overview
This method computes the surface normal vector for a Signed Distance Function (SDF) grid by evaluating the analytic derivatives of the cubic polynomial defining the implicit surface within a single voxel [S1, unofficial]. It solves the problem of obtaining smooth, high-quality normals for ray marching without relying on numerical differencing or epsilon-based offset calculations [S1, unofficial]. Unlike its sibling [Analytic Normal Computation](3205-analytic-normal-computation.md), which provides the general framework for spline-based normal derivation, this implementation leverages the bilinear structure of the trilinearly interpolated SDF grid to compute gradients efficiently [S1, unofficial]. It differs from [Analytic Normal Interpolation for SDF Grids](9650-analytic-normal-interpolation-for-sdf-grids.md) by computing normals strictly within the local voxel domain, whereas the interpolation variant evaluates normals from neighboring voxels at the global hit point to ensure $C^0$ continuity across boundaries [S1, unofficial][9650-analytic-normal-interpolation-for-sdf-grids.md].

## How it works
**Inputs:**
*   Signed distance values at the 8 corners of the current voxel: $s_{ijk}$ where $i,j,k \in \{0,1\}$ [S1, unofficial].
*   Local coordinates $(x, y, z)$ of the hit point within the voxel, normalized to the range $[0, 1]$ [S1, unofficial].

**Outputs:**
*   The unnormalized normal vector $\mathbf{n} = (\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z})$ [S1, unofficial].

**Data Structures:**
*   The SDF grid is stored as a dense array of signed distances [G].
*   Voxel corners are accessed via integer offsets relative to the voxel's base index [G].

**Steps:**
1.  Compute the partial derivative with respect to $x$ ($\frac{\partial f}{\partial x}$) by performing a bilinear interpolation of the distance differences along the x-axis [S1, unofficial].
2.  Compute the partial derivative with respect to $y$ ($\frac{\partial f}{\partial y}$) by performing a bilinear interpolation of the distance differences along the y-axis [S1, unofficial].
3.  Compute the partial derivative with respect to $z$ ($\frac{\partial f}{\partial z}$) by performing a bilinear interpolation of the distance differences along the z-axis [S1, unofficial].
4.  Assemble the normal vector $\mathbf{n}$ from the three components [S1, unofficial].
5.  Normalize $\mathbf{n}$ to obtain the unit normal (optional, depending on downstream usage) [G].

**Formulas:**
The partial derivative with respect to $x$ is given by [S1, unofficial]:
$$
\frac{\partial f(x,y,z)}{\partial x} = (1-y)(1-z)(s_{100} - s_{000}) + y(1-z)(s_{110} - s_{010}) + (1-y)z(s_{101} - s_{001}) + yz(s_{111} - s_{011})
$$
This expands to a bilinear interpolation [S1, unofficial]:
$$
y_0 = \text{lerp}(y, s_{100} - s_{000}, s_{110} - s_{010})
$$
$$
y_1 = \text{lerp}(y, s_{101} - s_{001}, s_{111} - s_{011})
$$
$$
\frac{\partial f}{\partial x} = \text{lerp}(z, y_0, y_1)
$$

The partial derivative with respect to $y$ is given by [S1, unofficial]:
$$
\frac{\partial f(x,y,z)}{\partial y} = (1-x)(1-z)(s_{010} - s_{000}) + x(1-z)(s_{110} - s_{100}) + (1-x)z(s_{011} - s_{001}) + xz(s_{111} - s_{101})
$$
Rewritten as bilinear interpolation [S1, unofficial]:
$$
x_0 = \text{lerp}(x, s_{010} - s_{000}, s_{110} - s_{100})
$$
$$
x_1 = \text{lerp}(x, s_{011} - s_{001}, s_{111} - s_{101})
$$
$$
\frac{\partial f}{\partial y} = \text{lerp}(z, x_0, x_1)
$$

The partial derivative with respect to $z$ is given by [S1, unofficial]:
$$
\frac{\partial f(x,y,z)}{\partial z} = (1-x)(1-y)(s_{001} - s_{000}) + x(1-y)(s_{101} - s_{100}) + (1-x)y(s_{011} - s_{010}) + xy(s_{111} - s_{110})
$$
Rewritten as bilinear interpolation [S1, unofficial]:
$$
x_0 = \text{lerp}(x, s_{001} - s_{000}, s_{101} - s_{100})
$$
$$
x_1 = \text{lerp}(x, s_{011} - s_{010}, s_{111} - s_{110})
$$
$$
\frac{\partial f}{\partial z} = \text{lerp}(y, x_0, x_1)
$$

The linear interpolation function is defined as [S1, unofficial]:
$$
\text{lerp}(u, a, b) = a + u(b - a)
$$
This form is chosen to be FMA (Fused Multiply-Add) friendly [S1, unofficial].

**Pseudocode:**
```python
def compute_analytic_normal(s, x, y, z):
    """
    Computes the analytic normal for an SDF grid voxel.
    
    Args:
        s: Array of 8 signed distance values at voxel corners.
           s[i][j][k] corresponds to s_ijk.
           Indices i, j, k are 0 or 1.
        x, y, z: Local coordinates of the hit point within the voxel [0, 1].
        
    Returns:
        Tuple (nx, ny, nz) representing the unnormalized normal vector.
    """
    # Helper for FMA-friendly linear interpolation
    def lerp(u, a, b):
        return a + u * (b - a)

    # Compute x-component of the normal (partial derivative w.r.t x)
    diff_y0 = s[1][0][0] - s[0][0][0] # s_100 - s_000
    diff_y1 = s[1][1][0] - s[0][1][0] # s_110 - s_010
    y0 = lerp(y, diff_y0, diff_y1)
    
    diff_y2 = s[1][0][1] - s[0][0][1] # s_101 - s_001
    diff_y3 = s[1][1][1] - s[0][1][1] # s_111 - s_011
    y1 = lerp(y, diff_y2, diff_y3)
    
    nx = lerp(z, y0, y1)

    # Compute y-component of the normal (partial derivative w.r.t y)
    diff_x0 = s[0][1][0] - s[0][0][0] # s_010 - s_000
    diff_x1 = s[1][1][0] - s[1][0][0] # s_110 - s_100
    x0 = lerp(x, diff_x0, diff_x1)
    
    diff_x2 = s[0][1][1] - s[0][0][1] # s_011 - s_001
    diff_x3 = s[1][1][1] - s[1][0][1] # s_111 - s_101
    x1 = lerp(x, diff_x2, diff_x3)
    
    ny = lerp(z, x0, x1)

    # Compute z-component of the normal (partial derivative w.r.t z)
    # Using dz0/dz1 to avoid confusion with coordinate z
    dz0 = lerp(x, s[0][0][1] - s[0][0][0], s[1][0][1] - s[1][0][0])
    dz1 = lerp(x, s[0][1][1] - s[0][1][0], s[1][1][1] - s[1][1][0])
    
    nz = lerp(y, dz0, dz1)

    return (nx, ny, nz)
```

**Edge Cases and Pitfalls:**
*   **Continuity:** The resulting normal field is $C^2$ continuous *inside* each voxel because the underlying function is a cubic polynomial [S1, unofficial]. However, the normals are **not** continuous across voxel boundaries ($C^0$ discontinuity) because neighboring voxels define independent surfaces that only meet at $C^0$ continuity [S1, unofficial]. This can cause visible artifacts at voxel edges if not handled by a continuity-preserving variant [G].
*   **Precision:** The use of the FMA-friendly `lerp` form helps maintain precision, but the subtraction of nearby distance values ($s_{100} - s_{000}$) can suffer from catastrophic cancellation if the voxel is very small or the SDF values are very close [G].
*   **Boundaries:** The method assumes the hit point is strictly within $[0,1]^3$. If the hit point is outside the voxel (e.g., due to traversal errors or extrapolation), the bilinear interpolation weights become invalid [G].

## Subtopics

### [Analytic Normal Interpolation for SDF Grids](9650-analytic-normal-interpolation-for-sdf-grids.md)
This method computes continuous surface normals for ray marching through SDF grids by evaluating analytic derivatives at the ray hit point within a "dual voxel" framework, rather than interpolating normals defined at voxel corners [9650-analytic-normal-interpolation-for-sdf-grids.md]. It solves the discontinuity artifacts inherent in standard trilinear normal interpolation or single-voxel analytic gradients by trading strict geometric accuracy for visual smoothness across voxel boundaries [9650-analytic-normal-interpolation-for-sdf-grids.md]. Unlike this method, which computes normals strictly within the local voxel domain, the interpolation variant evaluates normals from neighboring voxels at the global hit point to ensure $C^0$ continuity of the normal field [9650-analytic-normal-interpolation-for-sdf-grids.md]. Choose this variant when visual continuity across voxel edges is critical and the performance cost of sampling neighboring voxels is acceptable.

### Analytic Normal Computation for SDF Grids — Single Voxel
A normal computation method that is not $C^0$ across voxels and uses the distance values of a single voxel [S1, unofficial]. Analytic normals perform similar to the baseline method, as both only use the distance values of a single voxel [S1, unofficial]. It is chosen when traversal methods do not support easy access to neighboring voxels or when memory bandwidth is a constraint [G].

## Operating characteristics
*   **Time Complexity:** The method requires approximately 30 arithmetic operations (additions, subtractions, multiplications) to compute the unnormalized normal vector, excluding the final normalization step [S1, unofficial]. This is significantly faster than the finite difference method of Parker et al., which requires 54 operations [S1, unofficial].
*   **Memory Complexity:** $O(1)$ additional memory per hit point, as it only accesses the 8 corner values of the current voxel [G].
*   **Performance:** In benchmarks using GST-A, SVS-A, and SBS-A traversal methods, analytic normals performed consistently slightly worse than the baseline method (which also uses a single voxel) in terms of frame time, but the difference was minimal [S1, unofficial]. The baseline method was empirically found to have a visual quality comparable to analytic normals [S1, unofficial].
*   **Strengths:** High continuity ($C^2$) within voxels; computationally efficient; no need for epsilon tuning or offset point calculations required by finite difference methods [S1, unofficial].
*   **Limitations:** Discontinuous normals across voxel boundaries can lead to shading artifacts; does not account for the global surface shape beyond the local voxel [G].
*   **When to use:** When high-quality normals within voxels are required and voxel boundary discontinuities are either mitigated by other means (e.g., small voxel size) or acceptable [G].
*   **When not to use:** When strict $C^0$ or higher continuity across voxel boundaries is required for shading; in this case, [Analytic Normal Interpolation for SDF Grids](9650-analytic-normal-interpolation-for-sdf-grids.md) or Falcao normals should be considered [S1, unofficial].

## Background
The method was introduced by Falcao in the paper "Ray tracing of signed distance function grids" [S1, unofficial]. It is based on the analytic differentiation of the cubic polynomial that defines the implicit surface within a voxel, as described in Section 3.1 of the source [S1, unofficial]. The approach contrasts with earlier numerical methods such as forward/backward differencing or the tetrahedral method, which rely on an epsilon value to determine offset points [S1, unofficial]. The analytic approach ensures $C^2$ continuity inside the voxel, addressing the limitations of finite difference approximations [S1, unofficial]. The paper also discusses methods for achieving continuity across voxels, such as the "Falcao normals" method which samples neighboring voxels, but notes that a baseline version not $C^0$ across voxel edges is used for traversal methods where sampling neighbors is not feasible [S1, unofficial].
