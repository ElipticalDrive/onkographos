# Analytical Refractive Index Gradient and Hessian for Acousto-Optic Modulation

Also called: Acousto-Optic Analytical Derivatives, Analytical GRIN Gradient/Hessian

## Overview
This method computes the scalar refractive index gradient and Hessian analytically for in-situ acousto-optic spatial modulation, avoiding the need for spline interpolation or finite difference approximations by leveraging known analytical expressions for the refractive index profile [S1]. It is specifically designed for scenarios where the refractive index is modeled as a Bessel function of cylindrical coordinates, distinguishing it from general analytic gradient methods that rely on basis function derivatives like box-splines or triangle distributions [3199-analytic-gradient-computation-via-box-spline-derivatives.md, 5829-analytic-gradient-computation-for-triangle-distributions.md].

## How it works
**Inputs and Outputs:**
*   **Input:** Cartesian coordinates $(x, y)$, time $t$ (implicit in the profile model), and physical parameters $n_0, n_{\max}, m, K_r$.
*   **Output:** Gradient vector $\nabla n = (\frac{\partial n}{\partial x}, \frac{\partial n}{\partial y})$ and Hessian matrix $H_n$ containing $\frac{\partial^2 n}{\partial x^2}$, $\frac{\partial^2 n}{\partial x \partial y}$, and $\frac{\partial^2 n}{\partial y^2}$.

**Data Structures:**
No complex data structures are required. The computation relies on standard floating-point arithmetic and Bessel function evaluations.

**Step-by-Step Derivation and Computation:**

1.  **Coordinate Transformation:**
    Convert Cartesian coordinates $(x, y)$ to cylindrical coordinates $(r, \phi)$:
    $$r = \sqrt{x^2 + y^2}$$
    $$\phi = \tan^{-1}\left(\frac{y}{x}\right)$$
    *Pitfall:* Handle the case where $r=0$ (the origin) separately to avoid division by zero. In acousto-optic modulation, the refractive index is typically smooth at the origin, but the gradient components involving $1/r$ require limits or specific handling.

2.  **Compute First-Order Partial Derivatives of Coordinates:**
    These are needed for the chain rule application:
    $$\frac{\partial r}{\partial x} = \frac{x}{r}, \quad \frac{\partial r}{\partial y} = \frac{y}{r}$$
    $$\frac{\partial \phi}{\partial x} = -\frac{y}{r^2}, \quad \frac{\partial \phi}{\partial y} = \frac{x}{r^2}$$

3.  **Compute Second-Order Partial Derivatives of $r$:**
    These are needed for the Hessian:
    $$\frac{\partial^2 r}{\partial x^2} = \frac{y^2}{r^4}, \quad \frac{\partial^2 r}{\partial x \partial y} = -\frac{xy}{r^4}, \quad \frac{\partial^2 r}{\partial y^2} = \frac{x^2}{r^4}$$

4.  **Evaluate Bessel Functions:**
    Compute the Bessel function of the first kind of order $m$, denoted $J_m(K_r r)$, and order $m+1$, denoted $J_{m+1}(K_r r)$.
    Compute the derivative $J'_m(K_r r)$ using the identity:
    $$J'_m(K_r r) = \frac{m}{K_r r} J_m(K_r r) - J_{m+1}(K_r r)$$
    Compute the derivative $J'_{m+1}(K_r r)$ similarly:
    $$J'_{m+1}(K_r r) = \frac{m+1}{K_r r} J_{m+1}(K_r r) - J_{m+2}(K_r r)$$
    *Note:* If $J_{m+2}$ is not available, use the recurrence relation $J_{m+2}(z) = \frac{2(m+1)}{z} J_{m+1}(z) - J_m(z)$.

5.  **Compute Gradient Components:**
    The refractive index profile is:
    $$n(r, \phi, t) = n_0 + n_{\max} J_m(K_r r) \cos(m\phi)$$

    The partial derivative with respect to $x$ is:
    $$\frac{\partial n}{\partial x} = n_{\max} \left[ \frac{m}{r} \cos\{(m-1)\phi\} J_m(K_r r) - K_r \cos \phi \cos m\phi J_{m+1}(K_r r) \right]$$

    The partial derivative with respect to $y$ is:
    $$\frac{\partial n}{\partial y} = -n_{\max} \left[ \frac{m}{r} \sin\{(m-1)\phi\} J_m(K_r r) + K_r \sin \phi \cos m\phi J_{m+1}(K_r r) \right]$$

6.  **Compute Hessian Components:**
    The Hessian components are derived by differentiating the gradient expressions. The following formulas provide $\frac{1}{n_{\max}} \frac{\partial^2 n}{\partial x^2}$, $\frac{1}{n_{\max}} \frac{\partial^2 n}{\partial x \partial y}$, and $-\frac{1}{n_{\max}} \frac{\partial^2 n}{\partial y^2}$. Multiply by $n_{\max}$ to get the actual second derivatives.

    $$
    \begin{aligned}
    \frac{1}{n_{\max}} \frac{\partial^2 n}{\partial x^2} &= J_m(K_r r) \left[ -\frac{m}{r^2} \cos\{(m-2)\phi\} + \frac{m^2}{r^2} \sin\{(m-1)\phi\} \sin\phi \right] \\
    &\quad + J'_m(K_r r) \left[ \frac{m}{r} K_r \cos\{(m-1)\phi\} \cos\phi \right] \\
    &\quad - J_{m+1}(K_r r) \frac{K_r y}{r^2} [\sin\phi \cos m\phi + m \cos\phi \sin m\phi] \\
    &\quad - J'_{m+1}(K_r r) [K_r^2 \cos^2\phi \cos m\phi]
    \end{aligned}
    $$

    $$
    \begin{aligned}
    \frac{1}{n_{\max}} \frac{\partial^2 n}{\partial x \partial y} &= -J_m(K_r r) \left[ -\frac{m}{r^2} \sin\{(m-2)\phi\} + \frac{m^2}{r^2} \sin\{(m-1)\phi\} \cos\phi \right] \\
    &\quad + J'_m(K_r r) \left[ \frac{m K_r}{r} \cos\{(m-1)\phi\} \sin\phi \right] \\
    &\quad + J_{m+1}(K_r r) \frac{K_r x}{r^2} [\sin\phi \cos m\phi + m \cos\phi \sin m\phi] \\
    &\quad - J'_{m+1}(K_r r) [K_r^2 \cos\phi \sin\phi \cos m\phi]
    \end{aligned}
    $$

    $$
    \begin{aligned}
    -\frac{1}{n_{\max}} \frac{\partial^2 n}{\partial y^2} &= J_m(K_r r) \left[ -\frac{m}{r^2} \cos\{(m-2)\phi\} + \frac{m^2}{r^2} \cos\{(m-1)\phi\} \cos\phi \right] \\
    &\quad + J'_m(K_r r) \left[ \frac{m K_r}{r} \sin\{(m-1)\phi\} \sin\phi \right] \\
    &\quad + J_{m+1}(K_r r) \frac{K_r x}{r^2} [\cos\phi \cos m\phi - m \sin\phi \sin m\phi] \\
    &\quad + J'_{m+1}(K_r r) [K_r^2 \sin^2\phi \cos m\phi]
    \end{aligned}
    $$
    *Note:* The source provides $-\frac{1}{n_{\max}} \frac{\partial^2 n}{\partial y^2}$. To get $\frac{\partial^2 n}{\partial y^2}$, negate the result of the above expression.

**Parameters:**
*   $n_0$: Base refractive index constant.
*   $n_{\max}$: Maximum refractive index amplitude constant.
*   $m$: Angular mode number (integer).
*   $K_r$: Radial wavenumber or scaling factor.
*   $J_m$: Bessel function of the first kind of order $m$.

        'grad_y': grad_y,

## Subtopics

### Analytical Refractive Index Gradient Computation
This variant computes the spatial index of refraction $\eta(x)$ and its gradient $n(x)$ to define the refractive isosurface normal for refraction calculations, often derived from physical quantities like pressure and temperature using the Hauf-Grigull relation [S2]. It differs from the acousto-optic method by using a gas-state model rather than a Bessel function profile [S2]. The IOR is given by $\eta(x) - 1 = \frac{3}{2} \frac{rMP(x)}{RT(x)}$, where $r$ is gas refractivity, $M$ is molar mass, $R$ is the ideal gas constant, $P$ is pressure, and $T$ is temperature [S2]. The change in IOR between two states is $\eta_2(x) = 1 + (\eta_1(x) - 1) \frac{P_2(x)T_1(x)}{P_1(x)T_2(x)}$ [S2]. Ambient air constants are $\eta_1 = 1.000292$, $P_1 = 101325$ Pa, $T_1 = 300$ K [S2].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per evaluation, dominated by Bessel function evaluations.
*   **Memory Complexity:** $O(1)$, no additional data structures.
*   **Strengths:** Exact derivatives without discretization error; avoids interpolation artifacts; computationally efficient compared to finite differences or spline evaluations.
*   **Limitations:** Only applicable to the specific acousto-optic Bessel profile model; singularities at the origin $r=0$ require special handling.
*   **When to use:** When rendering acousto-optic modulated media where the refractive index profile is known analytically.
*   **When not to use:** For general volume data or other physical models (e.g., gas density) where the profile is not a Bessel function.

## Background
This method originates from research on refractive radiative transfer estimators, specifically for in-situ acousto-optic spatial modulation [S1]. It was developed to provide accurate gradient and Hessian information for photon mapping and BDPT (Bidirectional Path Tracing) without the need for numerical integration or interpolation, which are non-trivial for these estimators [S1]. The use of 100 $\theta$ values for numerical integration in other contexts highlights the advantage of this analytical approach [S1].
