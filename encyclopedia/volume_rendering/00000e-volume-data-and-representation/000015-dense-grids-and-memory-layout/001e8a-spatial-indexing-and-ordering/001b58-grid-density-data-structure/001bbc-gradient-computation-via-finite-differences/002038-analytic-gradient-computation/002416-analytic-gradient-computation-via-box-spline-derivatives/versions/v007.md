# Analytic Gradient Computation via Box-Spline Derivatives

Also called: Derivative Spline Evaluation, Exact Gradient for FCC

## Overview
This method computes the exact gradient vector for volume rendering shading by deriving analytic derivatives of the underlying box-spline basis function, avoiding the approximation errors and additional sampling costs of finite differences [S1]. It is distinguished from its parent method, [Analytic Gradient Computation](2167-analytic-gradient-computation.md), by specifically leveraging the symmetry and support properties of Face-Centered Cubic (FCC) box-splines to reuse existing texture fetches [S1]. Unlike [Analytic Gradient Computation for Triangle Distributions](5829-analytic-gradient-computation-for-triangle-distributions.md), which handles triangular supports, this method operates on the hexagonal/triangular lattice structure of FCC grids [S1].

## How it works
**Inputs and Outputs:**
- Input: Volume data $V$ defined on an FCC grid, position $x$ within the grid [S1].
- Output: Gradient vector $\nabla s(x)$ where $s(x) = V * M_{\text{fcc}}$ is the reconstructed scalar field [S1].

**Data Structures:**
- The method relies on precomputed B-spline coefficients (BB-coefficients) for the derivative kernel $M_{110}$ across three polynomial piece types: $\tau_0, \tau_2, \tau_4$ [S1]. These coefficients define the stencil weights for the derivative evaluation [S1].
- The support of the derivative kernel $M_{110}$ is a subset of the support of the primary FCC box-spline $M_{\text{fcc}}$ [S1].

**Steps:**
1. **Fetch Samples:** Retrieve the 19 voxel values required for the primary FCC box-spline evaluation at position $x$. These samples are reused for gradient computation [S1].
2. **Compute Directional Derivatives:** Calculate three directional derivatives $d_{110}, d_{101}, d_{011}$ along the vectors $\xi_{110}, \xi_{101}, \xi_{011}$ respectively [S1].
   - Due to permutational symmetries, only the BB-coefficients for $M_{110}$ are explicitly needed. The kernels for $M_{101}$ and $M_{011}$ are obtained via index permutation [S1].
   - Evaluate the derivative kernel $M_{110}$ using the de Casteljau algorithm. Because $M_{110}$ has lower symmetry than $M_{\text{fcc}}$, the evaluation must distinguish between three polynomial piece types: $\tau_0, \tau_2$, and $\tau_4$ [S1].
   - The directional derivative is defined as $d_\xi = V * M_\xi$ [S1].
3. **Reconstruct Gradient:** Combine the directional derivatives to form the Cartesian gradient vector using the linear combination defined in the Formulas section [S1].

**Formulas:**
The directional derivative of the FCC box-spline $M_{\text{fcc}}$ along a direction $\xi \in \Xi_{\text{fcc}}$ is expressed as another box-spline $M_\xi$ [S1]:
$$
D_\xi M_{\text{fcc}} = \nabla_\xi 2M_{\Xi_{\text{fcc}} \setminus \{\xi\}}(\cdot + \xi_c)
$$
where $\nabla_\xi$ is the backward difference operator [S1]. The kernel $M_\xi$ is defined as [S1]:
$$
M_\xi(x) = 2M_{\Xi_{\text{rec}} \setminus \{\xi\}}(x + \xi_c) - 2M_{\Xi_{\text{rec}} \setminus \{\xi\}}(x + \xi_c - \xi)
$$
Here, $\Xi_{\text{rec}}$ represents the set of directions defining the reconstruction spline, and $\xi_c$ is a centering vector [S1]. Since each derivative kernel $M_\xi$ is the sum of two box-splines, it can be computed similarly to $M_{\text{fcc}}$ using the de Casteljau algorithm [S1]. The gradient reconstruction combines the directional derivatives as follows [S1]:
$$
\nabla(V * M_{\text{fcc}}) = \frac{1}{2} \begin{bmatrix} d_{110} + d_{101} - d_{011} \\ d_{110} + d_{011} - d_{101} \\ d_{101} + d_{011} - d_{110} \end{bmatrix}
$$

**Pseudocode:**
```python
def compute_analytic_gradient_fcc(volume_data, position):
    # Step 1: Fetch the 19 samples required for the primary FCC spline evaluation [S1].
    # FCC_OFFSETS is assumed to be a list of 19 relative lattice offsets.
    samples = [volume_data(offset) for offset in FCC_OFFSETS]

    # Step 2: Compute directional derivative d_110
    # Determine the polynomial piece type (tau_0, tau_2, or tau_4) based on
    # the local lattice coordinates of the query position [S1].
    # Note: The exact mapping from continuous position to piece type is not given in the sources [G].
    piece_type = get_polynomial_piece_type(position)

    # Retrieve precomputed BB-coefficients for M_110 corresponding to the piece type [S1].
    # BB_COEFFICIENTS_M110 is assumed to be a dict mapping piece_type to a list of 19 weights.
    coeffs_110 = BB_COEFFICIENTS_M110[piece_type]

    # Evaluate M_110 using the de Casteljau algorithm or direct stencil convolution [S1].
    d_110 = sum(s * c for s, c in zip(samples, coeffs_110))

    # Step 3: Compute directional derivatives d_101 and d_011
    # Due to permutational symmetries, these are obtained by permuting the
    # sample indices and coefficients of d_110 [S1].
    # Note: The exact permutation indices for the FCC lattice are not given in the sources [G].
    # PERM_101 and PERM_011 are assumed to be lists of 19 integer indices.
    samples_101 = [samples[i] for i in PERM_101]
    coeffs_101 = [coeffs_110[i] for i in PERM_101]
    d_101 = sum(s * c for s, c in zip(samples_101, coeffs_101))

    samples_011 = [samples[i] for i in PERM_011]
    coeffs_011 = [coeffs_110[i] for i in PERM_011]
    d_011 = sum(s * c for s, c in zip(samples_011, coeffs_011))

    # Step 4: Reconstruct the gradient vector using the linear combination [S1].
    grad_x = 0.5 * (d_110 + d_101 - d_011)
    grad_y = 0.5 * (d_{110} + d_{011} - d_{101})
    grad_z = 0.5 * (d_{101} + d_{011} - d_{110})

    return (grad_x, grad_y, grad_z)
```

**Parameters:**
- Polynomial piece types: $\tau_0, \tau_2, \tau_4$ [S1]. The specific type is determined by the position of the query point within the FCC lattice unit cell [G].
- Stencil size: 19 samples (same as primary FCC spline evaluation) [S1].

**Edge Cases and Pitfalls:**
- **Precision:** The method avoids finite difference step-size selection errors. However, the de Casteljau algorithm and linear combinations must be implemented with sufficient floating-point precision to avoid accumulation errors, especially for high-resolution volumes [G].
- **Boundaries:** The support of $M_{110}$ is a subset of $M_{\text{fcc}}$. Boundary conditions must be handled consistently with the primary spline evaluation (e.g., clamping, wrapping, or zero-padding) to ensure the reused samples are valid [G].
- **Degenerate Input:** If the volume data is not defined on a regular FCC grid, the lattice coordinate calculation for piece type determination will fail [G].

## Subtopics

### [Analytic Normal Computation](3205-analytic-normal-computation.md)
Analytic Normal Computation computes surface normal vectors for volume rendering by deriving the gradient directly from the underlying spline basis function, rather than approximating it via finite differences. It solves the problem of normal inaccuracy inherent in numerical differencing, where the choice of offset step size creates a trade-off between rounding errors (small offsets) and approximation errors (large offsets) [G]. It is distinguished from its sibling [Analytic Normal Computation for SDF Grids](9645-analytic-normal-computation-for-sdf-grids.md) by providing the general framework for spline-based normal derivation, whereas the SDF variant leverages the specific bilinear structure of trilinearly interpolated Signed Distance Function grids.

## Operating characteristics
- **Time Complexity:** The method requires evaluating three derivative kernels ($M_{110}, M_{101}, M_{011}$) [S1]. However, due to symmetry, only one set of coefficients is needed, and the same 19 samples are reused [S1]. The derivative kernels are quadratic, allowing for fast evaluation via the de Casteljau algorithm [S1].
- **Memory Complexity:** No additional memory is required beyond the 19 samples fetched for the primary spline evaluation [S1].
- **Performance:** This method is significantly faster than finite difference approaches, which require six additional spline evaluations (114 additional samples) to compute the gradient [S1]. The reuse of samples reduces memory bandwidth pressure [S1].
- **Strengths:** Exact gradient computation; no approximation error from step size; reduced memory bandwidth compared to finite differences [S1].
- **Limitations:** Requires precomputed BB-coefficients for the derivative kernels; implementation complexity is higher than finite differences due to the need to handle polynomial piece types and symmetry permutations [S1].

## Background
This method was introduced by Minho Kim and Jürgen Peters in their 2012 paper "GPU Isosurface Raycasting of FCC Datasets" [S1]. It addresses the need for efficient and accurate gradient computation for volume rendering on Face-Centered Cubic (FCC) grids, which are known for their optimal packing density and interpolation properties [S1]. The method leverages the mathematical property that the directional derivative of a box-spline is another box-spline, allowing for analytic evaluation without numerical approximation [S1].
