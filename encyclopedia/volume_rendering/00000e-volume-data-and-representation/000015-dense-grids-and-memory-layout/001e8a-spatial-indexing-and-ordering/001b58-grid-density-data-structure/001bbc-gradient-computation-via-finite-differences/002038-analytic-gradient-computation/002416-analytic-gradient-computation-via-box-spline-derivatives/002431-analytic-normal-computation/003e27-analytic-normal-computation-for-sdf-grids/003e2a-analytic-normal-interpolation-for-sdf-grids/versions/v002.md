# Analytic Normal Interpolation for SDF Grids

Also called: Proposed normal method, Dual Voxel Normal Interpolation

## Overview
This method computes continuous surface normals for ray marching through Signed Distance Function (SDF) grids by evaluating analytic derivatives at the ray hit point within a "dual voxel" framework, rather than interpolating normals defined at voxel corners [S1, unofficial]. It solves the discontinuity artifacts inherent in standard trilinear normal interpolation or single-voxel analytic gradients by trading strict geometric accuracy for visual smoothness across voxel boundaries [S1, unofficial]. Unlike its sibling [Analytic Normal Computation for SDF Grids](9645-analytic-normal-computation-for-sdf-grids.md), which computes normals strictly within the local voxel domain, this method evaluates normals from neighboring voxels at the global hit point to ensure $C^0$ continuity of the normal field [S1, unofficial].

## How it works
**Inputs:**
- Ray hit point $\mathbf{p} = (x, y, z)$ in world space [S1, unofficial].
- Voxel grid dimensions and spacing [G].
- SDF values $s_{ijk}$ for a $4 \times 4 \times 4$ neighborhood centered on the voxel containing the hit point [S1, unofficial].

**Outputs:**
- Interpolated surface normal $\mathbf{n}$ [S1, unofficial].

**Data Structures:**
- SDF Grid: Stores $s_{ijk}$ values. To support this method efficiently, the implementation must store $4 \times 4 \times 4$ SDF values per voxel to avoid excessive runtime lookups [S1, unofficial].

**Step 1: Define the Dual Voxel**
A "dual voxel" is defined as a voxel shifted by half the voxel dimensions in all axes relative to the standard grid [S1, unofficial]. Any hit point $\mathbf{p}$ falls inside exactly one dual voxel, which overlaps $2 \times 2 \times 2$ standard voxels [S1, unofficial]. Let the indices of these 8 surrounding standard voxels be $(i, j, k)$ where $i, j, k \in \{0, 1\}$ relative to the dual voxel's local coordinate system [S1, unofficial].

**Step 2: Compute Local Coordinates**
Calculate the position $(u, v, w)$ of the hit point $\mathbf{p}$ within the dual voxel [S1, unofficial]. These coordinates are normalized to the range $[0, 1]^3$ [S1, unofficial].

**Step 3: Evaluate Analytic Normals**
For each of the 8 surrounding voxels $(i, j, k)$, compute the analytic normal $\mathbf{n}_{ijk}$ at the hit point $\mathbf{p}$ [S1, unofficial]. This involves computing the gradient of the SDF polynomial defined by that voxel's data, evaluated at $\mathbf{p}$, and normalizing the result [S1, unofficial]. The gradient components are computed using bilinear interpolation of distance differences [S1, unofficial]. For the x-component, using local coordinates $(y, z)$ relative to the voxel's origin:
$$
\frac{\partial f}{\partial x} = (1-y)(1-z)(s_{100} - s_{000}) + y(1-z)(s_{110} - s_{010}) + (1-y)z(s_{101} - s_{001}) + yz(s_{111} - s_{011})
$$
Similar formulas apply for $\frac{\partial f}{\partial y}$ and $\frac{\partial f}{\partial z}$, using the appropriate SDF values from the $4 \times 4 \times 4$ neighborhood associated with voxel $(i,j,k)$ [S1, unofficial]. The normal is then:
$$
\mathbf{n}_{ijk} = \frac{\nabla f(\mathbf{p})}{\|\nabla f(\mathbf{p})\|}
$$
Note that for 7 out of 8 voxels, the hit point $\mathbf{p}$ lies outside the standard domain of that voxel, meaning the analytic normal is computed "outside" the voxel's local bounds [S1, unofficial].

**Step 4: Trilinear Interpolation of Normals**
Interpolate the 8 computed normals $\mathbf{n}_{ijk}$ using trilinear interpolation weights based on $(u, v, w)$ [S1, unofficial]. The final normal $\mathbf{n}$ is:
$$
\mathbf{n} = \sum_{i=0}^{1} \sum_{j=0}^{1} \sum_{k=0}^{1} w_{ijk}(u,v,w) \mathbf{n}_{ijk}
$$
where the weights $w_{ijk}$ are the standard trilinear basis functions:
$$
w_{ijk} = u^i (1-u)^{1-i} v^j (1-v)^{1-j} w^k (1-w)^{1-k}
$$
[S1, unofficial]

**Pseudocode:**
```python
def compute_analytic_normal_interpolation(p, voxel_size, sdf_grid):
    # p: (x, y, z) hit point in world space
    # voxel_size: float, side length of a standard voxel
    # sdf_grid: dict mapping (base_i, base_j, base_k) to 4x4x4 array of SDF values
    
    # 1. Find base voxel containing p
    base_i = floor(p.x / voxel_size)
    base_j = floor(p.y / voxel_size)
    base_k = floor(p.z / voxel_size)
    
    # 2. Compute dual voxel local coordinates (u, v, w) in [0, 1]^3
    u = (p.x - (base_i + 0.5) * voxel_size) / voxel_size
    v = (p.y - (base_j + 0.5) * voxel_size) / voxel_size
    w = (p.z - (base_k + 0.5) * voxel_size) / voxel_size
    
    # 3. Evaluate analytic normals for 8 surrounding voxels
    normals = []
    for i in range(2):
        for j in range(2):
            for k in range(2):
                # Get 4x4x4 SDF block for voxel (base_i+i, base_j+j, base_k+k)
                block = sdf_grid[(base_i + i, base_j + j, base_k + k)]
                
                # Local coordinates relative to this voxel's origin
                y = (p.y - (base_j + j) * voxel_size) / voxel_size
                z = (p.z - (base_k + k) * voxel_size) / voxel_size
                
                # Compute gradient components using bilinear interpolation of differences
                dx = (1-y)*(1-z)*(block[1,0,0] - block[0,0,0]) + \
                     y*(1-z)*(block[1,1,0] - block[0,1,0]) + \
                     (1-y)*z*(block[1,0,1] - block[0,0,1]) + \
                     y*z*(block[1,1,1] - block[0,1,1])
                     
                dy = (1-x)*(1-z)*(block[0,1,0] - block[0,0,0]) + \
                     x*(1-z)*(block[1,1,0] - block[0,1,0]) + \
                     (1-x)*z*(block[0,1,1] - block[0,0,1]) + \
                     x*z*(block[1,1,1] - block[0,1,1])
                     
                dz = (1-x)*(1-y)*(block[0,0,1] - block[0,0,0]) + \
                     x*(1-y)*(block[1,0,1] - block[0,0,1]) + \
                     (1-x)*y*(block[0,1,1] - block[0,0,1]) + \
                     x*y*(block[1,1,1] - block[0,1,1])
                     
                # Normalize to get analytic normal
                grad = (dx, dy, dz)
                norm = sqrt(dx*dx + dy*dy + dz*dz)
                normals.append((grad[0]/norm, grad[1]/norm, grad[2]/norm))
    
    # 4. Trilinear interpolation of the 8 normals
    result = (0.0, 0.0, 0.0)
    idx = 0
    for i in range(2):
        for j in range(2):
            for k in range(2):
                w_ijk = (u**i * (1-u)**(1-i)) * (v**j * (1-v)**(1-j)) * (w**k * (1-w)**(1-k))
                result = (result[0] + w_ijk * normals[idx][0],
                          result[1] + w_ijk * normals[idx][1],
                          result[2] + w_ijk * normals[idx][2])
                idx += 1
                
    # Final normalization
    norm = sqrt(result[0]**2 + result[1]**2 + result[2]**2)
    return (result[0]/norm, result[1]/norm, result[2]/norm)
```

**Pitfalls:**
- **Domain Extrapolation:** Normals are computed outside the usual domain of a voxel in seven out of eight cases [S1, unofficial]. This extrapolation is necessary for continuity but means the normals do not correspond exactly to the original discontinuous geometric normals at voxel boundaries [S1, unofficial].
- **Storage Requirement:** The method requires storing $4 \times 4 \times 4$ SDF values per voxel [S1, unofficial]. Reducing this to $2 \times 2 \times 2$ makes the runtime substantially larger due to increased lookup overhead [S1, unofficial].
- **Geometric Accuracy:** The resulting normals are smooth but do not strictly correspond to the mathematical normals of the surface [S1, unofficial]. The method trades geometric accuracy for visual smoothness [S1, unofficial].

## Subtopics

### Dual Voxel Normal Interpolation
This is the core mechanism of the method. It defines the dual voxel as a voxel shifted by half the voxel dimensions in all axes [S1, unofficial]. Any hit point falls inside a single dual voxel, which overlaps $2 \times 2 \times 2$ neighboring voxels [S1, unofficial]. The method evaluates the analytic normal in each of the 8 surrounding voxels at the hit point's coordinates and interpolates the 8 normals using trilinear interpolation weights based on the hit point's position $(u, v, w)$ within the dual voxel [S1, unofficial]. Unlike PN triangles, which compute normals corresponding to the surface, this method computes continuous normals that appear reasonable but do not strictly correspond to the mathematical normals of the surface [S1, unofficial]. Simple trilinear interpolation of normals shared at voxel corners suffers from quality issues and is insufficient for reasonable normals in complex scenes [S1, unofficial].

## Operating characteristics
- **Time Complexity:** The method is more expensive than single-voxel analytic normals [S1, unofficial]. It uses 1.1–4.2% more time per frame on average for GST-A and 1.0–7.3% more time per frame on average for SVS-A compared to the baseline method [S1, unofficial].
- **Memory Complexity:** Requires storing $4 \times 4 \times 4$ SDF values per voxel [S1, unofficial]. Without this storage, the runtime was substantially larger [S1, unofficial].
- **Performance:** Tested on an Intel Core i9 10980XE (3.00 GHz) with 128 GB DDR4 (2.4 GHz) and NVIDIA RTX 3090 [S1, unofficial]. The method provides superior results for closeups compared to Falcao normals and standard analytic normals [S1, unofficial].
- **Strengths:** Delivers continuous normals across voxel boundaries, avoiding the visual artifacts of discontinuous normals [S1, unofficial].
- **Limitations:** Does not correspond exactly to the original geometric normals; requires significant memory overhead for SDF storage [S1, unofficial].

## Background
This method was proposed in the context of ray tracing SDF grids to address the discontinuity of normals at voxel boundaries [S1, unofficial]. It is similar in spirit to the approach used for PN triangles [Vlachos et al. 2001], where normals are interpolated to achieve smooth shading [S1, unofficial]. The method was introduced in "Ray tracing of signed distance function grids" [S1, unofficial].
