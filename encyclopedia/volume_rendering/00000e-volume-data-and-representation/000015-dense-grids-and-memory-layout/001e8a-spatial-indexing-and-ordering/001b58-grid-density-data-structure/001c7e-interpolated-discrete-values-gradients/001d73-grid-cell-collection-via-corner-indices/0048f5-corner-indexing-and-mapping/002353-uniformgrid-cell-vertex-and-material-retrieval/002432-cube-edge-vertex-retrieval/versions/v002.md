# Cube Edge Vertex Retrieval
Also called: Edge Retrieval
## Overview
Retrieves all 12 edge vertex pairs for a specific cube in the voxel grid [S1, unofficial]. It differs from its parent [UniformGrid Cell Vertex and Material Retrieval](2999-uniformgrid-cell-vertex-and-material-retrieval.md) by focusing specifically on the 12 edges rather than the 8 corner vertices [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: `cube_idx` (linear index of the target cube), `grid` (data structure containing vertex data) [S1, unofficial].
- Output: A list of 12 pairs, where each pair contains the linear indices of the two vertices defining an edge [S1, unofficial].

**Data Structures:**
- `CUBE_EDGES_FLAT`: A static lookup table of size 24 (12 edges × 2 vertices) that maps edge index $e$ to the local corner indices $c_0$ and $c_1$ within the cube [S1, unofficial].
  - Layout: `int CUBE_EDGES_FLAT[24]` [S1, unofficial].
  - Access: For edge $e$, corners are at indices $2e$ and $2e+1$ [S1, unofficial].
- `grid.cubes`: A 1D array or tensor storing vertex linear indices for all cubes [S1, unofficial].
  - Access pattern: `grid.cubes(cube_idx, local_corner_index)` [S1, unofficial].

**Steps:**
1. Initialize an empty list `edge_pairs` [S1, unofficial].
2. Loop $e$ from 0 to 11 (inclusive) [S1, unofficial]:
   a. Retrieve the first local corner index: $c_0 = \text{CUBE\_EDGES\_FLAT}[2e]$ [S1, unofficial].
   b. Retrieve the second local corner index: $c_1 = \text{CUBE\_EDGES\_FLAT}[2e+1]$ [S1, unofficial].
   c. Retrieve the global linear index of the first vertex: $v_0 = \text{grid.cubes}(\text{cube\_idx}, c_0)$ [S1, unofficial].
   d. Retrieve the global linear index of the second vertex: $v_1 = \text{grid.cubes}(\text{cube\_idx}, c_1)$ [S1, unofficial].
   e. Append the pair $\{v_0, v_1\}$ to `edge_pairs` [S1, unofficial].
3. Return `edge_pairs` [S1, unofficial].

**Pseudocode:**
```python
def retrieve_cube_edges(cube_idx, grid):
    # Standard cube edge connectivity mapping 12 edges to 24 local corner indices
    CUBE_EDGES_FLAT = [0, 1, 1, 2, 2, 3, 3, 0, 4, 5, 5, 6, 6, 7, 7, 4, 0, 4, 1, 5, 2, 6, 3, 7]
    edge_pairs = []
    
    for e in range(12):
        c0 = CUBE_EDGES_FLAT[e * 2]
        c1 = CUBE_EDGES_FLAT[e * 2 + 1]
        v0 = grid.cubes[cube_idx][c0]
        v1 = grid.cubes[cube_idx][c1]
        edge_pairs.append((v0, v1))
        
    return edge_pairs
```

**Parameters:**
- `CUBE_EDGES_FLAT`: Standard cube edge connectivity. Not given in the sources. [G]

**Edge Cases:**
- Invalid `cube_idx`: If `cube_idx` is out of bounds, the grid lookup will fail. [G]
- Degenerate cubes: The method returns indices regardless of whether the cube is valid or empty. [G]

## Subtopics

### [Cube SDF Sampling and Sign Configuration](3639-cube-sdf-sampling-and-sign-configuration.md)
Constructs the topological state of a single voxel cube for Marching Cubes by sampling a Signed Distance Field (SDF) at its eight vertices. It differs by handling degenerate cases where SDF values equal the threshold. It builds on [Cube Edge Vertex Retrieval](3217-cube-edge-vertex-retrieval.md) by providing the vertex data and sign flags required to identify which edges intersect the surface.

## Operating characteristics
- Time Complexity: $O(1)$ per cube, as it performs a fixed number of 12 lookups [G].
- Memory Complexity: $O(1)$ auxiliary space for the loop and pair storage [G].
- Strengths: Extremely fast, deterministic, and cache-friendly due to small, fixed-size access patterns [G].
- Limitations: Only provides connectivity; does not perform interpolation or surface detection itself [G].
- When to use: When implementing surface extraction algorithms that require edge-based traversal or triangle generation [G].
- When not to use: When only vertex positions or material properties are needed without edge connectivity [G].

## Background
Originated in the context of voxel-based surface extraction, specifically within implementations like FlexiCubes [S1, unofficial].
