# VoxelGrid

Also called: 3D Voxel Grid, Differentiable Voxel Grid, Learnable Voxel Grid, Neural Voxel Grid

## Overview
VoxelGrid is a dense, learnable 3D data structure that represents a parameterized function (such as density and color in neural radiance fields) by storing values at the corners of a regular grid, enabling differentiable trilinear interpolation. It differs from its parent, [Grid Cell Collection via Corner Indices](1518-grid-cell-collection-via-corner-indices.md), by providing a concrete, trainable tensor implementation with automatic boundary clamping, and from [Curvilinear to Rectilinear Resampling](2248-curvilinear-to-rectilinear-resampling.md) by maintaining a fixed, axis-aligned topology rather than mapping irregular coordinates.

## How it works
**Inputs and Outputs:**
- Input: A tensor $P$ of shape $(N, 3)$ containing $N$ query points with coordinates $(x, y, z)$.
- Output: A tensor of shape $(N, d)$ containing the interpolated values (e.g., density, RGB) at those points.

**Data Structures:**
The core data structure is a learnable parameter tensor `grid`.
- Layout: The grid stores values at the corners of the voxels to facilitate trilinear interpolation.
- Dimensions: If the logical grid dimensions are `shape` = $(S_x, S_y, S_z)$, the storage tensor has shape $(S_x+1, S_y+1, S_z+1, d)$.
- Fields: The tensor contains floating-point values (typically `float32`). $d$ is the output dimensionality (e.g., 1 for scalar density, 3 for RGB color).

**Parameters:**
- `shape`: Tuple of integers defining the logical grid dimensions (e.g., $(6, 6, 6)$).
- `d`: Integer defining the output dimensionality (default 1).
- `max`: Float defining the maximum value for random initialization (default 1.0).
- `fill`: Optional tensor or value used for initialization instead of random values.

**Algorithm Steps:**
1. **Initialization**: Create the `grid` parameter with shape $(S_x+1, S_y+1, S_z+1, d)$. Initialize with random values scaled by `max` or provided `fill`.
2. **Coordinate Extraction**: Extract $x, y, z$ coordinate vectors from the input points $P$.
3. **Bracketing**: For each coordinate axis, determine the lower and upper grid indices and the interpolation weight.
   - Compute $x_0 = \lfloor x \rfloor$.
   - Set $X_0 = \text{clamp}(x_0, 0, S_x)$ and $X_1 = \text{clamp}(x_0 + 1, 0, S_x)$.
   - Compute weight $\alpha = \text{clamp}(x - x_0, 0.0, 1.0)$.
   - Repeat for $y$ (indices $Y_0, Y_1$, weight $\beta$) and $z$ (indices $Z_0, Z_1$, weight $\gamma$).
4. **Trilinear Interpolation**:
   - **X-direction**: Interpolate along the x-axis for all 4 combinations of $(Y, Z)$ corners:
     $$ v_{y0z0} = v(X_0, Y_0, Z_0) \cdot (1-\alpha) + v(X_1, Y_0, Z_0) \cdot \alpha $$
     $$ v_{y1z0} = v(X_0, Y_1, Z_0) \cdot (1-\alpha) + v(X_1, Y_1, Z_0) \cdot \alpha $$
     $$ v_{y0z1} = v(X_0, Y_0, Z_1) \cdot (1-\alpha) + v(X_1, Y_0, Z_1) \cdot \alpha $$
     $$ v_{y1z1} = v(X_0, Y_1, Z_1) \cdot (1-\alpha) + v(X_1, Y_1, Z_1) \cdot \alpha $$
   - **Y-direction**: Interpolate the results from the previous step along the y-axis:
     $$ v_{z0} = v_{y0z0} \cdot (1-\beta) + v_{y1z0} \cdot \beta $$
     $$ v_{z1} = v_{y0z1} \cdot (1-\beta) + v_{y1z1} \cdot \beta $$
   - **Z-direction**: Interpolate the results along the z-axis:
     $$ v = v_{z0} \cdot (1-\gamma) + v_{z1} \cdot \gamma $$
5. **Output**: Return the final interpolated values, removing the trailing dimension if necessary.

**Pseudocode:**
```python
import torch
import torch.nn as nn

def bracket(x, n):
    """
    Return the indices of the nearest grid points to x, as well as weights.
    x: tensor of coordinates
    n: grid dimension size (e.g., shape[0])
    """
    x0 = torch.floor(x).long()
    # Clamp indices to [0, n-1] to handle boundaries
    X0 = torch.clamp(x0, min=0, max=(n - 1))
    X1 = torch.clamp(x0 + 1, min=0, max=(n - 1))
    # Clamp weight to [0.0, 1.0]
    alpha = torch.clamp(x - x0.float(), min=0.0, max=1.0)
    return X0, X1, alpha

def interpolate(v0, v1, alpha):
    """
    Interpolate between v0 and v1 using alpha.
    Handles batch dimensions by unsqueezing alpha.
    """
    # Ensure alpha has the correct shape for broadcasting
    alpha_expanded = alpha.unsqueeze(-1)
    return v0 * (1 - alpha_expanded) + v1 * alpha_expanded

class VoxelGrid(nn.Module):
    def __init__(self, shape, d=1, max_val=1.0, fill=None):
        """
        A 3D voxel grid with given `shape` with learnable values.
        Stores corner values for trilinear interpolation.
        """
        super(VoxelGrid, self).__init__()
        # Storage shape includes +1 in each dimension for corners
        storage_shape = tuple(s + 1 for s in shape)
        
        if fill is not None:
            # Reshape fill to broadcast correctly if needed
            self.grid = nn.Parameter(fill.view(1, 1, 1, d).repeat(*storage_shape, 1))
        else:
            # Initialize with random values scaled by max_val
            self.grid = nn.Parameter(torch.rand(*storage_shape, d, dtype=torch.float32) * max_val)

    def forward(self, P):
        """
        Implement trilinear interpolation at the points P.
        P: tensor of shape (N, 3)
        """
        x, y, z = P[..., 0], P[..., 1], P[..., 2]

        # Get indices of the corners, clamping to the grid size where needed
        X0, X1, a = bracket(x, self.grid.shape[0])
        Y0, Y1, b = bracket(y, self.grid.shape[1])
        Z0, Z1, c = bracket(z, self.grid.shape[2])

        # Interpolate in the x direction for all y, z combinations
        y0z0 = interpolate(self.grid[X0, Y0, Z0, :], self.grid[X1, Y0, Z0, :], a)
        y1z0 = interpolate(self.grid[X0, Y1, Z0, :], self.grid[X1, Y1, Z0, :], a)
        y0z1 = interpolate(self.grid[X0, Y0, Z1, :], self.grid[X1, Y0, Z1, :], a)
        y1z1 = interpolate(self.grid[X0, Y1, Z1, :], self.grid[X1, Y1, Z1, :], a)

        # Interpolate in the y direction
        z0 = interpolate(y0z0, y1z0, b)
        z1 = interpolate(y0z1, y1z1, b)

        # Interpolate in the z direction
        result = interpolate(z0, z1, c)
        
        # Squeeze the last dimension if d=1 and output is expected to be 1D
        return result.squeeze(-1)
```

**Edge Cases and Pitfalls:**
- **Boundary Handling**: Query points outside the grid bounds must be clamped to the nearest valid index $[0, n-1]$ to prevent out-of-bounds memory access. The `bracket` function handles this via `torch.clamp` [S1].
- **Precision**: Floating-point precision in coordinate extraction ($\lfloor x \rfloor$) and weight calculation ($x - \lfloor x \rfloor$) can introduce small errors, but clamping weights to $[0, 1]$ mitigates instability [S1].
- **Initialization**: Random initialization scale (`max`) affects training stability; values should be consistent with the target range of the output (e.g., density or color) [S1].

## Operating characteristics
- **Time Complexity**: $O(N)$ for $N$ query points, as each point requires a constant number of tensor lookups and arithmetic operations.
- **Memory Complexity**: $O(S_x \cdot S_y \cdot S_z \cdot d)$, where $S$ are the grid dimensions and $d$ is the feature dimension. The $+1$ per dimension is negligible for large grids.
- **Performance**: Significantly faster than MLP-based representations (like original NeRF) because it replaces neural network inference with simple tensor indexing and interpolation [S1].
- **Strengths**: Differentiable, easy to implement, fast inference, compatible with standard deep learning frameworks.
- **Limitations**: Fixed resolution; high resolution requires large memory. Cannot represent infinite domains without coordinate transformation.

## Background
VoxelGrid was introduced as a key component in Differentiable Volumetric Graphics (DVGO), a method proposed as a faster alternative to the original Neural Radiance Field (NeRF) which used a fully connected MLP [S1]. By storing density and color in a voxel grid and using differentiable trilinear interpolation, DVGO enabled efficient training and rendering of neural radiance fields [S1]. This approach is widely used in modern neural rendering pipelines for its balance of speed and quality.
