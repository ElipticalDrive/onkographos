# Quantile Mean Integration

Also called: Quantile Mean Technique

## Overview
Quantile Mean Integration is a volume rendering integration scheme for Direct Volume Rendering (DVR) that computes the expected fragment color by evaluating the Transfer Function (TF) at the mean intensity of each quantile, weighted by the discrete probability of that quantile [S1]. It differs from [Quantile Range Integration](5246-quantile-range-integration.md) by approximating the continuous distribution within each quantile with a single point mass (the mean) rather than integrating the TF over the quantile's intensity interval [S1].

## How it works
**Inputs and Outputs:**
- **Input:** A set of $q$ quantiles $Q_1, \dots, Q_q$ for an interpolated random variable $X$. Each quantile $Q_j$ is associated with a weight $w_j$ and a scalar scaling factor $qval$ [S1].
- **Input:** A Transfer Function $\text{TF}(x)$ mapping intensity $x$ to color/opacity [S1].
- **Output:** The expected fragment color $E(\text{TF}(X))$ [S1].

**Data Structures:**
- **Quantile Array:** An array of $q$ elements. Each element $j$ stores:
  - $w_j$: The weight/width of the $j$-th quantile.
  - $m_j$: The mean intensity of the $j$-th quantile.
- **Constants:**
  - $qval$: The quantile value scaling factor [S1].

**Steps:**
1. **Calculate Mean Intensities:** Determine the mean intensity $m_j$ for each quantile $Q_j$ [S1].
2. **Compute Discrete Probabilities:** Calculate the unnormalized probability mass $p_j$ for each quantile using $p_j = qval \cdot w_j$ [S1]. Compute the normalization constant $p = \sum_{k=1}^{q} qval \cdot w_k$ [S1]. Calculate the discrete probability $\Pr(x = m_j) = \frac{p_j}{p}$ [S1].
3. **Evaluate Transfer Function:** Sample the Transfer Function at each mean intensity $m_j$ to obtain $\text{TF}(x = m_j)$ [S1].
4. **Weight and Sum:** Compute the expected fragment color by summing the product of the TF value and the discrete probability for each quantile [S1].

**Formula:**
$$E(\text{TF}(X)) = \sum_{j=1}^{q} \text{TF}(x = m_j) \Pr(x = m_j)$$
where $m_j$ is the mean intensity of the $j$-th quantile, and $\Pr(x = m_j) = \frac{p_j}{p}$ is the discrete probability density, with $p_j = qval \cdot w_j$ and $p = \sum_{k=1}^q qval \cdot w_k$ being the normalization constant [S1].

**Pseudocode:**
```python
def quantile_mean_integration(quantiles, transfer_function, qval):
    """
    Compute expected fragment color using Quantile Mean Integration.
    
    Args:
        quantiles: List of tuples (w_j, m_j) where w_j is the weight/width 
                   and m_j is the mean intensity of the j-th quantile.
        transfer_function: A function TF(x) returning color/opacity for intensity x.
        qval: Scalar scaling factor for the probability mass.
        
    Returns:
        Expected fragment color.
    """
    q = len(quantiles)
    if q == 0:
        return 0.0  # Default background color [G]
    
    numerator = 0.0
    weighted_tf_sum = 0.0
    
    for j in range(q):
        w_j, m_j = quantiles[j]
        p_j = qval * w_j
        numerator += p_j
        weighted_tf_sum += transfer_function(m_j) * p_j
        
    if numerator == 0.0:
        return 0.0  # Guard against division by zero [G]
        
    expected_color = weighted_tf_sum / numerator
    return expected_color
```

**Edge Cases and Pitfalls:**
- **Zero Normalization Constant:** If all weights $w_j$ are zero, the normalization constant $p$ becomes zero, leading to division by zero. The implementation must guard against this case [G].
- **Precision:** Summing many small probability masses can accumulate floating-point errors. Standard summation is used here, but compensated summation may be required for very large $q$ [G].

## Subtopics

### Quantile Range Integration
An integration scheme for DVR where all intensities contained within a quantile are integrated with the Transfer Function (TF) [S1]. Unlike Quantile Mean Integration, which uses a single point (the mean), this method computes the integral of the TF over the entire interval $[start_j, end_j]$ of each quantile [S1]. The expected fragment color is calculated as:
$$E(\text{TF}(X)) = \sum_{j=1}^{q} \frac{qval}{w_j} \int_{start_j}^{end_j} \text{TF}(x) dx$$
where $w_j$ is the width of the $j$-th quantile [S1]. This is equivalent to averaging the TFs for each quantile and performing a weighted sum where the weight is $qval$ [S1].

## Operating characteristics
- **Memory Complexity:** The memory consumed by input data for the nonparametric DVR framework is $L \times M \times N \times (q+1)$, where $L \times M \times N$ is the grid size and $q+1$ represents the number of boundaries defining quantiles at each grid vertex [S1].
- **Preprocessing Cost:** The preprocessing step is computationally expensive, as it involves computing Kernel Density Estimation (KDE) at each grid vertex from noise samples and reducing continuous distributions to their quantile representations [S1].

## Background
Quantile Mean Integration was proposed in the context of Direct Volume Rendering with Nonparametric Models of Uncertainty [S1]. It is part of a framework that uses Kernel Density Estimation (KDE) to model uncertainty at grid vertices and reduces continuous distributions to quantile representations for efficient rendering [S1].
