# Nearest Neighbor Interpolation

Also called: Nearest Neighbor Voxel Sampling, Zero-order interpolation, Constant interpolation

## Overview
Nearest Neighbor Interpolation maps a continuous 3D world point to the value of the single closest voxel in a discrete density grid [S3, book]. It solves the problem of retrieving attribute values (density, gradient, object membership, importance) for sample points that do not align with integer grid coordinates [S4, unofficial]. Unlike trilinear or inverse weighting methods, which average surrounding voxels to ensure continuity, this method provides at best a rough estimate of the volume's nature by selecting the nearest grid vertex [S1].

## How it works
**Inputs:**
- `point_pos`: A 3D vector $(x, y, z)$ representing the sample location in world space [S2, unofficial].
- `min_pos`: A 3D vector representing the minimum corner of the volume grid in world space [S2, unofficial].
- `max_pos`: A 3D vector representing the maximum corner of the volume grid in world space [S2, unofficial].
- `grid_resolution`: A 3D vector $(W, H, D)$ representing the number of voxels along each axis [S2, unofficial].
- `density_grid`: An array storing voxel values [S2, unofficial].

**Outputs:**
- `value`: The density or attribute value of the nearest voxel. Returns 0 if the point is outside the grid bounds [S2, unofficial].

**Data Structures:**
- The method operates on a grid of identical rectangular boxes of uniform value centered on grid points [S3, book].

**Steps:**
1. **Calculate Local Coordinates:** Normalize the world position to the $[0, 1]$ range relative to the grid bounds [S2, unofficial].
   $$ p_{local} = \frac{point\_pos - min\_pos}{max\_pos - min\_pos} $$
   Where the division is component-wise.

2. **Calculate Voxel Coordinates:** Scale the normalized coordinates to the grid resolution [S2, unofficial].
   $$ p_{voxel} = p_{local} \times grid\_resolution $$
   $$ p_{voxel} = (p_{local}[0] \cdot W, \ p_{local}[1] \cdot H, \ p_{local}[2] \cdot D) $$

3. **Calculate Integer Indices:** Apply the floor function to each component to find the nearest lower integer index [S2, unofficial].
   $$ x_i = \lfloor p_{voxel}[0] \rfloor $$
   $$ y_i = \lfloor p_{voxel}[1] \rfloor $$
   $$ z_i = \lfloor p_{voxel}[2] \rfloor $$

4. **Boundary Check:** Verify if the calculated indices are within the valid grid range $[0, W-1]$, $[0, H-1]$, and $[0, D-1]$ [S2, unofficial].
   - If $x_i < 0$ or $x_i \ge W$ or $y_i < 0$ or $y_i \ge H$ or $z_i < 0$ or $z_i \ge D$, return 0 [S2, unofficial].

5. **Lookup:** Return the value from `density_grid` at $(x_i, y_i, z_i)$ [S2, unofficial].

**Pseudocode:**
```python
import math

def nearest_neighbor_interpolation(point_pos, min_pos, max_pos, grid_resolution, density_grid):
    # Guard against zero-sized grid dimensions [G]
    dx = max_pos[0] - min_pos[0]
    dy = max_pos[1] - min_pos[1]
    dz = max_pos[2] - min_pos[2]
    if dx == 0 or dy == 0 or dz == 0:
        return 0

    # Step 1: Calculate local coordinates
    p_local_x = (point_pos[0] - min_pos[0]) / dx
    p_local_y = (point_pos[1] - min_pos[1]) / dy
    p_local_z = (point_pos[2] - min_pos[2]) / dz

    # Step 2: Calculate voxel coordinates
    W, H, D = grid_resolution
    p_voxel_x = p_local_x * W
    p_voxel_y = p_local_y * H
    p_voxel_z = p_local_z * D

    # Step 3: Calculate integer indices using floor
    xi = math.floor(p_voxel_x)
    yi = math.floor(p_voxel_y)
    zi = math.floor(p_voxel_z)

    # Step 4: Boundary check
    if xi < 0 or xi >= W or \
       yi < 0 or yi >= H or \
       zi < 0 or zi >= D:
        return 0

    # Step 5: Lookup
    return density_grid[xi][yi][zi]
```

**Parameters:**
- Not given in the sources.

**Edge Cases and Pitfalls:**
- **Out of Bounds:** Points outside the grid bounds return density 0 [S2, unofficial].
- **Precision:** The method is imprecise and produces extensively large interpolation error margins [S4, unofficial].
- **Discontinuity:** The method does not guarantee $C^0$ continuity along interior faces of the grid, only at vertices, which creates visible artifacts [S1].
- **Rounding vs Floor:** While [S5] describes rounding to the nearest integer, the standard implementation for binning in this context uses the floor function [S2, unofficial].

## Subtopics

### Nearest Integer Rounding
A sibling method that explicitly rounds to the nearest integer rather than flooring. It is geometrically more accurate for "nearest neighbor" but may differ in boundary handling. See [Nearest Integer Rounding](4233-nearest-integer-rounding.md).

## Operating characteristics
- **Strengths:** Fast computation [S4, unofficial].
- **Limitations:** Produces extensively large interpolation error margins [S4, unofficial]. Gives at best a rough estimate of the volume's nature compared to trilinear or inverse weighting [S1].

## Background
Explored in early direct volume rendering studies as a baseline method [S1]. Implemented in importance-driven volume rendering applications as a fast alternative to trilinear interpolation [S4, unofficial].
