# Piecewise Quadratic Hermite Interpolation

Also called: Piecewise Quadratic Bézier Hermite Interpolation, Quadratic Polynomial Interpolation for SCALIS

## Overview
This method interpolates a normalized scalar field within a 1D interval using two piecewise quadratic Bézier curves to satisfy Hermite data (value and derivative) at both endpoints. It solves the incompatibility of single quadratic interpolation with four constraints (two values, two derivatives) by splitting the interval, providing exact interpolation in specific cases and better stability than cubic interpolation for small subdivision counts [S1].

## How it works
**Inputs:**
- Interval length $L$.
- Hermite data at start: value $h_1$, derivative $h'_1$.
- Hermite data at end: value $h_2$, derivative $h'_2$.

**Outputs:**
- A continuous, smooth interpolant defined by two quadratic Bézier segments.

**Data Structures:**
- Six control points $Q_0, \dots, Q_5$ for the two Bézier curves.
- Each control point $Q_i$ has an abscissa (x-coordinate) and an ordinate (y-coordinate, representing the field value).
- The abscissas are equally spaced across the two sub-intervals.

**Steps:**
1.  **Split Interval:** Divide the initial interval of length $L$ into two equal sub-intervals, each of length $L/2$.
2.  **Define Control Points:** Define two quadratic Bézier curves, one for each sub-interval. A quadratic Bézier curve is defined by three control points. Thus, we have six control points $Q_0, \dots, Q_5$.
3.  **Constrain Abscissas:** The control points are constrained to be equally spaced in abscissa. For the first sub-interval, $Q_0, Q_1, Q_2$ span the first half. For the second, $Q_3, Q_4, Q_5$ span the second half.
4.  **Set Boundary Ordinates:**
    -   Set the ordinates of $Q_0$ and $Q_1$ based on the Hermite data at the start of the interval ($h_1, h'_1$).
    -   Set the ordinates of $Q_4$ and $Q_5$ based on the Hermite data at the end of the interval ($h_2, h'_2$).
    -   *Note:* The specific mapping of Hermite data to $Q_0, Q_1$ and $Q_4, Q_5$ ordinates is not explicitly detailed in the provided text, but standard Hermite-Bézier conversion is implied. The text states these are "constrained by Hermite data" [S1].
5.  **Enforce Continuity and Smoothness:**
    -   **Continuity:** The shared control point between the two segments must be equal: $Q_2 = Q_3$. Let this common ordinate be $y_{mid}$.
    -   **Smoothness:** The shared point $Q_2$ (and $Q_3$) must lie on the line joining $Q_1$ and $Q_4$. This ensures $C^1$ continuity or smoothness of the derivative.
6.  **Calculate Shared Ordinate:** Calculate the ordinate $y_{mid}$ for $Q_2$ and $Q_3$ using the formula:
    $$ y_{mid} = \frac{1}{2}(h_1 + h_2) + \frac{L}{8}(h'_1 - h'_2) $$
    where $h_1, h'_1$ are the value and derivative at the start, and $h_2, h'_2$ are the value and derivative at the end [S1].

    that interpolate Hermite data (h1, h1_prime) at start and (h2, h2_prime)
    at end over an interval of length L.

    # Q0.y = h1
    # Q1.y = h1 + (L/4) * h1_prime
    # Q5.y = h2
    # Q4.y = h2 - (L/4) * h2_prime

    Q2_y = y_mid
    Q3_y = y_mid

        (0.0, h1),
        (L/4, h1 + (L/4) * h1_prime),
        (L/2, y_mid),
        (L/2, y_mid),
        (3*L/4, h2 - (L/4) * h2_prime),
        (L, h2)
    ]
    
    return Q

**Edge Cases and Pitfalls:**
-   **Precision:** The method is noted to be numerically stable [S1].
-   **Boundaries:** The method assumes a 1D interval. For 3D volume rendering, this is applied along the ray or within grid cells.
-   **Degenerate Input:** If $L=0$, the formula for $y_{mid}$ becomes $(h_1+h_2)/2$. If $h_1=h_2$ and $h'_1=h'_2$, the interpolation is constant.

## Operating characteristics
-   **Time Complexity:** Constant time per evaluation after control points are computed. The computation of control points is also constant time.
-   **Memory Complexity:** Minimal, storing only 6 control points per interval.
-   **Performance:** More efficient and simpler than cubic interpolation [S1]. Provides exact interpolation in specific cases [S1]. For Cauchy kernels, yields better interpolation for small numbers of subdivisions compared to cubic interpolation on the original field [S1].
-   **Strengths:** Numerical stability, exact interpolation in specific cases, efficiency.
-   **Limitations:** Only applicable to 1D intervals. Requires Hermite data (value and derivative).

## Background
This method is used in the context of ray tracing scale-invariant integral surfaces, specifically within the SCALIS framework [S1]. It was proposed as an alternative to Hermite-Birkhoff interpolation to respect Hermite data at both endpoints without ignoring derivatives [S1].
