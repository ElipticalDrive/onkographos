# Cube Index Calculation

Also called: Marching Cubes Cube Index Calculation

## Overview
Computes an 8-bit integer index representing the configuration of a voxel's eight corners relative to an isolevel, determining which edges are intersected by the surface [S1, unofficial][S2, unofficial]. It calculates the marching cubes case index for each voxel based on corner values relative to an iso-level [S2, unofficial]. Unlike sibling methods that handle sparse point clouds or pre-gathered data, this method operates directly on the scalar values at the voxel corners to produce the topology case [S2, unofficial].

## How it works
**Inputs:**
- `corners`: A collection of 8 scalar values representing the density or signed distance at the 8 corners of a voxel. In dense implementations, these are stored in a struct `VoxelCorners<T>` containing 8 fields (`Corner1` to `Corner8`) of type `T` [S1, unofficial]. In sparse implementations, these are provided as a float tensor of shape $[N, 8]$ [S2, unofficial].
- `iso_level`: The scalar threshold value [S1, unofficial][S2, unofficial].

**Outputs:**
- `cube_index`: An 8-bit integer (0–255) representing the voxel's configuration [S1, unofficial][S2, unofficial].

**Data Structures:**
- **Dense Layout**: A struct `VoxelCorners<T>` containing 8 fields (`Corner1` to `Corner8`) of type `T` (e.g., byte or float) [S1, unofficial].
- **Sparse Layout**: Input tensor `corners` of shape $[N, 8]$ where $N$ is the number of voxels [S2, unofficial]. Output tensor `cube_indices` of shape $[N]$ [S2, unofficial].

**Algorithm:**
1. Initialize `cube_index` to 0 [S1, unofficial].
2. For each corner $i$ from 0 to 7 (corresponding to corners 1 to 8 in 1-based indexing):
   - Compare the corner's scalar value $v_i$ with `iso_level` [S1, unofficial][S2, unofficial].
   - If $v_i < \text{iso\_level}$, set the $i$-th bit of `cube_index` to 1 [S1, unofficial].
   - Otherwise, the bit remains 0 [S1, unofficial].
3. Return `cube_index` [S1, unofficial][S2, unofficial].

**Formula:**
$$ \text{cube\_index} = \sum_{i=0}^{7} \mathbb{I}(v_i < \text{iso\_level}) \cdot 2^i $$
Where $\mathbb{I}(\cdot)$ is the indicator function (1 if true, 0 if false) [S2, unofficial].

**Parameters:**
Not given in the sources.

**Edge Cases and Pitfalls:**
- **Precision**: Comparisons use strict inequality. If $v_i = \text{iso\_level}$, the condition $v_i < \text{iso\_level}$ is false, so the bit remains 0 [S1, unofficial].
- **Boundary Conditions**: In sparse implementations, if a corner coordinate is missing from the point set, a default value is used (e.g., 1.0) before comparison [S2, unofficial].
- **Degenerate Input**: If all corners are equal, the index is either 0 or 255, resulting in no surface intersection [G].

**Pseudocode:**
```python
def compute_cube_index(corners, iso_level):
    """
    Computes the Marching Cubes cube index for a single voxel.
    
    Args:
        corners: List or array of 8 scalar values [v0, v1, ..., v7].
        iso_level: The threshold value.
        
    Returns:
        int: The 8-bit cube index.
    """
    cube_index = 0
    for i in range(8):
        if corners[i] < iso_level:
            cube_index |= (1 << i)
    return cube_index
```
