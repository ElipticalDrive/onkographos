# Third Order Elimination (Scaling)

Also called: Scaling, PSR Scaling

## Overview
Third Order Elimination (Scaling) is a quadratic interpolation method that derives a second-order polynomial from a cubic Hermite basis by scaling the input derivatives to force the third-order coefficient to zero [S1]. It solves the problem of approximating a function with derivative data while reducing the polynomial order to avoid the overshoot or instability associated with cubic terms, specifically when the derivatives do not cancel each other out [S1]. It is distinguished from [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) by its explicit elimination of the cubic term via scalar multiplication of derivatives, and from [Piecewise Quadratic Hermite Interpolation](4001-piecewise-quadratic-hermite-interpolation.md) by its derivation from a cubic constraint rather than a least-squares fit of derivatives [S1].

## How it works
**Inputs:**
*   $v_0$: Function value at parameter $t=0$.
*   $v_1$: Function value at parameter $t=1$.
*   $d_0$: Derivative value at parameter $t=0$.
*   $d_1$: Derivative value at parameter $t=1$.

**Outputs:**
*   Quadratic polynomial coefficients $a_0, a_1, a_2$ for $p(t) = a_0 + a_1 t + a_2 t^2$.

**Data Structures:**
*   Standard floating-point variables for $v_0, v_1, d_0, d_1, s, a_0, a_1, a_2$.

**Steps:**
1.  Calculate the scaling factor $s$ using the formula:
    $$ s = \frac{2v_1 - 2v_0}{d_0 + d_1} $$
2.  Scale the derivatives:
    $$ d'_0 = s \cdot d_0 $$
    $$ d'_1 = s \cdot d_1 $$
3.  Compute the quadratic coefficients based on the value and scaled derivative constraints for a quadratic polynomial $p(t) = a_0 + a_1 t + a_2 t^2$:
    *   $a_0 = v_0$
    *   $a_1 = d'_0$
    *   $a_2 = d'_1 - d'_0$ (Derived from $p'(1) = a_1 + 2a_2 = d'_1$)

**Pseudocode:**
```python
def third_order_elimination_scaling(v0, v1, d0, d1):
    # Calculate scaling factor
    denominator = d0 + d1
    
    # Guard against division by zero
    if abs(denominator) < 1e-9:
        # Fallback to linear interpolation or handle as error [G]
        # Linear interpolation: p(t) = v0 + (v1 - v0) * t
        return v0, v1 - v0, 0.0
    
    s = (2.0 * v1 - 2.0 * v0) / denominator
    
    # Scale derivatives
    d0_scaled = s * d0
    d1_scaled = s * d1
    
    # Compute quadratic coefficients
    # p(t) = a0 + a1*t + a2*t^2
    # p(0) = a0 = v0
    # p'(0) = a1 = d0_scaled
    # p'(1) = a1 + 2*a2 = d1_scaled  =>  a2 = (d1_scaled - a1) / 2
    a0 = v0
    a1 = d0_scaled
    a2 = (d1_scaled - a1) / 2.0
    
    return a0, a1, a2
```

**Edge Cases and Pitfalls:**
*   **Instability:** The solution becomes unstable if $d_0 + d_1 \approx 0$ (derivatives cancel each other out), leading to division by zero or large scaling factors [S1].
*   **Validity:** The method assumes the implicit function has a steep gradient and derivatives with the same sign, as is common in indicator functions near isosurfaces [S1].

## Subtopics

### Third Order Elimination (Offset)
A quadratic method obtained by adding an offset $o$ to derivatives to eliminate the third order coefficient $a_3$ [S1]. It solves for $o$ using $2v_0 - 2v_1 + (d_0 + o) + (d_1 + o) = 0$, yielding $o = (2v_1 - 2v_0 - d_0 - d_1) / 2$ [S1]. This solution is equivalent to the Least-Squares Derivatives method [S1].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample, involving a constant number of arithmetic operations.
*   **Memory Complexity:** $O(1)$, requiring storage for only the local neighborhood values and derivatives.
*   **Strengths:** Reduces the polynomial order to quadratic, potentially simplifying the shape of the interpolated field compared to cubic methods [S1].
*   **Limitations:** Numerical instability when $d_0 + d_1 \approx 0$ [S1]. Not suitable for functions where derivatives have opposite signs or cancel out [S1].
*   **Usage:** Implemented in the PSR code for interpolating the indicator function [S1].

## Background
The method is described in the context of accurate isosurface interpolation with Hermite data, where it is presented as an alternative to cubic interpolation and least-squares derivative methods [S1]. It is specifically noted as being implemented in the PSR code for interpolating indicator functions [S1].
