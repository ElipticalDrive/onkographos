# Third Order Elimination (Scaling)

Also called: Scaling method, PSR scaling interpolation

## Overview
Third Order Elimination (Scaling) is a quadratic interpolation method for implicit functions that eliminates the cubic term ($a_3$) from a cubic Hermite polynomial by scaling the input derivatives. It solves the problem of approximating a smooth field with $C^1$ continuity while reducing the polynomial order to avoid overshoots or instability associated with higher-order terms. It differs from [Tricubic Interpolation](14963-tricubic-interpolation.md) by enforcing a quadratic form and from [Piecewise Quadratic Hermite Interpolation](4001-piecewise-quadratic-hermite-interpolation.md) by deriving its coefficients through a specific scaling constraint rather than direct least-squares minimization of the derivatives.

## How it works
**Inputs:**
- Scalar values at endpoints: $v_0 = p(0)$, $v_1 = p(1)$.
- Derivatives at endpoints: $d_0 = p'(0)$, $d_1 = p'(1)$.
- Local coordinate: $t \in [0, 1]$.

**Outputs:**
- Interpolated value $p(t)$ and derivative $p'(t)$ of the resulting quadratic polynomial.

**Data Structures:**
- Coefficients $a_0, a_1, a_2$ for the polynomial $p(t) = a_0 + a_1 t + a_2 t^2$.

**Steps:**
1.  **Compute Scaling Factor:** Calculate the scalar $s$ that scales the derivatives to eliminate the third-order term. The condition for eliminating $a_3$ in the cubic Hermite basis leads to the constraint:
    $$ 2v_0 - 2v_1 + s \cdot d_0 + s \cdot d_1 = 0 $$
    Solving for $s$:
    $$ s = \frac{2v_1 - 2v_0}{d_0 + d_1} $$
2.  **Scale Derivatives:** Compute the effective derivatives $d'_0 = s \cdot d_0$ and $d'_1 = s \cdot d_1$.
3.  **Determine Coefficients:** Construct the quadratic polynomial $p(t) = a_0 + a_1 t + a_2 t^2$ that interpolates $v_0, v_1$ and has derivatives $d'_0, d'_1$ at the boundaries.
    -   $a_0 = v_0$
    -   $a_1 = d'_0$
    -   $a_2 = d'_1 - d'_0 - a_1 = d'_1 - 2d'_0$ (Derived from $p'(1) = a_1 + 2a_2 = d'_1$)
    *Note: The source [S1] implies the coefficients are derived from the scaled derivatives within the cubic framework where $a_3$ is forced to 0. A more robust derivation from the constraint $2v_0 - 2v_1 + s(d_0+d_1)=0$ ensures consistency.*
4.  **Evaluate:** Compute $p(t)$ using the coefficients.

**Pseudocode:**
```python
def third_order_elimination_scaling(v0, v1, d0, d1, t):
    # Step 1: Compute scaling factor
    denom = d0 + d1
    if abs(denom) < 1e-9:
        # Edge case: derivatives cancel out. 
        # The source notes this is unstable [S1]. 
        # Fallback to linear interpolation or handle as error.
        # [G] Linear interpolation is a safe fallback for degenerate cases.
        return lerp(v0, v1, t)
    
    s = (2.0 * v1 - 2.0 * v0) / denom
    
    # Step 2: Scale derivatives
    d0_scaled = s * d0
    d1_scaled = s * d1
    
    # Step 3: Determine quadratic coefficients
    # p(t) = a0 + a1*t + a2*t^2
    # p(0) = v0 => a0 = v0
    # p'(0) = d0_scaled => a1 = d0_scaled
    # p'(1) = d1_scaled => a1 + 2*a2 = d1_scaled => a2 = (d1_scaled - a1) / 2.0
    a0 = v0
    a1 = d0_scaled
    a2 = (d1_scaled - a1) / 2.0
    
    # Step 4: Evaluate polynomial
    return a0 + a1 * t + a2 * t * t
```

**Parameters:**
- None. The method is fully determined by the input data.

**Edge Cases:**
- **Derivative Cancellation:** If $d_0 + d_1 \approx 0$, the scaling factor $s$ becomes undefined or extremely large, leading to numerical instability [S1]. This occurs when the derivatives have opposite signs and similar magnitudes. The source notes this is unlikely for indicator functions with steep gradients near isosurfaces [S1].

## Subtopics

### Third Order Elimination (Offset)
A quadratic method obtained by adding an offset $o$ to the derivatives to eliminate the third-order coefficient $a_3$. The constraint is $2v_0 - 2v_1 + (d_0 + o) + (d_1 + o) = 0$, yielding $o = \frac{2v_1 - 2v_0 - d_0 - d_1}{2}$ [S1]. This solution is equivalent to the Least-Squares Derivatives (LSDERIV) method [S1]. It is chosen when derivative stability is preferred over the scaling approach, particularly when derivatives might sum to near zero.

## Operating characteristics
- **Time Complexity:** $O(1)$ per query. Requires a few floating-point operations and one division.
- **Memory Complexity:** $O(1)$. No additional storage beyond the input values and derivatives.
- **Strengths:** Reduces polynomial order to quadratic, potentially reducing overshoot compared to cubic interpolation. Simple to implement.
- **Limitations:** Numerically unstable when $d_0 + d_1 \approx 0$ [S1]. Not suitable for general-purpose interpolation where derivative signs are arbitrary.
- **When to use:** Interpolating indicator functions or implicit fields where derivatives are known to have the same sign (e.g., steep gradients near isosurfaces) [S1].
- **When not to use:** When derivatives may cancel out or when higher-order continuity is required.

## Background
The method originates from research on accurate isosurface interpolation using Hermite data. It is specifically implemented in the PSR (Polynomial Surface Reconstruction) code for interpolating the indicator function [S1]. The technique is part of a family of methods that modify cubic Hermite polynomials to achieve quadratic behavior by eliminating the cubic term through scaling or offsetting the derivatives.
