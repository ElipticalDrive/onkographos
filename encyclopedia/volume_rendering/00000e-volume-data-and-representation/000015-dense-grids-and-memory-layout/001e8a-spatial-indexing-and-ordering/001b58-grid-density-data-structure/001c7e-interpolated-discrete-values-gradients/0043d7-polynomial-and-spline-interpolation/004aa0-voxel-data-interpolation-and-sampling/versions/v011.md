# Voxel Data Interpolation and Sampling

Also called: Grid Sampling, Sample Grid, Sample Grid Index, getNextIntersectColor, getNextIntersectionGradient, getNextIntersectionScalar

## Overview
Voxel Data Interpolation and Sampling is the method for retrieving scalar values, gradients, and transformed colors at arbitrary 3D positions within a dense volume grid [S1, S2, unofficial]. It solves the problem of mapping continuous ray-casting coordinates to discrete grid storage, supporting both nearest-neighbor and trilinear interpolation modes [S1, unofficial]. It is distinguished from sibling methods by its explicit separation of grid access (via integer indices for raw data) and field evaluation (via continuous positions for interpolated data), often coupled with a configurable transfer function transformation mode [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D position $\mathbf{p} = (x, y, z)$ in world or grid space; grid dimensions $(X_{DIM}, Y_{DIM}, Z_{DIM})$; interpolation mode $INTER\_MODE$; transfer function mode $TRN\_MODE$.
*   **Output:** A scalar value, a gradient vector (optional), and a transformed color/opacity pair.

**Data Structures:**
The volume data is stored in two contiguous vectors [S1, unofficial]:
1.  `scalars`: `vector<float>` storing voxel values.
2.  `gradients`: `vector<glm::vec3>` storing pre-computed gradient vectors.

The linear index for a voxel at integer coordinates $(x, y, z)$ is calculated as [S1, unofficial]:
$$ index = x + (y \cdot X_{DIM}) + (z \cdot X_{DIM} \cdot Y_{DIM}) $$

**Parameters:**
*   $INTER\_MODE$: Integer. 1 for trilinear interpolation, 2 for nearest neighbor [S1, unofficial].
*   $TRN\_MODE$: Integer. 1 for transfer function input $(V, V)$, 2 for $(V, |\nabla V|)$ [S1, unofficial].

**Steps:**
1.  **Boundary Check:** If the query coordinates $(x, y, z)$ are outside the grid bounds $[0, X_{DIM}-1] \times [0, Y_{DIM}-1] \times [0, Z_{DIM}-1]$, return default values (e.g., $(0,0,0,0)$) [S1, unofficial].
2.  **Index Calculation:** Compute the base integer index for the voxel containing the query point [S1, unofficial].
3.  **Value Retrieval:**
    *   If $INTER\_MODE = 2$ (Nearest Neighbor): Retrieve the scalar $V$ and gradient $\mathbf{g}$ at the nearest integer coordinates [S1, unofficial].
    *   If $INTER\_MODE = 1$ (Trilinear): Retrieve the 8 neighboring scalar values and gradient vectors, then compute the weighted average based on the fractional part of $\mathbf{p}$ [S1, unofficial]. *Note: Some implementations default to nearest neighbor if full trilinear logic is not yet implemented [S1, unofficial].*
4.  **Gradient Magnitude Calculation:** If required by $TRN\_MODE$, compute the magnitude of the gradient vector:
    $$ |\mathbf{g}| = \sqrt{g_x^2 + g_y^2 + g_z^2} $$
5.  **Transfer Function Transformation:**
    *   If $TRN\_MODE = 1$: Pass $(V, V)$ to the transfer function transformer [S1, unofficial].
    *   If $TRN\_MODE = 2$: Clamp $|\mathbf{g}|$ to $[0, 1]$, scale by 256, and pass $(V, 256 \cdot |\mathbf{g}|)$ to the transformer [S1, unofficial].

**Pseudocode:**
```python
def sample_voxel(p: Vector3, grid_dims: Vector3, scalars: List[float], gradients: List[Vector3], 
                 inter_mode: int, trn_mode: int) -> Tuple[float, Vector3, float]:
    x, y, z = p.x, p.y, p.z
    
    # 1. Boundary Check
    if not (0 <= x < grid_dims.x and 0 <= y < grid_dims.y and 0 <= z < grid_dims.z):
        return 0.0, Vector3(0, 0, 0), 0.0

    # 2. Determine interpolation weights and neighbors
    if inter_mode == 2: # Nearest Neighbor
        ix, iy, iz = int(round(x)), int(round(y)), int(round(z))
        # Clamp to bounds if rounding pushes out
        ix = max(0, min(ix, grid_dims.x - 1))
        iy = max(0, min(iy, grid_dims.y - 1))
        iz = max(0, min(iz, grid_dims.z - 1))
        
        idx = ix + (iy * grid_dims.x) + (iz * grid_dims.x * grid_dims.y)
        scalar_val = scalars[idx]
        grad_val = gradients[idx]
        
    elif inter_mode == 1: # Trilinear
        # Implementation of trilinear interpolation using 8 neighbors
        # This requires fetching 8 scalars and 8 gradients and weighting by distance
        # Note: Some sources indicate this may be unimplemented in specific codebases [S1, unofficial]
        scalar_val = trilinear_interpolate(x, y, z, grid_dims, scalars)
        grad_val = trilinear_interpolate_vector(x, y, z, grid_dims, gradients)
    else:
        scalar_val = 0.0
        grad_val = Vector3(0, 0, 0)

    # 3. Transfer Function Mode Handling
    if trn_mode == 1:
        # Input: (Voxel Value, Voxel Value)
        tf_input_1 = scalar_val
        tf_input_2 = scalar_val
    elif trn_mode == 2:
        # Input: (Voxel Value, Gradient Magnitude)
        grad_mag = length(grad_val)
        grad_mag = clamp(grad_mag, 0.0, 1.0)
        tf_input_1 = scalar_val
        tf_input_2 = grad_mag * 256.0
    else:
        tf_input_1 = 0.0
        tf_input_2 = 0.0

    return scalar_val, grad_val, tf_input_1, tf_input_2
```

## Operating characteristics
*   **Time Complexity:** $O(1)$ for nearest neighbor. $O(1)$ for trilinear (constant 8 samples).
*   **Memory Complexity:** $O(N)$ where $N$ is the number of voxels, storing both scalars and gradients.
*   **Strengths:** Simple to implement; supports pre-computed gradients for faster ray marching; flexible transfer function inputs.
*   **Limitations:** Trilinear interpolation may be computationally expensive if not optimized; nearest neighbor causes aliasing artifacts.
*   **When to use:** Real-time volume rendering where performance is critical; when pre-computed gradients are available.
*   **When not to use:** When high-quality smooth interpolation is required and pre-computed gradients are not available (requires on-the-fly gradient calculation).

## Background
This method is commonly used in volume ray casting implementations, such as those found in academic computer graphics projects [S1, unofficial]. It is also referenced in modern 3D software like Blender, where "Sample Grid" nodes are used for field evaluation in geometry nodes [S2, unofficial].
