# Polynomial and Spline Interpolation


## Overview
Polynomial and Spline Interpolation provides continuous scalar or vector fields from discrete grid data by fitting piecewise polynomials or splines to the samples [S1][S2, unofficial]. It solves the discontinuity and aliasing artifacts inherent in nearest-neighbor sampling by ensuring $C^0$ or higher continuity across cell boundaries, which is critical for gradient-sensitive tasks like volume rendering and surface reconstruction [S1][S2, unofficial]. It sets itself apart from simple lookup methods by explicitly modeling the function's derivatives or using higher-order basis functions to blend neighboring values, with specific variants chosen based on the required continuity ($C^1$ vs $C^2$) and computational cost [S1][S2, unofficial].

## Shared principles
All methods in this family operate on a discrete grid of control points or samples and evaluate a continuous function $u(\mathbf{p})$ at arbitrary query points $\mathbf{p}$. The core mechanism involves:
1.  **Local Support:** The value at $\mathbf{p}$ depends only on a fixed, small neighborhood of grid vertices (e.g., 8 for trilinear, 64 for tricubic/B-spline) [S1][S2, unofficial].
2.  **Basis Functions:** The interpolation is computed as a weighted sum of the grid values, where weights are determined by basis functions (e.g., Hermite, B-spline, Bézier) evaluated at the normalized local coordinates of $\mathbf{p}$ within its supporting cell [S1][S2, unofficial].
3.  **Continuity:** The choice of basis function determines the continuity of the resulting field. Linear methods yield $C^0$, Hermite cubic yields $C^1$, and B-splines can yield $C^2$ [S1][S2, unofficial].
4.  **Gradient Handling:** Higher-order methods often utilize stored or computed gradients (first derivatives) to constrain the polynomial shape, ensuring smooth transitions [S1][S2, unofficial].

## Subtopics

### [Grid Cell Collection via Corner Indices](1518-grid-cell-collection-via-corner-indices.md)
Grid Cell Collection via Corner Indices retrieves the eight vertex values of the grid cell enclosing a query point, serving as the foundational data gathering step for trilinear interpolation in dense voxel grids. It solves the problem of efficiently mapping arbitrary floating-point coordinates to the discrete tensor indices required for volume rendering or feature extraction, handling boundary conditions and batched queries. It sets itself apart from higher-order methods like [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) by strictly limiting the support to the immediate 8 neighbors of the enclosing cell, and from [VoxelGrid](2159-voxelgrid.md) by focusing on the index computation and gathering logic rather than the storage structure itself.

### [Piecewise Quadratic Hermite Interpolation](4001-piecewise-quadratic-hermite-interpolation.md)
A method for interpolating scalar fields within a 1D subinterval using two piecewise quadratic Bézier curves to satisfy Hermite data (value and derivative) at both endpoints. It solves the incompatibility of single quadratic interpolation with four constraints (two values, two derivatives) by splitting the interval, providing exact interpolation for normalized fields and better stability for small subdivisions compared to cubic methods.

### [Hermite Interpolation of Scalar Fields](9450-hermite-interpolation-of-scalar-fields.md)
Hermite interpolation of scalar fields renders scalar-valued functions (such as height fields and signed distance fields) by storing partial derivatives alongside function values on a regular grid. Unlike standard trilinear interpolation which yields only $C^0$ continuity, this method guarantees a globally $C^1$-continuous result by using Hermite interpolation between samples. It serves as a storage-efficient replacement for normal mapping, as surface normals can be derived directly from the stored gradient data without requiring extra storage.

### [B-spline Field Interpolation](11066-b-spline-field-interpolation.md)
B-spline Field Interpolation is a method for evaluating a continuous scalar or vector field from a discrete grid of control points using cubic B-spline basis functions. It solves the problem of reconstructing a smooth, differentiable function from sparse samples while maintaining local support, ensuring that the value at any query point depends only on a fixed, small neighborhood of grid vertices. It is distinguished from its siblings, such as [Voxel Data Interpolation and Sampling](12781-voxel-data-interpolation-and-sampling.md) (trilinear) and [Hermite Interpolation of Scalar Fields](9450-hermite-interpolation-of-scalar-fields.md), by providing $C^2$ continuity (continuous second derivatives) and a wider support kernel (4x4x4 points) that blends neighboring weights more smoothly, preventing the "blocky" artifacts of linear interpolation.

### [Voxel Data Interpolation and Sampling](12781-voxel-data-interpolation-and-sampling.md)
Voxel Data Interpolation and Sampling is the method for retrieving scalar values, gradients, and transformed colors at arbitrary 3D positions within a dense volume grid. It solves the problem of mapping continuous ray-casting coordinates to discrete grid data, supporting various interpolation modes (nearest neighbor, trilinear) and transfer function input configurations. It is distinguished from sibling methods by its role as the fundamental access layer for dense grids, often exposing both interpolated values (`Sample Grid`) and raw integer-indexed values (`Sample Grid Index`).

### [Third Order Elimination (Scaling)](13712-third-order-elimination-scaling.md)
Third Order Elimination (Scaling) is a quadratic interpolation method that derives a second-order polynomial from a cubic Hermite basis by scaling the input derivatives to force the third-order coefficient to zero. It solves the problem of approximating a function with derivative data while reducing the polynomial order to avoid the overshoot or instability associated with cubic terms, specifically when the derivatives do not cancel each other out. It is distinguished from [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) by its explicit elimination of the cubic term via scalar multiplication of derivatives, and from [Piecewise Quadratic Hermite Interpolation](4001-piecewise-quadratic-hermite-interpolation.md) by its derivation from a cubic constraint rather than a least-squares fit of derivatives.

### [Tricubic Interpolation](14963-tricubic-interpolation.md)
Tricubic interpolation is a higher-order method that employs cubic polynomials over a 4x4x4 neighborhood of 64 points to approximate smooth underlying functions with an accuracy of $O(h^4)$, where $h$ is the grid spacing. It provides $C^1$ continuity, reducing artifacts in gradient-sensitive tasks like volume rendering, whereas trilinear interpolation only achieves $C^0$ continuity. It is chosen when differentiable outputs are required for visualization.

### [NURBS Spline Representation for Measurement Coordinates](16136-nurbs-spline-representation-for-measurement-coordinates.md)
This method represents uncertain measurement coordinates (such as view angles and detector locations) as a NURBS surface whose control points and weights are optimized alongside volume reconstruction. It differs from standard interpolation by treating the geometric parameters of the acquisition as learnable variables within a rational basis function framework, allowing for the correction of measurement noise and uncertainty during the reconstruction process.

#### Box Spline Interpolation
- **Definition:** A piecewise polynomial interpolation function with finite support, uniquely defined by a direction matrix, used for reconstructing continuous splines from discrete datasets [S1].
- **Steps:** Construct the box-spline by taking consecutive directional convolutions along each column direction of the direction matrix $\Xi$. For non-Cartesian lattices, apply a change-of-variables to the Cartesian lattice theory [S1].
- **Formula:** Recursive definition: $M_{\Xi \cup \{\mathbf{d}\}}(\mathbf{x}) = \int_0^1 M_\Xi(\mathbf{x} - t\mathbf{d}) dt, \mathbf{x} \in \mathbb{R}^n$ (Eq 6) [S1].
- **Comparison:** Provides higher quality and reasonable performance compared to trilinear or tricubic interpolations commonly used on mobile devices [S1].
- **Usage:** Mobile volume rendering, FCC datasets, GPU ray casting [S1].

#### Distance Weighting Filter
- **Definition:** A spatial interpolation filter that assigns weights based on distance to preserve data structure during grid mapping [S2, unofficial].
- **Parameter:** Filter radius determines the spatial extent of the weighting; must be shortened to increase sampling rate [S2, unofficial].
- **Pitfall:** Assumes a constant, second-order distribution of weighting terms based on the filter radius; under-samples areas with high data frequency, causing inner and outer shells to disappear where data density varies [S2, unofficial].
- **Comparison:** Performs worse than the Gaussian filter for preserving accuracy because it lacks a degree of freedom for adjusting sampling frequency independently of radius [S2, unofficial].

## Background
The family of polynomial and spline interpolation methods has evolved to address the limitations of linear interpolation in volume rendering, particularly regarding visual artifacts and gradient accuracy. Trilinear interpolation has long been the standard for dense grids due to its efficiency [S1][S2, unofficial]. However, for applications requiring smooth gradients, Hermite and B-spline methods have been adopted. Box splines, introduced by de Boor et al., offer a multivariate generalization of B-splines particularly useful for non-Cartesian lattices like Face-Centered Cubic (FCC) datasets, enabling real-time rendering on mobile platforms with fixed capabilities [S1]. The use of NURBS for measurement coordinates represents a more recent development in handling uncertainty in acquisition data [S1].
