# Trilinear Interpolation on Sparse Voxel Octree


## Overview
This method samples scalar or vector fields stored in the leaf nodes of a Sparse Voxel Octree (SVO) using trilinear interpolation [S1, unofficial]. It maps 3D query points to grid coordinates, identifies the 8 surrounding voxel neighbors, retrieves their payload values via the octree structure, and computes the weighted sum [S1, unofficial].

## How it works
**Inputs:**
- `octree`: Structure containing `NodeDescriptor` array, `leaf_payload_indices` array, `num_nodes`, `num_leaves`, `max_depth`, and `root_bounds` (min/max bounds) [S1, unofficial].
- `points`: Vector of 3D points (`glm::vec3`) to sample [S1, unofficial].
- `payload`: Pointer to raw payload data array (contiguous storage for leaf data) [S1, unofficial].
- `payload_rows`: Total number of rows (leaf entries) in the payload array [S1, unofficial].
- `channels`: Number of scalar values per payload row (e.g., 1 for grayscale, 3 for RGB) [S1, unofficial].
- `fill_value`: Value returned for points outside root bounds or in empty voxels [S1, unofficial].

**Outputs:**
- `outputs`: Vector of size `points.size() * channels`, initialized to `fill_value` [S1, unofficial].

**Data Structures:**
- `NodeDescriptor`: Contains `child_mask` (bitmask of children), `leaf_mask` (bitmask of leaf children), `child_base` (offset to internal children), and `payload_base` (offset to leaf payloads) [S1, unofficial].
- `RootBounds`: `min_bound` and `max_bound` defining the spatial extent of the octree root [S1, unofficial].

**Steps:**
1. **Validate Inputs:** Ensure `max_depth` is in $[0, 30]$, `channels > 0`, `payload` is not null if `payload_rows > 0`, and all `leaf_payload_indices` are within `payload_rows` [S1, unofficial]. If branching mode is Wide4, throw `ValidationError` [S1, unofficial].
2. **Initialize Output:** Set `outputs` to size `points.size() * channels` filled with `fill_value` [S1, unofficial].
3. **Calculate Grid Size:** Compute `grid_size = 2^{max_depth}` [S1, unofficial].
4. **Loop Over Points:** For each point `p` in `points`:
   a. **Bounds Check:** If `p` is not inside `root_bounds` (i.e., $p.x < min\_bound.x$ or $p.x \ge max\_bound.x$, etc.), skip to next point [S1, unofficial].
   b. **Normalize Coordinates:** Compute normalized position:
      $$ normalized = \frac{p - min\_bound}{max\_bound - min\_bound} $$
   c. **Grid Coordinates:** Compute continuous grid coordinates:
      $$ grid = normalized \times grid\_size - 0.5 $$
   d. **Base Voxel:** Compute integer base coordinates:
      $$ base = \lfloor grid \rfloor $$
   e. **Fractional Offsets:** Compute fractional parts:
      $$ frac = grid - base $$
   f. **Trilinear Interpolation:** Initialize `output_index = point_index * channels` [S1, unofficial]. Loop `dz` from 0 to 1, `dy` from 0 to 1, `dx` from 0 to 1:
      i. **Weights:**
         $$ wz = \begin{cases} 1.0 - frac.z & \text{if } dz=0 \\ frac.z & \text{if } dz=1 \end{cases} $$
         $$ wy = \begin{cases} 1.0 - frac.y & \text{if } dy=0 \\ frac.y & \text{if } dy=1 \end{cases} $$
         $$ wx = \begin{cases} 1.0 - frac.x & \text{if } dx=0 \\ frac.x & \text{if } dx=1 \end{cases} $$
      ii. **Total Weight:**
          $$ weight = wx \times wy \times wz $$
          If `weight == 0`, continue to next iteration [S1, unofficial].
      iii. **Neighbor Coordinate:**
           $$ neighbor = base + (dx, dy, dz) $$
      iv. **Lookup Payload Index:**
          - If `neighbor` is outside grid bounds $[0, grid\_size)$, set `payload_index = -1` [S1, unofficial].
          - Else, call `lookup_payload_index_by_voxel(octree, neighbor, payload_rows)` to get `payload_index` [S1, unofficial].
      v. **Retrieve Value:**
          - If `payload_index >= 0`, set `neighbor_payload = payload + payload_index * channels` [S1, unofficial].
          - Else, set `neighbor_payload = nullptr` [S1, unofficial].
          - For each `channel` in $[0, channels)$:
            - If `neighbor_payload` is `nullptr`, `value = fill_value` [S1, unofficial].
            - Else, `value = neighbor_payload[channel]` [S1, unofficial].
      vi. **Accumulate:**
          $$ outputs[output\_index + channel] += weight \times (value - fill\_value) $$

**Pseudocode:**
```python
import math

def sample_trilinear(octree, points, payload, payload_rows, channels, fill_value):
    # Validate inputs
    if octree.max_depth < 0 or octree.max_depth > 30:
        raise ValueError("max_depth must be in [0, 30]")
    if channels <= 0:
        raise ValueError("channels must be > 0")
    if payload_rows > 0 and payload is None:
        raise ValueError("payload cannot be null if payload_rows > 0")

    num_points = len(points)
    outputs = [fill_value] * (num_points * channels)

    grid_size = 1 << octree.max_depth
    min_bound = octree.root_bounds.min
    max_bound = octree.root_bounds.max
    extent = max_bound - min_bound

    for point_index, point in enumerate(points):
        # Bounds check
        if not (min_bound.x <= point.x < max_bound.x and
                min_bound.y <= point.y < max_bound.y and
                min_bound.z <= point.z < max_bound.z):
            continue

        # Normalize and grid coordinates
        normalized = [(point.x - min_bound.x) / extent.x,
                      (point.y - min_bound.y) / extent.y,
                      (point.z - min_bound.z) / extent.z]
        grid = [normalized[i] * grid_size - 0.5 for i in range(3)]

        # Base voxel and fractional offsets
        base = [int(math.floor(v)) for v in grid]
        frac = [grid[i] - base[i] for i in range(3)]

        output_index = point_index * channels

        for dz in range(2):
            wz = (1.0 - frac[2]) if dz == 0 else frac[2]
            for dy in range(2):
                wy = (1.0 - frac[1]) if dy == 0 else frac[1]
                for dx in range(2):
                    wx = (1.0 - frac[0]) if dx == 0 else frac[0]

                    weight = wx * wy * wz
                    if weight == 0:
                        continue

                    neighbor = [base[0] + dx, base[1] + dy, base[2] + dz]

                    # Check grid bounds
                    if not (0 <= neighbor[0] < grid_size and
                            0 <= neighbor[1] < grid_size and
                            0 <= neighbor[2] < grid_size):
                        payload_index = -1
                    else:
                        payload_index = lookup_payload_index_by_voxel(
                            octree.nodes, octree.num_nodes,
                            octree.leaf_payload_indices, octree.num_leaves,
                            octree.max_depth, min_bound, max_bound, neighbor)

                    # Retrieve value
                    if payload_index >= 0:
                        neighbor_payload = payload[payload_index * channels:]
                    else:
                        neighbor_payload = None

                    for channel in range(channels):
                        value = fill_value if neighbor_payload is None else neighbor_payload[channel]
                        outputs[output_index + channel] += weight * (value - fill_value)

    return outputs

def lookup_payload_index_by_voxel(nodes, num_nodes, leaf_payload_indices, num_leaves, max_depth, min_bound, max_bound, voxel):
    if num_nodes == 0:
        return -1
    node_index = 0
    depth_remaining = max_depth
    while True:
        if node_index >= num_nodes:
            return -1
        descriptor = nodes[node_index]
        child_depth = depth_remaining - 1
        x_bits = (voxel[0] >> child_depth) & 3
        y_bits = (voxel[1] >> child_depth) & 3
        z_bits = (voxel[2] >> child_depth) & 3
        child_index = x_bits | (y_bits << 2) | (z_bits << 4)
        child_bit = 1 << child_index

        if (descriptor.child_mask & child_bit) == 0:
            return -1
        if (descriptor.leaf_mask & child_bit) != 0:
            leaf_id = descriptor.payload_base + prefix_rank(descriptor.leaf_mask, child_index)
            if leaf_id >= num_leaves:
                return -1
            return leaf_payload_indices[leaf_id]

        node_index = descriptor.child_base + prefix_rank(descriptor.internal_child_mask, child_index)
        depth_remaining -= 1
        if depth_remaining <= 0:
            return -1

def prefix_rank(mask, index):
    count = 0
    for i in range(index):
        if mask & (1 << i):
            count += 1
    return count
```

**Parameters:**
- `octree`: Sparse voxel octree structure [S1, unofficial].
- `points`: Vector of 3D points [S1, unofficial].
- `payload`: Raw payload data array [S1, unofficial].
- `payload_rows`: Number of leaf entries [S1, unofficial].
- `channels`: Values per leaf [S1, unofficial].
- `fill_value`: Default value for empty/out-of-bounds [S1, unofficial].

**Edge Cases and Pitfalls:**
- Points outside root bounds are skipped, leaving output as `fill_value` [S1, unofficial].
- Wide4 branching mode is unsupported and throws `ValidationError` [S1, unofficial].
- Precision issues may arise if `grid_size` is very large; use appropriate floating-point types [G].
