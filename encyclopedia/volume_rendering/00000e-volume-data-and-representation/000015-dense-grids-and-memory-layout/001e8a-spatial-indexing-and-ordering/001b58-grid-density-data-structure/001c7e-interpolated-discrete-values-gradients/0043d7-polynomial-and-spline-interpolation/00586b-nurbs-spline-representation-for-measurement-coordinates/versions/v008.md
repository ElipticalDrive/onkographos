# NURBS Spline Representation for Measurement Coordinates

Also called: NURBS Spline Representation, NURBS surface for measurement coordinates, NURBS surface optimization for measurement coordinates, Rational B-spline optimization for view angles

## Overview
This method represents uncertain measurement coordinates (such as view angles and detector locations in CT imaging) as a NURBS surface whose control points and weights are optimized alongside the volume reconstruction [S1, unofficial]. It differs from implicit neural representations by using fixed-degree spline basis functions with optimized control points, which allows for the explicit enforcement of physical consistency conditions (such as Radon transform symmetries) that neural networks approximate implicitly [S1, unofficial]. It is typically paired with a U-Net reconstruction network $G_\mu(\cdot)$ that maps the NURBS-interpolated coordinates to image space [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of nominal measurement coordinates (e.g., view angles $\theta'$, detector positions $t'$) and their associated uncertainties.
*   **Outputs:** Optimized measurement coordinates $\hat{\mathbf{m}}$ and the corresponding volume data, where the mapping from nominal to optimized coordinates is defined by the NURBS surface.

**Data Structures:**
*   **Knot Vectors:** For each dimension $d$ (e.g., angle, detector), a knot vector $\mathbf{K}_d$ of size $N_d + d_{deg} + 1$ is required. The knot vector is not learnable.
*   **Control Points:** A grid of control points $\mathbf{Q}$ of shape $(J, K, \dots)$ corresponding to the dimensions of the measurement space. These are learnable.
*   **Weights:** A grid of scalar weights $w$ of shape $(J, K, \dots)$ corresponding to the control points. These are learnable.
*   **Degrees:** Integer degrees $d_\Theta, d_T \in \mathbb{Z}^+$ for each dimension.

**Knot Vector Construction:**
For a dimension with $J$ segments and degree $d_{deg}$, the knot vector elements $k_u$ for $0 \le u \le J + d_{deg}$ are defined as:
1.  $k_u = 0$ for $0 \le u < d_{deg} + 1$.
2.  $k_u$ is uniformly spaced between 0 and 1 for $d_{deg} + 1 \le u \le J$.
3.  $k_u = 1$ for $J < u \le J + d_{deg}$.

**Basis Function Evaluation:**
The 1D B-spline basis functions $Q_{u, d}(\xi)$ are computed using the Cox-de Boor recursion [S1, unofficial]:
$$
Q_{u,0}(\xi) = \begin{cases} 
1 & \text{if } k_u \le \xi < k_{u+1} \\
0 & \text{otherwise}
\end{cases}
$$
$$
Q_{u,d}(\xi) = \frac{\xi - k_u}{k_{u+d} - k_u} Q_{u,d-1}(\xi) + \frac{k_{u+d+1} - \xi}{k_{u+d+1} - k_{u+1}} Q_{u+1,d-1}(\xi)
$$
If any denominator in the recursion is zero, the corresponding term is set to zero [S1, unofficial].

**Rational Basis Function:**
For a 2D measurement coordinate vector $[\theta', t']^T$, the rational basis function $b_{j,k}$ is defined as [S1, unofficial]:
$$
b_{j,k}([\theta', t']^T) = \frac{\sum_{u=0}^{J-1} \sum_{v=0}^{K-1} w_{u,v} Q_{u,d_\Theta}(\theta') Q_{v,d_T}(t')}{\sum_{u=0}^{J-1} \sum_{v=0}^{K-1} Q_{u,d_\Theta}(\theta') Q_{v,d_T}(t')}
$$
For $D$ dimensions, the NURBS surface is constructed by taking the tensor product of $D$ one-dimensional NURBS curves [S1, unofficial].

**Algorithm Steps:**
1.  **Initialize:** Define knot vectors for each measurement dimension based on the number of segments and chosen degrees. Initialize learnable control points $\mathbf{Q}$ and weights $w$.
2.  **Evaluate Basis:** For a given nominal measurement coordinate $\mathbf{m}'$, compute the 1D B-spline basis functions $Q$ for each dimension using the Cox-de Boor recursion.
3.  **Compute Rational Weights:** Calculate the numerator and denominator of the rational basis function using the tensor product of the 1D basis functions and the learnable weights $w$.
4.  **Map Coordinates:** Compute the optimized measurement coordinate $\hat{\mathbf{m}}$ by applying the rational basis functions to the control points $\mathbf{Q}$.
5.  **Reconstruct:** Use the optimized coordinates $\hat{\mathbf{m}}$ as input to the volume reconstruction network $G_\mu(\cdot)$ to generate the volume data.
6.  **Optimize:** Update control points $\mathbf{Q}$ and weights $w$ via gradient descent to minimize the reconstruction error [S1, unofficial].

**Pseudocode:**
```python
def cox_de_boor(knot_vector, degree, xi):
    """
    Computes 1D B-spline basis functions using Cox-de Boor recursion.
    knot_vector: list of knot values
    degree: integer degree of the spline
    xi: scalar query point
    Returns: list of basis function values for all control points
    """
    n = len(knot_vector) - degree - 1
    basis = [0.0] * n
    
    # Degree 0
    for u in range(n):
        if knot_vector[u] <= xi < knot_vector[u+1]:
            basis[u] = 1.0
            
    # Higher degrees
    for d in range(1, degree + 1):
        new_basis = [0.0] * n
        for u in range(n):
            # First term
            denom1 = knot_vector[u+d] - knot_vector[u]
            if denom1 != 0:
                term1 = (xi - knot_vector[u]) / denom1 * basis[u]
            else:
                term1 = 0.0
                
            # Second term
            denom2 = knot_vector[u+d+1] - knot_vector[u+1]
            if denom2 != 0:
                term2 = (knot_vector[u+d+1] - xi) / denom2 * basis[u+1] if u+1 < n else 0.0
            else:
                term2 = 0.0
                
            new_basis[u] = term1 + term2
        basis = new_basis
    return basis

def nurbs_surface_evaluation(nominal_coords, knot_vectors, degrees, control_points, weights):
    """
    Evaluates the NURBS surface for given nominal coordinates.
    nominal_coords: list of coordinates [theta, t, ...]
    knot_vectors: list of knot vectors for each dimension
    degrees: list of degrees for each dimension
    control_points: tensor of control points
    weights: tensor of weights
    Returns: optimized coordinate value
    """
    # Compute 1D basis functions for each dimension
    basis_funcs = []
    for i, coord in enumerate(nominal_coords):
        basis = cox_de_boor(knot_vectors[i], degrees[i], coord)
        basis_funcs.append(basis)
        
    # Compute tensor product and rational weight
    numerator = 0.0
    denominator = 0.0
    
    # Iterate over all control points (simplified for 2D)
    for u in range(len(basis_funcs[0])):
        for v in range(len(basis_funcs[1])):
            # Tensor product of basis functions
            basis_val = basis_funcs[0][u] * basis_funcs[1][v]
            w = weights[u, v]
            
            numerator += w * basis_val
            denominator += basis_val
            
    if denominator == 0:
        return 0.0 # Or handle as undefined
        
    return numerator / denominator
```

## Subtopics

### [NURBS-based Uncalibrated Imaging Reconstruction](16412-nurbs-based-uncalibrated-imaging-reconstruction.md)
NURBS-based Uncalibrated Imaging Reconstruction is a method for reconstructing volumetric data (specifically CT) from projections with uncertain or uncalibrated measurement coordinates (view angles, tilt angles, detector positions) by modeling these coordinates as a NURBS surface. It differs from implicit neural representations by using fixed-degree spline basis functions with optimized control points, which allows for the explicit enforcement of physical consistency conditions (such as Radon transform symmetries) that neural networks approximate implicitly. It is typically paired with a U-Net reconstruction network $G_\mu(\cdot)$ that maps the NURBS-interpolated coordinates to image space.

## Operating characteristics
*   **Time Complexity:** Evaluation is $O(J \cdot K \cdot \dots)$ per dimension, where $J, K$ are the number of segments. This is generally faster than implicit neural representations which require evaluating deep networks for every query.
*   **Memory Complexity:** Requires storing control points and weights, which scales with the number of segments and dimensions.
*   **Strengths:** Explicitly enforces physical consistency; differentiable; fixed-degree basis functions provide predictable smoothness.
*   **Limitations:** Requires careful tuning of knot vectors and degrees; may struggle with highly irregular measurement errors compared to flexible neural networks.
*   **When to use:** When measurement coordinates are uncertain but follow a smooth, structured pattern, and physical consistency is important.
*   **When not to use:** When measurement errors are highly erratic or lack smoothness, or when computational resources for optimization are limited.

## Background
The method originates from the paper "Differentiable Uncalibrated Imaging" [S1, unofficial], which proposes using NURBS surfaces to model measurement coordinate uncertainties in CT reconstruction. It builds on the principles of spline interpolation and rational basis functions, extending them to the context of differentiable imaging reconstruction. The approach was implemented using PyTorch, leveraging the NURBS-Diff module [S1, unofficial].
