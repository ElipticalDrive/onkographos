# Voxel Data Interpolation and Sampling

Also called: Sample Grid, Sample Grid Index, getNextIntersectColor, getNextIntersectionGradient, getNextIntersectionScalar

## Overview
Voxel Data Interpolation and Sampling retrieves scalar values, gradients, and transformed colors at arbitrary 3D positions within a volume grid [S1, unofficial]. It supports configurable interpolation modes (trilinear or nearest neighbor) and transfer function input modes, enabling the evaluation of density, color, and opacity during ray casting [S1, unofficial]. Unlike the parent [Polynomial and Spline Interpolation](11104-polynomial-and-spline-interpolation.md) which defines the general basis function framework, this method specifically implements the discrete grid access and boundary handling required for standard voxel-based volume rendering [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** Query point $\mathbf{p} = (x, y, z)$ in grid coordinates; grid dimensions $X_{DIM}, Y_{DIM}, Z_{DIM}$; interpolation mode $INTER\_MODE$; transfer function mode $TRN\_MODE$; scalar grid $\mathbf{S}$; gradient grid $\mathbf{G}$.
- **Outputs:** Interpolated scalar value $v$; interpolated gradient vector $\mathbf{g}$; transformed color/opacity (via external transfer function).

**Data Structures:**
The volume data is stored in two contiguous vectors [S1, unofficial]:
1.  `scalars`: `std::vector<float>` of size $X_{DIM} \times Y_{DIM} \times Z_{DIM}$.
2.  `gradients`: `std::vector<glm::vec3>` of size $X_{DIM} \times Y_{DIM} \times Z_{DIM}$.

Index calculation for voxel $(x, y, z)$ [S1, unofficial]:
$$ index = x + (y \cdot X_{DIM}) + (z \cdot X_{DIM} \cdot Y_{DIM}) $$

**Parameters:**
- $INTER\_MODE$: Integer. 1 for trilinear interpolation, 2 for nearest neighbor [S1, unofficial].
- $TRN\_MODE$: Integer. 1 for transfer function input $(v, v)$, 2 for $(v, \|\mathbf{g}\|)$ [S1, unofficial].

**Steps:**
1.  **Boundary Check:** Determine integer coordinates $(i, j, k)$ from query point. If any coordinate is outside $[0, D-1]$, return default values (e.g., $(0,0,0,0)$ for color) [S1, unofficial].
2.  **Sample Grid:**
    - If $INTER\_MODE = 2$ (Nearest Neighbor): Retrieve $\mathbf{S}[index]$ and $\mathbf{G}[index]$ directly [S1, unofficial].
    - If $INTER\_MODE = 1$ (Trilinear): Compute fractional offsets $(u, v, w)$ within the cell. Gather the 8 corner values from $\mathbf{S}$ and $\mathbf{G}$ using the parent's basis function logic [S1, unofficial][S2, unofficial]. Perform weighted sum to get interpolated scalar $v$ and gradient $\mathbf{g}$ [S1, unofficial].
3.  **Transfer Function Preparation:**
    - If $TRN\_MODE = 1$: Pass $(v, v)$ to the transfer function transformer [S1, unofficial].
    - If $TRN\_MODE = 2$: Compute gradient magnitude $m = \|\mathbf{g}\|$. Clamp $m$ to $[0, 1]$. Scale by 256. Pass $(v, m \cdot 256)$ to the transformer [S1, unofficial].
4.  **Return:** Return the result of the transfer function evaluation (color/opacity) [S1, unofficial].

**Pseudocode:**
```python
def sample_voxel(x, y, z, xd, yd, zd, scalars, gradients, inter_mode, trn_mode):
    # 1. Boundary Check
    if not (0 <= x < xd and 0 <= y < yd and 0 <= z < zd):
        return (0.0, 0.0, 0.0, 0.0) # Default color/alpha

    # 2. Sample Grid
    if inter_mode == 2: # Nearest Neighbor
        idx = x + y * xd + z * xd * yd
        v = scalars[idx]
        g = gradients[idx]
    elif inter_mode == 1: # Trilinear
        # Implementation details for trilinear interpolation are assumed 
        # to follow the parent [Polynomial and Spline Interpolation](11104-polynomial-and-spline-interpolation.md)
        # using the 8 neighbors.
        v = trilinear_interpolate(x, y, z, xd, yd, zd, scalars)
        g = trilinear_interpolate_gradient(x, y, z, xd, yd, zd, gradients)
    else:
        raise ValueError("Unknown interpolation mode")

    # 3. Transfer Function Preparation
    if trn_mode == 1:
        tf_input = (v, v)
    elif trn_mode == 2:
        grad_mag = length(g)
        grad_mag = clamp(grad_mag, 0.0, 1.0)
        scaled_grad = grad_mag * 256.0
        tf_input = (v, scaled_grad)
    else:
        raise ValueError("Unknown transfer mode")

    # 4. Return transformed color (assuming external transfer function logic)
    # Note: The source mentions 'getNextIntersectColor' implies returning color/alpha
    return transfer_function(tf_input)

def trilinear_interpolate(x, y, z, xd, yd, zd, data):
    # [G] Standard trilinear interpolation implementation
    ix = int(floor(x))
    iy = int(floor(y))
    iz = int(floor(z))
    fx = x - ix
    fy = y - iy
    fz = z - iz
    
    # Helper to get clamped value
    def get_val(dx, dy, dz):
        idx = dx + dy * xd + dz * xd * yd
        return data[idx]

    c000 = get_val(ix, iy, iz)
    c100 = get_val(ix+1, iy, iz)
    c010 = get_val(ix, iy+1, iz)
    c110 = get_val(ix+1, iy+1, iz)
    c001 = get_val(ix, iy, iz+1)
    c101 = get_val(ix+1, iy, iz+1)
    c011 = get_val(ix, iy+1, iz+1)
    c111 = get_val(ix+1, iy+1, iz+1)

    # Interpolate x
    c00 = lerp(c000, c100, fx)
    c01 = lerp(c010, c110, fx)
    c10 = lerp(c001, c101, fx)
    c11 = lerp(c011, c111, fx)
    
    # Interpolate y
    c0 = lerp(c00, c01, fy)
    c1 = lerp(c10, c11, fy)
    
    # Interpolate z
    return lerp(c0, c1, fz)

def trilinear_interpolate_gradient(x, y, z, xd, yd, zd, gradients):
    # [G] Trilinear interpolation for vector fields
    ix = int(floor(x))
    iy = int(floor(y))
    iz = int(floor(z))
    fx = x - ix
    fy = y - iy
    fz = z - iz
    
    def get_vec(dx, dy, dz):
        idx = dx + dy * xd + dz * xd * yd
        return gradients[idx]

    c000 = get_vec(ix, iy, iz)
    c100 = get_vec(ix+1, iy, iz)
    c010 = get_vec(ix, iy+1, iz)
    c110 = get_vec(ix+1, iy+1, iz)
    c001 = get_vec(ix, iy, iz+1)
    c101 = get_vec(ix+1, iy, iz+1)
    c011 = get_vec(ix, iy+1, iz+1)
    c111 = get_vec(ix+1, iy+1, iz+1)

    c00 = lerp_vec(c000, c100, fx)
    c01 = lerp_vec(c010, c110, fx)
    c10 = lerp_vec(c001, c101, fx)
    c11 = lerp_vec(c011, c111, fx)
    
    c0 = lerp_vec(c00, c01, fy)
    c1 = lerp_vec(c10, c11, fy)
    
    return lerp_vec(c0, c1, fz)

def lerp(a, b, t):
    return a + t * (b - a)

def lerp_vec(a, b, t):
    return a + t * (b - a)
```

**Edge Cases and Pitfalls:**
- The source notes that while the structure supports trilinear interpolation, the specific implementation in `getNextIntersectColor` might default to nearest neighbor if voxel intersection logic is not fully implemented [S1, unofficial].
- Gradient magnitude clamping to $[0, 1]$ before scaling is critical for $TRN\_MODE=2$ [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample for nearest neighbor. $O(1)$ for trilinear (constant 8 lookups and arithmetic).
- **Memory Complexity:** $O(N)$ where $N$ is the number of voxels, storing both scalar and gradient vectors [S1, unofficial].
- **Strengths:** Simple implementation; supports both density and gradient-based transfer functions [S1, unofficial].
- **Limitations:** Trilinear interpolation may introduce artifacts; nearest neighbor is blocky [S1, unofficial].
- **When to use:** Standard volume rendering where performance is key and high-order continuity is not required.
- **When not to use:** When smooth gradients are critical and higher-order methods (B-spline, Tricubic) are available.

## Background
This method originates from early volume ray casting implementations, specifically referenced in the CSE-333 Computer Graphics 2020 project [S1, unofficial]. It is also conceptually aligned with modern field evaluation systems like Blender's Geometry Nodes "Sample Grid" and "Sample Grid Index" nodes, which provide position-based interpolation and low-level index access [S2, unofficial].
