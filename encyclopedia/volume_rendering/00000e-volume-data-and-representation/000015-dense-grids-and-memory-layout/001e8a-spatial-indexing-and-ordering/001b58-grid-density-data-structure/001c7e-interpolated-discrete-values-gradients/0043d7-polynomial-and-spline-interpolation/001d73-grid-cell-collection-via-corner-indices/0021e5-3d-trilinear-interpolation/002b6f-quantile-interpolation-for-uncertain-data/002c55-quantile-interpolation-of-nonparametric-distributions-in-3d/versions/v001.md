# Quantile Interpolation of Nonparametric Distributions in 3D

Also called: 3D Quantile Interpolation, Quantile Interpolation of Histograms in 3D

## Overview
This method computes the interpolated Probability Density Function (PDF) of a random variable at an arbitrary 3D position within a grid cell by interpolating quantile representations from the eight vertices of the containing 3D cell [S1]. It extends 1D quantile interpolation to 3D using a bilinear interpolation logic, sequentially interpolating along edges, then faces, then the volume [S1]. It is distinguished from standard trilinear interpolation of scalar values by operating on probability density functions, preserving the statistical properties of uncertain data [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The PDFs of the $j$-th quantile at the 8 vertices of a 3D grid cell, denoted $Pr_1$ through $Pr_8$ [S1]. The spatial distance parameters $\alpha, \beta, \gamma \in [0,1]$ defining the query point's position relative to the cell vertices along the three dimensions [S1].
*   **Output:** The interpolated probability density $Pr(Q_j)$ for the $j$-th quantile at the query point [S1].

**Data Structures:**
The method assumes the PDFs at vertices are pre-computed piecewise constant functions where each quantile $j$ has a constant probability density $Pr_i$ at vertex $i$ [S1]. No additional data structures are required beyond the 8 scalar values and 3 parameters.

**Steps:**
1.  **Edge Interpolation:** Compute interpolated PDFs along the cell edges by applying the 1D quantile interpolation formula to the PDFs at grid vertices using parameter $\alpha$ [S1]. This yields intermediate terms $t_1$ through $t_4$.
2.  **Face Interpolation:** Compute interpolated PDFs in the interior of cell faces by applying the 1D quantile interpolation formula to the edge-interpolated PDFs using parameter $\beta$ [S1]. This yields intermediate terms $t_5$ and $t_6$.
3.  **Volume Interpolation:** Compute the final interpolated PDF in the interior of the 3D cell by applying the 1D quantile interpolation formula to the face-interpolated PDFs using parameter $\gamma$ [S1]. This yields the final result $Pr(Q_j)$.

**Formulas:**
The final interpolated PDF for the $j$-th quantile is given by [S1]:

$$Pr(Q_j) = \frac{Pr_1 Pr_2 Pr_3 Pr_4 Pr_5 Pr_6 Pr_7 Pr_8}{t_1 t_2 t_3 t_4 t_5 t_6 t_7}$$

where the intermediate terms are defined as [S1]:

$$t_1 = \alpha Pr_1 + (1-\alpha)Pr_2$$
$$t_2 = \alpha Pr_3 + (1-\alpha)Pr_4$$
$$t_3 = \alpha Pr_5 + (1-\alpha)Pr_6$$
$$t_4 = \alpha Pr_7 + (1-\alpha)Pr_8$$
$$t_5 = \beta \frac{Pr_1 Pr_2}{t_1} + (1-\beta) \frac{Pr_3 Pr_4}{t_2}$$
$$t_6 = \beta \frac{Pr_5 Pr_6}{t_3} + (1-\beta) \frac{Pr_7 Pr_8}{t_4}$$
$$t_7 = \gamma \frac{Pr_1 Pr_2 Pr_3 Pr_4}{t_1 t_2 t_5} + (1-\gamma) \frac{Pr_5 Pr_6 Pr_7 Pr_8}{t_3 t_4 t_6}$$

**Parameters:**
*   $Pr_i$: The probability density of the $j$-th quantile for the random variable at the $i$-th vertex of the 3D grid cell ($i=1..8$) [S1].
*   $\alpha, \beta, \gamma$: Spatial distance parameters for the vertices of the 3D grid cell along the three dimensions, each in the range $[0,1]$ [S1].

**Pseudocode:**
```python
def quantile_interpolation_3d(Pr, alpha, beta, gamma):
    """
    Computes the interpolated PDF for a specific quantile in a 3D cell.
    
    Args:
        Pr (list of 8 floats): Probability densities Pr_1 to Pr_8 at the 8 vertices.
        alpha (float): Spatial parameter along the first dimension [0, 1].
        beta (float): Spatial parameter along the second dimension [0, 1].
        gamma (float): Spatial parameter along the third dimension [0, 1].
        
    Returns:
        float: The interpolated probability density Pr(Q_j).
    """
    Pr1, Pr2, Pr3, Pr4, Pr5, Pr6, Pr7, Pr8 = Pr
    
    # Step 1: Edge interpolation (along dimension 1)
    t1 = alpha * Pr1 + (1 - alpha) * Pr2
    t2 = alpha * Pr3 + (1 - alpha) * Pr4
    t3 = alpha * Pr5 + (1 - alpha) * Pr6
    t4 = alpha * Pr7 + (1 - alpha) * Pr8
    
    # Step 2: Face interpolation (along dimension 2)
    # Note: Division by zero if t1, t2, t3, or t4 is zero. 
    # In practice, PDFs are non-negative; if zero, the term vanishes.
    # Handle potential division by zero for numerical stability.
    term5_num = beta * Pr1 * Pr2
    term5_den = t1 if t1 != 0 else 1e-30 # Guard against division by zero [G]
    term5_part1 = term5_num / term5_den
    
    term5_part2 = (1 - beta) * (Pr3 * Pr4 / (t2 if t2 != 0 else 1e-30))
    t5 = term5_part1 + term5_part2
    
    term6_num = beta * Pr5 * Pr6
    term6_den = t3 if t3 != 0 else 1e-30
    term6_part1 = term6_num / term6_den
    
    term6_part2 = (1 - beta) * (Pr7 * Pr8 / (t4 if t4 != 0 else 1e-30))
    t6 = term6_part1 + term6_part2
    
    # Step 3: Volume interpolation (along dimension 3)
    # Numerator parts for t7
    num1 = Pr1 * Pr2 * Pr3 * Pr4
    den1 = t1 * t2 * t5
    part1 = gamma * (num1 / den1) if den1 != 0 else 0.0
    
    num2 = Pr5 * Pr6 * Pr7 * Pr8
    den2 = t3 * t4 * t6
    part2 = (1 - gamma) * (num2 / den2) if den2 != 0 else 0.0
    
    t7 = part1 + part2
    
    # Final result
    numerator = Pr1 * Pr2 * Pr3 * Pr4 * Pr5 * Pr6 * Pr7 * Pr8
    denominator = t1 * t2 * t3 * t4 * t5 * t6 * t7
    
    if denominator == 0:
        return 0.0 # Guard against division by zero [G]
        
    return numerator / denominator
```

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If any intermediate term $t_i$ is zero, division by zero occurs. This happens if the probability densities at vertices are zero and the interpolation weights result in a zero sum. A small epsilon or explicit zero-check is required [G].
*   **Non-Negativity:** PDFs must be non-negative. The interpolation formula preserves non-negativity if inputs are non-negative and parameters are in $[0,1]$.
*   **Normalization:** The interpolated PDF for a specific quantile $j$ is computed. The full PDF requires computing this for all quantiles $j$ and ensuring the sum of $Pr(Q_j) \times width_j$ equals 1, or normalizing the result if the quantile widths vary [S1].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per query point per quantile, as it involves a fixed number of arithmetic operations (multiplications, additions, divisions).
*   **Memory Complexity:** $O(1)$ auxiliary space per query, requiring storage for 8 vertex PDFs and 3 parameters.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Provides a closed-form solution for interpolating nonparametric distributions, preserving the statistical nature of uncertain data. It is computationally efficient.
*   **Limitations:** Requires pre-computation of PDFs at grid vertices (e.g., via histograms or KDE). The method assumes the quantile representation is consistent across vertices (same number of quantiles, same quantile values).
*   **When to Use:** When visualizing or analyzing data with inherent uncertainty represented by nonparametric PDFs, and smooth interpolation of these distributions is required.
*   **When Not to Use:** When parametric distributions are sufficient, or when computational resources are extremely limited and simple scalar interpolation is acceptable despite losing uncertainty information.

## Background
The method was extended from 2D by Hollister and Pang, who presented a closed-form solution for bilinear interpolation of histograms/nonparametric distributions on a 2D grid using quantile interpolation [S1]. The 3D extension follows a similar approach, applying the 1D quantile interpolation formula sequentially along edges, faces, and the volume [S1]. It is used in direct volume rendering with nonparametric models of uncertainty [S1].
