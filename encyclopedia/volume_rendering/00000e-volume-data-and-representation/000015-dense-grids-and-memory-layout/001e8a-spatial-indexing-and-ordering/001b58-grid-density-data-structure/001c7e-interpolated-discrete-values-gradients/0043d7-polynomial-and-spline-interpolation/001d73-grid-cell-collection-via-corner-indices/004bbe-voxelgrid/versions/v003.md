# VoxelGrid

Also called: 3D Voxel Grid, Differentiable Voxel Grid, Learnable Voxel Grid, Neural Voxel Grid, Voxel-grid Representation

## Overview
VoxelGrid is a dense, learnable 3D data structure that defines a parameterized function in 3D space by storing learnable values at the grid vertices to support efficient feature queries via trilinear interpolation [S1]. It enables differentiable trilinear interpolation of density and color, replacing coordinate-based MLPs with a fixed, axis-aligned tensor layout for efficient neural rendering [S2, unofficial]. It builds on [Grid Cell Collection via Corner Indices](1518-grid-cell-collection-via-corner-indices.md) by explicitly storing values at the 8 corners of each voxel for interpolation [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A tensor $P$ of query points with coordinates $(x, y, z)$ [S2, unofficial].
- Output: A tensor of interpolated values (e.g., density, RGB) at those points [S2, unofficial].

**Data Structures:**
- Layout: The grid stores corner values to facilitate trilinear interpolation [S1].
- Dimensions: If the logical grid dimensions are `shape` = $(S_x, S_y, S_z)$, the storage tensor has shape $(S_x+1, S_y+1, S_z+1, d)$ [S2, unofficial].
- Fields: The tensor contains floating-point values (typically `float32`) [S2, unofficial]. $d$ is the output dimensionality (e.g., 1 for scalar density, 3 for RGB color) [S2, unofficial].

**Parameters:**
- `shape`: Tuple of integers defining the logical grid dimensions (e.g., $(6, 6, 6)$) [S2, unofficial].
- `d`: Integer defining the output dimensionality (default 1) [S2, unofficial].
- `max`: Float defining the maximum value for random initialization (default 1.0) [S2, unofficial].
- `fill`: Optional tensor or value used for initialization instead of random values [S2, unofficial].

**Algorithm Steps:**
1. **Initialization**: Create the `grid` parameter with shape $(S_x+1, S_y+1, S_z+1, d)$ [S2, unofficial]. Initialize with random values scaled by `max` or provided `fill` [S2, unofficial].
2. **Coordinate Extraction**: Extract $x, y, z$ coordinate vectors from the input points $P$ [S2, unofficial].
3. **Bracketing**: For each coordinate axis, determine the lower and upper grid indices and the interpolation weight [S2, unofficial].
   - Compute $x_0 = \lfloor x \rfloor$.
   - Set $X_0 = \text{clamp}(x_0, 0, N_x-1)$ and $X_1 = \text{clamp}(x_0 + 1, 0, N_x-1)$, where $N_x = S_x+1$ is the storage dimension [S2, unofficial].
   - Compute weight $a = \text{clamp}(x - x_0, 0.0, 1.0)$ [S2, unofficial].
   - Repeat for $y$ (indices $Y_0, Y_1$, weight $b$) and $z$ (indices $Z_0, Z_1$, weight $c$) [S2, unofficial].
4. **Trilinear Interpolation**:
   - **X-direction**: Interpolate along the x-axis for all 4 combinations of $(Y, Z)$ corners:
     $$ v_{y0z0} = v(X_0, Y_0, Z_0) \cdot (1-a) + v(X_1, Y_0, Z_0) \cdot a $$
     $$ v_{y1z0} = v(X_0, Y_1, Z_0) \cdot (1-a) + v(X_1, Y_1, Z_0) \cdot a $$
     $$ v_{y0z1} = v(X_0, Y_0, Z_1) \cdot (1-a) + v(X_1, Y_0, Z_1) \cdot a $$
     $$ v_{y1z1} = v(X_0, Y_1, Z_1) \cdot (1-a) + v(X_1, Y_1, Z_1) \cdot a $$
   - **Y-direction**: Interpolate the results from the previous step along the y-axis:
     $$ v_{z0} = v_{y0z0} \cdot (1-b) + v_{y1z0} \cdot b $$
     $$ v_{z1} = v_{y0z1} \cdot (1-b) + v_{y1z1} \cdot b $$
   - **Z-direction**: Interpolate the results along the z-axis:
     $$ v = v_{z0} \cdot (1-c) + v_{z1} \cdot c $$
5. **Output**: Return the final interpolated values, removing the trailing dimension if necessary [S2, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn

def bracket(x, n):
    """Return the indices of the nearest grid points to x, as well as weights."""
    x0 = torch.floor(x).long()
    X0 = torch.clamp(x0, min=0, max=(n - 1))
    X1 = torch.clamp(x0 + 1, min=0, max=(n - 1))
    return X0, X1, torch.clamp(x - x0.float(), min=0.0, max=1.0)

def interpolate(v0, v1, alpha):
    """Interpolate between v0 and v1 using alpha, using unsqueeze to properly handle batches."""
    return v0 * (1 - alpha.unsqueeze(-1)) + v1 * alpha.unsqueeze(-1)

class VoxelGrid(nn.Module):
    def __init__(self, shape, d=1, max=1.0, fill=None):
        """A 3D voxel grid with given `shape` with learnable values at the middle of the voxels."""
        super(VoxelGrid, self).__init__()
        # Note that we store *corner* values, so we need one more point in each dimension:
        storage_shape = tuple(s + 1 for s in shape)
        if fill is not None:
            self.grid = nn.Parameter(fill.view(1, 1, 1, d).repeat(*storage_shape, 1))
        else:
           self.grid = nn.Parameter(torch.rand(*storage_shape, d, dtype=torch.float32) * max)

    def forward(self, P):
        """Implement trilinear interpolation at the points P."""
        x, y, z = P[..., 0], P[..., 1], P[..., 2]

        # Get indices of the corners, clamping to the grid size where needed:
        X0, X1, a = bracket(x, self.grid.shape[0])
        Y0, Y1, b = bracket(y, self.grid.shape[1])
        Z0, Z1, c = bracket(z, self.grid.shape[2])

        # Interpolate in the x direction:
        y0z0 = interpolate(self.grid[X0, Y0, Z0, :], self.grid[X1, Y0, Z0, :], a)
        y1z0 = interpolate(self.grid[X0, Y1, Z0, :], self.grid[X1, Y1, Z0, :], a)
        y0z1 = interpolate(self.grid[X0, Y0, Z1, :], self.grid[X1, Y0, Z1, :], a)
        y1z1 = interpolate(self.grid[X0, Y1, Z1, :], self.grid[X1, Y1, Z1, :], a)

        # Interpolate in the y direction:
        z0 = interpolate(y0z0, y1z0, b)
        z1 = interpolate(y0z1, y1z1, b)

        # Interpolate in the z direction:
        return interpolate(z0, z1, c).squeeze(-1)
```

**Edge Cases and Pitfalls:**
- **Boundary Handling**: Query points outside the grid bounds must be clamped to the nearest valid index $[0, n-1]$ to prevent out-of-bounds memory access [S2, unofficial].
- **Precision**: Floating-point precision in coordinate extraction ($\lfloor x \rfloor$) and weight calculation ($x - \lfloor x \rfloor$) can introduce small errors, but clamping weights to $[0, 1]$ mitigates instability [S2, unofficial].
- **Invalid Values**: The grid can store an `invalid_val` (default 0) to mark empty or uninitialized voxels, which is returned for out-of-bounds or uninitialized queries [S3, unofficial].

## Background
VoxelGrid was introduced in Differentiable Volumetric Graphics (DVGO) as a faster alternative to the original Neural Radiance Field (NeRF), which used a fully connected multi-layer perceptron (MLP) [S2, unofficial]. By storing density and color in a voxel grid and using differentiable trilinear interpolation, DVGO enabled efficient training and rendering of neural radiance fields [S2, unofficial]. Lightning NeRF also utilizes a voxel-grid representation explicitly storing scene properties in grid vertices to support efficient feature queries [S1].
