# Hermite Interpolation of Scalar Fields

Also called: C1-continuous Hermite Interpolation, Hermite Interpolation

## Overview
Hermite interpolation of scalar fields renders scalar-valued functions (such as height fields and signed distance fields) by storing partial derivatives alongside function values on a regular grid [S1, unofficial]. This approach guarantees a globally $C^1$-continuous result, unlike the $C^0$ approximations produced by standard bi- or trilinear filtering [S1, unofficial]. It serves as a storage-efficient replacement for normal mapping, as surface normals can be derived directly from the stored gradient data without requiring extra storage [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A regular grid of samples. Each grid point stores the scalar function value $f$ and its partial derivatives $\nabla f = (\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z})$ [S1, unofficial].
*   **Output:** An interpolated scalar value $u(\mathbf{p})$ and its gradient $\nabla u(\mathbf{p})$ at a query point $\mathbf{p}$ within a grid cell [S1, unofficial].

**Data Structures:**
Each grid node $i$ stores a tuple $(f_i, \frac{\partial f_i}{\partial x}, \frac{\partial f_i}{\partial y}, \frac{\partial f_i}{\partial z})$. In 3D, this is 4 values per node. In 2D, it is 3 values per node [S1, unofficial].

**Method Steps:**
1.  **Identify Cell:** For a query point $\mathbf{p}$, identify the enclosing grid cell defined by corner indices. Compute local coordinates $\mathbf{t} = (t_x, t_y, t_z) \in [0, 1]^d$ relative to the cell's origin [S1, unofficial].
2.  **Compute Basis Functions:** Use cubic Hermite basis functions. For a single dimension with local coordinate $t$, the basis functions for value and derivative are:
    $$ h_{00}(t) = 2t^3 - 3t^2 + 1 $$
    $$ h_{10}(t) = t^3 - 2t^2 + t $$
    $$ h_{01}(t) = -2t^3 + 3t^2 $$
    $$ h_{11}(t) = t^3 - t^2 $$
    These are applied independently to each dimension to form the tensor product basis [S1, unofficial].
3.  **Interpolate Value:** The interpolated scalar value $u(\mathbf{p})$ is the weighted sum of the stored values and derivatives at the cell corners using the tensor product of the basis functions [S1, unofficial].
4.  **Interpolate Gradient:** The gradient $\nabla u(\mathbf{p})$ is computed by differentiating the interpolation polynomial. The exact normals of the reconstructed cubic Hermite surface are used as shading normals [S1, unofficial].
5.  **Mixed Partial Derivatives (3D):** For 3D fields, mixed partial derivatives (e.g., $\frac{\partial^2 f}{\partial x \partial y}$) are required for full $C^1$ continuity in the gradient calculation. These are approximated using a method akin to Adini's method for parametric surface patches [S1, unofficial]. The specific formula for Adini's approximation is not detailed in the sources, but it is derived to approximate the mixed derivatives from the available first-order data [S1, unofficial].

**Pseudocode:**

    t2 = t * t

    h10 = t3 - 2 * t2 + t
    h01 = -2 * t3 + 3 * t2
    h11 = t3 - t2
    return h00, h10, h01, h11

## Subtopics

### Floating Scale Surface Reconstruction (FSSR) Integration
In Floating Scale Surface Reconstruction (FSSR), Hermite interpolation is used to improve surface reconstruction quality [S2]. The original FSSR weighting function is not $C^1$-continuous; it is replaced with $w(r) = \frac{1}{12} (r - 3)^{12} (r + 1)^4$ to ensure $C^1$ continuity [S2]. In FSSR, cubic Hermite interpolation improves mean and RMS error and visual appearance compared to quadratic methods, although the maximum error can remain large [S2].

## Operating characteristics
*   **Continuity:** Guarantees global $C^1$ continuity, providing smoother surfaces and more accurate shading normals compared to $C^0$ methods [S1, unofficial].
*   **Storage:** Storage efficient if surface normals are already part of the discrete field of samples, as it merely uses a different basis to store the same data (values and gradients) [S1, unofficial]. It does not necessarily require extra storage compared to storing normals separately [S1, unofficial].
*   **Performance:** Cubic interpolation improves visual appearance and error metrics over linear or quadratic methods in FSSR [S2].
*   **Limitations:** Requires computation of mixed partial derivatives in 3D, which are approximated rather than exact, potentially introducing artifacts if the approximation is poor [S1, unofficial].

## Background
Hermite interpolation of scalar fields was proposed as a technique for real-time computer graphics, specifically for rendering height fields and signed distance fields [S1, unofficial]. It generalizes to arbitrary orders and dimensions [S1, unofficial]. The method is used in surface reconstruction algorithms like Poisson Surface Reconstruction (PSR) and Floating Scale Surface Reconstruction (FSSR) [S2].
