# Trilinear Gradient Interpolation

Also called: Trilinear Interpolation Backward Pass

## Overview
Trilinear Gradient Interpolation computes the gradient of the trilinear interpolation operation with respect to the input scalar field values, enabling backpropagation through sparse voxel octree (SVO) or dense grid structures [S1, unofficial]. It solves the problem of differentiating the spatial sampling process in neural rendering and physics simulations by distributing the loss gradients from the output samples back to the 8 corner voxels of the interpolated cell [S1, unofficial]. Unlike forward interpolation which outputs a single value, this method outputs a gradient tensor of the same shape as the input payload, allowing end-to-end training of voxel-based representations [S1, unofficial]. It differs from [Analytic Derivative of Tri-linear Interpolation](6919-analytic-derivative-of-tri-linear-interpolation.md) by explicitly handling the discrete lookup and accumulation logic required for sparse data structures, rather than assuming a continuous analytic derivative on a dense grid.

## How it works
**Inputs:**
- `points`: Array of query points $(x, y, z)$ in world space.
- `grad_outputs`: Gradient of the loss with respect to the forward interpolation outputs. Shape: $(N, C)$, where $N$ is the number of points and $C$ is the number of channels (e.g., RGB, RGBA).
- `grid`: Sparse Voxel Octree (SVO) or dense grid structure containing scalar field values.
- `min_bound`, `max_bound`: World space bounding box of the grid.
- `max_depth`: Maximum depth of the SVO.
- `channels`: Number of channels per payload.

**Outputs:**
- `grad_payload`: Gradient tensor for the grid payloads. Shape: $(P, C)$, where $P$ is the number of leaf payloads. Initialized to zeros.

**Data Structures:**
- **SVO Node**: Contains `child_mask`, `leaf_mask`, `child_base`, `payload_base`.
- **Leaf Payload**: Stores the scalar values for the voxel.
- **Gradient Accumulator**: `grad_payload` array of size `num_leaves * channels`.

**Parameters:**
- `fadeX`, `fadeY`, `fadeZ`: Trilinear interpolation weights (fractional coordinates) in $[0, 1]$.
- `voxel_size`: Size of a voxel at the leaf level.

**Steps:**

1. **Initialization**: Create `grad_payload` of size `num_leaves * channels` initialized to 0.0.

2. **Point Processing Loop**: For each point $p_i$ in `points` with corresponding gradient `g_i` in `grad_outputs`:
   
   a. **Boundary Check**: If $p_i$ is outside `[min_bound, max_bound]`, skip to next point.
   
   b. **Voxel Coordinate Calculation**:
      Compute the scale factor $S = 2^{\text{max\_depth}}$.
      Calculate voxel indices $(v_x, v_y, v_z)$ and fractional offsets $(f_x, f_y, f_z)$:
      $$
      v_x = \lfloor \frac{p_i.x - \text{min\_bound}.x}{\text{max\_bound}.x - \text{min\_bound}.x} \times S \rfloor
      $$
      $$
      f_x = \frac{p_i.x - \text{min\_bound}.x}{\text{max\_bound}.x - \text{min\_bound}.x} \times S - v_x
      $$
      (Repeat for $y, z$).
      Let $\text{fadeX} = f_x$, $\text{fadeY} = f_y$, $\text{fadeZ} = f_z$.

   c. **Corner Identification**: Identify the 8 corner voxel indices $(x, y, z)$ where $x, y, z \in \{v_x, v_x+1\}$.
      Define corner indices $k \in \{0, \dots, 7\}$ based on binary representation of $(x-v_x, y-v_y, z-v_z)$.

   d. **Gradient Accumulation**:
      Initialize `grad_accum` vector of size $C$ to 0.
      For each corner $k \in \{0, \dots, 7\}$:
      
      i. **Weight Calculation**:
         Let $b_x, b_y, b_z$ be the bits of $k$ corresponding to $x, y, z$ offsets (0 or 1).
         $$
         w_k = (1 - \text{fadeX})^{1-b_x} \text{fadeX}^{b_x} \times (1 - \text{fadeY})^{1-b_y} \text{fadeY}^{b_y} \times (1 - \text{fadeZ})^{1-b_z} \text{fadeZ}^{b_z}
         $$
      
      ii. **Lookup**:
         Query the SVO for the leaf payload index $idx_k$ at corner $k$.
         If $idx_k < 0$ (not found or outside bounds), continue.
      
      iii. **Accumulate**:
         For each channel $c \in \{0, \dots, C-1\}$:
         $$
         \text{grad\_payload}[idx_k \times C + c] \ += w_k \times \text{grad\_outputs}[i \times C + c]
         $$

3. **Return**: `grad_payload`.

**Pseudocode:**

```python
def trilinear_gradient_interpolation(points, grad_outputs, grid, min_bound, max_bound, max_depth, channels):
    num_points = len(points)
    num_leaves = grid.num_leaves()
    grad_payload = [0.0] * (num_leaves * channels)
    
    scale = 1 << max_depth
    extent_x = max_bound.x - min_bound.x
    extent_y = max_bound.y - min_bound.y
    extent_z = max_bound.z - min_bound.z
    
    for i in range(num_points):
        p = points[i]
        g_out = grad_outputs[i] # Vector of size channels
        
        # Boundary check
        if not (min_bound.x <= p.x <= max_bound.x and 
                min_bound.y <= p.y <= max_bound.y and 
                min_bound.z <= p.z <= max_bound.z):
            continue
            
        # Voxel coordinates
        vx = floor((p.x - min_bound.x) / extent_x * scale)
        vy = floor((p.y - min_bound.y) / extent_y * scale)
        vz = floor((p.z - min_bound.z) / extent_z * scale)
        
        # Fractional offsets
        fx = (p.x - min_bound.x) / extent_x * scale - vx
        fy = (p.y - min_bound.y) / extent_y * scale - vy
        fz = (p.z - min_bound.z) / extent_z * scale - vz
        
        # Iterate over 8 corners
        for k in range(8):
            bx = (k >> 0) & 1
            by = (k >> 1) & 1
            bz = (k >> 2) & 1
            
            cx = vx + bx
            cy = vy + by
            cz = vz + bz
            
            # Weight calculation
            wx = (1 - fx) if bx == 0 else fx
            wy = (1 - fy) if by == 0 else fy
            wz = (1 - fz) if bz == 0 else fz
            weight = wx * wy * wz
            
            # Lookup payload index
            payload_idx = grid.query_leaf_index(cx, cy, cz)
            
            if payload_idx < 0:
                continue
                
            # Accumulate gradients
            base_idx = payload_idx * channels
            for c in range(channels):
                grad_payload[base_idx + c] += weight * g_out[c]
                
    return grad_payload
```

**Edge Cases and Pitfalls:**
- **Out of Bounds**: If a corner voxel is outside the grid bounds or not a leaf, its contribution is zero. The code must handle `payload_idx < 0` gracefully [S1, unofficial].
- **Precision**: Fractional coordinates should be computed carefully to avoid precision errors near voxel boundaries. Using `floor` and subtraction as shown helps maintain consistency with the forward pass [S1, unofficial].
- **Zero Weights**: If a point lies exactly on a voxel boundary, some weights may be zero. This is handled naturally by the weight calculation.

## Subtopics

### [Normal Approximation with Finite Differences](9736-normal-approximation-with-finite-differences.md)
Normal Approximation with Finite Differences computes the surface normal at a ray-scalar field intersection point by approximating the gradient via finite differences of the scalar field values. It differs from its parent method, Trilinear Gradient Interpolation, by explicitly requiring trilinear interpolation calls to evaluate the scalar field at displaced points, rather than relying on pre-computed or stored gradients. This approach avoids discontinuities at voxel boundaries that can cause artifacts in shading.

### Trilinear Normal Interpolation
Trilinear Normal Interpolation interpolates the surface normal at an intersection point using trilinear interpolation of the pre-computed grid normals at the 8 corners of the intersecting voxel [S3, unofficial]. It differs from Trilinear Gradient Interpolation by operating on normal vectors (3D) rather than scalar values, and assumes normals are stored in the grid rather than derived from scalar field gradients [S3, unofficial]. The weight for corner $(i,j,k)$ is $w_{ijk} = (1-t_x)^{1-i} t_x^i (1-t_y)^{1-j} t_y^j (1-t_z)^{1-k} t_z^k$ [S3, unofficial]. The final normal is normalized after interpolation [S3, unofficial].

## Operating characteristics
- **Time Complexity**: $O(N \times C)$, where $N$ is the number of query points and $C$ is the number of channels. Each point requires 8 lookups and $8 \times C$ additions.
- **Memory Complexity**: $O(P \times C)$ for the gradient payload, where $P$ is the number of leaves.
- **Performance**: Efficient on GPU due to parallel point processing. Memory access patterns can be coalesced if points are sorted.
- **Strengths**: Enables end-to-end training of voxel-based models. Handles sparse data structures efficiently.
- **Limitations**: Gradient discontinuities at voxel boundaries if not handled carefully. Performance degrades with very high channel counts.

## Background
Trilinear Gradient Interpolation is a fundamental operation in differentiable rendering and physics simulations involving voxel-based representations. It was popularized in the context of Sparse Voxel Octrees (SVO) for neural rendering [S1, unofficial]. The method allows gradients to flow back through the spatial sampling process, enabling optimization of voxel colors, densities, or other attributes.
