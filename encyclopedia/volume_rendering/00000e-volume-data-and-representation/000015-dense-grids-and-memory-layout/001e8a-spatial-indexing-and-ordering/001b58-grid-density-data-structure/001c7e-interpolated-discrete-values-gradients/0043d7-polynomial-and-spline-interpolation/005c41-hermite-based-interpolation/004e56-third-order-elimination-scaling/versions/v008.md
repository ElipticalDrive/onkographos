# Third Order Elimination (Scaling)

Also called: Scaling, PSR Scaling

## Overview
Third Order Elimination (Scaling) is a quadratic interpolation method that derives a second-order polynomial from a cubic Hermite basis by scaling the input derivatives to force the third-order coefficient to zero [S1]. It solves the problem of approximating a smooth field with a lower-degree polynomial when cubic complexity is undesirable, specifically targeting the elimination of the $x^3$ term in the local basis [S1]. It differs from [Piecewise Quadratic Hermite Interpolation](4001-piecewise-quadratic-hermite-interpolation.md) and [Least-Squares Derivatives](11066-b-spline-field-interpolation.md) by using a multiplicative scaling factor rather than a least-squares optimization or additive offset, making it computationally cheaper but potentially numerically unstable when derivatives cancel [S1].

## How it works
**Inputs and Outputs:**
- Input: Function values $v_0, v_1$ at local coordinates $t=0$ and $t=1$, and derivatives $d_0, d_1$ at those points.
- Output: Quadratic polynomial coefficients $a_0, a_1, a_2$ for $p(t) = a_0 + a_1 t + a_2 t^2$.

**Data Structures:**
- Scalars $v_0, v_1, d_0, d_1$ (floating point).
- Coefficients $a_0, a_1, a_2$ (floating point).

**Steps:**
1. Compute the scaling factor $s$ using the formula:
   $$ s = \frac{2v_1 - 2v_0}{d_0 + d_1} $$
2. Scale the derivatives:
   $$ d'_0 = s \cdot d_0 $$
   $$ d'_1 = s \cdot d_1 $$
3. Determine the quadratic coefficients based on the value and scaled derivative constraints at $t=0$ and $t=1$:
   - $a_0 = v_0$
   - $a_1 = d'_0$
   - $a_2 = v_1 - v_0 - a_1$

**Pitfalls:**
- The solution becomes unstable if $d_0 + d_1 \approx 0$ (derivatives cancel each other out) [S1]. This occurs when the field has a local extremum or inflection between the points where the gradient changes sign [S1].

**Pseudocode:**
```python
def third_order_elimination_scaling(v0, v1, d0, d1):
    # Compute scaling factor
    denom = d0 + d1
    if abs(denom) < 1e-12:
        # Fallback to linear interpolation if derivatives cancel
        # [G] Standard guard against division by zero
        a0 = v0
        a1 = (v1 - v0)
        a2 = 0.0
    else:
        s = (2.0 * v1 - 2.0 * v0) / denom
        # Scale derivatives
        d0_scaled = s * d0
        d1_scaled = s * d1
        
        # Solve for quadratic coefficients
        # p(0) = v0 => a0 = v0
        # p'(0) = d0_scaled => a1 = d0_scaled
        # p(1) = v1 => a0 + a1 + a2 = v1 => a2 = v1 - a0 - a1
        a0 = v0
        a1 = d0_scaled
        a2 = v1 - a0 - a1
        
    return a0, a1, a2
```

## Subtopics

### Third Order Elimination (Offset)
A quadratic method obtained by adding an offset $o$ to derivatives to eliminate the third order coefficient $a_3$ [S1]. It solves $2v_0 - 2v_1 + (d_0 + o) + (d_1 + o) = 0$, yielding $o = \frac{2v_1 - 2v_0 - d_0 - d_1}{2}$ [S1]. This solution is equivalent to the Least-Squares Derivatives method (equation 11 in [S1]), providing a stable alternative to scaling when derivatives cancel [S1].

## Operating characteristics
- **Time Complexity:** $O(1)$ arithmetic operations (one division, several multiplications/additions).
- **Memory Complexity:** $O(1)$ auxiliary storage.
- **Strengths:** Computationally efficient; implemented in the PSR code for interpolating indicator functions where gradients are steep and unlikely to have opposite signs [S1].
- **Limitations:** Numerically unstable if $d_0 + d_1 \approx 0$ [S1]. Not suitable for general implicit functions with arbitrary curvature without safeguards [S1].
- **When to use:** When cubic interpolation is too expensive and the field is known to have monotonic gradients between samples (e.g., indicator functions near isosurfaces) [S1].

## Background
Originated in the context of accurate isosurface interpolation from Hermite data [S1]. It is discussed as an alternative to least-squares derivative fitting and offset-based elimination, specifically noting its implementation in the PSR (Piecewise Smooth Reconstruction) code [S1].
