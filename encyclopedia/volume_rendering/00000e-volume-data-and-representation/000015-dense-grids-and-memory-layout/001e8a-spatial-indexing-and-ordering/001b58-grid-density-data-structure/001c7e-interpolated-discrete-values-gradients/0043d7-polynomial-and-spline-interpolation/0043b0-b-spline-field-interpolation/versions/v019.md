# B-spline Field Interpolation

Also called: B-spline deformation field, Cubic B-spline field

## Overview
B-spline Field Interpolation is a method for representing continuous scalar or vector fields using a grid of control points and cubic B-spline basis functions, where each basis function has local support [S1, unofficial]. It solves the problem of reconstructing a smooth, differentiable field from discrete samples or training weights, ensuring $C^2$ continuity across cell boundaries [S1, unofficial]. It is distinguished from [Tricubic Interpolation](14963-tricubic-interpolation.md) by its use of B-spline basis functions which guarantee higher-order continuity and local influence, meaning a change in one control point only affects the field within a limited neighborhood rather than globally [S1, unofficial].

## How it works
**Inputs:**
*   Query point $\mathbf{p} = (x, y, z) \in \mathbb{R}^3$.
*   Grid origin $\mathbf{x}_0 = (x_0, y_0, z_0)$.
*   Grid spacing $\mathbf{dx} = (dx, dy, dz)$.
*   Control point weights $w_{i,j,k}$ stored in a dense tensor of shape $(N_x, N_y, N_z, C)$, where $C$ is the channel count (1 for scalar, 3 for vector displacement) [S1, unofficial].

**Outputs:**
*   Interpolated value $u(\mathbf{p})$ or vector $\mathbf{u}(\mathbf{p})$.

**Data Structures:**
*   **Control Point Grid:** A 3D array of weights. For a 3D displacement field, the minimum grid size is $4 \times 4 \times 4$, requiring $64$ control points per component, totaling $192$ degrees of freedom [S1, unofficial].
*   **Basis Functions:** Fixed cubic polynomials defined on $[0, 1]$ [S1, unofficial].

**Steps:**
1.  **Calculate Integer Indices:** Determine the base index of the $4 \times 4 \times 4$ support grid for the query point. The indices $i_x, i_y, i_z$ are computed as:
    $$
    i_x = \left\lfloor \frac{x - x_0}{dx} - 1 \right\rfloor, \quad
    i_y = \left\lfloor \frac{y - y_0}{dy} - 1 \right\rfloor, \quad
    i_z = \left\lfloor \frac{z - z_0}{dz} - 1 \right\rfloor
    $$
    [S1, unofficial]. The support region spans indices $[i_x, i_x+3]$, $[i_y, i_y+3]$, and $[i_z, i_z+3]$ [S1, unofficial].

2.  **Calculate Normalized Coordinates:** Compute the local coordinates $\tilde{x}, \tilde{y}, \tilde{z}$ within the support region:
    $$
    \tilde{x} = \frac{x - x_0}{dx} - 1 - i_x, \quad
    \tilde{y} = \frac{y - y_0}{dy} - 1 - i_y, \quad
    \tilde{z} = \frac{z - z_0}{dz} - 1 - i_z
    $$
    These values lie in the range $[0, 1]$ [S1, unofficial].

3.  **Evaluate Basis Functions:** Compute the cubic B-spline basis weights for each dimension using the normalized coordinates [S1, unofficial]:
    $$
    B_0(\tilde{x}) = \frac{(1 - \tilde{x})^3}{6}
    $$
    $$
    B_1(\tilde{x}) = \frac{3\tilde{x}^3 - 6\tilde{x}^2 + 4}{6}
    $$
    $$
    B_2(\tilde{x}) = \frac{-3\tilde{x}^3 + 3\tilde{x}^2 + 3\tilde{x} + 1}{6}
    $$
    $$
    B_3(\tilde{x}) = \frac{\tilde{x}^3}{6}
    $$
    [S1, unofficial]. Note that $\sum_{k=0}^3 B_k(\tilde{x}) = 1$ [S1, unofficial].

4.  **Gather and Sum:** Retrieve the 64 weights from the grid corresponding to the support indices and compute the weighted sum:
    $$
    u = \sum_{l=0}^3 \sum_{m=0}^3 \sum_{n=0}^3 B_l(\tilde{x}) B_m(\tilde{y}) B_n(\tilde{z}) w_{i_x+l, i_y+m, i_z+n}
    $$
    [S1, unofficial]. For vector fields, this is performed independently for each component channel [S1, unofficial].

**Pseudocode:**
```python
def b_spline_interpolate(x, y, z, x0, y0, z0, dx, dy, dz, weights):
    """
    Interpolate a value at (x, y, z) using a 3D B-spline field.
    
    Args:
        x, y, z: Query coordinates.
        x0, y0, z0: Grid origin.
        dx, dy, dz: Grid spacing.
        weights: 3D array of shape (Nx, Ny, Nz) containing control point weights.
        
    Returns:
        Interpolated scalar value.
    """
    # 1. Calculate integer indices
    ix = int(math.floor((x - x0) / dx - 1))
    iy = int(math.floor((y - y0) / dy - 1))
    iz = int(math.floor((z - z0) / dz - 1))
    
    # 2. Calculate normalized coordinates
    x_tilde = (x - x0) / dx - 1 - ix
    y_tilde = (y - y0) / dy - 1 - iy
    z_tilde = (z - z0) / dz - 1 - iz
    
    # 3. Evaluate basis functions
    def b0(t): return (1 - t)**3 / 6
    def b1(t): return (3*t**3 - 6*t**2 + 4) / 6
    def b2(t): return (-3*t**3 + 3*t**2 + 3*t + 1) / 6
    def b3(t): return t**3 / 6
    
    bx = [b0(x_tilde), b1(x_tilde), b2(x_tilde), b3(x_tilde)]
    by = [b0(y_tilde), b1(y_tilde), b2(y_tilde), b3(y_tilde)]
    bz = [b0(z_tilde), b1(z_tilde), b2(z_tilde), b3(z_tilde)]
    
    # 4. Gather and sum
    value = 0.0
    for l in range(4):
        for m in range(4):
            for n in range(4):
                # Boundary handling: clamp indices to valid range [0, D-1]
                idx_x = max(0, min(ix + l, weights.shape[0] - 1))
                idx_y = max(0, min(iy + m, weights.shape[1] - 1))
                idx_z = max(0, min(iz + n, weights.shape[2] - 1))
                
                value += bx[l] * by[m] * bz[n] * weights[idx_x, idx_y, idx_z]
                
    return value
```

**Parameters:**
*   **Grid Origin:** $[x_0, y_0, z_0]$, the spatial origin of the control point grid [S1, unofficial].
*   **Grid Spacing:** $dx, dy, dz$, the distance between adjacent control points [S1, unofficial].
*   **Control Point Weight:** $w_{i_x, i_y, i_z}$, the scalar value associated with the control point at index $(i_x, i_y, i_z)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Non-Interpolating Property:** The field value at a control point location (where $\tilde{x}=0, \tilde{y}=0, \tilde{z}=0$) is not equal to the weight of that control point due to the blending of neighboring weights. For example, if a single control point has weight 1 and all others 0, the field value at that point is $2/3$ [S1, unofficial].
*   **Boundary Handling:** Indices outside the grid bounds must be clamped to $[0, D_d-1]$ or handled via periodic conditions, though specific strategies vary [S1, unofficial][S2, unofficial].

## Subtopics

### [B-spline Curve Modeling](14651-b-spline-curve-modeling.md)
B-spline Curve Modeling is a technique for generating smooth parametric space curves that interpolate a sequence of control points, primarily used to define the spines of volumetric flames. It is chosen over Hermite interpolation because it guarantees second-order continuity ($C^2$), preventing random twisting of the curve space, and possesses affine invariance. It builds on [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) by applying uniform B-spline basis functions to 1D parametric curves rather than 3D scalar fields.

### Time-varying B-spline Deformation Field
A time-varying displacement field $u(\mathbf{x}, t)$ parametrized by cubic B-splines on a fixed 3D grid, allowing arbitrary continuous position and time queries [S1, unofficial]. It differs from static fields by deriving weights $w(t)$ from a Multi-Layer Perceptron (MLP) $\phi(t) \to w(t)$, which takes time $t$ as input and returns the complete set of weights for the current timestep [S1, unofficial]. This approach ensures implicit time continuity and efficiency, avoiding the need to discretize time into fixed timesteps [S1, unofficial]. The displacement component $u$ at position $(x,y,z)$ and time $t$ is calculated by interpolating weights of the 64 closest grid points using the same cubic B-spline basis functions [S1, unofficial].

### Cox-de Boor recursion for B-spline basis functions
A general recursive method for computing B-spline basis functions of arbitrary degree $d$ given a knot vector [S2, unofficial]. It initializes degree-0 basis functions as piecewise constants and recursively computes higher degrees using a linear combination of degree $d-1$ functions [S2, unofficial]. The degree-0 basis is defined as $Q_{u,0}(k) = 1$ if $k_u \le k \le k_{u+1}$, else 0 [S2, unofficial]. The recursive step is $Q_{u,d}(k) = \frac{k - k_u}{k_{u+d} - k_u} Q_{u,d-1}(k) + \frac{k_{u+d+1} - k}{k_{u+d+1} - k_{u+1}} Q_{u+1,d-1}(k)$ [S2, unofficial]. A key pitfall is division by zero when $k_{u+d} = k_u$ or $k_{u+d+1} = k_{u+1}$, which must be handled by setting the corresponding term to zero [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per query, as it always accesses a fixed $4 \times 4 \times 4$ neighborhood (64 points) regardless of grid size [S1, unofficial].
*   **Memory Complexity:** $O(N_x N_y N_z C)$, where $N$ are grid dimensions and $C$ is channel count. Minimum memory for a 3D displacement field is 192 weights ($4^3 \times 3$) [S1, unofficial].
*   **Strengths:** $C^2$ continuity ensures smooth derivatives, which is critical for gradient-based optimization in neural rendering and deformation [S1, unofficial]. Local support allows for efficient updates and sparse memory access patterns [S1, unofficial].
*   **Limitations:** The field does not interpolate control points directly (values are blended), which may require careful initialization if exact point matching is needed [S1, unofficial].
*   **When to use:** When smooth, differentiable fields are required for deformation or density representation in neural rendering or medical imaging [S1, unofficial].
*   **When not to use:** When exact interpolation of control points is required without blending, or when computational budget is extremely tight and lower-order continuity is acceptable (e.g., linear interpolation).

## Background
The method is based on cubic B-splines introduced by Rueckert et al. [S1, unofficial]. It was adapted for dynamic tomography to represent time-varying displacement fields, where weights are generated by an MLP to allow continuous querying in space and time [S1, unofficial]. The specific cubic basis functions used are standard uniform B-splines [S1, unofficial]. The Cox-de Boor recursion provides the general theoretical foundation for B-spline basis construction [S2, unofficial].
