# Third Order Elimination (Scaling)

Also called: Scaling method, PSR scaling interpolation

## Overview
Third Order Elimination (Scaling) is a quadratic interpolation method that derives a second-order polynomial from a cubic Hermite basis by scaling the input derivatives to force the third-order coefficient ($a_3$) to zero [S1]. It solves the problem of approximating a smooth field with $C^1$ continuity while reducing computational complexity from cubic to quadratic terms [S1]. Unlike [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) which uses fixed basis functions, this method adapts the derivative weights based on the local function values and gradients [S1]. It is distinct from [Third Order Elimination (Offset)](#third-order-elimination-offset) by using multiplicative scaling rather than additive offsets, and from [Least-Squares Derivatives](11066-b-spline-field-interpolation.md) (which it approximates) by being a direct algebraic elimination rather than an optimization [S1].

## How it works
**Inputs:**
*   $v_0, v_1$: Scalar function values at the start and end of the interval ($p(0)$ and $p(1)$).
*   $d_0, d_1$: First-order derivatives (gradients projected onto the interval) at the start and end points.

**Outputs:**
*   Quadratic polynomial coefficients $a_0, a_1, a_2$ for $p(t) = a_0 + a_1 t + a_2 t^2$ where $t \in [0, 1]$.

**Data Structures:**
*   Standard scalar variables for $v_0, v_1, d_0, d_1, s, a_0, a_1, a_2$.

**Steps:**
1.  Calculate the scaling factor $s$ using the function values and derivatives:
    $$ s = \frac{2v_1 - 2v_0}{d_0 + d_1} $$
2.  Scale the derivatives to eliminate the cubic term. The resulting quadratic coefficients are derived from the constraint that the cubic term vanishes:
    $$ a_0 = v_0 $$
    $$ a_1 = s \cdot d_0 $$
    $$ a_2 = v_1 - v_0 - a_1 $$
    *(Note: The source defines the elimination condition as $2v_0 - 2v_1 + s \cdot d_0 + s \cdot d_1 = 0$. Solving for $s$ yields the formula above. The coefficient $a_2$ is determined by the value constraint $a_0 + a_1 + a_2 = v_1$ after the cubic term is removed.)*

**Pseudocode:**
```python
def third_order_elimination_scaling(v0, v1, d0, d1):
    # Calculate scaling factor s
    # Guard against division by zero if derivatives cancel out
    denom = d0 + d1
    if abs(denom) < 1e-9:
        # Fallback to linear interpolation or handle instability [G]
        # Standard linear interpolation: p(t) = v0 + (v1 - v0) * t
        a0 = v0
        a1 = v1 - v0
        a2 = 0.0
    else:
        s = (2.0 * v1 - 2.0 * v0) / denom
        
        # Compute quadratic coefficients
        a0 = v0
        a1 = s * d0
        a2 = v1 - v0 - a1
        
    return a0, a1, a2
```

**Parameters:**
*   None. The method is fully determined by the input data.

**Edge Cases:**
*   **Derivative Cancellation:** If $d_0 + d_1 \approx 0$, the scaling factor $s$ becomes unstable (division by zero) [S1]. This occurs when the derivatives have opposite signs and similar magnitudes [S1].
*   **Zero Derivatives:** If both $d_0$ and $d_1$ are zero, the method defaults to linear interpolation between $v_0$ and $v_1$ if a guard is implemented, otherwise it fails [S1, G].

## Subtopics

### Third Order Elimination (Offset)
A quadratic method obtained by adding an offset $o$ to the derivatives to eliminate the third-order coefficient $a_3$ [S1]. It solves the instability of scaling by using an additive degree of freedom [S1]. The offset is calculated as $o = (2v_1 - 2v_0 - d_0 - d_1) / 2$ [S1]. This solution is equivalent to the Least-Squares Derivatives method (equation 11 in [S1]) [S1]. Choose this when derivatives may cancel out or have opposite signs, as it avoids the division instability of the Scaling method [S1].

## Operating characteristics
**Time and Memory Complexity:**
*   Time: $O(1)$ per sample. Requires a few floating-point operations (additions, multiplications, one division).
*   Memory: $O(1)$ auxiliary storage.

**Measured Performance:**
*   Implemented in the PSR (Polynomial Surface Reconstruction) code for interpolating the indicator function [S1].
*   Effective for implicit functions with steep gradients near isosurfaces where partial derivatives are unlikely to have opposite signs [S1].

**Strengths and Limitations:**
*   **Strengths:** Reduces cubic complexity to quadratic; maintains $C^1$ continuity; simple algebraic implementation [S1].
*   **Limitations:** Numerically unstable when $d_0 + d_1 \approx 0$ [S1]. Not suitable for fields where gradients frequently cancel out [S1].

**When to use/not use:**
*   Use for indicator functions or smooth implicit fields with consistent gradient directions [S1].
*   Do not use when derivatives are expected to change sign rapidly or cancel out, as this causes numerical instability [S1].

## Background
The method was introduced in the context of accurate isosurface interpolation with Hermite data [S1]. It is part of a family of polynomial interpolation techniques that modify cubic Hermite bases to achieve lower-order continuity or stability [S1]. The specific "Scaling" variant is used in the PSR codebase [S1].
