# Hermite Interpolation of Scalar Fields

Also called: C1-continuous Hermite Interpolation, Hermite Interpolation

## Overview
Hermite interpolation of scalar fields renders scalar-valued functions (such as height fields or signed distance fields) by storing partial derivatives alongside function values on a regular grid [S1, unofficial]. Unlike bilinear or trilinear filtering which yields $C^0$ continuity, this method guarantees a globally $C^1$-continuous result by using Hermite interpolation between samples [S1, unofficial]. It serves as a storage-efficient replacement for normal mapping, as surface normals can be derived directly from the stored gradients without extra storage overhead [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A dense grid tensor $\mathbf{G}$ of shape $(D_x, D_y, D_z, C)$, where $C \ge 4$. The first component is the scalar value $f$, and the subsequent components are the partial derivatives $\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}$ [S1, unofficial]. A query point $\mathbf{p} \in \mathbb{R}^3$.
*   **Output:** The interpolated scalar value $f(\mathbf{p})$ and optionally the gradient $\nabla f(\mathbf{p})$ for shading [S1, unofficial].

**Data Structures:**
The grid stores tuples $(f, f_x, f_y, f_z)$ at each voxel corner. For 3D fields, mixed partial derivatives ($f_{xy}, f_{xz}, f_{yz}, f_{xyz}$) are required for exact $C^1$ continuity in all directions, though the sources note an approximation is derived for these akin to Adini's method [S1, unofficial].

**Steps:**
1.  **Locate Support:** Compute integer indices $(i, j, k) = (\lfloor p_x \rfloor, \lfloor p_y \rfloor, \lfloor p_z \rfloor)$ and normalized local coordinates $(u, v, w) = (p_x - i, p_y - j, p_z - k)$ [S1, unofficial][S2].
2.  **Gather Data:** Retrieve the 8 corner values and their associated derivatives from the grid. Let $f_{ijk}$ be the value at corner $(i,j,k)$, and $f_{x,ijk}, f_{y,ijk}, f_{z,ijk}$ be the partial derivatives [S1, unofficial].
3.  **Approximate Mixed Derivatives:** If exact mixed derivatives are not stored, approximate them using a method akin to Adini's for parametric surface patches [S1, unofficial].
4.  **Evaluate Basis:** Compute the 1D cubic Hermite basis functions for each dimension using $u, v, w$.
5.  **Interpolate:** Perform the weighted summation of the gathered data using the basis functions to obtain $f(\mathbf{p})$ [S1, unofficial].
6.  **Shading:** Use the exact normals of the reconstructed cubic Hermite surface as shading normals [S1, unofficial].

**Formulas:**
The 1D cubic Hermite basis functions for a parameter $t \in [0,1]$ are:
$$ H_0(t) = 2t^3 - 3t^2 + 1 $$
$$ H_1(t) = -2t^3 + 3t^2 $$
$$ H_2(t) = t^3 - 2t^2 + t $$
$$ H_3(t) = t^3 - t^2 $$

The interpolated value $f(u,v,w)$ is computed as:
$$ f(u,v,w) = \sum_{i=0}^1 \sum_{j=0}^1 \sum_{k=0}^1 \left( H_i(u) H_j(v) H_k(w) f_{ijk} + H_i(u) H_j(v) H_k(w) \frac{\partial f}{\partial x}_{ijk} \dots \right) $$
*Note: The full expansion involves 64 terms if mixed derivatives are included, or 32 terms if only first-order partials are used with approximated mixed terms [S1, unofficial].*

**Pseudocode:**
```python
def cubic_hermite_1d(t, y0, y1, dy0, dy1):
    """
    Evaluates 1D cubic Hermite interpolation.
    t: normalized coordinate in [0, 1]
    y0, y1: function values at endpoints
    dy0, dy1: first derivatives at endpoints (scaled by interval length if not unit)
    """
    t2 = t * t
    t3 = t2 * t
    
    h0 = 2 * t3 - 3 * t2 + 1
    h1 = -2 * t3 + 3 * t2
    h2 = t3 - 2 * t2 + t
    h3 = t3 - t2
    
    return h0 * y0 + h1 * y1 + h2 * dy0 + h3 * dy1

def interpolate_hermite_3d(p, grid):
    """
    Interpolates a scalar field with gradients using 3D Hermite interpolation.
    p: query point (x, y, z)
    grid: 3D array of tuples (value, dx, dy, dz)
    """
    # 1. Locate
    ix, iy, iz = floor(p.x), floor(p.y), floor(p.z)
    u, v, w = p.x - ix, p.y - iy, p.z - iz
    
    # 2. Gather 8 corners
    # corners[i][j][k] = (val, dx, dy, dz)
    corners = []
    for i in range(2):
        row = []
        for j in range(2):
            col = []
            for k in range(2):
                # Boundary handling: clamp indices
                idx_x = clamp(ix + i, 0, grid.dim_x - 1)
                idx_y = clamp(iy + j, 0, grid.dim_y - 1)
                idx_z = clamp(iz + k, 0, grid.dim_z - 1)
                col.append(grid[idx_x, idx_y, idx_z])
            row.append(col)
        corners.append(row)
        
    # 3. Evaluate
    # We interpolate along x, then y, then z.
    # Intermediate values after x-interpolation
    temp_yz = []
    for j in range(2):
        row_temp = []
        for k in range(2):
            # Interpolate along x for value and derivatives
            # Note: dy and dz are also interpolated as they vary across x
            val = cubic_hermite_1d(u, 
                                   corners[0][j][k].val, corners[1][j][k].val,
                                   corners[0][j][k].dx, corners[1][j][k].dx)
            dx = cubic_hermite_1d(u,
                                  corners[0][j][k].dx, corners[1][j][k].dx,
                                  corners[0][j][k].dx, corners[1][j][k].dx) # Approximation: dx varies linearly? 
                                  # Source [S1, unofficial] implies storing derivatives. Exact derivative interpolation requires mixed derivatives.
                                  # For simplicity in this implementation without mixed derivatives stored:
            dy = cubic_hermite_1d(u,
                                  corners[0][j][k].dy, corners[1][j][k].dy,
                                  corners[0][j][k].dx, corners[1][j][k].dx) # [G] Approximation of dy variation along x
            dz = cubic_hermite_1d(u,
                                  corners[0][j][k].dz, corners[1][j][k].dz,
                                  corners[0][j][k].dx, corners[1][j][k].dx) # [G] Approximation of dz variation along x
            row_temp.append((val, dx, dy, dz))
        temp_yz.append(row_temp)
        
    # Interpolate along y
    temp_z = []
    for k in range(2):
        val = cubic_hermite_1d(v,
                               temp_yz[0][k].val, temp_yz[1][k].val,
                               temp_yz[0][k].dy, temp_yz[1][k].dy)
        dx = cubic_hermite_1d(v,
                              temp_yz[0][k].dx, temp_yz[1][k].dx,
                              temp_yz[0][k].dy, temp_yz[1][k].dy)
        dy = cubic_hermite_1d(v,
                              temp_yz[0][k].dy, temp_yz[1][k].dy,
                              temp_yz[0][k].dy, temp_yz[1][k].dy)
        dz = cubic_hermite_1d(v,
                              temp_yz[0][k].dz, temp_yz[1][k].dz,
                              temp_yz[0][k].dy, temp_yz[1][k].dy)
        temp_z.append((val, dx, dy, dz))
        
    # Interpolate along z
    final_val = cubic_hermite_1d(w,
                                 temp_z[0].val, temp_z[1].val,
                                 temp_z[0].dz, temp_z[1].dz)
    final_dx = cubic_hermite_1d(w,
                                temp_z[0].dx, temp_z[1].dx,
                                temp_z[0].dz, temp_z[1].dz)
    final_dy = cubic_hermite_1d(w,
                                temp_z[0].dy, temp_z[1].dy,
                                temp_z[0].dz, temp_z[1].dz)
    final_dz = cubic_hermite_1d(w,
                                temp_z[0].dz, temp_z[1].dz,
                                temp_z[0].dz, temp_z[1].dz)
                                
    return final_val, (final_dx, final_dy, final_dz)
```

**Edge Cases:**
*   **Mixed Derivatives:** Exact $C^1$ continuity in 3D requires mixed partial derivatives ($f_{xy}$, etc.). The sources state an approximation akin to Adini's method is derived for these [S1, unofficial].
*   **Boundary Handling:** Out-of-bounds indices are clamped to $[0, D_d-1]$ [S1, unofficial][S2].

## Subtopics

### Floating Scale Surface Reconstruction (FSSR) Integration
In FSSR, Hermite interpolation is used to improve mean and RMS error and visual appearance compared to quadratic methods [S2]. The original FSSR weighting function is not $C^1$-continuous; it is replaced with $w(r) = \frac{1}{12} (r - 3)^{12} (r + 1)^4$ to ensure $C^1$ continuity [S2]. Hermite interpolation methods were implemented in FSSR to leverage this continuity [S2].

## Operating characteristics
*   **Continuity:** Guarantees globally $C^1$-continuous results, superior to $C^0$ bilinear/trilinear methods [S1, unofficial].
*   **Storage:** Storage efficient replacement for normal mapping; does not necessarily require extra storage if surface normals are already part of the discrete field of samples [S1, unofficial].
*   **Performance:** Provides richer visual appearance than lower-order interpolants [S1, unofficial].
*   **Limitations:** Requires storage of derivatives (or approximation thereof) [S1, unofficial].

## Background
The method was proposed to address the $C^0$ limitation of standard bilinear/trilinear filtering in real-time computer graphics [S1, unofficial]. It generalizes to arbitrary orders and dimensions [S1, unofficial]. It is applicable to height field and signed distance field rendering [S1, unofficial]. The approximation for mixed partial derivatives is akin to Adini's method for parametric surface patches [S1, unofficial].
