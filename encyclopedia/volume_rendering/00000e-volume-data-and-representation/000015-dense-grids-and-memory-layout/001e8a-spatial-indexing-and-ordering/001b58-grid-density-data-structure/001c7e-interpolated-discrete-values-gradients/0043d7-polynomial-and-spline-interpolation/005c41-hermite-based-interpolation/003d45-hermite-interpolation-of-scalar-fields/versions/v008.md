# Hermite Interpolation of Scalar Fields

Also called: C1-continuous Hermite Interpolation, Hermite Interpolation

## Overview
Hermite interpolation of scalar fields is a technique for rendering scalar-valued functions, such as height fields and signed distance fields (SDFs), by storing partial derivatives alongside function values and using Hermite interpolation between samples to guarantee a globally $C^1$-continuous result [S1, unofficial]. It differs from standard voxel interpolation [12781-voxel-data-interpolation-and-sampling.md] by explicitly modeling gradient information, allowing the exact normals of the reconstructed surface to be used as shading normals, which provides a storage-efficient replacement for normal mapping with richer visual appearance [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A dense grid tensor $\mathbf{G}$ of shape $(D_x, D_y, D_z, C)$, where $C$ includes the scalar function value and its partial derivatives (e.g., $\partial f/\partial x, \partial f/\partial y, \partial f/\partial z$) [S1, unofficial][S2].
*   **Output:** An interpolated scalar value $f(\mathbf{p})$ and its gradient $\nabla f(\mathbf{p})$ at a query point $\mathbf{p} \in \mathbb{R}^3$.

**Data Structures:**
The grid stores values at integer coordinates. For a 3D field, each voxel stores the function value $f$ and the three partial derivatives $f_x, f_y, f_z$. In 2D height fields, this would be $f, f_x, f_y$.

**Algorithm:**
1.  **Locate Support:** Given query point $\mathbf{p} = (x, y, z)$, compute integer indices $i = \lfloor x \rfloor, j = \lfloor y \rfloor, k = \lfloor z \rfloor$ and fractional coordinates $u = x - i, v = y - j, w = z - k$ where $u, v, w \in [0, 1)$ [S1, unofficial][S2].
2.  **Gather Data:** Retrieve the 8 corner values and their derivatives from the grid. Let $V_{ijk}$ be the value at corner $(i,j,k)$ and $D_{ijk}^x, D_{ijk}^y, D_{ijk}^z$ be the partial derivatives. Boundary conditions (clamping) are applied if indices fall outside $[0, D_d-1]$ [S1, unofficial][S2].
3.  **Approximate Mixed Derivatives (3D):** For 3D fields, mixed partial derivatives ($f_{xy}, f_{xz}, f_{yz}, f_{xyz}$) are required for full cubic Hermite interpolation. These are approximated using a method akin to Adini's method for parametric surface patches [S1, unofficial].
    *   *Note:* The specific formula for Adini's approximation is not provided in the sources [G]. Implementers must derive or source the standard Adini finite difference approximation for mixed derivatives on a grid.
4.  **Basis Evaluation:** Compute the 1D Hermite basis functions for each dimension. For a local coordinate $t \in [0,1]$, the basis functions for value and derivative are:
    $$
    h_{00}(t) = 2t^3 - 3t^2 + 1
    $$
    $$
    h_{10}(t) = t^3 - 2t^2 + t
    $$
    $$
    h_{01}(t) = -2t^3 + 3t^2
    $$
    $$
    h_{11}(t) = t^3 - t^2
    $$
    These are extended to 3D via tensor product.
5.  **Weighted Summation:** Combine the gathered values and derivatives with the basis weights to compute $f(\mathbf{p})$ and $\nabla f(\mathbf{p})$. The gradient $\nabla f(\mathbf{p})$ can be computed analytically from the derivative of the basis functions [S2].

**Pseudocode:**
```python
def hermite_basis(t):
    """Returns (h00, h10, h01, h11) for 1D Hermite interpolation."""
    t2 = t * t
    t3 = t2 * t
    h00 = 2 * t3 - 3 * t2 + 1
    h10 = t3 - 2 * t2 + t
    h01 = -2 * t3 + 3 * t2
    h11 = t3 - t2
    return h00, h10, h01, h11
```

## Subtopics

### Floating Scale Surface Reconstruction (FSSR) Integration
In FSSR, cubic Hermite interpolation improves mean and RMS error as well as visual appearance compared to quadratic methods, although maximum error can remain large [S2]. To ensure $C^1$ continuity, the original FSSR weighting function is replaced with $w(r) = \frac{1}{12} (r - 3)^{12} \cdot (r + 1)^4$ [S2]. Hermite interpolation methods were implemented in FSSR to leverage the analytic gradients computed from the implicit function [S2].

## Operating characteristics
*   **Complexity:** Time complexity is $O(1)$ per query as it involves a fixed number of arithmetic operations on 8 grid corners. Memory complexity is $O(N \cdot C)$ where $N$ is the number of voxels and $C$ is the number of stored channels (value + derivatives).
*   **Performance:** Provides a storage-efficient replacement for normal mapping if surface normals are already part of the discrete field of samples, as it merely requires a different basis to store the same data [S1, unofficial].
*   **Strengths:** Guarantees globally $C^1$-continuous results, enabling the use of exact normals of the reconstructed cubic Hermite surface as shading normals [S1, unofficial].
*   **Limitations:** Requires storage of derivatives. In 3D, full $C^1$ continuity may require approximation of mixed partial derivatives (e.g., Adini's method), which adds complexity [S1, unofficial].

## Background
The technique was proposed to address the $C^0$ approximation limitations of standard bi- or trilinear filtering in real-time computer graphics [S1, unofficial]. It generalizes to arbitrary orders and dimensions and has been demonstrated in height field and signed distance field rendering [S1, unofficial]. It has also been integrated into surface reconstruction algorithms like Poisson Surface Reconstruction (PSR) and Floating Scale Surface Reconstruction (FSSR) to analyze the impact of Hermite interpolation on real surface reconstruction [S2].
