# NURBS Spline Representation for Measurement Coordinates

Also called: NURBS Spline Representation, NURBS surface for measurement coordinates, NURBS surface optimization for measurement coordinates, Rational B-spline optimization for view angles

## Overview
This method represents uncertain measurement coordinates (such as view angles and detector locations) as a NURBS surface, where control points and weights are optimized jointly with volume reconstruction [S1, unofficial]. It differs from standard grid interpolation by learning the geometric parameters of the coordinate system itself, rather than interpolating values within a fixed grid [S1, unofficial].

## How it works
**Inputs:**
*   Measurement coordinates $\mathbf{x} = [\theta', t']^T$ (e.g., view angle, detector location).
*   Number of segments $J, K$ per dimension.
*   Degrees $d_\Theta, d_T \in \mathbb{Z}^+$.
*   Learnable weights $w_{u,v}$ and control points $Q_{u,v}$ (implied by "learnable control point vectors" in sources).

**Outputs:**
*   Rational basis function values $b_{j,k}(\mathbf{x})$ for the NURBS surface.

**Data Structures:**
*   **Knot Vector:** A 1D array of size $N + d + 1$ for a dimension with $N$ segments and degree $d$.
    *   Indices $0$ to $d$: Value $0.0$.
    *   Indices $d+1$ to $N$: Uniformly spaced between $0.0$ and $1.0$.
    *   Indices $N+1$ to $N+d$: Value $1.0$.
*   **Basis Functions:** Computed via Cox-de Boor recursion.

**Steps:**
1.  Construct knot vectors for each measurement coordinate dimension (e.g., angle and detector location) using the formula above [S1, unofficial].
2.  Compute 1D B-spline basis functions $Q_{u,d_\Theta}(\theta')$ and $Q_{v,d_T}(t')$ for the given coordinates using Cox-de Boor recursion [S1, unofficial].
3.  Form the tensor product of the 1D NURBS curves to create the D-dimensional surface [S1, unofficial].
4.  Compute the rational basis function using the weighted sum of basis functions divided by the sum of weights times basis functions [S1, unofficial].

**Formulas:**
The rational basis function is defined as [S1, unofficial]:
$$ b_{j,k}([\theta', t']^T) = \frac{\sum_{u=0}^{J-1} \sum_{v=0}^{K-1} w_{u,v} Q_{u,d_\Theta}(\theta') Q_{v,d_T}(t')}{\sum_{u=0}^{J-1} \sum_{v=0}^{K-1} w_{u,v} Q_{u,d_\Theta}(\theta') Q_{v,d_T}(t')} $$
Note: The source text for formula (16) in the numerator lists $w_{u,v}$ but the denominator in the provided text snippet for (16) appears to lack $w_{u,v}$ in the summation description, however, the standard NURBS definition and the context of "Rational basis function" implies weights are in both. The provided text for (16) actually writes:
$$ b_{j,k} ([\theta', t']^T) = \frac{\sum_{u=0}^{J-1} \sum_{v=0}^{K-1} w_{u,v} Q_{u,d_\Theta}(\theta') Q_{v,d_T}(t')}{\sum_{u=0}^{J-1} \sum_{v=0}^{K-1} Q_{u,d_\Theta}(\theta') Q_{v,d_T}(t')} $$
This matches the standard NURBS definition where the denominator is the weight sum.

The B-spline basis function $Q_{u,d}(k)$ is computed using Cox-de Boor recursion [S1, unofficial]:
$$ Q_{u,0}(k) = \begin{cases} 1 & \text{if } k_u \le k < k_{u+1} \\ 0 & \text{otherwise} \end{cases} $$
$$ Q_{u,d}(k) = \frac{k - k_u}{k_{u+d} - k_u} Q_{u,d-1}(k) + \frac{k_{u+d+1} - k}{k_{u+d+1} - k_{u+1}} Q_{u+1,d-1}(k) $$
where $k_u$ is the $u$-th element of the knot vector.

**Parameters:**
*   $d_\Theta, d_T$: Degrees of the spline.
*   $J, K$: Number of segments.

**Edge cases and pitfalls:**
*   **Zero Denominators:** In the Cox-de Boor recursion, if any denominator ($k_{u+d} - k_u$ or $k_{u+d+1} - k_{u+1}$) is zero, the entire term is set to zero [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def construct_knot_vector(num_segments: int, degree: int) -> np.ndarray:
    """
    Constructs a knot vector for NURBS.
    Elements 0..degree-1 are 0.
    Elements degree..num_segments-1 are uniformly spaced in (0,1).
    Elements num_segments..num_segments+degree-1 are 1.
    """
    n_knots = num_segments + degree + 1
    knots = np.zeros(n_knots)
    
    # First part: 0
    # knots[0:degree+1] are 0 (indices 0 to degree)
    # The source says: "zero when 0 <= u < d + 1"
    # This corresponds to indices 0 to d (inclusive), count is d+1.
    
    # Middle part: Uniformly spaced between 0 and 1
    # Source: "uniformly spaced between zero and one when d + 1 <= u <= J"
    # Indices d+1 to J. Count is J - (d+1) + 1 = J - d.
    
    # Last part: 1
    # Source: "one when J < u <= J + d"
    # Indices J+1 to J+d. Count is d.
    
    # Total elements: (d+1) + (J-d) + d = J + d + 1. Correct.
    
    # Implementation
    knots[:degree + 1] = 0.0
    
    # Uniform spacing for the middle section
    # We need J - d points between 0 and 1.
    # Note: The knot vector must be non-decreasing.
    # Standard clamped uniform knot vector usually includes endpoints.
    # The description implies the internal knots are strictly inside (0,1) or on boundaries?
    # "uniformly spaced between zero and one" usually implies [0, 1] range.
    # Let's use linspace excluding the already set endpoints if necessary, 
    # but the indices are distinct.
    
    mid_count = num_segments - degree
    if mid_count > 0:
        # Generate mid points. 
        # To ensure continuity with 0 and 1, we can use linspace(0, 1, mid_count + 2)[1:-1] 
        # or just linspace(0, 1, mid_count) if the boundaries are handled by the 0/1 arrays.
        # However, standard clamped uniform knots are: [0...0, t1...tN, 1...1].
        # The internal knots are usually (i / (N+1)) or similar.
        # The source says "uniformly spaced between zero and one".
        # Let's assume standard uniform internal knots.
        knots[degree + 1 : degree + 1 + mid_count] = np.linspace(0.0, 1.0, mid_count + 2)[1:-1]
        
    knots[degree + 1 + mid_count:] = 1.0
    
    return knots

def cox_de_boor(u: int, degree: int, k: float, knots: np.ndarray) -> float:
    """
    Computes the B-spline basis function Q_{u, degree}(k).
    """
    if degree == 0:
        # Q_{u,0}(k) = 1 if k_u <= k < k_{u+1}
        # Note: Source uses <= and <.
        if knots[u] <= k < knots[u+1]:
            return 1.0
        else:
            return 0.0
    
    # Recursive step
    # Term 1
    denom1 = knots[u + degree] - knots[u]
    term1 = 0.0
    if denom1 != 0:
        term1 = ((k - knots[u]) / denom1) * cox_de_boor(u, degree - 1, k, knots)
    else:
        # Pitfall: denominator is zero, term is zero
        term1 = 0.0
        
    # Term 2
    denom2 = knots[u + degree + 1] - knots[u + 1]
    term2 = 0.0
    if denom2 != 0:
        term2 = ((knots[u + degree + 1] - k) / denom2) * cox_de_boor(u + 1, degree - 1, k, knots)
    else:
        # Pitfall: denominator is zero, term is zero
        term2 = 0.0
        
    return term1 + term2

def nurbs_basis(theta: float, t: float, knots_theta: np.ndarray, knots_t: np.ndarray, 
                degree_theta: int, degree_t: int, weights: np.ndarray, 
                num_segments_theta: int, num_segments_t: int) -> float:
    """
    Computes the rational NURBS basis function value.
    """
    numerator = 0.0
    denominator = 0.0
    
    for u in range(num_segments_theta):
        for v in range(num_segments_t):
            # Compute B-spline basis functions
            q_u = cox_de_boor(u, degree_theta, theta, knots_theta)
            q_v = cox_de_boor(v, degree_t, t, knots_t)
            
            w = weights[u, v]
            
            numerator += w * q_u * q_v
            denominator += w * q_u * q_v # Standard NURBS definition
            
    if denominator == 0:
        return 0.0 # Handle division by zero
        
    return numerator / denominator
```

## Background
This method originates from work on differentiable uncalibrated imaging, specifically addressing view angle uncertainty in CT reconstruction [S1, unofficial]. It was implemented by modifying and extending the PyTorch source code from the NURBS-Diff module [S1, unofficial].
