# Voxel Data Interpolation and Sampling

Also called: getNextIntersectColor, getNextIntersectionGradient, getNextIntersectionScalar

## Overview
This method retrieves scalar values, gradients, and transformed colors at arbitrary 3D positions within a volume grid, supporting configurable interpolation and transfer function modes [S1, unofficial]. It differs from its siblings by explicitly exposing the gradient magnitude for transfer function input and providing a specific indexing scheme for dense grid storage, whereas [Grid Cell Collection via Corner Indices](1518-grid-cell-collection-via-corner-indices.md) focuses on geometric cell identification and [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) relies on higher-order continuity [S1, unofficial].

## How it works
**Inputs:**
- Query point $\mathbf{p} = (x, y, z)$ in voxel coordinates.
- Volume dimensions: $XDIM, YDIM, ZDIM$.
- Interpolation mode $INTER\_MODE \in \{1, 2\}$ (1: Trilinear, 2: Nearest Neighbor).
- Transfer function mode $TRN\_MODE \in \{1, 2\}$ (1: Scalar-only, 2: Scalar + Gradient Magnitude).

**Outputs:**
- Transformed color/opacity tuple (typically 4 components).

**Data Structures:**
The volume data is stored in two vectors:
1.  `scalars`: `std::vector<float>` containing scalar values.
2.  `gradients`: `std::vector<glm::vec3>` containing gradient vectors.

The index for a voxel at integer coordinates $(x, y, z)$ is calculated as:
$$ idx = x + (y \cdot XDIM) + (z \cdot XDIM \cdot YDIM) $$

**Steps:**

1.  **Boundary Check:**
    If $x < 0$ or $x \ge XDIM$ or $y < 0$ or $y \ge YDIM$ or $z < 0$ or $z \ge ZDIM$, return $(0, 0, 0, 0)$ [S1, unofficial].

2.  **Data Retrieval:**
    -   Retrieve scalar value $s$ at $\mathbf{p}$ using $INTER\_MODE$.
        -   If $INTER\_MODE = 2$ (Nearest Neighbor): $s = \text{scalars}[idx]$.
        -   If $INTER\_MODE = 1$ (Trilinear): Interpolate using the 8 nearest neighbors [S1, unofficial].
    -   Retrieve gradient vector $\mathbf{g}$ at $\mathbf{p}$ using $INTER\_MODE$.
        -   If $INTER\_MODE = 2$: $\mathbf{g} = \text{gradients}[idx]$.
        -   If $INTER\_MODE = 1$: Interpolate $\mathbf{g}$ using the 8 nearest neighbors [S1, unofficial].

3.  **Transfer Function Input Preparation:**
    -   If $TRN\_MODE = 1$: Pass $(s, s)$ to the transfer function transformer.
    -   If $TRN\_MODE = 2$:
        -   Compute gradient magnitude $m = \|\mathbf{g}\| = \sqrt{g_x^2 + g_y^2 + g_z^2}$.
        -   Clamp $m$ to $[0, 1]$.
        -   Scale by 256: $m' = m \cdot 256$.
        -   Pass $(s, m')$ to the transfer function transformer [S1, unofficial].

4.  **Transformation:**
    Apply the transfer function to the prepared inputs to obtain the final color/opacity result [S1, unofficial].

**Pseudocode:**

```python
def get_voxel_data(p: Vector3, scalars: List[float], gradients: List[Vector3], 
                   XDIM: int, YDIM: int, ZDIM: int, 
                   INTER_MODE: int, TRN_MODE: int) -> Vector4:
    x, y, z = p.x, p.y, p.z
    
    # 1. Boundary Check
    if x < 0 or x >= XDIM or y < 0 or y >= YDIM or z < 0 or z >= ZDIM:
        return Vector4(0, 0, 0, 0)
    
    # 2. Data Retrieval
    # Note: Trilinear interpolation logic is not fully detailed in sources [S1, unofficial]
    # Assuming helper functions get_scalar_trilinear and get_gradient_trilinear exist
    if INTER_MODE == 2: # Nearest Neighbor
        idx = int(x) + int(y) * XDIM + int(z) * XDIM * YDIM
        s = scalars[idx]
        g = gradients[idx]
    else: # Trilinear
        s = get_scalar_trilinear(p, scalars, XDIM, YDIM, ZDIM)
        g = get_gradient_trilinear(p, gradients, XDIM, YDIM, ZDIM)
        
    # 3. Transfer Function Input Preparation
    if TRN_MODE == 1:
        input1 = s
        input2 = s
    else: # TRN_MODE == 2
        input1 = s
        mag = sqrt(g.x**2 + g.y**2 + g.z**2)
        mag = max(0.0, min(1.0, mag)) # Clamp to [0, 1]
        input2 = mag * 256.0
        
    # 4. Transformation
    # Assuming apply_transfer_function is defined elsewhere or is a lookup
    return apply_transfer_function(input1, input2)
```

**Parameters:**
-   $INTER\_MODE$: 1 for trilinear, 2 for nearest neighbor [S1, unofficial].
-   $TRN\_MODE$: 1 for (Voxel Value, Voxel Value), 2 for (Voxel Value, Gradient Magnitude) [S1, unofficial].

**Pitfalls:**
-   The source code comments mention trilinear interpolation, but the implementation note states "currently do the nearest neighbour only" [S1, unofficial]. Implementers must ensure the trilinear logic is correctly implemented if $INTER\_MODE=1$ is used.
-   Gradient magnitude clamping and scaling are specific to this implementation [S1, unofficial].

## Operating characteristics
-   **Time Complexity:** $O(1)$ for nearest neighbor. $O(1)$ for trilinear (constant number of neighbors and operations).
-   **Memory Complexity:** $O(N)$ where $N$ is the number of voxels, storing both scalars and gradients.
-   **Strengths:** Simple indexing, explicit gradient access for transfer functions.
-   **Limitations:** Nearest neighbor interpolation is used by default in the reference implementation, leading to blocky artifacts. Trilinear implementation is noted as incomplete in the source [S1, unofficial].

## Background
This method originates from a student project for CSE-333 Computer Graphics (2020) [S1, unofficial]. It was developed as part of a volume ray casting implementation using a 1D transfer function and average rendering technique (X-Ray) [S1, unofficial].
