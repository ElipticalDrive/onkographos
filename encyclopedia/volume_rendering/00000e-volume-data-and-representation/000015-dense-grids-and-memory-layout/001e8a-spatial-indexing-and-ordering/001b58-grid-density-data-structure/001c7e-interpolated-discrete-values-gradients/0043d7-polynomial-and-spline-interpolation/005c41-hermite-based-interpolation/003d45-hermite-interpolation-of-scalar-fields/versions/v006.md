# Hermite Interpolation of Scalar Fields

Also called: C1-continuous Hermite Interpolation, Hermite Interpolation

## Overview
Hermite interpolation of scalar fields renders scalar-valued functions (such as height fields or signed distance fields) by storing partial derivatives alongside function values on a regular grid, using these derivatives to construct a globally $C^1$-continuous interpolation between samples [S1, unofficial]. Unlike standard trilinear interpolation which yields only $C^0$ continuity, this method guarantees smooth gradients, allowing the exact normals of the reconstructed cubic Hermite surface to be used as shading normals, providing a storage-efficient replacement for normal mapping when normals are already derived from the field [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A dense grid tensor $\mathbf{G}$ of shape $(D_x, D_y, D_z, C)$, where $C \ge 4$ to store the scalar value and its three partial derivatives ($\partial f/\partial x, \partial f/\partial y, \partial f/\partial z$) at each vertex [S1, unofficial]. A query point $\mathbf{p} \in \mathbb{R}^3$.
*   **Output:** The interpolated scalar value $f(\mathbf{p})$ and optionally the gradient $\nabla f(\mathbf{p})$ for shading.

**Data Structures:**
The grid stores 4 values per voxel: $f$ (value), $f_x$ (x-derivative), $f_y$ (y-derivative), $f_z$ (z-derivative). Indices are clamped to $[0, D_d-1]$ for boundary conditions [S1, unofficial][S2].

**Steps:**
1.  **Locate Cell:** Determine the integer indices $(i, j, k)$ such that $\mathbf{p}$ lies within the cell $[i, i+1] \times [j, j+1] \times [k, k+1]$. Compute local coordinates $(u, v, w) = \mathbf{p} - (i, j, k) \in [0, 1]^3$.
2.  **Gather Data:** Retrieve the 8 corner values and their derivatives from the grid. For corner $(l, m, n)$ where $l,m,n \in \{0,1\}$, let the data be $\mathbf{d}_{l,m,n} = [f, f_x, f_y, f_z]_{i+l, j+m, k+n}$.
3.  **Compute Basis Functions:** Calculate the 1D Hermite basis functions for each axis. For a coordinate $t \in [0,1]$, the basis functions are:
    $$ H_0(t) = 2t^3 - 3t^2 + 1 $$
    $$ H_1(t) = t^3 - 2t^2 + t $$
    $$ H_2(t) = -2t^3 + 3t^2 $$
    $$ H_3(t) = t^3 - t^2 $$
    These correspond to value, x-derivative, y-derivative, and z-derivative contributions respectively in the tensor product expansion.
4.  **Interpolate Value:** Compute the scalar value using the tensor product of the basis functions and the gathered data. The value $f(\mathbf{p})$ is:
    $$ f(\mathbf{p}) = \sum_{l=0}^{1} \sum_{m=0}^{1} \sum_{n=0}^{1} \left( H_{0,l}(u) H_{0,m}(v) H_{0,n}(w) f_{l,m,n} + H_{1,l}(u) H_{0,m}(v) H_{0,n}(w) f_{x,l,m,n} + H_{0,l}(u) H_{1,m}(v) H_{0,n}(w) f_{y,l,m,n} + H_{0,l}(u) H_{0,m}(v) H_{1,n}(w) f_{z,l,m,n} \right) $$
    Note: The derivative terms are scaled by the cell size if the grid is not unit-spaced, but assuming unit spacing, the derivatives are used directly [S1, unofficial].
5.  **Compute Gradient (Shading Normal):** To obtain the exact normal, compute the partial derivatives of the interpolant. The x-derivative $\frac{\partial f}{\partial x}$ at $\mathbf{p}$ is:
    $$ \frac{\partial f}{\partial x} = \sum_{l=0}^{1} \sum_{m=0}^{1} \sum_{n=0}^{1} \left( H'_{0,l}(u) H_{0,m}(v) H_{0,n}(w) f_{l,m,n} + H_{0,l}(u) H_{0,m}(v) H_{0,n}(w) f_{x,l,m,n} + H'_{1,l}(u) H_{0,m}(v) H_{0,n}(w) f_{x,l,m,n} + \dots \right) $$
    More simply, the gradient vector $\nabla f$ can be computed by applying the same Hermite logic to the derivative components or by differentiating the basis functions. The exact normals of the reconstructed surface are used as shading normals [S1, unofficial].
6.  **Mixed Derivatives (3D Extension):** For full $C^1$ continuity in 3D, mixed partial derivatives ($f_{xy}, f_{xz}, f_{yz}, f_{xyz}$) are required. The source derives an approximation for these akin to Adini's method for parametric surface patches, though the exact formula is not provided in the abstract [S1, unofficial]. If mixed derivatives are not stored, the interpolation is $C^1$ along axes but may have discontinuities in mixed directions.

**Pseudocode:**
```python
def hermite_basis(t):
    # Returns [H0, H1, H2, H3] for value, dx, dy, dz contributions
    t2 = t * t
    t3 = t2 * t
    h0 = 2 * t3 - 3 * t2 + 1
    h1 = t3 - 2 * t2 + t
    h2 = -2 * t3 + 3 * t2
    h3 = t3 - t2
    return h0, h1, h2, h3

def hermite_interpolate(grid, p):
    # grid: 4D array (Dx, Dy, Dz, 4) where 4th dim is [f, fx, fy, fz]
    # p: query point (x, y, z)
    
    # 1. Locate cell
    i, j, k = floor(p)
    u, v, w = p - (i, j, k)
    
    # 2. Gather 8 corners
    # corners[l][m][n] is the 4-vector [f, fx, fy, fz]
    corners = []
    for l in [0, 1]:
        row = []
        for m in [0, 1]:
            col = []
            for n in [0, 1]:
                # Clamp indices to grid bounds
                idx = clamp(i+l, 0, grid.shape[0]-1), clamp(j+m, 0, grid.shape[1]-1), clamp(k+n, 0, grid.shape[2]-1)
                col.append(grid[idx[0], idx[1], idx[2]])
            row.append(col)
        corners.append(row)
        
    # 3. Compute basis functions
    bu = hermite_basis(u)
    bv = hermite_basis(v)
    bw = hermite_basis(w)
    
    # 4. Interpolate value
    # f(p) = sum_{l,m,n} ( B_l(u)*B_m(v)*B_n(w) * data )
    # Data is 4D: [f, fx, fy, fz]
    # We need to map basis functions to data components.
    # For x-derivative term: basis is H1(u) for x, H0(v), H0(w)
    # For y-derivative term: basis is H0(u), H1(v), H0(w)
    # For z-derivative term: basis is H0(u), H0(v), H1(w)
    
    val = 0.0
    for l in [0, 1]:
        for m in [0, 1]:
            for n in [0, 1]:
                c = corners[l][m][n]
                # Contribution from value f
                val += bu[0] * bv[0] * bw[0] * c[0]
                # Contribution from fx
                val += bu[1] * bv[0] * bw[0] * c[1]
                # Contribution from fy
                val += bu[0] * bv[1] * bw[0] * c[2]
                # Contribution from fz
                val += bu[0] * bv[0] * bw[1] * c[3]
                
    return val
```

## Subtopics

### Floating Scale Surface Reconstruction (FSSR) Integration
In Floating Scale Surface Reconstruction (FSSR), Hermite interpolation is used to improve mean and RMS error and visual appearance compared to quadratic methods [S2]. Because the original FSSR weighting function is not $C^1$-continuous, it is replaced with a Hermite-compatible weighting function $w(r) = \frac{1}{12} (r - 3)^{12} (r + 1)^4$ to ensure $C^1$ continuity [S2].

## Operating characteristics
*   **Complexity:** Time complexity is $O(1)$ per query, involving a fixed number of arithmetic operations (8 corners, 4 derivatives each). Memory overhead is 4x that of a standard scalar field (storing derivatives).
*   **Performance:** Provides richer visual appearance than trilinear interpolation without the storage cost of explicit normal maps, as normals are derived from the field's gradients [S1, unofficial].
*   **Limitations:** Requires the computation or storage of partial derivatives. In 3D, achieving full $C^1$ continuity requires mixed partial derivatives, which are not naturally stored in standard scalar fields and require approximation (e.g., Adini's method) [S1, unofficial].

## Background
The method was proposed to address the $C^0$ discontinuity of standard trilinear filtering in real-time computer graphics, specifically for rendering height fields and signed distance fields [S1, unofficial]. It generalizes Hermite interpolation to arbitrary orders and dimensions [S1, unofficial]. It has been applied in surface reconstruction algorithms like Poisson Surface Reconstruction (PSR) and Floating Scale Surface Reconstruction (FSSR) to analyze the impact of Hermite interpolation on real surface reconstruction [S2].
