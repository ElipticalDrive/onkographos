# Voxel Data Interpolation and Sampling

Also called: getNextIntersectColor, getNextIntersectionGradient, getNextIntersectionScalar

## Overview
A method to retrieve scalar values, gradients, and transformed colors at arbitrary 3D positions within a volume grid, supporting different interpolation modes and transformation modes [S1, unofficial]. It differs from its siblings by explicitly coupling the interpolation of raw voxel data with a configurable transfer function input mode (scalar-only vs. scalar-plus-gradient magnitude) to drive color and opacity calculation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: 3D position $(x, y, z)$ in voxel space.
- Input: Grid dimensions $XDIM, YDIM, ZDIM$.
- Input: Volume data arrays: `scalars` (vector of floats) and `gradients` (vector of `glm::vec3`).
- Input: `INTER_MODE` (interpolation mode).
- Input: `TRN_MODE` (transfer function input mode).
- Output: Transformed color/alpha tuple (e.g., `Color` or `vec4`).

**Data Structures:**
The volume data is stored in two vectors:
1. `scalars`: `std::vector<float>` containing scalar values for each voxel.
2. `gradients`: `std::vector<glm::vec3>` containing 3D gradient vectors for each voxel.

The index for a voxel at integer coordinates $(x, y, z)$ is calculated as:
$$ index = x + (y \cdot XDIM) + (z \cdot XDIM \cdot YDIM) $$

**Parameters:**
- `INTER_MODE`: Controls interpolation.
  - `1`: Trilinear interpolation.
  - `2`: Nearest neighbor.
- `TRN_MODE`: Controls transfer function input.
  - `1`: Pass `(Voxel Value, Voxel Value)` to the transformer.
  - `2`: Pass `(Voxel Value, Gradient Magnitude)` to the transformer.

**Steps:**
1. **Boundary Check**: Check if the integer coordinates $(x, y, z)$ are within bounds $[0, XDIM-1] \times [0, YDIM-1] \times [0, ZDIM-1]$. If not, return $(0, 0, 0, 0)$ [S1, unofficial].
2. **Interpolation**: Retrieve the scalar value $V$ and gradient vector $\mathbf{G}$ at $(x, y, z)$ based on `INTER_MODE`.
   - If `INTER_MODE == 2` (Nearest Neighbor):
     - $V = scalars[index]$
     - $\mathbf{G} = gradients[index]$
   - If `INTER_MODE == 1` (Trilinear):
     - Perform trilinear interpolation using the 8 neighboring voxels. *Note: The source code comments mention trilinear interpolation, but the implementation note states "currently do the nearest neighbour only (needs to implement voxel intersection)" [S1, unofficial]. The logic below assumes nearest neighbor as per the explicit implementation note, but the structure supports trilinear via `INTER_MODE`.*
3. **Gradient Magnitude Calculation**:
   - Compute the magnitude of the gradient: $|\mathbf{G}| = \sqrt{G_x^2 + G_y^2 + G_z^2}$.
   - Clamp the magnitude to $[0, 1]$: $|\mathbf{G}|_{clamped} = \min(1.0, \max(0.0, |\mathbf{G}|))$.
   - Scale by 256: $M = |\mathbf{G}|_{clamped} \cdot 256$.
4. **Transfer Function Input Preparation**:
   - If `TRN_MODE == 1`:
     - Input to transformer: $(V, V)$.
   - If `TRN_MODE == 2`:
     - Input to transformer: $(V, M)$.
5. **Transformation**:
   - Pass the prepared inputs to the 1D transfer function transformer to obtain the final color and alpha. *Note: The source mentions using a 1D transfer function and needing to implement gradient-based opacity [S1, unofficial].*

**Pseudocode:**
```python
def get_voxel_color(x, y, z, scalars, gradients, xd, yd, zd, inter_mode, trn_mode):
    # 1. Boundary Check
    if not (0 <= x < xd and 0 <= y < yd and 0 <= z < zd):
        return (0.0, 0.0, 0.0, 0.0)

    # 2. Index Calculation
    index = x + (y * xd) + (z * xd * yd)

    # 3. Interpolation (Nearest Neighbor as per implementation note)
    # Note: Trilinear interpolation logic is not implemented in the source snippet
    scalar_value = scalars[index]
    gradient_vec = gradients[index]

    # 4. Gradient Magnitude Calculation
    grad_mag = sqrt(gradient_vec.x**2 + gradient_vec.y**2 + gradient_vec.z**2)
    grad_mag_clamped = min(1.0, max(0.0, grad_mag))
    scaled_grad_mag = grad_mag_clamped * 256.0

    # 5. Transfer Function Input
    if trn_mode == 1:
        tf_input_1 = scalar_value
        tf_input_2 = scalar_value
    elif trn_mode == 2:
        tf_input_1 = scalar_value
        tf_input_2 = scaled_grad_mag
    else:
        # Default or error case, assuming mode 1 if undefined
        tf_input_1 = scalar_value
        tf_input_2 = scalar_value

    # 6. Transformation
    # The source mentions a 1D transfer function transformer.
    # The exact implementation of the transformer is not provided in the snippet.
    # [G] Assuming a generic transform function that takes two floats and returns a Color/Alpha tuple.
    color = transform_function(tf_input_1, tf_input_2)

    return color
```

**Edge Cases and Pitfalls:**
- **Precision**: Gradient magnitude clamping and scaling may introduce quantization artifacts if not handled carefully.
- **Boundaries**: Out-of-bounds access must be handled to avoid memory errors.
- **Interpolation Implementation**: The source code explicitly states that only nearest neighbor is implemented, despite `INTER_MODE` supporting trilinear. Implementers must add trilinear interpolation logic if `INTER_MODE == 1` is required [S1, unofficial].
- **Gradient-Based Opacity**: The source notes that gradient-based opacity needs to be implemented, implying the current transfer function might not fully utilize the gradient magnitude for opacity [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(1)$ for nearest neighbor. $O(1)$ for trilinear (constant number of operations).
- **Memory Complexity**: $O(N)$ for storing scalars and gradients, where $N$ is the number of voxels.
- **Performance**: The method is efficient for real-time rendering as it involves simple arithmetic and array lookups. However, the lack of implemented trilinear interpolation in the source may affect visual quality.
- **Strengths**: Simple to implement, supports both scalar and gradient-based transfer functions.
- **Limitations**: Limited to nearest neighbor in the provided implementation; gradient-based opacity is not fully implemented.

## Background
This method is part of a volume ray casting implementation for a computer graphics course (CSE-333) at an unspecified institution, as indicated by the GitHub repository name [S1, unofficial]. It is designed to work with CT scan data (`volume_file.ctscan`) and uses a 1D transfer function for color and alpha mapping. The implementation is noted as unofficial and incomplete, with several features marked as needing implementation (e.g., voxel intersection, gradient-based opacity) [S1, unofficial].
