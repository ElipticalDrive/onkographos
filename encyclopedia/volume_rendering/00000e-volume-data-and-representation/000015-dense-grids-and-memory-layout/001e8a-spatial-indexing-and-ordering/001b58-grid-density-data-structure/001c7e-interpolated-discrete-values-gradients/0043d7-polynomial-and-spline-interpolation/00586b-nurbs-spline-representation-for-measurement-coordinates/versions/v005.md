# NURBS Spline Representation for Measurement Coordinates

Also called: NURBS Spline Representation, NURBS surface for measurement coordinates, NURBS surface optimization for measurement coordinates, Rational B-spline optimization for view angles

## Overview
This method represents uncertain measurement coordinates (such as view angles or detector locations) as a NURBS surface whose control points and weights are optimized alongside the volume reconstruction [S1, unofficial]. It solves the problem of inaccurate assumed measurement parameters by learning a continuous, differentiable mapping from normalized indices to physical coordinates [S1, unofficial]. It differs from standard interpolation methods by treating the coordinate mapping itself as a learnable parameter set, rather than a fixed geometric construct.

## How it works
**Inputs:**
*   Normalized measurement coordinates $\theta' \in [0, 1]$ and $t' \in [0, 1]$ representing view angle and detector location dimensions respectively.
*   Degrees $d_\Theta, d_T \in \mathbb{Z}^+$ for each dimension.
*   Number of segments $J$ (view angle) and $K$ (detector location).
*   Learnable control points $Q_{u,v}$ (implied by tensor product structure).
*   Learnable weights $w_{u,v}$.

**Outputs:**
*   Rational basis function values $b_{j,k}([\theta', t']^T)$ used to compute the optimized measurement coordinate.

**Data Structures:**
*   **Knot Vector:** A 1D array of size $N + d + 1$ for a dimension with $N$ segments and degree $d$.
    *   Elements $0$ to $d$: $0$.
    *   Elements $d+1$ to $N$: Uniformly spaced between $0$ and $1$.
    *   Elements $N+1$ to $N+d$: $1$.
*   **Control Points:** A grid of vectors $Q_{u,v}$ of size $J \times K$.
*   **Weights:** A grid of scalars $w_{u,v}$ of size $J \times K$.

**Steps:**
1.  **Construct Knot Vectors:** Create knot vectors $U$ for $\theta'$ and $V$ for $t'$ using the formula above.
2.  **Compute B-spline Basis Functions:** For each dimension, compute the 1D B-spline basis functions $Q_{u, d_\Theta}(\theta')$ and $Q_{v, d_T}(t')$ using the Cox-de Boor recursion.
3.  **Evaluate Rational Basis:** Compute the 2D rational basis function $b_{j,k}$ using the tensor product of the 1D bases and the learnable weights.
4.  **Optimize:** Update control points and weights via gradient descent to minimize measurement error.

**Formulas:**
The rational basis function is defined as [S1, unofficial]:
$$
b_{j,k}([\theta', t']^T) = \frac{\sum_{u=0}^{J-1} \sum_{v=0}^{K-1} w_{u,v} Q_{u,d_\Theta}(\theta') Q_{v,d_T}(t')}{\sum_{u=0}^{J-1} \sum_{v=0}^{K-1} Q_{u,d_\Theta}(\theta') Q_{v,d_T}(t')}
$$
where $Q_{u,d}(\cdot)$ is the $u$-th B-spline basis function of degree $d$.

The B-spline basis functions are computed via Cox-de Boor recursion [S1, unofficial]:
$$
Q_{u,0}(k) = \begin{cases} 
1 & \text{if } k_u \le k < k_{u+1} \\
0 & \text{otherwise}
\end{cases}
$$
$$
Q_{u,d}(k) = \frac{k - k_u}{k_{u+d} - k_u} Q_{u,d-1}(k) + \frac{k_{u+d+1} - k}{k_{u+d+1} - k_{u+1}} Q_{u+1,d-1}(k)
$$
Note: If any denominator in the recursion is zero, the corresponding term is set to zero [S1, unofficial].

**Parameters:**
*   $d_\Theta, d_T$: Degrees of the spline. Typical values are not specified in the source, but $d=3$ is common in practice [G].
*   $J, K$: Number of segments. In the cited example, $J=120$ for 120 view angles [S1, unofficial].

**Edge Cases:**
*   **Zero Denominator:** In the Cox-de Boor recursion, if $k_{u+d} - k_u = 0$ or $k_{u+d+1} - k_{u+1} = 0$, the term is zero [S1, unofficial].
*   **Boundary Conditions:** The knot vector construction ensures clamping behavior at the boundaries (0 and 1) [S1, unofficial].

**Pseudocode:**

```python
def cox_de_boor(u, k, degree, knots):
    """
    Computes the B-spline basis function Q_{u, degree}(k).
    k is the parameter value (e.g., theta_prime).
    """
    if degree == 0:
        # Q_{u,0}(k) = 1 if knots[u] <= k < knots[u+1]
        # Note: Source uses <= and <.
        if knots[u] <= k < knots[u+1]:
            return 1.0
        else:
            return 0.0
    
    # Recursive step
    term1 = 0.0
    denom1 = knots[u + degree] - knots[u]
    if denom1 != 0:
        term1 = ((k - knots[u]) / denom1) * cox_de_boor(u, k, degree - 1, knots)
    else:
        term1 = 0.0
        
    term2 = 0.0
    denom2 = knots[u + degree + 1] - knots[u + 1]
    if denom2 != 0:
        term2 = ((knots[u + degree + 1] - k) / denom2) * cox_de_boor(u + 1, k, degree - 1, knots)
    else:
        term2 = 0.0
        
    return term1 + term2

def evaluate_nurbs_surface(theta_prime, t_prime, J, K, d_theta, d_t, knots_theta, knots_t, weights, control_points):
    """
    Evaluates the NURBS surface for measurement coordinates.
    """
    # Compute 1D basis functions for theta
    basis_theta = []
    for u in range(J):
        basis_theta.append(cox_de_boor(u, theta_prime, d_theta, knots_theta))
        
    # Compute 1D basis functions for t
    basis_t = []
    for v in range(K):
        basis_t.append(cox_de_boor(v, t_prime, d_t, knots_t))
        
    # Compute numerator and denominator
    numerator = 0.0
    denominator = 0.0
    
    for u in range(J):
        for v in range(K):
            # Tensor product of basis functions
            basis_val = basis_theta[u] * basis_t[v]
            
            # Get control point Q_{u,v} (assumed to be a vector or scalar depending on context)
            # For measurement coordinates, Q is likely the physical coordinate value.
            q_val = control_points[u][v]
            w_val = weights[u][v]
            
            numerator += w_val * q_val * basis_val
            denominator += basis_val
            
    if denominator == 0:
        return 0.0 # Or handle as error
        
    return numerator / denominator
```

## Operating characteristics
*   **Time Complexity:** Evaluation is $O(J \cdot K)$ for the basis function computation and summation, where $J$ and $K$ are the number of segments. This is generally slower than linear interpolation but faster than high-degree polynomial interpolation for large grids.
*   **Memory Complexity:** $O(J \cdot K)$ for storing control points and weights.
*   **Strengths:** Differentiable, allowing end-to-end optimization of measurement parameters. Handles uncertainty explicitly.
*   **Limitations:** Requires optimization of additional parameters (weights, control points). Sensitive to initialization.
*   **When to use:** When measurement coordinates (view angles, detector positions) are uncertain or inaccurate.
*   **When not to use:** When measurement coordinates are known precisely and fixed.

## Background
This method originates from differentiable uncalibrated imaging frameworks, specifically for CT reconstruction where view angles and detector locations are uncertain [S1, unofficial]. It builds on the NURBS-Diff module [S1, unofficial]. The approach allows the network to learn more accurate tilt angles than assumed ones, reducing angle error during optimization [S1, unofficial].
