# Hermite Interpolation of Scalar Fields

Also called: C1-continuous Hermite Interpolation, Hermite Interpolation

## Overview
Hermite interpolation of scalar fields renders scalar-valued functions (such as height fields and signed distance fields) by storing partial derivatives alongside function values on a regular grid, using these derivatives to guarantee a globally $C^1$-continuous result [S1, unofficial]. Unlike [Voxel Data Interpolation and Sampling](12781-voxel-data-interpolation-and-sampling.md) which typically yields $C^0$ continuity via trilinear filtering, this method provides a storage-efficient replacement for normal mapping by using the exact normals of the reconstructed cubic Hermite surface as shading normals, without necessarily requiring extra storage if surface normals are already part of the discrete field of samples [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A regular grid of samples. Each grid point stores the scalar function value $f$ and its partial derivatives $\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}$. In rendering applications, these derivatives may correspond to surface normals [S1, unofficial].
- **Output:** A continuous, $C^1$-continuous scalar field $u(\mathbf{p})$ and its gradient $\nabla u(\mathbf{p})$ at any query point $\mathbf{p}$.

**Data Structures:**
The grid stores a tuple per vertex: $(f, f_x, f_y, f_z)$. For 3D fields, mixed partial derivatives ($f_{xy}, f_{xz}, f_{yz}$) are required for full cubic Hermite interpolation but are not naturally provided by simple gradient sampling. An approximation for these mixed partials is derived akin to Adini's method for parametric surface patches [S1, unofficial].

**Steps:**
1.  **Grid Construction:** Store the function value and partial derivatives at each grid node. If normals are available, they serve as the derivative data [S1, unofficial].
2.  **Mixed Derivative Approximation:** For 3D fields, approximate the mixed partial derivatives ($f_{xy}, f_{xz}, f_{yz}$) at each node. The specific formula is not detailed in the sources, but it is noted to be akin to Adini's method [S1, unofficial]. [G: Adini's method typically estimates mixed derivatives using central differences of the first derivatives across the cell, e.g., $f_{xy} \approx \frac{f_x(x+1,y) - f_x(x-1,y) + f_y(x,y+1) - f_y(x,y-1)}{4}$, assuming unit grid spacing.]
3.  **Basis Evaluation:** For a query point $\mathbf{p}$, identify the enclosing grid cell. Compute the local normalized coordinates $\mathbf{t} = (t_x, t_y, t_z) \in [0, 1]^3$. Compute the 1D cubic Hermite basis functions $H_0(t), H_1(t), H_2(t), H_3(t)$ for each dimension.
    - $H_0(t) = 2t^3 - 3t^2 + 1$
    - $H_1(t) = t^3 - 2t^2 + t$
    - $H_2(t) = -2t^3 + 3t^2$
    - $H_3(t) = t^3 - t^2$
4.  **Weighted Summation:** Calculate the interpolated value $u(\mathbf{p})$ by summing the contributions of all 64 control points (in 3D) weighted by the tensor product of the basis functions and the stored values/derivatives.
    $$ u(\mathbf{p}) = \sum_{i=0}^{1} \sum_{j=0}^{1} \sum_{k=0}^{1} \left( f_{ijk} B_{ijk}(\mathbf{t}) + \dots \right) $$
    Where $B_{ijk}$ are the tensor-product basis functions incorporating the mixed derivative terms.
5.  **Gradient Calculation:** Compute the gradient $\nabla u(\mathbf{p})$ by differentiating the basis functions. Use these exact normals for shading [S1, unofficial].

**Parameters:**
- Grid spacing: Implicitly 1 in normalized coordinates.
- Order: Cubic (3rd order) is specified for $C^1$ continuity [S1, unofficial].

**Edge Cases:**
- **Boundary Conditions:** The method assumes the grid covers the domain of interest. Extrapolation outside the grid is not defined in the sources.
- **Mixed Derivative Accuracy:** The approximation of mixed partial derivatives (akin to Adini's method) may introduce errors if the underlying field is not smooth or if the grid resolution is insufficient [S1, unofficial].

## Subtopics

### Floating Scale Surface Reconstruction (FSSR) Integration
In the context of Floating Scale Surface Reconstruction (FSSR), Hermite interpolation is used to improve surface reconstruction quality. The original weighting function in FSSR is not $C^1$-continuous. To ensure $C^1$ continuity, the weighting function is replaced with $w(r) = \frac{1}{12} (r - 3)^{12} (r + 1)^4$ [S2]. This modification allows the use of cubic Hermite interpolation, which improves mean and RMS error and visual appearance compared to quadratic methods, although the maximum error can remain large [S2].

## Operating characteristics
- **Continuity:** Globally $C^1$-continuous, ensuring smooth shading and normals [S1, unofficial].
- **Storage:** Storage efficient if normals are already available as part of the discrete field samples; otherwise, it requires storing derivatives in addition to function values [S1, unofficial].
- **Performance:** Cubic interpolation improves visual appearance and error metrics over quadratic methods in FSSR [S2].
- **Limitations:** Requires computation or approximation of mixed partial derivatives in 3D, which adds complexity compared to simple trilinear interpolation [S1, unofficial].

## Background
Hermite interpolation of scalar fields was proposed as a technique for real-time computer graphics, specifically for rendering height fields and signed distance fields [S1, unofficial]. It generalizes to arbitrary orders and dimensions [S1, unofficial]. The method has been implemented in surface reconstruction algorithms like Poisson Surface Reconstruction (PSR) and Floating Scale Surface Reconstruction (FSSR) to analyze the impact of Hermite interpolation on real surface reconstruction [S2].
