# B-spline Field Interpolation

Also called: B-spline deformation field, Cubic B-spline field

## Overview
B-spline Field Interpolation is a method for evaluating a continuous scalar or vector field from a discrete grid of control points using cubic B-spline basis functions [S1, unofficial]. It solves the problem of reconstructing a smooth, differentiable function from sparse samples while maintaining local support, ensuring that the value at any query point depends only on a fixed, small neighborhood of grid vertices [S1, unofficial]. It is distinguished from its siblings, such as [Voxel Data Interpolation and Sampling](12781-voxel-data-interpolation-and-sampling.md) (trilinear) and [Hermite Interpolation of Scalar Fields](9450-hermite-interpolation-of-scalar-fields.md), by providing $C^2$ continuity (continuous second derivatives) and a wider support kernel (4x4x4 points) that blends neighboring weights more smoothly, preventing the "blocky" artifacts of linear interpolation [S1, unofficial].

## How it works
**Inputs:**
*   Query point coordinates $\mathbf{p} = (x, y, z)$.
*   Grid origin $\mathbf{p}_0 = (x_0, y_0, z_0)$.
*   Grid spacing $\mathbf{s} = (dx, dy, dz)$.
*   Control point weights $w_{i,j,k}$ stored in a 3D array.

**Outputs:**
*   Interpolated scalar value $u(\mathbf{p})$. For vector fields, this is repeated for each component.

**Data Structures:**
*   **Control Point Grid:** A 3D array of weights. The minimum valid grid size is $4 \times 4 \times 4$ to support a single query [S1, unofficial].
*   **Weights:** Scalar values $w_{i,j,k}$ associated with integer indices $(i,j,k)$. For a 3D displacement vector field, three independent scalar grids are required, totaling 192 degrees of freedom for the minimum grid size [S1, unofficial].

**Steps:**
1.  **Calculate Integer Indices:** Determine the base index $(i_x, i_y, i_z)$ of the $4 \times 4 \times 4$ support grid that contains the query point. The indices are calculated using floor operations:
    $$ i_x = \left\lfloor \frac{x - x_0}{dx} - 1 \right\rfloor $$
    $$ i_y = \left\lfloor \frac{y - y_0}{dy} - 1 \right\rfloor $$
    $$ i_z = \left\lfloor \frac{z - z_0}{dz} - 1 \right\rfloor $$
    The support region spans indices $[i_x, i_x+3]$, $[i_y, i_y+3]$, and $[i_z, i_z+3]$ [S1, unofficial].

2.  **Calculate Normalized Coordinates:** Compute the local coordinates $(\tilde{x}, \tilde{y}, \tilde{z})$ within the support cell. These coordinates represent the position of the query point relative to the grid, normalized to the range $[0, 1]$ within the specific support interval:
    $$ \tilde{x} = \frac{x - x_0}{dx} - 1 - i_x $$
    $$ \tilde{y} = \frac{y - y_0}{dy} - 1 - i_y $$
    $$ \tilde{z} = \frac{z - z_0}{dz} - 1 - i_z $$
    Note that $\tilde{x}=0$ corresponds to the location of the control point at index $i_x+1$ [S1, unofficial].

3.  **Evaluate Basis Functions:** Compute the cubic B-spline basis weights $B_0, B_1, B_2, B_3$ for each dimension using the normalized coordinates. The basis functions are defined as:
    $$ B_0(\tilde{x}) = \frac{(1 - \tilde{x})^3}{6} $$
    $$ B_1(\tilde{x}) = \frac{3\tilde{x}^3 - 6\tilde{x}^2 + 4}{6} $$
    $$ B_2(\tilde{x}) = \frac{-3\tilde{x}^3 + 3\tilde{x}^2 + 3\tilde{x} + 1}{6} $$
    $$ B_3(\tilde{x}) = \frac{\tilde{x}^3}{6} $$
    These functions sum to 1 for any $\tilde{x} \in [0, 1]$ [S1, unofficial].

4.  **Compute Interpolated Value:** Sum the contributions of the 64 control points in the support grid, weighted by the product of the basis functions for each dimension:
    $$ u(\mathbf{p}) = \sum_{l=0}^3 \sum_{m=0}^3 \sum_{n=0}^3 B_l(\tilde{x}) B_m(\tilde{y}) B_n(\tilde{z}) w_{i_x+l, i_y+m, i_z+n} $$

**Pseudocode:**
```python
def cubic_b_spline_basis(t):
    """
    Computes the 4 cubic B-spline basis weights for a normalized coordinate t in [0, 1].
    """
    t2 = t * t
    t3 = t2 * t
    b0 = (1.0 - t) ** 3 / 6.0
    b1 = (3.0 * t3 - 6.0 * t2 + 4.0) / 6.0
    b2 = (-3.0 * t3 + 3.0 * t2 + 3.0 * t + 1.0) / 6.0
    b3 = t3 / 6.0
    return b0, b1, b2, b3

def interpolate_b_spline_field(x, y, z, x0, y0, z0, dx, dy, dz, weights):
    """
    Interpolates a value from a 3D B-spline field.
    
    Args:
        x, y, z: Query point coordinates.
        x0, y0, z0: Grid origin.
        dx, dy, dz: Grid spacing.
        weights: 3D array of control point weights.
        
    Returns:
        Interpolated scalar value.
    """
    # Step 1: Calculate integer indices
    ix = int((x - x0) / dx - 1)
    iy = int((y - y0) / dy - 1)
    iz = int((z - z0) / dz - 1)
    
    # Step 2: Calculate normalized coordinates
    tx = (x - x0) / dx - 1 - ix
    ty = (y - y0) / dy - 1 - iy
    tz = (z - z0) / dz - 1 - iz
    
    # Step 3: Evaluate basis functions
    bx = cubic_b_spline_basis(tx)
    by = cubic_b_spline_basis(ty)
    bz = cubic_b_spline_basis(tz)
    
    # Step 4: Compute interpolated value
    value = 0.0
    for l in range(4):
        for m in range(4):
            for n in range(4):
                # Access weight at index (ix+l, iy+m, iz+n)
                # Note: In a real implementation, bounds checking for the grid edges is required.
                w = weights[ix + l, iy + m, iz + n]
                value += bx[l] * by[m] * bz[n] * w
                
    return value
```

**Parameters:**
*   **Grid Origin $(x_0, y_0, z_0)$:** The coordinate of the first control point in the grid [S1, unofficial].
*   **Grid Spacing $(dx, dy, dz)$:** The distance between adjacent control points along each axis [S1, unofficial].
*   **Control Point Weight $(w_{i,j,k})$:** The scalar value associated with the control point at grid index $(i,j,k)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Non-Interpolatory Nature:** The value of the field at a control point location (where $\tilde{x}=0, \tilde{y}=0, \tilde{z}=0$) is not equal to the weight of that control point. Due to the blending of neighboring weights, the value is a weighted sum of the 64 surrounding points. For example, if only one control point has weight 1 and all others are 0, the field value at that point is $2/3$, not 1 [S1, unofficial].
*   **Boundary Conditions:** The method assumes the query point lies within the support of the defined grid. Queries outside the grid bounds require extrapolation or clamping strategies not defined in the base method [G].
*   **Precision:** The basis functions are cubic polynomials. Standard floating-point precision is sufficient, but care should be taken with very large coordinate values relative to grid spacing to avoid loss of precision in the subtraction steps for normalized coordinates [G].

## Subtopics

### [B-spline Curve Modeling](14651-b-spline-curve-modeling.md)
B-spline Curve Modeling is a technique for generating smooth parametric space curves that interpolate a sequence of control points, primarily used to define the spines of volumetric flames. It is chosen over Hermite interpolation because it guarantees second-order continuity ($C^2$), preventing random twisting of the curve space, and possesses affine invariance. It builds on [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) by applying uniform B-spline basis functions to 1D parametric curves rather than 3D scalar fields.

### Time-varying B-spline Deformation Field
A time-varying displacement field $u(\mathbf{x}, t)$ parametrized by cubic B-splines on a fixed 3D grid, allowing arbitrary continuous position and time queries [S1, unofficial].
*   **Definition:** The grid of control points remains fixed in space, but the weights $w(t)$ vary with time $t$ [S1, unofficial].
*   **Implementation:** The weights are generated implicitly as a function of time using a Multi-Layer Perceptron (MLP) $\phi(t) \rightarrow w(t)$, which takes time $t$ as input and returns the complete set of weights for the current timestep [S1, unofficial]. This approach ensures implicit time continuity and is more efficient than discretizing time into separate timesteps [S1, unofficial].
*   **Formula:** The displacement component $u$ at position $(x,y,z)$ and time $t$ is calculated by interpolating the time-varying weights of the 64 closest grid points:
    $$ u(x, y, z, t) = \sum_{l=0}^3 \sum_{m=0}^3 \sum_{n=0}^3 B_l(\tilde{x}) B_m(\tilde{y}) B_n(\tilde{z}) w(t)_{i_x+l, i_y+m, i_z+n} $$
    where $B_i$ are the fixed cubic B-spline functions, $i_x, i_y, i_z$ are the indices of the relevant grid points, and $\tilde{x}, \tilde{y}, \tilde{z}$ are the modulo-subtracted normalized coordinates [S1, unofficial].
*   **Layout:** The grid has size $n_x \times n_y \times n_z$. Each grid point has a trainable weight $w(t)$ for each of the 3 displacement components ($u_x, u_y, u_z$) [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per query, as it always accesses exactly 64 control points and performs a fixed number of arithmetic operations [S1, unofficial].
*   **Memory Complexity:** $O(N)$ where $N$ is the number of control points. For a 3D displacement field, memory usage is $3 \times N$ weights [S1, unofficial].
*   **Performance:** The method is computationally efficient for dense sampling due to the small, fixed support size. However, it is more expensive than trilinear interpolation due to the cubic polynomial evaluations [S1, unofficial].
*   **Strengths:** Provides $C^2$ continuity, resulting in very smooth fields suitable for deformation and density reconstruction. Local support ensures stability and efficiency [S1, unofficial].
*   **Limitations:** The field is not interpolatory (values at control points are not preserved exactly), which may be undesirable for certain applications requiring exact data retention. Boundary handling is non-trivial [S1, unofficial].
*   **When to use:** When smooth, differentiable fields are required, such as in deformation networks for medical imaging or volumetric flame modeling [S1, unofficial].
*   **When not to use:** When exact interpolation of control point values is required, or when computational resources are extremely limited and $C^0$ continuity is sufficient [S1, unofficial].

## Background
B-spline field interpolation was introduced in the context of medical image registration and deformation modeling by Rueckert et al. [S1, unofficial]. It was later adapted for neural rendering and dynamic tomography to represent continuous, time-varying density and displacement fields, allowing for efficient reconstruction from sparse projections [S1, unofficial]. The method leverages the local support and smoothness properties of cubic B-splines to model complex deformations and attenuation fields [S1, unofficial].
