# B-spline Field Interpolation

Also called: B-spline deformation field, Cubic B-spline field

## Overview
B-spline Field Interpolation is a method for function interpolation using cubic B-splines, defined by a grid of control points and weights, where shape functions have local influence [S1, unofficial]. It solves the problem of representing continuous scalar or vector fields from discrete control points, ensuring $C^2$ continuity across cell boundaries. It sets itself apart from its siblings by using a fixed 4x4x4 support region with specific cubic polynomial basis functions that do not interpolate the control points directly (the field value at a control point is not equal to its weight), unlike [Hermite Interpolation of Scalar Fields](9450-hermite-interpolation-of-scalar-fields.md) which matches derivatives, or [Voxel Data Interpolation and Sampling](12781-voxel-data-interpolation-and-sampling.md) which typically uses linear or trilinear blending.

## How it works
**Inputs and Outputs:**
- **Input:** Query point $\mathbf{p} = (x, y, z)$; Grid origin $\mathbf{o} = (x_0, y_0, z_0)$; Grid spacing $\mathbf{s} = (dx, dy, dz)$; Control point weights $w_{i,j,k}$ for a grid of size $N_x \times N_y \times N_z$.
- **Output:** Interpolated scalar value $u(\mathbf{p})$ or vector displacement $\mathbf{u}(\mathbf{p})$.

**Data Structures:**
- **Control Point Grid:** A 3D array of weights. For a scalar field, the minimum size is $4 \times 4 \times 4 = 64$ points [S1, unofficial]. For a vector field (e.g., 3D displacement), three independent sets of weights are required, totaling $3 \times 64 = 192$ degrees of freedom [S1, unofficial].
- **Weights:** $w_{i_x+l, i_y+m, i_z+n}$ are scalar values associated with each control point index.

**Numbered Steps:**
1.  **Index Calculation:** Calculate the integer indices for the 4x4x4 support grid for the query point $\mathbf{p}(x,y,z)$:
    $$i_x = \left\lfloor \frac{x - x_0}{dx} - 1 \right\rfloor$$
    $$i_y = \left\lfloor \frac{y - y_0}{dy} - 1 \right\rfloor$$
    $$i_z = \left\lfloor \frac{z - z_0}{dz} - 1 \right\rfloor$$
    [S1, unofficial]

2.  **Normalized Coordinates:** Calculate the normalized coordinates within the support region (specifically within the cube defined by control points $(i_x+1 \dots i_x+2)$, etc.):
    $$\tilde{x} = \frac{x - x_0}{dx} - 1 - i_x$$
    $$\tilde{y} = \frac{y - y_0}{dy} - 1 - i_y$$
    $$\tilde{z} = \frac{z - z_0}{dz} - 1 - i_z$$
    [S1, unofficial]
    Note: $\tilde{x}, \tilde{y}, \tilde{z} \in [0, 1)$.

3.  **Basis Evaluation:** Compute the cubic B-spline basis functions $B_0, B_1, B_2, B_3$ for each dimension using $\tilde{x}, \tilde{y}, \tilde{z}$:
    $$B_0(\tilde{x}) = \frac{(1 - \tilde{x})^3}{6}$$
    $$B_1(\tilde{x}) = \frac{3\tilde{x}^3 - 6\tilde{x}^2 + 4}{6}$$
    $$B_2(\tilde{x}) = \frac{-3\tilde{x}^3 + 3\tilde{x}^2 + 3\tilde{x} + 1}{6}$$
    $$B_3(\tilde{x}) = \frac{\tilde{x}^3}{6}$$
    [S1, unofficial]

4.  **Blending:** Calculate the interpolated value $u$ as the sum of weighted basis functions over the 4x4x4 support grid:
    $$u = \sum_{l=0}^3 \sum_{m=0}^3 \sum_{n=0}^3 B_l(\tilde{x}) B_m(\tilde{y}) B_n(\tilde{z}) w_{i_x+l, i_y+m, i_z+n}$$
    [S1, unofficial]

**Parameters:**
- **Grid Origin:** $[x_0, y_0, z_0]$, the origin of the grid of control points [S1, unofficial].
- **Grid Spacing:** $dx, dy, dz$, the spacing between control points along each axis [S1, unofficial].
- **Control Point Weight:** $w_{i_x, i_y, i_z}$, the scalar weight associated with control point indexed by $(i_x, i_y, i_z)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Non-Interpolating Property:** The field value at a control point ($\tilde{x}=0$) is not equal to the weight of that control point due to the blending of neighboring weights. For example, if a single control point has weight 1 and all others 0, the field value at that point is $2/3$ [S1, unofficial].
- **Boundary Conditions:** Support indices that fall outside the grid bounds must be handled via boundary conditions (e.g., clamp, periodic, or constant) [S1, unofficial]. The sources do not specify the exact boundary condition implementation details for out-of-bounds indices [G].

**Pseudocode:**
```python
def cubic_b_spline_basis(t):
    """
    Computes the 4 cubic B-spline basis functions for a normalized coordinate t in [0, 1).
    Returns a list [B0, B1, B2, B3].
    """
    t2 = t * t
    t3 = t2 * t
    b0 = (1.0 - t) ** 3 / 6.0
    b1 = (3.0 * t3 - 6.0 * t2 + 4.0) / 6.0
    b2 = (-3.0 * t3 + 3.0 * t2 + 3.0 * t + 1.0) / 6.0
    b3 = t3 / 6.0
    return [b0, b1, b2, b3]

def b_spline_field_interpolation(x, y, z, origin, spacing, weights):
    """
    Interpolates a value at point (x, y, z) using a 3D B-spline field.
    
    Args:
        x, y, z: Query point coordinates.
        origin: Tuple (x0, y0, z0) of grid origin.
        spacing: Tuple (dx, dy, dz) of grid spacing.
        weights: 3D array of control point weights. Shape should be at least (4, 4, 4).
                 Access weights[i, j, k] corresponds to index (i, j, k).
    
    Returns:
        Interpolated scalar value u.
    """
    x0, y0, z0 = origin
    dx, dy, dz = spacing
    
    # Step 1: Calculate integer indices for the 4x4x4 support grid
    ix = int((x - x0) / dx - 1)
    iy = int((y - y0) / dy - 1)
    iz = int((z - z0) / dz - 1)
    
    # Step 2: Calculate normalized coordinates within the support region
    x_tilde = (x - x0) / dx - 1 - ix
    y_tilde = (y - y0) / dy - 1 - iy
    z_tilde = (z - z0) / dz - 1 - iz
    
    # Step 3: Evaluate basis functions
    b_x = cubic_b_spline_basis(x_tilde)
    b_y = cubic_b_spline_basis(y_tilde)
    b_z = cubic_b_spline_basis(z_tilde)
    
    # Step 4: Blending
    u = 0.0
    for l in range(4):
        for m in range(4):
            for n in range(4):
                # Access weight with boundary handling [G]
                # Note: The sources do not specify the exact boundary condition logic.
                # A standard implementation would clamp indices or use periodic wrapping.
                # Here we assume valid indices for the core algorithm description.
                w = weights[ix + l, iy + m, iz + n]
                u += b_x[l] * b_y[m] * b_z[n] * w
                
    return u
```

## Subtopics

### Time-varying B-spline Deformation Field
A time-varying displacement field $\mathbf{u}(\mathbf{x}, t)$ parametrized by cubic B-splines on a fixed 3D grid, allowing arbitrary continuous position and time queries [S1, unofficial]. It sets itself apart by generating weights implicitly as a function of time $w(t)$ rather than discretizing time into timesteps, ensuring implicit time continuity and efficiency [S1, unofficial]. Choose this when representing dynamic deformations where temporal smoothness is required without storing discrete keyframes. The grid of control points remains fixed in space, and the weights are generated by a Multi-Layer Perceptron (MLP) $\phi(t) \rightarrow w(t)$ which takes time $t$ as input and returns the complete set of weights [S1, unofficial]. The displacement component $u$ at position $(x,y,z)$ and time $t$ is calculated by interpolating weights of the 64 closest grid points: $u(x, y, z, t) = \sum_{l=0}^3 \sum_{m=0}^3 \sum_{n=0}^3 B_l(\tilde{x}) B_m(\tilde{y}) B_n(\tilde{z}) w(t)_{i_x+l, i_y+m, i_z+n}$ [S1, unofficial]. Each grid point has a trainable weight for each of the 3 displacement components ($u_x, u_y, u_z$) [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per query, as it always accesses a fixed 4x4x4 = 64 control points and performs a constant number of arithmetic operations [S1, unofficial].
- **Memory Complexity:** $O(N_x N_y N_z)$ to store the control point weights. For a 3D displacement field, this is $3 \times N_x N_y N_z$ [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Strengths:** Local influence of shape functions (similar to finite element shape functions); $C^2$ continuity; efficient for arbitrary continuous position and time queries; low number of degrees of freedom for smooth fields (minimum 192 for 3D displacement) [S1, unofficial].
- **Limitations:** The field does not interpolate the control points directly (value at control point $\neq$ weight); requires careful handling of boundary conditions; expressive power depends on grid resolution [S1, unofficial].
- **When to use:** When smooth, continuous interpolation of a field is required, especially for deformation fields in medical imaging or dynamic tomography [S1, unofficial].
- **When not to use:** When exact interpolation of control point values is required; when the field has sharp discontinuities that B-splines may smooth out excessively.

## Background
B-spline field interpolation was originally proposed by Rueckert et al. [19] (cited in [S1, unofficial]) for non-rigid image registration. It was modified in recent work to account for temporal variations in deformation for dynamic tomography [S1, unofficial]. The method is used in neural rendering frameworks for X-ray attenuation tomography, where the density field is represented as a continuous function rather than a discrete voxel grid [S1, unofficial].
