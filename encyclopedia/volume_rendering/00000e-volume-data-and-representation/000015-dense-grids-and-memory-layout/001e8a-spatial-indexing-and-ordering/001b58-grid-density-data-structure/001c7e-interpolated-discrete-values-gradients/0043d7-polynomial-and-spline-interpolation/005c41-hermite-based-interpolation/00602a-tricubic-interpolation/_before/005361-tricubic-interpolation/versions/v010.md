# Tricubic Interpolation
Also called: Tricubic Hermite Interpolation
## Overview
Tricubic interpolation is a higher-order method that employs cubic polynomials over a $4 \times 4 \times 4$ neighborhood of 64 points to approximate smooth underlying functions [S1]. It provides $C^1$ continuity and fourth-order accuracy $O(h^4)$, making it superior to trilinear interpolation for gradient-sensitive tasks like volume rendering, albeit at increased computational cost [S1].
## How it works
**Inputs and Outputs:**
*   **Input:** A dense grid tensor $\mathbf{G}$ of shape $(D_x, D_y, D_z, C)$ containing scalar values and their spatial gradients (Hermite data) [S2, unofficial]. A query point $\mathbf{p} = (x, y, z)$ in continuous space.
*   **Output:** The interpolated value $u(\mathbf{p})$ and optionally the gradient $\nabla u(\mathbf{p})$ [S2, unofficial].

**Data Structures:**
The method requires access to the grid values and their first-order derivatives. For a voxel defined by corners $\mathbf{p}_{ijk}$, the Hermite patch requires:
1.  The value at the corner: $V_{ijk} = \mathbf{G}[i, j, k]$.
2.  The partial derivatives at the corner: $\frac{\partial V}{\partial x}, \frac{\partial V}{\partial y}, \frac{\partial V}{\partial z}$ [S2, unofficial].
These gradients are typically computed from the grid samples using finite differences or stored explicitly [S2, unofficial].

**Steps:**
1.  **Coordinate Mapping:** Map the continuous query point $\mathbf{p} = (x, y, z)$ to the grid indexing space. Determine the integer indices $(i, j, k)$ of the voxel containing $\mathbf{p}$, such that $i \le x < i+1$, etc. Compute the fractional coordinates $\tilde{x} = x - i$, $\tilde{y} = y - j$, $\tilde{z} = z - k$, where $\tilde{x}, \tilde{y}, \tilde{z} \in [0, 1)$ [S2, unofficial].
2.  **Support Selection:** Select the $4 \times 4 \times 4$ block of control points surrounding the query point. This includes vertices from indices $i-1$ to $i+2$ in each dimension [S1].
3.  **Basis Evaluation:** Evaluate the 1D cubic Hermite basis functions for each dimension. For a fractional coordinate $\tilde{t} \in [0, 1]$, the basis functions $H_0(\tilde{t}), H_1(\tilde{t}), H_2(\tilde{t}), H_3(\tilde{t})$ are:
    $$ H_0(\tilde{t}) = 2\tilde{t}^3 - 3\tilde{t}^2 + 1 $$
    $$ H_1(\tilde{t}) = -2\tilde{t}^3 + 3\tilde{t}^2 $$
    $$ H_2(\tilde{t}) = \tilde{t}^3 - 2\tilde{t}^2 + \tilde{t} $$
    $$ H_3(\tilde{t}) = \tilde{t}^3 - \tilde{t}^2 $$
    These functions ensure that the value and derivative at the endpoints of the interval are preserved [S2, unofficial].
4.  **Weighted Summation:** Compute the interpolated value by combining the 64 control points (values and gradients) using the tensor product of the basis functions. For a single channel:
    $$ u(\mathbf{p}) = \sum_{a=0}^{3} \sum_{b=0}^{3} \sum_{c=0}^{3} B_a(\tilde{x}) B_b(\tilde{y}) B_c(\tilde{z}) W_{i+a-1, j+b-1, k+c-1} $$
    where $W$ represents the combined value/gradient data at the support points, and $B$ are the specific Hermite basis functions mapped to value ($H_0, H_1$) or derivative ($H_2, H_3$) contributions [S2, unofficial].
5.  **Gradient Computation:** The gradient $\nabla u(\mathbf{p})$ is computed by differentiating the basis functions with respect to $\tilde{x}, \tilde{y}, \tilde{z}$ and applying the chain rule to account for grid spacing [S2, unofficial].

**Pseudocode:**
```python
def tricubic_hermite_interpolate(grid, gradients, p):
    # p is (x, y, z)
    # grid is 3D array of values
    # gradients is 3D array of (dx, dy, dz) tuples
    
    # 1. Coordinate Mapping
    x, y, z = p
    i = floor(x)
    j = floor(y)
    k = floor(z)
    tx = x - i
    ty = y - j
    tz = z - k
    
    # 2. Support Selection
    # We need indices from i-1 to i+2 for each dimension
    # To avoid boundary checks in this simplified example, assume valid interior query
    points = []
    for dx in range(-1, 3):
        for dy in range(-1, 3):
            for dz in range(-1, 3):
                val = grid[i+dx, j+dy, k+dz]
                grad = gradients[i+dx, j+dy, k+dz]
                points.append((val, grad))
                
    # 3 & 4. Basis Evaluation and Weighted Summation
    # The 4x4x4 block is mapped to the 64 coefficients
    # This is a simplified representation of the tensor product
    result = 0.0
    
    # Precompute basis functions for x, y, z
    hx = [2*tx**3 - 3*tx**2 + 1, -2*tx**3 + 3*tx**2, tx**3 - 2*tx**2 + tx, tx**3 - tx**2]
    hy = [2*ty**3 - 3*ty**2 + 1, -2*ty**3 + 3*ty**2, ty**3 - 2*ty**2 + ty, ty**3 - ty**2]
    hz = [2*tz**3 - 3*tz**2 + 1, -2*tz**3 + 3*tz**2, tz**3 - 2*tz**2 + tz, tz**3 - tz**2]
    
    # Iterate through the 4x4x4 support
    # Note: The mapping of indices to the 64 points must align with the basis function order
    # (Value, d/dx, d/dy, d/dz) for each corner of the local cell
    # For a standard Hermite patch on the cell [i,j,k] to [i+1,j+1,k+1],
    # the 16 points are the 4 corners, each with Value and 3 Gradients.
    # Tricubic extends this to the 4x4x4 neighborhood.
    
    # Simplified: Assuming the 'points' list is ordered correctly for the tensor product
    # In practice, one constructs a 4x4x4 matrix of coefficients
    coeff_matrix = build_hermite_coefficients(grid, gradients, i, j, k)
    
    for a in range(4):
        for b in range(4):
            for c in range(4):
                result += hx[a] * hy[b] * hz[c] * coeff_matrix[a, b, c]
                
    return result
```
*[G] The `build_hermite_coefficients` function maps the 64 grid points (values and gradients) into the 4x4x4 coefficient tensor required for the tensor product evaluation. This mapping depends on the specific ordering of the Hermite basis functions.*

## Operating characteristics
*   **Complexity:** Time complexity is $O(1)$ per query but with a high constant factor due to the $4 \times 4 \times 4 = 64$ support points and cubic polynomial evaluations [S1]. Memory access is less coherent than trilinear due to the larger support window [S1].
*   **Accuracy:** Provides $O(h^4)$ accuracy for smooth functions, compared to $O(h^2)$ for trilinear [S1].
*   **Continuity:** $C^1$ continuous, ensuring smooth gradients, which reduces artifacts in volume rendering and differentiable visualization [S1].
*   **Trade-offs:** Significantly higher computational expense than trilinear [S1]. Not suitable for real-time applications with strict latency constraints or very large volumes where memory bandwidth is a bottleneck [S1].
## Background
Tricubic interpolation is a standard extension of cubic Hermite interpolation to three dimensions. It is widely used in medical imaging and scientific visualization for upsampling 3D volumes where smoothness is critical [S1]. The method was highlighted in game development contexts (e.g., Irradiance Volumes) for its efficiency in approximating smooth lighting fields using samples and gradients [S2, unofficial].
