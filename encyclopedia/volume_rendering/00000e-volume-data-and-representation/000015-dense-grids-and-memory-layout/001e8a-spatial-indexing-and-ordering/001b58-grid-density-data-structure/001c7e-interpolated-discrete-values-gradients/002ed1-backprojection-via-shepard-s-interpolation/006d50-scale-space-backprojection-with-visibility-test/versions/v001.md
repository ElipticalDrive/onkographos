# Scale-space Backprojection with Visibility Test

Also called: Scale Field Construction, Weighted Backprojection

## Overview
This method constructs a continuous scale field $S(\mathbf{x})$ from a discrete set of Laplacian of Gaussian (LoG) extrema by interpolating representative scales, while applying a visibility test to prevent "scale bleeding" from large features into small embedded features [S1]. It distinguishes itself from standard Shepard interpolation by modulating the influence of each extremum based on occlusion, ensuring that small structures are not incorrectly assigned the scale of larger surrounding blobs [S1].

## How it works
**Inputs:**
*   $N$: A set of LoG extrema, where each extremum $i$ has a position $\mathbf{x}_i$ and a scale (time) $t_i$.
*   $\mathbf{x}$: The sample point in the volume domain where the scale $S(\mathbf{x})$ is being computed.
*   $I(\cdot)$: The scalar intensity function of the volume data.
*   $\tau$: The visibility threshold parameter [S1].

**Outputs:**
*   $S(\mathbf{x})$: The interpolated scale value at $\mathbf{x}$ [S1].

**Data Structures:**
*   The extrema set $N$ is typically stored as a list or array of structures containing 3D coordinates and a scalar scale value. No specific bit-packing is mandated by the source, but efficient spatial indexing (e.g., grid-based) is implied for performance [S1].

**Parameters:**
*   $\tau$: A thresholding value controlling the sensitivity of the visibility test. It can be based on scalar intensity or gradient magnitude [S1]. Typical values are not specified in the sources [S1].

**Algorithm Steps:**
1.  **Initialize Accumulators:** Initialize a weighted sum of scales $W_{sum} = 0$ and a weighted sum of scale values $S_{sum} = 0$.
2.  **Iterate Extrema:** For each LoG extremum $i \in N$:
    a.  **Compute Distance:** Calculate the Euclidean distance $d_i = \|\mathbf{x} - \mathbf{x}_i\|$.
    b.  **Visibility Test:** Determine if $\mathbf{x}$ is visible from $\mathbf{x}_i$.
        i.  Define the ray segment connecting $\mathbf{x}_i$ and $\mathbf{x}$.
        ii. Sample points along this ray.
        iii. Check if any sample point has an intensity $I(\mathbf{p}) < \tau$ (if using scalar threshold) or gradient magnitude $|\nabla I(\mathbf{p})| < \tau$ (if using gradient threshold).
        iv. If such a point exists, the extremum is occluded. Set visibility weight $\Theta_i = 0$.
        v.  Otherwise, the extremum is visible. Set $\Theta_i = 1$ (or apply a standard distance-based decay function if defined by the specific Shepard variant, though the source emphasizes the binary modulation by visibility) [S1].
    c.  **Accumulate:** If $\Theta_i > 0$, add the contribution to the sums:
        $$ W_{sum} \leftarrow W_{sum} + \Theta_i $$
        $$ S_{sum} \leftarrow S_{sum} + \Theta_i t_i $$
3.  **Compute Result:** Calculate the final scale field value:
    $$ S(\mathbf{x}) = \frac{S_{sum}}{W_{sum}} $$
    *Note: The source presents the formula as a direct sum $\sum \{\Theta t_i\}$, implying a weighted average where the denominator is the sum of weights [S1]. If using the max operator alternative, see below.*

**Alternative Operator:**
The source notes that instead of a sum, one can use the maximum operator to prioritize larger features and avoid smoothing scale variation:
$$ S(\mathbf{x}) = \max_{\mathbf{x}_i \in N} \{\Theta(\|\mathbf{x} - \mathbf{x}_i\|) t_i\} $$
This is useful when large features must dominate the classification [S1].

**Pitfalls:**
*   **Scale Bleeding:** Without the visibility test, a small feature embedded in the blob of a large feature may incorrectly inherit the large feature's scale [S1].
*   **Threshold Sensitivity:** The choice of $\tau$ significantly impacts the result. Too low, and bleeding persists; too high, and valid scale information from nearby features may be lost [S1].
*   **Approximation:** This is a fast approximation. For higher accuracy, a region-growing post-process is recommended [S1].

**Pseudocode:**
```python
def compute_scale_field(x, extrema, volume_data, tau, use_max=False):
    """
    Compute the scale field S(x) at point x using scale-space backprojection with visibility test.
    
    Args:
        x: 3D coordinate vector [x, y, z]
        extrema: List of tuples (pos, scale) representing LoG extrema
        volume_data: Function or object providing intensity I(p) and gradient |grad I(p)|
        tau: Visibility threshold
        use_max: If True, use max operator; otherwise use weighted sum (average)
    
    Returns:
        S: Interpolated scale value
    """
    if use_max:
        max_val = -infinity
        for pos_i, t_i in extrema:
            # Compute distance-based weight (assuming standard Gaussian or similar decay)
            # Note: Source does not specify the exact decay function for Theta, 
            # only that it is modulated by visibility. We assume a base weight w_i.
            dist = distance(x, pos_i)
            w_i = exp(-dist**2 / (2 * sigma**2)) # Placeholder for standard Shepard decay [G]
            
            # Visibility Test
            visible = is_visible(x, pos_i, volume_data, tau)
            
            if visible:
                val = w_i * t_i
                if val > max_val:
                    max_val = val
        return max_val
    else:
        sum_weights = 0.0
        sum_scaled = 0.0
        for pos_i, t_i in extrema:
            dist = distance(x, pos_i)
            w_i = exp(-dist**2 / (2 * sigma**2)) # Placeholder for standard Shepard decay [G]
            
            visible = is_visible(x, pos_i, volume_data, tau)
            
            if visible:
                sum_weights += w_i
                sum_scaled += w_i * t_i
        
        if sum_weights == 0:
            return 0.0 # Or handle as undefined
        return sum_scaled / sum_weights

def is_visible(x, pos_i, volume_data, tau):
    """
    Check if x is visible from pos_i based on intensity or gradient threshold.
    """
    # Sample points along the ray between pos_i and x
    # Number of samples depends on distance and desired accuracy [G]
    num_samples = max(1, int(distance(x, pos_i) * 2)) 
    for t in linspace(0, 1, num_samples):
        p = lerp(pos_i, x, t)
        intensity = volume_data.intensity(p)
        gradient_mag = volume_data.gradient_magnitude(p)
        
        # Check threshold condition
        # Source allows either scalar or gradient threshold [S1]
        if intensity < tau or gradient_mag < tau:
            return False
    return True
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of extrema $N$ for each sample point, $O(N)$, assuming visibility checks are $O(1)$ or bounded. Visibility checks add a constant factor depending on ray sampling density [S1].
*   **Memory Complexity:** $O(N)$ to store the extrema set [S1].
*   **Performance:** Described as a "fast approximation" suitable for GPU implementation using hardware-supported blending methods [S1].
*   **Strengths:** Prevents scale bleeding; robust to noise due to the underlying diffusion-based scale-space; allows size-based classification without segmentation [S1].
*   **Limitations:** Approximate; accuracy depends on $\tau$; may require region-growing post-processing for high precision [S1].
*   **When to use:** When rapid visualization of size-based features is needed and segmentation is too expensive or unreliable [S1].
*   **When not to use:** When high-precision scale boundaries are required, in which case region growing is preferred [S1].

## Background
*   **Origin:** Proposed by Correa, Ma, et al. in 2008 [S1].
*   **Context:** Developed as part of "Size-based Transfer Functions" for volume exploration, aiming to classify features by size without explicit segmentation [S1].
*   **Development:** Builds on diffusion-based scale-space theory, which is inherently robust to noise [S1]. The method was demonstrated on datasets such as hand scans and brain tissue with vessels [S1].
