# NURBS-based Uncalibrated Imaging Reconstruction

Also called: Spline method, NURBS representation

## Overview
NURBS-based Uncalibrated Imaging Reconstruction reconstructs CT volumes from projections with uncertain measurement coordinates by modeling the coordinates as a NURBS surface whose control points are optimized alongside a U-Net reconstruction network [S1, unofficial]. It differs from implicit neural representations by using fixed-degree spline basis functions with explicitly optimized control points, enabling direct enforcement of Radon transform consistency conditions rather than relying on the network to approximate them implicitly [S1, unofficial].

## How it works
**Inputs:**
*   Projection measurements and initial measurement coordinates (view angles $\theta$, tilt angles, detector locations $t$) [S1, unofficial].
*   Ground truth volumes for training loss computation [S1, unofficial].

**Outputs:**
*   Reconstructed volume [S1, unofficial].
*   Optimized NURBS control points defining the measurement coordinate mapping [S1, unofficial].

**Data Structures:**
*   **NURBS Surface:** Maps measurement coordinates to values; for 2D CT it maps $(\theta, t)$ and for 3D CT it maps $(\theta, t_x, t_y)$ [S1, unofficial].
*   **Control Points:** $p_{j,k}$ where $j$ indexes the view angle dimension and $k$ indexes the detector dimension [S1, unofficial].
*   **Weights:** For 3D CT, all basis function weights are fixed to $1.0$, reducing the NURBS surface to a B-spline surface [S1, unofficial].

**Parameters:**
*   **NURBS Degree (2D):** $18$ along the learned measurement coordinate dimension; $2$ along the non-learned dimension [S1, unofficial].
*   **NURBS Degree (3D):** $15$ along the tilt angle dimension; $2$ along the two detector location dimensions [S1, unofficial].
*   **Regularization ($\lambda$):** $0.6$ when splines are used (compared to $0.1$ for implicit neural representations) [S1, unofficial].
*   **Learning Rates:** Neural network parameters use $1 \times 10^{-3}$ for 2D implicit and $5 \times 10^{-3}$ for 3D spline; input coordinates (control points) use $1 \times 10^{-4}$ [S1, unofficial].
*   **Batch Size:** $128$ for 2D U-Net; $16$ for 3D U-Net [S1, unofficial].
*   **Epochs:** $100$ [S1, unofficial].

**Steps:**
1.  **Initialize Control Points:** Create initial control points for the NURBS surface from the observed measurement coordinates. Let $J$ be the number of view angles and $K$ be the number of detectors [S1, unofficial].
2.  **Enforce Consistency Conditions (2D CT):** If view angle uncertainty exists, create additional control points to satisfy the Radon transform consistency conditions $r_\phi([\theta + \pi, t]^T) = r_\phi([\theta, -t]^T)$ and $r_\phi([\theta - \pi, t]^T) = r_\phi([\theta, -t]^T)$, where $-t$ refers to the $t$-th last detector [S1, unofficial]. For $J - d_\Theta < j \le J$ (where $d_\Theta$ is the degree in the view angle dimension), create new control points $p_{j+J-1,k} = [\theta_j + \pi, t_k, y([\theta_{e_j}, -t_{e_k}]^T)]^T$ and $p_{j-J-1,k} = [\theta_j - \pi, t_k, y([\theta_{e_j}, -t_{e_k}]^T)]^T$ [S1, unofficial]. Here, $y$ is the function value being interpolated at the consistent coordinate pair, and $e_j, e_k$ are indices mapping to the observed measurements [S1, unofficial]. This adds exactly $2 d_\Theta K$ control points [S1, unofficial].
3.  **Fix Weights (3D CT):** Set all basis function weights to $1.0$, converting the NURBS surface into a B-spline surface [S1, unofficial].
4.  **Train Reconstruction Network:** Train a U-Net $G_\mu(\cdot)$ to reconstruct the volume from projections using the NURBS-interpolated coordinates [S1, unofficial]. Minimize the mean-squared error loss using the Adam optimizer for $100$ epochs [S1, unofficial]. The 2D U-Net uses $1$ input channel, $1$ output channel, and $16$ features in the first layer [S1, unofficial]. The 3D U-Net uses $1$ input channel, $1$ output channel, $16$ features in the first layer, and a depth of four blocks [S1, unofficial]. Apply random horizontal flips, random vertical flips, and random rotations by $90$, $180$, or $270$ degrees to the 3D training data [S1, unofficial].
5.  **Optimize Control Points:** Jointly optimize the NURBS control points and network weights $\mu$ using the specified learning rates [S1, unofficial]. Apply the regularization parameter $\lambda = 0.6$ to the spline-based solution [S1, unofficial].

**Pseudocode:**
```python
def train_nurbs_reconstruction(projections, initial_coords, is_3d, is_2d):
    # U-Net architecture setup
    if is_2d:
        unet = UNet(input_channels=1, output_channels=1, first_layer_features=16)
        batch_size = 128
        lr_nn = 1e-3
    else:
        unet = UNet(input_channels=1, output_channels=1, first_layer_features=16, depth=4)
        batch_size = 16
        lr_nn = 5e-3
        
    # NURBS parameters
    d_theta = 18 if is_2d else 15
    J = initial_coords.num_view_angles
    K = initial_coords.num_detectors
    
    # Initialize control points from observed coordinates
    control_points = list(initial_coords.control_points)
    
    # Enforce consistency conditions for 2D view angle uncertainty
    if is_2d:
        for j in range(J - d_theta, J + 1):
            for k in range(K):
                theta_j = initial_coords.theta[j]
                t_k = initial_coords.detector[k]
                # Evaluate function at consistent coordinate pair
                y_val = evaluate_target(theta_j, -t_k, initial_coords)
                # Create additional control points
                control_points.append([theta_j + math.pi, t_k, y_val])
                control_points.append([theta_j - math.pi, t_k, y_val])
                
    # Fix weights to 1.0 for 3D B-spline conversion
    if is_3d:
        for cp in control_points:
            cp.weight = 1.0
            
    # Optimizers
    optimizer_nn = Optimizer(unet.parameters(), lr=lr_nn)
    optimizer_coords = Optimizer(control_points, lr=1e-4)
    loss_fn = MSELoss()
    
    # Training loop
    for epoch in range(100):
        for batch in get_batches(projections, batch_size):
            if is_3d:
                batch = apply_augmentation(batch) # Random h/v flips, 90/180/270 rotations
            
            # Interpolate coordinates using NURBS basis functions
            coords = evaluate_nurbs(control_points, batch.input_coords)
            
            # Reconstruct volume
            volume = unet(coords, batch.projections)
            
            # Compute loss
            loss = loss_fn(volume, batch.ground_truth)
            
            # Add regularization for spline method
            if is_3d:
                loss += 0.6 * compute_spline_regularization(control_points)
            
            # Backpropagate and step
            optimizer_nn.zero_grad()
            optimizer_coords.zero_grad()
            loss.backward()
            optimizer_nn.step()
            optimizer_coords.step()
            
    return unet, control_points
```

**Edge Cases and Pitfalls:**
*   **Boundary Accuracy:** Creating additional control points ensures the locally supported NURBS basis functions have sufficient support around $0$ and $\pi$ radians, maintaining accuracy in the $[0, \pi]$ interval [S1, unofficial].
*   **Weight Optimization:** In 3D CT, basis function weights are fixed to $1.0$ and are not optimized [S1, unofficial].
*   **Regularization:** The regularization parameter $\lambda$ is set to $0.6$ for splines, differing from the $0.1$ used for implicit neural representations [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is dominated by U-Net forward/backward passes and NURBS evaluation [S1, unofficial].
*   **Memory Complexity:** Scales with the number of control points and U-Net parameters; the consistency condition adds $2 d_\Theta K$ control points [S1, unofficial].
*   **Performance:** The spline method achieves reconstruction SNRs comparable to or better than implicit neural and baseline methods under varying measurement noise and coordinate uncertainty SNRs (e.g., $19.5$ dB vs $19.4$ dB for 2D CT with Angle: $20$, Measurement: $25$) [S1, unofficial].
*   **Strengths:** Explicitly enforces physical consistency conditions (Radon transform symmetries) [S1, unofficial].
*   **Limitations:** Requires careful selection of NURBS degrees ($18$ for 2D learned dimension, $15$ for 3D tilt) and management of additional control points [S1, unofficial].

## Background
The method is described in "Different Differentiable Uncalibrated Imaging" (2022) [S1, unofficial]. It builds upon the concept of representing uncertain measurement coordinates as NURBS surfaces [G]. The approach addresses uncalibrated imaging challenges where view angles and detector positions are unknown by combining spline flexibility with deep learning U-Net reconstruction [S1, unofficial].
