# Voxel Data Interpolation and Sampling

Also called: Sample Grid, Sample Grid Index, getNextIntersectColor, getNextIntersectionGradient, getNextIntersectionScalar

## Overview
Voxel Data Interpolation and Sampling retrieves scalar values, gradients, and transformed colors at arbitrary 3D positions within a dense volume grid [S1, unofficial]. It maps continuous ray-casting coordinates to discrete grid indices, supporting nearest-neighbor and trilinear interpolation modes [S1, unofficial]. It provides the low-level access primitives (scalar and gradient retrieval) that higher-level transfer functions and shading models consume [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Continuous query position $\mathbf{p} = (x, y, z)$; Grid dimensions $X_{DIM}, Y_{DIM}, Z_{DIM}$; Interpolation mode $INTER\_MODE$; Transfer function mode $TRN\_MODE$ [S1, unofficial].
*   **Output:** Interpolated scalar value $v$, gradient vector $\mathbf{g}$, and optionally transformed color components [S1, unofficial].

**Data Structures:**
The volume data is stored in two parallel vectors [S1, unofficial]:
1.  `scalars`: `vector<float>` storing scalar values (e.g., density).
2.  `gradients`: `vector<glm::vec3>` storing pre-computed gradient vectors.

The index for a voxel at integer coordinates $(x, y, z)$ is calculated as [S1, unofficial]:
$$ index = x + (y \cdot X_{DIM}) + (z \cdot X_{DIM} \cdot Y_{DIM}) $$

**Parameters:**
*   $INTER\_MODE$: Controls interpolation. $1$ for trilinear interpolation, $2$ for nearest neighbor [S1, unofficial].
*   $TRN\_MODE$: Controls transfer function input. $1$ for $(Voxel Value, Voxel Value)$, $2$ for $(Voxel Value, Gradient Magnitude)$ [S1, unofficial].

**Steps:**
1.  **Boundary Check:** Determine the integer coordinates $(ix, iy, iz)$ of the query point. If any coordinate falls outside the grid bounds $[0, X_{DIM}-1]$, $[0, Y_{DIM}-1]$, or $[0, Z_{DIM}-1]$, return a default value of $(0,0,0,0)$ [S1, unofficial].
2.  **Value Retrieval:**
    *   If $INTER\_MODE = 2$ (Nearest Neighbor): Retrieve the scalar $v$ and gradient $\mathbf{g}$ at $(ix, iy, iz)$ using the index formula [S1, unofficial].
    *   If $INTER\_MODE = 1$ (Trilinear): Retrieve the 8 corner values and gradients, then compute the weighted sum based on fractional coordinates [S1, unofficial].
3.  **Transfer Function Preparation:**
    *   If $TRN\_MODE = 1$: Pass $(v, v)$ to the transfer function transformer [S1, unofficial].
    *   If $TRN\_MODE = 2$: Compute gradient magnitude $m = \|\mathbf{g}\|$. Clamp $m$ to $[0, 1]$. Scale by $256$. Pass $(v, m \cdot 256)$ to the transformer [S1, unofficial].

**Pseudocode:**
```python
def sample_voxel(p_x, p_y, p_z, scalars, gradients, x_dim, y_dim, z_dim, inter_mode, trn_mode):
    # 1. Boundary Check
    ix = int(p_x)
    iy = int(p_y)
    iz = int(p_z)
    
    if ix < 0 or ix >= x_dim or iy < 0 or iy >= y_dim or iz < 0 or iz >= z_dim:
        return 0.0, (0.0, 0.0, 0.0)

    # 2. Value Retrieval
    if inter_mode == 2: # Nearest Neighbor
        idx = ix + (iy * x_dim) + (iz * x_dim * y_dim)
        v = scalars[idx]
        g = gradients[idx]
    elif inter_mode == 1: # Trilinear
        fx = p_x - ix
        fy = p_y - iy
        fz = p_z - iz
        
        # Indices of the 8 enclosing corners [G]
        idx000 = ix + (iy * x_dim) + (iz * x_dim * y_dim)
        idx100 = idx000 + 1
        idx010 = idx000 + x_dim
        idx110 = idx010 + 1
        idx001 = idx000 + (x_dim * y_dim)
        idx101 = idx001 + 1
        idx011 = idx001 + x_dim
        idx111 = idx011 + 1
        
        # Trilinear interpolation weights [G]
        v = (scalars[idx000] * (1-fx)*(1-fy)*(1-fz) +
             scalars[idx100] * fx*(1-fy)*(1-fz) +
             scalars[idx010] * (1-fx)*fy*(1-fz) +
             scalars[idx110] * fx*fy*(1-fz) +
             scalars[idx001] * (1-fx)*(1-fy)*fz +
             scalars[idx101] * fx*(1-fy)*fz +
             scalars[idx011] * (1-fx)*fy*fz +
             scalars[idx111] * fx*fy*fz)
             
        g = (gradients[idx000] * (1-fx)*(1-fy)*(1-fz) +
             gradients[idx100] * fx*(1-fy)*(1-fz) +
             gradients[idx010] * (1-fx)*fy*(1-fz) +
             gradients[idx110] * fx*fy*(1-fz) +
             gradients[idx001] * (1-fx)*(1-fy)*fz +
             gradients[idx101] * fx*(1-fy)*fz +
             gradients[idx011] * (1-fx)*fy*fz +
             gradients[idx111] * fx*fy*fz)
    else:
        raise ValueError("Unknown interpolation mode")

    # 3. Transfer Function Preparation
    if trn_mode == 2:
        mag = (g[0]**2 + g[1]**2 + g[2]**2)**0.5
        mag = max(0.0, min(1.0, mag))
        scaled_mag = mag * 256.0
        # Transformer receives (v, scaled_mag)

    return v, g
```

**Edge Cases and Pitfalls:**
*   The original implementation defaults to nearest-neighbor sampling because the voxel intersection logic required for full trilinear interpolation was not yet implemented [S1, unofficial].
*   Gradient magnitude clamping to $[0, 1]$ before scaling prevents overflow in downstream transfer function transformers [S1, unofficial].

## Subtopics

### Sample Grid Index
Provides low-level access to actual values stored in the grid at integer coordinates without interpolation [S2, unofficial].

### Sample Grid
Computes the interpolated value at a continuous position in the grid, typically using the underlying interpolation logic [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ for nearest neighbor. $O(1)$ for trilinear, as it requires a constant number of memory accesses and arithmetic operations [S1, unofficial].
*   **Memory Complexity:** $O(N)$ where $N$ is the number of voxels, storing both scalar and gradient fields [S1, unofficial].
*   **Strengths:** Fast access; supports gradient-based shading which improves surface appearance [S1, unofficial].
*   **Limitations:** Pre-computed gradients increase memory bandwidth requirements [S1, unofficial].
*   **When to use:** When ray-casting requires smooth density transitions or gradient-based lighting [G]. When memory bandwidth allows storing auxiliary gradient data [G].

## Background
This method originates from early volume ray-casting implementations, specifically those processing CT scan data formats (`.ctscan`) [S1, unofficial]. It was developed to support 1D transfer functions and later extended to support gradient-based opacity control [S1, unofficial]. The concepts are also reflected in modern node-based geometry systems like Blender's Geometry Nodes, where `Sample Grid` and `Sample Grid Index` nodes provide similar functionality for field evaluation [S2, unofficial].
