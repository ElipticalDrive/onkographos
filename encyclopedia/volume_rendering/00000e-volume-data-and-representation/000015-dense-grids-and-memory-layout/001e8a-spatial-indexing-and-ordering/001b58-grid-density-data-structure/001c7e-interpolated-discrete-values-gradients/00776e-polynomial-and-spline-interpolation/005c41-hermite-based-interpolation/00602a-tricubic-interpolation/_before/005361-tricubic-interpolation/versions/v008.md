# Tricubic Interpolation
Also called: Tricubic Hermite Interpolation
## Overview
Tricubic interpolation is a higher-order method that employs cubic polynomials over a 4x4x4 neighborhood of 64 points to approximate smooth underlying functions with an accuracy of $O(h^4)$, where $h$ is the grid spacing [S1]. It provides $C^1$ continuity, reducing artifacts in gradient-sensitive tasks like volume rendering compared to the $C^0$ continuity of trilinear interpolation [S1]. It is chosen when differentiable outputs are required for visualization [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D grid of scalar values $V_{i,j,k}$ and their corresponding first-order gradients (tangents) $\nabla V_{i,j,k} = (\frac{\partial V}{\partial x}, \frac{\partial V}{\partial y}, \frac{\partial V}{\partial z})$ at each grid vertex. A query point $\mathbf{p} = (x, y, z)$.
*   **Output:** The interpolated scalar value $V(\mathbf{p})$ and optionally the interpolated gradient $\nabla V(\mathbf{p})$.

**Data Structures:**
For each grid vertex $(i, j, k)$, store:
1.  Scalar value $V_{i,j,k}$.
2.  Gradient vector $\mathbf{g}_{i,j,k} = (g_x, g_y, g_z)$.
*Note: The source [S2, unofficial] implies storing gradients alongside samples. The exact bit-packing or memory layout is Not given in the sources.*

**Numbered Steps:**
1.  **Locate Cell:** Identify the grid cell containing $\mathbf{p}$ such that $i \le x < i+1$, $j \le y < j+1$, $k \le z < k+1$.
2.  **Compute Local Coordinates:** Calculate fractional offsets $u = x - i$, $v = y - j$, $w = z - k$. These lie in $[0, 1)$.
3.  **Select Support:** Identify the 64 control points forming the 4x4x4 neighborhood centered around the cell. This includes vertices from $(i-1, j-1, k-1)$ to $(i+2, j+2, k+2)$.
4.  **Evaluate Basis Functions:** For each dimension, compute the 4 cubic Hermite basis functions $H_0(t), H_1(t), H_2(t), H_3(t)$ for the local coordinate $t \in \{u, v, w\}$.
    *   $H_0(t) = 2t^3 - 3t^2 + 1$
    *   $H_1(t) = -2t^3 + 3t^2$
    *   $H_2(t) = t^3 - 2t^2 + t$
    *   $H_3(t) = t^3 - t^2$
5.  **Compute Weights:** The weight for a control point at relative offset $(\Delta i, \Delta j, \Delta k)$ is the product of the basis functions corresponding to its position in the 1D support. For example, the weight for the point at $(i, j, k)$ is $H_0(u)H_0(v)H_0(w)$. The weight for the point at $(i+1, j, k)$ is $H_1(u)H_0(v)H_0(w)$. Gradients contribute to weights involving $H_2$ and $H_3$.
6.  **Weighted Summation:** Sum the contributions of all 64 points. The contribution of a scalar value $V$ at relative offset $(\Delta i, \Delta j, \Delta k)$ is $V \cdot H_{\Delta i}(u) H_{\Delta j}(v) H_{\Delta k}(w)$. The contribution of a gradient component (e.g., $\frac{\partial V}{\partial x}$) at relative offset $(\Delta i, \Delta j, \Delta k)$ is $\frac{\partial V}{\partial x} \cdot H_{\Delta i+1}(u) H_{\Delta j}(v) H_{\Delta k}(w)$ (assuming standard Hermite indexing where derivatives are associated with the next basis function).
7.  **Return Result:** The sum is $V(\mathbf{p})$.

**Parameters:**
*   Grid spacing $h$.

**Edge Cases:**
*   **Boundaries:** At the grid boundaries, the 4x4x4 neighborhood may extend outside the grid. Padding or clamping is required. Not given in the sources.
*   **Precision:** Higher-order polynomials can exhibit oscillations (Runge's phenomenon) if the data is not smooth. Not given in the sources.
*   **Degenerate Input:** If gradients are not available, the method cannot be applied as defined. Not given in the sources.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per query, but with a large constant factor due to 64 points and cubic evaluations.
*   **Memory Complexity:** Requires storing gradients in addition to values, doubling the memory footprint compared to scalar-only grids.
*   **Measured Performance:** Studies confirm tricubic's edge in accuracy over trilinear for upsampled 3D volumes, albeit with longer processing times [S1].
*   **Strengths:** $C^1$ continuity, $O(h^4)$ accuracy, reduced artifacts in gradient-sensitive tasks [S1].
*   **Limitations:** Increased computational expense, requires gradient data [S1].
*   **When to use:** When $C^1$ continuity is needed for differentiable outputs in visualization [S1].
*   **When not to use:** When performance is critical and $C^0$ continuity is sufficient (use trilinear) [S1].

## Background
Tricubic interpolation is a higher-order alternative to trilinear interpolation [S1]. It is used in medical imaging upsampling and volume rendering [S1]. The method is based on cubic Hermite patches [S2, unofficial].
