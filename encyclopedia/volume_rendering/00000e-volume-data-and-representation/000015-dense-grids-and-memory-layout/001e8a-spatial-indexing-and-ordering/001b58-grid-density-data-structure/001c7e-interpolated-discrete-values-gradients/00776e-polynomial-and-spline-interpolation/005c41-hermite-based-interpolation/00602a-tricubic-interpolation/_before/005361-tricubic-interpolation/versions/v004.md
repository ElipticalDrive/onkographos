# Tricubic Interpolation
Also called: Tricubic Hermite Interpolation

## Overview
Tricubic interpolation is a higher-order method that employs cubic polynomials over a 4x4x4 neighborhood of 64 points to approximate smooth underlying functions with an accuracy of $O(h^4)$, where $h$ is the grid spacing [S1]. It provides $C^1$ continuity, reducing artifacts in gradient-sensitive tasks like volume rendering, whereas trilinear interpolation only achieves $C^0$ continuity and second-order accuracy $O(h^2)$ [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A dense grid tensor $\mathbf{G}$ of shape $(D_x, D_y, D_z, C)$ containing scalar values and their spatial gradients (derivatives) at each voxel [S2, unofficial]. A query point $\mathbf{p} = (x, y, z) \in \mathbb{R}^3$.
*   **Output:** An interpolated value $V$ and optionally its gradient $\nabla V$ at $\mathbf{p}$ [S2, unofficial].

**Data Structures:**
The grid stores, for each voxel $(i, j, k)$, the value $V_{i,j,k}$ and the partial derivatives $\frac{\partial V}{\partial x}, \frac{\partial V}{\partial y}, \frac{\partial V}{\partial z}$ [S2, unofficial].

**Numbered Steps:**
1.  **Locate Support:** Compute the integer indices $i = \lfloor x \rfloor, j = \lfloor y \rfloor, k = \lfloor z \rfloor$ and fractional coordinates $u = x - i, v = y - j, w = z - k$ [S1][S2, unofficial]. Clamp indices to $[0, D_d-1]$ if necessary [S1].
2.  **Gather Data:** Retrieve the 64 control points from the $4 \times 4 \times 4$ neighborhood centered at $(i, j, k)$. For each neighbor $(i+dx, j+dy, k+dz)$ where $dx, dy, dz \in \{0, 1\}$, gather the value and the three partial derivatives [S1][S2, unofficial].
3.  **Basis Evaluation:** Compute the 16 1D Hermite basis functions for each dimension using the fractional coordinates $u, v, w$. The basis functions $H_0(t)$ and $H_1(t)$ for a coordinate $t \in [0, 1]$ are:
    $$ H_0(t) = 2t^3 - 3t^2 + 1 $$
    $$ H_1(t) = t^3 - 2t^2 + t $$
    [S2, unofficial]
4.  **Weighted Summation:** Combine the gathered values and derivatives using the tensor product of the basis functions. For a scalar field, the interpolated value $V(u,v,w)$ is:
    $$ V = \sum_{dx=0}^{1} \sum_{dy=0}^{1} \sum_{dz=0}^{1} \left( H_0(u)H_0(v)H_0(w) V_{i+dx,j+dy,k+dz} + H_1(u)H_0(v)H_0(w) \frac{\partial V}{\partial x} + H_0(u)H_1(v)H_0(w) \frac{\partial V}{\partial y} + H_0(u)H_0(v)H_1(w) \frac{\partial V}{\partial z} \right) $$
    [S2, unofficial]

**Pseudocode:**
```python
def tricubic_interpolate(grid, p):
    # p is (x, y, z)
    x, y, z = p
    i, j, k = floor(x), floor(y), floor(z)
    u, v, w = x - i, y - j, z - k
    
    # Clamp indices to valid range [0, D-1]
    i = clamp(i, 0, grid.Dx - 1)
    j = clamp(j, 0, grid.Dy - 1)
    k = clamp(k, 0, grid.Dz - 1)
    
    # Hermite basis functions
    def h0(t): return 2*t**3 - 3*t**2 + 1
    def h1(t): return t**3 - 2*t**2 + t
    
    result = 0.0
    for dx in [0, 1]:
        for dy in [0, 1]:
            for dz in [0, 1]:
                # Gather data from grid
                # Note: In a real implementation, gradients must be stored or computed
                val = grid[i+dx, j+dy, k+dz].value
                grad_x = grid[i+dx, j+dy, k+dz].grad_x
                grad_y = grid[i+dx, j+dy, k+dz].grad_y
                grad_z = grid[i+dx, j+dy, k+dz].grad_z
                
                # Compute weights
                w_val = h0(u) * h0(v) * h0(w)
                w_dx = h1(u) * h0(v) * h0(w)
                w_dy = h0(u) * h1(v) * h0(w)
                w_dz = h0(u) * h0(v) * h1(w)
                
                result += (w_val * val + 
                           w_dx * grad_x + 
                           w_dy * grad_y + 
                           w_dz * grad_z)
    return result
```

**Parameters:**
*   Grid spacing $h$: Determines the accuracy order $O(h^4)$ [S1].
*   Neighborhood size: Fixed at $4 \times 4 \times 4$ [S1].

**Edge Cases:**
*   **Boundary Conditions:** Indices falling outside the grid domain must be clamped or handled via periodic/constant boundary conditions [S1].
*   **Gradient Availability:** Standard voxel grids do not store gradients. If gradients are not pre-computed, they must be estimated (e.g., via finite differences), which may introduce noise or reduce accuracy [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Higher than trilinear due to 64 points and derivative calculations. Processing times are longer [S1].
*   **Memory Complexity:** Requires storage of gradients in addition to values, increasing memory footprint per voxel [S2, unofficial].
*   **Strengths:** $C^1$ continuity reduces artifacts in gradient-sensitive tasks; superior accuracy $O(h^4)$ for smooth functions [S1].
*   **Limitations:** Increased computational expense; requires gradient data [S1][S2, unofficial].
*   **When to use:** When $C^1$ continuity is needed for differentiable outputs in visualization [S1].
*   **When not to use:** For real-time applications with strict performance constraints where $C^0$ continuity is sufficient, or when gradient data is unavailable and expensive to compute [S1].

## Background
Tricubic interpolation is a higher-order alternative to trilinear interpolation, chosen in medical imaging upsampling and volume rendering for its smoothness [S1]. It was discussed in the context of Irradiance Volumes for Games, where Hermite patches were used to construct cubic patches from samples and gradients [S2, unofficial].
