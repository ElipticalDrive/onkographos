# Hermite Interpolation of Scalar Fields
Also called: C1-continuous Hermite Interpolation, Hermite Interpolation

## Overview
Hermite interpolation of scalar fields renders scalar-valued functions (such as height fields or signed distance fields) by storing partial derivatives alongside function values on a regular grid [S1, unofficial]. Unlike standard trilinear interpolation which yields only $C^0$ continuity, this method guarantees a globally $C^1$-continuous result by using Hermite basis functions to interpolate between samples [S1, unofficial]. It serves as a storage-efficient replacement for normal mapping, as surface normals can be derived directly from the stored gradient data without requiring additional texture memory [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A dense grid tensor $\mathbf{G}$ of shape $(D_x, D_y, D_z, C)$, where $C$ includes the scalar value and its partial derivatives. A query point $\mathbf{p} \in \mathbb{R}^3$.
*   **Output:** The interpolated scalar value $f(\mathbf{p})$ and optionally the gradient $\nabla f(\mathbf{p})$ for shading.

**Data Structures:**
The grid stores at each vertex $\mathbf{v}_{ijk}$:
1.  Scalar value $f_{ijk}$.
2.  Partial derivatives $\frac{\partial f}{\partial x}_{ijk}, \frac{\partial f}{\partial y}_{ijk}, \frac{\partial f}{\partial z}_{ijk}$.
3.  Mixed partial derivatives $\frac{\partial^2 f}{\partial x \partial y}, \frac{\partial^2 f}{\partial x \partial z}, \frac{\partial^2 f}{\partial y \partial z}$ (required for 3D continuity, approximated if not explicitly stored) [S1, unofficial].

**Steps:**
1.  **Locate Support:** Identify the enclosing voxel defined by indices $(i, j, k)$ such that $x_i \le p_x < x_{i+1}$, etc. Compute local coordinates $(u, v, w) \in [0, 1]^3$ relative to the voxel corner.
2.  **Gather Data:** Retrieve the 8 corner values and their associated derivative vectors from the grid. For 3D, this requires handling mixed partials. If mixed partials are not explicitly stored, approximate them using a method akin to Adini's finite difference scheme for parametric surface patches [S1, unofficial].
3.  **Basis Evaluation:** Compute the 1D Hermite basis functions for each dimension. For a local coordinate $t \in [0, 1]$, the basis functions for value and derivative are:
    $$
    h_0(t) = 2t^3 - 3t^2 + 1
    $$
    $$
    h_1(t) = t^3 - 2t^2 + t
    $$
    $$
    h_2(t) = -2t^3 + 3t^2
    $$
    $$
    h_3(t) = t^3 - t^2
    $$
    These are combined in 3D using the tensor product.
4.  **Weighted Summation:** Compute the interpolated value $f(\mathbf{p})$ by summing the contributions of the 8 corners, weighted by the product of the 1D basis functions corresponding to the value and derivatives at each corner.
    $$
    f(\mathbf{p}) = \sum_{m,n,o \in \{0,1\}} \left( h_{mn}(u) h_{no}(v) h_{op}(w) \cdot \text{Data}_{m,n,o} \right)
    $$
    Where $\text{Data}_{m,n,o}$ includes the value and derivative terms scaled by the grid spacing if coordinates are not normalized to unit length.
5.  **Shading:** Use the exact analytical normals of the reconstructed cubic Hermite surface as shading normals. The gradient $\nabla f(\mathbf{p})$ is computed by differentiating the basis functions and applying them to the stored derivative data [S1, unofficial].

**Pseudocode:**
```python
def hermite_basis(t):
    # Returns [h0, h1, h2, h3] for value and derivative weights
    t2 = t * t
    t3 = t2 * t
    h0 = 2 * t3 - 3 * t2 + 1
    h1 = t3 - 2 * t2 + t
    h2 = -2 * t3 + 3 * t2
    h3 = t3 - t2
    return h0, h1, h2, h3

def interpolate_hermite_3d(grid, p, spacing):
    # grid: 3D array of structs {val, dx, dy, dz, dxy, dxz, dyz}
    # p: query point (x, y, z)
    # spacing: voxel size (dx, dy, dz)
    
    # 1. Locate
    ix = floor(p.x / spacing.x)
    iy = floor(p.y / spacing.y)
    iz = floor(p.z / spacing.z)
    
    # Clamp indices to valid range [0, D-1]
    ix = clamp(ix, 0, grid.dim_x - 2)
    iy = clamp(iy, 0, grid.dim_y - 2)
    iz = clamp(iz, 0, grid.dim_z - 2)
    
    # Local coordinates
    u = (p.x - ix * spacing.x) / spacing.x
    v = (p.y - iy * spacing.y) / spacing.y
    w = (p.z - iz * spacing.z) / spacing.z
    
    # 2. Gather 8 corners
    corners = []
    for i in [0, 1]:
        for j in [0, 1]:
            for k in [0, 1]:
                idx = (ix + i, iy + j, iz + k)
                corners.append(grid[idx])
                
    # 3. Basis evaluation
    bu = hermite_basis(u)
    bv = hermite_basis(v)
    bw = hermite_basis(w)
    
    result_val = 0.0
    
    # 4. Weighted summation
    # Iterate through all 8 corners (indices 0..7)
    for idx in range(8):
        # Determine binary indices for this corner
        i_bit = (idx >> 2) & 1
        j_bit = (idx >> 1) & 1
        k_bit = idx & 1
        
        # Basis weights for this corner's position
        # h0 for value, h1/h3 for derivatives
        # Note: The derivative terms are multiplied by the grid spacing in physical units
        # if the stored derivatives are physical gradients. 
        # Here we assume stored derivatives are dF/dx, etc.
        
        # Basis product for the value component
        w_val = bu[i_bit] * bv[j_bit] * bw[k_bit]
        
        # Basis product for dx component (derivative w.r.t x)
        # Corresponds to h1 if i_bit=0, h3 if i_bit=1
        w_dx = bu[1 + i_bit] * bv[j_bit] * bw[k_bit]
        
        # Similarly for dy and dz
        w_dy = bu[i_bit] * bv[1 + j_bit] * bw[k_bit]
        w_dz = bu[i_bit] * bv[j_bit] * bw[1 + k_bit]
        
        # Mixed partials would require h1/h3 combinations for two dimensions
        # e.g., w_dxy = bu[1+i_bit] * bv[1+j_bit] * bw[k_bit]
        
        corner = corners[idx]
        
        # Accumulate value
        result_val += w_val * corner.val
        # result_val += w_dx * corner.dx * spacing.x # If derivatives are normalized differently
        # ... add other terms if computing full field approximation
        
    return result_val
```

**Edge Cases:**
*   **Mixed Partials:** In 3D, $C^1$ continuity requires mixed partial derivatives. If not stored, they must be approximated. Adini's method is suggested for this approximation [S1, unofficial].
*   **Boundary Conditions:** Indices outside $[0, D_d-1]$ must be clamped or handled via boundary conditions defined by the parent grid structure.

## Subtopics

### Floating Scale Surface Reconstruction (FSSR) Integration
In the context of Floating Scale Surface Reconstruction (FSSR), Hermite interpolation is used to improve surface quality. The original FSSR weighting function is not $C^1$-continuous; it is replaced with $w(r) = \frac{1}{12} (r - 3)^{12} (r + 1)^4$ to ensure $C^1$ continuity [S2]. While higher-order interpolants barely affect error in Poisson Surface Reconstruction (PSR) due to its B-spline basis, cubic Hermite interpolation significantly improves mean and RMS error and visual appearance in FSSR [S2].

## Operating characteristics
*   **Complexity:** Time complexity is constant $O(1)$ per query, involving 8 corner lookups and polynomial evaluations. Memory overhead is higher than trilinear interpolation, requiring storage of derivatives (and mixed partials) at each grid vertex.
*   **Performance:** Provides richer visual appearance than normal mapping without extra storage if normals are already part of the discrete field [S1, unofficial].
*   **Limitations:** Requires computation or storage of mixed partial derivatives for true 3D $C^1$ continuity. Approximations for mixed partials may introduce artifacts if not handled carefully [S1, unofficial].

## Background
The method was proposed to accelerate sphere tracing and rendering of scalar fields by replacing $C^0$ trilinear filtering with $C^1$ Hermite interpolation [S1, unofficial]. It generalizes to arbitrary orders and dimensions and is applicable to height field and signed distance field rendering [S1, unofficial]. The technique was also evaluated in the context of surface reconstruction algorithms like PSR and FSSR to analyze the impact of Hermite data on isosurface extraction [S2].
