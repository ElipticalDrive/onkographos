# Hermite Interpolation of Scalar Fields

Also called: C1-continuous Hermite Interpolation, Hermite Interpolation

## Overview
Hermite Interpolation of Scalar Fields renders scalar-valued functions (such as height fields and signed distance fields) by storing partial derivatives alongside function values on a regular grid, using Hermite interpolation between samples to guarantee a globally $C^1$-continuous result [S1, unofficial]. It differs from its siblings by explicitly utilizing the gradient information inherent in the scalar field to reconstruct shading normals, offering a storage-efficient replacement for normal mapping without requiring extra storage if normals are already part of the discrete samples [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A regular grid of scalar values $f$ and their partial derivatives $\nabla f$.
*   **Output:** A $C^1$-continuous scalar field approximation and exact surface normals for shading.

**Data Structures:**
Each grid node stores the scalar value and the three partial derivatives (for 3D) or two (for 2D). No additional structures are required if the normals are derived from the scalar field itself [S1, unofficial].

**Steps:**
1.  **Store Derivatives:** Store the partial derivatives of the scalar-valued function with the function values at each grid point [S1, unofficial].
2.  **Interpolate:** Use Hermite interpolation between the samples. For 3D, this involves deriving an approximation for mixed partial derivatives, akin to Adini's method for parametric surface patches [S1, unofficial].
3.  **Shade:** Use the exact normals of the reconstructed cubic Hermite surface as shading normals [S1, unofficial].

**Formulas:**
The method generalizes to arbitrary orders and dimensions [S1, unofficial]. For 3D first-order fields, mixed partial derivatives are approximated using a method akin to Adini's method [S1, unofficial]. Specific polynomial coefficients for the Hermite basis are not detailed in the sources, but the continuity is guaranteed by the storage of derivatives [S1, unofficial].

**Parameters:**
*   **Order:** The method generalizes to arbitrary orders, though cubic is implied for $C^1$ continuity in standard Hermite contexts [S1, unofficial].
*   **Dimension:** Works in arbitrary dimensions [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Mixed Derivatives:** In 3D, mixed partial derivatives must be approximated; the sources cite Adini's method as the approach but do not provide the specific formula [S1, unofficial].
*   **Storage:** While it claims no extra storage is needed if normals are part of the samples, this assumes the scalar field's gradient is available or computable from the same data [S1, unofficial].

## Subtopics

### Floating Scale Surface Reconstruction (FSSR) Integration
In FSSR, Hermite interpolation is implemented to improve surface reconstruction quality [S2]. The original FSSR weighting function is replaced with $w(r) = \frac{1}{12} (r - 3)^{12} (r + 1)^4$ to ensure $C^1$ continuity [S2]. This cubic interpolation improves mean and RMS error and visual appearance compared to quadratic methods in FSSR, although the maximum error can remain large [S2].

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Performance:** Hermite interpolation improves mean and RMS error and visual appearance in FSSR compared to quadratic methods [S2]. In PSR, higher-order interpolants barely make a difference because PSR represents the implicit function as the sum of second-order B-splines, which already reproduce quadratic functions along edges [S2].
*   **Strengths:** Storage-efficient replacement for normal mapping with richer visual appearance; does not necessarily require extra storage if surface normals are already part of the discrete field of samples [S1, unofficial]. Guarantees globally $C^1$-continuous results [S1, unofficial].
*   **Limitations:** In PSR, the benefit of higher-order interpolation is minimal due to the underlying B-spline representation [S2]. Maximum error can remain large in FSSR with cubic interpolation [S2].
*   **When to use:** When $C^1$ continuity is required for smooth shading and the scalar field's gradient is available or easily computable [S1, unofficial].

## Background
The method was proposed to address the limitation of bi- or trilinear filtering, which results in $C^0$ approximations, by storing partial derivatives with function values to guarantee $C^1$ continuity [S1, unofficial]. It is applicable to height field and signed distance field rendering [S1, unofficial]. The approach generalizes to arbitrary orders and dimensions [S1, unofficial].
