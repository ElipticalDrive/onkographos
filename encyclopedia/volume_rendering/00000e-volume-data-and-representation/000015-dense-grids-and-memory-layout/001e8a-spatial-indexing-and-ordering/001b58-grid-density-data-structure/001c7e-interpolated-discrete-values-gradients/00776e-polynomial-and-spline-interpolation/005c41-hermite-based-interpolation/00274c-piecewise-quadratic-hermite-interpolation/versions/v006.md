# Piecewise Quadratic Hermite Interpolation

Also called: Piecewise Quadratic Bézier Hermite Interpolation, Quadratic Polynomial Interpolation for SCALIS

## Overview
This method interpolates a normalized scalar field within a 1D interval using two connected piecewise quadratic Bézier curves to satisfy Hermite data (value and derivative) at both endpoints [S1]. It solves the incompatibility of single quadratic interpolation with four constraints (two values, two derivatives) by splitting the interval, providing a numerically stable and efficient alternative to cubic interpolation for root isolation in volume rendering [S1]. It is specifically designed for use with the SCALIS ray marching algorithm [S1].

## How it works
**Inputs:**
*   Interval endpoints $t_{begin}, t_{end} \in \mathbb{R}$.
*   Hermite data at endpoints: $H_{begin} = (h_1, h'_1)$ and $H_{end} = (h_2, h'_2)$, where $h$ is the normalized field value and $h'$ is the derivative with respect to the parameter $t$ [S1].
*   Interval length $L = t_{end} - t_{begin}$ [S1].

**Outputs:**
*   A continuous, piecewise quadratic function $P(t)$ defined on $[t_{begin}, t_{end}]$ that satisfies $P(t_{begin})=h_1, P'(t_{begin})=h'_1, P(t_{end})=h_2, P'(t_{end})=h'_2$ [S1].

**Data Structures:**
The interpolant is defined by six control points $Q_0, \dots, Q_5$ for two quadratic Bézier curves.
*   Curve 1 (first half): Control points $Q_0, Q_1, Q_2$.
*   Curve 2 (second half): Control points $Q_2, Q_3, Q_4, Q_5$? No, the source specifies "six control points $Q_{i=0..5}$ (three for each of the Bezier curves)". A quadratic Bézier curve has 3 control points. Thus:
    *   Curve 1: $Q_0, Q_1, Q_2$.
    *   Curve 2: $Q_3, Q_4, Q_5$.
    *   Continuity constraint: $Q_2 = Q_3$ [S1].

**Pseudocode:**

```python
def piecewise_quadratic_hermite(t_begin, t_end, h1, h_prime1, h2, h_prime2):
    """
    Returns the control points ordinates for the piecewise quadratic Hermite interpolation.
    Returns: (Q0, Q1, Q2, Q3, Q4, Q5) where Q2 == Q3.
    """
    L = t_end - t_begin
    
    # Control points abscissas (t-coordinates)
    # Curve 1: Q0 at t_begin, Q1 at t_mid, Q2 at t_mid
    # Curve 2: Q3 at t_mid, Q4 at t_mid, Q5 at t_end
    # Note: Q1 and Q2 share t_mid. Q3 and Q4 share t_mid.
    t_mid = t_begin + L / 2.0
    
    # Ordinate of Q0 (start of first curve)
    Q0 = h1
    
    # Ordinate of Q1 (middle of first curve)
    # Derived from h1 and h_prime1
    Q1 = h1 + (L / 4.0) * h_prime1
    
    # Ordinate of Q4 (middle of second curve)
    # Derived from h2 and h_prime2
    Q4 = h2 - (L / 4.0) * h_prime2
    
    # Ordinate of Q2 and Q3 (shared control point at t_mid)
    # Derived from continuity and smoothness (average of Q1 and Q4)
    Q2 = 0.5 * (Q1 + Q4)
    Q3 = Q2
    
    # Ordinate of Q5 (end of second curve)
    Q5 = h2
    
    return {
        "Q0": {"t": t_begin, "h": Q0},
        "Q1": {"t": t_mid, "h": Q1},
        "Q2": {"t": t_mid, "h": Q2},
        "Q3": {"t": t_mid, "h": Q3},
        "Q4": {"t": t_mid, "h": Q4},
        "Q5": {"t": t_end, "h": Q5}
    }

def evaluate_piecewise_quadratic_hermite(t, t_begin, t_end, h1, h_prime1, h2, h_prime2):
    """
    Evaluates the interpolated value at parameter t in [t_begin, t_end].
    """
    L = t_end - t_begin
    t_mid = t_begin + L / 2.0
    
    # Calculate control point ordinates
    Q0 = h1
    Q1 = h1 + (L / 4.0) * h_prime1
    Q4 = h2 - (L / 4.0) * h_prime2
    Q2 = 0.5 * (Q1 + Q4)
    
    if t <= t_mid:
        # First curve: Q0, Q1, Q2 on [t_begin, t_mid]
        # Local parameter u in [0, 1]
        # t = t_begin + u * (L/2) => u = (t - t_begin) / (L/2)
        u = (t - t_begin) / (L / 2.0)
        # Quadratic Bézier: (1-u)^2 P0 + 2(1-u)u P1 + u^2 P2
        val = (1 - u)**2 * Q0 + 2 * (1 - u) * u * Q1 + u**2 * Q2
    else:
        # Second curve: Q2, Q4, Q5 on [t_mid, t_end]
        # Note: Control points are Q3(Q2), Q4, Q5
        # Local parameter u in [0, 1]
        # t = t_mid + u * (L/2) => u = (t - t_mid) / (L/2)
        u = (t - t_mid) / (L / 2.0)
        val = (1 - u)**2 * Q2 + 2 * (1 - u) * u * Q4 + u**2 * Q5
        
    return val
```

**Edge Cases and Pitfalls:**
*   **Incompatible Hermite Data:** Single quadratic interpolation cannot satisfy arbitrary Hermite data (4 constraints, 3 DOF). This method avoids this by splitting the interval [S1].
*   **Missed Isovalues:** Polynomial interpolation may underestimate field variations, causing missed isosurface crossings. This is addressed by using Rational Bézier curves in the root isolation oracle [S1].
*   **Precision:** The method is numerically stable and efficient compared to cubic interpolation [S1].

## Subtopics

### Rational Bézier Oracle for Root Isolation
A heuristic used when polynomial interpolation might overestimate normalized field values (e.g., large radius variations), potentially missing the isosurface [S1]. It uses rational Bézier curves to ensure the interpolation is arbitrarily closer to the control polygon, increasing the chance of detecting an isovalue crossing until a root is isolated [S1].
*   **Definition:** Uses rational Bézier curves instead of polynomial curves for root estimation [S1].
*   **Steps:**
    1.  Use rational Bézier curves for interpolation [S1].
    2.  Set the weight of the middle control point to 3 [S1].
    3.  Compute roots using the same method as for polynomials (since poles are not in the range of interest) [S1].
    4.  Continue using rational curves until a sign change exists between interval endpoints (root isolated) [S1].
*   **Pitfall:** Polynomial interpolation can present smaller variations than the actual field function, resulting in possible missed isovalue crossings [S1].

## Operating characteristics
*   **Time Complexity:** More efficient than cubic interpolation due to simpler root computation [S1].
*   **Memory Complexity:** Requires storing 6 control points per interval (or derived values) [S1].
*   **Performance:** For Cauchy kernels, it yields much better interpolations for small numbers of subdivisions compared to cubic interpolation on the original field [S1].
*   **Strengths:** Numerically stable, exact interpolation in specific cases (due to field normalization), efficient [S1].
*   **Limitations:** Requires interval splitting for general Hermite data; potential for missed isosurfaces without rational Bézier heuristic [S1].
*   **When to use:** When high efficiency and stability are required for root isolation in volume rendering, particularly with SCALIS [S1].
*   **When not to use:** When exact cubic interpolation is required and performance is not a constraint [S1].

## Background
This method is part of the SCALIS (Scale-Invariant Integral Surfaces) algorithm [S1]. It was introduced to address the limitations of cubic interpolation in the context of ray tracing scale-invariant integral surfaces, specifically regarding numerical stability and efficiency [S1]. The paper "Fast Ray Tracing of Scale‐Invariant Integral Surfaces" describes the method in detail [S1].
