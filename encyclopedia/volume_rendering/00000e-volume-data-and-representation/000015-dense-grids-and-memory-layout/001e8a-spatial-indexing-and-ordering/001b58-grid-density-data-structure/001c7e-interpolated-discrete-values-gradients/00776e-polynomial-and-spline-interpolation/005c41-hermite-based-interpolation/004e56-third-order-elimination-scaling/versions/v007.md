# Third Order Elimination (Scaling)

Also called: Scaling, PSR Scaling

## Overview
Third Order Elimination (Scaling) is a quadratic interpolation method that derives a second-order polynomial from a cubic Hermite basis by scaling the input derivatives to force the third-order coefficient to zero [S1]. It solves the problem of fitting a smooth curve through two values and their derivatives while strictly enforcing a quadratic shape, which is useful in implicit surface reconstruction where cubic terms may introduce unwanted inflection points [S1]. It is distinguished from its sibling [Third Order Elimination (Offset)](1519-third-order-elimination-offset.md) by using a multiplicative scaling factor rather than an additive offset, and from [Least-Squares Derivatives](1520-least-squares-derivatives.md) by its direct algebraic elimination approach rather than optimization [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Two scalar values $v_0, v_1$ at local coordinates $t=0$ and $t=1$, and their corresponding derivatives $d_0, d_1$.
*   **Outputs:** A quadratic polynomial $p(t) = a_0 + a_1 t + a_2 t^2$ that interpolates the values and uses the scaled derivatives.

**Data Structures:**
No complex structures are required. The method operates on scalar values and derivatives.

**Steps:**
1.  **Calculate Scaling Factor:** Compute the scaling factor $s$ that eliminates the cubic term $a_3$ from the underlying cubic Hermite formulation. The condition for eliminating $a_3$ is derived from the constraint that the second derivative of the cubic term must balance the value differences relative to the derivatives [S1]:
    $$ 2v_0 - 2v_1 + s \cdot d_0 + s \cdot d_1 = 0 $$
    Solving for $s$:
    $$ s = \frac{2v_1 - 2v_0}{d_0 + d_1} $$
2.  **Scale Derivatives:** Multiply the original derivatives by $s$:
    $$ d'_0 = s \cdot d_0 $$
    $$ d'_1 = s \cdot d_1 $$
3.  **Construct Quadratic Polynomial:** Using the scaled derivatives $d'_0, d'_1$ and values $v_0, v_1$, determine the quadratic coefficients $a_0, a_1, a_2$.
    *   $a_0 = v_0$
    *   $a_1 = d'_0$
    *   $a_2 = \frac{d'_1 - d'_0}{2}$
    *   *Note:* This assumes the standard Hermite-to-polynomial conversion where $p'(0)=d'_0$ and $p'(1)=d'_1$. For a quadratic $p(t) = a_0 + a_1 t + a_2 t^2$, $p'(t) = a_1 + 2a_2 t$. Thus $p'(0)=a_1=d'_0$ and $p'(1)=a_1+2a_2=d'_1 \implies a_2 = (d'_1-d'_0)/2$. The value constraint $p(1)=v_1$ is satisfied by the derivation of $s$ [S1].

**Pseudocode:**
```python
def third_order_elimination_scaling(v0, v1, d0, d1):
    """
    Interpolate using Third Order Elimination (Scaling).
    Returns coefficients a0, a1, a2 for p(t) = a0 + a1*t + a2*t^2.
    """
    # Step 1: Calculate scaling factor s
    denominator = d0 + d1
    
    # Edge case: If derivatives cancel out, the solution is unstable.
    # [G] In practice, check for near-zero denominator to avoid division by zero.
    if abs(denominator) < 1e-9:
        # Fallback to linear interpolation or handle error
        # [G] The source notes this instability but does not specify a fallback.
        # We return a linear fit as a safe default.
        a0 = v0
        a1 = v1 - v0
        a2 = 0.0
        return a0, a1, a2

    s = (2.0 * v1 - 2.0 * v0) / denominator
    
    # Step 2: Scale derivatives
    d0_scaled = s * d0
    d1_scaled = s * d1
    
    # Step 3: Construct quadratic coefficients
    a0 = v0
    a1 = d0_scaled
    a2 = (d1_scaled - d0_scaled) / 2.0
    
    return a0, a1, a2
```

**Parameters:**
*   None. The method is fully determined by the input data.

**Edge Cases and Pitfalls:**
*   **Instability:** The solution becomes unstable if $d_0 + d_1 \approx 0$ (derivatives cancel each other out) [S1]. This occurs when the derivatives have opposite signs and similar magnitudes. The source notes that for the indicator function in the PSR code, this is unlikely because the gradient is steep and derivatives do not typically have opposite signs near the isosurface [S1].

## Subtopics

### Third Order Elimination (Offset)
A quadratic method obtained by adding an offset $o$ to derivatives to eliminate the third order coefficient $a_3$. It solves $2v_0 - 2v_1 + (d_0 + o) + (d_1 + o) = 0$, yielding $o = (2v_1 - 2v_0 - d_0 - d_1) / 2$. This solution is equivalent to the Least-Squares Derivatives method. Choose this when additive adjustment of derivatives is preferred or when the scaling method's division by zero risk is unacceptable. Link: [Third Order Elimination (Offset)](1519-third-order-elimination-offset.md).

## Operating characteristics
*   **Time Complexity:** $O(1)$ arithmetic operations.
*   **Memory Complexity:** $O(1)$ auxiliary storage.
*   **Strengths:** Produces a strictly quadratic polynomial, eliminating cubic inflection points. Simple to implement.
*   **Limitations:** Numerically unstable when $d_0 + d_1 \approx 0$. Not suitable for general-purpose interpolation where derivative signs are arbitrary.
*   **When to use:** Implicit surface interpolation (e.g., indicator functions) where derivatives are known to be consistent in sign and a quadratic fit is desired [S1].
*   **When not to use:** When derivatives may cancel out or when a higher-order smoothness is required.

## Background
The method was introduced in the context of accurate isosurface interpolation with Hermite data [S1]. It is implemented in the PSR (Polynomial Surface Reconstruction) code for interpolating the indicator function [S1]. The approach is part of a family of techniques that modify cubic Hermite bases to enforce lower-order polynomial constraints.
