# Voxel Trilinear Interpolation (SIMD)

Also called: SIMD Trilinear Sampling, Trilinear Interpolation with AVX, Trilinear Volume Interpolation, Trilinear Voxel Interpolation

## Overview
Voxel Trilinear Interpolation (SIMD) retrieves scalar or vector values from a 3D volume grid at arbitrary floating-point coordinates by interpolating the eight corner values of the enclosing voxel cell using Single Instruction, Multiple Data (SIMD) instructions [S3, unofficial]. It builds on [Grid Cell Collection via Corner Indices](1518-grid-cell-collection-via-corner-indices.md) by fetching the eight surrounding voxel values and combining them with fractional weights [S1, unofficial]. It sets itself apart from discrete nearest-neighbor sampling by producing smooth, continuous fields without lumpy artifacts, and from higher-order splines by maintaining O(1) memory access patterns and lower computational overhead [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume data array (dense grid or brick), query coordinates $(u, v, w)$, and volume dimensions $(N_x, N_y, N_z)$ [S1, S3, unofficial].
*   **Output:** The interpolated value (scalar or vector) at the query point [S1, S3, unofficial].

**Data Structures:**
*   **Volume Data:** Stored in a 1D array in row-major order [S3, unofficial]. For a brick of size $(B_x, B_y, B_z)$, the data size is $(B_x+1) \times (B_y+1) \times (B_z+1)$ elements [S3, unofficial].
*   **Strides:** Linear indexing uses strides: $x_{next} = 1$, $y_{next} = N_x$, $z_{next} = N_x \times N_y$ [S3, unofficial].
*   **SIMD Registers:** 128-bit registers (e.g., AVX `__m128`) used to hold multiple float components or bytes for parallel arithmetic [S3, unofficial].

**Numbered Steps:**
1.  **Coordinate Normalization:** Convert world or normalized coordinates to relative positions within the brick or grid [S3, unofficial].
2.  **Index Calculation:** Compute the integer grid indices $(i_x, i_y, i_z)$ and fractional offsets $(f_x, f_y, f_z)$:
    $$ i_x = \lfloor u \cdot (N_x - 1) \rfloor, \quad f_x = u \cdot (N_x - 1) - i_x $$
    (Similarly for $y$ and $z$) [S1, S2, S3, unofficial].
3.  **Boundary Clamping:** Clamp indices to valid ranges $[0, nGrids.dim - 1]$ to prevent out-of-bounds access [S2, unofficial]. If any index component is less than 0 or greater than or equal to dimensions, return 0.0f [S3, unofficial].
4.  **Corner Fetching:** Calculate the linear base index for the lower corner $(i_x, i_y, i_z)$ and fetch the 8 corner values:
    $$ \text{idx} = i_z \cdot z_{next} + i_y \cdot y_{next} + i_x \cdot x_{next} $$
    Values: $f_{000}, f_{001}, f_{010}, f_{011}, f_{100}, f_{101}, f_{110}, f_{111}$ [S3, unofficial].
5.  **SIMD Weight Preparation:** Broadcast fractional coordinates into SIMD registers [S3, unofficial].
    *   $w_x = f_x$
    *   $w_y = f_y$
    *   $w_z = f_z$
    *   Compute complementary weights: $1-w_x, 1-w_y, 1-w_z$ [S3, unofficial].
6.  **Parallel Interpolation:**
    *   Load corner values into SIMD registers [S3, unofficial].
    *   Perform bilinear interpolation on the bottom face ($z=0$) and top face ($z=1$) using X and Y weights [S1, unofficial].
    *   Interpolate between the bottom and top results using the Z weight [S1, unofficial].
7.  **Final Value:** Return the interpolated scalar or vector component [S3, unofficial].

**Formulas:**
The standard trilinear interpolation formula for a scalar value $V$ is:
$$ V = f_{000}(1-f_x)(1-f_y)(1-f_z) + f_{001}(1-f_x)(1-f_y)f_z + f_{010}(1-f_x)f_y(1-f_z) + f_{011}(1-f_x)f_y f_z + f_{100}f_x(1-f_y)(1-f_z) + f_{101}f_x(1-f_y)f_z + f_{110}f_x f_y(1-f_z) + f_{111}f_x f_y f_z $$
Where $f_{ijk}$ are the 8 corner values and $f_x, f_y, f_z$ are the fractional coordinates [S3, unofficial].

**Pseudocode:**
```python
import math

def voxel_trilinear_simd(volume_data, dims, u, v, w):
    """
    Performs trilinear interpolation with SIMD-style weight application.
    volume_data: 1D list/array of floats.
    dims: (Nx, Ny, Nz) grid dimensions.
    u, v, w: Query coordinates in [0, 1].
    """
    # 1. Normalize and scale to grid indices
    scale_x = dims[0] - 1
    scale_y = dims[1] - 1
    scale_z = dims[2] - 1
    
    pos_x = u * scale_x
    pos_y = v * scale_y
    pos_z = w * scale_z
    
    # 2. Integer indices and fractional parts
    ix = int(math.floor(pos_x))
    iy = int(math.floor(pos_y))
    iz = int(math.floor(pos_z))
    
    fx = pos_x - ix
    fy = pos_y - iy
    fz = pos_z - iz
    
    # 3. Boundary Clamping
    if ix < 0 or iy < 0 or iz < 0 or ix >= dims[0] or iy >= dims[1] or iz >= dims[2]:
        return 0.0
    
    # Clamp indices for fetching to [0, nGrids.dim - 1]
    x0 = max(0, min(ix, dims[0] - 1))
    x1 = max(0, min(ix + 1, dims[0] - 1))
    y0 = max(0, min(iy, dims[1] - 1))
    y1 = max(0, min(iy + 1, dims[1] - 1))
    z0 = max(0, min(iz, dims[2] - 1))
    z1 = max(0, min(iz + 1, dims[2] - 1))
    
    # 4. Calculate Strides and Base Index
    stride_x = 1
    stride_y = dims[0]
    stride_z = dims[0] * dims[1]
    
    base_idx = z0 * stride_z + y0 * stride_y + x0 * stride_x
    
    # 5. Fetch 8 Corners
    v000 = volume_data[base_idx]
    v100 = volume_data[base_idx + stride_x]
    v010 = volume_data[base_idx + stride_y]
    v110 = volume_data[base_idx + stride_y + stride_x]
    v001 = volume_data[base_idx + stride_z]
    v101 = volume_data[base_idx + stride_z + stride_x]
    v011 = volume_data[base_idx + stride_z + stride_y]
    v111 = volume_data[base_idx + stride_z + stride_y + stride_x]
    
    # 6. SIMD-style Interpolation (Simulated with scalar ops for clarity)
    w_x = fx
    w_y = fy
    w_z = fz
    w_x_inv = 1.0 - w_x
    w_y_inv = 1.0 - w_y
    w_z_inv = 1.0 - w_z
    
    # Interpolate along X for bottom face (z0)
    v00 = w_x_inv * v000 + w_x * v100
    v10 = w_x_inv * v010 + w_x * v110
    
    # Interpolate along X for top face (z1)
    v01 = w_x_inv * v001 + w_x * v101
    v11 = w_x_inv * v011 + w_x * v111
    
    # Interpolate along Y for bottom and top
    v0 = w_y_inv * v00 + w_y * v10
    v1 = w_y_inv * v01 + w_y * v11
    
    # Interpolate along Z
    final = w_z_inv * v0 + w_z * v1
    
    return final
```

**Parameters:**
*   **Block Dimensions:** In GPU implementations (CUDA), block dimensions are often fixed, e.g., `BLOCK_SIZE = 8`, resulting in `threads = {8, 8, 8}` (512 threads per block) [S2, unofficial].
*   **Grid Dimensions:** Calculated based on the number of points $N_p$ and maximum threads per axis (e.g., `MAX_THREADS_AXIS = 128`) [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Indices must be clamped to `[0, nGrids.dim - 1]` to prevent out-of-bounds memory access [S2, unofficial]. If any index component is less than 0 or greater than or equal to dimensions, return 0.0f [S3, unofficial].

## Background
Voxel trilinear interpolation is a fundamental technique in volume rendering and computer graphics for sampling dense 3D grids [S5, unofficial]. The SIMD optimization leverages CPU vector instructions (like AVX) to accelerate the interpolation process, which is a bottleneck in real-time applications [S3, unofficial]. The method is widely used in tools like `torchmcubes` for marching cubes on GPU [S2, unofficial], and in parallel volume renderers [S3, unofficial].
