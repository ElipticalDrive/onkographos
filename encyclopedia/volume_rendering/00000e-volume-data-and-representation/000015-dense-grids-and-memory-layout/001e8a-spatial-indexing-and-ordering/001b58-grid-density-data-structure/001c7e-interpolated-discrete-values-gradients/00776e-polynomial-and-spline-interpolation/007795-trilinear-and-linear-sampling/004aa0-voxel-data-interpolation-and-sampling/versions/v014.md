# Voxel Data Interpolation and Sampling

Also called: Sample Grid, Sample Grid Index, getNextIntersectColor, getNextIntersectionGradient, getNextIntersectionScalar

## Overview
This method retrieves scalar values, gradients, and transformed colors at arbitrary 3D positions within a dense volume grid, supporting configurable interpolation and transfer function modes [S1, unofficial][S2, unofficial]. It differs from its siblings by explicitly exposing both interpolated field values and their spatial derivatives (gradients) to a transfer function transformer, whereas methods like [Grid Cell Collection via Corner Indices](1518-grid-cell-collection-via-corner-indices.md) focus primarily on raw data access and [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) focuses on higher-order continuity without necessarily exposing gradient magnitudes for transfer functions directly in the sampling step.

## How it works
**Inputs and Outputs:**
*   **Input:** Query point $\mathbf{p} = (x, y, z)$ in grid coordinates; grid dimensions $D_x, D_y, D_z$; interpolation mode `INTER_MODE`; transfer function mode `TRN_MODE`.
*   **Output:** Transformed color/opacity tuple (e.g., RGBA) or raw scalar/gradient pair, depending on the calling context.

**Data Structures:**
The volume data is stored in two contiguous vectors [S1, unofficial]:
1.  `scalars`: `std::vector<float>` containing scalar values for each voxel.
2.  `gradients`: `std::vector<glm::vec3>` containing 3D gradient vectors for each voxel.

The index for a voxel at integer coordinates $(x, y, z)$ is calculated as [S1, unofficial]:
$$ \text{index} = x + (y \cdot D_x) + (z \cdot D_x \cdot D_y) $$

**Parameters:**
*   `INTER_MODE`: Controls interpolation. `1` for trilinear interpolation, `2` for nearest neighbor [S1, unofficial].
*   `TRN_MODE`: Controls transfer function input. `1` for input `(Voxel Value, Voxel Value)`, `2` for input `(Voxel Value, Gradient Magnitude)` [S1, unofficial].

**Steps:**
1.  **Boundary Check:** Determine if the query point $\mathbf{p}$ falls within the grid bounds $[0, D_x-1] \times [0, D_y-1] \times [0, D_z-1]$. If out of bounds, return a default value (e.g., $(0,0,0,0)$) [S1, unofficial].
2.  **Data Retrieval:**
    *   If `INTER_MODE` is `2` (nearest neighbor), retrieve the scalar $V$ and gradient $\mathbf{G}$ at the nearest integer coordinates $(\lfloor x \rfloor, \lfloor y \rfloor, \lfloor z \rfloor)$ using the index formula [S1, unofficial].
    *   If `INTER_MODE` is `1` (trilinear), gather the 8 corner values and gradients of the enclosing voxel, compute trilinear weights based on fractional coordinates, and interpolate $V$ and $\mathbf{G}$ [S1, unofficial]. *Note: Some implementations default to nearest neighbor if voxel intersection logic is not fully implemented [S1, unofficial].*
3.  **Transfer Function Preparation:**
    *   If `TRN_MODE` is `1`, pass the scalar $V$ as both the primary and secondary input to the transfer function transformer [S1, unofficial].
    *   If `TRN_MODE` is `2`, compute the gradient magnitude $M = \|\mathbf{G}\|$. Clamp $M$ to $[0, 1]$. Scale the clamped magnitude by 256. Pass $(V, 256 \cdot M)$ to the transfer function transformer [S1, unofficial].
4.  **Transformation:** Apply the 1D transfer function (or transformer) to the prepared inputs to generate the final color and opacity [S1, unofficial].

**Pseudocode:**
```python
def sample_voxel(p: Vector3, grid_dims: Tuple[int, int, int], 
                 scalars: List[float], gradients: List[Vector3],
                 inter_mode: int, trn_mode: int) -> Tuple[float, float, float, float]:
    """
    Samples voxel data and applies transfer function.
    Returns RGBA tuple.
    """
    x, y, z = p.x, p.y, p.z
    Dx, Dy, Dz = grid_dims
    
    # 1. Boundary Check
    if not (0 <= x < Dx and 0 <= y < Dy and 0 <= z < Dz):
        return (0.0, 0.0, 0.0, 0.0)

    # 2. Data Retrieval
    if inter_mode == 2: # Nearest Neighbor
        ix, iy, iz = int(round(x)), int(round(y)), int(round(z))
        # Clamp indices to valid range for safety
        ix = max(0, min(ix, Dx - 1))
        iy = max(0, min(iy, Dy - 1))
        iz = max(0, min(iz, Dz - 1))
        
        idx = ix + (iy * Dx) + (iz * Dx * Dy)
        scalar_val = scalars[idx]
        grad_vec = gradients[idx]
    else: # Trilinear (inter_mode == 1)
        # Implementation note: Full trilinear requires gathering 8 neighbors.
        # The source code snippet indicates this might not be fully implemented 
        # or defaults to nearest neighbor behavior in some contexts [S1, unofficial].
        # Below is the standard trilinear logic assuming it is implemented.
        ix, iy, iz = int(floor(x)), int(floor(y)), int(floor(z))
        fx, fy, fz = x - ix, y - iy, z - iz
        
        # Gather 8 corners
        # ... (Gathering logic omitted for brevity, see standard trilinear) ...
        # scalar_val = interpolate_8_corners(scalars, ix, iy, iz, fx, fy, fz, Dx, Dy, Dz)
        # grad_vec = interpolate_8_corners_vec3(gradients, ix, iy, iz, fx, fy, fz, Dx, Dy, Dz)
        
        # Fallback to nearest if trilinear not implemented [G]
        ix, iy, iz = int(round(x)), int(round(y)), int(round(z))
        ix = max(0, min(ix, Dx - 1))
        iy = max(0, min(iy, Dy - 1))
        iz = max(0, min(iz, Dz - 1))
        idx = ix + (iy * Dx) + (iz * Dx * Dy)
        scalar_val = scalars[idx]
        grad_vec = gradients[idx]

    # 3. Transfer Function Preparation
    if trn_mode == 1:
        input1 = scalar_val
        input2 = scalar_val
    elif trn_mode == 2:
        input1 = scalar_val
        grad_mag = length(grad_vec)
        grad_mag_clamped = clamp(grad_mag, 0.0, 1.0)
        input2 = grad_mag_clamped * 256.0
    else:
        # Default fallback [G]
        input1 = scalar_val
        input2 = scalar_val

    # 4. Transformation
    # Apply 1D transfer function transformer
    color = apply_transfer_function(input1, input2)
    
    return color
```

## Operating characteristics
*   **Time Complexity:** $O(1)$ for nearest neighbor. $O(1)$ for trilinear (constant number of memory accesses and arithmetic operations).
*   **Memory Complexity:** $O(N)$ where $N$ is the number of voxels, storing both scalar and gradient vectors.
*   **Strengths:** Direct access to gradient information allows for more sophisticated transfer functions (e.g., edge highlighting) [S1, unofficial].
*   **Limitations:** Trilinear interpolation implementation may be incomplete in some reference codebases, defaulting to nearest neighbor [S1, unofficial]. Gradient computation must be pre-calculated or computed on-the-fly, adding overhead.

## Background
This method originates from academic volume raycasting implementations, specifically the CSE-333 Computer Graphics course project [S1, unofficial]. It is also reflected in modern procedural geometry systems like Blender's Geometry Nodes, which provide "Sample Grid" and "Sample Grid Index" nodes for evaluating volume fields [S2, unofficial].
