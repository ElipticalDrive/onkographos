# Polynomial and Spline Interpolation

Also called: Grid-based Interpolation, Basis Function Interpolation

## Overview
Polynomial and Spline Interpolation provides a continuous scalar or vector field from discrete grid data by evaluating weighted sums of basis functions over a local support region [S1][S2, S3, S4, unofficial]. It solves the problem of mapping arbitrary continuous query coordinates to discrete grid vertices while ensuring smoothness and continuity properties required for high-quality volume rendering [S1]. It sets itself apart from [Nearest Voxel Lookup with Periodic Boundary](1573-nearest-voxel-lookup-with-periodic-boundary.md) by providing $C^0$ or higher continuity rather than discontinuous jumps, and from [Mipmap Grid Query](4154-mipmap-grid-query.md) by operating on a single resolution level with explicit basis function evaluation rather than pre-filtered hierarchical levels [S1][S2, S3, S4, unofficial].

## Shared principles
The family operates on a dense grid tensor $\mathbf{G}$ of shape $(D_x, D_y, D_z, C)$, where $D$ are spatial dimensions and $C$ is the channel count (e.g., density, color, or geometry parameters) [G]. The core mechanism involves mapping a continuous query point $\mathbf{p} = (x, y, z)$ to a local support region of discrete control points or vertices, evaluating basis functions over this region, and computing a weighted sum [G].

1.  **Coordinate Mapping:** Query coordinates are normalized or mapped to the grid's indexing space [G]. For a grid with origin $\mathbf{x}_0$ and spacing $\mathbf{dx}$, the continuous coordinate is transformed to a local fractional coordinate $\tilde{\mathbf{x}}$ within a unit cell or support window [G].
2.  **Support Selection:** A subset of grid vertices is selected based on the query position [G].
    *   For linear/trilinear methods, this is the 8 corners of the enclosing voxel [G].
    *   For cubic B-splines, this is the $4 \times 4 \times 4$ block of control points surrounding the query point [11066-b-spline-field-interpolation.md].
3.  **Basis Evaluation:** Weighting coefficients are computed using basis functions $B_i(\tilde{x})$ [G]. These functions must satisfy specific properties:
    *   **Partition of Unity:** $\sum B_i(\tilde{x}) = 1$ to ensure constant fields are reproduced exactly [G].
    *   **Continuity:** The degree of the polynomial determines the continuity order ($C^0$ for linear, $C^2$ for cubic B-splines) [G].
4.  **Weighted Summation:** The interpolated value $u(\mathbf{p})$ is calculated as:
    $$ u(\mathbf{p}) = \sum_{i} \sum_{j} \sum_{k} B_i(\tilde{x}) B_j(\tilde{y}) B_k(\tilde{z}) w_{i,j,k} $$
    where $w_{i,j,k}$ are the values or weights at the selected support points [G].
5.  **Gradient Computation:** Gradients are derived by differentiating the basis functions with respect to the query coordinates, allowing for the computation of $\nabla u(\mathbf{p})$ [G].

## Subtopics

### [Grid Cell Collection via Corner Indices](1518-grid-cell-collection-via-corner-indices.md)
Grid Cell Collection via Corner Indices is a sampling method that extracts the values of a dense 3D grid tensor at the eight vertices of the voxel cell enclosing each query point. It serves as the foundational data-fetching step for trilinear interpolation, enabling the computation of continuous field values and gradients from discrete grid storage. It sets itself apart from higher-order methods like [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) by strictly limiting the support region to the immediate enclosing voxel, and from [VoxelGrid](2159-voxelgrid.md) by focusing on the indexing and gathering mechanics rather than the grid structure itself.

### [B-spline Field Interpolation](11066-b-spline-field-interpolation.md)
B-spline Field Interpolation is a method for function interpolation using cubic B-splines, defined by a grid of control points and weights, where shape functions have local influence. It solves the problem of evaluating a continuous scalar or vector field from discrete control points with $C^2$ continuity, ensuring that constant fields are reproduced exactly via partition of unity. It sets itself apart from linear voxel interpolation by using a $4 \times 4 \times 4$ support region and cubic basis functions, providing smoother gradients and higher-order continuity.

### [Voxel Data Interpolation and Sampling](12781-voxel-data-interpolation-and-sampling.md)
Voxel Data Interpolation and Sampling retrieves scalar values, gradients, and transformed colors at arbitrary 3D positions within a dense volume grid. It maps continuous ray-casting coordinates to discrete grid indices, supporting nearest-neighbor and trilinear interpolation modes. It provides the low-level access primitives (scalar and gradient retrieval) that higher-level transfer functions and shading models consume.

### [NURBS Spline Representation for Measurement Coordinates](16136-nurbs-spline-representation-for-measurement-coordinates.md)
This method represents uncertain measurement coordinates (such as view angles, tilt angles, and detector locations) as a NURBS surface whose control points and weights are optimized alongside the volume reconstruction. It differs from implicit neural representations by using fixed-degree spline basis functions with optimized control points, which allows for the explicit enforcement of physical consistency conditions (such as Radon transform symmetries) that neural networks approximate implicitly. It is typically paired with a U-Net reconstruction network $G_\mu(\cdot)$ that maps the NURBS-interpolated coordinates to image space.

### [Multi-scale Feature Interpolation](16183-multi-scale-feature-interpolation.md)
Multi-scale feature interpolation combines feature representations from multiple resolution levels of a HexPlane grid to reconstruct dense 3D features at query points. It addresses the limitation of single-resolution grids by aggregating coarse structural information with fine-grained details, improving reconstruction quality for dynamic scenes. Unlike standard linear or B-spline interpolation which operates on a single fixed grid, this method explicitly manages a hierarchy of grid scales, concatenating or accumulating interpolated results across these levels.

### [Hermite-based Interpolation](17109-hermite-based-interpolation.md)
Hermite-based interpolation constructs a continuous, differentiable scalar field by interpolating both function values and their spatial derivatives (gradients) stored at grid vertices. It differs from its siblings by explicitly utilizing gradient information to guarantee $C^1$ continuity, allowing the exact normals of the reconstructed surface to be used as shading normals, which provides a storage-efficient replacement for normal mapping.

### [Scattered Data Interpolation (Hardy/Shepard)](20173-scattered-data-interpolation-hardy-shepard.md)
This family reconstructs continuous volume fields from sparse, irregularly distributed sample points, addressing the limitation of grid-based methods that require structured data. It differs from sibling methods like [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) by not relying on a pre-defined dense grid topology for basis evaluation, instead using distance-based kernels to determine influence. It is distinct from [Shepard Local Interpolation](19992-shepard-local-interpolation.md) in that the global variant considers all sample points simultaneously, whereas local variants restrict influence to a neighborhood.

#### Box Spline Interpolation
**Definition:** A piecewise polynomial interpolation function with finite support, uniquely defined by a direction matrix, used for reconstructing continuous splines from discrete datasets [S1].
**Steps:** Construct the box-spline by taking consecutive directional convolutions along each column direction of the direction matrix $\Xi$. For non-Cartesian lattices, apply a change-of-variables to the Cartesian lattice theory [S1].
**Formula:** Recursive definition: $M_{\Xi \cup \{\mathbf{d}\}}(\mathbf{x}) = \int_0^1 M_\Xi(\mathbf{x} - t\mathbf{d}) dt, \mathbf{x} \in \mathbb{R}^n$ (Eq 6) [S1].
**Comparison:** Provides higher quality and reasonable performance compared to trilinear or tricubic interpolations commonly used on mobile devices [S1].
**Usage:** Mobile volume rendering, FCC datasets, GPU ray casting [S1].

#### Distance Weighting Filter
**Definition:** A spatial interpolation filter that assigns weights based on distance to preserve data structure during grid mapping [S2, unofficial].
**Parameter:** Filter radius determines the spatial extent of the weighting; must be shortened to increase sampling rate [S2, unofficial].
**Pitfall:** Assumes a constant, second-order distribution of weighting terms based on the filter radius; under-samples areas with high data frequency, causing inner and outer shells to disappear where data density varies [S2, unofficial].
**Comparison:** Performs worse than the Gaussian filter for preserving accuracy because it lacks a degree of freedom for adjusting sampling frequency independently of radius [S2, unofficial].

#### 1D Interpolation
**Definition:** Performs 1D interpolation on a batch of signals using grid sampling, masking out-of-bounds values [S4, unofficial].
**Steps:** Construct a 2D grid for `grid_sample` where the x-coordinate is 0 and the y-coordinate is normalized from the input positions `x`. Reshape the input feature map `fp` to 4D `(N, C, W, 1)` for `grid_sample`. Sample using `F.grid_sample` with `padding_mode='zeros'` and `align_corners=False`. Mask out values where `x` is outside the range `[-img_shape//2, img_shape - 1 - img_shape//2]` by setting them to 0 [S4, unofficial].
**Parameter:** `mode`: String mapping to grid_sample modes: 'nearest'->'nearest', 'linear'->'bilinear', 'cubic'->'bicubic' [S4, unofficial].

#### Polynomial Interpolation
**Definition:** Interpolation using a polynomial blending function to ensure continuous derivatives, superior to linear interpolation [S4, unofficial].
**Formula:** Cubic Hermite Equation for blending function f(t): f(t) = 3t^2 - 2t^3. Quintic Hermite Equation for blending function f(t): f(t) = 6t^5 - 15t^4 + 10t^3 [S4, unofficial].
**Code:** Pseudocode for polynomial interpolation using a blending function f(x) [S4, unofficial].

#### FEM-based Vector Field Interpolation
**Definition:** A method to display vector fields (e.g., velocity) on a grid with density independent of the computational mesh, using the simulation's shape functions for interpolation [S5, unofficial].
**Steps:** Define bounding box and grid size (e.g., 5x7) for the vector grid. Solve for natural coordinates: For 2D, solve Eq. 6 (quadratic in $\tilde{\tilde{x}}$) for $\tilde{\tilde{x}}$, then substitute into Eq. 9 to compute $\tilde{\tilde{y}}$ (or $\tilde{\tilde{\tilde{x}}}$). Evaluate shape functions $N_i$ using the computed natural coordinates and calculate the velocity vector [S5, unofficial].
**Formula:** Vector interpolation: $\tilde{u} = \frac{\tilde{x}}{N_{npe}} \times \frac{N_{npe}}{i=1} \times N_i(\tilde{\tilde{x}}) u_i$ (Note: Source text Eq 5 is garbled; standard FEM interpolation is implied by context of shape functions Ni) [S5, unofficial]. Coefficients for 2D mapping (Eq 7): $\tilde{\tilde{x}} = -21 + 22 + x3 - 24$, etc. (Source text contains OCR errors for node indices) [S5, unofficial].

#### Parametric Interpolation of Spectral Bases
**Steps:** Discretize parameter space of angles $\theta$ and anisotropies $\eta$ into a half-polar-like grid. Anisotropies are log-scaled: $s_j = \ln(1 + \eta_j)$. For a query $(\eta, \theta)$, project anisotropy to log-space $s = \ln(1+\eta)$. Perform binary search to find bounding grid cell indices $i, j$ such that $\theta_i \le \theta < \theta_{i+1}$ and $s_j \le s < s_{j+1}$ [S6].
**Pitfall:** Permutation, rotation, and sign ambiguities in eigendecomposition hinder bilinear interpolation. This is resolved by aligning precomputed ALBO eigenproperties to a reference (isotropic LBO) using Hungarian algorithm for permutation, SVD for rotation (Orthogonal Procrustes), and sign correction via diagonal matrix [S6].

## Background
The family of polynomial and spline interpolation methods has roots in computer graphics and scientific visualization, where efficient evaluation of continuous fields from discrete samples is critical [G]. Box splines, introduced by de Boor et al., provide multivariate generalizations of uniform B-splines with finite support and specific continuity properties, originally developed for use on Cartesian and non-Cartesian lattices [S1]. In the context of mobile volume rendering, box splines have been adopted to achieve real-time visualization on devices with limited computational resources, offering a balance between visual quality and performance compared to traditional trilinear or tricubic methods [S1]. Distance weighting filters have been explored in the context of sampling scattered data onto rectangular grids for volume visualization, though they are noted to have limitations in preserving accuracy under high-frequency data variations compared to Gaussian filters [S2, unofficial]. More recently, NURBS splines have been applied to represent uncertain measurement coordinates in volume reconstruction pipelines, allowing for the optimization of control points to enforce physical consistency [S1]. Multi-scale feature interpolation using HexPlane grids has emerged in the context of 4D Gaussian Splatting for dynamic scene representation, combining features from multiple resolution levels [S3, unofficial].
