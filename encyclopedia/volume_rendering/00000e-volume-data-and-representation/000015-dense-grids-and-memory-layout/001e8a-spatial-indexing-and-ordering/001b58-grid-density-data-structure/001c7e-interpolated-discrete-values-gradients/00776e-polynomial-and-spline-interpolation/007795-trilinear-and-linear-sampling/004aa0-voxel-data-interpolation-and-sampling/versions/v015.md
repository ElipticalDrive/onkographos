# Voxel Data Interpolation and Sampling

Also called: Sample Grid, Sample Grid Index, getNextIntersectColor, getNextIntersectionGradient, getNextIntersectionScalar

## Overview
Voxel Data Interpolation and Sampling retrieves scalar values, gradients, and transformed colors at arbitrary 3D positions within a dense volume grid [S1, unofficial]. It solves the problem of mapping continuous ray-casting coordinates to discrete grid data, supporting both nearest-neighbor and trilinear interpolation modes [S1, unofficial]. It distinguishes itself from sibling methods by explicitly coupling the interpolation of the field value with a configurable transfer function input mode (scalar-only or scalar-plus-gradient magnitude) [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Query point $\mathbf{p} = (x, y, z)$ in grid coordinates; Grid dimensions $D_x, D_y, D_z$; Grid data vectors for scalars and gradients; Interpolation mode $M_{interp}$; Transfer function mode $M_{transf}$.
*   **Output:** Interpolated scalar value $V$, gradient vector $\mathbf{G}$, and transformed color/opacity tuple.

**Data Structures:**
The volume data is stored in two separate vectors [S1, unofficial]:
1.  `scalars`: `vector<float>` of size $D_x \times D_y \times D_z$.
2.  `gradients`: `vector<glm::vec3>` of size $D_x \times D_y \times D_z$.

The linear index $I$ for a voxel at integer coordinates $(x, y, z)$ is calculated as [S1, unofficial]:
$$ I = x + (y \cdot D_x) + (z \cdot D_x \cdot D_y) $$

**Parameters:**
*   $M_{interp}$: Interpolation mode. $1$ for trilinear, $2$ for nearest neighbor [S1, unofficial].
*   $M_{transf}$: Transfer function input mode. $1$ for (Voxel Value, Voxel Value), $2$ for (Voxel Value, Gradient Magnitude) [S1, unofficial].

**Steps:**

1.  **Boundary Check:**
    Check if the query point's integer coordinates (for nearest) or bounding box (for trilinear) fall within the valid grid domain $[0, D_x-1] \times [0, D_y-1] \times [0, D_z-1]$. If the primary query coordinate is out of bounds, return a default value (e.g., $(0,0,0,0)$) [S1, unofficial].

2.  **Gathering Data:**
    *   If $M_{interp} == 2$ (Nearest Neighbor):
        *   Compute integer indices $x_i = \lfloor x \rfloor, y_i = \lfloor y \rfloor, z_i = \lfloor z \rfloor$.
        *   Clamp indices to $[0, D_d-1]$.
        *   Retrieve scalar $V_{raw}$ and gradient $\mathbf{G}_{raw}$ using index $I(x_i, y_i, z_i)$ [S1, unofficial].
    *   If $M_{interp} == 1$ (Trilinear):
        *   Compute fractional coordinates and 8 corner indices.
        *   Retrieve 8 scalar values and 8 gradient vectors from the corners of the enclosing voxel [S1, unofficial].
        *   *Note:* The provided source implementation currently defaults to nearest neighbor, noting that trilinear voxel intersection logic needs implementation [S1, unofficial].

3.  **Interpolation (if $M_{interp} == 1$):**
    *   Compute local coordinates $(u, v, w) \in [0, 1]^3$.
    *   Apply trilinear basis weights to the 8 gathered scalars to produce $V$.
    *   Apply trilinear basis weights to the 8 gathered gradients to produce $\mathbf{G}$ [S1, unofficial].

4.  **Transfer Function Preparation:**
    *   Retrieve $V$ and $\mathbf{G}$ from the previous step.
    *   If $M_{transf} == 1$:
        *   Input to transformer: $(V, V)$ [S1, unofficial].
    *   If $M_{transf} == 2$:
        *   Compute gradient magnitude $|\mathbf{G}| = \sqrt{G_x^2 + G_y^2 + G_z^2}$.
        *   Clamp $|\mathbf{G}|$ to $[0, 1]$.
        *   Scale by 256: $G_{scaled} = |\mathbf{G}| \times 256$.
        *   Input to transformer: $(V, G_{scaled})$ [S1, unofficial].

5.  **Transformation:**
    *   Pass the prepared inputs to the 1D transfer function transformer to obtain final color and opacity [S1, unofficial].

## Subtopics

### Grid Cell Collection via Corner Indices
Retrieves the 8 corner values of a voxel without interpolation. Use when nearest-neighbor sampling is sufficient or for debugging grid layout. [Link](1518-grid-cell-collection-via-corner-indices.md)

### Piecewise Quadratic Hermite Interpolation
Uses quadratic basis functions with derivative continuity. Choose when smoother gradients are needed than trilinear but cubic cost is too high. [Link](4001-piecewise-quadratic-hermite-interpolation.md)

### Hermite Interpolation of Scalar Fields
General Hermite interpolation supporting gradient data. Choose when explicit gradient storage is available and higher-order continuity is required. [Link](9450-hermite-interpolation-of-scalar-fields.md)

### B-spline Field Interpolation
Uses B-spline basis functions over a larger support kernel. Choose for C2 continuity and smoother results at the cost of larger support. [Link](11066-b-spline-field-interpolation.md)

### Tricubic Interpolation
Uses cubic basis functions for trilinear-like sampling. Choose for higher-order smoothness than trilinear. [Link](14963-tricubic-interpolation.md)

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample. Nearest neighbor is a single index lookup. Trilinear requires 8 lookups and 8 multiplications/additions per channel.
*   **Memory Complexity:** $O(N)$ where $N$ is the number of voxels, storing separate scalar and gradient vectors.
*   **Strengths:** Simple implementation; supports explicit gradient usage for lighting/transfer functions; low memory overhead compared to sparse structures.
*   **Limitations:** Standard implementation in the cited source defaults to nearest neighbor, lacking full trilinear support [S1, unofficial]. Aliasing artifacts occur with nearest neighbor; blurring with trilinear.
*   **When to use:** Real-time volume rendering where performance is critical and high-frequency detail is not required, or as a base for more complex splines.

## Background
The method originates from academic computer graphics coursework and implementations, specifically the "VolumeRayCasting" project from the CSE-333 Computer Graphics course (2020) [S1, unofficial]. It is also referenced in modern DCC tooling, specifically Blender's Geometry Nodes volume grid sampling system, which distinguishes between interpolated "Sample Grid" and raw "Sample Grid Index" access [S2, unofficial].
