# B-spline Field Interpolation

Also called: B-spline deformation field, Cubic B-spline field

## Overview
B-spline field interpolation represents a continuous scalar or vector field using a grid of control points and associated weights, evaluated via cubic B-spline basis functions [S1, unofficial]. It solves the problem of reconstructing smooth, differentiable fields from discrete data or learning parameters, offering $C^2$ continuity and local support [S1, S2, unofficial]. Unlike trilinear interpolation which is only $C^0$, this method ensures smooth derivatives across cell boundaries, making it suitable for deformation fields and density representations where gradient continuity is critical [S1, S2, unofficial]. It builds on [Polynomial and Spline Interpolation](11104-polynomial-and-spline-interpolation.md) by using specific cubic basis functions with a 4-point local support per dimension.

## How it works
**Inputs:**
- Query point $\mathbf{p} = (x, y, z)$ in world coordinates [S1, unofficial].
- Grid origin $\mathbf{x}_0 = (x_0, y_0, z_0)$ [S1, unofficial].
- Grid spacing $\mathbf{dx} = (dx, dy, dz)$ [S1, unofficial].
- Control point weights $w_{i,j,k}$ for a 3D grid of control points [S1, unofficial]. For vector fields (e.g., displacement), three independent sets of weights are used for the $x, y, z$ components [S1, unofficial].

**Outputs:**
- Interpolated value $u(\mathbf{p})$ (scalar) or vector $\mathbf{u}(\mathbf{p})$ [S1, unofficial].

**Data Structures:**
- The field is defined by a grid of control points. The minimum grid size for a valid 3D field is $4 \times 4 \times 4$ control points [S1, unofficial].
- Each control point $(i_x, i_y, i_z)$ stores a scalar weight $w_{i_x, i_y, i_z}$ [S1, unofficial].
- For a 3D displacement vector field, the minimum degrees of freedom is $3 \times 64 = 192$ weights [S1, unofficial].

**Algorithm:**
1.  **Index Calculation:** Determine the integer indices of the support grid corner. The support region for point $\mathbf{p}$ is defined by indices $[i_x, i_x+1, i_x+2, i_x+3]$ in $x$, and similarly for $y$ and $z$ [S1, unofficial].
    $$ i_x = \left\lfloor \frac{x - x_0}{dx} - 1 \right\rfloor $$
    $$ i_y = \left\lfloor \frac{y - y_0}{dy} - 1 \right\rfloor $$
    $$ i_z = \left\lfloor \frac{z - z_0}{dz} - 1 \right\rfloor $$
    [S1, unofficial]

2.  **Normalized Coordinates:** Calculate the local coordinates $\tilde{x}, \tilde{y}, \tilde{z}$ within the support cell. These coordinates lie in the range $[0, 1]$ [S1, unofficial].
    $$ \tilde{x} = \frac{x - x_0}{dx} - 1 - i_x $$
    $$ \tilde{y} = \frac{y - y_0}{dy} - 1 - i_y $$
    $$ \tilde{z} = \frac{z - z_0}{dz} - 1 - i_z $$
    [S1, unofficial]

3.  **Basis Evaluation:** Evaluate the 1D cubic B-spline basis functions $B_0, B_1, B_2, B_3$ for each dimension [S1, unofficial].
    $$ B_0(\tilde{x}) = \frac{(1 - \tilde{x})^3}{6} $$
    $$ B_1(\tilde{x}) = \frac{3\tilde{x}^3 - 6\tilde{x}^2 + 4}{6} $$
    $$ B_2(\tilde{x}) = \frac{-3\tilde{x}^3 + 3\tilde{x}^2 + 3\tilde{x} + 1}{6} $$
    $$ B_3(\tilde{x}) = \frac{\tilde{x}^3}{6} $$
    [S1, unofficial]

4.  **Interpolation:** Compute the value by summing the weighted contributions of the $4 \times 4 \times 4 = 64$ neighboring control points [S1, unofficial].
    $$ u(\mathbf{p}) = \sum_{l=0}^{3} \sum_{m=0}^{3} \sum_{n=0}^{3} B_l(\tilde{x}) B_m(\tilde{y}) B_n(\tilde{z}) w_{i_x+l, i_y+m, i_z+n} $$
    [S1, unofficial]

**Pseudocode:**
```python
def b_spline_interpolate(x, y, z, x0, y0, z0, dx, dy, dz, weights):
    """
    Interpolate a value at (x, y, z) using a 3D B-spline field.
    
    Args:
        x, y, z: Query point coordinates.
        x0, y0, z0: Grid origin.
        dx, dy, dz: Grid spacing.
        weights: 3D array of control point weights, indexed as weights[ix, iy, iz].
                 Must be large enough to cover the support region.
    
    Returns:
        Interpolated scalar value.
    """
    # 1. Calculate integer indices for the support grid corner
    ix = int((x - x0) / dx - 1)
    iy = int((y - y0) / dy - 1)
    iz = int((z - z0) / dz - 1)
    
    # 2. Calculate normalized coordinates within the support region [0, 1]
    x_tilde = (x - x0) / dx - 1 - ix
    y_tilde = (y - y0) / dy - 1 - iy
    z_tilde = (z - z0) / dz - 1 - iz
    
    # 3. Evaluate 1D B-spline basis functions
    def b0(t):
        return (1 - t)**3 / 6.0
    
    def b1(t):
        return (3 * t**3 - 6 * t**2 + 4) / 6.0
    
    def b2(t):
        return (-3 * t**3 + 3 * t**2 + 3 * t + 1) / 6.0
    
    def b3(t):
        return t**3 / 6.0
    
    # Precompute basis values for each dimension
    bx = [b0(x_tilde), b1(x_tilde), b2(x_tilde), b3(x_tilde)]
    by = [b0(y_tilde), b1(y_tilde), b2(y_tilde), b3(y_tilde)]
    bz = [b0(z_tilde), b1(z_tilde), b2(z_tilde), b3(z_tilde)]
    
    # 4. Sum weighted contributions from the 4x4x4 support grid
    value = 0.0
    for l in range(4):
        for m in range(4):
            for n in range(4):
                # Access weight at index (ix+l, iy+m, iz+n)
                # Note: In practice, boundary checks are required if the query point
                # is near the edge of the defined grid. [G]
                w = weights[ix + l, iy + m, iz + n]
                value += bx[l] * by[m] * bz[n] * w
                
    return value
```

**Edge Cases and Pitfalls:**
-   **Non-Interpolatory Nature:** The field value at a control point location ($\tilde{x}=0$) is generally *not* equal to the weight of that control point due to blending with neighbors [S1, unofficial]. For example, if a single weight is 1 and all others are 0, the field value at that point is $2/3$ [S1, unofficial].
-   **Boundary Conditions:** The sources do not specify behavior for query points outside the grid bounds. Implementers must handle indices $i_x, i_y, i_z$ that fall outside the allocated weight array [G].
-   **Minimum Grid Size:** A grid smaller than $4 \times 4 \times 4$ cannot support a full cubic B-spline evaluation for all internal points [S1, unofficial].

## Subtopics

### Time-varying B-spline Deformation Field
A variant where the displacement field $\mathbf{u}(\mathbf{x}, t)$ is parametrized by cubic B-splines on a fixed 3D spatial grid, but the weights $w(t)$ vary with time [S1, unofficial]. This allows arbitrary continuous position and time queries [S1, unofficial]. The weights are generated implicitly as a function of time $t$ using a Multi-Layer Perceptron (MLP) $\phi(t) \rightarrow w(t)$, rather than being discretized into timesteps [S1, unofficial]. This approach ensures implicit time continuity and efficiency [S1, unofficial]. The spatial interpolation remains the same, using the 64 closest grid points [S1, unofficial].

### B-spline Curve Modeling
Used for modeling parametric space curves (e.g., flame spines) where uniform B-splines guarantee second-order continuity ($C^2$), preventing random twisting and ensuring curvature continuity [S2, unofficial]. Unlike Hermite polynomials, B-splines are invariant to affine transformations [S2, unofficial]. Evaluation is performed using de Boor's algorithm (Cox-de Boor algorithm), which is numerically stable and fast [S2, unofficial]. The basis functions are defined recursively over a domain $[0, 1]$ regardless of arc-length, allowing mapping of world coordinates to local texture coordinates [S2, unofficial]. The curve is defined as $s(x) = \sum_{i=0}^{p-1} d_i N_i^n(x)$, where $N_i^n(x)$ is the recursive B-spline basis function [S2, unofficial].

## Operating characteristics
-   **Time Complexity:** $O(1)$ per sample, as it requires evaluating 64 weights and basis functions regardless of grid size [S1, unofficial].
-   **Memory Complexity:** Proportional to the number of control points. Minimum 64 weights for a scalar field, 192 for a vector field [S1, unofficial].
-   **Continuity:** $C^2$ continuous (second-order derivative continuity) [S2, unofficial]. This is superior to trilinear ($C^0$) and bilinear methods [S1, S2, unofficial].
-   **Strengths:** Smooth gradients, local support (no global updates needed for local changes), affine invariance [S2, unofficial].
-   **Limitations:** Not interpolatory (values do not pass through control points exactly) [S1, unofficial]. Requires careful handling of grid boundaries [G].
-   **When to use:** When smooth deformation fields or density representations are needed, particularly in neural rendering or physics-based animation where gradient continuity is important [S1, S2, unofficial].
-   **When not to use:** When exact interpolation of control points is required, or when computational resources are extremely limited and $C^0$ continuity is sufficient [S1, unofficial].

## Background
The method is based on cubic B-splines introduced by Rueckert et al. [S1, unofficial]. It has been applied in neural rendering for dynamic tomography, where it replaces voxel grids with continuous functions to represent density and deformation fields [S1, unofficial]. It is also used in real-time rendering of fire, where B-spline curves model flame spines due to their continuity and affine invariance properties [S2, unofficial]. The de Boor's algorithm for evaluation is a generalization of de Casteljau's algorithm for Bezier curves [S2, unofficial].
