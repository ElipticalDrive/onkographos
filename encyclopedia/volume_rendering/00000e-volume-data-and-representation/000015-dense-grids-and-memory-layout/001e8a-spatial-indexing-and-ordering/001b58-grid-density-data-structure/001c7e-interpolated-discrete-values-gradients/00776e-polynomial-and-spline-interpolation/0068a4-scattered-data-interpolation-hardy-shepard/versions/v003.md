# Scattered Data Interpolation (Hardy/Shepard)
## Overview
This family reconstructs continuous volume fields from sparse, irregularly distributed sample points, addressing the limitation of grid-based methods that require structured data [G]. It differs from sibling methods like [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) by not relying on a pre-defined dense grid topology for basis evaluation, instead using distance-based kernels to determine influence [G]. The family splits into global methods that consider all sample points simultaneously, and local methods that restrict influence to a neighborhood [G].

## Shared principles
The family operates on a set of $N$ scattered sample points $\mathbf{x}_i \in \mathbb{R}^3$ with associated scalar values $d_i$ [G]. The core mechanism maps a continuous query point $\mathbf{p}$ to a weighted combination of these samples using a radial kernel $\phi(r)$, where $r$ is the Euclidean distance between $\mathbf{p}$ and $\mathbf{x}_i$ [G].

1.  **Kernel Definition:** A radial kernel $\phi(\|\mathbf{x}_i - \mathbf{p}\|)$ defines the influence of sample $i$ at query point $\mathbf{p}$ [G]. Common choices include the multiquadric kernel $\phi(r) = (r^2 + R)^{power}$ and the inverse distance kernel $\phi(r) = 1/r^2$ [G].
2.  **Global vs. Local Support:**
    *   **Global:** The value at $\mathbf{p}$ depends on all $N$ samples. Coefficients $\mathbf{c}$ are determined by solving a linear system $A\mathbf{c} = \mathbf{d}$, where $A_{ij} = \phi(\|\mathbf{x}_i - \mathbf{x}_j\|)$ [G].
    *   **Local:** The value at $\mathbf{p}$ depends only on the $k$ nearest neighbors. This avoids solving a large global system, reducing complexity from $O(N^3)$ to $O(N \cdot k)$ per query [G].
3.  **Interpolation Formula:**
    *   For global interpolation: $u(\mathbf{p}) = \sum_{i=1}^{N} c_i \phi(\|\mathbf{x}_i - \mathbf{p}\|)$ [G].
    *   For local interpolation (Shepard): $u(\mathbf{p}) = \frac{\sum_{i=1}^{k} w_i d_i}{\sum_{i=1}^{k} w_i}$, where $w_i = 1 / \|\mathbf{x}_i - \mathbf{p}\|^2$ [G].
4.  **Parameter Sensitivity:** The shape parameter $R$ (in multiquadric) and neighbor count $k$ (in local) significantly affect smoothness and computational cost [G].

## Subtopics

### [Shepard Local Interpolation](19992-shepard-local-interpolation.md)
Estimates values by weighting the $k$ nearest neighbors using inverse squared distance. It differs from the global variant by limiting influence to a local neighborhood, reducing computational cost and memory usage for large datasets. Choose this when $N$ is large and real-time or low-memory performance is required.

```python
import math

def shepard_local_interpolation(samples, grid_dims, k):
    """
    samples: list of tuples (x, y, z, d)
    grid_dims: tuple (dim_x, dim_y, dim_z)
    k: int, number of nearest neighbors
    """
    ret = [[[0.0 for _ in range(grid_dims[2])] for _ in range(grid_dims[1])] for _ in range(grid_dims[0])]
    
    for x in range(grid_dims[0]):
        for y in range(grid_dims[1]):
            for z in range(grid_dims[2]):
                point = (x, y, z)
                
                # Compute squared distances to all samples
                dists = []
                for i, s in enumerate(samples):
                    dx = point[0] - s[0]
                    dy = point[1] - s[1]
                    dz = point[2] - s[2]
                    dist_sq = dx*dx + dy*dy + dz*dz
                    dists.append((dist_sq, i))
                
                # Sort and pick k nearest
                dists.sort(key=lambda t: t[0])
                nearest = dists[:k]
                
                numerator = 0.0
                denominator = 0.0
                exact_match = False
                
                for dist_sq, idx in nearest:
                    s = samples[idx]
                    if dist_sq == 0.0:
                        ret[x][y][z] = s[3]
                        exact_match = True
                        break
                    
                    weight = 1.0 / dist_sq
                    numerator += s[3] * weight
                    denominator += weight
                
                if not exact_match and denominator != 0.0:
                    ret[x][y][z] = numerator / denominator
                else:
                    ret[x][y][z] = 0.0
                    
    return ret
```

### [Hardy Global Interpolation](19995-hardy-global-interpolation.md)
Uses Hardy's multiquadric kernel to solve a global linear system for coefficients. It differs from local methods by considering all sample points simultaneously, providing smooth global continuity but incurring $O(N^3)$ cost. Choose this when $N$ is small and high global smoothness is critical.

```python
import math

def hardy_global_interpolation(random_Points, d, R, power, grid_points):
    """
    random_Points: List of N 3D points (x_i).
    d: List of N scalar values corresponding to random_Points.
    R: Shape parameter for the multiquadric kernel.
    power: Exponent for the kernel (e.g., 0.5).
    grid_points: List of 3D points to interpolate.
    """
    N = len(random_Points)
    ret = {}
    
    # Step 3: Construct Matrix A
    A = [[0.0] * N for _ in range(N)]
    for i in range(N):
        for j in range(N):
            dist_sq = sum((a - b)**2 for a, b in zip(random_Points[i], random_Points[j]))
            A[i][j] = math.sqrt(R + dist_sq)
            
    # Step 4: Construct vector b
    b = list(d)
    
    # Step 5: Solve linear system A^T A x = A^T b
    AT = [[A[j][i] for j in range(N)] for i in range(N)]
    ATA = [[sum(AT[i][k] * A[k][j] for k in range(N)) for j in range(N)] for i in range(N)]
    ATb = [sum(AT[i][k] * b[k] for k in range(N)) for i in range(N)]
    c = solve_linear_system(ATA, ATb)
    
    # Step 6: Evaluate at grid points
    for p in grid_points:
        val_sum = 0.0
        for i in range(N):
            dist_sq = sum((a - b)**2 for a, b in zip(random_Points[i], p))
            val = R + dist_sq
            val_sum += c[i] * math.pow(val, power)
        ret[p] = val_sum
        
    return ret

def solve_linear_system(A, b):
    """Solves Ax = b using Gaussian elimination with partial pivoting."""
    n = len(A)
    M = [A[i][:] + [b[i]] for i in range(n)]
    
    for i in range(n):
        max_row = i
        for k in range(i+1, n):
            if abs(M[k][i]) > abs(M[max_row][i]):
                max_row = k
        M[i], M[max_row] = M[max_row], M[i]
        
        pivot = M[i][i]
        if abs(pivot) < 1e-12:
            continue
            
        for j in range(i, n+1):
            M[i][j] /= pivot
            
        for k in range(n):
            if k != i:
                factor = M[k][i]
                for j in range(i, n+1):
                    M[k][j] -= factor * M[i][j]
                    
    return [M[i][n] for i in range(n)]
```

### Hardy Local Interpolation
A variant that combines Hardy's multiquadric kernel with local neighbor selection [S1, unofficial]. It uses a K-D tree to find $k$ nearest neighbors and solves a local linear system for coefficients [S1, unofficial].
* **Definition:** Uses the multiquadric function $\phi(r) = \sqrt{r^2 + R^2}$ within a local support region [S1, unofficial].
* **Steps:**
  1. Initialize `ret` with zeros and copy sample point data to corresponding grid positions [S1, unofficial].
  2. For each point in the volume grid, query the K-D tree for the $k$ nearest neighbors (`inds`) [S1, unofficial].
  3. Retrieve the $k$ nearest neighbors into `vals` [S1, unofficial].
  4. Calculate local coefficients `c` by calling `self.C(R, vals)` [S1, unofficial].
  5. For each neighbor `i` in `vals`, calculate `val = R + distance2(vals[i], point)` and set `ret[point]` to `c[i] * math.pow(val, power)` [S1, unofficial]. Note: This loop overwrites `ret[point]` for each `i`, so only the last neighbor's contribution is stored [S1, unofficial].

## Background
Originating from the work of Michael D. Hardy in the 1970s on multiquadric interpolation, this method was developed for geostatistical and scattered data fitting problems [G]. It has been adapted for volume rendering to reconstruct dense fields from sparse sensor data or particle simulations [G]. The local variant, often associated with Shepard (1968), is widely used in computer graphics for smooth surface reconstruction and texture mapping from scattered points [G].
