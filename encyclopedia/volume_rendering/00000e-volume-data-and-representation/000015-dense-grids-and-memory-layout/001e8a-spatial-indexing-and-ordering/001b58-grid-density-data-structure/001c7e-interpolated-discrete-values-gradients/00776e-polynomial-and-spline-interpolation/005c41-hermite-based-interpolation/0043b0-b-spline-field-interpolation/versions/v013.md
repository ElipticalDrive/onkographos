# B-spline Field Interpolation

Also called: B-spline deformation field, Cubic B-spline field

## Overview
B-spline Field Interpolation is a method for function interpolation using cubic B-splines, defined by a grid of control points and weights, where shape functions have local influence [S1, unofficial]. It solves the problem of representing continuous scalar or vector fields (such as density or displacement) from discrete control points while ensuring $C^2$ continuity across cell boundaries. It sets itself apart from linear voxel interpolation by providing smooth derivatives and from global polynomial interpolation by its local support, requiring only a $4 \times 4 \times 4$ neighborhood for evaluation [S1, unofficial].

## How it works
**Inputs:**
- Query point coordinates $\mathbf{p} = (x, y, z)$.
- Grid origin $\mathbf{x}_0 = (x_0, y_0, z_0)$.
- Grid spacing $\mathbf{dx} = (dx, dy, dz)$.
- Control point weights $w_{i,j,k}$ stored in a 3D array.

**Outputs:**
- Interpolated value $u(\mathbf{p})$.

**Data Structures:**
- The field is defined on a regular 3D grid.
- Minimum grid size for a valid 3D field is $4 \times 4 \times 4$ control points [S1, unofficial].
- For vector fields (e.g., 3D displacement), three independent sets of weights are stored, one for each component ($u_x, u_y, u_z$), totaling 192 degrees of freedom for the minimum grid [S1, unofficial].

**Steps:**
1.  **Support Selection:** Calculate the integer indices $(i_x, i_y, i_z)$ of the bottom-left corner of the $4 \times 4 \times 4$ support grid that influences the query point. The support grid indices range from $[i_x, i_x+3]$, $[i_y, i_y+3]$, and $[i_z, i_z+3]$ [S1, unofficial].
    $$ i_x = \left\lfloor \frac{x - x_0}{dx} - 1 \right\rfloor $$
    $$ i_y = \left\lfloor \frac{y - y_0}{dy} - 1 \right\rfloor $$
    $$ i_z = \left\lfloor \frac{z - z_0}{dz} - 1 \right\rfloor $$
    *Note: The region supported by these points lies in the cube between control points $(i_x+1, i_y+1, i_z+1)$ and $(i_x+2, i_y+2, i_z+2)$ [S1, unofficial].*

2.  **Normalized Coordinates:** Calculate the local coordinates $\tilde{x}, \tilde{y}, \tilde{z}$ within the support cell. These coordinates are modulo-subtracted to lie in $[0, 1]$ [S1, unofficial].
    $$ \tilde{x} = \frac{x - x_0}{dx} - 1 - i_x $$
    $$ \tilde{y} = \frac{y - y_0}{dy} - 1 - i_y $$
    $$ \tilde{z} = \frac{z - z_0}{dz} - 1 - i_z $$

3.  **Basis Evaluation:** Compute the cubic B-spline basis functions $B_0, B_1, B_2, B_3$ for each dimension using the normalized coordinates. The basis functions are cubic polynomials defined over $0 \le \tilde{x} \le 1$ that sum to 1 [S1, unofficial].
    $$ B_0(\tilde{x}) = \frac{(1 - \tilde{x})^3}{6} $$
    $$ B_1(\tilde{x}) = \frac{3\tilde{x}^3 - 6\tilde{x}^2 + 4}{6} $$
    $$ B_2(\tilde{x}) = \frac{-3\tilde{x}^3 + 3\tilde{x}^2 + 3\tilde{x} + 1}{6} $$
    $$ B_3(\tilde{x}) = \frac{\tilde{x}^3}{6} $$

4.  **Weighted Summation:** Calculate the interpolated value $u$ as the sum of the contributions of all 64 control points in the support grid, weighted by the product of the basis functions [S1, unofficial].
    $$ u = \sum_{l=0}^3 \sum_{m=0}^3 \sum_{n=0}^3 B_l(\tilde{x}) B_m(\tilde{y}) B_n(\tilde{z}) w_{i_x+l, i_y+m, i_z+n} $$

**Pseudocode:**
```python
def cubic_b_spline_interpolation(x, y, z, x0, y0, z0, dx, dy, dz, weights):
    """
    Interpolate a value at (x, y, z) using a 3D grid of control points.
    
    Args:
        x, y, z: Query point coordinates.
        x0, y0, z0: Grid origin.
        dx, dy, dz: Grid spacing.
        weights: 3D array of control point weights.
        
    Returns:
        Interpolated scalar value.
    """
    # Step 1: Support Selection
    # Calculate integer indices for the 4x4x4 support grid
    ix = int((x - x0) / dx - 1)
    iy = int((y - y0) / dy - 1)
    iz = int((z - z0) / dz - 1)
    
    # Step 2: Normalized Coordinates
    # Calculate local coordinates within the support region [0, 1]
    x_tilde = (x - x0) / dx - 1 - ix
    y_tilde = (y - y0) / dy - 1 - iy
    z_tilde = (z - z0) / dz - 1 - iz
    
    # Step 3: Basis Evaluation
    # Define cubic B-spline basis functions
    def b0(t):
        return (1 - t)**3 / 6.0
    
    def b1(t):
        return (3 * t**3 - 6 * t**2 + 4) / 6.0
    
    def b2(t):
        return (-3 * t**3 + 3 * t**2 + 3 * t + 1) / 6.0
    
    def b3(t):
        return t**3 / 6.0
    
    # Precompute basis values for x, y, z
    bx = [b0(x_tilde), b1(x_tilde), b2(x_tilde), b3(x_tilde)]
    by = [b0(y_tilde), b1(y_tilde), b2(y_tilde), b3(y_tilde)]
    bz = [b0(z_tilde), b1(z_tilde), b2(z_tilde), b3(z_tilde)]
    
    # Step 4: Weighted Summation
    u = 0.0
    for l in range(4):
        for m in range(4):
            for n in range(4):
                # Access weight at index (ix+l, iy+m, iz+n)
                # Note: In a real implementation, bounds checking for the grid
                # boundaries should be added here [G].
                w = weights[ix + l, iy + m, iz + n]
                u += bx[l] * by[m] * bz[n] * w
                
    return u
```

**Parameters:**
- Grid origin $[x_0, y_0, z_0]$: The spatial origin of the control point grid [S1, unofficial].
- Grid spacing $dx, dy, dz$: The distance between adjacent control points along each axis [S1, unofficial].
- Control point weight $w_{i_x, i_y, i_z}$: The scalar value associated with the control point at grid indices $(i_x, i_y, i_z)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- The field value at a control point (where $\tilde{x}=0$) is generally not equal to the weight of that control point due to the blending of neighboring weights [S1, unofficial]. For example, if a single control point has weight 1 and all others 0, the field value at that point is $2/3$ [S1, unofficial].
- The minimum number of control points for a 3D field is $4 \times 4 \times 4 = 64$ [S1, unofficial].

## Subtopics

### Time-varying B-spline Deformation Field
A time-varying displacement field $u(\mathbf{x}, t)$ parametrized by cubic B-splines on a fixed 3D grid, allowing arbitrary continuous position and time queries [S1, unofficial]. It sets itself apart by generating weights implicitly as a function of time $w(t)$ rather than discretizing time into timesteps, which ensures implicit time continuity and efficiency [S1, unofficial]. Choose this when representing dynamic deformations where smooth temporal transitions are required. It uses a Multi-Layer Perceptron (MLP) $\phi(t)$ to generate the full set of weights $w(t)$ for the current time $t$ [S1, unofficial]. The displacement is calculated as $u(x, y, z, t) = \sum_{l=0}^3 \sum_{m=0}^3 \sum_{n=0}^3 B_l(\tilde{x}) B_m(\tilde{y}) B_n(\tilde{z}) w(t)_{i_x+l, i_y+m, i_z+n}$ [S1, unofficial].

### B-spline Curve Modeling
Individual flame elements modeled as parametric space curves interpolating points defining the spine of the flame [S2, unofficial]. It sets itself apart by using uniform B-splines to guarantee second-order continuity (preventing random twisting) and invariance to affine transformations [S2, unofficial]. Choose this for modeling smooth, continuous curves like flame spines. It evaluates the spline using de Boor's algorithm (Cox-de Boor algorithm), which is fast and numerically stable [S2, unofficial]. The curve is defined as $s(x) = \sum_{i=0}^{p-1} d_i N_i^n(x)$, where $N_i^n(x)$ is the recursive B-spline basis function [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per query, as it only requires accessing a fixed $4 \times 4 \times 4$ neighborhood (64 points) and evaluating cubic polynomials [S1, unofficial].
- **Memory Complexity:** $O(N)$ where $N$ is the number of control points. For a 3D displacement field, memory is $3 \times N$ [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Strengths:** Local support (efficiency), $C^2$ continuity (smoothness), and ability to represent complex fields with relatively few control points compared to voxel grids [S1, unofficial].
- **Limitations:** The value at a control point does not equal its weight, which may require adjustment if interpolation to control points is expected [S1, unofficial].
- **When to use:** When smooth, continuous interpolation of scalar or vector fields is required, particularly for deformation fields or density representations in neural rendering [S1, unofficial].
- **When not to use:** When exact interpolation of control point values is required without blending [S1, unofficial].

## Background
The method is based on cubic B-splines as described by Rueckert et al. [S1, unofficial]. It was modified in the context of neural rendering for dynamic tomography to account for temporal variations in deformation [S1, unofficial]. The underlying mathematical framework for B-splines, including the Cox-de Boor recursion, was devised by Carl R. de Boor [S2, unofficial].
