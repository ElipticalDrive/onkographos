# Grid Gradient Normal Estimation

Also called: Finite Difference Heightmap Normals, Finite Difference Normals, Gradient-Based Normals, Heightmap Vertex Normal Calculation

## Overview
Grid Gradient Normal Estimation computes vertex normals by estimating the gradient of the underlying scalar field (density or height function) at grid vertices using finite differences, then interpolating these normals to mesh vertices [S1, S2, unofficial]. It differs from face-normal averaging by sampling the density function directly, which is considered faster or more accurate for smooth shading if the field is differentiable [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A regular grid of scalar values (density $\rho$ or height $h$). For 3D, a 3D array `Grid[cx, cy, cz]`. For 2D heightmaps, a 2D array `H[i, j]`.
- Output: Normal vectors $\mathbf{n}$ at grid vertices, which are then interpolated to mesh vertices.

**Data Structures:**
- `Grid`: A 3D array where `Grid[cx, cy, cz]` stores the scalar value at integer coordinates $(cx, cy, cz)$.
- `Normal`: A 3D vector associated with each grid vertex.

**Steps:**
1. Iterate over each grid vertex at coordinates $(cx, cy, cz)$.
2. Calculate the X component of the gradient by taking the difference between the value at the previous grid point in X and the next grid point in X.
3. Calculate the Y component of the gradient by taking the difference between the value at the previous grid point in Y and the next grid point in Y.
4. Calculate the Z component of the gradient by taking the difference between the value at the previous grid point in Z and the next grid point in Z.
5. Normalize the resulting gradient vector to obtain the grid vertex normal.
6. Interpolate the grid vertex normals to the positions of the mesh vertices (which lie on the edges of the grid cells) to obtain the final vertex normals [S1, unofficial].

**Formulas:**
For a 3D grid vertex at $(cx, cy, cz)$, the unnormalized gradient $\mathbf{g}$ is calculated as [S1, unofficial]:
$$
g_x = \text{Grid}[cx-1, cy, cz].\text{Value} - \text{Grid}[cx+1, cy, cz].\text{Value}
$$
$$
g_y = \text{Grid}[cx, cy-1, cz].\text{Value} - \text{Grid}[cx, cy+1, cz].\text{Value}
$$
$$
g_z = \text{Grid}[cx, cy, cz-1].\text{Value} - \text{Grid}[cx, cy, cz+1].\text{Value}
$$
The normal $\mathbf{n}$ is:
$$
\mathbf{n} = \text{normalize}(\mathbf{g})
$$

For a 2D heightmap vertex at $(i, j)$ with height values $h$, the normal is calculated using neighboring heights [S2, unofficial]:
$$
\mathbf{n}_{i,j} = \text{normalize}(\text{calculateNormal}(h_{i-1,j}, h_{i+1,j}, h_{i,j-1}, h_{i,j+1}))
$$
Where `calculateNormal` constructs a vector from the height differences (typically $\mathbf{g} = (h_{i-1,j} - h_{i+1,j}, h_{i,j-1} - h_{i,j+1}, \text{constant})$ or similar depending on axis orientation).

**Pseudocode:**
```python
def compute_grid_normals_3d(grid, width, height, depth):
    """
    Computes normals at grid vertices using central finite differences.
    grid: 3D array of scalar values.
    width, height, depth: dimensions of the grid.
    Returns: 3D array of normal vectors.
    """
    normals = [[None for _ in range(depth)] for _ in range(height)]
    for _ in range(width):
        for y in range(height):
            for z in range(depth):
                normals[y][z] = [0.0, 0.0, 0.0]

    for cx in range(width):
        for cy in range(height):
            for cz in range(depth):
                # Calculate gradient components using central differences
                # Handle boundaries by clamping or assuming zero gradient [G]
                
                # X component
                if cx > 0 and cx < width - 1:
                    gx = grid[cx-1][cy][cz] - grid[cx+1][cy][cz]
                else:
                    gx = 0.0 # Boundary condition [G]

                # Y component
                if cy > 0 and cy < height - 1:
                    gy = grid[cx][cy-1][cz] - grid[cx][cy+1][cz]
                else:
                    gy = 0.0 # Boundary condition [G]

                # Z component
                if cz > 0 and cz < depth - 1:
                    gz = grid[cx][cy][cz-1] - grid[cx][cy][cz+1]
                else:
                    gz = 0.0 # Boundary condition [G]

                # Normalize the gradient vector
                length = sqrt(gx*gx + gy*gy + gz*gz)
                if length > 0:
                    normals[cx][cy][cz] = [gx/length, gy/length, gz/length]
                else:
                    normals[cx][cy][cz] = [0.0, 0.0, 1.0] # Default normal [G]

    return normals

def interpolate_normals_to_mesh(grid_normals, mesh_vertices, grid_spacing):
    """
    Interpolates grid vertex normals to mesh vertices.
    mesh_vertices: List of vertex positions (x, y, z) in world space.
    grid_spacing: Distance between grid points.
    Returns: List of normal vectors for mesh vertices.
    """
    mesh_normals = []
    for v in mesh_vertices:
        # Convert world position to grid coordinates
        gx = v.x / grid_spacing
        gy = v.y / grid_spacing
        gz = v.z / grid_spacing
        
        # Get integer and fractional parts
        ix = floor(gx)
        iy = floor(gy)
        iz = floor(gz)
        fx = gx - ix
        fy = gy - iy
        fz = gz - iz
        
        # Retrieve 8 corner normals
        n000 = grid_normals[ix][iy][iz]
        n100 = grid_normals[ix+1][iy][iz]
        n010 = grid_normals[ix][iy+1][iz]
        n110 = grid_normals[ix+1][iy+1][iz]
        n001 = grid_normals[ix][iy][iz+1]
        n101 = grid_normals[ix+1][iy][iz+1]
        n011 = grid_normals[ix][iy+1][iz+1]
        n111 = grid_normals[ix+1][iy+1][iz+1]
        
        # Trilinear interpolation of normals
        # Note: Normals should be interpolated in 3D space and then normalized,
        # or interpolated component-wise and normalized. Component-wise is common [G].
        nx = (1-fx)*(1-fy)*(1-fz)*n000.x + fx*(1-fy)*(1-fz)*n100.x + \
             (1-fx)*fy*(1-fz)*n010.x + fx*fy*(1-fz)*n110.x + \
             (1-fx)*(1-fy)*fz*n001.x + fx*(1-fy)*fz*n101.x + \
             (1-fx)*fy*fz*n011.x + fx*fy*fz*n111.x
             
        ny = (1-fx)*(1-fy)*(1-fz)*n000.y + fx*(1-fy)*(1-fz)*n100.y + \
             (1-fx)*fy*(1-fz)*n010.y + fx*fy*(1-fz)*n110.y + \
             (1-fx)*(1-fy)*fz*n001.y + fx*(1-fy)*fz*n101.y + \
             (1-fx)*fy*fz*n011.y + fx*fy*fz*n111.y
             
        nz = (1-fx)*(1-fy)*(1-fz)*n000.z + fx*(1-fy)*(1-fz)*n100.z + \
             (1-fx)*fy*(1-fz)*n010.z + fx*fy*(1-fz)*n110.z + \
             (1-fx)*(1-fy)*fz*n001.z + fx*(1-fy)*fz*n101.z + \
             (1-fx)*fy*fz*n011.z + fx*fy*fz*n111.z
             
        length = sqrt(nx*nx + ny*ny + nz*nz)
        if length > 0:
            mesh_normals.append([nx/length, ny/length, nz/length])
        else:
            mesh_normals.append([0.0, 0.0, 1.0]) # Default normal [G]
            
    return mesh_normals
```

**Edge Cases and Pitfalls:**
- **Boundaries:** The central difference requires neighbors on both sides. At grid boundaries, values must be handled (e.g., clamping, mirroring, or assuming zero gradient) [G].
- **Degenerate Input:** If the gradient vector is zero (e.g., flat region), normalization fails. A default normal should be returned [G].
- **Precision:** Finite differences are sensitive to noise in the scalar field. Smoothing the field before differentiation may be necessary.

## Subtopics

### Finite Difference Heightmap Normals
A 2D-specific variant for terrain meshes where normals are derived from height values in a 2D array [S2, unofficial]. Use when working with heightmaps.

### Gradient-Based Normals
A general term for any normal estimation using field gradients. Use when the scalar field is available and differentiable [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ for grid vertices, where $N$ is the number of grid points. Interpolation is $O(M)$ for $M$ mesh vertices.
- **Memory Complexity:** $O(N)$ to store grid normals.
- **Performance:** Considered fast and efficient for smooth shading if the field is differentiable [S1, unofficial].
- **Strengths:** Provides smooth shading; directly uses the underlying field data.
- **Limitations:** Requires access to the scalar field; sensitive to noise; boundary handling is non-trivial.
- **When to use:** When the scalar field is available and smooth shading is desired.
- **When not to use:** When only mesh topology is available (use face averaging); when the field is noisy without preprocessing.

## Background
This method is used in volume rendering and terrain synthesis to compute smooth vertex normals for isosurfaces or heightmaps [S1, S2, unofficial]. It was discussed in the context of Marching Cubes algorithms as an alternative to averaging face normals [S1, unofficial].
