# Third Order Elimination (Scaling)

Also called: Scaling, PSR Scaling

## Overview
Third Order Elimination (Scaling) is a quadratic interpolation method that derives a second-order polynomial from a cubic Hermite basis by scaling the input derivatives to force the third-order coefficient to zero [S1]. It solves the problem of approximating a smooth implicit function with reduced computational complexity while maintaining continuity, specifically distinguishing itself from [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) and [Piecewise Quadratic Hermite Interpolation](4001-piecewise-quadratic-hermite-interpolation.md) by using a multiplicative scaling factor rather than a least-squares fit or additive offset [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Function values $v_0, v_1$ at endpoints $t=0, t=1$; derivatives $d_0, d_1$ at endpoints.
*   **Output:** A quadratic polynomial $p(t) = a_0 + a_1 t + a_2 t^2$ defined on $t \in [0, 1]$.

**Data Structures:**
The method operates on scalar values. No complex data structures are required beyond the four input scalars.

**Steps:**
1.  Calculate the scaling factor $s$ using the input values and derivatives:
    $$ s = \frac{2v_1 - 2v_0}{d_0 + d_1} $$
2.  Scale the derivatives:
    $$ d'_0 = s \cdot d_0 $$
    $$ d'_1 = s \cdot d_1 $$
3.  Compute the polynomial coefficients $a_0, a_1, a_2$ based on the value constraints $p(0)=v_0, p(1)=v_1$ and derivative constraints $p'(0)=d'_0, p'(1)=d'_1$.
    *   $a_0 = v_0$
    *   $a_1 = d'_0$
    *   $a_2 = \frac{d'_1 - d'_0}{2} - a_1$ (Derived from $p'(1) = a_1 + 2a_2 = d'_1$)

    *Note: The source explicitly defines the condition for elimination as $2v_0 - 2v_1 + s \cdot d_0 + s \cdot d_1 = 0$ [S1]. Solving for $s$ yields the formula in Step 1. The resulting polynomial is quadratic because the cubic term $a_3$ is eliminated by construction.*

**Parameters:**
*   Typical values: None. The method is deterministic based on input data.

**Edge Cases and Pitfalls:**
*   **Instability:** The solution becomes unstable if $d_0 + d_1 \approx 0$ (derivatives cancel each other out) [S1]. This occurs when the partial derivatives have opposite signs.
*   **Mitigation:** The instability is less likely to cause issues for functions with steep gradients in the vicinity of an isosurface (e.g., indicator functions), where derivatives are unlikely to have opposite signs [S1].

**Pseudocode:**
```python
def third_order_elimination_scaling(v0, v1, d0, d1):
    """
    Computes quadratic polynomial coefficients for third order elimination via scaling.
    
    Args:
        v0: Value at t=0
        v1: Value at t=1
        d0: Derivative at t=0
        d1: Derivative at t=1
        
    Returns:
        tuple: (a0, a1, a2) coefficients for p(t) = a0 + a1*t + a2*t^2
    """
    # Calculate scaling factor s
    denominator = d0 + d1
    
    # Guard against division by zero or near-zero
    if abs(denominator) < 1e-9:
        # Fallback to linear interpolation or handle error appropriately [G]
        # Using linear interpolation as a safe default when derivatives cancel
        a0 = v0
        a1 = v1 - v0
        a2 = 0.0
        return (a0, a1, a2)
    
    s = (2.0 * v1 - 2.0 * v0) / denominator
    
    # Scale derivatives
    d0_scaled = s * d0
    d1_scaled = s * d1
    
    # Compute quadratic coefficients
    # p(t) = a0 + a1*t + a2*t^2
    # p(0) = a0 = v0
    # p'(0) = a1 = d0_scaled
    # p'(1) = a1 + 2*a2 = d1_scaled  =>  a2 = (d1_scaled - a1) / 2
    
    a0 = v0
    a1 = d0_scaled
    a2 = (d1_scaled - a1) / 2.0
    
    return (a0, a1, a2)
```

## Subtopics

### Third Order Elimination (Offset)
A quadratic method obtained by adding an offset $o$ to derivatives to eliminate the third order coefficient $a_3$ [S1]. It solves for $o$ using the equation $2v_0 - 2v_1 + (d_0 + o) + (d_1 + o) = 0$, yielding $o = \frac{2v_1 - 2v_0 - d_0 - d_1}{2}$ [S1]. This solution is equivalent to the Least-Squares Derivatives method (equation 11 in [S1]) [S1]. It is chosen when one prefers an additive adjustment to derivatives rather than scaling, and it avoids the instability of the scaling method when $d_0 + d_1 \approx 0$ [S1].

## Operating characteristics
*   **Time Complexity:** $O(1)$ arithmetic operations.
*   **Memory Complexity:** $O(1)$ auxiliary storage.
*   **Strengths:** Reduces a cubic Hermite interpolation to a quadratic one, potentially simplifying downstream processing or evaluation. Implemented in the PSR code for interpolating indicator functions [S1].
*   **Limitations:** Numerically unstable when $d_0 + d_1 \approx 0$ [S1]. Not suitable for functions where derivatives at endpoints are likely to have opposite signs [S1].
*   **When to use:** When interpolating indicator functions or similar implicit functions with steep gradients where derivatives are unlikely to cancel out [S1].

## Background
The method originates from the work on accurate isosurface interpolation with Hermite data [S1]. It is specifically implemented in the PSR (Presumably "Piecewise Smooth Representation" or similar context from the source) code for interpolating the indicator function [S1]. The technique is part of a family of methods that manipulate cubic Hermite coefficients to achieve lower-order polynomial behavior (quadratic) while preserving value and derivative constraints in a least-squares or elimination sense [S1].
