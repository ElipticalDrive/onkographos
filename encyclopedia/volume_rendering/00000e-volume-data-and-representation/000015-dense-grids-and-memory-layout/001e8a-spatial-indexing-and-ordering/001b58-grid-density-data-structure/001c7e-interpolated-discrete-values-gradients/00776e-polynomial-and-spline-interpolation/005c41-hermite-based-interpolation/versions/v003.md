# Hermite-based Interpolation

Also called: Hermite interpolation, Gradient-based interpolation

## Overview
Hermite-based interpolation constructs a continuous, differentiable scalar field by interpolating both function values and their spatial derivatives (gradients) stored at grid vertices [G]. It differs from its siblings by explicitly utilizing gradient information to guarantee $C^1$ continuity, allowing the exact normals of the reconstructed surface to be used as shading normals, which provides a storage-efficient replacement for normal mapping [G].

## Shared principles
The family operates on a dense grid tensor $\mathbf{G}$ of shape $(D_x, D_y, D_z, C)$, where $D$ are spatial dimensions and $C$ is the channel count (e.g., density, color, or geometry parameters) [G]. The core mechanism involves mapping a continuous query point $\mathbf{p} = (x, y, z)$ to a local support region of discrete control points or vertices, evaluating basis functions over this region, and computing a weighted sum [G].

1.  **Coordinate Mapping:** Query coordinates are normalized or mapped to the grid's indexing space [G]. For a grid with origin $\mathbf{x}_0$ and spacing $\mathbf{dx}$, the continuous coordinate is transformed to a local fractional coordinate $\tilde{\mathbf{x}}$ within a unit cell or support window [G].
2.  **Support Selection:** A subset of grid vertices is selected based on the query position [G].
    *   For linear/trilinear methods, this is the 8 corners of the enclosing voxel [G].
    *   For cubic B-splines, this is the $4 \times 4 \times 4$ block of control points surrounding the query point [G].
3.  **Basis Evaluation:** Weighting coefficients are computed using basis functions $B_i(\tilde{x})$ [G]. These functions must satisfy specific properties:
    *   **Partition of Unity:** $\sum B_i(\tilde{x}) = 1$ to ensure constant fields are reproduced exactly [G].
    *   **Continuity:** The degree of the polynomial determines the continuity order ($C^0$ for linear, $C^2$ for cubic B-splines) [G].
4.  **Weighted Summation:** The interpolated value $u(\mathbf{p})$ is calculated as:
    $$ u(\mathbf{p}) = \sum_{i} \sum_{j} \sum_{k} B_i(\tilde{x}) B_j(\tilde{y}) B_k(\tilde{z}) w_{i,j,k} $$
    where $w_{i,j,k}$ are the values or weights at the selected support points [G].
5.  **Gradient Computation:** Gradients are derived by differentiating the basis functions with respect to the query coordinates, allowing for the computation of $\nabla u(\mathbf{p})$ [G].

```python
def hermite_interpolate(grid, gradients, p, spacing):
    """
    Generic Hermite interpolation for a scalar field.
    grid: 3D array of values
    gradients: 3D array of vectors (dx, dy, dz)
    p: (x, y, z) query point
    spacing: (dx, dy, dz) grid spacing
    """
    ix, iy, iz = int(p[0]), int(p[1]), int(p[2])
    tx, ty, tz = p[0] - ix, p[1] - iy, p[2] - iz

    # 1D cubic Hermite basis functions
    def basis(t):
        t2, t3 = t*t, t*t*t
        h0 = 2*t3 - 3*t2 + 1
        h1 = -2*t3 + 3*t2
        h2 = t3 - 2*t2 + t
        h3 = t3 - t2
        return h0, h1, h2, h3

    hx = basis(tx)
    hy = basis(ty)
    hz = basis(tz)

    # Gather 8 vertices and scale derivatives by spacing
    def get_vertex(dx, dy, dz):
        v = grid[ix+dx, iy+dy, iz+dz]
        g = gradients[ix+dx, iy+dy, iz+dz]
        return v, g[0]*spacing[0], g[1]*spacing[1], g[2]*spacing[2]

    # Tensor product interpolation
    # Interpolate along X
    ux = [0.0]*4
    for dy in range(2):
        for dz in range(2):
            v0, d0x, d0y, d0z = get_vertex(0, dy, dz)
            v1, d1x, d1y, d1z = get_vertex(1, dy, dz)
            ux[dy*2 + dz] = hx[0]*v0 + hx[1]*v1 + hx[2]*d0x + hx[3]*d1x

    # Interpolate along Y
    uy = [0.0]*2
    for dz in range(2):
        v0 = ux[dz]
        d0y = hx[0]*get_vertex(0, 0, dz)[2] + hx[1]*get_vertex(1, 0, dz)[2]
        v1 = ux[2 + dz]
        d1y = hx[0]*get_vertex(0, 1, dz)[2] + hx[1]*get_vertex(1, 1, dz)[2]
        uy[dz] = hy[0]*v0 + hy[1]*v1 + hy[2]*d0y + hy[3]*d1y

    # Interpolate along Z
    v0 = uy[0]
    d0z = hy[0]*get_vertex(0, 0, 0)[3] + hy[1]*get_vertex(1, 0, 0)[3]
    v1 = uy[1]
    d1z = hy[0]*get_vertex(0, 0, 1)[3] + hy[1]*get_vertex(1, 0, 1)[3]
    val = hz[0]*v0 + hz[1]*v1 + hz[2]*d0z + hz[3]*d1z

    return val
```

## Subtopics

### [Piecewise Quadratic Hermite Interpolation](4001-piecewise-quadratic-hermite-interpolation.md)
A method for interpolating a normalized scalar field within a 1D interval using two connected quadratic Bézier curves, ensuring $C^1$ continuity while respecting Hermite data (value and derivative) at both endpoints. It solves the incompatibility of single quadratic interpolation with four constraints (two values, two derivatives) by splitting the interval, providing a numerically stable and efficient alternative to cubic interpolation for root isolation in volume rendering. It is specifically designed for use within the SCALIS framework, where it operates on a normalized field $g \circ f \circ r^{-1}$ to improve convergence for small numbers of subdivisions compared to cubic interpolation on the original field.

### [Hermite Interpolation of Scalar Fields](9450-hermite-interpolation-of-scalar-fields.md)
Renders scalar-valued functions (such as height fields or signed distance fields) by storing partial derivatives alongside function values and using Hermite interpolation between samples to guarantee a globally $C^1$-continuous result. It differs from its siblings by explicitly utilizing gradient information to construct a cubic Hermite surface, allowing the exact normals of this surface to be used as shading normals, which provides a storage-efficient replacement for normal mapping with richer visual appearance.

### [Third Order Elimination (Scaling)](13712-third-order-elimination-scaling.md)
A quadratic interpolation method derived from cubic Hermite interpolation by scaling the input derivatives to force the cubic coefficient ($a_3$) to zero. It solves the problem of approximating a smooth field with a polynomial that retains quadratic continuity while strictly interpolating the function values at grid vertices. It differs from its sibling [Hermite Interpolation of Scalar Fields](9450-hermite-interpolation-of-scalar-fields.md) by discarding the cubic term entirely through derivative scaling, and from [Tricubic Interpolation](14963-tricubic-interpolation.md) by reducing the polynomial degree to ensure $C^1$ continuity without the complexity of cubic basis evaluation.

### [Tricubic Interpolation](14963-tricubic-interpolation.md)
A higher-order method that employs cubic polynomials over a $4 \times 4 \times 4$ neighborhood of 64 points to approximate smooth underlying functions. It provides $C^1$ continuity and fourth-order accuracy $O(h^4)$, making it superior to trilinear interpolation for gradient-sensitive tasks like volume rendering, albeit at increased computational cost.

## Background
Hermite interpolation is a classical numerical analysis technique for constructing piecewise polynomial functions that interpolate both function values and derivatives [G]. In the context of volume rendering and computer graphics, it has been adapted to handle 3D scalar fields, often referred to as Hermite splines or gradient-based interpolation [G]. The specific application to rendering scalar fields for $C^1$-continuous shading and normal estimation is detailed in [Hermite Interpolation of Scalar Fields](9450-hermite-interpolation-of-scalar-fields.md). The piecewise quadratic variant is utilized in the SCALIS framework for robust root isolation [see Piecewise Quadratic Hermite Interpolation](4001-piecewise-quadratic-hermite-interpolation.md). The third-order elimination method offers a computationally cheaper quadratic alternative [see Third Order Elimination (Scaling)](13712-third-order-elimination-scaling.md).
