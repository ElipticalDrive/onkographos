# NURBS Spline Representation

Also called: NURBS spline representation for measurement coordinates, NURBS surface for measurement coordinates, Rational B-spline optimization for view angles

## Overview
This method represents uncertain measurement coordinates (such as view angles and detector locations) as a NURBS surface whose control points and weights are optimized alongside volume reconstruction [S1, unofficial]. It differs from standard interpolation by treating the geometric parameters of the acquisition as learnable variables within a rational basis function framework, allowing for the correction of measurement noise and uncertainty during the reconstruction process [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** Measurement coordinates $\mathbf{p} = [\theta', t']^T$ (e.g., view angle and detector location), degrees $d_\Theta, d_T \in \mathbb{Z}^+$, segment counts $J, K$, and learnable parameters: control point vectors $Q_{u,v}$ and weights $w_{u,v}$.
*   **Outputs:** The rational basis value $b_{j,k}$ used to weight the contribution of control points to the final signal or gradient.

**Data Structures**
*   **Knot Vector:** A 1D array of size $N + d + 1$ for each dimension, where $N$ is the number of segments and $d$ is the degree. The elements are non-decreasing.
*   **Control Points:** A grid of vectors $Q_{u,v}$ of size $J \times K$.
*   **Weights:** A grid of scalars $w_{u,v}$ of size $J \times K$.

**Steps**
1.  **Construct Knot Vectors:** For the view angle dimension with $J$ segments and degree $d_\Theta$, create a knot vector $U$ of size $J + d_\Theta + 1$.
    *   Set $k_u = 0$ for $0 \le u < d_\Theta + 1$.
    *   Set $k_u$ uniformly spaced between 0 and 1 for $d_\Theta + 1 \le u \le J$.
    *   Set $k_u = 1$ for $J < u \le J + d_\Theta$.
    *   Repeat for the detector location dimension with $K$ segments and degree $d_T$ to create knot vector $V$.
2.  **Compute 1D Basis Functions:** For each dimension, compute the B-spline basis functions $Q_{u,d}(\xi)$ using the Cox-de Boor recursion.
3.  **Form Tensor Product:** Combine the 1D basis functions into 2D rational basis functions using the tensor product structure.
4.  **Evaluate:** Compute the weighted sum of control points normalized by the sum of weights.

**Formulas**
The rational basis function for indices $u, v$ at coordinates $(\theta', t')$ is defined as [S1, unofficial]:

$$ b_{u,v}(\theta', t') = \frac{w_{u,v} Q_{u,d_\Theta}(\theta') Q_{v,d_T}(t')}{\sum_{i=0}^{J-1} \sum_{j=0}^{K-1} w_{i,j} Q_{i,d_\Theta}(\theta') Q_{j,d_T}(t')} $$

*Note: The source text uses indices $j,k$ in the numerator summation description but $u,v$ in the specific term definition. The standard NURBS definition implies the basis function for control point $(u,v)$ is weighted by $w_{u,v}$. The source formula (16) in the notes appears to have a typo in the numerator summation indices vs the term definition. We follow the standard NURBS definition where $b_{u,v}$ corresponds to control point $Q_{u,v}$.*

The B-spline basis functions $Q_{u,d}(\xi)$ are computed via Cox-de Boor recursion [S1, unofficial]:

$$ Q_{u,0}(\xi) = \begin{cases} 1 & \text{if } k_u \le \xi < k_{u+1} \\ 0 & \text{otherwise} \end{cases} $$

$$ Q_{u,d}(\xi) = \frac{\xi - k_u}{k_{u+d} - k_u} Q_{u,d-1}(\xi) + \frac{k_{u+d+1} - \xi}{k_{u+d+1} - k_{u+1}} Q_{u+1,d-1}(\xi) $$

**Parameters**
*   $d_\Theta, d_T$: Degrees of the spline in each dimension. Typically small integers (e.g., 1, 2, 3).
*   $J, K$: Number of segments (control points) in each dimension.
*   $w_{u,v}$: Learnable weights.
*   $Q_{u,v}$: Learnable control points.

**Pitfalls**
*   **Zero Denominators:** In the Cox-de Boor recursion, if a denominator ($k_{u+d} - k_u$ or $k_{u+d+1} - k_{u+1}$) is zero, the corresponding term is set to zero [S1, unofficial].
*   **Boundary Conditions:** The knot vector construction ensures that the basis functions cover the domain $[0,1]$ with clamped boundaries (multiplicity of $d+1$ at ends).

**Pseudocode**

```python

def cox_de_boor(u, d, xi, knots):
    """
    Computes the B-spline basis function Q_{u,d}(xi).
    """
    if d == 0:
        # Check if xi is in [k_u, k_{u+1})
        # Note: Source says k_u <= k <= k_{u+1}. Usually half-open [k_u, k_{u+1}).
        # We will use <= for left, < for right to handle boundaries consistently.
        if knots[u] <= xi < knots[u+1]:
            return 1.0
        else:
            return 0.0
            
    # Denominator 1
    denom1 = knots[u+d] - knots[u]
    term1 = 0.0
    if denom1 != 0:
        term1 = ((xi - knots[u]) / denom1) * cox_de_boor(u, d-1, xi, knots)
        
    # Denominator 2
    denom2 = knots[u+d+1] - knots[u+1]
    term2 = 0.0
    if denom2 != 0:
        term2 = ((knots[u+d+1] - xi) / denom2) * cox_de_boor(u+1, d-1, xi, knots)
        
    return term1 + term2

def evaluate_nurbs_basis(theta, t, J, K, d_theta, d_t, weights, control_points, knots_theta, knots_t):
    """
    Evaluates the NURBS basis functions for all control points.
    Returns a grid of basis values.
    """
    basis_values = []
    total_weighted_sum = 0.0
    total_weight_sum = 0.0
    
    for u in range(J):
        for v in range(K):
            # Compute 1D basis functions
            q_theta = cox_de_boor(u, d_theta, theta, knots_theta)
            q_t = cox_de_boor(v, d_t, t, knots_t)
            
            # Rational basis function numerator part (before division by sum)
            # b_{u,v} = (w * Q_theta * Q_t) / sum(w * Q_theta * Q_t)
            # We compute the unnormalized weight contribution
            w_uv = weights[u][v]
            numerator_term = w_uv * q_theta * q_t
            
            total_weighted_sum += numerator_term
            total_weight_sum += w_uv * q_theta * q_t # This is the denominator for the specific basis function
            
            # Store unnormalized basis for later normalization if needed, 
            # or just compute the final value.
            # The formula for the value u(p) is sum(b_{u,v} * Q_{u,v})
            # where b_{u,v} is the rational basis.
            
    # Normalize the basis functions
    # b_{u,v} = numerator_term / total_weight_sum
    # However, we need to return the basis values to multiply by control points.
    
    basis_grid = []
    for u in range(J):
        row = []
        for v in range(K):
            q_theta = cox_de_boor(u, d_theta, theta, knots_theta)
            q_t = cox_de_boor(v, d_t, t, knots_t)
            w_uv = weights[u][v]
            
            if total_weight_sum == 0:
                b_uv = 0.0
            else:
                b_uv = (w_uv * q_theta * q_t) / total_weight_sum
            row.append(b_uv)
        basis_grid.append(row)
        
    return basis_grid
```

## Subtopics

### B-spline Field Interpolation
Uses non-rational B-splines. Simpler evaluation but cannot represent conic sections exactly. Choose when weights are not needed or when rationality is not required. [11066-b-spline-field-interpolation.md]

### Tricubic Interpolation
Uses cubic polynomials in 3D. Higher continuity than linear but not rational. Choose for smooth 3D volume interpolation without angular parameterization. [14963-tricubic-interpolation.md]

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample evaluation, as the support of the basis functions is local (determined by the degree). The Cox-de Boor recursion is efficient.
*   **Memory Complexity:** $O(J \cdot K)$ to store control points and weights.
*   **Strengths:** Can model complex geometric uncertainties and non-linear relationships in measurement coordinates. Differentiable, allowing end-to-end optimization.
*   **Limitations:** Requires optimization of control points and weights, which adds computational overhead during training. Sensitive to knot vector placement and degree selection.
*   **When to use:** When measurement coordinates (angles, positions) are uncertain or noisy and need to be corrected during reconstruction.
*   **When not to use:** When measurement coordinates are known precisely and fixed, or when computational resources for optimization are limited.

## Background
This method originates from differentiable imaging frameworks that incorporate uncertainty in acquisition parameters. It was detailed in "Differentiable Uncalibrated Imaging" (2022), where NURBS surfaces were used to optimize view angles and detector locations for 2D CT reconstruction [S1, unofficial]. The implementation relied on extending the PyTorch source code from the NURBS-Diff module [S1, unofficial].
