# Scattered Data Interpolation (Hardy/Shepard)

Also called: Radial Basis Function Interpolation, Multiquadric Interpolation, Inverse Distance Weighting

## Overview
This family reconstructs continuous volume fields from sparse, irregularly distributed sample points, addressing the limitation of grid-based methods that require structured data. It differs from sibling methods like [B-spline Field Interpolation](11066-b-spline-field-interpolation.md) by not relying on a pre-defined dense grid topology for basis evaluation, instead using distance-based kernels to determine influence [S1, unofficial]. It is distinct from [Shepard Local Interpolation](19992-shepard-local-interpolation.md) in that the global variant considers all sample points simultaneously, whereas local variants restrict influence to a neighborhood [S1, unofficial].

## Shared principles
The family operates on a set of $N$ scattered sample points $\mathbf{x}_i \in \mathbb{R}^3$ with associated scalar values $d_i$. The core mechanism maps a continuous query point $\mathbf{p}$ to a weighted combination of these samples using a radial basis function $\phi(r)$, where $r$ is the Euclidean distance between $\mathbf{p}$ and $\mathbf{x}_i$.

1.  **Kernel Definition:** A radial kernel $\phi(\|\mathbf{x}_i - \mathbf{p}\|)$ defines the influence of sample $i$ at query point $\mathbf{p}$. Common kernels include the multiquadric $\phi(r) = \sqrt{r^2 + R^2}$ and the inverse distance $\phi(r) = 1/r^2$ [S1, unofficial].
2.  **Global vs. Local Support:**
    *   **Global:** The value at $\mathbf{p}$ depends on all $N$ samples. Coefficients are determined by solving a linear system $A\mathbf{c} = \mathbf{d}$, where $A_{ij} = \phi(\|\mathbf{x}_i - \mathbf{x}_j\|)$ [S1, unofficial].
    *   **Local:** The value at $\mathbf{p}$ depends only on the $k$ nearest neighbors. This avoids solving a large global system, reducing complexity from $O(N^3)$ to $O(N \cdot k)$ per query [S1, unofficial].
3.  **Interpolation Formula:**
    *   For global interpolation: $u(\mathbf{p}) = \sum_{i=1}^{N} c_i \phi(\|\mathbf{x}_i - \mathbf{p}\|)$ [S1, unofficial].
    *   For local interpolation (Shepard): $u(\mathbf{p}) = \frac{\sum_{i=1}^{k} w_i d_i}{\sum_{i=1}^{k} w_i}$, where $w_i = \phi(\|\mathbf{x}_i - \mathbf{p}\|)$ [S1, unofficial].
4.  **Parameter Sensitivity:** The shape parameter $R$ (in multiquadric) and neighbor count $k$ (in local) significantly affect smoothness and computational cost [S1, unofficial].

## Subtopics

### [Shepard Local Interpolation](19992-shepard-local-interpolation.md)
Estimates values by weighting the $k$ nearest neighbors using inverse squared distance. It differs from the global variant by limiting influence to a local neighborhood, reducing computational cost and memory usage for large datasets. Choose this when $N$ is large and real-time or low-memory performance is required.

### [Hardy Global Interpolation](19995-hardy-global-interpolation.md)
Uses Hardy's multiquadric kernel to solve a global linear system for coefficients. It differs from local methods by considering all sample points simultaneously, providing smooth global continuity but incurring $O(N^3)$ cost. Choose this when $N$ is small and high global smoothness is critical.

### Hardy Local Interpolation
A variant that combines Hardy's multiquadric kernel with local neighbor selection. It uses a K-D tree to find $k$ nearest neighbors and solves a local linear system for coefficients [S1, unofficial].
*   **Definition:** Uses the multiquadric function $\phi(r) = \sqrt{r^2 + R^2}$ within a local support region [S1, unofficial].
*   **Steps:**
    1. Initialize `ret` with zeros and copy sample point data to corresponding grid positions [S1, unofficial].
    2. For each point in the volume grid, query the K-D tree for the $k$ nearest neighbors (`inds`) [S1, unofficial].
    3. Retrieve the $k$ nearest neighbors into `vals` [S1, unofficial].
    4. Calculate local coefficients `c` by calling `self.C(R, vals)` [S1, unofficial].
    5. For each neighbor `i` in `vals`, calculate `val = R + distance2(vals[i], point)` and set `ret[point]` to `c[i] * math.pow(val, power)` [S1, unofficial]. Note: This loop overwrites `ret[point]` for each `i`, so only the last neighbor's contribution is stored [S1, unofficial].

## Background
Originating from the work of Michael D. Hardy in the 1970s on multiquadric interpolation, this method was developed for geostatistical and scattered data fitting problems [S1, unofficial]. It has been adapted for volume rendering to reconstruct dense fields from sparse sensor data or particle simulations [S1, unofficial]. The local variant, often associated with Shepard (1968), is widely used in computer graphics for smooth surface reconstruction and texture mapping from scattered points [S1, unofficial].
