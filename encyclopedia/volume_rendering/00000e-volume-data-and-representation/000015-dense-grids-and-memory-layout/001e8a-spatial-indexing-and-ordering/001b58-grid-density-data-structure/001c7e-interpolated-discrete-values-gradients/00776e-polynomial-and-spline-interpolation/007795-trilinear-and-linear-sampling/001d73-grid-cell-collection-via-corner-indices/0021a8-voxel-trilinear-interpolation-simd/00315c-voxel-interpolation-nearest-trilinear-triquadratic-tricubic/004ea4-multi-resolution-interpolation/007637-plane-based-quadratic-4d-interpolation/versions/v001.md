# Plane-based Quadratic 4D Interpolation

Also called: Local plane interpolation, SVO 4D interpolation

## Overview
A method to interpolate multi-resolution volumetric fields (opacity and radiance) stored in a Sparse Voxel Octree (SVO) using local plane samples (function value and spatial gradient) to achieve quadratic accuracy in 3D space and linear accuracy in Level-of-Detail (LoD) space [S1, unofficial]. It sets itself apart from standard trilinear interpolation by allowing field extrema to be positioned continuously in 3D space rather than being fixed to discrete node centers, which is critical for fine geometry reconstruction from coarse initial SVOs [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A query point $\mathbf{q} = [\mathbf{x}, d(\mathbf{q})] \in \mathbb{R}^4$, where $\mathbf{x}$ is the 3D spatial position and $d(\mathbf{q})$ is the depth (LoD) level. An SVO where each node $n_j$ stores a local plane defined by a function value $f_0(\mathbf{x}_j, d_j)$ and a spatial gradient $\nabla f(\mathbf{x}_j, d_j)$ at its center $\mathbf{x}_j$ and depth $d_j$ [S1, unofficial].
*   **Output:** The interpolated field value $f(\mathbf{q})$ [S1, unofficial].

**Data Structures:**
Each SVO node stores:
1.  Center position $\mathbf{x}_j \in \mathbb{R}^3$.
2.  Tree depth $d_j \in \mathbb{Z}$.
3.  Function value $f_0 \in \mathbb{R}$ (or $\mathbb{R}^3$ for radiance).
4.  Spatial gradient $\nabla f \in \mathbb{R}^3$.

**Steps:**
1.  **Identify Neighbors:** Determine the 16 neighboring nodes $\mathcal{N}_{16}(\mathbf{q})$ surrounding the query point $\mathbf{q}$ in 4D space. These consist of the 8 spatial neighbors at the current LoD level and the 8 spatial neighbors at the adjacent lower LoD level [S1, unofficial].
2.  **Determine LoD Levels:** Identify the two surrounding LoD levels $l$ and $l-1$ based on the query depth $d(\mathbf{q})$. The levels are chosen according to the Nyquist sampling theorem to avoid aliasing: $\sigma_n \leq \sigma(t) < 0.5 \cdot \sigma_n$, where $\sigma_n$ is the node size and $\sigma(t)$ is the scene sampling distance [S1, unofficial]. If the tree is not deep enough for the required depth, a lower depth is used, resulting in a "blurry" result [S1, unofficial].
3.  **Compute 3D Weights:** For each of the two LoD levels ($l$ and $l-1$), compute trilinear interpolation weights $w_{3\mathbf{D}}$ based on the Euclidean distance of the query $\mathbf{x}$ to the 8 surrounding node centers $\mathbf{x}_j$ at that specific tree level [S1, unofficial].
4.  **Compute LoD Weights:** Compute linear blending weights $w_{\text{LoD}}$ based on the distance of the query depth $d(\mathbf{q})$ to the depths of the two surrounding 8-neighborhoods (levels $l$ and $l-1$) [S1, unofficial].
5.  **Calculate 4D Weights:** Combine the weights: $w_{4\mathbf{D}}(\mathbf{q}, \mathbf{n}_j) = w_{\text{LoD}}(d(\mathbf{q}), d_j) \cdot w_{3\mathbf{D}}(\mathbf{x}, \mathbf{x}_j)$ [S1, unofficial].
6.  **Interpolate Field Value:** Sum the contributions of all 16 neighbors using the local plane approximation:
    $$f(\mathbf{q}) = \sum_{j \in \mathcal{N}_{16}(\mathbf{q})} w_{4\mathbf{D}}(\mathbf{q}, \mathbf{n}_j) \cdot (f_0(\mathbf{x}_j, d_j) + \Delta \mathbf{x} \cdot \nabla f(\mathbf{x}_j, d_j))$$
    where $\Delta \mathbf{x} = \mathbf{x} - \mathbf{x}_j$ is the distance vector from the node center to the query position [S1, unofficial].

**Pseudocode:**
```python
def plane_based_quadratic_4d_interpolation(query_x, query_depth, sv_nodes):
    """
    Interpolate field value at query point using plane-based 4D interpolation.
    
    Args:
        query_x: 3D vector (x, y, z) of the query point.
        query_depth: Float depth (LoD) of the query point.
        sv_nodes: List of SVO nodes. Each node is a dict/object with:
                  - center: 3D vector (x, y, z)
                  - depth: Integer tree depth
                  - f0: Scalar or vector field value
                  - grad: 3D vector spatial gradient
    
    Returns:
        Interpolated field value f(q).
    """
    # Step 1 & 2: Determine surrounding LoD levels l and l-1
    # Based on Nyquist criterion: sigma_n <= sigma(t) < 0.5 * sigma_n
    # In practice, this selects the two discrete tree levels bracketing the query depth.
    # Let's assume we identify the two relevant depths: depth_high and depth_low.
    # depth_high is the level >= query_depth, depth_low is depth_high - 1.
    # Note: If tree is not deep enough, use available lower depth [S1, unofficial].
    
    # Identify nodes at the two relevant levels
    nodes_l = [n for n in sv_nodes if n.depth == depth_high]
    nodes_l_minus_1 = [n for n in sv_nodes if n.depth == depth_low]
    
    # Step 3: Compute 3D trilinear weights for level l
    # Weights depend on distance from query_x to node centers at level l
    weights_l = compute_trilinear_weights(query_x, nodes_l)
    
    # Step 3: Compute 3D trilinear weights for level l-1
    weights_l_minus_1 = compute_trilinear_weights(query_x, nodes_l_minus_1)
    
    # Step 4: Compute LoD linear weight
    # Weight depends on distance from query_depth to depth_high and depth_low
    w_lod_high = compute_linear_lod_weight(query_depth, depth_high, depth_low)
    w_lod_low = 1.0 - w_lod_high
    
    # Step 5 & 6: Interpolate
    result = 0.0
    
    # Process nodes at level l
    for i, node in enumerate(nodes_l):
        # 4D weight = LoD weight * 3D weight
        w_4d = w_lod_high * weights_l[i]
        
        # Local plane approximation: f0 + dx . grad
        dx = query_x - node.center
        local_val = node.f0 + dot(dx, node.grad)
        
        result += w_4d * local_val
        
    # Process nodes at level l-1
    for i, node in enumerate(nodes_l_minus_1):
        # 4D weight = LoD weight * 3D weight
        w_4d = w_lod_low * weights_l_minus_1[i]
        
        # Local plane approximation: f0 + dx . grad
        dx = query_x - node.center
        local_val = node.f0 + dot(dx, node.grad)
        
        result += w_4d * local_val
        
    return result

    """
    Compute linear weight for LoD interpolation.

    # Linear interpolation between depth_high and depth_low
    # Weight for depth_high is proportional to distance from depth_low
    # Weight for depth_low is proportional to distance from depth_high
    
    # Assuming depth_high and depth_low are integers or floats representing levels

    dist_high = abs(query_depth - depth_high)
    dist_low = abs(query_depth - depth_low)
    
    total_dist = dist_high + dist_low
    
    if total_dist == 0:
```

**Parameters:**
*   **Nyquist Criterion:** The selection of LoD levels is governed by $\sigma_n \leq \sigma(t) < 0.5 \cdot \sigma_n$ [S1, unofficial].
*   **Border Plane:** For sparse regions where SVO nodes are missing, a globally constant "border" plane representing free space substitutes the data of all missing neighbors [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Insufficient Tree Depth:** If the SVO is not deep enough to support the required LoD levels for the query, a lower depth is used, resulting in a "blurry" query result [S1, unofficial].
*   **Sparse Regions:** Missing nodes are replaced by a constant border plane [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Requires searching for 16 neighbors and performing 16 local plane evaluations with trilinear and linear weight calculations. The complexity is constant with respect to the total number of nodes, but depends on the local density of the SVO.
*   **Memory Complexity:** Each node stores an additional gradient vector $\nabla f$ compared to simple value storage.
*   **Strengths:** Allows field extrema to be positioned continuously in 3D space, improving geometry reconstruction from coarse SVOs compared to methods that only optimize direct function samples [S1, unofficial].
*   **Limitations:** Requires storing gradients. Performance may degrade in sparse regions if not handled efficiently with the border plane.
*   **When to use:** When high-quality interpolation of multi-resolution volumetric fields is needed, especially when the initial SVO is coarse and fine geometry reconstruction is critical [S1, unofficial].
*   **When not to use:** If memory is extremely constrained and gradients cannot be stored, or if the SVO is very dense and simple trilinear interpolation is sufficient.

## Background
Originated in the context of Explicit Radiance Field Reconstruction [S1, unofficial]. It builds on the concept of Sparse Voxel Octrees and extends them with gradient information to enable higher-order interpolation. The method is analogous to sampling mipmap textures but in 4D (3D space + LoD) [S1, unofficial].
