# Third Order Elimination (Scaling)

Also called: SCALING

## Overview
Third Order Elimination (Scaling) is a quadratic interpolation method that derives a second-order polynomial by scaling the input derivatives to eliminate the third-order coefficient of a cubic Hermite polynomial [S1]. It is chosen when a strictly quadratic approximation is required but the derivative magnitudes need to be adjusted to satisfy the value constraints exactly, distinguishing it from [Piecewise Quadratic Hermite Interpolation](4001-piecewise-quadratic-hermite-interpolation.md) which uses least-squares optimization, and [Hermite Interpolation of Scalar Fields](9450-hermite-interpolation-of-scalar-fields.md) which retains the cubic term [S1].

## How it works
**Inputs:**
*   $v_0$: Function value at parameter $t=0$.
*   $v_1$: Function value at parameter $t=1$.
*   $d_0$: Derivative at $t=0$.
*   $d_1$: Derivative at $t=1$.

**Outputs:**
*   $p(t)$: The quadratic polynomial $p(t) = a_0 + a_1 t + a_2 t^2$ for $t \in [0, 1]$.

**Data Structures:**
The method computes three scalar coefficients $a_0, a_1, a_2$. No complex data structures are required beyond the four input scalars.

**Steps:**
1.  Calculate the scaling factor $s$ using the formula:
    $$ s = \frac{2v_1 - 2v_0}{d_0 + d_1} $$
2.  Scale the derivatives:
    $$ d'_0 = s \cdot d_0 $$
    $$ d'_1 = s \cdot d_1 $$
3.  Determine the polynomial coefficients $a_0, a_1, a_2$ for the quadratic polynomial $p(t) = a_0 + a_1 t + a_2 t^2$ that satisfies:
    *   $p(0) = v_0$
    *   $p(1) = v_1$
    *   $p'(0) = d'_0$
    *   $p'(1) = d'_1$

    From the boundary conditions:
    $$ a_0 = v_0 $$
    $$ a_1 = d'_0 $$
    $$ a_0 + a_1 + a_2 = v_1 \implies a_2 = v_1 - v_0 - d'_0 $$

    Substituting $d'_0 = s \cdot d_0$:
    $$ a_0 = v_0 $$
    $$ a_1 = s \cdot d_0 $$
    $$ a_2 = v_1 - v_0 - s \cdot d_0 $$

**Pitfalls:**
*   **Instability:** The solution becomes numerically unstable if $d_0 + d_1 \approx 0$ (i.e., the derivatives cancel each other out) [S1]. This occurs when the partial derivatives have opposite signs or are both near zero. The stability depends on the properties of the implicit function; for example, it is stable for indicator functions with steep gradients where derivatives are unlikely to have opposite signs [S1].

**Pseudocode:**
```python
def third_order_elimination_scaling(v0, v1, d0, d1):
    """
    Computes quadratic interpolation coefficients using Third Order Elimination (Scaling).
    
    Args:
        v0 (float): Value at t=0.
        v1 (float): Value at t=1.
        d0 (float): Derivative at t=0.
        d1 (float): Derivative at t=1.
        
    Returns:
        tuple: (a0, a1, a2) coefficients for p(t) = a0 + a1*t + a2*t^2
    """
    # Calculate scaling factor s
    # Guard against division by zero if d0 + d1 is effectively zero
    denom = d0 + d1
    if abs(denom) < 1e-12:
        # Fallback to linear interpolation or handle error appropriately [G]
        # Linear interpolation: p(t) = v0 + (v1 - v0)*t
        return (v0, v1 - v0, 0.0)
    
    s = (2.0 * v1 - 2.0 * v0) / denom
    
    # Scaled derivative at t=0
    d0_scaled = s * d0
    
    # Coefficients for p(t) = a0 + a1*t + a2*t^2
    a0 = v0
    a1 = d0_scaled
    a2 = v1 - v0 - d0_scaled
    
    return (a0, a1, a2)
```

## Subtopics

### Third Order Elimination (Offset)
A quadratic method obtained by adding an offset $o$ to derivatives to eliminate the third order coefficient $a_3$ [S1]. The offset is calculated as $o = \frac{2v_1 - 2v_0 - d_0 - d_1}{2}$ [S1]. This solution is equivalent to the Least-Squares Derivatives method (equation 11 in [S1]) [S1].

## Operating characteristics
*   **Complexity:** $O(1)$ time and memory per interpolation point.
*   **Strengths:** Produces a strictly quadratic polynomial, which can be computationally cheaper than cubic evaluation in some hardware contexts. It exactly satisfies value and scaled derivative constraints.
*   **Limitations:** Numerical instability when $d_0 + d_1 \approx 0$. It assumes the derivatives can be uniformly scaled to fit a quadratic curve, which may distort the shape if the original derivatives are not consistent with a quadratic model [S1].
*   **Usage:** Implemented in the PSR code for interpolating the indicator function [S1].

## Background
The method is described in the context of accurate isosurface interpolation with Hermite data [S1]. It is presented as an alternative to cubic Hermite interpolation when a second-order polynomial is preferred, specifically by eliminating the cubic term $a_3$ through scaling [S1].
