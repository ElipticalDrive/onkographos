# Tricubic Interpolation

Also called: Tricubic Hermite Interpolation

## Overview
Tricubic interpolation is a higher-order method that employs cubic polynomials over a 4x4x4 neighborhood of 64 points to approximate smooth underlying functions with an accuracy of $O(h^4)$, where $h$ is the grid spacing [S1]. Unlike trilinear interpolation which provides only $C^0$ continuity, tricubic interpolation yields $C^1$ continuity, significantly reducing artifacts in gradient-sensitive tasks such as volume rendering and medical imaging upsampling [S1]. It is chosen when differentiable outputs are required, despite the increased computational expense compared to lower-order methods [S1].

## How it works
**Inputs and Outputs:**
- Input: A dense grid tensor $\mathbf{G}$ of shape $(D_x, D_y, D_z, C)$ containing scalar values and their spatial gradients [S1][S2, unofficial].
- Input: A query point $\mathbf{p} \in \mathbb{R}^3$.
- Output: The interpolated value $f(\mathbf{p})$ and optionally its gradient $\nabla f(\mathbf{p})$.

**Data Structures:**
The method requires access to the grid values and gradients at the 8 corners of the enclosing grid cell. For a cell defined by integer indices $(i, j, k)$, the required data consists of:
- 8 scalar values: $\mathbf{G}_{i+l, j+m, k+n}$ for $l,m,n \in \{0,1\}$.
- 24 gradient vectors: $\nabla \mathbf{G}_{i+l, j+m, k+n}$ for $l,m,n \in \{0,1\}$, where each gradient is a 3D vector $(\partial_x, \partial_y, \partial_z)$.

**Numbered Steps:**
1. **Coordinate Mapping:** Map the query point $\mathbf{p}$ to local cell coordinates $(u, v, w) \in [0, 1]^3$ relative to the enclosing grid cell defined by integer indices $(i, j, k)$ [S1][S2, unofficial].
2. **Boundary Clamping:** Clamp indices $(i+l, j+m, k+n)$ to the grid domain $[0, D_d-1]$ if they fall outside the bounds [S1][S2, unofficial].
3. **Basis Evaluation:** Evaluate the 1D cubic Hermite basis functions for each dimension. The basis functions $H_0(t)$ and $H_1(t)$ for $t \in \{u, v, w\}$ are defined as:
   $$ H_0(t) = 2t^3 - 3t^2 + 1 $$
   $$ H_1(t) = t^3 - 2t^2 + t $$
   The derivatives of these basis functions are:
   $$ H'_0(t) = 6t^2 - 6t $$
   $$ H'_1(t) = 3t^2 - 4t + 1 $$
4. **Interpolation:** Compute the interpolated value using the tensor product of the basis functions and the gathered data. For a scalar field, the value is:
   $$ f(\mathbf{p}) = \sum_{l=0}^{1} \sum_{m=0}^{1} \sum_{n=0}^{1} \left[ H_l(u)H_m(v)H_n(w) \mathbf{G}_{i+l,j+m,k+n} + H'_l(u)H_m(v)H_n(w) \partial_x \mathbf{G}_{i+l,j+m,k+n} + H_l(u)H'_m(v)H_n(w) \partial_y \mathbf{G}_{i+l,j+m,k+n} + H_l(u)H_m(v)H'_n(w) \partial_z \mathbf{G}_{i+l,j+m,k+n} \right] $$
   Note: The gradient components $\partial_x, \partial_y, \partial_z$ must be scaled by the grid spacing $h$ if the gradients are stored as finite differences rather than normalized derivatives [S2, unofficial].

**Parameters:**
- Grid spacing $h$: Determines the scaling of gradient terms. Not given in the sources.

**Edge Cases and Pitfalls:**
- **Precision:** The use of cubic polynomials increases computational cost and potential numerical instability if gradients are noisy [S1].
- **Boundary Conditions:** Standard clamping is applied, but discontinuities at boundaries may still cause artifacts if gradients are not consistent [S1].

**Pseudocode:**
```python
def tricubic_interpolate(G, gradients, p, grid_shape):
    # 1. Map p to local coordinates
    i, j, k = floor(p)
    u, v, w = p - (i, j, k)
    
    # 2. Clamp indices
    i = clamp(i, 0, grid_shape[0] - 2)
    j = clamp(j, 0, grid_shape[1] - 2)
    k = clamp(k, 0, grid_shape[2] - 2)
    
    # 3. Gather data
    # Values at 8 corners
    vals = []
    for l in [0, 1]:
        for m in [0, 1]:
            for n in [0, 1]:
                vals.append(G[i+l, j+m, k+n])
    
    # Gradients at 8 corners
    grads = []
    for l in [0, 1]:
        for m in [0, 1]:
            for n in [0, 1]:
                grads.append(gradients[i+l, j+m, k+n])
                
    # 4. Evaluate basis functions
    H0_u, H1_u = hermite_basis(u)
    H0_v, H1_v = hermite_basis(v)
    H0_w, H1_w = hermite_basis(w)
    
    dH0_u, dH1_u = hermite_derivative(u)
    dH0_v, dH1_v = hermite_derivative(v)
    dH0_w, dH1_w = hermite_derivative(w)
    
    # 5. Compute interpolated value
    result = 0.0
    idx = 0
    for l in [0, 1]:
        for m in [0, 1]:
            for n in [0, 1]:
                # Basis weights
                w_val = [H0_u, H1_u][l] * [H0_v, H1_v][m] * [H0_w, H1_w][n]
                w_dx = [dH0_u, dH1_u][l] * [H0_v, H1_v][m] * [H0_w, H1_w][n]
                w_dy = [H0_u, H1_u][l] * [dH0_v, dH1_v][m] * [H0_w, H1_w][n]
                w_dz = [H0_u, H1_u][l] * [H0_v, H1_v][m] * [dH0_w, dH1_w][n]
                
                # Add contribution
                result += w_val * vals[idx]
                # Note: Gradient scaling by grid spacing h is assumed to be handled in gradients storage
                result += w_dx * grads[idx][0]
                result += w_dy * grads[idx][1]
                result += w_dz * grads[idx][2]
                idx += 1
                
    return result

def hermite_basis(t):
    H0 = 2*t**3 - 3*t**2 + 1
    H1 = t**3 - 2*t**2 + t
    return H0, H1

def hermite_derivative(t):
    dH0 = 6*t**2 - 6*t
    dH1 = 3*t**2 - 4*t + 1
    return dH0, dH1
```

## Operating characteristics
- **Time Complexity:** $O(1)$ per query, but with a significantly higher constant factor than trilinear due to 64 coefficients and gradient evaluations [S1].
- **Memory Complexity:** Requires storing gradients alongside values, increasing memory usage by a factor of 4 (1 value + 3 gradient components per voxel) [S2, unofficial].
- **Measured Performance:** Studies confirm tricubic's edge in accuracy over trilinear for upsampled 3D volumes, albeit with longer processing times [S1].
- **Strengths:** $C^1$ continuity, superior approximation for smooth functions ($O(h^4)$ accuracy) [S1].
- **Limitations:** Increased computational expense, potential for artifacts if gradients are noisy or inconsistent [S1].
- **When to use:** When $C^1$ continuity is needed for differentiable outputs in visualization [S1].
- **When not to use:** When performance is critical and $C^0$ continuity is sufficient, or when data is not smooth [S1].

## Background
Tricubic interpolation was developed as a higher-order alternative to trilinear interpolation, leveraging cubic Hermite patches which require four control points and four tangents (gradients) [S2, unofficial]. It is widely used in medical imaging and volume rendering where smoothness and gradient continuity are important [S1]. The method is discussed in the context of irradiance volumes for games, highlighting its suitability for constructing smooth patches from samples and gradients [S2, unofficial].
