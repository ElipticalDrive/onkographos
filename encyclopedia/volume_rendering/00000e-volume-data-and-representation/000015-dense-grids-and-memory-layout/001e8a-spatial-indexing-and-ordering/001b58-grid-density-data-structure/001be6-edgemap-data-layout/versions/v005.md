# EdgeMap Data Layout

## Overview
The EdgeMap Data Layout is a data structure that stores geometric intersection data for volume rendering isosurfaces [S1, unofficial]. It organizes edge intersection positions, normals, traversal directions, and index offsets into parallel arrays sized to a total edge count [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D grid volume and an `IndexMap` instance that defines the total number of edges (`TotalSize`) and their enumeration [S1, unofficial].
- Output: An `EdgeMap` struct instance containing populated arrays for intersection data [S1, unofficial].

**Data Structures:**
The `EdgeMap` struct contains five fields, all sized to `Index.TotalSize` [S1, unofficial]:
1. `Index`: An `IndexMap` object that manages edge indexing and provides `TotalSize` [S1, unofficial].
2. `Intersections`: A `unique_ptr<glm::vec3[]>` storing the 3D coordinates of the intersection point on each edge [S1, unofficial].
3. `Normals`: A `unique_ptr<glm::vec3[]>` storing the surface normal at each intersection point [S1, unofficial].
4. `Directions`: A `unique_ptr<float[]>` storing traversal direction information [S1, unofficial].
5. `IndexOffset`: A `unique_ptr<int[]>` storing offset values for indexing [S1, unofficial].

class EdgeMap:
    def __init__(self, index_map):
        self.Index = index_map
        self.TotalSize = index_map.TotalSize
        self.Intersections = [None] * self.TotalSize
        self.Normals = [None] * self.TotalSize

        self.IndexOffset = [0] * self.TotalSize

## Subtopics

### [Edge ID Calculation](1570-edge-id-calculation.md)
Determines the unique global identifier for a vertex located on a specific edge of a voxel cell. It maps local geometric primitives to a global vertex buffer index, enabling coherent mesh construction from discrete voxel data. It differs from standard Cartesian indexing by using a vertex layout formula that accounts for 3D grid topology, ensuring consistent adjacency across voxel boundaries.

### [Enhanced Volume Data Set (EVDS)](11040-enhanced-volume-data-set-evds.md)
An Enhanced Volume Data Set (EVDS) is a volumetric representation that augments standard voxel grids with Boolean edge labels to encode local connectivity between vertices. It solves the problem of separating segmentation from geometric modeling by providing a topological map of which vertices belong to the same underlying object. Unlike standard dense grids, EVDS explicitly tracks whether two adjacent vertices share an active connection, enabling efficient topological analysis and hierarchical compression via L-blocks.
