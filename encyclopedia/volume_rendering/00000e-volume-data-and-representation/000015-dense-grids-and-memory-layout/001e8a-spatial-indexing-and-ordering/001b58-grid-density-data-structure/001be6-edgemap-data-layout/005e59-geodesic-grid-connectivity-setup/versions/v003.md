# Geodesic Grid Connectivity Setup

Also called: Geodesic Grid Connectivity Initialization, Geodesic Grid DVR Connectivity Setup

## Overview
This method constructs the adjacency and incidence data structures required for rendering and ray-marching on a geodesic unstructured grid, transforming raw topology into GPU-accessible formats [S1, unofficial]. It uploads these relationships as Texture Buffer Objects (TBOs) for shader access [S1, unofficial].

## How it works
**Inputs:** Raw grid topology arrays from a NetCDF file: `varCellCorners` (cell-to-corner), `varEdgeCorners` (edge-to-corner), `varCellEdges` (cell-to-edge) [S1, unofficial]. Coordinate arrays: `varCenterLat`, `varCenterLon`, `varCornerLat`, `varCornerLon` [S1, unofficial]. Climate data array: `varClimate` (values at cell centers) [S1, unofficial]. Dimensions: `nCell` (number of cells), `nEdges` (number of edges), `nCorners` (number of corners), `nCenters`, `nLayers`, `nTimes` [S1, unofficial].

**Outputs:** Derived connectivity arrays: `varCornerCells`, `varCornerEdges`, `varEdgeCells` [S1, unofficial]. GPU Texture Buffer Objects (TBOs) bound to shader uniforms [S1, unofficial]. Vertex Buffer Object (VBO) and Vertex Array Object (VAO) for triangle mesh rendering [S1, unofficial].

**Data Structures:**
1. `varCornerCells`: 2D integer array of size `nCorners` x 3. Stores the indices of the hexagonal cells adjacent to each corner. Initialized to -1 [S1, unofficial].
2. `varCornerEdges`: 2D integer array of size `nCorners` x 3. Stores the indices of the edges connected to each corner. Initialized to -1 [S1, unofficial].
3. `varEdgeCells`: 2D integer array of size `nEdges` x 2. Stores the indices of the two cells sharing each edge. Initialized to -1 [S1, unofficial].
4. `varEdgeCorners`: 2D integer array of size `nEdges` x 2. Stores the corner indices for each edge (provided by input) [S1, unofficial].
5. `varCellCorners`: 2D integer array of size `nCell` x 6. Stores the corner indices for each cell (provided by input) [S1, unofficial].

**Algorithm Steps:**
1. Initialize `varCornerCells` of size `nCorners` x 3 with -1 [S1, unofficial].
2. Iterate `iCell` from 0 to `nCell - 1`. For each cell, iterate `i` from 0 to 5. Retrieve `vtxIdx = varCellCorners[iCell * 6 + i]`. Find the first empty slot `j` (where `varCornerCells[vtxIdx * 3 + j] == -1`) by incrementing `j` while `j < 3`. If `varCornerCells[vtxIdx * 3 + j] == iCell`, set `bHasDuplicate = true` and break (handling degeneracy where a hexagon becomes a pentagon). If `j < 3` and `!bHasDuplicate`, store `iCell` in `varCornerCells[vtxIdx * 3 + j]` [S1, unofficial].
3. Initialize `varCornerEdges` of size `nCorners` x 3 with -1 [S1, unofficial].
4. Iterate `iEdge` from 0 to `nEdges - 1`. For each edge, iterate `i` from 0 to 1. Retrieve `vtxIdx = varEdgeCorners[iEdge * 2 + i]`. Find the first empty slot `j` by incrementing `j` while `j < 3` and `varCornerEdges[vtxIdx * 3 + j] != -1`. If `j < 3`, store `iEdge` in `varCornerEdges[vtxIdx * 3 + j]` [S1, unofficial].
5. Initialize `varEdgeCells` of size `nEdges` x 2 with -1 [S1, unofficial].
6. Iterate `iCell` from 0 to `nCell - 1`. For each cell, iterate `iEdge` from 0 to 5. Retrieve `idxEdge = varCellEdges[iCell * 6 + iEdge]`. Initialize `j=0` and `bHasDuplicate=false`. While `j < 2` and `varEdgeCells[idxEdge * 2 + j] != -1`: check if `varEdgeCells[idxEdge * 2 + j] == iCell`. If true, set `bHasDuplicate=true` and break. Increment `j`. If `j < 2` and `!bHasDuplicate`, store `iCell` in `varEdgeCells[idxEdge * 2 + j]` [S1, unofficial].
7. Create TBO `m_tex1d_grid_edge_corners` with format `GL_RG32I` and usage `GL_STATIC_DRAW`. Upload `nEdges * 2` integers from `varEdgeCorners`. Set shader uniform `edge_corners` to this TBO [S1, unofficial].
8. Create TBO `m_tex1d_grid_center_lat` with format `GL_R32F` and usage `GL_STATIC_DRAW`. Upload `nCenters` floats from `varCenterLat`. Set shader uniforms `center_lat` for `shader_triangle`, `shader_hexagon`, and `shader_dvr` to this TBO [S1, unofficial].
9. Create TBO `m_tex1d_grid_center_lon` with format `GL_R32F` and usage `GL_STATIC_DRAW`. Upload `nCenters` floats from `varCenterLon`. Set shader uniforms `center_lon` for `shader_triangle`, `shader_hexagon`, and `shader_dvr` to this TBO [S1, unofficial].
10. Create TBO `m_tex1d_grid_corner_lat` with format `GL_R32F` and usage `GL_STATIC_DRAW`. Upload `nCorners` floats from `varCornerLat`. Compute `minLat` and `maxLat` by iterating over `varCornerLat` data, storing them in `m_minmax_lat[0]` and `m_minmax_lat[1]`. Set shader uniforms `corner_lat` for `shader_triangle` and `shader_hexagon` to this TBO [S1, unofficial].
11. Create TBO `m_tex1d_grid_corner_lon` with format `GL_R32F` and usage `GL_STATIC_DRAW`. Upload `nCorners` floats from `varCornerLon`. Compute `minLon` and `maxLon` by iterating over `varCornerLon` data, storing them in `m_minmax_lon[0]` and `m_minmax_lon[1]`. Set shader uniforms `corner_lon` for `shader_triangle` and `shader_hexagon` to this TBO [S1, unofficial].
12. Create TBO `m_tex1d_grid_center_val` with format `GL_R32F` and usage `GL_STATIC_DRAW`. Upload `nTimes * nCenters * nLayers` floats from `varClimate`. Set shader uniform `nLayers` to `nLayers` for `shader_triangle`, `shader_hexagon`, and `shader_dvr`. Set shader uniforms `center_val` for `shader_triangle`, `shader_hexagon`, and `shader_dvr` to this TBO [S1, unofficial].
13. Create TBO `m_tex1d_grid_cell_corners` with format `GL_R32I` and usage `GL_STATIC_DRAW`. Upload `nCells * 6` integers from `varCellCorners`. Set shader uniforms `cell_corners` for `shader_triangle`, `shader_hexagon`, and `shader_dvr` to this TBO [S1, unofficial].
14. Create TBO `m_tex1d_grid_corner_cells` with format `GL_RGB32I` and usage `GL_STATIC_DRAW`. Upload `nCorners * 3` integers from `varCornerCells`. Set shader uniforms `corner_cells` for `shader_triangle` and `shader_dvr` to this TBO [S1, unofficial].
15. Create TBO `m_tex1d_grid_corner_edges` with format `GL_RGB32I` and usage `GL_STATIC_DRAW`. Upload `nCorners * 3` integers from `varCornerEdges`. Set shader uniform `corner_edges` for `shader_dvr` to this TBO [S1, unofficial].
16. Create TBO `m_tex1d_grid_edge_cells` with format `GL_RG32I` and usage `GL_STATIC_DRAW`. Upload `nEdges * 2` integers from `varEdgeCells`. Set shader uniform `edge_cells` for `shader_dvr` to this TBO [S1, unofficial].
17. In `CreateVBOTriangleMesh`, if `m_vbo_triangle_center_id` is null, create a VBO containing an array of integers from 0 to `nCorners-1`. This represents the dual hexagon cell corner IDs for triangle centers [S1, unofficial].
18. In `CreateVBOTriangleMesh`, if `m_vao_triangle_center_id` is null, create a VAO with primitive type `GL_POINTS`. Bind the `m_vbo_triangle_center_id` VBO as an attribute `in_corner_id` (type `GL_INT`, size 1, stride `sizeof(int)`) to the shader program `gcrm_triangle_mesh`. Enable the VAO [S1, unofficial].

**Pseudocode:**
```python
def create_tbo(fmt, size, data):
    return {"format": fmt, "size": size, "data": data}

def set_uniform(name, value):
    pass

def create_vbo(data):
    return {"data": data}

def create_vao(primitive_type):
    return {"primitive_type": primitive_type, "attributes": []}

def bind_vbo(vbo, attribute, type, size):
    pass

def enable_vao(vao):
    pass

def setup_geodesic_connectivity(varCellCorners, varEdgeCorners, varCellEdges, 
                                varCenterLat, varCenterLon, varCornerLat, varCornerLon, 
                                varClimate, nCell, nEdges, nCorners, nCenters, nLayers, nTimes):
    # Step 1: Populate varCornerCells
    varCornerCells = [[-1 for _ in range(3)] for _ in range(nCorners)]
    for iCell in range(nCell):
        for i in range(6):
            vtxIdx = varCellCorners[iCell * 6 + i]
            j = 0
            bHasDuplicate = False
            while j < 3 and varCornerCells[vtxIdx][j] != -1:
                if varCornerCells[vtxIdx][j] == iCell:
                    bHasDuplicate = True
                    break
                j += 1
            if j < 3 and not bHasDuplicate:
                varCornerCells[vtxIdx][j] = iCell

    # Step 2: Populate varCornerEdges
    varCornerEdges = [[-1 for _ in range(3)] for _ in range(nCorners)]
    for iEdge in range(nEdges):
        for i in range(2):
            vtxIdx = varEdgeCorners[iEdge * 2 + i]
            j = 0
            while j < 3 and varCornerEdges[vtxIdx][j] != -1:
                j += 1
            if j < 3:
                varCornerEdges[vtxIdx][j] = iEdge

    # Step 3: Populate varEdgeCells
    varEdgeCells = [[-1 for _ in range(2)] for _ in range(nEdges)]
    for iCell in range(nCell):
        for iEdge in range(6):
            idxEdge = varCellEdges[iCell * 6 + iEdge]
            j = 0
            bHasDuplicate = False
            while j < 2 and varEdgeCells[idxEdge][j] != -1: # Fixed: source used j<3 for size-2 array
                if varEdgeCells[idxEdge][j] == iCell:
                    bHasDuplicate = True
                    break
                j += 1
            if j < 2 and not bHasDuplicate:
                varEdgeCells[idxEdge][j] = iCell

    # Step 4: Upload to GPU TBOs [G]
    tbo_edge_corners = create_tbo("GL_RG32I", nEdges * 2, varEdgeCorners)
    set_uniform("edge_corners", tbo_edge_corners)

    tbo_center_lat = create_tbo("GL_R32F", nCenters, varCenterLat)
    set_uniform("center_lat", tbo_center_lat)
    
    tbo_center_lon = create_tbo("GL_R32F", nCenters, varCenterLon)
    set_uniform("center_lon", tbo_center_lon)

    tbo_corner_lat = create_tbo("GL_R32F", nCorners, varCornerLat)
    minLat, maxLat = min(varCornerLat), max(varCornerLat)
    set_uniform("corner_lat", tbo_corner_lat)
    set_uniform("minmax_lat", [minLat, maxLat])

    tbo_corner_lon = create_tbo("GL_R32F", nCorners, varCornerLon)
    minLon, maxLon = min(varCornerLon), max(varCornerLon)
    set_uniform("corner_lon", tbo_corner_lon)
    set_uniform("minmax_lon", [minLon, maxLon])

    tbo_center_val = create_tbo("GL_R32F", nTimes * nCenters * nLayers, varClimate)
    set_uniform("nLayers", nLayers)
    set_uniform("center_val", tbo_center_val)

    tbo_cell_corners = create_tbo("GL_R32I", nCell * 6, varCellCorners)
    set_uniform("cell_corners", tbo_cell_corners)

    tbo_corner_cells = create_tbo("GL_RGB32I", nCorners * 3, varCornerCells)
    set_uniform("corner_cells", tbo_corner_cells)

    tbo_corner_edges = create_tbo("GL_RGB32I", nCorners * 3, varCornerEdges)
    set_uniform("corner_edges", tbo_corner_edges)

    tbo_edge_cells = create_tbo("GL_RG32I", nEdges * 2, varEdgeCells)
    set_uniform("edge_cells", tbo_edge_cells)

    # Step 5: Triangle Mesh VBO/VAO [G]
    if not vbo_triangle_center_id:
        vbo_triangle_center_id = create_vbo(list(range(nCorners)))
    if not vao_triangle_center_id:
        vao_triangle_center_id = create_vao("GL_POINTS")
        bind_vbo(vbo_triangle_center_id, attribute="in_corner_id", type="GL_INT", size=1)
        enable_vao(vao_triangle_center_id)

    return {
        "tbo_edge_corners": tbo_edge_corners,
        "tbo_center_lat": tbo_center_lat,
        "tbo_center_lon": tbo_center_lon,
        "tbo_corner_lat": tbo_corner_lat,
        "tbo_corner_lon": tbo_corner_lon,
        "tbo_center_val": tbo_center_val,
        "tbo_cell_corners": tbo_cell_corners,
        "tbo_corner_cells": tbo_corner_cells,
        "tbo_corner_edges": tbo_corner_edges,
        "tbo_edge_cells": tbo_edge_cells,
        "vao_triangle_center_id": vao_triangle_center_id
    }
```

**Edge Cases and Pitfalls:**
- **Degeneracy**: The grid may contain pentagons instead of hexagons. The code checks for duplicate cell indices when populating `varCornerCells` and `varEdgeCells` to handle this. If a duplicate is found, the slot is skipped to avoid overwriting valid data [S1, unofficial].
- **Array Bounds**: The source code originally used `j < 3` in the loop condition for `varEdgeCells` despite the array having size 2, which would cause an out-of-bounds access. This is corrected to `j < 2` [G].
- **NULL Pointers**: The code checks for NULL arrays from the NetCDF manager and throws an error if any required array is missing [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of grid primitives for connectivity setup and TBO upload [G].
- **Memory Complexity**: Linear for host-side connectivity arrays and GPU memory usage proportional to these arrays plus climate data [G].
- **Performance**: The method is designed for static grids. The use of TBOs allows efficient random access in shaders for DVR and mesh rendering [S1, unofficial].
- **Strengths**: Handles unstructured geodesic grids with degeneracies. Efficient GPU access via TBOs [S1, unofficial].
- **Limitations**: Requires the entire grid to be loaded into memory. Not given in the sources for dynamic grids or specific performance benchmarks.

## Background
This method is part of the Geodesic Grid DVR (Volume Rendering) project by Jinrong Xie (2013-2017) [S1, unofficial]. It is used for rendering climate data on unstructured geodesic grids, which provide better coverage and resolution control compared to regular lat-lon grids [S1, unofficial]. The method builds on the EdgeMap Data Layout [1109-edgemap-data-layout.md] to provide the necessary connectivity for rendering [S1, unofficial].
