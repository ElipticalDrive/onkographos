# Geodesic Grid Connectivity Setup

Also called: Geodesic Grid Connectivity Initialization, Geodesic Grid DVR Connectivity Setup

## Overview
This method constructs the adjacency and incidence data structures required for rendering and ray-marching on a geodesic unstructured grid, transforming raw topology into GPU-accessible formats. It differs from sibling methods by focusing on the bidirectional mapping between grid primitives (cells, edges, corners) and uploading these relationships as Texture Buffer Objects (TBOs) for shader access, whereas [Edge ID Calculation](1570-edge-id-calculation.md) focuses on local indexing and [Enhanced Volume Data Set (EVDS)](11040-enhanced-volume-data-set-evds.md) focuses on the volumetric data container itself.

## How it works
**Inputs:**
- Raw grid topology arrays from a NetCDF file: `varCellCorners` (cell-to-corner), `varEdgeCorners` (edge-to-corner), `varCellEdges` (cell-to-edge).
- Coordinate arrays: `varCenterLat`, `varCenterLon`, `varCornerLat`, `varCornerLon`.
- Climate data array: `varClimate` (values at cell centers).
- Dimensions: `nCell` (number of cells), `nEdges` (number of edges), `nCorners` (number of corners).

**Outputs:**
- Derived connectivity arrays: `varCornerCells`, `varCornerEdges`, `varEdgeCells`.
- GPU Texture Buffer Objects (TBOs) bound to shader uniforms.
- Vertex Buffer Object (VBO) and Vertex Array Object (VAO) for triangle mesh rendering.

**Data Structures:**
1.  **`varCornerCells`**: 2D integer array of size `nCorners` x 3. Stores the indices of the hexagonal cells adjacent to each corner. Initialized to -1.
2.  **`varCornerEdges`**: 2D integer array of size `nCorners` x 3. Stores the indices of the edges connected to each corner. Initialized to -1.
3.  **`varEdgeCells`**: 2D integer array of size `nEdges` x 2. Stores the indices of the two cells sharing each edge. Initialized to -1.
4.  **`varEdgeCorners`**: 2D integer array of size `nEdges` x 2. Stores the corner indices for each edge (provided by input).
5.  **`varCellCorners`**: 2D integer array of size `nCell` x 6. Stores the corner indices for each cell (provided by input).

**Algorithm Steps:**

1.  **Initialize `varCornerCells`**:
    - Create `varCornerCells` of size `nCorners` x 3.
    - Fill all entries with -1.

2.  **Populate `varCornerCells`**:
    - Iterate `iCell` from 0 to `nCell - 1`.
    - Iterate `i` from 0 to 5 (assuming 6 corners per cell, though degeneracy handling is present).
    - Retrieve `vtxIdx = varCellCorners[iCell * 6 + i]`.
    - Find the first empty slot `j` in row `vtxIdx` of `varCornerCells` (where `varCornerCells[vtxIdx * 3 + j] == -1`).
    - **Degeneracy Check**: If `varCornerCells[vtxIdx * 3 + j]` is not -1, check if it equals `iCell`. If true, a duplicate exists (degenerate pentagon). Set `bHasDuplicate = true` and break.
    - If `j < 3` and `!bHasDuplicate`, set `varCornerCells[vtxIdx * 3 + j] = iCell`.

3.  **Initialize `varCornerEdges`**:
    - Create `varCornerEdges` of size `nCorners` x 3.
    - Fill all entries with -1.

4.  **Populate `varCornerEdges`**:
    - Iterate `iEdge` from 0 to `nEdges - 1`.
    - Iterate `i` from 0 to 1 (endpoints of the edge).
    - Retrieve `vtxIdx = varEdgeCorners[iEdge * 2 + i]`.
    - Find the first empty slot `j` in row `vtxIdx` of `varCornerEdges` (where `varCornerEdges[vtxIdx * 3 + j] == -1`).
    - If `j < 3`, set `varCornerEdges[vtxIdx * 3 + j] = iEdge`.

5.  **Initialize `varEdgeCells`**:
    - Create `varEdgeCells` of size `nEdges` x 2.
    - Fill all entries with -1.

6.  **Populate `varEdgeCells`**:
    - Iterate `iCell` from 0 to `nCell - 1`.
    - Iterate `iEdge` from 0 to 5 (edges of the cell).
    - Retrieve `idxEdge = varCellEdges[iCell * 6 + iEdge]`.
    - Find the first empty slot `j` in row `idxEdge` of `varEdgeCells` (where `varEdgeCells[idxEdge * 2 + j] == -1`).
    - **Degeneracy Check**: If `varEdgeCells[idxEdge * 2 + j]` is not -1, check if it equals `iCell`. If true, a duplicate exists. Set `bHasDuplicate = true` and break.
    - If `j < 2` (note: source code uses `j < 3` in loop condition but array size is 2, likely a typo in source or safe guard) and `!bHasDuplicate`, set `varEdgeCells[idxEdge * 2 + j] = iCell`.

7.  **Upload to GPU (TBOs)**:
    - Create TBO `m_tex1d_grid_edge_corners` (`GL_RG32I`, `GL_STATIC_DRAW`). Upload `nEdges * 2` integers from `varEdgeCorners`. Bind to uniform `edge_corners`.
    - Create TBO `m_tex1d_grid_center_lat` (`GL_R32F`, `GL_STATIC_DRAW`). Upload `nCenters` floats from `varCenterLat`. Bind to uniform `center_lat`.
    - Create TBO `m_tex1d_grid_center_lon` (`GL_R32F`, `GL_STATIC_DRAW`). Upload `nCenters` floats from `varCenterLon`. Bind to uniform `center_lon`.
    - Create TBO `m_tex1d_grid_corner_lat` (`GL_R32F`, `GL_STATIC_DRAW`). Upload `nCorners` floats from `varCornerLat`. Compute `minLat`/`maxLat` from data. Bind to uniform `corner_lat`.
    - Create TBO `m_tex1d_grid_corner_lon` (`GL_R32F`, `GL_STATIC_DRAW`). Upload `nCorners` floats from `varCornerLon`. Compute `minLon`/`maxLon` from data. Bind to uniform `corner_lon`.
    - Create TBO `m_tex1d_grid_center_val` (`GL_R32F`, `GL_STATIC_DRAW`). Upload `nTimes * nCenters * nLayers` floats from `varClimate`. Bind to uniform `center_val`.
    - Create TBO `m_tex1d_grid_cell_corners` (`GL_R32I`, `GL_STATIC_DRAW`). Upload `nCells * 6` integers from `varCellCorners`. Bind to uniform `cell_corners`.
    - Create TBO `m_tex1d_grid_corner_cells` (`GL_RGB32I`, `GL_STATIC_DRAW`). Upload `nCorners * 3` integers from `varCornerCells`. Bind to uniform `corner_cells`.
    - Create TBO `m_tex1d_grid_corner_edges` (`GL_RGB32I`, `GL_STATIC_DRAW`). Upload `nCorners * 3` integers from `varCornerEdges`. Bind to uniform `corner_edges`.
    - Create TBO `m_tex1d_grid_edge_cells` (`GL_RG32I`, `GL_STATIC_DRAW`). Upload `nEdges * 2` integers from `varEdgeCells`. Bind to uniform `edge_cells`.

8.  **Triangle Mesh Setup (Dual Grid)**:
    - If `m_vbo_triangle_center_id` is null, create a VBO containing integers `0` to `nCorners - 1`. This represents dual hexagon cell corner IDs for triangle centers.
    - If `m_vao_triangle_center_id` is null, create a VAO with primitive type `GL_POINTS`. Bind the VBO as attribute `in_corner_id` (`GL_INT`, size 1). Enable VAO.

**Pseudocode:**

```python
def setup_geodesic_connectivity(varCellCorners, varEdgeCorners, varCellEdges, 
                                varCenterLat, varCenterLon, varCornerLat, varCornerLon, 
                                varClimate, nCell, nEdges, nCorners, nLayers, nTimes):
    # Step 1: Populate varCornerCells
    varCornerCells = [[-1 for _ in range(3)] for _ in range(nCorners)]
    for iCell in range(nCell):
        for i in range(6): # Assuming 6 corners per cell
            vtxIdx = varCellCorners[iCell * 6 + i]
            j = 0
            bHasDuplicate = False
            while j < 3 and varCornerCells[vtxIdx][j] != -1:
                if varCornerCells[vtxIdx][j] == iCell:
                    bHasDuplicate = True
                    break
                j += 1
            if j < 3 and not bHasDuplicate:
                varCornerCells[vtxIdx][j] = iCell

    # Step 2: Populate varCornerEdges
    varCornerEdges = [[-1 for _ in range(3)] for _ in range(nCorners)]
    for iEdge in range(nEdges):
        for i in range(2):
            vtxIdx = varEdgeCorners[iEdge * 2 + i]
            j = 0
            while j < 3 and varCornerEdges[vtxIdx][j] != -1:
                j += 1
            if j < 3:
                varCornerEdges[vtxIdx][j] = iEdge

    # Step 3: Populate varEdgeCells
    varEdgeCells = [[-1 for _ in range(2)] for _ in range(nEdges)]
    for iCell in range(nCell):
        for iEdge in range(6):
            idxEdge = varCellEdges[iCell * 6 + iEdge]
            j = 0
            bHasDuplicate = False
            while j < 2 and varEdgeCells[idxEdge][j] != -1: # Note: size is 2
                if varEdgeCells[idxEdge][j] == iCell:
                    bHasDuplicate = True
                    break
                j += 1
            if j < 2 and not bHasDuplicate:
                varEdgeCells[idxEdge][j] = iCell

    # Step 4: Upload to GPU TBOs
    # Note: Actual GPU upload depends on OpenGL API, represented here conceptually
    
    # Edge Corners (RG32I)
    tbo_edge_corners = create_tbo(GL_RG32I, nEdges * 2, varEdgeCorners.flatten())
    set_uniform("edge_corners", tbo_edge_corners)

    # Center Lat/Lon (R32F)
    tbo_center_lat = create_tbo(GL_R32F, nCell, varCenterLat)
    set_uniform("center_lat", tbo_center_lat)
    
    tbo_center_lon = create_tbo(GL_R32F, nCell, varCenterLon)
    set_uniform("center_lon", tbo_center_lon)

    # Corner Lat/Lon (R32F)
    tbo_corner_lat = create_tbo(GL_R32F, nCorners, varCornerLat)
    minLat, maxLat = min(varCornerLat), max(varCornerLat)
    set_uniform("corner_lat", tbo_corner_lat)
    set_uniform("minmax_lat", [minLat, maxLat])

    tbo_corner_lon = create_tbo(GL_R32F, nCorners, varCornerLon)
    minLon, maxLon = min(varCornerLon), max(varCornerLon)
    set_uniform("corner_lon", tbo_corner_lon)
    set_uniform("minmax_lon", [minLon, maxLon])

    # Climate Data (R32F)
    tbo_center_val = create_tbo(GL_R32F, nTimes * nCell * nLayers, varClimate)
    set_uniform("nLayers", nLayers)
    set_uniform("center_val", tbo_center_val)

    # Cell Corners (R32I)
    tbo_cell_corners = create_tbo(GL_R32I, nCell * 6, varCellCorners.flatten())
    set_uniform("cell_corners", tbo_cell_corners)

    # Corner Cells (RGB32I)
    tbo_corner_cells = create_tbo(GL_RGB32I, nCorners * 3, varCornerCells.flatten())
    set_uniform("corner_cells", tbo_corner_cells)

    # Corner Edges (RGB32I)
    tbo_corner_edges = create_tbo(GL_RGB32I, nCorners * 3, varCornerEdges.flatten())
    set_uniform("corner_edges", tbo_corner_edges)

    # Edge Cells (RG32I)
    tbo_edge_cells = create_tbo(GL_RG32I, nEdges * 2, varEdgeCells.flatten())
    set_uniform("edge_cells", tbo_edge_cells)

    # Triangle Mesh VBO/VAO
    if not vbo_triangle_center_id:
        vbo_triangle_center_id = create_vbo(list(range(nCorners)))
    if not vao_triangle_center_id:
        vao_triangle_center_id = create_vao(GL_POINTS)
        bind_vbo(vbo_triangle_center_id, attribute="in_corner_id", type=GL_INT, size=1)
        enable_vao(vao_triangle_center_id)

    return {
        "tbo_edge_corners": tbo_edge_corners,
        "tbo_center_lat": tbo_center_lat,
        "tbo_center_lon": tbo_center_lon,
        "tbo_corner_lat": tbo_corner_lat,
        "tbo_corner_lon": tbo_corner_lon,
        "tbo_center_val": tbo_center_val,
        "tbo_cell_corners": tbo_cell_corners,
        "tbo_corner_cells": tbo_corner_cells,
        "tbo_corner_edges": tbo_corner_edges,
        "tbo_edge_cells": tbo_edge_cells,
        "vao_triangle_center_id": vao_triangle_center_id
    }
```

**Edge Cases and Pitfalls:**
- **Degeneracy**: The grid may contain pentagons instead of hexagons. The code checks for duplicate cell indices when populating `varCornerCells` and `varEdgeCells` to handle this. If a duplicate is found, the slot is skipped to avoid overwriting valid data [S1, unofficial].
- **Array Bounds**: The source code uses `j < 3` in loops for `varEdgeCells` which has size 2. This is likely a copy-paste error from `varCornerCells` logic. The implementation should use `j < 2` for `varEdgeCells` [S1, unofficial].
- **NULL Pointers**: The code checks for NULL arrays from the NetCDF manager and throws an error if any required array is missing [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(nCell \cdot 6 + nEdges \cdot 2 + nCorners \cdot 3)$ for connectivity setup, which is linear with respect to the number of grid primitives. TBO upload is also linear.
- **Memory Complexity**: $O(nCorners \cdot 3 + nEdges \cdot 2 + nCell \cdot 6)$ for host-side connectivity arrays. GPU memory usage is proportional to the size of these arrays plus the climate data.
- **Performance**: The method is designed for static grids. The use of TBOs allows efficient random access in shaders for DVR and mesh rendering. The triangle mesh setup allows for efficient rendering of the grid structure using point sprites or similar techniques.
- **Strengths**: Handles unstructured geodesic grids with degeneracies. Efficient GPU access via TBOs.
- **Limitations**: Requires the entire grid to be loaded into memory. Not suitable for dynamic grids where connectivity changes frequently.

## Background
This method is part of the Geodesic Grid DVR (Volume Rendering) project by Jinrong Xie (2013-2017) [S1, unofficial]. It is used for rendering climate data on unstructured geodesic grids, which provide better coverage and resolution control compared to regular lat-lon grids. The method builds on the EdgeMap Data Layout [1109-edgemap-data-layout.md] to provide the necessary connectivity for rendering.
