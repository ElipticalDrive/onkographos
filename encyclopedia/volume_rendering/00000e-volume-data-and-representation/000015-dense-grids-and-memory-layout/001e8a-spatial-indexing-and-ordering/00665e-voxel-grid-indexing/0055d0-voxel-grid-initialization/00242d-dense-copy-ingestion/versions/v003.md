# Dense Copy Ingestion
## Overview
Dense Copy Ingestion constructs a VDB grid from a dense 3D array, storing only values that differ from a specified background value as active voxels [S1, unofficial].
## How it works
**Inputs:** `array` (dense 3D array), `background` (scalar value representing empty space), `bbox_min` (world-space minimum coordinate of the grid), and `voxel_size` (physical size per voxel) [G].
**Outputs:** A VDB grid object containing active voxels [S1, unofficial].
**Data Structures:** The source `array` is indexed by integer coordinates `(ix, iy, iz)` [G]. The target VDB grid stores only non-background values [S1, unofficial].
**Pseudocode:**
```python
def dense_copy_ingestion(array, background, bbox_min, voxel_size):
    data = []  # Initialize empty list to hold voxel entries [G]
    for ix, iy, iz in indices_of(array):  # Iterate through all indices [G]
        v = array[ix, iy, iz]  # Retrieve value [G]
        if v != background:  # Check against background [S1, unofficial]
            # Compute world-space center coordinate [G]
            c = bbox_min + (ix + 0.5, iy + 0.5, iz + 0.5) * voxel_size
            data.append((c, v))  # Add to data [G]
    return build_grid(data, background)  # Construct VDB grid [S1, unofficial]
```
**Parameters:** `background` must match the type of `array`; a typical value is `0.0` [G]. `voxel_size` defines the physical dimension per voxel [G].
**Edge Cases:** If all values equal `background`, the resulting grid has no active voxels [S1, unofficial].
