# Bounding Box Clipping
Also called: clip (bbox)
## Overview
Bounding Box Clipping returns a new grid containing only the active voxels of a source grid that lie within a specified world-space bounding box [S1, unofficial]. It differs from [Mask Clipping](3229-mask-clipping.md) by using a geometric region of interest rather than a secondary data grid to determine voxel inclusion [G]. It differs from [Grid Clone](7232-grid-clone.md) by filtering the spatial extent of the data rather than duplicating the entire logical structure [G].
## How it works
**Inputs:**
- `source_grid`: The input voxel grid [G].
- `bbox`: A world-space bounding box defining the region of interest [G].

**Outputs:**
- `clipped_grid`: A new grid containing only the active voxels from `source_grid` that intersect or lie within `bbox` [S1, unofficial].

**Data Structures:**
The implementation iterates through the active voxels of the `source_grid` [S1, unofficial]. For each active voxel at coordinate `c`, the algorithm checks if `c` is contained within `bbox` [S1, unofficial]. If the condition is true, the voxel's data is added to the `data` structure of the new grid [S1, unofficial].

**Steps:**
1. Initialize an empty list `clipped_data` [G].
2. Iterate through all active voxels in `source_grid` [S1, unofficial].
3. For each active voxel at coordinate `c`:
   - Check if `contains(bbox, c)` is true [S1, unofficial].
   - If true, add the voxel's data to `clipped_data` [S1, unofficial].
4. Return `clipped_grid` containing `clipped_data` [S1, unofficial].

**Pseudocode:**
```python
class BoundingBox:
    def __init__(self, min_corner, max_corner):
        self.min = min_corner
        self.max = max_corner
    def contains(self, point):
        return all(self.min[i] <= point[i] <= self.max[i] for i in range(len(point)))

class Grid:
    def __init__(self, active_voxels, data):
        self.active_voxels = active_voxels
        self.data = data

def bounding_box_clip(source_grid, bbox):
    clipped_data = []
    for voxel in source_grid.active_voxels:
        c = voxel.coordinate
        if bbox.contains(c):
            clipped_data.append(voxel.data)
    return Grid(active_voxels=source_grid.active_voxels, data=clipped_data)
```

**Parameters:**
- `bbox`: The bounding box defining the clipping region. Not given in the sources.

**Edge Cases:**
- If no active voxels lie within the bounding box, the resulting grid is empty [G].
- Precision issues may arise if voxel coordinates are very close to the bounding box boundaries [G].

## Subtopics

### [Voxel Body Copying with Sub-Voxel Clipping](7181-voxel-body-copying-with-sub-voxel-clipping.md)
Extracts a subset of a voxel grid by retaining only the active solid blocks that intersect a specified world-space bounding box, while preserving the internal structure of those blocks. Unlike [Grid Clone](7232-grid-clone.md), which duplicates the entire grid, this method creates a new `VoxelBody` containing only the relevant data. It differs from [Bounding Box Clipping](4643-bounding-box-clipping.md) in that it operates on discrete solid blocks rather than individual voxels, clipping blocks that partially overlap the boundary to maintain structural integrity.

### [Grid Clone](7232-grid-clone.md)
Creates a deep copy of a source voxel grid, preserving its bounding box, pixel dimensions, and all voxel data values. It solves the problem of duplicating grid state for independent modification or serialization. Unlike [Bounding Box Clipping](4643-bounding-box-clipping.md), which filters voxels by spatial containment, Grid Clone retains the entire logical extent of the source grid. It differs from [Voxel Body Copying with Sub-Voxel Clipping](7181-voxel-body-copying-with-sub-oxel-clipping.md) by performing a direct value assignment without geometric clipping or sub-voxel interpolation.

## Operating characteristics
Time complexity: Linear with respect to the number of active voxels in the source grid [G]. Memory complexity: Linear with respect to the number of active voxels within the bounding box [G]. Strengths: Simple to implement, efficient for sparse grids [G]. Limitations: Does not handle partial voxel intersections or sub-voxel precision [G]. When to use: When a subset of a grid is needed for further processing or rendering [G]. When not to use: When the entire grid is required or when sub-voxel precision is needed [G].
