# VoxelGridFromList
## Overview
`VoxelGridFromList` initializes a 3D voxel grid by copying boolean values from a flat list into the grid's linear memory layout [S1, unofficial]. It solves the problem of bulk-setting voxel states without iterating over spatial coordinates, relying on a pre-computed linear index mapping [G]. It differs from [Voxel Grid Construction](3085-voxel-grid-construction.md) by assuming the grid structure already exists and only updating values, and from [Dense Copy Ingestion](3212-dense-copy-ingestion.md) by handling boolean flags rather than dense scalar data [G].

## How it works
**Inputs:**
1. `grid`: A `VoxelGrid3D` object at input index 0 [S1, unofficial].
2. `values`: A list of boolean values at input index 1 [S1, unofficial].

**Outputs:**
1. `modified_grid`: A new `VoxelGrid3D` instance with updated values at output index 0 [S1, unofficial].

**Data Structures:**
- `VoxelGrid3D`: Contains a linear array of values, a size vector `SizeUVW` (width, height, depth), and a bounding box `BBox` [S1, unofficial]. The linear index $i$ maps to voxel coordinates $(u, v, w)$ via $i = u + v \cdot W + w \cdot W \cdot H$, where $W, H, D$ are dimensions [G].

**Steps:**
1. Retrieve the input grid from index 0 and cast it to `VoxelGrid3D` [S1, unofficial].
2. Clone the retrieved grid to create `modified_grid` [S1, unofficial].
3. Retrieve the list of boolean values from index 1 [S1, unofficial].
4. Calculate `max_count` as the minimum of the grid's total voxel count ($W \times H \times D$) and the input list's length ($L$) [S1, unofficial].
   $$ \text{max\_count} = \min(W \cdot H \cdot D, L) $$
5. Iterate from index $i = 0$ to `max_count` (exclusive) [S1, unofficial].
6. Set the value at linear index $i$ in `modified_grid` to the value at index $i$ in the input list [S1, unofficial].
7. Set `modified_grid` as the output at index 0 [S1, unofficial].

**Pseudocode:**
```python
class VoxelGrid3D:
    def __init__(self, size_uvw, bbox, values):
        self.SizeUVW = size_uvw  # (W, H, D)
        self.BBox = bbox
        self.values = values     # flat list/array
        self.Count = size_uvw[0] * size_uvw[1] * size_uvw[2]
    def clone(self):
        return VoxelGrid3D(self.SizeUVW, self.BBox, list(self.values))
    def __setitem__(self, idx, val):
        self.values[idx] = val
    def __getitem__(self, idx):
        return self.values[idx]

def VoxelGridFromList(grid_input, values_input):
    # Step 1: Retrieve and cast grid
    source_grid = grid_input[0]
    assert isinstance(source_grid, VoxelGrid3D)
    
    # Step 2: Clone the grid
    modified_grid = source_grid.clone()
    
    # Step 3: Retrieve values
    values = values_input[1]
    
    # Step 4: Calculate max
    W, H, D = source_grid.SizeUVW
    grid_voxel_count = W * H * D
    list_count = len(values)
    max_count = min(grid_voxel_count, list_count)
    
    # Step 5 & 6: Iterate and set values
    for i in range(max_count):
        modified_grid[i] = values[i]
        
    # Step 7: Output
    return [modified_grid]
```

**Edge Cases and Pitfalls:**
- **Length Mismatch:** If the input list is shorter than the grid, remaining voxels retain their cloned (original) values. If the list is longer, excess values are ignored [S1, unofficial].
- **Index Mapping:** This method assumes the input list is already flattened in the same order as the grid's internal memory layout (e.g., row-major or column-major) [G]. If the list is spatially ordered, it must be flattened before passing [G].
- **Type Safety:** The input list must contain boolean-compatible values [S1, unofficial]. Casting errors may occur if floats or integers are passed without explicit conversion [G].

## Subtopics

### Expanding Voxel Grid
A variant of `VoxelGridFromList` (or the underlying `__setitem__` operation) that automatically expands the grid's bounding box when points are set outside the current range, preserving existing data [S2, unofficial].
- **Definition:** A `VoxelGrid` variant that supports dynamic resizing [S2, unofficial].
- **Mechanism:** When setting points `pts` with values:
  1. Calculate `min_pts` and `max_pts` of the new points [S2, unofficial].
  2. Check if `max_pts` exceeds `range_per_dim[dim][1]` (over) or `min_pts` is below `range_per_dim[dim][0]` (under) for any dimension [S2, unofficial].
  3. If `over > 0`, expand the upper bound:
     $$ \text{new\_max} = \text{current\_max} + \lceil \frac{\text{over}}{\text{resolution}} \rceil \cdot \text{resolution} $$
  4. If `under > 0`, expand the lower bound:
     $$ \text{new\_min} = \text{current\_min} - \lceil \frac{\text{under}}{\text{resolution}} \rceil \cdot \text{resolution} $$
  5. If the new range differs from the current range (checked via `np.allclose`):
     - Retrieve existing known points and values [S2, unofficial].
     - Create a new `VoxelGrid` with the expanded range [S2, unofficial].
     - Insert existing points/values into the new grid [S2, unofficial].
     - Insert the new `pts` and values [S2, unofficial].
- **Use Case:** Useful for incremental SDF construction or occupancy mapping where the scene extent is unknown or grows over time [G].
- **Source:** [S2, unofficial]

## Operating characteristics
- **Time Complexity:** $O(\min(N, M))$ for the assignment loop, where $N$ is the number of voxels and $M$ is the number of values in the input list [G]. The cloning step is $O(N)$ [G].
- **Memory Complexity:** $O(N)$ for the cloned grid [G].
- **Performance:** Not given in the sources.
- **Strengths:** Simple implementation, no spatial traversal overhead, suitable for bulk updates [G].
- **Limitations:** Does not handle spatial indexing or sparse updates efficiently. Cloning the entire grid for small updates is wasteful [G].
- **When to Use:** When initializing a grid from a pre-flattened dataset or when updating a significant portion of the grid [G].
- **When Not to Use:** For sparse updates or when the grid is very large and memory is constrained. Use [Voxel Grid Construction](3085-voxel-grid-construction.md) or sparse variants instead [G].

## Background
The `VoxelGridFromList` method is part of the `voxeltools` library, providing a straightforward way to populate voxel grids from linear data structures [S1, unofficial]. The "Expanding Voxel Grid" variant is associated with `pytorch_volumetric`, which focuses on differentiable volumetric structures for robotics and SDF applications [S2, unofficial].
