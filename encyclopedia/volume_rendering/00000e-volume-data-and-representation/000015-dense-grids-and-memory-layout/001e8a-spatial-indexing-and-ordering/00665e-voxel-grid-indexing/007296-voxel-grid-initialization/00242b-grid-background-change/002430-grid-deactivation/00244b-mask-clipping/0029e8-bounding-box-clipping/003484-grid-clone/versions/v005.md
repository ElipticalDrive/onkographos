# Grid Clone

Also called: PixelGrid2D Clone

## Overview
Grid Clone produces a new grid instance that duplicates the source grid's bounding box, pixel size, and voxel data array [S1, unofficial]. It differs from [Bounding Box Clipping](4643-bounding-box-clipping.md) by retaining the full logical extent rather than filtering voxels, and from [Voxel Body Copying with Sub-Voxel Clipping](7181-voxel-body-copying-with-sub-voxel-clipping.md) by performing direct array assignment without geometric clipping [G].

## How it works
**Inputs and Outputs:**
- Input: A source grid object containing a bounding box, pixel size, total voxel count, and a contiguous value array [S1, unofficial].
- Output: A new grid instance with identical metadata and a deep copy of the value array [S1, unofficial].

**Data Structures:**
The source grid contains the following fields [S1, unofficial]:
- `_BBox`: A bounding box object defining the spatial extent.
- `_PixelSize`: A vector object defining the physical dimensions of a single voxel.
- `Count`: An integer representing the total number of voxels.
- `Values`: A contiguous array storing the scalar or color data for each voxel.

**Steps:**
1. Initialize a new grid instance and assign the source grid's `_BBox` and `_PixelSize` to it [S1, unofficial].
2. Allocate a new value array with a length equal to the source grid's `Count` [S1, unofficial].
3. Iterate from index $0$ to `Count` (exclusive) and assign each source value to the corresponding index in the new array [S1, unofficial].
   $$ V_{\text{new}}[i] = V_{\text{source}}[i] \quad \forall i \in [0, \text{Count}) $$
4. Return the new grid instance [S1, unofficial].

**Pseudocode:**
```python
def GridClone(source_grid):
    new_grid = PixelGrid2D()
    new_grid._BBox = source_grid._BBox
    new_grid._PixelSize = source_grid._PixelSize
    count = source_grid.Count
    new_grid.Values = [0.0] * count
    for i in range(count):
        new_grid.Values[i] = source_grid.Values[i]
    return new_grid
```

**Edge Cases and Pitfalls:**
- **Deep Copy Requirement:** The `Values` array must be allocated and copied element-wise; assigning the reference directly causes both grids to share data [G].
- **Metadata Fidelity:** `_BBox` and `_PixelSize` must be copied exactly to prevent spatial misalignment during rendering [G].
- **Bounds:** The loop runs for $i \in [0, \text{Count})$; accessing `Count` or beyond causes out-of-bounds errors [G].

## Subtopics

### [PixelGrid2D CloneEmpty](7356-pixelgrid2d-cloneempty.md)
Creates a new `PixelGrid2D` instance initialized with the current bounding box and pixel size, effectively producing an empty grid structure ready for population. It differs from `Grid Reinitialization` by preserving the existing grid topology and memory layout without reallocating underlying segmentation tensors or updating object counts.

## Operating characteristics
**Time and Memory Complexity:**
- Time: $O(N)$, where $N$ is `Count`, due to the linear value copy [G].
- Memory: $O(N)$ additional space for the new `Values` array; metadata overhead is $O(1)$ [G].

**Strengths and Limitations:**
- Preserves exact data integrity and spatial metadata without geometric calculations [G].
- Does not reduce memory footprint; unsuitable when only a spatial subset or empty structure is required [G].

**When to Use:**
- Independent modification, simulation, or serialization of the full grid state [G].

**When Not to Use:**
- Memory-constrained environments or when spatial filtering is needed [G].
