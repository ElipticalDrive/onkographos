# Mask Clipping
Also called: clip (mask)
## Overview
Mask Clipping returns a new grid containing only the active voxels of a source grid at coordinates where a secondary mask grid is also active [S1, unofficial]. It differs from [Bounding Box Clipping](4643-bounding-box-clipping.md) by using a secondary data grid rather than a geometric primitive to define the region of interest, and from [Grid Deactivation](3214-grid-deactivation.md) by allowing arbitrary spatial selection via an external mask rather than a single scalar value comparison.
## How it works
**Inputs:**
1. `source_grid`: The input volume grid containing active voxels.
2. `mask_grid`: A binary or categorical grid of the same spatial dimensions as `source_grid`.

**Outputs:**
1. `clipped_grid`: A new grid containing only the active voxels from `source_grid` where the corresponding voxel in `mask_grid` is active.

**Data Structures:**
- `source_grid`: Standard dense grid layout (e.g., VDB, Octree, or 3D array) with active voxel list.
- `mask_grid`: Same spatial resolution and layout as `source_grid`.

**Steps:**
1. Initialize an empty `clipped_grid` with the same metadata (resolution, transform) as `source_grid`.
2. Iterate through each active voxel `v` in `source_grid` at coordinate `c`.
3. Check if the voxel at coordinate `c` is active in `mask_grid`.
   - If `is_active(mask_grid, c)` is true, insert `v` into `clipped_grid`.
   - If false, discard `v`.
4. Return `clipped_grid`.

**Pseudocode:**
```python
def mask_clip(source_grid, mask_grid):
    clipped_grid = Grid(metadata=source_grid.metadata)
    
    # Iterate over active voxels in the source grid
    for voxel in source_grid.active_voxels():
        coord = voxel.coordinate
        
        # Check if the corresponding location is active in the mask grid
        if mask_grid.is_active(coord):
            # Add the voxel to the new grid
            clipped_grid.insert(voxel)
            
    return clipped_grid
```

**Parameters:**
- None explicitly defined in sources.

**Edge Cases and Pitfalls:**
- If `mask_grid` has a different resolution or transform than `source_grid`, coordinate mapping must be handled [G].
- If `mask_grid` is entirely inactive, the result is an empty grid.
- If `mask_grid` is entirely active, the result is a copy of `source_grid`.

## Subtopics

### [Bounding Box Clipping](4643-bounding-box-clipping.md)
Bounding Box Clipping returns a new grid containing only the active voxels of the source grid that lie within a specified world-space bounding box. It differs from [Mask Clipping](3229-mask-clipping.md) by using a geometric primitive (axis-aligned box) rather than a secondary data grid to define the region of interest, and from [Grid Clone](7232-grid-clone.md) by filtering spatial extent rather than duplicating the full logical structure [G].

### Mask-based Density Filtering
Mask-based Density Filtering is a variant where a segmentation mask is used to filter density values. Steps: Create `mask_grid` as zeros with the same shape as `seg_mask_grid.grid`. Set `mask_grid` values to 1 where `seg_mask_grid.grid > 0`. Multiply `density.grid` by `mask_grid`. Set `density.grid` values equal to 0 to `-1e7` [S2, unofficial]. Pitfall: Asserts that `seg_mask_grid.grid` has `shape[1] == 1`. Multi-object seg labels cannot be applied directly to the density grid [S2, unofficial].

## Operating characteristics
Time complexity: O(N), where N is the number of active voxels in `source_grid`, assuming O(1) lookup in `mask_grid`. Memory complexity: O(M), where M is the number of active voxels retained after clipping. Performance depends on the sparsity of the mask and the source grid. Strengths: Flexible selection region. Limitations: Requires storage of an additional mask grid. Use when arbitrary non-convex or complex selection regions are needed. Do not use when simple geometric bounds suffice (use Bounding Box Clipping).

## Background
Origin: Part of the Lyr.jl volume rendering framework [S1, unofficial]. History: Used for scene vetting and framing, such as for smoke and bunny_cloud scenes [S1, unofficial]. Usage: Applied to refine volume data for rendering by excluding irrelevant regions defined by a mask.
