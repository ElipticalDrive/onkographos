# PixelGrid2D CloneEmpty


## Overview
`PixelGrid2D CloneEmpty` creates a fresh, empty grid instance that inherits the spatial configuration (bounding box and pixel dimensions) of an existing grid. It solves the need for a clean slate with identical geometry without copying data or updating semantic counters. It differs from `Grid Reinitialization` by preserving the existing grid topology and memory layout without reallocating segmentation tensors or modifying object counts [S1, unofficial].

## How it works
**Inputs:** Source grid instance containing `BBox` (bounding box) and `PixelSize` (pixel dimensions).
**Outputs:** A new `PixelGrid2D` object.
**Data structures:** The grid stores a 1D array of floats sized to the total voxel count ($Size_{UVW} = W \times H \times D$), where $W, H, D$ are the grid dimensions derived from the bounding box and pixel size.
**Steps:**
1. Extract the current bounding box (`BBox`) and pixel dimensions (`PixelSize`) from the source grid [S1, unofficial].
2. Instantiate a new `PixelGrid2D` object using the extracted `BBox` and `PixelSize` [S1, unofficial].
3. Initialize the internal data array with a size equal to the product of the grid dimensions ($Size_{UVW}$) [S1, unofficial].

**Pseudocode:**
```python
def clone_empty(source_grid):
    # Extract geometry parameters
    bbox = source_grid.bounding_box
    pixel_dims = source_grid.pixel_dimensions
    
    # Create new instance with identical spatial configuration
    new_grid = PixelGrid2D(bbox, pixel_dims)
    
    # Compute total voxel count from dimensions
    total_voxels = new_grid.size_u * new_grid.size_v * new_grid.size_w
    
    # Allocate and initialize internal storage
    new_grid.grid = [0.0] * total_voxels
    
    return new_grid
```

**Parameters:**
- `bbox`: Spatial extent defining the grid's physical boundaries.
- `pixel_dims`: Physical size of a single voxel/pixel along each axis.

**Edge Cases:**
- If `source_grid` is null, the method fails [G].
- Precision loss may occur if `pixel_dims` are extremely small or large relative to floating-point limits [G].
- Degenerate bounding boxes (zero volume) result in a zero-length array [G].

## Subtopics

### Grid Reinitialization
Updates the internal segmentation masks to match a new number of objects (`num_obj`) [S2, unofficial]. It retrieves the device from the existing grid, recreates the dense grids (`seg_mask_grid` and `dual_seg_mask_grid`) using `grid.create_grid` with `channels=num_obj`, the current `world_size` (`xyz_min`, `xyz_max`), and `config=density_config`, then moves both grids to the correct device [S2, unofficial]. Choose this when the number of semantic classes changes, rather than when creating a fresh empty structure.
