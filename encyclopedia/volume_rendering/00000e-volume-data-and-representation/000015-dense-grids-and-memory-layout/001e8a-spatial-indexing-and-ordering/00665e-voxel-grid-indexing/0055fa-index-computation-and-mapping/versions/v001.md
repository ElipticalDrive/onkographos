# Index Computation and Mapping

Also called: Voxel Indexing, Grid Indexing, Spatial Mapping

## Overview
Index Computation and Mapping defines the algorithms for translating continuous 3D spatial coordinates into discrete linear indices within a voxel grid data structure. It solves the problem of spatial localization, enabling efficient ray marching, point cloud queries, and isosurface extraction by mapping world positions to specific memory locations . This family distinguishes itself from [Spatial Hashing](5002-spatial-hashing.md) by guaranteeing deterministic, collision-free indexing for all points within the grid bounds, and from [Sparse Voxel Storage and Chunking](15595-sparse-voxel-storage-and-chunking.md) by relying on fixed memory layouts rather than dynamic allocation [G].

## Shared principles
All methods in this family map a continuous position $\mathbf{p} = (x, y, z)$ to a discrete index $I$. The core mechanism involves:
1.  **Coordinate Transformation**: Converting world coordinates to a local grid space, often by subtracting a minimum bound $\mathbf{b}_{min}$ and dividing by a voxel size or scaling factor.
2.  **Discretization**: Applying a floor operation or rounding to convert floating-point coordinates into integer grid coordinates $(i, j, k)$.
3.  **Linearization**: Converting 3D integer coordinates $(i, j, k)$ into a 1D linear index $I$ using a stride-based formula, typically row-major ($I = i \cdot S_y S_z + j \cdot S_z + k$) or column-major, depending on memory layout.
4.  **Boundary Handling**: Managing points outside the defined grid bounds via clamping, sentinel values, or error handling.

## Subtopics

### [Uniform Grid Adjacent Cell Indexing](2992-uniform-grid-adjacent-cell-indexing.md)
Computes the linear indices of the four cells sharing a specific grid edge. It specializes in edge-adjacency relationships for isosurface extraction rather than arbitrary point-to-cell mapping.

### [Uniform Grid Indexing](6941-uniform-grid-indexing.md)
Converts a 3D world position into a linear array index within a dense, axis-aligned voxel grid using an AABB and fixed resolution. It guarantees deterministic indexing for dense grids.

### [Voxel Index Computation](13870-voxel-index-computation.md)
Maps continuous 3D coordinates to discrete voxel indices with support for batched bounding boxes and optional half-voxel alignment shifts. It is optimized for neural rendering pipelines using tensor operations.

## Background
The concept of mapping spatial coordinates to grid indices originates from early computer graphics and scientific visualization, where dense voxel grids were used for volume rendering and medical imaging. The specific implementations described here, such as batched index computation and 3-bit texture coordinate encoding, reflect modern adaptations for neural rendering and GPU-based processing . The use of row-major ordering and clamping strategies is standard in graphics APIs and game engines to handle floating-point precision errors at boundaries .
