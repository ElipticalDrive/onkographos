# Uniform Grid Adjacent Cell Indexing

Also called: Adjacent Cell Indexing, Edge Neighbor Indexing

## Overview
Computes the linear indices of the four cells sharing a specific grid edge in a uniform voxel grid, returning a sentinel value (`kBadIndex`) for neighbors that lie outside the grid boundaries [S1, unofficial]. It differs from general [Voxel Grid Indexing](1719-voxel-grid-indexing.md) by specializing in edge-adjacency relationships required for constructing quad primitives in isosurface extraction, rather than arbitrary point-to-cell mapping [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:**
  - `edgePos`: The 3D coordinates of the edge center or a point on the edge.
  - `edgeType`: An integer identifier (0, 1, or 2) indicating the orientation of the edge relative to the grid axes.
  - `m_size`: The dimension of the uniform grid (assumed cubic, $N \times N \times N$).
  - `m_halfSize`: Half the grid dimension, used for boundary checks.
  - `pointToIndex`: A helper function mapping 3D coordinates to a linear index.
- **Outputs:**
  - `cells`: An array of 4 integers representing the linear indices of the adjacent cells.
  - `kBadIndex`: A sentinel value (e.g., -1) indicating no neighbor exists.

**Data Structures:**
- `cells`: Array of 4 integers.
- `edgePos`: Struct or tuple $(x, y, z)$.

**Formulas and Steps:**
The method determines the linear indices based on the edge type. The linear index $I$ for a cell at $(i, j, k)$ in a grid of size $S$ is typically $i \cdot S^2 + j \cdot S + k$. The adjacent cells share an edge, meaning they differ in two dimensions.

1. **Edge Type 0 (Parallel to X-axis):**
   - The edge runs along the X-axis. The adjacent cells differ in Y and Z.
   - Calculate strides: $dy = (m\_size + 1) \times (m\_size + 1)$, $dz = 1$.
   - Base index: $cells[2] = pointToIndex(edgePos)$.
   - Neighbors:
     - $cells[0] = cells[2] - dy - dz$
     - $cells[1] = cells[2] - dz$
     - $cells[3] = cells[2] - dy$
   - **Boundary Checks:**
     - If $edgePos.y == -m\_halfSize$, $cells[0]$ and $cells[3]$ are invalid (set to `kBadIndex`).
     - If $edgePos.y == m\_halfSize$, $cells[1]$ and $cells[2]$ are invalid.
     - If $edgePos.z == -m\_halfSize$, $cells[0]$ and $cells[1]$ are invalid.
     - If $edgePos.z == m\_halfSize$, $cells[2]$ and $cells[3]$ are invalid.

2. **Edge Type 1 (Parallel to Y-axis):**
   - The edge runs along the Y-axis. The adjacent cells differ in X and Z.
   - Calculate strides: $dx = (m\_size + 1)$, $dz = 1$.
   - Base index: $cells[2] = pointToIndex(edgePos)$.
   - Neighbors:
     - $cells[0] = cells[2] - dx - dz$
     - $cells[1] = cells[2] - dx$
     - $cells[3] = cells[2] - dz$
   - **Boundary Checks:**
     - Similar logic applies based on X and Z boundaries. If $edgePos.x == -m\_halfSize$, $cells[0]$ and $cells[3]$ are invalid. If $edgePos.x == m\_halfSize$, $cells[1]$ and $cells[2]$ are invalid. If $edgePos.z == -m\_halfSize$, $cells[0]$ and $cells[1]$ are invalid. If $edgePos.z == m\_halfSize$, $cells[2]$ and $cells[3]$ are invalid.

3. **Edge Type 2 (Parallel to Z-axis):**
   - The edge runs along the Z-axis. The adjacent cells differ in X and Y.
   - Calculate strides: $dx = (m\_size + 1)$, $dy = (m\_size + 1) \times (m\_size + 1)$.
   - Base index: $cells[2] = pointToIndex(edgePos)$.
   - Neighbors:
     - $cells[0] = cells[2] - dx - dy$
     - $cells[1] = cells[2] - dy$
     - $cells[3] = cells[2] - dx$
   - **Boundary Checks:**
     - If $edgePos.x == -m\_halfSize$, $cells[0]$ and $cells[3]$ are invalid. If $edgePos.x == m\_halfSize$, $cells[1]$ and $cells[2]$ are invalid. If $edgePos.y == -m\_halfSize$, $cells[0]$ and $cells[1]$ are invalid. If $edgePos.y == m\_halfSize$, $cells[2]$ and $cells[3]$ are invalid.

**Pseudocode:**
```python
def get_adjacent_cells(edge_pos, edge_type, m_size, m_half_size, point_to_index):
    """
    Computes linear indices of 4 cells adjacent to an edge in a uniform grid.
    
    Args:
        edge_pos: Tuple (x, y, z) representing the edge position.
        edge_type: Integer 0 (X-parallel), 1 (Y-parallel), or 2 (Z-parallel).
        m_size: Grid dimension size.
        m_half_size: Half the grid dimension size.
        point_to_index: Function mapping (x, y, z) to linear index.
        
    Returns:
        List of 4 integers. kBadIndex (-1) for out-of-bounds neighbors.
    """
    kBadIndex = -1
    cells = [0] * 4
    
    # Calculate base index from edge position
    # Note: point_to_index implementation depends on specific grid coordinate system.
    # Assuming standard integer grid indexing where point_to_index returns the cell index
    # containing or adjacent to the point.
    cells[2] = point_to_index(edge_pos)
    
    if edge_type == 0:
        # Edge parallel to X-axis
        dy = (m_size + 1) * (m_size + 1)
        dz = 1
        cells[0] = cells[2] - dy - dz
        cells[1] = cells[2] - dz
        cells[3] = cells[2] - dy
        
        # Boundary checks for Y and Z
        if edge_pos[1] == -m_half_size:
            cells[0] = kBadIndex
            cells[3] = kBadIndex
        if edge_pos[1] == m_half_size:
            cells[1] = kBadIndex
            cells[2] = kBadIndex
        if edge_pos[2] == -m_half_size:
            cells[0] = kBadIndex
            cells[1] = kBadIndex
        if edge_pos[2] == m_half_size:
            cells[2] = kBadIndex
            cells[3] = kBadIndex
            
    elif edge_type == 1:
        # Edge parallel to Y-axis
        dx = (m_size + 1)
        dz = 1
        cells[0] = cells[2] - dx - dz
        cells[1] = cells[2] - dx
        cells[3] = cells[2] - dz
        
        # Boundary checks for X and Z
        if edge_pos[0] == -m_half_size:
            cells[0] = kBadIndex
            cells[3] = kBadIndex
        if edge_pos[0] == m_half_size:
            cells[1] = kBadIndex
            cells[2] = kBadIndex
        if edge_pos[2] == -m_half_size:
            cells[0] = kBadIndex
            cells[1] = kBadIndex
        if edge_pos[2] == m_half_size:
            cells[2] = kBadIndex
            cells[3] = kBadIndex
            
    elif edge_type == 2:
        # Edge parallel to Z-axis
        dx = (m_size + 1)
        dy = (m_size + 1) * (m_size + 1)
        cells[0] = cells[2] - dx - dy
        cells[1] = cells[2] - dy
        cells[3] = cells[2] - dx
        
        # Boundary checks for X and Y
        if edge_pos[0] == -m_half_size:
            cells[0] = kBadIndex
            cells[3] = kBadIndex
        if edge_pos[0] == m_half_size:
            cells[1] = kBadIndex
            cells[2] = kBadIndex
        if edge_pos[1] == -m_half_size:
            cells[0] = kBadIndex
            cells[1] = kBadIndex
        if edge_pos[1] == m_half_size:
            cells[2] = kBadIndex
            cells[3] = kBadIndex
            
    return cells
```

Multi-Material Quad Vertex Index Mapping maps a cell edge type to a four-element vertex index array defining a quadrilateral primitive. It resolves vertex connectivity for a quad face using pointer arithmetic on a cell array, building on [Uniform Grid Adjacent Cell Indexing](2992-uniform-grid-adjacent-cell-indexing.md) which computes adjacent cell linear indices.

## Operating characteristics
- **Time Complexity:** $O(1)$ per edge, involving a constant number of arithmetic operations and boundary checks.
- **Memory Complexity:** $O(1)$ auxiliary space, storing only 4 indices and temporary variables.
- **Strengths:** Efficient for isosurface extraction where edge-based quad construction is required. Direct index computation avoids complex tree traversals.
- **Limitations:** Requires precise boundary handling. Incorrect edge type or position can lead to invalid indices. Assumes a uniform grid structure.
- **When to use:** When extracting isosurfaces from uniform grids and constructing quad primitives based on edge connectivity.
- **When not to use:** For sparse grids or non-uniform grids where adjacency is not determined by simple arithmetic offsets.

## Background
Originated in the context of isosurface extraction from uniform voxel grids, specifically in implementations like `isomesh` [S1, unofficial]. It is a specialized indexing method for handling edge-adjacent cells in 3D grid data.
