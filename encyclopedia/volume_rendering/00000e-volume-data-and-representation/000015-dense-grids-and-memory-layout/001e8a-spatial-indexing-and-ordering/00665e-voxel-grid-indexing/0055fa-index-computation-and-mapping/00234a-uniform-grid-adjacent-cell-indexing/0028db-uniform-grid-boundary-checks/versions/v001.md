# Uniform Grid Boundary Checks

Also called: UniformGrid Face and Cell Boundary Checks, isCellInGrid, isCellOnBorder, isFaceInGrid

## Overview
Uniform Grid Boundary Checks determine whether a specified face or cell coordinate lies within the valid bounds of a uniform voxel grid or resides on its boundary. This method is essential for preventing out-of-bounds memory access when computing adjacent cell indices, serving as the validation layer for [Uniform Grid Adjacent Cell Indexing](2992-uniform-grid-adjacent-cell-indexing.md). It distinguishes itself by operating on half-size centered coordinates rather than linear indices, providing a geometric check before mapping to linear memory.

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `cellPos`: A 3D vector $(x, y, z)$ representing the integer cell coordinates.
    *   `facePos`: A 3D vector $(x, y, z)$ representing the integer face coordinates.
    *   `faceType`: An integer identifier for the face normal direction (0 for X-normal, 1 for Y-normal, 2 for Z-normal).
    *   `m_halfSize`: A scalar integer representing half the grid dimension in each axis. For a grid of size $N$ in a given dimension, $m\_halfSize = \lfloor N/2 \rfloor$.
*   **Outputs:**
    *   Boolean results for `isCellInGrid`, `isCellOnBorder`, `isFaceInGrid`, and `isFaceOnBorder`.

**Data Structures:**
The grid is assumed to be centered at the origin. The valid range for cell indices in any dimension $d$ is $[-m\_halfSize, m\_halfSize - 1]$. The valid range for face indices in any dimension $d$ is $[-m\_halfSize, m\_halfSize]$.

**Formulas and Logic:**
Let $m\_halfSize$ be the half-size of the grid.

1.  **Cell In Grid (`isCellInGrid`):**
    A cell position is inside the grid if all coordinates satisfy:
    $$ -m\_halfSize \le cellPos.d < m\_halfSize $$
    for $d \in \{x, y, z\}$.

2.  **Cell On Border (`isCellOnBorder`):**
    A cell position is on the border if any coordinate equals the minimum bound or the maximum valid index ($m\_halfSize - 1$):
    $$ cellPos.d = -m\_halfSize \quad \text{OR} \quad cellPos.d = m\_halfSize - 1 $$
    for any $d \in \{x, y, z\}$.

3.  **Face In Grid (`isFaceInGrid`):**
    A face position is inside the grid if it satisfies the following conditions based on `faceType`:
    *   If `faceType` == 0 (X-normal):
        $$ |facePos.x| \le m\_halfSize $$
        $$ -m\_halfSize \le facePos.y < m\_halfSize $$
        $$ -m\_halfSize \le facePos.z < m\_halfSize $$
    *   If `faceType` == 1 (Y-normal):
        $$ -m\_halfSize \le facePos.x < m\_halfSize $$
        $$ |facePos.y| \le m\_halfSize $$
        $$ -m\_halfSize \le facePos.z < m\_halfSize $$
    *   If `faceType` == 2 (Z-normal):
        $$ -m\_halfSize \le facePos.x < m\_halfSize $$
        $$ -m\_halfSize \le facePos.y < m\_halfSize $$
        $$ |facePos.z| \le m\_halfSize $$

4.  **Face On Border (`isFaceOnBorder`):**
    A face position is on the border if the coordinate corresponding to its normal type equals $\pm m\_halfSize$:
    *   If `faceType` == 0: $|facePos.x| = m\_halfSize$
    *   If `faceType` == 1: $|facePos.y| = m\_halfSize$
    *   If `faceType` == 2: $|facePos.z| = m\_halfSize$

**Pseudocode:**
```python
def is_cell_in_grid(cell_pos, m_half_size):
    """
    Returns True if cell_pos is strictly inside the grid bounds.
    """
    if cell_pos.x < -m_half_size:
        return False
    if cell_pos.y < -m_half_size:
        return False
    if cell_pos.z < -m_half_size:
        return False
    if cell_pos.x >= m_half_size:
        return False
    if cell_pos.y >= m_half_size:
        return False
    if cell_pos.z >= m_half_size:
        return False
    return True

def is_cell_on_border(cell_pos, m_half_size):
    """
    Returns True if cell_pos is on the boundary of the grid.
    """
    min_bound = -m_half_size
    max_bound = m_half_size - 1
    
    if cell_pos.x == min_bound or cell_pos.y == min_bound or cell_pos.z == min_bound:
        return True
    if cell_pos.x == max_bound or cell_pos.y == max_bound or cell_pos.z == max_bound:
        return True
    return False

def is_face_in_grid(face_pos, face_type, m_half_size):
    """
    Returns True if face_pos is inside the grid bounds for the given face type.
    """
    min_bound = -m_half_size
    max_bound = m_half_size
    
    if face_type == 0: # X-normal
        if abs(face_pos.x) > m_half_size:
            return False
        if face_pos.y < min_bound or face_pos.y >= max_bound:
            return False
        if face_pos.z < min_bound or face_pos.z >= max_bound:
            return False
    elif face_type == 1: # Y-normal
        if face_pos.x < min_bound or face_pos.x >= max_bound:
            return False
        if abs(face_pos.y) > m_half_size:
            return False
        if face_pos.z < min_bound or face_pos.z >= max_bound:
            return False
    elif face_type == 2: # Z-normal
        if face_pos.x < min_bound or face_pos.x >= max_bound:
            return False
        if face_pos.y < min_bound or face_pos.y >= max_bound:
            return False
        if abs(face_pos.z) > m_half_size:
            return False
    else:
        # Invalid face type [G]
        return False
        
    return True

def is_face_on_border(face_pos, face_type, m_half_size):
    """
    Returns True if face_pos is on the boundary of the grid.
    """
    if face_type == 0:
        return abs(face_pos.x) == m_half_size
    elif face_type == 1:
        return abs(face_pos.y) == m_half_size
    elif face_type == 2:
        return abs(face_pos.z) == m_half_size
    else:
        return False # Invalid face type [G]
```

## Subtopics

### Rect-Grid Bounds Validation
This variant applies boundary checks to rectilinear grids where dimensions may vary per axis. It requires that the grid bounds array be monotonically increasing and sized to `dims + 1`. Validation of these properties must occur during preflight and result in an error if violated [S2, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
The checks are $O(1)$ in time and memory, involving only a few integer comparisons.

**Strengths and Limitations:**
*   **Strengths:** Extremely fast; prevents segmentation faults or undefined behavior in adjacent cell lookups.
*   **Limitations:** Relies on correct initialization of `m_halfSize`. If the grid dimensions are even, the centering logic must be consistent with the indexing scheme.

**When to use:**
Use whenever accessing neighbor cells or faces in a uniform grid to ensure indices are valid before memory access.

## Background
This method is derived from implementations in the `isomesh` library, specifically within the `UniformGrid` class structure which manages face and cell positions relative to a half-size center [S1, unofficial]. It is also referenced in the context of point cloud voxelization filters where grid bounds validation is critical [S2, unofficial].
