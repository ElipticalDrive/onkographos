# Voxel Grid Construction from AABB

Also called: VoxelGrid.fromAABB

## Overview
Constructs a uniform voxel grid from an Axis-Aligned Bounding Box (AABB) and a target resolution, ensuring uniform voxel size by scaling based on the longest axis and clamping zero-extent axes [S1, unofficial]. It differs from sibling methods by focusing on the initial geometric discretization of a world-space bounding volume into a regular 3D lattice, whereas siblings handle spherical mappings, incremental rotations, or specific utility conversions [S1, unofficial].

## How it works
**Inputs:**
- `bbox`: An AABB defined by minimum and maximum coordinates $(x_{min}, y_{min}, z_{min})$ and $(x_{max}, y_{max}, z_{max})$.
- `resolution`: A positive integer $N$ representing the target voxel count along the longest axis.

**Outputs:**
- `voxelSize`: The side length of each cubic voxel.
- `dimensions`: A 3D vector $(D_x, D_y, D_z)$ representing the number of voxels along each axis.
- `grid`: The initialized voxel grid data structure.

**Data Structures:**
The voxel grid is typically a dense array or a sparse structure indexed by $(i, j, k)$ where $0 \le i < D_x$, $0 \le j < D_y$, $0 \le k < D_z$. The exact memory layout depends on the implementation (e.g., row-major or column-major), but indices are derived from the computed dimensions.

**Steps:**
1. **Validate Input:**
   - Check that `resolution` is a positive integer. If not, throw an error [S1, unofficial].
   - Check that the AABB is valid (i.e., $x_{min} \le x_{max}$, $y_{min} \le y_{max}$, $z_{min} \le z_{max}$). If any axis is inverted (min > max), throw an error [S1, unofficial].

2. **Calculate AABB Dimensions:**
   Compute the extent of the bounding box along each axis:
   $$
   D_x^{raw} = x_{max} - x_{min}
   $$
   $$
   D_y^{raw} = y_{max} - y_{min}
   $$
   $$
   D_z^{raw} = z_{max} - z_{min}
   $$

3. **Determine Voxel Size:**
   Find the maximum extent to ensure uniform voxel size across all axes:
   $$
   L_{max} = \max(D_x^{raw}, D_y^{raw}, D_z^{raw})
   $$
   Calculate the voxel size:
   $$
   \text{voxelSize} = \frac{L_{max}}{N}
   $$
   [S1, unofficial]

4. **Calculate Voxel Counts:**
   Compute the number of voxels required for each axis to fully cover the AABB:
   $$
   D_x = \lceil \frac{D_x^{raw}}{\text{voxelSize}} \rceil
   $$
   $$
   D_y = \lceil \frac{D_y^{raw}}{\text{voxelSize}} \rceil
   $$
   $$
   D_z = \lceil \frac{D_z^{raw}}{\text{voxelSize}} \rceil
   $$
   [S1, unofficial]

5. **Handle Zero-Extent Axes:**
   If any axis has a raw dimension of zero (e.g., a degenerate 2D object in 3D space), the corresponding count must be clamped to 1 to avoid division by zero or empty grids. This is implicitly handled by the ceiling function if $D^{raw}=0$ results in 0, but explicit clamping is required if the implementation does not naturally yield 1 for zero extent. Specifically, if $D^{raw} = 0$, set $D = 1$ [S1, unofficial].

6. **Initialize Grid:**
   Allocate the voxel grid with dimensions $(D_x, D_y, D_z)$ and store `voxelSize` for subsequent coordinate transformations.

**Pseudocode:**
```python
def VoxelGrid_fromAABB(bbox, resolution):
    # bbox is a tuple or object with min and max coordinates
    min_coords = bbox.min
    max_coords = bbox.max
    
    # Validate resolution
    if not isinstance(resolution, int) or resolution <= 0:
        raise ValueError("Resolution must be a positive integer")
        
    # Validate AABB
    if (max_coords.x < min_coords.x or 
        max_coords.y < min_coords.y or 
        max_coords.z < min_coords.z):
        raise ValueError("AABB is inverted (min > max)")
        
    # Calculate raw dimensions
    dim_x_raw = max_coords.x - min_coords.x
    dim_y_raw = max_coords.y - min_coords.y
    dim_z_raw = max_coords.z - min_coords.z
    
    # Determine voxel size based on longest axis
    max_dim = max(dim_x_raw, dim_y_raw, dim_z_raw)
    voxel_size = max_dim / resolution
    
    # Calculate voxel counts
    # Use ceiling to ensure full coverage
    dim_x = ceil(dim_x_raw / voxel_size)
    dim_y = ceil(dim_y_raw / voxel_size)
    dim_z = ceil(dim_z_raw / voxel_size)
    
    # Clamp zero-extent axes to 1
    if dim_x == 0: dim_x = 1
    if dim_y == 0: dim_y = 1
    if dim_z == 0: dim_z = 1
    
    # Initialize grid
    grid = VoxelGrid(dimensions=(dim_x, dim_y, dim_z), voxel_size=voxel_size)
    
    return grid
```

## Operating characteristics
- **Time Complexity:** $O(1)$ for the construction logic itself, as it involves a fixed number of arithmetic operations. Grid allocation is $O(D_x \cdot D_y \cdot D_z)$.
- **Memory Complexity:** $O(D_x \cdot D_y \cdot D_z)$ for the dense grid storage.
- **Strengths:** Ensures uniform voxel size, which simplifies subsequent ray marching or splatting operations. Handles degenerate cases (zero extent) gracefully.
- **Limitations:** May result in a larger grid than necessary if the object is thin along one axis but large along another, as the voxel size is determined by the longest axis.
- **When to use:** When a uniform voxelization of a bounding volume is required for subsequent spatial indexing or rendering.
- **When not to use:** When anisotropic voxels are acceptable or when memory constraints are tight and a sparse representation is preferred.

## Background
This method is part of the `splatcarve` library, which deals with 3D Gaussian Splatting carving and manipulation [S1, unofficial]. It provides a foundational step for converting world-space bounding boxes into a discrete voxel space suitable for processing splat data.
