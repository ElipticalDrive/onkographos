# Rotation
Also called: Rotate
## Overview
Rotation modifies the spatial orientation of a 3D volume geometry by applying angular transformations to voxel coordinates [S1, S2, unofficial]. It solves the problem of reorienting volumetric data for alignment or geometric manipulation while preserving the underlying voxel grid topology [S1, unofficial]. It builds on Volume Geometry Transformations [17760-volume-geometry-transformations.md].

## How it works
**Inputs and Outputs:**
- Input: A voxel grid (dense or sparse), rotation parameters (axis, `turns` for 90° increments or angle $\theta$, optional `center`) [S1, S2, unofficial].
- Output: A transformed voxel grid with updated coordinates and values [S1, S2, unofficial].

**Data Structures:**
The voxel grid is represented as a 3D array or hash map where each entry stores coordinates $(x, y, z)$ and a scalar or vector value [G].

**Steps:**
1. **Define Rotation Parameters:** Specify the axis ('x', 'y', or 'z'), the magnitude (`turns` for 90° increments or angle $\theta$), and an optional `center` $C = (c_x, c_y, c_z)$ [S1, S2, unofficial].
2. **Translate to Origin:** If `center` $C$ is specified, subtract $C$ from all voxel coordinates $(x, y, z)$ to move the rotation center to the origin [S1, unofficial].
   $$ x_{temp} = x - c_x $$
   $$ y_{temp} = y - c_y $$
   $$ z_{temp} = z - c_z $$
3. **Apply Rotation:** For 90° increments, apply discrete coordinate permutations based on `turns` [S1, unofficial]. For arbitrary angles, apply a rotation matrix to calculate new coordinates $(x', y', z')$ [S2, unofficial].
   - `turns = 1` (90°): $(x, y, z) \to (-y, x, z)$
   - `turns = 2` (180°): $(x, y, z) \to (-x, -y, z)$
   - `turns = 3` (270°): $(x, y, z) \to (y, -x, z)$
4. **Translate Back:** If `center` was used, add $C$ back to the rotated coordinates [S1, unofficial].
   $$ x_{final} = x' + c_x $$
   $$ y_{final} = y' + c_y $$
   $$ z_{final} = z' + c_z $$
5. **Place/Update Grid:** Insert the transformed coordinates and values into the output grid. Rotation can be applied before or after placement [S1, unofficial]. For sparse grids, update the hash map keys [G].

**Pseudocode:**
```python
def rotate_voxel_grid(grid, axis='z', turns=1, center=None):
    """
    Rotate a voxel grid by 90-degree increments.
    grid: dict mapping (x, y, z) tuples to values.
    axis: 'x', 'y', or 'z'.
    turns: integer number of 90-degree rotations.
    center: tuple (cx, cy, cz) or None for origin.
    """
    new_grid = {}
    t = turns % 4
    
    for (x, y, z), value in grid.items():
        # Step 2: Translate to center
        if center is not None:
            cx, cy, cz = center
            x -= cx
            y -= cy
            z -= cz
        
        # Step 3: Apply rotation permutation
        if axis == 'z':
            if t == 1: nx, ny, nz = -y, x, z
            elif t == 2: nx, ny, nz = -x, -y, z
            elif t == 3: nx, ny, nz = y, -x, z
            else: nx, ny, nz = x, y, z
        elif axis == 'x':
            if t == 1: nx, ny, nz = x, -z, y
            elif t == 2: nx, ny, nz = x, -y, -z
            elif t == 3: nx, ny, nz = x, z, -y
            else: nx, ny, nz = x, y, z
        elif axis == 'y':
            if t == 1: nx, ny, nz = z, y, -x
            elif t == 2: nx, ny, nz = -x, y, -z
            elif t == 3: nx, ny, nz = -z, y, x
            else: nx, ny, nz = x, y, z
        else:
            raise ValueError("Axis must be 'x', 'y', or 'z'")
        
        # Step 4: Translate back
        if center is not None:
            nx += cx
            ny += cy
            nz += cz
            
        # Step 5: Place into new grid
        new_grid[(nx, ny, nz)] = value
        
    return new_grid
```

**Parameters:**
- `axis`: String, one of 'x', 'y', 'z' [S1, unofficial].
- `turns`: Integer, number of 90-degree rotations [S1, unofficial].
- `center`: Optional tuple of floats, default is origin (0,0,0) [S1, unofficial].

**Edge Cases:**
- Non-integer coordinates: If arbitrary angles are used, interpolation is mandatory [G].
- Boundary conditions: Rotated voxels may fall outside the original grid bounds; clipping or padding may be required [G].
- Precision: Floating-point errors in arbitrary angle rotations can cause misalignment [G].

## Subtopics

### Geometric Transformations
Includes rotation, translation, and scaling [S2, unofficial]. Rotation specifically involves applying a rotation matrix to calculate new coordinates for a voxel at $(x, y, z)$ by an angle $\theta$ around an axis [S2, unofficial].
