# Spatial Sorting Layout
Also called: Directional sort, Spatial layout
## Overview
Spatial sorting is a memory layout technique for tetrahedral meshes that reorders vertices and cells to maximize spatial coherence along a dominant principal direction [S1]. Unlike general spatial indexing methods that handle arbitrary geometries, this approach is specifically optimized for meshes with a strong linear orientation, sacrificing performance on isotropic data like spheres [S1].
## How it works
**Inputs:** A tetrahedral mesh defined by a vertex list and a cell list, where each cell references four vertex indices [S1].
**Outputs:** A new interleaved file containing vertices and cells in the sorted order [S1].

**Data Structures:**
1.  **Vertex File:** Stores vertex coordinates [S1].
2.  **Mapping File:** Stores the permutation array mapping old vertex indices to new sorted indices [S1].
3.  **Cell File:** Stores cell indices, reindexed according to the mapping [S1].

**Steps:**
1.  **Direction Selection:** Identify a spatial direction that crosses the maximum number of tetrahedra [S1].
2.  **Vertex Sorting:** Perform an out-of-core sort of the vertices based on their projection onto the selected direction, and write them to a new file [S1].
3.  **Mapping Generation:** Create a mapping file recording the permutation from the original vertex ordering to the new sorted ordering [S1].
4.  **Cell Reindexing:** Write the tetrahedral cells to a new file, reindexing every vertex reference according to the mapping file [S1].
5.  **Cell Sorting:** Sort the reindexed cell file based on the largest vertex index contained within each cell [S1].
6.  **Interleaving:** Read the sorted vertex file and the sorted cell file simultaneously, interleaving them into a new output file by writing each cell immediately after the vertex corresponding to the cell’s largest index has been written [S1].

**Pseudocode:**
```python
def spatial_sort_layout(vertices, cells):
    # Step 1: Direction selection
    # The source does not specify how to compute the dominant direction [G]
    direction = (1.0, 0.0, 0.0)  # Example direction; replace with actual computation
    
    # Step 2: Sort vertices by projection onto direction
    projected = [(sum(v[j] * direction[j] for j in range(3)), i) for i, v in enumerate(vertices)]
    projected.sort(key=lambda x: x[0])
    
    # Step 3: Create mapping from old index to new index
    mapping = [0] * len(vertices)
    for new_idx, (proj, old_idx) in enumerate(projected):
        mapping[old_idx] = new_idx
        
    # Step 4: Reindex cells using mapping
    reindexed_cells = []
    for cell in cells:
        new_cell = [mapping[v] for v in cell]
        reindexed_cells.append(new_cell)
        
    # Step 5: Sort cells by their maximum vertex index
    reindexed_cells.sort(key=lambda c: max(c))
    
    # Step 6: Interleave vertices and cells
    cells_for_vertex = [[] for _ in range(len(vertices))]
    for cell in reindexed_cells:
        max_idx = max(cell)
        cells_for_vertex[max_idx].append(cell)
        
    output = []
    for i in range(len(vertices)):
        output.append(vertices[i])
        for cell in cells_for_vertex[i]:
            output.append(cell)
            
    return output
```

**Edge Cases and Pitfalls:**
*   **Dominant Direction Requirement:** The method works especially well only for meshes with a dominant principal direction [S1].
*   **Out-of-Core Sorting:** For very large meshes, sorting must be performed out-of-core to avoid memory exhaustion [S1].
*   **Tie Breaking:** If multiple directions cross the same number of tetrahedra, a secondary criterion is not specified in the source [G].
## Subtopics
## Operating characteristics
**Time Complexity:** Not given in the sources.
**Memory Complexity:** Not given in the sources.
**Performance:** Provides high cache efficiency for streaming rendering of large tetrahedral meshes with a clear orientation [S1]. It is not suitable for data without a dominant direction [S1].
**Strengths:** Simple to implement; effective for directional data; enables out-of-core processing [S1].
**Limitations:** Fails on isotropic data; requires multiple passes over the data (sort, map, reindex, sort, interleave) [S1].
## Background
The method was described in the context of streaming simplification of tetrahedral meshes [S1]. It builds on earlier work by Wu and Kobbelt for triangle mesh simplification, adapting the concept of directional sorting to tetrahedral volumes [S1]. The approach is designed to facilitate efficient out-of-core rendering and simplification of large datasets [S1].
