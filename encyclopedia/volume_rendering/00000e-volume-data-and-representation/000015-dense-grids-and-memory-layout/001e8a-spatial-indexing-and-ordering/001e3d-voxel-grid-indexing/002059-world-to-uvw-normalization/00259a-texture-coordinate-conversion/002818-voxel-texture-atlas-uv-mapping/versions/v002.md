# Voxel Texture Atlas UV Mapping
## Overview
Voxel Texture Atlas UV Mapping is a technique that maps voxel face types and directions to a 2D texture atlas using calculated UV coordinates, incorporating safety margins to prevent texture bleeding [S2, unofficial]. It differs from standard texture coordinate conversion by explicitly handling the discrete nature of voxel faces, remapping vertices to ensure unique UVs per face type, and applying per-voxel shading logic (transparency, shadow) within the sampling pipeline [S2, unofficial].
## How it works
**Inputs and Outputs:**
*   **Inputs:** Voxel type ID ($v\_Type$), face direction index ($v\_Direction \in [0,5]$), local vertex UV coordinate within the quad ($v\_TexCoord \in [0,1]$), and optional vertex mapping array ($vmapping$) [S2, unofficial].
*   **Outputs:** Final UV coordinates ($finalUV$) for texture sampling, and modified color output including transparency and shadow factors [S2, unofficial].

**Data Structures:**
*   **Texture Atlas:** A 512x512 pixel image [S2, unofficial].
*   **Tile Layout:**
    *   Tile Size: 16x16 pixels [S2, unofficial].
    *   Border Size: 1 pixel [S2, unofficial].
    *   Total Tile Size: 17x17 pixels [S2, unofficial].
    *   Tiles per Row/Column: 30 [S2, unofficial].
    *   Safe Margin: 0.002 in UV space [S2, unofficial].
*   **Face Data Packing:** Voxel face data is packed into a 32-bit integer with the following bit layout [S2, unofficial]:
    *   Bits 0-2: Direction (3 bits) [S2, unofficial].
    *   Bits 3-10: Type (8 bits) [S2, unofficial].
    *   Bits 11-14: Z coordinate (4 bits) [S2, unofficial].
    *   Bits 15-18: Y coordinate (4 bits) [S2, unofficial].
    *   Bits 19-22: X coordinate (4 bits) [S2, unofficial].
    *   The packed value fits in a `uint32` or `float32` [S2, unofficial].

**Steps:**

1.  **Cache Check:** Check for a cached UV file at `cache_path + '_uv.npz'` [S1, unofficial]. If it exists, load vertex texture (`vt`), face texture (`ft`), and vertex mapping (`vmapping`) arrays directly [S1, unofficial]. If not, proceed to calculation [S1, unofficial].
2.  **Calculate Base UV:** Determine the tile's position in the atlas grid based on the face type and direction index [S2, unofficial]. Let $col$ and $row$ be the grid coordinates of the tile [S2, unofficial].
    $$ baseUV.x = \frac{col \times TOTAL\_TILE\_SIZE + BORDER\_SIZE}{ATLAS\_WIDTH} $$
    $$ baseUV.y = 1.0 - \frac{row \times TOTAL\_TILE\_SIZE + TOTAL\_TILE\_SIZE - BORDER\_SIZE}{ATLAS\_HEIGHT} $$
    The Y calculation flips the coordinate system so that row 0 is at the top of the texture (UV y=1) [S2, unofficial].
3.  **Calculate Safe UV Range:** Compute the usable area within the tile, excluding the border [S2, unofficial].
    $$ safeTileSize.x = \frac{TILE\_SIZE - 2.0 \times BORDER\_SIZE}{ATLAS\_WIDTH} $$
    $$ safeTileSize.y = \frac{TILE\_SIZE - 2.0 \times BORDER\_SIZE}{ATLAS\_HEIGHT} $$
4.  **Calculate Within-Tile UV:** Scale the local vertex UV coordinate to the safe area and apply the margin [S2, unofficial].
    $$ withinTileUV.x = v\_TexCoord.x \times safeTileSize.x + SAFE\_MARGIN $$
    $$ withinTileUV.y = v\_TexCoord.y \times safeTileSize.y + SAFE\_MARGIN $$
5.  **Final UV Calculation:** Combine the base tile position with the within-tile offset [S2, unofficial].
    $$ finalUV = baseUV + withinTileUV $$
6.  **Vertex Remapping (Optional):** If $vmapping$ is true, remap vertex and normal arrays to align with UV indices using `align_v_to_vt(vmapping)`, ensuring each vertex has a unique UV coordinate [S1, unofficial].
7.  **Texture Sampling:** Sample the texture atlas using the final UV [S2, unofficial].
    $$ color = texture2D(textureAtlas, finalUV) $$
8.  **Apply Water Transparency:** If the voxel type is water ($v\_Type == 5.0$), set the alpha channel to 0.5 [S2, unofficial].
9.  **Apply Directional Shadow:** Calculate a shadow factor based on the face direction and a fixed light vector [S2, unofficial].
    $$ shadowFactor = \max(0.5, \text{dot}(\text{normalize}(\vec{3}(v\_Direction, 0.5, 1.0)), \vec{3}(0.0, 1.0, 1.0))) $$
    $$ color.rgb *= shadowFactor $$

**Pseudocode:**

```python
def calculate_voxel_uv(v_type, v_direction, v_tex_coord, atlas_width=512, atlas_height=512, 
                       tile_size=16, border_size=1, safe_margin=0.002):
    """
    Calculate UV coordinates for a voxel face in a texture atlas.
    
    Args:
        v_type: Voxel type ID (used to determine tile index)
        v_direction: Face direction index (0-5)
        v_tex_coord: Local UV coordinate within the quad (vec2, 0-1)
        
    Returns:
        final_uv: Final UV coordinate (vec2)
        color_mod: Dictionary with transparency and shadow adjustments
    """
    # Constants
    total_tile_size = tile_size + 2 * border_size
    safe_tile_size_x = (tile_size - 2 * border_size) / atlas_width
    safe_tile_size_y = (tile_size - 2 * border_size) / atlas_height
    
    # Mapping of (v_type, v_direction) to (col, row) is not specified in sources [S2, unofficial].
    # Assuming a linear index for demonstration:
    face_index = v_type * 6 + v_direction
    col = face_index % 30
    row = face_index // 30
    
    # Calculate Base UV
    base_uv_x = (col * total_tile_size + border_size) / atlas_width
    base_uv_y = 1.0 - ((row * total_tile_size + total_tile_size - border_size) / atlas_height)
    
    # Calculate Within-Tile UV
    within_tile_uv_x = v_tex_coord.x * safe_tile_size_x + safe_margin
    within_tile_uv_y = v_tex_coord.y * safe_tile_size_y + safe_margin
    
    # Final UV
    final_uv_x = base_uv_x + within_tile_uv_x
    final_uv_y = base_uv_y + within_tile_uv_y
    
    # Apply Shading
    color_mod = {}
    
    # Water Transparency
    if v_type == 5.0:
        color_mod['alpha'] = 0.5
    else:
        color_mod['alpha'] = 1.0
        
    # Directional Shadow
    normal_x = float(v_direction)
    normal_y = 0.5
    normal_z = 1.0
    length = (normal_x**2 + normal_y**2 + normal_z**2)**0.5
    if length > 0:
        normal_x /= length
        normal_y /= length
        normal_z /= length
        
    light_x = 0.0
    light_y = 1.0
    light_z = 1.0
    dot_product = normal_x * light_x + normal_y * light_y + normal_z * light_z
    shadow_factor = max(0.5, dot_product)
    color_mod['shadow'] = shadow_factor
    
    return (final_uv_x, final_uv_y), color_mod
```

**Edge Cases and Pitfalls:**
*   **Texture Bleeding:** The safe margin (0.002) is critical to prevent sampling from adjacent tiles due to filtering or precision errors [S2, unofficial].
*   **Y-Axis Flip:** The base UV Y calculation flips the coordinate system [S2, unofficial].
*   **Direction Normalization:** The shadow calculation uses the direction index as a float in a 3D vector [S2, unofficial].
