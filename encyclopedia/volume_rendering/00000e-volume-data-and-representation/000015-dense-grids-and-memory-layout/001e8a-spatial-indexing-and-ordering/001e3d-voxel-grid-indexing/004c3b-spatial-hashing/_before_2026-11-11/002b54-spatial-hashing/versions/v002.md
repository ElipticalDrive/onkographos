# Spatial Hashing


## Overview
Spatial Hashing maps 3D world positions to hierarchical string-based spatial hashes and vice versa, enabling efficient traversal of a voxel hierarchy without storing explicit grid structures [S1, unofficial]. It differs from flat spatial hashing by using a fixed-depth 12-level octal encoding where each character represents a 2×2×2 voxel block, allowing direct conversion between coordinates and region boundaries [S1, unofficial].

## How it works
**Inputs:** A 3D position (Vector3 with X, Y, Z coordinates) or a spatial hash string (1–12 octal digits) [S1, unofficial].
**Outputs:** A spatial hash string (for position input) or 3D coordinates/region bounds (for hash input) [S1, unofficial].

**Data Structures:**
*   `bits` (number): Base bit shift for voxel size calculation. Default: 2 [S1, unofficial].
*   `minSize` (number): $2^{\text{bits}}$ [S1, unofficial].
*   `totalVoxelsX/Y/Z` (number): $2^{10 + \text{bits}}$ [S1, unofficial].
*   `offsetVoxelsX/Y/Z` (number): $\text{totalVoxels} \gg 1$ (arithmetic right shift by 1) [S1, unofficial].
*   `hashAreaSizes` (table): Array of 12 `Vector3` objects. Index $k$ (1–12) stores `Vector3(BinaryValues[k] × minSize, ...)` [S1, unofficial].
*   `BinaryValues` (table): `{2048, 1024, 512, 256, 128, 64, 32, 16, 8, 4, 2, 1}`. Powers of 2 for bit testing, indexed 1–12 corresponding to bit positions 11 down to 0 [S1, unofficial].
*   `OctalToBits` (table): Maps characters '0'–'7' to 3-element arrays. The source code treats the array as `[y_bit, x_bit, z_bit]` despite documentation suggesting `[x, y, z]` [S1, unofficial].
    *   '0': `{0,0,0}`, '1': `{0,0,1}`, '2': `{0,1,0}`, '3': `{0,1,1}`
    *   '4': `{1,0,0}`, '5': `{1,0,1}`, '6': `{1,1,0}`, '7': `{1,1,1}` [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:**
    *   Set `self.bits` to input `bits` or `DEFAULT_BIT_SHIFT` (2) [S1, unofficial].
    *   Calculate `self.minSize = 2 ** self.bits` [S1, unofficial].
    *   Calculate `self.totalVoxelsX = self.totalVoxelsY = self.totalVoxelsZ = 2 ** (10 + self.bits)` [S1, unofficial].
    *   Calculate `self.offsetVoxelsX = self.offsetVoxelsY = self.offsetVoxelsZ = self.totalVoxelsX >> 1` [S1, unofficial].
    *   Initialize `self.hashAreaSizes` as empty table. Loop $k$ from 1 to 12:
        *   $v = \text{BinaryValues}[k] \times \text{self.minSize}$
        *   Insert `Vector3(v, v, v)` into `self.hashAreaSizes` [S1, unofficial].

2.  **Position to Space (`PositionToSpace`):**
    *   Input: `position` (Vector3) [S1, unofficial].
    *   Calculate shifted coordinates:
        *   $px = (position.X + \text{self.offsetVoxelsX}) \gg \text{self.bits}$
        *   $py = (position.Y + \text{self.offsetVoxelsY}) \gg \text{self.bits}$
        *   $pz = (position.Z + \text{self.offsetVoxelsZ}) \gg \text{self.bits}$ [S1, unofficial].
    *   Initialize `key` array of 12 empty strings [S1, unofficial].
    *   Loop $i$ from 12 down to 1:
        *   $v = \text{BinaryValues}[i]$ [S1, unofficial].
        *   Determine octal digit $c$ by testing bits of $py, px, pz$ at position $v$:
            *   If $py \& v$:
                *   If $px \& v$:
                    *   If $pz \& v$: $c = '7'$
                    *   Else: $c = '6'$
                *   Else:
                    *   If $pz \& v$: $c = '5'$
                    *   Else: $c = '4'$
            *   Else:
                *   If $px \& v$:
                    *   If $pz \& v$: $c = '3'$
                    *   Else: $c = '2'$
                *   Else:
                    *   If $pz \& v$: $c = '1'$
                    *   Else: $c = '0'$ [S1, unofficial].
        *   Store $c$ in `key[i]` [S1, unofficial].
    *   Concatenate `key[1..12]` into string $s$ [S1, unofficial].
    *   Return $s$ [S1, unofficial].

3.  **Space to Coordinates (`SpaceToCoordinates`):**
    *   Input: `space` (string) [S1, unofficial].
    *   Initialize $x=0, y=0, z=0$ [S1, unofficial].
    *   Loop $i$ from 1 to length of `space`:
        *   $ch = \text{space}[i]$ [S1, unofficial].
        *   $v = \text{BinaryValues}[i]$ [S1, unofficial].
        *   $bits = \text{OctalToBits}[ch]$ [S1, unofficial].
        *   If $bits[1] == 1$: $y = y \mid v$ [S1, unofficial].
        *   If $bits[2] == 1$: $x = x \mid v$ [S1, unofficial].
        *   If $bits[3] == 1$: $z = z \mid v$ [S1, unofficial].
    *   Shift and offset:
        *   $x = (x \ll \text{self.bits}) - \text{self.offsetVoxelsX}$
        *   $y = (y \ll \text{self.bits}) - \text{self.offsetVoxelsY}$
        *   $z = (z \ll \text{self.bits}) - \text{self.offsetVoxelsZ}$ [S1, unofficial].
    *   Return $x, y, z$ [S1, unofficial].

4.  **Space to Region (`SpaceToRegion3`):**
    *   Input: `space` (string) [S1, unofficial].
    *   Check length $n$. If $n < 1$ or $n > 12$, return `nil` [S1, unofficial].
    *   Parse $x, y, z$ from `space` using the same logic as `SpaceToCoordinates` [S1, unofficial].
    *   Get `size = self.hashAreaSizes[n]` [S1, unofficial].
    *   Calculate lower bound:
        *   $x_1 = (x \ll \text{self.bits}) - \text{self.offsetVoxelsX}$
        *   $y_1 = (y \ll \text{self.bits}) - \text{self.offsetVoxelsY}$
        *   $z_1 = (z \ll \text{self.bits}) - \text{self.offsetVoxelsZ}$ [S1, unofficial].
    *   Create `lower = Vector3(x1, y1, z1)` [S1, unofficial].
    *   Create `upper = lower + size` [S1, unofficial].
    *   Return `Region3(lower, upper)` [S1, unofficial].

5.  **Get Child Spaces (`GetChildSpaces`):**
    *   Input: `space` (string) [S1, unofficial].
    *   Initialize `results` table [S1, unofficial].
    *   $n = \text{length}(\text{space})$ [S1, unofficial].
    *   If $n < 12$:
        *   For each pair `(ch, bits)` in `OctalToBits`:
            *   Append `space .. ch` to `results` [S1, unofficial].
    *   Return `results` [S1, unofficial].

6.  **Get Parent Spaces (`GetParentSpaces`):**
    *   Input: `space` (string), `levels` (number, optional, default 1) [S1, unofficial].
    *   Initialize `results` table [S1, unofficial].
    *   $m = 12 - \min(11, \text{levels})$ [S1, unofficial].
    *   $n = \text{length}(\text{space})$ [S1, unofficial].
    *   If $n > 0$ and $m \le 12$:
        *   Loop $i$ from $n-1$ down to $m$:
            *   $p = \text{space}[1..i]$ [S1, unofficial].
            *   Append $p$ to `results` [S1, unofficial].
    *   Return `results` [S1, unofficial].

**Pseudocode:**

```python
import math

# Constants
DEFAULT_BIT_SHIFT = 2
BinaryValues = [2048, 1024, 512, 256, 128, 64, 32, 16, 8, 4, 2, 1]
OctalToBits = {
    '0': [0, 0, 0], '1': [0, 0, 1], '2': [0, 1, 0], '3': [0, 1, 1],
    '4': [1, 0, 0], '5': [1, 0, 1], '6': [1, 1, 0], '7': [1, 1, 1]
}

class SpatialHashing:
    def __init__(self, bits=None):
        self.bits = bits if bits is not None else DEFAULT_BIT_SHIFT
        self.minSize = 2 ** self.bits
        
        total_voxels = 2 ** (10 + self.bits)
        self.offsetVoxels = total_voxels >> 1
        
        self.hashAreaSizes = []
        for k in range(12):
            v = BinaryValues[k] * self.minSize
            self.hashAreaSizes.append((v, v, v))

    def position_to_space(self, position):
        px = (position[0] + self.offsetVoxels) >> self.bits
        py = (position[1] + self.offsetVoxels) >> self.bits
        pz = (position[2] + self.offsetVoxels) >> self.bits
        
        key = [''] * 12
        
        for i in range(11, -1, -1):
            v = BinaryValues[i]
            py_bit = (py & v) != 0
            px_bit = (px & v) != 0
            pz_bit = (pz & v) != 0
            
            if py_bit:
                if px_bit:
                    c = '7' if pz_bit else '6'
                else:
                    c = '5' if pz_bit else '4'
            else:
                if px_bit:
                    c = '3' if pz_bit else '2'
                else:
                    c = '1' if pz_bit else '0'
            key[i] = c
            
        return ''.join(key)

    def space_to_coordinates(self, space):
        x = 0
        y = 0
        z = 0
        
        for i in range(len(space)):
            ch = space[i]
            v = BinaryValues[i]
            bits = OctalToBits[ch]
            
            if bits[0] == 1:
                y |= v
            if bits[1] == 1:
                x |= v
            if bits[2] == 1:
                z |= v
                
        x = (x << self.bits) - self.offsetVoxels
        y = (y << self.bits) - self.offsetVoxels
        z = (z << self.bits) - self.offsetVoxels
        
        return (x, y, z)

    def space_to_region(self, space):
        n = len(space)
        if n < 1 or n > 12:
            return None
            
        x, y, z = self.space_to_coordinates(space)
        size = self.hashAreaSizes[n - 1]
        
        lower = (x, y, z)
        upper = (x + size[0], y + size[1], z + size[2])
        
        return (lower, upper)

    def get_child_spaces(self, space):
        results = []
        n = len(space)
        if n < 12:
            for ch in OctalToBits:
                results.append(space + ch)
        return results

    def get_parent_spaces(self, space, levels=None):
        results = []
        if levels is None:
            levels = 1
        m = 12 - min(11, levels)
        n = len(space)
        
        if n > 0 and m <= 12:
            for i in range(n - 1, m - 1, -1):
                p = space[:i]
                results.append(p)
        return results
```

**Parameters:**
*   `bits`: Base bit shift. Default 2 [S1, unofficial].
*   `levels`: Number of parent levels to retrieve. Default 1 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   `SpaceToRegion3` returns `nil` if input string length is not between 1 and 12 inclusive [S1, unofficial].
*   `GetChildSpaces` returns an empty table if the input space string length is 12 (maximum depth) [S1, unofficial].
*   `GetParentSpaces` uses `math.min(11, levels)` to ensure the minimum index $m$ is at least 1 (since $12-11=1$), preventing invalid substring indices [S1, unofficial].
*   Precision: Uses integer arithmetic (bitwise operations) to avoid floating-point errors during coordinate mapping [S1, unofficial].

## Operating characteristics
**Time Complexity:**
*   `PositionToSpace`: $O(1)$ (fixed 12 iterations) [S1, unofficial].
*   `SpaceToCoordinates`: $O(L)$ where $L$ is string length (max 12) [S1, unofficial].
*   `GetChildSpaces`: $O(1)$ (max 8 children) [S1, unofficial].
*   `GetParentSpaces`: $O(L)$ [S1, unofficial].

**Memory Complexity:**
*   Object initialization: $O(1)$ (fixed size arrays) [S1, unofficial].
*   Hash strings: $O(L)$ where $L \le 12$ [S1, unofficial].

**Performance:**
*   The method is optimized for Lua environments using bitwise operations (`bit32`) [S1, unofficial].
*   Fixed depth of 12 levels allows for predictable memory usage and fast lookups without dynamic tree traversal [S1, unofficial].

**Strengths:**
*   Direct conversion between coordinates and hierarchical keys [S1, unofficial].
*   No need for explicit grid storage; keys are self-describing [S1, unofficial].
*   Efficient parent/child traversal [S1, unofficial].

**Limitations:**
*   Fixed maximum depth of 12 levels [S1, unofficial].
*   Coordinate range is limited by `totalVoxels` ($2^{10+bits}$) [S1, unofficial].

## Background
Spatial Hashing was developed by Scott Beaudreau as a Lua library for Roblox, mapping 3D world positions to hierarchical spatial hashes [S1, unofficial]. It supports conversion to Region3 and parent/child space traversal, designed for efficient spatial queries in game environments [S1, unofficial]. The library is licensed under MIT [S1, unofficial].
