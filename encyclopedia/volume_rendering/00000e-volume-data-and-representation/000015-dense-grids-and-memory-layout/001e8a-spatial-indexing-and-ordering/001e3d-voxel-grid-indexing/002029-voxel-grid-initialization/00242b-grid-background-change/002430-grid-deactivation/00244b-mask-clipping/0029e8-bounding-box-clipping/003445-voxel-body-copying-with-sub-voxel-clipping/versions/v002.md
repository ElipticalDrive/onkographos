# Voxel Body Copying with Sub-Voxel Clipping

Also called: Clipped Block Copying, VoxelBody.Cropped

## Overview
Voxel Body Copying with Sub-Voxel Clipping extracts a subset of a voxel grid by retaining only the active solid blocks that intersect a specified world-space bounding box, while preserving the internal structure of those blocks [S1, unofficial]. Unlike [Grid Clone](7232-grid-clone.md), which duplicates the entire grid, this method creates a new `VoxelBody` containing only the relevant data [S1, unofficial]. It differs from [Bounding Box Clipping](4643-bounding-box-clipping.md) in that it operates on discrete solid blocks rather than individual voxels, clipping blocks that partially overlap the boundary to maintain structural integrity [S1, unofficial].

## How it works
**Inputs:**
- Source `VoxelBody` containing solid blocks [S1, unofficial].
- World-space bounding box defined by minimum and maximum integer coordinates $(min_x, min_y, min_z)$ and $(max_x, max_y, max_z)$ [G].

**Outputs:**
- A new `VoxelBody` containing only the clipped solid blocks, or `null` if no solid blocks remain [S1, unofficial].

**Data Structures:**
- `VoxelBody`: Container for a list of `Voxel` objects [S1, unofficial].
- `Voxel`: Represents a solid block of voxels, containing a field (e.g., a 3D array or sparse representation) defining the material or opacity within the block [S1, unofficial].
- `kept`: A list of `Voxel` objects to be included in the output [S1, unofficial].

**Algorithm:**
1. **Calculate Range:** Determine the integer bounding box of the source volume's solid content using a range query (e.g., `TryGetRange`) [S1, unofficial]. If the volume has no solid range, return `null` [S1, unofficial].
2. **Iterate and Clip:** Iterate over all solid blocks in the source volume using `ForEachSolidIn` [S1, unofficial]. For each block:
   - Check if the block is fully inside the target bounding box [G].
   - If not fully inside, call a clipping function `ClipBlock` with the parameter `keepInside: true` [S1, unofficial].
   - If the resulting clipped field is empty, skip the block [S1, unofficial].
   - If the resulting clipped field is full (identical to the original block), set the field to `null` to optimize storage [S1, unofficial].
   - Otherwise, create a new `VoxelBody.Voxel` with the clipped field and add it to the `kept` list [S1, unofficial].
3. **Construct Result:** If the `kept` list is empty, return `null` [S1, unofficial]. Otherwise, create a new `VoxelBody` using the constructor `VoxelBody.Cropped`, passing the original name and the `kept` list [S1, unofficial].

**Pseudocode:**
```python
def VoxelBody_CopyWithSubVoxelClipping(source_body, bbox_min, bbox_max):
    if not source_body.TryGetRange():
        return None
    kept = []
    for block in source_body.ForEachSolidIn():
        if not block.is_fully_inside(bbox_min, bbox_max):
            clipped_field = ClipBlock(block.field, bbox_min, bbox_max, keepInside=True)
            if clipped_field is None or clipped_field.is_empty():
                continue
            if clipped_field.is_full():
                voxel = VoxelBody.Voxel(name=block.name, field=None)
            else:
                voxel = VoxelBody.Voxel(name=block.name, field=clipped_field)
            kept.append(voxel)
    if not kept:
        return None
    return VoxelBody.Cropped(name=source_body.name, voxels=kept)
```

**Parameters:**
- `keepInside`: Boolean. When `true`, retains the part of the block inside the bounding box [S1, unofficial]. When `false`, retains the part outside (used in Carving) [S1, unofficial].

**Edge Cases:**
- **No Solid Range:** If the source volume is empty, the method returns `null` immediately [S1, unofficial].
- **Empty Clipped Field:** If a block is completely outside the bounding box, `ClipBlock` returns an empty field, and the block is skipped [S1, unofficial].
- **Full Clipped Field:** If a block is completely inside, the clipped field is "full". The implementation optimizes this by setting the field to `null` [S1, unofficial].

## Subtopics

### Voxel Body Carving with Sub-Voxel Clipping
This variant modifies the source grid in-place by removing the intersection of the volume with the bounding box [S1, unofficial]. It uses `ClipBlock` with `keepInside: false` to get the remaining part of the block outside the box [S1, unofficial]. If the remainder is null or empty, the chunk block is set to Air [S1, unofficial]. Otherwise, the chunk refinement is set to the remainder [S1, unofficial]. It also tracks touched chunks and their Y-range, marking the 3x3 neighborhood in XZ (dx, dz from -1 to 1) as dirty with the tracked Y-range to ensure face culling and ambient occlusion updates [S1, unofficial].
