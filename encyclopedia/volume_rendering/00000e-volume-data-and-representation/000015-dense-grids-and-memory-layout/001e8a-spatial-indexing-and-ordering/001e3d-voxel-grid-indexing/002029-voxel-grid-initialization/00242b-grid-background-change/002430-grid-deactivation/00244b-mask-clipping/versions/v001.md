# Mask Clipping

Also called: clip (mask)

## Overview
Mask Clipping returns a new grid containing only the active voxels of a source grid that correspond to active locations in a separate mask grid [S1, unofficial]. It differs from its parent, Grid Deactivation, which removes voxels based on a specific scalar value, by using a binary spatial inclusion criterion defined by another grid's active set [S1, unofficial].

## How it works
**Inputs:**
1. `source_grid`: The input volume grid containing active voxels.
2. `mask_grid`: A grid defining the spatial region of interest. Only voxels active in this grid are preserved.

**Outputs:**
1. `clipped_grid`: A new grid containing a subset of `source_grid`'s active voxels.

**Data Structures:**
The implementation relies on the sparse grid representation (e.g., NanoVDB or OpenVDB) where active voxels are stored in a leaf node structure. The mask grid must support efficient point-in-grid queries (`is_active`).

**Steps:**
1. Initialize an empty `clipped_grid` with the same metadata (resolution, transform, data type) as `source_grid`.
2. Iterate through every active voxel in `source_grid`. Let the current voxel be at coordinate $c$ with value $v$.
3. Query the `mask_grid` to determine if coordinate $c$ is active.
   - If `is_active(mask_grid, c)` is true, insert the voxel $(c, v)$ into `clipped_grid`.
   - If false, discard the voxel.
4. Return `clipped_grid`.

**Pseudocode:**
```python
def mask_clip(source_grid, mask_grid):
    # Create a new grid with identical structure to source
    clipped_grid = Grid.empty_like(source_grid)
    
    # Iterate over all active voxels in the source
    for voxel in source_grid.active_voxels():
        coord = voxel.coordinate
        value = voxel.value
        
        # Check if the coordinate is active in the mask
        if mask_grid.is_active(coord):
            clipped_grid.insert(coord, value)
            
    return clipped_grid
```

**Edge Cases:**
- If `mask_grid` is empty, the result is an empty grid.
- If `source_grid` is empty, the result is an empty grid.
- Precision issues may arise if coordinates are not aligned exactly due to floating-point transforms; integer coordinate comparison is preferred if possible.

## Subtopics

### Bounding Box Clipping
Returns a new grid containing only active voxels of the source grid that lie within a specified axis-aligned bounding box [S1, unofficial]. It differs from standard Mask Clipping by using a geometric primitive (bounding box) rather than a sparse grid mask for inclusion testing [S1, unofficial]. Choose this when the region of interest is a simple rectangular volume, as it avoids the overhead of loading and querying a separate mask grid. The step involves iterating active voxels and checking if `contains(bbox, c)` is true [S1, unofficial].

## Operating characteristics
**Time Complexity:** $O(N)$, where $N$ is the number of active voxels in the source grid. Each active voxel requires one lookup in the mask grid.
**Memory Complexity:** $O(M)$, where $M$ is the number of active voxels in the source grid that also pass the mask test.
**Performance:** Performance depends heavily on the sparsity of the mask and the efficiency of the `is_active` query in the mask grid. If the mask is dense, this operation is essentially a copy. If the mask is sparse, it acts as a filter.
**Strengths:** Flexible spatial filtering; allows complex non-rectangular regions.
**Limitations:** Requires storing or accessing a second grid; lookup cost per voxel can be significant if the mask grid is large or poorly indexed.

## Background
Mask Clipping is a standard operation in volume data processing pipelines, particularly in scientific visualization and VDB-based workflows. It is used to isolate specific regions of interest within a larger volume dataset. The method is implemented in libraries such as Lyr.jl, where it is part of the scene preparation pipeline for rendering [S1, unofficial].
