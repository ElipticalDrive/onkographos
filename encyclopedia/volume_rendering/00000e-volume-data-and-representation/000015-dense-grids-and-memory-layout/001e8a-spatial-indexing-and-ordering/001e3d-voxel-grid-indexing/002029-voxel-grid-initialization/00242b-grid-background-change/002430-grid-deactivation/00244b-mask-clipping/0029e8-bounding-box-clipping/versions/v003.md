# Bounding Box Clipping
Also called: clip (bbox)
## Overview
Bounding Box Clipping returns a new grid containing only the active voxels of the source grid that lie within a specified world-space bounding box [S1, unofficial]. It differs from [Mask Clipping](3229-mask-clipping.md) by using a geometric primitive (axis-aligned box) rather than a secondary data grid to define the region of interest, and from [Grid Clone](7232-grid-clone.md) by filtering spatial extent rather than duplicating the full logical structure.
## How it works
**Inputs:**
- `source_grid`: The input voxel grid containing active and inactive voxels.
- `bbox`: A world-space axis-aligned bounding box, typically defined by minimum and maximum coordinates $(x_{min}, y_{min}, z_{min})$ and $(x_{max}, y_{max}, z_{max})$.

**Outputs:**
- `clipped_grid`: A new voxel grid containing only the active voxels from `source_grid` whose centers (or relevant sampling points) fall within `bbox`.

**Data Structures:**
- The `source_grid` is assumed to have a layout allowing iteration over active voxels (e.g., a sparse list of active coordinates or a compressed sparse row structure).
- The `clipped_grid` is initialized with a layout compatible with the source, but sized to hold only the filtered subset.

**Steps:**
1. Initialize an empty container `data` for the new grid.
2. Iterate through each active voxel $v$ in `source_grid`.
3. For each active voxel, determine its world-space coordinate $c$.
4. Check if $c$ is contained within `bbox`. The containment test is:
   $$x_{min} \le c_x \le x_{max} \land y_{min} \le c_y \le y_{max} \land z_{min} \le c_z \le z_{max}$$
5. If the condition is true, add the voxel's data (value, coordinate, etc.) to `data`.
6. Construct `clipped_grid` from `data`.

**Pseudocode:**
```python
def bounding_box_clip(source_grid, bbox):
    """
    Returns a new grid containing only active voxels of source_grid 
    that lie within the specified world-space bounding box.
    
    Args:
        source_grid: Object with method active_voxels() returning list of active voxel objects.
                     Each voxel object has attributes .coord (world space vector) and .value.
        bbox: Tuple (x_min, y_min, z_min, x_max, y_max, z_max) defining the world-space box.
    
    Returns:
        A new grid-like object containing the filtered voxels.
    """
    x_min, y_min, z_min, x_max, y_max, z_max = bbox
    clipped_data = []
    
    # Iterate over all active voxels in the source grid
    for voxel in source_grid.active_voxels():
        c = voxel.coord
        
        # Check if the voxel's coordinate is within the bounding box
        if (x_min <= c.x <= x_max and
            y_min <= c.y <= y_max and
            z_min <= c.z <= z_max):
            clipped_data.append(voxel)
            
    # Construct and return the new grid
    return Grid(clipped_data)
```

**Edge Cases and Pitfalls:**
- **Empty Result:** If no active voxels fall within the box, the result is an empty grid.
- **Boundary Precision:** Floating-point comparisons for boundary inclusion ($\le$) must be consistent with how voxel coordinates are defined (center vs. corner). [G] Typically, voxel coordinates represent the center; ensure the bbox is defined in the same coordinate space.
- **Coordinate Space:** The `bbox` must be in world space, matching the `source_grid`'s coordinate system. Mismatched scales or origins will clip incorrect voxels.

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of active voxels in the source grid, as each active voxel must be checked against the bounding box.
- **Memory Complexity:** $O(K)$, where $K$ is the number of active voxels within the bounding box.
- **Performance:** Performance depends on the efficiency of iterating active voxels. For sparse grids, this is efficient as inactive voxels are skipped. For dense grids, it may be slower than direct memory access if the box covers most of the grid.
- **Strengths:** Simple to implement; efficient for sparse data; flexible box definition.
- **Limitations:** Does not handle sub-voxel precision or block structures natively; requires coordinate transformation if the grid is not in world space.
- **When to use:** When a rectangular region of interest is defined in world space and voxel-level filtering is sufficient.
- **When not to use:** When block-level integrity is needed (use [Voxel Body Copying](7181-voxel-body-copying-with-sub-voxel-clipping.md)) or when no filtering is needed (use [Grid Clone](7232-grid-clone.md)).

## Background
Bounding Box Clipping is a fundamental operation in volume data processing, often used for preprocessing or region-of-interest extraction. It is implemented in various graphics and scientific computing libraries. The specific implementation described here is derived from the `Lyr.jl` library's scene building utilities, where it is used to frame camera orbits and render scenes within specific spatial extents [S1, unofficial].
