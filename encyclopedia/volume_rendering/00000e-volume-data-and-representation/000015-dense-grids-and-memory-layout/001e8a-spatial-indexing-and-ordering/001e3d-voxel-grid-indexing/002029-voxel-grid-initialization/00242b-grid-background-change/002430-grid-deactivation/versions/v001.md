# Grid Deactivation

Also called: deactivate

## Overview
Grid Deactivation removes specific voxels from the active set of a volume grid based on their scalar value. It solves the problem of isolating or removing background noise by filtering out voxels that match a target `value`. Unlike its parent, [Grid Background Change](3210-grid-background-change.md), which updates inactive voxels to a new background value while preserving active ones, Grid Deactivation explicitly removes active voxels matching the criterion from the active set [S1, unofficial].

## How it works
**Inputs:**
- `grid`: The source volume grid containing active voxels.
- `value`: The scalar value identifying voxels to deactivate.

**Outputs:**
- `new_grid`: A new grid object where voxels with `value` are removed from the active set.

**Data Structures:**
- The grid maintains an active voxel list or sparse data structure. The exact internal layout (e.g., linearized indices, coordinate arrays) is implementation-specific but must support iteration over active elements only.

**Steps:**
1. Initialize an empty collection `data` to store the active voxels of the new grid.
2. Iterate through all voxels currently marked as active in `grid`.
3. For each active voxel `v`:
   - If `v.value != value`, append `v` to `data`.
   - If `v.value == value`, skip `v` (deactivate it).
4. Construct `new_grid` using the filtered `data` and the original grid's background configuration.

**Pseudocode:**
```python
def grid_deactivation(grid, value):
    # Step 1: Initialize empty data structure for new active voxels
    new_active_voxels = []

    # Step 2: Iterate all active voxels in the source grid
    for voxel in grid.active_voxels():
        # Step 3: Check if voxel value matches the target value
        if voxel.value != value:
            # Step 3a: Keep the voxel if it does not match
            new_active_voxels.append(voxel)
        # If voxel.value == value, it is excluded (deactivated)

    # Step 4: Build the new grid with filtered data and original background
    # Note: build_grid is a helper that reconstructs the grid structure
    new_grid = build_grid(new_active_voxels, grid.tree.background)

    return new_grid
```

**Parameters:**
- `value`: The scalar threshold for deactivation. Typical values depend on the volume data (e.g., 0.0 for background removal). Not given in the sources.

**Edge Cases:**
- If all active voxels match `value`, the resulting grid has an empty active set.
- Precision issues may arise if `value` is a floating-point number and voxel values are computed; exact equality checks might fail due to rounding. [G]

## Subtopics

### [Mask Clipping](3229-mask-clipping.md)
Mask Clipping returns a new grid containing only the active voxels of a source grid that correspond to active locations in a separate mask grid. It differs from its parent, Grid Deactivation, which removes voxels based on a specific scalar value, by using a binary spatial inclusion criterion defined by another grid's active set.

## Operating characteristics
**Time Complexity:** Linear with respect to the number of active voxels in the source grid, $O(N_{active})$, as each active voxel is visited once.
**Memory Complexity:** Linear with respect to the number of kept active voxels, $O(N_{kept})$, for storing the new grid's active data.
**Performance:** Performance depends on the efficiency of iterating active voxels and the sparsity of the grid. In the Lyr.jl implementation, benchmarks show efficient GPU rendering after grid construction, but specific deactivation timings are not provided in the sources.
**Strengths:** Simple logic, effective for removing uniform background noise or specific material layers.
**Limitations:** Requires iterating all active voxels; does not support spatial locality optimizations like bounding volume hierarchies during the filter step.

## Background
Grid Deactivation is a primitive operation in sparse volume grid manipulation, implemented in the Lyr.jl library by Tobias Osborne [S1, unofficial]. It is part of the grid transformation pipeline, following [Grid Background Change](3210-grid-background-change.md), to refine volume data before rendering.
