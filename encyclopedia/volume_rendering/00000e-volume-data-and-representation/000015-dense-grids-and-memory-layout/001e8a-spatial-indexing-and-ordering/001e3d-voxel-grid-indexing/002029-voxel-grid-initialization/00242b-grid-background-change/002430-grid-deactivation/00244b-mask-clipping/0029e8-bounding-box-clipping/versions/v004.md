# Bounding Box Clipping
Also called: clip (bbox)
## Overview
Bounding Box Clipping returns a new grid containing only the active voxels of the source grid that lie within a specified world-space bounding box [S1, unofficial]. It differs from [Mask Clipping](3229-mask-clipping.md) by using a geometric primitive (axis-aligned box) rather than a secondary data grid to define the region of interest, and from [Grid Clone](7232-grid-clone.md) by filtering spatial extent rather than duplicating the full logical structure [G].
## How it works
**Inputs:**
- `source_grid`: A voxel grid with a layout supporting iteration over active voxels (e.g., a sparse list of active coordinates) [G].
- `bbox`: A world-space axis-aligned bounding box defined by minimum and maximum coordinates $(x_{min}, y_{min}, z_{min})$ and $(x_{max}, y_{max}, z_{max})$ [G].

**Outputs:**
- `clipped_grid`: A new voxel grid containing only the active voxels from `source_grid` that lie within `bbox` [S1, unofficial].

**Data Structures:**
- `source_grid` stores active voxels with world-space coordinates and associated data values [G].
- `clipped_grid` uses a layout compatible with the source, sized to hold only the filtered subset [G].

**Steps:**
1. Initialize an empty container `data` for the new grid [S1, G, unofficial].
2. Iterate through each active voxel $v$ in `source_grid` [S1, G, unofficial].
3. For each active voxel, determine its world-space coordinate $c$ [S1, G, unofficial].
4. Check if $c$ is contained within `bbox` using the test: $x_{min} \le c_x \le x_{max} \land y_{min} \le c_y \le y_{max} \land z_{min} \le c_z \le z_{max}$ [S1, G, unofficial].
5. If the condition is true, add the voxel's data to `data` [S1, G, unofficial].
6. Construct `clipped_grid` from `data` [S1, G, unofficial].

**Pseudocode:**
```python
class Voxel:
    def __init__(self, coord, value):
        self.coord = coord  # (x, y, z) tuple
        self.value = value

class Grid:
    def __init__(self, voxels):
        self.voxels = voxels

    def active_voxels(self):
        return self.voxels

def bounding_box_clip(source_grid, bbox):
    x_min, y_min, z_min, x_max, y_max, z_max = bbox
    clipped_data = []
    for voxel in source_grid.active_voxels():
        c = voxel.coord
        if (x_min <= c[0] <= x_max and
            y_min <= c[1] <= y_max and
            z_min <= c[2] <= z_max):
            clipped_data.append(voxel)
    return Grid(clipped_data)
```

**Edge Cases and Pitfalls:**
- **Empty Result:** If no active voxels fall within the box, the result is an empty grid [G].
- **Coordinate Space:** The `bbox` must be in world space, matching the `source_grid`'s coordinate system. Mismatched scales or origins will clip incorrect voxels [G].
- **Boundary Precision:** Floating-point comparisons for boundary inclusion ($\le$) must be consistent with how voxel coordinates are defined (center vs. corner) [G].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of active voxels in the source grid, as each active voxel must be checked against the bounding box [G].
- **Memory Complexity:** $O(K)$, where $K$ is the number of active voxels within the bounding box [G].
- **Performance:** Performance depends on the efficiency of iterating active voxels. For sparse grids, this is efficient as inactive voxels are skipped. For dense grids, it may be slower than direct memory access if the box covers most of the grid [G].
- **Strengths:** Simple to implement; efficient for sparse data; flexible box definition [G].
- **Limitations:** Does not handle sub-voxel precision or block structures natively; requires coordinate transformation if the grid is not in world space [G].
- **When to use:** When a rectangular region of interest is defined in world space and voxel-level filtering is sufficient [G].
- **When not to use:** When block-level integrity is needed (use [Voxel Body Copying](7181-voxel-body-copying-with-sub-voxel-clipping.md)) or when no filtering is needed (use [Grid Clone](7232-grid-clone.md)) [G].

## Background
The method is used in the `Lyr.jl` library's scene building utilities to frame camera orbits and render scenes within specific spatial extents [S1, unofficial].
