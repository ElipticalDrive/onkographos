# Coordinate Conversion Utilities

Also called: FVoxelCoordinates, LocalToVoxel, Voxel Chunk Coordinate Conversion, VoxelToLocal

## Overview
Coordinate Conversion Utilities provide the arithmetic mapping between world-space positions, global voxel indices, chunk indices, and local voxel positions within a chunk. They solve the problem of addressing data in a sparse or dense voxel grid that is partitioned into fixed-size chunks, ensuring that coordinates wrap correctly across chunk boundaries and negative indices are handled consistently. Unlike [Spherical Voxel Grid Setup](3883-spherical-voxel-grid-setup.md), which handles angular discretization, these utilities operate on Cartesian grid topology.

## How it works
The method relies on integer arithmetic to map between continuous world coordinates and discrete grid indices. It assumes a uniform voxel size and a fixed chunk size. The core operations are `LocalToVoxel` (local to global) and `VoxelToLocal` (global to local), supported by world-space conversions.

### Inputs and Outputs
- **Inputs**:
  - `WorldPos`: 3D vector in world units.
  - `VoxelCoord`: Global integer voxel index $(X, Y, Z)$.
  - `ChunkCoord`: Integer chunk index $(C_X, C_Y, C_Z)$.
  - `LocalPos`: Local integer voxel index within a chunk $(L_X, L_Y, L_Z)$.
  - `VoxelSize`: Float scalar representing the side length of one voxel.
  - `ChunkSize`: Integer scalar representing the number of voxels along one axis in a chunk.
- **Outputs**:
  - Mapped coordinates in the target space (World, Global Voxel, Chunk, or Local Voxel).

### Data Structures
The implementation typically uses a 3D integer vector type (e.g., `FIntVector` or `int3`), defined as three integer fields:
- `X`: Integer horizontal coordinate.
- `Y`: Integer vertical coordinate.
- `Z`: Integer depth coordinate.

### Formulas and Steps

#### 1. World to Global Voxel
Converts a world position to a global voxel index. Uses floor division to ensure consistent behavior for negative coordinates.
$$
VoxelCoord = \lfloor \frac{WorldPos}{VoxelSize} \rfloor
$$
In integer arithmetic, this is implemented as:
$$
VoxelCoord.X = \lfloor WorldPos.X / VoxelSize \rfloor
$$
$$
VoxelCoord.Y = \lfloor WorldPos.Y / VoxelSize \rfloor
$$
$$
VoxelCoord.Z = \lfloor WorldPos.Z / VoxelSize \rfloor
$$
[G] In C++, integer division truncates toward zero. To achieve floor behavior for negative numbers, if the numerator and denominator signs differ, subtract 1 from the result.

#### 2. Global Voxel to Chunk Coordinate
Determines which chunk contains a given global voxel.
$$
ChunkCoord = \lfloor \frac{VoxelCoord}{ChunkSize} \rfloor
$$

#### 3. Global Voxel to Local Voxel (VoxelToLocal)
Calculates the position of a global voxel relative to the origin of its containing chunk. This requires handling negative modulo results correctly.
1. Calculate raw modulo:
   $$
   Local.X = VoxelCoord.X \pmod{ChunkSize}
   $$
   $$
   Local.Y = VoxelCoord.Y \pmod{ChunkSize}
   $$
   $$
   Local.Z = VoxelCoord.Z \pmod{ChunkSize}
   $$
2. Adjust for negative results:
   If $Local.X < 0$, then $Local.X = Local.X + ChunkSize$.
   If $Local.Y < 0$, then $Local.Y = Local.Y + ChunkSize$.
   If $Local.Z < 0$, then $Local.Z = Local.Z + ChunkSize$.

#### 4. Local Voxel to Global Voxel (LocalToVoxel)
Reconstructs the global voxel index from the chunk coordinate and local position.
$$
VoxelCoord.X = ChunkCoord.X \times ChunkSize + LocalPos.X
$$
$$
VoxelCoord.Y = ChunkCoord.Y \times ChunkSize + LocalPos.Y
$$
$$
VoxelCoord.Z = ChunkCoord.Z \times ChunkSize + LocalPos.Z
$$

#### 5. Chunk to World Origin
Calculates the world-space position of the minimum corner (origin) of a chunk.
$$
WorldOrigin = ChunkCoord \times ChunkSize \times VoxelSize
$$

#### 6. Chunk to World Center
Calculates the world-space center of a chunk.
$$
WorldCenter = WorldOrigin + \frac{ChunkSize \times VoxelSize}{2}
$$

#### 7. Local Voxel to World Position
Calculates the world-space center of a specific voxel given its local position within a chunk.
$$
WorldPos = (ChunkCoord \times ChunkSize + LocalPos) \times VoxelSize + \frac{VoxelSize}{2}
$$

### Pseudocode

```python
def world_to_voxel(world_pos: Vector3f, voxel_size: float) -> Vector3i:
    """Convert world position to global voxel coordinates."""
    # Floor division for integers
    x = floor(world_pos.x / voxel_size)
    y = floor(world_pos.y / voxel_size)
    z = floor(world_pos.z / voxel_size)
    return Vector3i(x, y, z)

def voxel_to_chunk(voxel_coord: Vector3i, chunk_size: int) -> Vector3i:
    """Convert global voxel coordinate to chunk coordinate."""
    x = floor(voxel_coord.x / chunk_size)
    y = floor(voxel_coord.y / chunk_size)
    z = floor(voxel_coord.z / chunk_size)
    return Vector3i(x, y, z)

def voxel_to_local(voxel_coord: Vector3i, chunk_size: int) -> Vector3i:
    """Convert global voxel coordinate to local coordinate within a chunk."""
    x = voxel_coord.x % chunk_size
    y = voxel_coord.y % chunk_size
    z = voxel_coord.z % chunk_size
    
    if x < 0:
        x += chunk_size
    if y < 0:
        y += chunk_size
    if z < 0:
        z += chunk_size
        
    return Vector3i(x, y, z)

def local_to_voxel(chunk_coord: Vector3i, local_pos: Vector3i, chunk_size: int) -> Vector3i:
    """Convert local voxel position to global voxel coordinate."""
    x = chunk_coord.x * chunk_size + local_pos.x
    y = chunk_coord.y * chunk_size + local_pos.y
    z = chunk_coord.z * chunk_size + local_pos.z
    return Vector3i(x, y, z)

def chunk_to_world_origin(chunk_coord: Vector3i, chunk_size: int, voxel_size: float) -> Vector3f:
    """Convert chunk coordinate to world-space origin (minimum corner)."""
    scale = chunk_size * voxel_size
    return Vector3f(
        chunk_coord.x * scale,
        chunk_coord.y * scale,
        chunk_coord.z * scale
    )

def chunk_to_world_center(chunk_coord: Vector3i, chunk_size: int, voxel_size: float) -> Vector3f:
    """Convert chunk coordinate to world-space center."""
    origin = chunk_to_world_origin(chunk_coord, chunk_size, voxel_size)
    half_size = (chunk_size * voxel_size) / 2.0
    return origin + Vector3f(half_size, half_size, half_size)

def local_voxel_to_world(chunk_coord: Vector3i, local_pos: Vector3i, chunk_size: int, voxel_size: float) -> Vector3f:
    """Convert local voxel position to world position (voxel center)."""
    # First get global voxel
    global_voxel = local_to_voxel(chunk_coord, local_pos, chunk_size)
    # Convert global voxel to world center
    origin = world_to_voxel(Vector3f(0,0,0), voxel_size) # Not needed, use direct formula
    # Direct formula: (Chunk * ChunkSize + Local) * VoxelSize + VoxelSize/2
    scale = voxel_size
    half_voxel = voxel_size / 2.0
    return Vector3f(
        (chunk_coord.x * chunk_size + local_pos.x) * scale + half_voxel,
        (chunk_coord.y * chunk_size + local_pos.y) * scale + half_voxel,
        (chunk_coord.z * chunk_size + local_pos.z) * scale + half_voxel
    )
```

### Parameters and Edge Cases
- **ChunkSize**: Typically a power of two (e.g., 16, 32, 64) to allow bitwise optimization for modulo and division, though the algorithm works for any integer $>0$.
- **VoxelSize**: Positive float.
- **Negative Coordinates**: The `VoxelToLocal` step explicitly handles negative global voxel indices by adding `ChunkSize` to the modulo result. This ensures local coordinates are always in the range $[0, ChunkSize-1]$.
- **Precision**: Floating-point division in `WorldToVoxel` should use standard IEEE 754 rounding. The floor operation is critical for consistent coordinate mapping across the world origin.

## Operating characteristics
- **Time Complexity**: $O(1)$ for all conversion functions. They involve a constant number of arithmetic operations (addition, multiplication, division, modulo).
- **Memory Complexity**: $O(1)$. No additional data structures are required beyond the input coordinates and constants.
- **Strengths**: Extremely fast, suitable for per-voxel operations in shaders or tight loops. Handles negative coordinates robustly.
- **Limitations**: Assumes uniform voxel size and axis-aligned chunks. Does not handle non-uniform scaling or rotated grids.

## Background
These utilities are standard components in voxel-based game engines and terrain generation systems, particularly those using chunked data structures for memory efficiency. They are found in implementations like Unreal Engine's Voxel Plugin and open-source voxel world generators. The specific handling of negative modulo is a common pitfall in C++ and similar languages, necessitating the explicit adjustment step.
