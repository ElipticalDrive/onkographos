# Balanced Spherical Grid

Also called: EgoNeRF grid, Yin and Yang grid

## Overview
The Balanced Spherical Grid is a dense spatial indexing structure for representing radiance fields in egocentric view synthesis, designed to handle the anisotropic resolution requirements of panoramic imagery [S1]. It partitions the 3D space using two complementary spherical grids (Yin and Yang) with exponential radial scaling to maintain uniform cell aspect ratios, allowing efficient hierarchical sampling without dedicated coarse-grid memory allocation [S1].

## How it works
**Inputs:** Camera poses, egocentric images, scene bounding radius $R_{\max}$, grid resolutions $N_r^y, N_\theta^y, N_\phi^y$ for $y \in \{\text{Yin, Yang}\}$, initial shell radius $r_0$, exponential growth constant $k$, and appearance feature dimension $C$.
**Outputs:** Density grid $G_\sigma$ and appearance grid $G_a$ for both Yin and Yang components.

**Data Structures:**
The method maintains two sets of grids, one for Yin and one for Yang. Each set consists of:
1.  **Density Grid ($G_\sigma$):** A 3D tensor of shape $\mathbb{R}^{2N_r^y \times N_\theta^y \times N_\phi^y}$. It stores a single channel of explicit volume density values. The factor $2$ accounts for the two radial partitions per logical radial bin (see Layout).
2.  **Appearance Grid ($G_a$):** A 4D tensor of shape $\mathbb{R}^{2N_r^y \times N_\theta^y \times N_\phi^y \times C}$. It stores $C$-dimensional neural appearance features.

**Coordinate System and Partitioning:**
The space is discretized using spherical coordinates $(r, \theta, \phi)$.
*   **Angular Partitions:** The angular ranges are fixed. $\theta$ spans $[0, \pi]$ and $\phi$ spans $[0, 2\pi]$. However, the grid partitions are defined as [S1]:
    $$ \Delta \theta^y = \frac{\pi}{2} \frac{1}{N_\theta^y}, \quad \Delta \phi^y = \frac{3\pi}{2} \frac{1}{N_\phi^y} $$
    *Note: The source defines the partition sizes this way, implying specific coverage or normalization conventions for the Yin/Yang split.*
*   **Radial Partitions:** Radial intervals increase exponentially to balance cell aspect ratios as distance increases [S1]. The radial boundaries are defined as:
    $$ r_i^y = r_0 k^{i-1}, \quad \text{for } i = 1, \dots, N_r^y $$
    The maximum radius is $r_{\max} = r_0 k^{N_r^y-1}$. For distances $r < r_0$, the grid interval is constant at $r_0$ [S1].

**Layout and Indexing:**
The "Balanced" aspect refers to the decomposition of the radial dimension. The density grid $G_\sigma$ has depth $2N_r^y$. This structure supports hierarchical sampling where the coarse grid is derived from the dense grid without extra memory [S1]. The factor of 2 in the radial dimension likely facilitates this coarse/fine distinction or Yin/Yang interleaving, though the exact mapping of indices to physical space requires trilinear interpolation $\mathcal{T}$ [S1].

**Lookup and Rendering:**
Given a 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$:
1.  Compute density $\sigma(\mathbf{x})$ by trilinear interpolation $\mathcal{T}$ on $G_\sigma$ [S1].
2.  Compute appearance features $\mathbf{f}$ by trilinear interpolation $\mathcal{T}$ on $G_a$ [S1].
3.  Decode color $c(\mathbf{x}, \mathbf{d})$ using a small MLP $f_{\text{MLP}}$:
    $$ c(\mathbf{x}, \mathbf{d}) = f_{\text{MLP}}(\mathbf{f}, \mathbf{d}) $$
    $$ \sigma(\mathbf{x}) = \mathcal{T}(G_\sigma, \mathbf{x}) $$
    $$ \mathbf{f} = \mathcal{T}(G_a, \mathbf{x}) $$
    [S1]

**Hierarchical Sampling:**
To optimize rendering, the method uses importance sampling. It first samples $N_c$ coarse points along a ray. Instead of allocating a separate coarse grid, it derives coarse density estimates from the dense $G_\sigma$ grid, potentially using a non-learnable convolution to downsample it on the fly [S1]. This avoids additional memory allocation [S1].

**Pseudocode:**
```python
def compute_radiance_field(x, d, G_sigma, G_a, r0, k, Nr, Nt, Np, C, f_MLP):
    """
    x: 3D position vector
    d: Viewing direction vector
    G_sigma: Density grid tensor [2*Nr, Nt, Np]
    G_a: Appearance grid tensor [2*Nr, Nt, Np, C]
    r0: Initial shell radius
    k: Exponential growth constant
    Nr: Number of radial partitions
    Nt: Number of theta partitions
    Np: Number of phi partitions
    C: Appearance feature dimension
    f_MLP: Neural network decoding features to color
    """
    # 1. Convert x to spherical coordinates (r, theta, phi)
    r, theta, phi = cartesian_to_spherical(x)
    
    # 2. Determine grid indices for trilinear interpolation
    # Radial index calculation based on exponential growth
    # r_i = r0 * k^(i-1)
    # Solve for i: i = 1 + log(r/r0) / log(k)
    if r < r0:
        r_idx = 0 # Or mapped to first bin
    else:
        r_idx = 1 + log(r / r0) / log(k)
        
    # Angular indices
    # Delta theta = pi / (2 * Nt)
    # Delta phi = 3pi / (2 * Np)
    theta_idx = theta / (pi / (2 * Nt))
    phi_idx = phi / (3 * pi / (2 * Np))
    
    # 3. Trilinear interpolation for density
    sigma = trilinear_interpolate(G_sigma, r_idx, theta_idx, phi_idx)
    
    # 4. Trilinear interpolation for appearance features
    features = trilinear_interpolate(G_a, r_idx, theta_idx, phi_idx)
    
    # 5. Decode color
    color = f_MLP(features, d)
    
    return sigma, color

def hierarchical_sampling(ray_origin, ray_direction, G_sigma, r0, k, Nr, Nt, Np):
    """
    Perform coarse sampling using the dense grid to estimate density for importance sampling.
    """
    # Sample Nc coarse points along the ray
    coarse_points = sample_points_along_ray(ray_origin, ray_direction, Nc)
    
    # Evaluate density at coarse points using G_sigma
    # This avoids allocating a separate coarse grid
    coarse_densities = []
    for p in coarse_points:
        sigma, _ = compute_radiance_field(p, ray_direction, G_sigma, None, r0, k, Nr, Nt, Np, 0, None)
        coarse_densities.append(sigma)
        
    # Use coarse_densities for importance sampling to determine fine points
    fine_points = importance_sample(ray_origin, ray_direction, coarse_densities, Nf)
    
    return fine_points
```

## Operating characteristics
*   **Memory:** The method uses dense grids $G_\sigma$ and $G_a$. The memory footprint is proportional to $2N_r^y N_\theta^y N_\phi^y (1 + C)$ elements [S1]. It saves memory compared to methods maintaining a dedicated coarse grid structure by reusing $G_\sigma$ for coarse sampling [S1].
*   **Time Complexity:** Lookup is $O(1)$ per sample point using trilinear interpolation. Hierarchical sampling adds overhead for coarse evaluation but reduces the number of fine samples needed for high-quality rendering [S1].
*   **Strengths:** Efficient for egocentric scenes where close objects require high resolution and distant objects can be coarser. The exponential radial scaling balances cell sizes [S1]. No extra memory for coarse grids [S1].
*   **Limitations:** Fixed spherical parameterization may not adapt well to non-egocentric or highly anisotropic scenes not centered at the origin. The angular partition definition ($\Delta \phi^y = \frac{3\pi}{2} \frac{1}{N_\phi^y}$) is non-standard and may require careful handling of the full $2\pi$ range [S1].

## Background
The Balanced Spherical Grid was introduced in the context of EgoNeRF for egocentric view synthesis [S1]. It addresses the challenge of representing radiance fields in panoramic captures where resolution requirements vary significantly with distance and angle [S1]. The method builds on the concept of feature grids in NeRF variants but adapts the spatial indexing to spherical coordinates with exponential radial scaling [S1].
