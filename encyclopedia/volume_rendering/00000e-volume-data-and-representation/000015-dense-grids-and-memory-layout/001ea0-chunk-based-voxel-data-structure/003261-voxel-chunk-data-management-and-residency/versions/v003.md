# Voxel Chunk Data Management and Residency

Also called: Voxel Chunk Compression and Residency Management, Far-Chunk Voxel Data Compression & Residency Management, Chunk residency tracking

## Overview
This method manages the memory residency of voxel chunks in an infinite voxel world by tracking state transitions between raw, uniform, and compressed forms to reduce memory footprint for distant chunks [S1, unofficial]. It solves the problem of unbounded memory usage in dense voxel grids by converting raw voxel arrays into compact representations (Uniform or Compressed) and dropping the resident raw array, while maintaining data consistency through versioning and mutation flags [S1, unofficial]. Unlike sibling structures that focus on spatial partitioning or octree traversal, this method operates on the data lifecycle within a fixed-size chunk, using distance-keyed asynchronous compression to prioritize memory savings for far chunks [S1, unofficial].

## How it works

### Inputs and Outputs
- **Inputs**: Chunk coordinates, local voxel positions, raw voxel data arrays, compression codec, chunk size [S1, unofficial].
- **Outputs**: Expanded voxel data, compressed buffers, residency state flags, version counters [S1, unofficial].

### Data Structures
**`FChunkDescriptor`**
Fields: `ChunkCoord` (`FIntVector`), `LODLevel` (`int32`), `ChunkSize` (`int32`), `VoxelArray` (`TSharedPtr<TArray<FVoxelData>>`), `Bounds` (`FBox`), `bIsDirty` (`bool`), `bHasEdits` (`bool`), `MorphFactor` (`float`), `GenerationSeed` (`int32`), `State` (`EChunkState`), `Residency` (`EVoxelDataResidency` enum: `Resident`, `Empty`, `Uniform`, `Compressed`), `bDataMutated` (`bool`), `ContentVersion` (`uint32`), `UniformValue` (`FVoxelData`), `bUniformValueValid` (`bool`), `bCompressionEvaluated` (`bool`), `CompressedVoxelData` (`TArray<uint8>`), `AsyncCompactTicket` (`uint32`) [S1, unofficial].

**`FVoxelChunkCompactForm`**
Fields: `Kind` (`uint8` enum `EKind`: `Incompressible`, `Uniform`, `Compressed`), `UniformValue` (`FVoxelData`), `Buffer` (`TArray<uint8>`) [S1, unofficial].

**`FVoxelData`**
Per-voxel data structure containing MaterialID, Density, BiomeID, and Metadata [S1, unofficial].

### Numbered Steps
1. **Initialization (`AllocateVoxelData`)**: Calculate `TotalVoxels = ChunkSize^3` [S1, unofficial]. Create `VoxelArray` with `SetNumZeroed(TotalVoxels)` [S1, unofficial]. Set `Residency` to `Resident` [S1, unofficial]. Reset `bDataMutated`, `bUniformValueValid`, `bCompressionEvaluated` [S1, unofficial]. Clear `CompressedVoxelData` [S1, unofficial]. Reset `AsyncCompactTicket` to 0 [S1, unofficial]. Increment `ContentVersion` [S1, unofficial].
2. **Setting Resident Data (`SetResidentVoxelData`)**: Replace `VoxelArray` with input data (moved) [S1, unofficial]. Set `Residency` to `Resident` [S1, unofficial]. Reset `bDataMutated`, `bUniformValueValid`, `bCompressionEvaluated` [S1, unofficial]. Clear `CompressedVoxelData` [S1, unofficial]. Reset `AsyncCompactTicket` [S1, unofficial]. Increment `ContentVersion` [S1, unofficial].
3. **Clearing Data (`ClearVoxelData`)**: Reset `VoxelArray` [S1, unofficial]. Set `Residency` to `Empty` [S1, unofficial]. Reset `bDataMutated`, `bUniformValueValid`, `bCompressionEvaluated` [S1, unofficial]. Clear `CompressedVoxelData` [S1, unofficial]. Reset `AsyncCompactTicket` [S1, unofficial]. Do NOT increment `ContentVersion` (clearing is memory teardown, not a logical change) [S1, unofficial].
4. **Reading a Voxel (`GetVoxel`)**: Calculate `Index` from `LocalPos` using the linear index formula [S1, unofficial]. Get `Data` from `GetResidentArray()` [S1, unofficial]. Return `Data[Index]` if valid, else `FVoxelData::Air()` [S1, unofficial].
5. **Writing a Voxel (`SetVoxel`)**: Calculate `Index` [S1, unofficial]. If index is valid in resident array: Detach `VoxelArray` (using `IsUnique()` check to avoid unnecessary copies) [S1, unofficial]. Set `DetachVoxelArray()[Index] = Data` [S1, unofficial]. Set `bIsDirty = true`, `bDataMutated = true` [S1, unofficial]. Reset `bUniformValueValid`, `bCompressionEvaluated` [S1, unofficial]. Clear `CompressedVoxelData` [S1, unofficial]. Reset `AsyncCompactTicket` [S1, unofficial]. Increment `ContentVersion` [S1, unofficial].
6. **Checking Uniformity (`TryCollapseUniform`)**: If `Residency` is not `Resident`, return `false` [S1, unofficial]. If `bUniformValueValid` is `true`: Reset `VoxelArray` [S1, unofficial]. Set `Residency` to `Uniform` [S1, unofficial]. Reset `AsyncCompactTicket` [S1, unofficial]. Return `true` [S1, unofficial]. Else: Set `bCompressionEvaluated = true` [S1, unofficial]. Call `ComputeUniformValue(GetResidentArray(), Value)` [S1, unofficial]. If true: Set `UniformValue = Value`, `bUniformValueValid = true` [S1, unofficial]. Reset `VoxelArray` [S1, unofficial]. Set `Residency` to `Uniform` [S1, unofficial]. Reset `AsyncCompactTicket` [S1, unofficial]. Return `true` [S1, unofficial]. Else return `false` [S1, unofficial].
7. **Compressing (`TryCompress`)**: If `Residency` is not `Resident`, return `false` [S1, unofficial]. If `bUniformValueValid` is `true` or `CompressedVoxelData.Num() > 0`: Call `DropResidentForCachedForm()` [S1, unofficial]. Else: Call `InstallCompactForm(ComputeCompactForm(GetResidentArray(), Codec, ChunkSize))` [S1, unofficial].
8. **Computing Compact Form (`ComputeCompactForm`)**: Input: `Data`, `Codec`, `ChunkSize` [S1, unofficial]. Check if all voxels are identical using `ComputeUniformValue` [S1, unofficial]. If true: Set `Form.Kind` to `Uniform` [S1, unofficial]. Return `Form` [S1, unofficial]. Else: Attempt compression using the general codec [S1, unofficial]. If compressed size < raw size (`Data.Num() * sizeof(FVoxelData)`): Set `Form.Kind` to `Compressed` [S1, unofficial]. Return `Form` with buffer [S1, unofficial]. Else: Return empty form (Incompressible) [S1, unofficial].
9. **Installing Compact Form (`InstallCompactForm`)**: Input: `Form`, `bDropResident` [S1, unofficial]. If `Residency` is not `Resident`, return `false` [S1, unofficial]. Set `AsyncCompactTicket` to 0 and `bCompressionEvaluated` to `true` [S1, unofficial]. If `Kind` is `Uniform`: Set `UniformValue` and `bUniformValueValid` to `true` [S1, unofficial]. If `Kind` is `Compressed`: Move `Form.Buffer` to `CompressedVoxelData` [S1, unofficial]. Set `bDataMutated` to `false` [S1, unofficial]. If `bDropResident` is `true`, call `DropResidentForCachedForm` [S1, unofficial].
10. **Dropping Resident (`DropResidentForCachedForm`)**: If `Residency` is not `Resident`, return `false` [S1, unofficial]. If `bUniformValueValid` is `true`: Reset `VoxelArray` [S1, unofficial]. Set `Residency` to `Uniform` [S1, unofficial]. Else if `CompressedVoxelData.Num() > 0`: Reset `VoxelArray` [S1, unofficial]. Set `Residency` to `Compressed` [S1, unofficial]. Else return `false` [S1, unofficial]. Set `AsyncCompactTicket` to 0 [S1, unofficial]. Return `true` if residency was changed [S1, unofficial].
11. **Computing Uniform Value (`ComputeUniformValue`)**: Input: `Data`, `Out` [S1, unofficial]. If empty, return `false` [S1, unofficial]. Cast data to `uint32` words [S1, unofficial]. If `sizeof(FVoxelData) == sizeof(uint32)`: Loop in blocks of 64 words [S1, unofficial]. OR-reduce XOR differences against the first word [S1, unofficial]. If any difference found, return `false` [S1, unofficial]. Check remaining elements individually [S1, unofficial]. If all identical, write first element to `Out` and return `true` [S1, unofficial].
12. **Expanding (`Expand`)**: If `Residency` is `Uniform`: Initialize `Out` with `UniformValue` repeated `TotalVoxels` times [S1, unofficial]. Return `true` [S1, unofficial]. If `Residency` is `Compressed`: Call `FVoxelChunkCodec::Decompress(Buffer, Out)` [S1, unofficial]. Return `Out.Num() == TotalVoxels` [S1, unofficial]. Else return `false` [S1, unofficial].

### Pseudocode
```python
def Expand(Out):
    if Residency == EVoxelDataResidency.Uniform:
        Out.Init(UniformValue, TotalVoxels)
        return True
    if Residency == EVoxelDataResidency.Compressed:
        FVoxelChunkCodec.Decompress(Buffer, Out)
        return Out.Num() == TotalVoxels
    return False
```

### Formulas
**Linear Index Calculation**
$$Index = LocalPos.X + LocalPos.Y \times ChunkSize + LocalPos.Z \times ChunkSize \times ChunkSize$$

**Inverse Index Calculation**
$$X = Index \pmod{ChunkSize}$$
$$Y = (Index / ChunkSize) \pmod{ChunkSize}$$
$$Z = Index / (ChunkSize \times ChunkSize)$$ [S1, unofficial]

### Parameters
- **ChunkSize**: Integer representing the edge length of a voxel chunk in voxels. Typical values: 32 or 64 [S1, unofficial].
- **Memory Footprint**: For a 32^3 chunk, voxel data only is ~128 KB [S1, unofficial].

### Edge Cases and Pitfalls
- **Negative Coordinates**: `WorldToLocalVoxel` and `VoxelToLocal` require modulo correction for negative coordinates to handle wrapping or boundary conditions correctly. For `WorldToLocalVoxel`, if `LocalWorld.X/Y/Z < 0`, add `ChunkWorldSize`. For `VoxelToLocal`, if `Local.X/Y/Z < 0`, add `ChunkSize` [S1, unofficial].
- **ContentVersion Bumping**: Must be bumped for logical changes (e.g., edit-layer changes) to invalidate caches, but NOT for `ClearVoxelData` (memory teardown only) [S1, unofficial].
- **Water-Flag Propagation**: Writes through `GetVoxelDataMutable()` do not bump `ContentVersion` because they are material changes, not density changes causing geometric boundary seams [S1, unofficial].
- **Async Compression Validation**: Async compression results must be validated against `AsyncCompactTicket` to prevent installing stale compressed data after concurrent writes [S1, unofficial].
- **DetachVoxelArray**: Uses `IsUnique()` on the game thread. If a reader let go meanwhile, a needless copy occurs, but no reader can take the array again except from the game thread [S1, unofficial].

## Operating characteristics
- **Time Complexity**: `GetVoxel` is O(1) for Uniform, O(1) + decompression time for Compressed, O(1) for Resident [G]. `SetVoxel` is O(1) amortized, O(N) if detachment or re-allocation is needed [G]. `TryCompress` is O(N) for uniformity check, O(N) for compression [G]. `ComputeUniformValue` is O(N) with word-aligned optimizations [G].
- **Memory Complexity**: Resident is O(N) where N = ChunkSize^3 [G]. Uniform is O(1) (stores one value) [G]. Compressed is O(C) where C is compressed size, typically < N [G]. Empty is O(1) [G].
- **Measured Performance**: For a 32^3 chunk, raw data is ~128 KB [S1, unofficial]. Compression can significantly reduce this for uniform or repetitive data [S1, unofficial]. Async compression is keyed on distance, allowing far chunks to be compressed without blocking the main thread [S1, unofficial].
- **Scaling**: Scales well with chunk size; larger chunks benefit more from compression if data is uniform or compressible [G]. Distance-based streaming ensures only relevant chunks are kept in high-residency states [S1, unofficial].
- **Strengths**: Reduces memory footprint for large worlds [S1, unofficial]. Asynchronous compression minimizes frame-time spikes [S1, unofficial]. Versioning ensures data consistency across concurrent accesses [S1, unofficial].
- **Limitations**: Compression overhead for small or highly varied chunks [G]. Complexity in managing residency states and versioning [G]. Requires careful handling of negative coordinates and boundary conditions [S1, unofficial].
- **When to Use**: Infinite voxel worlds with distance-based streaming [S1, unofficial]. Scenes with large uniform areas (e.g., sky, deep ocean) [G]. When memory is a constraint and compression ratios are favorable [G].
- **When Not to Use**: Small, static worlds where memory is not a concern [G]. Highly dynamic, non-uniform data where compression overhead outweighs benefits [G].

## Background
This method originates from the VoxelWorlds project by Daniel Raquel, implemented in C++ for Unreal Engine [S1, unofficial]. It is part of a broader system that includes streaming, hybrid rendering, procedural generation, editing, and materials [S1, unofficial]. The residency management is specifically designed to support distance-based chunk loading and unloading, with async mesh generation and far-chunk voxel data compression [S1, unofficial]. The approach is documented in the VoxelWorlds GitHub repository [S1, unofficial].
