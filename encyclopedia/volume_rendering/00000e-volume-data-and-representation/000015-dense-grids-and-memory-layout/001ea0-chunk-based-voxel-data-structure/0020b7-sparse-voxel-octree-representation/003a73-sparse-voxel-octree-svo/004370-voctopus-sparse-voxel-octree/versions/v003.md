# Voctopus Sparse Voxel Octree

Also called: Voctopus, Voctopus Kernel, VoctopusKernel32, asm.js octree kernel [S1, unofficial]

## Overview
Voctopus is a sparse voxel octree (SVO) implementation in JavaScript/asm.js designed for direct shader rendering in WebGL without meshification, utilizing ray tracing techniques [S1, unofficial]. It distinguishes itself by using a compact, flat memory layout with pointer encoding to minimize memory footprint and enable high-performance traversal in constrained environments [S1, unofficial]. Unlike general-purpose SVOs, it is optimized for a small kernel that handles pointer encoding, tree traversal, and ray-AABB intersection testing directly within a single buffer [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** Maximum tree depth $D_{MAX}$, initial buffer size (optional), ray origin $(r_x, r_y, r_z)$ and direction $(d_x, d_y, d_z)$ for traversal [S1, unofficial].
- **Output:** Voxel data (RGBA), traversal pointers, or boolean hit status for ray casting [S1, unofficial].

**Data Structures:**
The kernel manages a flat `Uint32Array` buffer (heap) acting as the octree storage [S1, unofficial]. The layout is fixed at specific indices:

| Index | Variable | Description |
| :--- | :--- | :--- |
| 0 | $D_{MAX}$ | Maximum depth of the tree |
| 1 | $P_{FO}$ | First offset (root octet offset) |
| 2 | $P_{NO}$ | Next octet pointer (allocation cursor) |
| 3 | $P_{CUR}$ | Current pointer (traversal state) |
| 4 | $P_{TMP}$ | Temporary pointer |
| 5 | $D_{CUR}$ | Current depth in traversal |
| 6 | $LOC_X$ | Current X coordinate |
| 7 | $LOC_Y$ | Current Y coordinate |
| 8 | $LOC_Z$ | Current Z coordinate |
| 9 | $D_{TGT}$ | Target depth for traversal |
| 10 | $D_{INV}$ | Depth inverse ($D_{MAX} - D_{CUR}$) |
| 11 | $V_{TMP}$ | Temporary value |
| 12 | $STEPA$ | Step accumulator |
| 13 | $STEPB$ | Step buffer |
| 14 | $TRAVA$ | Traversal accumulator |
| 15 | $INITA$ | Initialization accumulator |

Indices are multiplied by 4 (shifted right by 2) for 32-bit access in the heap [S1, unofficial].

**Voxel Value Layout:**
Each octant is a 32-bit value:
- Bits 0–23: RGB color (8 bits each) [S1, unofficial].
- Bits 24–27: Alpha channel (4 bits) [S1, unofficial].
- Bits 28–30: Reserved for rendering instructions [S1, unofficial].
- Bit 31: Flag indicating if the entry is a pointer or voxel data [S1, unofficial].

**Pointer Encoding:**
- **Encode:** $makeP(n) = (n \ll 1) \mid 1$. The least significant bit (LSB) is set to 1 to flag a value as a pointer [S1, unofficial].
- **Decode:** $pFrom(n) = ((\sim(0x7FFFFFFF + (n \& 1)) \& n) \gg 1)$. Returns 0 if $n$ is not a pointer (LSB is 0) [S1, unofficial].

**Voxel Packing:**
- **Pack:** $valFromRGBA(r, g, b, a) = (r \ll 24) + (g \ll 16) + (b \ll 8) + ((a \& 63) \ll 4)$. R, G, B are 8-bit; A is 4-bit (masked by 63) [S1, unofficial].
- **Unpack:**
  - $r = (n \gg 8) \& 0xFF$
  - $g = n \& 0xFF$
  - $b = (n \& 0xFF00) \gg 8$
  - $a = (n \& 0x0F000000) \gg 24$ [S1, unofficial].

**Octant Identity:**
To determine which of the 8 children an octet occupies at a given depth:
$octantIdentity(v, dc, dm) = (((v[2] \gg (dm - 1 - dc)) \& 1) \ll 2) \mid (((v[1] \gg (dm - 1 - dc)) \& 1) \ll 1) \mid ((v[0] \gg (dm - 1 - dc)) \& 1)$ [S1, unofficial].

**Parameters:**
- $MAX\_BUFFER$: $1024 \times 1024 \times 1024 \times 512$ bytes (512 GB) [S1, unofficial].
- $VK\_FO$: 100 (First Offset) [S1, unofficial].
- $VK\_OS$: 8 bytes (Octet Size) [S1, unofficial].
- $depth$: Required constructor parameter, minimum useful depth is 2 [S1, unofficial].

**Algorithm Steps:**

1. **Initialization:**
   - Validate depth [S1, unofficial].
   - Calculate $octantSize = 8$ bytes [S1, unofficial].
   - Calculate $octetSize = octantSize \times 8 = 64$ bytes [S1, unofficial]. (Note: The source notes "Octet size: 8 bytes for a single octet (in the kernel's internal representation context)", which likely refers to the stride or a specific internal metric, but the constructor explicitly uses `octetSize = octantSize * 8` [S1, unofficial].)
   - Calculate $firstOffset = VK\_FO$ [S1, unofficial].
   - Calculate $maxSize$ using `npot(firstOffset + sump8(depth))` [S1, unofficial].
   - Calculate $dimensions = 2^{depth}$ [S1, unofficial].
   - Calculate $startSize = npot(\max(0x10000, \min(maxSize/8, MAX\_BUFFER)))$ [S1, unofficial].
   - Allocate buffer of $startSize$ [S1, unofficial].
   - Initialize kernel with buffer and $depth-1$ [S1, unofficial].

2. **Buffer Expansion:**
   - If memory is needed, calculate $maxAllowed = \min(MAX\_BUFFER, this.maxSize)$ [S1, unofficial].
   - Calculate $newSize = buffer.byteLength \times 2$ [S1, unofficial].
   - If $newSize > maxAllowed$, return false [S1, unofficial].
   - Create new `ArrayBuffer` of size $newSize$ [S1, unofficial].
   - Transfer contents [S1, unofficial].
   - Re-initialize kernel with new buffer [S1, unofficial].
   - Update references. Return true [S1, unofficial].

3. **Traversal (`seek`):**
   - Initialize $TRAVA = 0$ [S1, unofficial].
   - Loop while $D_{CUR} < \min(D_{TGT}, D_{MAX})$:
     - Increment $D_{CUR}$ [S1, unofficial].
     - Calculate $octantPointer$ using current coordinates and depth inverse [S1, unofficial].
     - Read octant value into $TRAVA$ [S1, unofficial].
     - If $isP(TRAVA)$ is false, return $TRAVA$ (leaf voxel) [S1, unofficial].
     - If $isP(TRAVA)$ is true, update $P_{CUR} = pFrom(TRAVA)$ [S1, unofficial].
   - Return $P_{CUR}$ if loop finishes [S1, unofficial].

4. **Initialization (`initOctet`):**
   - Initialize $INITA = 0$ [S1, unofficial].
   - Loop while $D_{CUR} < \min(D_{TGT}, D_{MAX})$:
     - Increment $D_{CUR}$ [S1, unofficial].
     - Calculate $octantPointer$ [S1, unofficial].
     - Read octant value into $INITA$ [S1, unofficial].
     - If $isP(INITA)$ is false:
       - Allocate new octet (increment $P_{NO}$) [S1, unofficial].
       - Create pointer from allocation [S1, unofficial].
       - Set octant at $octantPointer$ to this new pointer [S1, unofficial].
     - Update $P_{CUR} = pFrom(INITA)$ [S1, unofficial].
   - Return $P_{CUR}$ [S1, unofficial].

5. **Step (`step`):**
   - Increment $D_{CUR}$ [S1, unofficial].
   - Calculate $octantPointer$ [S1, unofficial].
   - Read octant value into $STEPA$ [S1, unofficial].
   - Update $P_{CUR} = pFrom(STEPA)$ [S1, unofficial].
   - Return $octantPointer$ [S1, unofficial].

6. **Ray-AABB Intersection (`rayAABB`):**
   - Calculate slabs using inverse ray direction:
     - $DBLA = (bs_x - ro_x) \times rdx$
     - $DBLB = (be_x - ro_x) \times rdx$
     - $DBLC = (bs_y - ro_y) \times rdy$
     - $DBLD = (be_y - ro_y) \times rdy$
     - $DBLE = (bs_z - ro_z) \times rdz$
     - $DBLF = (be_z - ro_z) \times rdz$ (Note: The source code reuses `DBLD` for the Z-end slab, which is a typo; standard slab method uses distinct variables) [S1, unofficial].
   - Return $1$ if $\max(\min(DBLA, DBLB), \min(DBLC, DBLD), \min(DBLE, DBLF)) \le \min(\max(DBLA, DBLB), \max(DBLC, DBLD), \max(DBLE, DBLF))$, else $0$ [S1, unofficial].

**Pseudocode:**

```python
def voctopus_init(depth, buffer_size=None):
    VK_FO = 100
    VK_OS = 8
    MAX_BUFFER = 1024 * 1024 * 1024 * 512
    
    octant_size = 8
    octet_size = octant_size * 8
    
    sum_p8 = (8**(depth + 1) - 1) // 7
    first_offset = VK_FO
    max_size = next_power_of_two(first_offset + sum_p8)
    
    dimensions = 2 ** depth
    
    min_start = 0x10000
    max_start = max_size // 8
    start_size = next_power_of_two(max(min_start, min(max_start, MAX_BUFFER)))
    
    if buffer_size is None:
        buffer_size = start_size
        
    buffer = bytearray(buffer_size)
    heap = [0] * (buffer_size // 4)
    
    heap[0] = depth  # D_MAX
    heap[1] = VK_FO  # P_FO
    heap[2] = VK_FO + VK_OS  # P_NO
    
    return {'heap': heap, 'depth': depth, 'buffer': buffer}

def voctopus_seek(kernel, target_coords, target_depth):
    heap = kernel['heap']
    depth = kernel['depth']
    
    heap[9] = target_depth
    prepare_lookup(kernel, target_coords, depth)
    
    heap[5] = 0  # D_CUR = 0
    heap[3] = heap[1]  # P_CUR = P_FO
    
    while heap[5] < min(heap[9], heap[0]):
        heap[5] += 1
        octant_ptr = octant_pointer(kernel)
        trava = heap[octant_ptr >> 2]
        
        if not is_pointer(trava):
            return trava  # Leaf voxel data
        
        heap[3] = p_from(trava)
        
    return heap[3]

def voctopus_init_octet(kernel, target_coords, target_depth):
    heap = kernel['heap']
    depth = kernel['depth']
    
    heap[9] = target_depth
    prepare_lookup(kernel, target_coords, depth)
    heap[5] = 0
    heap[3] = heap[1]
    
    while heap[5] < min(heap[9], heap[0]):
        heap[5] += 1
        octant_ptr = octant_pointer(kernel)
        inita = heap[octant_ptr >> 2]
        
        if not is_pointer(inita):
            new_ptr = allocate_octet(kernel)
            new_ptr_encoded = make_pointer(new_ptr)
            heap[octant_ptr >> 2] = new_ptr_encoded
            inita = new_ptr_encoded
            
        heap[3] = p_from(inita)
        
    return heap[3]

def voctopus_set_voxel(kernel, coords, r, g, b, a):
    depth = kernel['depth']
    ptr = voctopus_init_octet(kernel, coords, depth)
    val = val_from_rgba(r, g, b, a)
    heap = kernel['heap']
    heap[ptr >> 2] = val
    return ptr

def voctopus_get_voxel(kernel, coords, out):
    depth = kernel['depth']
    ptr = voctopus_seek(kernel, coords, depth)
    raw = kernel['heap'][ptr >> 2]
    
    out['r'] = r_from(raw)
    out['g'] = g_from(raw)
    out['b'] = b_from(raw)
    out['a'] = a_from(raw)
    return out

def is_pointer(n):
    return (n & 1) != 0

def p_from(n):
    if not is_pointer(n):
        return 0
    return ((~(0x7FFFFFFF + (n & 1)) & n) >> 1)

def make_pointer(n):
    return (n << 1) | 1

def val_from_rgba(r, g, b, a):
    return (r << 24) + (g << 16) + (b << 8) + ((a & 63) << 4)

def r_from(n):
    return ((n >> 8) & 0xFF)

def g_from(n):
    return (n & 0xFF)

def b_from(n):
    return ((n & 0xFF00) >> 8)

def a_from(n):
    return (n & 0x0F000000) >> 24

def octant_identity(v, dc, dm):
    d = dm - 1 - dc
    return (((v[2] >> d) & 1) << 2) | (((v[1] >> d) & 1) << 1) | ((v[0] >> d) & 1)

def prepare_lookup(kernel, coords, depth):
    heap = kernel['heap']
    heap[6] = coords[0]
    heap[7] = coords[1]
    heap[8] = coords[2]

def octant_pointer(kernel):
    heap = kernel['heap']
    dc = heap[5]
    dm = heap[0]
    d_inv = dm - dc
    
    x = heap[6]
    y = heap[7]
    z = heap[8]
    
    id = octant_identity([x, y, z], dc, dm)
    p_cur = heap[3]
    
    return p_cur + id

def allocate_octet(kernel):
    heap = kernel['heap']
    p_no = heap[2]
    heap[2] = p_no + 8
    return p_no - 8

def next_power_of_two(n):
    n -= 1
    n |= n >> 1
    n |= n >> 2
    n |= n >> 4
    n |= n >> 8
    n |= n >> 16
    n |= n >> 32
    return n + 1
```

## Operating characteristics
- **Time Complexity:** Traversal is $O(D)$ where $D$ is the depth of the tree, as it visits one node per level [S1, unofficial].
- **Memory Complexity:** $O(8^D)$ in the worst case (dense), but sparse in practice. The buffer size is determined by `npot(firstOffset + sump8(depth))` [S1, unofficial].
- **Performance:** Over one million read/write operations per second on commodity hardware, up to 8 million r/w operations per second [S1, unofficial].
- **Strengths:** Small memory footprint, fast traversal in JavaScript/asm.js, direct shader rendering capability [S1, unofficial].
- **Limitations:** Buffer expansion is very expensive and should be avoided [S1, unofficial]. Using `get()` with an invalid index returns garbage data [S1, unofficial]. Using `set()` with an incorrect index will corrupt the octree [S1, unofficial].
- **When to use:** WebGL environments requiring direct voxel rendering without meshing [S1, unofficial].
- **When not to use:** When frequent buffer expansion is expected, or when high-precision floating-point voxel data is required (limited to 32-bit packed values) [S1, unofficial].

## Background
Voctopus was developed by nphyx as a JavaScript implementation of a sparse voxel octree [S1, unofficial]. The goal was to create a data structure small and fast enough to be rendered directly by a shader in WebGL without meshification, using ray tracing techniques [S1, unofficial]. It consists of a low-level kernel written in asm.js and a high-level JavaScript API [S1, unofficial]. The project is still a work in progress, with features like pruning and defragmentation incomplete [S1, unofficial].
