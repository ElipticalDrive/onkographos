# 2D Voxel Shadow Map

Also called: Column Shadow Map, Heightmap Shadowing

## Overview
A 2D Voxel Shadow Map stores the highest occupied voxel Y-coordinate per (X, Z) column to determine occlusion for lighting without ray marching [S1, unofficial]. It builds on [Top Voxel Retrieval](4236-top-voxel-retrieval.md) to provide occlusion data [G].

## How it works
**Inputs:**
- World-space bounding box maximum coordinates: `max[0]`, `max[1]`, `max[2]` [S1, unofficial].
- Voxel grid dimensions: `SH_MAX_X` (width in voxels), `SH_MAX_Z` (depth in voxels) [S1, unofficial].
- Scaling factor: `root_bitw` (log2 scaling factor, typically 3) [S1, unofficial].

**Outputs:**
- `shadow_map`: A `uint16_t*` array of size `shadow_map_size[0] * shadow_map_size[1]`, storing the maximum Y height for each (X, Z) column [S1, unofficial].

**Data Structures:**
- `shadow_map`: Array of size `width * depth` where each element stores the highest Y-coordinate of an occupied voxel at the corresponding (X, Z) column [S1, unofficial].

**Steps:**
1. **Initialize Shadow Map Dimensions:** Calculate dimensions using `width = (max[0] << root_bitw) + (max[1] << root_bitw)` and `depth = (max[2] << root_bitw)` [S1, unofficial]. Allocate a `uint16_t` array of size `width * depth` [S1, unofficial]. Initialize all entries to 0 [G].
2. **Populate Shadow Map:** For each occupied voxel at world position `ws = (ws[0], ws[1], ws[2])`, calculate the index using `index = (ws[0] + ws[1]) + (SH_MAX_X * ws[2])` [S1, unofficial]. Update the entry with `shadow_map[index] = max(shadow_map[index], ws[1])` [S1, unofficial].
3. **Sample Occlusion:** Calculate the shadow map index for `ws` [S1, unofficial]. Check if `shadow_map[index] >= ws[1] + 1` OR `shadow_map[index + 1] >= ws[1] + 1` [S1, unofficial]. Return 1 if occluded, 0 otherwise [S1, unofficial].

**Parameters:**
- `root_bitw`: Log2 scaling factor for world coordinates to shadow map coordinates. Typical value: 3 (scaling factor of 8) [S1, unofficial].

**Edge Cases and Pitfalls:**
- The formula `index = (ws[0] + ws[1]) + (SH_MAX_X * ws[2])` adds `ws[1]` to `ws[0]`, effectively shearing the coordinate space [S1, unofficial]. This requires careful alignment of world bounds and shadow map dimensions to avoid out-of-bounds access [S1, unofficial].
- Ensure that `ws[1] + 1` does not exceed the maximum representable value in `uint16_t` and that `index + 1` is within bounds when checking neighbors [G].

**Pseudocode:**
```python
def initialize_shadow_map(max_x: int, max_y: int, max_z: int, root_bitw: int):
    width = (max_x << root_bitw) + (max_y << root_bitw)
    depth = max_z << root_bitw
    shadow_map = [0] * (width * depth)
    return shadow_map, width, depth

def update_shadow_map(shadow_map: list, ws: tuple, SH_MAX_X: int):
    index = (ws[0] + ws[1]) + (SH_MAX_X * ws[2])
    if 0 <= index < len(shadow_map):
        if ws[1] > shadow_map[index]:
            shadow_map[index] = ws[1]

def sample_occlusion(shadow_map: list, ws: tuple, SH_MAX_X: int):
    index = (ws[0] + ws[1]) + (SH_MAX_X * ws[2])
    if 0 <= index < len(shadow_map) and (index + 1) < len(shadow_map):
        is_shadowed = (shadow_map[index] >= ws[1] + 1) or (shadow_map[index + 1] >= ws[1] + 1)
        return 1 if is_shadowed else 0
    return 0
```

## Subtopics

### [Dynamic Orthographic Shadow Map Generation](7386-dynamic-orthographic-shadow-map-generation.md)
Generates a per-frame depth texture from a directional light's perspective to compute shadow occlusion for voxel models. It sets itself apart by pre-computing occlusion data into a 2D texture rather than traversing voxels at render time. Choose this method when dynamic lighting and per-frame updates are required.

## Operating characteristics
- **Time Complexity:** Not given in the sources [S1, unofficial].
- **Memory Complexity:** O(W * D), where W and D are the shadow map dimensions [G].
- **Measured Performance:** Not given in the sources [S1, unofficial].
- **Strengths:** Fast shadow determination without ray marching [S1, unofficial].
- **Limitations:** Sheared coordinate space can lead to out-of-bounds access [S1, unofficial].
- **When to Use:** Suitable for static or slowly changing voxel environments where performance is critical [G].
- **When Not to Use:** Not ideal for highly dynamic scenes or non-voxel-based geometry [G].
