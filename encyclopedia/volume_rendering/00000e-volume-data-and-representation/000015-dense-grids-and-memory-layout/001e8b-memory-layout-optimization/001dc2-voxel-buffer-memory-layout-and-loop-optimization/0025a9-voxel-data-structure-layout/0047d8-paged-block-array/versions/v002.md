# Paged Block Array

Also called: Block Array, Block-allocated Dynamic Array, Chunked Array, Paged Array

## Overview
The Paged Block Array is a dynamic array implementation that stores elements in fixed-size blocks (pages) to optimize memory allocation and cache locality, avoiding the need for contiguous reallocation of the entire array [S1, unofficial]. It differs from standard dynamic arrays by using fixed-size blocks instead of contiguous reallocation, reducing allocation overhead and fragmentation at the cost of slightly higher pointer indirection and fixed block sizes [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A `BlockArray` structure, an element to insert, and an index [S1, unofficial].
- Output: A pointer to the element, or void for modification operations [S1, unofficial].

**Data Structures:**
The implementation relies on three core structures [S1, unofficial]. The element type is generic (`Element`), but the block size is fixed [S1, unofficial].

1.  **Block Structure**:
    ```c
    struct ElementBlock {
        Element Elements[N];
    };
    ```
    Where $N$ is the block size. For index-based arrays, $N=8$ [S1, unofficial]. For pointer-based arrays, $N=64$ [S1, unofficial].

2.  **Index Structure**:
    ```c
    struct BlockArrayIndex {
        umm Index; // Global linear index into the array [S1, unofficial]
    };
    ```
    `umm` is an unsigned integer type sufficient to hold the total element count [S1, unofficial].

3.  **BlockArray Structure**:
    ```c
    struct BlockArray {
        ElementBlock **BlockPtrs; // Pointer to array of pointers to blocks [S1, unofficial]
        u32 BlockCount;           // Number of allocated blocks [S1, unofficial]
        u32 ElementCount;         // Number of valid elements [S1, unofficial]
        MemoryArena *Memory;      // Memory allocator [S1, unofficial]
    };
    ```

**Parameters:**
- `N`: Block size. Typically 8 for index types, 64 for pointer types [S1, unofficial].
- `Memory`: A memory arena used for allocation [S1, unofficial].

**Algorithms:**

1.  **GetPtr**: Retrieves a pointer to the element at a global linear index [S1, unofficial].
    - Calculate `BlockIndex = Index / N` [S1, unofficial].
    - Assert `BlockIndex < BlockCount` [S1, unofficial].
    - Retrieve `Block = BlockPtrs[BlockIndex]` [S1, unofficial].
    - Calculate `ElementIndex = Index % N` [S1, unofficial].
    - Return `Block->Elements + ElementIndex` [S1, unofficial].

2.  **Push**: Appends an element to the end of the array [S1, unofficial].
    - Check if `ElementCount == Capacity` (where `Capacity = BlockCount * N`) [S1, unofficial].
    - If full, call `NewBlock` [S1, unofficial].
    - Call `Set` to place the element at `ElementCount` [S1, unofficial].
    - Increment `ElementCount` [S1, unofficial].

3.  **NewBlock**: Allocates a new block and updates the pointer array [S1, unofficial].
    - Allocate `NewBlock` of type `ElementBlock` from `Memory` [S1, unofficial].
    - Allocate `NewBlockPtrs` array of size `BlockCount + 1` from `Memory` [S1, unofficial].
    - Copy `BlockPtrs[0..BlockCount-1]` to `NewBlockPtrs[0..BlockCount-1]` [S1, unofficial].
    - Set `NewBlockPtrs[BlockCount] = NewBlock` [S1, unofficial].
    - Update `BlockPtrs = NewBlockPtrs` [S1, unofficial].
    - Increment `BlockCount` [S1, unofficial].

4.  **RemoveUnordered**: Removes an element at `Index` by swapping it with the last element [S1, unofficial].
    - Get `LastI = LastIndex` (where `LastIndex = ElementCount - 1`) [S1, unofficial].
    - Assert `Index <= LastI` [S1, unofficial].
    - Get `LastElement = GetPtr(Array, LastI)` [S1, unofficial].
    - Set `Array[Index] = LastElement` [S1, unofficial].
    - Decrement `ElementCount` [S1, unofficial].

5.  **RemoveOrdered**: Removes an element at `Index` by shifting subsequent elements [S1, unofficial].
    - Assert `Index < ElementCount` [S1, unofficial].
    - Iterate from `Index` to `LastIndex` [S1, unofficial].
    - Shift each element down by one position [S1, unofficial].
    - Decrement `ElementCount` [S1, unofficial].

6.  **Insert**: Inserts an element at `Index`, shifting subsequent elements [S1, unofficial].
    - Assert `Index <= LastIndex` [S1, unofficial].
    - Call `Push` to allocate space and get a pointer to the new last element (`Prev`) [S1, unofficial].
    - Iterate backwards from `LastIndex` to `Index` [S1, unofficial].
    - Shift each element up by one position [S1, unofficial].
    - Set the new element at `Index` [S1, unofficial].

7.  **Pop**: Removes and returns the last element [S1, unofficial].
    - If `ElementCount > 0`, decrement `ElementCount` and return pointer to last element [S1, unofficial].
    - Else return empty/null [S1, unofficial].

8.  **ClearList**: Resets the array [S1, unofficial].
    - Iterate over all elements and set them to empty/zero [S1, unofficial].
    - Set `ElementCount = 0` [S1, unofficial].

9.  **Find**: Searches for an element [S1, unofficial].
    - Iterate over all elements [S1, unofficial].
    - Compare each with `Query` using `AreEqual` [S1, unofficial].
    - Return `Index` if match found, else `INVALID_BLOCK_ARRAY_INDEX` [S1, unofficial].

**Pseudocode:**

```python
# Constants
N = 8  # Block size for index-based arrays [S1, unofficial]

# Data Structures
class BlockArrayIndex:
    def __init__(self, index):
        self.Index = index

class ElementBlock:
    def __init__(self):
        self.Elements = [None] * N

class BlockArray:
    def __init__(self, memory_arena):
        self.BlockPtrs = []
        self.BlockCount = 0
        self.ElementCount = 0
        self.Memory = memory_arena

    def Capacity(self):
        return self.BlockCount * N

    def AtElements(self):
        return self.ElementCount

    def LastIndex(self):
        if self.ElementCount == 0:
            return BlockArrayIndex(0)
        return BlockArrayIndex(self.ElementCount - 1)

    def GetBlock(self, index):
        block_index = index // N
        assert block_index < self.BlockCount
        return self.BlockPtrs[block_index]

    def GetPtr(self, index):
        assert self.BlockPtrs
        assert index < self.ElementCount
        assert index < self.Capacity()
        block = self.GetBlock(index)
        element_index = index % N
        return block.Elements[element_index]

    def Set(self, element, index):
        assert self.BlockPtrs
        assert index < self.Capacity()
        block = self.GetBlock(index)
        element_index = index % N
        block.Elements[element_index] = element

    def NewBlock(self):
        new_block = ElementBlock()
        new_block_ptrs = [None] * (self.BlockCount + 1)
        for i in range(self.BlockCount):
            new_block_ptrs[i] = self.BlockPtrs[i]
        new_block_ptrs[self.BlockCount] = new_block
        self.BlockPtrs = new_block_ptrs
        self.BlockCount += 1

    def Push(self, element):
        assert self.Memory
        if self.AtElements() == self.Capacity():
            self.NewBlock()
        self.Set(element, self.AtElements())
        self.ElementCount += 1
        return self.GetPtr(self.AtElements() - 1)

    def RemoveUnordered(self, index):
        last_i = self.LastIndex()
        assert index <= last_i.Index
        last_element = self.GetPtr(last_i.Index)
        self.Set(last_element, index)
        self.ElementCount -= 1

    def RemoveOrdered(self, index_to_remove):
        assert index_to_remove < self.ElementCount
        for i in range(index_to_remove, self.ElementCount - 1):
            src = self.GetPtr(i + 1)
            dst = self.GetPtr(i)
            dst[0] = src[0]
        self.ElementCount -= 1

    def Insert(self, index, element):
        assert index <= self.LastIndex().Index
        assert self.Memory
        self.Push(None)
        last = self.LastIndex()
        for i in range(last.Index, index, -1):
            e = self.GetPtr(i)
            self.Set(e, i-1)
        self.Set(element, index)

    def Pop(self):
        if self.ElementCount > 0:
            self.ElementCount -= 1
            return self.GetPtr(self.ElementCount)
        return None

    def ClearList(self):
        for i in range(self.ElementCount):
            self.Set(None, i)
        self.ElementCount = 0

    def Find(self, query):
        for i in range(self.ElementCount):
            if self.GetPtr(i) == query:
                return i
        return -1
```

**Edge Cases and Pitfalls:**
- `NewBlock` reallocates the entire `BlockPtrs` array. This invalidates any existing pointers to the `BlockPtrs` array itself, though pointers to individual blocks remain valid [S1, unofficial].
- Empty array pop: `TryGetPtr` checks `LastIndex` before accessing. Returns empty result if `ElementCount` is 0, preventing out-of-bounds access [S1, unofficial].

## Operating characteristics
- **Time Complexity**: `Push` is O(1) amortized. `NewBlock` is O(N) where N is the number of blocks due to pointer array reallocation and copy, but happens infrequently [S1, unofficial]. `GetPtr`, `RemoveUnordered`, and `Pop` are O(1) [S1, unofficial]. `RemoveOrdered` and `Insert` are O(K) where K is the number of elements after the affected index [S1, unofficial].
- **Memory Complexity**: O(B * N) where B is the number of blocks, with overhead for the `BlockPtrs` array [S1, unofficial].
- **Strengths**: Reduces allocation overhead and fragmentation compared to contiguous dynamic arrays [S1, unofficial].
- **Limitations**: Fixed block sizes and slightly higher pointer indirection [S1, unofficial].

## Background
The Paged Block Array is described in the context of the Bonsai voxel engine, a project by Scallyw4g [S1, unofficial]. It is used for managing dynamic arrays of voxel-related data, such as chunk completion callbacks and work queue entries [S1, unofficial]. The design choice reflects a need for efficient memory management in a voxel engine where data structures grow and shrink dynamically [S1, unofficial].
