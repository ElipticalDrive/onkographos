# Leaf Node Gaussian Approximation

Also called: Single Gaussian per Leaf, Spatial Clustering and Averaging

## Overview
Leaf Node Gaussian Approximation is a method to approximate VDB leaf nodes (512 voxels) with a single Gaussian primitive to reduce rendering complexity while maintaining spatial coherence [S1, unofficial]. It serves as the lowest Level of Detail (LOD) in a hierarchical Gaussian representation, leveraging the inherent spatial clustering of VDB leaf nodes [S1, unofficial]. Unlike higher LOD variants that subdivide leaf nodes into smaller blocks, this method treats the entire leaf node as a single cluster, making it distinct from [Medium LOD Approximation](4128-voxel-representation-with-gaussian-lobes.md#medium-lod-approximation) and [High LOD Approximation](4128-voxel-representation-with-gaussian-lobes.md#high-lod-approximation) [S1, unofficial].

## How it works
The method processes VDB leaf nodes to generate a set of axis-aligned Gaussian primitives [S1, unofficial]. It distinguishes between dense and sparse leaf nodes to calculate position, opacity, and covariance [S1, unofficial].

### Inputs and Outputs
*   **Input:** A VDB grid with Tiled data storage [S1, unofficial]. Leaf nodes are either dense (all voxels active) or sparse (subset of voxels active) [S1, unofficial].
*   **Output:** A global array of Gaussian parameters (position, opacity, covariance) and metadata for OptiX Geometry Acceleration Structure (GAS) creation [S1, unofficial].

### Data Structures
The implementation uses thread-local buffers during parallel processing to avoid contention [S1, unofficial]. Each thread maintains:
*   `thread_gaussian_positions`: List of 3D centers (world coordinates) [S1, unofficial].
*   `thread_gaussian_opacities`: List of scalar opacity values [S1, unofficial].
*   `thread_gaussian_covariances`: Flat array of diagonal elements of a $3 \times 3$ covariance matrix (variances in X, Y, Z) [S1, unofficial].
*   `localLeafData`: Metadata for Axis-Aligned Bounding Boxes (AABBs), including point offsets and counts for the global buffer [S1, unofficial].
Off-diagonal elements are zero, enforcing axis-aligned Gaussians [S1, unofficial].

### Steps
1.  **Verify Tiled Storage:** Ensure the VDB grid uses Tiled data storage to guarantee no data is omitted [S1, unofficial]. Skip leaf nodes excluded because they have a fixed value for every voxel; these are stored in the parent node's value mask [S1, unofficial].
2.  **Parallel Processing:** Process leaf nodes in parallel using Intel Thread Building Blocks (TBB) [S1, unofficial]. Each thread processes one leaf node, collecting data into its thread-local buffers [S1, unofficial].
3.  **Global Write:** Write collected Gaussian data to a global array using a mutex for safety [S1, unofficial].
4.  **Process Sparse Leaf Nodes:** Traverse all active voxels [S1, unofficial]. Initialize the bounding box to the dimensions of the starting voxel [S1, unofficial]. Iteratively expand the bounding box [S1, unofficial]. If no active voxels are found, exit early [S1, unofficial]. Calculate the minimum and maximum coordinates of the active bounding box in VDB index space ($bboxMin$, $bboxMax$) [S1, unofficial]. Transform the centroid of the active voxel region into world space to serve as the Gaussian position using $p_{world} = M \cdot p_{index}$ [S1, unofficial]. Average the opacity values of all active voxels to estimate overall opacity, optionally scaling the result to account for the Gaussian’s spatial extent [S1, unofficial]. Construct a diagonal covariance matrix from the radii [S1, unofficial]. The radii vector $\sigma$ is calculated as:
    $$ \sigma = \frac{1}{2} \cdot (bboxMax - bboxMin) \cdot voxelSize $$
    where $\sigma$ and $voxelSize$ are vectors of 3 floating-point values representing radii and voxel dimensions in each axis, respectively [S1, unofficial]. This defines an axis-aligned ellipsoid [S1, unofficial].
5.  **Process Dense Leaf Nodes:** Calculate the Gaussian center in world coordinates through its Index space bounding boxes [S1, unofficial]. For dense nodes, the bounding box corresponds to the leaf node's index space bounds [S1, unofficial]. If $voxelSize$ is isotropic, the resulting Gaussians are mostly spherical [S1, unofficial].
6.  **Store Parameters:** Store Gaussian parameters (position, opacity, covariance) and metadata for OptiX rendering in output buffers [S1, unofficial].

### Pseudocode
```python
import threading

global_gaussian_positions = []
global_gaussian_opacities = []
global_gaussian_covariances = []
global_mutex = threading.Lock()

def vec_min(a, b): return tuple(min(x, y) for x, y in zip(a, b))
def vec_max(a, b): return tuple(max(x, y) for x, y in zip(a, b))
def vec_add(a, b): return tuple(x + y for x, y in zip(a, b))
def vec_sub(a, b): return tuple(x - y for x, y in zip(a, b))
def vec_scale(v, s): return tuple(x * s for x in v)
def vec_sq(v): return tuple(x * x for x in v)

def process_leaf_node(leaf_node, grid_transform_matrix, voxel_size):
    local_positions = []
    local_opacities = []
    local_covariances = []

    if leaf_node.is_excluded_by_value_mask():
        return

    active_voxels = leaf_node.get_active_voxels()
    is_sparse = len(active_voxels) < 512

    if is_sparse:
        if not active_voxels:
            return

        bbox_min = active_voxels[0].index
        bbox_max = active_voxels[0].index

        for voxel in active_voxels:
            idx = voxel.index
            bbox_min = vec_min(bbox_min, idx)
            bbox_max = vec_max(bbox_max, idx)

        centroid_idx = vec_scale(vec_add(bbox_min, bbox_max), 0.5)
        centroid_world = grid_transform_matrix.transform(centroid_idx)

        opacity = sum(voxel.opacity for voxel in active_voxels) / len(active_voxels)

        radii = vec_scale(vec_sub(bbox_max, bbox_min), 0.5)
        radii = vec_scale(radii, voxel_size)
        variance = vec_sq(radii)

        local_positions.append(centroid_world)
        local_opacities.append(opacity)
        local_covariances.extend(variance)
    else:
        leaf_bbox_min = leaf_node.get_bbox_min_index()
        leaf_bbox_max = leaf_node.get_bbox_max_index()

        centroid_idx = vec_scale(vec_add(leaf_bbox_min, leaf_bbox_max), 0.5)
        centroid_world = grid_transform_matrix.transform(centroid_idx)

        opacity = leaf_node.get_representative_opacity()

        radii = vec_scale(vec_sub(leaf_bbox_max, leaf_bbox_min), 0.5)
        radii = vec_scale(radii, voxel_size)
        variance = vec_sq(radii)

        local_positions.append(centroid_world)
        local_opacities.append(opacity)
        local_covariances.extend(variance)

    with global_mutex:
        global_gaussian_positions.extend(local_positions)
        global_gaussian_opacities.extend(local_opacities)
        global_gaussian_covariances.extend(local_covariances)

def run_parallel_approximation(grid):
    leaf_nodes = grid.get_leaf_nodes()
    grid_transform = grid.get_transform_matrix()
    voxel_size = grid.get_voxel_size()

    threads = []
    for leaf in leaf_nodes:
        t = threading.Thread(target=process_leaf_node, args=(leaf, grid_transform, voxel_size))
        threads.append(t)
        t.start()

    for t in threads:
        t.join()

    return global_gaussian_positions, global_gaussian_opacities, global_gaussian_covariances
```

### Parameters and Edge Cases
*   **Voxel Size:** Must be provided [S1, unofficial]. If isotropic, Gaussians are spherical [S1, unofficial]. If anisotropic, they are ellipsoidal [S1, unofficial].
*   **Sparse Nodes with No Active Voxels:** The algorithm exits early and emits no Gaussian [S1, unofficial].
*   **Tiled Storage:** Essential for correctness [S1, unofficial]. Non-tiled grids may require different traversal logic [G].
*   **Precision:** Floating-point precision issues may arise when transforming index coordinates to world space for very large grids [G].

## Subtopics

### Medium LOD Approximation
A refinement level that subdivides leaf nodes into blocks to reduce detail while preserving volumetric distribution, using different algorithms for dense and sparse nodes [S1, unofficial]. For dense leaf nodes, it applies uniform spatial partitioning into non-overlapping $4 \times 4 \times 4$ blocks (64 voxels each), computing mean opacity and placing Gaussians at block centers [S1, unofficial]. For sparse leaf nodes, it attempts to form $2 \times 2 \times 2$ blocks of adjacent active voxels; if found, a Gaussian is emitted at the block centroid; otherwise, isolated active voxels are represented individually with half-voxel radii [S1, unofficial]. Choose this when higher fidelity than the single-leaf approximation is needed without the cost of High LOD [G].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of leaf nodes, $O(N_{leaves})$ [S1, unofficial]. Each leaf is processed once [S1, unofficial]. Sparse nodes require traversal of active voxels, proportional to the number of active voxels in the leaf [S1, unofficial].
*   **Memory Complexity:** Linear with respect to the number of generated Gaussians [S1, unofficial]. Each leaf node produces exactly one Gaussian primitive at the lowest LOD level [S1, unofficial].
*   **Performance:** Reduces rendering complexity significantly by clustering 512 voxels into one primitive [S1, unofficial]. Suitable for real-time rendering of large VDB datasets where spatial coherence is more important than fine detail [S1, unofficial].
*   **Strengths:** Simple implementation, low memory overhead, leverages existing VDB structure [G].
*   **Limitations:** Loses all internal detail of the leaf node [G]. Not suitable for scenes requiring high-frequency volumetric features [G].
*   **When to Use:** Low LOD rendering, distant views, or when computational resources are severely constrained [G].
*   **When Not to Use:** High LOD requirements, close-up views, or when internal density variations within a leaf node are significant [G].

## Background
The method originates from the study of 3D Gaussian particle approximation of VDB datasets for scientific visualization [S1, unofficial]. It was developed to enable efficient rendering of large volumetric datasets using ray tracing acceleration structures like OptiX GAS [S1, unofficial]. The approach utilizes Intel Thread Building Blocks (TBB) for parallel processing, which is a default backend for multi-threading in the OpenVDB library ecosystem [S1, unofficial].
