# Volume Texture Setup


## Overview
Volume Texture Setup initializes GPU-side 3D texture objects with specific memory formats, dimensions, and sampling parameters required for subsequent volume rendering passes. It solves the problem of preparing dense voxel grids or noise fields for GPU-accelerated raycasting by ensuring correct memory layout, alignment, and filtering behavior [S1, S2, unofficial]. It differs from [GPU Data Layout](2469-gpu-data-layout.md) by focusing on the OpenGL/WebGPU API object creation rather than raw memory buffers, and from [Trilinear Volume Sampling for Texture Generation](2726-trilinear-volume-sampling-for-texture-generation.md) by handling the texture object lifecycle rather than the interpolation logic.

## How it works
**Inputs:**
- Resolution settings for high-resolution and low-resolution noise fields (e.g., `settings.hiResNoise.resolution`, `settings.loResNoise.resolution`) [S1, unofficial].
- Texture file path (e.g., `"./LDR_LLL1_16.png"`) [S2, unofficial].
- Desired texture dimensions (e.g., 512x512) [S2, unofficial].

**Outputs:**
- Bound 3D texture objects (`volumeTexHighRes`, `volumeTexLowRes`) [S1, unofficial].
- Sampler objects with defined address and filter modes [S1, S2, unofficial].
- Texture views and bind groups ready for shader access [S2, unofficial].

**Data Structures:**
1. **High-Res Noise Texture:**
   - Format: `GL_RGBA32F` (OpenGL) or equivalent 32-bit float RGBA [S1, unofficial].
   - Dimensions: $D_{HiRes} \times D_{HiRes} \times D_{HiRes}$ [S1, unofficial].
   - Wrap Mode: `GL_REPEAT` on S, T, R axes [S1, unofficial].
   - Filter: `GL_LINEAR` for both magnification and minification [S1, unofficial].

2. **Low-Res Noise Texture:**
   - Format: `GL_RGBA32F` [S1, unofficial].
   - Dimensions: $D_{LoRes} \times D_{LoRes} \times D_{LoRes}$ [S1, unofficial].
   - Wrap Mode: `GL_REPEAT` on S, T, R axes [S1, unofficial].
   - Filter: `GL_LINEAR` for both magnification and minification [S1, unofficial].

3. **2D Sampler Texture (WebGPU variant):**
   - Format: `depth32float` or `rgba8unorm` [S2, unofficial].
   - Dimensions: $512 \times 512$ [S2, unofficial].
   - Address Modes: `repeat` for U and V [S2, unofficial].
   - Filters: `nearest` for magnification, minification, and mipmap [S2, unofficial].

**Steps:**
1. **Generate High-Res Texture:**
   - Create a 3D texture object.
   - Bind to texture unit `GL_TEXTURE0`.
   - Set wrap modes for S, T, R to `GL_REPEAT`.
   - Set magnification and minification filters to `GL_LINEAR`.
   - Allocate memory with format `GL_RGBA32F` and dimensions from `settings.hiResNoise.resolution` [S1, unofficial].

2. **Generate Low-Res Texture:**
   - Create a 3D texture object.
   - Bind to texture unit `GL_TEXTURE1`.
   - Set wrap modes for S, T, R to `GL_REPEAT`.
   - Set magnification and minification filters to `GL_LINEAR`.
   - Allocate memory with format `GL_RGBA32F` and dimensions from `settings.loResNoise.resolution` [S1, unofficial].

3. **Load 2D Texture (WebGPU Variant):**
   - Fetch texture data from file (e.g., `"./LDR_LLL1_16.png"`) [S2, unofficial].
   - Create a texture object with size $512 \times 512$ and format `depth32float` (or `rgba8unorm` for image data) [S2, unofficial].
   - Set usage flags to `RENDER_ATTACHMENT` and `TEXTURE_BINDING` [S2, unofficial].

4. **Create Sampler:**
   - Define address modes: `repeat` for U and V axes [S2, unofficial].
   - Define filter modes: `nearest` for magnification, minification, and mipmap [S2, unofficial].
   - For OpenGL variants, use `GL_LINEAR` filters as specified in steps 1-2 [S1, unofficial].

5. **Create Bind Groups/Views:**
   - Create texture views for the generated textures [S2, unofficial].
   - Create bind groups linking the texture views to shader binding points [S2, unofficial].

**Pseudocode:**
```python
def setup_volume_textures(settings, device, gl_context=None):
    """
    Sets up 3D noise textures for OpenGL or 2D textures for WebGPU.
    """
    if gl_context:
        # OpenGL Path
        # 1. High-Res Texture
        high_res_dim = settings.hiResNoise.resolution
        volumeTexHighRes = glCreateTexture(GL_TEXTURE_3D)
        glBindTexture(GL_TEXTURE_3D, volumeTexHighRes)
        glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_WRAP_S, GL_REPEAT)
        glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_WRAP_T, GL_REPEAT)
        glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_WRAP_R, GL_REPEAT)
        glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_MAG_FILTER, GL_LINEAR)
        glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_MIN_FILTER, GL_LINEAR)
        glTexImage3D(GL_TEXTURE_3D, 0, GL_RGBA32F, high_res_dim, high_res_dim, high_res_dim, 0, GL_RGBA, GL_FLOAT, None)
        glBindTexture(GL_TEXTURE_3D, 0)

        # 2. Low-Res Texture
        low_res_dim = settings.loResNoise.resolution
        volumeTexLowRes = glCreateTexture(GL_TEXTURE_3D)
        glBindTexture(GL_TEXTURE_3D, volumeTexLowRes)
        glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_WRAP_S, GL_REPEAT)
        glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_WRAP_T, GL_REPEAT)
        glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_WRAP_R, GL_REPEAT)
        glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_MAG_FILTER, GL_LINEAR)
        glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_MIN_FILTER, GL_LINEAR)
        glTexImage3D(GL_TEXTURE_3D, 0, GL_RGBA32F, low_res_dim, low_res_dim, low_res_dim, 0, GL_RGBA, GL_FLOAT, None)
        glBindTexture(GL_TEXTURE_3D, 0)

    else:
        # WebGPU Path
        # 1. Load 2D Texture
        texture_data = load_texture_from_file("./LDR_LLL1_16.png")
        shadowMap = device.createTexture({
            size: [512, 512],
            format: "depth32float",
            usage: GPUTextureUsage.RENDER_ATTACHMENT | GPUTextureUsage.TEXTURE_BINDING
        })
        
        # 2. Create Sampler
        sampler = device.createSampler({
            addressModeU: "repeat",
            addressModeV: "repeat",
            magFilter: "nearest",
            minFilter: "nearest",
            mipmapFilter: "nearest"
        })
        
        # 3. Create Bind Group
        shadowMapBindGroup = device.createBindGroup({
            layout: shadowMapPipeline.getBindGroupLayout(0),
            entries: [
                { binding: 0, resource: shadowMapUniformBuffer }
            ]
        })
```

**Parameters:**
- `settings.hiResNoise.resolution`: Integer, typical value not given in sources [S1, unofficial].
- `settings.loResNoise.resolution`: Integer, typical value not given in sources [S1, unofficial].
- Texture dimensions: 512x512 for 2D variants [S2, unofficial].

**Edge Cases:**
- Precision: `GL_RGBA32F` ensures high precision for noise values, preventing quantization artifacts [S1, unofficial].
- Boundaries: `GL_REPEAT` wrap mode handles out-of-bounds sampling by wrapping coordinates, which is critical for seamless noise generation [S1, unofficial].

## Subtopics

### [3D Texture Upload](4419-3d-texture-upload.md)
This method transfers classified volume data from host memory to GPU memory by populating an OpenGL `GL_TEXTURE_3D` object. It solves the problem of preparing dense voxel grids for GPU-accelerated raycasting or slicing by ensuring correct memory layout, alignment, and filtering parameters [G].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels for texture allocation and upload.
- **Memory Complexity:** Proportional to $D^3 \times 4$ bytes for `GL_RGBA32F` textures, where $D$ is the resolution [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales with resolution cubed; high-resolution textures consume significant VRAM.
- **Strengths:** High precision with 32-bit floats; seamless wrapping for infinite noise fields.
- **Limitations:** High memory usage for large volumes; requires careful management of texture units.
- **When to use:** When high-precision noise fields are needed for volumetric effects like clouds or smoke.
- **When not to use:** When memory is constrained or lower precision is acceptable.

## Background
Originated in real-time volumetric rendering applications, specifically for generating procedural noise fields for volumetric clouds [S1, unofficial]. Developed by Depersonalizc and Ne0nWinds for their respective volumetric rendering demos [S1, S2, unofficial].
