# Volume Texture Ping-Pong Swap

Also called: 3D Texture Field Manager, Double-Buffered Volume Upload

## Overview
Manages dynamic 3D scalar fields in GPU memory using a double-buffered ping-pong swap to avoid full re-uploads on field updates [S1, unofficial].

## How it works
**Inputs:** `field` (scalar data array), `float32Filterable` (boolean flag) [S1, unofficial].
**Outputs:** A 3D texture bound to a TSL sampling node [S1, unofficial].

**Data Structures:**
The manager maintains two `Data3DTexture` slots (ping-pong buffers). Each slot stores:
- `texture`: GPU texture handle.
- `data`: CPU-side array backing the texture (`Float32Array` or `Uint16Array`).
- `version`: Integer counter, incremented on each update to signal the shader to re-sample.
- `format`: `R32F` or `R16F`.
- `min`, `max`: Normalization bounds for the field.

**Steps:**
1. `createVolumeTexture(field, float32Filterable)`: Allocate the first `Data3DTexture` slot. If `float32Filterable` is true, set format to `R32F` (`FloatType`, `Float32Array`, `LinearFilter`); otherwise, fallback to `R16F` (`HalfFloatType`, `Uint16Array`). Compute `min` and `max` of the field data. If `min == max`, widen `max` by 1 to prevent division by zero during normalization. Replace non-finite values (NaN/Inf) with `min`; if all values are non-finite, use 0. Bind the texture to the TSL sampling node [S1, unofficial].
2. `setField(newField)`: If `newField.shape` differs from the current field shape, return `false` (caller must rebuild). Otherwise, swap to the inactive ping-pong slot. Copy `newField` data into the inactive slot. Bump the inactive slot's `version` property to trigger GPU re-upload. Update `node.value` to point to the inactive slot [S1, unofficial].
3. `dispose()`: Call `dispose()` on both ping-pong textures and clear VRAM ledger entries. Double disposal is idempotent [S1, unofficial].

**Parameters:**
- `float32Filterable`: boolean flag indicating if the GPU/backend supports linear filtering on 32-bit floats. Typical: `true` for Metal, `false` for fallback [S1, unofficial].

**Pitfalls:**
- Constant fields cause division by zero during normalization. Handled by widening `max` to `min + 1` [S1, unofficial].
- Non-finite samples (NaN/Inf) cause undefined behavior. Handled by replacing with finite `min`, or `0` if all values are non-finite [S1, unofficial].
- Shape mismatches during `setField` break the ping-pong buffer. Handled by rejecting the swap and returning `false` [S1, unofficial].

**Pseudocode:**
```python
import math

class VolumeTexturePingPongSwap:
    def __init__(self, field, float32_filterable):
        self.float32_filterable = float32_filterable
        self.slots = [None, None]
        self.active_slot_index = 0
        self.node_value = None
        self.create_texture(field)

    def create_texture(self, field):
        # Allocate first Data3DTexture slot
        self.slots[0] = {'data': None, 'version': 0, 'min': 0.0, 'max': 1.0, 'texture': None}
        
        # Determine format
        if self.float32_filterable:
            dtype_name = 'Float32Array'
            gl_format = 'R32F'
        else:
            dtype_name = 'Uint16Array'
            gl_format = 'R16F'
            
        # Handle non-finite values
        data = list(field)
        finite_vals = [v for v in data if math.isfinite(v)]
        if not finite_vals:
            data = [0.0] * len(data)
            min_val = 0.0
        else:
            min_val = min(finite_vals)
            data = [min_val if not math.isfinite(v) else v for v in data]
            
        max_val = max(data)
        if min_val == max_val:
            max_val = min_val + 1.0
            
        self.slots[0]['data'] = data
        self.slots[0]['min'] = min_val
        self.slots[0]['max'] = max_val
        self.slots[0]['version'] = 1
        
        # Upload data to GPU and bind to sampling node (standard driver operation)
        # upload_to_gpu(self.slots[0]['data'], gl_format)
        # bind_texture(self.slots[0]['texture'])
        self.node_value = self.slots[0]['texture']

    def set_field(self, new_field):
        # Check shape match
        if len(new_field) != len(self.slots[self.active_slot_index]['data']):
            return False
            
        # Swap to inactive slot
        inactive_index = 1 - self.active_slot_index
        if self.slots[inactive_index] is None:
            self.slots[inactive_index] = {'data': None, 'version': 0, 'min': 0.0, 'max': 1.0, 'texture': None}
            
        # Copy data into inactive slot
        self.slots[inactive_index]['data'] = list(new_field)
        self.slots[inactive_index]['version'] += 1
        
        # Trigger GPU re-upload and update node value
        # upload_to_gpu(self.slots[inactive_index]['data'], 'R32F' if self.float32_filterable else 'R16F')
        # bind_texture(self.slots[inactive_index]['texture'])
        self.node_value = self.slots[inactive_index]['texture']
        self.active_slot_index = inactive_index
        return True

    def dispose(self):
        for slot in self.slots:
            if slot is not None:
                # delete_gpu_texture(slot['texture'])
                pass
        self.slots = [None, None]
        self.node_value = None
```
