# Texture Array Loading
Also called: 2D Array Texture Creation
## Overview
This method assembles a list of 2D images into a single WebGL `gl.TEXTURE_2D_ARRAY` object for 3D coordinate sampling [S1, unofficial]. It solves the problem of mapping discrete image layers into a contiguous GPU texture buffer [S1, unofficial].

## How it works
**Inputs:**
- `urls`: An array of strings representing URLs to image files [S1, unofficial].
- `width`: Integer width of each individual texture layer [S1, unofficial].
- `height`: Integer height of each individual texture layer [S1, unofficial].

**Outputs:**
- A WebGL texture object bound to `gl.TEXTURE_2D_ARRAY`, containing `len(urls)` layers of size `width x height` [S1, unofficial].

**Data Structures:**
- `pixels`: A flat byte array storing RGBA data. Size is `width * height * 4 * len(urls)` bytes [S1, unofficial].
- `canvas`: An off-screen HTML Canvas element used for decoding images [G].

**Steps:**
1. Create a WebGL texture object and bind it to `gl.TEXTURE_2D_ARRAY` [S1, unofficial].
2. Initialize the texture with a 1x1x1 RGBA texture (magenta) to allocate GPU storage [S1, unofficial].
3. For each `url` in `urls`: load the image, create a canvas of size `width x height`, draw the image onto the canvas, extract pixel data using `ctx.getImageData`, flatten the data into a byte array, and append it to the `pixels` array [S1, unofficial].
4. Upload the complete `pixels` array to the texture using `texImage3D` with dimensions `width`, `height`, and `depth` equal to `len(urls)` [S1, unofficial].
5. Generate mipmaps [S1, unofficial].
6. Set the magnification filter to `gl.NEAREST` and the minification filter to `gl.NEAREST_MIPMAP_LINEAR` [S1, unofficial].

**Pseudocode:**
```python
def load_texture_array(gl, urls, width, height):
    texture = gl.createTexture()
    gl.bindTexture(gl.TEXTURE_2D_ARRAY, texture)
    # Allocate placeholder storage (1x1x1 RGBA magenta)
    gl.texImage3D(gl.TEXTURE_2D_ARRAY, 0, gl.RGBA, 1, 1, 1, 0, gl.RGBA, gl.UNSIGNED_BYTE, bytearray([255, 0, 255, 255]))
    pixels = bytearray()
    for url in urls:
        # [G] Standard browser image loading
        img = load_image_from_url(url)
        # [G] Standard off-screen canvas creation
        canvas = create_offscreen_canvas(width, height)
        ctx = canvas.getContext('2d')
        ctx.drawImage(img, 0, 0, width, height)
        pixels.extend(ctx.getImageData(0, 0, width, height).data)
    gl.texImage3D(gl.TEXTURE_2D_ARRAY, 0, gl.RGBA, width, height, len(urls), 0, gl.RGBA, gl.UNSIGNED_BYTE, pixels)
    gl.generateMipmap(gl.TEXTURE_2D_ARRAY)
    gl.texParameteri(gl.TEXTURE_2D_ARRAY, gl.TEXTURE_MIN_FILTER, gl.NEAREST_MIPMAP_LINEAR)
    gl.texParameteri(gl.TEXTURE_2D_ARRAY, gl.TEXTURE_MAG_FILTER, gl.NEAREST)
    return texture
```

**Parameters:**
- `width`: Width of individual layers [S1, unofficial].
- `height`: Height of individual layers [S1, unofficial].

## Subtopics

### [Dynamic Segment Texture Array Update](16688-dynamic-segment-texture-array-update.md)
A method for synchronizing GPU-side volumetric data with CPU-side segment definitions by rebuilding a texture array bound to shader uniforms. It solves the problem of efficiently mapping discrete, sparse voxel segments to a contiguous 3D texture array for rendering. It differs from standard volume rendering by treating the volume texture as a collection of independent 2D slices or bricks that are dynamically assembled, rather than as a monolithic 3D buffer.
