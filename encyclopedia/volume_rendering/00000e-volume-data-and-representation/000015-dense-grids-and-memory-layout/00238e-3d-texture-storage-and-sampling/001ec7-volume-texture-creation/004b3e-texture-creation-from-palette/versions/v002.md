# Texture Creation from Palette

Also called: FVox::CreateTexture, Palette Texture Setup with Endianness Reversal

## Overview
This method creates a 256×1 texture from a 1D palette array for volume rendering, handling the byte-order conversion required when the source data is stored as 32-bit integers [S2, unofficial]. It differs from general volume texture generation by mapping the palette to a 2D texture and explicitly addressing the endianness reversal pitfall where shader sRGB sampling relies on the specific R, G, B, A byte layout resulting from the little-endian interpretation of the reversed uint [S2, unofficial].

## How it works
**Inputs:**
- `Palette`: A 1D array of 32-bit unsigned integers (`uint[]`) representing color indices or RGBA values.
- `OutTexture`: A texture object instance to be populated.

**Outputs:**
- `OutTexture`: A fully initialized 2D texture ready for GPU binding.

**Data Structures:**
- `Palette`: `uint[]` of size 256.
- `OutTexture`: 2D texture with dimensions width 256, height 1, depth 1, layers 1, format `TSF_BGRA8` [S1, unofficial].

**Steps:**

1. **Initialize Texture Properties:**
   Set the texture metadata to ensure correct rendering and memory management:
   - `LODGroup`: Set to `TEXTUREGROUP_World`.
   - `CompressionSettings`: Set to `TC_Default`.
   - `MipGenSettings`: Set to `TMGS_NoMipmaps`.
   - `DeferCompression`: Set to `true` [S1, unofficial].

2. **Convert and Copy Memory:**
   Convert the `uint[]` palette data to a `byte[]` array using `MemoryMarshal.AsBytes` [S2, unofficial]. This relies on the little-endian byte order being R, G, B, A [S2, unofficial].

3. **Initialize Texture Source:**
   Configure the texture source with the following parameters:
   - Width: 256
   - Height: 1
   - Depth: 1
   - Layers: 1
   - Format: `TSF_BGRA8`
   - Data: The byte array from Step 2, derived from `Palette.GetData()` [S1, unofficial].

4. **Create and Bind Texture:**
   Create a 256×1 RGBA8 texture from the byte data and bind it to the shader as `palette` [S2, unofficial].

5. **Finalize Texture:**
   Call `OutTexture->UpdateResource()` and `OutTexture->PostEditChange()` [S1, unofficial].

**Pseudocode:**

```python
class Texture:
    def __init__(self):
        self.LODGroup = None
        self.CompressionSettings = None
        self.MipGenSettings = None
        self.DeferCompression = False
        self.Source = None
        self.Created = False
        self.Updated = False
        self.Edited = False

def reverse_uint(value: int) -> int:
    """Reverse the byte order of a 32-bit unsigned integer."""
    return ((value & 0xFF) << 24) | ((value & 0xFF00) << 8) | \
           ((value & 0xFF0000) >> 8) | ((value & 0xFF000000) >> 24)

def create_palette_texture(palette_uints: list[int]) -> Texture:
    """
    Creates a 256x1 RGBA8 texture from a 256-element uint palette,
    handling endianness reversal and byte packing for sRGB shader reading.
    """
    # Step 1: Initialize Texture Properties
    texture = Texture()
    texture.LODGroup = "TEXTUREGROUP_World"
    texture.CompressionSettings = "TC_Default"
    texture.MipGenSettings = "TMGS_NoMipmaps"
    texture.DeferCompression = True
    
    # Step 2: Convert and Copy Memory
    # Reverse endianness of each uint, then pack into bytes in little-endian order (R, G, B, A)
    byte_data = bytearray()
    for u in palette_uints:
        rev = reverse_uint(u)
        byte_data.append(rev & 0xFF)          # R
        byte_data.append((rev >> 8) & 0xFF)   # G
        byte_data.append((rev >> 16) & 0xFF)  # B
        byte_data.append((rev >> 24) & 0xFF)  # A
        
    # Step 3: Initialize Texture Source
    texture.Source = {
        "Width": 256,
        "Height": 1,
        "Depth": 1,
        "Layers": 1,
        "Format": "TSF_BGRA8",
        "Data": bytes(byte_data)
    }
    
    # Step 4: Create and Bind Texture
    # Create 256x1 RGBA8 texture from byte_data
    texture.Created = True
    # Bind to shader as 'palette' (runtime step)
    
    # Step 5: Finalize Texture
    texture.Updated = True
    texture.Edited = True
    
    return texture
```

**Parameters:**
- Palette Size: 256 entries [S1, unofficial].
- Texture Dimensions: 256×1 [S1, unofficial].
- Format: `TSF_BGRA8` [S1, unofficial] / RGBA8 [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Endianness Mismatch:** The endianness reversal and the raw byte copy must be changed together [S2, unofficial]. Failure to align these results in incorrect color channels [S2, unofficial].
- **sRGB Interpretation:** The shader reads the texture as sRGB and relies on the specific byte order (R, G, B, A) resulting from the little-endian interpretation of the reversed uint [S2, unofficial].

## Subtopics

### Voxel Material Palette Texture Upload
This variant initializes a `std::vector<glm::vec4>` of size 65536 filled with magenta `{1.0F, 0.0F, 1.0F, 1.0F}` to represent non-existent materials [S3, unofficial]. It iterates over `voxelPalette->data()`, and for each index `i`, if `voxelPalette->data()[i].similarity(VoxelMaterial::Empty) < 1.0F`, it assigns `data[i + 1] = voxelPalette->data()[i].color` [S3, unofficial]. The vector is then uploaded to the GPU texture at coordinates `(0, 0, 256, 256)` [S3, unofficial]. Parameters specify a 256×256 texture with RGBA32Float format [S3, unofficial]. A pitfall is that palette indices are offset by +1 in the texture array (`data[i + 1]`), leaving index 0 unused or reserved for empty/invalid materials [S3, unofficial].
