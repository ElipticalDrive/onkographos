# ClearView Unified Buffer Construction

Also called: ClearView Buffer Construction

## Overview
ClearView Unified Buffer Construction is a preprocessing technique that converts a hexahedral mesh (positions, connectivity, and scalar data) into four GPU-friendly 2D texture buffers optimized for the ClearView volume rendering pipeline [S1, unofficial]. It enables efficient gather and resolve passes by mapping topological elements (vertices, edges, faces) and cell attributes into linearized texture layouts, distinguishing itself from standard 3D texture storage by utilizing 2D textures for topology mapping [S1, unofficial].

## How it works
**Inputs**: Hexahedral mesh defined by vertex positions, cell connectivity (8 corners per cell), face definitions (4 corners, 4 edges per face), and scalar values at each vertex.
**Outputs**: Four 2D textures: `verticesTex` (not explicitly detailed in layout notes but implied by topology mapping), `edgesTex`, `facesTex`, and `cellScalarTex`.

**Data Structures and Layout**:
1.  **Edges Texture (`edgesTex`)**:
    *   Format: `RG32F` (Float32Array).
    *   Dimensions: Width and Height determined by `texDims(edgeCount)`.
    *   Layout: 1 texel = 2 floats.
    *   Indexing: Linear index `linear = c * 12 + e`, where `c` is cell index and `e` is edge index (0-11). Column `col = linear % width`, Row `row = floor(linear / width)`. Texel index `ti = (row * width + col) * 2`.
    *   Values: `edgesTex[ti] = max(scalars[pia], scalars[pib])` (attribute), `edgesTex[ti+1] = 1 - normScalar` (LOD).
2.  **Faces Texture (`facesTex`)**:
    *   Format: `RG32UI` (Uint32Array).
    *   Dimensions: Width = 2, Height = `faceCount`.
    *   Layout: 2 texels per face.
    *   Indexing: `faceId = c * 6 + f`. Linear texel index `t0linear = faceId * 2 + 0`, `t1linear = faceId * 2 + 1`. Column `col = tlinear % width`, Row `row = floor(tlinear / width)`. Texel index `ti = (row * width + col) * 4`.
    *   Values:
        *   Texel 0 (Vertex Indices): `.r`, `.g`, `.b`, `.a` store `c*8 + face.corners[0..3]`.
        *   Texel 1 (Edge Indices): `.r`, `.g`, `.b`, `.a` store `c*12 + face.edges[0..3]`.
3.  **Cell Scalar Texture (`cellScalarTex`)**:
    *   Format: `R32F` (Float32Array).
    *   Dimensions: Width and Height determined by `texDims(faceCount)`.
    *   Layout: 1 texel per face.
    *   Indexing: Linear index `faceId = c * 6 + f`. Column `col = faceId % width`, Row `row = floor(faceId / width)`.
    *   Values: `cellScalarTex[row * width + col] = cellScalarAvg`.

**Steps**:
1.  **Compute Scalar Range**:
    *   $s_{min} = \min(\text{mesh.scalars})$
    *   $s_{max} = \max(\text{mesh.scalars})$
    *   $s_{range} = \max(s_{max} - s_{min}, 10^{-9})$ [S1, unofficial].
2.  **Compute Edge LOD**:
    *   For each cell $c$:
        *   $cellScalarAvg = \frac{\sum_{i=0}^{7} scalars[\text{corners}_i]}{8}$
        *   $normScalar = \frac{cellScalarAvg - s_{min}}{s_{range}}$
        *   $edgeLod = 1 - normScalar$ [S1, unofficial].
3.  **Populate Edges Texture**:
    *   For each cell $c$ and edge $e$:
        *   Calculate linear index and texel position.
        *   Store max scalar of edge endpoints in attribute channel.
        *   Store $edgeLod$ in LOD channel [S1, unofficial].
4.  **Populate Faces Texture**:
    *   For each cell $c$ and face $f$:
        *   Calculate `faceId`.
        *   Store vertex indices (relative to cell start) in Texel 0.
        *   Store edge indices (relative to cell start) in Texel 1 [S1, unofficial].
5.  **Populate Cell Scalar Texture**:
    *   For each cell $c$ and face $f$:
        *   Calculate `faceId`.
        *   Store $cellScalarAvg$ in the texel [S1, unofficial].

**Pseudocode**:
```python
def clearview_buffer_construction(mesh):
    # 1. Compute Scalar Range
    s_min = min(mesh.scalars)
    s_max = max(mesh.scalars)
    s_range = max(s_max - s_min, 1e-9)

    # Precompute cell scalar averages and LOD
    cell_data = []
    for c in mesh.cells:
        corners = c.corners # indices 0-7
        cell_avg = sum(mesh.scalars[corners[i]] for i in range(8)) / 8.0
        norm_scalar = (cell_avg - s_min) / s_range
        edge_lod = 1.0 - norm_scalar
        cell_data.append({
            'avg': cell_avg,
            'lod': edge_lod,
            'corners': corners,
            'faces': c.faces # list of 6 faces, each with 4 corners, 4 edges
        })

    # 2. Build Edges Texture
    edge_count = len(mesh.cells) * 12
    edges_tex = allocate_texture_2d_rg32f(edge_count)
    width_e = tex_dims(edge_count)[0]
    
    for c_idx, c_data in enumerate(cell_data):
        for e_idx in range(12):
            linear = c_idx * 12 + e_idx
            col = linear % width_e
            row = linear // width_e
            ti = (row * width_e + col) * 2
            
            # Get endpoints for this edge (simplified indexing logic)
            # Note: Exact endpoint mapping depends on HEX_FACES[e] definition
            # Assuming edge e connects two vertices from the cell's 8 corners
            p_a, p_b = get_edge_vertices(c_data['corners'], e_idx)
            attr = max(mesh.scalars[p_a], mesh.scalars[p_b])
            
            edges_tex[ti] = attr
            edges_tex[ti + 1] = c_data['lod']

    # 3. Build Faces Texture
    face_count = len(mesh.cells) * 6
    faces_tex = allocate_texture_2d_rg32ui(face_count, 2) # Width=2, Height=face_count
    
    for c_idx, c_data in enumerate(cell_data):
        for f_idx in range(6):
            face_id = c_idx * 6 + f_idx
            face = c_data['faces'][f_idx]
            
            # Texel 0: Vertex Indices
            t0_linear = face_id * 2 + 0
            col = t0_linear % 2
            row = t0_linear // 2
            ti = (row * 2 + col) * 4
            
            faces_tex[ti + 0] = c_idx * 8 + face.corners[0]
            faces_tex[ti + 1] = c_idx * 8 + face.corners[1]
            faces_tex[ti + 2] = c_idx * 8 + face.corners[2]
            faces_tex[ti + 3] = c_idx * 8 + face.corners[3]
            
            # Texel 1: Edge Indices
            t1_linear = face_id * 2 + 1
            col = t1_linear % 2
            row = t1_linear // 2
            ti = (row * 2 + col) * 4
            
            faces_tex[ti + 0] = c_idx * 12 + face.edges[0]
            faces_tex[ti + 1] = c_idx * 12 + face.edges[1]
            faces_tex[ti + 2] = c_idx * 12 + face.edges[2]
            faces_tex[ti + 3] = c_idx * 12 + face.edges[3]

    # 4. Build Cell Scalar Texture
    cell_scalar_tex = allocate_texture_2d_r32f(face_count)
    width_cs = tex_dims(face_count)[0]
    
    for c_idx, c_data in enumerate(cell_data):
        for f_idx in range(6):
            face_id = c_idx * 6 + f_idx
            col = face_id % width_cs
            row = face_id // width_cs
            cell_scalar_tex[row * width_cs + col] = c_data['avg']

    return edges_tex, faces_tex, cell_scalar_tex
```

**Parameters**:
*   `s_range` minimum: $10^{-9}$ [S1, unofficial].
*   Focus sphere radius modulation: `focusMask = pow(focusT, 4.0)` where `focusT = clamp(distance(p, sphereCenter) / sphereRadius, 0, 1)` [S1, unofficial].

**Edge Cases and Pitfalls**:
*   Division by zero in scalar normalization is prevented by clamping `s_range` to $10^{-9}$ [S1, unofficial].
*   Texture dimensions must be computed using `texDims` to ensure proper linear indexing [S1, unofficial].
*   Requires WebGL2 support for `uimage2D` and `atomic_uint` for the full PPLL pipeline; otherwise, fallback to ray-march alpha modulation is used [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of cells and faces, $O(N_c \times 18)$ for edges and faces, plus $O(N_c \times 6)$ for cell scalars.
*   **Memory Complexity**: Proportional to the number of edges, faces, and cells. Specifically, 2 floats per edge, 8 uints per face, 1 float per cell-face pair.
*   **Strengths**: Optimizes gather/resolve passes by pre-computing topological relationships and LOD values in texture formats directly consumable by shaders [S1, unofficial].
*   **Limitations**: Requires specific GPU features (image load/store) for the primary pipeline; fallback mode has different performance characteristics [S1, unofficial].
*   **When to use**: When rendering hexahedral meshes with ClearView's focus+context visualization and gather/resolve passes [S1, unofficial].
*   **When not to use**: When hardware lacks required WebGL2 features and fallback is insufficient, or for non-hexahedral topologies not supported by the specific face/edge indexing [S1, unofficial].

## Background
The ClearView Unified Buffer Construction method originates from the `geresim-spike` project, an unofficial implementation of the ClearView volume rendering technique [S1, unofficial]. It was developed to optimize the visualization of hexahedral meshes by mapping topology to 2D textures, enabling efficient screen-space operations like focus control and context modulation [S1, unofficial].
