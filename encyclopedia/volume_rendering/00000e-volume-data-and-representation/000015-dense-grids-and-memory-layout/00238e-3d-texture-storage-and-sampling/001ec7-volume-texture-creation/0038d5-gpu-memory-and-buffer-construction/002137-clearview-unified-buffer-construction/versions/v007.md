# ClearView Unified Buffer Construction

Also called: ClearView Buffer Construction

## Overview
ClearView Unified Buffer Construction is a preprocessing technique that converts a hexahedral mesh (positions, connectivity, and scalar values) into four GPU-friendly texture buffers—vertices, edges, faces, and cell scalars—optimized for the ClearView volume rendering pipeline [S1, unofficial]. It differs from standard volume texture creation by explicitly linearizing hexahedral topology (faces and edges) into 2D texture arrays to facilitate efficient fragment-based rendering and focus-control masking, rather than relying on 3D voxel grids or sparse structures [S1, unofficial].

## How it works
**Inputs:**
- Hexahedral mesh geometry: `positions` (array of 3D coordinates), `scalars` (array of scalar values per vertex).
- Mesh topology: implicit hexahedral connectivity (cells composed of 8 vertices and 12 edges).
- Camera parameters: `fov` (field of view in degrees), `viewportSize` (width, height).

**Outputs:**
- `vertexTex`: Texture containing vertex positions (implied by context, though specific layout not detailed in source snippets, standard vertex buffers are typically used for position).
- `edgeTex`: Texture containing edge attributes and Level-of-Detail (LOD) values.
- `facesTex`: Texture containing face vertex indices and edge indices.
- `cellScalarTex`: Texture containing average scalar values per face.

**Data Structures and Layouts:**

1.  **Edge Texture (`edgeTex`)**
    -   **Format**: `RG32F` (two 32-bit floating-point components).
    -   **Dimensions**: Width and Height determined by `texDims(edgeCount)`.
    -   **Layout**: Linear index `linear = c * 12 + e` for cell `c` and edge `e`.
    -   **Texel Index**: `ti = (row * width + col) * 2`, where `col = linear % width`, `row = floor(linear / width)`.
    -   **Values**:
        -   `edgeTex[ti]`: Maximum scalar value of the two vertices defining the edge (`max(scalars[pia], scalars[pib])`).
        -   `edgeTex[ti+1]`: LOD value (`1 - normScalar`).

2.  **Face Texture (`facesTex`)**
    -   **Format**: `RG32UI` (two 32-bit unsigned integer components).
    -   **Dimensions**: Width = 2, Height = `faceCount`.
    -   **Layout**: 2 texels per face.
        -   Texel 0: Vertex indices.
        -   Texel 1: Edge indices.
    -   **Linear Texel Index**: `t0linear = faceId * 2 + 0`, `t1linear = faceId * 2 + 1`, where `faceId = c * 6 + f`.
    -   **Texel Index**: `ti = (row * width + col) * 4`, where `col = tlinear % width`, `row = floor(tlinear / width)`.
    -   **Values**:
        -   `facesTex[ti+0..3]`: Vertex indices (`c*8 + face.corners[0..3]`).
        -   `facesTex[ti+4..7]`: Edge indices (`c*12 + face.edges[0..3]`).

3.  **Cell Scalar Texture (`cellScalarTex`)**
    -   **Format**: `R32F` (one 32-bit floating-point component).
    -   **Dimensions**: Width and Height determined by `texDims(faceCount)`.
    -   **Layout**: 1 texel per face.
    -   **Linear Index**: `faceId = c * 6 + f`.
    -   **Texel Index**: `ti = row * width + col`, where `col = faceId % width`, `row = floor(faceId / width)`.
    -   **Values**: `cellScalarTex[ti] = cellScalarAvg`.

**Algorithm Steps:**

1.  **Compute Scalar Range**:
    Calculate the minimum and maximum scalar values in the mesh.
    $$ s_{min} = \min(\text{mesh.scalars}) $$
    $$ s_{max} = \max(\text{mesh.scalars}) $$
    $$ s_{range} = \max(s_{max} - s_{min}, 10^{-9}) $$

2.  **Compute Edge LOD**:
    For each cell, calculate the average scalar value of its 8 corners.
    $$ \text{cellScalarAvg} = \frac{\sum_{i=0}^{7} \text{scalars}[\text{corners}_i]}{8} $$
    Normalize this average against the global range.
    $$ \text{normScalar} = \frac{\text{cellScalarAvg} - s_{min}}{s_{range}} $$
    The LOD value for edges associated with this cell is derived as:
    $$ \text{edgeLod} = 1 - \text{normScalar} $$

3.  **Populate Face Texture**:
    For each cell `c` and each of its 6 faces `f`:
    -   Calculate `faceId = c * 6 + f`.
    -   Retrieve the face definition `face = HEX_FACES[f]`.
    -   Store vertex indices in Texel 0: `c*8 + face.corners[0..3]`.
    -   Store edge indices in Texel 1: `c*12 + face.edges[0..3]`.

4.  **Populate Edge Texture**:
    For each cell `c` and each of its 12 edges `e`:
    -   Calculate linear index `linear = c * 12 + e`.
    -   Determine row and column based on texture width.
    -   Store the maximum scalar of the edge's two vertices in the first component.
    -   Store the `edgeLod` (computed in Step 2) in the second component.

5.  **Populate Cell Scalar Texture**:
    For each cell `c` and face `f`:
    -   Calculate `faceId = c * 6 + f`.
    -   Store `cellScalarAvg` (computed in Step 2) in the corresponding texel.

**Pseudocode:**

```python
def clearview_buffer_construction(mesh):
    # mesh.positions: list of [x, y, z]
    # mesh.scalars: list of float values per vertex
    # mesh.cells: list of [v0, v1, v2, v3, v4, v5, v6, v7]
    
    # 1. Compute Scalar Range
    s_min = min(mesh.scalars)
    s_max = max(mesh.scalars)
    s_range = max(s_max - s_min, 1e-9)
    
    # 2. Precompute Cell Scalar Averages and LODs
    cell_data = []
    for cell_verts in mesh.cells:
        cell_scalars = [mesh.scalars[v] for v in cell_verts]
        cell_avg = sum(cell_scalars) / 8.0
        norm_scalar = (cell_avg - s_min) / s_range
        edge_lod = 1.0 - norm_scalar
        cell_data.append({
            'avg': cell_avg,
            'lod': edge_lod,
            'verts': cell_verts
        })
        
    # 3. Define Hexahedral Topology Constants
    # 6 faces per cell, 4 vertices and 4 edges per face
    # 12 edges per cell
    HEX_FACES = [
        # Face 0: corners 0,1,2,3; edges 0,1,2,3
        {'corners': [0, 1, 2, 3], 'edges': [0, 1, 2, 3]},
        # Face 1: corners 4,5,6,7; edges 8,9,10,11
        {'corners': [4, 5, 6, 7], 'edges': [8, 9, 10, 11]},
        # Face 2: corners 0,1,5,4; edges 0,4,8,7
        {'corners': [0, 1, 5, 4], 'edges': [0, 4, 8, 7]},
        # Face 3: corners 2,3,7,6; edges 2,5,10,9
        {'corners': [2, 3, 7, 6], 'edges': [2, 5, 10, 9]},
        # Face 4: corners 0,3,7,4; edges 3,6,11,7
        {'corners': [0, 3, 7, 4], 'edges': [3, 6, 11, 7]},
        # Face 5: corners 1,2,6,5; edges 1,4,9,8
        {'corners': [1, 2, 6, 5], 'edges': [1, 4, 9, 8]}
    ]
    
    # Edge vertex mapping for each cell (12 edges)
    # Edge 0: v0-v1, Edge 1: v1-v2, Edge 2: v2-v3, Edge 3: v3-v0
    # Edge 4: v0-v4, Edge 5: v1-v5, Edge 6: v2-v6, Edge 7: v3-v7
    # Edge 8: v4-v5, Edge 9: v5-v6, Edge 10: v6-v7, Edge 11: v7-v4
    HEX_EDGE_VERTS = [
        (0, 1), (1, 2), (2, 3), (3, 0),
        (0, 4), (1, 5), (2, 6), (3, 7),
        (4, 5), (5, 6), (6, 7), (7, 4)
    ]
    
    num_cells = len(mesh.cells)
    num_faces = num_cells * 6
    num_edges = num_cells * 12
    
    # Helper to calculate texture dimensions
    def tex_dims(count):
        # Simple square approximation for 2D texture
        dim = int(math.ceil(math.sqrt(count)))
        return dim, dim
        
    # 4. Build Edge Texture
    edge_width, edge_height = tex_dims(num_edges)
    edge_tex = [0.0] * (edge_width * edge_height * 2) # RG32F
    
    for c in range(num_cells):
        cell = mesh.cells[c]
        lod = cell_data[c]['lod']
        for e in range(12):
            linear_idx = c * 12 + e
            v1_idx, v2_idx = HEX_EDGE_VERTS[e]
            vert1 = cell[v1_idx]
            vert2 = cell[v2_idx]
            
            max_scalar = max(mesh.scalars[vert1], mesh.scalars[vert2])
            
            col = linear_idx % edge_width
            row = linear_idx // edge_width
            ti = (row * edge_width + col) * 2
            
            edge_tex[ti] = max_scalar
            edge_tex[ti+1] = lod
            
    # 5. Build Face Texture
    face_width = 2
    face_height = num_faces
    faces_tex = [0] * (face_width * face_height * 4) # RG32UI
    
    for c in range(num_cells):
        cell = mesh.cells[c]
        cell_verts = cell_data[c]['verts']
        
        for f in range(6):
            face_id = c * 6 + f
            face_def = HEX_FACES[f]
            
            # Vertex indices
            v_indices = [cell_verts[face_def['corners'][i]] for i in range(4)]
            # Edge indices (global edge index = c*12 + local edge index)
            e_indices = [c * 12 + face_def['edges'][i] for i in range(4)]
            
            # Texel 0: Vertices
            t0_linear = face_id * 2 + 0
            col = t0_linear % face_width
            row = t0_linear // face_width
            ti = (row * face_width + col) * 4
            
            faces_tex[ti+0] = v_indices[0]
            faces_tex[ti+1] = v_indices[1]
            faces_tex[ti+2] = v_indices[2]
            faces_tex[ti+3] = v_indices[3]
            
            # Texel 1: Edges
            t1_linear = face_id * 2 + 1
            col = t1_linear % face_width
            row = t1_linear // face_width
            ti = (row * face_width + col) * 4
            
            faces_tex[ti+0] = e_indices[0]
            faces_tex[ti+1] = e_indices[1]
            faces_tex[ti+2] = e_indices[2]
            faces_tex[ti+3] = e_indices[3]
            
    # 6. Build Cell Scalar Texture
    scalar_width, scalar_height = tex_dims(num_faces)
    cell_scalar_tex = [0.0] * (scalar_width * scalar_height) # R32F
    
    for c in range(num_cells):
        for f in range(6):
            face_id = c * 6 + f
            avg = cell_data[c]['avg']
            
            col = face_id % scalar_width
            row = face_id // scalar_width
            ti = row * scalar_width + col
            
            cell_scalar_tex[ti] = avg
            
    return {
        'edgeTex': edge_tex,
        'facesTex': faces_tex,
        'cellScalarTex': cell_scalar_tex,
        'sMin': s_min,
        'sMax': s_max
    }
```

**Parameters and Edge Cases:**
-   **Scalar Range Floor**: `s_range` is clamped to a minimum of $10^{-9}$ to prevent division by zero if all scalar values are identical [S1, unofficial].
-   **Texture Dimensions**: The source uses a helper `texDims` to determine width and height for non-square textures (edges, scalars). The exact implementation of `texDims` is not provided, but it must ensure the texture can hold all elements [S1, unofficial].
-   **Indexing**: All indices are 0-based. Vertex indices are global vertex IDs. Edge indices are global edge IDs (calculated as `c*12 + e`).

## Operating characteristics
-   **Time Complexity**: $O(N)$ where $N$ is the number of cells, as each cell, face, and edge is processed a constant number of times.
-   **Memory Complexity**: $O(N)$ for the four texture buffers. The memory footprint is proportional to the number of faces and edges.
-   **Performance**: The linearization into 2D textures allows for efficient GPU sampling during the rendering passes (gather and resolve) [S1, unofficial].
-   **Strengths**: Explicit control over memory layout; optimized for hexahedral meshes; facilitates focus-control visualization by providing scalar and LOD data per face/edge [S1, unofficial].
-   **Limitations**: Specific to hexahedral meshes; requires preprocessing step; texture dimensions may not be powers of two, which can affect some GPU hardware optimizations (though modern GPUs handle this well) [S1, unofficial].

## Background
ClearView Unified Buffer Construction is part of the ClearView volume rendering pipeline, specifically designed for the "geresim" spike implementation [S1, unofficial]. It was developed to enable efficient fragment-based rendering and focus-control masking on hexahedral meshes using WebGL2 [S1, unofficial]. The technique bridges the gap between logical hexahedral topology and GPU texture resources, allowing for advanced visualization features like focus spheres that modulate opacity based on distance to a center point [S1, unofficial].
