# ClearView Unified Buffer Construction

Also called: ClearView Buffer Construction

## Overview
ClearView Unified Buffer Construction is a preprocessing technique that converts a hexahedral mesh (positions, connectivity, scalars) into four GPU-friendly 2D texture buffers (vertices, edges, faces, cellScalar) for the ClearView volume rendering pipeline [S1, unofficial]. It maps topological elements and cell attributes into linearized 2D texture layouts rather than standard 3D volumetric textures [S1, unofficial].

## How it works
**Inputs**: Hexahedral mesh defined by vertex positions, cell connectivity (8 corners per cell), face definitions (4 corners, 4 edges per face), and scalar values at each vertex [S1, unofficial].
**Outputs**: Four 2D textures: `verticesTex`, `edgesTex`, `facesTex`, and `cellScalarTex` [S1, unofficial].

**Data Structures and Layout**:
1.  **Edges Texture (`edgesTex`)**:
    *   Format: `RG32F` (Float32Array) [S1, unofficial].
    *   Dimensions: Width and height determined by `texDims(edgeCount)` [S1, unofficial].
    *   Layout: 1 texel = 2 floats = (attribute, LOD) [S1, unofficial].
    *   Indexing: Linear index `linear = c * 12 + e`, where `c` is cell index and `e` is edge index (0–11). Column `col = linear % width`, Row `row = floor(linear / width)`. Texel index `ti = (row * width + col) * 2` [S1, unofficial].
    *   Values: `edgesTex[ti] = max(scalars[pia], scalars[pib])`, `edgesTex[ti+1] = 1 - normScalar` [S1, unofficial].
2.  **Faces Texture (`facesTex`)**:
    *   Format: `RG32UI` (Uint32Array) [S1, unofficial].
    *   Dimensions: Width = 2, Height = `faceCount` [S1, unofficial].
    *   Layout: 2 texels per face [S1, unofficial].
    *   Indexing: `faceId = c * 6 + f`. Linear texel index `t0linear = faceId * 2 + 0`, `t1linear = faceId * 2 + 1`. Column `col = tlinear % width`, Row `row = floor(tlinear / width)`. Texel index `ti = (row * width + col) * 4` [S1, unofficial].
    *   Values: Texel 0 (Vertex Indices): `.r`, `.g`, `.b`, `.a` store `c*8 + face.corners[0..3]`. Texel 1 (Edge Indices): `.r`, `.g`, `.b`, `.a` store `c*12 + face.edges[0..3]` [S1, unofficial].
3.  **Cell Scalar Texture (`cellScalarTex`)**:
    *   Format: `R32F` (Float32Array) [S1, unofficial].
    *   Dimensions: Width and height determined by `texDims(faceCount)` [S1, unofficial].
    *   Layout: 1 texel per face [S1, unofficial].
    *   Indexing: Linear index `faceId = c * 6 + f`. Column `col = faceId % width`, Row `row = floor(faceId / width)` [S1, unofficial].
    *   Values: `cellScalarTex[row * width + col] = cellScalarAvg` [S1, unofficial].

**Steps**:
1.  **Compute Scalar Range**: $s_{min} = \min(\text{mesh.scalars})$, $s_{max} = \max(\text{mesh.scalars})$, $s_{range} = \max(s_{max} - s_{min}, 10^{-9})$ [S1, unofficial].
2.  **Compute Edge LOD**: For each cell $c$: $cellScalarAvg = \frac{\sum_{i=0}^{7} scalars[\text{corners}_i]}{8}$, $normScalar = \frac{cellScalarAvg - s_{min}}{s_{range}}$, $edgeLod = 1 - normScalar$ [S1, unofficial].
3.  **Populate Edges Texture**: For each cell $c$ and edge $e$: calculate linear index and texel position, store $\max(scalars[pia], scalars[pib])$ in the attribute channel, store $edgeLod$ in the LOD channel [S1, unofficial].
4.  **Populate Faces Texture**: For each cell $c$ and face $f$: calculate `faceId`, store vertex indices in Texel 0, store edge indices in Texel 1 [S1, unofficial].
5.  **Populate Cell Scalar Texture**: For each cell $c$ and face $f$: calculate `faceId`, store $cellScalarAvg$ in the texel [S1, unofficial].

**Pseudocode**:
```python
import math

def clearview_buffer_construction(mesh):
    # 1. Compute Scalar Range
    s_min = min(mesh.scalars)
    s_max = max(mesh.scalars)
    s_range = max(s_max - s_min, 1e-9)

    # Precompute cell scalar averages and LOD
    cell_data = []
    for c_idx, c in enumerate(mesh.cells):
        corners = c.corners # indices 0-7
        cell_avg = sum(mesh.scalars[corners[i]] for i in range(8)) / 8.0
        norm_scalar = (cell_avg - s_min) / s_range
        edge_lod = 1.0 - norm_scalar
        cell_data.append({
            'avg': cell_avg,
            'lod': edge_lod,
            'corners': corners,
            'faces': c.faces # list of 6 faces, each with 4 corners, 4 edges
        })

    # Helper: compute 2D texture dimensions from element count
    def tex_dims(n):
        width = int(math.ceil(math.sqrt(n)))
        height = int(math.ceil(n / width))
        return width, height

    # Helper: allocate texture arrays
    def alloc_rg32f(n): return [0.0] * (n * 2)
    def alloc_rg32ui(n, w): return [0] * (n * 2 * 4) # 2 texels per face, 4 components each
    def alloc_r32f(n): return [0.0] * n

    # Standard hexahedron edge connectivity (0-11)
    HEX_EDGES = [[0,1], [1,5], [5,4], [4,0], [2,3], [3,7], [7,6], [6,2], [0,2], [1,3], [4,6], [5,7]]

    # 2. Build Edges Texture
    edge_count = len(mesh.cells) * 12
    edges_tex = alloc_rg32f(edge_count)
    width_e, height_e = tex_dims(edge_count)

    for c_idx, c_data in enumerate(cell_data):
        for e_idx in range(12):
            linear = c_idx * 12 + e_idx
            col = linear % width_e
            row = linear // width_e
            ti = (row * width_e + col) * 2

            p_a, p_b = HEX_EDGES[e_idx]
            attr = max(mesh.scalars[c_data['corners'][p_a]], mesh.scalars[c_data['corners'][p_b]])

            edges_tex[ti] = attr
            edges_tex[ti + 1] = c_data['lod']

    # 3. Build Faces Texture
    face_count = len(mesh.cells) * 6
    faces_tex = alloc_rg32ui(face_count, 2)

    for c_idx, c_data in enumerate(cell_data):
        for f_idx in range(6):
            face_id = c_idx * 6 + f_idx
            face = c_data['faces'][f_idx]

            # Texel 0: Vertex Indices
            t0_linear = face_id * 2 + 0
            col = t0_linear % 2
            row = t0_linear // 2
            ti = (row * 2 + col) * 4

            faces_tex[ti + 0] = c_idx * 8 + face.corners[0]
            faces_tex[ti + 1] = c_idx * 8 + face.corners[1]
            faces_tex[ti + 2] = c_idx * 8 + face.corners[2]
            faces_tex[ti + 3] = c_idx * 8 + face.corners[3]

            # Texel 1: Edge Indices
            t1_linear = face_id * 2 + 1
            col = t1_linear % 2
            row = t1_linear // 2
            ti = (row * 2 + col) * 4

            faces_tex[ti + 0] = c_idx * 12 + face.edges[0]
            faces_tex[ti + 1] = c_idx * 12 + face.edges[1]
            faces_tex[ti + 2] = c_idx * 12 + face.edges[2]
            faces_tex[ti + 3] = c_idx * 12 + face.edges[3]

    # 4. Build Cell Scalar Texture
    cell_scalar_tex = alloc_r32f(face_count)
    width_cs, height_cs = tex_dims(face_count)

    for c_idx, c_data in enumerate(cell_data):
        for f_idx in range(6):
            face_id = c_idx * 6 + f_idx
            col = face_id % width_cs
            row = face_id // width_cs
            cell_scalar_tex[row * width_cs + col] = c_data['avg']

    return edges_tex, faces_tex, cell_scalar_tex
```

**Parameters**:
*   `s_range` minimum: $10^{-9}$ [S1, unofficial].

**Edge Cases and Pitfalls**:
*   Division by zero in scalar normalization is prevented by clamping `s_range` to $10^{-9}$ [S1, unofficial].
