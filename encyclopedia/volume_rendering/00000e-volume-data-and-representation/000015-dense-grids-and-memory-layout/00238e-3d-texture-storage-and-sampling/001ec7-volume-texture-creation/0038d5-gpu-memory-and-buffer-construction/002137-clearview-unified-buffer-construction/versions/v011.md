# ClearView Unified Buffer Construction

Also called: ClearView Buffer Construction

## Overview
ClearView Unified Buffer Construction is a preprocessing technique that converts a hexahedral mesh (positions, connectivity, and scalar values) into four GPU-friendly texture buffers—vertices, edges, faces, and cellScalar—optimized for the ClearView volume rendering pipeline [S1, unofficial]. It differs from general GPU data layout methods by explicitly structuring hexahedral topology into face-centric textures to support the subsequent PPLL (Per-Pixel Line List) or focus-context rendering passes, whereas [Device Volume Snapshot](2246-device-volume-snapshot.md) focuses on immutability and [Volume Upload via Staging Buffer](15388-volume-upload-via-staging-buffer.md) focuses on the transfer mechanism rather than the topological mapping [S1, unofficial].

## How it works
**Inputs:**
- `mesh.positions`: Array of vertex positions (x, y, z).
- `mesh.scalars`: Array of scalar values for each vertex.
- `mesh.cells`: Array of hexahedral cells, each defined by 8 vertex indices.

**Outputs:**
- `vertexTex`: Texture containing vertex indices (not explicitly detailed in layout notes, but implied by `facesTex` referencing them).
- `edgeTex`: Texture containing edge attributes and LOD values.
- `facesTex`: Texture containing face vertex and edge indices.
- `cellScalarTex`: Texture containing average scalar values per face.

**Data Structures and Layout:**

1.  **Edges Texture (`edgeTex`)**:
    -   Format: `RG32F` (Float32Array).
    -   Dimensions: Width and Height determined by `texDims(edgeCount)`.
    -   Layout: 1 texel = 2 floats = `(attribute, lod)`.
    -   Linear Index: `linear = c * 12 + e`, where `c` is cell index and `e` is edge index (0-11).
    -   Texel Index: `ti = (row * width + col) * 2`, where `col = linear % width`, `row = floor(linear / width)`.
    -   Values:
        -   `edgesTex[ti] = max(scalars[pia], scalars[pib])` (Attribute: max scalar of the two endpoints).
        -   `edgesTex[ti+1] = 1 - normScalar` (LOD: derived from cell average).

2.  **Faces Texture (`facesTex`)**:
    -   Format: `RG32UI` (Uint32Array).
    -   Dimensions: Width = 2, Height = `faceCount`.
    -   Layout: 2 texels per face.
    -   Linear Texel Index: `t0linear = faceId * 2 + 0`, `t1linear = faceId * 2 + 1`.
    -   Texel Index: `ti = (row * width + col) * 4`, where `col = tlinear % width`, `row = floor(tlinear / width)`.
    -   Values:
        -   Texel 0 (Vertex Indices): `.r=vertexIdx[0]`, `.g=vertexIdx[1]`, `.b=vertexIdx[2]`, `.a=vertexIdx[3]`.
        -   Texel 1 (Edge Indices): `.r=edgeIdx[0]`, `.g=edgeIdx[1]`, `.b=edgeIdx[2]`, `.a=edgeIdx[3]`.
        -   `vertexIdx` are global vertex indices (`c*8 + face.corners[0..3]`).
        -   `edgeIdx` are linear edge indices (`c*12 + face.edges[0..3]`).

3.  **Cell Scalar Texture (`cellScalarTex`)**:
    -   Format: `R32F` (Float32Array).
    -   Dimensions: Width and Height determined by `texDims(faceCount)`.
    -   Layout: 1 texel per face.
    -   Linear Index: `faceId = c * 6 + f`.
    -   Texel Index: `ti = row * width + col`, where `col = faceId % width`, `row = floor(faceId / width)`.
    -   Value: `cellScalarTex[ti] = cellScalarAvg`.

**Algorithm Steps:**

1.  **Compute Scalar Range:**
    $$s_{min} = \min(\text{mesh.scalars})$$
    $$s_{max} = \max(\text{mesh.scalars})$$
    $$s_{range} = \max(s_{max} - s_{min}, 10^{-9})$$

2.  **Compute Edge LOD:**
    For each cell `c`:
    $$\text{cellScalarAvg} = \frac{\sum_{i=0}^{7} \text{scalars}[\text{cell.corners}[i]]}{8}$$
    $$\text{normScalar} = \frac{\text{cellScalarAvg} - s_{min}}{s_{range}}$$
    $$\text{edgeLod} = 1 - \text{normScalar}$$

3.  **Populate Faces Texture:**
    For each cell `c` and face `f` (0-5):
    $$\text{faceId} = c \times 6 + f$$
    $$\text{face} = \text{HEX\_FACES}[f]$$
    Store vertex indices: `facesTex[ti+0..3] = c*8 + face.corners[0..3]`
    Store edge indices: `facesTex[ti+4..7] = c*12 + face.edges[0..3]`

4.  **Populate Edges Texture:**
    For each cell `c` and edge `e` (0-11):
    $$\text{linear} = c \times 12 + e$$
    $$\text{col} = \text{linear} \% \text{width}$$
    $$\text{row} = \lfloor \text{linear} / \text{width} \rfloor$$
    $$\text{ti} = (\text{row} \times \text{width} + \text{col}) \times 2$$
    $$\text{edgesTex}[\text{ti}] = \max(\text{scalars}[\text{pia}], \text{scalars}[\text{pib}])$$
    $$\text{edgesTex}[\text{ti}+1] = \text{edgeLod}$$
    *(Note: `pia` and `pib` are the two vertex indices of edge `e` in cell `c`)*

5.  **Populate Cell Scalar Texture:**
    For each cell `c` and face `f`:
    $$\text{faceId} = c \times 6 + f$$
    $$\text{col} = \text{faceId} \% \text{width}$$
    $$\text{row} = \lfloor \text{faceId} / \text{width} \rfloor$$
    $$\text{cellScalarTex}[\text{row} \times \text{width} + \text{col}] = \text{cellScalarAvg}$$

**Pseudocode:**

```python
def clearview_buffer_construction(mesh):
    # 1. Compute Scalar Range
    s_min = min(mesh.scalars)
    s_max = max(mesh.scalars)
    s_range = max(s_max - s_min, 1e-9)
    
    # Precompute cell averages and norm scalars
    cell_data = []
    for c in mesh.cells:
        corners = c.corners
        avg = sum(mesh.scalars[v] for v in corners) / 8.0
        norm = (avg - s_min) / s_range
        cell_data.append({'avg': avg, 'norm': norm, 'lod': 1.0 - norm})

    # 2. Define Hexahedral Topology
    # HEX_FACES[f] returns {'corners': [v0, v1, v2, v3], 'edges': [e0, e1, e2, e3]}
    # HEX_EDGES[e] returns {'vertices': [v0, v1]}
    # These are standard hexahedral definitions.
    
    # 3. Prepare Textures
    edge_count = len(mesh.cells) * 12
    face_count = len(mesh.cells) * 6
    
    # Helper to determine texture dimensions
    width, height = tex_dims(edge_count)
    edge_tex = Float32Array(width * height * 2)
    
    width_f, height_f = tex_dims(face_count)
    faces_tex = Uint32Array(width_f * height_f * 2 * 4) # 2 texels per face, 4 components each
    cell_scalar_tex = Float32Array(width_f * height_f)
    
    # 4. Populate Edges
    for c_idx, cell in enumerate(mesh.cells):
        lod = cell_data[c_idx]['lod']
        for e_idx in range(12):
            linear = c_idx * 12 + e_idx
            col = linear % width
            row = linear // width
            ti = (row * width + col) * 2
            
            # Get edge vertices
            edge_verts = HEX_EDGES[e_idx]
            v0 = cell.corners[edge_verts[0]]
            v1 = cell.corners[edge_verts[1]]
            
            attr = max(mesh.scalars[v0], mesh.scalars[v1])
            
            edge_tex[ti] = attr
            edge_tex[ti + 1] = lod

    # 5. Populate Faces
    for c_idx, cell in enumerate(mesh.cells):
        for f_idx in range(6):
            face_id = c_idx * 6 + f_idx
            face = HEX_FACES[f_idx]
            
            # Calculate texel index
            t_linear = face_id * 2
            col = t_linear % width_f
            row = t_linear // width_f
            ti = (row * width_f + col) * 4
            
            # Vertex indices
            v_indices = [c_idx * 8 + face.corners[i] for i in range(4)]
            faces_tex[ti + 0] = v_indices[0]
            faces_tex[ti + 1] = v_indices[1]
            faces_tex[ti + 2] = v_indices[2]
            faces_tex[ti + 3] = v_indices[3]
            
            # Edge indices
            e_indices = [c_idx * 12 + face.edges[i] for i in range(4)]
            faces_tex[ti + 4] = e_indices[0]
            faces_tex[ti + 5] = e_indices[1]
            faces_tex[ti + 6] = e_indices[2]
            faces_tex[ti + 7] = e_indices[3]

    # 6. Populate Cell Scalar
    for c_idx, cell in enumerate(mesh.cells):
        for f_idx in range(6):
            face_id = c_idx * 6 + f_idx
            col = face_id % width_f
            row = face_id // width_f
            cell_scalar_tex[row * width_f + col] = cell_data[c_idx]['avg']

    return edge_tex, faces_tex, cell_scalar_tex
```

**Parameters and Edge Cases:**
-   `s_range` uses a floor of `1e-9` to prevent division by zero if all scalars are identical [S1, unofficial].
-   Texture dimensions are calculated using `texDims`, which typically rounds up to powers of two or specific block sizes for GPU optimization [S1, unofficial].
-   The method assumes a standard hexahedral connectivity map (`HEX_FACES`, `HEX_EDGES`) [S1, unofficial].

## Operating characteristics
-   **Time Complexity:** $O(N)$ where $N$ is the number of cells, as it iterates through cells, faces, and edges once.
-   **Memory Complexity:** $O(N)$ for the four texture buffers.
-   **Strengths:** Optimizes memory access for the subsequent PPLL rendering pass by packing topology into 2D textures, enabling efficient texture sampling in shaders.
-   **Limitations:** Requires a hexahedral mesh; not directly applicable to tetrahedral or unstructured grids without conversion. The fixed layout assumes specific GPU texture format support (`RG32F`, `RG32UI`, `R32F`) [S1, unofficial].
-   **When to use:** When rendering hexahedral volumes using the ClearView pipeline, specifically for focus+context visualization or PPLL-based line rendering.

## Background
The ClearView Unified Buffer Construction method originates from the ClearView volume rendering pipeline, specifically designed for focus+context visualization. It was implemented in the `geresim-spike` project, which explores GPU-accelerated volume rendering techniques [S1, unofficial]. The technique is part of a broader effort to optimize hexahedral mesh data for GPU-based ray marching and line list generation, allowing for efficient modulation of sample alpha based on focus spheres [S1, unofficial].
