# ClearView Unified Buffer Construction

Also called: ClearView Buffer Construction

## Overview
ClearView Unified Buffer Construction is a preprocessing technique that converts a hexahedral mesh (positions, connectivity, and scalar values) into four GPU-friendly texture buffers for the ClearView volume rendering pipeline [S1, unofficial]. It differs from standard volume texture creation by explicitly encoding topological connectivity (faces and edges) alongside scalar data to support a specific fragment-based rendering pass, rather than relying on implicit grid traversal or sparse voxel structures [S1, unofficial].

## How it works
**Inputs:**
*   Hexahedral mesh geometry: vertex positions, cell connectivity (8 vertices per cell).
*   Scalar field: one scalar value per vertex.
*   Constants: `HEX_FACES` (predefined array of 6 faces per hexahedron, each containing 4 corner indices and 4 edge indices).

**Outputs:**
Four 2D textures stored in GPU memory:
1.  `vertexTex`: Vertex attributes (not detailed in source notes, but implied by deletion list).
2.  `edgeTex`: Edge attributes and Level of Detail (LOD).
3.  `facesTex`: Face vertex and edge indices.
4.  `cellScalarTex`: Average scalar value per face.

**Data Structures and Layout:**

1.  **Edge Texture (`edgeTex`)**
    *   **Format:** `RG32F` (Float32Array).
    *   **Dimensions:** Width and Height determined by `texDims(edgeCount)`.
    *   **Layout:** 1 texel = 2 floats.
        *   Float 0: `max(scalars[pia], scalars[pib])` (Attribute).
        *   Float 1: `1 - normScalar` (LOD).
    *   **Indexing:** Linear index `linear = c * 12 + e` (where `c` is cell index, `e` is edge index 0-11).
        *   `col = linear % width`
        *   `row = floor(linear / width)`
        *   `texel_index = (row * width + col) * 2`

2.  **Face Texture (`facesTex`)**
    *   **Format:** `RG32UI` (Uint32Array).
    *   **Dimensions:** Width = 2, Height = `faceCount`.
    *   **Layout:** 2 texels per face.
        *   **Texel 0 (Vertex Indices):** `.r`, `.g`, `.b`, `.a` store the 4 vertex indices of the face.
        *   **Texel 1 (Edge Indices):** `.r`, `.g`, `.b`, `.a` store the 4 edge indices of the face.
    *   **Indexing:**
        *   `faceId = c * 6 + f` (where `f` is face index 0-5).
        *   `t0linear = faceId * 2 + 0`
        *   `t1linear = faceId * 2 + 1`
        *   `col = tlinear % width`
        *   `row = floor(tlinear / width)`
        *   `texel_index = (row * width + col) * 4`
        *   Values: `facesTex[ti+0..3] = c*8 + face.corners[0..3]`, `facesTex[ti+4..7] = c*12 + face.edges[0..3]`.

3.  **Cell Scalar Texture (`cellScalarTex`)**
    *   **Format:** `R32F` (Float32Array).
    *   **Dimensions:** Width and Height determined by `texDims(faceCount)`.
    *   **Layout:** 1 texel per face.
    *   **Indexing:**
        *   `faceId = c * 6 + f`
        *   `col = faceId % width`
        *   `row = floor(faceId / width)`
        *   Value: `cellScalarTex[row * width + col] = cellScalarAvg`.

**Algorithm Steps:**

1.  **Compute Scalar Range:**
    $$s_{min} = \min(\text{mesh.scalars})$$
    $$s_{max} = \max(\text{mesh.scalars})$$
    $$s_{range} = \max(s_{max} - s_{min}, 10^{-9})$$

2.  **Compute Edge LOD:**
    For each cell `c`:
    $$cellScalarAvg = \frac{\sum_{i=0}^{7} \text{scalars}[v_i]}{8}$$
    $$normScalar = \frac{cellScalarAvg - s_{min}}{s_{range}}$$
    $$edgeLod = 1 - normScalar$$

3.  **Populate Face Texture:**
    For each cell `c` and face `f` (0 to 5):
    $$faceId = c \times 6 + f$$
    $$face = HEX\_FACES[f]$$
    Store vertex indices: `c*8 + face.corners[0..3]` in Texel 0.
    Store edge indices: `c*12 + face.edges[0..3]` in Texel 1.

4.  **Populate Edge Texture:**
    For each cell `c` and edge `e` (0 to 11):
    $$linear = c \times 12 + e$$
    Determine `row` and `col` from `linear` and texture width.
    $$p_a, p_b = \text{vertices of edge } e \text{ in cell } c$$
    $$edgesTex[ti] = \max(\text{scalars}[p_a], \text{scalars}[p_b])$$
    $$edgesTex[ti+1] = 1 - normScalar$$

5.  **Populate Cell Scalar Texture:**
    For each cell `c` and face `f`:
    $$faceId = c \times 6 + f$$
    Determine `row` and `col` from `faceId` and texture width.
    $$cellScalarTex[row \times width + col] = cellScalarAvg$$

**Pseudocode:**

```python
def clearview_buffer_construction(mesh):
    """
    mesh: object with .positions (N*3), .scalars (N), .cells (M*8)
    Returns: buffers dict with 'edgeTex', 'facesTex', 'cellScalarTex'
    """
    N = len(mesh.scalars)
    M = len(mesh.cells)
    
    # 1. Compute Scalar Range
    s_min = min(mesh.scalars)
    s_max = max(mesh.scalars)
    s_range = max(s_max - s_min, 1e-9)
    
    # Precompute cell scalar averages and norm scalars
    cell_avg_scalars = []
    cell_norm_scalars = []
    for c in range(M):
        cell_verts = mesh.cells[c]
        avg = sum(mesh.scalars[v] for v in cell_verts) / 8.0
        cell_avg_scalars.append(avg)
        norm = (avg - s_min) / s_range
        cell_norm_scalars.append(norm)
        
    # 2. Define Hexahedron Topology
    # HEX_FACES[f] = { 'corners': [v0, v1, v2, v3], 'edges': [e0, e1, e2, e3] }
    # Edges are defined by vertex indices. Standard hexahedron edge mapping:
    # 0: 0-1, 1: 1-5, 2: 5-4, 3: 4-0, 4: 2-3, 5: 3-7, 6: 7-6, 7: 6-2, 
    # 8: 0-4, 9: 1-5, 10: 2-6, 11: 3-7
    # Note: The source notes imply a specific mapping for 'face.edges'. 
    # We assume HEX_FACES is provided as input constant.
    
    # 3. Calculate Dimensions
    # Helper to calculate texture dimensions for a given count
    def tex_dims(count):
        width = int(math.ceil(math.sqrt(count)))
        height = int(math.ceil(count / width))
        return width, height

    # Edge Texture
    edge_count = M * 12
    edge_width, edge_height = tex_dims(edge_count)
    edge_tex = [0.0] * (edge_width * edge_height * 2) # RG32F
    
    for c in range(M):
        norm_scalar = cell_norm_scalars[c]
        for e in range(12):
            linear = c * 12 + e
            col = linear % edge_width
            row = linear // edge_width
            ti = (row * edge_width + col) * 2
            
            # Get edge vertices from HEX_FACES or direct edge table
            # Assuming helper get_edge_vertices(c, e) returns (v_a, v_b)
            v_a, v_b = get_edge_vertices(mesh.cells[c], e)
            
            attr = max(mesh.scalars[v_a], mesh.scalars[v_b])
            lod = 1.0 - norm_scalar
            
            edge_tex[ti] = attr
            edge_tex[ti + 1] = lod

    # Face Texture
    face_count = M * 6
    face_width = 2
    face_height = face_count
    faces_tex = [0] * (face_width * face_height * 4) # RG32UI
    
    for c in range(M):
        for f in range(6):
            face_id = c * 6 + f
            face = HEX_FACES[f]
            
            # Texel 0: Vertex Indices
            t0_linear = face_id * 2 + 0
            col = t0_linear % face_width
            row = t0_linear // face_width
            ti = (row * face_width + col) * 4
            
            # Vertices are local to cell, offset by c*8
            faces_tex[ti + 0] = c * 8 + face.corners[0]
            faces_tex[ti + 1] = c * 8 + face.corners[1]
            faces_tex[ti + 2] = c * 8 + face.corners[2]
            faces_tex[ti + 3] = c * 8 + face.corners[3]
            
            # Texel 1: Edge Indices
            t1_linear = face_id * 2 + 1
            col = t1_linear % face_width
            row = t1_linear // face_width
            ti = (row * face_width + col) * 4
            
            # Edges are local to cell, offset by c*12
            faces_tex[ti + 0] = c * 12 + face.edges[0]
            faces_tex[ti + 1] = c * 12 + face.edges[1]
            faces_tex[ti + 2] = c * 12 + face.edges[2]
            faces_tex[ti + 3] = c * 12 + face.edges[3]

    # Cell Scalar Texture
    scalar_width, scalar_height = tex_dims(face_count)
    cell_scalar_tex = [0.0] * (scalar_width * scalar_height)
    
    for c in range(M):
        for f in range(6):
            face_id = c * 6 + f
            col = face_id % scalar_width
            row = face_id // scalar_width
            cell_scalar_tex[row * scalar_width + col] = cell_avg_scalars[c]

    return {
        'edgeTex': edge_tex,
        'facesTex': faces_tex,
        'cellScalarTex': cell_scalar_tex,
        'sMin': s_min,
        'sMax': s_max
    }

def get_edge_vertices(cell_verts, edge_idx):
    """
    Returns vertex indices for a specific edge in a hexahedron.
    Standard ordering:
    0: 0-1, 1: 1-5, 2: 5-4, 3: 4-0
    4: 2-3, 5: 3-7, 6: 7-6, 7: 6-2
    8: 0-4, 9: 1-5, 10: 2-6, 11: 3-7
    """
    edges = [
        (0, 1), (1, 5), (5, 4), (4, 0),
        (2, 3), (3, 7), (7, 6), (6, 2),
        (0, 4), (1, 5), (2, 6), (3, 7)
    ]
    v1, v2 = edges[edge_idx]
    return cell_verts[v1], cell_verts[v2]
```

**Parameters:**
*   `s_range` minimum: `1e-9` (to prevent division by zero) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If `s_max == s_min`, `s_range` is clamped to `1e-9` [S1, unofficial].
*   **Texture Dimensions:** Width and height must be calculated to accommodate the total number of edges or faces, potentially requiring padding if the count is not a perfect square or multiple of 2 (for faces width=2) [S1, unofficial].
*   **Index Overflow:** Vertex and edge indices are stored as offsets relative to the cell start (`c*8`, `c*12`). Ensure these fit within the `Uint32` range for `RG32UI` format [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of cells $O(M)$, as each cell's faces and edges are processed once.
*   **Memory Complexity:** Proportional to the number of faces and edges. Specifically, $O(M)$ for `cellScalarTex`, $O(M)$ for `facesTex` (constant 2 texels per face), and $O(M)$ for `edgeTex` (constant 12 edges per cell).
*   **Strengths:** Explicitly encodes connectivity for fragment-based rendering, allowing for efficient face/edge attribute lookup without runtime topology traversal.
*   **Limitations:** Requires preprocessing step. Memory usage is higher than implicit grid representations due to explicit storage of face/edge indices.
*   **When to use:** When using the ClearView pipeline which relies on face-based fragment generation and edge LOD.
*   **When not to use:** For standard ray-marching on dense grids where implicit traversal is preferred, or for sparse data where VDB is more suitable.

## Background
The method originates from the "geresim-spike" project, an unofficial implementation of a ClearView volume rendering pipeline [S1, unofficial]. It is designed to support a specific visualization technique involving focus+context controls and fragment-based resolution passes [S1, unofficial].
