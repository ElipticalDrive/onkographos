# Texture Array Sampling with Alpha Discard

Also called: Alpha Discard Fragment Shader, Fragment Shader Texture Sampling, SPIRV_Cross_CombinedtextureArraytextureSampler Sampling

## Overview
This method implements a fragment shader that samples a 3D texture array to retrieve voxel color and opacity, discarding fragments with alpha below a specific threshold to optimize rendering performance by avoiding overdraw for transparent regions [S1, S2, unofficial]. It differs from proxy geometry approaches by relying entirely on hardware texture sampling and early-Z rejection, rather than generating geometry for occupied voxels [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `in_var_TEXCOORD0`: `vec2` (Location 0), representing the 2D screen-space coordinates or UVs for the texture array layer selection [S1, unofficial].
    *   `in_var_TEXCOORD1`: `flat int` (Location 1), representing the texture array layer index (voxel index) [S1, unofficial].
    *   `in_var_TEXCOORD2`: `vec3` (Location 2), representing a color multiplier or base color [S1, unofficial].
    *   `SPIRV_Cross_CombinedtextureArraytextureSampler`: A `sampler2DArray` uniform binding the 3D texture array [S1, unofficial].
*   **Outputs:**
    *   `out_var_SV_TARGET`: `vec4` (Location 0), the final color with alpha [S1, unofficial].

**Data Structures:**
The texture is a `sampler2DArray`, which maps 2D coordinates and a layer index to a 3D volume. The layer index is provided via `in_var_TEXCOORD1` [S1, unofficial].

**Steps:**
1.  Construct the 3D texture coordinate by combining the 2D UVs from `in_var_TEXCOORD0` and the layer index from `in_var_TEXCOORD1` cast to `float` [S1, unofficial].
2.  Sample the texture array using the constructed coordinate and the sampler [S1, S2, unofficial]. Let the result be `texColor` [S2, unofficial].
3.  Extract the alpha component from `texColor` [S1, unofficial].
4.  Compare the alpha value against the discard threshold [S1, unofficial].
5.  If the alpha is less than the threshold, discard the fragment [S1, unofficial].
6.  Otherwise, compute the output color by multiplying the sampled RGB components by `in_var_TEXCOORD2` and attaching the original alpha [S1, unofficial].

**Pseudocode:**
```python
# Inputs
# tex_coord_2d: vec2 from in_var_TEXCOORD0
# layer_index: int from in_var_TEXCOORD1
# color_multiplier: vec3 from in_var_TEXCOORD2
# texture_sampler: sampler2DArray

# Step 1: Construct 3D coordinate
# The layer index is cast to float for the z-coordinate of the 2D array sampler
tex_coord_3d = vec3(tex_coord_2d, float(layer_index))

# Step 2: Sample texture
tex_color = texture(texture_sampler, tex_coord_3d)

# Step 3: Extract alpha
alpha = tex_color.w

# Step 4 & 5: Alpha discard check
# Threshold is approximately 0.01 (0.00999999977648258209228515625)
if alpha < 0.00999999977648258209228515625:
    discard_fragment()

# Step 6: Output color
output_color = vec4(tex_color.xyz * color_multiplier, alpha)
```

**Parameters:**
*   **Alpha Discard Threshold:** `0.00999999977648258209228515625` (approx `0.01`) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** The threshold is a specific float value derived from SPIRV-Cross output [S1, unofficial]. Using a slightly different threshold may include or exclude edge-case transparent voxels.
*   **Layer Indexing:** The layer index must be valid for the texture array dimensions. Invalid indices may result in undefined behavior or sampling errors [S1, unofficial].
*   **Color Multiplication:** The `in_var_TEXCOORD2` multiplier allows for per-voxel or per-chunk color variation, but if not provided correctly, the output color may be incorrect [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** O(1) per fragment, dominated by texture sampling and a single comparison [S1, S2, unofficial].
*   **Memory Complexity:** O(1) additional memory per fragment, relying on the GPU's texture cache [S1, S2, unofficial].
*   **Performance:** Efficient for sparse volumes as transparent voxels are discarded early, reducing fill rate pressure [S1, S2, unofficial].
*   **Strengths:** Simple implementation, leverages hardware texture sampling, effective alpha culling [S1, S2, unofficial].
*   **Limitations:** Requires a texture array layout, not suitable for non-texture-based volume representations [S1, S2, unofficial].

## Background
This method is derived from fragment shader implementations in voxel rendering engines, specifically those using SPIRV-Cross to generate GLSL from HLSL or other shader languages [S1, S2, unofficial]. It is commonly used in real-time voxel engines for terrain and block rendering [S1, S2, unofficial].
