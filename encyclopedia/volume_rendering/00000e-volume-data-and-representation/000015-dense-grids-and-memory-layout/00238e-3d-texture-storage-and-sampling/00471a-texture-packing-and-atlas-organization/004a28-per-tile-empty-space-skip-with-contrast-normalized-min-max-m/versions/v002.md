# Per-tile empty-space skip with contrast-normalized min/max metadata

Also called: VT: per-tile (min, max) metadata + contrast-floor empty-space skip, tile-level empty-space skip

## Overview
This method is a rendering-side optimization that skips raymarch stepping through resident-but-empty tiles by comparing tile-local density bounds against a global contrast floor [S1, unofficial]. It solves the gap left by residency/LOD-walk skipping, which only skips unloaded space, by allowing the raymarcher to bypass empty regions within already-loaded data [S1, unofficial]. It differs from its siblings, which focus on memory packing, by operating on the raymarching logic itself, using metadata to avoid unnecessary sampling and shading calculations [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Raymarcher state (position, direction, step size), tile resolution, global contrast floor (`contrast_min`), and a toggle flag (`skip_empty`).
*   **Output:** Updated ray position (advanced past empty tiles) and raymarch result (value, LOD, tile_max).

**Data Structures:**
1.  **Metadata Texture:** A parallel `Rg8Unorm` texture with the same dimensions as the `PageTable`. It holds each resident tile's (min, max) density values in the contrast-normalized [0, 1] range.
    *   Channel `.r`: Minimum density value.
    *   Channel `.g`: Maximum density value.
    *   Binding: Group 1, Binding 8.
    *   Filtering: Non-filtering (nearest neighbor).
    *   Format: Float D2Array (2D Array of floats, though stored as Rg8Unorm for upload efficiency, sampled as float) [S1, unofficial].
2.  **Tile Min/Max Map (`tile_minmax`):** A CPU-side cache mirroring the `slot_map`'s lifetime. It stores the computed (min, max) tuples for resident tiles.
    *   Insert: On upload.
    *   Remove: On eviction/scrub.
    *   Default: If a tile's metadata is absent (e.g., initial load), it defaults to `(0, 1)`, meaning "never skip" [S1, unofficial].

**Numbered Steps:**
1.  **Compute Tile Min/Max:** During data upload, the `compute_tile_min_max` function scans the `R16Float` chunk corresponding to a tile to determine the minimum and maximum density values for that tile [S1, unofficial].
2.  **Cache Metadata:** The computed (min, max) values are inserted into the `tile_minmax` map. The parallel metadata texture is updated with these values normalized to [0, 1] [S1, unofficial].
3.  **Shader Sampling:** When the raymarcher resolves a tile (`try_lod`/`sample_vvt`), it reads the metadata texture at the tile's coordinate. The function returns a tuple `(value, lod, tile_max)`, where `tile_max` is the value from the `.g` channel of the parallel metadata texel [S1, unofficial].
4.  **Skip Condition Check:** In `fs_translucent` mode 0, if the `skip_empty` flag is enabled and `tile_max < contrast_min + ε`, the tile is considered empty [S1, unofficial].
5.  **Skip Advancement:** If the skip condition is met, the ray advances to the resolved tile's far boundary using `tile_skip_advance`.
6.  **Clamp Advancement:** The advancement is clamped to `step_size` to ensure grazing rays still make progress and do not skip over the entire tile in one step, which could cause visual artifacts [S1, unofficial].
7.  **Fallback:** If the skip condition is not met, or if debug/other render modes are active, the ray steps verbatim through the tile [S1, unofficial].

**Formulas:**
*   **Normalization:** $v_{norm} = \frac{v - v_{min\_global}}{v_{max\_global} - v_{min\_global}}$ (Implicit in the contrast-normalized [0,1] range, though exact global bounds are not specified, the metadata stores values in this range) [S1, unofficial].
*   **Skip Condition:** $tile\_max < contrast\_min + \epsilon$ [S1, unofficial].
*   **Advancement:** $pos_{new} = pos_{old} + \min(tile\_skip\_advance, step\_size) \cdot direction$ [S1, unofficial].

**Parameters:**
*   `contrast_min`: Global contrast floor. Recomputed every frame.
*   `skip_empty`: Toggle flag in `VolumeUniforms` (repurposing `_pad0`). Default: On. Exposed via `K` key in native renderer and `setSkipEmpty` in web WASM wrappers [S1, unofficial].
*   `ε`: Small epsilon for floating-point comparison. Not given in the sources.

**Pitfalls:**
*   **Grazing Rays:** Without clamping `tile_skip_advance` to `step_size`, grazing rays might skip over the entire tile in one step, potentially missing boundaries or causing visual artifacts [S1, unofficial].
*   **Missing Metadata:** If a tile's metadata is absent from the `tile_minmax` map, it defaults to `(0, 1)`, ensuring the tile is never skipped incorrectly [S1, unofficial].

**Pseudocode:**
```python
# Pseudocode for the raymarcher's tile processing step

def process_tile(ray, tile_coord, metadata_texture, step_size, contrast_min, skip_empty_enabled):
    """
    Processes a single tile for raymarching.
    Returns: (new_ray_position, value, lod, tile_max)
    """
    # 1. Sample metadata
    # Metadata texture is bound at group(1) binding 8, non-filtering Float D2Array
    # Returns (min_norm, max_norm) in [0, 1] range
    min_norm, max_norm = metadata_texture.sample(tile_coord)
    
    # 2. Check skip condition
    # Only applies in fs_translucent mode 0 and if skip_empty is enabled
    if skip_empty_enabled and max_norm < contrast_min + EPSILON:
        # 3. Skip the tile
        # Calculate distance to far boundary of the tile
        tile_skip_distance = calculate_tile_far_boundary_distance(ray, tile_coord)
        
        # Clamp advancement to step_size to prevent grazing ray artifacts
        advance_distance = min(tile_skip_distance, step_size)
        
        # Advance ray
        new_ray_pos = ray.position + advance_distance * ray.direction
        
        # Return a marker or default value indicating skip
        # The actual value/lod are not computed for this tile
        return (new_ray_pos, 0.0, 0, max_norm)
    
    else:
        # 4. Step verbatim (or use residency/LOD-walk logic if applicable)
        # This part is handled by the parent method's logic or standard raymarching
        # For this method, we just return the metadata for potential future use
        # The actual stepping is done by the caller or parent method
        return (ray.position, 0.0, 0, max_norm)

def compute_tile_min_max(chunk_data):
    """
    Scans an R16Float chunk to find min and max density values.
    """
    min_val = infinity
    max_val = -infinity
    
    for value in chunk_data:
        if value < min_val:
            min_val = value
        if value > max_val:
            max_val = value
            
    return (min_val, max_val)
```

## Operating characteristics
*   **Time Complexity:** Reduces the number of raymarch steps for empty tiles, potentially improving performance in sparse volumes. The overhead of sampling the metadata texture is minimal.
*   **Memory Complexity:** Adds a parallel `Rg8Unorm` metadata texture, doubling the memory requirement for the page table's spatial data (though the metadata is smaller per element). The `tile_minmax` map adds CPU-side memory proportional to the number of resident tiles.
*   **Performance:** Measured performance gains depend on the sparsity of the volume. In dense volumes, the skip is rarely triggered, and the overhead is negligible. In sparse volumes, significant speedups are possible. Not given in the sources.
*   **Strengths:** Effective for sparse volumes; no impact on residency/LOD-walk skipping; easy to toggle for A/B testing.
*   **Limitations:** Only applies to resident tiles; requires additional memory for metadata; requires careful handling of grazing rays.
*   **When to use:** When rendering sparse volumes with significant empty space within resident tiles.
*   **When not to use:** When rendering dense volumes; when memory is constrained; when debug modes are active.
