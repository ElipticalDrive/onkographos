# Per-tile empty-space skip with contrast-normalized min/max metadata

Also called: VT: per-tile (min, max) metadata + contrast-floor empty-space skip, tile-level empty-space skip

## Overview
This method is a rendering-side optimization that skips raymarch stepping through resident-but-empty tiles by comparing tile-local density bounds against a global contrast floor [S1, unofficial]. It solves the gap left by residency/LOD-walk skipping, which only skips unloaded space [S1, unofficial]. Unlike its siblings which focus on memory packing, this method operates on resident tiles to reduce shader execution time without evicting data or touching the wanted set [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   Volume density data stored in R16Float chunks.
*   A global contrast floor value (`contrast_min`), recomputed every frame.
*   A skip toggle flag (`skip_empty`), defaulting to enabled.
*   Tile metadata: minimum and maximum density values for each resident tile, stored in a parallel texture.

**Outputs:**
*   Raymarch step advancement: either a standard step or a jump to the tile's far boundary if the tile is determined to be empty.
*   Shader return tuple: `(value, lod, tile_max)` from the volume sampling functions.

### Data Structures
1.  **Metadata Texture:**
    *   Format: `Rg8Unorm` (8-bit unsigned normalized integer for each channel).
    *   Dimensions: Identical to the `PageTable` dimensions.
    *   Layout:
        *   `.r` channel: Minimum density value, normalized to `[0, 1]`.
        *   `.g` channel: Maximum density value, normalized to `[0, 1]`.
    *   Binding: Bound at `group(1) binding 8` in the shader [S1, unofficial].
    *   Sampling: Non-filtering (nearest neighbor) `Float D2Array` [S1, unofficial].

2.  **Tile Min/Max Map (`tile_minmax`):**
    *   A CPU-side cache mirroring the lifetime of `slot_map` [S1, unofficial].
    *   Keys: Tile identifiers.
    *   Values: Tuple `(min, max)` in contrast-normalized `[0, 1]` range.
    *   Management:
        *   Insert on upload.
        *   Remove on eviction/scrub.
        *   Default value if absent: `(0, 1)` (meaning "never skip") [S1, unofficial].

### Parameters
*   **`contrast_min`**: The global contrast floor. Computed every frame. [S1, unofficial].
*   **`step_size`**: The current raymarch step size. [S1, unofficial].
*   **`skip_empty`**: Boolean flag in `VolumeUniforms` (repurposing `_pad0`). Controlled via `VolumeCore::set_skip_empty`. Default: `true`. Exposed via `K` key in native renderer and `setSkipEmpty` in web WASM wrappers [S1, unofficial].
*   **`ε` (epsilon)**: A small numerical tolerance added to `contrast_min` for comparison. [S1, unofficial].

### Numbered Steps

1.  **Compute Tile Min/Max (Upload Phase):**
    *   During data upload, invoke `compute_tile_min_max` on the R16Float chunk for the tile.
    *   Determine the minimum and maximum density values within the tile.
    *   Normalize these values to the `[0, 1]` range based on the current contrast settings.
    *   Store the normalized `(min, max)` tuple in the `tile_minmax` map.
    *   Update the parallel `Rg8Unorm` metadata texture with these values at the corresponding tile coordinate [S1, unofficial].

2.  **Shader Sampling (Raymarch Phase):**
    *   Call `try_lod` or `sample_vvt` to sample the volume at the current ray position.
    *   These functions now return a tuple `(value, lod, tile_max)`.
    *   `tile_max` is read from the `.g` channel of the parallel metadata texel corresponding to the currently resident tile [S1, unofficial].

3.  **Skip Condition Check:**
    *   If `skip_empty` is `false`, or if the render mode is not `fs_translucent mode 0`, or if debug modes are active, proceed with standard stepping [S1, unofficial].
    *   Otherwise, check if `tile_max < contrast_min + ε`.
    *   If the condition is true, the tile is considered empty relative to the contrast floor.

4.  **Skip Advancement:**
    *   If the skip condition is met, jump the ray to the resolved tile's far boundary using `tile_skip_advance`.
    *   **Crucial:** Clamp the advancement distance to `step_size` to ensure grazing rays still make progress and do not skip over boundaries entirely [S1, unofficial].
    *   Continue raymarching from the new position [S1, unofficial].

### Pseudocode

```python
# CPU Side: Upload and Metadata Management

def compute_tile_min_max(r16_float_chunk):
    """
    Scans an R16Float chunk to find min and max density values.
    Returns (min_val, max_val) in original density units.
    """
    min_val = infinity
    max_val = -infinity
    for density in r16_float_chunk:
        if density < min_val:
            min_val = density
        if density > max_val:
            max_val = density
    return (min_val, max_val)

def normalize_to_contrast(val, contrast_min, contrast_max):
    """
    Normalizes a density value to [0, 1] range based on contrast bounds.
    """
    if contrast_max == contrast_min:
        return 0.0
    normalized = (val - contrast_min) / (contrast_max - contrast_min)
    # Clamp to [0, 1]
    return max(0.0, min(1.0, normalized))

def update_tile_metadata(tile_id, r16_float_chunk, contrast_min, contrast_max):
    """
    Updates the tile_minmax map and the parallel metadata texture.
    """
    (min_val, max_val) = compute_tile_min_max(r16_float_chunk)
    
    min_norm = normalize_to_contrast(min_val, contrast_min, contrast_max)
    max_norm = normalize_to_contrast(max_val, contrast_min, contrast_max)
    
    # Update CPU cache
    tile_minmax[tile_id] = (min_norm, max_norm)
    
    # Update GPU metadata texture (Rg8Unorm)
    # r_channel = min_norm, g_channel = max_norm
    metadata_texture.set_tile(tile_id, (min_norm, max_norm))

def remove_tile_metadata(tile_id):
    """
    Removes metadata on eviction/scrub.
    """
    if tile_id in tile_minmax:
        del tile_minmax[tile_id]
    # Note: GPU texture update may be deferred or batched

def get_tile_metadata(tile_id):
    """
    Retrieves metadata, defaulting to (0, 1) if absent.
    """
    if tile_id in tile_minmax:
        return tile_minmax[tile_id]
    else:
        return (0.0, 1.0) # Default: never skip

# GPU Side: Raymarch Shader Logic (Pseudo-WGSL/Python-like)

def sample_vvt(ray_origin, ray_direction, current_pos, page_table, metadata_texture):
    """
    Samples the volume at current_pos.
    Returns (value, lod, tile_max).
    """
    # Determine which tile the current_pos falls into
    tile_id = page_table.get_tile_id(current_pos)
    
    # Sample the actual volume data
    value = volume_data.sample(ray_origin, ray_direction, current_pos)
    lod = page_table.get_lod(tile_id)
    
    # Read tile_max from the parallel metadata texture (.g channel)
    # metadata_texture is bound at group(1) binding 8
    metadata_texel = metadata_texture.sample_nearest(tile_id)
    tile_max = metadata_texel.g
    
    return (value, lod, tile_max)

def raymarch_step(ray_origin, ray_direction, current_pos, step_size, contrast_min, skip_empty, render_mode):
    """
    Performs a single raymarch step, potentially skipping empty tiles.
    """
    # Check if skipping is enabled and appropriate mode
    if not skip_empty:
        return current_pos + ray_direction * step_size
    
    if render_mode != "fs_translucent_mode_0":
        return current_pos + ray_direction * step_size
    
    # Sample volume and get tile metadata
    (value, lod, tile_max) = sample_vvt(ray_origin, ray_direction, current_pos, page_table, metadata_texture)
    
    # Skip condition: tile_max < contrast_min + epsilon
    epsilon = 1e-6 # Small numerical tolerance
    if tile_max < contrast_min + epsilon:
        # Tile is empty relative to contrast floor
        # Jump to the far boundary of the current tile
        far_boundary = page_table.get_tile_far_boundary(current_pos)
        
        # Calculate distance to far boundary
        dist_to_far = length(far_boundary - current_pos)
        
        # Clamp advancement to step_size to prevent grazing rays from skipping entirely
        # This ensures progress
        actual_advance = min(dist_to_far, step_size)
        
        # Advance the ray
        new_pos = current_pos + normalize(ray_direction) * actual_advance
        
        # If we hit the far boundary exactly, we might need to handle the next tile
        # The tile_skip_advance function handles the logic of resolving the next tile
        return tile_skip_advance(new_pos, ray_direction, step_size)
    else:
        # Tile has content, step normally
        return current_pos + ray_direction * step_size

def tile_skip_advance(pos, ray_direction, step_size):
    """
    Advances the ray to the resolved tile's far boundary, clamped to step_size.
    This is a helper for the skip logic.
    """
    # Resolve the tile at the new position
    # If the ray is still within the same tile, advance by step_size
    # If it crossed a boundary, resolve the new tile and continue
    # This function ensures that grazing rays make progress
    # Implementation details depend on the specific page table structure
    # For the purpose of this article, we assume it returns the next valid position
    return pos + ray_direction * step_size
```

### Edge Cases and Pitfalls
*   **Grazing Rays:** Without clamping `tile_skip_advance` to `step_size`, grazing rays might skip over the entire tile in one step, potentially missing boundaries or causing visual artifacts. The clamp ensures progress [S1, unofficial].
*   **Missing Metadata:** If a tile's metadata is absent from the `tile_minmax` map (e.g., during initial load or specific refresh paths), it defaults to `(0, 1)`, ensuring the tile is never skipped incorrectly [S1, unofficial].
*   **Debug Modes:** Debug modes and other render modes step verbatim, ignoring the skip [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Reduces the number of texture samples and shader computations for empty tiles. The complexity of the skip check is O(1) per step.
*   **Memory Complexity:** Adds a parallel `Rg8Unorm` metadata texture, doubling the memory footprint for the page table metadata. The `tile_minmax` map adds CPU memory proportional to the number of resident tiles.
*   **Performance:** Provides a measurable reduction in render-pass time for sparse datasets, as confirmed by A/B testing with GPU frame captures [S1, unofficial].
*   **Strengths:**
    *   Operates on resident tiles, avoiding the overhead of residency management for empty space.
    *   Coupling the threshold to the contrast floor is safe and requires zero re-streaming [S1, unofficial].
    *   Does not conflict with residency-layer empty-tile dropping rules [S1, unofficial].
*   **Limitations:**
    *   Only effective when tiles are resident.
    *   Requires additional memory for metadata.
    *   Does not handle the case of completely unloaded space (handled by residency/LOD-walk skipping) [S1, unofficial].
*   **When to Use:** Use when rendering sparse volumes with significant empty space, and residency/LOD-walk skipping is already in place. It is particularly effective when the contrast floor can effectively filter out noise or low-density regions.
*   **When Not to Use:** Do not use if memory is extremely constrained, or if the volume is dense with no significant empty regions.

## Background
This method was forward-ported from the `stranded phase-3-tile-cached-raymarch` branch to the current multi-atlas Virtual Texture (VT) implementation [S1, unofficial]. It addresses the limitation of previous skipping methods that only operated on unloaded space, leaving resident empty tiles to be sampled unnecessarily [S1, unofficial]. The implementation was verified in a Python volume rendering example and builds cleanly on native and WASM platforms [S1, unofficial]. A tile-cache optimization was deliberately omitted from this port, as it was written against the pre-multi-atlas shader and is considered a separate follow-up [S1, unofficial].
