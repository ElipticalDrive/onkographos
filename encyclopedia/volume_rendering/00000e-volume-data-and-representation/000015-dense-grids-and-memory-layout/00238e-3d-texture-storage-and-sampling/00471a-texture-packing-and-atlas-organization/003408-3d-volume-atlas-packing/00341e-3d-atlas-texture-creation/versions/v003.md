# 3D Atlas Texture Creation

Also called: createAtlasTexture

## Overview
Creates a half-precision 3D atlas texture and updates shader uniforms based on volume parameters [S1, unofficial].

## How it works
**Inputs:**
- `volumeResolution`: `THREE.Vector3`. 3D resolution (voxel count) of one volume [S1, unofficial].
- `volumeOrigin`: `THREE.Vector3`. 3D world-space origin of the volume [S1, unofficial].
- `voxelSize`: `THREE.Vector3`. Physical 3D size of one voxel [S1, unofficial].
- `timeCount`: `number`. Total number of timesteps [S1, unofficial].
- `textureFilter`: `number`. Texture interpolation mode, default `THREE.LinearFilter` [S1, unofficial].
- `atlasBuffer`: Flat buffer containing voxel data allocated by the parent packing step [G].
- `atlasResolution`: 3D grid dimensions for the volumes, calculated by the parent packing step [G].

**Outputs:**
- A GPU 3D texture object configured for half-precision single-channel storage [G].
- Updated shader uniforms: `volumeAtlas`, `atlasResolution`, `volumeResolution`, `voxelSize`, `timeCount`, `volumeOrigin` [S1, unofficial].

**Data Structures:**
The `atlasBuffer` holds the raw voxel data in a flat layout [G]. The `atlasResolution` defines the 3D grid dimensions that tile the individual volumes within the atlas [G].

**Steps:**
1. Allocate a 3D texture object using the graphics context [G].
2. Configure the texture to use half-precision (16-bit) storage for single-channel data [G].
3. Set the texture dimensions to the `atlasResolution` calculated by the parent packing step [G].
4. Bind the `atlasBuffer` to the texture object [G].
5. Set the texture interpolation mode to `textureFilter`, defaulting to linear filtering [S1, unofficial].
6. Upload the texture data to GPU memory [G].
7. Update the shader uniforms with the input parameters and the texture reference [S1, unofficial].

**Coordinate Mapping:**
The created atlas is sampled using the following coordinate transformations [S1, unofficial]:
$$ \text{volumeVoxel} = \frac{\text{position} - \text{volumeOrigin}}{\text{voxelSize}} $$
$$ \text{volumeUv} = \frac{\text{volumeVoxel} + 0.5}{\text{volumeResolution}} $$
$$ \text{uv}_0 = \text{volumeUvOffset}_0 + \frac{\text{volumeUv}}{\text{atlasResolution}} $$
$$ \text{uv}_1 = \text{volumeUvOffset}_1 + \frac{\text{volumeUv}}{\text{atlasResolution}} $$
$$ \text{value} = \text{mix}(\text{texture}(\text{volumeAtlas}, \text{uv}_0).\text{r}, \text{texture}(\text{volumeAtlas}, \text{uv}_1).\text{r}, \text{volumeT}) $$
where `position` is the world-space query point, `volumeUvOffset0/1` are the base UV offsets for the two volumes being interpolated, and `volumeT` is the interpolation weight [S1, unofficial].

**Pseudocode:**
```python
def create_atlas_texture(volume_resolution, volume_origin, voxel_size, time_count, texture_filter, atlas_buffer, atlas_resolution):
    # Allocate 3D texture object [G]
    texture = allocate_3d_texture_object()
    # Configure half-precision single-channel storage [G]
    configure_texture_format(texture, precision='HALF_FLOAT', channels='RED')
    # Set dimensions from parent packing calculation [G]
    set_texture_dimensions(texture, atlas_resolution.x, atlas_resolution.y, atlas_resolution.z)
    # Bind flat voxel data buffer [G]
    bind_texture_data(texture, atlas_buffer)
    # Set interpolation mode, defaulting to linear [S1, unofficial]
    filter_mode = texture_filter if texture_filter is not None else 'LINEAR'
    set_texture_filter(texture, filter_mode)
    # Upload to GPU memory [G]
    upload_texture_to_gpu(texture)
    # Update shader uniforms [S1, unofficial]
    uniforms = {
        'volumeAtlas': texture,
        'atlasResolution': atlas_resolution,
        'volumeResolution': volume_resolution,
        'voxelSize': voxel_size,
        'timeCount': time_count,
        'volumeOrigin': volume_origin
    }
    return texture, uniforms
```

## Subtopics

### [Atlas Budget Validation](8813-atlas-budget-validation.md)
Ensures the coarsest pyramid level's brick grid fits within the GPU's available VRAM budget, preventing out-of-memory (OOM) crashes during initialization, particularly on mobile GPUs. It acts as a gatekeeper before texture allocation, calculating the required memory for the base level and comparing it against a configurable limit.
