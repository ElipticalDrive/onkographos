# 3D Volume Atlas Packing

Also called: Multi-volume 3D Texture Packing, Time-step Volume Atlas

## Overview
3D Volume Atlas Packing packs multiple volumes or timesteps into a single 3D texture by calculating a 3D grid resolution and allocating a flat buffer [S1, unofficial]. It differs from [Texture Uniting (Multi-Channel Packing)](2470-texture-uniting-multi-channel-packing.md), which combines semantic channels of a single volume, by handling distinct volumetric datasets along a dedicated atlas dimension [G].

## How it works
**Inputs:**
- `timeCount`: Integer, total number of volumes/timesteps to pack [S1, unofficial].
- `volumeResolution`: A 3D vector $(V_x, V_y, V_z)$ representing the voxel dimensions of a single source volume [S1, unofficial].
- `textureFilter`: Sampling mode (default: `LinearFilter`) [S1, unofficial].
- `source_volumes`: List of arrays, each containing voxel data for one volume in row-major order [G].

**Outputs:**
- A flat voxel buffer [S1, unofficial].
- A 3D texture object configured with specific dimensions and format [S1, unofficial].

**Data Structures:**
1. **Voxel Buffer**: A flat `Uint16Array` of length $T_x \times T_y \times T_z$, stored in row-major order (X fastest, then Y, then Z). Each element is a 16-bit unsigned integer representing a single voxel value [S1, unofficial].
2. **3D Texture**: A `Data3DTexture` with dimensions $(T_x, T_y, T_z)$, format `RedFormat`, type `HalfFloatType`, and wrapping set to `ClampToEdgeWrapping` on all axes [S1, unofficial].

**Algorithm:**
1. Calculate the atlas grid dimensions. Let $R = \lceil \sqrt[3]{\text{timeCount}} \rceil$ [S1, unofficial].
2. Set the atlas X and Y resolutions to $R$: $A_x = R$, $A_y = R$ [S1, unofficial].
3. Calculate the atlas Z resolution to accommodate all volumes: $A_z = \lceil \text{timeCount} / (A_x \times A_y) \rceil$ [S1, unofficial].
4. Compute the final texture dimensions by scaling the single volume resolution by the atlas grid: $T_x = V_x \times A_x$, $T_y = V_y \times A_y$, $T_z = V_z \times A_z$ [S1, unofficial].
5. Allocate the flat buffer of size $T_x \times T_y \times T_z$ [S1, unofficial].
6. Populate the buffer with voxel data from each source volume. The mapping from logical volume index $k$ ($0 \le k < \text{timeCount}$) and local voxel coordinates $(v_x, v_y, v_z)$ to global texture coordinates $(t_x, t_y, t_z)$ is:
   $$ \text{grid}_x = k \pmod{A_x} $$
   $$ \text{grid}_y = \lfloor k / A_x \rfloor \pmod{A_y} $$
   $$ \text{grid}_z = \lfloor k / (A_x \times A_y) \rfloor $$
   $$ t_x = v_x + \text{grid}_x \times V_x $$
   $$ t_y = v_y + \text{grid}_y \times V_y $$
   $$ t_z = v_z + \text{grid}_z \times V_z $$
   [S1, unofficial]
7. Create the 3D texture from the buffer with the calculated dimensions and format [S1, unofficial].
8. Configure texture parameters: set min/mag filters to `textureFilter` and wrap modes to `ClampToEdgeWrapping` [S1, unofficial].

**Pseudocode:**
```python
import math

def pack_volumes(time_count, volume_resolution, texture_filter, source_volumes):
    if time_count == 0:
        return []
    
    # 1. Calculate atlas grid dimensions
    r = math.ceil(time_count ** (1/3))
    atlas_x = r
    atlas_y = r
    atlas_z = math.ceil(time_count / (atlas_x * atlas_y))

    # 2. Compute texture dimensions
    vol_x, vol_y, vol_z = volume_resolution
    tex_x = vol_x * atlas_x
    tex_y = vol_y * atlas_y
    tex_z = vol_z * atlas_z

    # 3. Allocate buffer (Python list representing Uint16Array per [S1, unofficial])
    buffer_size = tex_x * tex_y * tex_z
    voxels = [0] * buffer_size

    # 4. Populate buffer
    for k in range(time_count):
        src_vol = source_volumes[k]
        
        # Determine grid position for this volume
        grid_x = k % atlas_x
        grid_y = (k // atlas_x) % atlas_y
        grid_z = k // (atlas_x * atlas_y)
        
        # Offset in the global texture
        offset_x = grid_x * vol_x
        offset_y = grid_y * vol_y
        offset_z = grid_z * vol_z
        
        # Copy voxels
        for v_z in range(vol_z):
            for v_y in range(vol_y):
                for v_x in range(vol_x):
                    # Source index (row-major: X fastest)
                    src_idx = (v_z * vol_y * vol_x) + (v_y * vol_x) + v_x
                    
                    # Target index (row-major: X fastest)
                    tgt_idx = ((v_z + offset_z) * tex_y * tex_x) + \
                              ((v_y + offset_y) * tex_x) + \
                              (v_x + offset_x)
                    
                    voxels[tgt_idx] = src_vol[src_idx]

    # 5. Create texture object
    # Implementation specific: create Data3DTexture(voxels, tex_x, tex_y, tex_z)
    # Set format: RedFormat
    # Set type: HalfFloatType
    # Set filter: texture_filter
    # Set wrap: ClampToEdgeWrapping for S, T, R
    return voxels
```

**Edge Cases:**
- If `timeCount` is 0, the grid dimensions should default to 1 or handle as empty [G].
- Precision issues in `cbrt` calculation may require epsilon adjustment for perfect cubes, though `ceil` generally handles integer inputs correctly [G].

## Operating characteristics
- Memory complexity: Not given in the sources [S1, unofficial].
- Time complexity: Not given in the sources [S1, unofficial].
- Performance: Not given in the sources [S1, unofficial].
- Limitations: The method assumes the hardware supports 3D textures with the specified format (e.g., `RedFormat`, `HalfFloatType`) [S1, unofficial]. Interpolation across volume boundaries may produce artifacts if not handled carefully in the shader, as adjacent voxels in texture space may belong to different logical volumes [G].
