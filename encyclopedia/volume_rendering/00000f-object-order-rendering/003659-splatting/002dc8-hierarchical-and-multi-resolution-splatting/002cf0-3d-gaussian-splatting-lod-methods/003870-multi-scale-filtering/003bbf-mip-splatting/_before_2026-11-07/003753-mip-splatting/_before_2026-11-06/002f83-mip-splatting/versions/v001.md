# MIP-Splatting


## Overview
MIP-Splatting is an extension of 3D Gaussian Splatting (3DGS) that introduces 2D and 3D Gaussian filters to improve robustness to aliasing caused by resolution changes, focal length variations, or camera distance changes [S1][S3, unofficial]. It sets itself apart from standard 3DGS by replacing the simple dilation filter with explicit frequency control mechanisms, thereby eliminating dilation and erosion artifacts when zooming in or out [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 3D Gaussians $\{G_i\}$, each defined by a center $\mathbf{c}_i$, a covariance matrix $\mathbf{\Sigma}_i$ (or rotation $\mathbf{R}_i$ and scale $\mathbf{s}_i$), opacity $\alpha_i$, and spherical harmonic coefficients for color. Camera parameters (view matrix $\mathbf{V}$, projection matrix $\mathbf{P}$, intrinsics).
*   **Outputs:** A rendered image with reduced aliasing artifacts.

**Data Structures:**
The method operates on the standard 3DGS Gaussian representation but modifies the covariance during the splatting process. No new persistent data structures are introduced; the filtering is applied dynamically during rendering or optimization.

**Method Steps:**
The core innovation is the application of Gaussian filters in both 3D and 2D spaces to enforce a maximum sampling rate.

1.  **3D Smoothing Filter (Pre-rendering/Optimization):**
    *   Limit the minimum size of primitives based on visibility from training views.
    *   Ensure each primitive is visible from at least one pixel in the training set. This prevents primitives from becoming too small to be adequately sampled, which causes high-frequency artifacts [S4].
    *   *Note:* While [S4] describes this as a strategy adopted from MIP-Splatting to limit primitive size, MIP-Splatting itself uses this to control the maximum frequency of primitives [S4].

2.  **2D Mip Filter (Rendering):**
    *   When projecting a 3D Gaussian to screen space, the resulting 2D covariance $\mathbf{\Sigma}_{2D}$ is modified to account for the sampling rate.
    *   Calculate the screen-space covariance $\mathbf{\Sigma}_{2D}$ using the standard 3DGS projection:
        $$ \mathbf{\Sigma}_{2D} = \mathbf{J} \mathbf{W} \mathbf{\Sigma}_{3D} \mathbf{W}^T \mathbf{J}^T $$
        where $\mathbf{J}$ is the Jacobian of the affine approximation of the projective transformation, and $\mathbf{W}$ is the view matrix rotation component [S1][S3, unofficial].
    *   Apply the Mip filter by adding a smoothing term to the covariance. The exact formula for the 2D Mip filter in MIP-Splatting involves scaling the covariance based on the pixel footprint. If the Gaussian is smaller than the pixel size, it is blurred.
    *   *Implementation Detail:* The method enforces a maximum sampling rate. If the Gaussian's projected size is smaller than the Nyquist limit, the covariance is inflated. This is conceptually similar to a Mipmap level selection but applied continuously to the Gaussian kernel [S2, unofficial].

3.  **Splatting and Compositing:**
    *   Render the modified Gaussians using alpha compositing.
    *   The modified covariance $\mathbf{\Sigma}_{2D}'$ is used to compute the screen-space Gaussian values.
    *   Standard alpha blending is performed:
        $$ C = \sum_{i \in \text{sorted}} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$

**Parameters:**
*   **Filter Strength:** Not explicitly defined with a single scalar in the provided notes, but implied to be tied to the pixel sampling rate and resolution changes [S1].
*   **Visibility Threshold:** For the 3D smoothing step, primitives must be visible from at least one pixel [S4].

**Edge Cases and Pitfalls:**
*   **Precision:** Standard floating-point precision issues in covariance decomposition may arise if the Gaussian becomes extremely small or large.
*   **Boundary:** The 2D Mip filter is incompatible with methods that modify the screen-space Gaussian distribution directly without relying on covariance modification (e.g., LinPrim) [S4].

**Pseudocode:**
```python
def render_mip_splatting(gaussians, camera):
    """
    Render a scene using MIP-Splatting filters.
    gaussians: List of Gaussian objects with properties:
        - center: (x, y, z)
        - scale: (sx, sy, sz)
        - rotation: quaternion
        - opacity: float
        - sh_coeffs: spherical harmonic coefficients
    camera: Camera object with properties:
        - view_matrix: 4x4 matrix
        - proj_matrix: 4x4 matrix
        - intrinsics: focal length, principal point
    """
    # 1. Project Gaussians to Screen Space
    screen_gaussians = []
    for g in gaussians:
        # Standard 3DGS projection
        # Compute 3D covariance in world space
        R = quaternion_to_rotation_matrix(g.rotation)
        S = scale_to_matrix(g.scale)
        Sigma_3D = R @ S @ S.T @ R.T
        
        # Transform to camera space
        W = camera.view_matrix[:3, :3]
        T = camera.view_matrix[:3, 3]
        Sigma_cam = W @ Sigma_3D @ W.T
        
        # Compute Jacobian of the projective transformation
        # J is the 2x3 Jacobian of the projection at the Gaussian center
        J = compute_jacobian(g.center, camera.proj_matrix, camera.intrinsics)
        
        # Projected 2D covariance
        Sigma_2D = J @ Sigma_cam @ J.T
        
        # 2. Apply 2D Mip Filter
        # Determine the pixel footprint size (e.g., based on focal length and depth)
        # If the Gaussian is smaller than the pixel size, inflate the covariance
        # This is the core of MIP-Splatting's anti-aliasing
        pixel_size = get_pixel_size(camera, g.center[2])
        
        # Add smoothing to covariance to enforce maximum sampling rate
        # Sigma_2D_filtered = Sigma_2D + smoothing_term
        # The smoothing term ensures the Gaussian covers at least one pixel
        Sigma_2D_filtered = apply_mip_filter(Sigma_2D, pixel_size)
        
        # Compute screen-space center
        center_screen = project_point(g.center, camera.proj_matrix, camera.intrinsics)
        
        screen_gaussians.append({
            'center': center_screen,
            'covariance': Sigma_2D_filtered,
            'opacity': g.opacity,
            'color': evaluate_sh(g.sh_coeffs, g.center, camera.direction)
        })
    
    # 3. Sort and Composite
    # Sort by depth for correct alpha blending
    screen_gaussians.sort(key=lambda g: g['center'][2])
    
    image = zeros_like(image_buffer)
    alpha_accum = zeros_like(image_buffer)
    
    for g in screen_gaussians:
        # Rasterize the 2D Gaussian with filtered covariance
        # Compute contribution to pixels within bounding box
        pixels = get_pixels_in_bbox(g['center'], g['covariance'])
        
        for p in pixels:
            # Evaluate 2D Gaussian at pixel p
            dist = (p - g['center'])
            val = exp(-0.5 * dist.T @ inv(g['covariance']) @ dist)
            contribution = g['opacity'] * val * g['color']
            
            # Alpha blending
            alpha = val * g['opacity']
            image[p] = image[p] * (1 - alpha) + contribution
            alpha_accum[p] = alpha_accum[p] * (1 - alpha) + alpha
            
    return image

def apply_mip_filter(Sigma_2D, pixel_size):
    """
    Apply MIP filter by inflating covariance if Gaussian is smaller than pixel.
    """
    # Calculate eigenvalues of Sigma_2D
    eigenvalues = eigvals(Sigma_2D)
    
    # Determine if Gaussian is undersampled
    # If the Gaussian's extent is smaller than the pixel size, add noise/smoothing
    # This is a conceptual implementation; exact formula depends on specific MIP-Splatting variant
    # Typically: Sigma_filtered = Sigma + (pixel_size^2 / 4) * I
    smoothing = (pixel_size ** 2 / 4.0) * np.eye(2)
    return Sigma_2D + smoothing
```

## Subtopics

### LinPrim Anti-Aliasing
An anti-aliasing strategy that combines a 3D smoothing filter and a bounding box expansion technique to limit high frequencies and prevent aliasing/dilation artifacts [S4]. It applies the 3D smoothing strategy to limit primitive size based on visibility, ensuring each primitive is visible from at least one pixel [S4]. It uses Bounding Box Expansion: identifying vertices on the bounding box used for tiling and shifting them outward, parallel to the screen. This enlarges the bounding box footprint and increases the minimum size at which the primitive appears. Expanding the distance from the center raises the opacity along the primitive as it is evaluated over a larger extent, acting as a coarse band-limiting approximation [S4]. **Pitfall:** It is incompatible with MIP-Splatting's 2D Mip filter because LinPrim primitives do not rely on modifying the screen space Gaussian distribution [S4].

### Anti-Aliasing via Kernel Adaptation
Adapts the kernel bandwidth to prevent aliasing when the volume is undersampled relative to the screen (low magnification or perspective) [S5, unofficial]. It calculates the Jacobian $J$ of the local perspective distortion for each point and computes the ray-space ellipsoid $G_{JMV}$ using $J$ to stretch the kernel appropriately [S5, unofficial]. Swan '97 and Mueller '98 suggest linearly increasing splat kernel size and linearly decreasing splat amplitude [S5, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering time is similar to standard 3DGS, with minor overhead for covariance modification.
*   **Memory Complexity:** No additional memory overhead compared to standard 3DGS.
*   **Strengths:** Eliminates dilation/erosion artifacts when zooming in/out [S2, unofficial]. Improves robustness to resolution changes, focal length variations, or camera distance changes [S1][S3, unofficial].
*   **Limitations:** The 2D Mip filter is incompatible with methods that modify screen-space distribution directly (e.g., LinPrim) [S4]. Conventional projection in MIP-Splatting results in larger approximation error compared to optimal projection strategies [S6].
*   **When to use:** When rendering scenes with varying camera distances, focal lengths, or resolutions where aliasing is a concern.
*   **When not to use:** When using primitives that do not rely on screen-space Gaussian distribution modification (e.g., LinPrim) [S4].

## Background
MIP-Splatting was introduced by Yu et al. at CVPR 2024 [S2, unofficial]. It addresses the limitations of 3DGS's dilation filter, which fails to suppress high-frequency artifacts when varying focal length or camera distance [S1][S3, unofficial]. It builds on the concept of Gaussian splatting for multi-resolution applications [S1][S3, unofficial].
