# Pre-Classified Splatting

Also called: Pre-Classified Rendering

## Overview
Pre-classified splatting is a volume rendering strategy where classification and shading are applied to the raw density volume prior to the splatting process [S1, unofficial]. This approach solves the problem of edge blurring inherent in standard splatting by ensuring that the data being projected is already optically defined, although it results in a blurred edge image upon reconstruction due to the subsequent smoothing kernel [S1, unofficial]. It is distinguished from post-classified splatting, which performs classification after projection to preserve crisp edges, by its reliance on pre-computed optical properties [S1, unofficial].

## How it works
**Inputs:** Raw density volume, viewing parameters (camera position, orientation, field of view).
**Outputs:** Final 2D image.

**Data Structures:**
1.  **Color and Opacity Volume:** A 3D grid storing pre-classified color ($C$) and opacity ($\alpha$) values for each voxel. These are derived from the raw density volume.
2.  **Sheet Buffer:** A 2D buffer aligned with the image plane (or principal axes) used to accumulate splatted contributions.

**Steps:**
1.  **Classify and Shade:** Iterate through the raw density volume. For each voxel, apply a transfer function to determine its final color $C$ and opacity $\alpha$. This creates the Color and Opacity Volume [S1, unofficial].
2.  **Splat:** Project the voxels from the Color and Opacity Volume onto the sheet buffer. Each voxel is treated as a splat with a specific footprint (e.g., Gaussian kernel). The splatting operation adds the voxel's color and opacity to the corresponding pixels in the sheet buffer [S1, unofficial].
    *   *Note:* This step requires multiple footprint rasterizations per point if the footprint is not axis-aligned or if high precision is required [S1, unofficial].
3.  **Composite:** Combine the accumulated values in the sheet buffer to produce the final pixel colors for the current view. Standard alpha compositing is used [S1, unofficial].
4.  **Advance:** Update the sheet buffer position or structure for the next viewing angle or slice [S1, unofficial].

**Pseudocode:**
```python
def pre_classified_splatting(raw_density_volume, transfer_function, camera_params):
    # Step 1: Classify and Shade
    # Create a volume of color and opacity
    color_opacity_volume = empty_3d_array_like(raw_density_volume)
    for voxel in raw_density_volume:
        density = voxel.density
        # Apply transfer function to get color and opacity
        color_opacity_volume[voxel.id] = transfer_function(density)
    
    # Step 2: Splat into Sheet Buffer
    # Initialize sheet buffer (e.g., 2D array for current view)
    sheet_buffer = initialize_sheet_buffer(camera_params)
    
    for voxel in color_opacity_volume:
        if voxel.opacity > 0:
            # Project voxel onto sheet buffer
            # Determine footprint and rasterize
            splat_footprint = get_footprint(voxel, camera_params)
            rasterize_splat(splat_footprint, voxel.color, voxel.opacity, sheet_buffer)
            
    # Step 3: Composite
    final_image = composite_sheet_buffer(sheet_buffer)
    
    return final_image
```

**Parameters:**
*   **Transfer Function:** Maps density to color and opacity. Typical values depend on the dataset.
*   **Splat Kernel:** Gaussian kernel is commonly used [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Blurred Edges:** The primary pitfall is that the reconstruction results in a blurred edge image because the classification is done before the smoothing effect of the splatting kernel is applied [S1, unofficial].
*   **Pre-processing Cost:** Requires significant pre-processing to classify and shade the entire volume [S1, unofficial].

## Subtopics

### Edge Splats
Edge splats are a solution to the blurred edges problem in pre-classified splatting by replacing normal splats with special edge splats [S1, unofficial]. This method aims to preserve edge sharpness but has shortcomings including required pre-processing, problems with discontinuities, and difficulty resolving 'micro-edges' [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** High pre-processing time due to classification and shading of the entire volume. Splatting time is proportional to the number of non-transparent voxels.
*   **Memory Complexity:** Requires storage for the Color and Opacity Volume in addition to the sheet buffer.
*   **Strengths:** Simplifies the rendering loop by decoupling classification from projection.
*   **Limitations:** Results in blurred edges upon reconstruction. Requires pre-processing.
*   **When to use:** When pre-processing is acceptable and edge sharpness is less critical than rendering speed or simplicity.
*   **When not to use:** When crisp edges are required (use Post-Classified Splatting instead).

## Background
Pre-classified splatting is a foundational technique in volume rendering, often contrasted with post-classified splatting (Mueller '99) [S1, unofficial]. It represents an early approach to handling volume data by pre-computing optical properties.
