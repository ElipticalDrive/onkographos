# RLE Accelerated Sheet Buffer Splatting

Also called: RLE accelerated, pre-classification and pre-shade sheet buffer volume splatting, RLE based sheet buffer splatting

## Overview
RLE Accelerated Sheet Buffer Splatting is a volume rendering algorithm that accelerates object-order splatting by combining Run Length Encoding (RLE) with a sheet buffer approach, utilizing pre-classified and pre-shaded voxel data to skip transparent regions [S1]. It solves the performance bottleneck of processing large volumes with high transparency by exploiting spatial coherence, allowing the renderer to traverse only non-transparent voxel scanlines while simultaneously updating the image plane [S1]. Unlike standard splatting which processes every voxel, or Lacroute’s shear-warp method which uses a single RLE structure, this method maintains three sets of RLE structures for principal axes to ensure the sheet buffer remains parallel to the image plane, enabling flexible random access and avoiding alignment issues [S1].

## How it works
The method consists of a pre-processing phase to prepare the data and a rendering phase to composite the image. It builds on [Pre-Classified Splatting](5410-pre-classified-splatting.md) by moving classification and shading out of the rendering loop and adding RLE acceleration.

### Inputs and Outputs
*   **Input:** Raw density volume (scalar field), transfer function (mapping density to opacity), illumination model (e.g., Phong), and camera parameters (view direction, projection).
*   **Output:** Final 2D image (RGB with alpha).

### Data Structures
The algorithm constructs four tables for each of the three principal volume axes (X, Y, Z). Let $N_x, N_y, N_z$ be the dimensions of the volume. For a given principal axis (e.g., Z), the structures are:

1.  **Slice Scanline Pointer Array ($S$):** An array of pointers. $S_{ij}$ points to the first entry in the Scanline RLE Array corresponding to the $j$-th scanline in the $i$-th slice (perpendicular to the principal axis). If the entire scanline is transparent, $S_{ij} = -1$ [S1].
2.  **Data Pointer Array ($D$):** An array where each entry $D_i$ points to the starting index in the Voxel Data Array for the $i$-th slice. This pointer manages all non-transparent voxels in that slice [S1].
3.  **Scanline RLE Array ($R$):** A sequence of integers representing run lengths. It is constructed in slice-by-slice, scanline-by-scanline order. It stores the lengths of transparent runs and non-transparent runs. Since transparent voxels are skipped, this array primarily tracks transparent run lengths to skip over them, followed by the count of non-transparent voxels in that segment [S1].
4.  **Voxel Data Array ($V$):** Stores pre-computed optical properties (opacity $\alpha$ and RGB color) for non-transparent voxels only. Entries are stored sequentially as they are encountered in the scanline traversal. Transparent voxels are not stored here [S1].

### Pre-processing Steps
1.  **Pre-classification:** Load the raw density volume. For each voxel, apply the transfer function to map the density value to an opacity value $\alpha$. This is done once [S1].
2.  **Pre-shading:** Calculate the RGB color for each voxel. Using the view parameters and local gradient approximated normals, apply an illumination model (e.g., Phong) to compute the color. This is done once [S1].
3.  **RLE Encoding:**
    *   Iterate through the volume slice by slice, scanline by scanline.
    *   For each scanline, identify runs of transparent voxels and runs of non-transparent voxels.
    *   Populate the **Scanline RLE Array** with the lengths of these runs.
    *   Populate the **Voxel Data Array** with the pre-classified and pre-shaded data ($\alpha, R, G, B$) for every non-transparent voxel.
    *   Populate the **Slice Scanline Pointer Array** to point to the correct position in the RLE array for each scanline.
    *   Populate the **Data Pointer Array** to point to the start of the non-transparent voxel data for each slice.
    *   Repeat this process for all three principal axes (X, Y, Z) to create three independent sets of these data structures [S1].

### Rendering Steps
1.  **View Selection:** Determine the angle between the image plane and the three principal volume axes. Select the principal axis set where the angle is less than 45 degrees. This ensures the sheet buffer is parallel to the image plane, optimizing the traversal [S1].
2.  **Sheet Buffer Initialization:** Initialize a sheet buffer (a temporary image buffer) parallel to the selected principal axis.
3.  **Traversal and Splatting:**
    *   Traverse the voxel scanlines defined by the RLE structures.
    *   For each scanline, use the **Slice Scanline Pointer Array** to find the start in the **Scanline RLE Array**.
    *   Iterate through the RLE entries:
        *   If the entry represents a transparent run, skip that many voxels (do not access the Voxel Data Array).
        *   If the entry represents a non-transparent run, retrieve the corresponding voxel data from the **Voxel Data Array** (using the **Data Pointer Array** offset).
    *   For each non-transparent voxel:
        *   Project the voxel center onto the sheet buffer.
        *   Spread the voxel's contribution ($\alpha, RGB$) to the neighbor pixels in the sheet buffer using the reconstruction kernel.
        *   **Overlap Handling:** When multiple voxels contribute to the same pixel in the sheet buffer, use simple addition for the color and opacity contributions, rather than standard over/under compositing operations, to avoid artifacts [S1].
4.  **Final Composition:** After all voxels are splatted into the sheet buffer, composite the sheet buffer into the final image plane.

### Pseudocode

def rle_accelerated_sheet_buffer_splatting(volume, transfer_function, illumination_model, camera):
    # Pre-processing
    # 1. Pre-classification and Pre-shading
    classified_volume = {}
    for voxel in volume:
        opacity = transfer_function(voxel.density)
        color = illumination_model(voxel.position, camera.view_direction, voxel.gradient)
        classified_volume[voxel] = (opacity, color)

    # 2. Build RLE structures for all 3 principal axes
    rle_structures_x = build_rle_structures(classified_volume, axis='x')
    rle_structures_y = build_rle_structures(classified_volume, axis='y')
    rle_structures_z = build_rle_structures(classified_volume, axis='z')

    # 3. Select best axis based on view angle
    angle_x = angle_between(camera.image_plane_normal, vector(1, 0, 0))
    angle_y = angle_between(camera.image_plane_normal, vector(0, 1, 0))
    angle_z = angle_between(camera.image_plane_normal, vector(0, 0, 1))

    if angle_x < 45:
        structures = rle_structures_x
    elif angle_y < 45:
        structures = rle_structures_y
    else:
        structures = rle_structures_z

    # Rendering
    sheet_buffer = initialize_sheet_buffer(structures.axis)
    
    # Traverse slices
    for i in range(structures.num_slices):
        # Get pointer to first transparent run in this slice
        scanline_ptr = structures.slice_scanline_pointer[i]
        
        # If all transparent, skip
        if scanline_ptr == -1:
            continue
            
        # Traverse scanlines in this slice
        for j in range(structures.num_scanlines):
            # Get pointer to RLE data for this scanline
            rle_start = scanline_ptr[j]
            
            # If all transparent, skip
            if rle_start == -1:
                continue
                
            # Get pointer to voxel data for this slice
            data_start = structures.data_pointer[i]
            
            # Traverse RLE runs
            current_rle_idx = rle_start
            current_data_idx = data_start
            
            while current_rle_idx < len(structures.scanline_rle):
                run_length = structures.scanline_rle[current_rle_idx]
                
                # Check if it's a transparent run or non-transparent run
                # Note: The source implies RLE tracks transparent runs to skip,
                # and implicitly handles non-transparent runs by consuming data.
                # Assuming alternating transparent/non-transparent or explicit type flag.
                # Based on "sequences of transparent run and a nontransparent run":
                
                is_transparent_run = (current_rle_idx % 2 == 0) # Assuming even indices are transparent runs
                
                if is_transparent_run:
                    # Skip transparent voxels
                    current_rle_idx += 1
                else:
                    # Process non-transparent voxels
                    # The run_length here is the count of non-transparent voxels
                    for k in range(run_length):
                        voxel_opacity, voxel_color = structures.voxel_data[current_data_idx + k]
                        
                        # Project voxel to sheet buffer
                        sheet_pos = project_onto_sheet_buffer(voxel.position, structures.axis)
                        
                        # Splat to sheet buffer
                        splat_kernel(sheet_buffer, sheet_pos, voxel_opacity, voxel_color)
                    
                    current_data_idx += run_length
                    current_rle_idx += 1

    # Composite sheet buffer to final image
    final_image = composite_sheet_buffer(sheet_buffer, camera)
    return final_image

def construct_rle_for_scanline(voxels, classified_volume):
    rle = []
    i = 0
    n = len(voxels)
    while i < n:
        # Count transparent run
        trans_count = 0
        while i < n and classified_volume[voxels[i]].opacity == 0:
            trans_count += 1
            i += 1
        
        if trans_count > 0:
            rle.append(trans_count)
            
        # Count non-transparent run
        non_trans_count = 0
        while i < n and classified_volume[voxels[i]].opacity != 0:
            non_trans_count += 1
            i += 1
            
        if non_trans_count > 0:
            rle.append(non_trans_count)
            
    return rle if rle else None

### Parameters
*   **View Angle Threshold:** 45 degrees. If the angle between the image plane and the principal volume axis exceeds this, a different RLE structure set is used [S1].
*   **Non-transparent Voxels:** Typically 5%-30% of the total volume [S1].

### Edge Cases and Pitfalls
*   **Overlap Artifacts:** Conventional splatting uses over/under operations for overlapping pixels, which can lead to artifacts. This method uses simple addition for overlapping pixels to ensure accuracy [S1].
*   **Memory Usage:** The RLE structures require 3-5 times the memory of the original volume storage because three sets of structures (one for each principal axis) are kept in memory [S1].
*   **Alignment:** Separating run lengths from voxel data avoids alignment problems on certain processor architectures [S1].

## Operating characteristics
*   **Time Complexity:** The rendering time is linearly proportional to the number of non-transparent voxels rendered, rather than the total volume size [S1].
*   **Memory Complexity:** $O(V)$ where $V$ is the volume size, multiplied by a factor of 3-5 due to the three RLE structure sets and the separation of data [S1].
*   **Measured Performance:** On a 1 GHz AMD Duron CPU with 256MB RAM, speedups ranged from 9.1x to 26.5x compared to non-RLE splatting across datasets like CT head, lobster, MRI head, engine, X-ray foot, and bonsai [S1].
*   **Strengths:** High speedup for volumes with significant transparency; flexible random access to voxel scanlines; avoids alignment issues; accurate rendering via additive compositing in sheet buffer.
*   **Limitations:** High memory overhead (3-5x); pre-processing time for classification and shading; limited to three principal axes for RLE structures.
*   **When to Use:** When rendering large volumes with high transparency and sufficient memory is available.
*   **When Not to Use:** When memory is constrained, or when the volume has very low transparency (most voxels are opaque), reducing the benefit of RLE skipping.

## Background
The method was proposed by Zhang et al. in 2003 [S1]. It addresses the limitations of earlier acceleration techniques like splat hierarchies and octrees, which require complex traversal logic. It also improves upon Lacroute's shear-warp RLE method by separating the slice pointer array from the data pointer array and applying RLE at the scanline level, which allows for flexible random access and better performance on various processor architectures [S1]. The use of pre-classification and pre-shading was previously established in splatting literature to reduce per-pixel computation, but this method integrates it with RLE and sheet buffers for significant speedups [S1].
