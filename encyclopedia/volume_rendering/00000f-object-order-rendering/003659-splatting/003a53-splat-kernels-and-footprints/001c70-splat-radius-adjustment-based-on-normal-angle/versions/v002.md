# Splat Radius Adjustment Based on Normal Angle

Also called: Angle-dependent Splat Radius, Normal-based Splat Radius Adjustment

## Overview
This method adjusts the radius of individual splats to prevent visual holes that occur when surface samples are elevated in the normal direction of a base plane [S1, unofficial]. It scales the splat radius based on the angle between the splat's normal vector and the base plane's normal vector [S1, unofficial]. Unlike fixed-radius splatting, which assumes a flat distribution, this approach increases radii in areas with high local elevation variance, ensuring continuous coverage [S1, unofficial]. It builds on [Splat Kernels and Footprints](8724-splat-kernels-and-footprints.md) by providing a specific heuristic for radius calculation in surface splatting contexts.

## How it works
**Inputs:**
- $\mu$: The sampling step size of the regular grid on the base plane [S1, unofficial].
- $\mathbf{n}$: The normal vector of the splat (surface point) [S1, unofficial].
- $\mathbf{n}_B$: The normal vector of the base plane [S1, unofficial].

**Outputs:**
- $r$: The adjusted radius for the splat [S1, unofficial].

**Data Structures:**
- Vectors $\mathbf{n}$ and $\mathbf{n}_B$ are typically 3D unit vectors.
- The radius $r$ is a scalar value.

**Algorithm:**
1.  **Calculate Base Radius:** Determine the base radius for a flat distribution. This is defined as $\frac{1}{2}\sqrt{2}\mu$ [S1, unofficial]. This value corresponds to the radius required to cover the grid cells if samples were perfectly flat and regularly distributed [S1, unofficial].
2.  **Compute Dot Product:** Calculate the dot product between the splat normal and the base plane normal: $\langle \mathbf{n}, \mathbf{n}_B \rangle$ [S1, unofficial]. This value ranges from -1 to 1, but typically 0 to 1 for surface normals aligned with the plane orientation [S1, unofficial].
3.  **Calculate Scaling Factor:** Compute the denominator using the constants 0.1 and 0.9 [S1, unofficial]:
    $$ \text{denominator} = 0.1 + 0.9 \langle \mathbf{n}, \mathbf{n}_B \rangle $$
    The constant 0.1 prevents division by zero or excessively large radii when the dot product is small (i.e., when the splat is nearly perpendicular to the base plane) [S1, unofficial]. The constant 0.9 controls the maximal radius increase [S1, unofficial].
4.  **Compute Final Radius:** Divide the base radius by the scaling factor:
    $$ r = \frac{\frac{1}{2}\sqrt{2}\mu}{0.1 + 0.9 \langle \mathbf{n}, \mathbf{n}_B \rangle} $$
    [S1, unofficial].

**Pseudocode:**
```python
def calculate_splat_radius(mu, n, n_B):
    """
    Calculate the splat radius based on the angle between the splat normal
    and the base plane normal.

    Args:
        mu (float): Sampling step size of the regular grid.
        n (Vector3): Normal vector of the splat.
        n_B (Vector3): Normal vector of the base plane.

    Returns:
        float: Adjusted splat radius.
    """
    # Base radius for flat distribution
    base_radius = 0.5 * math.sqrt(2) * mu
    
    # Dot product between splat normal and base plane normal
    # Ensure vectors are normalized before dot product if not already
    dot_product = dot(normalize(n), normalize(n_B))
    
    # Scaling factor with constants to prevent division by zero
    # and control maximal radius increase
    denominator = 0.1 + 0.9 * dot_product
    
    # Avoid division by zero, though denominator >= 0.1 due to constant
    if denominator < 1e-6:
        return base_radius / 1e-6 # Fallback, though theoretically unreachable with 0.1 constant
        
    radius = base_radius / denominator
    
    return radius
```

**Parameters:**
- $\mu$: Grid sampling step size. Typical value depends on the resolution of the input point cloud or grid [S1, unofficial].
- Constants: 0.1 and 0.9. These are fixed heuristic values provided in the source [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Holes in Rendering:** If samples are elevated in the normal direction of the plane and radii are not adjusted, holes may occur between splats [S1, unofficial].
- **Large Angles:** A large angle between the splat normal and the plane normal indicates large variance between neighboring elevation values, resulting in increased spatial gaps [S1, unofficial]. The formula increases the radius in these areas to compensate [S1, unofficial].
- **Perpendicular Normals:** If the splat normal is nearly perpendicular to the base plane normal ($\langle \mathbf{n}, \mathbf{n}_B \rangle \approx 0$), the denominator approaches 0.1, resulting in a radius 10 times larger than the base radius [S1, unofficial]. This prevents extreme blow-up but may cause over-blending in steep areas.
- **Parallel Normals:** If the splat normal is parallel to the base plane normal ($\langle \mathbf{n}, \mathbf{n}_B \rangle = 1$), the denominator is 1.0, and the radius is exactly the base radius $\frac{1}{2}\sqrt{2}\mu$ [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per splat for radius calculation, assuming normal vectors are pre-computed [S1, unofficial].
- **Memory Complexity:** $O(1)$ additional memory per splat for storing the calculated radius [S1, unofficial].
- **Strengths:** Prevents holes in surface splatting when samples are elevated, adapting to local surface geometry [S1, unofficial].
- **Limitations:** Relies on heuristic constants (0.1, 0.9) which may not be optimal for all datasets [S1, unofficial]. Does not account for view-dependent foreshortening (unlike EWA Splatting) [S1, unofficial].
- **When to Use:** Surface splatting of regularly sampled point clouds where elevation variance causes gaps [S1, unofficial].
- **When Not to Use:** When view-dependent distortion is significant (use EWA Splatting) or when automatic density-based sizing is preferred [S1, unofficial].

## Background
This method was proposed in the context of single-pass high-quality splatting for surface rendering [S1, unofficial]. It addresses the specific issue of holes arising from the elevation of samples in the normal direction of a base plane [S1, unofficial]. The approach is part of a framework that uses regular grids on base planes and adjusts splat parameters to ensure continuous coverage [S1, unofficial].
