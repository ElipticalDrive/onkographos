# EWA Splatting with kNN Covariance Estimation

Also called: Elliptical Weighted Average splatting

## Overview
EWA Splatting with kNN Covariance Estimation is a point-cloud rendering method that projects 3D points onto 2D image planes using elliptical footprints derived from local geometric structure [S1, unofficial]. Unlike simple disk splatting which assumes isotropic coverage, this method estimates a 3D covariance matrix for each point using its $k$-nearest neighbours, allowing the splat to adapt its shape and orientation to the local surface density [S1, unofficial]. It builds on [Splatting](23-splatting.md) by providing a mechanism to generate anisotropic splats directly from raw point clouds without mesh reconstruction [S1, unofficial].

## How it works
**Inputs:**
- Point cloud: positions $\mathbf{xyz} \in \mathbb{R}^{N \times 3}$, colors $\mathbf{rgb} \in \mathbb{R}^{N \times 3}$, labels $\mathbf{l} \in \mathbb{Z}^N$.
- Camera parameters: intrinsic matrix $\mathbf{K}$ (or parameters $f_x, f_y, c_x, c_y$), extrinsic matrix $\mathbf{E}$ (world-to-camera), viewport width $W$, height $H$.
- Parameters: $k$ (number of neighbours, default 16), splat radius limit (default 32 pixels), extent margin (default 1.3).

**Outputs:**
- Color image: $\mathbf{C} \in [0, 255]^{H \times W \times 3}$ (uint8).
- Label image: $\mathbf{L} \in \mathbb{Z}^{H \times W}$ (uint8).
- Index map: $\mathbf{I} \in \mathbb{Z}^{H \times W}$ (int32), storing the source point index for each pixel (or -1 if empty).

**Data Structures:**
- KDTree: Built on $\mathbf{xyz}$ for $O(\log N)$ nearest-neighbour queries.
- Covariance Matrix: $\mathbf{\Sigma}_3 \in \mathbb{R}^{3 \times 3}$, symmetric positive semi-definite, computed per point.
- Conic Matrix: $\mathbf{C}_{2D} \in \mathbb{R}^{3 \times 3}$, representing the projected elliptical footprint in screen space.

**Steps:**

1.  **Build Neighbourhood Structure:** Convert $\mathbf{xyz}$ to a numpy array and construct a KDTree [S1, unofficial].
2.  **Query Neighbours:** For each point $i$, query the $k$-nearest neighbours to obtain indices $\mathbf{idx}_i \in \mathbb{Z}^k$ [S1, unofficial].
3.  **Gather Coordinates:** Retrieve the 3D coordinates of the $k$ neighbours for each point, forming a tensor $\mathbf{P} \in \mathbb{R}^{N \times k \times 3}$ [S1, unofficial].
4.  **Compute 3D Covariance:** Calculate the sample covariance matrix $\mathbf{\Sigma}_3^{(i)}$ for each point $i$ using its neighbour positions $\mathbf{P}_i$ [S1, unofficial].
    $$ \mathbf{\Sigma}_3^{(i)} = \frac{1}{k-1} \sum_{j=1}^{k} (\mathbf{p}_{ij} - \bar{\mathbf{p}}_i)(\mathbf{p}_{ij} - \bar{\mathbf{p}}_i)^T $$
    where $\bar{\mathbf{p}}_i$ is the mean of the $k$ neighbours.
5.  **Project to Screen Space:** For each camera view, project the 3D covariance $\mathbf{\Sigma}_3$ to a 2D conic matrix $\mathbf{C}_{2D}$ using the camera intrinsics and extrinsics [S1, unofficial]. This step also computes the projected depth and visibility mask. The projection accounts for perspective distortion, transforming the 3D ellipsoid into an elliptical footprint on the image plane [S1, unofficial].
6.  **Filter Visible Points:** Identify points that are visible ($depth > 0$) and within the viewport [S1, unofficial].
7.  **Calculate Splat Radius:** Determine the integer radius $r_{int}$ for each visible point based on the extent of the projected covariance. Clamp $r_{int}$ to the range $[0, 32]$ [S1, unofficial].
8.  **Sort by Depth:** Sort the visible points in ascending order of their depth values (front-to-back) [S1, unofficial].
9.  **Rasterize (Splat):** Iterate through the sorted points. For each point, iterate over the pixel grid defined by $[-r_{int}, r_{int}]$ in both x and y directions.
    -   Map the point's center to pixel coordinates $(u, v)$. Note that the image Y-axis is inverted relative to the camera coordinate system: $v = H - 1 - \text{round}(u_{cam})$ [S1, unofficial].
    -   If the pixel is within bounds and the current point's depth is less than the existing depth in the Z-buffer (or if the Z-buffer is empty), write the point's color, label, and index to the output canvases [S1, unofficial].
    -   The contribution is typically weighted by the EWA kernel, but in this specific implementation, it performs occlusion-aware overwriting for the visible surface [S1, unofficial].

**Pseudocode:**

```python
import torch
import numpy as np
from scipy.spatial import KDTree

def ewa_splatting_knn(xyz, rgb, label, K, E, W, H, k=16, max_radius=32):
    """
    xyz: [N, 3] float32
    rgb: [N, 3] float32 (0-1)
    label: [N] int64
    K: [4] float32 [fx, fy, cx, cy]
    E: [4, 4] float32 world-to-camera
    W, H: int
    k: int, number of neighbours
    max_radius: int, max splat radius
    """
    N = xyz.shape[0]
    
    # Step 1-3: Build KDTree and gather neighbours
    xyz_np = xyz.cpu().numpy()
    kdt = KDTree(xyz_np)
    _, knn_idx = kdt.query(xyz_np, k=k)
    xyz_padded = xyz[knn_idx] # [N, k, 3]
    
    # Step 4: Compute 3D Covariance
    # Mean of neighbours
    mean_p = xyz_padded.mean(dim=1, keepdim=True) # [N, 1, 3]
    diff = xyz_padded - mean_p # [N, k, 3]
    # Covariance: (N, k, 3) @ (N, 3, k) -> (N, 3, 3)
    cov3d = torch.bmm(diff.transpose(1, 2), diff) / (k - 1)
    
    # Step 5: Project Covariance and Points
    # Extract R and t from E
    R = E[:3, :3]
    t = E[:3, 3]
    
    # Transform points to camera space
    # xyz: [N, 3] -> [N, 3, 1]
    # pt_cam = R @ xyz.T + t -> [3, N]
    xyz_cam = torch.matmul(R, xyz.transpose(0, 1)) + t.unsqueeze(1) # [3, N]
    xyz_cam = xyz_cam.transpose(0, 1) # [N, 3]
    
    # Project to 2D
    fx, fy, cx, cy = K
    z = xyz_cam[:, 2] # [N]
    u = (xyz_cam[:, 0] * fx / z) + cx # [N]
    v = (xyz_cam[:, 1] * fy / z) + cy # [N]
    
    # Project Covariance to 2D Conic
    # J is the Jacobian of the projection
    # Simplified projection for covariance:
    # C_2d = J @ C_3d @ J^T
    # J = [[fx/z, 0, -fx*x/z^2],
    #      [0, fy/z, -fy*y/z^2]]
    x, y, z_vals = xyz_cam[:, 0], xyz_cam[:, 1], xyz_cam[:, 2]
    J = torch.zeros(N, 2, 3)
    J[:, 0, 0] = fx / z_vals
    J[:, 0, 2] = -fx * x / (z_vals ** 2)
    J[:, 1, 1] = fy / z_vals
    J[:, 1, 2] = -fy * y / (z_vals ** 2)
    
    cov2d = torch.bmm(torch.bmm(J, cov3d), J.transpose(1, 2)) # [N, 2, 2]
    
    # Calculate radius from eigenvalues of cov2d
    # Radius is proportional to sqrt(eigenvalue)
    eigenvalues = torch.linalg.eigvalsh(cov2d) # [N, 2]
    radius = torch.sqrt(torch.max(eigenvalues, dim=1).values) # [N]
    radius_int = torch.clamp(radius.long(), 0, max_radius)
    
    # Visibility mask
    visible = (z > 0) & (u >= 0) & (u < W) & (v >= 0) & (v < H)
    
    if not visible.any():
        return np.zeros((H, W, 3), dtype=np.uint8), \
               np.zeros((H, W), dtype=np.uint8), \
               np.full((H, W), -1, dtype=np.int32)
    
    # Step 6-8: Filter and Sort
    vis_idx = torch.where(visible)[0]
    vis_depth = z[vis_idx]
    vis_u = u[vis_idx]
    vis_v = v[vis_idx]
    vis_rgb = rgb[vis_idx]
    vis_label = label[vis_idx]
    vis_radius = radius_int[vis_idx]
    
    # Sort by depth ascending (front-to-back)
    sort_idx = torch.argsort(vis_depth)
    vis_idx = vis_idx[sort_idx]
    vis_depth = vis_depth[sort_idx]
    vis_u = vis_u[sort_idx]
    vis_v = vis_v[sort_idx]
    vis_rgb = vis_rgb[sort_idx]
    vis_label = vis_label[sort_idx]
    vis_radius = vis_radius[sort_idx]
    
    # Step 9: Rasterize
    color_img = np.zeros((H, W, 3), dtype=np.uint8)
    label_img = np.zeros((H, W), dtype=np.uint8)
    index_map = np.full((H, W), -1, dtype=np.int32)
    depth_canvas = np.full((H, W), np.inf, dtype=np.float32)
    
    for i in range(len(vis_idx)):
        idx = vis_idx[i].item()
        u_px = vis_u[i].item()
        v_px = vis_v[i].item()
        r = vis_radius[i].item()
        
        # Flip Y axis for image coordinates
        v_img = H - 1 - v_px
        
        # Iterate over splat area
        for dy in range(-r, r + 1):
            for dx in range(-r, r + 1):
                py = int(v_img + dy)
                px = int(u_px + dx)
                
                if 0 <= py < H and 0 <= px < W:
                    # Simple Z-buffer check
                    if vis_depth[i].item() < depth_canvas[py, px]:
                        depth_canvas[py, px] = vis_depth[i].item()
                        color_img[py, px] = (vis_rgb[i] * 255).astype(np.uint8)
                        label_img[py, px] = vis_label[i].item()
                        index_map[py, px] = idx
                        
    return color_img, label_img, index_map
```

## Operating characteristics
- **Time Complexity:** $O(N \log N)$ for KDTree construction and $O(N \cdot k)$ for neighbour queries. Projection and rasterization are $O(N \cdot r^2)$ where $r$ is the average splat radius.
- **Memory Complexity:** $O(N \cdot k)$ to store neighbour indices and intermediate covariance tensors.
- **Performance:** Real-time performance is achievable on modern GPUs for point clouds up to millions of points, depending on $k$ and $r$ [S1, unofficial].
- **Strengths:** Handles raw point clouds without meshing; adapts splat shape to local geometry, reducing aliasing and gaps [S1, unofficial].
- **Limitations:** Sensitive to $k$; too small $k$ leads to noisy covariance, too large $k$ blurs fine details. Performance degrades with very large $k$ or large splat radii [S1, unofficial].
