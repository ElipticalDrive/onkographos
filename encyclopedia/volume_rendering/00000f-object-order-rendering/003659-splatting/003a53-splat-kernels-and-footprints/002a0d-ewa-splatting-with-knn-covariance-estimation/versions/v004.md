# EWA Splatting with kNN Covariance Estimation

Also called: Elliptical Weighted Average splatting

## Overview
A rendering method that uses per-point 3D covariance estimated from k-nearest neighbours to project an elliptical weighted average (EWA) shape onto the 2D image plane for denser coverage than simple disk splatting [S1, unofficial]. It builds on [EWA Splatting](1069-ewa-splatting.md) by replacing the simplified spherical impostor with an anisotropic footprint derived from local point cloud geometry, trading the need for explicit surface normals for a statistical estimate of local orientation [S1, unofficial].

## How it works
**Inputs:**
- Point cloud: `xyz` ($[N, 3]$ float32), `rgb` ($[N, 3]$ float32, normalized to $[0,1]$), `label` ($[N]$ int64).
- Camera batch: `intr` ($[M, 4]$ intrinsics $f_x, f_y, c_x, c_y$), `extr` ($[M, 4, 4]$ world-to-camera matrices), viewport dimensions $W, H$.
- Parameters: $k$ (neighbours, default 16), `splat_radius` (pixel radius, default 1), `extent` (frustum culling margin, default 1.3).

**Outputs:**
- `color_img_np`: $[H, W, 3]$ uint8.
- `label_img_np`: $[H, W]$ uint8.
- `index_map_np`: $[H, W]$ int32 (pixel-to-point index, -1 if empty).

**Data Structures:**
- KDTree built on `xyz` for $k$-NN queries.
- `cov3d`: $[N, 3, 3]$ covariance matrices.
- `knn_idx`: $[N, k]$ integer indices.
- `xyz_padded`: $[N, k, 3]$ neighbour coordinates.
- Visibility mask: `visible` ($[N, 1, M]$ boolean).
- Depth canvas: initialized to infinity for occlusion testing.

**Steps:**

1. **Load Data:** Convert `xyz` to CPU numpy for KDTree construction. Load `xyz`, `rgb`, `label` to GPU. Normalize `rgb` to $[0,1]$ if uint8 [S1, unofficial].
2. **Build KDTree:** Construct a KDTree from `xyz_np` [S1, unofficial].
3. **Query Neighbours:** Query $k$-nearest neighbours for all points. `_, knn_idx = kdt.query(xyz_np, k=k)`. Shape $[N, k]$ [S1, unofficial].
4. **Gather Coordinates:** Gather neighbour positions: `xyz_padded = self.xyz[knn_idx]`. Shape $[N, k, 3]$ [S1, unofficial].
5. **Compute 3D Covariance:** Calculate the covariance matrix for each point using its neighbours. `cov3d = compute_cov3d(xyz_padded)`. Shape $[N, 3, 3]$. [G] The covariance is typically computed as the sample covariance of the $k$ neighbours relative to the point's position, or the centroid of the neighbours.
6. **Project to 2D:** For each camera view (processed in batches), project the 3D covariance to 2D using `ewa_project`. Inputs: `xyz_b`, `cov3d_b`, `intr_b`, `extr_b`, `uv_j`, $W$, $H$, `vis_j`. Outputs: conic matrix, radius, and tile information [S1, unofficial].
7. **Filter Visible Points:** In `_assemble_view_ewa`, filter points where `visible.squeeze(-1) > 0` and `depths.squeeze(-1) > 0` [S1, unofficial].
8. **Calculate Pixel Coordinates:** Compute pixel coordinates `px` and `py`. Flip Y-axis: `py = H - 1 - torch.round(uv_vis[:, 1]).long()` because world camera Y points up while image v points down [S1, unofficial].
9. **Determine Radius:** Calculate integer radius `r_int` clamped between 0 and 32: `r_int = radius_vis.long().clamp(0, 32)` [S1, unofficial].
10. **Sort by Depth:** Sort visible points by depth ascending: `d_sorted, sort_idx = torch.sort(d_flat)` [S1, unofficial].
11. **Rasterize:** Iterate through points in depth order. For each point, iterate `dy` from `-r_k` to `r_k` and `dx` from `-r_k` to `r_k`. If the pixel is within bounds and the current depth `d_k` is less than the existing `depth_canvas`, write the color, label, and index [S1, unofficial].

**Pseudocode:**

```python
import torch
import numpy as np
from sklearn.neighbors import KDTree

def compute_cov3d(xyz_padded):
    """
    Compute 3D covariance matrix for each point from its k-nearest neighbours.
    xyz_padded: [N, k, 3]
    Returns: [N, 3, 3]
    """
    # Center the neighbours around the point's position (or their centroid)
    # Assuming xyz_padded[:, 0] is the point itself or centroid
    # Standard sample covariance: 1/(k-1) * (X - mean)^T (X - mean)
    # [G] Implementation detail: subtract mean of neighbours, then compute covariance
    mean = xyz_padded.mean(dim=1, keepdim=True)  # [N, 1, 3]
    diff = xyz_padded - mean                     # [N, k, 3]
    # Covariance = (diff^T @ diff) / (k-1)
    cov = torch.bmm(diff.transpose(1, 2), diff) / (xyz_padded.shape[1] - 1)
    return cov

def ewa_splatting_with_knn(xyz, rgb, label, intr, extr, W, H, k=16, splat_radius=1, extent=1.3):
    """
    Main rendering pipeline.
    xyz: [N, 3] float32
    rgb: [N, 3] float32 (0-1)
    label: [N] int64
    intr: [M, 4] float32
    extr: [M, 4, 4] float32
    """
    N = xyz.shape[0]
    M = intr.shape[0]
    device = xyz.device
    
    # Step 1-4: Build KDTree and compute 3D Covariance
    xyz_np = xyz.cpu().numpy()
    kdt = KDTree(xyz_np)
    _, knn_idx = kdt.query(xyz_np, k=k)
    xyz_padded = xyz[knn_idx] # [N, k, 3]
    cov3d = compute_cov3d(xyz_padded) # [N, 3, 3]
    
    # Initialize output canvases
    color_img = torch.zeros((H, W, 3), dtype=torch.uint8, device=device)
    label_img = torch.zeros((H, W), dtype=torch.uint8, device=device)
    index_map = torch.full((H, W), -1, dtype=torch.int32, device=device)
    depth_canvas = torch.full((H, W), float('inf'), dtype=torch.float32, device=device)
    
    # Step 5-6: Project and Filter
    # [G] project_points and shelter_points are external helpers
    # uv: [N, 2, M], depths: [N, 1, M], visible: [N, 1, M]
    uv, depths = project_points(xyz, intr, extr, W, H, nearest=0.2, extent=extent)
    # Permute to [N, 2, M] and [N, 1, M]
    uv = uv.permute(1, 2, 0).contiguous()
    depths = depths.permute(1, 2, 0).contiguous()
    
    visible = shelter_points(uv, depths, W, H) # [N, 1, M]
    
    # Filter visible points
    vis_idx = torch.where(visible.squeeze(-1) > 0)[0]
    if vis_idx.numel() == 0:
        return color_img.cpu().numpy(), label_img.cpu().numpy(), index_map.cpu().numpy()
        
    xyz_vis = xyz[vis_idx]
    rgb_vis = rgb[vis_idx]
    label_vis = label[vis_idx]
    cov3d_vis = cov3d[vis_idx]
    uv_vis = uv[vis_idx]
    depths_vis = depths[vis_idx]
    visible_vis = visible[vis_idx]
    
    # Step 7-9: Project Covariance and Rasterize
    # [G] ewa_project returns conic, radius, etc. for each visible point
    # Assuming it handles the batch of visible points
    conic, radius = ewa_project(xyz_vis, cov3d_vis, intr, extr, uv_vis, W, H, visible_vis)
    
    # Calculate pixel coordinates
    px = torch.round(uv_vis[:, 0]).long()
    py = H - 1 - torch.round(uv_vis[:, 1]).long() # Flip Y
    
    # Clamp radius
    r_int = radius.long().clamp(0, 32)
    
    # Sort by depth
    d_flat = depths_vis.squeeze(-1)
    d_sorted, sort_idx = torch.sort(d_flat)
    
    # Rasterize
    for i in sort_idx:
        r = r_int[i].item()
        if r == 0:
            r = 1 # Minimum 1 pixel
        
        # Iterate over bounding box
        for dy in range(-r, r + 1):
            for dx in range(-r, r + 1):
                y = py[i] + dy
                x = px[i] + dx
                
                if 0 <= y < H and 0 <= x < W:
                    d_k = d_sorted[i].item()
                    if d_k < depth_canvas[y, x].item():
                        depth_canvas[y, x] = d_k
                        color_img[y, x] = (rgb_vis[i] * 255).byte()
                        label_img[y, x] = label_vis[i].byte()
                        index_map[y, x] = vis_idx[i].item()
                        
    return color_img.cpu().numpy(), label_img.cpu().numpy(), index_map.cpu().numpy()
```

## Operating characteristics
- **Time Complexity:** Dominated by KDTree construction $O(N \log N)$, $k$-NN query $O(N \log N)$, and rasterization $O(N \cdot R^2)$ where $R$ is the splat radius.
- **Memory Complexity:** $O(N \cdot k)$ for neighbour storage and covariance matrices.
- **Performance:** Produces denser images than simple disk splatting due to elliptical footprints adapting to local geometry [S1, unofficial]. Larger `splat_radius` softens details but increases coverage [S1, unofficial].
- **Strengths:** No mesh reconstruction required; works directly on raw point clouds [S1, unofficial]. Handles anisotropic structures better than isotropic splats.
- **Limitations:** Computationally heavier than simple splatting due to covariance estimation. Sensitive to $k$ and point cloud density.

## Background
Originated in the context of point-cloud rendering pipelines, specifically as part of the CamPoint renderer with EWA projection and Z-buffer occlusion operators [S1, unofficial]. It allows for dense coverage without mesh reconstruction, working directly on raw point clouds [S1, unofficial].
