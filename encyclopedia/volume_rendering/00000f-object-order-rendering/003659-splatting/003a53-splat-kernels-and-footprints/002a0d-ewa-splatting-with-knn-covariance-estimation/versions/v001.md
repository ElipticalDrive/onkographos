# EWA Splatting with kNN Covariance Estimation

Also called: Elliptical Weighted Average splatting

## Overview
EWA Splatting with kNN Covariance Estimation is a point-cloud rendering method that projects elliptical weighted average (EWA) shapes onto the 2D image plane using per-point 3D covariance matrices estimated from k-nearest neighbours [S1, unofficial]. Unlike simple disk splatting, this approach provides denser coverage and better handles anisotropic point distributions by adapting the splat shape to local geometry [S1, unofficial]. It builds on [Splatting](23-splatting.md) by replacing isotropic footprints with covariance-driven elliptical ones and operates directly on raw point clouds without requiring mesh reconstruction [S1, unofficial].

## How it works
**Inputs:**
- Point cloud: positions `xyz` ($[N, 3]$), colors `rgb` ($[N, 3]$), labels `label` ($[N]$).
- Camera parameters: intrinsics `intr` ($[M, 4]$ containing $f_x, f_y, c_x, c_y$), extrinsics `extr` ($[M, 4, 4]$ world-to-camera matrices).
- Viewport dimensions: width $W$, height $H$.
- Parameters: $k$ (number of neighbours, default 16), `splat_radius` (pixel radius, default 1), `extent` (frustum culling margin, default 1.3).

**Outputs:**
- `color_img_np`: $[H, W, 3]$ uint8 RGB image.
- `label_img_np`: $[H, W]$ uint8 label map.
- `index_map_np`: $[H, W]$ int32 map storing the index of the splatting point (or -1 if empty).

**Data Structures:**
- KDTree: Built on `xyz` for $O(\log N)$ nearest neighbour queries.
- Covariance Matrix: $3 \times 3$ symmetric matrix $\Sigma$ for each point, computed from neighbour positions.
- Conic Matrix: $2 \times 2$ matrix representing the projected 2D footprint.
- Depth Canvas: $[H, W]$ float32 buffer tracking the minimum depth for Z-buffer occlusion.

**Steps:**
1. **Build KDTree:** Convert `xyz` to numpy and construct a KDTree: `kdt = KDTree(xyz_np)`.
2. **Query Neighbours:** For each point, query $k$-nearest neighbours to get indices `knn_idx` ($[N, k]$).
3. **Gather Coordinates:** Gather neighbour positions `xyz_padded` ($[N, k, 3]$) using `knn_idx`.
4. **Compute 3D Covariance:** Calculate $\Sigma_{3D}$ for each point from `xyz_padded`. Let $\mu$ be the mean of the $k$ neighbours. The covariance is:
   $$ \Sigma_{3D} = \frac{1}{k-1} \sum_{i=1}^{k} (\mathbf{p}_i - \mu)(\mathbf{p}_i - \mu)^T $$
   where $\mathbf{p}_i$ is the position of the $i$-th neighbour [S1, unofficial].
5. **Project to 2D:** For each camera view, project the 3D covariance to 2D using EWA projection. This involves transforming the covariance by the camera's Jacobian $J$ and projection matrix $P$. The 2D conic matrix $C$ is derived from the projected covariance. Also compute the pixel coordinates $(u, v)$ and radius $r$ for each point [S1, unofficial].
6. **Filter Visible Points:** Identify points where the visibility mask `visible` is true and depth `depths` > 0.
7. **Calculate Pixel Coordinates:** Compute integer pixel coordinates $(px, py)$. Flip the Y-axis: $py = H - 1 - \text{round}(uv[:, 1])$. Clamp the integer radius $r_{int}$ to $[0, 32]$.
8. **Sort by Depth:** Sort visible points by depth in ascending order (front-to-back).
9. **Splat and Composit:** Iterate through sorted points. For each point, iterate $dy \in [-r_{int}, r_{int}]$ and $dx \in [-r_{int}, r_{int}]$. If the pixel $(px+dx, py+dy)$ is within bounds and the current point's depth is less than the existing `depth_canvas` at that pixel, write the color, label, and index to the output canvases and update `depth_canvas` [S1, unofficial].

**Pseudocode:**
```python
import numpy as np
import torch
from sklearn.neighbors import KDTree

def compute_cov3d(xyz_padded):
    """Compute 3D covariance matrix for each point from its k-nearest neighbours.
    xyz_padded: [N, k, 3]
    Returns: [N, 3, 3]
    """
    # Mean of neighbours for each point
    mu = torch.mean(xyz_padded, dim=1)  # [N, 3]
    # Centered coordinates
    centered = xyz_padded - mu.unsqueeze(1)  # [N, k, 3]
    # Covariance: (1/(k-1)) * sum( (p_i - mu) * (p_i - mu)^T )
    # Using matrix multiplication: centered^T @ centered gives [N, 3, 3] sum over k
    cov = torch.bmm(centered.transpose(1, 2), centered) / (xyz_padded.shape[1] - 1)
    return cov

def ewa_splatting(xyz, rgb, label, intr, extr, W, H, k=16, splat_radius=1, extent=1.3):
    """
    xyz: [N, 3] float32
    rgb: [N, 3] float32 (0-1)
    label: [N] int64
    intr: [M, 4] float32 (fx, fy, cx, cy)
    extr: [M, 4, 4] float32
    Returns: color_img [H,W,3] uint8, label_img [H,W] uint8, index_map [H,W] int32
    """
    N = xyz.shape[0]
    M = intr.shape[0]
    
    # Step 1-4: Compute 3D Covariance
    xyz_np = xyz.cpu().numpy()
    kdt = KDTree(xyz_np)
    _, knn_idx = kdt.query(xyz_np, k=k)
    xyz_padded = xyz[knn_idx] # [N, k, 3]
    cov3d = compute_cov3d(xyz_padded) # [N, 3, 3]
    
    # Step 5: Project to 2D (Simplified placeholder for actual EWA projection)
    # In practice, this involves projecting points and transforming covariance
    # using camera intrinsics/extrinsics to get 2D conic matrices and radii.
    # uv: [N, 2, M], depths: [N, 1, M], visible: [N, 1, M]
    # For brevity, assume project_points and shelter_points are available
    # uv, depths, visible = project_and_shelter(xyz, intr, extr, W, H, extent)
    
    # Initialize output canvases
    color_img = np.zeros((H, W, 3), dtype=np.uint8)
    label_img = np.zeros((H, W), dtype=np.uint8)
    index_map = np.full((H, W), -1, dtype=np.int32)
    depth_canvas = np.full((H, W), np.inf, dtype=np.float32)
    
    # Process each camera view
    for m in range(M):
        # Get points visible for camera m
        # Note: Actual implementation batches cameras, but here we iterate for clarity
        uv_m = uv[:, :, m] # [N, 2]
        depths_m = depths[:, 0, m] # [N]
        visible_m = visible[:, 0, m] # [N]
        
        # Filter visible points
        vis_idx = torch.where(visible_m > 0)[0]
        if vis_idx.numel() == 0:
            continue
            
        uv_vis = uv_m[vis_idx]
        depths_vis = depths_m[vis_idx]
        rgb_vis = rgb[vis_idx]
        label_vis = label[vis_idx]
        
        # Calculate pixel coordinates
        px = torch.round(uv_vis[:, 0]).long() # [V]
        py = H - 1 - torch.round(uv_vis[:, 1]).long() # Flip Y
        
        # Clamp coordinates to image bounds
        valid_mask = (px >= 0) & (px < W) & (py >= 0) & (py < H)
        px = px[valid_mask]
        py = py[valid_mask]
        depths_vis = depths_vis[valid_mask]
        rgb_vis = rgb_vis[valid_mask]
        label_vis = label_vis[valid_mask]
        vis_idx = vis_idx[valid_mask]
        
        if px.numel() == 0:
            continue
            
        # Sort by depth (front-to-back)
        sort_idx = torch.argsort(depths_vis)
        px = px[sort_idx]
        py = py[sort_idx]
        depths_vis = depths_vis[sort_idx]
        rgb_vis = rgb_vis[sort_idx]
        label_vis = label_vis[sort_idx]
        vis_idx = vis_idx[sort_idx]
        
        # Splat points
        for i in range(px.numel()):
            cx, cy = px[i].item(), py[i].item()
            d = depths_vis[i].item()
            
            # Determine radius (simplified: use splat_radius or computed radius)
            r = splat_radius
            
            # Iterate over splat footprint
            for dy in range(-r, r + 1):
                for dx in range(-r, r + 1):
                    x, y = cx + dx, cy + dy
                    if 0 <= x < W and 0 <= y < H:
                        if d < depth_canvas[y, x]:
                            depth_canvas[y, x] = d
                            color_img[y, x] = (rgb_vis[i] * 255).astype(np.uint8)
                            label_img[y, x] = label_vis[i].item()
                            index_map[y, x] = vis_idx[i].item()
                            
    return color_img, label_img, index_map
```

**Parameters:**
- $k$: Number of neighbours for covariance estimation. Default: 16 [S1, unofficial].
- `splat_radius`: Pixel radius for point splatting. Default: 1 [S1, unofficial].
- `extent`: Frustum culling margin. Default: 1.3 [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Y-axis Orientation:** World camera Y points up, but image v points down. The Y coordinate must be flipped: $py = H - 1 - \text{round}(uv[:, 1])$ [S1, unofficial].
- **Empty Visible Set:** If no points are visible for a camera, return zero-filled canvases with `index_map` filled with -1 [S1, unofficial].
- **Radius Clamping:** The integer radius $r_{int}$ should be clamped between 0 and 32 to prevent excessive memory access [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Building the KDTree is $O(N \log N)$. Querying neighbours is $O(N k \log N)$. Projection and splatting is $O(N \cdot r^2)$ per camera, where $r$ is the splat radius.
- **Memory Complexity:** $O(N k)$ for storing neighbour indices and covariance matrices. Output images are $O(H \cdot W)$.
- **Performance:** Performance depends on the number of points $N$, camera views $M$, and splat radius $r$. Larger $r$ increases coverage but softens details [S1, unofficial].
- **Strengths:** Provides denser coverage than disk splatting, handles anisotropic distributions well, no mesh reconstruction required [S1, unofficial].
- **Limitations:** Computationally more expensive than simple splatting due to covariance estimation. Sensitive to the choice of $k$ and splat radius.

## Background
This method is part of the CamPoint point-cloud rendering pipeline, which uses EWA projection and Z-buffer occlusion operators [S1, unofficial]. It is designed to work directly on raw point clouds, avoiding the need for mesh reconstruction. The approach is inspired by Elliptical Weighted Average (EWA) splatting techniques used in volume rendering and point-based graphics.
