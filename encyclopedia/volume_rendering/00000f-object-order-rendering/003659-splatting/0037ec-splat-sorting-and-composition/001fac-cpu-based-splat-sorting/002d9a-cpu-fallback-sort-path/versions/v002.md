# CPU Fallback Sort Path

Also called: CPU-only cutout path, Portable CPU-sort path

## Overview
The CPU Fallback Sort Path provides a CPU-side sorting and rendering fallback for Gaussian splatting when GPU compute sorting is disabled or unavailable [S1, unofficial]. It differs from GPU-based approaches by utilizing a shader-readable structured buffer instead of append or unordered access view (UAV) buffers [S1, unofficial].

## How it works
**Inputs:**
- `GsplatSorter.Instance.CpuFallbackEnabled`: A boolean flag determining the active path [S1, unofficial].

**Outputs:**
- `OrderBuffer`: A buffer containing the sorted order of splats, readable by shaders [S1, unofficial].
- `OrderSizeBuffer`: (Optional) An indirect argument buffer storing the number of sorted splats [S1, unofficial].
- `BoundsBuffer`: (Optional) A structured buffer storing bounding box information [S1, unofficial].

**Data Structures:**
1.  **`OrderBuffer`**:
    -   Type: `GraphicsBuffer.Target.Structured` (if CPU fallback enabled) or `GraphicsBuffer.Target.Append` (if disabled) [S1, unofficial].
    -   Content: Indices or identifiers of splats in sorted order.
2.  **`OrderSizeBuffer`**:
    -   Type: `GraphicsBuffer.Target.IndirectArguments` [S1, unofficial].
    -   Size: 1 element [S1, unofficial].
    -   Content: The count of splats to be rendered/sorted [S1, unofficial].
3.  **`BoundsBuffer`**:
    -   Type: `GraphicsBuffer.Target.Structured` [S1, unofficial].
    -   Size: 6 elements [S1, unofficial].
    -   Content: Bounding box data for the splats [S1, unofficial].

**Steps:**
1.  Check `GsplatSorter.Instance.CpuFallbackEnabled` [S1, unofficial].
2.  If true, create `OrderBuffer` as `GraphicsBuffer.Target.Structured` [S1, unofficial].
3.  If false, create `OrderBuffer` as `GraphicsBuffer.Target.Append` [S1, unofficial].
4.  If CPU fallback is disabled, additionally allocate `OrderSizeBuffer` (IndirectArguments, size 1) and `BoundsBuffer` (Structured, size 6) [S1, unofficial].

**Pseudocode:**
```python
class TargetType:
    Structured = "Structured"
    Append = "Append"
    IndirectArguments = "IndirectArguments"

def allocate_buffer(target_type, size=1):
    # Allocates a buffer object with the specified target type and element count
    return {"target": target_type, "size": size}

def setup_sort_buffers(cpu_fallback_enabled):
    # Step 1: Check flag
    is_fallback = cpu_fallback_enabled

    # Step 2 & 3: Create OrderBuffer based on flag
    if is_fallback:
        # CPU fallback enabled: use Structured buffer for shader readability
        order_buffer = allocate_buffer(TargetType.Structured)
        order_size_buffer = None
        bounds_buffer = None
    else:
        # CPU fallback disabled: use Append buffer
        order_buffer = allocate_buffer(TargetType.Append)
        
        # Step 4: Allocate additional buffers for non-fallback path
        order_size_buffer = allocate_buffer(TargetType.IndirectArguments, size=1)
        bounds_buffer = allocate_buffer(TargetType.Structured, size=6)

    # Sorting logic details are not given in the sources.
    return order_buffer, order_size_buffer, bounds_buffer
```

**Parameters:**
-   `CpuFallbackEnabled`: Boolean flag that determines whether the CPU fallback path is active, controlling the `GraphicsBuffer.Target` type for `OrderBuffer` [S1, unofficial].

## Subtopics

### [CPU Radix Sort for Face Centroids](6216-cpu-radix-sort-for-face-centroids.md)
This method provides a CPU-side fallback for sorting face centroids in volume splatting when GPU compute sorting is unavailable, building on [CPU Fallback Sort Path](5586-cpu-fallback-sort-path.md). It achieves linear time complexity by converting IEEE 754 floating-point numbers to signed integers and performing a Least Significant Digit (LSD) radix sort using counting sort on 8-bit blocks. It is chosen over general-purpose sorts (quicksort, heapsort) or re-sorting-optimized algorithms (mergesort) because viewing direction changes significantly alter centroid ordering, making the overhead of adaptive sorts inefficient compared to the raw speed of radix sort.
