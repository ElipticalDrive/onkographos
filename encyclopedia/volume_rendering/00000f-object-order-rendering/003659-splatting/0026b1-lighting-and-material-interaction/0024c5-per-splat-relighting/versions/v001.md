# Per-Splat Relighting


## Overview
Per-Splat Relighting computes a dynamic lighting multiplier for individual Gaussian splats based on scene lights, surface normals, ambient occlusion, and confidence values. It differs from pre-baked lighting by allowing real-time changes to light positions or intensities without retraining or resplatting the geometry, and differs from Photon Splatting by computing direct illumination analytically per-splat rather than storing photon densities.

## How it works
**Inputs:**
- `splat_lighting`: A texture or buffer containing packed lighting records for each splat.
- `splat_index`: The index of the current splat being processed.
- `light_rig`: A flat array or buffer of light parameters, organized in chunks of 4 floats per light.
- `world_position`: The 3D world position of the splat center.
- `ambient`: A scalar ambient light intensity.
- `gain`: A scalar multiplier for the computed irradiance.
- `unlit_level`: The base color or intensity of the splat without lighting.

**Outputs:**
- `relight_factor`: A scalar or vector representing the final lighting contribution.

**Data Structures:**
- `splat_lighting`: Packed as RGBA.
    - `r`, `g`: Octahedral normal encoding.
    - `b`: Ambient occlusion value.
    - `a`: Confidence value.
- `light_rig`: Flat array. For light $i$, parameters are stored at indices $4i$ to $4i+3$:
    - `light_rig[4i+0]`: Light direction (for directional) or position (for point/spot).
    - `light_rig[4i+1]`: Tint (RGB) and Type (A).
    - `light_rig[4i+2]`: Setup parameters (Range/Decay R/G, Spot Cone B, Spot Exponent A).
    - `light_rig[4i+3]`: Spot direction (for spot lights).

**Steps:**
1. **Unpack Lighting Record:** Extract normal, AO, and confidence from `splat_lighting[splat_index]`.
2. **Normalize Normal:** Convert the octahedral normal to a 3D vector. If the length is zero, default to $(0,0,1)$.
3. **Initialize Direct Lighting:** Set `direct = 0`.
4. **Loop Over Lights:** For each light $i$:
    - Extract `tint`, `setup`, `type`, and `to_light` vector.
    - Calculate attenuation based on light type (omni or spot).
    - Add contribution to `direct` if visible.
5. **Compute Irradiance:** Combine ambient and direct lighting with AO and confidence.
6. **Return Result:** Scale by gain and add unlit level.

**Formulas:**
- Octahedral Normal Unpacking (implied by "record.rg is octahedral normal"):
  Let $n_{xy} = (r, g)$.
  $$ n_x = 1 - |r| - |g| $$
  $$ n_y = r $$
  $$ n_z = g $$
  If $n_x < 0$:
  $$ r = \text{sign}(r) \cdot (1 - |n_z|) $$
  $$ g = \text{sign}(g) \cdot (1 - |n_y|) $$
  [G] Standard octahedral projection.

- Normal Normalization:
  $$ \text{normal\_length} = \|\text{world\_normal}\| $$
  $$ \text{world\_normal} = \begin{cases} \frac{\text{world\_normal}}{\text{normal\_length}} & \text{if } \text{normal\_length} > 0 \\ (0,0,1) & \text{otherwise} \end{cases} $$

- Omni Attenuation:
  $$ \text{omni\_attenuation}(d, \text{inv\_range}, \text{decay}) = \max(1.0 - (d \cdot \text{inv\_range})^4, 0)^2 \cdot d^{-\text{decay}} $$

- Spot Light Attenuation:
  $$ \text{cone\_cosine} = \max(\mathbf{-to\_light} \cdot \text{spot\_dir}, \text{setup.b}) $$
  $$ \text{rim} = \frac{1.0 - \text{cone\_cosine}}{\max(10^{-4}, 1.0 - \text{setup.b})} $$
  $$ \text{attenuation} \cdot= 1.0 - \text{clamp}(\text{rim}, 0, 1)^{\text{setup.a}} $$

- Final Irradiance:
  $$ \text{irradiance} = \text{ambient} \cdot \text{ao} + \text{direct} \cdot \text{confidence} $$
  $$ \text{result} = \text{unlit\_level} + \text{gain} \cdot \text{irradiance} $$

**Pseudocode:**
```python
def per_splat_relighting(splat_lighting, splat_index, light_rig, world_position, ambient, gain, unlit_level):
    # 1. Unpack lighting record
    record = splat_lighting[splat_index]
    # record.rg is octahedral normal, record.b is AO, record.a is confidence
    oct_normal = vec2(record.r, record.g)
    ao = record.b
    confidence = record.a

    # 2. Normalize normal
    # Unpack octahedral normal
    nx = 1.0 - abs(oct_normal.x) - abs(oct_normal.y)
    ny = oct_normal.x
    nz = oct_normal.y
    if nx < 0.0:
        ny = sign(oct_normal.x) * (1.0 - abs(nz))
        nz = sign(oct_normal.y) * (1.0 - abs(ny))
    
    world_normal = vec3(ny, nz, nx) # Note: Source implies standard unpacking, order may vary by implementation
    normal_length = length(world_normal)
    if normal_length > 0.0:
        world_normal = world_normal / normal_length
    else:
        world_normal = vec3(0.0, 0.0, 1.0)

    # 3. Loop over lights
    direct = vec3(0.0)
    num_lights = len(light_rig) // 4
    
    for i in range(num_lights):
        base_idx = i * 4
        tint = vec4(light_rig[base_idx+1]) # Assuming light_rig[4i+1] holds tint RGB and Type A
        setup = vec4(light_rig[base_idx+2]) # Setup params
        type_int = int(tint.a + 0.5)
        
        # Light direction/position
        light_vec = vec3(light_rig[base_idx+0])
        
        attenuation = 1.0
        
        if type_int != 0: # Not directional
            relative = light_vec - world_position
            dist = length(relative)
            if dist < 1e-6:
                continue
            to_light = relative / dist
            attenuation = omni_attenuation(dist, setup.r, setup.g)
            
            if type_int == 2: # Spot light
                spot_dir = vec3(light_rig[base_idx+3])
                cone_cosine = max(dot(-to_light, spot_dir), setup.b)
                rim = (1.0 - cone_cosine) / max(1e-4, 1.0 - setup.b)
                attenuation *= 1.0 - pow(clamp(rim, 0.0, 1.0), setup.a)
        
        # Direct lighting contribution
        # Source: direct += tint.rgb * attenuation * max(dot(world_normal, to_light), 0)
        # Note: For directional lights, to_light is the light direction vector itself
        if type_int == 0:
            # Directional light: to_light is already the direction
            pass
        else:
            # Point/Spot: to_light is normalized vector from splat to light
            pass
            
        direct += tint.rgb * attenuation * max(dot(world_normal, to_light), 0.0)

    # 4. Compute irradiance
    irradiance = ambient * ao + direct * confidence
    return unlit_level + gain * irradiance

def omni_attenuation(dist, inv_range, decay):
    return max(1.0 - pow(dist * inv_range, 4.0), 0.0)**2 * pow(dist, -decay)
```

## Operating characteristics
- **Time Complexity:** $O(L)$ per splat, where $L$ is the number of lights.
- **Memory Complexity:** $O(1)$ additional memory per splat for lighting calculation.
- **Strengths:** Real-time dynamic lighting; no need to store high-frequency lighting details in splat attributes.
- **Limitations:** Performance scales linearly with light count; shadows are not supported (diffuse approximation only); relies on accurate normal estimation from splat attributes.

## Background
Per-Splat Relighting is a technique used in real-time Gaussian Splatting renderers to apply dynamic lighting to pre-trained splats. It was popularized by implementations such as ReconWorldLab's Godot Gaussian Splatting plugin [S1, unofficial].
