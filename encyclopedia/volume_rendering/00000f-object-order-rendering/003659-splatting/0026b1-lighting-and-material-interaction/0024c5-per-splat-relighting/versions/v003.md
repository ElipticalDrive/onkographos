# Per-Splat Relighting


## Overview
Per-Splat Relighting computes a lighting multiplier for individual Gaussian splats based on light sources, surface normals, ambient occlusion, and confidence values [S1, unofficial]. It differs from standard splatting by injecting per-primitive shading calculations into the rendering pipeline, allowing for dynamic lighting interactions on 3D Gaussian Splatting (3DGS) representations [S1, unofficial].

## How it works
**Inputs:**
- `splat_lighting`: A buffer containing packed lighting records for each splat.
- `light_rig`: An array of light definitions, where each light occupies 4 `vec4` slots (16 floats).
- `world_position`: The 3D position of the splat in world space.
- `ambient`: A `vec3` representing ambient light color/intensity.
- `unlit_level`: A `vec3` base color.
- `gain`: A scalar multiplier for the lighting contribution.
- `omni_attenuation`: Parameters for distance decay.

**Outputs:**
- `relight_factor`: A `vec3` representing the final lighting multiplier to be applied to the splat's color.

**Data Structures:**
The lighting record is unpacked from `splat_lighting[splat_index]`. The record is packed as follows:
- `rg`: Octahedral normal representation.
- `b`: Ambient occlusion value.
- `a`: Confidence value.

**Steps:**
1. **Unpack Lighting Record:** Extract the normal, ambient occlusion (AO), and confidence from the packed splat lighting data.
2. **Normalize Normal:** Convert the octahedral normal to a 3D vector. If the length is zero, default to `(0, 0, 1)`.
3. **Loop Over Lights:** For each light in the `light_rig`:
    - Extract light direction, color, and setup parameters.
    - Determine light type from the alpha channel of the tint.
    - Calculate attenuation based on distance and light type (omnidirectional or spot).
    - Compute direct lighting contribution using the dot product of the normal and light direction.
4. **Compute Irradiance:** Combine ambient and direct lighting, modulated by AO and confidence.
5. **Return Result:** Calculate the final color using the unlit level, gain, and computed irradiance.

**Formulas:**
- **Omni Attenuation:**
  $$ \text{omni\_attenuation}(dist, inv\_range, decay) = \max(1.0 - (dist \cdot inv\_range)^4, 0)^2 \cdot dist^{-decay} $$
  Where $dist$ is the distance to the light, $inv\_range$ is the inverse range, and $decay$ is the decay exponent [S1, unofficial].

- **Spot Light Attenuation:**
  $$ \text{rim} = \frac{1.0 - \text{cone\_cosine}}{\max(1e-4, 1.0 - \text{setup}.b)} $$
  $$ \text{attenuation} *= 1.0 - \text{pow}(\text{clamp}(\text{rim}, 0, 1), \text{setup}.a) $$
  Where $\text{cone\_cosine} = \max(\text{dot}(-\text{to\_light}, \text{light\_rig}[i*4+3].\text{xyz}), \text{setup}.b)$ [S1, unofficial].

- **Final Irradiance:**
  $$ \text{irradiance} = \text{ambient} \cdot \text{ao} + \text{direct} \cdot \text{confidence} $$
  $$ \text{result} = \text{unlit\_level} + \text{gain} \cdot \text{irradiance} $$

**Pseudocode:**
```python
def per_splat_relighting(splat_lighting, splat_index, light_rig, world_position, ambient, unlit_level, gain):
    # 1. Unpack lighting record
    record = unpack_lighting(splat_lighting[splat_index])
    # record.rg is octahedral normal, record.b is AO, record.a is confidence
    oct_normal = vec2(record.rg)
    ao = record.b
    confidence = record.a

    # 2. Normalize normal
    world_normal = octahedral_to_world_normal(oct_normal)
    normal_length = length(world_normal)
    if normal_length > 0:
        world_normal = world_normal / normal_length
    else:
        world_normal = vec3(0, 0, 1)

    # 3. Loop over lights
    direct = vec3(0, 0, 0)
    num_lights = len(light_rig) // 4
    
    for i in range(num_lights):
        tint = light_rig[i * 4 + 1]
        setup = light_rig[i * 4 + 2]
        type = int(tint.a + 0.5)
        to_light = light_rig[i * 4 + 0].xyz
        attenuation = 1.0

        if type != 0:
            relative = light_rig[i * 4 + 0].xyz - world_position
            dist = length(relative)
            if dist < 1e-6:
                continue
            to_light = relative / dist
            attenuation = omni_attenuation(dist, setup.r, setup.g)

        if type == 2:  # Spot light
            cone_cosine = max(dot(-to_light, light_rig[i * 4 + 3].xyz), setup.b)
            rim = (1.0 - cone_cosine) / max(1e-4, 1.0 - setup.b)
            attenuation *= 1.0 - pow(clamp(rim, 0, 1), setup.a)

        direct += tint.rgb * attenuation * max(dot(world_normal, to_light), 0)

    # 4. Compute irradiance
    irradiance = ambient * ao + direct * confidence
    
    # 5. Return result
    return unlit_level + gain * irradiance
```

## Background
Per-Splat Relighting is part of the 3D Gaussian Splatting ecosystem, specifically implemented in the Godot Gaussian Splatting project by ReconWorldLab [S1, unofficial]. It enables dynamic lighting on 3DGS scenes by treating each Gaussian splat as a primitive that can interact with light sources.
