# Gaussian Splat Projection and Sorting


## Overview
This method is a compute-shader stage that projects 3D Gaussians to 2D screen space, performs visibility and frustum culling, computes lighting, and prepares data for tile-based sorting [S1, unofficial]. It bridges raw 3D Gaussian data and the tiled rasterization pipeline by ensuring only visible splats are processed and ordered by tile and depth [S1, unofficial]. It differs from non-tiled approaches by explicitly preparing tile-boundary data and from tile-based culling by handling full projection and sorting key generation [S1, unofficial].

## How it works
**Inputs:**
- `SplatsBuffer`: `std430` buffer of `Splat` structs [S1, unofficial].
- `InstanceTransformsBuffer`: `std430` buffer of `mat4` instance model matrices [S1, unofficial].
- `SplatInstanceIdsBuffer`: `std430` buffer of `uvec2` where `x` is the unique instance ID and `y` is the index into `SplatsBuffer` [S1, unofficial].
- `Uniforms`: `std140` uniform block containing `camera_pos`, `time`, `dims` (image resolution), `point_count`, and `light_count` [S1, unofficial].
- `LightRigBuffer`: `std430` buffer of `vec4` light data [S1, unofficial].
- `SplatLightingBuffer`: `std430` buffer of `uint` packed lighting data [S1, unofficial].
- `InstanceRelightBuffer`: `std430` buffer of `vec4` per-instance relighting data [S1, unofficial].
- `GridDimensionsBuffer`: `std430` buffer storing grid dimensions [S1, unofficial].
- `projection_matrix`, `view_matrix`: Standard camera matrices [G].

**Outputs:**
- `CulledBuffer`: `std430` buffer of `RasterizeData` structs for visible splats [S1, unofficial].
- `SortKeysBuffer`: `std430` buffer of `uint` keys for sorting [S1, unofficial].
- `SortValuesBuffer`: `std430` buffer of `uint` values (splat indices) for sorting [S1, unofficial].
- `Histograms`: `std430` buffer containing `sort_buffer_size` and histogram data [S1, unofficial].

**Data Structures:**
```glsl
struct Splat {
    vec3 position;
    float time;
    float covariance[6]; // Contains top triangle of symmetric matrix
    float opacity;
    float _pad;
    float sh_coefficients[16*3]; // Spherical harmonic coefficients in increasing order
};

struct RasterizeData {
    vec2 image_pos;
    vec2 pos_xy;
    vec3 conic;
    float pos_z;
    vec4 color;
    vec4 depth_data;
};
```

**Constants:**
- `TILE_SIZE`: 16. Used to partition the screen into tiles for sorting [S1, unofficial].
- `SH_C0` to `SH_C3_6`: Spherical harmonic constants. `SH_C0=0.28209479177387814`, `SH_C1=0.4886025119029199`, `SH_C2_0=1.0925484305920792`, `SH_C2_1=1.0925484305920792`, `SH_C2_2=0.31539156525252005`, `SH_C2_3=1.0925484305920792`, `SH_C2_4=0.5462742152960396`, `SH_C3_0=0.5900435899266435`, `SH_C3_1=2.890611442640554`, `SH_C3_2=0.4570457994644658`, `SH_C3_3=0.3731763325901154`, `SH_C3_4=0.4570457994644658`, `SH_C3_5=1.445305721320277`, `SH_C3_6=0.5900435899266435` [S1, unofficial].
- `DECODE_COVARIANCE(c)`: Macro to construct `mat3` from `covariance[6]` as `mat3(c[0], c[1], c[2], c[1], c[3], c[4], c[2], c[4], c[5])` [S1, unofficial].

**Algorithm:**
1. **Initialization:** Get global invocation ID `id`. If `id >= point_count`, return [S1, unofficial].
2. **Barrier:** Synchronize workgroup [S1, unofficial].
3. **Retrieve Instance Data:** `instance_id = splat_instance_data[id].x`, `unique_splat_index = splat_instance_data[id].y` [S1, unofficial].
4. **Load Data:** Load `splat` from `splat_buffer[unique_splat_index]` and `model_matrix` from `instance_model_matrices[instance_id]` [S1, unofficial].
5. **Visibility Check:** If `model_matrix[0][3] < 0.5`, return. Set `model_matrix[0][3] = 0.0` [S1, unofficial].
6. **Frustum Culling:** Compute `object_linear` from `model_matrix`. Compute `world_covariance = object_linear * DECODE_COVARIANCE(splat.covariance) * transpose(object_linear)`. Compute `world_pos = model_matrix * vec4(splat.position, 1.0)`. Compute `view_pos = view_matrix * world_pos`. Compute `clip_pos = projection_matrix * view_pos`. Check bounds: If any component of `clip_pos.xyz` is less than `vec3(-view_bounds, 0.0)` or greater than `vec3(view_bounds, clip_pos.w)`, return. `view_bounds = clip_pos.w * 1.2` [S1, unofficial].
7. **Time Animation:** `splat_time = time - splat.time`. `time_factor = ease_out_cubic(clamp(splat_time, 0, 1))`. `time_factor_late = ease_out_cubic(clamp(splat_time - 0.35, 0, 1))`. `splat_opacity = splat.opacity * time_factor_late * time_factor_late`. `splat_scale = mix(2.0, 1.0, time_factor_late)`. `ease_out_cubic(x) = 1.0 - (1.0-x)^3` [S1, unofficial].
8. **Project Covariance:** Call `project_covariance(world_covariance, splat_scale, view_pos.xyz, dims)`. Inside `project_covariance`: `cov_3d = covariance_3d * scale_modifier^2`. `tan_fov_inv = vec2(projection_matrix[0][0], projection_matrix[1][1])`. `focal = (dims-1)*0.5*tan_fov_inv * (-1.0/mean.z)`. `mean.xy = clamp(mean.xy * (-1.0/mean.z), -tan_fov*1.3, tan_fov*1.3)`. `jacobian = mat3(focal.x, 0, 0, 0, focal.y, 0, focal.x*mean.x, focal.y*mean.y, 0)`. `screen_transform = jacobian * view_linear`. `cov_2d = screen_transform * cov_3d * transpose(screen_transform)`. Return `vec3(cov_2d[0][0]+0.3, cov_2d[0][1], cov_2d[1][1]+0.3)` [S1, unofficial].
9. **Check Determinant:** `det = covariance.x*covariance.z - covariance.y*covariance.y`. If `det == 0.0`, return [S1, unofficial].
10. **Compute Eigenvalues:** `mid = 0.5*(covariance.x + covariance.z)`. `eigenvalues = mid + vec2(1, -1)*sqrt(max(0.1, mid*mid - det))`. If any `eigenvalues < 0`, return [S1, unofficial].
11. **Compute Image Position:** `ndc_pos = clip_pos.xyz / clip_pos.w`. `image_pos = ((ndc_pos.xy + 1.0)*0.5 - vec2(1, 0.75)*(1.0 - time_factor)) * (dims - 1)` [S1, unofficial].
12. **Compute Radius:** `radius = pow(splat_opacity, 0.2) * 2.5 * sqrt(max(eigenvalues.x, eigenvalues.y))` [S1, unofficial].
13. **Compute Tile Bounds:** `grid_size = (dims + TILE_SIZE - 1) / TILE_SIZE`. `rect_bounds = get_rect(image_pos, radius, grid_size)`. `get_rect` returns `uvec4(clamp((image_pos-radius)/TILE_SIZE, vec2(0), grid_size), clamp(ceil((image_pos+radius)/TILE_SIZE), vec2(0), grid_size))` [S1, unofficial].
14. **Check Tile Count:** `num_tiles_touched = (rect_bounds.z - rect_bounds.x)*(rect_bounds.w - rect_bounds.y)`. If `num_tiles_touched == 0`, return [S1, unofficial].
15. **Atomic Add:** `buffer_size = atomicAdd(sort_buffer_size, num_tiles_touched)`. `sort_buffer_offset = buffer_size` [S1, unofficial].
16. **Compute View Direction:** `view_dir = normalize(inverse(object_linear) * (world_pos.xyz - camera_pos))` [S1, unofficial].
17. **Compute Base Color:** `base_color = get_color(view_dir, splat.sh_coefficients)`. `get_color` evaluates SH up to degree 3 using constants `SH_C0`..`SH_C3_6` and coefficients from `splat.sh_coefficients` [S1, unofficial].
18. **Relighting:** `relight = instance_relight[instance_id * 2]`. If `relight.w > 0.5`: If `relight.z > 0.5`, `base_color = max(0.0, 0.5 + splat.sh_coefficients[0..2] * SH_C0)`. Else, `base_color *= relight_factor(unique_splat_index, world_pos.xyz, object_linear, relight.x, relight.y, instance_relight[instance_id*2+1].rgb)` [S1, unofficial].
19. **Fill RasterizeData:** `data.image_pos = image_pos`. `data.conic = vec3(covariance.z, -covariance.y, covariance.x) / det`. `data.color = vec4(base_color, splat_opacity)`. `data.pos_xy = world_pos.xy`. `data.pos_z = world_pos.z`. `data.depth_data = vec4(-view_pos.z, 0, 0, 0)`. Write to `culled_buffer[id]` [S1, unofficial].
20. **Gaussian Duplication/Sorting Preparation:** `view_depth = max(0.0, clip_pos.w)`. `depth01 = view_depth / (1.0 + view_depth)`. `depth = uint(depth01 * 65535.0) & 0xFFFF`. Loop `y` from `rect_bounds.y` to `rect_bounds.w`, `x` from `rect_bounds.x` to `rect_bounds.z`: `tile_id = y*grid_size.x + x`. `key = (tile_id << 16) | depth`. `sort_keys[sort_buffer_offset] = key`. `sort_values[sort_buffer_offset] = id`. `sort_buffer_offset++` [S1, unofficial].

**Pseudocode:**
```python
TILE_SIZE = 16
SH_C0 = 0.28209479177387814
# SH_C1..SH_C3_6 defined per [S1, unofficial]

def mat_mul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(A[0]))) for j in range(len(B[0]))] for i in range(len(A))]

def transpose(M):
    return [[M[j][i] for j in range(len(M))] for i in range(len(M[0]))]

def vec_mul(M, v):
    return [sum(M[i][j] * v[j] for j in range(len(v))) for i in range(len(M))]

def normalize(v):
    mag = (sum(x*x for x in v))**0.5
    return [x/mag for x in v]

def clamp(x, mn, mx):
    return max(mn, min(mx, x))

def ceil(x):
    return int(x) if x == int(x) else int(x) + 1

def mix(a, b, t):
    return a + (b - a) * t

def any(cond_list):
    return any(cond_list)

def decode_covariance(cov):
    return [[cov[0], cov[1], cov[2]],
            [cov[1], cov[3], cov[4]],
            [cov[2], cov[4], cov[5]]]

def project_covariance(covariance_3d, scale, mean, dims, projection_matrix, view_matrix):
    cov_3d = [[r * scale * scale for r in row] for row in covariance_3d]
    tan_fov_inv = [projection_matrix[0][0], projection_matrix[1][1]]
    tan_fov = [1.0 / tan_fov_inv[0], 1.0 / tan_fov_inv[1]]
    focal = [(dims[0] - 1) * 0.5 * tan_fov_inv[0] * (-1.0 / mean[2]),
             (dims[1] - 1) * 0.5 * tan_fov_inv[1] * (-1.0 / mean[2])]
    mean_xy = [clamp(mean[0] * (-1.0 / mean[2]), -tan_fov[0] * 1.3, tan_fov[0] * 1.3),
               clamp(mean[1] * (-1.0 / mean[2]), -tan_fov[1] * 1.3, tan_fov[1] * 1.3)]
    jacobian = [[focal[0], 0, 0],
                [0, focal[1], 0],
                [focal[0] * mean_xy[0], focal[1] * mean_xy[1], 0]]
    view_linear = [[view_matrix[i][j] for j in range(3)] for i in range(3)]
    screen_transform = mat_mul(jacobian, view_linear)
    cov_2d = mat_mul(mat_mul(screen_transform, cov_3d), transpose(screen_transform))
    return [cov_2d[0][0] + 0.3, cov_2d[0][1], cov_2d[1][1] + 0.3]

def ease_out_cubic(x):
    return 1.0 - pow(1.0 - x, 3.0)

def get_rect(image_pos, radius, grid_size):
    min_coords = [clamp((image_pos[0] - radius) / TILE_SIZE, 0, grid_size[0]),
                  clamp((image_pos[1] - radius) / TILE_SIZE, 0, grid_size[1])]
    max_coords = [clamp(ceil((image_pos[0] + radius) / TILE_SIZE), 0, grid_size[0]),
                  clamp(ceil((image_pos[1] + radius) / TILE_SIZE), 0, grid_size[1])]
    return [min_coords[0], min_coords[1], max_coords[0], max_coords[1]]

def get_color(view_dir, sh_coefficients):
    # Sources do not provide the full SH evaluation implementation.
    return [0.0, 0.0, 0.0]

def relight_factor(unique_splat_index, world_pos, object_linear, x, y, rgb):
    # Sources do not provide the full relighting implementation.
    return rgb

def atomic_add(counter, value):
    counter[0] += value
    return counter[0] - value

def gsplat_projection(id, point_count, splat_buffer, instance_model_matrices, splat_instance_data,
                      camera_pos, time, dims, projection_matrix, view_matrix, instance_relight,
                      sort_buffer_size, sort_keys, sort_values, culled_buffer, grid_dims):
    if id >= point_count:
        return

    instance_id = splat_instance_data[id][0]
    unique_splat_index = splat_instance_data[id][1]

    splat = splat_buffer[unique_splat_index]
    model_matrix = instance_model_matrices[instance_id]

    if model_matrix[0][3] < 0.5:
        return
    model_matrix[0][3] = 0.0

    object_linear = [[model_matrix[i][j] for j in range(3)] for i in range(3)]
    world_covariance = mat_mul(mat_mul(object_linear, decode_covariance(splat.covariance)), transpose(object_linear))
    world_pos = vec_mul(model_matrix, [splat.position[0], splat.position[1], splat.position[2], 1.0])
    view_pos = vec_mul(view_matrix, world_pos)
    clip_pos = vec_mul(projection_matrix, view_pos)

    view_bounds = clip_pos[3] * 1.2
    if any(clip_pos[i] < -view_bounds for i in range(3)) or any(clip_pos[i] > (view_bounds if i < 2 else clip_pos[3]) for i in range(3)):
        return

    splat_time = time - splat.time
    time_factor = ease_out_cubic(clamp(splat_time, 0, 1))
    time_factor_late = ease_out_cubic(clamp(splat_time - 0.35, 0, 1))
    splat_opacity = splat.opacity * time_factor_late * time_factor_late
    splat_scale = mix(2.0, 1.0, time_factor_late)

    cov_2d = project_covariance(world_covariance, splat_scale, view_pos[:3], dims, projection_matrix, view_matrix)
    covariance = [cov_2d[0], cov_2d[1], cov_2d[2]]

    det = covariance[0] * covariance[2] - covariance[1] * covariance[1]
    if det == 0.0:
        return

    mid = 0.5 * (covariance[0] + covariance[2])
    eigenvalues = [mid + (max(0.1, mid * mid - det))**0.5, mid - (max(0.1, mid * mid - det))**0.5]
    if any(e < 0 for e in eigenvalues):
        return

    ndc_pos = [clip_pos[0] / clip_pos[3], clip_pos[1] / clip_pos[3]]
    image_pos = [((ndc_pos[0] + 1.0) * 0.5 - 1.0 * (1.0 - time_factor)) * (dims[0] - 1),
                 ((ndc_pos[1] + 1.0) * 0.5 - 0.75 * (1.0 - time_factor)) * (dims[1] - 1)]

    radius = pow(splat_opacity, 0.2) * 2.5 * (max(eigenvalues[0], eigenvalues[1]))**0.5

    grid_size = [int((dims[0] + TILE_SIZE - 1) / TILE_SIZE), int((dims[1] + TILE_SIZE - 1) / TILE_SIZE)]
    rect_bounds = get_rect(image_pos, radius, grid_size)

    num_tiles_touched = (rect_bounds[2] - rect_bounds[0]) * (rect_bounds[3] - rect_bounds[1])
    if num_tiles_touched == 0:
        return

    buffer_size = atomic_add(sort_buffer_size, num_tiles_touched)
    sort_buffer_offset = buffer_size

    view_dir = normalize(vec_mul(transpose(mat_mul([[1,0,0],[0,1,0],[0,0,1]], object_linear)), [world_pos[0] - camera_pos[0], world_pos[1] - camera_pos[1], world_pos[2] - camera_pos[2]]))
    base_color = get_color(view_dir, splat.sh_coefficients)

    relight = instance_relight[instance_id * 2]
    if relight[3] > 0.5:
        if relight[2] > 0.5:
            base_color = [max(0.0, 0.5 + c * SH_C0) for c in splat.sh_coefficients[:3]]
        else:
            base_color = [base_color[i] * relight_factor(unique_splat_index, world_pos, object_linear, relight[0], relight[1], instance_relight[instance_id * 2 + 1][:3])[i] for i in range(3)]

    data_image_pos = image_pos
    data_conic = [covariance[2], -covariance[1], covariance[0]] / det
    data_color = base_color + [splat_opacity]
    data_pos_xy = [world_pos[0], world_pos[1]]
    data_pos_z = world_pos[2]
    data_depth_data = [-view_pos[2], 0.0, 0.0, 0.0]
    culled_buffer[id] = (data_image_pos, data_conic, data_color, data_pos_xy, data_pos_z, data_depth_data)

    view_depth = max(0.0, clip_pos[3])
    depth01 = view_depth / (1.0 + view_depth)
    depth = int(depth01 * 65535.0) & 0xFFFF

    for y in range(int(rect_bounds[1]), int(rect_bounds[3])):
        for x in range(int(rect_bounds[0]), int(rect_bounds[2])):
            tile_id = y * grid_size[0] + x
            key = (tile_id << 16) | depth
            sort_keys[sort_buffer_offset] = key
            sort_values[sort_buffer_offset] = id
            sort_buffer_offset += 1
```

**Parameters:**
- `TILE_SIZE`: 16. Used to partition the screen into tiles for sorting [S1, unofficial].
- `SH_C0` to `SH_C3_6`: Spherical harmonic constants [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** Depth quantization uses 16 bits (`depth01 * 65535.0`). This may cause sorting artifacts for very distant or very close splats if not handled by the rasterizer [S1, unofficial].
- **Boundaries:** Frustum culling uses a 1.2x margin (`view_bounds = clip_pos.w * 1.2`). This may include some splats that are technically outside the canonical view volume but are close to the edge [S1, unofficial].
- **Degenerate Input:** If `det == 0` or eigenvalues are negative, the splat is discarded. This handles degenerate Gaussians [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of points and tiles [S1, unofficial].
- **Strengths:** Efficient culling and sorting preparation. Handles animation and lighting [S1, unofficial].
- **Limitations:** Requires a subsequent sorting step. The depth quantization may affect sorting accuracy [S1, unofficial].
- **When to use:** When using tiled rasterization for 3D Gaussian Splatting [S1, unofficial].
- **When not to use:** When using non-tiled rasterization or when sorting is handled differently [S1, unofficial].
