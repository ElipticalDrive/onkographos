# Gaussian Splat Shader Property Configuration

Also called: Render property block setup, Splat instance property binding

## Overview
Configures the material property block (or uniform buffer) with splat count, spherical harmonic (SH) degree, brightness, scale, antialiasing, transform matrix, and optional skinning/volume lighting data for the GPU render pass [S1, unofficial]. It ensures that the fragment shader receives valid sampled resources even when advanced features like rigging are disabled, preventing compilation or runtime errors [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Splat asset metadata (SH bands, rigging status), current render parameters (brightness, scale), and GPU buffer handles.
*   **Output:** A configured shader property block or uniform buffer state ready for the draw call.

**Data Structures:**
The configuration must handle the `GsplatRigWeight` struct layout for skinning data. The layout is inferred from buffer creation requirements:
*   `BoneIndex0`: `uint`
*   `Weight0`: `float`
*   Padding: Added to align the total size to `sizeof(uint) * 4 + sizeof(float) * 4` (16 bytes + 4 bytes + padding = 24 bytes? No, `uint*4` is 16, `float*4` is 16, total 32 bytes. The note says "padding to align with `sizeof(uint) * 4 + sizeof(float) * 4` total size". This implies the struct size is 32 bytes. `BoneIndex0` (4) + `Weight0` (4) = 8 bytes. To reach 32 bytes, 24 bytes of padding follow. This structure is used for skinning weights [S1, unofficial].

**Parameters:**
*   `shDegree`: Order of SH coefficients used for rendering. Capped by the asset's `SHBands` property [S1, unofficial].
*   `brightness`: Brightness color scaling factor. Default: `1.0f` [S1, unofficial].
*   `scaleFactor`: Splat UV scaling factor to reduce splat size while keeping visual fidelity. Default: `1.0f` [S1, unofficial].

**Steps:**
1.  **Bind Splat Textures:** Bind the two main splat textures to uniforms `sourceSplats` and `sourceSplats2` [S2, unofficial].
2.  **Bind SH Textures:** Bind Spherical Harmonics block textures to uniforms `shBlock0Texture` through `shBlock5Texture`. If a specific block texture is missing, bind `Splats.emptyTexture` [S2, unofficial].
3.  **Set Layer Configuration:**
    *   Set `sourceLayerBits` to `layerBits`.
    *   Set `sourceLayerMask` to $2^{\text{layerBits}} - 1$.
    *   Set `sourceBlockBits` to `SPLAT_BLOCKS_DISABLED` [S2, unofficial].
4.  **Disable Advanced Features:**
    *   Set `sourcePackedGroups` to `false`.
    *   Set `sourceBlocks`, `sourceOpacities`, and `sourceIndices` to `Splats.emptyTexture`.
    *   Set `sourceIndexed` to `false` [S2, unofficial].
5.  **Handle Skinning (Portable Shader Variants):**
    *   If rigging is disabled, a dummy skinning buffer must be initialized.
    *   **Pitfall:** Binding null or uninitialized buffers causes shader compilation/runtime errors because portable shader variants require valid sampled resources even when skinning is disabled [S1, unofficial].
    *   Initialize the dummy buffer with the `GsplatRigWeight` layout (32 bytes total) containing zeroed or dummy values [S1, unofficial].
6.  **Finalize:** Mark the splats object as needing no further updates by setting `needsUpdate` to `false` [S2, unofficial].

**Pseudocode:**
```python
def configure_splat_shader_properties(renderer, asset, rigging_enabled):
    # 1. Bind Splat Textures
    renderer.bind_texture("sourceSplats", asset.splat_texture_1)
    renderer.bind_texture("sourceSplats2", asset.splat_texture_2)

    # 2. Bind SH Textures
    for i in range(6):
        texture_name = f"shBlock{i}Texture"
        if asset.has_sh_block(i):
            renderer.bind_texture(texture_name, asset.sh_blocks[i])
        else:
            renderer.bind_texture(texture_name, Splats.empty_texture)

    # 3. Set Layer Configuration
    layer_bits = asset.layer_bits
    renderer.set_uniform("sourceLayerBits", layer_bits)
    renderer.set_uniform("sourceLayerMask", (1 << layer_bits) - 1)
    renderer.set_uniform("sourceBlockBits", SPLAT_BLOCKS_DISABLED)

    # 4. Disable Advanced Features
    renderer.set_uniform("sourcePackedGroups", False)
    renderer.set_uniform("sourceBlocks", Splats.empty_texture)
    renderer.set_uniform("sourceOpacities", Splats.empty_texture)
    renderer.set_uniform("sourceIndices", Splats.empty_texture)
    renderer.set_uniform("sourceIndexed", False)

    # 5. Handle Skinning
    if rigging_enabled:
        renderer.bind_buffer("rigWeights", asset.rig_weight_buffer)
        renderer.set_uniform("rigWeightCount", asset.rig_weight_count)
    else:
        # Pitfall: Must bind a valid buffer even if disabled
        dummy_buffer = create_dummy_rig_buffer()
        renderer.bind_buffer("rigWeights", dummy_buffer)
        renderer.set_uniform("rigWeightCount", 0)

    # 6. Set Render Parameters
    renderer.set_uniform("shDegree", min(asset.sh_bands, 3)) # Capped by asset
    renderer.set_uniform("brightness", 1.0)
    renderer.set_uniform("scaleFactor", 1.0)

    # 7. Finalize
    renderer.needs_update = False

def create_dummy_rig_buffer():
    # GsplatRigWeight layout: BoneIndex0 (uint), Weight0 (float), Padding (24 bytes)
    # Total size: 32 bytes
    # Initialize with zeros
    return Buffer(size=32, data=[0] * 8) # 8 uints/floats worth of zeros
```

## Subtopics

### Renderer Uniform Configuration
A variant focusing on the WebGL/JavaScript implementation using `Gaussian-Splat-Lite`. It explicitly details the binding of `sourceSplats`, `sourceSplats2`, and SH blocks (`shBlock0Texture` to `shBlock5Texture`), handling missing blocks with `Splats.emptyTexture`. It sets layer bits and masks, disables advanced features like packed groups and indexed splats, and marks the object as needing no updates. This variant is specific to the browser-based renderer and uses JavaScript/TypeScript conventions [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ for property configuration, as it involves a fixed number of uniform bindings and buffer setups regardless of splat count.
*   **Memory Complexity:** $O(1)$ for the property block itself. The dummy skinning buffer requires a fixed 32 bytes [S1, unofficial].
*   **Strengths:** Ensures robustness by preventing shader errors when features are disabled. Standardizes the interface for the fragment shader.
*   **Limitations:** Requires careful handling of dummy buffers for portable shader variants.
*   **When to use:** Always, before rendering a Gaussian Splat frame.

## Background
This method is part of the UnitySplats and Gaussian-Splat-Lite implementations for rendering 3D Gaussian Splatting assets. It bridges the gap between the asset data (PLY/GLB) and the GPU shader, ensuring that the complex data structures (SH coefficients, skinning weights) are correctly formatted and bound [S1, unofficial][S2, unofficial].
