# Non-Tiled 2D Gaussian Splatting with Transmittance Culling
## Overview
A rasterization method for 3D Gaussian Splatting that iterates over Gaussians rather than tiles, using axis-aligned bounding boxes to limit pixel iteration and transmittance-based early ray termination for performance optimization [S1, unofficial]. It produces visually identical results to tiled rasterization in most cases but is significantly faster due to early stopping and better culling [S1, unofficial].

## How it works
**Inputs:**
- `gs`: List of $N$ Gaussians, each with 3D mean, covariance, opacity, and spherical harmonic (SH) coefficients [S1, unofficial].
- `camera`: Camera object containing intrinsic parameters ($f_x, f_y, c_x, c_y$), image dimensions ($W, H$), and extrinsic rotation/translation [S1, unofficial].
- `sigma_multiplier`: Scaling factor for the 2D covariance approximation (default 3.33) [S1, unofficial].

**Outputs:**
- `rendered_image`: An $H \times W \times 3$ image tensor in uint8 format [S1, unofficial].

**Data Structures:**
- `u_mean, v_mean`: Projected 2D mean coordinates in pixel space [S1, unofficial].
- `opacity_gaussian`: Scalar opacity value [S1, unofficial].
- `sh_color`: 3-channel color vector derived from SH evaluation [S1, unofficial].
- `a, b, c`: Elements of the inverse 2D covariance matrix (conics) [S1, unofficial].
- `u_min, v_min, u_max, v_max`: Axis-aligned bounding box coordinates in pixel space [S1, unofficial].
- `color`, `alpha`: $H \times W$ tensors initialized to zeros, accumulating final color and alpha per pixel [S1, unofficial].

**Steps:**
1. Initialize `color` and `alpha` tensors to zeros [S1, unofficial].
2. Perform background initialization, projection, and sorting identical to `render_splats` [S1, unofficial]: transform means to camera space, project to image plane, frustum cull with `fov_margin_ratio=0.3`, sort Gaussians back-to-front, rotate covariances to camera space, approximate 2D covariances with `eps_2d=0.3`, compute conics ($a, b, c$), evaluate SH colors, and compute AABBs [S1, unofficial].
3. Iterate over each Gaussian index `i` from 0 to `len(gs)` [S1, unofficial].
4. Retrieve properties: `u_mean, v_mean, opacity_gaussian, sh_color, a, b, c, u_min, v_min, u_max, v_max` [S1, unofficial].
5. If `opacity_gaussian < 0.01`, skip the Gaussian [S1, unofficial].
6. Iterate over pixels `u_pix` from `u_min` to `u_max` and `v_pix` from `v_min` to `v_max` [S1, unofficial].
7. Check if pixel is within image bounds: `if 0 <= u_pix < W and 0 <= v_pix < H` [S1, unofficial].
8. Read current pixel alpha. If `alpha_pixel >= 0.99`, skip the Gaussian for this pixel (early termination) [S1, unofficial].
9. Compute squared Mahalanobis distance with half-pixel offset: $du = u\_pix + 0.5 - u\_mean$, $dv = v\_pix + 0.5 - v\_mean$, $dist\_sq = a \cdot du^2 + 2 \cdot b \cdot du \cdot dv + c \cdot dv^2$ [S1, unofficial].
10. Calculate Gaussian alpha $\alpha_g = \exp(-0.5 \cdot dist\_sq) \cdot opacity\_gaussian$ and update pixel alpha and color using standard alpha blending [G].
11. After processing all Gaussians, add background and clamp/convert to uint8 as in `render_splats` [S1, unofficial].

**Pseudocode:**
```python
import math

def render_splats_fov_cull_transmittance(gs, camera, sigma_multiplier=3.33):
    W, H = camera.width, camera.height
    # Initialize color and alpha buffers
    color = [[0.0, 0.0, 0.0] for _ in range(H)]
    alpha = [[0.0] * W for _ in range(H)]

    # Preprocessing identical to render_splats
    # Transform means, project, frustum cull (fov_margin_ratio=0.3), sort back-to-front
    # Rotate covariances, approximate 2D covariances (eps_2d=0.3), compute conics
    # Evaluate SH colors, compute AABBs
    # (Assumed implemented in gs object or preprocessing step)

    for i in range(len(gs)):
        u_mean, v_mean = gs[i].u_mean, gs[i].v_mean
        opacity_gaussian = gs[i].opacity
        sh_color = gs[i].sh_color
        a, b, c = gs[i].conics
        u_min, v_min, u_max, v_max = gs[i].aabb

        if opacity_gaussian < 0.01:
            continue

        for u_pix in range(u_min, u_max + 1):
            for v_pix in range(v_min, v_max + 1):
                if 0 <= u_pix < W and 0 <= v_pix < H:
                    if alpha[v_pix][u_pix] >= 0.99:
                        continue

                    du = u_pix + 0.5 - u_mean
                    dv = v_pix + 0.5 - v_mean
                    dist_sq = a * du**2 + 2 * b * du * dv + c * dv**2

                    alpha_g = math.exp(-0.5 * dist_sq) * opacity_gaussian
                    current_alpha = alpha[v_pix][u_pix]
                    alpha_new = current_alpha + alpha_g * (1.0 - current_alpha)
                    color_new = [
                        color[v_pix][u_pix][0] + sh_color[0] * alpha_g * (1.0 - current_alpha),
                        color[v_pix][u_pix][1] + sh_color[1] * alpha_g * (1.0 - current_alpha),
                        color[v_pix][u_pix][2] + sh_color[2] * alpha_g * (1.0 - current_alpha)
                    ]

                    alpha[v_pix][u_pix] = alpha_new
                    color[v_pix][u_pix] = color_new

    # Add background color and clamp/convert to uint8 [G]
    for v in range(H):
        for u in range(W):
            for c in range(3):
                color[v][u][c] = max(0.0, min(1.0, color[v][u][c]))
    return [[int(c * 255) for c in row] for row in color]
```

**Edge cases and pitfalls:**
- Low-opacity Gaussians (`opacity_gaussian < 0.01`) are skipped entirely to save computation [S1, unofficial].
- Fully opaque pixels (`alpha_pixel >= 0.99`) trigger early termination for subsequent Gaussians, preventing redundant blending [S1, unofficial].
- The half-pixel offset in the Mahalanobis distance calculation aligns the Gaussian center with pixel sampling coordinates [S1, unofficial].
- Bounding box iteration must be clamped to image dimensions to avoid out-of-bounds memory access [S1, unofficial].
