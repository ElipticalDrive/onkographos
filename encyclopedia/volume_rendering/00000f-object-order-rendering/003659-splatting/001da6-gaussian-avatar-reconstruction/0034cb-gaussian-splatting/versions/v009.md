# Gaussian Splatting

Also called: 3D Gaussian Splatting (3DGS), Vanilla 3DGS rendering

## Overview
Gaussian Splatting is a novel-view synthesis method that represents a scene as an explicit collection of anisotropic 3D Gaussians, each carrying opacity and view-dependent color encoded via spherical harmonics [S5, unofficial]. It solves the computational bottleneck of implicit neural radiance fields (NeRFs) by replacing ray marching with a tile-based differentiable rasterizer, enabling real-time rendering speeds (≥30 fps at 1080p) while maintaining photorealistic quality [S5, unofficial]. It sets itself apart from its siblings by optimizing Gaussian parameters directly from images using adaptive density control (cloning, splitting, pruning) rather than relying on a fixed mesh or implicit network, and from [Gaussian Avatar Reconstruction](1575-gaussian-avatar-reconstruction.md) by lacking pose-conditioned deformation constraints, treating the scene as static geometry [S5, unofficial].

## How it works
**Inputs:** A set of posed input images $\{I_i\}$ and their corresponding camera poses (extrinsics $W$ and intrinsics $K$) obtained via Structure-from-Motion (SfM) [S1].
**Outputs:** A rendered 2D image $C_{\mathbf{x}}$ for any arbitrary camera viewpoint, and a set of optimized Gaussian parameters $\theta$ [S1].

**Data Structures:**
The scene is represented by a collection of $M$ 3D Gaussians. Each Gaussian $g_i$ is defined by the following parameters [S1][S12, unofficial]:
*   $\boldsymbol{\mu}_i \in \mathbb{R}^3$: Center position in world space.
*   $\mathbf{s}_i \in \mathbb{R}^3$: Scale vector (stored in log space for optimization stability) [S4, unofficial].
*   $\mathbf{q}_i \in \mathbb{R}^4$: Rotation quaternion (normalized to unit length) [S4, unofficial].
*   $\sigma_i \in \mathbb{R}$: Opacity (stored as a logit, mapped to $[0,1]$ via sigmoid during rendering) [S4, unofficial].
*   $\mathbf{h}_i \in \mathbb{R}^{4 \times 3}$: Spherical Harmonic (SH) coefficients for view-dependent color (typically up to band 3, i.e., 48 coefficients per splat for RGB) [S4, unofficial].

The 3D covariance matrix $\boldsymbol{\Sigma}_i$ is not stored directly but reconstructed from scale and rotation to ensure positive semi-definiteness [S5, unofficial]:
$$ \boldsymbol{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^\top \mathbf{R}_i^\top $$
where $\mathbf{R}_i$ is the rotation matrix derived from $\mathbf{q}_i$, and $\mathbf{S}_i = \text{diag}(e^{\mathbf{s}_i})$ is the scaling matrix [S5, unofficial][S14, unofficial].

**Numbered Steps:**

1.  **Initialization:** Initialize $M$ Gaussians by placing their centers $\boldsymbol{\mu}_i$ at the points of a sparse SfM point cloud. Initialize scales $\mathbf{s}_i$ to a small constant, rotations $\mathbf{q}_i$ to identity, opacities $\sigma_i$ to a small constant, and SH coefficients $\mathbf{h}_i$ to zero (or precomputed from image colors) [S1][S5, unofficial].

2.  **3D-to-2D Projection (Splatting):** For each Gaussian $i$, project it onto the 2D image plane [S8].
    *   Transform the center to camera space: $\boldsymbol{\mu}_i^{cam} = W \boldsymbol{\mu}_i$ [S12, unofficial].
    *   Compute the Jacobian $\mathbf{J} \in \mathbb{R}^{2 \times 3}$ of the perspective projection $\phi_{\mathbf{K}}$ at $\boldsymbol{\mu}_i^{cam}$ [S12, unofficial].
    *   Approximate the 2D covariance $\tilde{\boldsymbol{\Sigma}}_i$ using the linearized projection [S1]:
        $$ \tilde{\boldsymbol{\Sigma}}_i = \mathbf{J} W \boldsymbol{\Sigma}_i W^\top \mathbf{J}^\top $$
    *   Compute the 2D mean $\tilde{\boldsymbol{\mu}}_i = \phi_{\mathbf{K}}(W \boldsymbol{\mu}_i)$ [S1].
    *   Compute the 3-sigma bounding box in screen space to determine which tiles the Gaussian affects [S11, unofficial].

3.  **Tile-Based Sorting:** Partition the image into tiles (typically $16 \times 16$ pixels) [S8]. Assign each Gaussian to the tiles it intersects. Sort the Gaussians within each tile by depth (z-coordinate of the center in camera space) from front to back using a GPU-optimized radix sort [S8][S15].

4.  **Alpha Compositing (Rasterization):** For each pixel $\mathbf{x}$ in a tile, iterate through the sorted list of overlapping Gaussians $i=1 \dots N$ [S8].
    *   Evaluate the 2D Gaussian density at the pixel:
        $$ g'_i(\mathbf{x}) = \exp\left(-\frac{1}{2} (\mathbf{x} - \tilde{\boldsymbol{\mu}}_i)^\top \tilde{\boldsymbol{\Sigma}}_i^{-1} (\mathbf{x} - \tilde{\boldsymbol{\mu}}_i)\right) $$
    *   Compute the effective alpha contribution:
        $$ \alpha_i(\mathbf{x}) = \sigma_i \cdot g'_i(\mathbf{x}) $$
        Clamp $\alpha_i(\mathbf{x})$ to a maximum value (e.g., 0.99) to prevent full opacity blocking [S11, unofficial].
    *   Compute the view-dependent color $\mathbf{c}_i$ by evaluating the SH coefficients with the viewing direction $\mathbf{d}_i$ (from camera to $\boldsymbol{\mu}_i$) [S7, unofficial]. For band 0 only: $\mathbf{c}_i = \text{clamp}(0.5 + C_0 \mathbf{h}_{i,0}, 0, 1)$ where $C_0 \approx 0.282$ [S4, unofficial].
    *   Accumulate color and transmittance:
        $$ C_{\mathbf{x}} = \sum_{i=1}^{N} \mathbf{c}_i \alpha_i(\mathbf{x}) \prod_{j=1}^{i-1} (1 - \alpha_j(\mathbf{x})) $$
        $$ T_{\mathbf{x}} = \prod_{i=1}^{N} (1 - \alpha_i(\mathbf{x})) $$
    *   Add background color $\mathbf{c}_{BG}$ (default white) weighted by remaining transmittance: $C_{\mathbf{x}} = C_{\mathbf{x}} + \mathbf{c}_{BG} T_{\mathbf{x}}$ [S10, unofficial].

5.  **Optimization Loop:**
    *   Render the image from a random training viewpoint.
    *   Compute photometric loss $\mathcal{L}$ between rendered image $C_{\mathbf{x}}$ and ground truth $I_{\mathbf{x}}$ using L1 and D-SSIM [S6, unofficial]:
        $$ \mathcal{L} = (1 - \lambda) \mathcal{L}_{L1} + \lambda \mathcal{L}_{DSSIM} $$
    *   Backpropagate gradients to update $\boldsymbol{\mu}_i, \mathbf{s}_i, \mathbf{q}_i, \sigma_i, \mathbf{h}_i$ using an optimizer like Adam [S12, unofficial].
    *   **Adaptive Density Control:** Every $k$ iterations (e.g., 100):
        *   **Clone:** Duplicate Gaussians in regions with high image error and small scale.
        *   **Split:** Split large Gaussians (scale above threshold) into two, inheriting parent attributes with slight perturbations.
        *   **Prune:** Remove Gaussians with opacity below a threshold [S1][S15].

**Pseudocode:**

```python
import numpy as np

def render_gaussian_splats(gaussians, camera, image_width, image_height, tile_size=16):
    """
    Renders a scene of 3D Gaussians to a 2D image.
    
    Args:
        gaussians: List of dicts, each containing:
            'mu': (3,) center position
            's': (3,) scale (log space)
            'q': (4,) rotation quaternion
            'sigma': (1,) opacity logit
            'sh': (48,) SH coefficients (band 3)
        camera: Dict containing 'W' (4x4 extrinsic), 'K' (3x3 intrinsic)
        image_width, image_height: int
        tile_size: int (default 16)
        
    Returns:
        image: (H, W, 3) rendered RGB image
    """
    # 1. Precompute 3D Covariance and 2D Projection for all Gaussians
    projected_gaussians = []
    for g in gaussians:
        # Reconstruct 3D Covariance
        R = quat_to_rot_mat(g['q'])
        S = np.diag(np.exp(g['s']))
        Sigma_3d = R @ (S @ S.T) @ R.T
        
        # Transform to camera space
        mu_cam = camera['W'] @ np.append(g['mu'], 1.0)
        mu_cam = mu_cam[:3] / mu_cam[3] # Perspective divide
        
        # Jacobian of projection
        # J approximates d(proj)/d(x) at mu_cam
        J = compute_projection_jacobian(mu_cam, camera['K'])
        
        # Project Covariance to 2D
        # Sigma_2d = J @ W_3x3 @ Sigma_3d @ W_3x3.T @ J.T
        # Note: W in formula includes the 3x3 rotation part of camera pose
        W_3x3 = camera['W'][:3, :3]
        Sigma_2d = J @ (W_3x3 @ Sigma_3d @ W_3x3.T) @ J.T
        
        # Project Mean
        mu_2d = project_point(mu_cam, camera['K'])
        
        # Compute Bounding Box (3-sigma)
        # Eigenvalues of Sigma_2d give squared semi-axes
        eigenvalues = np.linalg.eigvalsh(Sigma_2d)
        axes = 3.0 * np.sqrt(eigenvalues)
        bbox_min = mu_2d - axes
        bbox_max = mu_2d + axes
        
        # Clip to image bounds
        bbox_min = np.clip(bbox_min, 0, [image_width, image_height])
        bbox_max = np.clip(bbox_max, 0, [image_width, image_height])
        
        projected_gaussians.append({
            'mu_2d': mu_2d,
            'Sigma_2d': Sigma_2d,
            'sigma': sigmoid(g['sigma']),
            'sh': g['sh'],
            'bbox': (bbox_min, bbox_max),
            'mu_cam': mu_cam
        })
        
    # 2. Tile-based Sorting
    # Initialize tile lists
    num_tiles_x = (image_width + tile_size - 1) // tile_size
    num_tiles_y = (image_height + tile_size - 1) // tile_size
    tiles = [[[] for _ in range(num_tiles_x)] for _ in range(num_tiles_y)]
    
    for idx, pg in enumerate(projected_gaussians):
        bbox_min, bbox_max = pg['bbox']
        tile_min_x = int(bbox_min[0] // tile_size)
        tile_min_y = int(bbox_min[1] // tile_size)
        tile_max_x = int(bbox_max[0] // tile_size)
        tile_max_y = int(bbox_max[1] // tile_size)
        
        for ty in range(tile_min_y, tile_max_y + 1):
            for tx in range(tile_min_x, tile_max_x + 1):
                if 0 <= ty < num_tiles_y and 0 <= tx < num_tiles_x:
                    # Store index and depth for sorting
                    depth = pg['mu_cam'][2]
                    tiles[ty][tx].append((idx, depth))
                    
    # Sort each tile by depth (front to back)
    for ty in range(num_tiles_y):
        for tx in range(num_tiles_x):
            tiles[ty][tx].sort(key=lambda x: x[1])
            
    # 3. Rasterization
    image = np.zeros((image_height, image_width, 3))
    transmittance = np.ones((image_height, image_width))
    
    for ty in range(num_tiles_y):
        for tx in range(num_tiles_x):
            tile_gaussians = tiles[ty][tx]
            y_start, y_end = ty * tile_size, min((ty + 1) * tile_size, image_height)
            x_start, x_end = tx * tile_size, min((tx + 1) * tile_size, image_width)
            
            for idx, _ in tile_gaussians:
                pg = projected_gaussians[idx]
                mu_2d = pg['mu_2d']
                Sigma_2d = pg['Sigma_2d']
                alpha_base = pg['sigma']
                
                # Inverse 2D Covariance for Gaussian evaluation
                try:
                    Sigma_2d_inv = np.linalg.inv(Sigma_2d)
                except np.linalg.LinAlgError:
                    continue # Skip invalid covariance
                
                # Evaluate Gaussian over the tile pixels
                # Vectorized evaluation for performance
                ys = np.arange(y_start, y_end)
                xs = np.arange(x_start, x_end)
                Y, X = np.meshgrid(ys, xs, indexing='ij')
                coords = np.stack([X - mu_2d[0], Y - mu_2d[1]], axis=-1) # (H_tile, W_tile, 2)
                
                # Power = -0.5 * (x - mu)^T Sigma^-1 (x - mu)
                # Using conic matrix C = Sigma^-1
                C = Sigma_2d_inv
                # power = -0.5 * (C[0,0]*x^2 + C[1,1]*y^2 + 2*C[0,1]*xy)
                x_vec = coords[:,:,0]
                y_vec = coords[:,:,1]
                power = -0.5 * (C[0,0]*x_vec**2 + C[1,1]*y_vec**2 + 2*C[0,1]*x_vec*y_vec)
                
                # Clamp power to avoid exp(0) issues, though exp(0)=1
                # Discard if power > 0 (outside effective area)
                valid_mask = power < 0
                
                # Alpha = sigma * exp(power)
                alpha = alpha_base * np.exp(power)
                alpha = np.clip(alpha, 0, 0.99) # Clamp max alpha
                
                # Color from SH
                # Direction from camera to Gaussian center
                cam_pos = np.linalg.inv(camera['W'])[:3, 3]
                view_dir = pg['mu_cam'] - cam_pos
                view_dir = view_dir / np.linalg.norm(view_dir)
                color = sh_eval(pg['sh'], view_dir)
                
                # Composite
                # C_new = C_old * (1 - alpha) + color * alpha
                # T_new = T_old * (1 - alpha)
                
                # Apply to tile region
                # Note: transmittance is global, but here we assume tile-local accumulation 
                # is not enough; we need global transmittance. 
                # Simplified: accumulate into image directly.
                
                # Update image and transmittance
                # This loop is slow in Python; in C++/CUDA this is the fragment shader
                for y in range(y_start, y_end):
                    for x in range(x_start, x_end):
                        if valid_mask[y-y_start, x-x_start]:
                            a = alpha[y-y_start, x-x_start]
                            if transmittance[y, x] > 1e-4:
                                c = color
                                image[y, x] = image[y, x] * (1 - a) + c * a
                                transmittance[y, x] *= (1 - a)
                                
    # Add background
    bg_color = np.array([1.0, 1.0, 1.0])
    image = image + bg_color * transmittance[..., np.newaxis]
    
    return image

def quat_to_rot_mat(q):
    # q = [w, x, y, z] or [x, y, z, w]? Standard 3DGS uses [w, x, y, z] or [x, y, z, w]?
    # Sources say q = [q_r, q_i, q_j, q_k]. Usually q_r is real part.
    # Assuming input q is [w, x, y, z]
    w, x, y, z = q
    return np.array([
        [1 - 2*(y**2 + z**2), 2*(x*y - w*z), 2*(x*z + w*y)],
        [2*(x*y + w*z), 1 - 2*(x**2 + z**2), 2*(y*z - w*x)],
        [2*(x*z - w*y), 2*(y*z + w*x), 1 - 2*(x**2 + y**2)]
    ])

def compute_projection_jacobian(mu_cam, K):
    x, y, z = mu_cam
    # Perspective projection: u = K[0,0]*x/z + K[0,2], v = K[1,1]*y/z + K[1,2]
    # Jacobian d(u,v)/d(x,y,z)
    fx, fy = K[0,0], K[1,1]
    cx, cy = K[0,2], K[1,2]
    
    # d(u)/dx = fx/z, d(u)/dy = 0, d(u)/dz = -fx*x/z^2
    # d(v)/dx = 0, d(v)/dy = fy/z, d(v)/dz = -fy*y/z^2
    J = np.array([
        [fx/z, 0, -fx*x/(z**2)],
        [0, fy/z, -fy*y/(z**2)]
    ])
    return J

def project_point(mu_cam, K):
    x, y, z = mu_cam
    u = K[0,0]*x/z + K[0,2]
    v = K[1,1]*y/z + K[1,2]
    return np.array([u, v])

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))

def sh_eval(sh_coeffs, view_dir):
    # Simplified Band 0 evaluation
    # C0 = 0.28209479177387814
    C0 = 0.28209479177387814
    # sh_coeffs shape (48,) or (4,3)? Assuming (4,3) for 3 channels, 4 bands
    # Band 0 is index 0
    dc = sh_coeffs[0] # (3,)
    color = np.clip(0.5 + C0 * dc, 0, 1)
    return color
```

## Operating characteristics
*   **Time Complexity:** Rendering is $O(M)$ where $M$ is the number of Gaussians, but effectively $O(N \cdot K)$ per pixel where $N$ is average Gaussians per tile and $K$ is tile size. Sorting is $O(M \log M)$ per frame [S8].
*   **Memory Complexity:** $O(M)$, storing 59 floats per Gaussian (position, scale, rotation, opacity, SH) [S15]. Typical scenes use 1-5 million Gaussians, consuming 1-5 GB VRAM [S15].
*   **Performance:** Achieves ≥30 fps at 1080p on consumer hardware [S5, unofficial]. Mip-NeRF360 benchmark: 27.21 dB PSNR, 0.214 LPIPS at 134 fps [S5, unofficial].
*   **Strengths:** Real-time rendering, high visual fidelity, explicit representation allows easy editing.
*   **Limitations:** Temporal flickering due to sorting artifacts [S14, unofficial], "floaters" in unobserved regions [S5, unofficial], poor handling of highly reflective surfaces (emission-absorption model) [S12, unofficial], no explicit surface definition [S15].
*   **When to use:** Novel view synthesis, static scene reconstruction, real-time visualization.
*   **When not to use:** Dynamic scenes with complex non-rigid deformation (use [Gaussian Avatar Reconstruction](1575-gaussian-avatar-reconstruction.md)), scenes requiring precise surface meshes, or highly reflective environments.

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [S1][S5, unofficial]. It builds on EWA Volume Splatting [S2][S3, unofficial] and point-based rendering techniques [S5, unofficial]. The method was developed to address the slow rendering speeds of NeRFs while maintaining their high quality. It has become a standard baseline for novel view synthesis and 3D reconstruction [S5, unofficial].
