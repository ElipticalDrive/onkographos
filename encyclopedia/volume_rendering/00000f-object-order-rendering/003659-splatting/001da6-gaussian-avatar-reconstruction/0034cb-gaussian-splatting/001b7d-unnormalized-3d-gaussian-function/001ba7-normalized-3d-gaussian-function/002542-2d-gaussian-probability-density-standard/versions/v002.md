# 2D Gaussian Probability Density (Standard)

Also called: 2D Gaussian PDF

## Overview
Computes the probability density function (PDF) value of a 2D Gaussian distribution at a specific 2D point, given its mean vector and covariance matrix. It serves as the core evaluation primitive for determining the contribution of a projected 3D Gaussian splat to a pixel in Gaussian Splatting rendering. It differs from its sibling [Gaussian Interpolation](2347-gaussian-interpolation.md) by providing a direct analytical evaluation of the density rather than interpolating values between grid points.

## How it works
**Inputs:**
- `xy`: A 2D point (vector) representing the location in screen space where the PDF is evaluated.
- `gaussian_mean`: A 2D vector representing the mean (center) of the Gaussian.
- `gaussian_covariance`: A $2 \times 2$ symmetric positive-definite covariance matrix $\Sigma$.

**Outputs:**
- `pdf`: A scalar float representing the probability density at `xy`.

**Data Structures:**
- `xy`: `vec2` (float x, float y).
- `gaussian_mean`: `vec2` (float x, float y).
- `gaussian_covariance`: `mat2x2` (float m00, m01, m10, m11). Note: $m_{01} = m_{10}$ for symmetric covariance.

**Steps:**
1.  **Compute Mean Difference:** Calculate the vector from the Gaussian mean to the evaluation point.
    $$ \Delta = xy - gaussian\_mean $$
2.  **Compute Determinant:** Calculate the determinant of the covariance matrix.
    $$ \det(\Sigma) = \Sigma_{00}\Sigma_{11} - \Sigma_{01}\Sigma_{10} $$
3.  **Compute Inverse Covariance:** Calculate the inverse of the $2 \times 2$ covariance matrix analytically.
    $$ \Sigma^{-1} = \frac{1}{\det(\Sigma)} \begin{bmatrix} \Sigma_{11} & -\Sigma_{01} \\ -\Sigma_{10} & \Sigma_{00} \end{bmatrix} $$
4.  **Compute Quadratic Form:** Calculate the Mahalanobis distance squared (quadratic form).
    $$ q = \Delta^T \Sigma^{-1} \Delta $$
    This is computed as:
    $$ \Delta^T \Sigma^{-1} = \begin{bmatrix} \Delta_x & \Delta_y \end{bmatrix} \Sigma^{-1} $$
    $$ q = (\Delta^T \Sigma^{-1}) \cdot \begin{bmatrix} \Delta_x \\ \Delta_y \end{bmatrix} $$
5.  **Compute Exponent:**
    $$ exponent = -0.5 \cdot q $$
6.  **Return PDF:** Compute the final normalized probability density.
    $$ PDF = \frac{\exp(exponent)}{2 \pi \sqrt{\det(\Sigma)}} $$

**Pseudocode:**
```python
def compute_2d_gaussian_pdf_standard(xy: vec2, gaussian_mean: vec2, gaussian_covariance: mat2x2) -> float:
    # Step 1: Compute mean difference
    delta = xy - gaussian_mean
    
    # Step 2: Compute determinant of the 2x2 covariance matrix
    # cov = [[m00, m01], [m10, m11]]
    det_cov = gaussian_covariance.m00 * gaussian_covariance.m11 - gaussian_covariance.m01 * gaussian_covariance.m10
    
    # Guard against singular or near-singular matrices to prevent division by zero
    if det_cov <= 0.0:
        return 0.0
        
    # Step 3: Compute inverse covariance matrix analytically
    # inv_cov = (1/det) * [[m11, -m01], [-m10, m00]]
    inv_m00 = gaussian_covariance.m11 / det_cov
    inv_m01 = -gaussian_covariance.m01 / det_cov
    inv_m10 = -gaussian_covariance.m10 / det_cov
    inv_m11 = gaussian_covariance.m00 / det_cov
    
    # Step 4: Compute quadratic form: delta^T * inv_cov * delta
    # First: temp = delta^T * inv_cov
    temp_x = delta.x * inv_m00 + delta.y * inv_m10
    temp_y = delta.x * inv_m01 + delta.y * inv_m11
    
    # Second: q = temp . delta
    quadratic_form = temp_x * delta.x + temp_y * delta.y
    
    # Step 5: Compute exponent
    exponent = -0.5 * quadratic_form
    
    # Step 6: Return normalized PDF
    # Normalization constant: 1 / (2 * pi * sqrt(det))
    normalization = 1.0 / (2.0 * 3.14159265358979323846 * sqrt(det_cov))
    
    return exp(exponent) * normalization
```

**Parameters:**
- $\pi$: Mathematical constant pi.
- No tunable parameters; this is a deterministic mathematical evaluation.

**Edge Cases and Pitfalls:**
- **Singular Covariance:** If $\det(\Sigma) = 0$, the inverse is undefined. The implementation must check for non-positive determinants and return 0 or handle gracefully [G].
- **Precision:** For very small covariances, $\sqrt{\det(\Sigma)}$ may underflow. For very large covariances, the exponent may underflow to 0. Standard IEEE 754 floating-point behavior applies.
- **Symmetry:** The covariance matrix is symmetric. The code assumes $\Sigma_{01} = \Sigma_{10}$. If the input matrix is not symmetric, the result may be incorrect.

## Subtopics

### [Gradient of 2D Gaussian PDF (Conic)](3472-gradient-of-2d-gaussian-pdf-conic.md)
Computes the probability density value $p$ and its gradients with respect to the Gaussian mean ($\frac{dp}{d\_mean}$) and covariance ($\frac{dp}{d\_cov}$) for a 2D Gaussian distribution. This method provides three variants: normalized (including the $1/(2\pi\sqrt{\det})$ factor), unnormalized (excluding the factor), and conic-based (using the conic matrix representation). It builds on [2D Gaussian Probability Density (Standard)](3466-2d-gaussian-probability-density-standard.md) by providing the necessary derivatives for optimization, specifically for training Gaussian splats where gradients must flow back to mean and covariance parameters.

### [Single Point Alpha Forward](3478-single-point-alpha-forward.md)
Computes the alpha value for a single 3D Gaussian projected onto a 2D pixel by evaluating the 2D Gaussian probability density function (PDF) at the pixel center. It builds on [2D Gaussian Probability Density (Standard)](3466-2d-gaussian-probability-density-standard.md) by handling the full pipeline of transforming 3D Gaussian parameters (position, rotation, scale) into camera space, projecting the covariance to screen space, and combining the resulting PDF with the Gaussian's intrinsic opacity. It differs from its sibling [Gradient of 2D Gaussian PDF (Conic)](3472-gradient-of-2d-gaussian-pdf-conic.md) by returning a scalar alpha value rather than the gradient of the PDF.

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation. Involves a fixed number of arithmetic operations (additions, multiplications, square root, exponential).
- **Memory Complexity:** $O(1)$ auxiliary memory.
- **Strengths:** Analytical solution is exact and fast. No approximation errors from grid sampling.
- **Limitations:** Requires the covariance matrix to be invertible. Does not handle occlusion or depth sorting (those are handled by the rasterization pipeline).
- **When to use:** When evaluating the contribution of a single Gaussian splat to a specific pixel coordinate.
- **When not to use:** When gradients are needed (use [Gradient of 2D Gaussian PDF (Conic)](3472-gradient-of-2d-gaussian-pdf-conic.md)) or when computing alpha compositing over multiple splats (use [Single Point Alpha Forward](3478-single-point-alpha-forward.md) or the full rasterizer).

## Background
Originated in the context of Gaussian Splatting for 3D Gaussian Avatar Reconstruction, specifically within implementations like `taichi_3d_gaussian_splatting` [S1, unofficial]. It is a fundamental component of the EWA (Elliptical Weighted Average) splatting technique used to project 3D Gaussians onto the 2D image plane. The method relies on the standard definition of the multivariate Gaussian distribution.
