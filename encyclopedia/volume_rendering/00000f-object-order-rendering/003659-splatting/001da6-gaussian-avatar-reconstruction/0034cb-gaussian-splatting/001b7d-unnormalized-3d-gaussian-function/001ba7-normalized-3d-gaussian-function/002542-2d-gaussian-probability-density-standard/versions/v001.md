# 2D Gaussian Probability Density (Standard)

Also called: 2D Gaussian PDF

## Overview
Computes the probability density function (PDF) value of a 2D Gaussian distribution at a specific point $(x, y)$, given its mean vector and covariance matrix [S1, unofficial]. It serves as the core evaluation kernel for determining the contribution of a projected 3D Gaussian splat to a pixel in Gaussian Splatting rendering [S1, unofficial]. Unlike the unnormalized variant, this method includes the normalization constant $1/(2\pi\sqrt{\det(\Sigma)})$, ensuring the integral over the entire plane equals one [S1, unofficial]. It is distinct from the conic-based variant by explicitly computing the inverse covariance matrix rather than using a pre-computed conic matrix [S1, unofficial].

## How it works
**Inputs:**
- `xy`: A 2D vector representing the point of evaluation (e.g., pixel center or fragment coordinate) [S1, unofficial].
- `gaussian_mean`: A 2D vector representing the mean $\mu$ of the Gaussian [S1, unofficial].
- `gaussian_covariance`: A $2 \times 2$ symmetric positive-definite matrix $\Sigma$ representing the covariance [S1, unofficial].

**Outputs:**
- `pdf`: A scalar float representing the probability density value $P(xy)$ [S1, unofficial].

**Data Structures:**
- `gaussian_covariance`: Stored as a $2 \times 2$ matrix. For a 2D Gaussian, the covariance matrix is:
  $$
  \Sigma = \begin{bmatrix} \Sigma_{00} & \Sigma_{01} \\ \Sigma_{10} & \Sigma_{11} \end{bmatrix}
  $$
  where $\Sigma_{01} = \Sigma_{10}$ due to symmetry [S1, unofficial].

**Steps:**
1. **Compute Mean Difference:** Calculate the vector from the mean to the evaluation point:
   $$
   \Delta = xy - \text{gaussian\_mean}
   $$
   Let $\Delta = [\Delta x, \Delta y]^T$ [S1, unofficial].

2. **Compute Determinant:** Calculate the determinant of the covariance matrix:
   $$
   \det(\Sigma) = \Sigma_{00}\Sigma_{11} - \Sigma_{01}\Sigma_{10}
   $$
   [S1, unofficial].

3. **Compute Inverse Covariance:** Compute the analytical inverse of the $2 \times 2$ covariance matrix:
   $$
   \Sigma^{-1} = \frac{1}{\det(\Sigma)} \begin{bmatrix} \Sigma_{11} & -\Sigma_{01} \\ -\Sigma_{10} & \Sigma_{00} \end{bmatrix}
   $$
   [S1, unofficial].

4. **Compute Quadratic Form:** Calculate the exponent's argument (the Mahalanobis distance squared):
   $$
   Q = \Delta^T \Sigma^{-1} \Delta
   $$
   This involves two matrix-vector multiplications:
   $$
   v = \Sigma^{-1} \Delta
   $$
   $$
   Q = v^T \Delta = v_x \Delta x + v_y \Delta y
   $$
   [S1, unofficial].

5. **Compute Exponent:**
   $$
   \text{exponent} = -0.5 \cdot Q
   $$
   [S1, unofficial].

6. **Compute Normalization Constant:**
   $$
   Z = 2 \pi \sqrt{\det(\Sigma)}
   $$
   [S1, unofficial].

7. **Return PDF:**
   $$
   P(xy) = \frac{\exp(\text{exponent})}{Z}
   $$
   [S1, unofficial].

**Pseudocode:**
```python
import math

def compute_2d_gaussian_pdf(xy, gaussian_mean, gaussian_covariance):
    """
    Computes the normalized 2D Gaussian PDF at point xy.
    
    Args:
        xy: tuple (x, y)
        gaussian_mean: tuple (mu_x, mu_y)
        gaussian_covariance: list of lists [[c00, c01], [c10, c11]]
        
    Returns:
        float: The probability density value.
    """
    # 1. Compute mean difference
    dx = xy[0] - gaussian_mean[0]
    dy = xy[1] - gaussian_mean[1]
    
    # 2. Compute determinant
    c00 = gaussian_covariance[0][0]
    c01 = gaussian_covariance[0][1]
    c10 = gaussian_covariance[1][0]
    c11 = gaussian_covariance[1][1]
    
    det_cov = c00 * c11 - c01 * c10
    
    # Guard against singular covariance matrices
    if det_cov <= 0:
        return 0.0
        
    # 3. Compute inverse covariance matrix
    inv_det = 1.0 / det_cov
    inv_c00 = c11 * inv_det
    inv_c01 = -c01 * inv_det
    inv_c10 = -c10 * inv_det
    inv_c11 = c00 * inv_det
    
    # 4. Compute quadratic form: dx * (inv_c00 * dx + inv_c01 * dy) + dy * (inv_c10 * dx + inv_c11 * dy)
    # Since covariance is symmetric, inv_c01 == inv_c10
    quad_form = dx * (inv_c00 * dx + inv_c01 * dy) + dy * (inv_c10 * dx + inv_c11 * dy)
    
    # 5. Compute exponent
    exponent = -0.5 * quad_form
    
    # 6. Compute normalization constant
    normalization = 2.0 * math.pi * math.sqrt(det_cov)
    
    # 7. Return PDF
    return math.exp(exponent) / normalization
```

**Parameters:**
- No explicit tuning parameters. The shape is defined entirely by the input covariance matrix [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Singular Covariance:** If $\det(\Sigma) = 0$, the inverse is undefined. The implementation should return 0 or handle this via a small epsilon addition to the determinant [G].
- **Numerical Stability:** For very large or very small determinants, `sqrt(det_cov)` may underflow or overflow. Using log-space computations is an alternative but not specified in the source [G].
- **Symmetry:** The covariance matrix must be symmetric. If the input is not symmetric, the result may be incorrect [G].

## Subtopics

### 2D Gaussian Probability Density (Conic)
Computes the unnormalized probability density of a 2D Gaussian at a point `xy` using a pre-computed conic matrix and a rescaling factor [S1, unofficial]. The conic matrix represents the inverse covariance matrix $\Sigma^{-1}$ [S1, unofficial]. This variant is more efficient for rendering as it avoids matrix inversion and square root operations during evaluation [S1, unofficial]. It is chosen when performance is critical and the covariance is already transformed into conic form [S1, unofficial]. Link: [Gradient of 2D Gaussian PDF (Conic)](3472-gradient-of-2d-gaussian-pdf-conic.md).

**Formula:**
$$
p = \exp\left(-0.5 (\Delta x^2 C_{00} + \Delta y^2 C_{11} + 2 \Delta x \Delta y C_{01})\right) \cdot R
$$
where $\Delta x = xy.x - \text{gaussian\_mean}.x$, $\Delta y = xy.y - \text{gaussian\_mean}.y$, $C_{00}, C_{01}, C_{11}$ are components of the conic matrix, and $R$ is the rescaling factor [S1, unofficial].

**Code:**
```python
def compute_2d_gaussian_pdf_conic(xy, gaussian_mean, conic_and_rescale):
    """
    Computes the unnormalized 2D Gaussian PDF using conic matrix.
    
    Args:
        xy: tuple (x, y)
        gaussian_mean: tuple (mu_x, mu_y)
        conic_and_rescale: tuple (C00, C01, C11, R)
        
    Returns:
        float: The unnormalized probability density value.
    """
    dx = xy[0] - gaussian_mean[0]
    dy = xy[1] - gaussian_mean[1]
    
    C00 = conic_and_rescale[0]
    C01 = conic_and_rescale[1]
    C11 = conic_and_rescale[2]
    R = conic_and_rescale[3]
    
    exponent = -0.5 * (dx * dx * C00 + dy * dy * C11 + 2.0 * dx * dy * C01)
    
    return math.exp(exponent) * R
```

### Single Point Alpha Forward
Computes the alpha value for a single 3D Gaussian projected onto a 2D pixel [S1, unofficial]. It transforms the Gaussian to camera space, computes the 2D covariance, projects it to screen space, and evaluates the 2D Gaussian PDF at the pixel center [S1, unofficial]. This is the complete forward pass for a single splat's contribution to a pixel's opacity [S1, unofficial].

**Steps:**
1. Homogenize point position: $xyz1 = [xyz, 1]$ [S1, unofficial].
2. Transform to camera space: $xyz1_{camera} = T_{camera} \cdot xyz1$ [S1, unofficial].
3. Extract camera coordinates $xyz_{camera}$ [S1, unofficial].
4. Project to UV: $uv1 = K \cdot xyz_{camera}$, $uv = uv1_{0:2} / uv1_2$ [S1, unofficial].
5. Compute scale matrix $S = \text{diag}(\exp(s))$ [S1, unofficial].
6. Compute rotation matrix $R$ from quaternion $q$ [S1, unofficial].
7. Compute 3D covariance $\Sigma = R S S R^T$ [S1, unofficial].
8. Compute Jacobian $J$ of projection [S1, unofficial].
9. Compute 2D covariance $cov = J W \Sigma W^T J^T$, where $W$ is the rotation part of $T_{camera}$ [S1, unofficial].
10. Compute probability density $p = \exp(-0.5 (uv_{center} - uv)^T cov^{-1} (uv_{center} - uv))$ [S1, unofficial].
11. Compute alpha: $\alpha = \sigma(\text{point\_alpha}) \cdot p$ [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation, involving a constant number of arithmetic operations (matrix-vector multiplications, exponentiation) [S1, unofficial].
- **Memory Complexity:** $O(1)$, requiring storage for the mean, covariance, and intermediate vectors [S1, unofficial].
- **Performance:** Efficient for CPU and GPU execution. The conic variant is faster as it avoids matrix inversion and square roots [S1, unofficial].
- **Strengths:** Mathematically rigorous, provides normalized probabilities suitable for probabilistic interpretations [S1, unofficial].
- **Limitations:** Requires matrix inversion, which is more expensive than the conic method [S1, unofficial]. Sensitive to singular covariance matrices [G].
- **When to use:** When normalized probabilities are required or when debugging/analyzing the Gaussian distribution properties [S1, unofficial].
- **When not to use:** In high-performance rendering pipelines where the conic variant is preferred for speed [S1, unofficial].

## Background
Originated from the mathematical definition of the 2D Gaussian distribution, widely used in computer graphics for EWA (Elliptical Weighted Average) splatting and Gaussian Splatting rendering techniques [S1, unofficial]. The specific implementation details are derived from the `taichi_3d_gaussian_splatting` repository [S1, unofficial].
