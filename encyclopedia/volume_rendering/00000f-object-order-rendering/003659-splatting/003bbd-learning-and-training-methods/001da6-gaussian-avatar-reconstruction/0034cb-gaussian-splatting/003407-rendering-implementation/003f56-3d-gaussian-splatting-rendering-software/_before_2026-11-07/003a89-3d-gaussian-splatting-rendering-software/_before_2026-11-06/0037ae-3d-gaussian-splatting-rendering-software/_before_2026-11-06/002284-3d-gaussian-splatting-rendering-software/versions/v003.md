# 3D Gaussian Splatting Rendering (Software)

Also called: 3D Gaussian Splatting (3D-GS) Projection, Gaussian Splatting Rendering (Software), GaussianSplatPipeline01, GaussianSplatPipeline02, Local Affine Approximation, Standard 3D-GS Projection

## Overview
This method renders a scene represented as a collection of 3D Gaussians to a 2D image buffer by projecting each Gaussian onto the image plane ($z=1$) using a local affine approximation of the projective transformation [S2]. It computes a 2D covariance matrix for each Gaussian and rasterizes the resulting ellipses [S1, unofficial]. Unlike production renderers that use tile-based CUDA rasterization, spherical harmonics, or adaptive density control, this software implementation serves as a foundational reference for the underlying mathematical projection and rasterization pipeline [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A list of $N$ 3D Gaussians defined by their parameters (position, rotation, scale, opacity, and spherical harmonic coefficients) and a camera model (view and projection matrices) [S1, unofficial].
*   **Output:** A 2D image buffer containing the accumulated color and opacity values for each pixel [S1, unofficial].

**Data Structures:**
The Gaussian data is stored in a struct `GaussianData` with the following fields [S1, unofficial]:
*   `xyz`: `np.ndarray`, `float32`, shape `[N, 3]` — World space positions.
*   `rot`: `np.ndarray`, `float32`, shape `[N, 4]` — Quaternions representing rotation.
*   `scale`: `np.ndarray`, `float32`, shape `[N, 3]` — Log-space scales (exponentiated during preprocessing).
*   `opacity`: `np.ndarray`, `float32`, shape `[N, 1]` — Log-space opacities (sigmoided during preprocessing).
*   `sh`: `np.ndarray`, `float32`, shape `[N, SH_dim]` — Concatenated spherical harmonic coefficients.

The vertex shader output for each Gaussian consists of a tuple [S1, unofficial]:
*   `gl_position`: `Vector4<f32>` — Clip-space position.
*   `conic`: `Vector3<f32>` — Packed inverse 2D covariance matrix containing `cov2d_inv[(0,0)]`, `cov2d_inv[(0,1)]`, and `cov2d_inv[(1,1)]` [S1, unofficial].
*   `coordxy`: `Vector2<f32>` — Screen-space center coordinates.

**Preprocessing:**
Before rendering, the Gaussian parameters must be normalized from their stored format [S1, unofficial]:
1.  **Normalize Rotations:** $rots = rots / \|rots\|_{axis=-1, keepdims=True}$ [S1, unofficial].
2.  **Exponentiate Scales:** $scales = \exp(scales)$ [S1, unofficial].
3.  **Sigmoid Opacities:** $opacities = 1 / (1 + \exp(-opacities))$ [S1, unofficial].
4.  **Concatenate SH Coefficients:** $shs = \text{concat}([features\_dc.reshape(-1, 3), features\_extra.reshape(len(features\_dc), -1)], axis=-1)$ [S1, unofficial].

**Projection and Rasterization Steps:**
For each Gaussian $i$ in the list:

1.  **Compute 3D Covariance:** Construct the 3D covariance matrix $\Sigma_{3D}$ from the rotation quaternion $q$ and scale vector $s$. The rotation matrix $R$ is derived from $q$, and $\Sigma_{3D} = R \cdot \text{diag}(s^2) \cdot R^T$ [S1, unofficial].
2.  **Transform to Camera Space:** Apply the viewing transformation matrix $W$ to transform the Gaussian mean $\mu$ and covariance $\Sigma_{3D}$ to camera space [S2]:
    $$ \mu' = W\mu $$
    $$ \Sigma' = W\Sigma_{3D}W^T $$
3.  **Local Affine Approximation:** Project the Gaussian from camera space to the image plane ($z=1$) using the projection function $\phi(\mathbf{x}') = \mathbf{x}' (\mathbf{x}_0^\top \mathbf{x}')^{-1}$, where $\mathbf{x}_0 = [0, 0, 1]^\top$ [S2]. Since Gaussians are not closed under projective transformations, 3D-GS uses a local affine approximation via the Jacobian $J = \frac{\partial \phi}{\partial \mathbf{x}'}$ evaluated at $\mu'$ [S2].
4.  **Compute 2D Covariance:** Calculate the 2D covariance matrix $\Sigma_{2D}$ in the image space [S2]:
    $$ \Sigma_{2D} = J\Sigma'J^T $$
    Note: The matrix $J$ has rank 2. The inverse of $\Sigma_{2D}$ is effectively the inverse of the $2 \times 2$ covariance matrix obtained by skipping the third row and column of the full projected covariance [S2].
5.  **Compute Screen Position:** The 2D mean is $\mu_{2D} = \phi(\mu')$ [S2]. Convert $\mu_{2D}$ to screen coordinates $(u, v)$ [G].
6.  **Compute Conic Matrix:** Invert the $2 \times 2$ $\Sigma_{2D}$ to get $\Sigma_{2D}^{-1}$ [S1, unofficial]. Pack the upper triangle into the `conic` vector:
    $$ \text{conic} = [\Sigma_{2D}^{-1}[0,0], \Sigma_{2D}^{-1}[0,1], \Sigma_{2D}^{-1}[1,1]] $$
7.  **Determine Bounding Box:** Calculate the bounding box size for the Gaussian in screen space. The multiplier is 3.0, representing the 3-sigma extent [S1, unofficial]:
    $$ \text{bboxsize\_cam} = [3.0 \sqrt{\Sigma_{2D}[0,0]}, 3.0 \sqrt{\Sigma_{2D}[1,1]}] $$
    Convert to NDC and then to pixel coordinates using the camera width $w$ and height $h$:
    $$ \text{bboxsize\_ndc} = \frac{\text{bboxsize\_cam}}{[w, h]} \times 2.0 $$
    The bounding box in pixels is centered at $(u, v)$ with dimensions derived from `bboxsize_ndc` [S1, unofficial].
8.  **Rasterization:** For each pixel $(u, v)$ within the bounding box, evaluate the 2D Gaussian value [S2]:
    $$ G_{2D}(x_{2D}) = \exp \left( -\frac{1}{2} (x_{2D} - \mu_{2D})^\top \Sigma_{2D}^{-1} (x_{2D} - \mu_{2D}) \right) $$
    where $x_{2D} = [u, v]^\top$. Perform alpha blending with the existing pixel color and opacity using the Gaussian's opacity and the computed $G_{2D}$ value [S2].

**Pseudocode:**
```python
import numpy as np

def render_gaussians(gaussians, camera):
    """
    Render a list of 3D Gaussians to a 2D image buffer.
    
    Args:
        gaussians: List of dicts with keys 'xyz', 'rot', 'scale', 'opacity', 'sh'.
        camera: Object with methods get_view_matrix(), and attributes w, h.
    
    Returns:
        image: np.ndarray of shape (H, W, 3)
        alpha: np.ndarray of shape (H, W)
    """
    H, W = camera.h, camera.w
    image = np.zeros((H, W, 3), dtype=np.float32)
    alpha = np.zeros((H, W), dtype=np.float32)
    
    view_mat = camera.get_view_matrix()
    W_linear = view_mat[:3, :3]
    
    N = len(gaussians)
    xyz = np.array([g['xyz'] for g in gaussians], dtype=np.float32)
    rot = np.array([g['rot'] for g in gaussians], dtype=np.float32)
    scale = np.array([g['scale'] for g in gaussians], dtype=np.float32)
    opacity = np.array([g['opacity'] for g in gaussians], dtype=np.float32)
    sh = np.array([g['sh'] for g in gaussians], dtype=np.float32)
    
    # Preprocessing
    rot = rot / np.linalg.norm(rot, axis=-1, keepdims=True)
    scale = np.exp(scale)
    opacity = 1.0 / (1.0 + np.exp(-opacity))
    
    # Compute 3D Covariance
    def quat_to_rot(q):
        w, x, y, z = q[:, 0], q[:, 1], q[:, 2], q[:, 3]
        R = np.zeros((N, 3, 3))
        R[:, 0, 0] = 1 - 2*(y**2 + z**2)
        R[:, 0, 1] = 2*(x*y - w*z)
        R[:, 0, 2] = 2*(x*z + w*y)
        R[:, 1, 0] = 2*(x*y + w*z)
        R[:, 1, 1] = 1 - 2*(x**2 + z**2)
        R[:, 1, 2] = 2*(y*z - w*x)
        R[:, 2, 0] = 2*(x*z - w*y)
        R[:, 2, 1] = 2*(y*z + w*x)
        R[:, 2, 2] = 1 - 2*(x**2 + y**2)
        return R
    
    R_mat = quat_to_rot(rot)
    cov3d = np.zeros((N, 3, 3))
    for i in range(N):
        cov3d[i] = R_mat[i] @ np.diag(scale[i]**2) @ R_mat[i].T
        
    # Transform to Camera Space
    xyz_h = np.hstack([xyz, np.ones((N, 1))])
    xyz_cam = (view_mat @ xyz_h.T).T[:, :3]
    cov3d_cam = np.zeros((N, 3, 3))
    for i in range(N):
        cov3d_cam[i] = W_linear @ cov3d[i] @ W_linear.T
        
    # Project to 2D
    z_cam = xyz_cam[:, 2]
    x_cam = xyz_cam[:, 0]
    y_cam = xyz_cam[:, 1]
    z_safe = np.maximum(z_cam, 1e-6)
    
    J = np.zeros((N, 2, 3))
    J[:, 0, 0] = 1.0 / z_safe
    J[:, 0, 2] = -x_cam / (z_safe**2)
    J[:, 1, 1] = 1.0 / z_safe
    J[:, 1, 2] = -y_cam / (z_safe**2)
    
    cov2d = np.zeros((N, 2, 2))
    for i in range(N):
        cov2d[i] = J[i] @ cov3d_cam[i] @ J[i].T
        
    # Invert 2D Covariance
    det = cov2d[:, 0, 0] * cov2d[:, 1, 1] - cov2d[:, 0, 1] * cov2d[:, 1, 0]
    safe_det = np.where(np.abs(det) > 1e-6, det, 1e-6)
    cov2d_inv = np.zeros((N, 2, 2))
    cov2d_inv[:, 0, 0] = cov2d[:, 1, 1] / safe_det
    cov2d_inv[:, 0, 1] = -cov2d[:, 0, 1] / safe_det
    cov2d_inv[:, 1, 0] = -cov2d[:, 1, 0] / safe_det
    cov2d_inv[:, 1, 1] = cov2d[:, 0, 0] / safe_det
    
    # Screen Coordinates
    u_ndc = x_cam / z_safe
    v_ndc = y_cam / z_safe
    u_pix = (u_ndc + 1.0) * 0.5 * W
    v_pix = (1.0 - v_ndc) * 0.5 * H
    
    # Bounding Box
    bboxsize_cam = np.stack([3.0 * np.sqrt(np.abs(cov2d[:, 0, 0])), 3.0 * np.sqrt(np.abs(cov2d[:, 1, 1]))], axis=-1)
    bboxsize_ndc = bboxsize_cam / np.array([W, H]) * 2.0
    bboxsize_pix = (bboxsize_ndc + 1.0) * 0.5 * np.array([W, H])
    bbox_x = bboxsize_pix[:, 0]
    bbox_y = bboxsize_pix[:, 1]
    
    # Rasterization
    for i in range(N):
        cx, cy = u_pix[i], v_pix[i]
        cov_inv = cov2d_inv[i]
        op = opacity[i, 0]
        color = sh[i, :3]
        
        min_x = max(0, int(cx - bbox_x[i]))
        max_x = min(W, int(cx + bbox_x[i]))
        min_y = max(0, int(cy - bbox_y[i]))
        max_y = min(H, int(cy + bbox_y[i]))
        
        for y in range(min_y, max_y):
            for x in range(min_x, max_x):
                dx = x - cx
                dy = y - cy
                exponent = -0.5 * np.dot([dx, dy], cov_inv @ [dx, dy])
                val = np.exp(exponent)
                alpha_val = op * val
                
                current_alpha = alpha[y, x]
                current_color = image[y, x]
                
                new_alpha = current_alpha + alpha_val * (1.0 - current_alpha)
                if new_alpha > 1e-6:
                    image[y, x] = (current_color * current_alpha + color * alpha_val * (1.0 - current_alpha)) / new_alpha
                    alpha[y, x] = new_alpha
                    
    return image, alpha
```

## Subtopics

### [3D Gaussian Splatting MVP](3410-3d-gaussian-splatting-mvp.md)
3D Gaussian Splatting MVP is a self-contained, pure-PyTorch implementation of the core 3D Gaussian Splatting algorithm. It renders a list of 3D Gaussians to a 2D buffer by projecting them to screen space, computing a 2D covariance matrix, and rasterizing the resulting ellipses. Unlike production renderers, it intentionally skips tile-based CUDA rasterization, spherical harmonics, and adaptive density control, serving instead as a teaching reference for the underlying mathematics.

### Perspective-Correct 3D Gaussian Splat Evaluation
A differentiable method for evaluating 3D Gaussians along per-pixel viewing rays that avoids matrix inversion, ensuring numerical stability and eliminating special handling for degenerate splats [S3]. It performs evaluation without matrix inversions to ensure stability [S3]. Unlike the affine approximation used in standard 3D-GS, which causes perspective distortion artifacts at close distances, this method provides fully perspective-correct rendering [S3]. Unlike ray-tracing frameworks which calculate intersection points with per-pixel viewing rays but have significantly lower rendering speeds, this method is implemented within a rasterization-based pipeline for real-time performance [S3].

## Operating characteristics
**Time and Memory Complexity:**
The projection step is $O(N)$ for $N$ Gaussians [G]. The rasterization step is $O(N \cdot B)$ where $B$ is the average bounding box area in pixels [G]. Memory complexity is $O(N)$ to store Gaussian parameters and $O(W \cdot H)$ for the image buffer [G].

**Measured Performance:**
Performance depends heavily on the rasterization backend [S1, unofficial]. The software implementation described here is significantly slower than GPU-accelerated versions due to the lack of parallelization and tile-based optimization [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Simple to implement and understand; serves as a good reference for the mathematical projection steps; no external dependencies beyond basic linear algebra [S1, unofficial].
*   **Limitations:** Slow performance due to software rasterization; uses local affine approximation which introduces perspective distortion artifacts, especially at close distances or wide angles [S2]; requires special handling for degenerate splats if matrix inversion fails (though the software renderer assumes invertibility) [S1, unofficial].

**When to Use:**
Use this method for educational purposes, prototyping, or when a GPU-accelerated solution is not available [S1, unofficial]. It is not suitable for production real-time rendering due to performance limitations [S1, unofficial].

## Background
3D Gaussian Splatting represents scenes with 3D Gaussians and projects them onto the image plane ($z=1$) using a local affine approximation of the projective transformation to achieve real-time rasterization [S2]. Given a set of images with the camera parameters calibrated by SfM, the method optimizes a set of 3D Gaussians as graphical primitives to explicitly represent the scene [S2].
