# 3D/2D Hybrid Gaussian Rasterization with Fallback Sigma

Also called: Hybrid Sigma Rasterization, Fallback Sigma Gaussian Rasterization

## Overview
This method renders 3D Gaussians by combining a 3D ray-surfel distance metric with a 2D screen-space fallback to determine the effective spread (sigma) of each Gaussian splat. It solves the problem of inaccurate alpha estimation when Gaussians are viewed at extreme angles or distances, where the standard 2D covariance approximation may fail or become numerically unstable. It sets itself apart from standard differentiable rasterizers by explicitly computing a tighter bound using both 3D geometric depth and 2D pixel offsets, ensuring robust alpha culling and compositing [S1, unofficial].

## How it works
**Inputs:**
- `means`: 3D Gaussian centers, shape $(N, 3)$.
- `quats`: Gaussian rotations (quaternions), shape $(N, 4)$.
- `scales`: Gaussian scales, shape $(N, 3)$.
- `opacities`: Gaussian opacities, shape $(N)$.
- `sh_coeffs`: Spherical harmonic coefficients (SH degree 0 assumed for base color), shape $(N, 1, 3)$.
- `cameras`: Camera parameters including intrinsic matrix $K$ and view matrix $V$ for each camera $c$.
- `width`, `height`: Image dimensions.
- `MAX_ALPHA`: Maximum alpha value for clamping (e.g., 0.99).
- `ALPHA_THRESHOLD`: Alpha threshold for culling (e.g., 0.01).
- `TRANSMITTANCE_THRESHOLD`: Transmittance threshold to stop compositing (e.g., 0.001).
- `backgrounds`: Optional background color per camera, shape $(C, 3)$.

**Outputs:**
- `render_colors`: Rendered RGB images, shape $(C, H, W, 3)$.
- `render_normals`: Rendered normal images, shape $(C, H, W, 3)$.
- `render_alphas`: Rendered alpha images, shape $(C, H, W, 1)$.

**Data Structures:**
- `means2d_np`: Pre-computed 2D screen-space means for each Gaussian and camera, shape $(C, N, 2)$.
- `colors_np`: Pre-computed colors for each Gaussian and camera, shape $(C, N, 3)$.
- `normals_np`: Pre-computed normals for each Gaussian and camera, shape $(C, N, 3)$.
- `opacities_np`: Opacities broadcasted to $(C, N)$.

**Steps:**
1.  **Initialization**: Initialize `render_colors`, `render_normals` to zeros. Initialize `render_alphas` to zeros. Initialize transmittance $T = 1.0$ for each pixel.
2.  **Pixel Loop**: Iterate over each pixel $(py, px)$ and each camera $c$.
3.  **Gaussian Loop**: Iterate through all Gaussians $gid$.
    a.  **Projection**: Calculate temporary coordinates $tmp[0], tmp[1], tmp[2]$ by projecting the 3D mean of Gaussian $gid$ using the camera's view and projection matrices.
    b.  **Depth Check**: If $|tmp[2]| < 10^{-10}$, skip this Gaussian [S1, unofficial].
    c.  **Screen Coordinates**: Calculate screen-space coordinates $u_s = tmp[0] / tmp[2]$ and $v_s = tmp[1] / tmp[2]$.
    d.  **3D Sigma**: Calculate 3D sigma from ray-surfel intersection: $\sigma_{3d} = u_s^2 + v_s^2$ [S1, unofficial].
    e.  **2D Fallback Sigma**: Calculate 2D fallback sigma using pre-computed 2D means $\mu = \text{means2d\_np}[c, gid]$. Calculate $dx = px_f - \mu[0]$ and $dy = py_f - \mu[1]$. Then $\sigma_{2d} = 2.0 \cdot (dx^2 + dy^2)$ [S1, unofficial].
    f.  **Hybrid Sigma**: Take the tighter bound: $\sigma = 0.5 \cdot \min(\sigma_{3d}, \sigma_{2d})$ [S1, unofficial].
    g.  **Negative Sigma Check**: If $\sigma < 0.0$, skip the Gaussian [S1, unofficial].
    h.  **Alpha Calculation**: Calculate $\alpha = \min(\text{opacities\_np}[c, gid] \cdot \exp(-\sigma), \text{MAX\_ALPHA})$ [S1, unofficial].
    i.  **Alpha Threshold Check**: If $\alpha < \text{ALPHA\_THRESHOLD}$, skip the Gaussian [S1, unofficial].
    j.  **Transmittance Check**: If current transmittance $T < \text{TRANSMITTANCE\_THRESHOLD}$, break the Gaussian loop [S1, unofficial].
    k.  **Compositing**: Calculate weight $w = T \cdot \alpha$. Add $w \cdot \text{colors\_np}[c, gid]$ to `render_colors[c, py, px]`. Add $w \cdot \text{normals\_np}[c, gid]$ to `render_normals[c, py, px]`. Update $T \leftarrow T \cdot (1.0 - \alpha)$ [S1, unofficial].
4.  **Alpha Finalization**: After the Gaussian loop, set `render_alphas[c, py, px, 0] = 1.0 - T` [S1, unofficial].
5.  **Background Addition**: If `backgrounds` is not None, convert to numpy array `bg_np`. For each camera $c$, add $(1.0 - \text{render\_alphas}[c]) \cdot \text{bg\_np}[c]$ to `render_colors[c]` [S1, unofficial].

**Pseudocode:**
```python
def hybrid_gaussian_rasterization(means, quats, scales, opacities, sh_coeffs, cameras, width, height, MAX_ALPHA=0.99, ALPHA_THRESHOLD=0.01, TRANSMITTANCE_THRESHOLD=0.001, backgrounds=None):
    # Pre-compute 2D means, colors, normals for all cameras and Gaussians
    # This step is assumed to be done externally or in a previous pass
    means2d_np = precompute_means2d(means, quats, scales, cameras)
    colors_np = precompute_colors(sh_coeffs, cameras)
    normals_np = precompute_normals(quats, cameras)
    opacities_np = broadcast_opacities(opacities, cameras)
    
    C = len(cameras)
    render_colors = np.zeros((C, height, width, 3))
    render_normals = np.zeros((C, height, width, 3))
    render_alphas = np.zeros((C, height, width, 1))
    
    for c in range(C):
        for py in range(height):
            for px in range(width):
                T = 1.0
                for gid in range(len(means)):
                    # Project 3D mean to screen space
                    tmp = project_3d_to_screen(means[gid], cameras[c])
                    
                    # Depth check
                    if abs(tmp[2]) < 1e-10:
                        continue
                    
                    # Screen coordinates
                    us = tmp[0] / tmp[2]
                    vs = tmp[1] / tmp[2]
                    
                    # 3D Sigma
                    sigma_3d = us * us + vs * vs
                    
                    # 2D Fallback Sigma
                    mu = means2d_np[c, gid]
                    dx = px - mu[0]
                    dy = py - mu[1]
                    sigma_2d = 2.0 * (dx * dx + dy * dy)
                    
                    # Hybrid Sigma
                    sigma = 0.5 * min(sigma_3d, sigma_2d)
                    
                    # Negative Sigma Check
                    if sigma < 0.0:
                        continue
                    
                    # Alpha Calculation
                    alpha = min(opacities_np[c, gid] * exp(-sigma), MAX_ALPHA)
                    
                    # Alpha Threshold Check
                    if alpha < ALPHA_THRESHOLD:
                        continue
                    
                    # Transmittance Check
                    if T < TRANSMITTANCE_THRESHOLD:
                        break
                    
                    # Compositing
                    weight = T * alpha
                    render_colors[c, py, px] += weight * colors_np[c, gid]
                    render_normals[c, py, px] += weight * normals_np[c, gid]
                    T *= (1.0 - alpha)
                
                render_alphas[c, py, px, 0] = 1.0 - T
    
    # Background Addition
    if backgrounds is not None:
        bg_np = np.array(backgrounds)
        for c in range(C):
            render_colors[c] += (1.0 - render_alphas[c, :, :, 0]) * bg_np[c]
            
    return render_colors, render_normals, render_alphas
```

**Parameters:**
- `MAX_ALPHA`: Typically 0.99. Prevents numerical instability in transmittance updates [S1, unofficial].
- `ALPHA_THRESHOLD`: Typically 0.01. Culls Gaussians with negligible contribution [S1, unofficial].
- `TRANSMITTANCE_THRESHOLD`: Typically 0.001. Stops compositing when the pixel is effectively opaque [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision**: Division by $tmp[2]$ can cause instability if $tmp[2]$ is very small. The check $|tmp[2]| < 10^{-10}$ handles this [S1, unofficial].
- **Boundaries**: Pixel coordinates $(px, py)$ are integer indices. The 2D fallback sigma uses floating-point offsets from the pre-computed 2D mean, which may be sub-pixel.
- **Degenerate Input**: If a Gaussian is behind the camera or has zero scale, the projection or sigma calculation may fail. The depth check and negative sigma check handle these cases [S1, unofficial].

## Subtopics

## Operating characteristics
- **Time Complexity**: $O(C \cdot H \cdot W \cdot N)$ in the worst case, where $C$ is the number of cameras, $H \times W$ is the resolution, and $N$ is the number of Gaussians. However, alpha and transmittance thresholds provide significant culling, reducing the average case complexity.
- **Memory Complexity**: $O(C \cdot N)$ for pre-computed 2D means, colors, and normals. Output buffers are $O(C \cdot H \cdot W)$.
- **Measured Performance**: Not given in the sources.
- **Scaling**: Performance scales linearly with the number of Gaussians and pixels, but culling mechanisms mitigate this.
- **Strengths**: Robust alpha estimation under extreme viewing angles; efficient culling via hybrid sigma.
- **Limitations**: Requires pre-computation of 2D means and colors; more complex than standard 2D covariance rasterization.
- **When to use**: When rendering Gaussians at extreme angles or distances where standard 2D approximations fail.
- **When not to use**: When computational resources are extremely limited and standard rasterization suffices.

## Background
This method is derived from the `gsplat-mlx` implementation by RobotFlow-Labs, which provides an unofficial implementation of Gaussian Splatting for the MLX framework [S1, unofficial]. It extends the standard differentiable rasterizer by incorporating a hybrid sigma calculation to improve rendering quality and stability.
