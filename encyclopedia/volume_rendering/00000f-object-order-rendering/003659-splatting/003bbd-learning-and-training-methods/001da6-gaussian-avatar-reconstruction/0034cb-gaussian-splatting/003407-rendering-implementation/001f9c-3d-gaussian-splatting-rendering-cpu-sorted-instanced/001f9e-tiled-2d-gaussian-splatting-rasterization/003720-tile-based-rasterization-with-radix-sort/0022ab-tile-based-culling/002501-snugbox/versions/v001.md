# SnugBox

Also called: Tight Bounding Box, Elliptical Bounding Box

## Overview
SnugBox is a precise algorithm for computing Gaussian-to-tile bounding box intersections in 3D Gaussian Splatting, replacing the overly conservative tile assignment of standard 3D-GS to reduce the number of pixels processed per Gaussian [S1]. It computes an axis-aligned bounding box (AABB) around each Gaussian using its elliptical extent in image space, allowing for tighter identification of intersected tiles compared to the standard method which inscribes a circle within a square [S1, S2].

## How it works
**Inputs:**
*   3D Gaussian parameters: mean $\mu_i$, scale $s_i$, rotation $r_i$, opacity $\sigma_i$.
*   Camera parameters: viewing transform $W$, perspective projection.
*   Image resolution and tile size.

**Outputs:**
*   Tile indices $[x_{min}, x_{max}] \times [y_{min}, y_{max}]$ representing the tight AABB intersecting the Gaussian's elliptical extent.

**Data Structures:**
*   $\Sigma_{i_{3D}}$: 3x3 3D covariance matrix.
*   $\Sigma_{i_{2D}}$: 2x2 2D projected covariance matrix.
*   $\Sigma_{i_{2D}}^{-1}$: Inverse of the 2D covariance matrix, represented as $\begin{pmatrix} a & b \\ b & c \end{pmatrix}$.
*   $t$: Threshold value derived from opacity.

**Steps:**

1.  **Project Covariance:** Compute the 2D covariance matrix $\Sigma_{i_{2D}}$ from the 3D covariance $\Sigma_{i_{3D}}$.
    *   Compute the 3D covariance: $\Sigma_{i_{3D}} = R_i S_i S_i^T R_i^T$, where $S_i$ and $R_i$ are diagonal scale and rotation matrices derived from $s_i$ and $r_i$ [S1].
    *   Project to 2D: $\hat{\Sigma}_{i_{3D}} = J W \Sigma_{i_{3D}} W^T J^T$, where $J$ is the Jacobian of the first-order approximation of the perspective projection and $W$ is the viewing transform [S1].
    *   Extract 2D covariance: Drop the last row and column of $\hat{\Sigma}_{i_{3D}}$ to obtain $\Sigma_{i_{2D}}$ [S1].

2.  **Compute Inverse and Threshold:**
    *   Compute the inverse of the 2D covariance matrix: $\Sigma_{i_{2D}}^{-1} = \begin{pmatrix} a & b \\ b & c \end{pmatrix}$ [S1].
    *   Compute the threshold $t$ based on the Gaussian's opacity $\sigma_i$: $t = 2 \log(255 \sigma_i)$ [S1].

3.  **Compute Extrema:**
    *   The pixel extent is defined by the ellipse equation: $t = ax_d^2 + 2bx_dy_d + cy_d^2$, where $x_d = p_x - \mu_x$ and $y_d = p_y - \mu_y$ are coordinates relative to the 2D mean $\mu_{i_{2D}}$ [S1].
    *   Rearrange to solve for $y_d$:
        $$y_d = \frac{-bx_d \pm \sqrt{(b^2 - ac)x_d^2 + tc}}{c} \quad (15)$$
    *   Find the $x_d$ values ($x_{d_{args}}$) where $\partial y_d / \partial x_d = 0$ (the extrema of $y_d$):
        $$x_{d_{args}} = \pm \sqrt{\frac{-b^2 t}{(b^2 - ac)a}} \quad (16)$$
    *   Calculate $y_{min}$ and $y_{max}$ by substituting $x_{d_{args}}$ into Equation 15 and adding $\mu_y$ [S1].
    *   Calculate $x_{min}$ and $x_{max}$ by swapping $y_d$ and $x_d$ and constants $a$ and $c$ in Equations 15 and 16, solving for $y_{d_{args}}$, and adding $\mu_x$ [S1].

4.  **Map to Tiles:**
    *   Convert bounding box edges to tile indices by dividing by tile size, rounding, and clipping to the image boundary [S1].

**Pseudocode:**

```python
import math

def compute_snugbox(gaussian, camera, tile_size, image_width, image_height):
    """
    Computes the tight AABB tile indices for a Gaussian.
    
    Args:
        gaussian: Object with attributes .mu_3d (3,), .scale (3,), .rot (4,), .opacity (float)
        camera: Object with attributes .W (3x3 matrix), .project (function)
        tile_size: int, size of a tile in pixels
        image_width: int
        image_height: int
        
    Returns:
        (x_min, x_max, y_min, y_max): Tile indices
    """
    # 1. Project Covariance
    # Compute 3D covariance Sigma_3D = R * S * S^T * R^T
    # Note: R and S are derived from rotation quaternion and scale vector
    R = quaternion_to_rotation_matrix(gaussian.rot)
    S = diagonal_matrix(gaussian.scale)
    Sigma_3D = R @ (S @ S.T) @ R.T
    
    # Project to 2D: Sigma_hat_3D = J * W * Sigma_3D * W^T * J^T
    # W is the viewing transform (camera to world inverse or similar, as per source)
    # J is the Jacobian of the perspective projection
    # For implementation, assume camera provides a function to get 2D mean and projected covariance
    mu_2d, Sigma_2D = project_covariance(Sigma_3D, gaussian.mu_3d, camera.W, camera.J)
    
    # 2. Compute Inverse and Threshold
    # Sigma_2D_inv = [[a, b], [b, c]]
    Sigma_2D_inv = inverse_2x2(Sigma_2D)
    a, b, c = Sigma_2D_inv[0][0], Sigma_2D_inv[0][1], Sigma_2D_inv[1][1]
    
    t = 2.0 * math.log(255.0 * gaussian.opacity)
    
    # 3. Compute Extrema
    # Calculate x_d_args
    # x_d_args = +/- sqrt( (-b^2 * t) / ((b^2 - a*c) * a) )
    denominator_x = (b**2 - a*c) * a
    if denominator_x == 0:
        # Handle degenerate case, e.g., return minimal box or handle error
        # [G] Guard against division by zero. In practice, ensure epsilon for stability.
        return (0, 0, 0, 0)
        
    radicand_x = (-b**2 * t) / denominator_x
    if radicand_x < 0:
        # [G] Numerical noise might make radicand slightly negative. Clamp to 0.
        radicand_x = 0
        
    x_d_args = math.sqrt(radicand_x)
    
    # Calculate y_d for x_d_args using Equation 15
    # y_d = (-b*x_d +/- sqrt((b^2 - a*c)*x_d^2 + t*c)) / c
    # We need min and max y_d. The +/- gives two values.
    # Note: Equation 15 solves for y_d given x_d.
    
    def get_y_d(x_d_val):
        term_inside_sqrt = (b**2 - a*c) * (x_d_val**2) + t*c
        if term_inside_sqrt < 0:
            term_inside_sqrt = 0
        sqrt_val = math.sqrt(term_inside_sqrt)
        y_d1 = (-b * x_d_val + sqrt_val) / c
        y_d2 = (-b * x_d_val - sqrt_val) / c
        return min(y_d1, y_d2), max(y_d1, y_d2)

    y_d_min_val, y_d_max_val = get_y_d(x_d_args)
    
    # y_min and y_max in pixel coordinates
    y_min_px = mu_2d[1] + y_d_min_val
    y_max_px = mu_2d[1] + y_d_max_val
    
    # Calculate x_min and x_max by swapping roles
    # Swap y_d and x_d, and a and c
    # New equation for x_d in terms of y_d: t = c*y_d^2 + 2b*y_d*x_d + a*x_d^2
    # This is symmetric. We solve for x_d extrema w.r.t y_d.
    # x_d_args_y = +/- sqrt( (-b^2 * t) / ((b^2 - c*a) * c) )
    denominator_y = (b**2 - c*a) * c
    if denominator_y == 0:
        return (0, 0, 0, 0)
        
    radicand_y = (-b**2 * t) / denominator_y
    if radicand_y < 0:
        radicand_y = 0
        
    y_d_args = math.sqrt(radicand_y)
    
    def get_x_d(y_d_val):
        term_inside_sqrt = (b**2 - c*a) * (y_d_val**2) + t*a
        if term_inside_sqrt < 0:
            term_inside_sqrt = 0
        sqrt_val = math.sqrt(term_inside_sqrt)
        # Solving a*x^2 + 2b*y*x + (c*y^2 - t) = 0 for x
        # x = (-2b*y +/- sqrt(4b^2y^2 - 4a(cy^2 - t))) / 2a
        # x = (-b*y +/- sqrt(b^2y^2 - a(cy^2 - t))) / a
        # Note: b^2y^2 - a(cy^2 - t) = (b^2 - ac)y^2 + at
        sqrt_val_inner = (b**2 - c*a) * (y_d_val**2) + t*a
        if sqrt_val_inner < 0:
            sqrt_val_inner = 0
        sqrt_val = math.sqrt(sqrt_val_inner)
        x_d1 = (-b * y_d_val + sqrt_val) / a
        x_d2 = (-b * y_d_val - sqrt_val) / a
        return min(x_d1, x_d2), max(x_d1, x_d2)

    x_d_min_val, x_d_max_val = get_x_d(y_d_args)
    
    x_min_px = mu_2d[0] + x_d_min_val
    x_max_px = mu_2d[0] + x_d_max_val
    
    # 4. Map to Tiles
    x_min_tile = int(math.floor(x_min_px / tile_size))
    x_max_tile = int(math.ceil(x_max_px / tile_size))
    y_min_tile = int(math.floor(y_min_px / tile_size))
    y_max_tile = int(math.ceil(y_max_px / tile_size))
    
    # Clip to image boundary
    x_min_tile = max(0, min(x_min_tile, image_width // tile_size))
    x_max_tile = max(0, min(x_max_tile, image_width // tile_size))
    y_min_tile = max(0, min(y_min_tile, image_height // tile_size))
    y_max_tile = max(0, min(y_max_tile, image_height // tile_size))
    
    return (x_min_tile, x_max_tile, y_min_tile, y_max_tile)
```

**Edge Cases and Pitfalls:**
*   **Singular Covariance:** If the determinant of $\Sigma_{i_{2D}}$ is zero (degenerate Gaussian), the inverse is undefined. A guard should handle this, potentially returning a minimal bounding box or skipping the Gaussian [G].
*   **Numerical Stability:** The term under the square root in Equation 16 and the y-d calculation must be non-negative. Numerical errors may cause slight negative values; these should be clamped to zero [G].
*   **Division by Zero:** The denominators in Equation 16 and the x-d calculation involve $a$ and $c$. If these are zero, the formula breaks. This corresponds to axis-aligned ellipses with infinite extent in one direction, which is physically unlikely for a valid Gaussian but possible in degenerate cases [G].

## Operating characteristics
*   **Time Complexity:** Constant number of operations per Gaussian. It is called twice in the rendering pipeline: once during preprocessing to count Gaussians per tile, and once in `duplicateWithKeys` to populate the Gaussian-to-tile arrays [S1].
*   **Memory Complexity:** No additional significant memory overhead beyond the computed bounding box indices [S1].
*   **Performance:** Produces an average overall inference speed-up of 1.82× on Mip-NeRF 360, Tanks & Temples, and Deep Blending datasets compared to baseline 3D-GS [S1].
*   **Strengths:** Significantly tighter bounding boxes than the standard 3D-GS method, reducing the number of tiles processed per Gaussian [S1].
*   **Limitations:** More complex than the standard square-inscribing-circle method, though the overhead is small [S1].

## Background
SnugBox was introduced in the "Speedy-Splat" paper (2025) as a plug-and-play optimization for 3D Gaussian Splatting [S1]. It addresses the overly conservative tile assignment of the original 3D-GS algorithm, which assigns a Gaussian to any tile intersecting a square inscribing a circle of radius $\lceil 3 \sqrt{\lambda_{max}} \rceil$ [S2]. SnugBox replaces this with a tight AABB derived from the Gaussian's elliptical extent [S1, S2].
