# Analytic-Splatting

Also called: Analytic Integration for 3D Gaussian Splatting

## Overview
Analytic-Splatting is a rendering method that replaces the point-sampling of 2D Gaussians in 3D Gaussian Splatting (3DGS) with an analytical approximation of the integral of the Gaussian signal over the pixel window area to reduce aliasing artifacts during zooming or resolution changes [S1]. It addresses the limitation of standard 3DGS, which treats pixels as isolated points and suffers from aliasing when pixel footprints change due to focal length or camera distance adjustments [S1]. Unlike Mip-Splatting, which uses a hybrid filtering mechanism that suppresses high-frequency components and causes over-smoothing, Analytic-Splatting preserves high-quality details by analytically integrating the signal using a conditioned logistic function approximation of the Gaussian CDF [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Projected 2D Gaussian parameters for a splat $i$: mean $\hat{\bm{\mu}}_i \in \mathbb{R}^2$, covariance matrix $\hat{\bm{\Sigma}}_i \in \mathbb{R}^{2\times2}$, opacity $\alpha_i \in [0,1]$, and color $\mathbf{c}_i \in \mathbb{R}^3$. Pixel coordinate $\mathbf{u} = [u_x, u_y]^\top$.
*   **Outputs:** Transmittance $T_i$ and accumulated color contribution for the pixel.

**Data Structures:**
The method operates on the projected 2D covariance matrix $\hat{\bm{\Sigma}}$. It requires the eigenvalues $\{\lambda_1, \lambda_2\}$ and eigenvectors $\{\mathbf{v}_1, \mathbf{v}_2\}$ of $\hat{\bm{\Sigma}}$.

**Steps:**

1.  **Compute Inverse Covariance:**
    Calculate the inverse of the projected 2D covariance matrix $\hat{\bm{\Sigma}}^{-1}$:
    $$ \hat{\bm{\Sigma}}^{-1} = \begin{bmatrix} a & b \\ b & c \end{bmatrix} $$
    where:
    $$ a = \frac{\hat{\Sigma}_{22}}{|\hat{\bm{\Sigma}}|}, \quad b = -\frac{\hat{\Sigma}_{12}}{|\hat{\bm{\Sigma}}|}, \quad c = \frac{\hat{\Sigma}_{11}}{|\hat{\bm{\Sigma}}|} $$
    and $|\hat{\bm{\Sigma}}| = \hat{\Sigma}_{11}\hat{\Sigma}_{22} - \hat{\Sigma}_{12}^2$ [S1].

2.  **Eigenvalue Decomposition:**
    Perform eigenvalue decomposition on $\hat{\bm{\Sigma}}$ to obtain eigenvalues $\{\lambda_1, \lambda_2\}$ and corresponding eigenvectors $\{\mathbf{v}_1, \mathbf{v}_2\}$. Define standard deviations $\sigma_1 = \sqrt{\lambda_1}$ and $\sigma_2 = \sqrt{\lambda_2}$ [S1].

3.  **Transform Pixel Center:**
    Transform the pixel center $\mathbf{u}$ into the diagonalized coordinate system defined by the eigenvectors. Let $\tilde{\mathbf{u}} = [\tilde{u}_x, \tilde{u}_y]^\top$:
    $$ \tilde{\mathbf{u}} = \begin{bmatrix} - & \mathbf{v}_1 & - \\ - & \mathbf{v}_2 & - \end{bmatrix} (\mathbf{u} - \hat{\bm{\mu}}) $$
    Component-wise:
    $$ \tilde{u}_x = v_{1x}(u_x - \hat{\mu}_x) + v_{1y}(u_y - \hat{\mu}_y) $$
    $$ \tilde{u}_y = v_{2x}(u_x - \hat{\mu}_x) + v_{2y}(u_y - \hat{\mu}_y) $$
    [S1].

4.  **Compute 1D Logistic Approximation:**
    Define the conditioned logistic function $S(x)$ as the analytic approximation of the standard Gaussian CDF:
    $$ S(x) = \frac{1}{1 + \exp(-1.6 \cdot x - 0.07 \cdot x^3)} $$
    [S1].
    Define the scaled logistic function for standard deviation $\sigma$:
    $$ S_\sigma(x) = S\left(\frac{x}{\sigma}\right) = \frac{1}{1 + \exp\left(-1.6 \cdot \frac{x}{\sigma} - 0.07 \cdot \left(\frac{x}{\sigma}\right)^3\right)} $$
    [S1].

5.  **Compute 2D Integral Approximation:**
    Calculate the integral of the Gaussian signal over the 1-width pixel window centered at $\mathbf{u}$, approximated as the product of two independent 1D integrals:
    $$ \mathcal{I}_g^\text{2D}(\mathbf{u}) = 2\pi \sigma_1 \sigma_2 \left[ S_{\sigma_1}\left(\tilde{u}_x + \frac{1}{2}\right) - S_{\sigma_1}\left(\tilde{u}_x - \frac{1}{2}\right) \right] \left[ S_{\sigma_2}\left(\tilde{u}_y + \frac{1}{2}\right) - S_{\sigma_2}\left(\tilde{u}_y - \frac{1}{2}\right) \right] $$
    [S1].

6.  **Volume Rendering:**
    Compute the final color $\mathbf{C}(\mathbf{u})$ using alpha blending, replacing the point sample $g^{2D}$ with the integral $\mathcal{I}_g^\text{2D}$:
    $$ \mathbf{C}(\mathbf{u}) = \sum_{i\in N} T_i \mathcal{I}_{g-i}^\text{2D}(\mathbf{u} | \hat{\bm{\mu}}_i, \hat{\bm{\Sigma}}_i) \alpha_i \mathbf{c}_i $$
    where transmittance $T_i$ is:
    $$ T_i = \prod_{j=1}^{i-1} \left(1 - \mathcal{I}_{g-j}^\text{2D}(\mathbf{u} | \hat{\bm{\mu}}_j, \hat{\bm{\Sigma}}_j) \alpha_j\right) $$
    [S1].

**Pseudocode:**

```python
import math

def logistic_approx(x):
    """
    Conditioned logistic function S(x) approximating standard Gaussian CDF.
    """
    exponent = -1.6 * x - 0.07 * (x ** 3)
    return 1.0 / (1.0 + math.exp(exponent))

def scaled_logistic(x, sigma):
    """
    Scaled logistic function S_sigma(x) for standard deviation sigma.
    """
    return logistic_approx(x / sigma)

def analytic_splatting_integral(u_x, u_y, mu_x, mu_y, v1_x, v1_y, v2_x, v2_y, lambda1, lambda2):
    """
    Computes the 2D integral approximation I_g^2D for a single Gaussian splat.
    
    Args:
        u_x, u_y: Pixel center coordinates.
        mu_x, mu_y: Gaussian mean coordinates.
        v1_x, v1_y: Eigenvector 1 components.
        v2_x, v2_y: Eigenvector 2 components.
        lambda1, lambda2: Eigenvalues of the covariance matrix.
        
    Returns:
        The integrated intensity response.
    """
    # Step 1: Compute standard deviations
    sigma1 = math.sqrt(lambda1)
    sigma2 = math.sqrt(lambda2)
    
    # Step 2: Transform pixel center to diagonalized coordinates
    dx = u_x - mu_x
    dy = u_y - mu_y
    
    tilde_u_x = v1_x * dx + v1_y * dy
    tilde_u_y = v2_x * dx + v2_y * dy
    
    # Step 3: Compute 1D integral components
    # I_sigma1 = sigma1 * [S_sigma1(u_x + 0.5) - S_sigma1(u_x - 0.5)]
    term1_pos = scaled_logistic(tilde_u_x + 0.5, sigma1)
    term1_neg = scaled_logistic(tilde_u_x - 0.5, sigma1)
    i_sigma1 = sigma1 * (term1_pos - term1_neg)
    
    # I_sigma2 = sigma2 * [S_sigma2(u_y + 0.5) - S_sigma2(u_y - 0.5)]
    term2_pos = scaled_logistic(tilde_u_y + 0.5, sigma2)
    term2_neg = scaled_logistic(tilde_u_y - 0.5, sigma2)
    i_sigma2 = sigma2 * (term2_pos - term2_neg)
    
    # Step 4: Compute 2D integral
    # I_g^2D = 2 * pi * sigma1 * sigma2 * [...] * [...]
    # Note: i_sigma1 already contains sigma1, i_sigma2 already contains sigma2.
    # The formula is 2*pi * (sigma1 * diff1) * (sigma2 * diff2)
    # Which is 2*pi * i_sigma1 * i_sigma2
    integral = 2.0 * math.pi * i_sigma1 * i_sigma2
    
    return integral

def render_pixel(u_x, u_y, splats):
    """
    Renders a single pixel using Analytic-Splatting.
    
    Args:
        u_x, u_y: Pixel center coordinates.
        splats: List of dictionaries containing splat parameters:
                'mu_x', 'mu_y', 'v1_x', 'v1_y', 'v2_x', 'v2_y', 
                'lambda1', 'lambda2', 'alpha', 'color_r', 'color_g', 'color_b'.
                Sorted by depth (front-to-back).
                
    Returns:
        Final color [r, g, b].
    """
    T = 1.0
    C_r, C_g, C_b = 0.0, 0.0, 0.0
    
    for splat in splats:
        # Compute integral for this splat
        I_g = analytic_splatting_integral(
            u_x, u_y,
            splat['mu_x'], splat['mu_y'],
            splat['v1_x'], splat['v1_y'],
            splat['v2_x'], splat['v2_y'],
            splat['lambda1'], splat['lambda2']
        )
        
        alpha = splat['alpha']
        
        # Contribution
        weight = T * I_g * alpha
        C_r += weight * splat['color_r']
        C_g += weight * splat['color_g']
        C_b += weight * splat['color_b']
        
        # Update transmittance
        T *= (1.0 - I_g * alpha)
        
        # Early exit if fully opaque
        if T < 1e-4:
            break
            
    return [C_r, C_g, C_b]
```

**Edge Cases and Pitfalls:**
*   **Correlation Term:** The 2D Gaussian integral contains a correlation term $b(x-\hat{\mu}_x)(y-\hat{\mu}_y)$ which is intractable analytically in the original coordinate system. The method resolves this by diagonalizing the covariance matrix and rotating the integration domain to align with eigenvectors, approximating the 2D integral as a product of two independent 1D integrals [S1].
*   **Small Standard Deviation:** Unlike Mip-Splatting, which convolves the Gaussian signal with a Gaussian kernel and may introduce large gaps for high-frequency components (small $\sigma$), Analytic-Splatting calculates the integral analytically, avoiding this issue [S1].
*   **Precision:** The logistic approximation coefficients (1.6 and 0.07) are fixed constants [S1].

## Subtopics

### [Analytic-Splatting Gradient Computation](5597-analytic-splatting-gradient-computation.md)
This method computes the exact gradient of the analytically integrated 2D Gaussian splat intensity with respect to the elements of the 2D covariance matrix $\hat{\Sigma}$. It enables differentiable training of Gaussian splat parameters by providing the necessary backpropagation signals for the covariance, which is critical for optimizing the shape and orientation of the Gaussians in 3D Gaussian Splatting. It builds on [Analytic-Splatting](3025-analytic-splatting.md) by extending the analytical integration to include the derivative terms required for gradient-based optimization.

## Operating characteristics
*   **Time Complexity:** The method replaces the exponential function evaluation in the standard 2D Gaussian with logistic function evaluations and square roots for eigenvalues. It avoids the computational burden of super-sampling (Monte Carlo integration) which requires $N$ samples [S1].
*   **Memory Complexity:** No additional memory structures are required beyond the standard Gaussian parameters.
*   **Performance:** Analytic-Splatting provides better anti-aliasing capability than standard 3DGS and Mip-Splatting, giving more details and better fidelity, especially during zooming or resolution changes [S1].
*   **Strengths:** Removes aliasing artifacts present in 3DGS; preserves high-frequency details better than Mip-Splatting; closed-form analytical approximation avoids sampling noise [S1].
*   **Limitations:** The approximation relies on the logistic function fit, which may have small errors compared to the true Gaussian integral, though experiments show it is accurate within appropriate standard deviation ranges [S1].

## Background
Analytic-Splatting was introduced by Zhihao Liang et al. in the paper "Analytic-Splatting: Anti-Aliased 3D Gaussian Splatting via Analytic Integration" (arXiv:2403.11056v2, 2024) [S1]. It addresses the aliasing issues inherent in 3D Gaussian Splatting, which treats pixels as isolated points and fails to account for pixel footprint changes [S1]. The method is used to replace the $g^{2D}$ term in the 3DGS framework [S1].
