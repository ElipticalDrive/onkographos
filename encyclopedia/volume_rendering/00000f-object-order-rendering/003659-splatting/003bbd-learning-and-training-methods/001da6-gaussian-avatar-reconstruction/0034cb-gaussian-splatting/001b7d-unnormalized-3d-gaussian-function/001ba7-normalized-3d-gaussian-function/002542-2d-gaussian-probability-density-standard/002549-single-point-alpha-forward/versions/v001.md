# Single Point Alpha Forward

Also called: Gaussian Alpha Computation, Single Point Alpha

## Overview
Computes the alpha value for a single 3D Gaussian projected onto a 2D pixel by evaluating the 2D Gaussian probability density function (PDF) at the pixel center [S1, unofficial]. It builds on [2D Gaussian Probability Density (Standard)](3466-2d-gaussian-probability-density-standard.md) by handling the full pipeline of transforming 3D Gaussian parameters (position, rotation, scale) into camera space, projecting the covariance to screen space, and combining the resulting PDF with the Gaussian's intrinsic opacity [S1, unofficial]. It differs from its sibling [Gradient of 2D Gaussian PDF (Conic)](3472-gradient-of-2d-gaussian-pdf-conic.md) by returning a scalar alpha value rather than the gradient of the PDF [S1, S2, unofficial].

## How it works
**Inputs:**
- 3D Gaussian parameters: mean position $\mathbf{xyz} \in \mathbb{R}^3$, pre-activation scale $s \in \mathbb{R}^3$, pre-activation quaternion $q \in \mathbb{R}^4$ (w, x, y, z), pre-activation opacity $\sigma_{pre} \in \mathbb{R}$.
- Camera matrices: World-to-camera transformation $T_{camera} \in \mathbb{R}^{4 \times 4}$, camera intrinsic matrix $K \in \mathbb{R}^{3 \times 3}$.
- Pixel coordinates: $\mathbf{uv}_{center} \in \mathbb{R}^2$ (the center of the pixel in screen space).

**Outputs:**
- Alpha value $\alpha \in [0, 1]$.

**Data Structures:**
- No persistent data structures; computation is stateless for a single Gaussian.

**Steps:**
1. **Homogenize Position:** Construct the homogeneous coordinate vector $\mathbf{xyz1} = [\mathbf{xyz}, 1]^T$.
2. **Transform to Camera Space:** Compute $\mathbf{xyz1}_{camera} = T_{camera} \cdot \mathbf{xyz1}$.
3. **Extract Camera Coordinates:** Let $\mathbf{xyz}_{camera}$ be the first three components of $\mathbf{xyz1}_{camera}$.
4. **Project to Screen Space:** Compute $\mathbf{uv1} = K \cdot \mathbf{xyz}_{camera}$. The screen coordinates are $\mathbf{uv} = \mathbf{uv1}_{0:2} / \mathbf{uv1}_2$ (perspective division).
5. **Compute Scale Matrix:** Construct the diagonal scale matrix $S = \text{diag}(\exp(s))$.
6. **Compute Rotation Matrix:** Construct the rotation matrix $R$ from the quaternion $q$.
7. **Compute 3D Covariance:** Compute the 3D covariance matrix $\Sigma = R S S^T R^T$. Note: $S$ is diagonal, so $S S^T = S^2 = \text{diag}(\exp(2s))$.
8. **Compute Projection Jacobian:** Compute the Jacobian $J$ of the projection transformation. For a perspective camera with intrinsic $K$, if $\mathbf{xyz}_{camera} = [X, Y, Z]^T$, the Jacobian of the projection $(X/Z, Y/Z)$ with respect to $(X, Y, Z)$ is:
   $$
   J_{proj} = \begin{bmatrix}
   1/Z & 0 & -X/Z^2 \\
   0 & 1/Z & -Y/Z^2
   \end{bmatrix}
   $$
   The full Jacobian $J$ includes the intrinsic matrix $K$: $J = K_{2 \times 3} \cdot J_{proj}$, where $K_{2 \times 3}$ is the first two rows of $K$.
9. **Compute 2D Covariance:** Let $W$ be the upper-left $3 \times 3$ rotation part of $T_{camera}$. Compute the 2D covariance matrix in screen space:
   $$
   cov = J W \Sigma W^T J^T
   $$
10. **Compute Probability Density:** Evaluate the 2D Gaussian PDF at the pixel center. Let $\mathbf{d} = \mathbf{uv}_{center} - \mathbf{uv}$. The exponent is:
    $$
    p = \exp\left(-0.5 \mathbf{d}^T cov^{-1} \mathbf{d}\right)
    $$
    [S1, unofficial]
11. **Compute Alpha:** Apply the sigmoid function to the pre-activation opacity $\sigma_{pre}$ to get the base opacity $\sigma(\sigma_{pre}) = \frac{1}{1 + e^{-\sigma_{pre}}}$. The final alpha is:
    $$
    \alpha = \sigma(\sigma_{pre}) \cdot p
    $$
    [S1, unofficial]

**Parameters:**
- Sigmoid activation for opacity: Standard logistic sigmoid.
- Exponential activation for scale: Standard exponential.

**Edge Cases and Pitfalls:**
- **Depth Zero:** If $Z=0$ (camera plane), perspective division fails. Guard against $Z \le \epsilon$.
- **Singular Covariance:** If the Gaussian is degenerate (e.g., zero scale), $cov$ may be singular. In practice, scales are regularized or clamped to prevent this.
- **Numerical Stability:** Very small or large exponents in the PDF evaluation can lead to underflow/overflow. Clamping the exponent or the final alpha is recommended.

**Pseudocode:**
```python
import numpy as np

def single_point_alpha_forward(xyz, s, q, sigma_pre, T_camera, K, uv_center):
    """
    Computes alpha for a single 3D Gaussian projected to a 2D pixel.
    
    Args:
        xyz: (3,) array, 3D mean position.
        s: (3,) array, pre-activation scale (log scale).
        q: (4,) array, pre-activation quaternion (w, x, y, z).
        sigma_pre: float, pre-activation opacity.
        T_camera: (4, 4) array, world-to-camera transformation matrix.
        K: (3, 3) array, camera intrinsic matrix.
        uv_center: (2,) array, pixel center coordinates (u, v).
        
    Returns:
        alpha: float, the computed alpha value.
    """
    # 1. Homogenize position
    xyz1 = np.append(xyz, 1.0)
    
    # 2. Transform to camera space
    xyz1_camera = T_camera @ xyz1
    
    # 3. Extract camera coordinates
    xyz_camera = xyz1_camera[:3]
    X, Y, Z = xyz_camera
    
    # 4. Project to screen space
    uv1 = K @ xyz_camera
    uv = uv1[:2] / uv1[2]
    
    # 5. Compute scale matrix S
    exp_s = np.exp(s)
    S = np.diag(exp_s)
    
    # 6. Compute rotation matrix R from quaternion q
    w, x, y, z = q
    R = np.array([
        [1 - 2*(y**2 + z**2), 2*(x*y - w*z), 2*(x*z + w*y)],
        [2*(x*y + w*z), 1 - 2*(x**2 + z**2), 2*(y*z - w*x)],
        [2*(x*z - w*y), 2*(y*z + w*x), 1 - 2*(x**2 + y**2)]
    ])
    
    # 7. Compute 3D covariance Sigma
    # Sigma = R * S * S^T * R^T
    # Since S is diagonal, S * S^T = diag(exp(2s))
    S2 = np.diag(np.exp(2 * s))
    Sigma = R @ S2 @ R.T
    
    # 8. Compute Jacobian J of projection
    # J = K[0:2, :] @ J_proj
    # J_proj = d(uv)/d(X,Y,Z)
    if abs(Z) < 1e-6:
        # Handle degenerate case, e.g., return 0 or clamp
        return 0.0
    
    J_proj = np.array([
        [1/Z, 0, -X/(Z**2)],
        [0, 1/Z, -Y/(Z**2)]
    ])
    K_2x3 = K[:2, :]
    J = K_2x3 @ J_proj
    
    # 9. Compute 2D covariance cov
    # W is the upper-left 3x3 part of T_camera
    W = T_camera[:3, :3]
    cov = J @ W @ Sigma @ W.T @ J.T
    
    # 10. Compute probability density p
    # d = uv_center - uv
    d = uv_center - uv
    try:
        cov_inv = np.linalg.inv(cov)
    except np.linalg.LinAlgError:
        # If cov is singular, return 0 or handle appropriately
        return 0.0
    
    exponent = -0.5 * (d @ cov_inv @ d)
    p = np.exp(exponent)
    
    # 11. Compute alpha
    sigma = 1.0 / (1.0 + np.exp(-sigma_pre))
    alpha = sigma * p
    
    return alpha
```

## Subtopics

### 2D Gaussian Alpha Computation (Batched)
Evaluates the alpha for all pixels in a frame for a set of Gaussians using batched tensor operations [S2, unofficial]. It creates a meshgrid of pixel coordinates, expands dimensions to match Gaussian counts, evaluates the 2D Gaussian function, applies the exponential, multiplies by opacity, and reshapes to $(N, H, W)$ [S2, unofficial]. It clamps alphas to a maximum of 0.99 for numerical stability and zeros out values below $1/255.0$ [S2, unofficial]. This variant is optimized for GPU execution using frameworks like PyTorch [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per Gaussian per pixel. For batched evaluation over $N$ Gaussians and $P$ pixels, it is $O(N \cdot P)$ with constant factors dependent on matrix inversion and exponentiation.
- **Memory Complexity:** $O(1)$ for single point; $O(N \cdot P)$ for batched evaluation if storing all alphas [S2, unofficial].
- **Strengths:** Direct evaluation allows for precise alpha computation at specific points. The batched variant leverages GPU parallelism for high throughput [S2, unofficial].
- **Limitations:** Single-point evaluation does not account for coverage area, only the center. Requires careful handling of singular covariances and perspective division edge cases.
- **When to use:** When precise alpha values at specific pixel centers are needed, or as a component in a larger rasterization pipeline. The batched version is suitable for full-frame rendering.

## Background
The method is part of the 3D Gaussian Splatting rendering pipeline, specifically the alpha computation step for projecting 3D Gaussians to 2D [S1, S2, unofficial]. It relies on the mathematical formulation of projecting 3D covariance matrices to 2D screen space using the Jacobian of the projection transformation [S1, unofficial]. The batched implementation is commonly found in unofficial PyTorch-based implementations of 3D Gaussian Splatting [S2, unofficial].
