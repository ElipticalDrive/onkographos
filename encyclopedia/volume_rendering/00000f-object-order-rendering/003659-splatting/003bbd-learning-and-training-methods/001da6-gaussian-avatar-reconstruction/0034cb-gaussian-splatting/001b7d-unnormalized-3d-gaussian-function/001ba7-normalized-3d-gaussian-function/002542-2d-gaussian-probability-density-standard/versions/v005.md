# 2D Gaussian Probability Density (Standard)

Also called: 2D Gaussian PDF

## Overview
Computes the probability density function (PDF) value of a 2D Gaussian distribution at a query point `xy`, given its mean vector and covariance matrix [S1, unofficial]. It serves as the fundamental evaluation primitive for Gaussian splatting, providing the spatial weighting used to determine pixel contribution and opacity [S1, unofficial]. It differs from the [Conic](3475-2d-gaussian-probability-density-conic.md) variant by operating on the explicit covariance matrix $\Sigma$ rather than the pre-computed conic matrix $C$, and from the [Unnormalized](1065-unnormalized-3d-gaussian-function.md) variant by including the normalization constant $1/(2\pi\sqrt{\det(\Sigma)})$ [S1, unofficial].

## How it works
**Inputs:**
- `xy`: A 2D vector representing the query point in screen space $(x, y)$ [S1, unofficial].
- `gaussian_mean`: A 2D vector representing the mean of the Gaussian $(\mu_x, \mu_y)$ [S1, unofficial].
- `gaussian_covariance`: A $2 \times 2$ symmetric positive-definite covariance matrix $\Sigma$ [S1, unofficial].

**Outputs:**
- `pdf`: A scalar float representing the probability density value at `xy` [S1, unofficial].

**Data Structures:**
- `xy`: `float2` or equivalent 2-element array.
- `gaussian_mean`: `float2` or equivalent 2-element array.
- `gaussian_covariance`: $2 \times 2$ matrix, typically stored as `float2x2` or four floats `[cov[0,0], cov[0,1], cov[1,0], cov[1,1]]`. Since $\Sigma$ is symmetric, `cov[0,1] == cov[1,0]`.

**Steps:**
1. Compute the difference vector between the query point and the mean:
   $$ \Delta = xy - \text{gaussian\_mean} $$
   Let $\Delta = [\Delta x, \Delta y]^T$ [S1, unofficial].

2. Compute the determinant of the covariance matrix $\Sigma$:
   $$ \det(\Sigma) = \Sigma_{0,0}\Sigma_{1,1} - \Sigma_{0,1}\Sigma_{1,0} $$
   Since $\Sigma$ is symmetric, $\Sigma_{0,1} = \Sigma_{1,0}$, so:
   $$ \det(\Sigma) = \Sigma_{0,0}\Sigma_{1,1} - \Sigma_{0,1}^2 $$
   [S1, unofficial].

3. Compute the inverse covariance matrix $\Sigma^{-1}$ analytically for the $2 \times 2$ case:
   $$ \Sigma^{-1} = \frac{1}{\det(\Sigma)} \begin{bmatrix} \Sigma_{1,1} & -\Sigma_{0,1} \\ -\Sigma_{1,0} & \Sigma_{0,0} \end{bmatrix} $$
   [S1, unofficial].

4. Compute the quadratic form $\Delta^T \Sigma^{-1} \Delta$:
   $$ \text{quad} = \Delta^T \Sigma^{-1} \Delta $$
   This can be expanded as:
   $$ \text{quad} = \frac{1}{\det(\Sigma)} \left( \Sigma_{1,1} \Delta x^2 - 2\Sigma_{0,1} \Delta x \Delta y + \Sigma_{0,0} \Delta y^2 \right) $$
   [S1, unofficial].

5. Compute the exponent:
   $$ \text{exponent} = -0.5 \cdot \text{quad} $$
   [S1, unofficial].

6. Compute the final PDF value:
   $$ \text{pdf} = \frac{\exp(\text{exponent})}{2 \pi \sqrt{\det(\Sigma)}} $$
   [S1, unofficial].

**Pseudocode:**
```python
def compute_2d_gaussian_pdf_standard(xy, gaussian_mean, gaussian_covariance):
    """
    Computes the 2D Gaussian PDF value at point xy.
    
    Args:
        xy: float2, query point (x, y)
        gaussian_mean: float2, mean of the Gaussian (mu_x, mu_y)
        gaussian_covariance: float2x2, covariance matrix Sigma
        
    Returns:
        float, the probability density value
    """
    # Step 1: Compute mean difference
    delta_x = xy.x - gaussian_mean.x
    delta_y = xy.y - gaussian_mean.y
    
    # Step 2: Compute determinant of Sigma
    # Sigma is symmetric: cov[0,1] == cov[1,0]
    cov_00 = gaussian_covariance[0, 0]
    cov_01 = gaussian_covariance[0, 1]
    cov_11 = gaussian_covariance[1, 1]
    
    det_cov = cov_00 * cov_11 - cov_01 * cov_01
    
    # Handle degenerate case where determinant is zero or negative (numerical instability)
    # [G] In practice, a small epsilon is added to det_cov to prevent division by zero or sqrt of negative.
    if det_cov <= 0.0:
        return 0.0
        
    # Step 3: Compute inverse covariance matrix elements (scaled by 1/det)
    # inv_cov = (1/det) * [[cov_11, -cov_01], [-cov_01, cov_00]]
    inv_00 = cov_11 / det_cov
    inv_01 = -cov_01 / det_cov
    inv_11 = cov_00 / det_cov
    
    # Step 4: Compute quadratic form delta^T * inv_cov * delta
    # quad = delta_x * (inv_00 * delta_x + inv_01 * delta_y) + delta_y * (inv_01 * delta_x + inv_11 * delta_y)
    quad = delta_x * (inv_00 * delta_x + inv_01 * delta_y) + delta_y * (inv_01 * delta_x + inv_11 * delta_y)
    
    # Step 5: Compute exponent
    exponent = -0.5 * quad
    
    # Step 6: Compute PDF
    # pdf = exp(exponent) / (2 * pi * sqrt(det_cov))
    pdf = math.exp(exponent) / (2.0 * math.pi * math.sqrt(det_cov))
    
    return pdf
```

**Parameters:**
- No explicit tuning parameters. The shape is determined entirely by the input covariance matrix [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Degenerate Covariance:** If $\det(\Sigma) \le 0$, the matrix is not positive-definite or is singular. This results in division by zero or invalid square roots. In practice, this indicates a numerical error in covariance propagation or a degenerate Gaussian (e.g., zero scale). The implementation should guard against this, typically returning 0 or handling it as an error [G].
- **Precision:** Computing the inverse via the analytical formula is stable for well-conditioned matrices. However, if $\det(\Sigma)$ is very small, precision loss may occur in the division. Using the conic representation (inverse covariance) directly can avoid explicit inversion and determinant calculation [S1, unofficial].
- **Symmetry:** The covariance matrix must be symmetric. If the input is not symmetric, the result is undefined or incorrect. The implementation should assume symmetry or enforce it (e.g., `cov[1,0] = cov[0,1]`) [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per Gaussian evaluation. The computation involves a fixed number of arithmetic operations (additions, multiplications, one square root, one exponential) [S1, unofficial].
- **Memory Complexity:** $O(1)$ auxiliary memory. Only a few temporary variables are needed [S1, unofficial].
- **Strengths:** Simple to implement, numerically stable for well-conditioned covariances, provides the exact normalized PDF value required for probabilistic interpretation [S1, unofficial].
- **Limitations:** Requires computing the determinant and inverse of the covariance matrix, which can be slightly more expensive than using the pre-computed conic matrix. Sensitive to degenerate covariances [S1, unofficial].
- **When to use:** When the covariance matrix is available in standard form and the normalized PDF value is required. Useful for debugging, visualization, or when gradients are not needed [S1, unofficial].
- **When not to use:** When performance is critical and the conic matrix is already available; use the Conic variant instead. When gradients are needed for optimization; use the Gradient variant [S1, unofficial].

## Background
The 2D Gaussian PDF is a fundamental concept in probability theory and computer graphics, particularly in splatting techniques. In the context of 3D Gaussian Splatting, the 3D Gaussians are projected onto the 2D image plane, resulting in 2D Gaussians whose PDFs are evaluated to determine pixel contributions [S1, unofficial]. The standard form, including the normalization constant, is used when the probabilistic interpretation of the density is important. The implementation details are derived from the Taichi-based 3D Gaussian Splatting repository [S1, unofficial].
