# Composite-Only Splatting
Also called: Basic Splatting

## Overview
Composite-only splatting is the foundational object-order volume rendering technique where volumetric primitives are traversed in depth order, projected onto the screen, and immediately composited into the final image buffers [S1, unofficial][S2, book]. It differs from sibling methods like [Stop-the-pop](1472-stop-the-pop.md) or [Sorting Algorithms](14243-sorting-algorithms.md) by performing per-primitive compositing rather than accumulating splats into intermediate buffers or sorting all splats globally before a single pass, making it the simplest but most artifact-prone approach [S1, unofficial][S2, book].

## How it works
**Inputs and Outputs:** Not given in the sources.

**Data Structures:** Not given in the sources.

**Numbered Steps:**
1. **Sorting/Traversal:** Sort all volume primitives in front-to-back or back-to-front order relative to the camera, then traverse them in that order [S1, unofficial][S2, book].
2. **Shading:** For each primitive $k$, compute its color $\mathbf{c}_k$ and opacity $\alpha_k$ using the transfer functions and a shading equation (referenced as Equation 9 in the sources) [S1, unofficial][S2, book].
3. **Splatting:** Project the primitive's footprint onto the 2D screen and compute the footprint weight $w(x,y)$ based on the reconstruction kernel for each covered pixel [S1, unofficial][S2, book].
4. **Compositing:** Update the screen's color and opacity buffers by compositing the primitive's contribution with the existing pixel values using a blending equation (referenced as Equation 13 in the sources) [S1, unofficial][S2, book].
5. **Repeat:** Continue until all primitives are processed [S1, unofficial][S2, book].

**Formulas:** The sources reference Equation (9) for shading and Equation (13) for compositing but do not provide the explicit mathematical expressions [S1, unofficial][S2, book]. Standard alpha compositing applies: $\alpha_{\text{splat}} = w \cdot \alpha_k$, $C_{\text{out}} = C_{\text{in}}(1 - \alpha_{\text{splat}}) + C_{\text{splat}}$, and $\alpha_{\text{out}} = \alpha_{\text{in}}(1 - \alpha_{\text{splat}}) + \alpha_{\text{splat}}$ [G].

**Parameters:** Not given in the sources.

**Edge Cases and Pitfalls:** Color bleeding and slight sparkling artifacts in animated viewing may be noticeable because interpolation and compositing operations cannot be separated due to the pre-integration of the basis kernel [S1, unofficial][S2, book].

**Pseudocode:**
```python
def composite_only_splatting(primitives, transfer_function, camera, width, height):
    # Initialize screen buffers
    color_buffer = [[(0.0, 0.0, 0.0) for _ in range(height)] for _ in range(width)]
    opacity_buffer = [[0.0 for _ in range(height)] for _ in range(width)]

    # 1. Sort primitives in depth order (front-to-back or back-to-front)
    sorted_primitives = sorted(primitives, key=lambda p: p.position.z)

    for prim in sorted_primitives:
        # 2. Shading: assign color and opacity using transfer functions
        c_k, alpha_k = transfer_function(prim)  # Standard transfer function evaluation [G]

        # 3. Splatting: project footprint to screen coordinates
        # Standard perspective/orthographic projection [G]
        footprint_pixels = []
        for dx, dy in prim.kernel.support_grid:
            sx = camera.x + dx
            sy = camera.y + dy
            if 0 <= sx < width and 0 <= sy < height:
                footprint_pixels.append((int(sx), int(sy)))

        for x, y in footprint_pixels:
            # Calculate footprint weight w(x,y) based on kernel
            w = prim.kernel.value(x - camera.x, y - camera.y)

            # 4. Compositing: update buffers using standard alpha blending
            alpha_splat = w * alpha_k
            r, g, b = color_buffer[x][y]
            color_buffer[x][y] = (
                r * (1.0 - alpha_splat) + c_k[0] * alpha_splat,
                g * (1.0 - alpha_splat) + c_k[1] * alpha_splat,
                b * (1.0 - alpha_splat) + c_k[2] * alpha_splat
            )
            opacity_buffer[x][y] = opacity_buffer[x][y] * (1.0 - alpha_splat) + alpha_splat

    return color_buffer, opacity_buffer
```

## Background
Composite-only splatting was the first proposed splatting method for volume rendering [S1, unofficial][S2, book]. It established the fundamental object-order paradigm of projecting primitives and compositing them directly into the image buffer [S1, unofficial][S2, book]. Its limitations with color bleeding and sparkling artifacts led to the development of axis-aligned sheet-buffered splatting [S1, unofficial][S2, book].
