# Seed Generation for Initial Splats

Also called: Gradient and Uniform Grid Seeding, Initial Splat Position Generation

## Overview
This method generates the initial set of splat primitives for volume rendering by combining gradient-based edge detection with uniform grid sampling [S1, unofficial]. It solves the problem of sparse or uneven primitive distribution, ensuring that high-frequency details are captured by gradient-weighted sampling while smooth regions are covered by a uniform grid [S1, unofficial]. It differs from sibling methods like [World-aligned lattice octree bake](11637-world-aligned-lattice-octree-bake.md) by using a fixed budget split rather than hierarchical spatial partitioning, and from [Splat Data Structure (ISplatSource)](10289-splat-data-structure-isplatsource.md) by focusing on the *creation* of positions rather than their *storage* [S1, unofficial].

## How it works
**Inputs:**
- Volume data $V$ with dimensions $N_x \times N_y \times N_z$ (total voxels $N_{vox}$) [S1, unofficial].
- Target seed count $N_{target}$ [S1, unofficial].
- Gradient threshold $\tau = 0.1$ [S1, unofficial].
- Exclusion radius $r = 2$ voxels [S1, unofficial].
- Grid coverage share $S_{grid} = 0.4$ (40%) [S1, unofficial].

**Outputs:**
- A list of initial splat positions $P = \{p_1, p_2, ..., p_k\}$ where $k \le N_{target}$ [S1, unofficial].

**Data Structures:**
- `GradientMap`: 3D array of normalized gradient magnitudes, same size as $V$ [G].
- `CandidateList`: List of voxel coordinates $(x,y,z)$ passing the gradient threshold [G].
- `PoissonDiskSampler`: Maintains a spatial hash grid of exclusion zones to enforce minimum distance $r$ [G].

**Steps:**
1. **Compute Gradients:** Calculate Sobel gradients in all three dimensions for every voxel. Compute the normalized gradient magnitude $g(x,y,z)$ for each voxel [S1, unofficial].
2. **Filter Candidates:** Identify voxels where $g(x,y,z) > 0.1$. Store these in `CandidateList` [S1, unofficial].
3. **Poisson-Disk Sampling:** Apply gradient-weighted Poisson-disk sampling on `CandidateList` with exclusion radius $r=2$. This selects a subset of high-gradient voxels, ensuring they are spatially separated [S1, unofficial]. Let this set be $P_{edge}$.
4. **Calculate Grid Spacing:** Determine the number of grid seeds $N_{grid}$ required to fill the remaining budget ($40\%$ of $N_{target}$). The grid spacing $s$ is calculated such that the volume is tiled:
   $$ s = \left(\frac{N_{vox}}{N_{grid}}\right)^{1/D} $$
   where $D$ is the dimensionality (typically 3) [S1, unofficial].
5. **Generate Uniform Seeds:** Create a uniform grid with spacing $s$ across the volume bounds. Let this set be $P_{grid}$ [S1, unofficial].
6. **Combine and Cap:** Merge $P_{edge}$ and $P_{grid}$. The default seeder enforces a 60/40 split, capping $P_{edge}$ at 60% of $N_{target}$ and $P_{grid}$ at 40% of $N_{target}$ [S1, unofficial].
7. **GPU Execution:** Run the seeding process on GPU (CUDA/MPS) if available [S1, unofficial].

**Parameters:**
- **Seed Target ($N_{target}$):**
  $$ N_{target} = \min\left(10000, \max\left(100, \left\lfloor \frac{N_{vox}}{2^{1/D}} \right\rfloor\right)\right) $$
  [S1, unofficial]
- **Gradient Threshold:** $0.1$ [S1, unofficial].
- **Exclusion Radius:** $2$ voxels [S1, unofficial].
- **Grid Share:** $40\%$ of the seed budget [S1, unofficial].

**Edge Cases:**
- If $N_{vox} / 2^{1/D} < 100$, $N_{target}$ defaults to $100$ [S1, unofficial].
- Grid spacing is clamped to a minimum of $2$ voxels to prevent overly dense uniform sampling in small volumes [S1, unofficial].
- The final retained count may be lower than $N_{target}$ due to post-fit culling (see [Dynamic operations](link)) [S1, unofficial].

**Pseudocode:**
```python
import math

def generate_seeds(nx, ny, nz, data, D=3):
    # data is a flat list of length nx*ny*nz
    def idx(x, y, z): return x * ny * nz + y * nz + z

    # 1. Compute gradient magnitudes
    mag = [0.0] * (nx * ny * nz)
    max_m = 0.0
    for x in range(nx):
        for y in range(ny):
            for z in range(nz):
                gx = data[idx(min(x+1, nx-1), y, z)] - data[idx(max(x-1, 0), y, z)]
                gy = data[idx(x, min(y+1, ny-1), z)] - data[idx(x, max(y-1, 0), z)]
                gz = data[idx(x, y, min(z+1, nz-1))] - data[idx(x, y, max(z-1, 0))]
                m = math.sqrt(gx**2 + gy**2 + gz**2)
                mag[idx(x, y, z)] = m
                if m > max_m: max_m = m

    norm_mag = [m / max_m if max_m > 0 else m for m in mag]

    # 2. Filter candidates
    candidates = []
    for i, m in enumerate(norm_mag):
        if m > 0.1:
            x, rem = divmod(i, ny * nz)
            y, z = divmod(rem, nz)
            candidates.append((x, y, z))

    # 3. Poisson-disk sampling
    edge_seeds = []
    r = 2
    cell_size = r / math.sqrt(D)
    grid = {}
    def dist(a, b): return math.sqrt((a[0]-b[0])**2 + (a[1]-b[1])**2 + (a[2]-b[2])**2)

    for p in candidates:
        gx, gy, gz = math.floor(p[0]/cell_size), math.floor(p[1]/cell_size), math.floor(p[2]/cell_size)
        valid = True
        for dx in range(-2, 3):
            for dy in range(-2, 3):
                for dz in range(-2, 3):
                    key = (gx+dx, gy+dy, gz+dz)
                    if key in grid:
                        for existing in grid[key]:
                            if dist(p, existing) < r:
                                valid = False; break
                    if not valid: break
                if not valid: break
            if not valid: break
        if valid:
            edge_seeds.append(p)
            grid[(gx, gy, gz)] = grid.get((gx, gy, gz), []) + [p]

    # 4. Calculate targets
    raw_target = max(100, math.floor(nx * ny * nz / (2 ** (1/D))))
    N_target = min(10000, raw_target)
    N_edge = math.floor(0.6 * N_target)
    N_grid = math.floor(0.4 * N_target)

    # 5. Cap edge seeds
    edge_seeds = edge_seeds[:N_edge]

    # 6. Generate uniform grid seeds
    spacing = max(2, math.floor((nx * ny * nz / N_grid) ** (1/D)))
    grid_seeds = []
    for x in range(0, nx, spacing):
        for y in range(0, ny, spacing):
            for z in range(0, nz, spacing):
                grid_seeds.append((x, y, z))

    # 7. Cap grid seeds and combine
    grid_seeds = grid_seeds[:N_grid]
    all_seeds = edge_seeds + grid_seeds
    return all_seeds
```

## Subtopics

### Seed Selection Preview
A technique that provides a preview of the selected seeds during the seed selecting process [S2, unofficial]. This is part of an enhanced isosurface rendering approach involving voxel selecting and selection-based coloring [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N_{vox})$ for gradient computation and candidate filtering; Poisson-disk sampling scales with the number of candidates and spatial hash lookups [S1, unofficial].
- **Memory Complexity:** $O(N_{vox})$ for gradient storage and candidate lists [S1, unofficial].
- **Execution:** Runs on GPU (CUDA/MPS) when available to prevent main-thread blocking [S1, unofficial].
- **Strengths:** Ensures coverage of smooth regions (via grid) and edges (via gradient) [S1, unofficial].
- **Limitations:** The final retained count may be lower than requested due to post-fit culling [S1, unofficial].

## Background
The method is described in the context of "Luxar," a Gaussian splatting framework for microscopy and scalable interactive web visualization of multidimensional scientific data [S1, unofficial]. The specific seed generation strategy (60% gradient, 40% uniform) is the default "auto" seeder used in single-pass fitting reported in the source [S1, unofficial]. The concept of seed preview is associated with enhanced isosurface rendering techniques [S2, unofficial].
