# Seed Generation for Initial Splats

Also called: Gradient and Uniform Grid Seeding, Initial Splat Position Generation

## Overview
This method generates the initial set of splat primitives from volumetric data by combining gradient-based sampling for high-frequency details with uniform grid sampling for smooth regions. It solves the problem of determining an optimal, sparse set of splat positions that accurately represent the volume's structure without excessive redundancy. It differs from sibling methods by explicitly balancing edge detection (via Sobel gradients) with uniform coverage, whereas [Splat Texture Layout & Mapping](7089-splat-texture-layout-mapping.md) focuses on memory organization and [World-aligned lattice octree bake](11637-world-aligned-lattice-octree-bake.md) uses hierarchical spatial partitioning.

## How it works
**Inputs:**
- Volume data $V$ with dimensions $N_x \times N_y \times N_z$.
- Total voxel count $N_{vox}$.
- Dimensionality $D$ (typically 3).

**Outputs:**
- A list of seed positions $\{\mathbf{p}_k\}$ and associated weights.

**Data Structures:**
- **Gradient Field:** 3-channel Sobel gradient vectors $\nabla V$ per voxel.
- **Seed List:** Array of 3D coordinates and metadata.

**Steps:**

1.  **Compute Gradients:** Calculate Sobel gradients across all dimensions for every voxel. Compute the normalized gradient magnitude $|\nabla V|_{norm}$ for each voxel [S1, unofficial].

2.  **Gradient-Based Seeding (60% of budget):**
    - Identify voxels where $|\nabla V|_{norm} > 0.1$ [S1, unofficial].
    - Apply gradient-weighted Poisson-disk sampling to these voxels.
    - Use an exclusion radius of 2 voxels to ensure spatial separation [S1, unofficial].
    - This step captures edges and high-frequency features.

3.  **Uniform Grid Seeding (40% of budget):**
    - Determine grid spacing $S$ such that the uniform grid contributes 40% of the total seed count.
    - Calculate $S$ using the formula:
      $$ S = \left( \frac{N_{vox}}{N_{grid}} \right)^{1/D} $$
      where $N_{grid}$ is the target number of uniform seeds.
    - Enforce a minimum spacing of 2 voxels ($S \ge 2$) [S1, unofficial].
    - This step ensures coverage of smooth, low-gradient regions missed by the gradient sampler [S1, unofficial].

4.  **Target Count Calculation:**
    - Calculate the target seed count $N_{target}$:
      $$ N_{target} = \min\left(10,000, \max\left(100, \left\lfloor \frac{N_{vox}}{2^{1/D}} \right\rfloor \right)\right) $$
    - The 60/40 split applies to this $N_{target}$ [S1, unofficial].

5.  **Post-Fit Cull:**
    - After fitting splats to the volume, remove seeds that do not contribute significantly to the reconstruction. The retained count may fall below the requested seed count [S1, unofficial].

**Parameters:**
- Gradient threshold: 0.1 [S1, unofficial].
- Exclusion radius: 2 voxels [S1, unofficial].
- Minimum grid spacing: 2 voxels [S1, unofficial].
- Seed target cap: 10,000 [S1, unofficial].

**Edge Cases:**
- If $N_{vox}$ is very small, the target count defaults to 100 [S1, unofficial].
- If the calculated grid spacing $S < 2$, clamp to 2 [S1, unofficial].
- Seeding runs on the GPU (CUDA, MPS) when available for performance [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by gradient computation and Poisson-disk sampling. Single-pass and two-pass implementations have comparable wall-time (ratio 0.70–1.75×, median 1.07×) [S1, unofficial].
- **Memory Complexity:** Requires storage for the volume, gradient field, and seed list. GPU memory usage depends on the seed count and volume size.
- **Strengths:** Efficiently captures both high-frequency edges and smooth regions. GPU-accelerated implementation enables fast generation.
- **Limitations:** The fixed 60/40 split may not be optimal for all volume types. Post-fit culling can result in fewer seeds than targeted.
- **When to use:** General-purpose volumetric visualization where a balance of detail and coverage is needed.
- **When not to use:** When explicit user control over seed placement is required, or when the volume has extreme anisotropy not handled by the uniform grid.

## Background
The method originates from the Luxar framework for Gaussian splatting in microscopy and scientific data visualization [S1, unofficial]. It was developed to provide scalable, interactive web visualization of multidimensional data. The approach combines established techniques (Sobel gradients, Poisson-disk sampling) into a unified seeding strategy tailored for volumetric splatting.
