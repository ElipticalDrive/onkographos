# Seed Generation for Initial Splats

Also called: Gradient and Uniform Grid Seeding, Initial Splat Position Generation

## Overview
This method generates the initial set of splat primitives from volumetric data by combining edge-aware sampling with uniform grid coverage [S1, unofficial]. It solves the problem of determining where to place splats to accurately represent volume geometry and density without excessive redundancy. It differs from purely uniform seeding by prioritizing high-gradient regions (edges) to capture detail, while ensuring smooth regions are covered by a secondary uniform pass [S1, unofficial].

## How it works
**Inputs:**
- Volume data $V$ with dimensions $N_x \times N_y \times N_z$.
- Total voxel count $N_{vox} = N_x N_y N_z$.
- Dimensionality $D$ (typically 3).
- Target seed count limit $C_{max} = 10,000$.

**Outputs:**
- A list of initial splat positions $\{\mathbf{p}_k\}$ and associated weights.

**Data Structures:**
- **Gradient Volume:** A 3D grid of the same size as $V$, storing the magnitude of the Sobel gradient for each voxel.
- **Seed Buffer:** A dynamic list or array storing valid seed positions.
- **Exclusion Mask:** A boolean grid or spatial hash to enforce Poisson-disk constraints.

**Parameters:**
- Gradient threshold: $\tau = 0.1$ (normalized magnitude) [S1, unofficial].
- Poisson-disk radius: $r = 2$ voxels [S1, unofficial].
- Uniform grid minimum spacing: $s_{min} = 2$ voxels [S1, unofficial].
- Edge share: 60% of the seed budget [S1, unofficial].
- Uniform share: 40% of the seed budget [S1, unofficial].

**Steps:**

1.  **Compute Gradients:**
    Calculate the Sobel gradient magnitude $G(i,j,k)$ for every voxel in $V$. Normalize $G$ to the range $[0, 1]$.

2.  **Calculate Seed Budget:**
    Determine the target number of seeds $N_{target}$:
    $$ N_{target} = \min\left(10,000, \max\left(100, \left\lfloor \frac{N_{vox}}{2^{1/D}} \right\rfloor \right)\right) $$
    [S1, unofficial]

3.  **Generate Edge Seeds (60% of budget):**
    a. Identify candidate voxels where $G(i,j,k) > \tau$.
    b. Apply gradient-weighted Poisson-disk sampling on these candidates with exclusion radius $r=2$.
       - For each candidate, check if any existing seed in the seed buffer is within distance $r$.
       - If no conflict, add the voxel to the seed buffer.
       - The "gradient-weighted" aspect implies higher gradient magnitudes have higher probability of selection or are processed first to ensure edge fidelity [S1, unofficial].
    c. Let $N_{edge}$ be the number of seeds selected. Cap $N_{edge}$ at $\lfloor 0.6 \times N_{target} \rfloor$.

4.  **Generate Uniform Seeds (40% of budget):**
    a. Calculate the required grid spacing $s$ to provide the remaining seeds:
       $$ N_{rem} = \lfloor 0.4 \times N_{target} \rfloor $$
       $$ s = \max\left(2, \left\lfloor \left( \frac{N_{vox}}{N_{rem}} \right)^{1/D} \right\rfloor \right) $$
       [S1, unofficial]
    b. Generate a regular 3D grid with spacing $s$.
    c. For each grid point, find the nearest voxel center in $V$.
    d. Add this voxel to the seed buffer if it is not already present (or sufficiently close to an existing edge seed, though the source implies distinct sets contributing to the total budget) [S1, unofficial].

5.  **Post-Processing:**
    The final count of retained seeds may be lower than $N_{target}$ due to post-fit culling (e.g., removing splats with negligible contribution) [S1, unofficial].

**Pseudocode:**

```python
def generate_seeds(volume, N_vox, D=3):
    # 1. Compute normalized Sobel gradient magnitude
    gradients = compute_sobel_magnitude(volume)
    gradients = gradients / max(gradients) # Normalize to [0,1]

    # 2. Calculate target count
    raw_target = floor(N_vox / (2 ** (1/D)))
    N_target = min(10000, max(100, raw_target))

    seeds = []
    exclusion_radius = 2
    threshold = 0.1

    # Helper: Check if position is too close to existing seeds
    def is_excluded(pos):
        for s in seeds:
            if distance(pos, s) <= exclusion_radius:
                return True
        return False

    # 3. Edge Seeds (60%)
    edge_budget = floor(0.6 * N_target)
    candidates = []
    for voxel in volume_voxels:
        if gradients[voxel] > threshold:
            candidates.append(voxel)
    
    # Gradient-weighted Poisson disk sampling
    # Sort candidates by gradient magnitude descending to prioritize edges
    candidates.sort(key=lambda v: gradients[v], reverse=True)
    
    edge_seeds_count = 0
    for cand in candidates:
        if edge_seeds_count >= edge_budget:
            break
        if not is_excluded(cand):
            seeds.append(cand)
            edge_seeds_count += 1

    # 4. Uniform Seeds (40%)
    rem_budget = floor(0.4 * N_target)
    if rem_budget > 0:
        # Calculate spacing
        spacing_raw = (N_vox / rem_budget) ** (1/D)
        spacing = max(2, floor(spacing_raw))
        
        # Generate uniform grid
        for x in range(0, volume_dims[0], spacing):
            for y in range(0, volume_dims[1], spacing):
                for z in range(0, volume_dims[2], spacing):
                    pos = (x, y, z)
                    # Map grid point to nearest voxel
                    voxel_pos = round_to_nearest_voxel(pos)
                    if not is_excluded(voxel_pos):
                        seeds.append(voxel_pos)
    
    return seeds
```

**Edge Cases and Pitfalls:**
- **Precision:** Normalization of gradients must be consistent across datasets.
- **Boundaries:** Poisson-disk sampling near volume boundaries may result in fewer seeds than budgeted if candidates are sparse.
- **Degenerate Input:** If $N_{vox}$ is very small, the target count defaults to 100 [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by gradient computation ($O(N_{vox})$) and Poisson-disk sampling. The sources note that single-pass implementations have a wall-time ratio of 0.70–1.75× compared to multi-pass, with a median of 1.07× [S1, unofficial].
- **Memory Complexity:** Requires storage for the gradient volume and the seed list. Seeding runs on GPU (CUDA, MPS) when available, leveraging parallel processing [S1, unofficial].
- **Strengths:** Efficiently captures high-frequency details (edges) while maintaining coverage of smooth areas. Scalable to large volumes via tiled fitting [S1, unofficial].
- **Limitations:** The final retained count may fall below the requested seed count after post-fit culling [S1, unofficial].

## Background
This method is primarily associated with the **Luxar** framework, which uses Gaussian splatting for microscopy and scalable interactive web visualization of multidimensional scientific data [S1, unofficial]. It was developed to handle the trade-off between visual fidelity and performance in large-scale scientific visualization.
