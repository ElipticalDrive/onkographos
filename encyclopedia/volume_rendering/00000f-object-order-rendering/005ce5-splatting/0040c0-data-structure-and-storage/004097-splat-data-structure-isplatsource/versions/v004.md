# Splat Data Structure (ISplatSource)
Also called: ISplatSource

## Overview
The Splat Data Structure (ISplatSource) is an abstract interface designed to load splat data asynchronously, returning a `LoadResult` upon completion [S1, unofficial]. It solves the problem of blocking the main thread during large asset ingestion by decoupling data loading from rendering [S1, unofficial]. It is distinguished from its siblings by providing the foundational asynchronous loading contract that `Splat Cloud Loading` implements for specific file formats and `LOD Download Manager` uses for prioritized network fetching .

## How it works
**Inputs and Outputs:**
The method takes no direct input parameters in its interface definition but requires a callback function to handle the result. The output is a `LoadResult` struct containing the loaded splat data, spherical harmonic degree, and error status.

**Data Structures:**
The core data structure is `LoadResult`, defined as follows:
- `splats`: `std::vector<SplatGPU>` - The container for the loaded splat primitives.
- `sh_degree`: `int` - The active spherical harmonic degree of the loaded data.
- `error`: `std::string` - A non-empty string if loading failed; empty if successful.
- `ok()`: A method returning `true` if `error` is empty.

The `SplatGPU` structure contains the geometric and photometric data for each splat. While the exact layout of `SplatGPU` is not fully detailed in the interface notes, the source indicates it includes spherical harmonic coefficients (`sh`) where `sh[0]` is the DC component and subsequent indices are non-DC coefficients [S1, unofficial].

**Steps:**
1. Initialize the `ISplatSource` instance.
2. Call `start(Callback cb)`, passing a callback function of type `std::function<void(LoadResult)>` [S1, unofficial].
3. The implementation performs asynchronous loading (e.g., file I/O, decompression) in the background.
4. Upon completion, the callback is invoked with a `LoadResult` object.
5. The caller checks `result.ok()`. If false, `result.error` contains the failure reason. If true, `result.splats` contains the data.

- `Callback`: A function pointer or lambda that handles the `LoadResult`.

**Edge Cases:**
- Network failures or file corruption result in a non-empty `error` string.
- The `SplatGPU` vector may be empty if the source file contains no splats.

## Subtopics

### [Splat Cloud Loading](13758-splat-cloud-loading.md)
An asynchronous method for loading 3D Gaussian Splat data from compressed files (`.spz` or `.ply`) off the main thread. It is distinguished by its support for Niantic's `.spz` format and integration with `SplatNode` for camera-relative sorting.

### [LOD Download Manager](14938-lod-download-manager.md)
A component that manages asynchronous, prioritized downloading of 3D Gaussian splat data organized in a Level of Detail hierarchy. It differs by dynamically adapting to predicted bandwidth and viewport position.

## Operating characteristics
**Time and Memory Complexity:**
Not given in the sources. The complexity depends on the concrete implementation (e.g., file size, network speed, decompression algorithm).

**Strengths and Limitations:**
- **Strengths:** Prevents UI thread blocking during large asset ingestion . Provides a standardized interface for asynchronous loading [S1, unofficial].
- **Limitations:** The abstract interface itself does not define the loading mechanism; performance depends on the specific implementation (e.g., `Splat Cloud Loading` or `LOD Download Manager`).

**When to Use:**
Use when loading large splat datasets that would otherwise block the main thread. Choose a specific implementation (e.g., `Splat Cloud Loading`) based on the data format and source (local file vs. network).

## Background
The `ISplatSource` interface is part of the splatting family, which treats volumetric data as a set of geometric or parametric primitives [G]. It is used in the `RVizSplat` project and related tools for loading 3D Gaussian Splat data [S1, unofficial]. The interface was developed to support asynchronous loading in ROS-based visualization tools.
