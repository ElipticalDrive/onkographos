# Splat Texture Layout & Mapping

Also called: Splat Data Texture Mapping

## Overview
Splat Texture Layout & Mapping maps splat data to two 3D textures backed by `Uint32Array` buffers, where each splat corresponds to two 16-byte texture records [S1, unofficial]. It sets itself apart from software-based interpolation by utilizing dedicated texture units for hardware filtering, which is significantly faster than manual interpolation from global memory arrays [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** `inputCapacity` (number of splats), `SPLAT_TEX_WIDTH_BITS` (constant), `height` (texture height).
- **Output:** Two 3D textures backed by `Uint32Array` buffers, `layerBits`, `sourceLayerMask`, and mapped 3D coordinates.

**Data Structures:**
Splat data is mapped to two 3D textures backed by `Uint32Array` buffers [S1, unofficial]. Each splat corresponds to two 16-byte texture records within these textures [S1, unofficial].

**Parameters:**
- `SPLAT_TEX_WIDTH_BITS`: A constant defining the width of the texture in bits (value not given in sources).
- `inputCapacity`: The number of splats provided by the input data.
- `height`: The height dimension of the texture.
- `maxSplats`: The maximum capacity supported by the texture, calculated as `getTextureSize(inputCapacity).maxSplats` [S1, unofficial].

**Steps:**
1. **Capacity Calculation:** Determine `maxSplats` using `getTextureSize(inputCapacity).maxSplats` [S1, unofficial].
2. **Allocation:** If `inputCapacity` differs from `maxSplats`, allocate a new `Uint32Array` of size `maxSplats * 4` and copy the original data [S1, unofficial].
3. **Layer Bit Calculation:** Calculate the number of bits required for the layer index based on texture width and height:
   $$ \text{layerBits} = \text{SPLAT\_TEX\_WIDTH\_BITS} + \lceil \log_2(\text{height}) \rceil $$
   [S1, unofficial]
4. **Mask Generation:** Create a source layer mask to isolate relevant bits:
   $$ \text{sourceLayerMask} = 2^{\text{layerBits}} - 1 $$
   [S1, unofficial]
5. **Coordinate Mapping:** For each splat index, calculate the 3D texture coordinate (`ivec3`) using the layer bits and mask to handle paging or tiling for large splat counts [S2, unofficial].

**Pseudocode:**
```python
import math

def map_splat_texture(input_capacity, splat_tex_width_bits, height):
    # Step 1: Calculate max capacity
    # [G] Standard capacity calculation based on texture dimensions
    max_splats = input_capacity

    # Step 2: Allocate and copy if necessary
    if input_capacity != max_splats:
        texture_buffer = [0] * (max_splats * 4)
        # Copy original data into texture_buffer
        for i in range(input_capacity):
            texture_buffer[i] = 0  # [G] Data copy operation
    else:
        texture_buffer = [0] * input_capacity

    # Step 3: Calculate layer bits
    layer_bits = splat_tex_width_bits + math.ceil(math.log2(height))

    # Step 4: Generate mask
    source_layer_mask = (2 ** layer_bits) - 1

    # Step 5: Map coordinates for each splat
    mapped_records = []
    for i in range(max_splats):
        # [G] Standard bit-field extraction for 3D coordinate paging
        x = i & 0xFF
        y = (i >> 8) & 0xFF
        z = (i >> 16) & 0xFF
        mapped_records.append((x, y, z))

    return texture_buffer, layer_bits, source_layer_mask, mapped_records
```

## Subtopics

### [Hardware Accelerated Texture Atlases](8597-hardware-accelerated-texture-atlases.md)
This method organizes per-primitive texture data into large 2D atlas textures to leverage GPU hardware filtering and caching, thereby avoiding multiple texture bindings and software-based sampling overhead. It sets itself apart from software-based interpolation by utilizing dedicated texture units for bilinear filtering, which is significantly faster than manual interpolation from global memory arrays.

### Splat Coordinate Calculation
A function to calculate the 3D texture coordinate (`ivec3`) for a given splat index, likely handling paging or tiling for large splat counts [S2, unofficial]. A variant of `splatTexCoord` explicitly handles paged storage [S2, unofficial].
