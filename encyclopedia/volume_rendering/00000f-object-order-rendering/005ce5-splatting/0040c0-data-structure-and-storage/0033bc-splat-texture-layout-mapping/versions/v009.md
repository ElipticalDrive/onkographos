# Splat Texture Layout & Mapping

Also called: Splat Data Texture Mapping

## Overview
This method defines the GPU-accessible memory layout for volumetric splat primitives, mapping discrete splat data into two 3D textures backed by `Uint32Array` buffers to enable efficient attribute fetching during rasterization [S1, unofficial]. It standardizes the storage structure so each splat occupies two 16-byte texture records [S1, unofficial].

## How it works
**Inputs:** Initial splat capacity and primitive data [S1, unofficial].
**Outputs:** Two 3D textures backed by `Uint32Array` buffers, containing the mapped splat data [S1, unofficial].

**Data Structures:**
Each splat corresponds to two 16-byte texture records within the 3D textures [S1, unofficial]. The total capacity is determined by `getTextureSize(inputCapacity).maxSplats` [S1, unofficial].

**Steps:**
1. Calculate the maximum splat capacity using `getTextureSize(inputCapacity).maxSplats` [S1, unofficial].
2. If the input capacity differs from `maxSplats`, allocate new `Uint32Array` buffers of size `maxSplats * 4` and copy the original data [S1, unofficial].
3. Compute the layer bits and source layer mask for coordinate mapping [S1, unofficial].
4. Map each splat index to a 3D texture coordinate `(ivec3)` [S2, unofficial].

**Formulas:**
The layer index within the 3D texture is derived from the splat's height and the texture width bits [S1, unofficial]:

$$
\text{layerBits} = \text{SPLAT\_TEX\_WIDTH\_BITS} + \lceil \log_2(\text{height}) \rceil
$$

$$
\text{sourceLayerMask} = 2^{\text{layerBits}} - 1
$$

**Parameters:**
* `SPLAT_TEX_WIDTH_BITS`: Not given in the sources.
* `height`: The height dimension used in the layer bits calculation [S1, unofficial].

**Edge Cases:**
* Capacity Mismatch: If the input capacity does not match the texture's maximum splat capacity, reallocation and copying are required [S1, unofficial].

**Pseudocode:**
```python
import math

def map_splat_data(input_capacity, input_data):
    # 1. Calculate maximum splat capacity
    max_splats = get_texture_size(input_capacity).max_splats
    
    # 2. Allocate and copy if capacity differs
    if input_capacity != max_splats:
        buffer_size = max_splats * 4
        texture_buffers = [[0] * buffer_size for _ in range(2)]
        texture_buffers[0][:len(input_data)] = input_data
        texture_buffers[1][:len(input_data)] = input_data
    else:
        texture_buffers = [[0] * (input_capacity * 4) for _ in range(2)]
        texture_buffers[0][:len(input_data)] = input_data
        texture_buffers[1][:len(input_data)] = input_data
        
    return texture_buffers

def calculate_layer_bits(height, splat_tex_width_bits):
    # 3. Compute layer bits and mask
    layer_bits = splat_tex_width_bits + math.ceil(math.log2(height))
    source_layer_mask = (1 << layer_bits) - 1
    return layer_bits, source_layer_mask

def calculate_splat_coordinate(splat_index, layer_bits, source_layer_mask):
    # 4. Map splat index to 3D texture coordinate (ivec3)
    # The exact bit-packing for x, y, z coordinates is not specified in the sources.
    # Standard practice decomposes the linear index into 3D coordinates.
    return (0, 0, 0)
```

## Operating characteristics
**Time and Memory Complexity:**
Memory usage is proportional to `maxSplats * 4` for the `Uint32Array` backing plus texture storage overhead [S1, unofficial]. Access time depends on texture sampling hardware efficiency [S1, unofficial].

**Measured Performance:**
Not given in the sources.

**Strengths and Limitations:**
* Strengths: Leverages GPU hardware filtering and caching; avoids multiple texture bindings and software-based sampling overhead [S1, unofficial].
* Limitations: Requires careful management of texture dimensions and capacity limits [S1, unofficial].

**When to Use:**
Use when efficient attribute fetching via hardware filtering is required and the scene size fits within texture volume constraints [S1, unofficial].

## Background
The method is used in GPU-accelerated splatting implementations to manage primitive data storage [G]. It is referenced in the `gaussian-splat-lite` library for streaming large scenes [S1, unofficial].
