# Single-Stage Splat Vertex Shader

Also called: MetalGaussianSplatRelighting Vertex Shader

## Overview
This method implements a single-stage vertex shader for splat rasterization that integrates deferred indirect lighting (IBL) and depth-based occlusion directly into the vertex processing stage [S1, unofficial]. It solves the problem of efficiently rendering large-scale Gaussian splats with physically-based relighting and AR scene occlusion on Metal GPUs [S1, unofficial]. It differs from standard splatting by performing lighting and occlusion checks per-vertex to modulate coverage and color before fragment generation, reducing fragment shader workload and enabling early discard of occluded primitives [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Instance ID, vertex ID, `amplificationID`, `v.normalRough`, `v.viewRefl`, `v.indirect`, `v.depth`, `v_base_color`, `v_ori_color`, `coverage`, `scene_depth_m`, `relight` struct, `uniforms_array`, `splat_index_array`, `chunks`, `k_max_view_count`, `inv_mw` [S1, unofficial].
- **Outputs:** Clip-space position, coverage, color (with lighting applied), depth [S1, unofficial].

**Data Structures:**
- `UniformsArray`: A constant buffer containing an array of `Uniforms` structs, indexed by `amplificationID` [S1, unofficial]. Fields: `indexedSplatCount`, `splatCount`, `chunkCount` [S1, unofficial].
- `splatIndexArray`: A constant buffer (`ChunkedSplatIndex`) mapping each splat ID to a `ChunkInfo` reference via `chunkIndex` [S1, unofficial].
- `chunks`: A device buffer storing per-chunk metadata (`ChunkInfo`), accessed via `idx.chunkIndex` [S1, unofficial].
- `prefilteredEnv`: A 3D texture (texturecube) storing prefiltered environment maps for specular relighting [S1, unofficial].
- `brdfLUT`: A 2D texture storing the pre-integrated BRDF lookup table for importance sampling [S1, unofficial].
- `irradianceEnv`: A 3D texture (texturecube) storing the irradiance environment map for diffuse relighting [S1, unofficial].

**Parameters:**
- `kMaxViewCount`: The maximum number of simultaneous views supported in the `UniformsArray` [S1, unofficial].

**Steps:**
1. Fetch uniforms from the `UniformsArray` buffer using the `amplificationID` clamped to `kMaxViewCount` [S1, unofficial].
2. Compute the global splat ID by multiplying the instance ID by the indexed splat count per view and adding the vertex ID divided by 4 [S1, unofficial].
3. Discard the primitive if the computed splat ID exceeds the total splat count by outputting a clip-space position of $(1, 1, 0, 1)$ [S1, unofficial].
4. Fetch the chunk index mapping from the `splatIndexArray` using the computed splat ID [S1, unofficial].
5. Discard the primitive if the chunk index exceeds the total chunk count [S1, unofficial].
6. Fetch the chunk metadata from the `chunks` buffer using the validated chunk index [S1, unofficial].
7. Extract normal and view direction from vertex attributes `v.normalRough` and `v.viewRefl`, then normalize them to $N$ and $V$ [S1, unofficial].
8. Compute roughness as $r = v.\text{normalRough}.a \times \text{invMW}$ and reflection strength as $s = v.\text{viewRefl}.a \times \text{invMW}$, where $\text{invMW}$ is the inverse material weight [S1, unofficial].
9. Compute indirect blended color as $\text{indirectBlended} = v.\text{indirect} \times \text{invMW}$ [S1, unofficial].
10. Apply tint if `relight.tint.w > 0.0` by preserving value using luminance weights $L = [0.2126, 0.7152, 0.0722]$ [S1, unofficial].
11. Shade using IBL deferred function: $\text{shaded} = \text{shadeIBLDeferred}(\text{baseColor}, \text{oriColor}, \text{indirectBlended}, N, V, r, s, \text{relight}, \text{prefilteredEnv}, \text{irradianceEnv}, \text{brdfLUT}, \text{iblSampler})$ [S1, unofficial].
12. If debug mode is enabled, return $\text{shaded} \times \text{coverage}$ with alpha $\text{coverage}$ [S1, unofficial].
13. Apply depth occlusion: if `relight.occlusionEnabled != 0` and scene depth $D_{\text{scene}} > 0.01$, linearize splat NDC depth to meters and compare with scene depth [S1, unofficial]. If splat is behind scene geometry, suppress coverage [S1, unofficial].

**Pseudocode:**
```python
def single_stage_splat_vertex_shader(instance_id, vertex_id, amplification_id, v_normal_rough, v_view_refl, v_indirect, v_depth, v_base_color, v_ori_color, coverage, scene_depth_m, relight, uniforms_array, splat_index_array, chunks, k_max_view_count, inv_mw):
    # Step 1: Fetch uniforms
    view_idx = min(amplification_id, k_max_view_count)
    uniforms = uniforms_array[view_idx]
    
    # Step 2: Compute global splat ID
    indexed_splat_count = uniforms.indexedSplatCount
    global_splat_id = instance_id * indexed_splat_count + (vertex_id // 4)
    
    # Step 3: Check splat count
    if global_splat_id > uniforms.splatCount:
        return (1.0, 1.0, 0.0, 1.0)
    
    # Step 4: Fetch chunk index
    chunk_info_ref = splat_index_array[global_splat_id]
    chunk_index = chunk_info_ref.chunkIndex
    
    # Step 5: Check chunk count
    if chunk_index > uniforms.chunkCount:
        return (1.0, 1.0, 0.0, 1.0)
    
    # Step 6: Fetch chunk metadata
    chunk_metadata = chunks[chunk_index]
    
    # Step 7-8: Extract and normalize vectors
    N = normalize(v_normal_rough[:3])
    V = normalize(v_view_refl[:3])
    
    # Step 9: Compute roughness and reflection strength
    roughness = v_normal_rough[3] * inv_mw
    refl_strength = v_view_refl[3] * inv_mw
    
    # Step 10: Compute indirect blended color
    indirect_blended = [x * inv_mw for x in v_indirect]
    
    # Step 11: Apply tint if enabled
    base_color = v_base_color
    ori_color = v_ori_color
    if relight.tint[3] > 0.0:
        lw = [0.2126, 0.7152, 0.0722]
        # [S1, unofficial] recolor_preserving_value implementation not provided in sources.
        base_color = recolor_preserving_value(base_color, relight.tint[:3], lw, relight.tint[3])
        ori_color = recolor_preserving_value(ori_color, relight.tint[:3], lw, relight.tint[3])
        
    # Step 12: Shade using IBL
    # [S1, unofficial] shade_ibl_deferred implementation not provided in sources.
    shaded = shade_ibl_deferred(base_color, ori_color, indirect_blended, N, V, roughness, refl_strength, relight, prefiltered_env, irradiance_env, brdf_lut, ibl_sampler)
    
    # Step 13: Debug mode
    if relight.debug_mode != 0:
        return (shaded, coverage)
    
    # Step 14: Depth occlusion
    effective_coverage = coverage
    if relight.occlusion_enabled and scene_depth_m > 0.01:
        splat_ndc = v_depth / coverage
        # [G] Standard perspective depth linearization to complete cut-off source snippet
        splat_depth_m = relight.depth_linearize.y / max(relight.depth_linearize.x, 1e-6)
        if splat_depth_m > scene_depth_m:
            effective_coverage = 0.0
            shaded = [0.0, 0.0, 0.0]
            
    return (v_position, v_depth), effective_coverage, shaded
```
