# Differentiable Forward Warping with Average Splatting

Also called: Average Splatting, Forward Warping

## Overview
Differentiable Forward Warping with Average Splatting is a technique for synthesizing dynamic scenes by warping a canonical volumetric representation (such as a voxel grid or radiance field) from a reference time step to a target time step using estimated deformation flows [S1]. It solves the "many-to-one" mapping issue inherent in forward warping—where multiple source voxels map to the same target location, such as when an object shrinks—by fusing these contributions using a weighted average via a trilinear kernel [S1]. Unlike standard forward warping which may leave holes in the "one-to-many" case (expansion), this method specifically addresses the density accumulation conflict, often paired with inpainting for missing regions [S1]. It distinguishes itself from sibling methods like [Differentiable Robot Rendering](15698-differentiable-robot-rendering-dr-robot.md) by focusing on temporal deformation of canonical fields rather than static multi-view consistency or specific robotic sensor models.

## How it works
**Inputs:**
*   Source voxel grid $\Vgrid{}{S}$ (e.g., canonical radiance field).
*   Deformation flow field $f_{\text{S}\rightarrow\text{T}}$ mapping source positions to target positions.
*   Target voxel grid indices $\mathbf{p}$.

**Outputs:**
*   Target voxel grid $\Vgrid{}{T}$ with values fused from the source.

**Data Structures:**
*   $\Vgrid{}{S}$ and $\Vgrid{}{T}$: 3D arrays indexed by integer coordinates $(x, y, z)$.
*   $f_{\text{S}\rightarrow\text{T}}[\mathbf{q}]$: A vector field where each entry at source index $\mathbf{q}$ is a 3D displacement vector $\in \mathbb{R}^3$.

**Algorithm:**
The warping function $\Vgrid{}{T} = \text{Fwarp}(\Vgrid{}{S}, f_{\text{S}\rightarrow\text{T}})$ is computed as follows:

1.  Initialize $\Vgrid{}{T}$ with zeros (or appropriate background).
2.  For each voxel $\mathbf{q}$ in the source grid $\Vgrid{}{S}$:
    a. Calculate the deformed position: $\mathbf{q}' = \mathbf{q} + f_{\text{S}\rightarrow\text{T}}[\mathbf{q}]$.
    b. Determine the integer target indices $\mathbf{p}$ that fall within the support of the reconstruction kernel centered at $\mathbf{q}'$.
    c. For each target voxel $\mathbf{p}$ in the support:
        i. Compute the fractional offset vector $\mathbf{u} = \mathbf{q}' - \mathbf{p}$.
        ii. Compute the trilinear kernel weight $b[\mathbf{u}]$.
        iii. Accumulate the weighted source value into the numerator and the weight into the denominator of $\Vgrid{}{T}[\mathbf{p}]$.
3.  Normalize $\Vgrid{}{T}[\mathbf{p}]$ by dividing the accumulated numerator by the accumulated denominator for all $\mathbf{p}$.

**Formulas:**
The value of a target voxel $\mathbf{p}$ is given by [S1]:

$$
\Vgrid{}{T}[\mathbf{p}] = \frac {\sum _{\forall \mathbf {q}\in \Vgrid {}{S}}b[\mathbf {u}]\cdot \Vgrid {}{S}[\mathbf {q}]}{\sum _{\forall \mathbf {q}\in \Vgrid {}{S}}^{}b[\mathbf {u}]}
$$

where the trilinear kernel weight $b[\mathbf{u}]$ is defined as [S1]:

$$
b[\mathbf {u}] = \prod _{i \in \{x,y,z\}} \text {max}(0, 1\!-\!\left |\mathbf {u}_i \right |)
$$

and the offset vector $\mathbf{u}$ is [S1]:

$$
\mathbf {u} = (\mathbf {q}+f_{\text {S}\rightarrow \text {T}}[\mathbf {q}]) - \mathbf {p}
$$

Here, $\mathbf{q}$ is the integer coordinate of a source voxel, $f_{\text{S}\rightarrow\text{T}}[\mathbf{q}]$ is the deformation flow vector at $\mathbf{q}$, $\mathbf{p}$ is the integer coordinate of a target voxel, and $\mathbf{u}_i$ is the $i$-th component of $\mathbf{u}$.

**Pseudocode:**
```python
def forward_warp_average_splatting(source_grid, flow_field, target_shape):
    """
    Warps source_grid to target_grid using average splatting.
    
    Args:
        source_grid: 3D array (H, W, D) or (X, Y, Z) containing source values.
        flow_field: 3D array of vectors (H, W, D, 3) containing displacement vectors.
        target_shape: Tuple (H, W, D) defining the output grid dimensions.
        
    Returns:
        target_grid: 3D array with warped values.
    """
    # Initialize accumulators
    numerator = np.zeros(target_shape)
    denominator = np.zeros(target_shape)
    
    # Iterate over all source voxels
    # Note: In practice, this is often implemented as a GPU kernel or 
    # vectorized operation. The loop below represents the logical accumulation.
    for q in np.ndindex(source_grid.shape):
        # Get source value and flow
        val = source_grid[q]
        flow = flow_field[q] # Vector (3,)
        
        # Calculate deformed position
        # q is integer index, flow is displacement
        deformed_pos = np.array(q, dtype=float) + flow
        
        # Determine bounding box of the kernel support
        # Trilinear kernel has support [-1, 1] in each dimension
        # So we need to check target indices p where |deformed_pos - p| <= 1
        p_min = np.floor(deformed_pos - 1.0).astype(int)
        p_max = np.ceil(deformed_pos + 1.0).astype(int)
        
        # Clip to target grid boundaries
        p_min = np.clip(p_min, 0, np.array(target_shape) - 1)
        p_max = np.clip(p_max, 0, np.array(target_shape) - 1)
        
        # Iterate over target voxels in the support
        for p in np.ndindex(*[range(p_min[i], p_max[i] + 1) for i in range(3)]):
            # Calculate fractional offset u
            u = deformed_pos - np.array(p, dtype=float)
            
            # Calculate trilinear weight b[u]
            # b[u] = max(0, 1 - |u_x|) * max(0, 1 - |u_y|) * max(0, 1 - |u_z|)
            weight = 1.0
            for i in range(3):
                weight *= max(0.0, 1.0 - abs(u[i]))
            
            # Accumulate
            numerator[p] += weight * val
            denominator[p] += weight
            
    # Normalize
    # Avoid division by zero
    denominator = np.where(denominator == 0, 1.0, denominator)
    target_grid = numerator / denominator
    
    return target_grid
```

**Parameters:**
*   Kernel support: Trilinear (support size 2x2x2 in terms of integer grid steps, covering the immediate 8 neighbors).
*   Flow estimation: The flow $f_{\text{S}\rightarrow\text{T}}$ is typically estimated to be smooth and continuous along the timeline [S1].

**Edge Cases and Pitfalls:**
*   **Many-to-One:** When multiple source voxels map to the same target voxel (e.g., object shrinking), average splatting correctly fuses them [S1].
*   **One-to-Many:** When one source voxel maps to multiple target voxels (e.g., object expanding), holes may appear in the target grid. The source notes indicate an inpaint network is used to handle this, but the specific algorithm for the inpaint network is not detailed in the provided text [S1].
*   **Boundary Conditions:** Source voxels near the boundary may warp outside the target grid bounds. The pseudocode handles this by clipping $p_{min}$ and $p_{max}$ to the target shape [G].

## Subtopics

### Forward Warping with Subpixel Offsets
A variant used in multi-view warping contexts (e.g., Depth Peeling) to handle warping seams caused by source texel enlargement in the novel view [S2]. It uses four subpixel samples (subpixel offsets) to avoid seams, as no simpler solution is known [S2]. It also extends the field of view for Depth Peeling by scaling the screen dimension by a constant factor (1.2) to handle corrupt periphery due to large view displacements and lack of source pixels at image boundaries [S2].

## Operating characteristics
*   **Complexity:** The complexity is proportional to the number of source voxels multiplied by the kernel support size (constant, 8 for trilinear). $O(N \cdot K)$ where $N$ is the number of source voxels and $K$ is the kernel footprint.
*   **Performance:** The method is differentiable, allowing gradients to flow back through the warping operation to the flow field and source grid, enabling end-to-end training [S1].
*   **Strengths:** Handles the many-to-one problem naturally without leaving artifacts or requiring complex conflict resolution logic beyond weighting. Ensures smooth flows by assuming continuous deformation [S1].
*   **Limitations:** Does not inherently solve the one-to-many problem (holes); requires additional inpainting or sampling strategies [S1]. Performance may degrade if the deformation field is highly discontinuous or if the kernel support is large.

## Background
The method was introduced in the context of novel view synthesis for dynamic scenes, specifically in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It builds on the concept of forward warping, which estimates deformation from a canonical time to another time step [S1]. The specific "average splatting" technique was proposed to address the many-to-one mapping issue in forward warping of voxel grids [S1].
