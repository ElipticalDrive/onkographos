# Differentiable Forward Warping with Average Splatting

Also called: Average Splatting, Forward Warping

## Overview
Differentiable Forward Warping with Average Splatting is a method for synthesizing dynamic scenes by warping a canonical voxel grid representation to a target time step using a learned deformation field [S1]. It solves the "many-to-one" mapping issue inherent in forward warping, where multiple source voxels map to the same target voxel (e.g., during object contraction), by fusing these values using a trilinear kernel [S1]. Unlike naive forward warping which leaves holes during expansion ("one-to-many"), this method specifically addresses the density collision problem, often requiring auxiliary inpainting for the remaining holes [S1]. It differs from sibling methods like Differentiable Robot Rendering by focusing on voxel-grid-based temporal deformation rather than depth-peeling-based view warping [S2].

## How it works
**Inputs:**
*   Source voxel grid $\Vgrid{}{S}$ (e.g., canonical radiance field).
*   Deformation flow field $f_{\text{S}\rightarrow\text{T}}$ mapping source positions to target positions.
*   Target voxel grid indices $\mathbf{p}$.

**Outputs:**
*   Target voxel grid $\Vgrid{}{T}$ with values fused from the source.

**Data Structures:**
*   $\Vgrid{}{S}$: 3D array of voxel values (radiance/density).
*   $f_{\text{S}\rightarrow\text{T}}$: 3D vector field where each entry at index $\mathbf{q}$ is a displacement vector $\mathbf{d} \in \mathbb{R}^3$.
*   $\Vgrid{}{T}$: 3D array of the same dimensions as $\Vgrid{}{S}$.

**Algorithm:**
1.  Initialize $\Vgrid{}{T}$ with zeros.
2.  Initialize a denominator accumulator grid $D$ with zeros (same dimensions as $\Vgrid{}{T}$).
3.  Iterate over every voxel index $\mathbf{q}$ in the source grid $\Vgrid{}{S}$:
    a.  Retrieve the source value $v_s = \Vgrid{}{S}[\mathbf{q}]$.
    b.  Retrieve the deformation vector $\mathbf{d} = f_{\text{S}\rightarrow\text{T}}[\mathbf{q}]$.
    c.  Calculate the continuous target position $\mathbf{p}_{\text{cont}} = \mathbf{q} + \mathbf{d}$.
    d.  Identify the 8 surrounding integer voxel indices $\mathbf{p}$ in the target grid that bound $\mathbf{p}_{\text{cont}}$.
    e.  For each neighbor $\mathbf{p}$:
        i.  Calculate the fractional offset $\mathbf{u} = \mathbf{p}_{\text{cont}} - \mathbf{p}$. Note: $\mathbf{u} \in [-0.5, 0.5]^3$ if $\mathbf{p}$ is the nearest integer, or generally $\mathbf{u}$ represents the distance from the integer grid point to the continuous position. Based on the formula definition $\mathbf{u} = (\mathbf{q}+f_{\text{S}\rightarrow\text{T}}[\mathbf{q}]) - \mathbf{p}$, $\mathbf{u}$ is the vector from the target integer grid point to the warped source position.
        ii. Compute the trilinear kernel weight $b[\mathbf{u}] = \prod_{i \in \{x,y,z\}} \max(0, 1 - |u_i|)$.
        iii. Add to the numerator accumulator: $\Vgrid{}{T}[\mathbf{p}] \leftarrow \Vgrid{}{T}[\mathbf{p}] + b[\mathbf{u}] \cdot v_s$.
        iv. Add to the denominator accumulator: $D[\mathbf{p}] \leftarrow D[\mathbf{p}] + b[\mathbf{u}]$.
4.  Normalize the target grid: For each voxel $\mathbf{p}$ where $D[\mathbf{p}] > 0$, compute $\Vgrid{}{T}[\mathbf{p}] = \Vgrid{}{T}[\mathbf{p}] / D[\mathbf{p}]$. For voxels where $D[\mathbf{p}] = 0$, the value remains 0 (or undefined, requiring inpainting).

**Formulas:**
The core warping operation is defined as [S1]:
$$
\Vgrid{}{T}[\mathbf{p}] = \frac {\sum _{\forall \mathbf {q}\in \Vgrid{}{S}}b[\mathbf {u}]\cdot \Vgrid{}{S}[\mathbf {q}]}{\sum _{\forall \mathbf {q}\in \Vgrid{}{S}}^{}b[\mathbf {u}]}
$$
where the weight function $b[\mathbf{u}]$ is [S1]:
$$
b[\mathbf {u}] = \prod \max(0, 1 - |\mathbf {u}_i |), \quad i \in \{x,y,z\}
$$
and the offset vector $\mathbf{u}$ is [S1]:
$$
\mathbf {u} = (\mathbf {q}+f_{\text {S}\rightarrow \text {T}}[\mathbf {q}]) - \mathbf {p}
$$
Here, $\mathbf{p}$ and $\mathbf{q}$ are integer indices of voxels in the target and source grids, respectively. $\mathbf{u} \in \mathbb{R}^3$ is the vector from the target voxel center $\mathbf{p}$ to the warped source position. $x, y, z$ denote the three spatial axes.

**Parameters:**
*   Trilinear kernel support: 1 unit (covers 8 neighbors).
*   Flow field $f_{\text{S}\rightarrow\text{T}}$: Typically learned or estimated from canonical time to target time [S1].

**Edge Cases and Pitfalls:**
*   **Many-to-one:** Multiple source voxels map to the same target voxel. Average splatting handles this by summing weighted values and dividing by the sum of weights [S1].
*   **One-to-many:** A single source voxel maps to multiple target voxels (e.g., expansion). This creates holes in the target grid where no source data contributes. The method requires an inpaint network to fill these missing positions [S1].
*   **Precision:** Floating point accumulation in the numerator and denominator grids is required to maintain differentiability and accuracy during the splatting process [S1].

## Subtopics

### Forward Warping with Subpixel Offsets
This variant, used in contexts like multi-view warping with depth peeling, addresses warping seams caused by source texel enlargement in the novel view [S2]. It handles conflicts where multiple fragments map to the same location using atomic depth tests against a custom depth buffer [S2]. To specifically avoid seams, it uses four subpixel samples (subpixel offsets) for reprojecting peeled fragments to pixel positions [S2]. Additionally, to handle corrupt periphery due to large view displacements and lack of source pixels at boundaries, it extends the field of view for Depth Peeling by scaling the screen dimension by a constant factor of 1.2 [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of source voxels and the kernel size (constant 8 neighbors for trilinear). The normalization step is linear with respect to the target grid size.
*   **Memory Complexity:** Requires storage for the source grid, target grid, flow field, and two accumulator grids (numerator and denominator) of the same size as the target grid.
*   **Strengths:** Handles the many-to-one problem naturally without leaving artifacts from overlapping voxels; differentiable with respect to the flow field and source values.
*   **Limitations:** Does not handle the one-to-many problem (holes) inherently; requires additional inpainting or rendering steps to fill gaps. Sensitive to large deformations if the flow field is not smooth.
*   **When to use:** Suitable for dynamic scene synthesis where temporal coherence is maintained via smooth flow fields, and voxel-based representations are used [S1].

## Background
The method was introduced in the context of novel view synthesis for dynamic scenes, specifically within the TrajectoryNeRF framework [S1]. It addresses the limitations of naive forward warping by proposing average splatting to fuse multiple values into one voxel, ensuring smooth flows along the timeline [S1]. The concept of forward warping with subpixel offsets and atomic depth testing for conflict resolution has also been applied in multi-view warping and potentially visible hidden-volume rendering contexts [S2].
