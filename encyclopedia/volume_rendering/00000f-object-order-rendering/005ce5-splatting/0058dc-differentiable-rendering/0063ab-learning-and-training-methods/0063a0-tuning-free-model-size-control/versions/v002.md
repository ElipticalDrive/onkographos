# Tuning-Free Model-Size Control


## Overview
Tuning-Free Model-Size Control enforces a strict primitive count budget during 3D Gaussian Splatting training, guaranteeing the final model contains exactly the user-specified number of primitives regardless of scene complexity [S1, unofficial]. Unlike MaskGaussian, which allows model size to vary by up to 7.8x across scenes, this method delivers the exact requested count in every instance by approaching the budget from above and applying a single terminal projection [S1, unofficial]. The resulting models are 2.2× smaller than MaskGaussian and 1.40× faster to render, with paired quality differences bounded to $[-0.076, +0.085]$ dB [S1, unofficial].

## How it works
The method replaces standard adaptive density control with a closed-loop controller that treats model size as a constrained optimization variable [S1, unofficial]. It manages the primitive population via multiplicative dual ascent on a log-domain error [S1, unofficial].

**Inputs and Outputs:**
*   **Input:** Target budget $B$ (exact desired primitive count) [S1, unofficial].
*   **Output:** Trained 3D Gaussian Splatting model containing exactly $B$ primitives [S1, unofficial].

**Data Structures:**
The method operates on the 3D Gaussian Splatting representation [S1, unofficial]. The controller maintains a scalar dual variable $\lambda$ and internal state variables for the control logic [S1, unofficial].

**Parameters:**
A fixed set of constants is applied unchanged across all experiments (13 scenes, 3 datasets, 2 seeds) [S1, unofficial]: gain, step bound, dead band, release ratio, initial multiplier, setpoint margin, and projection iteration count [S1, unofficial]. The user supplies only $B$ [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Initialize $\lambda$ using the `initial_multiplier` and set controller state [S1, unofficial].
2.  **Setpoint Definition:** Define setpoint $S$ above budget $B$ by `setpoint_margin` ($S = B + \text{margin}$) [S1, unofficial]. This ensures the population approaches from the recoverable side (overshoot), avoiding the one-way masking failure mode [S1, unofficial].
3.  **Training Loop:** For each step:
    a. Render the image and compute the loss [G].
    b. Compute error $e = N_{curr} - S$ [S1, unofficial].
    c. Update $\lambda$ via multiplicative dual ascent on log-domain error with asymmetric release, bounded by `step_bound` and `dead_band` [S1, unofficial].
    d. Apply $\lambda$ to density control: if $\lambda$ indicates oversize, mark primitives for deletion; if undersize, permit growth [S1, unofficial].
    e. Enforce a deletion floor to prevent removal below a threshold [S1, unofficial].
    f. Update $N_{curr}$ [S1, unofficial].
4.  **Terminal Projection:** After training converges, perform a single terminal projection onto $B$ to deliver exactly the requested primitives [S1, unofficial].

import math
import numpy as np

def tuning_free_model_size_control(gaussians, target_budget, params):
    # params: dict with gain, step_bound, dead_band, release_ratio,
    #         initial_multiplier, setpoint_margin, projection_iterations, training_steps
    lambda_val = params['initial_multiplier']
    setpoint = target_budget + params['setpoint_margin']
    current_count = len(gaussians)

    for step in range(params['training_steps']):
        # Standard differentiable rendering step updates gaussian parameters [G]
        render_and_backward(gaussians)

        # Log-domain error relative to setpoint
        log_error = math.log(max(current_count, 1e-6) / setpoint)

        # Multiplicative dual ascent with asymmetric release
        if abs(log_error) > params['dead_band']:
            if log_error > 0:  # Overshoot: increase pressure to delete
                lambda_val *= math.exp(params['gain'] * log_error)
                lambda_val = min(lambda_val, params['step_bound'])
            else:              # Undershoot: asymmetric release to allow growth
                lambda_val /= math.exp(params['release_ratio'] * abs(log_error))
                lambda_val = max(lambda_val, 1.0 / params['step_bound'])

        # Apply density control influenced by lambda
        gaussians, current_count = apply_density_control(
            gaussians, lambda_val, params['deletion_floor']
        )

    # Single terminal projection onto exact budget
    gaussians, current_count = project_to_budget(gaussians, target_budget)
    return gaussians

def apply_density_control(gaussians, lambda_val, deletion_floor):
    # Compute per-primitive contribution scores
    scores = compute_contribution_scores(gaussians)
    sorted_indices = np.argsort(scores)

    # Determine deletion count based on lambda
    delete_ratio = min(1.0, max(0.0, (lambda_val - 1.0) * 10.0))  # [G] scaling factor
    delete_count = max(0, int(len(gaussians) * delete_ratio))

    # Enforce deletion floor
    delete_count = min(delete_count, len(gaussians) - deletion_floor)

    # Remove lowest contribution primitives
    if delete_count > 0:
        remove_indices = set(sorted_indices[:delete_count])
        gaussians = [g for i, g in enumerate(gaussians) if i not in remove_indices]

    # Standard 3D-GS growth gated by lambda
    if lambda_val < 1.0:
        gaussians = standard_gaussian_growth(gaussians)

    return gaussians, len(gaussians)

def project_to_budget(gaussians, target):
    current = len(gaussians)
    if current > target:
        scores = compute_contribution_scores(gaussians)
        sorted_indices = np.argsort(scores)
        excess = current - target
        remove_indices = set(sorted_indices[:excess])
        gaussians = [g for i, g in enumerate(gaussians) if i not in remove_indices]
    elif current < target:
        scores = compute_contribution_scores(gaussians)
        top_indices = np.argsort(scores)[-1:][0]
        for _ in range(target - current):
            gaussians.append(clone_primitive(gaussians[top_indices]))
    return gaussians, len(gaussians)

**Edge Cases and Pitfalls:**
*   **Overshoot Recovery:** Naive dual ascent fails if the population crosses the budget early because masking is a "one-way door" [S1, unofficial]. The setpoint held above the budget ensures the population settles from the recoverable side [S1, unofficial].
*   **Undershoot:** Without the terminal projection, undershoots of up to 36% occur in naive controllers [S1, unofficial]. The terminal projection removes this failure entirely [S1, unofficial].
*   **Negative Results:** Weighting sparsity penalty by screen footprint and annealing the Gumbel temperature help when model size is free, but collapse once size is held fixed [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The controller adds minimal overhead to the standard training loop, primarily involving the dual variable update and the final projection [S1, unofficial]. The projection executes as a single pass at the end [S1, unofficial].
*   **Memory Complexity:** Memory usage is strictly bounded by the target budget $B$, unlike standard 3D-GS which can grow to millions of primitives [S1, unofficial]. Models are 2.2× smaller than MaskGaussian and 5.0× smaller than standard 3D-GS [S1, unofficial].
*   **Performance:** Models render 1.40× faster than MaskGaussian [S1, unofficial].
*   **Strengths:** Delivers exactly the requested number of primitives in every scene and seed without per-scene tuning [S1, unofficial].
*   **Limitations:** Quality difference is bounded but non-zero ($[-0.076, +0.085]$ dB vs MaskGaussian) [S1, unofficial]. Requires a final projection pass over the data [S1, unofficial].
*   **When to use:** Deployment constraints require a strict, predictable model size [S1, unofficial]. MaskGaussian's variability is unacceptable [S1, unofficial].

## Background
The method was introduced in "One Setting, Any Scene: Tuning-Free Model-Size Control for 3D Gaussian Splatting" [S1, unofficial]. It addresses the issue that 3D Gaussian Splatting's adaptive density control lacks a stopping criterion, routinely producing models with several million primitives [S1, unofficial]. Previous methods like MaskGaussian allowed size to vary significantly across scenes [S1, unofficial]. This work proposes a controller correct under the asymmetry of soft masking, using multiplicative dual ascent on a log-domain error [S1, unofficial].
