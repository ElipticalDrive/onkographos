# Linear Blend Skinning for Gaussian Splatting

Also called: Canonical LBS, Canonical to Observation Space Transformation, Forward Skinning, Linear Blend Skinning (LBS) for 3DGS Avatars

## Overview
Linear Blend Skinning (LBS) for Gaussian Splatting is a deformation technique that transforms 3D Gaussians from a canonical space to an observation space using skeleton-driven rigid joint transformations and learnable per-Gaussian skinning weights [S1, S2]. Unlike NeRF-based inverse skinning methods that map observation-space points to canonical space, this forward approach applies fixed skinning weights to transform Gaussian positions and rotations directly [S2]. It avoids pose blend shapes and template vertex deformation, relying instead on an MLP for pose-dependent deformations to handle inaccuracies in shape estimation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Canonical 3D Gaussian attributes (position $\mu_c$, rotation $r_c$, scale $s$, color, opacity), joint transformation matrices $M_{j,t}$ derived from a parametric body model (e.g., SMPL) for each training timestep $t$, and initial learnable skinning weights $w$ [S1, S2].
*   **Outputs:** Posed Gaussian attributes (position $\mu_o$, rotation $r_o$) ready for rasterization [S2].

**Data Structures:**
*   **Skinning Weights ($w$):** A vector of size $J$ (total number of joints) per Gaussian, optimized during training [S1, S2].
*   **Joint Transformation Matrices ($M_{j,t}$):** Precomputed rigid transformation matrices for each joint $j$ and timestep $t$, containing rotation $A_R(\theta_t)$ and translation components [S1, S2].

**Numbered Steps:**
1.  **Precompute Joint Transformations:** For each training timestep $t$, compute the rigid transformation matrix $M_{j,t}$ for every body joint $j$ based on pose parameters $\theta_t$ from the parametric mesh [S1, S2].
2.  **Optimize Skinning Weights:** Initialize learnable per-Gaussian skinning weights vector $w$ and optimize it via gradient descent [S1].
3.  **Activate and Normalize Weights:** Apply ReLU activation to each component $w_j$ to ensure non-negativity, then normalize the vector so components sum to 1 [S1].
4.  **Transform Position:** Compute the observation space position $\mu_o$ by applying the weighted sum of joint transformations to the canonical position $\mu_c$ [S2].
5.  **Transform Rotation:** Transform the canonical rotation $r_c$ to observation space rotation $r_o$ using the rotation component $A_R(\theta_t)$ of the combined transformation matrix [S2].

**Formulas:**
*   Normalized skinning weights: $w_j^{\text{final}} = \frac{\max(0, w_j)}{\sum_{k=1}^{J} \max(0, w_k)}$ [S1].
*   Posed position: $\mu_o = A(\theta_t) \cdot \mu_c = \sum_{k=1}^{J} W_k M_{k,t} \cdot \mu_c$, where $W_k$ are normalized weights and $M_{k,t}$ is the transformation matrix for joint $k$ [S2].
*   Posed rotation: $r_o = A_R(\theta_t) r_c$, where $A_R(\theta_t)$ is the rotation part of the blended transformation [S2].

**Parameters:**
*   **Learning Rate for MLP and Skinning Weights ($w$):** $1 \times 10^{-4}$ [S1].
*   **Learning Rate for Latent Codes ($l$):** $2.5 \times 10^{-3}$ [S1].
*   **Skinned Weights ($W$):** Static attributes of the Gaussian after training; not regressed per-frame [S2].
*   **Joint Transformation Matrices ($\theta_k$):** Pose parameters derived from the parametric human mesh (e.g., SMPL) [S2].

**Edge Cases and Pitfalls:**
*   **Negative Weights:** During optimization, skinning weights $w$ may become negative, requiring ReLU activation and normalization to ensure valid convex combination weights [S1].
*   **Pose Blend Shapes:** Pose blend shapes are explicitly excluded because shape estimation and obtained blend shapes may be inaccurate; an MLP handles pose-dependent deformations instead [S1].
*   **Template Vertex Deformation:** Not necessary as LBS is applied directly on canonical Gaussians [S1].

**Pseudocode:**
```python
def compute_posed_gaussian(canonical_pos, canonical_rot, skinning_weights_raw, joint_transforms):
    """
    canonical_pos: list of lists, shape (N, 3), canonical positions
    canonical_rot: list of lists, shape (N, 4), canonical rotations (quaternions)
    skinning_weights_raw: list of lists, shape (N, J), raw learnable skinning weights
    joint_transforms: list of J matrices, each shape (4, 4), representing M_{j,t}
    Returns: posed_pos (N, 3), posed_rot (N, 4)
    """
    import math
    N = len(canonical_pos)
    J = len(joint_transforms)
    
    # Step 2 & 3: Activate and Normalize Weights
    relu_weights = [[max(0.0, w) for w in row] for row in skinning_weights_raw]
    normalized_weights = []
    for i in range(N):
        s = sum(relu_weights[i])
        if s < 1e-8: s = 1e-8 # Guard against zero sum [G]
        normalized_weights.append([w / s for w in relu_weights[i]])
    
    posed_pos = [[0.0, 0.0, 0.0] for _ in range(N)]
    posed_rot = []
    
    for i in range(N):
        # Step 4: Transform Position
        pos_hom = canonical_pos[i] + [1.0]
        for j in range(J):
            M_j = joint_transforms[j]
            W_j = normalized_weights[i][j]
            transformed = [sum(M_j[r][c] * pos_hom[c] for c in range(4)) for r in range(3)]
            for r in range(3):
                posed_pos[i][r] += W_j * transformed[r]
        
        # Step 5: Transform Rotation
        # Blend rotation matrices for this Gaussian
        B = [[sum(normalized_weights[i][j] * joint_transforms[j][r][c] for j in range(J)) for c in range(3)] for r in range(3)]
        
        # Convert quaternion to rotation matrix
        q = canonical_rot[i]
        w, x, y, z = q[0], q[1], q[2], q[3]
        R_c = [[1-2*(y*y+z*z), 2*(x*y-w*z), 2*(x*z+w*y)],
               [2*(x*y+w*z), 1-2*(x*x+z*z), 2*(y*z-w*x)],
               [2*(x*z-w*y), 2*(y*z+w*x), 1-2*(x*x+y*y)]]
        
        # Apply blended rotation
        R_o = [[sum(B[r][k] * R_c[k][c] for k in range(3)) for c in range(3)] for r in range(3)]
        
        # Convert back to quaternion
        tr = R_o[0][0] + R_o[1][1] + R_o[2][2]
        if tr > 0:
            s = 0.5 / math.sqrt(tr + 1e-8)
            q_o = [0.25/s, (R_o[2][1]-R_o[1][2])*s, (R_o[0][2]-R_o[2][0])*s, (R_o[1][0]-R_o[0][1])*s]
        elif R_o[0][0] > R_o[1][1] and R_o[0][0] > R_o[2][2]:
            s = 2.0 * math.sqrt(1.0 + R_o[0][0] - R_o[1][1] - R_o[2][2] + 1e-8)
            q_o = [(R_o[2][1]-R_o[1][2])/s, 0.25*s, (R_o[0][1]+R_o[1][0])/s, (R_o[0][2]+R_o[2][0])/s]
        elif R_o[1][1] > R_o[2][2]:
            s = 2.0 * math.sqrt(1.0 + R_o[1][1] - R_o[0][0] - R_o[2][2] + 1e-8)
            q_o = [(R_o[0][2]-R_o[2][0])/s, (R_o[0][1]+R_o[1][0])/s, 0.25*s, (R_o[1][2]+R_o[2][1])/s]
        else:
            s = 2.0 * math.sqrt(1.0 + R_o[2][2] - R_o[0][0] - R_o[1][1] + 1e-8)
            q_o = [(R_o[1][0]-R_o[0][1])/s, (R_o[0][2]+R_o[2][0])/s, (R_o[1][2]+R_o[2][1])/s, 0.25*s]
        posed_rot.append(q_o)
        
    return posed_pos, posed_rot
```

## Subtopics

### [LBS Network Variants](19671-lbs-network-variants.md)
This family explores alternative mechanisms for computing skinning weights and deformations in Linear Blend Skinning for Gaussian Splatting, specifically comparing learned networks against deterministic template-based approaches. It addresses the limitations of fixed skinning weights by investigating whether conditioning on pose or using learned mappings improves reconstruction quality and reduces artifacts in animatable human avatars.

### INN-based View-to-Canonical Deformation
A method using an Invertible Neural Network (INN) to transform view space points to canonical space and learn skinning weights simultaneously, replacing iterative root-finding methods like Broyden's to speed up training. It transforms deformed space points $x_v$ to an initial canonical approximation $x_{\text{init}_c}$ using the nearest joint's one-hot vector $w'$ and posed skeleton $B_i$: $x_{\text{init}_c} = (\sum_{i=1}^{nb} w'_i \cdot B_i)^{-1} \cdot x_v$. It predicts skinning weight $w_s$ at canonical space from predicted canonical points $x'_c$ using network $G_{x_c \to w}^W$, then calculates final canonical points $x_c = (\sum_{i=1}^{nb} w_{s,i} \cdot B_i) \cdot x_v$. The INN $G_{v \to c}^{\text{INN}}$ is conditioned on per-frame 3D skeleton $J$, mapping view space to canonical space. Unlike TAVA and SNARF which use iterative Broyden's method for root finding involving expensive matrix inversions, this method uses INN for direct bijective mapping, resulting in time-efficient training. [S3]

## Operating characteristics
*   **Time Complexity:** $O(N \cdot J)$ per Gaussian per frame, where $N$ is the number of Gaussians and $J$ is the number of joints. The precomputation of joint transforms is $O(J)$ [S1, S2].
*   **Memory Complexity:** $O(N \cdot J)$ to store skinning weights. Joint transforms are $O(J)$ per timestep [S1, S2].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with the number of Gaussians and joints. Precomputing joint transforms improves efficiency during training [S1].
*   **Strengths:** Avoids inaccuracies from pose blend shapes; efficient precomputation of joint transforms; direct transformation of Gaussian attributes [S1, S2].
*   **Limitations:** Relies on the accuracy of the parametric body model (e.g., SMPL); skinning weights are static after training, limiting per-frame adaptability; negative weights must be handled via ReLU and normalization [S1, S2].
*   **When to use:** Real-time rendering of animatable avatars where pose-dependent deformations are handled by an MLP and rigid joint transformations are sufficient for the base deformation [S1].
*   **When not to use:** When high-fidelity non-rigid deformations beyond rigid joint transformations are required without additional MLP capacity, or when inverse mapping is preferred for specific rendering pipelines [S2].

## Background
Linear Blend Skinning for Gaussian Splatting was introduced in the context of human avatar modeling using 3D Gaussian Splatting. It builds on the SMPL body model and adapts LBS to work with canonical Gaussians. The method was proposed to address inaccuracies in pose blend shapes and template vertex deformation by using learnable skinning weights and an MLP for pose-dependent deformations [S1].
