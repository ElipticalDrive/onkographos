# LBS Network Variants

Also called: Backward LBS, Deterministic SMPL skinning, Learned forward LBS

## Overview
This family compares learned and deterministic mechanisms for computing skinning weights in Linear Blend Skinning for Gaussian Splatting [S1]. Learned forward LBS achieves the highest reconstruction quality (PSNR 31.6), while backward LBS (PSNR 29.5) and deterministic SMPL weights (PSNR 30.5) exhibit specific artifacts under certain poses or discretization [S1].

## Subtopics

### [Forward LBS Network](19756-forward-lbs-network.md)
Predicts learnable skinning weights for any query point in canonical space using a neural network, replacing fixed geometric weights. It operates directly on canonical points without requiring global canonicalization relative to the SMPL frame, and generally achieves higher reconstruction quality than deterministic baselines. Choose it when maximizing PSNR and avoiding discretized artifacts is prioritized over training complexity.

### Backward LBS
Conditions the skinning weight network on local body poses $\theta$ and canonicalizes query points using the SMPL global translation and rotation before querying the network [S1]. It has difficulties learning skinning weights for points far from the surface, resulting in artifacts under specific poses, and yields a PSNR of 29.5 [S1]. Choose it when pose-conditioned networks are required despite potential far-surface artifacts [S1].

### Deterministic SMPL weights
Uses nearest neighbor SMPL skinning weights derived from the template mesh [S1]. While avoiding network training, it causes discretized artifacts on the cloth surface and achieves a PSNR of 30.5 [S1]. Choose it when a fast, training-free baseline is needed despite discretization artifacts [S1].

## Background
The comparison originates from the ARAH (Animatable Volume Rendering of Articulated Human SDFs) paper, which ablates different LBS strategies to determine the optimal deformation method for Gaussian Splatting-based avatars [S1]. The network initialization uses meta-learning (Reptile) on skinning weights from the CAPE dataset, with resulting models fine-tuned on the ZJU-MoCap dataset [S1].
