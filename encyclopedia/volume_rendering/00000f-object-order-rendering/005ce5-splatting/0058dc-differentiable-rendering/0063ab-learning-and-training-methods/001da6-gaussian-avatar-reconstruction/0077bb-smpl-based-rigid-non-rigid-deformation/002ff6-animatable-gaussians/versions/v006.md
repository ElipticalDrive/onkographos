# Animatable Gaussians

## Overview
Animatable Gaussians reconstructs animatable 3D human avatars by binding 3D Gaussians to an SMPL-X parametric model [S1, unofficial]. It solves the problem of generating pose-dependent geometry by using explicit pose-conditioned offsets rather than implicit deformation fields [S1, unofficial]. It builds on [SMPL-based rigid/non-rigid deformation](8385-smpl-based-rigid-non-rigid-deformation.md) and differs from [Gaussian Avatar](1479-gaussian-avatar.md) and [3DGS-Avatar](1480-3dgs-avatar.md) by predicting explicit offsets [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** SMPL-X template and training images [S1, unofficial].
*   **Outputs:** A set of canonical 3D Gaussians and explicit pose-conditioned offset parameters or a deformation network [S1, unofficial].

**Data Structures:**
*   **Canonical Gaussians:** Stored in a flat array [G]. Each Gaussian $i$ stores position $\mathbf{p}_i \in \mathbb{R}^3$, covariance $\Sigma_i \in \mathbb{R}^{3 \times 3}$ (parameterized as rotation $\mathbf{R}_i \in \mathbb{R}^{3 \times 3}$ and scale $\mathbf{s}_i \in \mathbb{R}^3$), opacity $\alpha_i \in [0, 1]$, and spherical harmonics coefficients $\mathbf{c}_i$ [G].
*   **Deformation Parameters:** A network or parameter set $f_{def}$ that outputs residual offsets conditioned on pose and canonical position [S1, unofficial].

**Steps:**
1.  **Initialization:** Gaussians are initialized on the surface of the SMPL-X mesh in the canonical rest pose [S1, unofficial].
2.  **Rigid Deformation:** Canonical positions $\mathbf{p}_i$ are transformed using Linear Blend Skinning (LBS) [S1, unofficial]:
    $$ \mathbf{p}_{rigid} = \sum_{j=1}^{N_{bones}} w_{i,j} \mathbf{T}_j(\theta) \mathbf{p}_i $$
    where $w_{i,j}$ are skinning weights and $\mathbf{T}_j(\theta)$ are bone transformation matrices [S1, unofficial].
3.  **Non-Rigid Deformation:** Explicit pose-conditioned offsets $\Delta \mathbf{p}$ are predicted conditioned on the target pose $\theta$ and canonical position [S1, unofficial]. The final position is computed as $\mathbf{p}'_i = \mathbf{p}_{rigid} + \Delta \mathbf{p}$ [S1, unofficial].
4.  **Covariance Update:** The covariance matrix is transformed using the Jacobian $J$ of the deformation map with respect to the canonical position [G]:
    $$ \Sigma'_i = J \Sigma_i J^T + \sigma^2 I $$
    where $\sigma^2 I$ is a small regularization term to ensure positive definiteness [G].
5.  **Rendering:** The deformed Gaussians are rasterized and composited using differentiable 3D Gaussian Splatting [S1, unofficial].
6.  **Training:** Gaussian parameters and deformation offsets are optimized by minimizing $\mathcal{L} = \mathcal{L}_{L1} + \lambda \mathcal{L}_{MS-SSIM}$ between rendered and ground truth images [S1, unofficial], where $\mathcal{L}_{L1}$ is the L1 loss and $\mathcal{L}_{MS-SSIM}$ is the multi-scale structural similarity loss [S1, unofficial].

**Parameters:**
*   Learning rate: Not given in the sources [G].
*   Number of Gaussians: Not given in the sources [G].
*   Deformation network depth/width: Not given in the sources [G].

**Edge Cases:**
*   **Degenerate Poses:** Extreme poses may cause skinning weights to become unstable or the Jacobian to become singular [G].
*   **Precision:** Floating-point precision in Jacobian computation may affect gradient stability [G].

## Subtopics

### GSMs
GSMs generates animatable 3D humans using a model prior (SMPL) and generative adversarial networks [S2]. It builds multi-layer shells from the SMPL template and binds 3D Gaussians on these shells [S2]. Animatable 3D humans are efficiently generated by utilizing the differentiable rendering of 3DGS and the generative adversarial network of StyleGAN2 [S2].

## Operating characteristics
*   **Time Complexity:** Training time scales with the number of Gaussians and the complexity of the deformation network [G].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians and the size of the deformation parameters [G].
*   **Performance:** Not given in the sources [G].
*   **Strengths:** Explicit pose-conditioned offsets enable efficient deformation [S1, unofficial].
*   **Limitations:** Requires an SMPL-X rig and training data [S1, unofficial].

## Background
Animatable Gaussians is introduced as an avatar method using an SMPL-X rig with explicit pose-conditioned offsets [S1, unofficial]. It builds on the principles of SMPL-based rigid/non-rigid deformation and differentiable rendering [S1, unofficial]. The method is documented in surveys of 3D Gaussian Splatting variants [S1, unofficial].
