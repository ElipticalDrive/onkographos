# Normal Field Supervision via Rendering and Depth Derivatives

Also called: Lemma 2, Supervision of Normal Field

## Overview
This method supervises the learnable surface normal field of a 3D Gaussian Splatting representation by enforcing consistency between rendered normal maps and the image-derivative of the rendered depth map [S1]. It establishes a supervisory loss by comparing the normal estimated directly from Gaussian attributes against the normal estimated from the depth field [S1].

## How it works
### Inputs and Outputs
*   **Inputs:** 3D Gaussian Splatting representation containing Gaussians with learnable normals $n_i$ [S1]. Camera rays defined by origin $\mathbf{o}$ and direction $\mathbf{w}$ [S1].
*   **Outputs:** Supervision loss $\mathcal{L}_{\text{normal}}$ minimizing the angular difference between the two normal estimates [G].

### Data Structures
*   **Rendered Normal Map:** 2D array of 3D vectors $\mathbf{N}_{\text{rendered}}(u,v)$, computed via alpha-blending of Gaussian normals [S1].
*   **Rendered Depth Map:** 2D array of scalar depths $D(u,v)$, specifically the median depth [S1].
*   **Depth Derivative:** 2D array of 3D vectors $\mathbf{N}_{\text{depth}}$, computed from the spatial gradient of $D(u,v)$ [G].

### Steps
1.  **Render Normal Map:** Rasterize the Gaussian splats using alpha-blending to produce $\mathbf{N}_{\text{rendered}}$ [S1].
2.  **Render Median Depth:** Compute the median depth $D(u,v)$ for each pixel [S1].
3.  **Compute Depth Derivative:** Estimate the surface normal $\mathbf{N}_{\text{depth}}$ by taking the spatial gradient of $D(u,v)$ [S1].
4.  **Compute Loss:** Calculate the angular difference between $\mathbf{N}_{\text{rendered}}$ and $\mathbf{N}_{\text{depth}}$ [G].

### Formulas
The method uses the **median** free-flight distance $t^*_{o,w}$ for robustness against outliers, rather than the expectancy [S1]. The median depth $t$ is defined as the infimum of $t$ such that the transmittance $T_{\mathbf{o},\mathbf{w}}(t) \leq 0.5$ [S1]:

$$ \text{Median}_M(t_{\mathbf{o},\mathbf{w}}^*) = \inf \{ t \in [0, +\infty) : T_{\mathbf{o},\mathbf{w}}(t) \leq 0.5 \} $$

In point-based rendering, this is approximated as the depth $t^G_{o,w}$ of the first Gaussian along the ray where the accumulated transmittance drops to or below 0.5 [S1]. The rendered normal $\mathbf{N}_{\text{rendered}}$ is obtained by alpha-compositing the learnable normals $n_i$ of the splats [G]. The depth-derived normal $\mathbf{N}_{\text{depth}}$ is computed by taking the spatial gradient of the depth map $D(u,v)$ and converting it to world space [G].

### Pseudocode
```python
def compute_normal_supervision_loss(gaussians, camera, width, height):
    # Step 1: Render Normal Map via alpha-blending
    N_rendered = [[(0.0, 0.0, 0.0) for _ in range(width)] for _ in range(height)]
    for y in range(height):
        for x in range(width):
            ray = camera.get_ray(x, y)
            splats = sorted(gaussians, key=lambda s: dot(s.position - ray.origin, ray.direction))
            alpha_acc = 0.0
            N_acc = [0.0, 0.0, 0.0]
            for s in splats:
                alpha = s.alpha
                weight = alpha * (1.0 - alpha_acc)
                N_acc[0] += weight * s.normal[0]
                N_acc[1] += weight * s.normal[1]
                N_acc[2] += weight * s.normal[2]
                alpha_acc += weight
                if alpha_acc >= 1.0:
                    break
            denom = max(alpha_acc, 1e-6)
            N_rendered[y][x] = (N_acc[0]/denom, N_acc[1]/denom, N_acc[2]/denom)

    # Step 2: Render Median Depth Map
    D_median = [[0.0 for _ in range(width)] for _ in range(height)]
    for y in range(height):
        for x in range(width):
            ray = camera.get_ray(x, y)
            splats = sorted(gaussians, key=lambda s: dot(s.position - ray.origin, ray.direction))
            transmittance = 1.0
            median_depth = None
            for s in splats:
                if transmittance * (1.0 - s.alpha) <= 0.5:
                    median_depth = s.depth_along_ray
                    break
                transmittance *= (1.0 - s.alpha)
            if median_depth is None:
                median_depth = camera.far_plane # [G]
            D_median[y][x] = median_depth

    # Step 3: Compute Depth Derivative
    N_depth = [[(0.0, 0.0, 0.0) for _ in range(width)] for _ in range(height)]
    fx = camera.focal_length
    for y in range(1, height - 1):
        for x in range(1, width - 1):
            dx = D_median[y][x + 1] - D_median[y][x - 1]
            dy = D_median[y + 1][x] - D_median[y - 1][x]
            # Convert depth gradients to surface normal in camera space [G]
            n_cam = normalize((dx, dy, -2.0 * fx))
            # Transform to world space [G]
            N_depth[y][x] = tuple(camera.world_rotation @ n_cam)

    # Step 4: Compute Loss
    total_loss = 0.0
    count = 0
    for y in range(height):
        for x in range(width):
            dot_prod = dot(N_rendered[y][x], N_depth[y][x])
            dot_prod = max(-1.0, min(1.0, dot_prod))
            total_loss += 1.0 - dot_prod
            count += 1
    return total_loss / count

def dot(v1, v2):
    return v1[0]*v2[0] + v1[1]*v2[1] + v1[2]*v2[2]

def normalize(v):
    mag = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    return (v[0]/mag, v[1]/mag, v[2]/mag)
```

### Parameters
*   **Transmittance Threshold:** 0.5 [S1].
*   **Gradient Window:** Not given in the sources.

### Edge Cases and Pitfalls
*   **Specular/Transparent Regions:** Artifacts in the normal field correspond to under-reconstructed parts of the scene (e.g., specular spots, sky, background) [S1]. The depth derivative may be noisy or undefined in these regions.
*   **Outliers:** The method explicitly chooses median depth over expectancy to be robust to statistical outliers [S1].
*   **Orientation Ambiguity:** The normal derived from depth derivatives has an inherent sign ambiguity (inward vs outward) [G]. The learnable normals $n_i$ must be oriented consistently with the depth gradient direction, typically by flipping the depth-derived normal if the dot product with the rendered normal is negative.

## Subtopics

### [Learnable Normal Estimation with Pseudo-Normal Supervision](10917-learnable-normal-estimation-with-pseudo-normal-supervision.md)
This method assigns a learnable unit normal to each 3D Gaussian to replace noisy gradient-based estimates, preventing the optimization from overfitting to training lighting conditions by aligning rendered normals with geometry priors derived from expected depth gradients. It differs from pure gradient-based approaches by explicitly optimizing normal attributes per Gaussian and supervising them against pseudo-normals computed from expected depth.

## Operating characteristics
*   **Time Complexity:** Dominated by rasterization for normal and depth maps, $O(N)$ per pixel where $N$ is the number of splats [G]. Depth derivative computation is $O(1)$ per pixel [G].
*   **Memory Complexity:** Requires storing rendered normal and depth maps, $O(W \times H)$ per frame [G].
*   **Strengths:** Self-supervised; does not require ground-truth normals or external geometry. Robust to outliers via median depth [S1].
*   **Limitations:** Relies on depth map accuracy. Fails in textureless or specular regions where depth estimation is ambiguous. The "first Gaussian" approximation for median depth may be inaccurate if Gaussians are large or overlapping significantly [G].

## Background
Originating from "From Blobs to Spokes: High-Fidelity Surface Reconstruction via Oriented Gaussians" [S1], this method (Lemma 2) leverages the closed-form equation for transmittance to define a robust median depth. It builds on the observation that the derivative of the depth map estimates the normal of the expected visible surface [S1].
