# 3D Half-Gaussian Splatting Covariance Transformation and Regularization

Also called: 3D-HGS

## Overview
This method modifies the covariance structure of 3D Gaussians to enforce half-ellipsoid geometry, aligning the splats with surface normals to better model sharp transitions between object surfaces and empty space [S1]. It sets itself apart from sibling methods like [Hard and Soft Depth Regularization](9178-hard-and-soft-depth-regularization.md) by directly transforming the covariance matrix into a local basis defined by the surface normal, rather than relying solely on auxiliary loss terms or depth consistency constraints [S1]. This structural transformation reduces "dust" and noise artifacts common in standard 3D Gaussian Splatting [S1].

## How it works
**Inputs:**
*   $\Sigma$: The original $3 \times 3$ covariance matrix of a 3D Gaussian.
*   $n$: The surface normal vector at the Gaussian's center.

**Outputs:**
*   $\sigma$: The regularized $3 \times 3$ covariance matrix representing a half-Gaussian.

**Data Structures:**
*   `basis`: A $3 \times 3$ matrix where columns are the orthonormal vectors $v_1, v_2, n$.
*   `cov`: A $3 \times 3$ matrix representing $\Sigma$ in the basis coordinate system.
*   `sigma`: A $3 \times 3$ matrix representing the regularized covariance in the basis coordinate system.

**Parameters:**
*   Regularization interval: 5000 iterations [S1].
*   Scale factor for the normal component: $1/100$ [S1].
*   Opacity threshold for densification/pruning: $0.01$ [S1].
*   Initial opacity for half-Gaussians: $0.02$ [S1].

**Algorithm:**
The transformation projects the Gaussian onto the tangent plane defined by $n$, effectively creating a half-ellipsoid that is flattened along the normal direction [S1].

1.  **Normalize Normal:** Compute $n \leftarrow n / \|n\|$.
2.  **Construct Basis:**
    *   If $n_x = 0$ and $n_y = 0$:
        *   Set $v_1 = (1, 0, 0)$ and $v_2 = (0, 1, 0)$.
    *   Else:
        *   Compute $v_1 \leftarrow (n_y, -n_x, 0) / \|(n_y, -n_x, 0)\|$.
        *   Compute $v_2 \leftarrow (n \times v_1) / \|n \times v_1\|$.
    *   Construct `basis` by concatenating $v_1, v_2, n$ as columns: `basis` $= [v_1 | v_2 | n]$.
3.  **Transform to Basis:** Compute `cov` $= \text{basis}^T \cdot \Sigma \cdot \text{basis}$.
4.  **Compute Modified Diagonal/Off-Diagonal Terms:**
    *   $a' \leftarrow \text{cov}[0, 0] - \frac{\text{cov}[0, 2]^2}{\text{cov}[2, 2]}$
    *   $b' \leftarrow \text{cov}[0, 1] - \frac{\text{cov}[0, 2] \cdot \text{cov}[1, 2]}{\text{cov}[2, 2]}$
    *   $c' \leftarrow \text{cov}[1, 1] - \frac{\text{cov}[1, 2]^2}{\text{cov}[2, 2]}$
5.  **Construct Regularized Covariance in Basis:**
    *   Initialize `sigma` as a $3 \times 3$ zero matrix.
    *   Set `sigma`$[0, 0] = a'$, `sigma`$[0, 1] = b'$, `sigma`$[1, 0] = b'$, `sigma`$[1, 1] = c'$.
    *   Set `sigma`$[2, 2] = \min(a', c') / 100$.
    *   All other elements remain 0.
6.  **Transform Back to World Space:** Compute $\sigma = \text{basis} \cdot \text{sigma} \cdot \text{basis}^T$.
7.  **Apply Regularization:** Perform steps 1-6 every 5000 iterations [S1].
8.  **Opacity Adjustment:** During densification and pruning, use an opacity threshold of $0.01$ and reset half-Gaussian opacity to $0.02$ [S1].

**Pseudocode:**

```python
import numpy as np

def transform_covariance_to_half_gaussian(cov_matrix: np.ndarray, normal: np.ndarray) -> np.ndarray:
    """
    Transforms a 3D Gaussian covariance matrix into a half-Gaussian covariance
    aligned with the given surface normal.
    
    Args:
        cov_matrix: 3x3 numpy array, the original covariance matrix Sigma.
        normal: 3-element numpy array, the surface normal vector n.
        
    Returns:
        3x3 numpy array, the regularized covariance matrix sigma.
    """
    # 1. Normalize normal
    n = normal / np.linalg.norm(normal)
    
    # 2. Construct basis
    # Check for degenerate case where normal is aligned with Z-axis
    if np.isclose(n[0], 0.0) and np.isclose(n[1], 0.0):
        v1 = np.array([1.0, 0.0, 0.0])
        v2 = np.array([0.0, 1.0, 0.0])
    else:
        # v1 is perpendicular to n in the XY plane projection
        v1 = np.array([n[1], -n[0], 0.0])
        v1 = v1 / np.linalg.norm(v1)
        
        # v2 is orthogonal to both n and v1
        v2 = np.cross(n, v1)
        v2 = v2 / np.linalg.norm(v2)
        
    # Concatenate v1, v2, n as columns to form the basis matrix
    basis = np.column_stack((v1, v2, n))
    
    # 3. Transform covariance to basis coordinate system
    cov = basis.T @ cov_matrix @ basis
    
    # 4. Compute modified terms
    # Avoid division by zero if cov[2,2] is extremely small, though typically it represents variance along normal
    cov_22 = cov[2, 2]
    if np.isclose(cov_22, 0.0):
        cov_22 = 1e-8 # [G] Guard against division by zero
        
    a_prime = cov[0, 0] - (cov[0, 2]**2) / cov_22
    b_prime = cov[0, 1] - (cov[0, 2] * cov[1, 2]) / cov_22
    c_prime = cov[1, 1] - (cov[1, 2]**2) / cov_22
    
    # 5. Construct regularized covariance in basis space
    sigma_basis = np.zeros((3, 3))
    sigma_basis[0, 0] = a_prime
    sigma_basis[0, 1] = b_prime
    sigma_basis[1, 0] = b_prime
    sigma_basis[1, 1] = c_prime
    
    # The normal component is scaled down significantly to flatten the ellipsoid
    sigma_basis[2, 2] = min(a_prime, c_prime) / 100.0
    
    # 6. Transform back to world space
    sigma = basis @ sigma_basis @ basis.T
    
    return sigma
```

**Edge Cases and Pitfalls:**
*   **Degenerate Normal:** If the normal vector is parallel to the Z-axis ($n_x=0, n_y=0$), the standard cross-product method for finding $v_1$ fails. The algorithm explicitly handles this by setting $v_1=(1,0,0)$ and $v_2=(0,1,0)$ [S1].
*   **Division by Zero:** The calculation of $a', b', c'$ involves dividing by $\text{cov}[2, 2]$. If the Gaussian is already perfectly flat along the normal, this term could be zero. A small epsilon guard is recommended [G].
*   **Frequency:** The transformation is applied every 5000 iterations, not every step, to stabilize training [S1].

## Operating characteristics
*   **Time Complexity:** The transformation involves matrix multiplications ($3 \times 3$) and vector operations, which are $O(1)$ per Gaussian. However, it is applied only every 5000 iterations, reducing the per-step overhead [S1].
*   **Memory Complexity:** No additional significant memory is required beyond the existing Gaussian parameters [S1].
*   **Performance:** On the Mip-NeRF 360 dataset, 3D-HGS with an efficient rasterizer achieves 125 FPS and 29.66 PSNR using 3.8M kernels, compared to 3DGS which uses 3.2M kernels [S1]. On Tank & Dengin, it achieves 160 FPS and 24.45 PSNR with 1.8M kernels [S1]. On Tank & Blending, it achieves 126 FPS and 29.76 PSNR with 2.6M kernels [S1].
*   **Strengths:** Consistently outperforms original 3D Gaussian Splatting in PSNR and other metrics [S1]. Effectively eliminates dust and noise by enforcing geometric constraints [S1]. The efficient rasterizer significantly improves rendering speed [S1].
*   **Limitations:** Requires surface normals, which may need to be estimated or provided. The fixed interval of 5000 iterations may not adapt to rapid changes in geometry during early training [S1].
*   **When to Use:** When high-fidelity surface reconstruction is required and artifacts like "dust" or floating geometry are problematic. Particularly suitable for scenes with sharp boundaries [S1].

## Background
3D Half-Gaussian Splatting (3D-HGS) was introduced to address the limitations of standard 3D Gaussian Splatting in modeling sharp surface transitions. By transforming the covariance matrix into a half-ellipsoid aligned with surface normals, the method provides a more physically plausible representation of surfaces [S1]. It is evaluated against architectures such as Scaffold, mip-splatting, and MCMC [S1].
