# Align Your Gaussians (AYG)
## Overview
Align Your Gaussians (AYG) is a text-to-4D synthesis method that generates dynamic 3D Gaussian Splatting (3DGS) scenes from text prompts [S1][S2, unofficial]. It solves the problem of creating temporally consistent, deformable 3D content by endowing static 3DGS with dynamics via a deformation network [S2, unofficial]. It is distinguished from static 3D generation methods by its explicit modeling of motion through a text-to-video diffusion prior, and from other 4D methods like DreamGaussian4D by its use of a text-to-video model for motion capture rather than learning motion from a driving video [S1].

## How it works
**Inputs and Outputs:**
- Input: A text prompt describing the scene and its motion.
- Output: A set of 3D Gaussians with static attributes (position, scale, rotation, color, opacity) and a deformation field network that maps time to Gaussian attribute updates.

**Data Structures:**
- **Static 3DGS:** Standard 3D Gaussian representation. Positions $\mathbf{p}$, scales $\mathbf{s}$, rotations $\mathbf{q}$, colors $\mathbf{c}$, opacities $\alpha$. These are fixed after the first stage.
- **Deformation Field Network:** A neural network (architecture not specified in sources) that takes Gaussian indices and time $t$ as input, outputting displacement vectors or velocity fields to modulate the static Gaussians [S2, unofficial].

**Steps:**
The method operates in two distinct stages [S2, unofficial]:

1. **Static 3DGS Generation:**
   - Initialize a static 3DGS representation.
   - Optimize the static Gaussian attributes using Score Distillation Sampling (SDS) losses.
   - The SDS losses are derived from a text-to-image diffusion model (Stable Diffusion) and a multi-view consistent prior (MVDream) [S2, unofficial].
   - This stage establishes the base geometry and appearance [S2, unofficial].

2. **Dynamic Generation (Deformation Optimization):**
   - Freeze the static Gaussian attributes from Stage 1.
   - Optimize only the parameters of the deformation field network [S2, unofficial].
   - The optimization uses a **Video SDS Loss** based on a text-to-video diffusion model to enforce temporal consistency and motion dynamics [S2, unofficial].
   - To prevent temporal flickering and ensure high visual quality, **Image-based SDS** losses are applied to randomly selected frames during the dynamic optimization [S2, unofficial].

**Pseudocode:**

```python
# Stage 1: Static Initialization
gaussians = initialize_3dgs() # Positions, scales, rotations, colors, opacity
# Optimize static gaussians using SDS from Stable Diffusion and MVDream
for step in range(static_steps):
    loss = compute_sds_loss(gaussians, text_prompt, model=StableDiffusion)
    loss += compute_mvdream_loss(gaussians, text_prompt)
    optimize(gaussians, loss)

# Stage 2: Dynamic Deformation
deformation_net = DeformationNetwork() # Parameters to optimize
# Freeze static gaussians
gaussians.requires_grad = False

for step in range(dynamic_steps):
    t = sample_time()
    # Apply deformation to get dynamic view
    dynamic_gaussians = apply_deformation(gaussians, deformation_net, t)
    
    # Video SDS Loss for motion
    loss_video = compute_video_sds_loss(dynamic_gaussians, text_prompt, model=TextToVideoDiffusion)
    
    # Image-based SDS for quality on random frames
    if random_selection():
        loss_image = compute_image_sds_loss(dynamic_gaussians, text_prompt, model=StableDiffusion)
        loss = loss_video + loss_image
    else:
        loss = loss_video
        
    optimize(deformation_net, loss)
```

**Parameters:**
- **Text Prompt:** Describes the object and motion.
- **Diffusion Models:** Stable Diffusion (image), MVDream (multi-view), Text-to-Video Diffusion (motion) [S2, unofficial].
- **Loss Weights:** Not given in the sources.

**Edge Cases and Pitfalls:**
- **Temporal Inconsistency:** Without the image-based SDS on random frames, the video SDS loss alone may lead to flickering or quality degradation [S2, unofficial].
- **Deformation Field Capacity:** The sources do not specify the capacity of the deformation network; insufficient capacity may fail to capture complex motions.

## Subtopics

### [Conditional 3D Gaussian Splatting Generation](15578-conditional-3d-gaussian-splatting-generation.md)
Generates 3DGS conditioned on input images or text, focusing on static or single-view consistency, whereas AYG explicitly targets 4D dynamic synthesis.

## Operating characteristics
- **Time Complexity:** High, due to the iterative optimization of both static and dynamic components using multiple diffusion models (SDS) [S2, unofficial].
- **Memory Complexity:** Moderate, storing static Gaussians and the deformation network parameters [S2, unofficial].
- **Strengths:** Enables text-to-4D generation with explicit dynamic control via text prompts [S1].
- **Limitations:** Relies on heavy diffusion-based optimization (SDS), which is computationally expensive compared to feedforward methods [S2, unofficial].
- **When to use:** When text-driven 4D content generation is required and computational resources allow for iterative optimization.
- **When not to use:** For real-time applications or when feedforward generation is preferred.

## Background
AYG was introduced as a method to extend 3D Gaussian Splatting to 4D by incorporating deformation fields [S1][S2, unofficial]. It builds on the success of 3D generation using SDS [S2, unofficial]. It is cited in surveys of 3D editing and generation, highlighting its role in enabling text-to-4D synthesis and deformation [S1][S2, unofficial].
