# Spacetime Gaussian Feature Splatting

Also called: STG, Spacetime Gaussians

## Overview
Spacetime Gaussian Feature Splatting (STG) is a dynamic scene representation that extends 3D Gaussian Splatting to the 4D spacetime domain to model emerging, vanishing, and deforming content in real-time [S1]. It distinguishes itself from static 3D Gaussian Splatting by introducing time-dependent opacity and parametric motion/rotation, and from other dynamic methods like 4D Gaussians by using a polynomial motion model and neural features instead of spherical harmonics [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Multi-view video sequences (sparse point clouds from Structure-from-Motion at all timestamps).
*   **Output:** A set of Spacetime Gaussians (STGs) and a small Multi-Layer Perceptron (MLP) $\Phi$, enabling real-time novel view synthesis at arbitrary viewpoints and timestamps.

**Data Structures:**
Each STG $i$ stores the following parameters:
1.  **Spatial Opacity:** $\sigma_{is} \in \mathbb{R}$ (scalar).
2.  **Temporal Opacity:** $\sigma_{\tau i} \in \mathbb{R}$ (temporal scaling factor), $\mu_{\tau i} \in \mathbb{R}$ (temporal center).
3.  **Motion (Position):** Polynomial coefficients $\{b_{i,k}\}_{k=0}^{n_p}$ where $b_{i,k} \in \mathbb{R}^3$.
4.  **Rotation:** Polynomial coefficients $\{c_{i,k}\}_{k=0}^{n_q}$ where $c_{i,k} \in \mathbb{R}^4$ (quaternions).
5.  **Scaling:** $s_i \in \mathbb{R}^3$ (diagonal scaling vector, time-independent).
6.  **Features:** $f_{base} \in \mathbb{R}^3$, $f_{dir} \in \mathbb{R}^3$, $f_{time} \in \mathbb{R}^3$. Total feature dimension is 9.

**Parameters:**
*   Polynomial degree for motion: $n_p = 3$ [S1].
*   Polynomial degree for rotation: $n_q = 1$ [S1].
*   Optimizer: Adam [S1].

**Formulas:**
1.  **Temporal Opacity:**
    $$ \sigma_i(t) = \sigma_{is} \exp \left( -s_{\tau i} |t - \mu_{\tau i}|^2 \right) $$
    where $\sigma_{is}$ is the time-independent spatial opacity, $\mu_{\tau i}$ is the timestamp of maximum visibility, and $s_{\tau i}$ controls the effective duration [S1].

2.  **Time-Dependent Position:**
    $$ \mu_i(t) = \sum_{k=0}^{n_p} b_{i,k} (t - \mu_{\tau i})^k $$
    where $\mu_i(t)$ is the 3D position at time $t$ [S1].

3.  **Time-Dependent Rotation:**
    $$ q_i(t) = \sum_{k=0}^{n_q} c_{i,k} (t - \mu_{\tau i})^k $$
    where $q_i(t)$ is the quaternion at time $t$. The rotation matrix $R_i(t)$ is derived from $q_i(t)$ [S1].

4.  **Covariance Matrix:**
    $$ \Sigma_i(t) = R_i(t) S_i S_i^T R_i(t)^T $$
    where $S_i$ is a diagonal scaling matrix parameterized by $s_i$. $S_i$ is kept time-independent [S1].

5.  **2D Projection:**
    The 3D Gaussian is projected to 2D image space using the viewing transformation $W$ and projection matrix $K$:
    $$ \mu^{2D}_i = \left( K \left( \frac{W \mu_i(t)}{(W \mu_i(t))_z} \right) \right)_{1:2} $$
    $$ \Sigma^{2D}_i = (J W \Sigma_i(t) W^T J^T)_{1:2,1:2} $$
    where $J$ is the Jacobian of the projective transformation [S1].

6.  **2D Opacity:**
    $$ \alpha^{2D}_i = \alpha_i(t) \sqrt{\det(\Sigma^{2D}_i)} $$
    where $\alpha_i(t)$ is the 3D opacity at spacetime point $(x,t)$:
    $$ \alpha_i(t) = \sigma_i(t) \exp \left( -\frac{1}{2} (x - \mu_i(t))^T \Sigma_i(t)^{-1} (x - \mu_i(t)) \right) $$
    [S1].

7.  **Feature Splatting and Rendering:**
    Features $f_i(t)$ are splatted to image space and split into $F_{base}, F_{dir}, F_{time}$. The final color $I$ is computed by passing these features through a tiny MLP $\Phi$ along with the view direction $r$:
    $$ f_i(t) = [f_{base}, f_{dir}, (t - \mu_{\tau i})f_{time}]^T $$
    $$ I = F_{base} + \Phi(F_{dir}, F_{time}, r) $$
    [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize STGs using structure-from-motion sparse point clouds from all available timestamps [S1].
2.  **Feature Splatting:** For each frame and view, project STGs to 2D. Splat the features $f_i(t)$ to the image plane. Aggregate features per pixel.
3.  **Color Prediction:** For each pixel, extract aggregated $F_{base}, F_{dir}, F_{time}$ and view direction $r$. Compute color $I$ using the MLP $\Phi$ [S1].
4.  **Loss Calculation:** Compare rendered image $I$ with ground truth using L1 loss and D-SSIM loss [S1].
5.  **Optimization:** Update STG parameters ($\sigma_{is}, s_{\tau i}, \mu_{\tau i}, \{b_{i,k}\}, \{c_{i,k}\}, s_i, f_{base}, f_{dir}, f_{time}$) and MLP $\Phi$ using Adam optimizer via backpropagation [S1].
6.  **Density Control:** Perform aggressive pruning to reduce Gaussian count and model size [S1].
7.  **Guided Sampling (Optional/Iterative):**
    *   Wait until training loss is stable.
    *   Aggregate training errors patch-wise to identify regions with substantial errors.
    *   Use coarse depth maps of existing Gaussians to determine depth ranges for these patches.
    *   Sample new Gaussians uniformly along rays from the center of selected patches within the depth range, adding small noise to centers.
    *   Repeat this sampling process no more than 3 times [S1].

**Pseudocode:**

```python
import numpy as np

def compute_temporal_opacity(sigma_is, s_tau, mu_tau, t):
    """
    Computes temporal opacity sigma_i(t).
    """
    return sigma_is * np.exp(-s_tau * (t - mu_tau)**2)

def compute_position(b_coeffs, mu_tau, t):
    """
    Computes time-dependent position mu_i(t) using polynomial coefficients.
    b_coeffs: list of numpy arrays [b_0, b_1, ..., b_np], each shape (3,)
    """
    pos = np.zeros(3)
    for k, b_k in enumerate(b_coeffs):
        pos += b_k * (t - mu_tau)**k
    return pos

def compute_rotation(c_coeffs, mu_tau, t):
    """
    Computes time-dependent rotation quaternion q_i(t).
    c_coeffs: list of numpy arrays [c_0, c_1, ..., c_nq], each shape (4,)
    """
    quat = np.zeros(4)
    for k, c_k in enumerate(c_coeffs):
        quat += c_k * (t - mu_tau)**k
    # Normalize quaternion to ensure valid rotation
    quat = quat / np.linalg.norm(quat)
    return quat

def compute_covariance(quat, s_vec):
    """
    Computes covariance matrix Sigma = R S S^T R^T.
    s_vec: scaling vector (3,), S is diag(s_vec)
    """
    R = quaternion_to_rotation_matrix(quat)
    S = np.diag(s_vec)
    return R @ (S @ S.T) @ R.T

def project_gaussian(mu_3d, sigma_3d, W, K):
    """
    Projects 3D Gaussian to 2D image space.
    W: viewing transformation matrix
    K: projection matrix
    """
    # Homogeneous coordinates
    mu_h = np.append(mu_3d, 1.0)
    mu_view = W @ mu_h
    mu_proj = K @ mu_view
    mu_2d = mu_proj[:2] / mu_proj[2]
    
    # Jacobian J of projective transformation
    # J is 2x3 matrix derived from K and W
    J = compute_jacobian(K, W, mu_view)
    
    # 2D Covariance
    sigma_2d = J @ W @ sigma_3d @ W.T @ J.T
    # Take top-left 2x2 block
    sigma_2d = sigma_2d[:2, :2]
    
    return mu_2d, sigma_2d

def splat_features(stgs, camera_params, t):
    """
    Splat features to image space.
    Returns aggregated F_base, F_dir, F_time per pixel.
    """
    # Initialize buffers for F_base, F_dir, F_time
    # Assume image size H x W
    H, W = camera_params.image_size
    F_base = np.zeros((H, W, 3))
    F_dir = np.zeros((H, W, 3))
    F_time = np.zeros((H, W, 3))
    Alpha_accum = np.zeros((H, W))
    
    # Sort STGs by depth (z-coordinate in camera space)
    sorted_stgs = sort_by_depth(stgs, camera_params.W)
    
    for stg in sorted_stgs:
        # 1. Compute time-dependent properties
        sigma_t = compute_temporal_opacity(stg.sigma_is, stg.s_tau, stg.mu_tau, t)
        mu_3d = compute_position(stg.b_coeffs, stg.mu_tau, t)
        quat = compute_rotation(stg.c_coeffs, stg.mu_tau, t)
        sigma_3d = compute_covariance(quat, stg.s_vec)
        
        # 2. Project to 2D
        mu_2d, sigma_2d = project_gaussian(mu_3d, sigma_3d, camera_params.W, camera_params.K)
        
        # 3. Compute 2D opacity alpha_2D
        # alpha_2D = alpha_3D * sqrt(det(sigma_2D))
        # alpha_3D = sigma_t * exp(-0.5 * (x-mu)^T Sigma^-1 (x-mu))
        # We rasterize this Gaussian onto the image grid
        alpha_2d_map = rasterize_gaussian_2d(mu_2d, sigma_2d, sigma_t)
        
        # 4. Prepare features
        # f_i(t) = [f_base, f_dir, (t - mu_tau)*f_time]
        f_base = stg.f_base
        f_dir = stg.f_dir
        f_time = stg.f_time * (t - stg.mu_tau)
        
        # 5. Accumulate into buffers using alpha blending
        # I = sum(c_i * alpha_i * prod(1 - alpha_j))
        # We update F_base, F_dir, F_time and Alpha_accum
        # Note: This is a simplified accumulation; actual implementation uses efficient rasterization
        alpha_2d_flat = alpha_2d_map.flatten()
        alpha_accum_flat = Alpha_accum.flatten()
        
        # Contribution weight
        weight = alpha_2d_flat * np.prod(1 - alpha_accum_flat) # Approximation for single pass
        
        F_base += f_base * weight
        F_dir += f_dir * weight
        F_time += f_time * weight
        Alpha_accum += alpha_2d_flat * (1 - alpha_accum_flat) # Update alpha accumulation for next Gaussian
        
    return F_base, F_dir, F_time

def render(F_base, F_dir, F_time, view_direction):
    """
    Computes final color using MLP Phi.
    """
    # Concatenate features and view direction
    input_features = np.concatenate([F_base, F_dir, F_time, view_direction], axis=-1)
    # Apply MLP Phi
    color = mlp_phi(input_features)
    return color

def guided_sampling(error_map, coarse_depth_map, stgs):
    """
    Samples new Gaussians in areas with large errors.
    """
    # 1. Patch-wise aggregate errors
    patches = aggregate_errors_patchwise(error_map)
    
    # 2. Select patches with large errors
    selected_patches = select_large_error_patches(patches)
    
    new_stgs = []
    for patch in selected_patches:
        # 3. Determine depth range from coarse depth map
        depth_min, depth_max = get_depth_range(patch, coarse_depth_map)
        
        # 4. Sample ray from center of patch
        ray_origin, ray_direction = get_ray_from_patch_center(patch)
        
        # 5. Sample uniformly within depth range
        num_samples = 10 # Example number
        depths = np.linspace(depth_min, depth_max, num_samples)
        
        for d in depths:
            center = ray_origin + d * ray_direction
            # Add small noise
            center += np.random.normal(0, 0.01, 3)
            
            # Initialize new STG
            new_stg = initialize_stg(center)
            new_stgs.append(new_stg)
            
    return new_stgs
```

**Edge Cases and Pitfalls:**
*   **Scaling Matrix:** The scaling matrix $S_i$ is kept time-independent. Applying time-conditioned functions to $S_i$ did not observe improvement in rendering quality [S1].
*   **Sampling Frequency:** Guided sampling should be conducted no more than 3 times for the scenes in experiments to avoid overfitting or excessive noise [S1].
*   **Depth Range:** Coarse depth maps are used to limit the depth range for guided sampling to avoid sampling in excessively large or incorrect depth ranges [S1].

## Operating characteristics
*   **Time Complexity:** Training time is 40-60 minutes for a 50-frame sequence on a single NVIDIA A6000 GPU [S1].
*   **Memory Complexity:** Model size is compact, with 9 parameters per STG for features compared to 48 for 3-degree Spherical Harmonics [S1].
*   **Measured Performance:**
    *   140 FPS at 1352 × 1014 resolution on the Neural 3D Video Dataset [S1].
    *   66 FPS at 8K resolution on an Nvidia RTX 4090 GPU [S1].
*   **Strengths:** Real-time high-resolution rendering, compact model size, ability to model emerging/vanishing content, and adaptive scene structure representation [S1].
*   **Limitations:** Requires multi-view video input, guided sampling adds complexity to the training pipeline [S1].
*   **When to use:** When real-time dynamic view synthesis with high quality and compact storage is required [S1].
*   **When not to use:** For static scenes where standard 3D Gaussian Splatting is sufficient, or when single-view input is the only option [S1].

## Background
Spacetime Gaussian Feature Splatting was introduced by Zhan Li, Zhang Chen, Zhong Li, and Yi Xu from OPPO US Research Center and Portland State University in the paper 'Spacetime Gaussian Feature Splatting for Real-Time Dynamic View Synthesis' (arXiv:2312.16812v2, Apr 4 2024) [S1]. It builds on the success of 3D Gaussian Splatting [41] and addresses the challenges of dynamic scene representation by incorporating temporal components and neural features [S1].
