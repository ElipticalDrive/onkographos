# 3D Gaussian Splatting Rendering (Software)

Also called: 3D Gaussian Splatting (3DGS) Pipeline, 3D Gaussian Splatting Rendering Pipeline, Standard 3D Gaussian Splatting Rendering, Original 3DGS, Kerbl et al. pipeline

## Overview
3D Gaussian Splatting (3DGS) rendering is a novel view synthesis method that represents a 3D scene as a large collection of anisotropic 3D Gaussian ellipsoids, enabling fast, high-quality real-time rendering by rasterizing these projected primitives [S5]. It solves the bottleneck of volume rendering (e.g., NeRF) by replacing ray marching with a tile-based, differentiable software rasterization pipeline that projects Gaussians to screen space and alpha-composites them [S3, unofficial][S4]. It sets itself apart from its siblings by using a specific object-order sorting strategy followed by tile-based rasterization, distinct from the CPU-sorted instanced approach [2058-3d-gaussian-splatting-rendering-cpu-sorted-instanced.md] or the pure rasterization kernel focus [2812-3d-gaussian-splatting-rasterization.md].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ 3D Gaussian primitives, each defined by mean position $\mu \in \mathbb{R}^3$, scale $s \in \mathbb{R}^3$, rotation $q \in \mathbb{R}^4$ (quaternion), opacity $\alpha \in \mathbb{R}$, and spherical harmonics (SH) coefficients $c_{\ell m}$ for view-dependent color [S1][S3, unofficial][S4]. Camera parameters: view matrix $V$, projection intrinsics ($f_x, f_y, c_x, c_y$), near plane $z_{near}$, far plane $z_{far}$ [S6, unofficial].
*   **Output:** A 2D image buffer of color values $C_{final}$ and optionally depth/transmittance.

**Data Structures:**
The Gaussian data is typically stored in a Structure of Arrays (SoA) or Struct of Arrays format for cache efficiency during projection. A common layout includes:
*   `xyz`: `float32[N, 3]` – Mean positions [S6, unofficial].
*   `rot`: `float32[N, 4]` – Quaternions, normalized before rendering [S3, S6, unofficial].
*   `scale`: `float32[N, 3]` – Scales, exponentiated before rendering to ensure positivity [S3, S6, unofficial].
*   `opacity`: `float32[N, 1]` – Opacity values, sigmoided before rendering [S3, S6, unofficial].
*   `sh`: `float32[N, SH_dim]` – SH coefficients. For degree 3, $SH\_dim = 3 \times 16 = 48$ [S3, S6, unofficial].

**Steps:**

1.  **Initialization and Activation:**
    *   Normalize rotations: $q_{norm} = q / \|q\|$ [S6, unofficial].
    *   Exponentiate scales: $s_{eff} = \exp(s)$ [S3, S6, unofficial].
    *   Sigmoid opacity: $\alpha_{eff} = \sigma(\alpha) = 1 / (1 + e^{-\alpha})$ [S3, S6, unofficial].
    *   Construct 3D covariance matrix $\Sigma_{3D}$ from $R$ (derived from $q_{norm}$) and $S = \text{diag}(s_{eff})$:
        $$ \Sigma_{3D} = R S S^T R^T $$
        [S1][S3, unofficial][S4].

2.  **Near-Plane Culling:**
    *   Transform mean to camera space: $\mu' = V \mu$ [S3, unofficial][S7].
    *   Discard Gaussians where $\mu'_z < z_{near}$ (typically $0.01$) [S5][S6, unofficial].

3.  **Projection to Screen Space:**
    *   Transform $\Sigma_{3D}$ to camera space: $\Sigma' = V_{1:3, 1:3} \Sigma_{3D} V_{1:3, 1:3}^T$ [S3, unofficial][S7].
    *   Compute the Jacobian $J$ of the projective projection at $\mu'$:
        $$ J = \begin{pmatrix} \frac{f_x}{\mu'_z} & 0 & -\frac{f_x \mu'_x}{\mu'_z^2} \\ 0 & \frac{f_y}{\mu'_z} & -\frac{f_y \mu'_y}{\mu'_z^2} \end{pmatrix} $$
        [S2][S3, unofficial][S5]. Note: $J$ contains zero terms which can be optimized by hardware [S5].
    *   Compute 2D screen-space covariance: $\Sigma_{2D} = J \Sigma' J^T$ [S3, unofficial][S5, S7].
    *   Compute 2D mean:
        $$ \mu_{2D} = \begin{pmatrix} \frac{f_x \mu'_x}{\mu'_z} + c_x \\ \frac{f_y \mu'_y}{\mu'_z} + c_y \end{pmatrix} $$
        [S3, unofficial][S5].
    *   Convert $\Sigma_{2D}$ to conic representation $C$ to avoid repeated inversions during rasterization:
        $$ C = [\Sigma_{2D}^{-1}[0,0], \Sigma_{2D}^{-1}[0,1], \Sigma_{2D}^{-1}[1,1]] $$
        [S2][S3, S6, unofficial].
    *   Compute bounding box for rasterization tiles. The radius is typically truncated at $3.33\sigma$ [S3, unofficial]. The bounding box size in camera space is approximated by $3.0 \times \sqrt{\text{diag}(\Sigma_{2D})}$ [S6, unofficial].

4.  **Sorting:**
    *   Sort the remaining Gaussians by their camera-space depth $\mu'_z$ (or $\hat{\mu}_z$) in ascending order (front-to-back) [S3, unofficial][S5]. This approximates the correct occlusion order without per-pixel sorting [S3, unofficial].

5.  **Tile-Based Rasterization and Alpha Compositing:**
    *   Divide the image into tiles (e.g., $16 \times 16$ pixels) [S5][S6, unofficial].
    *   For each pixel $(u, v)$ in a tile, initialize accumulated color $C_{acc} = 0$ and transmittance $T = 1$ [S5].
    *   Iterate through Gaussians $i$ that overlap the pixel's tile and are in depth order:
        *   Evaluate 2D Gaussian density at pixel offset $\mathbf{x} = [u - \mu_{2D,x}, v - \mu_{2D,y}]^T$:
            $$ \alpha_{pixel} = \alpha_{eff,i} \cdot \exp\left(-\frac{1}{2} \mathbf{x}^T \Sigma_{2D,i}^{-1} \mathbf{x}\right) $$
            [S3, unofficial][S5, S8].
        *   Update color and transmittance:
            $$ C_{acc} \leftarrow C_{acc} + T \cdot \alpha_{pixel} \cdot c_i $$
            $$ T \leftarrow T \cdot (1 - \alpha_{pixel}) $$
            [S3, unofficial][S5].
        *   **Early Termination:** If $T < \tau$ (threshold), stop processing further Gaussians for this pixel [S5].
    *   Final color: $C_{final} = C_{acc} + T \cdot C_{bg}$, where $C_{bg}$ is the background color [S3, unofficial][S5].

**Pseudocode:**

```python
import numpy as np

def render_3dgs(gaussians, camera, image_width, image_height, tile_size=16, tau=1e-4):
    """
    Render 3D Gaussians using the standard software pipeline.
    
    Args:
        gaussians: Dict with keys 'xyz' (N,3), 'rot' (N,4), 'scale' (N,3), 
                   'opacity' (N,1), 'sh' (N, SH_dim).
        camera: Dict with 'view' (4,4), 'fx', 'fy', 'cx', 'cy', 'znear', 'zfar'.
        image_width, image_height: int.
        tile_size: int.
        tau: float, early termination threshold.
        
    Returns:
        image: (H, W, 3) float32 array.
    """
    N = gaussians['xyz'].shape[0]
    
    # 1. Activation Functions
    # Normalize rotations
    q = gaussians['rot'] / np.linalg.norm(gaussians['rot'], axis=1, keepdims=True)
    # Exponentiate scales
    s = np.exp(gaussians['scale'])
    # Sigmoid opacity
    alpha_raw = gaussians['opacity']
    alpha_eff = 1.0 / (1.0 + np.exp(-alpha_raw))
    
    # 2. Construct 3D Covariance
    # Build rotation matrix R from quaternion q
    R = quaternion_to_rotation_matrix(q) # Helper defined below
    S_diag = np.diag(s, axis1=-2, axis2=-1) # Diagonal matrix for each Gaussian
    # Sigma_3D = R @ S @ S^T @ R^T
    # Optimized: Sigma_3D = R @ (S @ S^T) @ R^T. Since S is diagonal, S @ S^T is diag(s^2)
    s_sq = s ** 2
    # Construct Sigma_3D efficiently
    # For each i, Sigma_3D[i] = R[i] @ diag(s_sq[i]) @ R[i].T
    # This is a batched operation.
    Sigma_3D = batched_covariance(R, s_sq)
    
    # 3. Camera Space Transformation
    view_mat = camera['view']
    # Transform means: mu' = V @ mu
    mu_homogeneous = np.concatenate([gaussians['xyz'], np.ones((N, 1))], axis=1)
    mu_cam = (view_mat @ mu_homogeneous.T).T[:, :3] # (N, 3)
    
    # Transform Covariance: Sigma' = V_1:3 @ Sigma_3D @ V_1:3^T
    V_3x3 = view_mat[:3, :3]
    Sigma_cam = batched_transform_covariance(Sigma_3D, V_3x3)
    
    # 4. Near-Plane Culling
    z_near = camera['znear']
    valid_mask = mu_cam[:, 2] >= z_near
    mu_cam = mu_cam[valid_mask]
    Sigma_cam = Sigma_cam[valid_mask]
    alpha_eff = alpha_eff[valid_mask]
    q_valid = q[valid_mask]
    s_valid = s[valid_mask]
    sh_valid = gaussians['sh'][valid_mask]
    
    N_valid = mu_cam.shape[0]
    if N_valid == 0:
        return np.zeros((image_height, image_width, 3))

    # 5. Projection
    fx = camera['fx']
    fy = camera['fy']
    cx = camera['cx']
    cy = camera['cy']
    
    mu_x = mu_cam[:, 0]
    mu_y = mu_cam[:, 1]
    mu_z = mu_cam[:, 2]
    
    # Jacobian J
    # J = [[fx/mu_z, 0, -fx*mu_x/mu_z^2],
    #      [0, fy/mu_z, -fy*mu_y/mu_z^2]]
    inv_mu_z = 1.0 / mu_z
    inv_mu_z_sq = inv_mu_z ** 2
    
    J_00 = fx * inv_mu_z
    J_02 = -fx * mu_x * inv_mu_z_sq
    J_11 = fy * inv_mu_z
    J_12 = -fy * mu_y * inv_mu_z_sq
    
    # Compute Sigma_2D = J @ Sigma_cam @ J^T
    # Sigma_cam is (N, 3, 3). J is (N, 2, 3).
    # We can compute this via batched matrix multiplication
    J_mat = np.zeros((N_valid, 2, 3))
    J_mat[:, 0, 0] = J_00
    J_mat[:, 0, 2] = J_02
    J_mat[:, 1, 1] = J_11
    J_mat[:, 1, 2] = J_12
    
    Sigma_2D = batched_matmul(J_mat, batched_matmul(Sigma_cam, np.transpose(J_mat, (0, 2, 1))))
    
    # 2D Means
    mu_2d_x = fx * mu_x * inv_mu_z + cx
    mu_2d_y = fy * mu_y * inv_mu_z + cy
    mu_2d = np.stack([mu_2d_x, mu_2d_y], axis=1) # (N, 2)
    
    # 6. Sorting
    # Sort by depth (mu_z)
    sort_indices = np.argsort(mu_z)
    mu_2d = mu_2d[sort_indices]
    Sigma_2D = Sigma_2D[sort_indices]
    alpha_eff = alpha_eff[sort_indices]
    sh_valid = sh_valid[sort_indices]
    mu_z_sorted = mu_z[sort_indices]
    
    # 7. Rasterization
    image = np.zeros((image_height, image_width, 3))
    
    # Precompute SH colors for all viewing directions? 
    # In standard 3DGS, SH evaluation is done per-pixel or per-tile based on view direction.
    # For simplicity, we assume view direction is constant or evaluated per pixel.
    # Here we evaluate SH color for each Gaussian based on its view direction from camera center.
    # Camera center in world space is inverse of view matrix.
    cam_center_world = np.linalg.inv(view_mat)[:3, 3]
    # View direction for each Gaussian: from cam_center to mu_cam (in world)
    # But SH is evaluated in camera space usually? No, SH coefficients are in world space or camera space?
    # Standard 3DGS: SH coefficients are optimized in world space, evaluated based on view direction in camera space.
    # Let's assume standard evaluation: c = SH_eval(sh, view_dir_cam)
    # View direction for Gaussian i: -mu_cam[i] (normalized)
    view_dirs = -mu_cam[sort_indices]
    view_dirs_norm = view_dirs / np.linalg.norm(view_dirs, axis=1, keepdims=True)
    
    # Evaluate SH colors
    colors = evaluate_sh(sh_valid, view_dirs_norm) # (N, 3)
    
    # Tile-based processing
    num_tiles_x = (image_width + tile_size - 1) // tile_size
    num_tiles_y = (image_height + tile_size - 1) // tile_size
    
    for ty in range(num_tiles_y):
        for tx in range(num_tiles_x):
            y_start = ty * tile_size
            y_end = min((ty + 1) * tile_size, image_height)
            x_start = tx * tile_size
            x_end = min((tx + 1) * tile_size, image_width)
            
            # Determine bounding box for tile in 2D space
            # We need to find which Gaussians cover this tile
            # Approximate bounding box of Gaussian i: mu_2d[i] +/- 3 * sqrt(diag(Sigma_2D[i]))
            # This is expensive to check for all N. 
            # In practice, a spatial index or bucketing is used. 
            # For this software implementation, we iterate all valid Gaussians and check overlap.
            
            tile_pixels_y = np.arange(y_start, y_end)
            tile_pixels_x = np.arange(x_start, x_end)
            pixel_coords = np.meshgrid(tile_pixels_x, tile_pixels_y, indexing='ij')
            # pixel_coords[0] is x, pixel_coords[1] is y
            
            # Initialize accumulators for this tile
            tile_acc = np.zeros((y_end - y_start, x_end - x_start, 3))
            tile_T = np.ones((y_end - y_start, x_end - x_start))
            
            for i in range(N_valid):
                # Check if Gaussian i overlaps with tile
                # Bounding box of Gaussian i
                sigma_xx = Sigma_2D[i, 0, 0]
                sigma_yy = Sigma_2D[i, 1, 1]
                radius_x = 3.0 * np.sqrt(sigma_xx)
                radius_y = 3.0 * np.sqrt(sigma_yy)
                
                min_x = mu_2d[i, 0] - radius_x
                max_x = mu_2d[i, 0] + radius_x
                min_y = mu_2d[i, 1] - radius_y
                max_y = mu_2d[i, 1] + radius_y
                
                # Check overlap with tile bounds
                if max_x < x_start or min_x >= x_end or max_y < y_start or min_y >= y_end:
                    continue
                
                # Compute conic inverse for this Gaussian
                # Sigma_2D[i] is 2x2. Invert it.
                # Sigma_2D[i] = [[a, b], [b, c]]
                a = Sigma_2D[i, 0, 0]
                b = Sigma_2D[i, 0, 1]
                c = Sigma_2D[i, 1, 1]
                det = a * c - b * b
                if det == 0:
                    continue # Singular
                inv_a = c / det
                inv_b = -b / det
                inv_c = a / det
                
                # Evaluate alpha for each pixel in tile
                # x_vec = [px - mu_2d[i,0], py - mu_2d[i,1]]
                # alpha = alpha_eff[i] * exp(-0.5 * x_vec^T @ Sigma_inv @ x_vec)
                
                # Vectorized over pixels in tile
                dx = tile_pixels_x[np.newaxis, :] - mu_2d[i, 0] # (1, W_tile)
                dy = tile_pixels_y[:, np.newaxis] - mu_2d[i, 1] # (H_tile, 1)
                
                # Quadratic form: a*dx^2 + 2*b*dx*dy + c*dy^2
                exponent = -0.5 * (inv_a * dx**2 + 2 * inv_b * dx * dy + inv_c * dy**2)
                
                # Clip exponent to avoid overflow
                exponent = np.clip(exponent, -100, 0)
                
                alpha_pixel = alpha_eff[i] * np.exp(exponent)
                
                # Update accumulators
                # Only update if alpha_pixel > 0 and T > tau
                # Vectorized update
                mask = tile_T > tau
                if not np.any(mask):
                    break # Early termination for entire tile
                
                # Update color and T
                # tile_acc[mask] += tile_T[mask][:, :, np.newaxis] * alpha_pixel[mask][:, :, np.newaxis] * colors[i][np.newaxis, np.newaxis, :]
                # tile_T[mask] *= (1 - alpha_pixel[mask])
                
                # Efficient update
                contrib = tile_T[:, :, np.newaxis] * alpha_pixel[:, :, np.newaxis] * colors[i][np.newaxis, np.newaxis, :]
                tile_acc += contrib
                tile_T *= (1 - alpha_pixel)
                
                # Check early termination for all pixels in tile
                if np.all(tile_T < tau):
                    break
            
            # Add background
            tile_acc += tile_T[:, :, np.newaxis] * camera.get('bg_color', np.array([0.0, 0.0, 0.0]))
            
            image[y_start:y_end, x_start:x_end, :] = tile_acc
            
    return image

def quaternion_to_rotation_matrix(q):
    # q is (N, 4), w, x, y, z
    w, x, y, z = q[:, 0], q[:, 1], q[:, 2], q[:, 3]
    N = q.shape[0]
    R = np.zeros((N, 3, 3))
    R[:, 0, 0] = 1 - 2*(y*y + z*z)
    R[:, 0, 1] = 2*(x*y - w*z)
    R[:, 0, 2] = 2*(x*z + w*y)
    R[:, 1, 0] = 2*(x*y + w*z)
    R[:, 1, 1] = 1 - 2*(x*x + z*z)
    R[:, 1, 2] = 2*(y*z - w*x)
    R[:, 2, 0] = 2*(x*z - w*y)
    R[:, 2, 1] = 2*(y*z + w*x)
    R[:, 2, 2] = 1 - 2*(x*x + y*y)
    return R

def batched_covariance(R, s_sq):
    # R: (N, 3, 3), s_sq: (N, 3)
    # Sigma = R @ diag(s_sq) @ R^T
    # diag(s_sq) @ R^T
    s_sq_expanded = s_sq[:, :, np.newaxis] # (N, 3, 1)
    R_T = np.transpose(R, (0, 2, 1)) # (N, 3, 3)
    # Element-wise multiply R_T by s_sq
    R_T_scaled = R_T * s_sq_expanded # (N, 3, 3)
    # R @ (R_T_scaled)
    Sigma = np.einsum('nij,njk->nik', R, R_T_scaled)
    return Sigma

def batched_transform_covariance(Sigma, V):
    # Sigma: (N, 3, 3), V: (3, 3)
    # Sigma' = V @ Sigma @ V^T
    # V @ Sigma
    Sigma_VT = np.einsum('ij,njk->nik', V, Sigma) # (N, 3, 3)
    # (V @ Sigma) @ V^T
    Sigma_cam = np.einsum('nij,njk->nik', Sigma_VT, np.transpose(V, (1, 0)))
    return Sigma_cam
```

#### Perspective-Correct 3D Gaussian Splat Evaluation
A differentiable method that avoids matrix inversion for numerical stability and eliminates special handling for degenerate splats [S9]. It provides fully perspective-correct rendering, unlike the affine approximation in standard 3DGS which causes distortion at close distances [S9]. It is implemented within a rasterization pipeline for real-time performance, unlike slower ray-tracing frameworks [S9].
#### Fisheye Camera Adaptation (Equidistant Projection)
Adapts rasterization for fisheye cameras using the equidistant projection model [S7]. It computes the 2D coordinate vector $\mathbf{x}_{2D}$ using intrinsic parameters $c_x, c_y, f_x, f_y$ and the equidistant formula involving sine and square roots of pixel offsets [S7].
#### 3D Gaussian Splatting on Mesh Surfaces
Attaches Gaussians onto the surface of a mesh, combining rendered results from a textured mesh and Gaussians to reduce the number of required Gaussians [S1].
#### RadSplat
Leverages robust NeRF initialization to generate a dense point cloud converted into Gaussians, avoiding SfM topological pitfalls [S10, unofficial]. Achieves 900+ FPS rendering [S10, unofficial].
#### 3D Gaussian Splatting with Motion Bases
Positions and rotations change over time, sharing motion coefficients with different bases, with regularization for sparsity and local rigidity [S1].
#### 3D Gaussian Splatting with Frequency-Domain Regularization
Applies frequency-domain regularization to the rendered image to encourage high-frequency detail recovery [S1].
#### 3D Gaussian Splatting with NFD
Utilizes the Generalized Normal Distribution (NFD) to sharpen scene edges [S1].
#### Don't Splat your Gaussians
Introduces volumetric ray-traced primitives with closed-form transmittance for efficient media rendering, addressing violations of physical absorption-emission models [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot T)$ where $N$ is the number of Gaussians and $T$ is the number of tiles/pixels. Sorting is $O(N \log N)$ [S3, unofficial].
*   **Memory Complexity:** $O(N)$ for storing Gaussian attributes. Unbounded scenes can require gigabytes of memory [S5].
*   **Performance:** Targets desktop GPUs for real-time rendering (e.g., 129 FPS Full HD) [S5]. Faces memory/bandwidth limits on mobile/AR-VR devices [S5].
*   **Strengths:** Fast real-time rendering, high-quality novel view synthesis, differentiable optimization [S3, unofficial][S5].
*   **Limitations:** Large model size, memory fragmentation during training, approximation errors from affine projection [S3, unofficial][S7].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. [37] as a novel view synthesis method using unnormalized 3D Gaussian point primitives [S3, unofficial]. It builds on Gaussian Splatting techniques [103] and differentiable point-based rendering [S4]. The method uses a tile-based, differentiable software rasterizer implemented in C++/CUDA [S3, unofficial]. Training typically involves 30,000 iterations with adaptive density control [S3, unofficial].
