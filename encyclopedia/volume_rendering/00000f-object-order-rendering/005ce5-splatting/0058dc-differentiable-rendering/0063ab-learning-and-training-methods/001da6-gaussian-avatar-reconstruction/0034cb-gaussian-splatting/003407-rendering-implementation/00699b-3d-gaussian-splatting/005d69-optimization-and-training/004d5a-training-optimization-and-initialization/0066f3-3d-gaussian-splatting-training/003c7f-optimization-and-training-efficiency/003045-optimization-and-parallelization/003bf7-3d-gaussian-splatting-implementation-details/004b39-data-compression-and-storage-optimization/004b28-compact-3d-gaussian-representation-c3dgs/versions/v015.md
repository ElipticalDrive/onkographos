# Compact 3D Gaussian Representation (C3DGS)
## Overview
Compact 3D Gaussian Representation (C3DGS) is a method for reducing the storage footprint and rendering latency of 3D Gaussian Splatting (3DGS) by exploiting spatial redundancy in scene attributes. It addresses the excessive memory usage of standard 3DGS, which stores high-dimensional per-Gaussian attributes, by replacing direct storage with a grid-based neural field for color and a codebook for geometry, while simultaneously pruning redundant Gaussians via a learnable mask. Unlike its sibling [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md) which focuses on clustering sensitivity, C3DGS explicitly separates geometric and appearance compression into distinct structural mechanisms (codebooks and hash grids) to achieve over 25× compression.
## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians $\{G_i\}$ initialized from a reconstruction process, each with position $\mathbf{p}_i$, scale $\mathbf{s}_i$, rotation $\mathbf{q}_i$, opacity $\alpha_i$, and spherical harmonic (SH) coefficients $\mathbf{c}_i$.
*   **Output:** A compact scene representation consisting of:
    1.  A binary mask vector $\mathbf{m}$ indicating active Gaussians.
    2.  A hash-based grid neural field $\mathcal{F}_{grid}$ for color prediction.
    3.  A geometry codebook $\mathcal{C}_{geo}$ containing prototype scale/rotation vectors.
    4.  Codebook indices $\mathbf{k}_i$ for each Gaussian.

**Data Structures:**
1.  **Mask $\mathbf{m}$:** A boolean array of size $N$ (number of Gaussians). $\mathbf{m}_i = 1$ if Gaussian $i$ is active, $0$ otherwise.
2.  **Hash Grid $\mathcal{F}_{grid}$:** Uses the Instant NGP hash grid structure [S1]. It maps 3D coordinates to a feature vector $\mathbf{f} \in \mathbb{R}^d$. The grid consists of multiple levels of hash tables mapping coordinate hashes to feature vectors.
3.  **Geometry Codebook $\mathcal{C}_{geo}$:** A set of $K$ prototype vectors. Each prototype $j \in \{1, \dots, K\}$ stores a scale vector $\mathbf{s}_j$ and a rotation quaternion $\mathbf{q}_j$. The size $K$ is small (e.g., hundreds), significantly smaller than $N$.
4.  **Indices $\mathbf{k}$:** An integer array of size $N$, where $\mathbf{k}_i \in \{1, \dots, K\}$ is the index of the codebook entry assigned to Gaussian $i$.

**Numbered Steps:**

1.  **Volume-Based Masking (Pruning):**
    During training, a learnable mask $\mathbf{m}$ is introduced. Gaussians with low contribution to the rendered image (determined by a threshold on opacity or gradient magnitude) are masked out ($\mathbf{m}_i = 0$). This reduces the effective number of Gaussians $N_{eff}$ without sacrificing visual quality [S1].

2.  **Grid-Based Color Compression:**
    Instead of storing SH coefficients $\mathbf{c}_i$ for each Gaussian, the view-dependent color is predicted by querying the hash grid $\mathcal{F}_{grid}$ at the Gaussian's position $\mathbf{p}_i$.
    *   Query $\mathcal{F}_{grid}(\mathbf{p}_i)$ to obtain a feature vector $\mathbf{f}_i$.
    *   Decode $\mathbf{f}_i$ through a small MLP to predict the SH coefficients $\hat{\mathbf{c}}_i$ for the current view direction.
    *   This replaces $O(N \cdot D_{SH})$ storage with $O(|\mathcal{F}_{grid}|)$, where $|\mathcal{F}_{grid}|$ is the size of the hash grid [S1].

3.  **Codebook-Based Geometry Compression:**
    Scale and rotation attributes are quantized to a codebook.
    *   **Initialization:** Initialize $\mathcal{C}_{geo}$ with $K$ random or k-means clustered prototypes of $(\mathbf{s}, \mathbf{q})$.
    *   **Assignment:** For each Gaussian $i$, find the closest codebook entry $j^*$ based on a distance metric $d(\mathbf{s}_i, \mathbf{q}_i, \mathbf{s}_j, \mathbf{q}_j)$. Store the index $\mathbf{k}_i = j^*$.
    *   **Update:** During training, update the codebook entries $\mathcal{C}_{geo}$ and the indices $\mathbf{k}_i$ to minimize the reconstruction error. The actual scale and rotation used for rendering are retrieved from $\mathcal{C}_{geo}[\mathbf{k}_i]$ [S1].

4.  **Rendering:**
    For each pixel, iterate over active Gaussians ($\mathbf{m}_i = 1$).
    *   Retrieve geometry from $\mathcal{C}_{geo}[\mathbf{k}_i]$.
    *   Predict color from $\mathcal{F}_{grid}(\mathbf{p}_i)$.
    *   Splat and composite as in standard 3DGS.

**Formulas:**
*   **Color Prediction:** $\hat{\mathbf{c}}_i = \text{MLP}(\mathcal{F}_{grid}(\mathbf{p}_i))$ [S1].
*   **Codebook Assignment:** $\mathbf{k}_i = \arg\min_{j} \| (\mathbf{s}_i, \mathbf{q}_i) - (\mathbf{s}_j, \mathbf{q}_j) \|^2$ [S1].
*   **Storage Reduction:** The storage is reduced from $O(N \cdot (D_{SH} + D_{geo}))$ to $O(N_{eff} \cdot (\log_2 K + D_{grid}))$, where $D_{grid}$ is the size of the grid features [S1].

**Parameters:**
*   **Grid Type:** Hash-based grid (Instant NGP) [S1].
*   **Codebook Size $K$:** Not given in the sources.
*   **Mask Threshold:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Precision:** The hash grid and codebook introduce quantization errors. The sources note that post-processing (quantization and entropy coding) further compresses the data, achieving over 25× compression [S1].
*   **Boundaries:** The hash grid must handle out-of-bounds queries gracefully. Not given in the sources.
*   **Degenerate Input:** If all Gaussians are masked out, rendering fails. A minimum number of active Gaussians should be enforced [G].

**Pseudocode:**
```python
def c3dgs_render(gaussians, grid, codebook, mask, view_direction):
    """
    Render a frame using C3DGS.
    
    Args:
        gaussians: List of Gaussian primitives with positions p_i.
        grid: Hash-based neural field function F_grid(p).
        codebook: List of (scale, rotation) tuples.
        mask: Boolean array indicating active Gaussians.
        view_direction: Camera view direction vector.
        
    Returns:
        Rendered image.
    """
    image = zeros_like(target_image)
    
    for i in range(len(gaussians)):
        if not mask[i]:
            continue
            
        p_i = gaussians[i].position
        alpha_i = gaussians[i].opacity
        
        # Retrieve geometry from codebook
        k_i = gaussians[i].codebook_index
        scale_i, rot_i = codebook[k_i]
        
        # Predict color from grid
        feature_i = grid(p_i)
        sh_coeffs_i = mlp_decode(feature_i) # Small MLP to decode SH from grid features
        color_i = evaluate_sh(sh_coeffs_i, view_direction)
        
        # Splat Gaussian with retrieved geometry and predicted color
        image += splat(p_i, scale_i, rot_i, alpha_i, color_i)
        
    return image

def c3dgs_train_step(gaussians, grid, codebook, mask, images, targets):
    """
    One training step for C3DGS.
    """
    # Forward pass
    rendered_images = c3dgs_render(gaussians, grid, codebook, mask, view_direction)
    
    # Compute loss
    loss = mse_loss(rendered_images, targets)
    
    # Backward pass
    # Update grid parameters
    grid.backward(loss)
    
    # Update codebook entries
    # Assign Gaussians to nearest codebook entry
    for i in range(len(gaussians)):
        if not mask[i]:
            continue
        p_i = gaussians[i].position
        s_i = gaussians[i].scale
        q_i = gaussians[i].rotation
        
        # Find closest codebook entry
        min_dist = infinity
        best_k = 0
        for j in range(len(codebook)):
            s_j, q_j = codebook[j]
            dist = distance((s_i, q_i), (s_j, q_j))
            if dist < min_dist:
                min_dist = dist
                best_k = j
        gaussians[i].codebook_index = best_k
        
        # Update codebook entry based on gradient
        codebook[best_k].backward(loss)
        
    # Update mask
    # Prune Gaussians with low contribution
    for i in range(len(gaussians)):
        if gaussians[i].contribution < threshold:
            mask[i] = False
            
    return loss
```
## Subtopics

### [Optimized Minimal 3D Gaussian Splatting (OMG)](13978-optimized-minimal-3d-gaussian-splatting-omg.md)
Optimized Minimal 3D Gaussian Splatting (OMG) is a method for compact 3D Gaussian representation that retains per-Gaussian parameterization for geometry (scale and rotation) to handle sparsity, while using a small neural field and Sub-Vector Quantization (SVQ) for appearance features to exploit local continuity. It achieves state-of-the-art storage compression (e.g., >300× relative to 3DGS in the bicycle scene) while maintaining high visual fidelity, building on [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md) by addressing the weakness of neural fields in sparse settings where neighboring Gaussians are further apart.

## Operating characteristics
*   **Time Complexity:** Rendering complexity is linearly proportional to the number of active Gaussians $N_{eff}$, which is reduced by the masking strategy [S1]. Grid queries are $O(1)$ on average due to hashing.
*   **Memory Complexity:** Storage is reduced by over 25× compared to 3DGS [S1]. The grid size is fixed and independent of $N$, while the codebook size $K$ is small.
*   **Measured Performance:** On the Deep Blending dataset, C3DGS achieves over 28× storage efficiency enhancement and nearly 40% increase in rendering speed compared to 3DGS, while outperforming it in PSNR [S1]. Across various datasets, it consistently shows about 15× reduced storage and enhanced rendering speed [S1].
*   **Strengths:** Significant storage reduction, faster rendering, high visual fidelity.
*   **Limitations:** Relies on spatial redundancy; may struggle with highly sparse or non-repetitive scenes where grid interpolation is inaccurate.
*   **When to use:** When storage and rendering speed are critical constraints and the scene exhibits spatial redundancy in color and geometry.
*   **When not to use:** For scenes with high geometric diversity and low spatial redundancy where codebook quantization errors are unacceptable.
## Background
C3DGS was proposed to address the critical memory and storage issues in 3D Gaussian Splatting, which often requires >1GB for large real-world scenes [S1]. It builds on the observation that current densification algorithms produce redundant Gaussians and that neighboring Gaussians share similar attributes. The method uses a hash-based grid representation (Instant NGP) for color and a codebook for geometry [S1].
