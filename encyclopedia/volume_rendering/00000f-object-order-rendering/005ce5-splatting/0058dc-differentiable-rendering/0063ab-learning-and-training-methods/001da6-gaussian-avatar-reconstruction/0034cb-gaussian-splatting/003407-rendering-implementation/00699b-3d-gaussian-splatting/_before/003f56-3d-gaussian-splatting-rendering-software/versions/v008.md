# 3D Gaussian Splatting Rendering (Software)

Also called: 3D Gaussian Splatting (3DGS) Pipeline, 3D Gaussian Splatting Rendering Pipeline, Standard 3D Gaussian Splatting Rendering, Original 3DGS, Kerbl et al. pipeline

## Overview
3D Gaussian Splatting (3DGS) rendering is a software-based rasterization method that represents a 3D scene as a collection of anisotropic Gaussian ellipsoids, enabling real-time novel view synthesis by projecting these primitives to screen space and alpha-compositing them [S3, unofficial][S5]. It distinguishes itself from volume rendering techniques like NeRF by using explicit, differentiable point primitives and from hardware-accelerated ray tracing by relying on a tile-based, object-order rasterization pipeline that approximates perspective projection via a local Jacobian [S3, unofficial][S5].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ 3D Gaussian primitives, each defined by mean $\mu \in \mathbb{R}^3$, covariance $\Sigma \in \mathbb{R}^{3 \times 3}$, opacity $\alpha \in [0, 1]$, and spherical harmonics (SH) coefficients for view-dependent color $c$ [S3, S6, unofficial].
*   **Output:** A 2D image buffer containing the accumulated color $C$ and optionally transmittance $T$ for each pixel [S3, unofficial][S5].

**Data Structures:**
The Gaussian data is typically stored in a Structure of Arrays (SoA) layout for efficient vectorization [S6, unofficial]:
*   `xyz`: `float32[N, 3]` – World-space means.
*   `rot`: `float32[N, 4]` – Quaternions representing rotation.
*   `scale`: `float32[N, 3]` – Log-space scales.
*   `opacity`: `float32[N, 1]` – Log-space opacities.
*   `sh`: `float32[N, SH_dim]` – SH coefficients (e.g., degree 3 implies $3 \times 16 = 48$ coefficients) [S3, S6, unofficial].

**Parameters:**
*   Camera intrinsics: focal lengths $f_x, f_y$, principal point $c_x, c_y$ [S3, unofficial].
*   Camera extrinsics: World-to-camera transformation matrix $W \in \mathbb{R}^{4 \times 4}$ [S3, unofficial].
*   Near plane $z_{near} = 0.01$, Far plane $z_{far} = 100.0$ [S6, unofficial].
*   Tile size: $16 \times 16$ pixels [S5].
*   Early termination threshold $\tau$ [S5].
*   Bounding box multiplier: $3.0$ (representing $3\sigma$ extent) [S6, unofficial].

**Steps:**

1.  **Activation and Covariance Construction:**
    *   Normalize rotations: $q_{norm} = q / \|q\|$ [S3, unofficial].
    *   Exponentiate scales to ensure positivity: $s_{eff} = \exp(s)$ [S3, unofficial].
    *   Sigmoid opacities: $\alpha_{eff} = \sigma(\alpha)$ [S3, unofficial].
    *   Construct 3D covariance: $\Sigma_{3D} = R S S^T R^T$, where $R$ is the rotation matrix derived from $q_{norm}$ and $S = \text{diag}(s_{eff})$ [S3, unofficial].

2.  **Camera Space Transformation:**
    *   Transform means to camera space: $\mu' = W \mu$ (using homogeneous coordinates) [S3, unofficial].
    *   Transform covariance to camera space using the upper-left $3 \times 3$ submatrix of $W$ (denoted $W_{1:3, 1:3}$):
        $$ \Sigma' = W_{1:3, 1:3} \Sigma_{3D} W_{1:3, 1:3}^T $$
        [S3, unofficial].

3.  **Projection to Screen Space:**
    *   Compute the Jacobian $J$ of the projective projection at $\mu'$:
        $$ J = \begin{pmatrix} \frac{f_x}{\mu'_z} & 0 & -\frac{f_x \mu'_x}{\mu'_z^2} \\ 0 & \frac{f_y}{\mu'_z} & -\frac{f_y \mu'_y}{\mu'_z^2} \end{pmatrix} $$
        [S3, unofficial][S5]. Note: $J$ contains zero terms which can be optimized by hardware [S5].
    *   Compute the 2D screen-space covariance:
        $$ \Sigma_{2D} = J \Sigma' J^T $$
        [S3, unofficial][S5].
    *   Compute the 2D mean:
        $$ \mu_{2D} = \begin{pmatrix} \frac{f_x \mu'_x}{\mu'_z} + c_x \\ \frac{f_y \mu'_y}{\mu'_z} + c_y \end{pmatrix} $$
        [S3, unofficial].

4.  **Culling and Sorting:**
    *   **Culling:** Discard Gaussians where $\mu'_z < z_{near}$ or outside the view frustum [S5].
    *   **Sorting:** Sort remaining Gaussians by camera-space depth $\mu'_z$ to approximate front-to-back order [S3, unofficial][S5]. This object-level sorting is an approximation to avoid prohibitively slow per-pixel sorting [S3, unofficial].

5.  **Rasterization and Compositing:**
    *   Divide the image into tiles (e.g., $16 \times 16$) [S5].
    *   For each pixel, identify covering Gaussians. The alpha contribution at pixel offset $\mathbf{x}$ from $\mu_{2D}$ is:
        $$ \alpha_{pixel} = \alpha_{eff} \cdot \exp\left(-\frac{1}{2} (\mathbf{x} - \mu_{2D})^T \Sigma_{2D}^{-1} (\mathbf{x} - \mu_{2D})\right) $$
        [S3, unofficial]. Truncation is typically applied at $\approx 3.33\sigma$ [S3, unofficial].
    *   Accumulate color using front-to-back blending:
        $$ C_{acc} \leftarrow C_{acc} + T \cdot \alpha_{pixel} \cdot c $$
        $$ T \leftarrow T \cdot (1 - \alpha_{pixel}) $$
        [S3, unofficial][S5]. Initialize $C_{acc}=0, T=1$.
    *   **Early Termination:** Stop processing Gaussians for a pixel when $T < \tau$ [S5].

**Pseudocode:**

```python
import numpy as np

def render_gaussians(gaussians, camera, image_width, image_height, tile_size=16, tau=1e-4):
    """
    Render 3D Gaussians to a 2D image buffer.
    
    Args:
        gaussians: Dict with keys 'xyz' (N,3), 'rot' (N,4), 'scale' (N,3), 
                   'opacity' (N,1), 'sh' (N, SH_dim).
        camera: Object with attributes 'W' (4,4), 'fx', 'fy', 'cx', 'cy', 
                'znear', 'zfar'.
        image_width, image_height: int.
        tile_size: int.
        tau: float, early termination threshold.
        
    Returns:
        color_buffer: (H, W, 3) float32 array.
    """
    N = gaussians['xyz'].shape[0]
    color_buffer = np.zeros((image_height, image_width, 3), dtype=np.float32)
    transmittance_buffer = np.ones((image_height, image_width), dtype=np.float32)
    
    # 1. Activation
    q_norm = gaussians['rot'] / np.linalg.norm(gaussians['rot'], axis=1, keepdims=True)
    s_eff = np.exp(gaussians['scale'])
    alpha_eff = 1.0 / (1.0 + np.exp(-gaussians['opacity']))
    
    # Construct 3D Covariance
    # Helper to convert quaternion to rotation matrix
    R = quaternion_to_rotation_matrix(q_norm) # [N, 3, 3]
    S_diag = np.diag_embed(s_eff) # [N, 3, 3]
    Sigma_3D = R @ S_diag @ S_diag.transpose(0, 2, 1) # [N, 3, 3]
    
    # 2. Camera Space Transformation
    # Homogeneous means
    mu_h = np.concatenate([gaussians['xyz'], np.ones((N, 1))], axis=1) # [N, 4]
    mu_cam_h = (camera.W @ mu_h.T).T # [N, 4]
    mu_prime = mu_cam_h[:, :3] # [N, 3]
    
    W_sub = camera.W[:3, :3] # [3, 3]
    Sigma_cam = W_sub @ Sigma_3D @ W_sub.T # [N, 3, 3]
    
    # 3. Projection
    # Jacobian J [N, 2, 3]
    fz = mu_prime[:, 2:3] # [N, 1]
    fx = mu_prime[:, 0:1] # [N, 1]
    fy = mu_prime[:, 1:2] # [N, 1]
    
    J = np.zeros((N, 2, 3), dtype=np.float32)
    J[:, 0, 0] = camera.fx / fz
    J[:, 0, 2] = -camera.fx * fx / (fz ** 2)
    J[:, 1, 1] = camera.fy / fz
    J[:, 1, 2] = -camera.fy * fy / (fz ** 2)
    
    # 2D Covariance Sigma_2D [N, 2, 2]
    Sigma_2D = J @ Sigma_cam @ J.transpose(0, 2, 1)
    
    # 2D Mean mu_2D [N, 2]
    mu_2D = np.zeros((N, 2), dtype=np.float32)
    mu_2D[:, 0] = (camera.fx * fx / fz) + camera.cx
    mu_2D[:, 1] = (camera.fy * fy / fz) + camera.cy
    
    # 4. Culling and Sorting
    # Cull behind near plane
    valid_mask = mu_prime[:, 2] > camera.znear
    valid_indices = np.where(valid_mask)[0]
    
    if len(valid_indices) == 0:
        return color_buffer
        
    sorted_indices = valid_indices[np.argsort(mu_prime[valid_indices, 2])]
    
    # Precompute inverse 2D covariance and conic for rasterization
    # Sigma_2D_inv [N, 2, 2]
    Sigma_2D_inv = np.linalg.inv(Sigma_2D)
    
    # Conic representation: [inv(0,0), inv(0,1), inv(1,1)]
    conics = np.stack([
        Sigma_2D_inv[:, 0, 0],
        Sigma_2D_inv[:, 0, 1],
        Sigma_2D_inv[:, 1, 1]
    ], axis=1) # [N, 3]
    
    # Bounding box calculation (3 sigma)
    # sqrt of diagonal elements of Sigma_2D
    bbox_size = 3.0 * np.sqrt(np.diag(Sigma_2D)) # [N, 2]
    
    # 5. Rasterization (Tile-based)
    # Iterate over tiles
    for ty in range(0, image_height, tile_size):
        for tx in range(0, image_width, tile_size):
            # Determine tile pixel range
            y_min, y_max = ty, min(ty + tile_size, image_height)
            x_min, x_max = tx, min(tx + tile_size, image_width)
            
            # Get pixel coordinates in this tile
            pixel_y, pixel_x = np.mgrid[y_min:y_max, x_min:x_max]
            pixel_coords = np.stack([pixel_x, pixel_y], axis=-1).astype(np.float32) # [H_t, W_t, 2]
            
            # For each Gaussian, check if it covers this tile
            # Simple bounding box check first
            # Expand bbox to pixel space
            # Note: In efficient implementations, this is done via GPU shaders or specialized CPU loops
            # Here we simulate the logic for clarity
            
            for idx in sorted_indices:
                # Check if Gaussian center is within expanded tile bounds
                # This is a simplification; real impl checks intersection of ellipse and tile rect
                if not gaussian_covers_tile(idx, conics[idx], mu_2D[idx], bbox_size[idx], 
                                           x_min, x_max, y_min, y_max):
                    continue
                
                # Rasterize pixels covered by this Gaussian
                # Calculate relative positions
                rel_x = pixel_coords[:, :, 0] - mu_2D[idx, 0]
                rel_y = pixel_coords[:, :, 1] - mu_2D[idx, 1]
                
                # Quadratic form: x^T Sigma_inv x
                # Using conic: inv_xx * x^2 + 2 * inv_xy * x * y + inv_yy * y^2
                # Note: conic[1] is inv(0,1), which equals inv(1,0)
                exponent = -(0.5 * (
                    conics[idx, 0] * (rel_x ** 2) + 
                    2 * conics[idx, 1] * (rel_x * rel_y) + 
                    conics[idx, 2] * (rel_y ** 2)
                ))
                
                # Clip exponent to avoid overflow in exp
                exponent = np.clip(exponent, -100.0, 0.0)
                
                # Gaussian value
                g_val = np.exp(exponent)
                
                # Effective alpha
                alpha_p = alpha_eff[idx] * g_val
                
                # Get color from SH
                # View direction needed for SH evaluation. 
                # Simplified: assume constant color c for this software example or pass view dir
                # In full impl, c is evaluated per pixel based on view ray
                c = evaluate_sh(gaussians['sh'][idx], camera, mu_prime[idx]) # [3]
                
                # Update buffer
                # Only update if alpha_p > 0 and transmittance > tau
                mask = (alpha_p > 0) & (transmittance_buffer[y_min:y_max, x_min:x_max] > tau)
                
                if np.any(mask):
                    # Vectorized update for the tile region
                    # C_acc += T * alpha * c
                    # T *= (1 - alpha)
                    
                    # Current transmittance in this tile region
                    T_curr = transmittance_buffer[y_min:y_max, x_min:x_max][mask]
                    
                    # Color contribution
                    color_contrib = T_curr[:, np.newaxis] * alpha_p[mask] * c # [M, 3]
                    
                    # Update color buffer
                    color_buffer[y_min:y_max, x_min:x_max][mask] += color_contrib
                    
                    # Update transmittance
                    new_T = T_curr * (1 - alpha_p[mask])
                    transmittance_buffer[y_min:y_max, x_min:x_max][mask] = new_T

    return color_buffer
```

### Perspective-Correct 3D Gaussian Splat Evaluation
A differentiable method that evaluates 3D Gaussians along per-pixel viewing rays without matrix inversion, ensuring numerical stability and eliminating special handling for degenerate splats [S9]. Unlike the affine approximation in standard 3DGS which causes perspective distortion at close distances, this method provides fully perspective-correct rendering while maintaining real-time performance within a rasterization pipeline [S9].

### Fisheye Camera Adaptation (Equidistant Projection)
Adapts the rasterization projection for fisheye cameras by modifying the transformation from image space to camera space based on the unit sphere using the equidistant projection model [S7]. It computes the 2D coordinate vector $\mathbf{x}_{2D}$ using intrinsic parameters $c_x, c_y, f_x, f_y$ and the pixel coordinates $(u, v)$ via a specific trigonometric formula involving the square root of the normalized squared distances [S7].

### 3D Gaussian Splatting on Mesh Surfaces
Attaches Gaussians onto the surface of a mesh, such as a textured human body mesh, to reduce the number of Gaussians required by combining rendered results from the mesh and the Gaussians [S1].

### RadSplat
Leverages robust initialization from NeRF to generate a highly accurate dense point cloud, which is converted into Gaussians, circumventing topological pitfalls of raw SfM initialization and achieving over 900 FPS rendering [S10, unofficial].

### 3D Gaussian Splatting with Motion Bases
Positions and rotations change over time, sharing motion coefficients with different motion bases, and introduces regularization, sparsity, and local rigidity terms during optimization [S1].

### 3D Gaussian Splatting with Frequency-Domain Regularization
Applies frequency-domain regularization to the rendered 2D image to encourage high-frequency detail recovery [S1].

### 3D Gaussian Splatting with NFD
Utilizes the Generalized Normal Distribution (NFD) to sharpen scene edges [S1].

### Don't Splat your Gaussians
Introduces volumetric ray-traced primitives with closed-form transmittance for efficient media rendering, addressing violations of physical absorption-emission models [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot P)$ where $N$ is the number of Gaussians and $P$ is the number of pixels, but optimized via tiling and early termination [S3, unofficial][S5]. Object-level sorting is $O(N \log N)$ [S3, unofficial].
*   **Memory Complexity:** $O(N)$ for storing Gaussian attributes [S3, unofficial]. Unbounded scenes can require gigabytes of storage [S5].
*   **Performance:** Targets desktop GPUs for real-time rendering (e.g., 129 FPS Full HD) [S5]. Faces memory and bandwidth limits on mobile/AR-VR edge devices [S5].
*   **Strengths:** Real-time rendering speeds, high-quality novel view synthesis, differentiable optimization [S3, unofficial][S4].
*   **Limitations:** Approximate perspective projection (affine Jacobian) causes distortion at close distances [S9]. Unbounded Gaussian growth leads to memory fragmentation [S3, unofficial]. Matrix inversion in rasterization can cause numerical instability for degenerate splats [S9].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. [37] as a novel view synthesis method representing scenes as a set of 3D Gaussian ellipsoids [S5]. It uses a tile-based, differentiable software rasterizer for rendering [S3, unofficial]. The method initializes from sparse Structure-from-Motion (SfM) points or random points and employs adaptive density control (cloning and splitting) to optimize the Gaussian distribution [S4][S3, unofficial]. Training typically involves 30,000 iterations with L1 and D-SSIM losses [S3, unofficial].
