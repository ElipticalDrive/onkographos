# Computational Deformation Field (CDF)

Also called: DHE multi-hash construction, Hash Feature Decoder

## Overview
The Computational Deformation Field (CDF) is a storage-efficient method for synthesizing spatial features on-the-fly in dynamic 3D Gaussian Splatting, replacing large learnable multi-resolution hash tables with a neural decoder [S1]. It solves the memory bottleneck of explicit storage in dynamic scenes by using a compact neural function to generate deformation features at query time, reducing the memory footprint compared to prior works that rely on deep hash grid hierarchies [S1]. Unlike [4D Neural Voxel Splatting](16404-4d-neural-voxel-splatting.md), which may rely on different voxelization strategies, CDF specifically utilizes a Dense Hash Encoding (DHE) multi-hash construction combined with a Hash Feature Decoder to balance storage efficiency and representational capacity [S1].

## How it works
**Inputs:**
*   Primitive center coordinate in canonical space: $\mu \in \mathbb{R}^3$ [S1].
*   Timestamp: $t$ [S1].
*   Grid resolution: $R$ [S1].
*   Number of parallel hash functions: $k=128$ [S1].
*   Hash parameters: Matrix $A \in \mathbb{Z}^{k \times 3}$, vector $b \in \mathbb{Z}^k$, large prime $P$, and modulo basis $m$ [S1].
*   Number of frequency bands for time encoding: $L$ [S1].

**Outputs:**
*   Deformation offsets: $\Delta \mu$ (Position, size 3), $\Delta s$ (Scale, size 3), $\Delta r$ (Rotation, size 4), $\Delta o$ (Opacity, size 1), $\Delta c$ (Spherical Harmonics, size 48) [S1].

**Data Structures:**
*   **Hash Feature Decoder:** A neural network consisting of Linear Layers interleaved with Mish activation functions and LayerNorm [S1]. It maps the high-dimensional hash signature to continuous deformation features [S1].
*   **TimeMLP:** A shallow neural module processing the temporal feature [S1].
*   **FiLM Generator:** A compact network regressing scale $\gamma(f_{time})$ and shift $\beta(f_{time})$ vectors [S1].

**Steps:**

1.  **Normalization:** Normalize the primitive's center coordinate $\mu$ to the unit cube:
    $$ \hat{\mu} = \text{normalize}(\mu) \in [0, 1]^3 $$
    [S1]

2.  **Discretization:** Discretize $\hat{\mu}$ into an integer voxel index $v$ at resolution $R$:
    $$ v = \lfloor R \cdot \hat{\mu} \rfloor $$
    [S1]

3.  **Voxel Corner Generation:** Generate the eight corner vertices $\tilde{\mu}$ of the enclosing voxel by applying binary offsets $(dx, dy, dz) \in \{0, 1\}^3$ to $v$:
    $$ \tilde{\mu}_{(dx,dy,dz)} = v + (dx, dy, dz) $$
    [S1]

4.  **Dense Hash Encoding (DHE):** For each corner vertex $\tilde{\mu}$, compute the hash signature using $k$ parallel hash functions. The integer vector is calculated as:
    $$ h_{int}(\tilde{\mu}) = (\tilde{\mu} A^\top + b) \pmod P \pmod m $$
    [S1]
    Normalize the resulting integer vector to the range $[-1, 1]^k$ to yield the dense, real-valued signature $\hat{h}(\tilde{\mu})$:
    $$ \hat{h}(\tilde{\mu}) = \text{normalize\_to\_minus\_one\_one}(h_{int}(\tilde{\mu})) $$
    [S1]

5.  **Hash Feature Decoding:** Pass the signature $\hat{h}(\tilde{\mu})$ through the Hash Feature Decoder to synthesize vertex-specific features. The decoder consists of Linear Layers interleaved with Mish activations and LayerNorm. Let $D(\cdot)$ denote this decoder:
    $$ f_{vertex} = D(\hat{h}(\tilde{\mu})) $$
    [S1]

6.  **Trilinear Interpolation:** Perform trilinear interpolation on the decoded features from the eight grid vertices to derive the final spatial feature $f_{voxel}$ at the primitive center $\mu$. Let $f_i$ be the feature at the $i$-th corner. The interpolated feature is:
    $$ f_{voxel} = \sum_{i=1}^{8} w_i f_i $$
    where $w_i$ are the trilinear interpolation weights based on the fractional part of $\hat{\mu}$.
    [S1]

7.  **Time Encoding:** Encode the timestamp $t$ using sinusoidal positional encoding with $L$ frequency bands:
    $$ \gamma(t) = \left[ t, \sin(2\pi f_1 t), \cos(2\pi f_1 t), \dots, \sin(2\pi f_L t), \cos(2\pi f_L t) \right] $$
    where $f_l = 2^{l-1}$.
    [S1]

8.  **Temporal Feature Extraction:** Process $\gamma(t)$ through the TimeMLP to yield the high-level temporal feature $f_{time}$:
    $$ f_{time} = \text{TimeMLP}(\gamma(t)) $$
    [S1]

9.  **FiLM Fusion:** Fuse $f_{time}$ with $f_{voxel}$ using Feature-wise Linear Modulation (FiLM).
    First, project the spatial feature into a latent space:
    $$ h_{spatial} = W_s f_{voxel} + b_s $$
    [S1]
    The FiLM generator takes $f_{time}$ as input and regresses channel-wise scale $\gamma(f_{time})$ and shift $\beta(f_{time})$. The unified spatiotemporal feature $f_{ST}$ is computed via affine modulation:
    $$ f_{ST} = \gamma(f_{time}) \odot h_{spatial} + \beta(f_{time}) $$
    [S1]

10. **Deformation Prediction:** Feed $f_{ST}$ into the deformation network to predict the offsets $(\Delta \mu, \Delta s, \Delta r, \Delta o, \Delta c)$.
    [S1]

11. **Voxel Reuse:** Identify shared vertices between adjacent voxels to avoid re-computation of the hash encoding and decoding for identical spatial coordinates.
    [S1]

**Pseudocode:**

```python
import math
import torch
import torch.nn as nn

class ComputationalDeformationField:
    def __init__(self, k=128, R=256, L=10, P=10**9 + 7, m=2**16):
        self.k = k
        self.R = R
        self.L = L
        self.P = P
        self.m = m
        
        # Hash parameters A: [k, 3], b: [k]
        self.A = nn.Parameter(torch.randint(0, m, (k, 3), dtype=torch.long))
        self.b = nn.Parameter(torch.randint(0, m, (k,), dtype=torch.long))
        
        # Hash Feature Decoder: Linear -> Mish -> LayerNorm
        self.hash_decoder = nn.Sequential(
            nn.Linear(k, 256),
            nn.Mish(),
            nn.LayerNorm(256),
            nn.Linear(256, 128),
            nn.Mish(),
            nn.LayerNorm(128),
            nn.Linear(128, 64)
        )
        
        # TimeMLP
        self.time_mlp = nn.Sequential(
            nn.Linear(2 * L + 1, 64),
            nn.Mish(),
            nn.Linear(64, 32)
        )
        
        # FiLM Generator
        self.film_gen = nn.Sequential(
            nn.Linear(32, 64),
            nn.Mish(),
            nn.Linear(64, 128)
        )
        
        # Deformation Network
        self.deform_net = nn.Sequential(
            nn.Linear(128, 64),
            nn.Mish(),
            nn.Linear(64, 3 + 3 + 4 + 1 + 48)
        )
        
        # Spatial projection weights for FiLM
        self.W_s = nn.Parameter(torch.eye(64))
        self.b_s = nn.Parameter(torch.zeros(64))

    def sinusoidal_encoding(self, t):
        freq_bands = torch.pow(2.0, torch.arange(self.L, device=t.device).float())
        sin_vals = torch.sin(2 * math.pi * freq_bands * t)
        cos_vals = torch.cos(2 * math.pi * freq_bands * t)
        return torch.cat([t, sin_vals, cos_vals], dim=0)

    def dense_hash_encode(self, coords):
        h_int = (coords @ self.A.T + self.b) % self.P % self.m
        h_norm = 2.0 * (h_int.float() / self.m) - 1.0
        return h_norm

    def trilinear_interpolate(self, features, coords_frac):
        x, y, z = coords_frac.unbind(dim=0)
        w000 = (1-x)*(1-y)*(1-z)
        w100 = x*(1-y)*(1-z)
        w010 = (1-x)*y*(1-z)
        w110 = x*y*(1-z)
        w001 = (1-x)*(1-y)*z
        w101 = x*(1-y)*z
        w011 = (1-x)*y*z
        w111 = x*y*z
        weights = torch.stack([w000, w100, w010, w110, w001, w101, w011, w111])
        return torch.sum(weights.unsqueeze(1) * features, dim=0)

    def forward(self, mu, t):
        # [G] Canonical space is normalized to [0,1]^3; if input is unbounded, apply min-max normalization.
        mu_hat = mu
        v = torch.floor(self.R * mu_hat).long()
        
        corners = []
        for dx in [0, 1]:
            for dy in [0, 1]:
                for dz in [0, 1]:
                    corner = v + torch.tensor([dx, dy, dz], dtype=torch.long, device=v.device)
                    corners.append(corner)
        corners = torch.stack(corners)
        
        h_sigs = self.dense_hash_encode(corners)
        vertex_features = self.hash_decoder(h_sigs)
        
        frac = mu_hat - v.float() / self.R
        f_voxel = self.trilinear_interpolate(vertex_features, frac)
        
        gamma_t = self.sinusoidal_encoding(t)
        f_time = self.time_mlp(gamma_t)
        
        h_spatial = self.W_s @ f_voxel + self.b_s
        film_params = self.film_gen(f_time)
        D = vertex_features.shape[1]
        gamma_film = film_params[:D]
        beta_film = film_params[D:]
        f_ST = gamma_film * h_spatial + beta_film
        
        offsets = self.deform_net(f_ST)
        return offsets
```

**Parameters:**
*   $k=128$: The number of parallel hash functions, set to 128 to produce full signatures with zero exact duplicates in the $N^{3D}$V query domain [S1].
*   Resolution Levels: The voxel grid hierarchy comprises only 4 to 5 resolution levels, compared to typical 16 levels in prior works [S1].
*   $P$: A large prime number used in the hash modulo operation [S1].
*   $m$: The modulo basis for the hash operation [S1].
*   $L$: The number of frequency bands for sinusoidal time encoding [S1].

**Edge Cases and Pitfalls:**
*   **Hash Collisions:** The design avoids resolving arbitrary hash collisions explicitly. Instead, the Hash Feature Decoder learns a joint mapping from high-dimensional signatures to continuous deformation features. Exact signature collisions are rare with $k=128$, and in the $N^{3D}$V query domain, full signatures produced zero exact duplicates across all queried voxel-corner coordinate sets [S1].
*   **Precision:** The hash operation involves modulo arithmetic with large primes, which may require careful handling of integer overflow in fixed-width integer types if implemented in lower-level languages [S1].

## Operating characteristics
*   **Memory Footprint:** Significantly reduced compared to prior works using deep hash grid hierarchies (e.g., 16 levels). By using only 4-5 resolution levels and replacing explicit hash tables with a neural decoder, CDF minimizes storage overhead [S1].
*   **Computational Efficiency:** The Hash Feature Decoder synthesizes features on-the-fly, eliminating the memory bottleneck of explicit storage. Voxel reuse further optimizes computation by avoiding re-computation for shared vertices [S1].
*   **Representational Capacity:** The collision-resilient DHE multi-hash construction and the non-linear mapping of the Hash Feature Decoder provide a favorable balance between storage efficiency, computational fidelity, and representational capacity [S1].
*   **Scalability:** The method is designed for dynamic 4D scenes, scaling with the number of Gaussian primitives and the complexity of the deformation field [S1].

## Background
The Computational Deformation Field (CDF) was introduced in the CC-4DGS framework, which stands for Computational Deformation and Point-Cloud Compression for Storage-Efficient Dynamic Gaussian Splatting [S1]. The method was developed to address the substantial memory overhead incurred by dynamic 3D Gaussian Splatting when using learnable multi-resolution hash grids for deformation features [S1]. Inspired by the philosophy of learnable hash-table-free designs, CDF replaces these grids with a compact neural function that generates features at query time [S1]. The work was published in IEEE Transactions on Visualization and Computer Graphics in 2026 [S1].
