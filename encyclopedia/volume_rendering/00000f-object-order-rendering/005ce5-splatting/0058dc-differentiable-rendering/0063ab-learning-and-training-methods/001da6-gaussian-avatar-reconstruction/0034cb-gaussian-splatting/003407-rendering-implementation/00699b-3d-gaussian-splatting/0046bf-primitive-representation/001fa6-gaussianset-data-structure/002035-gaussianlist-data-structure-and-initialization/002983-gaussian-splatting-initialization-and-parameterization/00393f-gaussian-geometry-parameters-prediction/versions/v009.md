# Gaussian Geometry Parameters Prediction

Also called: EVolSplat, Efficient Volume-based Gaussian Splatting, GRM, Gaussian MLP Heads, Gaussian Representation Model

## Overview
Gaussian Geometry Parameters Prediction is a feed-forward method that predicts the geometric attributes (position, opacity, covariance) of 3D Gaussians from a global volumetric feature representation, rather than regressing them per-pixel from local 2D features [S2]. It solves the problem of multi-view inconsistencies and ghosting artifacts inherent in pixel-aligned prediction methods by accumulating depth information into a unified 3D space and refining primitives globally [S2]. Unlike standard initialization which sets fixed parameters, this method learns to predict offsets and attributes via MLP heads conditioned on 3D context, enabling faithful 3D generation or urban scene reconstruction in a single pass [S1, S2].

## How it works
**Inputs:** A set of $N$ sparse input images $\{I_n\}_{n=1}^N$, their calibrated intrinsic matrices $\{K_n\}$, extrinsic matrices $\{T_n = R_n | t_n\}$, and optionally depth maps $\{D_n\}$ if not provided by an off-the-shelf estimator [S2].

**Outputs:** A set of 3D Gaussians $\mathcal{G} = \{(\mu_i, \alpha_i, \Sigma_i, c_i)\}_{i=1}^{N_p}$, where $\mu_i$ is the center, $\alpha_i$ is the opacity, $\Sigma_i$ is the covariance matrix, and $c_i$ is the view-dependent color [S2].

**Data Structures:**
1.  **Global Point Cloud ($\mathcal{P}$):** A set of 3D points in world coordinates, $\mathcal{P} \in \mathbb{R}^{N_p \times 3}$, constructed by unprojecting RGB-D data [S2].
2.  **Feature Volume ($\mathcal{F}$):** A sparse 3D tensor $H \times W \times D \times C$ extracted by a sparse 3D CNN, aligned with the world coordinate system [S2].
3.  **MLP Heads:** Three independent Multi-Layer Perceptrons: $\mathcal{D}_{pos}$ (position offset), $\mathcal{D}_{opa}$ (opacity), and $\mathcal{D}_{cov}$ (covariance) [S2].

**Steps:**

1.  **Global Point Cloud Initialization:**
    *   Predict metric depth maps $\{D_n\}$ for each input image $I_n$ using a pretrained depth estimator [S2].
    *   Apply a depth consistency check to remove inconsistent values [S2].
    *   Unproject the RGB images and depth maps into 3D space to construct the global point cloud $\mathcal{P}$:
        $$ \mathcal{P} = \bigcup_{n=1}^N \pi^{-1}(I_n, D_n, T_n, K_n) $$
        where $\pi^{-1}$ denotes pixel unprojection [S2].
    *   Apply a uniform filter to $\mathcal{P}$ to delete duplicate primitives while keeping scene structure [S2].
    *   Apply a statistical filter to remove floating artifacts (noise) from the processed primitives [S2].

2.  **Feature Volume Construction:**
    *   Construct a sparse tensor from the filtered points $\mathcal{P}$ [S2].
    *   Pass the sparse tensor through a sparse 3D CNN (e.g., sparse U-Net) to extract the neural feature volume $\mathcal{F}$ [S2].

3.  **Gaussian Geometry Parameters Prediction:**
    *   Initialize Gaussian centers $\mu^{init}_i$ using the scene point cloud $\mathcal{P}$ (i.e., $\mu^{init}_i = p_i \in \mathcal{P}$) [S2].
    *   For each Gaussian $i$, query the feature volume $\mathcal{F}$ using trilinear interpolation at the current estimated position:
        $$ \mathbf{f}_i = \mathcal{F}(\mu^{init}_i + \Delta \mu^{prev}_i) $$
        where $\mathbf{f}_i$ is the feature vector and $\Delta \mu^{prev}_i$ is the position offset from the previous iteration (initialized to 0 at the start of training or inference) [S2].
    *   Decode opacity and covariance using independent MLP heads:
        $$ \alpha_i = \mathcal{D}_{opa}(\mathbf{f}_i), \quad \Sigma_i = \mathcal{D}_{cov}(\mathbf{f}_i) $$
        where $\mathcal{D}_{opa}$ and $\mathcal{D}_{cov}$ are MLPs [S2].
    *   Decode the position offset $\Delta \mu_i$ using the position MLP head $\mathcal{D}_{pos}$, passed through a Tanh activation and scaled by the voxel size $v_{size}$:
        $$ \Delta \mu_i = \text{Tanh}(\mathcal{D}_{pos}(\mathbf{f}_i)) \cdot v_{size} $$
        The final center is updated as:
        $$ \mu_i = \mu^{init}_i + \Delta \mu_i $$
        where $v_{size}$ is the voxel size used to scale the offset [S2].

4.  **Color Prediction (Occlusion-Aware IBR):**
    *   Project the 3D Gaussians to the nearest $K$ reference views to retrieve 2D context, including color windows $\{c_k\}_{k=1}^K$ and visibility maps [S2].
    *   Decode the Gaussian color $c_i$ using the retrieved 2D context [S2].

5.  **Background Modeling:**
    *   Model distant views and the sky with a generalizable hemisphere Gaussian model where geometry is fixed and color is predicted similarly to the foreground volume [S2].

6.  **Rendering:**
    *   Compose foreground and background Gaussians to reconstruct the image using alpha blending:
        $$ c = \sum_{i \in \mathcal{G}} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
        where $c$ is the rendered color, $\mathcal{G}$ is the set of Gaussians, $c_i$ is the view-dependent color, and $\alpha_i$ is the opacity [S2].

**Inference Specifics:**
During inference, initialize $\Delta \mu^{prev}_i = 0$. Recursively execute the update rules (querying $\mathbf{f}_i$, computing $\Delta \mu_i$, updating $\mu_i$, then querying $\alpha_i$ and $\Sigma_i$) twice to obtain a converged $\Delta \mu_i$ [S2].

**Parameters:**
*   $N$: Number of input images [S2].
*   $N_p$: Number of primitives in the global point cloud [S2].
*   $K$: Number of nearest reference views for 2D context retrieval [S2].
*   $v_{size}$: Voxel size scaling factor for position offset [S2].

**Edge Cases and Pitfalls:**
*   **Ghosting Artifacts:** Pixel-aligned methods generate redundant and inconsistent primitives in overlapping regions. This method addresses this by using a global volume and filtering duplicates [S2].
*   **Depth Noise:** Monocular depth predictions contain noise and floating artifacts. This method handles this by applying a statistical filter to remove floaters after uniform filtering [S2].
*   **Recursive Convergence:** The position offset $\Delta \mu_i$ depends on the previous estimation. The method relies on the convergence of this recursive formulation, which is stabilized at infinite training iterations [S2].

## Subtopics

### GSGEN
A method introducing 3D SDS loss based on Point-E to mitigate the multi-face or Janus problem in text-to-3D generation. It adopts Point-E to initialize the point cloud as the initial geometry for optimization and refines appearance with only the 2D image prior [S1].

### BrightDreamer
A method predicting the deviation of a set of fixed anchor points to determine the centers of Gaussians, rather than predicting the point cloud directly from the image [S1].

### NeRF-Guided 3D Gaussian Splatting
Uses a pretrained NeRF as a teacher to guide feature distillation, improving alignment between geometry and semantics [S3, unofficial].

### Gaussian Splatting Attribute Prediction
A voxel transformer that predicts residuals added to initial Gaussian rendering attributes on voxels, rather than generating new attributes directly. The residual is calculated as $\Delta \mathbf{G}_j = \text{MLP}_{fine}([\mathbf{O}_j, \mathbf{E}_j])$, where $[\mathbf{O}_j, \mathbf{E}_j]$ is the concatenation of offset and voxel attribute, and the final parameter is $\mathbf{G}'_j = \mathbf{G}_j + \Delta \mathbf{G}_j$ [S4].

### 6D Gaussian Splatting
An extension of 3DGS that models view-dependent effects by adding directional dimensions, representing scene elements as 6D Gaussians (space+direction). It parameterizes the full 6D covariance via Cholesky decomposition $\Sigma = LL^\top$ with $L$ lower-triangular and positive diagonal entries to guarantee positive definiteness [S5].

### Anisotropic Covariance
Allows 3D Gaussians to scale anisotropically along the x, y, and z axes and rotate in 3D space, rather than remaining spherical. Each Gaussian optimizes 3 scale parameters and 4 rotation parameters (quaternion). The Isotropic variant fixes these, removing 7 variables per Gaussian. On Average-30K, Full achieves PSNR 26.05, while Isotropic achieves 25.23. Anisotropic allows elongated/rotated shapes matching scene geometry, whereas Isotropic causes blurry, rounded artifacts [S6, unofficial].

### Defocus Blur Modeling
Models optical defocus by adjusting the scale $s$ of 3D Gaussians based on their distance from the camera's focal plane. During training, larger scale values $\bar{s}_j$ are used to rasterize blurred images; during testing, smaller scale values $s_j$ are used to render sharp details. Unlike a naive Gaussian kernel that blurs the entire image uniformly, this method selectively enlarges covariances only for Gaussians corresponding to blurred regions [S7].

### 3D Gaussians Prediction from Voxels
Predicts a set of learnable Gaussian parameters for each voxel $v$, including center offset, opacity, covariance, and spherical harmonic color. The final center is computed as $\mu_j = r \cdot (\sigma(\bar{\mu}_j) - 0.5) + \text{Center}_j$, where $\sigma$ is sigmoid, $\bar{\mu}_j$ is the predicted offset, $\text{Center}_j$ is the voxel centroid, and $r$ is a scaling factor (set to 3 times the voxel size). The sigmoid restricts the offset to a localized neighborhood, and the -0.5 shift facilitates symmetrical movement from the voxel center [S8].

### GS-LRM / Long-LRM
Predicts 3D Gaussians directly (not triplane -> Gaussians), resulting in faster downstream rendering [S9, unofficial].

### GauS (Gaussian Splatting Surface Reconstruction)
A render-then-fuse approach for high-fidelity mesh reconstruction from 3DGS inputs without fine-tuning. It uses volumetric fusion to convert 3D Gaussians into textured triangle meshes. Unlike NeRF-based re-training or further fine-tuning required for explicit surface modeling in other methods, GauS converts optimized Gaussians directly into textured meshes serving as a versatile plug-and-play solution [S10, unofficial].

### Hybrid Scene Representation (Foreground/Background)
A scene representation comprising Gaussian foreground models and background models. The background models support diverse backends like environment maps, textured meshes, and neural representations. Specifically, sky background is built using spherical environment maps composed of Gaussians to reduce artifacts in unbounded outdoor scenes [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Feed-forward inference is significantly faster than iterative optimization-based 3DGS methods, as it predicts parameters in a single pass through the network [S2].
*   **Memory Complexity:** Uses a global volumetric feature representation, which may require more memory than local cost volumes but reduces redundancy compared to per-pixel aligned methods [S2].
*   **Performance:** Achieves real-time rendering by feed-forward prediction of Gaussian primitives [S2].
*   **Strengths:** Improves global consistency and reduces ghosting artifacts when rendering new images from new viewpoints by accumulating and refining depth information in 3D space [S2]. Better incorporates neighbor information by learning Gaussian geometry in 3D rather than from a 2D feature map [S2].
*   **Limitations:** Relies on the quality of off-the-shelf depth estimators; noise in depth predictions can affect initialization, though filtering mitigates this [S2].
*   **When to use:** Efficient urban scene reconstruction or faithful 3D generation from sparse views where global consistency is critical [S2].
*   **When not to use:** When per-pixel local detail is more important than global consistency, or when computational resources for 3D CNNs are limited [S2].

## Background
Originating from the need for efficient, feed-forward 3D Gaussian Splatting models for urban view synthesis and faithful 3D generation, this method was introduced by Miao et al. in "EVolSplat: Efficient Volume-based Gaussian Splatting for Urban View Synthesis" (2025) [S2]. It builds on the limitations of existing feed-forward methods that predict per-pixel aligned Gaussians using local cost volumes or epipolar transformers, which suffer from multi-view inconsistencies and duplicated content [S2]. The method utilizes existing multi-view generation models to train a pixel-aligned Gaussian representation for faithful 3D generation via a single feed-forward pass [S1].
