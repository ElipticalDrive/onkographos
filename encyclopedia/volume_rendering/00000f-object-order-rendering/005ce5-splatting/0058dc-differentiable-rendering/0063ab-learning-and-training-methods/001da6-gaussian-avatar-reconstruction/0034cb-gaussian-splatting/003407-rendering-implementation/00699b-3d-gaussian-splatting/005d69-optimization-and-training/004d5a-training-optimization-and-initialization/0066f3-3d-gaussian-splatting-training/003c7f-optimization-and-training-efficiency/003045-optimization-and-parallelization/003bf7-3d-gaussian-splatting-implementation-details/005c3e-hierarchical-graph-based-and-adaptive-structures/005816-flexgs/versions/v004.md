# FlexGS

Also called: Flexible 3D Gaussian Splatting, Elastic 3DGS

## Overview
FlexGS is an elastic inference method for 3D Gaussian Splatting (3DGS) that enables a single trained model to adapt to varying computational constraints (e.g., memory limits on smartphones or VR headsets) at inference time by selecting and transforming a subset of Gaussians [S1]. Unlike standard 3DGS which requires fixed memory for millions of primitives, or post-hoc compression methods that require separate fine-tuning runs for each target size, FlexGS allows dynamic adjustment of model size and rendering quality without additional training [S1]. It achieves this through a learnable Gaussian selector and a ratio-dependent transformation field that compensates for missing details [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A pre-trained 3DGS model consisting of $N$ Gaussians, each characterized by position $X$, scaling $s$, rotation $q$, opacity $\alpha$, and spherical harmonics coefficients $SH$ [S1]. A target ratio $e \in (0, 1]$ specifying the desired fraction of Gaussians to retain [S1].
*   **Output:** A subset of $K = eN$ Gaussians, with modified parameters, ready for standard 3DGS rendering [S1].

**Data Structures**
Each Gaussian $i$ is defined by:
*   Mean position $X \in \mathbb{R}^3$ [S1].
*   Scaling vector $s \in \mathbb{R}^3$ [S1].
*   Rotation quaternion $q \in \mathbb{R}^3$ (normalized to unit length) [S1].
*   Opacity $\alpha \in \mathbb{R}$ [S1].
*   Color $c$ defined by spherical harmonics coefficients $SH \in \mathbb{R}^{(d+1)}$, where $d$ is the SH degree [S1].
*   The covariance matrix $\Sigma$ is derived from $s$ and $q$: $\Sigma = RSS^\top R^\top$, where $S$ is the diagonal scaling matrix from $s$ and $R$ is the rotation matrix from $q$ [S1].

**Algorithm Steps**
The method consists of two modules trained jointly during the initial 3DGS optimization:

1.  **Gaussian Selection:**
    For each Gaussian $i$, a learnable selector predicts a binary scaler $\lambda_i \in \{0, 1\}$ [S1].
    *   The selection is constrained such that $\sum_{i=1}^{N} \lambda_i = eN$ [S1].
    *   To enable gradient-based training despite the discrete nature of $\lambda_i$, the method uses a Gumbel-Softmax relaxation during training to approximate the discrete selection, allowing the network to learn which Gaussians are important based on their attributes and the input ratio $e$ [S1].
    *   At inference, the top $K=eN$ Gaussians with the highest selection scores (or hard thresholding of the relaxed output) are chosen [S1].

2.  **Gaussian Transformation:**
    For the selected Gaussians ($\lambda_i = 1$), a ratio-dependent transformation field adjusts their parameters to compensate for the visual loss caused by removing the other $N-K$ Gaussians [S1].
    *   This module takes the attributes of the selected Gaussians and the target ratio $e$ as input [S1].
    *   It outputs modified parameters (e.g., adjusted position, scale, or opacity) that "stretch" or "enhance" the remaining primitives to cover the void left by the pruned ones [S1].

**Rendering**
The transformed subset is rendered using standard differentiable splatting [S1]. For a pixel, the color $C$ is computed by blending $N_{active}$ ordered Gaussians overlapping the pixel:
$$ C = \sum_{i \in N_{active}} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
where $c_i$ is the color and $\alpha_i$ is the opacity of the $i$-th Gaussian [S1].

**Pseudocode**
```python
def flexgs_inference(pretrained_gaussians, target_ratio_e):
    """
    pretrained_gaussians: List of N Gaussian objects with attributes X, s, q, alpha, SH.
    target_ratio_e: Float between 0 and 1, e.g., 0.5 for 50% size.
    """
    N = len(pretrained_gaussians)
    K = int(target_ratio_e * N)
    
    # 1. Selection Phase
    # The selector module predicts importance scores or probabilities for each Gaussian
    # based on its attributes and the target_ratio_e.
    # During training, this uses Gumbel-Softmax. At inference, we use hard selection.
    selection_scores = selector_module(pretrained_gaussians, target_ratio_e)
    
    # Select top K Gaussians
    # Note: In a real implementation, this would be a differentiable operation during training.
    # Here we assume a hard top-K selection for inference.
    selected_indices = top_k_indices(selection_scores, K)
    selected_gaussians = [pretrained_gaussians[i] for i in selected_indices]
    
    # 2. Transformation Phase
    # Adjust parameters of selected Gaussians to compensate for missing ones
    transformed_gaussians = transformation_field(selected_gaussians, target_ratio_e)
    
    # 3. Rendering Phase
    # Render using standard 3DGS rasterization on the transformed subset
    image = render_3dgs(transformed_gaussians, camera_params)
    
    return image
```

**Parameters and Typical Values**
*   **Target Ratio ($e$):** Can be any value in $(0, 1]$. Typical values depend on hardware constraints (e.g., 0.1 for low-end mobile, 1.0 for high-end desktop) [S1].
*   **Number of Gaussians ($N$):** Varies by scene scale (e.g., millions for city-scale scenes) [S1].

**Edge Cases and Pitfalls**
*   **Extreme Compression:** Fixed heuristic selection (e.g., pruning based on static importance) may fail when selecting very small fractions (e.g., 1%) because importance scores must be re-computed as Gaussian attributes evolve during training [S1]. FlexGS addresses this by jointly training the selector [S1].
*   **Discrete Optimization:** Direct optimization of binary selection variables is non-differentiable [S1]. The method relies on Gumbel-Softmax relaxation during training to mitigate this [S1].

## Operating characteristics
*   **Time Complexity:** Inference time scales linearly with the number of selected Gaussians $K = eN$ [S1]. The selection and transformation modules add negligible overhead compared to the rendering cost [S1].
*   **Memory Complexity:** Memory usage scales with $K$ instead of $N$ [S1]. This allows deployment on devices with limited GPU memory [S1].
*   **Performance:** FlexGS achieves substantial rendering performance without additional fine-tuning [S1]. It outperforms post-hoc compression methods that require separate runs for each ratio [S1].
*   **Strengths:** Single model for multiple deployment scenarios; no retraining required for different ratios; adapts to diverse hardware constraints [S1].
*   **Limitations:** Requires initial joint training of the selector and transformation modules; performance may degrade at extreme compression ratios if the transformation field cannot fully compensate for missing details [S1].

## Background
FlexGS was introduced by Hengyu Liu, Yuehao Wang, Chenxin Li, et al. from The Chinese University of Hong Kong, University of Texas at Austin, and Nvidia [S1]. It was published in CVPR 2025 (arXiv:2506.04174v1, June 4, 2025) [S1]. The work addresses the challenge of 3DGS's high memory overhead, which limits its use on resource-constrained devices like smartphones and standalone VR headsets [S1]. Previous approaches focused on pruning Gaussians but required fine-tuning for each target size [S1]. FlexGS proposes an "elastic" inference framework that trains once and deploys everywhere [S1].
