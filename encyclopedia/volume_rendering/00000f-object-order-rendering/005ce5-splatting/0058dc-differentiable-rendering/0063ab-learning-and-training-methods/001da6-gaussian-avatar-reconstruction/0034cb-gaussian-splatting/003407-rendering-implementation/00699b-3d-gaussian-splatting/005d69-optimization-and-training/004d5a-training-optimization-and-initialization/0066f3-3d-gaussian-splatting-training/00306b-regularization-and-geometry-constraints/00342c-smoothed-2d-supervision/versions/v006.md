# Smoothed 2D Supervision

Also called: Adaptive Gaussian blur strategy, Progressive Gaussian Blurring

## Overview
Smoothed 2D Supervision is a regularization technique that enhances the robustness of joint optimization in radiance fields by smoothing the 2D supervision signal [S1][S2, unofficial]. It addresses the instability caused by high-frequency noise in raw image gradients, which can lead to poor camera alignment and overfitting to noise [S2, unofficial]. Unlike standard supervision that uses raw pixels, this method applies a scheduled 2D Gaussian blur to training images, stabilizing gradients and restricting the spectrum of the learned 3D scene [S2, unofficial]. It sets itself apart from frequency regularization [6130-frequency-regularization.md] by operating directly on the 2D image domain rather than modifying the positional encoding or loss weights in the frequency domain [G].

## How it works
**Inputs and Outputs:**
- Input: Raw 2D training image $I_{\text{raw}}$, current iteration $t$, total iterations $T_{\text{max}}$, kernel schedule parameters.
- Output: Smoothed supervision image $I_{\text{smooth}}$ used in the rendering loss $\mathcal{L}_{\text{rgb}}$.

**Data Structures:**
- The Gaussian kernel $K$ is defined by its standard deviation $\sigma$ and size $S \times S$ [G].

**Parameters:**
- Initial standard deviation $\sigma_0 = 2.4$ [S4].
- Initial kernel size $S = 9$ [S4].
- Schedule interval $k_b = 100$ iterations [S4].
- End iteration for blurring: 19,500 [S4] or 10,000 [S2, unofficial]. (Sources disagree on the exact end iteration; [S4] specifies 19,500 while [S2, unofficial] mentions reduction to 0 at 10,000.)
- Downsampling scale factor $s_{\text{down}}$: Applied if downsampling is active [S4].

**Steps:**
1. **Initialize Kernel:** Set initial $\sigma = \sigma_0$ and kernel size $S = 9$ [S4].
2. **Schedule Update:** At every $k_b$ iterations, reduce $\sigma$ [S4]. [S2, unofficial] specifies an exponential reduction to 0 at 10,000 iterations, while [S4] describes a gradual reduction until 19,500. A common implementation uses a decay curve: $\sigma(t) = \sigma_0 \cdot \max\left(0, 1 - \frac{t}{T_{\text{end}}}\right)^\alpha$ [G].
3. **Adjust for Downsampling:** If training images are downsampled by $s_{\text{down}}$, scale the effective standard deviation: $\sigma_{\text{effective}} = \sigma \cdot s_{\text{down}}$ [S4].
4. **Apply Blur:** Convolve $I_{\text{raw}}$ with the 2D Gaussian kernel $K(\sigma_{\text{effective}})$ to produce $I_{\text{smooth}}$ [S2, unofficial].
5. **Compute Loss:** Calculate the rendering loss $\mathcal{L}_{\text{rgb}}$ between the rendered image and $I_{\text{smooth}}$ instead of $I_{\text{raw}}$ [S2, unofficial].
6. **Pre-Densification Adjustment:** Lower the blurring kernel size before densifying Gaussians to introduce extra signal on the gradient of erroneous Gaussians as noise level reduces [S4].

**Pseudocode:**
```python
import math

def get_smoothed_supervision(raw_image, iteration, sigma_0=2.4, k_b=100, t_end=19500, downsampling_scale=1.0):
    """
    Computes the smoothed supervision image for a given iteration.
    
    Args:
        raw_image: 2D list/array of pixel values.
        iteration: Current training iteration.
        sigma_0: Initial standard deviation.
        k_b: Interval for kernel reduction steps.
        t_end: Iteration at which sigma reaches 0.
        downsampling_scale: Scale factor if images are downsampled.
        
    Returns:
        smoothed_image: Blurred image array.
    """
    # Calculate current sigma based on schedule
    progress = min(iteration / t_end, 1.0)
    sigma = sigma_0 * max(0.0, 1.0 - progress)
    
    # Adjust for downsampling if applicable
    sigma = sigma * downsampling_scale
    
    # If sigma is effectively zero, return raw image
    if sigma < 1e-6:
        return raw_image
    
    # Create 2D Gaussian kernel
    kernel_radius = int(3 * sigma) + 1
    kernel_size = 2 * kernel_radius + 1
    center = kernel_size // 2
    kernel = [[0.0] * kernel_size for _ in range(kernel_size)]
    for y in range(kernel_size):
        for x in range(kernel_size):
            dist_sq = (x - center)**2 + (y - center)**2
            kernel[y][x] = math.exp(-0.5 * dist_sq / (sigma**2))
    # Normalize kernel
    total = sum(sum(row) for row in kernel)
    kernel = [[val / total for val in row] for row in kernel]
    
    # Apply convolution with zero-padding
    h, w = len(raw_image), len(raw_image[0])
    smoothed = [[0.0] * w for _ in range(h)]
    for y in range(h):
        for x in range(w):
            acc = 0.0
            for ky in range(kernel_size):
                for kx in range(kernel_size):
                    py, px = y + ky - center, x + kx - center
                    if 0 <= py < h and 0 <= px < w:
                        acc += raw_image[py][px] * kernel[ky][kx]
            smoothed[y][x] = acc
    return smoothed
```

**Edge Cases and Pitfalls:**
- **Zero Sigma:** When $\sigma$ reaches 0, the blur becomes an identity operation [G].
- **Boundary Conditions:** Gaussian convolution at image boundaries can cause darkening; use appropriate padding or clamp the kernel [G].
- **Downsampling Mismatch:** If downsampling is used, failing to scale $\sigma$ by the downsampling factor results in incorrect frequency suppression [S4].

## Operating characteristics
- **Time Complexity:** The blur operation is $O(N \cdot S^2)$ per image, where $N$ is the number of pixels and $S$ is the kernel size [G].
- **Memory Complexity:** Not given in the sources.
- **Performance:** Improves PSNR on DTU 3-view from 19.54 (Baseline) to 19.72 [S3]. It reduces training iterations required for convergence (e.g., 50k vs 200k for some MLP-based methods) [S1].
- **Strengths:** Stabilizes camera alignment, restricts high-frequency noise, and improves robustness in joint optimization [S1][S2, unofficial].
- **Limitations:** Handcrafted schedule may not fully align frequency relationships between positional encoding and pixel supervision compared to adaptive methods [S3].
- **When to Use:** Crucial for successful pose refinement in joint optimization scenarios [S1]. Recommended when training is unstable or prone to overfitting high-frequency noise [S2, unofficial].

## Background
Smoothed 2D Supervision was proposed to improve the robustness of joint optimization of camera poses and radiance fields [S1][S2, unofficial]. It is based on the observation that blurring 2D training images produces smoother gradients, which helps stabilize camera alignment and restricts the spectrum of the learned scene [S2, unofficial]. The technique is often used in conjunction with other regularization methods like randomly scaled kernel parameters [S1]. It has been shown to be effective in few-shot NeRF settings and Gaussian Splatting variants [S3][S4].
