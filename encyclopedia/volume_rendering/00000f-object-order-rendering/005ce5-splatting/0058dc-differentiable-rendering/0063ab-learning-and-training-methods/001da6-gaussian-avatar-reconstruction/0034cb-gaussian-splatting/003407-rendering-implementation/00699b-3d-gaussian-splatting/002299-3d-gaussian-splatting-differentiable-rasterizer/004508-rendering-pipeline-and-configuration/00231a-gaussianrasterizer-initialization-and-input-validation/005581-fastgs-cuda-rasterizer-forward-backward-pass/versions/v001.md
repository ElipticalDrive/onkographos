# FastGS CUDA Rasterizer Forward/Backward Pass

Also called: CUDA Gaussian Rasterization, Fast Gaussian Splatting, FastGS CUDA Rasterizer, FastGS Rasterization Pipeline, FastGS Rasterizer

## Overview
The FastGS CUDA Rasterizer is a differentiable, tile-based rasterization backend for 3D Gaussian Splatting [S1, unofficial]. It extends the original differentiable Gaussian rasterizer by introducing optimized memory access patterns via radix sorting and bucket-based parallel blending, along with support for additional buffers such as `sampleBuffer` and `accum_metric_counts` [S1, unofficial]. It distinguishes itself from standard implementations by explicitly managing tile ranges and bucket offsets to reduce memory contention during the blending phase [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   `means3D`: Tensor of shape $(N, 3)$, 3D Gaussian centers.
*   `colors_precomp`: Tensor of shape $(N, 3)$ or $(N, C)$, precomputed colors. If null, `dc` and `sh` are used.
*   `opacities`: Tensor of shape $(N, 1)$, Gaussian opacities.
*   `scales`: Tensor of shape $(N, 3)$, local scaling factors.
*   `rotations`: Tensor of shape $(N, 4)$, local rotations (quaternions).
*   `cov3Ds_precomp`: Tensor of shape $(N, 6)$, precomputed 3D covariances (symmetric). If null, `scales` and `rotations` are used.
*   `viewmatrix`: $4 \times 4$ view transformation matrix.
*   `projmatrix`: $4 \times 4$ projection matrix.
*   `tanfovx`, `tanfovy`: Tangents of the horizontal and vertical field of view.
*   `image_height`, `image_width`: Output image dimensions.
*   `bg`: Background color tensor.
*   `scale_modifier`: Float multiplier for opacity/thresholds.
*   `dc`: Direct color coefficients (if `colors_precomp` is null).
*   `sh`: Spherical Harmonics coefficients (if `colors_precomp` is null).
*   `sh_degree`: Degree of SH.
*   `campos`: Camera position.
*   `metric_map`: Optional integer tensor of size $(H \times W)$ for metric accumulation.
*   `mult`: Float multiplier for tile culling thresholds.
*   `prefiltered`: Boolean flag.
*   `debug`: Boolean flag for error snapshotting.
*   `get_flag`: Boolean flag for feature pointer selection.

**Outputs:**
*   `render`: Rendered image tensor.
*   `viewspace_points`: Tensor of shape $(N, 4)$ containing 2D means and gradients.
*   `visibility_filter`: Indices of Gaussians with `radii > 0`.
*   `radii`: Tensor of visible radii.
*   `accum_metric_counts`: Accumulated metric counts per pixel.

### Data Structures
*   **GaussianRasterizationSettings**: Named tuple containing `image_height`, `image_width`, `tanfovx`, `tanfovy`, `bg`, `scale_modifier`, `viewmatrix`, `projmatrix`, `sh_degree`, `campos`, `mult`, `prefiltered`, `debug`, `get_flag`, `metric_map`.
*   **SampleState**: Stores bucket-to-tile mappings, tile boundaries (`T`), and aspect ratios (`ar`).
*   **ImgState**: Stores tile ranges, bucket offsets, accumulated alpha, contribution counts (`n_contrib`, `max_contrib`), pixel colors, and scan buffers.
*   **BinningState**: Stores the sorted point list (`point_list`) and unsorted keys/values.
*   **GeomState**: Stores 2D means (`means2D`), conic matrices (`conic_opacity`), and clamping flags.

def render_fastgs_cuda(bg, means3D, colors_precomp, opacities, scales, rotations, 
                       scale_modifier, cov3Ds_precomp, metric_map, viewmatrix, 
                       projmatrix, tanfovx, tanfovy, image_height, image_width, 
                       dc, sh, sh_degree, campos, mult, prefiltered, debug, get_flag):
    """
    Core CUDA kernel logic (conceptual Python representation).
    """
    N = means3D.shape[0]
    
    # 1. Mark visible Gaussians (checkFrustum)
    # Transform means to view space
    means_view = transform_point_4x3(viewmatrix, means3D)
    # Check frustum: p_view.z > 0.2f
    in_frustum = means_view[:, 2] > 0.2
    present = in_frustum.int()
    
    if prefiltered and not present.any():
        raise AssertionError("All points filtered")
        
    # 2. Preprocess Gaussians (FORWARD::preprocess)
    # Transform to screen space, compute 2D covariances, clamp, determine tiles_touched

        means3D, cov3Ds_precomp, opacities, viewmatrix, projmatrix, 
        tanfovx, tanfovy, image_height, image_width, scale_modifier
    )
    
    # 3. Compute prefix sums (cub::DeviceScan::InclusiveSum)
    point_offsets = inclusive_sum(tiles_touched)
    
    # 4. Duplicate and Key Generation (duplicateWithKeys)
    # Generate 64-bit key: (tile_id << 32) | depth
    gaussian_keys_unsorted, gaussian_values_unsorted = duplicate_with_keys(
        present, tiles_touched, point_offsets, means2D
    )
    
    # 5. Radix Sort (cub::DeviceRadixSort::SortPairs)
    # Sort by keys. Bit depth = 32 + MSB(tile_count)
    num_rendered = present.sum()
    sorted_keys, sorted_values = radix_sort_pairs(gaussian_keys_unsorted, gaussian_values_unsorted, num_rendered)
    
    # 6. Identify Tile Ranges (identifyTileRanges)
    ranges = identify_tile_ranges(sorted_keys)
    
    # 7. Bucket Counting (perTileBucketCount)
    # num_buckets = (num_splats + 31) / 32
    bucket_count = (ranges.diff() + 31) // 32
    
    # 8. Bucket Offset Calculation (cub::DeviceScan::InclusiveSum)
    bucket_offsets = inclusive_sum(bucket_count)
    
    # 9. Parallel Rendering (FORWARD::render)
    # Initialize sample buffer state
    sample_chunk_size = required_size_for_buckets(bucket_offsets[-1] if len(bucket_offsets) > 0 else 0)
    sample_chunkptr = allocate_buffer(sample_chunk_size)
    sample_state = SampleState.from_chunk(sample_chunkptr, bucket_offsets[-1] if len(bucket_offsets) > 0 else 0)
    
    # Determine feature pointer
    if colors_precomp is not None:
        feature_ptr = colors_precomp
    else:
        feature_ptr = geom_state.rgb # From geomBuffer
        
    # Launch render kernel
    out_color = torch.zeros(image_height, image_width, 3, device=means3D.device)
    radii = torch.zeros(N, device=means3D.device)
    metricCount = torch.zeros(image_height * image_width, device=means3D.device)
    
    render_kernel(
        tile_grid=(image_width // BLOCK_X, image_height // BLOCK_Y, 1),
        block=(BLOCK_X, BLOCK_Y, 1),
        ranges=ranges,
        point_list=sorted_values,
        bucket_offsets=bucket_offsets,
        sample_state=sample_state,
        means2D=means2D,
        feature_ptr=feature_ptr,
        conic_opacity=conic_opacity,
        bg=bg,
        out_color=out_color,
        radii=radii,
        metric_map=metric_map,
        get_flag=get_flag,
        metricCount=metricCount
    )
    
    return out_color, radii, metricCount

def preprocess_gaussians(means3D, cov3Ds_precomp, opacities, viewmatrix, projmatrix, 
                         tanfovx, tanfovy, image_height, image_width, scale_modifier):
    """
    Transforms 3D Gaussians to 2D screen space.
    """
    # Transform 3D means to view space
    means_view = transform_point_4x3(viewmatrix, means3D)
    
    # Project to NDC
    means_hom = transform_point_4x4(projmatrix, means_view)
    # Handle near-zero w
    w = means_hom[:, 3] + 1e-7
    means_ndc = means_hom[:, :3] / w.unsqueeze(1)
    
    # NDC to Pixel
    # pix = ((v + 1.0) * S - 1.0) * 0.5
    pix_x = ((means_ndc[:, 0] + 1.0) * image_width - 1.0) * 0.5
    pix_y = ((means_ndc[:, 1] + 1.0) * image_height - 1.0) * 0.5
    means2D = torch.stack([pix_x, pix_y, means_ndc[:, 2]], dim=1)
    
    # Compute 2D Covariance
    # J = d(pix)/d(means_view) * J_view_to_ndc ...
    # Simplified: Project 3D covariance to 2D
    # L = Jacobian of projection
    # Sigma_2D = L @ Sigma_3D @ L^T
    # Clamp values for stability
    conic_opacity = compute_conic_covariance(means2D, cov3Ds_precomp, scale_modifier)
    
    # Determine tiles touched
    BLOCK_X = 16 # Example block size
    BLOCK_Y = 16
    max_radius = compute_max_radius(conic_opacity)
    
    rect_min = torch.clamp((means2D[:, :2] - max_radius) / BLOCK_X, min=0).int()
    rect_max = torch.clamp((means2D[:, :2] + max_radius + BLOCK_X - 1) / BLOCK_X, max=(image_width // BLOCK_X)).int()
    
    tiles_touched = (rect_max - rect_min).sum(dim=1)
    
    return means2D, conic_opacity, tiles_touched

### Parameters

### Edge Cases and Pitfalls
*   **Input Validation**: Exactly one of `SHs` or `precomputed colors` must be provided. Exactly one of `scale/rotation` pair or `precomputed 3D covariance` must be provided [S1, unofficial].
*   **Frustum Culling**: Uses a near plane threshold of `0.2f`. Points behind this are discarded. If `prefiltered` is true and a point is filtered, an assertion trap is triggered [S1, unofficial].
*   **Homogeneous Division**: Near-zero `w` is handled by adding `0.0000001f` to prevent division by zero [S1, unofficial].
*   **Debug Mode**: If `debug` is true, tensors are copied to CPU before CUDA invocation to allow snapshotting on error. Errors save `snapshot_fw.dump` or `snapshot_bw.dump` [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Dominated by the radix sort and bucket-based blending. Sorting is $O(N \log N)$ where $N$ is the number of visible Gaussians. Blending is linear in the number of splats per tile.
*   **Memory Complexity**: Requires buffers for sorted keys/values, tile ranges, bucket offsets, and sample states. Memory usage scales with the number of Gaussians and image resolution.
*   **Performance**: Optimized for high throughput on CUDA-capable GPUs by minimizing memory contention through tile-based binning and radix sorting [S1, unofficial].
*   **Strengths**: High rendering speed, differentiable, supports additional metric buffers.
*   **Limitations**: High memory overhead for large scenes due to sorting and bucketing. Debug mode is slow.

## Background
The FastGS CUDA Rasterizer is part of the FastGS project, an unofficial extension of 3D Gaussian Splatting [S1, unofficial]. It builds upon the original differentiable Gaussian rasterizer by Inria [S1, unofficial], adding optimizations for tile-based rendering and additional debugging features. It is used in training and rendering pipelines for 3D Gaussian Avatar Reconstruction and Gaussian Splatting [S1, unofficial].
