# Generalizable Pixel-Wise 3D Gaussian Splatting

Also called: GPS-Gaussian, Generalizable 3D Gaussian Splatting

## Overview
GPS-Gaussian is a feed-forward method for real-time novel view synthesis of humans from sparse camera views [S1]. It directly regresses Gaussian parameters in a feed-forward manner from source views, eliminating the need for per-subject optimization or fine-tuning [S1]. Unlike original 3D-GS which requires per-subject optimization, GPS-Gaussian is instant and generalizable [S1]. It builds on [Feed-forward and Generalizable Prediction](15832-feed-forward-and-generalizable-prediction.md) by defining 2D Gaussian parameter maps on source view image planes, where each foreground pixel corresponds to a specific Gaussian point, allowing the use of efficient 2D convolution networks [S1].

## How it works
**Inputs:** $N$ source RGB images $I_n \in \mathbb{R}^{H \times W \times 3}$ with known camera positions $C_n$ and scene center $O$. A target novel view camera position $C_{tar}$ is required for rendering.
**Outputs:** Rendered RGB image $I_{tar}$ at the target viewpoint.

**Data Structures:**
*   **Feature Maps:** $f^s \in \mathbb{R}^{H/2^s \times W/2^s \times D_s}$ for $s \in \{1, 2, 3\}$. $D_1=32, D_2=48, D_3=96$.
*   **Cost Volume:** $C \in \mathbb{R}^{H/2 \times W/2 \times W/2}$.
*   **Depth Maps:** $D \in \mathbb{R}^{H \times W}$.
*   **Gaussian Parameter Maps:** Defined on the image plane for each foreground pixel $x$:
    *   Position Map $M_p(x)$: 3D position.
    *   Color Map $M_c(x)$: RGB color.
    *   Rotation Map $M_r(x)$: Normalized rotation vector.
    *   Scaling Map $M_s(x)$: Scale factors.
    *   Opacity Map $M_\alpha(x)$: Opacity scalar.
*   **Gaussian Features:** $\Gamma \in \mathbb{R}^{H \times W \times D_G}$, intermediate feature representation before final parameter heads.

**Steps:**

1.  **View Selection:**
    Compute view vectors $V_n = C_n - O$ for all source views and $V_{tar} = C_{tar} - O$ for the target view. Calculate dot products between $V_{tar}$ and all $V_n$. Select the two source views $I_l, I_r$ with the highest dot products (nearest views) as the working set [S1].

2.  **Feature Extraction:**
    Feed rectified source images $I_l, I_r$ into a shared image encoder $E_{img}$ to extract dense feature maps. The encoder consists of residual blocks and downsampling layers. It produces features at 3 scales ($S=3$):
    $$ \{f^1_l, f^2_l, f^3_l\} = E_{img}(I_l) $$
    $$ \{f^1_r, f^2_r, f^3_r\} = E_{img}(I_r) $$
    The encoder uses a $5 \times 5$ kernel in the first conv layer (replacing the $7 \times 7$ in RAFT-Stereo) and Group Normalization instead of Batch Normalization [S1].

3.  **Cost Volume Construction:**
    Compute a 3D correlation volume $C$ from the deepest feature maps $f^3_l, f^3_r$ using matrix multiplication:
    $$ C(f^3_l, f^3_r), \quad C_{ijk} = \sum_{h} (f^3_l)_{ijh} \cdot (f^3_r)_{ikh} $$
    where $i,j$ are spatial coordinates and $k$ is the disparity index [S1].

4.  **Iterative Depth Estimation:**
    Predict a sequence of depth estimations $\{d^t_l\}_{t=1}^T$ and $\{d^t_r\}_{t=1}^T$ by looking up in volume $C$. The depth estimation module $\Phi_{depth}$ is formulated as:
    $$ \langle D_l, D_r \rangle = \Phi_{depth}(f^3_l, f^3_r, K_l, K_r) $$
    where $K_l, K_r$ are camera intrinsics. The outputs of the final iteration $(D^T_l, D^T_r)$ are upsampled to full image resolution via convex upsampling [S1].

5.  **Position Map Generation:**
    For each foreground pixel $x$, unproject from 2D to 3D using the predicted depth map $D(x)$ and projection matrix $P$:
    $$ M_p(x) = \Pi^{-1}_P (x, D(x)) $$
    This bridges 2D feature space and 3D Gaussian representation [S1].

6.  **Color Map Generation:**
    For diffuse human scenes, use the source RGB image directly as the color map:
    $$ M_c(x) = I(x) $$
    Spherical Harmonics are not predicted; constant RGB is used [S1].

7.  **Geometric Feature Fusion:**
    Construct an encoder $E_{depth}$ taking the depth map $D$ as input to complement geometric awareness. Fuse image features from $E_{img}$ and spatial features from $E_{depth}$ using a U-Net like decoder $D_{parm}$ to regress Gaussian features $\Gamma$:
    $$ \Gamma = D_{parm} (E_{img}(I) \oplus E_{depth}(D)) $$
    where $\oplus$ stands for concatenations at all feature levels. $\Gamma \in \mathbb{R}^{H \times W \times D_G}$ [S1].

8.  **Scaling Map Generation:**
    Predict scaling $h_s(\Gamma(x))$ and apply Softplus activation:
    $$ M_s(x) = \text{Softplus}(h_s(\Gamma(x))) $$
    where $h_s$ is a prediction head composed of 2 convolution layers [S1].

9.  **Opacity Map Generation:**
    Predict opacity $h_\alpha(\Gamma(x))$ and apply Sigmoid activation:
    $$ M_\alpha(x) = \text{Sigmoid}(h_\alpha(\Gamma(x))) $$
    where $h_\alpha$ is a prediction head composed of 2 convolution layers [S1].

10. **Rotation Map Generation:**
    Predict rotation $h_r(\Gamma(x))$ and apply normalization:
    $$ M_r(x) = \text{Norm}(h_r(\Gamma(x))) $$
    where $h_r$ is a prediction head composed of 2 convolution layers [S1].

11. **Aggregation and Rendering:**
    Unproject Gaussian parameter maps from both source views ($l$ and $r$) to 3D space. Aggregate the Gaussians from both views. Render the target viewpoint using differentiable Gaussian splatting [S1].

**Pseudocode:**

```python
def gps_gaussian(source_images, camera_positions, scene_center, target_camera_position):
    """
    source_images: List of N RGB images (H, W, 3)
    camera_positions: List of N camera positions (3,)
    scene_center: Scene center (3,)
    target_camera_position: Target camera position (3,)
    """
    # 1. View Selection
    view_vectors = [pos - scene_center for pos in camera_positions]
    target_view_vector = target_camera_position - scene_center
    
    # Calculate dot products and select two nearest views
    dot_products = [np.dot(v, target_view_vector) for v in view_vectors]
    indices = np.argsort(dot_products)[::-1][:2]
    idx_l, idx_r = indices[0], indices[1]
    
    I_l = source_images[idx_l]
    I_r = source_images[idx_r]
    
    # 2. Feature Extraction
    # E_img is a shared encoder with GroupNorm and 5x5 first conv
    f_l = E_img(I_l) # Returns list of 3 feature maps at 1/2, 1/4, 1/8 resolution
    f_r = E_img(I_r)
    
    # 3. Cost Volume Construction
    # Using deepest feature maps f_l[2], f_r[2]
    C = compute_correlation_volume(f_l[2], f_r[2])
    
    # 4. Iterative Depth Estimation
    # Phi_depth uses iterative updates on C
    D_l, D_r = Phi_depth(f_l[2], f_r[2], camera_positions[idx_l], camera_positions[idx_r])
    
    # 5. Position Map Generation
    # Unproject using depth and projection matrix P derived from camera params
    M_p_l = unproject_2d_to_3d(I_l, D_l, camera_positions[idx_l])
    M_p_r = unproject_2d_to_3d(I_r, D_r, camera_positions[idx_r])
    
    # 6. Color Map Generation
    M_c_l = I_l
    M_c_r = I_r
    
    # 7. Geometric Feature Fusion
    # E_depth takes depth map D
    # D_parm is U-Net like decoder
    # Concatenate image features and depth features
    Gamma_l = D_parm(concat(E_img(I_l), E_depth(D_l)))
    Gamma_r = D_parm(concat(E_img(I_r), E_depth(D_r)))
    
    # 8. Scaling Map Generation
    M_s_l = Softplus(Head_s(Gamma_l))
    M_s_r = Softplus(Head_s(Gamma_r))
    
    # 9. Opacity Map Generation
    M_alpha_l = Sigmoid(Head_alpha(Gamma_l))
    M_alpha_r = Sigmoid(Head_alpha(Gamma_r))
    
    # 10. Rotation Map Generation
    M_r_l = Normalize(Head_r(Gamma_l))
    M_r_r = Normalize(Head_r(Gamma_r))
    
    # 11. Aggregation and Rendering
    # Create Gaussian objects from maps
    Gaussians_l = create_gaussians(M_p_l, M_c_l, M_r_l, M_s_l, M_alpha_l)
    Gaussians_r = create_gaussians(M_p_r, M_c_r, M_r_r, M_s_r, M_alpha_r)
    
    # Aggregate all Gaussians
    All_Gaussians = Gaussians_l + Gaussians_r
    
    # Render target view
    I_tar = differentiable_gaussian_splatting(All_Gaussians, target_camera_position)
    
    return I_tar

def compute_correlation_volume(f_l, f_r):
    # f_l, f_r are (H/2, W/2, D)
    # C is (H/2, W/2, W/2)
    # C_ijk = sum_h (f_l)_ijh * (f_r)_ikh
    H, W, D = f_l.shape
    C = np.zeros((H, W, W))
    for i in range(H):
        for j in range(W):
            for k in range(W):
                # Dot product of feature vectors
                C[i, j, k] = np.dot(f_l[i, j, :], f_r[i, k, :])
    return C
```

**Parameters:**
*   $S=3$: Number of feature scales [S1].
*   $\beta=0.8$: Weight for L1 loss [S1].
*   $\gamma=0.2$: Weight for SSIM loss [S1].
*   $\mu=0.9$: Exponential decay weight for depth supervision loss [S1].
*   Initial Learning Rate: $2 \times 10^{-4}$ (AdamW) [S1].
*   Batch Size: 2 [S1].
*   Input Resolution: $1024 \times 1024$ [S1].
*   Training Time: ~15 hours on RTX 3090 [S1].
*   Pre-training: Depth estimation module pre-trained for 40k iterations before joint training [S1].

**Edge Cases and Pitfalls:**
*   **Occlusion:** When target regions are invisible in one or both source views, depth ambiguity occurs. GPS-Gaussian alleviates this using human priors learned from massive human images [S1].
*   **Unstable Depth Estimation:** Unstable depth estimation in early training steps strongly impacts Gaussian parameter regression. Mitigation: Pre-train the depth estimation module for 40k iterations before joint training [S1].

## Operating characteristics
*   **Time Complexity:** The source view computation (depth estimation and Gaussian parameter map regression) dominates the run-time. Novel view rendering is extremely fast.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On an RTX 3090 GPU with $1024 \times 1024$ source images:
    *   Source view computation ($T_{src}$): 14 ms (includes binocular depth estimation and Gaussian parameter map regression) [S1].
    *   Novel view rendering ($T_{novel}$): 0.8 ms per view [S1].
    *   Total time for 10 concurrent novel views: 35 ms [S1].
    *   Comparison: FloRen takes 124 ms, ENeRF takes 1261 ms for 10 views [S1].
*   **Quality:** On THuman2.0 dataset: PSNR 25.57, SSIM 0.898, LPIPS 0.112 [S1].
*   **Strengths:** Real-time rendering, generalizable to unseen scenes without per-scene optimization, handles sparse camera views better than original 3D-GS [S1].
*   **Limitations:** Requires known camera poses for source views (though the parent family includes methods that predict poses, this specific method assumes them for view selection) [S1]. Performance is specific to human subjects due to learned priors [S1].

## Background
GPS-Gaussian was introduced in 2024 by Zheng et al. [S1]. It addresses the need for real-time novel view synthesis of humans in applications like sports broadcasting and holographic communication [S1]. It builds on the principles of generalizable neural rendering and 3D Gaussian Splatting, adapting them to a feed-forward, pixel-wise parameter regression framework [S1].
