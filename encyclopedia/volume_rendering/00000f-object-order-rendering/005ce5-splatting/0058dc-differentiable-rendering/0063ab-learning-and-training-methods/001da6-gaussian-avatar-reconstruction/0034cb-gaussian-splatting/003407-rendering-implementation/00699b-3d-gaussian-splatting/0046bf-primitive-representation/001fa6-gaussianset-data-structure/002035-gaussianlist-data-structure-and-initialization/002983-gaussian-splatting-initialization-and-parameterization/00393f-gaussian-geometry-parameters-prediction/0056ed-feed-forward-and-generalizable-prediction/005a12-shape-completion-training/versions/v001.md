# Shape Completion Training

Also called: Decoder-based Shape Completion, Folding Grid Expansion for Shape Completion

## Overview
Shape Completion Training is a decoder-based method that predicts all 14 Gaussian attributes from partial 3D inputs without requiring target coordinates, utilizing a folding grid expansion to increase primitive density [S1, unofficial]. It differs from sibling methods like [AnySplat Pipeline](12847-anysplat-pipeline.md) and [FineSplat](15257-finesplat.md) by explicitly training a decoder to complete missing geometry and attributes from sparse or occluded inputs, rather than relying solely on forward rendering or global optimization [S1, unofficial].

## How it works
**Inputs:** Partial 3D point cloud or voxel representation (derived from the encoder's frozen output), including spatial coordinates and associated masks indicating visibility.
**Outputs:** A set of 1,024 3D Gaussians, each defined by 14 attributes: position (3), scale (3), rotation quaternion (4), opacity (1), and 9 spherical harmonic coefficients (DC color + 8 SH coefficients) [S1, unofficial].

**Data Structures:**
1.  **Coarse Primitives:** A list of 256 primitives. Each primitive contains 3D position $(x, y, z)$ and potentially initial attribute estimates, though the primary output is positional for the Chamfer loss.
2.  **Expanded Gaussians:** A list of 1,024 Gaussians. Each Gaussian $i$ has attributes:
    *   $\mathbf{p}_i \in \mathbb{R}^3$: Position.
    *   $\mathbf{s}_i \in \mathbb{R}^3$: Scale (log-space or linear, typically log-space in GS, but here treated as raw scale for L1 loss).
    *   $\mathbf{q}_i \in \mathbb{R}^4$: Rotation quaternion (normalized).
    *   $\alpha_i \in \mathbb{R}$: Opacity.
    *   $\mathbf{c}_i \in \mathbb{R}^9$: DC color and SH coefficients.

**Algorithm Steps:**
1.  **Freeze Encoder:** Use a pretrained encoder (e.g., from [Feed-forward and Generalizable Prediction](15832-feed-forward-and-generalizable-prediction.md)) and freeze its weights.
2.  **Decoder Architecture:** Initialize a decoder with an identical architecture to the encoder's projection head or a dedicated Transformer decoder. The decoder consists of 4 Transformer layers, each with a width of 256 and 8 attention heads [S1, unofficial].
3.  **Coarse Prediction:** Process the input through the 4 Transformer layers to predict 256 coarse primitives. These primitives serve as the initial set of Gaussian centers [S1, unofficial].
4.  **Folding Grid Expansion:** Expand the 256 coarse primitives to 1,024 Gaussians using a fixed $2 \times 2$ folding grid. This operation duplicates and slightly perturbs each coarse primitive to create a denser set of Gaussians [S1, unofficial].
5.  **Attribute Prediction:** The decoder predicts all 14 attributes for the expanded 1,024 Gaussians. No target coordinates are provided during training; the model learns to infer complete geometry and attributes [S1, unofficial].
6.  **Loss Calculation:** Compute the total loss $\mathcal{L}$ as a combination of geometric and attribute losses:
    $$ \mathcal{L} = \mathcal{L}_{Chamfer}^{2} + \mathcal{L}_{NN} + 0.1 \left( \mathcal{L}_{L1}(\alpha, s, c) + \mathcal{L}_{sign\text{-}inv}(q) \right) $$
    Where:
    *   $\mathcal{L}_{Chamfer}^{2}$: Squared $\ell_2$ Chamfer distance between predicted Gaussian positions and ground truth points.
    *   $\mathcal{L}_{NN}$: Nearest-neighbor attribute matching loss, aligning predicted attributes with the nearest ground truth point's attributes.
    *   $\mathcal{L}_{L1}(\alpha, s, c)$: $\ell_1$ loss applied to opacity $\alpha$, scale $s$, and DC coefficients $c$.
    *   $\mathcal{L}_{sign\text{-}inv}(q)$: Sign-invariant quaternion similarity loss for rotation $q$, handling the ambiguity of quaternion signs [S1, unofficial].
    *   The aggregate attribute term is weighted by 0.1 [S1, unofficial].
7.  **Optimization:** Optimize the decoder parameters using AdamW with a learning rate of $10^{-3}$, weight decay of 0.05, batch size of 64, and 5 warm-up epochs. Train for 80 epochs [S1, unofficial].
8.  **Ensembling:** Train three independent decoder seeds for each frozen encoder to improve robustness [S1, unofficial].

**Pseudocode:**
```python
def shape_completion_training(encoder, decoder, dataloader, num_epochs=80, lr=1e-3, weight_decay=0.05, warmup_epochs=5, batch_size=64):
    """
    Trains the decoder for shape completion.
    encoder: Frozen pretrained encoder.
    decoder: Decoder with 4 Transformer layers (width 256, 8 heads).
    dataloader: Yields (partial_input, ground_truth_points, ground_truth_attributes).
    """
    optimizer = AdamW(decoder.parameters(), lr=lr, weight_decay=weight_decay)
    scheduler = WarmupScheduler(optimizer, warmup_epochs, total_epochs=num_epochs)
    
    for epoch in range(num_epochs):
        for partial_input, gt_points, gt_attrs in dataloader:
            # Step 1: Encode partial input (encoder is frozen)
            with torch.no_grad():
                encoded_features = encoder(partial_input)
            
            # Step 2: Decoder predicts 256 coarse primitives
            coarse_primitives = decoder(encoded_features) # Shape: [B, 256, 3]
            
            # Step 3: Expand to 1024 Gaussians using fixed 2x2 folding grid
            # This duplicates each primitive 4 times with small perturbations
            expanded_gaussians = folding_grid_expand(coarse_primitives, grid_size=2) # Shape: [B, 1024, 3]
            
            # Step 4: Predict all 14 attributes for the 1024 Gaussians
            # The decoder outputs positions, scales, quaternions, opacity, and SH coefficients
            predictions = decoder.predict_attributes(expanded_gaussians)
            # predictions contains: pos (1024, 3), scale (1024, 3), quat (1024, 4), alpha (1024, 1), c (1024, 9)
            
            # Step 5: Compute Loss
            # Chamfer Loss: Squared L2 distance between predicted positions and GT points
            # Note: GT points may be fewer or more; use bidirectional Chamfer
            chamfer_loss = squared_chamfer_distance(predictions.pos, gt_points)
            
            # Nearest Neighbor Attribute Loss
            # Match each predicted Gaussian to the nearest GT point and compare attributes
            nn_loss = nearest_neighbor_attribute_loss(predictions, gt_points, gt_attrs)
            
            # Attribute Losses
            # L1 loss for opacity, scale, and DC coefficients
            attr_l1_loss = l1_loss(predictions.alpha, gt_attrs.alpha) + \
                           l1_loss(predictions.scale, gt_attrs.scale) + \
                           l1_loss(predictions.c, gt_attrs.c)
            
            # Sign-invariant quaternion loss
            quat_loss = sign_invariant_quaternion_loss(predictions.quat, gt_attrs.quat)
            
            # Total Loss
            loss = chamfer_loss + nn_loss + 0.1 * (attr_l1_loss + quat_loss)
            
            # Step 6: Backpropagate and optimize
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            scheduler.step()

def folding_grid_expand(primitives, grid_size=2):
    """
    Expands N primitives to N * grid_size^2 Gaussians using a fixed folding grid.
    """
    N = primitives.shape[0]
    expanded = []
    for i in range(N):
        base_pos = primitives[i]
        for dx in range(grid_size):
            for dy in range(grid_size):
                # Add small perturbation based on grid position
                perturbation = torch.tensor([dx, dy, 0.0]) * 0.01 # Example perturbation
                new_pos = base_pos + perturbation
                expanded.append(new_pos)
    return torch.stack(expanded) # Shape: [N * grid_size^2, 3]

def squared_chamfer_distance(pred_pos, gt_points):
    """
    Computes squared L2 Chamfer distance between predicted positions and ground truth points.
    """
    # Bidirectional Chamfer
    pred_to_gt = min_squared_dist(pred_pos, gt_points)
    gt_to_pred = min_squared_dist(gt_points, pred_pos)
    return torch.mean(pred_to_gt) + torch.mean(gt_to_pred)

def min_squared_dist(p1, p2):
    """
    Computes min squared L2 distance from each point in p1 to any point in p2.
    """
    # p1: [N, 3], p2: [M, 3]
    # Returns: [N]
    dists = torch.cdist(p1, p2) ** 2
    return torch.min(dists, dim=1)[0]

def nearest_neighbor_attribute_loss(predictions, gt_points, gt_attrs):
    """
    Computes nearest neighbor attribute matching loss.
    """
    # Find nearest GT point for each predicted Gaussian
    dists = torch.cdist(predictions.pos, gt_points) ** 2
    nn_indices = torch.argmin(dists, dim=1)
    
    # Gather GT attributes for nearest neighbors
    nn_alpha = gt_attrs.alpha[nn_indices]
    nn_scale = gt_attrs.scale[nn_indices]
    nn_c = gt_attrs.c[nn_indices]
    nn_quat = gt_attrs.quat[nn_indices]
    
    # Compute L1 loss for alpha, scale, c
    l1_alpha = torch.mean(torch.abs(predictions.alpha - nn_alpha))
    l1_scale = torch.mean(torch.abs(predictions.scale - nn_scale))
    l1_c = torch.mean(torch.abs(predictions.c - nn_c))
    
    # Compute sign-invariant quaternion loss
    quat_loss = sign_invariant_quaternion_loss(predictions.quat, nn_quat)
    
    return l1_alpha + l1_scale + l1_c + quat_loss

def sign_invariant_quaternion_loss(q1, q2):
    """
    Computes loss between quaternions, invariant to sign flip.
    """
    # q1, q2: [N, 4]
    # Ensure same sign
    q2_sign = torch.sign(torch.sum(q1 * q2, dim=1, keepdim=True))
    q2_aligned = q2 * q2_sign
    return torch.mean((q1 - q2_aligned) ** 2)

def l1_loss(pred, target):
    return torch.mean(torch.abs(pred - target))
```

## Operating characteristics
*   **Time Complexity:** Training involves 4 Transformer layers of width 256 and 8 heads, which is computationally moderate. The folding grid expansion is a fixed $O(N)$ operation. The Chamfer and nearest-neighbor computations are $O(N \cdot M)$ where $N=1024$ and $M$ is the number of ground truth points.
*   **Memory Complexity:** The decoder stores parameters for 4 Transformer layers. The expansion to 1,024 Gaussians increases memory usage compared to the 256 coarse primitives, but remains manageable.
*   **Performance:** Evaluated on 520 held-out objects with visible ratios {0.3, 0.5, 0.7}. The method reports render metrics using the seed-0 decoder at 50% visibility and four fixed views per object [S1, unofficial].
*   **Strengths:** Handles partial inputs effectively without target coordinates. The folding grid expansion allows for dense Gaussian representation from coarse predictions.
*   **Limitations:** Relies on a fixed expansion strategy, which may not adapt to varying levels of occlusion or noise. The loss function combines multiple terms, requiring careful tuning of weights (e.g., 0.1 for attribute loss).

## Background
Shape Completion Training was introduced in the context of Gaussian-JEPA (Joint-Embedding Predictive Learning for 3D Gaussian Splats) [S1, unofficial]. It builds on the idea of using decoders to complete missing 3D information from partial observations, leveraging the efficiency of 3D Gaussian Splatting for rendering. The method is part of a broader effort to make Gaussian Splatting more robust to incomplete data and to enable generalizable prediction from sparse inputs [S1, unofficial].
