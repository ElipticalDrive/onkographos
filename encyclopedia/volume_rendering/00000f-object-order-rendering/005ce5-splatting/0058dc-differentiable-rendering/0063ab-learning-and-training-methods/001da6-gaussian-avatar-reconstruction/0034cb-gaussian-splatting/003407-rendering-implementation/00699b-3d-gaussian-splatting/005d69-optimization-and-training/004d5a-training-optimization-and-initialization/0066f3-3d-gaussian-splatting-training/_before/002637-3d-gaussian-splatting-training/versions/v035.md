# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the photometric difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing a high-fidelity radiance field from sparse or dense image collections without relying on neural network weights, instead optimizing explicit geometric and appearance attributes [S5, unofficial]. It sets itself apart from NeRF-based methods by offering significantly faster training and inference speeds while achieving comparable image quality [S2][S4, unofficial]. Unlike static initialization methods, it employs adaptive density control to dynamically adjust the number and distribution of Gaussians during optimization [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images with known camera poses (extrinsics $R_{cw}, t_{cw}$ and intrinsics $K$) and initial 3D Gaussian parameters derived from Structure from Motion (SfM) [S2][S6, unofficial].
*   **Outputs:** Optimized Gaussian parameters: positions $\mathbf{p}_i$, rotations $q_i$, scales $\mathbf{s}_i$, opacities $\alpha_i$, and spherical harmonic coefficients $h_i$ [S6, unofficial].

**Data Structures:**
Each Gaussian primitive $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$ (initialized from SfM points) [S2][S6, unofficial].
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion, initialized as constant) [S2][S6, unofficial].
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$ (initialized between 0 and 1) [S2][S6, unofficial].
*   Opacity $\alpha_i \in [0, 1]$ (initialized as constant) [S2][S6, unofficial].
*   Appearance: Spherical Harmonic coefficients $h_i$ (initialized from SfM) [S6, unofficial].

The covariance matrix $\Sigma_i$ is computed from scale and rotation: $\Sigma_i = R_i S_i S_i^T R_i^T$, where $R_i$ is the rotation matrix derived from $q_i$ and $S_i$ is the diagonal scale matrix [S2].

**Numbered Steps:**

1.  **Initialization:**
    *   Initialize positions $\mathbf{p}_i$ in normalized bounds $[-1, 1]$ using SfM point clouds (e.g., from COLMAP) [S2][S6, unofficial].
    *   Initialize scales $\mathbf{s}_i$ between 0 and 1 [S2].
    *   Initialize rotations $q_i$ as unit quaternions [S2].
    *   Initialize opacities $\alpha_i$ and colors $h_i$ [S2][S6, unofficial].
    *   Set iteration counter $i = 0$ [S2].

2.  **Camera Sampling:**
    *   Select a training camera $V$ and its corresponding ground truth image $\hat{I}$ [S2].
    *   Cameras are selected via a round-robin iterator with periodic shuffling [S4, unofficial].
    *   Apply a downscale factor to the ground truth image based on the current training step [S4, unofficial].

3.  **Rendering (Forward Pass):**
    *   Project 3D Gaussians to 2D screen space using the camera matrix [S2].
    *   Sort Gaussians by depth for each pixel [S2].
    *   Compute pixel color $\gamma_j$ via alpha blending:
        $$ \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij} $$
        where $\tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj})$ is the accumulated transmittance, $\alpha'_{ij}$ is the effective opacity, and $c_i$ is the color [S6, unofficial].
    *   Effective opacity $\alpha'_{ij} = g \alpha_i$, where $g = \exp(-0.5 \omega'_0 d_0^2 - 0.5 \omega'_2 d_1^2 - \omega'_1 d_0 d_1)$, with $\omega'$ being upper triangular elements of the inverse 2D covariance matrix and $d$ being the distance from the Gaussian center to the pixel [S6, unofficial].

4.  **Loss Computation:**
    *   Compute loss $\mathcal{L}$ between rendered image $\gamma$ and ground truth $\gamma_{gt}$:
        $$ \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM} $$
        where $\lambda$ is the SSIM weight (default 0.2) [S6, S4, unofficial].

5.  **Backpropagation:**
    *   Compute gradients for all parameters using the chain rule [S6, unofficial].
    *   Jacobians for rotation $q_i$, scale $s_i$, SH $h_i$, opacity $\alpha_i$, and position $p_{w,i}$ are calculated by propagating gradients from pixel color $\gamma_j$ back through the rendering steps [S6, unofficial].
    *   Example Jacobian for position $p_{w,i}$:
        $$ \frac{\partial \mathcal{L}}{\partial p_{w,i}} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial u_i} \frac{\partial u_i}{\partial p_{c,i}} \frac{\partial p_{c,i}}{\partial p_{w,i}} + \dots $$
        (Includes terms for depth sorting, color, and covariance changes) [S6, unofficial].

6.  **Parameter Update:**
    *   Update parameters using the Adam optimizer [S2][S6, unofficial].

7.  **Adaptive Density Control (Refinement):**
    *   Performed periodically (e.g., every 100-500 steps) [S2][S4, unofficial].
    *   **Pruning:** If opacity $\alpha_i < \epsilon$ or the Gaussian is too large ($||S|| > \tau_S$), prune the Gaussian [S2].
    *   **Densification:** If positional gradient $\nabla_p \mathcal{L} > \tau_p$:
        *   **Over-reconstruction:** If $||S|| > \tau_S$, split the Gaussian into two [S2].
        *   **Under-reconstruction:** If $||S|| \le \tau_S$, clone the Gaussian [S2].

**Pseudocode:**

```python
def train_3dgs(cameras, initial_gaussians, num_iters=30000, ssim_weight=0.2):
    # Initialize parameters
    positions = initial_gaussians.positions  # From SfM, bounds [-1, 1]
    rotations = initial_gaussians.rotations  # Unit quaternions
    scales = initial_gaussians.scales        # Bounds [0, 1]
    opacities = initial_gaussians.opacities  # Constant
    sh_coeffs = initial_gaussians.sh_coeffs  # From SfM
    
    optimizer = Adam([positions, rotations, scales, opacities, sh_coeffs])
    camera_iterator = InfiniteRandomIterator(cameras)
    
    for step in range(1, num_iters + 1):
        # 1. Camera Sampling
        cam = camera_iterator.next()
        gt_image = cam.get_ground_truth(downscale_factor=get_downscale(step))
        
        # 2. Rendering
        rendered_image = rasterize(positions, rotations, scales, opacities, sh_coeffs, cam)
        
        # 3. Loss Computation
        loss = (1 - ssim_weight) * l1_loss(rendered_image, gt_image) + \
               ssim_weight * d_ssim_loss(rendered_image, gt_image)
        
        # 4. Backpropagation
        gradients = compute_gradients(loss, positions, rotations, scales, opacities, sh_coeffs, rendered_image, gt_image)
        
        # 5. Parameter Update
        optimizer.step(gradients)
        
        # 6. Adaptive Density Control (every refine_every steps)
        if step % refine_every == 0:
            gradients_magnitude = compute_gradient_magnitude(positions, gradients)
            
            for i in range(len(positions)):
                # Pruning
                if opacities[i] < epsilon or norm(scales[i]) > size_threshold:
                    prune_gaussian(i)
                # Densification
                elif gradients_magnitude[i] > grad_threshold:
                    if norm(scales[i]) > size_threshold:
                        split_gaussian(i)
                    else:
                        clone_gaussian(i)
    
    return positions, rotations, scales, opacities, sh_coeffs
```

## Operating characteristics
*   **Time Complexity:** Training is significantly faster than NeRFs, often completing in minutes to hours depending on scene complexity and resolution [S2][S5, unofficial]. The backward pass complexity is $O(N \cdot P)$ where $N$ is the number of Gaussians and $P$ is the number of pixels [6233-optimization-and-parallelization].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians. Default max Gaussians is 5,000,000 [S4, unofficial]. Sinc splatting variants consume less memory than standard Gaussians [S7].
*   **Performance:** Achieves real-time rendering speeds (high FPS) at 1080p or higher resolutions on modern GPUs [S5, unofficial]. PSNR and SSIM are comparable to NeRFs [S2].
*   **Strengths:** Fast training, real-time rendering, high visual fidelity [S5, unofficial].
*   **Limitations:** Can produce "floaters" or artifacts in unstructured data; sensitive to initialization; large memory footprint for high-detail scenes [S2][S3, unofficial].
*   **Hardware:** GPU-accelerated (CUDA/Metal) is standard; CPU execution is ~100x slower [S4, S3, unofficial].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. [9] (cited in [S2]) as a method for real-time radiance field rendering. It builds on the concept of splatting, using 3D Gaussians as primitives. The method initializes Gaussians from SfM point clouds (e.g., COLMAP) [S2][S6, unofficial]. It differs from NeRFs by using explicit primitives rather than implicit neural networks, enabling faster rasterization [S5, unofficial]. The training process uses adaptive density control to manage Gaussian distribution [S2].
