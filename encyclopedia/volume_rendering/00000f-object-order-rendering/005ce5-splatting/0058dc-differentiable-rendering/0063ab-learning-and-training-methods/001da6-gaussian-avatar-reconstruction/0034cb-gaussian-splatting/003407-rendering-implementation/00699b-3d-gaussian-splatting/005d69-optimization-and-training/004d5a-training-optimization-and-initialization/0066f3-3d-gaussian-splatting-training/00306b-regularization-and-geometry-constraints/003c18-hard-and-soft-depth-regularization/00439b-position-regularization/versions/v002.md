# Position Regularization
Also called: Position Constraint Loss, Surface Regularization Loss

## Overview
Position Regularization prevents floating artifacts and dramatic geometry shifts in 3D Gaussian Splatting by constraining Gaussian centers to remain close to their initial mesh positions or a reference surface [S1][S2, unofficial]. It differs from sibling methods like Global-Local Depth Normalization, which focuses on depth consistency, and Depth Reinitialization, which resets positions based on depth errors, by directly penalizing displacement from a known geometric prior (SMPL mesh or initial mesh bounds) rather than enforcing consistency with rendered depth maps [9178-hard-and-soft-depth-regularization.md].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Current Gaussian positions ($\mu$ or $p_i$), initial Gaussian positions ($\mu_{init}$ or stored initial positions), reference mesh vertices ($v_i$), and hyperparameters ($\tau_{pos}$, $\lambda_{sr}$).
*   **Outputs:** A scalar loss value used for gradient-based optimization.

**Data Structures:**
*   Gaussian positions: Vector of 3D coordinates.
*   Mesh vertices: Array of 3D coordinates from the reference mesh (e.g., SMPL).
*   Initial positions: Stored copy of Gaussian positions at initialization.

**Formulas:**
Two primary formulations exist in the literature:

1.  **Mesh-Proximity Loss (Human Gaussian Splatting):**
    $$L_{mesh} = \sum_i \text{ReLU}(\|v_i - p_i\|_2^2 - \tau_{pos})$$
    Where:
    *   $p_i$: Canonical position of the $i$-th Gaussian.
    *   $v_i$: Nearest vertex on the SMPL mesh to $p_i$.
    *   $\tau_{pos}$: Threshold representing the maximum expected distance between skin and clothes [S1].
    *   $\text{ReLU}(x) = \max(0, x)$.

2.  **Surface Regularization Loss (Phys3DGS):**
    $$L_{sr} = \|\mu - \mu_{init}\|_2^2$$
    Where:
    *   $\mu$: Current position of a Gaussian bound to the extracted mesh.
    *   $\mu_{init}$: Initial position of that Gaussian, stored separately at the start of training [S2, unofficial].

**Parameters:**
*   $\tau_{pos}$: Threshold for max distance between skin and clothes. Value not explicitly given in sources [S1].
*   $\lambda_{sr}$: Weight for the surface regularization loss in the total loss function. Value not explicitly given in sources [S2, unofficial].

**Steps:**
1.  Identify the reference geometry: either the SMPL mesh vertices [S1] or the initial Gaussian positions [S2, unofficial].
2.  For each Gaussian, find the nearest reference point ($v_i$ or $\mu_{init}$).
3.  Compute the squared Euclidean distance between the current Gaussian position and the reference point.
4.  Apply the specific loss function:
    *   If using Mesh-Proximity: Apply ReLU to the difference between squared distance and $\tau_{pos}$. Sum over all Gaussians.
    *   If using Surface Regularization: Compute the squared L2 norm of the difference between current and initial positions.
5.  Multiply by the respective weight ($\lambda_{sr}$ if applicable) and add to the total loss.

**Edge Cases and Pitfalls:**
*   **Nearest Vertex Search:** Finding $v_i$ requires efficient nearest-neighbor search. In [S1], this is done per Gaussian.
*   **Gradient Flow:** In [S1], the gradient of the distance $\|v_i - p_i\|_2$ is *not* backpropagated through the loss to avoid instability in skinning weight supervision, though it is used in the ReLU threshold calculation [S1].
*   **Storage:** [S2, unofficial] requires storing $\mu_{init}$ separately for every Gaussian, increasing memory usage.

**Pseudocode:**
```python
def position_regularization_loss(gaussians, mesh_vertices=None, initial_positions=None, tau_pos=0.0, lambda_sr=1.0):
    """
    Computes position regularization loss.
    
    Args:
        gaussians: Object with attribute 'positions' (N, 3)
        mesh_vertices: Optional, (M, 3) array of SMPL mesh vertices
        initial_positions: Optional, (N, 3) array of initial Gaussian positions
        tau_pos: Threshold for mesh proximity loss
        lambda_sr: Weight for surface regularization loss
        
    Returns:
        Scalar loss value
    """
    loss = 0.0
    
    if mesh_vertices is not None:
        # Mesh-Proximity Loss (Human Gaussian Splatting)
        # Find nearest vertex for each Gaussian
        # Note: Efficient nearest neighbor search required
        nearest_vertices = find_nearest_vertices(gaussians.positions, mesh_vertices)
        
        # Compute squared distances
        dist_sq = np.sum((gaussians.positions - nearest_vertices) ** 2, axis=1)
        
        # Apply ReLU threshold
        # ReLU(dist_sq - tau_pos)
        mesh_loss = np.sum(np.maximum(0, dist_sq - tau_pos))
        loss += mesh_loss
        
    elif initial_positions is not None:
        # Surface Regularization Loss (Phys3DGS)
        # Compute L2 norm squared between current and initial positions
        diff = gaussians.positions - initial_positions
        sr_loss = np.sum(diff ** 2)
        loss += lambda_sr * sr_loss
        
    else:
        raise ValueError("Either mesh_vertices or initial_positions must be provided")
        
    return loss
```

## Subtopics

### Canonical Position Regularization
This variant specifically encourages Gaussian positions to stay close to the SMPL mesh to avoid floating artifacts in animatable avatars [S1]. It is chosen when rendering clothed bodies where the distance between skin and clothes is bounded by $\tau_{pos}$ [S1]. It differs from general surface regularization by using a mesh-proximity threshold rather than a fixed initial position constraint [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the nearest-neighbor search for mesh vertices. If brute-force, $O(N \cdot M)$ where $N$ is Gaussians and $M$ is mesh vertices. With spatial indexing (e.g., KD-tree), it approaches $O(N \log M)$ [S1].
*   **Memory Complexity:** $O(N)$ for storing initial positions if using Phys3DGS variant [S2, unofficial]. No extra memory for SMPL variant if mesh is loaded separately [S1].
*   **Strengths:** Prevents floating artifacts and dramatic position shifts during training [S1][S2, unofficial]. Effective for inverse rendering and animatable avatars [S1][S2, unofficial].
*   **Limitations:** Requires a reference mesh or initial positions. May restrict the model's ability to learn complex geometry if the prior is inaccurate [S1][S2, unofficial].
*   **When to use:** When training on animatable avatars with SMPL priors [S1] or when inverse rendering requires stable geometry near the initial mesh [S2, unofficial].
*   **When not to use:** When no mesh prior is available and initial positions are not reliable [S1][S2, unofficial].

## Background
Originated in Human Gaussian Splatting (2024) for real-time rendering of animatable avatars, where it prevents floating artifacts by constraining Gaussians to the SMPL mesh [S1]. Also used in Phys3DGS (2024) for physically-based inverse rendering to prevent dramatic position shifts of vertices caused by large gradients in HDR space [S2, unofficial].
