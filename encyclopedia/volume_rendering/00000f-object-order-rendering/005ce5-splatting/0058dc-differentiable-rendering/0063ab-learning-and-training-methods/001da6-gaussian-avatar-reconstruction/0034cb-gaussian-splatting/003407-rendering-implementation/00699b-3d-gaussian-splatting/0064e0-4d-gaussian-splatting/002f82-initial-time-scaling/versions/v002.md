# Initial Time Scaling

Also called: Time variance initialization

## Overview
Initial Time Scaling adjusts the temporal variance of initialized 4D Gaussians to match the scene duration, preventing excessive Gaussian proliferation over long videos [S1, unofficial]. It sets the initial time scaling parameter to half of the total scene duration to leverage Gaussian anisotropy, distinguishing it from sibling methods like [Spacetime Gaussians (STG)](5997-spacetime-gaussians-stg.md) which model spacetime correlations differently, and [4D-Rotor Gaussian Splatting](6146-4d-rotor-gaussian-splatting.md) which uses rotation matrices for dynamic deformation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Total scene duration $T_{total}$ (in seconds or normalized time units).
- Output: Initial temporal variance parameter $\sigma_t$ for the 4D Gaussian initialization.

**Data Structures:**
- The 4D Gaussian is defined by a mean position $\mu \in \mathbb{R}^4$ (3D space + time) and a covariance matrix $\Sigma \in \mathbb{R}^{4 \times 4}$.
- The covariance matrix is typically parameterized by a rotation matrix $R \in SO(4)$ and a scaling matrix $S \in \mathbb{R}^{4 \times 4}$ (diagonal), such that $\Sigma = R S S^T R^T$.
- The temporal variance corresponds to the diagonal element of $S$ associated with the time dimension, denoted as $s_t$. Thus, $\sigma_t = s_t$.

**Steps:**
1. Determine the total duration of the video or dynamic scene, $T_{total}$.
2. Calculate the initial time scaling factor as half of the total duration:
   $$ \sigma_t = \frac{T_{total}}{2} $$
3. Initialize the 4D Gaussian's temporal variance parameter $s_t$ to $\sigma_t$.
4. Construct the initial covariance matrix $\Sigma$ using this $s_t$ and appropriate spatial variances and rotations.

**Parameters:**
- $T_{total}$: Total scene duration. Typical value depends on the video length (e.g., 10 seconds for a short clip).
- $\sigma_t$: Initial temporal variance. Set to $T_{total} / 2$.

**Edge Cases and Pitfalls:**
- If $T_{total}$ is very large, the resulting $\sigma_t$ will be large, leading to wide temporal support. This is intentional to prevent the need for an intractable number of Gaussians to cover the time axis [S1, unofficial].
- If the scene duration is not known a priori (e.g., streaming), this method cannot be applied directly without an estimate.
- Precision issues may arise if $T_{total}$ is extremely small or large; ensure floating-point precision is sufficient for the scale of $\sigma_t$.

**Pseudocode:**
```python
def initialize_temporal_variance(scene_duration):
    """
    Calculate initial temporal variance for 4D Gaussian Splatting.
    
    Args:
        scene_duration (float): Total duration of the scene in time units.
        
    Returns:
        float: Initial temporal variance sigma_t.
    """
    # Set initial time scaling to half of the scene's duration
    sigma_t = scene_duration / 2.0
    return sigma_t
```

## Subtopics

## Operating characteristics
- **Time Complexity:** $O(1)$ for initialization.
- **Memory Complexity:** $O(1)$ additional memory for the parameter.
- **Performance:** Reduces the number of Gaussians required to represent dynamic scenes, improving rendering efficiency and reducing memory usage for long videos [S1, unofficial].
- **Strengths:** Simple to implement, effective at controlling Gaussian count, leverages anisotropy.
- **Limitations:** Assumes uniform temporal distribution initially; may require further optimization during training to adapt to specific motion patterns.
- **When to use:** When rendering long dynamic scenes with 4D Gaussian Splatting to prevent Gaussian proliferation.
- **When not to use:** For very short scenes where the overhead is negligible, or if the temporal distribution is highly non-uniform and requires more sophisticated initialization.

## Background
The method was introduced in "Real-time Photorealistic Dynamic Scene Representation and Rendering with 4D Gaussian Splatting" [S1, unofficial]. The authors observed that if 4D Gaussians have only local support in time, the number of Gaussians becomes intractable as video length increases. By leveraging the anisotropic characteristic of Gaussians and setting the initial time scaling to half the scene duration, they avoid this predicament [S1, unofficial].
