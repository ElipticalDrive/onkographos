# Data Compression and Storage Optimization

Also called: 3DGS Compression, Scene Representation Compression

## Overview
Data Compression and Storage Optimization reduces the memory footprint and transmission overhead of 3D Gaussian Splatting (3DGS) scenes, which typically store high-dimensional per-Gaussian attributes (position, scale, rotation, opacity, and high-order Spherical Harmonics) [S1, S2, unofficial]. It distinguishes itself from sibling methods like [Pruning and Density Control](16215-pruning-and-density-control.md) by focusing on encoding efficiency rather than primitive count reduction, and from [Hardware and Computational Acceleration](16214-hardware-and-computational-acceleration.md) by targeting storage bandwidth rather than compute throughput.

## Shared principles
The family shares the goal of mapping continuous or high-cardinality Gaussian attributes to compact discrete representations. Common mechanisms include:
1.  **Vector Quantization / Codebooks:** Replacing per-Gaussian vectors (e.g., SH coefficients, scale/rotation) with indices into a shared codebook of prototypes [S1, S2, unofficial].
2.  **Sensitivity-Awareness:** Prioritizing the preservation of parameters that significantly impact image quality, often by computing gradients or energy contributions [S1, unofficial].
3.  **Spatial Coherence:** Leveraging spatial ordering (e.g., Z-order/Morton order) to improve entropy coding efficiency [S1, unofficial].
4.  **Hybrid Representation:** Combining explicit primitives with implicit fields (e.g., hash grids) for specific attributes like color [S1, unofficial].

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
Reduces storage footprint by encoding numerical attributes into compact ASCII strings using base-N character mapping. It targets transmission overhead between devices/processes.

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
Groups SH coefficients and shape parameters into codebooks using sensitivity-aware vector quantization, prioritizing parameters critical to visual quality.

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
Exploits spatial redundancy by replacing direct attribute storage with a grid-based neural field for color and a codebook for geometry, achieving >25× compression.

### [Monte Carlo Specular Energy Aggregator](15439-monte-carlo-specular-energy-aggregator.md)
Maps high-order SH radiance energy into a compact lower-order subspace via Monte Carlo projection of specular residuals, avoiding expensive distillation.

### Sparse Adaptive Scalable Compact Gaussian Splatting
A compression method that utilizes vector clustering to encode color and geometric attributes into two codebooks, employing a sensitivity-aware k-means method [S1, unofficial].

### 3DGS Quantization Compression
Reduces storage footprint by quantizing per-Gaussian attributes and using codebooks, achieving ~10× smaller sizes without significant quality loss [S2, unofficial]. Per-Gaussian attribute storage typically uses: position (FP16), scales (FP16), opacity (INT8), and spherical harmonic coefficients (INT8 or codebook-based) [S2, unofficial].

## Background
Compression techniques for 3DGS emerged as the method's memory requirements (often GBs for large scenes) became a bottleneck for storage and streaming. Early works like LightGaussian combined pruning with INT8 quantization and octree-based compression for positions [S1, unofficial]. Subsequent methods like C3DGS and SASCGS introduced hybrid implicit-explicit representations and sensitivity-aware clustering to further reduce size while maintaining novel view synthesis quality [S1, unofficial]. The field continues to evolve with specialized encoders for specific attributes (e.g., specular energy aggregation) and formats suitable for web streaming [S2, unofficial].
