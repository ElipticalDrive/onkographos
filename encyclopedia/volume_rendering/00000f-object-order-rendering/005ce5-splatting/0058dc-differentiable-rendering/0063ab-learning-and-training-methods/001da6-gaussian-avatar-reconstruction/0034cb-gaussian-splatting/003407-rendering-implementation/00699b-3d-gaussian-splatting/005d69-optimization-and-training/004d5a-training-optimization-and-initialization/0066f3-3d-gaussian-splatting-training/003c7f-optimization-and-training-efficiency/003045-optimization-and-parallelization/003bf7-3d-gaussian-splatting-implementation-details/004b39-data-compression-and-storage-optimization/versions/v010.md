# Data Compression and Storage Optimization

Also called: 3DGS Compression, Gaussian Pruning and Quantization

## Overview
This family of methods reduces the memory footprint and storage size of 3D Gaussian Splatting (3DGS) scenes, which often exceed 1GB for real-world datasets [12927-compact-3d-gaussian-representation-c3dgs.md]. The primary problem addressed is the high bandwidth and storage cost of storing unique attributes (position, scale, rotation, opacity, and high-order spherical harmonic coefficients) for millions of primitives [12927-compact-3d-gaussian-representation-c3dgs.md]. These methods distinguish themselves from rendering optimizations by focusing on data representation, quantization, and structural redundancy removal rather than pipeline acceleration [11820-ascii-based-data-compression.md].

## Shared principles
All methods in this family aim to reduce the number of bits required to represent the scene parameters while maintaining visual fidelity. They typically exploit spatial coherence, parameter redundancy, or sensitivity-based importance metrics to discard or compress less critical information [12167-sensitivity-aware-vector-clustering.md], [12927-compact-3d-gaussian-representation-c3dgs.md]. Common techniques include codebook-based quantization, pruning of low-contribution primitives, and mapping high-dimensional features to lower-dimensional subspaces [12167-sensitivity-aware-vector-clustering.md], [15439-monte-carlo-specular-energy-aggregator.md].

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
This method reduces storage and transmission size by encoding numerical parameters as ASCII strings using base-95 (integers) and base-94 (floating-point) schemes [11820-ascii-based-data-compression.md]. It focuses on data transmission efficiency during training rather than geometric quantization [11820-ascii-based-data-compression.md]. Unlike clustering methods, it does not group parameters but compresses individual values directly [11820-ascii-based-data-compression.md].

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
This scheme reduces storage by clustering spherical harmonic (SH) coefficients and Gaussian shape features into compact codebooks using sensitivity-aware vector quantization [12167-sensitivity-aware-vector-clustering.md]. It derives a sensitivity measure for each parameter to guide clustering, prioritizing parameters that significantly affect image quality [12167-sensitivity-aware-vector-clustering.md]. Unlike standard post-training quantization, it weights the k-Means distance metric by parameter sensitivity [12167-sensitivity-aware-vector-clustering.md].

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
C3DGS reduces memory by eliminating redundant primitives and compressing attributes using a volume-based masking strategy and a hash-based grid neural field for colors [12927-compact-3d-gaussian-representation-c3dgs.md]. It exploits spatial redundancy to achieve over 25× compression while maintaining reconstruction quality [12927-compact-3d-gaussian-representation-c3dgs.md]. Unlike clustering, it uses a continuous grid for color and a codebook for geometry [12927-compact-3d-gaussian-representation-c3dgs.md].

### [Monte Carlo Specular Energy Aggregator](15439-monte-carlo-specular-energy-aggregator.md)
MC-SEA maps high-order (third-order) SH radiance energy into a compact low-order (first-order) subspace to reduce memory overhead for mobile rendering [15439-monte-carlo-specular-energy-aggregator.md]. It preserves high-frequency specular features by extracting directional moments via Monte Carlo projection [15439-monte-carlo-specular-energy-aggregator.md]. Unlike distillation methods, it requires no pre-training or offline distillation, allowing direct compression during training [15439-monte-carlo-specular-energy-aggregator.md].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [12927-compact-3d-gaussian-representation-c3dgs.md]. The original implementation stores full attributes for each Gaussian, leading to large file sizes [12927-compact-3d-gaussian-representation-c3dgs.md]. Subsequent research focused on optimizing training efficiency and storage, leading to various compression techniques such as ASCII encoding for transmission [11820-ascii-based-data-compression.md], sensitivity-aware clustering [12167-sensitivity-aware-vector-clustering.md], and grid-based representations [12927-compact-3d-gaussian-representation-c3dgs.md]. These methods are used in applications requiring efficient storage and transmission of 3D scenes, such as mobile rendering and web-based visualization [15439-monte-carlo-specular-energy-aggregator.md], [12927-compact-3d-gaussian-representation-c3dgs.md].
