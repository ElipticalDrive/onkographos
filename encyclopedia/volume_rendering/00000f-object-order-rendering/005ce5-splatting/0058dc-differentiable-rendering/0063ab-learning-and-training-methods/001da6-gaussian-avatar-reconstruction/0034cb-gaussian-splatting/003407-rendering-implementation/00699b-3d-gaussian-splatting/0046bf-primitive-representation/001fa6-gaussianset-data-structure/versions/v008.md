# GaussianSet Data Structure

Also called: 3D Gaussian Representation, Gaussian Set

## Overview
The `GaussianSet` is the core data structure in 3D Gaussian Splatting (3DGS) that stores the explicit attributes of a set of $N$ 3D Gaussian primitives, enabling differentiable volume rendering via GPU rasterization [S1, unofficial]. It solves the problem of efficiently managing high-dimensional geometric and appearance data—position, orientation, scale, opacity, and spherical harmonics coefficients—by organizing them into contiguous tensors suitable for batched processing and gradient-based optimization [S1, unofficial]. Unlike implicit neural fields or hierarchical spatial structures, `GaussianSet` maintains a flat, unstructured list of primitives, prioritizing direct access and parallel computation over spatial locality [S1, unofficial].

## How it works
The `GaussianSet` serves as the container for primitive parameters and provides methods to compute derived quantities, such as the world-space covariance matrix, required for projection and rendering.

### Inputs and Outputs
- **Inputs**: Raw optimization parameters (quaternions, log-scales, logit-opacities, spherical harmonics coefficients) and the number of Gaussians $N$.
- **Outputs**: Normalized quaternions, exponentiated scales, sigmoided opacities, concatenated spherical harmonics coefficients, and computed covariance matrices.

### Data Structures
The structure consists of the following fields, typically stored as contiguous tensors on the GPU:

| Field | Type | Shape | Description |
| :--- | :--- | :--- | :--- |
| `means` | `Float32` | $(N, 3)$ | 3D position of each Gaussian in world coordinates. |
| `quats` | `Float32` | $(N, 4)$ | Unit quaternion representing orientation (w, x, y, z). |
| `scales` | `Float32` | $(N, 3)$ | Logarithmic scale parameters (exponentiated at runtime). |
| `opacities` | `Float32` | $(N,)$ | Logit opacity values (sigmoided at runtime). |
| `sh_coefficients` | `Float32` | $(N, S, 3)$ | Spherical harmonics coefficients for view-dependent color. |
| `covariances` | `Float32` | $(N, 3, 3)$ | World-space covariance matrices (computed on demand). |

*Note: $S$ is the number of SH bands per color channel, determined by the SH degree.*

### Numbered Steps and Formulas

1.  **Normalization of Quaternions**:
    The raw quaternion outputs from the optimizer are normalized to ensure they represent valid rotations.
    $$ q_{normalized} = \frac{q}{\|q\|_2} $$
    Where $q$ is the raw quaternion tensor of shape $(N, 4)$ [S1, unofficial].

2.  **Exponentiation of Scales**:
    The scale parameters are stored in log-space to ensure positive values during optimization. They are exponentiated to obtain the actual scale factors.
    $$ s = \exp(s_{raw}) $$
    Where $s_{raw}$ is the raw scale tensor of shape $(N, 3)$ [S1, unofficial].

3.  **Sigmoiding of Opacities**:
    Opacity logits are mapped to the range $(0, 1)$ using the sigmoid function.
    $$ \alpha = \sigma(\alpha_{raw}) = \frac{1}{1 + e^{-\alpha_{raw}}} $$
    Where $\alpha_{raw}$ is the raw opacity tensor of shape $(N,)$ [S1, unofficial].

4.  **Concatenation of SH Coefficients**:
    Spherical harmonics coefficients are often stored in separate tensors for different degrees (e.g., degree 0 and degree $N$). They are concatenated along the degree dimension.
    $$ SH = \text{concat}(SH_0, SH_N, \dots) $$
    Resulting in a tensor of shape $(N, S, 3)$ [S1, unofficial].

5.  **Covariance Matrix Computation**:
    The world-space covariance matrix $Cov$ is computed from the normalized quaternion and exponentiated scale.
    $$ Cov = R S R^T $$
    Where:
    - $R$ is the $3 \times 3$ rotation matrix derived from the normalized quaternion $q_{normalized}$ [S1, unofficial].
    - $S$ is the diagonal covariance matrix in local coordinates:
      $$ S = \text{diag}(s_x^2, s_y^2, s_z^2) $$
      where $s_x, s_y, s_z$ are the components of the exponentiated scale vector $s$ [S1, unofficial].

### Pseudocode

```python
import torch
import numpy as np

def compute_gaussian_set_attributes(quats_raw, scales_raw, opacities_raw, sh_coeffs_raw):
    """
    Processes raw optimization parameters into the standard GaussianSet format.
    
    Args:
        quats_raw: Tensor of shape (N, 4), raw quaternion outputs.
        scales_raw: Tensor of shape (N, 3), log-scale outputs.
        opacities_raw: Tensor of shape (N,), logit opacity outputs.
        sh_coeffs_raw: List of Tensors [sh0, shN, ...], each of shape (N, S_i, 3).
        
    Returns:
        A dictionary representing the GaussianSet with processed attributes.
    """
    # 1. Normalize quaternions
    # Ensure unit length for valid rotation representation
    quats_normalized = torch.nn.functional.normalize(quats_raw, p=2, dim=-1)
    
    # 2. Exponentiate scales
    # Convert log-space scales to positive linear space
    scales_exp = torch.exp(scales_raw)
    
    # 3. Sigmoid opacities
    # Map logits to (0, 1) range
    opacities_sig = torch.sigmoid(opacities_raw)
    
    # 4. Concatenate SH coefficients
    # Combine coefficients from different degrees into a single tensor
    sh_coefficients = torch.cat(sh_coeffs_raw, dim=-2)
    
    # 5. Compute Covariances (on-demand or precomputed)
    # This step is often deferred until rendering, but defined here for completeness
    # covariances = compute_covariances(quats_normalized, scales_exp)
    
    gaussian_set = {
        "means": None,  # Means are typically loaded separately or initialized
        "quats": quats_normalized,
        "scales": scales_exp,
        "opacities": opacities_sig,
        "sh_coefficients": sh_coefficients,
        "covariances": None  # Computed as needed
    }
    
    return gaussian_set

def compute_covariances(quats, scales):
    """
    Computes the world-space covariance matrix for each Gaussian.
    
    Args:
        quats: Tensor of shape (N, 4), normalized quaternions.
        scales: Tensor of shape (N, 3), exponentiated scales.
        
    Returns:
        Tensor of shape (N, 3, 3), covariance matrices.
    """
    N = quats.shape[0]
    
    # Convert quaternions to rotation matrices
    # R is shape (N, 3, 3)
    R = quaternion_to_rotation_matrix(quats)
    
    # Create diagonal scale matrix S
    # S = diag(sx^2, sy^2, sz^2)
    # scales is (N, 3), square it
    scales_sq = scales ** 2
    # Create diagonal tensor
    S = torch.zeros(N, 3, 3, device=quats.device, dtype=quats.dtype)
    S[:, 0, 0] = scales_sq[:, 0]
    S[:, 1, 1] = scales_sq[:, 1]
    S[:, 2, 2] = scales_sq[:, 2]
    
    # Compute Cov = R * S * R^T
    # Matrix multiplication: (N, 3, 3) @ (N, 3, 3) @ (N, 3, 3)
    Cov = torch.bmm(torch.bmm(R, S), R.transpose(1, 2))
    
    return Cov

def quaternion_to_rotation_matrix(quats):
    """
    Converts a batch of quaternions to rotation matrices.
    Assumes quats are normalized (w, x, y, z).
    
    Args:
        quats: Tensor of shape (N, 4).
        
    Returns:
        Tensor of shape (N, 3, 3).
    """
    w, x, y, z = torch.unbind(quats, dim=-1)
    
    # Precompute products
    xx, yy, zz = x*x, y*y, z*z
    xy, xz, xw = x*y, x*z, x*w
    yz, yw, zw = y*z, y*w, z*w
    
    # Construct rotation matrix
    R = torch.stack([
        1 - 2*(yy + zz),     2*(xy - zw),       2*(xz + yw),
        2*(xy + zw),         1 - 2*(xx + zz),   2*(yz - xw),
        2*(xz - yw),         2*(yz + xw),       1 - 2*(xx + yy)
    ], dim=-1).reshape(-1, 3, 3)
    
    return R
```

### Parameters and Edge Cases
- **SH Degree**: Determines the number of coefficients $S$. Higher degrees allow for more complex view-dependent effects but increase memory usage [S1, unofficial].
- **Precision**: Float32 is standard for all attributes. Double precision may be used for optimization stability but increases memory [S1, unofficial].
- **Degenerate Input**: If a quaternion is not normalized, the resulting rotation matrix will be invalid, leading to incorrect covariance computation. The normalization step (Step 1) is critical [S1, unofficial].
- **Boundary Conditions**: Opacities must be clamped or handled carefully during rendering to avoid division by zero or numerical instability in alpha blending [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Covariance computation is $O(N)$ per Gaussian, involving matrix multiplications. Rendering complexity depends on the number of Gaussians per pixel and the sorting algorithm, typically $O(N \log N)$ for sorting [S1, unofficial].
- **Memory Complexity**: $O(N \cdot (3 + 4 + 3 + 1 + S \cdot 3 + 9))$ bytes per Gaussian, dominated by SH coefficients and covariance matrices if precomputed [S1, unofficial].
- **Performance**: Enables real-time rendering (30+ FPS) on modern GPUs due to efficient rasterization and parallel processing [S1, unofficial].
- **Strengths**: High visual quality, real-time performance, differentiable optimization [S1, unofficial].
- **Limitations**: Large memory footprint for high-resolution scenes with many Gaussians; artifacts from overlapping Gaussians [S1, unofficial].

## Background
The `GaussianSet` data structure is central to the 3D Gaussian Splatting (3DGS) method, introduced by Kerbl et al. in 2023 [S1, unofficial]. It represents a shift from implicit neural radiance fields (NeRFs) to explicit, differentiable Gaussian primitives, enabling real-time novel view synthesis [S1, unofficial]. The structure has been widely adopted in various extensions and applications of 3DGS [S1, unofficial].
