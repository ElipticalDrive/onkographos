# GaussianMesh

Also called: OMeGa (specifically the GaussianMesh component as described in), Mesh-Embedded Gaussian Splatting (general category)

## Overview
GaussianMesh is a hybrid 3D representation that defines 3D Gaussian splats over an explicit triangle mesh, tying the two via joint refinement [S1, S3]. It solves the problem of coherent large-scale deformation and adaptive density control by decoupling geometric support (handled by the mesh) from textural detail (handled by the splats) [S3]. Unlike methods that allocate a fixed number of splats uniformly or keep rotation/scale fixed, GaussianMesh allows adaptive density control and free movement of splats within the face plane, guided by mesh operations [S3]. It builds on [Mesh-Embedded Gaussian Splatting](9553-mesh-embedded-gaussian-splatting.md) by introducing specific binding strategies and regularization to prevent discrepancies between Gaussian scales and face scales [S3].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of multi-view images, an initial explicit triangle mesh (reconstructed from calibrated images or estimated), and camera parameters [S2, S3].
*   **Outputs:** A jointly optimized explicit triangle mesh and a set of 2D Gaussian splats with associated attributes (color, opacity, scale, rotation) [S3].

**Data Structures:**
1.  **Mesh Parameters:**
    *   Learnable vertex positions $V \in \mathbb{R}^{N_v \times 3}$, where $N_v$ is the number of vertices [S3].
    *   Mesh faces $F \in \mathbb{R}^{N_f \times 3}$, where $N_f$ is the number of faces, defined by indices into $V$ [S3].
2.  **Gaussian Splatting Parameters:**
    *   Splat set $G$. Each splat $g_i$ has texture attributes (color, opacity) and spatial attributes (mean, scale, rotation) [S3].
3.  **Binding Map:**
    *   A mapping $B: G \rightarrow F$ such that $B(g_i) = f_j$, associating each splat to its supporting face [S3].

**Numbered Steps:**

1.  **Initialization:** Initialize Gaussians using a reconstructed explicit mesh derived from calibrated images [S2]. Assign each initial Gaussian to a mesh face via the binding map $B$ [S3].
2.  **Spatial Parameterization:** For each splat $g_i$ bound to face $f_j$ with vertices $v_1, v_2, v_3$:
    *   **Mean:** The splat mean $m$ is derived from learnable barycentric coordinates $u, w$:
        $$m = u \cdot v_1 + w \cdot v_2 + (1 - u - w) \cdot v_3$$
        where $u, w \in [0, 1]$ and $u + w \le 1$ [S3].
    *   **Scale:** The splat scale $s$ is the element-wise product of a learnable relative scale $s_{rel}$ and a predefined base scale $s_0$ derived from the mesh face:
        $$s = s_{rel} \odot s_0$$
        where $s_{rel} = (s_{rel,1}, s_{rel,2}) \in [s_{min}, s_{max}] \times [s_{min}, s_{max}]$ [S3].
    *   **Rotation:** The final rotation matrix $R$ is computed by combining the face rotation $R_s$ and an in-plane rotation parameter $R_{2d}$:
        $$R = R_s \cdot R_{2d}$$
        where $R_s$ is the rotation matrix of the triangle face, and $R_{2d}$ allows the splat to rotate within the face plane [S3].
3.  **Joint Optimization:** Optimize mesh parameters ($V, F$) and Gaussian parameters simultaneously.
    *   **Losses:** Include photometric loss from GS rasterization, mesh regularization, mesh constraints, and monocular normal supervision [S3].
    *   **Regularization:** Use mesh constraints to regularize Gaussian shapes and prevent artifacts during large deformations [S1, S2].
4.  **Adaptive Density Control (Splat Operations):** Update the binding map $B$ and splat set $G$ based on optimization gradients:
    *   **Splat Cloning/Splitting:** When a Gaussian $g_i$ bound to $f_j$ is cloned or split, create a new splat $g_{new}$. Bind $g_{new}$ to the same face $f_j$. Inherit $g_i$'s barycentric position with a small in-plane offset onto the face plane $\Pi_{f_j}$. Insert $(g_{new}, f_j)$ into $B$ [S3].
    *   **Splat Removal:** If a splat is pruned by the adaptive density controller, remove its entry from $B$ [S3].
5.  **Mesh Refinement (Face Operations):** Update the mesh topology $F$ and reassign bindings:
    *   **Mesh Subdivision:** When a face $f_j$ is subdivided into children $\{f_{jk}\}$, reassign each splat previously bound to $f_j$ to the child whose domain contains its barycentric coordinates. Preserve per-splat attributes [S3].
    *   **Mesh Removal:** When a face $f_j$ is removed, identify all splats mapped to $f_j$ and flag them for removal in subsequent steps [S3].
6.  **Deformation:** User-controlled mesh deformations are applied to $V$. Since splat means are derived from $V$ via barycentric coordinates, the deformation propagates automatically to the Gaussians, enabling real-time animation [S2].

**Pseudocode:**

```python
# Data Structures
# V: Tensor[N_v, 3], learnable vertex positions
# F: List of tuples (v1_idx, v2_idx, v3_idx), mesh faces
# G: List of Splat objects, each with attributes:
#    - bary_u, bary_w: float, barycentric coords on face
#    - color: Tensor[3], RGB
#    - opacity: float
#    - s_rel: Tensor[2], relative scale [s_min, s_max]
#    - r_2d: float, in-plane rotation angle
# B: Dict mapping splat_id -> face_idx

def get_splat_mean(splat, face_vertices):
    """
    Compute 3D mean from barycentric coords and face vertices.
    face_vertices: List of 3 vectors [v1, v2, v3]
    """
    v1, v2, v3 = face_vertices
    u = splat.bary_u
    w = splat.bary_w
    # m = u*v1 + w*v2 + (1-u-w)*v3
    return u * v1 + w * v2 + (1.0 - u - w) * v3

def get_splat_scale(splat, face_scale):
    """
    Compute 3D scale from relative scale and face base scale.
    face_scale: Tensor[2] or [3], predefined scale from mesh face
    """
    # s = s_rel odot s_0
    return splat.s_rel * face_scale

def get_splat_rotation(splat, face_normal):
    """
    Compute 3D rotation matrix from in-plane rotation and face orientation.
    face_normal: Vector normal to the face
    """
    # Rs is rotation matrix of triangle faces (derived from face geometry)
    # R2d is rotation in the plane of the face
    # R = Rs * R2d
    Rs = compute_face_rotation_matrix(face_normal)
    R2d = compute_in_plane_rotation_matrix(splat.r_2d)
    return Rs @ R2d

def update_binding_after_splat_split(old_splat_id, new_splat_id, face_idx, B):
    """
    When a splat is cloned/split, bind the new splat to the same face.
    """
    B[new_splat_id] = face_idx
    # Inherit barycentric coords with small offset [S3]

def update_binding_after_mesh_subdivision(face_idx, children_faces, B, G):
    """
    When a face is subdivided, reassign splats to child faces based on barycentric coords.
    """
    for splat_id, current_face_idx in list(B.items()):
        if current_face_idx == face_idx:
            splat = G[splat_id]
            # Determine which child face contains the splat's barycentric coordinates
            child_face_idx = find_child_face_containing_barycentric(splat.bary_u, splat.bary_w, children_faces)
            B[splat_id] = child_face_idx

def update_binding_after_mesh_removal(face_idx, B, G):
    """
    When a face is removed, flag splats for removal.
    """
    splats_to_remove = []
    for splat_id, current_face_idx in B.items():
        if current_face_idx == face_idx:
            splats_to_remove.append(splat_id)
    for splat_id in splats_to_remove:
        del B[splat_id]

def optimize_step(images, cameras, V, F, G, B):
    """
    One step of joint optimization.
    """
    # 1. Render
    rendered_images = []
    for img, cam in zip(images, cameras):
        splats_for_render = []
        for splat_id, face_idx in B.items():
            splat = G[splat_id]
            face_vertices = get_face_vertices(V, F[face_idx])
            face_scale = compute_face_scale(face_vertices)
            face_normal = compute_face_normal(face_vertices)
            
            mean = get_splat_mean(splat, face_vertices)
            scale = get_splat_scale(splat, face_scale)
            rotation = get_splat_rotation(splat, face_normal)
            
            splats_for_render.append({
                'mean': mean,
                'scale': scale,
                'rotation': rotation,
                'color': splat.color,
                'opacity': splat.opacity
            })
        
        rendered_img = rasterize_2dgs(splats_for_render, cam)
        rendered_images.append(rendered_img)
    
    # 2. Compute Losses

    total_loss = photometric_loss + mesh_loss + normal_loss

    F.step() # Note: F topology changes are handled separately via subdivision/removal
```

**Parameters:**
*   $s_{min}, s_{max}$: Bounds for the relative scale $s_{rel}$ to prevent discrepancies between Gaussian scales and face scales [S3]. Not given in the sources.
*   Learning rates for $V, F, G$ attributes: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Scale Discrepancy:** Significant discrepancies between Gaussian Splat scales and triangular face scales can cause artifacts. This is prevented by imposing upper and lower bounds for each Gaussian Splat's scale $s$ [S3].
*   **Mesh Proxy Errors:** Errors in segmentation or remeshing (if using an estimated pseudo-mesh) can produce artifacts, as the method relies on accurate mesh proxies [S1].
*   **Large Deformations:** While GaussianMesh supports large interactive deformations, artifacts may still exhibit when dealing with significant deformations in meshes with large faces if not properly regularized [S2].

## Operating characteristics
*   **Time Complexity:** Real-time deformation is achieved due to the explicit mesh-based parameterization [S2]. The joint optimization step involves rasterization of Gaussays and backpropagation through mesh parameters, which is more complex than standard 3DGS but allows for explicit mesh editing [S3].
*   **Memory Complexity:** Depends on the number of mesh vertices $N_v$, faces $N_f$, and splats $|G|$ [S3]. The binding map $B$ adds minimal overhead.
*   **Strengths:** Decouples geometric support from textural detail, allowing adaptive density control and free movement of splats within the face plane [S3]. Supports large, interactive deformations driven by mesh editing [S1]. Joint optimization improves reconstruction accuracy in challenging indoor regions compared to decoupled approaches [S3].
*   **Limitations:** Relies on accurate semantic labels or mesh proxies; errors in segmentation or remeshing can produce artifacts [S1]. Requires careful regularization and cross-view alignment to preserve plausibility when editing attributes [S1].
*   **When to use:** When explicit mesh control is required for animation or editing, and high-fidelity texture reconstruction is needed [S2, S3].
*   **When not to use:** When the scene lacks clear geometric structure or when accurate mesh proxies are unavailable [S1].

## Background
GaussianMesh was introduced as part of the OMeGa framework, which jointly optimizes explicit meshes and Gaussian splats for robust scene-level surface reconstruction [S3]. It builds upon earlier works like Mesh-GS, which utilized reconstructed explicit meshes to initialize Gaussians and employed face split and normal guidance strategies [S2]. The concept of defining Gaussians over explicit meshes to induce coherent changes via classical mesh operations was also explored in prior work [S1]. OMeGa specifically addresses limitations of previous methods, such as inaccurate geometry in texture-less regions and the decoupling of mesh extraction from optimization [S3].
