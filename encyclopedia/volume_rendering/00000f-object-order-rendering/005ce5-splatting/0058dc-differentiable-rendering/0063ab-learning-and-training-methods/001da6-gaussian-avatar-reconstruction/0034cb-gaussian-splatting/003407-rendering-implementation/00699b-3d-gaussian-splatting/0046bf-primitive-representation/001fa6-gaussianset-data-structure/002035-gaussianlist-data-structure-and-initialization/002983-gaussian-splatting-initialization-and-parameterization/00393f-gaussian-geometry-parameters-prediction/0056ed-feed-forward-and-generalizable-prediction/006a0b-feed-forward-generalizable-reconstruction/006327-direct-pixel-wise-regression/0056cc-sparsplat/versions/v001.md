# SparSplat

Also called: Generalizable 2D Gaussian Splatting, SparSplat Model, SparSplat: Fast Multi-View Reconstruction with Generalizable 2D Gaussian Splatting

## Overview
SparSplat is a generalizable, feed-forward model that maps a set of sparse input images (typically 3) and their camera poses to a pixel-aligned map of 2D Gaussian Splatting (2DGS) parameters in a single forward pass [S1, unofficial]. It solves the joint problem of fast multi-view 3D shape reconstruction and novel view synthesis (NVS) from sparse views, leveraging deep features from foundation models like DINOv2 and MASt3R [S1, unofficial]. It differs from its sibling [MVSGaussian](8985-gsgen.md) by using 2DGS primitives instead of 3D Gaussians, which ensures consistent depth across views and enables coherent TSDF mesh extraction, whereas prior generalizable GS methods are primarily optimized for NVS and fail to produce coherent surface reconstructions [S1, unofficial].

## How it works
**Inputs:** A set of $N$ color images $\{I_i\}_{i=1}^N$ (where $N=3$ during training) with resolution $H \times W$ (typically $640 \times 512$) and their corresponding camera poses $P_i$ (rotation and translation).
**Outputs:** 
1. A 2DGS parameter map $O_t = \{s, q, p, \alpha, c\} \in \mathbb{R}^{H \times W \times (2+4+3+1+3)}$ for a target view $P_t$, where $s$ is scale (2D), $q$ is rotation (quaternion, 4D), $p$ is centroid (3D), $\alpha$ is opacity (1D), and $c$ is color (3D).
2. An explicit 3D triangle mesh $S$ extracted from the splatted depths.

**Data Structures:**
The model predicts a dense tensor $O_t$ of shape $H \times W \times 13$. The channels are ordered as:
- Channels 0-1: Scale $s$ (2 floats)
- Channels 2-5: Rotation $q$ (4 floats, quaternion)
- Channels 6-8: Position $p$ (3 floats, derived from depth unprojection)
- Channel 9: Opacity $\alpha$ (1 float)
- Channels 10-12: Color $c$ (3 floats)

**Algorithm Steps:**

1. **Feature Encoding:**
   - Encode each input image $I_i$ using a Feature Pyramid Network (FPN) to obtain 2D feature maps $f_i$ [S1, unofficial].
   - Extract monocular semantic features from DINOv2 for each $I_i$ [S1, unofficial].
   - Extract pairwise dense correspondence features from MASt3R for pairs of input images [S1, unofficial].
   - *Note:* The specific fusion of DINOv2 and MASt3R features into the input stream is described as concatenating these foundation model features with the FPN image features [S1, unofficial].

2. **Homography Warping:**
   - For a target view $P_t$, warp the feature maps $f_i$ from each source view $P_i$ to the target view using homography based on the relative poses $P_t / P_i$ [S1, unofficial]. This yields warped feature maps $f_{t,i}$ [S1, unofficial].

3. **Deep MVS Branch (Depth Prediction):**
   - Merge the warped features $f_{t,i}$ into a 3D cost volume [S1, unofficial].
   - Process the cost volume with a 3D convolutional network to produce a probability volume [S1, unofficial].
   - Perform depth estimation by sampling discrete depth planes: 64 planes for the coarse stage and 8 planes for the fine stage [S1, unofficial].
   - Output a predicted depth map $D_t$ for the target view [S1, unofficial].

4. **Pixel-Aligned Prediction Branch (Gaussian Attributes):**
   - Pool the warped features $f_{t,i}$ into a target feature map $f_t$ [S1, unofficial].
   - Pass $f_t$ through a 2D convolutional network followed by a Multi-Layer Perceptron (MLP) [S1, unofficial].
   - Predict the Gaussian primitive attributes $\{s, q, \alpha, c\}$ for each pixel [S1, unofficial].

5. **Position Unprojection:**
   - Unproject the predicted depth $D_t$ using the camera intrinsics $K$ of the target view to obtain the 3D position attribute $p$ for each pixel [S1, unofficial].
   - Combine $\{s, q, p, \alpha, c\}$ to form the final parameter map $O_t$ [S1, unofficial].

6. **Rendering and Mesh Extraction:**
   - **NVS:** Render the scene using perspective-accurate 2D Gaussian Splatting rasterization [S1, unofficial].
   - **Mesh:** Render mean depth maps $D_i$ for all training views $P_i$ using the inferred splat maps $O_i = \Phi(P_i | I_1, ..., I_N)$ [S1, unofficial].
   - Perform Truncated Signed Distance Function (TSDF) fusion on the set of rendered depth maps to extract the explicit 3D triangle mesh $S$ [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn

class SparSplatModel(nn.Module):
    def __init__(self, H=640, W=512, N=3):
        super().__init__()
        # Feature encoders
        self.fpn = FPN() # Predicts 2D feature maps f_i
        self.dinov2_encoder = DINOv2() # Monocular semantic features
        self.mast3r_encoder = MASt3R() # Pairwise dense correspondence features
        
        # MVS Backbone (DeepMVS Branch)
        self.cost_volume_net = CostVolumeNetwork()
        self.prob_volume_net = ProbVolumeNetwork()
        self.depth_regression = DepthRegression(coarse_planes=64, fine_planes=8)
        
        # Gaussian Attribute Prediction (Pixel-Aligned Branch)
        self.feature_pool = FeaturePool()
        self.attr_net = AttrNetwork() # 2D Conv + MLP
        
        # Loss weights
        self.lambda_s = 0.1
        self.lambda_p = 0.05
        self.lambda_alpha = 0.05
        self.lambda_beta = 0.05
        self.lambda_gamma = 0.05
        self.lambda_1 = 0.5
        self.lambda_2 = 1.0

    def forward(self, images, poses, intrinsics, target_pose):
        """
        images: List[N] of shape (H, W, 3)
        poses: List[N] of (4, 4) camera-to-world matrices
        intrinsics: (3, 3) camera matrix K
        target_pose: (4, 4) camera-to-world matrix for target view
        """
        N = len(images)
        
        # 1. Feature Encoding
        f_list = []
        dino_feat_list = []
        mast3r_feat_list = []
        
        for i in range(N):
            f_i = self.fpn(images[i])
            f_list.append(f_i)
            dino_feat_list.append(self.dinov2_encoder(images[i]))
            # MASt3R features are pairwise, handled during warping or pre-computed
            # Assuming MASt3R provides features compatible with warping
        
        # 2. Homography Warping
        # Warp features from source views to target view
        f_t_list = []
        for i in range(N):
            # Compute relative pose
            rel_pose = target_pose @ poses[i].inverse()
            # Warp features using homography derived from rel_pose and intrinsics
            f_t_i = warp_homography(f_list[i], dino_feat_list[i], rel_pose, intrinsics)
            f_t_list.append(f_t_i)
            
        # 3. Deep MVS Branch
        # Merge features into cost volume
        cost_volume = merge_cost_volume(f_t_list)
        # Process into probability volume
        prob_volume = self.prob_volume_net(cost_volume)
        # Predict depth
        depth_coarse = self.depth_regression(prob_volume, stage='coarse')
        # Refine depth (fine stage)
        depth_fine = self.depth_regression(prob_volume, stage='fine')
        depth_map = depth_fine # Final depth D_t
        
        # 4. Pixel-Aligned Prediction Branch
        # Pool features into target feature map
        f_t = self.feature_pool(f_t_list)
        # Predict attributes {s, q, alpha, c}
        attr_map = self.attr_net(f_t)
        s = attr_map[..., 0:2]
        q = attr_map[..., 2:6]
        alpha = attr_map[..., 6]
        c = attr_map[..., 7:10]
        
        # 5. Position Unprojection
        # Unproject depth using intrinsics to get p
        p = unproject_depth(depth_map, intrinsics)
        
        # 6. Combine into O_t
        O_t = torch.cat([s, q, p, alpha.unsqueeze(-1), c], dim=-1)
        
        return O_t, depth_map

    def extract_mesh(self, images, poses, intrinsics):
        """
        Extracts 3D mesh from training views.
        """
        depth_maps = []
        for i in range(len(images)):
            # Infer splat map for each training view
            O_i, _ = self.forward(images, poses, intrinsics, poses[i])
            # Render depth map from O_i
            D_i = render_depth(O_i, poses[i], intrinsics)
            depth_maps.append(D_i)
        
        # TSDF Fusion
        mesh = tsdf_fusion(depth_maps, voxel_size=1.5)
        return mesh

    def compute_loss(self, O_t, depth_map, target_image, target_depth_gt):
        # Render image from O_t
        rendered_image = render_image(O_t, target_image.shape)
        
        # Image Loss (L1/L2)
        loss_img = torch.mean(torch.abs(rendered_image - target_image))
        
        # Depth Loss (Ldepth)
        # Guiding mean 2DGS splatted depth with ground truth
        loss_depth = torch.mean(torch.abs(depth_map - target_depth_gt))
        
        # Total Loss
        # Note: Specific weights for s, p, alpha, beta, gamma, lambda1, lambda2 
        # are defined in the paper but the exact loss function formula for 
        # Gaussian attributes is not fully detailed in the provided text.
        # We assume standard reconstruction losses.
        loss = loss_img + loss_depth 
        
        return loss
```

**Parameters:**
- Training resolution: $640 \times 512$ [S1, unofficial].
- Number of source images $N$: 3 [S1, unofficial].
- Optimizer: Adam [S1, unofficial].
- Initial learning rate: $5 \times 10^{-4}$ [S1, unofficial].
- Training steps: 300,000 [S1, unofficial].
- Hardware: Single RTX A6000 GPU [S1, unofficial].
- TSDF Voxel size: 1.5 [S1, unofficial].
- Loss weights: $\lambda_s = 0.1, \lambda_p = 0.05, \lambda_\alpha = 0.05, \lambda_\beta = 0.05, \lambda_\gamma = 0.05, \lambda_1 = 0.5, \lambda_2 = 1$ [S1, unofficial].
- Depth planes: 64 (coarse), 8 (fine) [S1, unofficial].

**Edge Cases and Pitfalls:**
- Using 3DGS instead of 2DGS causes depth inconsistencies across views, leading to TSDF producing incorrect fusions with warped/disconnected surfaces [S1, unofficial].
- Prior SOTA generalizable GS methods fail to give coherent reconstructions on TSDF fusion of rendered depth maps [S1, unofficial].
- Precision: The model relies on accurate homography warping; incorrect relative poses will degrade feature alignment [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Inference is extremely fast, approximately 2 orders of magnitude higher than prior state-of-the-art feed-forward sparse view reconstruction methods based on volume rendering of implicit representations [S1, unofficial].
- **Measured Performance:** Inference time is 0.8s (reproduced 0.88s) on an RTX A6000, compared to 66s for UfoRecon and 32s for GeoTransfer [S1, unofficial].
- **Accuracy:** On the DTU test set, SparSplat achieves PSNR 28.33, SSIM 0.938, and LPIPS 0.073 [S1, unofficial]. Mean Chamfer Distance improves from 4.37 to 1.04 when using depth loss and MASt3R features [S1, unofficial].
- **Scaling:** The method is designed for sparse views (N=3) and generalizes to datasets like BlendedMVS and Tanks and Temples without fine-tuning [S1, unofficial].
- **Strengths:** Fast inference, coherent 3D mesh extraction via TSDF, superior NVS in low-overlap regions compared to MVSGaussian [S1, unofficial].
- **Limitations:** Performance depends heavily on the quality of foundation model features (MASt3R provides significant boost over DINOv2 or image-only features) [S1, unofficial].

## Background
SparSplat was proposed by Shubhendu Jena et al. in 2025 [S1, unofficial]. It builds on the MVSGaussian framework [48] but replaces 3D Gaussians with 2D Gaussians to improve geometric consistency for surface reconstruction. It integrates features from DINOv2 [59] and MASt3R [41] to enhance generalizability. The method addresses the limitation of prior generalizable GS methods which were optimized for novel view synthesis and failed to produce coherent 3D meshes [S1, unofficial].
