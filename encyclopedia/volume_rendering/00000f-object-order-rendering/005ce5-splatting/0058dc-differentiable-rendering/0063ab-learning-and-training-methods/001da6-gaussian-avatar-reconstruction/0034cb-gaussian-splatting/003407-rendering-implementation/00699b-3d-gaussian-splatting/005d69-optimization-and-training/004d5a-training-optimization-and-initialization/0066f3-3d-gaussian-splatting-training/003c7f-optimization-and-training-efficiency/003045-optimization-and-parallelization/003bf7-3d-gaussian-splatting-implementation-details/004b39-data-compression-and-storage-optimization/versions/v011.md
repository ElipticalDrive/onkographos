# Data Compression and Storage Optimization

Also called: 3DGS Compression, Scene Representation Compression

## Overview
Data Compression and Storage Optimization reduces the memory footprint and storage requirements of 3D Gaussian Splatting (3DGS) scenes, which often exceed 1GB for large datasets [S1, S2, unofficial]. It addresses the excessive memory usage of standard 3DGS by compressing attributes such as spherical harmonic (SH) coefficients, geometry (scale/rotation), and color [S1, unofficial]. Unlike sibling methods that focus on training efficiency or geometric constraints, this family focuses on reducing the size of the scene representation through quantization, clustering, and structural pruning [S1, S2, unofficial].

## Shared principles
The core mechanism involves mapping high-dimensional or redundant Gaussian attributes to a more compact representation. Common strategies include:
1.  **Vector Quantization/Clustering:** Grouping similar attribute vectors (e.g., SH coefficients, scale, rotation) into a codebook and storing only indices [S1, S2, unofficial].
2.  **Quantization:** Reducing the bit-width of stored values (e.g., from FP32 to INT8 or FP16) [S2, unofficial].
3.  **Structural Pruning/Masking:** Removing non-essential Gaussians or using learnable masks to exclude them from rendering and storage [S1, unofficial].
4.  **Spatial Sharing:** Using hash grids or shared codebooks to exploit spatial redundancy, where neighboring Gaussians share attributes rather than storing unique values [S1, unofficial].

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
Reduces bit-width by encoding numerical values as ASCII characters to improve transmission speed. It uses specific integer and floating-point encoding maps and restricts color matrix values to one decimal place in $[0.0, 2.0]$. It distinguishes itself by focusing on transmission efficiency via character-based encoding rather than geometric simplification.

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
Reduces storage by clustering SH coefficients and shape parameters into compact codebooks using sensitivity-aware vector quantization. It derives a sensitivity measure to guide clustering, prioritizing parameters that significantly affect image quality. It differs from post-training quantization by integrating sensitivity into the clustering process.

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
Reduces memory footprint by eliminating redundant primitives and compressing attributes via spatial sharing. It uses volume-based masking to prune non-essential Gaussians and replaces per-Gaussian attribute storage with a hash-based grid neural field for color and a codebook for geometry. It achieves over 15× storage reduction.

### [Monte Carlo Specular Energy Aggregator](15439-monte-carlo-specular-energy-aggregator.md)
Maps high-order (third-order) SH radiance energy into a compact lower-order (first-order) subspace without pre-training. It solves high memory overhead in mobile 3DGS by extracting directional moments of the specular residual via Monte Carlo projection, preserving high-frequency specular features.

### Sparse Adaptive Scalable Compact Gaussian Splatting
A compression method that utilizes vector clustering to encode color and geometric attributes into two codebooks, with a sensitivity-aware k-means method [S1, unofficial].

### 3DGS Quantization Compression
Reduces storage footprint of 3DGS scenes by quantizing per-Gaussian attributes and using codebooks, achieving ~10x smaller sizes without significant quality loss [S2, unofficial]. Per-Gaussian attribute storage includes position (FP16), scales (FP16), opacity (INT8), and spherical harmonic coefficients (INT8 or codebook-based) [S2, unofficial].

## Background
The need for compression in 3DGS arises from the large number of primitives required for high-quality novel view synthesis, leading to memory usage often exceeding 1GB for large scenes [S1, unofficial]. Standard 3DGS stores unique attributes for every primitive, which is inefficient due to spatial redundancy [S1, unofficial]. Techniques like vector quantization, pruning, and hash-based representations have been adapted from NeRF compression and general graphics optimization to address these limitations [S1, S2, unofficial].
