# Atomized Proliferation

Also called: Atom Gaussian Densification

## Overview
Atomized Proliferation is a training optimization strategy for 3D Gaussian Splatting that enhances geometric precision by constraining Gaussians representing fine details into isotropic "Atom Gaussians" and prioritizing their proliferation to align with scene geometry, followed by pruning to merge large smooth surfaces [S1, unofficial]. Unlike standard 3D Gaussian Splatting, which struggles to stabilize densification and often produces noisy meshes or blurry artifacts due to elongated primitives covering voids, Atomized Proliferation uses a warm-up strategy that aggressively densifies initially and then merges, leading to a declining and stabilizing trend in Gaussian count [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ 3D Gaussians defined by mean $\mu$, covariance $\Sigma$, color $c$, and opacity $\alpha$; input Structure-from-Motion (SfM) points; hyperparameters $\tau_c, \tau_s, \varepsilon, S, t_a, t_w$.
*   **Output:** An optimized set of Gaussians with refined geometry, where fine details are represented by uniform-sized Atom Gaussians and smooth surfaces are merged.

**Data Structures:**
The method operates on the standard Gaussian representation defined in [Gaussian Representation and Truncation](12855-gaussian-representation-and-truncation.md). Additionally, it tracks:
*   **Atom Scale ($S$):** A scalar value representing the maximum allowed minimum covariance norm for atomization. Calculated as $S = P_i(d)$, where $P_i$ is the $i$-th percentile of ordered distances between input SfM points. Typically $i=1$ (first percentile) [S1, unofficial].
*   **Iteration Counter ($i$):** Current training iteration.
*   **Gradient ($\nabla_p L$):** The loss gradient with respect to the Gaussian parameters.

**Parameters:**
*   **Clone Threshold ($\tau_c$):** Threshold for cloning based on loss gradient. Typical value: $0.002$ [S1, unofficial].
*   **Split Threshold ($\tau_s$):** Base threshold for splitting. Typical value: $0.002$ [S1, unofficial].
*   **Prune Threshold ($\varepsilon$):** Opacity threshold for pruning. Typical value: $0.005$ (or $0.5$ for object-centered datasets like DTU) [S1, unofficial].
*   **Atom Scale ($S$):** Derived from SfM points. Typical value: $P_1(d)$ [S1, unofficial].
*   **Atomized Proliferation Duration ($t_a$):** Iteration limit for atomization. Typical value: $7000$ [S1, unofficial].
*   **Warm-Up Duration ($t_w$):** Iteration limit for the warm-up phase. Typical value: $7000$ [S1, unofficial].

**Algorithm Steps:**
The algorithm iterates through all Gaussians in the set $(M, S, C, A)$ representing mean, covariance, color, and opacity [S1, unofficial].

1.  **Initialization:** Calculate Atom Scale $S$ from input SfM points. Set $S = P_i(d)$ [S1, unofficial].
2.  **Pruning:** For each Gaussian, if opacity $\alpha < \varepsilon$ or if the covariance $\Sigma$ is excessively large (determined by `IsTooLarge($\Sigma$)`), prune the Gaussian [S1, unofficial].
3.  **Cloning:** If the loss gradient $\nabla_p L \ge \tau_c$, clone the Gaussian. This allows larger Gaussians to be cloned to bridge geometry gaps [S1, unofficial].
4.  **Splitting:** If $\nabla_p L \ge \min(\frac{i}{t_w}\tau_s, \tau_s)$ AND the maximum norm of the covariance $\|\Sigma\|_{\max} > S$, split the Gaussian. This condition applies during the warm-up phase ($i < t_w$) using a linearly increasing threshold to enhance the probability of division into smaller Atom Gaussians [S1, unofficial].
5.  **Atomization:** If the minimum norm of the covariance $\|\Sigma\|_{\min} \le S$ AND the current iteration $i < t_a$, designate the Gaussian as an Atom Gaussian.
    *   Set its size $s = \sqrt[3]{S}$ (assuming isotropic scaling where $s_1=s_2=s_3$) [S1, unofficial].
    *   Fix the Atom Gaussian scales so they are no longer optimized via backpropagation.
    *   Update the scale via geometric progression: $S_n = S_{n-1} \cdot r^{n-1}$, where $r = \sqrt[t_a]{p}$ and $p$ is the final proportion to the initial $S$. This ensures the atom scale decreases over iterations, progressively enhancing the representation of fine details [S1, unofficial].
6.  **Opacity Resetting:** Increase the frequency of opacity resetting during training to merge Gaussians depicting large, simple surfaces, rather than eliminating noisy ones near the camera [S1, unofficial].

            # 3. Splitting with warm-up

                split_threshold = tau_s

                atomize_gaussian(g, S, ta)

    return gaussians

**Edge Cases and Pitfalls:**
*   **Object-Centered Datasets:** For datasets lacking extensive backgrounds (e.g., DTU), the Prune Threshold $\varepsilon$ should be increased (e.g., to $0.5$) to avoid over-pruning [S1, unofficial].
*   **Scale Learning Rate:** To maximize geometric accuracy, the scale learning rate $\eta_s$ should be set to $0$ for object-centered datasets [S1, unofficial].
*   **Atom Scale Calculation:** The Atom Scale $S$ is sensitive to the percentile $i$ chosen from SfM point distances. Using $P_1(d)$ is standard, but $P_{10}(d)$ may be used for specific datasets like DTU [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to or slightly faster than standard 3D Gaussian Splatting. On the Mip-NeRF360 dataset, AtomGS averages 0.28 hours compared to 3DGS's 0.40 hours [S1, unofficial].
*   **Memory Complexity:** Model size is reduced. On Mip-NeRF360, AtomGS results in 749MB compared to 3DGS's 869MB [S1, unofficial].
*   **Strengths:** Enhances geometric precision, reduces noisy meshes and blurry artifacts, and stabilizes Gaussian proliferation with a declining trend in count [S1, unofficial].
*   **Limitations:** Requires careful tuning of hyperparameters like $\varepsilon$ and $S$ for different datasets. The atomization process fixes scales, which may limit adaptability for very complex, non-uniform details if $S$ is not chosen correctly [S1, unofficial].
*   **When to Use:** When high-fidelity geometric reconstruction is required, especially for scenes with intricate details and smooth surfaces. Particularly effective for object-centered datasets with proper parameter adjustment [S1, unofficial].

## Background
Atomized Proliferation was proposed in the paper "AtomGS: Atomizing Gaussian Splatting for High-Fidelity Radiance Field" by Liu, Xu, Hu, Chen, and Feng [S1, unofficial]. The method addresses issues in standard 3D Gaussian Splatting where Gaussians may not adhere to underlying geometric structures, leading to noisy meshes and slower convergence. It introduces a two-part approach: Atomized Proliferation for fine details and geometry-guided optimization for smooth surfaces [S1, unofficial].
