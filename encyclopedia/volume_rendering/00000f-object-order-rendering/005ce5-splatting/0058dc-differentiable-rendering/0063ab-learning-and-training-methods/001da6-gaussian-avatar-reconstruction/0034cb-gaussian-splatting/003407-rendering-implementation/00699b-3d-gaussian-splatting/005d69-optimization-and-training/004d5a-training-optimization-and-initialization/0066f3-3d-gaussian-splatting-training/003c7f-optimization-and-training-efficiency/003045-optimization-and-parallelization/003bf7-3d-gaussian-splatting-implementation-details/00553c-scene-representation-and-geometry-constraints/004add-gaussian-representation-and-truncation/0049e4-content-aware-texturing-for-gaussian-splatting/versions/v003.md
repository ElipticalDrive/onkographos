# Content-Aware Texturing for Gaussian Splatting

Also called: Content-Aware Texturing, Ours

## Overview
Content-Aware Texturing augments 2D Gaussian primitives with spatially varying texture maps that add offsets to spherical harmonic colors, allowing appearance to adapt to captured content without pretrained models [S1]. It distinguishes itself from sibling methods by decoupling texture resolution from primitive geometry via world-space fixed texel sizing, using dynamic upscaling/downscaling and splitting (rather than cloning) to manage geometric and appearance errors [S1].

## How it works

### Inputs and Outputs
*   **Inputs:** A set of 2D Gaussian primitives (initialized from 3DGS or 2DGS), input images/views, and optimization hyperparameters.
*   **Outputs:** Optimized primitive parameters (position, rotation, scale, opacity, SH coefficients, texel size) and texture maps for each primitive.

### Data Structures
Each primitive $i$ stores 59 parameters, each as a 4-byte float [S1]:
1.  **Position:** `float3` ($\mu_i$)
2.  **Rotation:** `float4` (unit quaternion)
3.  **Scale:** `float2` (2DGS uses 2 scale factors; the source notes 2 scale parameters for 2DGS base) [S1]. *Note: Standard 3DGS uses 3, but this method builds on 2DGS [S1].*
4.  **Opacity:** `float` ($\omega_i$)
5.  **Color:** `float48` (Spherical Harmonics coefficients, degree 3) [S1].
6.  **Texel Size Ratio:** `float` ($t2pr_i$) [S1].

**Texture Storage:**
*   Textures are stored in a custom "jagged" tensor data structure to handle varying resolutions per primitive [S1].
*   Each texel stores 3 parameters (RGB offsets) [S1].
*   Texel values are constrained to $[-1, 1]$ via sigmoid activation on unactivated features $c'_{Ti}$: $c_{Ti} = 2\sigma(c'_{Ti}) - 1$ [S1].

### Coordinate Systems
To facilitate operations, the method uses four coordinate systems [S1]:
1.  **World Space ($p_w$):** Intersection point in world space.
2.  **World Space Centered ($p_{w0}$):** $p_w - \mu_i$.
3.  **Local Axis-Aligned ($p_l$):** $R^{-1} p_{w0}$. Since the primitive is 2D, the last component is 0, so $p_l \in \mathbb{R}^2$.
4.  **Local Normalized/Canonical ($p_c$):** $S^{-1} p_l$, where $S = \text{diag}(\sigma)$.

### Rendering
The color of a ray $r$ is computed by alpha blending in camera view space [S1]:
$$ C(r) = \sum_i w_i(p_i) c_i(d) = \sum_i T_i \omega_i G_i(p_i) c_i(d) $$
$$ T_i = \prod_{j<i} (1 - \omega_j G_j(p_j)) $$
where $G(x) = e^{-\frac{1}{2} (x^T x)}$ is the Gaussian falloff, and $T_i$ is the transmittance [S1].

The color $c_i$ of primitive $i$ combines spherical harmonics and a texture offset [S1]:
$$ c_i = SH(d) + \text{bilerp}(T_i, u) $$
where $u$ are the UV coordinates in the texture map $T_i$ [S1].

### Texture Coordinate Calculation
To prevent texture stretching during optimization, texel size is fixed in world space [S1]. The UV coordinate $u$ is calculated as [S1]:
$$ u = \frac{p_l}{k_i} + T_{\text{offset}} $$
where:
*   $p_l$ is the local axis-aligned intersection point.
*   $k_i$ is the texel size in world space units.
*   $T_{\text{offset}}$ centers the texture map.

The texel size $k_i$ is derived from the minimum pixel size $k_{\min}$ and the texel size-to-pixel size ratio $t2pr_i$ [S1]:
$$ k_i = k_{\min} \cdot t2pr_i $$
$t2pr_i$ takes values that are powers of two, with a lower bound of 1 [S1].

### Training Loss
The total loss $L$ is the sum of RGB, texture sparsity, and opacity regularization terms [S1]:
$$ L = L_{\text{RGB}} + L_{\text{texture}} + L_{\text{opacity}} $$

1.  **RGB Loss:** Weighted sum of L1 and SSIM [S1]:
    $$ L_{\text{RGB}} = (1 - \lambda_{\text{SSIM}}) L_1 + \lambda_{\text{SSIM}} L_{\text{SSIM}} $$
    Typical value: $\lambda_{\text{SSIM}} = 0.2$ [S1].

2.  **Texture Sparsity Loss:** Pushes texel values toward zero to allow downsampling [S1]:
    $$ L_{\text{texture}} = \lambda_{\text{texture}} \sum_i |c_{Ti}| $$

3.  **Opacity Regularization:** Incentivizes low-contribution primitives to disappear [S1]:
    $$ L_{\text{opacity}} = \lambda_{\text{opacity}} \frac{1}{N} \sum_i \omega_i $$

### Primitive Management and Densification
The method avoids cloning to prevent convergence issues from superimposed textured primitives [S1]. Instead, it uses splitting and dynamic texture resolution adjustment [S1].

**Error Calculation:**
Per-primitive error $E_i$ is a weighted sum of per-view errors, proportional to the primitive's contribution [S1]:
$$ E_i = \frac{\sum_{\pi \in \Pi} E_i^\pi w_i^\pi}{\sum_{\pi \in \Pi} w_i^\pi} $$
where $w_i^\pi = \sum_{r \in P_i} w_i^\pi(r)$ is the total contribution of primitive $i$ in view $\pi$, and $P_i$ is the set of pixels covered by the primitive [S1].

**Upscaling (Appearance Error):**
1.  Select the top 10% of primitives with the highest error $E_i$ [S1].
2.  If $t2pr_i \ge 2$, halve $t2pr_i$ (upscale texture resolution by factor of 4) [S1].
3.  This allows primitives in high-frequency regions to use more texels [S1].

**Downscaling (Appearance Error):**
1.  Compute error $E_d$ by comparing the original texture $T_{\text{orig}}$ to a low-pass filtered version $T_{\text{lowpass}}$, weighted by Gaussian falloff [S1]:
    $$ E_d = \frac{\sum_p G(p) (T_{\text{orig}}(p) - T_{\text{lowpass}}(p))}{\sum_p G(p)} $$
2.  If $E_d < \tau_{ds}$, double $t2pr_i$ (downscale texture resolution by factor of 4) [S1].

**Splitting (Geometric Error):**
1.  Select the top 10% of primitives with the highest error $E_i$ [S1].
2.  Check if their texture resolution exceeds a threshold $\tau_{tr}$ [S1].
3.  If so, replace the primitive with two new primitives [S1]:
    *   Displaced by $\pm 1$ standard deviation of the Gaussian along the axis.
    *   New scale is half the original scale in the corresponding axis.
    *   New texture resolution is half the original.
    *   New opacity is $G(1)$ times the original opacity [S1].
    *   Texture map is initialized by sampling the original point at the respective locations [S1].

### Pseudocode

```python
def compute_uv(p_l, k_i, t_offset):
    """Compute UV coordinates for texture lookup."""
    return p_l / k_i + t_offset

def get_texel_size(k_min, t2pr):
    """Calculate world-space texel size."""
    return k_min * t2pr

def render_primitive(primitive, ray_intersection):
    """Render a single primitive's contribution."""
    # Coordinate transforms
    p_w0 = ray_intersection - primitive.pos
    p_l = inverse_rotation(primitive.rot) @ p_w0
    # p_l is 2D (last component 0)
    
    # Texture lookup
    k_i = get_texel_size(k_min, primitive.t2pr)
    u = compute_uv(p_l, k_i, primitive.t_offset)
    texel_offset = bilerp(primitive.texture, u)
    
    # Color
    c_sh = spherical_harmonics(primitive.sh_coeffs, ray_direction)
    c_i = c_sh + texel_offset
    
    # Gaussian falloff
    p_c = inverse_scale(primitive.scale) @ p_l
    g_val = exp(-0.5 * dot(p_c, p_c))
    
    return {
        'color': c_i,
        'alpha': primitive.opacity * g_val,
        'depth': ray_intersection.z # or appropriate depth metric
    }

def calculate_per_primitive_error(primitive, views):
    """Calculate weighted error for primitive management."""
    total_weight = 0
    total_error = 0
    
    for view in views:
        # Get pixels covered by primitive in this view
        pixels = get_covered_pixels(primitive, view)
        if not pixels:
            continue
            
        # Sum of weights (contributions)
        w_view = sum(primitive.contribution(p) for p in pixels)
        
        # Sum of weighted errors
        e_view = sum(view.error_image[p] * primitive.contribution(p) for p in pixels)
        
        total_weight += w_view
        total_error += e_view * w_view
        
    return total_error / total_weight if total_weight > 0 else 0

def check_downscaling(primitive):
    """Check if texture can be downsampled."""
    t_orig = primitive.texture
    t_lowpass = lowpass_filter(t_orig)
    
    # Weighted error
    sum_g = 0
    sum_err = 0
    for p in primitive.covered_area:
        g = gaussian_falloff(p, primitive)
        err = abs(t_orig[p] - t_lowpass[p])
        sum_g += g
        sum_err += g * err
        
    e_d = sum_err / sum_g if sum_g > 0 else 0
    
    if e_d < tau_ds:
        return True
    return False

def split_primitive(primitive):
    """Split a primitive into two."""
    # Determine axis with largest scale for splitting? 
    # Source says "separately for each axis" but implies single split action in Alg 1 context.
    # We assume splitting along the axis of highest error or largest scale.
    # For simplicity, we split along the axis with max scale.
    
    axis = argmax(primitive.scale)
    std_dev = primitive.scale[axis]
    
    # Create two new primitives
    p1 = copy(primitive)
    p2 = copy(primitive)
    
    # Displace by +/- 1 std dev
    displacement = std_dev * unit_vector(axis)
    p1.pos = primitive.pos - displacement
    p2.pos = primitive.pos + displacement
    
    # Halve scale in that axis
    p1.scale[axis] = primitive.scale[axis] / 2
    p2.scale[axis] = primitive.scale[axis] / 2
    
    # Halve texture resolution
    p1.t2pr = primitive.t2pr * 2 # Larger t2pr means fewer texels
    p2.t2pr = primitive.t2pr * 2
    
    # Opacity: G(1) times original
    g1 = exp(-0.5) # G(1) = e^-0.5
    p1.opacity = primitive.opacity * g1
    p2.opacity = primitive.opacity * g1
    
    # Initialize textures by sampling
    p1.texture = sample_texture(primitive.texture, p1.pos)
    p2.texture = sample_texture(primitive.texture, p2.pos)
    
    return [p1, p2]

def update_primitives(primitives, views, iteration):
    """Main primitive management step."""
    if iteration % 100 != 0:
        return
        
    errors = {p: calculate_per_primitive_error(p, views) for p in primitives}
    
    # Sort by error
    sorted_prims = sorted(primitives, key=lambda p: errors[p], reverse=True)
    top_10_percent = sorted_prims[:len(sorted_prims)//10]
    
    new_primitives = []
    for p in top_10_percent:

        if p.t2pr > tau_tr:

            # Source implies splitting happens if error remains high after upscaling logic or if t2pr is high.
            # We split.
            new_prims = split_primitive(p)
            new_primitives.extend(new_prims)

            p.t2pr /= 2 # Halve t2pr -> upscale

        if check_downscaling(p):
```

### Edge Cases and Pitfalls
*   **Texture Stretching:** Naive mapping of canonical space to UV space causes stretching during optimization because texture parameters are coupled with primitive shape parameters [S1]. The world-space fixed texel size avoids this [S1].
*   **Cloning Incompatibility:** Cloning-based densification is incompatible because superimposition of multiple textured primitives makes convergence difficult and requires excessive parameters [S1].
*   **Primitive Growth:** If a primitive grows outside its allocated texture grid (due to lack of allocation or hitting the 256 limit), zero-padding is used. This reduces to the DC color since texels are offsets [S1].
*   **Upscaling Limit:** Upscaling is only allowed for primitives with $t2pr \ge 2$ to avoid sub-texel scaled details which can be retrieved via alpha blending [S1].
*   **Max Resolution:** A hard limit of 256 texture resolution is enforced to avoid excessive memory usage [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Memory:** Each primitive has 59 parameters (4-byte floats) plus texture storage. Textures are stored in a jagged tensor structure. The number of texels varies per primitive [S1].
*   **Training Time:** Training is 1.5-2 times slower than 2DGS due to per-ray texture querying overhead [S1].
*   **Rendering Time:** Rendering is 25% slower than 2DGS due to the same overhead [S1].

### Measured Performance
*   **DeepBlending:** SSIM 0.907, PSNR 30.03, LPIPS 0.303. 222K points, 21.6M texels, 78.1M params, 70 FPS [S1].
*   **Mip-Nerf-360:** SSIM 0.795, PSNR 27.00, LPIPS 0.263. 218K points, 46.6M texels, 152.6M params, 67 FPS [S1].
*   **Tanks&Temples:** SSIM 0.835, PSNR 23.43, LPIPS 0.225. 164K points, 10.4M texels, 41.1M params, 121 FPS [S1].

### Strengths and Limitations
*   **Strengths:** Significantly fewer parameters than BBSplat and GSTex while achieving competitive or superior quality. Dynamic texel allocation adapts to scene content frequency [S1].
*   **Limitations:** Slower training and rendering compared to 2DGS. Requires custom jagged tensor storage [S1].

### When to Use
*   Use when high-frequency detail reconstruction is needed with fewer parameters than fixed-budget methods.
*   Use when geometric and appearance errors need to be managed separately via splitting and texture upscaling.

### When Not to Use
*   Avoid if training/rendering speed is critical and 2DGS performance is acceptable.
*   Avoid if cloning-based densification is preferred for other reasons (incompatible).

## Background

### Origin
The method was introduced by Panagiotis Papantonakis, Georgios Kopanas, Frédo Durand, and George Drettakis in the paper "Content-Aware Texturing for Gaussian Splatting" [S1].

### History and Development
The method builds on 2DGS, introducing 2D primitives and content-aware texturing. It addresses limitations of fixed texel budgets (GSTex) and fixed texel-to-primitive ratios (BBSplat) by dynamically adapting texture resolution based on scene content and primitive error [S1].

### Usage
Implemented using the 3DGS codebase, introducing 2D primitives as in 2DGS. It does not use the $R^2 \to R^2$ transformation for intersection, using Eq. 1 directly in camera space instead [S1].
