# 3D Gaussian Splatting Initialization & Training Schedule

Also called: LiDAR-guided 3DGS Training, Pseudo-view Guided 3DGS Training

## Overview
This method defines the initialization and iterative training schedule for 3D Gaussian Splatting (3DGS) models, specifically addressing robust initialization via LiDAR data and regularization via pseudo-view guidance. It solves the problem of poor initialization and training instability in sparse or unstructured scenes by combining geometric priors with diffusion-based regularization. It differs from standard 3DGS pipelines by explicitly integrating LiDAR point cloud processing for initialization and a staged pseudo-view sampling schedule for training stability [S1].

## How it works
The method consists of two distinct phases: Initialization and Training Schedule. The specific implementation details vary between the LiDAR-guided approach [S1] and the improved optimization pipeline [S2].

### Initialization (LiDAR-Guided)
The initialization process converts sparse LiDAR data into a dense set of 3D Gaussians [S1].

1.  **Color Assignment**: Project each LiDAR point from the frame to the corresponding image frame to retrieve its color.
2.  **Re-projection**: Re-project the colored LiDAR points back into 3D space to create a colored 3D point cloud.
3.  **Accumulation**: Accumulate point clouds from all available frames.
4.  **Voxel Downsampling**: Apply voxel downsampling to the accumulated points with a voxel size of $5$ to reduce density and remove outliers.
5.  **Gaussian Initialization**: Initialize the 3D Gaussian model parameters (positions $\mu$, covariances $\Sigma$, colors, opacity $\alpha$, and spherical harmonics coefficients) from the downsampled point cloud. [G] Covariances are typically initialized based on the local point density or a fixed small value, and opacity is set to a low initial value (e.g., 0.1) to allow for densification during training.

### Training Schedule (LiDAR-Guided)
The training is performed using Stochastic Gradient Descent (SGD) for a total of 50,000 iterations [S1]. The schedule is divided into two phases:

1.  **Warm-up Phase**: Train for the first 500 iterations without sampling pseudo views. This allows the model to stabilize based on the real input images.
2.  **Guided Phase**: For every 10 iterations, sample 4 pseudo views. These pseudo views are rendered from the current 3DGS model and used to generate guidance images via a fine-tuned Diffusion Model.
    *   **Pseudo-view Generation**: Render random views not present in the training set.
    *   **Diffusion Guidance**: The rendered pseudo-view is encoded into a latent feature map by a VAE Encoder. Noise at level $t \sim [t_{min}, t_{max}]$ is added. The Diffusion Model denoises the latent feature from level $t$ to $t_{min}$, and the result is decoded to generate a guidance image.
    *   **Classifier-Free Guidance**: To enable classifier-free guidance, text prompts and reference images are set to empty with a 10% probability during training [S1].
    *   **Parameters**: Set $t_{max} = 10$ [S1].

### Improved Optimization Pipeline
An alternative schedule uses Adam optimization with a Cosine Annealing Learning Rate schedule [S2].

1.  **Initialization**: Initialize Gaussians $G$ with positions $\mu$, covariances $\Sigma$, colors $C$, opacity $\alpha$, and SH coefficients. Set initial learning rate $LR_{initial}$ and CosineAnnealingLR schedule.
2.  **Iterative Loop**: Run for 30,000 iterations [S2].
3.  **Resolution Switching**:
    *   If iteration $t < 5,000$: Render at low resolution $R_t = (540, 960)$.
    *   If iteration $t \ge 5,000$: Render at high resolution $R_t = (1080, 1920)$.
4.  **Loss Computation**: Compute the total loss $L$ as a weighted sum of components [S2]:
    $$ L = \lambda_1 L_1 + \lambda_2 (1 - SSIM) + \lambda_3 VGG + \lambda_4 LPIPS $$
    where $\lambda_1, \lambda_2, \lambda_3, \lambda_4$ are the weights for L1, SSIM, VGG, and LPIPS losses respectively.
5.  **Gradient Update**: Compute gradients $\nabla L$ with respect to Gaussian parameters and update parameters using Adam and the current learning rate from the CosineAnnealingLR schedule.
6.  **Adaptive Pruning**: For each Gaussian $G_i$:
    *   If opacity $\alpha_i < 0.005$ or the size of covariance $\Sigma_i$ exceeds a threshold, remove $G_i$ from $G$.
7.  **Improved Densification**: For each Gaussian $G_i$:
    *   If gradient magnitude $\nabla L(G_i) > \tau$:
        *   If size of $\Sigma_i > \tau_S$: Split $G_i$ into $G_{new}$ with $\Sigma_{new} = 0.8 * \Sigma_i$.
        *   Else: Clone $G_{new}$ at $\mu_i + \text{noise}(\sigma)$.
        *   Add $G_{new}$ to $G$.
8.  **Optimized Spherical Harmonics**: Compute SH-to-RGB conversion outside the rasterizer for each $G_i$ to improve performance.

### Pseudocode (Combined LiDAR-Guided Schedule)
```python
def train_3dgs_lidar_guided(LiDAR_frames, Image_frames, DiffusionModel, VAE, num_iterations=50000):
    # 1. Initialization
    colored_points = []
    for frame in LiDAR_frames:
        # Project LiDAR to image to get color
        points_with_color = project_lidar_to_image(frame.LiDAR_points, frame.Image)
        # Re-project to 3D
        points_3d = reproject_to_3d(points_with_color)
        colored_points.extend(points_3d)
    
    # Voxel downsampling with voxel size 5
    initial_points = voxel_downsample(colored_points, voxel_size=5)
    
    # Initialize Gaussians from points
    gaussians = initialize_gaussians(initial_points)
    
    # 2. Training Schedule
    for t in range(1, num_iterations + 1):
        if t <= 500:
            # Warm-up phase: no pseudo views
            loss = compute_loss(gaussians, Image_frames)
        else:
            # Guided phase: sample 4 pseudo views every 10 iterations
            if t % 10 == 0:
                pseudo_views = sample_pseudo_views(gaussians, num_views=4)
                guidance_images = []
                for view in pseudo_views:
                    # Render pseudo view
                    rendered_latent = VAE.encode(render(view))
                    # Add noise
                    noisy_latent = add_noise(rendered_latent, t_noise=random.uniform(t_min, 10))
                    # Denoise and decode
                    denoised_latent = DiffusionModel.denoise(noisy_latent, t_noise)
                    guidance_image = VAE.decode(denoised_latent)
                    guidance_images.append(guidance_image)
                loss = compute_loss_with_guidance(gaussians, Image_frames, guidance_images)
            else:
                loss = compute_loss(gaussians, Image_frames)
        
        # Update parameters
        update_gaussians(gaussians, loss)
        
    return gaussians
```

## Subtopics

### Improved 3D Gaussian Splatting Optimization Pipeline
A variant that replaces SGD with Adam and introduces a resolution switch and adaptive densification/pruning. It uses a total of 30,000 iterations, switching from low resolution (540x960) to high resolution (1080x1920) at iteration 5,000. It employs a composite loss function with L1, SSIM, VGG, and LPIPS components, and optimizes spherical harmonics computation outside the rasterizer [S2].

## Operating characteristics
*   **Time Complexity**: The LiDAR-guided method adds an initialization cost proportional to the number of LiDAR points and frames. The training cost is dominated by the rasterization and diffusion guidance. Sampling pseudo views every 10 iterations adds a constant overhead. The improved pipeline reduces training time by using lower resolution for the first 5,000 iterations [S2].
*   **Memory Complexity**: Depends on the number of Gaussians. Voxel downsampling reduces initial memory usage [S1]. Adaptive pruning removes low-opacity Gaussians, reducing memory over time [S2].
*   **Strengths**: LiDAR initialization provides robust geometric priors, reducing artifacts in sparse regions. Pseudo-view guidance regularizes training, improving generalization to unseen views. Resolution switching accelerates early training [S1, S2].
*   **Limitations**: Requires LiDAR data for initialization in the LiDAR-guided variant. Diffusion guidance adds significant computational overhead during training. The schedule parameters (e.g., 500 warm-up, 10 iteration interval) are specific to the cited implementations and may need tuning for other datasets [S1, S2].

## Background
The LiDAR-guided initialization and pseudo-view training schedule was introduced in "SGD: Street View Synthesis with Gaussian Splatting and Diffusion Prior" [S1]. The improved optimization pipeline with Adam and resolution switching was proposed in "Optimization of 3D Gaussian Splatting for Accurate Image Reconstruction" [S2]. These methods build upon the original 3D Gaussian Splatting framework [Parent](5325-training-pipeline.md) to address initialization quality and training efficiency.
