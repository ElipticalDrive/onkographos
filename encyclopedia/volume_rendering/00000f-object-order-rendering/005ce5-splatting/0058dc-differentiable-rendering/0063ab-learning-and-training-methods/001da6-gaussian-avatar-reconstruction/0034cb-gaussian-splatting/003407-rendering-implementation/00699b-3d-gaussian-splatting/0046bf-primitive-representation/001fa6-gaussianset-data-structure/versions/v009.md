# GaussianSet Data Structure

Also called: 3D Gaussian Representation, Gaussian Set

## Overview
The `GaussianSet` is a class representing a set of 3D Gaussians that stores means, orientations, scales, opacities, and spherical harmonics coefficients, and computes covariance matrices [S1, unofficial]. It solves the problem of efficiently managing high-dimensional geometric and appearance data by organizing them into contiguous tensors suitable for batched processing [S1, unofficial]. Unlike implicit neural fields or hierarchical spatial structures, it maintains a flat list of primitives prioritizing direct tensor access [S1, unofficial].

## How it works
The `GaussianSet` serves as the container for primitive parameters and provides methods to compute derived quantities, such as the world-space covariance matrix, required for projection and rendering [S1, unofficial].

### Inputs and Outputs
- **Inputs**: Raw optimization parameters (quaternions, scales, opacities, spherical harmonics coefficients) and the number of Gaussians $N$ [S1, unofficial].
- **Outputs**: Normalized quaternions, exponentiated scales, sigmoided opacities, concatenated spherical harmonics coefficients, and computed covariance matrices [S1, unofficial].

### Data Structures
The structure consists of the following fields, typically stored as contiguous tensors on the GPU:

| Field | Type | Shape | Description |
| :--- | :--- | :--- | :--- |
| `means` | `Float32` | $(N, 3)$ | 3D position of each Gaussian in world coordinates [S1, unofficial]. |
| `quats` | `Float32` | $(N, 4)$ | Unit quaternion representing orientation [S1, unofficial]. |
| `scales` | `Float32` | $(N, 3)$ | Logarithmic scale parameters (exponentiated at runtime) [S1, unofficial]. |
| `opacities` | `Float32` | $(N,)$ | Logit opacity values (sigmoided at runtime) [S1, unofficial]. |
| `sh_coefficients` | `Float32` | $(N, S, 3)$ | Spherical harmonics coefficients for view-dependent color [S1, unofficial]. |
| `covariances` | `Float32` | $(N, 3, 3)$ | World-space covariance matrices (computed on demand) [S1, unofficial]. |

*Note: $S$ is the number of SH bands per color channel, determined by the SH degree [S1, unofficial].*

### Numbered Steps and Formulas

1.  **Normalization of Quaternions**:
    The raw quaternion outputs from the optimizer are normalized to ensure they represent valid rotations.
    $$ q_{normalized} = \frac{q}{\|q\|_2} $$
    Where $q$ is the raw quaternion tensor of shape $(N, 4)$ [S1, unofficial].

2.  **Exponentiation of Scales**:
    The scale parameters are stored in log-space to ensure positive values during optimization. They are exponentiated to obtain the actual scale factors.
    $$ s = \exp(s_{raw}) $$
    Where $s_{raw}$ is the raw scale tensor of shape $(N, 3)$ [S1, unofficial].

3.  **Sigmoiding of Opacities**:
    Opacity logits are mapped to the range $(0, 1)$ using the sigmoid function.
    $$ \alpha = \sigma(\alpha_{raw}) = \frac{1}{1 + e^{-\alpha_{raw}}} $$
    Where $\alpha_{raw}$ is the raw opacity tensor of shape $(N,)$ [S1, unofficial].

4.  **Concatenation of SH Coefficients**:
    Spherical harmonics coefficients are often stored in separate tensors for different degrees (e.g., degree 0 and degree $N$). They are concatenated along the degree dimension.
    $$ SH = \text{concat}(SH_0, SH_N, \dots) $$
    Resulting in a tensor of shape $(N, S, 3)$ [S1, unofficial].

5.  **Covariance Matrix Computation**:
    The world-space covariance matrix $Cov$ is computed from the normalized quaternion and exponentiated scale.
    $$ Cov = R S R^T $$
    Where:
    - $R$ is the $3 \times 3$ rotation matrix derived from the normalized quaternion $q_{normalized}$ [S1, unofficial].
    - $S$ is the diagonal covariance matrix in local coordinates:
      $$ S = \text{diag}(s_x^2, s_y^2, s_z^2) $$
      where $s_x, s_y, s_z$ are the components of the exponentiated scale vector $s$ [S1, unofficial].

### Pseudocode

```python
import torch

def process_gaussian_set(quats_raw, scales_raw, opacities_raw, sh_coeffs_raw):
    """
    Processes raw optimization parameters into the standard GaussianSet format.
    
    Args:
        quats_raw: Tensor of shape (N, 4), raw quaternion outputs.
        scales_raw: Tensor of shape (N, 3), log-scale outputs.
        opacities_raw: Tensor of shape (N,), logit opacity outputs.
        sh_coeffs_raw: List of Tensors [sh0, shN, ...], each of shape (N, S_i, 3).
        
    Returns:
        A dictionary representing the GaussianSet with processed attributes.
    """
    # 1. Normalize quaternions
    quats_norm = torch.nn.functional.normalize(quats_raw, p=2, dim=-1)
    
    # 2. Exponentiate scales
    scales_exp = torch.exp(scales_raw)
    
    # 3. Sigmoid opacities
    opacities_sig = torch.sigmoid(opacities_raw)
    
    # 4. Concatenate SH coefficients
    sh_coefficients = torch.cat(sh_coeffs_raw, dim=-2)
    
    # 5. Compute covariances
    covariances = compute_covariances(quats_norm, scales_exp)
    
    # Means are stored directly; loading procedure not specified in sources.
    return {
        "quats": quats_norm,
        "scales": scales_exp,
        "opacities": opacities_sig,
        "sh_coefficients": sh_coefficients,
        "covariances": covariances
    }

def compute_covariances(quats, scales):
    """
    Computes the world-space covariance matrix for each Gaussian.
    
    Args:
        quats: Tensor of shape (N, 4), normalized quaternions.
        scales: Tensor of shape (N, 3), exponentiated scales.
        
    Returns:
        Tensor of shape (N, 3, 3), covariance matrices.
    """
    # Convert quaternions to rotation matrices [G]
    w, x, y, z = torch.unbind(quats, dim=-1)
    xx, yy, zz = x*x, y*y, z*z
    xy, xz, xw = x*y, x*z, x*w
    yz, yw, zw = y*z, y*w, z*w
    R = torch.stack([
        1 - 2*(yy + zz), 2*(xy - zw), 2*(xz + yw),
        2*(xy + zw), 1 - 2*(xx + zz), 2*(yz - xw),
        2*(xz - yw), 2*(yz + xw), 1 - 2*(xx + yy)
    ], dim=-1).reshape(-1, 3, 3)
    
    # Local covariance S = diag(sx^2, sy^2, sz^2)
    scales_sq = scales ** 2
    S = torch.zeros(quats.shape[0], 3, 3, device=quats.device, dtype=quats.dtype)
    S[:, 0, 0] = scales_sq[:, 0]
    S[:, 1, 1] = scales_sq[:, 1]
    S[:, 2, 2] = scales_sq[:, 2]
    
    # Cov = R S R^T
    return torch.bmm(torch.bmm(R, S), R.transpose(1, 2))
```

### Parameters and Edge Cases
- **SH Degree**: Determines the number of coefficients $S$ [S1, unofficial].
- **Time Complexity**: Covariance computation is $O(N)$ per Gaussian, involving matrix multiplications [S1, unofficial].
- **Degenerate Input**: If a quaternion is not normalized, the resulting rotation matrix will be invalid, leading to incorrect covariance computation [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Covariance computation is $O(N)$ per Gaussian, involving matrix multiplications [S1, unofficial].
- **Memory Complexity**: Memory usage scales linearly with $N$ and the number of SH coefficients $S$ [S1, unofficial].
- **Performance**: Computation is performed on the GPU using batched tensor operations [S1, unofficial].
- **Strengths**: Supports differentiable optimization and direct tensor access [S1, unofficial].
- **Limitations**: Not given in the sources.
