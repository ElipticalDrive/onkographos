# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images by converting sparse Structure-from-Motion (SfM) points into a dense, differentiable volumetric representation [S5, unofficial]. Unlike NeRFs, which optimize a continuous neural field, this method optimizes explicit geometric primitives (positions, covariances, opacities, and colors) using adaptive density control to manage complexity [S2][S5, unofficial]. It sets itself apart from its siblings by relying on heuristic-based densification (splitting/cloning) rather than neural priors or probabilistic sampling [S2][S6, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images (or video frames) with known camera poses (extrinsics $R_{cw}, t_{cw}$ and intrinsics $K$) [S6, unofficial]. Initial 3D Gaussian parameters derived from SfM point clouds [S2][S6, unofficial].
*   **Outputs:** Optimized 3D Gaussian parameters: positions $\mathbf{p}_w$, rotations $q$, scales $s$, opacities $\alpha$, and spherical harmonic coefficients $h$ [S6, unofficial].

**Data Structures:**
Each Gaussian $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$ (initialized from SfM) [S6, unofficial].
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion) [S6, unofficial].
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$ (initialized between 0 and 1) [S2].
*   Opacity $\alpha_i \in [0, 1]$ (initialized as a constant) [S6, unofficial].
*   Appearance: Spherical Harmonic coefficients $h_i$ (initialized from SfM color) [S6, unofficial].

**Numbered Steps:**

1.  **Initialization:**
    *   Initialize positions $\mathbf{p}_w$ from SfM point cloud [S2][S6, unofficial].
    *   Initialize scales $\mathbf{s}$ uniformly between 0 and 1 [S2].
    *   Initialize rotations $q$ as unit quaternions [S2].
    *   Initialize opacities $\alpha$ and colors/features $h$ via `InitAttributes()` [S2].
    *   Set iteration counter $i = 0$ [S2].

2.  **Training Loop:** While not converged (or $i <$ `numIters`):
    *   **Camera Sampling:** Select a training camera $V$ and its ground truth image $\hat{I}$ [S2]. Camera selection uses a shuffled iterator; when exhausted, reshuffle [S4, unofficial].
    *   **Rendering:** Rasterize the current Gaussians $(\mathbf{M}, \mathbf{S}, \mathbf{C}, \mathbf{A})$ using camera $V$ to obtain rendered image $I$ [S2]. This involves projecting 3D Gaussians to 2D screen space, sorting by depth, and alpha blending [Parent].
    *   **Loss Computation:** Compute loss $\mathcal{L}$ between $I$ and $\hat{I}$ [S2].
    *   **Backpropagation:** Compute gradients $\nabla \mathcal{L}$ with respect to all parameters ($q, s, h, \alpha, \mathbf{p}_w$) using the chain rule [S6, unofficial].
    *   **Optimization Step:** Update parameters using the Adam optimizer [S2][S6, unofficial].
    *   **Densification Check:** If $i$ is a refinement iteration (e.g., every `refineEvery` steps):
        *   Iterate over all Gaussians [S2].
        *   **Pruning:** If $\alpha_i < \epsilon$ or the Gaussian is too large (`IsTooLarge`), prune it [S2].
        *   **Densification:** If positional gradient $\|\nabla_{\mathbf{p}} \mathcal{L}\| > \tau_p$:
            *   **Over-reconstruction:** If covariance norm $\|\mathbf{S}\| > \tau_S$, split the Gaussian [S2].
            *   **Under-reconstruction:** Else, clone the Gaussian [S2].
    *   Increment $i$ [S2].

**Formulas:**

*   **Rotation Matrix from Quaternion:**
    Given $q = (q_r, q_i, q_j, q_k)$:
    $$
    R(q) = 2 \begin{bmatrix} \frac{1}{2} - (q_j^2 + q_k^2) & q_i q_j - q_r q_k & q_i q_k + q_r q_j \\ q_i q_j + q_r q_k & \frac{1}{2} - (q_i^2 + q_k^2) & q_j q_k - q_r q_i \\ q_i q_k - q_r q_j & q_j q_k + q_r q_i & \frac{1}{2} - (q_i^2 + q_j^2) \end{bmatrix}
    \tag{14}
    $$
    [S2][S6, unofficial]

*   **Loss Function:**
    $$
    \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM}
    \tag{2}
    $$
    where $\lambda$ is the SSIM weight (default 0.2) [S6, S4, unofficial].

*   **Jacobian for Rotation $q_i$:**
    $$
    \frac{\partial \mathcal{L}}{\partial q_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial q_i}
    \tag{4}
    $$
    [S6, unofficial]

*   **Jacobian for Scale $s_i$:**
    $$
    \frac{\partial \mathcal{L}}{\partial s_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial s_i}
    \tag{5}
    $$
    [S6, unofficial]

*   **Jacobian for SH Coefficients $h_i$:**
    $$
    \frac{\partial \mathcal{L}}{\partial h_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial c_i} \frac{\partial c_i}{\partial h_i}
    \tag{6}
    $$
    [S6, unofficial]

*   **Jacobian for Opacity $\alpha_i$:**
    $$
    \frac{\partial \mathcal{L}}{\partial \alpha_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial \alpha_i}
    \tag{7}
    $$
    [S6, unofficial]

*   **Jacobian for Position $\mathbf{p}_{w,i}$:**
    $$
    \begin{aligned}
    \frac{\partial \mathcal{L}}{\partial \mathbf{p}_{w,i}} &= \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial u_i} \frac{\partial u_i}{\partial \mathbf{p}_{c,i}} \frac{\partial \mathbf{p}_{c,i}}{\partial \mathbf{p}_{w,i}} \\
    &+ \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial c_i} \frac{\partial c_i}{\partial \mathbf{p}_{w,i}} \\
    &+ \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \mathbf{p}_{c,i}} \frac{\partial \mathbf{p}_{c,i}}{\partial \mathbf{p}_{w,i}}
    \end{aligned}
    \tag{8}
    $$
    [S6, unofficial]

*   **Pixel Color $\gamma_j$:**
    $$
    \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij}, \quad \tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj})
    $$
    [S6, unofficial]

*   **Derivative of Pixel Color w.r.t Effective Opacity $\alpha'_{i,j}$:**
    $$
    \frac{\partial \gamma_j}{\partial \alpha'_{i,j}} = \tau_{i,j}(c_i - \gamma_{i+1,j})
    \tag{B.5a}
    $$
    [S6, unofficial]

*   **Derivative of Pixel Color w.r.t Color $c_i$:**
    $$
    \frac{\partial \gamma_j}{\partial c_i} = \tau_{i,j}\alpha'_{i,j}
    \tag{B.5b}
    $$
    [S6, unofficial]

*   **Effective Opacity $\alpha'_{ij}$:**
    $$
    \alpha'_{ij} = g \alpha_i, \quad g = \exp(-0.5 \omega'_0 d_0^2 - 0.5 \omega'_2 d_1^2 - \omega'_1 d_0 d_1)
    $$
    where $\omega'$ are upper triangular elements of the inverse 2D covariance matrix, and $d$ are elements of $u_i - x_j$ [S6, unofficial].

*   **Derivative of $g$ w.r.t Inverse Covariance $\omega'_i$:**
    $$
    \frac{\partial g}{\partial \omega'_i} = [-0.5d_0^2, -d_0d_1, -0.5d_1^2]^T g
    $$
    [S6, unofficial]

*   **Derivative of $g$ w.r.t Center $u_i$:**
    $$
    \frac{\partial g}{\partial u_i} = [-\omega'_0 d_0 - \omega'_1 d_1, -\omega'_2 d_1 - \omega'_1 d_0]^T g
    $$
    [S6, unofficial]

**Parameters:**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `sh_degree`: Spherical harmonic degree. Default: 3 [S4, unofficial].
*   `sh_degree_interval`: Steps between increasing SH degree. Default: 1,000 [S4, unofficial].
*   `resolutionSchedule`: Steps between doubling image resolution. Default: 3,000 [S3, S4, unofficial].
*   `refineEvery`: Steps between densification/pruning. Default: 500 [S3, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S3, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: $\min(15000, \text{numIters}/2)$ [S3, unofficial].
*   `densify_grad_thresh`: Gradient threshold $\tau_p$. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold $\tau_S$. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size splitting stops. Default: 4,000 [S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].
*   `ssim_weight`: Weight $\lambda$ for SSIM loss. Default: 0.2 [S4, unofficial].
*   `bg_color`: Background color. Default: Magenta [0.613, 0.010, 0.398] [S4, unofficial].

**Pseudocode:**
```python
# Initialization
means = SfM_points() # p_w
scales = random_uniform(0, 1, size=(N, 3))
quats = random_unit_quaternions(N)
opacities = constant_init(N)
sh_coeffs = SfM_colors(N)

# Hyperparameters
num_iters = 30000
refine_every = 500
densify_from = 500
densify_until = min(15000, num_iters // 2)
densify_grad_thresh = 0.0002
densify_size_thresh = 0.01
ssim_weight = 0.2

optimizer = Adam([means, scales, quats, opacities, sh_coeffs])

for step in range(1, num_iters + 1):
    # 1. Camera Sampling
    cam = camera_iterator.next()
    gt_image = load_ground_truth(cam, downscale_factor_for_step(step))
    
    # 2. Rendering
    rendered_image = rasterize(means, scales, quats, opacities, sh_coeffs, cam)
    
    # 3. Loss Computation
    l1_loss = L1(rendered_image, gt_image)
    ssim_loss = D_SSIM(rendered_image, gt_image)
    loss = (1 - ssim_weight) * l1_loss + ssim_weight * ssim_loss
    
    # 4. Backpropagation
    loss.backward()
    
    # 5. Optimization Step
    optimizer.step()
    optimizer.zero_grad()
    
    # 6. Densification and Pruning (Interleaved)
    if step >= densify_from and step <= densify_until and step % refine_every == 0:
        gradients = get_gradients(means) # Positional gradients
        
        for i in range(N):
            # Pruning
            if opacities[i] < epsilon or is_too_large(scales[i]):
                prune(i)
                continue
            
            # Densification
            if gradients[i] > densify_grad_thresh:
                if norm(scales[i]) > densify_size_thresh:
                    # Over-reconstruction: Split
                    split_gaussian(i)
                else:
                    # Under-reconstruction: Clone
                    clone_gaussian(i)
```
[G] `rasterize` implements the differentiable alpha-compositing forward pass described in the parent article. `get_gradients` retrieves the accumulated gradients for the current step. `prune`, `split_gaussian`, and `clone_gaussian` modify the lists of parameters, handling index reallocation.

## Operating characteristics
*   **Time Complexity:** Training typically requires 30,000 iterations [S3, S4, unofficial]. Each iteration involves rasterization ($O(N \cdot P)$ where $N$ is Gaussians, $P$ is pixels) and backpropagation [Parent].
*   **Memory Complexity:** Scales with the number of Gaussians $N$. Default max is 5,000,000 [S3, unofficial].
*   **Performance:** Significantly faster training and inference than NeRFs [S2][S5, unofficial]. On M4 Max, training can complete in ~90 seconds with optimized Metal backends [S4, unofficial]. CPU execution is ~100x slower than GPU [S3, unofficial].
*   **Strengths:** Real-time rendering, high fidelity, fast training compared to NeRFs [S2][S5, unofficial].
*   **Limitations:** Prone to "floaters" and over-reconstruction artifacts if densification thresholds are not tuned [S2]. Requires known camera poses for standard training [Parent].
*   **Scaling:** Resolution increases dynamically via `resolutionSchedule` [S4, unofficial]. SH degree increases via `sh_degree_interval` [S4, unofficial].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. [9] (cited in [S1, S2]). It initializes positions using sparse point clouds from SfM tools like COLMAP [S2][S6, unofficial]. The method falls under the category of radiance fields but differs from NeRFs by using explicit Gaussian primitives [S5, unofficial]. It has been widely adopted for real-time rendering, SLAM, and dynamic scene reconstruction [S1].
