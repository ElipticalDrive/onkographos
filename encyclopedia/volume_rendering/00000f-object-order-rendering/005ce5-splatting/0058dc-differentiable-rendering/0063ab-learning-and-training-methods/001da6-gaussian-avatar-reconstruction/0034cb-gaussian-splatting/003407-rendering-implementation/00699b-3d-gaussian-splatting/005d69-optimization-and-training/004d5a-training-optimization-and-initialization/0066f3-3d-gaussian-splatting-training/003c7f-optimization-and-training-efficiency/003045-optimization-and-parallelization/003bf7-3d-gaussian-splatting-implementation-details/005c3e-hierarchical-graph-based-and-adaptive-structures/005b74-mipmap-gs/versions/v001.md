# Mipmap-GS

Also called: Mipmap-Gaussian Splatting

## Overview
Mipmap-GS is a test-time adaptation method that deforms pre-trained 3D Gaussians into scale-adaptive primitives to eliminate aliasing artifacts (zoom-in spikes and zoom-out thickness) caused by fixed Gaussian distributions at varying zoom factors [S1]. Unlike methods that apply heuristic 2D/3D smoothing filters or hierarchical Level-of-Detail (LoD) selection, Mipmap-GS self-adjusts primitive properties (color, shape, size) and distribution (position) by supervising the deformation against scale-specific mipmap-like pseudo ground-truth, effectively informing the Gaussians of the new sampling rate [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of base 3D Gaussians $\{G_k\}_{k=1}^K$ trained at a single basic scale ($\times 1$), a set of novel viewpoints $\{V_j\}_{j=1}^J$, a target zoom factor $N$, and the number of adaptation iterations $S$ [S1].
*   **Output:** Optimized Gaussians $\{G^{opt}_k\}_{k=1}^K$ that are deformable and adaptive to the target scale $N$ [S1].

**Data Structures**
The method operates on the standard 3D Gaussian representation. Each Gaussian $G_k$ is defined by:
*   Mean position $\mu_k \in \mathbb{R}^3$
*   Covariance matrix $\Sigma_k \in \mathbb{R}^{3 \times 3}$ (often parameterized by a rotation matrix $R_k$ and scaling vector $s_k$)
*   Opacity $\alpha_k \in [0, 1]$
*   Spherical Harmonics coefficients for color $c_k$ [S1]

**Parameters**
*   $N$: The zoom factor. For zoom-in, $N > 1$ (upsampling by $\times N$). For zoom-out, $N < 1$ (downsampling by $\times 1/N$) [S1].
*   $S$: The number of adaptation iterations. The sources specify $S = 1000$ (1K iterations) for convergence [S1].
*   $\beta$: The learning rate for the gradient descent update [S1].
*   $r(x)$: The mipmap resizing function. For zoom-in, super-resolution methods like SwinIR are used. For zoom-out, bilinear interpolation is used [S1].

**Algorithm Steps**
The optimization is performed at test time. The process is as follows:

1.  **Generate Base Rendering:** For a randomly selected viewpoint $v_j$, render the scene using the base Gaussians $\{G_k\}$ to obtain the basic scale image $\hat{x}_j$ [S1].
2.  **Construct Pseudo-GT:** Apply the mipmap resizing function $r(\cdot)$ to $\hat{x}_j$ to create the scale-specific pseudo ground-truth $r(\hat{x}_j)$.
    *   If zooming in ($\times N$), upsample $\hat{x}_j$ using a super-resolution method (e.g., SwinIR) [S1].
    *   If zooming out ($\times 1/N$), downsample $\hat{x}_j$ using bilinear interpolation [S1].
3.  **Render Optimized Gaussians:** Render the current set of optimized Gaussians $\{G^{i}_k\}$ (initially $\{G_k\}$) at the target scale to produce the image $x_j$ [S1].
4.  **Compute Loss:** Calculate the L2 loss between the rendered image $x_j$ and the pseudo-GT $r(\hat{x}_j)$:
    $$ L(x_j, r(\hat{x}_j)) = \| x_j - r(\hat{x}_j) \|_2^2 $$
    [S1]
5.  **Update Gaussians:** Update the Gaussian parameters using gradient descent:
    $$ G^{i+1}_k = G^i_k - \beta \nabla_{G^i_k} L(x_j, r(\hat{x}_j)) $$
    [S1]
6.  **Pruning/Densification:** If the iteration index $i$ is a multiple of 100, perform active pruning (and densification if applicable) to maintain a compact representation [S1].
7.  **Repeat:** Repeat steps 1-6 for $i = 0$ to $S-1$.

**Pseudocode**
```python
def mipmap_gs_optimize(base_gaussians, viewpoints, zoom_factor_N, iterations_S, learning_rate_beta):
    """
    Deforms base Gaussians to be adaptive for a specific zoom scale.
    
    Args:
        base_gaussians: List of Gaussian primitives {G_k} trained at basic scale.
        viewpoints: List of novel camera viewpoints {V_j}.
        zoom_factor_N: Integer > 1 for zoom-in (upsample by N), or float < 1 for zoom-out (downsample by 1/N).
        iterations_S: Number of optimization steps (default 1000).
        learning_rate_beta: Step size for gradient descent.
        
    Returns:
        optimized_gaussians: Deformed Gaussians {G_opt_k}.
    """
    # Initialize optimized Gaussians as a copy of base Gaussians
    current_gaussians = copy(base_gaussians)
    
    for i in range(iterations_S):
        # 1. Select viewpoint randomly
        v_j = random_choice(viewpoints)
        
        # 2. Render base Gaussians to basic scale image x_hat_j
        # This uses the standard 3DGS rasterization pipeline at the original resolution
        x_hat_j = render_3dgs(current_gaussians, v_j, scale=1.0)
        
        # 3. Construct mipmap-like pseudo-GT r(x_hat_j)
        if zoom_factor_N > 1:
            # Zoom-in: Upsample using super-resolution (e.g., SwinIR)
            pseudo_gt = super_resolution_upsample(x_hat_j, factor=zoom_factor_N)
        else:
            # Zoom-out: Downsample using bilinear interpolation
            # Note: zoom_factor_N is effectively 1/N in magnitude for downsampling logic
            # The source specifies downsampling by x 1/N. If N is the factor, 
            # we downsample by factor N.
            pseudo_gt = bilinear_downsample(x_hat_j, factor=zoom_factor_N)
            
        # 4. Render optimized Gaussians to new scale image x_j
        # The rasterizer must handle the new scale. In practice, this often involves
        # adjusting the projection matrix or the effective pixel size during splatting.
        x_j = render_3dgs(current_gaussians, v_j, scale=zoom_factor_N)
        
        # 5. Optimize current_gaussians to minimize L(x_j, pseudo_gt)
        # Loss is L2 norm squared
        loss = l2_loss(x_j, pseudo_gt)
        
        # Compute gradients with respect to Gaussian parameters (mu, sigma, alpha, SH)
        gradients = compute_gradients(loss, current_gaussians)
        
        # Update parameters
        current_gaussians = apply_gradient_descent(current_gaussians, gradients, learning_rate_beta)
        
        # 6. Active pruning every 100 iterations
        if i % 100 == 0:
            current_gaussians = active_pruning(current_gaussians)
            
    return current_gaussians
```

**Edge Cases and Pitfalls**
*   **Zoom-in Spikes:** Varying shrinkage bias leads to confusion during accumulation when sampling rates change. The constant dilation used in standard 3DGS causes thin structures and empty areas with no splats when zooming in [S1].
*   **Zoom-out Thickness:** Constant dilation leads to excessively wide coverage and thick structures when zooming out, as Gaussians that should not fall into a pixel are included due to inherited dilation [S1].
*   **Super-Resolution Artifacts:** For zoom-in, the choice of super-resolution method (e.g., SwinIR) affects the quality of the pseudo-GT. Poor super-resolution may introduce hallucinated details that mislead the Gaussian deformation [S1].
*   **Bilinear Interpolation Limitations:** For zoom-out, bilinear interpolation is used for downsampling. While efficient, it may not perfectly mimic the fading away of high-frequency details compared to more complex anti-aliasing filters, though the source notes it involves less textural deterioration than upsampling [S1].

## Operating characteristics
*   **Time Complexity:** The method requires 1K (1000) iterations of optimization per target scale. This is significantly faster than training from scratch, requiring only 3% of the iterations [S1].
*   **Memory Complexity:** Active pruning is performed throughout the optimization process (every 100 iterations), resulting in a more compact representation than standard 3DGS, which stops pruning halfway. The storage size reduction is more pronounced in zoom-out scenarios [S1].
*   **Performance:** On the NeRF Synthetic dataset, Mipmap-GS outperforms standard 3DGS in PSNR by an average of 9.25 dB for zoom-in and 10.40 dB for zoom-out [S1].
    *   At $\times 1/2$ zoom-out on NeRF Synthetic: SSIM 0.971, PSNR 32.71, LPIPS 0.026 (vs. 3DGS: SSIM 0.951, PSNR 27.14, LPIPS 0.031) [S1].
    *   At $\times 1/2$ zoom-out on Mip-NeRF 360: SSIM 0.854, PSNR 28.57 (vs. 3DGS: SSIM 0.774, PSNR 26.66) [S1].
*   **Strengths:** Plug-in module applicable to any 3DGS model; solves aliasing essentially by informing the new sampling rate rather than using filters; preserves finer details compared to heuristic filtering methods [S1].
*   **Limitations:** Requires test-time adaptation for each new scale; relies on external super-resolution models for zoom-in [S1].

## Background
Mipmap-GS was proposed to address the severe aliasing or blurriness suffered by 3D Gaussian Splatting (3DGS) when zooming in or out [S1]. Standard 3DGS uses a fixed Gaussian distribution and constant dilation, which mismatches pixel coverage at varying zoom factors. Previous methods like Mip-Splatting used heuristic 2D/3D smoothing filters that suppress high-frequency components, while Octree-GS used hierarchical LoD which is sensitive to hyper-parameters [S1]. Mipmap-GS introduces a unified optimization method that makes Gaussians adaptive for arbitrary scales by self-adjusting primitive properties and distribution using scale-specific mipmap-like pseudo ground-truth [S1].
