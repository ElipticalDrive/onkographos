# First-order Spherical Harmonics Distillation

Also called: Mobile-GS SH Distillation, SH Knowledge Distillation, SH Order Reduction via Distillation, SH degree reduction, Spherical Harmonics degree reduction

## Overview
First-order Spherical Harmonics Distillation reduces the spherical harmonics (SH) degree of 3D Gaussian elements from third-order to first-order to decrease parameter count and computation cost [S1][S2, unofficial]. It achieves this by distilling the appearance information from a high-fidelity teacher model (using third-order SH) into a lower-dimensional student model (using first-order SH) [S2, unofficial]. Unlike standard degree reduction which may suffer from significant quality loss, this method uses knowledge distillation to preserve rendering fidelity while enabling faster rendering and lower storage usage, making it suitable for mobile and edge hardware deployment [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A pretrained teacher 3D Gaussian Splatting model using third-order SH (48 coefficients per Gaussian: $3 \times 16$) [S2, unofficial].
*   **Output:** A student 3D Gaussian Splatting model using first-order SH (12 coefficients per Gaussian: $3 \times 4$) [S2, unofficial].

**Data Structures:**
The student model stores SH coefficients $\mathbf{c}_i$ for each Gaussian $i$. For first-order SH, $\mathbf{c}_i$ is a vector of size 12 (3 RGB channels $\times$ 4 SH basis functions: $Y_0^0, Y_1^{-1}, Y_1^0, Y_1^1$) [S2, unofficial].

**Steps:**
1.  **Initialize Student:** Initialize the student model with the same Gaussian primitives (positions, covariances, opacities) as the teacher, but with first-order SH coefficients initialized to zero or copied from a low-degree projection of the teacher [S2, G, unofficial].
2.  **Forward Pass (Teacher):** Render images from the teacher model using third-order SH to obtain teacher pixel colors $\mathbf{C}_p^{tea}$ and teacher depth $\hat{\mathbf{D}}_p^{tea}$ for a set of training pixels $P$ [S2, unofficial].
3.  **Forward Pass (Student):** Render images from the student model using first-order SH to obtain student pixel colors $\mathbf{C}_p$ and student depth $\hat{\mathbf{D}}_p$ for the same pixels $P$ [S2, unofficial].
4.  **Compute Distillation Loss:** Calculate the color distillation loss $\mathcal{L}_{\text{dstill}}$ between teacher and student rendered colors [S2, unofficial]:
    $$ \mathcal{L}_{\text{dstill}} = \frac{1}{|P|} \sum_{p \in P} \|\mathbf{C}_p^{tea} - \mathbf{C}_p\| $$
    where $\|\cdot\|$ denotes the L2 norm [S2, unofficial].
5.  **Compute Depth Distillation Loss:** Calculate the scale-invariant depth distillation loss $\mathcal{L}_{\text{depth}}$ to supervise depth consistency [S2, unofficial]:
    $$ \mathcal{L}_{\text{depth}}(\mathbf{D}, \mathbf{D}^{tea}) = \frac{1}{|P|} \sum_{p \in P} \left( \log(\hat{\mathbf{D}}_p) - \log(\hat{\mathbf{D}}_p^{tea}) \right)^2 - \frac{1}{|P|^2} \left( \sum_{p \in P} \left( \log(\hat{\mathbf{D}}_p) - \log(\hat{\mathbf{D}}_p^{tea}) \right) \right)^2 $$
    where $\hat{\mathbf{D}}_p^{tea} = \mathbf{D}^{tea} + \epsilon$ and $\epsilon = 1e-8$ for numerical stability [S2, unofficial].
6.  **Optimize:** Update the student model's first-order SH coefficients (and potentially other Gaussian attributes) by minimizing the combined loss $\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{dstill}} + \lambda \mathcal{L}_{\text{depth}}$ (where $\lambda$ is a weighting factor, not specified in sources) [S2, unofficial].

**Parameters:**
*   Target SH degree: 1 [S1][S2, unofficial].
*   Epsilon $\epsilon$: $1e-8$ [S2, unofficial].

**Edge Cases and Pitfalls:**
*   Depth from the teacher model is not always reliable, so strict L1/L2 depth losses are avoided in favor of scale-invariant log losses [S2, unofficial].
*   The student and teacher depths may have slight differences, which the scale-invariant loss accommodates [S2, unofficial].

**Pseudocode:**
```python
def first_order_sh_distillation(teacher_model, student_model, training_data, epsilon=1e-8):
    """
    Distill third-order SH from teacher to first-order SH in student.
    """
    for batch in training_data:
        # Get camera parameters and pixel coordinates for the batch
        cameras = batch.cameras
        pixels = batch.pixels
        
        # Render teacher output
        teacher_colors, teacher_depths = teacher_model.render(cameras, pixels)
        # Apply epsilon to teacher depth for stability
        teacher_depths_stable = teacher_depths + epsilon
        
        # Render student output
        student_colors, student_depths = student_model.render(cameras, pixels)
        
        # Compute color distillation loss (L2 norm)
        # Note: Sources use ||C_tea - C||, implying L2. 
        # Assuming per-pixel vector difference.
        color_diff = teacher_colors - student_colors
        l_dstill = mean(square_norm(color_diff))
        
        # Compute scale-invariant depth distillation loss
        log_teacher_depth = log(teacher_depths_stable)
        log_student_depth = log(student_depths)
        
        diff_log_depth = log_student_depth - log_teacher_depth
        
        # Term 1: Mean of squared differences
        term1 = mean(square(diff_log_depth))
        
        # Term 2: Square of mean of differences
        term2 = square(mean(diff_log_depth))
        
        l_depth = term1 - term2
        
        # Total loss (lambda not specified, assumed 1 or tuned)
        total_loss = l_dstill + l_depth
        
        # Backpropagate and update student model
        student_model.zero_grad()
        total_loss.backward()
        student_model.optimizer.step()
```

## Subtopics

### SH Degree Reduction (General)
Reducing SH degree (e.g., 3→2, 2→1) without distillation. Sets apart by being a direct projection or truncation rather than learned distillation. Choose when distillation overhead is unacceptable. [Link to [Spherical Harmonics Optimization](14206-spherical-harmonics-optimization.md)]

### Spherical Harmonics Vector Quantization
Replaces continuous SH coefficients with discrete indices from a shared palette. Sets apart by using codebooks for further compression after distillation. Choose when extreme storage reduction is needed. [Link to [Spherical Harmonics Vector Quantization](14181-spherical-harmonics-vector-quantization.md)]

## Operating characteristics
*   **Time and Memory Complexity:** Reduces SH coefficients from 48 to 12 per Gaussian, a 61% reduction in parameters and 52% reduction in computation [S1].
*   **Measured Performance:** 
    *   Degree 3→2: -36% parameters, -35% computation, -0.17 dB PSNR [S1].
    *   Degree 2→1: -25% parameters, -17% computation, -0.31 dB PSNR [S1].
    *   Degree 3→1 (Distillation): -61% parameters, -52% computation, -0.48 dB PSNR [S1].
*   **Scaling:** Enables real-time rendering on mobile devices and edge hardware [S2, unofficial].
*   **Strengths:** Significant compression with minimal quality loss compared to naive degree reduction.
*   **Limitations:** Requires a pretrained teacher model. Distillation adds training complexity.
*   **When to use:** Mobile deployment, edge devices, storage-constrained environments.
*   **When not to use:** When maximum visual fidelity is required and storage/compute are not constraints.

## Background
First-order Spherical Harmonics Distillation was introduced in the Mobile-GS paper [S2, unofficial]. It addresses the high storage and computational burden of third-order SH in original 3D Gaussian Splatting [S2, unofficial]. It builds on the concept of SH degree reduction [S1] and knowledge distillation techniques [S2, unofficial].
