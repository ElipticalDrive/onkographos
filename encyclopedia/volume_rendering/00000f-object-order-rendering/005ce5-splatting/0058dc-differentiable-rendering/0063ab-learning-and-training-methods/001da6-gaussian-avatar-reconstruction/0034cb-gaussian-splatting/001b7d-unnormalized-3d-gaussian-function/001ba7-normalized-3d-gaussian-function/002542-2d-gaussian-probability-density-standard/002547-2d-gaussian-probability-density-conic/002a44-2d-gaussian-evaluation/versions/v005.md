# 2D Gaussian Evaluation

Also called: 2D Gaussian PDF exponent

## Overview
Computes the exponent term of the 2D Gaussian probability density function at given 2D points, used for rasterization or shading [S1, unofficial].

## How it works
**Inputs:**
- `points_2D`: Tensor of shape $(N, 2)$ containing the 2D query coordinates [S1, unofficial].
- `means_2D`: Tensor of shape $(N, 2)$ containing the 2D Gaussian means [S1, unofficial].
- `cov_2D`: Tensor of shape $(N, 2, 2)$ containing the 2D covariance matrices [S1, unofficial].

**Outputs:**
- `power`: Tensor of shape $(N,)$ containing the exponent values $P$ [S1, unofficial].

**Data Structures:**
- Tensors are batched. `points_2D`, `means_2D` are 2D vectors. `cov_2D` is a $2 \times 2$ matrix per Gaussian [S1, unofficial].

**Steps:**
1. Compute the difference vector between query points and 2D means: $\mathbf{x}_m = \text{points\_2D} - \text{means\_2D}$ [S1, unofficial].
2. Reshape the difference vector for batched matrix multiplication:
   - $\mathbf{x}_m^{\text{col}} = \text{unsqueeze}(\mathbf{x}_m, \text{dim}=-1)$, shape $(N, 2, 1)$ [S1, unofficial].
   - $\mathbf{x}_m^{\text{row}} = \text{unsqueeze}(\mathbf{x}_m, \text{dim}=-2)$, shape $(N, 1, 2)$ [S1, unofficial].
3. Compute the inverse of the 2D covariance matrix and unsqueeze for broadcasting:
   - $C_{2D}^{-1} = \text{inverse}(\text{cov\_2D})$, shape $(N, 2, 2)$ [S1, unofficial].
   - $C_{2D}^{-1}_{\text{batch}} = \text{unsqueeze}(C_{2D}^{-1}, \text{dim}=1)$, shape $(N, 1, 2, 2)$ [S1, unofficial].
4. Compute the quadratic form and scale by $-0.5$:
   - $Q = \mathbf{x}_m^{\text{row}} \times C_{2D}^{-1}_{\text{batch}} \times \mathbf{x}_m^{\text{col}}$ [S1, unofficial].
   - The result $Q$ has shape $(N, 1, 1)$ [S1, unofficial].
   - $P = -0.5 \times \text{squeeze}(Q, \text{dim}=(-1, -2))$ [S1, unofficial].

**Formula:**
$$P = -\frac{1}{2} (\mathbf{x}_m^T C_{2D}^{-1} \mathbf{x}_m)$$
where $\mathbf{x}_m$ is the $2 \times 1$ difference vector, $C_{2D}^{-1}$ is the $2 \times 2$ inverse covariance, and $P$ is the exponent value [S1, unofficial].

**Pseudocode:**
```python
def evaluate_2d_gaussian(points_2d, means_2d, cov_2d):
    # points_2d, means_2d: list of [x, y] or 2D array of shape (N, 2)
    # cov_2d: list of [[a, b], [c, d]] or 3D array of shape (N, 2, 2)
    # Returns: list/array of exponent values P of shape (N,)
    
    # Step 1: Difference vector
    xm = [p - m for p, m in zip(points_2d, means_2d)]  # (N, 2)
    
    # Step 2: Reshape for batched matrix multiplication
    # xm_col: (N, 2, 1), xm_row: (N, 1, 2)
    xm_col = [[[v] for v in pt] for pt in xm]
    xm_row = [[[xm[i][j] for j in range(2)]] for i in range(len(xm))]
    
    power = []
    for i in range(len(xm)):
        # Step 3: Inverse of 2x2 covariance matrix
        cov = cov_2d[i]
        det = cov[0][0] * cov[1][1] - cov[0][1] * cov[1][0]
        cov_inv = [[cov[1][1]/det, -cov[0][1]/det], [-cov[1][0]/det, cov[0][0]/det]]
        
        # Step 4: Quadratic form: xm_row @ cov_inv @ xm_col
        # xm_row is (1, 2), cov_inv is (2, 2), xm_col is (2, 1)
        temp = [[sum(xm_row[i][0][k] * cov_inv[k][j] for k in range(2)) for j in range(2)]]
        q_val = sum(temp[0][j] * xm_col[i][j][0] for j in range(2))
        
        power.append(-0.5 * q_val)
        
    return power
```

**Edge Cases and Pitfalls:**
- **Singular Covariance:** If `cov_2d` is singular, matrix inversion will fail or produce NaNs [G].
- **Precision:** Matrix inversion can be numerically unstable for near-singular matrices [G].
- **Batching:** The implementation assumes batched inputs [S1, unofficial].

## Subtopics

### [Generalized Gaussian Particles](9164-generalized-gaussian-particles.md)
Generalized Gaussian Particles replace the standard quadratic exponent in the 2D Gaussian probability density function with a power-law exponent controlled by a degree parameter $n$. This modification allows for steeper and narrower density fall-off, enabling denser particle packing and finer control over the trade-off between rendering quality and computational speed compared to standard Gaussians.

### [2D Gaussian Evaluation (Rotated/Anisotropic)](12462-2d-gaussian-evaluation-rotated-anisotropic.md)
This method computes the alpha component of a rotated, anisotropic 2D Gaussian function at specific 2D texture coordinates, primarily for generating brush-stroke textures in stroke-based splatting [G]. It differs from standard isotropic splatting by applying a rotation matrix to the coordinate system before evaluating the decay, allowing for directional brush strokes [G]. It builds on [2D Gaussian Evaluation](4728-2d-gaussian-evaluation.md) by adding explicit rotational transformation of the input coordinates [G].

## Operating characteristics
- **Time Complexity:** $O(N)$ for $N$ Gaussians, dominated by matrix inversion and multiplication [G].
- **Memory Complexity:** $O(N)$ for storing intermediate tensors [G].
- **Strengths:** Efficient batched computation suitable for GPU acceleration [G].
- **Limitations:** Sensitive to singular covariance matrices [G].
