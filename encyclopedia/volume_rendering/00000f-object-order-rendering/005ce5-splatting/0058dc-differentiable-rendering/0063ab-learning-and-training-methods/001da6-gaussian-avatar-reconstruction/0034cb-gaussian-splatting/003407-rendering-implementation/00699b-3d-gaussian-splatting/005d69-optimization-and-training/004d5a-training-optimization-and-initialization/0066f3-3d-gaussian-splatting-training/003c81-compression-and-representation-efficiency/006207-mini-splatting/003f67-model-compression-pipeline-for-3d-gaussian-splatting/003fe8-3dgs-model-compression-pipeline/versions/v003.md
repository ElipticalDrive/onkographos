# 3DGS Model Compression Pipeline

Also called: Hardware-Friendly Compression, Iterative Pruning & VQ Compression

## Overview
A compression scheme tailored for hardware deployment that reduces model size and bandwidth by iteratively pruning Gaussians, reducing spherical harmonics (SH) degree, and quantizing attributes [S1]. It modifies LightGaussian to achieve higher compression ratios (51.6× vs 15×) by adding iterative pruning, progressive SH reduction, and full VQ on all coefficients/colors [S1].

## How it works
**Inputs:** Pre-trained 3D Gaussian Splatting model (Gaussians with positions, covariances, opacities, colors, and SH coefficients).
**Outputs:** Compressed model ready for hardware acceleration.

**Data Structures:**
*   **Gaussian Set:** List of $N$ Gaussians. Each Gaussian $i$ has:
    *   Mean position $\mu_i \in \mathbb{R}^3$
    *   Covariance $\Sigma_i \in \mathbb{R}^{3 \times 3}$ (or quaternion/scale representation)
    *   Opacity $\alpha_i \in [0, 1]$
    *   Color/SH coefficients: $c_{i, l, m}$ for degree $L$ and order $m$.

**Steps:**
1.  **Iterative Gaussian Pruning:**
    *   Remove Gaussians that contribute minimally to the rendered image.
    *   This step reduces the number of Gaussians $N$ significantly.
    *   [G] Pruning criteria typically involve rendering error or opacity thresholds, but specific metrics are not detailed in the source beyond "iterative."

2.  **Progressive Spherical Harmonics (SH) Degree Reduction:**
    *   Reduce the SH degree $L$ from its initial value (e.g., 3 or 4) to a lower value (e.g., 1 or 2).
    *   This reduces the number of coefficients per Gaussian from $(L+1)^2$ to $(L'+1)^2$.
    *   Fine-tuning may be performed after reduction to recover quality.

3.  **Vector Quantization (VQ):**
    *   Apply VQ to **all** SH coefficients and colors.
    *   This replaces continuous values with indices into a codebook.
    *   [G] Standard VQ involves clustering (e.g., k-means) to find codebooks and assigning each coefficient to the nearest codeword.

**Parameters:**
*   Target compression ratio: 51.6× model-size reduction [S1].
*   PSNR loss: 0.743 dB [S1].

**Pseudocode:**
```python
def compress_3dgs(model):
    # Step 1: Iterative Pruning
    # Remove Gaussians based on contribution metrics
    model.gaussians = iterative_pruning(model.gaussians)
    
    # Step 2: Progressive SH Degree Reduction
    # Reduce SH degree from L to L'
    model.sh_degree = reduce_sh_degree(model.sh_degree, target_degree=1) # Example target
    # Fine-tune to recover quality if necessary
    model = fine_tune(model)
    
    # Step 3: Vector Quantization
    # Quantize all SH coefficients and colors
    codebook_sh = train_vq(model.sh_coefficients)
    codebook_color = train_vq(model.colors)
    model.sh_coefficients = quantize(model.sh_coefficients, codebook_sh)
    model.colors = quantize(model.colors, codebook_color)
    
    return model
```

## Subtopics

### [Mini-Splatting-C](10131-mini-splatting-c.md)
Mini-Splatting-C is a storage-compression variant of the Mini-Splatting method designed for scenarios requiring minimal model footprint. It achieves significant size reduction by applying post-processing techniques to the attributes of a pre-trained Mini-Splatting model, including transform coding, quantization, and entropy encoding. Unlike Mini-Splatting-D, which prioritizes rendering quality, Mini-Splatting-C optimizes for storage efficiency, demonstrating superior performance compared to other compression-oriented works applied to 3D Gaussian Splatting (3DGS).

### [Hybrid Compression Framework](15040-hybrid-compression-framework.md)
The Hybrid Compression Framework is a post-training compression method for 3D Gaussian Splatting (3DGS) that reduces model size and bandwidth by combining adaptive voxelization with Generalized Prediction Context Coding (GPCC). It addresses the impracticality of generative compression, which requires retraining distinct models for each bitrate, and the quality degradation of standard post-training methods due to parameter distortion. By quantizing mean positions to voxel centers and fine-tuning remaining attributes, it achieves higher quality at lower bitrates compared to sibling methods like Mini-Splatting-C.

## Operating characteristics
*   **Compression Ratio:** 51.6× model-size reduction [S1].
*   **Quality Loss:** 0.743 dB PSNR loss [S1].
*   **Hardware Efficiency:** The compressed model enables a hardware accelerator to achieve 1219 Mpixels/J at 267.5 Mpixels/s, delivering 1080p at 129 FPS [S1].
*   **Strengths:** High compression ratio, hardware-friendly, low latency.
*   **Limitations:** PSNR loss, view-dependent culling benefits (42% of points unnecessary on average, but decreases when zooming out) [S1].

## Background
Originated from the need for real-time rendering of 3DGS models on portable AR/VR devices, targeting full-HD resolution at 120 FPS per eye [S1]. It modifies LightGaussian [4] to achieve higher compression ratios [S1].
