# Adaptive Gaussian Refinement

Also called: 7DGS Adaptive Refinement, Residual Gaussian Adjustment

## Overview
Adaptive Gaussian Refinement is a technique that dynamically adjusts Gaussian parameters using neural network-predicted residuals to improve the modeling of complex non-rigid deformations and time-varying appearance [S1]. It addresses the limitation of static covariance matrices in standard 3D Gaussian Splatting, which cannot adequately represent dynamic behaviors such as motion-induced shape changes [S1]. Unlike sibling methods that rely on gradient-based densification metrics (e.g., [Adaptive Density Control](9188-adaptive-density-control.md)) or MCMC sampling (e.g., [3DGS-MCMC](7852-3dgs-mcmc.md)), this method uses a lightweight neural network to predict continuous corrections to the Gaussian's spatial, temporal, directional, and covariance parameters [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The base set of 7D Gaussian parameters for a primitive $k$: spatial mean $\mu_p \in \mathbb{R}^3$, temporal mean $\mu_t \in \mathbb{R}$, directional mean $\mu_d \in \mathbb{R}^3$, and the vectorized lower-triangular elements of the 7D covariance matrix $l \in \mathbb{R}^{28}$ [S1]. The current time $t$ is required for the temporal encoding [S1].
*   **Output:** Refined parameters $\hat{\mu}_p, \hat{\mu}_t, \hat{\mu}_d, \hat{l}$ [S1].

**Data Structures:**
*   **Feature Vector $f$:** A concatenated vector formed by $\mu_p, \mu_t, \mu_d$, and a high-frequency temporal encoding $\gamma(t)$ [S1].
*   **MLP:** A small two-layer multilayer perceptron (MLP) with architecture $C_{in} \times 64 \times C_{out}$ [S1]. Four such MLPs ($\phi_p, \phi_t, \phi_d, \phi_l$) predict residuals for position, time, direction, and covariance respectively [S1].

**Steps:**
1.  **Temporal Encoding:** Compute the positional encoding for the current time $t$ [S1]. The encoding $\gamma(t)$ is defined as:
    $$ \gamma(t) = [\sin(2^0 \pi t), \cos(2^0 \pi t), \dots, \sin(2^{K-1} \pi t), \cos(2^{K-1} \pi t)] $$
    where $K=10$ [S1]. This results in a vector of size $2K = 20$ [S1].
2.  **Feature Construction:** Concatenate the spatial mean, temporal mean, directional mean, and the temporal encoding to form the input feature vector $f$:
    $$ f = \mu_p \oplus \mu_t \oplus \mu_d \oplus \gamma(t) $$
    where $\oplus$ denotes vector concatenation [S1]. The dimension $C_{in}$ is $3 + 1 + 3 + 20 = 27$ [S1].
3.  **Residual Prediction:** Pass $f$ through the respective MLPs ($\phi_p, \phi_t, \phi_d, \phi_l$) to predict residual adjustments [S1]. Each MLP has a hidden layer of size 64 [S1].
4.  **Parameter Update:** Add the predicted residuals to the original parameters to obtain the refined estimates:
    $$ \hat{\mu}_p = \mu_p + \phi_p(f) $$
    $$ \hat{\mu}_t = \mu_t + \phi_t(f) $$
    $$ \hat{\mu}_d = \mu_d + \phi_d(f) $$
    $$ \hat{l} = l + \phi_l(f) $$
    Here, $l$ represents the vectorized lower-triangular elements of the 7D covariance matrix [S1].
5.  **Application:** These refined parameters are used in subsequent rendering steps, specifically before the conditional slicing step [S1].

**Pseudocode:**
```python
import numpy as np

def temporal_encoding(t, K=10):
    """
    Computes the high-frequency temporal encoding gamma(t).
    Args:
        t: float, current time coordinate.
        K: int, number of frequency bands (default 10).
    Returns:
        np.array of shape (2*K,)
    """
    frequencies = np.power(2, np.arange(K))
    sin_vals = np.sin(2 * np.pi * frequencies * t)
    cos_vals = np.cos(2 * np.pi * frequencies * t)
    return np.concatenate([sin_vals, cos_vals])

def mlp_predict(x, W1, b1, W2, b2):
    """
    Standard 2-layer MLP forward pass.
    Args:
        x: input vector
        W1, b1: first layer weights and biases
        W2, b2: second layer weights and biases
    Returns:
        residual vector
    """
    h = np.maximum(0, x @ W1 + b1) # ReLU activation [G]
    return h @ W2 + b2

def adaptive_gaussian_refinement(mu_p, mu_t, mu_d, l, t, mlp_params):
    """
    Applies adaptive refinement to 7D Gaussian parameters.
    Args:
        mu_p: np.array, shape (3,), spatial mean.
        mu_t: float, temporal mean.
        mu_d: np.array, shape (3,), directional mean.
        l: np.array, shape (28,), vectorized lower-triangular covariance elements.
        t: float, observed time.
        mlp_params: dict, containing 'W1_p', 'b1_p', 'W2_p', 'b2_p', etc.
                    for phi_p, phi_t, phi_d, phi_l.
    Returns:
        tuple: (hat_mu_p, hat_mu_t, hat_mu_d, hat_l)
    """
    # Step 1 & 2: Feature Construction
    gamma_t = temporal_encoding(t, K=10)
    f = np.concatenate([mu_p, np.array([mu_t]), mu_d, gamma_t])
    
    # Step 3 & 4: Residual Prediction and Update
    # Note: mlp_params contain the trained weights for the four MLPs [S1]
    res_p = mlp_predict(f, mlp_params['W1_p'], mlp_params['b1_p'], mlp_params['W2_p'], mlp_params['b2_p'])
    res_t = mlp_predict(f, mlp_params['W1_t'], mlp_params['b1_t'], mlp_params['W2_t'], mlp_params['b2_t'])
    res_d = mlp_predict(f, mlp_params['W1_d'], mlp_params['b1_d'], mlp_params['W2_d'], mlp_params['b2_d'])
    res_l = mlp_predict(f, mlp_params['W1_l'], mlp_params['b1_l'], mlp_params['W2_l'], mlp_params['b2_l'])
    
    hat_mu_p = mu_p + res_p
    hat_mu_t = mu_t + res_t
    hat_mu_d = mu_d + res_d
    hat_l = l + res_l
    
    return hat_mu_p, hat_mu_t, hat_mu_d, hat_l
```

**Parameters:**
*   $K=10$: Number of frequency bands in the temporal encoding [S1].
*   MLP Hidden Size: 64 [S1].
*   MLP Architecture: Two layers ($C_{in} \to 64 \to C_{out}$) [S1].

**Edge Cases and Pitfalls:**
*   **Covariance Reconstruction:** The refined covariance matrix $\hat{\Sigma}$ is reconstructed from $\hat{l}$ as $\hat{\Sigma} = \hat{L}\hat{L}^\top$ (where $\hat{L}$ is the lower-triangular matrix from $\hat{l}$) [S1].
*   **Training Dependency:** The method requires training the MLPs alongside the Gaussians, and the residuals are added directly to the vectorized covariance elements, which requires careful handling of numerical stability during optimization [S1].

## Operating characteristics
*   **Computational Cost:** Adds the cost of four MLP forward passes per Gaussian per frame [S1]. The MLPs are small ($C_{in} \times 64 \times C_{out}$) [S1].
*   **Memory:** Requires storing the MLP weights [S1]. The number of parameters is small: $27 \times 64 + 64 \times C_{out}$ per MLP [S1].
*   **Strengths:** Enables accurate modeling of complex non-rigid deformations and time-varying appearance without increasing the number of Gaussians [S1].
*   **Limitations:** Requires training the MLPs alongside the Gaussians and is specific to 7D Gaussian Splatting without direct application to static 3DGS [S1].

## Background
Adaptive Gaussian Refinement was introduced in the 7DGS (Unified Spatial-Temporal-Angular Gaussian Splatting) paper [S1]. It was developed to address the static nature of 3D Gaussian covariances, which limits their ability to represent dynamic scenes with non-rigid deformations [S1]. The method builds on the idea of using neural networks to predict residuals, a technique seen in other neural rendering contexts, but applies it specifically to the parameters of 7D Gaussians [S1].
