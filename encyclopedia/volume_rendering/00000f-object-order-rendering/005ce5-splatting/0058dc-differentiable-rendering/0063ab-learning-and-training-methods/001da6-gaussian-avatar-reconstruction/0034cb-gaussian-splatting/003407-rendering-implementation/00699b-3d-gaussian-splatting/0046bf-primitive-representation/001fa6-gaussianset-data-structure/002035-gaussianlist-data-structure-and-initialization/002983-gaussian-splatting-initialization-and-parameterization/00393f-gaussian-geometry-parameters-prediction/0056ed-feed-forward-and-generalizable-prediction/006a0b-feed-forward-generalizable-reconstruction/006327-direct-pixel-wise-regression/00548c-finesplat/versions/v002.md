# FineSplat

Also called: Detailed Splats, Fine Patches, Local Groups

## Overview
FineSplat is a feed-forward 3D Gaussian Splatting (3DGS) framework that predicts a set of 3D Gaussian primitives from $N$ context views to enable novel view synthesis [S1, unofficial]. It addresses the trade-off between fine-grained visual detail and the computational cost of global multi-view attention by employing a dual-grouping strategy: view-wise token grouping in Stage 1 and 3D spatial grouping in Stage 2 [S1, unofficial]. Unlike sibling methods such as [YoNoSplat](15813-sparsplat.md) and [ZipSplat](12847-anysplat-pipeline.md) which use coarser 14x14 patches and global or simpler interactions, FineSplat uses 4x4 patches to preserve high-resolution features while avoiding the prohibitive cost of global attention [S1, unofficial].

## How it works
**Inputs:** A set of $N$ context images $\{I_n\}_{n=1}^N$ with resolution $H \times W$, and their corresponding camera poses (intrinsics and extrinsics). The method assumes poses are known or predicted; if not, they are predicted by a backbone [S1, unofficial].
**Outputs:** A set of $K \cdot M$ 3D Gaussian primitives, where $M$ is the number of tokens and $K$ is the number of Gaussians per token. Each Gaussian is defined by mean $\mu$, covariance (scale $s$ and rotation $r$), opacity $\alpha$, and color $c$ (spherical harmonics coefficients).

**Data Structures:**
1.  **Feature Maps:** $F^l \in \mathbb{R}^{N \times (H/2^l) \times (W/2^l) \times d}$ for levels $l \in \{1, 2, 3\}$, where $l=1$ is finest and $l=3$ is coarsest.
2.  **Tokens:** $z \in \mathbb{R}^{M \times d}$, where $M = N \cdot \frac{H}{p} \cdot \frac{W}{p}$ and $p=4$ is the patch size.
3.  **Gaussians:** A list of primitives, each with parameters $\{\mu, s, r, \alpha, c\}$.
4.  **Error Feature Maps:** $F^{err}_n \in \mathbb{R}^{(H/p) \times (W/p) \times d_e}$ for each view $n$.

**Parameters:**
*   $p$: Patch size, fixed at 4x4 pixels [S1, unofficial].
*   $K$: Number of Gaussians per token, fixed at 4 [S1, unofficial].
*   $T$: Number of Stage 2 refinement steps, fixed at 4 [S1, unofficial].
*   $S$: Size of groups for serialized attention in Stage 2 [S1, unofficial].
*   $s$: Sub-patch stride, fixed at 2 [S1, unofficial].
*   $N$: Number of context views. Training samples $N \in \{6, 12, 24, 32\}$ [S1, unofficial].

**Algorithm:**

1.  **Scene Normalization:** To handle scale ambiguity in feed-forward reconstruction, transform all camera poses into the mean context camera frame. Rescale translations so that all context camera centers lie within $[-1, 1]^3$ [S1, unofficial].

2.  **Stage 1: View-Wise Token Grouping:**
    a. Encode input images $I$ into feature maps $F^1, F^2, F^3$ using a backbone (e.g., transformer/CNN) [S1, unofficial].
    b. Fuse features into fine-grained tokens $z^{(0)}$ using Equation (1):
       $$ z^{(0)} = \text{fuse}(\text{up}(\text{fuse}(\text{up}(F^3) + F^2)) + F^1) $$
       where $\text{up}(\cdot)$ is bilinear upsampling and $\text{fuse}(\cdot)$ is a convolutional fusion block [S1, unofficial].
    c. Apply view-wise attention. Divide views into groups. Perform fine-grained attention within small view groups and exchange information across all views via coarser global tokens [S1, unofficial].

3.  **Stage 2: 3D Spatial Token Grouping (Iterative Refinement for $t = 1$ to $T$):**
    a. **Gaussian Prediction:** Decode tokens $z^{(t-1)}$ into an initial set of Gaussians using a linear Gaussian head $\mathcal{D}$. For each token, predict $K=4$ Gaussians [S1, unofficial].
    b. **Patch-Aligned Sub-Pixel Reconstruction:**
       i. Divide each 4x4 token into four non-overlapping 2x2 sub-patches.
       ii. Predict a 2D image-space offset $\Delta = (\Delta_x, \Delta_y)$ for each Gaussian.
       iii. Bound the offset to keep the Gaussian within its sub-patch:
           $$ \delta_x = 2s \tanh(\Delta_x), \quad \delta_y = 2s \tanh(\Delta_y) $$
           where $s=2$ is the sub-patch stride, ensuring $\delta_x, \delta_y \in [-1, 1]$ [S1, unofficial].
       iv. For a sub-patch center $(u_c, v_c)$, compute displaced coordinate $(u, v) = (u_c, v_c) + (\delta_x, \delta_y)$.
       v. Unproject $(u, v)$ using predicted camera intrinsics to get a ray direction. Transform and normalize this direction using camera-to-world rotation, using camera translation as ray origin. Set $\mu$ along this ray [S1, unofficial].
    c. **Rendering and Error Computation:**
       i. Render the predicted Gaussians into each context view $n$ to get $\hat{I}_n$.
       ii. Compute signed pixel error map $E_n = \hat{I}_n - I_n$ [S1, unofficial].
       iii. Compute feature-level difference $\Delta \phi_n = \phi(\hat{I}_n) - \phi(I_n)$ using a pretrained ResNet-18 encoder $\phi(\cdot)$ [S1, unofficial].
       iv. Combine errors with finest-scale features $F^1_n$ from Stage 1 to form error feature maps $F^{err}_n$:
           $$ F^{err}_n = [E_{err}(E_n, \Delta \phi_n); E_{feat}(F^1_n)] \in \mathbb{R}^{(H/p) \times (W/p) \times d_e} $$
           where $E_{err}$ and $E_{feat}$ are linear embedding layers and $[\cdot; \cdot]$ is concatenation [S1, unofficial].
    d. **Error Aggregation:**
       i. For each token $j$, compute self error feature $e_{self}$ from its own view's error map.
       ii. Compute aggregated error feature $e_{agg}$ by averaging error features over all context views where the token is visible (passes frustum and occlusion tests) [S1, unofficial].
    e. **3D Spatial Grouping:**
       i. Lift tokens to 3D space using their predicted $\mu$.
       ii. Order tokens along a space-filling curve.
       iii. Partition tokens into groups of $S$ consecutive points.
       iv. Apply serialized self-attention within each group. Use four attention blocks, each using a different space-filling curve, so each token meets a different set of neighbors [S1, unofficial].
       v. Update tokens:
           $$ \Delta z_j = \text{Linear}(\text{SerialAttn}(h_j)) $$
           $$ z_j^{(t)} = z_j^{(t-1)} + \Delta z_j $$
           where $h_j$ is the concatenated self and aggregated error features [S1, unofficial].
    f. Repeat steps a-e for $T=4$ steps [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import numpy as np

def fine_splat(context_images, context_poses, num_views=6):
    """
    context_images: Tensor of shape (N, H, W, 3)
    context_poses: List of camera poses (extrinsics, intrinsics)
    """
    # 1. Scene Normalization
    # Transform poses to mean context camera frame and rescale translations to [-1, 1]^3
    normalized_poses = normalize_scene_scale(context_poses)
    
    # 2. Stage 1: View-Wise Token Grouping
    # Encode images into feature maps F^1, F^2, F^3
    F1, F2, F3 = encode_images(context_images)
    
    # Fuse features into tokens z^(0)
    # z^(0) = fuse(up(fuse(up(F3) + F2)) + F1)
    z0 = fuse_features(F3, F2, F1)
    
    # Apply view-wise attention
    tokens = view_wise_attention(z0, context_images)
    
    # 3. Stage 2: 3D Spatial Token Grouping (Iterative)
    for t in range(4): # T=4 steps
        # Decode tokens to Gaussians
        gaussians = decode_gaussians(tokens)
        
        # Render back to context views
        rendered_images = render_gaussians(gaussians, normalized_poses)
        
        # Compute error features
        error_features = compute_error_features(rendered_images, context_images, F1)
        
        # Aggregate errors for each token
        token_errors = aggregate_token_errors(tokens, gaussians, error_features, normalized_poses)
        
        # 3D Spatial Grouping
        # Lift tokens to 3D
        token_3d_positions = get_token_3d_positions(tokens, gaussians)
        
        # Order along space-filling curves and apply serialized attention
        # Use 4 different curves
        updated_tokens = serialized_attention_3d(tokens, token_3d_positions, token_errors)
        
        tokens = updated_tokens
        
    return gaussians

def fuse_features(F3, F2, F1):
    # up() is bilinear upsampling, fuse() is conv fusion block
    F2_up = bilinear_upsample(F2)
    F3_up = bilinear_upsample(F3)
    F23 = conv_fuse(F3_up + F2_up)
    F23_up = bilinear_upsample(F23)
    z0 = conv_fuse(F23_up + F1)
    return z0

def compute_error_features(rendered_images, input_images, F1):
    # E_n = I_hat_n - I_n
    pixel_errors = rendered_images - input_images
    
    # Delta phi_n = phi(I_hat_n) - phi(I_n) using ResNet-18
    phi = get_resnet18_encoder()
    phi_rendered = phi(rendered_images)
    phi_input = phi(input_images)
    feature_diffs = phi_rendered - phi_input
    
    # F_err_n = [E_err(E_n, Delta phi_n); E_feat(F1_n)]
    # E_err, E_feat are linear embeddings
    error_emb = linear_embed(pixel_errors, feature_diffs)
    feat_emb = linear_embed(F1)
    error_features = concat(error_emb, feat_emb)
    return error_features

def aggregate_token_errors(tokens, gaussians, error_features, poses):
    # For each token, get self error and aggregated error from visible views
    # pi_n(.) projects to error map of view n
    # v_j^n indicates if token j is visible in view n
    self_errors = []
    agg_errors = []
    
    for j in range(num_tokens):
        # Self error from the view where token was predicted
        view_idx = get_source_view_for_token(j)
        self_err = get_error_at_token_position(tokens[j], error_features[view_idx])
        self_errors.append(self_err)
        
        # Aggregated error from all visible views
        visible_views = get_visible_views_for_token(j, gaussians[j], poses)
        agg_err = mean([get_error_at_token_position(tokens[j], error_features[v]) for v in visible_views])
        agg_errors.append(agg_err)
        
    return self_errors, agg_errors

def serialized_attention_3d(tokens, token_3d_positions, token_errors):
    # Use 4 different space-filling curves
    updated_tokens = tokens.clone()
    for curve_idx in range(4):
        # Order points along space-filling curve
        ordered_indices = order_by_space_filling_curve(token_3d_positions, curve_idx)
        
        # Group into windows of size S
        groups = create_groups(ordered_indices, S)
        
        # Apply self-attention within each group
        for group in groups:
            group_tokens = tokens[group]
            group_errors = [token_errors[i] for i in group]
            # SerialAttn takes group tokens and their errors
            delta_z = linear_layer(serial_attn(group_tokens, group_errors))
            for k, idx in enumerate(group):
                updated_tokens[idx] += delta_z[k]
                
    return updated_tokens
```

## Operating characteristics
*   **Time Complexity:** Stage 1 uses view-wise attention, which is cheaper than global attention. Stage 2 uses serialized attention, which scales favorably with token count compared to k-NN search [S1, unofficial].
*   **Memory Complexity:** Depends on the number of tokens $M$ and Gaussians. FineSplat uses 4x4 patches, resulting in more tokens than 14x14 patch methods but fewer Gaussians per token (4 vs. more in some baselines) [S1, unofficial].
*   **Measured Performance:**
    *   DL3DV (6 views): 27.325 PSNR, 0.871 SSIM, 0.115 LPIPS with 62K Gaussians [S1, unofficial].
    *   RE10K (6 views): 27.394 PSNR, 0.886 SSIM, 0.116 LPIPS with 75K Gaussians [S1, unofficial].
    *   Mip-NeRF 360 (128 views): 23.463 PSNR, 0.706 SSIM, 0.214 LPIPS with 1.6M Gaussians [S1, unofficial].
*   **Strengths:** High quality with small primitive budget; efficient due to dual-grouping; handles fine-grained details better than coarser patch methods [S1, unofficial].
*   **Limitations:** Requires camera poses (or accurate pose prediction); scale ambiguity handled by normalization but may fail if poses are poor; fixed view grouping in Stage 1 leaves blind spots, mitigated by Stage 2 but not eliminated [S1, unofficial].
*   **When to use:** Novel view synthesis where high quality and efficiency are needed, and camera poses are available or predictable.
*   **When not to use:** Scenes with extreme scale variations not covered by normalization; real-time applications requiring extremely low latency (though it is faster than some baselines, it is still heavier than simple NeRFs).

## Background
FineSplat was introduced in 2026 by [S1, unofficial]. It builds on the principles of 3D Gaussian Splatting and feed-forward reconstruction methods. It addresses the limitations of global multi-view attention in fine-grained token-based methods by introducing a dual-grouping strategy. It is trained on the DL3DV dataset and evaluated on DL3DV, RealEstate10K, and Mip-NeRF 360 [S1, unofficial].
