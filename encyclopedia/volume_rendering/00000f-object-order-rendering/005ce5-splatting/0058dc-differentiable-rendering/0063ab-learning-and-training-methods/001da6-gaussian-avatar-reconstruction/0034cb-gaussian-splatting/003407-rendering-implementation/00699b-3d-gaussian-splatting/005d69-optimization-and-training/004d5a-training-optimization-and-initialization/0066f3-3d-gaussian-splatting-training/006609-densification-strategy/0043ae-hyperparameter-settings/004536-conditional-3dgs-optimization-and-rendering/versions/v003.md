# Conditional 3DGS Optimization and Rendering

Also called: 7DGS to Conditional 3DGS, Optimization and Rendering Pipeline

## Overview
Conditional 3DGS Optimization and Rendering extends 3D Gaussian Splatting to handle dynamic scenes by incorporating temporal and directional dependencies into the Gaussian representation [S1]. It solves the problem of rendering animated or view-dependent content by conditioning the Gaussian parameters on time and view direction, allowing for unified spatial-temporal-angular optimization [S1]. Unlike static 3DGS, this method leverages temporal cues for densification and uses conditional covariance matrices to capture motion dynamics, distinguishing it from siblings like [Blended Error Densification and Splitting](13892-blended-error-densification-and-splitting.md) which focus on spatial error metrics alone [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 3D Gaussians with base parameters (mean $\mu$, covariance $\Sigma$, opacity $\alpha$, spherical harmonics coefficients), observed time $t$, and view direction $d$. Ground truth images for optimization.
*   **Outputs:** Rendered images for given $t$ and $d$, optimized Gaussian parameters.

**Data Structures:**
The core data structure is the Gaussian, extended with conditional components. The conditional covariance matrix $\Sigma_{cond}$ is derived from the base covariance and conditioned on $t$ and $d$. It is structured as a block matrix:
$$
\Sigma_{cond} = \begin{bmatrix} \Sigma_s & \Sigma_{st} \\ \Sigma_{ts} & \Sigma_t \end{bmatrix}
$$
where $\Sigma_s$ is the spatial covariance, $\Sigma_t$ is the temporal covariance, and $\Sigma_{st} = \Sigma_{ts}^T$ is the spatial-temporal correlation block [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize point clouds. For synthetic datasets (e.g., D-NeRF), use 100,000 randomly initialized points within a bounding cube or marching cubes for specific objects (e.g., heart models) [S1]. For in-the-wild data (e.g., Technicolor), initialize from COLMAP sparse reconstructions [S1].
2.  **Conditional Covariance Extraction:** For each Gaussian, compute the conditional covariance $\Sigma_{cond}$ based on the current time $t$ and view direction $d$ [S1].
3.  **Scale and Rotation Extraction:** Perform Singular Value Decomposition (SVD) on $\Sigma_{cond}$:
    $$ \Sigma_{cond} = U D U^T $$
    where $U$ is an orthogonal matrix and $D$ is a diagonal matrix of singular values [S1].
    Define the rotation matrix $R = U$ and scale vector $S = \text{diag}(D)$ [S1].
    Ensure $R$ represents a right-handed coordinate system by adjusting the last column:
    $$ R_{:,3} = R_{:,3} \cdot \text{sign}(\det(R)) $$
    [S1].
4.  **Conditional Densification (Splitting):** Determine if a Gaussian should be split based on temporal cues [S1]:
    *   Calculate the magnitude of the off-diagonal block $\Sigma_{pt}$ (spatial-temporal correlation) [S1].
    *   Split the Gaussian if:
        1.  $|\Sigma_{pt}| > 0.05$ (relative to screen extent) [S1].
        2.  The normalized temporal scale (derived from $\Sigma_t$) is larger than 0.25 [S1].
    This criterion ensures regions with significant motion dynamics are densely represented [S1].
5.  **Rendering Pipeline:**
    *   Convert the 7DGS representation to a 3DGS-compatible format via conditional slicing [S1].
    *   Project the resulting conditional 3D Gaussian mean and covariance onto the image plane using standard perspective projection to yield 2D Gaussians [S1].
    *   Splat the 2D Gaussians onto the image canvas using a differentiable rasterization routine [S1].
    *   Compute final pixel colors by aggregating contributions in a depth-aware, opacity-blended manner [S1].
6.  **Optimization:** Use standard 3DGS loss functions and optimizers (e.g., Adam) [S1].
    *   Modulate opacity $\alpha_{cond}$ by time and view direction [S1].
    *   Prune Gaussians with opacity below $\tau_{min} = 0.01$ [S1]. This threshold is increased from the standard 3DGS value to compensate for the modulation of conditional opacity [S1].
    *   Directional and temporal modulation parameters ($\lambda_d$ and $\lambda_t$) are initially fixed and become trainable after 15,000 iterations [S1].

**Parameters:**
*   $\tau_{min}$: Minimum opacity threshold for pruning. Value: $0.01$ [S1].
*   $\lambda_d, \lambda_t$: Directional and temporal modulation parameters.
    *   7DGS-PBR: Initially $0.5$ [S1].
    *   D-NeRF: Initially $0.05$ [S1].
    *   Technicolor: Initially $0.1$ [S1].
    *   These become trainable after 15,000 iterations [S1].
*   Splitting Thresholds: Spatial-temporal correlation magnitude $> 0.05$; normalized temporal scale $> 0.25$ [S1].
*   Batch Size: 4 for most datasets; 1 for Technicolor [S1].
*   Downscaling Factor: 2 for most datasets; none for Technicolor [S1].

## Subtopics

### [Ground Truth Downsampling](15761-ground-truth-downsampling.md)
A technique to adapt a pre-trained 3D Gaussian Splatting (3DGS) model for anti-aliased rendering at lower resolutions (zoom-out) by generating pseudo-ground truth through downsampling high-resolution renderings. It prevents misguidance from aliased supervision during the optimization of low-resolution (LR) Gaussian renderings. Unlike Mip-Splatting, which uses filters that only mitigate dilation artifacts, this method achieves better visual effects and improves PSNR by 5dB compared to baseline 3DGS.

## Operating characteristics
*   **Time and Memory Complexity:** The method leverages the existing 3DGS training pipeline, implying similar complexity to 3DGS for rasterization and optimization, with additional overhead for conditional covariance computation and temporal correlation checks [S1].
*   **Measured Performance:** Evaluated on D-NeRF (synthetic, 800x800), Technicolor (in-the-wild video), and 7DGS-PBR [S1]. Experiments conducted on NVIDIA Tesla V100 GPU (16GB memory) [S1].
*   **Scaling:** Uses batch size of 4 (or 1 for Technicolor) and downscaling factor of 2 (or none for Technicolor) [S1].
*   **Strengths:** Integrates seamlessly with existing 3DGS training pipeline, leveraging adaptive density control and efficient rasterization [S1]. Handles dynamic scenes via temporal cues [S1].
*   **Limitations:** Requires careful tuning of modulation parameters ($\lambda_d, \lambda_t$) [S1]. Increased opacity threshold ($\tau_{min}=0.01$) is specific to this method [S1].
*   **When to use:** When rendering dynamic scenes with significant motion dynamics or view-dependent effects where standard 3DGS fails [S1].
*   **When not to use:** For static scenes where standard 3DGS is sufficient and faster [S1].

## Background
Originated from the 7DGS paper, which proposes a unified spatial-temporal-angular Gaussian Splatting framework [S1]. It builds on 3DGS and 4DGS, extending them to include directional dependencies [S1]. The method was evaluated on synthetic and in-the-wild datasets to demonstrate its ability to handle dynamic content [S1].
