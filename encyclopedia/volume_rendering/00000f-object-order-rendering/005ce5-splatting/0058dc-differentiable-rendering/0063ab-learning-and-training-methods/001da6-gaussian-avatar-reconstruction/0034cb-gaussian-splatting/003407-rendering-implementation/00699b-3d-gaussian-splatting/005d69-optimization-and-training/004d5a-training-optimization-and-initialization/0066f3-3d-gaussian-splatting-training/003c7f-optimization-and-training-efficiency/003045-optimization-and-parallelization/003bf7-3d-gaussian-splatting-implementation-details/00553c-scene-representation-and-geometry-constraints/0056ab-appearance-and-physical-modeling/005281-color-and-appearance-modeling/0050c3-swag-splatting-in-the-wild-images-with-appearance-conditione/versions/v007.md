# SWAG (Splatting in the Wild images with Appearance-conditioned Gaussians)


## Overview
SWAG is an extension of 3D Gaussian Splatting (3DGS) designed to handle unstructured, in-the-wild image collections by modeling appearance variations and handling transient objects (occluders) without supervision [S1]. It sets itself apart from base 3DGS and siblings like [DAVIGS](12021-davigs.md) and [3iGS](13977-3igs-factorised-tensorial-illumination-for-3d-gaussian-splat.md) by using a per-image embedding vector and an MLP to modulate Gaussian color and opacity, enabling the disentangling of static scene geometry from dynamic occluders and lighting conditions [S1].

## How it works
SWAG operates on the standard 3DGS rendering equation but modifies the color $\mathbf{c}_i$ and opacity $\alpha_i$ terms to be image-dependent [S1].

### Inputs and Outputs
*   **Inputs:** A set of unstructured images $\{I_j\}$ with known camera poses; initial 3D Gaussian parameters derived from Structure-from-Motion (SfM) points.
*   **Outputs:** Optimized Gaussian parameters (centroid, scale, rotation, base opacity, base color), a Hash Grid encoding, per-image embeddings, and an MLP. At inference, it renders novel views and can separate static/transient components.

### Data Structures
For each Gaussian $i$, the model optimizes the following parameters:
1.  **Centroid:** $\mathbf{x}_i \in \mathbb{R}^3$
2.  **Scale:** $\mathbf{s}_i \in \mathbb{R}^3$
3.  **Rotation:** $\mathbf{q}_i \in \mathbb{R}^4$ (quaternion)
4.  **Base Opacity:** $\alpha_i \in \mathbb{R}$
5.  **Base Color:** $\mathbf{c}_i$ encoded as spherical harmonic coefficients.

Additionally, the model optimizes:
1.  **Hash Grid Encoding:** A hash table mapping 3D positions to feature vectors.
    *   **Hash Table Size ($T$):** $2^{19}$ [S1].
    *   **Coarsest Resolution ($N_{min}$):** 16 [S1].
    *   **Finest Resolution ($N_{max}$):** 2048 [S1].
    *   **Number of Levels ($L$):** 12 [S1].
    *   **Encoding:** $\text{emb}(\mathbf{x}_i)$ is the output of the Hash Grid for center $\mathbf{x}_i$.
2.  **Per-Image Embedding:** A latent vector $\mathbf{l}_{I_j} \in \mathbb{R}^{24}$ for each training image $j$ [S1].
3.  **MLP ($F_\theta$):** A multi-layer perceptron with 8 layers, input dimension 3 (concatenated features), hidden layer size 51, and output dimension 64 [S1].

### Numbered Steps

1.  **Initialization:** Initialize 3D Gaussians using SfM points. Initialize Hash Grid, per-image embeddings $\mathbf{l}_{I_j}$, and MLP weights $\theta$ randomly.
2.  **Feature Encoding:** For each Gaussian $i$ and training image $j$:
    *   Compute the spatial encoding: $\mathbf{e}_x = \text{HashGrid}(\mathbf{x}_i)$.
    *   Retrieve the image embedding: $\mathbf{l}_{I_j}$.
    *   Retrieve the base color: $\mathbf{c}_i$.
3.  **Appearance and Opacity Modulation:**
    *   Concatenate inputs for the MLP: $\mathbf{z} = [\mathbf{c}_i; \mathbf{l}_{I_j}; \mathbf{e}_x]$ [S1].
    *   Pass $\mathbf{z}$ through the MLP $F_\theta$ to get an output vector $\mathbf{y} \in \mathbb{R}^{64}$ [S1].
    *   The output $\mathbf{y}$ is split to produce:
        *   Image-dependent color modulation $\mathbf{c}_{I_j}$ (derived from part of $\mathbf{y}$).
        *   Image-dependent opacity variation parameter $\Delta \alpha_{I_j}$ (derived from part of $\mathbf{y}$) [S1].
    *   **Concrete Distribution Sampling:** To handle transient objects, $\Delta \alpha_{I_j}$ serves as the location variable for a concrete distribution (Gumbel-Softmax or similar reparameterization trick). Sample $\Delta \tilde{\alpha}_{I_j}$ from this distribution [S1].
    *   **Final Opacity:** The effective opacity for Gaussian $i$ in image $j$ is modulated by $\Delta \tilde{\alpha}_{I_j}$. The method ensures Gaussians do not vary opacity to compensate for appearance variation, allowing transient Gaussians to be identified by high variance in $\Delta \tilde{\alpha}_{I_j}$ across images [S1].
4.  **Rendering:** Render the image using the modified color $\mathbf{c}_{I_j}$ and modulated opacity.
5.  **Optimization:** Minimize the reconstruction loss (e.g., L1 + SSIM) against the ground truth image $I_j$.
    *   **Learning Rates:**
        *   Image embeddings: 0.0025 [S1].
        *   Hash Grid: 0.0025 [S1].
        *   MLP $F_\theta$: 0.0025 [S1].
    *   **Densification:** Standard 3DGS densification (splitting/cloning) occurs every 2000 iterations, ending at iteration 30,000 [S1]. Total iterations: 60,000 [S1].
6.  **Transient Object Removal (Inference/Post-processing):**
    *   Identify transient Gaussians as those with high variance in $\Delta \tilde{\alpha}_{I_j}$ across training images.
    *   **Pitfall Handling:** Simply removing all transient Gaussians can leave holes (black spots) in areas with frequent transients (e.g., clouds, tourists) [S1].
    *   **Adaptive Threshold:** To mitigate holes, remove Gaussians based on an adaptive threshold $\lambda$ rather than zero variance: remove if $\text{Var}(\Delta \tilde{\alpha}_{I_j}) < \lambda$. This requires manual tuning of $\lambda$ [S1].

### Subtopics
*   **SWAG-A (No Transient Detection):** Uses appearance modeling but no transient handling. Results in closer colors to ground truth than 3DGS but still suffers from floaters caused by transient objects [S1].
*   **SWAG-T (No Appearance):** Uses transient detection but no appearance conditioning. Eliminates floaters and produces occluder-free scenes but suffers from color alterations (averaging) like base 3DGS [S1].

## Operating characteristics
*   **Time Complexity:** Training time almost doubles compared to base 3DGS [S1].
*   **Memory Complexity:** Increased due to Hash Grid, MLP, and per-image embeddings. Hash Grid size is $2^{19}$ entries [S1].
*   **Inference Time:** Inference time per frame is 10 times longer than 3DGS due to the MLP evaluation and Hash Grid lookups [S1].
*   **Strengths:** Handles unstructured in-the-wild data; disentangles static and dynamic Gaussians; enables controllable appearance via embedding interpolation; removes transient objects without supervision [S1].
*   **Limitations:** Slower training and inference than 3DGS; requires manual tuning of threshold $\lambda$ for transient removal to avoid holes; less than 20% of Gaussians capture transient objects on average [S1].
*   **When to use:** When reconstructing scenes from unstructured internet photo collections with significant lighting variations and transient occluders (e.g., tourists, clouds) [S1].
*   **When not to use:** When real-time performance is critical and the scene is static/controlled; when manual tuning of transient removal thresholds is undesirable [S1].

## Background
SWAG was proposed by H. Dahmani et al. in the paper "SWAG: Splatting in the Wild images with Appearance-conditioned Gaussians" [S1]. It addresses the poor performance of standard 3DGS on unstructured in-the-wild data by incorporating appearance modeling and transient object handling. The method was evaluated on the Phototourism Dataset (Brandenburg Gate, Sacré Cœur, Trevi Fountain) and the NeRF-OSR Dataset [S1].
