# Supplementary Point Addition for Sparse Point Clouds

Also called: Supplementary Point Addition

## Overview
A densification technique designed to compensate for the sparsity of 3D Gaussians in the far end of a scene, particularly in defocus blurry scenes where Structure-from-Motion (SfM) extraction fails [S1]. It supplements the initial point cloud with synthetic points to ensure coverage in regions where SfM provides poor initialization [S1]. It is distinguished from geometry-aware methods like DART by relying on uniform spatial sampling within the existing point cloud's bounding box rather than tangent-plane replication [S1, S1].

## How it works
**Inputs:**
*   Existing 3D Gaussian point cloud with positions $\mathbf{P}_{existing}$ and colors $\mathbf{C}_{existing}$.
*   Hyperparameters: start iteration $N_{st}$, number of points $N_p$, neighbor count $K$, distance threshold $t_d$.

**Outputs:**
*   Updated point cloud with added synthetic points.

**Data Structures:**
*   Point Cloud: List of points, each containing a 3D position vector $\mathbf{p}$ and a color vector $\mathbf{c}$ (RGB).

**Parameters:**
*   $N_{st}$: Iteration at which addition begins. Value: 2,500 [S1].
*   $N_p$: Number of points to add. Proportional to the extent of the point cloud, capped at 200,000 [S1].
*   $K$: Number of nearest neighbors for color interpolation. Value: 4 [S1].
*   $t_d$: Minimum distance threshold for discarding points. Value: 2 [S1].

**Steps:**
1.  Check if current training iteration $i \ge N_{st}$. If not, skip.
2.  Determine the bounding box of the existing point cloud. Calculate $\alpha = \min(\mathbf{P}_{existing})$ and $\beta = \max(\mathbf{P}_{existing})$ for each dimension [S1].
3.  Sample $N_p$ new points $\mathbf{p}_{new}$ from a uniform distribution $U(\alpha, \beta)$ [S1].
4.  For each new point $\mathbf{p}_{new}$:
    a. Find the $K$ nearest neighbors $P_{knn}$ from $\mathbf{P}_{existing}$ based on Euclidean distance [S1].
    b. Calculate the distance $d$ to the nearest neighbor in $P_{knn}$ [S1].
    c. If $d > t_d$, discard $\mathbf{p}_{new}$ [S1].
    d. If $d \le t_d$, assign color $\mathbf{c}_{new}$ by interpolating colors from $P_{knn}$ [S1].
5.  Add all accepted points to the point cloud [S1].

**Pseudocode:**
```python
def add_supplementary_points(point_cloud, iteration, N_st, N_p, K, t_d):
    if iteration < N_st:
        return point_cloud

    # Extract positions and colors
    positions = [p.pos for p in point_cloud]
    colors = [p.color for p in point_cloud]
    
    if not positions:
        return point_cloud

    # Determine bounding box
    # Note: In 3D, alpha and beta are vectors. 
    # The source describes U(alpha, beta) where alpha/beta are min/max values.
    # This implies sampling each dimension independently within the global min/max range.
    min_pos = min(positions, key=lambda p: p[0]) # Simplified for logic, actual min per dim
    max_pos = max(positions, key=lambda p: p[0])
    
    # Calculate global min and max for each dimension
    dims = 3
    alpha = [min(p[d] for p in positions) for d in range(dims)]
    beta = [max(p[d] for p in positions) for d in range(dims)]
    
    new_points = []
    
    for _ in range(N_p):
        # Sample from uniform distribution U(alpha, beta)
        # Assuming independent sampling per dimension
        p_new = [random.uniform(alpha[d], beta[d]) for d in range(dims)]
        
        # Find K nearest neighbors
        distances = [euclidean_distance(p_new, p) for p in positions]
        sorted_indices = sorted(range(len(distances)), key=lambda k: distances[k])
        knn_indices = sorted_indices[:K]
        
        # Check distance threshold
        min_dist = distances[knn_indices[0]]
        
        if min_dist > t_d:
            continue
            
        # Interpolate color from KNN
        knn_colors = [colors[i] for i in knn_indices]
        knn_dists = [distances[i] for i in knn_indices]
        
        # Inverse distance weighting for color interpolation
        # If distance is 0, use exact color
        if min_dist == 0:
            c_new = knn_colors[0]
        else:
            weights = [1.0 / (d + 1e-6) for d in knn_dists]
            total_weight = sum(weights)
            c_new = [sum(w * c for w, c in zip(weights, knn_colors[d])) / total_weight for d in range(3)]
            
        new_points.append({'pos': p_new, 'color': c_new})
        
    # Add new points to point cloud
    for np in new_points:
        point_cloud.append(Point(np['pos'], np['color']))
        
    return point_cloud
```

**Edge Cases and Pitfalls:**
*   **Empty Point Cloud:** If the initial SfM cloud is empty, the bounding box cannot be defined. The method assumes a non-empty initial cloud [S1].
*   **Precision:** The distance threshold $t_d=2$ is absolute. In scenes with different scales, this may need normalization [S1].
*   **Boundary:** Points are sampled within the min/max of existing points. This may leave corners of the scene uncovered if the SfM cloud is sparse at the edges [S1].

## Subtopics

### [Distance-Aware Replication on Tangent-planes (DART)](12502-distance-aware-replication-on-tangent-planes-dart.md)
A geometry-only initialization augmentation that replicates points on local tangent planes, targeting sparsely seeded regions peripherally. It is deterministic and relies on geometric relationships rather than uniform sampling.

### [Hybrid Volume-based Densification](15407-hybrid-volume-based-densification.md)
Uses a grid-based volumetric representation to supply missing points in low-texture or distant regions, preventing empty 2D splats.

## Operating characteristics
*   **Time Complexity:** $O(N_p \cdot N_{existing} \cdot K)$ for naive nearest neighbor search, where $N_p$ is the number of added points and $N_{existing}$ is the number of existing points. Using KD-trees or similar structures can reduce this to $O(N_p \log N_{existing})$ [S1].
*   **Memory Complexity:** Increases by $O(N_p)$ to store the new points [S1].
*   **Performance:** Improves PSNR and SSIM in defocus blurry scenes by filling gaps in the far end of the scene [S1].
*   **Strengths:** Simple to implement; does not require modifying the rasterizer or pruning criteria [S1].
*   **Limitations:** May add unnecessary points in empty space if $t_d$ is not set correctly; does not account for scene geometry beyond bounding box [S1].
*   **When to use:** Defocus blurry scenes with large depth of field where SfM fails to extract points at the far end [S1].
*   **When not to use:** Scenes with good SfM initialization or where memory is constrained [S1].

## Background
Originated in the context of Deblurring 3D Gaussian Splatting to address the issue of sparse point clouds in blurry images [S1]. SfM extraction is particularly poor in defocus blurry scenes with large depth of field, leading to missing points at the far end of the scene [S1]. The method was introduced to densify the point cloud after a initial training phase ($N_{st}=2,500$ iterations) [S1]. It is used in conjunction with periodic adaptive density control (densifying and pruning) to manage the number of 3D Gaussians [S1].
