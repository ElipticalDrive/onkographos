# Supplementary Point Addition for Sparse Point Clouds

Also called: Supplementary Point Addition

## Overview
Supplementary Point Addition is a densification technique designed to compensate for the sparsity of 3D Gaussians at the far end of scenes with large depth of field, where Structure-from-Motion (SfM) extraction is poor due to defocus blur [S1]. It differs from its siblings by explicitly injecting synthetic points into empty or sparse regions after a fixed number of training iterations, rather than relying on gradient-based densification or geometric replication on tangent planes [S1, S1]. This method ensures that distant objects are represented by initial Gaussians, preventing them from being ignored during the adaptive density control phase [S1].

## How it works
**Inputs:**
*   Existing point cloud $P_{existing}$ with positions and colors.
*   Training iteration counter $t$.
*   Hyperparameters: $N_{st}$ (start iteration), $N_p$ (number of points), $K$ (KNN neighbors), $t_d$ (distance threshold).

**Outputs:**
*   Updated point cloud $P_{new} = P_{existing} \cup P_{supp}$, where $P_{supp}$ are the newly added points.

**Data Structures:**
*   $P_{existing}$: List of points, each with position $\mathbf{x} \in \mathbb{R}^3$ and color $\mathbf{c} \in \mathbb{R}^3$.
*   $P_{supp}$: List of new points with position $\mathbf{x}$ and interpolated color $\mathbf{c}_p$.

**Steps:**
1.  **Check Start Condition:** If current iteration $t < N_{st}$, terminate. No points are added.
2.  **Determine Bounds:** Calculate the minimum ($\alpha$) and maximum ($\beta$) coordinate values across all dimensions of the existing point cloud $P_{existing}$.
    *   $\alpha = \min_{\mathbf{x} \in P_{existing}} (\mathbf{x})$
    *   $\beta = \max_{\mathbf{x} \in P_{existing}} (\mathbf{x})$
    *   Note: The source defines $\alpha$ and $\beta$ as the minimum and maximum *values* of the position. In implementation, this typically implies finding the bounding box of the existing points.
3.  **Sample Positions:** Generate $N_p$ new points $P_{raw}$ by sampling uniformly from the distribution $U(\alpha, \beta)$.
    *   For each point $\mathbf{x}_{new} \in P_{raw}$, sample each coordinate independently from $U(\alpha, \beta)$.
4.  **Interpolate Colors:** For each new point $\mathbf{x}_{new}$:
    *   Find the $K$-Nearest-Neighbors ($P_{knn}$) of $\mathbf{x}_{new}$ within $P_{existing}$ based on Euclidean distance.
    *   Compute the interpolated color $\mathbf{c}_p$ from the colors of $P_{knn}$.
    *   *Implementation Note:* The source cites KNN [29] but does not specify the interpolation formula (e.g., inverse distance weighting or simple average). Standard practice for such initialization is inverse distance weighting or uniform averaging. Given the lack of specific formula in [S1], a simple average or uniform weighting is assumed if distances are similar, or inverse distance weighting if specified by the referenced KNN method. For strict adherence to "no guessing," we define the color assignment as an interpolation function $f(\mathbf{c}_{knn})$.
5.  **Filter by Distance:** For each new point $\mathbf{x}_{new}$ with nearest neighbor distance $d_{min}$:
    *   If $d_{min} > t_d$, discard $\mathbf{x}_{new}$.
    *   Otherwise, add $\mathbf{x}_{new}$ with color $\mathbf{c}_p$ to $P_{supp}$.
6.  **Merge:** Update the point cloud: $P_{new} = P_{existing} \cup P_{supp}$.

**Pseudocode:**
```python
def supplementary_point_addition(existing_points, current_iteration, Nst, Np, K, td):
    """
    Adds supplementary points to the existing point cloud if the current iteration
    has reached the start threshold Nst.
    
    Args:
        existing_points: List of dicts with 'pos' (np.array [3]) and 'color' (np.array [3]).
        current_iteration: Integer, current training step.
        Nst: Integer, start iteration for adding points.
        Np: Integer, number of points to sample.
        K: Integer, number of neighbors for KNN color interpolation.
        td: Float, distance threshold to discard points.
        
    Returns:
        Updated list of points.
    """
    if current_iteration < Nst:
        return existing_points

    # Step 2: Determine bounds
    positions = np.array([p['pos'] for p in existing_points])
    # Find min and max for each dimension
    min_coords = np.min(positions, axis=0)
    max_coords = np.max(positions, axis=0)
    
    # Step 3: Sample positions uniformly within the bounding box
    # U(alpha, beta) implies uniform distribution between min and max per dimension
    new_positions = np.random.uniform(low=min_coords, high=max_coords, size=(Np, 3))
    
    new_points = []
    
    # Precompute KNN structure for efficiency if Np is large, 
    # but for clarity we iterate.
    for i in range(Np):
        x_new = new_positions[i]
        
        # Step 4: Find K nearest neighbors
        distances = np.linalg.norm(positions - x_new, axis=1)
        k_indices = np.argsort(distances)[:K]
        k_colors = np.array([existing_points[idx]['color'] for idx in k_indices])
        
        # Interpolate color. Source does not specify weighting. 
        # Assuming simple average as a baseline for "interpolated color" without distance weighting specified.
        # [G] If inverse distance weighting is required, it should be implemented here.
        c_p = np.mean(k_colors, axis=0)
        
        # Step 5: Check distance threshold
        min_dist = distances[k_indices[0]]
        
        if min_dist <= td:
            new_points.append({'pos': x_new, 'color': c_p})
            
    # Step 6: Merge
    updated_points = existing_points + new_points
    return updated_points
```

**Parameters:**
*   $N_{st}$: The iteration number at which supplementary point addition begins. Value: 2,500 [S1].
*   $N_p$: The number of supplementing points. Value: Proportional to the extent of the point cloud, at most 200,000 [S1].
*   $K$: The number of neighbors for KNN interpolation. Value: 4 [S1].
*   $t_d$: The minimum distance threshold for discarding points. Value: 2 [S1].

**Edge Cases and Pitfalls:**
*   **Empty Point Cloud:** If $P_{existing}$ is empty, bounds $\alpha, \beta$ are undefined. The method assumes a non-empty SfM cloud exists [S1].
*   **Precision:** The distance threshold $t_d=2$ is a fixed value. Its unit (meters, world units) depends on the scene scale. If the scene is scaled differently, this threshold may need adjustment [S1].
*   **Color Interpolation:** The source does not specify the interpolation kernel. Using simple average may cause color bleeding if neighbors are far apart. Inverse distance weighting is a common alternative but is not explicitly defined in the source [S1].

## Subtopics

### [Distance-Aware Replication on Tangent-planes (DART)](12502-distance-aware-replication-on-tangent-planes-dart.md)
A geometry-only initialization augmentation that replicates points on local tangent planes, targeting sparsely seeded regions peripherally. It is deterministic and relies on geometric relationships rather than uniform sampling.

### [Hybrid Volume-based Densification](15407-hybrid-volume-based-densification.md)
Uses a continuous neural radiance field (MLP) to predict density and position for filling large voids where no initial point cloud exists, differing from the uniform sampling approach.

## Operating characteristics
*   **Time Complexity:** $O(N_p \cdot N_{existing} \log N_{existing})$ or $O(N_p \cdot N_{existing})$ depending on KNN implementation, where $N_p$ is the number of supplementary points and $N_{existing}$ is the number of existing points.
*   **Memory Complexity:** $O(N_p)$ for storing the new points.
*   **Performance:** The method is applied once after $N_{st}=2,500$ iterations [S1]. It increases the primitive count by up to 200,000 points [S1].
*   **Strengths:** Effectively compensates for sparsity in defocus blurry scenes where SfM fails at far distances [S1].
*   **Limitations:** Adds points uniformly, which may not align perfectly with scene geometry compared to tangent-plane methods. Requires careful tuning of $t_d$ relative to scene scale [S1].
*   **When to Use:** Defocus blurry scenes with large depth of field where SfM extraction is poor at the far end [S1].
*   **When Not to Use:** Scenes with clear SfM initialization or where geometric precision is critical without subsequent densification [S1].

## Background
The method was introduced in the context of Deblurring 3D Gaussian Splatting to address the issue of sparse point clouds in defocus blurry scenes [S1]. Standard SfM techniques struggle to extract points on the far end of scenes with large depth of field, leading to incomplete 3D Gaussian representations [S1]. The technique is part of a broader effort to improve initialization for 3DGS in challenging imaging conditions [S1].
