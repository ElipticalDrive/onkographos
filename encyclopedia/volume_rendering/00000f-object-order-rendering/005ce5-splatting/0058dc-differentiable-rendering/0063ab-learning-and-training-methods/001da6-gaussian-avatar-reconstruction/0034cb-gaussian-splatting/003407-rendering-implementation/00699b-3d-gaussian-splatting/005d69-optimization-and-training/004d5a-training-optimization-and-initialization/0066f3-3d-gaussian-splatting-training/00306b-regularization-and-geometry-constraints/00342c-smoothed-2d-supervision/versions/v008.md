# Smoothed 2D Supervision

Also called: Adaptive Gaussian blur strategy, Progressive Gaussian Blurring

## Overview
Smoothed 2D Supervision is a regularization technique that stabilizes the joint optimization of 3D scene parameters and camera poses by blurring 2D training images with a scheduled set of 2D Gaussian kernels [S2, unofficial]. It addresses the instability caused by high-frequency noise in raw image gradients, which can lead to poor camera alignment and overfitting to high-frequency artifacts in the learned 3D scene [S2, unofficial]. Unlike standard photometric supervision that uses raw pixels, this method constructs a multi-scale supervision signal that restricts the spectrum of the learned scene, ensuring robust convergence during the early stages of training [S2, unofficial][S3]. It is distinct from frequency regularization methods that modify positional encodings or loss weights by directly modifying the target image data itself [S3].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 2D training images $I_{raw}$, camera poses, and a current iteration count $t$.
*   **Output:** A smoothed supervision image $I_{smooth}$ for each training view, used in the photometric loss calculation.

**Data Structures:**
*   **Kernel Schedule:** A sequence of Gaussian kernel parameters $(\sigma_t, k_t)$ defined for iteration $t$.
*   **Image Buffer:** The raw training image $I_{raw}$ and the blurred output $I_{smooth}$.

**Parameters:**
*   $\sigma_{start}$: Initial standard deviation of the Gaussian kernel. Typical value: 2.4 [S4].
*   $k_{start}$: Initial kernel size (width/height). Typical value: 9x9 [S4].
*   $k_b$: Iteration interval for reducing blur. Typical value: 100 iterations [S4].
*   $T_{end}$: Iteration at which blur is fully removed. Typical value: 19,500 [S4].
*   $s_{down}$: Downsampling scale factor, if applicable. Default: 1.0 [S4].

**Steps:**
1.  **Initialize Kernel:** At iteration $t=0$, set the Gaussian kernel standard deviation $\sigma = \sigma_{start}$ and kernel size $k = k_{start}$ [S4].
2.  **Schedule Update:** For every $k_b$ iterations, reduce the blur intensity. The sources describe two variations:
    *   *Exponential Decay:* $\sigma$ is exponentially reduced to 0 at a specific iteration (e.g., 10,000) and remains 0 afterward [S2, unofficial].
    *   *Linear/Progressive Reduction:* $\sigma$ is progressively reduced to construct adaptive blurred supervision [S3].
    *   *Fixed Schedule (Trick-GS):* The kernel size is lowered before densifying Gaussians to introduce extra signal on erroneous Gaussians as noise reduces [S4].
3.  **Apply Downsampling Adjustment:** If downsampling is activated, adjust the kernel size by the scale of downsampling at the current stage, as initial hyperparameters are based on original image resolutions [S4].
    *   Adjusted Kernel Size $k' = k / s_{down}$ [S4].
4.  **Blur Image:** Convolve the raw training image $I_{raw}$ with the 2D Gaussian kernel $G(\sigma)$ to produce $I_{smooth}$:
    $$ I_{smooth}(x, y) = (I_{raw} * G(\sigma))(x, y) $$
    where $G(\sigma)$ is the 2D Gaussian function with standard deviation $\sigma$ [S2, unofficial].
5.  **Compute Loss:** Calculate the photometric loss (e.g., L1 or L2) between the rendered image $I_{render}$ and the smoothed image $I_{smooth}$ [S2, unofficial].
    $$ \mathcal{L}_{smooth} = \| I_{render} - I_{smooth} \|_1 $$
6.  **Edge Cases:**
    *   **Boundary Conditions:** Ensure the convolution handles image boundaries correctly (e.g., zero-padding or reflection padding) to avoid artifacts at image edges [G].
    *   **Zero Blur:** When $\sigma = 0$, the kernel becomes a delta function, and $I_{smooth} = I_{raw}$, reverting to standard supervision [S2, unofficial].

**Pseudocode:**
```python
def get_smoothed_supervision(raw_image, iteration, total_iterations, 
                             sigma_start=2.4, k_start=9, k_b=100, 
                             t_end=19500, downscale_scale=1.0):
    """
    Computes the smoothed supervision image for a given iteration.
    
    Args:
        raw_image: 2D numpy array of the training image.
        iteration: Current training iteration number.
        total_iterations: Total number of training iterations.
        sigma_start: Initial standard deviation of the Gaussian kernel.
        k_start: Initial kernel size (width/height).
        k_b: Iteration interval for reducing blur.
        t_end: Iteration at which blur is fully removed.
        downscale_scale: Scale factor for downsampling.
        
    Returns:
        smoothed_image: 2D numpy array of the blurred image.
    """
    # Step 1: Determine current sigma based on schedule
    # Variation 1: Linear/Progressive reduction (common in adaptive methods)
    if iteration < t_end:
        # Linear decay from sigma_start to 0 over t_end iterations
        sigma = sigma_start * (1.0 - iteration / t_end)
    else:
        sigma = 0.0
        
    # Variation 2: Exponential decay (as per [S2, unofficial])
    # sigma = sigma_start * exp(-iteration / decay_constant)
    # Note: Exact decay constant not specified in [S2, unofficial], refer to supplement.
    
    # Step 2: Adjust kernel size for downsampling
    # Initial hyperparameters are based on original resolution
    current_kernel_size = k_start / downscale_scale
    
    # Ensure kernel size is odd for symmetric convolution
    current_kernel_size = int(current_kernel_size)
    if current_kernel_size % 2 == 0:
        current_kernel_size += 1
        
    # Step 3: Apply Gaussian Blur
    # Create 2D Gaussian kernel
    # If sigma is 0, return raw image (delta function)
    if sigma == 0:
        return raw_image
        
    # Generate 1D Gaussian kernel
    kernel_1d = gaussian_1d(sigma, current_kernel_size)
    # Create 2D kernel via outer product (separable convolution)
    kernel_2d = np.outer(kernel_1d, kernel_1d)
    
    # Convolve image with kernel
    # Use appropriate padding to handle boundaries
    smoothed_image = convolve2d(raw_image, kernel_2d, mode='same', boundary='fill', fillvalue=0)
    
    return smoothed_image

def gaussian_1d(sigma, size):
    """Generates a 1D Gaussian kernel."""
    ax = np.linspace(-(size // 2), size // 2, size)
    gauss = np.exp(-0.5 * np.square(ax) / np.square(sigma))
    return gauss / np.sum(gauss)
```

A technique that randomly scales the kernel size during optimization to mitigate weak and noisy gradient signals, allowing combinations of different-sized kernels to guide training.

## Operating characteristics
*   **Time Complexity:** The blurring operation is $O(N \cdot k^2)$ per image, where $N$ is the number of pixels and $k$ is the kernel size. Since the kernel size is small (e.g., 9x9) and separable convolution can be used ($O(N \cdot k)$), the overhead is minimal compared to the rendering cost [S1].
*   **Memory Complexity:** Requires storing the raw image and the smoothed image, or computing the blur on-the-fly. No additional large data structures are needed [S2, unofficial].
*   **Measured Performance:** On DTU 3-view, Smoothed 2D Supervision (Adaptive Gaussian Blur) achieves 19.72 PSNR, improving over the Baseline (19.54) [S3].
*   **Strengths:** Stabilizes camera alignment, restricts the spectrum of the learned 3D scene, and reduces training iterations (e.g., to 50k compared to 200k for MLP-based methods) [S1][S2, unofficial].
*   **Limitations:** Handcrafted strategies (linear or adaptive Gaussian blur) cannot fully align the frequency relationship between positional encodings and pixel supervision, potentially leading to suboptimal results compared to adaptive methods [S3].
*   **When to Use:** Crucial for successful pose refinement and joint optimization, especially in the early stages of training or when dealing with noisy data [S1].
*   **When Not to Use:** When high-frequency detail preservation is critical in the final output and the overhead of blurring is unacceptable, or when using fully adaptive frequency alignment methods that do not require explicit blurring [S3].

## Background
Smoothed 2D Supervision was introduced as part of techniques to improve the robustness of joint optimization of camera poses and radiance fields. It was proposed in "Improving Robustness for Joint Optimization of Camera Pose and Decomposed Low-Rank Tensorial Radiance Fields" [S1][S2, unofficial] and further analyzed in "Few-shot NeRF by Adaptive Rendering Loss Regularization" [S3] and "Trick-GS: A Balanced Bag of Tricks for Efficient Gaussian Splatting" [S4]. The method is inspired by the analysis of spectral modulation in radiance fields, where blurring the 2D training images helps to stabilize the optimization process by providing smoother gradients [S2, unofficial].
