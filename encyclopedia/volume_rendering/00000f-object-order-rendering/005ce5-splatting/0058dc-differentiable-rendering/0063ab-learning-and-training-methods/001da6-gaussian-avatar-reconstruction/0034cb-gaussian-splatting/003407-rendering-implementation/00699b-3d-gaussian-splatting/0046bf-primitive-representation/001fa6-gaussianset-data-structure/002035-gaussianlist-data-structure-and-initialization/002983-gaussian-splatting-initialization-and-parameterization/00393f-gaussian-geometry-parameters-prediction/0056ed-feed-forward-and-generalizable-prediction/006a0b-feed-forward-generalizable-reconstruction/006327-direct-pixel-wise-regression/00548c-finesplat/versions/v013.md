# FineSplat

Also called: Detailed Splats, Fine Patches, Local Groups

## Overview
FineSplat is a feed-forward 3D Gaussian Splatting framework that predicts a set of 3D Gaussians from $N$ context views (with or without known poses) using a two-stage dual-grouping strategy to balance local detail preservation with global multi-view reasoning [S1, unofficial]. It builds on [Feed-forward and Generalizable Prediction](15832-feed-forward-and-generalizable-prediction.md) by replacing global attention with view-wise token grouping in Stage 1 and 3D spatial grouping in Stage 2, allowing fine-grained 4x4 patch tokens to interact across different view groups once lifted to 3D [S1, unofficial]. This approach avoids the prohibitive cost of global multi-view attention while preserving fine-grained visual information, distinguishing it from sibling methods like [YoNoSplat](12847-anysplat-pipeline.md) and [ZipSplat](16423-splatt3r.md) which use coarser 14x14 patches and global or coarser interactions [S1, unofficial].

## How it works
**Inputs:** $N$ context images $I \in \mathbb{R}^{N \times H \times W \times 3}$ with known or unknown camera poses.
**Outputs:** A set of 3D Gaussians $\mathcal{G}$ defined by mean $\mu$, scale $s$, rotation $r$, opacity $\alpha$, and spherical harmonic coefficients $c$.

**Data Structures:**
1.  **Tokens:** $z \in \mathbb{R}^{M \times d}$, where $M = N \cdot (H/p) \cdot (W/p)$ is the number of fine-grained tokens, $p=4$ is the patch size, and $d$ is the feature dimension.
2.  **Gaussians:** Predicted per token. Each token generates $K=4$ Gaussians.
3.  **Error Feature Maps:** $F_n^{err} \in \mathbb{R}^{(H/p) \times (W/p) \times d_e}$ for each view $n$, combining pixel error and feature difference.

**Parameters:**
*   $p$: Patch size, fixed at 4x4 pixels [S1, unofficial].
*   $T$: Number of Stage 2 refinement steps, fixed at 4 [S1, unofficial].
*   $s$: Sub-patch stride, fixed at 2 [S1, unofficial].
*   $K$: Number of Gaussians per token, fixed at 4 [S1, unofficial].
*   $S$: Size of groups for serialized attention in Stage 2 (number of consecutive points along space-filling curve) [S1, unofficial].
*   $N$: Number of input views. Training samples $N \in \{6, 12, 24, 32\}$ [S1, unofficial].

**Algorithm:**

1.  **Scene Normalization:** To handle scale ambiguity, transform camera poses into the mean context camera frame. Rescale translations so all context camera centers lie within $[-1, 1]^3$ [S1, unofficial]. Apply the same transform to target poses [S1, unofficial].

2.  **Stage 1: View-wise Token Grouping:**
    *   Extract multi-scale features $F^l$ for $l \in \{1, 2, 3\}$ (finest to coarsest) from the input images using a shared encoder (e.g., Vision Transformer) [S1, unofficial].
    *   Fuse features into $M$ fine-grained tokens $z^{(0)}$ using Equation (1):
        $$ z^{(0)} = \text{fuse}\left(\text{up}\left(\text{fuse}\left(\text{up}(F^3) + F^2\right)\right)\right) + F^1 $$
        where $\text{up}(\cdot)$ is bilinear upsampling and $\text{fuse}(\cdot)$ is a convolutional fusion block [S1, unofficial].
    *   Encode tokens using view-wise token grouping based on the Multi-View Pyramid (MVP) architecture. This performs fine-grained attention within small view groups and exchanges information across all views via coarser global tokens [S1, unofficial].

3.  **Stage 2: 3D Spatial Token Grouping (Iterative Refinement for $t = 1 \dots T$):**
    *   **Decode:** Map each token $z^{(t-1)}$ to $K=4$ Gaussian primitives and their attributes using a lightweight linear Gaussian head $\mathcal{D}$ [S1, unofficial].
    *   **Patch-Aligned Sub-Pixel Gaussian Reconstruction:** For each token, predict 4 Gaussians assigned to non-overlapping 2x2 sub-patches. Learn a 2D image-space offset $\Delta = (\Delta_x, \Delta_y)$ for each Gaussian. Compute bounded offsets:
        $$ \delta_x = 2s \tanh(\Delta_x), \quad \delta_y = 2s \tanh(\Delta_y) $$
        where $s=2$. This ensures $\delta_x, \delta_y \in [-s/2, s/2]$, keeping Gaussians within their 2x2 sub-patch [S1, unofficial].
    *   **Ray Unprojection:** For a sub-patch with center $(u_c, v_c)$, compute displaced coordinate $(u, v) = (u_c, v_c) + (\delta_x, \delta_y)$. Unproject using predicted camera intrinsics. Transform and normalize direction using camera-to-world rotation, using camera translation as ray origin [S1, unofficial].
    *   **Render:** Render the predicted Gaussians into every context view $n$ to obtain rendered images $\hat{I}_n$ [S1, unofficial].
    *   **Compute Error Features:** For each view $n$, compute signed error map $E_n = \hat{I}_n - I_n$ and feature-level difference $\Delta\phi_n = \phi(\hat{I}_n) - \phi(I_n)$ using a pretrained ResNet-18 encoder $\phi(\cdot)$ [S1, unofficial]. Combine with finest-scale features $F_n^1$ from Stage 1:
        $$ F_n^{err} = [E_{err}(E_n, \Delta\phi_n); E_{feat}(F_n^1)] \in \mathbb{R}^{(H/p) \times (W/p) \times d_e} $$
        where $E_{err}$ and $E_{feat}$ are linear embedding layers, and $[\cdot; \cdot]$ is concatenation [S1, unofficial].
    *   **Gather Errors:** For each token, compute self error feature $e_{self}$ from its predicted patch and aggregated error feature $e_{agg}$ averaged over all context views where the token is visible (projected onto error feature maps and filtered by frustum/occlusion) [S1, unofficial].
    *   **3D Spatial Grouping:** Lift tokens to 3D using predicted centers. Order tokens along a space-filling curve. Partition into groups of $S$ consecutive points. Apply serialized self-attention within each group. Use four attention blocks, each using a different space-filling curve, so each token meets a different set of neighbors [S1, unofficial].
    *   **Update Tokens:** Compute token residual $\Delta z_j^{(t)} = \text{Linear}(\text{SerialAttn}(h_j^{(t)}))$. Update token: $z_j^{(t)} = z_j^{(t-1)} + \Delta z_j^{(t)}$ [S1, unofficial].

4.  **Final Output:** After $T=4$ steps, decode the final tokens $z^{(T)}$ into the final set of 3D Gaussians [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Efficient due to dual-grouping. Stage 1 uses view-wise attention (affordable), and Stage 2 uses serialized attention (scales favorably with token count) instead of global attention or k-NN search [S1, unofficial].
*   **Memory Complexity:** Depends on the number of tokens $M$ and Gaussians. Uses 62K Gaussians for DL3DV (6 views), 75K for RE10K (6 views), and 1.6M for Mip-NeRF 360 (128 views) [S1, unofficial].
*   **Measured Performance:**
    *   DL3DV (6 views): 27.325 PSNR, 0.871 SSIM, 0.115 LPIPS [S1, unofficial].
    *   RE10K (6 views): 27.394 PSNR, 0.886 SSIM, 0.116 LPIPS [S1, unofficial].
    *   Mip-NeRF 360 (128 views): 23.463 PSNR, 0.706 SSIM, 0.214 LPIPS [S1, unofficial].
*   **Strengths:** Fastest among patch-aligned models with 6 and 12 views; largest quality gain per unit of time; handles fine-grained details better than coarser patch methods; no depth supervision required [S1, unofficial].
*   **Limitations:** Quality may degrade if a single pass must reconstruct a very large scene with many views, as tokens observing the same surface are more often separated into different view groups (mitigated by Stage 2) [S1, unofficial].
*   **When to use:** Novel view synthesis where high quality and efficiency are needed, especially with a small number of context views (6-24).
*   **When not to use:** When depth supervision is available and preferred, or when global attention is feasible and necessary for very complex scenes with many views (though Stage 2 helps) [S1, unofficial].

## Background
FineSplat was introduced in 2026 by Chen et al. [S1, unofficial]. It is trained on the DL3DV dataset and evaluated on DL3DV, RealEstate10K, and Mip-NeRF 360 for novel view synthesis [S1, unofficial]. It addresses the trade-off between fine-grained multi-view reasoning and computational cost in feed-forward 3D Gaussian Splatting [S1, unofficial].
