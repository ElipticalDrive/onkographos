# GART

Also called: GART, A method that extends the human to more articulated models (e.g, animals) based on the 3DGS representation

## Overview
GART is a method that extends the human to more articulated models (e.g., animals) based on the 3DGS representation [S1][S2, unofficial]. It builds on [Human and Articulated Avatars](8209-human-and-articulated-avatars.md) by generalizing the canonical-space deformation framework from bipedal humans to other articulated species.

## How it works
**Inputs and outputs:**
*   **Inputs:** Multi-view images of an articulated non-human subject (e.g., animal); camera poses; initial canonical 3D Gaussian parameters (position, covariance, opacity, color, SH coefficients) in a reference pose.
*   **Outputs:** Rendered images; optimized Gaussian attributes; deformation parameters mapping canonical Gaussians to target poses.

**Data structures:**
*   **Canonical Gaussians:** Stored in a canonical space (reference pose). Each Gaussian $i$ has attributes $\{\mathbf{p}_i, \mathbf{R}_i, \mathbf{S}_i, \alpha_i, \mathbf{c}_i, \mathbf{sh}_i\}$, where $\mathbf{p}_i$ is position, $\mathbf{R}_i$ rotation, $\mathbf{S}_i$ scale, $\alpha_i$ opacity, $\mathbf{c}_i$ base color, and $\mathbf{sh}_i$ spherical harmonic coefficients.
*   **Deformation Parameters:** Parameters defining the target pose (e.g., skeleton joint angles, shape coefficients). These map canonical Gaussians to world space via a differentiable deformation function $D(\cdot)$.

**Steps:**
1.  **Initialization:** Initialize 3D Gaussians in a canonical reference pose (e.g., neutral stance) using structure-from-motion or neural network initialization [S1][S2, unofficial].
2.  **Deformation:** For a target pose defined by parameters $\theta$, deform canonical Gaussians to world space using a differentiable deformation function $D(\mathbf{p}_i, \theta)$ [S1][S2, unofficial]. This function maps canonical positions to world positions based on the articulated skeleton or mesh.
3.  **Rasterization:** Project deformed Gaussians to 2D screen space. Sort overlapping Gaussians $\mathcal{O}_p$ front-to-back for each pixel $p$.
4.  **Differentiable Rendering:** Compute the rendered color $\mathbf{C}(p)$ using alpha-blending:
    $$
    \mathbf{C}(p) = \sum_{i \in \mathcal{O}_p} \mathbf{c}_i \cdot \alpha_i \cdot \prod_{j=1}^{i-1} (1 - \alpha_j)
    $$
    where $\mathbf{c}_i$ is the color of the $i$-th Gaussian, $\alpha_i$ is its opacity, and the product term is the transmittance from preceding Gaussians [S1][S2, unofficial].
5.  **Optimization:** Minimize photometric loss between rendered images and ground truth multi-view images. Optimize Gaussian attributes and deformation parameters $\theta$ via gradient descent [S1][S2, unofficial].

**Parameters:**

*   **Number of Gaussians:** Not given in the sources.
*   **Deformation function:** Specific implementation details (e.g., linear blend skinning, neural deformation field) are not given in the sources [G].

**Edge cases and pitfalls:**
*   **Degenerate poses:** Extreme articulation may cause self-intersection or invalid deformation. Not given in the sources.
*   **Precision:** Standard floating-point precision used in 3DGS [G].

## Background
GART was introduced in the context of recent advances in 3D Gaussian splatting [S1][S2, unofficial]. It extends the human avatar reconstruction capabilities of 3DGS to other articulated models, such as animals [S1][S2, unofficial].
