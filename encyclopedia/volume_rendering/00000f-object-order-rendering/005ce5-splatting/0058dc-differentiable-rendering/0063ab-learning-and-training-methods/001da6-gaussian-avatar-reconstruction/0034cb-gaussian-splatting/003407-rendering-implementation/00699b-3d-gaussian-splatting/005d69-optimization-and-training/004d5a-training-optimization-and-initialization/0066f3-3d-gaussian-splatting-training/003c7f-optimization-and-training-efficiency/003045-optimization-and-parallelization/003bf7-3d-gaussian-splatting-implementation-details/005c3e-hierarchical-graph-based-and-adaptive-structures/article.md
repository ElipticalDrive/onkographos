# Hierarchical, Graph-Based, and Adaptive Structures

Also called: Adaptive Spatial Partitioning, Dynamic Gaussian Selection, Scale-Adaptive Splatting, Cross-Level Feature Coupling

## Overview
This family addresses the limitations of standard 3D Gaussian Splatting (3DGS) regarding memory efficiency, rendering quality at varying scales, and structural coherence in large or complex scenes. While standard 3DGS uses a flat list of Gaussians, these methods introduce hierarchy, graph connectivity, or dynamic adaptation to optimize training, reduce memory footprint, and eliminate artifacts like aliasing or boundary discontinuities. They differ from siblings like [TurboGS](15697-turbogs.md) (which focuses on rasterization speed) and [Data Compression](12943-data-compression-and-storage-optimization.md) (which focuses on storage) by modifying the geometric representation or optimization graph itself.

## Shared principles
All methods in this family modify the standard 3DGS primitive set or its optimization/rendering pipeline to introduce structure or adaptivity.
*   **Primitive Representation:** Gaussians are defined by mean $\mathbf{\mu}$, covariance $\mathbf{\Sigma}$ (derived from scale $\mathbf{s}$ and rotation $\mathbf{q}$), opacity $\alpha$, and spherical harmonics coefficients $\mathbf{c}$ .
*   **Rendering Equation:** The color $C$ for a pixel is computed via alpha-blending of overlapping Gaussians sorted by depth:
    $$ C = \sum_{i \in N_{active}} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $N_{active}$ are the Gaussians overlapping the pixel .
*   **Adaptivity:** Methods either partition the scene (graph/tree), select a subset of primitives (dynamic), or deform primitives based on view scale (adaptive) .

## Subtopics

### [TraGraph-GS](14454-tragraph-gs.md)
TraGraph-GS handles large-scale scenes by decoupling training into local regions using a camera connectivity graph. It constructs a graph $G=(V, E, w)$ where vertices are images and edge weights are feature match counts. It segments this graph into $k$ regions using BFS. Local Gaussians are trained per region with multi-view (NCC) and multi-scale constraints. A global coarse representation is trained on downsampled data. Novel views are rendered by combining local and global Gaussians using a progressive weighting strategy based on a matching score $S$ and overlap threshold $\beta$ to eliminate boundary artifacts.

### [FlexGS](16110-flexgs.md)
FlexGS enables dynamic inference-time adaptation to memory constraints without retraining. It uses a learnable Gaussian selector (trained with Gumbel-Softmax relaxation) to choose a subset of $K=eN$ Gaussians based on a target ratio $e$. A ratio-dependent transformation field then adjusts the parameters (position, scale, opacity) of the selected Gaussians to compensate for the visual loss of the pruned ones. This allows a single model to serve varying hardware constraints (e.g., mobile vs. desktop).

### [Mipmap-GS](16893-mipmap-gs.md)
Mipmap-GS eliminates aliasing artifacts (zoom-in spikes, zoom-out thickness) by deforming pre-trained Gaussians at test time. It optimizes the Gaussians against scale-specific "pseudo ground-truth" images generated by resizing the base rendering: super-resolution (SwinIR) for zoom-in and bilinear interpolation for zoom-out. The optimization minimizes the L2 loss between the rendered image at the target scale and the pseudo-GT, updating Gaussians via gradient descent for 1,000 iterations.

### [Hierarchical Anchor Coupling](17260-hierarchical-anchor-coupling.md)
Hierarchical Anchor Coupling (HAC) solves feature isolation in octree-based 3DGS. It aggregates context from adjacent octree levels (coarser and finer) to compute a per-level feature adjustment $\delta^l$. This adjustment is broadcast as a residual to all visible anchors at that level: $\hat{f}_i = f_i + \delta^{l_i}$. The context is computed using Structure-Aware Containment Aggregation (SACA) operators. If a level lacks an adjacent neighbor (boundary case), the self-context is used. This injects shared structural information while preserving per-anchor variation.

## Background
3D Gaussian Splatting [G] introduced a fast, differentiable rendering technique using explicit Gaussian primitives. However, standard 3DGS suffers from high memory usage, boundary artifacts in large scenes, and aliasing at varying zoom levels. Recent research has focused on hierarchical structures (octrees, graphs) and adaptive mechanisms to improve scalability and quality. TraGraph-GS  addresses large-scale scene partitioning. FlexGS  addresses dynamic memory constraints. Mipmap-GS  addresses scale-dependent aliasing. Hierarchical Anchor Coupling  addresses feature propagation in hierarchical representations.
