# GSGAN Hierarchical Generation

Also called: GSGAN

## Overview
GSGAN is a generative model that synthesizes 3D Gaussian splats hierarchically to approximate complex 3D shapes and textures, building on the primitive representation defined in [Gaussian Parameter Prediction](18303-gaussian-parameter-prediction.md). It differs from standard 3D Gaussian Splatting by generating the Gaussian parameters via a deep neural network conditioned on pose and camera views, rather than optimizing them from static point clouds. This allows for the generation of novel 3D objects from 2D images.

## How it works
**Inputs and Outputs:**
The method takes an intermediate feature tensor $x_l$ at level $l$ and a camera parameter vector $\theta$ as input. It outputs a set of Gaussian parameters: opacity $\hat{\alpha}$, quaternion orientation $\hat{q}$, position $\hat{\mu}$, scale difference $\hat{s}$, and color $\hat{c}$. The final scale is derived from $\hat{s}$ and a hierarchical constant $\Delta s$.

**Data Structures:**
The Gaussian set is organized hierarchically across $L$ levels.
- Level $l=0$ starts with $N=256$ Gaussians.
- Each level upsamples by a ratio $r=4$.
- Total Gaussians: 87,000 for $256 \times 256$ resolution ($L=5$) and 349,000 for $512 \times 512$ resolution ($L=6$).
- Channel dimensions per level $[0, 1, 2, 3, 4, 5]$ are $[512, 512, 256, 128, 128, 128]$.

2. **Feature Propagation:** For each level $l$ from 0 to $L-1$:

        - If $0 < l \le 3$: Use local attention similar to EdgeConv, computing attention scores against $K$-nearest neighbors ($K=16$).

3. **Parameter Activation:** Apply specific activation functions to the linear outputs:
    - Position $\hat{\mu}$: $\tanh$ activation.
    - Scale difference $\hat{s}$: $-\text{softplus}$ activation.
    - Color $\hat{c}$: Linear output (no activation mentioned, but typically sigmoid or linear depending on range).
    - Quaternion $\hat{q}$: Normalized to unit length.
    - Opacity $\hat{\alpha}$: Sigmoid activation (implied by "opacity to be 0.1" initialization and standard GAN practice, though source says "omit for simplicity" in rendering, the initialization implies a bounded output).
4. **Hierarchical Scaling:** Calculate the scale reduction constant $\Delta s$ based on resolution and hierarchy depth. The final scale is derived from the predicted $\hat{s}$ and $\Delta s$.

**Formulas:**
The output of the `toGaus` layer at level $l$ is defined as [S1]:
$$
p_l = \text{Lin}_p(x_l)
$$
$$
\hat{\mu}_l = \tanh(\text{Lin}_{\hat{\mu}}(x_l))
$$
$$
\hat{s}_l = -\text{softplus}(\text{Lin}_{\hat{s}}(x_l))
$$
$$
\hat{c}_l = \text{Lin}_{\hat{c}}(x_l, \theta)
$$
where $p \in \{\hat{\alpha}, \hat{q}\}$ and $\text{Lin}_{(\cdot)}$ is a linear layer. The constant $\Delta s$ is calculated as [S1]:
$$
\Delta s = -\log\left(\sqrt{\frac{H \times W}{L \times N}}\right)
$$
where $H, W$ are image height and width, $L$ is the total number of hierarchical levels, and $N$ is the initial number of Gaussians at level $l=0$.

**Parameters:**
- Upsampling ratio $r = 4$ [S1].
- Initial Gaussians $N = 256$ [S1].
- Hierarchical levels $L = 5$ for $256 \times 256$ resolution, $L = 6$ for $512 \times 512$ resolution [S1].
- Objective function coefficients: $\lambda = 1$, $\lambda_{pose} = 1$, $\lambda_{knn} = 10$ [S1].
- $\lambda_{center} = 1$ for FFHQ dataset, $\lambda_{center} = 10$ for AFHQ-Cat dataset [S1].
- Training duration: Discriminator sees 10–15 million images [S1].
- AdaIN and adaptive layerscale are applied only to layers lower than level 3 [S1].
- Equalized learning rate is used for every layer [S1].

**Edge Cases and Pitfalls:**
- Computational cost of self-attention and KNN grows with the number of Gaussians. The method switches to parent-point interaction for $l>3$ to mitigate this [S1].
- Modulation (AdaIN) on higher levels ($l \ge 3$) does not significantly affect rendering results and is omitted to save computation [S1].

## Operating characteristics
- **Time Complexity:** Self-attention at level 0 is $O(N^2)$. Local attention at levels 1-3 is $O(N \cdot K)$ where $K=16$. Parent-point interaction at levels 4+ is $O(N)$. The hierarchical structure keeps the total computational cost manageable compared to global self-attention on the full set.
- **Memory Complexity:** Stores Gaussian parameters for all levels simultaneously during generation. Total Gaussians: 87K ($256^2$) or 349K ($512^2$).
- **Strengths:** Generates high-fidelity 3D structures with hierarchical detail. Efficient attention mechanisms allow scaling to higher resolutions.
- **Limitations:** Requires significant training time (10-15M images for discriminator). Performance depends on the quality of the pose conditioning.
- **When to use:** When generating novel 3D objects from 2D images is required, and hierarchical detail is beneficial.
- **When not to use:** When real-time rendering of a fixed set of Gaussians is the only goal without generation capability.

## Background
GSGAN was introduced in the paper "GSGAN: Adversarial Learning for Hierarchical Generation of 3D Gaussian Splats" [S1]. It builds upon the 3D Gaussian Splatting representation [22] and the StyleGAN2 architecture [12, 58]. The method was developed to enable the generation of 3D-aware images using Gaussian primitives, extending the capabilities of GANs to 3D space.
