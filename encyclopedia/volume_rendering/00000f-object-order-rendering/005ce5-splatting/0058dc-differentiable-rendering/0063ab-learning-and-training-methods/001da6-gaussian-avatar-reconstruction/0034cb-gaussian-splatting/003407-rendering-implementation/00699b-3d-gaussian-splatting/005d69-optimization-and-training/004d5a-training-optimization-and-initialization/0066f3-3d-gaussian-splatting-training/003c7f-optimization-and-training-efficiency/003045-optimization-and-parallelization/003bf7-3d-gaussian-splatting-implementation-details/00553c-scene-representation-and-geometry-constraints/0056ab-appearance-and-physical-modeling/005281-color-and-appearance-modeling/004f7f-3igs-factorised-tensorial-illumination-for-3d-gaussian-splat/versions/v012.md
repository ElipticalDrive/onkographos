# 3iGS (Factorised Tensorial Illumination for 3D Gaussian Splatting)

## Overview
3iGS enhances the rendering quality of 3D Gaussian Splatting (3DGS) by modeling specular view-dependent effects through a continuous local illumination field and per-Gaussian Bidirectional Reflectance Distribution Function (BRDF) attributes, rather than optimizing outgoing radiance in isolation [S1]. It solves the problem of inaccurate specular highlights in reflective scenes by decoupling scene lighting from material properties, allowing for physically interpretable shading while maintaining the rapid rasterization speeds of the base 3DGS pipeline [S1]. Unlike vanilla 3DGS, which uses fixed Spherical Harmonics (SH) coefficients for view-dependent color that lack physical interpretability, 3iGS explicitly models the interaction between a learned illumination grid and Gaussian BRDF features [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ 3D Gaussians $\{G_i\}_{i=1}^N$ initialized from a point cloud (e.g., via SfM), a coarse illumination grid $\mathcal{G}_l$, and a neural network $\mathcal{F}$ for specular shading.
*   **Outputs:** A rendered image $\hat{\mathbf{C}}$ and optimized Gaussian parameters (mean, covariance, opacity, diffuse color, BRDF features) and grid parameters.

**Data Structures:**
1.  **3D Gaussian $G_i$:**
    *   Mean $\boldsymbol{\mu}_i \in \mathbb{R}^3$: Position.
    *   Opacity $\alpha_i \in \mathbb{R}$: Transparency.
    *   Scaling matrix $\mathbf{S}_i \in \mathbb{R}^{3 \times 3}$: Diagonal scaling factors.
    *   Rotation matrix $\mathbf{R}_i \in \mathbb{R}^{3 \times 3}$: Orientation.
    *   Diffuse color $\mathbf{c}_{d,i} \in \mathbb{R}^3$: Constant base color.
    *   BRDF features $\boldsymbol{\rho}_i \in \mathbb{R}^{20}$: Repurposed 16 SH coefficients (from 3DGS) plus 4 additional parameters for base color and roughness used in Integrated Directional Encoding (IDE) [S1].
2.  **Illumination Grid $\mathcal{G}_l$:**
    *   Represented as a factorised tensor with resolution $150^3$ voxels (coarse) [S1].
    *   Formulated using vector-matrix spatial factorisation with $R_L$ feature channels [S1].
    *   Parameters: Feature tensors $\mathbf{A}_{L,r}^X, \mathbf{A}_{L,r}^Y, \mathbf{A}_{L,r}^Z$ and feature vectors $\mathbf{b}_{3r-2}, \mathbf{b}_{3r-1}, \mathbf{b}_{3r}$ for $r=1 \dots R_L$ [S1].
3.  **Neural Renderer $\mathcal{F}$:**
    *   A small neural network mapping $\{\boldsymbol{\rho}_i, L_i, \omega_o\} \mapsto \mathbf{c}_{s,i}$ [S1].

**Formulas:**
*   **Covariance Matrix:** Derived from learned scaling $\mathbf{S}$ and rotation $\mathbf{R}$:
    $$ \boldsymbol{\Sigma} = \mathbf{R}\mathbf{S}\mathbf{S}^\top\mathbf{R}^\top $$
    In camera coordinates, using viewing transformation $\mathbf{W}$ and affine approximation of projective transformation $\mathbf{J}$:
    $$ \boldsymbol{\Sigma}' = \mathbf{J}\mathbf{W}\boldsymbol{\Sigma}\mathbf{W}^\top\mathbf{J}^\top $$
    [S1]

*   **Gaussian Density:**
    $$ g(\mathbf{x}|\boldsymbol{\mu}, \boldsymbol{\Sigma}) = \exp\left(-\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})\right) $$
    [S1]

*   **Illumination Grid Query:**
    The incoming illumination $L_i$ for a Gaussian at mean $\mathbf{x}_i$ is computed by interpolating from the factorised tensor grid $\mathcal{G}_l$:
    $$ \mathcal{G}_l : \{\mathbf{x}_i\} \mapsto L_i $$
    The grid is defined as:
    $$ \mathcal{G}_l = \sum_{r=1}^{R_L} \mathbf{A}_{L,r}^X \circ \mathbf{b}_{3r-2} + \mathbf{A}_{L,r}^Y \circ \mathbf{b}_{3r-1} + \mathbf{A}_{L,r}^Z \circ \mathbf{b}_{3r} $$
    where $\circ$ denotes the appropriate tensor contraction/interaction defined by the factorisation scheme (vector-matrix spatial factorisation) [S1].

*   **Outgoing Radiance:**
    The total color $\mathbf{c}(\omega_o)$ is the sum of diffuse and specular components:
    $$ \mathbf{c}(\omega_o) = \mathbf{c}_d + \mathbf{c}_s(\omega_o) $$
    [S1]

*   **Specular Color:**
    Computed by the neural network $\mathcal{F}$:
    $$ \mathcal{F} : \{ \boldsymbol{\rho}_i, L_i, \omega_o \} \mapsto \mathbf{c}_s $$
    The viewing direction $\omega_o$ is encoded using Integrated Directional Encoding (IDE) [S1].

*   **Alpha Blending:**
    For a pixel $\mathbf{u}$, the final color $\hat{\mathbf{C}}$ is computed by alpha blending $N$ ordered Gaussians:
    $$ \hat{\mathbf{C}} = \sum_{i \in N} T_i g_i(\mathbf{u} | \boldsymbol{\mu}', \boldsymbol{\Sigma}') \alpha_i \mathbf{c}_i, \quad T_i = \prod_{j=1}^{i-1} (1 - g_j(\mathbf{u} | \boldsymbol{\mu}', \boldsymbol{\Sigma}') \alpha_j) $$
    [S1]

*   **Loss Function:**
    $$ \mathcal{L} = (1 - \lambda)\mathcal{L}_1 + \lambda \mathcal{L}_{\text{D-SSIM}} $$
    with $\lambda = 0.2$ [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize 3D Gaussians from a point cloud. Initialize the illumination grid $\mathcal{G}_l$ with a boundary encapsulating the scene bounding box. Set grid resolution to $150^3$ voxels [S1].
2.  **Training Phase 1 (Diffuse Only):** For the first 3,000 iterations, optimize the model using only the diffuse color $\mathbf{c}_d$. Do not include the specular component $\mathbf{c}_s$ in the rendering equation [S1].
3.  **Training Phase 2 (Full Shading):** After 3,000 iterations, enable specular shading. Compute incoming illumination $L_i$ for each Gaussian by querying $\mathcal{G}_l$ at $\boldsymbol{\mu}_i$. Compute specular color $\mathbf{c}_s$ using $\mathcal{F}(\boldsymbol{\rho}_i, L_i, \omega_o)$. Combine with $\mathbf{c}_d$ to get $\mathbf{c}(\omega_o)$ [S1].
4.  **Grid Boundary Management:** Midway through training, shrink the illumination grid boundary to fit the current distribution of Gaussians. Resample the grid to maintain the same number of voxels (density) [S1].
5.  **Rendering:** Rasterize the scene using the standard 3DGS alpha-blending pipeline with the computed $\mathbf{c}(\omega_o)$ [S1].
6.  **Optimization:** Update all parameters (Gaussian means, opacities, covariances, diffuse colors, BRDF features, and grid tensors) using gradient descent to minimize $\mathcal{L}$ [S1].

**Edge Cases and Pitfalls:**
*   **Grid Boundary:** If the illumination grid boundary is not shrunk midway through training, it may encompass empty space, leading to inefficient memory usage and potentially inaccurate illumination queries for Gaussians near the edges. The source specifies shrinking the grid to fit the Gaussians and resampling with the same number of voxels [S1].
*   **Training Stability:** Training specular effects from the beginning can be unstable. The method requires a two-phase training strategy: diffuse-only for the first 3,000 iterations, then adding specular [S1].
*   **BRDF Feature Initialization:** The BRDF features $\boldsymbol{\rho}_i$ are repurposed from the 16x3 SH coefficients of 3DGS. This initialization leverages existing view-dependent information but must be adapted for the new shading model [S1].

## Subtopics

### [Physically-Based 3D Gaussian Splatting](16738-physically-based-3d-gaussian-splatting.md)
Physically-Based 3D Gaussian Splatting (PBR 3DGS) is a framework that assigns physically interpretable rendering attributes to Gaussian primitives and evaluates the rendering equation to produce per-Gaussian PBR colors, replacing the view-dependent spherical harmonics used in vanilla 3DGS with a physical Bidirectional Reflectance Distribution Function (BRDF). It solves the problem of inverse rendering and relighting by enabling the simulation of complex lighting interactions, such as indirect illumination and shadows, which vanilla 3DGS cannot natively represent due to its lack of physical material definitions. Unlike vanilla 3DGS, which uses $k$-order spherical harmonics for view-dependent effects that lack physical interpretability, this method provides physical interpretability by explicitly modeling albedo, roughness, and metalness.

### [Variational Quantum Circuit (VQC) for View-Dependent Encoding](17531-variational-quantum-circuit-vqc-for-view-dependent-encoding.md)
This method replaces or modulates classical Spherical Harmonics (SH) with a Variational Quantum Circuit (VQC) to model view-dependent radiance and opacity for 3D Gaussians, specifically targeting high-frequency specular effects and reducing artifacts like "floaters". It sets itself apart from its parent [3iGS](13977-3igs-factorised-tensorial-illumination-for-3d-gaussian-splat.md) by using quantum-inspired entanglement and Bloch sphere mapping for directional encoding, and from its sibling [Physically-Based 3D Gaussian Splatting](16738-physically-based-3d-gaussian-splatting.md) by relying on learned quantum parameterizations rather than explicit physical scattering models.

## Operating characteristics
*   **Time Complexity:** Rendering speed is comparable to 3DGS because the illumination field is pre-calculated and stored in the grid, avoiding per-ray tracing. The query operation is a tensor interpolation [S1].
*   **Memory Complexity:** The illumination grid uses a coarse resolution of $150^3$ voxels, which uses 87.5% less voxels compared to TensoRF on synthetic datasets. The memory footprint is low relative to the number of optimized Gaussians, which is often an order of magnitude higher [S1].
*   **Performance:** On the Shiny Blender dataset, 3iGS achieves an average PSNR of 27.51, SSIM of 0.930, and LPIPS of 0.045 [S1]. It surpasses vanilla 3DGS in scenes with reflective surfaces and specular highlights [S1].
*   **Strengths:** Accurate modeling of specular view-dependent effects; fast rendering; compact illumination representation.
*   **Limitations:** Relies on a neural network for specular shading, which adds some computational overhead compared to pure analytical functions; requires careful training schedule (diffuse then specular) [S1].
*   **When to use:** Scenes with significant specular reflections and glossy materials where vanilla 3DGS fails to capture view-dependent color changes.
*   **When not to use:** Scenes with purely diffuse materials where the added complexity of the illumination grid and neural renderer provides no benefit over standard 3DGS.

## Background
3iGS (Factorised Tensorial Illumination for 3D Gaussian Splatting) was introduced by Z.J. Tang and T.J. Cham [S1]. It addresses the limitations of vanilla 3DGS, which optimizes outgoing radiance in isolation using Spherical Harmonics, failing to capture complex specular effects and physical lighting interactions [S1]. The method is inspired by conventional computer graphics engines that use baking techniques and light probes for fast rendering [S1]. It builds on the factorised tensor representation from TensoRF [S1] to create a compact, continuous local illumination field.
