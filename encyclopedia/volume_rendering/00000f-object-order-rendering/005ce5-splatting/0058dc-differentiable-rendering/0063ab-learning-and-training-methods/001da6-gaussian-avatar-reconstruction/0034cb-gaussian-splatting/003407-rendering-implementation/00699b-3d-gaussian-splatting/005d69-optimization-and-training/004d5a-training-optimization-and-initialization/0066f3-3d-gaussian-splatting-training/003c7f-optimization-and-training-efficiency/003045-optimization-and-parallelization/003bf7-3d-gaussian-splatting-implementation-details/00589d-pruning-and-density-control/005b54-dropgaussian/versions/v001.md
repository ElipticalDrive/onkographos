# DropGaussian

Also called: Structural Regularization for Sparse-view Gaussian Splatting

## Overview
DropGaussian is a structural regularization technique for sparse-view 3D Gaussian Splatting that randomly removes a subset of Gaussians during the training process to alleviate overfitting to the limited number of training views [S1]. It sets itself apart from prior-based methods (which use external depth signals or 2D generative models) by being prior-free, requiring no additional computational costs, external data, or complex modules [S1]. Unlike standard 3DGS, which suffers from overfitting in sparse-view settings due to low gradient feedback for occluded or distant Gaussians, DropGaussian improves the visibility and gradient magnitude of remaining Gaussians by temporarily excluding closer ones [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:** The set of 3D Gaussians $\mathcal{G}$ (position, covariance, opacity, spherical harmonics coefficients) from the base 3D Gaussian Splatting framework [S1]; a target training view image; a current iteration index $t$; and a total iteration count $t_{\text{total}}$ [S1].
- **Outputs:** Gradients for the non-dropped Gaussians; modified opacity values for the non-dropped Gaussians used in the forward pass [S1].

**Data Structures:**
The method operates on the standard 3D Gaussian Splatting representation. Each Gaussian $i$ is defined by:
- Position $\mathbf{p}_i \in \mathbb{R}^3$
- Covariance matrix $\mathbf{\Sigma}_i$ (or rotation $\mathbf{R}_i$ and scale $\mathbf{s}_i$)
- Opacity $o_i \in [0, 1]$
- Spherical Harmonics coefficients for color

**Parameters:**
- $r$: Base dropping rate. Typical value: $0.1$ (10%) [S1].
- $\gamma$: Scaling factor for the progressive dropping rate. Values: $0$ or $1$ [S1].
- $t$: Current training iteration index [S1].
- $t_{\text{total}}$: Total number of training iterations [S1].

**Step-by-Step Method:**

1.  **Calculate Progressive Dropping Rate:**
    Compute the dropping rate $r_t$ for the current iteration $t$ using the formula:
    $$ r_t = \gamma \cdot \frac{t}{t_{\text{total}}} $$
    If $\gamma = 0$, no Gaussians are dropped. If $\gamma = 1$, the dropping rate increases linearly from $0$ to $1$ over the course of training [S1].

2.  **Random Selection:**
    Randomly select a subset of Gaussians to be dropped. The fraction of Gaussians to drop is determined by $r_t$. Let $D$ be the set of indices of dropped Gaussians, and $R$ be the set of indices of remaining (non-dropped) Gaussians [S1].

3.  **Opacity Compensation:**
    For each Gaussian $i$, calculate the modified opacity $\tilde{o}_i$ to maintain the total pixel color contribution despite the removal of other Gaussians:
    $$ \tilde{o}_i = M(i) \cdot o_i $$
    where the compensation factor $M(i)$ is defined as:
    $$ M(i) = \begin{cases} \frac{1}{1 - r_t} & \text{if } i \in R \\ 0 & \text{if } i \in D \end{cases} $$
    This scaling ensures that the cumulative opacity contributing to the color value of each pixel is preserved on average [S1].

4.  **Rendering:**
    Render the image using only the Gaussians in $R$ (those with $\tilde{o}_i > 0$) through the differentiable rasterizer. The Gaussians in $D$ are excluded from rendering and gradient computation for this iteration [S1].

5.  **Loss Computation:**
    Compute the loss $\mathcal{L}$ between the rendered RGB image and the target training view image. The loss is composed of L1 loss and D-SSIM loss, consistent with the standard 3D Gaussian Splatting framework [S1].

6.  **Backpropagation:**
    Backpropagate gradients only to the non-excluded Gaussians (those in $R$). The dropped Gaussians do not receive gradients in this iteration [S1].

7.  **Optimization Step:**
    Update the parameters (position, covariance, opacity, SH coefficients) of the non-dropped Gaussians using the computed gradients [S1].

8.  **Evaluation Phase:**
    During the evaluation/test phase, render using all Gaussians without dropping any ($r_t = 0$ effectively, or simply no dropping logic applied) to generate high-quality novel view images [S1].

**Pseudocode:**

```python
def drop_gaussian_forward_backward(
    gaussians: List[Gaussian],
    target_image: Tensor,
    current_iteration: int,
    total_iterations: int,
    gamma: float = 1.0,
    base_drop_rate: float = 0.1
) -> Tuple[List[Gaussian], Tensor]:
    """
    Performs one step of DropGaussian training.
    
    Args:
        gaussians: List of Gaussian objects with attributes:
                   - position: np.array (3,)
                   - opacity: float
                   - sh_coeffs: np.array
                   - covariance: np.array (3,3) or (rotation, scale)
        target_image: Tensor of shape (H, W, 3)
        current_iteration: int t
        total_iterations: int t_total
        gamma: float scaling factor (0 or 1)
        base_drop_rate: float r (typically 0.1)
        
    Returns:
        updated_gaussians: List of updated Gaussian objects
        loss: Scalar loss value
    """
    t = current_iteration
    t_total = total_iterations
    
    # 1. Calculate progressive dropping rate
    # Note: The source defines r_t = gamma * (t / t_total). 
    # However, the base drop rate 'r' is mentioned as 0.1. 
    # The source text says "r is set to 0.1 for 10% removal" and then 
    # "adjust the dropping rate according to the current iteration index t as follows: r_t = gamma * t / t_total".
    # It is ambiguous if r_t replaces r or scales it. 
    # Given "r_t = gamma * t / t_total", if gamma=1, r_t goes from 0 to 1. 
    # This implies the drop rate increases from 0% to 100%. 
    # The "base drop rate" of 0.1 might be a specific setting for gamma or a cap.
    # However, the formula explicitly uses gamma and t/t_total. 
    # We follow the explicit formula for r_t.
    
    r_t = gamma * (t / t_total)
    
    # Guard against division by zero in compensation if r_t approaches 1
    # In practice, t < t_total, so r_t < 1.
    
    n_gaussians = len(gaussians)
    
    # 2. Random Selection
    # Randomly select a subset of Gaussians to drop based on r_t
    # Create a mask: 1 for keep, 0 for drop
    # Number of gaussians to drop = floor(n_gaussians * r_t)
    num_to_drop = int(n_gaussians * r_t)
    
    # Generate random indices
    indices = np.arange(n_gaussians)
    np.random.shuffle(indices)
    drop_indices = indices[:num_to_drop]
    keep_indices = indices[num_to_drop:]
    
    drop_mask = np.zeros(n_gaussians, dtype=bool)
    drop_mask[drop_indices] = True
    
    # 3. Opacity Compensation
    # Calculate modified opacities
    # M(i) = 1 / (1 - r_t) if kept, 0 if dropped
    compensation_factor = 1.0 / (1.0 - r_t) if r_t < 1.0 else float('inf')
    
    # Update opacities in place or create a temporary list
    # We need to preserve original opacities for the next iteration if not updated yet
    # But 3DGS updates opacities via gradients. Here we modify the forward pass opacity.
    
    modified_gaussians = []
    for i, g in enumerate(gaussians):
        new_g = copy.deepcopy(g) # Assume Gaussian has a copy method or we reconstruct
        if drop_mask[i]:
            new_g.opacity = 0.0
        else:
            new_g.opacity = g.opacity * compensation_factor
        modified_gaussians.append(new_g)
        
    # 4. Rendering
    # Render using only modified_gaussians
    # The rasterizer handles the alpha blending based on the modified opacities
    rendered_image = rasterize(modified_gaussians, camera_params)
    
    # 5. Loss Computation
    # L1 + SSIM
    l1_loss = l1_loss(rendered_image, target_image)
    ssim_loss = ssim_loss(rendered_image, target_image)
    loss = l1_loss + ssim_loss
    
    # 6. Backpropagation
    # Compute gradients w.r.t the parameters of the modified_gaussians
    # Note: The gradients are computed for the parameters that resulted in the modified opacities.
    # Since opacity is a parameter, gradients will flow to the original opacity values 
    # scaled by the compensation factor.
    gradients = compute_gradients(loss, modified_gaussians)
    
    # 7. Optimization Step
    # Update only the non-dropped Gaussians
    # The dropped Gaussians (drop_mask[i] == True) do not receive gradients 
    # because their opacity is fixed to 0 and they are not part of the computation graph 
    # for the rendered image (or their contribution is zero).
    # However, in standard autograd, if we set opacity to 0, gradients might still be computed 
    # but multiplied by 0. The source says "backpropagate gradients only to the non-excluded Gaussians".
    # This implies we should not update the dropped ones.
    
    updated_gaussians = []
    for i, g in enumerate(gaussians):
        new_g = copy.deepcopy(g)
        if not drop_mask[i]:
            # Apply gradient update
            new_g.position -= learning_rate * gradients[i].position
            new_g.opacity -= learning_rate * gradients[i].opacity
            # Update other parameters (covariance, SH) similarly
            # Note: The source does not specify the optimizer details, 
            # assuming standard Adam or SGD as in 3DGS.
            # [G] Assuming standard Adam optimizer update step.
            updated_gaussians.append(new_g)
        else:
            # Dropped Gaussians are not updated
            updated_gaussians.append(g)
            
    return updated_gaussians, loss
```

**Edge Cases and Pitfalls:**
- **Early Training:** Overfitting primarily manifests during the later stages of training. Applying the drop ratio too early may negatively impact initial convergence [S1]. The progressive rate $r_t$ mitigates this by starting at 0 (if $\gamma=1$) or a low value.
- **Distant Gaussians:** In sparse-view settings, Gaussians far from the camera have low transmittance and are often occluded, leading to low gradient feedback. DropGaussian mitigates this by randomly removing closer Gaussians, thereby improving the visibility and gradient feedback for distant Gaussians [S1].
- **Division by Zero:** If $r_t$ approaches 1, the compensation factor $\frac{1}{1-r_t}$ approaches infinity. In practice, $t < t_{\text{total}}$, so $r_t < 1$. However, care should be taken if $t$ equals $t_{\text{total}}$ [S1].

## Operating characteristics
- **Time Complexity:** The method adds minimal computational overhead. It involves a random selection step and a simple opacity scaling operation, both of which are $O(N)$ where $N$ is the number of Gaussians. The rendering and backpropagation complexity remains the same as standard 3D Gaussian Splatting [S1].
- **Memory Complexity:** No additional memory is required beyond the standard Gaussian representation. The compensation factor is computed on the fly [S1].
- **Measured Performance:** On LLFF, Mip-NeRF360, and Blender datasets with sparse views (3, 12, and 8 training views respectively), DropGaussian achieves competitive or superior performance compared to prior-based methods (e.g., CoR-GS, FSGS) and NeRF-based methods (e.g., MipNeRF, DietNeRF) without increasing computational complexity [S1]. For example, on LLFF 3-view setting, it achieved a PSNR of 20.76, surpassing other methods [S1].
- **Strengths:** Prior-free, no additional modules, no external data, simple implementation, effective in sparse-view settings, improves gradient feedback for distant Gaussians [S1].
- **Limitations:** Requires careful tuning of the progressive rate parameters ($\gamma$, $r$). If applied too aggressively or too early, it may harm convergence [S1].
- **When to Use:** Sparse-view novel view synthesis where overfitting is a concern.
- **When Not to Use:** Dense-view settings where overfitting is less of an issue, or when computational resources are extremely constrained (though overhead is minimal, the logic adds complexity to the training loop) [S1].

## Background
DropGaussian was introduced in the paper "DropGaussian: Structural Regularization for Sparse-view Gaussian Splatting" [S1]. It addresses the overfitting problem in 3D Gaussian Splatting when trained on a small number of input views. The method is inspired by dropout in neural networks but applied structurally to the Gaussian primitives. It was developed to provide a simple, prior-free alternative to methods that rely on external depth signals or 2D generative models [S1]. The code and model are publicly available at https://github.com/DCVL-3D/DropGaussian [S1].
