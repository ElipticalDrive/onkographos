# Sensitivity-Aware Vector Clustering

Also called: Color Compression, Sensitivity-Aware Scene Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering spherical harmonic (SH) coefficients and Gaussian shape features (scale and rotation) into compact codebooks using a sensitivity-weighted distance metric [S1]. Unlike standard post-training quantization, this method derives a sensitivity measure for each parameter to prioritize the preservation of features that significantly affect image quality, achieving compression rates up to 31× with minimal visual degradation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of optimized 3D Gaussian kernels $\{G_i\}$, each defined by position, opacity, rotation, scale, and SH coefficients, along with a set of $N$ training images with known camera parameters.
*   **Output:** Two codebooks (one for color/SH, one for shape/rotation-scale) and a list of indices mapping each Gaussian to its respective codebook entry.

**Data Structures:**
*   **Codebook Entry (Shape):** 4 scalar values for a quaternion (rotation) plus 3 scalar values for scaling [S1].
*   **Codebook Entry (Color):** Indices into the SH codebook. The specific bit-width is not explicitly defined in the notes, but indices are stored as 32-bit unsigned integers [S1].
*   **Sensitivity Map:** A scalar value $S(p)$ for each parameter $p$ or vector $x$.

**Algorithm Steps:**

1.  **Sensitivity Calculation:**
    Compute the sensitivity $S(p)$ for each scene parameter $p$ by analyzing its contribution to the training images. The sensitivity is defined as the gradient of the total image energy with respect to the parameter, normalized by the image size [S1]:
    $$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p}}{\sum_{i=1}^{N} P_i} $$
    where $N$ is the number of training images, $P_i$ is the number of pixels in image $i$, and $E_i$ is the total image energy (sum of RGB components) for image $i$. The gradient $\frac{\partial E_i}{\partial p}$ is computed via a single backward pass over each training image [S1].

    For a vector $x$ (e.g., a set of SH coefficients or a covariance matrix), the sensitivity $S(x)$ is the maximum sensitivity among its components $d$:
    $$ S(x) = \max_d S(x_d) $$
    where $S(x_d)$ is the sensitivity of component $d$ [S1].

2.  **Codebook Initialization:**
    Initialize the codebooks randomly with a uniform distribution within the minimum and maximum values of each parameter [S1]. The default codebook size $K$ is 4096 [S1].

3.  **Handling High-Sensitivity Vectors (Outliers):**
    Identify vectors with sensitivity higher than a threshold $\beta_c$ (for SH coefficients) or $\beta_g$ (for Gaussian shape parameters). These vectors are not clustered but are added directly to the codebook to preserve high-impact features [S1].
    *   Typical value for $\beta_c$: $6 \times 10^{-7}$ [S1].
    *   Typical value for $\beta_g$: $3 \times 10^{-6}$ [S1].

4.  **Sensitivity-Aware Clustering:**
    Cluster the remaining vectors using a modified k-Means algorithm.
    *   **Distance Metric:** The weighted distance $D(x, c_k)$ between a vector $x$ and a centroid $c_k$ is defined as:
        $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
        where $\| \cdot \|_2^2$ is the squared Euclidean distance [S1].
    *   **Assignment:** Assign each vector $x$ to the centroid $c_k$ with the minimum distance $D(x, c_k)$ [S1].
    *   **Centroid Update:** Update each centroid $c_k$ using the weighted average of the assigned vectors $A(k)$:
        $$ c_k = \frac{1}{\sum_{x_i \in A(k)} S(x_i)} \sum_{x_i \in A(k)} S(x_i) x_i $$
        where $A(k)$ is the set of vectors assigned to centroid $c_k$ [S1].

5.  **Batched Clustering Strategy:**
    To improve performance, use a batched strategy [S1]:
    *   In each update step, pick a random subset of vectors.
    *   Compute the assignment and centroid updates for this subset.
    *   Update the global centroids using a moving average with a decay factor $\lambda_d$:
        $$ c_k^{new} = \lambda_d c_k^{old} + (1 - \lambda_d) c_k^{batch} $$
    *   Typical value for $\lambda_d$: 0.8 [S1].
    *   Batch size for color features (SH): $2^{18}$ [S1].
    *   Batch size for Gaussian parameters (shape): $2^{20}$ [S1].
    *   Number of update steps: 800 for Gaussians, 100 for SH coefficients [S1].

6.  **Normalization and Decomposition:**
    *   **Normalization:** Due to floating-point errors, clustering normalized covariance matrices may result in non-unit scaling vectors. Re-normalize each codebook vector after each update step by dividing it through the trace of the covariance metric [S1].
    *   **Decomposition:** After clustering, decompose each codebook entry (covariance matrix) into rotation and scale parameters using eigenvalue decomposition. This is required for quantization-aware training, as direct optimization of the matrix is not possible [S1]. The final codebook entry stores 4 scalars for the quaternion and 3 scalars for the scaling vector [S1].

7.  **Quantization-Aware Training (QAT):**
    Fine-tune the scene parameters at the reduced bit-rate using quantization-aware training to recover information lost during clustering. In the forward pass, simulate quantization by replacing parameters with their codebook entries. In the backward pass, ignore the quantization (straight-through estimator) [S1].
    *   Typical number of optimization steps: 5000 [S1].

def compute_sensitivity(optimization_state, training_images, num_images):
    """
    Computes sensitivity S(p) for each parameter p.
    optimization_state: dict containing current Gaussian parameters and SH coefficients.
    training_images: list of training image tensors.
    num_images: N, number of training images.
    Returns: sensitivity_map, a dict mapping parameter names to sensitivity values.
    """
    sensitivity_map = {}
    total_pixel_count = sum(img.shape[0] * img.shape[1] for img in training_images)
    
    # Compute gradients for each training image
    # Note: In practice, this requires a differentiable renderer.
    # We assume a function compute_gradients that returns dE/dp for each image.
    gradients = []
    for img in training_images:
        grad = compute_gradients(optimization_state, img)
        gradients.append(grad)
        
    # Aggregate sensitivities
    for param_name in optimization_state.keys():
        grad_sum = sum(g[param_name] for g in gradients)
        sensitivity_map[param_name] = grad_sum / total_pixel_count
        
    return sensitivity_map

        # Sample a random batch

        # Compute weighted distances

        # dists shape: (batch_size, k)

## Operating characteristics
*   **Compression Ratio:** Achieves up to 31× compression on real-world scenes with minimal visual degradation [S1].
*   **Rendering Performance:** Enables real-time rendering on lightweight GPUs, up to 4× higher framerates than the original 3D Gaussian Splatting via an optimized GPU compute pipeline [S1].
*   **Memory:** Reduces storage requirements significantly by replacing continuous parameters with integer indices into compact codebooks [S1].
*   **Strengths:** Preserves high-impact features by excluding them from clustering; efficient batched clustering strategy; compatible with hardware rasterization [S1].
*   **Limitations:** Requires a backward pass for sensitivity calculation, which can be computationally expensive during the initial phase; quantization-aware training adds overhead to the fine-tuning phase [S1].
*   **When to Use:** When storage bandwidth or memory is a bottleneck, and real-time rendering on low-power devices is required [S1].
*   **When Not to Use:** When maximum possible visual fidelity is required without any compression artifacts, or when the overhead of sensitivity calculation and QAT is prohibitive [S1].

## Background
Sensitivity-Aware Vector Clustering was proposed in the paper "Compressed 3D Gaussian Splatting for Accelerated Novel View Synthesis" [S1]. It builds on the observation that SH coefficients and Gaussian shape parameters in 3D Gaussian Splatting are highly redundant and take up the majority of storage space [S1]. The method is inspired by volumetric radiance field compression and deep network weight quantization [S1]. It was introduced to make 3D Gaussian representations suitable for applications like network streaming and rendering on low-power devices [S1].
