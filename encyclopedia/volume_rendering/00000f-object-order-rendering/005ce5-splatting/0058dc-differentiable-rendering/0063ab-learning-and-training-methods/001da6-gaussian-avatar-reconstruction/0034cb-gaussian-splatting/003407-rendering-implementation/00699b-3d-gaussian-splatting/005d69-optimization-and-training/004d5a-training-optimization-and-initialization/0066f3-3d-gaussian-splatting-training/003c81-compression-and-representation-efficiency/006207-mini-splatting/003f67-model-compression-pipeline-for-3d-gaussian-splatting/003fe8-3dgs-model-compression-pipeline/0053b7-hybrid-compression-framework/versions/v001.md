# Hybrid Compression Framework

Also called: Adaptive Voxelization and GPCC Compression for 3DGS

## Overview
The Hybrid Compression Framework is a post-training compression method for 3D Gaussian Splatting (3DGS) that reduces model size and bandwidth by combining adaptive voxelization with Generalized Prediction Context Coding (GPCC) [S1]. It addresses the impracticality of generative compression, which requires retraining distinct models for each bitrate, and the quality degradation of standard post-training methods due to parameter distortion [S1]. By quantizing mean positions to voxel centers and fine-tuning remaining attributes, it achieves higher quality at lower bitrates compared to sibling methods like Mini-Splatting-C [S1, 10131-mini-splatting-c.md].

## How it works
**Inputs:** Pre-trained 3DGS model $G = \{\mu_i, \Sigma_i, C_i, \alpha_i\}_{i=1}^N$, where $\mu_i \in \mathbb{R}^3$ are means, $\Sigma_i \in \mathbb{R}^{3\times3}$ are covariances, $C_i$ are spherical harmonic (SH) coefficients, and $\alpha_i \in [0,1]$ are opacities. Training images $\{\tilde{I}_i\}_{i=1}^k$ and camera views $\{\tilde{\theta}_i\}_{i=1}^k$.

**Outputs:** Compressed bitstream containing GPCC-coded positions, covariances, SH coefficients, and opacities.

**Data Structures:**
1.  **Voxelized Model $\tilde{G}$:** A set of $M$ Gaussians ($M < N$).
    *   $\hat{\mu}_i$: Quantized mean position (voxel center).
    *   $\tilde{\Sigma}_i$: Fine-tuned covariance.
    *   $\tilde{C}_i$: Fine-tuned SH coefficients.
    *   $\tilde{\alpha}_i$: Fine-tuned opacity.
2.  **GPCC Context:** Octree structure for position coding; transform coding context for attributes.

**Parameters:**
*   $Q_{dc}$: Quantization parameter for low-frequency SH coefficients (DC/base color). Set relatively small [S1].
*   $Q_{ac}$: Quantization parameter for high-frequency SH coefficients (AC). Set relatively large compared to $Q_{dc}$ [S1].
*   $Q_{op}$: Quantization parameter for opacity. Set relatively small compared to $Q_{ac}$ [S1].
*   $J$: Number of octree partitioning levels (resolution) [S1].

**Steps:**
1.  **Adaptive Voxelization:**
    *   Define the bounding box of the Gaussian volume.
    *   Partition the space into an octree. At each level, occupied voxels are subdivided up to level $J$ [S1].
    *   Quantize each Gaussian mean $\mu_i$ to the center of its containing voxel $\hat{\mu}_i$ [S1].
    *   Merge Gaussians falling into the same voxel. Let the unique voxel centers be $\{\hat{\mu}_i\}_{i=1}^M$ [S1].
2.  **Attribute Initialization:**
    *   For each unique voxel center $\hat{\mu}_i$, initialize the remaining attributes $\Sigma_i, C_i, \alpha_i$ by averaging the attributes of all original Gaussians mapped to that voxel [S1].
3.  **Fine-Tuning:**
    *   Keep the quantized mean positions $\{\hat{\mu}_i\}_{i=1}^M$ fixed.
    *   Optimize the remaining attributes $\{\tilde{\Sigma}_i, \tilde{C}_i, \tilde{\alpha}_i\}_{i=1}^M$ by minimizing the training loss $L_{train}$ until the rendering quality matches the input model $G$ [S1].
    *   The training loss is defined as:
        $$ L_{train} = \frac{1}{k} \sum_{i=1}^k \frac{1}{2} \| R_{\tilde{\theta}_i}(\tilde{G}) - \tilde{I}_i \|_F $$
        where $R_{\theta}$ is the rendering function for view $\theta$, and $\| \cdot \|_F$ is the Frobenius norm [S1].
4.  **Compression:**
    *   **Positions:** Losslessly compress the voxelized positions $\{\hat{\mu}_i\}_{i=1}^M$ using GPCC (octree coding + entropy coder) [S1].
    *   **Covariances:** Compress $\{\tilde{\Sigma}_i\}_{i=1}^M$ using vector quantization [S1].
    *   **SH and Opacity:** Compress $\{\tilde{C}_i, \tilde{\alpha}_i\}_{i=1}^M$ using transform coding with quantization parameters $Q_{dc}, Q_{ac}, Q_{op}$ via GPCC [S1].

**Pseudocode:**
```python
def hybrid_compression(3DGS_model, training_data, Q_dc, Q_ac, Q_op, octree_levels):
    # 1. Adaptive Voxelization
    # Determine bounding box and build octree up to octree_levels
    voxel_centers = {}
    for gaussian in 3DGS_model:
        voxel_id = get_voxel_id(gaussian.mean, octree_levels)
        if voxel_id not in voxel_centers:
            voxel_centers[voxel_id] = []
        voxel_centers[voxel_id].append(gaussian)

    voxelized_gaussians = []
    for voxel_id, gaussians_in_voxel in voxel_centers.items():
        # Quantize mean to voxel center
        mean = get_voxel_center(voxel_id)
        
        # Initialize attributes by averaging
        cov = average_covariances([g.cov for g in gaussians_in_voxel])
        sh_coeffs = average_sh([g.sh for g in gaussians_in_voxel])
        opacity = average_opacities([g.alpha for g in gaussians_in_voxel])
        
        voxelized_gaussians.append({
            'mean': mean,
            'cov': cov,
            'sh': sh_coeffs,
            'alpha': opacity
        })

    # 2. Fine-Tuning
    # Fix means, optimize other attributes
    for gaussian in voxelized_gaussians:
        gaussian.mean = gaussian.mean # Fixed
    
    # Minimize L_train using gradient descent on attributes
    # L_train = (1/k) * sum(0.5 * ||R_theta(G) - I||_F^2)
    voxelized_gaussians = fine_tune_attributes(voxelized_gaussians, training_data)

    # 3. Compression
    # Compress positions with GPCC
    pos_bitstream = gpcc_encode_positions([g['mean'] for g in voxelized_gaussians])
    
    # Compress covariances with vector quantization
    cov_bitstream = vector_quantize_covariances([g['cov'] for g in voxelized_gaussians])
    
    # Compress SH and opacity with GPCC transform coding
    sh_bitstream = gpcc_encode_transform([g['sh'] for g in voxelized_gaussians], Q_dc, Q_ac)
    alpha_bitstream = gpcc_encode_transform([g['alpha'] for g in voxelized_gaussians], Q_op)

    return pos_bitstream + cov_bitstream + sh_bitstream + alpha_bitstream
```

## Operating characteristics
*   **Time Complexity:** Requires a fine-tuning phase after voxelization, which incurs retraining costs proportional to the number of voxels and training iterations [S1].
*   **Memory/Bandwidth:** Significantly reduces model size compared to the original 3DGS by merging Gaussians and compressing attributes [S1].
*   **Quality:** Achieves higher quality at equivalent bitrates compared to standard post-training PCC methods by mitigating distortion through fine-tuning [S1].
*   **Strengths:** No need to retrain the entire model from scratch for different bitrates (unlike generative compression) [S1].
*   **Limitations:** The fine-tuning step adds computational overhead during compression [S1].

## Background
The method was proposed in "Adaptive Voxelization for Transform Coding of 3D Gaussian Splatting Data" (2025) [S1]. It builds on the observation that 3DGS data can be viewed as a 3D point cloud (3DPC) [S1]. Previous post-training methods relied on point cloud compression (PCC) but suffered from quality loss due to parameter distortion [S1]. Generative compression methods, while efficient, require retraining for each rate-distortion point, making them impractical for multi-rate applications [S1]. This framework combines adaptive voxelization with GPCC to balance compression efficiency and rendering quality [S1].
