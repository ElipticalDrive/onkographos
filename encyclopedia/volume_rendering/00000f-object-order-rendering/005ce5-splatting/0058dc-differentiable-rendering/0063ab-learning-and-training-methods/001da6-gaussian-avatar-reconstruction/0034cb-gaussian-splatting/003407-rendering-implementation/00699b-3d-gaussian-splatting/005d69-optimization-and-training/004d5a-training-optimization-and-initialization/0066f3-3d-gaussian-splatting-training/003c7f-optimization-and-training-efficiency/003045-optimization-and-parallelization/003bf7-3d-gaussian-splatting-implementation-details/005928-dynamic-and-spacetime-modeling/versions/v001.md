# Dynamic and Spacetime Modeling

Also called: Dynamic 3D Gaussian Splatting, Spacetime Gaussians, Deformable Gaussians

## Overview
Dynamic and Spacetime Modeling extends static 3D Gaussian Splatting to handle time-varying scenes, enabling real-time novel view synthesis for dynamic content . It solves the problem of temporal coherence and motion representation by introducing time-dependent attributes (position, rotation, opacity) or canonical-space deformation fields, distinguishing itself from static methods that assume scene rigidity .

## Shared principles
All methods in this family share the core 3D Gaussian Splatting rendering pipeline: differentiable rasterization of 3D Gaussians projected to 2D via affine approximation [16260-deformable-3d-gaussians.md, 16313-spacetime-gaussian-feature-splatting.md]. They optimize Gaussian attributes (position, rotation, scale, opacity, features) using gradient descent (typically Adam) to minimize rendering loss (L1 + D-SSIM) against ground-truth images [16260-deformable-3d-gaussians.md, 16313-spacetime-gaussian-feature-splatting.md]. Adaptive density control (densification, pruning, splitting) is applied during training to manage Gaussian count and detail [16260-deformable-3d-gaussians.md, 16313-spacetime-gaussian-feature-splatting.md]. Initialization typically relies on Structure-from-Motion (SfM) sparse point clouds [16260-deformable-3d-gaussians.md, 16313-spacetime-gaussian-feature-splatting.md].

## Subtopics

### [SpacetimeGaussians Training Pipeline](15898-spacetimegaussians-training-pipeline.md)
Explicitly models time-dependent Gaussians with motion parameters ($\omega$) and applies a structured densification/pruning schedule with motion regularization. Chose for explicit temporal attribute optimization with specific regularization terms.

### [Deformable 3D Gaussians](16260-deformable-3d-gaussians.md)
Uses a canonical space with a learned deformation network (MLP) to map static Gaussians to dynamic states. Chose for monocular dynamic scene reconstruction with decoupled radiance and deformation fields.

### [Spacetime Gaussian Feature Splatting](16313-spacetime-gaussian-feature-splatting.md)
Models 4D spacetime with polynomial motion/rotation and neural features, supporting emerging/vanishing content. Chose for high-fidelity dynamic scenes with explicit temporal opacity and feature splatting.

## Background
Originating from the success of 3D Gaussian Splatting [9128-3d-gaussian-splatting-implementation-details.md], dynamic variants emerged to handle video and dynamic scenes. Deformable 3D Gaussians [16260-deformable-3d-gaussians.md] and SpacetimeGaussians [15898-spacetimegaussians-training-pipeline.md] address real-time dynamic view synthesis. Spacetime Gaussian Feature Splatting [16313-spacetime-gaussian-feature-splatting.md] extends this to 4D spacetime modeling. These methods are used in dynamic scene reconstruction, novel view synthesis, and real-time rendering of moving content.
