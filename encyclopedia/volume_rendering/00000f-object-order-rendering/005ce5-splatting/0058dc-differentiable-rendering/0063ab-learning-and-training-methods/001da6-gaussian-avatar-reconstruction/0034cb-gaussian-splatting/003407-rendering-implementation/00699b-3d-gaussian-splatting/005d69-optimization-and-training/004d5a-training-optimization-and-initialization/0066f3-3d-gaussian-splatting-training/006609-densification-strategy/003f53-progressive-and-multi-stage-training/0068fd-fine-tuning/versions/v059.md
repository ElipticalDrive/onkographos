# Fine-tuning

Also called: 3DGS Fine-tuning, Fine-tuning Strategy, Gaussian Splatting Fine-tuning

## Overview
Fine-tuning in 3D Gaussian Splatting refers to the optimization phase where an initial set of Gaussian primitives is refined to minimize rendering error, often leveraging pretrained weights or feed-forward initialization to accelerate convergence and improve fidelity [S2]. It addresses the problem of initializing Gaussian representations by generating them via a direct feed-forward process or refining existing sets through iterative optimization [S2]. It sets itself apart from static initialization methods by dynamically adjusting the Gaussian population based on rendering loss and gradient metrics, and from pure feed-forward generation by allowing iterative parameter optimization [S2].

## How it works
The fine-tuning process typically begins with an initial set of 3D Gaussians $\mathcal{G}$, which is generated via a direct feed-forward process predicting geometry and color attributes [S2]. The core mechanism involves iterative optimization of geometry ($\mu, \Sigma$), opacity ($\alpha$), and color attributes (SH coefficients $\mathbf{c}$) using differentiable rasterization [S2].

### Inputs and Outputs
*   **Inputs:** Initial Gaussian set $\mathcal{G}_0$, camera poses $\{P_v\}$, input images $\{I_v\}$, and optionally pretrained model weights [S2].
*   **Outputs:** Optimized Gaussian set $\mathcal{G}_{final}$ with refined attributes [S2].

### Data Structures
The Gaussian set is stored as a contiguous array or list of objects, where each object $g_k$ contains:
*   $\mu_k \in \mathbb{R}^3$: Mean position.
*   $s_k \in \mathbb{R}^3$: Scale (vector).
*   $q_k \in \mathbb{R}^4$: Rotation (quaternion).
*   $\alpha_k \in \mathbb{R}$: Opacity.
*   $\mathbf{c}_k$: Spherical Harmonic coefficients.

### Steps
1.  **Initialization:** Generate initial Gaussians via a direct feed-forward process predicting geometry and color attributes [S2].
2.  **Optimization Loop:** For each iteration $t$:
    a. **Rendering:** Render images from all training views using the current Gaussian set [S2].
    b. **Loss Computation:** Compute loss $\mathcal{L}$ between rendered images and ground truth [S2][S3]. Common losses include L1 color loss, SSIM, and depth loss [S3].
    c. **Backpropagation:** Update Gaussian parameters using an optimizer (e.g., Adam) [S2].
    d. **Densification/Pruning:** Periodically (e.g., every $N$ iterations) evaluate metrics to modify $\mathcal{G}$ [Parent]:
        i. **Gradient-based Densification:** Calculate accumulated 2D positional gradients $\tau_k$ [Parent]. Split or clone Gaussians with high gradients [Parent].
        ii. **Opacity Pruning:** Remove Gaussians with $\alpha_k < \alpha_{\min}$ [Parent].
        iii. **Scale-based Pruning:** Remove excessively large Gaussians [Parent].
        iv. **Rendering-Loss Densification:** Identify regions with high rendering error or low opacity (holes) and add new Gaussians [S3].
3.  **Buffer Management:** Compact the Gaussian list to maintain contiguous memory access after pruning or splitting [Parent].

### Formulas
*   **Opacity Rendering:** The accumulated opacity $O$ at a pixel is computed as:
    $$ O = \sum_{i \in N} \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $N$ are the 2D Gaussians overlapping the pixel, and $\alpha_i$ is the alpha value of the $i$-th Gaussian [S3][S4, unofficial].
*   **Color Rendering:** The accumulated color $\mathbf{C}$ is:
    $$ \mathbf{C} = \sum_{i \in N} \mathbf{c}_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $\mathbf{c}_i$ is the color of the $i$-th Gaussian [S4, unofficial].
*   **Rendering-Loss Densification Thresholds:** New Gaussians are added if:
    $$ O(x, y) < \tau_{opa} \quad \text{or} \quad E_{color}(x, y) > \tau_{color} \quad \text{or} \quad \frac{E_{depth}(x, y)}{D(x, y)} > \tau_{depth} $$
    where $E_{color}$ and $E_{depth}$ are color and depth errors, $D(x,y)$ is rendered depth, and $\tau$ are thresholds [S3].

### Parameters
*   **Learning Rate:** Typically $1 \times 10^{-3}$ for Adam optimizer [S2].
*   **Densification Interval:** Every 100 iterations (common in vanilla 3DGS) [Parent].
*   **Naive Fine-tuning Iterations:** 10,000 steps (in specific generator fine-tuning contexts) [S5].
*   **Transfer Functions:** 5 transfer functions selected per volume in image-space fine-tuning [S4, unofficial].

### Edge Cases and Pitfalls
*   **Forgetting:** In continuous mapping, Gaussians may overfit to the latest frame, degrading quality for previous frames [S3]. Regularization terms (e.g., SSIM) are used to mitigate this [S3].
*   **Sparse Initialization:** SfM points may have holes in sky or distant areas, requiring densification beyond initial points [S4, unofficial].
*   **Overfitting:** Naive fine-tuning of all generator weights can lead to overfitting if not regularized [S5].

### Pseudocode
```python
def fine_tune_gaussians(initial_gaussians, training_data, num_iterations, densify_interval, 
                        lr=1e-3, alpha_min=0.01, gradient_threshold=0.0002, 
                        tau_opa=0.1, tau_color=0.05, tau_depth=0.1):
    """
    Fine-tune 3D Gaussian Splatting representation.
    
    Args:
        initial_gaussians: List of Gaussian primitives with initial attributes.
        training_data: List of (camera_pose, image, depth) tuples.
        num_iterations: Total number of optimization steps.
        densify_interval: Interval for densification/pruning.
        lr: Learning rate for optimizer.
        alpha_min: Opacity threshold for pruning.
        gradient_threshold: Gradient magnitude threshold for splitting.
        tau_opa, tau_color, tau_depth: Thresholds for rendering-loss densification.
        
    Returns:
        optimized_gaussians: Final list of Gaussian primitives.
    """
    gaussians = list(initial_gaussians)
    
    for t in range(num_iterations):
        # 1. Sample a batch of training views
        batch = training_data[t % len(training_data)]
        pose, gt_image, gt_depth = batch
        
        # 2. Render images from current Gaussians
        rendered_img, rendered_depth = render_gaussians(gaussians, pose)
        
        # 3. Compute Loss
        loss = l1_loss(rendered_img, gt_image) + ssim_loss(rendered_img, gt_image) + l1_loss(rendered_depth, gt_depth)
        
        # 4. Backpropagate & Update (simplified Adam step) [G]
        for g in gaussians:
            grad = compute_gradients(loss, g)
            g.params -= lr * grad
            
        # 5. Periodic Densification and Pruning
        if t % densify_interval == 0:
            gaussians = densify_and_prune(gaussians, batch, alpha_min, gradient_threshold, tau_opa, tau_color, tau_depth)
            
    return gaussians

def render_gaussians(gaussians, pose):
    # Standard differentiable rasterization [G]
    return rasterize(gaussians, pose), compute_depth(gaussians, pose)

def densify_and_prune(gaussians, batch, alpha_min, gradient_threshold, tau_opa, tau_color, tau_depth):
    """
    Adaptively modify Gaussian population based on gradients and rendering error.
    """
    new_gaussians = []
    
    for g in gaussians:
        # Opacity pruning
        if g.opacity < alpha_min:
            continue
            
        # Gradient-based splitting
        if g.gradient_magnitude > gradient_threshold:
            children = split_gaussian(g)
            new_gaussians.extend(children)
        else:
            new_gaussians.append(g)
            
    # Rendering-loss densification (hole filling)
    holes = find_holes(gaussians, batch, tau_opa, tau_color, tau_depth)
    for h in holes:
        new_g = create_gaussian(h)
        new_gaussians.append(new_g)
        
    return new_gaussians

# Helper definitions
def l1_loss(a, b):
    return sum(abs(a[i] - b[i]) for i in range(len(a))) / len(a)

def ssim_loss(a, b):
    # Structural similarity index computation [G]
    return 1.0 - structural_similarity(a, b)

def compute_gradients(loss, g):
    # Backpropagation through differentiable rasterizer [G]
    return loss.gradient(g.params)

def split_gaussian(g):
    # Clone with noise and reduced scale per Parent
    children = []
    for _ in range(2):
        child = Gaussian(g.params + random_noise(scale=0.01))
        child.scale *= 5.0 / 4.0 / (2 ** 0.5)
        children.append(child)
    return children

def find_holes(gaussians, batch, tau_opa, tau_color, tau_depth):
    holes = []
    pose, gt_image, gt_depth = batch
    rendered_img, rendered_depth = render_gaussians(gaussians, pose)
    for x, y in pixel_grid():
        if rendered_img[y, x] < tau_opa or l1_loss(rendered_img[y, x], gt_image[y, x]) > tau_color or l1_loss(rendered_depth[y, x], gt_depth[y, x]) / gt_depth[y, x] > tau_depth:
            holes.append((x, y, pose))
    return holes

def create_gaussian(hole):
    return Gaussian(mean=project_to_3d(hole), scale=0.01, opacity=0.5)
```

## Subtopics

### [Exponentially Ascending Gradient Threshold](9684-exponentially-ascending-gradient-threshold.md)
A densification control mechanism that uses an exponentially ascending gradient threshold to regulate splitting and cloning during training. It allows aggressive densification when few Gaussians exist and restricts it as the scene becomes dense, solving the trade-off between early-stage convergence speed and late-stage overfitting.

### [SplatFormer Training Objective & Refinement](11745-splatformer-training-objective-refinement.md)
A learning-based, feed-forward 3D neural module that refines initial 3DGS representations to enable robust novel view synthesis from out-of-distribution (OOD) camera angles. It applies a point transformer network to predict attribute residuals, addressing the bias of standard 3DGS optimization which overfits to input views.

### [MCMC-based 3DGS / SGLD for 3DGS](11917-mcmc-based-3dgs-sgld-for-3dgs.md)
Reforms 3DGS by treating Gaussians as MCMC samples from an underlying probability distribution. It converts updates into Stochastic Gradient Langevin Dynamics (SGLD) by introducing noise, removing the need for manual densification heuristics like cloning and splitting.

### [Deblurring 3D Gaussian Splatting](12318-deblurring-3d-gaussian-splatting.md)
A real-time deblurring framework that reconstructs sharp 3D scenes from blurry inputs by manipulating covariance matrices and means using a small MLP during training. It uses differentiable rasterization for real-time inference (>800 FPS) and handles defocus and camera motion blur.

### [Supplementary Point Addition for Sparse Point Clouds](12323-supplementary-point-addition-for-sparse-point-clouds.md)
A densification technique that injects synthetic points into empty or sparse regions after a fixed number of training iterations, compensating for poor SfM extraction in far-end scenes. It prevents distant objects from being ignored during adaptive density control.

### [Augmented Radiance Field](13218-augmented-radiance-field.md)
A post-enhancement framework that adds Gaussian kernels with view-dependent opacity to explicitly model specular components. It solves the problem of standard SH failing to decouple diffuse and specular radiance, avoiding memory and stability issues of high-order SH.

### [Frequency Regularization for Densification](13484-frequency-regularization-for-densification.md)
Addresses over-reconstruction by minimizing the discrepancy between the frequency spectrum of the rendered image and the ground truth in Fourier space. It increases pixel gradients in over-reconstruction regions, enabling coarse-to-fine densification guided by progressive frequency annealing.

### [Error-Guided Redistribution](14037-error-guided-redistribution.md)
A family of strategies that dynamically adjusts the spatial distribution of Gaussians based on rendering errors or gradient magnitudes. It targets regions with persistent coarse-scale errors or "hard" gradients, either by reallocating a fixed budget or growing defective primitives.

### CoherentGS
A regularized optimization method for sparse novel view synthesis that introduces structural coherency by constraining Gaussian movement in 2D image space [G]. It solves instability and "needle-like" artifacts in sparse-view training by enforcing single-view and multi-view consistency [G].

### [Pruning and Sparsity Control](14431-pruning-and-sparsity-control.md)
Methods that reduce the number of active Gaussians to lower memory and storage while maintaining quality. They actively eliminate redundant primitives throughout optimization using explicit geometric or volume-based criteria, distinguishing them from methods relying solely on gradient magnitude [G].

### [Rendering-Free Pruning via Hessian Importance](14447-rendering-free-pruning-via-hessian-importance.md)
A post-processing framework that identifies and removes unimportant Gaussians without forward rendering passes. It uses an analytically approximated Hessian field to estimate quality degradation, achieving a 3,000× reduction in computational complexity and ~20× speedup in device latency.

### [GoF-based Dynamic 3DGS Video Construction](14770-gof-based-dynamic-3dgs-video-construction.md)
Constructs dynamic 3DGS video by temporally segmenting input sequences into Groups of Frames (GoFs) and independently training Gaussian deformation fields within each segment. It solves motion drift and geometric inconsistencies in long-range temporal dependencies by limiting motion degree within short segments.

### [TIP-Editor](14859-tip-editor.md)
A method for editing existing 3DGS scenes using text and image prompts. It employs a stepwise 2D personalization strategy with LoRA-based reference image alignment and localization loss, maintaining multi-view consistency better than depth-conditioned ControlNet methods.

### StylizedGS
A controllable 3D stylization method that performs color matching with a reference style image while using a 3DGS filter to remove artifacts [S5]. It explicitly optimizes for nearest neighbor feature matching and depth preservation, retaining geometric structure while adopting artistic appearance [S5].

### [SGD (Street View Synthesis with Gaussian Splatting and Diffusion Prior)](15522-sgd-street-view-synthesis-with-gaussian-splatting-and-diffus.md)
Enhances 3DGS for street scenes by fine-tuning a Stable Diffusion model on driving data and using it to regularize 3DGS training at unseen viewpoints. It addresses sparse-view reconstruction by using adjacent frames and LiDAR depth for direct fine-tuning, overcoming domain gaps.

### [Backbone Fine-tuning](16908-backbone-fine-tuning.md)
Adapts the weights of a pre-trained 3D generator (backbone) alongside the decoder to generate Gaussian Splatting attributes. It modifies the generative prior itself rather than just the optimization trajectory, and may update geometry if not explicitly frozen.

### [Equivalent Distribution Reorganization](16968-equivalent-distribution-reorganization.md)
A post-training reorganization method that addresses "parameterization degeneration" by rebuilding centers, covariances, and visibility structure through resampling from the empirical distribution. It reduces parameter coupling and opacity barriers, delivering up to 0.5 dB higher PSNR and 12.8% rendering speedup.

### [S2Gaussian](17154-s2gaussian.md)
A two-stage framework for reconstructing high-quality scenes from sparse and low-resolution inputs. It initializes high-resolution Gaussians from a densified low-resolution representation and refines them using super-resolved supervision, introducing a "Gaussian Shuffle Split" densification strategy.

### [FreeFix](17532-freefix.md)
A fine-tuning-free method to improve rendering quality of extrapolated views by leveraging pretrained 2D image diffusion models. It uses a 2D–3D interleaved refinement strategy with per-pixel confidence masks derived from Fisher information, avoiding artifacts from naive 2D IDMs.

### [Localized Point Management (LPM)](17850-localized-point-management-lpm.md)
Identifies error-contributing 3D zones via cross-view feature mapping and performs localized point addition, opacity reset, and pruning. It uses image rendering errors and multiview geometry constraints to target specific regions, improving quality without substantial training overhead.

### ParetoGS
A continuous-budget 3DGS representation that decodes any Gaussian count $K$ from a single asset without separate optimization per budget [G]. It constructs sparse, adapted budget anchors with persistent member identities, encoding parameter changes in a residual atlas [G].

### [Multi-stage and Progressive Training](18485-multi-stage-and-progressive-training.md)
Strategies that decouple the optimization of 3DGS parameters or data streams to improve stability, convergence, or real-time capability. It separates concerns into distinct phases or temporal streams, targeting parameter decoupling (Two-stage) or incremental field updates (On-the-Fly).

### Gaussian Densification via Rendering Loss
A strategy to add new 3D Gaussians by identifying unobserved regions (holes) and regions with high rendering error, using opacity, color, and depth thresholds [S3]. It densifies regions where opacity is below $\tau_{opa}$, color error exceeds $\tau_{color}$, or normalized depth error exceeds $\tau_{depth}$ [S3].

### Point Densification
A process in original 3DGS that adaptively controls the number of Gaussian points through clone and split operations to convert a sparse set into a denser one [S4, unofficial]. In HO-Gaussian, this is performed at regular intervals to populate problematic regions [S4, unofficial].

### Naive Fine-tuning
A generator fine-tuning method identical to model rewriting except freely optimizing all weights of the generator [S5]. It is typically optimized over 10,000 steps with a learning rate of $10^{-3}$ [S5].

### Image-space Gaussian Fine-tuning
A process to account for different visual modes in the volume by generating multiple radiance fields using different transfer functions and optimizing the Gaussian set against rendered images [S4, unofficial]. It selects 5 transfer functions per volume, renders 64 images per field for supervision, and backpropagates to update the Gaussian set [S4, unofficial].

### Ada-GS
A baseline method that trains vanilla 3D Gaussian Splatting directly on 2D stylized images [S5]. It preserves better details than GS-Ada but requires training from scratch for every new style image, limiting practical usability compared to GSS [S5].

## Operating characteristics
*   **Time Complexity:** Depends on the number of Gaussians $N$ and views $V$. Rendering is $O(N)$ per pixel, optimization is $O(N \cdot V)$ per iteration [G]. Densification adds overhead but reduces total iterations needed for convergence [Parent].
*   **Memory Complexity:** $O(N)$ for storing Gaussian attributes [G]. Fine-tuning with densification can increase $N$ significantly, requiring more memory [Parent].
*   **Performance:** Fine-tuning with pretrained weights accelerates convergence and improves photorealism [S2].
*   **Strengths:** Improves fidelity and adapts to scene complexity via feed-forward initialization or iterative refinement [S2][S4, unofficial].
*   **Limitations:** Can suffer from forgetting in continuous mapping [S3], overfitting if not regularized [S5], and high memory usage with large $N$ [Parent].
*   **When to Use:** When high fidelity is required, when adapting to specific visual modes, or when refining feed-forward initialized Gaussians [S2][S4, unofficial].
*   **When Not to Use:** When real-time performance is critical and $N$ is already large, or when input data is already dense and high-quality [S4, unofficial].

## Background
Fine-tuning in the context of 3D Gaussian Splatting builds on the original 3DGS method which introduced adaptive density control [Parent]. The concept of fine-tuning pretrained models for specific tasks is well-established in deep learning, where lower layers are fixed and higher layers are adapted [S1]. In 3DGS, fine-tuning strategies have been developed to address specific challenges such as sparse views [S2], blurry inputs [S1], and dynamic scenes [S1].
