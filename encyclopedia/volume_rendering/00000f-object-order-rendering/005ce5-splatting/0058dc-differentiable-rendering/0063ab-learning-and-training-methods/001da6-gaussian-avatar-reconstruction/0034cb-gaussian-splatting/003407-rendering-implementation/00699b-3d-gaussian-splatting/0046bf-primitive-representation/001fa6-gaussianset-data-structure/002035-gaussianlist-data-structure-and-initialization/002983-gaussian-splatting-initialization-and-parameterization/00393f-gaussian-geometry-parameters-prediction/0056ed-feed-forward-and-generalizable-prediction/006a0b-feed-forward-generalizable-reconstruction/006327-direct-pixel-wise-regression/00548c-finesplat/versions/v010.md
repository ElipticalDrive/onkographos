# FineSplat

Also called: Detailed Splats, Fine Patches, Local Groups

## Overview
FineSplat is a feed-forward 3D Gaussian Splatting (3DGS) framework that predicts a set of 3D Gaussians from $N$ context views (with or without known poses) using a two-stage dual-grouping strategy [S1, unofficial]. It balances local detail preservation with global multi-view reasoning by employing high-resolution 4x4 patch tokens and a dual-grouping mechanism: view-wise token grouping in Stage 1 and 3D spatial grouping in Stage 2 [S1, unofficial]. This approach preserves fine-grained visual information while avoiding the prohibitive computational costs of global multi-view attention [S1, unofficial].

## How it works
**Inputs:** $N$ context views (images $I \in \mathbb{R}^{N \times H \times W \times 3}$) with or without known camera poses.
**Outputs:** A set of 3D Gaussian primitives defined by mean, covariance, opacity, and spherical harmonics coefficients.

**Data Structures:**
*   **Tokens:** $z \in \mathbb{R}^{M \times d}$, where $M = N \cdot (H/p) \cdot (W/p)$ is the number of fine-grained tokens, $p$ is the patch size (4), and $d$ is the token dimension.
*   **Gaussians:** Predicted per token. Each token predicts $K$ Gaussians (typically $K=4$).
*   **Error Feature Maps:** $F_n^{err} \in \mathbb{R}^{(H/p) \times (W/p) \times d_e}$ for each view $n$.

**Parameters:**
*   $p$: Patch size, 4x4 pixels [S1, unofficial].
*   $T$: Number of iterative refinement steps in Stage 2, default 4 [S1, unofficial].
*   $K$: Number of Gaussians per token [S1, unofficial].
*   $S$: Size of groups for serialized attention in 3D spatial grouping [S1, unofficial].
*   $s$: Sub-patch stride, equal to 2 for 4x4 tokens divided into 2x2 sub-patches [S1, unofficial].
*   $N$: Number of input context views. Training samples $N \in \{6, 12, 24, 32\}$ [S1, unofficial].

**Algorithm:**

1.  **Scene Normalization:** To handle scale ambiguity in feed-forward reconstruction, normalize the scene scale using context camera poses. Express poses in the mean context camera frame and rescale translations so that all context camera centers lie within $[-1, 1]^3$ [S1, unofficial]. Apply the same transform to target poses.

2.  **Stage 1: View-Wise Token Grouping:**
    *   **Feature Extraction:** Extract feature maps $F^l$ for levels $l \in \{1, 2, 3\}$ (finest to coarsest) from the input images.
    *   **Token Initialization:** Fuse features into $M$ fine-grained tokens $z^{(0)}$ using Equation (1) [S1, unofficial]:
        $$ z^{(0)} = \text{fuse}\left(\text{up}\left(\text{fuse}\left(\text{up}(F^3) + F^2\right)\right)\right) + F^1 $$
        where $\text{up}(\cdot)$ is bilinear upsampling and $\text{fuse}(\cdot)$ is a convolutional fusion block.
    *   **Encoding:** Encode tokens using view-wise token grouping based on the Multi-View Pyramid (MVP) architecture. This performs fine-grained attention within small view groups and exchanges information across all views via coarser global tokens [S1, unofficial].

3.  **Stage 2: 3D Spatial Token Grouping (Iterative Refinement for $t = 1$ to $T$):**
    *   **Gaussian Prediction:** Decode tokens $z^{(t-1)}$ into an initial set of Gaussians using a lightweight Gaussian head $\mathcal{D}$ (linear decoder). Each token predicts $K$ Gaussian primitives [S1, unofficial].
    *   **Patch-Aligned Sub-Pixel Gaussian Reconstruction:** For each 4x4 token, predict 4 Gaussians, assigning each to a non-overlapping 2x2 sub-patch [S1, unofficial].
        *   Learn a 2D image-space offset $\Delta = (\Delta_x, \Delta_y)$.
        *   Bound the offset to keep Gaussians within their sub-patch:
            $$ \delta_x = 2s \tanh(\Delta_x), \quad \delta_y = 2s \tanh(\Delta_y) $$
            where $s=2$ is the sub-patch stride, ensuring $\delta_x, \delta_y \in [-s/2, s/2]$ [S1, unofficial].
        *   For a sub-patch with center $(u_c, v_c)$, compute displaced coordinate $(u, v) = (u_c, v_c) + \delta$.
        *   Unproject $(u, v)$ using predicted camera intrinsics to get a ray direction. Transform and normalize the direction using camera-to-world rotation, using camera translation as the ray origin [S1, unofficial].
    *   **Rendering:** Render the predicted Gaussians into every context view $n$ to obtain rendered images $\hat{I}_n$.
    *   **Error Feature Computation:** For each view $n$, compute:
        *   Signed error map: $E_n = \hat{I}_n - I_n$ [S1, unofficial].
        *   Feature-level difference: $\Delta\phi_n = \phi(\hat{I}_n) - \phi(I_n)$, where $\phi(\cdot)$ is a pretrained ResNet-18 encoder [S1, unofficial].
        *   Combine with finest-scale features $F_n^1$ from Stage 1 via linear embeddings $E_{err}$ and $E_{feat}$:
            $$ F_n^{err} = [E_{err}(E_n, \Delta\phi_n); E_{feat}(F_n^1)] \in \mathbb{R}^{(H/p) \times (W/p) \times d_e} $$
            where $[\cdot; \cdot]$ represents feature concatenation [S1, unofficial].
    *   **Error Aggregation:** For each token, gather two error signals:
        *   Self error feature $e_{self}$ from the patch where the token is predicted.
        *   Aggregated error feature $e_{agg}$ averaged over all context views where the token is visible (projected onto error feature maps and filtered by frustum/occlusion) [S1, unofficial].
    *   **3D Spatial Grouping:** Lift tokens to 3D space using predicted Gaussian centers. Regroup tokens according to spatial proximity in 3D world coordinates.
        *   Use serialized attention (Wu et al., 2024) to exchange information among nearby points. Order points along a space-filling curve, partition into groups of $S$ consecutive points, and apply self-attention within each group [S1, unofficial].
        *   Use four attention blocks, each using a different space-filling curve, so each token meets a different set of neighbors [S1, unofficial].
        *   Compute token residual: $\Delta z_j^{(t)} = \text{Linear}(\text{SerialAttn}(h_j^{(t)}))$.
        *   Update tokens: $z_j^{(t)} = z_j^{(t-1)} + \Delta z_j^{(t)}$ [S1, unofficial].
    *   **Repeat:** Go to Gaussian Prediction with updated tokens $z^{(t)}$.

**Pitfalls:**
*   **Blind Spots:** Fixed view grouping in Stage 1 leaves blind spots where fine-grained tokens in different groups cannot interact. Stage 2 3D spatial grouping connects tokens across view groups once lifted to 3D [S1, unofficial].
*   **Scale Ambiguity:** Feed-forward reconstruction is scale-ambiguous. Must normalize scene scale using context camera poses as described in Step 1 [S1, unofficial].
*   **Iteration Count:** Quality improves gradually with more Stage 2 steps, but going beyond $T=4$ yields no further gain [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** FineSplat is faster than explicit k-nearest-neighbor search for 3D grouping and scales favorably with token count due to serialized attention [S1, unofficial]. It is faster than YoNoSplat and ZipSplat with 6 and 12 input views, and still faster than ZipSplat with 24 views [S1, unofficial].
*   **Memory Complexity:** Uses a small primitive budget. On DL3DV with 6 views, it uses 62K Gaussians [S1, unofficial].
*   **Performance:**
    *   DL3DV (6 views): 27.325 PSNR, 0.871 SSIM, 0.115 LPIPS [S1, unofficial].
    *   RE10K (6 views): 27.394 PSNR, 0.886 SSIM, 0.116 LPIPS [S1, unofficial].
    *   Mip-NeRF 360 (128 views): 23.463 PSNR, 0.706 SSIM, 0.214 LPIPS [S1, unofficial].
*   **Strengths:** High quality with fine-grained details, efficient compared to global attention methods, robust to varying numbers of input views.
*   **Limitations:** Performance may degrade if a single pass must reconstruct a very large scene with many views, though Stage 2 compensates for this [S1, unofficial].

## Background
FineSplat was introduced by [S1, unofficial] in 2026. It is trained on the DL3DV dataset and evaluated on DL3DV, RealEstate10K (RE10K), and Mip-NeRF 360 for novel view synthesis [S1, unofficial]. It builds on [Feed-forward and Generalizable Prediction](15832-feed-forward-and-generalizable-prediction.md).
