# Dynamic Neural Radiance Fields

Also called: Dynamic NeRF, Dynamic Neural Radiance Fields for Monocular 4D Facial Avatar Reconstruction

## Overview
Dynamic Neural Radiance Fields (Dynamic NeRF) is a method for learning and rendering controllable 4D facial avatars from a single fixed camera view, such as a webcam [S1]. It extends the standard NeRF architecture by conditioning the radiance field on temporal dynamics, specifically per-frame facial expression coefficients and learned latent codes, allowing for the reconstruction of arbitrary geometry and topology (e.g., hair, eyewear, hats) that static methods or morphable models often fail to capture [S1]. Unlike multi-view volumetric approaches, it operates on monocular input, making it suitable for rapid, home-based avatar capture [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Viewing direction $\mathbf{d}$, 3D sample position $\mathbf{x} = (x, y, z)$, expression coefficients $\delta$, and a learned latent code $\gamma$.
*   **Outputs:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$.

**Data Structures and Layout:**
The method uses a Multi-Layer Perceptron (MLP) with a specific backbone and branch structure [S1]:
1.  **Positional Encoding:** The viewing direction $\mathbf{d}$ and position $\mathbf{x}$ are encoded using the standard positional encoding function $\gamma(\cdot)$ [S1].
2.  **Backbone Network:**
    *   **Input:** Concatenated vector $I = [\text{encoded } \mathbf{x}, \delta, \gamma]$.
    *   **Architecture:** 8 linear layers.
    *   **Width:** 256 neurons per layer.
    *   **Activation:** ReLU.
    *   **Output:** A feature vector used for density and color prediction.
3.  **Density Head:**
    *   A single linear layer applied to the backbone output to produce scalar density $\sigma$.
4.  **Color Branch:**
    *   **Input:** Concatenation of the backbone output and the encoded viewing direction $\gamma(\mathbf{d})$.
    *   **Architecture:** 4 linear layers.
    *   **Width:** 128 neurons per layer.
    *   **Activation:** ReLU.
    *   **Output:** View-dependent color $\mathbf{c}$.

**Algorithm:**
1.  **Training Data Preparation:** Collect a video sequence of a subject from a fixed camera. Extract per-frame facial expression coefficients $\delta_t$ for each frame $t$.
2.  **Latent Code Initialization:** Initialize a set of learned latent codes $\gamma$. During training, associate each frame with a specific latent code.
3.  **Sampling:** For each training image, sample points along rays passing through the scene.
4.  **Network Forward Pass:**
    *   Encode $\mathbf{x}$ and $\mathbf{d}$ using $\gamma(\cdot)$.
    *   Concatenate encoded $\mathbf{x}$, expression coefficients $\delta_t$, and latent code $\gamma_t$ to form input $I$.
    *   Pass $I$ through the 8-layer backbone (256 units, ReLU).
    *   Compute density $\sigma$ from the backbone output.
    *   Concatenate backbone output with encoded $\mathbf{d}$.
    *   Pass this concatenation through the 4-layer color branch (128 units, ReLU) to get $\mathbf{c}$.
5.  **Rendering:** Render the image using standard volumetric rendering with transmittance weights $T_i$ and opacity $\alpha_i$:
    $$
    \hat{C}(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i
    $$
6.  **Optimization:** Minimize the difference between rendered images $\hat{C}(r)$ and ground truth images using gradient descent.

**Parameters:**
*   **Backbone Layers:** 8 linear layers [S1].
*   **Backbone Width:** 256 neurons [S1].
*   **Color Branch Layers:** 4 linear layers [S1].
*   **Color Branch Width:** 128 neurons [S1].
*   **Activation:** ReLU [S1].

**Edge Cases and Pitfalls:**
*   **Test Time Latent Code:** At test time, always employ the latent code from the first frame of the training set [S1].
*   **Data Requirements:** The method requires a significantly larger training corpus than static NeRF (which needs ~100 posed images) to generalize over the space of expression vectors [S1]. Training on reduced data (first halves or quarters of sequences) leads to measurable degradation in quality [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Suitable for capturing avatars of end users at home using only 2 minutes of their time [S1].
*   **Scaling:** Performance benefits significantly from a larger training corpus; metrics degrade when trained on smaller subsets of expression variety [S1].
*   **Strengths:** Supports arbitrary geometry and topology (hair, eyewear, hats) unlike morphable models; requires only a single fixed camera view (e.g., webcam) unlike other volumetric approaches requiring multi-view rigs [S1].
*   **Limitations:** Requires more training data than static NeRF; quality is sensitive to the variety of expressions seen during training [S1].
*   **When to use:** When capturing 4D facial avatars from monocular video with limited setup time and hardware.
*   **When not to use:** When high-fidelity reconstruction of complex non-facial topology is required without sufficient training data, or when multi-view calibrated rigs are unavailable but high-quality volumetric reconstruction is needed without the dynamic constraints.

## Background
Dynamic Neural Radiance Fields were introduced in the paper "Dynamic Neural Radiance Fields for Monocular 4D Facial Avatar Reconstruction" [S1]. The method builds on the static NeRF architecture  by incorporating dynamics in the form of per-frame facial expression coefficients and learnable latent codes. It addresses the limitations of morphable model-based methods (which struggle with hair, eyewear, and hats) and multi-view volumetric approaches (which require expensive calibrated rigs) by enabling high-quality 4D reconstruction from a single webcam view [S1].
