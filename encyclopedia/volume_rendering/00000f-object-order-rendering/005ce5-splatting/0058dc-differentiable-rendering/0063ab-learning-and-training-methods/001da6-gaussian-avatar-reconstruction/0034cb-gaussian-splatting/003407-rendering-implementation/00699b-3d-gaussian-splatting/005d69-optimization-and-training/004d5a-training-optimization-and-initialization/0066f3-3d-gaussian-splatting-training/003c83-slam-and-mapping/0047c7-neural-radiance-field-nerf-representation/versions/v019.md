# Neural Radiance Field (NeRF) Representation

Also called: Instant Neural Graphics Primitives (INGP), Photon Field Networks, Photon Fields

## Overview
Neural Radiance Field (NeRF) representation is a method for encoding a 3D scene as a continuous volumetric function using a neural network, enabling high-quality novel view synthesis from sparse 2D images [S1][S2, unofficial]. It solves the problem of reconstructing complex lighting and geometry without explicit mesh extraction by mapping 3D coordinates and viewing directions to color and density [S1]. Unlike explicit representations like [Gaussian Splatting](12484-scene-nerf.md) which store millions of discrete blobs, NeRF stores the scene implicitly within a network, trading higher memory usage for compactness and smoother interpolation, though it typically requires significantly more training time and slower rendering speeds [S2, unofficial].

## How it works
The NeRF representation generally refers to the implicit neural field formulation introduced by Mildenhall et al., though the provided notes also detail specific variants like Photon Field Networks (INGP) and the explicit Gaussian Splatting representation often grouped under this family in SLAM contexts. The core NeRF mechanism involves training a Multi-Layer Perceptron (MLP) to predict volume density and view-dependent color.

### Inputs and Outputs
*   **Inputs:** 3D spatial coordinates $\mathbf{x} = (x, y, z)$ and a 2D view direction vector $\vec{\omega} = (\theta, \phi)$.
*   **Outputs:** Volume density $\sigma$ (scattering coefficient) and view-dependent color $\mathbf{c} = (R, G, B)$.

### Data Structures
*   **Neural Network:** A fully connected MLP. Standard configurations use 8 layers with 256 hidden units, using ReLU activations, with positional encoding applied to inputs [S1][S2, unofficial].
*   **Positional Encoding:** Inputs $\mathbf{x}$ and $\vec{\omega}$ are mapped to higher dimensions using sine and cosine functions at multiple frequencies to help the network learn high-frequency details [S1].
*   **Volumetric Rendering:** The scene is rendered by sampling points along a ray $\mathbf{r}(t) = \mathbf{o} + t\vec{\omega}$.

### Numbered Steps
1.  **Initialization:** Collect a set of images with known camera poses (e.g., from Structure from Motion like COLMAP) [S2, unofficial].
2.  **Sampling:** For each pixel in a training image, cast a ray from the camera origin through the pixel. Sample $N$ points along the ray within the scene bounds [S1].
3.  **Network Evaluation:** For each sample point $\mathbf{x}_i$ and view direction $\vec{\omega}$, pass the encoded inputs through the MLP to obtain density $\sigma_i$ and color $\mathbf{c}_i$ [S1].
4.  **Alpha Compositing:** Compute the final pixel color $C(\mathbf{r})$ by integrating along the ray using alpha compositing:
    $$ C(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i $$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity of the $i$-th segment, $\delta_i$ is the distance between samples, and $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance [S1].
5.  **Loss Computation:** Compare the rendered image with the ground truth image using a loss function, typically combining L1 loss and Structural Similarity (SSIM) [S2, unofficial].
6.  **Optimization:** Backpropagate the loss to update the MLP weights using gradient descent (e.g., Adam) [S2, unofficial].

### Formulas
*   **Radiance Estimation (Photon Fields variant):** For Photon Field Networks, the field approximates indirect radiance $L_i$:
    $$ P_{\phi}(x, g, \vec{\omega}) \approx L_i(x, \vec{\omega}) = \int_{\Omega_{4\pi}} p_g(x, \vec{\omega}, \vec{\omega}_i) L(x, \vec{\omega}_i) d\omega_i \quad (4) $$
    where $g$ is the phase function coefficient [S1].
*   **KNN Radiance Estimation:**
    $$ L_i(x, \vec{\omega}) \approx \sum_{n=1}^K p_g(x, \vec{\omega}, \vec{\omega}_n) \frac{\Phi_n}{4\pi r^3} \quad (5) $$
    where $r$ is the distance to the farthest photon, $\Phi_n$ is photon intensity, and $p_g$ is the Henyey-Greenstein phase function [S1].
*   **Target Encoding:**
    $$ L_i'(x, \vec{\omega}) = \begin{cases} -\frac{\log_{10}(L_i(x, \vec{\omega}))}{\psi} & \text{if } L_i(x, \vec{\omega}) > \frac{1}{10^{\psi}} \\ 1 & \text{otherwise} \end{cases} \quad (6) $$
    where $\psi$ is the precision parameter (typically 4-6) [S1].
*   **Inverse Transformation:**
    $$ L_i(x, \vec{\omega}) = 10^{-L_i'(x, \vec{\omega})} \cdot \Psi \quad (7) $$
    [S1].

### Parameters
*   **$\psi$:** Maximum desired floating point precision in digits beyond zero. Values of 4 to 6 are sufficient [S1].
*   **$G$:** Set of discrete phase coefficients for photon assignment. $G = \{-0.75, 0.0, 0.75\}$ is a common compromise [S1].
*   **$K$:** Number of neighbors in KNN query. $K=1024$ is used in Photon Fields [S1].
*   **Batch Size:** $2^{16}$ samples per batch for training [S1].

### Pseudocode
```python
# Core NeRF Rendering Step
def render_ray(ray_origin, ray_direction, network, num_samples):
    # Sample points along the ray
    t_vals = linspace(ray_near, ray_far, num_samples)
    points = ray_origin + outer_product(t_vals, ray_direction)
    
    # Encode inputs (positional encoding omitted for brevity)
    encoded_points = positional_encoding(points)
    encoded_dirs = positional_encoding(ray_direction)
    
    # Evaluate network
    densities, colors = network(encoded_points, encoded_dirs)
    
    # Compute alphas and transmittance
    deltas = diff(t_vals)
    alphas = 1.0 - exp(-densities * deltas)
    transmittance = exp(-cumsum(densities * deltas))
    
    # Composite color
    weights = alphas * transmittance
    final_color = sum(weights * colors)
    
    return final_color

# Photon Field Training Step (Variant)
def train_photon_field(photon_map, network, batch_size=2**16, psi=4):
    kd_tree = build_kd_tree(photon_map)
    for step in range(num_steps):
        # Generate random samples
        x = random_uniform_grid(batch_size)
        omega = random_uniform_directions(batch_size)
        g = random_choice([-0.75, 0.0, 0.75], batch_size)
        
        # Estimate ground truth radiance using KNN
        L_i = estimate_radiance_knn(kd_tree, x, omega, g, K=1024)
        
        # Encode target
        L_i_prime = encode_target(L_i, psi)
        
        # Forward pass
        L_i_pred = network(x, omega, g)
        
        # Compute loss and update
        loss = mse(L_i_pred, L_i_prime)
        network.backward(loss)
        network.update()
```

### Edge Cases and Pitfalls
*   **Precision:** Radiance values can vary widely; logarithmic encoding is necessary to normalize targets to $[0,1]$ for stable training [S1].
*   **Boundaries:** Ray sampling must be bounded to avoid infinite integration; near and far clipping planes are required [S1].
*   **Degenerate Input:** If camera poses are inaccurate, the network may learn inconsistent geometry, leading to artifacts [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Training is slow, often taking hours to days, as the network must converge to represent the entire scene [S2, unofficial]. Rendering is slow (seconds per image) because it requires evaluating the network at many points along each ray [S2, unofficial].
*   **Memory Complexity:** The network weights are compact (few megabytes), but training requires storing large datasets of images and poses [S2, unofficial].
*   **Performance:** On standard hardware, NeRF achieves high visual quality but low frame rates. Gaussian Splatting variants offer >100 FPS but use hundreds of megabytes of memory [S2, unofficial].
*   **Strengths:** High-quality novel view synthesis, handles complex lighting and reflections implicitly, no explicit mesh required.
*   **Limitations:** Slow training and rendering, prone to floating artifacts and aliasing in sparse regions, difficult to extract clean meshes [S2, unofficial].
*   **When to Use:** When visual quality is paramount and real-time performance is not required, or for offline content creation.
*   **When Not to Use:** For real-time applications requiring high frame rates, or when explicit geometry extraction is needed [S2, unofficial].

## Background
NeRF was introduced by Mildenhall et al. in 2020, revolutionizing novel view synthesis by using neural networks to represent 3D scenes implicitly [S1][S2, unofficial]. The concept of Photon Field Networks (INGP) was later introduced to accelerate global illumination computation by replacing expensive photon tracing with neural inference [S1]. Gaussian Splatting, introduced by Kerbl et al. at SIGGRAPH 2023, offers an explicit alternative that trades memory for speed [S2, unofficial]. These methods are widely used in virtual reality, film, robotics, and cultural heritage preservation [S2, unofficial].
