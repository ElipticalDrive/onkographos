# Appearance Embedding
Also called: Image-specific Embedding, NeRF in the Wild, WildConvexes, WildGaussians
## Overview
Appearance Embedding is a technique that associates each training image with a unique embedding vector to model appearance changes such as lighting variations, shadows, and camera exposure differences [S1, unofficial][S2]. It sets itself apart from sibling methods by optimizing per-image lighting condition embeddings jointly with scene parameters and incorporating them as an extra input during color computation, rather than relying solely on fixed scene representations [S3, unofficial].
## How it works
**Inputs:** Training image set, camera poses, initial scene parameters (e.g., Gaussian attributes or neural field weights).
**Outputs:** Optimized per-image embedding vectors, rendered images.
**Data Structures:** A list of per-image embedding vectors, each of dimension $d=8$ [S1, unofficial]. Each vector is stored as a trainable parameter tensor.
**Steps:**
1. Initialize a unique embedding vector $\mathbf{e}_i \in \mathbb{R}^8$ for each training image $i$.
2. During training, for each image $i$, retrieve its embedding $\mathbf{e}_i$ and condition it with the spatial/feature representation of a point or primitive.
3. Compute the color $C$ of the point/primitive using the conditioned representation, jointly optimizing $\mathbf{e}_i$ alongside scene parameters via gradient descent.
4. During validation, since validation image embeddings are unknown, compute the mean of all training embeddings $\bar{\mathbf{e}} = \frac{1}{N}\sum_{i=1}^N \mathbf{e}_i$ and use $\bar{\mathbf{e}}$ for all validation queries [S1, unofficial].
**Formulas:** Color computation is defined as $C = \mathcal{N}(F, \mathbf{e}_i)$, where $\mathcal{N}$ is the color prediction network, $F$ is the base feature representation of the point/primitive, and $\mathbf{e}_i$ is the per-image embedding [S3, unofficial].
**Parameters:** Embedding dimension is fixed at $8$ [S1, unofficial].
**Edge Cases and Pitfalls:** Validation requires a heuristic fallback (mean embedding) to avoid unknown inputs [S1, unofficial]. Joint optimization can introduce artifacts if not regularized, though embeddings were originally designed for lighting robustness and later studied for mitigating floater artifacts [S3, unofficial].
**Pseudocode:**
```python
def initialize_embeddings(num_images, dim=8):
    return [[random.gauss(0, 1) for _ in range(dim)] for _ in range(num_images)]

def color_network(features, embedding):
    return features + embedding

def render_image(pose, embedding, scene_params):
    return color_network(scene_params, embedding)

def photometric_loss(rendered, ground_truth):
    return sum((r - g)**2 for r, g in zip(rendered, ground_truth))

def train_step(images, poses, embeddings, scene_params, optimizer):
    for img_idx, (image, pose) in enumerate(zip(images, poses)):
        emb = embeddings[img_idx]
        rendered = render_image(pose, emb, scene_params)
        loss = photometric_loss(rendered, image)
        optimizer.step(loss)

def validate(poses, embeddings, scene_params):
    mean_emb = [sum(v) / len(embeddings) for v in zip(*embeddings)]
    return [render_image(pose, mean_emb, scene_params) for pose in poses]
```
## Subtopics

### Feature Embedding for Illumination
This variant replaces spherical harmonics with a feature embedding $f$ and a trainable per-image embedding $e$ to handle intense illumination changes, such as multiple light sources in indoor scenes [S4]. It retains the opacity parameter $\alpha$ consistent with standard 2D Gaussian Splatting [S4]. It is chosen when spherical harmonics are insufficient for modeling complex lighting [S4].

## Operating characteristics
*Performance:* Improves robustness to lighting variations and can mitigate floater artifacts in geometry-critical tasks [S3, unofficial].
*Strengths:* Handles dynamic lighting, shadows, and appearance changes effectively across large-scale scenes [S1, unofficial][S2].
*Limitations:* Requires per-image optimization during training; validation requires a heuristic mean-embedding fallback [S1, unofficial].
## Background
Appearance embeddings were originally introduced in "NeRF in the Wild" to address lighting variations in uncontrolled outdoor environments [S3, unofficial]. The concept has been extended to various rendering frameworks, including K-Planes and Gaussian Splatting (referred to as WildGaussians) and Convex Splatting (WildConvexes) [S3, unofficial]. It is commonly used in large-scale scene reconstruction where lighting consistency is challenging [S1, unofficial].
