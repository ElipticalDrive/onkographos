# Fine-tuning

Also called: 3DGS Fine-tuning, Gaussian Splatting Fine-tuning

## Overview
Fine-tuning in 3D Gaussian Splatting (3DGS) refers to the optimization phase that follows an initial initialization or pre-training step, where the full set of Gaussian primitives (geometry, color, and opacity) is jointly optimized to minimize reconstruction error [S1]. It solves the problem of initializing a high-fidelity radiance field by leveraging pretrained priors or feed-forward predictions to accelerate convergence and reduce memory consumption compared to training from scratch [S1]. It sets itself apart from standard training by often decoupling the initialization (e.g., via a feed-forward network) from the subsequent differentiable rasterization optimization, and by explicitly enabling dynamic densification (growing/pruning) during this phase to refine the primitive distribution [S1].

## How it works
### Inputs and Outputs
- **Inputs**: A set of input images with known camera poses; an initial set of 3D Gaussian primitives (either from Structure-from-Motion, a feed-forward network, or a coarse initialization); and hyperparameters for the optimizer and loss functions.
- **Outputs**: Optimized 3D Gaussian primitives defined by mean position $\mu$, covariance $\Sigma$ (or scale $s$ and rotation $q$), opacity $\alpha$, and spherical harmonic coefficients $c_{lm}$ for color.

### Data Structures
The core data structure is the list of $N$ Gaussians. Each Gaussian $i$ stores:
- $\mu_i \in \mathbb{R}^3$: 3D position.
- $s_i \in \mathbb{R}^3$: Scale vector (3 components).
- $q_i \in \mathbb{R}^4$: Rotation quaternion (4 components).
- $\alpha_i \in \mathbb{R}$: Opacity (1 component).
- $c_{i,lm} \in \mathbb{R}$: Spherical Harmonic coefficients (typically $4 \times 3 = 12$ floats for degree 3).

### Steps
1. **Initialization**: Generate an initial set of 3D Gaussian primitives. This can be done via a direct feed-forward process where a network predicts geometry and color attributes [S1], or via standard SfM point clouds. If using a feed-forward prior, the network outputs initial $\mu, s, q, \alpha, c$ [S1].
2. **Joint Optimization**: Optimize all geometry ($\mu, s, q$) and color ($c$) attributes directly using differentiable rasterization [S1]. The optimization minimizes a loss function, typically combining L1 color reconstruction loss and SSIM [S1].
3. **Dynamic Densification**: Enable growing (splitting/cloning) and pruning of 3D primitives during fine-tuning [S1]. This step is crucial because initial feed-forward Gaussians may be redundant; pruning reduces memory consumption while maintaining fidelity [S1].
4. **Convergence**: Continue optimization until the reconstruction error plateaus or a fixed iteration count is reached. The pretrained priors accelerate convergence compared to test-time optimization from random initialization [S1].

### Formulas
The total loss $\mathcal{L}$ typically includes:
$$ \mathcal{L} = \mathcal{L}_{\text{L1}} + \lambda_{\text{ssim}} \mathcal{L}_{\text{SSIM}} + \lambda_e \mathcal{L}_{\text{entropy}} $$
Where:
- $\mathcal{L}_{\text{L1}}$ is the L1 distance between rendered and ground truth colors.
- $\mathcal{L}_{\text{SSIM}}$ is the Structural Similarity Index Measure loss.
- $\mathcal{L}_{\text{entropy}}$ is an entropy loss to encourage opacity values to be either 0 or 1 [S1].
- $\lambda_{\text{ssim}}$ and $\lambda_e$ are weighting hyperparameters.

### Parameters
- **Optimizer**: Adam [S1].
- **Learning Rate**: $1 \times 10^{-3}$ for geometry and color attributes [S1].
- **Hardware**: Single GPU (e.g., NVIDIA V100) [S1, S2].
- **Library**: `gsplat` for Gaussian rasterization [S1].

### Edge Cases and Pitfalls
- **Redundancy**: Initial feed-forward Gaussians can be redundant; failing to prune them leads to high memory usage without quality gains [S1].
- **Convergence Speed**: Without pretrained priors, convergence is slower [S1].
- **Overfitting**: Aggressive densification without pruning can lead to overfitting to input views [S1].

### Pseudocode
```python
# Initialize Gaussians from feed-forward network or SfM
gaussians = initialize_gaussians(input_images, poses)

# Setup optimizer
optimizer = Adam(params=gaussians.parameters(), lr=1e-3)

# Training loop
for iteration in range(total_iterations):
    # Sample a random camera view
    camera = sample_random_view(input_images, poses)
    
    # Render the scene
    rendered_image = rasterize(gaussians, camera)
    
    # Compute loss
    loss_l1 = L1_loss(rendered_image, camera.gt_image)
    loss_ssim = SSIM_loss(rendered_image, camera.gt_image)
    loss_entropy = Entropy_loss(gaussians.opacity)
    
    total_loss = loss_l1 + lambda_ssim * loss_ssim + lambda_e * loss_entropy
    
    # Backpropagate and update
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
    
    # Dynamic densification and pruning
    if iteration % densification_interval == 0:
        gaussians = densify_and_prune(gaussians, camera, threshold=gradient_threshold)

return gaussians
```

## Subtopics

### Two-stage Optimization
A variant where optimization is split into an initial stage optimizing geometry and appearance, followed by a decomposition stage optimizing material properties [S2].
- **Stage 1 (Initial)**: Minimize color reconstruction loss $\mathcal{L}_c$ and normal loss $\mathcal{L}_n$ to optimize geometry $T$ and appearance $A$ for 30,000 iterations [S2].
- **Stage 2 (Decomposition)**: Fix $T$ and $A$, then minimize decomposition loss $\mathcal{L}_d$ to optimize material $M$ for 10,000 iterations [S2].
- **Parameters**: Adam optimizer; Single NVIDIA V100 GPU; Smoothing weights: $\lambda_{n-TV} = 5.0$, $\lambda_M = 1.0$, $\lambda_E = 0.01$ [S2].

### StylizedGS
A controllable 3D stylization method that performs color matching with a style image and utilizes a 3DGS filter to remove artifacts [S3].
- **Steps**: Employs a nearest neighbor feature match loss and a depth preservation loss for optimization [S3].

## Operating characteristics
- **Time Complexity**: Depends on the number of Gaussians $N$ and the number of training iterations. Fine-tuning with pretrained priors converges faster than training from scratch [S1].
- **Memory Complexity**: $O(N \cdot D)$ where $D$ is the dimensionality of Gaussian attributes (position, scale, rotation, opacity, SH coefficients). Pruning reduces $N$ and thus memory usage [S1].
- **Performance**: Achieves photorealism on par with or surpassing other methods, with faster convergence [S1].
- **Strengths**: Accelerated training, reduced memory consumption via pruning, high fidelity [S1].
- **Limitations**: Requires a good initialization (feed-forward or SfM); sensitive to hyperparameters for densification and pruning [S1].

## Background
Fine-tuning in 3DGS has emerged as a key technique to leverage pretrained models and accelerate the training process. Methods like EVolSplat demonstrate that predicting initial Gaussians via a feed-forward network and then fine-tuning them with standard 3DGS optimization leads to efficient and high-quality urban view synthesis [S1]. Other works like GS-IR use fine-tuning strategies to decompose geometry, appearance, and material properties [S2]. StylizedGS applies fine-tuning principles to 3D stylization tasks [S3].
