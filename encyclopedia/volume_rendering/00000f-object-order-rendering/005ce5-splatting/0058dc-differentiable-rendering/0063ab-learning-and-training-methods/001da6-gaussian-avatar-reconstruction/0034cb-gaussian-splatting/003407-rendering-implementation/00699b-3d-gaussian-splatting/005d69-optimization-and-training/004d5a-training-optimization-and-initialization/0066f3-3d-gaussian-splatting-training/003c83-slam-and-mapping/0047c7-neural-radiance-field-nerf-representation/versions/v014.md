# Neural Radiance Field (NeRF) Representation

Also called: INGP, Instant Neural Graphics Primitives, Photon Field Networks, Photon Fields

## Overview
Neural Radiance Field (NeRF) representation methods map 3D scene geometry and appearance into a continuous volumetric function, typically implemented as a neural network, to synthesize novel views from sparse input images [S1][S2, unofficial]. Unlike explicit representations that store discrete geometric primitives, NeRF implicitly encodes density and color, solving the problem of view-dependent rendering without requiring explicit mesh extraction [S2, unofficial]. While standard NeRF relies on volumetric ray marching, variants like Instant Neural Graphics Primitives (INGP) optimize training speed via hash-based encoding, and Photon Field Networks replace expensive global illumination tracing with neural inference [S1].

## How it works
The implementation of NeRF representations varies significantly between implicit volumetric fields (standard NeRF/INGP) and explicit Gaussian splatting approximations. The following details cover the core implicit NeRF formulation and the specific Photon Field Network variant, as well as the explicit Gaussian Splatting method often grouped under this representation family in SLAM contexts.

### Inputs and Outputs
*   **Inputs:** A set of $N$ calibrated images with known camera poses $T_i \in SE(3)$, intrinsics $K$, and pixel coordinates. For Photon Fields, additional phase function coefficients $g$ are required.
*   **Outputs:** A rendered RGB image for a novel viewpoint, or a neural field function $F_\theta$ that maps spatial coordinates and view directions to color and density.

### Data Structures

#### 1. Implicit Neural Field (Standard NeRF / INGP)
The scene is represented by a Multi-Layer Perceptron (MLP) $\mathcal{F}_\theta$.
*   **Position Encoding:** For INGP, positions $\mathbf{x} \in \mathbb{R}^3$ and directions $\mathbf{v} \in \mathbb{R}^3$ are encoded using a hash grid.
    *   **Hash Grid:** 16 levels, 8 features per level, 2x scaling factor between levels, hash table size $2^{19}$ [S1].
    *   **Input Vector:** Concatenated encoded position and direction vectors.
*   **MLP Architecture:**
    *   Input dimension: Sum of encoded position and direction dimensions.
    *   Hidden layers: 5 layers, 64 neurons per layer.
    *   Activation: ReLU between hidden layers.
    *   Output: No activation on the final layer.
    *   Output Vector: $[\sigma, \mathbf{c}]$, where $\sigma$ is volume density and $\mathbf{c} \in \mathbb{R}^3$ is view-dependent color.

#### 2. Photon Field Network (Photon Fields)
A specialized implicit field for indirect global illumination.
*   **Mapping Function:** $P_\phi(x, g, \vec{\omega}) = (R, G, B)$ [S1].
    *   $x \in [0,1]^3$: Normalized 3D position.
    *   $g \in [-1,1]$: Scattering coefficient (phase function parameter).
    *   $\vec{\omega}$: View direction in normalized spherical coordinates.
*   **Network Architecture:**
    *   **Encoding:** Hash grid for $x$ and $\vec{\omega}$ (same as INGP: 16 levels, 8 features, $2^{19}$ hash table). $g$ is left unencoded [S1].
    *   **MLP:** 5-layer perceptron, 64 neurons/layer, ReLU activations, no output activation [S1].
    *   **Output:** Log-encoded radiance $L_i'$ [S1].
*   **Photon Map (for Training Data Generation):**
    *   Stored on GPU.
    *   Structure: List of photons, each containing position, direction, intensity $\Phi$, and phase coefficient $g$.
    *   Spatial Index: GPU-accelerated kd-tree for fast KNN queries [S1].

#### 3. Explicit Gaussian Splatting (3DGS)
Represents the scene as a set of 3D Gaussians $\mathcal{G} = \{g_i\}$ [S2, unofficial].
*   **Gaussian Parameterization:** Each Gaussian $g_i$ stores ~59 learnable numbers [S2, unofficial]:
    *   **Position:** $\mu_i \in \mathbb{R}^3$ (center).
    *   **Covariance:** $\Sigma_i \in \mathbb{R}^{3 \times 3}$. Parameterized by scale $S \in \mathbb{R}^3$ and rotation $R \in SO(3)$ (quaternion). $\Sigma = R S S^T R^T$ to ensure positive semi-definiteness [S2, unofficial].
    *   **Opacity:** $\alpha_i \in [0,1]$.
    *   **Color:** Spherical Harmonic (SH) coefficients for view-dependent color $c_i$ [S2, unofficial].

### Numbered Steps

#### A. Training Data Generation (Photon Fields Only)
1.  **Photon Tracing:** Generate photons from random light sources using delta tracking [S1].
    *   Assign a random phase coefficient $g \in G = \{-0.75, 0.0, 0.75\}$ [S1].
    *   Trace bounces. Skip first interaction (store only indirect photons) [S1].
    *   Update direction using Henyey-Greenstein phase function $p_g$ [S1].
    *   Store photon in `photonmap` with intensity $\Phi$ and position [S1].
2.  **KD-Tree Construction:** Build a kd-tree on the GPU from the `photonmap` [S1].
3.  **Sampling:** Generate batches of size $2^{16}$ [S1].
    *   Sample $x \in [0,1]^3$ uniformly.
    *   Sample $\vec{\omega}$ uniformly.
    *   Sample $g$ randomly from $G$ [S1].
4.  **Ground Truth Estimation:** For each sample $(x, \vec{\omega}, g)$:
    *   Perform KNN query on `photonmap` for photons with matching $g$.
    *   Use $K=1024$ neighbors and max radius $r$ [S1].
    *   Compute radiance:
        $$ L_i(x, \vec{\omega}) \approx \sum_{n=1}^K p_g(x, \vec{\omega}, \vec{\omega}_n) \frac{\Phi_n}{4\pi r^3} $$
        where $r$ is distance to farthest photon, $\Phi_n$ is intensity, $p_g$ is Henyey-Greenstein phase function [S1].
5.  **Target Encoding:** Normalize radiance to $[0,1]$ using precision $\psi \in [4,6]$ [S1]:
    $$ L_i'(x, \vec{\omega}) = \begin{cases} -\frac{\log_{10}(L_i(x, \vec{\omega}))}{\psi} & \text{if } L_i(x, \vec{\omega}) > 10^{-\psi} \\ 1 & \text{otherwise} \end{cases} $$
    [S1].

#### B. Neural Field Training (Standard NeRF / INGP / Photon Fields)
1.  **Ray Casting:** For each pixel, cast a ray through the scene.
2.  **Sampling:** Sample points along the ray. For INGP/Photon Fields, query the hash grid and MLP.
3.  **Forward Pass:**
    *   **Standard NeRF:** Input $(x, \vec{\omega})$ to MLP $\to$ $(\sigma, \mathbf{c})$.
    *   **Photon Fields:** Input $(x, g, \vec{\omega})$ to MLP $\to$ $L_i'$. Decode to $L_i = 10^{-L_i'} \cdot \Psi$ [S1].
4.  **Volume Rendering:** Composite colors front-to-back:
    $$ C = \sum_{i} T_i \alpha_i \mathbf{c}_i, \quad T_i = \prod_{j < i} (1 - \alpha_j) $$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ [S2, unofficial].
5.  **Loss Computation:** Compare rendered image $\hat{C}$ with ground truth $C$.
    *   Loss = L1 Loss + SSIM term [S2, unofficial].
    *   For SLAIM, add KL regularization over ray termination distribution [S3].
6.  **Backpropagation:** Update network weights $\theta$ via gradient descent [S2, unofficial].

#### C. Gaussian Splatting Optimization (3DGS)
1.  **Initialization:** Use Structure from Motion (e.g., COLMAP) to generate a sparse 3D point cloud. Each point initializes one Gaussian [S2, unofficial].
2.  **Projection:** Project 3D Gaussians to 2D screen space.
    *   Compute 2D covariance using camera projection matrix and local linear approximation [S2, unofficial].
3.  **Tiling:** Divide screen into $16 \times 16$ pixel tiles. Assign Gaussians to overlapping tiles [S2, unofficial].
4.  **Sorting:** Sort Gaussians by depth within each tile (front-to-back) using fast GPU sort [S2, unofficial].
5.  **Rasterization:** For each pixel, blend Gaussians:
    $$ C = \sum_{i \in \text{sorted}} c_i \alpha_i \prod_{j < i} (1 - \alpha_j) $$
    [S2, unofficial].
6.  **Loss & Update:** Compute L1 + SSIM loss. Backpropagate to update $\mu, S, R, \alpha, c$ [S2, unofficial].
7.  **Adaptive Density Control:**
    *   **Cloning:** Clone small Gaussians in under-reconstructed regions [S2, unofficial].
    *   **Splitting:** Split large Gaussians covering too much detail into two smaller ones [S2, unofficial].
    *   **Pruning:** Remove Gaussians with low opacity [S2, unofficial].

### Parameters
*   **$\psi$ (Precision):** Maximum desired floating point precision digits. Typical values: 4–6 [S1].
*   **$K$ (KNN Neighbors):** Number of photons for radiance estimation. Value: 1024 [S1].
*   **$G$ (Phase Coefficients):** Discrete set for photon assignment. Optimal set: $\{-0.75, 0.0, 0.75\}$ [S1].
*   **Tile Size:** $16 \times 16$ pixels [S2, unofficial].
*   **Batch Size:** $2^{16}$ samples per training step [S1].

### Edge Cases and Pitfalls
*   **Precision Clamping:** In Photon Fields, radiance values below $10^{-\psi}$ are clamped to 1 in the log domain (mapping to 0 in inverse), preventing gradient issues for negligible light [S1].
*   **Covariance Validity:** In Gaussian Splatting, covariance must be constructed as $R S S^T R^T$ to ensure it remains positive semi-definite [S2, unofficial].
*   **Aliasing:** Gaussian Splatting suffers from aliasing when zooming in or out [S2, unofficial].
*   **Artifacts:** Floating artifacts and needle-like Gaussians may appear in regions seen by few cameras [S2, unofficial].
*   **Surface Extraction:** Neither standard NeRF nor Gaussian Splatting directly yields a clean, watertight mesh without post-processing [S2, unofficial].

## Subtopics

### [Scene NeRF](12484-scene-nerf.md)
Isolates static background by training NeRF only on background-masked pixels, using an emptiness regularizer.

### [NeRF-OSR](14477-nerf-osr.md)
Decomposes outdoor scenes into albedo, geometry, and lighting for relighting, unlike standard NeRF's fixed-lighting Lambertian model.

### [Explicit Volumetric Rendering with Multiple View Aggregation](15335-explicit-volumetric-rendering-with-multiple-view-aggregation.md)
Uses a dense RGB$\alpha$ volume for real-time rendering and SSIM losses, amortizing computation across views.

### [Dynamic Neural Radiance Fields](16398-dynamic-neural-radiance-fields.md)
Models dynamic faces using a morphable model conditioned on expression parameters, requiring only monocular input.

### SLAIM
A SLAM method introducing a coarse-to-fine tracking pipeline and Gaussian-filtered image signal for photometric bundle adjustment. It maintains NeRF’s volume density formulation but adds KL regularization over ray termination distribution to handle high-frequency rendering artifacts that hinder alignment [S3].

### SNI-SLAM
A dense NeRF-based RGB-D SLAM system for real-time 3D semantic mapping. It uses hierarchical semantic encoding and cross-attention to reinforce appearance, geometry, and semantics. A novel one-way decoder enhances inter-modal flow without reverse interference [S3].

### KN-SLAM
A NeRF-based SLAM method integrating local feature correspondences for coarse pose initialization. It uses global image features and local matches for loop detection, followed by pose graph optimization and global refinement of the neural map [S3].

## Operating characteristics
*   **Time Complexity:**
    *   **Standard NeRF:** Training takes many hours; rendering is slow (seconds per image) due to per-ray MLP evaluations [S2, unofficial].
    *   **INGP:** Faster convergence due to hash encoding [S1].
    *   **Gaussian Splatting:** Training drops to tens of minutes; rendering exceeds 100 FPS at high resolution [S2, unofficial].
*   **Memory Complexity:**
    *   **Standard NeRF:** Low memory (few MBs for network weights) [S2, unofficial].
    *   **Gaussian Splatting:** High memory (hundreds of MBs) due to storing millions of Gaussian parameters [S2, unofficial].
    *   **Photon Fields:** Requires storing photon maps and kd-trees on GPU [S1].
*   **Strengths:**
    *   High-quality novel view synthesis.
    *   Gaussian Splatting enables real-time performance [S2, unofficial].
    *   Photon Fields accelerate global illumination calculation [S1].
*   **Limitations:**
    *   Gaussian Splatting: Aliasing, floating artifacts, no direct mesh output [S2, unofficial].
    *   NeRF: Slow training and rendering (unless optimized) [S2, unofficial].
*   **Usage:** Virtual reality, film, robotics, mapping, digital humans, ecommerce, cultural heritage [S2, unofficial].

## Background
Neural Radiance Fields were introduced by Mildenhall et al. in 2020, establishing the paradigm of implicit neural representations for 3D scenes [S2, unofficial]. Instant Neural Graphics Primitives (INGP) by Müller et al. improved training speed using hash-based positional encoding [S1]. Photon Field Networks were introduced to accelerate global illumination in volumetric rendering by replacing photon tracing with neural inference [S1]. Gaussian Splatting was introduced by Kerbl et al. at SIGGRAPH 2023, offering explicit, real-time rendering [S2, unofficial].
