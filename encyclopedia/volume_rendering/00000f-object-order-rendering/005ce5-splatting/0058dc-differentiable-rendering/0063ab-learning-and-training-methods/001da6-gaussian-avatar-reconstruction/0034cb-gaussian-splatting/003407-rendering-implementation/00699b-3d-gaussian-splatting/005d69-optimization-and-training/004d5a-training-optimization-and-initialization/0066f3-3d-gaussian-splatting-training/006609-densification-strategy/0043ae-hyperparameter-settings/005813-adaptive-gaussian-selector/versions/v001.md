# Adaptive Gaussian Selector

Also called: GsNet, Gumbel-Softmax Selection

## Overview
The Adaptive Gaussian Selector is a learnable module within the FlexGS framework that adaptively selects a subset of 3D Gaussians during training based on their attributes and a desired elastic ratio $e$, using a differentiable mask to enable gradient-based optimization [S1]. It differs from heuristic densification strategies by jointly optimizing a neural network (GsNet) to predict selection probabilities, allowing the model to generalize across varying sparsity levels rather than relying on fixed thresholds [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ 3D Gaussians with attributes $A_i$ (mean position, scaling vector $s_i$, rotation quaternion, opacity $\alpha_i$, spherical harmonics coefficients) and a target elastic ratio $e \in E$, where $E$ is a set of discrete ratios (e.g., $\{0.01, 0.05, 0.10, 0.15\}$) [S1].
*   **Outputs:** A binary selection mask $\hat{M}$ (or continuous logits during inference) indicating which Gaussians are active, and updated Gaussian attributes optimized via the selector's gradients [S1].

**Data Structures:**
*   **GsNet:** A lightweight neural network consisting of two feature embedding sub-networks and a mixing layer.
    *   Ratio Embedder: Two linear layers with ReLU activation. Weights $W_{1e} \in \mathbb{R}^{D}$, $W_{2e} \in \mathbb{R}^{D \times D}$.
    *   Attribute Embedder: Two linear layers with ReLU activation. Weights $W_{1a} \in \mathbb{R}^{H \times D}$, $W_{2a} \in \mathbb{R}^{D \times D}$, where $H$ is the flattened dimension of Gaussian attributes [S1].
    *   Mixing Layer: Linear projection $W \in \mathbb{R}^{2D \times 2}$ mapping concatenated features to 2 logits [S1].
*   **Global Importance (GI):** A scalar score $GI_i$ for each Gaussian, updated periodically [S1].

**Numbered Steps:**

1.  **Feature Embedding:**
    *   Convert the scalar elastic ratio $e$ into a feature vector $h_e$ using the ratio embedder:
        $$ h_e = \sigma(\sigma(e W_{1e}) W_{2e}) $$
        where $\sigma$ is ReLU [S1].
    *   Flatten all attributes $A_i$ of the $i$-th Gaussian into a vector $\xi$, then convert to feature vector $h_{a_i}$:
        $$ \xi = \text{Concat}(\{a : a \in A_i\}) $$
        $$ h_{a_i} = \sigma(\sigma(\xi W_{1a}) W_{2a}) $$
        [S1].

2.  **Logit Generation:**
    *   Concatenate $h_e$ and $h_{a_i}$ and project to logits $z \in \mathbb{R}^2$:
        $$ z = [h_e, h_{a_i}] W $$
        where $z_m$ corresponds to the logit for selection ($m=1$) or rejection ($m=0$) [S1].

3.  **Differentiable Sampling (Gumbel-Softmax):**
    *   Sample binary masks $\hat{M}$ using Gumbel-Softmax to allow backpropagation:
        $$ P(\lambda_i = m | A_i, e) = \frac{\exp((z_m + g_m)/\tau)}{\sum_{m=0,1} \exp((z_m + g_m)/\tau)} $$
        where $g_m \sim \text{Gumbel}(0,1)$ and $\tau$ is the temperature parameter [S1].
    *   During training, $\tau$ is exponentially decayed to converge to deterministic one-hot selections [S1].

4.  **Global Importance (GI) Calculation:**
    *   Compute $GI_i$ to guide selection and prevent convergence issues at high ratios:
        $$ GI_i = \sum_{p=1}^{QHW} \mathbb{1}(G(X_i), r_p) \cdot \gamma(s_i) \cdot \alpha_i \cdot T(i, p) $$
        where $Q$ is the number of views, $H/W$ are image dimensions, $\mathbb{1}$ is an overlap indicator, $\alpha_i$ is opacity, and $T(i,p)$ is transmittance [S1].
    *   Volume normalization factor $\gamma(s_i)$:
        $$ \gamma(s_i) = \max(V(s_i)/V_{90\%}, 1), \quad V(s) = |s_1 s_2 s_3|\pi/3 $$
        where $V_{90\%}$ is 90% of the largest Gaussian volume in the scene [S1].
    *   Transmittance $T(i,p)$:
        $$ T(i, p) = \prod_{t=1}^{ID(i,p)-1} (1 - \alpha_t) $$
        where $ID(i,p)$ is the index of the $i$-th Gaussian among sorted overlapping Gaussians at pixel $p$ [S1].
    *   **Update Frequency:** $GI$ is recomputed every 1,000 training iterations to ensure accuracy as attributes evolve [S1].

5.  **Guidance Mask Construction:**
    *   Select the top $\lfloor eN \rfloor$ Gaussians with the highest $GI$ scores to form the guidance mask $M_{GI}$ [S1].

6.  **Opacity Update and Rendering:**
    *   Update the opacity of all Gaussians to mask out unselected ones:
        $$ \alpha_i = \alpha_i \cdot \hat{M}_i $$
        Unselected Gaussians ($\hat{M}_i=0$) become transparent [S1].
    *   Render two images per iteration:
        *   $I_{es}$: Rendered using only the selected Gaussians (based on $\hat{M}$).
        *   $I_f$: Rendered using all Gaussians (standard 3DGS rendering).
    *   Both are supervised against the ground truth $I_{GT}$ [S1].

7.  **Loss Calculation:**
    *   Compute the total loss:
        $$ L = L_{render} + \beta_1 L_{GI} + \beta_2 L_{spar} $$
    *   $L_{render} = \|I_{es} - I_{GT}\|_1 + \|I_f - I_{GT}\|_1$ [S1].
    *   $L_{GI} = \|\hat{M} - M_{GI}\|_1$ (Regularization to align learned selection with GI guidance) [S1].
    *   $L_{spar} = |e - \sum_{m \in \hat{M}} m / N|$ (Constraint to enforce the target ratio $e$) [S1].

**Parameters:**
*   $\tau$: Temperature for Gumbel-Softmax. Exponentially decayed during optimization [S1].
*   $\beta_1$: Weight for $L_{GI}$. Value: 1.0 [S1].
*   $\beta_2$: Weight for $L_{spar}$. Value: 0.01 [S1].
*   $E$: Set of elastic ratios sampled randomly each iteration. Typical values: $\{0.01, 0.05, 0.10, 0.15\}$ [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class AdaptiveGaussianSelector(nn.Module):
    def __init__(self, attr_dim, hidden_dim=64):
        super().__init__()
        self.hidden_dim = hidden_dim
        # Ratio Embedder
        self.w1_e = nn.Parameter(torch.randn(hidden_dim))
        self.w2_e = nn.Parameter(torch.randn(hidden_dim, hidden_dim))
        # Attribute Embedder
        self.w1_a = nn.Parameter(torch.randn(attr_dim, hidden_dim))
        self.w2_a = nn.Parameter(torch.randn(hidden_dim, hidden_dim))
        # Mixing Layer
        self.w_mix = nn.Parameter(torch.randn(2 * hidden_dim, 2))
        
        self.tau = 1.0
        self.tau_decay = 0.999 # Example decay factor
        
    def forward(self, gaussians, e, gi_scores, update_gi=True):
        """
        gaussians: dict with keys 's' (scaling), 'alpha', 'xyz', etc.
        e: target elastic ratio (float)
        gi_scores: tensor of shape (N,) containing Global Importance scores
        """
        N = gaussians['alpha'].shape[0]
        
        # 1. Feature Embedding
        # Ratio feature
        e_feat = torch.relu(torch.relu(e * self.w1_e) @ self.w2_e.T) # Shape: (hidden_dim,)
        
        # Attribute feature (concatenate relevant attributes)
        # Assuming attributes are flattened into a single vector per gaussian
        # In practice, this requires gathering specific attributes from the Gaussian structure
        # For this pseudocode, we assume a helper function `get_flat_attrs` exists
        # which returns shape (N, attr_dim)
        attrs = get_flat_attrs(gaussians) 
        a_feat = torch.relu(torch.relu(attrs @ self.w1_a) @ self.w2_a.T) # Shape: (N, hidden_dim)
        
        # 2. Logit Generation
        # Repeat e_feat for all N gaussians
        e_feat_expanded = e_feat.unsqueeze(0).expand(N, -1)
        concat_feat = torch.cat([e_feat_expanded, a_feat], dim=1) # Shape: (N, 2*hidden_dim)
        logits = concat_feat @ self.w_mix.T # Shape: (N, 2)
        
        # 3. Differentiable Sampling
        # Sample binary masks using Gumbel-Softmax
        # hard=True for training to get discrete masks for opacity update, 
        # but gradients flow through soft version
        masks = F.gumbel_softmax(logits, tau=self.tau, hard=True) # Shape: (N, 2)
        # Select the probability of being active (index 1)
        selection_prob = masks[:, 1] # Shape: (N,)
        
        # 4. Guidance Mask Construction
        # Select top floor(e*N) Gaussians based on GI
        k = int(e * N)
        # Ensure k is within bounds
        k = max(0, min(k, N))
        _, top_indices = torch.topk(gi_scores, k)
        guidance_mask = torch.zeros(N, dtype=torch.float32)
        guidance_mask[top_indices] = 1.0
        
        # 5. Loss Components
        # L_GI: Align selection_prob with guidance_mask
        l_gi = torch.mean(torch.abs(selection_prob - guidance_mask))
        
        # L_spar: Constraint on the sum of selection probabilities to match e
        # Note: The source defines L_spar as |e - sum(m)/N| where m in M_hat.
        # Using the hard mask sum for the constraint term is more direct for the ratio.
        current_ratio = torch.mean(selection_prob) # Or use hard mask mean
        l_spar = torch.abs(e - current_ratio)
        
        # 6. Opacity Update
        # Update alpha in place or return new alpha
        # alpha_new = alpha * selection_prob
        # This step is usually handled in the rendering loop using the mask
        # Here we return the mask to be applied externally
        mask_applied = selection_prob # Shape: (N,)
        
        # Decay temperature
        self.tau *= self.tau_decay
        
        return mask_applied, l_gi, l_spar
```

**Edge Cases and Pitfalls:**
*   **Sparsity Supervision Drift:** During inference, the stochastic nature of Gumbel-Softmax or the learned probabilities may not yield exactly $\lfloor eN \rfloor$ active Gaussians (e.g., target 0.20 yields ~19.5%) [S1]. This is addressed in the Elastic Inference Procedure (see Subtopics) by using continuous logits and top-k selection [S1].
*   **Convergence at High Ratios:** At high elastic ratios, there are many ways to mask Gaussians, making it difficult for GsNet to converge smoothly. The Global Importance (GI) guidance is critical to stabilize training in these regimes [S1].
*   **GI Update Frequency:** GI must be recomputed frequently (every 1k iterations) because Gaussian attributes evolve during training, rendering stale GI scores inaccurate [S1].

## Subtopics

### [Differentiable Gaussian Selection via Gumbel-Softmax and STE](16109-differentiable-gaussian-selection-via-gumbel-softmax-and-ste.md)
A mechanism that converts continuous logits from GsNet into a binary mask using the Straight-Through Estimator (STE) or Gumbel-Softmax relaxation. This allows gradients to flow through the discrete selection process, enabling the optimization of Gaussian attributes (position, scale, opacity) based on their contribution to the final image, rather than relying on static heuristics. It is chosen when differentiable pruning or dynamic sparsity control is required during the training phase.

### Elastic Inference Procedure
An inference-time protocol that discards unselected Gaussians entirely and uses continuous logits to guarantee an exact target sparsity ratio $e$. It addresses the pitfall where training-time sparsity supervision does not guarantee exact activation counts at inference. By calling `F.gumbel_softmax` with `hard=False` to obtain continuous logits and then selecting the top $\lfloor eN \rfloor$ logits, it ensures the exact target ratio is met despite any drift in the learned probabilities [S1].

## Operating characteristics
*   **Time Complexity:** The selector adds a lightweight neural network evaluation per Gaussian per iteration. The dominant cost is the Global Importance (GI) calculation, which involves iterating over all pixels and overlapping Gaussians. GI is updated every 1,000 iterations, amortizing this cost [S1].
*   **Memory Complexity:** Requires storing the GsNet parameters (small, $D=64$ typically) and the GI scores for all Gaussians ($O(N)$) [S1].
*   **Measured Performance:** On Mip-NeRF360, FlexGS achieves competitive PSNR/SSIM at 1% sparsity compared to LightGS (fine-tuned), demonstrating effective selection [S1].
*   **Strengths:** Enables a single model to support multiple sparsity levels (elastic inference); differentiable selection allows end-to-end optimization of Gaussian properties for sparsity [S1].
*   **Limitations:** Requires careful tuning of $\tau$ decay and regularization weights ($\beta_1, \beta_2$); GI calculation is expensive if done too frequently [S1].
*   **When to use:** When deploying 3DGS models on hardware with varying memory constraints or when a single model needs to support multiple quality/resolution trade-offs without retraining [S1].

## Background
The Adaptive Gaussian Selector was introduced in the FlexGS paper (2025) by the authors of "FlexGS: Train Once, Deploy Everywhere with Many-in-One Flexible 3D Gaussian Splatting" [S1]. It builds upon the original 3D Gaussian Splatting (3DGS) framework [S1] and addresses the limitation of fixed pruning or densification strategies by introducing a learnable, ratio-adaptive selection mechanism. The method was developed to enable efficient deployment across diverse hardware configurations by allowing elastic inference [S1].
