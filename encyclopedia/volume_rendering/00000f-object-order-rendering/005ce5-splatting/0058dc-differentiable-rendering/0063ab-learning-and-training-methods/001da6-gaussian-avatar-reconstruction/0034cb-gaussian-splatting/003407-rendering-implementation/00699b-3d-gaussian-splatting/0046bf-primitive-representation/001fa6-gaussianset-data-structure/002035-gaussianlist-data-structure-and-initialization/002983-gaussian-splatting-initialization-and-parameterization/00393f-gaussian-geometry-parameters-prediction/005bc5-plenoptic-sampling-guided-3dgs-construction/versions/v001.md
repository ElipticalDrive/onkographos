# Plenoptic Sampling Guided 3DGS Construction
Also called: White-Box 3DGS Construction, Mesh2GS Construction

## Overview
Plenoptic Sampling Guided 3DGS Construction is a method for initializing 3D Gaussian Splatting (3DGS) representations directly from mesh geometry, using plenoptic sampling theory to theoretically derive the minimum sampling rate for views and the optimal distribution of 3D Gaussians [S1, unofficial]. Unlike heuristic initialization methods that rely on trial-and-error, this approach precisely constrains Gaussian density and camera sampling to achieve Nyquist-level performance for global illumination caching [S1, unofficial]. It sets itself apart by grounding the initialization in signal processing principles, ensuring that the number of Gaussians and sampled views is minimized while maintaining high-fidelity rendering [S1, unofficial].

## How it works
The method constructs 3D Gaussians from a given scene mesh $G$ by deriving sampling parameters from camera intrinsics and scene depth bounds. The process involves determining the camera sampling interval, computing the world-space Gaussian sampling interval, initializing Gaussian attributes (position, scale, rotation, opacity), and optimizing color attributes using an albedo-shading decomposition strategy [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   Scene geometry: A mesh $G$ representing the scene surfaces.
*   Camera parameters: Focal length $f$, pixel size $\Delta v$ (or resolution $R$ and field of view $\theta$), minimum observation distance $z_{min}$, and maximum observation distance $z_{max}$ [S1, unofficial].
*   Light field properties: Highest spatial frequency in the continuous light field $B_v$ [S1, unofficial].

**Outputs:**
*   A set of 3D Gaussians $\mathcal{G}$ with initialized positions, scales, rotations, opacities, and colors.
*   A neural illumination enhancement module (optional, for non-Lambertian effects) [S1, unofficial].

### Data Structures
The core data structure is a list of 3D Gaussians. Each Gaussian $g_i$ contains:
*   **Position** $\mathbf{p}_i \in \mathbb{R}^3$: 3D coordinates.
*   **Scale** $\mathbf{s}_i \in \mathbb{R}^3$: Diagonal elements of the scaling matrix, typically $r_x, r_y, r_z$.
*   **Rotation** $\mathbf{q}_i \in \mathbb{R}^4$: A quaternion representing orientation.
*   **Opacity** $\alpha_i \in [0, 1]$: Scalar opacity value.
*   **Color** $\mathbf{c}_i \in \mathbb{R}^3$: RGB color value (optimized; initial value is derived or set to 0.5 opacity base) [S1, unofficial].

### Step-by-Step Method

1.  **Compute Maximum Camera Sampling Interval ($\Delta t$):**
    Calculate the highest spatial frequency $K_v$ and the maximum interval between sampled views [S1, unofficial]:
    $$
    K_v = \min\left(B_v, \frac{1}{2\Delta v}\right)
    $$
    $$
    \Delta t = \frac{1}{K_v f \left(\frac{1}{z_{min}} - \frac{1}{z_{max}}\right)}
    $$
    If the scene is decomposed into $D$ depth ranges, the interval increases by a factor of $D$:
    $$
    \Delta t = \frac{D}{K_v f \left(\frac{1}{z_{min}} - \frac{1}{z_{max}}\right)}
    $$
    [S1, unofficial]

2.  **Sample Camera Views:**
    Uniformly sample views from a spherical space around each object in the scene. Maintain a minimum observation distance of $z_{min}$ and ensure adequate coverage of all visible surfaces. The number of views $n_c$ is determined such that the sampling interval $\Delta t$ is satisfied [S1, unofficial].

3.  **Compute World-Space Sampling Interval ($\Delta w$):**
    Derive the sampling interval in world space from the image space sampling interval $\Delta v$ [S1, unofficial]:
    $$
    \Delta v = \frac{2f \tan\left(\frac{\theta}{2}\right)}{R}
    $$
    $$
    \Delta w = \frac{z_{min} \Delta v}{f}
    $$
    where $\theta$ is the field of view angle and $R$ is the camera resolution (e.g., width or height) [S1, unofficial].

4.  **Initialize Gaussian Positions:**
    Uniformly sample points on the mesh $G$ according to the sampling interval $\Delta w$. For each point, calculate the downward offset $d_{off}$ from the surface to place the Gaussian just below the visible surface [S1, unofficial]:
    $$
    d_{off} = \frac{\Delta w^2 \sin\alpha}{2(z_{min} + z_{max})}
    $$
    where $\alpha$ is the angle between the surface normal and the principal axis of the camera. The Gaussian position is set at this offset [S1, unofficial].

5.  **Initialize Gaussian Scales:**
    Set the scale parameters based on $\Delta w$ and $z_{min}$ [S1, unofficial]:
    $$
    r_x = r_y = \Delta w
    $$
    $$
    r_z = \frac{\Delta w^2}{4z_{min}}
    $$
    [S1, unofficial]

6.  **Initialize Gaussian Rotation:**
    Align the rotation of each Gaussian with the surface normal at its position. This ensures the Gaussian ellipsoid is tangent to the surface [S1, unofficial].

7.  **Initialize Gaussian Opacity:**
    Set the initial opacity for all Gaussians to 0.5 [S1, unofficial].

8.  **Freeze Non-Color Attributes:**
    Freeze all attributes of the 3D Gaussians except for the color values. This allows for efficient caching of global illumination in dynamic scenes [S1, unofficial].

9.  **Optimize Color Attributes (Albedo-Shading Decomposition):**
    Decompose the scene into albedo $I_a$ and shading $I_s$. The Gaussian image is represented as the product $I_g = I_a * I_s$ [S1, unofficial].
    *   Obtain the albedo image $I_a$ from G-Buffers.
    *   Optimize the color attributes of the Gaussians to fit the shading image $I_s$ derived from path-traced renderings.
    *   Use noisy 1-spp path-traced renderings with an exponential moving average (EMA) strategy for real-time shared rendering applications [S1, unofficial].

10. **Neural Illumination Enhancement (Optional):**
    For non-Lambertian regions, introduce a neural residual $I_n$. The final rendered image $I$ is the sum of the Gaussian image $I_g$ and the neural residual $I_n$ [S1, unofficial]:
    $$
    I = I_g + I_n
    $$
    The neural module models view-dependent residuals, while explicit Gaussians handle the base appearance [S1, unofficial].

### Edge Cases and Pitfalls
*   **Precision:** The formulas involve small differences ($1/z_{min} - 1/z_{max}$) and squares of small intervals ($\Delta w^2$). Care must be taken with floating-point precision, especially for large $z_{max}$ or small $\Delta w$ [S1, unofficial].
*   **Boundaries:** The method assumes a closed mesh or well-defined surfaces. For open surfaces, the "downward offset" direction must be carefully defined (e.g., along the normal) [S1, unofficial].
*   **Degenerate Input:** If $z_{min} = z_{max}$, the camera sampling interval formula becomes undefined. The method requires a depth range [S1, unofficial].
*   **Non-Lambertian Effects:** The explicit 3DGS representation is limited in modeling non-Lambertian effects. The method requires the Neural Illumination Enhancement module for such cases [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The initialization step is linear with respect to the number of sampled points on the mesh, which is determined by $\Delta w$. The optimization step involves path-traced renderings and EMA updates, which are computationally intensive but optimized for real-time shared rendering [S1, unofficial].
*   **Memory Complexity:** The memory usage is proportional to the number of Gaussians, which is minimized by the plenoptic sampling theory. The method achieves Nyquist-level performance, meaning it uses the minimum necessary Gaussians for the given resolution and depth range [S1, unofficial].
*   **Measured Performance:** The method surpasses state-of-the-art baselines in both qualitative and quantitative metrics for global illumination rendering [S1, unofficial].
*   **Strengths:**
    *   Theoretically grounded initialization reduces trial-and-error.
    *   Efficient caching of global illumination in dynamic scenes.
    *   Supports real-time shared rendering with noisy 1-spp path-traced renderings [S1, unofficial].
*   **Limitations:**
    *   Requires mesh geometry as input.
    *   Limited in modeling non-Lambertian effects without the neural enhancement module [S1, unofficial].
*   **When to Use:** When high-quality global illumination caching is required, and mesh geometry is available. Particularly suitable for real-time shared rendering applications [S1, unofficial].
*   **When Not to Use:** When mesh geometry is not available, or when the scene is primarily non-Lambertian and the neural enhancement module is not desired [S1, unofficial].

## Background
The method was introduced in the paper "Mesh2GS: White-Box 3DGS Construction via Plenoptic Sampling" [S1, unofficial]. It is based on plenoptic sampling theory, which derives the minimum sampling rate for light fields. The method addresses the limitations of heuristic 3DGS construction methods (e.g., SuGaR, GaussianMesh) by providing a rigorous formulation for Gaussian distribution and camera sampling density [S1, unofficial]. It is used for high-quality global illumination rendering and real-time shared rendering applications [S1, unofficial].
