# AnySplat Pipeline

Also called: Feed-forward 3D Gaussian Splatting from Unconstrained Views

## Overview
The AnySplat pipeline is a feed-forward method for novel-view synthesis that predicts a complete set of 3D Gaussians and camera poses directly from uncalibrated input images [S1, unofficial]. It differs from iterative optimization methods by using a transformer-based encoder-decoder architecture to regress scene geometry and appearance in a single forward pass [S1, unofficial]. Unlike sibling methods that may assume calibrated inputs or fixed grids, AnySplat handles unconstrained views by jointly predicting depth and poses, utilizing a differentiable voxelization module to bridge pixel-wise predictions with a global 3D representation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A tensor of $K$ uncalibrated RGB images. The standard input shape is $[1, K, 3, 448, 448]$ (batch, views, channels, height, width) [S1, unofficial].
*   **Outputs:** A set of 3D Gaussians $\mathcal{G}$ (parameters $\mu, \sigma, r, s, c$) and predicted camera poses (extrinsics $p_{ext}$ and intrinsics $p_{int}$) [S1, unofficial].

**Data Structures:**
The method constructs "pixel-wise 3D Gaussians" from the decoder outputs. These are subsequently voxelized into "pre-voxel 3D Gaussians" using a Differentiable Voxelization module [S1, unofficial]. The specific internal layout of the Gaussian parameter tensor is not explicitly detailed in the sources, but it comprises mean $\mu$, scale $\sigma$, rotation $r$, opacity $s$, and color $c$ [S1, unofficial].

**Steps:**
1.  **Encoding:** Input images are processed by a transformer-based geometry encoder to extract multi-scale features [S1, unofficial].
2.  **Decoding:** Three decoder heads ($F_G, F_D, F_C$) predict:
    *   $F_G$: Gaussian parameters ($\mu, \sigma, r, s, c$) [S1, unofficial].
    *   $F_D$: A depth map $D$ [S1, unofficial].
    *   $F_C$: Camera poses $p$ [S1, unofficial].
3.  **Construction:** The predicted parameters are used to construct a set of pixel-wise 3D Gaussians [S1, unofficial].
4.  **Voxelization:** The pixel-wise Gaussians are voxelized into pre-voxel 3D Gaussians using the Differentiable Voxelization module [S1, unofficial].
5.  **Rendering:** Multi-view images and depth maps are rendered from the voxelized Gaussians using differentiable rasterization [S1, unofficial].
6.  **Loss Computation:**
    *   **RGB Loss:** Rendered images are compared against ground truth RGB images [S1, unofficial].
    *   **Geometry Loss:** Rendered depth maps, decoded depth $D$, and predicted poses $p$ are used to compute geometry losses [S1, unofficial].
7.  **Supervision:** Geometries are supervised by pseudo-geometry priors obtained from a pretrained VGGT model [S1, unofficial].

**Parameters:**
*   Input resolution: 448x448 pixels [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Uncalibrated Inputs:** The method is designed for uncalibrated views, but accuracy depends on the quality of the pseudo-geometry priors from VGGT [S1, unofficial].
*   **Voxelization Artifacts:** The transition from pixel-wise to pre-voxel Gaussians via differentiable voxelization may introduce artifacts if the voxel grid resolution is mismatched to the scene scale [S1, unofficial].

## Subtopics

### [SubSplat](13524-subsplat.md)
SubSplat is a method for high-resolution novel-view synthesis that resolves the trade-off between network computational cost and rendering fidelity in pixel-aligned 3D Gaussian Splatting. It solves the problem of insufficient Gaussian density and artifacts when using low-resolution backbone inputs by introducing a Sub-pixel Gaussian Reparameterizer (SPGR). Unlike prior methods limited by fixed grids or image-space upsamplers, SubSplat subdivides each grid-anchored primary Gaussian into multiple fine-grained sub-pixel primitives, restoring structural density directly from low-resolution features while maintaining stable network latency.

### [Deformable Radial Kernel (DRK)](13699-deformable-radial-kernel-drk.md)
Deformable Radial Kernel (DRK) Splatting is a 3D scene representation method that replaces the fixed radial symmetry of Gaussian primitives with a flexible planar kernel defined by multiple radial basis functions. It solves the overparameterization and geometric fidelity limitations of Gaussian Splatting by allowing adaptive stretching, rotation, and sharp boundary control, enabling high-fidelity rendering with significantly fewer primitives. Unlike standard 2D Gaussian Splatting, which relies on smooth, elliptical distributions, DRK supports straight edges and sharp corners through L1/L2 norm blending and piecewise edge sharpening.

## Background
AnySplat was introduced by InternRobotics as a feed-forward approach to 3D Gaussian Splatting [S1, unofficial]. It builds on the principles of differentiable rendering and transformer-based geometry estimation [S1, unofficial]. The method utilizes a pretrained VGGT model to provide pseudo-geometry priors, which guide the training of the Gaussian prediction network [S1, unofficial].
