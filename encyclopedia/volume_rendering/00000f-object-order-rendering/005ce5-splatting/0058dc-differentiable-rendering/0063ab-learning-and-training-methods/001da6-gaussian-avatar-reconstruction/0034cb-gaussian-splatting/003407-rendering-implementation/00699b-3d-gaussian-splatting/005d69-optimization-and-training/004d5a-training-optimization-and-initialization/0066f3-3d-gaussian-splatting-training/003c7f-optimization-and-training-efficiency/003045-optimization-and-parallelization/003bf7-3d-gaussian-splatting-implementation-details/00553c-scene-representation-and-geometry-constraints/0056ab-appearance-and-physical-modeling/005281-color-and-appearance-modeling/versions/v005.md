# Color and Appearance Modeling

Also called: Appearance Modeling, View-Dependent Color, Radiance Modeling

## Overview
Color and Appearance Modeling in 3D Gaussian Splatting (3DGS) addresses the limitation of standard SH-based radiance representation, which struggles with high-frequency view-dependent effects, complex lighting, and photometric variations in unstructured data. It sets itself apart from standard 3DGS by decoupling appearance from static geometry or replacing the SH basis with neural fields, allowing for handling of transient objects, factorized illumination, and efficient compression.

## Shared principles
All methods in this family operate on the standard 3DGS rendering equation, where the pixel color $\hat{\mathbf{C}}$ is computed via alpha-blending of Gaussian contributions:
$$ \hat{\mathbf{C}} = \sum_{i \in N} T_i g_i(\mathbf{u} | \boldsymbol{\mu}', \boldsymbol{\Sigma}') \alpha_i \mathbf{c}_i(\omega) $$
where $T_i$ is transmittance, $g_i$ is the 2D Gaussian density, $\alpha_i$ is opacity, and $\mathbf{c}_i(\omega)$ is the view-dependent outgoing radiance. The core variation across methods lies in the definition and optimization of $\mathbf{c}_i(\omega)$ and potentially $\alpha_i$, moving beyond the fixed Spherical Harmonics (SH) coefficients $\mathbf{c}_i$ used in base 3DGS.

## Subtopics

### DAVIGS
DAVIGS is a plug-and-play appearance modeling method that mitigates appearance variation-induced floaters and color distortions by applying an affine transformation to the rendered image at the image level [12021-davigs.md]. Unlike coupled methods that manipulate Gaussian properties (slowing rendering) or decoupled methods that only account for mild global variations, DAVIGS decouples global view-dependent appearance variations (e.g., daylight, ISPs) from local spatial changes (e.g., street lamps) by applying an affine transformation to the final rendered image [12021-davigs.md]. This approach ensures 3D consistency across views while retaining the low-cost advantage of decoupled modeling, as the appearance module can be discarded after optimization without impacting rendering speed [12021-davigs.md].

### [3iGS (Factorised Tensorial Illumination for 3D Gaussian Splatting)](13977-3igs-factorised-tensorial-illumination-for-3d-gaussian-splat.md)
3iGS enhances 3D Gaussian Splatting by modeling outgoing radiance as a function of a continuous local illumination field and individual Gaussian BRDF attributes, rather than optimizing outgoing radiance in isolation [13977-3igs-factorised-tensorial-illumination-for-3d-gaussian-splat.md]. It differs from its sibling SWAG by using a factorised tensor grid for local illumination and a neural network for specular shading, whereas SWAG conditions Gaussians on external appearance variables like image ID or camera pose [13977-3igs-factorised-tensorial-illumination-for-3d-gaussian-splat.md].

### [Spherical Harmonics Optimization](14206-spherical-harmonics-optimization.md)
Spherical Harmonics (SH) Optimization encompasses techniques to reduce the memory footprint, computational cost, and training time of 3DGS by modifying the SH representation of Gaussian radiance. It addresses the high parameter count (48 coefficients per Gaussian for degree 3) and the redundancy of higher-order coefficients in standard training. It sets itself apart from siblings like DAVIGS and SWAG by focusing on compression and efficiency of the existing SH basis rather than introducing new appearance conditioning or factorized illumination models [14206-spherical-harmonics-optimization.md].

### [SWAG (Splatting in the Wild images with Appearance-conditioned Gaussians)](14315-swag-splatting-in-the-wild-images-with-appearance-conditione.md)
SWAG is an extension of 3DGS designed to reconstruct 3D scenes from unstructured, in-the-wild image collections that exhibit significant photometric variations and contain transient occluders (e.g., tourists, clouds) [14315-swag-splatting-in-the-wild-images-with-appearance-conditione.md]. It differs from standard 3DGS by decoupling appearance modeling from static geometry: it uses per-image embeddings and a neural network to predict image-dependent color and opacity variations, while simultaneously identifying and isolating transient objects into separate "transient Gaussians" to prevent them from causing floaters or blurring the static scene reconstruction [14315-swag-splatting-in-the-wild-images-with-appearance-conditione.md]. Unlike 3iGS, which focuses on factorized tensorial illumination, SWAG explicitly handles transient occlusion and appearance interpolation via latent embeddings [14315-swag-splatting-in-the-wild-images-with-appearance-conditione.md].

### Compact View-dependent Color
#### definition
- A method to represent view-dependent color using a grid-based neural field instead of storing Spherical Harmonics (SH) coefficients per Gaussian, reducing parameters from 48 to a shared grid [S1].
#### step
- Contract unbounded positions $p \in \mathbb{R}^3$ to a bounded range using the contraction function from mip-NeRF 360 [S1].
- Input positions into hash grids, then feed the resulting feature and view direction into the tiny MLP [S1].
- Use 0-degree components of SH (same channels as RGB, not view-dependent) and convert to RGB colors [S1].
#### formula
- Contraction function: $\text{contract}(p_n) = p_n$ if $\|p_n\| \le 1$, else $\frac{p_n}{\|p_n\|} (2 - \|p_n\|)$ [S1].
- View-dependent color $c_n(d)$ is computed as: $c_n(d) = f(\text{contract}(p_n), d; \theta)$, where $f$ is a tiny MLP with parameters $\theta$ [S1].
#### comparison
- Original 3DGS uses 48 parameters per Gaussian for SH (max 3 degrees) to model view-dependent color; this method uses a shared grid-based neural field [S1].

## Background
The standard 3D Gaussian Splatting method [G] uses Spherical Harmonics (SH) to represent view-dependent color, which requires 48 coefficients per Gaussian for degree 3. This approach is parameter-inefficient and struggles with complex lighting and transient objects in unstructured data. Subsequent works have introduced various appearance modeling techniques to address these limitations, including decoupled appearance modules [12021-davigs.md], factorized illumination [13977-3igs-factorised-tensorial-illumination-for-3d-gaussian-splat.md], and neural field-based color representations [S1].
