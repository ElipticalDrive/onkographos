# Validation Metric Computation & Logging

Also called: Testing Loop Evaluation, Validation Metric Computation, Validation Metrics

## Overview
This method computes quantitative validation metrics (primarily PSNR) between rendered novel views and ground truth images, and saves example outputs for visual inspection [S1, unofficial]. It operates in evaluation mode with gradient tracking disabled, distinguishing it from the training optimization loop [S1, unofficial].

## How it works
**Inputs:**
- Model parameters and scene data containing training and testing camera poses [S1, S2, unofficial].
- `testing_iterations`: List of iterations at which validation metrics are computed and logged [S2, unofficial].

**Outputs:**
- Mean PSNR score for test and training subsets [S1, unofficial].
- Saved JPEG images of rendered novel views [S1, unofficial].

**Data Structures:**
- `psnr_list`: List of floating-point PSNR values collected during the validation pass [S1, unofficial].
- `validation_configs`: Dictionary mapping configuration names ('test', 'train') to camera lists [S2, unofficial].

**Steps:**
1. **Setup:** Clear the CUDA cache. Initialize `psnr_list` as empty. Select one random index `show_idx` for visualization [S1, unofficial].
2. **Trigger:** Check if the current training iteration exists in `testing_iterations`. If not, skip validation [S2, unofficial].
3. **Configuration:** Define `validation_configs` with two entries: `'test'` using all cameras from `scene.getTestCameras()`, and `'train'` using 5 evenly spaced cameras from `scene.getTrainCameras()` at indices 5 to 30 with a step of 5 [S2, unofficial].
4. **Iteration Loop:** For each camera index in the selected configuration:
   a. Fetch data for the view. Move all tensors to the GPU [S1, unofficial].
   b. Run the model forward pass with `is_train=False` inside a gradient-disabled context [S1, unofficial].
   c. Render the novel view. Apply background color compositing if applicable [S1, unofficial].
   d. **Metric Computation:** Clamp the rendered image and ground truth to $[0.0, 1.0]$. Compute the Peak Signal-to-Noise Ratio (PSNR) between the rendered image $I_{render}$ and ground truth $I_{gt}$:
      $$ \text{PSNR} = 10 \cdot \log_{10} \left( \frac{1}{\text{MSE}(I_{render}, I_{gt})} \right) $$
      where $\text{MSE}(I_{render}, I_{gt}) = \frac{1}{N} \sum_{i=1}^{N} (I_{render,i} - I_{gt,i})^2$ and $N$ is the number of pixels [G]. Accumulate PSNR (and L1 loss if required) across cameras [S2, unofficial]. Append the PSNR value to `psnr_list` [S1, unofficial].
   e. **Visualization:** If the current index equals `show_idx`: detach the tensor from the computation graph, multiply pixel values by 255, permute dimensions from CHW to HWC, convert to a NumPy array, and save as a JPEG file [S1, unofficial].
5. **Aggregation:** Compute the mean of `psnr_list`. Round the result to 4 decimal places. If the mean PSNR is less than 10, print an error message and exit. Log the final PSNR to the logger [S1, unofficial].

**Pseudocode:**
```python
def compute_validation_metrics(model, scene, testing_iterations, current_iter, logger):
    # Step 1: Setup
    clear_cuda_cache()
    psnr_list = []
    show_idx = random.randint(0, max(0, len(scene.getTestCameras()) - 1))

    # Step 2: Trigger
    if current_iter not in testing_iterations:
        return

    # Step 3: Configuration
    test_cameras = scene.getTestCameras()
    train_cameras = scene.getTrainCameras()
    train_sample_indices = list(range(5, 31, 5))
    train_sample_cameras = [train_cameras[i] for i in train_sample_indices if i < len(train_cameras)]
    validation_configs = {'test': test_cameras, 'train': train_sample_cameras}

    # Step 4: Iteration Loop
    for config_name, cameras in validation_configs.items():
        current_psnr_list = []
        for idx, camera in enumerate(cameras):
            # 4a: Fetch data
            data = fetch_data(camera, phase='val')
            for view in data:
                for key in data[view]:
                    data[view][key] = move_to_gpu(data[view][key])

            # 4b: Forward pass
            with disable_gradients():
                model.set_eval()
                rendered_data = model(data, is_train=False)
                rendered_img = rendered_data['novel_view']['img_pred'][0]
                rendered_img = apply_bg_color(rendered_img, bg_color=0.0)

            # 4c: Metric Computation
            gt_img = data['novel_view']['img_gt'][0]
            rendered_clamped = clamp(rendered_img, 0.0, 1.0)
            gt_clamped = clamp(gt_img, 0.0, 1.0)
            mse = mean_squared_error(rendered_clamped, gt_clamped)
            if mse == 0:
                psnr_val = 100.0
            else:
                psnr_val = 10 * math.log10(1.0 / mse)
            current_psnr_list.append(psnr_val)

            # 4d: Visualization
            if idx == show_idx:
                img_tensor = detach(rendered_img)
                img_tensor = img_tensor * 255
                img_tensor = permute(img_tensor, (1, 2, 0))
                img_np = to_numpy(img_tensor)
                save_as_jpeg(img_np, f"validation_{config_name}_{idx}.jpg")

        # Step 5: Aggregation
        mean_psnr = sum(current_psnr_list) / len(current_psnr_list)
        mean_psnr = round(mean_psnr, 4)
        if mean_psnr < 10:
            logger.error(f"Validation PSNR too low: {mean_psnr}")
            exit()
        logger.info(f"{config_name} PSNR: {mean_psnr}")
```

**Parameters:**
- `testing_iterations`: List of integers specifying training iterations to run validation [S2, unofficial].
- `bg_color`: Background color used for compositing transparent renders (default 0.0) [S1, unofficial].

**Edge Cases:**
- **MSE = 0:** If the rendered image is identical to the ground truth, PSNR is undefined due to $\log(0)$. Assign a high constant (e.g., 100.0) [G].
- **Empty Camera Lists:** If a configuration returns zero cameras, skip the loop or raise an error [G].
- **Index Out of Bounds:** When selecting training camera indices, ensure they do not exceed the list length [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources. Validation runs only at specified iterations, not every step [S2, unofficial].
- **Memory Complexity:** Not given in the sources. The CUDA cache is cleared before execution to manage memory [S1, unofficial].
- **Strengths:** Provides objective quantitative feedback (PSNR) and visual sanity checks (saved JPEGs) [S1, unofficial].
- **Limitations:** Computationally expensive if validation iterations are frequent [S2, unofficial].

## Background
This procedure is part of the training loop for differentiable rendering implementations, specifically noted in repositories handling stereo matching and novel view synthesis [S1, S2, unofficial]. It builds on the general rasterization and optimization loop defined in [Training Pipeline](5325-training-pipeline.md) [G].
