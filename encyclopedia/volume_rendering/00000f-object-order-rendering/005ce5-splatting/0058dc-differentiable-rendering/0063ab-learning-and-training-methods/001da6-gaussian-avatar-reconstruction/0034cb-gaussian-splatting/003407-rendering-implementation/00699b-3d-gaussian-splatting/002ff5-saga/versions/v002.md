# SAGA

Also called: OmniSeg3D-GS, SegAnyGaussians

## Overview
SAGA is a 2D promptable segmentation method lifted to 3D, leveraging the Segment Anything Model (SAM) for efficient segmentation within 3D Gaussian Splatting (3DGS) [S1, unofficial][S2]. It differs from sibling methods like [CoR-GS](1486-cor-gs.md) by relying on SAM's 2D segmentation capabilities to guide 3D Gaussian assignment rather than learned identity encodings or language features [S1, unofficial][S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D Gaussians reconstructed from images and 2D segmentation prompts (points, boxes, or masks) [S1, unofficial].
*   **Outputs:** A segmented 3D scene where Gaussians are classified into foreground/background or specific object instances based on the 2D prompts [S1, unofficial].

**Data Structures:**
*   **3D Gaussians:** Standard 3DGS representation [S1, unofficial].
*   **Layout details:** Not given in the sources.

**Steps:**
1.  **SAM Integration:** Leverage SAM to extract segmentation masks or features from input 2D views [S2].
2.  **Prompt Lifting:** Map 2D prompts to 3D space by associating 2D segmentation results with the corresponding 3D Gaussians [S1, unofficial][S2].
3.  **Gaussian Assignment:** Assign instance IDs or segmentation labels to individual 3D Gaussians based on their overlap with the 2D SAM-generated masks [S1, unofficial].
4.  **Feature Field:** Employ a low-dimensional feature field upsampled using a convolutional decoder to improve rendering efficiency [S2].

**Formulas:** Not given in the sources.

**Parameters:**
*   **SAM Model:** Uses the pre-trained Segment Anything Model [S2].
*   **Prompt Type:** Points, boxes, or masks [S1, unofficial].

**Edge Cases:** Not given in the sources.

## Subtopics

### SAGD
A variant of SAGA that also leverages SAM for efficient segmentation within 3DGS [S2]. It employs a low-dimensional feature field upsampled using a convolutional decoder to improve rendering efficiency [S2].

## Background
SAGA (also known as OmniSeg3D-GS or SegAnyGaussians) was introduced as a method to lift 2D promptable segmentation to 3D using 3DGS [S1, unofficial]. It leverages SAM for efficient segmentation within 3DGS [S2]. It is part of the broader trend of integrating foundation models into 3D Gaussian Splatting for editing and segmentation tasks [S1, unofficial][S2].
