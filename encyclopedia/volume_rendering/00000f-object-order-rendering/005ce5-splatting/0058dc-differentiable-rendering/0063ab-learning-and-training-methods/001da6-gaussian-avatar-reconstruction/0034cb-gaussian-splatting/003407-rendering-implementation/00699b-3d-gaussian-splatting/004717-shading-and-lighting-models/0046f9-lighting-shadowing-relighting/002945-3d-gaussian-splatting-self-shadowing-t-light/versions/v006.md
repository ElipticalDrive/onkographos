# 3D Gaussian Splatting Self-Shadowing (T_light)

Also called: 光源视角自阴影 (T_light)

## Overview
Calculates the self-shadowing transmittance $T_{light}$ for each Gaussian along a directional sun direction, representing the 'front occlusion transmittance' to model self-shadowing effects in volume rendering [S1, unofficial]. It differs from standard rasterization by performing a dedicated light-space pass that accumulates front-to-back occlusion without modifying the main camera's sampling expansion or applying amplitude compensation [S1, unofficial].

## How it works
**Inputs:**
- 3D Gaussian primitives (position, covariance, opacity, color).
- Sun direction vector.
- Configuration flags (`--tlight_voxel` for fallback, default rasterization).

**Outputs:**
- Per-Gaussian self-shadowing transmittance $T_{light}$ (stored in `record_front_tau` channel).
- Updated Gaussian attributes with gradients enabled for training.

**Data Structures:**
- `record_front_tau`: A buffer aligned with the Gaussian buffer, storing the accumulated front transmittance weighted by weight (energy-weighted mean over the sun-facing footprint).

**Steps:**

1. **Light Camera Setup:** Construct a virtual perspective camera to simulate a directional sun light source. Place it at a large distance with a narrow field of view (FOV) to minimize parallax error to below 2% and avoid modifying the EWA Jacobian [S1, unofficial].

2. **Rasterization Pass:** Perform a CUDA rasterization pass from the sun camera's perspective. Traverse Gaussians in depth order relative to the sun camera [S1, unofficial].

3. **Transmittance Accumulation:** For each Gaussian, calculate its contribution to the front occlusion. Record the accumulated front transmittance $\tau$ weighted by $\tau \times \text{weight}$ into the `record_front_tau` channel. This represents an energy-weighted mean over the entire sun-facing footprint, not just a center point sample [S1, unofficial].

4. **Gradient Handling:** Enable full continuous gradients by default. This includes gradients for $\tau$, weights, normalization, weak density backup transmittance, and projection position/scale/rotation. However, treat sun camera framing, sorting, coverage, and threshold branches as constants to prevent incorrect gradient propagation [S1, unofficial].

5. **Covariance Handling:** Do not expand the projection covariance by $0.3I$ during this light pass, and do not apply amplitude compensation. Keep the sampling expansion from the main camera pass as is [S1, unofficial].

6. **Deeply Buried Gaussians:** Handle deeply buried Gaussians (where early termination causes $wsum=0$) by explicitly mapping them to full shadow to prevent inversion artifacts [S1, unofficial].

7. **Fallback Mode:** If the `--tlight_voxel` flag is passed, use the old $128^3$ voxel cache path. This is compatible with models trained before rasterization support was added [S1, unofficial].

**Pseudocode:**

```python
def compute_tlight(gaussians, sun_direction, use_voxel_fallback=False):
    """
    Compute self-shadowing transmittance T_light for Gaussians.
    
    Args:
        gaussians: List of Gaussian primitives with position, covariance, opacity, etc.
        sun_direction: 3D vector representing the sun direction.
        use_voxel_fallback: Boolean flag to use old voxel cache path.
        
    Returns:
        t_light: Array of transmittance values for each Gaussian.
    """
    if use_voxel_fallback:
        # Fallback to old 128^3 voxel cache path
        return compute_tlight_voxel_fallback(gaussians, sun_direction)
    
    # Step 1: Setup light camera
    light_camera = setup_light_camera(sun_direction, distance=large, fov=narrow)
    
    # Step 2: Rasterize from light camera perspective
    # Sort Gaussians by depth relative to light camera
    sorted_gaussians = sort_by_depth(gaussians, light_camera)
    
    # Initialize transmittance buffer
    t_light = zeros(len(gaussians))
    accumulated_tau = 1.0  # Initial transmittance
    
    # Step 3: Accumulate front transmittance
    for gaussian in sorted_gaussians:
        # Calculate footprint contribution
        # Energy-weighted mean over sun-facing footprint
        footprint_weight = gaussian.weight * gaussian.opacity
        
        # Update accumulated transmittance
        # tau is the front occlusion transmittance
        tau = accumulated_tau * footprint_weight
        
        # Record into buffer (conceptually)
        # record_front_tau[gaussian.id] = tau
        
        # Update accumulated transmittance for next Gaussian
        # Note: In volume rendering, T_light is typically the transmittance
        # from the light source to the current point.
        # The description says "accumulated front transmittance tau weighted by tau * weight"
        # This implies T_light for a Gaussian is the transmittance reaching it.
        
        # Check for deeply buried Gaussians
        if accumulated_tau is effectively_zero:
            t_light[gaussian.id] = 0.0  # Full shadow
        else:
            t_light[gaussian.id] = accumulated_tau
            
        # Update accumulated transmittance for the next Gaussian in depth order
        # This is a simplification; actual implementation may vary based on exact volume rendering equation
        accumulated_tau *= (1.0 - gaussian.opacity)
        
    return t_light

def setup_light_camera(sun_direction, distance, fov):
    """
    Setup a virtual camera to simulate directional light.
    
    Args:
        sun_direction: 3D vector for sun direction.
        distance: Large distance to minimize parallax.
        fov: Narrow field of view.
        
    Returns:
        Camera object with projection matrix.
    """
    # Place camera at large distance along sun direction
    camera_position = sun_direction * distance
    camera_target = vec3(0, 0, 0)
    camera_up = vec3(0, 1, 0)
    
    # Create perspective camera with narrow FOV
    camera = PerspectiveCamera(position=camera_position, target=camera_target, up=camera_up, fov=fov)
    return camera

def sort_by_depth(gaussians, camera):
    """
    Sort Gaussians by depth relative to camera.
    
    Args:
        gaussians: List of Gaussians.
        camera: Camera object.
        
    Returns:
        Sorted list of Gaussians.
    """
    # Project Gaussian centers to camera space
    depths = [project_depth(g, camera) for g in gaussians]
    
    # Sort Gaussians by depth (front to back)
    sorted_indices = argsort(depths)
    sorted_gaussians = [gaussians[i] for i in sorted_indices]
    
    return sorted_gaussians

def project_depth(gaussian, camera):
    """
    Project Gaussian center to camera space and return depth.
    
    Args:
        gaussian: Gaussian primitive.
        camera: Camera object.
        
    Returns:
        Depth value.
    """
    # Transform Gaussian center to camera space
    center_cam = camera.world_to_camera(gaussian.position)
    return center_cam.z
```

**Parameters:**
- `--tlight_voxel`: Flag to enable old $128^3$ voxel cache fallback path [S1, unofficial].
- `--tlight auto|voxel|raster`: Viewer flag to control shadow source (auto reads training cfg_args) [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Deeply Buried Gaussians:** If early termination causes $wsum=0$, explicitly map to full shadow to prevent inversion artifacts [S1, unofficial].
- **Gradient Propagation:** Treat sun camera framing, sorting, coverage, and threshold branches as constants to prevent incorrect gradient propagation [S1, unofficial].
- **Covariance Expansion:** Do not expand projection covariance by $0.3I$ or apply amplitude compensation during the light pass [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of Gaussians and the rasterization pass. The light-space rasterization adds an additional pass over the Gaussians.
- **Memory Complexity:** Requires additional buffer for `record_front_tau` aligned with the Gaussian buffer.
- **Strengths:** Provides accurate self-shadowing effects in volume rendering. Compatible with existing training pipelines.
- **Limitations:** Requires additional computation for the light pass. Fallback mode may be less efficient or accurate than rasterization.
- **When to Use:** When self-shadowing effects are desired in 3D Gaussian Splatting scenes.
- **When Not to Use:** When performance is critical and self-shadowing is not necessary.

## Background
Originated in the context of 4D Gaussian Splatting for volume cloud rendering [S1, unofficial]. The method was developed to address the lack of self-shadowing in standard 3D Gaussian Splatting rendering. It builds on the principles of volume rendering and light-space rasterization.
