# Gaussian Extraction Algorithm
Also called: Discretization Algorithm, Octree-Guided Geometry Sampling, Optimizing Geometry with GauPF, Octree-guided Sampling

## Overview
The Gaussian Extraction Algorithm extracts discrete 3D Gaussian primitives from continuous Gaussian Splatting Functions (GauPF) at arbitrary densities. It solves the problem of converting a continuous probabilistic representation into a finite set of splattable Gaussians, analogous to how Marching Cubes extracts meshes from Signed Distance Functions. It is distinguished from sibling methods by its use of an octree-guided progressive sampling strategy to locate high-probability regions, followed by gradient-based optimization of proxy points, rather than fixed-grid voxelization or direct mesh embedding.

## How it works
**Inputs and Outputs:**
*   **Input:** A trained Gaussian Probability Function $\psi_{pf}$ (neural network), a Gaussian Color Function $\psi_{cf}$, a Gaussian Transform Function $\psi_{tf}$, a latent triplane representation $t$, and a target number of Gaussians $N$.
*   **Output:** A set of $N$ discrete 3D Gaussians $\hat{G} = \{\hat{\sigma}_i, \hat{c}_i, \hat{r}_i, \hat{s}_i, \hat{o}_i\}_{i=1}^N$, where $\hat{\sigma}_i$ is the center, $\hat{c}_i$ is the color, and $\{\hat{r}_i, \hat{s}_i, \hat{o}_i\}$ are rotation, scale, and opacity.

**Data Structures:**
*   **Octree:** A hierarchical 3D grid structure used to partition the space. It is built progressively over $L$ layers. Each node represents a cubic region.
*   **Proxy Points:** A set of learnable 3D coordinates $\{\rho_i\}_{i=1}^N$. These act as initial estimates for Gaussian centers.

**Steps:**
1.  **Octree Construction:** Build an octree progressively over $L$ layers. At each depth, identify 3D regions with large probabilities using $\psi_{pf}$ and subdivide them. This focuses computational resources on high-density areas [S1].
2.  **Coarse Sampling:** After $L$ layers of subdivision, uniformly sample $N$ 3D points within the leaf nodes of the octree. These points form the initial proxy points $\{\rho_i\}_{i=1}^N$ [S1].
3.  **Geometry Optimization:** Optimize the positions of the proxy points $\rho_i$ to maximize the probability assigned by $\psi_{pf}$. The positions are treated as learnable parameters. The loss function is:
    $$
    L_{Geo} = -\frac{1}{N} \sum_{i=1}^N \psi_{pf}(\rho_i)
    $$
    Gradient descent updates $\rho_i$ to converge to the locations $\{\hat{\sigma}_i\}_{i=1}^N$ with the highest probabilities in the continuous GauPF [S1].
4.  **Attribute Extraction:** For each optimized center $\hat{\sigma}_i$, extract color and transform attributes using the latent triplane $t$ and the respective functions:
    $$
    \hat{c}_i = \psi_{cf}(\text{interp}(t, \hat{\sigma}_i))
    $$
    $$
    \{\hat{r}_i, \hat{s}_i, \hat{o}_i\} = \psi_{tf}(\text{interp}(t, \hat{\sigma}_i))
    $$
    Here, $\text{interp}(t, \hat{\sigma}_i)$ retrieves the latent features at location $\hat{\sigma}_i$ from the triplane $t$ [S1].

**Pseudocode:**
```python
def gaussian_extraction_algorithm(psf, pcf, ptf, triplane_t, num_gaussians, octree_depth):
    """
    Extracts discrete Gaussians from continuous functions.
    
    Args:
        psf: Gaussian Probability Function (neural net returning scalar prob)
        pcf: Gaussian Color Function (neural net returning color vector)
        ptf: Gaussian Transform Function (neural net returning rot, scale, opac)
        triplane_t: Latent triplane tensor
        num_gaussians: N, target number of Gaussians
        octree_depth: L, number of octree subdivision layers
        
    Returns:
        centers: (N, 3) optimized Gaussian centers
        colors: (N, 3) extracted colors
        transforms: (N, 4+3+1) extracted rotations, scales, opacities
    """
    
    # Step 1 & 2: Octree-guided coarse sampling
    # Build octree and sample initial proxy points
    proxy_points = octree_guided_sampling(psf, octree_depth, num_gaussians)
    
    # Step 3: Optimize geometry
    # Initialize proxy points as learnable tensors
    proxy_points.requires_grad = True
    optimizer = torch.optim.Adam([proxy_points], lr=0.01)
    
    # Optimization loop
    for iteration in range(1000): # Not given in sources; typical optimization steps
        optimizer.zero_grad()
        # Loss is negative probability to maximize it
        probs = psf(proxy_points)
        loss = -torch.mean(probs)
        loss.backward()
        optimizer.step()
        
    # Get optimized centers
    centers = proxy_points.detach()
    
    # Step 4: Extract attributes
    # Interpolate latent features from triplane at center locations
    latent_features = interpolate_triplane(triplane_t, centers)
    
    # Predict color
    colors = pcf(latent_features)
    
    # Predict transforms (rotation, scale, opacity)
    transforms = ptf(latent_features)
    
    return centers, colors, transforms

def octree_guided_sampling(psf, depth, num_points):
    """
    Builds an octree and samples points from high-probability leaves.
    """
    # Initialize root node covering bounding box
    root = OctreeNode(bounding_box)
    
    # Progressive subdivision
    for layer in range(depth):
        # Identify regions with high probability
        high_prob_nodes = []
        for node in root.get_leaves():
            prob = psf(node.center)
            if prob > threshold: # Threshold not given in sources
                high_prob_nodes.append(node)
        
        # Subdivide high-probability nodes
        for node in high_prob_nodes:
            node.subdivide()
            
    # Uniformly sample N points from remaining leaves
    leaves = root.get_leaves()
    points = []
    points_per_leaf = num_points // len(leaves)
    remainder = num_points % len(leaves)
    
    for i, leaf in enumerate(leaves):
        count = points_per_leaf + (1 if i < remainder else 0)
        # Uniform random sampling within leaf bounding box
        leaf_points = random_uniform_in_box(leaf.bounding_box, count)
        points.extend(leaf_points)
        
    return torch.tensor(points)

def interpolate_triplane(triplane, points):
    """
    Interpolates latent features from triplane at 3D points.
    """
    # Extract features from XY, YZ, XZ planes
    # This is a standard triplane lookup operation
    # Not given in sources; assumed standard implementation
    features_xy = sample_2d(triplane[0], points[:, [0, 1]])
    features_yz = sample_2d(triplane[1], points[:, [1, 2]])
    features_xz = sample_2d(triplane[2], points[:, [0, 2]])
    
    # Concatenate or average features
```

**Parameters:**
*   $N$: Target number of Gaussians. Can be arbitrary [S1].
*   $L$: Number of octree subdivision layers. Not given in sources.
*   Learning rate for geometry optimization: Not given in sources.

**Edge Cases and Pitfalls:**
*   **Sampling Accuracy:** Uniform sampling after octree subdivision may not accurately reach the exact locations of largest probabilities without the optimization step [S1].
*   **Computational Cost:** Direct inference on a dense grid is computationally expensive; the octree strategy mitigates this by focusing on high-probability regions [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the octree depth $L$ and the number of optimization iterations. The octree construction is logarithmic in space but requires evaluating $\psi_{pf}$ at many nodes. Optimization is iterative.
*   **Memory Complexity:** Proportional to the number of Gaussians $N$ and the size of the neural networks $\psi_{pf}, \psi_{cf}, \psi_{tf}$.
*   **Strengths:** Allows generation of 3DGS at arbitrary numbers and densities. Scalable and efficient compared to dense grid sampling. Generates native 3DGS without voxelization, preserving quality [S1].
*   **Limitations:** Requires a trained continuous function ($\psi_{pf}$). Optimization can be slow for large $N$.
*   **When to use:** When generating 3DGS from continuous latent representations (e.g., diffusion models) where flexible density control is needed.

## Background
The algorithm was introduced in **DiffGS: Functional Gaussian Splatting Diffusion** by Zhou et al. (2024) [S1]. It is designed to discretize Gaussian Splatting Functions generated by a latent diffusion model, enabling tasks like unconditional generation, text/image-conditioned generation, and completion. The approach is inspired by the Marching Cubes algorithm for mesh extraction from SDFs [S1].
