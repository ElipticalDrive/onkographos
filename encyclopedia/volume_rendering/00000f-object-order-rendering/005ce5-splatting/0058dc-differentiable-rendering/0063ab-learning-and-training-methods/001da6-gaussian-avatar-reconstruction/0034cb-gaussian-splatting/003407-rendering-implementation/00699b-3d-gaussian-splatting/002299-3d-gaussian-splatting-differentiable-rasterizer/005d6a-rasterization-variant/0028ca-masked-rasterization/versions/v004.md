# Masked-Rasterization


## Overview
Masked-rasterization is a differentiable rendering technique that allows "masked" (probabilistically unused) 3D Gaussians to participate in the rasterization pipeline and receive gradient updates, rather than being strictly culled. It solves the problem of gradient starvation in dynamic pruning scenarios, where Gaussians with zero opacity or scale are filtered out before rasterization and thus cannot update their existence probability [S1]. Unlike standard rasterization variants that treat Gaussians as binary present/absent entities based on static attributes, this method applies masks during the blending process to enable dynamic assessment of a Gaussian's contribution [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 3D Gaussians $G_i$, each defined by center $\boldsymbol{\mu}_i$, covariance $\boldsymbol{\Sigma}_i$, opacity $\alpha_i$, and a learned existence mask $m_i \in [0, 1]$. The mask $m_i$ represents the probability of the Gaussian's existence.
*   **Outputs:** Final pixel color $C$ and gradients for Gaussian attributes and masks.

**Data Structures:**
*   **Gaussian Attributes:** Standard 3DGS attributes (position, scale, rotation, opacity, color).
*   **Mask:** A scalar value $m_i$ per Gaussian, sampled from a distribution representing existence probability [S1].

**Steps:**
1.  **Standard Splatting:** Project all 3D Gaussians to 2D screen space using the standard projection pipeline (extrinsic/intrinsic matrices, Jacobian transformation) [S1, 4526-differentiable-radiative-rasterization]. Compute the 2D alpha value $\alpha_i$ for each Gaussian based on its center, scale, and rotation [S1].
2.  **Alpha Filtering:** Filter out splats with exactly zero $\alpha_i$ values. All other splats, including those with non-zero $\alpha_i$ but masked ($m_i < 1$), proceed to the masked-rasterization stage [S1].
3.  **Mask Sampling:** For each Gaussian, sample a differentiable mask $m_i$ from its existence distribution. This mask indicates whether the Gaussian is "present" or "absent" for the current iteration [S1].
4.  **Masked Blending:** Iterate through the sorted list of Gaussians for each pixel. Apply the mask $m_i$ to two specific components of the standard alpha-blending equation:
    *   **Transmittance Attenuation:** Modify the transmittance $T_i$ evolution using the mask.
    *   **Color Accumulation:** Modify the color contribution $c_i$ using the mask.
    
    The specific equations (referenced as Eq 3 and Eq 4 in the source) integrate $m_i$ into the blending loop. A masked Gaussian ($m_i \approx 0$) does not contribute to the final pixel color significantly, but its presence in the blending loop allows it to receive gradients with respect to $m_i$ [S1].
5.  **Gradient Update:**
    *   Gaussians with $m_i < 1$ do **not** receive gradients for their standard attributes ($\alpha_i$, scale, rotation) [S1].
    *   They **do** receive gradients for their mask $m_i$, allowing the existence probability to be updated based on their "virtual" contribution to the loss [S1].

**Pseudocode:**
```python
def masked_rasterization(gaussians, masks, camera_params):
    """
    gaussians: List of Gaussian objects with attributes (mu, Sigma, alpha, color)
    masks: List of scalar mask values m_i for each Gaussian
    camera_params: Extrinsic and intrinsic matrices
    
    Returns: Final image color buffer
    """
    # 1. Project all Gaussians to 2D
    projected_gaussians = []
    for i, g in enumerate(gaussians):
        # Standard projection: transform 3D center to 2D, transform covariance
        u_i, Sigma_2d_i = project_to_screen(g.mu, g.Sigma, camera_params)
        
        # Compute 2D alpha from attributes
        alpha_i = compute_2d_alpha(u_i, Sigma_2d_i, g.scale, g.rotation)
        
        # 2. Alpha Filtering: Skip if alpha is exactly zero
        if alpha_i == 0:
            continue
            
        projected_gaussians.append({
            'index': i,
            'u': u_i,
            'Sigma': Sigma_2d_i,
            'alpha': alpha_i,
            'color': g.color,
            'mask': masks[i] # Pass the mask along
        })
    
    # 3. Sort by depth (standard step)
    projected_gaussians.sort(key=lambda x: x['depth'])
    
    # 4. Initialize image buffer and transmittance
    image = zeros_like(target_resolution)
    transmittance = ones_like(target_resolution)
    
    # 5. Masked Blending Loop
    for g in projected_gaussians:
        # Evaluate Gaussian at pixel locations within its bounding box
        # This returns a mask of pixels covered by this Gaussian
        pixel_mask, alpha_at_pixel = evaluate_gaussian_coverage(g)
        
        # Apply the existence mask m_i to the blending process
        m = g['mask']
        
        # Modified Transmittance: Attenuate transmittance based on masked alpha
        # Standard: T_new = T_old * (1 - alpha)
        # Masked: The source states masks are applied to transmittance evolution.
        # Effectively, the contribution to transmittance drop is scaled by m.
        alpha_effective = alpha_at_pixel * m
        
        # Update transmittance
        transmittance[pixel_mask] *= (1 - alpha_effective[pixel_mask])
        
        # Modified Color Accumulation: Scale color contribution by m
        # Standard: C_new += T_old * alpha * color
        # Masked: Scale the color term by m
        color_contribution = transmittance[pixel_mask] * alpha_at_pixel[pixel_mask] * g['color']
        
        # The source implies the mask modulates the accumulation.
        # If m=0, no color is added, but the Gaussian remains in the list.
        image[pixel_mask] += color_contribution * m
        
    return image
```

**Edge Cases and Pitfalls:**
*   **Zero Alpha Filtering:** If a Gaussian's opacity or scale is set to zero, its $\alpha_i$ becomes zero. Standard rasterizers filter these out *before* the blending loop. This prevents them from receiving any gradient updates, causing them to become "outdated" and unable to adjust their existence probability [S1]. Masked-rasterization must ensure that Gaussians with non-zero $\alpha_i$ but zero mask are still processed in the blending loop to receive mask gradients [S1].
*   **Gradient Isolation:** It is critical that masked Gaussians do *not* receive gradients for their geometric attributes (scale, rotation, position) if they are effectively "off". The source specifies that masked splats do not receive gradients for $\alpha_i$ or normal attributes, only for the mask $m_i$ [S1].

## Operating characteristics
*   **Performance:** The method enables pruning over 60% of Gaussians on average with only a 0.02 PSNR decline [S1]. It achieves rendering speedups of $2.05\times$, $2.19\times$, and $3.16\times$ on Mip-NeRF360, Tanks & Temples, and Deep Blending datasets, respectively [S1].
*   **Quality:** Substantially outperforms previous pruning methods that multiply masks with Gaussian attributes (opacity/scale), which lead to drastic quality decreases due to gradient starvation [S1].
*   **Memory:** No significant additional memory overhead compared to standard 3DGS, as the mask is a single scalar per Gaussian.

## Background
**Origin:** Introduced in "MaskGaussian: Adaptive 3D Gaussian Representation from Probabilistic Masks" (CVPR 2025) by researchers from Shanghai AI Laboratory [S1].
**History:** Previous pruning methods [4, 17, 34] failed to address gradient starvation by multiplying masks with scales or opacities, which resulted in zero density alpha and prevented gradient updates [S1]. MaskGaussian addresses this by modeling Gaussians as probabilistic entities and using masked-rasterization to allow unused but probabilistically existing Gaussians to receive gradients [S1].
