# Transmittance of Gaussian Splatting

Also called: Proposition 2, Ray-marching equivalence of Gaussian Splatting

## Overview
This method establishes that the image formation model of Gaussian Splatting (alpha-blending) is equivalent to a ray-marching volumetric rendering model under assumptions of statistical independence and non-overlapping Gaussian primitives [S1]. It defines a continuous transmittance function and a view-dependent attenuation coefficient that yield the exact same color output as the standard discrete alpha-compositing rasterizer [S1].

## How it works
**Inputs:**
- Ray origin $\mathbf{o} \in \mathbb{R}^3$ (in empty space) [S1].
- Ray direction $\mathbf{w} \in \mathbb{S}^2$ [S1].
- Distance parameter $t \in [0, +\infty)$ [S1].
- Set of $N$ 3D Gaussians $\{G_i\}_{i=1}^N$, where each $G_i(\mathbf{x})$ is the Gaussian density function at position $\mathbf{x}$ [S1].
- View-dependent colors $\mathbf{c}_i(\mathbf{w})$ for each Gaussian [S1].

**Outputs:**
- Total transmittance $T_{\mathbf{o}, \mathbf{w}}(t)$ [S1].
- Rendered color $C_{\mathbf{o}, \mathbf{w}}$ [S1].

**Data Structures:**
- Gaussian primitives are stored as a list or array [S1].
- Each primitive $i$ contains parameters defining $G_i(\mathbf{x})$ (mean, covariance) and color $\mathbf{c}_i$ [S1].
- No explicit volumetric grid is required; the attenuation is computed analytically from the Gaussian parameters [S1].

**Steps:**
1. Derive total transmittance from statistical independence: the total attenuation coefficient is the sum of individual coefficients ($\sigma = \sum \sigma_i$) [S1]. Under exponential transport, total transmittance becomes the product of individual transmittances: $T_{\mathbf{o}, \mathbf{w}}(t) = \exp \left( - \int_0^t \sum_i \sigma_i(\mathbf{o} + s\mathbf{w}, \mathbf{w}) ds \right) = \prod_i T_{\mathbf{o}, \mathbf{w}}^{(i)}(t)$ [S1].
2. Apply the single-Gaussian transmittance identity to obtain $T_{\mathbf{o}, \mathbf{w}}(t) = \prod_{i=1}^N (1 - \bar{G}_{\mathbf{o}, \mathbf{w}}^{(i)}(t))$ [S1].
3. Verify equivalence by comparing rendered color values: order $M$ Gaussians with positive projection along the ray by increasing distance from $\mathbf{o}$ [S1]. Define intervals $t_0=0 < t_1 < \dots < t_M=+\infty$ such that within $[t_{i-1}, t_i]$, only Gaussian $i$ contributes significantly and previous Gaussians are fully attenuated [S1].
4. Substitute the interval boundaries into the volumetric color integral to recover the discrete alpha-blending sum [S1].

**Formulas:**
1. **Capped Gaussian Value:** Let $t_{\mathbf{o}, \mathbf{w}}^{G_i}$ be the distance along the ray where Gaussian $G_i$ reaches its maximum contribution [S1]. The capped Gaussian value along the ray is:
   $$ \bar{G}_{\mathbf{o}, \mathbf{w}}^{(i)}(t) = G_i(\mathbf{o} + \min(t, t_{\mathbf{o}, \mathbf{w}}^{G_i})\mathbf{w}) $$
   [S1]
2. **Continuous Transmittance Function:** The total transmittance from the origin to distance $t$ is the product of the individual transmittances of all $N$ Gaussians:
   $$ T_{\mathbf{o}, \mathbf{w}}(t) = \prod_{i=1}^N \left(1 - \bar{G}_{\mathbf{o}, \mathbf{w}}^{(i)}(t)\right) $$
   [S1]
3. **View-Dependent Attenuation Coefficient:** The attenuation coefficient $\sigma(\mathbf{x}, \mathbf{w})$ at position $\mathbf{x}$ for direction $\mathbf{w}$ is derived from the transmittance:
   $$ \sigma(\mathbf{x}, \mathbf{w}) = \sum_{i=1}^N \max(0, -\mathbf{w} \cdot \nabla \log(1 - G_i(\mathbf{x}))) $$
   [S1]
4. **Rendered Color:** Order $M$ Gaussians with positive projection along the ray by increasing distance from $\mathbf{o}$ [S1]. The color is:
   $$ C_{\mathbf{o}, \mathbf{w}} = \sum_{i=1}^M \mathbf{c}_i(\mathbf{w}) \bar{G}_{\mathbf{o}, \mathbf{w}}^{(i)}(t_{\mathbf{o}, \mathbf{w}}^{G_i}) \prod_{j=1}^{i-1} \left( 1 - \bar{G}_{\mathbf{o}, \mathbf{w}}^{(j)}(t_{\mathbf{o}, \mathbf{w}}^{G_j}) \right) $$
   [S1]
   This matches the standard alpha-blending formula [S1].

**Parameters:**
- Typical values are not given in the sources. [S1]

**Edge Cases and Pitfalls:**
- **Non-Reciprocity:** The attenuation coefficient is not reciprocal ($\sigma(\mathbf{x}, \mathbf{w}) \neq \sigma(\mathbf{x}, -\mathbf{w})$) because each Gaussian contributes to attenuation only before the ray reaches its point of maximum contribution [S1].
- **Overlap Assumption:** The equivalence relies on non-overlapping Gaussians; in practice, this is an approximation similar to alpha blending sorting [S1].
- **Numerical Stability:** If $G_i(\mathbf{x}) \approx 1$, the term $\log(1 - G_i(\mathbf{x}))$ approaches $-\infty$, requiring clamping or careful handling [G].

**Pseudocode:**
```python
def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def gaussian_eval(center, cov_inv, x):
    """Standard 3D Gaussian evaluation [G]."""
    diff = [x[0]-center[0], x[1]-center[1], x[2]-center[2]]
    quad = dot(diff, [cov_inv[0][0]*diff[0]+cov_inv[0][1]*diff[1]+cov_inv[0][2]*diff[2],
                       cov_inv[1][0]*diff[0]+cov_inv[1][1]*diff[1]+cov_inv[1][2]*diff[2],
                       cov_inv[2][0]*diff[0]+cov_inv[2][1]*diff[1]+cov_inv[2][2]*diff[2]])
    return max(0.0, 1.0 - 1e-6)  # Clamp to avoid log(0) in attenuation [G]

def render_gaussian_splatting_transmittance(ray_origin, ray_direction, gaussians):
    """
    Computes the transmittance and color for a ray using the 
    Transmittance of Gaussian Splatting equivalence.
    
    Args:
        ray_origin: 3D vector (o)
        ray_direction: 3D vector (w), normalized
        gaussians: List of dicts with keys: 'center', 'cov_inv', 'color'
    
    Returns:
        transmittance: float T(o, w, infinity)
        color: 3D vector C(o, w)
    """
    # 1. Filter and sort Gaussians by positive projection along the ray
    valid_gaussians = []
    for g in gaussians:
        vec_to_center = [g['center'][0]-ray_origin[0], g['center'][1]-ray_origin[1], g['center'][2]-ray_origin[2]]
        proj_dist = dot(vec_to_center, ray_direction)
        if proj_dist > 0:
            valid_gaussians.append((proj_dist, g))
            
    valid_gaussians.sort(key=lambda x: x[0])
    M = len(valid_gaussians)
    
    accumulated_transmittance = 1.0
    color = [0.0, 0.0, 0.0]
    
    for i in range(M):
        _, g = valid_gaussians[i]
        # t_max is the projection distance to the Gaussian center [G]
        t_max = dot([g['center'][0]-ray_origin[0], g['center'][1]-ray_origin[1], g['center'][2]-ray_origin[2]], ray_direction)
        
        point = [ray_origin[0]+ray_direction[0]*t_max, ray_origin[1]+ray_direction[1]*t_max, ray_origin[2]+ray_direction[2]*t_max]
        g_val = gaussian_eval(g['center'], g['cov_inv'], point)
        
        c_i = g['color']
        color[0] += c_i[0] * g_val * accumulated_transmittance
        color[1] += c_i[1] * g_val * accumulated_transmittance
        color[2] += c_i[2] * g_val * accumulated_transmittance
        
        accumulated_transmittance *= (1.0 - g_val)
        
    return accumulated_transmittance, color
```

## Background
This result is presented as "Proposition 2" in the paper "From Blobs to Spokes: High-Fidelity Surface Reconstruction via Oriented Gaussians" [S1]. It builds on the observation that alpha blending approximates volumetric rendering by sorting and compositing [S1]. The statistical independence assumption follows from RayGauss [S1]. The non-overlapping assumption is noted as an approximation similar to alpha blending sorting [S1].
