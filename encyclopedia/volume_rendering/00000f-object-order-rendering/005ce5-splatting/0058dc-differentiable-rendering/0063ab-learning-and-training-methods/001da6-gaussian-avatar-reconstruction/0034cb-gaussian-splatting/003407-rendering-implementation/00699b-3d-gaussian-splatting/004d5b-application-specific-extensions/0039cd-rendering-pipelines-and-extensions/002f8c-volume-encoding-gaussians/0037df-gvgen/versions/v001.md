# GVGEN
Also called: 3D Gaussian Volume, GVGEN
## Overview
GVGEN is a method for 3D generation that operates in 3D space using a 3D Gaussian volume representation [S1][S2, unofficial]. It is distinguished from sibling methods like GaussianCube, which converts a constant number of Gaussians into a voxelized representation via optimal transport, by maintaining a direct 3D Gaussian volume structure [S1][S2, unofficial].
