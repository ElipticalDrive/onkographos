# GlobalSplat

Also called: GlobalSplat: Efficient Feed-Forward 3D Gaussian Splatting via Global Scene Tokens

## Overview
GlobalSplat is a feed-forward 3D Gaussian Splatting framework that aligns multi-view inputs into a fixed set of global latent scene tokens before decoding explicit 3D geometry, preventing representation bloat and ensuring global consistency [S1]. Unlike sibling methods that form primitives in dense view-aligned spaces and align them globally afterward, GlobalSplat aggregates multi-view inputs into a fixed number of latent tokens (2048) regardless of the number of input views, then decodes these tokens into a fixed budget of Gaussians (16K) [S1]. This "align first, decode later" approach achieves a stronger large-context quality-efficiency trade-off compared to alternatives like C3G, which rely on full self-attention and single-Gaussian decoding [S1].

## How it works
GlobalSplat operates by normalizing the scene, extracting ray-augmented patch features, iteratively refining latent tokens via a dual-branch architecture, and decoding them into Gaussians using a coarse-to-fine curriculum.

### Inputs and Outputs
*   **Inputs:** A set of $C$ input images $I \in \mathbb{R}^{C \times H \times W \times 3}$ with corresponding camera poses $T_i$ and intrinsics $\kappa_i$.
*   **Outputs:** A set of $N = 16,384$ 3D Gaussians, each defined by mean $\mu_i$, scale $s_i$, rotation $r_i$, opacity $\alpha_i$, and spherical harmonics coefficients $c_i$.

### Data Structures
1.  **Latent Tokens:** A fixed set of $M=2048$ learnable latent tokens $l_j \in \mathbb{R}^{512}$, initialized to zero.
2.  **Register Tokens:** Learnable register tokens used to capture global context (dimension not explicitly specified, assumed 512 to match latent tokens).
3.  **Patch Features:** Input images are patchified into $8 \times 8$ patches. For $256 \times 256$ images, this yields $32 \times 32 = 1024$ patches per view.
4.  **Gaussian Candidates:** For each latent token, the decoder predicts $K_s=16$ candidates for geometry and appearance attributes.
    *   Geometry candidates per token $p$:
        *   Means: $\mathbf{X}_p \in \mathbb{R}^{16 \times 3}$
        *   Scales: $\mathbf{S}_p \in \mathbb{R}^{16 \times 3}$
        *   Rotations: $\mathbf{R}_p \in \mathbb{R}^{16 \times 6}$ (6D parameterization)
        *   Opacities: $\mathbf{O}_p \in \mathbb{R}^{16 \times 1}$ (logits)
        *   Importance scores: $\boldsymbol{\ell}_p \in \mathbb{R}^{16 \times 1}$
    *   Appearance candidates per token $p$:
        *   SH Coefficients: $\mathbf{C}_p \in \mathbb{R}^{16 \times (3 \times D_{\mathrm{SH}})}$, where $D_{\mathrm{SH}}=16$ for SH degree 3.

### Steps

1.  **Scene Normalization:**
    *   Compute the canonical frame origin: $\bar{o} = \frac{1}{C} \sum_{i=1}^C o_i$.
    *   Compute axes by averaging camera viewing directions and re-orthonormalizing. Let $T_{\text{avg}}$ be the resulting average pose.
    *   Transform all cameras: $\hat{T}_i = T_{\text{avg}}^{-1} T_i$.
    *   Compute scene scale: $s = \max_{a,b} \|\hat{o}_a - \hat{o}_b\|_2$.
    *   Scale camera translations: $\tilde{o}_i = \frac{\hat{o}_i}{s}$.

2.  **Input Context Construction:**
    *   Preprocess images: Resize height to 256, round width to multiple of 8, apply centered square crop, resize to $256 \times 256$. Update intrinsics accordingly.
    *   Extract RGB patch features $u_{i,p}^{\text{rgb}}$ using a View Encoder.
    *   Compute dense Plücker-ray features $r_{i,p}$ for each patch and map them: $\hat{r}_{i,p} = W_{\text{ray}} r_{i,p}$.
    *   Compute per-view camera code $e_i$ using Fourier positional encoding for camera center and MLP for intrinsics.
    *   Combine camera features: $u_{i,p}^{\text{cam}} = \hat{r}_{i,p} + e_i$.
    *   Form input context: $u_{i,p} = [u_{i,p}^{\text{cam}} ; u_{i,p}^{\text{rgb}}]$.

3.  **Dual-Branch Iterative Refinement:**
    *   Initialize $M$ latent tokens $l_j$ and register tokens.
    *   For each of $B=4$ encoder blocks:
        *   Project latent tokens into geometry and appearance streams: $f_{\text{geo}}^{(0)}, f_{\text{app}}^{(0)} = \text{Proj}_{\text{geo}}(l), \text{Proj}_{\text{app}}(l)$.
        *   For each branch $i \in \{\text{geo}, \text{app}\}$:
            *   Apply cross-attention between input patches $x$ (the context $u_{i,p}$) and stream features: $f' = \text{CrossAtt}_i(x, f_i)$.
            *   Apply $L=2$ self-attention blocks: $f_i^{(j+1)} = \text{SelfAtt}_i(f')$.
        *   Fuse streams: $l_{\text{geo}}^{(j+1)}, l_{\text{app}}^{(j+1)} = \text{MLP}(\text{Concat}(f_{\text{geo}}^{(j+1)}, f_{\text{app}}^{(j+1)}))$.
        *   Update latent tokens $l$ using the fused geometry and appearance tokens.

4.  **Gaussian Decoding:**
    *   Project refined latent tokens: $G_{\text{geo}} = \text{Proj}_{\text{geo}}^{\text{dec}}(l_{\text{geo}}^{(B)})$, $G_{\text{app}} = \text{Proj}_{\text{app}}^{\text{dec}}(l_{\text{app}}^{(B)})$.
    *   For each latent token $p$, predict 16 candidates for geometry ($\mathbf{X}_p, \mathbf{S}_p, \mathbf{R}_p, \mathbf{O}_p, \boldsymbol{\ell}_p$) and appearance ($\mathbf{C}_p$).

5.  **Coarse-to-Fine Merging (Training Curriculum):**
    *   During training, use a stage parameter $s \in \{0, 1, 2, 3, 4\}$.
    *   Partition 16 candidates into $G = 2^s$ groups of size $b_s = 16/G$.
    *   Compute importance weights using temperature-scaled softmax on gate logits $\ell_{p,g,i}$:
        $$ w_{p,g,i} = \frac{\exp(\ell_{p,g,i}/\tau)}{\sum_{j=1}^{b_s} \exp(\ell_{p,g,j}/\tau)} $$
    *   Merge candidates in each group $g$ for each attribute $z$:
        $$ \bar{z}_{p,g} = \sum_{i=1}^{b_s} w_{p,g,i} z_{p,g,i} $$
    *   Start with $G=1$ (all 16 merged into 1 Gaussian per token) and incrementally increase $G$ to 8 in the final model.

6.  **Rendering:**
    *   Project Gaussians to 2D.
    *   Render image using alpha blending:
        $$ C = \sum_{i=1}^{M} c_i \alpha'_i \prod_{j=1}^{i-1} (1 - \alpha'_j) $$
        where $\alpha'_i = \alpha_i \cdot \text{2D Gaussian}(x)$.

### Gaussian Parameterization Details
*   **Means:** Initialized with a fixed forward offset of 1.5.
*   **Scales:** Predicted in log space as an offset from -2.
*   **Opacities:** Predicted in logit space as an offset from -5.
*   **Rotations:** Use continuous 6D parameterization as residual offsets from a static rotation.
*   **Color:** Spherical Harmonics (SH) degree 3, resulting in $D_{\mathrm{SH}} = 16$ coefficients per color channel.

### Loss Functions
The total loss is $\mathcal{L} = \lambda_{\text{ren}}\mathcal{L}_{\text{ren}} + \lambda_{\text{con}}\mathcal{L}_{\text{con}} + \lambda_{\text{reg}}\mathcal{L}_{\text{reg}}$.
*   **Rendering Loss:** $\mathcal{L}_{\text{ren}} = \|I_t - \hat{I}_t\|_2^2 + \lambda_{\text{perc}}\mathcal{L}_{\text{perc}}(I_t, \hat{I}_t)$.
*   **Self-Supervised Consistency Loss:** $\mathcal{L}_{\text{con}} = \|O(\mathcal{I}_a) - \text{sg}(O(\mathcal{I}_b))\|_2^2 + \|D(\mathcal{I}_a) - \text{sg}(D(\mathcal{I}_b))\|_2^2$, where $O$ and $D$ are rendered opacity and depth maps, and $\text{sg}$ is stop-gradient.
*   **Regularization Loss:** $\mathcal{L}_{\text{reg}} = \lambda_{\text{thr}}\mathcal{L}_{\text{thr}} + \lambda_{\text{fru}}\mathcal{L}_{\text{fru}}$, consisting of soft thresholding on features and a frustum constraint.

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class GlobalSplat:
    def __init__(self, num_latents=2048, latent_dim=512, num_candidates=16, sh_degree=3):
        self.num_latents = num_latents
        self.latent_dim = latent_dim
        self.num_candidates = num_candidates
        self.sh_degree = sh_degree
        self.D_SH = (sh_degree + 1) ** 2
        
        # Learnable tokens
        self.latent_tokens = nn.Parameter(torch.zeros(num_latents, latent_dim))
        self.register_tokens = nn.Parameter(torch.zeros(num_latents, latent_dim)) # Assuming same dim
        
        # Encoder components
        self.num_encoder_blocks = 4
        self.num_self_attn_layers = 2
        self.view_encoder = ViewEncoder() # Extracts RGB patches
        self.ray_proj = nn.Linear(6, 256) # W_ray for Plucker rays
        self.camera_encoder = CameraEncoder() # Encodes center and intrinsics
        
        # Dual-branch projections
        self.proj_geo = nn.Linear(latent_dim, latent_dim)
        self.proj_app = nn.Linear(latent_dim, latent_dim)
        self.cross_attn_geo = CrossAttention(latent_dim)
        self.cross_attn_app = CrossAttention(latent_dim)
        self.self_attn_geo = nn.ModuleList([SelfAttention(latent_dim) for _ in range(self.num_self_attn_layers)])
        self.self_attn_app = nn.ModuleList([SelfAttention(latent_dim) for _ in range(self.num_self_attn_layers)])
        self.mixer_mlp = nn.Sequential(
            nn.Linear(latent_dim * 2, latent_dim),
            nn.ReLU(),
            nn.Linear(latent_dim, latent_dim)
        )
        
        # Decoder components
        self.proj_geo_dec = nn.Linear(latent_dim, num_candidates * (3 + 3 + 6 + 1 + 1)) # X, S, R, O, l
        self.proj_app_dec = nn.Linear(latent_dim, num_candidates * (3 * self.D_SH)) # C
        
        # Training curriculum stage
        self.training_stage = 3 # Final model uses G=8, so s=3
        
    def normalize_scene(self, poses, intrinsics):
        # Compute canonical frame
        origins = poses[:, :3, 3]
        avg_origin = origins.mean(dim=0)
        # Average viewing directions and re-orthonormalize (simplified)
        views = poses[:, :3, 2]
        avg_view = views.mean(dim=0)
        avg_view = F.normalize(avg_view, dim=0)
        # Construct T_avg (simplified)
        T_avg = torch.eye(4)
        T_avg[:3, 3] = avg_origin
        
        # Transform cameras
        T_inv = torch.linalg.inv(T_avg)
        T_hat = T_inv @ poses
        
        # Scale normalization
        centers = T_hat[:, :3, 3]
        max_dist = torch.cdist(centers, centers).max()
        scale = max_dist
        T_scaled = T_hat.clone()
        T_scaled[:, :3, 3] = centers / scale
        return T_scaled, intrinsics # Intrinsics might need scaling adjustment if focal length is in pixels

    def forward(self, images, poses, intrinsics, stage=None):
        if stage is None:
            stage = self.training_stage
            
        # 1. Normalize Scene
        T_norm, K_norm = self.normalize_scene(poses, intrinsics)
        
        # 2. Input Context Construction
        # Patchify images
        patches = self.view_encoder(images) # Shape: (C, H_p*W_p, D_rgb)
        
        # Compute Plucker rays and patchify
        plucker_rays = compute_plucker_rays(T_norm, K_norm) # (C, H, W, 6)
        plucker_patches = patchify(plucker_rays) # (C, H_p*W_p, 6)
        ray_features = self.ray_proj(plucker_patches) # (C, H_p*W_p, 256)
        
        # Camera codes
        camera_codes = self.camera_encoder(T_norm[:, :3, 3], K_norm) # (C, D_cam)
        
        # Combine
        # Broadcast camera code to all patches
        C, P, D_ray = ray_features.shape
        cam_codes_expanded = camera_codes.unsqueeze(1).expand(-1, P, -1)
        cam_features = ray_features + cam_codes_expanded
        
        # Concatenate with RGB features
        # Assuming patches are (C, P, D_rgb)
        input_context = torch.cat([cam_features, patches], dim=-1) # (C, P, D_cam + D_rgb)
        
        # 3. Dual-Branch Iterative Refinement
        l = self.latent_tokens.clone() # (M, D)
        
        for b in range(self.num_encoder_blocks):
            # Project to streams
            f_geo = self.proj_geo(l)
            f_app = self.proj_app(l)
            
            # Cross Attention
            f_geo_cross = self.cross_attn_geo(query=l, key=input_context, value=input_context)
            f_app_cross = self.cross_attn_app(query=l, key=input_context, value=input_context)
            
            # Self Attention
            for i in range(self.num_self_attn_layers):
                f_geo = self.self_attn_geo[i](f_geo_cross)
                f_app = self.self_attn_app[i](f_app_cross)
                
            # Fuse
            fused = torch.cat([f_geo, f_app], dim=-1)
            l = self.mixer_mlp(fused) + l # Residual connection assumed or just update
            
        # 4. Decoding
        G_geo = self.proj_geo_dec(l) # (M, num_candidates * attr_dim)
        G_app = self.proj_app_dec(l) # (M, num_candidates * attr_dim)
        
        # Reshape to candidates
        # Geometry: X(16,3), S(16,3), R(16,6), O(16,1), l(16,1)
        geo_attrs = G_geo.view(self.num_latents, self.num_candidates, -1)
        # Appearance: C(16, 3*16)
        app_attrs = G_app.view(self.num_latents, self.num_candidates, -1)
        
        # 5. Coarse-to-Fine Merging
        num_groups = 2 ** stage
        group_size = self.num_candidates // num_groups
        
        final_means = []
        final_scales = []
        final_rots = []
        final_opacities = []
        final_colors = []
        
        for m in range(self.num_latents):
            # Get attributes for this token
            X_p = geo_attrs[m, :, :3]
            S_p = geo_attrs[m, :, 3:6]
            R_p = geo_attrs[m, :, 6:12]
            O_p = geo_attrs[m, :, 12:13]
            l_p = geo_attrs[m, :, 13:14] # Importance scores
            C_p = app_attrs[m, :, :]
            
            # Reshape candidates into groups
            X_groups = X_p.view(num_groups, group_size, 3)
            S_groups = S_p.view(num_groups, group_size, 3)
            R_groups = R_p.view(num_groups, group_size, 6)
            O_groups = O_p.view(num_groups, group_size, 1)
            l_groups = l_p.view(num_groups, group_size, 1)
            C_groups = C_p.view(num_groups, group_size, -1)
            
            # Compute weights
            # l_groups is (num_groups, group_size, 1)
            weights = F.softmax(l_groups / 0.1, dim=1) # tau=0.1 assumed
            
            # Merge
            X_merged = (weights * X_groups).sum(dim=1)
            S_merged = (weights * S_groups).sum(dim=1)
            R_merged = (weights * R_groups).sum(dim=1)
            O_merged = (weights * O_groups).sum(dim=1)
            C_merged = (weights * C_groups).sum(dim=1)
            
            final_means.append(X_merged)
            final_scales.append(S_merged)
            final_rots.append(R_merged)
            final_opacities.append(O_merged)
            final_colors.append(C_merged)
            
        means = torch.stack(final_means, dim=0)
        scales = torch.stack(final_scales, dim=0)
        rots = torch.stack(final_rots, dim=0)
        opacities = torch.stack(final_opacities, dim=0)
        colors = torch.stack(final_colors, dim=0)
        
        # Apply parameterization offsets
        # Means: offset 1.5 (forward direction, simplified as adding to z in local frame or global)
        # Scales: log offset from -2
        # Opacities: logit offset from -5
        # Rotations: residual from static
        
        # Render
        rendered_images = render_gaussians(means, scales, rots, opacities, colors, T_norm, K_norm)
        
        return rendered_images
```

## Operating characteristics
*   **Memory:** Uses a fixed 16K Gaussians regardless of input view count, resulting in a small disk footprint (<4 MB) and low peak GPU memory (1.79 GB for 24 views on RealEstate10K) [S1].
*   **Speed:** Extremely fast inference, operating under 78 ms in a single forward pass [S1].
*   **Quality:** On RealEstate10K with 24 views, achieves 28.5 PSNR. With 12 views, GlobalSplat16K achieves 28.57 PSNR, 0.885 SSIM, and 0.138 LPIPS [S1].
*   **Scalability:** The fixed number of latent tokens (2048) and Gaussians (16K) ensures constant memory and compute cost relative to the number of input views, unlike dense pipelines that scale with view count [S1].
*   **Limitations:** The coarse-to-fine curriculum and fixed budget may limit the ability to capture extremely fine details compared to methods using millions of Gaussians, though it maintains competitive quality [S1].

## Background
GlobalSplat was introduced by R. Itkin et al. in 2025 [S1]. It addresses the limitation of current feed-forward 3DGS pipelines where primitives are formed in dense view-aligned spaces, leading to representation bloat and fragile global consistency as more views are added [S1]. It builds on the principles of 3D Gaussian Splatting and differentiable rendering, but introduces a global latent scene representation to disentangle geometry and appearance processing [S1].
