# Content-Aware Texturing for Gaussian Splatting

Also called: Content-Aware Texturing, Ours

## Overview
Content-Aware Texturing augments 2D Gaussian primitives with spatially varying texture maps that add offsets to spherical harmonic colors, allowing appearance to adapt to captured content without pretrained models [S1]. It distinguishes itself from siblings like [BBSplat](9910-inverse-multiquadric-splatting.md) by using dynamic, content-aware texel allocation rather than fixed ratios, and from [GSTex](12924-atomized-proliferation.md) by optimizing primitives and textures jointly from scratch rather than applying textures to a fixed point cloud [S1].

## How it works
**Inputs:** Training images, camera poses, initial 2D Gaussian primitives (mean $\mu$, scale $\sigma$, rotation $R$, opacity $\omega$, SH coefficients).
**Outputs:** Optimized Gaussian primitives with associated texture maps.

**Data Structures:**
*   **Primitive:** 59 parameters per primitive, stored as 4-byte floats [S1].
    *   3: Position ($\mu$).
    *   2: Scale ($\sigma_x, \sigma_y$).
    *   4: Rotation (Quaternion).
    *   1: Opacity ($\omega$).
    *   48: SH Coefficients (Degree 3).
    *   1: Texel size ratio parameter ($t_{2pr}$) [S1].
*   **Texture Map:** Stored in a custom "jagged" tensor structure to handle varying resolutions [S1].
    *   Each texel stores 3 RGB offset values [S1].
    *   Values are constrained to $[-1, 1]$ via sigmoid activation on unactivated features $c'_{Ti}$: $c_{Ti} = 2\sigma(c'_{Ti}) - 1$ [S1].

**Coordinate Systems:**
1.  **World Space ($p_w$):** Intersection point.
2.  **World Space Centered ($p_{w0}$):** $p_w - \mu$.
3.  **Local Axis-Aligned ($p_l$):** $R^{-1} p_{w0}$. Since the ray is in the plane, $p_l \in \mathbb{R}^2$ [S1].
4.  **Local Normalized ($p_c$):** $S^{-1} p_l$, where $S = \text{diag}(\sigma)$ [S1].

**Rendering:**
Color is computed by alpha blending in camera space [S1]:
$$ C(r) = \sum_i w_i(p_i) c_i(d) = \sum_i T_i \omega_i G_i(p_i) c_i(d) $$
$$ T_i = \prod_{j<i} (1 - \omega_j G_j(p_j)) $$
$$ G(x) = e^{-\frac{1}{2} (x^T x)} $$
$$ c_i = \text{SH}(d) + \text{bilerp}(T_i, u) $$
where $u$ are UV coordinates [S1].

**Texture Coordinate Mapping:**
To avoid texture stretching during optimization, texel size $k_i$ is fixed in world space [S1]:
$$ u = \frac{p_l}{k_i} + T_{\text{offset}} $$
where $k_i = k_{\min} \cdot t_{2pr}$, $k_{\min}$ is the minimum pixel size, and $t_{2pr}$ is the texel size-to-pixel size ratio (powers of two, lower bound 1) [S1]. $T_{\text{offset}}$ centers the texture map [S1].

**Training Loss:**
$$ L = L_{\text{RGB}} + L_{\text{texture}} + L_{\text{opacity}} $$
$$ L_{\text{RGB}} = (1 - \lambda_{\text{SSIM}}) L_1 + \lambda_{\text{SSIM}} L_{\text{SSIM}} \quad (\lambda_{\text{SSIM}} = 0.2) $$
$$ L_{\text{opacity}} = \lambda_{\text{opacity}} \frac{1}{N} \sum_i \omega_i $$
$$ L_{\text{texture}} = \lambda_{\text{texture}} \sum_i |c_{Ti}| $$
$\lambda_{\text{opacity}}$ and $\lambda_{\text{texture}}$ are weights [S1].

**Primitive Management (Densification):**
Cloning is incompatible due to superimposition convergence issues; splitting is used [S1].
1.  **Error Calculation:** Per-primitive error $E_i$ is a weighted sum of per-view errors $E_i^\pi$ [S1]:
    $$ E_i^\pi = \sum_{r \in P_i} E^\pi(r) w_i^\pi(r) $$
    $$ E_i = \frac{\sum_{\pi \in \Pi} E_i^\pi w_i^\pi}{\sum_{\pi \in \Pi} w_i^\pi}, \quad w_i^\pi = \sum_{r \in P_i} w_i^\pi(r) $$
    where $P_i$ is the set of pixels covered by primitive $i$, and $\Pi$ is the set of views [S1].
2.  **Upscaling:** Select top 10% primitives with highest $E_i$. If $t_{2pr} > 1$, halve $t_{2pr}$ (upscale texture resolution by 4x) [S1].
3.  **Splitting:** If texture resolution exceeds threshold $\tau_{tr}$ after upscaling, split the primitive [S1].
    *   Replace with two new primitives displaced by $\pm 1$ standard deviation along the axis.
    *   New primitives have half the scale in that axis, half the texture resolution, and $G(1)$ times the opacity [S1].
    *   Texture initialized by sampling the original point [S1].

**Downscaling:**
To reduce parameters, check if texture can be reconstructed with lower resolution [S1].
1.  Compute error $E_d$ between original texture $T_{\text{orig}}$ and low-pass filtered version $T_{\text{lowpass}}$, weighted by Gaussian falloff [S1]:
    $$ E_d = \frac{\sum_p G(p) (T_{\text{orig}}(p) - T_{\text{lowpass}}(p))}{\sum_p G(p)} $$
2.  If $E_d < \tau_{ds}$, double $t_{2pr}$ (downscale resolution by 4x) [S1].

**Pitfalls:**
*   Naive mapping (fixing UV to canonical space) causes texture stretching and local minima [S1].
*   Primitive growth outside allocated texture grid (or hitting max resolution 256) requires zero-padding, which reverts to DC color [S1].
*   Upscaling is restricted to primitives with $t_{2pr} \ge 2$ to avoid sub-texel scaling issues [S1].

```python
def render_gaussian_splat_with_texture(primitive, ray_origin, ray_direction, camera_intrinsics):
    # 1. Intersect ray with 2D Gaussian primitive in camera space
    # Note: Implementation uses Eq. 1 directly in camera space, not R2->R2 transform
    intersection_point_camera = intersect_ray_gaussian(ray_origin, ray_direction, primitive)
    
    if intersection_point_camera is None:
        return None, 0.0

    # 2. Transform intersection point to local axis-aligned space
    # p_l = R^-1 * (p_w - mu)
    # Assuming primitive provides R and mu in world space, and ray is in world space
    # Or directly in camera space if primitive is transformed to camera space
    p_w = intersection_point_camera
    p_w0 = p_w - primitive.mu
    p_l = inverse(primitive.R) @ p_w0
    
    # 3. Calculate UV coordinates using world-space fixed texel size
    # k = k_min * t_2pr
    k = primitive.k_min * primitive.t_2pr
    u = (p_l / k) + primitive.T_offset
    
    # 4. Sample texture map
    # T_i is the texture map for this primitive
    # bilerp handles the jagged tensor structure
    texture_offset = bilerp(primitive.texture_map, u)
    
    # 5. Compute color
    # SH(d) is the spherical harmonic color for direction d
    sh_color = evaluate_sh(primitive.sh_coeffs, ray_direction)
    c_i = sh_color + texture_offset
    
    # 6. Compute Gaussian falloff G(p_i)
    # G(x) = exp(-0.5 * x^T x)
    # x is in canonical space p_c = S^-1 * p_l
    S = diag(primitive.scale)
    p_c = inverse(S) @ p_l
    G_val = exp(-0.5 * dot(p_c, p_c))
    
    # 7. Compute contribution weight
    # w_i = T_i * omega_i * G_i
    # T_i (transmittance) is handled by the renderer's alpha blending loop
    # Here we return the color and opacity contribution for the blending step
    alpha_contribution = primitive.opacity * G_val
    
    return c_i, alpha_contribution

def update_primitives(primitives, errors, iteration):
    # Called every 100 iterations
    if iteration % 100 != 0:
        return

    # 1. Upscaling
    # Select top 10% primitives with highest error E_i
    top_10_percent = get_top_primitives_by_error(primitives, 0.1)
    
    for prim in top_10_percent:
        if prim.t_2pr > 1:
            # Halve t_2pr to upscale texture resolution by 4x
            prim.t_2pr = prim.t_2pr / 2
            # Reallocate texture map with higher resolution
            prim.texture_map = upscale_texture(prim.texture_map, factor=2)

    # 2. Splitting
    # Check if primitives with high error exceed texture resolution threshold tau_tr
    for prim in top_10_percent:
        if prim.texture_resolution > prim.tau_tr:
            # Split primitive
            new_prims = split_primitive(prim)
            # Replace old primitive with new ones
            primitives.remove(prim)
            primitives.extend(new_prims)

    # 3. Downscaling
    for prim in primitives:
        # Compute error E_d between original and lowpass filtered texture
        T_orig = prim.texture_map
        T_lowpass = lowpass_filter(T_orig)
        G_vals = compute_gaussian_falloff_over_texture(prim)
        
        numerator = sum(G * (T_orig - T_lowpass) for G, T_orig, T_lowpass in zip(G_vals, T_orig, T_lowpass))
        denominator = sum(G_vals)
        E_d = numerator / denominator
        
        if E_d < prim.tau_ds:
            # Double t_2pr to downscale texture resolution by 4x
            prim.t_2pr = prim.t_2pr * 2
            # Downallocate texture map
            prim.texture_map = downscale_texture(prim.texture_map, factor=2)
```

## Operating characteristics
*   **Complexity:** Training is 1.5-2x slower and rendering is 25% slower than [2DGS](9910-inverse-multiquadric-splatting.md) due to per-ray texture querying overhead [S1].
*   **Memory:** Uses a "jagged" tensor structure for textures. Max texture resolution is hard-limited to 256 to prevent excessive memory usage [S1].
*   **Performance (DeepBlending):** SSIM 0.907, PSNR 30.03, LPIPS 0.303, 222K points, 21.6M texels, 78.1M params, 70 FPS [S1].
*   **Performance (Mip-Nerf-360):** SSIM 0.795, PSNR 27.00, LPIPS 0.263, 218K points, 46.6M texels, 152.6M params, 67 FPS [S1].
*   **Performance (Tanks&Temples):** SSIM 0.835, PSNR 23.43, LPIPS 0.225, 164K points, 10.4M texels, 41.1M params, 121 FPS [S1].
*   **Strengths:** Significantly fewer parameters than [BBSplat](9910-inverse-multiquadric-splatting.md) and [GSTex](12924-atomized-proliferation.md) while maintaining competitive quality [S1]. Dynamic allocation adapts to scene frequency content [S1].
*   **Limitations:** Slower training and rendering than baseline 2DGS [S1].

## Background
The method was introduced by Papantonakis, Kopanas, Durand, and Drettakis in 2025 [S1]. It builds on [2DGS](9910-inverse-multiquadric-splatting.md) by adding content-aware textures and replacing cloning-based densification with splitting to handle texture superimposition [S1].
