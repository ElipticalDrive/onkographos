# Inverse and Internal Rendering

Also called: Inverse Rendering, Internal Rendering, GS-IR, Inner 3D Gaussian Splatting

## Overview
Inverse and Internal Rendering extends 3D Gaussian Splatting (3DGS) to solve problems where standard forward mapping fails: estimating scene properties from unknown lighting (inverse rendering) and reconstructing volumes from data without camera poses (internal rendering) [S1]. Unlike standard 3DGS which optimizes for camera-visible surfaces, these methods address the lack of native normal estimation, the inability of forward mapping to trace occlusion for indirect lighting, and the failure of projection-based rendering when camera parameters are unavailable [S1].

## Shared principles
The family shares the core 3D Gaussian representation defined by a mean position $\mu_i \in \mathbb{R}^3$ and a covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$ [S1]. The covariance is decomposed into a scaling matrix $S$ and a rotation matrix $R$ derived from a unit quaternion $q$, such that $\Sigma = RSS^\top R^\top$ [S1][S2, unofficial]. Rendering utilizes differentiable tile-based rasterization with front-to-back alpha compositing [S1]. To support inverse and internal tasks, the representation is extended with additional attributes per Gaussian, including normals, material properties (Albedo, Metallic, Roughness, Ambient Occlusion), and Spherical Harmonics (SH) coefficients for color or illumination [S1].

## Subtopics

### GS-IR (Gaussian Splatting for Internal Rendering)
GS-IR is an inverse rendering framework that estimates geometry, material, and environment illumination from multi-view images under unknown lighting [S1]. It differs from NeRF-based inverse methods by using 3D Gaussians and forward mapping for real-time efficiency, addressing the lack of native normals and occlusion tracing in forward mapping [S1].
- **Geometry and Normal Optimization:** Optimizes geometry using differentiable splatting. To solve the lack of plausible normals, it computes a pseudo-normal $\hat{\mathbf{n}}_D = \nabla_{uv} \hat{D}$ from the rendered depth map gradient and uses it to supervise the Gaussian normals $\mathbf{n}$ [S1].
- **Occlusion Baking:** Precomputes occlusion based on learned geometry and stores it in a spherical harmonics-based architecture to model indirect illumination, bypassing the need for ray tracing [S1].
- **Material and Illumination Optimization:** Integrates baked occlusion and material properties into a PBR pipeline, jointly optimizing environment lighting and material-aware Gaussians for relighting [S1].
- **Performance:** Achieves PSNR improvements of up to 21.52 dB and SSIM improvements of up to 0.54 on medical datasets [S1].

### [Inner 3D Gaussian Splatting](15745-inner-3d-gaussian-splatting.md)
Inner 3D Gaussian Splatting (InnerGS) is a framework for direct volumetric inference that reconstructs internal structures from sparse, pose-free sliced data. It sets itself apart by eliminating the need for camera parameters and using a slice-based rendering pipeline with Conditional Splatting, which adapts the bounding box per slice, unlike sibling methods that project identical bounding boxes.
- **Conditional Splatting:** Computes conditional 2D Gaussian splats for each depth slice $t$, determining the 2D center and influence radii without camera matrices.
- **3D Gaussian Formulation:** Combines conditional 2D Gaussians with a marginal 1D Gaussian along the depth axis to capture continuous volumetric density between slices.
- **Rendering:** Renders slice $t$ using front-to-back alpha compositing:
  $$ I(u, v, t) = \sum_{i=1}^{N} p_i(u, v, t)\alpha_i c_i \prod_{j=1}^{i-1} (1 - p_j(u, v, t)\alpha_j) $$
  where $p_i(u, v, t)$ is the density at pixel $(u, v)$ for slice $t$.

### GS-IR (Gaussian Splatting for Internal Rendering)
- **Definition:** A plane-based internal rendering framework that replaces exterior-view supervision with cross-sectional supervision sampled from a volume to reconstruct internal volumetric structure [S1].
- **Steps:** Virtual cameras define slicing planes within the volume. A binary mask selects the Gaussian subset whose centers lie within the plane thickness. The selected subset is rendered using the original Gaussian rasterizer. Optimization is performed against ground-truth cross-sections generated through trilinear resampling. Distance-aware soft weighting is applied to continuously attenuate Gaussian opacity as the distance from the Gaussian to the plane increases [S1].
- **Parameters:** Plane thickness defines the spatial extent for Gaussian selection [S1].
- **Performance:** Improves PSNR by up to 21.52 dB and SSIM by up to 0.54 on KiTS23 CT and IXI MRI datasets [S1].
- **Comparison:** Unlike conventional 3DGS which constrains camera-visible surfaces, GS-IR focuses optimization gradients on interior Gaussians to supervise occluded internal regions [S1].
- **Usage:** Applied to 3DGS, 2DGS, and Mip-Splatting without modifying their rasterizers [S1].

### Neural Illumination Enhancement
- **Definition:** A module that complements explicit 3DGS representation by predicting a view-dependent color residual using a lightweight Multilayer Perceptron (MLP) to handle non-Lambertian effects [S2, unofficial].
- **Steps:** Input spatial position, reflection direction, and material-related features (view direction, surface normals, Fresnel term, roughness) into the MLP. Encode spatial positions using HashGrid encoding to capture local spatial structures. Encode reflection directions using Spherical Harmonics (SH) to model directional effects. Use other features directly as identity features. Compute the final rendered image by adding the neural residual $I_n$ to the explicit Gaussian image $I_g$ [S2, unofficial].

### 3DGS Update Procedure with Albedo-Shading Decomposition
- **Definition:** A procedure to efficiently capture global illumination by updating 3D Gaussians using path-traced renderings, combined with albedo-shading decomposition [S2, unofficial].
- **Steps:** Utilize path-traced renderings to efficiently update 3DGS and capture global illumination effects. Apply albedo-shading decomposition strategy to separate intrinsic scene properties for efficient global illumination capture [S2, unofficial].

## Background
3D Gaussian Splatting was introduced as a real-time rendering method using explicit Gaussian primitives [S1][S2, unofficial]. Inverse rendering with 3DGS addresses the limitations of implicit neural representations (NeRFs) which suffer from low expressive power and high computational complexity due to ray tracing [S1]. Internal rendering addresses the failure of standard projection-based 3DGS to reconstruct volumes when camera poses are unavailable or when data consists of sparse slices [S1]. The GS-IR framework for inverse rendering was proposed to handle unknown lighting and material estimation [S1]. Inner 3D Gaussian Splatting was developed to handle pose-free sliced data for internal volume reconstruction [S1].
