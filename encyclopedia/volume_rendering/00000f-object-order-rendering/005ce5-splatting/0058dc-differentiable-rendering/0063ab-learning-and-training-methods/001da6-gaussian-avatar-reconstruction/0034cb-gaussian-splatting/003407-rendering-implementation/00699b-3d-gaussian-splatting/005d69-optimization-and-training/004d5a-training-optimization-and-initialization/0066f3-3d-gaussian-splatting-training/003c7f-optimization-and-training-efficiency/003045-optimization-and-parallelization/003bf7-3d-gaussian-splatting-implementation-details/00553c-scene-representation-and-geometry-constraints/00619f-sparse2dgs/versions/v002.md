# Sparse2DGS

Also called: Geometry-Prioritized Gaussian Splatting for Surface Reconstruction from Sparse Views

## Overview
Sparse2DGS is a Gaussian Splatting method designed for surface reconstruction from sparse input views, addressing the ill-posed nature of geometric optimization when dense Structure-from-Motion points are unavailable [S1]. It distinguishes itself from standard 3D Gaussian Splatting and its sibling [2DGS](12855-gaussian-representation-and-truncation.md) by initializing primitives with unsupervised Multi-View Stereo (MVS) points and employing geometric-prioritized enhancements—such as fixed feature splatting and selective updates—to prevent appearance overfitting and improve geometric learning [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ sparse input images $\{I_i\}_{i=1}^N$, where $I_i \in \mathbb{R}^{H \times W \times 3}$ [S1].
*   **Outputs:** A set of 2D Gaussian primitives representing the 3D surface, optimized to minimize reconstruction error [S1].

**Data Structures:**
The scene is represented by a set of 2D Gaussian primitives. Each primitive $G$ is defined by:
*   Central position $\mathbf{p}$ [S1].
*   Two principal tangential vectors $\mathbf{t}_u$ and $\mathbf{t}_v$ [S1].
*   Scaling vector $(s_u, s_v)$ [S1].
*   The rotation matrix is $\mathbf{R} = (\mathbf{t}_u, \mathbf{t}_v, \mathbf{t}_z)$, where $\mathbf{t}_z = \mathbf{t}_u \times \mathbf{t}_v$ [S1].
*   The scale matrix is $\mathbf{S} = \text{diag}(s_u, s_v, 0)$ [S1].
*   The local tangent plane in world space is parameterized as:
    $$ P(u, v) = \mathbf{p} + s_u \mathbf{t}_u u + s_v \mathbf{t}_v v \quad (1) $$
*   The Gaussian value for a point $\mathbf{u} = (u, v)$ in the local $uv$ space is:
    $$ G(\mathbf{u}) = \exp\left(-\frac{u^2 + v^2}{2}\right) \quad (2) $$
*   MVS-derived feature maps $\{D_i\}_{i=1}^N$ (dense depth maps) are used for initialization and supervision [S1].

**Numbered Steps:**

1.  **MVS Initialization:**
    *   Run an unsupervised MVS network (specifically CLMVSNet [S1]) on the input images $\{I_i\}_{i=1}^N$ to estimate dense depth maps $\{D_i\}_{i=1}^N$ [S1].
    *   Back-project the depth maps $D_i$ into 3D space and fuse them to create a point cloud $\{\mathbf{p}_{ij} \mid 1 \le i \le N, 1 \le j \le HW\}$ [S1].
    *   Initialize the 2D Gaussian primitives' central positions $\mathbf{p}$ using this MVS point cloud [S1].

2.  **Geometrically Enhanced Supervision (Feature Splatting):**
    *   Sample the MVS-derived feature maps (depth/geometry) into the Gaussian splatting process [S1].
    *   **Crucial Constraint:** Keep the feature values and RGB color values **fixed** during optimization [S1]. This provides geometrically expressive supervision and prevents the model from overfitting to appearance in sparse views, which would otherwise compromise geometry [S1].

3.  **Gaussian Primitive Regularization:**
    *   Apply a reparameterization-based disk sampling strategy to regularize the geometric properties (position, orientation, scale) of the primitives [S1].
    *   Reformulate the Gaussian properties into point representations [S1].
    *   Optimize these properties using a unified point-based, cross-view consistency loss [S1]. This ensures that the 2D disk-like primitives maintain coherent geometry across views.

4.  **Selective Gaussian Update:**
    *   Instead of using standard densification (splitting/copying) which can fail under ill-posed sparse-view conditions, selectively update the existing MVS-initialized Gaussian primitives [S1].
    *   Use rendered geometric cues to guide these updates, allowing for self-guided geometric corrections [S1].

**Pseudocode:**

```python
def sparse2dgs(input_images, num_views):
    """
    input_images: List of N images [H, W, 3]
    num_views: N
    """
    # Step 1: MVS Initialization
    # Run unsupervised MVS (e.g., CLMVSNet) to get depth maps
    depth_maps = run_mvs_network(input_images)
    
    # Back-project and fuse depth maps to point cloud
    # i: image index, j: pixel index
    mvs_point_cloud = []
    for i in range(num_views):
        for j in range(H * W):
            p_ij = back_project(depth_maps[i], j)
            mvs_point_cloud.append(p_ij)
            
    # Initialize 2D Gaussians with MVS points
    # Each Gaussian G has: p, tu, tv, su, sv
    gaussians = []
    for p in mvs_point_cloud:
        # Initialize tangential vectors and scales arbitrarily or via normal estimation
        tu, tv = initialize_tangents(p) 
        su, sv = 1.0, 1.0 # Initial scale
        g = Gaussian(p=p, tu=tu, tv=tv, su=su, sv=sv)
        gaussians.append(g)
        
    # Step 2: Optimization Loop
    for iteration in range(max_iterations):
        losses = []
        
        for view_idx in range(num_views):
            image = input_images[view_idx]
            # Render current view using 2D Gaussian Splatting
            # Note: Feature and Color values are FIXED from MVS/Initialization
            rendered_image, rendered_depth = render_gaussians(gaussians, view_idx)
            
            # Compute loss against ground truth image
            # Since color is fixed, this loss primarily drives geometric consistency
            # and prevents appearance overfitting
            color_loss = compute_color_loss(rendered_image, image)
            losses.append(color_loss)
            
            # Compute geometric consistency loss using MVS depth
            # Compare rendered depth with MVS depth map
            mvs_depth = depth_maps[view_idx]
            geo_loss = compute_depth_consistency(rendered_depth, mvs_depth)
            losses.append(geo_loss)
            
        # Step 3: Regularization
        # Apply disk sampling regularization to reformulate properties
        # into point-based supervision
        reg_loss = apply_disk_sampling_regularization(gaussians)
        losses.append(reg_loss)
        
        # Backpropagate and update gradients
        # Only update geometric parameters (p, tu, tv, su, sv)
        # Do NOT update color or feature attributes
        optimize(gaussians, losses)
        
        # Step 4: Selective Update
        # Instead of densification, selectively update primitives
        # based on geometric cues
        gaussians = selective_update(gaussians, rendered_depth, mvs_depth)
        
    return gaussians
```

**Parameters:**
*   $N$: Number of sparse input views [S1].
*   $H, W$: Height and width of input images [S1].
*   $D_i$: Dense depth maps estimated by the MVS network for view $i$ [S1].

**Edge Cases and Pitfalls:**
*   **Appearance Overfitting:** In sparse views, optimizing color and geometry simultaneously leads to severe degradation where color overfits the sparse inputs, compromising geometry [S1]. Sparse2DGS mitigates this by fixing feature and color values during optimization [S1].
*   **Ill-posed Geometry:** Standard densification strategies fail under sparse-view conditions [S1]. Sparse2DGS uses selective updates instead [S1].
*   **Textureless Regions:** Challenges in textureless areas are amplified with sparse views; the geometric-prioritized supervision helps address this [S1].

## Operating characteristics
*   **Performance:** Achieves a Chamfer Distance (CD) error of 1.13 on the DTU dataset with 3 views [S1]. This is significantly lower than 2DGS (2.81), GOF (2.82), and PGSR (2.08) [S1].
*   **Efficiency:** Training time is 10 minutes, which is 2x faster than the NeRF-based fine-tuning approach SparseNeus (25 minutes) [S1].
*   **Strengths:** Robust geometric learning under ill-posed conditions; complete and accurate reconstruction from sparse images; faster than NeRF-based methods [S1].
*   **Limitations:** Relies on the quality of the unsupervised MVS initialization (CLMVSNet); performance is specific to sparse-view scenarios [S1].

## Background
Sparse2DGS was proposed to address the limitations of previous Gaussian Splatting methods that rely on dense views for initialization, which struggle with extremely sparse Structure-from-Motion points [S1]. It combines the strengths of Gaussian Splatting and Multi-view Stereo (MVS) through geometric-prioritized enhancement schemes [S1]. The method was introduced in the paper "Sparse2DGS: Geometry-Prioritized Gaussian Splatting for Surface Reconstruction from Sparse Views" [S1].
