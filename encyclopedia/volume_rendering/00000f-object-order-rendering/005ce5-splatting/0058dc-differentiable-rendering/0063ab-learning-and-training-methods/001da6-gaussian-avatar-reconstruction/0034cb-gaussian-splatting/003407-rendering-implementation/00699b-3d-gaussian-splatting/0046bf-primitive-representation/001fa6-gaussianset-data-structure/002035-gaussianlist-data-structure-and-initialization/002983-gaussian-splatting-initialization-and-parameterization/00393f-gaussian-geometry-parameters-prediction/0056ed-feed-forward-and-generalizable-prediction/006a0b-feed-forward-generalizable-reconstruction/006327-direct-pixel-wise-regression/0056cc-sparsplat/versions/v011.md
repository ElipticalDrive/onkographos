# SparSplat

Also called: Generalizable 2D Gaussian Splatting, SparSplat Model, SparSplat: Fast Multi-View Reconstruction with Generalizable 2D Gaussian Splatting

## Overview
SparSplat is a generalizable, feed-forward model that maps a set of sparse input images (typically 3 views) directly to 2D Gaussian Splatting (2DGS) parameters for a target view in a single forward pass [S1, unofficial]. It solves the joint problem of fast multi-view 3D shape reconstruction and novel-view synthesis (NVS) from sparse inputs, leveraging deep features from foundation models like DINOv2 and MASt3R [S1, unofficial]. It sets itself apart from its sibling [MVSGaussian](12847-anysplat-pipeline.md) by using 2DGS primitives instead of 3D Gaussians, which ensures multi-view depth consistency required for coherent TSDF mesh fusion, and differs from prior generalizable GS methods by being explicitly fit for feed-forward surface reconstruction rather than NVS-only [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ color images $\{I_i\}_{i=1}^N$ (where $N=3$ during training) with known camera poses $\{P_i\}_{i=1}^N$. Images are normalized and resized to $640 \times 512$ [S1, unofficial].
*   **Output:** A pixel-aligned 2DGS parameter map $O_t = \{s, q, p, \alpha, c\} \in \mathbb{R}^{H \times W \times (2+4+3+1+3)}$ for a target view $P_t$, where $s$ is scale, $q$ is rotation quaternion, $p$ is 3D position, $\alpha$ is opacity, and $c$ is color [S1, unofficial].

**Data Structures:**
The model predicts a dense map $O_t$ of dimensions $H \times W \times 13$.
*   $s \in \mathbb{R}^2$: 2D scale parameters (width and height of the planar Gaussian).
*   $q \in \mathbb{R}^4$: Rotation quaternion (normalized).
*   $p \in \mathbb{R}^3$: 3D centroid position.
*   $\alpha \in [0, 1]$: Opacity.
*   $c \in \mathbb{R}^3$: Color (RGB).

**Algorithm Steps:**
1.  **Feature Encoding:**
    *   Extract monocular 2D semantic features from each input image $I_i$ using DINOv2 [S1, unofficial].
    *   Extract pairwise dense correspondence features from input images using MASt3R [S1, unofficial].
    *   An FPN network predicts a 2D feature map $f_i$ for each input image $I_i$ [S1, unofficial].

2.  **Feature Warping:**
    *   Warp the feature maps $f_i$ to the target view coordinate system using homography-based warping, driven by the relative poses $P_t / P_i$ [S1, unofficial]. Let the warped features be $f_{t,i}$ [S1, unofficial].

3.  **Cost Volume and Depth Estimation (DeepMVS Branch):**
    *   Merge warped features $f_{t,i}$ into a cost volume [S1, unofficial].
    *   Process the cost volume into a probability volume using a 3D convolutional network [S1, unofficial].
    *   Produce a coarse depth prediction by sampling 64 depth planes [S1, unofficial].
    *   Refine the depth prediction by sampling 8 depth planes for the fine stage [S1, unofficial].
    *   Unproject the final depth prediction using camera intrinsics $K$ to obtain the 3D position attribute $p$ for each pixel [S1, unofficial].

4.  **Gaussian Parameter Regression (Pixel-Aligned Branch):**
    *   Pool the warped features $f_{t,i}$ into a target feature map $f_t$ [S1, unofficial].
    *   Pass $f_t$ through a 2D convolutional network and an MLP to predict the remaining Gaussian primitive attributes $\{s, q, \alpha, c\}$ [S1, unofficial].

5.  **Parameter Assembly:**
    *   Combine the predicted attributes $\{s, q, \alpha, c\}$ from the pixel-aligned branch with the unprojected positions $p$ from the DeepMVS branch to form the full attribute map $O_t$ [S1, unofficial].

6.  **Rendering (Inference):**
    *   Render the scene using perspective-accurate 2D Gaussian Splatting [S1, unofficial].
    *   For 3D mesh reconstruction, render depth maps $D_i$ for all training views $P_i$ using the inferred splat maps $O_i = \Phi(P_i | I_1, \dots, I_N)$ [S1, unofficial].
    *   Perform TSDF fusion on the splatted depths $D_i$ to extract an explicit 3D triangle mesh $S$ [S1, unofficial]. The TSDF voxel size is set to 1.5 [S1, unofficial].

**Loss Functions:**
Training minimizes a weighted sum of losses [S1, unofficial]:
$$ L = \lambda_s L_s + \lambda_p L_p + \lambda_\alpha L_\alpha + \lambda_\beta L_\beta + \lambda_\gamma L_\gamma + \lambda_1 L_1 + \lambda_2 L_2 $$
Where:
*   $\lambda_s = 0.1, \lambda_p = 0.05, \lambda_\alpha = 0.05, \lambda_\beta = 0.05, \lambda_\gamma = 0.05, \lambda_1 = 0.5, \lambda_2 = 1$ [S1, unofficial].
*   Specific definitions for $L_s, L_p, L_\alpha, L_\beta, L_\gamma, L_1, L_2$ are not provided in the source text, but the architecture follows [48] (MVSGaussian) [S1, unofficial].
*   A depth loss $L_{depth}$ is applied to guide the mean 2DGS splatted depth with ground truth depth supervision, improving Chamfer distance significantly [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn

class SparSplat:
    def __init__(self):
        # Feature encoders
        self.dinov2 = DINOv2Encoder() # Monocular semantic features
        self.mast3r = MASt3REncoder() # Pairwise dense correspondence features
        self.fpn = FeaturePyramidNetwork()
        
        # DeepMVS Branch
        self.cost_volume_net = CostVolumeNetwork()
        self.depth_head = DepthHead(coarse_planes=64, fine_planes=8)
        
        # Pixel-Aligned Branch
        self.feature_pooler = FeaturePooler()
        self.param_predictor = ParamPredictor() # 2D Conv + MLP
        
        # Loss weights
        self.lambda_s = 0.1
        self.lambda_p = 0.05
        self.lambda_alpha = 0.05
        self.lambda_beta = 0.05
        self.lambda_gamma = 0.05
        self.lambda_1 = 0.5
        self.lambda_2 = 1

    def forward(self, images, poses, target_pose, intrinsics):
        """
        images: List of N images [H, W, 3]
        poses: List of N camera poses [R, t]
        target_pose: Target camera pose [R, t]
        intrinsics: Camera intrinsics K
        """
        N = len(images)
        
        # 1. Feature Encoding
        # Extract DINOv2 features
        dinov2_feats = [self.dinov2(img) for img in images]
        
        # Extract MASt3R features (pairwise)
        # Note: MASt3R typically takes pairs of images. 
        # Implementation detail: Aggregate pairwise features relevant to target view.
        mast3r_feats = self.mast3r.get_pairwise_features(images, poses)
        
        # FPN features
        fpn_feats = [self.fpn(img) for img in images]
        
        # 2. Feature Warping
        warped_feats = []
        for i in range(N):
            # Warp feature maps to target view using relative pose
            rel_pose = target_pose.inverse() @ poses[i]
            warped_f = self.warp_homography(fpn_feats[i], rel_pose)
            warped_feats.append(warped_f)
            
        # 3. DeepMVS Branch (Depth/Position)
        # Merge warped features into cost volume
        cost_volume = self.merge_cost_volume(warped_feats)
        
        # Process cost volume to probability volume
        prob_volume = self.cost_volume_net(cost_volume)
        
        # Predict depth (coarse then fine)
        depth_map = self.depth_head(prob_volume)
        
        # Unproject depth to 3D position p
        # p = K^-1 * [x, y, 1] * depth
        p = self.unproject_depth(depth_map, intrinsics, target_pose)
        
        # 4. Pixel-Aligned Branch (Attributes)
        # Pool warped features into target feature map
        f_t = self.feature_pooler(warped_feats)
        
        # Predict s, q, alpha, c
        params = self.param_predictor(f_t)
        s, q, alpha, c = self.split_params(params)
        
        # 5. Assemble Output
        O_t = {
            's': s,      # [H, W, 2]
            'q': q,      # [H, W, 4]
            'p': p,      # [H, W, 3]
            'alpha': alpha, # [H, W, 1]
            'c': c       # [H, W, 3]
        }
        
        return O_t

    def render_mesh(self, images, poses, intrinsics):
        """
        Reconstruct mesh from input images.
        """
        N = len(images)
        depth_maps = []
        
        for i in range(N):
            # Predict splat map for view i
            O_i = self.forward(images, poses, poses[i], intrinsics)
            
            # Render depth map from 2DGS
            D_i = self.render_2dgs_depth(O_i, poses[i], intrinsics)
            depth_maps.append(D_i)
            
        # TSDF Fusion
        mesh = self.tsdf_fusion(depth_maps, voxel_size=1.5)
        return mesh

    def compute_loss(self, O_t, gt_color, gt_depth):
        # Compute rendering loss (L1, SSIM, etc. as per [48])
        rendered_color = self.render_2dgs_color(O_t)
        rendered_depth = self.render_2dgs_depth(O_t)
        
        loss_color = self.l1_loss(rendered_color, gt_color)
        loss_depth = self.l1_loss(rendered_depth, gt_depth)
        
        # Total loss with weights
        # Note: Specific L_s, L_p, etc. definitions are not in source, 
        # assuming standard Gaussian Splatting losses or those from [48]
        total_loss = (self.lambda_s * self.loss_scale(O_t) + 
                      self.lambda_p * self.loss_position(O_t) + 
                      self.lambda_alpha * self.loss_opacity(O_t) + 
                      self.lambda_1 * loss_color + 
                      self.lambda_2 * loss_depth)
        return total_loss
```

## Operating characteristics
*   **Time Complexity:** Inference is extremely fast, approximately 0.8s (reproduced 0.88s) on an RTX A6000 GPU for 3 views [S1, unofficial]. This is nearly 2 orders of magnitude faster than prior state-of-the-art feed-forward sparse view reconstruction methods based on implicit volume rendering (e.g., UfoRecon at 66s, GeoTransfer at 32s) [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:**
    *   On the DTU test set, SparSplat achieves PSNR 28.33, SSIM 0.938, and LPIPS 0.073 for novel-view synthesis [S1, unofficial].
    *   For 3D reconstruction (Chamfer Distance), it achieves a mean CD of 1.04 on the DTU dataset [S1, unofficial].
    *   Using MASt3R features provides an 11.11% boost in reconstruction quality over using only image features, compared to a 0.85% boost from DINOv2 [S1, unofficial].
    *   Adding depth loss $L_{depth}$ improves mean Chamfer distance by 71.8% (from 4.37 to 1.04) [S1, unofficial].
*   **Strengths:**
    *   Fast, feed-forward inference suitable for real-time applications.
    *   Superior reconstruction quality and NVS performance compared to implicit methods (e.g., SparseNeuS) and prior generalizable GS methods (e.g., MVSGaussian) [S1, unofficial].
    *   Produces coherent 3D meshes via TSDF fusion, which prior 3DGS-based generalizable methods fail to do due to depth inconsistencies [S1, unofficial].
    *   Strong generalization on BlendedMVS and Tanks and Temples datasets [S1, unofficial].
*   **Limitations:**
    *   Requires known camera poses for input images [S1, unofficial].
    *   Performance relies on the quality of foundation model features (MASt3R/DINOv2) [S1, unofficial].
    *   TSDF fusion parameters (voxel size) need tuning; incorrect settings may lead to poor mesh quality [S1, unofficial].
*   **When to use:** When fast, generalizable 3D reconstruction and novel-view synthesis from sparse (3-view) inputs are required, and an explicit mesh is needed.
*   **When not to use:** When camera poses are unknown, or when dense input views are available and per-scene optimization is acceptable for higher quality.

## Background
SparSplat was proposed by Shubhendu Jena et al. in 2025 [S1, unofficial]. It builds upon the MVSGaussian framework [48] and MVSFormer++ [6], extending them to use 2D Gaussian Splatting and foundation model features (DINOv2, MASt3R) for generalizable sparse-view reconstruction. It addresses the limitation of prior generalizable GS methods which were designed for novel-view synthesis and failed to produce coherent 3D meshes via TSDF fusion [S1, unofficial]. The method is evaluated on the DTU, BlendedMVS, and Tanks and Temples datasets [S1, unofficial].
