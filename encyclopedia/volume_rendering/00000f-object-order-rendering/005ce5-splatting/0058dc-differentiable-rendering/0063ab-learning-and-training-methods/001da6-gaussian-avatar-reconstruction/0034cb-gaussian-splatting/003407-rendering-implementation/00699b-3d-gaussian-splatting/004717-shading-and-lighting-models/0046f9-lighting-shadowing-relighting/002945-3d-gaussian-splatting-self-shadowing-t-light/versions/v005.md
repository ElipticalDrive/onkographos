# 3D Gaussian Splatting Self-Shadowing (T_light)

Also called: 光源视角自阴影 (T_light)

## Overview
Calculates the self-shadowing transmittance $T_{light}$ for each Gaussian primitive along the sun direction, representing the 'front occlusion transmittance' to model self-shadowing effects in volume rendering [S1, unofficial]. It sets itself apart from sibling methods by performing a dedicated light-space rasterization pass that accumulates depth-weighted transmittance without modifying the primary camera's covariance expansion or applying amplitude compensation, ensuring consistency with the main rendering pass [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D Gaussian primitives (position, covariance/scale/rotation, opacity, color/SH), sun direction (simulated via a distant perspective camera), and the accumulated transmittance state from previous Gaussians in the light path [S1, unofficial].
*   **Outputs:** Per-Gaussian self-shadowing transmittance value $T_{light}$ (or `front_tau`), which modulates the final illumination [S1, unofficial].

**Data Structures:**
*   **Gaussian Buffer:** Standard 3D Gaussian attributes [S1, unofficial].
*   **Light-Space Projection Attributes:** Projected 2D position, 2D covariance matrix, and depth [S1, unofficial].
*   **Accumulation Buffer:** Stores the accumulated front transmittance $\tau$ for the current pixel/fragment in the light pass [S1, unofficial].
*   **Record Channel:** `record_front_tau` stores the energy-weighted mean transmittance for each Gaussian [S1, unofficial].

**Steps:**
1.  **Light Camera Setup:** Construct a virtual perspective camera to simulate a directional sun light source [S1, unofficial]. Place it at a large distance with a narrow Field of View (FOV) to minimize parallax error to below 2% [S1, unofficial]. This setup avoids modifying the EWA Jacobian used in the main pass [S1, unofficial].
2.  **Covariance Handling:** During this light pass, do not expand the projection covariance by $0.3I$ and do not apply amplitude compensation [S1, unofficial]. Preserve the sampling expansion from the main camera pass exactly as is [S1, unofficial].
3.  **Depth Sorting:** Sort the Gaussians by their depth relative to the sun camera (light-space depth) to ensure correct front-to-back accumulation [S1, unofficial].
4.  **Rasterization and Accumulation:** Traverse the sorted Gaussians [S1, unofficial]. For each Gaussian, calculate its contribution to the accumulated front transmittance $\tau$ [S1, unofficial]. The transmittance is weighted by the Gaussian's weight (opacity/density contribution) [S1, unofficial]. Record the accumulated front transmittance $\tau$ weighted by $\tau \times \text{weight}$ into the `record_front_tau` channel [S1, unofficial]. This represents an energy-weighted mean over the entire sun-facing footprint, not just a center point sample [S1, unofficial].
5.  **Gradient Treatment:** Enable full continuous gradients for $\tau$, weights, normalization, weak density backup transmittance, and projection position/scale/rotation [S1, unofficial]. However, treat sun camera framing, sorting, coverage, and threshold branches as constants (detach from gradient computation) to prevent incorrect gradient propagation [S1, unofficial].
6.  **Edge Case Handling:** Handle deeply buried Gaussians (where early termination causes the accumulated weight sum $wsum=0$) by explicitly mapping them to full shadow ($T_{light}=0$) to prevent inversion artifacts [S1, unofficial].

**Pseudocode:**

```python
def compute_tlight(gaussians, sun_camera, pixel_width=1.0, pixel_height=1.0):
    """
    Computes self-shadowing transmittance T_light for 3D Gaussians.
    Implements the light-space rasterization pass described in the sources.
    """
    # Step 1: Project Gaussians into Light Space
    # Do NOT apply the 0.3I expansion or amplitude compensation here [S1, unofficial]
    light_space_gaussians = []
    for g in gaussians:
        # Standard EWA projection to light space [G]
        pos_cam = sun_camera.world_to_camera(g.position)
        pos_2d = sun_camera.projection(pos_cam)
        # 2D covariance from 3D covariance and projection Jacobian [G]
        J = sun_camera.jacobian(pos_cam)
        cov_2d = J @ g.cov_3d @ J.T
        depth = pos_cam.z
        light_space_gaussians.append({
            'index': g.index,
            'pos_2d': pos_2d,
            'cov_2d': cov_2d,
            'depth': depth,
            'weight': g.weight
        })

    # Step 2: Sort by Light-Space Depth (Front-to-Back) [S1, unofficial]
    # Sorting is treated as a constant operation for gradients [S1, unofficial]
    light_space_gaussians.sort(key=lambda x: x['depth'])

    # Initialize per-pixel accumulation buffer [G]
    accumulated_tau = 1.0
    record_front_tau = {}

    # Step 3: Rasterize and Accumulate [S1, unofficial]
    for g in light_space_gaussians:
        # Evaluate Gaussian contribution over the pixel footprint [G]
        contribution = evaluate_gaussian_footprint(g['cov_2d'], g['pos_2d'], pixel_width, pixel_height)

        # Update accumulated transmittance
        current_tau = accumulated_tau
        accumulated_tau *= (1.0 - contribution)

        # Record the front transmittance weighted by the Gaussian's weight
        # Energy-weighted mean over the entire sun-facing footprint [S1, unofficial]
        record_front_tau[g['index']] = current_tau * g['weight']

        # Handle deeply buried Gaussians (early termination) [S1, unofficial]
        if accumulated_tau < 1e-4:
            record_front_tau[g['index']] = 0.0

    # Step 4: Assign T_light
    t_light = [record_front_tau.get(g.index, 0.0) for g in gaussians]
    return t_light

def evaluate_gaussian_footprint(cov_2d, pos_2d, pw, ph):
    """
    Calculates the weight contribution of a Gaussian over the pixel footprint.
    Standard 2D Gaussian integral approximation over pixel area [G].
    """
    # Approximate integral using analytical Gaussian CDF bounds [G]
    dx = pw / 2.0
    dy = ph / 2.0
    sx = math.sqrt(cov_2d[0][0])
    sy = math.sqrt(cov_2d[1][1])
    # Probability mass within pixel bounds centered at pos_2d
    prob_x = 0.5 * (math.erf((dx - pos_2d.x) / (sx * math.sqrt(2))) + math.erf((dx + pos_2d.x) / (sx * math.sqrt(2))))
    prob_y = 0.5 * (math.erf((dy - pos_2d.y) / (sy * math.sqrt(2))) + math.erf((dy + pos_2d.y) / (sy * math.sqrt(2))))
    return prob_x * prob_y
```

**Parameters:**
*   **Sun Camera FOV:** Narrow FOV to minimize parallax error (< 2%) [S1, unofficial].
*   **Covariance Expansion:** Disabled ($0.3I$ expansion is skipped) [S1, unofficial].
*   **Amplitude Compensation:** Disabled [S1, unofficial].
*   **Fallback Mode:** If the `--tlight_voxel` flag is passed, use the old $128^3$ voxel cache path instead of rasterization [S1, unofficial]. This is compatible with models trained before rasterization support [S1, unofficial]. The viewer's `--tlight auto` reads `cfg_args` to automatically match the mode [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Deeply Buried Gaussians:** If early termination causes the accumulated weight sum $wsum=0$, the Gaussian must be explicitly mapped to full shadow ($T_{light}=0$) to prevent inversion artifacts [S1, unofficial].
*   **Gradient Propagation:** Sun camera framing, sorting, coverage, and threshold branches must be treated as constants (no gradients) to prevent incorrect gradient propagation [S1, unofficial].
*   **Covariance Mismatch:** Failing to skip the $0.3I$ expansion and amplitude compensation in the light pass will cause inconsistency with the main camera pass [S1, unofficial].

## Background
Originated in the context of 4D Gaussian Splatting for volume clouds, as described in the `4DGS-Volume-Cloud` repository [S1, unofficial]. The method addresses the lack of self-shadowing in standard 3D Gaussian Splatting, which treats Gaussians as opaque or transparent billboards without considering occlusion from other Gaussians along the light direction [S1, unofficial]. It builds on the principles of light-space rasterization and front-to-back accumulation [S1, unofficial].
