# Pruning and Reduction
Also called: Gaussian Splatting Pruning, 3DGS Optimization Efficiency

## Overview
Pruning and reduction methods aim to decrease the number of 3D Gaussian primitives in a trained model to improve rendering efficiency, reduce memory footprint, and mitigate overfitting, without significantly degrading visual quality. Unlike standard opacity-based culling which removes primitives based on their learned transparency, this family includes advanced techniques that evaluate geometric redundancy, spatial importance, and joint rendering effects to select a subset of Gaussians or simplify their structure.

## Shared principles
The family operates on the standard 3D Gaussian Splatting representation defined in [Gaussian Representation and Truncation](12855-gaussian-representation-and-truncation.md). The core mechanism involves evaluating a criterion for each Gaussian $g_i$ (or group of Gaussians) to determine if it should be removed, simplified, or retained. The evaluation typically occurs during or after the training optimization phase. The decision is based on attributes such as opacity $\omega_i$, spatial position $\mu_i$, scale $s_i$, and their contribution to the rendered image error. The goal is to map the original set of $N$ Gaussians to a reduced set of $K$ Gaussians ($K < N$) or a simplified primitive type.

## Subtopics

### [Vertex-level Pruning in Mixed-Primitive Gaussian Splatting](13983-vertex-level-pruning-in-mixed-primitive-gaussian-splatting.md)
Vertex-level pruning is a refinement mechanism applied during the training of Mixed-Primitive Gaussian Splatting (MP-GS) to remove redundant vertices from Gaussian triangles and lines, converting them into simpler primitives (ellipses or lines) as needed. While standard 3D Gaussian Splatting performs only primitive-level opacity pruning, MP-GS introduces vertex-level pruning to eliminate unnecessary geometric complexity in regions where lower-order primitives suffice, thereby reducing storage overhead and refining the surface representation. It is chosen when using mixed primitives (points, lines, triangles) and the goal is to optimize surface representation by reducing vertex count. See [Vertex-level Pruning in Mixed-Primitive Gaussian Splatting](13983-vertex-level-pruning-in-mixed-primitive-gaussian-splatting.md).

### [SplatQ](14415-splatq.md)
SplatQ is a post-training pruning framework for 3D Gaussian Splatting (3DGS) that addresses the spatial quality imbalance and loss of joint rendering effects inherent in global Top-K selection methods. It partitions Gaussians into size-limited blocks based on spatial and appearance similarity, allocates retention quotas to these blocks to ensure balanced budget distribution, and solves a Quadratic Unconstrained Binary Optimization (QUBO) problem within each block to jointly select Gaussians that minimize reconstruction error under a fixed global count. It is chosen when a fixed target count $K$ is required and spatial uniformity of quality is critical. See [SplatQ](14415-splatq.md).

#### definition
- [S1, unofficial] A pruning mechanism designed to support mixed-primitive-based learning, as standard pruning is incompatible with mixed primitives.
#### step
- [S1, unofficial] Prune vertices of the mixed primitives to optimize the representation.

### Gaussian Reduction with Learnable Mask
#### definition
- [S2] A method to reduce the number of Gaussians using a learnable mask during optimization, targeting small-sized kernels for removal.
#### step
- [S2] Apply binary masks M to the opacities and scale attributes of the kernels at every densification step.
- [S2] Use residual vector quantization with L stages of vector quantization for geometric attributes like scale and rotation.
- [S2] Represent view-dependent colors via a grid-based neural field using hash grids for input positions, features, and view direction, fed into an MLP.
#### formula
- [S2] The end-to-end loss is: $L = L_{ren} + \lambda_m L_m + L_r + L_s$, where $L_{ren}$ is L1+SSIM loss, $L_m$ is masking loss ($\frac{1}{N} \sum \sigma(m_n)$), and $L_r, L_s$ are rotation and scale objective functions.
#### parameter
- [S2] $\epsilon$: Masking threshold for the sigmoid function in the learnable mask.
- [S2] $\lambda_m$: Weight for the masking loss term, typically $5 \times 10^{-4}$.

### 3DGS Visibility Pruning
#### definition
- [S2] Application of visibility-based pruning to 3D Gaussian Splatting, using Gaussian centroids as reference points for visibility calculation.
#### step
- [S2] Represent each Gaussian kernel by its centroid position, scaling matrix $S$, and rotation matrix $R$ defining the covariance $\Sigma$.
- [S2] Use the Gaussian centroids as the 3D points $p_i$ in the visibility mask computation algorithm.

## Background
Pruning in 3D Gaussian Splatting emerged as the number of Gaussians required for high-fidelity reconstruction grew large, leading to high memory usage and training times. Standard 3DGS uses opacity-based culling, but this can leave redundant high-opacity primitives. Subsequent works introduced geometric redundancy checks (vertex pruning for mixed primitives) [S1, unofficial] and optimization-based reduction (learnable masks) [S2]. More recently, post-training methods like SplatQ addressed the limitations of global ranking by considering local spatial blocks and joint effects [S1, unofficial]. Visibility-based pruning, originally developed for neural radiance fields, has been adapted to 3DGS by using centroids as reference points [S2].
