# Dynamic Neural Radiance Fields

Also called: 4D Facial Avatar Reconstruction, Dynamic NeRF, Dynamic Neural Scene Representation Network

## Overview
Dynamic Neural Radiance Fields (Dynamic NeRF) is a method for modeling the appearance and dynamics of a human face using an implicit volumetric representation, enabling novel viewpoint and expression synthesis from monocular input [S1]. It combines a neural scene representation network with a low-dimensional morphable model to handle facial dynamics, allowing the capture of arbitrary geometry and topology (such as hair, eyewear, and hats) that explicit geometry methods often struggle with [S1]. Unlike static NeRF methods, it handles dynamically changing surfaces by conditioning the neural network on morphable model expression parameters and a per-frame latent code, distinguishing it from siblings like [Scene NeRF](12484-scene-nerf.md) which focus on static scenes, and [NeRF-OSR](14477-nerf-osr.md) which addresses other specific rendering constraints [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A monocular portrait video sequence and a static background image.
*   **Output:** Synthesized images of the face at novel viewpoints and expressions.
*   **Auxiliary Inputs:** Pose parameters (rotation, translation) and expression coefficients estimated from a 3D morphable model for each frame.

**Data Structures**
*   **Dynamic Radiance Field MLP ($D_\theta$):** A multi-layer perceptron representing the implicit volumetric function.
    *   **Input Vector:** Concatenation of positional encoding of position $p$, positional encoding of view direction $\vec{v}$, expression coefficients $\delta$, and latent code $\gamma$.
    *   **Backbone:** 8 linear layers, each 256 neurons wide, with ReLU non-linearity. Takes the concatenated input $I$ (position, expression, latent code).
    *   **Density Output:** A single layer taking the backbone output to produce density $\sigma$.
    *   **Color Branch:** A 4-layer branch, 128 neurons wide, with ReLU activations. Takes the backbone output concatenated with the encoded viewing direction to produce RGB color.
*   **Morphable Model Parameters:**
    *   $\delta \in \mathbb{R}^{76}$: Facial expression coefficients from a low-dimensional delta-blendshape basis.
    *   Pose parameters: Rotation and translation vectors.
*   **Latent Code:** A learnable vector $\gamma$ per frame.

**Numbered Steps**
1.  **Preprocessing:** Given a monocular portrait video sequence, apply facial expression tracking using a 3D morphable model to estimate pose and expression parameters for each frame [S1].
2.  **Ray Dispatch:** For each frame to be synthesized, dispatch rays in a canonical space shared by all frames. The pose parameters (rotation, translation) from the morphable model are used to transform the rays into this canonical space [S1].
3.  **Sampling:** Sample points along the viewing rays in the canonical space [S1].
4.  **Network Evaluation:** For each sample point, input its canonical position $p$, view direction $\vec{v}$, the morphable model's expression parameters $\delta$, and a per-frame learnable latent code $\gamma$ into the dynamic radiance field MLP $D_\theta$ [S1].
    *   The position $p$ and view direction $\vec{v}$ are first encoded using positional encoding [S1].
    *   The MLP computes:
        $$ D_\theta (p, \vec{v} , \delta, \gamma) = (RGB, \sigma) $$
        where $RGB$ is the color and $\sigma$ is the density [S1].
5.  **Volumetric Integration:** Perform volumetric integration of the density and color values predicted by the MLP along the rays to generate the final image [S1].
6.  **Background Handling:** For the last sample point of each ray (background), set the color to the corresponding value from the static background image, as the background is static [S1].
7.  **Test-Time Latent Code:** At test time, always employ the latent code from the first frame of the training set [S1].

import math

def positional_encoding(x, num_frequencies):
    """
    Standard positional encoding as used in [S1] (Mildenhall et al. [22]).
    x: tensor of shape (..., D)
    num_frequencies: int
    Returns: tensor of shape (..., D * 2 * num_frequencies)
    """
    # Implementation detail: [G] Standard PE scales x by powers of 2*pi/freq
    # Since exact implementation of [22] is referenced but not fully detailed in S1,
    # we assume standard sine/cosine encoding.
    scales = [2**i for i in range(num_frequencies)]
    encoded = []
    for scale in scales:
        encoded.append(math.sin(x * scale * math.pi))
        encoded.append(math.cos(x * scale * math.pi))
    return torch.cat(encoded, dim=-1)

def dynamic_nerf_forward(p, v, delta, gamma, theta):
    """
    Forward pass of the Dynamic Neural Radiance Field MLP.
    p: position (x, y, z)
    v: view direction
    delta: expression coefficients (R^76)
    gamma: latent code
    theta: MLP weights
    Returns: RGB color, sigma density
    """
    # 1. Positional Encoding
    # S1 specifies 10 frequencies for position and 4 for view direction
    p_enc = positional_encoding(p, 10)
    v_enc = positional_encoding(v, 4)
    
    # 2. Prepare Backbone Input
    # Concatenate position, expression, and latent code
    # S1: "takes concatenated input I (position, expression, latent code)"
    # Note: p_enc is already encoded, but S1 says "Instead of directly inputting... 
    # we use positional encoding". It implies the MLP input is the encoded vectors.
    # However, S1 also says "takes the position, the expression and latent code as input".
    # Clarification from S1: "The viewing direction as well as the position are encoded 
    # using positional encoding... The MLP consists of a backbone... which takes the 
    # position, the expression and latent code as input (concatenated as vector I)."
    # This implies I = [p_enc, delta, gamma] or [p, delta, gamma] with PE inside?
    # S1 Formula 1: D_theta(p, v, delta, gamma). 
    # S1 Text: "Instead of directly inputting the canonical position p... we use positional encoding".
    # This strongly suggests the input to the linear layers is the PE output.
    backbone_input = torch.cat([p_enc, delta, gamma], dim=-1)
    
    # 3. Backbone Layers (8 linear layers, 256 neurons, ReLU)
    x = backbone_input
    for i in range(8):
        x = linear_layer(x, theta.backbone_weights[i], theta.backbone_biases[i])
        x = relu(x)
        
    # 4. Density Output (Single layer)
    sigma = linear_layer(x, theta.density_weights, theta.density_biases)
    
    # 5. Color Branch
    # Concatenate backbone output with encoded viewing direction
    color_input = torch.cat([x, v_enc], dim=-1)
    
    # 4 linear layers, 128 neurons, ReLU
    for i in range(4):
        color_input = linear_layer(color_input, theta.color_weights[i], theta.color_biases[i])
        color_input = relu(color_input)
        
    # Final RGB output
    rgb = linear_layer(color_input, theta.color_output_weights, theta.color_output_biases)
    
    return rgb, sigma

    samples = sample_along_rays(canonical_rays, num_samples=256)
    
    # 4. Evaluate MLP for all samples
    # S1: "input its canonical position, view direction, ... expression parameters, 
    # and a per-frame learnable latent code"
    # Note: delta is constant for all samples in a frame.
    # gamma is per-frame.

    # If test time, use latent code from first frame

    positions = samples.position
    directions = samples.direction # View direction in canonical space
    
    rgb, sigma = dynamic_nerf_forward(positions, directions, delta, gamma, theta)
    
    # 5. Volumetric Integration
    # S1: "Perform volumetric integration of the density and color values"
    # Standard volume rendering equation:
    # C(r) = sum_{i=1}^N T_i * (1 - exp(-sigma_i * delta_i)) * c_i

    rgb[last_idx] = bg_color

    # S1 says "set the color... to the corresponding value". 
    # If we just change the RGB of the last sample, the standard integration 
    # will blend the background color with the transmittance.
    # However, usually background is treated as infinite depth.
    # S1 phrasing suggests a specific handling for the "last sample point".
    # We will assume standard integration with the modified last sample color.
    
    # Re-calculate color with modified RGB
    color = torch.sum(weights.unsqueeze(-1) * rgb, dim=0)
    
    return color

**Parameters**
*   **Positional Encoding Frequencies:** 10 frequencies for position $p$ and 4 frequencies for viewing direction $\vec{v}$ [S1].
*   **Expression Coefficients:** $\delta \in \mathbb{R}^{76}$, representing a low-dimensional delta-blendshape basis [S1].
*   **Latent Code:** A learnable vector $\gamma$ per frame, used to compensate for errors in facial expression and pose estimation [S1].
*   **Training Data:** Requires a large training corpus to generalize over the space of expression vectors. Static NeRF needs ~100 posed images; Dynamic NeRF requires significantly more to handle the dynamic variety [S1].

**Edge Cases and Pitfalls**
*   **Pose/Expression Errors:** The per-frame latent code $\gamma$ is critical to compensate for inaccuracies in the 3D morphable model's pose and expression estimation [S1].
*   **Test-Time Latent Code:** During inference, the latent code from the *first* frame of the training set must be used, not the one corresponding to the target expression [S1].
*   **Background:** The background is assumed static and is handled by explicitly setting the color of the last sample point to the background image value [S1].
*   **Data Requirements:** Performance degrades significantly if the training corpus does not cover the full space of expressions and poses seen during testing [S1].

## Operating characteristics
*   **Time and Memory Complexity:** The method uses an MLP with 8 backbone layers (256 neurons) and a 4-layer color branch (128 neurons). Memory usage is dominated by the MLP weights and the per-frame latent codes. Rendering time depends on the number of samples per ray and the MLP evaluation cost.
*   **Measured Performance:** Suitable for capturing avatars of end users at home using only 2 minutes of their time [S1]. Achieves photo-realistic image generation that surpasses the quality of state-of-the-art video-based reenactment methods [S1].
*   **Scaling:** Requires more training data than static NeRF. Quality degrades if the training corpus is small, as the network must generalize over the space of expression vectors [S1].
*   **Strengths:** Captures arbitrary geometry and topology (hair, eyewear, hats) which explicit methods struggle with. Does not suffer from discretization artifacts of voxel grids. Requires only a single view from a fixed camera (e.g., webcam) instead of an expensive calibrated multi-view rig [S1].
*   **Limitations:** Requires a large training corpus. Relies on the accuracy of the 3D morphable model for pose and expression estimation (mitigated by latent codes). The expression parameters model coarse geometric surface changes and do not model changes like eye orientation [S1].

## Background
Dynamic Neural Radiance Fields were introduced by [S1] as a novel method for learning and rendering controllable 4D facial avatars. The work builds on the static Neural Radiance Fields (NeRF) by Mildenhall et al. [22], extending it to handle dynamic facial expressions. It was developed to address the limitations of explicit geometry methods and purely image-based approaches in capturing complex facial dynamics and topology from monocular input. The method is particularly relevant for augmented reality (AR) and virtual reality (VR) telepresence applications [S1].
