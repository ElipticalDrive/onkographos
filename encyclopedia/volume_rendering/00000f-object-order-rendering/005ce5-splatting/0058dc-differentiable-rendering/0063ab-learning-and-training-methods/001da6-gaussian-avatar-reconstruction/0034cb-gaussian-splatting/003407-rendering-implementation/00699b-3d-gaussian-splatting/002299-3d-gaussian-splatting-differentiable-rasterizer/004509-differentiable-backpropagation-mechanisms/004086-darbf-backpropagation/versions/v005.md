# DARBF Backpropagation

Also called: DARBF Gradient Calculation, Differentiable DARBF Rasterizer

## Overview
DARBF Backpropagation is the gradient computation mechanism for Decaying Anisotropic Radial Basis Functions (DARBFs) within the 3D Gaussian Splatting pipeline [S1]. It solves the problem of differentiating the rendering loss with respect to Gaussian parameters when the alpha splatting function is not a standard Gaussian but a decaying anisotropic function (e.g., half-cosine) [S1]. It differs from standard 3DGS backpropagation by explicitly modifying the rasterizer's gradient computation to support the specific derivative terms of non-Gaussian DARBFs, rather than using the fixed Gaussian gradient formulas [S1].

## How it works
**Inputs:**
*   Gradient of the loss with respect to the pixel color: $\frac{\partial L}{\partial C_j}$ for each pixel $j$ [G].
*   Forward pass data for splat $s$ contributing to pixel $j$:
    *   Projected mean $\boldsymbol{\mu}'$ (2D vector) [G].
    *   Inverse projected covariance matrix $(\Sigma'_{2\times 2})^{-1}$ (2x2 matrix) [G].
    *   Weight $w_s$ (scalar opacity contribution before compositing) [G].
    *   Parameter $\xi$ (scalar frequency/decay control) [S1].
    *   Accumulated transparency $\alpha_{prev} = \prod_{k < s} (1 - \alpha_k)$ [G].

**Outputs:**
*   Gradients with respect to the projected mean difference: $\frac{\partial L}{\partial (x - \boldsymbol{\mu}')}$ [S1].
*   Gradients with respect to the inverse covariance matrix: $\frac{\partial L}{\partial (\Sigma'_{2\times 2})^{-1}}$ [S1].

**Data Structures:**
*   $x$: The 2D pixel coordinate vector [G].
*   $\boldsymbol{\mu}'$: The 2D projected mean vector [G].
*   $\Sigma'_{2\times 2}$: The 2D projected covariance matrix [G].
*   $(\Sigma'_{2\times 2})^{-1}$: The inverse of the projected covariance matrix [G].
*   $d_M$: The Mahalanobis-like distance metric defined as $d_M = \frac{(x - \boldsymbol{\mu}')^T(\Sigma'_{2\times 2})^{-1}(x - \boldsymbol{\mu}')}{\xi}$ [S1].
*   $F(d_M)$: The DARBF activation function (e.g., half-cosine) [S1].
*   $F'(d_M)$: The derivative of the activation function [S1].

**Steps:**
1.  **Compute Activation Derivative:** Calculate the derivative of the DARBF activation function $F$ with respect to the distance metric $d_M$ [S1]. For the half-cosine example, this is:
    $$ F'(d_M) = -\sin\left(\frac{(x - \boldsymbol{\mu}')^T(\Sigma'_{2\times 2})^{-1}(x - \boldsymbol{\mu}')}{\xi}\right) $$
    [S1]
2.  **Compute Distance Metric Derivatives:** Calculate the partial derivatives of the distance metric $d_M$ with respect to the inverse covariance matrix and the projected mean difference [S1].
    *   With respect to the inverse covariance matrix:
        $$ \frac{\partial d_M}{\partial(\Sigma'_{2 \times 2})^{-1}} = \frac{(x - \boldsymbol{\mu}')(x - \boldsymbol{\mu}')^T}{\xi} $$
        [S1]
    *   With respect to the projected mean difference $(x - \boldsymbol{\mu}')$:
        $$ \frac{\partial d_M}{\partial(x - \boldsymbol{\mu}')} = \frac{2(\Sigma'_{2 \times 2})^{-1}(x - \boldsymbol{\mu}')}{\xi} $$
        [S1]
3.  **Compute Weight Gradients:** Apply the chain rule to compute the gradient of the weight $w$ with respect to the geometric parameters [S1].
    *   Gradient with respect to the projected mean difference:
        $$ \frac{dw}{d(x - \boldsymbol{\mu}')} = F'(d_M) \frac{\partial d_M}{\partial(x - \boldsymbol{\mu}')} $$
        [S1]
    *   Gradient with respect to the inverse covariance matrix:
        $$ \frac{dw}{d((\Sigma'_{2\times 2})^{-1})} = F'(d_M) \frac{\partial d_M}{\partial(\Sigma'_{2 \times 2})^{-1}} $$
        [S1]
4.  **Accumulate Loss Gradients:** Multiply the weight gradients by the gradient flowing from the loss through the alpha compositing equation [G]. If $\frac{\partial L}{\partial \alpha_s}$ is the gradient of the loss with respect to the splat's opacity $\alpha_s$ (derived from the compositing chain rule in the parent article), then:
    $$ \frac{\partial L}{\partial (x - \boldsymbol{\mu}')} = \frac{\partial L}{\partial \alpha_s} \frac{d\alpha_s}{dw} \frac{dw}{d(x - \boldsymbol{\mu}')} $$
    $$ \frac{\partial L}{\partial (\Sigma'_{2\times 2})^{-1}} = \frac{\partial L}{\partial \alpha_s} \frac{d\alpha_s}{dw} \frac{dw}{d((\Sigma'_{2\times 2})^{-1})} $$
    [G] Note that the term $\frac{d\alpha_s}{dw}$ depends on the specific mapping from weight $w$ to opacity $\alpha_s$ (e.g., $\alpha_s = w \cdot \alpha_{prev}$) [G]. The sources provide the derivatives of $w$ with respect to the geometric parameters, which must be scaled by the compositing gradient [S1].
5.  **Map to Parameter Space:** Convert the gradients with respect to $(x - \boldsymbol{\mu}')$ and $(\Sigma'_{2\times 2})^{-1}$ back to the gradients for the learnable parameters (mean $\boldsymbol{\mu}$, covariance $\Sigma$, etc.) using the Jacobian of the projection and parameterization steps [G]. This step is standard in differentiable rasterizers and relies on the forward projection derivatives [G].

**Parameters:**
*   $\xi$: A parameter controlling the frequency/decay of the DARBF. In the half-cosine function example, $\xi = 18\pi$ [S1].

**Pseudocode:**
```python
import numpy as np

def darbf_backprop(x, mu_prime, inv_cov, xi, grad_L_alpha_s, d_alpha_s_dw):
    """
    Computes gradients for DARBF splatting based on [S1].
    
    Args:
        x: (2,) pixel coordinate vector.
        mu_prime: (2,) projected mean vector.
        inv_cov: (2, 2) inverse projected covariance matrix.
        xi: scalar decay parameter.
        grad_L_alpha_s: scalar gradient of loss w.r.t. opacity alpha_s.
        d_alpha_s_dw: scalar derivative of alpha_s w.r.t. weight w.
        
    Returns:
        grad_mu_diff: (2,) gradient w.r.t. (x - mu_prime).
        grad_inv_cov: (2, 2) gradient w.r.t. inv_cov.
    """
    # Step 1: Compute distance metric d_M
    diff = x - mu_prime
    d_M = (diff.T @ inv_cov @ diff) / xi
    
    # Step 2: Compute activation derivative F'(d_M) for half-cosine [S1]
    F_prime = -np.sin(d_M)
    
    # Step 3: Compute distance metric derivatives [S1]
    # d(d_M) / d(inv_cov) = (diff @ diff.T) / xi
    grad_dM_d_inv_cov = (diff.reshape(-1, 1) @ diff.reshape(1, -1)) / xi
    
    # d(d_M) / d(diff) = 2 * inv_cov @ diff / xi
    grad_dM_d_diff = 2.0 * (inv_cov @ diff) / xi
    
    # Step 4: Compute weight gradients using chain rule [S1]
    dw_d_diff = F_prime * grad_dM_d_diff
    dw_d_inv_cov = F_prime * grad_dM_d_inv_cov
    
    # Step 5: Scale by loss gradient and compositing derivative [G]
    grad_mu_diff = grad_L_alpha_s * d_alpha_s_dw * dw_d_diff
    grad_inv_cov = grad_L_alpha_s * d_alpha_s_dw * dw_d_inv_cov
    
    return grad_mu_diff, grad_inv_cov
```

## Background
DARBF Backpropagation is the process of computing gradients for Decaying Anisotropic Radial Basis Functions (DARBFs) during backpropagation, modifying the standard differentiable Gaussian rasterizer to support specific DARBF gradient terms [S1]. It is implemented in the DARBF-Splatting codebase, which anchors on the 3DGS codebase updated as of October 2024 [S1].
