# SpacetimeGaussians Training Pipeline


## Overview
The SpacetimeGaussians Training Pipeline is the optimization procedure for the SpacetimeGaussians method, designed to train dynamic 3D Gaussian splats for real-time dynamic view synthesis. It extends the standard 3D Gaussian Splatting optimization by incorporating time-dependent motion parameters and a specialized densification schedule that freezes motion variables after an initial phase. It differs from sibling methods by its specific iteration-based control over Gaussian density (densification/pruning) and the conditional freezing of motion-related weights to stabilize training.

## How it works
The pipeline initializes the scene model and data structures, then iterates through training steps. At each step, it renders the scene using a specific rasterization backend, computes a loss function (potentially with regularization), and updates the Gaussian parameters. A critical aspect is the dynamic management of Gaussian density and the freezing of motion parameters based on the current iteration count.

### Inputs and Outputs
*   **Inputs:**
    *   `dataset`: Contains scene data, including camera poses, images, and SfM points.
    *   `opt`: Configuration object containing hyperparameters (e.g., `densify`, `reg`, `lambda_dssim`, `regl`, `densify_from_iter`, `densify_until_iter`, `densification_interval`, `opacity_reset_interval`, `desicnt`, `densify_grad_threshold`, `opthr`).
    *   `iteration`: Current training iteration number.
    *   `multiview`: Boolean flag for multiview training mode.
    *   `duration`: Duration of the scene.
    *   `loader`: Data loader.
    *   `option`: String specifying the rendering pipeline variant (e.g., 'train_ours_full').
*   **Outputs:**
    *   Updated Gaussian parameters (position, covariance, opacity, color, motion).
    *   Rendered images (for loss computation).

### Data Structures
*   **Gaussian Model (`gaussians`):**
    *   `_xyz`: Position tensor.
    *   `_rotation`: Rotation quaternion tensor.
    *   `_scaling`: Scaling vector tensor.
    *   `_opacity`: Opacity tensor.
    *   `_sh_coeffs`: Spherical Harmonics coefficients tensor.
    *   `_omega`: Motion parameter tensor.
    *   `omegamask`: Boolean mask tensor indicating which Gaussians keep their motion parameters.
    *   `ts`: Time tensor, shape `(1, 1, H, W)`, dtype `torch.float32`, device `cuda`. Initialized to ones if `None`.
    *   `rgbdecoder`: Optional RGB decoder module.
*   **Background Color (`background`):**
    *   Shape `(numchannels,)`, dtype `torch.float32`, device `cuda`. Initialized to zeros. Default `numchannels` is 9.
*   **Rendering Pipeline Components:**
    *   Retrieved via `getrenderpip(option)`.
    *   `train_ours_full` / `train_ours_fullss`: Use `diff_gaussian_rasterization_ch9`.
    *   `train_ours_lite` / `train_ours_litess`: Use `diff_gaussian_rasterization_ch3`.
    *   Includes `GaussianRasterizationSettings` and `GaussianRasterizer`.

def compute_loss(rendering, gt_image, opt):
    """
    Compute loss based on opt.reg.
    """
    lambda_dssim = opt.lambda_dssim
    regl = opt.regl
    reg = opt.reg
    
    # L1 Loss
    L_L1 = torch.abs(rendering - gt_image).mean()
    
    # D-SSIM Loss
    ssim_loss = 1 - SSIM(rendering, gt_image)
    
    # Regularization
    reg_loss = 0.0
    
    if reg == 1:
        # Sum of motion gradients divided by N
        g_motion = compute_gradient(gaussians._omega) # [G]
        N = gaussians._omega.shape[0]
        reg_loss = regl * (torch.sum(g_motion) / N) # [S1, unofficial]

        # Sum of squared omega gradients for r > 0
        g_omega = compute_gradient(gaussians._omega) # [G]
        # Assuming r > 0 condition is handled by mask or index
        reg_loss = regl * torch.sum(g_omega[g_omega > 0]**2) # [S1, unofficial]
    elif reg == 10:
        # Sum of squared motion gradients for r > 0
        g_motion = compute_gradient(gaussians._omega) # [G]
        reg_loss = regl * torch.sum(g_motion[g_motion > 0]**2) # [S1, unofficial]
    elif reg == 4:
        # Sum of scaling gradients divided by N
        g_scaling = compute_gradient(gaussians._scaling) # [G]
        N = gaussians._scaling.shape[0]
        reg_loss = regl * (torch.sum(g_scaling) / N) # [S1, unofficial]
    elif reg == 6:
        # Adaptive lambda_dssim
        r = torch.clamp(torch.mean(gt_image) - 0.5 + lambda_dssim, 0, 1) # [S1, unofficial]
        L_L1 = (1 - r) * L_L1
        ssim_loss = r * ssim_loss
    elif reg == 7:
        # Normalize L1 by 2 * mean(gt_image)
        L_L1 = L_L1 / (2 * torch.mean(gt_image)) # [S1, unofficial]
    elif reg == 8:
        # L2 loss on mean
        mean_rendering = torch.mean(rendering)
        mean_gt = torch.mean(gt_image)
        reg_loss = 0.0002 * lambda_dssim * torch.sum((mean_rendering - mean_gt)**2) / rendering.shape[0] # [S1, unofficial]
    
    # Total Loss
    if reg == 6:
        loss = L_L1 + ssim_loss
    else:
        loss = (1 - lambda_dssim) * L_L1 + lambda_dssim * ssim_loss + reg_loss
    
    return loss

### Parameters
*   `numchannels`: Number of channels for background color and potentially RGB decoder output. Default: 9.
*   `scaling_modifier`: Passed to the render function. Default: 1.0.
*   `basicfunction`: Passed to the render function. Default: `trbfunction`.
*   `GRsetting` and `GRzer`: Retrieved from `getrenderpip`.
*   `opt.densify`: Densification mode (0, 1, 2, or 3).
*   `opt.reg`: Regularization type (1, 4, 6, 7, 8, 9, 10).
*   `opt.lambda_dssim`: Weight for D-SSIM loss.
*   `opt.regl`: Weight for regularization term.
*   `opt.densify_from_iter`: Iteration after which densification starts.
*   `opt.densify_until_iter`: Iteration after which motion parameters are frozen.
*   `opt.densification_interval`: Interval between densification steps.
*   `opt.opacity_reset_interval`: Interval between opacity resets.
*   `opt.desicnt`: Threshold for densification count.
*   `opt.densify_grad_threshold`: Gradient threshold for densification.
*   `opt.opthr`: Opacity threshold for pruning.
*   `size_threshold`: Size threshold for densification. Set to 20 if `iteration > opt.opacity_reset_interval`, else `None`.

### Edge Cases and Pitfalls
*   **RGB Decoder:** If `gaussians.rgbdecoder` is not `None`, it must be moved to CUDA and set to `eval` mode before rendering [S1, unofficial].
*   **Pruning Logic:** Pruning logic differs based on the densification phase. Before `opt.desicnt` is reached, densification is performed. After, pruning is based on opacity threshold if `iteration < 7000`. After `opt.densify_until_iter`, pruning is based on Z-coordinate < 4.5 if `iteration % 1000 == 500` [S1, unofficial].
*   **Time Tensor:** If `gaussians.ts` is `None`, it must be initialized as a tensor of ones with shape `(1, 1, H, W)` on CUDA, where H and W are from the first test camera [S1, unofficial].

## Subtopics

### SpacetimeGaussians Densification & Pruning Schedule
A training iteration schedule that controls Gaussian densification, pruning, and parameter freezing based on iteration count, mode selection, and visibility metrics. It selects densification mode via `densify` parameter (0, 1, 2, or 3). If `densify == 1`, it prunes points where `gaussians._xyz[:,2] < 4.5` at iteration 1000, and resets opacity every 3000 iterations. If `densify == 3`, it updates `max_radii2D` and `add_densification_stats` every iteration, densifies/prunes clones at intervals, prunes low-opacity points if `iteration < 7000`, resets opacity every `opt.opacity_reset_interval`, and calls `removeminmax` at iteration 10000. Parameters include `size_threshold` (set to 20 if `iteration > opt.opacity_reset_interval`, otherwise `None`), and various `opt.*` thresholds and intervals for densification, pruning, and opacity resets [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of Gaussians and pixels, as it relies on the differentiable rasterization of 3D Gaussians. The densification and pruning steps add overhead proportional to the number of Gaussians.
*   **Memory Complexity:** Linear with respect to the number of Gaussians. The background tensor and time tensor have fixed sizes.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales with the number of Gaussians and the resolution of the rendered images.
*   **Strengths:** Real-time dynamic view synthesis, adaptive density control, stable training through parameter freezing.
*   **Limitations:** Complexity of the training schedule, potential for instability if parameters are not tuned correctly.
*   **When to use:** When real-time dynamic view synthesis is required and the scene has significant motion.
*   **When not to use:** For static scenes or scenes with minimal motion, where standard 3D Gaussian Splatting may be sufficient.

## Background
The SpacetimeGaussians method was introduced by Li, Zhan, Chen, Zhang, Li, Zhong, and Xu, Yi in the paper "Spacetime Gaussian Feature Splatting for Real-Time Dynamic View Synthesis" presented at the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR) in June 2024 [S1, unofficial]. It builds on the 3D Gaussian Splatting method by Kerbl, Bernhard, Kopanas, Georgios, Leimkühler, Thomas, and Drettakis, George, published in ACM Transactions on Graphics in July 2023 [S1, unofficial]. The code is available on GitHub at https://github.com/oppo-us-research/SpacetimeGaussians [S1, unofficial].
