# QuantumGS

Also called: Quantum 3D Gaussian Splatting

## Overview
QuantumGS is a hybrid quantum-classical framework that integrates Variational Quantum Circuits (VQCs) into the 3D Gaussian Splatting pipeline to capture high-frequency view-dependent effects, such as sharp reflections and transparency, which classical Multi-Layer Perceptrons (MLPs) struggle to model efficiently in low-parameter regimes [S1]. It distinguishes itself from standard view-dependent splatting by mapping viewing directions directly onto the Bloch sphere, leveraging the natural geometry of qubits to represent 3D directional data and achieving higher expressivity through quantum entanglement [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D Gaussian primitive with base color (encoded via Spherical Harmonics), opacity, position, covariance, and a normalized viewing direction vector $\mathbf{d} = [d_x, d_y, d_z]$.
*   **Output:** Refined color $c' = c + \Delta c(\mathbf{d})$ and opacity $\alpha' = \alpha + \Delta \alpha(\mathbf{d})$, where $\Delta c$ and $\Delta \alpha$ are view-dependent corrections derived from the quantum processing.

**Data Structures:**
*   **Viewing Direction:** Normalized 3D vector $\mathbf{d} \in \mathbb{R}^3$ with $\|\mathbf{d}\| = 1$.
*   **Quantum State:** A 3-qubit state $|\psi\rangle \in \mathbb{C}^8$, represented as a superposition of basis states $|000\rangle$ to $|111\rangle$.
*   **VQC Parameters:** A set of rotation angles $\theta = \{\theta_{j,\ell}, \phi_{j,\ell}\}$ for $j \in \{0,1,2\}$ (qubits) and $\ell \in \{1,\dots,L\}$ (layers).
*   **Feature Vector:** A 3D vector $\mathbf{v}_{quantum} = (\langle Z_0 \rangle, \langle Z_1 \rangle, \langle Z_2 \rangle)$ where each component is in $[-1, 1]$.

**Numbered Steps:**

1.  **Directional Encoding:** Encode the normalized viewing direction $\mathbf{d}$ into a 3-qubit initial state $|\psi_{enc}\rangle$ by mapping the spherical coordinates of $\mathbf{d}$ to the Bloch sphere of each qubit.
    *   Calculate polar angle $\theta = \arccos(d_z)$ and azimuthal angle $\phi = \operatorname{atan2}(d_y, d_x)$.
    *   Apply rotation gates to each qubit $j \in \{0, 1, 2\}$ initialized to $|0\rangle$:
        $$ |\psi_{enc}\rangle = \bigotimes_{j=0}^{2} R_z^{(j)}(\phi) R_y^{(j)}(\theta) |0\rangle^{\otimes 3} $$
    *   Here, $R_y(\theta) = \exp(-i \frac{\theta}{2} Y)$ and $R_z(\phi) = \exp(-i \frac{\phi}{2} Z)$, where $Y$ and $Z$ are Pauli matrices [S1]. This creates a diffeomorphic mapping that preserves the manifold structure of $S^2$ [S1].

2.  **Variational Quantum Circuit Processing:** Process $|\psi_{enc}\rangle$ through a VQC ansatz $U(\theta; L)$ consisting of $L=4$ layers [S1]. The full transformation is:
    $$ |\psi_{out}\rangle = U(\theta; L)|\psi_{enc}\rangle = U^{(L)}(\theta_L) \cdots U^{(1)}(\theta_1)|\psi_{enc}\rangle $$
    where each layer $U^{(\ell)}(\theta_\ell)$ is defined as:
    $$ U^{(\ell)}(\theta_\ell) = U_{ent}^{(\ell)} \bigotimes_{j=0}^{2} R_j(\theta_{j,\ell}, \phi_{j,\ell}) $$
    *   **Single-Qubit Rotations:** For each qubit $j$ and layer $\ell$, apply trainable rotations $R_j(\theta_{j,\ell}, \phi_{j,\ell})$. These angles are learned parameters (generated by a hypernetwork in Pipeline I or shared in Pipeline II) that define how the viewing direction transforms [S1].
    *   **Circular Entanglement:** Apply a cyclic CNOT sequence to entangle all three qubits, creating correlations between color channels and opacity:
        $$ U_{ent} = \text{CNOT}_{0\to1} \text{CNOT}_{1\to2} \text{CNOT}_{2\to0} $$
        This ring topology ensures view-dependent effects emerge from the joint quantum state [S1].

3.  **Measurement:** Perform computational basis measurements of the output state $|\psi_{out}\rangle$ in the Z-basis.
    *   Compute the expectation values $\langle Z_j \rangle$ for each qubit $j \in \{0, 1, 2\}$.
    *   Form the 3D quantum feature vector $\mathbf{v}_{quantum} = (\langle Z_0 \rangle, \langle Z_1 \rangle, \langle Z_2 \rangle) \in [-1, 1]^3$ [S1].

4.  **Classical Refinement:** Feed $\mathbf{v}_{quantum}$ into a lightweight classical Multi-Layer Perceptron (MLP).
    *   The MLP outputs view-dependent refinements $\Delta c(\mathbf{d})$ and $\Delta \alpha(\mathbf{d})$.
    *   Update the Gaussian attributes: $c' = c + \Delta c(\mathbf{d})$ and $\alpha' = \alpha + \Delta \alpha(\mathbf{d})$ [S1].

**Dual-Pipeline Framework:**
*   **Pipeline I (Per-Gaussian):** A hypernetwork generates unique VQC parameters (rotation angles) for each Gaussian, maximizing local expressivity [S1].
*   **Pipeline II (Global):** A shared VQC with hash-conditioned global parameters processes spatial and directional hash features to scale to real-world scenes [S1].

**Pseudocode:**

```python
import numpy as np

def encode_viewing_direction(d):
    """
    Encodes a normalized viewing direction d into a 3-qubit state.
    Returns the initial state vector |psi_enc> in the computational basis.
    """
    # d is a numpy array of shape (3,) with norm 1
    dz = d[2]
    dx = d[0]
    dy = d[1]
    
    # Calculate spherical coordinates
    theta = np.arccos(np.clip(dz, -1.0, 1.0))
    phi = np.arctan2(dy, dx)
    
    # Initialize 3-qubit state |000>
    # State vector size is 2^3 = 8
    psi = np.zeros(8, dtype=complex)
    psi[0] = 1.0  # |000>
    
    # Apply rotations to each qubit j=0,1,2
    # R_y(theta) and R_z(phi) are applied sequentially to each qubit
    # Since they act on different qubits, they commute, but we apply them per qubit
    
    # Pauli Y and Z matrices
    Y = np.array([[0, -1j], [1j, 0]])
    Z = np.array([[1, 0], [0, -1]])
    
    # Identity for other qubits
    I = np.eye(2)
    
    # Construct rotation matrices for each qubit
    # R_y(theta) = exp(-i * theta/2 * Y)
    # R_z(phi) = exp(-i * phi/2 * Z)
    
    # We can compute the single-qubit rotation matrices explicitly
    # R_y(theta) = [[cos(theta/2), -sin(theta/2)], [sin(theta/2), cos(theta/2)]]
    # R_z(phi) = [[exp(-i*phi/2), 0], [0, exp(i*phi/2)]]
    
    cos_t2 = np.cos(theta / 2)
    sin_t2 = np.sin(theta / 2)
    R_y = np.array([[cos_t2, -sin_t2], [sin_t2, cos_t2]])
    
    exp_m_i_phi_2 = np.exp(-1j * phi / 2)
    exp_i_phi_2 = np.exp(1j * phi / 2)
    R_z = np.array([[exp_m_i_phi_2, 0], [0, exp_i_phi_2]])
    
    # Apply to each qubit
    # Qubit 0 (LSB in some conventions, but let's stick to tensor product order)
    # |psi> = q0 \otimes q1 \otimes q2
    # We apply R_z(phi) R_y(theta) to each qubit
    
    # Operator for qubit 0: R_z(phi) R_y(theta) \otimes I \otimes I
    Op0 = np.kron(np.kron(R_z @ R_y, I), I)
    # Operator for qubit 1: I \otimes R_z(phi) R_y(theta) \otimes I
    Op1 = np.kron(np.kron(I, R_z @ R_y), I)
    # Operator for qubit 2: I \otimes I \otimes R_z(phi) R_y(theta)
    Op2 = np.kron(np.kron(I, I), R_z @ R_y)
    
    # Combined initial encoding operator
    # Since they act on different qubits, we can apply them sequentially or multiply
    # The source says: |psi_enc> = \otimes_{j=0}^2 R_z^{(j)} R_y^{(j)} |0>
    # This implies the state is the tensor product of individual qubit states.
    # We can construct the state directly as the tensor product of single-qubit states.
    
    # Single qubit state after R_z R_y |0>
    # |0> = [1, 0]^T
    # R_y |0> = [cos(t/2), sin(t/2)]^T
    # R_z (R_y |0>) = [exp(-i phi/2) cos(t/2), exp(i phi/2) sin(t/2)]^T
    
    alpha = np.exp(-1j * phi / 2) * cos_t2
    beta = np.exp(1j * phi / 2) * sin_t2
    single_qubit_state = np.array([alpha, beta])
    
    # Tensor product of 3 identical states
    psi = np.kron(np.kron(single_qubit_state, single_qubit_state), single_qubit_state)
    
    return psi

def apply_vqc_layer(psi, angles):
    """
    Applies one layer of the VQC.
    angles: list of (theta_j, phi_j) for j=0,1,2
    """
    # Single qubit rotations
    I = np.eye(2)
    Y = np.array([[0, -1j], [1j, 0]])
    Z = np.array([[1, 0], [0, -1]])
    
    # Build rotation operators for each qubit
    # R_j(theta, phi) = R_z(phi) R_y(theta)
    
    ops = []
    for j in range(3):
        theta, phi = angles[j]
        cos_t2 = np.cos(theta / 2)
        sin_t2 = np.sin(theta / 2)
        R_y = np.array([[cos_t2, -sin_t2], [sin_t2, cos_t2]])
        exp_m_i_phi_2 = np.exp(-1j * phi / 2)
        exp_i_phi_2 = np.exp(1j * phi / 2)
        R_z = np.array([[exp_m_i_phi_2, 0], [0, exp_i_phi_2]])
        R_j = R_z @ R_y
        
        # Construct full operator for this qubit
        if j == 0:
            Op = np.kron(np.kron(R_j, I), I)
        elif j == 1:
            Op = np.kron(np.kron(I, R_j), I)
        else:
            Op = np.kron(np.kron(I, I), R_j)
        ops.append(Op)
    
    # Apply single qubit rotations
    psi = ops[0] @ psi
    psi = ops[1] @ psi
    psi = ops[2] @ psi
    
    # Circular Entanglement: CNOT_0->1 CNOT_1->2 CNOT_2->0
    # CNOT control qubit k, target qubit m
    # CNOT matrix in computational basis
    def CNOT(control, target, num_qubits=3):
        # Construct CNOT matrix for num_qubits qubits
        # Control is 'control', Target is 'target'
        # This is a simplified implementation for 3 qubits
        # Indices: 0 is LSB or MSB? Let's assume standard binary representation
        # |q2 q1 q0> -> index 4*q2 + 2*q1 + q0
        # CNOT_0->1: Control qubit 0 (LSB), Target qubit 1
        # CNOT_1->2: Control qubit 1, Target qubit 2
        # CNOT_2->0: Control qubit 2, Target qubit 0
        
        # We will build the matrix by applying to basis states
        mat = np.zeros((8, 8), dtype=complex)
        for i in range(8):
            # Decode index to bits
            q0 = i & 1
            q1 = (i >> 1) & 1
            q2 = (i >> 2) & 1
            
            # Apply CNOTs
            # CNOT_0->1
            if q0 == 1:
                q1 = 1 - q1
            # CNOT_1->2
            if q1 == 1:
                q2 = 1 - q2
            # CNOT_2->0
            if q2 == 1:
                q0 = 1 - q0
            
            j = q2 * 4 + q1 * 2 + q0
            mat[j, i] = 1.0
            
        return mat

    U_ent = CNOT(0, 1) @ CNOT(1, 2) @ CNOT(2, 0)
    psi = U_ent @ psi
    
    return psi

def measure_quantum_state(psi):
    """
    Measures the state in the Z-basis and returns expectation values <Z_j>.
    """
    # Probability of |0> and |1> for each qubit
    # <Z_j> = P(0) - P(1)
    
    probs = np.abs(psi)**2
    
    # Qubit 0 (LSB): indices where bit 0 is 0 or 1
    # Indices: 0,2,4,6 have q0=0; 1,3,5,7 have q0=1
    p0_0 = np.sum(probs[[0, 2, 4, 6]])
    p1_0 = np.sum(probs[[1, 3, 5, 7]])
    z0 = p0_0 - p1_0
    
    # Qubit 1: indices where bit 1 is 0 or 1
    # Indices: 0,1,4,5 have q1=0; 2,3,6,7 have q1=1
    p0_1 = np.sum(probs[[0, 1, 4, 5]])
    p1_1 = np.sum(probs[[2, 3, 6, 7]])
    z1 = p0_1 - p1_1
    
    # Qubit 2: indices where bit 2 is 0 or 1
    # Indices: 0,1,2,3 have q2=0; 4,5,6,7 have q2=1
    p0_2 = np.sum(probs[[0, 1, 2, 3]])
    p1_2 = np.sum(probs[[4, 5, 6, 7]])
    z2 = p0_2 - p1_2
    
    return np.array([z0, z1, z2])

def quantumgs_forward(d, vqc_params, mlp):
    """
    Full QuantumGS forward pass.
    d: viewing direction (3,)
    vqc_params: list of 4 layers, each layer has 3 tuples of (theta, phi)
    mlp: classical MLP function
    """
    # 1. Encode
    psi = encode_viewing_direction(d)
    
    # 2. Process through VQC
    for layer_angles in vqc_params:
        psi = apply_vqc_layer(psi, layer_angles)
        
    # 3. Measure
    v_quantum = measure_quantum_state(psi)
    
    # 4. Refine
    delta_c, delta_alpha = mlp(v_quantum)
    
    return delta_c, delta_alpha
```

## Operating characteristics
*   **Complexity:** The quantum simulation of 3 qubits requires managing an 8-dimensional complex vector space, which is computationally lightweight for classical simulation but represents a high-dimensional feature space relative to the input. The VQC has $L=4$ layers with 3 qubits, resulting in a manageable number of trainable parameters per Gaussian in Pipeline I or globally in Pipeline II.
*   **Performance:** The method achieves higher expressivity and better generalization for view-dependent effects compared to classical MLPs in low-parameter regimes [S1].
*   **Strengths:** Physically consistent basis for modeling light-surface interactions; captures high-frequency effects like sharp reflections and transparency; scalable via dual-pipeline approach (hypernetwork for local, hash-conditioned for global) [S1].
*   **Limitations:** Requires simulation of quantum circuits (or access to quantum hardware); potential precision issues in simulating exponential state spaces if scaled beyond 3 qubits; complexity in integrating quantum gradients into classical training loops (not detailed in sources) [S1].
*   **When to use:** When modeling complex view-dependent appearance (specularities, transparency) with limited parameters is critical, and classical MLPs are insufficient [S1].

## Background
QuantumGS was introduced by Wilczyński et al. in 2026 as a novel hybrid framework integrating Variational Quantum Circuits into the 3D Gaussian Splatting pipeline [S1]. It addresses the limitations of Viewing Direction Gaussian Splatting (VDGS) and classical MLPs in capturing high-frequency view-dependent effects with low parameter counts [S1]. The work builds on the shift from implicit NeRFs to explicit 3DGS and relates to prior quantum graphics research like QKAN-GS, which focused on storage efficiency rather than view-dependent appearance [S1].
