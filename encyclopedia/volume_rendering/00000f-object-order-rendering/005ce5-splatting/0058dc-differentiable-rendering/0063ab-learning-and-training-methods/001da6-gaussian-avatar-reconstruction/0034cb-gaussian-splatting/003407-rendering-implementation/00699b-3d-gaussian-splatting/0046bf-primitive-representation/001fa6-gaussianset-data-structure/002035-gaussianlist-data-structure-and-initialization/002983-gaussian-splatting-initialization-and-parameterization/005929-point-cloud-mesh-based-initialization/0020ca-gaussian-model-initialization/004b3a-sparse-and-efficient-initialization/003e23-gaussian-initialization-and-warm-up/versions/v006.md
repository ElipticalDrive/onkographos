# Gaussian Initialization and Warm-up

Also called: Random initialization, Warm-up stage

## Overview
Gaussian Initialization and Warm-up establishes the initial state of 3D Gaussians for radiance-field optimization, solving the problem of poor convergence and incorrect placement caused by naive random initialization. It sets apart from standard 3D Gaussian Splatting by introducing a static warm-up phase and specific biasing strategies (low reflectivity, background perturbation) to ensure Gaussians are placed in useful positions before complex dynamics or densification are introduced [S1].

## How it works
**Inputs:** Camera poses (intrinsics/extrinsics), near/far plane distances, initial image data (e.g., C-ToF quarts or RGB), and optional color sequences.
**Outputs:** A set of 3D Gaussians with initialized means $\mu_i$, covariances $\Sigma_i$, opacities $\alpha_i$, and spherical harmonic coefficients $C_i$.

**Data Structures:**
*   **Gaussian Set:** A list of $N$ Gaussians.
*   **Gaussian Fields:**
    *   $\mu_i \in \mathbb{R}^3$: Mean position.
    *   $\Sigma_i \in \mathbb{R}^{3 \times 3}$: Covariance matrix (often parameterized as rotation $R_i \in SO(3)$ and scale $s_i \in \mathbb{R}^3$).
    *   $\alpha_i \in [0, 1]$: Opacity.
    *   $C_i$: Spherical Harmonic coefficients.

**Steps:**

1.  **Random Placement within Frustum:**
    Sample Gaussian means $\mu_i$ uniformly within the camera frustum, bounded by the near and far planes [S1].
    *   *Note:* If using real-world units, coordinates may be large. Rescale input coordinates to any associated MLP using the unambiguous depth range to ensure most values lie within $[0, 1]$ [S1].

2.  **Low Reflectivity Bias Initialization:**
    Initialize opacity/reflectivity $\alpha_i$ to a low value, typically between $0.01$ and $0.1$ [S1].
    *   *Rationale:* High initial reflectivity (e.g., $0.5$) combined with occupancy bias causes Gaussians in low-reflectivity regions to be incorrectly placed far from the camera due to inverse-square falloff assumptions. This leads to multiple opacity peaks and interference from closer splats before reflectivity can be corrected. Low initial reflectivity allows Gaussians to be placed more correctly, closer to the true scene depth [S1].
    *   *Comparison:* Combining occupancy and low-reflectivity biases is effective for both low and high reflectivity regions. Using only occupancy bias harms low-reflectivity regions [S1].

3.  **Static Warm-up Phase:**
    Run an initial optimization stage for a fixed number of iterations (typically $2,000$) assuming the scene is static [S1].
    *   *Purpose:* This places Gaussians into useful positions before introducing dynamics or densification [S1].

4.  **Background Perturbation (Optional/Conditional):**
    For sensitive low-reflectivity areas, randomly change the background signal $q_{bg}$ uniformly between $-1$ and $1$ at each optimization iteration [S1].
    *   *Rationale:* A low background contribution can cause Gaussians to fail to place on surfaces because the background already reproduces the signal, resulting in only low-contributing Gaussians [S1].

5.  **Fine-tuning/Recoloring Initialization (If Voxelization is Used):**
    If Gaussian means are fixed via voxelization, initialize remaining attributes ($\Sigma_i, C_i, \alpha_i$) by averaging attributes within each voxel [S3].
    *   Initialize DC colors $C_i^{(dc)}$, high-frequency SH coefficients $C_i^{(ac)}$, and opacities $\alpha_i$ by averaging within the voxel [S3].
    *   Initialize covariance $\Sigma_i$ using the largest volume Gaussian in the voxel [S3].
    *   *Pitfall:* Initializing attributes to zero takes more iterations and often results in sub-optimal rendering quality because Gaussian splitting and merging are disabled during retraining [S3].
    *   *Performance:* This initialization requires approximately $8,000$ iterations to approach ground-truth PSNR, whereas fine-tuning without initialization requires $30,000$ iterations and may fail to recover ground-truth PSNR at higher compression rates [S3].

**Pseudocode:**

```python
def initialize_gaussians(cameras, images, num_gaussians, warmup_iters=2000):
    """
    Initialize 3D Gaussians for radiance field optimization.
    
    Args:
        cameras: List of camera objects with intrinsics and extrinsics.
        images: List of input images (e.g., C-ToF quarts or RGB).
        num_gaussians: Number of Gaussians to initialize.
        warmup_iters: Number of static warm-up iterations.
        
    Returns:
        gaussians: Initialized Gaussian parameters.
    """
    gaussians = []
    
    # Step 1: Random Placement within Frustum
    for i in range(num_gaussians):
        # Sample mean uniformly within camera frustum (near to far plane)
        mu = sample_random_point_in_frustum(cameras[0]) # Assuming first camera for initial placement
        
        # Step 2: Low Reflectivity Bias
        # Initialize opacity to low value [0.01, 0.1]
        alpha = random.uniform(0.01, 0.1)
        
        # Initialize covariance (e.g., small isotropic)
        # Sigma = diag(s^2) where s is small
        scale = random.uniform(0.01, 0.1)
        sigma = scale * np.eye(3)
        
        # Initialize SH coefficients (e.g., zero or small random)
        sh_coeffs = np.zeros(num_sh_bases)
        
        gaussians.append({
            'mu': mu,
            'alpha': alpha,
            'sigma': sigma,
            'sh_coeffs': sh_coeffs
        })
        
    # Step 3: Static Warm-up Phase
    # Assume scene is static for warmup_iters
    for iteration in range(warmup_iters):
        # Render current Gaussians
        rendered_images = render_gaussians(gaussians, cameras)
        
        # Step 4: Background Perturbation (for sensitive low-reflectivity areas)
        # Randomly change background signal uniformly between -1 and 1
        # This is applied to the target or background model during loss calculation
        background_noise = random.uniform(-1, 1)
        
        # Compute Loss (e.g., L2/SSIM between rendered and input images)
        loss = compute_loss(rendered_images, images, background_noise)
        
        # Backpropagate and update Gaussians (positions, opacities, etc.)
        update_gaussians(gaussians, loss)
        
    return gaussians
```

## Subtopics

### Low-Reflectivity Bias
A specific initialization heuristic where Gaussian reflectivity (opacity) is set to a low value (0.01 to 0.1) [S1]. It prevents Gaussians in low-reflectivity regions from being incorrectly placed far from the camera due to inverse-square falloff assumptions, which would otherwise lead to multiple opacity peaks and interference from closer splats [S1]. Low initial reflectivity allows Gaussians to be placed more correctly, closer to the true scene depth [S1]. Combining this with occupancy bias is effective for both low and high reflectivity regions, whereas using only occupancy bias harms low-reflectivity regions [S1].

### APMGSRN Initialization
A method for initializing transformation matrices and feature grids in multi-grid scene representation networks [S2]. Transformation matrices are initialized to cover a near global domain with small random shears, rotations, and translations. Diagonals are sampled from $N(1, 0.05)$, and remaining entries in the first three rows are sampled from $N(0, 0.05)$ [S2]. This ensures each entry is non-zero, guaranteeing gradients can update each entry [S2]. Feature grids are initialized from $U(-0.0001, 0.0001)$, and decoder weights follow Glorot and Bengio [S2].

### Fine-tuning/Recoloring with Initialization
A constrained retraining process that fixes Gaussian means after voxelization and fine-tunes remaining attributes ($\Sigma, C, \alpha$) [S3]. Attributes are initialized by averaging within each voxel, with covariance initialized from the largest volume Gaussian in the voxel [S3]. This reduces fine-tuning iterations from 30K to ~8K and prevents sub-optimal quality associated with zero-initialization [S3].

### Appearance-aware Rendering with Color Correction
A mechanism to handle lighting variations by applying per-cluster color correction $\Delta c_i$ based on camera appearance embedding and cluster embedding [S4, unofficial]. The correction is computed as $\Delta c_i = F_\phi (\text{Concat}(E_c[k_i], E_{app}[n]))$ [S4, unofficial]. The final color is blended using $\hat{C} = \sum_{i=1}^{N} \frac{(c_i + \Delta c_i) \cdot w_{k_i,n}[l_i] \cdot \alpha_i}{\prod_{j=1}^{i-1} (1 - w_{k_j,n}[l_j] \cdot \alpha_j)}$ [S4, unofficial].

## Operating characteristics
*   **Time Complexity:** The warm-up phase adds a fixed cost of $O(I_{warmup} \cdot N \cdot P)$, where $I_{warmup}$ is the number of warm-up iterations (typically 2,000), $N$ is the number of Gaussians, and $P$ is the number of pixels [S1].
*   **Memory Complexity:** Initialization requires storing the initial parameters for $N$ Gaussians. No additional significant memory overhead compared to standard initialization [S1].
*   **Performance:** The warm-up stage significantly improves convergence speed and final reconstruction quality by placing Gaussians in useful positions early [S1]. Low-reflectivity bias prevents incorrect placement in low-reflectivity regions, improving fidelity [S1].
*   **Strengths:** Robust to initial placement errors; handles low-reflectivity regions better than standard initialization; reduces total training time by avoiding early misplacement [S1].
*   **Limitations:** Requires additional iterations for warm-up; background perturbation may introduce noise if not tuned correctly [S1].
*   **When to Use:** When initializing 3D Gaussians for radiance fields, especially in dynamic scenes or scenes with varying reflectivity [S1].

## Background
The method originates from work on optimizing depth indirectly in dynamic radiance fields using 3D Gaussians, specifically in the context of Time-of-Flight (C-ToF) data [S1]. The warm-up stage and low-reflectivity bias were introduced to address the challenges of initializing Gaussians for dynamic scenes and low-reflectivity regions, which are common in C-ToF imaging [S1]. The fine-tuning/recoloring initialization was introduced in the context of adaptive voxelization for transform coding of 3D Gaussian Splatting data [S3]. The appearance-aware rendering with color correction was introduced in PyGS, a large-scale scene representation method using pyramidal 3D Gaussian Splatting [S4, unofficial].
