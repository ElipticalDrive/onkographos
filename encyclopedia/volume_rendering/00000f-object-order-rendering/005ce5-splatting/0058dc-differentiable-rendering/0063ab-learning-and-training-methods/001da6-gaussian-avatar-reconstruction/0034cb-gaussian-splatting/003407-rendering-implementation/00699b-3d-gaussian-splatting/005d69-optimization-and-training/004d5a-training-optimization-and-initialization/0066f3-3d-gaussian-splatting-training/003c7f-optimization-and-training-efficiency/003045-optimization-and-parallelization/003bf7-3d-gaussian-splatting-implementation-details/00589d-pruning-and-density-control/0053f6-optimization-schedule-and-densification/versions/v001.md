# Optimization Schedule and Densification

Also called: Densification Schedule, Adaptive Densification

## Overview
This family defines the temporal schedule and geometric criteria for modifying the set of 3D Gaussian primitives during training, specifically addressing when and how to split, clone, or prune Gaussians to balance reconstruction fidelity with computational efficiency. It sets itself apart from static initialization methods by dynamically adapting the primitive count and distribution based on optimization gradients and rendering errors, building on [3D Gaussian Splatting Implementation Details](9128-3d-gaussian-splatting-implementation-details.md).

## Shared principles
The core mechanism involves periodic evaluation of Gaussian primitives against specific criteria (gradient magnitude, opacity, or spatial coverage) to trigger structural changes. The primary operations are:
1.  **Splitting:** Dividing a large Gaussian into smaller ones to capture high-frequency details.
2.  **Cloning:** Duplicating a Gaussian to increase density in under-represented regions without changing scale significantly.
3.  **Pruning:** Removing Gaussians with low opacity or minimal contribution to the rendered image to reduce memory and compute load.

These operations are typically gated by iteration counts (e.g., "every 100 iterations") and thresholds derived from the optimization state. The shared goal is to prevent premature convergence to local minima and ensure uniform coverage of the scene geometry.

## Subtopics

### [Error-Driven 2D Gaussian Training](13985-error-driven-2d-gaussian-training.md)
Error-Driven 2D Gaussian Training is a densification strategy that samples and optimizes 2D Gaussian kernels in image space using a differentiable rasterizer, then back-projects them to 3D to initialize new 3D Gaussians [13985-error-driven-2d-gaussian-training.md]. It solves the problem of initializing view-dependent Gaussian kernels for complex specular radiance reconstruction, where standard 3D initialization may be insufficient [13985-error-driven-2d-gaussian-training.md]. It sets itself apart from standard 3DGS densification by performing optimization in 2D image space with pre-rendered images as fixed backgrounds, rather than directly manipulating 3D primitives [13985-error-driven-2d-gaussian-training.md].

### QuickSplat Optimization Process
An optimization framework for 3D Gaussian Splatting that uses learned networks for initialization, densification, and parameter updates to accelerate surface reconstruction [S1]. It replaces heuristic gradient-based densification with neural networks [S1].
*   **Initialization:** Gaussian set $G_0$ is generated from Structure-from-Motion (SfM) points $P$ using an initializer network $f_I$: $G_0 \leftarrow f_I(P)$ [S1].
*   **Iteration:** For $t = 0$ to $T-1$:
    1.  Reset gradient accumulator $\nabla G_t \leftarrow 0$ [S1].
    2.  For all images, compute rendering loss $L$, compute gradient $\delta G_t$, and accumulate: $\nabla G_t \leftarrow \nabla G_t + \delta G_t$ [S1].
    3.  Generate new Gaussians $\hat{G}_t$ using a densifier network $f_D$ on current Gaussians $G_t$, accumulated gradients $\nabla G_t$, and time step $t$: $\hat{G}_t \leftarrow f_D(G_t, \nabla G_t, t)$ [S1].
    4.  Concatenate new Gaussians: $\bar{G}_t \leftarrow G_t \cup \hat{G}_t$ [S1].
    5.  Compute update $\Delta \bar{G}_t$ using an optimizer network $f_O$: $\Delta \bar{G}_t \leftarrow f_O(\bar{G}_t, \nabla \bar{G}_t, t)$ [S1].
    6.  Update Gaussians: $G_{t+1} \leftarrow \bar{G}_t + \Delta \bar{G}_t$ [S1].

### BlitzGS Optimization Schedule
A schedule designed to reduce active workload by managing density control and Level-of-Detail (LOD) gating [S2, unofficial].
*   **Density Control Window:** Runs every 1,000 steps from iteration 2,000 up to 32,000 (last event at 31,000) [S2, unofficial].
*   **LOD Gate:** Disabled during the density-control window (iterations 2,000–32,000) [S2, unofficial]. Engaged after the first importance-scoring pass ($T_1$) [S2, unofficial].
*   **Gradient Reweighting:** After the importance-scoring pass, density-control gradients are reweighted using the per-Gaussian visibility factor $\phi_i$ for the remainder of the density-control window [S2, unofficial].
*   **Comparison:** Extending training iterations (e.g., 500k–1000k) does not significantly improve quality on aerial scenes (e.g., Building 19.27→19.50 dB), indicating deficits stem from representation structure rather than insufficient budget [S2, unofficial].

### Normal Gradient Based Densification
A densification criterion to improve normal recovery in thin regions by introducing an additional densification criterion on the gradient of normals, beyond the vanilla 3DGS gradient of view space points [S3].
*   **Criterion:** Densify Gaussians whose normal gradient exceeds a threshold $T_n$ [S3].
*   **Parameter:** $T_n$ is typically set to $2 \times 10^{-9}$ [S3].

### Global-to-local densification
A densification strategy that decouples split and clone operations across densification phases to accelerate optimization. It uses split for global spread at low resolution and suppresses clone, then reintroduces clone for local refinement at full resolution [S4, unofficial].
*   **Mechanism:**
    1.  Calculate the norm of the average position gradient of each Gaussian primitive every 100 iterations [S4, unofficial].
    2.  If the gradient norm exceeds a predefined threshold, check the maximum scale of the Gaussian primitive [S4, unofficial].
    3.  If the maximum scale exceeds a given scale threshold, split the Gaussian into smaller components [S4, unofficial].
    4.  Otherwise, clone the Gaussian with the same parameters [S4, unofficial].
    5.  During low-resolution training, promote Gaussian primitives' global spread with the split operation and suppress clone operations to prevent premature local clustering [S4, unofficial].
    6.  When transitioning to full-resolution training, reintroduce clone operations to refine high-frequency details [S4, unofficial].
*   **Comparison:** Unlike standard 3DGS which applies split and clone simultaneously, this method decouples them across phases (global vs local) to address inefficient spatial spread and redundant primitives [S4, unofficial].

## Background
The concept of adaptive densification originated with the introduction of 3D Gaussian Splatting (3DGS), which established the baseline split and clone operations based on position gradients and opacity thresholds [26]. Subsequent work has focused on optimizing the schedule (e.g., BlitzGS) to reduce training time, improving geometric fidelity in specific regions (e.g., Normal Gradient Based Densification), and decoupling operations for efficiency (e.g., Global-to-local densification). More recent approaches explore learned densification networks (e.g., QuickSplat) and image-space optimization for initialization (e.g., Error-Driven 2D Gaussian Training).
