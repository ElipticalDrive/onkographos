# Gaussian Geometry Parameters Prediction

Also called: EVolSplat, Efficient Volume-based Gaussian Splatting, GRM, Gaussian MLP Heads, Gaussian Representation Model

## Overview
Gaussian Geometry Parameters Prediction is a method for generating 3D Gaussian Splatting (3DGS) primitives via a single feed-forward pass, typically using a neural network to predict geometric attributes (position, scale, rotation, opacity) from input images or a global volume [S1, S5]. It solves the problem of slow, iterative per-scene optimization required by standard 3DGS, enabling real-time reconstruction and generalizable synthesis [S5]. It differs from standard initialization methods (e.g., [Random Large-Variance Initialization](6129-random-large-variance-initialization.md)) by learning a mapping from data to geometry rather than relying on heuristic point-cloud distribution, and from pixel-aligned methods (e.g., MVSplat) by using global volumetric context to reduce ghosting artifacts [S5].

## How it works
The method predicts Gaussian parameters using neural networks conditioned on input data (images, depth, or a feature volume). Two primary architectural approaches are documented: global volume-based prediction (EVolSplat) and sequential decoder prediction (GRM).

### Inputs and Outputs
*   **Inputs:**
    *   Set of $N$ input images $\{I_n\}_{n=1}^N$ [S5].
    *   Optional: Metric depth maps $\{D_n\}_{n=1}^N$ predicted by an off-the-shelf estimator [S5].
    *   Optional: Tri-plane features $\psi$ representing the scene [S2].
    *   Optional: Global point cloud $P$ initialized from unprojected depth [S5].
*   **Outputs:**
    *   A set of 3D Gaussians $\mathcal{G} = \{(\mu_i, \alpha_i, \Sigma_i, c_i)\}_{i=1}^{N_p}$, where $\mu_i$ is position, $\alpha_i$ is opacity, $\Sigma_i$ is covariance, and $c_i$ is color [S5].

### Data Structures
1.  **Global Point Cloud ($P$):** A set of 3D points in world coordinates, $P \in \mathbb{R}^{N_p \times 3}$, initialized by unprojecting depth maps [S5].
2.  **Feature Volume ($F$):** A sparse 3D tensor $F \in \mathbb{R}^{H \times W \times D \times C}$ extracted by a 3D CNN from $P$ [S5].
3.  **Tri-Plane ($\psi$):** A multi-resolution 4D volume $\psi = \{\psi_l \in \mathbb{R}^4\}_{l \in \{1,2\}}$, factorized into 6 planes per resolution for efficient querying [S3].
4.  **MLP Heads:**
    *   $\mathcal{D}_{pos}$: Predicts position offset [S5].
    *   $\mathcal{D}_{opa}$: Predicts opacity [S5].
    *   $\mathcal{D}_{cov}$: Predicts covariance parameters [S5].
    *   Sequential Decoders: A chain of fully connected networks for color, opacity, rotation, scale, and position offset [S2].

### Steps

#### Approach 1: Global Volume-Based Prediction (EVolSplat)
1.  **Depth Estimation:** Predict metric depth maps $\{D_n\}$ for input images $\{I_n\}$ [S5].
2.  **Point Cloud Construction:** Unproject RGB images using intrinsic $\{K_n\}$ and extrinsic $\{T_n\}$ matrices and depth maps to form $P = \bigcup^N \pi^{-1}(I_n, D_n, T_n, K_n)$ [S5].
3.  **Filtering:** Apply a uniform filter to remove duplicate primitives and a statistical filter to remove floating artifacts from $P$ [S5].
4.  **Feature Extraction:** Feed $P$ into a sparse 3D CNN to extract feature volume $F$ [S5].
5.  **Initialization:** Set initial Gaussian centers $\mu^{init}_i = p_i \in P$ [S5].
6.  **Geometry Prediction (Iterative):**
    *   For each Gaussian $i$, query feature $f_i$ from $F$ at position $\mu^{init}_i + \Delta \mu^{prev}_i$ using trilinear interpolation [S5].
    *   Predict opacity $\alpha_i$ and covariance $\Sigma_i$ using $\mathcal{D}_{opa}$ and $\mathcal{D}_{cov}$ [S5].
    *   Predict position offset $\Delta \mu_i$ using $\mathcal{D}_{pos}$ [S5].
    *   Update position: $\mu_i = \mu^{init}_i + \Delta \mu_i$ [S5].
    *   *Training:* Track $\Delta \mu^{prev}_i$ from the previous iteration [S5].
    *   *Inference:* Initialize $\Delta \mu^{prev}_i = 0$, recursively execute the update rule twice to converge $\Delta \mu_i$, then query $\alpha_i$ and $\Sigma_i$ at the converged position [S5].
7.  **Color Prediction:** Project Gaussians to nearest reference views to retrieve 2D context (color windows, visibility) and decode color $c_i$ [S5].

#### Approach 2: Sequential Decoder Prediction (GRM)
1.  **Feature Input:** Obtain tri-plane features $\psi$ [S2].
2.  **Sequential Decoding:** Decode attributes iteratively in the order: Color $\rightarrow$ Opacity $\rightarrow$ Rotation $\rightarrow$ Scale $\rightarrow$ Position Offset [S2].
3.  **Decoder Architecture:** Each step uses a fully connected network with 3 hidden layers (128 neurons, GELU activation) [S2].
4.  **Dependency:** Each decoder receives the output of the previous decoder and the tri-plane features [S2].
5.  **Output Activation:** Use no activation for most attributes; use inverted Softplus for scale to prevent excessive GPU memory usage [S2].

### Formulas
*   **Rendering:** $c = \sum_{i \in \mathcal{G}} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j)$ [S5].
*   **Feature Query (Tri-Plane):** $f = F_m(f_m)$, where $f_m = \text{BiInterp}(\psi_l(X, e))$ [S3].
*   **Transform Field (FlexGS):** $T_X = \phi_X(f)$, $T_s = \phi_s(f)$, $T_q = \phi_q(f)$ [S3].
*   **Transformed Attributes:** $X' = X + T_X$, $s' = s + T_s$, $q' = q + T_q$ [S3].
*   **Mesh Parameterization (GaMeS):**
    *   Forward: $v_1 = m$, $v_2 = m + s_2 r_2$, $v_3 = m + s_3 r_3$ [S4, unofficial].
    *   Inverse: $\hat{m} = v_1$, $\hat{r}_1 = \frac{(v_2 - v_1) \times (v_3 - v_1)}{\|(v_2 - v_1) \times (v_3 - v_1)\|}$, $\hat{r}_2 = \frac{v_2 - v_1}{\|v_2 - v_1\|}$, $\hat{r}_3 = \text{orth}(v_3 - v_1; \hat{r}_1, \hat{r}_2)$, $\hat{s}_1 = \epsilon$, $\hat{s}_2 = \|v_2 - v_1\|$, $\hat{s}_3 = \langle v_3 - v_1, \hat{r}_3 \rangle$ [S4, unofficial].
    *   Covariance: $\hat{\Sigma} = \hat{R}\hat{S}\hat{S}^T\hat{R}^T$ [S4, unofficial].
*   **EVolSplat Offset Update:**
    *   $f_i = F(\mu^{init}_i + \Delta \mu^{prev}_i)$ [S5].
    *   $\alpha_i = \mathcal{D}_{opa}(f_i)$, $\Sigma_i = \mathcal{D}_{cov}(f_i)$ [S5].
    *   $\Delta \mu_i = \text{Tanh}(\mathcal{D}_{pos}(f_i)) \cdot v_{\text{size}}$, $\mu_i = \mu^{init}_i + \Delta \mu_i$ [S5].

### Parameters
*   **Hidden Layers:** 3 layers, 128 neurons each, GELU activation [S2].
*   **Voxel Size ($v_{\text{size}}$):** Scales the position offset output [S5].
*   **Elastic Ratio ($e$):** Controls the sparsity of Gaussians in FlexGS [S3].
*   **Number of Views ($N$):** Input images per scene [S5].
*   **Number of Nearest Views ($K$):** Used for retrieving 2D context [S5].

### Edge Cases and Pitfalls
*   **Ghosting Artifacts:** Pixel-aligned methods generate redundant primitives in overlapping regions [S5]. Solved by global volume prediction and filtering [S5].
*   **Depth Noise:** Monocular depth predictions contain noise and floaters [S5]. Solved by uniform and statistical filtering [S5].
*   **Excessive Scale:** Large Gaussian scales consume excessive GPU memory [S2]. Solved by inverted Softplus activation on scale output [S2].
*   **Recursive Convergence:** The offset update in EVolSplat is recursive; inference requires fixed iterations (e.g., 2) to converge [S5].

def evolsplat_predict_geometry(input_images, depth_estimator, sparse_3d_cnn, d_pos, d_opa, d_cov, voxel_size):
    """
    Predicts Gaussian geometry using global volume-based approach (EVolSplat).
    """
    # 1. Depth Estimation
    depth_maps = [depth_estimator(img) for img in input_images]
    
    # 2. Point Cloud Construction (Simplified unprojection)
    # Assume K_n, T_n are known/calibrated
    point_cloud = []
    for img, depth, K, T in zip(input_images, depth_maps, K_list, T_list):
        points = unproject_rgb_depth(img, depth, K, T)
        point_cloud.extend(points)
    
    # 3. Filtering
    point_cloud = uniform_filter(point_cloud)
    point_cloud = statistical_filter(point_cloud)
    
    # 4. Feature Volume Extraction
    feature_volume = sparse_3d_cnn(point_cloud)
    
    # 5. Initialization
    gaussians = []
    for p in point_cloud:
        gaussians.append({
            'mu_init': p,
            'mu_prev': p, # For iterative update
            'delta_mu_prev': 0.0
        })
        
    # 6. Geometry Prediction (Iterative for training, fixed steps for inference)
    is_inference = True # Set to False for training
    
    for g in gaussians:
        mu_query = g['mu_init'] + g['delta_mu_prev']
        
        # Query feature volume
        f = trilinear_interpolate(feature_volume, mu_query)
        
        # Predict Opacity and Covariance
        alpha = d_opa(f)
        sigma = d_cov(f)
        
        # Predict Position Offset
        delta_mu = tanh(d_pos(f)) * voxel_size
        
        # Update Position
        mu = g['mu_init'] + delta_mu
        
        if is_inference:
            # Inference: Run recursion twice to converge
            # (Simplified: assume delta_mu_prev is updated internally or looped)
            pass 
        else:
            # Training: Track previous delta for next iteration
            g['delta_mu_prev'] = delta_mu
            
        g['alpha'] = alpha
        g['sigma'] = sigma
        g['mu'] = mu
        
    return gaussians

def grm_sequential_decode(tri_plane_features):
    """
    Predicts Gaussian attributes using sequential decoders (GRM).
    """
    # Decoder 1: Color
    color = decoder_color(tri_plane_features)
    
    # Decoder 2: Opacity (Input: Color + Tri-Plane)
    opacity = decoder_opacity(color, tri_plane_features)
    
    # Decoder 3: Rotation (Input: Opacity + Tri-Plane)
    rotation = decoder_rotation(opacity, tri_plane_features)
    
    # Decoder 4: Scale (Input: Rotation + Tri-Plane)
    # Use inverted Softplus to prevent large scales
    scale_raw = decoder_scale(rotation, tri_plane_features)
    scale = inverted_softplus(scale_raw)
    
    # Decoder 5: Position Offset (Input: Scale + Tri-Plane)
    position_offset = decoder_position(scale, tri_plane_features)
    
    return {
        'color': color,
        'opacity': opacity,
        'rotation': rotation,
        'scale': scale,
        'position_offset': position_offset
    }

def flexgs_transform_gaussians(gaussians, spatial_ratio_field, elastic_ratio):
    """
    Transforms selected Gaussians to patch missing areas (FlexGS).
    """
    transformed_gaussians = []
    
    # Select top Gaussians based on elastic ratio
    selected_indices = select_top_gaussians(gaussians, elastic_ratio)
    
    for i, g in enumerate(gaussians):
        if i in selected_indices:
            # Query spatial-ratio feature
            f = query_spatial_ratio_field(spatial_ratio_field, g['position'], elastic_ratio)
            
            # Predict displacements
            delta_pos = mlp_pos(f)
            delta_scale = mlp_scale(f)
            delta_rot = mlp_rot(f)
            
            # Apply transformations
            new_pos = g['position'] + delta_pos
            new_scale = g['scale'] + delta_scale
            new_rot = g['rotation'] + delta_rot
            
            transformed_gaussians.append({
                'position': new_pos,
                'scale': new_scale,
                'rotation': new_rot,
                'opacity': g['opacity'],
                'color': g['color']
            })
        else:
            transformed_gaussians.append(g)
            
    return transformed_gaussians

### BrightDreamer
Predicts the deviation of a set of fixed anchor points to determine the centers of Gaussians [S1].

### Defocus Blur Modeling
Models optical defocus by adjusting the scale $s$ of 3D Gaussians based on their distance from the camera's focal plane [S6]. Larger $s$ models out-of-focus points, smaller $s$ models in-focus points [S6].

## Operating characteristics
*   **Time Complexity:** Feed-forward methods (e.g., EVolSplat, GRM) are significantly faster than iterative optimization, enabling real-time rendering [S5].
*   **Memory Complexity:** Global volume methods require storing a 3D feature volume, which can be large for urban scenes [S5]. Sequential decoders reduce memory by specializing decoders [S2].
*   **Performance:** EVolSplat achieves real-time rendering for urban scenes [S5]. GRM enables fast 3D-aware generation [S2].
*   **Strengths:** Real-time inference, generalizability across scenes, reduced ghosting artifacts compared to pixel-aligned methods [S5].
*   **Limitations:** Dependency on depth estimator quality [S5], potential loss of high-frequency details if primitives are downsampled [S5].

## Background
Originated from the need to accelerate 3D Gaussian Splatting reconstruction, which traditionally requires slow per-scene optimization [S5]. EVolSplat was introduced in 2025 for efficient urban view synthesis [S5]. GRM and sequential decoding approaches were developed for 3D-aware generative models [S2]. BrightDreamer predicts anchor deviations for 3D generation [S1].
