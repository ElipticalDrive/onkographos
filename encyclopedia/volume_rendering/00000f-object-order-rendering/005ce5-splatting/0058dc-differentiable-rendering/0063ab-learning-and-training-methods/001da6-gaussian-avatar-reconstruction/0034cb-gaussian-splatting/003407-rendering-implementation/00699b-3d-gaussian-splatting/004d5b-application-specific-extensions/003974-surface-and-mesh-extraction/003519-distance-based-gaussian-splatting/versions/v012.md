# Distance-based Gaussian Splatting

Also called: Mesh-based Gaussian Splatting, Tightly/Loosely-bound Gaussian Splatting

## Overview
Distance-based Gaussian Splatting is a method that integrates a pre-existing 3D mesh with 3D Gaussian Splatting (3DGS) primitives to improve rendering quality and geometric consistency in large-scale scenes. It solves the problem of redundant or distorted Gaussian splats in regions where the underlying mesh is inaccurate or overly dense by classifying splats as "tightly-bound" or "loosely-bound" based on their distance to the mesh surface. Unlike standard 3DGS which treats all primitives equally, this method masks occluded splats, prunes those hidden behind the mesh, and aligns tightly-bound splats to the mesh geometry, thereby reducing memory usage and preventing artifacts from mesh reconstruction errors [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A trained 3D Gaussian splatting model $\mathcal{G} = \{G_i\}_{i=1}^M$ (where each $G_i$ has center $p_i$, covariance $\Sigma_i$, opacity $o_i$, and color $c_i$); a 3D mesh $M$ composed of triangles $f_j$; a set of training camera viewpoints $P_k$; and a distance threshold $d_{th}$.
*   **Outputs:** An optimized set of Gaussian splats $\mathcal{G}'$ and rendered images that respect the mesh geometry.

**Data Structures**
The method relies on the standard 3DGS data structures [S1]:
*   **3D Gaussian $G_i$:** Defined by center $p_i \in \mathbb{R}^3$, 3D covariance $\Sigma_i \in \mathbb{R}^{3\times3}$, opacity $o_i \in [0,1]$, and view-dependent color $c_i$ (represented by spherical harmonics).
*   **Covariance Parameterization:** $\Sigma_i = R_i S_i S_i^T R_i^T$, where $S_i \in \mathbb{R}^3$ is a scaling vector and $R_i \in \mathbb{R}^{3\times3}$ is a rotation matrix encoded by a quaternion $q \in \mathbb{R}^4$ [S1].
*   **Mesh $M$:** A set of triangles $f_j$ with associated surface normals and centers $m_j$.

**Numbered Steps**

1.  **Initialization:** Initialize a 3D Gaussian splat at the center $m_j$ of each triangle $f_j$ of the input mesh $M$ [S1].
2.  **Depth Rendering and Occlusion Masking:** For each training viewpoint $P_k$, render a depth map $D_k$ using the current Gaussian splats. To ensure the mesh surface is treated as opaque, add a small offset $\epsilon = 0.01$ to the rendered depth $D_k$ [S1]. Use this depth map to mask out Gaussian splats that are occluded by the mesh surface. Splats with a depth greater than the mesh depth at their projected pixel location are considered occluded and excluded from rendering [S1].
3.  **Visibility Assessment and Pruning:** Assess the visibility of all Gaussian splats across all training views. Identify splats that are located behind the mesh surface and are never observed by any training view. Remove these redundant splats at specific training intervals (e.g., every 500 iterations) [S1].
4.  **Distance Calculation:** Calculate the Euclidean distance $d_i$ between the center $p_i$ of each Gaussian splat and the corresponding closest mesh face $f_j$ [S1].
5.  **Classification:** Classify each Gaussian splat $G_i$ based on the distance $d_i$ and a threshold $d_{th}$:
    *   **Tightly-bound splats ($G_{ti}$):** If $d_i < d_{th}$, the splat is tightly bound to the mesh.
    *   **Loosely-bound splats ($G_{li}$):** If $d_i > d_{th}$, the splat is loosely bound [S1].
    *   *Note:* The threshold $d_{th}$ is typically set to 0.01 [S1].
6.  **Alignment and Flattening:** For tightly-bound splats $G_{ti}$, flatten the splats and align them with the mesh surface. This involves constraining the covariance or orientation to match the local mesh geometry, ensuring the splat lies flat against the surface [S1].
7.  **Rendering:** Render the image using alpha blending. The 3D Gaussians are projected into camera space ($p_{ci} = R_{cw} p_i + t_{cw}$, $\Sigma_{ic} = R_{cw} \Sigma_i R_{cw}^T$) and then into ray space using the affine transformation $J_i \in \mathbb{R}^{2\times3}$ defined by $p_{ci}$:
    $$ \Sigma'_i = J_i \Sigma_{ic} J_i^T $$
    The 2D Gaussian value is:
    $$ g_i(x) = e^{-\frac{1}{2}(x-p'_i)^T {\Sigma'_i}^{-1}(x-p'_i)} $$
    The final color $c$ is computed as:
    $$ c = \sum_{i=1}^{n} c_i \alpha_i \prod_{j=1}^{i-1}(1-\alpha_j), \quad \alpha_i = o_i g_i(x) $$
    where $n$ is the number of splats contributing to the pixel, sorted by depth [S1].

**Pseudocode**

```python
def distance_based_gaussian_splatting(mesh M, gaussians G, viewpoints V, d_th=0.01, prune_interval=500):
    """
    Implements Distance-based Gaussian Splatting.
    
    Args:
        M: Mesh object with triangles f_j, centers m_j, and normals.
        G: List of Gaussian splats, each with center p_i, covariance Sigma_i, 
           opacity o_i, color c_i, and rotation R_i, scale S_i.
        V: List of viewpoints, each with camera matrix (R_cw, t_cw).
        d_th: Distance threshold for tight/loose binding.
        prune_interval: Number of iterations between pruning steps.
        
    Returns:
        Optimized list of Gaussian splats G'.
    """
    
    # Step 1: Initialization
    # Initialize a Gaussian splat at the center of each mesh triangle
    G = []
    for triangle in M.triangles:
        center = triangle.center
        # Initialize covariance based on triangle size or default 3DGS initialization
        Sigma = initialize_covariance(triangle)
        G.append(Gaussian(center=center, Sigma=Sigma, opacity=1.0, color=0.5))
        
    # Step 2-3: Training Loop with Occlusion Handling and Pruning
    for iteration in range(total_iterations):
        
        # Render depth maps for all viewpoints to determine occlusion
        occlusion_masks = {}
        for viewpoint in V:
            # Render depth map D_k from current Gaussians
            depth_map = render_depth(G, viewpoint)
            # Add offset to ensure mesh is treated as opaque
            depth_map += 0.01
            occlusion_masks[viewpoint.id] = depth_map
            
        # Mask out occluded splats for rendering
        for viewpoint in V:
            depth_map = occlusion_masks[viewpoint.id]
            for splat in G:
                # Project splat center to 2D pixel coordinates
                pixel_u, pixel_v = project_to_pixel(splat.center, viewpoint)
                # Check if splat is behind the mesh surface
                if is_behind_mesh(splat, depth_map, pixel_u, pixel_v):
                    splat.occluded = True
                else:
                    splat.occluded = False
                    
        # Step 3: Pruning redundant splats behind the mesh
        if iteration % prune_interval == 0:
            visible_splats = [s for s in G if not s.occluded]
            # Further check visibility across all views
            for splat in G:
                if splat.occluded:
                    # Check if splat is never visible in any view
                    if not is_ever_visible(splat, V, occlusion_masks):
                        G.remove(splat)
                        
        # Step 4-5: Distance Calculation and Classification
        for splat in G:
            # Find closest mesh face f_j
            closest_face, distance = find_closest_mesh_face(splat.center, M)
            splat.distance_to_mesh = distance
            
            if distance < d_th:
                splat.type = TIGHTLY_BOUND
            else:
                splat.type = LOOSELY_BOUND
                
        # Step 6: Alignment for Tightly-bound Splats
        for splat in G:
            if splat.type == TIGHTLY_BOUND:
                # Flatten and align splat with mesh surface normal
                closest_face, _ = find_closest_mesh_face(splat.center, M)
                align_splat_to_mesh(splat, closest_face.normal)
                
        # Step 7: Rendering and Loss Computation
        # Render images using alpha blending
        rendered_images = []
        for viewpoint in V:
            image = render_image(G, viewpoint)
            rendered_images.append(image)
            
        # Compute losses (L1, SSIM, Normal Consistency, etc.)
        # Note: Normal consistency loss is applied to tightly-bound splats
        loss = compute_losses(rendered_images, ground_truth_images, G)
        
        # Update Gaussians via gradient descent
        G = optimize_gaussians(G, loss)
        
    return G

def is_behind_mesh(splat, depth_map, u, v):
    """
    Checks if a splat is occluded by the mesh surface.
    Assumes the mesh depth is stored in depth_map.
    """
    # Get mesh depth at splat's projected pixel
    mesh_depth = depth_map[u, v]
    # Get splat depth in camera space
    splat_depth = project_depth(splat.center, splat.covariance)
    
    # If splat depth is greater than mesh depth, it is behind the mesh
    return splat_depth > mesh_depth

def align_splat_to_mesh(splat, normal):
    """
    Flattens the Gaussian splat and aligns its orientation with the mesh normal.
    """
    # Adjust rotation matrix R_i to align with normal
    # This typically involves setting the smallest scale axis to be along the normal
    # and flattening the splat in the tangent plane
    splat.R = align_rotation_to_normal(splat.R, normal)
    splat.S = flatten_scale(splat.S, normal)
```

**Parameters**
*   **Distance Threshold ($d_{th}$):** The threshold used to distinguish tightly-bound and loosely-bound splats. Typical value: 0.01 [S1].
*   **Pruning Interval:** The frequency at which redundant splats behind the mesh are removed. Typical value: every 500 iterations [S1].
*   **Depth Offset:** An offset added to the rendered depth to ensure the mesh is treated as opaque. Typical value: 0.01 [S1].
*   **Loss Weights:** $\lambda_{img} = 0.001$, $\lambda_{nc} = 0.1$, $\lambda_{min} = 0.1$, $\lambda_{max} = 10$, $\lambda_{proj} = 50$ [S1].

**Edge Cases and Pitfalls**
*   **Mesh Artifacts:** If the mesh has severe artifacts, tightly binding all splats can degrade rendering quality. The loosely-bound splats help recover these inaccuracies [S1].
*   **Redundant Splats:** Without pruning, initializing a splat per triangle can lead to a rapid increase in GPU memory usage, especially with high-resolution meshes (e.g., 44 million triangles) [S1].
*   **Occlusion Handling:** The method assumes the mesh surface is entirely opaque. If the mesh is not watertight or has holes, occlusion masking may fail [S1].

## Operating characteristics
*   **Time Complexity:** The method adds overhead to the standard 3DGS training loop due to distance calculations, occlusion masking, and pruning. The pruning step occurs every 500 iterations, reducing the number of splats over time [S1].
*   **Memory Complexity:** By pruning redundant splats behind the mesh and avoiding initialization in distorted regions, the method reduces GPU memory usage compared to initializing splats for every triangle in a high-resolution mesh [S1].
*   **Performance:** The method improves rendering quality in large-scale scenes by leveraging the geometric priors of the mesh. It is particularly effective when the mesh is lightweight (e.g., LTM) but may lack detailed geometry [S1].
*   **Strengths:** Reduces memory usage, improves geometric consistency, handles mesh artifacts via loosely-bound splats.
*   **Limitations:** Relies on the quality of the input mesh. If the mesh is poor, the tightly-bound splats may introduce artifacts. The method requires a pre-reconstructed mesh [S1].

## Background
Distance-based Gaussian Splatting was introduced in the paper "MeshGS: Adaptive Mesh-Aligned Gaussian Splatting for High-Quality Rendering" by Jaehoon et al. (2024) [S1]. The method builds upon the original 3D Gaussian Splatting framework [22] and integrates it with mesh-based representations like LTM (Lightweight Triangular Mesh) [7]. The goal is to combine the high-fidelity rendering of 3DGS with the geometric efficiency of meshes. The method addresses the issue of redundant splats in regions where the mesh is distorted or overly dense, which is common in large-scale scene reconstruction [S1].
