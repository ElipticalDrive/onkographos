# Curriculum Learning with Slice and Voxel Supervision

Also called: Slice and Voxel Supervision Curriculum

## Overview
This method addresses the instability and incomplete volumetric coverage inherent in optimizing 3D Gaussian representations for shear-warp rendering by enforcing a structured training schedule. It differs from sibling methods like [Hybrid Coarse-to-Fine Strategy](7173-hybrid-coarse-to-fine-strategy.md) by explicitly decoupling global spatial guidance (via sparse voxels) from local structural continuity (via slices), rather than relying on hierarchical scene decomposition. It outperforms [Training Objective and Densification](7448-training-objective-and-densification.md) in volumetric consistency by preventing the "unstable global approximation" caused by random voxel sampling alone [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $m$ initial 3D Gaussian kernels $\mathcal{G} = \{G_1, \dots, G_m\}$, where each $G_i$ is centered at a sampled voxel position with learnable mean $\mu_i$, covariance $\Sigma_i$, opacity $\alpha_i$, and spherical harmonic coefficients $\mathbf{c}_i$ [S1].
*   **Output:** Optimized Gaussian parameters $\mathcal{G}^*$ that minimize rendering loss against target volumetric data (e.g., MRI, Cryosection) [S1].

**Data Structures:**
*   **Gaussian Set:** Contiguous array of $m$ Gaussians. Each Gaussian stores $\mu \in \mathbb{R}^3$, $\Sigma \in \mathbb{R}^{3 \times 3}$ (or parameterized scale/rotation), $\alpha \in \mathbb{R}$, $\mathbf{c} \in \mathbb{R}^K$ [S1, Parent].
*   **Voxel Grid:** Sparse representation of the volume, mapping 3D coordinates to voxel indices [S1].

**Algorithm Steps:**
The training proceeds in two distinct phases to ensure stable convergence:

1.  **Phase 1: Slice Supervision (Local Structure)**
    *   Sample a plane with arbitrary orientation $\mathbf{n}$ and offset $d$.
    *   Select sparse pixels on this 2D plane.
    *   Map each selected pixel to a 3D voxel coordinate $v_{3D}$ using the shear-warp projection geometry.
    *   Compute the rendering loss $L_{slice}$ between the projected Gaussian slice and the target voxel values at $v_{3D}$.
    *   Update Gaussian parameters $\mathcal{G}$ using gradient descent on $L_{slice}$ [S1].
    *   *Rationale:* This aligns the representation with the shear-warp rendering process, capturing geometric structure and texture continuity [S1].

2.  **Phase 2: Voxel Supervision (Global Guidance)**
    *   After Phase 1 stabilizes local structures, introduce voxel supervision.
    *   Sample sparse voxels from the volume grid.
    *   Compute the rendering loss $L_{voxel}$ for these voxels.
    *   Update Gaussian parameters $\mathcal{G}$ using gradient descent on $L_{voxel}$ [S1].
    *   *Rationale:* Sparse voxels provide global coverage, correcting the lack of global spatial guidance present in slice-only training [S1].

**Pseudocode:**
```python
def train_gaussian_volume(G, target_volume, num_iterations):
    # Phase 1: Slice Supervision
    for iter in range(num_iterations // 2):
        # Sample arbitrary plane
        plane = sample_arbitrary_plane()
        # Select sparse pixels on the plane
        pixels = sample_sparse_pixels(plane)
        
        loss = 0
        for pixel in pixels:
            # Map 2D pixel to 3D voxel coordinate
            voxel_coord = map_pixel_to_voxel(pixel, plane)
            # Render Gaussian contribution at voxel_coord
            rendered_value = render_gaussian_slice(G, voxel_coord)
            # Compute loss against target
            target_value = target_volume[voxel_coord]
            loss += (rendered_value - target_value) ** 2
            
        # Update Gaussians
        gradients = compute_gradients(loss, G)
        G = update_parameters(G, gradients)

    # Phase 2: Voxel Supervision
    for iter in range(num_iterations // 2, num_iterations):
        # Sample sparse voxels
        voxels = sample_sparse_voxels(target_volume)
        
        loss = 0
        for voxel in voxels:
            # Render Gaussian contribution at voxel
            rendered_value = render_gaussian_voxel(G, voxel)
            # Compute loss against target
            target_value = target_volume[voxel]
            loss += (rendered_value - target_value) ** 2
            
        # Update Gaussians
        gradients = compute_gradients(loss, G)
        G = update_parameters(G, gradients)
        
    return G
```

**Parameters:**
*   **Sampling Density:** Sparse sampling is used for both slices and voxels to ensure efficiency [S1]. Exact sparsity ratios are not given in the sources.
*   **Phase Split:** The sources imply a sequential curriculum (Slice then Voxel) but do not specify the exact iteration count split. [G] A 50/50 split is assumed for pseudocode completeness.

**Edge Cases and Pitfalls:**
*   **Random Voxel Sampling:** Using random voxel sampling *before* or *alongside* slice supervision leads to unstable global approximation and destabilizes learning [S1].
*   **Slice-Only Training:** Using only slice supervision limits accurate reconstruction of the full volumetric structure due to lack of global spatial guidance [S1].
*   **Voxel-Only Training:** Using only voxel supervision (even with MCE importance weighting) lacks structured planar constraints, resulting in lower performance in rendered views [S1].

## Subtopics

### Curriculum Learning with Sparse Voxel and Slice Sampling
This variant explicitly combines sparse voxel sampling (for global coverage) with slice-based sampling (for spatially correlated regions encoding geometric structure and texture continuity) [S1]. It aligns with shear-warp volume rendering, which generates images from stacks of 2D slices extracted from a 3D volume [S1]. In each iteration, a plane with arbitrary orientation is sampled, sparse pixels are selected, and each pixel is mapped to a 3D voxel coordinate [S1]. This strategy ensures the Gaussian representation learns spatial continuity across neighboring regions while maintaining global consistency [S1].

## Operating characteristics
*   **Time Complexity:** Linear in the number of sampled pixels/voxels per iteration. The two-phase approach may double the training time compared to single-supervision methods, but convergence is more stable [S1].
*   **Memory Complexity:** Proportional to the number of Gaussians $m$ and the target volume size for sparse sampling [S1].
*   **Strengths:** Efficient reconstruction of multimodal volumetric data (MRI, Cryosection); real-time selective visualization support; higher PSNR/SSIM than slice-only or random voxel-only methods [S1].
*   **Limitations:** Requires careful sequencing of supervision phases; random voxel sampling destabilizes learning if not properly scheduled [S1].
*   **When to Use:** When reconstructing volumetric medical or scientific data where both global structure and local texture continuity are critical [S1].
*   **When Not to Use:** When real-time performance is constrained and global volumetric consistency is less important than local surface detail [S1].

## Background
Originated in the context of Gaussian Volumetric Representation for Efficient Shear-Warp Visualization [S1]. The method leverages the alignment between shear-warp rendering (which operates on 2D slice stacks) and slice-based supervision to improve learning efficiency [S1]. It was developed to address the limitations of random sampling in Gaussian optimization for volumetric data [S1].
