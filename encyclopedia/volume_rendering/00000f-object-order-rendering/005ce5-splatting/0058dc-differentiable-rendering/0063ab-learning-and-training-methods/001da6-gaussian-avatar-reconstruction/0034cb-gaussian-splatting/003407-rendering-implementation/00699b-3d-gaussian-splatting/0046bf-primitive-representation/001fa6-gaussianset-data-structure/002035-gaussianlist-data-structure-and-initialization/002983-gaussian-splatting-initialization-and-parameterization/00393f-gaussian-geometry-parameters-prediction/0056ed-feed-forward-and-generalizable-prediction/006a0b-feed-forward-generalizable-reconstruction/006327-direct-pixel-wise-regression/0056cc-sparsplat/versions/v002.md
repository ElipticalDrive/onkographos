# SparSplat

Also called: Generalizable 2D Gaussian Splatting, SparSplat Model, SparSplat: Fast Multi-View Reconstruction with Generalizable 2D Gaussian Splatting

## Overview
SparSplat is a generalizable, feed-forward model that maps a set of sparse input images to planar surface elements (2D Gaussian Splatting parameters) in a single forward pass to perform 3D shape reconstruction and novel view synthesis [S1, unofficial]. It differs from its sibling [AnySplat Pipeline](12847-anysplat-pipeline.md) and [FineSplat](15257-finesplat.md) by explicitly optimizing for surface consistency via 2D primitives rather than 3D volume primitives, enabling coherent TSDF mesh extraction [S1, unofficial]. Unlike prior generalizable Gaussian methods [48] which are novel-view synthesis (NVS) purposed and fail to produce coherent surfaces upon TSDF fusion, SparSplat is fit for feed-forward surface reconstruction while maintaining superior NVS capabilities [S1, unofficial].

## How it works
**Inputs:** A set of $N$ color images $\{I_i\}_{i=1}^N$ where $I_i \in \mathbb{R}^{H \times W \times 3}$ and their corresponding camera poses $\{P_i\}_{i=1}^N$ (rotation and translation). A target view pose $P_t$ is specified for prediction.
**Outputs:** A pixel-aligned 2D Gaussian Splatting parameter map $O_t = \{s, q, p, \alpha, c\} \in \mathbb{R}^{H \times W \times (2+4+3+1+3)}$ for the target view, where $s$ is scale, $q$ is rotation quaternion, $p$ is centroid, $\alpha$ is opacity, and $c$ is color [S1, unofficial]. Optionally, an explicit 3D triangle mesh $S$ is extracted via TSDF fusion of splatted depths [S1, unofficial].

**Data Structures:**
The model $\Phi$ predicts the attribute map $O_t$. The layout of $O_t$ at each pixel $(u,v)$ is:
- $s \in \mathbb{R}^2$: 2D scale parameters.
- $q \in \mathbb{R}^4$: Rotation quaternion.
- $p \in \mathbb{R}^3$: 3D centroid position.
- $\alpha \in \mathbb{R}$: Opacity.
- $c \in \mathbb{R}^3$: Color (RGB).

**Algorithm:**
The prediction pipeline follows the architecture of [48] but utilizes 2DGS and foundation model features [S1, unofficial].

1.  **Feature Encoding:**
    - Encode each input image $I_i$ using a Feature Pyramid Network (FPN) to predict 2D feature maps $f_i$ [S1, unofficial].
    - Extract monocular 2D semantic features from DINOv2 for each $I_i$ [S1, unofficial].
    - Extract pairwise feature maps from MASt3R encoding dense pairwise correspondences between input images [S1, unofficial].
    - Concatenate these features to form the input representation for the fusion stage.

2.  **Multi-View Fusion (Homography Warping):**
    - For a target view $P_t$, compute relative poses $P_t / P_i$ for each source view $i$ [S1, unofficial].
    - Warp the feature maps $f_i$ from source views to the target view coordinate system using homography-based warping, resulting in warped features $f_{t,i}$ [S1, unofficial].

3.  **Parallel Branches:**
    - **DeepMVS Branch (Geometry):**
        - Merge warped features $f_{t,i}$ into a cost volume [S1, unofficial].
        - Sample depth planes: 64 planes for the coarse stage and 8 planes for the fine stage [S1, unofficial].
        - Process the cost volume into a probability volume using a 3D convolutional network [S1, unofficial].
        - Predict a depth map $D_t$ [S1, unofficial].
    - **Pixel-Aligned Prediction Branch (Attributes):**
        - Pool the warped features $f_{t,i}$ into a target feature map $f_t$ [S1, unofficial].
        - Pass $f_t$ through a 2D convolutional network and an MLP to predict Gaussian primitive attributes $\{s, q, \alpha, c\}$ [S1, unofficial].

4.  **Parameter Assembly:**
    - Unproject the predicted depth $D_t$ using the camera intrinsics $K$ of the target view to obtain the 3D position attribute $p$ [S1, unofficial].
    - Combine $\{s, q, p, \alpha, c\}$ to form the final attribute map $O_t$ [S1, unofficial].

5.  **Rendering and Mesh Extraction (Inference):**
    - Render the scene using perspective-accurate 2D Gaussian Splatting to produce novel views [S1, unofficial].
    - To extract a mesh $S$:
        - For each training view $P_i$, infer the splat map $O_i = \Phi(P_i | I_1, \dots, I_N)$ [S1, unofficial].
        - Render mean depth maps $D_i$ for each view $P_i$ using the splatted Gaussians [S1, unofficial].
        - Perform TSDF fusion on the set of depth maps $\{D_i\}$ with a voxel size of 1.5 to generate the 3D triangle mesh $S$ [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn

def sparsplat_forward(images, poses, target_pose, intrinsics):
    """
    images: List of N tensors, shape (H, W, 3)
    poses: List of N SE3 matrices (4x4)
    target_pose: SE3 matrix (4x4) for the target view
    intrinsics: Camera intrinsic matrix K (3x3)
    Returns:
        O_t: Tensor of shape (H, W, 13) containing [s(2), q(4), p(3), alpha(1), c(3)]
        mesh: Optional 3D mesh object from TSDF fusion
    """
    N = len(images)
    
    # 1. Feature Encoding
    # FPN features
    f_list = [fpn_encoder(img) for img in images]
    
    # Foundation model features
    dino_feats = [dinov2_encoder(img) for img in images]
    mast3r_feats = mast3r_encoder(images) # Pairwise features
    
    # Concatenate features for each view
    # Note: Exact concatenation order depends on implementation, 
    # assuming concatenation along channel dim
    fused_f_list = []
    for i in range(N):
        combined = torch.cat([f_list[i], dino_feats[i], mast3r_feats[i]], dim=-1)
        fused_f_list.append(combined)
        
    # 2. Homography Warping
    warped_features = []
    for i in range(N):
        # Compute homography from source pose i to target pose
        H = compute_homography(poses[i], target_pose, intrinsics)
        # Warp features using H
        f_t_i = warp_homography(fused_f_list[i], H)
        warped_features.append(f_t_i)
        
    # 3. Parallel Branches
    # DeepMVS Branch
    cost_volume = build_cost_volume(warped_features)
    # Coarse stage: 64 depth planes
    prob_vol_coarse = conv3d_net(cost_volume, num_planes=64)
    depth_coarse = argmax(prob_vol_coarse)
    
    # Fine stage: 8 depth planes around coarse depth
    depth_fine = refine_depth(prob_vol_coarse, num_planes=8)
    
    # Pixel-Aligned Branch
    # Pool warped features into target feature map
    f_t = pool_features(warped_features)
    
    # Predict attributes excluding position
    # Output shape: (H, W, 2+4+1+3) = (H, W, 10)
    attr_pred = mlp_head(conv2d_net(f_t))
    
    # 4. Assemble Parameters
    # Unproject depth to get 3D position p
    # p = K^-1 * [x, y, 1]^T * depth
    p = unproject_depth(depth_fine, intrinsics)
    
    # Extract s, q, alpha, c from attr_pred
    s = attr_pred[..., 0:2]
    q = attr_pred[..., 2:6]
    alpha = attr_pred[..., 6:7]
    c = attr_pred[..., 7:10]
    
    # Concatenate to form O_t: (H, W, 13)
    O_t = torch.cat([s, q, p, alpha, c], dim=-1)
    
    # 5. Mesh Extraction (Optional, for reconstruction)
    # Infer splat maps for all training views
    splat_maps = [sparsplat_forward(images, poses, poses[i], intrinsics) for i in range(N)]
    
    # Render depth maps for each training view
    depth_maps = [render_depth(splat_map) for splat_map in splat_maps]
    
    # TSDF Fusion
    mesh = tsdf_fusion(depth_maps, voxel_size=1.5)
    
    return O_t, mesh
```

**Parameters:**
- Training resolution: $640 \times 512$ [S1, unofficial].
- Number of source images $N$: 3 [S1, unofficial].
- Optimizer: Adam, initial learning rate $5 \times 10^{-4}$ [S1, unofficial].
- Training steps: 300k [S1, unofficial].
- Hardware: Single RTX A6000 GPU [S1, unofficial].
- TSDF voxel size: 1.5 [S1, unofficial].
- Loss weights: $\lambda_s = 0.1, \lambda_p = 0.05, \lambda_\alpha = 0.05, \lambda_\beta = 0.05, \lambda_\gamma = 0.05, \lambda_1 = 0.5, \lambda_2 = 1$ [S1, unofficial].
- Depth planes: 64 (coarse), 8 (fine) [S1, unofficial].

**Edge Cases and Pitfalls:**
- Using 3DGS instead of 2DGS causes depth inconsistencies across views, leading to TSDF producing incorrect fusions with warped/disconnected surfaces [S1, unofficial].
- Prior SOTA generalizable GS methods fail to give coherent reconstructions on TSDF fusion of rendered depth maps [S1, unofficial].
- Precision in homography warping is critical for feature alignment; misalignment leads to poor depth and attribute prediction [G].

## Operating characteristics
- **Time Complexity:** Inference is nearly 2 orders of magnitude faster than prior state-of-the-art feed-forward sparse view reconstruction based on volume rendering of implicit representations [S1, unofficial].
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:**
    - Inference time: 0.8s (reproduced 0.88s) on RTX A6000 [S1, unofficial].
    - Comparison: 66s for UfoRecon, 32s for GeoTransfer [S1, unofficial].
    - DTU Test Set (NVS): PSNR 28.33, SSIM 0.938, LPIPS 0.073 [S1, unofficial].
    - DTU Test Set (Reconstruction): Mean Chamfer Distance 1.04 (with MASt3R features and depth loss) [S1, unofficial].
- **Scaling:** Performance benefits from adding depth loss $L_{depth}$, improving mean Chamfer distance by 71.8% (from 4.37 to 1.04) [S1, unofficial]. Using MASt3R features provides an 11.11% boost over image-only features, compared to 0.85% from DINOv2 [S1, unofficial].
- **Strengths:** Fast multi-view reconstruction, coherent surface extraction via TSDF, superior NVS in low-overlap regions compared to MVSGaussian [S1, unofficial].
- **Limitations:** Relies on foundation models (DINOv2, MASt3R) which may introduce biases or fail on out-of-distribution textures; requires calibrated camera poses [S1, unofficial].

## Background
SparSplat was proposed by Shubhendu Jena et al. in 2025 [S1, unofficial]. It builds on the MVSGaussian framework [48] but replaces 3D Gaussians with 2D Gaussians to improve geometric consistency for surface reconstruction. It integrates features from DINOv2 [59] and MASt3R [41] to enhance generalizability from sparse views. The method is evaluated on the DTU, BlendedMVS, and Tanks and Temples datasets [S1, unofficial].
