# Surface-Constrained Gaussian Splatting

Also called: Surface-Anchor Gaussian Splatting

## Overview
Surface-Constrained Gaussian Splatting is a training optimization for 3D Gaussian Splatting that initializes splats on a mesh surface and applies geometric constraints to prevent floating artifacts and improve surface fidelity [S1, unofficial]. It differs from standard 3D Gaussian Splatting by enforcing planar alignment and surface proximity through specific loss functions and initialization strategies, distinguishing it from sibling methods like [DeSplat](12925-desplat.md) which focuses on differentiable splatting primitives, and [Scene Representation and Geometry Constraints](15421-scene-representation-and-geometry-constraints.md) which offers broader geometric regularization [S1, unofficial].

## How it works
**Inputs:** A triangular mesh (vertices and faces), camera poses, and input images.
**Outputs:** Optimized 3D Gaussians (means, covariances via quaternions/scales, opacities, spherical harmonic coefficients).

**Data Structures:**
*   **Gaussian:**
    *   `mean`: `vec3` (3D position)
    *   `scale`: `vec3` (log-space scales for x, y, z axes)
    *   `opacity`: `float` (initially 0.5)
    *   `sh0`: `vec3` (zeroth-order spherical harmonic coefficients, derived from RGB)
    *   `shN`: `vec3` (higher-order SH coefficients, initialized to 0)
    *   `quaternion`: `vec4` (normalized, representing rotation)

**Initialization Steps:**
1.  **Point Sampling:** Sample points uniformly on the mesh triangles using area-weighted sampling. For each triangle, generate random barycentric coordinates $bary = [1 - \sqrt{r_1}, \sqrt{r_1}(1 - r_2), \sqrt{r_1}r_2]$ where $r_1, r_2 \sim U[0,1]$ [S1, unofficial].
2.  **Scale Initialization:** Compute the average distance to K-nearest neighbors (KNN) in the sampled point cloud. Set initial log-scales:
    *   $scales_{xy} = \log(\text{avg\_dist} \times 1.0)$
    *   $scales_z = \log(\text{avg\_dist} \times 0.2)$
    This creates flat discs that overlap with neighbors [S1, unofficial].
3.  **Rotation Initialization:** Align the splat's Z-axis to the surface normal. Compute the rotation quaternion using the half-angle Rodrigues formula:
    *   $\cos\theta = \text{dot}(\text{initial\_z}, \text{normal})$
    *   If $\cos\theta < -0.999$ (anti-aligned), set quaternion to $[0, 1, 0, 0]$ (180-degree rotation around X-axis) [S1, unofficial].
    *   Otherwise, $q_w = \sqrt{(1+\cos\theta)/2}$ and $q_{xyz} = \sqrt{(1-\cos\theta)/2} \cdot \text{axis}$, where axis is the cross product of initial Z and normal [S1, unofficial].
4.  **Color and Opacity:** Set initial opacity to 0.5 to prevent premature pruning. Compute $SH_0$ from the RGB color of the sampled point; initialize higher-order SH coefficients to zero [S1, unofficial].

**Training Losses:**
1.  **Flatness Loss:** Penalizes the ratio of the thinnest axis scale to the middle axis scale to enforce disc-like shapes [S1, unofficial].
2.  **Normal Alignment Loss:** Penalizes deviation of the thin axis (Z-axis) from the surface normal: $L_{normal} = 1 - |\text{dot}(\text{thin\_axis}, \text{normal})|$ [S1, unofficial].
3.  **Surface Anchor Loss:** Computes the L2 distance from each splat's mean to the nearest point on the mesh. This cache is updated every 50 training steps [S1, unofficial].
4.  **Laplacian Smoothing:** Applies smoothing to scales, quaternions, and $SH_0$ using KNN neighbors with a specified strength parameter to reduce noise [S1, unofficial].

**Spawn Strategy:**
New splats are spawned at pixels with high frequency gaps or low alpha values using weighted multinomial sampling [S1, unofficial].

```python
def initialize_gaussians_from_mesh(mesh, num_points):
    """
    Initialize 3D Gaussians on a mesh surface.
    mesh: Object with vertices, faces, and face_normals methods.
    num_points: Number of splats to initialize.
    Returns: List of Gaussian objects.
    """
    gaussians = []
    # 1. Sample points on mesh
    points, normals = sample_mesh_points(mesh, num_points)
    
    # 2. Compute KNN distances for scale initialization
    # [G] Assuming a KDTree or similar structure for efficient KNN lookup
    knn_distances = compute_knn_distances(points, k=5)
    avg_dist = np.mean(knn_distances, axis=1)
    
    for i in range(num_points):
        p = points[i]
        n = normals[i]
        
        # 3. Initialize Scales (log-space)
        # xy scales are larger, z scale is smaller (flat disc)
        scale_xy = np.log(avg_dist[i] * 1.0)
        scale_z = np.log(avg_dist[i] * 0.2)
        scale = np.array([scale_xy, scale_xy, scale_z])
        
        # 4. Initialize Rotation (Quaternion)
        # Align Z-axis (0,0,1) to normal n
        initial_z = np.array([0.0, 0.0, 1.0])
        cos_theta = np.dot(initial_z, n)
        
        if cos_theta < -0.999:
            # Anti-aligned: 180 deg rotation around X
            q = np.array([0.0, 1.0, 0.0, 0.0]) # w, x, y, z
        else:
            # Half-angle Rodrigues
            axis = np.cross(initial_z, n)
            norm_axis = np.linalg.norm(axis)
            if norm_axis < 1e-8:
                q = np.array([1.0, 0.0, 0.0, 0.0]) # No rotation needed
            else:
                axis = axis / norm_axis
                q_w = np.sqrt((1 + cos_theta) / 2)
                q_xyz = np.sqrt((1 - cos_theta) / 2) * axis
                q = np.concatenate([[q_w], q_xyz])
        
        # 5. Initialize Opacity and Color
        opacity = 0.5
        # [G] rgb is assumed to be retrieved from the mesh vertex or interpolated color
        rgb = get_color_at_point(p, mesh) 
        sh0 = rgb_to_sh(rgb) # Standard SH conversion for 0th order
        shN = np.zeros(3 * (N_SH_BANDS - 1)) # Higher order zeros
        
        gaussians.append({
            'mean': p,
            'scale': scale,
            'quaternion': q,
            'opacity': opacity,
            'sh0': sh0,
            'shN': shN
        })
        
    return gaussians

def compute_surface_anchor_loss(gaussians, mesh, cache_step, current_step):
    """
    Compute L2 distance from splat means to nearest mesh points.
    Cache is updated every 50 steps.
    """
    if current_step % 50 == 0:
        # Update nearest point cache
        # [G] Implementation depends on spatial data structure (e.g., KDTree on mesh vertices/points)
        nearest_mesh_points = find_nearest_mesh_points([g['mean'] for g in gaussians], mesh)
        cache_step['nearest_points'] = nearest_mesh_points
        
    nearest_points = cache_step['nearest_points']
    loss = 0.0
    for i, g in enumerate(gaussians):
        dist = np.linalg.norm(g['mean'] - nearest_points[i])
        loss += dist * dist
    return loss
```

## Operating characteristics
*   **Time Complexity:** Initialization is $O(N \log N)$ due to KNN and mesh sampling. Training adds overhead for surface anchor loss computation (cached every 50 steps) and Laplacian smoothing, increasing per-step cost compared to standard 3DGS.
*   **Memory Complexity:** Requires storing the mesh geometry and nearest-point cache. Slightly higher memory usage than standard 3DGS due to additional loss computations.
*   **Strengths:** Significantly reduces floating artifacts and improves surface reconstruction quality for scenes with well-defined geometry.
*   **Limitations:** Requires a high-quality input mesh. Performance degrades if the mesh is noisy or incomplete. Not suitable for scenes without clear surface geometry (e.g., dense foliage, smoke).
*   **When to use:** When surface fidelity is critical and a good mesh is available.
*   **When not to use:** For general-purpose 3DGS where mesh acquisition is difficult or the scene is non-rigid/complex without clear surfaces.

## Background
Surface-Constrained Gaussian Splatting was introduced as an unofficial extension to 3D Gaussian Splatting, integrating mesh-based initialization and geometric constraints. It is part of the `dust3r-3dgs` pipeline, which combines DUSt3R/MASt3R reconstruction with Gaussian Splatting training [S1, unofficial]. The method addresses the common issue of "floating" Gaussian artifacts that appear in standard 3DGS when training on sparse or noisy point clouds.
