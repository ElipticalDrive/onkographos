# Supplementing Points for Camera Motion Blur

Also called: Adding extra points, Point densification via extent-based calculation

## Overview
This method supplements an initial sparse point cloud with additional 3D Gaussian primitives to enable the representation of fine details and tiny objects that are otherwise lost due to sparsity, specifically to handle camera motion blur artifacts [S1]. It differs from standard initialization by dynamically calculating the number of required points based on the spatial extent of the existing cloud and ensuring these new points inherit color features from neighbors rather than random initialization, which is critical for high-fidelity deblurring [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An initial sparse point cloud consisting of $N$ 3D Gaussians with positions $\mu_i$.
*   **Output:** An augmented point cloud with $N + N_p$ Gaussians, where $N_p$ is the number of supplementing points.

**Data Structures:**
The method operates on the existing list of Gaussian parameters. For the new points, the covariance $\Sigma_i$, opacity $\alpha_i$, and rotation $R_i$ are typically initialized using standard sparse initialization principles (e.g., small scale, low opacity) as defined in the parent article [S1]. The key differentiator is the calculation of the count $N_p$ and the initialization of the color coefficients $C_i$.

**Parameters:**
*   $c$: A stability constant, set to $1.1$ [S1].
*   $N_{max}$: The maximum number of supplementing points allowed, set to $200,000$ [S1].

**Algorithm:**

1.  **Calculate Spatial Extent:**
    Determine the bounding box of the current point cloud along the x, y, and z axes.
    Let $Q_{max} \in \mathbb{R}^3$ be the vector of maximum position coordinates:
    $$ Q_{max} = [\max_i(\mu_{i,x}), \max_i(\mu_{i,y}), \max_i(\mu_{i,z})] $$
    Let $Q_{min} \in \mathbb{R}^3$ be the vector of minimum position coordinates:
    $$ Q_{min} = [\min_i(\mu_{i,x}), \min_i(\mu_{i,y}), \min_i(\mu_{i,z})] $$

2.  **Calculate Supplementing Point Count ($N_p$):**
    Compute the volume of the bounding box and divide by the cube of the stability constant $c$. Cap the result at $N_{max}$.
    $$ N_p = \min\left( \frac{\text{prod}(Q_{max} - Q_{min})}{c^3}, N_{max} \right) $$
    where $\text{prod}(\mathbf{v}) = v_x \cdot v_y \cdot v_z$ [S1].

3.  **Generate New Positions:**
    Distribute $N_p$ new Gaussian means uniformly within the bounding box defined by $Q_{min}$ and $Q_{max}$ [S1]. *Note: The source does not specify the exact sampling distribution (e.g., uniform vs. Poisson disk), but implies uniform distribution within the extent.*

4.  **Initialize Color Features:**
    For each new Gaussian $j$ (where $j > N$), initialize its color coefficients $C_j$ by interpolating from the nearest neighboring points in the existing cloud [S1].
    *   **Pitfall:** Randomly initializing color features for added points leads to inferior reconstruction quality [S1].

5.  **Initialize Other Attributes:**
    Initialize covariance $\Sigma_j$, opacity $\alpha_j$, and rotation $R_j$ for the new points. Standard practice suggests low initial opacity (e.g., $0.01$ to $0.1$) and small scales to allow optimization to refine them [S1].

**Pseudocode:**

```python
import numpy as np

def supplement_points_for_motion_blur(existing_gaussians, c=1.1, n_max=200000):
    """
    Supplements the existing point cloud with additional Gaussians to handle camera motion blur.
    
    Args:
        existing_gaussians: List or array of N Gaussians. 
                            Each Gaussian has a position attribute .mu (shape (3,)).
        c: Stability constant (default 1.1).
        n_max: Maximum number of points to add (default 200,000).
        
    Returns:
        augmented_gaussians: List of N + N_p Gaussians.
    """
    # 1. Calculate Spatial Extent
    positions = np.array([g.mu for g in existing_gaussians])
    
    if len(positions) == 0:
        return existing_gaussians

    q_max = np.max(positions, axis=0)
    q_min = np.min(positions, axis=0)
    
    # 2. Calculate Supplementing Point Count
    # prod(Q_max - Q_min) is the volume of the bounding box
    extent = q_max - q_min
    volume = np.prod(extent)
    
    n_p = int(volume / (c ** 3))
    n_p = min(n_p, n_max)
    
    if n_p == 0:
        return existing_gaussians

    # 3. Generate New Positions
    # Uniformly sample within the bounding box [G]
    new_positions = np.random.uniform(low=q_min, high=q_max, size=(n_p, 3))
    
    # 4. Initialize Color Features
    # Interpolate colors from nearest neighbors [S1]
    # [G] Implementation detail: Use k-NN (e.g., k=3) to find nearest existing points
    # and average their color coefficients.
    new_colors = interpolate_colors_from_neighbors(new_positions, existing_gaussians)
    
    # 5. Initialize Other Attributes
    # [G] Standard initialization: small scale, low opacity, identity rotation
    new_gaussians = []
    for i in range(n_p):
        new_g = Gaussian()
        new_g.mu = new_positions[i]
        new_g.color = new_colors[i]
        new_g.opacity = 0.01 # Low initial opacity [S1]
        new_g.scale = np.array([0.01, 0.01, 0.01]) # Small initial scale [S1]
        new_g.rotation = np.array([1, 0, 0, 0]) # Identity quaternion [S1]
        new_gaussians.append(new_g)
        
    # Combine and return
    augmented_gaussians = list(existing_gaussians) + new_gaussians
    return augmented_gaussians

def interpolate_colors_from_neighbors(new_positions, existing_gaussians):
    """
    Interpolates color features for new points based on nearest neighbors in the existing cloud.
    """
    existing_positions = np.array([g.mu for g in existing_gaussians])
    existing_colors = np.array([g.color for g in existing_gaussians])
    
    # [G] Using simple nearest neighbor for demonstration; in practice, 
    # inverse-distance weighting or k-NN averaging is preferred.
    # Here we assume a helper function exists to find nearest neighbor indices.
    # Since we cannot call external libraries, we implement a basic brute-force 
    # nearest neighbor search for completeness.
    
    n_new = new_positions.shape[0]
    n_existing = existing_positions.shape[0]
    
    # Calculate distances (Euclidean)
    # Shape: (n_new, n_existing)
    dists = np.sqrt(np.sum((new_positions[:, np.newaxis, :] - existing_positions[np.newaxis, :, :]) ** 2, axis=2))
    
    # Find index of nearest neighbor
    nearest_indices = np.argmin(dists, axis=1)
    
    # Retrieve colors of nearest neighbors
    interpolated_colors = existing_colors[nearest_indices]
    
    return interpolated_colors

class Gaussian:
    def __init__(self):
        self.mu = np.zeros(3)
        self.color = np.zeros(3) # Assuming SH degree 0 for simplicity
        self.opacity = 0.0
        self.scale = np.zeros(3)
        self.rotation = np.zeros(4)
```

**Edge Cases and Pitfalls:**
*   **Sparse Clouds:** Directly using a sparse point cloud without this densification results in objects being represented by a small number of points or failing to model tiny objects entirely [S1].
*   **Color Initialization:** Randomly initializing color features for added points yields inferior reconstruction quality (PSNR 23.46, SSIM 0.7411) compared to interpolating colors (PSNR 23.73, SSIM 0.7474) or adding no extra points (PSNR 23.34, SSIM 0.7374) [S1].
*   **Volume Calculation:** If the point cloud is degenerate (e.g., all points on a plane), the volume $\text{prod}(Q_{max} - Q_{min})$ may be zero or very small, resulting in $N_p=0$.

## Operating characteristics
*   **Time Complexity:** The calculation of $N_p$ is $O(N)$ to find min/max positions. Generating new points is $O(N_p)$. Interpolating colors is $O(N_p \cdot N)$ for brute-force nearest neighbor, or $O(N_p \log N)$ with spatial indexing [G].
*   **Memory Complexity:** Increases by $O(N_p)$ Gaussians.
*   **Performance:** This method improves PSNR and SSIM metrics for scenes with camera motion blur by ensuring dense coverage of the scene volume [S1].
*   **Strengths:** Prevents failure to model tiny objects; improves deblurring quality by providing valid initial color features.
*   **Limitations:** Adds computational overhead during initialization; requires careful tuning of $c$ and $N_{max}$ to avoid excessive point counts in large scenes.

## Background
This method was introduced in the context of "Deblurring 3D Gaussian Splatting" to address the limitations of standard 3D Gaussian Splatting when handling camera motion blur [S1]. Standard 3D-GS struggles to model camera motion blur, often resulting in fewer Gaussians and poorer reconstruction of dynamic or blurred details [S1]. The technique was proposed by B. Lee et al. in the paper "Deblurring 3D Gaussian Splatting" [S1].
