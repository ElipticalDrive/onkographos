# C3DGS
Also called: Compact 3D Gaussian Splatting
## Overview
C3DGS is a compression method for 3D Gaussian Splatting that reduces model size by applying residual vector quantization (R-VQ) to geometric attributes, specifically scaling and rotation [S1][S2, unofficial]. It distinguishes itself from siblings like Mini-Splatting by focusing on quantization of geometric parameters rather than pruning or sampling Gaussians [S1][S2, unofficial].
## How it works
### Inputs and outputs
- **Input**: Trained 3D Gaussian attributes (position, opacity, color, scaling, rotation) from a standard 3DGS pipeline.
- **Output**: Compressed representation using codebooks for geometric attributes, enabling reconstruction of the scene with reduced memory footprint.

### Data structures
- **Codebooks**: Finite sets of representative vectors for scaling and rotation attributes.
- **Indices**: Quantized indices mapping each Gaussian's geometric attributes to the nearest codeword in the respective codebook.
- **Residuals**: Small correction values stored to refine the quantized geometric attributes [S1][S2, unofficial].

### Steps
1. **Attribute Selection**: Identify geometric attributes for quantization: scaling and rotation. Position and opacity are typically excluded to avoid overlapping Gaussians and artifacts [S1][S2, unofficial].
2. **Residual Vector Quantization (R-VQ)**:
   - Apply R-VQ to scale and rotation vectors [S1][S2, unofficial].
   - R-VQ clusters multidimensional data into a finite set of representations, storing indices and residuals [S1][S2, unofficial].
3. **Storage**: Store codebooks and quantized indices/residuals instead of full-precision floating-point attributes [S1][S2, unofficial].

### Formulas
- R-VQ approximates a vector $\mathbf{v}$ as:
  $$ \mathbf{v} \approx \mathbf{c}_1 + \mathbf{c}_2 + \dots + \mathbf{c}_k + \mathbf{r} $$
  where $\mathbf{c}_i$ are codewords from hierarchical codebooks and $\mathbf{r}$ is the residual [S1][S2, unofficial].

### Parameters
- **Codebook size**: Not given in the sources.
- **Number of R-VQ stages**: Not given in the sources.

### Edge cases and pitfalls
- **Quantization of opacity/position**: Avoided because sharing these attributes leads to overlapping Gaussians and visual artifacts [S1][S2, unofficial].
- **Precision loss**: R-VQ may introduce minor quality degradation compared to full-precision storage, but balances size and quality effectively [S1][S2, unofficial].

### Pseudocode
```python
# Pseudocode for C3DGS compression
def compress_gaussians(gaussians, codebooks_scale, codebooks_rot):
    """
    Compress 3D Gaussian attributes using R-VQ for scaling and rotation.
    """
    compressed_data = {}
    
    # Exclude position and opacity from quantization
    compressed_data['position'] = gaussians['position']
    compressed_data['opacity'] = gaussians['opacity']
    compressed_data['color'] = gaussians['color']
    
    # Quantize scaling using R-VQ
    scale_indices, scale_residuals = residual_vector_quantize(
        gaussians['scaling'], codebooks_scale
    )
    compressed_data['scale_indices'] = scale_indices
    compressed_data['scale_residuals'] = scale_residuals
    
    # Quantize rotation using R-VQ
    rot_indices, rot_residuals = residual_vector_quantize(
        gaussians['rotation'], codebooks_rot
    )
    compressed_data['rot_indices'] = rot_indices
    compressed_data['rot_residuals'] = rot_residuals
    
    return compressed_data

def residual_vector_quantize(attributes, codebooks):
    """
    Perform R-VQ on attributes using hierarchical codebooks.
    """
    indices = []
    residuals = []
    for attr in attributes:
        # Find best codeword in first stage
        best_idx = find_nearest_codeword(attr, codebooks[0])
        residual = attr - codebooks[0][best_idx]
        
        # Find best codeword in subsequent stages
        for i in range(1, len(codebooks)):
            best_idx_stage = find_nearest_codeword(residual, codebooks[i])
            residual = residual - codebooks[i][best_idx_stage]
            indices.append(best_idx_stage)
        
        indices.append(best_idx)
        residuals.append(residual)
    
    return indices, residuals

def find_nearest_codeword(vector, codebook):
    """
    Find the index of the nearest codeword in the codebook.
    """
    min_dist = float('inf')
    best_idx = -1
    for idx, codeword in enumerate(codebook):
        dist = sum((vector - codeword) ** 2)
        if dist < min_dist:
            min_dist = dist
            best_idx = idx
    return best_idx
```

## Operating characteristics
- **Time complexity**: Not given in the sources.
- **Memory complexity**: Significantly reduced compared to full-precision 3DGS due to quantization [S1][S2, unofficial].
- **Measured performance**: On MipNeRF360, C3DGS achieves SSIM 0.798, PSNR 27.08, LPIPS 0.247, and a size of 48.8 MB [S1].
- **Scaling**: Effective for large scenes where storage is a bottleneck [S1][S2, unofficial].
- **Strengths**: Reduces model size while maintaining reasonable quality [S1][S2, unofficial].
- **Limitations**: May introduce minor quality degradation due to quantization [S1][S2, unofficial].
- **When to use**: When storage efficiency is prioritized over maximum quality [S1][S2, unofficial].
- **When not to use**: When maximum visual fidelity is required without compression artifacts [S1][S2, unofficial].

## Background
C3DGS was introduced as part of recent advances in 3D Gaussian Splatting compression techniques [S1][S2, unofficial]. It builds on traditional vector quantization methods adapted for 3D Gaussian attributes [S1][S2, unofficial].
