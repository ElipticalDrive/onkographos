# Normalized Depth Rendering

Also called: Depth Normalized by Opacity, Normalized Depth Map

## Overview
Normalized Depth Rendering computes a depth map by dividing the accumulated depth buffer by the accumulated opacity buffer to correct for transparency artifacts in Gaussian splatting renders [S1, unofficial].

## How it works
**Inputs:**
*   `render_depth`: Accumulated depth buffer from the rasterizer [S1, unofficial].
*   `render_acc`: Accumulated alpha/opacity buffer from the rasterizer [S1, unofficial].
*   `znear`: Near plane distance of the camera frustum [G].
*   `zfar`: Far plane distance of the camera frustum [G].

**Outputs:**
*   `rendered_depth_norm`: Normalized depth map [S1, unofficial].
*   `rendered_disp_norm`: Displayable disparity map [S1, unofficial].

**Data Structures:**
*   `render_depth`: 2D array of floats, shape $(H, W)$ [S1, unofficial].
*   `render_acc`: 2D array of floats, shape $(H, W)$ [S1, unofficial].

**Steps:**
1.  **Normalize Depth:** Divide the accumulated depth buffer by the accumulated opacity buffer at each pixel $(x, y)$ to produce the normalized depth map [S1, unofficial].
    $$ \text{rendered\_depth\_norm}_{x,y} = \frac{\text{render\_depth}_{x,y}}{\text{render\_acc}_{x,y}} $$
2.  **Convert to Disparity:** Map the normalized depth to a displayable disparity range using the camera frustum bounds [S1, unofficial].
    $$ \text{rendered\_disp\_norm}_{x,y} = 1 - \frac{\text{rendered\_depth\_norm}_{x,y} - z_{\text{near}}}{z_{\text{far}} - z_{\text{near}}} $$

**Parameters:**
*   `znear`, `zfar`: Camera frustum bounds [G]. Typical values depend on the scene scale and are not given in the sources.

**Edge Cases and Pitfalls:**
*   Division by zero occurs when `render_acc` is exactly $0$ (no Gaussians cover the pixel), yielding undefined results. Clamp the denominator to a small positive epsilon or mask these pixels to a default value like `zfar` or `NaN` [G].
*   Precision loss may occur in low-opacity regions where the denominator approaches the epsilon floor, amplifying noise [G].

**Pseudocode:**
```python
def normalized_depth_rendering(render_depth, render_acc, znear, zfar):
    epsilon = 1e-6
    H, W = len(render_depth), len(render_depth[0])
    
    # Step 1: Normalize depth, handling zero-opacity pixels
    safe_acc = [[max(render_acc[i][j], epsilon) for j in range(W)] for i in range(H)]
    normalized_depth = [[render_depth[i][j] / safe_acc[i][j] for j in range(W)] for i in range(H)]
    
    # Step 2: Convert to disparity
    disparity = [[1.0 - (normalized_depth[i][j] - znear) / (zfar - znear) for j in range(W)] for i in range(H)]
    
    return normalized_depth, disparity
```

## Subtopics

### Logistic Depth Normalization
A CUDA-based post-processing step that maps raw 3DGS depth outputs to the $[0, 1.0)$ range to ensure compatibility with underwater visualization pipelines [S2]. It applies a logistic transformation to all raw depth values during the rasterization pipeline [S2]. The normalized depth is computed as $z_{\text{norm}} = \frac{2}{1 + e^{-0.1 \cdot z_{\text{raw}}}} - 1$, where $z_{\text{raw}}$ is the initial depth output from 3DGS manipulation [S2].

## Operating characteristics
Time complexity is not given in the sources. Memory complexity is not given in the sources. Strengths: Produces geometrically accurate depth maps in transparent or semi-transparent regions where standard depth accumulation fails [S1, unofficial]. Limitations: Sensitive to noise in low-opacity regions due to division by small values; requires robust handling of zero-opacity pixels [G]. When to use: When accurate depth estimation is needed for scenes with varying opacity [G]. When not to use: When simple geometric depth is sufficient and opacity is uniform, or when performance constraints prohibit the extra division step [G].

## Background
Normalized Depth Rendering is a post-processing technique used in Gaussian Splatting pipelines to improve depth map quality [S1, unofficial]. It leverages the existing alpha compositing infrastructure of Gaussian Splatting to derive a transparency-corrected depth value [S1, unofficial].
