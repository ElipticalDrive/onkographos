# Base Splat Model Generation

Also called: Elliptical Splat Generation, PCA-based Splat Fitting

## Overview
Base Splat Model Generation replaces isolated 3D points with elliptical surface patches (splats) that approximate local surface geometry, solving the problem of representing continuous surfaces from sparse or noisy point clouds. It differs from its parent [3D Convex Splatting](8758-3d-convex-splatting.md) by using elliptical primitives derived from local PCA rather than smooth convex shapes, and from [Compositional Splatting Strategy](13273-compositional-splatting-strategy.md) by generating the initial primitive set via local neighborhood analysis rather than hierarchical composition.

## How it works
**Inputs:** A set of $M$ 3D points $P = \{p_i \in \mathbb{R}^3 \mid 0 \le i < M\}$, where each point $p_i$ has an associated camera position $c_i$ (indicating the viewpoint from which the point was observed).
**Outputs:** A set of splats, each defined by a center $s_i$, a normal vector $n_i$, and two orthogonal tangential vectors $u_i, v_i$ defining the elliptical axes.

**Data Structures:**
*   **Voxel Grid:** A 3D grid used to accelerate neighbor search. Points are mapped to voxels based on their coordinates.
*   **Neighbor List:** For each point $p_i$, a list of neighbors $N_r(p_i)$ within a fixed radius $r$.
*   **PCA Results:** For each point, the mean $\bar{p}_i$, eigenvalues $\lambda_1 \ge \lambda_2 \ge \lambda_3$, and eigenvectors $w_1, w_2, w_3$.

**Parameters:**
*   $r$: Fixed search radius for neighbors. [Not given in the sources.]
*   Flatness threshold: Empirical threshold to decide between using the original point or the PCA mean as the splat center. [Not given in the sources.]

**Steps:**

1.  **Voxelization and Neighbor Search:**
    Discretize the 3D space into voxels. For each point $p_i$, identify neighbors $N_r(p_i)$ by checking the voxel containing $p_i$ and its 26 adjacent voxels. Filter points to keep only those within distance $r$ of $p_i$. [S1]

2.  **Principal Component Analysis (PCA):**
    For each point $p_i$ and its neighbor set $N_r(p_i)$, compute the covariance matrix of the neighbor positions. Perform eigen-decomposition to obtain:
    *   The mean point $\bar{p}_i = \frac{1}{|N_r(p_i)|} \sum_{q \in N_r(p_i)} q$.
    *   Three eigenvalues $\lambda_1 \ge \lambda_2 \ge \lambda_3$.
    *   Three corresponding eigenvectors $w_1, w_2, w_3$, which represent the principal directions of the local point distribution. [S1]

3.  **Compute Flatness Coefficient:**
    Calculate the flatness coefficient $f_i$ to measure the planarity of the local region:
    $$ f_i = \frac{\sqrt{\lambda_1} + \sqrt{\lambda_2}}{\sqrt{\lambda_1} + \sqrt{\lambda_2} + \sqrt{\lambda_3}} $$
    *   $f_i = 1$ indicates a completely planar area ($\lambda_3 = 0$).
    *   $f_i = 2/3$ indicates a perfectly isotropic point set ($\lambda_1 = \lambda_2 = \lambda_3$). [S1]

4.  **Determine Splat Center ($s_i$):**
    *   If $f_i$ is high (above the empirical threshold), set $s_i = p_i$ (the original point). This preserves detail in non-planar or well-sampled regions.
    *   If $f_i$ is low (below the threshold), set $s_i = \bar{p}_i$ (the PCA mean). This reduces holes in flat, undersampled regions by moving the splat to the best-fit plane center. [S1]

5.  **Compute Splat Geometry (Axes and Normal):**
    *   **Normal Vector:** The normal $n_i$ is the eigenvector corresponding to the smallest eigenvalue:
        $$ n_i = w_3 $$
    *   **Tangential Vectors (Axes):** The major and minor axes of the elliptical splat are the eigenvectors corresponding to the largest eigenvalues, scaled by the square root of their respective eigenvalues:
        $$ u_i = \sqrt{\lambda_1} \cdot w_1 $$
        $$ v_i = \sqrt{\lambda_2} \cdot w_2 $$
    These vectors define the orientation and scale of the elliptical splat. [S1]

6.  **Orientation Correction:**
    Ensure the normal $n_i$ points outwards from the model interior. Using the camera position $c_i$ associated with point $p_i$:
    *   If $n_i \cdot (c_i - p_i) < 0$, the normal points towards the camera (inwards). Flip the orientation of $n_i$ ($n_i \leftarrow -n_i$).
    *   Adjust $u_i$ and $v_i$ to maintain the right-handed coordinate system such that $u_i \times v_i$ aligns with the new $n_i$. Specifically, if $n_i$ is flipped, one of the tangential vectors must also be flipped to preserve the cross-product relationship $u_i \times v_i = k \cdot n_i$ (where $k > 0$). [S1]

**Pseudocode:**

```python
import numpy as np

def base_splat_generation(points, camera_positions, radius, flatness_threshold):
    """
    Generate base splats from a point cloud using PCA.
    
    Args:
        points: Array of shape (M, 3) containing 3D points p_i.
        camera_positions: Array of shape (M, 3) containing camera positions c_i for each point.
        radius: Search radius r for neighbor identification.
        flatness_threshold: Empirical threshold for flatness coefficient f_i.
        
    Returns:
        splats: List of dictionaries, each containing 'center', 'normal', 'axis_u', 'axis_v'.
    """
    M = len(points)
    splats = []
    
    # Step 1: Voxelization and Neighbor Search
    # Note: Implementation of voxel grid is assumed to be handled by a helper 
    # or standard library, but the logic is:
    # For each point i, find neighbors j such that distance(p_i, p_j) <= radius.
    # Optimization: Check only points in the same voxel and 26 adjacent voxels.
    
    neighbors_list = get_neighbors_voxel_grid(points, radius)
    
    for i in range(M):
        p_i = points[i]
        c_i = camera_positions[i]
        neighbors = neighbors_list[i]
        
        if len(neighbors) == 0:
            # Edge case: No neighbors. Create a degenerate splat or skip.
            # [G] Default to identity orientation with zero scale if no neighbors found.
            splats.append({
                'center': p_i,
                'normal': np.array([0, 0, 1]),
                'axis_u': np.array([0, 0, 0]),
                'axis_v': np.array([0, 0, 0])
            })
            continue
            
        # Step 2: PCA on neighbors
        neighbor_points = points[neighbors]
        mean_p = np.mean(neighbor_points, axis=0)
        
        # Center the points for covariance calculation
        centered_points = neighbor_points - mean_p
        covariance_matrix = np.cov(centered_points, rowvar=False)
        
        # Eigen-decomposition
        eigenvalues, eigenvectors = np.linalg.eigh(covariance_matrix)
        
        # Sort eigenvalues and eigenvectors in descending order
        # eigh returns them in ascending order, so reverse
        idx = np.argsort(eigenvalues)[::-1]
        eigenvalues = eigenvalues[idx]
        eigenvectors = eigenvectors[:, idx]
        
        lambda_1, lambda_2, lambda_3 = eigenvalues[0], eigenvalues[1], eigenvalues[2]
        w_1, w_2, w_3 = eigenvectors[:, 0], eigenvectors[:, 1], eigenvectors[:, 2]
        
        # Step 3: Flatness Coefficient
        sqrt_l1 = np.sqrt(lambda_1)
        sqrt_l2 = np.sqrt(lambda_2)
        sqrt_l3 = np.sqrt(lambda_3)
        
        denominator = sqrt_l1 + sqrt_l2 + sqrt_l3
        if denominator == 0:
            f_i = 0.0 # Avoid division by zero
        else:
            f_i = (sqrt_l1 + sqrt_l2) / denominator
            
        # Step 4: Determine Splat Center
        if f_i > flatness_threshold:
            s_i = p_i
        else:
            s_i = mean_p
            
        # Step 5: Compute Geometry
        # Normal is the eigenvector of the smallest eigenvalue
        n_i = w_3
        
        # Tangential vectors scaled by sqrt of eigenvalues
        u_i = sqrt_l1 * w_1
        v_i = sqrt_l2 * w_2
        
        # Step 6: Orientation Correction
        # Check if normal points towards the camera
        # Vector from point to camera
        p_to_c = c_i - p_i
        
        if np.dot(n_i, p_to_c) < 0:
            # Flip normal
            n_i = -n_i
            # Flip one tangential vector to maintain right-handed system
            # u x v should be parallel to n. If n flips, u or v must flip.
            # We flip u.
            u_i = -u_i
            
        splats.append({
            'center': s_i,
            'normal': n_i,
            'axis_u': u_i,
            'axis_v': v_i
        })
        
    return splats
```

## Operating characteristics
*   **Time Complexity:** $O(M \cdot K)$, where $M$ is the number of points and $K$ is the average number of neighbors found within radius $r$. Voxelization reduces the search space from $O(M^2)$ to $O(M)$ on average, assuming uniform distribution. PCA is $O(K)$ per point.
*   **Memory Complexity:** $O(M)$ to store the splat parameters (center, normal, two axes) for each point. The voxel grid adds overhead proportional to the volume of the scene.
*   **Strengths:** Adapts splat shape to local surface geometry, reducing holes in flat regions and improving compactness. Filters out noisy samples that lack sufficient neighbors.
*   **Limitations:** Requires a dense enough point cloud for PCA to be meaningful. Performance depends heavily on the choice of radius $r$ and the flatness threshold. [S1]
*   **When to use:** When starting with a sparse or noisy point cloud and needing a robust initial approximation of surface geometry for textured splat rendering. [S1]
*   **When not to use:** For very sparse data where neighbor counts are too low for reliable PCA, or when real-time performance is critical and voxelization overhead is prohibitive.

## Background
The method was introduced in the context of textured splat-based point clouds for rendering on handheld devices. It builds upon earlier work by Pauly et al. [2002] on hierarchical clustering and Wu and Kobbelt [2004; 2005] on point cloud subsampling. The specific technique of using PCA to fit elliptical splats and the flatness coefficient for merging/centering decisions is detailed in [S1].
