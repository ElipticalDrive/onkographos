# GaussianDiffusion


## Overview
GaussianDiffusion is a method that trains a 3D diffusion model based on a GaussianCube representation to generate 3D Gaussian primitives directly from conditioning signals [S1]. It solves the problem of multi-view inconsistency (the "Janus problem") and spurious geometry ("floaters") common in single-view or text-to-3D generation by incorporating structured noise from multiple viewpoints and using variational 3DGS [S1][S2, unofficial]. Unlike iterative optimization methods, it amortizes generation cost over a trained network, enabling near-real-time sampling [S1].

## How it works
**Inputs and Outputs:**
- Input: Conditioning signal (e.g., text, single image).
- Output: A set of 3D Gaussians $\mathcal{G} = \{g_1, \dots, g_N\}$, where each $g_k$ is defined by mean $\mu_k$, covariance $\Sigma_k$ (scale $s_k$, rotation $q_k$), opacity $\alpha_k$, and spherical harmonic coefficients $\mathbf{c}_k$.

**Data Structures:**
- **GaussianCube:** A structured grid representation created by converting a constant number of Gaussians into a voxelized format via optimal transport [S1]. This fixed-size representation allows the diffusion model to process the unstructured Gaussian set as a dense 3D volume.

**Steps:**
1. **Representation Conversion:** Convert the input or intermediate set of 3D Gaussians into a GaussianCube using voxelization via optimal transport [S1].
2. **Diffusion Process:** Train a 3D diffusion model on GaussianCube representations. During inference, the model denoises a latent GaussianCube to predict the target geometry.
3. **Structured Noise Incorporation:** Incorporate structured noise from multiple viewpoints during the diffusion process to enforce multi-view consistency and alleviate the Janus problem [S1][S2, unofficial].
4. **Variational Refinement:** Apply variational 3DGS techniques to the generated Gaussians to mitigate floaters and improve generation quality [S1][S2, unofficial].

**Parameters:**
- Not given in the sources.

**Edge Cases and Pitfalls:**
- The difference between the diffusion prior and the training process of the diffusion model can impair generation quality [S2, unofficial].
- Single-step reconstruction can suffer from high error if not properly supervised [S1].

## Subtopics

### [Direct 3D Generation](11810-direct-3d-generation.md)
Direct 3D Generation refers to methods that learn a feedforward or diffusion model to output Gaussian fields directly from text or images, without an explicit intermediate image set. It solves the problem of high reconstruction latency and multi-view inconsistency inherent in iterative optimization by amortizing the cost over a trained network. Unlike iterative reconstruction, it naturally promotes multi-view coherence and enables near-real-time sampling at test time.

### Gaussian Masking
Gaussian Masking uses Gaussian masks to prune Gaussians at every densification step and for every 500 iterations after densification stops [S3].
- **Parameters:**
  - $\lambda_m$: Loss weight for Gaussian masking loss. Value is 0.05 [S3].
  - $\epsilon_m$: Threshold for Gaussian masks. Value is 0.05 [S3].
  - Learning rate for Gaussian masks: 0.5 [S3].

- **When not:** When high-fidelity single-view reconstruction without multi-view constraints is sufficient, or when iterative optimization is preferred for fine-grained control.

## Background
GaussianDiffusion was proposed in [251] (cited in [S1][S2, unofficial]) as a method to incorporate structured noises from multiple viewpoints to alleviate the Janus problem and use variational 3DGS for better generation results by mitigating floaters. It is part of a broader trend of using generative models (diffusion or feed-forward) to predict 3D Gaussian parameters directly, bridging the gap between continuous latent spaces and discrete 3D Gaussian sets [S1]. The method relies on the GaussianCube representation, which converts a constant number of Gaussians into a voxelized format via optimal transport [S1].
