# DaReNeRF

Also called: DaReNeRF architecture, Direction-Aware Representation

## Overview
DaReNeRF is a method for representing dynamic 3D scenes that combines plane-based 4D volume decomposition with a direction-aware representation derived from the Dual-Tree Complex Wavelet Transform (DTCWT) [S1]. It solves the problem of directional ambiguity and checkerboard artifacts inherent in standard 2D Discrete Wavelet Transforms (DWT) by modeling features from six distinct directions using real and imaginary wavelet coefficients [S1]. Unlike standard plane-based methods, DaReNeRF explicitly encodes directional information to improve reconstruction quality while reducing memory complexity from $O(N^3 T F)$ to $O(R N^2 T F)$ through low-rank decomposition [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of posed images with timestamps.
*   **Outputs:** Rendered images at arbitrary poses and timestamps via volumetric rendering.

**Data Structures:**
The core data structure is the **Direction-Aware Representation** for each 2D plane $M^{AB}_r$ (where $A,B \in \{X,Y,Z,T\}, A \neq B$). It consists of:
1.  **Approximation Coefficient:** $W^{AB}_{a,r} \in \mathbb{R}^{m/2^{l-1} \times n/2^{l-1}}$, where $l$ is the DTCWT level.
2.  **Real Direction-Aware Coefficients:** $\{R\{W^{AB}_{i,r}\}\}_{i=1}^6$, where each $R\{W^{AB}_{i,r}\} \in \mathbb{R}^{m/2^l \times n/2^l}$.
3.  **Imaginary Direction-Aware Coefficients:** $\{I\{W^{AB}_{i,r}\}\}_{i=1}^6$, where each $I\{W^{AB}_{i,r}\} \in \mathbb{R}^{m/2^l \times n/2^l}$.
4.  **Mask:** $M^{AB} \in \mathbb{R}^{m \times n}$, used to induce sparsity.

For static scenes, the decomposition follows a TensorRF-like structure using plane-based representations $M^{AB}_r$ and vector-based representations $v^r_C$.

**Numbered Steps:**

1.  **Plane Reconstruction:** Reconstruct the plane-based representation $M^{AB}_r$ from its wavelet coefficients using the Inverse Dual-Tree Complex Wavelet Transform (IDTCWT) [S1]:
    $$ M^{AB}_r = \text{IDTCWT}([W^{AB}_{a,r}, \{R\{W^{AB}_{i,r}\}\}_{i=1}^6, \{I\{W^{AB}_{i,r}\}\}_{i=1}^6]) $$
    where $W^{AB}_{a,r}$ is the approximation coefficient, and $R\{W\}, I\{W\}$ are the real and imaginary direction-aware wavelet coefficients [S1].

2.  **Feature Extraction and Fusion:**
    a. Extract feature vectors from paired planes (e.g., $XY$ and $ZT$) [S1].
    b. Multiply the feature vectors from the paired planes element-wise [S1].
    c. Concatenate the multiplied results into a single vector [S1].
    d. Multiply the concatenated vector by $V_{RF}$, which stacks all learned vectors $v^r_i$ into a 2D tensor [S1].

3.  **Density and Opacity Query:** Query point opacities directly from the density features obtained in Step 2 [S1].

4.  **Color Regression:** Regress RGB color values using a compact Multi-Layer Perceptron (MLP). The MLP inputs are the appearance features (from Step 2) and the view direction [S1].

5.  **Volumetric Rendering:** Synthesize images via differentiable volumetric rendering along rays [S1].

6.  **Sparsity Masking (Optional/Implicit in Training):** To encourage sparsity, apply a mask to the wavelet coefficients. The masked coefficients $\tilde{W}^{AB}$ are computed as [S1]:
    $$ \tilde{W}^{AB} = \text{sg}(H(M^{AB}) - \text{sigmoid}(M^{AB})) \odot W^{AB} $$
    where $\text{sg}$ is the stop-gradient operator, $H$ is the Heaviside step function, and $M^{AB}$ are learned masks [S1].

7.  **Static Scene Decomposition (If applicable):** For static scenes, decompose the density field $D$ as [S1]:
    $$ D = \sum_{r=1}^{R1} M^{XY}_r \circ v^r_Z \circ v^{r1} + \sum_{r=1}^{R2} M^{XZ}_r \circ v^r_Y \circ v^{r2} + \sum_{r=1}^{R3} M^{YZ}_r \circ v^r_X \circ v^{r3} $$
    where $M^{AB}_r$ are plane-based representations, $v^r_C$ are vector-based representations, and $R1, R2, R3$ are the number of low-rank components [S1].

8.  **Emptiness Voxel Optimization:** Maintain a small 3D voxel representation to skip empty regions. Evaluate opacities across time steps and aggregate them by retaining the maximum opacity to generate the voxel [S1].

**Formulas:**
*   **Total Loss:** The model is optimized using a photometric loss combined with regularization and sparsity terms [S1]:
    $$ L = \frac{1}{|R|} \sum_{r \in R} ||C(r) - \hat{C}(r)||^2 + \lambda_{reg} L_{reg} + \lambda_m L_m $$
    where $C(r)$ is the rendered color, $\hat{C}(r)$ is the ground-truth color, $L_{reg}$ is the total variation loss, and $L_m$ is the mask sparsity loss (sum of all masks) [S1].

**Parameters:**
*   **Spatial Grid Size:** 512 [S1].
*   **Temporal Grid Size:** 300 [S1].
*   **Batch Size:** 4,096 [S1].
*   **Coordinate System:** Normalized Device Coordinates (NDC) [S1].
*   **Training Strategy:** Coarse-to-fine training, progressively increasing grid resolution [S1].

**Pitfalls and Edge Cases:**
*   **Checkerboard Effect:** Standard 2D DWT suffers from direction ambiguity and checkerboard artifacts. DaReNeRF mitigates this by using DTCWT, which employs two complex wavelets (real and imaginary parts) satisfying Hilbert transform properties, providing 6 directional coefficients versus 3 in DWT [S1].
*   **Empty Regions:** Large empty regions in dynamic scenes waste computation. The emptiness voxel strategy skips points in these regions, significantly aiding acceleration [S1].
*   **Memory Complexity:** The method reduces memory complexity from $O(N^3 T F)$ to $O(R N^2 T F)$ by defining $R = R1 + R2 + R3 \ll N$ [S1].

**Pseudocode:**

```python
def darenerf_forward(point_coords, view_dirs, plane_params, vec_params, mask_params):
    """
    Forward pass for DaReNeRF.
    
    Args:
        point_coords: (N, 4) tensor of (x, y, z, t) coordinates.
        view_dirs: (N, 3) tensor of view directions.
        plane_params: Dictionary of plane representations M_AB.
        vec_params: Dictionary of vector representations v_C.
        mask_params: Dictionary of masks M_AB.
        
    Returns:
        colors: (N, 3) tensor of predicted RGB colors.
        opacities: (N,) tensor of predicted opacities.
    """
    # 1. Extract and Fuse Features
    # Example for XY and ZT planes
    # Note: In practice, this involves sampling from the learned wavelet coefficients
    # and reconstructing the plane M_AB using IDTCWT.
    
    # Reconstruct plane features from wavelet coefficients
    # M_XY = IDTCWT(W_XY_approx, R{W_XY}, I{W_XY})
    # M_ZT = IDTCWT(W_ZT_approx, R{W_ZT}, I{W_ZT})
    
    # Extract feature vectors from paired planes
    feat_XY = sample_features(M_XY, point_coords[:, :2])
    feat_ZT = sample_features(M_ZT, point_coords[:, 2:])
    
    # Multiply element-wise
    fused_feat = feat_XY * feat_ZT
    
    # Concatenate and multiply by V_RF
    # V_RF stacks all v^r_i into a 2D tensor
    fused_vector = concatenate(fused_feat)
    density_appearance = matmul(fused_vector, V_RF)
    
    # 2. Query Opacity
    # Opacities are directly queried from density features
    opacities = query_opacity(density_appearance)
    
    # 3. Regress Color
    # Compact MLP with appearance features and view directions
    colors = color_mlp(density_appearance, view_dirs)
    
    return colors, opacities

def darenerf_loss(rendered_colors, gt_colors, plane_params, mask_params):
    """
    Compute the total loss for DaReNeRF.
    """
    # Photometric loss
    photometric_loss = mean_squared_error(rendered_colors, gt_colors)
    
    # Total Variation Loss for regularization
    tv_loss = total_variation(plane_params)
    
    # Mask Sparsity Loss
    mask_loss = sum(mask_params)
    
    # Total Loss
    # Lambda values are hyperparameters
    total_loss = photometric_loss + lambda_reg * tv_loss + lambda_m * mask_loss
    
    return total_loss
```

## Operating characteristics
*   **Memory Complexity:** Reduced from $O(N^3 T F)$ to $O(R N^2 T F)$, where $R$ is the number of low-rank components and $N$ is the grid size [S1].
*   **Hardware:** Tested on a single NVIDIA A100 GPU [S1].
*   **Performance:** Evaluated on Plenoptic Video and D-NeRF datasets for novel view synthesis of dynamic scenes [S1].
*   **Strengths:** Eliminates checkerboard effects through direction-aware representation; reduces memory usage; handles dynamic scenes effectively [S1].
*   **Limitations:** Requires careful tuning of mask sparsity and regularization weights; relies on coarse-to-fine training strategy [S1].

## Background
DaReNeRF was introduced in the paper "DaReNeRF: Direction-aware Representation for Dynamic Scenes" [S1]. It builds upon plane-based 4D volume decomposition and draws inspiration from the Dual-Tree Complex Wavelet Transform (DTCWT) [S1]. The method addresses limitations in standard 2D DWT, such as direction ambiguity, by leveraging the properties of complex wavelets [S1]. It is used in DaReNeRF and its sparse variant, DaReNeRF-S, for novel view synthesis [S1].
