# Appearance-Aware 3D Gaussian Splatting

Also called: AAGS

## Overview
AAGS reconstructs static scenes from unconstrained, in-the-wild photo collections by decoupling intrinsic object properties from extrinsic appearance conditions (lighting and post-processing) and explicitly removing transient objects [S1]. Unlike NeRF-based methods (e.g., NeRF-W, Ha-NeRF) which model transients explicitly with high overhead, or SWAG which requires additional Gaussian training for transients, AAGS leverages 3D Gaussian Splatting's fast rendering to use a lightweight 2D visibility mask for transient exclusion [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A collection of unconstrained images $\{I_i\}$ of a static scene.
*   **Output:** A set of 3D Gaussians representing the static scene geometry and appearance, and a trained appearance-aware rendering pipeline.

**Data Structures**
*   **3D Gaussian Parameters:** Each Gaussian $i$ is defined by:
    *   Center: $\mu_i \in \mathbb{R}^3$
    *   Rotation: Quaternion $q_i \in \mathbb{R}^4$
    *   Scaling: $s_i \in \mathbb{R}^3$
    *   Opacity: $\alpha_i \in [0, 1]$
    *   Implicit Color Feature: $V_{g,i} \in \mathbb{R}^{n_g}$ (replaces standard spherical harmonics coefficients) [S1].
*   **Appearance Extractor ($E_\Phi$):** A CNN-based network that outputs an image-specific latent vector $V_{ia} \in \mathbb{R}^{n_a}$ for each input image $I_i$ [S1].
*   **Color Decoder ($F_\theta$):** An MLP-based network with 4 layers and 64 hidden units. It takes $V_{g,i}$, $V_{ia}$, and directional encoding $\gamma(d)$ as input to predict color $c$ [S1].
*   **Transient UNet ($U_\Psi$):** A UNet with downsampling and upsampling layers that outputs a binary classification map $M_i \in [0, 1]$ of the same size as $I_i$. Values closer to 1 indicate static pixels [S1].

**Parameters**
*   $n_g = 24$: Length of Gaussian implicit feature vector $V_g$ [S1].
*   $n_a = 48$: Length of image appearance latent vector $V_{ia}$ [S1].
*   $\lambda_1 = 0.8$: Weight for L1 loss in the reconstruction loss [S1].
*   $\lambda_m$: Weight for transient regularization loss, starting at 0.5 and exponentially annealing to 0.15 [S1].
*   Spherical Harmonics Degree: 4, used for directional encoding $\gamma(d)$ [S1].

**Steps**

1.  **Initialization:** Initialize 3D Gaussians using a Structure from Motion (SfM) sparse point cloud. Assign parameters $\mu_i, q_i, s_i, \alpha_i$ and initialize $V_{g,i} \in \mathbb{R}^{24}$ [S1].
2.  **Appearance Encoding:** For each training image $I_i$, compute the appearance latent vector:
    $$ V_{ia} = E_\Phi(I_i) $$
    [S1]
3.  **Directional Encoding:** For each Gaussian $i$ and camera view, calculate the direction vector $d$ from the Gaussian center $\mu_i$ to the camera position. Apply spherical harmonic positional encoding to obtain $\gamma(d)$ [S1].
4.  **Color Prediction:** Concatenate $V_{g,i}$, $V_{ia}$, and $\gamma(d)$, and pass them through the color decoder $F_\theta$ to predict the color $c_i$:
    $$ c_i = F_\theta(V_{g,i}, V_{ia}, \gamma(d)) $$
    [S1]
5.  **Rasterization:** Project the 3D Gaussians to the 2D image plane. Calculate the projected opacity $\alpha'_i$ for each Gaussian $i$ at pixel location $x'$:
    $$ \alpha'_i = \alpha_i \exp\left(-0.5 (x' - \mu'_i)^T \Sigma'^{-1}_i (x' - \mu'_i)\right) $$
    where $\mu'_i$ and $\Sigma'_i$ are the projected mean and covariance matrix [S1].
6.  **Color Compositing:** Render the image $\hat{I}_i$ by sorting Gaussians $N$ front-to-back and compositing colors:
    $$ \hat{I}_i(x') = \sum_{i \in N} c_i \alpha'_i \prod_{j=1}^{i-1} (1 - \alpha'_j) $$
    [S1]
7.  **Transient Masking:** Compute the transient visibility map $M_i$ for the input image:
    $$ M_i = U_\Psi(I_i) $$
    [S1]
8.  **Loss Calculation:** Compute the total loss $L$ using the masked L1 and SSIM losses, plus transient regularization:
    $$ L = (1 - \lambda_1) L_{SSIM}(M_i \odot I_i, M_i \odot \hat{I}_i) + \lambda_1 L_1(M_i \odot I_i, M_i \odot \hat{I}_i) + \lambda_m L_m $$
    where $\odot$ is element-wise multiplication, and $L_m$ is the regularization loss [S1].
9.  **Regularization:** Prevent the trivial solution where $U_\Psi$ predicts all pixels as transient by minimizing:
    $$ L_m = (1 - M_i)^2 $$
    [S1]
10. **Optimization:** Update parameters $\{E_\Phi, F_\theta, U_\Psi, \mu, q, s, \alpha, V_g\}$ using gradient descent [S1].

**Pseudocode**

```python
def forward_pass(image, gaussians, camera_params, E_phi, F_theta, U_psi):
    # 1. Appearance Extraction
    Via = E_phi(image)
    
    # 2. Color Prediction for each Gaussian
    colors = []
    for g in gaussians:
        # Direction from Gaussian center to camera
        d = camera_params.position - g.center
        # Spherical Harmonic encoding (Degree 4)
        gamma_d = spherical_harmonic_encode(d, degree=4)
        # Predict color
        c = F_theta(g.Vg, Via, gamma_d)
        colors.append(c)
        
    # 3. Rasterization (Standard 3DGS Splatting)
    # Project Gaussians to 2D, compute alpha' and sort
    projected_gaussians = project_gaussians(gaussians, camera_params)
    sorted_gaussians = sort_front_to_back(projected_gaussians)
    
    # Composite color
    rendered_image = composite_colors(sorted_gaussians)
    
    # 4. Transient Masking
    M = U_psi(image)
    
    return rendered_image, M

def compute_loss(rendered_image, ground_truth_image, mask, lambda1, lambda_m):
    # Soft mask the images
    masked_gt = ground_truth_image * mask
    masked_pred = rendered_image * mask
    
    # Reconstruction Loss
    l_ssim = ssim_loss(masked_gt, masked_pred)
    l1 = l1_loss(masked_gt, masked_pred)
    l_rec = (1 - lambda1) * l_ssim + lambda1 * l1
    
    # Transient Regularization Loss
    # Prevents mask from being all zeros (all transient)
    l_m = mean((1 - mask)**2)
    
    total_loss = l_rec + lambda_m * l_m
    return total_loss
```

## Operating characteristics
*   **Speed:** Achieves reconstruction speeds at the minute level and real-time rendering capabilities, leveraging the fast rendering speed of 3D Gaussian Splatting [S1].
*   **Memory:** Trained on a single RTX 3090 GPU with 24GB memory [S1].
*   **Strengths:** Concise and efficient compared to SWAG (no extra Gaussian training for transients) and NeRF-based methods (faster, lower overhead) [S1]. Handles unconstrained in-the-wild photos without requiring COLMAP preprocessing for multi-view stereo [S1].
*   **Limitations:** Relies on the accuracy of the transient UNet; if the regularization is insufficient, it may fall into the trivial solution of masking everything [S1].

## Background
AAGS was introduced to extend 3D Gaussian Splatting to unconstrained photo collections, addressing the limitations of previous NeRF-based methods (NeRF-W, Ha-NeRF) and concurrent 3DGS-based methods (SWAG) [S1]. It was developed to facilitate real-world applications by combining high-quality reconstruction with real-time rendering [S1].
