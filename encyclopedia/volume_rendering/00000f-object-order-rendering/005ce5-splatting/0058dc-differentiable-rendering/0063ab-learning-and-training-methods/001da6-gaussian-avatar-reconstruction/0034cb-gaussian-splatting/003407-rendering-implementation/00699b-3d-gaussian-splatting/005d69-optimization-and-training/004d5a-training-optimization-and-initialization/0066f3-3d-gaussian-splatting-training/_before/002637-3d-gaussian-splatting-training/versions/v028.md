# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the photometric difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images by optimizing position, rotation, scale, opacity, and appearance (spherical harmonics) [S5, unofficial]. Unlike static initialization methods, it employs adaptive density control to dynamically split, clone, or prune Gaussians during optimization, balancing reconstruction fidelity against computational cost [S2]. It differs from NeRF-based methods by offering significantly faster training and inference speeds while achieving comparable image quality [S2][S4, unofficial].

## How it works
**Inputs:** A set of $N$ input images with known camera poses (rotation $R_{cw}$, translation $t_{cw}$, intrinsic matrix $K$) and initial 3D Gaussian estimates derived from Structure from Motion (SfM) [S2][S6, unofficial].
**Outputs:** Optimized 3D Gaussian parameters: positions $\mathbf{p}_i$, rotations $q_i$, scales $\mathbf{s}_i$, opacities $\alpha_i$, and spherical harmonic coefficients $h_i$ [S6, unofficial].

**Data Structures:**
*   **Gaussian Attributes:** Each Gaussian $i$ stores:
    *   Position $\mathbf{p}_i \in \mathbb{R}^3$ (initialized from SfM points) [S2][S6, unofficial].
    *   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion, initialized as constant) [S2][S6, unofficial].
    *   Scale $\mathbf{s}_i \in \mathbb{R}^3$ (initialized uniformly between 0 and 1) [S2][S6, unofficial].
    *   Opacity $\alpha_i \in [0, 1]$ (initialized as constant) [S2][S6, unofficial].
    *   Color $c_i$ (derived from spherical harmonic coefficients $h_i$, initialized from SfM) [S2][S6, unofficial].
*   **Camera Data:** Ground truth images $\gamma^{gt}$ and camera matrices [S6, unofficial].

**Formulas:**
The optimization minimizes a loss function $\mathcal{L}$ combining L1 loss and D-SSIM loss [S6, unofficial]:
$$ \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM} $$
where $\lambda$ is the SSIM weight (default 0.2) [S4, S6, unofficial].

The rendering process projects 3D Gaussians to 2D screen space. The rotation matrix $R$ from quaternion $q = (q_r, q_i, q_j, q_k)$ is [S2]:
$$ R(q) = 2 \begin{bmatrix} \frac{1}{2} - (q_j^2 + q_k^2) & q_i q_j - q_r q_k & q_i q_k + q_r q_j \\ q_i q_j + q_r q_k & \frac{1}{2} - (q_i^2 + q_k^2) & q_j q_k - q_r q_i \\ q_i q_k - q_r q_j & q_j q_k + q_r q_i & \frac{1}{2} - (q_i^2 + q_j^2) \end{bmatrix} $$

Pixel color $\gamma_j$ is computed via alpha blending of $N$ projected Gaussians sorted by depth [S6, unofficial]:
$$ \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij}, \quad \tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj}) $$
where $\alpha'_{ij} = g \alpha_i$ is the effective opacity, and $g$ is the 2D Gaussian contribution [S6, unofficial].

**Parameters:**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `sh_degree`: Spherical harmonic degree. Default: 3 [S3, S4, unofficial].
*   `shDegreeInterval`: Steps between increasing SH degree. Default: 1,000 [S3, S4, unofficial].
*   `resolutionSchedule`: Steps between doubling image resolution. Default: 3,000 [S3, S4, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S3, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: $\min(15,000, \text{numIters}/2)$ [S3, unofficial].
*   `refineEvery`: Frequency of densification/pruning operations. Default: 500 [S3, unofficial].
*   `densify_grad_thresh`: Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold for densification. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size splitting stops. Default: 4,000 [S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].
*   `bg_color`: Background color. Default: [0.613, 0.010, 0.398] (magenta) [S4, unofficial].

**Algorithm:**
1.  **Initialization:** Initialize positions $\mathbf{p}_i$ from SfM points in normalized bounds $[-1, 1]$. Initialize scales $\mathbf{s}_i$ between 0 and 1. Initialize rotations $q_i$ as unit quaternions and opacities $\alpha_i$ as constants [S2][S6, unofficial].
2.  **Iteration Loop:** For step $i$ from 1 to `numIters`:
    a.  **Camera Sampling:** Select a training camera $V$ and ground truth image $\hat{I}$ using round-robin with periodic shuffle [S2][S4, unofficial]. Apply downscaling if $i <$ `resolutionSchedule` [S4, unofficial].
    b.  **Rendering:** Rasterize Gaussians using camera $V$ to obtain rendered image $I$ [S2].
    c.  **Loss Computation:** Compute $\mathcal{L}$ between $I$ and $\hat{I}$ [S2].
    d.  **Backpropagation:** Compute gradients $\frac{\partial \mathcal{L}}{\partial \mathbf{p}}, \frac{\partial \mathcal{L}}{\partial q}, \frac{\partial \mathcal{L}}{\partial \mathbf{s}}, \frac{\partial \mathcal{L}}{\partial h}, \frac{\partial \mathcal{L}}{\partial \alpha}$ using the chain rule [S6, unofficial].
    e.  **Optimization Step:** Update parameters using the Adam optimizer [S2][S6, unofficial].
    f.  **Adaptive Density Control:** If $i$ is a refinement iteration (e.g., $i \% \text{refineEvery} == 0$) and $i > \text{densifyFrom}$:
        i.  **Pruning:** For each Gaussian, if $\alpha_i < \epsilon$ or the Gaussian is too large (screen size $> \text{split\_screen\_size}$), prune it [S2][S4, unofficial].
        ii. **Densification:** If the positional gradient magnitude $\|\nabla_{\mathbf{p}} \mathcal{L}\| > \text{densify\_grad\_thresh}$:
            *   **Over-reconstruction:** If the Gaussian scale norm $\|\mathbf{s}\| > \text{densify\_size\_thresh}$, split the Gaussian into two [S2].
            *   **Under-reconstruction:** Else, clone the Gaussian [S2].
    g.  **Scheduler Update:** Advance learning rate schedulers [S4, unofficial].

**Pseudocode:**
```python
def train_3dgs(training_data, num_iters=30000, sh_degree=3, refine_every=500, densify_from=500, densify_until=15000, densify_grad_thresh=0.0002, densify_size_thresh=0.01, split_screen_size=0.05, stop_screen_size_at=4000, max_gaussians=5000000, ssim_weight=0.2):
    # 1. Initialization
    gaussians = initialize_gaussians_from_sfm(training_data.sfm_points)
    # gaussians: list of {p, q, s, alpha, h}
    # p: position, q: quaternion, s: scale, alpha: opacity, h: SH coefficients
    
    optimizer = Adam(gaussians.parameters(), lr=1e-4)
    camera_iterator = InfiniteRandomIterator(training_data.cameras)
    
    for step in range(1, num_iters + 1):
        # 2. Camera Sampling
        cam = camera_iterator.next()
        gt_image = training_data.get_image(cam, step)
        
        # 3. Rendering
        rendered_image = rasterize(gaussians, cam)
        
        # 4. Loss Computation
        loss = (1 - ssim_weight) * l1_loss(rendered_image, gt_image) + ssim_weight * ssim_loss(rendered_image, gt_image)
        
        # 5. Backpropagation
        loss.backward()
        
        # 6. Optimization Step
        optimizer.step()
        optimizer.zero_grad()
        
        # 7. Adaptive Density Control
        if step > densify_from and step <= densify_until and step % refine_every == 0:
            prune_and_densify(gaussians, step, densify_grad_thresh, densify_size_thresh, split_screen_size, stop_screen_size_at, max_gaussians)
            
        # 8. Scheduler Update
        update_schedulers(optimizer, step)

def prune_and_densify(gaussians, step, densify_grad_thresh, densify_size_thresh, split_screen_size, stop_screen_size_at, max_gaussians):
    to_prune = []
    to_split = []
    to_clone = []
    
    for g in gaussians:
        # Pruning
        if g.alpha < 0.005 or (step <= stop_screen_size_at and g.screen_size > split_screen_size):
            to_prune.append(g)
            continue
            
        # Densification based on gradient
        if g.gradient_norm > densify_grad_thresh:
            if g.scale_norm > densify_size_thresh:
                to_split.append(g)
            else:
                to_clone.append(g)
                
    # Execute operations
    gaussians.remove(to_prune)
    gaussians.extend(split_gaussians(to_split))
    gaussians.extend(clone_gaussians(to_clone))
    
    # Cap max gaussians
    if len(gaussians) > max_gaussians:
        gaussians.sort(key=lambda g: g.alpha, reverse=True)
        gaussians = gaussians[:max_gaussians]
```

### HUGS
HUGS creates a coarse-to-fine deformation module using linear blend skinning and local learning-based refinement for animating virtual human avatars based on 3DGS [S1]. It utilizes tri-plane representation to factorize the canonical space, reconstructing the person and scene from monocular video (50-100 frames) within 30 minutes, achieving state-of-the-art performance at 20 FPS [S1].

### Wolf et al. Stereo Method
Trains a 3DGS to render stereo-calibrated novel views, applies stereo depth estimation on the rendered views, and fuses the estimated dense depth maps using a Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
A labeling pipeline that generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for the densification and pruning processes of 3D-GS optimization [S8, unofficial].

### Cross-View Pruning Mechanism
A mechanism comprising a Cross-View Consistency Loss and adaptive pruning to reduce Gaussian redundancy and ensure geometric validity [S9]. It selects adjacent view pairs with SSIM > 0.6, computes the loss to penalize residual discrepancies, and prunes based on depth consistency [S9].

### Structure-View Co-learning
A module combining structural and view-dependent gradients for robust joint optimization of Gaussian positions and appearance [S9]. The loss is $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$, where $\mathcal{L}_V$ is view gradient loss and $\mathcal{L}_S$ is structure gradient loss [S9].

### Single-view Mini-batch Strategy
A training data sampling strategy where data is organized per viewpoint, and a mini-batch consists of data from only a single viewpoint [S10, unofficial]. For each viewpoint $i$, datasets $D_i$ are collected, and a mini-batch $B_{3DGS}$ is sampled from $D = \{D_i\}$ with count=1 [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training typically takes 15-30 minutes for standard datasets (e.g., Mip-NeRF 360) on modern GPUs, significantly faster than NeRFs which can take hours [S2][S5, unofficial]. The C++ implementation with Metal backend (msplat) claims ~90 seconds on M4 Max [S4, unofficial].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians, which can grow up to 5,000,000 or more depending on scene complexity [S3, unofficial]. Sinc splatting variants consume less memory than standard Gaussians [S7].
*   **Performance:** Achieves real-time rendering (100+ FPS) at 1080p on consumer hardware [S5, unofficial]. PSNR and SSIM are comparable to NeRFs [S2].
*   **Strengths:** Fast training, real-time rendering, high visual fidelity [S2][S5, unofficial].
*   **Limitations:** Can produce "floaters" or artifacts in dynamic scenes; sensitive to initialization; large memory footprint for high-resolution scenes [S2][S5, unofficial].
*   **When to use:** Static or slowly changing scenes requiring real-time visualization [S5, unofficial].
*   **When not to use:** Highly dynamic scenes without temporal modeling, or scenes with extreme occlusions/transients without specific adaptations like WildGaussians [S3, S6, unofficial].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [S2]. It builds on the concept of radiance fields but uses explicit 3D Gaussians instead of implicit neural networks. The method initializes positions using sparse point clouds from SfM tools like COLMAP [S2]. It has since been extended to various domains including SLAM, dynamic scenes, and human avatars [S1].
