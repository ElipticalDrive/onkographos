# Error-Driven 2D Gaussian Training

Also called: 2D Gaussian Initialization, Image Space Optimization

## Overview
Error-Driven 2D Gaussian Training is a densification and initialization strategy that samples and optimizes 2D Gaussian kernels in image space using a differentiable rasterizer, then back-projects them to 3D [S1, unofficial]. It solves the problem of initializing view-dependent Gaussian kernels for complex specular radiance by leveraging pre-rendered images as fixed backgrounds, distinguishing it from standard 3DGS densification which operates directly in 3D space [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** Rendered images $I = \{I_i\}_{i=1}^M$ and depth maps $D = \{D_i\}_{i=1}^M$ from standard 3DGS training for all $M$ training views [S1, unofficial].
*   **Outputs:** A set of supplementary 3D Gaussian primitives initialized from optimized 2D kernels [S1, unofficial].

**Data Structures**
Each 2D Gaussian primitive is defined by the parameter set $\{x, \alpha, c, d, r, s\}_{2D}$ [S1, unofficial]:
*   $x$: Image-space coordinates $(u, v)$.
*   $s$: Scale along the two principal axes.
*   $r$: Rotation angle between the primary axis and the image y-axis.
*   $\alpha$: Opacity.
*   $c$: Color.
*   $d$: Depth value used for rendering-order sorting [S1, unofficial].

**Algorithm Steps**
1.  **Pre-rendering:** Obtain rendered images $I$ and depth maps $D$ from the standard 3DGS training loop [S1, unofficial].
2.  **Allocation:** Predefine the total number of supplementary Gaussians for the scene. Allocate the count across views proportional to their respective rendering loss values, assigning more kernels to higher-loss views [S1, unofficial].
3.  **Initialization:** For each view, initialize new Gaussian kernels with minimal opacity. Sample color $c$ from the current rendered image $I_i$ at the mean positions $x$. Determine spatial distribution via multinomial sampling across pixel coordinates $(u, v)$ with probability:
    $$p(u, v) \propto [(1 - \lambda_{SSIM}) L_1(u, v) + \lambda_{SSIM} L_{SSIM}(u, v)]^2$$
    where $L_1$ and $L_{SSIM}$ are the loss metrics and $\lambda_{SSIM}$ is the weight matching the original 3DGS paper [S1, unofficial].
4.  **Optimization:** Overlay supplementary 2D Gaussians on the image. Optimize parameters $\{x, \alpha, c, d, r, s\}_{2D}$ using a differentiable rasterizer that emulates 3DGS rendering. Use the pre-rendered image $I_i$ as a fixed background [S1, unofficial].
5.  **Depth Update:** During optimization, update each primitive’s depth $d$ via nearest-neighbor sampling on the depth map $D_i$ using the primitive's current image-space coordinates [S1, unofficial].
6.  **Augmentation and Pruning:** Periodically augment the kernel set by introducing 20% new primitives at fixed intervals. Prune primitives that exhibit excessive transparency or occupy insufficient pixels [S1, unofficial].
7.  **Depth Map Rendering:** Render depth maps for each training image to ensure correct rendering order. Compute depth values at points where transmittance first drops below 0.5 during rasterization, representing positions where 3D Gaussians attain maximal response along camera rays [S1, unofficial].
8.  **Back-projection:** Back-project optimized 2D primitives into world space to serve as initializations for new 3D Gaussians. This involves:
    *   Foreground-background separation through point cloud clustering.
    *   Determination of 3D Gaussian rotations and scales via Weighted Principal Component Analysis (WPCA) [S1, unofficial].
    *   Final calibration of the scales [S1, unofficial].

def initialize_2d_gaussians(n_primitives, image, depth_map, lambda_ssim):
    """
    Initializes 2D Gaussians using error-driven multinomial sampling.
    """
    # Compute pixel-wise loss map
    # Note: L1 and SSIM are computed per-pixel or locally
    l1_map = compute_l1_loss(image)
    ssim_map = compute_ssim_loss(image)
    
    # Compute sampling probability distribution
    # p(u, v) proportional to squared composite loss
    composite_loss = (1 - lambda_ssim) * l1_map + lambda_ssim * ssim_map
    probability_map = composite_loss ** 2
    probability_map = probability_map / sum(probability_map) # Normalize
    
    # Multinomial sampling for coordinates
    coords = multinomial_sample(probability_map, n_primitives)
    
    # Initialize parameters
    primitives = []
    for coord in coords:
        primitive = {
            'x': coord,
            'alpha': minimal_opacity, # Conservative strategy
            'c': sample_color(image, coord),
            'd': depth_map[coord], # Initial depth from map
            'r': 0, # Initial rotation
            's': default_scale # Initial scale
        }
        primitives.append(primitive)
        
    return primitives

## Operating characteristics
*   **Time Complexity:** Adds an optimization loop over image space primitives. Complexity depends on the number of supplementary Gaussians and the number of optimization steps.
*   **Memory Complexity:** Requires storing the supplementary 2D Gaussian parameters and the pre-rendered images/depth maps.
*   **Strengths:** Effective for reconstructing complex specular radiance by allowing view-dependent kernels to be initialized in the space where they are observed [S1, unofficial].
*   **Limitations:** Requires pre-rendered images and depth maps from a standard 3DGS training phase. The back-projection step involves additional geometric processing (clustering, WPCA) [S1, unofficial].
