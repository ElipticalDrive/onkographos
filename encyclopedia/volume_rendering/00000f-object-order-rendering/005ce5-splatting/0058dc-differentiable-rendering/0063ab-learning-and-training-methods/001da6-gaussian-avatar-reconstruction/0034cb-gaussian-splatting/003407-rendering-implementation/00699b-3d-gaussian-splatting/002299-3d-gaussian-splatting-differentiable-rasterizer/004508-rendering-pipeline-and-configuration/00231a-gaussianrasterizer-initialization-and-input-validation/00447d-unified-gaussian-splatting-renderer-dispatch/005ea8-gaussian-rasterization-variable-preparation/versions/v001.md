# Gaussian Rasterization Variable Preparation

Also called: render variable setup, splat parameter extraction

## Overview
Prepares a dictionary of PyTorch tensors containing 3D Gaussian parameters filtered by timestep, formatted for the differentiable Gaussian rasterizer. It converts raw learnable parameters (log-scales, logit-opacities, unnormalized rotations) into the physical quantities required by the rasterization kernel (scales, opacities, normalized rotations). It also initializes the 2D mean positions and constructs separate variable sets for color rendering and depth/silhouette rendering.

## How it works
**Inputs:**
- `params`: A dictionary containing raw Gaussian parameters. Must include keys: `timestep`, `log_scales`, `logit_opacities`, `unnorm_rotations`, `rgb_colors`, `means3D`.
- `curr_timestep`: Integer or float indicating the current time step to filter parameters [S1, unofficial].
- `w2c`: World-to-camera transformation matrix (used only for depth variable preparation) [S1, unofficial].

**Outputs:**
- `rendervar`: Dictionary for standard color rendering.
- `depth_rendervar`: Dictionary for depth and silhouette rendering.

**Data Structures:**
- `rendervar` and `depth_rendervar` are Python dictionaries with the following keys:
  - `means3D`: Tensor of shape $(N, 3)$, 3D positions.
  - `means2D`: Tensor of shape $(N, 2)$, 2D screen positions (initialized to zero).
  - `colors_precomp`: Tensor of shape $(N, 3)$, RGB colors.
  - `rotations`: Tensor of shape $(N, 4)$, normalized quaternion rotations.
  - `opacities`: Tensor of shape $(N, 1)$, scalar opacities.
  - `scales`: Tensor of shape $(N, 3)$, physical scales.

**Steps:**
1. **Filter by Timestep:** Identify active Gaussians for the current time step.
   $$ \text{selected\_params\_idx} = \{ i \mid \text{params}['\text{timestep}'][i] \le \text{curr\_timestep} \} $$
   Extract the subset:
   $$ \text{selected\_params} = \text{params}[\text{selected\_params\_idx}] $$
   [S1, unofficial]

2. **Handle Scale Dimensionality:** If the scale parameter is stored as a single scalar per Gaussian (shape ending in 1), tile it to match the 3D scale requirement.
   If $\text{selected\_params}['\text{log\_scales}'].shape[-1] == 1$:
   $$ \text{selected\_params}['\text{log\_scales}] = \text{torch.tile}(\text{selected\_params}['\text{log\_scales}], (1, 3)) $$
   [S1, unofficial]

3. **Compute Opacities:** Convert logit opacities to probability space.
   $$ \text{opacities} = \sigma(\text{selected\_params}['\text{logit\_opacities}]) $$
   where $\sigma(x) = \frac{1}{1 + e^{-x}}$.
   [S1, unofficial]

4. **Compute Scales:** Convert log scales to physical scales.
   $$ \text{scales} = \exp(\text{selected\_params}['\text{log\_scales}]) $$
   [S1, unofficial]

5. **Normalize Rotations:** Normalize unnormalized rotation quaternions to unit length.
   $$ \text{rotations} = \text{normalize}(\text{selected\_params}['\text{unnorm\_rotations}]) $$
   [S1, unofficial]

6. **Initialize 2D Means:** Create a zero tensor on CUDA matching the shape of `means3D` (projected later by the rasterizer).
   $$ \text{means2D} = \text{zeros}(\text{means3D}.shape, \text{device}=\text{'cuda'}) $$
   [S1, unofficial]

7. **Construct Color Render Variable:**
   $$ \text{rendervar} = \{ \text{'means3D'}: \text{means3D}, \text{'colors\_precomp'}: \text{selected\_params}['\text{rgb\_colors'}], \text{'rotations'}: \text{rotations}, \text{'opacities'}: \text{opacities}, \text{'scales'}: \text{scales}, \text{'means2D'}: \text{means2D} \} $$
   [S1, unofficial]

8. **Construct Depth Render Variable:**
   Compute depth and silhouette data from 3D means and camera matrix.
   $$ \text{depth\_data} = \text{get\_depth\_and\_silhouette}(\text{selected\_params}['\text{means3D}], \text{w2c}) $$
   $$ \text{depth\_rendervar} = \{ \text{'means3D'}: \text{means3D}, \text{'colors\_precomp'}: \text{depth\_data}, \text{'rotations'}: \text{rotations}, \text{'opacities'}: \text{opacities}, \text{'scales'}: \text{scales}, \text{'means2D'}: \text{means2D} \} $$
   [S1, unofficial]

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def prepare_gaussian_variables(params, curr_timestep, w2c):
    # 1. Filter by timestep
    selected_params_idx = params['timestep'] <= curr_timestep
    selected_params = {k: v[selected_params_idx] for k, v in params.items()}
    
    # 2. Handle scale dimensionality
    if selected_params['log_scales'].shape[-1] == 1:
        selected_params['log_scales'] = torch.tile(selected_params['log_scales'], (1, 3))
        
    # 3. Compute opacities
    opacities = torch.sigmoid(selected_params['logit_opacities'])
    
    # 4. Compute scales
    scales = torch.exp(selected_params['log_scales'])
    
    # 5. Normalize rotations
    rotations = F.normalize(selected_params['unnorm_rotations'], p=2, dim=-1)
    
    # 6. Initialize means2D
    means3D = selected_params['means3D']
    means2D = torch.zeros_like(means3D[:, :2], device=means3D.device)
    
    # 7. Construct color render variable
    rendervar = {
        'means3D': means3D,
        'colors_precomp': selected_params['rgb_colors'],
        'rotations': rotations,
        'opacities': opacities,
        'scales': scales,
        'means2D': means2D
    }
    
    # 8. Construct depth render variable
    # Note: get_depth_and_silhouette is assumed to return a tensor of shape (N, 3) 
    # or compatible format for colors_precomp, containing depth/silhouette info.
    depth_data = get_depth_and_silhouette(selected_params['means3D'], w2c)
    
    depth_rendervar = {
        'means3D': means3D,
        'colors_precomp': depth_data,
        'rotations': rotations,
        'opacities': opacities,
        'scales': scales,
        'means2D': means2D
    }
    
    return rendervar, depth_rendervar
```
[G] `get_depth_and_silhouette` is not defined in the source snippet but is called in Step 8. It typically computes the depth value (Z-coordinate in camera space) and a silhouette mask (1.0 for visible, 0.0 for invisible) for each Gaussian center. The output is packed into the `colors_precomp` field because the rasterizer expects a 3-channel tensor for `colors_precomp`. For depth rendering, the first channel might be depth, and the second/third might be unused or used for silhouette.

## Subtopics

## Operating characteristics
- **Time Complexity:** Linear in the number of Gaussians $N$ for filtering, tiling, sigmoid, exp, and normalization. $O(N)$.
- **Memory Complexity:** $O(N)$ for storing the filtered parameters and the two render variable dictionaries.
- **Strengths:** Efficiently prepares data for differentiable rendering by separating color and depth/silhouette paths. Handles dynamic scene updates via timestep filtering.
- **Limitations:** Requires all Gaussians to be on CUDA. The depth variable construction relies on an external helper function `get_depth_and_silhouette` which is not detailed in the source.

## Background
This method is part of the SplaTAM pipeline, which integrates Gaussian Splatting with SLAM (Simultaneous Localization and Mapping) for dynamic scene reconstruction. It enables differentiable rendering of time-varying Gaussian fields by filtering Gaussians based on their activation timestep.
