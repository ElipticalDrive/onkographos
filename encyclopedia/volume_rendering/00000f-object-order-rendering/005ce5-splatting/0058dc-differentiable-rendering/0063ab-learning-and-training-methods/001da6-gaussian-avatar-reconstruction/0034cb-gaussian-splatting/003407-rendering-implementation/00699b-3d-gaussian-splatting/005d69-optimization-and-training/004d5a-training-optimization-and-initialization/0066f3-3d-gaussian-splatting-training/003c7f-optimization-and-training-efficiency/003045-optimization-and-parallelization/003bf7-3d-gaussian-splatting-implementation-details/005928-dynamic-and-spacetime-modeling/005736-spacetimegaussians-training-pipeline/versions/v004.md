# SpacetimeGaussians Training Pipeline


## Overview
The SpacetimeGaussians training pipeline optimizes a dynamic 3D Gaussian splatting model for real-time dynamic view synthesis by combining adaptive density control with specific regularization terms and parameter freezing schedules [S1, unofficial]. It distinguishes itself from standard 3D Gaussian Splatting by introducing time-dependent Gaussian parameters and a structured training loop that freezes motion parameters after a certain iteration to stabilize the dynamic scene representation [S1, unofficial]. It builds on [Dynamic and Spacetime Modeling](16342-dynamic-and-spacetime-modeling.md).

## How it works
The pipeline initializes a Gaussian model with spherical harmonics (SH) degree and an RGB function, loads scene data, and sets up a CUDA background color tensor. It retrieves a specific rendering pipeline option (e.g., `train_ours_full`) which determines the rasterizer settings. The training loop iterates through a dataset, computing a loss function that combines L1 loss, D-SSIM loss, and optional regularization terms based on motion or scaling gradients. Adaptive density control (densification, splitting, pruning) is applied periodically based on positional gradients and opacity thresholds. Specific freezing masks are applied to motion parameters (`_omega`) and rotation parameters (`_rotation`) after iteration 8001 or `opt.densify_until_iter` to prevent overfitting and stabilize the dynamic model.

### Inputs and Outputs
*   **Inputs:**
    *   `dataset`: Contains model configuration and scene data.
    *   `gaussians`: The 3D Gaussian model object containing parameters like `_xyz`, `_opacity`, `_scaling`, `_rotation`, `_omega` (motion), and SH coefficients.
    *   `iteration`: Current training iteration number.
    *   `opt`: Configuration object containing hyperparameters (e.g., `densify_from_iter`, `densification_interval`, `opthr`, `reg`, `lambda_dssim`).
    *   `scene`: Scene object containing camera poses and images.
*   **Outputs:**
    *   Updated `gaussians` parameters.
    *   Rendered image $I$ and loss value $L$.

### Data Structures
*   **Background Tensor:**
    *   Shape: `(numchannels,)`
    *   Dtype: `torch.float32`
    *   Device: `cuda`
    *   Initialization: Zeros.
    *   `numchannels`: Default 9.
*   **Time Tensor (`gaussians.ts`):**
    *   Shape: `(1, 1, H, W)`
    *   Dtype: `torch.float32`
    *   Device: `cuda`
    *   Initialization: Ones if `None`.
    *   `H, W`: Dimensions from the first test camera.
*   **Omega Mask (`gaussians.omegamask`):**
    *   Type: Boolean tensor.
    *   Purpose: Determines which Gaussians keep their motion parameters (`_omega`) and which are frozen. Computed at iteration 8001 via `gaussians.zero_omegabymotion()`.

### Pseudocode

```python
def train_spacetime_gaussians(dataset, gaussians, opt, scene, iteration):
    """
    Main training step for SpacetimeGaussians.
    """
    # 1. Initialization (if first iteration)
    if iteration == 0:
        # Initialize background color tensor
        numchannels = 9
        background = torch.zeros(numchannels, dtype=torch.float32, device='cuda')
        
        # Initialize time tensor if not present
        if gaussians.ts is None:
            H, W = scene.first_test_camera_resolution
            gaussians.ts = torch.ones((1, 1, H, W), dtype=torch.float32, device='cuda')
        
        # Setup RGB decoder if needed
        if gaussians.rgbdecoder is not None:
            gaussians.rgbdecoder = gaussians.rgbdecoder.cuda()
            gaussians.rgbdecoder.eval()

    # 2. Retrieve Rendering Pipeline
    # Options: 'train_ours_full', 'train_ours_lite', 'train_ours_fullss', 'train_ours_litess'
    option = opt.render_option # e.g., 'train_ours_full'
    render_func, RasterizationSettings, Rasterizer = getrenderpip(option)
    
    # 3. Forward Pass
    # Render image I using current gaussians, scene cameras, and time t
    # Note: Specific rendering details depend on the chosen option (full vs lite)
    # and the underlying diff_gaussian_rasterization implementation.
    I = render_func(gaussians, scene, RasterizationSettings, Rasterizer, 
                    scaling_modifier=1.0, basicfunction='trbfunction')

    # 4. Loss Calculation
    # L_L1: L1 loss between rendered image I and ground truth I_gt
    # SSIM: Structural Similarity Index
    lambda_dssim = opt.lambda_dssim
    reg = opt.reg
    regl = opt.regl
    
    # Base loss components
    L_L1 = torch.abs(I - I_gt).mean()
    L_DSSIM = 1 - SSIM(I, I_gt)
    
    # Regularization term based on 'reg' flag
    if reg == 1:
        # L1 regularization on motion gradients
        g_motion = compute_gradient_norm(gaussians._omega) # Placeholder for gradient computation
        L_reg = regl * (torch.sum(g_motion) / gaussians.num_gaussians)
    elif reg == 9:
        # L2 regularization on omega gradients for r > 0
        g_omega = compute_gradient_norm(gaussians._omega)
        L_reg = regl * torch.sum(g_omega[g_omega > 0] ** 2)
    elif reg == 10:
        # L2 regularization on motion gradients
        g_motion = compute_gradient_norm(gaussians._omega)
        L_reg = regl * torch.sum(g_motion ** 2)
    elif reg == 4:
        # L1 regularization on scaling gradients
        g_scaling = compute_gradient_norm(gaussians._scaling)
        L_reg = regl * (torch.sum(g_scaling) / gaussians.num_gaussians)
    elif reg == 6:
        # Adaptive weighting for L1 and DSSIM
        r = clamp(torch.mean(I_gt) - 0.5 + lambda_dssim, 0, 1)
        L = (1 - r) * L_L1 + r * L_DSSIM
        L_reg = 0
    elif reg == 7:
        # Normalize L1 by 2 * mean(I_gt)
        L_L1 = L_L1 / (2 * torch.mean(I_gt))
        L_reg = 0
    elif reg == 8:
        # L2 regularization on mean difference
        L_reg = regl * torch.sum((torch.mean(I) - I) ** 2) / gaussians.num_gaussians
    else:
        L_reg = 0

    # Total Loss
    if reg != 6:
        L = (1 - lambda_dssim) * L_L1 + lambda_dssim * L_DSSIM + L_reg
    else:
        L = L # Already computed in reg==6 block

    # 5. Backward Pass
    L.backward()

    # 6. Densification and Pruning (if densify == 1)
    if opt.densify == 1:
        # At iteration 8001, compute omega mask
        if iteration == 8001:
            gaussians.omegamask = gaussians.zero_omegabymotion()
        
        # Freeze weights based on mask
        if iteration > 8001:
            # Freeze _omega where omegamask is True
            freeze_weightsbymasknounsqueeze(gaussians._omega, gaussians.omegamask)
            # Freeze _rotation where omegamask is False
            freeze_weightsbymasknounsqueeze(gaussians._rotation, ~gaussians.omegamask)
        
        # Densification
        if iteration > opt.densify_from_iter and iteration % opt.densification_interval == 0:
            if gaussians.flag < opt.desicnt:
                size_threshold = 20 if iteration > opt.opacity_reset_interval else None
                gaussians.densify_pruneclone(
                    opt.densify_grad_threshold, 
                    opt.opthr, 
                    scene.cameras_extent, 
                    size_threshold
                )
        
        # Pruning
        if gaussians.flag >= opt.desicnt and iteration < 7000:
            gaussians.prune_points(opacity_threshold=opt.opthr)
        
        # Opacity Reset
        if iteration % 3000 == 0:
            gaussians.reset_opacity()
            
        # Final Freezing and Pruning
        if iteration >= opt.densify_until_iter:
            # Freeze _omega and _rotation
            freeze_weightsbymasknounsqueeze(gaussians._omega, torch.ones_like(gaussians.omegamask, dtype=torch.bool))
            freeze_weightsbymasknounsqueeze(gaussians._rotation, torch.ones_like(gaussians.omegamask, dtype=torch.bool))
            
            # Prune points with z < 4.5 every 1000 iterations at specific offset
            if iteration % 1000 == 500:
                gaussians.prune_points(z_threshold=4.5)

    # 7. Optimizer Step
    optimizer.step()
    optimizer.zero_grad()

    return L, I
```

### Parameters
*   `numchannels`: Number of channels for background color. Default: 9.
*   `scaling_modifier`: Passed to render function. Default: 1.0.
*   `basicfunction`: Passed to render function. Default: `trbfunction`.
*   `GRsetting`, `GRzer`: Retrieved from `getrenderpip`.
*   `opt.densify`: Densification mode selector (0, 1, 2, 3).
*   `opt.densify_from_iter`: Iteration after which densification starts.
*   `opt.densification_interval`: Interval between densification steps.
*   `opt.densify_grad_threshold`: Gradient threshold for densification.
*   `opt.opthr`: Opacity threshold for pruning.
*   `opt.desicnt`: Count limit for densification.
*   `opt.densify_until_iter`: Iteration after which parameters are frozen.
*   `opt.opacity_reset_interval`: Interval for opacity reset.
*   `opt.reg`: Regularization type selector (1, 4, 6, 7, 8, 9, 10).
*   `opt.lambda_dssim`: Weight for D-SSIM loss.
*   `opt.regl`: Weight for regularization term.

### Edge Cases and Pitfalls
*   **RGB Decoder:** If `gaussians.rgbdecoder` is not None, it must be moved to CUDA and set to eval mode before rendering [S1, unofficial].
*   **Pruning Logic:** Pruning behavior changes based on the densification phase. Before `opt.desicnt` is reached, densification is prioritized. After `opt.desicnt` and before iteration 7000, pruning is based on opacity. After `opt.densify_until_iter`, pruning is based on Z-coordinate < 4.5 [S1, unofficial].
*   **Time Tensor:** If `gaussians.ts` is None, it must be initialized to ones with shape `(1, 1, H, W)` [S1, unofficial].

## Subtopics

### SpacetimeGaussians Densification & Pruning Schedule
A training iteration schedule that controls Gaussian densification, pruning, and parameter freezing based on iteration count, mode selection, and visibility metrics [S1, unofficial].
*   **Definition:** A structured schedule that adapts the Gaussian population during training to maintain quality and efficiency [S1, unofficial].
*   **Steps:**
    *   Select densification mode via `densify` parameter (0, 1, 2, or 3) [S1, unofficial].
    *   If `densify == 1`: Prune points where `gaussians._xyz[:,2] < 4.5` at iteration 1000, and reset opacity every 3000 iterations [S1, unofficial].
    *   If `densify == 3`: Update `max_radii2D` and `add_densification_stats` every iteration. Densify/prune clones at intervals. Prune low-opacity points if iteration < 7000. Reset opacity every `opt.opacity_reset_interval`. At iteration 10000, call `removeminmax` [S1, unofficial].
*   **Parameters:**
    *   `size_threshold`: Passed to `densify_pruneclone`. Set to 20 if `iteration > opt.opacity_reset_interval`, otherwise `None` [S1, unofficial].
    *   `opt.densify_until_iter`, `opt.densify_from_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, `opt.opthr`: Control thresholds and intervals for densification, pruning, and opacity resets [S1, unofficial].

## Background
The SpacetimeGaussians method was introduced by Li, Zhan, Chen, Zhang, Li, Zhong, and Yi in the paper "Spacetime Gaussian Feature Splatting for Real-Time Dynamic View Synthesis" presented at CVPR 2024 [S1, unofficial]. It extends the 3D Gaussian Splatting framework to handle dynamic scenes by incorporating time-dependent parameters and a specialized training pipeline [S1, unofficial]. The code is available on GitHub [S1, unofficial].
