# Keyframe Management
Also called: Keyframing
## Overview
Keyframe management maintains a small, computationally feasible sliding window $W_k$ of camera poses and corresponding Gaussian states to enable joint optimization in online 3D Gaussian Splatting SLAM [S1, unofficial]. It solves the infeasibility of jointly optimizing all captured frames by selecting non-redundant keyframes that span a wide baseline for multiview constraints while discarding those with low overlap [S1, unofficial]. It differs from fixed-interval or purely heuristic insertion by explicitly measuring covisibility via Gaussian rasterization visibility [S1, unofficial] or voxel allocation ratios [S2].
## How it works
**Inputs and Outputs:**
- Input: Current tracked frame $i$, last keyframe $j$, current keyframe window $W_k$, and scene representation (Gaussians or Voxels).
- Output: Updated window $W_k$ (insertion/removal of keyframes).

**Data Structures:**
- **Keyframe Window $W_k$:** A list or queue of keyframe indices/poses. Size is limited to a small constant (e.g., ~10-20, though exact max is "detailed in the supplementary" [S1, unofficial]).
- **Visibility Mask:** A boolean or count array indicating which Gaussians are visible from a specific view. A Gaussian is visible if it is used in rasterization and the accumulated alpha $\alpha$ along the ray has not reached 0.5 [S1, unofficial].

**Steps:**
1. **Covisibility Estimation:**
   - Calculate the Intersection over Union (IoU) of visible Gaussians between the current frame $i$ and the last keyframe $j$ [S1, unofficial]:
     $$ \text{Covisibility}(i, j) = \frac{|V_i \cap V_j|}{|V_i \cup V_j|} $$
     where $V_i$ is the set of visible Gaussians for frame $i$ [S1, unofficial].
   - Alternatively, for voxel-based methods, calculate the ratio $p_{kf} = N_c / N_o$, where $N_c$ is the number of voxels that would be allocated if frame $i$ were chosen as a keyframe, and $N_o$ is the number of currently observed voxels [S2].

2. **Keyframe Insertion:**
   - Register frame $i$ as a keyframe if:
     - Covisibility with the last keyframe drops below a threshold [S1, unofficial], OR
     - Relative translation $t_{ij}$ is large with respect to the median depth [S1, unofficial], OR
     - The ratio $p_{kf}$ exceeds a threshold [S2], OR
     - No keyframe has been created for the past $N$ frames (maximum interval constraint) [S2].
   - If inserted, initialize new Gaussians $\mu_W$ by back-projecting depth (if available) or rendering depth at the current frame with low variance [S1, unofficial].

3. **Keyframe Removal:**
   - Remove a keyframe from $W_k$ if its overlap coefficient with the latest keyframe drops below a threshold [S1, unofficial]. This heuristic follows DSO [S1, unofficial].

**Pseudocode:**
```python
def update_keyframe_window(current_frame, last_keyframe, window, scene):
    # Step 1: Estimate Covisibility
    visible_gaussians_current = get_visible_gaussians(current_frame, scene)
    visible_gaussians_last = get_visible_gaussians(last_keyframe, scene)
    
    # IoU calculation
    intersection = len(visible_gaussians_current & visible_gaussians_last)
    union = len(visible_gaussians_current | visible_gaussians_last)
    covisibility = intersection / union if union > 0 else 0.0
    
    # Relative translation check
    rel_translation = compute_relative_translation(current_frame, last_keyframe)
    median_depth = get_median_depth(scene)
    translation_large = rel_translation > threshold * median_depth
    
    # Step 2: Check Insertion Criteria
    should_insert = False
    
    # Criterion 1: Low Covisibility
    if covisibility < COVISIBILITY_THRESHOLD:
        should_insert = True
        
    # Criterion 2: Large Translation
    if translation_large:
        should_insert = True
        
    # Criterion 3: Max Interval (if no keyframe in past N frames)
    if frames_since_last_keyframe >= MAX_INTERVAL:
        should_insert = True
        
    # Criterion 4: Voxel Allocation Ratio (if using voxel-based method)
    # N_c = count_new_voxels(current_frame, scene)
    # N_o = count_observed_voxels(scene)
    # if (N_c / N_o) > VOXEL_RATIO_THRESHOLD:
    #     should_insert = True
        
    if should_insert:
        # Insert new keyframe
        window.append(current_frame)
        insert_new_gaussians(current_frame, scene)
        
        # Step 3: Remove old keyframes if necessary
        # Remove keyframe k from window if overlap(k, latest_keyframe) < OVERLAP_THRESHOLD
        latest = window[-1]
        for k in window[:-1]:
            if compute_overlap(k, latest) < OVERLAP_THRESHOLD:
                window.remove(k)
                
    return window
```

- **Covisibility Threshold:** Not given in the sources.
- **Translation Threshold:** Not given in the sources.
- **Max Interval ($N$):** Not given in the sources [S2].
- **Voxel Ratio Threshold:** Not given in the sources [S2].

**Edge Cases and Pitfalls:**
- **Loopy Camera Motions:** Without a maximum interval constraint, the system may fail to allocate new keyframes in loops, leading to missing parts of the model or insufficient multi-view constraints [S2].
- **Catastrophic Forgetting:** Online incremental learning is prone to forgetting; joint optimization with a sliding window helps mitigate this [S2].
- **Occlusion Handling:** The visibility metric (accumulated $\alpha < 0.5$) naturally handles occlusions without additional heuristics [S1, unofficial].

## Subtopics

### Keyframe Selection
A strategy for long-term map consistency in voxel-based SLAM (Vox-Fusion) that tests tracked frames against the existing map to determine allocatable voxels [S2]. It inserts a keyframe if the ratio of new allocatable voxels $N_c$ to currently observed voxels $N_o$ exceeds a threshold, ensuring exploratory movements are captured [S2]. It also enforces a maximum interval $N$ between keyframe insertions to prevent missing parts in loopy camera motions [S2].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of visible Gaussians for covisibility calculation [S1, unofficial]. Voxel-based selection requires intersection tests against the map [S2].
- **Memory Complexity:** Proportional to the size of the keyframe window $W_k$, which is kept small [S1, unofficial].
- **Performance:** Enables online optimization by restricting joint bundle adjustment to a small window [S1, unofficial].
- **Strengths:** Handles occlusions naturally via rasterization visibility [S1, unofficial]; prevents catastrophic forgetting [S2]; ensures multiview constraints via baseline selection [S1, unofficial].
- **Limitations:** Relies on heuristics for thresholds (detailed in supplementary [S1, unofficial]); may miss details if interval constraints are not tuned [S2].

## Background
Originated in the context of online 3D Gaussian Splatting SLAM, where joint optimization of all frames is infeasible [S1, unofficial]. The keyframe management heuristics are adapted from DSO [S1, unofficial]. Voxel-based keyframe selection was introduced in Vox-Fusion to ensure long-term map consistency and prevent catastrophic forgetting [S2].
