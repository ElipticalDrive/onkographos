# Application-Specific Extensions

Also called: Domain-Specific 3DGS, Non-Photometric Gaussian Splatting, Geometric 3DGS

## Overview
Application-Specific Extensions adapt the standard 3D Gaussian Splatting (3DGS) framework [2812-3d-gaussian-splatting.md] to non-photometric domains, explicit geometry extraction, or specialized physical phenomena. While standard 3DGS optimizes for novel-view synthesis of RGB images using view-dependent spherical harmonics, these extensions replace or augment the appearance model with view-independent scalar attributes, geometric priors, or physical quantities. They solve problems such as X-ray tomography, volumetric microscopy, ultrasound imaging, and explicit mesh extraction, where the target data is not surface reflectance but density, distance, or semantic structure.

## Shared principles
All extensions in this family retain the core 3DGS primitive representation: a set of $M$ anisotropic 3D Gaussian kernels $\mathcal{G} = \{G_i\}_{i=1}^M$ [Radiative Gaussian Splatting](3040-radiative-gaussian-splatting.md). Each kernel is defined by:
*   $\mathbf{p}_i \in \mathbb{R}^3$: Position (mean) [Radiative Gaussian Splatting](3040-radiative-gaussian-splatting.md).
*   $\mathbf{R}_i \in \mathbb{R}^{3 \times 3}$: Rotation matrix [Radiative Gaussian Splatting](3040-radiative-gaussian-splatting.md).
*   $\mathbf{S}_i \in \mathbb{R}^{3 \times 3}$: Scale matrix [Radiative Gaussian Splatting](3040-radiative-gaussian-splatting.md).
*   The covariance matrix is $\mathbf{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^\top \mathbf{R}_i^\top$ [Radiative Gaussian Splatting](3040-radiative-gaussian-splatting.md).

The rendering pipeline's geometric projection remains consistent for ray-based methods: 3D Gaussians are transformed into ray space, and the projected 2D covariance $\mathbf{\hat{\Sigma}}_i$ is computed using the Jacobian $J$ of the affine approximation of the projection and the rotation part $W$ of the extrinsic matrix:
$$ \mathbf{\hat{\Sigma}}_i = J W \mathbf{\Sigma}_i W^T J^T $$
[Radiative Gaussian Splatting](3040-radiative-gaussian-splatting.md)

However, the attribute representation and loss functions diverge significantly from the standard RGB opacity/color model [G]. Standard 3D Gaussian Splatting uses view-dependent color $\mathbf{c}_i(\mathbf{d})$ [G]. In radiative and domain-specific variants, this is replaced by view-independent scalar attributes or feature vectors [1875-volumetric-gaussian-splatting-avis.md], [3301-gaussian-splatting-for-microscopy.md], [5170-ultragauss-rendering.md].

## Subtopics

### [Radiative and Tomographic Gaussians](4971-radiative-and-tomographic-gaussians.md)
This family adapts 3DGS for X-ray imaging and radiative physics by replacing view-dependent color with view-independent scalar attributes (density or intensity) [Radiative Gaussian Splatting](3040-radiative-gaussian-splatting.md). It solves the problem of reconstructing volumetric density fields or synthesizing X-ray projections from 2D attenuation measurements, where physical attenuation depends on integrated density along the ray path rather than surface appearance [Radiative Gaussian Splatting](3040-radiative-gaussian-splatting.md). Unlike standard 3DGS, which uses spherical harmonics for view-dependent appearance, these methods remove angular dependence to model isotropic radiative transfer [Radiative Gaussian Splatting](3040-radiative-gaussian-splatting.md). [4971-radiative-and-tomographic-gaussians.md]

### [Domain-Specific Adaptations](5621-domain-specific-adaptations.md)
Domain-Specific Adaptations extend 3DGS to non-photometric domains by replacing view-dependent RGB color with scalar attributes or specialized geometric intersections [1875-volumetric-gaussian-splatting-avis.md], [3301-gaussian-splatting-for-microscopy.md], [5170-ultragauss-rendering.md]. Unlike standard 3DGS which optimizes for novel-view synthesis from calibrated RGB images, these methods optimize against 3D volume data, microscopy stacks, or ultrasound probe planes using domain-specific loss functions and rendering primitives [1875-volumetric-gaussian-splatting-avis.md], [3301-gaussian-splatting-for-microscopy.md], [5170-ultragauss-rendering.md]. [5621-domain-specific-adaptations.md]

### [Surface and Mesh Extraction](8498-surface-and-mesh-extraction.md)
This family provides methods to derive explicit geometric representations (meshes, point clouds, or semantic segmentations) from trained 3DGS models. Standard 3DGS renders implicit volumetric fields; these extensions bridge the gap to explicit geometry for applications requiring mesh-based editing, simulation, or semantic understanding. They differ from sibling methods by their specific geometric priors: [Gaussian Opacity Fields (GOF) Mesh Extraction](3692-gaussian-opacity-fields-gof-mesh-extraction.md) treats opacity as a continuous density field for isosurface extraction; [Distance-based Gaussian Splatting](7411-distance-based-gaussian-splatting.md) enforces alignment with a pre-existing mesh; [2D-Lift-3D Scene Segmentation](11513-2d-lift-3d-scene-segmentation.md) lifts 2D semantic masks to 3D primitives; and [Mesh Extraction via Poisson Reconstruction](12790-mesh-extraction-via-poisson-reconstruction.md) converts rendered depth/normal maps into an oriented point cloud for volumetric reconstruction. [8498-surface-and-mesh-extraction.md]

## Background
Originating from the need to apply Gaussian Splatting beyond standard computer vision tasks, these extensions emerged as the 3DGS framework matured. The core innovation was decoupling the geometric projection (which remains robust) from the attribute representation (which can be domain-specific). This allowed the efficient rasterization pipeline to be reused for tomography, microscopy, and geometry processing without redesigning the rendering engine.
