# 3D Gaussian Splatting Rendering with Language Features

Also called: LangSplat Rendering, Language Feature Rasterization

## Overview
This method extends the standard 3D Gaussian Splatting rasterizer to simultaneously render a language feature image alongside the RGB image by passing precomputed per-Gaussian language features to the rasterization backend [S1, unofficial]. It differs from standard 3DGS rendering by adding a parallel feature channel output and normalizing features per Gaussian before rasterization to prevent magnitude bias [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** `pc` (Gaussian primitive container), `opt` (configuration with `include_feature` flag), `pipe` (pipeline configuration with `compute_cov3D_python`, `convert_SHs_python`, and `scaling_modifier`), `bg_color` (background color tensor of shape `[3]` on GPU) [S1, unofficial].
*   **Outputs:** `rendered_image` (RGB tensor), `language_feature_image` (feature tensor), `radii` (screen-space radii tensor), and a dictionary containing `"render"`, `"language_feature_image"`, `"viewspace_points"`, `"visibility_filter"`, and `"radii"` [S1, unofficial].

**Data Structures:**
*   **Per-Gaussian Language Features:** A tensor retrieved from `pc` via `pc.get_language_feature()` [S1, unofficial]. The dimensionality depends on the feature level (e.g., 3D or higher), but the rasterization backend expects a feature tensor per Gaussian [S1, unofficial].
*   **GaussianRasterizationSettings:** Configuration object passed to the rasterizer backend, specifically setting `include_feature=opt.include_feature` [S1, unofficial].

**Steps:**
1.  Check the `opt.include_feature` flag to decide whether to compute and return language features [S1, unofficial].
2.  If `opt.include_feature` is true, retrieve per-Gaussian language features via `pc.get_language_feature()` [S1, unofficial].
3.  L2-normalize the language features per Gaussian to prevent magnitude bias during blending by dividing by the L2 norm along the last dimension plus a small epsilon [S1, unofficial]. The normalization formula is:
    $$
    \mathbf{f}_{norm} = \frac{\mathbf{f}}{\|\mathbf{f}\|_2 + \epsilon}
    $$
    where $\mathbf{f}$ is the feature vector, $\|\mathbf{f}\|_2$ is the L2 norm along the last dimension, and $\epsilon = 10^{-9}$ [S1, unofficial].
4.  If `opt.include_feature` is false, set `language_feature_precomp` to a dummy tensor of shape `(1,)` matching the dtype and device of `opacity` [S1, unofficial].
5.  Configure `GaussianRasterizationSettings` with `include_feature=opt.include_feature` [S1, unofficial].
6.  Prepare covariance and color data based on `pipe` settings: if `pipe.compute_cov3D_python` is true, compute 3D covariance in Python via `pc.get_covariance(scaling_modifier)`; otherwise, pass `scales` and `rotations` to the rasterizer [S1, unofficial]. If `pipe.convert_SHs_python` is true, evaluate spherical harmonics in Python using `eval_sh`; otherwise, pass raw SH coefficients (`shs`) or precomputed colors (`colors_precomp`) [S1, unofficial].
7.  Call the rasterizer with `means3D`, `means2D`, `shs`/`colors_precomp`, `language_feature_precomp`, `opacity`, and `scales`/`rotations`/`cov3D_precomp` [S1, unofficial].
8.  The rasterizer returns `rendered_image`, `language_feature_image`, and `radii` [S1, unofficial]. Return a dictionary containing `"render"`, `"language_feature_image"`, `"viewspace_points"`, `"visibility_filter"` (`radii > 0`), and `"radii"` [S1, unofficial].

**Pseudocode:**
```python
import torch

def render_language_features(pc, opt, pipe, bg_color, image_height, image_width, tanfovx, tanfovy, viewmatrix, projmatrix, sh_degree):
    # Step 1-4: Prepare language features
    if opt.include_feature:
        language_feature_precomp = pc.get_language_feature()
        # L2-normalize to prevent magnitude bias during blending
        language_feature_precomp = language_feature_precomp / (
            language_feature_precomp.norm(dim=-1, keepdim=True) + 1e-9
        )
    else:
        # Dummy tensor matching dtype and device of opacity
        language_feature_precomp = torch.zeros(1, dtype=pc.opacity.dtype, device=pc.opacity.device)

    # Step 6: Prepare covariance and colors
    if pipe.compute_cov3D_python:
        cov3D_precomp = pc.get_covariance(pipe.scaling_modifier)
        scales = None
        rotations = None
    else:
        cov3D_precomp = None
        scales = pc.scales
        rotations = pc.rotations

    if pipe.convert_SHs_python:
        # Evaluate spherical harmonics in Python
        colors_precomp = pc.get_sh_colors()
        shs = None
    else:
        colors_precomp = None
        shs = pc.shs

    # Step 5: Configure rasterization settings
    rasterization_settings = {
        "image_height": image_height,
        "image_width": image_width,
        "tanfovx": tanfovx,
        "tanfovy": tanfovy,
        "bg": bg_color,
        "scale_modifier": pipe.scaling_modifier,
        "viewmatrix": viewmatrix,
        "projmatrix": projmatrix,
        "sh_degree": sh_degree,
        "include_feature": opt.include_feature
    }

    # Step 7-8: Call rasterizer backend and return results
    rendered_image, language_feature_image, radii = rasterize(
        means3D=pc.means3D,
        means2D=pc.means2D,
        shs=shs,
        colors_precomp=colors_precomp,
        language_feature_precomp=language_feature_precomp,
        opacities=pc.opacity,
        scales=scales,
        rotations=rotations,
        cov3D_precomp=cov3D_precomp,
        settings=rasterization_settings
    )

    visibility_filter = radii > 0
    return {
        "render": rendered_image,
        "language_feature_image": language_feature_image,
        "viewspace_points": pc.means2D,
        "visibility_filter": visibility_filter,
        "radii": radii
    }

def rasterize(means3D, means2D, shs, colors_precomp, language_feature_precomp, opacities, scales, rotations, cov3D_precomp, settings):
    # Invokes the CUDA rasterization backend
    # Returns rendered RGB image, language feature image, and screen-space radii
    return torch.zeros(1, 3, settings["image_height"], settings["image_width"]), \
           torch.zeros(1, 3, settings["image_height"], settings["image_width"]), \
           torch.zeros(means3D.shape[0], dtype=torch.int32)
```

**Parameters:**
*   `opt.include_feature` (bool): Flag to enable/disable language feature rendering and computation [S1, unofficial].
*   `scaling_modifier` (float, default 1.0): Multiplier applied to Gaussian scales during rasterization [S1, unofficial].
*   `pipe.compute_cov3D_python` (bool): If true, computes 3D covariance in Python; otherwise passes `scales` and `rotations` [S1, unofficial].
*   `pipe.convert_SHs_python` (bool): If true, evaluates spherical harmonics in Python; otherwise passes raw SH coefficients [S1, unofficial].
*   `bg_color` (torch.Tensor, shape [3]): Background color tensor on GPU, set to `[1,1,1]` for white background or `[0,0,0]` for black [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Magnitude Bias:** Failure to L2-normalize language features can lead to magnitude bias during blending, causing incorrect feature interpolation [S1, unofficial].
*   **Feature Dimensionality:** The decoder elevates features from 3 dimensions to 512 dimensions for further operations, implying the rasterized language feature image may be low-dimensional (e.g., 3D) and requires post-processing for high-dimensional tasks [S1, unofficial].
*   **Dummy Tensor:** When features are disabled, a dummy tensor of shape `(1,)` must be passed to maintain tensor shape consistency in the rasterizer call [S1, unofficial].

## Operating characteristics

*   **Strengths:** Enables simultaneous rendering of semantic/language information alongside geometry and appearance, facilitating tasks like 3D object localization and semantic segmentation [S1, unofficial].
*   **Limitations:** Requires precomputed language features and an additional normalization step. The output language feature image is low-dimensional (3D) and requires a decoder for high-dimensional applications [S1, unofficial].

## Background
*   **Origin:** LangSplat was introduced by Minghan Qin, Wanhua Li, Jiawei Zhou, Haoqian Wang, and Hanspeter Pfister in the paper "LangSplat: 3D Language Gaussian Splatting" (CVPR 2024) [S1, unofficial].
*   **History:** The method extends the original 3D Gaussian Splatting framework to include language features, allowing for 3D language understanding and interaction. It builds upon the differentiable rasterization of 3D Gaussians [S1, unofficial].
*   **Usage:** Used for 3D object localization on LERF and 3D semantic segmentation on LERF, leveraging preprocessed datasets like 3D-OVS with language features [S1, unofficial].
