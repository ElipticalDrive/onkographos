# Direct 3D Generation

Also called: Direct Gaussian Generation, Feedforward 3DGS Synthesis

## Overview
Direct 3D Generation refers to methods that learn a feedforward or diffusion model to output 3D Gaussian Splatting (3DGS) fields directly from text or images, bypassing the explicit intermediate step of generating a set of multi-view images [S1]. By training on large collections of synthetic or reconstructed data, these models amortize the reconstruction cost and naturally promote multi-view coherence, enabling near-real-time sampling at test time [S1]. This approach differs from traditional two-stage pipelines (image generation followed by 3D reconstruction) by optimizing directly for the structured Gaussian output space, addressing challenges such as high-dimensional outputs (positions, anisotropic covariance, colors, opacity) and maintaining controllability [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Text prompts, input images, or partial 3DGS inputs (e.g., containing large occlusions) [S1, S3].
*   **Outputs:** A set of 3D Gaussian primitives defined by position, covariance (transform), color, and opacity [S1, S3].

**Data Structures:**
The method typically utilizes a Gaussian VAE to map Gaussian Splatting functions into a regularized latent space [S3]. The 3DGS is disentangled into three Gaussian Splatting Functions:
1.  **GauPF:** Gaussian Probability (geometry/locations) [S3].
2.  **GauCF:** Color Function [S3].
3.  **GauTF:** Transform Function (covariance/opacity) [S3].
The latent vector $z$ represents the compressed representation of these functions [S3].

**Algorithm Steps:**
1.  **Training (Latent Space):**
    *   Fit 3DGS to training data and extract GauPF, GauCF, and GauTF [S3].
    *   Train a Gaussian VAE to encode these functions into a latent vector $z$ [S3].
    *   Train a Conditional Latent Diffusion Model (LDM) in the latent space to predict noise or reverse the diffusion process on latent vectors $z_k$ derived from the VAE [S3]. The LDM is conditioned on text, image, or partial GS inputs [S3].
2.  **Generation (Diffusion Process):**
    *   Start from noise sampled from $N(0,1)$ [S3].
    *   Iteratively denoise from Step $K$ to Step $0$ using the trained LDM to obtain the clean latent vector $z_0$ [S3].
3.  **Decoding and Extraction:**
    *   Decode $z_0$ using the Gaussian VAE decoder to reconstruct GauPF, GauCF, and GauTF [S3].
    *   **Geometry Extraction:** Sample 3D locations in the 3D space with the highest Gaussian probabilities from GauPF [S3].
    *   **Attribute Prediction:** Predict the Gaussian attributes (color and transform) using GauCF and GauTF at the sampled locations [S3].
    *   **Discretization:** Apply octree-guided sampling and optimization to extract Gaussians at arbitrary numbers [S3].

**Pseudocode:**
```python
def generate_3dgs(condition, diffusion_model, vae_decoder, extractor):
    """
    Generates 3D Gaussian Splatting from a condition (text/image/partial GS).
    """
    # Step 1: Diffusion in Latent Space
    # Start with noise
    z_k = sample_noise(N(0, 1))
    
    # Iterative denoising from Step K to Step 0
    for k in range(K, 0, -1):
        # Predict noise or reverse diffusion step conditioned on input
        # epsilon_pred = diffusion_model(z_k, condition, t=k)
        # z_k = reverse_diffusion_step(z_k, epsilon_pred, t=k)
        z_k = diffusion_model.step(z_k, condition, k)
    
    z_0 = z_k
    
    # Step 2: Decode Latent to Gaussian Functions
    gau_pf, gau_cf, gau_tf = vae_decoder.decode(z_0)
    
    # Step 3: Extract Geometry and Attributes
    # Sample locations with highest probability from GauPF
    locations = extractor.sample_geometry(gau_pf)
    
    # Predict attributes at these locations
    colors = gau_cf.evaluate(locations)
    transforms = gau_tf.evaluate(locations)
    
    # Step 4: Discretization/Optimization (Optional refinement)
    gaussians = extractor.discretize(locations, colors, transforms)
    
    return gaussians
```

**Parameters:**
*   $K$: Number of diffusion steps. Not given in the sources.
*   Condition: Text, image, or partial GS. [S1, S3]

**Edge Cases and Pitfalls:**
*   **Imperfect Cross-View Consistency:** Can lead to noisy surface geometry, duplicated structures, and degraded textures, especially in occluded or textureless regions [S1].
*   **High-Dimensional Output Space:** The structured nature of positions, anisotropic covariance, colors, and opacity poses challenges for model stability [S1].
*   **Data Requirements:** Requires large, curated 3D training corpora [S1].

## Subtopics

### [Conditional 3D Gaussian Splatting Generation](15578-conditional-3d-gaussian-splatting-generation.md)
Conditional 3D Gaussian Splatting Generation extends the DiffGS framework to produce 3DGS representations conditioned on external signals such as text prompts, input images, or partial 3DGS inputs containing large occlusions. It differs from unconditional generation by leveraging frozen encoders (CLIP or PointNet) to map conditions into embeddings that guide the diffusion process, enabling controllable synthesis and completion.

### Align Your Gaussians (AYG)
Align Your Gaussians (AYG) is a method realizing text-to-4D synthesis and deformation, employing dynamic 3D Gaussians with deformation fields [S2]. It starts with a 3D-aware diffusion model and text-to-image model to create an initial 3D shape, then employs a text-to-video diffusion model for motion and a text-to-image model for visual quality [S2].
1. Start with 3D-aware diffusion model and text-to-image model to create initial 3D shape.
2. Employ text-to-video diffusion model to capture scene motion.
3. Utilize text-to-image model to maintain high visual quality for all frames [S2].

### Latent Diffusion Model (LDM) for 3DGS
A diffusion model trained in the latent space of the Gaussian VAE to generate novel 3DGS shapes conditionally or unconditionally [S3].
*   **Training:** The LDM is trained to predict noise or reverse the diffusion process on latent vectors $z_k$ derived from the VAE [S3].
*   **Generation:** Starts from noise $N(0,1)$, iteratively denoises to $z_0$ (Step K to Step 0), conditioned on text, image, or partial GS if applicable [S3].

## Operating characteristics
*   **Time Complexity:** Near-real-time sampling at test time due to the feedforward nature of the model [S1].
*   **Memory Complexity:** Requires storing the diffusion model and VAE decoder; latent space compression reduces memory compared to raw Gaussian fields [S3].
*   **Strengths:** Amortizes reconstruction cost; promotes multi-view coherence; enables direct text/image-to-3D generation [S1].
*   **Limitations:** Sensitive to imperfect cross-view consistency (noisy geometry in occluded regions); requires large curated 3D datasets [S1].
*   **When to Use:** When real-time generation from text/image is required and multi-view coherence is critical.
*   **When Not to Use:** When high-fidelity geometry in complex occluded regions is required without post-processing, or when training data is scarce [S1].

## Background
Direct 3D generation methods aim to learn a feedforward or diffusion model that outputs Gaussian fields directly from text or images, without an explicit intermediate image set [S1]. This approach addresses the limitations of two-stage pipelines by optimizing directly for the Gaussian output space [S1]. The field has evolved to include dynamic 4D generation (e.g., AYG) and latent space diffusion models (e.g., DiffGS) to handle high-dimensional structured outputs [S2, S3].
