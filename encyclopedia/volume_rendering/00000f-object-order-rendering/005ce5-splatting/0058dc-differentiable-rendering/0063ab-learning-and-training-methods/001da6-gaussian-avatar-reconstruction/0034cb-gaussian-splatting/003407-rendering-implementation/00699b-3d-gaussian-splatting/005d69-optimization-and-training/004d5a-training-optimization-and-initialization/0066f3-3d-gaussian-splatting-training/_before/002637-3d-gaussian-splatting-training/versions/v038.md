# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting (3DGS) Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images without relying on neural network weights, instead optimizing explicit geometric and appearance attributes directly [S6, unofficial]. Unlike NeRFs, which optimize implicit field values, 3DGS training optimizes a discrete set of ellipsoids, offering significantly faster training and real-time rendering speeds while achieving comparable image quality [S2][S5, unofficial]. It distinguishes itself from sibling methods like [GauFRe](7994-gaufre.md) by using a fixed set of primitives with adaptive density control rather than a fixed-resolution grid or voxel structure.

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of $N$ input images (or video frames) with known camera poses (rotation $R_{cw}$, translation $t_{cw}$, intrinsic matrix $K$) [S6, unofficial]. Initial 3D Gaussian parameters derived from Structure from Motion (SfM) [S2][S6, unofficial].
*   **Outputs:** Optimized 3D Gaussian parameters: positions $\mathbf{p}_w$, rotations $q$, scales $s$, opacities $\alpha$, and spherical harmonic coefficients $h$ [S6, unofficial].

**Data Structures**
Each Gaussian primitive $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$ (initialized from SfM points) [S6, unofficial].
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion) [S2].
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$ (initialized between 0 and 1) [S2].
*   Opacity $\alpha_i \in [0, 1]$ (initialized as a constant) [S6, unofficial].
*   Appearance: Spherical Harmonic coefficients $h_i$ (initialized from SfM colors) [S6, unofficial].

**Numbered Steps**
1.  **Initialization:** Initialize positions $\mathbf{p}_w$ and colors $h$ from SfM photogrammetry (e.g., COLMAP) [S2][S6, unofficial]. Initialize rotation $q$, scale $s$, and opacity $\alpha$ as constants [S6, unofficial]. Set iteration count $i = 0$ [S2].
2.  **Camera Sampling:** Select a training camera $V$ and retrieve the corresponding ground truth image $\hat{I}$ at the current resolution [S2]. The resolution is determined by a downscale schedule [S4, unofficial].
3.  **Rendering (Forward Pass):**
    *   Project 3D Gaussians to 2D screen space using the camera matrix [S2].
    *   Sort Gaussians by depth for each pixel [S2].
    *   Compute pixel color $\gamma_j$ via alpha blending:
        $$ \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij}, \quad \tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj}) $$
        where $\alpha'_{ij} = g \alpha_i$, and $g = \exp(-0.5 \omega'_0 d_0^2 - 0.5 \omega'_2 d_1^2 - \omega'_1 d_0 d_1)$ [S6, unofficial].
4.  **Loss Computation:** Calculate the loss $\mathcal{L}$ between the rendered image $\gamma$ and ground truth $\gamma_{gt}$:
    $$ \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM} $$
    where $\lambda$ is the SSIM weight (default 0.2) [S6, S4, unofficial].
5.  **Backpropagation:** Compute gradients $\frac{\partial \mathcal{L}}{\partial \theta}$ for all parameters $\theta \in \{q, s, h, \alpha, \mathbf{p}_w\}$ using the chain rule [S6, unofficial].
6.  **Optimization Step:** Update parameters using the Adam optimizer [S2][S6, unofficial].
7.  **Adaptive Density Control (Refinement):** If the current step is a refinement iteration (e.g., every 100 steps [S4, unofficial] or 500 steps [S3, unofficial]):
    *   **Pruning:** If $\alpha_i < \epsilon$ or the Gaussian is too large ($||\mathbf{s}_i|| > \tau_S$), remove the Gaussian [S2].
    *   **Densification:** If the positional gradient magnitude $\|\nabla_{\mathbf{p}} \mathcal{L}\| > \tau_p$:
        *   **Over-reconstruction:** If $||\mathbf{s}_i|| > \tau_S$, split the Gaussian into two [S2].
        *   **Under-reconstruction:** If $||\mathbf{s}_i|| \le \tau_S$, clone the Gaussian [S2].
8.  **Iteration:** Increment $i$. Repeat until convergence or max iterations [S2].

**Formulas**
*   **Rotation Matrix from Quaternion:**
    $$ R(q) = 2 \begin{bmatrix} \frac{1}{2} - (q_j^2 + q_k^2) & q_i q_j - q_r q_k & q_i q_k + q_r q_j \\ q_i q_j + q_r q_k & \frac{1}{2} - (q_i^2 + q_k^2) & q_j q_k - q_r q_i \\ q_i q_k - q_r q_j & q_j q_k + q_r q_i & \frac{1}{2} - (q_i^2 + q_j^2) \end{bmatrix} $$
    [S2]
*   **Jacobian for Position $\mathbf{p}_{w,i}$:**
    $$ \frac{\partial \mathcal{L}}{\partial \mathbf{p}_{w,i}} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial u_i} \frac{\partial u_i}{\partial \mathbf{p}_{c,i}} \frac{\partial \mathbf{p}_{c,i}}{\partial \mathbf{p}_{w,i}} + \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial c_i} \frac{\partial c_i}{\partial \mathbf{p}_{w,i}} + \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \mathbf{p}_{c,i}} \frac{\partial \mathbf{p}_{c,i}}{\partial \mathbf{p}_{w,i}} $$
    [S6, unofficial]
*   **Jacobian for Opacity $\alpha_i$:**
    $$ \frac{\partial \mathcal{L}}{\partial \alpha_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial \alpha_i} $$
    [S6, unofficial]
*   **Derivative of Effective Opacity w.r.t. Center $u_i$:**
    $$ \frac{\partial g}{\partial u_i} = [-\omega'_0 d_0 - \omega'_1 d_1, -\omega'_2 d_1 - \omega'_1 d_0]^T g $$
    [S6, unofficial]

**Parameters**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `sh_degree`: Spherical harmonic degree. Default: 3 [S4, unofficial].
*   `sh_degree_interval`: Steps between increasing SH degree. Default: 1,000 [S4, unofficial].
*   `resolution_schedule`: Steps between doubling image resolution. Default: 3,000 [S4, unofficial].
*   `densify_grad_thresh`: Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold for densification. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size splitting stops. Default: 4,000 [S4, unofficial].
*   `refine_every`: Frequency of refinement operations. Default: 100 [S4, unofficial].
*   `bg_color`: Background color. Default: Magenta [0.613, 0.010, 0.398] [S4, unofficial].

**Edge Cases and Pitfalls**
*   **No Cameras:** If all cameras are discarded because they see no sparse points, training fails [S3, unofficial].
*   **Arbitrary Pose:** Rendering with arbitrary poses requires exactly 16 elements for the `cam_to_world` matrix [S4, unofficial].
*   **Evaluation Mode:** Evaluation requires the dataset to be loaded with `eval_mode=True` [S4, unofficial].
*   **CPU Performance:** CPU execution is ~100x slower than GPU [S3, unofficial].

**Pseudocode**
```python
# Initialization
means = init_from_sfm() # Positions from SfM
quats = init_quaternions() # Unit quaternions
scales = init_scales() # Between 0 and 1
opacities = init_opacities() # Constant
sh_coeffs = init_sh_from_sfm() # Colors from SfM

optimizer = Adam([means, quats, scales, opacities, sh_coeffs])

for step in range(1, numIters + 1):
    # 1. Camera Sampling
    cam = camera_iterator.next()
    gt_image, mask = load_ground_truth(cam, step)
    
    # 2. Rendering
    rendered_rgb = render_gaussians(means, quats, scales, opacities, sh_coeffs, cam)
    
    # 3. Loss Computation
    loss = compute_loss(rendered_rgb, gt_image, mask, ssim_weight)
    
    # 4. Backpropagation
    loss.backward()
    
    # 5. Optimization Step
    optimizer.step()
    optimizer.zero_grad()
    
    # 6. Adaptive Density Control (Refinement)
    if step % refine_every == 0:
        gradients = get_gradients() # Specifically positional gradients
        
        for i in range(num_gaussians):
            # Pruning
            if opacities[i] < epsilon or is_too_large(scales[i]):
                remove_gaussian(i)
                continue
            
            # Densification
            if norm(gradients[i]) > densify_grad_thresh:
                if norm(scales[i]) > densify_size_thresh:
                    # Over-reconstruction: Split
                    split_gaussian(i)
                else:
                    # Under-reconstruction: Clone
                    clone_gaussian(i)

    # 7. Schedule Updates
    update_sh_degree(step)
    update_resolution(step)
    scheduler.step()
```

### Wolf et al. Stereo Method
Trains a 3DGS to render stereo-calibrated novel views, applies stereo depth estimation on the rendered views, and fuses the estimated dense depth maps using a Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
A labeling pipeline that generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for the densification and pruning processes of 3D-GS optimization [S8, unofficial].

### Cross-View Pruning Mechanism
A mechanism comprising a Cross-View Consistency Loss and adaptive pruning to reduce Gaussian redundancy. It selects adjacent view pairs with SSIM > 0.6, computes a Cross-View Consistent Loss ($L_{CVC}$) to penalize residual discrepancies, and prunes Gaussians based on depth consistency conditions ($d^i_p < 0.01 \land d^j_p < 0.5 \lor d^i_p > 3\sigma$) [S9].

### Structure-View Co-learning
A module combining structural and view-dependent gradients for robust joint optimization. The loss is defined as $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$, where $\mathcal{L}_V$ is view gradient loss and $\mathcal{L}_S$ is structure gradient loss [S9].

### Single-view Mini-batch Strategy
A training data sampling strategy where data is organized per viewpoint. A mini-batch consists of data from only a single viewpoint, improving training efficiency for multi-view scenarios [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is significantly faster than NeRFs, often completing in minutes to hours depending on scene complexity and resolution [S2][S5, unofficial].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians. The default maximum is 5,000,000 Gaussians, but this can be unlimited [S3, unofficial].
*   **Performance:** Achieves real-time rendering speeds (30-100+ FPS) on modern GPUs [S5, unofficial].
*   **Strengths:** Fast training, real-time rendering, high visual fidelity [S2][S5, unofficial].
*   **Limitations:** Can produce "floaters" in empty space; sensitive to initialization; large memory footprint for high-resolution scenes [S2][S5, unofficial].
*   **Hardware:** Supports CUDA, MPS, and CPU (CPU is ~100x slower) [S3, S4, unofficial].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [S2]. It builds on the concept of radiance fields but replaces neural networks with explicit 3D Gaussians. The method initializes positions using sparse point clouds from SfM tools like COLMAP [S2]. It has since been extended to various domains including SLAM, dynamic scenes, and physical parameter optimization [S1].
