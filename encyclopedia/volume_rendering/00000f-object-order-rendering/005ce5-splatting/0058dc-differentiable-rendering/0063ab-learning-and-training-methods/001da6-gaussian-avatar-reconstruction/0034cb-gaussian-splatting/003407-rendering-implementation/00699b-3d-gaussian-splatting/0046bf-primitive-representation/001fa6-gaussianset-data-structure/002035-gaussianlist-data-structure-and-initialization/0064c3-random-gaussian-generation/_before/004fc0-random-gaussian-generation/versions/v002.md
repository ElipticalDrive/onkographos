# Random Gaussian Generation

Also called: Gaussian Generation Dataset, Random Gaussian Sampling

## Overview
Random Gaussian Generation is the initialization procedure for creating a set of 3D Gaussians from scratch, typically to serve as the starting point for differentiable rendering optimization in methods like 3D Gaussian Splatting. It generates a fixed number of Gaussian primitives with random positions (implicitly at the origin before transformation), scales, orientations, opacities, and spherical harmonics coefficients. It differs from [LinPrim Population Control](2295-linprim-population-control.md) which manages the density of existing Gaussians during training, and from [Gaussian Splatting Initialization and Parameterization](2313-gaussian-splatting-initialization-and-parameterization.md) which may use structured or data-driven initialization strategies. This method provides a uniform, uninformative prior over the parameter space.

## How it works
The method generates a set of $N$ Gaussian objects. Each Gaussian is defined by a centroid, a scale vector, a rotation quaternion, an opacity scalar, and spherical harmonics (SH) coefficients for color.

### Inputs and Outputs
**Inputs:**
- `num_samples`: Total number of Gaussians to generate. Default: 1000 [S1, unofficial].
- `num_points`: Number of points per Gaussian (used for internal representation or visualization, not stored in the final Gaussian object). Default: 144 ($12 \times 12$) [S1, unofficial].
- `min_scale`: Lower bound for the uniform distribution of scale components (in log space). Default: -12 [S1, unofficial].
- `max_scale`: Upper bound for the uniform distribution of scale components (in log space). Default: -2 [S1, unofficial].
- `min_opacity`: Lower bound for the uniform distribution of opacity (in logit space). Default: -5 [S1, unofficial].
- `max_opacity`: Upper bound for the uniform distribution of opacity (in logit space). Default: 10 [S1, unofficial].
- `sh_degree`: Maximum spherical harmonics degree to generate. Default: 3 [S1, unofficial].
- `return_type`: Output format. Options: `'gaussian'`, `'param'`, or `'both'`. Default: `'gaussian'` [S1, unofficial].

**Outputs:**
- A list or tensor of Gaussian objects/parameters. If `return_type` is `'gaussian'`, returns full Gaussian objects. If `'param'`, returns raw parameter tensors. If `'both'`, returns both [S1, unofficial].

### Data Structures
Each Gaussian object contains:
- `centroid`: 3D vector $[0, 0, 0]$ (initial position, often transformed later) [S1, unofficial].
- `scale`: 3D vector $[s_x, s_y, s_z]$ [S1, unofficial].
- `rotation`: Quaternion $q$ derived from a rotation matrix [S1, unofficial].
- `opacity`: Scalar $\alpha$ [S1, unofficial].
- `feat_dc`: 3D vector containing DC SH coefficients for R, G, B [S1, unofficial].
- `feat_extra`: Concatenated higher-order SH coefficients [S1, unofficial].

### Steps
1. **Initialize Scale**: For each Gaussian $i$, sample $s_x, s_y, s_z$ independently from a uniform distribution $U(\text{min\_scale}, \text{max\_scale})$ [S1, unofficial].
2. **Initialize Rotation**:
   - Generate a $3 \times 3$ matrix $M$ with entries drawn from a standard normal distribution $\mathcal{N}(0, 1)$ [S1, unofficial].
   - Compute the QR decomposition of $M$: $M = QR$ [S1, unofficial].
   - Take the $Q$ factor as the rotation matrix $R_{mat}$ [S1, unofficial].
   - Convert $R_{mat}$ to a quaternion $q$ using a standard conversion function (e.g., `rotmat2qvec`) [S1, unofficial].
3. **Initialize Opacity**: Sample opacity $\alpha_i$ from a uniform distribution $U(\text{min\_opacity}, \text{max\_opacity})$ [S1, unofficial]. Note: These values are likely logits, to be converted to probabilities via sigmoid during rendering or optimization [G].
4. **Initialize Spherical Harmonics Coefficients**:
   - For each color channel (R, G, B) and each degree $d$ from $0$ to $\text{sh\_degree}$:
     - Calculate variance $\sigma_d^2 = \frac{1}{4^d}$ [S1, unofficial].
     - Sample $(2d+1)$ coefficients from a normal distribution $\mathcal{N}(0, \sigma_d)$ [S1, unofficial].
   - If $\text{sh\_degree} < \text{max\_SH\_degree}$ (where max_SH_degree is typically 3 or higher in full implementations), fill the remaining coefficients with noise from $\mathcal{N}(0, 0.05)$ [S1, unofficial].
   - The DC coefficients ($d=0$) for R, G, B form `feat_dc` [S1, unofficial].
   - Higher-order coefficients ($d > 0$) are concatenated to form `feat_extra` [S1, unofficial].
5. **Construct Gaussian Object**: Assemble the components into a Gaussian object with centroid at $[0,0,0]$, scale $[s_x, s_y, s_z]$, rotation $q$, opacity $\alpha$, `feat_dc`, and `feat_extra` [S1, unofficial].
6. **Repeat**: Steps 1-5 are repeated for $N = \text{num\_samples}$ Gaussians.

### Pseudocode
```python
import numpy as np
import torch

def generate_random_gaussians(num_samples=1000, min_scale=-12, max_scale=-2,
                              min_opacity=-5, max_opacity=10, sh_degree=3,
                              return_type='gaussian'):
    """
    Generates a set of random 3D Gaussians for initialization.
    """
    gaussians = []
    
    for _ in range(num_samples):
        # 1. Generate Scale
        scale = np.random.uniform(min_scale, max_scale, 3)
        
        # 2. Generate Rotation
        # QR decomposition of random normal matrix
        M = np.random.randn(3, 3)
        Q, R = np.linalg.qr(M)
        # Ensure proper rotation matrix (handle reflection if det(Q) == -1)
        if np.linalg.det(Q) < 0:
            Q[:, 0] *= -1
        # Convert rotation matrix to quaternion
        # Assuming a standard conversion function exists
        rotation = rotmat2qvec(Q)
        
        # 3. Generate Opacity
        opacity = np.random.uniform(min_opacity, max_opacity)
        
        # 4. Generate Spherical Harmonics Coefficients
        feat_dc = []
        feat_extra = []
        
        for d in range(sh_degree + 1):
            variance = 1.0 / (4 ** d)
            std = np.sqrt(variance)
            num_coeffs = 2 * d + 1
            
            # Sample coefficients for R, G, B
            coeffs_r = np.random.normal(0, std, num_coeffs)
            coeffs_g = np.random.normal(0, std, num_coeffs)
            coeffs_b = np.random.normal(0, std, num_coeffs)
            
            if d == 0:
                feat_dc = [coeffs_r[0], coeffs_g[0], coeffs_b[0]]
            else:
                feat_extra.extend(coeffs_r)
                feat_extra.extend(coeffs_g)
                feat_extra.extend(coeffs_b)
        
        # Fill remaining coefficients if sh_degree < max possible (e.g., 3)
        # Assuming max_SH_degree is 3 for this example
        max_sh_degree = 3
        if sh_degree < max_sh_degree:
            for d in range(sh_degree + 1, max_sh_degree + 1):
                num_coeffs = 2 * d + 1
                noise = np.random.normal(0, 0.05, num_coeffs)
                feat_extra.extend(noise)
                feat_extra.extend(np.random.normal(0, 0.05, num_coeffs))
                feat_extra.extend(np.random.normal(0, 0.05, num_coeffs))
        
        # 5. Construct Gaussian Object
        gaussian = {
            'centroid': np.array([0.0, 0.0, 0.0]),
            'scale': scale,
            'rotation': rotation,
            'opacity': opacity,
            'feat_dc': np.array(feat_dc),
            'feat_extra': np.array(feat_extra)
        }
        gaussians.append(gaussian)
        
    return gaussians

def rotmat2qvec(R):
    """
    Converts a 3x3 rotation matrix to a quaternion [w, x, y, z].
    Standard conversion algorithm.
    """
    m00, m01, m02 = R[0, 0], R[0, 1], R[0, 2]
    m10, m11, m12 = R[1, 0], R[1, 1], R[1, 2]
    m20, m21, m22 = R[2, 0], R[2, 1], R[2, 2]
    
    trace = m00 + m11 + m22
    if trace > 0:
        s = 0.5 / np.sqrt(trace + 1.0)
        w = 0.25 / s
        x = (m21 - m12) * s
        y = (m02 - m20) * s
        z = (m10 - m01) * s
    elif (m00 > m11) and (m00 > m22):
        s = 2.0 * np.sqrt(1.0 + m00 - m11 - m22)
        w = (m21 - m12) / s
        x = 0.25 * s
        y = (m01 + m10) / s
        z = (m02 + m20) / s
    elif m11 > m22:
        s = 2.0 * np.sqrt(1.0 + m11 - m00 - m22)
        w = (m02 - m20) / s
        x = (m01 + m10) / s
        y = 0.25 * s
        z = (m12 + m21) / s
    else:
        s = 2.0 * np.sqrt(1.0 + m22 - m00 - m11)
        w = (m10 - m01) / s
        x = (m02 + m20) / s
        y = (m12 + m21) / s
        z = 0.25 * s
        
    return np.array([w, x, y, z])
```

### Edge Cases and Pitfalls
- **Reflection in Rotation**: The QR decomposition of a random normal matrix can produce a reflection (determinant -1) instead of a rotation. The pseudocode includes a check to flip the first column if `det(Q) < 0` to ensure a proper rotation matrix [G].
- **Opacity Range**: The default opacity range $[-5, 10]$ suggests logit space. If used directly as probability, it will cause numerical issues. It should be passed through a sigmoid function if interpreted as probability [G].
- **SH Variance**: The variance decreases exponentially with degree ($1/4^d$). This ensures higher-frequency details have smaller initial amplitudes, stabilizing optimization [S1, unofficial].
- **Missing SH Coefficients**: If `sh_degree` is less than the maximum supported degree, remaining coefficients must be filled with noise to maintain tensor shape consistency [S1, unofficial].

## Subtopics

### [Consistent Anchor Guided Gaussian Splatting](14982-consistent-anchor-guided-gaussian-splatting.md)
Consistent Anchor Guided Gaussian Splatting (CAG-GS) is a large-scale scene rendering method that employs a divide-and-conquer strategy with semantic guidance to ensure global consistency across spatial blocks, thereby avoiding artifacts such as floaters and brightness inconsistencies. It distinguishes itself from sibling methods like Momentum-GS by directly incorporating consistent semantic information from a pre-trained segmentation model (SAM2) to guide feature learning, rather than relying solely on shared MLP decoders for regularization.

## Operating characteristics
- **Time Complexity**: $O(N \cdot D)$, where $N$ is the number of samples and $D$ is the number of SH coefficients. The QR decomposition is $O(1)$ per Gaussian (fixed 3x3 matrix).
- **Memory Complexity**: $O(N \cdot D)$ to store the generated Gaussians.
- **Performance**: The method is fast and deterministic in its randomness. It does not depend on scene geometry, making it suitable for initial exploration or when no point cloud is available.
- **Strengths**: Simple to implement, no external data required, provides a diverse initial set of orientations and scales.
- **Limitations**: The Gaussians are not aligned with any scene structure, leading to slow convergence if the scene is complex. The random positions (implicitly at origin) require subsequent transformation or optimization to match the scene [G].
- **When to Use**: When initializing a new scene with no prior geometric information, or as a baseline for comparison.
- **When Not to Use**: When a point cloud or mesh is available, structured initialization (e.g., [Gaussian Splatting Initialization and Parameterization](2313-gaussian-splatting-initialization-and-parameterization.md)) is preferred for faster convergence and better initial quality.

## Background
The method is described in the context of the `gs-embedding` project, which explores embedding-based representations for 3D Gaussians [S1, unofficial]. The specific parameters and generation steps are derived from the implementation details provided in the source code and documentation of this project. The use of QR decomposition for random rotations is a standard technique in computer graphics for generating uniform random rotations [G]. The exponential decay of SH variance is a common practice in neural rendering to stabilize training [G].
