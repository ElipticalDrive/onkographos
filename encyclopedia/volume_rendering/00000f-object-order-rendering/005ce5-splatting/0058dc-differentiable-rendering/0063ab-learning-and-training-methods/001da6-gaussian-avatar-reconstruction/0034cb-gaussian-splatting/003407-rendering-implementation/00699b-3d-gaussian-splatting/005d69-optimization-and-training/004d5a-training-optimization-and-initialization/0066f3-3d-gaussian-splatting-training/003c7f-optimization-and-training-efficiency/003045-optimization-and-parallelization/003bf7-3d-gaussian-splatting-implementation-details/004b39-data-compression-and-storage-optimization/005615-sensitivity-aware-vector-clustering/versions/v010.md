# Sensitivity-Aware Vector Clustering

Also called: Color Compression, Niedemayr et al. compression, Niedermayr, Sensitivity-Aware Scene Compression, Sensitivity-Aware Vector Clustering for 3DGS Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering spherical harmonic (SH) coefficients and Gaussian shape features (scale and rotation) into compact codebooks using sensitivity-aware vector quantization [S1, S2]. It sets itself apart from standard post-training quantization by deriving a sensitivity measure for each scene parameter to guide the clustering process, prioritizing the preservation of parameters that significantly affect image quality [S1]. Unlike [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md) which may use different pruning or quantization strategies, this method explicitly weights the k-Means distance metric by parameter sensitivity [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of optimized 3D Gaussians $\{G_i\}$, each defined by position $\mathbf{p}_i$, opacity $\alpha_i$, scale $\mathbf{s}_i$, rotation $\mathbf{q}_i$, and SH coefficients $\mathbf{c}_i$. A set of training images with known camera parameters.
*   **Outputs:** Two codebooks (one for SH coefficients, one for shape parameters) and a compressed representation of the Gaussians consisting of indices into these codebooks, along with uncompressed position, opacity, and other non-clustered parameters.

**Data Structures:**
1.  **Codebook (Shape):** A list of $K$ entries. Each entry consists of 4 scalar values for a quaternion (rotation) and 3 scalar values for scaling [S1].
2.  **Codebook (Color):** A list of $K$ entries. Each entry consists of the SH coefficient vector for a specific order (e.g., 48 coefficients for 3rd order) [S1].
3.  **Gaussian Record:** For each Gaussian, stores indices (32-bit unsigned integers) pointing to the respective codebook entries, plus position, opacity, and other non-clustered data [S1].

**Sensitivity Calculation:**
The sensitivity $S(p)$ of a parameter $p$ is calculated to determine its impact on image quality [S1, S2].
1.  Compute the total image energy $E$, defined as the sum of RGB components over all pixels in all training images [S1, S2].
2.  Compute the sensitivity for parameter $p$ using a single backward pass over the training images:
    $$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p_i}}{\sum_{i=1}^{N} P_i} $$
    where $N$ is the number of training images, $P_i$ is the number of pixels in image $i$, and $E_i$ is the energy contribution of image $i$ [S1, S2].
3.  For a vector $x$ (e.g., a set of SH coefficients or a shape vector), define its sensitivity as the maximum sensitivity over its components $d$:
    $$ S(x) = \max_d S(x_d) $$
    where $S(x_d)$ is the sensitivity of component $d$ [S1].

**Clustering Algorithm:**
The method uses two separate codebooks: one for color (SH coefficients) and one for shape (scale and rotation) [S1].

1.  **Initialization:** Initialize codebook centroids randomly with a uniform distribution within the minimum and maximum values of each parameter [S1]. Set codebook size $K$ (typical value: 4096) [S1].
2.  **Thresholding (Outliers):** Calculate sensitivity for all vectors. Identify vectors with sensitivity higher than a threshold $\beta_c$ (for SH coefficients, typical value: $6 \times 10^{-7}$) or $\beta_g$ (for shape, typical value: $3 \times 10^{-6}$) [S1]. These high-sensitivity vectors are excluded from clustering and added directly to the codebook [S1, S2].
3.  **Batched Clustering:** For the remaining vectors, perform sensitivity-aware k-Means clustering using a batched strategy [S1]:
    *   **Step 3a:** Pick a random subset (batch) of vectors. Typical batch sizes: $2^{18}$ for color features, $2^{20}$ for Gaussian parameters [S1].
    *   **Step 3b:** Compute pairwise weighted distances between vectors $x$ and centroids $c_k$:
        $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
    *   **Step 3c:** Assign each vector $x$ to the centroid $c_k$ with the minimum distance $D(x, c_k)$ [S1]. Let $A(k)$ be the set of vectors assigned to centroid $c_k$ [S1].
    *   **Step 3d:** Update centroids using a moving average with decay factor $\lambda_d$ (typical value: 0.8) [S1]:
        $$ c_k^{new} = (1 - \lambda_d) c_k^{old} + \lambda_d \frac{\sum_{x_i \in A(k)} S(x_i) x_i}{\sum_{x_i \in A(k)} S(x_i)} $$
        *Note: The source formula for the weighted average is $\frac{1}{\sum S(x_i)} \sum S(x_i) x_i$. The moving average update combines this new centroid estimate with the old one.* [S1].
    *   **Step 3e:** For shape parameters, after updating the centroid (which represents a covariance matrix), re-normalize the codebook vector by dividing it through the trace of the covariance metric to counteract floating-point errors that lead to non-unit scaling vectors [S1].
    *   **Step 3f:** Decompose each codebook entry (covariance matrix) into rotation (quaternion) and scale parameters using eigenvalue decomposition [S1].
    *   Repeat Steps 3a-3f for a specified number of update steps (e.g., 800 for Gaussians, 100 for SH coefficients) [S1].

**Quantization-Aware Training (Fine-tuning):**
To recover information lost during clustering, fine-tune the scene parameters on the training set [S1, S2].
1.  **Forward Pass:** Simulate quantization. For each parameter, apply Min-Max Quantization considering a certain number of bits and the moving average of the parameter's min/max values [S2].
2.  **Backward Pass:** Ignore the simulated quantization and calculate the gradient for the parameter without quantization [S2].
3.  **Optimization:** Perform optimization steps (e.g., 5000 steps) using a loss function that may include D-SSIM with weight $\lambda$ (typical value: 0.2) [S1, S2].

**Final Compression:**
1.  Order the Gaussians by their positions along a Z-order curve (Morton order) to exploit spatial coherence [S1, S2].
2.  Compress the set of Gaussians and codebooks using DEFLATE (LZ77 + Huffman coding) [S1, S2].

**Pseudocode:**

import numpy as np

def calculate_sensitivity(training_images, gaussians, parameter_indices):
    """
    Calculate sensitivity S(p) for each parameter p.
    training_images: List of images with known camera params.
    gaussians: List of 3D Gaussians.
    parameter_indices: Indices of parameters to compute sensitivity for.
    Returns: Dictionary mapping parameter index to sensitivity value.
    """
    sensitivities = {}
    total_pixels = sum(img.num_pixels for img in training_images)
    
    # Compute total image energy E (sum of RGB components)
    # This requires rendering the scene with the current Gaussians
    E = compute_total_image_energy(training_images, gaussians)
    
    # Single backward pass to get gradients dE/dp
    # Note: In practice, this is done via automatic differentiation
    gradients = compute_gradients(E, gaussians, parameter_indices)
    
    for p_idx in parameter_indices:
        # S(p) = sum(dE_i/dp_i) / sum(P_i)
        # Assuming gradients are aggregated over all images
        sensitivities[p_idx] = gradients[p_idx] / total_pixels
        
    return sensitivities

def sensitivity_aware_kmeans(vectors, sensitivities, K, lambda_d, batch_size, max_steps):
    """
    Perform sensitivity-aware k-Means clustering.
    vectors: Array of shape (N, D)
    sensitivities: Array of shape (N,) containing S(x) for each vector
    K: Number of centroids
    lambda_d: Decay factor for moving average
    batch_size: Number of vectors per update step
    max_steps: Number of update steps
    Returns: Centroids array of shape (K, D)
    """
    N, D = vectors.shape
    # Initialize centroids randomly within min/max of vectors
    centroids = np.random.uniform(vectors.min(axis=0), vectors.max(axis=0), size=(K, D))
    
    for step in range(max_steps):
        # Pick random subset
        indices = np.random.choice(N, size=min(batch_size, N), replace=False)
        batch_vectors = vectors[indices]
        batch_sensitivities = sensitivities[indices]
        
        # Compute weighted distances
        # D(x, ck) = S(x) * ||x - ck||^2
        # Shape: (batch_size, K)
        distances = np.zeros((len(indices), K))
        for k in range(K):
            diff = batch_vectors - centroids[k]
            distances[:, k] = batch_sensitivities * np.sum(diff**2, axis=1)
            
        # Assign to nearest centroid
        assignments = np.argmin(distances, axis=1)
        
        # Update centroids using moving average
        for k in range(K):
            mask = assignments == k
            if np.sum(mask) > 0:
                assigned_vectors = batch_vectors[mask]
                assigned_sensitivities = batch_sensitivities[mask]
                
                # Weighted average
                sum_s = np.sum(assigned_sensitivities)
                weighted_sum = np.sum(assigned_vectors * assigned_sensitivities[:, np.newaxis], axis=0)
                new_centroid = weighted_sum / sum_s
                
                # Moving average update
                centroids[k] = (1 - lambda_d) * centroids[k] + lambda_d * new_centroid
                
                # Renormalize if shape parameters (covariance matrix)
                # This step is specific to shape parameters
                # centroids[k] = normalize_covariance(centroids[k])
                
    return centroids

def decompose_covariance_matrix(cov_matrix):
    """
    Decompose covariance matrix into rotation (quaternion) and scale.
    cov_matrix: 3x3 symmetric positive definite matrix
    Returns: Quaternion (4,), Scale (3,)
    """
    # Eigenvalue decomposition
    eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)
    
    # Scale is sqrt of eigenvalues
    scale = np.sqrt(eigenvalues)
    
    # Rotation is eigenvectors

def compress_scene(gaussians, sh_codebook, shape_codebook, morton_order_indices):
    """
    Compress the scene data.
    gaussians: List of Gaussian objects
    sh_codebook: Codebook for SH coefficients
    shape_codebook: Codebook for shape parameters
    morton_order_indices: Indices to reorder Gaussians by Z-order
    Returns: Compressed byte stream
    """
    # Reorder Gaussians by Morton order
    ordered_gaussians = [gaussians[i] for i in morton_order_indices]
    
    # Create compressed records
    records = []
    for g in ordered_gaussians:
        # Find index in codebooks
        sh_idx = find_codebook_index(g.sh_coeffs, sh_codebook)

## Operating characteristics
*   **Time Complexity:** The clustering step is iterative k-Means, which is generally $O(I \cdot N \cdot K \cdot D)$ where $I$ is iterations, $N$ is number of vectors, $K$ is codebook size, and $D$ is dimensionality. The batched strategy reduces memory usage but may require more steps to converge. Sensitivity calculation requires a backward pass over training images.
*   **Memory Complexity:** Storage is reduced by a factor of up to 31× on real-world scenes [S1]. The codebooks store $K$ entries instead of $N$ vectors. Indices are 32-bit integers [S1].
*   **Measured Performance:** Achieves compression rates of up to 31× with minimal visual degradation [S1]. Enables rendering at up to 4× higher framerates on lightweight GPUs compared to uncompressed 3DGS [S1].
*   **Strengths:** Preserves high-sensitivity parameters, leading to better visual quality at low bitrates compared to uniform quantization. Efficient rendering on low-end devices.
*   **Limitations:** Requires a sensitivity calculation step (backward pass) which adds to preprocessing time. Clustering is iterative and may not converge to the global optimum.
*   **When to use:** When storage or bandwidth is constrained, and visual quality must be preserved for important features. Suitable for applications like network streaming and low-power devices [S1].
*   **When not to use:** When real-time compression is required during training (it is a post-processing step). When the scene has very few Gaussians and the overhead of codebook management is not justified.

## Background
Sensitivity-Aware Vector Clustering was proposed by Niedemayr et al. in 2024 [S1]. It builds on previous work on volumetric radiance field compression and deep network weight quantization [S1]. The method was introduced to address the high memory consumption of 3D Gaussian Splatting, making it suitable for applications like network streaming and rendering on low-power devices [S1]. It is cited in subsequent works on 3D Gaussian Splatting compression and pruning [S2].
