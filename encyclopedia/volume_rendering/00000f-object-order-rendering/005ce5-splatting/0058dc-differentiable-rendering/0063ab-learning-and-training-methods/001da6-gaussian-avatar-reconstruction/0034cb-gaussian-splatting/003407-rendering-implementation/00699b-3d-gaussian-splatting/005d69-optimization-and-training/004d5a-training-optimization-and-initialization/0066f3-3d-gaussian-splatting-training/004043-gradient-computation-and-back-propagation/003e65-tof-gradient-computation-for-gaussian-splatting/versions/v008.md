# ToF Gradient Computation for Gaussian Splatting

Also called: Opacity gradient for ToF image formation, Recursive gradient for quad pixels

## Overview
This method computes the gradient of the loss function with respect to the opacity parameters of 3D Gaussians specifically for Time-of-Flight (ToF) image formation models, such as those generating phasor or quad pixel signals [S1]. It extends the standard differentiable alpha-compositing gradient used in RGB rendering by introducing recursive accumulation terms that account for the squared transmittance factors inherent in ToF signal models [S1]. Unlike standard color rendering where the gradient depends linearly on transmittance, ToF gradients require a backward pass that squares the transmittance terms, making the computation less trivial and distinct from sibling methods that rely on simple chain rules or intermediate variable optimizations [S1].

## How it works
The method computes the gradient $\frac{\partial L}{\partial \alpha_k}$ for the opacity $\alpha_k$ of the $k$-th Gaussian sorted by depth. The computation relies on a backward recursive pass to accumulate contributions from Gaussians with greater depth (higher index $k$).

### Inputs and Outputs
- **Inputs**:
  - $L$: The scalar loss function.
  - $\frac{\partial L}{\partial \mathbf{q}(\mathbf{x})}$: The gradient of the loss with respect to the rendered ToF signal (e.g., quad pixel signal) at pixel $\mathbf{x}$.
  - $N$: The total number of Gaussians sorted by depth for the pixel.
  - $\alpha_k$: The opacity of the $k$-th Gaussian.
  - $\mathbf{q}_k$: The ToF signal contribution (e.g., quad value) of the $k$-th Gaussian.
  - $T_k$: The transmittance up to the $k$-th Gaussian, defined as $T_k = \prod_{j=1}^{k-1} (1 - \alpha_j)$.
- **Outputs**:
  - $\frac{\partial L}{\partial \alpha_k}$: The gradient of the loss with respect to the opacity of the $k$-th Gaussian.

### Data Structures
The algorithm requires two scalar/vector accumulators for each pixel, initialized to zero before the backward pass:
1. $\text{acc}_k^q$: The accumulated ToF signal contribution from Gaussians $k+1$ to $N$.
2. (Implicit) The transmittance $T_k$ is computed during the forward pass or stored.

### Numbered Steps
1. **Initialize Accumulator**: Set $\text{acc}_{N+1}^q = 0$.
2. **Backward Recursion**: Iterate $k$ from $N$ down to $1$:
   a. Compute the gradient of the signal with respect to opacity using the recursive formula:
      $$ \frac{\partial \mathbf{q}(\mathbf{x})}{\partial \alpha_k} = T_k^2 \left( \mathbf{q}_k + 2(\alpha_k - 1)\text{acc}_k^q \right) $$
   b. Compute the final opacity gradient using the chain rule:
      $$ \frac{\partial L}{\partial \alpha_k} = \frac{\partial L}{\partial \mathbf{q}(\mathbf{x})} \frac{\partial \mathbf{q}(\mathbf{x})}{\partial \alpha_k} $$
   c. Update the accumulator for the next iteration (previous Gaussian in depth order):
      $$ \text{acc}_k^q = \alpha_{k+1} \mathbf{q}_{k+1} + (1 - \alpha_{k+1})^2 \text{acc}_{k+1}^q $$
      *Note: For $k=N$, $\text{acc}_{N+1}^q$ is 0, so $\text{acc}_N^q = \alpha_{N+1} \mathbf{q}_{N+1}$ is not applicable as $N+1$ does not exist. The base case for the accumulator update is handled by the loop structure where the update uses the *next* Gaussian's data. Specifically, the recurrence for $\text{acc}_k^q$ depends on $\text{acc}_{k+1}^q$. The definition in [S1] is:*
      $$ \text{acc}_k^q = \begin{cases} \alpha_{k+1} \mathbf{q}_{k+1} + (1 - \alpha_{k+1})^2 \text{acc}_{k+1}^q, & k < N \\ 0, & k = N \end{cases} $$
      *Correction on Step 2c logic based on [S1] definition:* The accumulator $\text{acc}_k^q$ is defined for index $k$. The recurrence calculates $\text{acc}_k^q$ using values from $k+1$. Therefore, the loop should compute $\text{acc}_k^q$ *after* computing the gradient for $k$, or the gradient for $k$ uses $\text{acc}_k^q$ which was computed in the previous iteration (for $k+1$). Let's align with the standard backward pass pattern:
      
      *Revised Step 2:*
      Initialize $\text{acc}_{N+1}^q = 0$.
      For $k = N$ down to $1$:
      1. Calculate $\frac{\partial \mathbf{q}(\mathbf{x})}{\partial \alpha_k} = T_k^2 (\mathbf{q}_k + 2(\alpha_k - 1)\text{acc}_k^q)$.
         *Wait, the definition of $\text{acc}_k^q$ in [S1] is:*
         $$ \text{acc}_k^q = \begin{cases} \alpha_{k+1} \mathbf{q}_{k+1} + (1 - \alpha_{k+1})^2 \text{acc}_{k+1}^q, & k < N \\ 0, & k = N \end{cases} $$
         This implies $\text{acc}_k^q$ is the accumulation *starting* from $k+1$. So for $k=N$, $\text{acc}_N^q = 0$. For $k=N-1$, $\text{acc}_{N-1}^q = \alpha_N \mathbf{q}_N + (1-\alpha_N)^2 \text{acc}_N^q$.
         
         Therefore, the algorithm is:
         1. Set $\text{acc}_{N+1}^q = 0$.
         2. For $k = N$ down to $1$:
            a. Determine $\text{acc}_k^q$:
               If $k < N$: $\text{acc}_k^q = \alpha_{k+1} \mathbf{q}_{k+1} + (1 - \alpha_{k+1})^2 \text{acc}_{k+1}^q$.
               If $k = N$: $\text{acc}_k^q = 0$.
            b. Compute signal gradient: $\frac{\partial \mathbf{q}(\mathbf{x})}{\partial \alpha_k} = T_k^2 (\mathbf{q}_k + 2(\alpha_k - 1)\text{acc}_k^q)$.
            c. Compute loss gradient: $\frac{\partial L}{\partial \alpha_k} = \frac{\partial L}{\partial \mathbf{q}(\mathbf{x})} \frac{\partial \mathbf{q}(\mathbf{x})}{\partial \alpha_k}$.

### Formulas
1. **Chain Rule**:
   $$ \frac{\partial L}{\partial \alpha_k} = \frac{\partial L}{\partial \mathbf{q}(\mathbf{x})} \frac{\partial \mathbf{q}(\mathbf{x})}{\partial \alpha_k} $$
2. **Signal Gradient**:
   $$ \frac{\partial \mathbf{q}(\mathbf{x})}{\partial \alpha_k} = T_k^2 \left( \mathbf{q}_k + 2(\alpha_k - 1)\text{acc}_k^q \right) $$
3. **Accumulator Recurrence**:
   $$ \text{acc}_k^q = \begin{cases} \alpha_{k+1} \mathbf{q}_{k+1} + (1 - \alpha_{k+1})^2 \text{acc}_{k+1}^q, & k < N \\ 0, & k = N \end{cases} $$

### Parameters
- $T_k$: Transmittance up to Gaussian $k$.
- $\mathbf{q}_k$: Quad contribution of Gaussian $k$.
- $\alpha_k$: Opacity of Gaussian $k$.

### Edge Cases and Pitfalls
- **Squared Transmittance**: The presence of $T_k^2$ in the gradient formula makes the computation distinct from standard RGB rendering, where the factor is $T_k$ [S1]. This increases the sensitivity to depth ordering and opacity values.
- **Recursion Base Case**: The accumulator $\text{acc}_N^q$ must be explicitly initialized to 0. Failure to do so leads to incorrect gradient accumulation for the deepest Gaussian.
- **Precision**: The squared terms $(1-\alpha_{k+1})^2$ can lead to numerical instability if opacities are very close to 1 or 0, though this is inherent to the ToF model [S1].

### Pseudocode
```python
def compute_tof_opacity_gradient(
    grad_loss_signal,  # dL/dq(x), scalar or vector
    q_contributions,   # List of q_k for k=1..N
    alphas,            # List of alpha_k for k=1..N
    transmittances     # List of T_k for k=1..N
):
    """
    Computes dL/d_alpha_k for ToF quad pixel signals.
    Args:
        grad_loss_signal: Gradient of loss w.r.t. rendered signal q(x).
        q_contributions: Array of shape (N,) containing q_k.
        alphas: Array of shape (N,) containing alpha_k.
        transmittances: Array of shape (N,) containing T_k.
    Returns:
        grad_alphas: Array of shape (N,) containing dL/d_alpha_k.
    """
    N = len(alphas)
    grad_alphas = [0.0] * N
    acc_k_q = 0.0  # This will hold acc_{k+1}^q in the loop, initialized to acc_{N+1}^q = 0
    
    # Iterate backwards from N-1 to 0 (indices 0..N-1)
    for k in range(N - 1, -1, -1):
        # k is the current index (0-based)
        # Corresponds to Gaussian k+1 in 1-based indexing from sources
        
        # 1. Compute acc_k^q (accumulation from k+1 onwards)
        # In 1-based indexing: acc_k^q = alpha_{k+1} q_{k+1} + (1-alpha_{k+1})^2 acc_{k+1}^q
        # In 0-based indexing: current k, next is k+1
        # acc_k_q currently holds acc_{k+1}^q from the previous iteration (which was k+1 in 0-based, i.e., k+2 in 1-based)
        # Wait, let's trace carefully.
        # Loop starts at k = N-1 (last Gaussian).
        # acc_k_q is initialized to 0 (acc_{N+1}^q).
        # For k = N-1:
        #   We need acc_{N-1}^q (1-based index N).
        #   Formula: acc_N^q = 0 (base case).
        #   So for the last element, acc is 0.
        
        if k == N - 1:
            acc_current = 0.0
        else:
            # acc_current = alpha_{k+1} * q_{k+1} + (1 - alpha_{k+1})^2 * acc_next
            # In 0-based: next index is k+1
            alpha_next = alphas[k+1]
            q_next = q_contributions[k+1]
            acc_current = alpha_next * q_next + (1.0 - alpha_next)**2 * acc_k_q
            
        # 2. Compute signal gradient d q(x) / d alpha_k
        # Formula: T_k^2 * (q_k + 2*(alpha_k - 1)*acc_k^q)
        T_k = transmittances[k]
        q_k = q_contributions[k]
        alpha_k = alphas[k]
        
        grad_signal = (T_k ** 2) * (q_k + 2.0 * (alpha_k - 1.0) * acc_current)
        
        # 3. Compute loss gradient
        grad_alphas[k] = grad_loss_signal * grad_signal
        
        # 4. Update acc_k_q for the next iteration (which is k-1)
        # The next iteration needs acc_{k-1}^q? No, the next iteration is k-1.
        # It will need acc_{k-1}^q which depends on acc_k^q.
        # So we store acc_current as acc_k_q for the next loop step.
        acc_k_q = acc_current
        
    return grad_alphas
```

## Operating characteristics
- **Time Complexity**: $O(N)$ per pixel for the backward pass, where $N$ is the number of Gaussians. This is comparable to the forward pass but requires an additional recursive accumulator.
- **Memory Complexity**: $O(1)$ additional memory per pixel for the accumulator, assuming transmittances and contributions are available.
- **Strengths**: Enables end-to-end training of 3D Gaussian Splatting models for ToF data, allowing optimization of geometry and appearance based on depth/reflectivity signals.
- **Limitations**: The squared transmittance terms can make gradients more sensitive to noise and numerical precision compared to RGB rendering. The method is specific to ToF signal models (phasor/quad) and does not apply to standard RGB rendering without modification.
- **When to use**: When training 3D Gaussian Splatting models on Time-of-Flight datasets (e.g., depth, quad pixels) and gradients with respect to opacity are required.
- **When not to use**: For standard RGB rendering where the simpler linear transmittance gradient suffices.

## Background
The method was introduced in the context of optimizing depth indirectly in dynamic radiance fields using 3D Gaussian Splatting [S1]. It addresses the gap in differentiable rendering for ToF sensors, where the image formation model involves phasor or quad pixel signals that differ from standard RGB alpha-compositing. The key insight is that the gradient of the ToF signal with respect to opacity involves a recursive accumulation with squared transmittance terms, necessitating a specialized backward pass [S1].
