# Inner 3D Gaussian Splatting
Also called: Inner Gaussian Splatting, InnerGS

## Overview
Inner 3D Gaussian Splatting (InnerGS) is a framework for direct volumetric inference that models continuous volumetric density using 3D Gaussians to reconstruct internal structures from sparse, pose-free sliced data, eliminating the need for camera poses [S1, unofficial]. It solves the problem of internal scene reconstruction where standard 3D Gaussian Splatting fails because learned Gaussians concentrate on the object's surface, leaving the interior volume empty, and because standard rendering relies on camera parameters (view/projection matrices) which are absent in sliced data [S1, unofficial]. It sets itself apart from siblings like [GS-IR](14852-gs-ir.md) by using a slice-based rendering pipeline centered on Conditional Splatting, which dynamically adapts the sampling of Gaussians for each 2D slice, whereas GS-IR typically relies on inverse rendering techniques with explicit camera poses [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Sparse, pose-free sliced data (e.g., medical CT/MRI slices or cross-sections). Each slice provides 2D image data at a specific depth $t$.
*   **Output:** A set of 3D Gaussians representing the internal volumetric density and color, allowing for the reconstruction of smooth and detailed internal structures.

**Data Structures:**
The scene is represented as a cloud of 3D Gaussians. Each Gaussian $i$ is defined by:
*   Mean position $\mu_i = (\mu_{x,i}, \mu_{y,i}, \mu_{z,i}) \in \mathbb{R}^3$.
*   Covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$, decomposed into scaling component $S$ (diagonal matrix with scale factors $s_{x,i}, s_{y,i}, s_{z,i}$) and rotation component $R$ (derived from unit quaternion $q_i$): $\Sigma_i = R_i S_i S_i^\top R_i^\top$.
*   Opacity parameter $\alpha_i$.
*   Spherical Harmonics (SH) coefficients for view-dependent color variations.
*   Color $c_i$ (or SH coefficients from which $c_i$ is derived).

**Method Steps:**
1.  **Conditional Splatting:** For each depth slice $t$, compute conditional 2D Gaussian splats. This determines the 2D Gaussian center and influence radii in the image plane for that specific slice. This step adapts the bounding box per slice based on conditional Gaussians, unlike methods that compute a single cube and project identical bounding boxes across slices [S1, unofficial].
2.  **3D Gaussian Formulation:** Combine the conditional 2D Gaussians with a marginal 1D Gaussian along the depth axis to formulate the complete 3D Gaussian Splatting (3DGS) density. This factorization allows the representation of volumetric density without explicit camera projection matrices [S1, unofficial].
3.  **Tile-based Rasterization:** Perform tile-based rasterization using the formulated 3DGS density. The rendering equation for a pixel at coordinates $(u, v)$ on a slice at depth $t$ is:
    $$ I(u, v, t) = \sum_{i=1}^{N} p_i(u, v, t)\alpha_i c_i \prod_{j=1}^{i-1} (1 - p_j(u, v, t)\alpha_j) $$
    where $p_i(u, v, t)$ is the screen-space density contribution of the $i$-th splat at pixel $(u, v)$ for slice $t$, $\alpha_i$ is the opacity, and $c_i$ is the color. The accumulation is performed front-to-back [S1, unofficial].
4.  **Optimization:** Jointly optimize the parameters ($\mu, \Sigma, \alpha, \text{SH}$) by minimizing a rendering loss between the rendered slices and the input sliced data [S1, unofficial].

    Render internal structures from sparse slices using InnerGS.
    
    Args:
        gaussians: List of 3D Gaussian primitives. Each has:
            - mu: (N, 3) mean positions
            - S: (N, 3) scale factors
            - q: (N, 4) unit quaternions for rotation

            - depth_t: float, depth coordinate of the slice
            - image: (H, W, 3) ground truth RGB image

    Returns:
        rendered_slices: List of rendered (H, W, 3) images.
    """
    rendered_slices = []
    
    for slice_data in slices:

        H, W = gt_image.shape[:2]
        
        # Initialize output buffer

        # Step 1 & 2: Compute Conditional Splatting and 3D Density

        # This involves combining conditional 2D Gaussians with marginal 1D Gaussian.

        effective_gaussians = []

            mu = gaussians[i].mu
            S = gaussians[i].S
            q = gaussians[i].q
            alpha = gaussians[i].alpha
            sh = gaussians[i].sh_coeffs
            
            # Compute the 3D Gaussian density at the slice plane z=t (or appropriate axis)
            # This step adapts the bounding box per slice based on conditional Gaussians [S1, unofficial]
            # The marginal 1D Gaussian along depth is combined with conditional 2D Gaussians [S1, unofficial]
            
            # Calculate the 2D covariance and mean for the slice
            # This is a simplified representation of the factorization
            # In practice, this requires deriving the 2D projection of the 3D Gaussian
            # onto the slice plane, conditioned on the slice depth.
            
            # Let's assume a helper function that computes the 2D splat parameters
            # for a given 3D Gaussian and slice depth t.
            splat_params = compute_conditional_splat(mu, S, q, t)
            
            # splat_params contains:
            # - center_2d: (2,) center in (u, v)
            # - cov_2d: (2, 2) 2D covariance matrix
            # - alpha_slice: float, effective opacity for this slice
            
            if splat_params is not None:
                effective_gaussians.append({
                    'center': splat_params['center_2d'],
                    'cov': splat_params['cov_2d'],
                    'alpha': splat_params['alpha_slice'],
                    'color': sh, # SH coefficients for view-dependent color
                    'mu_3d': mu
                })
        
        # Step 3: Tile-based Rasterization
        # Sort effective Gaussians by depth or some other criterion if necessary
        # For InnerGS, the order is determined by the slice-based pipeline.
        # We assume the effective_gaussians are processed in a consistent order.
        
        # For each pixel, accumulate color from front-to-back
        for y in range(H):
            for x in range(W):
                u, v = pixel_coords[y, x]
                accumulated_color = np.zeros(3)
                accumulated_alpha = 0.0
                
                # Iterate over Gaussians that cover this pixel
                # In practice, use a tile-based approach to only check relevant Gaussians
                for g in effective_gaussians:
                    center = g['center']
                    cov = g['cov']
                    alpha = g['alpha']
                    sh = g['color']
                    
                    # Compute density p_i(u, v, t)
                    # p_i(u, v, t) = exp(-0.5 * (x - mu)^T Sigma^-1 (x - mu))
                    # where x = [u, v], mu = center, Sigma = cov
                    
                    diff = np.array([u - center[0], v - center[1]])
                    try:
                        inv_cov = np.linalg.inv(cov)
                        exponent = -0.5 * diff @ inv_cov @ diff
                        density = np.exp(exponent)
                    except np.linalg.LinAlgError:

                    # View direction is needed for SH evaluation.

                    contribution = density * alpha * color
                    accumulated_color += contribution * transmittance
                    accumulated_alpha += density * alpha * transmittance

    # The 1D Gaussian density along z is proportional to exp(-0.5 * (z - mu_z)^2 / s_z^2)
    # The effective opacity is the integral of this density over the slice thickness.

**Parameters:**
*   Pixel coordinates $(u, v)$ where $u \in [0, W - 1]$ and $v \in [0, H - 1]$ for an image of width $W$ and height $H$ [S1, unofficial].
*   Position vector $\mu = (\mu_x, \mu_y, \mu_z)$ defining the center of each 3D Gaussian [S1, unofficial].
*   Covariance matrix $\Sigma$ decomposed into scaling component $S$ (diagonal matrix with scale factors $s_x, s_y, s_z$) and rotation component $R$ (derived from unit quaternion $q$): $\Sigma = RSS^\top R^\top$ [S1, unofficial].
*   Spherical Harmonics (SH) coefficients used to model view-dependent color variations [S1, unofficial].
*   Opacity parameter $\alpha$ for each 3D Gaussian [S1, unofficial].

**Edge Cases and Pitfalls:**
*   Standard 3DGS projection-based mechanism fails for internal volumetric structures because learned Gaussians concentrate on the object's surface, leaving the interior volume empty, and it relies on camera parameters (view/projection matrices) which are absent in sliced data [S1, unofficial].
*   The method must handle sparse sliced data, which may have gaps between slices. The marginal 1D Gaussian helps interpolate between slices, but performance may degrade with very large gaps.

## Operating characteristics
*   **Time Complexity:** Not given in the sources. However, it uses tile-based rasterization similar to 3DGS, which is generally efficient. The conditional splatting adds overhead per slice.
*   **Memory Complexity:** Not given in the sources. Depends on the number of Gaussians and the number of slices.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Not given in the sources.
*   **Strengths:** Eliminates the need for camera poses; plug-and-play; inherently compatible with any data modalities; enables high-fidelity reconstruction of complex internal structures from sparse, pose-free sliced data [S1, unofficial].
*   **Limitations:** Relies on the assumption that the sliced data is aligned and has a known depth order. Performance may be sensitive to the sparsity of the slices.
*   **When to use:** When reconstructing internal structures from sparse, pose-free sliced data (e.g., medical imaging, cross-sections).
*   **When not to use:** When camera poses are available and the goal is surface reconstruction rather than volumetric internal structure reconstruction.

## Background
Inner 3D Gaussian Splatting (InnerGS) was proposed by Shuxin Liang et al. in the paper "InnerGS: Internal Scenes Reconstruction and Segmentation via Factorized 3D Gaussian Splatting" [S1, unofficial]. It addresses the limitations of standard 3D Gaussian Splatting and NeRF in modeling internal volumetric structures. Standard 3DGS focuses on surface reconstruction and requires camera poses, while NeRF is computationally expensive. InnerGS introduces a novel approach using 3D Gaussian density for direct volumetric inference, leveraging conditional splatting and factorization to handle pose-free sliced data [S1, unofficial].
