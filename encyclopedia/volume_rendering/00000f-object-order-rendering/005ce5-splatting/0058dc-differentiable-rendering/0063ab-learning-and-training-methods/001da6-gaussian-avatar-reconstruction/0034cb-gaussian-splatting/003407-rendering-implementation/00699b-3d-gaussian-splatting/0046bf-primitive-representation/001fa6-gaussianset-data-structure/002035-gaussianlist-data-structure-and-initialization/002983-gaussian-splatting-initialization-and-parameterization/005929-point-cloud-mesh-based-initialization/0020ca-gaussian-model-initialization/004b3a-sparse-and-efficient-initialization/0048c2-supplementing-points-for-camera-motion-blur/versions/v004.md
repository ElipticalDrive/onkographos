# Supplementing Points for Camera Motion Blur

Also called: Adding extra points, Point densification via extent-based calculation

## Overview
This method supplements an initial sparse point cloud with additional 3D Gaussian points to enable the representation of tiny objects and handle camera motion blur, which sparse representations typically fail to model [S1]. It distinguishes itself from standard initialization by dynamically calculating the number of extra points based on the spatial extent of the existing cloud and explicitly interpolating color features for these new points to ensure high-fidelity reconstruction [S1].

## How it works
**Inputs and Outputs**
*   **Input:** An initial set of 3D Gaussian points with positions $\mu_i$.
*   **Output:** An augmented set of 3D Gaussians including the original points and $N_p$ supplementing points with initialized positions, colors, and opacities.

**Data Structures**
The method operates on the existing list of 3D Gaussians. For the supplementing points, the following attributes are initialized:
*   **Position ($\mu$):** Determined by the extent calculation (see below).
*   **Color ($C$):** Interpolated from neighboring points in the original cloud [S1].
*   **Opacity ($\alpha$):** Initialized to a low value, consistent with the shared principles of the parent method [S1].
*   **Scale and Rotation:** Initialized according to standard Gaussian Splatting practices (e.g., small scales, random rotations) [G].

**Algorithm Steps**
1.  **Calculate Extent:** Determine the bounding box of the initial point cloud. Let $Q_{min} \in \mathbb{R}^3$ and $Q_{max} \in \mathbb{R}^3$ be the minimum and maximum coordinates along the x, y, and z axes, respectively.
2.  **Compute Number of Points ($N_p$):** Calculate the number of supplementing points using the formula:
    $$ N_p = \min\left(\frac{\text{prod}(Q_{max} - Q_{min})}{c^3}, N_{max}\right) $$
    Where:
    *   $\text{prod}(\cdot)$ is the product of all elements in the vector $(Q_{max} - Q_{min})$, representing the volume of the bounding box.
    *   $c$ is a stability constant, set to $1.1$ [S1].
    *   $N_{max}$ is the maximum number of points to add, set to $200,000$ [S1].
3.  **Generate Positions:** Distribute $N_p$ new points within the bounding box defined by $Q_{min}$ and $Q_{max}$. The source does not specify the exact spatial distribution strategy (e.g., uniform random, grid-based) for these positions, only that they are added to the cloud [S1].
4.  **Initialize Colors:** For each new point, interpolate its color $C$ from the colors of neighboring points in the original sparse cloud [S1].
    *   *Pitfall:* Randomly initializing color features for added points leads to inferior reconstruction quality compared to interpolation [S1].
5.  **Initialize Other Attributes:** Set opacity $\alpha$ to a low value (e.g., $0.01$–$0.1$) and initialize scale/rotation parameters [G].

**Pseudocode**
```python
def supplement_points_for_motion_blur(initial_gaussians, c=1.1, n_max=200000):
    """
    Supplements the initial point cloud with extra points to handle camera motion blur.
    
    Args:
        initial_gaussians: List of Gaussian objects with 'position' (vec3) and 'color' (vec3).
        c: Stability constant (default 1.1).
        n_max: Maximum number of supplementing points (default 200,000).
        
    Returns:
        augmented_gaussians: List of Gaussian objects including original and new points.
    """
    # Step 1: Calculate Extent
    positions = [g.position for g in initial_gaussians]
    q_min = vec3(min(p.x for p in positions), min(p.y for p in positions), min(p.z for p in positions))
    q_max = vec3(max(p.x for p in positions), max(p.y for p in positions), max(p.z for p in positions))
    
    # Step 2: Compute Number of Points
    # prod(Q_max - Q_min) calculates the volume of the bounding box
    extent_vector = q_max - q_min
    volume = extent_vector.x * extent_vector.y * extent_vector.z
    n_p = min(volume / (c ** 3), n_max)
    
    augmented_gaussians = list(initial_gaussians)
    
    # Step 3 & 4: Generate Positions and Initialize Colors
    # Note: The source does not specify the exact distribution algorithm for the new positions.
    # We assume a uniform random distribution within the bounding box for implementation.
    # Color interpolation is required to avoid inferior quality [S1].
    
    for i in range(int(n_p)):
        # Generate random position within the bounding box
        new_pos = vec3(
            random.uniform(q_min.x, q_max.x),
            random.uniform(q_min.y, q_max.y),
            random.uniform(q_min.z, q_max.z)
        )
        
        # Interpolate color from neighbors [S1]
        # Since the source does not define the interpolation kernel, we use a simple 
        # nearest-neighbor or average of k-nearest neighbors as a standard implementation detail [G].
        new_color = interpolate_color_from_neighbors(new_pos, initial_gaussians)
        
        # Create new Gaussian
        new_gaussian = Gaussian(
            position=new_pos,
            color=new_color,
            opacity=0.05, # Low opacity initialization [G, S1]
            scale=vec3(0.1, 0.1, 0.1), # Small initial scale [G]
            rotation=identity_quaternion() # Random rotation [G]
        )
        augmented_gaussians.append(new_gaussian)
        
    return augmented_gaussians

def interpolate_color_from_neighbors(point, gaussians, k=5):
    """
    Interpolates color from the k-nearest neighbors in the initial cloud.
    This is a standard implementation of the requirement to interpolate colors [S1].
    """
    distances = []
    for g in gaussians:
        dist = vector_length(point - g.position)
        distances.append((dist, g.color))
    
    distances.sort(key=lambda x: x[0])
    neighbors = distances[:k]
    
    # Weighted average based on inverse distance
    total_weight = 0.0
    weighted_color = vec3(0.0, 0.0, 0.0)
    
    for dist, color in neighbors:
        weight = 1.0 / (dist + 1e-6) # Avoid division by zero
        weighted_color += color * weight
        total_weight += weight
        
    return weighted_color / total_weight
```

**Parameters**
*   $c = 1.1$: Stability constant [S1].
*   $N_{max} = 200,000$: Maximum number of supplementing points [S1].

**Edge Cases and Pitfalls**
*   **Sparse Representation Failure:** Directly using a sparse point cloud without densification results in objects being represented by a small number of points or failing to model tiny objects entirely [S1].
*   **Color Initialization:** Randomly initializing color features for added points leads to inferior reconstruction quality compared to interpolating colors from neighboring points [S1].

## Operating characteristics
*   **Complexity:** The calculation of $N_p$ is $O(N)$ where $N$ is the number of initial points (to find min/max). Generating new points is $O(N_p)$. Color interpolation for each new point depends on the neighbor search strategy, typically $O(N \log N)$ or $O(N)$ with spatial hashing.
*   **Performance:** The method improves reconstruction quality for camera motion blur scenes. Quantitative results show that using extra points with interpolated colors yields a PSNR of 23.73 and SSIM of 0.7474, compared to 23.34/0.7374 without extra points and 23.46/0.7411 with randomly colored extra points [S1].
*   **Strengths:** Effectively handles tiny objects and camera motion blur which sparse clouds miss [S1].
*   **Limitations:** Increases the total number of Gaussians, potentially impacting rendering and training time, though the source notes that the overall method remains efficient compared to prior convolution-based works [S1].

## Background
This method was introduced in the paper "Deblurring 3D Gaussian Splatting" by B. Lee et al. [S1]. It addresses the limitation of standard 3D Gaussian Splatting, which struggles to model camera motion blur due to the sparse nature of the initial point cloud representation [S1].
