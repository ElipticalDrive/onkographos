# FineSplat

Also called: Detailed Splats, Fine Patches, Local Groups

## Overview
FineSplat is a feed-forward 3D Gaussian Splatting framework that predicts a set of 3D Gaussians from $N$ context views using a dual-grouping strategy to balance local detail preservation with global multi-view reasoning [S1, unofficial]. It distinguishes itself from sibling methods like [YoNoSplat](15813-sparsplat.md) and [ZipSplat](15813-sparsplat.md) by employing high-resolution 4x4 patch tokens instead of coarser 14x14 patches, combined with a two-stage process that restricts attention scope to avoid the prohibitive cost of global multi-view attention while ensuring fine-grained interactions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ context images $\{I_n\}_{n=1}^N$ with known or predicted camera poses and intrinsics.
*   **Output:** A set of 3D Gaussian primitives $\Theta = \{\mu, s, r, \alpha, c\}$, where $\mu$ is the mean, $s$ is the scale, $r$ is the rotation, $\alpha$ is the opacity, and $c$ is the color.

**Data Structures:**
*   **Tokens:** $M = N \cdot (H/p) \cdot (W/p)$ fine-grained tokens $z^{(0)} \in \mathbb{R}^{M \times d}$, where $p=4$ is the patch size, $H, W$ are image dimensions, and $d$ is the feature dimension.
*   **Gaussians:** $K$ primitives predicted per token. In the default configuration, $K=4$ Gaussians are predicted per 4x4 token, assigned to non-overlapping 2x2 sub-patches.

**Parameters:**
*   $p$: Patch size, set to 4.
*   $T$: Number of Stage 2 refinement steps, set to 4.
*   $s$: Sub-patch stride, set to 2.
*   $S$: Size of groups for serialized attention in 3D spatial grouping (number of consecutive points along the space-filling curve).
*   $N$: Number of input views. Training samples $N \in \{6, 12, 24, 32\}$. Evaluation uses $N \in \{6, 12, 24\}$ on DL3DV, $N=6$ on RE10K, and $N \in \{32, 64, 128\}$ on Mip-NeRF 360.

**Algorithm:**

1.  **Scene Normalization:** To handle scale ambiguity, transform camera poses into the mean context camera frame. Rescale translations so all context camera centers lie within $[-1, 1]^3$ [S1, unofficial]. Apply the same transform to target poses [S1, unofficial].

2.  **Stage 1: View-wise Token Grouping:**
    *   Extract multi-scale features $F^l$ for $l \in \{1, 2, 3\}$ (finest to coarsest) from the input images.
    *   Fuse features into initial tokens $z^{(0)}$ using Equation (1) [S1, unofficial]:
        $$ z^{(0)} = \text{fuse}\left(\text{up}\left(\text{fuse}\left(\text{up}(F^3) + F^2\right)\right)\right) + F^1 $$
        where $\text{up}(\cdot)$ is bilinear upsampling and $\text{fuse}(\cdot)$ is a convolutional fusion block [S1, unofficial].
    *   Encode tokens using view-wise token grouping based on the Multi-View Pyramid (MVP) architecture. This performs fine-grained attention within small view groups and exchanges information across all views via coarser global tokens [S1, unofficial].

3.  **Stage 2: 3D Spatial Token Grouping (Iterative Refinement):**
    *   Initialize current tokens $z = z^{(0)}$.
    *   For $t = 1$ to $T$:
        1.  **Gaussian Prediction:** Decode tokens $z$ into an initial set of Gaussians using a lightweight Gaussian head $\mathcal{D}$ (linear decoder). Each token predicts $K$ Gaussians [S1, unofficial].
        2.  **Patch-Aligned Sub-Pixel Gaussian Reconstruction:** For each 4x4 token, predict 4 Gaussians assigned to four non-overlapping 2x2 sub-patches. Learn a 2D image-space offset $\Delta = (\Delta_x, \Delta_y)$ for each Gaussian [S1, unofficial].
            *   Compute bounded offsets:
                $$ \delta_x = 2s \tanh(\Delta_x), \quad \delta_y = 2s \tanh(\Delta_y) $$
                where $s=2$. This ensures $\delta_x, \delta_y \in [-s/2, s/2]$, keeping Gaussians within their 2x2 sub-patch [S1, unofficial].
            *   For a sub-patch with center $(u_c, v_c)$, compute displaced coordinate $(u, v) = (u_c, v_c) + (\delta_x, \delta_y)$ [S1, unofficial].
            *   Unproject $(u, v)$ using predicted camera intrinsics to get a ray direction. Transform and normalize this direction using camera-to-world rotation, using camera translation as ray origin to determine $\mu$ [S1, unofficial].
        3.  **Rendering and Error Computation:** Render the predicted Gaussians into every context view $n$ to obtain rendered images $\hat{I}_n$. Compute the signed pixel error map $E_n = \hat{I}_n - I_n$ [S1, unofficial].
        4.  **Feature-Level Difference:** Compute feature-level difference $\Delta\phi_n = \phi(\hat{I}_n) - \phi(I_n)$ using a pretrained ResNet-18 encoder $\phi(\cdot)$ [S1, unofficial].
        5.  **Error Feature Map Construction:** Combine pixel errors, feature differences, and finest-scale features $F_n^1$ from Stage 1 via linear embeddings $E_{\text{err}}$ and $E_{\text{feat}}$ [S1, unofficial]:
            $$ F_n^{\text{err}} = [E_{\text{err}}(E_n, \Delta\phi_n); E_{\text{feat}}(F_n^1)] \in \mathbb{R}^{(H/p) \times (W/p) \times d_e} $$
            where $[\cdot; \cdot]$ denotes concatenation [S1, unofficial].
        6.  **Error Aggregation:** For each token, gather two error signals:
            *   $e_{\text{self}}$: Self error feature from the patch where the token is predicted.
            *   $e_{\text{agg}}$: Aggregated error feature averaged over all context views where the token is visible (projected onto error feature maps and filtered by frustum/occlusion) [S1, unofficial].
        7.  **3D Spatial Grouping:** Lift tokens to 3D space using their predicted Gaussian centers. Regroup tokens based on spatial proximity using serialized attention [S1, unofficial].
            *   Order points along a space-filling curve.
            *   Partition into groups of $S$ consecutive points.
            *   Apply self-attention within each group.
            *   Use four attention blocks, each using a different space-filling curve, so each token meets a different set of neighbors [S1, unofficial].
            *   Update tokens:
                $$ \Delta z_j^{(i)} = \text{Linear}(\text{SerialAttn}(h_j^{(i)})) $$
                $$ z_j^{(i+1)} = z_j^{(i)} + \Delta z_j^{(i)} $$
                where $h_j^{(i)}$ are the features augmented with error signals $e_{\text{self}}$ and $e_{\text{agg}}$ [S1, unofficial].

4.  **Final Output:** After $T$ steps, decode the final tokens into the final set of Gaussians [S1, unofficial].

**Pseudocode:**

```python
def finesplat(context_images, context_poses, context_intrinsics, N, p=4, T=4, s=2):
    """
    context_images: List of N images [H, W, 3]
    context_poses: List of N camera-to-world poses [4, 4]
    context_intrinsics: List of N intrinsic matrices [3, 3]
    """
    # 1. Scene Normalization
    mean_pose = compute_mean_pose(context_poses)
    scale_transform = compute_scale_transform(context_poses, mean_pose, target_range=(-1, 1))
    normalized_poses = [apply_transform(pose, scale_transform) for pose in context_poses]
    
    # 2. Stage 1: View-wise Token Grouping
    # Extract multi-scale features F^1, F^2, F^3
    features = extract_multi_scale_features(context_images)
    F1, F2, F3 = features[0], features[1], features[2]
    
    # Fuse into initial tokens z^(0)
    # up() is bilinear upsampling, fuse() is conv fusion block
    fused_coarse = fuse(bilinear_upsample(fuse(bilinear_upsample(F3) + F2)))
    z0 = fuse(fused_coarse) + F1
    # Reshape z0 into M tokens, M = N * (H/p) * (W/p)
    tokens = reshape_to_tokens(z0, p)
    
    # MVP-based view-wise grouping and attention
    tokens = multi_view_pyramid_attention(tokens, context_poses, p)
    
    # 3. Stage 2: 3D Spatial Token Grouping
    current_tokens = tokens
    for t in range(T):
        # Decode Gaussians
        gaussians = gaussian_head_decode(current_tokens)
        
        # Render to all context views
        rendered_images = []
        for n in range(N):
            # Differentiable rasterization
            img = render_gaussians(gaussians, normalized_poses[n], context_intrinsics[n])
            rendered_images.append(img)
            
        # Compute Error Features
        error_features = []
        for n in range(N):
            I_n = context_images[n]
            I_hat_n = rendered_images[n]
            
            # Pixel error
            E_n = I_hat_n - I_n
            
            # Feature difference using pretrained ResNet-18 phi
            phi = pretrained_resnet18()
            delta_phi_n = phi(I_hat_n) - phi(I_n)
            
            # Get finest scale features for view n (from Stage 1 features)
            F1_n = get_feature_for_view(F1, n, p)
            
            # Linear embeddings
            E_err_emb = linear_embed(E_n, delta_phi_n)
            E_feat_emb = linear_embed(F1_n)
            
            # Concatenate
            F_err_n = concatenate(E_err_emb, E_feat_emb)
            error_features.append(F_err_n)
            
        # Aggregate errors for each token
        token_error_signals = []
        for token_idx, token in enumerate(current_tokens):
            # Get 3D position of token's primary Gaussian
            pos_3d = get_token_3d_position(token, gaussians)
            
            e_self = get_self_error(token_idx, error_features)
            e_agg = aggregate_visible_errors(pos_3d, error_features, normalized_poses, context_intrinsics)
            
            token_error_signals.append((e_self, e_agg))
            
        # 3D Spatial Grouping with Serialized Attention
        # Lift tokens to 3D
        token_positions = [get_token_3d_position(t, gaussians) for t in current_tokens]
        
        # Order along space-filling curve
        ordered_indices = sort_by_space_filling_curve(token_positions)
        ordered_tokens = [current_tokens[i] for i in ordered_indices]
        ordered_errors = [token_error_signals[i] for i in ordered_indices]
        
        # Group into windows of size S
        # Use 4 different space-filling curves in 4 attention blocks
        updated_tokens = []
        for block_idx in range(4):
            curve = get_space_filling_curve(block_idx)
            # Re-order based on this curve
            curve_indices = sort_by_curve(token_positions, curve)
            curve_tokens = [current_tokens[i] for i in curve_indices]
            curve_errors = [token_error_signals[i] for i in curve_indices]
            
            # Group consecutive S points
            groups = group_consecutive(curve_tokens, curve_errors, S)
            
            # Apply serialized attention within groups
            new_curve_tokens = []
            for group_tokens, group_errors in groups:
                # Augment features with errors
                augmented = augment_with_errors(group_tokens, group_errors)
                # Self-attention
                attended = self_attention(augmented)
                # Linear projection to residual
                residual = linear_layer(attended)
                # Update
                updated_group = group_tokens + residual
                new_curve_tokens.extend(updated_group)
            
            # Map back to original order
            # (Simplified: assume we update current_tokens in place based on block logic)
            # In practice, this updates the token features
            current_tokens = map_back_to_original_order(new_curve_tokens, curve_indices)
            
        # Decode updated tokens for next iteration (or final output)
        # The loop continues with updated current_tokens
        
    # Final decoding
    final_gaussians = gaussian_head_decode(current_tokens)
    return final_gaussians
```

**Edge Cases and Pitfalls:**
*   **Blind Spots:** Fixed view grouping in Stage 1 leaves blind spots where fine-grained tokens in different groups cannot interact. Stage 2's 3D spatial grouping connects these tokens once lifted to 3D [S1, unofficial].
*   **Scale Ambiguity:** Feed-forward reconstruction is scale-ambiguous. Normalization using context camera poses is required [S1, unofficial].
*   **Precision:** The bounded offset formula $\delta = 2s \tanh(\Delta)$ ensures Gaussians stay within sub-patches, preventing invalid projections [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** FineSplat is efficient due to the dual-grouping strategy. Stage 1 uses local view-wise attention, and Stage 2 uses serialized 3D attention, avoiding global multi-view attention costs [S1, unofficial]. It is faster than YoNoSplat and ZipSplat with 6 and 12 input views, and still faster than ZipSplat with 24 views [S1, unofficial].
*   **Memory Complexity:** Uses 62K Gaussians for DL3DV (6 views), 75K for RE10K (6 views), and 1.6M for Mip-NeRF 360 (128 views) [S1, unofficial].
*   **Performance:**
    *   DL3DV (6 views): 27.325 PSNR, 0.871 SSIM, 0.115 LPIPS [S1, unofficial].
    *   RE10K (6 views): 27.394 PSNR, 0.886 SSIM, 0.116 LPIPS [S1, unofficial].
    *   Mip-NeRF 360 (128 views): 23.463 PSNR, 0.706 SSIM, 0.214 LPIPS [S1, unofficial].
*   **Strengths:** High quality with small primitive budget; fine-grained detail preservation; efficient compared to global attention methods.
*   **Limitations:** Quality may degrade with very large scenes if tokens observing the same surface are separated into different view groups, though Stage 2 compensates for this [S1, unofficial].

## Background
FineSplat was introduced in 2026 by Xu et al. [S1, unofficial]. It is trained on the DL3DV dataset and evaluated on DL3DV, RealEstate10K, and Mip-NeRF 360 for novel view synthesis [S1, unofficial]. It builds on the principles of feed-forward 3D Gaussian Splatting, replacing iterative optimization with a neural network that maps input images to Gaussian parameters [15832-feed-forward-and-generalizable-prediction.md].
