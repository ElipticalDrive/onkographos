# 3D Half-Gaussian Splatting Covariance Transformation and Regularization

Also called: 3D-HGS

## Overview
This method regularizes the covariance matrices of 3D Gaussians to enforce a "half-Gaussian" geometry, effectively modeling sharp transitions between object surfaces and empty space [S1]. It transforms the covariance into a local basis aligned with the surface normal, projects the ellipsoid onto the tangent plane, and reconstructs a flattened covariance that penalizes thickness along the normal direction [S1]. Unlike standard 3D Gaussian Splatting which uses full ellipsoids, this approach explicitly constrains the shape to be thin, improving geometric fidelity and reducing noise artifacts like "dust" [S1].

## How it works
The method operates on the covariance matrix $\Sigma$ of each Gaussian kernel. It assumes access to a surface normal vector $n$ for each Gaussian, typically derived from depth estimation or gradient-based surface reconstruction during training [S1]. The transformation is applied periodically rather than every iteration to stabilize optimization [S1].

### Inputs and Outputs
- **Input**: Original covariance matrix $\Sigma \in \mathbb{R}^{3 \times 3}$ (symmetric positive definite), surface normal vector $n \in \mathbb{R}^3$.
- **Output**: Regularized covariance matrix $\sigma \in \mathbb{R}^{3 \times 3}$.

### Data Structures
The covariance matrix is stored as a $3 \times 3$ symmetric matrix. In implementation, this is often represented by 6 unique values or a full $3 \times 3$ matrix for ease of linear algebra operations. The basis matrix is a $3 \times 3$ orthogonal matrix.

### Parameters
- **Iteration Interval**: The transformation is applied every 5000 iterations [S1].
- **Opacity Thresholds**:
  - Densification/Pruning threshold increased to 0.01 [S1].
  - Initial opacity for half-Gaussians reset to 0.02 [S1].
- **Flattening Factor**: The diagonal element along the normal is scaled by $1/100$ [S1].

### Algorithm Steps

1.  **Normalize Normal**: Normalize the input normal vector $n$ to unit length:
    $$ n \leftarrow \frac{n}{\|n\|} $$

2.  **Construct Basis**: Create an orthonormal basis $\{v_1, v_2, n\}$ where $v_1$ and $v_2$ span the tangent plane perpendicular to $n$.
    - If $n_x = 0$ and $n_y = 0$ (i.e., $n$ is parallel to the z-axis):
      $$ v_1 = (1, 0, 0) $$
      $$ v_2 = (0, 1, 0) $$
    - Otherwise:
      $$ v_1 = \frac{(n_y, -n_x, 0)}{\|(n_y, -n_x, 0)\|} $$
      $$ v_2 = \frac{n \times v_1}{\|n \times v_1\|} $$
    - Construct the basis matrix $B$ by concatenating these vectors as columns:
      $$ B = [v_1, v_2, n] $$

3.  **Transform to Basis Space**: Project the original covariance $\Sigma$ into the local basis coordinate system:
    $$ \text{cov} = B^T \Sigma B $$
    Here, $\text{cov}$ is a $3 \times 3$ matrix representing the covariance in the $(v_1, v_2, n)$ frame.

4.  **Compute Modified Diagonal/Off-Diagonal Terms**: Calculate the Schur complement-like terms for the tangent plane components, effectively removing the variance coupled with the normal direction.
    $$ a' = \text{cov}[0, 0] - \frac{\text{cov}[0, 2]^2}{\text{cov}[2, 2]} $$
    $$ b' = \text{cov}[0, 1] - \frac{\text{cov}[0, 2] \cdot \text{cov}[1, 2]}{\text{cov}[2, 2]} $$
    $$ c' = \text{cov}[1, 1] - \frac{\text{cov}[1, 2]^2}{\text{cov}[2, 2]} $$
    *Note*: $\text{cov}[2, 2]$ represents the variance along the normal direction. Division by zero is a potential pitfall if the Gaussian has zero thickness along the normal initially; a small epsilon should be added to the denominator [G].

5.  **Construct Regularized Covariance in Basis Space**: Build the new covariance matrix $\sigma_{\text{local}}$ in the basis frame. The top-left $2 \times 2$ block contains the modified tangent-plane statistics. The off-diagonal terms connecting the tangent plane to the normal are set to zero. The normal-direction variance is set to a small fraction of the minimum tangent variance to enforce flatness.
    $$ \sigma_{\text{local}} = \begin{bmatrix} a' & b' & 0 \\ b' & c' & 0 \\ 0 & 0 & \frac{\min(a', c')}{100} \end{bmatrix} $$

6.  **Transform Back to World Space**: Map the regularized covariance back to the world coordinate system:
    $$ \sigma = B \sigma_{\text{local}} B^T $$

### Pseudocode

```python
import numpy as np

def regularize_covariance(cov: np.ndarray, normal: np.ndarray) -> np.ndarray:
    """
    Transforms covariance matrix into a half-Gaussian shape aligned with the normal.
    
    Args:
        cov: 3x3 symmetric covariance matrix Sigma.
        normal: 3D normal vector n.
        
    Returns:
        Regularized 3x3 covariance matrix sigma.
    """
    # 1. Normalize normal
    n = normal / np.linalg.norm(normal)
    
    # 2. Construct basis
    # Check if normal is parallel to Z axis
    if np.isclose(n[0], 0.0) and np.isclose(n[1], 0.0):
        v1 = np.array([1.0, 0.0, 0.0])
        v2 = np.array([0.0, 1.0, 0.0])
    else:
        # v1 is perpendicular to n and lies in XY plane
        v1 = np.array([n[1], -n[0], 0.0])
        v1 = v1 / np.linalg.norm(v1)
        # v2 is perpendicular to both n and v1
        v2 = np.cross(n, v1)
        v2 = v2 / np.linalg.norm(v2)
        
    # Basis matrix B = [v1, v2, n]
    B = np.column_stack((v1, v2, n))
    
    # 3. Transform to basis space
    cov_local = B.T @ cov @ B
    
    # 4. Compute modified terms
    # Add small epsilon to denominator to prevent division by zero [G]
    epsilon = 1e-8
    cov_22 = cov_local[2, 2] + epsilon
    
    a_prime = cov_local[0, 0] - (cov_local[0, 2]**2) / cov_22
    b_prime = cov_local[0, 1] - (cov_local[0, 2] * cov_local[1, 2]) / cov_22
    c_prime = cov_local[1, 1] - (cov_local[1, 2]**2) / cov_22
    
    # 5. Construct regularized covariance in basis space
    # The normal variance is set to min(a', c') / 100
    min_tangent_var = min(a_prime, c_prime)
    sigma_local = np.array([
        [a_prime, b_prime, 0.0],
        [b_prime, c_prime, 0.0],
        [0.0, 0.0, min_tangent_var / 100.0]
    ])
    
    # 6. Transform back to world space
    sigma = B @ sigma_local @ B.T
    
    return sigma
```

### Edge Cases and Pitfalls
- **Zero Normal Variance**: If $\text{cov}[2, 2]$ is zero or near-zero, the division in step 4 will fail. A small epsilon should be added to the denominator [G].
- **Degenerate Normals**: If the normal vector is not unit length, the basis construction will be skewed. Normalization is mandatory [S1].
- **Frequency of Application**: Applying this transformation every iteration may destabilize training. The sources specify applying it every 5000 iterations [S1].
- **Opacity Management**: To prevent noise accumulation, the opacity threshold for pruning/densification is raised to 0.01, and half-Gaussian opacity is initialized to 0.02 [S1].

## Operating characteristics
- **Time Complexity**: The transformation involves matrix multiplications ($3 \times 3$) and vector operations, which are $O(1)$ per Gaussian. However, it is applied only every 5000 iterations, minimizing the overhead per frame [S1].
- **Memory Complexity**: No additional memory structures are required beyond the existing Gaussian attributes [S1].
- **Performance**:
  - On Mip-NeRF 360: 125 FPS with Efficient Rasterizer, 29.66 PSNR, using 3.8M kernels (vs 3.2M for 3DGS) [S1].
  - On Tank & Dengin: 160 FPS with Efficient Rasterizer, 24.45 PSNR, using 1.8M kernels (vs 1.0M for 3DGS) [S1].
  - On Tank & Blending: 126 FPS with Efficient Rasterizer, 29.76 PSNR, using 2.6M kernels (vs 3.0M for 3DGS) [S1].
- **Strengths**: Consistently outperforms original 3D Gaussian Splatting in PSNR and other metrics across evaluated datasets [S1]. Effectively models sharp surface transitions and reduces noise/dust [S1].
- **Limitations**: Requires more kernels than standard 3DGS to achieve comparable or better results, potentially increasing memory usage [S1]. The method relies on accurate surface normals; poor normal estimates may lead to incorrect regularization [S1].

## Background
The method was introduced in the paper "3D-HGS: 3D Half-Gaussian Splatting" [S1]. It extends the 3D Gaussian Splatting framework by incorporating half-Gaussian kernels, which are ellipsoids cut by a plane, to better represent surfaces. The covariance transformation and regularization are key components of this approach, ensuring that the Gaussians remain thin and aligned with the surface geometry. The method has been evaluated against Scaffold, mip-splatting, and MCMC architectures [S1].
