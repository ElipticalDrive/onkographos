# Adaptive Densification

Also called: Adaptive Density Control (ADC), Cloning and Splitting, Gaussian Cloning, Splitting, and Pruning, Gradient-based densification, Original Densification

## Overview
Adaptive Densification is a mechanism that dynamically adjusts the number, position, and scale of 3D Gaussian primitives during optimization to improve reconstruction quality [S4]. It addresses the fundamental limitation of standard gradient descent, which can only move, stretch, or fade existing Gaussians but cannot create new ones in empty regions or cleanly remove useless ones [S2, unofficial]. By periodically inspecting view-space positional gradients, the method identifies under-reconstructed regions (requiring cloning) and over-reconstructed regions (requiring splitting), thereby allowing model capacity to follow image error [S2, unofficial]. It is distinguished from sibling methods like [OTS+SAtn Densification](1488-ots-satn-densification.md) by its reliance on raw positional gradient magnitudes rather than opacity-weighted or attention-guided metrics, and from [Fixed-Pool Relocation](3094-fixed-pool-relocation.md) by its ability to increase the total primitive count rather than maintaining a fixed budget.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Current Gaussian parameters (means $\mu$, standard deviations/scales $\sigma$, intensities/opacities $I$), accumulated view-space positional gradients $\nabla_{\mu} \mathcal{L}$, current iteration count, and hyperparameters $\tau$ (gradient threshold), $\theta$ (size threshold), $N_{max}$ (max primitive count), and $size$ (box size for pruning) [S4].
*   **Outputs:** Updated arrays of Gaussian parameters $\mu, \sigma, I$ with modified counts [S4].

**Data Structures:**
Gaussians are stored in parallel arrays or a single struct array:
*   $\mu \in \mathbb{R}^{N \times 3}$: Mean positions.
*   $\sigma \in \mathbb{R}^{N \times 3}$ or $\mathbb{R}^{N}$: Scales (standard deviations). In the source algorithm, $\sigma$ is treated as a scalar or per-dimension magnitude for thresholding [S4].
*   $I \in \mathbb{R}^{N}$: Intensity or opacity.
*   $\nabla_{\mu} \mathcal{L} \in \mathbb{R}^{N}$: Accumulated gradient magnitudes.

**Parameters:**
*   $\tau$: Gradient threshold for densification consideration. Default: $2 \times 10^{-4}$ [S4]. Range: $1.5 \times 10^{-4}$ to $2 \times 10^{-4}$ [S2, S5, unofficial].
*   $\theta$: Size threshold distinguishing small from large Gaussians. Default: $0.005$ of the scene's body diagonal [S4].
*   $N_{max}$: Maximum primitive count. Default: $500,000$ [S4]. Range: $100k$ to $5M$ [S2, unofficial].
*   $size$: Box size for pruning criteria. Default: $17$ [S4].
*   $\tau_{opac}$: Opacity threshold for pruning. Default: $0.005$ [S5, unofficial].

**Numbered Steps:**
1.  **Schedule:** Execute densification periodically every $K=100$ iterations, starting from iteration $100$ up to the maximum iteration count [S4].
2.  **Gradient Normalization:** Calculate the average gradient magnitude for each Gaussian:
    $$ \text{avg\_grad}_i = \frac{\|\nabla_{\mu_i} \mathcal{L}\|}{\text{iteration}} $$
    [S4]. Note: Gradients are accumulated as magnitudes to prevent cancellation from opposite directions across views [S2, unofficial].
3.  **Cloning (Under-reconstructed regions):**
    *   Identify candidates where $\text{avg\_grad}_i \ge \tau$ AND $\sigma_i \le \theta$ [S4].
    *   Calculate available slots: $N_{avail} = N_{max} - N_{current}$ [S4].
    *   Select up to $N_{avail}$ candidates with the highest $\text{avg\_grad}$ [S4].
    *   For each selected Gaussian $i$:
        *   Create a clone $G_{clone}$ at $\mu_{clone} = \mu_i$ with $\sigma_{clone} = \sigma_i$ [S4].
        *   Set intensity $I_{clone} = I_i / 2$ to preserve energy [S4].
        *   Detach gradients for the clone (set to zero) [S4].
        *   Append clone to the Gaussian list. Increment $N$ [S4].
4.  **Splitting (Over-reconstructed regions):**
    *   Identify candidates where $\text{avg\_grad}_i \ge \tau$ AND $\sigma_i > \theta$ [S4].
    *   Recalculate $N_{avail} = N_{max} - N_{current}$ [S4].
    *   Select up to $N_{avail}$ candidates with the highest $\text{avg\_grad}$ [S4].
    *   For each selected Gaussian $i$:
        *   Remove original $G_i$ from the list [S4].
        *   Generate two new Gaussians $G_{new1}, G_{new2}$.
        *   Sample positions $\mu_{new}$ from the probability density function (PDF) of the original Gaussian $G_i$ [S4]. [G: In practice, this is often implemented by sampling from a normal distribution $\mathcal{N}(\mu_i, \Sigma_i)$].
        *   Update scales: $\sigma_{new} = \sigma_i / (\sqrt{3}/2)$ [S4]. This factor maintains the total volume/extent of the two children relative to the parent.
        *   Distribute intensity: $I_{new} = I_i$ (distributed between the two, typically halved each, though the source algorithm assigns $I_{new} = I_{masksplit}$ implying the sum or individual assignment needs clarification; standard 3DGS halves opacity) [S4][S2, unofficial].
        *   Append new Gaussians. Increment $N$ by 1 for each split (net +1 per split) [S4].
5.  **Pruning:**
    *   Identify Gaussians to remove where $\text{avg\_grad}_i \le \tau$ OR $\sigma_i > 3 \times size$ [S4]. [G: The original 3DGS paper also prunes based on opacity $\alpha < 0.005$; this variant uses gradient and size, but opacity pruning is a common sibling/variant feature [S5, unofficial]].
    *   Filter out pruned Gaussians from $\mu, \sigma, I$ arrays [S4].
    *   [G: Some implementations periodically reset all opacities to a low value to force floating artifacts to vanish [S5, unofficial]].

**Pseudocode:**
```python
def adaptive_densification(mu, sigma, intensity, grad_accum, iteration, n_max, tau, theta, size):
    """
    mu: array of shape (N, 3)
    sigma: array of shape (N,) or (N, 3) representing scale magnitude
    intensity: array of shape (N,)
    grad_accum: array of shape (N,) accumulated gradient magnitudes
    iteration: current training iteration
    n_max: max number of gaussians
    tau: gradient threshold
    theta: size threshold
    size: box size for pruning
    """
    n = len(mu)
    if iteration < 100 or iteration % 100 != 0:
        return mu, sigma, intensity

    # 1. Calculate average gradient
    avg_grad = grad_accum / iteration
    
    # 2. Cloning
    # Criteria: High gradient AND small size
    mask_clone = (avg_grad >= tau) & (sigma <= theta)
    available = n_max - n
    n_clone_candidates = np.sum(mask_clone)
    n_clone = min(available, n_clone_candidates)
    
    if n_clone > 0:
        # Select top n_clone by gradient
        clone_indices = np.where(mask_clone)[0]
        sorted_indices = clone_indices[np.argsort(avg_grad[clone_indices])[::-1]]
        top_clone_indices = sorted_indices[:n_clone]
        
        # Create clones
        mu_clone = mu[top_clone_indices].copy()
        sigma_clone = sigma[top_clone_indices].copy()
        intensity_clone = intensity[top_clone_indices] / 2.0
        
        # Append
        mu = np.concatenate([mu, mu_clone], axis=0)
        sigma = np.concatenate([sigma, sigma_clone], axis=0)
        intensity = np.concatenate([intensity, intensity_clone], axis=0)
        n += n_clone

    # 3. Splitting
    # Criteria: High gradient AND large size
    mask_split = (avg_grad >= tau) & (sigma > theta)
    available = n_max - n
    n_split_candidates = np.sum(mask_split)
    n_split = min(available, n_split_candidates)
    
    if n_split > 0:
        # Select top n_split by gradient
        split_indices = np.where(mask_split)[0]
        sorted_indices = split_indices[np.argsort(avg_grad[split_indices])[::-1]]
        top_split_indices = sorted_indices[:n_split]
        
        # Remove originals
        keep_mask = np.ones(n, dtype=bool)
        keep_mask[top_split_indices] = False
        mu = mu[keep_mask]
        sigma = sigma[keep_mask]
        intensity = intensity[keep_mask]
        n -= n_split
        
        # Create new split gaussians
        # Sample positions from original PDF
        mu_new = sample_from_gaussian_pdf(mu[top_split_indices], sigma[top_split_indices], count=2)
        
        # Update scales: divide by sqrt(3)/2
        sigma_new = sigma[top_split_indices] / (np.sqrt(3) / 2.0)
        # Repeat for two children
        sigma_new = np.repeat(sigma_new, 2)
        
        # Intensity: Source says Inew = I[masksplit]. Standard practice is halving.
        # We assume distribution to maintain energy.
        intensity_new = intensity[top_split_indices] / 2.0
        intensity_new = np.repeat(intensity_new, 2)
        
        # Append
        mu = np.concatenate([mu, mu_new], axis=0)
        sigma = np.concatenate([sigma, sigma_new], axis=0)
        intensity = np.concatenate([intensity, intensity_new], axis=0)
        n += n_split * 2 # Each split adds 1 net gaussian (2 new - 1 old)

    # 4. Pruning
    # Criteria: Low gradient OR excessive size
    mask_prune = (avg_grad <= tau) | (sigma > 3 * size)
    
    # Optional: Opacity pruning (common in ADC, though not in the specific Algorithm 2 source)
    # mask_prune = mask_prune | (intensity < 0.005)
    
    mu = mu[~mask_prune]
    sigma = sigma[~mask_prune]
    intensity = intensity[~mask_prune]
    
    return mu, sigma, intensity
```

## Subtopics

### [Fixed-Pool Relocation](3094-fixed-pool-relocation.md)
[3094-fixed-pool-relocation.md]: A strategy that redistributes a fixed budget of splats to areas of high reconstruction error without increasing the total component count. It identifies low-importance splats and moves them to local maxima of the positive reconstruction residual. Unlike Adaptive Densification, which increases the Gaussian count via cloning and splitting, Fixed-Pool Relocation maintains a constant budget by recycling existing components, making it suitable for memory-constrained environments.

### [Blind-Spot Cross-Validation](3102-blind-spot-cross-validation.md)
[3102-blind-spot-cross-validation.md]: A model selection procedure that determines the optimal number of Gaussians (splat budget) for a 3D Gaussian Splatting reconstruction without requiring noise-free ground truth references. It identifies the point of diminishing returns where additional splats begin to memorize noise rather than signal by monitoring the divergence between training and held-out PSNR metrics.

### [Density-Aware Densification (Splitting Surfels)](4514-density-aware-densification-splitting-surfels.md)
[4514-density-aware-densification-splitting-surfels.md]: A mechanism for surfel densification that uses a density-aware splitting criterion based on local inter-sample spacing and a screen-space gradient accumulation strategy based on T-matrix backward passes. It replaces the ad-hoc projected 3D position gradient used in 2DGS with screen-space gradients and replaces the global scale threshold with a criterion that adapts to spatially varying overlap conditions.

### [Temporal Densification](9531-temporal-densification.md)
[9531-temporal-densification.md]: A strategy that detects and resolves reconstruction errors caused by object or camera motion by splitting Gaussians based on the variance of their normalized image error across time segments. It addresses the limitation of static spatial densification by identifying Gaussians whose error fluctuates significantly between keyframes.

### Density-preserving Splitting
A variant that discards cloning operations and relies only on splitting operations to avoid loss function perturbations caused by cloning [S6]. It modifies the splitting operation to be performed along the longest principal axis, shifting means by $\pm \alpha \sigma$ (where $\alpha=0.3$) and adjusting sizes and opacity to ensure the resulting density of the sum of the two children is close to the density of the mother Gaussian [S6].

## Operating characteristics
*   **Time Complexity:** Densification is executed every $K$ iterations (typically 100). The sorting step for selecting top candidates is $O(N \log N)$, where $N$ is the number of Gaussians. Cloning and splitting are $O(N_{ops})$ where $N_{ops}$ is the number of modified primitives. Overall, it adds a small overhead per step relative to the rendering and gradient computation cost.
*   **Memory Complexity:** The number of Gaussians $N$ grows over time, bounded by $N_{max}$. Memory usage scales linearly with $N$.
*   **Performance:** The method effectively captures fine details (via cloning) and resolves blurry regions (via splitting) [S2, unofficial]. Ablation studies show that disabling splitting leads to blurry backgrounds, while disabling cloning leads to loss of thin structures like bicycle spokes [S2, unofficial].
*   **Strengths:** Simple to implement; adapts density to scene complexity; no need for manual tuning of density grids.
*   **Limitations:** Can lead to unbounded growth if $N_{max}$ is not set; gradient cancellation issues can occur if raw vectors are accumulated instead of magnitudes [S2, unofficial]; cloning can introduce artifacts if not handled carefully (e.g., intensity halving) [S6].
*   **When to use:** Standard 3D Gaussian Splatting training where scene complexity varies and a fixed initialization is insufficient.
*   **When not to use:** Memory-constrained environments requiring a fixed primitive count (use [Fixed-Pool Relocation](3094-fixed-pool-relocation.md)) or scenes with significant motion (use [Temporal Densification](9531-temporal-densification.md)).

## Background
Adaptive Densification was introduced as part of the original 3D Gaussian Splatting paper by Kerbl et al. (2023) [S1][S5, unofficial]. It was designed to overcome the limitations of fixed-point-cloud representations by allowing the Gaussian representation to grow and shrink dynamically during optimization. The method draws inspiration from adaptive mesh refinement and previous work on probabilistic densification using MCMC [S3]. It has become the standard densification strategy for 3DGS and is the basis for many subsequent variants [S5, unofficial].
