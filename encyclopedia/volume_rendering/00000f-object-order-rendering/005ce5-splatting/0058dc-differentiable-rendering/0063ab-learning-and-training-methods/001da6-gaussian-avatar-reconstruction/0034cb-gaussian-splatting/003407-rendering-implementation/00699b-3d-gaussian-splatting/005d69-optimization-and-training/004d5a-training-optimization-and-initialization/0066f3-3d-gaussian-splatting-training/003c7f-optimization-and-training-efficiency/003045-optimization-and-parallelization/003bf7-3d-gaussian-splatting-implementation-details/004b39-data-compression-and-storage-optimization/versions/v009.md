# Data Compression and Storage Optimization

Also called: 3DGS Compression, Gaussian Pruning and Quantization

## Overview
Data Compression and Storage Optimization reduces the memory footprint and transmission bitrate of 3D Gaussian Splatting (3DGS) scenes, which typically exceed 1GB for large environments [S1]. It sets itself apart from sibling methods like [Sorting and Rendering Pipeline Optimization](12180-sorting-and-rendering-pipeline-optimization.md) by focusing on the representation of Gaussian attributes (color, geometry, opacity) rather than the rendering execution order, and from [LangSplat Training Procedure](12438-langsplat-training-procedure.md) by addressing storage density rather than semantic encoding.

## Shared principles
The family shares the goal of reducing the storage size of Gaussian primitives $\{G_i\}$, defined by position $\mathbf{p}_i$, opacity $\alpha_i$, scale $\mathbf{s}_i$, rotation $\mathbf{q}_i$, and spherical harmonic (SH) coefficients $\mathbf{c}_i$. Common mechanisms include:
1.  **Codebook Quantization:** Replacing continuous parameters (scale, rotation, SH coefficients) with discrete indices pointing to a learned codebook [S1, 12167, 12927].
2.  **Pruning/Masking:** Removing redundant Gaussians using learnable masks or sensitivity thresholds to reduce the number of primitives [S1, 12927].
3.  **Spatial Redundancy Exploitation:** Using spatial coherence (e.g., hash grids or Z-order sorting) to improve entropy coding or feature sharing [S1, 11820, 12927].
4.  **Quantization-Aware Training (QAT):** Fine-tuning parameters after compression to recover quality lost during quantization, using straight-through estimators in the backward pass [S1, 12167, 12927].

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
Reduces transmission bitrate by encoding numerical values into ASCII strings. It focuses on transmission efficiency rather than storage density, achieving ~6% training speed improvement.

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
Clusters SH coefficients and shape features into codebooks using a sensitivity-weighted distance metric. It prioritizes features affecting image quality, achieving up to 31× compression with minimal degradation.

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
Reduces memory by sharing view-dependent color via a hash-based grid neural field and quantizing geometric attributes. It achieves >25× compression by exploiting spatial redundancy.

### [Monte Carlo Specular Energy Aggregator](15439-monte-carlo-specular-energy-aggregator.md)
Maps high-order SH energy into a compact lower-order subspace using Monte Carlo projection of specular residuals. It preserves sharp specular features for efficient mobile rendering without distillation.

### Sensitivity-Aware Vector Clustering for 3DGS Compression
- **Definition:** A compression method that groups Gaussian colors and shape parameters into codebooks using sensitivity-aware vector clustering and quantization-aware training [S1].
- **Steps:**
    1. Calculate sensitivity $S(p)$ for each parameter $p$ to guide clustering into codebooks $C$ [S1].
    2. Compute codebooks $C$ using k-Means with a similarity measure between vectors and centroids [S1].
    3. Fine-tune parameters on the training set using quantization-aware training with Min-Max Quantization [S1].
    4. In the forward pass, simulate quantization considering a certain number of bits and the moving average of each parameter's min/max values [S1].
    5. In the backward pass, ignore simulated quantization and calculate the gradient for the parameter without quantization [S1].
    6. Compress the set of Gaussians and codebooks using DEFLATE after ordering Gaussians by Z-order (Morton order) to leverage spatial coherence [S1].
- **Parameters:** $\lambda$: Weight for the D-SSIM loss term, typically 0.2 [S1].

## Background
The need for compression in 3DGS arises from the high storage cost of per-Gaussian attributes. Early methods like those by Niedemayr et al. [16] and Lee et al. [17] (cited in [S1]) introduced sensitivity-aware clustering and learnable masking, respectively. These approaches laid the groundwork for modern compression techniques that balance bitrate constraints with model quality [S1].
