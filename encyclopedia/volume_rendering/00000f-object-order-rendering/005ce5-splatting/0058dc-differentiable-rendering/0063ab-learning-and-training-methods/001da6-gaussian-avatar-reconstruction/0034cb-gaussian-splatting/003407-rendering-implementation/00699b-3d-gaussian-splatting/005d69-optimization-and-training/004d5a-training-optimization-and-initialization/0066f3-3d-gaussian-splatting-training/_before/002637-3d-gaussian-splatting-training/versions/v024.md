# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the photometric difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images by optimizing position, rotation, scale, opacity, and appearance (e.g., spherical harmonics) [S5, unofficial]. Unlike NeRF-based methods which optimize a continuous neural field, 3DGS training optimizes discrete geometric primitives, offering significantly faster training and inference speeds while achieving comparable image quality [S2][S5, unofficial]. It builds on [Training Optimization and Initialization](13464-training-optimization-and-initialization.md) by applying adaptive density control and gradient-based updates to the Gaussian parameters.

## How it works
**Inputs:** A set of $N$ input images with known camera poses (rotation $R_{cw}$, translation $t_{cw}$, intrinsic matrix $K$) and initial 3D Gaussian estimates derived from Structure from Motion (SfM) [S2][S6, unofficial].
**Outputs:** A set of optimized 3D Gaussian primitives defined by position $\mathbf{p}_i$, rotation $q_i$, scale $\mathbf{s}_i$, opacity $\alpha_i$, and appearance coefficients $h_i$ [S6, unofficial].

**Data Structures:**
*   **Gaussian Attributes:** Each Gaussian $i$ stores:
    *   Position $\mathbf{p}_i \in \mathbb{R}^3$ (initialized from SfM points) [S2][S6, unofficial].
    *   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion, initialized as constant) [S2][S6, unofficial].
    *   Scale $\mathbf{s}_i \in \mathbb{R}^3$ (initialized between 0 and 1) [S2][S6, unofficial].
    *   Opacity $\alpha_i \in [0, 1]$ (initialized as constant) [S2][S6, unofficial].
    *   Appearance $h_i$ (Spherical Harmonic coefficients, initialized from SfM) [S6, unofficial].
*   **Covariance Matrix:** The 3D covariance $\Sigma_i$ is computed from scale and rotation: $\Sigma_i = R(q_i) S(\mathbf{s}_i) S(\mathbf{s}_i)^T R(q_i)^T$ [S2].
*   **Training State:** Iteration counter $i$, current step, camera iterator, and optimization history [S4, unofficial].

**Numbered Steps:**

1.  **Initialization:**
    *   Initialize positions $\mathbf{p}_w$ and appearance $h$ from SfM photogrammetry (e.g., COLMAP) [S2][S6, unofficial].
    *   Initialize rotation $q$, scale $s$, and opacity $\alpha$ as constants [S6, unofficial].
    *   Set iteration count $i = 0$ [S2].
    *   Set hyperparameters: `numIters` (default 30,000), `densifyFrom` (500), `densifyUntil` (default $\min(15000, \text{numIters}/2)$), `shDegree` (default 3), `shDegreeInterval` (1000) [S3, S4, unofficial].

2.  **Camera Sampling:**
    *   Maintain a shuffled vector of training camera indices [S4, unofficial].
    *   Select the next training camera $V$ via round-robin with periodic shuffle [S2][S4, unofficial].
    *   Compute the downscale factor for the current step based on `resolutionSchedule` (default 3000 steps) [S3, S4, unofficial].
    *   Retrieve the ground truth image $\hat{I}$ at the computed resolution [S2][S4, unofficial].

3.  **Rendering (Forward Pass):**
    *   Project the 3D Gaussians to 2D screen space using the camera $V$ [S2].
    *   Sort Gaussians by depth for each pixel [S2].
    *   Rasterize the Gaussians to obtain the rendered image $I$ [S2]. The pixel color $\gamma_j$ is computed via alpha blending:
        $$ \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij}, \quad \tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj}) $$
        where $\alpha'_{ij} = g \alpha_i$ is the effective opacity, $g$ is the 2D Gaussian weight, and $c_i$ is the color [S6, unofficial].

4.  **Loss Computation:**
    *   Compute the loss $\mathcal{L}$ between the rendered image $I$ and ground truth $\hat{I}$ [S2].
    *   The loss is a combination of L1 loss ($\mathcal{L}_1$) and D-SSIM loss ($\mathcal{L}_{D-SSIM}$) weighted by $\lambda$ (default 0.2) [S6, unofficial]:
        $$ \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM} $$

5.  **Backpropagation:**
    *   Compute the Jacobian matrices for each parameter ($q, s, h, \alpha, \mathbf{p}_w$) using the chain rule through the forward steps [S6, unofficial].
    *   Update parameters using the Adam optimizer [S2][S6, unofficial].

6.  **Adaptive Density Control (Refinement):**
    *   If $i \ge \text{densifyFrom}$ and $i \le \text{densifyUntil}$, and every `refineEvery` steps (default 500):
        *   Iterate over all Gaussians [S2].
        *   **Pruning:** If opacity $\alpha_i < \epsilon$ or the Gaussian is too large ($\|\mathbf{S}\| > \tau_S$), prune the Gaussian [S2].
        *   **Densification:** If the positional gradient $\nabla_{\mathbf{p}} \mathcal{L} > \tau_p$ (default 0.0002):
            *   **Over-reconstruction:** If $\|\mathbf{S}\| > \tau_S$ (default 0.01), split the Gaussian into two [S2].
            *   **Under-reconstruction:** Else, clone the Gaussian [S2].
    *   Increment $i$ [S2].

**Pseudocode:**

```python
def train_3dgs(training_data, initial_gaussians, config):
    """
    training_data: List of (camera_pose, ground_truth_image)
    initial_gaussians: List of Gaussian objects with p, q, s, alpha, h
    config: Dictionary of hyperparameters
    """
    gaussians = initial_gaussians
    num_iters = config.get('numIters', 30000)
    densify_from = config.get('densifyFrom', 500)
    densify_until = config.get('densifyUntil', min(15000, num_iters // 2))
    refine_every = config.get('refineEvery', 500)
    sh_degree = config.get('shDegree', 3)
    sh_interval = config.get('shDegreeInterval', 1000)
    resolution_schedule = config.get('resolutionSchedule', 3000)
    
    # Initialize optimizer
    optimizer = Adam(gaussians.parameters())
    
    # Camera iterator
    cam_indices = list(range(len(training_data)))
    shuffle(cam_indices)
    cam_iter = Iterator(cam_indices)
    
    for step in range(1, num_iters + 1):
        # 1. Camera Sampling
        cam_idx = cam_iter.next()
        if cam_iter.is_end():
            shuffle(cam_indices)
            cam_iter.reset()
            
        camera, gt_image = training_data[cam_idx]
        
        # 2. Resolution Scaling
        # Increase resolution every resolution_schedule steps
        downscale_factor = compute_downscale(step, resolution_schedule)
        gt_resized = resize(gt_image, downscale_factor)
        
        # 3. Rendering
        rendered_image = rasterize(gaussians, camera, downscale_factor)
        
        # 4. Loss Computation
        # Update SH degree if needed
        current_sh_degree = min(sh_degree, step // sh_interval)
        loss = compute_loss(rendered_image, gt_resized, current_sh_degree)
        
        # 5. Backpropagation
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # 6. Adaptive Density Control
        if densify_from <= step <= densify_until and step % refine_every == 0:
            gaussians = adaptive_density_control(gaussians, step)
            
        # Post-training updates (schedulers, logging)
        update_schedulers(optimizer, step)
        
    return gaussians

def adaptive_density_control(gaussians, step):
    """
    Prunes, splits, and clones Gaussians based on gradients and opacity.
    """
    # Compute gradients for positions
    pos_gradients = compute_position_gradients(gaussians)
    
    new_gaussians = []
    for g in gaussians:
        # Pruning
        if g.opacity < 0.005 or g.scale_norm > 0.1: # Example thresholds
            continue # Prune
            
        # Densification
        if pos_gradients[g.id] > 0.0002: # Gradient threshold
            if g.scale_norm > 0.01: # Over-reconstruction
                # Split into two
                child1, child2 = split_gaussian(g)
                new_gaussians.append(child1)
                new_gaussians.append(child2)
            else: # Under-reconstruction
                # Clone
                child = clone_gaussian(g)
                new_gaussians.append(child)
        else:
            new_gaussians.append(g)
            
    return new_gaussians
```

### HUGS
HUGS creates a coarse-to-fine deformation module using linear blend skinning and local learning-based refinement for animating virtual human avatars based on 3DGS [S1]. It utilizes the tri-plane representation to factorize the canonical space and can reconstruct a person and scene from monocular video (50-100 frames) within 30 minutes, achieving state-of-the-art performance at 20 FPS [S1].

### Wolf et al. Stereo Method
This method trains a 3DGS to render stereo-calibrated novel views, applies stereo depth estimation on the rendered views, and fuses the estimated dense depth maps using a Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
A labeling pipeline that generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for the densification and pruning processes of 3D-GS optimization [S8, unofficial].

### Cross-View Pruning Mechanism
A mechanism comprising a Cross-View Consistency Loss and adaptive pruning to reduce Gaussian redundancy and ensure geometric validity [S9]. It selects adjacent view pairs with SSIM > 0.6, computes a Cross-View Consistent Loss ($L_{CVC}$) to penalize residual discrepancies, and prunes Gaussians based on depth consistency conditions [S9].

### Structure-View Co-learning
A module combining structural and view-dependent gradients for robust joint optimization of Gaussian positions and appearance [S9]. The loss is defined as $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$, where $\mathcal{L}_V$ is view gradient loss and $\mathcal{L}_S$ is structure gradient loss [S9].

### Single-view Mini-batch Strategy
A training data sampling strategy where data is organized per viewpoint, and a mini-batch consists of data from only a single viewpoint [S10, unofficial]. For each viewpoint $i$, the dataset $D_i$ is collected, and a mini-batch $B_{3DGS}$ is sampled from $D = \{D_i\}$ with count=1 [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training typically requires 30,000 iterations [S3, S4, unofficial]. On GPU, training is significantly faster than NeRFs, often completing in minutes to hours depending on scene complexity [S2][S5, unofficial]. CPU execution is approximately 100x slower than GPU [S3, unofficial].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians. The default maximum number of Gaussians is 5,000,000 [S3, unofficial]. Sinc splatting variants consume less memory than standard Gaussians [S7].
*   **Measured Performance:** On the Replica dataset, SGS-SLAM achieves PSNR 34.15, SSIM 0.97, and LPIPS 0.096 [S1]. In 1D simulation with N=10 components, Modified Sinc achieved MSE 0.0002, matching Gaussian [S7].
*   **Strengths:** Real-time rendering speeds, high-fidelity reconstruction, faster training than NeRFs [S2][S5, unofficial].
*   **Limitations:** Can produce "floaters" or over-reconstruction artifacts if not properly pruned [S2]. Sensitive to initialization and local minima in some variants .
*   **When to use:** When real-time rendering and fast training are prioritized over implicit surface extraction.
*   **When not to use:** When explicit watertight meshes are required without post-processing, or when computational resources are extremely limited (CPU-only).

## Background
3D Gaussian Splatting was introduced by Kerbl et al. [9] (cited in [S2][S6, unofficial]). The original method initializes positions using sparse point clouds from SfM tools like COLMAP [S2]. It falls under the category of radiance fields but differs from NeRFs by using explicit Gaussian primitives [S5, unofficial]. The method has been widely adopted for real-time rendering, SLAM, and dynamic scene reconstruction [S1].
