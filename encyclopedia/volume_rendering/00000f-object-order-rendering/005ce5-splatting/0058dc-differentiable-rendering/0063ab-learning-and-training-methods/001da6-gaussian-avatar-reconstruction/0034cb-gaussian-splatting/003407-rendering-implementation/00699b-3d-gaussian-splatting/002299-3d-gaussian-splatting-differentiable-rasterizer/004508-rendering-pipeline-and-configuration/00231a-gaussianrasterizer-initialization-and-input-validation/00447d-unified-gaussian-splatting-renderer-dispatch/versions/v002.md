# Unified Gaussian Splatting Renderer Dispatch

Also called: Gaussian Splatting Renderer Dispatch, render function dispatch, vggt Gaussian Renderer

## Overview
The Unified Gaussian Splatting Renderer Dispatch is a routing mechanism that selects and invokes the appropriate differentiable rasterization backend (3DGS, 2DGS, or GGGS) based on the geometric representation of the input Gaussian primitives [S1, unofficial]. It abstracts the heterogeneity of Gaussian splatting variants by handling data preparation, backend selection, and post-processing of depth and normal outputs, allowing a single rendering pipeline to support multiple Gaussian parameterizations [S1, unofficial]. It differs from standard dispatchers by explicitly managing the transition between 3D covariance-based, 2D surface-based, and Gaussian Splatting with Spherical Gaussians (GGGS) representations within the same execution context [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- `pc`: A Gaussian point cloud object containing attributes: `means` (3D positions), `opacities` (scalar opacity), `scales` (scaling factors), `rotations` (quaternions), `harmonic`/`features` (SH coefficients), `max_sh_degree` (max spherical harmonic degree), and `active_sh_degree` (active SH degree) [S1, unofficial]. For GGGS, it may also contain `sg_axis`, `sg_sharpness`, `sg_color` [S1, unofficial].
- `batch_idx`: Integer or tensor indexing the batch dimension [S1, unofficial].
- `viewpoint_camera`: Camera object containing `FoVx`, `FoVy` (field of view in radians), `viewmatrix` (world-to-camera), `projmatrix` (projection), and `campos` (camera position) [S1, unofficial].
- `pipe`: Configuration object containing flags: `compute_cov3D_python`, `convert_SHs_python`, `depth_ratio`, `debug` [S1, unofficial].
- `gs_mode`: Optional explicit string override for render mode ("3DGS", "2DGS", "GGGS") [S1, unofficial].
- `override_color`: Optional tensor overriding computed colors [S1, unofficial].
- `bg`: Background color tensor [S1, unofficial].
- `scaling_modifier`: Float scaling factor for Gaussian sizes [S1, unofficial].
- `image_height`, `image_width`: Output image dimensions [S1, unofficial].

**Outputs:**
- `render`: Color tensor of shape `(3, H, W)` [S1, unofficial].
- `depth`: Depth tensor (format varies by mode: expected/median for 2DGS, inverse depth for 3DGS) [S1, unofficial].
- `normal`: Normal tensor (world-space normals for 2DGS/GGGS) [S1, unofficial].
- `alpha`: Alpha mask tensor [S1, unofficial].
- `means2D`: Screen-space positions with gradients attached [S1, unofficial].

### Data Structures
- **Gaussian Attributes**:
  - `xyz`: Tensor of shape `(N, 3)`, dtype `float32`, device `cuda` [S1, unofficial].
  - `opacity`: Tensor of shape `(N, 1)`, dtype `float32` [S1, unofficial].
  - `shs`: Tensor of shape `(N, 3, K)` where $K = (max\_sh\_degree + 1)^2$, dtype `float32` [S1, unofficial].
  - `scales`: Tensor of shape `(N, 3)`, dtype `float32` [S1, unofficial].
  - `rotations`: Tensor of shape `(N, 4)`, dtype `float32` (quaternions) [S1, unofficial].
  - `cov3D_precomp`: Tensor of shape `(N, 9)`, dtype `float32`, column-major 3x3 covariance matrix [S1, unofficial].
- **Rasterization Settings**:
  - `GaussianRasterizationSettings`: Struct containing `image_height`, `image_width`, `tanfovx`, `tanfovy`, `bg`, `scaling_modifier`, `viewmatrix`, `projmatrix`, `sh_degree`, `campos`, `prefiltered`, `debug` [S1, unofficial]. For GGGS: `kernel_size`, `sg_degree`, `require_depth` [S1, unofficial].

### Steps
1. **Extract Batch Attributes**: Retrieve `xyz = pc.means[batch_idx]` and `opacity = pc.opacities[batch_idx].unsqueeze(-1)` [S1, unofficial].
2. **Initialize Screen-Space Points**: Create `screenspace_points = torch.zeros_like(xyz, dtype=xyz.dtype, requires_grad=True, device="cuda") + 0` to capture gradients for screen-space positions [S1, unofficial].
3. **Compute Tangent FOV**: Calculate `tanfovx = math.tan(viewpoint_camera.FoVx * 0.5)` and `tanfovy = math.tan(viewpoint_camera.FoVy * 0.5)` [S1, unofficial].
4. **Determine Render Mode**: If `gs_mode` is explicitly provided, use it; else if `pc.scales[batch_idx].shape[1] == 2`, set `requested_render_mode = "2DGS"`; else set `requested_render_mode = "3DGS"` [S1, unofficial].
5. **Select Rasterizer Backend**: Map `requested_render_mode` to the corresponding `GaussianRasterizationSettings` and `GaussianRasterizer` classes: `"2DGS"` uses `diff_surfel_rasterization`, `"3DGS"` uses `diff_gaussian_rasterization`, and `"GGGS"` uses `gggs_diff_gaussian_rasterization` [S1, unofficial].
6. **Construct Rasterization Settings**: Instantiate `GaussianRasterizationSettings` with `image_height`, `image_width`, `tanfovx`, `tanfovy`, `bg`, `scaling_modifier`, `viewmatrix`, `projmatrix`, `sh_degree`, `campos`, `prefiltered=False`, `debug` [S1, unofficial]. For GGGS, additionally pass `kernel_size`, `sg_degree=0`, `require_depth` [S1, unofficial].
7. **Prepare Covariance**: If `pipe.compute_cov3D_python` is true, compute `cov3D_precomp` by transforming world-space covariance to pixel space using `ndc2pix` and `world2pix` matrices, reshaping to `(-1, 9)` in column-major order [S1, unofficial]. Else, set `scales` and `rotations` directly from `pc` [S1, unofficial].
8. **Prepare Colors**: If `override_color` is None and `pipe.convert_SHs_python` is true, compute `colors_precomp` by evaluating SHs: extract `shs_view = pc.get_features.transpose(1, 2).view(-1, 3, (pc.max_sh_degree+1)**2)`, normalize direction vectors `dir_pp_normalized = dir_pp/dir_pp.norm(dim=1, keepdim=True)`, evaluate `sh2rgb = eval_sh(pc.active_sh_degree, shs_view, dir_pp_normalized)`, and clamp `colors_precomp = torch.clamp_min(sh2rgb + 0.5, 0.0)` [S1, unofficial]. Else, set `shs = pc.harmonics[batch_idx].permute(0, 2, 1)` [S1, unofficial].
9. **Execute Rasterizer**: Call `rasterizer(means3D, means2D, shs, colors_precomp, opacity, scales, rotations, cov3D_precomp)` [S1, unofficial]. For GGGS, also pass `sg_axis`, `sg_sharpness`, `sg_color` [S1, unofficial].
10. **Post-Process Outputs**:
    - **2DGS**: Extract `allmap` from rasterizer output. Set `render_alpha = allmap[1:2]`, `render_normal = allmap[2:5]` (transformed to world space), `render_depth_median = allmap[5:6]`, `render_depth_expected = allmap[0:1] / render_alpha`, `render_dist = allmap[6:7]` [S1, unofficial]. Compute `surf_depth = render_depth_expected * (1 - pipe.depth_ratio) + pipe.depth_ratio * render_depth_median` and `surf_normal = depth_to_normal(viewpoint_camera, surf_depth) * render_alpha.detach()` [S1, unofficial].
    - **3DGS**: Compute `depth = 1.0 / inv_depth.clamp(min=1e-6)` [S1, unofficial].
    - **GGGS**: Retrieve optional attributes `sg_axis`, `sg_sharpness`, `sg_color` from `pc` (handling defaults and tensor dimensions) and return `rendered_median_depth`, `rendered_alpha`, `rendered_normal` [S1, unofficial].

### Pseudocode
```python
import math
import torch

def unified_gaussian_splatting_dispatch(
    pc, batch_idx, viewpoint_camera, pipe, gs_mode=None, override_color=None,
    bg=torch.tensor([0.0, 0.0, 0.0]), scaling_modifier=1.0,
    image_height=512, image_width=512, debug=False
):
    # 1. Extract Batch Attributes
    xyz = pc.means[batch_idx]
    opacity = pc.opacities[batch_idx].unsqueeze(-1)

    # 2. Initialize Screen-Space Points
    screenspace_points = torch.zeros_like(xyz, dtype=xyz.dtype, requires_grad=True, device="cuda") + 0

    # 3. Compute Tangent FOV
    tanfovx = math.tan(viewpoint_camera.FoVx * 0.5)
    tanfovy = math.tan(viewpoint_camera.FoVy * 0.5)

    # 4. Determine Render Mode
    if gs_mode is not None:
        requested_render_mode = gs_mode
    elif pc.scales[batch_idx].shape[1] == 2:
        requested_render_mode = "2DGS"
    else:
        requested_render_mode = "3DGS"

    # 5. Select Rasterizer Backend
    if requested_render_mode == "2DGS":
        from diff_surfel_rasterization import GaussianRasterizationSettings as RasterSettings2D
        from diff_surfel_rasterization import GaussianRasterizer as Rasterizer2D
    elif requested_render_mode == "GGGS":
        from gggs_diff_gaussian_rasterization import GaussianRasterizationSettings as RasterSettingsGGGS
        from gggs_diff_gaussian_rasterization import GaussianRasterizer as RasterizerGGGS
    else: # 3DGS
        from diff_gaussian_rasterization import GaussianRasterizationSettings as RasterSettings3D
        from diff_gaussian_rasterization import GaussianRasterizer as Rasterizer3D

    # 6. Construct Rasterization Settings
    if requested_render_mode == "2DGS":
        raster_settings = RasterSettings2D(
            image_height=image_height, image_width=image_width,
            tanfovx=tanfovx, tanfovy=tanfovy, bg=bg,
            scaling_modifier=scaling_modifier,
            viewmatrix=viewpoint_camera.viewmatrix,
            projmatrix=viewpoint_camera.projmatrix,
            sh_degree=pc.active_sh_degree,
            campos=viewpoint_camera.campos,
            prefiltered=False, debug=debug
        )
        rasterizer = Rasterizer2D(raster_settings)
    elif requested_render_mode == "GGGS":
        sg_axis = getattr(pc, 'sg_axis', None)
        sg_sharpness = getattr(pc, 'sg_sharpness', None)
        sg_color = getattr(pc, 'sg_color', None)
        raster_settings = RasterSettingsGGGS(
            image_height=image_height, image_width=image_width,
            tanfovx=tanfovx, tanfovy=tanfovy, bg=bg,
            scaling_modifier=scaling_modifier,
            viewmatrix=viewpoint_camera.viewmatrix,
            projmatrix=viewpoint_camera.projmatrix,
            sh_degree=pc.active_sh_degree,
            campos=viewpoint_camera.campos,
            prefiltered=False, debug=debug,
            kernel_size=getattr(pipe, 'kernel_size', 1),
            sg_degree=0, require_depth=True
        )
        rasterizer = RasterizerGGGS(raster_settings)
    else:
        raster_settings = RasterSettings3D(
            image_height=image_height, image_width=image_width,
            tanfovx=tanfovx, tanfovy=tanfovy, bg=bg,
            scaling_modifier=scaling_modifier,
            viewmatrix=viewpoint_camera.viewmatrix,
            projmatrix=viewpoint_camera.projmatrix,
            sh_degree=pc.active_sh_degree,
            campos=viewpoint_camera.campos,
            prefiltered=False, debug=debug
        )
        rasterizer = Rasterizer3D(raster_settings)

    # 7. Prepare Covariance
    if pipe.compute_cov3D_python:
        # Sources do not provide the implementation for ndc2pix/world2pix transformation.
        cov3D_precomp = compute_cov3D_python(xyz, pc.scales[batch_idx], pc.rotations[batch_idx],
                                             viewpoint_camera.viewmatrix, viewpoint_camera.projmatrix)
        cov3D_precomp = cov3D_precomp.reshape(-1, 9) # Column-major
    else:
        cov3D_precomp = None

    # 8. Prepare Colors
    if override_color is None and pipe.convert_SHs_python:
        shs_view = pc.get_features.transpose(1, 2).view(-1, 3, (pc.max_sh_degree + 1) ** 2)
        dir_pp = xyz - viewpoint_camera.campos
        dir_pp_normalized = dir_pp / dir_pp.norm(dim=1, keepdim=True)
        sh2rgb = eval_sh(pc.active_sh_degree, shs_view, dir_pp_normalized)
        colors_precomp = torch.clamp_min(sh2rgb + 0.5, 0.0)
        shs = None
    else:
        colors_precomp = None
        shs = pc.harmonics[batch_idx].permute(0, 2, 1)

    # 9. Execute Rasterizer
    if requested_render_mode == "GGGS":
        render_out = rasterizer(
            means3D=xyz, means2D=screenspace_points,
            shs=shs, colors_precomp=colors_precomp, opacity=opacity,
            scales=pc.scales[batch_idx], rotations=pc.rotations[batch_idx],
            cov3D_precomp=cov3D_precomp,
            sg_axis=sg_axis, sg_sharpness=sg_sharpness, sg_color=sg_color
        )
    else:
        render_out = rasterizer(
            means3D=xyz, means2D=screenspace_points,
            shs=shs, colors_precomp=colors_precomp, opacity=opacity,
            scales=pc.scales[batch_idx], rotations=pc.rotations[batch_idx],
            cov3D_precomp=cov3D_precomp
        )

    # 10. Post-Process Outputs
    if requested_render_mode == "2DGS":
        allmap = render_out
        render_alpha = allmap[1:2]
        render_normal = allmap[2:5] # Transform to world space if necessary
        render_depth_median = allmap[5:6]
        render_depth_expected = allmap[0:1] / render_alpha
        render_dist = allmap[6:7]
        
        depth_ratio = pipe.depth_ratio
        surf_depth = render_depth_expected * (1 - depth_ratio) + depth_ratio * render_depth_median
        # Sources do not provide the implementation for depth_to_normal.
        surf_normal = depth_to_normal(viewpoint_camera, surf_depth) * render_alpha.detach()
        
        return render_out[0:3], surf_depth, surf_normal, render_alpha, screenspace_points
    elif requested_render_mode == "GGGS":
        rendered_median_depth = render_out.get('median_depth')
        rendered_alpha = render_out.get('alpha')
        rendered_normal = render_out.get('normal')
        return render_out.get('color'), rendered_median_depth, rendered_normal, rendered_alpha, screenspace_points
    else: # 3DGS
        inv_depth = render_out.get('inv_depth')
        depth = 1.0 / inv_depth.clamp(min=1e-6)
        return render_out.get('color'), depth, render_out.get('normal'), render_out.get('alpha'), screenspace_points
```

### Parameters
- `depth_ratio`: Float, typically between 0.0 and 1.0, weighting the blend between expected and median depth in 2DGS [S1, unofficial].
- `scaling_modifier`: Float, typically 1.0, scaling the Gaussian sizes [S1, unofficial].
- `kernel_size`: Integer, typically 1 or 3, for GGGS kernel [S1, unofficial].

### Edge Cases and Pitfalls
- **Precision**: Inverse depth clamping at `1e-6` prevents division by zero in 3DGS [S1, unofficial].
- **Boundaries**: `screenspace_points` must be initialized with `requires_grad=True` to ensure gradient flow for screen-space optimization [S1, unofficial].
- **Mode Detection**: The mode detection relies on `pc.scales[batch_idx].shape[1] == 2` for 2DGS; explicit `gs_mode` is recommended when scale dimensions are ambiguous [S1, unofficial].

## Subtopics

### 3D Gaussian Splatting Rasterization
Standard 3D covariance-based splatting. Use for general scene representation. [3D Gaussian Splatting Rasterization](52-3d-gaussian-splatting-rasterization.md)

### 2D Gaussian Splatting
Surface-based representation using 2D covariances. Use for high-fidelity surface reconstruction. [2D Gaussian Splatting](53-2d-gaussian-splatting.md)

### Gaussian Splatting with Spherical Gaussians (GGGS)
Variant using SGs for lighting. Use for relighting and material editing. [GGGS](54-gggs.md)

## Operating characteristics
- **Time Complexity**: Dominated by the rasterization backend, typically $O(N)$ where $N$ is the number of Gaussians, but depends on the specific backend's optimization [S1, unofficial].
- **Memory Complexity**: $O(N)$ for Gaussian attributes and intermediate tensors [S1, unofficial].
- **Measured Performance**: Not given in the sources.
- **Scaling**: Scales with the number of Gaussians and image resolution [S1, unofficial]. GGGS may have higher overhead due to additional SG attributes [S1, unofficial].
- **Strengths**: Unified interface for multiple Gaussian variants; flexible mode selection [S1, unofficial].
- **Limitations**: Requires careful handling of backend-specific attributes; potential for mode misclassification if `gs_mode` is not set and scale dimensions are ambiguous [S1, unofficial].

## Background
The Unified Gaussian Splatting Renderer Dispatch originates from the VGGT project, which integrates various Gaussian splatting backends for 3D reconstruction and rendering [S1, unofficial]. It was developed to support multiple Gaussian parameterizations within a single pipeline, enabling seamless switching between 3DGS, 2DGS, and GGGS representations [S1, unofficial].
