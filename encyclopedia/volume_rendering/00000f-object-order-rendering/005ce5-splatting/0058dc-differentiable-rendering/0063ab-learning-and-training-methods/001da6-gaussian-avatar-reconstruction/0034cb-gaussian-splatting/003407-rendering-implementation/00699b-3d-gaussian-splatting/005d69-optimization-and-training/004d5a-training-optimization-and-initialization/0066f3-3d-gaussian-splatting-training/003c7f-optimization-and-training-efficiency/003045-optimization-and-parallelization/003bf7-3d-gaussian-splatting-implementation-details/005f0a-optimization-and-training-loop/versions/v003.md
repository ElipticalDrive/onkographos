# Optimization and Training Loop

Also called: Differentiable Training, Gaussian Optimization

## Overview
This family encompasses the stochastic gradient descent procedures and initialization strategies used to optimize the parameters of 3D Gaussian point clouds for novel view synthesis [S1]. It distinguishes itself from non-differentiable reconstruction methods by leveraging a differentiable rasterizer to compute explicit gradients, allowing millions of parameters (position, covariance, opacity, spherical harmonics) to be updated simultaneously . The core challenge addressed is adapting a static point cloud representation to fit multi-view photometric data while managing density through periodic densification and pruning [S1].

## Shared principles
All methods in this family operate on a fixed iteration budget (typically 30,000 steps) rather than a convergence threshold [S1]. The optimization loop follows a consistent pattern:
1.  **Sampling:** Randomly select one or more training images and camera poses from the dataset [S1].
2.  **Rendering:** Project the 3D Gaussians to 2D and alpha-blend them using a differentiable rasterizer to produce a rendered image $\hat{I}$ [S1].
3.  **Loss Computation:** Compute a photometric loss $\mathcal{L}$ between $\hat{I}$ and the ground-truth image $I_{gt}$ . The standard loss is a weighted sum:
    $$ \mathcal{L}_{img} = (1 - \lambda) \mathcal{L}_{L1} + \lambda \mathcal{L}_{D-SSIM} $$
    where $\mathcal{L}_{L1}$ is the L1 loss and $\mathcal{L}_{D-SSIM}$ is the differentiable Structural Similarity index loss [S1]. The weight $\lambda$ is typically 0.2 [S1].
4.  **Backpropagation:** Compute gradients $\nabla \mathcal{L}$ with respect to all Gaussian parameters using automatic differentiation through the rasterizer [S1].
5.  **Update:** Update parameters using the Adam optimizer with $\beta_1 = 0.9$ and $\beta_2 = 0.99$ [S1].
6.  **Densification/Pruning:** Periodically evaluate gradient magnitudes and opacity thresholds to split high-gradient Gaussians or prune low-opacity ones, adapting the scene density [S1].

## Subtopics

### [3D Gaussian Splatting Training Loop](15139-3d-gaussian-splatting-training-loop.md)
The standard training loop minimizes photometric loss to optimize a 3D Gaussian point cloud initialized from Structure-from-Motion (SfM) points. It distinguishes itself by operating on a single view per iteration with standard alpha blending. It is the baseline method for static scene reconstruction.

### [Multi-View Regulated Gaussian Splatting](15783-multi-view-regulated-gaussian-splatting.md)
MVGS imposes multi-view coherent (MVC) constraints to enhance consistency and stabilize gradients. Unlike standard single-view optimization, it aggregates gradients from $M$ views per iteration by summing them (not averaging), which increases the effective learning rate for jointly observed Gaussians. It is chosen for scenes with minimal overlap or resolution scaling needs, using cross-ray densification and cross-intrinsic guidance.

### [Mip-Splatting Training Loop & Evaluation Pipeline](17975-mip-splatting-training-loop-evaluation-pipeline.md)
This method addresses aliasing by rendering at multiple resolutions and handling subpixel jittering for both rendered and ground truth images. It distinguishes itself by dynamically adjusting the spherical harmonics (SH) degree during training to prevent high-frequency artifacts and using adaptive densification thresholds based on image-space radii. It is chosen for high-fidelity reconstruction where aliasing is a concern.

### [Bézier-boundary gradient approximation](13137-b-zier-boundary-gradient-approximation.md)
This method approximates gradients of a discontinuous indicator function $g(\cdot)$ with respect to Bézier curve control point coordinates. It sets itself apart by enabling backpropagation in Gaussian Splatting despite the function being piecewise constant, explicitly handling discontinuities introduced by modified $\alpha$-blending functions that standard methods cannot natively support. It is chosen when using non-standard blending functions or boundary constraints.

### Global Latent Optimization (GLO)
A method to handle photometric inconsistencies (automatic exposure/white-balance) by co-optimizing a per-view latent vector mapped via an MLP to a linear transformation of spherical harmonic coefficients [S1]. The transformation is $\hat{c}_i = a \odot c_i + b$, where $\hat{c}_i$ are the transformed coefficients, $c_i$ are the original spherical harmonic coefficients, $\odot$ is the Hadamard product, $b$ models brightness changes, and $a$ provides white-balance expressive power [S1]. The parameters $a, b$ are generated by an MLP $Q$ taking a latent vector $z_n \in \mathbb{R}^{64}$ per camera view [S1]. A reduced model prevents $z_n$ from explaining distractors as per-image adjustments [S1].

## Background
The 3D Gaussian Splatting training loop was introduced by Kerbl et al. in 2023 [S1]. It builds on the differentiable rendering framework established by prior work, adapting the rasterization process to support gradient-based optimization of Gaussian primitives . The method has become the standard for real-time novel view synthesis, with numerous variants addressing specific challenges such as aliasing [S1], multi-view consistency [S1], and photometric inconsistencies [S1].
