# On-the-Fly GS Progressive Training

Also called: On-the-Fly Gaussian Splatting

## Overview
On-the-Fly GS Progressive Training is a method for incrementally optimizing a 3D Gaussian Splatting (3DGS) field as new images are acquired in real-time, enabling near real-time reconstruction without retraining the entire scene from scratch [S1]. It differs from offline training by decoupling the optimization domain temporally, appending new Gaussians for newly observed geometry and performing localized, weighted gradient updates for each incoming image [S1, Parent]. Unlike [Two-stage Optimization](14857-two-stage-optimization.md), which separates geometry and appearance into sequential phases, this method integrates densification and appearance refinement continuously through a hierarchical weighting scheme and adaptive learning rates [S1].

## How it works
The method operates in three distinct phases: Initial Training, Progressive Training, and Final Optimization [S1].

### Inputs and Outputs
*   **Inputs:** A sequence of incoming RGB images $I_{new}$, camera poses estimated by On-the-Fly SfM, and the current 3DGS field $\mathcal{G}$ containing $N$ Gaussians. Each Gaussian $g$ is defined by position $\mathbf{p}$, covariance $\mathbf{\Sigma}$ (or rotation $\mathbf{R}$ and scale $\mathbf{s}$), opacity $\alpha$, and spherical harmonics coefficients for view-dependent color [S1].
*   **Outputs:** An updated 3DGS field $\mathcal{G}'$ and refined camera poses for the registered images [S1].

### Data Structures
*   **3DGS Field:** A list of Gaussians. Each Gaussian stores position, rotation, scale, opacity, and SH coefficients.
*   **Sparse Point Cloud:** A set of 3D points $\mathcal{P}$ generated by On-the-Fly SfM.
*   **Search Tree:** A spatial index (e.g., KD-tree) built over $\mathcal{P}$ to query nearest neighbors [S1].
*   **Image Weights:** A map associating each registered image with a scalar weight $\omega$ [S1].
*   **Gaussian Count per Pixel:** An array $G_p$ storing the number of Gaussians splatting onto pixel $p$ for load balancing [S1].

### Numbered Steps

#### Phase 1: Initial 3DGS Training
1.  Acquire the first $N_0$ images.
2.  Run On-the-Fly SfM to estimate poses and generate the initial sparse point cloud $\mathcal{P}_0$ [S1].
3.  Initialize the 3DGS field $\mathcal{G}$ using the points in $\mathcal{P}_0$ [S1].
4.  Perform standard 3DGS optimization for $T_{init}$ iterations on these $N_0$ images [S1].

#### Phase 2: Progressive 3DGS Training (per new image $n$)
1.  **Pose and Point Cloud Update:** On-the-Fly SfM estimates the pose of the new image $n$ and performs local Bundle Adjustment (BA) to refine poses of neighboring registered images, updating the sparse point cloud $\mathcal{P}$ [S1].
2.  **Densification:**
    *   Construct a search tree over the current sparse point cloud $\mathcal{P}$ [S1].
    *   For each point $p_{new}$ in the new image's point cloud, query the search tree for the nearest neighbor distance $d$.
    *   If $d > \tau$ (predefined distance threshold), classify $p_{new}$ as a new point [S1].
    *   Initialize new Gaussians for these points and append them to $\mathcal{G}$ [S1].
3.  **Hierarchical Image Weighting:** Calculate weights $\omega_i$ for all registered images to determine training priority [S1]:
    *   Set weight for the new image: $\omega_{11} = 1$ [S1].
    *   For images $i$ with direct overlap ($M_{i,n} \neq 0$), calculate:
        $$ \omega_{2i} = M_{i,n} $$
        where $M_{i,n}$ is the number of matched feature points between image $i$ and new image $n$ [S1].
    *   For images in indirect layers $k \ge 3$, calculate weights based on the previous layer $k-1$:
        $$ \omega_{ki} = \frac{\sum_{j=1}^{N_{k-1}} \omega_{j}^{(k-1)} \times M_{j,ki}^{(k-1)}}{N_{k-1}} $$
        where $\omega_{j}^{(k-1)}$ is the weight of image $j$ in layer $k-1$, $M_{j,ki}^{(k-1)}$ is the match count between image $j$ and image $i$, and $N_{k-1}$ is the number of images in layer $k-1$ [S1].
4.  **Training Iteration Allocation:** Perform $T_I$ total iterations [S1]. Split into Local and Semi-Global optimization (each $T_I/2$ iterations) [S1]:
    *   **Local Optimization:** Select the top $N_m$ images with highest weights as key targets [S1]. For each key image $i$ with weight $\omega_i$, allocate iterations $T_{im}$:
        $$ T_{im} = \frac{1 - e^{-\omega_i}}{\sum_{j=1}^{N_m} (1 - e^{-\omega_j})} \times T_I $$
        Train the 3DGS field on these images for their allocated iterations [S1].
    *   **Semi-Global Optimization:** Distribute the remaining $T_I/2$ iterations evenly among the other registered images [S1].
5.  **Adaptive Learning Rate:** For each image $j$ trained for $T_j$ iterations, calculate the base learning rate $\eta_j^c$ [S1]:
    *   Calculate progress $t_i$:
        $$ t_i = \begin{cases} 1 & T_j > T_a \\ T_j / T_a & T_j \le T_a \end{cases} $$
    *   Interpolate initial $\eta_j^0$ and final $\eta_j^f$ rates:
        $$ \eta_j^c = (\eta_j^0)^{1-t_i} \times (\eta_j^f)^{t_i} $$
    *   Adjust for overlapping images $I$ (where $M_{i,j} > 0$):
        $$ \eta_j = \frac{\eta_j^c + \sum_{i \in I} M_{i,j} \times \eta_i^c}{N_I + 1} $$
        where $N_I$ is the count of overlapping images [S1].
6.  **Loss Computation and Update:**
    *   Calculate Load-Balancing-Loss $L_{load}$:
        $$ L_{load} = \text{std}(G_p), \quad p \in \text{image pixels} $$
        where $G_p$ is the number of Gaussians associated with pixel $p$ [S1].
    *   Compute total loss:
        $$ L_{total} = \lambda_1 L_1 + \lambda_{ssim} L_{ssim} + \lambda_{load} L_{load} $$
    *   Perform gradient descent using Splatting-based parallelism (gradient accumulation per Gaussian) [S1].

#### Phase 3: Final Optimization
1.  After all images are acquired, perform global Bundle Adjustment on all estimated poses [S1].
2.  Apply rapid additional optimization to the final 3DGS field [S1].

        N_m = params['N_m']

        key_images = sorted_imgs[:N_m]

        # Local Optimization

def calculate_hierarchical_weights(registered_images, new_img, new_pose):
    """
    Calculates weights based on feature matches.
    """
    weights = {}
    # New image weight
    weights[new_img] = 1.0
    
    # Direct overlap (Layer 2)
    for img in registered_images:
        M_in = count_feature_matches(img, new_img)
        if M_in > 0:
            weights[img] = M_in
            
    # Indirect overlap (Layer k >= 3)
    # This requires a graph traversal or iterative layer construction
    # Simplified representation:
    layers = {1: [new_img], 2: [img for img in registered_images if count_feature_matches(img, new_img) > 0]}
    
    k = 3
    while True:
        prev_layer = layers[k-1]
        if not prev_layer: break
        
        current_layer_weights = {}
        for img in registered_images:
            if img in layers: continue # Already weighted
            
            # Check if connected to previous layer
            matches = []
            for prev_img in prev_layer:
                M = count_feature_matches(prev_img, img)
                if M > 0:
                    matches.append((prev_img, M))
            
            if matches:
                # Calculate weight based on Eq 4
                numerator = sum(weights[prev_img] * M for prev_img, M in matches)
                denominator = len(prev_layer) # N_{k-1}
                w = numerator / denominator
                current_layer_weights[img] = w
                
        if current_layer_weights:
            layers[k] = list(current_layer_weights.keys())
            for img, w in current_layer_weights.items():
                weights[img] = w
            k += 1
        else:
            break
            
    return weights

    Performs gradient descent for a specific image allocation.
    """
    # Adaptive Learning Rate Calculation
    # T_j is the total iterations this image has been trained for across all steps
    # For simplicity, we assume T_j is tracked externally or passed in.
    # Here we calculate the rate for the current step based on accumulated T_j.
    
    # Note: In the actual implementation, T_j accumulates.

    eta_f = params['eta_f']
    T_a = params['T_a']
    
    t_i = 1.0 if T_j > T_a else T_j / T_a
    eta_c = (eta_0 ** (1 - t_i)) * (eta_f ** t_i)
    
    # Adjust for overlapping images
    overlapping_imgs = get_overlapping_images(image)
    N_I = len(overlapping_imgs)
    
    sum_eta = 0
    for i in overlapping_imgs:
        M_ij = count_feature_matches(i, image)
        if M_ij > 0:
            # Need eta_i^c for overlapping images

            eta_i_c = (params['eta_0'] ** (1 - t_i_over)) * (params['eta_f'] ** t_i_over)
            sum_eta += M_ij * eta_i_c
            
    eta_j = (eta_c + sum_eta) / (N_I + 1)
    
    # Gradient Accumulation per Gaussian (Splatting-based parallelism)
    for _ in range(int(iterations)):
        loss = 0
        # Render current image
        rendered_img, gaussian_contributions = render_gaussians(gaussians, image, params['camera'])
        
        # Calculate Losses

        lambda_ssim = params['lambda_ssim']
        lambda_load = params['lambda_load']
        
        L_total = lambda_1 * L1 + lambda_ssim * SSIM + lambda_load * L_load

        gradients = compute_gradients(L_total, gaussians, rendered_img, image)
        update_gaussians(gaussians, gradients, eta_j)
        
    update_accumulated_iterations(image, iterations)

### Parameters
*   $N_0$: Number of initial images. Typical value: 30 [S1].
*   Initial training iterations ($T_{init}$): Typical value: 2,000 [S1].
*   $T_I$: Total training iterations per new image. Typical value: 200 [S1].
*   $N_m$: Number of top-weighted images for local optimization. Typical value: 10 [S1].
*   $T_a$: Predefined parameter for satisfactory quality iterations. Typical value: 200 [S1].
*   $\eta^0$: Initial learning rate. Typical value: $1.6 \times 10^{-4}$ [S1].
*   $\eta^f$: Final learning rate. Typical value: $1.6 \times 10^{-6}$ [S1].
*   $\lambda_1$: Weight for $L_1$-Loss. Typical value: 0.47 [S1].
*   $\lambda_{load}$: Weight for Load-Balancing-Loss. Typical value: 0.41 [S1].
*   $\lambda_{ssim}$: Weight for SSIM-Loss. Typical value: 0.12 [S1].

### Edge Cases and Pitfalls
*   **Overfitting in Phase 1:** Training too long on the initial $N_0$ images can cause overfitting to the sparse initial geometry [S1].
*   **Threshold Selection:** The distance threshold $\tau$ for densification must be chosen carefully; too low results in redundant Gaussians, too high misses new geometry [S1].
*   **Weight Calculation Stability:** If $N_{k-1}$ is zero or match counts are zero, division by zero or undefined weights may occur. The pseudocode handles empty layers by breaking the loop [S1].
*   **Gradient Contention:** Using per-pixel gradient accumulation can lead to serialized atomic operations. The method uses per-Gaussian accumulation to mitigate this [S1].

## Operating characteristics
*   **Time Complexity:** The method is designed for near real-time performance. Each new image triggers $T_I$ iterations (typically 200) on the current field, rather than retraining the entire scene [S1]. The average iterations per image approach $T_I$ as the scene grows [S1].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians, which increases as new images are added. The load-balancing loss helps control the total number of Gaussians [S1].
*   **Performance:** Evaluated on RGB and RGB-D datasets (indoor, outdoor, UAV, VSLAM) using an RTX 4090 GPU [S1]. It outperforms offline methods like Adr-Gaussian and Taming-3DGS in speed while maintaining competitive quality [S1].
*   **Strengths:** Enables continuous, incremental reconstruction; reduces training time via localized updates and load balancing; prevents Gaussian accumulation in specific regions [S1].
*   **Limitations:** Requires On-the-Fly SfM for pose estimation and point cloud generation; quality depends on the accuracy of the sparse point cloud and feature matching [S1].

## Background
On-the-Fly GS was proposed to address the need for near real-time 3DGS optimization in dynamic environments [S1]. It builds on the original 3DGS method [S1] and integrates concepts from Taming-3DGS regarding gradient accumulation [S1]. The method is part of the broader family of progressive and multi-stage training techniques for Gaussian Splatting [Parent].
