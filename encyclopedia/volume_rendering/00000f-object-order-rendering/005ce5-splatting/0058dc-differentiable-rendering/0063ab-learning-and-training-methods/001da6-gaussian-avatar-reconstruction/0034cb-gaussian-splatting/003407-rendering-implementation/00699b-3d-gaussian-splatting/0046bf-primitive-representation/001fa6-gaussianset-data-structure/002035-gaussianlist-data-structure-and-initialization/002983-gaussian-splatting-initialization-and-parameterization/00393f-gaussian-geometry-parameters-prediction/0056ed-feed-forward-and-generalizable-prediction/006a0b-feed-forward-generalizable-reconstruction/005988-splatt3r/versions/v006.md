# Splatt3R

Also called: Splatt3R: Zero-Shot Gaussian Splatting from Uncalibrated Image Pairs

## Overview
Splatt3R is a feed-forward model that predicts 3D Gaussian Splat parameters directly from a pair of uncalibrated natural images, without requiring camera intrinsics, extrinsics, or depth information [S1, unofficial]. It solves the problem of pose-free novel view synthesis by extending the MASt3R foundation model with a parallel "Gaussian head" to predict geometry offsets, covariances, opacities, and colors [S1, unofficial]. Unlike sibling methods that restrict supervision to viewpoints interpolated between input stereo views, Splatt3R employs a loss masking strategy to enable stable training and inference for extrapolated viewpoints beyond the stereo baseline [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Two uncalibrated RGB images $I_1, I_2 \in \mathbb{R}^{H \times W \times 3}$. The source uses a resolution of $512 \times 512$ [S1, unofficial].
*   **Output:** A set of 3D Gaussian primitives $\mathcal{G} = \mathcal{G}_1 \cup \mathcal{G}_2$, where $\mathcal{G}_1$ and $\mathcal{G}_2$ are the Gaussians predicted from $I_1$ and $I_2$ respectively. Each Gaussian $i$ is defined by mean position $\mu_i$, covariance $\Sigma_i$ (parameterized by rotation $q_i$ and scale $s_i$), opacity $\alpha_i$, and color $c_i$ [S1, unofficial].

**Data Structures:**
The method relies on the MASt3R architecture's internal feature maps and prediction heads.
1.  **MASt3R Backbone:** A shared Vision Transformer (ViT) encoder and cross-attention transformers extract multi-scale features. These weights are frozen during Splatt3R training [S1, unofficial].
2.  **Point Cloud Head:** Predicts 3D point locations $\hat{X}_1, \hat{X}_2$ and confidence maps $C_1, C_2$ in the coordinate frame of the first image [S1, unofficial].
3.  **Gaussian Head:** A DPT-style decoder running in parallel to the Point Cloud Head. It predicts per-pixel:
    *   Offset $\Delta \in \mathbb{R}^3$
    *   Rotation quaternion $q \in \mathbb{R}^4$
    *   Scale $s \in \mathbb{R}^3$
    *   Opacity $\alpha \in \mathbb{R}$
    *   Spherical Harmonics coefficients $S \in \mathbb{R}^{3 \times d}$ (or constant color $S \in \mathbb{R}^3$) [S1, unofficial].

**Algorithm Steps:**

1.  **Feature Encoding:** Encode input images $I_1, I_2$ using the frozen MASt3R ViT encoder and cross-attention transformers to obtain feature maps [S1, unofficial].
2.  **Point Prediction:** Use the frozen MASt3R Point Cloud Head to predict 3D point locations $\hat{X}_1, \hat{X}_2$ and confidence maps $C_1, C_2$ for each pixel in the coordinate frame of the first image [S1, unofficial].
3.  **Gaussian Parameter Regression:** Use the parallel Gaussian Head (DPT architecture) to predict offsets $\Delta$, rotations $q$, scales $s$, opacities $\alpha$, and spherical harmonics $S$ for each pixel [S1, unofficial].
    *   Apply activation functions: normalization for $q$, exponential for $s$ and $\Delta$, and sigmoid for $\alpha$ [S1, unofficial].
4.  **Gaussian Construction:** Construct the mean position $\mu$ for each Gaussian using the predicted point $\hat{x}$ and offset $\Delta$:
    $$ \mu = \hat{x} + \Delta $$
    Construct the covariance matrix $\Sigma$ using the rotation quaternion $q$ and scale $s$:
    $$ \Sigma = R(q) S(s) S(s)^T R(q)^T $$
    where $R(q)$ is the rotation matrix derived from $q$, and $S(s)$ is the diagonal scaling matrix [S1, unofficial].
5.  **Union:** The final scene representation is the union of Gaussians predicted from both input images: $\mathcal{G} = \mathcal{G}_1 \cup \mathcal{G}_2$ [S1, unofficial].
6.  **Rendering:** Render the Gaussians using differentiable rasterization to produce image $\hat{I}$ [S1, unofficial].
7.  **Loss Masking (Training Only):** Calculate a binary loss mask $M$ to restrict supervision to feasibly reconstructed regions:
    *   Unproject target image points to 3D.
    *   Reproject onto context images.
    *   Check if the pixel is inside the frustum of at least one context view.
    *   Check if the rendered depth matches the ground truth depth within a tolerance.
    *   $M_{ij} = 1$ if valid, $0$ otherwise [S1, unofficial].
8.  **Loss Calculation:** Compute the total loss $L$ using the mask $M$:
    $$ L = \lambda_{MSE} L_{MSE}(M \odot \hat{I}, M \odot I) + \lambda_{LPIPS} L_{LPIPS}(M \odot \hat{I}, M \odot I) $$
    where $L_{MSE}$ is Mean Squared Error and $L_{LPIPS}$ is Learned Perceptual Image Patch Similarity [S1, unofficial].

**Pseudocode:**

import torch
import torch.nn as nn
import torch.nn.functional as F

def splatt3r_forward(I1, I2, mast3r_backbone, gaussian_head):
    """
    Forward pass of Splatt3R.
    I1, I2: Input images [B, 3, H, W]
    Returns: List of Gaussian parameters for all pixels from both images.
    """
    # 1. Feature Encoding (Frozen MASt3R Backbone)
    features = mast3r_backbone.encode(I1, I2)
    
    # 2. Point Cloud Prediction (Frozen MASt3R Head)
    # Predicts 3D points and confidences in the coordinate frame of I1
    X1, C1 = mast3r_backbone.point_head(features['I1'])
    X2, C2 = mast3r_backbone.point_head(features['I2'])
    
    # 3. Gaussian Parameter Regression
    # Predicts offsets, rotations, scales, opacities, and colors
    # Gaussian Head runs in parallel to Point Cloud Head
    offsets = gaussian_head.predict_offsets(features)
    rotations = gaussian_head.predict_rotations(features)
    scales = gaussian_head.predict_scales(features)
    opacities = gaussian_head.predict_opacities(features)
    colors = gaussian_head.predict_colors(features)
    
    # 4. Construct Gaussians for Image 1
    # Mean: mu = x + delta
    mu1 = X1 + offsets['I1']
    # Covariance: Sigma = R(q) S(s) S(s)^T R(q)^T
    cov1 = gaussian_head.construct_covariance(rotations['I1'], scales['I1'])
    
    # 5. Construct Gaussians for Image 2
    # Note: X2 is also in I1's coordinate frame per MASt3R convention
    mu2 = X2 + offsets['I2']
    cov2 = gaussian_head.construct_covariance(rotations['I2'], scales['I2'])
    
    # 6. Union of Gaussians
    all_mu = torch.cat([mu1, mu2], dim=0)
    all_cov = torch.cat([cov1, cov2], dim=0)
    all_alpha = torch.cat([opacities['I1'], opacities['I2']], dim=0)
    all_color = torch.cat([colors['I1'], colors['I2']], dim=0)
    
    return all_mu, all_cov, all_alpha, all_color

def calculate_loss_mask(target_depth, context_depths, context_intrinsics, target_intrinsics):
    """
    Calculate loss mask M for a target view.
    M[i,j] = 1 if pixel (i,j) is visible and depth-consistent in context views.
    """
    # Unproject target points to 3D using target depth and intrinsics
    target_points_3d = unproject_depth(target_depth, target_intrinsics)
    
    mask = torch.zeros_like(target_depth, dtype=torch.bool)
    
    for context_depth, context_intr in zip(context_depths, context_intrinsics):
        # Reproject 3D points to context view
        u, v, z_ctx = project_3d_to_2d(target_points_3d, context_intr)
        
        # Check frustum: valid u, v coordinates
        in_frustum = (u >= 0) & (u < W) & (v >= 0) & (v < H)
        
        # Check depth consistency: compare projected depth z_ctx with context_depth at (u,v)
        # Sample context_depth at (u,v) using bilinear interpolation
        sampled_depth = bilinear_sample(context_depth, u, v)
        
        # Depth match: absolute difference within tolerance
        depth_match = torch.abs(z_ctx - sampled_depth) < TOLERANCE
        
        # Combine conditions
        valid_pixels = in_frustum & depth_match
        mask = mask | valid_pixels
        
    return mask

def train_step(I1, I2, target_images, target_depths, mast3r_backbone, gaussian_head, optimizer):
    """
    Single training step.
    """
    optimizer.zero_grad()
    
    # Forward pass
    mu, cov, alpha, color = splatt3r_forward(I1, I2, mast3r_backbone, gaussian_head)
    
    # Render novel views

    # Calculate loss masks for each target view
    loss_masks = []
    for target_img, target_depth in zip(target_images, target_depths):
        # Assuming context intrinsics are known or estimated for training supervision
        # In practice, ground truth poses/depths are used during training
        m = calculate_loss_mask(target_depth, context_depths, context_intrinsics, target_intrinsics)
        loss_masks.append(m)
        
    # Calculate masked losses
    total_loss = 0
    for rendered, target, mask in zip(rendered_images, target_images, loss_masks):
        masked_rendered = rendered * mask
        masked_target = target * mask
        
        mse_loss = F.mse_loss(masked_rendered, masked_target)

    total_loss.backward()
    optimizer.step()

**Parameters:**
*   **Input Resolution:** $512 \times 512$ pixels [S1, unofficial].
*   **Color Parameterization:** Constant, view-independent color $S \in \mathbb{R}^3$ is used in experiments. View-dependent spherical harmonics are ablated but supported [S1, unofficial].
*   **Overlap Thresholds:** Hyperparameters $\phi$ and $\psi$ control context/target selection during training.
    *   Close: $\phi=0.9, \psi=0.9$
    *   Medium: $\phi=0.7, \psi=0.7$
    *   Wide: $\phi=0.5, \psi=0.5$
    *   Very Wide: $\phi=0.3, \psi=0.3$ [S1, unofficial].
*   **Activation Functions:** Normalization for quaternions, exponential for scales and offsets, sigmoid for opacities [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Extrapolation Loss:** Supervising rendering loss for pixels not visible in context views (obscured or outside frustums) is counterproductive and destructive to performance. This is addressed by the loss masking strategy [S1, unofficial].
*   **Local Minima:** Unlike methods that predict depth distributions, Splatt3R directly supervises positions using ground-truth point clouds, providing a monotonic loss path to correct positions [S1, unofficial].

## Operating characteristics
*   **Speed:** Splatt3R reconstructs scenes at 4 FPS at $512 \times 512$ resolution. The resultant splats can be rendered in real-time [S1, unofficial].
*   **Performance:** On ScanNet++ test scenes with Close view overlap ($\phi=0.9, \psi=0.9$), Splatt3R achieves PSNR 19.66, SSIM 0.757, and LPIPS 0.234 [S1, unofficial].
*   **Strengths:**
    *   Pose-free: No camera intrinsics or extrinsics required.
    *   Generalizable: Trained on ScanNet++, generalizes to uncalibrated, in-the-wild images.
    *   Extrapolation: Can synthesize views beyond the stereo baseline, unlike many siblings that only interpolate [S1, unofficial].
*   **Limitations:**
    *   Relies on the quality of the frozen MASt3R backbone for initial point cloud estimation.
    *   Performance degrades with very wide baselines (low $\phi, \psi$), though it remains functional [S1, unofficial].
*   **When to use:** When camera parameters are unknown and a single forward pass is required for novel view synthesis from a stereo pair.
*   **When not to use:** When high-precision camera poses are available and per-scene optimization is acceptable (e.g., standard 3D-GS).

## Background
Splatt3R was introduced in 2024 by Brandon, Zheng, Iro, and Victor from the University of Oxford [S1, unofficial]. It builds upon the MASt3R foundation model for 3D geometry reconstruction [S1, unofficial]. The method addresses the limitations of existing generalizable 3D-GS methods (like pixelSplat and MVSplat) which typically restrict supervision to viewpoints between input stereo views, failing to learn extrapolation [S1, unofficial]. By extending MASt3R with a Gaussian head and a novel loss masking strategy, Splatt3R enables zero-shot Gaussian Splatting from uncalibrated image pairs [S1, unofficial].
