# 3D Skew-Normal Splatting

Also called: Skew-Normal Splatting

## Overview
3D Skew-Normal Splatting (SNS) replaces the standard symmetric 3D Gaussian kernel with the Azzalini Skew-Normal distribution to model directional asymmetry, sharp boundaries, and one-sided surfaces [S1, unofficial]. It sets itself apart from [Oriented Gaussian Splatting](9621-oriented-gaussian-splatting.md) by using a continuous skewness parameter rather than a hard half-space truncation, allowing smooth interpolation between symmetric Gaussians and half-ellipsoids while preserving analytical tractability under affine transformations [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ 3D Skew-Normal primitives, each defined by location $\mu_i \in \mathbb{R}^3$, scale matrix $\Omega_i \in \mathbb{R}^{3 \times 3}$, latent skew variable $k_i \in \mathbb{R}^3$, color $c_i$ (from SH coefficients), and opacity $o_i \in [-1, 1]$. Camera parameters (view matrix $V$, projection matrix $P$) and pixel coordinates $u$.
*   **Output:** Rendered image color $C(u)$ for each pixel.

**Data Structures:**
Each primitive $i$ stores:
*   $\mu_i$: 3D center (float32[3]).
*   $R_i$: Rotation matrix (float32[3,3], derived from quaternion or axis-angle).
*   $S_i$: Scale vector (float32[3], positive).
*   $\Omega_i = R_i S_i S_i^\top R_i^\top$: Scale matrix.
*   $x_i$: Scalar for skew magnitude (float32).
*   $v_i$: 3D vector for skew direction (float32[3]).
*   $c_i$: SH coefficients.
*   $o_i$: Signed opacity (float32).

**Parameters:**
*   Skew magnitude mapping: $m_k = \frac{8}{1 + \exp(-x/6)}$, where $x \in \mathbb{R}$ [S1, unofficial].
*   Skew direction: $d_k = \frac{v}{\|v\|_2 + \epsilon}$, where $v \in \mathbb{R}^3$ [S1, unofficial].
*   Latent skew variable: $k = m_k d_k$ [S1, unofficial].

**Steps:**

1.  **Compute 3D Skew-Normal Kernel:**
    Define the 3D Skew-Normal density for a point $x$:
    $$ SN(x; \mu, \Omega, k) = G_3(x - \mu; \Omega) \Phi \left( \alpha^\top \omega^{-1}(x - \mu) \right) $$
    where:
    *   $G_3(z; \Omega) = \exp \left( -\frac{1}{2} z^\top \Omega^{-1} z \right)$ is the Gaussian PDF kernel (unnormalized).
    *   $\Phi(\cdot)$ is the standard normal CDF.
    *   $\omega = (\Omega \odot I_3)^{1/2}$ is the diagonal matrix of scale matrix square roots.
    *   $\alpha = \omega R S^{-1} k$ is the decoupled slant parameter [S1, unofficial].
    *   $\odot$ is the Hadamard product [S1, unofficial].

2.  **Project to 2D Image Plane:**
    Compute the affine transformation matrix $A = JW \in \mathbb{R}^{2 \times 3}$, where $J$ is the Jacobian of the projection and $W$ is the view matrix [S1, unofficial].
    Compute 2D parameters:
    $$ \mu^{2D} = A \mu $$
    $$ \Omega^{2D} = A \Omega A^\top $$
    $$ m^{2D} = \frac{(\Omega^{2D})^{-1} A R S k}{\sqrt{1 + k^\top k} - (A R S k)^\top (\Omega^{2D})^{-1} A R S k} $$
    The 2D Skew-Normal kernel is:
    $$ SN^{2D}(u; \mu^{2D}, \Omega^{2D}, m^{2D}) = G_2(u - \mu^{2D}; \Omega^{2D}) \Phi \left( (m^{2D})^\top (u - \mu^{2D}) \right) $$
    where $G_2(z; \Omega^{2D}) = \exp \left( -\frac{1}{2} z^\top (\Omega^{2D})^{-1} z \right)$ [S1, unofficial].

3.  **Bounding Box Correction:**
    Because the location parameter $\mu$ does not coincide with the spatial mean, shift the bounding box center to the true spatial mean:
    $$ \mu_{bbox} = \mu^{2D} + \sqrt{\frac{2}{\pi}} \cdot \frac{A R S k}{\sqrt{1 + k^\top k}} $$
    Use $\mu_{bbox}$ and $\Omega^{2D}$ to determine the tile footprint for rasterization [S1, unofficial].

4.  **Rendering:**
    Sort primitives by depth. For each pixel $u$, aggregate color using signed opacity splatting:
    $$ C(u) = \sum_{i \in \mathcal{N}} c_i o_i SN_i^{2D}(u) \prod_{j=1}^{i-1} (1 - o_j SN_j^{2D}(u)) $$
    where $o_i \in [-1, 1]$ allows subtractive volumetric density [S1, unofficial].

5.  **Optimization:**
    *   **Phase 1:** Jointly optimize all parameters ($R, S, m_k, d_k$) using Adam to establish global structure [S1, unofficial].
    *   **Phase 2:** Use Block Coordinate Descent (BCD).
        *   Part 1: Update ellipsoidal base parameters ($R, S$) while freezing skew parameters ($m_k, d_k$).
        *   Part 2: Refine skew parameters ($m_k, d_k$) while holding ($R, S$) constant [S1, unofficial].
    *   **Positional Update:** Update $\mu$ using Stochastic Gradient Hamiltonian Monte Carlo (SGHMC) to escape local minima [S1, unofficial].

## Subtopics

### [2D Skew-Normal Parameter Projection](10052-2d-skew-normal-parameter-projection.md)
Computes the parameters of a 2D Skew-Normal distribution (SN2D) resulting from the linear projection of a 3D Skew-Normal kernel (SN3) onto the image plane. It sets apart from standard Gaussian splatting by preserving the asymmetry (skewness) of the 3D primitive during projection, allowing the 2D kernel to model one-sided surfaces and sharp boundaries that symmetric Gaussians cannot.

## Operating characteristics
*   **Time Complexity:** Comparable to [Oriented Gaussian Splatting](9621-oriented-gaussian-splatting.md) and standard 3DGS, with overhead from computing the CDF $\Phi$ and the additional skew parameters [S1, unofficial].
*   **Memory Complexity:** Slightly higher than 3DGS due to storing skew parameters ($k$ or $m_k, d_k$) [S1, unofficial].
*   **Performance:** On Mip-NeRF360, SNS achieves 30.17 PSNR, 0.895 SSIM, 0.144 LPIPS, outperforming SSS (29.90 PSNR) and 3DGS (28.69 PSNR) [S1, unofficial]. On the drjohnson scene, SNS completes 30,000 iterations in 38m 4s (29.89 dB PSNR), comparable to SSS (38m 7s, 29.66 dB PSNR) [S1, unofficial].
*   **Strengths:** Continuous shape interpolation, bounded skewness prevents excessive tile intersection, analytical tractability under affine transformations [S1, unofficial].
*   **Limitations:** Optimization instability due to coupling between scale, rotation, and skewness requires complex decoupling and block-wise optimization [S1, unofficial].
*   **When to use:** Scenes with sharp boundaries, flat surfaces, or one-sided structures where symmetric Gaussians require many overlapping kernels [S1, unofficial].
*   **When not to use:** Scenes with highly symmetric structures where the overhead of skew parameters is unnecessary [S1, unofficial].

## Background
3D Skew-Normal Splatting was introduced in the paper "3D Skew-Normal Splatting" (2026) [S1, unofficial]. It builds on the Azzalini Skew-Normal distribution, which provides directional asymmetry through a slant parameter $\alpha$. The method addresses the limitations of standard Gaussian Splatting in modeling asymmetric structures by introducing a learnable, bounded skewness parameter. It was implemented in PyTorch, extending the 3DGS rasterization engine, and tested on NVIDIA RTX A6000 GPUs [S1, unofficial].
