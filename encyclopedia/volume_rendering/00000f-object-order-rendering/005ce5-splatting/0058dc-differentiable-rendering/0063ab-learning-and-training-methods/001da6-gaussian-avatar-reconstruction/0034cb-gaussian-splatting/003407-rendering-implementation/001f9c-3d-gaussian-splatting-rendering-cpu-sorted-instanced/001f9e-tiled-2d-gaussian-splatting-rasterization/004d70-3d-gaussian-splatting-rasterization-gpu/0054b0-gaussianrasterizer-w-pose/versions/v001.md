# GaussianRasterizer_w_pose


## Overview
A variant of the Gaussian rasterizer that accepts camera rotation and translation deltas to render the scene with pose perturbations, returning an additional count of touched pixels (`n_touched`) [S1, unofficial]. It differs from the standard [3D Gaussian Splatting Rasterization (GPU)](13469-3d-gaussian-splatting-rasterization-gpu.md) by exposing pose perturbation inputs and tracking pixel coverage statistics for optimization feedback.

## How it works
**Inputs:**
- `means3D`: 3D Gaussian means, shape $(N, 3)$.
- `means2D`: 2D projected means, shape $(N, 2)$, initialized with `requires_grad=True` and `retain_grad()` [S1, unofficial].
- `shs` or `colors_precomp`: Spherical Harmonics coefficients or precomputed RGB colors.
- `opacities`: Opacity values, shape $(N, 1)$.
- `scales` and `rotations`: Scale and rotation parameters, or `cov3D_precomp` if `pipe.compute_cov3D_python` is true [S1, unofficial].
- `theta`, `rho`: Camera rotation and translation deltas [S1, unofficial].
- `viewpoint_cam`: Camera object providing FoV and projection matrix.
- `pipe`: Configuration object controlling SH evaluation and covariance computation [S1, unofficial].

**Outputs:**
- Dictionary with keys: `render` (image), `viewspace_points` (means2D), `visibility_filter` (boolean mask), `radii`, `rendered_depth`, `rendered_alpha`, `n_touched` [S1, unofficial].

**Steps:**
1. Initialize `screenspace_points` tensor with `requires_grad=True` and call `retain_grad()` to enable gradients for 2D means [S1, unofficial].
2. Compute `tanfovx` and `tanfovy` from `viewpoint_cam.FoVx` and `viewpoint_cam.FoVy` [S1, unofficial].
3. Construct `GaussianRasterizationSettings_w_pose` with `projmatrix_raw`, `sh_degree`, `campos`, and `prefiltered=False` [S1, unofficial].
4. Instantiate `GaussianRasterizer_w_pose` with the settings [S1, unofficial].
5. Determine covariance representation: if `pipe.compute_cov3D_python` is true, compute `cov3D_precomp` from `pc.get_covariance(scaling_modifier)`; otherwise, pass `scales` and `rotations` separately [S1, unofficial].
6. Determine color representation: if `override_color` is None and `pipe.convert_SHs_python` is true, convert SHs to RGB in Python using `eval_sh` and clamp; otherwise, pass `shs` directly [S1, unofficial].
7. Call the rasterizer with `means3D`, `means2D`, `shs/colors_precomp`, `opacities`, `scales/rotations/cov3D_precomp`, and pose deltas `theta` and `rho` [S1, unofficial].

```python
def render_w_pose(means3D, means2D, shs, opacities, scales, rotations, 
                  viewpoint_cam, pipe, theta, rho, override_color=None):
    # Step 1: Initialize screenspace_points for gradient tracking
    screenspace_points = means2D.clone().detach()
    screenspace_points.requires_grad = True
    screenspace_points.retain_grad()
    
    # Step 2: Compute tanfovx and tanfovy
    tanfovx = torch.tan(viewpoint_cam.FoVx * 0.5)
    tanfovy = torch.tan(viewpoint_cam.FoVy * 0.5)
    
    # Step 3: Construct rasterization settings
    raster_settings = GaussianRasterizationSettings_w_pose(
        image_height=int(viewpoint_cam.image_height),
        image_width=int(viewpoint_cam.image_width),
        tanfovx=tanfovx,
        tanfovy=tanfovy,
        projmatrix_raw=viewpoint_cam.projection_matrix @ viewpoint_cam.world_view_transform,
        sh_degree=pipe.SH_degree,
        campos=viewpoint_cam.camera_center,
        prefiltered=False,
        debug=False
    )
    
    # Step 4: Instantiate rasterizer
    rasterizer = GaussianRasterizer_w_pose(raster_settings=raster_settings)
    
    # Step 5: Determine covariance representation
    if pipe.compute_cov3D_python:
        cov3D_precomp = pc.get_covariance(scaling_modifier=1.0) # [G] scaling_modifier assumed 1.0 if not specified
    else:
        cov3D_precomp = None
        
    # Step 6: Determine color representation
    if override_color is None and pipe.convert_SHs_python:
        colors_precomp = torch.clamp(eval_sh(pipe.SH_degree, shs, means3D), 0.0, 1.0)
    else:
        colors_precomp = shs if override_color is None else override_color
        
    # Step 7: Call rasterizer
    render_pkg = rasterizer(
        means3D=means3D,
        means2D=means2D,
        shs=colors_precomp,
        opacities=opacities,
        scales=scales,
        rotations=rotations,
        cov3D_precomp=cov3D_precomp,
        theta=theta,
        rho=rho
    )
    
    return render_pkg
```
