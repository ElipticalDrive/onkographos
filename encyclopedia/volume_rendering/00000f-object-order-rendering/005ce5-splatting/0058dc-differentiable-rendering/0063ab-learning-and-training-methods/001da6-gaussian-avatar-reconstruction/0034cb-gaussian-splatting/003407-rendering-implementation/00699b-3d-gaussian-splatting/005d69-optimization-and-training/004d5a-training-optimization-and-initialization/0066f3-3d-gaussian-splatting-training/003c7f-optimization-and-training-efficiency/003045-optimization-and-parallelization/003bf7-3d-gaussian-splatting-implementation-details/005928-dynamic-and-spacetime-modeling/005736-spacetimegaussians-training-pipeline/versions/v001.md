# SpacetimeGaussians Training Pipeline


## Overview
The SpacetimeGaussians training pipeline is a specific implementation of the optimization schedule for dynamic 3D Gaussian Splatting, designed to handle spatiotemporal data by integrating motion parameters and time-dependent rendering into the standard densification and pruning workflow [S1, unofficial]. It distinguishes itself from static Gaussian Splatting implementations by managing time tensors, motion-specific regularization terms, and iteration-dependent freezing of motion parameters to stabilize dynamic view synthesis [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** Dataset object containing scene metadata; optimization options (`opt`) including thresholds for densification, pruning, and regularization weights; rendering pipeline option string.
*   **Outputs:** Optimized Gaussian model (positions, covariances, opacities, colors, motion parameters) and background tensor.

**Data Structures**
*   **Background Tensor:** Shape `(numchannels,)`, dtype `torch.float32`, device `cuda`. Initialized to zeros. `numchannels` defaults to 9 [S1, unofficial].
*   **Time Tensor (`gaussians.ts`):** Shape `(1, 1, H, W)`, dtype `torch.float32`, device `cuda`. Initialized to ones if `gaussians.ts` is None, where $H$ and $W$ are derived from the first test camera [S1, unofficial].
*   **Gaussian Model:** Contains `_xyz`, `_rotation`, `_scaling`, `_opacity`, `_features_dc`, `_features_rest`, and motion-specific parameters like `_omega` [S1, unofficial].

**Rendering Pipeline Selection**
The pipeline retrieves the rasterizer and settings based on the `option` string [S1, unofficial]:
*   `train_ours_full`: Uses `diff_gaussian_rasterization_ch9` (9 channels).
*   `train_ours_lite`: Uses `diff_gaussian_rasterization_ch3` (3 channels).
*   `train_ours_fullss`: Uses `diff_gaussian_rasterization_ch9`.
*   `train_ours_litess`: Uses `diff_gaussian_rasterization_ch3` [S1, unofficial].

**Training Steps**
1.  **Initialization:**
    *   Initialize the Gaussian model using `getmodel(dataset.model)` with SH degree and RGB function [S1, unofficial].
    *   Load scene data into a `Scene` object with `shuffle=False`, `multiview=multiview`, `duration=duration`, and the selected `loader` [S1, unofficial].
    *   Initialize `background` tensor to zeros [S1, unofficial].
    *   If `gaussians.ts` is None, initialize it as a tensor of ones with shape `(1, 1, H, W)` [S1, unofficial].
    *   If `gaussians.rgbdecoder` is not None, move it to CUDA and set it to eval mode [S1, unofficial].
    *   Retrieve rendering pipeline components (`train_func`, `RasterizationSettings`, `Rasterizer`) via `getrenderpip(option)` [S1, unofficial].

2.  **Iteration Loop:**
    For each iteration `i`:
    *   **Motion Freezing (n3d mode, `densify == 1`):**
        *   At iteration 8001, compute `omegamask` by calling `gaussians.zero_omegabymotion()` to determine which Gaussians retain motion parameters [S1, unofficial]. Store this in `gaussians.omegamask` [S1, unofficial].
        *   For iterations > 8001, freeze weights for `_omega` using `omegamask` and freeze weights for `_rotation` using `~omegamask` via `freezweightsbymasknounsqueeze` [S1, unofficial].
    *   **Densification and Pruning:**
        *   If `densify == 1` (n3d mode):
            *   If `iteration > opt.densify_from_iter` and `iteration % opt.densification_interval == 0` and `flag < opt.desicnt`:
                *   Perform densification via `gaussians.densify_pruneclone(opt.densify_grad_threshold, opt.opthr, scene.cameras_extent, size_threshold)` [S1, unofficial].
                *   `size_threshold` is 20 if `iteration > opt.opacity_reset_interval`, else `None` [S1, unofficial].
            *   If `flag >= opt.desicnt` and `iteration < 7000`:
                *   Prune points with opacity below `opt.opthr` [S1, unofficial].
            *   Every 3000 iterations, reset opacity via `gaussians.reset_opacity()` [S1, unofficial].
            *   If `iteration >= opt.densify_until_iter`:
                *   Freeze `_omega` and `_rotation` weights as described above [S1, unofficial].
                *   If `iteration % 1000 == 500`, prune points where `gaussians._xyz[:,2] < 4.5` [S1, unofficial].
        *   If `densify == 3`:
            *   Update `max_radii2D` and `add_densification_stats` every iteration [S1, unofficial].
            *   Densify/prune clones at intervals [S1, unofficial].
            *   Prune low-opacity points if `iteration < 7000` [S1, unofficial].
            *   Reset opacity every `opt.opacity_reset_interval` [S1, unofficial].
            *   At iteration 10000, call `removeminmax` [S1, unofficial].
        *   If `densify == 1` (specific variant note): Prune points where `gaussians._xyz[:,2] < 4.5` at iteration 1000 [S1, unofficial].
    *   **Rendering:**
        *   Render the current view using the selected rasterizer. Pass `scaling_modifier=1.0` and `basicfunction=trbfunction` [S1, unofficial].
        *   Pass `GRsetting` and `GRzer` from the retrieved pipeline [S1, unofficial].
    *   **Loss Calculation:**
        *   Compute loss $L$ based on `opt.reg` [S1, unofficial]:
            *   $L_{L1}$: L1 loss between rendered image $I$ and ground truth $I_{gt}$.
            *   $SSIM$: Structural Similarity Index.
            *   $\mathbf{g}_{\text{motion}}$: Motion gradient term.
            *   $\mathbf{g}_{\omega}$: Omega gradient term.
            *   $\mathbf{g}_{\text{scaling}}$: Scaling gradient term.
            *   $N$: Number of Gaussians.
            *   $\bar{x}$: Mean of image.
            *   $x$: Image pixel.
            *   $r$: Clamped value.
            *   Formulas:
                *   `reg=1`: $L = (1 - \text{opt.lambda_dssim}) L_{L1} + \text{opt.lambda_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \frac{\sum \mathbf{g}_{\text{motion}}}{N}$ [S1, unofficial].
                *   `reg=9`: $L = (1 - \text{opt.lambda_dssim}) L_{L1} + \text{opt.lambda_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \sum_{r>0} \mathbf{g}_{\omega}^2$ [S1, unofficial].
                *   `reg=10`: $L = (1 - \text{opt.lambda_dssim}) L_{L1} + \text{opt.lambda_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \sum_{r>0} \mathbf{g}_{\text{motion}}^2$ [S1, unofficial].
                *   `reg=4`: $L = (1 - \text{opt.lambda_dssim}) L_{L1} + \text{opt.lambda_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \frac{\sum \mathbf{g}_{\text{scaling}}}{N}$ [S1, unofficial].
                *   `reg=6`: $L = (1 - r) L_{L1} + r (1 - \text{SSIM}(I, I_{gt}))$ where $r = \text{clamp}(\text{mean}(I_{gt}) - 0.5 + \text{opt.lambda_dssim}, 0, 1)$ [S1, unofficial].
                *   `reg=7`: $L_{L1}$ is normalized by $2 \cdot \text{mean}(I_{gt})$ [S1, unofficial].
                *   `reg=8`: $L = (1 - \text{opt.lambda_dssim}) L_{L1} + 0.0002 \cdot \text{opt.lambda_dssim} \frac{\sum (\bar{x} - x)^2}{N}$ [S1, unofficial].
    *   **Optimization Step:**
        *   Backpropagate and update parameters [S1, unofficial].

**Parameters**
*   `numchannels`: Number of channels for background color. Default: 9 [S1, unofficial].
*   `scaling_modifier`: Passed to render function. Default: 1.0 [S1, unofficial].
*   `basicfunction`: Passed to render function. Default: `trbfunction` [S1, unofficial].
*   `size_threshold`: Threshold for densification. Set to 20 if `iteration > opt.opacity_reset_interval`, else `None` [S1, unofficial].
*   `opt.densify_until_iter`, `opt.densify_from_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, `opt.opthr`: Control thresholds and intervals [S1, unofficial].

**Edge Cases and Pitfalls**
*   If `gaussians.rgbdecoder` is not None, it must be moved to CUDA and set to eval mode before rendering [S1, unofficial].
*   Pruning logic differs based on densification phase: before `opt.desicnt` is reached, densification is performed; after, pruning is based on opacity threshold if iteration < 7000; after `opt.densify_until_iter`, pruning is based on Z-coordinate < 4.5 if iteration % 1000 == 500 [S1, unofficial].

## Subtopics

### SpacetimeGaussians Densification & Pruning Schedule
A training iteration schedule that controls Gaussian densification, pruning, and parameter freezing based on iteration count, mode selection, and visibility metrics [S1, unofficial]. It supports multiple densification modes (`densify` parameter: 0, 1, 2, or 3) [S1, unofficial]. In mode 1, it prunes points where `gaussians._xyz[:,2] < 4.5` at iteration 1000 and resets opacity every 3000 iterations [S1, unofficial]. In mode 3, it updates `max_radii2D` and `add_densification_stats` every iteration, densifies/prunes clones at intervals, prunes low-opacity points if iteration < 7000, resets opacity every `opt.opacity_reset_interval`, and calls `removeminmax` at iteration 10000 [S1, unofficial]. Key parameters include `size_threshold` (20 if `iteration > opt.opacity_reset_interval`, else `None`), `opt.densify_until_iter`, `opt.densify_from_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, and `opt.opthr` [S1, unofficial].

## Background
The SpacetimeGaussians training pipeline originates from the paper "Spacetime Gaussian Feature Splatting for Real-Time Dynamic View Synthesis" by Zhan Li, Zhang Chen, Zhong Li, and Yi Xu, published in the Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR) in June 2024 [S1, unofficial]. It builds upon the 3D Gaussian Splatting framework [S1, unofficial].
