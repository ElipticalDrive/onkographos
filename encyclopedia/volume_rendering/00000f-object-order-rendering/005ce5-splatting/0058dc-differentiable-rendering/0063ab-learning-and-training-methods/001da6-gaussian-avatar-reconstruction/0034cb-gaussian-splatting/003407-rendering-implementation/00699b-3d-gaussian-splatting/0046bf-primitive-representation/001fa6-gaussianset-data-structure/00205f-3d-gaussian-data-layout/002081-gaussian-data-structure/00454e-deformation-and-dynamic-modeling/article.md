# Deformation and Dynamic Modeling

Also called: Dynamic 3D Gaussian Splatting, Time-varying Gaussian Splatting, Spacetime Gaussians

## Overview
Deformation and Dynamic Modeling extends static 3D Gaussian Splatting to represent and render time-varying scenes by predicting time-dependent deformation deltas for canonical Gaussian parameters [S1, unofficial]. It solves the problem of reconstructing moving objects (e.g., people, fluids) from multi-view video or casual capture, enabling real-time rendering of dynamic content [S1, unofficial]. It sets itself apart from static methods by introducing a temporal dimension $t$ that modulates the geometry (position, rotation, scale) of the Gaussian set, distinguishing it from sibling methods like [Sparse-Controlled 3D Gaussian Splatting](6145-sparse-controlled-3d-gaussian-splatting.md) which use sparse control points, or [Deformable Radial Kernel](13703-deformable-radial-kernel-drk-parametrization.md) which modifies the kernel shape.

## Shared principles
All methods in this family operate on a set of canonical 3D Gaussians $\mathcal{G}_{canon}$, where each Gaussian $i$ has static base parameters $(\boldsymbol{\mu}_i, \mathbf{q}_i, \mathbf{s}_i, \alpha_i, \mathbf{c}_{SH,i})$ [S1, unofficial]. The core mechanism involves a deformation function $f_\theta$ that takes canonical features and a time parameter $t \in [0, 1]$ to predict deltas $(\Delta\boldsymbol{\mu}_i, \Delta\mathbf{q}_i, \Delta\mathbf{s}_i)$ [S1, unofficial]. The time-varying parameters are computed as:
$$ \boldsymbol{\mu}_i(t) = \boldsymbol{\mu}_i + \Delta\boldsymbol{\mu}_i $$
$$ \mathbf{q}_i(t) = \text{Normalize}(\mathbf{q}_i \otimes \Delta\mathbf{q}_i) $$
$$ \mathbf{s}_i(t) = \mathbf{s}_i + \Delta\mathbf{s}_i $$
where $\otimes$ is quaternion multiplication and normalization prevents drift [G]. The rendered image is generated by rasterizing $\mathcal{G}(t)$ using standard differentiable rasterization with camera pose and time $t$ [S1, unofficial]. Optimization minimizes photometric loss $\mathcal{L} = \mathcal{L}_{rec} + \lambda \mathcal{L}_{reg}$, updating canonical parameters, features, and network weights via SGD .

## Subtopics

### [Sparse-Controlled 3D Gaussian Splatting](6145-sparse-controlled-3d-gaussian-splatting.md)
Uses sparse user-provided control points with influence weights to drive deformation via locally interpolated 6 DoF transformations, offering a compact and editable representation. Choose when explicit user control or sparse editing is required.

### [Deformable 3DGS](6866-deformable-3dgs.md)
Uses a dense deformation network (MLP or HexPlane) to predict deltas directly from canonical features and time, trading flexibility for computational overhead. Choose for general dynamic scene reconstruction without sparse control constraints.

### Drive-GS
End-to-end driving simulators that integrate dynamic Gaussian modeling for autonomous driving contexts [S1, unofficial].

### 4D-Driving-GS
Drives time-of-day and weather conditioning for closed-loop simulation in autonomous driving scenarios [S1, unofficial].

### D-MiSo
A motion-aware optimization method using sparse control trajectories to handle dynamic scenes [S1, unofficial].

## Background
Originated from the need to extend 3D Gaussian Splatting to dynamic scenes, with early works like GaussianFlow and MoSca introducing temporal regularization and priors [S1, unofficial]. The field has evolved to include specialized variants for autonomous driving (Drive-GS, 4D-Driving-GS) and monocular capture (Shape-of-Motion) [S1, unofficial]. By 2026, per-actor and per-scene Gaussian decomposition became dominant for AV simulation, supporting closed-loop simulators for companies like Tesla and Waymo [S1, unofficial].
