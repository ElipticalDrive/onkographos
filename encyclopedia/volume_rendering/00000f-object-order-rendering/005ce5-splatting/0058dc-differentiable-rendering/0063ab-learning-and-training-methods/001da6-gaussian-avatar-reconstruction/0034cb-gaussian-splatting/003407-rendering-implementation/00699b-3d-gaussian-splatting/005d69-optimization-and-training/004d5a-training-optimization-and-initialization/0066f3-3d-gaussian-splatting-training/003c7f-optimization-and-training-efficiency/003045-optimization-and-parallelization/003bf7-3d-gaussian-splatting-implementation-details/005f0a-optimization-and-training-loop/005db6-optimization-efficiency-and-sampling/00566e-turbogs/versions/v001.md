# TurboGS

Also called: Error-guided training framework for 3DGS

## Overview
TurboGS is an error-guided training framework for 3D Gaussian Splatting (3DGS) that accelerates optimization by dynamically focusing computation on perceptually informative pixels, addressing redundant computation in well-reconstructed regions and loss of fine details [S1, unofficial]. It differs from standard 3DGS by replacing dense per-pixel rasterization and supervision with a sparse, error-guided sampling strategy that adaptively reallocates computation from easy regions to challenging ones [S1, unofficial].

## How it works
TurboGS reduces rasterization cost while maintaining quality by executing the standard 3DGS training loop only on a sparse set of pixels selected via error and age maps [S1, unofficial].

**Inputs and Outputs**
*   **Inputs:** Calibrated multiview images $\{I_v\}$, cameras $\{C_v\}$, initial Gaussian primitives $G_0$ derived from Structure-from-Motion (SfM), total training iterations $T$, view budget range $[K_{min}, K_{max}]$, and hyperparameters $\Theta$ [S1, unofficial].
*   **Outputs:** Optimized Gaussian primitives $G$ [S1, unofficial].

**Data Structures**
*   **Error Map ($E_v$):** Stored in contiguous GPU memory with half precision (float16). Initialized by densely evaluating error for $G_0$ [S1, unofficial].
*   **Age Map ($A_v$):** Stored in contiguous GPU memory with uint16 precision. Tracks how long it has been since a pixel was last sampled [S1, unofficial].
*   **View Stack:** A shuffled list of candidate view indices used for geometry-aware sampling [S1, unofficial].

**Parameters**
*   **Tile Size ($S$):** Typically $16 \times 16$ pixels [S1, unofficial].
*   **Pixel Sampling Rate ($r_t$):** Controls the number of pixels sampled per tile [S1, unofficial].
*   **Number of Views ($K$):** Number of views sampled per iteration [S1, unofficial].
*   **EMA Decay ($\beta$):** Decay factor for the error map exponential moving average [S1, unofficial].
*   **Geometry-aware Weights ($\lambda_d, \lambda_\theta$):** Weights for camera position and viewing direction in view selection [S1, unofficial].
*   **Hard/Stable Fractions ($r_{hard}, r_{stable}$):** Fractions of pixels allocated to hard and stable sets [S1, unofficial].
*   **Effective Learning Rate Scaling ($\lambda_{base}$):** Base scaling factor for the difficulty score [S1, unofficial].

**Algorithm Steps**

1.  **Initialization:** Initialize error maps $E$ using initial Gaussians $G_0$, cameras $C$, and images $I$ [S1, unofficial].
2.  **Iteration Loop:** For each iteration $t$ from $0$ to $T-1$:
    a.  **Progress Coefficient:** Compute $\rho = \min(1, t/\tau_{until})$ [S1, unofficial].
    b.  **Sampling Schedule:** Query the sampling schedule to get view budget $K_t$ and pixel sampling rate $r_t$ based on $K_{max}, K_{min}, E_{init}, \Theta$, and $t$ [S1, unofficial].
    c.  **View Selection:** Perform geometry-aware view selection to obtain view set $V_t$ of size $K_t$ [S1, unofficial].
        i.  **Anchor View:** Select anchor view $v^*$ with the highest average error:
            $$v^* = \arg \max_v \bar{E}_v, \quad \bar{E}_v = \frac{1}{|\Omega|} \sum_{p \in \Omega} E_v(p)$$
            [S1, unofficial]
        ii. **Neighbor Views:** Sample $K-1$ remaining views without replacement from a candidate stack using geometry-aware distribution:
            $$\pi(u | v^*) \propto \exp(-\lambda_d \|c_u - c_{v^*}\|^2 - \lambda_\theta (1 - \langle d_u, d_{v^*} \rangle))$$
            where $c_u, d_u$ are camera center and viewing direction of view $u$ [S1, unofficial].
        iii. **Stack Management:** Maintain a shuffled view stack. Pop sampled indices. Refill and reshuffle stack when fewer than $K$ views remain [S1, unofficial].
    d.  **Tile-Wise Sparse Pixel Sampling:** For each view $v \in V_t$, sample pixel set $P_{t,v}$ [S1, unofficial].
        i.  Partition image into tiles of size $S \times S$.
        ii. Compute number of pixels per tile: $N_{pix} = \max(1, \lfloor r_t \cdot S^2 \rfloor)$ [S1, unofficial].
        iii. Split $N_{pix}$ into hard set size $N_{hard} = \lceil r_{hard} \cdot N_{pix} \rceil$ and stable set size $N_{stable} = \lfloor r_{stable} \cdot N_{pix} \rfloor$, such that $N_{hard} + N_{stable} \le N_{pix}$ [S1, unofficial].
        iv. **Hard Pixels:** For each tile $\tau$, select $N_{hard}$ pixels with largest errors using distribution:
            $$\pi_E(p | \tau, v) = \frac{E_v(p)}{\sum_{q \in \tau} E_v(q) + \epsilon}$$
            Let $H_{t,v}(\tau)$ be the selected hard pixels [S1, unofficial].
        v.  **Stable Pixels:** Select $N_{stable}$ pixels with largest ages from remaining pixels $\tau \setminus H_{t,v}(\tau)$:
            $$S_{t,v}(\tau) = \text{TopK}_{p \in \tau \setminus H_{t,v}(\tau)} (A_v(p), N_{stable})$$
            [S1, unofficial]
        vi. **Final Set:** $P_{t,v}(\tau) = H_{t,v}(\tau) \cup S_{t,v}(\tau)$. Full set $P_{t,v} = \bigcup_\tau P_{t,v}(\tau)$ [S1, unofficial].
    e.  **Sparse Forward Rasterization:** Output sampled pixels in tile order. Compute tile-wise pixel offsets via prefix-sum. Each CUDA block (tile) accesses sparse pixels to render colors $\hat{I}_{t,v}(p)$ and depth $d$ [S1, unofficial].
    f.  **Loss Evaluation:** Calculate per-pixel reconstruction error:
        $$e_{t,v}(p) = \|\hat{I}_{t,v}(p) - I_v(p)\|_1$$
        [S1, unofficial]
        Compute tile-level NCC loss for structure preservation:
        $$L_{\tau}^{S-NCC} = 1 - \text{NCC}(\hat{I}_{t,v}(P_{t,v}(\tau)), I_v(P_{t,v}(\tau)))$$
        [S1, unofficial]
        Compute gradient-balanced weighting for NCC:
        $$\bar{g}_{\ell_1}^\tau = \mathbb{E}_{p \in P_{t,v}(\tau)} \|\nabla_{\hat{I}}(p) L_{\tau}^{\ell_1}\|_1, \quad \bar{g}_{S-NCC}^\tau = \mathbb{E}_{p \in P_{t,v}(\tau)} \|\nabla_{\hat{I}}(p) L_{\tau}^{S-NCC}\|_1$$
        $$\lambda_{\tau}^{ncc} = \text{clip}\left(\frac{\bar{g}_{\ell_1}^\tau}{\bar{g}_{S-NCC}^\tau + \epsilon}, 0, 1\right)$$
        [S1, unofficial]
    g.  **EMA Updates:**
        i.  **Error Map:** Update only for sampled pixels:
            $$E_v(p) \leftarrow (1-\beta)E_v(p) + \beta e_{t,v}(p) \quad \text{for } p \in P_{t,v}$$
            [S1, unofficial]
        ii. **Age Map:** Increment age globally, reset sampled pixels:
            $$A_v(p) \leftarrow \begin{cases} 0 & p \in P_{t,v} \\ A_v(p) + 1 & \text{otherwise} \end{cases}$$
            [S1, unofficial]
    h.  **Gaussian Backward Pass:** Retrieve sparse pixels within each tile through tile-pixel indexing. Propagate gradients via warp shuffle only over sampled pixels to get $\nabla G$ and screen radii $r$ [S1, unofficial].
    i.  **Hybrid Solver (Moment-Damped LM):** For each Gaussian $g$, solve local equation:
        $$(J_g^T J_g + \text{diag}(\sqrt{v_g} + \epsilon)) \Delta g = -m_g$$
        where $m_g, v_g$ are Adam moments, $J_g$ is local Jacobian [S1, unofficial].
    j.  **Error-Driven Density Control:**
        i.  Back-project pixel properties to Gaussians to get per-Gaussian error $e_G$, distance $D_G$, and alpha $\alpha_G$ [S1, unofficial].
        ii. Normalize statistics by visibility $W_i = \sum_{v,p} w_{t,i}(p)$:
            $$e_i(t) = E_i(t) / (W_i(t) + \epsilon), \quad d_i(t) = D_i(t) / (W_i(t) + \epsilon)$$
            [S1, unofficial]
        iii. Compute difficulty score:
            $$s_i = e_i(t) + \lambda_{eff} d_i(t), \quad \lambda_{eff} = \lambda_{base}(1 - \rho_t)$$
            [S1, unofficial]
        iv. Perform densification and pruning based on screen radii, back-projected properties, $t$, and $\Theta$ [S1, unofficial].
    k.  **Apply Update:** Update Gaussians $G$ with $\Delta G$ [S1, unofficial].

**Pseudocode**

```python
def turbogs_train(Images I, Cameras C, Gaussians G, Iterations T, 
                  K_min, K_max, Theta, tau_until):
    # Initialization
    E = initialize_error_maps(G, C, I) # Dense evaluation for G0
    A = zeros_like(E, dtype=uint16)   # Age maps
    ViewStack = shuffle(range(len(I)))
    
    for t in range(T):
        rho = min(1.0, t / tau_until)
        
        # 1. Sampling Parameters
        K_t, r_t = query_sampling_schedule(K_max, K_min, E, Theta, t)
        
        # 2. View Selection
        # Anchor view: highest average error
        avg_errors = [mean(E[v]) for v in range(len(I))]
        v_star = argmax(avg_errors)
        
        # Neighbor views: geometry-aware sampling
        V_t = [v_star]
        remaining_views = [v for v in range(len(I)) if v != v_star]
        
        # Pop from stack if available, else refill
        if len(ViewStack) < K_t:
            ViewStack = shuffle(range(len(I)))
        
        for _ in range(K_t - 1):
            if len(ViewStack) == 0:
                ViewStack = shuffle(range(len(I)))
            u = ViewStack.pop()
            
            # Compute geometry-aware probability
            # pi(u | v*) proportional to exp(-lambda_d * ||c_u - c_v*||^2 - lambda_theta * (1 - <d_u, d_v*>))
            # Sample without replacement from remaining_views based on pi
            u = sample_geometry_aware(remaining_views, v_star, lambda_d, lambda_theta)
            V_t.append(u)
            remaining_views.remove(u)
            
        # 3. Tile-Wise Pixel Sampling
        P_t = {}
        for v in V_t:
            P_t[v] = []
            for tile tau in tiles:
                N_pix = max(1, floor(r_t * S * S))
                N_hard = ceil(r_hard * N_pix)
                N_stable = floor(r_stable * N_pix)
                
                # Hard pixels: top error
                errors_in_tile = [E[v][p] for p in pixels_in_tile(tau)]
                H = top_k_by_value(errors_in_tile, N_hard)
                
                # Stable pixels: top age from remaining
                remaining_pixels = pixels_in_tile(tau) - H
                ages_in_tile = [A[v][p] for p in remaining_pixels]
                S = top_k_by_value(ages_in_tile, N_stable)
                
                P_t[v].extend(H + S)
                
        # 4. Sparse Forward Rendering
        # Output sampled pixels in tile order
        # Compute tile-wise pixel offsets via prefix-sum
        I_hat, depth = sparse_rasterize_forward(G, V_t, P_t)
        
        # 5. Loss Evaluation
        L_pix = 0
        for v in V_t:
            for p in P_t[v]:
                e_p = l1_loss(I_hat[v][p], I[v][p])
                L_pix += e_p
                
            # Tile-level NCC
            for tile tau in tiles:
                pixels_tau = P_t[v] intersect pixels_in_tile(tau)
                L_ncc_tau = 1 - ncc(I_hat[v][pixels_tau], I[v][pixels_tau])
                
                # Gradient-balanced weighting
                g_l1 = mean(grad_norm(I_hat[v][pixels_tau], L_l1))
                g_ncc = mean(grad_norm(I_hat[v][pixels_tau], L_ncc_tau))
                lambda_ncc = clip(g_l1 / (g_ncc + eps), 0, 1)
                
                L_pix += lambda_ncc * L_ncc_tau
                
        # 6. EMA Updates
        for v in V_t:
            for p in P_t[v]:
                e_p = l1_loss(I_hat[v][p], I[v][p])
                E[v][p] = (1 - beta) * E[v][p] + beta * e_p
                A[v][p] = 0
            for p in all_pixels_not_in(P_t[v]):
                A[v][p] += 1
                
        # 7. Gaussian Backward Pass
        # Retrieve sparse pixels, propagate gradients via warp shuffle
        grad_G = sparse_rasterize_backward(I_hat, I, P_t, grad_L_pix)
        screen_radii = compute_screen_radii(grad_G, G)
        
        # 8. Hybrid Solver
        for g in G:
            m_g, v_g = adam_moments(g)
            J_g = local_jacobian(g, P_t)
            # Solve (J_g^T J_g + diag(sqrt(v_g) + eps)) Delta_g = -m_g
            Delta_g = solve_linear_system(J_g, v_g, m_g)
            g += Delta_g
            
        # 9. Error-Driven Density Control
        # Back-project properties
        e_G, D_G, alpha_G = back_project_properties(G, P_t, I_hat, I)
        
        # Compute difficulty scores
        for g in G:
            W_g = visibility_sum(g)
            e_i = e_G[g] / (W_g + eps)
            d_i = D_G[g] / (W_g + eps)
            lambda_eff = lambda_base * (1 - rho)
            s_i = e_i + lambda_eff * d_i
            g.difficulty = s_i
            
        # Densify and Prune based on difficulty, screen_radii, t, Theta
        G = densify_prune(G, screen_radii, e_G, D_G, t, Theta)
        
    return G
```

## Operating characteristics
*   **Time Complexity:** Significantly reduced compared to vanilla 3DGS due to sparse rasterization and optimization. TurboGS completes training within 80 seconds on Mip-NeRF 360 Bicycle scene, compared to 891 seconds for vanilla 3DGS [S1, unofficial].
*   **Memory Complexity:** Requires storage for Error maps (float16) and Age maps (uint16) per view [S1, unofficial].
*   **Performance:** Achieves 27.57 PSNR on Mip-NeRF 360 Bicycle, comparable to vanilla 3DGS (27.57 PSNR) and Taming-3DGS (27.99 PSNR) [S1, unofficial].
*   **Strengths:** Accelerates training by up to ~10x while maintaining quality; adaptively focuses on difficult regions; preserves fine details via structure-aware loss [S1, unofficial].
*   **Limitations:** Sparse supervision may introduce subtle rippling artifacts in low-frequency regions with weak texture variations (e.g., walls or ceilings) [S1, unofficial].

## Background
TurboGS was introduced as an error-guided training framework for 3D Gaussian Splatting to address redundant computation in well-reconstructed regions and loss of fine details [S1, unofficial]. It builds on the 3DGS method [S1, unofficial].
