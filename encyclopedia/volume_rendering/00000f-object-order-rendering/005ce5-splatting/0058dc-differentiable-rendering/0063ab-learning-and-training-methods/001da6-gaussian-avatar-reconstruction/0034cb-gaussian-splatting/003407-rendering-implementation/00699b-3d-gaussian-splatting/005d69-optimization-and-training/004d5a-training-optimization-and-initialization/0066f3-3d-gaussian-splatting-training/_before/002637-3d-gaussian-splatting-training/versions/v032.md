# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the photometric difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images by replacing implicit neural fields with explicit, differentiable geometric primitives [S5, unofficial]. What sets it apart from NeRF-based methods is its use of explicit Gaussian ellipsoids and analytic rasterization, which enables significantly faster training and real-time rendering speeds while achieving comparable image quality [S2][S5, unofficial]. Unlike static initialization methods, it employs adaptive density control to dynamically modify the primitive set during optimization [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images (or video frames) with known camera poses (extrinsics $R_{cw}, t_{cw}$ and intrinsics $K$) [S6, unofficial]. Initial 3D Gaussian parameters derived from Structure from Motion (SfM) [S2][S6, unofficial].
*   **Outputs:** Optimized 3D Gaussian parameters: positions $\mathbf{p}_i$, rotations $q_i$, scales $\mathbf{s}_i$, opacities $\alpha_i$, and spherical harmonic coefficients $h_i$ [S6, unofficial].

**Data Structures:**
Each Gaussian primitive $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$ (initialized from SfM points) [S6, unofficial].
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion) [S6, unofficial].
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$ (initialized between 0 and 1) [S2].
*   Opacity $\alpha_i \in [0, 1]$ (initialized as a constant) [S6, unofficial].
*   Appearance: Spherical Harmonic coefficients $h_i$ (initialized from SfM) [S6, unofficial].
*   Covariance $\Sigma_i \in \mathbb{R}^{3 \times 3}$, computed from $q_i$ and $\mathbf{s}_i$ [S2].

**Rotation Matrix:**
The rotation matrix $R$ from unit quaternion $q = (q_r, q_i, q_j, q_k)$ is:
$$
R(q) = 2 \begin{bmatrix} \frac{1}{2} - (q_j^2 + q_k^2) & q_i q_j - q_r q_k & q_i q_k + q_r q_j \\ q_i q_j + q_r q_k & \frac{1}{2} - (q_i^2 + q_k^2) & q_j q_k - q_r q_i \\ q_i q_k - q_r q_j & q_j q_k + q_r q_i & \frac{1}{2} - (q_i^2 + q_j^2) \end{bmatrix}
$$
The covariance matrix is then $\Sigma = R S S^T R^T$, where $S$ is the diagonal scale matrix [S2].

**Loss Function:**
The optimization minimizes a combined loss $\mathcal{L}$:
$$
\mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM}
$$
where $\lambda$ is a weight (typically 0.2) [S6, unofficial]. $\mathcal{L}_1$ is the L1 loss and $\mathcal{L}_{D-SSIM}$ is the differentiable Structural Similarity loss [S6, unofficial].

**Optimization Steps:**
1.  **Initialization:** Initialize positions $\mathbf{p}$ from SfM points in normalized bounds $[-1, 1]$. Initialize scales $\mathbf{s}$ in $[0, 1]$. Initialize rotations $q$ as unit quaternions. Initialize opacities $\alpha$ and colors $h$ [S2][S6, unofficial].
2.  **Camera Sampling:** Select a training camera $V$ and its ground truth image $\hat{I}$ [S2].
3.  **Rendering:** Rasterize the Gaussians using camera $V$ to obtain rendered image $I$. This involves projecting 3D Gaussians to 2D screen space, sorting by depth, and alpha blending [Parent].
4.  **Loss Computation:** Compute $\mathcal{L}$ between $I$ and $\hat{I}$ [S2].
5.  **Backpropagation:** Compute gradients $\nabla \mathcal{L}$ for all parameters ($\mathbf{p}, q, \mathbf{s}, h, \alpha$) using the chain rule [S6, unofficial].
6.  **Parameter Update:** Update parameters using the Adam optimizer [S2].
7.  **Adaptive Density Control:** Periodically (every $K$ steps), modify the Gaussian set:
    *   **Pruning:** If $\alpha_i < \epsilon$ or the Gaussian is too large, remove it [S2].
    *   **Densification:** If the positional gradient $\nabla_{\mathbf{p}} \mathcal{L} > \tau_p$:
        *   **Split:** If $\|\mathbf{s}_i\| > \tau_s$ (over-reconstruction), split the Gaussian into two [S2].
        *   **Clone:** If $\|\mathbf{s}_i\| \le \tau_s$ (under-reconstruction), clone the Gaussian [S2].

**Pseudocode:**
```python
# Initialization
M = SfM_points() # Positions
S, C, A = InitAttributes() # Scales, Colors (SH), Opacities
i = 0 # Iteration count
cameras = LoadCameras() # List of camera poses and images

while not converged:
    # 1. Sample View
    V, I_gt = SampleTrainingView(cameras)
    
    # 2. Render
    I_render = Rasterize(M, S, C, A, V)
    
    # 3. Compute Loss
    L = Loss(I_render, I_gt)
    
    # 4. Backpropagate
    grads = Backpropagate(L, M, S, C, A, V)
    
    # 5. Update Parameters (Adam)
    M, S, C, A = AdamUpdate(M, S, C, A, grads)
    
    # 6. Adaptive Density Control (every refine_every steps)
    if i % refine_every == 0:
        for gaussian in Gaussians(M, S, C, A):
            # Pruning
            if gaussian.alpha < epsilon or IsTooLarge(gaussian):
                Remove(gaussian)
            
            # Densification
            if gradient_norm(gaussian) > tau_p:
                if norm(gaussian.scale) > tau_s:
                    SplitGaussian(gaussian)
                else:
                    CloneGaussian(gaussian)
    
    i += 1
```

**Parameters:**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `sh_degree`: Spherical harmonic degree. Default: 3 [S4, unofficial].
*   `sh_degree_interval`: Steps between increasing SH degree. Default: 1,000 [S4, unofficial].
*   `resolutionSchedule`: Steps between doubling image resolution. Default: 3,000 [S3, S4, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S3, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: min(15,000, `numIters` / 2) [S3, unofficial].
*   `refineEvery`: Steps between densification/pruning. Default: 500 [S3, unofficial].
*   `densify_grad_thresh`: Gradient threshold $\tau_p$. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold $\tau_s$. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size splitting stops. Default: 4,000 [S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].
*   `ssim_weight`: Weight $\lambda$ for SSIM loss. Default: 0.2 [S4, unofficial].
*   `bg_color`: Background color. Default: [0.613, 0.010, 0.398] (magenta) [S4, unofficial].

**Edge Cases and Pitfalls:**
*   **No Cameras See Points:** If all cameras are filtered out because they see no sparse points, training fails [S3, unofficial].
*   **Over-reconstruction:** Large gradients and large covariance indicate over-reconstruction, handled by splitting [S2].
*   **Under-reconstruction:** Large gradients and small covariance indicate under-reconstruction, handled by cloning [S2].
*   **CPU vs GPU:** CPU execution is ~100x slower than GPU [S3, unofficial].
*   **Evaluation Mode:** Evaluation requires the dataset to be loaded with `eval_mode=True` [S4, unofficial].

### HUGS
Creates a coarse-to-fine deformation module using linear blend skinning and local learning-based refinement for virtual human avatars. Utilizes tri-plane representation to factorize canonical space. Reconstructs from monocular video (50-100 frames) within 30 minutes, achieving 20 FPS [S1].

### Wolf et al. Stereo Method
Trains a 3DGS to render stereo-calibrated novel views, applies stereo depth estimation, and fuses dense depth maps via Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
A labeling pipeline generating Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for densification and pruning processes [S8, unofficial].

### Cross-View Pruning Mechanism
Uses a Cross-View Consistency Loss and adaptive pruning to reduce redundancy. Selects adjacent view pairs with SSIM > 0.6, computes loss to penalize residual discrepancies, and prunes based on depth consistency [S9].

### Structure-View Co-learning
Combines structural and view-dependent gradients for joint optimization. Loss $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$, where $\mathcal{L}_V$ is view gradient loss and $\mathcal{L}_S$ is structure gradient loss [S9].

### Single-view Mini-batch Strategy
Organizes data per viewpoint and samples mini-batches from a single viewpoint to improve training efficiency [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training typically takes 15-30 minutes for standard scenes (e.g., Mip-NeRF 360) on modern GPUs, significantly faster than NeRFs which can take hours [S5, unofficial][S2].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians. Default max is 5,000,000 Gaussians [S3, unofficial]. Sinc splatting variants consume less memory than standard Gaussians [S7].
*   **Measured Performance:** On the Replica dataset, SGS-SLAM achieves PSNR 34.15, SSIM 0.97, and LPIPS 0.096 [S1].
*   **Scaling:** Performance degrades on CPU, which is ~100x slower than GPU [S3, unofficial]. Resolution scaling (downscaling) is used during early training to accelerate convergence [S4, unofficial].
*   **Strengths:** Real-time rendering, fast training, high fidelity [S5, unofficial].
*   **Limitations:** Can produce "floaters" or artifacts in dynamic scenes or unconstrained settings without modifications (e.g., WildGaussians) [S3, unofficial]. Sensitive to initialization and local minima in some variants [S1].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. [9] (cited in [S2][S6, unofficial]). It initializes positions using sparse point clouds from SfM tools like COLMAP [S2][S6, unofficial]. The method falls under the category of radiance fields but differs from NeRFs by using explicit Gaussian primitives [S5, unofficial]. It has been widely adopted for SLAM [S1], dynamic scene reconstruction [S1], and human avatars [S1].
