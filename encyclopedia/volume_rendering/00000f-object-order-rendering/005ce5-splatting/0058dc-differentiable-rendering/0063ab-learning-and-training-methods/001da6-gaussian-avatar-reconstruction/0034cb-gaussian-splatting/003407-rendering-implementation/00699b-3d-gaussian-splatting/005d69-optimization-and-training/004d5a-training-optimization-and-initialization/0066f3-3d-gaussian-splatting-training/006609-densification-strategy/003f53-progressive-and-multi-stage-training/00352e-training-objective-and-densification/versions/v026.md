# Training Objective and Densification

Also called: MeshGS Training, Tightly/Loosely-bound Training

## Overview
This method defines the specific loss function and densification strategy for **MeshGS** [S1], a variant of 3D Gaussian Splatting that aligns primitives with an explicit mesh surface. It solves the problem of standard Gaussian splatting ignoring existing 3D geometry by introducing projection, normal consistency, and scale regularization losses for "tightly-bound" Gaussians [S1]. It differs from its siblings by splitting the Gaussian set into tightly-bound ($G^t$) and loosely-bound ($G^l$) subsets, applying mesh-aware constraints only to $G^t$ while retaining standard densification for $G^l$ [S1].

## How it works
**Inputs:**
*   Rendered image $\hat{I}_i$ and ground truth image $I_i$ [S1].
*   Set of tightly-bound Gaussians $G^t$ and loosely-bound Gaussians $G^l$ [S1].
*   Mesh $M$ consisting of faces $f_j$ and vertices $v_i$ with face normals $n_f$ [S1].
*   Hyperparameters: $\lambda_{img}=0.001$, $\lambda_{nc}=0.1$, $\lambda_{min}=0.1$, $\lambda_{max}=10$, $\lambda_{proj}=50$, $\rho=0.1$ [S1].
*   Training duration: 30,000 iterations [S1].
*   Densification interval: Every 500 iterations [S1].

**Outputs:**
*   Optimized Gaussian parameters ($\mu, \Sigma, \alpha, \mathbf{c}$) and updated set $G$ [S1].

**Data Structures:**
*   Gaussian $g_i \in G^t$: Mean $P_i$, Scale $S_i=(s_1, s_2, s_3)$, Rotation $R_i$, Opacity $\alpha_i$, SH coefficients $\mathbf{c}_i$ [S1].
*   Gaussian $g_i \in G^l$: Same attributes as above [S1].
*   Distance threshold $d_{th} = 0.01$ used to classify Gaussians as tightly or loosely bound [S1].

**Formulas:**
1.  **Image Loss:**
    $$L_{img} = (1-\lambda_{img})L_{1}(\hat{I}_{i},I_{i}) + \lambda_{img}SSIM(\hat{I}_{i}, I_{i})$$
    Where $L_1$ is the L1 loss and $SSIM$ is the Structural Similarity Index [S1].

2.  **Normal Consistency Loss:**
    $$L_{nc} = \sum_{i \in G^{t},f \in F} (1 - n_{i} \cdot n_{f})$$
    Where $n_i$ is the estimated normal of the Gaussian splat and $n_f$ is the mesh face normal [S1].

3.  **Scale Regularization Loss:**
    $$L_{scale} = \sum_{i \in G^{t}}(\lambda_{min}|\text{min}(s_{1}, s_{2}, s_{3})| + \lambda_{max}|\text{max}(s_{1}, s_{2}, s_{3}) - \rho|)$$
    Where $\rho=0.1$ is the threshold for the maximum scale [S1].

4.  **Projection Loss:**
    $$s_{i} = P_{i} + ((P_{i} - v_{i}) \cdot f_{j}) \cdot f_{j}$$
    $$L_{proj} = \sum_{i \in G^{t}}\parallel s_{i} - P_{i} \parallel _{2}$$
    Where $s_i$ is the projection of the Gaussian center $P_i$ onto the mesh face defined by vertex $v_i$ and normal $f_j$ [S1].

5.  **Total Loss:**
    $$L = L_{img} + \lambda_{nc} L_{nc} + L_{scale} + \lambda_{proj} L_{proj}$$
    [S1]

**Algorithm Steps:**
1.  **Initialization:** Initialize Gaussians. Classify each Gaussian $g_i$ as tightly-bound ($G^t$) or loosely-bound ($G^l$) based on its distance to the mesh surface relative to $d_{th}=0.01$ [S1].
2.  **Rendering:** Render image $\hat{I}_i$ from current Gaussian set [S1].
3.  **Loss Computation:**
    *   Compute $L_{img}$ using $\hat{I}_i$ and $I_i$ [S1].
    *   For each $g_i \in G^t$:
        *   Estimate normal $n_i$: Identify the axis in $S_i$ with the minimum scale value. Apply rotation matrix $R_i$ to this axis to obtain $n_i$ in world coordinates [S1].
        *   Find the closest mesh face $f_j$ (with normal $n_f$) to $g_i$ [S1].
        *   Compute $L_{nc}$ using $n_i$ and $n_f$ [S1].
        *   Compute $L_{scale}$ using $S_i$ and $\rho$ [S1].
        *   Compute projection $s_i$ of $P_i$ onto face $f_j$ and add to $L_{proj}$ [S1].
    *   Compute Total Loss $L$ [S1].
4.  **Optimization:** Update Gaussian parameters using gradient descent on $L$ [S1].
5.  **Densification (Every 500 iterations):**
    *   **For $G^l$:** Apply standard 3DGS densification strategy (gradient-based splitting/cloning/pruning) [S1].
    *   **For $G^t$:**
        *   Identify Gaussians requiring densification based on standard metrics (implied by "follows original 3DGS" for $G^l$ and distinct strategy for $G^t$) [S1].
        *   **Cloning:** Copy attributes ($\mu, \Sigma, \alpha, \mathbf{c}$) from parent to child. Initialize child position by sampling a point from the corresponding mesh triangle [S1].
        *   **Splitting:** Divide parent scale by a factor of 1.6. Initialize child position by sampling a point from the corresponding mesh triangle [S1].
        *   Note: The sources specify sampling from the triangle for *both* cloning and splitting of $G^t$ [S1].

**Pseudocode:**
```python
def train_meshgs(G_t, G_l, mesh, images, iterations=30000, refine_every=500):
    # Hyperparameters from [S1]
    lambda_img = 0.001
    lambda_nc = 0.1
    lambda_min = 0.1
    lambda_max = 10
    lambda_proj = 50
    rho = 0.1
    d_th = 0.01

    for iter in range(1, iterations + 1):
        # 1. Render
        I_hat = render(G_t + G_l)
        I_gt = images[iter]

        # 2. Compute Loss
        L_img = (1 - lambda_img) * L1_loss(I_hat, I_gt) + lambda_img * SSIM_loss(I_hat, I_gt)
        L_total = L_img

        # 3. Tightly-bound losses
        for g in G_t:
            # Estimate normal: min scale axis rotated by R
            min_axis_idx = argmin(g.scale)
            n_i = rotate_axis(g.rotation, g.scale, min_axis_idx)
            
            # Find closest mesh face f with normal n_f and vertex v
            f, v = find_closest_mesh_face(mesh, g.position)
            n_f = f.normal
            v_i = v.position
            
            # Normal Consistency
            L_nc = sum(1 - dot(n_i, n_f) for g in G_t for f in mesh.faces) # Simplified aggregation
            
            # Scale Regularization
            s_min = min(g.scale)
            s_max = max(g.scale)
            L_scale_term = lambda_min * abs(s_min) + lambda_max * abs(s_max - rho)
            L_total += L_scale_term
            
            # Projection Loss
            # Project P_i onto face defined by v_i and normal f.normal (assuming f.normal is face normal)
            # Formula: s_i = P_i + ((P_i - v_i) . f_j) * f_j
            # Note: Source [S1] uses f_j as normal in projection formula context
            projection_vec = dot(g.position - v_i, n_f) * n_f
            s_i = g.position + projection_vec
            L_proj_term = norm(s_i - g.position)
            L_total += lambda_proj * L_proj_term
            
            L_total += lambda_nc * (1 - dot(n_i, n_f))

        # 4. Optimize
        gradients = compute_gradients(L_total, G_t + G_l)
        update_parameters(G_t + G_l, gradients)

        # 5. Densification
        if iter % refine_every == 0:
            densify_loosely_bound(G_l) # Standard 3DGS strategy [S1]
            densify_tightly_bound(G_t, mesh) # Mesh-aligned strategy [S1]

def densify_tightly_bound(G_t, mesh):
    for g in G_t:
        if needs_splitting(g):
            # Splitting: scale divided by 1.6, position sampled from triangle
            new_scale = g.scale / 1.6
            # Sample point from the closest mesh triangle to g
            new_pos = sample_point_from_mesh_triangle(mesh, g)
            create_child_gaussian(g, new_pos, new_scale, g.opacity, g.sh_coeffs)
        elif needs_cloning(g):
            # Cloning: copy attributes, position sampled from triangle
            new_pos = sample_point_from_mesh_triangle(mesh, g)
            create_child_gaussian(g, new_pos, g.scale, g.opacity, g.sh_coeffs)
```

## Operating characteristics
*   **Time Complexity:** Standard 3DGS optimization complexity, plus overhead for mesh proximity queries and normal estimation for $G^t$ [S1].
*   **Memory Complexity:** Requires storage for mesh geometry and separate tracking for $G^t$ and $G^l$ [S1].
*   **Performance:** Evaluated on Mip-NeRF360 and Deep Blending datasets [S1].
*   **Strengths:** Aligns Gaussians with explicit mesh geometry, preventing expansion into free space [S1].
*   **Limitations:** Relies on the quality of the input mesh; tightly-bound Gaussians are constrained by mesh topology [S1].
*   **When to use:** When an explicit mesh is available and high-fidelity alignment with surface geometry is required [S1].
*   **When not to use:** When no mesh is available or when the scene contains significant non-rigid deformation not captured by the mesh [S1].

## Background
Originated in **MeshGS: Adaptive Mesh-Aligned Gaussian Splatting for High-Quality Rendering** [S1]. It builds on the original 3DGS densification strategy [S1] by introducing mesh-aware constraints. The method distinguishes between tightly-bound and loosely-bound splats to balance mesh alignment and general rendering flexibility [S1].
