# 4D Gaussian Rasterization

Also called: 4D Gaussian Splatting Forward Pass, 4DGS Render

## Overview
4D Gaussian Rasterization renders a scene represented by 4D Gaussians (3D spatial + 1D temporal) into a 2D image for a specific viewpoint and timestamp [S1, unofficial]. It extends 2D Gaussian Splatting by handling time-dependent opacity, position offsets, and spherical harmonics evaluation in 4D [S1, unofficial]. It builds on [Tiled 2D Gaussian Splatting Rasterization](2061-tiled-2d-gaussian-splatting-rasterization.md) by adding temporal attributes to the Gaussian primitives and their projection pipeline.

## How it works
**Inputs:**
- `viewpoint_camera`: Object containing `FoVx`, `FoVy`, `image_height`, `image_width`, `world_view_transform` (view matrix), `full_proj_transform` (projection matrix), `camera_center` (campos), and `timestamp`.
- `pc` (GaussianModel): Object containing:
  - `get_xyz`: 3D means tensor ($N \times 3$).
  - `active_sh_degree`: Spatial SH degree.
  - `active_sh_degree_t`: Temporal SH degree.
  - `rot_4d`: Boolean flag for 4D rotation.
  - `gaussian_dim`: Integer, 3 or 4.
  - `force_sh_3d`: Boolean flag.
  - `time_duration`: Tensor or tuple defining time range.
  - `env_map_res`: Resolution for environment map (0 if disabled).
  - `env_map`: Texture tensor for environment map.
  - Attributes: `opacity`, `scales`, `scales_t`, `ts` (time positions), `rotations`, `rotations_r`, `shs` (Spherical Harmonics coefficients), `cov3D_precomp` (precomputed 3D covariance), `flow_2d`.
- `pipe`: Configuration object with flags:
  - `compute_cov3D_python`: Boolean.
  - `convert_SHs_python`: Boolean.
  - `env_map_res`: Integer.
- `bg_color`: Background color tensor ($3$).
- `scaling_modifier`: Float (default 1.0).

**Outputs:**
- `rendered_image`: Tensor ($H \times W \times 3$).
- `radii`: Tensor ($N$) indicating visible Gaussians.
- `depth`: Tensor ($H \times W$).
- `alpha`: Tensor ($H \times W$) accumulated opacity.
- `flow`: Tensor ($H \times W \times 2$) or similar.
- `viewspace_points`: Gradients of 2D means.
- `visibility_filter`: Boolean mask.

**Data Structures:**
- `GaussianRasterizationSettings`: Struct holding image dimensions, FOV tangents, background, scale modifier, view/projection matrices, SH degrees, camera position, timestamp, time duration, rotation flag, Gaussian dimension, and debug flags.
- `GaussianRasterizer`: CUDA kernel wrapper initialized with settings.

**Steps:**

1. **Initialize Gradients:**
   Create `screenspace_points` as a zero tensor on CUDA with `requires_grad=True` to store gradients of 2D screen-space means [S1, unofficial].

2. **Compute FOV Tangents:**
   Calculate tangent field of view values:
   $$ \text{tanfovx} = \tan(\text{viewpoint\_camera.FoVx} \times 0.5) $$
   $$ \text{tanfovy} = \tan(\text{viewpoint\_camera.FoVy} \times 0.5) $$
   [S1, unofficial]

3. **Configure Rasterization Settings:**
   Construct `GaussianRasterizationSettings` with:
   - `image_height`, `image_width` from `viewpoint_camera`.
   - `tanfovx`, `tanfovy`.
   - `bg`: `bg_color` if `pipe.env_map_res` is 0, else `torch.zeros(3, device="cuda")` [S1, unofficial].
   - `scale_modifier`: `scaling_modifier`.
   - `viewmatrix`: `viewpoint_camera.world_view_transform`.
   - `projmatrix`: `viewpoint_camera.full_proj_transform`.
   - `sh_degree`: `pc.active_sh_degree`.
   - `sh_degree_t`: `pc.active_sh_degree_t`.
   - `campos`: `viewpoint_camera.camera_center`.
   - `timestamp`: `viewpoint_camera.timestamp`.
   - `time_duration`: `pc.time_duration[1] - pc.time_duration[0]` [S1, unofficial].
   - `rot_4d`: `pc.rot_4d`.
   - `gaussian_dim`: `pc.gaussian_dim`.
   - `force_sh_3d`: `pc.force_sh_3d` [S1, unofficial].

4. **Initialize Rasterizer:**
   Instantiate `GaussianRasterizer` with the configured settings [S1, unofficial].

5. **Retrieve and Preprocess Attributes:**
   - Retrieve 3D means, opacity, and other attributes from `pc` [S1, unofficial].
   - If `pipe.compute_cov3D_python` is true:
     - Compute pre-computed 3D covariance and mean offset [S1, unofficial].
     - If `pc.rot_4d` is true, apply the mean offset to `means3D` [S1, unofficial].
     - If `pc.gaussian_dim == 4`, multiply opacity by marginal time probability `marginal_t` [S1, unofficial].
   - If `pipe.compute_cov3D_python` is false:
     - Retrieve raw scales, rotations, and time-specific scales/positions (`scales_t`, `ts`) [S1, unofficial].
     - If `pc.rot_4d` is true, retrieve `rotations_r` [S1, unofficial].
     - Retrieve `prefilter_var` if greater than 0 [S1, unofficial].

6. **Compute Colors:**
   - If `pipe.convert_SHs_python` is true:
     - Extract SH features [S1, unofficial].
     - Compute direction vectors `dir_pp` from means (adjusted by `delta_mean` if cov3D is precomputed) to camera center. Normalize direction [S1, unofficial].
     - If `pc.gaussian_dim == 3` or `force_sh_3d` is true:
       - Use `eval_sh` (standard 3D SH evaluation) [S1, unofficial].
     - If `pc.gaussian_dim == 4`:
       - Compute temporal direction `dir_t` [S1, unofficial].
       - Use `eval_shfs_4d` with spatial direction, temporal direction, and time duration [S1, unofficial].
     - Clamp result `sh2rgb + 0.5` to minimum 0.0 [S1, unofficial].

7. **Prefiltering (Optional):**
   - If `pipe.compute_cov3D_python` and `pc.gaussian_dim == 4`:
     - Apply a prefilter mask where `marginal_t[:,0] > 0.05` [S1, unofficial].
     - Filter all relevant tensors (`means2D`, `means3D`, `ts`, `shs`, `colors_precomp`, `opacity`, `scales`, `scales_t`, `rotations`, `rotations_r`, `cov3D_precomp`, `flow_2d`) using this boolean mask [S1, unofficial].

8. **Rasterize:**
   Call `rasterizer` with:
   - 3D means, 2D means, SHs, precomputed colors, flow, opacities, time scales/positions, rotations, covariance, and prefilter variance [S1, unofficial].
   - Produce `rendered_image`, `radii`, `depth`, `alpha`, `flow`, and `covs_com` [S1, unofficial].

9. **Environment Map Background (Optional):**
   - If `pipe.env_map_res` is set:
     - Compute environment map background [S1, unofficial].
     - Calculate ray intersection with a sphere of radius $R=60$ using `rays_o` and `rays_d` [S1, unofficial].
     - Compute intersection parameter `t_inter` and intersection point `xyz_inter` [S1, unofficial].
     - Convert to spherical coordinates `tu` (theta) and `tv` (phi) normalized to $[-1, 1]$ for texture sampling [S1, unofficial].
     - Sample `pc.env_map` using `F.grid_sample` [S1, unofficial].
     - Add to `rendered_image` weighted by $(1 - \alpha)$ [S1, unofficial].

10. **Finalize Output:**
    - Construct `radii_all` by zero-initializing a tensor of size `mask.shape` (if prefiltered) or using original `radii` [S1, unofficial].
    - If prefiltered, assign original `radii` to the positions indicated by `mask` [S1, unofficial].
    - Return render dictionary including `rendered_image`, `viewspace_points`, `visibility_filter` (`radii_all > 0`), `radii_all`, `depth`, `alpha`, and `flow` [S1, unofficial].

**Pseudocode:**

```python
import torch
import math
from torch.nn import functional as F

def render_4d_gaussians(viewpoint_camera, pc, pipe, bg_color, scaling_modifier=1.0):
    # 1. Initialize gradients for 2D means
    screenspace_points = torch.zeros_like(pc.get_xyz, dtype=pc.get_xyz.dtype, requires_grad=True, device="cuda") + 0
    try:
        screenspace_points.retain_grad()
    except:
        pass

    # 2. Compute FOV tangents
    tanfovx = math.tan(viewpoint_camera.FoVx * 0.5)
    tanfovy = math.tan(viewpoint_camera.FoVy * 0.5)

    # 3. Configure settings
    bg = bg_color if not pipe.env_map_res else torch.zeros(3, device="cuda")
    raster_settings = GaussianRasterizationSettings(
        image_height=int(viewpoint_camera.image_height),
        image_width=int(viewpoint_camera.image_width),
        tanfovx=tanfovx,
        tanfovy=tanfovy,
        bg=bg,
        scale_modifier=scaling_modifier,
        viewmatrix=viewpoint_camera.world_view_transform,
        projmatrix=viewpoint_camera.full_proj_transform,
        sh_degree=pc.active_sh_degree,
        sh_degree_t=pc.active_sh_degree_t,
        campos=viewpoint_camera.camera_center,
        timestamp=viewpoint_camera.timestamp,
        time_duration=pc.time_duration[1]-pc.time_duration[0],
        rot_4d=pc.rot_4d,
        gaussian_dim=pc.gaussian_dim,
        force_sh_3d=pc.force_sh_3d,
        # ... other flags from pipe/pc
    )
    
    rasterizer = GaussianRasterizer(raster_settings)

    # 5. Retrieve attributes
    means3D = pc.get_xyz
    opacity = pc.get_opacity
    # ... retrieve other attributes based on flags
    
    if pipe.compute_cov3D_python:
        # Compute pre-computed 3D covariance and mean offset [S1, unofficial]
        cov3D_precomp, delta_mean = compute_cov3D_python(means3D, pc)
        if pc.rot_4d:
            means3D = means3D + delta_mean
        if pc.gaussian_dim == 4:
            opacity = opacity * pc.marginal_t[:,0] # Assuming marginal_t is available [S1, unofficial]
    else:
        scales_t = pc.get_scales_t
        ts = pc.get_ts
        if pc.rot_4d:
            rotations_r = pc.get_rotations_r
        prefilter_var = pc.get_prefilter_var if pc.get_prefilter_var > 0 else 0.0

    # 6. Compute colors
    if pipe.convert_SHs_python:
        shs = pc.get_shs
        dir_pp = (means3D - viewpoint_camera.camera_center).detach() # Adjusted by delta_mean if needed [S1, unofficial]
        dir_pp = dir_pp / dir_pp.norm(dim=1, keepdim=True)
        
        if pc.gaussian_dim == 3 or pc.force_sh_3d:
            colors_precomp = eval_sh(pc.active_sh_degree, shs, dir_pp)
        else: # pc.gaussian_dim == 4
            dir_t = compute_temporal_direction(ts, viewpoint_camera.timestamp, pc.time_duration) # Placeholder for dir_t [S1, unofficial]
            colors_precomp = eval_shfs_4d(pc.active_sh_degree, pc.active_sh_degree_t, shs, dir_pp, dir_t, pc.time_duration)
        
        colors_precomp = torch.clamp(colors_precomp + 0.5, min=0.0)
    else:
        colors_precomp = pc.get_colors_precomp

    # 7. Prefiltering
    mask = None
    if pipe.compute_cov3D_python and pc.gaussian_dim == 4:
        marginal_t_val = pc.marginal_t[:,0]
        mask = marginal_t_val > 0.05
        # Filter tensors using mask [S1, unofficial]
        means3D = means3D[mask]
        opacity = opacity[mask]
        # ... filter other tensors

    # 8. Rasterize
    rendered_image, radii, depth, alpha, flow, covs_com = rasterizer(
        means3D=means3D,
        means2D=screenspace_points, # Passed for gradient storage
        shs=shs if not pipe.convert_SHs_python else None,
        colors_precomp=colors_precomp if pipe.convert_SHs_python else None,
        flows=pc.get_flow_2d,
        opacity=opacity,
        ts=ts if not pipe.compute_cov3D_python else None,
        scales=scales,
        scales_t=scales_t if not pipe.compute_cov3D_python else None,
        rotations=rotations,
        rotations_r=rotations_r if pc.rot_4d and not pipe.compute_cov3D_python else None,
        cov3D_precomp=cov3D_precomp if pipe.compute_cov3D_python else None,
        prefilter_var=prefilter_var if not pipe.compute_cov3D_python else 0.0
    )

    # 9. Environment Map
    if pipe.env_map_res:
        # Compute rays_o, rays_d from camera and pixel coordinates
        # Intersect with sphere R=60
        # Convert to tu, tv in [-1, 1]
        # Sample env_map
        env_bg = F.grid_sample(pc.env_map, coords_tu_tv)
        rendered_image = rendered_image + env_bg * (1 - alpha)

    # 10. Finalize
    if mask is not None:
        radii_all = torch.zeros_like(pc.get_xyz[:,0]) # Or mask.shape
        radii_all[mask] = radii
    else:
        radii_all = radii
        
    visibility_filter = radii_all > 0
    
    return {
        "rendered_image": rendered_image,
        "viewspace_points": screenspace_points,
        "visibility_filter": visibility_filter,
        "radii_all": radii_all,
        "depth": depth,
        "alpha": alpha,
        "flow": flow
    }
```

## Subtopics

### 4D Gaussian Splatting (DreamGaussian4D)
A method generating dynamic 4D scenes from single image or video, proposing DreamGaussianHD based on DreamGaussian for image-to-3D initialization, utilizing HexPlane to model Gaussian deformations for realistic motion [S2]. It learns motion from a driving video generated by an image-to-video model, exports 4D GS as an animated mesh, and optionally refines for temporal coherence using a video-to-video optimization pipeline [S2].

## Background
4D Gaussian Rasterization is part of the evolution of Gaussian Splatting to handle dynamic scenes. It extends the static 3D Gaussian Splatting rendering pipeline by incorporating temporal dimensions into the Gaussian primitives and their projection [S1, unofficial]. The underlying rasterization engine is based on the `diff-gaussian-rasterization` library from the Inria GRAPHDECO research group [S1, unofficial]. DreamGaussian4D is a notable application that uses 4D Gaussians with HexPlane deformation modeling [S2].
