# Inpainting for Displaced Objects

Also called: GSP Inpainting, LaMa Inpainting

## Overview
This method remedies black smudges and dirty textures caused by displaced objects exposing unseen areas that 3DGS cannot recover from input images [S1]. Unlike vanilla 3DGS which leaves empty spots and dirty textures blended from irrelevant kernels when objects are displaced, this method ameliorates the issue using generative AI inpainting [S1]. It builds on [3D Gaussian Splatting Training](3761-3d-gaussian-splatting-training.md) by modifying the kernel set to remove and reinitialize specific subsets [Parent].

## How it works
**Inputs:**
*   A set of 3D Gaussian kernels $\mathcal{G}$ representing the scene, including those belonging to objects that may be displaced [S1].
*   A rendered image $I_{rendered}$ of the current view [S1].
*   A segmentation mask or identification of the Gaussian kernels belonging to the displaced object [S1].

**Outputs:**
*   Updated Gaussian kernels $\mathcal{G}'$ with corrected colors, opacity, and specular properties [S1].
*   An inpainted image $I_{inpainted}$ (intermediate) [S1].

**Data Structures:**
*   **Gaussian Kernel:** Contains position $\mathbf{p}$, covariance $\Sigma$ (or scale/rotation), opacity $\alpha$, spherical harmonics coefficients (defining color $c$), and potentially separate diffuse/specular color components [G].
*   **Inpainting Model:** LaMa [S1] or Stable Diffusion [S2].

**Steps:**
1.  **Remove Displaced Kernels:** Identify all Gaussian kernels $\mathcal{G}_{obj} \subset \mathcal{G}$ belonging to the object that may be displaced. Remove these kernels from the scene representation [S1].
2.  **Render Current View:** Render the scene using the remaining kernels $\mathcal{G} \setminus \mathcal{G}_{obj}$ to obtain $I_{rendered}$ and an alpha mask indicating the missing regions (holes) [G].
3.  **Inpaint Image:** Use a generative inpainting model (LaMa [S1] or Stable Diffusion [S2]) to fill the holes in $I_{rendered}$ using the alpha mask. Let the result be $I_{inpainted}$ [S1].
4.  **Trace Rays and Record Colors:** For each pixel $(u, v)$ in the hole region of $I_{rendered}$: emit a ray from the camera through $(u, v)$; find the first Gaussian kernel $\mathcal{G}_i$ encountered by this ray in the current scene; note the new color from $I_{inpainted}(u, v)$ and assign it to $\mathcal{G}_i$ [S1].
5.  **Update Gaussian Attributes:** For each noted Gaussian kernel $\mathcal{G}_i$: calculate the average of all recorded colors assigned to it to set the new diffuse color; set opacity $\alpha = 1$; set specular color to $0$ to prevent highlights [S1].
6.  **Re-insert Kernels:** Add the updated kernels back into the scene representation $\mathcal{G}'$ [S1].

**Pseudocode:**
```python
def inpaint_displaced_objects(gaussians, camera, inpaint_model, displaced_indices):
    # 1. Separate displaced and remaining kernels
    displaced_gaussians = [gaussians[i] for i in displaced_indices]
    remaining_gaussians = [g for i, g in enumerate(gaussians) if i not in displaced_indices]

    # 2. Render scene with remaining kernels
    rendered_image = zeros(camera.resolution)
    alpha_mask = zeros(camera.resolution)
    for kernel in remaining_gaussians:
        u_min, v_min, u_max, v_max = project_2d_bounds(kernel, camera)
        for u in range(u_min, u_max):
            for v in range(v_min, v_max):
                alpha = compute_kernel_alpha(kernel, u, v, camera)
                color = compute_kernel_color(kernel, u, v, camera)
                rendered_image[u, v] = rendered_image[u, v] * (1 - alpha) + color * alpha
                alpha_mask[u, v] = 1.0

    # Invert mask to get holes
    hole_mask = 1.0 - alpha_mask

    # 3. Inpaint holes using generative model
    inpainted_image = inpaint_model(rendered_image, hole_mask)

    # 4. Assign inpainted colors to kernels
    for g in displaced_gaussians:
        u_min, v_min, u_max, v_max = project_2d_bounds(g, camera)
        recorded_colors = []
        for u in range(u_min, u_max):
            for v in range(v_min, v_max):
                # Emit ray from camera through pixel (u, v)
                ray_origin, ray_direction = camera.get_ray(u, v)
                # Find first kernel intersected by ray in remaining scene
                hit_kernel = None
                min_t = infinity
                for other in remaining_gaussians:
                    t = intersect_ray_kernel(ray_origin, ray_direction, other)
                    if 0 < t < min_t:
                        min_t = t
                        hit_kernel = other
                if hit_kernel is not None:
                    recorded_colors.append(inpainted_image[u, v])
        # 5. Update kernel attributes
        if recorded_colors:
            g.diffuse_color = sum(recorded_colors) / len(recorded_colors)
            g.opacity = 1.0
            g.specular_color = 0.0
        else:
            g.opacity = 0.0

    # 6. Return updated kernel set
    return remaining_gaussians + displaced_gaussians
```

**Edge Cases and Pitfalls:**
*   **Precision:** The accuracy of the inpainted color depends on the quality of the generative model [S1].
*   **Boundaries:** The transition between the inpainted region and the rest of the scene must be seamless; the method assumes the inpainted texture matches the surrounding geometry's lighting and material properties [S1].
*   **Degenerate Input:** If a displaced object is completely outside the camera view, no rays will intersect its previous position, resulting in zero recorded colors and opacity set to 0 [S1, G].

## Subtopics

### 3D Inpainting Pipeline
A sequential pipeline to fill occluded/missing regions in rendered novel views while maintaining 3D consistency, leveraging the constraint that Gaussians do not hallucinate details [S2]. Unlike the single-view LaMa approach, this method uses Stable Diffusion for texture generation and Poisson blending for depth consistency [S2]. It is applied when 3D consistency across multiple novel views is required, particularly in sparse view synthesis scenarios [S2].

**Steps:**
1.  Render a novel view with holes and an alpha mask [S2].
2.  Use Stable Diffusion inpainting to generate missing texture in the masked regions [S2].
3.  Estimate monocular depth on the inpainted image [S2].
4.  Use the gradient of this depth to fill in rendered depth in the masked regions using Poisson blending [S2].
5.  Project Gaussians to the scene using the inpainted depth and image [S2].
6.  Repeat the process sequentially for a few novel views until the scene is 3D consistent and renderable from any view without holes [S2].

## Operating characteristics
*   **Time Complexity:** Depends on the inpainting model. LaMa is relatively fast, while Stable Diffusion is computationally expensive. The sequential repetition across multiple views increases total runtime [S2].
*   **Memory Complexity:** Requires storing the inpainted images and intermediate depth maps. No significant additional memory overhead for the Gaussian kernels themselves, as they are re-initialized [S1].
*   **Measured Performance:** GSP with inpainting shows improved visual quality in scenes with displaced objects, removing black smudges and dirty textures [S1]. CoherentGS outperforms DNGaussian visually and numerically on sparse view synthesis, avoiding blurry textures and distracting artifacts [S2].
*   **Strengths:** Effectively handles unseen areas caused by object displacement; leverages state-of-the-art generative models for realistic texture synthesis; maintains 3D consistency in the sequential pipeline [S2].
*   **Limitations:** Relies on the quality of the inpainting model; may introduce artifacts if the context is ambiguous; requires accurate segmentation or identification of displaced objects [S1].
*   **When to Use:** When objects in the scene are displaced or removed, exposing background areas not present in the input images [S1]. When sparse view synthesis is required and competing methods produce blurry textures [S2].

## Background
The method was introduced in the context of Gaussian Splashing (GSP), a unified particle-based framework for versatile motion synthesis and rendering [S1]. The authors observed that standard 3DGS fails to recover color and texture information for areas exposed by displaced objects, leading to visual artifacts [S1]. They proposed using LaMa, a large kernel mask inpainting model, to remedy this issue [S1]. The 3D Inpainting Pipeline variant was introduced in CoherentGS for sparse novel view synthesis, leveraging the constraint that Gaussians do not hallucinate details to safely use generative inpainting [S2].
