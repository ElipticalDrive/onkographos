# GO-Surf Neural Feature Grid Optimization

Also called: GO-Surf, Neural Feature Grid Optimization for Fast, High-Fidelity RGB-D Surface Reconstruction

## Overview
GO-Surf is a differentiable volume rendering method that reconstructs high-fidelity 3D surfaces from RGB-D inputs by optimizing a multi-resolution neural feature grid and a lightweight geometry decoder [S1]. It solves the problem of slow convergence and poor surface quality in implicit neural representations by combining explicit grid-based features with approximate Signed Distance Function (SDF) supervision [S1]. Unlike its sibling [Voxel and Grid-Based Prediction](15382-voxel-and-grid-based-prediction.md), which typically predicts Gaussian parameters or raw densities, GO-Surf explicitly predicts an SDF value via a feature grid to enable robust surface extraction and regularization [S1]. It is significantly faster than implicit-only methods like NeuralRGB-D but requires larger memory footprints due to the explicit grid storage [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of RGB-D images with known camera poses (translation $t \in \mathbb{R}^3$ and rotation parameterized by Lie Algebra $\nu \in \mathfrak{so}(3)$) [S1].
*   **Outputs:** An optimized scene representation consisting of a multi-resolution feature grid $\theta$, a geometry decoder network parameters $\omega$, a color decoder network parameters $\beta, \gamma$, and refined camera poses $\{\xi_t\}$ [S1]. The final output is a continuous SDF field $\phi(x)$ and color field $c(x)$ [S1].

**Data Structures:**
1.  **Multi-Resolution Feature Grid:**
    *   Consists of 4 levels with voxel sizes: 3cm, 6cm, 24cm, and 96cm [S1].
    *   **Geometry Features:** Each voxel stores a feature vector of dimension $h_g = 4$ [S1]. The features from all active levels are concatenated to form a final geometry feature vector of dimension 16 [S1].
    *   **Color Features:** Each voxel stores a feature vector of dimension $h_c = 6$ [S1].
    *   **Interpolation:** Trilinear interpolation is used to query features from the grid [S1]. A custom CUDA kernel is required to support double back-propagation for second-order derivatives (Hessian) [S1].
2.  **Decoders:**
    *   **Geometry Decoder:** A lightweight Multi-Layer Perceptron (MLP) with 2 hidden layers and 32 neurons each [S1]. It takes the concatenated geometry feature vector and outputs the SDF value $\phi(x)$ [S1].
    *   **Color Decoder:** An MLP with 2 hidden layers and 32 neurons each [S1]. It takes the color feature vector and viewing direction $d$ to output RGB color [S1].

**Numbered Steps:**

1.  **Geometric Initialization:**
    *   Initialize the feature grid and geometry decoder such that the initial SDF surface is a sphere centered at the volume origin with a radius equal to half the size of the smallest scene dimension [S1].

2.  **Ray Sampling and Importance Sampling:**
    *   For each batch of rays (batch size $M=6144$), parameterized by camera center $o$ and direction $r$, sample points $x_i = o + d_i r$ [S1].
    *   Perform 3 steps of importance sampling [S1].
    *   Start with $N_c = 96$ coarse samples [S1].
    *   Iteratively add $N_f = 36$ fine samples in subsequent steps based on weights computed from previously sampled points [S1].

3.  **Feature Query and Network Forward Pass:**
    *   For each sample point $x_i$, query the multi-resolution feature grid to obtain the geometry feature vector $V_\theta(x_i)$ and color feature vector [S1].
    *   Compute SDF: $\phi(x_i, \theta, \omega) = f_\omega(V_\theta(x_i))$ [S1].
    *   Compute Color: $c_i = g_\gamma(W_\beta(x_i), d)$, where $d$ is the viewing direction [S1].

4.  **Opacity and Weight Computation:**
    *   Compute opacity $\alpha_i$ using the SDF values of adjacent samples $x_i$ and $x_{i+1}$ [S1]:
        $$ \alpha_i = \max \left( \frac{\sigma_s(\phi(x_i)) - \sigma_s(\phi(x_{i+1}))}{\sigma_s(\phi(x_i))}, 0 \right) $$
    *   Where $\sigma_s(x) = (1 + e^{-sx})^{-1}$ is a sigmoid function modulated by a learnable parameter $s$ [S1].
    *   Compute accumulated transmittance $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ [S1].
    *   Compute weights $w_i = T_i \alpha_i$ [S1].

5.  **Volume Rendering:**
    *   Render expected color $\hat{c}$ and depth $\hat{d}$ for each ray:
        $$ \hat{c} = \sum_{i=1}^{N} w_i c_i $$
        $$ \hat{d} = \sum_{i=1}^{N} w_i d_i $$
    *   Where $N = N_c + 2 \times N_f$ (96 + 72 = 168 total samples) [S1].

6.  **Loss Computation:**
    *   **RGB Loss:** $l_{rgb} = \| I[u, v] - \hat{c} \|$ [S1].
    *   **Depth Loss:** $l_d = | D[u, v] - \hat{d} |$ [S1].
    *   **Approximate SDF Bound:** Calculate bound $b(x) = D[u, v] - d$ [S1].
    *   **SDF Loss (Near-Surface):** For points where $|D[u, v] - d| \le t$ (truncation threshold $t=16$cm):
        $$ l_{sdf}(x) = | \phi(x) - b(x) | $$
    *   **Free Space Loss (Far-Surface):** For points where $|D[u, v] - d| > t$:
        $$ l_{fs}(x) = \max(0, e^{-\alpha \phi(x)} - 1, \phi(x) - b(x)) $$
        Where $\alpha = 5$ is the exponential penalty parameter [S1].
    *   **Eikonal Regularization:** Applied on free space points $S_{fs}$:
        $$ l_{eik}(x) = (1 - \| \nabla \phi(x) \|)^2 $$
    *   **Smoothness Regularization:** Applied on near-surface points $S_g$:
        $$ l_{smooth}(x) = \| \nabla \phi(x) - \nabla \phi(x + \epsilon) \|^2 $$
        Where $\epsilon$ is a perturbation of length $\delta_s \in [1\text{mm}, 4\text{mm}]$ in a random direction [S1].

7.  **Global Objective and Optimization:**
    *   Compute global loss:
        $$ L(P) = \lambda_{rgb} L_{rgb} + \lambda_d L_d + \lambda_{sdf} L_{sdf} + \lambda_{fs} L_{fs} + \lambda_{eik} L_{eik} + \lambda_{smooth} L_{smooth} $$
    *   Where $L_{rgb}$ and $L_d$ are averaged over all sampled rays (or valid depth rays for $L_d$), and regularization losses are averaged over their respective subsets $S_{str}, S_{fs}, S_g$ [S1].
    *   Optimize parameters $P = \{\theta, \omega, \beta, \gamma, \{\xi_t\}\}$ using ADAM optimizer [S1].
    *   Learning rates: $1 \times 10^{-3}$ for MLP decoders, $1 \times 10^{-2}$ for feature grids, $5 \times 10^{-4}$ for camera poses [S1].
    *   Run for 10,000 iterations [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class GO_Surf:
    def __init__(self, voxel_sizes, hg=4, hc=6, hidden_dim=32, num_hidden=2):
        """
        Initialize GO-Surf model.
        :param voxel_sizes: List of voxel sizes per level [3cm, 6cm, 24cm, 96cm]
        :param hg: Geometry feature dimension per level
        :param hc: Color feature dimension per level
        :param hidden_dim: MLP hidden layer size
        :param num_hidden: Number of MLP hidden layers
        """
        self.voxel_sizes = voxel_sizes
        self.hg = hg
        self.hc = hc
        self.num_levels = len(voxel_sizes)
        self.total_geo_dim = hg * self.num_levels # 16
        
        # Initialize Feature Grids (simplified representation)
        # In practice, these are dense tensors or sparse structures
        self.feature_grids = nn.ModuleList([
            nn.Parameter(torch.randn(1, hc, *grid_size)) for grid_size in self._get_grid_dims(voxel_sizes)
        ])
        self.geo_feature_grids = nn.ModuleList([
            nn.Parameter(torch.randn(1, hg, *grid_size)) for grid_size in self._get_grid_dims(voxel_sizes)
        ])
        
        # Geometry Decoder: Input dim 16, Output dim 1 (SDF)
        self.geo_mlp = self._build_mlp(self.total_geo_dim, 1, hidden_dim, num_hidden)
        
        # Color Decoder: Input dim 6, Output dim 3 (RGB)
        self.color_mlp = self._build_mlp(self.hc, 3, hidden_dim, num_hidden)
        
        # Learnable sigmoid parameter s
        self.s = nn.Parameter(torch.tensor(10.0))
        
        # Hyperparameters
        self.t = 0.16 # 16cm truncation threshold
        self.alpha_fs = 5.0 # Free space exponential penalty
        self.delta_s_min = 0.001 # 1mm
        self.delta_s_max = 0.004 # 4mm
        
    def _get_grid_dims(self, voxel_sizes):
        # Placeholder for logic converting voxel sizes to tensor dimensions based on scene bounds
        # Returns list of (H, W, D) for each level
        return [(129, 161, 97), (65, 81, 49), (17, 21, 13), (5, 6, 4)] # Example dims from source

    def _build_mlp(self, input_dim, output_dim, hidden_dim, num_hidden):
        layers = []
        current_dim = input_dim
        for _ in range(num_hidden):
            layers.append(nn.Linear(current_dim, hidden_dim))
            layers.append(nn.ReLU())
            current_dim = hidden_dim
        layers.append(nn.Linear(current_dim, output_dim))
        return nn.Sequential(*layers)

    def query_features(self, x):
        """
        Query multi-resolution feature grids using trilinear interpolation.
        x: (N, 3) coordinates normalized to [-1, 1] or [0, 1] depending on grid sampler
        """
        geo_features = []
        color_features = []
        
        # Note: In PyTorch, grid_sample expects coordinates in [-1, 1]
        # This is a simplified representation of the custom grid sampler
        for i, grid in enumerate(self.feature_grids):
            # Query color features
            # c_feat = custom_grid_sampler(grid, x) 
            # For pseudocode, assume a function that returns (N, C)
            c_feat = self._sample_grid(grid, x) 
            color_features.append(c_feat)
            
            # Query geometry features
            g_feat = self._sample_grid(self.geo_feature_grids[i], x)
            geo_features.append(g_feat)
            
        # Concatenate features from all levels
        # Geometry: [N, 4] + [N, 4] + [N, 4] + [N, 4] -> [N, 16]
        geo_feat_concat = torch.cat(geo_features, dim=-1)
        # Color: [N, 6] + [N, 6] + [N, 6] + [N, 6] -> [N, 24] (Note: Source says hc=6, but doesn't explicitly state concatenation for color, 
        # however, standard practice and "final geometry feature vector" implies similar for color or single level. 
        # Source says "Color features have dimension hc=6". It does not explicitly say they are concatenated across levels like geometry.
        # However, to be safe and consistent with "multi-resolution", we assume similar structure or just use the finest level.
        # Given the source says "final geometry feature vector of dimension 16", it implies concatenation.
        # For color, it just says "dimension hc=6". We will assume concatenation for consistency or use the finest level.
        # Let's assume concatenation for color as well to match the architecture description of "multi-resolution feature grids".
        color_feat_concat = torch.cat(color_features, dim=-1)
        
        return geo_feat_concat, color_feat_concat

    def _sample_grid(self, grid, x):
        # Placeholder for custom grid sampler supporting double backprop
        # Returns (N, C)
        return F.grid_sample(grid, x.unsqueeze(1).unsqueeze(1), mode='trilinear', align_corners=True).squeeze(-1).squeeze(-1)

    def compute_sdf(self, geo_feat):
        """
        Compute SDF using geometry MLP.
        """
        sdf = self.geo_mlp(geo_feat)
        return sdf.squeeze(-1)

    def compute_color(self, color_feat, direction):
        """
        Compute color using color MLP and viewing direction.
        """
        # Concatenate direction to features? Source says c = g_gamma(W_beta(x), d)
        # Assuming MLP takes concatenated features and direction
        input_color = torch.cat([color_feat, direction], dim=-1)
        rgb = self.color_mlp(input_color)
        return rgb

    def render_ray(self, o, r, depth_gt, color_gt, num_coarse=96, num_fine=36):
        """
        Render a single ray.
        """
        # 1. Importance Sampling
        # Coarse samples
        t_coarse = torch.linspace(0, 1, num_coarse) # Simplified sampling range
        x_coarse = o + t_coarse.unsqueeze(1) * r.unsqueeze(0) # (N_coarse, 3)
        
        # Query features and compute SDF for coarse samples
        geo_feat_c, color_feat_c = self.query_features(x_coarse)
        sdf_c = self.compute_sdf(geo_feat_c)
        rgb_c = self.compute_color(color_feat_c, r)
        
        # Compute Opacity and Weights
        # alpha_i = max((sigma(sdf_i) - sigma(sdf_{i+1})) / sigma(sdf_i), 0)
        sigma_c = torch.sigmoid(self.s * sdf_c)
        # Shifted sigma for alpha calculation
        sigma_c_shifted = torch.roll(sigma_c, -1)
        sigma_c_shifted[-1] = sigma_c[-1] # Handle last point
        
        alpha_c = torch.clamp((sigma_c - sigma_c_shifted) / sigma_c, min=0)
        
        # Transmittance
        T_c = torch.cumprod(1 - alpha_c, dim=0)
        T_c = torch.cat([torch.ones_like(T_c[:1]), T_c[:-1]], dim=0)
        
    # ... (Rest of rendering logic for fine samples and final integration would follow here)
    # Due to space constraints, the full ray marching loop is omitted, but the core components are defined.
    
    def compute_losses(self, rendered_color, rendered_depth, color_gt, depth_gt, sdf_pred, x_samples):
        """
        Compute all loss components.
        """
        # RGB Loss
        l_rgb = torch.mean(torch.abs(color_gt - rendered_color))
        
        # Depth Loss (only valid depth)
        valid_depth_mask = depth_gt > 0
        l_d = torch.mean(torch.abs(depth_gt[valid_depth_mask] - rendered_depth[valid_depth_mask]))
        
        # SDF Bound
        b_x = depth_gt - rendered_depth # Approximate bound
        
        # SDF Loss (Near Surface)
        near_surface_mask = torch.abs(b_x) <= self.t
        l_sdf = torch.mean(torch.abs(sdf_pred[near_surface_mask] - b_x[near_surface_mask]))
        
        # Free Space Loss (Far Surface)
        far_surface_mask = torch.abs(b_x) > self.t
        # l_fs = max(0, exp(-alpha * phi) - 1, phi - b)
        term1 = torch.exp(-self.alpha_fs * sdf_pred[far_surface_mask]) - 1
        term2 = sdf_pred[far_surface_mask] - b_x[far_surface_mask]
        l_fs = torch.mean(torch.clamp(torch.stack([torch.zeros_like(term1), term1, term2], dim=-1), min=0).max(dim=-1)[0])
        
        # Eikonal Loss (on far surface points)
        # Requires gradient of SDF w.r.t x
        grad_sdf = self.compute_gradient(sdf_pred, x_samples)
        l_eik = torch.mean((1 - torch.norm(grad_sdf[far_surface_mask], dim=1))**2)
        
        # Smoothness Loss (on near surface points)
        # Requires gradient at x and x + epsilon
        epsilon = torch.randn_like(x_samples) * torch.rand(1) * (self.delta_s_max - self.delta_s_min) + self.delta_s_min
        x_eps = x_samples + epsilon
        grad_sdf_eps = self.compute_gradient(self.compute_sdf(self.query_features(x_eps)[0]), x_eps)
        l_smooth = torch.mean(torch.norm(grad_sdf[near_surface_mask] - grad_sdf_eps[near_surface_mask], dim=1)**2)
        
        return l_rgb, l_d, l_sdf, l_fs, l_eik, l_smooth

    def compute_gradient(self, sdf, x):
        # Compute gradient using autograd
        grad = torch.autograd.grad(
            sdf.sum(), x, create_graph=True, retain_graph=True
        )[0]
        return grad
```

**Parameters:**
*   **Voxel Sizes:** 3cm, 6cm, 24cm, 96cm [S1].
*   **Feature Dimensions:** Geometry $h_g=4$ per level (total 16), Color $h_c=6$ [S1].
*   **MLP Architecture:** 2 hidden layers, 32 neurons each [S1].
*   **Truncation Threshold $t$:** 16cm [S1].
*   **Free Space Penalty $\alpha$:** 5 [S1].
*   **Perturbation Length $\delta_s$:** 1mm to 4mm [S1].
*   **Batch Size $M$:** 6144 rays [S1].
*   **Samples:** $N_c=96$ coarse, $N_f=36$ fine [S1].
*   **Optimizer:** ADAM [S1].
*   **Learning Rates:** $10^{-3}$ (MLP), $10^{-2}$ (Grid), $5 \times 10^{-4}$ (Camera Poses) [S1].
*   **Loss Weights:** $\lambda_{rgb}=10.0, \lambda_{depth}=1.0, \lambda_{sdf}=10.0, \lambda_{fs}=1.0, \lambda_{eik}=1.0, \lambda_{smooth}=1.0$ [S1].
*   **Iterations:** 10,000 [S1].

**Edge Cases and Pitfalls:**
*   **Second-Order Derivatives:** Computing the Eikonal and Smoothness losses requires the Hessian of the SDF, which involves second-order derivatives of trilinear interpolation. Standard PyTorch autograd does not support double back-propagation through the standard grid sampler [S1]. **Solution:** Implement a custom CUDA kernel for the second backward pass of the grid sampler [S1].
*   **Missing Depth:** The method handles missing depth values by only applying depth loss on rays with valid depth values, while still using RGB and SDF regularization [S1].
*   **Initialization:** Poor initialization can lead to convergence issues. The method initializes the surface as a sphere to guide the optimization [S1].

## Operating characteristics
*   **Time Complexity:** The optimization process takes 15 to 45 minutes depending on scene size [S1]. This is significantly faster than NeuralRGB-D (15-25 hours) [S1].
*   **Memory Complexity:** The method requires storing the multi-resolution feature grid. Model size ranges from 41 MB (synthetic, 10.1M params) to 268 MB (ScanNet scene 0000, 66.5M params) [S1]. Memory usage scales rapidly with scene size [S1].
*   **Performance:** Achieves high-quality reconstructions with smooth surfaces and hole-filling capabilities [S1]. Outperforms baselines like BundleFusion and NeuralRGB-D in completion and normal consistency on ScanNet and synthetic datasets [S1].
*   **Strengths:** Fast convergence, robust to noisy/missing depth, handles thin structures well, joint pose refinement [S1].
*   **Limitations:** Large memory footprint compared to implicit representations [S1].

## Background
GO-Surf was introduced in the paper "GO-Surf: Neural Feature Grid Optimization for Fast, High-Fidelity RGB-D Surface Reconstruction" [S1]. It builds upon the principles of differentiable volume rendering and neural implicit surfaces [S1]. The method was developed to address the slow optimization times of implicit neural representations like NeuralRGB-D while maintaining high reconstruction fidelity [S1]. It is used for RGB-D surface reconstruction on datasets like ScanNet and synthetic sequences [S1].
