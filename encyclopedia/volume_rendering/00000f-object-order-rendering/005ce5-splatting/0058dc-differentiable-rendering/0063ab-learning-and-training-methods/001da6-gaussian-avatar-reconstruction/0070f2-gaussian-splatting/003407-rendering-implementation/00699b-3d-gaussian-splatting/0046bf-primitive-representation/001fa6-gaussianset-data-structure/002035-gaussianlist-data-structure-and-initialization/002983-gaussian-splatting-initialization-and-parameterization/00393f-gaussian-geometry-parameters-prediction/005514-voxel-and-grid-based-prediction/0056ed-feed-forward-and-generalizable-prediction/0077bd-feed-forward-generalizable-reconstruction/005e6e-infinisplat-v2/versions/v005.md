# InfiniSplat v2

Also called: InfiniSplat

## Overview
InfiniSplat v2 is a feed-forward Gaussian reconstruction method for arbitrary input views that decouples geometry and attribute prediction, uses ground-truth (GT) camera poses for alignment during training, and employs large-angle target view supervision to improve rendering quality under large viewpoint changes [S1, unofficial]. It differs from its parent [Feed-forward Generalizable Reconstruction](23168-feed-forward-generalizable-reconstruction.md) and siblings like [DA3-GS](12847-anysplat-pipeline.md) by freezing the geometry branch to prevent geometric degradation caused by joint optimization, and by using GT poses to avoid pose errors that misguide the network under large-angle supervision [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $N$ input RGB images $I_C = \{I_i\}_{i \in C}$ and optional pose conditions $Q_C$ (camera intrinsics and poses). In the pose-free setting, $Q_C = \emptyset$ [S1, unofficial].
*   **Outputs:** A set of $M$ 3D Gaussians $\mathcal{G} = \{(\mu_m, \xi_m)\}_{m=1}^M$, where $\mu_m \in \mathbb{R}^3$ is the center and $\xi_m = (\alpha_m, s_m, q_m, c_m)$ contains opacity, three-axis scale, rotation (quaternion), and zeroth-order spherical-harmonic (SH) color [S1, unofficial].

**Data Structures:**
*   **Gaussian Set:** Stored as a list of centers and attributes. During Stage II, a global KNN graph is maintained. Core sets are sorted along the longest voxel-coordinate axis. Chunks exceeding 300,000 points are recursively bisected [S1, unofficial].
*   **Hidden State:** A 16-dimensional vector per Gaussian, initialized to zero [S1, unofficial].

**Parameters:**
*   Voxel merging side length: 0.004 (scale-normalized frame) [S1, unofficial].
*   Opacity pruning threshold $\tau_\alpha$: 0.01 [S1, unofficial].
*   Mask thresholds: $\tau_{abs} = 0.03$, $\tau_{rel} = 0.01$ [S1, unofficial].
*   $gsplat$ `eps2d`: $10^{-2}$ [S1, unofficial].
*   Stage I learning rates: $10^{-6}$ (last 10 attribute Transformer blocks), $2 \times 10^{-4}$ (Gaussian head) [S1, unofficial].
*   Stage I steps: 25,000 (2,000 warmup, cosine decay to 0.1) [S1, unofficial].
*   Stage II learning rate: $2 \times 10^{-4}$ (cosine decay to 0.1), 5,000 steps [S1, unofficial].
*   AdamW: $\beta = (0.9, 0.95)$, global batch size 16, L2 gradient clipping 1.0 [S1, unofficial].

**Steps:**

1.  **Dual-Branch Feature Extraction:**
    Initialize two branches from pretrained DA3 weights. The frozen geometry branch $\Phi_{geo}$ predicts depths $\hat{C}$ and cameras $\hat{\Pi}_C$. The trainable attribute branch $\Phi_{attr}$ (last $K$ blocks fine-tuned) produces multi-layer patch features $F_C$ [S1, unofficial].
    $$ \hat{C}, \hat{\Pi}_C = \Phi_{geo}(I_C; Q_C) $$
    $$ F_C = \Phi_{attr}(I_C; Q_C) $$

2.  **Scale Alignment and Point Construction (Stage I):**
    *   Normalize predicted depths and translations by $s_{norm} > 0$.
    *   Fit an Umeyama similarity transform from the GT trajectory to the normalized predicted trajectory using only input-camera center correspondences. Retain the scale $s_C$ [S1, unofficial].
    *   Align GT poses: $R^\star_v = R_v$, $t^\star_v = s_C t_v$. Rotations remain unchanged [S1, unofficial].
    *   Construct Gaussian centers $\mu_m$ from normalized predicted z-depth, GT intrinsics, and scale-aligned GT poses. No predicted positional offsets are used [S1, unofficial].

3.  **Initial Attribute Prediction and Pruning (Stage I):**
    *   Use a DPT decoder to map $F_C$ to per-pixel attributes $\xi$ [S1, unofficial].
    *   Merge voxels with side length 0.004.
    *   Prune Gaussians with opacity $\alpha_m < \tau_\alpha = 0.01$ [S1, unofficial].
    *   Render initial scene $\mathcal{G}_0$ into input and target views $v \in V = C \cup T$:
        $$ \hat{I}_v = \mathcal{R}(\mathcal{G}_0; \Pi^\star_v) $$

4.  **Visibility Mask Construction (Stage I):**
    *   A target pixel is retained if it has finite GT depth $> 10^{-6}$, passes validity mask, and satisfies:
        $$ |z_{proj} - d_{src}| \leq \max(\tau_{abs}, \tau_{rel} d_{src}) $$
        where $z_{proj}$ is point depth in input camera, $d_{src}$ is sampled depth [S1, unofficial].

5.  **Stage I Loss Computation:**
    *   Compute LPIPS spatial distance map $d_v = \text{LPIPS}_{spatial}(M_v \odot \hat{I}_v, M_v \odot I_v)$, zeroing invalid regions before normalization [S1, unofficial].
    *   Aggregate losses over valid pixels:
        $$ \mathcal{L}_I = \frac{\sum_{v \in V} \sum_p M_v(p) [e_v(p) + d_v(p)]}{\max(1, \sum_{v \in V} \sum_p M_v(p))} $$
        where $e_v(p)$ is RGB-channel-averaged absolute error [S1, unofficial].

6.  **Stage II Refinement Setup:**
    *   Project DPT features to 8 channels via learnable 1x1 conv, merge using Gaussian voxel groups/weights, and reuse [S1, unofficial].
    *   Initialize 16-dim hidden state via linear projection [S1, unofficial].

7.  **Stage II Iterative Refinement:**
    *   For each step $k$ (sampled $K_r \in \{1, 2, 3\}$ during training, 3 at inference):
        *   Concatenate image features, current attributes, gradient feedback, neighbor distances, and hidden states. Project to 64 dims [S1, unofficial].
        *   Process through four KNN Transformer blocks (single-head attention over 8 neighbors, LayerNorm, MLP, residual) [S1, unofficial].
        *   Concatenate output with input, predict increments via MLP [S1, unofficial].
        *   **Attribute Updates:**
            *   Scales: $s_{new} = s_{old} \exp(\Delta \log s)$ [S1, unofficial].
            *   Opacity-logit, local rotation-vector, RGB-logit: $a \tanh(\text{raw})$ with $a = 0.1, 0.25, 1.0$ respectively [S1, unofficial].
            *   Hidden-state increments: $0.1 \tanh(\text{raw})$ [S1, unofficial].
            *   Clamp logit inputs to $[10^{-6}, 1-10^{-6}]$ [S1, unofficial].
        *   **Feedback Loss:**
            $$ \ell_{fb} = 0.8 L_1 + 0.2 L_{DSSIM} $$
            where $L_{DSSIM} = (1 - \text{SSIM})/2$ over valid regions [S1, unofficial].
        *   **Surrogate Loss:**
            Compute rendering gradients on independent leaf copies $z_k = \text{sg}(x_k)$ to form $r_k = \text{sg}(\nabla_z \mathcal{L}_{render}(z_k))$.
            $$ \mathcal{L}_{kproxy} = \text{sg}(\mathcal{L}_{render}(z_k)) + \langle x_k - \text{sg}(x_k), r_k \rangle $$
            where $x_k$ collects updated log-scale, opacity-logit, local-rotation, and RGB-logit parameters [S1, unofficial].
        *   **Outer Loss:**
            $$ \ell_{out} = 0.8 L_1 + 0.2 L_{DSSIM} + 0.5 L_{LPIPS} $$
            Input and target views receive weight 0.5 each [S1, unofficial].

8.  **Stage II Objective:**
    $$ \mathcal{L}_{II} = \sum_{k=1}^{K_r} 0.9^{K_r-k} \mathcal{L}_{krender} + 0.1 \mathcal{L}_{opacity} $$
    where $\mathcal{L}_{opacity} = \frac{1}{M} \sum_{m=1}^M [\text{logit}_\epsilon(\alpha_{m, K_r}) - \text{logit}_\epsilon(\alpha_{m, 0})]^2$, $\epsilon=10^{-6}$ [S1, unofficial].

9.  **Chunked Execution:**
    *   Reuse global KNN graph. Sort along longest voxel-coordinate axis. Expand core sets (max 200,000 points) with four-hop neighborhoods. Bisect chunks > 300,000 points recursively. Retain only core-point outputs. Use gradient checkpointing [S1, unofficial].

class KNNTransformerBlocks(nn.Module):
    def __init__(self, num_blocks, num_neighbors, dim):
        super().__init__()
        self.blocks = nn.ModuleList([
            KNNTransformerBlock(num_neighbors, dim) for _ in range(num_blocks)
        ])
        
    def forward(self, x, neighbors):
        for block in self.blocks:
            x = block(x, neighbors)
        return x

class KNNTransformerBlock(nn.Module):
    def __init__(self, num_neighbors, dim):
        super().__init__()
        self.attention = SingleHeadAttention(dim, num_neighbors)
        self.norm1 = nn.LayerNorm(dim)
        self.mlp = nn.Sequential(
            nn.Linear(dim, dim * 4),
            nn.GELU(),
            nn.Linear(dim * 4, dim)
        )
        self.norm2 = nn.LayerNorm(dim)
        
    def forward(self, x, neighbors):
        # x: [N, D], neighbors: [N, K, D]
        attn_out = self.attention(x, neighbors)
        x = self.norm1(x + attn_out)
        mlp_out = self.mlp(x)
        x = self.norm2(x + mlp_out)
        return x

## Operating characteristics
*   **Time Complexity:** Stage I is dominated by the DA3 backbone and DPT decoder. Stage II involves iterative KNN updates and rendering. Chunked execution limits memory usage but adds overhead for neighborhood recomputation [S1, unofficial].
*   **Memory Complexity:** Depends on the number of Gaussians $M$ and the KNN graph size. Chunking limits peak memory to ~300,000 points per chunk [S1, unofficial].
*   **Performance:** Achieves state-of-the-art mean LPIPS and DISTS on six datasets in both pose-conditioned and pose-free settings. In pose-conditioned setting, LPIPS and DISTS decrease by 25.8% and 32.9% respectively compared to strongest baselines [S1, unofficial].
*   **Strengths:** Decoupled geometry prevents flying-point artifacts. GT pose alignment improves large-angle supervision. Opacity learning suppresses outliers [S1, unofficial].
*   **Limitations:** Requires GT poses during training for alignment. Pose-free setting relies on reference cameras for scale estimation [S1, unofficial].

## Background
InfiniSplat v2 builds on [DA3-GS](12847-anysplat-pipeline.md) and [InfiniSplat](12847-anysplat-pipeline.md). It addresses limitations in Gaussian attribute learning, specifically geometric degradation from joint optimization and pose errors from predicted cameras [S1, unofficial]. It was introduced to improve rendering quality under large viewpoint changes [S1, unofficial].
