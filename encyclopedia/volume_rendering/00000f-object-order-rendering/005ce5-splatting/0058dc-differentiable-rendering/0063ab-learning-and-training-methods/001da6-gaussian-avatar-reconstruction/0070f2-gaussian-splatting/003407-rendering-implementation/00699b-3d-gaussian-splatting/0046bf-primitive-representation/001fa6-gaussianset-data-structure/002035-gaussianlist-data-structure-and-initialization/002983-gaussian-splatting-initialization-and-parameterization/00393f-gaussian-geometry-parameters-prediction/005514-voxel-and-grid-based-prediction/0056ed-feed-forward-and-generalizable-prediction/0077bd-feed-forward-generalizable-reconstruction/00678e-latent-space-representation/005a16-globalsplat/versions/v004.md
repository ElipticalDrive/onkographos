# GlobalSplat


## Overview
GlobalSplat is a feed-forward 3D Gaussian Splatting framework that aligns multi-view inputs into a fixed set of global latent scene tokens before decoding explicit 3D geometry, preventing representation bloat and ensuring global consistency [S1]. Unlike sibling methods that form primitives in dense view-aligned spaces and align them globally afterward, GlobalSplat aggregates multi-view inputs into a fixed number of latent tokens (2048) regardless of the number of input views, then decodes these tokens into a strict budget of Gaussians (16K) [S1]. This approach achieves a stronger large-context quality-efficiency trade-off compared to alternatives like C3G, which rely on full self-attention and single-Gaussian decoding [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $C$ input images $\mathcal{I} = \{I_i\}_{i=1}^C$ with corresponding camera poses $T_i$ (rotation $R_i$, translation $o_i$) and intrinsics $\kappa_i$.
*   **Output:** A set of $N$ 3D Gaussians $\mathcal{G} = \{g_n\}_{n=1}^N$, where each Gaussian $g_n$ is defined by mean $\mu_n$, scale $s_n$, rotation $r_n$, opacity $\alpha_n$, and spherical harmonic coefficients $c_n$.

**Data Structures:**
1.  **Latent Tokens:** A set of $M=2048$ learnable latent tokens $l_j \in \mathbb{R}^{512}$ and learnable register tokens.
2.  **Input Patches:** Image patches of size $8 \times 8$.
3.  **Gaussian Candidates:** For each latent token, 16 candidates are predicted with attributes:
    *   $\mathbf{X}_p \in \mathbb{R}^{16 \times 3}$: Means.
    *   $\mathbf{S}_p \in \mathbb{R}^{16 \times 3}$: Log-scales.
    *   $\mathbf{R}_p \in \mathbb{R}^{16 \times 6}$: 6D rotations.
    *   $\mathbf{O}_p \in \mathbb{R}^{16 \times 1}$: Opacity logits.
    *   $\boldsymbol{\ell}_p \in \mathbb{R}^{16 \times 1}$: Importance scores (gate logits).
    *   $\mathbf{C}_p \in \mathbb{R}^{16 \times (3 D_{\text{SH}})}$: SH coefficients ($D_{\text{SH}}=16$).

**Preprocessing:**
1.  **Image Resize:** Resize input image height to 256, preserving aspect ratio. Round width to a multiple of patch size 8. Update intrinsics. Apply centered square crop. Final resize to $256 \times 256$ [S1].
2.  **Scene Normalization:**
    *   Compute canonical frame origin: $\bar{o} = \frac{1}{C} \sum_{i=1}^C o_i$.
    *   Compute axes by averaging camera viewing directions and re-orthonormalizing. Let $T_{\text{avg}}$ be the resulting average pose.
    *   Transform cameras: $\hat{T}_i = T_{\text{avg}}^{-1} T_i$ [S1].
    *   Compute scene scale: $s = \max_{a,b} \|\hat{o}_a - \hat{o}_b\|_2$.
    *   Scale translations: $\tilde{o}_i = \frac{\hat{o}_i}{s}$ [S1].

**Step 1: Input Context Construction**
For each input view $i$ and patch $p$:
1.  Extract RGB patch features $u_{i,p}^{\text{rgb}}$ [S1].
2.  Compute dense Plücker-ray features $r_{i,p}$ and patchify. Map to $\hat{r}_{i,p} = W_{\text{ray}} r_{i,p}$ [S1].
3.  Compute per-view camera code $e_i$:
    *   Encode intrinsics $\kappa_i$ with MLP and Fourier features $\phi(\kappa_i)$.
    *   Encode center $o_i$ with Fourier positional encoding $\text{PE}(o_i)$.
    *   $e_i = W_{\text{proj}}([\text{MLP}_K(\phi(\kappa_i)); \text{PE}(o_i)])$ [S1].
4.  Combine: $u_{i,p}^{\text{cam}} = \hat{r}_{i,p} + e_i$ [S1].
5.  Concatenate: $u_{i,p} = [u_{i,p}^{\text{cam}} ; u_{i,p}^{\text{rgb}}]$ [S1].

**Step 2: Dual-Branch Iterative Encoder**
Initialize latent tokens $l^{(0)}$. For each block $b \in \{1, \dots, B\}$ where $B=4$:
1.  Project tokens to geometry and appearance streams:
    $f_{\text{geo}}^{(b-1)}, f_{\text{app}}^{(b-1)} = \text{Proj}_{\text{geo}}(l^{(b-1)}), \text{Proj}_{\text{app}}(l^{(b-1)})$ [S1].
2.  For each branch $i \in \{\text{geo}, \text{app}\}$:
    *   Apply cross-attention with input patches $x$ (the collection of $u_{i,p}$):
        $f_i^{\text{cross}} = \text{CrossAtt}_i(x, f_i^{(b-1)})$ [S1].
    *   Apply $L=2$ self-attention blocks:
        $f_i^{(b)} = \text{SelfAtt}_i(\dots \text{SelfAtt}_i(f_i^{\text{cross}}) \dots)$ [S1].
3.  Fuse streams and update tokens:
    $l^{(b)} = \text{MLP}(\text{Concat}(f_{\text{geo}}^{(b)}, f_{\text{app}}^{(b)}))$ [S1].

**Step 3: Dual-Branch Decoder**
1.  Project final latent tokens to candidate attributes:
    $G_{\text{geo}} = \text{Proj}_{\text{geo}}^{\text{dec}}(l_{\text{geo}}^{(B)})$, $G_{\text{app}} = \text{Proj}_{\text{app}}^{\text{dec}}(l_{\text{app}}^{(B)})$ [S1].
2.  For each latent token $p$, predict 16 candidates for geometry ($\mathbf{X}_p, \mathbf{S}_p, \mathbf{R}_p, \mathbf{O}_p, \boldsymbol{\ell}_p$) and appearance ($\mathbf{C}_p$) [S1].

**Step 4: Coarse-to-Fine Merging**
GlobalSplat uses a stage-dependent merging mechanism controlled by stage $s \in \{0, 1, 2, 3, 4\}$. The final model uses $s=3$ [S1].
1.  Partition 16 candidates into $G = 2^s$ groups of size $b_s = 16/G$ [S1].
2.  For each group $g$ and candidate $i \in \{1, \dots, b_s\}$:
    *   Compute normalized weight using temperature $\tau$:
        $w_{p,g,i} = \frac{\exp(\ell_{p,g,i}/\tau)}{\sum_{j=1}^{b_s} \exp(\ell_{p,g,j}/\tau)}$ [S1].
    *   Merge attributes for attribute $z$:
        $\bar{z}_{p,g} = \sum_{i=1}^{b_s} w_{p,g,i} z_{p,g,i}$ [S1].
3.  The final set of Gaussians is the collection of all merged groups across all latent tokens. Total Gaussians $N = M \times G = 2048 \times 8 = 16,384$ [S1].

**Gaussian Parameterization:**
*   **Means:** Initialized with fixed forward offset of 1.5 [S1].
*   **Scales:** Predicted in log space as offset from -2 [S1].
*   **Opacity:** Predicted in logit space as offset from -5 [S1].
*   **Rotations:** Continuous 6D parameterization as residual offsets from static rotation [S1].
*   **Color:** SH degree 3 ($D_{\text{SH}}=16$ coefficients per channel) [S1].

**Pseudocode:**
```python
def global_splat(input_images, camera_poses, intrinsics):
    # 1. Preprocessing
    resized_images = []
    for img in input_images:
        # Resize height to 256, preserve aspect ratio, round width to multiple of 8
        # Crop to 256x256, update intrinsics
        resized_images.append(preprocess_image(img))
    
    # 2. Scene Normalization
    C = len(resized_images)
    origins = [pose.translation for pose in camera_poses]
    avg_origin = sum(origins) / C
    viewing_dirs = [pose.rotation @ [0,0,1] for pose in camera_poses]
    avg_dir = sum(viewing_dirs) / C
    # Re-orthonormalize axes to form T_avg
    T_avg = build_pose(avg_origin, avg_dir)
    
    normalized_poses = []
    for pose in camera_poses:
        T_hat = T_avg.inverse() @ pose
        normalized_poses.append(T_hat)
        
    # Scale normalization
    max_dist = max(norm(p1.translation - p2.translation) for p1 in normalized_poses for p2 in normalized_poses)
    scaled_poses = [T @ scale(1/max_dist) for T in normalized_poses]
    
    # 3. Input Context Construction
    patches = []
    for i, img in enumerate(resized_images):
        # Extract 8x8 patches
        rgb_patches = extract_patches(img)
        # Compute Plücker rays and patchify
        ray_patches = compute_plucker_patches(scaled_poses[i], intrinsics[i])
        r_hat = W_ray @ ray_patches
        
        # Per-view code
        e_i = W_proj([MLP_K(Fourier(intrinsics[i])), Fourier(scaled_poses[i].translation)])
        cam_patches = r_hat + broadcast(e_i, rgb_patches.shape)
        
        # Concatenate
        context_patches = concat(cam_patches, rgb_patches, axis=-1)
        patches.append(context_patches)
        
    # 4. Dual-Branch Encoder
    latent_tokens = init_latent_tokens(M=2048, d=512)
    for b in range(B=4):
        f_geo = Proj_geo(latent_tokens)
        f_app = Proj_app(latent_tokens)
        
        for branch_f in [f_geo, f_app]:
            # Cross attention with all patches
            branch_f = CrossAtt(patches, branch_f)
            # 2 Self-attention blocks
            for _ in range(L=2):
                branch_f = SelfAtt(branch_f)
        
        # Fuse
        fused = MLP(concat(f_geo, f_app))
        latent_tokens = fused
        
    # 5. Decoder
    l_geo = latent_tokens[geo_branch]
    l_app = latent_tokens[app_branch]
    G_geo = Proj_geo_dec(l_geo)
    G_app = Proj_app_dec(l_app)
    
    # Predict 16 candidates per token
    # X, S, R, O, l, C are predicted for each token
    candidates = predict_candidates(G_geo, G_app)
    
    # 6. Merging (Stage s=3 -> G=8)
    G = 8
    b_s = 16 // G
    gaussians = []
    for token_idx in range(M):
        for g in range(G):
            group_candidates = candidates[token_idx][g * b_s : (g + 1) * b_s]
            # Compute weights from importance scores l
            weights = softmax(group_candidates.l / tau)
            # Merge attributes
            merged_g = merge_gaussians(group_candidates, weights)
            gaussians.append(merged_g)
            
    return gaussians
```

## Subtopics

### Coarse-to-Fine Curriculum
A training strategy where the number of exposed Gaussians per token $G$ starts at 1 and increases to 8, preventing representation bloat and stabilizing training [S1].

### Dual-Branch Architecture
Separates geometry and appearance processing into parallel streams to prevent texture from masking poor structural predictions [S1].

## Operating characteristics
*   **Time Complexity:** Inference is a single forward pass. On RealEstate10K with 24 views, inference time is <78 ms [S1].
*   **Memory Complexity:** Peak GPU memory is 1.79 GB for 24 views [S1]. Disk size is ~4 MB for the 16K Gaussian representation [S1].
*   **Performance:** On RealEstate10K with 24 views, GlobalSplat16K achieves 28.57 PSNR, 0.885 SSIM, 0.138 LPIPS [S1]. With 12 views, GlobalSplat32K achieves 29.54 PSNR, 0.903 SSIM, 0.121 LPIPS [S1].
*   **Strengths:** Fixed Gaussian budget (16K) regardless of input view count; extremely fast inference; low memory footprint; global consistency via latent tokens [S1].
*   **Limitations:** Fixed capacity may limit detail in very complex scenes compared to adaptive methods; requires careful tuning of the merging temperature and curriculum [S1].

## Background
GlobalSplat was introduced by R. Itkin et al. in 2025 [S1]. It addresses the limitation of existing feed-forward 3DGS pipelines where primitives are formed in dense view-aligned spaces, leading to representation bloat and fragile global consistency as more views are added [S1]. It builds on the principles of differentiable rendering and feed-forward prediction established in [Feed-forward and Generalizable Prediction](15832-feed-forward-and-generalizable-prediction.md).
