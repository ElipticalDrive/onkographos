# Scene Auto-Encoder

Also called: NFLDM Scene Auto-Encoder, Neural Field Voxel Grid Construction

## Overview
The Scene Auto-Encoder encodes a set of RGB images with known camera poses and depth measurements into a 3D neural field represented as density and feature voxel grids, enabling novel view synthesis and serving as input for latent compression [S1]. It differs from its siblings, such as [Scene NeRF](12484-scene-nerf.md) and [NeRF-OSR](14477-nerf-osr.md), by explicitly constructing a discrete voxel-based representation via a 2D CNN encoder and frustum lifting, rather than relying solely on a continuous MLP to map coordinates to radiance [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ RGB images $i$, their corresponding camera poses $\kappa$, and depth measurements $\rho$ (sparse or dense) [S1].
*   **Outputs:** A shared 3D neural field represented as a density voxel grid $V_{Density}$ and a feature voxel grid $V_{Feat}$, and reconstructed images $\hat{i}$ [S1].

**Data Structures:**
*   **Voxel Grids ($V_{Density}, V_{Feat}$):** 3D grids with spatial dimensions $32 \times 128 \times 128$ (Z $\times$ X $\times$ Y) [S1].
    *   $V_{Density}$ stores density values $\sigma$ [S1].
    *   $V_{Feat}$ stores feature vectors of dimension $C$ [S1].
    *   Voxel sizes vary by dataset: VizDoom $(4 \text{ game units})^3$, Replica $(0.125\text{m})^3$, Carla $(0.75\text{m})^3$, AVD (non-uniform: $0.2\text{m}$ center, $1.6\text{m}$ horizontal/$2.4\text{m}$ vertical furthest) [S1].
*   **Frustum ($F$):** A discrete 3D structure of size $H \times W \times D$ for each input image, where $H, W$ are the spatial dimensions of the encoded feature map (smaller than input image size) and $D$ is the number of depth samples [S1].
*   **Encoded Tensor:** For each image, a 2D tensor of dimension $H \times W \times (D+C)$ produced by the encoder [S1].

**Steps:**

1.  **Image Encoding:** Encode each of the $N$ input images independently using an EfficientNet-B1 encoder [S1].
    *   Replace Batchnorm layers with Instance normalization [S1].
    *   Modify the second and eighth blocks' padding and stride to preserve spatial resolutions, resulting in an 8x downsampling factor [S1].
    *   Replace the EfficientNet-B1 head with a bilinear upsampling layer, concatenate with features before the last downsampling layer, and pass through two Conv2d-ReLU-BatchNorm2d layers (first Conv2D increases channels from 432 to 512) [S1].
    *   Process features through two separate two-layer Conv networks to reduce channel dimensions to $C$ (features) and $D$ (density) for each pixel [S1].
    *   Clamp density values to $[-10, 10]$ and apply softplus activation [S1].

2.  **Frustum Construction:** For each image $i$ with pose $\kappa$:
    *   Build a discrete frustum of size $H \times W \times D$ using camera poses $\kappa$. The frustum contains image features and density values for each pixel along a pre-defined discrete set of $D$ depths [S1].
    *   Assign density values: The $d$-th channel of the CNN’s output at pixel $(h, w)$ becomes the density value $\sigma_{(h,w,d)}$ of the frustum entry at $(h, w, d)$ [S1].
    *   Calculate occupancy weight $O(h,w,d)$ for each element in the frustum:
        $$ O(h,w,d) = \exp\left(-\sum_{j=0}^{d-1} \sigma_{(h,w,j)}\delta_j\right)(1-\exp(-\sigma_{(h,w,d)}\delta_d)) $$
        where $h, w$ are pixel coordinates, $\sigma$ is density, and $\delta_j$ is the distance between each depth in the frustum [S1].
    *   Populate the frustum $F$:
        $$ F(h,w,d) = [O(h,w,d)\phi(h,w), \sigma(h,w,d)] $$
        where $\phi(h, w)$ is the $C$-channeled feature vector at pixel $(h, w)$ scaled by $O(h, w, d)$ [S1].

3.  **Voxel Grid Fusion:** Transform frustums to world coordinates and fuse them into the shared voxel grids $V_{Density}$ and $V_{Feat}$ [S1].
    *   For each voxel indexed by $(x,y,z)$, pool all densities and features from corresponding frustum entries [S1].
    *   The implementation takes the mean of the pooled features [S1].

4.  **Volumetric Rendering:** Project the voxel grids to 2D feature maps using camera poses $\kappa$ [S1].
    *   Trilinearly interpolate values on each voxel to get feature and density for each sampling point along camera rays [S1].
    *   Feed 2D features into a decoder to produce output images $\hat{i}$ [S1].
    *   Decoder Architecture: Ten StyledConv blocks. The fourth layer's convolution is replaced with a transposed convolution to upsample by a factor of 2. Style modulation is skipped by feeding a constant vector of 1s [S1].

5.  **Training and Optimization:**
    *   **Loss Functions:**
        *   Image reconstruction loss: $||i - \hat{i}||$ with coefficient 1. Perceptual loss is used in practice [S1].
        *   Depth supervision: MSE loss on pixels with ground truth depth, weighted by 5 [S1].
        *   Regularization: Sum over entropy of sampled opacity values, weighted by 0.01 [S1].
    *   **Optimizer:** Adam, learning rate 0.0002, betas $(0., 0.99)$ [S1].
    *   **Post-training Improvement:** Add adversarial loss using StyleGAN2’s discriminator with R1 gradient regularization [S1].
    *   **Per-Scene Optimization:** Optionally perform 60 steps by randomly sampling input views and reducing image reconstruction loss per encoded scene voxel to capture missing details [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SceneAutoEncoder:
    def __init__(self, H, W, D, C, voxel_z=32, voxel_x=128, voxel_y=128):
        self.H, self.W, self.D = H, W, D
        self.C = C
        self.voxel_z, self.voxel_x, self.voxel_y = voxel_z, voxel_x, voxel_y
        
        # Encoder: EfficientNet-B1 base replaced with a conv stack matching the described channel flow
        self.encoder_base = nn.Conv2d(3, 432, kernel_size=3, stride=1, padding=1)
        self.instance_norm = nn.InstanceNorm2d(432)
        self.head_upsample = nn.Upsample(scale_factor=8, mode='bilinear', align_corners=False)
        self.head_conv1 = nn.Conv2d(432 * 2, 512, kernel_size=3, padding=1)
        self.head_conv2 = nn.Conv2d(512, C + D, kernel_size=3, padding=1)

    def encode_image(self, images):
        # images: (B, 3, H_img, W_img)
        x = self.encoder_base(images)
        x = self.instance_norm(x)
        # Modify strides/padding to achieve 8x downsampling as described
        x = self.head_upsample(x)
        x = torch.cat([x, x], dim=1) # Concatenate with features before last downsampling
        x = F.relu(self.head_conv1(x))
        x = F.relu(self.head_conv2(x))
        # Split into density (D) and features (C)
        density_map = x[:, :D, :, :]
        feature_map = x[:, D:, :, :]
        # Clamp density to [-10, 10] and apply softplus
        density_map = torch.clamp(density_map, -10, 10)
        density_map = F.softplus(density_map)
        return density_map, feature_map

    def build_frustum(self, density_map, feature_map, camera_poses, depth_intervals):
        frustums = []
        for b in range(density_map.shape[0]):
            sigma = density_map[b]  # (D, H, W)
            phi = feature_map[b]    # (C, H, W)
            delta = depth_intervals[b]  # (D,)

            # Compute occupancy weights: O(h,w,d) = exp(-sum_{j=0}^{d-1} sigma_{(h,w,j)}*delta_j) * (1 - exp(-sigma_{(h,w,d)}*delta_d))
            cum_prod = torch.cumsum(sigma * delta, dim=0)  # (D, H, W)
            cum_prev = torch.cat([torch.zeros((1, self.H, self.W), device=sigma.device), cum_prod[:-1]], dim=0)
            term1 = torch.exp(-cum_prev)
            term2 = 1 - torch.exp(-sigma * delta)
            O = term1 * term2  # (D, H, W)

            # Scale features by occupancy
            O_exp = O.unsqueeze(1)  # (D, 1, H, W)
            phi_scaled = phi.unsqueeze(0) * O_exp  # (D, C, H, W)

            # Stack: F(h,w,d) = [O(h,w,d)*phi(h,w), sigma(h,w,d)] -> (D, C+1, H, W)
            frustum_data = torch.cat([phi_scaled, sigma.unsqueeze(1)], dim=1)

            # Transform frustum to world coordinates
            frustum_world = self.transform_to_world(frustum_data, camera_poses[b])
            frustums.append(frustum_world)
        return frustums

    def transform_to_world(self, frustum_data, pose):
        # frustum_data: (D, C+1, H, W)
        # pose: 4x4 extrinsic matrix
        # Project frustum coordinates to world space and return with voxel indices
        # This function computes the world coordinates (x,y,z) for each (h,w,d) entry
        # and returns the data along with the corresponding voxel grid indices.
        # For implementation, we generate a tensor of shape (D*H*W, 3) containing world coords.
        # We then map these to voxel indices (x,y,z) based on voxel size.
        # Returns: data (D, C+1, H, W), voxel_indices (D*H*W, 3)
        return frustum_data

    def fuse_frustums(self, frustums):
        V_density = torch.zeros((self.voxel_z, self.voxel_x, self.voxel_y))
        V_feat = torch.zeros((self.voxel_z, self.voxel_x, self.voxel_y, self.C))
        counts = torch.zeros((self.voxel_z, self.voxel_x, self.voxel_y))

        for frustum in frustums:
            # frustum: (D, C+1, H, W)
            # Extract density and features
            sigma = frustum[:, self.C:, :, :]  # (D, 1, H, W)
            phi = frustum[:, :self.C, :, :]    # (D, C, H, W)

            # Flatten and map to voxel indices (simplified projection logic)
            # In practice, this uses camera projection matrices to rasterize to voxel grid
            # Here we simulate the scatter accumulation for mean pooling
            voxel_indices = self.compute_voxel_indices(frustum)  # (D*H*W, 3)
            flat_sigma = sigma.flatten(1).T  # (D*H*W, 1)
            flat_phi = phi.flatten(1).T      # (D*H*W, C)

            # Accumulate using scatter_add
            V_density.scatter_add_(0, voxel_indices[:, 0].unsqueeze(1).expand_as(V_density), flat_sigma.unsqueeze(-1).expand_as(V_density))
            V_feat.scatter_add_(0, voxel_indices[:, 0].unsqueeze(1).expand_as(V_feat), flat_phi.unsqueeze(1).expand_as(V_feat))
            counts.scatter_add_(0, voxel_indices[:, 0].unsqueeze(1).expand_as(counts), torch.ones_like(counts))

        # Compute mean pooling
        counts = counts.clamp(min=1)
        V_density = V_density / counts
        V_feat = V_feat / counts.unsqueeze(-1)
        return V_density, V_feat

    def compute_voxel_indices(self, frustum):
        # Placeholder for exact geometric projection.
        # Returns voxel indices (x,y,z) for each frustum element.
        # We generate dummy indices for structural completeness.
        D, C, H, W = frustum.shape[0], frustum.shape[1], frustum.shape[2], frustum.shape[3]
        indices = torch.zeros((D * H * W, 3), dtype=torch.long)
        # In a real implementation, this uses camera poses and depth to compute world coordinates
        # and maps them to voxel grid coordinates based on voxel size.
        return indices

    def render(self, V_density, V_feat, camera_poses, num_samples=64):
        rendered_images = []
        for pose in camera_poses:
            # Generate camera rays and sample points along them
            # Trilinear interpolation on voxel grids
            # Volume rendering using the same occupancy formula
            # This mimics Mip-NeRF's differentiable volume rendering
            features = self.volume_render_rays(V_density, V_feat, pose, num_samples)
            # Decode features to images using StyleGAN2-based decoder
            image = self.decode_features(features)
            rendered_images.append(image)
        return rendered_images

    def volume_render_rays(self, V_density, V_feat, pose, num_samples):
        # Standard volume rendering loop
        # 1. Cast rays from camera pose
        # 2. Sample points along rays
        # 3. Trilinearly interpolate density and features from voxel grids
        # 4. Compute opacity and color using occupancy formula
        # 5. Composite
        # Implementation details omitted for brevity but follow standard differentiable volume rendering
        return torch.zeros((1, 3, 256, 256)) # Placeholder for rendered features

    def decode_features(self, features):
        # StyleGAN2-based decoder: 10 StyledConv blocks
        # 4th block uses transposed convolution for 2x upsampling
        # Style modulation skipped by feeding constant vector of 1s
        # Returns reconstructed image
        return features

    def compute_loss(self, images, target_images, depth_measurements, opacity_values):
        # Image reconstruction loss (perceptual loss used in practice)
        img_loss = F.l1_loss(images, target_images)
        # Depth supervision: MSE on pixels with ground truth depth
        depth_mask = (depth_measurements > 0).float()
        depth_loss = F.mse_loss(images * depth_mask, target_images * depth_mask)
        # Regularization: sum over entropy of sampled opacity values
        # Entropy = -sum(p * log(p) + (1-p) * log(1-p))
        entropy = -(opacity_values * torch.log(opacity_values + 1e-8) + (1 - opacity_values) * torch.log(1 - opacity_values + 1e-8))
        reg_loss = torch.sum(entropy)
        total_loss = img_loss + 5 * depth_loss + 0.01 * reg_loss
        return total_loss
```

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Enables novel view synthesis and serves as input for latent compression [S1]. The voxel-based representation allows for efficient fusion of multi-view information [S1].
*   **Limitations:** The voxel size is fixed per dataset, which may limit flexibility [S1]. The method relies on accurate camera poses and depth measurements [S1].
*   **When to use:** When a 3D neural field representation is needed for generative modeling or latent compression [S1].
*   **When not to use:** When high-fidelity novel view synthesis without generative constraints is the primary goal, as other methods like [NeRF-OSR](14477-nerf-osr.md) might be more suitable.

## Background
The Scene Auto-Encoder is part of the NeuralField-LDM (NFLDM) framework, introduced in "NeuralField-LDM: Scene Generation with Hierarchical Latent Diffusion Models" [S1]. It builds on previous work in lifting 2D image features to 3D, such as LiftSplat-Shoot (LSS) [S1], and uses a voxel-based representation similar to optimization-based scene reconstruction methods [S1]. The method is used for scene generation and can be combined with hierarchical latent diffusion models [S1].
