# Smoothed 2D Supervision

Also called: Adaptive Gaussian blur strategy, Progressive Gaussian Blurring

## Overview
Smoothed 2D Supervision is a regularization technique that enhances the robustness of joint optimization (e.g., camera pose and scene parameters) by smoothing the 2D supervision signal [S1][S2, unofficial]. It solves the problem of unstable gradients and poor camera alignment caused by high-frequency noise in raw training images [S2, unofficial]. Unlike [Frequency Regularization](6130-frequency-regularization.md) which operates in the spectral domain or [FreGS](9212-fregs.md) which adapts loss weights dynamically, Smoothed 2D Supervision explicitly blurs the ground-truth images with a scheduled 2D Gaussian kernel to restrict the spectrum of the learned 3D scene and produce smoother image gradients [S2, unofficial][S3].

## How it works
**Inputs and Outputs:**
- Input: Raw 2D training images $I_{raw}$, camera parameters, and 3D scene representation (e.g., Gaussians or NeRF).
- Output: Smoothed supervision images $I_{smooth}$ used in the photometric loss $\mathcal{L}_{photo}$.

**Data Structures:**
- Gaussian Kernel $K$: Defined by standard deviation $\sigma$ and kernel size $W \times W$.
- Schedule Parameters: Initial $\sigma_0$, initial $W_0$, decay interval $k_b$, and total iterations $T$.

**Method Steps:**
1. **Initialization:** Set initial kernel size $W = W_0$ (e.g., $9 \times 9$) and standard deviation $\sigma = \sigma_0$ (e.g., 2.4) [S4].
2. **Iteration Loop:** For each training iteration $t$:
   a. **Kernel Adjustment:** If $t$ is a multiple of $k_b$ (e.g., $k_b = 100$) and $t < T$ (e.g., $T = 19500$), reduce $\sigma$ and $W$ [S4]. The reduction is typically exponential or linear towards 0 [S2, unofficial][S3].
   b. **Downsampling Adjustment:** If image downsampling is active, scale the kernel size by the downsampling factor to maintain consistency with the original resolution hyperparameters [S4].
   c. **Pre-densification Adjustment:** Before densifying Gaussians, lower the kernel size to introduce extra gradient signal on erroneous Gaussians as the noise level reduces [S4].
   d. **Blurring:** Convolve each raw training image $I_{raw}$ with the current kernel $K(\sigma, W)$ to produce $I_{smooth}$:
      $$ I_{smooth} = I_{raw} * K $$
   e. **Loss Computation:** Compute photometric loss (e.g., L1 or SSIM) between the rendered image and $I_{smooth}$ [S2, unofficial].

**Pseudocode:**
```python
def smoothed_2d_supervision(raw_images, iteration, total_iterations=19500, 
                            decay_interval=100, initial_sigma=2.4, 
                            initial_kernel_size=9, downsampling_scale=1.0):
    """
    Generates smoothed supervision images for a given iteration.
    """
    # 1. Determine current kernel parameters based on schedule
    sigma = initial_sigma
    kernel_size = initial_kernel_size
    
    # Progressive reduction: reduce sigma and kernel size every decay_interval iterations
    if iteration > 0 and iteration % decay_interval == 0 and iteration < total_iterations:
        # Exponential decay towards 0 is common in radiance field literature [S2, unofficial]
        # Linear decay is also used [S3]
        # Here we assume a linear reduction to 0 over the interval for clarity,
        # though exact decay function may vary by implementation [S2, unofficial][S3].
        progress = iteration / total_iterations
        sigma = initial_sigma * (1.0 - progress)
        kernel_size = initial_kernel_size * (1.0 - progress)
        
        # Ensure kernel size is at least 1
        kernel_size = max(1, int(round(kernel_size)))
        sigma = max(0.0, sigma)

    # 2. Adjust for downsampling if active [S4]
    # The initial hyperparameters are based on original image resolution.
    # If images are downsampled by factor 'd', the effective blur in original space
    # must be scaled.
    if downsampling_scale > 1.0:
        # Scale kernel size by the downsampling factor
        effective_kernel_size = kernel_size * downsampling_scale
        # Note: Sigma scaling depends on whether sigma is in pixel units of the 
        # downsampled or original image. Typically, sigma is scaled by downsampling_scale
        # to maintain the same physical blur extent in the original image space.
        sigma = sigma * downsampling_scale
    else:
        effective_kernel_size = kernel_size

    # 3. Apply Gaussian Blur to each raw image
    smoothed_images = []
    for img in raw_images:
        # Create 2D Gaussian kernel
        # K(x, y) = exp(-(x^2 + y^2) / (2 * sigma^2))
        kernel = create_gaussian_kernel(effective_kernel_size, sigma)
        
        # Convolve image with kernel
        # Use separable convolution for efficiency if supported
        blurred_img = convolve_2d(img, kernel)
        smoothed_images.append(blurred_img)
        
    return smoothed_images

def create_gaussian_kernel(size, sigma):
    """
    Creates a 2D Gaussian kernel of given size and sigma.
    """
    if sigma == 0:
        # Identity kernel if sigma is 0
        kernel = np.zeros((size, size))
        center = size // 2
        kernel[center, center] = 1.0
        return kernel
    
    # Create coordinate grids
    y, x = np.ogrid[:size, :size]
    center = size // 2
    y -= center
    x -= center
    
    # Calculate Gaussian values
    kernel = np.exp(-(x**2 + y**2) / (2 * sigma**2))
    
    # Normalize kernel
    kernel /= np.sum(kernel)
    return kernel

def convolve_2d(image, kernel):
    """
    Performs 2D convolution of image with kernel.
    """
    # Pad image to handle boundaries
    pad_size = kernel.shape[0] // 2
    padded_image = np.pad(image, pad_size, mode='reflect')
    
    # Perform convolution
    # Using separable property for efficiency: 1D vertical then 1D horizontal
    h_kernel = kernel[0, :]
    v_kernel = kernel[:, 0]
    
    # Vertical pass
    temp = np.zeros_like(padded_image)
    for i in range(padded_image.shape[0]):
        for j in range(padded_image.shape[1]):
            val = 0
            for k in range(kernel.shape[0]):
                val += padded_image[i + k, j] * v_kernel[k]
            temp[i, j] = val
            
    # Horizontal pass
    result = np.zeros_like(temp)
    for i in range(temp.shape[0]):
        for j in range(temp.shape[1]):
            val = 0
            for k in range(kernel.shape[1]):
                val += temp[i, j + k] * h_kernel[k]
            result[i, j] = val
            
    # Crop back to original size
    return result[pad_size:-pad_size, pad_size:-pad_size]
```

**Parameters:**
- Initial $\sigma$: 2.4 [S4].
- Initial Kernel Size: $9 \times 9$ [S4].
- Decay Interval ($k_b$): 100 iterations [S4].
- Total Iterations for Decay: 19500 [S4].
- Decay Type: Exponential to 0 [S2, unofficial] or Linear [S3]. Sources differ on the exact decay function; [S2, unofficial] suggests exponential, [S3] mentions linear increase of weights or adaptive reduction.

**Edge Cases and Pitfalls:**
- **Sigma = 0:** When $\sigma$ reaches 0, the kernel becomes a delta function (identity). Ensure the convolution handles this efficiently [S2, unofficial].
- **Boundary Conditions:** Use reflection or replication padding to avoid edge artifacts in blurred images [G].
- **Downsampling Mismatch:** If downsampling is used, failing to scale the kernel size by the downsampling factor leads to incorrect frequency suppression [S4].

## Subtopics

### [Randomly Scaled Kernel Parameter](7875-randomly-scaled-kernel-parameter.md)
Randomly Scaled Kernel Parameter is a regularization technique used during joint optimization to mitigate weak and noisy gradient signals. It addresses the insufficiency of using a single-size kernel for diverse real-world scene structures, where a fixed kernel may be overly aggressive in some contexts and overly gentle in others. By randomly scaling the kernel size, it allows combinations of different-sized kernels to guide the optimization, resulting in a more robust training schedule.

### [Multiscale Pre-convolved Representation](10911-multiscale-pre-convolved-representation.md)
A regularization technique for neural illumination fields that stabilizes the decomposition of object materials from environmental illumination by enforcing consistency with pre-computed, roughness-adapted background reflections. It addresses the ambiguity where diffuse object color is incorrectly absorbed into the estimated environment map, a problem inherent to high-dimensional neural illumination representations. Unlike methods that ignore the background or treat it as static, this method explicitly models the relationship between rough refractive surfaces and the convolved background, allowing for realistic specular reflections even when roughness exceeds the kernel scale. The technique builds on [Smoothed 2D Supervision](7213-smoothed-2d-supervision.md) by applying discrete Gaussian blur kernels to the background to stabilize convergence.

### [Soft Rasterization](13687-soft-rasterization.md)
Soft rasterization is a differentiable rendering technique that mitigates the discontinuities inherent in standard rasterization by blending facet contributions for pixels near primitive edges. It solves the problem of sparse and vanishing gradients caused by the non-uniformity of bilinear interpolation operands, which typically have similar values except at object boundaries. Unlike standard hard rasterization, it yields slightly distorted images but allows backpropagating more useful gradients, thereby stabilizing optimization and preventing gradient vanishing at edges.

## Operating characteristics
**Time and Memory Complexity:**
- Time: Adding a Gaussian blur step increases per-iteration cost by $O(W^2)$ per pixel, where $W$ is the kernel size. Using separable convolution reduces this to $O(W)$ per pixel [S1].
- Memory: Requires storing the blurred images or computing them on-the-fly. On-the-fly computation saves memory [G].

**Measured Performance:**
- On DTU 3-view, Smoothed 2D Supervision (Adaptive Gaussian Blur) achieves 19.72 PSNR, improving over the Baseline (19.54) [S3].
- It reduces training iterations to 50k compared to 200k for previous MLP-based methods, reducing overall training time to 25% [S1].

**Strengths and Limitations:**
- Strengths: Stabilizes camera alignment, restricts high-frequency noise, and improves robustness in joint optimization [S1][S2, unofficial].
- Limitations: Handcrafted schedule may not fully align frequency relationships compared to adaptive methods like [FreGS](9212-fregs.md) [S3].

**When to Use:**
- Use when joint optimization of camera poses and scene parameters is unstable [S1].
- Use when high-frequency noise in training images leads to poor convergence [S2, unofficial].

**When Not to Use:**
- When adaptive frequency alignment is available and preferred [S3].
- When computational budget is extremely tight and blur cost is prohibitive [G].

## Background
Smoothed 2D Supervision was introduced to improve the robustness of joint optimization in radiance fields and Gaussian Splatting [S1][S2, unofficial]. It is inspired by spectral analysis showing that blurring training images produces smoother gradients and restricts the spectrum of the learned scene [S2, unofficial]. It is often used in conjunction with other regularization techniques like [Frequency Regularization](6130-frequency-regularization.md) and [Randomly Scaled Kernel Parameter](7875-randomly-scaled-kernel-parameter.md) [S1].
