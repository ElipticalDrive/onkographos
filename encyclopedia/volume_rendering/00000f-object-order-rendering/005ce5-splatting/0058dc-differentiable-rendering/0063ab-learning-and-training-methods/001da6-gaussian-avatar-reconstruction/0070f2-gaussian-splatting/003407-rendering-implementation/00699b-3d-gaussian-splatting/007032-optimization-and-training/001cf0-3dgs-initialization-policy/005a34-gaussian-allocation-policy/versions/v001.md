# Gaussian Allocation Policy
Also called: GSPO-based allocation

## Overview
The Gaussian Allocation Policy (GAP) is a reinforcement learning method that determines how to distribute a fixed budget of 3D Gaussians among learned anchor tokens to maximize rendering fidelity [S1, unofficial]. It differs from heuristic initialization methods by treating allocation as a discrete optimization problem solved via Group Sequence Policy Optimization (GSPO), allowing the policy to learn complex geometric dependencies between anchors and required Gaussian density [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of anchor tokens $\{a_n\}_{n=1}^N$ encoding local 3D regions, and a target Gaussian budget $B$.
*   **Outputs:** A discrete allocation vector $k = \{k_n\}_{n=1}^N$, where $k_n$ is the integer count of Gaussians assigned to anchor $n$, such that $\sum_{n=1}^N k_n = B$ [S1, unofficial].

**Data Structures:**
*   **Anchor Tokens:** Feature vectors representing geometric primitives.
*   **Policy Network $\pi_\psi$:** A neural network that takes anchor tokens as input and outputs allocation proportions $p = \{p_n\}_{n=1}^N$.
*   **Allocation Vector $k$:** Integer array of size $N$.

**Algorithm Steps:**
1.  **Proportion Prediction:** The policy $\pi_\psi$ processes the anchor tokens $\{a_n\}$ to predict allocation proportions $p = \{p_n\}_{n=1}^N$, where $p_n$ represents the expected fraction of the budget $B$ assigned to anchor $n$ [S1, unofficial].
2.  **Stochastic Sampling (Training):** For each training step, draw $C$ candidate allocations (rollouts). For each rollout $c \in \{1, \dots, C\}$, sample $k^{(c)}$ from a multinomial distribution:
    $$ k^{(c)} \sim \text{Mult}(B, \text{sg}(p)) $$
    where $\text{sg}(\cdot)$ denotes the stop-gradient operator, ensuring gradients do not flow through the sampling process [S1, unofficial].
3.  **Representation Generation:** For each rollout $c$, generate the 3D Gaussian Splatting (3DGS) representation $G^{(c)}$ using the allocated counts $k^{(c)}$ and the resource-linear decoder [S1, unofficial].
4.  **Rendering and Reward:** Render an image $\hat{I}^{(c)}$ from $G^{(c)}$ at novel target views. Compute the reconstruction loss $\mathcal{L}_{\text{recon}}$ between $\hat{I}^{(c)}$ and the ground truth image $I$. The reward is defined as the negative loss:
    $$ R_c = -\mathcal{L}_{\text{recon}} $$
    Gradients are not tracked during this evaluation [S1, unofficial].
5.  **Advantage Calculation:** Compute the group-relative advantage $\hat{A}_c$ by standardizing the rewards within the group of $C$ rollouts:
    $$ \hat{A}_c = \frac{R_c - \text{mean}\{R_{c'}\}_{c'=1}^C}{\text{std}\{R_{c'}\}_{c'=1}^C} $$
    [S1, unofficial]
6.  **Importance Ratio:** Compute the length-normalized importance ratio $s_c$ for each rollout to account for the change in policy probability:
    $$ s_c = \exp \left( \frac{1}{B} \sum_{n=1}^N k_n^{(c)} \log \frac{p_n}{\text{sg}(p_n)} \right) $$
    [S1, unofficial]
7.  **Policy Update:** Maximize the clipped surrogate objective $J_{\text{policy}}$:
    $$ J_{\text{policy}} = \mathbb{E} \left[ \frac{1}{C} \sum_{c=1}^C \min \left( s_c \hat{A}_c, \text{clip}(s_c, 1-\epsilon, 1+\epsilon) \hat{A}_c \right) \right] $$
    where $\epsilon$ is the clipping range [S1, unofficial].
8.  **Inference:** Bypass stochastic sampling. Convert the expected counts $B p$ into an integer allocation $k$ summing exactly to $B$ using a deterministic rounding procedure [S1, unofficial].

**Pseudocode:**
```python
def gaussian_allocation_policy(anchor_tokens, budget, num_rollouts, clip_epsilon, policy_net):
    """
    Implements the Gaussian Allocation Policy optimization step.
    
    Args:
        anchor_tokens: List of anchor feature vectors.
        budget: Total number of Gaussians B.
        num_rollouts: Number of candidate allocations C.
        clip_epsilon: Clipping range epsilon.
        policy_net: Neural network returning allocation proportions p.
        
    Returns:
        policy_net: Updated network parameters.
    """
    # 1. Predict proportions
    proportions = policy_net(anchor_tokens)
    
    # 2. Sample rollouts using stop-gradient on proportions
    # k_samples shape: (num_rollouts, num_anchors)
    k_samples = sample_multinomial(budget, stop_gradient(proportions), num_rollouts)
    
    rewards = []
    importance_ratios = []
    
    for c in range(num_rollouts):
        k_c = k_samples[c]
        
        # 3. Generate 3DGS representation and render
        # Note: In practice, this involves spawning Gaussians and rasterizing
        rendered_image = render_3dgs(anchor_tokens, k_c)
        ground_truth_image = get_ground_truth_view()
        
        # 4. Compute reward
        loss = compute_reconstruction_loss(rendered_image, ground_truth_image)
        reward = -loss
        rewards.append(reward)
        
        # 5. Compute importance ratio
        # s_c = exp( (1/B) * sum( k_n * log(p_n / sg(p_n)) ) )
        log_ratio_sum = 0.0
        for n in range(len(anchor_tokens)):
            log_ratio_sum += k_c[n] * log(proportions[n] / stop_gradient(proportions[n]))
        importance_ratio = exp(log_ratio_sum / budget)
        importance_ratios.append(importance_ratio)
        
    # 6. Compute group-relative advantage
    rewards_tensor = tensor(rewards)
    mean_reward = mean(rewards_tensor)
    std_reward = std(rewards_tensor)
    advantages = (rewards_tensor - mean_reward) / std_reward
    
    # 7. Update policy via clipped objective
    # J = E[ (1/C) * sum( min(s_c * A_c, clip(s_c, 1-eps, 1+eps) * A_c) ) ]
    ratios_tensor = tensor(importance_ratios)
    clipped_ratios = clip(ratios_tensor, 1 - clip_epsilon, 1 + clip_epsilon)
    
    term1 = ratios_tensor * advantages
    term2 = clipped_ratios * advantages
    losses = min(term1, term2)
    
    policy_loss = mean(losses)
    
    # Backpropagate through policy_net to update psi
    update_parameters(policy_net, policy_loss)
    
    return policy_net

def sample_multinomial(budget, probs, num_samples):
    """
    Samples discrete allocations from a multinomial distribution.
    Args:
        budget: Integer B.
        probs: Tensor of probabilities p.
        num_samples: Integer C.
    Returns:
        Tensor of shape (num_samples, len(probs)) with integer counts summing to budget.
    """
    # Implementation detail: Use a library function or custom C++/CUDA kernel
    # for efficient multinomial sampling that respects the sum constraint.
    # Here we assume a standard multinomial sampler exists.
    return multinomial_sample(probs, budget, num_samples)
```

**Parameters:**
*   $C$: Number of rollouts (candidate allocations) drawn per training step [S1, unofficial].
*   $\epsilon$: Clipping range for the importance ratio in the policy objective [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Probability:** If $p_n = 0$ but $k_n > 0$, the log term in the importance ratio becomes undefined. The stop-gradient on the denominator prevents this during training if the policy is well-initialized, but numerical stability requires ensuring $p_n > 0$ or handling the limit [S1, unofficial].
*   **Rounding Errors:** At inference, the deterministic rounding of $B p$ must ensure $\sum k_n = B$. Standard rounding may fail this constraint; a specific rounding procedure (e.g., largest remainder method) is required [S1, unofficial].

## Subtopics

### DART (Distance-Aware Replication on Tangent-planes)
A heuristic initialization method that replicates Gaussians based on distance to tangent planes, lacking the learned adaptive allocation of GAP. See [DART](12512-dart-distance-aware-replication-on-tangent-planes.md).

## Operating characteristics
*   **Time Complexity:** The policy optimization step scales linearly with the number of rollouts $C$ and the number of anchors $N$. Rendering $C$ views per step adds overhead, but 3DGS rasterization is highly efficient, keeping this minimal [S1, unofficial].
*   **Memory Complexity:** Requires storing $C$ intermediate 3DGS representations and gradients for the policy network. Memory usage scales with $C \times B$ [S1, unofficial].
*   **Strengths:** Enables resource-linear decoding where Gaussian count scales linearly with budget $B$. Adapts allocation to geometric complexity automatically [S1, unofficial].
*   **Limitations:** Requires reinforcement learning training loop, which is more complex to implement than static initialization. Performance depends on the quality of the anchor tokens [S1, unofficial].

## Background
The Gaussian Allocation Policy was introduced in the context of resource-linear 3D Gaussian Splatting, specifically in the RLSplat framework [S1, unofficial]. It leverages Group Sequence Policy Optimization (GSPO) to solve the discrete allocation problem, addressing the need for compact and high-fidelity representations by densely allocating Gaussians to geometrically complex regions [S1, unofficial].
