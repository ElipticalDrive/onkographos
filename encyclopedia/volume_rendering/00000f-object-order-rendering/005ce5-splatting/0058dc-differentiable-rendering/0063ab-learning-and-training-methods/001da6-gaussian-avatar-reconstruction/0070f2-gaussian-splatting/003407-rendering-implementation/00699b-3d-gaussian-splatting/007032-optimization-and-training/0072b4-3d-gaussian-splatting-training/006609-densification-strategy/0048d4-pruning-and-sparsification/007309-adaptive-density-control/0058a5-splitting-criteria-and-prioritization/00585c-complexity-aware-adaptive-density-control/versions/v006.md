# Complexity-Aware Adaptive Density Control

Also called: Complexity-Aware Density Control, Complexity-Aware Level of Details, Complexity-Guided Relocation

## Overview
Complexity-Aware Adaptive Density Control is a training optimization strategy for 3D Gaussian Splatting that replaces opacity-only heuristics with a composite importance score incorporating image complexity, opacity, and scale [S1, unofficial]. It solves the problem of inefficient primitive distribution by biasing densification toward high-complexity regions and ensuring uniform degradation across different levels of detail (LoD) budgets [S1, unofficial]. It differs from standard 3DGS by using a complexity field as a surrogate for reconstruction error, and from its siblings by explicitly modeling the exponential relationship between particle count and visual complexity [S1, unofficial].

## How it works
The method operates by maintaining a per-Gaussian complexity value, updating it online during training, and using it to modulate both the probability of relocating primitives (densification) and the retention score for variable budget rendering (LoD) [S1, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   Set of 3D Gaussians $G = \{g_j\}$, where each $g_j$ has mean $\mu_j$, covariance $\Sigma_j$, opacity $\alpha_j$, and scale $s(g_j)$.
    *   Camera views $\Pi_i$ with projection function $\pi_i$.
    *   Target LoD budget factor $\tau \in (0, 1]$.
    *   Hyperparameters: EMA learning rate $\eta \in (0, 1]$, scalar weight $\lambda = 2$, complexity dropout probability $\delta = 0.2$, variance loss weight $\lambda_{var}$ [S1, unofficial].
*   **Outputs:**
    *   Updated Gaussian set $G$ with refined positions, scales, opacities, and complexity values $C_j$.
    *   Rendered images optimized for uniform error distribution across LoD levels.

### Data Structures
*   **Complexity Field $C_j$:** A scalar value stored per Gaussian $g_j$. Initialized to 0. Updated via exponential moving average [S1, unofficial].
*   **Normalized Complexity $\tilde{C}_j$:** A value in $[0, 1]$ derived from $C_j$ via min-max normalization over the current training batch or global statistics [S1, unofficial].

### Steps

1.  **Complexity Map Computation:**
    For each training view $i$, compute a 2D complexity map $C_i^{2D}(u)$ using delentropy [S1, unofficial]. This map serves as a surrogate for local reconstruction error [S1, unofficial].

2.  **Complexity Update:**
    After rendering view $i$, project the means of all contributing Gaussians into the image plane. For each Gaussian $g_j$ whose center $\mu_j$ projects within the view's frustum:
    $$ C_j \leftarrow (1 - \eta) C_j + \eta C_i^{2D}(\pi_i(\mu_j)) $$
    Gaussians outside the frustum retain their previous $C_j$ [S1, unofficial]. Over time, $C_j$ converges to a multi-view average complexity [S1, unofficial].

3.  **Relocation Sampling (Densification):**
    When selecting a Gaussian $g_j$ to spawn new primitives or relocate, sample with probability $p(g_j)$:
    $$ p(g_j) = \alpha_j \cdot \exp(\tilde{C}_j) $$
    To prevent collapse onto fixed complex regions, apply complexity dropout: with probability $\delta = 0.2$, set $\tilde{C}_j = 0$ for that candidate, scoring it by opacity alone [S1, unofficial].

4.  **Importance Scoring (LoD Retention):**
    For variable budget rendering ($\tau < 1$), rank Gaussians by importance score $S(g_j)$ to determine which primitives survive:
    $$ S(g_j) = \alpha_j + \lambda \cdot \frac{s(g_j)}{\exp(\tilde{C}_j(\mu_j))} $$
    where $s(g_j)$ is the max-normalized scale of the Gaussian [S1, unofficial].
    *   In high-complexity regions ($\exp(\tilde{C}_j)$ is large), the scale term is attenuated, prioritizing opacity [S1, unofficial].
    *   In low-complexity regions ($\exp(\tilde{C}_j) \to 1$), the scale term dominates, allowing large primitives to efficiently cover simple areas [S1, unofficial].

5.  **Variance Loss Minimization:**
    To ensure uniform degradation, compute the residual $\Delta_i$ between the full-capacity error $E(I_i^{full})$ and the budgeted error $E(I_i^{\tau})$ for view $i$:
    $$ \Delta_i = E(I_i^{full}) - E(I_i^{\tau}) $$
    Minimize the spatial variance of this residual:
    $$ L_{var} = \text{Var}_{u \in \Omega} \Delta_i(u) $$
    The total training loss is the average of L1+D-SSIM losses on full and budgeted renders plus the variance loss:
    $$ \text{Total Loss} = \text{Average}(\text{L1+D-SSIM}) + \lambda_{var} L_{var} $$
    [S1, unofficial]

### Pseudocode

```python
import numpy as np

def update_complexity(gaussians, view, complexity_map, eta):
    """
    Update complexity C_j for Gaussians visible in the current view.
    """
    # Project Gaussian means to 2D image coordinates
    projected_means = project_to_image(view, gaussians.means)
    
    # Identify Gaussians within the view frustum
    visible_mask = is_in_frustum(projected_means, view)
    
    # Sample complexity values from the 2D map at projected locations
    # C_i_2D is the complexity map for view i
    sampled_complexities = sample_from_map(complexity_map, projected_means[visible_mask])
    
    # Update C_j using Exponential Moving Average
    # Only update Gaussians that are visible
    gaussians.C[visible_mask] = (1 - eta) * gaussians.C[visible_mask] + eta * sampled_complexities

def compute_normalized_complexity(gaussians):
    """
    Min-max normalize C_j to [0, 1] to get tilde_C_j.
    """
    c_min = np.min(gaussians.C)
    c_max = np.max(gaussians.C)
    # Avoid division by zero
    if c_max == c_min:
        return np.zeros_like(gaussians.C)
    return (gaussians.C - c_min) / (c_max - c_min)

def sample_relocation_candidates(gaussians, normalized_C, dropout_prob=0.2):
    """
    Sample Gaussians for densification/relocation based on complexity-aware probability.
    """
    # Apply dropout: with probability delta, set normalized_C to 0
    dropout_mask = np.random.rand(len(gaussians)) < dropout_prob
    effective_C = np.where(dropout_mask, 0.0, normalized_C)
    
    # Compute probability p(g_j) = alpha_j * exp(tilde_C_j)
    probs = gaussians.alpha * np.exp(effective_C)
    
    # Normalize to form a probability distribution
    probs_sum = np.sum(probs)
    if probs_sum == 0:
        return np.array([])
    probs /= probs_sum
    
    # Sample indices
    num_samples = ... # determined by densification schedule
    indices = np.random.choice(len(gaussians), size=num_samples, p=probs, replace=False)
    return indices

def compute_importance_score(gaussians, normalized_C, lambda_weight=2.0):
    """
    Compute importance score S(g_j) for LoD retention.
    """
    # s(g_j) is max-normalized scale
    s_max = np.max(gaussians.scale)
    if s_max == 0:
        s_normalized = np.zeros_like(gaussians.scale)
    else:
        s_normalized = gaussians.scale / s_max
        
    # S(g_j) = alpha_j + lambda * s(g_j) / exp(tilde_C_j)
    # Note: exp(tilde_C_j) is in denominator
    score = gaussians.alpha + lambda_weight * (s_normalized / np.exp(normalized_C))
    return score

def compute_variance_loss(render_full, render_budget, error_func):
    """
    Compute L_var = Var(Delta_i) where Delta_i = E(I_full) - E(I_budget).
    """
    # Compute error maps (e.g., L1 error)
    error_full = error_func(render_full)
    error_budget = error_func(render_budget)
    
    # Residual
    residual = error_full - error_budget
    
    # Spatial variance over the image domain Omega
    var_loss = np.var(residual)
    return var_loss
```

### Parameters
*   $\eta$: EMA learning rate for complexity update. Range $(0, 1]$ [S1, unofficial].
*   $\lambda$: Scalar weight for the scale term in importance score. Fixed at 2 [S1, unofficial].
*   $\delta$: Complexity dropout probability. Fixed at 0.2 [S1, unofficial].
*   $\lambda_{var}$: Weight for the variance loss term. Not given in the sources.
*   $\tau$: LoD budget factor. Varies during training [S1, unofficial].

### Edge Cases and Pitfalls
*   **Complexity Collapse:** Without dropout ($\delta=0$), Gaussians may collapse onto fixed complex regions. Dropout $\delta=0.2$ prevents this [S1, unofficial].
*   **Normalization Stability:** Min-max normalization of $C_j$ must handle cases where all complexity values are identical to avoid division by zero [S1, unofficial].
*   **Frustum Culling:** Only Gaussians projecting within the current view's frustum should update their complexity. Updating all Gaussians with interpolated values from outside the view introduces noise [S1, unofficial].
*   **Scale Normalization:** The scale $s(g_j)$ must be max-normalized across the current set of Gaussians to ensure consistent weighting relative to $\lambda$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Adds overhead for computing the 2D complexity map (dentropy) and updating per-Gaussian complexity values. The complexity update is $O(N)$ per view where $N$ is the number of Gaussians [S1, unofficial].
*   **Memory Complexity:** Requires storing a scalar complexity value $C_j$ per Gaussian, adding $O(N)$ memory [S1, unofficial].
*   **Performance:** On the Tanks and Temples dataset at 100% capacity, it achieves PSNR 29.92, SSIM 0.911, LPIPS 0.240, outperforming 3DGS-MCMC (PSNR 29.70, SSIM 0.907, LPIPS 0.236) and LightGaussian (PSNR 29.73, SSIM 0.907, LPIPS 0.240) [S1, unofficial]. At 1% capacity, it achieves PSNR 23.40, SSIM 0.798, LPIPS 0.419, significantly outperforming baselines like OctreeGS (PSNR 24.68 at 10% capacity, but unreachable at 1%) and FlexGS (unreachable) [S1, unofficial].
*   **Strengths:** Uniform degradation across LoD levels; efficient primitive usage in low-complexity regions; robust against collapse.
*   **Limitations:** Requires online complexity map computation; sensitive to the choice of $\lambda$ and $\delta$ [S1, unofficial].

## Background
The method originates from the KoalaGS paper, which introduces complexity-aware continuous level of detail for Gaussian Splatting [S1, unofficial]. It addresses the limitation of standard 3DGS variants that rely on opacity as a proxy for reconstruction error, which fails to account for spatial footprint and leads to under-served regions [S1, unofficial]. The approach builds on the observation that particle count grows exponentially with visual complexity [S1, unofficial].
