# Data Compression and Storage Optimization

Also called: 3DGS Compression, Gaussian Quantization, Codebook-Based Compression

## Overview
Data compression and storage optimization addresses the high memory and storage overhead of 3D Gaussian Splatting (3DGS), which often exceeds 1GB for large scenes due to the storage of per-Gaussian attributes (position, opacity, scale, rotation, and high-order spherical harmonic coefficients) [S1, S2, unofficial]. These methods reduce storage requirements by exploiting spatial redundancy, quantizing attributes, or clustering parameters into codebooks, achieving compression ratios from 10x to over 25x while maintaining visual fidelity [S1, S2, unofficial]. They differ from sibling methods like [Pruning and Density Control](16215-pruning-and-density-control.md) by focusing on encoding efficiency rather than primitive count reduction, and from [Hardware and Computational Acceleration](16214-hardware-and-computational-acceleration.md) by targeting storage bandwidth and disk size rather than rendering speed directly.

## Shared principles
All methods in this family aim to reduce the storage footprint of the Gaussian scene representation. The core mechanism involves replacing the direct storage of high-dimensional or high-precision floating-point attributes with more compact representations. Common techniques include:
1.  **Vector Quantization/Clustering:** Grouping similar attribute vectors (e.g., SH coefficients, scale/rotation) into a codebook and storing only indices [S1, S2, unofficial].
2.  **Quantization:** Reducing the bit-depth of attributes (e.g., FP16 to INT8) [S2, unofficial].
3.  **Neural Fields/Grids:** Using a shared neural network (e.g., hash grid) to predict attributes like color based on position, exploiting spatial redundancy [S1, unofficial].
4.  **Entropy Encoding:** Applying lossless compression (e.g., DEFLATE) to the compressed indices or attributes, often after sorting by spatial coherence (Morton order) [S1, unofficial].

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
Focuses on transmission efficiency during training by encoding numerical attributes into compact ASCII strings.

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
Uses gradient-based sensitivity to weight clustering, preserving high-impact parameters in codebooks.

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
Combines hash grids for color and codebooks for geometry, achieving >25x storage reduction.

### [Monte Carlo Specular Energy Aggregator](15439-monte-carlo-specular-energy-aggregator.md)
Compresses high-order SH into first-order SH using Monte Carlo aggregation of specular residuals, avoiding distillation.

### Sparse Adaptive Scalable Compact Gaussian Splatting
- [S1, unofficial] A compression method that utilizes vector clustering to encode color and geometric attributes.

### 3DGS Quantization Compression
- [S2, unofficial] Reduces storage footprint of 3DGS scenes by quantizing per-Gaussian attributes and using codebooks, achieving ~10x smaller sizes without significant quality loss.
- [S2, unofficial] Per-Gaussian attribute storage: position (FP16), scales (FP16), opacity (INT8), spherical harmonic coefficients (INT8 or codebook-based).

## Background
The high storage cost of 3DGS, primarily driven by spherical harmonic coefficients and per-primitive attributes, has motivated significant research into compression [S1, S2, unofficial]. Early approaches like LightGaussian combined pruning with INT8 quantization and SH distillation [S2, unofficial]. Subsequent methods introduced codebook-based compression (CompGS, C3DGS) and sensitivity-aware clustering to improve quality at high compression ratios [S1, S2, unofficial]. The field continues to evolve with methods targeting specific aspects like specular highlights (MC-SEA) or transmission efficiency (ASCII compression) [S1, unofficial].
