# AnySplat Pipeline

Also called: Feed-forward 3D Gaussian Splatting from Unconstrained Views

## Overview
AnySplat is a feed-forward method that predicts 3D Gaussian Splatting parameters and camera poses directly from uncalibrated input images, eliminating the need for iterative optimization or known camera intrinsics/extrinsics [S1, unofficial]. It differs from sibling methods like [FineSplat](15257-finesplat.md) and [SparSplat](15813-sparsplat.md) by explicitly predicting camera poses alongside Gaussian parameters, enabling novel view synthesis from unconstrained view sets without prior calibration [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $K$ uncalibrated RGB images $\{I_i\}_{i=1}^K$. The input tensor shape is $[1, K, 3, 448, 448]$ (batch, views, channels, height, width) [S1, unofficial].
*   **Outputs:**
    *   A set of 3D Gaussians defined by parameters $\Theta = \{\mu, \sigma, r, s, c\}$ (mean, scale, rotation, opacity, color) [S1, unofficial].
    *   Predicted camera poses $p$ (intrinsic and extrinsic matrices) [S1, unofficial].
    *   A predicted depth map $D$ [S1, unofficial].

**Data Structures:**
The method constructs pixel-wise 3D Gaussians. These are then processed by a **Differentiable Voxelization** module to produce "pre-voxel 3D Gaussians" suitable for efficient rendering [S1, unofficial]. The specific internal layout of the voxelization structure is not detailed in the sources [G].

**Algorithm Steps:**
1.  **Feature Extraction:** Pass the input images through a transformer-based geometry encoder to extract multi-scale features [S1, unofficial].
2.  **Parameter Prediction:** Decode the features using three heads:
    *   $F_G$: Predicts Gaussian parameters $\mu, \sigma, r, s, c$ [S1, unofficial].
    *   $F_D$: Predicts a depth map $D$ [S1, unofficial].
    *   $F_C$: Predicts camera poses $p$ (intrinsics and extrinsics) [S1, unofficial].
3.  **Gaussian Construction:** Construct pixel-wise 3D Gaussians using the predicted parameters $\Theta$ and depth $D$ [S1, unofficial].
4.  **Voxelization:** Apply the Differentiable Voxelization module to convert pixel-wise Gaussians into pre-voxel 3D Gaussians [S1, unofficial].
5.  **Rendering:** Render multi-view images and depth maps from the voxelized Gaussians using differentiable rasterization [S1, unofficial].
6.  **Loss Computation:**
    *   **RGB Loss:** Compare rendered images against ground truth images [S1, unofficial].
    *   **Geometry Loss:** Compute losses using rendered depth maps, decoded depth $D$, and predicted poses $p$ [S1, unofficial].
7.  **Supervision:** Supervise the geometry predictions using pseudo-geometry priors obtained from a pretrained VGGT model [S1, unofficial].

**Parameters:**
*   Input resolution: $448 \times 448$ pixels [S1, unofficial].

*   VGGT: A pretrained model used for generating pseudo-geometry priors [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Uncalibrated Input:** The method handles uncalibrated images, but accuracy depends on the quality of the predicted poses and the VGGT priors [S1, unofficial].
*   **Voxelization:** The specific implementation details of the Differentiable Voxelization module are not provided [G].

## Subtopics

### [SubSplat](13524-subsplat.md)
A high-resolution variant that uses a Sub-pixel Gaussian Reparameterizer to increase Gaussian density from low-resolution features.

### [Deformable Radial Kernel (DRK)](13699-deformable-radial-kernel-drk.md)
A variant replacing fixed radial Gaussians with flexible planar kernels for better geometric fidelity.

## Background
AnySplat was introduced by InternRobotics as a feed-forward approach to 3D Gaussian Splatting [S1, unofficial]. It builds on the principles of differentiable rendering and neural field optimization, specifically targeting the limitation of requiring calibrated camera poses in standard 3DGS pipelines [S1, unofficial].
