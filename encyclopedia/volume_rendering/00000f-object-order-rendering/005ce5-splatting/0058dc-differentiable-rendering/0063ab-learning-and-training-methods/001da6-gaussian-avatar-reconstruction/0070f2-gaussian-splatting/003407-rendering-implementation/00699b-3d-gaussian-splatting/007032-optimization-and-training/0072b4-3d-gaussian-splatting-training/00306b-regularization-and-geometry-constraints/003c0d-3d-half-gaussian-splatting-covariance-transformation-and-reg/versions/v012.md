# 3D Half-Gaussian Splatting Covariance Transformation and Regularization

Also called: 3D-HGS

## Overview
This method modifies the covariance structure of 3D Gaussians to enforce half-ellipsoid geometry, allowing them to model sharp surface boundaries and occlusions more effectively than full ellipsoids [S1]. It solves the problem of "bloated" or "double-sided" Gaussian artifacts that occur when full ellipsoids intersect object surfaces, by projecting the covariance into a local basis aligned with a surface normal and regularizing the depth component [S1]. Unlike [Frequency Regularization](6130-frequency-regularization.md) which operates in the spectral domain, or [Hard and Soft Depth Regularization](9178-hard-and-soft-depth-regularization.md) which uses external depth priors, this method intrinsically alters the Gaussian shape during training to match surface geometry [S1].

## How it works
The method transforms the standard 3D Gaussian covariance matrix $\Sigma$ into a "half-Gaussian" form by aligning it with a local surface normal and suppressing the variance along the normal direction. This transformation is applied periodically during training.

### Inputs and Outputs
*   **Input:** The original 3D Gaussian covariance matrix $\Sigma \in \mathbb{R}^{3 \times 3}$, which is symmetric and positive definite. The surface normal vector $n \in \mathbb{R}^3$ at the Gaussian's position $\mu$.
*   **Output:** The regularized covariance matrix $\sigma \in \mathbb{R}^{3 \times 3}$, representing a half-Gaussian oriented along $n$.

### Data Structures
The covariance matrix is stored as a $3 \times 3$ symmetric matrix. In implementation, this is often derived from scale $s$ and rotation $q$ parameters as $\Sigma = R S S^T R^T$, where $R$ is the rotation matrix from quaternion $q$ and $S$ is the diagonal scale matrix. The transformation operates directly on the $3 \times 3$ matrix representation.

### Algorithm Steps
The transformation is performed every 5000 training iterations [S1].

1.  **Normalize Normal:** Ensure the surface normal is unit length:
    $$ n \leftarrow \frac{n}{\|n\|} $$

2.  **Construct Local Basis:** Create an orthonormal basis matrix $B$ where the third column is the normal $n$, and the first two columns $v_1, v_2$ span the tangent plane.
    *   If $n_x = 0$ and $n_y = 0$ (i.e., $n$ is parallel to the z-axis):
        $$ v_1 = (1, 0, 0)^T, \quad v_2 = (0, 1, 0)^T $$
    *   Otherwise:
        $$ v_1 = \frac{(n_y, -n_x, 0)^T}{\|(n_y, -n_x, 0)\|} $$
        $$ v_2 = \frac{n \times v_1}{\|n \times v_1\|} $$
    *   Concatenate to form the basis matrix:
        $$ B = [v_1, v_2, n] $$

3.  **Project to Local Basis:** Transform the covariance matrix into the local coordinate system defined by $B$:
    $$ \text{cov} = B^T \Sigma B $$
    Let $\text{cov}_{ij}$ denote the element at row $i$, column $j$ of this matrix.

4.  **Compute Regularized Diagonal/Off-Diagonal Terms:** Calculate the modified terms $a', b', c'$ which effectively marginalize out the normal direction variance from the tangent plane components:
    $$ a' = \text{cov}_{0,0} - \frac{\text{cov}_{0,2}^2}{\text{cov}_{2,2}} $$
    $$ b' = \text{cov}_{0,1} - \frac{\text{cov}_{0,2} \cdot \text{cov}_{1,2}}{\text{cov}_{2,2}} $$
    $$ c' = \text{cov}_{1,1} - \frac{\text{cov}_{1,2}^2}{\text{cov}_{2,2}} $$
    *Note: This step assumes $\text{cov}_{2,2} > 0$. If $\text{cov}_{2,2}$ is near zero, numerical stability measures are required [G].*

5.  **Construct Regularized Local Covariance:** Build the new covariance matrix $\sigma_{\text{local}}$ in the basis space. The tangent plane components ($0,0; 0,1; 1,1$) are updated to $a', b', c'$. The cross-terms with the normal ($0,2; 1,2$) are set to 0. The normal variance ($2,2$) is set to a small fraction of the tangent variances to enforce flatness:
    $$ \sigma_{\text{local}} = \begin{pmatrix} a' & b' & 0 \\ b' & c' & 0 \\ 0 & 0 & \min(a', c') / 100 \end{pmatrix} $$
    The matrix is symmetric, so $\sigma_{\text{local}, 1,0} = b'$ and $\sigma_{\text{local}, 2,0} = \sigma_{\text{local}, 0,2} = 0$, etc.

6.  **Transform Back to World Space:**
    $$ \sigma = B \sigma_{\text{local}} B^T $$

### Parameters
*   **Regularization Interval:** The transformation is applied every 5000 iterations [S1].
*   **Opacity Thresholds:** To support the half-Gaussian representation and reduce noise, the opacity threshold for densification and pruning is increased to 0.01, and the initial opacity for half-Gaussians is reset to 0.02 [S1].
*   **Flatness Factor:** The normal variance is scaled by $1/100$ relative to the minimum tangent variance [S1].

### Pseudocode
```python
def transform_covariance_to_half_gaussian(cov_matrix: np.ndarray, normal: np.ndarray) -> np.ndarray:
    """
    Transforms a 3x3 covariance matrix into a half-Gaussian form aligned with a surface normal.
    
    Args:
        cov_matrix: 3x3 symmetric covariance matrix Sigma.
        normal: 3D unit normal vector n.
        
    Returns:
        Regularized 3x3 covariance matrix sigma.
    """
    # 1. Normalize normal
    n = normal / np.linalg.norm(normal)
    
    # 2. Construct basis
    # Check if normal is parallel to Z axis
    if abs(n[0]) < 1e-6 and abs(n[1]) < 1e-6:
        v1 = np.array([1.0, 0.0, 0.0])
        v2 = np.array([0.0, 1.0, 0.0])
    else:
        # v1 is perpendicular to n and lies in XY plane projection
        v1 = np.array([n[1], -n[0], 0.0])
        v1 = v1 / np.linalg.norm(v1)
        # v2 is orthogonal to both n and v1
        v2 = np.cross(n, v1)
        v2 = v2 / np.linalg.norm(v2)
        
    # Basis matrix B = [v1, v2, n]
    B = np.column_stack((v1, v2, n))
    
    # 3. Project to local basis
    cov_local = B.T @ cov_matrix @ B
    
    # 4. Compute modified terms
    # Guard against division by zero or near-zero cov[2,2]
    cov_22 = cov_local[2, 2]
    if cov_22 < 1e-8:
        cov_22 = 1e-8
        
    a_prime = cov_local[0, 0] - (cov_local[0, 2]**2) / cov_22
    b_prime = cov_local[0, 1] - (cov_local[0, 2] * cov_local[1, 2]) / cov_22
    c_prime = cov_local[1, 1] - (cov_local[1, 2]**2) / cov_22
    
    # 5. Construct regularized local covariance
    # The normal variance is minimized to enforce half-Gaussian (flat) geometry
    min_tangent_var = min(a_prime, c_prime)
    normal_var = min_tangent_var / 100.0
    
    sigma_local = np.array([
        [a_prime, b_prime, 0.0],
        [b_prime, c_prime, 0.0],
        [0.0, 0.0, normal_var]
    ])
    
    # 6. Transform back to world space
    sigma = B @ sigma_local @ B.T
    
    return sigma
```

### Edge Cases and Pitfalls
*   **Degenerate Normal:** If the normal vector is zero or undefined, the basis construction fails. A fallback basis (e.g., identity) or skipping the regularization for that iteration is required [G].
*   **Positive Definiteness:** The transformation may result in a covariance matrix that is not strictly positive definite if $a'$ or $c'$ become negative due to numerical errors or ill-conditioned input $\Sigma$. Clamping negative eigenvalues to a small positive value is recommended [G].
*   **Frequency:** Applying this transformation too frequently may destabilize training. The source specifies every 5000 iterations [S1].

## Operating characteristics
*   **Time Complexity:** The transformation involves matrix multiplications ($3 \times 3$) and vector operations, which is $O(1)$ per Gaussian. However, it is only applied every 5000 iterations, so the per-frame overhead during rendering is negligible. The densification/pruning adjustments (opacity thresholds) may slightly increase the number of Gaussians, impacting rasterization time.
*   **Memory Complexity:** No additional memory structures are required beyond the standard Gaussian parameters. The method modifies existing covariance data.
*   **Performance:** On the Mip-NeRF 360 dataset, 3D-HGS with an efficient rasterizer achieves 125 FPS and 29.66 PSNR using 3.8M kernels, compared to 3DGS which uses 3.2M kernels [S1]. On Tank & Dengin, it achieves 160 FPS and 24.45 PSNR with 1.8M kernels [S1]. On Tank & Blending, it achieves 126 FPS and 29.76 PSNR with 2.6M kernels [S1].
*   **Strengths:** Effectively models sharp surface boundaries and occlusions, reducing "ghosting" artifacts common in full-Gaussian splatting. Consistently outperforms original 3DGS in PSNR [S1].
*   **Limitations:** Requires accurate surface normals for the transformation. If normals are noisy or incorrect, the half-Gaussian orientation will be wrong, potentially degrading quality. The method increases the number of kernels required to achieve comparable detail to 3DGS in some scenes (e.g., 3.8M vs 3.2M on Mip-NeRF 360) [S1].

## Background
The method was introduced in the paper "3D-HGS: 3D Half-Gaussian Splatting" [S1]. It builds upon the 3D Gaussian Splatting framework [Parent](6269-regularization-and-geometry-constraints.md) by addressing the limitation of full ellipsoids in representing sharp geometric features. The concept of half-Gaussians is inspired by the need to model one-sided surfaces, similar to techniques used in implicit surface representations. The method is evaluated against Scaffold, mip-splatting, and MCMC architectures [S1].
