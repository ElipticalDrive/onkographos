# Data Compression and Storage Optimization

Also called: 3DGS Compression, Gaussian Quantization, Codebook-based Compression

## Overview
Data compression and storage optimization reduces the memory footprint and transmission cost of 3D Gaussian Splatting (3DGS) scenes by quantizing attributes, clustering primitives, or replacing explicit storage with learned representations [S1, S2, unofficial]. It differs from general lossless compression by exploiting the semantic redundancy of Gaussian primitives (e.g., shared colors or similar shapes) rather than just bit-level entropy, often trading negligible visual quality for significant storage gains (e.g., >10× to >25×) [S1, S2, unofficial].

## Shared principles
All methods in this family operate on the set of $N$ Gaussian primitives $\{G_i\}$, where each $G_i$ is defined by position $\mu_i$, scale $\hat{s}_i$, rotation $r_i$ (quaternion), opacity $o_i$, and spherical harmonic (SH) coefficients $c_i$ [S1, unofficial]. The core mechanism involves reducing the storage per primitive from raw floating-point vectors to compact indices or lower-precision values [S1, unofficial].

1.  **Quantization:** Mapping continuous values to a discrete set. Common precisions include FP16 for position/scale, INT8 for opacity/SH, or custom bit-widths [S2, unofficial].
2.  **Vector Quantization (Clustering):** Grouping similar attribute vectors (e.g., SH coefficients or shape parameters) into a codebook of size $K$. Each Gaussian stores only an index $k \in \{0, \dots, K-1\}$ [S1, unofficial].
3.  **Redundancy Exploitation:** Removing spatially redundant Gaussians (pruning) or sharing attributes across neighbors (hash grids, neural fields) [S1, unofficial].
4.  **Entropy Coding:** Applying lossless compression (e.g., DEFLATE, GPCC) to the resulting indices and residuals to further reduce file size [S1, S2, unofficial].

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
Reduces bit-width during data transmission using Base-94/95 ASCII mapping. It trades transmission efficiency for implementation simplicity in Python training loops, yielding ~6% speed improvement [11820-ascii-based-data-compression.md].

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
Uses sensitivity-aware k-Means to cluster SH and shape parameters into codebooks. It prioritizes preserving parameters that significantly affect image quality, excluding high-sensitivity vectors from clustering [12167-sensitivity-aware-vector-clustering.md].

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
Achieves >25× compression by eliminating redundant Gaussians via learnable masks, sharing color via a hash grid, and quantizing geometry into a codebook [12927-compact-3d-gaussian-representation-c3dgs.md].

### [Monte Carlo Specular Energy Aggregator](15439-monte-carlo-specular-energy-aggregator.md)
Compresses third-order SH into first-order SH by aggregating specular energy into latent variables ($E_{mag}, E_{dir}$) via Monte Carlo sampling, avoiding expensive distillation [15439-monte-carlo-specular-energy-aggregator.md].

### Sparse Adaptive Scalable Compact Gaussian Splatting
A compression method that utilizes vector clustering to encode color and geometric attributes into two codebooks, guided by a sensitivity-aware k-means method [S1, unofficial].

### 3DGS Quantization Compression
Reduces storage footprint by quantizing per-Gaussian attributes and using codebooks, achieving ~10× smaller sizes without significant quality loss [S2, unofficial]. Per-Gaussian attribute storage typically uses: position (FP16), scales (FP16), opacity (INT8), and spherical harmonic coefficients (INT8 or codebook-based) [S2, unofficial].

## Background
Compression for 3DGS emerged as the standard representation's memory footprint (often gigabytes for large scenes) became a bottleneck for storage and streaming [S1, S2, unofficial]. Early works like LightGaussian combined pruning with INT8 quantization and SH distillation [S1, unofficial]. Subsequent methods like C3DGS and SASCGS introduced codebook-based vector quantization and hash grids to exploit spatial and attribute redundancy [S1, unofficial]. The field also explores mesh extraction (e.g., SuGaR, Gaussian Frosting) as an alternative storage format for narrow domains [S2, unofficial].
