# Hybrid Compression Framework

Also called: Adaptive Voxelization and GPCC Compression for 3DGS

## Overview
The Hybrid Compression Framework is a post-training compression method for 3D Gaussian Splatting (3DGS) that reduces model size and bandwidth by combining adaptive voxelization with Generalized Prediction Context Coding (GPCC) [S1]. It addresses the impracticality of generative compression, which requires retraining distinct models for each bitrate, and the quality degradation of standard post-training methods due to parameter distortion [S1]. By quantizing mean positions to voxel centers and fine-tuning remaining attributes, it achieves higher quality at lower bitrates compared to sibling methods like Mini-Splatting-C [S1, 10131-mini-splatting-c.md].

## How it works
**Inputs:** Pre-trained 3DGS model $G = \{\mu_i, \Sigma_i, C_i, \alpha_i\}_{i=1}^N$, where $\mu_i \in \mathbb{R}^3$ are means, $\Sigma_i \in \mathbb{R}^{3\times3}$ are covariances, $C_i$ are spherical harmonic (SH) coefficients, and $\alpha_i \in [0,1]$ are opacities [S1]. Training images $\{\tilde{I}_i\}_{i=1}^k$ and camera views $\{\tilde{\theta}_i\}_{i=1}^k$ [S1].

**Outputs:** Compressed bitstream containing GPCC-coded positions, covariances, SH coefficients, and opacities [S1].

**Data Structures:**
1. **Voxelized Model $\tilde{G}$:** A set of $M$ Gaussians ($M < N$) with quantized means $\{\hat{\mu}_i\}_{i=1}^M$, fine-tuned covariances $\{\tilde{\Sigma}_i\}_{i=1}^M$, fine-tuned SH coefficients $\{\tilde{C}_i\}_{i=1}^M$, and fine-tuned opacities $\{\tilde{\alpha}_i\}_{i=1}^M$ [S1].
2. **GPCC Context:** Octree structure for position coding; transform coding context for attributes [S1].

**Parameters:**
* $Q_{dc}$: Quantization parameter for low-frequency SH coefficients (DC/base color) [S1].
* $Q_{ac}$: Quantization parameter for high-frequency SH coefficients (AC) [S1].
* $Q_{op}$: Quantization parameter for opacity [S1].
* $J$: Number of octree partitioning levels (resolution) [S1].

**Steps:**
1. **Adaptive Voxelization:** Partition the 3D space into an octree up to level $J$, where only occupied voxels are subdivided [S1]. Quantize each Gaussian mean $\mu_i$ to the center of its containing voxel $\hat{\mu}_i$ [S1]. Merge Gaussians falling into the same voxel to obtain unique voxel centers $\{\hat{\mu}_i\}_{i=1}^M$ [S1].
2. **Attribute Initialization:** For each unique voxel center $\hat{\mu}_i$, initialize the remaining attributes $\Sigma_i, C_i, \alpha_i$ by averaging the attributes of all original Gaussians mapped to that voxel [S1].
3. **Fine-Tuning:** Keep the quantized mean positions $\{\hat{\mu}_i\}_{i=1}^M$ fixed [S1]. Optimize the remaining attributes $\{\tilde{\Sigma}_i, \tilde{C}_i, \tilde{\alpha}_i\}_{i=1}^M$ by minimizing the training loss $L_{train}$ until the rendering quality matches the input model $G$ [S1]. The training loss is defined as:
   $$ L_{train} = \frac{1}{k} \sum_{i=1}^k \frac{1}{2} \| R_{\tilde{\theta}_i}(\tilde{G}) - \tilde{I}_i \|_F $$
   where $R_{\theta}$ is the rendering function for view $\theta$, and $\| \cdot \|_F$ is the Frobenius norm [S1].
4. **Compression:** Losslessly compress the voxelized positions $\{\hat{\mu}_i\}_{i=1}^M$ using GPCC (octree coding followed by an octree-designed entropy coder) [S1]. Compress covariances $\{\tilde{\Sigma}_i\}_{i=1}^M$ using vector quantization [S1]. Compress SH coefficients $\{\tilde{C}_i\}_{i=1}^M$ and opacities $\{\tilde{\alpha}_i\}_{i=1}^M$ using transform coding with quantization parameters $Q_{dc}$, $Q_{ac}$, and $Q_{op}$ via GPCC [S1].

**Pseudocode:**
```python
def hybrid_compression(model, train_imgs, train_views, Q_dc, Q_ac, Q_op, max_depth):
    # 1. Adaptive Voxelization
    voxel_map = {}
    for g in model:
        voxel_id = quantize_to_voxel(g.mean, max_depth) # [G] standard octree quantization
        voxel_map.setdefault(voxel_id, []).append(g)

    voxelized = []
    for voxel_id, group in voxel_map.items():
        mean = get_voxel_center(voxel_id) # [G] center of the voxel cube
        # Initialize attributes by averaging merged Gaussians
        cov = sum(g.cov for g in group) / len(group)
        sh = sum(g.sh for g in group) / len(group)
        alpha = sum(g.alpha for g in group) / len(group)
        voxelized.append({'mean': mean, 'cov': cov, 'sh': sh, 'alpha': alpha})

    # 2. Fine-Tuning
    # Keep quantized means fixed, optimize attributes to minimize L_train
    for g in voxelized:
        g.mean = g.mean  # Fixed
    # Minimize L_train = (1/k) * sum_{i=1}^k (1/2) * ||R_theta_i(G) - I_i||_F
    voxelized = gradient_descent_optimize(voxelized, train_imgs, train_views) # [Comment: Sources do not specify the exact optimizer or convergence criteria]

    # 3. Compression
    # Positions: lossless GPCC (octree coding + entropy coder)
    pos_stream = gpcc_octree_encode([g['mean'] for g in voxelized]) # [Comment: Standard GPCC implementation]
    # Covariances: vector quantization
    cov_stream = vector_quantize_encode([g['cov'] for g in voxelized]) # [Comment: Standard vector quantization]
    # SH and Opacity: transform coding with quantization parameters
    sh_stream = gpcc_transform_encode([g['sh'] for g in voxelized], Q_dc, Q_ac)
    alpha_stream = gpcc_transform_encode([g['alpha'] for g in voxelized], Q_op)

    return pos_stream + cov_stream + sh_stream + alpha_stream
```

## Operating characteristics
* **Time Complexity:** Requires a fine-tuning phase after voxelization, which incurs retraining costs proportional to the number of voxels and training iterations [S1].
* **Memory/Bandwidth:** Significantly reduces model size compared to the original 3DGS by merging Gaussians and compressing attributes [S1].
* **Quality:** Achieves higher quality at equivalent bitrates compared to standard post-training PCC methods by mitigating distortion through fine-tuning [S1].
* **Strengths:** No need to retrain the entire model from scratch for different bitrates (unlike generative compression) [S1].
* **Limitations:** The fine-tuning step adds computational overhead during compression [S1].

## Background
The method was proposed in "Adaptive Voxelization for Transform Coding of 3D Gaussian Splatting Data" (2025) [S1]. It builds on the observation that 3DGS data can be viewed as a 3D point cloud (3DPC) [S1]. Previous post-training methods relied on point cloud compression (PCC) but suffered from quality loss due to parameter distortion [S1]. Generative compression methods, while efficient, require retraining for each rate-distortion point, making them impractical for multi-rate applications [S1]. This framework combines adaptive voxelization with GPCC to balance compression efficiency and rendering quality [S1].
