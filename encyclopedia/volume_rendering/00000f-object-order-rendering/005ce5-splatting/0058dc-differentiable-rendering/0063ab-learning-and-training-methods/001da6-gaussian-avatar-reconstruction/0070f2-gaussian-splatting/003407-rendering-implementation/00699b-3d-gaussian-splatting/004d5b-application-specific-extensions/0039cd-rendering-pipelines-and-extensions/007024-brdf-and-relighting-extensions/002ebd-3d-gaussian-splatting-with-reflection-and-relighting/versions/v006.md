# 3D Gaussian Splatting with Reflection and Relighting

Also called: Gaussian-Shader, 3DGS-DR, IRGS, Relightable 3D Gaussians, GS-IR

## Overview
This method extends 3D Gaussian Splatting (3DGS) by incorporating classical physically based rendering (PBR) concepts to address limitations with highly reflective surfaces and enable relighting under novel illumination [S1][S2, unofficial]. Unlike standard 3DGS, which bakes lighting into spherical harmonics via an emission-absorption model, this approach decomposes geometry, material, and lighting, allowing for dynamic specular shading synthesis [S1, S3]. It distinguishes itself from NeRF-based PBR methods by leveraging the Gaussian kernel’s natural normal estimation, avoiding the time-consuming training and slow rendering speeds associated with gradient-based normal estimation in volumetric representations [S3].

## How it works
**Inputs:**
*   Optimized 3D Gaussian primitives (position, covariance, opacity, view-dependent color).
*   Scene environment map (lighting).
*   Camera parameters.

**Outputs:**
*   Relit image with accurate specular reflections and interreflections.

**Data Structures:**
Each Gaussian $i$ is augmented with the following fields:
1.  **Albedo** ($\rho_i$): Per-Gaussian diffuse albedo.
2.  **Roughness** ($\alpha_i$): Per-Gaussian surface roughness.
3.  **Metallic** ($m_i$): Per-Gaussian metallic factor.
4.  **Normal** ($\mathbf{n}_i$): Per-Gaussian surface normal.
5.  **Scene Lighting** ($L_e$): Environment map or learned lighting field.

**Normal Estimation:**
The normal $\mathbf{n}_i$ is derived from the Gaussian kernel's shape. Specifically, it corresponds to the shortest axis of the Gaussian covariance ellipsoid [S3]. This provides a robust normal estimate without additional differentiable surface reconstruction or expensive gradient computations [S3].

**Rendering Steps:**
1.  **Primary Ray Casting:** For each pixel, cast a primary ray from the camera.
2.  **Gaussian Splatting:** Project Gaussians onto the image plane. Compute the contribution of each Gaussian to the pixel based on its opacity and projected covariance [S1].
3.  **BRDF Evaluation:** At the intersection point (or centroid) of the Gaussian, evaluate the BRDF using the stored albedo, roughness, metallic, and normal [S2, unofficial].
4.  **Lighting Integration:**
    *   **Direct Lighting:** Sample the environment map for direct illumination [S1].
    *   **Indirect Lighting:** Model indirect lighting using spherical harmonics or additional environment map samples [S1].
5.  **Secondary Rays (Interreflections):** Integrate secondary rays (reflections and refractions) spawned upon primary ray interactions with Gaussians using ray tracing techniques to model interreflections [S1]. This step distinguishes the method from simple direct-lighting relighting [S1].
6.  **Compositing:** Alpha-composite the contributions of all splatted Gaussians along the ray to produce the final pixel color [S1].

**Pseudocode:**
```python
def render_relit_gaussians(camera, gaussians, env_map):
    """
    Renders a scene using 3D Gaussians with PBR and relighting.
    
    Args:
        camera: Camera object with position, orientation, and intrinsics.
        gaussians: List of Gaussian objects, each containing:
            - pos: (x, y, z) position
            - cov: 3x3 covariance matrix
            - opacity: float
            - albedo: (r, g, b)
            - roughness: float
            - metallic: float
            - normal: (nx, ny, nz) derived from shortest axis of cov
        env_map: Environment map function L_e(omega) returning radiance.
        
    Returns:
        Image buffer.
    """
    image = zeros(camera.resolution)
    
    # Iterate over pixels
    for y in range(camera.resolution.height):
        for x in range(camera.resolution.width):
            ray_origin = camera.position
            ray_direction = camera.get_ray_direction(x, y)
            
            # Collect contributing Gaussians (spatial acceleration structure implied)
            contributing_gaussians = get_contributing_gaussians(gaussians, ray_origin, ray_direction)
            
            # Sort Gaussians by distance along ray
            contributing_gaussians.sort(key=lambda g: dot(g.pos - ray_origin, ray_direction))
            
            accumulated_color = vec3(0.0)
            accumulated_opacity = 0.0
            
            for gaussian in contributing_gaussians:
                # Project Gaussian to 2D
                proj_cov = project_covariance(gaussian.cov, camera, gaussian.pos)
                proj_mean = project_position(gaussian.pos, camera)
                
                # Check if pixel center is within Gaussian support
                if not is_inside_support(proj_mean, proj_cov, x, y):
                    continue
                
                # Compute 2D Gaussian weight
                dist_sq = mahalanobis_dist(vec2(x, y), proj_mean, proj_cov)
                weight = exp(-0.5 * dist_sq) * gaussian.opacity
                
                if accumulated_opacity + weight * (1 - accumulated_opacity) >= 1.0:
                    break
                
                # Evaluate BRDF
                # Normal is derived from the shortest axis of the 3D covariance
                normal = get_shortest_axis(gaussian.cov)
                
                # Sample environment map for direct lighting
                # Reflect ray direction around normal for specular
                reflected_dir = reflect(ray_direction, normal)
                direct_light = env_map(reflected_dir)
                
                # Compute BRDF value
                brdf_value = evaluate_pbr_brdf(
                    albedo=gaussian.albedo,
                    roughness=gaussian.roughness,
                    metallic=gaussian.metallic,
                    normal=normal,
                    view_dir=ray_direction,
                    light_dir=reflected_dir,
                    env_map=env_map
                )
                
                # Combine lighting and material
                color = brdf_value * direct_light
                
                # Alpha blending
                alpha = weight
                accumulated_color = accumulated_color * (1 - alpha) + color * alpha
                accumulated_opacity = accumulated_opacity + alpha * (1 - accumulated_opacity)
            
            image[y, x] = accumulated_color
            
    return image

def evaluate_pbr_brdf(albedo, roughness, metallic, normal, view_dir, light_dir, env_map):
    """
    Simplified PBR evaluation.
    """
    # Fresnel-Schlick approximation
    F0 = mix(vec3(0.04), albedo, metallic)
    F = fresnel_schlick(max(dot(view_dir, normal), 0.0), F0)
    
    # Diffuse component
    diffuse = albedo * (1 - F) * (1 - metallic)
    
    # Specular component (simplified)
    # In a full implementation, this would involve a microfacet distribution (GGX)
    # and geometry function (Schlick-Beckmann), sampled against env_map.
    specular = F * sample_specular(env_map, light_dir, roughness)
    
    return diffuse + specular
```

**Edge Cases and Pitfalls:**
*   **Normal Degeneracy:** If a Gaussian is highly anisotropic or degenerate (e.g., flattened), the shortest axis may be unstable. Regularization or constraints on the covariance matrix may be needed [S3].
*   **Interreflection Complexity:** Modeling secondary rays with Gaussians requires efficient ray-Gaussian intersection tests and may increase computational cost significantly [S1].
*   **Precision:** High dynamic range lighting and metallic materials require careful handling of numerical precision in BRDF evaluation [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering is dominated by Gaussian splatting, which is $O(N)$ per pixel where $N$ is the number of contributing Gaussians. BRDF evaluation and environment map sampling add constant overhead per Gaussian. Secondary ray tracing adds additional cost proportional to the number of bounces and intersected Gaussians [S1, S3].
*   **Memory Complexity:** Storage increases by a constant factor per Gaussian to store albedo, roughness, metallic, and normal (typically 4-5 additional floats per Gaussian) [S2, unofficial].
*   **Performance:** Offers faster training and rendering compared to NeRF-based PBR methods due to the explicit nature of Gaussians and efficient normal estimation [S3].
*   **Strengths:** High-quality specular reflections, support for relighting, efficient normal estimation, and compatibility with existing 3DGS pipelines [S1, S3].
*   **Limitations:** May struggle with complex interreflections if secondary ray tracing is not fully optimized; relies on the assumption that Gaussians approximate surface geometry well [S1, S3].

## Background
The method originates from the need to extend 3D Gaussian Splatting beyond diffuse, baked-lighting scenes to support physically based rendering and relighting [S1]. Early 3DGS used an emission-absorption model, limiting its ability to render reflective surfaces [S1]. Subsequent works like Gaussian-Shader, 3DGS-DR, and IRGS introduced BRDF parameters and environment lighting to enable dynamic specular shading [S1, S3]. The key insight was leveraging the Gaussian kernel's covariance to derive normals, avoiding the computational overhead of NeRF-based normal estimation [S3]. This approach has been applied in various contexts, including fluid simulation and solid object rendering, demonstrating its versatility [S3].
