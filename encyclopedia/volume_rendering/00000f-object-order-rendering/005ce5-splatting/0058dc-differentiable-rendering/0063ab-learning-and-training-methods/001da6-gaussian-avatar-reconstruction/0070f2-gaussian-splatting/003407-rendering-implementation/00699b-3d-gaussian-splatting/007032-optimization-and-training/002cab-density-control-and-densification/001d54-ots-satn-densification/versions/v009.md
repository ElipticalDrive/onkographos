# OTS+SAtn Densification
Also called: Densification for Real-World Scenes

## Overview
OTS+SAtn Densification is a density control strategy adapted from the OTS+SAtn splatting technique to operate within the standard 3D Gaussian Splatting framework for real-world scene reconstruction [S1]. It addresses unbounded primitive growth by imposing strict caps on the total number of Gaussians and adapting densification thresholds to match 3DGS conventions [S1]. Unlike standard 3DGS which may allow indefinite growth, this method stops densification once a predefined maximum count (e.g., 100k, 500k, 1m, or 5m) is reached, ensuring controlled memory usage while maintaining competitive reconstruction quality [S1].

## How it works
The method integrates the OTS+SAtn rendering logic with a densification schedule that mirrors the standard 3DGS adaptive control but with specific constraints for real-world datasets like MipNeRF360 [S1].

**Inputs and Outputs:**
*   **Input:** Set of $N$ 3D Gaussians, each with position $\mathbf{p}$, covariance $\mathbf{S}$ (or scale/rotation), opacity $\alpha$, and view-space positional gradient $\nabla_{\mathbf{p}} \mathcal{L}$ [G].
*   **Output:** Updated set of Gaussians with modified positions, scales, opacities, and potentially new primitives added or removed [G].

**Data Structures:**
*   **Gaussian Set:** List of primitives storing $\mathbf{p} \in \mathbb{R}^3$, $\mathbf{S} \in \mathbb{R}^{3 \times 3}$ (symmetric positive definite), $\alpha \in [0,1]$, $\nabla_{\mathbf{p}} \mathcal{L} \in \mathbb{R}^3$, and screen-space size [G].
*   **Thresholds:**
    *   $N_{max}$: Maximum allowed primitives (e.g., 100,000, 500,000, 1,000,000, 5,000,000) [S1].
    *   $\tau_{grad}$: Gradient threshold for densification candidates [S2].
    *   $\tau_{opac}$: Opacity threshold for pruning [S2].
    *   $\tau_{size\_small}$: Size threshold for cloning candidates [S2].
    *   $\tau_{size\_large}$: Size threshold for removal candidates [S2].

**Parameters:**
*   **Densification Interval:** Executes every $K=100$ iterations starting after iteration 100 [G].
*   **Gradient Threshold:** $\tau_{grad} = 1.5 \times 10^{-4}$ [S2].
*   **Opacity Pruning Threshold:** $\tau_{opac} = 0.025$ [S2].
*   **Cloning Threshold:** Primitives smaller than $1\%$ of the scene diagonal are candidates for cloning [S2].
*   **Removal Threshold:** Primitives larger than $40\%$ of the scene diagonal or $> 20$ pixels in screen space are marked for removal [S2].
*   **Splitting Scale Factor:** Primitives are split with a relative size reduction of $1.2^{-1}$ [S2].

**Steps:**
1.  **Check Limit:** If current primitive count $N \ge N_{max}$, skip densification entirely [S1].
2.  **Evaluate Candidates:** Identify Gaussians where $|\nabla_{\mathbf{p}} \mathcal{L}| > \tau_{grad}$ [S2].
3.  **Classify Candidates:**
    *   **Small:** If 3D size $< 1\%$ of scene diagonal, mark for **Cloning** [S2].
    *   **Large:** If 3D size $> 40\%$ of scene diagonal or screen size $> 20$ pixels, mark for **Splitting** [S2].
    *   **Prune:** If $\alpha < \tau_{opac}$, mark for **Removal** [S2].
4.  **Execute Cloning:**
    *   For each "Small" candidate, create a new Gaussian at $\mathbf{p}$ with identical $\mathbf{S}$ and rotation [G].
    *   Set new opacity $\alpha_{new} = \alpha / 2$ to preserve total opacity contribution [G].
5.  **Execute Splitting:**
    *   Remove the original "Large" candidate [S2].
    *   Create two new Gaussians sampled from the original's probability density function $\mathcal{N}(\mathbf{p}, \mathbf{S})$ [G].
    *   Reduce scale by $1.2^{-1}$ and halve opacity for both new primitives [S2, G].
6.  **Execute Pruning:** Remove all Gaussians marked as "Large" or "Prune" from the set [S2].
7.  **Gradient Handling:** Do not propagate gradients through the density normalization factor [S2].

**Pseudocode:**
```python
import math
import random
from typing import List

class Gaussian:
    def __init__(self, position: List[float], covariance: List[List[float]], 
                 rotation: List[List[float]], opacity: float, gradient: List[float],
                 screen_size: float = 0.0):
        self.position = position
        self.covariance = covariance
        self.rotation = rotation
        self.opacity = opacity
        self.gradient = gradient
        self.screen_size = screen_size

def norm(v: List[float]) -> float:
    return math.sqrt(sum(x**2 for x in v))

def get_3d_size(g: Gaussian) -> float:
    return max(g.covariance[i][i] for i in range(3))

def sample_from_gaussian_pdf(g: Gaussian, scale_factor: float) -> Gaussian:
    std_devs = [math.sqrt(g.covariance[i][i]) * scale_factor for i in range(3)]
    new_pos = [g.position[i] + random.gauss(0, std_devs[i]) for i in range(3)]
    new_cov = [[g.covariance[i][j] * (scale_factor ** 2) for j in range(3)] for i in range(3)]
    return Gaussian(new_pos, new_cov, g.rotation, g.opacity / 2.0, g.gradient, g.screen_size)

def ots_satn_densification(gaussians: List[Gaussian], scene_diagonal: float, 
                           max_primitives: int, iteration: int) -> List[Gaussian]:
    if iteration < 100:
        return gaussians
    
    if len(gaussians) >= max_primitives:
        return gaussians

    to_remove = set()
    new_gaussians = []
    
    for g in gaussians:
        grad_norm = norm(g.gradient)
        size_3d = get_3d_size(g)
        
        if g.opacity < 0.025:
            to_remove.add(g)
            continue
            
        if grad_norm > 1.5e-4:
            if size_3d < 0.01 * scene_diagonal:
                clone = Gaussian(
                    position=g.position,
                    covariance=g.covariance,
                    rotation=g.rotation,
                    opacity=g.opacity / 2.0,
                    gradient=g.gradient,
                    screen_size=g.screen_size
                )
                new_gaussians.append(clone)
            elif size_3d > 0.40 * scene_diagonal or g.screen_size > 20:
                split1 = sample_from_gaussian_pdf(g, 1.0 / 1.2)
                split2 = sample_from_gaussian_pdf(g, 1.0 / 1.2)
                new_gaussians.extend([split1, split2])
                to_remove.add(g)
                
    remaining = [g for g in gaussians if g not in to_remove]
    return remaining + new_gaussians
```

## Subtopics

### [Gradient-based Densification Control](3182-gradient-based-densification-control.md)
Gradient-based Densification Control is a mechanism for allocating 3D Gaussian primitives to regions with high reconstruction error by using the magnitude of the photometric loss gradient. It ensures efficient spatial allocation by triggering cloning or splitting operations only when primitives exhibit significant gradients, thereby adapting the representation density to the scene's geometric complexity. It differs from fixed-scale splitting methods by relying on gradient magnitude rather than a static fraction of scene extent, allowing for adaptive refinement based on learning progress [G].

### LinPrim Densification and Anti-Aliasing
LinPrim Densification and Anti-Aliasing modifies the splitting logic for linear primitives (octahedra and tetrahedra) [S2]. During densification, primitives smaller than 1% of the scene are duplicated, while larger ones are replaced with two newer ones scaled by $1.2^{-1}$ [S2]. For octahedra, new positions are sampled normally with standard deviations equal to the distances in each dimension, whereas tetrahedra use standard deviations equal to half of the largest distance [S2]. Gradients are explicitly not propagated through the density normalization factor [S2]. Anti-aliasing is handled by setting the 2D filter kernel size to 0.1, shifting the ray space vector by half that amount (0.05) to account for mirrored adjustments, while keeping the 3D filter consistent with Mip-Splatting [S2].

## Operating characteristics
*   **Time Complexity:** Densification executes periodically every 100 iterations [G]. The cost is proportional to the number of candidates, which is a subset of $N$ [G].
*   **Memory Complexity:** Bounded by $N_{max}$, explicitly stopping densification at 100k, 500k, 1m, or 5m primitives [S1].
*   **Performance:** On MipNeRF360, OTS+SAtn with this densification differs from standard 3DGS by at most 4% PSNR across all tested sizes and scenes [S1]. Average training times are slightly lower (2%) for OTS+SAtn [S1]. Rendering times are balanced [S1].
*   **Strengths:** Prevents unbounded growth, suitable for large real-world scenes, maintains competitive quality [S1].
*   **Limitations:** The strict cap $N_{max}$ may limit detail in extremely complex scenes if the cap is too low [G].

## Background
The method originates from the OTS+SAtn paper, which explores alternative splatting techniques for differentiable rendering [S1]. The authors adapted their densification variables to match 3DGS as closely as possible to evaluate performance on real-world datasets like MipNeRF360 and ScanNet++ v2 [S1]. The specific thresholds and logic are further detailed in the LinPrim paper, which introduces linear primitives and anti-aliasing strategies, noting that gradients are not propagated through the density normalization factor [S2].
