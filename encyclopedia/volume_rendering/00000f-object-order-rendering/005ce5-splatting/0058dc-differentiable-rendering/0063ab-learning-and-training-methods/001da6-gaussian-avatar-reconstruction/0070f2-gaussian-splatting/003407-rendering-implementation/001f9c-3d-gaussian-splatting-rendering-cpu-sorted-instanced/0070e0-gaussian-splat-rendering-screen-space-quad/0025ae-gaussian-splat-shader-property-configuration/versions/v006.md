# Gaussian Splat Shader Property Configuration

Also called: Render property block setup, Splat instance property binding

## Overview
This method configures the GPU render pass by populating a material property block with splat count, spherical harmonic (SH) degree, brightness, scale, antialiasing settings, transform matrices, and optional skinning or volume lighting data [S1, unofficial]. It solves the problem of efficiently passing per-renderer and global state to the fragment shader without causing state overwrites in multi-camera setups or shader compilation errors when optional features (like skinning) are disabled [S1, S3, unofficial].

## How it works
### Inputs and Outputs
- **Inputs**: 
  - Splat count (`m_totalRemainingCount` or `SplatCount`) [S3, unofficial].
  - SH degree (`shDegree` or `SHBands`) [S1, unofficial].
  - Brightness scaling factor (`brightness`, default 1.0) [S1, unofficial].
  - Scale factor (`scaleFactor`, default 1.0) [S1, unofficial].
  - Renderer-specific parameters (gamma, downscale) [S3, unofficial].
  - Global buffers: Order buffer, Packed buffer, SH buffers, Transform buffers [S3, unofficial].
  - Optional: Skinning weights/bone indices if rigging is enabled [S1, unofficial].
- **Outputs**: 
  - A populated `MaterialPropertyBlock` (Unity) or uniform buffer structure containing all necessary shader constants and texture bindings [S1, unofficial].

### Data Structures
**RendererParams** [S3, unofficial]:
- `Brightness`: `float`
- `ScaleFactor`: `float`
- `GammaToLinear`: `uint` (1 if true, 0 if false)
- `SHDegree`: `uint`

**GsplatRigWeight** (for skinning support) [S1, unofficial]:
- `BoneIndex0`: `uint`
- `Weight0`: `float`
- Padding: Aligned to `sizeof(uint) * 4 + sizeof(float) * 4` total size.

### Steps
1. **Check Global State**: If `m_globalBuffersDirty` is true, `m_globalOrderBuffer` is null, or `m_totalRemainingCount` is 0, return early to prevent stale buffer usage [S3, unofficial].
2. **Initialize Property Block**: Clear or initialize `m_globalPropertyBlock` [S3, unofficial].
3. **Bind Core Buffers**: Bind the following to their respective shader properties: `k_globalOrderBuffer`, `k_globalPackedBuffer`, `k_rendererOffsetsProp`, `k_rendererTransformsProp`, `k_rendererParamsProp` [S3, unofficial].
4. **Bind Integer Parameters**: `k_totalSplatCount` = `m_totalRemainingCount`, `k_splatInstanceSize` = `GsplatSettings.Instance.SplatInstanceSize` [S3, unofficial].
5. **Bind SH Buffers**: Conditionally bind SH buffers based on `m_globalSHBands`: if `m_globalSHBands >= 1`, bind `k_globalSH1Buffer`; if `>= 2`, bind `k_globalSH2Buffer`; if `>= 3`, bind `k_globalSH3Buffer`; if `>= 4`, bind `k_globalSH4Buffer` [S3, unofficial].
6. **Update Per-Renderer Parameters**: For each active renderer `k`: if it is a `GsplatRenderer`, set `Brightness` = `gs.Brightness`, `ScaleFactor` = `1.0 - gs.SplatDownscaleFactor`, `GammaToLinear` = `1` if `gs.GammaToLinear` else `0`, `SHDegree` = `min(gs.SHDegree, activeGsplats[k].SHBands)` [S3, unofficial]. Else, set `Brightness` = `1.0`, `ScaleFactor` = `1.0`, `GammaToLinear` = `0`, `SHDegree` = `activeGsplats[k].SHBands` [S3, unofficial]. Set the cached `RendererParams` array into `m_rendererParamsBuffer` [S3, unofficial].
7. **Construct Render Params**: Create `RenderParams` with the global material, world bounds (1e6 units), and the populated property block [S3, unofficial].
8. **Compute Instance Count**: `instanceCount` = `ceil(m_totalRemainingCount / SplatInstanceSize)` [S3, unofficial].
9. **Issue Draw Call**: Use `RenderMeshPrimitives` with the instance mesh, `instanceCount`, and `RenderParams` [S3, unofficial].

### Pseudocode
```python
import math

class MaterialPropertyBlock:
    def __init__(self):
        self._props = {}
    def set_buffer(self, name, buf):
        self._props[name] = buf
    def set_int(self, name, val):
        self._props[name] = val
    def set_texture(self, name, tex):
        self._props[name] = tex
    def set_buffer_array(self, name, arr):
        self._props[name] = arr

def configure_splat_shader_properties(renderer, global_state, splat_asset):
    # Step 1: Check global state
    if global_state.m_global_buffers_dirty or \
       global_state.m_global_order_buffer is None or \
       global_state.m_total_remaining_count == 0:
        return

    # Step 2: Initialize Property Block
    prop_block = MaterialPropertyBlock()

    # Step 3: Bind Core Buffers
    prop_block.set_buffer("k_globalOrderBuffer", global_state.k_global_order_buffer)
    prop_block.set_buffer("k_globalPackedBuffer", global_state.k_global_packed_buffer)
    prop_block.set_buffer("k_rendererOffsetsProp", global_state.k_renderer_offsets_prop)
    prop_block.set_buffer("k_rendererTransformsProp", global_state.k_renderer_transforms_prop)
    prop_block.set_buffer("k_rendererParamsProp", global_state.k_renderer_params_prop)

    # Step 4: Bind Integer Parameters
    prop_block.set_int("k_totalSplatCount", global_state.m_total_remaining_count)
    prop_block.set_int("k_splatInstanceSize", GsplatSettings.instance.splat_instance_size)

    # Step 5: Bind SH Buffers
    global_sh_bands = global_state.m_global_sh_bands
    if global_sh_bands >= 1:
        prop_block.set_texture("k_globalSH1Buffer", global_state.k_global_sh1_buffer)
    if global_sh_bands >= 2:
        prop_block.set_texture("k_globalSH2Buffer", global_state.k_global_sh2_buffer)
    if global_sh_bands >= 3:
        prop_block.set_texture("k_globalSH3Buffer", global_state.k_global_sh3_buffer)
    if global_sh_bands >= 4:
        prop_block.set_texture("k_globalSH4Buffer", global_state.k_global_sh4_buffer)

    # Step 6: Update Per-Renderer Parameters
    renderer_params_array = []
    for k in range(renderer.active_renderer_count):
        gs = renderer.active_gsplats[k]
        if renderer.is_gsplat_renderer(k):
            brightness = gs.brightness
            scale_factor = 1.0 - gs.splat_downscale_factor
            gamma_to_linear = 1 if gs.gamma_to_linear else 0
            sh_degree = min(gs.sh_degree, gs.sh_bands)
        else:
            brightness = 1.0
            scale_factor = 1.0
            gamma_to_linear = 0
            sh_degree = gs.sh_bands
        
        renderer_params_array.append({
            "Brightness": brightness,
            "ScaleFactor": scale_factor,
            "GammaToLinear": gamma_to_linear,
            "SHDegree": sh_degree
        })
    
    prop_block.set_buffer_array("m_rendererParamsBuffer", renderer_params_array)

    # Step 7: Construct Render Params
    render_params = {
        "material": splat_asset.gsplat_material,
        "world_bounds": {"center": (0, 0, 0), "extents": (1e6, 1e6, 1e6)},
        "property_block": prop_block
    }

    # Step 8: Compute Instance Count
    instance_count = math.ceil(global_state.m_total_remaining_count / GsplatSettings.instance.splat_instance_size)

    # Step 9: Issue Draw Call
    render_mesh_primitives(
        instance_mesh=splat_asset.instance_mesh,
        instance_count=instance_count,
        render_params=render_params
    )
```

### Parameters
- `shDegree`: Order of SH coefficients used for rendering, capped by the asset's `SHBands` property [S1, unofficial].
- `brightness`: Brightness color scaling factor, default 1.0 [S1, unofficial].
- `scaleFactor`: Splat UV scaling factor to reduce splat size while keeping visual fidelity, default 1.0 [S1, unofficial].

### Edge Cases and Pitfalls
- **Portable Shader Variants**: If skinning is disabled, valid sampled resources must still be bound [S1, unofficial]. Binding null or uninitialized buffers causes shader compilation/runtime errors [S1, unofficial].
- **Stale Buffers**: Drawing is skipped if `m_globalBuffersDirty` is true [S3, unofficial]. This is critical in URP where `DrawAllIfEnabled` may fire before `DispatchSort` [S3, unofficial].
- **SH Degree Clamping**: `SHDegree` must be clamped to the renderer's `SHBands` to prevent `EvalSH` from reading uninitialized data, as global buffers are sized to the max bands across all renderers [S3, unofficial].

## Subtopics

### [Gaussian Splat TAA Jitter Integration](13883-gaussian-splat-taa-jitter-integration.md)
Integrates temporal anti-aliasing (TAA) jitter into the Gaussian Splatting rendering pipeline to prevent splats from appearing "swimming" or bit-stable while surrounding meshes are correctly jittered [Brief]. It solves the problem where splats, previously rendered with an unjittered projection matrix, failed to accumulate temporal history correctly under TAA and temporal upscaling (e.g., FSR2), causing residual displacement and visual artifacts [Brief]. It differs from standard mesh rendering by explicitly excluding the engine's depth correction from the jittered projection, as the Gaussian pipeline relies on linear view-space depth [Brief].

### Renderer Uniform Configuration
Binds the two main splat textures to uniforms `sourceSplats` and `sourceSplats2` [S2, unofficial]. Binds Spherical Harmonics block textures to uniforms `shBlock0Texture` through `shBlock5Texture` [S2, unofficial]. If a specific block texture is missing, binds `Splats.emptyTexture` [S2, unofficial]. Sets layer configuration uniforms: `sourceLayerBits` to `layerBits`, `sourceLayerMask` to `2 ** layerBits - 1`, and `sourceBlockBits` to `SPLAT_BLOCKS_DISABLED` [S2, unofficial]. Disables advanced features by setting `sourcePackedGroups` to false, `sourceBlocks/sourceOpacities/sourceIndices` to `Splats.emptyTexture`, and `sourceIndexed` to false [S2, unofficial]. Marks the splats object as needing no further updates by setting `needsUpdate` to false [S2, unofficial].

### Global Draw Call with MaterialPropertyBlock
Binds global splat data buffers to the rendering material using a MaterialPropertyBlock to support multi-camera setups without state overwrites [S3, unofficial]. Returns early if `m_globalBuffersDirty`, `m_globalOrderBuffer` is null, or `m_totalRemainingCount` is 0 [S3, unofficial]. Initializes or clears `m_globalPropertyBlock` [S3, unofficial]. Binds core buffers: `k_globalOrderBuffer`, `k_globalPackedBuffer`, `k_rendererOffsetsProp`, `k_rendererTransformsProp`, `k_rendererParamsProp` [S3, unofficial]. Binds integer parameters: `k_totalSplatCount` (`m_totalRemainingCount`) and `k_splatInstanceSize` (`GsplatSettings.Instance.SplatInstanceSize`) [S3, unofficial]. Binds SH buffers conditionally based on `m_globalSHBands`: `k_globalSH1Buffer` (if >=1), `k_globalSH2Buffer` (if >=2), `k_globalSH3Buffer` (if >=3), `k_globalSH4Buffer` (if >=4) [S3, unofficial]. Drawing is skipped if `m_globalBuffersDirty` is true, preventing stale buffer usage, especially important in URP where `DrawAllIfEnabled` fires before `DispatchSort` [S3, unofficial].

### Renderer Parameter Caching and SH Degree Clamping
Updates per-renderer parameters including brightness, scale, gamma, and spherical harmonic degree, ensuring SH evaluation does not read uninitialized data [S3, unofficial]. For each active renderer `k`, if it is a `GsplatRenderer`, sets `Brightness=gs.Brightness`, `ScaleFactor=1.0f-gs.SplatDownscaleFactor`, `GammaToLinear=gs.GammaToLinear?1u:0u`, `SHDegree=min(gs.SHDegree, activeGsplats[k].SHBands)` [S3, unofficial]. If the renderer is not a `GsplatRenderer`, sets `Brightness=1.0f`, `ScaleFactor=1.0f`, `GammaToLinear=0u`, `SHDegree=activeGsplats[k].SHBands` [S3, unofficial]. Sets the cached `RendererParams` array into `m_rendererParamsBuffer` [S3, unofficial]. `SHDegree` is clamped to the renderer's `SHBands` to prevent `EvalSH` from reading slots not copied for that renderer, as global buffers are sized to max bands across all renderers [S3, unofficial].

### Global Splat Rendering Setup
Binds renderer parameters buffer containing total splat count and instance size to `k_rendererParamsProp` [S3, unofficial]. Conditionally binds spherical harmonic buffers for bands 1 through 4 based on `m_globalSHBands` [S3, unofficial]. Constructs `RenderParams` with the appropriate global material, a world bounds covering 1e6 units in all directions, and the populated property block [S3, unofficial]. Computes instance count by dividing remaining splat count by `SplatInstanceSize`, rounded up [S3, unofficial]. Issues the draw call using `RenderMeshPrimitives` with the pre-built instance mesh, instance count, and render params [S3, unofficial].

## Background
Originated from the implementation of 3D Gaussian Splatting in real-time engines like Unity and WebGL [S1, S2, S3, unofficial]. The method was developed to address the specific challenges of passing large amounts of per-splat and global state to the GPU efficiently [S1, S3, unofficial]. Key implementations include `UnitySplats` [S1, S3, unofficial] and `Gaussian-Splat-Lite` [S2, unofficial]. The approach evolved to support multi-camera setups, TAA jitter integration, and efficient SH evaluation [S1, S2, S3, unofficial].
