# Full Factors Weighted (FFW) Importance Score Pruning

Also called: MiniGS Pruning, Scorev4

## Overview
Full Factors Weighted (FFW) Importance Score Pruning, also known as MiniGS Pruning or Scorev4, is a method for selectively removing less important 3D Gaussian primitives during training to reduce memory footprint and rendering latency while preserving visual fidelity [S1]. It addresses the limitation of vanilla 3DGS pruning, which relies solely on opacity and transparency, by incorporating position, color similarity, opacity, and transparency into a single importance score [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ 3D Gaussians $\{G_i\}$, the current camera view (defined by ray $r$ and pixel coordinate $X_r$), the rendered pixel color $c_r$, and the Gaussian parameters (position $X_i$, view-dependent color $c_i$, opacity $\alpha_i$, transparency $T_i$) [S1].
*   **Output:** A ranked list of Gaussians and a binary mask indicating which Gaussians to prune from the scene representation [S1].

**Data Structures:**
The method operates on the standard 3D Gaussian data layout defined in [Gaussian Data Structure](14647-gaussian-data-structure.md). Each Gaussian $G_i$ stores:
*   $X_i \in \mathbb{R}^3$: Center position [S1].
*   $c_i \in \mathbb{R}^3$: View-dependent color computed from spherical harmonics coefficients [S1].
*   $\alpha_i \in [0, 1]$: Blending opacity [S1].
*   $T_i \in [0, 1]$: Transparency calculated during rasterization as $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ for Gaussians sorted by depth [S1].
*   $\Sigma \in \mathbb{R}^{3 \times 3}$: 3D covariance matrix [S1].

**Step-by-Step Procedure:**

1.  **Project Covariance:**
    To determine the 2D extent of the Gaussian for rasterization, the 3D covariance matrix $\Sigma$ is projected to the 2D image plane using the world-to-camera projective transform matrix $W$ and the Jacobian $J$ of the projective transform [S1]:
    $$ \Sigma' = J W \Sigma W^T J^T $$
    This step generates the intermediate values ($T_i$) used in the importance score [S1].

2.  **Compute Importance Score:**
    For each Gaussian $G_i$ contributing to the pixel color $c_r$ along ray $r$, calculate the importance score $S(G_i, r)$ using the Scorev4 formula [S1]:
    $$ S(G_i, r) = (1 - \text{mean}(c_r - c_i)) \cdot \exp(-\|X_r - X_i\|^2) \cdot \alpha_i \cdot T_i $$
    Where:
    *   $c_r$ is the final rendered color of the pixel [S1].
    *   $c_i$ is the view-dependent color of the Gaussian $G_i$ [S1].
    *   $\text{mean}(c_r - c_i)$ is the mean difference across the RGB channels of the color vectors [S1].
    *   $X_r$ is the 2D pixel coordinate of the ray [S1].
    *   $X_i$ is the center position of the projected Gaussian [S1].
    *   $\alpha_i$ is the blending opacity [S1].
    *   $T_i$ is the transparency (accumulated alpha from previous Gaussians) [S1].

3.  **Rank and Prune:**
    *   Rank all Gaussians based on their computed importance scores [S1].
    *   Remove the Gaussians with the lowest scores until the target number of primitives is reached [S1].

**Pseudocode:**

```python
import math

def compute_ffw_score(pixel_color, pixel_coord, gaussian_color, gaussian_center_2d, opacity, transparency):
    """
    Computes the FFW (Scorev4) importance score for a single Gaussian contribution.
    
    Args:
        pixel_color: list of 3 floats [R, G, B] for the rendered pixel.
        pixel_coord: list of 2 floats [x, y] for the 2D pixel coordinate.
        gaussian_color: list of 3 floats [R, G, B] for the Gaussian's view-dependent color.
        gaussian_center_2d: list of 2 floats [x, y] for the projected Gaussian center.
        opacity: float alpha_i.
        transparency: float T_i.
        
    Returns:
        float: Importance score.
    """
    # Calculate color similarity factor: (1 - mean(color difference))
    color_diff = [pixel_color[k] - gaussian_color[k] for k in range(3)]
    mean_color_diff = sum(color_diff) / 3.0
    color_similarity = 1.0 - mean_color_diff
    
    # Calculate spatial proximity factor: exp(-squared distance)
    dx = pixel_coord[0] - gaussian_center_2d[0]
    dy = pixel_coord[1] - gaussian_center_2d[1]
    spatial_dist_sq = dx * dx + dy * dy
    spatial_factor = math.exp(-spatial_dist_sq)
    
    # Combine factors
    score = color_similarity * spatial_factor * opacity * transparency
    return score

def prune_gaussians(gaussians, render_data, target_count):
    """
    Prunes Gaussians using FFW importance scores.
    
    Args:
        gaussians: List of Gaussian objects.
        render_data: Dictionary mapping Gaussian index to list of (pixel_color, pixel_coord, transparency) tuples.
        target_count: Integer, number of Gaussians to keep.
        
    Returns:
        List of Gaussian objects: The pruned set.
    """
    scores = []
    
    for i, g in enumerate(gaussians):
        # Aggregate score across all pixels where this Gaussian contributes
        # The source implies a global ranking based on the computed importance [S1].
        # Implementation detail: average the scores across contributing pixels [G].
        pixel_scores = []
        for pixel_color, pixel_coord, transparency in render_data.contributing_pixels[i]:
            score = compute_ffw_score(
                pixel_color=pixel_color,
                pixel_coord=pixel_coord,
                gaussian_color=g.color,
                gaussian_center_2d=g.center_2d,
                opacity=g.opacity,
                transparency=transparency
            )
            pixel_scores.append(score)
        
        avg_score = sum(pixel_scores) / len(pixel_scores) if pixel_scores else 0.0
        scores.append((i, avg_score))
    
    # Sort by score ascending (lowest importance first)
    scores.sort(key=lambda x: x[1])
    
    # Determine how many to prune
    num_to_prune = len(gaussians) - target_count
    if num_to_prune <= 0:
        return gaussians
        
    # Indices to remove
    indices_to_remove = set([idx for idx, _ in scores[:num_to_prune]])
    
    # Return pruned list
    return [g for i, g in enumerate(gaussians) if i not in indices_to_remove]
```

**Parameters:**
*   **Target Primitive Count ($K$):** The desired number of Gaussians after pruning [S1].
*   **Color Difference Metric:** The source uses `mean(cr - ci)` [S1].

**Edge Cases and Pitfalls:**
Not given in the sources.

## Operating characteristics
*   **Measured Performance:**
    *   **Mip-NeRF360:** SSIM 0.798, PSNR 27.10, LPIPS 0.242 with 402.2k primitives [S1].
    *   **Tanks&Temples:** SSIM 0.828, PSNR 23.11, LPIPS 0.207 with 230.7k primitives [S1].
    *   **DeepBlending:** SSIM 0.897, PSNR 25.87, LPIPS 0.316 with 250.7k primitives [S1].
*   **Strengths:** Incorporates color and position information, preventing the removal of visually important Gaussians that have low opacity [S1]. Outperforms vanilla opacity-only pruning (Scorevanilla) and other variants (Scorev1-v3) in quantitative metrics [S1].
*   **Limitations:** Requires access to rendered pixel colors and intermediate blending values ($T_i$), which must be stored or recomputed during the pruning phase [S1].

## Background
The Full Factors Weighted (FFW) Importance Score Pruning, also known as Scorev4, was introduced in the MiniGS method [S1]. MiniGS aims to provide an efficient 3D Gaussian splatting pipeline by combining FFW pruning with a Variational Densify Threshold (VDT) module [S1]. The method was developed to address the inefficiency of vanilla 3DGS pruning, which fails to account for color and spatial contributions, leading to suboptimal pruning decisions [S1]. The approach was evaluated on standard NeRF benchmarks (Mip-NeRF360, Tanks&Temples, DeepBlending) using a single NVIDIA H100 GPU [S1].
