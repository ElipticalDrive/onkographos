# SemGauss-SLAM

Also called: SGS-SLAM, NEDS-SLAM / SemGauss-SLAM

## Overview
SemGauss-SLAM is a simultaneous localization and mapping (SLAM) method that integrates semantic information into the 3D Gaussian Splatting framework [S1]. It distinguishes itself from standard radiance-field optimization by distilling 2D semantic labels to guide the Gaussian representation, enabling semantic-aware mapping [S2, unofficial].

## How it works
Inputs: Image sequences, camera poses, and 2D semantic segmentation masks obtained via 2D segmentation methods or dataset annotations [S2, unofficial].
Outputs: Optimized 3D Gaussians with semantic attributes, refined camera poses, and a semantic map [S1].

Data Structures:
- 3D Gaussians: Each Gaussian $i$ is augmented with a semantic label $l_i$ [S2, unofficial].
- Semantic Label: $l_i$ is a discrete class identifier or a probability vector over semantic classes [S2, unofficial].

Steps:
1. Semantic Augmentation: Assign each 3D Gaussian $i$ a semantic label $l_i$ [S2, unofficial].
2. Semantic Distillation: Obtain 2D semantic masks from a pre-trained 2D segmentation network or dataset annotations [S2, unofficial]. Project or back-project these 2D labels to align with the 3D Gaussians [S2, unofficial].
3. Loss Computation: Compute a semantic distillation loss $\mathcal{L}_{sem}$ between the rendered semantic features (or projected labels) and the 2D semantic masks [S2, unofficial].
4. Combined Optimization: Minimize the total loss $\mathcal{L} = \mathcal{L}_{rgb} + \lambda_{sem} \mathcal{L}_{sem}$, where $\mathcal{L}_{rgb}$ is the photometric reconstruction loss and $\lambda_{sem}$ is the semantic loss weight [S2, unofficial]. Backpropagate gradients to update Gaussian parameters (position, scale, rotation, opacity, color, semantics) and camera poses [S2, unofficial].
5. Semantic-Guided Control: Apply adaptive splitting and pruning guided by semantic boundaries to avoid redundant splitting in homogeneous semantic regions [S1].

Formulas:
- Total Loss: $\mathcal{L} = \mathcal{L}_{rgb} + \lambda_{sem} \mathcal{L}_{sem}$ [S2, unofficial].
- $\mathcal{L}_{rgb}$: Photometric reconstruction loss [S2, unofficial].
- $\mathcal{L}_{sem}$: Semantic distillation loss, measuring the discrepancy between projected 2D semantic labels and rendered semantic features [S2, unofficial].
- $\lambda_{sem}$: Weight for the semantic loss [S2, unofficial].

Parameters:
- $\lambda_{sem}$: Not given in the sources.
- Semantic segmentation model: Not specified, but implied to be a standard 2D method [S2, unofficial].

Edge cases and pitfalls:
- Semantic ambiguity in textureless regions may lead to incorrect label propagation [G].
- Misalignment between 2D semantic masks and 3D Gaussians due to depth errors can degrade map quality [G].

## Subtopics
- SGS-SLAM: A variant that considers Gaussian semantic information [S1].
- NEDS-SLAM: Another variant integrating semantic information into SLAM [S1].

## Operating characteristics
Time and memory complexity: Not given in the sources.
Measured performance: Not given in the sources.
Strengths: Enables semantic understanding in the reconstructed map, useful for robotics tasks like relocalization, navigation, and 6D pose estimation [S1].
Limitations: Relies on the accuracy of 2D semantic segmentation [S2, unofficial].

## Background
Origin: SemGauss-SLAM, along with SGS-SLAM and NEDS-SLAM, was introduced to enhance 3D Gaussian Splatting-based SLAM by incorporating semantic information [S1].
History: It builds on earlier methods like LIVGaussMap which used LiDAR for initialization [S1].
Usage: Used in robotics for relocalization, navigation, and 6D pose estimation [S1].
