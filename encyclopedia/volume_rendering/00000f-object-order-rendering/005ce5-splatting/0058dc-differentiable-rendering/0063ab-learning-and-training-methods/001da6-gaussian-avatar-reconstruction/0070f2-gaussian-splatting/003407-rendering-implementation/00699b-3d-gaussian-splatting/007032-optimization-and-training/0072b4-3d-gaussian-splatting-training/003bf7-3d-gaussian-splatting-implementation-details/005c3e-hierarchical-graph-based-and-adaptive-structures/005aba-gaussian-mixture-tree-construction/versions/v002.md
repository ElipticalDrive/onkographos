# Gaussian Mixture Tree Construction

Also called: Hierarchically Merging Gaussians

## Overview
Gaussian Mixture Tree (GMT) Construction is a post-processing method that organizes 3D Gaussian primitives into a hierarchical tree structure to identify distinct 3D plane instances [S1]. Unlike standard 3D Gaussian Splatting which treats primitives as independent entities, GMT recursively merges leaf nodes using Gaussian Mixture Models to create parent nodes that encompass child distributions [S1]. It is distinguished from siblings like [TraGraph-GS](14454-tragraph-gs.md) by its explicit probabilistic merging of Gaussians into a tree, rather than graph-based connectivity or grid-based organization.

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N_s$ leaf nodes $\{G_i\}_{i=1}^{N_s}$, where each node $G_i$ is a local cluster of 3D Gaussian primitives. Each node $G_i$ is defined by mean $\mathbf{\mu}_i$, covariance $\mathbf{\Sigma}_i$, normal vector $\mathbf{n}_i \in \mathbb{R}^3$, and plane descriptor $\mathbf{z}_i \in \mathbb{R}^k$ (typically $k=3$) [S1].
*   **Output:** A set of merged parent nodes $\mathcal{G}_s$ representing the tree structure, and the total number of merged nodes $L$ [S1].

**Data Structures:**
Each node in the tree stores:
*   $\mathbf{\mu} \in \mathbb{R}^3$: Mean position.
*   $\mathbf{\Sigma} \in \mathbb{R}^{3 \times 3}$: Covariance matrix.
*   $\mathbf{n} \in \mathbb{R}^3$: Surface normal vector.
*   $\mathbf{z} \in \mathbb{R}^k$: Plane descriptor vector [S1].

**Parameters:**
*   $\epsilon_B$: Threshold for the Bhattacharya distance. Not given in the sources.
*   $\epsilon_z$: Threshold for the difference in cosine similarity between plane descriptors. Not given in the sources.

**Merging Formulas:**
When merging two nodes $G_i$ and $G_j$ into a parent $G_p(\mathbf{\mu}_p, \mathbf{\Sigma}_p)$, the parameters are computed as [S1]:

$$
\mathbf{\Sigma}_p = \mathbf{\Sigma}_j \cdot (\mathbf{\Sigma}_i + \mathbf{\Sigma}_j)^{-1} \cdot \mathbf{\Sigma}_i
$$

$$
\mathbf{\mu}_p = \mathbf{\Sigma}_j \cdot (\mathbf{\Sigma}_i + \mathbf{\Sigma}_j)^{-1} \cdot \mathbf{\mu}_i + \mathbf{\Sigma}_i \cdot (\mathbf{\Sigma}_i + \mathbf{\Sigma}_j)^{-1} \cdot \mathbf{\mu}_j
$$

The merging criterion uses the Bhattacharya distance $D_B(G_i, G_j)$ [S1]:

$$
D_B(G_i, G_j) = \frac{1}{8}(\mathbf{\mu}_i - \mathbf{\mu}_j)^{T}\mathbf{\Sigma}^{-1}(\mathbf{\mu}_i - \mathbf{\mu}_j) + \frac{1}{2}\ln \left( \frac{\det \mathbf{\Sigma}}{\sqrt{\det \mathbf{\Sigma}_i \det \mathbf{\Sigma}_j}} \right)
$$

where $\mathbf{\Sigma} = (\mathbf{\Sigma}_i + \mathbf{\Sigma}_j)/2$ [S1].

**Algorithm Steps:**
1.  Initialize counter $L = 0$ and output set $\mathcal{G} = \emptyset$.
2.  Iterate $i$ from $1$ to $N_s$:
    a. Check if node $i$ is already a descendant of any existing node in $\mathcal{G}$. If yes, skip to next $i$.
    b. Iterate $j$ from $i+1$ to $N_s$:
        i. Check if node $j$ is already a descendant of any existing node in $\mathcal{G}$. If yes, continue to next $j$.
        ii. Calculate $D_B(G_i, G_j)$.
        iii. Calculate cosine similarity difference $1 - \langle \mathbf{z}_i \cdot \mathbf{z}_j \rangle$.
        iv. If $D_B(G_i, G_j) \le \epsilon_B$ AND $1 - \langle \mathbf{z}_i \cdot \mathbf{z}_j \rangle \le \epsilon_z$:
            1. Compute $\mathbf{\mu}_p, \mathbf{\Sigma}_p$ using the formulas above.
            2. Create parent node $G_{ij}^p$.
            3. Update $G_i \leftarrow G_{ij}^p$.
            4. Break inner loop (stop checking other $j$ for this $i$).
    c. Insert $G_i$ into $\mathcal{G}_s$.
    d. Increment $L \leftarrow L + 1$.

**Pseudocode:**

```python
def construct_gaussian_mixture_tree(leaf_nodes, epsilon_b, epsilon_z):
    """
    Constructs a Gaussian Mixture Tree by hierarchically merging Gaussians.
    
    Args:
        leaf_nodes: List of Ns nodes, each with attributes:
            mu: numpy array (3,)
            Sigma: numpy array (3,3)
            z: numpy array (k,)
        epsilon_b: Float, Bhattacharya distance threshold.
        epsilon_z: Float, Cosine similarity difference threshold.
            
    Returns:
        merged_nodes: List of merged parent nodes.
        L: Integer, count of merged nodes.
    """
    import numpy as np
    
    Ns = len(leaf_nodes)
    merged_nodes = []
    L = 0
    
    # Track which original indices have been merged into a new node
    # to avoid re-processing descendants.
    # We modify the list in place or track status. 
    # The algorithm processes i, and if merged, updates G_i.
    # We need to know if an index 'k' is a descendant of any node in merged_nodes.
    # Since merged_nodes contains the NEW parent, and the children are i and j,
    # we can track which original indices are "consumed".
    
    # However, the algorithm says "if i is NOT descendant of {G_sk}".
    # G_sk are the nodes in the output set G.
    # When we merge i and j, we create a new node G_p.
    # The next iterations check if current i is a descendant of ANY G in G.
    # Since we process i sequentially, if i was merged as a child of a previous merge,
    # it would have been updated? No, the loop is over original indices.
    # The condition "i is NOT descendant" implies we must check if index i 
    # was already used as a child in a previous merge step.
    
    # Let's track used indices.
    used_indices = set()
    
    for i in range(Ns):
        if i in used_indices:
            continue
            
        current_node = leaf_nodes[i]
        merged = False
        
        for j in range(i + 1, Ns):
            if j in used_indices:
                continue
                
            node_j = leaf_nodes[j]
            
            # Calculate Bhattacharya Distance
            Sigma_i = current_node.Sigma
            Sigma_j = node_j.Sigma
            mu_i = current_node.mu
            mu_j = node_j.mu
            
            Sigma_avg = (Sigma_i + Sigma_j) / 2.0
            
            # Term 1: Mahalanobis distance part
            diff = mu_i - mu_j
            try:
                Sigma_avg_inv = np.linalg.inv(Sigma_avg)
                term1 = 0.125 * diff.T @ Sigma_avg_inv @ diff
            except np.linalg.LinAlgError:
                # Singular matrix, treat distance as infinite
                term1 = float('inf')
                
            # Term 2: Determinant part
            det_Sigma_i = np.linalg.det(Sigma_i)
            det_Sigma_j = np.linalg.det(Sigma_j)
            det_Sigma_avg = np.linalg.det(Sigma_avg)
            
            # Ensure determinants are positive for log
            if det_Sigma_i <= 0 or det_Sigma_j <= 0 or det_Sigma_avg <= 0:
                term2 = float('inf')
            else:
                term2 = 0.5 * np.log(det_Sigma_avg / np.sqrt(det_Sigma_i * det_Sigma_j))
                
            db_dist = term1 + term2
            
            # Calculate Cosine Similarity Difference
            # Normalize vectors for cosine similarity
            z_i_norm = current_node.z / (np.linalg.norm(current_node.z) + 1e-8)
            z_j_norm = node_j.z / (np.linalg.norm(node_j.z) + 1e-8)
            cosine_sim = np.dot(z_i_norm, z_j_norm)
            cosine_diff = 1.0 - cosine_sim
            
            # Check criteria
            if db_dist <= epsilon_b and cosine_diff <= epsilon_z:
                # Merge i and j
                # Sigma_p = Sigma_j * (Sigma_i + Sigma_j)^-1 * Sigma_i
                try:
                    Sigma_sum_inv = np.linalg.inv(Sigma_i + Sigma_j)
                    Sigma_p = Sigma_j @ Sigma_sum_inv @ Sigma_i
                    
                    mu_p = (Sigma_j @ Sigma_sum_inv @ mu_i + 
                            Sigma_i @ Sigma_sum_inv @ mu_j)
                except np.linalg.LinAlgError:
                    continue # Cannot merge if sum is singular
                    
                # Create new node object
                new_node = type(current_node)()
                new_node.mu = mu_p
                new_node.Sigma = Sigma_p
                # Normal and descriptor need to be defined for parent. 
                # Sources do not specify how n_p and z_p are derived from children.
                # [G] Assuming they are averaged or inherited; not specified in sources.
                # We will leave them undefined or placeholder as per instruction.
                new_node.n = (current_node.n + node_j.n) / 2.0 
                new_node.z = (current_node.z + node_j.z) / 2.0
                
                current_node = new_node
                used_indices.add(j)
                merged = True
                break # Break inner loop, continue with updated current_node in outer loop?
                      # Algorithm says "break the inner loop". 
                      # Then "After the inner loop, insert Gi into Gs".
                      # This implies one merge per i.
        
        # Insert the resulting node (either original or merged) into Gs
        merged_nodes.append(current_node)
        L += 1
        
    return merged_nodes, L
```

**Edge Cases and Pitfalls:**
*   **Singular Matrices:** The inversion of $\mathbf{\Sigma}_i + \mathbf{\Sigma}_j$ or $\mathbf{\Sigma}$ in the Bhattacharya distance may fail if covariances are singular. A guard (e.g., adding small diagonal noise) is required [G].
*   **Leaf Node Initialization:** Raw optimized Gaussians are too numerous for direct leaf nodes. They must first be grouped into local clusters [S1]. The method for this clustering is not detailed in the sources [G].
*   **Descriptor Learning:** The plane descriptors $\mathbf{z}$ and normals $\mathbf{n}$ are learned via auxiliary losses (normal loss, SAM mask lifting) during training, not just constructed [S1].

## Operating characteristics
*   **Time Complexity:** The nested loop structure suggests $O(N_s^2)$ comparisons in the worst case, where $N_s$ is the number of leaf nodes. However, early breaks and descendant checks may reduce this.
*   **Memory Complexity:** Requires storing the tree structure and intermediate node parameters.
*   **Strengths:** Explicitly models 3D plane instances, enabling higher-level semantic understanding of the scene [S1].
*   **Limitations:** Computationally expensive if $N_s$ is large; requires auxiliary learning of normals and descriptors [S1].

## Background
The method was introduced in "Planar Gaussian Splatting" [S1]. It builds on the standard 3D Gaussian Splatting optimization but adds a probabilistic hierarchical structure to identify planar surfaces.
