# Hybrid Coarse-to-Fine Strategy

Also called: Multi-stage refinement, Progressive densification

## Overview
The Hybrid Coarse-to-Fine Strategy is a training methodology for 3D Gaussian Splatting that structures optimization into discrete stages to establish a valid geometric backbone before refining details [S1, S2]. Unlike single-stage training, which often converges to suboptimal local minima or exhibits poor structural fidelity, this approach decouples initialization from refinement, yielding significantly higher rendering quality [S1]. It sets itself apart from sibling methods like [Curriculum Learning with Slice and Voxel Supervision](12921-curriculum-learning-with-slice-and-voxel-supervision.md) by focusing on the topological evolution of the primitive set (mesh or point cloud) rather than the supervision signal itself.

## How it works
The strategy operates on a set of 3D Gaussian primitives $\mathcal{G} = \{g_1, \dots, g_N\}$, where each primitive is defined by mean position $\mu_k$, covariance $\Sigma_k$ (scale $s_k$, rotation $q_k$), opacity $\alpha_k$, and spherical harmonic coefficients $\mathbf{c}_k$ [Parent]. The method consists of two primary phases: a coarse initialization phase and a fine refinement phase with periodic densification.

### Inputs and Outputs
*   **Inputs:** A set of input images (potentially downsampled for initialization), camera poses, and hyperparameters for stage transitions.
*   **Outputs:** An optimized set of 3D Gaussians $\mathcal{G}$ with converged positions, scales, opacities, and colors.

### Data Structures
The core data structure is a list of Gaussian primitives. In mesh-based variants (see Subtopics), this is augmented by a connectivity structure (triangles) and a vertex list.
*   **Gaussian List:** Array of structs containing $\mu, \Sigma, \alpha, \mathbf{c}$.
*   **Triangle List (Mesh Variant):** Array of triangle indices referencing vertices. Each triangle $t$ maintains a score and pixel coverage count.

### Numbered Steps

1.  **Coarse Initialization:**
    *   Generate an initial sparse representation. This may involve random allocation, feed-forward network prediction, or edge-aware sampling [S1][S2].
    *   In the mesh-based variant [S2]: Compute Sobel gradient magnitudes on a downsampled target image. Sample initial vertex positions proportionally to edge strength with a small uniform floor for coverage. Create a Delaunay triangulation of sampled points, ensuring boundary vertices cover the full image.

2.  **Coarse Optimization:**
    *   Optimize the initial primitives using standard differentiable rendering losses. This stage establishes the global geometry and approximate appearance.

3.  **Refinement and Densification Loop:**
    *   Enter the fine-tuning phase. Periodically evaluate metrics to trigger densification.
    *   **Scoring (Mesh Variant):** Every 500 iterations (starting at iteration 1,500 and ending at 15,000) [S2], score each triangle $t$ using:
        $$ \text{score}_t = \overline{\text{DSSIM}}_t \cdot |\text{pixels}_t|^\alpha $$
        where $\overline{\text{DSSIM}}_t$ is the mean per-pixel structural dissimilarity of triangle $t$, $|\text{pixels}_t|$ is the number of pixels covered by the triangle, and $\alpha = 0.75$ is the area-weighting exponent [S2].
    *   **Filtering:** Exclude triangles with fewer than 3 pixels from scoring [S2].
    *   **Insertion:** Insert centroid vertices for the top-scoring triangles. The number of new vertices is capped at $0.35 \times V$, where $V$ is the current vertex count [S2].
    *   **Feature Initialization:** Initialize features of new vertices by averaging the parent triangle's vertex features [S2].
    *   **Re-meshing:** Re-run Delaunay triangulation on the full vertex set [S2]. Detect and handle degenerate meshes (e.g., colinear vertices) if necessary [S2].
    *   **Optimization:** Continue optimizing all parameters (positions, scales, opacities, colors) for the densified set.

4.  **Final Convergence:**
    *   Continue optimization until convergence or a fixed iteration limit.

### Pseudocode
```python
def hybrid_coarse_to_fine_training(input_images, camera_poses, max_iterations):
    # Phase 1: Coarse Initialization
    # Implementation depends on specific variant (random, mesh, etc.)
    # For mesh variant [S2]:
    gradients = compute_sobel_gradients(downsample(input_images[0]))
    vertices = sample_vertices_proportional_to(gradients, floor=0.01)
    triangles = delaunay_triangulate(vertices)
    gaussians = initialize_gaussians_from_mesh(vertices, triangles)
    
    # Phase 2: Coarse Optimization
    optimize(gaussians, input_images, camera_poses, iterations=1500)
    
    # Phase 3: Refinement and Densification
    for iter in range(1500, max_iterations):
        if iter % 500 == 0 and iter <= 15000:
            # Densification Step [S2]
            scores = []
            for t in triangles:
                if t.pixel_count < 3:
                    continue
                dssim = compute_mean_dssim(t)
                area_weight = t.pixel_count ** 0.75
                scores.append((t, dssim * area_weight))
            
            # Sort and select top triangles
            scores.sort(key=lambda x: x[1], reverse=True)
            top_triangles = [s[0] for s in scores[:int(0.35 * len(vertices))]]
            
            new_vertices = []
            for t in top_triangles:
                centroid = compute_centroid(t)
                new_feat = average_parent_features(t)
                new_vertices.append(Vertex(centroid, new_feat))
            
            vertices.extend(new_vertices)
            triangles = delaunay_triangulate(vertices)
            gaussians = update_gaussians_from_mesh(vertices, triangles)
        
        optimize(gaussians, input_images, camera_poses, iterations=1)
        
    return gaussians
```

### Parameters
*   **Densification Interval:** 500 iterations [S2].
*   **Start/End Iterations:** 1,500 to 15,000 [S2].
*   **Area-weighting exponent ($\alpha$):** 0.75 [S2].
*   **Vertex Insertion Cap:** 0.35 $\times$ Current Vertex Count [S2].

### Edge Cases and Pitfalls
*   **Degeneracy:** Mesh-based variants may produce degenerate triangles (colinear vertices). A re-meshing step is required, though rare in practice [S2].
*   **Tiny Triangles:** Triangles with very few pixels can have high error but low spatial impact. The area-weighting exponent $\alpha < 1$ mitigates this by reducing their score relative to larger triangles [S2].
*   **Precision:** Standard 32-bit floating point is typically sufficient, but HDR pipelines may compress dynamic range before supervision [S2].

## Subtopics

### Coarse-to-Fine Densification
A specific implementation of the hybrid strategy using a triangular mesh representation instead of a raw point cloud [S2]. It differs from the standard point-based densification by explicitly managing topological connectivity via Delaunay triangulation. It is chosen when high-quality surface reconstruction is prioritized over raw point cloud flexibility. The scoring mechanism relies on DSSIM and pixel coverage to guide vertex insertion [S2].

## Operating characteristics
*   **Time Complexity:** Higher than single-stage training due to multiple optimization phases and periodic densification/re-meshing operations. Mesh-based variants add the cost of Delaunay triangulation [S2].
*   **Memory Complexity:** Increases during densification as the number of primitives grows. Buffer management is critical for contiguous memory access during rasterization [Parent].
*   **Performance:** Significantly improves rendering quality. On the Blender dataset, removing the hybrid strategy reduces PSNR from 30.3 dB to 26.6 dB, SSIM from 0.945 to 0.925, and increases LPIPS from 0.078 to 0.163 [S1].
*   **Strengths:** Better structural fidelity, robust convergence, and higher PSNR/SSIM compared to single-stage training [S1].
*   **Limitations:** Increased training time and complexity in implementation [S1, S2].

## Background
The Hybrid Coarse-to-Fine Strategy originates from the need to stabilize the training of differentiable point-based radiance fields. Early work on differentiable point-based rendering noted that single-stage training often failed to capture fine details [S1]. The mesh-based variant, "Neural Harmonic Textures," introduced explicit coarse-to-fine densification using DSSIM scoring to refine surface geometry [S2]. The strategy is widely used in modern 3D Gaussian Splatting pipelines to ensure high-quality view synthesis.
