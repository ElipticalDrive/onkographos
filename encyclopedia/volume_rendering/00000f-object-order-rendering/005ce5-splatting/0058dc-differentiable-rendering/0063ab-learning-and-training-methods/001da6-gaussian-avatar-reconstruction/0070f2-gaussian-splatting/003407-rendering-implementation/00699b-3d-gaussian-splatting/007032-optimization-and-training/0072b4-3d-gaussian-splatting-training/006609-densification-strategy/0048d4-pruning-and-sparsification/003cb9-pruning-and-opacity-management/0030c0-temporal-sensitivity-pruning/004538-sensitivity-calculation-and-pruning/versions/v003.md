# Sensitivity Calculation and Pruning
Also called: Gradient-based Sensitivity Pruning

## Overview
Sensitivity Calculation and Pruning is a method to eliminate 3D Gaussians that have no impact on training images by calculating sensitivity using the gradient of total image energy with respect to parameters [S1]. It differs from its parent, [Temporal Sensitivity Pruning](6350-temporal-sensitivity-pruning.md), by using a first-order gradient of total image energy rather than a second-order approximation of the L2 loss, and from [Gradient-based Pruning](17720-gradient-based-pruning.md) by specifically targeting the elimination of splats with zero sensitivity in color parameters to remove structural redundancy [S1].

## How it works
**Inputs:**
*   Set of 3D Gaussians $\mathcal{G}$, where each Gaussian $i$ has parameters including position, covariance, opacity, and spherical harmonic (SH) coefficients for color.
*   Training images and their corresponding camera poses.
*   Pruning threshold $\tau$ (value not given in the sources).

**Outputs:**
*   Pruned set of 3D Gaussians $\mathcal{G}'$ containing only Gaussians with non-zero sensitivity.

**Data Structures:**
*   Gaussian parameters are stored in standard 3DGS format.
*   Sensitivity score $S_i$ for each Gaussian $i$.

**Steps:**
1.  **Render Training Images:** Render the current set of Gaussians $\mathcal{G}$ to generate images for all training views.
2.  **Calculate Total Image Energy:** Compute the total image energy $E$ across all training views. The specific formula for energy is not explicitly defined in the sources, but it is derived from the rendered pixel values [S1].
3.  **Compute Sensitivity:** For each Gaussian $i$, calculate its sensitivity $S_i$ using the gradient of the total image energy $E$ with respect to the Gaussian's parameters (specifically the color parameters) [S1].
    *   **Critical Implementation Detail:** When calculating the gradient, **do not clamp** negative direction-dependent colors to zero. The standard 3DGS rendering pipeline clamps negative SH coefficients to zero during forward rendering. However, for sensitivity calculation, these clamped values must be treated as continuous to avoid setting partial derivatives to zero in the backward pass [S1]. If clamping is applied, SH coefficients that contribute to training images will incorrectly yield zero sensitivity [S1].
4.  **Identify Zero-Sensitivity Gaussians:** Identify Gaussians where the sensitivity in the color parameters is exactly zero. The sources observe that up to 15% of Gaussians may exhibit this property [S1].
5.  **Prune:** Eliminate all Gaussians with zero sensitivity from the scene [S1].

**Pseudocode:**
```python
def calculate_sensitivity_and_prune(gaussians, training_views):
    """
    Prunes Gaussians with zero sensitivity to total image energy.
    """
    # Step 1: Render images without clamping negative colors for gradient calculation
    # Note: Standard rendering might clamp, but sensitivity calc requires unclamped gradients
    rendered_images = render_unclamped(gaussians, training_views)
    
    # Step 2: Calculate total image energy
    # Formula for E is not explicitly given, assumed to be sum of squared pixel values or similar
    total_energy = calculate_total_image_energy(rendered_images)
    
    # Step 3: Calculate gradients of total energy w.r.t. Gaussian parameters
    # Specifically focus on color parameters (SH coefficients)
    gradients = compute_gradients(total_energy, gaussians, training_views)
    
    # Step 4: Identify Gaussians with zero sensitivity in color parameters
    zero_sensitivity_indices = []
    for i, gaussian in enumerate(gaussians):
        # Check if gradient magnitude for color parameters is zero
        color_gradient = gradients[i].color_params
        if is_zero(color_gradient):
            zero_sensitivity_indices.append(i)
            
    # Step 5: Remove zero-sensitivity Gaussians
    pruned_gaussians = [g for i, g in enumerate(gaussians) if i not in zero_sensitivity_indices]
    
    return pruned_gaussians

def render_unclamped(gaussians, views):
    """
    Renders images but ensures gradients flow through negative color values.
    In standard 3DGS, negative SH outputs are clamped to 0.
    Here, we must avoid this clamping for the backward pass.
    """
    # Implementation detail [G]: This requires modifying the rasterizer's backward pass
    # to not apply max(0, x) to the color contribution before gradient computation.
    return standard_rasterize(gaussians, views, clamp_colors=False)

def is_zero(vector, epsilon=1e-6):
    """
    Check if a vector is effectively zero.
    """
    return np.linalg.norm(vector) < epsilon
```

**Parameters:**
*   Pruning threshold: Not given in the sources. The method primarily targets *zero* sensitivity, but higher thresholds can be used to remove more Gaussians [S1].

**Edge Cases and Pitfalls:**
*   **Clamping Artifacts:** If negative direction-dependent colors are clamped to zero during the backward pass, the partial derivatives become zero, resulting in zero sensitivity for SH coefficients that may still contribute to training images [S1]. This must be avoided.
*   **Loss of Fine Details:** Using higher pruning thresholds (beyond zero) can remove fine details, such as small leaves, from the reconstruction [S1].

## Subtopics

### [Statistical Sensitivity-Driven Online Sparsification](14437-statistical-sensitivity-driven-online-sparsification.md)
Defines sensitivity as the expected gradient magnitude of the global photometric loss over a fixed accumulation window, performing sparsification online to avoid prohibitive time costs.

### [Gradient-based Pruning](17720-gradient-based-pruning.md)
Evaluates the magnitude of gradients associated with each Gaussian during training to remove structurally redundant or poorly aligned Gaussians, rather than just transparent ones.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** The sources note that a notable number of Gaussians (up to 15%) may have no impact on training images and can be safely eliminated [S1].
*   **Strengths:** Removes Gaussians that have no impact on training images, potentially reducing model size without significant loss in PSNR if thresholds are low [S1].
*   **Limitations:** Higher pruning thresholds can lead to the removal of fine details (e.g., small leaves) [S1].
*   **When to use:** When aiming to reduce model size by removing structurally redundant Gaussians that do not contribute to the rendered output.
*   **When not to use:** When preserving fine geometric details is critical, as aggressive pruning may remove them.

## Background
This method is described in "Compressed 3D Gaussian Splatting for Accelerated Novel View Synthesis" [S1]. It addresses the issue of redundant Gaussians in 3D Gaussian Splatting by identifying those with zero sensitivity to the total image energy.
