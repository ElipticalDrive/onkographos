# Mixed-Primitive Densification

Also called: Mixed-Primitive-based Gaussian Splatting Densification

## Overview
Mixed-Primitive Densification is a strategy for 3D Gaussian Splatting that extends the standard ellipsoidal primitive to include Gaussian triangles and lines, addressing the limitation of standard Gaussians in representing thin, linear, or planar structures [S1, unofficial]. It differs from sibling methods like [Score-based Densification](4705-score-based-densification.md) and [AdpSplit](16061-adpsplit.md) by explicitly changing the geometric primitive type during densification rather than just adjusting the shape or position of existing ellipsoids. It builds on [Densification and Splitting](20677-densification-and-splitting.md) by introducing a hybrid primitive system.

## How it works
**Inputs:** A set of 3D Gaussians (ellipsoids) with position $\mu$, rotation $R$, scale $S$, opacity $\alpha$, and spherical harmonics coefficients. Scene geometry estimates or depth information to identify linear/planar structures [S1, unofficial].
**Outputs:** An updated set of primitives containing ellipsoids, triangles, and lines, with optimized parameters.

**Data Structures:**
1.  **Gaussian Ellipsoid:** Standard 3D Gaussian Splatting representation.
2.  **Gaussian Triangle:** Defined by three vertices. Each vertex has a position $\mu_i$ ($i=1,2,3$). The triangle has a shared opacity $\alpha$ and color/SH coefficients.
3.  **Gaussian Line:** Defined by two endpoints. Each endpoint has a position $\mu_i$ ($i=1,2$). The line has a shared opacity $\alpha$ and color/SH coefficients.

**Parameters:**
*   $\omega_{dist}$: Distance threshold for vertex clustering. Set to 0.5 [S1, unofficial].
*   $\omega_{pear}$: Pearson correlation threshold for collinearity detection. Set to 0.9 [S1, unofficial].

**Steps:**
1.  **Primitive Selection:** Analyze the local geometry. If a region is identified as planar or linear, instantiate a Gaussian Triangle or Line primitive instead of a standard Gaussian Ellipsoid [S1, unofficial].
2.  **Cloning/Splitting Logic:** When a Gaussian Triangle or Line needs to be densified (cloned or split):
    *   **For Gaussian Triangles:**
        *   Clone or split the triangle into two new triangles.
        *   Assign the first vertex position $\mu_1$ of the new triangles according to the standard Gaussian Splatting rule for splitting ellipsoids (typically based on the parent's position and scale) [S1, unofficial].
        *   Assign the second and third vertex positions $\mu_2$ and $\mu_3$ of the new triangles to be identical to the original parent triangle's $\mu_2$ and $\mu_3$ [S1, unofficial].
    *   **For Gaussian Lines:**
        *   Clone or split the line into two new lines.
        *   Assign the first endpoint position $\mu_1$ of the new lines according to the standard splitting rule [S1, unofficial].
        *   Assign the second endpoint position $\mu_2$ of the new lines to be identical to the original parent line's $\mu_2$ [S1, unofficial].
3.  **Optimization:** Optimize the positions $\mu$, opacities $\alpha$, and other attributes of the new primitives using gradient descent on the rendering loss [S1, unofficial].

**Pseudocode:**
```python
def densify_mixed_primitive(primitive, split_rule):
    """
    Densifies a mixed primitive (Triangle or Line) based on the split rule.
    primitive: object with type ('triangle' or 'line'), vertices (list of positions), opacity, etc.
    split_rule: function that returns a new position based on parent position and scale (standard GS split)
    """
    if primitive.type == 'triangle':
        # Create two new triangles
        new_tri_1 = copy(primitive)
        new_tri_2 = copy(primitive)
        
        # Calculate new first vertex using standard GS split logic
        new_mu_1 = split_rule(primitive.mu_1, primitive.scale)
        
        # Assign vertices: mu1 is new, mu2 and mu3 are copied from parent
        new_tri_1.mu_1 = new_mu_1
        new_tri_1.mu_2 = primitive.mu_2
        new_tri_1.mu_3 = primitive.mu_3
        
        new_tri_2.mu_1 = new_mu_1
        new_tri_2.mu_2 = primitive.mu_2
        new_tri_2.mu_3 = primitive.mu_3
        
        return [new_tri_1, new_tri_2]
        
    elif primitive.type == 'line':
        # Create two new lines
        new_line_1 = copy(primitive)
        new_line_2 = copy(primitive)
        
        # Calculate new first endpoint using standard GS split logic
        new_mu_1 = split_rule(primitive.mu_1, primitive.scale)
        
        # Assign endpoints: mu1 is new, mu2 is copied from parent
        new_line_1.mu_1 = new_mu_1
        new_line_1.mu_2 = primitive.mu_2
        
        new_line_2.mu_1 = new_mu_1
        new_line_2.mu_2 = primitive.mu_2
        
        return [new_line_1, new_line_2]
```

## Subtopics

### Structure-aware Densification
A densification strategy that determines the split factor directly from the structure tensor eigenvalue ratio $\eta_{max}$, allowing Gaussians to adapt their shape for anisotropic structures and reach fine resolution in fewer iterations than uniform shrinkage methods [S2]. Unlike previous methods that split each Gaussian into two children with uniform shrinkage requiring multiple iterations, this method determines split factors from local frequency content, reaching necessary resolution in fewer cycles [S2]. It is applied every 500 iterations [S2].

**Formula:**
The number of children $n$ along a specific axis is calculated as:
$$ n = \lceil \sqrt{\eta} \rceil $$
where $\eta$ is the eigenvalue ratio for that axis [S2].

The position of each child Gaussian is calculated as:
$$ \boldsymbol{\mu}_{\text{child}}^{(i,j,k)} = \boldsymbol{\mu}_{\text{parent}} + \boldsymbol{R}_{\text{parent}} \cdot (\mathbf{s}_{\text{parent}} \odot \mathbf{g}^{(i,j,k)}) $$
where $\boldsymbol{\mu}$ is position, $\boldsymbol{R}$ is rotation matrix, $\mathbf{s}$ is scaling vector, $\odot$ is element-wise multiplication, and $\mathbf{g}$ are grid coordinates in the unit cube [S2].

The children's scaling vectors are defined as:
$$ \mathbf{s}_{\text{child}} = \mathbf{s}_{\text{parent}} \oslash (n_x, n_y, n_z) $$
where $\oslash$ denotes element-wise division [S2].

**Parameters:**
*   $\eta_{max}$: The factor by which the Gaussian's extent exceeds the local wavelength along the $i$-th principal direction, derived from the multi-scale structure tensor [S2].
*   Densification frequency: Every 500 iterations [S2].

**Comparison:**
This method avoids excessive splitting when $\eta$ is large or noisy by using a concave mapping ($\sqrt{\eta}$) instead of a linear one [S2]. It computes $\eta$ independently for each dimension [S2].

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Performance:** Mixed-Primitive Densification improves surface reconstruction quality for thin structures compared to standard Gaussian Splatting [S1, unofficial]. Structure-aware Densification reduces the number of iterations required to converge to fine resolution [S2].
*   **Strengths:** Better representation of linear and planar features; faster convergence for anisotropic structures (Structure-aware variant).
*   **Limitations:** Increased complexity in primitive management; requires geometry estimation for primitive selection (Mixed-Primitive variant); sensitive to noise in eigenvalue calculation (Structure-aware variant).
