# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the photometric difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images by replacing implicit neural fields with explicit, differentiable Gaussian splats [S5, unofficial]. Unlike NeRF-based methods which require per-pixel ray marching and neural network inference, 3DGS training relies on differentiable rasterization of ellipsoids, offering significantly faster training and real-time rendering speeds while achieving comparable image quality [S2][S5, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images (or video frames) with known camera poses (extrinsics $R_{cw}, t_{cw}$ and intrinsics $K$) [S6, unofficial]. Initial 3D Gaussian parameters derived from Structure from Motion (SfM) [S2][S6, unofficial].
*   **Outputs:** Optimized Gaussian parameters: positions $\mathbf{p}$, rotations $q$, scales $\mathbf{s}$, opacities $\alpha$, and spherical harmonic coefficients $h$ [S6, unofficial].

**Data Structures:**
Each Gaussian primitive $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$ (initialized from SfM point cloud) [S6, unofficial].
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion) [S6, unofficial].
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$ (initialized between 0 and 1) [S2].
*   Opacity $\alpha_i \in [0, 1]$ (initialized as a constant) [S6, unofficial].
*   Appearance: Spherical Harmonic coefficients $h_i$ (initialized from SfM) [S6, unofficial].

**Rotation Matrix:**
The unit quaternion $q = (q_r, q_i, q_j, q_k)$ is converted to a rotation matrix $R$ [S2]:
$$
R(q) = 2 \begin{bmatrix} \frac{1}{2} - (q_j^2 + q_k^2) & q_i q_j - q_r q_k & q_i q_k + q_r q_j \\ q_i q_j + q_r q_k & \frac{1}{2} - (q_i^2 + q_k^2) & q_j q_k - q_r q_i \\ q_i q_k - q_r q_j & q_j q_k + q_r q_i & \frac{1}{2} - (q_i^2 + q_j^2) \end{bmatrix}
$$
The covariance matrix $\Sigma$ is computed from $R$ and $\mathbf{s}$ [S2].

**Loss Function:**
The optimization minimizes a combined loss $\mathcal{L}$ [S6, unofficial]:
$$
\mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM}
$$
where $\lambda$ is a weight (typically 0.2) [S6, unofficial]. $\mathcal{L}_1$ is the L1 loss and $\mathcal{L}_{D-SSIM}$ is the differentiable Structural Similarity loss [S6, unofficial].

**Optimization Steps:**
The training loop iterates for a fixed number of steps (default 30,000) [S3, S4, unofficial].

1.  **Camera Sampling:** Select a training view $V$ and its ground truth image $\hat{I}$ [S2]. Cameras are sampled via a shuffled round-robin iterator [S4, unofficial].
2.  **Rendering:** Project the 3D Gaussians to 2D screen space using the camera matrix. Sort Gaussians by depth. Alpha-blend them to produce the rendered image $I$ [S2][S6, unofficial].
    *   Pixel color $\gamma_j$ for pixel $j$ is computed as:
        $$
        \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij}, \quad \tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj})
        $$
        where $N$ is the number of projected Gaussians, $c_i$ is the color, and $\tau_{ij}$ is the transmittance [S6, unofficial].
    *   Effective opacity $\alpha'_{ij} = g \alpha_i$, where $g$ accounts for the 2D covariance projection [S6, unofficial].
3.  **Loss Computation:** Compute $\mathcal{L}$ between $I$ and $\hat{I}$ [S2].
4.  **Backpropagation:** Compute gradients $\frac{\partial \mathcal{L}}{\partial \theta}$ for all parameters $\theta \in \{\mathbf{p}, q, \mathbf{s}, h, \alpha\}$ using the chain rule [S6, unofficial].
5.  **Parameter Update:** Update parameters using the Adam optimizer [S2].
6.  **Adaptive Density Control:** Periodically (e.g., every 100–500 steps), modify the Gaussian set based on optimization metrics [S2]:
    *   **Pruning:** If $\alpha_i < \epsilon$ or the Gaussian is too large, remove it [S2].
    *   **Densification:** If the positional gradient magnitude $\|\nabla_{\mathbf{p}} \mathcal{L}\| > \tau_p$:
        *   **Split:** If the scale $\|\mathbf{s}\| > \tau_s$ (over-reconstruction), split the Gaussian into two [S2].
        *   **Clone:** If the scale $\|\mathbf{s}\| \le \tau_s$ (under-reconstruction), clone the Gaussian [S2].

**Pseudocode:**
```python
def train_3dgs(images, cameras, num_iters=30000, densify_from=500, densify_until=15000, refine_every=100):
    # 1. Initialization
    # Initialize positions from SfM point cloud
    positions = get_sfm_points(images)
    # Initialize other parameters
    rotations = init_quaternions(positions)
    scales = init_scales(positions)
    opacities = init_opacities()
    colors = init_colors(positions) # Spherical Harmonics
    
    # Initialize optimizer (Adam)
    optimizer = Adam([positions, rotations, scales, opacities, colors])
    
    # Camera iterator (shuffled round-robin)
    cam_iter = InfiniteRandomIterator(cameras)
    
    step = 1
    while step <= num_iters:
        # 2. Sample View
        cam = cam_iter.next()
        gt_image = get_ground_truth(cam)
        
        # 3. Render
        # Project Gaussians, sort by depth, alpha blend
        rendered_image = rasterize(positions, rotations, scales, opacities, colors, cam)
        
        # 4. Compute Loss
        loss = compute_loss(rendered_image, gt_image)
        
        # 5. Backpropagate and Update
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # 6. Adaptive Density Control (Interleaved)
        if step % refine_every == 0 and densify_from <= step <= densify_until:
            gradients = compute_position_gradients(loss)
            for i in range(len(positions)):
                # Pruning
                if opacities[i] < epsilon or is_too_large(scales[i]):
                    prune_gaussian(i)
                # Densification
                elif gradients[i] > densify_grad_thresh:
                    if norm(scales[i]) > densify_size_thresh:
                        split_gaussian(i)
                    else:
                        clone_gaussian(i)
        
        step += 1
```

**Parameters:**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `shDegree`: Spherical Harmonic degree. Default: 3 [S3, S4, unofficial].
*   `shDegreeInterval`: Steps between increasing SH degree. Default: 1,000 [S3, S4, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S3, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: min(15,000, numIters / 2) [S3, unofficial].
*   `refineEvery`: Frequency of densification/pruning. Default: 500 [S3, unofficial] or 100 [S4, unofficial].
*   `densifyGradThresh`: Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   `densifySizeThresh`: Size threshold for splitting. Default: 0.01 [S4, unofficial].
*   `ssimWeight`: Weight for SSIM loss. Default: 0.2 [S3, S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].

**Edge Cases and Pitfalls:**
*   **No Cameras See Points:** If all cameras are filtered out because they see no sparse points, training fails [S3, unofficial].
*   **Arbitrary Pose Rendering:** Requires exactly 16 elements for the camera-to-world matrix [S4, unofficial].
*   **Evaluation Mode:** Dataset must be loaded with `eval_mode=True` for evaluation, otherwise it throws a runtime error [S4, unofficial].
*   **CPU vs GPU:** CPU execution is ~100x slower than GPU [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is significantly faster than NeRFs, typically completing in minutes to hours depending on scene size and resolution [S2][S5, unofficial].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians. Default limit is 5,000,000 Gaussians [S3, unofficial]. Sinc splatting variants consume less memory than standard Gaussians [S7].
*   **Performance:** Achieves real-time rendering speeds (often >100 FPS) on consumer hardware [S5, unofficial]. On the Replica dataset, SGS-SLAM achieves PSNR 34.15, SSIM 0.97, and LPIPS 0.096 [S1].
*   **Hardware:** Supports CUDA, MPS, and CPU. CPU is ~100x slower than GPU [S3, S4, unofficial].
*   **Strengths:** Fast training, real-time rendering, high fidelity.
*   **Limitations:** Sensitive to initialization; prone to "floaters" in empty space without regularization; requires careful densification tuning [S2].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. [9] (cited in [S2][S6, unofficial]). It initializes positions using sparse point clouds from SfM tools like COLMAP [S2][S6, unofficial]. The method has been widely adopted for real-time novel view synthesis and is implemented in various frameworks including OpenSplat [S3, unofficial] and Msplat [S4, unofficial].
