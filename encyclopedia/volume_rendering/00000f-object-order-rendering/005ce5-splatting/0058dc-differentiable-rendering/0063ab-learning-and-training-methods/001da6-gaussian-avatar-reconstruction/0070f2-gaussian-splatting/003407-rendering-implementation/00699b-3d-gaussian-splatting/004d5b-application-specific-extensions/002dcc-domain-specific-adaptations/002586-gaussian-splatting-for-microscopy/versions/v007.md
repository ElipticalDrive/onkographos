# Gaussian Splatting for Microscopy

Also called: Gaussian Splatting for Microscopy Volumes, nD Gaussian splatting

## Overview
Gaussian Splatting for Microscopy decomposes an $n$-dimensional fluorescence microscopy volume into a mixture of oriented, anisotropic Gaussian primitives, optimizing them against the data to place representational capacity only where signal exists [S1, unofficial]. This enables interactive web visualization and significant compression by allowing direct GPU rasterization without voxel grids [S1, unofficial]. Unlike standard 3D Gaussian Splatting which uses view-dependent color, this method uses view-independent scalar attributes (amplitudes) to represent intensity, diverging from the RGB opacity/color model [G]. It builds on [Domain-Specific Adaptations](5621-domain-specific-adaptations.md).

## How it works
**Inputs and Outputs**
*   **Input:** A preprocessed, normalized $n$-dimensional microscopy volume $V: \mathbb{R}^D \rightarrow \mathbb{R}_{\ge 0}$.
*   **Output:** A set of $K$ Gaussian splats, each defined by a center $\mu_k$, an amplitude $a_k$, and a Cholesky factor $L_k$ of the covariance matrix.

**Data Structures**
Each Gaussian splat $k$ stores:
*   $\mu_k \in \mathbb{R}^D$: The center position.
*   $a_k \in \mathbb{R}$: The amplitude (non-negative).
*   $L_k \in \mathbb{R}^{D \times D}$: The lower-triangular Cholesky factor of the covariance $\Sigma_k = L_k L_k^\top$. This stores $D(D+1)/2$ elements (6 for 3D), guaranteeing positive-definiteness by construction [S1, unofficial].
    *   The diagonal of $L_k$ is parameterized as $\sigma_{min} + \text{softplus}(\cdot)$, where $\sigma_{min} = 1/\sqrt{12}$ voxels (the standard deviation of a uniform voxel), ensuring no splat is narrower than a voxel's own spread [S1, unofficial].
*   Amplitudes are made non-negative by a softplus activation and are upper-bounded by a configurable maximum $a_{max}$ [S1, unofficial].

**Preprocessing**
1.  **Registration and Fusion:** Multi-view images (e.g., light-sheet) are registered and fused. Deconvolution (e.g., ten iterations against the point-spread function) produces a single fused volume per timepoint [S1, unofficial].
2.  **Normalization:** Source volumes (stored as 16-bit integers or float32) are normalized to $[0, 1]$ using an affine map of the intensity range with dataset-specific outlier clipping [S1, unofficial].
    *   **Clipping Strategy:** Specific percentile clipping is applied based on dataset characteristics:
        *   Plain min-max: Kidney, Cells3D, Blastocyst, Tribolium, Mouse heart [S1, unofficial].
        *   1st–99.5th percentiles: OpenCell [S1, unofficial].
        *   1st–99.999th percentiles: C. elegans [S1, unofficial].
        *   0th–99.999th percentiles: Sparse Fly brain [S1, unofficial].
        *   0th–99.9th percentiles: Zebrafish, Drosophila [S1, unofficial].
        *   Neuromast channels: Background floors (105.99 and 103.89 grey levels) are subtracted, then clipped to 0th–99.9th percentiles [S1, unofficial].
    *   **Background Floor Handling:** For quality benchmarks, no floor suppression is applied. For timing/compression benchmarks, automatic floor suppression subtracts a constant background pedestal before fitting to improve compression [S1, unofficial].

**Initialization**
Initial positions are seeded automatically from the volume using gradient-weighted samples of the volume’s edges, complemented by a coarse uniform grid [S1, unofficial].

**Optimization**
The parameters are optimized using the Adam optimizer [S1, unofficial]. The loss function is L1 with regularization on splat amplitudes and extents [S1, unofficial].
*   **Fixed-Pool Optimizer:** The number of splats $K$ is fixed during optimization. Periodically, the least informative splats are relocated to regions of high reconstruction residual. This acts as a fixed-pool analogue to the pruning-and-seeding cycle used in standard 3D Gaussian Splatting, keeping optimizer tensor shapes constant [S1, unofficial].
*   **Splat Budget Selection ($K$):** The optimal number of splats is determined by blind-spot cross-validation to balance PSNR and overfitting [S1, unofficial].
    1.  Mask 5% of voxels.
    2.  Replace masked voxels with donut-median neighbourhood values [S1, unofficial].
    3.  Score reconstruction on held-out voxels.
    4.  Stop fitting at the held-out PSNR peak to prevent overfitting noise. If the peak is interior or cull-limited, use the peak or the point where cull holds count constant [S1, unofficial].
    *   *Note:* Blind-spot cross-validation assumes noise is independent across voxels. On fused or deconvolved volumes, a held-out peak is not guaranteed. If a noise floor is estimable, it caps the budget from above to avoid reproducing noise [S1, unofficial].

**Rendering Formula**
The model prediction at voxel $x$ is:
$$ \hat{V}(x) = \sum_{k=1}^{K} a_k \exp\left(-\frac{1}{2} \|L_k^{-1} (x - \mu_k)\|^2\right) $$
where $\mu_k$ is the position, $a_k > 0$ is the amplitude, and $L_k$ is the Cholesky factor of the covariance [S1, unofficial].

**Viewer Evaluation**
The viewer uses a truncated Gaussian to ensure compact support:
$$ a_k \max\left(0, \exp\left(-\frac{1}{2} \|L_k^{-1} (x - \mu_k)\|^2\right) - \frac{c_T}{1 - c_T}\right) $$
with $c_T = \exp(-T/2)$ at $T = 2.75$ standard deviations [S1, unofficial].

def preprocess_volume(volume, dataset_name):
    """
    Preprocesses a microscopy volume for fitting.
    volume: numpy array, raw intensity data.
    dataset_name: str, identifier for clipping strategy.
    returns: normalized volume in [0, 1].
    """
    # Step 1: Normalization and Clipping
    # Apply dataset-specific outlier clipping
    if dataset_name in ['Kidney', 'Cells3D', 'Blastocyst', 'Tribolium', 'Mouse heart']:
        v_min, v_max = np.min(volume), np.max(volume)
    elif dataset_name == 'OpenCell':
        v_min = np.percentile(volume, 1)
        v_max = np.percentile(volume, 99.5)
    elif dataset_name == 'C. elegans':
        v_min = np.percentile(volume, 1)
        v_max = np.percentile(volume, 99.999)
    elif dataset_name == 'Fly brain':
        v_min = np.percentile(volume, 0)
        v_max = np.percentile(volume, 99.999)
    elif dataset_name in ['Zebrafish', 'Drosophila']:
        v_min = np.percentile(volume, 0)
        v_max = np.percentile(volume, 99.9)
    elif dataset_name == 'Neuromast':
        # Subtract background floors
        floor1, floor2 = 105.99, 103.89
        volume = volume - floor1 # Simplified for single channel logic
        volume = np.clip(volume, 0, None)
        v_min = np.percentile(volume, 0)
        v_max = np.percentile(volume, 99.9)
    else:
        v_min, v_max = np.min(volume), np.max_volume()

    # Affine map to [0, 1]
    normalized = (volume - v_min) / (v_max - v_min)
    return normalized

    # Gradient-weighted samples of edges

    edge_strength = np.linalg.norm(gradients, axis=0)

    centers = sample_centers(edge_strength, num_splats)
    
    # Initialize amplitudes to mean intensity
    amplitudes = np.full(num_splats, np.mean(volume))
    
    # Initialize Cholesky factors
    # Diagonal parameterized as sigma_min + softplus(0) = sigma_min
    sigma_min = 1.0 / np.sqrt(12)
    L = np.zeros((num_splats, D, D))
    for k in range(num_splats):
        np.fill_diagonal(L[k], sigma_min)
        
    return centers, amplitudes, L

def loss_function(predicted, target, amplitudes, extents):
    """
    Computes L1 loss with regularization.
    predicted: numpy array, reconstructed volume.
    target: numpy array, ground truth volume.
    amplitudes: numpy array, splat amplitudes.
    extents: numpy array, derived from L (e.g., trace or determinant).
    returns: scalar loss.
    """
    l1_loss = np.mean(np.abs(predicted - target))
    # Regularization on amplitudes and extents
    amp_reg = np.mean(amplitudes)
    ext_reg = np.mean(extents)
    return l1_loss + 0.1 * amp_reg + 0.1 * ext_reg

def cross_validation_optimal_k(volume, k_candidates):

    k_candidates: list of int, splat counts to test.
    returns: int, optimal K.

    best_k = None
    best_psnr = -np.inf
    
    for k in k_candidates:

def reconstruct_volume_from_params(mu, a, L, shape):
    """
    Reconstructs volume from Gaussian parameters.
    mu: centers, shape (K, D)
    a: amplitudes, shape (K,)
    L: Cholesky factors, shape (K, D, D)
    shape: tuple, volume dimensions.
    returns: numpy array, reconstructed volume.
    """
    # Create grid of coordinates
    coords = np.meshgrid(*[np.arange(s) for s in shape], indexing='ij')
    coords = np.stack(coords, axis=-1).reshape(-1, len(shape))
    
    reconstructed = np.zeros(shape)
    for k in range(len(a)):
        diff = coords - mu[k]
        # Compute Mahalanobis distance
        # dist_sq = sum((L_inv @ diff)^2)

## Operating characteristics
*   **Time Complexity**: Fitting is the expensive side. Convergence is rapid; at 2,000 iterations, training PSNR is within 0.5 dB of the 20,000-iteration value for 77 of 85 volume-capacity cells [S1, unofficial]. Adding capacity (more splats) outperforms adding iterations: 16K splats × 500 iterations beat 4K splats × 20,000 iterations by +3.03 dB average across 17 volumes at 10× fewer splat-iterations [S1, unofficial].
*   **Memory Complexity**: The representation is compact. Median compression ratio is 99.3× (range 6–340×) across 17 volumes from 12 datasets [S1, unofficial]. For example, a Kidney nuclei volume (199 MB raw) is compressed to 18.4 MB (11× smaller) with 2.04M splats achieving 56.0 dB PSNR [S1, unofficial].
*   **Measured Performance**: On an NVIDIA RTX 3070 (8 GiB), median fitting time is 2.4 minutes per volume at a 32K budget [S1, unofficial]. Rendering maintains 60 FPS (16.7 ms budget) through $10^6$ elements at 720p HDR [S1, unofficial].
*   **Strengths**: Direct GPU rasterization without voxel grids; suitable for streaming and interactive web visualization; significant compression; fast convergence.
*   **Limitations**: Structures thinner than the local Gaussian scale (e.g., individual microtubules) blur; the representation is for looking, not measuring; fitting is asymmetric (expensive fitting, cheap viewing); blind-spot cross-validation may not find a clear peak on fused/deconvolved volumes [S1, unofficial].
*   **When to use**: Interactive web visualization of large nD microscopy volumes; sharing data via static file hosting; compression for storage.
*   **When not to use**: Quantification, segmentation, or tracking tasks where precise voxel-level accuracy is required; quick inspection of a single stack where fitting time is prohibitive [S1, unofficial].

## Background
The method was introduced in the Luxar framework, an open-source Python system for compiling multidimensional scientific data into compact archives for web visualization [S1, unofficial]. It adapts nD Gaussian splatting for microscopy, validating the approach on 17 volumes from 12 datasets spanning spinning-disk, confocal, light-sheet, and structured-illumination modalities [S1, unofficial]. The approach builds on the principle that fluorescence volumes can be represented as mixtures of anisotropic Gaussians, with the number of splats determined by blind-spot cross-validation to separate signal from noise [S1, unofficial]. It complements desktop tools like napari and Fiji, and voxel-pyramid web viewers like Neuroglancer and Viv [S1, unofficial].
