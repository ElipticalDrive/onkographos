# latentSplat

Also called: Autoencoding Variational Gaussians for Fast Generalizable 3D Reconstruction

## Overview
latentSplat is a method for generalizable 3D reconstruction from two reference views that predicts semantic 3D Gaussians in a latent space [S1, unofficial]. It models uncertainty explicitly by storing distributions (mean and variance) of spherical harmonic coefficients for each Gaussian, allowing sampling of specific instances for rendering [S1, unofficial]. Unlike regression-based methods such as [pixelSplat](16424-pixelsplat.md) which provide a single low-variance solution, latentSplat handles high-ambiguity regions and view extrapolation better, avoiding blurry reconstructions in unobserved areas [S1, unofficial]. Compared to generative diffusion-based methods like [GeNVS](16426-genvs.md), it is orders of magnitude faster and scales to high resolutions by using efficient Gaussian splatting for rendering instead of volume rendering or iterative diffusion sampling [S1, unofficial].

## How it works
**Inputs:** Two reference views (RGB images) and their corresponding camera poses [S1, unofficial].
**Outputs:** A synthesized RGB image for an arbitrary novel view [S1, unofficial].

**Data Structures:**
The scene is represented as a set of $N$ variational Gaussians $\mathcal{G} = \{(\mathbf{x}, \mathbf{S}, \mathbf{R}, o, \mathbf{c}, \mathbf{h}_\mu, \mathbf{h}_\sigma)_i\}_{1 \leq i \leq N}$ [S1, unofficial].
*   $\mathbf{x} \in \mathbb{R}^3$: 3D location.
*   $\mathbf{S} \in \mathbb{R}^3$: Scale (diagonal matrix elements).
*   $\mathbf{R} \in \mathbb{R}^3$: Rotation (normalized quaternion) [S1, unofficial].
*   $o \in [0, 1]$: Opacity.
*   $\mathbf{c} \in \mathbb{R}^{K_c}$: Spherical Harmonics (SH) coefficients for view-dependent color.
*   $\mathbf{h}_\mu \in \mathbb{R}^{K_h}$: Mean of the Gaussian distribution for semantic feature SH coefficients.
*   $\mathbf{h}_\sigma \in \mathbb{R}^{K_h}$: Standard deviation of the Gaussian distribution for semantic feature SH coefficients [S1, unofficial].
*   The covariance matrix is $\mathbf{C} = \mathbf{R} \mathbf{S} \mathbf{S}^\top \mathbf{R}^\top$ [S1, unofficial].
*   SH coefficients are computed up to degree 4 for RGB and degree 2 for semantic features (dimensionality 4) [S1, unofficial].

**Parameters:**
*   $N$: Total number of variational Gaussians representing the scene [S1, unofficial].
*   Token dimensionality in the epipolar transformer: 128 [S1, unofficial].
*   Input feature maps downscaled by a factor of 4 in each dimension for computational feasibility [S1, unofficial].
*   Epipolar transformer processes 32 samples of each pixel's epipolar line [S1, unofficial].

**Steps:**
1.  **Feature Encoding:** Encode the two input views using a DINOv1 ViT-B/8 backbone [S1, unofficial]. Upscale local patch tokens by repeating them to the original patch size [S1, unofficial]. Add a linearly projected global class token to obtain a feature map at the original image resolution [S1, unofficial]. Downscale the input feature maps by a factor of 4 in each dimension for computational feasibility [S1, unofficial].
2.  **Epipolar Aggregation:** Process 32 samples of each pixel's epipolar line using an epipolar transformer [S1, unofficial]. The transformer consists of two blocks with four-head attention [S1, unofficial]. Token dimensionality is 128 [S1, unofficial]. Add a skip connection at the original resolution to prevent a bottleneck with low spatial dimensions in the epipolar transformer [S1, unofficial].
3.  **Gaussian Parameter Prediction:** Pass the aggregated features through a Gaussian sampling head [S1, unofficial]. The head employs simple linear projections with specific activation functions: normalized quaternions for rotation $\mathbf{R}$ [S1, unofficial], and scaled and shifted sigmoid for scale $\mathbf{S}$ and opacity $o$ [S1, unofficial]. Predict $\mathbf{h}_\mu$ and $\mathbf{h}_\sigma$ for the semantic feature distributions [S1, unofficial].
4.  **Sampling:** Sample a specific instance of semantic Gaussians from the variational distributions using the reparameterization trick [S1, unofficial]. For each Gaussian $i$, sample feature coefficients $\mathbf{h}_i \sim \mathcal{N}(\mathbf{h}_{\mu,i}, \mathbf{h}_{\sigma,i})$ [S1, unofficial].
5.  **Rendering:** Render the sampled instance of semantic Gaussians to the target novel view using efficient Gaussian splatting [S1, unofficial]. This produces an auxiliary RGB rendering and feature maps [S1, unofficial].
6.  **Decoding:** Decode the splatted features into pixel space using a lightweight generative decoder network (VAE-GAN decoder) [S1, unofficial]. The decoder is a fully convolutional architecture with four upsample blocks, each containing two residual blocks [S1, unofficial]. Add 1x1 convolutions as skip connections to feed downscaled versions of the intermediate auxiliary RGB renderings and feature maps into each upsample block [S1, unofficial]. Initialize the weights of these additional skip connection layers to zero to avoid noisy gradients [S1, unofficial].
7.  **Discrimination (Training Only):** A discriminator (small CNN with three strided convolutions) predicts the likelihood of patches [S1, unofficial]. It has no global receptive field [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Fast rendering due to Gaussian splatting, orders of magnitude faster than diffusion-based methods [S1, unofficial].
*   **Memory Complexity:** Scales to high resolutions due to the efficient Gaussian representation [S1, unofficial].
*   **Performance:** Achieves state-of-the-art quality in two-view reconstruction, especially in challenging cases of wide-spread input views and view extrapolation [S1, unofficial].
*   **Strengths:** Handles high-ambiguity regions, generalizes to interpolated and extrapolated views, purely trained on real video data without 3D supervision (depth/pose labels for target view) [S1, unofficial].
*   **Limitations:** Requires two reference views and their camera poses [S1, unofficial].
*   **When to use:** When fast, generalizable 3D reconstruction from few views is needed, especially for extrapolation or ambiguous scenes [S1, unofficial].
*   **When not to use:** When single-view reconstruction is required or when per-scene optimization is acceptable and higher fidelity is needed [S1, unofficial].

## Background
latentSplat was introduced by C. Wewer et al. in 2024 [S1, unofficial]. It builds on the success of 3D Gaussian Splatting [31] and addresses limitations of previous generalizable methods that either do not scale to large scenes or are limited to interpolation of close input views [S1, unofficial]. It combines regression-based and generative approaches, using variational Gaussians to model uncertainty [S1, unofficial].
