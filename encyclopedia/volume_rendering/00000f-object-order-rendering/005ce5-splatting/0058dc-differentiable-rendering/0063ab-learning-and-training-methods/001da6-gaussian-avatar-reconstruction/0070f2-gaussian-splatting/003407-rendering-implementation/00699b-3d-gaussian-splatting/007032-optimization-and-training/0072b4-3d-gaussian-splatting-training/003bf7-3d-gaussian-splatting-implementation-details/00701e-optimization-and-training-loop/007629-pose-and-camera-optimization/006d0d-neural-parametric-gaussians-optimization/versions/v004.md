# Neural Parametric Gaussians Optimization

Also called: two-stage optimization for monocular non-rigid reconstruction

## Overview
Neural Parametric Gaussians (NPGs) is a two-stage optimization procedure for monocular non-rigid object reconstruction that combines a coarse parametric point model regularized by a low-rank deformation basis with 3D Gaussians to model fine geometric and appearance details efficiently [S1]. It sets itself apart from siblings like [Local 3DGS Optimization](20073-local-3dgs-optimization.md) by explicitly decoupling the learning of global non-rigid deformation (via the parametric basis) from local detail fitting (via Gaussians), ensuring coarse geometry remains intact over time [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A sequence of monocular images (or video frames) of a non-rigid object. Masks for dynamic objects are required if static background elements exist (e.g., ground planes) [S1].
*   **Output:** A set of 3D Gaussians representing the object's geometry and appearance, parameterized by a coarse template and deformation coefficients.

**Data Structures:**
1.  **Coarse Template:** A set of $N=1500$ points representing the initial coarse geometry [S1].
2.  **Deformation Basis Coefficients:** A 6-layer Multi-Layer Perceptron (MLP) that maps input features (e.g., time, position) to coefficients for a low-rank deformation basis [S1].
3.  **Deformation Basis Size ($K$):** A hyperparameter controlling the rank of the deformation basis. Optimal value is 25 for synthetic sequences like the cactus [S1].
4.  **3D Gaussians:** Parameters for position, scale, rotation, opacity, and spherical harmonics coefficients, initialized or refined in Stage 2 [S1].
5.  **Interpolation Weights ($w$):** Weights used to blend or interpolate between the coarse template and Gaussian details [S1].

**Numbered Steps:**

1.  **Stage 1: Coarse Parametric Model Initialization**
    *   Initialize the coarse template with $N=1500$ points [S1].
    *   Initialize the 6-layer MLP to compute deformation basis coefficients [S1].
    *   Optimize the template and MLP parameters using the Adam optimizer [S1].
    *   **Loss Function:** Includes a rigidity loss to keep the template consistent across timesteps [S1].
    *   **Training Schedule:**
        *   Batch size: 10 [S1].
        *   Learning Rate (LR): 0.0005 with cosine annealing and warm-up [S1].
        *   Iterations: 100,000 [S1].

2.  **Stage 2: Gaussian Refinement**
    *   Initialize 3D Gaussians based on the coarse template [S1].
    *   Optimize Gaussian parameters (position, scale, etc.) and interpolation weights $w$ [S1].
    *   **Learning Rate Schedules:**
        *   Interpolation weights $w$: Matches the default point position learning rate from 3DGS [S1].
        *   Gaussian scale: Starts high and decays exponentially to 0.0005 [S1].
        *   Other parameters: Follow the default 3DGS learning rate schedule [S1].
    *   **Training Schedule:**
        *   Iterations: 70,000 [S1].
    *   **Optional Finetuning:** Stage 1 parameters (template and MLP) can be finetuned during Stage 2 with a fixed LR of 0.0001 to improve template accuracy [S1].

**Formulas:**
*   **Rigidity Loss:** Applied in Stage 1 to enforce temporal consistency of the template [S1]. Specific mathematical formulation is not provided in the sources.
*   **Deformation Basis:** The deformation is controlled by the basis size $K$. A smaller $K$ over-regularizes, restricting non-rigid deformations; a larger $K$ overfits, hindering novel view synthesis [S1].

**Pitfalls and Edge Cases:**
*   **Template Collapse:** If the camera is very static, the optimized template may collapse to a flat surface, leading to incorrect deformation [S1].
*   **Static Background:** In object-centric settings with large static ground planes, masks for dynamic objects only are required to ensure fair comparison and correct reconstruction [S1].

def stage_2_optimization(template_points, deformation_mlp, images, masks, iterations=70000):

        coefficients = deformation_mlp(batch_features)
        
        # Apply deformation to template
        deformed_template = apply_deformation_basis(template_points, coefficients, basis_size=25)
        
        # Combine template and Gaussians using weights

        final_representation = blend(deformed_template, gaussians, weights)
        
        # Render image
        rendered_image = render(final_representation, batch_masks)
        
        # Compute loss
        loss = compute_rendering_loss(rendered_image, batch_images)
        
        # Backpropagate and update

## Operating characteristics
*   **Performance:** NPGs outperform Nerfies, HyperNeRF, TiNeuVox, and HexPlane on the Unbiased4D dataset, achieving a PSNR of 22.348 compared to 15.92-18.56 for baselines [S1].
*   **Strengths:** Keeps coarse geometry intact over the sequence and successfully fits high-frequency details, leading to consistent novel view synthesis [S1].
*   **Limitations:** Highly ill-posed problem; performance depends on camera movement, lighting, speed, and extent of deformations [S1]. Fails if the camera is very static, leading to template collapse [S1].
*   **Complexity:** Uses 1500 points for coarse geometry and a 6-layer MLP, which is computationally lighter than full neural radiance fields but requires careful tuning of the deformation basis size $K$ [S1].

## Background
*   **Origin:** Introduced in "Neural Parametric Gaussians for Monocular Non-Rigid Object Reconstruction" (CVPR 2024) [S1].
*   **History:** Developed to address the challenges of monocular non-rigid reconstruction, where previous methods failed to capture geometry correctly [S1].
*   **Usage:** Applied to object-centric settings with monocular cameras, including synthetic sequences (e.g., cactus, Lego, T-Rex) and real-world sequences from the Unbiased4D dataset [S1].
