# AnySplat Pipeline

Also called: Feed-forward 3D Gaussian Splatting from Unconstrained Views

## Overview
AnySplat is a feed-forward generalizable reconstruction method that predicts a set of 3D Gaussians directly from uncalibrated input images, eliminating the need for per-scene optimization or known camera poses [S1, unofficial]. It differs from sibling methods like Splatt3R and ZeroGS by employing a specific transformer-based geometry encoder followed by dedicated decoder heads for Gaussian parameters, depth, and poses, which are then processed through a differentiable voxelization module to ensure rendering stability [S1, unofficial].

## How it works
**Inputs and Outputs:**
The method takes $K$ uncalibrated RGB images as input. The input tensor shape is $[1, K, 3, 448, 448]$ (batch, views, channels, height, width) [S1, unofficial]. The output is a set of 3D Gaussians $\mathcal{G}$ and predicted camera poses (intrinsic and extrinsic matrices) [S1, unofficial].

**Data Structures:**
The core data structure is the set of 3D Gaussians, where each Gaussian is defined by:
*   Mean position $\mu \in \mathbb{R}^3$
*   Scale $s \in \mathbb{R}^3$
*   Rotation $r$ (quaternion)
*   Color $c$ (Spherical Harmonics coefficients or RGB)
*   Opacity $\alpha$

These parameters are predicted by the decoder heads. The Gaussians are subsequently voxelized into "pre-voxel 3D Gaussians" using a Differentiable Voxelization module [S1, unofficial].

**Algorithm Steps:**
1.  **Feature Encoding:** Input images are processed by a transformer-based geometry encoder to extract multi-scale features [S1, unofficial].
2.  **Parameter Prediction:** Three decoder heads ($F_G, F_D, F_C$) predict:
    *   $F_G$: Gaussian parameters ($\mu, \sigma, r, s, c$) [S1, unofficial].
    *   $F_D$: Depth map $D$ [S1, unofficial].
    *   $F_C$: Camera poses $p$ [S1, unofficial].
3.  **Gaussian Construction:** The predicted parameters are used to construct pixel-wise 3D Gaussians [S1, unofficial].
4.  **Differentiable Voxelization:** The constructed Gaussians are voxelized into pre-voxel 3D Gaussians using the Differentiable Voxelization module [S1, unofficial].
5.  **Rendering:** Multi-view images and depth maps are rendered from the voxelized Gaussians using differentiable rasterization [S1, unofficial].
6.  **Loss Computation:**
    *   **RGB Loss:** Rendered images are supervised against ground truth RGB images [S1, unofficial].
    *   **Geometry Loss:** Rendered depth maps, decoded depth $D$, and predicted poses $p$ are used to compute geometry losses [S1, unofficial].
7.  **Pseudo-Geometry Supervision:** The geometries are further supervised by pseudo-geometry priors obtained from a pretrained VGGT model [S1, unofficial].

*   **Uncalibrated Inputs:** The method must handle unknown camera poses, relying on the network to predict them [S1, unofficial].
*   **Voxelization Artifacts:** The differentiable voxelization step is critical for stability; improper voxelization may lead to rendering artifacts [S1, unofficial].

## Subtopics

### [SubSplat](13524-subsplat.md)
SubSplat is a method for high-resolution novel-view synthesis that resolves the trade-off between network computational cost and rendering fidelity in pixel-aligned 3D Gaussian Splatting. It solves the problem of insufficient Gaussian density and artifacts when using low-resolution backbone inputs by introducing a Sub-pixel Gaussian Reparameterizer (SPGR). Unlike prior methods limited by fixed grids or image-space upsamplers, SubSplat subdivides each grid-anchored primary Gaussian into multiple fine-grained sub-pixel primitives, restoring structural density directly from low-resolution features while maintaining stable network latency.

### [Deformable Radial Kernel (DRK)](13699-deformable-radial-kernel-drk.md)
Deformable Radial Kernel (DRK) Splatting is a 3D scene representation method that replaces the fixed radial symmetry of Gaussian primitives with a flexible planar kernel defined by multiple radial basis functions. It solves the overparameterization and geometric fidelity limitations of Gaussian Splatting by allowing adaptive stretching, rotation, and sharp boundary control, enabling high-fidelity rendering with significantly fewer primitives. Unlike standard 2D Gaussian Splatting, which relies on smooth, elliptical distributions, DRK supports straight edges and sharp corners through L1/L2 norm blending and piecewise edge sharpening.
