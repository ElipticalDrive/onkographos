# First-order Spherical Harmonics Distillation

Also called: Mobile-GS SH Distillation, SH Knowledge Distillation, SH Order Reduction via Distillation, SH degree reduction, Spherical Harmonics degree reduction

## Overview
First-order Spherical Harmonics (SH) Distillation is a compression technique that reduces the directional appearance complexity of 3D Gaussian primitives by distilling high-order SH coefficients (typically degree 3) into a lower-order representation (typically degree 1) [S2, unofficial]. It solves the problem of excessive storage and computational overhead associated with third-order SH in 3D Gaussian Splatting (3DGS) by training a "student" model with first-order SH to approximate the radiance output of a pretrained "teacher" model with third-order SH [S2, unofficial]. Unlike [Spherical Harmonics Vector Quantization](14181-spherical-harmonics-vector-quantization.md), which reduces precision via codebooks, or [Adaptive SH Regularization](16786-adaptive-sh-regularization.md), which prunes coefficients based on importance, distillation preserves the full first-order basis while transferring knowledge from the higher-order domain [S2, unofficial].

## How it works
The method operates in two phases: teacher model preparation and student model distillation. The teacher model uses the standard 3DGS representation with third-order SH (16 coefficients per color channel, 48 total per Gaussian). The student model is initialized with the same geometric parameters (position, rotation, scale, opacity) but uses first-order SH (4 coefficients per color channel, 12 total per Gaussian) [S2, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   Pretrained teacher model with third-order SH coefficients $\mathbf{C}^{tea}_i$ for each Gaussian $i$.
    *   Training dataset (images and camera poses).
    *   Student model initialized with first-order SH coefficients $\mathbf{C}_i$ (often initialized to zero or copied from the DC term of the teacher).
*   **Outputs:**
    *   Optimized first-order SH coefficients $\mathbf{C}_i$ for the student model.

### Data Structures
The Gaussian primitive data structure is modified to store fewer SH coefficients:
*   **Teacher Gaussian:**
    *   `sh_coeffs`: Array of size $3 \times 16$ (RGB $\times$ 16 coefficients for degrees $l=0,1,2,3$).
*   **Student Gaussian:**
    *   `sh_coeffs`: Array of size $3 \times 4$ (RGB $\times$ 4 coefficients for degrees $l=0,1$).
    *   Other attributes (mean, covariance, opacity) remain identical to the teacher to isolate appearance changes [S2, unofficial].

### Algorithm Steps
1.  **Teacher Rendering:** Render training images using the pretrained teacher model with third-order SH. Compute the rendered pixel color $\mathbf{C}^{tea}_p$ and depth $\hat{\mathbf{D}}^{tea}_p$ for each pixel $p \in P$.
2.  **Student Rendering:** Render the same images using the student model with first-order SH. Compute the rendered pixel color $\mathbf{C}_p$ and depth $\hat{\mathbf{D}}_p$.
3.  **Distillation Loss Calculation:** Compute the color distillation loss and scale-invariant depth distillation loss.
4.  **Optimization:** Update the student's first-order SH coefficients $\mathbf{C}_i$ to minimize the combined loss.

### Formulas
The primary distillation loss is the mean squared error between the teacher's and student's rendered pixel colors [S2, unofficial]:
$$ \mathcal{L}_{\text{distill}} = \frac{1}{|P|} \sum_{p \in P} \|\mathbf{C}_p^{tea} - \mathbf{C}_p\|^2 $$
where $P$ is the set of pixels, $\mathbf{C}_p^{tea}$ is the teacher's rendered color, and $\mathbf{C}_p$ is the student's rendered color.

To stabilize training and handle depth discrepancies, a scale-invariant depth distillation loss is used [S2, unofficial]:
$$ \mathcal{L}_{\text{depth}}(\mathbf{D}, \mathbf{D}^{tea}) = \frac{1}{|P|} \sum_{p \in P} \left( \log(\hat{\mathbf{D}}_p) - \log(\hat{\mathbf{D}}_p^{tea}) \right)^2 - \frac{1}{|P|^2} \left( \sum_{p \in P} \left( \log(\hat{\mathbf{D}}_p) - \log(\hat{\mathbf{D}}_p^{tea}) \right) \right)^2 $$
where $\hat{\mathbf{D}}_p^{tea} = \mathbf{D}^{tea} + \epsilon$ and $\epsilon = 10^{-8}$ for numerical stability. The second term removes the scale bias between teacher and student depths.

The total loss is typically a weighted sum:
$$ \mathcal{L}_{\text{total}} = \lambda_1 \mathcal{L}_{\text{distill}} + \lambda_2 \mathcal{L}_{\text{depth}} + \lambda_3 \mathcal{L}_{\text{photometric}} $$
where $\mathcal{L}_{\text{photometric}}$ is the standard photometric loss between student output and ground truth, if ground truth is also used. Note: [S2, unofficial] emphasizes that strict L1/L2 depth losses are avoided because teacher depth may be unreliable [S2, unofficial].

### Pseudocode
```python
def train_student_distillation(teacher_model, student_model, training_data, epochs):
    """
    Distill third-order SH from teacher to first-order SH student.
    """
    epsilon = 1e-8
    lambda_distill = 1.0
    lambda_depth = 1.0
    lambda_photo = 1.0
    
    # Initialize student SH coefficients (e.g., zero or copy DC term)
    student_model.sh_coeffs = initialize_first_order_sh(teacher_model.sh_coeffs)
    
    optimizer = Adam(student_model.parameters())
    
    for epoch in range(epochs):
        for image, camera in training_data:
            optimizer.zero_grad()
            
            # 1. Render Teacher
            teacher_color, teacher_depth = render_gaussians(teacher_model, camera)
            
            # 2. Render Student
            student_color, student_depth = render_gaussians(student_model, camera)
            
            # 3. Compute Distillation Loss (Color)
            # Note: Source [S2, unofficial] uses L2 norm squared implicitly in the formula description
            # L_dstill = mean(||C_tea - C_stu||^2)
            color_diff = teacher_color - student_color
            l_distill = mean_squared_error(color_diff)
            
            # 4. Compute Depth Distillation Loss (Scale-Invariant)
            # Stabilize teacher depth
            safe_teacher_depth = teacher_depth + epsilon
            safe_student_depth = student_depth + epsilon
            
            log_diff = log(safe_student_depth) - log(safe_teacher_depth)
            
            # Term 1: Mean of squared log differences
            term1 = mean(log_diff ** 2)
            
            # Term 2: Square of mean of log differences
            term2 = mean(log_diff) ** 2
            
            l_depth = term1 - term2
            
            # 5. Compute Photometric Loss (Optional but common for alignment)
            # L_photo = mean(||C_stu - GT||^2)
            gt_color = get_ground_truth(image)
            l_photo = mean_squared_error(student_color - gt_color)
            
            # 6. Total Loss
            total_loss = lambda_distill * l_distill + lambda_depth * l_depth + lambda_photo * l_photo
            
            # 7. Backpropagate
            total_loss.backward()
            optimizer.step()
            
    return student_model
```

### Parameters and Edge Cases
*   **Target Degree:** Typically reduced from 3 to 1 [S2, unofficial]. Reduction to degree 2 is also possible but less aggressive [S1].
*   **Epsilon:** $\epsilon = 10^{-8}$ is used for depth stability [S2, unofficial].
*   **Initialization:** The student's first-order coefficients are often initialized to match the teacher's zeroth-order (DC) term to preserve average color, leveraging the "DC Preservation" principle from [Spherical Harmonics Optimization](14206-spherical-harmonics-optimization.md).
*   **Pitfall:** If the student is not initialized with the DC term, the average color may drift, violating the shared principle of DC preservation [16786-adaptive-sh-regularization.md].
*   **Depth Reliability:** Teacher depth maps from 3DGS can be noisy or inconsistent across views; hence the scale-invariant loss is preferred over direct depth L1/L2 [S2, unofficial].

## Subtopics

### L3GS with Spherical Harmonics Distillation
A variant where splats are organized into layers, but each splat contains both a compact (first-order) and full (third-order) version of the SH representation, while other shared features (opacity, location) remain consistent [S3]. The dimension (compact or full) of the SH is added as a component to the utility function, allowing the scheduler to choose from layered splats with either full or compact SH [S3]. Initially, compact SH versions are loaded to allow more splats within the same bandwidth; over time, compact SH is replaced by full SH to enhance visual quality [S3]. This enables efficient streaming and progressive loading [S3].

## Operating characteristics
*   **Parameter Reduction:** Reducing SH degree from 3 to 1 reduces parameters by 61% (from 48 to 12 coefficients per Gaussian) [S1].
*   **Computation Reduction:** Reduces rendering computation by 52% [S1].
*   **Quality Trade-off:** Results in a PSNR drop of 0.48 dB compared to the original third-order model [S1].
*   **Comparison:** Compared to [Spherical Harmonics Vector Quantization](14181-spherical-harmonics-vector-quantization.md), distillation preserves the continuous nature of SH coefficients but requires a teacher model for training. Compared to [Adaptive SH Regularization](16786-adaptive-sh-regularization.md), it is a global reduction rather than per-Gaussian pruning.
*   **Use Case:** Ideal for mobile and edge devices where storage and bandwidth are constrained, as demonstrated by Mobile-GS [S2, unofficial]. Not recommended for offline high-fidelity rendering where the 0.48 dB PSNR drop is unacceptable.

## Background
First-order Spherical Harmonics Distillation was introduced in the context of Mobile-GS, a framework for real-time Gaussian Splatting on mobile devices [S2, unofficial]. The method addresses the storage burden of third-order SH in 3DGS [S2, unofficial]. It builds on the concept of knowledge distillation in neural networks, applying it to the directional radiance representation of Gaussian primitives. The technique was further integrated into layered rendering systems like L3GS to support progressive detail loading [S3].
