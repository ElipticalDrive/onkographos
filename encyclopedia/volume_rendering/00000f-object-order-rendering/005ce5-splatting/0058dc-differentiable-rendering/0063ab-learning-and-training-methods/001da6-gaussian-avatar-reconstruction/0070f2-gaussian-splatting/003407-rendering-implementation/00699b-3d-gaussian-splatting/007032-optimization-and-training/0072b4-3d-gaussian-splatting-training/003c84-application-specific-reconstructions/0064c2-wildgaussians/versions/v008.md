# WildGaussians

Also called: Splatting in the Wild images with Appearance-conditioned Gaussians

## Overview
WildGaussians extends 3D Gaussian Splatting (3DGS) to handle "in-the-wild" photo collections characterized by unconstrained illumination, transient occluders (e.g., pedestrians, vehicles), and dynamic objects [S2, S4]. It solves the problem of explicit representations struggling with appearance variations and occlusions by integrating robust DINO features for uncertainty-aware masking and a lightweight appearance modeling module [S1, S2]. Unlike NeRF-based methods that use global per-image embeddings to condition a radiance field MLP, WildGaussians embeds appearance vectors directly within each Gaussian, predicting an affine transformation of the base color [S2]. This preserves real-time rendering speeds and allows the trained appearance to be "baked" back into standard 3DGS parameters [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ uncalibrated or calibrated images $\{I_j\}_{j=1}^N$ with known camera poses (extrinsics and intrinsics).
*   **Outputs:** A set of 3D Gaussians $\{G_i\}$ representing the static scene, optimized with appearance and uncertainty modules.

**Data Structures:**
1.  **Gaussian $G_i$:** Defined by mean $\mu_i$, positive semi-definite covariance matrix $\Sigma_i$, opacity $\alpha_i$, and view-dependent color parametrized by spherical harmonics (SH) coefficients [S2].
2.  **Per-Image Embedding $l_I$:** A trainable vector of size $n=24$ for each training image $I$ [S4].
3.  **Hash Grid Encoding:** A hash table encoding Gaussian centers.
    *   Table size $T = 2^{19}$ [S4].
    *   Finest resolution $N_{max} = 2048$ [S4].
    *   Coarsest resolution $N_{min} = 16$ [S4].
    *   Number of levels $L = 12$ [S4].
    *   Output: $emb(x)$, the positional encoding of center $x$ [S4].
4.  **Appearance MLP $F_\theta$:** A multi-layer perceptron taking inputs $(c, emb(x), l_I)$ and outputting parameters for color transformation and opacity variation [S2, S4].
5.  **Uncertainty Predictor:** A trainable affine transformation taking DINO features as input [S2].

**Numbered Steps:**

1.  **Initialization:** Initialize 3D Gaussians $\{G_i\}$ from the input images using standard 3DGS initialization [S2]. Initialize per-image embeddings $l_I$, Hash Grid parameters, and MLP weights $F_\theta$ [S4].

2.  **Projection:** For each Gaussian $G_i$ and camera view, project the 3D covariance $\Sigma_i$ to 2D image space $\Sigma'_i$ [S2]:
    $$ \Sigma'_i = J_W \Sigma_i W^T J_{1:2,1:2}^T $$
    where $W$ is the viewing transformation, $J$ is the Jacobian of the affine approximation of the projection, and $(\cdot)_{1:2,1:2}$ denotes the first two rows and columns [S2].

3.  **Appearance Modeling (Training):**
    a. Retrieve the Gaussian's base color $c$ from SH coefficients [S4].
    b. Retrieve the center embedding $emb(x)$ from the Hash Grid [S4].
    c. Retrieve the image embedding $l_I$ for the current view [S4].
    d. Pass $(c, emb(x), l_I)$ through $F_\theta$ to obtain image-dependent color $c^I$ and opacity variation parameter $\Delta \alpha^I$ [S4]:
    $$ (c^I, \Delta \alpha^I) = F_\theta(c, emb(x), l_I) $$
    *Note: WildGaussians [S2] predicts an affine transformation applied to $c$, while SWAG [S4] predicts $c^I$ directly. Both approaches are cited in the sources for this method family.*

4.  **Opacity Variation Sampling (Transient Handling):**
    a. Sample a random variable $U \sim \text{Uniform}(0,1)$ [S4].
    b. Compute the opacity variation $\Delta \tilde{\alpha}^I$ using the Binary Concrete distribution with temperature $T=0.1$ [S4]:
    $$ \Delta \tilde{\alpha}^I = \text{sigmoid} \left[ \frac{1}{T} \left( \log(|\Delta \alpha^I|) + \log(U) - \log(1-U) \right) \right] $$
    c. Compute the final image-dependent opacity $\alpha^I$:
    $$ \alpha^I = \max(\alpha - \Delta \tilde{\alpha}^I, 0) $$
    *During evaluation, $U$ is fixed at $0.5$ [S4].*

5.  **Rendering:**
    a. Rasterize the 2D Gaussians using alpha-compositing to produce the predicted color $\hat{C}$ [S2].
    b. Extract DINO v2 features from the rendered image $\hat{C}$ and the ground truth image $C$ [S2].

6.  **Uncertainty Modeling:**
    a. Pass DINO features from the ground truth image $C$ through the trainable affine transformation to predict per-pixel uncertainty [S2].
    b. Optimize the uncertainty predictor by minimizing the cosine similarity between DINO features of $\hat{C}$ and $C$ [S2].

7.  **Loss Computation and Optimization:**
    a. Compute the uncertainty mask from the predictor [S2].
    b. Compute the loss $L_{3DGS}$ masked by the uncertainty, combining D-SSIM and L1 terms [S2, S4]:
    $$ L_{3DGS} = \lambda_{dssim} DSSIM(\hat{C}, C) + (1 - \lambda_{dssim}) \|\hat{C} - C\|_1 $$
    where $\lambda_{dssim}$ is a weighting factor [S2].
    c. Optimize Gaussian parameters, $F_\theta$, Hash Encoder, and $l_I$ by minimizing $L_{3DGS}$ [S4].

8.  **Baking (Post-Training):**
    After training, the appearance embeddings and MLP outputs are baked into the standard 3DGS Gaussian parameters (color and opacity) to enable fast, editable rendering without the MLP [S2].

9.  **Transient Separation:**
    Identify transient Gaussians as those with non-zero variance of $\Delta \tilde{\alpha}^I$ across training images: $\text{Var}(\Delta \tilde{\alpha}^I) \neq 0$ [S4]. Discard these Gaussians to retain only the static scene [S4].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class WildGaussiansRenderer:
    def __init__(self, gaussians, hash_grid, appearance_mlp, uncertainty_predictor, n_images):
        """
        gaussians: List of Gaussian objects with attributes mu, sigma, alpha, sh_coeffs
        hash_grid: HashGrid object with method encode(center)
        appearance_mlp: MLP F_theta
        uncertainty_predictor: Linear/Affine layer
        n_images: Number of training images
        """
        self.gaussians = gaussians
        self.hash_grid = hash_grid
        self.appearance_mlp = appearance_mlp
        self.uncertainty_predictor = uncertainty_predictor
        self.image_embeddings = nn.Embedding(n_images, 24) # n=24 [S4]
        self.lambda_dssim = 0.2 # Typical value, not explicitly given in notes [S2]
        self.temperature = 0.1 # T=0.1 [S4]

    def get_gaussian_color(self, gaussian):
        # Retrieve base color c from SH coefficients for the view direction
        # Implementation detail: [G] Standard SH evaluation
        return evaluate_sh(gaussian.sh_coeffs, gaussian.view_direction)

    def sample_concrete(self, location_param, temperature):
        U = torch.rand_like(location_param)
        logit = (torch.log(U) - torch.log(1 - U)) / temperature
        return torch.sigmoid((torch.log(torch.abs(location_param)) + logit))

    def render(self, image_idx, camera_params):
        """
        Renders a single view.
        image_idx: Index of the training image
        camera_params: Extrinsics and Intrinsics
        """
        # 1. Appearance Modeling
        l_I = self.image_embeddings(image_idx) # Per-image embedding [S4]
        
        rendered_colors = []
        rendered_opacities = []
        
        for G in self.gaussians:
            c = self.get_gaussian_color(G)
            emb_x = self.hash_grid.encode(G.mu) # Hash encoding of center [S4]
            
            # MLP outputs color variation and opacity parameter
            # Note: Sources differ on output format. 
            # WildGaussians [S2]: Affine transform params.
            # SWAG [S4]: Direct color c^I and delta_alpha.
            # We implement SWAG variant [S4] as it is more detailed in formulas.
            c_I, delta_alpha_loc = self.appearance_mlp(torch.cat([c, emb_x, l_I], dim=-1))
            
            # Sample opacity variation
            delta_alpha_tilde = self.sample_concrete(delta_alpha_loc, self.temperature)
            
            # Final opacity
            alpha_I = torch.clamp(G.alpha - delta_alpha_tilde, min=0.0)
            
            # Project Gaussian to 2D
            mu_2d, sigma_2d = project_2d(G.mu, G.sigma, camera_params)
            
            rendered_colors.append(c_I)
            rendered_opacities.append(alpha_I)
            
        # 2. Rasterization
        # [G] Standard 3DGS rasterization: sort, compute coverage, alpha composite
        C_hat = rasterize(rendered_colors, rendered_opacities, mu_2d, sigma_2d, camera_params)
        
        return C_hat

    def compute_loss(self, C_hat, C_gt, image_idx):
        """
        C_hat: Rendered image
        C_gt: Ground truth image
        """
        # 1. Uncertainty Modeling
        # Extract DINO features [S2]
        # [G] Assuming a DINO extractor function exists
        feat_gt = extract_dino(C_gt)
        feat_hat = extract_dino(C_hat)
        
        # Predict uncertainty from GT features [S2]
        uncertainty = self.uncertainty_predictor(feat_gt)
        # [G] Convert uncertainty to a mask (e.g., sigmoid)
        mask = torch.sigmoid(uncertainty)
        
        # 2. Loss Calculation
        # DSSIM and L1 masked by uncertainty [S2]
        l1_loss = torch.abs(C_hat - C_gt)
        dssim_loss = compute_dssim(C_hat, C_gt)
        
        # Apply mask: reduce loss contribution from occluders
        masked_l1 = l1_loss * mask
        masked_dssim = dssim_loss * mask
        
        loss = self.lambda_dssim * masked_dssim.mean() + \
               (1 - self.lambda_dssim) * masked_l1.mean()
               
        return loss

    def identify_transient_gaussians(self, training_opacities_var):
        """
        training_opacities_var: Tensor of shape (N_gaussians, N_images) containing 
        delta_alpha_tilde for each Gaussian across all training images.
        """
        variance = torch.var(training_opacities_var, dim=1)
        # Transient if variance != 0 [S4]
        is_transient = variance > 1e-6 # [G] Small epsilon for numerical stability
        return is_transient
```

## Subtopics

### [Dynamic Appearance Features Modeling](3776-dynamic-appearance-features-modeling.md)
Addresses the limitation of global feature embeddings by extracting dynamic appearance features from a reference image and allowing each Gaussian to sample from multiple feature maps, capturing local details like highlights and shadows. It sets itself apart from methods like NeRF-W and Ha-NeRF which use global scene embeddings, and CR-NeRF which integrates features at the 2D level.

## Operating characteristics
**Time and Memory Complexity:**
*   **Training:** SWAG achieves one order of magnitude faster training compared to previous implicit methods (NeRF-W, Ha-NeRF, CR-NeRF, RefinedFields) [S4].
*   **Rendering:** Matches real-time rendering speeds of standard 3DGS after baking [S2, S4]. During training, the MLP evaluation adds overhead but remains efficient due to the lightweight nature of the appearance module [S2].

**Measured Performance:**
*   **Phototourism:** SWAG improves 3DGS PSNR by an average margin of 5.01 dB [S4].
*   **NeRF-OSR:** SWAG improves 3DGS PSNR by an average margin of 5 dB [S4].
*   **Transient Handling:** On the Trevi Fountain scene, transient objects were represented using less than 20% of the Gaussians [S4]. On the Locomotive scene (static), less than 4% of Gaussians were detected as transient [S4].

**Strengths and Limitations:**
*   **Strengths:** Handles unconstrained photo collections with varying illumination and occlusions [S1, S4]. Preserves real-time rendering speed [S2]. Allows separation of static and transient elements [S4].
*   **Limitations:** Failure cases include over-construction of static parts, observed as black spots on roads (Brandenburg Gate) and fountain water (Trevi Fountain) [S2, S4]. Incorrect training signals can lead to irreversibly removing geometry due to 3DGS's pruning process [S2].

**When to Use:**
*   Use for 3D reconstruction from in-the-wild photo collections where occlusions and appearance changes are present [S2, S4].
*   Use when real-time rendering speed is required after training [S2].
*   Do not use if the scene is strictly static and well-controlled, as standard 3DGS may suffice and SWAG adds complexity [S4].

## Background
WildGaussians was introduced to address the challenges of 3D reconstruction in "in-the-wild" settings, where images contain occlusions, transient objects, and varying illumination [S2, S4]. Traditional 3DGS struggles with these conditions due to its explicit representation and lack of shared parameters, unlike NeRFs which use per-image embeddings [S2]. The method integrates robust DINO features for uncertainty modeling and a lightweight appearance module [S1, S2]. It is evaluated on datasets such as Phototourism (Brandenburg Gate, Sacre Coeur, Trevi Fountain) and NeRF-OSR [S4].
