# Adaptive SH Regularization

Also called: Directional support-aware SH regularization

## Overview
Adaptive SH Regularization is a technique for stabilizing the optimization of Spherical Harmonics (SH) coefficients in 3D Gaussian Splatting under sparse or uneven camera observations. It prevents overfitting by suppressing higher-order SH components for vertices that lack sufficient directional support, while preserving the zeroth-order (DC) component. Unlike methods that rely on iterative optimization with fixed SH complexity, this approach explicitly adapts the regularization strength to the available viewing directions, improving generalization to unseen viewpoints and conditioning of the linear system.

## How it works
**Inputs and Outputs**
*   **Input:** Per-vertex SH coefficients $\mathbf{c}_i$ (stored as in [Scene Representation and Geometry Constraints](15421-scene-representation-and-geometry-constraints.md)), the set of observed viewing directions $\{\omega_k\}$ for vertex $i$, and a support threshold parameter.
*   **Output:** Regularized SH coefficients $\mathbf{c}_i'$ suitable for rendering and further optimization.

**Data Structures**
The method operates on the standard SH coefficient vector for each Gaussian. For degree $L$, the vector has size $(L+1)^2$. The coefficients are typically stored in a flat array or tensor, indexed by band $l$ and order $m$.

**Steps**
1.  **Evaluate Directional Support:** For each vertex $i$, determine the set of viewing directions $\{\omega_k\}$ from which it is observed in the training data.
2.  **Check Support Criterion:** For each SH band $l$ (where $l=0$ is DC, $l>0$ are higher-order), evaluate whether the available viewing directions provide sufficient constraints. The criterion is defined by equation (25) in [S1, unofficial]. While the exact mathematical form of (25) is not fully detailed in the provided text, it implicitly determines if the band is "well-supported" or "weakly supported" based on the geometry of the viewing cone.
3.  **Compute Regularization Weights:** Assign a regularization weight $\lambda_{i,l}$ to each band $l$ of vertex $i$:
    *   If band $l$ satisfies the support criterion (well-supported), apply weak regularization (small $\lambda_{i,l}$).
    *   If band $l$ does not satisfy the criterion (weakly supported), apply strong suppression (large $\lambda_{i,l}$).
    *   The DC component ($l=0$) is always preserved (weak regularization) regardless of support, as it represents average color.
4.  **Apply Regularization in LLS:** When solving the Least Squares System (LLS) for SH coefficients (as in [CF-Splat](12021-cf-splat-closed-form-triangle-splatting-with-mesh-priors.md)), incorporate these weights into the diagonal of the regularization matrix. This modifies the normal equations to penalize large coefficients in weakly supported bands more heavily.

**Formulas**
The regularization term added to the loss or LLS system for vertex $i$ is:
$$ \mathcal{L}_{reg} = \sum_{l=0}^{L} \lambda_{i,l} \sum_{m=-l}^{l} |c_{i,l,m}|^2 $$
Where:
*   $c_{i,l,m}$ is the SH coefficient for vertex $i$, band $l$, order $m$.
*   $\lambda_{i,l}$ is the adaptive weight for band $l$.
*   The support criterion (Eq. 25 in [S1, unofficial]) determines $\lambda_{i,l}$. Specifically, as more views are added, more bands satisfy the criterion, leading to weaker regularization for those bands (Eq. 26 in [S1, unofficial]).

**Parameters**
*   **Support Threshold:** Implicitly defined in equation (25). It controls the transition between weak and strong regularization. Not given in the sources as a specific numerical value, but described as determining whether an SH band receives weak or strong regularization based on available viewing directions.
*   **Regularization Strength Ratio:** The ratio between strong and weak $\lambda$. Not given in the sources.

**Edge Cases and Pitfalls**
*   **Overfitting:** Without regularization, unconstrained SH coefficients lacking sufficient directional constraints overfit input views and generalize poorly to unseen viewpoints, producing noisy colors [S1, unofficial].
*   **Convergence:** Unregularized systems may fail to converge within a reasonable iteration count (e.g., $T_{max}=300$) due to poor conditioning [S1, unofficial].
*   **Degenerate Input:** If a vertex is observed from only one direction, all non-DC bands are weakly supported and will be strongly suppressed, leaving only the DC color.

**Pseudocode**
```python
def adaptive_sh_regularization(sh_coeffs, viewing_directions, support_threshold):
    """
    sh_coeffs: Tensor of shape (N, (L+1)^2), N vertices, SH coefficients flattened.
    viewing_directions: List of arrays, viewing_directions[i] contains directions for vertex i.
    support_threshold: Scalar threshold for the support criterion (Eq. 25 in [S1, unofficial]).
    
    Returns:
    regularized_coeffs: Tensor of shape (N, (L+1)^2)
    """
    N, num_coeffs = sh_coeffs.shape
    L = int((num_coeffs)**0.5) - 1
    regularized_coeffs = sh_coeffs.clone()
    
    # Precompute regularization weights
    reg_weights = torch.zeros(N, num_coeffs)
    
    for i in range(N):
        directions = viewing_directions[i]
        if len(directions) == 0:
            # No views, suppress all except DC
            reg_weights[i, 0] = 0.0 # Preserve DC
            reg_weights[i, 1:] = 1e6 # Strong suppression
            continue
            
        # Evaluate support for each band l
        for l in range(L + 1):
            # Determine if band l is supported by directions
            # This corresponds to Eq. 25 in [S1, unofficial]
            # The exact formula is not provided, but it depends on the spread of directions
            is_supported = check_directional_support(directions, l, support_threshold)
            
            # Assign weights
            if l == 0:
                # DC component always preserved
                reg_weights[i, l] = 1e-6 # Weak regularization
            elif is_supported:
                # Well-supported band
                reg_weights[i, l] = 1e-6 # Weak regularization
            else:
                # Weakly supported band
                reg_weights[i, l] = 1.0 # Strong suppression (relative to weak)
                
    # Apply regularization during LLS solve
    # In the LLS system Ax = b, the regularized system is (A^T A + Lambda) x = A^T b
    # Lambda is a diagonal matrix with reg_weights
    return regularized_coeffs, reg_weights
```

## Operating characteristics
*   **Time Complexity:** The regularization step adds minimal overhead to the LLS solving process. The global LLS solution remains efficient, with solving time growing with the number of observations, consistent with the complexity of the LLS solver [S1, unofficial].
*   **Memory Complexity:** No additional memory is required beyond the SH coefficients and viewing direction metadata.
*   **Measured Performance:** On the C3VD scene with $K=7$ views and $L=3$, adaptive regularization improves test-view PSNR from 33.66 to 34.69 compared to baselines [S1, unofficial].
*   **Convergence:** With regularization, the PCG residual decreases rapidly. Without it, the system fails to converge within $T_{max}=300$ iterations, demonstrating improved conditioning [S1, unofficial].
*   **Strengths:** Improves generalization to unseen viewpoints, stabilizes optimization under sparse views, and reduces noisy colors.
*   **Limitations:** Requires knowledge of viewing directions for each vertex. Performance may vary with the choice of support threshold.
*   **When to Use:** Use when training data is sparse or unevenly distributed, and when standard SH optimization leads to overfitting or convergence issues.
*   **When Not to Use:** Use with caution when views are dense and uniformly distributed, as the regularization may unnecessarily suppress valid high-frequency details.

## Background
Adaptive SH Regularization was introduced in the context of CF-Splat (Closed-Form Triangle Splatting with Mesh Priors) to address the challenges of appearance estimation under sparse and uneven observations. It builds on the standard 3D Gaussian Splatting representation but modifies the SH optimization process to be aware of directional support. The method is part of a broader effort to improve the robustness and fidelity of differentiable rendering methods in challenging acquisition scenarios.
