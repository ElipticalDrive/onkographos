# 3D Half-Gaussian Splatting Covariance Transformation and Regularization

Also called: 3D-HGS

## Overview
3D Half-Gaussian Splatting (3D-HGS) transforms standard volumetric 3D Gaussians into half-ellipsoids to better model sharp surface boundaries and reduce volumetric artifacts [S1]. It achieves this by projecting the Gaussian covariance onto a plane defined by the surface normal, effectively discarding the volume behind the surface [S1]. This method consistently outperforms original 3D Gaussian Splatting (3DGS) in PSNR and rendering efficiency across standard datasets [S1].

## How it works
**Inputs:**
*   $\Sigma$: The $3 \times 3$ covariance matrix of a 3D Gaussian primitive.
*   $n$: The estimated surface normal vector at the Gaussian's center.

**Outputs:**
*   $\sigma$: The regularized $3 \times 3$ covariance matrix for the half-Gaussian.

**Data Structures:**
*   Vectors $v_1, v_2, n$ are 3D column vectors.
*   Matrices are $3 \times 3$.
*   Basis matrix $B$ is formed by concatenating vectors as columns: $B = [v_1, v_2, n]$.

**Algorithm:**

1.  **Normalize Normal:**
    $$n \leftarrow n / \|n\|$$

2.  **Construct Basis Vectors:**
    If $n_x = 0$ and $n_y = 0$:
    $$v_1 \leftarrow (1, 0, 0)$$
    $$v_2 \leftarrow (0, 1, 0)$$
    Else:
    $$v_1 \leftarrow (n_y, -n_x, 0) / \|(n_y, -n_x, 0)\|$$
    $$v_2 \leftarrow (n \times v_1) / \|n \times v_1\|$$

3.  **Form Basis Matrix:**
    $$B \leftarrow \text{concatenate}(v_1, v_2, n)$$
    *(Note: $v_1, v_2, n$ are columns of $B$)*

4.  **Transform Covariance to Basis Space:**
    $$cov \leftarrow B^T \cdot \Sigma \cdot B$$

5.  **Compute Modified Diagonal and Off-Diagonal Elements:**
    $$a' \leftarrow cov[0, 0] - \frac{cov[0, 2]^2}{cov[2, 2]}$$
    $$b' \leftarrow cov[0, 1] - \frac{cov[0, 2] \cdot cov[1, 2]}{cov[2, 2]}$$
    $$c' \leftarrow cov[1, 1] - \frac{cov[1, 2]^2}{cov[2, 2]}$$

6.  **Construct Regularized Covariance in Basis Space:**
    $$\sigma_{basis} = \begin{bmatrix} a' & b' & 0 \\ b' & c' & 0 \\ 0 & 0 & \min(a', c') / 100 \end{bmatrix}$$

7.  **Transform Back to World Space:**
    $$\sigma \leftarrow B \cdot \sigma_{basis} \cdot B^T$$

**Parameters:**
*   **Regularization Frequency:** The transformation is performed every 5000 iterations [S1].
*   **Opacity Threshold:** Increased to 0.01 for densification and pruning to eliminate dust and noise [S1].
*   **Half-Gaussian Opacity:** Reset to 0.02 [S1].

**Pseudocode:**

```python
import numpy as np

def transform_covariance_to_half_gaussian(cov_matrix: np.ndarray, normal: np.ndarray) -> np.ndarray:
    """
    Transforms a 3D Gaussian covariance matrix into a half-Gaussian covariance
    based on a surface normal.
    
    Args:
        cov_matrix: 3x3 covariance matrix Sigma.
        normal: 3D surface normal vector n.
        
    Returns:
        Regularized 3x3 covariance matrix sigma.
    """
    # 1. Normalize normal
    n = normal / np.linalg.norm(normal)
    
    # 2. Construct basis vectors
    if n[0] == 0 and n[1] == 0:
        v1 = np.array([1.0, 0.0, 0.0])
        v2 = np.array([0.0, 1.0, 0.0])
    else:
        # v1 perpendicular to n in the xy-plane projection
        v1_raw = np.array([n[1], -n[0], 0.0])
        v1 = v1_raw / np.linalg.norm(v1_raw)
        
        # v2 perpendicular to both n and v1
        v2_raw = np.cross(n, v1)
        v2 = v2_raw / np.linalg.norm(v2_raw)
        
    # 3. Form Basis Matrix B = [v1, v2, n]
    B = np.column_stack((v1, v2, n))
    
    # 4. Transform covariance to basis space
    cov_basis = B.T @ cov_matrix @ B
    
    # 5. Compute modified elements
    # Ensure cov[2,2] is not zero to avoid division by zero
    cov_22 = cov_basis[2, 2]
    if cov_22 == 0:
        cov_22 = 1e-8 # [G] Guard against degenerate case
        
    a_prime = cov_basis[0, 0] - (cov_basis[0, 2] ** 2) / cov_22
    b_prime = cov_basis[0, 1] - (cov_basis[0, 2] * cov_basis[1, 2]) / cov_22
    c_prime = cov_basis[1, 1] - (cov_basis[1, 2] ** 2) / cov_22
    
    # 6. Construct regularized covariance in basis space
    sigma_basis = np.zeros((3, 3))
    sigma_basis[0, 0] = a_prime
    sigma_basis[0, 1] = b_prime
    sigma_basis[1, 0] = b_prime
    sigma_basis[1, 1] = c_prime
    sigma_basis[2, 2] = min(a_prime, c_prime) / 100.0
    
    # 7. Transform back to world space
    sigma = B @ sigma_basis @ B.T
    
    return sigma
```

## Operating characteristics
*   **Performance:** On the Mip-NeRF 360 dataset, 3D-HGS with an efficient rasterizer achieves 125 FPS and 29.66 PSNR using 3.8M kernels, compared to 3DGS which uses 3.2M kernels [S1]. On the Tank & Dengin dataset, it achieves 160 FPS and 24.45 PSNR using 1.8M kernels [S1]. On the Tank & Blending dataset, it achieves 126 FPS and 29.76 PSNR using 2.6M kernels [S1].
*   **Quality:** 3D-HGS consistently outperforms original 3DGS across all metrics (PSNR, etc.) on evaluated datasets [S1].
*   **Efficiency:** The method includes an efficient rasterizer that significantly improves rendering speed [S1].
*   **Limitations:** The method relies on accurate surface normal estimation for the transformation to align correctly with scene geometry [S1].

## Background
3D Half-Gaussian Splatting (3D-HGS) was introduced to address the limitations of standard 3D Gaussian Splatting in modeling sharp surface boundaries. By converting volumetric Gaussians into half-ellipsoids, it reduces volumetric artifacts and improves reconstruction quality [S1]. The method was evaluated against Scaffold, mip-splatting, and MCMC architectures [S1].
