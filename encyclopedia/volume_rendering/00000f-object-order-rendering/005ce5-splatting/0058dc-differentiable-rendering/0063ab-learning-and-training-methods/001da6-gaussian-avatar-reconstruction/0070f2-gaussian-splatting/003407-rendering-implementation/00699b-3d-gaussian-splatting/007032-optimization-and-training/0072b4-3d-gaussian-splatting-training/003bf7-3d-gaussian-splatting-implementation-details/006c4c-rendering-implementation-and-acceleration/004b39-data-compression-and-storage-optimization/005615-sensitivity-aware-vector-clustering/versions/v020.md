# Sensitivity-Aware Vector Clustering

Also called: Niedemayr et al. compression, Niedermayr, Sensitivity-Aware Scene Compression, Sensitivity-Aware Vector Clustering for 3DGS Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering spherical harmonic (SH) coefficients and Gaussian shape parameters (scale and rotation) into compact codebooks using sensitivity-aware vector quantization [S1, S2]. It distinguishes itself from standard post-training quantization by deriving a sensitivity measure for each parameter to guide the clustering process, prioritizing the preservation of parameters that significantly affect image quality [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of optimized 3D Gaussians $\{G_i\}_{i=1}^N$ with positions, opacities, scales, rotations, and SH coefficients for color. A set of training images with known camera parameters.
*   **Output:** Two codebooks (one for color/SH, one for shape/scale-rotation), a list of indices mapping each Gaussian to its codebook entries, and the remaining uncompressed parameters (position, opacity, and high-sensitivity SH coefficients).

**Data Structures:**
1.  **Codebook (Color):** Array of size $K$. Each entry is a vector of SH coefficients (e.g., 48 floats for degree 3).
2.  **Codebook (Shape):** Array of size $K$. Each entry represents a normalized covariance matrix, decomposed into 4 scalar values for a quaternion (rotation) and 3 scalar values for scaling [S1].
3.  **Gaussian Index:** For each Gaussian, two 32-bit unsigned integers storing indices into the Color and Shape codebooks [S1].
4.  **High-Sensitivity List:** A list of Gaussians whose SH coefficients exceed the sensitivity threshold $\beta_c$, stored with their original full-precision coefficients [S1].

**Parameters:**
*   $K$: Codebook size. Typical value: 4096 [S1].
*   $\beta_c$: Sensitivity threshold for SH coefficients. Gaussians with sensitivity $> \beta_c$ are excluded from clustering. Typical value: $6 \times 10^{-7}$ [S1].
*   $\beta_g$: Sensitivity threshold for Gaussian shape parameters. Typical value: $3 \times 10^{-6}$ [S1].
*   $\lambda_d$: Decay factor for moving average in batched clustering. Typical value: 0.8 [S1].
*   Batch size (Color): $2^{18}$ [S1].
*   Batch size (Shape): $2^{20}$ [S1].
*   Optimization steps: 5000 steps for quantization-aware fine-tuning [S1].

**Sensitivity Calculation:**
The sensitivity $S(p)$ of a parameter $p$ is calculated to measure its contribution to the training images [S1, S2].
1.  Compute the total image energy $E$, defined as the sum of RGB components over all pixels in all training images [S1].
2.  Compute the gradient of $E$ with respect to parameter $p$ using a single backward pass over the training images [S1].
3.  The sensitivity for a single parameter $p$ is:
    $$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p_i}}{\sum_{i=1}^{N} P_i} $$
    where $N$ is the number of training images, $P_i$ is the number of pixels in image $i$, and $E_i$ is the energy contribution of image $i$ [S1, S2].
4.  For a vector $x$ (e.g., a set of SH coefficients or a shape vector), the sensitivity is the maximum sensitivity over its components $d$:
    $$ S(x) = \max_d S(x_d) $$
    where $S(x_d)$ is the sensitivity of component $d$ [S1].

**Clustering Algorithm (Sensitivity-Aware k-Means):**
1.  **Initialization:** Initialize codebook centroids randomly with a uniform distribution within the minimum and maximum values of each parameter [S1].
2.  **Assignment:** For each vector $x$ in the batch, calculate the weighted distance to each centroid $c_k$:
    $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
    Assign $x$ to the centroid $c_k$ with the minimum distance [S1].
3.  **Update:** Update the centroid $c_k$ using the weighted average of assigned vectors $A(k)$:
    $$ c_k = \frac{1}{\sum_{x_i \in A(k)} S(x_i)} \sum_{x_i \in A(k)} S(x_i) x_i $$
    [S1].
4.  **Batched Strategy:** To handle large datasets, use a batched clustering strategy. Pick a random subset of vectors (batch size $2^{18}$ for color, $2^{20}$ for shape), compute the update step, and update centroids using a moving average with decay factor $\lambda_d$ [S1].
5.  **Renormalization:** For shape parameters, clustering normalized covariance matrices can lead to floating-point errors resulting in non-unit scaling vectors. After each update step, re-normalize each codebook vector by dividing it through the trace of the covariance metric [S1].
6.  **Decomposition:** After clustering, decompose each codebook entry (covariance matrix) into rotation (quaternion) and scale parameters using eigenvalue decomposition for quantization-aware training [S1].

**Handling High-Sensitivity Parameters:**
1.  Calculate sensitivity for all SH coefficients and shape parameters [S1].
2.  Identify SH vectors with sensitivity higher than $\beta_c$ and shape vectors with sensitivity higher than $\beta_g$ [S1].
3.  These high-sensitivity vectors are not clustered but are added directly to their respective codebooks [S1].
4.  The remaining vectors are clustered using the sensitivity-aware k-Means algorithm described above [S1].

**Quantization-Aware Fine-Tuning:**
1.  Initialize the scene parameters with the clustered indices and codebooks [S2].
2.  Perform optimization on the training set using quantization-aware training with Min-Max Quantization [S2].
3.  **Forward Pass:** Simulate quantization considering a certain number of bits and the moving average of each parameter's min/max values [S2].
4.  **Backward Pass:** Ignore simulated quantization and calculate the gradient for the parameter without quantization [S2].
5.  Optimize position, opacity, scaling, color, and codebook entries [S2].

**Compression:**
1.  Order the Gaussians by their positions along a Z-order curve (Morton order) to leverage spatial coherence [S1, S2].
2.  Compress the set of Gaussians (indices and remaining parameters) and codebooks using DEFLATE (LZ77 + Huffman coding) [S1, S2].

import numpy as np

def calculate_sensitivity(gradient, pixels_per_image, num_images):
    """
    Calculate sensitivity S(p) for a parameter p.
    gradient: Gradient of total image energy E w.r.t p.
    pixels_per_image: Array of pixel counts for each training image.
    num_images: Total number of training images.
    """
    # Sum of gradients weighted by pixel counts? 
    # Note: Formula in [S1] is sum(dE/dp) / sum(Pi). 
    # The gradient dE/dp is already aggregated over all images in a single backward pass.
    # Pi is the normalization factor.
    total_pixels = np.sum(pixels_per_image)
    sensitivity = np.sum(gradient) / total_pixels
    return sensitivity

def sensitivity_aware_kmeans(vectors, sensitivities, centroids, decay_factor, batch_size):
    """
    Perform one step of sensitivity-aware k-Means clustering.
    vectors: Array of shape (N, D) containing the vectors to cluster.
    sensitivities: Array of shape (N,) containing sensitivity S(x) for each vector.
    centroids: Array of shape (K, D) containing current codebook entries.
    decay_factor: Lambda_d for moving average update.
    batch_size: Number of vectors to process in this step.
    """
    # Select random subset
    indices = np.random.choice(len(vectors), size=batch_size, replace=False)
    batch_vectors = vectors[indices]
    batch_sensitivities = sensitivities[indices]
    
    # Calculate weighted distances
    # D(x, ck) = S(x) * ||x - ck||^2
    # Expand ||x - ck||^2 = ||x||^2 + ||ck||^2 - 2*x.ck
    # However, direct computation is clearer for implementation
    
    distances = np.zeros((batch_size, len(centroids)))
    for k in range(len(centroids)):
        diff = batch_vectors - centroids[k]
        sq_dist = np.sum(diff**2, axis=1)
        distances[:, k] = batch_sensitivities * sq_dist
        
    # Assign to nearest centroid
    assignments = np.argmin(distances, axis=1)
    
    # Update centroids using moving average
    new_centroids = centroids.copy()
    for k in range(len(centroids)):
        mask = assignments == k
        assigned_vectors = batch_vectors[mask]
        assigned_sensitivities = batch_sensitivities[mask]
        
        if len(assigned_vectors) > 0:
            # Weighted average
            total_weight = np.sum(assigned_sensitivities)
            weighted_sum = np.sum(assigned_vectors * assigned_sensitivities[:, np.newaxis], axis=0)
            new_centroid = weighted_sum / total_weight
            
            # Renormalization for shape parameters (if applicable)
            # Assuming new_centroid is a covariance matrix or needs trace normalization
            # For general vector, this step might not apply, but for shape it does.
            # Here we assume generic vector update.
            
            # Moving average update
            new_centroids[k] = decay_factor * new_centroids[k] + (1 - decay_factor) * new_centroid
            
    return new_centroids

    # 4. Sensitivity-Aware Clustering
    # Batched k-Means
    for step in range(800): # Steps for Gaussians
        codebook_shape = sensitivity_aware_kmeans(

## Operating characteristics
*   **Compression Ratio:** Achieves up to 31× compression on real-world scenes with minimal visual degradation [S1].
*   **Rendering Speed:** Enables real-time rendering on lightweight GPUs, up to 4× higher framerates than optimized GPU compute pipelines [S1].
*   **Memory:** Significantly reduces memory consumption, suitable for network streaming and low-power devices [S1].
*   **Strengths:** Preserves visual quality by prioritizing high-sensitivity parameters; efficient hardware rasterization support [S1].
*   **Limitations:** Requires a backward pass for sensitivity calculation; clustering is iterative and may require tuning of batch sizes and decay factors [S1].
*   **When to use:** When storage and bandwidth are constrained, and real-time rendering on limited hardware is required [S1].
*   **When not to use:** When maximum possible visual fidelity is required without any compression artifacts, or when scene parameters are not highly redundant [S1].

## Background
*   **Origin:** Proposed by Niedemayr et al. in 2024 [S1].
*   **History:** Developed to address the high memory consumption of 3D Gaussian Splatting, inspired by volumetric radiance field compression and deep network weight quantization [S1].
*   **Usage:** Used for compressed 3D Gaussian splatting representations to enable accelerated novel view synthesis on a variety of devices, including web browsers via WebGPU [S1].
