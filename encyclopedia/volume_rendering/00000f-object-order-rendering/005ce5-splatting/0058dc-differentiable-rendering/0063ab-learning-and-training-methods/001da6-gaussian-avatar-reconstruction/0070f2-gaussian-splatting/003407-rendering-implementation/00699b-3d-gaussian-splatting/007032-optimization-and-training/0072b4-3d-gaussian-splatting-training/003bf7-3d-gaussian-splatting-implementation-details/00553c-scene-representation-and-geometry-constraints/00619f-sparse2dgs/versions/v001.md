# Sparse2DGS

Also called: Geometry-Prioritized Gaussian Splatting for Surface Reconstruction from Sparse Views

## Overview
Sparse2DGS is a Gaussian Splatting method for surface reconstruction using sparse input views, initialized with MVS points and enhanced with geometric-prioritized schemes to prevent appearance overfitting and improve geometric learning under ill-posed conditions [S1]. It sets itself apart from standard 2DGS by fixing feature and color values during optimization to provide geometrically expressive supervision, and by using selective updates with rendered geometric cues instead of standard densification [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ sparse input views $\{I_i\}_{i=1}^N$, where $I_i \in \mathbb{R}^{H \times W \times 3}$ [S1].
*   **Outputs:** A reconstructed 3D surface represented by optimized 2D Gaussian primitives [S1].

**Data Structures:**
Each 2D Gaussian primitive is defined by:
*   Central position $p$ [S1].
*   Two principal tangential vectors $t_u$ and $t_v$ [S1].
*   Scaling vector $(s_u, s_v)$ [S1].
*   Rotation matrix $R = (t_u, t_v, t_z)$, where $t_z = t_u \times t_v$ [S1].
*   Scale matrix $S = \text{diag}(s_u, s_v, 0)$ [S1].

The primitive is defined in a local tangent plane in world space, parameterized as:
$$ P(u, v) = p + s_u t_u u + s_v t_v v \quad (1) $$
For a point $u = (u, v)$ in $uv$ space, the 2D Gaussian value is evaluated by:
$$ G(u) = \exp\left(-\frac{u^2 + v^2}{2}\right) \quad (2) $$
[S1]

**Steps:**
1.  **MVS Initialization:** Use an unsupervised MVS network (e.g., CLMVSNet [S1]) to estimate dense depth maps $\{D_i\}_{i=1}^N$ for the input views [S1]. Back-project these depth maps and fuse them into a point cloud $\{p_{ij} \mid 1 \le i \le N, 1 \le j \le HW\}$ to initialize the positions of the Gaussian primitives [S1].
2.  **Feature Splatting:** Sample MVS-derived feature maps into feature splatting. Keep feature values and RGB color values fixed during optimization to provide geometrically expressive supervision and prevent appearance overfitting [S1].
3.  **Regularization:** Regularize Gaussian primitive properties (position, orientation, scale) using a reparameterization-based disk sampling strategy. This reformulates these properties into point representations for unified optimization with point-based cross-view consistency loss [S1].
4.  **Selective Update:** Update Gaussian primitives selectively using rendered geometric cues instead of standard densification. This allows for self-guided geometric corrections under ill-posed conditions [S1].

**Pseudocode:**
```python
def sparse2dgs(input_images, num_views):
    # Step 1: MVS Initialization
    # Estimate dense depth maps using unsupervised MVS (e.g., CLMVSNet)
    depth_maps = mvs_network(input_images)
    
    # Back-project and fuse depth maps into a point cloud
    # i: image index, j: pixel index
    point_cloud = []
    for i in range(num_views):
        for j in range(H * W):
            p_ij = back_project(depth_maps[i], j)
            point_cloud.append(p_ij)
            
    # Initialize 2D Gaussian primitives with the point cloud
    # Each primitive has position p, tangents tu, tv, scales su, sv
    gaussians = initialize_gaussians(point_cloud)
    
    # Step 2: Geometrically Enhanced Supervision
    # Sample MVS-derived feature maps
    # Keep feature values and RGB color values fixed
    fixed_features = sample_mvs_features(input_images)
    fixed_colors = get_rgb_from_features(fixed_features)
    
    # Step 3: Regularization via Disk Sampling
    # Reformulate Gaussian properties into point representations
    # Optimize using point-based cross-view consistency loss
    for iteration in range(max_iterations):
        # Render current gaussians
        rendered_image = render_gaussians(gaussians, camera)
        
        # Calculate geometric loss based on rendered cues
        # and cross-view consistency
        loss = geometric_loss(rendered_image, fixed_features) + \
               cross_view_consistency_loss(gaussians)
        
        # Update gaussians using gradients
        gaussians = optimize(gaussians, loss)
        
    # Step 4: Selective Update
    # Instead of densification, selectively update primitives
    # using rendered geometric cues for self-guided correction
    gaussians = selective_update(gaussians, rendered_image)
    
    return gaussians
```

**Parameters:**
*   $N$: The number of sparse input views [S1].
*   $H, W$: Height and width of the input images $I_i$ [S1].
*   $D_i$: Dense depth maps estimated by the MVS network for each input view $i$ [S1].

**Edge Cases and Pitfalls:**
*   **Ill-posed Conditions:** Sparse views lead to ill-posed geometric optimization. Standard densification can fail; selective updates are required [S1].
*   **Appearance Overfitting:** Coupling color and geometry optimization leads to severe degradation under sparse views as color overfits. Fixing features and colors prevents this [S1].

## Operating characteristics
*   **Performance:** Achieves 1.13 Chamfer Distance (CD) error on the DTU dataset with 3 views, compared to 2.81 for 2DGS, 2.82 for GOF, and 2.08 for PGSR [S1].
*   **Efficiency:** Training time is 10 minutes, which is 2x faster than the NeRF-based fine-tuning approach SparseNeus (25 minutes) [S1].
*   **Strengths:** Complete and accurate reconstruction from sparse images; robust geometric learning under ill-posed conditions [S1].
*   **Limitations:** Relies on the quality of the MVS initialization (e.g., CLMVSNet) [S1].

## Background
Sparse2DGS was proposed to address the limitations of previous methods that rely on dense views for 3D surface reconstruction. It boosts the strengths of Gaussian Splatting and Multi-view Stereo (MVS) by incorporating geometric-prioritized enhancement schemes [S1]. The method was introduced in the paper "Sparse2DGS: Geometry-Prioritized Gaussian Splatting for Surface Reconstruction from Sparse Views" [S1].
