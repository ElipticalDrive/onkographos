# Smoothed 2D Supervision

Also called: Adaptive Gaussian blur strategy, Progressive Gaussian Blurring

## Overview
Smoothed 2D Supervision is a regularization technique that enhances the robustness of joint optimization in differentiable rendering by smoothing the 2D supervision signal [S1][S2, unofficial]. It solves the problem of noisy gradients and unstable camera alignment during training by blurring training images with a scheduled set of 2D Gaussian kernels [S2, unofficial]. Unlike frequency regularization methods that operate in the Fourier domain [6130-frequency-regularization.md] or covariance transformations that modify primitive shapes [9150-3d-half-gaussian-splatting-covariance-transformation-and-reg.md], this method operates directly on the image plane supervision targets [S2, unofficial]. It stabilizes optimization by restricting the spectrum of the learned 3D scene and producing smoother image gradients [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Raw 2D training images $I_{raw}$, current iteration count $t$, and hyperparameters defining the blur schedule (initial kernel size, initial standard deviation $\sigma_0$, decay interval $k_b$, and end iteration $t_{end}$) [S2, unofficial][S4].
*   **Output:** Smoothed supervision images $I_{smooth}$ used for computing the rendering loss [S2, unofficial].

**Data Structures:**
*   **Blur Kernel:** A 2D Gaussian kernel $K$ defined by its standard deviation $\sigma$ and spatial extent (kernel size). The kernel is separable, allowing efficient convolution [S1].
*   **Schedule State:** Variables tracking the current $\sigma$ and kernel dimensions, updated every $k_b$ iterations [S4].

**Steps:**
1.  **Initialize Schedule:** Set the initial standard deviation $\sigma = \sigma_0$ and initial kernel size $S_{init}$ (e.g., $9 \times 9$) [S4].
2.  **Iterative Update:** For each training iteration $t$:
    a.  **Check Decay:** If $t > 0$ and $t \pmod{k_b} == 0$ and $t < t_{end}$, reduce the blur intensity [S4].
    b.  **Update Parameters:** Decrease $\sigma$ and/or the kernel size. The schedule is designed to progressively reduce the standard variance to construct adaptive blurred image supervision [S3]. In specific implementations, $\sigma$ is exponentially reduced to 0 at a specific iteration (e.g., 10k) and remains 0 afterward [S2, unofficial].
    c.  **Adjust for Downsampling:** If image downsampling is active, lower the kernel size by the scale of downsampling at the current stage to account for the initial hyperparameter choice based on original image resolutions [S4].
    d.  **Pre-Densification Adjustment:** Lower the blurring kernel size before densifying Gaussians. This introduces extra signal on the gradient of erroneous Gaussians as the noise level reduces [S4].
3.  **Apply Blur:** Convolve the raw training image $I_{raw}$ with the current Gaussian kernel $K(\sigma)$ to produce the smoothed image $I_{smooth}$ [S2, unofficial].
    $$ I_{smooth} = I_{raw} * K(\sigma) $$
4.  **Compute Loss:** Calculate the rendering loss (e.g., L1 or SSIM) between the rendered image and $I_{smooth}$ [S2, unofficial].

**Pseudocode:**
```python
def get_smoothed_supervision(raw_image, iteration, config):
    """
    Generates smoothed supervision image based on iteration schedule.
    
    Args:
        raw_image: 2D numpy array or tensor of the training image.
        iteration: Current training iteration number.
        config: Dictionary containing schedule parameters.
            - sigma_0: Initial standard deviation (e.g., 2.4).
            - kernel_size_init: Initial kernel size (e.g., 9).
            - k_b: Iteration interval for decay (e.g., 100).
            - t_end: Iteration at which blur becomes zero (e.g., 19500).
            - downscale_factor: Current image downsampling scale (1.0 if none).
            
    Returns:
        smoothed_image: Blurred version of raw_image.
    """
    # 1. Determine current sigma and kernel size
    # Linear or exponential decay logic depends on specific implementation variant.
    # Based on [S4]: Gradually reduce blur for every k_b iterations until t_end.
    
    if iteration >= config['t_end']:
        sigma = 0.0
        kernel_size = 1 # Effectively no blur
    else:
        # Calculate decay steps
        steps = iteration // config['k_b']
        
        # Example linear decay of sigma from sigma_0 to 0 over t_end
        # Note: [S2, unofficial] mentions exponential reduction to 0 at 10k; [S4] mentions reduction until 19500.
        # We implement a generic decay function here.
        progress = min(iteration / config['t_end'], 1.0)
        
        # Linear decay of sigma
        sigma = config['sigma_0'] * (1.0 - progress)
        
        # Kernel size is typically related to sigma (e.g., 6*sigma + 1)
        # Adjusted for downsampling as per [S4]
        base_kernel_size = int(6 * sigma + 1)
        if base_kernel_size < 1:
            base_kernel_size = 1
            
        # Apply downsampling scale adjustment
        # "lower the kernel size by the scale of downsampling"
        kernel_size = max(1, int(base_kernel_size / config['downscale_factor']))
        
        # Ensure odd kernel size for symmetry
        if kernel_size % 2 == 0:
            kernel_size += 1

    # 2. Apply Gaussian Blur
    if sigma == 0 or kernel_size == 1:
        return raw_image
    
    # Create separable Gaussian kernel
    # Kernel generation is a standard operation
    kernel_1d = generate_gaussian_1d(kernel_size, sigma)
    
    # Apply 2D convolution using separable kernels for efficiency [S1]
    # Horizontal pass
    blurred_h = convolve_separable(raw_image, kernel_1d, axis=1)
    # Vertical pass
    smoothed_image = convolve_separable(blurred_h, kernel_1d, axis=0)
    
    return smoothed_image

def generate_gaussian_1d(size, sigma):
    """Generates a 1D Gaussian kernel."""
    import numpy as np
    x = np.arange(size) - size // 2
    kernel = np.exp(-0.5 * (x / sigma)**2)
    return kernel / np.sum(kernel)

def convolve_separable(image, kernel_1d, axis):
    """Applies 1D convolution along a specific axis."""
    import numpy as np
    # Padding to maintain size
    pad_size = len(kernel_1d) // 2
    if axis == 0:
        padded = np.pad(image, ((pad_size, pad_size), (0, 0)), mode='reflect')
        # Convolve along rows
        result = np.zeros_like(image)
        for i in range(image.shape[0]):
            result[i, :] = np.convolve(padded[i+pad_size:i+pad_size+image.shape[0], :], kernel_1d, mode='valid')
        return result
    else: # axis == 1
        padded = np.pad(image, ((0, 0), (pad_size, pad_size)), mode='reflect')
        result = np.zeros_like(image)
        for j in range(image.shape[1]):
            result[:, j] = np.convolve(padded[:, j+pad_size:j+pad_size+image.shape[1]], kernel_1d, mode='valid')
        return result
```

**Parameters:**
*   $\sigma_0$: Initial standard deviation. Typical value: 2.4 [S4].
*   $k_b$: Decay interval. Typical value: 100 iterations [S4].
*   $t_{end}$: Iteration where blur is removed. Typical value: 19,500 [S4] or 10,000 [S2, unofficial].
*   Kernel Size: Initial size $9 \times 9$ [S4].

**Edge Cases and Pitfalls:**
*   **Over-smoothing:** If the kernel is too large for too long, high-frequency details are lost, potentially leading to blurry reconstructions [S2, unofficial].
*   **Gradient Noise:** As $\sigma \to 0$, the gradient signal becomes weaker and more susceptible to noise, particularly if the kernel magnitude $H(u, k)$ decreases linearly as $k \to 0$ [S2, unofficial]. This is why the kernel size is lowered before densification to introduce extra signal on erroneous Gaussians [S4].
*   **Downsampling Mismatch:** Failing to adjust the kernel size relative to the downsampling scale leads to incorrect frequency suppression [S4].

## Subtopics

### [Randomly Scaled Kernel Parameter](7875-randomly-scaled-kernel-parameter.md)
A regularization technique used during joint optimization to mitigate weak and noisy gradient signals. It addresses the insufficiency of using a single-size kernel for diverse real-world scene structures, where a fixed kernel may be overly aggressive in some contexts and overly gentle in others. By randomly scaling the kernel size, it allows combinations of different-sized kernels to guide the optimization, resulting in a more robust training schedule.

### [Multiscale Pre-convolved Representation](10911-multiscale-pre-convolved-representation.md)
A regularization technique for neural illumination fields that stabilizes the decomposition of object materials from environmental illumination by enforcing consistency with pre-computed, roughness-adapted background reflections. It addresses the ambiguity where diffuse object color is incorrectly absorbed into the estimated environment map, a problem inherent to high-dimensional neural illumination representations. Unlike methods that ignore the background or treat it as static, this method explicitly models the relationship between rough refractive surfaces and the convolved background, allowing for realistic specular reflections even when roughness exceeds the kernel scale. The technique builds on [Smoothed 2D Supervision](7213-smoothed-2d-supervision.md) by applying discrete Gaussian blur kernels to the background to stabilize convergence.

### [Soft Rasterization](13687-soft-rasterization.md)
Soft rasterization is a differentiable rendering technique that mitigates the discontinuities inherent in standard rasterization by blending facet contributions for pixels near primitive edges. It solves the problem of sparse and vanishing gradients caused by the non-uniformity of bilinear interpolation operands, which typically have similar values except at object boundaries. Unlike standard hard rasterization, it yields slightly distorted images but allows backpropagating more useful gradients, thereby stabilizing optimization and preventing gradient vanishing at edges.

### Platonic GAN (pGAN)
A learning-based method for 2D supervision per class of reconstructed objects, used here to pre-train a network for per-frame supervision of rising smoke [S5]. It is applied to improve depth artifacts in single-view evaluations but may lead to incoherent solutions if temporal constraints are lacking [S5].

## Operating characteristics
**Time and Memory Complexity:**
*   **Time:** The convolution operation is $O(N \cdot K^2)$ per image, where $N$ is the number of pixels and $K$ is the kernel size. However, using separable kernels reduces this to $O(N \cdot K)$ [S1]. The schedule updates are negligible $O(1)$ per iteration.
*   **Memory:** Requires storing the blurred image or recomputing it on the fly. No additional large data structures are needed beyond the kernel [S1].

**Measured Performance:**
*   On DTU 3-view, Smoothed 2D Supervision (specifically the "Adaptive Gaussian Blur" variant) achieves 19.72 PSNR, improving over the Baseline of 19.54 PSNR [S3].
*   It is experimentally proven crucial for successful pose refinement in ablation studies [S1].

**Strengths and Limitations:**
*   **Strengths:** Stabilizes camera alignment and joint optimization [S2, unofficial]. Reduces training iterations required (e.g., 50k vs 200k in some MLP-based methods) by providing robust gradients [S1]. Restricts the spectrum of the learned scene to prevent overfitting to noise [S2, unofficial].
*   **Limitations:** The strategies (linear or adaptive Gaussian blur) are handcrafted and cannot fully align frequency relationships between positional encodings and pixel supervision as effectively as adaptive methods [S3].

**When to Use:**
*   Use when joint optimization of camera poses and scene representation is unstable [S1].
*   Use when training requires stabilization in the early phases to avoid local minima [S2, unofficial].

**When Not to Use:**
*   When high-frequency detail preservation is critical from the start and the overhead of managing the schedule is not justified [S3].
*   When using an adaptive frequency regularization method that already handles spectral alignment [S3].

## Background
Smoothed 2D Supervision originated as a technique to improve the robustness of joint optimization in radiance fields and Gaussian Splatting [S1][S2, unofficial]. It was inspired by spectral analysis showing that blurring training images produces smoother gradients and stabilizes camera alignment [S2, unofficial]. The method is closely related to the Gaussian schedules used in 3D radiance fields [S2, unofficial]. It has been adopted in various forms, including "Adaptive Gaussian Blur" in few-shot NeRF [S3] and "Trick-GS" in efficient Gaussian Splatting [S4].
