# CG-SLAM


## Overview
CG-SLAM is a 3D Gaussian Splatting (3DGS) based Simultaneous Localization and Mapping (SLAM) method that enhances reconstruction quality by integrating an uncertainty map derived from rendered depth into the training process [S1][S2, unofficial]. It distinguishes itself from standard 3DGS SLAM by explicitly modeling depth uncertainty to guide densification and optimization, addressing misalignment issues common in explicit geometry representations [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Input image sequence, initial camera poses, initial 3D Gaussian set $\mathcal{G}$.
- **Outputs:** Optimized camera poses, refined 3D Gaussian parameters (means, covariances, opacities, colors), uncertainty map.

**Data Structures:**
- **3D Gaussians $\mathcal{G}$:** As defined in [Parent](9268-slam-and-mapping.md).
- **Uncertainty Map $U$:** A 2D image or per-pixel scalar field representing depth estimation confidence, computed from the rendered depth $\hat{D}$.

**Steps:**
1. **Rendering:** Render current view to obtain color $\hat{C}$ and depth $\hat{D}$ using differentiable rasterization.
2. **Uncertainty Estimation:** Compute the uncertainty map $U$ based on the rendered depth $\hat{D}$. The specific formula for $U$ is not detailed in the sources, but it serves as a confidence metric [S1][S2, unofficial].
3. **Loss Computation:** Calculate the rendering loss (e.g., L1 + SSIM) between $\hat{C}$ and ground truth $C$.
4. **Uncertainty-Aware Optimization:** Integrate $U$ into the training process. This likely modulates the gradient updates or loss weights based on depth confidence, preventing overfitting to unreliable depth regions [S1][S2, unofficial].
5. **Densification:** Update Gaussian parameters. The uncertainty map may influence splitting/cloning decisions, prioritizing regions with high uncertainty or error [S1][S2, unofficial].
6. **Pose Update:** Optimize camera poses using gradients from the uncertainty-aware loss .

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** CG-SLAM greatly improves reconstruction quality compared to standard 3DGS SLAM methods [S1][S2, unofficial].
- **Strengths:** Explicit geometry representation allows flexible reprojection, alleviating viewpoint misalignment [S1][S2, unofficial]. Real-time rendering capability makes it suitable for robotics applications [S1][S2, unofficial].
- **Limitations:** Not given in the sources.
- **When to use:** When high-quality reconstruction is critical and depth uncertainty needs to be explicitly modeled [S1][S2, unofficial].

## Background
CG-SLAM was introduced in reference [189] (cited in [S1][S2, unofficial]). It builds on the explicit geometry representation of 3DGS, which enables better reconstruction than NeRF-based methods due to flexible reprojection [S1][S2, unofficial]. It is applicable to robotics tasks such as relocalization, navigation, 6D pose estimation, multi-sensor calibration, and manipulation [S1][S2, unofficial].
