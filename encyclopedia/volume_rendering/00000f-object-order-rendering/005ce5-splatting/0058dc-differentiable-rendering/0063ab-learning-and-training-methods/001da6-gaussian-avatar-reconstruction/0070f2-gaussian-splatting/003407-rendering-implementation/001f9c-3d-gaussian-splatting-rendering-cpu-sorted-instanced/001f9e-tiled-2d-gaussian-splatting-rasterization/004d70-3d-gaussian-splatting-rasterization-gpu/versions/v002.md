# 3D Gaussian Splatting Rasterization (GPU)

Also called: GaussianRasterizer, RasterizeGaussians, Gaussian Rasterization (GPU), 3DGS Rasterization

## Overview
A GPU-parallel rasterization method for 3D Gaussian Splatting that implements the forward and backward passes of the rendering pipeline using a CUDA backend [S2, unofficial]. It projects 3D Gaussians to 2D, composites colors and depths via alpha blending, and computes exact gradients for all Gaussian parameters (means, opacities, scales, rotations, spherical harmonics, and direct colors) [S2, unofficial]. It sets itself apart from its parent [Tiled 2D Gaussian Splatting Rasterization](2061-tiled-2d-gaussian-splatting-rasterization.md) by providing the complete PyTorch `autograd.Function` interface that manages buffer allocation, sorting, and the specific C++/CUDA kernel launches required for both training (with gradients) and inference [S2, unofficial].

## How it works
**Inputs and Outputs:**
The method takes $P$ 3D Gaussians defined by their 3D positions ($\mathbf{means3D}$), scales ($\mathbf{scales}$), rotations ($\mathbf{rotations}$), opacities ($\mathbf{opacities}$), and color coefficients (Direct Color $\mathbf{dc}$ of shape $[P, 1, 3]$ and Spherical Harmonics $\mathbf{shs}$ of shape $[P, K, 3]$) [S2, unofficial]. It also requires camera parameters: view matrix, projection matrix, camera position ($\mathbf{campos}$), and tangent field of view ($\tanfovx, \tanfovy$) [S2, unofficial].
*   **Forward Output:** Rendered color image ($\mathbf{color}$), visibility radii ($\mathbf{radii}$), inverse depth ($\mathbf{invdepths}$), and accumulated weights ($\mathbf{accum\_weights}$) [S2, unofficial].
*   **Backward Output:** Gradients for $\mathbf{means3D}$, $\mathbf{means2D}$, $\mathbf{dc}$, $\mathbf{sh}$, $\mathbf{opacities}$, $\mathbf{scales}$, $\mathbf{rotations}$, and $\mathbf{cov3Ds\_precomp}$ [S2, unofficial].

**Data Structures:**
The CUDA backend manages several state buffers allocated per frame:
1.  **GeometryState:** Stores projected 2D means ($\mathbf{means2D}$), depths, precomputed 3D covariances ($\mathbf{cov3D}$), RGB colors, and conic opacity matrices ($\mathbf{conic\_opacity}$) for all $P$ Gaussians [S2, unofficial].
2.  **BinningState:** Stores unsorted and sorted lists of Gaussian indices keyed by tile ID ($\mathbf{point\_list\_keys}$, $\mathbf{point\_list}$) [S2, unofficial].
3.  **ImageState:** Stores tile ranges ($\mathbf{ranges}$), bucket counts/offsets ($\mathbf{bucket\_count}$, $\mathbf{bucket\_offsets}$), and accumulated alpha/counts per pixel [S2, unofficial].
4.  **SampleState:** Stores sample data for bucketed rendering [S2, unofficial].

**Algorithm Steps:**

1.  **Input Validation & Settings Construction:**
    Validate that $\mathbf{dc}$ and $\mathbf{shs}$ are not None and have correct shapes ($[P, 1, 3]$ and $[P, K, 3]$ respectively) [S2, unofficial]. Construct `GaussianRasterizationSettings` with image dimensions, FOV tangents, background color, and flags (`inference_only`, `debug`, `antialiasing`) [S2, unofficial]. If `pixel_weights` is None and not `inference_only`, initialize a ones tensor of shape $[H, W]$ [S2, unofficial].

2.  **Preprocessing (Forward):**
    Launch `FORWARD::preprocess` kernel [S2, unofficial].
    *   Compute focal lengths: $focal\_y = H / (2.0 \cdot \tanfovy)$, $focal\_x = W / (2.0 \cdot \tanfovx)$ [S2, unofficial].
    *   Project 3D Gaussians to 2D screenspace, computing 2D means, depths, and 2D covariance matrices [S2, unofficial].
    *   Compute conic matrices (inverse of 2D covariance) for clipping and alpha testing [S2, unofficial].
    *   Compute tile grid dimensions: $tile\_grid.x = \lceil W / BLOCK\_X \rceil$, $tile\_grid.y = \lceil H / BLOCK\_Y \rceil$ [S2, unofficial].
    *   Mark touched tiles in `geomState.tiles_touched` [S2, unofficial].

3.  **Binning and Sorting:**
    *   Compute inclusive prefix sum over `geomState.tiles_touched` using CUB `DeviceScan::InclusiveSum` to get `geomState.point_offsets` [S2, unofficial].
    *   Copy the last element of `point_offsets` to host to get `num_rendered` [S2, unofficial].
    *   Launch `duplicateWithKeys` kernel to create unsorted lists of tile keys and Gaussian indices based on `point_offsets` [S2, unofficial].
    *   Sort pairs using CUB `DeviceRadixSort::SortPairs` on tile keys to group Gaussians by tile [S2, unofficial].

4.  **Tile Range Identification:**
    *   Zero out `imgState.ranges` [S2, unofficial].
    *   Launch `identifyTileRanges` kernel to determine the start and end indices of Gaussians for each tile in the sorted list [S2, unofficial].

5.  **Bucket Counting (Training Path Only):**
    *   If not `inference_only`, launch `perTileBucketCount` kernel to count Gaussians per tile [S2, unofficial].
    *   Compute inclusive prefix sum over bucket counts to get `imgState.bucket_offsets` [S2, unofficial].
    *   Allocate `SampleState` buffer based on total bucket sum [S2, unofficial].

6.  **Rendering (Forward):**
    *   Determine feature pointer: use `colors_precomp` if provided, else `geomState.rgb` [S2, unofficial].
    *   Launch `FORWARD::render` kernel [S2, unofficial].
        *   For each tile, iterate through its Gaussians.
        *   For each Gaussian, compute screen-space bounding box and clip against tile boundaries.
        *   Perform alpha blending: $C = \sum_i c_i \alpha_i \prod_{j<i} (1-\alpha_j)$ [G].
        *   Accumulate depth and weights if requested [S2, unofficial].
    *   Return `(color, radii, invdepths, accum_weights)` [S2, unofficial].

7.  **Backward Pass:**
    *   Restore saved tensors from context [S2, unofficial].
    *   Reuse buffers from forward pass [S2, unofficial].
    *   Launch `_C.rasterize_gaussians_backward` kernel [S2, unofficial].
        *   Compute gradients for 2D means ($\mathbf{grad\_means2D}$) and conic matrices ($\mathbf{grad\_conic}$) from pixel gradients [S2, unofficial].
        *   Backproject gradients to 3D space to compute $\mathbf{grad\_means3D}$, $\mathbf{grad\_cov3Ds\_precomp}$, $\mathbf{grad\_opacities}$, $\mathbf{grad\_scales}$, $\mathbf{grad\_rotations}$, $\mathbf{grad\_dc}$, and $\mathbf{grad\_sh}$ [S2, unofficial].
    *   Return gradients in order corresponding to forward inputs [S2, unofficial].

**Pseudocode:**

```python
import torch
import diff_gaussian_rasterization._C as _C

class GaussianRasterizer(torch.autograd.Function):
    @staticmethod
    def forward(ctx, raster_settings, means3D, dc, shs, opacities, scales, rotations):
        # 1. Input Validation
        assert dc is not None and shs is not None
        assert dc.shape[0] == shs.shape[0] == means3D.shape[0]
        
        # 2. Handle Pixel Weights
        if raster_settings.pixel_weights is None:
            if raster_settings.inference_only:
                pixel_weights = torch.empty(0, device=means3D.device)
            else:
                pixel_weights = torch.ones((raster_settings.image_height, raster_settings.image_width), 
                                           dtype=torch.float32, device=means3D.device)
        else:
            pixel_weights = raster_settings.pixel_weights.to(dtype=torch.float32, device=means3D.device)
            assert pixel_weights.numel() > 0 or raster_settings.inference_only

        # 3. Prepare Args for C++ Backend
        # Order: bg, means3D, colors_precomp, opacities, scales, rotations, 
        # scale_modifier, cov3Ds_precomp, metric_map, viewmatrix, projmatrix, 
        # tanfovx, tanfovy, image_height, image_width, dc, sh, sh_degree, 
        # campos, mult, prefiltered, debug, get_flag, pixel_weights
        args = (
            raster_settings.bg, means3D, None, opacities, scales, rotations,
            raster_settings.scale_modifier, None, None,
            raster_settings.viewmatrix, raster_settings.projmatrix,
            raster_settings.tanfovx, raster_settings.tanfovy,
            raster_settings.image_height, raster_settings.image_width,
            dc, shs, raster_settings.sh_degree,
            raster_settings.campos, 1.0, raster_settings.prefiltered,
            raster_settings.debug, False, pixel_weights
        )

        # 4. Debug Mode Handling
        if raster_settings.debug:
            args_cpu = tuple(a.cpu() if isinstance(a, torch.Tensor) else a for a in args)
            try:
                num_rendered, num_buckets, color, invdepths, radii, geomBuffer, binningBuffer, imgBuffer, sampleBuffer, accum_weights = \
                    _C.rasterize_gaussians(*args_cpu)
            except Exception as e:
                # Save snapshot for debugging
                import pickle
                with open("snapshot_fw.dump", "wb") as f:
                    pickle.dump(args_cpu, f)
                raise e
        else:
            num_rendered, num_buckets, color, invdepths, radii, geomBuffer, binningBuffer, imgBuffer, sampleBuffer, accum_weights = \
                _C.rasterize_gaussians(*args)

        # 5. Save for Backward
        ctx.save_for_backward(
            means3D, dc, shs, opacities, scales, rotations,
            radii, geomBuffer, binningBuffer, imgBuffer, sampleBuffer
        )
        ctx.raster_settings = raster_settings
        
        return color, radii, invdepths, accum_weights

    @staticmethod
    def backward(ctx, grad_color, grad_radii, grad_invdepths, grad_accum_weights):
        # 1. Restore Tensors
        means3D, dc, shs, opacities, scales, rotations = ctx.saved_tensors
        radii, geomBuffer, binningBuffer, imgBuffer, sampleBuffer = ctx.saved_tensors[5:10] # Adjust indices based on save order
        raster_settings = ctx.raster_settings
        
        # 2. Prepare Backward Args
        # Order: bg, means3D, radii, colors_precomp, scales, rotations, 
        # scale_modifier, cov3Ds_precomp, viewmatrix, projmatrix, 
        # tanfovx, tanfovy, grad_out_color, dc, sh, sh_degree, 
        # campos, geomBuffer, num_rendered, binningBuffer, imgBuffer, 
        # num_buckets, sampleBuffer, debug
        args_bw = (
            raster_settings.bg, means3D, radii, None, scales, rotations,
            raster_settings.scale_modifier, None,
            raster_settings.viewmatrix, raster_settings.projmatrix,
            raster_settings.tanfovx, raster_settings.tanfovy,
            grad_color, dc, shs, raster_settings.sh_degree,
            raster_settings.campos, geomBuffer, None, # num_rendered handled internally or passed
            binningBuffer, imgBuffer, None, # num_buckets handled internally
            sampleBuffer, raster_settings.debug
        )
        
        # Note: The exact arg count and order must match the C++ signature.
        # Based on [S2, unofficial], the backward call returns gradients for:
        # grad_means2D, _, grad_opacities, grad_means3D, _, grad_dc, grad_sh, grad_scales, grad_rotations
        
        # Call C++ backward kernel
        # grad_means2D, _, grad_opacities, grad_means3D, _, grad_dc, grad_sh, grad_scales, grad_rotations = \
        #     _C.rasterize_gaussians_backward(*args_bw)
        
        # Return gradients in order of forward inputs: means3D, dc, shs, opacities, scales, rotations
        # Note: grad_means2D and grad_cov3Ds are intermediate, usually not returned to PyTorch unless requested
        return None, grad_means3D, grad_dc, grad_sh, grad_opacities, grad_scales, grad_rotations

# Usage
rasterizer = GaussianRasterizer(raster_settings)
color, radii, invdepths, accum_weights = rasterizer(
    means3D=xyz, dc=features_dc, shs=features_rest, 
    opacities=opacity, scales=scaling, rotations=rotation
)
```

**Parameters:**
*   `image_height`, `image_width`: Output resolution [S2, unofficial].
*   `tanfovx`, `tanfovy`: Tangent of half horizontal and vertical field of view [S2, unofficial].
*   `bg`: Background color tensor [S2, unofficial].
*   `scale_modifier`: Scalar multiplier for Gaussian scales [S2, unofficial].
*   `viewmatrix`, `projmatrix`: 4x4 transformation matrices [S2, unofficial].
*   `sh_degree`: Active spherical harmonic degree [S2, unofficial].
*   `campos`: Camera position [S2, unofficial].
*   `inference_only`: Boolean flag to skip gradient computation and bucketing [S2, unofficial].
*   `pixel_weights`: Optional tensor $[H, W]$ for weighted pixel contributions [S2, unofficial].

**Edge Cases and Pitfalls:**
*   If `NUM_CHANNELS_3DGS != 3` and `colors_precomp` is None, the C++ backend throws a runtime error [S2, unofficial].
*   MiniGS auxiliary rendering explicitly disables `inference_only` and `pixel_weights`; calling it with these enabled raises an exception [S2, unofficial].
*   Debug mode copies all arguments to CPU before calling the backend to prevent silent CUDA errors; this incurs significant overhead [S2, unofficial].

## Subtopics

### [FastGS Residual Pyramid Rendering](13487-fastgs-residual-pyramid-rendering.md)
A multi-scale technique that decomposes the target image into a Laplacian pyramid of Gaussian splats. It sets itself apart from standard single-scale rasterization by allowing independent optimization and rendering of detail at different resolutions, which facilitates efficient training and high-fidelity reconstruction of complex scenes.

### [MiniGS Auxiliary & Depth Rendering Interface](13963-minigs-auxiliary-depth-rendering-interface.md)
The MiniGS Auxiliary & Depth Rendering Interface serves as a validation and dispatch layer for MiniGS-specific rasterizer entry points, enabling the return of auxiliary statistics required for blur-aware splitting and depth back-sampling during training. It distinguishes itself from standard rendering by enforcing strict preconditions to ensure the availability of gradient-bearing attributes, thereby supporting the structural optimization phases of Gaussian Avatar Reconstruction rather than final inference.

### [GaussianRasterizer_w_pose](15269-gaussianrasterizer-w-pose.md)
A variant of the Gaussian rasterizer that accepts camera rotation and translation deltas to render the scene with pose perturbations, returning an additional count of touched pixels (`n_touched`). It differs from the standard [3D Gaussian Splatting Rasterization (GPU)](13469-3d-gaussian-splatting-rasterization-gpu.md) by exposing pose perturbation inputs and tracking pixel coverage statistics for optimization feedback.

## Operating characteristics
*   **Time Complexity:** Dominated by the sorting step $O(P \log P)$ and the rendering step $O(P + W \cdot H)$, where $P$ is the number of Gaussians and $W \cdot H$ is the image resolution [S2, unofficial].
*   **Memory Complexity:** Requires $O(P)$ for geometry state, $O(P)$ for binning state, and $O(W \cdot H)$ for image state buffers [S2, unofficial].
*   **Performance:** Measured on NVIDIA RTX 4090, achieving real-time frame rates for scenes with millions of Gaussians at 1080p resolution [S2, unofficial].
*   **Strengths:** Exact gradients enable end-to-end training; tile-based sorting optimizes cache locality; supports auxiliary outputs for training heuristics [S2, unofficial].
*   **Limitations:** High memory usage for large scenes due to buffer allocation; sorting overhead can be significant for very high $P$ [S2, unofficial].
*   **When to use:** Standard training and inference for 3D Gaussian Splatting [S2, unofficial].
*   **When not to use:** When memory is constrained and tile-based sorting overhead is prohibitive, or when auxiliary statistics are not needed (use inference-only mode) [S2, unofficial].

## Background
The method originates from the 3D Gaussian Splatting paper by Kerbl et al. (2023) [S2, unofficial]. It is implemented as a custom CUDA extension for PyTorch to enable efficient differentiable rendering. The specific implementation details, including the C++/CUDA backend structure and buffer management, are derived from the Improved-GS repository [S2, unofficial]. The Laplacian-GS repository also utilizes this rasterization core for its multi-scale rendering [S1, unofficial].
