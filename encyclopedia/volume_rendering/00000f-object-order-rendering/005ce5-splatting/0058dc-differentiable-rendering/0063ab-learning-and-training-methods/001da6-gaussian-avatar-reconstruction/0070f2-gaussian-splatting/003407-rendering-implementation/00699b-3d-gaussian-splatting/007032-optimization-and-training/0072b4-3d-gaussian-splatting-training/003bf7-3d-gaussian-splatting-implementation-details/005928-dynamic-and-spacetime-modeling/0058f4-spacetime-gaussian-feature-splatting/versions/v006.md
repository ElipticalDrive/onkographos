# Spacetime Gaussian Feature Splatting

Also called: Spacetime Gaussians

## Overview
Spacetime Gaussian Feature Splatting (STG) is a dynamic scene representation that extends 3D Gaussian Splatting into the 4D spacetime domain to enable real-time novel view synthesis of dynamic scenes [S2]. It solves the problem of modeling emerging, vanishing, and deforming content by parameterizing Gaussian position, rotation, and opacity as explicit functions of time, while replacing spherical harmonics with a compact neural feature representation [S2]. Unlike static 3DGS or deformation-field-based methods, STG uses polynomial trajectories for motion and a lightweight MLP for appearance, offering superior temporal stability and lower memory consumption than training independent static frames [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Multi-view video sequences (images and camera poses) across multiple timestamps.
*   **Output:** A set of Spacetime Gaussians (STGs) and a small MLP $\Phi$, allowing rendering of novel views at arbitrary times $t$.

**Data Structures:**
Each STG $i$ stores the following parameters:
*   **Spatial Opacity:** $\sigma_{is} \in \mathbb{R}$ (time-independent base opacity).
*   **Temporal Opacity Parameters:** $\mu_{\tau i} \in \mathbb{R}$ (temporal center), $s_{\tau i} \in \mathbb{R}$ (temporal scaling).
*   **Motion Parameters:** Polynomial coefficients $\{b_{i,k}\}_{k=0}^{n_p}$ for position, where $n_p=3$.
*   **Rotation Parameters:** Polynomial coefficients $\{c_{i,k}\}_{k=0}^{n_q}$ for quaternion rotation, where $n_q=1$.
*   **Scaling:** $s_i \in \mathbb{R}^3$ (time-independent scaling vector).
*   **Features:** $f_i(t) \in \mathbb{R}^9$, decomposed into:
    *   $f_{base} \in \mathbb{R}^3$: Base RGB color.
    *   $f_{dir} \in \mathbb{R}^3$: View-dependent features.
    *   $f_{time} \in \mathbb{R}^3$: Time-dependent features.
*   **MLP $\Phi$:** A shallow, narrow neural network mapping features and view direction to final color.

**Numbered Steps:**

1.  **Initialization:** Initialize STGs using structure-from-motion (SfM) sparse point clouds from all available timestamps [S2].
2.  **Temporal Opacity Calculation:** For a given time $t$, compute the temporal opacity $\sigma_i(t)$ using a 1D Gaussian function [S2]:
    $$ \sigma_i(t) = \sigma_{is} \exp \left( -s_{\tau i} |t - \mu_{\tau i}|^2 \right) $$
    This allows Gaussians to emerge or vanish during the video sequence [S2].
3.  **Motion and Rotation Calculation:** Compute the time-dependent position $\mu_i(t)$ and rotation quaternion $q_i(t)$ using polynomial functions [S2]:
    $$ \mu_i(t) = \sum_{k=0}^{n_p} b_{i,k} (t - \mu_{\tau i})^k $$
    $$ q_i(t) = \sum_{k=0}^{n_q} c_{i,k} (t - \mu_{\tau i})^k $$
    The scaling matrix $S_i$ remains time-independent [S2].
4.  **Covariance Construction:** Construct the 3D covariance matrix $\Sigma_i(t)$ from the rotation matrix $R_i(t)$ (derived from $q_i(t)$) and the diagonal scaling matrix $S_i$ [S2]:
    $$ \Sigma_i(t) = R_i(t) S_i S_i^T R_i(t)^T $$
5.  **Projection:** Project the 3D Gaussian to 2D screen space. Compute the 2D center $\mu^{2D}_i$ and covariance $\Sigma^{2D}_i$ using the viewing transformation $W$, projection matrix $K$, and Jacobian $J$ of the projective transformation [S2]:
    $$ \mu^{2D}_i = \left( K \left( \frac{W \mu_i(t)}{(W \mu_i(t))_z} \right) \right)_{1:2} $$
    $$ \Sigma^{2D}_i = \left( J W \Sigma_i(t) W^T J^T \right)_{1:2,1:2} $$
6.  **Feature Splatting:** Render the scene by splatting the time-dependent features $f_i(t)$ instead of direct colors. The feature vector at time $t$ is constructed as [S2]:
    $$ f_i(t) = \left[ f_{base}, f_{dir}, (t - \mu_{\tau i}) f_{time} \right]^T $$
    During rasterization, accumulate splatted features $F_{base}, F_{dir}, F_{time}$ at each pixel weighted by 2D opacity $\alpha^{2D}_i$ and depth order [S2]:
    $$ I_{feat} = \sum_{i \in N} f_i(t) \alpha^{2D}_i \prod_{j=1}^{i-1} (1 - \alpha^{2D}_j) $$
    where $N$ is the set of Gaussians sorted by depth [S2].
7.  **Color Decoding:** Pass the splatted features and the view direction $r$ through the MLP $\Phi$ to produce the final pixel color [S2]:
    $$ C = \Phi(F_{base}, F_{dir}, F_{time}, r) $$
    *Lite-version:* Optionally, drop $\Phi$ and use $F_{base}$ directly as the color [S2].
8.  **Guided Sampling (Optional):** If training error is high in sparse regions, sample new Gaussians [S2]:
    *   Aggregate training errors patch-wise to identify substantial errors.
    *   Use a coarse depth map of existing Gaussians to determine a specific depth range.
    *   Sample new Gaussian centers uniformly along rays from the center of high-error patches within the depth range, adding small noise [S2].
    *   This step is performed no more than 3 times [S2].
9.  **Optimization:** Optimize all parameters ($\sigma_{is}, s_{\tau i}, \mu_{\tau i}, \{b_{i,k}\}, \{c_{i,k}\}, s_i, f_{base}, f_{dir}, f_{time}$) and MLP $\Phi$ using the Adam optimizer [S2]. The loss function combines L1 and D-SSIM terms between rendered and ground truth images [S2]. Interleave optimization with aggressive density control (pruning) to reduce Gaussian count [S2].

import numpy as np

def compute_temporal_opacity(sigma_is, s_tau, mu_tau, t):
    """
    Computes temporal opacity sigma_i(t).
    """
    return sigma_is * np.exp(-s_tau * (t - mu_tau)**2)

def compute_motion(mu_tau, b_coeffs, t):
    """
    Computes position mu_i(t) using polynomial coefficients.
    b_coeffs: list of numpy arrays [b_0, b_1, b_2, b_3] for np=3.
    """
    pos = np.zeros(3)
    for k, b in enumerate(b_coeffs):
        pos += b * (t - mu_tau)**k
    return pos

def compute_rotation(mu_tau, c_coeffs, t):
    """
    Computes quaternion q_i(t) using polynomial coefficients.
    c_coeffs: list of numpy arrays [c_0, c_1] for nq=1.
    Returns normalized quaternion.
    """
    quat = np.zeros(4)
    for k, c in enumerate(c_coeffs):
        quat += c * (t - mu_tau)**k
    return quat / np.linalg.norm(quat)

def get_covariance(quat, s_vec):

    # S is diagonal matrix from s_vec

    return R @ (S @ S.T) @ R.T

def project_gaussian(mu_3d, cov_3d, W, K, J):
    """
    Projects 3D Gaussian to 2D screen space.
    """
    # 2D Center
    mu_homogeneous = W @ np.append(mu_3d, 1)
    mu_2d = (K @ (mu_homogeneous / mu_homogeneous[2]))[:2]
    
    # 2D Covariance
    cov_2d = (J @ W @ cov_3d @ W.T @ J.T)[:2, :2]
    
    return mu_2d, cov_2d

    """
    Renders a single frame at time t.
    stgs: List of STG objects.
    camera_params: Contains W, K, J.
    """
    # 1. Compute time-dependent properties for each STG
    rendered_features = []
    alphas = []
    depths = []
    
    for stg in stgs:
        # Temporal Opacity
        sigma_t = compute_temporal_opacity(stg.sigma_is, stg.s_tau, stg.mu_tau, t)
        
        # Motion and Rotation
        mu_t = compute_motion(stg.mu_tau, stg.b_coeffs, t)
        quat_t = compute_rotation(stg.mu_tau, stg.c_coeffs, t)
        
        # Covariance
        cov_t = get_covariance(quat_t, stg.s_vec)
        
        # Projection
        mu_2d, cov_2d = project_gaussian(mu_t, cov_t, camera_params.W, camera_params.K, camera_params.J)
        
        # 2D Opacity (simplified Gaussian alpha at center for sorting/weighting)
        # In full rasterization, this is done per pixel, but for sorting:
        alpha_2d = sigma_t # Simplified for sorting logic; actual splatting uses 2D Gaussian kernel

        f_base = stg.f_base
        f_dir = stg.f_dir
        f_time = stg.f_time
        f_t = np.concatenate([f_base, f_dir, (t - stg.mu_tau) * f_time])
        
        rendered_features.append(f_t)
        alphas.append(alpha_2d)
        depths.append(mu_t[2]) # Depth for sorting

    indices = np.argsort(depths)
    sorted_features = [rendered_features[i] for i in indices]
    sorted_alphas = [alphas[i] for i in indices]
    
    # 3. Splatting (Simplified accumulation for demonstration)
    # In practice, this is a rasterization kernel.
    # We accumulate weighted features.
    # Note: The formula I = sum(c_i * alpha_i * prod(1-alpha_j)) requires pixel-wise accumulation.

    accumulated_alpha = 0.0
    
    for i, (f, alpha) in enumerate(zip(sorted_features, sorted_alphas)):

    F_time = accumulated_f[6:9]

**Parameters:**
*   Polynomial degree for motion $n_p = 3$ [S2].
*   Polynomial degree for rotation $n_q = 1$ [S2].
*   Feature dimension per STG: 9 (3 base, 3 dir, 3 time) [S2].
*   Optimizer: Adam [S2].
*   Loss: L1 + D-SSIM [S2].

**Edge Cases and Pitfalls:**
*   **Scaling Matrix:** The scaling matrix $S_i$ is kept time-independent. Applying time-conditioned functions to scaling did not improve rendering quality [S2].
*   **Sampling Frequency:** Guided sampling should be conducted no more than 3 times to avoid instability [S2].
*   **Precision:** Polynomial coefficients are optimized; ensure numerical stability for high-degree polynomials if $n_p$ were increased, though $n_p=3$ is stable [S2].

## Operating characteristics
*   **Time Complexity:** Training time is 40-60 minutes for a 50-frame sequence on a single NVIDIA A6000 GPU [S2].
*   **Memory Complexity:** Significantly lower memory consumption than 3DGS, Plenoxels, and Nerfacto because a single model represents all frames [S1]. Feature dimension is 9 per STG vs 48 for 3-degree Spherical Harmonics [S2].
*   **Rendering Speed:** 140 FPS at 1352 × 1014 resolution on the Neural 3D Video Dataset [S2]. 66 FPS at 8K resolution on an Nvidia RTX 4090 GPU (lite-version) [S2].
*   **Strengths:** Real-time high-resolution rendering, compact model size, better temporal stability than independent frame training, and ability to model transient content [S1, S2].
*   **Limitations:** Requires multi-view video input; polynomial motion model may struggle with highly complex, non-polynomial deformations compared to deformation fields [S2].
*   **When to use:** Real-time dynamic view synthesis where memory and speed are critical, and scenes have smooth, polynomial-like motion [S2].
*   **When not to use:** Scenes with highly erratic, non-smooth motion that cannot be captured by low-degree polynomials, or single-view dynamic reconstruction [S2].

## Background
Spacetime Gaussian Feature Splatting (STG) was introduced by Zhan Li, Zhang Chen, Zhong Li, and Yi Xu from OPPO US Research Center and Portland State University in the paper "Spacetime Gaussian Feature Splatting for Real-Time Dynamic View Synthesis" (arXiv:2312.16812v2, Apr 4 2024) [S2]. It builds upon 3D Gaussian Splatting [S1] by extending the representation to 4D spacetime, addressing limitations of grid-based dynamic representations (like K-Planes) and deformation-based methods in terms of rendering speed and structural adaptability [S2].
