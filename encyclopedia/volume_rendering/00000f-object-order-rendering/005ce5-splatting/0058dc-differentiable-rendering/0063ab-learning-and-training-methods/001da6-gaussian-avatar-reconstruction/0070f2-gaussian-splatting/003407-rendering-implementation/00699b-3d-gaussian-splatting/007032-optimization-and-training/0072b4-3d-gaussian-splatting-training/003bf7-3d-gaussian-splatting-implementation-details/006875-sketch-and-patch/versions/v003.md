# Sketch and Patch

Also called: Sketch Gaussian Extraction, Sketch and Patch: Efficient 3D Gaussian Representation for Man-Made Scenes

## Overview
Sketch and Patch is a hybrid 3D Gaussian representation method that categorizes Gaussians into two distinct roles: Sketch Gaussians, which define scene boundaries and high-frequency features, and Patch Gaussians, which cover smoother, broader regions [S1]. It solves the problem of storage inefficiency and redundancy in standard 3D Gaussian Splatting (3DGS), where adaptive density control overestimates densification needs in high-frequency areas, leading to redundant Gaussian clusters along edges [S1]. Unlike conventional 3D downsampling or tiling which degrade visual quality due to the tightly coupled, heterogeneous nature of 3DGS Gaussians, this method separates Gaussians by role to allow specialized encoding [S1].

## How it works
**Inputs:** Multi-view images and camera poses [S1].
**Outputs:** A unified hybrid representation consisting of encoded Sketch Gaussians and optimized Patch Gaussians [S1].

### Data Structures
1. **3D Line Segment ($L_i$):** Defined by endpoints $p_{start}, p_{end} \in \mathbb{R}^3$ and parameter $t \in [0, 1]$ [S1].
2. **Sketch Gaussian Candidate Set ($S_i$):** A subset of original 3DGS Gaussians associated with line segment $L_i$ [S1].
3. **Parametric Model:** A function (e.g., polynomial or spline) encoding the attributes of Sketch Gaussians along the line [S1].
4. **Patch Gaussian Set:** The remaining Gaussians after Sketch extraction, subject to pruning [S1].

### Numbered Steps
1. **Extract 3D Line Segments:** Process input images and camera poses using a geometry-guided line reconstruction method, specifically Line3D++ [S1]. This abstracts object boundaries into discrete 2D line segments and back-projects them into 3D space to obtain a set of 3D line segments $\{L_i\}$ [S1].
2. **Identify Sketch Gaussians:** For each 3D line segment $L_i$, identify candidate Gaussians concentrated along the line [S1]. A Gaussian splat $G_j$ with center $\mu_j \in \mathbb{R}^3$ is included in the candidate set $S_i$ if its distance to the line segment is within a radius $r$:
   $$ d(\mu_j, L_i) = \min_{t \in [0,1]} \|\mu_j - L_i(t)\| \le r $$
   where the line segment is parameterized as:
   $$ L_i(t) = (1 - t)p_{start} + t p_{end}, \quad t \in [0, 1] $$
   [S1]. Apply Random Sample Consensus (RANSAC) to the candidate set $S_i$ to ensure coherent attribute values among the selected Sketch Gaussians, refining the set to robustly represent the line [S1].
3. **Encode Sketch Gaussians:** Encode the identified Sketch Gaussians using parametric models (such as polynomials or splines) defined on the given 3D line $L_i$ [S1]. This leverages the geometric coherence of Gaussians along edges to model their attributes compactly, significantly reducing storage requirements [S1].
4. **Optimize Patch Gaussians:** For the remaining smoother regions represented by Patch Gaussians, apply pruning and retraining [S1]. This sparsifies their distribution while maintaining visual fidelity and volumetric consistency [S1].
5. **Integrate Representation:** Combine the encoded Sketch Gaussians and the optimized Patch Gaussians into a unified hybrid representation for efficient storage, transmission, and rendering [S1].

### Pseudocode
```python
import math

def sketch_and_patch(images, camera_poses, original_gaussians, radius_threshold, n_ransac_iter=100, ransac_threshold=0.05):
    # Step 1: Extract 3D Line Segments using Line3D++ [S1]
    # [G] Standard geometry-guided line reconstruction takes images and poses,
    # outputs 3D line segments as pairs of endpoints.
    line_segments = []  # Populated by Line3D++ extraction

    sketch_gaussians = []
    patch_gaussians = []
    sketch_indices = set()

    # Step 2 & 3: Identify and Encode Sketch Gaussians
    for line in line_segments:
        p_start, p_end = line
        candidates = []
        for idx, g in enumerate(original_gaussians):
            dist = min_distance_point_to_segment(g.center, p_start, p_end)
            if dist <= radius_threshold:
                candidates.append((idx, g))

        # Step 2 continued: RANSAC filtering for attribute coherence [S1]
        refined_candidates = ransac_attribute_filter(candidates, n_ransac_iter, ransac_threshold)
        for idx, _ in refined_candidates:
            sketch_indices.add(idx)

        # Step 3: Parametric encoding [S1]
        encoded_sketch = parametric_fit(refined_candidates, p_start, p_end)
        sketch_gaussians.append(encoded_sketch)

    # Step 4: Optimize Patch Gaussians
    unprocessed_gaussians = [g for i, g in enumerate(original_gaussians) if i not in sketch_indices]
    # [G] Standard 3DGS pruning removes Gaussians below opacity/contribution threshold;
    # Retraining runs gradient descent on remaining Gaussians to recover fidelity.
    patch_gaussians = prune_and_retrain_gaussians(unprocessed_gaussians)

    return sketch_gaussians, patch_gaussians

def min_distance_point_to_segment(point, p1, p2):
    line_vec = [p2[i] - p1[i] for i in range(3)]
    point_vec = [point[i] - p1[i] for i in range(3)]
    line_len_sq = sum(v*v for v in line_vec)
    if line_len_sq == 0:
        return math.sqrt(sum(v*v for v in point_vec))
    t = sum(point_vec[i]*line_vec[i] for i in range(3)) / line_len_sq
    t = max(0.0, min(1.0, t))
    closest = [p1[i] + t * line_vec[i] for i in range(3)]
    diff = [point[i] - closest[i] for i in range(3)]
    return math.sqrt(sum(v*v for v in diff))

def projection_t(point, p1, p2):
    line_vec = [p2[i] - p1[i] for i in range(3)]
    point_vec = [point[i] - p1[i] for i in range(3)]
    line_len_sq = sum(v*v for v in line_vec)
    if line_len_sq == 0:
        return 0.0
    t = sum(point_vec[i]*line_vec[i] for i in range(3)) / line_len_sq
    return max(0.0, min(1.0, t))

def ransac_attribute_filter(candidates, n_iter, threshold):
    best_inliers = []
    for _ in range(n_iter):
        if len(candidates) < 2:
            break
        subset = [candidates[i] for i in range(min(2, len(candidates)))]
        t_vals = [projection_t(c.center, subset[0][1].center, subset[1][1].center) for c in subset]
        opacities = [c.opacity for c in subset]
        if abs(t_vals[1] - t_vals[0]) < 1e-6:
            continue
        m = (opacities[1] - opacities[0]) / (t_vals[1] - t_vals[0])
        b = opacities[0] - m * t_vals[0]
        inliers = []
        for c in candidates:
            t = projection_t(c.center, subset[0][1].center, subset[1][1].center)
            pred = m * t + b
            if abs(c.opacity - pred) < threshold:
                inliers.append(c)
        if len(inliers) > len(best_inliers):
            best_inliers = inliers
    return best_inliers

def parametric_fit(candidates, p_start, p_end):
    # [G] Polynomial regression fits attributes (opacity, SH coefficients) along the line parameter t
    # Stores coefficients instead of per-Gaussian values.
    if not candidates:
        return None
    t_vals = [projection_t(c.center, p_start, p_end) for c in candidates]
    opacities = [c.opacity for c in candidates]
    n = len(t_vals)
    s_t = sum(t_vals)
    s_t2 = sum(t*t for t in t_vals)
    s_t3 = sum(t*t*t for t in t_vals)
    s_t4 = sum(t*t*t*t for t in t_vals)
    s_y = sum(opacities)
    s_ty = sum(t*y for t, y in zip(t_vals, opacities))
    s_t2y = sum(t*t*y for t, y in zip(t_vals, opacities))
    # Solve 3x3 normal equations for quadratic fit: a*t^2 + b*t + c
    det = s_t4*(s_t2*n - s_t*s_t) - s_t3*(s_t3*n - s_t*s_t2) + s_t2*(s_t3*s_t - s_t2*s_t2)
    if abs(det) < 1e-9:
        return {"type": "linear", "coeffs": [0.0, 0.0], "t_range": [0.0, 1.0]}
    a = (s_t2y*(s_t2*n - s_t*s_t) - s_ty*(s_t3*n - s_t*s_t2) + s_y*(s_t3*s_t - s_t2*s_t2)) / det
    b = (s_t4*s_ty - s_t3*s_t2y - s_t*(s_t3*s_ty - s_t2*s_t2y)) / det
    c = (s_t4*s_t2y - s_t3*s_t3y - s_t2*(s_t3*s_ty - s_t2*s_t2y)) / det
    return {"type": "polynomial", "coeffs": [a, b, c], "t_range": [0.0, 1.0]}

def prune_and_retrain_gaussians(gaussians):
    # [G] Standard 3DGS pruning: removes Gaussians below opacity/contribution threshold.
    # Retraining: runs gradient descent on remaining Gaussians to recover fidelity.
    pruned = [g for g in gaussians if g.opacity > 0.01]
    return pruned
```

### Parameters
* **Line Reconstruction Method:** Line3D++ [S1].
* **Radius Threshold ($r$):** Distance threshold for including a Gaussian in the Sketch candidate set [S1]. Not given in the sources.
* **Parametric Model Type:** Polynomials or splines [S1].

### Edge Cases and Pitfalls
* **Redundancy in High-Frequency Areas:** Standard 3DGS adaptive density control relies on 2D positional gradients, which often overestimates the need for densification in high-frequency areas like edges and contours [S1]. Sketch and Patch addresses this by explicitly identifying and encoding these regions rather than densifying blindly [S1].
* **Scene Type:** The method is especially effective in man-made scenes with well-defined straight edges and planar surfaces (architectural elements, furniture, manufactured objects) [S1]. Performance on natural scenes may vary as the "Sketch" prior relies on geometric coherence along lines [S1].

## Operating characteristics
* **Storage Efficiency:** For an indoor scene, the model maintains visual quality with 7.9% of the original 3DGS model size [S1].
* **Visual Quality:** Achieves up to 11.52% improvement in PSNR, 1.83% in SSIM, and 19.20% in LPIPS at equivalent model sizes across diverse indoor and outdoor scenes [S1].
* **Strengths:** Significant reduction in storage requirements through compact encoding of Sketch Gaussians; improved visual fidelity at low bitrates compared to standard 3DGS or naive downsampling [S1].
* **Limitations:** Relies on the presence of extractable 3D lines; less effective in scenes lacking well-defined geometric structures (natural environments) [S1].
* **When to Use:** Man-made scenes with clear edges and planar surfaces where storage efficiency is critical [S1].
* **When Not to Use:** Natural scenes with complex, non-linear, or ambiguous boundaries where the Sketch/Patch separation is less distinct [S1].

## Background
* **Origin:** Proposed in the paper "Sketch and Patch: Efficient 3D Gaussian Representation for Man-Made Scenes" [S1].
* **History:** Developed as a response to the storage inefficiencies of 3D Gaussian Splatting, which generates vast numbers of Gaussians [S1]. While 3DGS achieves impressive visual fidelity, standard compression techniques like 3D downsampling or tiling are unsuitable due to the heterogeneous and interdependent nature of Gaussian attributes [S1].
* **Usage:** Applied to efficient storage, transmission, and rendering of 3D scenes, particularly in multimedia streaming applications [S1].
