# UniqueSplat
Also called: View-Conditioned 3D Gaussian Splatting

## Overview
UniqueSplat is a feed-forward 3D Gaussian Splatting method that generates dynamic Gaussian parameters conditioned on the query view, addressing the limitation of prior feed-forward methods that produce fixed Gaussians across all views [S1]. It distinguishes itself by using a dual-branch hypernetwork to inject both view-agnostic scene knowledge and view-specific geometric priors into the primary network, enabling accurate reconstruction of scene structures and realistic novel view synthesis [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $K$ sparse-view input images $I_c = \{I^i_c\}_{i=1}^K$, their camera projection matrices $P_c = \{P^i_c\}_{i=1}^K$, and $N$ target view projection matrices $P_t = \{P^i_t\}_{i=1}^N$ [S1].
*   **Outputs:** Rendered target view images $I_t = \{I^i_t\}_{i=1}^N$ [S1].

**Data Structures:**
*   **Learnable Embedding ($e_a$):** A fixed vector capturing generalizable features across views [S1].
*   **Weight Matrix ($W_a$):** Dimensions $R^{C_{out} \times C_{in}}$, generated by the view-agnostic hypernetwork [S1].
*   **Feature Volume ($F_p$):** Extracted by the primary network encoder, containing intrinsic view information [S1].
*   **Projected Features ($F_t$):** Features from input views projected onto the target view geometry [S1].
*   **View-Specific Embedding ($e_s$):** Derived from $F_t$, capturing specific view knowledge [S1].
*   **Weight Delta ($\Delta W$):** Dimensions $R^{C_{out} \times C_{in}}$, generated by the view-specific hypernetwork [S1].
*   **Fused Weight ($W_H$):** Dimensions $R^{C_{out} \times C_{in}}$, sum of $W_a$ and $\Delta W$ [S1].
*   **Gaussian Parameters:** Mean $\mu$, covariance $\Sigma$, opacity $\alpha$, and color $c$ [S1].

**Steps:**

1.  **View-Agnostic Branch Initialization:**
    Compute the view-agnostic weight matrix $W_a$ using a hypernetwork $H_a$ and the learnable embedding $e_a$ [S1]:
    $$ W_a = H_a(e_a), \quad W_a \in R^{C_{out} \times C_{in}} $$
    where $C_{in}$ and $C_{out}$ are the input and output dimensions of the target convolution layers in the primary network [S1].

2.  **Input Feature Extraction:**
    For each input image $I^i_c$ ($i=1 \dots K$), extract per-view features $F^i_c$ using a backbone encoder $E_H$ [S1]:
    $$ F^i_c = E_H(I^i_c), \quad I^i_c \in R^{H \times W \times 3} $$
    Collect these into $F_c = \{F^i_c\}_{i=1}^K$ [S1].

3.  **Primary Network Feature Encoding:**
    Encode the input images and their camera parameters using the primary network encoder $E_p$ to produce the feature volume $F_p$ [S1]:
    $$ F_p = E_p(I_c, P_c) $$
    where $I_c$ and $P_c$ represent the input images and their corresponding camera parameters [S1].

4.  **View-Specific Feature Projection:**
    For each target view $i$ ($i=1 \dots N$) with projection matrix $P^i_t = K_t[R_t | t_t]$, project the source features $F_c$ to align with the target view to get $F^i_t$ [S1]:
    $$ F^i_t = \text{Proj}(F_c, P_c, P^i_t) $$
    The projection details for a single target pixel $(u_t, v_t)$ are as follows [S1]:
    a. Convert pixel coordinates to normalized camera coordinates $p_t$:
       $$ p_t = K_t^{-1} \begin{bmatrix} u_t \\ v_t \\ 1 \end{bmatrix} $$
       where $p_t = [x_t, y_t, 1]^\top$ [S1].
    b. Map $p_t$ to world coordinates to get ray origin $o$ and direction $r$:
       $$ r = R_t^\top p_t, \quad o = t_t $$
       where $R_t$ and $t_t$ are the rotation and translation of the target view [S1].
    c. Define the ray in world coordinates:
       $$ x(\lambda) = o + \lambda r, \quad \lambda \in R $$
       [S1].
    d. Project the ray onto source views to obtain epipolar lines $p_c(\lambda)$:
       $$ p_c(\lambda) = P_c x(\lambda) = P_c(o + \lambda r) $$
       [S1].
    e. Express epipolar lines as a linear function $L = A p_t + b$, where:
       $$ A = K_c R_c R_t^\top $$
       $$ b = K_c(R_c t_t + t_c) $$
       Here, $A$ represents the relative rotation and $b$ encodes the relative translation between target and source views [S1].
    f. Uniformly sample $n$ points along the features between near and far planes. Compute a correlation matrix $C_{ij}$ to fuse projected features:
       $$ C_{ij}(M_1, M_2) = \frac{\langle M^i_1, M^j_2 \rangle}{\|M^i_1\| \|M^j_2\|} $$
       where $M^i_j$ is the $j$-th row of matrix $M_i$, $\langle \cdot, \cdot \rangle$ is the inner product, and $\|\cdot\|$ is the vector norm [S1].

5.  **View-Specific Embedding and Weight Generation:**
    Map the fused target view feature $F_t$ to an embedding $e_s$ using a function $\phi$ [S1]:
    $$ e_s = \phi(F_t) $$
    [S1].
    Process $e_s$ with a hypernetwork $H_s$ to generate the weight delta $\Delta W$ [S1]:
    $$ \Delta W = H_s(e_s), \quad \Delta W \in R^{C_{out} \times C_{in}} $$
    [S1].

6.  **Weight Fusion:**
    Fuse the view-agnostic weight $W_a$ and the view-specific weight delta $\Delta W$ to obtain the final weight matrix $W_H$ [S1]:
    $$ W_H = W_a + \Delta W, \quad W_H \in R^{C_{out} \times C_{in}} $$
    [S1].

7.  **Gaussian Parameter Prediction:**
    Inject the fused weights $W_H$ into the convolutional layers of the primary network's predictor. The predictor estimates the 3D Gaussian parameters $\mu, \Sigma, \alpha, c$ from the feature volume $F_p$ [S1]:
    $$ \mu, \Sigma, \alpha, c = D_{\text{Injected}}(F_p) $$
    [S1].

8.  **Rendering:**
    Render the target views $I_t$ using the predicted Gaussians $G$ and target projection matrices $P_t$ [S1]:
    $$ I_t = R(G, P_t) $$
    [S1].

**Parameters:**
*   $K$: Number of input sparse views.
*   $N$: Number of target views.
*   $n$: Number of points sampled along features between near/far planes.
*   $C_{in}, C_{out}$: Input and output dimensions of target convolution layers.

**Edge Cases and Pitfalls:**
*   **Precision:** The correlation matrix calculation involves normalization by vector norms; ensure numerical stability for near-zero norms [S1].
*   **Boundaries:** The projection `Proj` must handle pixels outside the source view boundaries (e.g., via masking or padding) [S1].
*   **Degenerate Input:** If input views are too sparse or have large baselines, the epipolar line approximation may fail to capture sufficient texture for correlation [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.

*   **Strengths:** Enables accurate reconstruction of scene structures by explicitly encoding scene geometry; produces more realistic and high-quality images by adapting Gaussians to each view query [S1].
*   **Limitations:** Relies on sparse-view inputs; performance depends on the quality of the epipolar line approximation and feature correlation [S1].
*   **When to use:** When high-fidelity novel view synthesis is required from sparse input views and view-dependent adaptation is beneficial [S1].
*   **When not to use:** When real-time performance is critical and the overhead of hypernetwork weight generation is prohibitive (implied by the complexity of the method) [S1].

## Background
UniqueSplat was proposed in the paper "UniqueSplat: View-Conditioned 3D Gaussian Splatting for Generalizable 3D Reconstruction" [S1]. It addresses the limitation of feed-forward methods that generate fixed Gaussians across all views, which fails to adapt to individual views [S1]. The method builds on hypernetworks, which are neural networks that generate weights for another network based on input embeddings [S1]. It is the first feed-forward Gaussian Splatting model to predict dynamic Gaussians across views [S1].
