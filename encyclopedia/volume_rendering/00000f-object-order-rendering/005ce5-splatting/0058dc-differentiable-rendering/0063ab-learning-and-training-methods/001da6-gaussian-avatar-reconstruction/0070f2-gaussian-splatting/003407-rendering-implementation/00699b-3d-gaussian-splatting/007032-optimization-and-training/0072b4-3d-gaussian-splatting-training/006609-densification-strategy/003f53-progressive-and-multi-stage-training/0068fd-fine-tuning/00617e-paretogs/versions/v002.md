# ParetoGS

Also called: ParetoGS: High-Quality Continuous-Budget 3D Gaussian Splatting with Sparse Adapted Anchors

## Overview
ParetoGS is a continuous-budget 3D Gaussian Splatting (3DGS) representation that decodes any Gaussian count $K$ from a single asset without separate optimization per budget [S1, unofficial]. It achieves this by constructing a small set of sparse, adapted budget anchors with persistent member identities, encoding their parameter changes relative to a full model in a residual atlas, and interpolating shared parameters while gradually activating entering members at runtime [S1, unofficial]. Unlike prefix-based or hierarchical methods that require fixed orderings or complex transformation modules, ParetoGS explicitly optimizes nested anchors and connects their aligned states, offering superior quality at low budgets compared to FlexGS and NanoGS [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   A fully trained 3DGS model with $N$ Gaussians, optimized using ImprovedGS for 30K iterations [S1, unofficial].
*   Target anchor budgets $K_j$ and scene data for calibration [S1, unofficial].

**Outputs:**
*   An ordered full model $\Theta_N$.
*   A layered residual atlas $\Delta_j$ storing parameter changes for each anchor $j$ relative to the full model [S1, unofficial].
*   Interval exponents $p$ and $q$ for each anchor interval [S1, unofficial].
*   Member-order metadata defining the global nested sequence [S1, unofficial].

### Data Structures

**Gaussian Parameter Vector:**
Each Gaussian $i$ is defined by $\theta_i = (x_i, s_i, r_i, o_i, c_i)$, where:
*   $x_i \in \mathbb{R}^3$: Position.
*   $s_i \in \mathbb{R}^3$: Log scale.
*   $r_i \in \mathbb{R}^4$: Raw rotation quaternion.
*   $o_i \in \mathbb{R}$: Opacity logit.
*   $c_i$: Spherical-harmonic coefficients [S1, unofficial].

**Residual Atlas:**
For each anchor $K_j$, the stored residual is $\Delta_j = \Theta_{K_j} - \Theta_N[1:K_j]$, where $\Theta_N$ is the full model parameter matrix ordered by the global member sequence. The full model ($K_M=N$) has zero residual and requires no additional state [S1, unofficial]. The atlas uses lossy encoding (quantization) for storage [S1, unofficial].

**Interval Metadata:**
Two scalar exponents $p$ and $q$ are stored per interval between anchors [S1, unofficial].

### Algorithm Steps

1.  **Full Model Training:** Train a 3DGS model for 30K iterations using ImprovedGS densification [S1, unofficial].
2.  **Anchor Schedule Definition:** Define 11 anchors spanning 0.1% to 100% of the full count $N$. Target counts are $K_j = \text{round}(N \rho_j)$ for $\rho_j \in \{0.001, 0.002, \dots, 0.512, 1\}$ [S1, unofficial].
3.  **Anchor Construction (Contraction):**
    *   Start from the current anchor (initially the Full model) [S1, unofficial].
    *   Contract to the next target budget $K_j$ using GNS for 15K–18K iterations. GNS adjusts regularization based on a linear opacity-decay trajectory, advances removal within a selection window, and uses a budget safeguard to retain exactly $K_j$ members [S1, unofficial].
    *   Disable densification during this phase [S1, unofficial].
    *   Hold membership fixed and continue optimizing pixel L1 and SSIM reconstruction losses until 25K iterations total for the stage [S1, unofficial].
    *   Record deletions to determine the entry order $\pi_{L \to U}$ for the reverse direction (lower to upper anchor) [S1, unofficial].
4.  **Member Correspondence:**
    *   Concatenate the smallest anchor with the entry sequences from subsequent contractions to form a global nested order [S1, unofficial].
    *   This order ensures $S(K_a) \subset S(K_b)$ for $K_a < K_b$ [S1, unofficial].
5.  **Residual Encoding:**
    *   Compute residuals $\Delta_j = \Theta_{K_j} - \Theta_N[1:K_j]$ for all non-full anchors [S1, unofficial].
    *   Encode the residuals using quantization rules (details in Appendix A of source) [S1, unofficial].
6.  **Interval Calibration:**
    *   For each interval between anchors $L$ and $U$, calibrate exponents $p$ and $q$ using 10 training views [S1, unofficial].
    *   Minimize reconstruction loss plus penalties for loss regressions and slope deviations at $t \in \{0.25, 0.5, 0.75\}$ [S1, unofficial].
    *   Store $p$ and $q$ for the interval [S1, unofficial].

### Formulas

**Budget-Conditioned Model:**
$$G(K) = \{(z_i, \theta_i(K)) \mid z_i \in S(K)\}, \quad |S(K)| = K$$
where $z_i$ is the persistent identity [S1, unofficial].

**Membership at Intermediate Budget:**
For $L < K < U$:
$$S(K) = S(L) \cup \pi_{L \to U}[1 : K - L]$$
The first $L$ members are from the lower anchor; the next $K-L$ are the first entries from the upper anchor's entry sequence [S1, unofficial].

**Shared Member Interpolation:**
For shared members $i \le L$:
$$t = \frac{K - L}{U - L}$$
$$\theta_i(K) = (1 - t^p)\theta_i(L) + t^p \theta_i(U)$$
where $p > 0$ controls the trajectory. $p=1$ is linear; $p<1$ approaches the upper state earlier; $p>1$ approaches it later [S1, unofficial].

**Entering Member Opacity Gating:**
For entering members $L < i \le K$:
$$a_i(K) = \text{clip}(t^q a_i(U), \epsilon, 1 - \epsilon)$$
where $a_i(U) = \sigma(o_i(U))$ is the upper-anchor opacity, $q > 0$ controls activation speed, $t^q$ is the normalized progress weight, and $\epsilon$ is a clipping epsilon [S1, unofficial].

### Pseudocode

```python
import math

def sigmoid(x):
    return 1.0 / (1.0 + math.exp(-x))

def clip(x, lo, hi):
    return max(lo, min(hi, x))

def logit(x):
    return math.log(x / (1.0 - x))

def restore_endpoint(K, full_model, residual):
    # Adds residual to the first K rows of the full model
    return [full_model[i] + residual[i] for i in range(K)]

def pareto_gs_decode(K, full_model, residual_atlas, exponents, member_order, anchor_budgets):
    """
    Decode a 3DGS model with exactly K Gaussians.
    
    Args:
        K: Target number of Gaussians.
        full_model: Parameter matrix Theta_N of the full model (list of lists).
        residual_atlas: List of encoded residuals Delta_j for each anchor.
        exponents: List of (p, q) tuples for each interval.
        member_order: Global nested order of member indices.
        anchor_budgets: List of anchor budget counts [K1, K2, ..., KM].
        
    Returns:
        Theta_K: Parameter matrix for K Gaussians.
    """
    # 1. Identify surrounding anchors L and U such that K_L <= K <= K_U
    L_idx = 0
    U_idx = len(anchor_budgets) - 1
    for i in range(len(anchor_budgets) - 1):
        if anchor_budgets[i] <= K <= anchor_budgets[i+1]:
            L_idx, U_idx = i, i+1
            break
            
    L = anchor_budgets[L_idx]
    U = anchor_budgets[U_idx]
    
    # 2. Restore endpoint parameters for L and U
    Theta_L = restore_endpoint(L, full_model, residual_atlas[L_idx])
    Theta_U = restore_endpoint(U, full_model, residual_atlas[U_idx])
    
    # 3. Determine membership S(K)
    shared_indices = member_order[0:L]
    entering_indices = member_order[L:K]
    
    Theta_K = []
    
    # 4. Interpolate shared members
    t = (K - L) / (U - L)
    p = exponents[L_idx][0]
    
    for i in range(L):
        theta_L_i = Theta_L[i]
        theta_U_i = Theta_U[i]
        theta_interp = [(1 - t**p) * theta_L_i[d] + (t**p) * theta_U_i[d] for d in range(len(theta_L_i))]
        Theta_K.append(theta_interp)
        
    # 5. Handle entering members
    q = exponents[L_idx][1]
    epsilon = 1e-4
    
    for j, idx in enumerate(entering_indices):
        theta_U_idx = Theta_U[L + j]
        o_U = theta_U_idx[3] # opacity logit index is 3 (x, s, r, o, c)
        a_U = sigmoid(o_U)
        
        t_q = t**q
        a_K = clip(t_q * a_U, epsilon, 1 - epsilon)
        o_K = logit(a_K)
        
        theta_K_entry = theta_U_idx.copy()
        theta_K_entry[3] = o_K
        Theta_K.append(theta_K_entry)
        
    return Theta_K
```

### Parameters
*   **Anchor Schedule:** 11 anchors, $\rho_j \in \{0.001, \dots, 1\}$ [S1, unofficial].
*   **Interpolation Exponent $p$:** Calibrated per interval. Default search grid in Appendix A [S1, unofficial].
*   **Opacity Gating Exponent $q$:** Calibrated per interval. $q > 0$ [S1, unofficial].
*   **Clipping Epsilon $\epsilon$:** Small value, e.g., $10^{-4}$ [S1, unofficial].
*   **Training Iterations:** 30K for Full model; 25K total per anchor stage [S1, unofficial].
*   **Precision:** FP16 for calibration residual anchor states; half precision for anchor coefficients and quantization scales [S1, unofficial].

### Edge Cases and Pitfalls
*   **Precision:** Quantization of residuals introduces encoding error. Anchor-budget requests incur this error, but interval decoding does not add further estimation error [S1, unofficial].
*   **Boundary Conditions:** At $K=L$, $t=0$, shared members use $\theta(L)$, and no entering members exist. At $K=U$, $t=1$, shared members use $\theta(U)$, and all $U-L$ members are entering with full opacity [S1, unofficial].
*   **Degenerate Input:** If $K$ is outside $[K_{min}, N]$, the method is undefined. The method assumes $N$ is the count of the fully trained model [S1, unofficial].

## Operating characteristics

**Time Complexity:**
*   **Offline Construction:** Mean offline time of ~10.3 minutes across 13 scenes, significantly faster than CLOD-3DGS (~35 min) and MGS (~74 min) [S1, unofficial].
*   **Runtime:** Parameter generation at runtime takes $O(K)$ work for fixed parameter dimension [S1, unofficial].

**Memory Complexity:**
*   **Storage:** Encoding reduces mean additional state from 390.0 MB to 85.7 MB across 13 scenes [S1, unofficial].
*   **FlexGS Module:** FlexGS-imp uses a fixed ~30 MB budget module [S1, unofficial].

**Performance:**
*   **Quality:** ParetoGS attains better average PSNR, SSIM, and LPIPS with fewer Gaussians than compared prefix methods at 10% of each method’s own full model across 13 scenes [S1, unofficial].
*   **Low Budgets:** At 1% budget, ParetoGS achieves 24.40 dB PSNR vs 18.84 dB for NanoGS-imp [S1, unofficial]. At 0.1% budget, ParetoGS achieves 21.15 dB PSNR, 0.580 SSIM, and 0.539 LPIPS, outperforming NanoGS-imp [S1, unofficial].
*   **Scaling:** Quality degrades gracefully with decreasing $K$, outperforming CLOD-3DGS and MGS at low retention ratios [S1, unofficial].

**Strengths:**
*   Continuous budget support without per-budget optimization [S1, unofficial].
*   High quality at very low budgets (0.1%) [S1, unofficial].
*   Compact storage overhead [S1, unofficial].

**Limitations:**
*   Requires initial full model training [S1, unofficial].
*   Encoding error from quantization [S1, unofficial].
*   Calibration required for each interval [S1, unofficial].

## Background

**Origin:**
ParetoGS was introduced by Xiaobin et al. [S1, unofficial]. The paper "ParetoGS: High-Quality Continuous-Budget 3D Gaussian Splatting with Sparse Adapted Anchors" presents the method as a solution to the inefficiency of pruning and re-optimizing for each budget in 3DGS [S1, unofficial].

**History and Development:**
The method builds on 3DGS (Kerbl et al., 2023) and ImprovedGS (Deng et al., 2026) [S1, unofficial]. It addresses limitations of existing scalable methods like FlexGS (Liu et al., 2025a), NanoGS (Xiong et al., 2026), and SCAR-GS (Revilla et al., 2026) by explicitly optimizing nested anchors and connecting their states [S1, unofficial].

**Usage:**
ParetoGS is used for efficient 3DGS representation where multiple resolution levels or budget constraints are required, such as in real-time rendering or streaming applications [S1, unofficial].
