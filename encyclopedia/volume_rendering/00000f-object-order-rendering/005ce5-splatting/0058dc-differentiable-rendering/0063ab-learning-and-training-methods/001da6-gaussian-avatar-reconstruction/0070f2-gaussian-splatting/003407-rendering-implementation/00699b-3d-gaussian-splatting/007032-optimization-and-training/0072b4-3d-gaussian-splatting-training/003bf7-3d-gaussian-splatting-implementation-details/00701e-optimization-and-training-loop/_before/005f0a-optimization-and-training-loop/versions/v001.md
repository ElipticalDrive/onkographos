# Optimization and Training Loop

Also called: 3D Gaussian Splatting Training Loop, Multi-View Regulated Gaussian Splatting, Bézier-boundary gradient approximation

## Overview
This family covers the iterative optimization processes used to reconstruct 3D scenes from 2D images using 3D Gaussian primitives. It solves the inverse problem of estimating Gaussian parameters (position, covariance, opacity, color) by minimizing the difference between rendered and ground-truth images via differentiable rendering [15139-3d-gaussian-splatting-training-loop.md]. It sets itself apart from standard rendering by treating the scene representation as a set of learnable parameters updated via gradient descent, with specific variants addressing gradient stability across multiple views [15783-multi-view-regulated-gaussian-splatting.md] or handling non-differentiable geometric boundaries [13137-b-zier-boundary-gradient-approximation.md].

## Shared principles
All methods in this family rely on a differentiable rendering pipeline that computes gradients of a loss function with respect to Gaussian parameters. The core optimization loop involves:
1.  **Initialization:** Starting from a sparse point cloud (e.g., Structure-from-Motion) or model vertices [15139-3d-gaussian-splatting-training-loop.md][15783-multi-view-regulated-gaussian-splatting.md].
2.  **Sampling:** Selecting training views to render [15139-3d-gaussian-splatting-training-loop.md][15783-multi-view-regulated-gaussian-splatting.md].
3.  **Rendering:** Projecting 3D Gaussians to 2D and alpha-blending to produce an image [15139-3d-gaussian-splatting-training-loop.md][15783-multi-view-regulated-gaussian-splatting.md].
4.  **Loss Computation:** Comparing the rendered image to the ground truth using a combination of L1 loss and D-SSIM loss [15139-3d-gaussian-splatting-training-loop.md][15783-multi-view-regulated-gaussian-splatting.md].
5.  **Backpropagation:** Computing gradients $\nabla \mathcal{L}$ with respect to Gaussian attributes [15139-3d-gaussian-splatting-training-loop.md].
6.  **Update:** Adjusting parameters using an optimizer, typically Adam [15139-3d-gaussian-splatting-training-loop.md].

The loss function is generally defined as:
$$ \mathcal{L} = (1 - \lambda) \mathcal{L}_{L1} + \lambda \mathcal{L}_{D-SSIM} $$
where $\lambda \approx 0.2$ [15139-3d-gaussian-splatting-training-loop.md][15783-multi-view-regulated-gaussian-splatting.md].

## Subtopics

### [3D Gaussian Splatting Training Loop](15139-3d-gaussian-splatting-training-loop.md)
The standard iterative optimization process using random view sampling and Adam optimizer. It is the baseline method for static scene reconstruction. Choose this for general-purpose 3DGS training.

### [Multi-View Regulated Gaussian Splatting](15783-multi-view-regulated-gaussian-splatting.md)
A strategy that aggregates gradients from multiple views per iteration to ensure multi-view consistency. It sets itself apart by summing gradients rather than averaging them, increasing update magnitude for jointly observed Gaussians. Choose this when multi-view consistency is critical or when single-view optimization leads to unstable gradients.

### [Bézier-boundary gradient approximation](13137-b-zier-boundary-gradient-approximation.md)
A technique for approximating gradients of discontinuous indicator functions with respect to Bézier curve control points. It sets itself apart by enabling backpropagation through non-differentiable geometric boundaries. Choose this when optimizing Gaussian shapes defined by discontinuous geometric constraints.

## Background
The 3D Gaussian Splatting training loop was introduced in the seminal work on 3D Gaussian Splatting [15139-3d-gaussian-splatting-training-loop.md]. It builds on the differentiable rendering framework established by prior splatting methods. The method has become the standard for fast, high-quality 3D scene reconstruction from multi-view images. Variants like MVGS and Bézier-boundary approximation address specific limitations regarding multi-view consistency and non-differentiable geometry, respectively.
