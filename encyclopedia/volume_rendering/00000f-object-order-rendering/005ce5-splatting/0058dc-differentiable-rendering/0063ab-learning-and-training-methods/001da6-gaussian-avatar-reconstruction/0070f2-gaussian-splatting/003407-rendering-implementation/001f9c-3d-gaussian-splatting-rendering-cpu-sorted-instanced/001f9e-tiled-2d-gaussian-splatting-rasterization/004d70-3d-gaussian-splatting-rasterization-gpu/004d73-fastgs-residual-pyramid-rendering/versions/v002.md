# FastGS Residual Pyramid Rendering

Also called: Laplacian pyramid accumulation, multi-scale Gaussian rendering

## Overview
FastGS Residual Pyramid Rendering is a multi-scale rendering technique that decomposes the target image into a Laplacian pyramid of Gaussian splats [S1, unofficial]. The coarsest level renders the base image, while subsequent levels render signed residuals (differences) that are upsampled and accumulated to reconstruct the final high-resolution image [S1, unofficial]. It sets itself apart from standard single-scale rasterization by allowing independent optimization and rendering of detail at different resolutions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A list of Gaussian models (`gaussians_list`) organized from coarsest (L0) to finest (L_{n-1}); a list of camera views; ground-truth images; a rasterization function (`render_fn`); and a pyramid processing module (`pyramid_func`) [S1, unofficial].
*   **Outputs:** A rendered image tensor; intermediate buffers for accumulated predictions and ground-truth residuals; and metadata including visibility filters and radii [S1, unofficial].

**Data Structures:**
*   `gaussians_list`: A list of Gaussian model objects containing 3D Gaussian parameters (means, covariances, opacities, spherical harmonics coefficients) [S1, unofficial].
*   `gt_gaussian_pyr_dict`: A dictionary mapping camera IDs to lists of ground-truth Gaussian pyramid levels [S1, unofficial].
*   `pred_accumulated_dict`: A dictionary mapping camera IDs to the accumulated prediction tensor at each stage [S1, unofficial].
*   `render_pkg`: A dictionary returned by `render_fn` containing: `'render'` (`torch.Tensor`, image), `'viewspace_points'` (`torch.Tensor`, shape `[N, 4]`, requires gradient), `'visibility_filter'` (`torch.Tensor`, indices where screen-space radii are greater than 0), `'radii'` (`torch.Tensor`, screen-space radii of splats), and `'accum_metric_counts'` (`torch.Tensor`, metric accumulation buffer) [S1, unofficial].

**Parameters:**
*   `pos_and_neg`: Boolean flag controlling output range. When `False`, the rasterizer outputs values clamped to `[0, 1]` [S1, unofficial]. When `True`, it outputs signed values in `[-1.0, 1.0]` to represent residuals [S1, unofficial].
*   `mult`: Scalar multiplier passed to `GaussianRasterizationSettings`, likely controlling opacity or scale weighting during rasterization [S1, unofficial].
*   `render_size`: Target resolution for the current stage, derived from the ground-truth pyramid level shape `gt_gau.shape[-2:]` [S1, unofficial].

**Numbered Steps:**
1.  Load Gaussian models from subfolders `L0` to `L_{n-1}` into `gaussians_list` [S1, unofficial].
2.  For each view, compute the ground-truth Gaussian pyramid: `gt_gaussian_pyr_dict[viewpoint_cam.uid] = [pyr_gpu[0]] + [lvl.detach().to(device) for lvl in pyr_gpu[1:]]`, where `pyr_gpu = pyramid_func.build_pyr_gaussian(viewpoint_cam.original_image.unsqueeze(0))` [S1, unofficial].
3.  Iterate `i_stage` from `0` to `len(gaussians_list) - 1` [S1, unofficial].
4.  Retrieve `gaussians = gaussians_list[-i_stage-1]` and `gt_gau = gt_gaussian_pyr_dict[viewpoint_cam.uid][-i_stage-1].squeeze(0)` [S1, unofficial].
5.  If `i_stage == 0`: render with `pos_and_neg=False`. Set `pred_accumulated = rendering`. Set `gt = gt_gau` [S1, unofficial].
6.  If `i_stage > 0`: render with `pos_and_neg=True`. Compute `upsampled = pyramid_func.get_upsampled([rendering.unsqueeze(0), pred_accumulated.unsqueeze(0)])`. Update `pred_accumulated = rendering + upsampled`. Normalize `rendering` to `[0, 1]` via `(rendering + 1.0) / 2.0`. Set `gt = gt_gau - upsampled`, then normalize to `[0, 1]` via `(gt + 1.0) / 2.0` [S1, unofficial].
7.  After each stage (except the last), prepare Gaussians for the next stage using inheritance or densification logic based on `pipe.inherit_state` (e.g., "keep_and_adc", "only_xyz", "with_state") [S1, unofficial].

**Pseudocode:**
```python
import torch

def render_fastgs_stage(view, gaussians, pipeline, background, opt, pyramid_func, gt_gau, pred_accumulated, i_stage, render_fn):
    render_size = gt_gau.shape[-2:]
    
    if i_stage == 0:
        render_pkg = render_fn(
            view, gaussians, pipeline, background, 
            opt.mult, render_size=render_size, pos_and_neg=False
        )
        rendering = render_pkg["render"]
        pred_accumulated = rendering
        gt = gt_gau
    else:
        render_pkg = render_fn(
            view, gaussians, pipeline, background, 
            opt.mult, render_size=render_size, pos_and_neg=True
        )
        rendering = render_pkg["render"]
        
        upsampled = pyramid_func.get_upsampled([
            rendering.unsqueeze(0), 
            pred_accumulated.unsqueeze(0)
        ]).squeeze(0)
        
        pred_accumulated = rendering + upsampled
        rendering = (rendering + 1.0) / 2.0
        gt = (gt_gau - upsampled + 1.0) / 2.0
        
    return rendering, pred_accumulated, gt

def fastgs_render_loop(gaussians_list, viewpoint_cams, pipeline, background, opt, pyramid_func, render_fn):
    device = viewpoint_cams[0].original_image.device
    gt_gaussian_pyr_dict = {}
    pred_accumulated_dict = {}
    
    for viewpoint_cam in viewpoint_cams:
        pyr_gpu = pyramid_func.build_pyr_gaussian(viewpoint_cam.original_image.unsqueeze(0))
        gt_gaussian_pyr_dict[viewpoint_cam.uid] = [pyr_gpu[0]] + [lvl.detach().to(device) for lvl in pyr_gpu[1:]]
        
    num_stages = len(gaussians_list)
    for i_stage in range(num_stages):
        gaussians = gaussians_list[-i_stage-1]
        
        for viewpoint_cam in viewpoint_cams:
            gt_gau = gt_gaussian_pyr_dict[viewpoint_cam.uid][-i_stage-1].squeeze(0)
            pred_accumulated = pred_accumulated_dict.get(viewpoint_cam.uid, None)
            
            rendering, pred_accumulated, gt = render_fastgs_stage(
                viewpoint_cam, gaussians, pipeline, background, opt, 
                pyramid_func, gt_gau, pred_accumulated, i_stage, render_fn
            )
            
            pred_accumulated_dict[viewpoint_cam.uid] = pred_accumulated
```

**Edge Cases and Pitfalls:**
*   **PyTorch Version Compatibility:** The `viewspace_points` tensor is initialized with `requires_grad=True`, but `retain_grad()` may fail on older PyTorch versions. The code uses a `try-except` block to handle this gracefully [S1, unofficial].
*   **Resolution Mismatch:** The `render_size` must match the shape of the current ground-truth pyramid level `gt_gau.shape[-2:]` to ensure correct upsampling and accumulation [S1, unofficial].
*   **Signed Values:** When `pos_and_neg=True`, the rasterizer outputs values in `[-1.0, 1.0]`. Failure to normalize these values to `[0, 1]` before loss computation will lead to incorrect gradients [S1, unofficial].
