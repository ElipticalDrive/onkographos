# Geometry-Driven Pruning Score


## Overview
A scoring mechanism to select a subset of $K$ Gaussians that preserves global structure and visual appearance using only intrinsic 3D attributes, avoiding expensive ray-pixel intersections [S1, unofficial]. It balances geometric coverage and appearance contribution by weighting normalized opacity and volume [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Set of $N$ 3D Gaussians, each defined by opacity $\alpha_i$, scale vector $\mathbf{s}_i = (s_{xi}, s_{yi}, s_{zi})$, and other attributes [S1, unofficial].
- Output: Indices of the top $K$ Gaussians with the highest scores [S1, unofficial].

**Data Structures:**
- Gaussian attributes are stored in arrays of size $N$ [G].

**Steps:**
1. Compute the raw volume $V_i$ for each Gaussian $i$:
   $$ V_i = \frac{4}{3} \pi s_{xi} s_{yi} s_{zi} $$
2. Compute the z-score normalized opacity $\nu(\alpha_i)$ and volume $\nu(V_i)$ across all $N$ Gaussians:
   $$ \nu(\alpha_i) = \frac{\alpha_i - \mu_\alpha}{\sigma_\alpha}, \quad \nu(V_i) = \frac{V_i - \mu_V}{\sigma_V} $$
   where $\mu_\alpha, \sigma_\alpha$ are the mean and standard deviation of all opacities, and $\mu_V, \sigma_V$ are the mean and standard deviation of all volumes [S1, unofficial].
3. Compute the pruning score $S_i$ for each Gaussian $i$:
   $$ S_i = \lambda_\alpha \cdot \nu(\alpha_i) + (1 - \lambda_\alpha) \cdot \nu(V_i) $$
4. Select the top $K$ Gaussians with the highest scores $S_i$ [S1, unofficial].

**Parameters:**
- $\lambda_\alpha \in [0, 1]$: Trade-off parameter controlling the balance between appearance (opacity) and spatial (volume) contribution. Typical value: $0.3$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- If $\sigma_\alpha$ or $\sigma_V$ is zero (all Gaussians have identical opacity or volume), z-score normalization is undefined. In this case, the normalized values are set to $0$ [G].
- The source does not specify handling for degenerate inputs or precision limits [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def geometry_driven_pruning_score(gaussians, K, lambda_alpha=0.3):
    """
    Select top K Gaussians based on geometry-driven pruning score.
    
    Args:
        gaussians: List of Gaussian objects with attributes:
            - alpha: float, opacity
            - scale: tuple (sx, sy, sz), scale vector
        K: int, number of Gaussians to select
        lambda_alpha: float, trade-off parameter (default 0.3)
        
    Returns:
        List of indices of the top K Gaussians
    """
    N = len(gaussians)
    if N == 0:
        return []
    
    # Extract attributes
    alphas = np.array([g.alpha for g in gaussians])
    scales = np.array([g.scale for g in gaussians])
    
    # Compute volumes
    volumes = (4.0 / 3.0) * np.pi * scales[:, 0] * scales[:, 1] * scales[:, 2]
    
    # Z-score normalization
    alpha_mean = np.mean(alphas)
    alpha_std = np.std(alphas)
    if alpha_std == 0:
        alpha_norm = np.zeros(N)
    else:
        alpha_norm = (alphas - alpha_mean) / alpha_std
        
    volume_mean = np.mean(volumes)
    volume_std = np.std(volumes)
    if volume_std == 0:
        volume_norm = np.zeros(N)
    else:
        volume_norm = (volumes - volume_mean) / volume_std
        
    # Compute scores
    scores = lambda_alpha * alpha_norm + (1 - lambda_alpha) * volume_norm
    
    # Select top K
    top_k_indices = np.argsort(scores)[::-1][:K]
    
    return top_k_indices.tolist()
```

## Subtopics

### [PointSplat](14667-pointsplat.md)
PointSplat is a geometry-driven prune-and-refine framework for 3D Gaussian Splatting (3DGS) that enables high-quality reconstruction of compact Gaussian sets without requiring per-scene optimization at deployment. It bridges the gap between Gaussian pruning and transformer refinement by using intrinsic 3D attributes for pruning and a dual-branch encoder for refinement. Unlike image-driven pruning methods (e.g., LightGaussians, PUP-3DGS, Speedy-Splat) that rely on 2D images and per-scene optimization, PointSplat uses only 3D attributes for pruning. Unlike SplatFormer, which concatenates all Gaussian parameters into a single feature vector causing appearance dominance due to high-dimensional spherical harmonics, PointSplat decouples geometry and appearance.

## Operating characteristics
- **Time and Memory Complexity:** Not given in the sources [S1, unofficial].
- **Performance:** Efficient as it avoids ray-pixel intersections required by image-driven methods [S1, unofficial].
- **Strengths:** Preserves global structure and visual appearance using only intrinsic 3D attributes [S1, unofficial]. Results remain stable across a range of $\lambda_\alpha$ values, demonstrating robustness [S1, unofficial].
- **Limitations:** Relies on z-score normalization, which may be sensitive to outliers in opacity or volume distributions [G].
- **When to use:** When pruning 3D Gaussians for compact representation without per-scene optimization, especially in transformer-based refinement frameworks like PointSplat [S1, unofficial].
- **When not to use:** Not given in the sources [S1, unofficial].

## Background
Introduced in the PointSplat framework for efficient geometry-driven pruning and transformer refinement [S1, unofficial]. It was developed to address the limitations of image-driven pruning methods that require expensive ray-pixel intersections and per-scene optimization [S1, unofficial]. The method leverages intrinsic 3D attributes to enable efficient pruning for transformer-based refinement [S1, unofficial].
