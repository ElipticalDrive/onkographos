# Geometry-Guided Appearance Modeling

Also called: Appearance module, GAM

## Overview
Geometry-Guided Appearance Modeling (GAM) is a method for predicting view-dependent colors in 3D Gaussian Splatting by conditioning the appearance on explicit geometric cues, such as surface normals and learned geometric features derived from a Signed Distance Field (SDF) [S1]. It solves the limitation of standard Spherical Harmonics (SH), which often fail to capture fine-grained geometric details and high-frequency reflections [S1]. Unlike its sibling [Spherical Harmonics Optimization](14206-spherical-harmonics-optimization.md), which relies on fixed basis functions, GAM replaces or augments SH with a geometry-conditioned Multi-Layer Perceptron (MLP) [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The centroid position $\mathbf{p}_k$ of a Gaussian $G_k$, the viewing direction $\mathbf{d}$, and the SDF-derived geometric features [S1].
*   **Output:** The RGB color $\mathbf{c}_k$ for the Gaussian [S1].

**Data Structures:**
1.  **SDF Module ($f_{sdf}$):** An MLP that takes a 3D position and outputs a scalar signed distance $s$ and a geometric feature vector $\mathbf{F}_{geo}$ [S1].
2.  **Appearance Module ($f_{rgb}$):** An MLP that takes geometric inputs and outputs the final color [S1].

**Numbered Steps:**
1.  **SDF Feature Extraction:** For each Gaussian centroid $\mathbf{p}_k$, query the SDF module to obtain the signed distance $s$ and the geometric feature vector $\mathbf{F}_{geo}$ [S1]:
    $$ (s, \mathbf{F}_{geo}) = f_{sdf}(\mathbf{p}_k) $$
2.  **Normal Computation:** Compute the surface normal $\mathbf{n}$ by taking the gradient of the SDF with respect to position [S1]:
    $$ \mathbf{n} = \nabla f_{sdf}(\mathbf{p}_k) $$
3.  **Color Prediction:** Feed the centroid position $\mathbf{p}_k$, viewing direction $\mathbf{d}$, the normal vector $\mathbf{n}$, and the geometric feature $\mathbf{F}_{geo}$ into the appearance MLP to produce the RGB color $\mathbf{c}_k$ [S1]:
    $$ \mathbf{c}_k = f_{rgb}(\mathbf{p}_k, \mathbf{d}, \mathbf{n}, \mathbf{F}_{geo}) $$

**Parameters:**
*   **Appearance MLP Architecture:** 4 layers, 256 hidden units, ReLU activation [S1].
*   **SDF MLP Architecture:** 8 layers, 256 hidden units, ReLU activation [S1].
*   **Training:** Optimized using Adam [S1].

**Pseudocode:**
```python
def compute_gradient(output, inputs, create_graph=True):
    """Standard autograd gradient computation."""
    return torch.autograd.grad(output, inputs, create_graph=create_graph)[0]

def concatenate(vectors):
    """Concatenate a list of tensors along the last dimension."""
    return torch.cat(vectors, dim=-1)

def geometry_guided_appearance(centroid: torch.Tensor, view_dir: torch.Tensor, sdf_mlp: torch.nn.Module, appearance_mlp: torch.nn.Module) -> torch.Tensor:
    """
    Predicts the RGB color of a Gaussian using geometry-guided appearance modeling.
    
    Args:
        centroid: The 3D position of the Gaussian center (pk).
        view_dir: The normalized viewing direction (d).
        sdf_mlp: The MLP representing fsdf, outputting (signed_distance, geometric_feature).
        appearance_mlp: The MLP representing frgb.
        
    Returns:
        The predicted RGB color vector (ck).
    """
    # Step 1: Extract SDF features
    # fsdf outputs a tuple: (signed_distance s, geometric_feature_vector F_geo)
    s, F_geo = sdf_mlp(centroid)
    
    # Step 2: Compute surface normal
    # The normal is the gradient of the SDF at the centroid.
    n = compute_gradient(s, centroid)
    
    # Step 3: Predict color
    # frgb takes position, view direction, normal, and geometric features
    ck = appearance_mlp(concatenate([centroid, view_dir, n, F_geo]))
    
    return ck
```

**Edge Cases and Pitfalls:**
*   **SDF Initialization:** The SDF is typically initialized as a sphere to promote robust convergence [S1].
*   **Training Delay:** SDF learning may be delayed (e.g., starting after 500 iterations) to stabilize the initial Gaussian distribution [S1].
*   **Opacity Bias:** When combined with opacity regularization forcing $\alpha \to 1$, the appearance MLP may "bake" internal volumetric transmission into high-frequency textures on the outer shell [S1].

## Operating characteristics
*   **Performance:** On the OmniObject3D dataset, removing GAM degrades PSNR from 40.06 to 39.19, SSIM from 0.986 to 0.984, and increases LPIPS from 0.025 to 0.031 [S1].
*   **Strengths:** Improves geometry reconstruction and rendering quality, particularly for reflective surfaces and fine geometric details where SH fails [S1].
*   **Limitations:** Requires maintaining and optimizing an additional SDF MLP, increasing memory and computational overhead compared to pure SH approaches [S1].

## Background
GAM is utilized in methods such as GSurf, which adapts 3D Gaussian Splatting for high-quality 3D reconstruction by learning SDFs from splatting opaque Gaussians [S1]. It addresses the observation that appearance modeling based solely on spatial position and viewing direction often fails to capture fine-grained geometry, a problem previously addressed in neural implicit surface methods by incorporating normals and geometric features [S1].
