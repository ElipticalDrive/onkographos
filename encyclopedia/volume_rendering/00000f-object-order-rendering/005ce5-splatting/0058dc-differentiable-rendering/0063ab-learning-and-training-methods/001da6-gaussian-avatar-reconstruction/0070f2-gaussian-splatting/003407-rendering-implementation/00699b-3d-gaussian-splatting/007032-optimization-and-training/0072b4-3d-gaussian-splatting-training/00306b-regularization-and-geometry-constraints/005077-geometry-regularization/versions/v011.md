# Geometry Regularization

Also called: Gaussian Flattening, Normal Consistency and Flattening

## Overview
Geometry regularization improves the structural integrity and smoothness of reconstructed surfaces in 3D Gaussian Splatting by constraining the geometric shape of the Gaussians, distinct from depth supervision which primarily constrains positional accuracy [S1, unofficial]. It addresses the issue of "floaters" and noisy geometry by enforcing two specific constraints: aligning the orientation of rendered depth normals with per-Gaussian normals, and flattening each Gaussian along its smallest axis to better approximate surface surfels [S1, unofficial]. This method builds on [Regularization and Geometry Constraints](6269-regularization-and-geometry-constraints.md) and is particularly useful for reducing artifacts in complex geometries where standard photometric loss alone leads to ambiguous depth estimates [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Per-Gaussian parameters (position $\mu$, scale $s \in \mathbb{R}^3$, rotation $q$, opacity $\alpha$); rendered depth map $D$; rendered normal map $N_{rendered}$; per-Gaussian normal estimates $N_{gauss}$ [S1, unofficial].
*   **Outputs:** Gradient updates for Gaussian parameters to minimize geometric inconsistency [G].

**Data Structures:**
*   `OptimizationParams`: A configuration struct containing the boolean flag `use_normal_loss` [S1, unofficial].
*   `Scaling Factor`: Vector $s \in \mathbb{R}^3$ representing the anisotropic scale of each Gaussian [S2, unofficial].

**Steps:**
1.  **Enable Regularization:** Set `use_normal_loss = true` in the optimization configuration [S1, unofficial].
2.  **Compute Rendered Normals:** Differentiably render the scene to obtain a normal map $N_{rendered}$ from the depth buffer [G].
3.  **Normal Consistency Loss:** Calculate the alignment between the rendered normal $N_{rendered}$ at each pixel and the corresponding per-Gaussian normal $N_{gauss}$ derived from the Gaussian's rotation matrix [S1, unofficial].
4.  **Flattening Loss:** For each Gaussian, identify the smallest component of the scaling vector $s$ and minimize this component towards zero during optimization [S2, unofficial].

**Formulas:**
Let $s_i \in \mathbb{R}^3$ be the scaling vector for Gaussian $i$. The flattening loss $\mathcal{L}_{flat}$ for a single Gaussian is:
$$
\mathcal{L}_{flat} = \min(s_{i,1}, s_{i,2}, s_{i,3})
$$
The total regularization loss combines normal consistency and flattening:
$$
\mathcal{L}_{reg} = \lambda_{norm} \mathcal{L}_{norm} + \lambda_{flat} \mathcal{L}_{flat}
$$
where $\mathcal{L}_{norm}$ measures alignment between $N_{rendered}$ and $N_{gauss}$, and $\lambda_{norm}, \lambda_{flat}$ are weighting factors [G].

**Parameters:**
*   `use_normal_loss`: Boolean flag to enable the feature [S1, unofficial].
*   $\lambda_{norm}, \lambda_{flat}$: Weights for normal consistency and flattening terms. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Depth Refitting:** Depth maps must be refitted against a prior point cloud to the correct scale before use. Depth maps that fail this refitting process are discarded and not used for supervision [S1, unofficial].
*   **Precision:** The minimization of the smallest scale component requires careful handling to prevent numerical instability when scales approach zero [G].

**Pseudocode:**
```python
def geometry_regularization_loss(gaussians, rendered_normals, params):
    """
    Computes geometry regularization loss for 3D Gaussian Splatting.
    
    Args:
        gaussians: List of Gaussian objects with attributes:
            - scale: s (R3 vector)
            - normal: n (R3 vector, derived from rotation q)
            - rendered_normal: nr (R3 vector, sampled from N_rendered)
        rendered_normals: Normal map N_rendered (H x W x 3)
        params: OptimizationParams with use_normal_loss (bool)
        
    Returns:
        loss: Scalar tensor representing the regularization loss
    """
    if not params.use_normal_loss:
        return 0.0

    loss = 0.0
    
    # Step 1: Flattening Loss
    # Minimize the smallest component of the scaling factor towards zero
    for g in gaussians:
        s = g.scale
        loss += min(s[0], s[1], s[2])
        
    # Step 2: Normal Consistency Loss
    # Align rendered normals with per-Gaussian normals
    for g in gaussians:
        n_gauss = g.normal
        n_rendered = g.rendered_normal
        # Alignment loss: 1 - dot product (maximizes cosine similarity)
        loss += 1.0 - max(0.0, dot(n_gauss, n_rendered))
        
    return loss
```

## Subtopics

### Scaling Loss for Geometry Modeling
A specific variant of geometry regularization that focuses exclusively on flattening Gaussian kernels into 3D surfels aligned with the surface [S2, unofficial]. It minimizes the smallest component of the scaling factor $s \in \mathbb{R}^3$ towards zero [S2, unofficial]. This aids in determining Gaussian normals by selecting the shortest scaled edge [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Adds overhead proportional to the number of Gaussians for computing scale minima and normal alignment [S1, unofficial][S2, unofficial].
*   **Memory Complexity:** Requires storage for rendered depth and normal maps, and intermediate buffers for normal consistency calculations [S1, unofficial].
*   **Strengths:** Significantly reduces "floaters" and improves surface smoothness and geometric coherence [S1, unofficial][S2, unofficial].
*   **Limitations:** May reduce the number of remaining points when combined with pruning, potentially compromising detail if not balanced with entropy loss [S2, unofficial]. Requires accurate depth refitting; failed refits are discarded, which may reduce supervision signal in sparse regions [S1, unofficial].
*   **When to use:** Not given in the sources.
*   **When not to use:** Not given in the sources.

## Background
Originating from community-driven optimizations in `GaussianSplatting.jl` and the `GauStudio` framework, this technique addresses the limitation of standard photometric loss, which often results in ambiguous geometry, by introducing explicit geometric constraints [S1, unofficial][S2, unofficial]. The concept of flattening Gaussians into surfels is inspired by earlier work on surface reconstruction using Gaussian kernels [S2, unofficial].
