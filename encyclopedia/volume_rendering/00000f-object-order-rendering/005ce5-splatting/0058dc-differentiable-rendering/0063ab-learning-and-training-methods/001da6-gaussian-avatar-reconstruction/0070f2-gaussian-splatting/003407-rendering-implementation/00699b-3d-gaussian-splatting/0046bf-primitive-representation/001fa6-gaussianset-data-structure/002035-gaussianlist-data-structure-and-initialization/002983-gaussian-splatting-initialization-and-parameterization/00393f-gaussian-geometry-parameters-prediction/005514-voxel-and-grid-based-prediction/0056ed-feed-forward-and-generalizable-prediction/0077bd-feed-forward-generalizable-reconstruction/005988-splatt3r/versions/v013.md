# Splatt3R

Also called: Splatt3R: Zero-Shot Gaussian Splatting from Uncalibrated Image Pairs

## Overview
Splatt3R is a feed-forward, pose-free method for 3D reconstruction and novel view synthesis that predicts 3D Gaussian primitives directly from a pair of uncalibrated natural images, without requiring camera intrinsics, extrinsics, or depth maps [S1, unofficial][S2]. It extends the MASt3R foundation model by adding a parallel "Gaussian head" to predict geometric offsets, covariances, opacities, and colors for each pixel [S1, unofficial]. Unlike existing generalizable 3D-GS methods that are limited to interpolating viewpoints between input stereo views, Splatt3R is designed to extrapolate to wider baselines using a novel loss masking strategy that prevents training updates from unseen or obscured scene regions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A pair of uncalibrated RGB images $I_1, I_2 \in \mathbb{R}^{H \times W \times 3}$ with resolution $512 \times 512$ [S1, unofficial].
*   **Output:** A set of 3D Gaussian primitives $\mathcal{G}$, defined by mean positions $\mu$, covariance matrices $\Sigma$ (parameterized by rotation $q$ and scale $s$), opacities $\alpha$, and colors $c$ (or spherical harmonics $S$) [S1, unofficial][S2].

**Data Structures:**
The method predicts per-pixel attributes. For each pixel $j$ in the image grid:
*   Base position $x_j \in \mathbb{R}^3$ (predicted by MASt3R backbone).
*   Position offset $\Delta x_j \in \mathbb{R}^3$.
*   Rotation quaternion $q_j \in \mathbb{R}^4$.
*   Scale vector $s_j \in \mathbb{R}^3$.
*   Opacity $\alpha_j \in \mathbb{R}$.
*   Color $c_j \in \mathbb{R}^3$ (constant view-independent color) or spherical harmonics coefficients [S1, unofficial][S2].

**Algorithm Steps:**

1.  **Feature Encoding:** Encode the input images $I_1, I_2$ using a shared Vision Transformer (ViT) encoder and cross-attention transformers. This backbone is based on MASt3R and is frozen during training [S1, unofficial].
2.  **Base Point Prediction:** Use the frozen MASt3R backbone to predict 3D point locations $\hat{X}_1, \hat{X}_2$ and confidence maps $C_1, C_2$ in the coordinate frame of the first image [S1, unofficial].
3.  **Gaussian Parameter Prediction:** Pass the encoded features through a parallel "Gaussian head" (using DPT architecture) to predict the residual attributes for each pixel: offsets $\Delta$, rotations $q$, scales $s$, opacities $\alpha$, and spherical harmonics $S$ [S1, unofficial].
4.  **Parameter Activation:** Apply specific activation functions to ensure valid parameter ranges:
    *   Normalization for quaternions $q$.
    *   Exponential activation for scales $s$ and offsets $\Delta$.
    *   Sigmoid activation for opacities $\alpha$ [S1, unofficial].
5.  **Primitive Construction:** Compute the final Gaussian mean $\mu_j$ and covariance $\Sigma_j$ for each pixel $j$:
    $$ \mu_j = x_j + \Delta x_j $$
    $$ \Sigma_j = R(q_j) S(s_j) S(s_j)^T R(q_j)^T $$
    where $R(q)$ is the rotation matrix derived from quaternion $q$, and $S(s)$ is the diagonal scaling matrix [S1, unofficial][S2].
6.  **Union of Primitives:** Construct the final set of Gaussian primitives as the union of primitives predicted from both input images $I_1$ and $I_2$ [S1, unofficial].
7.  **Rendering:** Render the novel view using standard 3D Gaussian Splatting rasterization [S1, unofficial].

**Training Procedure:**
Training is performed in two stages [S1, unofficial]:
1.  **Geometry Loss:** Optimize the 3D point cloud's geometry using the MASt3R point prediction head (which is not frozen if training from scratch, but the backbone weights are initialized from MASt3R). The loss is a confidence-based regression loss $L_{pts}$ handling ill-defined depths [S1, unofficial].
2.  **Novel View Synthesis (NVS) Loss:** Optimize the Gaussian head parameters to minimize rendering errors on target views.

**Loss Masking:**
To enable extrapolation beyond the stereo baseline, a loss mask $M$ is calculated for each target image [S1, unofficial]:
1.  Unproject target image points to 3D.
2.  Reproject these points onto the context images ($I_1, I_2$).
3.  Check if the reprojected pixel is inside the frustum of at least one context view.
4.  Check if the rendered depth matches the ground truth depth within a tolerance.
5.  Set $M_{ij} = 1$ if valid, $0$ otherwise.

The total loss is:
$$ L = \lambda_{MSE} L_{MSE}(M \odot \hat{I}, M \odot I) + \lambda_{LPIPS} L_{LPIPS}(M \odot \hat{I}, M \odot I) $$
where $\hat{I}$ is the rendered image and $I$ is the ground truth target image [S1, unofficial].

**Sampling Constraints:**
During training, context images are selected such that at least $\phi\%$ of pixels in the second image have correspondences in the first, and target images are selected such that at least $\psi\%$ of pixels are present in at least one context image [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class Splatt3R:
    def __init__(self, backbone, gaussian_head):
        """
        Initialize Splatt3R.
        backbone: Frozen MASt3R encoder (ViT + Cross-Attention).
        gaussian_head: DPT-based decoder predicting Gaussian attributes.
        """
        self.backbone = backbone
        self.gaussian_head = gaussian_head
        self.backbone.eval() # Frozen during NVS training
        
    def forward(self, I1, I2):
        """
        Predict 3D Gaussians from uncalibrated image pair.
        Args:
            I1, I2: Tensor [B, 3, H, W]
        Returns:
            Gaussians: List of parameters for 3D Gaussian Splatting
        """
        # 1. Encode images using frozen MASt3R backbone
        with torch.no_grad():
            features, base_points, confidences = self.backbone(I1, I2)
            
        # 2. Predict Gaussian attributes using Gaussian Head
        # Outputs: offsets, rotations, scales, opacities, harmonics
        offsets = self.gaussian_head.predict_offsets(features)
        rotations = self.gaussian_head.predict_rotations(features)
        scales = self.gaussian_head.predict_scales(features)
        opacities = self.gaussian_head.predict_opacities(features)
        harmonics = self.gaussian_head.predict_harmonics(features)
        
        # 3. Apply activation functions
        # Normalization for quaternions
        rotations = F.normalize(rotations, dim=-1)
        # Exponential for scales and offsets
        scales = torch.exp(scales)
        offsets = torch.exp(offsets) # Or softplus, source says exponential
        # Sigmoid for opacities
        opacities = torch.sigmoid(opacities)
        
        # 4. Construct Gaussians
        # base_points are in the coordinate frame of I1
        means = base_points + offsets
        
        # Covariance from rotation and scale
        # R(q) * S(s) * S(s)^T * R(q)^T
        covariances = self.compute_covariance(rotations, scales)
        
        # 5. Union of Gaussians from both views
        # Note: The backbone predicts points for both I1 and I2 frames.
        # The Gaussian head attributes are predicted in the frame of I1.
        # We must transform I2's Gaussians to I1's frame or handle union carefully.
        # Source states: "The final set of Gaussian primitives is the union of the 
        # Gaussian primitives predicted from both images."
        # And: "predicted covariances and spherical harmonics are considered as 
        # being in the first image’s camera frame."
        
        gaussians_I1 = {
            'means': means_I1,
            'covs': covariances_I1,
            'opacities': opacities_I1,
            'colors': harmonics_I1
        }
        
        # For I2, we need to transform the base points to I1's frame?
        # MASt3R predicts X_hat_1 and X_hat_2 in I1's frame.
        # So base_points from backbone are already aligned.
        gaussians_I2 = {
            'means': means_I2,
            'covs': covariances_I2,
            'opacities': opacities_I2,
            'colors': harmonics_I2
        }
        
        return self.union_gaussians(gaussians_I1, gaussians_I2)

    def compute_covariance(self, q, s):
        """
        Compute covariance matrix from quaternion q and scale s.
        q: [B, H, W, 4]
        s: [B, H, W, 3]
        Returns: [B, H, W, 3, 3]
        """
        # Convert quaternion to rotation matrix R
        R = quaternion_to_rotation_matrix(q)
        # Scale matrix S
        S = torch.diag_embed(s)
        # Sigma = R S S^T R^T
        Sigma = R @ S @ S.transpose(-2, -1) @ R.transpose(-2, -1)
        return Sigma

    def compute_loss_mask(self, target_depth, target_pose, context_depths, context_poses):
        """
        Compute loss mask M for novel view supervision.
        """
        # Unproject target points
        target_points_3d = unproject_depth(target_depth, target_pose)
        
        # Reproject to context views
        reprojected_coords = []
        valid_depths = []
        
        for context_depth, context_pose in zip(context_depths, context_poses):
            # Project to context view
            coords, depths = project_to_view(target_points_3d, context_pose, target_pose)
            
            # Check frustum (coords within HxW)
            in_frustum = (coords[..., 0] >= 0) & (coords[..., 0] < H) & \
                         (coords[..., 1] >= 0) & (coords[..., 1] < W)
            
            # Check depth consistency
            # Sample context depth at coords
            ctx_depth = sample_depth(context_depth, coords)
            depth_match = torch.abs(depths - ctx_depth) < threshold
            
            valid = in_frustum & depth_match & (ctx_depth > 0)
            reprojected_coords.append(coords)
            valid_depths.append(valid)
            
        # Union of valid pixels across contexts
        M = torch.zeros_like(target_depth)
        for valid in valid_depths:
            M = M | valid
            
        return M

    def train_step(self, I1, I2, target_images, target_depths, target_poses, 
                   context_depths, context_poses):
        """
        Single training step.
        """
        # Forward pass
        gaussians = self.forward(I1, I2)
        
        # Render target view
        rendered_image = render_gaussians(gaussians, target_poses)
        
        # Compute loss mask
        M = self.compute_loss_mask(target_depths, target_poses, 
                                   context_depths, context_poses)
        
        # Compute losses
        mse_loss = F.mse_loss(rendered_image * M, target_images * M)
        lpips_loss = lpips_loss_fn(rendered_image * M, target_images * M)
        
        # Weighted sum
        loss = lambda_mse * mse_loss + lambda_lpips * lpips_loss
        
        # Backward pass
        loss.backward()
        return loss
```

## Operating characteristics
*   **Time Complexity:** The method is feed-forward, requiring a single forward pass of the network. Construction/export runtime is approximately 1.10 seconds on ScanNet++ with 2 views [S2].
*   **Memory Complexity:** Not explicitly given, but it stores per-pixel Gaussians for two images, resulting in $2 \times H \times W$ primitives [S1, unofficial].
*   **Performance:** On ScanNet++ test scenes with Close view overlap ($\phi=0.9, \psi=0.9$), Splatt3R achieves PSNR 19.66, SSIM 0.757, LPIPS 0.234 [S1, unofficial]. With 2 views, it achieves PSNR 23.30, SSIM 0.823, LPIPS 0.125 [S2].
*   **Strengths:** Pose-free operation; generalizes to uncalibrated, in-the-wild images; supports extrapolation beyond stereo baseline via loss masking; fast inference [S1, unofficial].
*   **Limitations:** Performance degrades with wider baselines (lower $\phi, \psi$) [S1, unofficial]; relies on ground truth depth/poses during training for loss masking [S1, unofficial]; constant view-independent color used in main experiments, limiting view-dependent effects [S1, unofficial].
*   **When to use:** When camera parameters are unknown and per-scene optimization is prohibitive.
*   **When not to use:** When high-fidelity view-dependent effects are required without ablation; when very wide baselines are needed (performance drops significantly) [S1, unofficial].

## Background
Splatt3R was introduced in 2024 by Brandon, Zheng, Iro, and Victor from the University of Oxford [S1, unofficial]. It builds upon the MASt3R foundation model for 3D geometry reconstruction [S1, unofficial]. The method addresses the limitation of existing generalizable 3D-GS methods (like pixelSplat and MVSplat) that are restricted to interpolating viewpoints between input stereo views [S1, unofficial]. By extending MASt3R with a Gaussian prediction head and a loss masking strategy, Splatt3R enables zero-shot Gaussian splatting from uncalibrated image pairs [S1, unofficial][S2]. It is trained on the ScanNet++ dataset [S1, unofficial].
