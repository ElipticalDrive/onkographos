# Data Compression and Storage Optimization

Also called: 3DGS Compression, Gaussian Quantization, Codebook-Based Compression

## Overview
This family of methods reduces the memory footprint and storage size of 3D Gaussian Splatting (3DGS) models by compressing geometric attributes (position, scale, rotation), opacity, and view-dependent color (Spherical Harmonics coefficients) [S1, S2, unofficial]. It addresses the high memory overhead of unbounded scenes and high-order SH representations, which hinder mobile deployment and large-scale storage [S1, S2, unofficial]. Unlike [Hardware and Computational Acceleration](16214-hardware-and-computational-acceleration.md) which optimizes runtime throughput, these methods optimize data density. Key distinctions include [ASCII-Based Data Compression](11820-ascii-based-data-compression.md) for training-time transmission, [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md) for post-training codebook quantization, [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md) for structural grid-based compression, and [Monte Carlo Specular Energy Aggregator](15439-monte-carlo-specular-energy-aggregator.md) for SH degree reduction [S1, S2, unofficial].

## Shared principles
All methods operate on the set of $N$ 3D Gaussians $\{G_i\}_{i=1}^N$ defined in [Rendering Implementation and Acceleration](21069-rendering-implementation-and-acceleration.md). The core optimization targets the following attribute sets:
1.  **Geometric Attributes:** Position $\mathbf{p}_i \in \mathbb{R}^3$, scale $\mathbf{s}_i \in \mathbb{R}^3$, and rotation $\mathbf{r}_i$ (quaternion).
2.  **Appearance Attributes:** Opacity $\alpha_i \in [0, 1]$ and Spherical Harmonics (SH) coefficients $c_i \in \mathbb{R}^{(L+1)^2 \times 3}$.

Common strategies include:
*   **Vector Quantization (VQ):** Mapping continuous attributes to discrete indices in a codebook [S1, S2, unofficial].
*   **Pruning:** Discarding Gaussians with low contribution scores (volume $\times$ opacity) [S1, S2, unofficial].
*   **Degree Reduction:** Lowering the SH order $L$ from 3 to 1 or 2, often requiring enhancement networks to preserve high-frequency details [S1, S2, unofficial].
*   **Entropy Coding:** Applying lossless compression (e.g., DEFLATE) to the final integer indices and residuals [S1, S2, unofficial].

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
Accelerates data transmission during training (e.g., `densify_and_prune`) by encoding numerical values into ASCII strings using base-95 and base-94 schemes. It targets color matrix optimization by limiting precision to one decimal place.

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
Reduces storage by clustering SH coefficients and shape parameters into compact codebooks, guided by a sensitivity measure derived from training image gradients. It preserves high-sensitivity parameters by adding them directly to the codebook rather than clustering them.

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
Compresses models by replacing per-Gaussian attributes with a grid-based neural field for color and a codebook for geometry, combined with a learnable volume-based mask for pruning. It achieves over 25× storage reduction by exploiting spatial redundancy.

### [Monte Carlo Specular Energy Aggregator](15439-monte-carlo-specular-energy-aggregator.md)
Compresses high-order (e.g., 3rd) SH coefficients into a lower-order (e.g., 1st) representation by aggregating specular energy magnitude and direction via Monte Carlo integration. It uses an MLP to map these latents to low-order coefficients, preserving specular features without distillation.

#### Sparse Adaptive Scalable Compact Gaussian Splatting
A compression method that utilizes vector clustering to encode color and geometric attributes into two separate codebooks, employing a sensitivity-aware k-means algorithm to prioritize important features [S1, unofficial].

#### 3DGS Quantization Compression
Reduces storage footprint by quantizing per-Gaussian attributes: position and scales are stored as FP16, opacity as INT8, and SH coefficients as INT8 or via codebooks, achieving ~10× smaller sizes [S2, unofficial].

## Background
3D Gaussian Splatting models typically require significant VRAM and storage due to the large number of primitives and high-dimensional SH coefficients [S1, S2, unofficial]. Early compression efforts focused on post-training quantization and codebook-based storage [S2, unofficial]. Recent advances integrate compression into the training process, such as C3DGS's grid-based representation and MC-SEA's SH aggregation, to enable efficient deployment on mobile devices and large-scale streaming [S1, S2, unofficial].
