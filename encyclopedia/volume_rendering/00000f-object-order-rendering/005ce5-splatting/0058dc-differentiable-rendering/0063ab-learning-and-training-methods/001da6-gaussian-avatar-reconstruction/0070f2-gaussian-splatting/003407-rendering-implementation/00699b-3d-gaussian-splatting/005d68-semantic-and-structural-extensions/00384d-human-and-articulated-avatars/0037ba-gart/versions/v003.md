# GART

Also called: GART, A method that extends the human to more articulated models (e.g, animals) based on the 3DGS representation

## Overview
GART is a 3D Gaussian Splatting extension designed to generalize articulated avatar reconstruction beyond humans to other articulated models, such as animals [S1][S2, unofficial]. It builds on [Human and Articulated Avatars](8209-human-and-articulated-avatars.md) by adapting the canonical space deformation framework to non-human skeletal structures. Unlike [GaussianHead](8051-gaussianhead.md) which focuses on facial details, or [D3GA](8094-d3ga.md) which may target specific dynamic aspects, GART specifically addresses the broader class of articulated non-human meshes.

## How it works
The method relies on the shared principles of the parent family: 3D Gaussians are initialized in a canonical reference pose (e.g., neutral T-pose or standard animal stance) and deformed to target poses via differentiable mapping [S1][S2, unofficial].

**Inputs and Outputs:**
*   **Inputs:** Multi-view images of the articulated model in various poses; a template mesh or skeleton definition for the non-human model; camera parameters.
*   **Outputs:** A set of 3D Gaussians with attributes (position, covariance, opacity, spherical harmonics) and deformation parameters (e.g., skinning weights or pose-dependent transformations) that allow rendering of the model in arbitrary poses.

**Data Structures:**
*   **Canonical Gaussians:** Defined in the rest pose. Attributes include mean $\mu_0$, covariance $\Sigma_0$, opacity $\alpha$, and color coefficients $c$.
*   **Deformation Parameters:** Mappings from canonical space to posed space. For non-human models, this requires a generalized skinning or deformation field compatible with the specific skeletal hierarchy (e.g., quadruped vs. biped) [S1][S2, unofficial].

**Steps:**
1.  **Initialization:** Initialize 3D Gaussians in the canonical pose of the target articulated model (e.g., animal rest pose) [S1][S2, unofficial].
2.  **Pose Parameterization:** Define the target pose using skeletal joint angles or pose parameters specific to the non-human model [S1][S2, unofficial].
3.  **Deformation:** Map canonical Gaussians to the posed space. This involves transforming the Gaussian means and covariances based on the pose. The specific deformation function is adapted from human-centric methods to accommodate the topology of the target model (e.g., animals) [S1][S2, unofficial].
4.  **Rendering:** Render the posed Gaussians using standard differentiable rasterization (splatting) [S1][S2, unofficial].
5.  **Optimization:** Minimize photometric loss between rendered images and ground truth multi-view images to optimize Gaussian attributes and deformation parameters [S1][S2, unofficial].

**Formulas:**
*   The transformation of a Gaussian from canonical mean $\mu_0$ to posed mean $\mu_p$ is typically defined by a deformation function $D(\cdot)$:
    $$ \mu_p = D(\mu_0, \theta) $$
    where $\theta$ represents the pose parameters [S1][S2, unofficial].
*   The covariance transformation follows similar rigid or affine transformations based on the pose [S1][S2, unofficial].

**Parameters:**
*   Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Topology Differences:** The method must handle skeletal structures different from humans (e.g., tails, wings, four legs). The deformation logic must be generalized [S1][S2, unofficial].
*   **Precision:** Standard 3DGS precision issues apply (e.g., floating point errors in splatting) [S1][S2, unofficial].

## Subtopics

### Generalized Articulation
What it is: Adapting the deformation pipeline to non-human skeletons. What sets it apart: Focuses on animals and other articulated models rather than just humans. When to choose: When reconstructing non-human articulated avatars. Link: [Human and Articulated Avatars](8209-human-and-articulated-avatars.md).

## Operating characteristics
*   **Time and Memory Complexity:** Inherits the complexity of 3D Gaussian Splatting. Real-time rendering is achievable. Memory usage depends on the number of Gaussians required to represent the non-human model's geometry and appearance [S1][S2, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales with the complexity of the articulated model and the number of Gaussians.
*   **Strengths:** Extends the high-quality, real-time rendering of 3DGS to a broader class of articulated models.
*   **Limitations:** Requires appropriate template/skeleton definition for the non-human model. Performance may vary depending on the complexity of the animal's topology compared to humans.
*   **When to use:** For animatable, high-fidelity rendering of non-human articulated models (e.g., animals) from multi-view images.
*   **When not:** For static objects or non-articulated models where simpler methods suffice.

## Background
GART was introduced in the context of recent advances in 3D Gaussian Splatting. It is cited as a method that extends the human-focused 3DGS representations to more articulated models, such as animals [S1][S2, unofficial]. The paper "Recent advances in 3D Gaussian splatting" discusses GART alongside other methods like GPS-Gaussian, Animatable Gaussians, Gaussian Shell Maps, and ASH, highlighting the trend of extending 3DGS to various articulated and dynamic scenarios [S1][S2, unofficial].
