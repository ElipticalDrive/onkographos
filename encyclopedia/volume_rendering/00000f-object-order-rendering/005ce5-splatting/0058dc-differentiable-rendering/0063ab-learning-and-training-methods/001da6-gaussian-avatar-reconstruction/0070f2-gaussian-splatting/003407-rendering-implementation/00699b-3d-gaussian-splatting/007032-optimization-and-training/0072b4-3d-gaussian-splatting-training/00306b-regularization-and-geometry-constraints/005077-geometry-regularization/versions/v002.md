# Geometry Regularization

Also called: Gaussian Flattening, Normal Consistency and Flattening

## Overview
Geometry regularization improves the geometric plausibility and smoothness of 3D Gaussian Splatting scenes by constraining the shape and orientation of the Gaussian kernels, distinct from depth supervision which only constrains their location [S1, S2, unofficial]. It sets itself apart from sibling methods like [Hard and Soft Depth Regularization](9178-hard-and-soft-depth-regularization.md) by enforcing structural priors (flattening and normal alignment) rather than purely positional consistency, and from [Frequency Regularization](6130-frequency-regularization.md) by operating in the spatial domain to reduce floaters and improve surface coherence [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Per-Gaussian parameters (position $\mathbf{p}$, scaling vector $\mathbf{s} \in \mathbb{R}^3$, rotation quaternion $\mathbf{q}$, opacity $\alpha$, spherical harmonics coefficients), rendered depth map $D$, and optionally a normal map $N$ derived from $D$.
*   **Outputs:** Gradient updates to Gaussian parameters that penalize non-planar shapes and misaligned normals.

**Data Structures:**
*   **Gaussian State:** Each Gaussian $i$ is defined by position $\mathbf{p}_i$, scaling $\mathbf{s}_i = [s_{i,x}, s_{i,y}, s_{i,z}]^T$, rotation $\mathbf{q}_i$, and opacity $\alpha_i$. The covariance matrix $\Sigma_i$ is constructed as $\Sigma_i = R_i S_i S_i^T R_i^T$, where $R_i$ is the rotation matrix from $\mathbf{q}_i$ and $S_i = \text{diag}(\mathbf{s}_i)$ [S2, unofficial].
*   **Rendered Data:** Depth map $D(u,v)$ and normal map $N(u,v)$ at pixel coordinates $(u,v)$.

**Parameters:**
*   `use_normal_loss`: Boolean flag to enable geometry regularization [S1, unofficial].
*   $\lambda_{flat}$: Weight for the flattening loss. Not given in the sources.
*   $\lambda_{norm}$: Weight for the normal consistency loss. Not given in the sources.

**Steps:**
1.  **Depth Normal Consistency:** Render the depth map $D$ and compute the surface normal map $N$ from $D$. For each pixel $(u,v)$, retrieve the corresponding Gaussian $i$ that contributes most to the color/depth. Compute the per-Gaussian normal $\mathbf{n}_i$ from its covariance matrix (typically the eigenvector corresponding to the smallest eigenvalue, or derived from the rotation matrix). Enforce alignment between $\mathbf{n}_i$ and $N(u,v)$ [S1, S2, unofficial].
2.  **Flattening Surface:** For each Gaussian, identify the smallest component of the scaling vector $\mathbf{s}_i$. Minimize this component towards zero to flatten the Gaussian into a surfel aligned with the surface [S2, unofficial].

**Formulas:**
*   **Flattening Loss:** Let $s_{min} = \min(s_{x}, s_{y}, s_{z})$. The loss encourages $s_{min} \to 0$:
    $$ \mathcal{L}_{flat} = \sum_{i} s_{min, i} $$
    [S2, unofficial]
*   **Normal Consistency Loss:** Let $\mathbf{n}_i$ be the Gaussian normal and $\mathbf{n}_{rendered}$ be the normal from the depth map. The loss minimizes the angle between them:
    $$ \mathcal{L}_{norm} = \sum_{i} (1 - \mathbf{n}_i \cdot \mathbf{n}_{rendered}) $$
    [S1, S2, unofficial]

**Pseudocode:**
```python
def geometry_regularization_loss(gaussians, rendered_depth, rendered_normals, lambda_flat=1.0, lambda_norm=1.0):
    """
    Computes geometry regularization loss for 3D Gaussians.
    
    Args:
        gaussians: List of Gaussian objects with attributes:
            - s: scaling vector (R3)
            - q: rotation quaternion
            - p: position (R3)
        rendered_depth: Depth map (H, W)
        rendered_normals: Normal map (H, W, 3)
        lambda_flat: Weight for flattening loss
        lambda_norm: Weight for normal consistency loss
        
    Returns:
        Total loss scalar
    """
    loss_flat = 0.0
    loss_norm = 0.0
    
    # Note: In practice, this requires a differentiable rasterizer to map 
    # pixels back to contributing Gaussians. This pseudocode assumes 
    # we have access to the list of Gaussians contributing to each pixel.
    # If not, this step is implemented via the rasterizer's backward pass.
    
    for pixel_u, pixel_v in all_pixels:
        # Get contributing Gaussians for this pixel (from rasterizer)
        contributing_gaussians = get_contributing_gaussians(pixel_u, pixel_v, gaussians)
        
        if not contributing_gaussians:
            continue
            
        # Get rendered normal for this pixel
        n_rendered = rendered_normals[pixel_v, pixel_u]
        
        for g in contributing_gaussians:
            # 1. Flattening Loss: Minimize smallest scale component
            s = g.s
            s_min = min(s[0], s[1], s[2])
            loss_flat += s_min
            
            # 2. Normal Consistency Loss
            # Compute Gaussian normal from rotation/shape
            # Normal is typically the eigenvector of covariance with smallest eigenvalue
            # Or simply the z-axis of the rotation matrix if aligned
            R = quaternion_to_rotation_matrix(g.q)
            n_gaussian = R[:, 2] # Assuming z-axis is the normal direction
            
            # Dot product similarity
            dot_product = dot(n_gaussian, n_rendered)
            # Clamp to avoid numerical issues
            dot_product = clamp(dot_product, -1.0, 1.0)
            loss_norm += (1.0 - dot_product)
            
    total_loss = lambda_flat * loss_flat + lambda_norm * loss_norm
    return total_loss
```

## Subtopics

### Scaling Loss for Geometry Modeling
A specific instance of geometry regularization that focuses exclusively on flattening Gaussian kernels into 3D surfels by minimizing the smallest component of the scaling factor $\mathbf{s} \in \mathbb{R}^3$ towards zero [S2, unofficial]. This aids in determining Gaussian normals by selecting the shortest scaled edge. It is chosen when the primary goal is to enforce planar surface structures without necessarily enforcing strict normal alignment with a rendered depth map [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Adds $O(N)$ overhead per training step, where $N$ is the number of Gaussians, for computing scaling and normal terms. The depth normal computation is $O(H \times W)$ but is typically cached or computed once per frame.
*   **Memory Complexity:** Minimal additional memory, requiring storage for the rendered depth and normal maps if not already present.
*   **Strengths:** Significantly reduces "floaters" (errant Gaussians in empty space) and improves surface smoothness and geometric coherence [S1, S2, unofficial].
*   **Limitations:** May over-constrain the optimization if the scene contains highly curved or thin structures that cannot be well-approximated by flattened surfels. Requires accurate depth maps for normal consistency [S1, unofficial].
*   **When to use:** When the input data includes reliable depth maps and the goal is to produce clean, watertight-looking geometry [S1, unofficial].
*   **When not to use:** When depth data is noisy or unavailable, or when the scene contains fine, non-planar details that would be lost by aggressive flattening [S2, unofficial].

## Background
Originating from the need to improve the geometric quality of 3D Gaussian Splatting beyond color fidelity, this technique was introduced in various modular frameworks for Gaussian Splatting. The concept of "scaling loss" to flatten Gaussians into surfels is cited from prior work [5] in the GauStudio framework [S2, unofficial]. The implementation in GaussianSplatting.jl, which exposes this via `use_normal_loss`, is documented in an unofficial blog post [S1, unofficial]. It is part of the broader trend of integrating geometric priors into differentiable rendering pipelines [S2, unofficial].
