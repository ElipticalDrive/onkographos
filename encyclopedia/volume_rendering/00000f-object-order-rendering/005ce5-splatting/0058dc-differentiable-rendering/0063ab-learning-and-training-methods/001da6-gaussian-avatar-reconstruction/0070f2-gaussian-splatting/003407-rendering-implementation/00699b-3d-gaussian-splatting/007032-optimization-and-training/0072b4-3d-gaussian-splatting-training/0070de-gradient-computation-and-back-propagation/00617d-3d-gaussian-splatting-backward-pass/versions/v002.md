# 3D Gaussian Splatting Backward Pass

Also called: 3DGS backward pass, DiffRasterizer backward pass

## Overview
The 3D Gaussian Splatting backward pass computes the gradients of a rendering loss with respect to the learnable parameters of the 3D Gaussian primitives (position, covariance, opacity, color, and spherical harmonic coefficients) [S1, unofficial]. It differs from standard rasterization by propagating gradients through the differentiable alpha-compositing equation and the 2D projection approximation, enabling end-to-end training of the scene representation [S1, unofficial].

## How it works
The backward pass is implemented as a CUDA kernel (often encapsulated in a `DiffRasterizer` class) that takes the forward pass buffers and the upstream loss gradient to compute per-primitive gradients [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   `model_attributes`: Current state of the Gaussian primitives (3D positions, covariances, opacities, SH coefficients, etc.) [S1, unofficial].
*   `camera_matrices`: View and projection matrices for the current camera [S1, unofficial].
*   `fov_tangents`: Tangent of the half-field-of-view values, identical to those computed in the forward pass [S1, unofficial].
*   `forward_buffers`: Results from the forward pass, specifically:
    *   `radii`: 2D radii of rendered Gaussians [S1, unofficial].
    *   `framebuffer`: The rendered image and accumulation buffers [S1, unofficial].
    *   `geometry_buffer`: Intermediate geometric data (e.g., 2D means, conic matrices) [S1, unofficial].
    *   `binning_buffer`: Tile-based binning information [S1, unofficial].
    *   `image_buffer`: Pixel-based sorting and accumulation data [S1, unofficial].
*   `loss_gradient`: The gradient of the loss function with respect to the rendered image, shape $(H, W, 3)$ [S1, unofficial].

**Outputs:**
*   `d_xyz`: Gradient w.r.t. 3D positions, shape $(N, 3)$ [S1, unofficial].
*   `d_mean2D`: Gradient w.r.t. 2D mean positions, shape $(N, 3)$ [S1, unofficial].
*   `d_conic`: Gradient w.r.t. the 2D conic matrix (inverse covariance), shape $(N, 2, 2)$ [S1, unofficial].
*   `d_color`: Gradient w.r.t. SH features, shape $(N, N_{SH}, 3)$ [S1, unofficial].
*   `d_opacity`: Gradient w.r.t. opacity, shape $(N, 1)$ [S1, unofficial].
*   `d_cov3D`: Gradient w.r.t. 3D covariance parameters, shape $(N, 6)$ [S1, unofficial].
*   `d_scale`: Gradient w.r.t. scaling factors, shape $(N, 3)$ [S1, unofficial].
*   `d_rotation`: Gradient w.r.t. rotation quaternions, shape $(N, 4)$ [S1, unofficial].

### Data Structures
The implementation uses PyTorch tensors on the GPU [G]. Key structures include:
*   `DiffRasterizerForwardResult`: Contains `n_rendered` (count of visible primitives), `framebuffer`, `radii`, `geometry_buffer`, `binning_buffer`, and `image_buffer` [S1, unofficial].
*   `DiffRasterizerBackwardResult`: Contains the gradient tensors listed above, plus a copy of `radii` [S1, unofficial].

### Algorithm Steps
1.  **Initialize Gradient Tensors**: Allocate zero-initialized CUDA tensors for all output gradients (`d_xyz`, `d_mean2D`, `d_conic`, `d_color`, `d_opacity`, `d_cov3D`, `d_sh`, `d_scale`, `d_rotation`) with shapes matching the number of primitives $N$ [S1, unofficial].
2.  **Copy Forward Data**: Copy the `radii` from the forward pass result to the backward result structure to ensure consistency [S1, unofficial].
3.  **Compute FOV Tangents**: Calculate the tangent of the half-field-of-view values, ensuring they match the forward pass exactly [S1, unofficial].
4.  **Invoke CUDA Kernel**: Call the `DiffRasterizer` backward function with model attributes, camera matrices, FOV tangents, forward buffers, loss gradient, and gradient output tensors [S1, unofficial].

### Formulas and Gradients
The core gradient computation relies on the differentiable alpha-compositing equation provided in the parent article [Gradient Computation and Back-Propagation](10202-gradient-computation-and-back-propagation.md). The gradient of the loss $L$ with respect to the parameters $\theta_k$ of the $k$-th Gaussian is computed via the chain rule [G]:
$$
\frac{\partial L}{\partial \theta_k} = \frac{\partial L}{\partial \mathbf{C}(\mathbf{x})} \frac{\partial \mathbf{C}(\mathbf{x})}{\partial \alpha_k(\mathbf{x})} \frac{\partial \alpha_k(\mathbf{x})}{\partial \theta_k}
$$
The term $\frac{\partial \mathbf{C}(\mathbf{x})}{\partial \alpha_k(\mathbf{x})}$ is computed efficiently using recursive accumulators traversed in reverse depth order to avoid $O(N^2)$ complexity [S1, unofficial]. Specifically:
$$
\frac{\partial \mathbf{C}(\mathbf{x})}{\partial \alpha_k(\mathbf{x})} = T_k(\mathbf{x}) \mathbf{c}_k - \alpha_k(\mathbf{x}) \sum_{j=k+1}^{N} \mathbf{c}_j \alpha_j(\mathbf{x}) T_j(\mathbf{x}) \frac{1}{1-\alpha_k(\mathbf{x})}
$$
The term $\frac{\partial \alpha_k(\mathbf{x})}{\partial \theta_k}$ depends on the parameterization [S1, unofficial]:
*   **Opacity**: $\alpha_k$ is typically the sigmoid of a learnable scalar. The gradient is $\frac{\partial \alpha_k}{\partial \text{opacity}_{raw}} = \alpha_k (1 - \alpha_k)$ [S1, unofficial].
*   **2D Projection**: The 2D covariance $\Sigma_{2D}$ is derived from the 3D covariance $\Sigma_{3D}$ and the view matrix. The conic matrix $C = \Sigma_{2D}^{-1}$ is used for efficient evaluation. Gradients $\frac{\partial \alpha_k}{\partial C}$ are computed based on the Gaussian PDF derivative [S1, unofficial].
*   **3D Covariance**: $\Sigma_{3D}$ is parameterized by scale and rotation ($\Sigma_{3D} = R S S^T R^T$). Gradients flow to scale and rotation via the chain rule through $\Sigma_{3D}$ and then to $\Sigma_{2D}$ [S1, unofficial].
*   **Color/SH**: $\mathbf{c}_k$ is computed from spherical harmonic (SH) coefficients. Gradients flow directly to SH coefficients based on the basis function evaluation at the viewing direction [S1, unofficial].

### Pseudocode
The following pseudocode represents the high-level logic of the backward pass invocation and tensor management, based on the `gscache` implementation [S1, unofficial].

class Tensor:
    def __init__(self, shape, device='cuda'):
        self.shape = shape
        self.device = device
        self.data = [0.0] * (shape[0] * shape[1] if len(shape) == 2 else 1)

def allocate_zeros(shape):
    return Tensor(shape)

def copy_tensor(src):
    return Tensor(src.shape)

def compute_fov_tangents(fov_x, fov_y):
    import math
    return (math.tan(fov_x / 2), math.tan(fov_y / 2))

class DiffRasterizerBackwardResult:
    def __init__(self, radii, d_xyz, d_conic, d_opacity, d_color, d_mean2D, d_cov3D, d_sh, d_scale, d_rotation):
        self.radii = radii
        self.d_xyz = d_xyz
        self.d_conic = d_conic
        self.d_opacity = d_opacity
        self.d_color = d_color
        self.d_mean2D = d_mean2D
        self.d_cov3D = d_cov3D
        self.d_sh = d_sh
        self.d_scale = d_scale
        self.d_rotation = d_rotation

def backward_pass(gaussian_model, camera_matrix, fov_x, fov_y, forward_result, loss_gradient):
    # 1. Allocate zero-initialized gradient tensors
    n_points = gaussian_model.num_primitives
    n_sh_features = (gaussian_model.sh_degree + 1) ** 2
    
    d_xyz = allocate_zeros((n_points, 3))
    d_mean2D = allocate_zeros((n_points, 3))
    d_conic = allocate_zeros((n_points, 2, 2))
    d_color = allocate_zeros((n_points, n_sh_features, 3))
    d_opacity = allocate_zeros((n_points, 1))
    d_cov3D = allocate_zeros((n_points, 6))
    d_sh = allocate_zeros((n_points, n_sh_features, 3))
    d_scale = allocate_zeros((n_points, 3))
    d_rotation = allocate_zeros((n_points, 4))
    
    # 2. Copy radii from forward result
    radii_backward = copy_tensor(forward_result.radii)
    
    # 3. Compute FOV tangents (must match forward pass)
    fov_tangents = compute_fov_tangents(fov_x, fov_y)
    
    # 4. Invoke CUDA kernel
    # The sources do not provide the internal CUDA kernel implementation.

    # 5. Return backward result
    return DiffRasterizerBackwardResult(
        radii=radii_backward,

### Edge Cases and Pitfalls
*   **Empty Scene**: If `n_points` is 0, the model initializes with a dummy point to avoid empty tensor issues [S1, unofficial].
*   **Normalization**: Rotation quaternions are normalized during the forward pass. The backward pass must account for this normalization when computing gradients w.r.t. raw quaternion parameters [S1, unofficial].
*   **Scaling**: Scaling factors are exponentiated during the forward pass. The gradient w.r.t. raw scale is scaled by the exponential of the raw scale [S1, unofficial].
*   **Boundary Conditions**: Gaussians outside the frustum are culled in the forward pass. The backward pass only computes gradients for rendered primitives (`n_rendered`), so gradients for culled primitives remain zero [S1, unofficial].
