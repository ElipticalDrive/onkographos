# Mipmap-GS

Also called: Mipmap-Gaussian Splatting

## Overview
Mipmap-GS is a test-time adaptation method that deforms pre-trained 3D Gaussians into scale-adaptive primitives to eliminate aliasing artifacts (zoom-in spikes and zoom-out thickness) caused by fixed Gaussian distributions at varying zoom factors [S1]. Unlike sibling methods that apply heuristic 2D/3D smoothing filters or hierarchical Level-of-Detail (LoD) selection, Mipmap-GS self-adjusts primitive properties (color, shape, size) and distribution (position) using scale-specific mipmap-like pseudo ground-truth, effectively informing the Gaussians of the new sampling rate [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of single-scale trained base 3D Gaussians $G = \{G_k\}_{k=1}^K$, a set of viewpoints $V = \{v_j\}$, a target zoom factor $N$, and the number of adaptation iterations $S$ [S1].
*   **Output:** Optimized scale-adaptive Gaussians $G^{opt} = \{G^{opt}_k\}_{k=1}^K$ [S1].

**Data Structures:**
The method operates on the standard 3D Gaussian representation. Each Gaussian $G_k$ is defined by:
*   Position $\mu_k \in \mathbb{R}^3$
*   Covariance $\Sigma_k \in \mathbb{R}^{3 \times 3}$ (or rotation $q_k \in \mathbb{R}^4$ and scale $s_k \in \mathbb{R}^3$)
*   Opacity $\alpha_k \in [0, 1]$
*   Spherical Harmonics coefficients for color $c_k$ [S1]

**Parameters:**
*   $N$: The zoom factor. For zoom-in, $N > 1$ (upsampling); for zoom-out, $N < 1$ (downsampling) [S1].
*   $S$: Number of adaptation iterations. Typically 1,000 (1K) [S1].
*   $\beta$: Learning rate for gradient descent [S1].
*   $r(x)$: Mipmap resizing function. For zoom-in, super-resolution methods like SwinIR are used [S1]. For zoom-out, bilinear interpolation is used [S1].

**Algorithm Steps:**
1.  **Base Rendering:** For a randomly selected viewpoint $v_j$, render the base Gaussians $G$ to obtain a basic scale image $\hat{x}_j$ at resolution $\times 1$ [S1].
2.  **Pseudo-GT Construction:** Apply the mipmap resizing function $r(\cdot)$ to $\hat{x}_j$ to generate the scale-specific pseudo ground-truth $r(\hat{x}_j)$.
    *   If zoom-in ($N > 1$): Upsample $\hat{x}_j$ by factor $N$ using a super-resolution network (e.g., SwinIR) [S1].
    *   If zoom-out ($N < 1$): Downsample $\hat{x}_j$ by factor $1/N$ using bilinear interpolation [S1].
3.  **Adaptive Rendering:** Render the current optimized Gaussians $G^{opt}$ (initially $G^{opt} = G$) to the target scale to produce image $x_j$ [S1].
4.  **Loss Calculation:** Compute the L2 loss between the rendered image $x_j$ and the pseudo-GT $r(\hat{x}_j)$:
    $$ L(x_j, r(\hat{x}_j)) = \| x_j - r(\hat{x}_j) \|_2^2 $$
    [S1]
5.  **Optimization:** Update the Gaussians using gradient descent:
    $$ G^{opt} \leftarrow G^{opt} - \beta \nabla L(x_j, r(\hat{x}_j)) $$
    [S1]
6.  **Pruning/Densification:** Every 100 iterations ($i \mod 100 == 0$), perform active pruning or densification to maintain a compact representation [S1].
7.  **Repeat:** Steps 1-6 are repeated for $S$ iterations [S1].

**Pseudocode:**
```python
def mipmap_gs_optimization(base_gaussians G, viewpoints V, zoom_factor N, iterations S, learning_rate beta):
    """
    Deforms base Gaussians G to be adaptive for zoom factor N.
    """
    # Initialize optimized Gaussians
    G_opt = copy(G)
    
    # Define resizing function r(x)
    # For zoom-in (N > 1), use super-resolution (e.g., SwinIR)
    # For zoom-out (N < 1), use bilinear downsampling
    resize_func = get_resize_function(N) 
    
    for i in range(S):
        # 1. Select viewpoint
        v_j = random_choice(V)
        
        # 2. Render base Gaussians at basic scale (x1)
        x_hat_j = render(G, v_j)
        
        # 3. Construct mipmap-like pseudo-GT
        pseudo_gt = resize_func(x_hat_j)
        
        # 4. Render optimized Gaussians at new scale
        # Note: The rendering engine must support the target resolution/scale
        x_j = render(G_opt, v_j)
        
        # 5. Compute Loss
        loss = l2_loss(x_j, pseudo_gt)
        
        # 6. Optimize Gaussians
        gradients = compute_gradients(loss, G_opt)
        G_opt = G_opt - beta * gradients
        
        # 7. Active Pruning/Densification every 100 iterations
        if i % 100 == 0:
            G_opt = densify_or_prune(G_opt)
            
    return G_opt
```

**Edge Cases and Pitfalls:**
*   **Zoom-in Spikes:** Varying shrinkage bias leads to confusion during accumulation when sampling rates change, causing visual spikes [S1].
*   **Zoom-out Thickness:** Constant dilation in standard 3DGS leads to excessively wide coverage and thick structures when zooming out [S1].
*   **High-Frequency Loss:** Unlike Mip-Splatting which uses smoothing filters that suppress high-frequency components, Mipmap-GS preserves details by deforming Gaussians directly [S1].

## Operating characteristics
*   **Time Complexity:** The method requires $S$ iterations of rendering and optimization. Since $S=1000$ is small compared to initial training, the adaptation is fast, requiring only ~3% of the iterations of training from scratch [S1].
*   **Memory Complexity:** Active pruning during optimization reduces the number of Gaussians, particularly for zoom-out scenarios where lower spatial resolution requires fewer primitives [S1].
*   **Performance:** On the NeRF Synthetic dataset, Mipmap-GS outperforms standard 3DGS by an average of 9.25 dB PSNR for zoom-in and 10.40 dB for zoom-out [S1]. At $\times 1/2$ zoom-out on NeRF Synthetic, it achieves SSIM 0.971, PSNR 32.71, LPIPS 0.026, compared to 3DGS SSIM 0.951, PSNR 27.14, LPIPS 0.031 [S1]. On Mip-NeRF 360 at $\times 1/2$ zoom-out, it achieves SSIM 0.854, PSNR 28.57, compared to 3DGS SSIM 0.774, PSNR 26.66 [S1].
*   **Strengths:** Plug-in module applicable to any 3DGS model; test-time adaptation without retraining; preserves fine details better than filter-based methods [S1].
*   **Limitations:** Requires super-resolution inference for zoom-in (e.g., SwinIR), which may add latency; relies on the quality of the pseudo-GT generation [S1].

## Background
Mipmap-GS was proposed to address the aliasing and blurriness issues in 3D Gaussian Splatting (3DGS) when zooming in or out [S1]. Standard 3DGS suffers from mismatched pixel coverage because the 2D dilation operation is constant, leading to thin structures in zoom-in and thick structures in zoom-out [S1]. Previous methods like Mip-Splatting used heuristic 2D/3D smoothing filters, while Octree-GS used hierarchical LoD, but these did not fundamentally adapt the Gaussian distribution to the sampling rate [S1]. Mipmap-GS introduces a scale-aware guidance loss using mipmap-like pseudo ground-truth to deform Gaussians interactively [S1].
