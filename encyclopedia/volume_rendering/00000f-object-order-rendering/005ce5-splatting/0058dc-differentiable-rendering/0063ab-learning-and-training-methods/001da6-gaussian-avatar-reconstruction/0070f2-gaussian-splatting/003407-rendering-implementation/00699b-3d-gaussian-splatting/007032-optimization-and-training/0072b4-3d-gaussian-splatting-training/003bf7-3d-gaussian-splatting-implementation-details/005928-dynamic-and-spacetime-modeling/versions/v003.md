# Dynamic and Spacetime Modeling


## Overview
Dynamic and Spacetime Modeling extends static 3D Gaussian Splatting to handle temporal variations, enabling real-time novel view synthesis for dynamic scenes . It solves the problem of modeling emerging, vanishing, and deforming content by integrating time-dependent attributes (motion, opacity, rotation) into the Gaussian representation . It is distinguished from static methods by its explicit handling of time as a dimension, using either learned deformation fields or parametric polynomial trajectories to model geometry changes .

## Shared principles
All methods in this family share the core 3D Gaussian Splatting rendering pipeline: differentiable rasterization of 3D Gaussians defined by position, covariance, opacity, and color features [G]. The covariance matrix $\Sigma$ is typically constructed from a rotation quaternion $\mathbf{r}$ and scaling vector $\mathbf{s}$ as $\Sigma = \mathbf{R}\mathbf{S}\mathbf{S}^T\mathbf{R}^T$ [G]. Rendering uses alpha blending: $C(\mathbf{p}) = \sum_{i \in \mathcal{N}} T_i \alpha_i c_i$, where $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ [G].

Key shared mechanisms include:
1. **Time Input:** All methods accept a time parameter $t$ to query the scene state .
2. **Optimization:** Training uses the Adam optimizer and minimizes a combination of L1 loss and D-SSIM loss between rendered and ground-truth images .
3. **Density Control:** Methods employ adaptive density control (densification, splitting, pruning) based on positional gradients and opacity thresholds to maintain representation quality .
4. **Initialization:** Gaussians are typically initialized from Structure-from-Motion (SfM) sparse point clouds .

## Subtopics

### [SpacetimeGaussians Training Pipeline](15898-spacetimegaussians-training-pipeline.md)
A training strategy that integrates motion parameters ($\omega$) directly into Gaussian attributes. It distinguishes itself by using a structured schedule to freeze motion parameters after initial training and applying specific regularization terms for motion gradients. Choose this for explicit motion modeling with controlled freezing.

### [Deformable 3D Gaussians](16260-deformable-3d-gaussians.md)
A framework that decouples the radiance field from a learned deformation field. It models time-varying geometry by learning offsets $(\delta\mathbf{x}, \delta\mathbf{r}, \delta\mathbf{s})$ from a canonical space using an MLP. It distinguishes itself by using a deformation network and Annealing Smooth Training (AST) to mitigate temporal jitter. Choose this for high-fidelity reconstruction of complex deformations.

### [Spacetime Gaussian Feature Splatting](16313-spacetime-gaussian-feature-splatting.md)
A representation that models emerging/vanishing content using time-dependent opacity and polynomial motion/rotation. It distinguishes itself by using neural features (MLP) instead of spherical harmonics and polynomial trajectories for motion. Choose this for scenes with significant appearance changes or non-rigid motion.

## Background
Originating from the need to render dynamic scenes in real-time, these methods build on [3D Gaussian Splatting](9128-3d-gaussian-splatting-implementation-details.md) [G]. [Deformable 3D Gaussians](16260-deformable-3d-gaussians.md) addresses limitations of implicit methods (slow convergence, overfitting) by using explicit Gaussians with a deformation field. [SpacetimeGaussians Training Pipeline](15898-spacetimegaussians-training-pipeline.md) and [Spacetime Gaussian Feature Splatting](16313-spacetime-gaussian-feature-splatting.md) further explore parametric and feature-based temporal modeling.
