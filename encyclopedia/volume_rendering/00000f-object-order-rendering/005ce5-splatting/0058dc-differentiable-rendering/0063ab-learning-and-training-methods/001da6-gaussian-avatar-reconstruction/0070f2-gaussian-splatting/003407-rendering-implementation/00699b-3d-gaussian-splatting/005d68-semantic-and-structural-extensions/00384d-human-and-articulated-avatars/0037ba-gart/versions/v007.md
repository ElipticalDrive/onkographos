# GART
Also called: GART
## Overview
GART extends human models to more articulated models (e.g., animals) based on the 3DGS representation [S1][S2, unofficial]. It builds on [Human and Articulated Avatars](8209-human-and-articulated-avatars.md) [G].
## How it works
**Inputs and Outputs:** Not given in the sources [G].
**Data Structures:** Not given in the sources [G].
**Steps:**
1. **Initialization:** Initialize 3D Gaussians in the canonical space [G].
2. **Deformation:** Apply the deformation function $D(\cdot)$ to map canonical Gaussians to target poses defined by parameters $\theta$ [G].
3. **Rendering:** Project deformed Gaussians to screen space and accumulate features/colors using differentiable alpha-blending [G].
4. **Optimization:** Optimize Gaussian attributes and deformation parameters via photometric loss [G].

## Background
GART was introduced in the context of recent advances in 3D Gaussian Splatting, extending human-centric animation methods to broader articulated models like animals [S1][S2, unofficial].
