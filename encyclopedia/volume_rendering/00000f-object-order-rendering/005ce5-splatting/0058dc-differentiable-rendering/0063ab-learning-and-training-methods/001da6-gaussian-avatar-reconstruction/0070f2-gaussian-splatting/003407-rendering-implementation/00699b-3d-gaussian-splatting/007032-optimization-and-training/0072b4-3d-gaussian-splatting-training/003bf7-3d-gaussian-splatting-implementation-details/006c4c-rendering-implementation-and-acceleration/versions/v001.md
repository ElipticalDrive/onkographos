# Rendering Implementation and Acceleration


## Overview
This family covers implementation strategies and acceleration techniques for 3D Gaussian Splatting, focusing on robust geometric queries, slice-based volumetric consistency, and high-dynamic-range rendering. It differs from standard rasterization by introducing specialized intersection criteria [19020-occupancy-region-derivation-intersection-criterion.md], imaging-system-aware focus models [19322-gaussian-piling.md], and parallel HDR/LDR pipelines [19784-parallel-differentiable-rasterization.md].

## Shared principles
The methods share a foundation in 3D Gaussian primitives defined by mean $\mu$, covariance $\Sigma$ (derived from scale $s$ and rotation $q$), opacity $\alpha$, and color/radiance parameters. Rendering involves projecting these 3D primitives to 2D screen space, typically via affine approximation of the projective transformation. The core mathematical operation is the evaluation of the Gaussian density function $P(x|\mu, \Sigma) = \exp\left(-\frac{1}{2}(x - \mu)^\top \Sigma^{-1} (x - \mu)\right)$ and alpha blending. Acceleration often relies on tiling the image plane and sorting primitives by depth.

## Subtopics

### [Occupancy Region Derivation & ϵ-Intersection Criterion](19020-occupancy-region-derivation-intersection-criterion.md)
Defines a robust geometric intersection test for 3D Gaussian splats by deriving an elliptic occupancy region $\Omega_i$ from the Gaussian kernel $G_i$, replacing strict binary overlap checks with a tolerance-based $\epsilon$-intersection criterion. It solves the problem of robustly determining whether two splats $G_i$ and $G_j$ interact during rendering or optimization, avoiding numerical instability from strict boundary comparisons. It differs from standard alpha-testing by using a derived geometric region $\Omega_i$ defined by an adaptive threshold $T_i$ and a normal-wise offset metric $\delta_{ij}$, rather than simple distance-to-center checks.

### [Gaussian Piling](19322-gaussian-piling.md)
Gaussian Piling is a slice-based volumetric reconstruction method that unifies 3D Gaussian Splatting with an imaging system-aware focus model to compress aggressively while preserving internal structure. Unlike standard 3D Gaussian Splatting, which discards internal volumetric information and produces incoherent 3D structures with floating artifacts for slice-based modalities, Gaussian Piling models the finite focal zone to preserve high-frequency internal volumetric detail. It achieves this by maintaining Gaussian primitives' form through axial re-parameterization, opacity modulation, and additive rasterization to enforce 3D-to-2D consistency.

### [Parallel Differentiable Rasterization](19784-parallel-differentiable-rasterization.md)
Parallel Differentiable Rasterization is a rendering technique that jointly generates High Dynamic Range (HDR) and Low Dynamic Range (LDR) views from a single set of 3D Gaussian primitives by employing two parallel differentiable rasterization pipelines ($F_{HDR}$ and $F_{LDR}$). It distinguishes itself from standard 3D Gaussian Splatting by decoupling the color representation into HDR base values and LDR exposure-dependent values, allowing simultaneous optimization and rendering of both radiance ranges without tone-mapping artifacts during the differentiable process.

### Conditional Splat Approximation
- **Definition**: A technique to approximate the influence range of a 3D Gaussian on a slice by using a 2D ellipse splat scaled by the marginal factor, which closely matches the true iso-probability contours [S1, unofficial].
- **Validation**: Qualitative validation shows that the conditional splat approximation (dashed red contours) closely overlaps with the true 3D Gaussian iso-probability contours (solid blue contours) [S1, unofficial].
- **Comparison**: The conditional splat provides an accurate and efficient approximation of the original 3D Gaussian’s influence range [S1, unofficial].

### GaussianPile Forward Rendering
- **Definition**: A forward rendering process for slice-based volumetric reconstruction that converts 3D Gaussian primitives into 2D images by convolving the Gaussian with a reversed sensitivity map (PSF) along the axial direction, resulting in a 'focus Gaussian' that accounts for depth-of-field effects [S2, unofficial].
- **Steps**:
    1. Represent each primitive as an anisotropic 3D Gaussian with parameters $G = (\mu, s, q, \alpha)$, where $\mu$ is position, $s$ is scale, $q$ is orientation quaternion, and $\alpha$ is opacity [S2, unofficial].
    2. Convert scale $s$ and orientation $q$ into a 3D covariance matrix $\Sigma$ in world coordinates: $S = \text{diag}(\text{mod} \cdot s)$, $R = \text{quatToMatrix}(q)$, $\Sigma = R S S^\top R^\top$ [S2, unofficial].
    3. Extract the 2D components from the focus Gaussian: $\Sigma_{2d}$ is the top-left 2x2 block of $\Sigma_e$, and $\mu_{2d} = [\mu_e[0], \mu_e[1]]^\top$ [S2, unofficial].

## Background
The techniques in this family address specific limitations of standard 3D Gaussian Splatting in specialized domains. Occupancy region derivation improves robustness in geometric queries [19020-occupancy-region-derivation-intersection-criterion.md]. Gaussian Piling targets slice-based modalities like ultrasound or tomography, where standard splatting fails to preserve internal structure [S2, unofficial]. Parallel differentiable rasterization enables HDR rendering without post-processing artifacts [S1, unofficial]. Conditional splat approximation provides an efficient way to handle slice intersections [S1, unofficial].
