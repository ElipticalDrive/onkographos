# Covariance Factorisation

Also called: Covariance Decomposition, RQ Decomposition for Covariance, Rotation and Scale Parameterization

## Overview
Covariance Factorisation is the parameterization strategy used in 3D Gaussian Splatting to represent the 3D Gaussian covariance matrix $\boldsymbol{\Sigma}$ as a product of a rotation matrix $\mathbf{R}$ and a scaling matrix $\mathbf{S}$ [S1, unofficial][S2]. It solves the problem that directly optimizing the entries of $\boldsymbol{\Sigma}$ can result in non-positive semi-definite matrices, which violates physical interpretation and causes numerical instability during gradient-based training [S1, unofficial]. It sets itself apart from sibling methods like [Cholesky Parameterisation for Gaussian Splats](3120-cholesky-parameterisation-for-gaussian-splats.md) by explicitly decoupling rotation and scale into distinct learnable components, rather than relying on a triangular factorization to implicitly encode orientation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Unconstrained learnable parameters for rotation (typically a quaternion) and scale (a 3D vector) [G].
- Output: The $3 \times 3$ symmetric positive semi-definite covariance matrix $\boldsymbol{\Sigma}$ [S1, unofficial][S2].

**Data Structures:**
The method does not store $\boldsymbol{\Sigma}$ directly. Instead, it stores:
1. **Rotation:** A quaternion $\mathbf{q} = (w, x, y, z)$ or equivalent representation, normalized to unit length [G].
2. **Scale:** A 3D vector $\mathbf{s} = (s_x, s_y, s_z)$ with $s_i > 0$ [G].

**Steps:**
1. **Construct Rotation Matrix:** Convert the learnable rotation parameter (e.g., quaternion $\mathbf{q}$) into a $3 \times 3$ orthogonal rotation matrix $\mathbf{R}$ [G].
2. **Construct Scaling Matrix:** Create a diagonal matrix $\mathbf{S}$ from the scale vector $\mathbf{s}$:
   $$ \mathbf{S} = \text{diag}(s_x, s_y, s_z) $$ [G].
3. **Compute Covariance:** Calculate $\boldsymbol{\Sigma}$ using the factorization formula:
   $$ \boldsymbol{\Sigma} = \mathbf{R} \mathbf{S} \mathbf{S}^T \mathbf{R}^T $$ [S2].
   Since $\mathbf{S}$ is diagonal, $\mathbf{S} \mathbf{S}^T = \mathbf{S}^2 = \text{diag}(s_x^2, s_y^2, s_z^2)$ [G]. Thus:
   $$ \boldsymbol{\Sigma} = \mathbf{R} \begin{bmatrix} s_x^2 & 0 & 0 \\ 0 & s_y^2 & 0 \\ 0 & 0 & s_z^2 \end{bmatrix} \mathbf{R}^T $$ [G].

**Formulas:**
- $\boldsymbol{\Sigma} = \mathbf{R} \mathbf{S} \mathbf{S}^T \mathbf{R}^T$ [S2]
- $\mathbf{S} = \text{diag}(\mathbf{s})$ [G]

**Parameters:**
- Scale vector $\mathbf{s}$: Values must be positive [G].
- Rotation $\mathbf{R}$: Derived from a unit quaternion [G].

**Edge Cases and Pitfalls:**
- **Non-PSD Matrices:** If $\mathbf{R}$ is not orthogonal or $\mathbf{s}$ contains negative values, $\boldsymbol{\Sigma}$ may not be PSD [G]. Ensure $\mathbf{R}$ is constructed from a normalized quaternion and $\mathbf{s}$ is clamped to positive values or passed through an exponential activation function during optimization [G].
- **Numerical Stability:** Factorizing the covariance into rotation and scale ensures it remains positive semi-definite under unconstrained gradient descent [S1, unofficial].

**Pseudocode:**
```python
def compute_covariance(quaternion: Tuple[float, float, float, float], scale: Tuple[float, float, float]) -> List[List[float]]:
    """
    Computes the 3x3 covariance matrix from a quaternion and scale vector.
    
    Args:
        quaternion: (w, x, y, z) normalized quaternion.
        scale: (sx, sy, sz) positive scale factors.
        
    Returns:
        3x3 covariance matrix as a list of lists.
    """
    # Normalize quaternion to ensure valid rotation
    w, x, y, z = quaternion
    norm = (w**2 + x**2 + y**2 + z**2)**0.5
    w, x, y, z = w/norm, x/norm, y/norm, z/norm
    
    # Construct rotation matrix R from quaternion
    R = [
        [1 - 2*(y**2 + z**2), 2*(x*y - w*z), 2*(x*z + w*y)],
        [2*(x*y + w*z), 1 - 2*(x**2 + z**2), 2*(y*z - w*x)],
        [2*(x*z - w*y), 2*(y*z + w*x), 1 - 2*(x**2 + y**2)]
    ]
    
    # Construct scaling matrix S^2 (diagonal)
    sx, sy, sz = scale
    S2 = [
        [sx**2, 0, 0],
        [0, sy**2, 0],
        [0, 0, sz**2]
    ]
    
    # Compute R * S2
    R_S2 = [
        [R[0][0]*S2[0][0], R[0][1]*S2[1][1], R[0][2]*S2[2][2]],
        [R[1][0]*S2[0][0], R[1][1]*S2[1][1], R[1][2]*S2[2][2]],
        [R[2][0]*S2[0][0], R[2][1]*S2[1][1], R[2][2]*S2[2][2]]
    ]
    
    # Compute R * S2 * R^T
    Rt = [
        [R[0][0], R[1][0], R[2][0]],
        [R[0][1], R[1][1], R[2][1]],
        [R[0][2], R[1][2], R[2][2]]
    ]
    
    Sigma = [
        [R_S2[0][0]*Rt[0][0] + R_S2[0][1]*Rt[1][0] + R_S2[0][2]*Rt[2][0],
         R_S2[0][0]*Rt[0][1] + R_S2[0][1]*Rt[1][1] + R_S2[0][2]*Rt[2][1],
         R_S2[0][0]*Rt[0][2] + R_S2[0][1]*Rt[1][2] + R_S2[0][2]*Rt[2][2]],
        [R_S2[1][0]*Rt[0][0] + R_S2[1][1]*Rt[1][0] + R_S2[1][2]*Rt[2][0],
         R_S2[1][0]*Rt[0][1] + R_S2[1][1]*Rt[1][1] + R_S2[1][2]*Rt[2][1],
         R_S2[1][0]*Rt[0][2] + R_S2[1][1]*Rt[1][2] + R_S2[1][2]*Rt[2][2]],
        [R_S2[2][0]*Rt[0][0] + R_S2[2][1]*Rt[1][0] + R_S2[2][2]*Rt[2][0],
         R_S2[2][0]*Rt[0][1] + R_S2[2][1]*Rt[1][1] + R_S2[2][2]*Rt[2][1],
         R_S2[2][0]*Rt[0][2] + R_S2[2][1]*Rt[1][2] + R_S2[2][2]*Rt[2][2]]
    ]
    
    return Sigma
```

## Subtopics

### [Cholesky Parameterisation for Gaussian Splats](3120-cholesky-parameterisation-for-gaussian-splats.md)
This method parameterizes the 3D Gaussian covariance matrix using Cholesky decomposition to guarantee positive-definiteness by construction during gradient-based optimization. It stores $D(D+1)/2$ elements per splat (6 for 3D), ensuring the covariance matrix remains valid without requiring post-hoc projection or regularization. It differs from sibling methods like [Quaternion-Scale Covariance Parameterization](11801-quaternion-scale-covariance-parameterization.md) by avoiding explicit rotation parameterization, instead relying on the triangular structure of the Cholesky factor to encode orientation and scale implicitly.

### [Quaternion-Scale Covariance Parameterization](11801-quaternion-scale-covariance-parameterization.md)
This method parameterizes the 3D Gaussian covariance matrix $\Sigma$ using a quaternion $q$ and a 3D scale vector $s$ to ensure the matrix remains positive semi-definite during optimization. It solves the problem that directly optimizing the entries of $\Sigma$ can result in non-positive semi-definite matrices, violating physical interpretation and causing numerical instability. Unlike siblings such as [Cholesky Parameterisation for Gaussian Splats](3120-cholesky-parameterisation-for-gaussian-splats.md), which uses a triangular factorization, this approach explicitly decouples rotation and scale, allowing for efficient gradient derivation and intuitive ellipsoid parameterization.

### Gamma-Decomposed Covariance Update
A numerical stability technique for computing the new covariance matrix after recycling, replacing the unsupported β() function with Γ() and ln(Γ()) to prevent overflow [S3].

### Covariance Matrix Normalization
A technique to transform a covariance matrix Σ into a normalized form Σ̂ by dividing it by its trace, separating the scaling vector s from the rotation matrix R [S4].
Formula: $\hat{\Sigma} = \frac{\Sigma}{\text{Tr}(\Sigma)} = R \frac{S^2}{\|s\|_2^2} R^T = R \hat{S}^2 R^T$, where $\|s\|_2^2 = \text{Tr}(\Sigma)$ [S4].
