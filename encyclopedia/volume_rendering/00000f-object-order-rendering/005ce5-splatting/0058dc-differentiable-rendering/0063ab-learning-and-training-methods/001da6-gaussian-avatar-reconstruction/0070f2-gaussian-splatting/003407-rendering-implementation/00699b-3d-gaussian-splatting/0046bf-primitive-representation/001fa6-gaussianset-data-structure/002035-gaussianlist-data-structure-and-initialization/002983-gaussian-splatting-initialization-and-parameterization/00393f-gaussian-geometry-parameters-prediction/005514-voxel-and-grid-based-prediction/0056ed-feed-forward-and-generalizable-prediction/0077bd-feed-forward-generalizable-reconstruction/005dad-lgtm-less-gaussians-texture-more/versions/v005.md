# LGTM (Less Gaussians, Texture More)

Also called: Feed-Forward Prediction of Textured Gaussians, Feed-Forward Textured Splatting

## Overview
LGTM is a feed-forward framework that predicts compact 2D Gaussian primitives coupled with per-primitive texture maps to enable high-fidelity 4K novel view synthesis without per-scene optimization [S1, unofficial]. It solves the quadratic growth in primitive count inherent in existing feed-forward 3DGS methods, which makes high-resolution synthesis intractable due to memory and compute limits [S1, unofficial]. Unlike standard 3DGS which couples appearance and geometry within each primitive, LGTM decouples them, allowing a compact set of geometric primitives to represent rich texture regions via per-primitive textures [S1, unofficial].

## How it works
**Inputs and Outputs:**
The network $f$ takes a set of input images $\{I^v\}_{v=1}^N$ and their low-resolution counterparts $\{I^v_{low}\}_{v=1}^N$ as input. It outputs a set of textured 2D Gaussians:
$$ f : (I^v, I^v_{low}) \rightarrow \{\mu_i, s_i, r_i, c_i, T^i_c, T^i_\alpha\} $$
where $\mu_i$ is the position, $s_i$ is the scale, $r_i$ is the rotation, $c_i$ is the spherical harmonic (SH) coefficients, $T^i_c$ is the color texture map, and $T^i_\alpha$ is the alpha texture map for primitive $i$ [S1, unofficial].

**Data Structures:**
*   **Primitive Grid:** The primitive network predicts a grid of $h \times w$ 2DGS primitives, where $h \times w$ corresponds to the resolution of the low-resolution input $I^v_{low}$ [S1, unofficial].
*   **Per-primitive Texture Maps:** Each primitive $i$ has two texture maps:
    *   Color texture: $T^i_c \in \mathbb{R}^{T \times T \times 3}$
    *   Alpha texture: $T^i_\alpha \in \mathbb{R}^{T \times T}$
    *   $T$ is the texture resolution, a tunable parameter trading off primitive size and texture size [S1, unofficial].
    *   $T^i_c$ is zero-initialized [S1, unofficial].

**Architecture:**
The architecture consists of two submodules:
1.  **Primitive Network ($f_{prim}$):** Processes low-resolution images to predict compact geometric primitives ($\mu, s, r, c$) and base opacity $o_i$. It uses a ViT encoder-decoder to process $I^v_{low} \in \mathbb{R}^{h \times w \times 3}$ and produces a grid of $h \times w$ primitives [S1, unofficial]. It also outputs feature maps $F^{v}_{prim}$ from the ViT decoder, which are shared with the texture network [S1, unofficial].
2.  **Texture Network ($f_{texture}$):** Processes high-resolution inputs to predict detailed per-primitive texture maps. It extracts high-resolution features via image patchification and projective mapping, then fuses them with geometric features from the primitive network [S1, unofficial].

**Rendering Formulas:**
For a ray-splat intersection point $u$ on primitive $i$:
*   Alpha value: $a_i(u) = o_i \cdot T^i_\alpha[u]$
*   Color: $\hat{c}_i(u, d_i) = T^i_c[u] + SH(c_i, d_i)$
    *   $d_i$ is the view direction.
    *   $T^i_\alpha[u]$ and $T^i_c[u]$ are retrieved from the texture maps using bilinear sampling [S1, unofficial].
*   Final pixel color $C$ is computed by alpha-blending contributions from all primitives sorted by depth:
    $$ C = \sum_i a_i(u_i) \hat{c}_i(d_i) \prod_{j=1}^{i-1} (1 - a_j(u_j)) $$
    [S1, unofficial]

**Projective Features:**
To compute projective features $F^{v}_{proj}$, the texture network performs projective texture mapping from the source image back to the primitive local coordinates. For each primitive $i$, a projective prior texture $T^{i,c,proj}$ is computed using the inverse transformation $M_{i,v}^{-1}$:
$$ T^{i,c,proj}[u] = I^v[x] = I^v[M_{i,v}^{-1}(u)] $$
where $M_{i,v}$ is the 2D homography transformation mapping image pixel coordinates $x$ to primitive local coordinates $u$. Features $F^{v}_{proj}$ are extracted from $T^{i,c,proj}[u]$ to provide high-frequency appearance details [S1, unofficial].

**Texture Network Feature Fusion:**
The texture network combines three features:
1.  $F^{v}_{patch}$: Computed from the patchified high-resolution image $I^v$ via convolutional layers.
2.  $F^{v}_{proj}$: Extracted from the projective prior textures.
3.  $F^{v}_{prim}$: Reused backbone features from the primitive network.
These are aggregated to predict $T^i_\alpha$ and $T^i_c$ [S1, unofficial].

**Training Strategy:**
1.  **Stage 1:** Pre-train the primitive network $f_{prim}$ to predict 2DGS parameters using low-resolution inputs $I^v_{low}$ with high-resolution supervision (rendering and supervising at full resolution $H \times W$) [S1, unofficial].
2.  **Stage 2:** Jointly train $f_{prim}$ and $f_{texture}$. Freeze or reduce the learning rate of $f_{prim}$ by 0.1x to maintain geometric stability. The color texture $T^i_c$ is zero-initialized [S1, unofficial].
3.  **Loss:** Standard photometric losses (MSE + LPIPS) are used for supervision in both stages [S1, unofficial].

**Pseudocode:**

```python
def lgtm_forward(input_images, low_res_images, camera_poses):
    """
    Forward pass of the LGTM network.
    
    Args:
        input_images: List of high-resolution input images I^v.
        low_res_images: List of low-resolution input images I^v_low.
        camera_poses: Camera poses for the input views.
        
    Returns:
        primitives: List of primitive parameters (mu, s, r, c, o).
        textures: List of per-primitive texture maps (T_c, T_alpha).
    """
    # Stage 1: Primitive Network
    # f_prim takes low-res images and predicts compact geometry
    primitives, prim_features = f_prim(low_res_images)
    
    # Stage 2: Texture Network
    # f_texture takes high-res images and primitive features
    textures = f_texture(input_images, prim_features, primitives, camera_poses)
    
    return primitives, textures

def render_lgtm(primitives, textures, camera_poses, resolution):
    """
    Render an image using the predicted textured Gaussians.
    
    Args:
        primitives: List of primitive parameters.
        textures: List of per-primitive texture maps.
        camera_poses: Camera poses for the target view.
        resolution: Target image resolution (H, W).
        
    Returns:
        rendered_image: Rendered RGB image.
    """
    # Initialize output buffers
    alpha_buffer = zeros((H, W))
    color_buffer = zeros((H, W, 3))
    
    # Sort primitives by depth relative to camera
    sorted_primitives = sort_by_depth(primitives, camera_poses)
    
    for primitive in sorted_primitives:
        # Compute homography M for this primitive
        M = compute_homography(primitive, camera_poses)
        
        # Find ray-splat intersections for all pixels
        # u = M^-1(x) maps pixel x to local primitive coordinates u
        # This step is typically done via rasterization
        
        # For each pixel x covered by the primitive:
        for x in pixels_covered_by(primitive):
            u = inverse_homography(M, x)
            
            # Sample alpha and color from texture maps
            # T_alpha[u] and T_c[u] use bilinear sampling
            alpha_tex = sample_texture(primitive.alpha_texture, u)
            color_tex = sample_texture(primitive.color_texture, u)
            
            # Compute base color from SH
            view_dir = compute_view_direction(primitive, camera_poses)
            sh_color = spherical_harmonic(primitive.sh_coeffs, view_dir)
            
            # Combine texture and SH
            final_alpha = primitive.opacity * alpha_tex
            final_color = color_tex + sh_color
            
            # Alpha blending
            # C_new = C_old * (1 - a) + a * c
            alpha_buffer[x] = alpha_buffer[x] + final_alpha * (1 - alpha_buffer[x])
            color_buffer[x] = color_buffer[x] * (1 - final_alpha) + final_color * final_alpha
            
    return color_buffer

def train_lgtm_stage1(model, data_loader):
    """
    Stage 1: Train primitive network with high-res supervision.
    """
    for batch in data_loader:
        low_res_imgs = batch.low_res_images
        high_res_imgs = batch.high_res_images
        camera_poses = batch.camera_poses
        
        # Predict primitives from low-res images
        primitives, _ = f_prim(low_res_imgs)
        
        # Render at high resolution
        rendered_imgs = render_lgtm(primitives, None, camera_poses, high_res_imgs.shape)
        
        # Compute loss against high-res ground truth
        loss = mse_loss(rendered_imgs, high_res_imgs) + lpips_loss(rendered_imgs, high_res_imgs)
        
        # Backpropagate through f_prim only
        loss.backward()
        optimizer.step()

def train_lgtm_stage2(model, data_loader):
    """
    Stage 2: Jointly train primitive and texture networks.
    """
    for batch in data_loader:
        high_res_imgs = batch.high_res_images
        low_res_imgs = batch.low_res_images
        camera_poses = batch.camera_poses
        
        # Predict primitives from low-res images
        primitives, prim_features = f_prim(low_res_imgs)
        
        # Predict textures from high-res images and primitive features
        textures = f_texture(high_res_imgs, prim_features, primitives, camera_poses)
        
        # Render at high resolution
        rendered_imgs = render_lgtm(primitives, textures, camera_poses, high_res_imgs.shape)
        
        # Compute loss
        loss = mse_loss(rendered_imgs, high_res_imgs) + lpips_loss(rendered_imgs, high_res_imgs)
        
        # Backpropagate through both networks
        # Note: f_prim learning rate is reduced by 0.1x
        loss.backward()
        optimizer.step()
```

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Standard feed-forward methods fail to train at 2K or higher resolutions due to memory constraints (OOM). LGTM trains successfully at 2K and 4K using under 30 GB of memory [S1, unofficial].
*   **Holes in Rendering:** Rendering without high-resolution supervision may result in areas with holes as they are not anti-aliased. High-resolution supervision forces the network to learn proper anti-aliasing [S1, unofficial].
*   **Geometric Stability:** In Stage 2, the primitive network must be trained with a reduced learning rate (0.1x) to maintain geometric stability while the texture network learns high-frequency details [S1, unofficial].

## Operating characteristics
*   **Memory:** LGTM trains successfully at 2K and 4K resolutions using under 30 GB of memory [S1, unofficial]. In contrast, NoPoSplat fails to train at 2K or higher due to memory constraints (OOM), reaching 61.85 GB for a batch size of 1 at 1024x576 primitives [S1, unofficial].
*   **Scalability:** LGTM scales efficiently at inference; a 64x pixel increase adds only modest memory and time overhead [S1, unofficial].
*   **Performance:** Enables high-fidelity 4K novel view synthesis, a capability previously intractable for feed-forward methods [S1, unofficial].
*   **Strengths:** Decouples geometry and appearance, allowing compact primitives to represent rich textures. Feed-forward, no per-scene optimization required. Applicable to monocular, posed two-view, unposed two-view, and multi-view inputs [S1, unofficial].
*   **Limitations:** Requires a dual-network architecture and staged training. Texture resolution $T$ is a tunable parameter that trades off primitive size and texture size [S1, unofficial].

## Background
LGTM was published as a conference paper at ICLR 2026 by Yixing Lao, Xuyang Bai, Xiaoyang Wu, Nuoyuan Yan, Zixin Luo, Jean-Daniel Nahmias, Yanghai Tsin, Shiwei Li, and Hengshuang Zhao from HKU and Apple [S1, unofficial]. It addresses the resolution scalability bottleneck of feed-forward 3DGS methods and the per-scene optimization requirement of existing textured Gaussian techniques [S1, unofficial].
