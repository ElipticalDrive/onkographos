# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing a photorealistic 3D scene from a sparse set of 2D images by optimizing position, rotation, scale, opacity, and appearance (spherical harmonics) attributes [S5, S6, unofficial]. Unlike NeRF-based methods which optimize a continuous neural field, 3DGS training optimizes a discrete set of explicit primitives, offering significantly faster training and inference speeds while achieving comparable image quality [S2][S4, unofficial]. It sets itself apart from its siblings by using adaptive density control (splitting, cloning, and pruning) to dynamically adjust the number of Gaussians during optimization, balancing reconstruction fidelity against computational cost [S2].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of $N$ input images (or video frames) with known camera poses (rotation $R_{cw}$, translation $t_{cw}$, intrinsic matrix $K$) [S6, unofficial]. Initial 3D Gaussian parameters are derived from Structure from Motion (SfM) point clouds [S2][S6, unofficial].
*   **Outputs:** A trained set of 3D Gaussians (position $\mathbf{p}$, rotation $q$, scale $\mathbf{s}$, opacity $\alpha$, spherical harmonic coefficients $h$) stored in a format such as PLY [S4, unofficial].

**Data Structures**
Each Gaussian primitive $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$ (initialized from SfM points) [S6, unofficial].
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion) [S2].
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$ (initialized between 0 and 1) [S2].
*   Opacity $\alpha_i \in [0, 1]$ (initialized as a constant) [S6, unofficial].
*   Appearance: Spherical Harmonic coefficients $h_i$ (initialized from SfM colors) [S6, unofficial].

The covariance matrix $\Sigma_i$ is computed from scale and rotation:
$$ \Sigma_i = R(q_i) S(\mathbf{s}_i) S(\mathbf{s}_i)^T R(q_i)^T $$
where $R(q_i)$ is the rotation matrix derived from the quaternion [S2]:
$$ R(q) = 2 \begin{bmatrix} \frac{1}{2} - (q_j^2 + q_k^2) & q_i q_j - q_r q_k & q_i q_k + q_r q_j \\ q_i q_j + q_r q_k & \frac{1}{2} - (q_i^2 + q_k^2) & q_j q_k - q_r q_i \\ q_i q_k - q_r q_j & q_j q_k + q_r q_i & \frac{1}{2} - (q_i^2 + q_j^2) \end{bmatrix} $$

**Numbered Steps**
1.  **Initialization:** Initialize Gaussian positions $\mathbf{p}$ from SfM points in normalized bounds $[-1, 1]$. Initialize scales $\mathbf{s}$ between 0 and 1. Initialize rotations $q$ as unit quaternions. Initialize opacities $\alpha$ and spherical harmonics $h$ [S2][S6, unofficial].
2.  **Camera Sampling:** Select a training camera $V$ and its corresponding ground truth image $\hat{I}$ from the dataset [S2]. Cameras are sampled via a shuffled iterator [S4, unofficial].
3.  **Rendering:** Rasterize the current set of Gaussians using camera $V$ to obtain the rendered image $I$. This involves projecting 3D Gaussians to 2D screen space, sorting by depth, and alpha blending [S2][S6, unofficial].
    *   Pixel color $\gamma_j$ is computed via alpha blending:
        $$ \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij}, \quad \tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj}) $$
    *   Effective opacity $\alpha'_{ij} = g \alpha_i$, where $g = \exp(-0.5 \omega'_0 d_0^2 - 0.5 \omega'_2 d_1^2 - \omega'_1 d_0 d_1)$ [S6, unofficial].
4.  **Loss Computation:** Compute the loss $\mathcal{L}$ between the rendered image $I$ and the ground truth image $\hat{I}$ [S2]. The loss is a combination of L1 loss and D-SSIM loss:
    $$ \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM} $$
    where $\lambda$ is the SSIM weight (default 0.2) [S6, S4, unofficial].
5.  **Backpropagation:** Compute gradients of $\mathcal{L}$ with respect to all Gaussian parameters ($\mathbf{p}, q, \mathbf{s}, h, \alpha$) using the chain rule [S6, unofficial].
    *   Jacobian for rotation $q_i$:
        $$ \frac{\partial \mathcal{L}}{\partial q_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial q_i} $$
    *   Jacobian for scale $\mathbf{s}_i$:
        $$ \frac{\partial \mathcal{L}}{\partial s_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial s_i} $$
    *   Jacobian for SH $h_i$:
        $$ \frac{\partial \mathcal{L}}{\partial h_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial c_i} \frac{\partial c_i}{\partial h_i} $$
    *   Jacobian for opacity $\alpha_i$:
        $$ \frac{\partial \mathcal{L}}{\partial \alpha_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial \alpha_i} $$
    *   Jacobian for position $\mathbf{p}_{w,i}$ involves three terms accounting for depth sorting, color, and covariance changes [S6, unofficial].
6.  **Optimization Step:** Update parameters using the Adam optimizer [S2][S6, unofficial].
7.  **Adaptive Density Control:** Periodically (every `refineEvery` steps, default 500), perform densification and pruning [S2]:
    *   **Pruning:** If opacity $\alpha < \epsilon$ or the Gaussian is too large (`IsTooLarge`), prune the Gaussian [S2].
    *   **Densification:** If the positional gradient $\nabla_p \mathcal{L} > \tau_p$ (default 0.0002) [S4, unofficial]:
        *   **Over-reconstruction:** If the norm of the covariance matrix $\|\mathbf{S}\| > \tau_S$ (default 0.01), split the Gaussian into two [S2].
        *   **Under-reconstruction:** Else, clone the Gaussian [S2].
    *   **Refinement:** Reset opacity for cloned/split Gaussians to stabilize training [S1].

**Pseudocode**
```python
# Initialization
M = SfM_Initialize_Positions() # Positions from SfM
S, C, A = Init_Attributes()    # Scales, Colors (SH), Opacities
q = Init_Quaternions()         # Unit quaternions
step = 0
num_iters = 30000              # Default iterations [S4, unofficial]

while step < num_iters:
    # 1. Camera Sampling
    cam = Sample_Camera()
    gt_image = Get_Ground_Truth(cam)
    
    # 2. Rendering
    rendered_image = Rasterize(M, S, C, A, q, cam)
    
    # 3. Loss Computation
    loss = Compute_Loss(rendered_image, gt_image) # L1 + D-SSIM
    
    # 4. Backpropagation
    gradients = Backpropagate(loss, M, S, C, A, q)
    
    # 5. Optimization Step
    M, S, C, A, q = Adam_Update(M, S, C, A, q, gradients)
    
    # 6. Adaptive Density Control (Periodic)
    if step % refine_every == 0:
        for i in range(len(M)):
            # Pruning
            if A[i] < epsilon or Is_Too_Large(S[i]):
                Prune(i)
            # Densification
            elif Gradient_Magnitude(i) > densify_grad_thresh:
                if Norm_Covariance(S[i]) > densify_size_thresh:
                    Split(i)
                else:
                    Clone(i)
    
    step += 1
```

**Parameters**
*   `numIters`: Total number of optimization steps. Default: 30,000 [S4, unofficial].
*   `sh_degree`: Spherical harmonic degree. Default: 3 [S4, unofficial].
*   `shDegreeInterval`: Steps between increasing SH degree. Default: 1,000 [S4, unofficial].
*   `resolutionSchedule`: Steps between doubling image resolution. Default: 3,000 [S4, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S4, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: min(15,000, numIters / 2) [S4, unofficial].
*   `refineEvery`: Frequency of refinement operations. Default: 500 [S4, unofficial].
*   `densify_grad_thresh`: Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold for densification. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size based splitting stops. Default: 4,000 [S4, unofficial].
*   `ssim_weight`: Weight for SSIM loss. Default: 0.2 [S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S4, unofficial].

**Edge Cases and Pitfalls**
*   **No Cameras See Points:** If all cameras are discarded because they see no sparse points, training fails [S3, unofficial].
*   **Arbitrary Pose Rendering:** Requires exactly 16 elements for the `cam_to_world` matrix; otherwise, it throws an error [S4, unofficial].
*   **Evaluation Mode:** Evaluation requires the dataset to be loaded with `eval_mode=True`; otherwise, it throws a runtime error [S4, unofficial].
*   **CPU vs GPU:** CPU execution is ~100x slower than GPU [S3, unofficial].

Train a 3DGS to render stereo-calibrated novel views. Apply stereo depth estimation on the rendered views. Fuse the estimated dense depth maps together by the Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
A labeling pipeline that generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for the densification and pruning processes of 3D-GS optimization [S8, unofficial].

### Cross-View Pruning Mechanism
A mechanism comprising a Cross-View Consistency Loss and adaptive pruning to reduce Gaussian redundancy and ensure geometric validity [S9]. Select adjacent view pairs from $M$ views based on SSIM > 0.6. Compute Cross-View Consistent Loss ($L_{CVC}$) to penalize discrepancies between residuals of paired views. Pruning condition: $d^i_p < 0.01 \land d^j_p < 0.5 \lor d^i_p > 3\sigma$ [S9].

### Single-view Mini-batch Strategy
A training data sampling strategy for 3D Gaussian Splatting where data is organized per viewpoint, and a mini-batch consists of data from only a single viewpoint [S10, unofficial]. For each viewpoint $i$ from 1 to $N$, collect the dataset $D_i$ containing pixel-color pairs $\{p_{ij}, C_{ij}\}$. Organize the datasets into a collection $D = \{D_i\}$ for all $N$ viewpoints. Sample a mini-batch $B_{3DGS}$ containing data from count=1 viewpoint from $D$ [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is significantly faster than NeRF-based methods, typically completing in minutes to hours depending on scene complexity and resolution [S2][S5, unofficial]. The training loop involves $O(N \cdot P)$ operations per step, where $N$ is the number of Gaussians and $P$ is the number of pixels, but optimized rasterization reduces this overhead [6233-optimization-and-parallelization].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians $N$. Default max Gaussians is 5,000,000 [S4, unofficial]. Sinc splatting variants consume less memory than standard Gaussians [S7].
*   **Measured Performance:** On the Replica dataset, SGS-SLAM achieves PSNR 34.15, SSIM 0.97, and LPIPS 0.096 [S1]. Training on an M4 Max GPU can complete in ~90 seconds for certain benchmarks [S4, unofficial]. CPU execution is ~100x slower than GPU [S3, unofficial].
*   **Scaling:** Performance scales with resolution and number of input views. Resolution is typically increased during training via a downscale schedule [S4, unofficial].
*   **Strengths:** Real-time rendering speeds, high photorealism, faster training than NeRFs, explicit representation allows for easy editing and compression [S2][S5, unofficial].
*   **Limitations:** Can produce "floaters" in empty space, sensitive to initialization, and may require significant VRAM for large scenes [S2][S4, unofficial].
*   **When to Use:** When real-time rendering and fast training are prioritized over implicit representation flexibility.
*   **When Not to Use:** When memory is extremely constrained, or when the scene requires continuous volumetric representation without discrete primitives.

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [9, cited in S2]. It builds on the concept of radiance fields but uses explicit 3D Gaussians instead of neural networks. The method initializes positions using sparse point clouds from SfM tools like COLMAP [S2][S6, unofficial]. It has since been extended to various domains including SLAM, dynamic scenes, and physical parameter optimization [S1].
