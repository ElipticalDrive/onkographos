# SF-VAE (Spherical Folding Variational Autoencoder)
Also called: SFVAE, Spherical Folding VAE

## Overview
SF-VAE is a learning-based initialization method that encodes 3D Gaussian parameters into a compact latent space and decodes them using a spherical folding grid to reconstruct geometry and color [S1, unofficial]. It differs from heuristic initialization by providing a structured prior aligned with local surface normals, and from other generative methods by its specific use of a spherical folding decoder architecture [S1, unofficial].

## How it works
**Inputs and Outputs:**
The model takes a set of 3D points or Gaussian parameters as input. The primary input vector per sample is 7-dimensional, comprising 3 coordinates for the centroid ($\mathbf{p}$), 3 for scale ($\mathbf{s}$), and 1 for opacity ($\alpha$) or similar feature [S1, unofficial]. The output is a reconstructed set of points (geometry) and potentially color features [S1, unofficial].

**Data Structures:**
*   **SFModel:** The core neural network.
    *   `input_dim`: 7 [S1, unofficial].
    *   `embedding_dim`: Dimensionality of the latent vector $z$. Default is 32 [S1, unofficial].
    *   `grid_dim`: Dimension of the spherical folding grid. Default is 24 [S1, unofficial].
    *   `vae`: Boolean flag indicating VAE mode [S1, unofficial].
    *   `deterministic`: Boolean flag for deterministic sampling [S1, unofficial].
*   **SFDecoder Grid:** A 2D grid of shape `[grid_dim^2, 2]` representing local coordinates, repeated for the batch size [S1, unofficial].

**Parameters:**
*   `embedding_dim`: 32 [S1, unofficial].
*   `norm_weight`: Weight for normalization loss. Default is 0 [S1, unofficial].
*   `geo_weight`: Weight for Chamfer loss. Default is 0.5 [S1, unofficial].
*   `grid_dim`: 24 [S1, unofficial].

**Algorithm:**
1.  **Initialization:** Create an `SFModel` instance with the specified dimensions. Initialize a Chamfer Loss criterion with `geo_weight=0.5` [S1, unofficial].
2.  **Encoding:** Pass the input data through the encoder to obtain the mean $\mu$ and log-variance $\log\sigma^2$ of the latent distribution [S1, unofficial].
3.  **Latent Sampling:**
    *   If `vae` is true, sample the latent vector $z$ using the reparameterization trick: $z = \mu + \sigma \odot \epsilon$, where $\epsilon \sim \mathcal{N}(0, I)$ [S1, unofficial].
    *   If `vae` is false or `deterministic` is true, use $z = \mu$ [S1, unofficial].
4.  **Decoding (Spherical Folding):**
    *   The decoder uses the spherical folding grid to map the latent vector $z$ back to 3D space [S1, unofficial].
    *   The grid coordinates are used to interpolate or fold the latent features into the output geometry [S1, unofficial].
5.  **Loss Calculation:**
    *   **Chamfer Loss:** Compute the Chamfer distance between the input points and the reconstructed output points.
        $$ L_{Chamfer} = \frac{1}{N} \sum_{x \in X} \min_{y \in Y} \|x - y\|^2 + \frac{1}{N} \sum_{y \in Y} \min_{x \in X} \|y - x\|^2 $$
        where $X$ is input and $Y$ is output, weighted by `geo_weight` [S1, unofficial].
    *   **KL Divergence:** If in VAE mode, compute the KL divergence loss:
        $$ L_{KL} = -0.5 \times \frac{1}{N} \sum_{i=1}^{N} (1 + \log\sigma_i^2 - \mu_i^2 - \sigma_i^2) $$
        where $N$ is the batch size [S1, unofficial].
    *   **Total Loss:**
        $$ L_{total} = L_{Chamfer} + L_{KL} + \text{norm\_weight} \times L_{norm} $$
        [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** The use of floating-point arithmetic for the reparameterization trick requires careful handling of numerical stability, particularly for `logvar` [G].
*   **Boundaries:** The spherical folding grid must cover the relevant angular space to avoid reconstruction artifacts at the poles or seams [G].
*   **Degenerate Input:** If the input point cloud is sparse or noisy, the Chamfer loss may not provide sufficient gradient signal for the latent space to learn meaningful structures [G].

## Subtopics

### Gaussian VAE
A Variational Auto-encoder that compresses Gaussian Splatting Functions into a regularized latent space, mapping functions of each shape into one latent vector [S2]. It uses an Encoder and Decoder with Triplane representation [S2]. Unlike SF-VAE which focuses on point-based initialization, Gaussian VAE is part of the DiffGS framework, which also trains a Latent Diffusion Model (LDM) in the latent space to generate novel 3DGS shapes conditionally or unconditionally [S2]. It disentangles 3DGS into three Gaussian Splatting Functions (probability, colors, transforms) [S2].

## Background
SF-VAE originates from the `gs-embedding` project, an unofficial implementation [S1, unofficial]. It is designed to integrate with Gaussian Splatting pipelines to improve the initial placement and parameterization of Gaussians [S1, unofficial]. The method leverages the spherical folding technique to decode latent representations into 3D geometry [S1, unofficial].
