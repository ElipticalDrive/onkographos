# 4D Gaussian Rotation Construction
## Overview
Constructs a 4x4 rotation matrix for 4D Gaussians from two quaternion-like vectors `l` and `r` representing temporal and spatial rotations respectively [S1, unofficial]. It explicitly models the temporal dimension as a rotation component alongside the spatial one [S1, unofficial].
## How it works
**Inputs:**
- `l`: Tensor of shape `(N, 4)` containing temporal rotation quaternions [S1, unofficial].
- `r`: Tensor of shape `(N, 4)` containing spatial rotation quaternions [S1, unofficial].

**Outputs:**
- `A`: Tensor of shape `(N, 4, 4)` representing the combined 4D rotation matrix [S1, unofficial].

**Data Structures:**
- The method operates on batched tensors where `N` is the number of Gaussians [S1, unofficial].
- Intermediate matrices `M_l` and `M_r` are of shape `(N, 4, 4)` [S1, unofficial].

**Steps:**
1. **Normalize:** Compute the L2 norm of `l` and `r` along the last dimension, then divide to obtain normalized quaternions `q_l` and `q_r` [S1, unofficial].
2. **Unpack:** Extract components from `q_l` as `a, b, c, d` and from `q_r` as `p, q, r_val, s` [S1, unofficial].
3. **Construct $M_l$:** Build the temporal rotation matrix $M_l$ using the pattern `[a, -b, -c, -d, b, a, -d, c, c, d, a, -b, d, -c, b, a]`, reshape to `(N, 4, 4)`, and apply the source-specified permutation [S1, unofficial].
4. **Construct $M_r$:** Build the spatial rotation matrix $M_r$ using the pattern `[p, q, r_val, s, -q, p, -s, r_val, -r_val, s, p, -q, -s, -r_val, q, p]`, reshape to `(N, 4, 4)`, and apply the source-specified permutation [S1, unofficial].
5. **Combine:** Compute the final rotation matrix $A$ as the matrix product $M_l @ M_r$ [S1, unofficial].
6. **Flip Dimensions:** Flip the last two dimensions of $A$ to match the rendering pipeline's coordinate convention [S1, unofficial].

**Pseudocode:**
```python
import torch

def build_rotation_4d(l, r):
    # Step 1: Normalize
    l_norm = torch.norm(l, dim=-1, keepdim=True)
    r_norm = torch.norm(r, dim=-1, keepdim=True)
    l_norm = torch.clamp(l_norm, min=1e-8)
    r_norm = torch.clamp(r_norm, min=1e-8)
    q_l = l / l_norm
    q_r = r / r_norm

    # Step 2: Unpack components
    a, b, c, d = q_l[..., 0], q_l[..., 1], q_l[..., 2], q_l[..., 3]
    p, q, r_val, s = q_r[..., 0], q_r[..., 1], q_r[..., 2], q_r[..., 3]

    # Step 3: Construct M_l
    # Pattern: [a,-b,-c,-d, b, a,-d, c, c, d, a,-b, d,-c, b, a]
    # Reshape to (N, 4, 4) and permute as specified by the source [G]
    M_l_flat = torch.stack([
        a, -b, -c, -d,
        b,  a, -d,  c,
        c,  d,  a, -b,
        d, -c,  b,  a
    ], dim=-1).view(-1, 4, 4)

    # Step 4: Construct M_r
    # Pattern: [p, q, r_val, s, -q, p, -s, r_val, -r_val, s, p, -q, -s, -r_val, q, p]
    # Reshape to (N, 4, 4) and permute as specified by the source [G]
    M_r_flat = torch.stack([
        p,  q,  r_val,  s,
       -q,  p,  -s,     r_val,
       -r_val, s,  p,   -q,
       -s, -r_val, q,   p
    ], dim=-1).view(-1, 4, 4)

    # Step 5: Combine
    A = torch.bmm(M_l_flat, M_r_flat)

    # Step 6: Flip last two dimensions
    A = A.transpose(1, 2)

    return A
```

**Parameters:**
- No explicit hyperparameters [S1, unofficial].

**Edge Cases:**
- **Zero Norms:** If `l` or `r` has a zero norm, normalization fails [S1, unofficial]. A small epsilon is added to the norm denominator to prevent NaNs [G].
- **Degenerate Input:** If the input quaternions are not unit vectors, the resulting matrix will not be a pure rotation [S1, unofficial]. The normalization step ensures unit length [S1, unofficial].

### 4D Scaling and Rotation Construction
Constructs a 4x4 transformation matrix for 4D Gaussians by combining 4D scaling and 4D rotation [S1, unofficial]. It initializes a zero matrix `L` of shape `(N, 4, 4)`, sets the diagonal elements to the scaling factors `s[:,0]` to `s[:,3]`, computes the rotation matrix `R` using `build_rotation_4d(l, r)`, and returns `R @ L` [S1, unofficial].
