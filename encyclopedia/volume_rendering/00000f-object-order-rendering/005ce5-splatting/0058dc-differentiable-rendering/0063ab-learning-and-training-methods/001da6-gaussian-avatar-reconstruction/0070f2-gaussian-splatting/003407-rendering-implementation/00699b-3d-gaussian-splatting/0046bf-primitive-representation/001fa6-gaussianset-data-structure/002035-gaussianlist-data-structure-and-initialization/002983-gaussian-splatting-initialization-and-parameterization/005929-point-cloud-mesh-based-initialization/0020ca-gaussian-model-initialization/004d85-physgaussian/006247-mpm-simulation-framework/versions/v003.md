# MPM Simulation Framework

Also called: Material Point Method

## Overview
The MPM Simulation Framework is a continuum mechanics method that tracks the deformation gradient $\mathbf{F}$ on particles to measure distortion relative to an initial state [S1, unofficial]. Internal forces are derived from the Cauchy stress tensor $\mathbf{T}$, which is defined by $\mathbf{F}$ and the chosen constitutive model [S1, unofficial]. For plastic materials, $\mathbf{F}$ is constrained within an elastic region, and a return mapping $Z$ is applied to project $\mathbf{F}$ back onto the yield surface if it exceeds this region [S1, unofficial]. It is distinguished from its siblings by its unified support for diverse constitutive and plasticity models within a single particle-based framework [S1, unofficial].

### Steps
1. Track the deformation gradient $\mathbf{F}$ on MPM particles to measure distortion compared to the initial state [S1, unofficial].
2. Compute internal forces using the Cauchy stress tensor $\mathbf{T}$, which is defined by $\mathbf{F}$ and the selected constitutive model [S1, unofficial].
3. For plasticity, constrain $\mathbf{F}$ within an elastic region [S1, unofficial].
4. Apply a return mapping $Z$ to pull $\mathbf{F}$ back onto the yield surface if it exceeds the elastic region [S1, unofficial].

### Formulas
**Neo-Hookean Elasticity** [S1, unofficial]:
$$ \mathbf{T}(\mathbf{F}) = \mu(\mathbf{F}\mathbf{F}^T) + (\lambda \log(J) - \mu)\mathbf{I} $$
where $J = \det(\mathbf{F})$, and $\mu, \lambda$ are Lamé parameters related to Young’s modulus $E$ and Poisson’s ratio $\nu$ by:
$$ \mu = \frac{E}{2(1 + \nu)}, \quad \lambda = \frac{\nu E}{(1 + \nu)(1 - 2\nu)} $$

**StVK + von-Mises Plasticity** [S1, unofficial]:
$$ \mathbf{T}(\mathbf{F}) = \mathbf{U}(2\mu\mathbf{\epsilon} + \lambda \text{Tr}(\mathbf{\epsilon}))\mathbf{U}^T $$
where $\mathbf{F} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}$ is the SVD of $\mathbf{F}$, and $\mathbf{\epsilon} = \log(\mathbf{\Sigma})$ is the Hencky strain [S1, unofficial]. The von-Mises yielding condition is:
$$ \delta\gamma = \|\hat{\mathbf{\epsilon}}\| - \frac{\tau_Y}{2\mu} > 0 $$
where $\hat{\mathbf{\epsilon}}$ is the normalized Hencky strain and $\tau_Y$ is the yield stress [S1, unofficial]. The return mapping is:
$$ Z(\mathbf{F}) = \begin{cases} \mathbf{F} & \delta\gamma \le 0 \\ \mathbf{U} \exp\left(\hat{\mathbf{\epsilon}} - \delta\gamma \frac{\hat{\mathbf{\epsilon}}}{\|\hat{\mathbf{\epsilon}}\|}\right)\mathbf{V}^T & \text{otherwise} \end{cases} $$

**Viscoplastic Model** [S1, unofficial]:
Define:
$$ \hat{\mu} = \frac{\text{Tr}(\mathbf{\Sigma}^2)}{d}, \quad \mathbf{s} = 2\hat{\mu}\hat{\mathbf{\epsilon}}, \quad \hat{s} = \|\mathbf{s}\| - \frac{\eta}{1 + 2\hat{\mu}\Delta t} $$
where $d$ is dimension, $\eta$ is viscosity, and $\Delta t$ is time step [S1, unofficial]. The return mapping is:
$$ Z(\mathbf{F}) = \begin{cases} \mathbf{F} & \delta\gamma \le 0 \\ \mathbf{U} \exp\left(\frac{1}{2\mu}\hat{\mathbf{\epsilon}} + \frac{1}{d}\text{Tr}(\mathbf{\epsilon})\mathbf{I}\right)\mathbf{V}^T & \text{otherwise} \end{cases} $$
Note: The source text for the viscoplastic return mapping formula contains garbled notation (`U exp ( 1 2µ ˆ + d Tr(ε)1)V`), which is interpreted here as a standard viscoplastic return mapping structure based on the provided context [S1, unofficial].

## Subtopics

### [Neo-Hookean Elasticity](21557-neo-hookean-elasticity.md)
Neo-Hookean elasticity is a hyperelastic constitutive model used to simulate the large-deformation behavior of incompressible or nearly incompressible materials. It defines the Cauchy stress tensor $\mathbf{T}$ as a function of the deformation gradient $\mathbf{F}$ and the material's Lamé parameters. It is distinguished from linear elasticity by its ability to handle finite strains and from plasticity models by its reversible, energy-conserving nature.

### StVK + von-Mises Plasticity Model
Simulates plasticine using the St.Venant-Kirchhoff (StVK) constitutive model combined with von-Mises plastic return mapping [S1, unofficial]. The stress associated with the model is defined by $\mathbf{T}(\mathbf{F}) = \mathbf{U}(2\mu\mathbf{\epsilon} + \lambda \text{Tr}(\mathbf{\epsilon}))\mathbf{U}^T$, where $\mathbf{F} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}$ is the SVD of deformation gradient $\mathbf{F}$, and $\mathbf{\epsilon} = \log(\mathbf{\Sigma})$ is the Hencky strain [S1, unofficial]. The von-Mises yielding condition is $\delta\gamma = \|\hat{\mathbf{\epsilon}}\| - \frac{\tau_Y}{2\mu} > 0$, where $\hat{\mathbf{\epsilon}}$ is the normalized Hencky strain [S1, unofficial]. $\tau_Y$ is the yield stress, which is the parameter for this model [S1, unofficial]. $\delta\gamma > 0$ means the deformation gradient is outside the elastic region [S1, unofficial]. The deformation gradient will be projected back onto the boundary of the elastic region (yield surface) by the return mapping $Z(\mathbf{F})$ [S1, unofficial].

### Viscoplastic Model
Models non-Newtonian fluid with yield stress using a viscoplastic model with von-Mises criteria for the elastic region [S1, unofficial]. Define $\hat{\mu} = \frac{\text{Tr}(\mathbf{\Sigma}^2)}{d}$, $\mathbf{s} = 2\hat{\mu}\hat{\mathbf{\epsilon}}$, $\hat{s} = \|\mathbf{s}\| - \frac{\eta}{1 + 2\hat{\mu}\Delta t}$, where $d$ is dimension, $\eta$ is viscosity, and $\Delta t$ is time step [S1, unofficial]. The return mapping $Z(\mathbf{F})$ is applied if $\delta\gamma > 0$ [S1, unofficial]. Note: The source text formula for the return mapping is garbled, so the exact implementation details are ambiguous [S1, unofficial].

The Material Point Method (MPM) is a continuum mechanics framework that supports various constitutive and plasticity models [S1, unofficial]. The specific implementations of Neo-Hookean, StVK, and viscoplastic models are adapted from continuum mechanics literature and applied to the particle-based representation [S1, unofficial].
