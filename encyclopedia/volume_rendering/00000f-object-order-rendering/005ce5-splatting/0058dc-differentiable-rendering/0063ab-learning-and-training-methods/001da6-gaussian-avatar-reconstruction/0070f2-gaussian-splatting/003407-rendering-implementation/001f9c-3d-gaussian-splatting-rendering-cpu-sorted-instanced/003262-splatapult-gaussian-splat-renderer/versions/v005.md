# Splatapult Gaussian Splat Renderer

Also called: 3D Gaussian Splatting Rendering (SplatNode pipeline), Gaussian Splatting radiance-field cloud render, SplatNode pipeline, SplatNode render

## Overview
A renderer for 3D Gaussian Splatting (3DGS) files that supports VR, camera navigation, and optional spherical harmonic (SH) rendering, using either a C++ radix sort or a GPU-based multi-radix sort for depth sorting [S1, unofficial]. It decodes a 3D Gaussian Splat radiance-field cloud from a PLY file and renders it as hardware-instanced, camera-facing quads on-device [S2, unofficial]. It supports both desktop and mobile XR environments, with configurable sorting backends (CPU vs GPU) and optional sRGB framebuffer conversion to reduce color banding [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A binary PLY file containing 3D Gaussian parameters (positions, covariances, spherical harmonics, opacity) [S2, unofficial].
*   **Output:** A rendered image with correct alpha blending order (back-to-front) [S2, unofficial].

**Data Structures:**
*   **PLY Layout:** INRIA binary_little_endian 1.0 format with properties in order: `x`, `y`, `z`, `f_dc_0`, `f_dc_1`, `f_dc_2`, `opacity`, `scale_0`, `scale_1`, `scale_2`, `rot_0`, `rot_1`, `rot_2`, `rot_3` [S2, unofficial].
*   **Buffers:**
    *   `posBuffer`: `GL_SHADER_STORAGE_BUFFER`, stores `posVec` (Gaussian positions `x,y,z,1.0`) [S1, unofficial].
    *   `keyBuffer`, `keyBuffer2`: `GL_SHADER_STORAGE_BUFFER`, stores depth keys (`depthVec`) [S1, unofficial].
    *   `valBuffer`, `valBuffer2`: `GL_SHADER_STORAGE_BUFFER`, stores indices (`indexVec`) [S1, unofficial].
    *   `histogramBuffer`: `GL_SHADER_STORAGE_BUFFER`, stores histogram data (`histogramVec`) [S1, unofficial].
    *   `atomicCounterBuffer`: `GL_ATOMIC_COUNTER_BUFFER`, stores `atomicCounterVec` [S1, unofficial].

**Parameters:**
*   `NUM_BLOCKS_PER_WORKGROUP`: Constant set to 1024 [S1, unofficial].
*   `splatCount`: Controls the number of splats drawn (0..count), used for LOD or reveal hooks. Defaults to the full cloud count [S2, unofficial].
*   `isFramebufferSRGBEnabled`: Boolean flag enabling sRGB framebuffer conversion to reduce color banding; triggers the `#define FRAMEBUFFER_SRGB` in shaders [S1, unofficial].
*   `gaussianCloud->HasFullSH()`: Boolean flag indicating if full spherical harmonics are loaded; triggers the `#define FULL_SH` in shaders to enable full SH rendering [S1, unofficial].
*   `useRgcSortOverride`: Boolean flag; if true, forces the use of the CPU-based `rgc::radix_sort` instead of the GPU-based `multi_radixsort` even if hardware supports it [S1, unofficial].
*   `cameraPositionProvider`: A callback returning the live camera world position, fed to the node's painter's sort each frame [S2, unofficial].

**Steps:**

1.  **Initialization:**
    *   Load vertex, geometry, and fragment shaders (`splat_vert.glsl`, `splat_geom.glsl`, `splat_frag.glsl`) with defines for SRGB and Full SH [S1, unofficial].
    *   Load pre-sort compute shader (`presort_compute.glsl`) [S1, unofficial].
    *   If `GLEW_KHR_shader_subgroup` is present and `useRgcSortOverride` is false, load multi-radix sort shaders (`multi_radixsort.glsl`, `multi_radixsort_histograms.glsl`) [S1, unofficial].
    *   Reserve `posVec` and fill it with Gaussian positions (`x,y,z,1.0`) [S1, unofficial].
    *   Build Vertex Array Object (VAO) [S1, unofficial].
    *   Resize `depthVec` [S1, unofficial].
    *   If using multi-radix sort, allocate `keyBuffer`, `keyBuffer2`, `histogramBuffer`, `valBuffer`, `valBuffer2`, `posBuffer` [S1, unofficial].
    *   If not, allocate `keyBuffer`, `valBuffer`, `posBuffer` and create `rgc::radix_sort::sorter` [S1, unofficial].

2.  **Decode PLY:**
    *   Decode the bundled `.ply` asset off the main thread using `SplatParser.fromPly(bytes)` to produce a `SplatCloud` object [S2, unofficial].
    *   Handle null `SplatCloud` during loading [S2, unofficial].

3.  **Pre-sort (Compute Shader):**
    *   Bind `preSortProg` [S1, unofficial].
    *   Set uniforms: `modelViewProj` (`projMat * modelViewMat`), `nearFar`, `keyMax` (`std::numeric_limits<uint32_t>::max`) [S1, unofficial].
    *   Reset `atomicCounterBuffer` to 0 [S1, unofficial].
    *   Bind buffers: slot 0 `posBuffer` (readonly), slot 1 `keyBuffer` (writeonly), slot 2 `valBuffer` (writeonly), slot 4 `atomicCounterBuffer` [S1, unofficial].
    *   Dispatch compute with `LOCAL_SIZE=256` threads per group: `glDispatchCompute(((numPoints + 255) / 256), 1, 1)` [S1, unofficial].
    *   Barrier: `GL_SHADER_STORAGE_BARRIER_BIT | GL_ATOMIC_COUNTER_BARRIER_BIT` [S1, unofficial].

4.  **Get Count:**
    *   Read `atomicCounterBuffer` into `atomicCounterVec` [S1, unofficial].
    *   Set `sortCount = atomicCounterVec[0]` [S1, unofficial].
    *   Assert `sortCount <= numPoints` [S1, unofficial].

5.  **Sort:**
    *   **Multi-Radix Sort (if enabled):**
        *   Set `NUM_ELEMENTS = sortCount`, `NUM_WORKGROUPS = (NUM_ELEMENTS + 1023) / 1024` [S1, unofficial].
        *   Loop `i` from 0 to 3 (`NUM_BYTES=4`):
            1.  Bind `histogramProg`, set `g_shift = 8*i` [S1, unofficial].
            2.  Bind `keyBuffer` or `keyBuffer2` to slot 0, `histogramBuffer` to slot 1 [S1, unofficial].
            3.  Dispatch compute `NUM_WORKGROUPS` [S1, unofficial].
            4.  Barrier [S1, unofficial].
            5.  Bind `sortProg`, set `g_shift = 8*i` [S1, unofficial].
            6.  Bind buffers based on parity of `i`:
                *   If even: slot 0=`keyBuffer`, 1=`keyBuffer2`, 2=`valBuffer`, 3=`valBuffer2`, 4=`histogramBuffer` [S1, unofficial].
                *   If odd: slot 0=`keyBuffer2`, 1=`keyBuffer`, 2=`valBuffer2`, 3=`valBuffer`, 4=`histogramBuffer` [S1, unofficial].
            7.  Dispatch compute `NUM_WORKGROUPS` [S1, unofficial].
            8.  Barrier [S1, unofficial].
    *   **CPU Radix Sort (if multi-radix disabled):**
        *   Call `sorter->sort(keyBuffer->GetObj(), valBuffer->GetObj(), sortCount)` [S1, unofficial].

6.  **Copy Sorted:**
    *   If using multi-radix sort and `NUM_BYTES` is odd, bind `valBuffer2` to `GL_COPY_READ_BUFFER`, else bind `valBuffer` [S1, unofficial].
    *   Bind `splatVao->GetElementBuffer()` to `GL_COPY_WRITE_BUFFER` [S1, unofficial].
    *   Perform `glCopyBufferSubData` to transfer sorted indices to the VAO element buffer for rendering [S1, unofficial].

7.  **Render:**
    *   On each frame, read the live camera world position and pass it to the node's painter's sort via a `cameraPositionProvider` callback [S2, unofficial].
    *   The node re-sorts the splats back-to-front based on the camera position so the far side composites correctly behind the near side [S2, unofficial].
    *   Render using hardware-instanced, camera-facing quads [S2, unofficial].

**Pseudocode:**

```python
def splatapult_render(ply_bytes, camera_position, proj_mat, model_view_mat, use_gpu_sort=True):
    # Helper definitions for OpenGL-like operations
    def allocate_storage_buffer(size): return [0] * size
    def allocate_atomic_counter_buffer(): return [0]
    def load_shader(name): return {"name": name}
    def bind_shader(prog): pass
    def set_uniform(prog, name, value): pass
    def reset_atomic_counter(buf): buf[0] = 0
    def bind_buffer(prog, slot, buf, readonly=False): pass
    def dispatch_compute(x, y, z): pass
    def barrier(flags): pass
    def read_atomic_counter(buf): return buf
    def rgc_radix_sort_create_sorter(): return type('Sorter', (), {'sort': lambda s, k, v, c: k.sort(v, key=lambda x: x)})()
    def gl_copy_buffer_sub_data(src, dst, src_off, dst_off, size): pass
    def render_instanced_quads(vao, count): pass

    # 1. Decode PLY
    splat_cloud = SplatParser.fromPly(ply_bytes)
    if splat_cloud is None:
        return None  # Handle null case during loading
    
    num_points = splat_cloud.count
    pos_vec = splat_cloud.positions  # x,y,z,1.0
    
    # 2. Initialize Buffers
    if use_gpu_sort:
        key_buffer = allocate_storage_buffer(num_points)
        key_buffer2 = allocate_storage_buffer(num_points)
        histogram_buffer = allocate_storage_buffer(num_points)
        val_buffer = allocate_storage_buffer(num_points)
        val_buffer2 = allocate_storage_buffer(num_points)
        pos_buffer = allocate_storage_buffer(num_points)
        atomic_counter_buffer = allocate_atomic_counter_buffer()
        
        pre_sort_prog = load_shader("presort_compute.glsl")
        histogram_prog = load_shader("multi_radixsort_histograms.glsl")
        sort_prog = load_shader("multi_radixsort.glsl")
    else:
        key_buffer = allocate_storage_buffer(num_points)
        val_buffer = allocate_storage_buffer(num_points)
        pos_buffer = allocate_storage_buffer(num_points)
        atomic_counter_buffer = allocate_atomic_counter_buffer()
        
        sorter = rgc_radix_sort_create_sorter()
    
    # 3. Pre-sort Compute
    bind_shader(pre_sort_prog)
    set_uniform(pre_sort_prog, "modelViewProj", proj_mat @ model_view_mat)
    set_uniform(pre_sort_prog, "nearFar", near_far)
    set_uniform(pre_sort_prog, "keyMax", 0xFFFFFFFF)
    
    reset_atomic_counter(atomic_counter_buffer)
    
    bind_buffer(pre_sort_prog, 0, pos_buffer, readonly=True)
    bind_buffer(pre_sort_prog, 1, key_buffer, readonly=False)
    bind_buffer(pre_sort_prog, 2, val_buffer, readonly=False)
    bind_buffer(pre_sort_prog, 4, atomic_counter_buffer, readonly=False)
    
    dispatch_compute(((num_points + 255) // 256), 1, 1)
    barrier(GL_SHADER_STORAGE_BARRIER_BIT | GL_ATOMIC_COUNTER_BARRIER_BIT)
    
    # 4. Get Count
    atomic_counter_vec = read_atomic_counter(atomic_counter_buffer)
    sort_count = atomic_counter_vec[0]
    assert sort_count <= num_points
    
    # 5. Sort
    if use_gpu_sort:
        num_elements = sort_count
        num_workgroups = (num_elements + 1023) // 1024
        
        for i in range(4):  # NUM_BYTES=4
            # Histogram Step
            bind_shader(histogram_prog)
            set_uniform(histogram_prog, "g_shift", 8 * i)
            
            key_src = key_buffer if i % 2 == 0 else key_buffer2
            bind_buffer(histogram_prog, 0, key_src, readonly=True)
            bind_buffer(histogram_prog, 1, histogram_buffer, readonly=False)
            
            dispatch_compute(num_workgroups, 1, 1)
            barrier()
            
            # Sort Step
            bind_shader(sort_prog)
            set_uniform(sort_prog, "g_shift", 8 * i)
            
            if i % 2 == 0:
                bind_buffer(sort_prog, 0, key_buffer, readonly=True)
                bind_buffer(sort_prog, 1, key_buffer2, readonly=False)
                bind_buffer(sort_prog, 2, val_buffer, readonly=True)
                bind_buffer(sort_prog, 3, val_buffer2, readonly=False)
            else:
                bind_buffer(sort_prog, 0, key_buffer2, readonly=True)
                bind_buffer(sort_prog, 1, key_buffer, readonly=False)
                bind_buffer(sort_prog, 2, val_buffer2, readonly=True)
                bind_buffer(sort_prog, 3, val_buffer, readonly=False)
            
            bind_buffer(sort_prog, 4, histogram_buffer, readonly=True)
            
            dispatch_compute(num_workgroups, 1, 1)
            barrier()
    else:
        sorter.sort(key_buffer, val_buffer, sort_count)
    
    # 6. Copy Sorted
    if use_gpu_sort:
        if 4 % 2 != 0:
            read_buf = val_buffer2
        else:
            read_buf = val_buffer
        
        write_buf = splat_vao.element_buffer
        gl_copy_buffer_sub_data(read_buf, write_buf, 0, 0, sort_count * 4)
    else:
        write_buf = splat_vao.element_buffer
        gl_copy_buffer_sub_data(val_buffer, write_buf, 0, 0, sort_count * 4)
    
    # 7. Render
    render_instanced_quads(splat_vao, splat_count=num_points)
```

## Subtopics

### [SplatXR On-Headset 3D Gaussian Splatting Renderer](18166-splatxr-on-headset-3d-gaussian-splatting-renderer.md)
SplatXR is a Unity-based renderer designed to display 3D Gaussian Splatting (3DGS) assets directly on Extended Reality (XR) headsets, supporting both in-editor previews and on-headset execution with automatic camera switching. It distinguishes itself from general-purpose GPU-sorted renderers by offloading the depth-sorting of splats to a background CPU thread at a configurable rate, allowing the GPU shader to focus solely on rasterization and alpha-blending. This approach trades off sorting latency for reduced GPU overhead, making it suitable for mobile XR hardware where computational budgets are shared with other system tasks.

## Operating characteristics
*   **Time Complexity:** Sorting is $O(N \log N)$ or $O(N)$ depending on the radix sort implementation (GPU multi-radix or CPU radix). Rendering is $O(N)$ for instanced drawing.
*   **Memory Complexity:** $O(N)$ for storing positions, keys, values, and histograms.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Not given in the sources.
*   **Strengths:** Reduces GPU overhead by offloading sorting to CPU, suitable for mobile XR hardware [S1, unofficial]. Stable within-batch alpha-blend order prevents splat popping during slow camera orbits [S2, unofficial].
*   **Limitations:** 24-bit radix sort has artifacts on some datasets, so 32-bit sort is used by default [S1, unofficial].
*   **When to use:** Mobile XR hardware, real-time on-device rendering [S1, unofficial][S2, unofficial].
*   **When not to use:** When GPU sorting is preferred or hardware does not support CPU offloading [S1, unofficial].

## Background
*   **Origin:** Splatapult is a program to display 3D Gaussian Splatting files [S1, unofficial].
