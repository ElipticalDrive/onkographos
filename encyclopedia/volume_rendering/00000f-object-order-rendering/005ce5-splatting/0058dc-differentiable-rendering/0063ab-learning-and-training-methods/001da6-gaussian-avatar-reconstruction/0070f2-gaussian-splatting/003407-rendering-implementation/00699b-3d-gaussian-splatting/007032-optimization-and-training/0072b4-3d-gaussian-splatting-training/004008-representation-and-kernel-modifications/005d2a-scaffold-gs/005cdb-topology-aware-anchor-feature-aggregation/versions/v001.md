# Topology-Aware Anchor Feature Aggregation

Also called: Anchor Feature Aggregation, Cross-level feature aggregation

## Overview
Topology-Aware Anchor Feature Aggregation is a mechanism for aggregating features across different levels of a hierarchical anchor structure to improve texture and edge consistency in large-scale 3D Gaussian Splatting, addressing feature isolation [S1, unofficial]. It sets itself apart from sibling methods like [Scaffold-GS Integration](12513-scaffold-gs-integration.md) by explicitly enforcing topological containment relations between anchors at adjacent hierarchical levels, ensuring that feature aggregation respects the spatial hierarchy rather than treating all nearby anchors equally.

## How it works
**Inputs and Outputs**
*   **Input:** A set of anchors $\mathcal{A}$ organized into levels $L$. Each anchor $a_i$ has a position $p_i$, a level $l_i$, and a feature vector $f_i$.
*   **Output:** Aggregated features for each anchor at level $l$, incorporating information from anchors at levels $l-1$ (parents) and $l+1$ (children).

**Data Structures**
*   **Anchor Set:** A list of anchors, each containing position $p_i \in \mathbb{R}^3$, level $l_i \in \mathbb{Z}$, and feature $f_i$.
*   **Indicator Masks:** Two boolean arrays $m_{par}, m_{chi} \in \{0, 1\}^N$, where $N$ is the total number of anchors. $m_i^{par}=1$ if anchor $i$ acts as a parent, $m_i^{chi}=1$ if it acts as a child. These are cached based on anchor positions and levels.

**Steps**

1.  **Determine Anchor Activity (Parent/Child Roles):**
    For each anchor $a_i$ at level $l_i$:
    *   **Child Role:** $a_i$ is active as a child if there exists an anchor $a_j$ at level $l_i - 1$ such that the grid coordinate of $a_j$ falls within the voxel defined by $a_i$'s parent grid. Specifically, the condition is:
        $$ \text{round}\left(\frac{p_j - o}{v_{l_i-1}}\right) = g_{i,par} $$
        where $o$ is the origin, $v_{l_i-1}$ is the voxel size at level $l_i-1$, and $g_{i,par}$ is the grid coordinate of the parent voxel of $a_i$.
    *   **Parent Role:** Symmetrically, an anchor $a_j$ at level $l_j$ is active as a parent if at least one anchor $a_i$ at level $l_j + 1$ falls within its voxel.

2.  **Encode Roles using Indicator Masks:**
    Create two indicator masks $m_{par}, m_{chi} \in \{0, 1\}^N$ encoding the parent and child roles over the full anchor set. If anchor $i$ satisfies the condition for being a parent, $m_i^{par} = 1$, else $0$. Similarly for $m_i^{chi}$.

3.  **Efficient Containment Lookup:**
    To avoid pairwise comparisons of order $|V_l| \times |V_{l \pm 1}|$, encode each grid coordinate as a 64-bit integer using a spatial hash function:
    $$ h(g) = (g_x p_1) \oplus (g_y p_2) \oplus (g_z p_3) $$
    where $g_x, g_y, g_z$ are grid coordinates, $p_1, p_2, p_3$ are large primes, and $\oplus$ is bitwise XOR. Perform sorted lookup by binary search on the hashed coordinates to determine containment relations efficiently. The total cost for this lookup is $O(N \log N)$ [S1, unofficial].

4.  **Compute Per-Anchor Weights:**
    Calculate weights for parent and child roles using a parameter $\alpha \in [0, 1]$:
    $$ w_i^{par} = m_i^{par} + \alpha (1 - m_i^{par}) $$
    $$ w_i^{chi} = m_i^{chi} + \alpha (1 - m_i^{chi}) $$
    Here, $\alpha$ controls the weight assigned to topologically isolated anchors. $\alpha = 1$ recovers a uniform mean, while $\alpha = 0$ assigns zero weight to anchors not in a valid containment relation [S1, unofficial].

5.  **Soft-Weighted Aggregation:**
    Compute the aggregated features for anchors at level $l$ using soft-weighted means:
    $$ A(\{f_i\}_{i \in V_{l-1}}) = \frac{\sum_{i \in V_{l-1}} w_i^{par} f_i}{\max_{i \in V_{l-1}} w_i^{par}, \varepsilon} $$
    $$ A(\{f_i\}_{i \in V_{l+1}}) = \frac{\sum_{i \in V_{l+1}} w_i^{chi} f_i}{\max_{i \in V_{l+1}} w_i^{chi}, \varepsilon} $$
    where $V_{l-1}$ and $V_{l+1}$ are the sets of parent and child anchors respectively, and $\varepsilon$ is a stability constant [S1, unofficial].

**Parameters**
*   $\alpha \in [0, 1]$: Controls the weight for isolated anchors. Typical value determined empirically via ablation study [S1, unofficial].
*   $\varepsilon = 10^{-6}$: Numerical stability constant [S1, unofficial].
*   $p_1, p_2, p_3$: Large primes for spatial hashing [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Zero Context:** When $\alpha = 0$ and no active anchor is visible in the corresponding adjacent level, the resulting context is the zero vector [S1, unofficial].
*   **Mask Caching:** The masks $m_{par}$ and $m_{chi}$ depend only on anchor positions and levels and are cached while the anchor set remains unchanged [S1, unofficial].

**Pseudocode**

```python
import numpy as np

def spatial_hash(g, p1, p2, p3):
    """
    Encode grid coordinates as 64-bit integer using spatial hash.
    g: array of shape (N, 3) with grid coordinates (gx, gy, gz)
    p1, p2, p3: large primes
    """
    # Ensure integer arithmetic for bitwise operations
    gx = g[:, 0].astype(np.int64)
    gy = g[:, 1].astype(np.int64)
    gz = g[:, 2].astype(np.int64)
    
    h = (gx * p1) ^ (gy * p2) ^ (gz * p3)
    return h

def determine_activity(anchors, origin, voxel_sizes):
    """
    Determine parent and child activity masks for anchors.
    anchors: list of dicts with 'pos' (np.array), 'level' (int)
    origin: np.array (3,)
    voxel_sizes: dict mapping level to voxel size float
    """
    n = len(anchors)
    m_par = np.zeros(n, dtype=np.int32)
    m_chi = np.zeros(n, dtype=np.int32)
    
    # Group anchors by level
    levels = sorted(list(set(a['level'] for a in anchors)))
    anchors_by_level = {l: [] for l in levels}
    for i, a in enumerate(anchors):
        anchors_by_level[a['level']].append(i)
        
    # Precompute grid coordinates for all anchors
    # g = round((p - o) / v_l)
    grid_coords = np.zeros((n, 3), dtype=np.float64)
    for i, a in enumerate(anchors):
        l = a['level']
        v = voxel_sizes[l]
        grid_coords[i] = np.round((a['pos'] - origin) / v)
        
    # Compute hashes for all anchors
    # Using arbitrary large primes for demonstration
    p1, p2, p3 = 1000000007, 1000000009, 1000000021
    hashes = spatial_hash(grid_coords, p1, p2, p3)
    
    # Sort hashes to enable binary search
    sorted_indices = np.argsort(hashes)
    sorted_hashes = hashes[sorted_indices]
    
    for l in levels:
        if l == 0:
            continue # No parent level
        if l == max(levels):
            continue # No child level
            
        parent_level = l - 1
        child_level = l + 1
        
        parent_indices = anchors_by_level[parent_level]
        child_indices = anchors_by_level[child_level]
        
        # Determine Child Role for current level anchors
        # An anchor i at level l is a child if its parent voxel contains an anchor j at level l-1
        # Parent voxel of i is determined by grid_coords[i] at level l-1? 
        # The formula says: round((pj - o)/v_{l-1}) == g_{i,par}
        # g_{i,par} is the grid coordinate of the parent voxel of anchor i.
        # Assuming g_{i,par} is simply grid_coords[i] computed at level l-1 resolution?
        # Or is it the grid coordinate of the anchor i itself, but interpreted in the parent's grid?
        # The text says: "round((pj - o)/v_{l-1}) = g_{i,par}"
        # This implies g_{i,par} is a specific grid coordinate associated with anchor i.
        # In hierarchical grids, the parent voxel of a child at level l is the voxel at level l-1 containing it.
        # So g_{i,par} should be the grid coordinate of the voxel at level l-1 that contains anchor i.
        # This is exactly grid_coords[i] if we compute it using v_{l-1}.
        
        # Let's re-calculate grid coords for parent level for all anchors to find parent voxels
        grid_coords_parent_level = np.zeros((n, 3), dtype=np.float64)
        for i, a in enumerate(anchors):
            v = voxel_sizes[parent_level]
            grid_coords_parent_level[i] = np.round((a['pos'] - origin) / v)
            
        hashes_parent_level = spatial_hash(grid_coords_parent_level, p1, p2, p3)
        sorted_indices_parent = np.argsort(hashes_parent_level)
        sorted_hashes_parent = hashes_parent_level[sorted_indices_parent]
        
        # For each anchor i at level l, find its parent voxel hash
        # The parent voxel of anchor i is the voxel at level l-1 containing it.
        # We need to check if any anchor j at level l-1 has grid coordinate equal to this parent voxel.
        
        # Indices of anchors at level l
        current_indices = anchors_by_level[l]
        
        for i in current_indices:
            # Get the grid coordinate of the parent voxel for anchor i
            # This is the grid coordinate of anchor i computed at level l-1
            parent_voxel_hash = hashes_parent_level[i]
            
            # Check if any anchor j at parent_level has this hash
            # Binary search in sorted_hashes_parent
            pos = np.searchsorted(sorted_hashes_parent, parent_voxel_hash)
            is_child = False
            if pos < len(sorted_hashes_parent) and sorted_hashes_parent[pos] == parent_voxel_hash:
                # Found an anchor at parent level in the same voxel
                is_child = True
            
            if is_child:
                m_chi[i] = 1
                
        # Determine Parent Role for current level anchors
        # An anchor j at level l is a parent if at least one anchor i at level l+1 falls within its voxel.
        # This is symmetric. We iterate over children at l+1 and mark their parents at l.
        
        child_indices = anchors_by_level[child_level]
        
        # Compute grid coords for child level for all anchors to find child voxels
        grid_coords_child_level = np.zeros((n, 3), dtype=np.float64)
        for i, a in enumerate(anchors):
            v = voxel_sizes[child_level]
            grid_coords_child_level[i] = np.round((a['pos'] - origin) / v)
            
        hashes_child_level = spatial_hash(grid_coords_child_level, p1, p2, p3)
        sorted_indices_child = np.argsort(hashes_child_level)
        sorted_hashes_child = hashes_child_level[sorted_indices_child]
        
        for j in current_indices:
            # Get the grid coordinate of the voxel for anchor j at child level
            # This is the grid coordinate of anchor j computed at level l+1
            child_voxel_hash = hashes_child_level[j]
            
            # Check if any anchor i at child_level has this hash
            pos = np.searchsorted(sorted_hashes_child, child_voxel_hash)
            is_parent = False
            if pos < len(sorted_hashes_child) and sorted_hashes_child[pos] == child_voxel_hash:
                is_parent = True
                
            if is_parent:
                m_par[j] = 1
                
    return m_par, m_chi

def aggregate_features(anchors, m_par, m_chi, alpha, epsilon):
    """
    Aggregate features using topology-aware weights.
    """
    n = len(anchors)
    aggregated_features = np.zeros_like(anchors[0]['feat']) # Assuming all features same shape
    
    # This function assumes we are aggregating for a specific level l
    # We need to group anchors by level and perform aggregation per level
    # For simplicity, we return the weights and masks, actual aggregation depends on level grouping
    
    # Calculate weights
    w_par = m_par + alpha * (1 - m_par)
    w_chi = m_chi + alpha * (1 - m_chi)
    
    return w_par, w_chi

def soft_weighted_mean(features, weights, epsilon):
    """
    Compute soft-weighted mean.
    """
    numerator = np.sum(weights[:, np.newaxis] * features, axis=0)
    denominator = np.maximum(np.max(weights), epsilon)
    return numerator / denominator
```

## Operating characteristics
*   **Time Complexity:** The lookup cost for determining containment relations is $O(N \log N)$ due to the sorted binary search on hashed coordinates [S1, unofficial].
*   **Memory Complexity:** Requires storage for indicator masks $m_{par}, m_{chi}$ and cached hashes. The masks are cached while the anchor set remains unchanged [S1, unofficial].
*   **Performance:** On the MatrixCity benchmark, TopoGS improves over Geo-GS by approximately 0.45 dB in PSNR [S1, unofficial]. On the WHU benchmark, it achieves 40.68 dB PSNR on WHU-Area 1, 40.61 dB on WHU-Area 4, and 37.18 dB on WHU-Area 5 [S1, unofficial]. It also reduces LPIPS from 0.137 to 0.084 on the Truck scene, a relative reduction of approximately 39% [S1, unofficial].
*   **Strengths:** Improves texture and edge consistency; produces smoother normals and cleaner depth without additional geometric supervision; stable across different scene types, capture modalities, and benchmark saturation levels [S1, unofficial].
*   **Limitations:** Performance depends on the hierarchical structure and anchor distribution; $\alpha$ needs empirical tuning [S1, unofficial].

## Background
Topology-Aware Anchor Feature Aggregation is used in TopoGS, which is built on the CityGS-X backbone [S1, unofficial]. It was introduced to address feature isolation in large-scale 3D Gaussian Splatting by leveraging the topological relationships between anchors at different hierarchical levels. The method was proposed in the paper "TopoGS: Topology-Aware Anchor Feature Aggregation for Large-Scale 3D Gaussian Splatting" [S1, unofficial].
