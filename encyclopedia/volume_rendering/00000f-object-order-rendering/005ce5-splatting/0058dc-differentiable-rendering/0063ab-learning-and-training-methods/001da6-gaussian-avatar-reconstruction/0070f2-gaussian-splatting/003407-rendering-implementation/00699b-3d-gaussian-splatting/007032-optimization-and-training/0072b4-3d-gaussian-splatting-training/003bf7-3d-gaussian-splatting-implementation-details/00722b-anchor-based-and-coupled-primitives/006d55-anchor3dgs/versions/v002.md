# Anchor3DGS

Also called: Anchor-based 3D Gaussian Splatting

## Overview
Anchor3DGS is a pose-free, feed-forward framework for 3D Gaussian Splatting (3DGS) that replaces pixel-aligned paradigms with a compact anchor-based representation [S1, unofficial]. It places a fixed number of 3D anchors on a geometry-aware scaffold, decoupling the final Gaussian count from input resolution and view count, thereby allocating capacity based on scene content rather than data volume [S1, unofficial]. Unlike pixel-aligned methods that produce millions of Gaussians proportional to input views, Anchor3DGS achieves comparable dense-view quality with an order of magnitude fewer primitives (0.26M) and significantly lower storage, while maintaining state-of-the-art performance in sparse-view settings through entropy-guided sampling and cross-anchor attention [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $V$ input images (context views) with known or estimated poses and intrinsics. The maximum input resolution is 448 pixels on the longer side [S1, unofficial].
*   **Outputs:** A set of $K \times N$ 3D Gaussians defined by position, scale, rotation, color, and opacity, ready for differentiable rasterization [S1, unofficial].

**Data Structures:**
1.  **Anchor Embeddings ($Z$):** A tensor of shape $(N, D_z)$, where $N$ is the anchor budget and $D_z = 128$ is the embedding dimension [S1, unofficial].
2.  **Gaussian Attributes:** For each anchor, a decoder predicts $K$ Gaussians. Each Gaussian is defined by standard 3DGS parameters: mean $\mu \in \mathbb{R}^3$, covariance $\Sigma \in \mathbb{R}^{3 \times 3}$ (or quaternion/scale), color $c \in \mathbb{R}^3$, and opacity $\alpha \in \mathbb{R}$ [S1, unofficial].
3.  **Refinement Features ($H$):** A per-Gaussian feature vector of dimension $D_h = 16$ used for rendering refinement [S1, unofficial].

**Algorithm Steps:**

1.  **Geometry Backbone Prediction:**
    A geometry backbone (initialized with pretrained VGGT weights [S1, unofficial]) processes the input images to predict depth maps and camera poses. The patch-embedding layer is frozen during fine-tuning [S1, unofficial].

2.  **Anchor Initialization and Sampling:**
    Anchors are initialized on a geometry-aware scaffold derived from the backbone's depth predictions. To concentrate capacity on visually complex regions, **entropy-guided sampling** is applied. Uniform grid subsampling is replaced by this strategy to allocate the limited anchor budget more reasonably [S1, unofficial].

3.  **Multi-View Aggregation:**
    Anchor features are encoded using **occlusion-aware multi-view aggregation**. Instead of plain mean pooling, this step aggregates features from multiple context views while accounting for occlusions, ensuring robust feature representation for each anchor [S1, unofficial].

4.  **Cross-Anchor Self-Attention:**
    A self-attention mechanism propagates context between anchors. This step specifically targets poorly-observed areas, allowing information from well-observed regions to fill in gaps, mitigating the holes prevalent in pixel-aligned methods [S1, unofficial].

5.  **Gaussian Decoding:**
    A network decodes the refined anchor embeddings $Z$ into Gaussian attributes. Each anchor $n$ produces $K$ Gaussians. The decoder outputs the necessary parameters for position, scale, rotation, color, and opacity [S1, unofficial].

6.  **Rendering Refinement:**
    The initial splatted RGB images are refined using an **enhancement UNet**. This step recovers fine high-frequency details that the raw splatting process struggles to capture [S1, unofficial].

7.  **Training Loss:**
    The model is trained using a composite loss function:
    $$ \mathcal{L} = \lambda_{\text{mse}} \mathcal{L}_{\text{mse}} + \lambda_{\text{lpips}} \mathcal{L}_{\text{lpips}} + \lambda_{\text{depth}} \mathcal{L}_{\text{depth}} $$
    where $\mathcal{L}_{\text{mse}}$ is the Mean Squared Error between refined renderings and ground truth, $\mathcal{L}_{\text{lpips}}$ is the LPIPS loss, and $\mathcal{L}_{\text{depth}}$ is a depth-consistency loss encouraging rasterized depth to agree with the geometry backbone's predictions [S1, unofficial].

**Pseudocode:**

import torch.nn as nn
import torch.nn.functional as F

class Anchor3DGS:
    def __init__(self, N=32768, K=8, D_z=128, D_h=16):
        """
        Initialize Anchor3DGS model.
        
        Args:
            N (int): Total number of 3D anchors per scene. Default: 32,768.
            K (int): Number of Gaussians decoded per anchor. Default: 8.
            D_z (int): Dimension of each anchor embedding. Default: 128.
            D_h (int): Dimension of per-Gaussian feature vector for refinement. Default: 16.
        """
        self.N = N
        self.K = K
        self.D_z = D_z
        self.D_h = D_h
        
        # Geometry Backbone (VGGT-based)
        # Initialized with pretrained VGGT weights. Patch-embedding layer frozen.
        self.geometry_backbone = VGGTBackbone()
        
        # Anchor Feature Encoder
        # Includes occlusion-aware multi-view aggregation
        self.anchor_encoder = AnchorFeatureEncoder(D_z)
        
        # Cross-Anchor Self-Attention
        self.self_attention = CrossAnchorSelfAttention(D_z)
        
        # Gaussian Decoder
        # Decodes anchor embeddings to K Gaussians per anchor
        self.gaussian_decoder = GaussianDecoder(D_z, K)
        
        # Rendering Refinement UNet
        self.refinement_unet = EnhancementUNet(input_channels=3, output_channels=3, feature_dim=D_h)
        
        # Loss weights
        self.lambda_mse = 1.0
        self.lambda_lpips = 0.05
        self.lambda_depth = 0.1

    def forward(self, images, poses=None):
        """
        Forward pass for training or inference.
        
        Args:
            images (Tensor): Input images of shape (B, V, C, H, W).
            poses (Tensor, optional): Camera poses. If None, estimated by backbone.
            
        Returns:
            Tensor: Refined rendered images.
            Tensor: Predicted Gaussians (for loss calculation).
        """

        # Step 1: Geometry Backbone Prediction
        # Predict depth maps and potentially refine poses
        # geometry_backbone outputs depth maps and potentially pose corrections
        depth_maps, refined_poses = self.geometry_backbone(images)
        
        # Step 2: Anchor Initialization and Entropy-Guided Sampling
        # Initialize anchors on geometry-aware scaffold
        # Apply entropy-guided sampling to select anchor locations
        # This concentrates capacity on visually complex regions
        anchor_positions = self.entropy_guided_sampling(depth_maps, refined_poses, self.N)
        
        # Step 3: Multi-View Aggregation
        # Encode anchor features using occlusion-aware multi-view aggregation
        # Instead of plain mean pooling
        anchor_features = self.anchor_encoder(images, anchor_positions, refined_poses)
        
        # Step 4: Cross-Anchor Self-Attention
        # Propagate context to poorly-observed areas
        anchor_features = self.self_attention(anchor_features)
        
        # Step 5: Gaussian Decoding
        # Decode anchor embeddings to Gaussian attributes
        # Each anchor produces K Gaussians
        gaussians = self.gaussian_decoder(anchor_features)
        
        # Step 6: Rendering
        # Render Gaussians to images
        rendered_images = render_gaussians(gaussians, refined_poses, image_size=(H, W))
        
        # Step 7: Rendering Refinement
        # Use enhancement UNet to recover fine high-frequency details
        refined_images = self.refinement_unet(rendered_images)
        
        return refined_images, gaussians

    def compute_loss(self, refined_images, gaussians, ground_truth_images, ground_truth_depths):
        """
        Compute the total training loss.
        
        Args:
            refined_images (Tensor): Refined rendered images.
            gaussians (Tensor): Predicted Gaussians.
            ground_truth_images (Tensor): Ground truth images.
            ground_truth_depths (Tensor): Ground truth depth maps (if available).
            
        Returns:
            Tensor: Total loss.
        """
        # MSE Loss
        loss_mse = F.mse_loss(refined_images, ground_truth_images)
        
        # LPIPS Loss
        loss_lpips = lpips_loss(refined_images, ground_truth_images)
        
        # Depth Consistency Loss
        # Encourage rasterized depth from Gaussians to agree with geometry backbone predictions
        rasterized_depth = rasterize_depth(gaussians, refined_poses, image_size=(H, W))
        # Note: geometry_backbone_depths are from Step 1
        loss_depth = F.mse_loss(rasterized_depth, geometry_backbone_depths)
        
        total_loss = (self.lambda_mse * loss_mse + 
                      self.lambda_lpips * loss_lpips + 
                      self.lambda_depth * loss_depth)
        
        return total_loss

    def entropy_guided_sampling(self, depth_maps, poses, N):
        """
        Sample anchor positions based on entropy of depth maps.
        
        Args:
            depth_maps (Tensor): Predicted depth maps.
            poses (Tensor): Camera poses.
            N (int): Number of anchors to sample.
            
        Returns:
            Tensor: Selected anchor positions in 3D space.
        """
        # Calculate entropy of depth maps to identify visually complex regions
        # Higher entropy indicates more detail/complexity

        # This concentrates capacity on visually complex regions

        selected_indices = sample_with_entropy(entropy, N)

    def anchor_encoder(self, images, anchor_positions, poses):
        """
        Encode anchor features using occlusion-aware multi-view aggregation.
        
        Args:
            images (Tensor): Input images.

        """
        # Project anchor positions to each view

        # Sample features from each view at projected locations
        view_features = sample_features(images, projections)
        
        # Occlusion-aware aggregation
        # Check visibility of each anchor in each view
        # Weight features based on occlusion confidence
        aggregated_features = occlusion_aware_mean_pool(view_features, visibility_masks)
        
        return aggregated_features

    def self_attention(self, anchor_features):
        """
        Apply cross-anchor self-attention.
        
        Args:
            anchor_features (Tensor): Anchor features of shape (N, D_z).
            
        Returns:
            Tensor: Refined anchor features.
        """
        # Standard self-attention mechanism
        # Q, K, V = Linear(anchor_features)
        # attention_scores = softmax(Q @ K^T / sqrt(D_z))
        # output = attention_scores @ V

        refined_features = anchor_features + self_attention_layer(anchor_features)
        
        return refined_features

    def gaussian_decoder(self, anchor_features):
        """
        Decode anchor features to Gaussian attributes.
        
        Args:
            anchor_features (Tensor): Refined anchor features.
            
        Returns:
            Tensor: Gaussian attributes for all N*K Gaussians.
        """

    def refinement_unet(self, rendered_images):
        """
        Refine rendered images using UNet.
        
        Args:

        Returns:

        """

        return refined_images

**Parameters:**
*   **Anchor Budget ($N$):** 32,768 [S1, unofficial].
*   **Decoded Gaussians per Anchor ($K$):** 8 [S1, unofficial].
*   **Anchor Embedding Dimension ($D_z$):** 128 [S1, unofficial].
*   **Per-Gaussian Feature Vector Dimension ($D_h$):** 16 [S1, unofficial].
*   **Geometry Backbone:** Initialized with pretrained VGGT weights [S1, unofficial].
*   **Learning Rate:** AdamW with peak learning rate $2 \times 10^{-4}$ and 1,000 warmup steps. Geometry backbone fine-tuned with 0.1x smaller learning rate; patch-embedding layer frozen [S1, unofficial].
*   **Training Context Views:** Randomly sampled between 2 and 16 per scene [S1, unofficial].
*   **Input Resolution:** Maximum 448 pixels on the longer side during training; 448x448 at inference [S1, unofficial].
*   **Loss Weights:** $\lambda_{\text{mse}} = 1.0$, $\lambda_{\text{lpips}} = 0.05$, $\lambda_{\text{depth}} = 0.1$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Geometry Backbone Dependency:** Performance relies heavily on the prediction quality of the geometry backbone. Inaccurate poses or noisy depth maps from the backbone degrade anchor placement and final rendering [S1, unofficial].
*   **Fixed Anchor Budget:** The anchor budget is fixed regardless of scene scale. Very large or unbounded scenes may benefit from a scene-adaptive budget, as the current fixed budget may be insufficient [S1, unofficial].

## Subtopics

### SOGS (Second-Order Anchor for Advanced 3D Gaussian Splatting)
Uses second-order statistics (covariance) of anchor features to augment feature vectors before prediction. Chooses this when feature richness is critical for complex textures. [Link](13171-sogs-second-order-anchor-for-advanced-3d-gaussian-splatting.md)

### Coupled Gaussian Primitives Rendering
Predicts residual offsets or features for coupled primitives based on anchor primitives. Chooses this when explicit coupling between anchor and derived primitives is needed for structural fidelity. [Link](20018-coupled-gaussian-primitives-rendering.md)

## Operating characteristics
*   **Time Complexity:** Inference is feed-forward and takes seconds (e.g., 2.9s on H800 for VR-NeRF), compared to minutes for per-scene optimization methods like VGGT+3DGS [S1, unofficial].
*   **Memory Complexity:** Storage is compact. 0.26M Gaussians per scene require ~35MB, compared to >650MB for pixel-aligned methods producing several million Gaussians [S1, unofficial].
*   **Measured Performance:**
    *   **Sparse-View (3 views) on VR-NeRF:** PSNR 23.69 (Full model) vs 22.50 (w/o enhancement), 23.03 (w/o self-attention), 23.28 (w/o occ-aggregation), 22.16 (w/o entropy-sample) [S1, unofficial].
    *   **Dense-View (32 views) on VR-NeRF:** PSNR 24.56, SSIM 0.815, LPIPS 0.297 [S1, unofficial].
    *   **Dense-View (32 views) on DL3DV:** PSNR 19.52, SSIM 0.593, LPIPS 0.364 [S1, unofficial].
*   **Scaling:** Gaussian count (0.26M) is independent of input resolution and view count, unlike pixel-aligned methods where count scales with views/resolution [S1, unofficial].
*   **Strengths:** State-of-the-art in sparse-view settings; order of magnitude fewer Gaussians and lower storage in dense-view settings; fast feed-forward inference; mitigates holes in poorly observed regions.
*   **Limitations:** Relies on geometry backbone accuracy; fixed anchor budget may not suit very large/unbounded scenes; refinement UNet adds some computational overhead compared to raw splatting.
*   **When to Use:** When fast, pose-free novel view synthesis is required with limited storage/compute, especially in sparse-view scenarios.
*   **When Not to Use:** When per-scene optimization is acceptable for higher quality, or when scenes are extremely large and require adaptive anchor budgets.

## Background
Anchor3DGS was introduced in the paper "Anchor3DGS: Feed-Forward 3D Gaussian Splatting with Compact Anchor-Based Representation" [S1, unofficial]. It addresses the limitations of pixel-aligned 3DGS methods, which produce large numbers of Gaussians proportional to input views and require per-scene optimization. By adopting an anchor-based paradigm, it enables pose-free, feed-forward reconstruction with compact representation. Evaluated on VR-NeRF, MipNeRF360, and DL3DV datasets [S1, unofficial].
