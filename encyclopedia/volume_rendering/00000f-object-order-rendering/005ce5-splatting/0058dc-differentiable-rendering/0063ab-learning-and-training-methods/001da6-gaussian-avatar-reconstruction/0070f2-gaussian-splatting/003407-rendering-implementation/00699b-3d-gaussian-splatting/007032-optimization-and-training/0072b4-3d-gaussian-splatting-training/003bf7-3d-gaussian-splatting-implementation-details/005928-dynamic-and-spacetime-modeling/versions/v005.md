# Dynamic and Spacetime Modeling

Also called: Dynamic 3D Gaussian Splatting, 4D Gaussian Splatting, Spacetime Gaussian Splatting

## Overview
Dynamic and Spacetime Modeling extends static 3D Gaussian Splatting to represent and render time-varying scenes by introducing temporal dependencies into Gaussian parameters or via deformation fields [S1]. It solves the problem of high-fidelity, real-time rendering of dynamic content where static representations fail to capture motion [S1]. Unlike static methods, these approaches decouple geometry from appearance over time, using either learned deformation fields in a canonical space [S1] or explicit polynomial motion models , distinguishing them from entangled methods that condition the radiance field directly on time [S1].

## Shared principles
All methods in this family share the core 3D Gaussian Splatting representation: a set of anisotropic 3D Gaussians defined by center position $\mathbf{x}$, rotation quaternion $\mathbf{r}$, scaling vector $\mathbf{s}$, opacity $\sigma$, and view-dependent color features (typically Spherical Harmonics or neural features) [S1]. The rendering process remains differentiable rasterization, projecting 3D Gaussians to 2D screen space using the covariance transformation $\Sigma' = \mathbf{J} \mathbf{V} \Sigma \mathbf{V}^T \mathbf{J}^T$ and alpha blending [S1].

The fundamental extension is the introduction of time $t$ as an input variable. This is achieved through one of two primary mechanisms:
1.  **Deformation Fields:** A neural network $F_\theta$ maps canonical 3D positions and time to offsets $(\delta\mathbf{x}, \delta\mathbf{r}, \delta\mathbf{s})$, deforming static Gaussians into dynamic ones [S1].
2.  **Explicit Spacetime Parameters:** Gaussian parameters (position, rotation, opacity) are explicitly parameterized as functions of time, such as polynomial coefficients or temporal opacity curves .

Training involves optimizing these time-dependent parameters against multi-view video sequences using L1 and D-SSIM losses [S1]. Adaptive density control (densification, splitting, pruning) is applied iteratively, often with specific schedules to stabilize motion parameters [S1].

## Subtopics

### [SpacetimeGaussians Training Pipeline](15898-spacetimegaussians-training-pipeline.md)
A training procedure that manages the lifecycle of Gaussian primitives (creation, splitting, pruning, and freezing) based on iteration-specific thresholds. It explicitly freezes motion parameters after an initial learning phase (e.g., iteration 8001) to stabilize the representation.

### [Deformable 3D Gaussians](16260-deformable-3d-gaussians.md)
A framework that learns time-independent 3D Gaussians in a canonical space and uses a learned deformation field (MLP) to model time-varying geometry. It introduces Annealing Smooth Training (AST) to mitigate temporal jitter from inaccurate camera poses.

### [Spacetime Gaussian Feature Splatting](16313-spacetime-gaussian-feature-splatting.md)
A representation using polynomial motion models for position and rotation, and a compact neural feature vector processed by a tiny MLP. It replaces spherical harmonics with explicit temporal opacity and feature splatting, enabling real-time rendering of static, dynamic, and transient content.

### [Rendering-aware QP Offset Modelling](21036-rendering-aware-qp-offset-modelling.md)
A compression-aware method that approximates optimal Quantization Parameter (QP) distributions for RAHT coding of 3DGS by linking hierarchical data structure to visual impact via spatial density.

## Background
The extension of 3D Gaussian Splatting to dynamic scenes emerged to address the limitations of implicit neural representations (like NeRF) in real-time rendering and the inability of static 3DGS to handle motion. Deformable 3D Gaussians [S1] and Spacetime Gaussian Feature Splatting  represent key developments in decoupling geometry deformation from appearance. These methods are used in applications requiring high-fidelity dynamic scene reconstruction, such as virtual production, autonomous driving simulation, and dynamic novel view synthesis [S1].
