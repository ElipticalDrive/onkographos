# DepthSplat


## Overview
DepthSplat is a feed-forward method for 3D Gaussian Splatting reconstruction that integrates pre-trained monocular depth features into a multi-view cost volume framework to produce robust depth maps and Gaussian parameters [S1]. It solves the problem of multi-view depth estimation failures in occlusions, low-textured areas, and non-Lambertian surfaces, while avoiding the scale ambiguities inherent in monocular depth estimation [S1]. Unlike TranSplat, which uses monocular features to refine coarse depth (vulnerable to error propagation), DepthSplat combines cost volumes and monocular features early in the pipeline, and unlike GS-LRM, it relies on explicit feature matching rather than heavy data-driven priors, making it significantly cheaper to train [S1].

## How it works
**Inputs:** $N$ input images $\{I_i\}_{i=1}^N$ with corresponding projection matrices $\{P_i\}_{i=1}^N$, where $I_i \in \mathbb{R}^{H \times W \times 3}$ and $P_i \in \mathbb{R}^{3 \times 4}$ [S1].

**Outputs:** A set of 3D Gaussians $\mathcal{G} = \{\mu_j, \alpha_j, \Sigma_j, c_j\}$ for each pixel $j$ in the reference views, where $\mu_j$ is the 3D position, $\alpha_j$ is opacity, $\Sigma_j$ is covariance, and $c_j$ is color [S1].

**Data Structures:**
*   **Monocular Features:** Extracted per-view using a Vision Transformer (ViT).
*   **Cost Volume $C_i$:** For each view $i$, a tensor of size $\frac{H}{s} \times \frac{W}{s} \times D$, where $s$ is the downsampling factor and $D$ is the number of depth candidates [S1].
*   **Depth Map $D_i$:** Dense per-pixel depth prediction $\in \mathbb{R}^{H \times W}$ [S1].

**Parameters:**
*   **Downsampling factor $s$:** Controlled by the number of stride-2 $3 \times 3$ convolutions in the feature extraction. $s=4$ if two convolutions are used; $s=8$ if three are used [S1].
*   **Depth candidates $D$:** Uniformly sampled from near/far depth ranges [S1].
*   **Multi-view Transformer:** Contains six stacked self- and cross-attention layers [S1].
*   **Neighbor Selection:** For $N > 2$, the top-2 nearest neighboring views are selected based on camera distance to the reference view [S1].

**Steps:**
1.  **Monocular Feature Extraction:** For each input image $I_i$, extract per-view features $F_i$ using a pre-trained ViT (Monocular Branch) [S1].
2.  **Depth Candidate Sampling:** For each view $i$, uniformly sample $D$ depth candidates $\{d_m\}_{m=1}^D$ from the near and far depth ranges [S1].
3.  **Feature Warping:** For each neighboring view $j$ (selected as top-2 nearest if $N>2$), warp the features $F_j$ to view $i$ using the camera projection matrix $P_i$ and each depth candidate $d_m$ to obtain warped features $\{F_{j \to i}^m\}_{m=1}^D$ [S1].
4.  **Cost Volume Construction:** Measure feature correlations via dot-product between the reference feature $F_i$ and the warped features $F_{j \to i}^m$. Stack these correlations to build the cost volume $C_i \in \mathbb{R}^{\frac{H}{s} \times \frac{W}{s} \times D}$ [S1]. If multiple neighbors are used ($N>2$), compute correlations for each and combine values with averaging [S1].
5.  **Feature Concatenation:** Concatenate the multi-view cost volumes $C_i$ with the extracted monocular features [S1].
6.  **Depth Regression:** Perform depth regression using a 2D U-Net architecture followed by a softmax layer to predict dense per-pixel depth $D_i$ [S1].
7.  **Gaussian Center Unprojection:** Unproject the predicted depth maps $D_i$ to 3D space using camera parameters $P_i$ to obtain Gaussian centers $\mu_j$ [S1].
8.  **Parameter Prediction:** Predict remaining Gaussian parameters (opacity $\alpha_j$, covariance $\Sigma_j$, color $c_j$) using an additional lightweight network/head in parallel with the depth regression [S1].
9.  **Rendering:** Render novel views using the splatting operation with the predicted 3D Gaussians [S1].

## Subtopics

### [Gaussian Graph Network](18863-gaussian-graph-network.md)
Gaussian Graph Network (GGN) is a feed-forward method that generates efficient and generalizable 3D Gaussian representations from multi-view images by modeling relations between Gaussian groups from different views using a Gaussian Graph structure. It solves the problem of artifacts and excessive memory costs caused by previous methods that simply combine pixel-aligned Gaussians from multiple views without capturing their inter-view relations. Unlike sibling methods that treat multi-view Gaussians as independent sets, GGN performs message passing and aggregation at the Gaussian level, allowing each Gaussian to benefit from connected groups in other views.

## Operating characteristics
**Time and Memory Complexity:** The method scales efficiently to a larger number of input views by selecting only the top-2 nearest neighboring views for cross-attention and cost volume construction, achieving a good speed-accuracy trade-off [S1].

**Measured Performance:** DepthSplat achieves state-of-the-art performance on ScanNet, RealEstate10K, and DL3DV datasets [S1]. It achieves promising feed-forward reconstruction results of large-scale or 360° scenes from 12 input views (512 × 960 resolutions) in 0.6 seconds [S1].

**Scaling:** The downsampling factor $s$ can be controlled by the number of stride-2 convolutions ($s=4$ or $s=8$), allowing flexibility in resolution and computational cost [S1].

**Strengths and Limitations:** DepthSplat mitigates multi-view depth estimation failures in occlusions, low-textured areas, and non-Lambertian surfaces by augmenting multi-view cost volumes with monocular features [S1]. It maintains multi-view consistency by using monocular features only as an augmentation to multi-view matching, avoiding scale ambiguities [S1]. Unlike TranSplat, it avoids error propagation by combining cost volume and monocular features early [S1]. Unlike GS-LRM, it is cheaper to train (4 GPUs vs 64 A100s) [S1].

**When to Use:** Use DepthSplat when robust multi-view depth prediction is required for challenging scenes (low texture, reflections) and when computational resources for training are limited compared to data-heavy methods like GS-LRM [S1].

## Background
DepthSplat was introduced to connect Gaussian splatting and depth estimation, studying their interactions [S1]. It leverages pre-trained monocular depth features to augment multi-view feature matching, enabling robust multi-view depth prediction and feed-forward 3D Gaussian splatting reconstruction [S1]. The method was trained on TartanAir, ScanNet, RealEstate10K, and DL3DV datasets [S1]. It also demonstrates that Gaussian splatting can serve as an unsupervised pre-training objective for learning powerful depth models from large-scale multi-view posed datasets [S1].
