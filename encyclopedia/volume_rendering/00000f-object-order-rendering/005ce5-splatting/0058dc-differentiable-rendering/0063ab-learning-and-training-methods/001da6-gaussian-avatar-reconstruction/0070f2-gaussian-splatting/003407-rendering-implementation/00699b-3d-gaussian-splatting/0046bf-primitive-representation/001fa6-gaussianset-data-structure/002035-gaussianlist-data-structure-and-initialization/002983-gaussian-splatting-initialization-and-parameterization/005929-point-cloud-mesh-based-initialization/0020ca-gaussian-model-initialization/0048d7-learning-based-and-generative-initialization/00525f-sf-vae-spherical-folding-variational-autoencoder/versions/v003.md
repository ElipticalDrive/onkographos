# SF-VAE (Spherical Folding Variational Autoencoder)
Also called: SFVAE, Spherical Folding VAE

## Overview
SF-VAE is a neural network architecture that encodes 3D Gaussian parameters into a latent space and decodes them using a spherical folding grid to reconstruct the geometry and color of the Gaussians [S1, unofficial]. It differs from heuristic initialization methods by enforcing geometric consistency through a learned latent representation and a structured folding mechanism [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 7-dimensional vector per sample [S1, unofficial].
*   **Output:** Reconstructed points (geometry) and potentially color [S1, unofficial].

**Data Structures:**
*   **SFModel:** The core neural network module with fields `input_dim=7`, `embedding_dim` (latent vector $z$ dimension), `grid_dim`, `vae` (boolean flag), and `deterministic` (boolean flag) [S1, unofficial].
*   **SFDecoder Grid:** A 2D grid of shape `[grid_dim^2, 2]` representing local coordinates, repeated for the batch size [S1, unofficial].
*   **Latent Space:** A 32-dimensional vector $z$ [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Create `SFModel` with `input_dim=7`, `embedding_dim` (default 32), `grid_dim` (default 24), `vae` flag, and `deterministic` flag [S1, unofficial]. Initialize the Chamfer loss criterion with `geo_weight=0.5` [S1, unofficial].
2.  **Encoding:** Pass the input vector through the encoder network to produce the mean ($\mu$) and log-variance ($\log\text{var}$) of the latent distribution [S1, unofficial].
3.  **Reparameterization:** Sample the latent vector $z$ from the distribution $\mathcal{N}(\mu, \sigma^2)$ using the reparameterization trick [G].
4.  **Decoding (Spherical Folding):** Process the latent vector $z$ through the decoder network, which utilizes the spherical folding grid of size `grid_dim` × `grid_dim` to reconstruct the 7-dimensional output parameters [S1, unofficial].
5.  **Loss Calculation:** 
    *   **Chamfer Loss:** Compute the Chamfer distance between the input points and the reconstructed centroids, weighted by `geo_weight=0.5` [S1, unofficial].
    *   **KL Divergence:** If `vae=True`, compute the Kullback-Leibler divergence loss:
        $$ L_{KL} = -0.5 \times \frac{1}{N} \sum_{i=1}^{N} (1 + \log\text{var}_i - \mu_i^2 - \exp(\log\text{var}_i)) $$
        where $N$ is the batch size (`input.size(0)`) [S1, unofficial].
    *   **Normalization Loss:** Apply an optional normalization loss term weighted by `norm_weight` (default 0) [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class SFVAE(nn.Module):
    def __init__(self, embedding_dim=32, grid_dim=24, norm_weight=0.0):
        super().__init__()
        self.embedding_dim = embedding_dim
        self.grid_dim = grid_dim
        self.norm_weight = norm_weight
        self.input_dim = 7
        self.geo_weight = 0.5
        
        # Encoder: Maps input (dim 7) to latent mean and log-variance
        self.encoder = nn.Sequential(
            nn.Linear(self.input_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, self.embedding_dim * 2)
        )
        
        # Decoder: Maps latent vector to reconstructed 7D output
        self.decoder = nn.Sequential(
            nn.Linear(self.embedding_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, self.input_dim)
        )
        
        # Spherical Folding Grid: shape [grid_dim^2, 2]
        u = torch.linspace(0, 1, grid_dim)
        v = torch.linspace(0, 1, grid_dim)
        U, V = torch.meshgrid(u, v, indexing='ij')
        self.grid = torch.stack([U.flatten(), V.flatten()], dim=-1)

    def forward(self, x, vae=True):
        # x shape: [Batch, 7]
        params = self.encoder(x)
        mu = params[:, :self.embedding_dim]
        logvar = params[:, self.embedding_dim:]
        
        # Reparameterization trick
        if vae:
            std = torch.exp(0.5 * logvar)
            eps = torch.randn_like(std)
            z = mu + eps * std
        else:
            z = mu
            
        # Decode to reconstructed geometry/color
        reconstructed = self.decoder(z)
        
        # Chamfer Loss
        loss_chamfer = torch.mean(torch.cdist(x[:, :3], reconstructed[:, :3])) * self.geo_weight
        
        # KL Divergence Loss
        loss_kl = -0.5 * torch.mean(1 + logvar - mu**2 - logvar.exp())
        
        # Normalization Loss
        loss_norm = torch.tensor(0.0)
        if self.norm_weight > 0:
            loss_norm = torch.mean(torch.abs(reconstructed)) * self.norm_weight
            
        total_loss = loss_chamfer + loss_kl + loss_norm
        return reconstructed, total_loss, loss_chamfer, loss_kl
```

**Parameters:**
*   `embedding_dim`: Dimensionality of the latent feature vector $z$. Default: 32 [S1, unofficial].
*   `grid_dim`: Dimension of the 2D spherical folding grid. Default: 24 [S1, unofficial].
*   `norm_weight`: Weight for the normalization loss term applied during training. Default: 0 [S1, unofficial].
*   `geo_weight`: Weight for the Chamfer loss term. Default: 0.5 [S1, unofficial].

## Subtopics

### Gaussian VAE
A Variational Auto-encoder that compresses Gaussian Splatting Functions into a regularized latent space, mapping functions of each shape into one latent vector [S2]. The architecture consists of an Encoder and Decoder with a Triplane representation, taking Gaussian Splatting Functions as input and outputting a latent vector $z$ [S2].

## Background
SF-VAE was introduced in the "gs-embedding" project, an unofficial implementation exploring the integration of VAEs with 3D Gaussian Splatting [S1, unofficial]. It builds on [Learning-based and Generative Initialization](12356-learning-based-and-generative-initialization.md) by applying a structured folding mechanism to map point cloud data into Gaussian parameter space [S1, unofficial].
