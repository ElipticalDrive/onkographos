# Curriculum Learning with Slice and Voxel Supervision

Also called: Slice and Voxel Supervision Curriculum

## Overview
This method addresses the instability and incomplete volumetric coverage inherent in optimizing 3D Gaussian representations for volume rendering by enforcing a structured training schedule. It combines sparse voxel sampling, which provides global volumetric consistency, with slice-based sampling, which captures local geometric structure and texture continuity [S1]. Unlike sibling methods that rely solely on random voxel supervision or unstructured slice supervision, this approach progressively introduces these constraints to stabilize optimization and improve reconstruction quality [S1].

## How it works
**Inputs:** A set of 3D Gaussian primitives $\mathcal{G} = \{g_1, \dots, g_m\}$ initialized from voxel samples, where each $g_k$ has mean $\mu_k$, covariance $\Sigma_k$, opacity $\alpha_k$, and spherical harmonic coefficients $\mathbf{c}_k$ [S1]. A volumetric dataset (e.g., MRI or Cryosection) [S1].

**Outputs:** Optimized Gaussian parameters $\mathcal{G}$ that minimize rendering loss against target views [S1].

**Data Structures:**
*   **Gaussian Set:** List of $m$ Gaussians. Each Gaussian stores $\mu \in \mathbb{R}^3$, $\Sigma \in \mathbb{R}^{3 \times 3}$ (or scale/rotation parameters), $\alpha \in [0,1]$, and color/SH coefficients [S1].
*   **Voxel Grid:** Implicit or explicit representation of the input volume, used to map 2D slice pixels to 3D coordinates [S1].

**Algorithm Steps:**
1.  **Initialization:** Initialize one Gaussian kernel centered at each sampled voxel position [S1].
2.  **Iteration Loop:** For each training iteration $t$:
    a.  **Phase 1: Sparse Voxel Supervision (Global Guidance):**
        i.   Sample a subset of voxels from the volume. The sources describe this as "sparse voxel sampling" providing global coverage [S1].
        ii.  Render the current Gaussian representation to match the voxel values or derived targets.
        iii. Compute loss and update Gaussian parameters [S1].
    b.  **Phase 2: Slice Supervision (Local Structure):**
        i.   Sample a plane with arbitrary orientation [S1].
        ii.  Select sparse pixels on the sampled plane [S1].
        iii. Map each selected pixel to a 3D voxel coordinate using the volume geometry [S1].
        iv.  Render the Gaussians intersecting this plane/slice.
        v.   Compute loss against the slice data. This aligns with shear-warp rendering which operates on stacks of 2D slices [S1].
        vi.  Update Gaussian parameters [S1].
3.  **Curriculum Progression:** The method employs a curriculum strategy. The sources indicate that combining both strategies yields higher PSNR/SSIM than using either alone [S1]. Specifically, ablation studies show that applying slice supervision *first* (A3) or using *only* slice supervision (A4) leads to unstable learning or lack of global guidance, respectively [S1]. The recommended approach (A2/A5 context) implies establishing global voxel constraints before or concurrently with structured slice constraints to ensure stable optimization [S1].

**Pseudocode:**
```python
def train_gaussian_volume(volume_data, gaussians, num_iterations):
    # Initialize Gaussians from voxel samples
    gaussians = initialize_from_voxels(volume_data)
    
    for t in range(num_iterations):
        # Phase 1: Sparse Voxel Supervision
        # Sample sparse voxels for global coverage
        voxel_indices = sample_sparse_voxels(volume_data)
        voxel_targets = get_voxel_values(volume_data, voxel_indices)
        
        # Render and compute loss for voxels
        rendered_voxels = render_gaussians_to_voxels(gaussians, voxel_indices)
        loss_voxel = compute_loss(rendered_voxels, voxel_targets)
        update_gaussians(gaussians, loss_voxel)
        
        # Phase 2: Slice Supervision
        # Sample a plane with arbitrary orientation
        plane = sample_random_plane()
        
        # Select sparse pixels on the plane
        pixels = sample_sparse_pixels_on_plane(plane)
        
        # Map pixels to 3D voxel coordinates
        voxel_coords = map_pixels_to_voxels(pixels, plane, volume_data)
        
        # Render slice and compute loss
        rendered_slice = render_gaussians_to_slice(gaussians, plane)
        slice_targets = get_slice_values(volume_data, plane)
        loss_slice = compute_loss(rendered_slice, slice_targets)
        update_gaussians(gaussians, loss_slice)
        
    return gaussians
```

**Parameters:**
*   **Sampling Density:** "Sparse" for both voxels and slice pixels is specified [S1]. Exact density is not given in the sources.
*   **Plane Orientation:** Arbitrary [S1].

**Edge Cases:**
*   **Instability:** Using only slice supervision (A4) limits accurate reconstruction of the full volumetric structure due to lack of global spatial guidance [S1].
*   **Ordering:** Applying slice supervision before stable global voxel constraints are established (A3) results in unstable learning of the volumetric structure [S1].
*   **Randomness:** Random voxel sampling without structure leads to unstable global approximation [S1].

## Subtopics

### Curriculum Learning with Sparse Voxel and Slice Sampling
This variant explicitly defines the sampling strategy. Sparse voxels provide global coverage of the volume, while slice samples capture spatially correlated regions that encode geometric structure and texture continuity [S1]. This strategy aligns with shear-warp volume rendering, which generates images from stacks of 2D slices extracted from a 3D volume [S1]. In each iteration, a plane with arbitrary orientation is sampled, sparse pixels are selected on the plane, and each pixel is mapped to a 3D voxel coordinate [S1].

## Operating characteristics
*   **Performance:** Combining sparse voxel and slice supervision yields higher PSNR and SSIM than using only slice supervision (A4) or random voxel sampling [S1].
*   **Limitations:** Using only slice supervision limits accurate reconstruction of the full volumetric structure [S1]. Random voxel sampling alone leads to unstable global approximation [S1].
*   **Hardware/Resolution:** Applicable to multimodal volumetric datasets including MRI and Cryosection volumes [S1]. Enables efficient reconstruction and real-time selective visualization [S1].
*   **Scaling:** Not given in the sources.

## Background
This method was proposed in the context of Gaussian Volumetric Shear-Warp Visualization for medical data [S1]. It builds on the Gaussian representation for shear-warp rendering [S1]. The curriculum learning approach is inspired by general curriculum learning principles [S1, citing [37]].
