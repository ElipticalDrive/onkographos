# Warm-up stage

Also called: 3D Gaussian Initialization (Warm-up)

## Overview
The warm-up stage is a training adaptation that initializes 3D Gaussians before optimizing higher-order representations, such as 4D Gaussians, to prevent convergence difficulties when SfM point initialization is absent [S2]. It serves as a coarse optimization phase that stabilizes the learning of deformation fields and suppresses transient distractors [S1, S2].

## How it works
The warm-up stage operates as a preliminary optimization loop before the main training of dynamic or complex Gaussian representations.

**Inputs and Outputs:**
*   **Input:** Sparse or absent SfM points; initial set of 3D Gaussians $\Gamma$; camera poses and images.
*   **Output:** Optimized 3D Gaussian parameters (position, covariance, opacity, color) and initial deformation field suggestions.

**Data Structures:**
*   **3D Gaussians ($\Gamma$):** A set of $N$ Gaussians, each defined by mean position $\mu$, covariance matrix $\Sigma$, opacity $\alpha$, and spherical harmonics coefficients for color.
*   **Deformation Network ($\Delta$):** A neural network (e.g., MLP) that predicts deformation offsets for Gaussian centers and scales based on time and spatial features.

**Steps:**
1.  **Initialization:** Initialize 3D Gaussians from SfM points if available; otherwise, use random or grid-based initialization [S2].
2.  **Static Optimization:** Optimize the static 3D Gaussian parameters ($\Gamma$) using standard 3D Gaussian Splatting rendering loss (photometric and perceptual losses) for a fixed number of iterations [S2].
3.  **Deformation Guidance:** During this phase, keep a subset of 3D Gaussians in the dynamic part to release the pressure of large deformation learning on the 4D Gaussians [S2]. This allows the deformation network $\Delta$ to learn coarse motion patterns without numeric instability [S2].
4.  **Transition:** Pass the optimized 3D Gaussian parameters and the learned deformation field suggestions to the subsequent 4D Gaussian training stage [S2].

**Formulas:**
*   Rendering loss $\mathcal{L}$: Standard differentiable rendering loss between rendered image $I_{render}$ and ground truth $I_{gt}$:
    $$ \mathcal{L} = \mathcal{L}_{L1}(I_{render}, I_{gt}) + \lambda \mathcal{L}_{DSSIM}(I_{render}, I_{gt}) $$
*   Deformation prediction: The deformation network $\Delta$ predicts offsets $\Delta \mu, \Delta \Sigma$ based on input features:
    $$ \{\Delta \mu, \Delta \Sigma\} = \Delta(\text{features}) $$

**Parameters:**
*   **Warm-up Iterations:** Not given in the sources.
*   **Learning Rate:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Absence of SfM Points:** Direct training of 4D-GS without this warm-up stage leads to convergence difficulty [S2].
*   **Numeric Errors:** Skipping the warm-up stage can cause numeric errors in optimizing the Gaussian deformation network $\Delta$ [S2].

**Pseudocode:**
```python
def warm_up_stage(gaussians, images, poses, deformation_network, iterations):
    """
    Optimizes 3D Gaussians and initializes deformation field.
    """
    # Initialize Gaussians if SfM points are absent
    if not has_sfm_points():
        gaussians = initialize_random_gaussians()
    
    # Static optimization loop
    for step in range(iterations):
        # Sample a random camera view
        view_id = random_sample(poses)
        image = images[view_id]
        pose = poses[view_id]
        
        # Render current Gaussians
        rendered_image = render(gaussians, pose)
        
        # Compute loss
        loss = compute_loss(rendered_image, image)
        
        # Backpropagate to update Gaussians and deformation network
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
        
        # Keep some 3D Gaussians in dynamic part to relieve deformation pressure
        # [G]: Implementation detail to mark specific Gaussians as dynamic/static
        mark_dynamic_gaussians(gaussians)
        
    return gaussians, deformation_network
```

## Subtopics

### 3D Gaussian Initialization (Warm-up)
A specific variant where the warm-up stage optimizes 3D Gaussians before training 4D-GS directly, used when SfM points initialization is absent to prevent convergence difficulty [S2]. It keeps some 3D Gaussians in the dynamic part to release pressure of large deformation learning by 4D Gaussians, learns proper 3D Gaussians $\Gamma$, and suggests deformation fields to pay more attention to the dynamic part, avoiding numeric errors in optimizing the Gaussian deformation network $\Delta$ [S2].

## Operating characteristics
*   **Performance Impact:** Training without the warm-up coarse stage yields PSNR 31.91 dB, SSIM 0.97, LPIPS 0.03, training time 7.5 mins, 79 FPS, and 18 MB storage [S2].
*   **Convergence:** Prevents convergence difficulty in dynamic scene rendering when SfM points are missing [S2].
*   **Stability:** Avoids numeric errors in optimizing the Gaussian deformation network [S2].
*   **Distractor Suppression:** Shows improvements in distractor suppression when used in conjunction with other adaptations like SpotLessSplats [S1].

## Background
The warm-up stage is part of the training strategy for 4D Gaussian Splatting, specifically addressing the challenges of dynamic scene rendering without reliable SfM initialization [S2]. It is also referenced in the context of distractor suppression methods like SpotLessSplats, where it is listed as one of the adaptations that show improvements [S1].
