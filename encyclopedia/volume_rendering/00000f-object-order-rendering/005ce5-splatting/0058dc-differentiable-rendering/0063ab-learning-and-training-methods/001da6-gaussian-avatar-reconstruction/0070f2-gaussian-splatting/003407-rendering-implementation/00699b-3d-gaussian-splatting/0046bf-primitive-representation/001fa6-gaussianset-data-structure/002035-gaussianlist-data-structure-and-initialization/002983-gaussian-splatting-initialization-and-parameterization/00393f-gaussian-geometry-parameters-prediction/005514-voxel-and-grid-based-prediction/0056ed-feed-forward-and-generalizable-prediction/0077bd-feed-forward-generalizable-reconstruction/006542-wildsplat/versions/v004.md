# WildSplat

Also called: WildSplat: Feedforward Gaussian Splatting from Unposed In-the-Wild Images

## Overview
WildSplat is a feedforward 3D Gaussian Splatting framework for appearance-conditioned novel-view synthesis from sparse, unposed, in-the-wild images [S1]. It explicitly decouples geometry from appearance to handle inconsistent photometric conditions, such as varying weather and lighting, which typically cause entangled representations in existing methods to fail [S1]. Unlike optimization-based methods that require precomputed poses and dense inputs, or prior feedforward methods that assume photometric consistency, WildSplat reconstructs a 3D Gaussian representation and predicts camera poses in a single forward pass using a dual-branch architecture [S1].

## How it works
**Inputs and Outputs:**
The model takes a set of $N$ context images $\{I_i\}_{i=1}^N$ and a single reference image $I_{ref}$ [S1]. It outputs:
1.  A 3D Gaussian geometry set $\mathcal{G}$ consisting of positions $\mu \in \mathbb{R}^{G \times 3}$, rotations $q \in \mathbb{R}^{G \times 4}$ (quaternions), scales $s \in \mathbb{R}^{G \times 3}$, and opacities $\alpha \in \mathbb{R}^G$, where $G$ is the number of Gaussians [S1].
2.  Conditioned spherical harmonics coefficients $\mathcal{C}_{ref} \in \mathbb{R}^{G \times 3 \times (k+1)}$ of degree $k$, conditioned on $I_{ref}$ [S1].
3.  Camera poses $\{p_i\}$ for the context views [S1].

The mapping is defined as:
$$ f: \{I_i\}, I_{ref} \mapsto (\mathcal{G}, \mathcal{C}_{ref}, \{p_i\}) $$
[S1]

**Data Structures:**
*   **Patch Tokens:** $T_i^{(0)} = E_{geo}(I_i) \in \mathbb{R}^{P \times D}$, where $P$ is the number of patches and $D$ is the feature dimension [S1].
*   **Camera Tokens:** Learnable tokens $C_i \in \mathbb{R}^{5 \times D}$ concatenated with patch tokens [S1].
*   **Content Features:** Aggregated multi-scale representations $\mathbf{F}_{content}$ extracted from the geometry branch, serving as the geometric scaffold [S1].
*   **Reference Tokens:** $T_{ref} \in \mathbb{R}^{P_a \times D}$, local dense appearance tokens from the reference image, where $P_a$ is the number of patches [S1].

**Algorithm Steps:**

1.  **Geometry Branch (Pose and Geometry Prediction):**
    *   Process each context image $I_i$ independently through a DINOv2-based geometry encoder $E_{geo}$ to obtain initial patch tokens $T_i^{(0)}$ [S1].
    *   Concatenate learnable camera tokens $C_i$ with $T_i^{(0)}$ [S1].
    *   Refine the combined tokens through $L$ alternating attention blocks to produce refined patch tokens $T_i^{(k)}$ and camera tokens $C_i^{(k)}$ for layer $k$ [S1].
    *   Extract and aggregate multi-scale representations from a subset of transformer layers $\mathcal{K} = \{l_1, \dots, l_K\}$ to form the content features $\mathbf{F}_{content}$ [S1].
    *   Predict camera poses $\{p_i\}$ and geometry $\mathcal{G}$ from the refined tokens [S1].

2.  **Appearance Branch (Conditioned Appearance):**
    *   Extract features from the reference image $I_{ref}$ to obtain reference tokens $T_{ref}$ [S1].
    *   **Global Pre-modulation:** To prevent the original photometric properties of $\mathbf{F}_{content}$ from interfering with the target appearance, apply an AdaLN-Zero layer [G: Adaptive Layer Normalization with Zero Initialization] to the global descriptor $T_{[CLS]}$ of the content features. This decodes parameters: scale $\gamma$, shift $\beta$, and adaptive gating $\eta$ [S1].
    *   Modulate the content features:
        $$ \tilde{T}_i^{(k)} = \gamma \cdot \text{LayerNorm}(\mathbf{F}_{content}) + \beta $$
        [S1] (Note: The source describes $\tilde{T}_i^{(k)}$ as the modulated features used as queries).
    *   **Cross-Attention:** Use the modulated features $\tilde{T}_i^{(k)}$ as queries ($Q$) and the reference tokens $T_{ref}$ as keys ($K$) and values ($V$) to aggregate condition-specific details [S1].
    *   Output the conditioned spherical harmonics coefficients $\mathcal{C}_{ref}$ [S1].

3.  **Conditioned Rasterization:**
    *   Render novel views using tile-based differentiable rasterization $\mathcal{R}$ of 3D Gaussian Splatting [S1]:
        $$ \{\hat{I}_i\} = \mathcal{R}(\mathcal{G}, \mathcal{C}_{ref}, \{p_i\}) $$
        [S1]

4.  **Geometry-guided View Sampling (Training Data Selection):**
    *   Construct an overlap matrix $S$ and a scale matrix $R$ using Structure-from-Motion (SfM) points [S1].
    *   Filter valid view pairs where $S \ge \tau_s$ and $R \ge \tau_r$ [S1].
    *   Select starting rows $C$ where the sum of valid columns $> \tau_n$ [S1].
    *   Initialize a queue with a uniform sample from $C$. Iteratively pop $u$, sample up to $K$ neighbors from valid unvisited views, push to queue, and add to index set $\mathcal{I}$ until $N$ views are selected [S1].

5.  **Joint Multi-Reference Supervision:**
    *   Randomly sample $M$ images $\{I_m\}$ from the batch as target references [S1].
    *   Extract conditioned appearance $\{\mathcal{C}_{ref,m}\}$ for each [S1].
    *   Render images $\{\hat{I}_m\}$ conditioned on their respective appearance [S1].
    *   Apply color jittering to input images and random cropping to references prior to feature extraction to prevent appearance leakage [S1].

**Pseudocode:**

```python
def wildsplat_forward(context_images, reference_image):
    """
    context_images: List of N images {I_i}
    reference_image: Image I_ref
    Returns: Geometry G, Conditioned SH Coeffs C_ref, Poses {p_i}
    """
    # 1. Geometry Branch
    # Encode context images
    patch_tokens_list = []
    for I_i in context_images:
        T_i_0 = dino_v2_encoder(I_i) # E_geo, shape [P, D]
        patch_tokens_list.append(T_i_0)
    
    # Initialize camera tokens
    camera_tokens_list = [learnable_camera_tokens for _ in range(len(context_images))]
    
    # Refine through L attention blocks
    for k in range(L):
        new_patch_tokens = []
        new_camera_tokens = []
        for i in range(len(context_images)):
            combined_tokens = concat(patch_tokens_list[i], camera_tokens_list[i])
            # Attention block refinement
            refined_tokens = attention_block(combined_tokens)
            new_patch_tokens.append(refined_tokens[:, :-5, :]) # Extract patch tokens
            new_camera_tokens.append(refined_tokens[:, -5:, :]) # Extract camera tokens
        patch_tokens_list = new_patch_tokens
        camera_tokens_list = new_camera_tokens
        
    # Aggregate multi-scale content features
    F_content = aggregate_multi_scale(patch_tokens_list, layers=K)
    
    # Predict geometry and poses
    G, poses = predict_geometry_and_poses(camera_tokens_list, F_content)
    
    # 2. Appearance Branch
    # Encode reference image
    T_ref = reference_encoder(reference_image) # Shape [P_a, D]
    
    # Global Pre-modulation using AdaLN-Zero
    # Extract CLS token from F_content (assuming global descriptor is available)
    T_CLS = get_cls_token(F_content)
    gamma, beta, eta = adaln_zero_layer(T_CLS)
    
    # Modulate content features
    F_content_norm = layer_norm(F_content)
    T_modulated = gamma * F_content_norm + beta
    
    # Cross-Attention for appearance conditioning
    # Q = T_modulated, K = V = T_ref
    C_ref = cross_attention(Q=T_modulated, K=T_ref, V=T_ref)
    
    return G, C_ref, poses

def geometry_guided_view_sampling(S_matrix, R_matrix, N, K, tau_s, tau_r, tau_n):
    """
    S_matrix: Overlap matrix
    R_matrix: Scale matrix
    N: Number of views to select
    K: Max neighbors to sample
    tau_s, tau_r, tau_n: Thresholds
    Returns: Selected indices I
    """
    # Valid mask
    V = (S_matrix >= tau_s) & (R_matrix >= tau_r)
    
    # Valid starting rows
    C = [i for i in range(len(V)) if sum(V[i]) > tau_n]
    
    if not C:
        return []
        
    # Initialize queue and index set
    import random
    start_node = random.choice(C)
    queue = [start_node]
    I = {start_node}
    
    while len(I) < N and queue:
        u = queue.pop(0)
        # Sample up to K neighbors from valid unvisited views
        candidates = [v for v in range(len(V[u])) if V[u, v] and v not in I]
        k_neighbors = random.sample(candidates, min(K, len(candidates)))
        
        for neighbor in k_neighbors:
            queue.append(neighbor)
            I.add(neighbor)
            
    return list(I)

def compute_loss(rendered_images, ground_truth_images, poses, gt_poses):
    """
    rendered_images: {I_hat_m}
    ground_truth_images: {I_m}
    poses: Predicted poses
    gt_poses: Ground truth poses (for pose loss)
    """
    # Photometric Loss
    L_MSE = mean_squared_error(rendered_images, ground_truth_images)
    L_SSIM = ssim_loss(rendered_images, ground_truth_images)
    L_LPIPS = lpips_loss(rendered_images, ground_truth_images)
    
    L_rgb = 1.0 * L_MSE + 0.05 * L_SSIM + 0.05 * L_LPIPS
    
    # Pose Loss (Distillation loss from AnySplat)
    L_pose = pose_distillation_loss(poses, gt_poses)
    
    # Total Loss
    L_total = L_rgb + 10.0 * L_pose
    
    return L_total
```

**Parameters:**
*   $\lambda_1 = 10$ (pose loss weight) [S1]
*   $\lambda_2 = 1.0$ (MSE loss weight) [S1]
*   $\lambda_3 = 0.05$ (SSIM loss weight) [S1]
*   $\lambda_4 = 0.05$ (LPIPS loss weight) [S1]
*   Thresholds $\tau_s, \tau_r, \tau_n$ and neighbor count $K$ are predefined for view sampling [S1].

**Edge Cases and Pitfalls:**
*   **Varying Focal Lengths:** Standard sampling relying on camera extrinsics fails on in-the-wild datasets where minor pose shifts alter captured content due to varying focal lengths. Mitigated by overlap-based sampling using SfM points [S1].
*   **Photometric Interference:** Content features from the geometry branch retain original photometric properties, potentially interfering with target appearance conditioning. Mitigated by global pre-modulation using AdaLN-Zero to shift features into the target appearance domain [S1].
*   **Appearance Leakage:** To prevent the geometry from learning appearance-specific features, color jittering is applied to input images and random cropping to references prior to feature extraction [S1].

## Operating characteristics
*   **Time Complexity:** Single forward pass for reconstruction and pose estimation, significantly faster than optimization-based methods like NeRF-W or GS-W [S1].
*   **Memory Complexity:** Depends on the number of Gaussians $G$ and the feature dimensions $P, D$. The dual-branch architecture requires storing features for both geometry and appearance branches [S1].
*   **Performance:**
    *   On MegaScenes with 12 views: PSNR 19.20, SSIM 0.683, LPIPS 0.210 [S1].
    *   On Phototourism with 12 views: PSNR 21.47, SSIM 0.788, LPIPS 0.137 [S1].
*   **Strengths:** Handles sparse, unposed, in-the-wild images; decouples geometry and appearance; enables appearance editing via reference image conditioning [S1].
*   **Limitations:** Relies on SfM points for view sampling, which may not be available for all in-the-wild datasets; performance depends on the quality of the DINOv2 encoder and the reference image [S1].
*   **When to use:** When efficient novel-view synthesis is required for scenes with varying illumination and sparse, unposed input images, and appearance conditioning is desired [S1].
*   **When not to use:** When dense, posed input images are available and photometric consistency is guaranteed, simpler feedforward methods may suffice; when real-time performance is not critical and optimization-based methods can provide higher quality [S1].

## Background
WildSplat was introduced by Zhang et al. in 2024 [S1]. It is the first feedforward 3D Gaussian Splatting framework capable of appearance-conditioned novel-view synthesis for unposed in-the-wild images [S1]. It builds on the VGGT-like architecture [S1] and addresses the limitations of existing feedforward methods that assume photometric consistency [S1]. The method uses the DL3DV dataset for geometric priors and MegaScenes/MegaDepth for diverse appearance training [S1].
