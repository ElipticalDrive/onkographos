# Content-Aware Texturing for Gaussian Splatting

Also called: Content-Aware Texturing, Ours

## Overview
This method augments 2D Gaussian primitives with spatially varying texture maps that add offsets to spherical harmonic colors, allowing appearance to adapt to captured content without pretrained models [S1]. It distinguishes itself from sibling methods by using dynamic, content-aware texel allocation and splitting-based densification, avoiding the cloning strategies of [RPK24] and the fixed texel budgets of [GSTex] [S1].

## How it works
**Inputs and Outputs:**
Input: A set of $N$ 2D Gaussian primitives $\{G_i\}$, each defined by mean $\boldsymbol{\mu}_i$, scale $\boldsymbol{\sigma}_i$, rotation $\mathbf{R}_i$, opacity $\alpha_i$, and SH coefficients [S1]. Output: Rendered images and optimized primitive parameters including texture maps [S1].

**Data Structures:**
Each primitive stores 59 parameters: 3 position, 2 scale, 4 rotation, 1 opacity, 48 SH color coefficients, and 1 scalar for texel size ratio $t2pr$ [S1]. Texture maps are stored in a custom "jagged" tensor structure to handle varying resolutions per primitive, with 3 floats (RGB) per texel [S1]. All parameters are 4-byte floats [S1].

**Coordinate Systems:**
To facilitate operations, the method uses:
1. World space $\mathbf{p}_w$ [S1].
2. World space centered on primitive $\mathbf{p}_{w0} = \mathbf{p}_w - \boldsymbol{\mu}_i$ [S1].
3. Local axis-aligned space $\mathbf{p}_l = \mathbf{R}_i^{-1} \mathbf{p}_{w0}$, where the last component is 0, so $\mathbf{p}_l \in \mathbb{R}^2$ [S1].
4. Local normalized/canonical space $\mathbf{p}_c = \mathbf{S}_i^{-1} \mathbf{p}_l$, where $\mathbf{S}_i = \text{diag}(\boldsymbol{\sigma}_i)$ [S1].

**Rendering Formula:**
The color of a ray $\mathbf{r}$ is computed by alpha blending [S1]:
$$ C(\mathbf{r}) = \sum_i w_i(\mathbf{p}_i) c_i(\mathbf{d}) = \sum_i T_i \alpha_i G_i(\mathbf{p}_i) c_i(\mathbf{d}) $$
where $T_i = \prod_{j<i} (1 - \alpha_j G_j(\mathbf{p}_j))$ is the transmittance, and $G(\mathbf{x}) = e^{-\frac{1}{2} (\mathbf{x}^T \mathbf{x})}$ [S1]. The color $c_i(\mathbf{d})$ is defined as:
$$ c_i = \text{SH}(\mathbf{d}) + \text{bilerp}(T_i, \mathbf{u}) $$
where $\text{bilerp}$ is bilinear interpolation of the texture map $T_i$ at UV coordinate $\mathbf{u}$ [S1].

**Texture Coordinate Calculation:**
To avoid texture stretching during optimization, the texel size $k_i$ is fixed in world space [S1]:
$$ \mathbf{u} = \frac{\mathbf{p}_l}{k_i} + \mathbf{T}_{\text{offset}} $$
where $k_i = k_{\min} \cdot t2pr_i$, $k_{\min}$ is the minimum pixel size, and $t2pr_i$ is the texel size-to-pixel size ratio (powers of two, lower bound 1) [S1]. $\mathbf{T}_{\text{offset}}$ centers the texture map [S1].

**Training Loss:**
The total loss is $L = L_{\text{RGB}} + L_{\text{texture}} + L_{\text{opacity}}$ [S1]:
1. $L_{\text{RGB}} = (1 - \lambda_{\text{SSIM}}) L_1 + \lambda_{\text{SSIM}} L_{\text{SSIM}}$ with $\lambda_{\text{SSIM}} = 0.2$ [S1].
2. $L_{\text{texture}} = \lambda_{\text{texture}} \sum_i |c_i^T|$, where $c_i^T = 2\sigma(c_i^{\prime T}) - 1$ constrains texels to $[-1, 1]$ via sigmoid $\sigma$ on unactivated features $c_i^{\prime T}$ [S1].
3. $L_{\text{opacity}} = \lambda_{\text{opacity}} \frac{1}{N} \sum_i \alpha_i$ [S1].

**Primitive Management (Upscaling and Splitting):**
Error is computed per primitive $i$ as a weighted sum over views $\Pi$:
$$ E_i^\pi = \sum_{\mathbf{r} \in P_i} E^\pi(\mathbf{r}) w_i^\pi(\mathbf{r}), \quad E_i = \frac{\sum_{\pi \in \Pi} E_i^\pi w_i^\pi}{\sum_{\pi \in \Pi} w_i^\pi}, \quad w_i^\pi = \sum_{\mathbf{r} \in P_i} w_i^\pi(\mathbf{r}) $$
where $P_i$ is the set of pixels covered by primitive $i$ [S1].

1. **Downscaling:** If appearance error $E_d < \tau_{ds}$, double $t2pr_i$. $E_d$ is the Gaussian-weighted difference between original and low-pass filtered textures:
   $$ E_d = \frac{\sum_p G(\mathbf{p})(T_{\text{orig}}(\mathbf{p}) - T_{\text{lowpass}}(\mathbf{p}))}{\sum_p G(\mathbf{p})} $$
   [S1]. Upscaling is only allowed if $t2pr_i \ge 2$ [S1].

2. **Upscaling:** Select top 10% of primitives by $E_i$. Halve $t2pr_i$ (upscale texture by factor of 4) [S1].

3. **Splitting:** If a primitive's texture resolution exceeds threshold $\tau_{tr}$ after upscaling, split it. Replace primitive with two new primitives displaced by $\pm 1$ standard deviation along the axis. New primitives have half the scale in that axis, half the texture resolution, and $G(1)$ times the opacity. Texture maps are initialized by sampling the original point at respective locations [S1].

**Edge Cases:**
If a primitive grows outside its allocated texture grid (due to lack of allocation or hitting the 256 max resolution limit), use zero-padding. This reduces to the DC color since texels are offsets [S1].

```python
def render_ray(ray, primitives):
    contributions = []
    for i, prim in enumerate(primitives):
        # Compute intersection in camera space directly
        p_w = ray.origin + ray.direction * t
        p_w0 = p_w - prim.mu
        p_l = prim.R_inv @ p_w0[:2] # 2D local space
        
        # Texture coordinate
        k = prim.k_min * prim.t2pr
        u = p_l / k + prim.T_offset
        
        # Texture lookup with zero-padding if out of bounds
        tex_val = bilerp(prim.texture, u, max_res=256)
        
        # Color
        c_sh = prim.SH(ray.direction)
        c_i = c_sh + tex_val
        
        # Gaussian weight
        p_c = prim.S_inv @ p_l
        g_val = exp(-0.5 * dot(p_c, p_c))
        w = prim.alpha * g_val
        
        contributions.append((w, c_i))
    
    # Alpha blend
    color = zeros(3)
    transmittance = 1.0
    for w, c in sorted(contributions, key=lambda x: x[1]): # Sort by depth if needed
        alpha = w * transmittance
        color += alpha * c
        transmittance *= (1 - alpha)
    return color

def update_primitives(primitives, errors, views):
    # Compute weighted error
    for prim in primitives:
        E_i = 0
        W_i = 0
        for view in views:
            E_i_pi = sum(error_image[r] * weight(r, prim) for r in prim.covered_pixels)
            W_i_pi = sum(weight(r, prim) for r in prim.covered_pixels)
            E_i += E_i_pi * W_i_pi
            W_i += W_i_pi
        prim.error = E_i / W_i if W_i > 0 else 0
        
    # Downscaling
    for prim in primitives:
        E_d = compute_appearance_error(prim)
        if E_d < tau_ds:
            prim.t2pr *= 2
            
    # Upscaling and Splitting
    top_10_percent = get_top_primitives_by_error(primitives, 0.1)
    for prim in top_10_percent:
        if prim.t2pr > 1:
            prim.t2pr /= 2
            if prim.t2pr < 1: prim.t2pr = 1 # Clamp
            
        if prim.t2pr < tau_tr: # Check if resolution is high enough to warrant split
            # Split primitive
            new_prim_1 = copy(prim)
            new_prim_2 = copy(prim)
            
            # Displace by +/- 1 std dev
            std_dev = prim.scale # Assuming scale is std dev
            new_prim_1.mu += std_dev
            new_prim_2.mu -= std_dev
            
            # Halve scale and texture resolution
            new_prim_1.scale /= 2
            new_prim_2.scale /= 2
            new_prim_1.t2pr /= 2
            new_prim_2.t2pr /= 2
            
            # Opacity
            new_prim_1.alpha = prim.alpha * G(1)
            new_prim_2.alpha = prim.alpha * G(1)
            
            # Texture init
            new_prim_1.texture = sample_texture(prim.texture, new_prim_1.mu)
            new_prim_2.texture = sample_texture(prim.texture, new_prim_2.mu)
            
            # Replace in list
            primitives.remove(prim)
            primitives.append(new_prim_1)
            primitives.append(new_prim_2)
```

## Operating characteristics
**Time and Memory Complexity:**
Training is 1.5-2x slower than 2DGS due to per-ray texture querying overhead [S1]. Rendering is 25% slower than 2DGS [S1]. Memory usage is determined by the number of primitives and dynamic texel allocation, with a hard limit of 256 texture resolution per primitive to cap memory [S1].

**Measured Performance:**
- DeepBlending: SSIM 0.907, PSNR 30.03, LPIPS 0.303, 222K points, 21.6M texels, 78.1M params, 70 FPS [S1].
- Mip-Nerf-360: SSIM 0.795, PSNR 27.00, LPIPS 0.263, 218K points, 46.6M texels, 152.6M params, 67 FPS [S1].
- Tanks&Temples: SSIM 0.835, PSNR 23.43, LPIPS 0.225, 164K points, 10.4M texels, 41.1M params, 121 FPS [S1].

**Strengths and Limitations:**
Achieves competitive quality with significantly fewer parameters than BBSplat and GSTex by dynamically allocating texels [S1]. Avoids local minima from texture stretching by fixing texel size in world space [S1]. Limitations include slower training and rendering compared to 2DGS due to texture lookups [S1].
