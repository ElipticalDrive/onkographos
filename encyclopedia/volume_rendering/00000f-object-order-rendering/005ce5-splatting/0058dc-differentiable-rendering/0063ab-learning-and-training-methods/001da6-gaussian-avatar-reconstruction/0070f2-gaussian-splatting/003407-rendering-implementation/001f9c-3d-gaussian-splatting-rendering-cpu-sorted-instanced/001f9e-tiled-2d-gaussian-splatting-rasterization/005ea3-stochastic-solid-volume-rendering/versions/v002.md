# Stochastic Solid Volume Rendering


## Overview
Stochastic Solid Volume Rendering (SSVR) is a volume rendering technique that reformulates 3D Gaussian Splatting rasterization using a vacancy function to improve geometric fidelity [S1, unofficial]. It produces RGB images nearly identical to standard 3DGS rasterization under suitable conditions but reduces holes and blurred boundaries in depth maps [S1, unofficial]. It is equivalent to 3DGS rasterization when the vacancy function is set to $v(x) = \sqrt{1 - G(x)}$ [S1, unofficial].

## How it works
**Inputs:**
- 3D Gaussian primitives defined by parameters $\theta$ (position $\mu_i$, covariance $\Sigma_i$, opacity $\alpha_i$, color $c_i$) [G].
- Camera ray origin $o$ and direction $d$ [G].

**Outputs:**
- RGB image pixel color $C$ [S1, unofficial].
- Depth map value $t_{med}$ [S1, unofficial].

**Data Structures:**
- List of Gaussians sorted by their ray parameter $t^*_i$ (front to back) [G].
- Accumulated transmittance state $T(t)$ [G].

**Core Concept:**
SSVR reformulates the volume rendering integral using a vacancy function $v(x)$ [S1, unofficial]. The density $\sigma(x, \omega)$ is defined as $\sigma(x, \omega) = \omega^\top \nabla \log v(x)$ [S1, unofficial]. To obtain RGB images equivalent to 3DGS rasterization, the vacancy function must be $v(x) = \sqrt{1 - G(x)}$ [S1, unofficial].

**Rendering Steps:**
1. **Ray Parameterization:** For each pixel, define the ray $x(t) = o + t \cdot d$. Compute the Gaussian maximum location along the ray $t^*_i = d^\top (\mu_i - o)$ and the ray-space variance $\sigma_{i}^2 = d^\top \Sigma_i d$ [G].
2. **Single Gaussian Transmittance:** Compute $T_i(t)$ for each Gaussian $i$ based on the position $t$ relative to $t^*_i$ [S1, unofficial]:
   $$
   T_i(t) =
   \begin{cases}
   \sqrt{1 - G_i(t)}, & t \le t^*_i \\
   \sqrt{1 - G_i(t^*_i)}, & t > t^*_i
   \end{cases}
   $$
   where $G_i(t) = \alpha_i \exp\left(-\frac{(t - t^*_i)^2}{2\sigma_{i}^2}\right)$ is the 1D Gaussian density along the ray [G].
3. **Accumulation:** Compute the accumulated transmittance $T(t) = \prod_{j} T_j(t)$ for all Gaussians $j$ with $t^*_j \le t$ [G]. The color is accumulated using standard alpha blending weights derived from the transmittance curve [G].
4. **Depth Rendering:** Find the median depth $t_{med}$ defined by the point where $T(t_{med}) = 0.5$ using a fixed number of bisection iterations [S1, unofficial].
5. **Backpropagation:** During training, differentiate the fixed condition $T(t_{med}) = 0.5$ with respect to Gaussian parameters $\theta$ [S1, unofficial]. Using the chain rule, the gradient is computed as $\frac{\partial T}{\partial t} \frac{\partial t_{med}}{\partial \theta} + \frac{\partial T}{\partial \theta} = 0$ [S1, unofficial].

**Pseudocode:**
```python
import math

def gaussian_density_1d(t, t_star, sigma_sq, alpha):
    """Compute G_i(t) for a Gaussian at ray parameter t."""
    if sigma_sq <= 1e-8:
        sigma_sq = 1e-8
    return alpha * math.exp(-0.5 * ((t - t_star) ** 2) / sigma_sq)

def single_transmittance(t, t_star, sigma_sq, alpha):
    """Compute T_i(t) according to the piecewise definition."""
    G = gaussian_density_1d(t, t_star, sigma_sq, alpha)
    # Clamp to [0, 1] to prevent NaN from sqrt of negative numbers [G]
    G = max(0.0, min(1.0, G))
    if t <= t_star:
        return math.sqrt(1.0 - G)
    else:
        G_star = gaussian_density_1d(t_star, t_star, sigma_sq, alpha)
        G_star = max(0.0, min(1.0, G_star))
        return math.sqrt(1.0 - G_star)

def accumulated_transmittance(t, gaussians_sorted):
    """Compute T(t) = product of T_i(t) for all Gaussians behind t."""
    T_acc = 1.0
    for g in gaussians_sorted:
        if g['t_star'] <= t:
            T_acc *= single_transmittance(t, g['t_star'], g['sigma_sq'], g['alpha'])
    return max(0.0, min(1.0, T_acc))

def find_median_depth(gaussians_sorted, t_min, t_max, iterations=10):
    """Find t_med such that T(t_med) = 0.5 via bisection."""
    low, high = t_min, t_max
    for _ in range(iterations):
        mid = (low + high) / 2.0
        T_mid = accumulated_transmittance(mid, gaussians_sorted)
        if T_mid > 0.5:
            low = mid
        else:
            high = mid
    return (low + high) / 2.0

def render_pixel(ray_o, ray_d, gaussians):
    """Render a single pixel using SSVR."""
    # Precompute ray-space parameters for visible Gaussians
    visible = []
    for g in gaussians:
        t_star = ray_d[0]*g['mu'][0] + ray_d[1]*g['mu'][1] + ray_d[2]*g['mu'][2] - (ray_d[0]*ray_o[0] + ray_d[1]*ray_o[1] + ray_d[2]*ray_o[2])
        sigma_sq = ray_d[0]**2 * g['Sigma'][0][0] + ray_d[1]**2 * g['Sigma'][1][1] + ray_d[2]**2 * g['Sigma'][2][2]
        visible.append({'t_star': t_star, 'sigma_sq': sigma_sq, 'alpha': g['alpha'], 'color': g['color']})
    
    # Sort front-to-back
    visible.sort(key=lambda x: x['t_star'])
    if not visible:
        return [0.0, 0.0, 0.0], 0.0
    
    t_min = visible[0]['t_star'] - 5.0 * math.sqrt(max(visible[0]['sigma_sq'], 1e-4))
    t_max = visible[-1]['t_star'] + 5.0 * math.sqrt(max(visible[-1]['sigma_sq'], 1e-4))
    
    # Compute color via standard alpha blending (equivalent to 3DGS)
    color = [0.0, 0.0, 0.0]
    T_acc = 1.0
    for g in visible:
        T_i = single_transmittance(g['t_star'], g['t_star'], g['sigma_sq'], g['alpha'])
        weight = T_acc * (1.0 - T_i)
        for c in range(3):
            color[c] += weight * g['color'][c]
        T_acc *= T_i
    
    # Compute median depth
    t_med = find_median_depth(visible, t_min, t_max)
    
    return color, t_med
```

**Edge Cases and Pitfalls:**
- **Precision:** The square root in $v(x) = \sqrt{1 - G(x)}$ requires $G(x) \le 1$. Numerical errors may push $G(x)$ slightly above 1; clamping $G(x)$ to $[0, 1]$ before the square root prevents NaN propagation [G].
- **Boundaries:** The piecewise definition of $T_i(t)$ depends on accurate computation of $t^*_i$. Incorrect $t^*_i$ shifts the transmittance curve and breaks depth accuracy [S1, unofficial].
- **Degenerate Input:** If a Gaussian has near-zero covariance, $\sigma_i^2$ approaches zero, causing density spikes. Clamping $\sigma_i^2$ to a minimum value (e.g., $10^{-8}$) stabilizes the exponential [G].

## Operating characteristics
- **Time and Memory Complexity:** Not given in the sources.
- **Strengths:** Improved geometric fidelity for depth and surface reconstruction; reduces holes and blurred boundaries in depth maps [S1, unofficial].
- **Limitations:** Requires accurate camera parameters and optimization-based training pipelines [S1, unofficial].
- **When to use:** When geometric accuracy for depth is prioritized over raw RGB fidelity [S1, unofficial].
- **When not to use:** When standard 3DGS rasterization suffices for RGB output [S1, unofficial].

## Background
Stochastic Solid Volume Rendering was introduced to improve geometric representation in optimization-based 3D Gaussian Splatting methods [S1, unofficial]. It builds on prior work by Miller et al. (2023), Zhang et al. (2026), and Gomez et al. (2026), which proved the mathematical equivalence between SSVR and 3DGS rasterization under the specified vacancy function [S1, unofficial].
