# Laplacian Frequency Hierarchy for 3DGS

Also called: Frequency-staged Training Pipeline, Frequency-staged Training with Archiving, Laplacian Frequency Hierarchies Training Procedure, Laplacian-GS inheritance strategy

## Overview
This method reduces 3D Gaussian Splatting (3DGS) training time and memory usage by factorizing the scene representation into a hierarchy of frequency-specific Gaussian fields aligned with a Laplacian pyramid of training images [S1]. It optimizes these fields sequentially from coarse to fine, archiving completed fields to free GPU memory, and composes the final image in the image domain [S1]. Unlike simultaneous multi-field optimization, this approach reduces the number of active primitives on the GPU at any given stage, offering a speedup with minor quality trade-offs [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of training views $\{v\}$ with ground truth images $\{I^v\}$ at full resolution [S1]. Each view includes a camera model for projection, which is standard for 3DGS [G].
*   **Outputs:** A set of Gaussian fields $\{G^0, \dots, G^{L-1}\}$ representing the scene across frequency bands [S1].

**Data Structures:**
*   **Gaussian Field $G^\ell$:** A set of $N_\ell$ anisotropic Gaussian primitives [S1]. Each primitive $i$ is parameterized by a mean position $\mu_i \in \mathbb{R}^3$, an opacity $\sigma_i \in (0, 1)$, a covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$ (typically decomposed as $\Sigma_i = R_i S_i S_i^\top R_i^\top$ where $R_i$ is a rotation quaternion and $S_i$ is a diagonal scale matrix), and spherical harmonics (SH) coefficients for view-dependent color [S1].
*   **Laplacian Pyramid:** A hierarchy of images $\{I^{L-1}, \dots, I^0\}$ where $I^0$ is the full-resolution ground truth and $I^{L-1}$ is the coarsest low-frequency approximation [S1].
*   **Cache:** A storage for accumulated rendered predictions $\{\hat{I}^v_\ell\}$ used to reconstruct finer levels [S1].

**Preprocessing: Pyramid Construction**
1.  For each training view $v$, construct the resolution pyramid:
    $$I^{\ell+1} = \text{Down}(I^\ell)$$
    where $\text{Down}(\cdot)$ is Gaussian filtering followed by subsampling [S1].
2.  Compute Laplacian residual targets for levels $\ell \in \{0, \dots, L-2\}$:
    $$R^\ell = I^\ell - \text{Up}(I^{\ell+1})$$
    where $\text{Up}(\cdot)$ is the paired upsampling operator [S1].
    Note: $I^{L-1}$ is the low-frequency target for the coarsest field [S1]. Residuals $R^\ell$ are signed and lie in $[-1, 1]$, while base images lie in $[0, 1]$ [S1].

**Rendering Functions:**
*   **Render_base:** Standard 3DGS rasterization with post-processing to map SH colors to $[0, 1]$:
    $$c_i(d) = \text{clamp}(c_i(d) + 0.5, 0, 1)$$
    Used for the coarsest level $G^{L-1}$ [S1].
*   **Render_res:** Modified rasterization that removes the shift and clamp, allowing signed outputs in $[-1, 1]$ to match residual targets [S1].

**Algorithm: Frequency-staged Training with Archiving**

```python
def laplacian_frequency_hierarchy_training(training_views, L=2, iterations_per_level=[10000, 20000], inheritance_ratio=1.0):
    # 1. Precompute Laplacian Pyramids
    I_pyramid = {}
    for v in training_views:
        I_full = v.image
        I_pyramid[v] = [I_full]
        current = I_full
        for _ in range(L - 1):
            current = gaussian_downsample(current)
            I_pyramid[v].append(current)
        I_pyramid[v].reverse()

    prediction_cache = {}
    gaussian_fields = {}

    for l in range(L - 1, -1, -1):
        if l == L - 1:
            G_l = initialize_from_colmap()
        else:
            G_prev = gaussian_fields[l + 1]
            G_l = inherit_gaussians(G_prev, inheritance_ratio)

        optimizer = AdamOptimizer(G_l.parameters())

        for iteration in range(iterations_per_level[L - 1 - l]):
            v = random.choice(training_views)

            if l == L - 1:
                I_hat_l = render_base(G_l, v)
            else:
                I_hat_l_plus_1 = prediction_cache[v]
                I_up = upsample_2x(I_hat_l_plus_1)
                R_hat_l = render_res(G_l, v)
                I_hat_l = I_up + R_hat_l

            target_I = I_pyramid[v][l]
            loss = photometric_loss(I_hat_l, target_I)
            loss.backward()
            optimizer.step()
            optimizer.zero_grad()
            apply_densification_and_pruning(G_l, iteration)

        prediction_cache[v] = I_hat_l
        gaussian_fields[l] = G_l
        archive_field(G_l)

    return gaussian_fields

def gaussian_downsample(img):
    return subsample(gaussian_filter(img, sigma=1.0), stride=2)

def upsample_2x(img):
    return nearest_neighbor_resize(img, scale=2.0)

def initialize_from_colmap():
    return [Gaussian(mu=p, sigma=0.2, S=init_scale(), R=init_rotation(), SH=init_sh()) for p in colmap_points]

def inherit_gaussians(G_prev, rho):
    N_prev = len(G_prev)
    N_new = int(N_prev * rho)
    indices = random.sample(range(N_prev), N_new) if rho < 1.0 else range(N_prev)
    G_new = []
    for i in indices:
        g = G_prev[i]
        new_g = Gaussian()
        new_g.mu = g.mu
        new_g.sigma = random_uniform(0, 1)
        new_g.S = random_scale()
        new_g.R = random_rotation()
        new_g.SH = random_sh_coefficients()
        G_new.append(new_g)
    return G_new

def render_base(G, v):
    return splat_render(G, v, shift_and_clamp=True)

def render_res(G, v):
    return splat_render(G, v, shift_and_clamp=False)

def splat_render(G, v, shift_and_clamp):
    colors = compute_sh_colors(G, v)
    if shift_and_clamp:
        colors = clamp(colors + 0.5, 0, 1)
    return composite_alpha_blending(G, v, colors)

def photometric_loss(pred, target):
    return 0.8 * ssim_loss(pred, target) + 0.2 * l1_loss(pred, target)

def apply_densification_and_pruning(G, iteration):
    standard_3dgs_densification_pruning(G, iteration)

def archive_field(G):
    move_to_cpu_or_disk(G)

class AdamOptimizer:
    def __init__(self, params):
        self.params = params
        self.state = {}
    def step(self):
        apply_adam_update(self.params, self.state)
    def zero_grad(self):
        for p in self.params:
            p.grad = None
```

**Parameters:**
*   **$L$ (Hierarchy Depth):** Number of pyramid levels. Default is 2 (levels 0 and 1) [S1]. Deeper hierarchies make finer residuals harder to represent efficiently, potentially reducing gains [S1].
*   **$\rho$ (Inheritance Ratio):** Fraction of Gaussians inherited from the previous stage. Default is 1.0 [S1]. Values $< 1.0$ accelerate training but cause a clear drop in reconstruction quality [S1].
*   **Iterations:** Default total 30K iterations split as 10K for the coarsest level and 20K for the finest level in a two-level setup [S1].
*   **Optimizer:** Adam [S1].

**Edge Cases and Pitfalls:**
*   **Error Accumulation:** Training each field to directly match its Laplacian residual target ($R^\ell$) can lead to accumulated approximation errors and degraded quality [S1]. The method mitigates this by supervising each stage using the reconstructed image $\hat{I}^v_\ell$ against the ground truth at that resolution level $I^v_\ell$ [S1].
*   **Inheritance Ratio:** Reducing $\rho$ below 1.0 speeds up training but significantly reduces fidelity because fewer primitives remain to represent fine details [S1].
*   **Hierarchy Depth:** Using too many levels (deep hierarchies) can degrade quality because high-frequency residuals become difficult for 3DGS to represent efficiently [S1].

## Subtopics

### Multi-stage and Progressive Training
A broader category of methods that optimize scene representations in stages, often coarse-to-fine. Laplacian Frequency Hierarchy is a specific implementation using frequency decomposition and archiving. [Multi-stage and Progressive Training](18485-multi-stage-and-progressive-training.md)

### Pruning and Sparsity Control
Methods that reduce the number of Gaussians to save memory and speed up training. Laplacian Frequency Hierarchy uses archiving (moving fields off GPU) and optional inheritance ratio reduction to manage active primitives. [Pruning and Sparsity Control](14431-pruning-and-sparsity-control.md)

### FastGS
A backbone framework used to implement Laplacian Frequency Hierarchy. FastGS provides optimized rendering and training routines. [FastGS](11745-splatformer-training-objective-refinement.md)

## Operating characteristics
*   **Time Complexity:** Reduces training time by optimizing fewer Gaussians per stage and reducing per-iteration cost at coarser levels [S1]. On Mip-NeRF 360 1K, it achieves a 1.73x speedup (8.88 to 5.13 minutes) with Taming-3DGS and 1.22x (4.82 to 3.96 minutes) with FastGS [S1].
*   **Memory Complexity:** Significantly reduces peak VRAM usage by archiving completed Gaussian fields off the GPU [S1]. This allows training higher-resolution scenes (2K/4K) that might otherwise OOM [S1].
*   **Performance:** Slight degradation in reconstruction quality (e.g., 0.34 dB PSNR drop on Mip-NeRF 360 1K) is attributed to approximation errors from hierarchical rendering and composition [S1].
*   **Strengths:** Efficient training for high-resolution scenes; reduced memory footprint; leverages standard 3DGS densification/pruning [S1].
*   **Limitations:** Slight quality drop; deeper hierarchies may degrade quality; requires careful tuning of inheritance ratio $\rho$ if speed is prioritized over quality [S1].
*   **When to Use:** When training time or VRAM is a bottleneck for high-resolution 3DGS scenes [S1].
*   **When Not to Use:** When maximum reconstruction fidelity is required and training time is not a constraint [S1].

## Background
The method was introduced in "Laplacian Frequency Hierarchies for Efficient 3D Gaussian Splatting Training" [S1]. It builds on the observation that low-frequency structures in 3DGS converge earlier than high-frequency details, and that standard 3DGS rasterizers assume non-negative colors, which is incompatible with signed residual learning [S1]. The Laplacian pyramid (Burt & Adelson, 1983) provides a framework for decomposing images into frequency bands, allowing separate optimization of coarse and fine details [S1].
