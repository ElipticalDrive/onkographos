# 3D Half-Gaussian Splatting Covariance Transformation and Regularization

Also called: 3D-HGS

## Overview
3D Half-Gaussian Splatting (3D-HGS) modifies the standard 3D Gaussian primitive into a half-ellipsoid to better model sharp boundaries between object surfaces and empty space, thereby reducing the "floaters" and noise artifacts common in unconstrained Gaussian optimization [S1]. It achieves this by projecting the Gaussian's covariance matrix onto a local basis defined by the surface normal, effectively cutting the ellipsoid in half, and applying specific regularization to the resulting shape parameters [S1]. Unlike sibling methods that rely on frequency domain penalties or external depth supervision, 3D-HGS enforces geometric regularity directly through the algebraic transformation of the covariance matrix during training [S1].

## How it works
**Inputs:**
- $\Sigma$: The $3 \times 3$ covariance matrix of a 3D Gaussian kernel.
- $n$: The estimated surface normal vector at the Gaussian's center.

**Outputs:**
- $\sigma$: The regularized, half-Gaussian covariance matrix in world space.

**Data Structures:**
- Vectors $v_1, v_2, n \in \mathbb{R}^3$.
- Matrix $B \in \mathbb{R}^{3 \times 3}$ (basis matrix).
- Matrix $cov \in \mathbb{R}^{3 \times 3}$ (transformed covariance).
- Matrix $\sigma \in \mathbb{R}^{3 \times 3}$ (regularized covariance).

**Parameters:**
- Regularization interval: 5000 iterations [S1].
- Opacity threshold for densification/pruning: 0.01 [S1].
- Initial opacity for half-Gaussians: 0.02 [S1].

**Algorithm:**
The transformation is performed every 5000 training iterations [S1].

1.  **Normalize the normal vector:**
    $$n \leftarrow \frac{n}{\|n\|}$$

2.  **Construct the local basis:**
    Define two orthogonal vectors $v_1$ and $v_2$ that span the plane perpendicular to $n$.
    - If $n_x = 0$ and $n_y = 0$:
      $$v_1 = (1, 0, 0)$$
      $$v_2 = (0, 1, 0)$$
    - Else:
      $$v_1 \leftarrow \frac{(n_y, -n_x, 0)}{\|(n_y, -n_x, 0)\|}$$
      $$v_2 \leftarrow \frac{n \times v_1}{\|n \times v_1\|}$$
    Construct the basis matrix $B$ by concatenating these vectors as columns:
    $$B = \begin{bmatrix} | & | & | \\ v_1 & v_2 & n \\ | & | & | \end{bmatrix}$$

3.  **Transform covariance to basis space:**
    $$cov \leftarrow B^T \Sigma B$$

4.  **Compute modified diagonal/off-diagonal elements:**
    Calculate the intermediate values $a', b', c'$ based on the elements of $cov$:
    $$a' \leftarrow cov[0, 0] - \frac{cov[0, 2]^2}{cov[2, 2]}$$
    $$b' \leftarrow cov[0, 1] - \frac{cov[0, 2] \cdot cov[1, 2]}{cov[2, 2]}$$
    $$c' \leftarrow cov[1, 1] - \frac{cov[1, 2]^2}{cov[2, 2]}$$

5.  **Construct the regularized covariance in basis space ($\sigma_{local}$):**
    Create a new $3 \times 3$ matrix where the top-left $2 \times 2$ block contains the modified values, the coupling terms with the normal direction are zeroed out, and the normal-direction variance is scaled down:
    $$\sigma_{local} = \begin{bmatrix} a' & b' & 0 \\ b' & c' & 0 \\ 0 & 0 & \frac{\min(a', c')}{100} \end{bmatrix}$$
    *Note: The source explicitly sets $\sigma_{local}[0,2]=0, \sigma_{local}[1,2]=0, \sigma_{local}[2,0]=0, \sigma_{local}[2,1]=0$. The element $\sigma_{local}[2,2]$ is set to $\min(a', c') / 100$ [S1].*

6.  **Transform back to world space:**
    $$\sigma \leftarrow B \sigma_{local} B^T$$

7.  **Training Adjustments:**
    To support the half-Gaussian representation, the opacity threshold for densification and pruning is increased to 0.01, and the initial opacity value for newly created half-Gaussians is reset to 0.02 [S1].

**Pseudocode:**
```python
import numpy as np

def transform_covariance_to_half_gaussian(cov_matrix: np.ndarray, normal: np.ndarray) -> np.ndarray:
    """
    Transforms a 3D Gaussian covariance matrix into a half-Gaussian covariance
    matrix using the provided surface normal.
    
    Args:
        cov_matrix: 3x3 numpy array, the original covariance matrix Sigma.
        normal: 3-element numpy array, the surface normal vector n.
        
    Returns:
        3x3 numpy array, the regularized covariance matrix sigma.
    """
    # 1. Normalize normal
    n = normal / np.linalg.norm(normal)
    
    # 2. Construct basis
    # Check if n is aligned with Z axis (nx=0, ny=0)
    if np.isclose(n[0], 0.0) and np.isclose(n[1], 0.0):
        v1 = np.array([1.0, 0.0, 0.0])
        v2 = np.array([0.0, 1.0, 0.0])
    else:
        # v1 perpendicular to n in XY plane
        v1 = np.array([n[1], -n[0], 0.0])
        v1 = v1 / np.linalg.norm(v1)
        
        # v2 perpendicular to both n and v1
        v2 = np.cross(n, v1)
        v2 = v2 / np.linalg.norm(v2)
        
    # Basis matrix B: columns are v1, v2, n
    B = np.column_stack((v1, v2, n))
    
    # 3. Transform to basis space
    cov_basis = B.T @ cov_matrix @ B
    
    # 4. Compute modified elements
    # Avoid division by zero if cov[2,2] is extremely small, though source does not specify guard.
    # [G] Added a small epsilon to prevent numerical instability during division.
    eps = 1e-8
    denom = cov_basis[2, 2] + eps
    
    a_prime = cov_basis[0, 0] - (cov_basis[0, 2] ** 2) / denom
    b_prime = cov_basis[0, 1] - (cov_basis[0, 2] * cov_basis[1, 2]) / denom
    c_prime = cov_basis[1, 1] - (cov_basis[1, 2] ** 2) / denom
    
    # 5. Construct regularized local covariance
    # Top-left 2x2: a', b', b', c'
    # Off-diagonals with z: 0
    # z-z element: min(a', c') / 100
    min_ac = min(a_prime, c_prime)
    sigma_local = np.array([
        [a_prime, b_prime, 0.0],
        [b_prime, c_prime, 0.0],
        [0.0, 0.0, min_ac / 100.0]
    ])
    
    # 6. Transform back to world space
    sigma = B @ sigma_local @ B.T
    
    return sigma
```

## Operating characteristics
- **Time Complexity:** The transformation involves matrix multiplications ($3 \times 3$) and vector operations, which are $O(1)$ per kernel. However, it is applied only every 5000 iterations, minimizing the overhead per frame [S1].
- **Memory Complexity:** No additional significant memory is required beyond the standard Gaussian attributes, as the transformation is computed on-the-fly or stored as a modified covariance [S1].
- **Performance:** On the Mip-NeRF 360 dataset, 3D-HGS with an efficient rasterizer achieves 125 FPS and 29.66 PSNR using 3.8M kernels, compared to 3DGS which uses 3.2M kernels [S1]. On Tank & Dengin, it achieves 160 FPS and 24.45 PSNR with 1.8M kernels [S1]. On Tank & Blending, it achieves 126 FPS and 29.76 PSNR with 2.6M kernels [S1].
- **Strengths:** Consistently outperforms original 3D Gaussian Splatting across all metrics (PSNR, etc.) on evaluated datasets [S1]. The half-ellipsoid shape effectively models sharp transitions between object surfaces and empty space, reducing noise [S1].
- **Limitations:** Requires accurate surface normal estimation to define the cutting plane; if normals are noisy, the half-Gaussian orientation may be incorrect. The method increases the number of kernels compared to standard 3DGS in some datasets (e.g., 3.8M vs 3.2M on Mip-NeRF 360) [S1].

## Background
3D Half-Gaussian Splatting (3D-HGS) was introduced in the paper "3D-HGS: 3D Half-Gaussian Splatting" [S1]. The method addresses the limitation of full ellipsoids in representing sharp boundaries by cutting the Gaussian in half along the surface normal. It is evaluated against architectures such as Scaffold, mip-splatting, and MCMC [S1]. The approach is part of the broader family of regularization and geometry constraints in Gaussian Splatting, specifically focusing on spatial/shape domain modifications [S1].
