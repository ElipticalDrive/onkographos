# Height-field Gaussian Primitive

Also called: H-2DGS primitive

## Overview
The Height-field Gaussian Primitive is a curved local chart that combines the thin support of a 2D surfel with bending capability via a Gaussian-basis height field [S1, unofficial]. It stores spatially varying appearance (color and opacity) on the same local domain, allowing a small number of patches to represent both smooth geometry and detailed texture [S1, unofficial]. It sets itself apart from vanilla Gaussian Splatting by providing an explicit surface intersection and camera-linear depth, rather than volumetric accumulation through an ellipsoid [S1, unofficial].

## How it works
**Inputs:** World-space ray $r(t) = o + td$ [S1, unofficial].
**Outputs:** Intersection parameter $t$, color $C_i$, and opacity $O_i$ at the intersection point [S1, unofficial].

**Data Structures:**
Each primitive $i$ stores: center $\mathbf{c}_i \in \mathbb{R}^3$; tangent frame $R_i = [\mathbf{t}_{u,i}, \mathbf{t}_{v,i}, \mathbf{n}_i] \in \mathbb{R}^{3 \times 3}$; tangent scales $s_{x,i}, s_{y,i} \in \mathbb{R}$; height basis coefficients $b_{i,k}^h \in \mathbb{R}$ for $k=1 \dots K_h$; height basis centers $\boldsymbol{\mu}_{i,k}^h \in \mathbb{R}^2$; height basis bandwidths $\sigma_{i,k}^h \in \mathbb{R}$; color basis coefficients and centers; opacity basis coefficients and centers; constant terms for color and opacity [S1, unofficial].

**Parameters:**
- $K_h = 5$ height bases [S1, unofficial].
- 20 opacity bases [S1, unofficial].
- 50 color bases [S1, unofficial].

**Steps:**
1. Transform the world-space ray into the primitive's local frame: $\mathbf{y}_i(t) = R_i^T (r(t) - \mathbf{c}_i)$ [S1, unofficial].
2. Compute normalized local coordinates: $u_i(t) = y_{x,i}(t)/s_{x,i}$ and $v_i(t) = y_{y,i}(t)/s_{y,i}$ [S1, unofficial].
3. Evaluate the height field $h_i(u, v)$ at $(u_i(t), v_i(t))$: $h_i(u, v) = \sum_{k=1}^{K_h} b_{i,k}^h \phi_{i,k}^h(u, v)$, where $\phi_{i,k}^h(u, v) = \exp\left(-\frac{\|(u, v) - \boldsymbol{\mu}_{i,k}^h\|^2}{2(\sigma_{i,k}^h)^2}\right)$ [S1, unofficial].
4. Define the residual function for intersection: $f_i(t) = y_{z,i}(t) - h_i(u_i(t), v_i(t))$ [S1, unofficial].
5. Solve $f_i(t) = 0$ for $t$ using a small fixed number of Newton iterations [S1, unofficial]. The derivative $f_i'(t)$ requires the chain rule because $u_i(t)$ and $v_i(t)$ depend on $t$ [G].
6. Evaluate color $C_i(u, v)$ and opacity $O_i(u, v)$ at the accepted intersection using their respective Gaussian bases and constant terms [S1, unofficial].
7. Composite the result in depth order [S1, unofficial].

**Pseudocode:**
```python
def render_height_field_primitive(ray_origin, ray_direction, primitive, initial_guess=0.0, max_iterations=5, tolerance=1e-6):
    # Precompute local frame axes (columns of R_i^T)
    R_T = transpose(primitive.R)
    c = primitive.c
    s_x = primitive.s_x
    s_y = primitive.s_y
    K_h = primitive.K_h

    # Helper: compute y_i(t) = R^T * (r(t) - c)
    def get_y(t):
        diff = ray_origin + t * ray_direction - c
        y_x = dot(R_T[0], diff)
        y_y = dot(R_T[1], diff)
        y_z = dot(R_T[2], diff)
        return y_x, y_y, y_z

    # Helper: evaluate height field
    def eval_height(u, v):
        h = 0.0
        for k in range(K_h):
            mu = primitive.mu_h[k]
            sigma = primitive.sigma_h[k]
            b = primitive.b_h[k]
            dx = u - mu[0]
            dy = v - mu[1]
            dist_sq = dx*dx + dy*dy
            phi = exp(-dist_sq / (2.0 * sigma*sigma))
            h += b * phi
        return h

    # Helper: evaluate appearance (color/opacity) using analogous bases + constant
    def eval_appearance(u, v, centers, sigmas, coeffs, constant):
        val = constant
        for k in range(len(centers)):
            mu = centers[k]
            sigma = sigmas[k]
            b = coeffs[k]
            dx = u - mu[0]
            dy = v - mu[1]
            dist_sq = dx*dx + dy*dy
            phi = exp(-dist_sq / (2.0 * sigma*sigma))
            val += b * phi
        return val

    # Newton's method to find root
    t = initial_guess
    for _ in range(max_iterations):
        y_x, y_y, y_z = get_y(t)
        u = y_x / s_x
        v = y_y / s_y
        h = eval_height(u, v)
        f_val = y_z - h
        if abs(f_val) < tolerance:
            break

        # Derivative f'(t) = dy_z/dt - (dh/du * du/dt + dh/dv * dv/dt)
        d = ray_direction
        dy_x_dt = dot(R_T[0], d)
        dy_y_dt = dot(R_T[1], d)
        dy_z_dt = dot(R_T[2], d)

        du_dt = dy_x_dt / s_x
        dv_dt = dy_y_dt / s_y

        dh_du = 0.0
        dh_dv = 0.0
        for k in range(K_h):
            mu = primitive.mu_h[k]
            sigma = primitive.sigma_h[k]
            b = primitive.b_h[k]
            dx = u - mu[0]
            dy = v - mu[1]
            dist_sq = dx*dx + dy*dy
            phi = exp(-dist_sq / (2.0 * sigma*sigma))
            dphi_du = -phi * dx / (sigma*sigma)
            dphi_dv = -phi * dy / (sigma*sigma)
            dh_du += b * dphi_du
            dh_dv += b * dphi_dv

        dh_dt = dh_du * du_dt + dh_dv * dv_dt
        f_prime = dy_z_dt - dh_dt

        if abs(f_prime) < 1e-8:
            break
        t = t - f_val / f_prime

    # Evaluate final appearance
    y_x, y_y, y_z = get_y(t)
    u_final = y_x / s_x
    v_final = y_y / s_y
    color = eval_appearance(u_final, v_final, primitive.color_bases, primitive.color_sigmas, primitive.color_coeffs, primitive.color_const)
    opacity = eval_appearance(u_final, v_final, primitive.opacity_bases, primitive.opacity_sigmas, primitive.opacity_coeffs, primitive.opacity_const)

    return t, color, opacity
```

## Operating characteristics
- **Time Complexity:** Dominated by the Newton iterations and the evaluation of the Gaussian bases. Each iteration requires $O(K_h)$ operations for the height field [S1, unofficial].
- **Memory Complexity:** Each primitive stores $K_h$ height bases, 20 opacity bases, and 50 color bases [S1, unofficial].
- **Strengths:** Provides explicit surface intersection and camera-linear depth, which is beneficial for postoperative alignment and sharp reconstruction [S1, unofficial]. Allows spatially varying appearance within a single primitive [S1, unofficial].
- **Limitations:** Requires solving a non-linear equation for each ray, which is more complex than simple plane intersection [S1, unofficial].

## Background
The Height-field Gaussian Primitive was introduced in "H-2DGS: Height-Field Gaussian Splatting for Sharp and Deformable Neurosurgical Surface Reconstruction" [S1, unofficial]. It addresses the limitation of planar surfels, which can only approximate cortical curvature by using many small elements [S1, unofficial]. The method was developed to represent both smooth geometry and detailed cortical texture with a relatively small number of patches [S1, unofficial].
