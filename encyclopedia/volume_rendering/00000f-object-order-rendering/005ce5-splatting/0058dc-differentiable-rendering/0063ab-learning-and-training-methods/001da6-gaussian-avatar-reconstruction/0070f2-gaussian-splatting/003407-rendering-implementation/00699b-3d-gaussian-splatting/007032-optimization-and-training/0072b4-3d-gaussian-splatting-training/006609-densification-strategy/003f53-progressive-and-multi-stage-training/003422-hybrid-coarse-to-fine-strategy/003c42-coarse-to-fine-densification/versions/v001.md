# Coarse-to-Fine Densification

Also called: Mesh densification, Progressive mesh refinement

## Overview
Coarse-to-Fine Densification is a training strategy for primitive-based neural reconstruction that progressively refines a sparse mesh by inserting new vertices at high-error locations [S1]. It solves the challenge of initializing and densifying a mesh representation without manual tuning, ensuring uniform distribution of vertices proportional to their spatial impact on the rendered image [S1]. Unlike single-stage training, it decouples initialization from refinement, allowing the mesh topology to adapt to the scene's complexity over time [S1].

## How it works
**Inputs:** Target image (or batch), initial sparse mesh (vertices and triangles), rendering parameters.
**Outputs:** Refined mesh (vertices, features, topology) after densification steps.

**Data Structures:**
*   **Mesh:** Set of vertices $V$ and triangles $T$. Each vertex $v \in V$ has position $\mathbf{p}_v$ and feature vector $\mathbf{f}_v$.
*   **Triangle Score:** Scalar value $\text{score}_t$ for each $t \in T$.
*   **Pixel Count:** $|\text{pixels}_t|$ number of pixels covered by triangle $t$ during rasterization.

**Steps:**

1.  **Initialization:**
    a. Downsample the target image.
    b. Compute Sobel gradient magnitudes on the downsampled image.
    c. Sample initial vertex positions proportionally to edge strength, applying a small uniform floor to ensure coverage.
    d. Create a Delaunay triangulation of the sampled points.
    e. Add boundary vertices to ensure full image coverage.
    f. Initialize vertex features (e.g., color, opacity) based on the target image at the vertex positions.

2.  **Iterative Densification:**
    For each densification step (every 500 iterations, starting at iteration 1,500 and ending at 15,000):
    a. **Score Triangles:** For each triangle $t$ in the current mesh:
        i. Calculate $\overline{\text{DSSIM}}_t$, the mean DSSIM (structural dissimilarity) of pixels covered by $t$.
        ii. Count $|\text{pixels}_t|$, the number of pixels covered by $t$.
        iii. If $|\text{pixels}_t| < 3$, exclude $t$ from scoring.
        iv. Compute score:
        $$ \text{score}_t = \overline{\text{DSSIM}}_t \cdot |\text{pixels}_t|^\alpha $$
        where $\alpha = 0.75$ [S1].
    b. **Select Triangles:** Sort triangles by $\text{score}_t$ descending. Select the top-scoring triangles such that the total number of new vertices does not exceed $0.35 \times V$, where $V$ is the current number of vertices.
    c. **Insert Vertices:** For each selected triangle $t$:
        i. Compute the centroid position $\mathbf{p}_{new} = \frac{1}{3} \sum_{v \in t} \mathbf{p}_v$.
        ii. Initialize new vertex features $\mathbf{f}_{new}$ by averaging the features of the parent triangle's vertices: $\mathbf{f}_{new} = \frac{1}{3} \sum_{v \in t} \mathbf{f}_v$.
        iii. Add $\mathbf{p}_{new}$ and $\mathbf{f}_{new}$ to the vertex set.
    d. **Re-triangulate:** Re-run Delaunay triangulation on the full updated vertex set.
    e. **Degeneracy Check:** Detect if the mesh is degenerate (e.g., colinear vertices). If so, re-mesh. This rarely occurs in practice [S1].

**Pseudocode:**

```python
def coarse_to_fine_densification(mesh, target_image, iterations, start_iter=1500, end_iter=15000, step=500):
    # Initialization
    downsampled_img = downsample(target_image)
    gradients = sobel_magnitude(downsampled_img)
    vertices = sample_vertices(gradients, uniform_floor=0.01)
    mesh.vertices = vertices
    mesh.triangles = delaunay_triangulation(vertices)
    mesh.add_boundary_vertices()
    initialize_vertex_features(mesh, target_image)

    for i in range(start_iter, end_iter + 1, step):
        # Score triangles
        scores = {}
        for t in mesh.triangles:
            pixels = rasterize_triangle(t, target_image)
            if len(pixels) < 3:
                continue
            dssim = mean_dssim(t, pixels)
            score = dssim * (len(pixels) ** 0.75)
            scores[t] = score

        # Select top triangles
        sorted_triangles = sorted(scores.items(), key=lambda x: x[1], reverse=True)
        max_new_vertices = 0.35 * len(mesh.vertices)
        new_vertices = []
        triangles_to_split = []
        count = 0

        for t, score in sorted_triangles:
            if count >= max_new_vertices:
                break
            triangles_to_split.append(t)
            count += 1

        # Insert vertices
        for t in triangles_to_split:
            centroid_pos = mean_position(t.vertices)
            centroid_feat = mean_features(t.vertices)
            new_v = Vertex(position=centroid_pos, features=centroid_feat)
            new_vertices.append(new_v)

        mesh.vertices.extend(new_vertices)

        # Re-triangulate
        mesh.triangles = delaunay_triangulation(mesh.vertices)

        # Degeneracy check (simplified)
        if is_degenerate(mesh):
            mesh = remesh(mesh)
```

**Parameters:**
*   $\alpha = 0.75$: Area-weighting exponent [S1].
*   Densification interval: Every 500 iterations [S1].
*   Start iteration: 1,500 [S1].
*   End iteration: 15,000 [S1].
*   Max new vertices: $0.35 \times V$ per step [S1].
*   Minimum pixels for scoring: 3 [S1].

**Edge Cases:**
*   **Degeneracy:** Vertices may become colinear, causing mesh degeneracy. Re-meshing is required, though rare [S1].
*   **Small Triangles:** Triangles with fewer than 3 pixels are excluded to prevent over-densification of tiny areas [S1].
*   **Precision:** DSSIM calculation should use standard floating-point precision. Gradient computation on downsampled images reduces memory usage [S1].

## Subtopics

## Operating characteristics
*   **Time Complexity:** Densification occurs every 500 iterations. Each step involves scoring all triangles ($O(T)$), sorting ($O(T \log T)$), and Delaunay triangulation ($O(V \log V)$ or $O(V^2)$ depending on implementation). Total overhead is minimal compared to rendering.
*   **Memory Complexity:** Increases with the number of vertices. Max vertices grow by 35% per step.
*   **Performance:** Training takes 1-3 minutes on an RTX A6000 [S1].
*   **Strengths:** Automatic initialization, uniform vertex distribution, prevents over-densification of small areas.
*   **Limitations:** Requires Delaunay triangulation, which can be computationally expensive for very large meshes. Degeneracy handling is necessary but rare.
*   **When to Use:** When initializing a mesh-based neural reconstruction without manual seed placement.
*   **When Not to Use:** When real-time densification is required during training (it is periodic).

## Background
Coarse-to-Fine Densification was introduced in "Neural Harmonic Textures for High-Quality Primitive Based Neural Reconstruction" [S1]. It addresses the need for robust mesh initialization and refinement in primitive-based neural reconstruction methods. The method uses structural dissimilarity (DSSIM) and area weighting to guide densification, ensuring that vertices are placed where they contribute most to image fidelity.
