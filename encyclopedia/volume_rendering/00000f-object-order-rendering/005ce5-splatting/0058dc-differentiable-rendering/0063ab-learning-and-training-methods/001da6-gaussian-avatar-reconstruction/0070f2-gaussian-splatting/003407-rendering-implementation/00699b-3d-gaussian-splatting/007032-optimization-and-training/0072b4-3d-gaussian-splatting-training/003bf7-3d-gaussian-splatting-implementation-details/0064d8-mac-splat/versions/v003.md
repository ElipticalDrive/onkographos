# MAC-Splat


## Overview
MAC-Splat is a training framework for sparse-view 3D Gaussian Splatting that resolves depth and correspondence ambiguities by enforcing direct 3D consistency supervision [S1]. Unlike methods relying on 2D photometric losses or proxy geometry, it uses semantically informed 2D correspondences to anchor and jointly regularize the position, shape, and appearance of matched Gaussians in a shared world coordinate frame [S1].

## How it works
**Inputs:** Sparse-view image set, initial 3D Gaussian primitives (centroids, covariances, opacities, colors), and camera poses [G].
**Outputs:** Optimized 3D Gaussian scene representation [G].

**Data Structures:**
*   **Gaussian Primitives:** Standard 3DGS attributes: centroid $\mathbf{c}$, covariance matrix $\mathbf{\Sigma}$ (parameterized by rotation $\mathbf{R}$ and scale $\mathbf{s}$), opacity $\alpha$, and spherical harmonic coefficients for color $\mathbf{c}_{sh}$ [G].
*   **Correspondence Anchors:** Pairs of 2D pixel coordinates $(u_1, v_1)$ and $(u_2, v_2)$ from different views, associated with a confidence score and semantic feature vector [S1].

**Steps:**

1.  **Geometric Correspondence Extraction:** Use the MASt3R geometric backbone to extract sparse 2D correspondences between image pairs [S1].
2.  **Semantic Enrichment:** Enrich the geometric matches with part-level features from a frozen DINOv3 encoder via a lightweight Residual Semantic Fusion module to improve correspondence reliability and confidence estimation [S1].
3.  **3D Lifting:** Lift the 2D anchor pairs into 3D space [S1]. During training, use ground-truth camera poses [S1]. At test time, use MASt3R-estimated poses [S1].
4.  **Multi-Attribute Consistency (MAC) Loss Calculation:** Identify the Gaussians in the scene that project to the corresponding 2D anchors [S1]. Enforce direct, confidence-weighted consistency on these matched Gaussians in a common world coordinate frame [S1]. The loss jointly regularizes positional consistency (distance between centroids), shape consistency (agreement between covariance parameters, respecting covariance geometry), and appearance consistency (agreement between opacity and color attributes) [S1]. The formulation is robust to outliers [S1].

**Pseudocode:**

```python
def compute_mac_loss(gaussians, matches, poses):
    """
    Computes the Multi-Attribute Consistency loss for matched Gaussians.
    matches: list of tuples (u1, v1, u2, v2, confidence)
    poses: dict mapping view_id to camera-to-world transformation
    gaussians: list of dicts with keys 'centroid', 'covariance', 'opacity', 'color'
    """
    pos_loss = 0.0
    shape_loss = 0.0
    app_loss = 0.0
    total_weight = 0.0

    for u1, v1, u2, v2, conf in matches:
        # [Comment: MASt3R backbone extracts sparse 2D correspondences and confidence scores.]
        # [Comment: Residual Semantic Fusion enriches matches with DINOv3 part-level features.]
        
        # Project 2D pixels to 3D rays using camera poses
        ray1 = backproject_pixel(u1, v1, poses['view1'])
        ray2 = backproject_pixel(u2, v2, poses['view2'])
        
        # Find Gaussians whose 2D projection is closest to the pixel centers
        g1 = find_closest_gaussian(gaussians, u1, v1, poses['view1'])
        g2 = find_closest_gaussian(gaussians, u2, v2, poses['view2'])
        
        if g1 is None or g2 is None:
            continue
            
        # Positional Consistency: Euclidean distance between centroids
        delta_pos = [g1['centroid'][i] - g2['centroid'][i] for i in range(3)]
        pos_term = sum(d**2 for d in delta_pos)
        
        # Shape Consistency: Covariance alignment respecting geometry
        delta_cov = [[g1['covariance'][i][j] - g2['covariance'][i][j] for j in range(3)] for i in range(3)]
        shape_term = sum(val**2 for row in delta_cov for val in row)
        
        # Appearance Consistency: Opacity and color agreement
        delta_alpha = g1['opacity'] - g2['opacity']
        delta_color = [g1['color'][i] - g2['color'][i] for i in range(3)]
        app_term = delta_alpha**2 + sum(c**2 for c in delta_color)
        
        # Weight by confidence
        pos_loss += conf * pos_term
        shape_loss += conf * shape_term
        app_loss += conf * app_term
        total_weight += conf
        
    if total_weight > 0:
        pos_loss /= total_weight
        shape_loss /= total_weight
        app_loss /= total_weight
        
    # [G] Combines positional, shape, and appearance terms with equal weighting.
    loss = pos_loss + shape_loss + app_loss
    return loss

def backproject_pixel(u, v, pose):
    # [G] Standard pinhole camera inverse projection to a unit depth ray.
    return (u, v, 1.0)

def find_closest_gaussian(gaussians, u, v, pose):
    # [G] Projects all Gaussian centroids to 2D screen space and returns the closest one.
    best_g = None
    min_dist = float('inf')
    for g in gaussians:
        # [G] Simplified orthographic projection for demonstration; real implementation uses perspective projection.
        center_2d = (g['centroid'][0], g['centroid'][1])
        dist = (center_2d[0] - u)**2 + (center_2d[1] - v)**2
        if dist < min_dist:
            min_dist = dist
            best_g = g
    return best_g
```

**Parameters:**
*   **Encoder:** DINOv3, kept frozen during training [S1].
*   **Backbone:** MASt3R, used for geometric matching [S1].
*   **Camera Poses:** Ground-truth during training; MASt3R-estimated at test time [S1].

**Edge Cases and Pitfalls:**
*   **Outliers:** The MAC loss formulation is designed to be robust to outliers in correspondences [S1].
*   **Pose Accuracy:** Performance depends on the quality of camera poses, as the method uses ground-truth poses during training but must rely on MASt3R-estimated poses at test time [S1].
*   **Sparse View Ambiguity:** The method specifically targets sparse-view settings where 2D photometric losses are insufficient [S1].

## Operating characteristics
*   **Performance:** On ScanNet++, MAC-Splat improves average PSNR over Splatt3R by more than 4.5 dB [S1]. It also reduces LPIPS and maintains performance as the camera pose gap increases [S1].
*   **Strengths:** Resolves geometric ambiguities in sparse-view reconstruction, produces geometrically coherent and semantically plausible reconstructions, and is robust to outliers [S1].
*   **Limitations:** Relies on external geometric backbones (MASt3R) and semantic encoders (DINOv3), increasing computational overhead during the correspondence extraction phase [S1].
*   **When to use:** Sparse-view 3D reconstruction where standard 3DGS fails due to depth ambiguity [S1].
*   **When not to use:** Dense-view settings where photometric losses are sufficient, or real-time applications where the overhead of MASt3R/DINOv3 inference is prohibitive [G].

## Background
*   **Origin:** MAC-Splat was introduced to address geometric artifacts in sparse-view 3D Gaussian Splatting caused by the inability of 2D photometric losses to resolve depth and correspondence ambiguities [S1].
*   **Development:** It builds on the MASt3R geometric backbone and a frozen DINOv3 encoder to obtain semantically informed 2D correspondences [S1]. The core contribution is the Multi-Attribute Consistency (MAC) loss, which enforces holistic 3D consistency [S1].
*   **Usage:** Applied to sparse-view reconstruction tasks, with experiments conducted on ScanNet++ [S1].
