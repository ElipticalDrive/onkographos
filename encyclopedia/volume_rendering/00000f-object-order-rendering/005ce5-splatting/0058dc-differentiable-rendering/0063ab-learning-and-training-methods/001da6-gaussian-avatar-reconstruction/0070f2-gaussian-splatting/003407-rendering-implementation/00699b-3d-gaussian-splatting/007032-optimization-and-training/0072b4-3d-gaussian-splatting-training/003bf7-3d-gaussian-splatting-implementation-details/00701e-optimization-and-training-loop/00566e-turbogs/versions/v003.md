# TurboGS

Also called: Error-guided training framework for 3DGS

## Overview
TurboGS is an acceleration method for 3D Gaussian Splatting (3DGS) that reduces training time by dynamically focusing optimization on perceptually informative pixels while skipping well-reconstructed regions [S1, unofficial]. It addresses the redundant computation of dense rasterization and the loss of fine details in existing sparse methods by using error-guided sparse pixel sampling, tile-level structure-aware losses, and a moment-damped hybrid solver [S1, unofficial]. Unlike standard 3DGS which rasterizes full tiles, TurboGS restricts forward and backward passes to a sparse subset of pixels selected via error and age maps, achieving up to ~10× speedup with comparable or superior quality [S1, unofficial].

## How it works
**Inputs:** Initial Gaussian primitives $G_0$, camera poses $\{C_v\}$, training images $\{I_v\}$, total iterations $T$, view budget range $[K_{min}, K_{max}]$, tile size $S$ (typically $16 \times 16$), and hyperparameters $\Theta$ including sampling rates and decay factors [S1, unofficial].
**Outputs:** Optimized Gaussian primitives $G$ [S1, unofficial].

**Data Structures:**
*   **Error Map ($E_v$):** For each view $v$, a 2D array storing per-pixel reconstruction error. Stored in contiguous GPU memory with half-precision (float16) [S1, unofficial].
*   **Age Map ($A_v$):** For each view $v$, a 2D array storing the number of consecutive iterations a pixel has not been sampled. Stored in contiguous GPU memory with uint16 precision [S1, unofficial].
*   **View Stack:** A shuffled list of candidate training views used for geometry-aware sampling [S1, unofficial].

**Formulas:**
*   **Per-pixel reconstruction error:** $e_{t,v}(p) = \|\hat{I}_{t,v}(p) - I_v(p)\|_1$ [S1, unofficial].
*   **Geometry-aware view distribution:** $\pi(u | v^\star) \propto \exp(-\lambda_d \|c_u - c_{v^\star}\|^2 - \lambda_\theta (1 - \langle d_u, d_{v^\star} \rangle))$, where $c_u, d_u$ are camera center and viewing direction of view $u$, and $v^\star$ is the anchor view [S1, unofficial].
*   **Tile-level Sparse Normalized Cross-Correlation (S-NCC) loss:** $\mathcal{L}^\tau_{S-NCC} = 1 - \text{NCC}(\hat{I}_{t,v}(P_{t,v}(\tau)), I_v(P_{t,v}(\tau)))$ [S1, unofficial].
*   **Gradient-balanced NCC weight:** $\lambda^\tau_{ncc} = \text{clip}\left(\frac{\bar{g}^\tau_{\ell_1}}{\bar{g}^\tau_{S-NCC} + \epsilon}, 0, 1\right)$, where $\bar{g}^\tau_k = \mathbb{E}_{p \in P_{t,v}(\tau)} \|\nabla_{\hat{I}}(p) \mathcal{L}^\tau_k(p)\|_1$ [S1, unofficial].
*   **Gaussian difficulty score:** $s_i = e_i + \lambda_{eff} d_i$, where $e_i = E_i / (W_i + \epsilon)$, $d_i = D_i / (W_i + \epsilon)$, and $\lambda_{eff} = \lambda_{base}(1 - \rho_t)$ [S1, unofficial].
*   **Moment-damped LM update:** $(J_g^T J_g + \text{diag}(\sqrt{v_g} + \epsilon)) \Delta g = -m_g$, where $m_g, v_g$ are Adam moments and $J_g$ is the local Jacobian [S1, unofficial].

**Parameters:**
*   $S$: Tile size, typically $16 \times 16$ pixels [S1, unofficial].
*   $K$: Number of views sampled per iteration [S1, unofficial].
*   $N_{pix}$: Number of pixels sampled per tile, $N_{pix} = \max(1, \lfloor r_t \cdot S^2 \rfloor)$, where $r_t$ is the pixel sampling rate [S1, unofficial].
*   $r_{hard}, r_{stable}$: Fractions of hard and stable pixels. $N_{hard} = \lceil r_{hard} \cdot N_{pix} \rceil$, $N_{stable} = \lfloor r_{stable} \cdot N_{pix} \rfloor$ [S1, unofficial].
*   $\beta$: EMA decay factor for error map [S1, unofficial].
*   $\lambda_d, \lambda_\theta$: Geometry-aware sampling weights [S1, unofficial].
*   $\lambda_{base}$: Effective learning rate scaling factor [S1, unofficial].

**Steps:**
1.  **Initialization:** Initialize error maps $E$ by densely evaluating $e_{0,v}(p)$ for all pixels using initial Gaussians $G_0$ [S1, unofficial]. Initialize age maps $A$ to 0 [S1, unofficial].
2.  **Progress Coefficient:** Compute $\rho_t = \min(1, t/\tau_{until})$ [S1, unofficial].
3.  **Sampling Schedule:** Query schedule to get view budget $K_t$ and pixel rate $r_t$ based on $K_{max}, K_{min}, E_{init}, \Theta, t$ [S1, unofficial].
4.  **View Selection:**
    *   Select anchor view $v^\star = \arg\max_v \bar{E}_v$, where $\bar{E}_v = \frac{1}{|\Omega|} \sum_{p \in \Omega} E_v(p)$ [S1, unofficial].
    *   Sample $K_t-1$ remaining views from a candidate stack without replacement using distribution $\pi(u | v^\star)$ [S1, unofficial].
    *   Maintain a shuffled view stack; refill and reshuffle when fewer than $K_t$ views remain [S1, unofficial].
    *   Let $V_t$ be the set of selected views [S1, unofficial].
5.  **Tile-Wise Sparse Pixel Sampling:**
    *   Partition image into tiles $\tau$ of size $S \times S$ [S1, unofficial].
    *   For each view $v \in V_t$ and tile $\tau$:
        *   Select $N_{hard}$ pixels with highest error in $\tau$ using distribution $\pi_E(p|\tau, v) = \frac{E_v(p)}{\sum_{q \in \tau} E_v(q) + \epsilon}$ [S1, unofficial]. Let this set be $H_{t,v}(\tau)$ [S1, unofficial].
        *   Select $N_{stable}$ pixels with highest age from remaining pixels $\tau \setminus H_{t,v}(\tau)$ using $\text{TopK}(A_v(p), N_{stable})$. Let this set be $S_{t,v}(\tau)$ [S1, unofficial].
        *   Final sampled pixels in tile: $P_{t,v}(\tau) = H_{t,v}(\tau) \cup S_{t,v}(\tau)$ [S1, unofficial].
    *   Full sampled set $P_{t,v} = \bigcup_\tau P_{t,v}(\tau)$ [S1, unofficial].
6.  **Sparse Forward Rasterization:**
    *   Output sampled pixels in tile order [S1, unofficial].
    *   Compute tile-wise pixel offsets via prefix-sum to allow each CUDA block (tile) to access sparse pixels efficiently [S1, unofficial].
    *   Render colors $\hat{I}_{t,v}(p)$ and depth $d$ for $p \in P_{t,v}$ [S1, unofficial].
7.  **Sparse Loss Evaluation:**
    *   Compute $\ell_1$ loss and S-NCC loss on sampled pixels [S1, unofficial].
    *   Compute gradient norms $\bar{g}^\tau_{\ell_1}$ and $\bar{g}^\tau_{S-NCC}$ per tile via block-level reduction [S1, unofficial].
    *   Compute weighted loss $\mathcal{L}^\tau = \mathcal{L}^\tau_{\ell_1} + \lambda^\tau_{ncc} \mathcal{L}^\tau_{S-NCC}$ [S1, unofficial].
8.  **EMA Updates:**
    *   Update error map for sampled pixels: $E_v(p) \leftarrow (1-\beta)E_v(p) + \beta e_{t,v}(p)$ for $p \in P_{t,v}$ [S1, unofficial].
    *   Update age map: $A_v(p) \leftarrow 0$ for $p \in P_{t,v}$, and $A_v(p) \leftarrow A_v(p) + 1$ for all other pixels [S1, unofficial].
9.  **Gaussian Backward Pass:**
    *   Retrieve sparse pixels within each tile via tile-pixel indexing [S1, unofficial].
    *   Propagate gradients $\nabla G$ via warp shuffle only over sampled pixels [S1, unofficial].
10. **Moment-Damped LM Solver:**
    *   For each Gaussian $g$, form local equation $(J_g^T J_g + \text{diag}(\sqrt{v_g} + \epsilon)) \Delta g = -m_g$ [S1, unofficial].
    *   Solve for update $\Delta g$ [S1, unofficial].
11. **Error-Driven Density Control:**
    *   Back-project pixel properties to Gaussians to get per-Gaussian error $e_G$, distance $D_G$, and alpha $\alpha_G$ [S1, unofficial].
    *   Perform densification and pruning based on screen radii, back-projected properties, and difficulty score $s_i$ [S1, unofficial].
12. **Apply Updates:** Update $G \leftarrow G + \Delta G$ [S1, unofficial].

**Pseudocode:**
```python
def turbogs_train(G, Cameras, Images, T, K_max, K_min, S, beta, lambda_d, lambda_theta, lambda_base, r_hard, r_stable, tau_until):
    # Initialization: densely evaluate error for initial Gaussians G0
    E = np.zeros((len(Cameras), H, W), dtype=np.float16)
    for v in range(len(Cameras)):
        for p in all_pixels:
            E[v][p] = np.linalg.norm(render(G, Cameras[v], p) - Images[v][p])
    A = np.zeros_like(E, dtype=np.uint16)
    ViewStack = list(range(len(Cameras)))
    np.random.shuffle(ViewStack)
    
    for t in range(T):
        rho = min(1.0, t / tau_until)
        
        # 1. Sampling Parameters: query schedule (not given in sources)
        K_t, r_t = query_sampling_schedule(K_max, K_min, E, t)
        N_pix = max(1, int(np.floor(r_t * S * S)))
        N_hard = int(np.ceil(r_hard * N_pix))
        N_stable = int(np.floor(r_stable * N_pix))
        
        # 2. View Selection
        avg_errors = [np.mean(E[v]) for v in range(len(Cameras))]
        v_star = int(np.argmax(avg_errors))
        V_t = [v_star]
        candidates = [u for u in ViewStack if u != v_star]
        for _ in range(K_t - 1):
            if not candidates:
                ViewStack = list(range(len(Cameras)))
                np.random.shuffle(ViewStack)
                candidates = [u for u in ViewStack if u not in V_t]
            probs = []
            for u in candidates:
                c_u, d_u = Cameras[u].center, Cameras[u].direction
                c_v, d_v = Cameras[v_star].center, Cameras[v_star].direction
                score = np.exp(-lambda_d * np.linalg.norm(c_u - c_v)**2 - lambda_theta * (1 - np.dot(d_u, d_v)))
                probs.append(score)
            probs = np.array(probs) / np.sum(probs)
            u_idx = np.random.choice(len(candidates), p=probs)
            u = candidates[u_idx]
            V_t.append(u)
            candidates.remove(u)
            
        # 3. Tile-Wise Pixel Sampling
        P_t = {}
        for v in V_t:
            P_t[v] = []
            for tile_idx in range(num_tiles):
                tile_pixels = get_pixels_in_tile(tile_idx, S)
                errors_in_tile = [E[v][p] for p in tile_pixels]
                hard_indices = np.argsort(errors_in_tile)[-N_hard:]
                H = [tile_pixels[i] for i in hard_indices]
                remaining = [p for p in tile_pixels if p not in H]
                ages_in_remaining = [A[v][p] for p in remaining]
                stable_indices = np.argsort(ages_in_remaining)[-N_stable:]
                S_set = [remaining[i] for i in stable_indices]
                P_t[v].append((tile_idx, H + S_set))
                
        # 4. Sparse Forward Rendering: output sampled pixels in tile order, compute offsets via prefix-sum
        RenderedColors, RenderedDepth = sparse_rasterize_forward(G, Cameras, P_t)
        
        # 5. Sparse Loss & Gradients
        Loss = 0.0
        for v in V_t:
            for tile_idx, sampled_pixels in P_t[v]:
                GT_Colors = [Images[v][p] for p in sampled_pixels]
                Rendered = [RenderedColors[v][p] for p in sampled_pixels]
                L1 = np.mean([np.abs(r - g) for r, g in zip(Rendered, GT_Colors)])
                NCC = normalized_cross_correlation(Rendered, GT_Colors)
                SNCC = 1.0 - NCC
                g_L1 = np.mean([np.linalg.norm(grad_L1(p)) for p in sampled_pixels])
                g_SNCC = np.mean([np.linalg.norm(grad_SNCC(p)) for p in sampled_pixels])
                lambda_ncc = np.clip(g_L1 / (g_SNCC + epsilon), 0, 1)
                TileLoss = L1 + lambda_ncc * SNCC
                Loss += TileLoss
                
        # Backward pass: retrieve sparse pixels via tile-pixel indexing, propagate gradients via warp shuffle
        GradG = sparse_rasterize_backward(GradLoss, G, P_t)
        
        # 6. EMA Updates
        for v in V_t:
            for tile_idx, sampled_pixels in P_t[v]:
                for p in sampled_pixels:
                    err = np.abs(RenderedColors[v][p] - Images[v][p])
                    E[v][p] = (1 - beta) * E[v][p] + beta * err
                    A[v][p] = 0
            for p in all_pixels:
                if p not in sampled_pixels:
                    A[v][p] += 1
                        
        # 7. Moment-Damped LM Solver
        for g in G:
            J_g, m_g, v_g = compute_local_jacobian_and_moments(g, GradG)
            Delta_g = solve_linear_system(J_g.T @ J_g + np.diag(np.sqrt(v_g) + epsilon), -m_g)
            g += Delta_g
            
        # 8. Error-Driven Density Control: back-project properties, densify/prune
        e_G, D_G, alpha_G = back_project_properties(G, P_t, RenderedColors)
        G = error_driven_density_control(G, e_G, D_G, alpha_G, t)
        
    return G
```

## Operating characteristics
*   **Time Complexity:** Significantly reduced compared to dense 3DGS due to sparse rasterization and sampling. TurboGS completes training in ~80 seconds on Mip-NeRF 360 Bicycle scene, compared to 891 seconds for vanilla 3DGS [S1, unofficial].
*   **Memory Complexity:** Requires storage for Error Map ($E$) and Age Map ($A$) per view. $E$ uses float16, $A$ uses uint16 [S1, unofficial].
*   **Performance:** Achieves comparable or superior PSNR/SSIM to baseline 3DGS and other acceleration methods (e.g., Taming-3DGS, Speedy-Splat) while being faster [S1, unofficial].
*   **Strengths:** Reduces redundant computation on well-reconstructed regions; preserves fine details via S-NCC loss; stable convergence via moment-damped LM solver [S1, unofficial].
*   **Limitations:** Sparse supervision may introduce subtle rippling artifacts in low-frequency regions with weak texture variations (e.g., walls or ceilings) [S1, unofficial].
