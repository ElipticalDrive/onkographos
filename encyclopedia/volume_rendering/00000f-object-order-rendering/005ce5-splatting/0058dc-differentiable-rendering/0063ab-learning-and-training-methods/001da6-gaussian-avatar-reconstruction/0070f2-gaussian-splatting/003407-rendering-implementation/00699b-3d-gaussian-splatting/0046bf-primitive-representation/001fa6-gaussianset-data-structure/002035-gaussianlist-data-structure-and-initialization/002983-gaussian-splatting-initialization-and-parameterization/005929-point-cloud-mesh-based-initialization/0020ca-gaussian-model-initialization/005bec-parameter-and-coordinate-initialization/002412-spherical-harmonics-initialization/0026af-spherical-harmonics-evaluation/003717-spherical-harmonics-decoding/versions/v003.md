# Spherical Harmonics Decoding

Also called: RGB SH decoding, SH coefficient unpacking

## Overview
Spherical Harmonics (SH) Decoding reconstructs the RGB color of a 3D Gaussian splat from its stored SH coefficients [S1, unofficial]. It focuses on unpacking and interpreting the raw coefficient storage format, typically packed in GPU buffers, rather than evaluating the basis functions [S1, unofficial]. It is distinguished from [Spherical Harmonics Evaluation](3848-spherical-harmonics-evaluation.md) which computes the final color from coefficients and direction, and from [Spherical Harmonics Rotation](3985-spherical-harmonics-rotation.md) which transforms coefficients to camera space [S1, unofficial].

## How it works
**Inputs:**
- `coefficients_packed`: A flat `Uint32Array` storing SH coefficients, packed 4 per 32-bit word [S1, unofficial].
- `degree`: The maximum SH degree used (typically 0, 1, 2, or 3) [S1, unofficial].
- `SH_KEYS`: A lookup table mapping coefficient groups to their corresponding SH basis indices [S1, unofficial].

**Outputs:**
- `color`: A 3-component RGB vector $(R, G, B)$ representing the decoded color [S1, unofficial].

**Data Structures:**
- `Uint32Array`: The storage format where each 32-bit word contains 4 float values, corresponding to one RGB channel component across multiple coefficients [S1, unofficial].
- `SH_KEYS`: A mapping array where `SH_KEYS[coefficient >> 2]` determines the base index for the SH basis in the packed buffer [S1, unofficial].

**Steps:**
1. Compute the coefficient count as `degree * (degree + 2)` [S1, unofficial].
2. Initialize an RGB accumulator to $[0, 0, 0]$ and a result array of the computed length [S1, unofficial].
3. Iterate through each coefficient index $c$ from $0$ to $N-1$.
4. Determine the source array index using `SH_KEYS[c >> 2]` [S1, unofficial].
5. Calculate the word offset using `base + (c & 3)`, where `base = index * 4` [S1, unofficial].
6. Read the 32-bit word from the array, defaulting to $0$ if the index is out of bounds or missing [S1, unofficial].
7. Decode the word to RGB using a helper function `decodeShRgbToArray` [S1, unofficial].
8. Store the decoded color in the result array and add it to the RGB accumulator [S1, unofficial].
9. Return the accumulated RGB color.

**Pseudocode:**
```python
def decode_sh_rgb(coefficients_packed, degree, SH_KEYS):
    # Compute coefficient count as per source [S1, unofficial]
    num_coeffs = degree * (degree + 2)
    
    # Initialize RGB accumulator and result array [S1, unofficial]
    r_acc, g_acc, b_acc = 0.0, 0.0, 0.0
    result = [None] * num_coeffs
    
    for c in range(num_coeffs):
        # Determine source array index using SH_KEYS lookup [S1, unofficial]
        index = SH_KEYS[c >> 2]
        base = index * 4
        offset = c & 3
        
        # Read word, defaulting to 0 if missing [S1, unofficial]
        word = coefficients_packed[base + offset] if (base + offset) < len(coefficients_packed) else 0
        
        # Decode word to RGB via source-specific function [S1, unofficial]
        # The exact implementation of decodeShRgbToArray is not provided in the sources.
        r, g, b = decodeShRgbToArray(word)
        
        # Store in result and accumulate [S1, unofficial]
        result[c] = (r, g, b)
        r_acc += r
        g_acc += g
        b_acc += b
        
    return [r_acc, g_acc, b_acc]
```

**Parameters:**
- `degree`: Integer, typically 0, 1, 2, or 3 [S1, unofficial].
- `SH_KEYS`: Lookup table mapping coefficient groups to SH basis indices, specific to the implementation [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** Reading from `Uint32Array` requires careful bit-packing interpretation, as the raw bits must be reinterpreted as floats [S1, unofficial].
- **Missing Data:** If a coefficient index is out of bounds, the implementation defaults to $0$ [S1, unofficial].
- **Boundary Conditions:** Ensure array bounds are checked before accessing `coefficients_packed` to prevent out-of-bounds errors [G].

## Subtopics

### [Spherical Harmonics Degree 0 Color Reconstruction](11528-spherical-harmonics-degree-0-color-reconstruction.md)
Reconstructs the base diffuse color of a 3D Gaussian splat from its stored zeroth-order spherical harmonic coefficient ($SH_0$). It serves as the fallback color mechanism for the `COLOR_0` attribute in glTF, allowing renderers without 3D Gaussian splatting support to display the point cloud with correct diffuse shading. It is distinguished from higher-degree SH decoding by evaluating only the constant basis function, ignoring directional variation.

### Neural Deferred Shading
A decoding strategy that concatenates the accumulated harmonics with ray direction encoding and decodes the final pixel color using a shallow MLP in a single image-space pass [S2]. It encodes the ray direction $\mathbf{d}$ using second-degree spherical harmonics $\text{SH}_2(\mathbf{d}) \in \mathbb{R}^9$ [S2]. The final color $\mathbf{c}$ is computed as:
$$
\mathbf{c} = \text{MLP}_\theta \left( \sum_{i \in \mathcal{G}} \alpha_i T_i \begin{bmatrix} \sin(\mathbf{f}_i) \\ \cos(\mathbf{f}_i) \end{bmatrix}, k \cdot \text{SH}_2(\mathbf{d}) \right)
$$
where $\text{MLP}_\theta$ is a shallow MLP with weights $\theta$, $k$ is a scaling factor, $\alpha_i$ and $T_i$ are primitive opacity and accumulated transmittance, and $\mathbf{f}_i$ are primitive features [S2]. The scaling factor $k$ is applied to the spherical harmonics encoding of the ray direction [S2].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of coefficients $N$, i.e., $O(N)$ [S1, unofficial].
- **Memory Complexity:** Linear with respect to the number of coefficients $N$ [S1, unofficial].
- **Strengths:** Efficient unpacking from GPU buffers; supports variable degrees; fallback compatibility with glTF [S1, unofficial].
- **Limitations:** Requires specific packing format; `SH_KEYS` lookup is implementation-specific [S1, unofficial].
- **When to use:** When rendering 3D Gaussian splats with directional color variation; when compatibility with glTF is required [S1, unofficial].
- **When not to use:** When high-frequency directional detail is not needed (use Degree 0); when real-time performance is critical and degree is high (consider lower degree or neural decoding) [S2].

## Background
Spherical Harmonics Decoding is a core component of 3D Gaussian Splatting, a method for real-time radiance field rendering [S1, unofficial]. The specific packing format described in [S1, unofficial] is from an unofficial implementation (Gaussian-Splat-Lite) aimed at glTF compatibility [S1, unofficial]. Neural Deferred Shading, a variant, was proposed in "Neural Harmonic Textures for High-Quality Primitive Based Neural Reconstruction" [S2].
