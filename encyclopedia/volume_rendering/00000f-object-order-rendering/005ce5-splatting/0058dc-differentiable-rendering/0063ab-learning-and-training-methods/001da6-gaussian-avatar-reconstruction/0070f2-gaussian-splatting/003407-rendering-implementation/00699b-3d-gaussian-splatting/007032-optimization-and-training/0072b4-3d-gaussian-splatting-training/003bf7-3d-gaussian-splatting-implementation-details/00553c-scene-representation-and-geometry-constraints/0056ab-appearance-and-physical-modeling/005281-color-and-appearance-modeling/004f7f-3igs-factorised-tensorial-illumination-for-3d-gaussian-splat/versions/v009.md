# 3iGS (Factorised Tensorial Illumination for 3D Gaussian Splatting)


## Overview
3iGS enhances 3D Gaussian Splatting by modeling outgoing radiance as a function of a continuous local illumination field and individual Gaussian BRDF attributes, rather than optimizing radiance in isolation [S1]. It differs from [DAVIGS](12021-davigs.md) by using a grid-based tensor illumination field instead of post-processing transformations, and from [Compact View-dependent Color](12904-compact-view-dependent-color.md) by explicitly separating diffuse and specular components via a neural renderer [S1].

## How it works
**Inputs:** 3D Gaussian primitives (means $\mu$, scales $S$, rotations $R$, opacity $\alpha$), initial SH coefficients, and training images.
**Outputs:** Rendered images, optimized Gaussian parameters, and illumination grid.

**Data Structures:**
1.  **Illumination Grid ($\mathcal{G}_l$):** A factorised tensor field.
    *   Resolution: $150^3$ voxels (coarse) [S1].
    *   Structure: Vector-matrix spatial factorisation with $R_L$ feature channels [S1].
    *   Fields: Feature tensors $\mathbf{A}_{L,r}^X, \mathbf{A}_{L,r}^Y, \mathbf{A}_{L,r}^Z$ and feature vectors $\mathbf{b}_{3r-2}, \mathbf{b}_{3r-1}, \mathbf{b}_{3r}$ for $r \in [1, R_L]$ [S1].
2.  **Gaussian Attributes:**
    *   Mean $\mu \in \mathbb{R}^3$ [S1].
    *   Opacity $\alpha \in \mathbb{R}$ [S1].
    *   Covariance $\Sigma = RSS^TR^T$ derived from scale $S$ and rotation $R$ [S1].
    *   Diffuse color $\mathbf{c}_d$ [S1].
    *   BRDF features $\rho_i$: Repurposed 16x3 SH coefficients from base 3DGS, plus 4 additional parameters for base color and roughness for IDE encoding [S1].
3.  **Neural Renderer ($\mathcal{F}$):** Maps $\{\rho_i, L_i, \omega_o\}$ to specular color $\mathbf{c}_s$ [S1].

**Steps:**

1.  **Initialize Gaussians:** Fit 3D Gaussians to point cloud data using standard 3DGS initialization [S1].
2.  **Define Illumination Grid Boundary:** Create an initial boundary encapsulating the scene bounding box [S1].
3.  **Training Phase 1 (Diffuse):** Optimize the model for the first 3,000 iterations using only the diffuse color $\mathbf{c}_d$ [S1].
    *   Compute covariance in camera coordinates: $\mathbf{\Sigma}' = JW\Sigma W^TJ^T$, where $W$ is the viewing transformation and $J$ is the affine approximation of the projective transformation [S1].
    *   Render using alpha blending:
        $$ \hat{\mathbf{C}} = \sum_{i \in N} T_i g_i(\mathbf{u} | \boldsymbol{\mu}', \mathbf{\Sigma}') \alpha_i \mathbf{c}_d $$
        $$ T_i = \prod_{j=1}^{i-1} (1 - g_j(\mathbf{u} | \boldsymbol{\mu}', \mathbf{\Sigma}') \alpha_j) $$
        $$ g(\mathbf{x} | \boldsymbol{\mu}, \mathbf{\Sigma}) = e^{-\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})} $$
    *   Minimize loss:
        $$ \mathcal{L} = (1 - \lambda)\mathcal{L}_1 + \lambda \mathcal{L}_{\text{D-SSIM}} $$
        with $\lambda = 0.2$ [S1].
4.  **Shrink Illumination Grid:** Midway through training (after Phase 1), shrink the illumination grid boundary to fit the current Gaussians and resample the grid with the same number of voxels [S1].
5.  **Training Phase 2 (Specular):** Add specular colors to the Gaussians.
    *   Query illumination $L_i$ for each Gaussian mean $\mathbf{x}_i$ from $\mathcal{G}_l$:
        $$ \mathcal{G}_l = \sum_{r=1}^{R_L} \mathbf{A}_{L,r}^X \circ \mathbf{b}_{3r-2} + \mathbf{A}_{L,r}^Y \circ \mathbf{b}_{3r-1} + \mathbf{A}_{L,r}^Z \circ \mathbf{b}_{3r} $$
        where $\circ$ denotes the appropriate tensor contraction/interpolation [S1].
    *   Encode viewing direction $\omega_o$ using Integrated Directional Encoding (IDE) [S1].
    *   Compute specular color $\mathbf{c}_s$ via neural network $\mathcal{F}$:
        $$ \mathcal{F} : \{ \rho_i, L_i, \omega_o \} \mapsto \mathbf{c}_s $$
    *   Compute final outgoing radiance:
        $$ \mathbf{c}(\omega_o) = \mathbf{c}_d + \mathbf{c}_s(\omega_o) $$
    *   Render and optimize all parameters ($\mu, \alpha, S, R, \mathbf{c}_d, \rho_i, \mathcal{G}_l$) for the remaining iterations (total 30,000 steps) [S1].

**Pitfalls:**
*   The illumination grid boundary must be shrunk midway through training to fit the Gaussians; otherwise, interpolation may be inaccurate [S1].
*   Standard 3DGS SH optimization fails to capture specular effects because it optimizes radiance in isolation without accounting for shared scene lighting [S1].

## Operating characteristics
*   **Memory:** The illumination field uses 87.5% less voxels compared to TensoRF on synthetic datasets [S1].
*   **Performance:** On the Shiny Blender dataset, 3iGS achieves PSNR 27.51, SSIM 0.930, LPIPS 0.045 [S1].
*   **Strengths:** Significantly enhances specular view-dependent effects compared to base 3DGS while maintaining rapid training and rendering speeds [S1].
*   **Limitations:** Requires a neural network $\mathcal{F}$ for shading, adding complexity compared to pure SH [S1].

## Background
3iGS was introduced by Z.J. Tang and T.J. Cham [S1]. It addresses the limitations of 3DGS in rendering reflective surfaces by modeling incident illumination locally with grid-based tensors and optimizing Gaussian BRDF features relative to this field, contrasting with methods like GaussianShader which use global environment lights [S1].
