# DOF-GS

Also called: Adjustable Depth-of-Field 3D Gaussian Splatting

## Overview
DOF-GS is a 3D Gaussian Splatting framework that incorporates a finite-aperture camera model to explicitly model and render depth-of-field (DOF) effects, enabling post-capture control of aperture and focal distance [S1]. Unlike previous NeRF-based techniques that simulate defocus via expensive per-ray blur kernels or recent 3DGS methods that use black-box neural networks for shape offsets, DOF-GS blurs individual Gaussians based on learnable Circle-of-Confusion (CoC) cues before compositing, allowing efficient, differentiable, and intuitive DOF adjustment [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:** A set of multi-view images with moderate defocus blur [S1].
- **Outputs:** A reconstructed 3D scene representation $\mathcal{S}$ consisting of anisotropic 3D Gaussian points, and optimized camera parameters (aperture and focal distance) per view [S1].

**Scene Representation:**
The scene is represented by a set of $K$ anisotropic 3D Gaussian points $\{G_k\}_{k=1}^K$ [S1]. Each Gaussian $G_k$ is defined by a center position $u_k$, a covariance matrix $\Sigma_k$ derived from anisotropic scaling $s_k$ and a quaternion $q_k$, an opacity $o_k$, and spherical harmonics coefficients $h_k$ [S1]. The 3D Gaussian function is defined as [S1]:
$$ G_k(p) = \exp\left(-\frac{1}{2}(p - u_k)^T \Sigma_k^{-1} (p - u_k)\right) $$

**Projection:**
3D Gaussian points are projected to 2D screen space [S1]. The Jacobian $J$ of the projective transformation is calculated [S1]. The 2D covariance matrix $\Sigma'_k$ is computed as [S1]:
$$ \Sigma'_k = J W \Sigma_k W^T J^T $$
where $W$ is the view matrix transforming points from world space to camera space [S1]. The 2D Gaussian in screen space is [S1]:
$$ G'_k(x) = \exp\left(-\frac{1}{2}(x - u'_k)^T \Sigma'^{-1}_k (x - u'_k)\right) $$
where $u'_k$ is the 2D center position post-projection [S1].

**Standard Rasterization:**
For each pixel $x$, a small number $N_x$ of Gaussians within a cutoff radius $t$ are associated with it [S1]. The image is rendered using alpha blending [S1]:
$$ \tilde{I}(x) = \sum_{i=1}^{N_x} T_i \alpha_i c_i $$
where $\alpha_i = G'_i(x)$, $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the transmittance, and $c_i$ is the view-dependent color of the $i$-th Gaussian [S1].

**DOF Rendering:**
A differentiable DOF rendering process is integrated into the rasterizer [S1]. Individual Gaussians are blurred based on learnable CoC cues before compositing [S1]. This process is fully differentiable, allowing optimization of camera parameters alongside the 3D scene [S1].

**CoC Calculation:**
The radius of the Circle-of-Confusion (CoC) $R_{coc}$ for an object point at depth $z_o$ is determined by the focal length $F$, aperture diameter $A$, and focal distance $f$ [S1]:
$$ R_{coc} = \frac{1}{2} F A \frac{|z_o - f|}{z_o (f - F)} $$
Since $F$ is often much smaller than $f$ and object depths, this is simplified to [S1]:
$$ R_{coc} = \frac{1}{2} Q \left| \frac{1}{z_o} - \frac{1}{f} \right| $$
where $Q = FA$ is a simplified aperture parameter [S1].

**CoC-Guided Detail Enhancement:**
A lightweight CoC-guided neural network predicts an in-focus mask for each view [S1]. These masks are used to enhance details within All-in-Focus (AiF) renderings during optimization, counteracting reduced sharpness due to defocus blur in multi-view inputs [S1].

**Optimization:**
The scene representation $\mathcal{S}$ and camera parameters are optimized by minimizing the reconstruction loss $L_{rec}$ between rendered views $\tilde{I}_m$ and training views $I_m$ [S1]:
$$ \min_{\mathcal{S}} \sum_{m=1}^M L_{rec}(\tilde{I}_m, I_m) $$
The loss is a weighted combination of MSE and DSSIM [S1]:
$$ L_{rec}(I_a, I_b) = ||I_a - I_b|| + \lambda_{dssim} L_{dssim}(I_a, I_b) $$

**Pseudocode:**

import torch

def compute_coc_radius(z_o, F, A, f):
    """Compute Circle-of-Confusion radius for depth z_o."""
    Q = F * A
    return 0.5 * Q * abs(1.0 / z_o - 1.0 / f)

def project_gaussian(u_k, Sigma_k, W, J):
    """Project 3D Gaussian to 2D screen space."""
    u_prime_k = J @ W @ u_k
    Sigma_prime_k = J @ W @ Sigma_k @ W.T @ J.T
    return u_prime_k, Sigma_prime_k

def evaluate_gaussian(x, u_prime_k, Sigma_prime_k):
    """Evaluate 2D Gaussian at pixel x."""
    diff = x - u_prime_k
    inv_cov = torch.linalg.inv(Sigma_prime_k)
    return torch.exp(-0.5 * diff.T @ inv_cov @ diff)

def render_dof_scene(gaussians, A, f, F, W, J, image_shape):
    """Render scene with DOF blur using alpha compositing."""
    rendered = torch.zeros(image_shape)
    transmittance = torch.ones(image_shape)
    # Gaussians are sorted by depth for correct alpha blending
    for g in gaussians:
        u_k, Sigma_k, color, z_o = g
        u_prime_k, Sigma_prime_k = project_gaussian(u_k, Sigma_k, W, J)
        alpha_base = evaluate_gaussian(x, u_prime_k, Sigma_prime_k)
        coc = compute_coc_radius(z_o, F, A, f)

        # Implementation typically convolves the projected Gaussian with a disk kernel of radius coc.

## Operating characteristics
- **Time Complexity:** Rendering is efficient, leveraging the standard 3DGS rasterization pipeline with additional CoC-based blurring [S1]. This is significantly faster than NeRF-based defocus methods which require hours to days of training and yield below 1 FPS [S1].
- **Memory Complexity:** Stores standard 3DGS attributes plus learnable camera parameters ($A, f$) per view and a lightweight neural network for CoC-guided detail enhancement [S1].
- **Strengths:** Enables post-capture control of aperture and focal distance; differentiable optimization allows learning camera characteristics from defocused images; efficient compared to ray-tracing based defocus methods [S1].
- **Limitations:** Requires multi-view defocused images for training; relies on a simplified thin lens model [S1].
- **When to use:** When post-capture DOF control and refocusing from multi-view defocused inputs is required [S1].
- **When not to use:** For scenes without defocus blur where standard pinhole 3DGS is sufficient, or when real-time performance on extremely low-end hardware is critical without the overhead of the CoC-guided network [S1].

## Background
DOF-GS was introduced to address the limitations of the pinhole camera model in existing 3DGS methods, which lack effective modeling of defocus effects [S1]. It builds on the 3DGS framework and surface-splatting techniques, extending them with a finite-aperture camera model [S1]. The method was tested on scenes from the multi-view defocus blur dataset [S1].
