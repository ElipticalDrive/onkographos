# Pruning and Reduction

Also called: Gaussian Pruning, Gaussian Reduction, Vertex Pruning

## Overview
Pruning and reduction methods aim to decrease the number of 3D Gaussian primitives in a scene representation to improve storage efficiency, rendering speed, or model compactness, while maintaining visual fidelity. Unlike standard opacity-based pruning which removes primitives based on their individual contribution to the image, this family includes methods that handle mixed primitives [S1, unofficial], optimize global retention budgets via combinatorial selection [S1, unofficial], or apply visibility and learnable mask constraints during optimization [S2].

## Shared principles
All methods in this family operate on the set of $N$ 3D Gaussian primitives defined in [Gaussian Representation and Truncation](12855-gaussian-representation-and-truncation.md). The core mechanism involves reducing the cardinality $N$ or simplifying the geometric complexity of the primitives. This is achieved by:
1.  **Removal:** Deleting primitives that contribute minimally to the rendering loss or visibility [S2].
2.  **Simplification:** Converting complex primitives (e.g., triangles) into simpler ones (e.g., lines or ellipses) by removing redundant vertices [S1, unofficial].
3.  **Masking:** Applying learnable binary masks to attributes like opacity and scale to effectively zero out or compress primitives during training [S2].

## Subtopics

### [Vertex-level Pruning in Mixed-Primitive Gaussian Splatting](13983-vertex-level-pruning-in-mixed-primitive-gaussian-splatting.md)
Vertex-level pruning is a refinement mechanism for mixed-primitive Gaussian Splatting that removes redundant vertices from Gaussian triangles and lines during training to simplify the representation. Unlike standard 3D Gaussian Splatting which only performs primitive-level opacity pruning, this method dynamically converts complex primitives (triangles) into simpler ones (lines or ellipses) based on vertex geometry, reducing storage overhead and representation clutter. See [Vertex-level Pruning in Mixed-Primitive Gaussian Splatting](13983-vertex-level-pruning-in-mixed-primitive-gaussian-splatting.md).

### [SplatQ](14415-splatq.md)
SplatQ is a post-training Gaussian pruning framework that partitions Gaussians by spatial proximity and appearance similarity into size-limited blocks, smooths importance-based block retention quotas to prevent budget concentration, and constructs a quadratic approximation of joint deletion effects to jointly select Gaussians under a fixed budget. It differs from global Top-K methods by decomposing the selection into subproblems of specific size and solving a combinatorial optimization problem within each block, rather than ranking all Gaussians globally by independent scores. See [SplatQ](14415-splatq.md).

### Gaussian Reduction with Learnable Mask
#### definition
- [S2] A method to reduce the number of Gaussians using a learnable mask during optimization, targeting small-sized kernels for removal.
#### step
- [S2] Apply binary masks M to the opacities and scale attributes of the kernels at every densification step.
- [S2] Use residual vector quantization with L stages of vector quantization for geometric attributes like scale and rotation.
- [S2] Represent view-dependent colors via a grid-based neural field using hash grids for input positions, features, and view direction, fed into an MLP.
#### formula
- [S2] The end-to-end loss is: $L = L_{ren} + \lambda_m L_m + L_r + L_s$, where $L_{ren}$ is L1+SSIM loss, $L_m$ is masking loss ($\frac{1}{N} \sum \sigma(m_n)$), and $L_r, L_s$ are rotation and scale objective functions.
#### parameter
- [S2] $\epsilon$: Masking threshold for the sigmoid function in the learnable mask.
- [S2] $\lambda_m$: Weight for the masking loss term, typically $5 \times 10^{-4}$.

### 3DGS Visibility Pruning
#### definition
- [S2] Application of visibility-based pruning to 3D Gaussian Splatting, using Gaussian centroids as reference points for visibility calculation.
#### step
- [S2] Represent each Gaussian kernel by its centroid position, scaling matrix $S$, and rotation matrix $R$ defining the covariance $\Sigma$.
- [S2] Use the Gaussian centroids as the 3D points $p_i$ in the visibility mask computation algorithm.

## Background
The need for pruning arises from the high memory footprint of 3D Gaussian Splatting, which can scale to millions of primitives. Early work focused on opacity-based pruning [S1, unofficial]. Subsequent research introduced mixed-primitive handling [S1, unofficial], global optimization strategies like SplatQ [S1, unofficial], and integration of visibility checks [S2] or learnable masks [S2] directly into the training pipeline to achieve more compact representations.
