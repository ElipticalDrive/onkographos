# SpacetimeGaussians Training Pipeline


## Overview
The SpacetimeGaussians training pipeline is a specific optimization schedule and implementation strategy for training dynamic 3D Gaussian splats, extending the static [3D Gaussian Splatting](9128-3d-gaussian-splatting-implementation-details.md) method to handle temporal variations [S1, unofficial]. It solves the problem of real-time dynamic view synthesis by integrating motion parameters into the Gaussian attributes and applying a structured densification, pruning, and freezing schedule to stabilize training [S1, unofficial]. It is distinguished from its siblings by its explicit handling of time-dependent Gaussians, specific regularization terms for motion gradients, and a multi-channel rendering pipeline that supports both full and lite configurations [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset containing multi-view images and camera poses; a Gaussian model object (`gaussians`) initialized with positions, colors, opacities, rotations, scales, and motion parameters; optimization hyperparameters (`opt`) including learning rates, thresholds, and iteration counts; and a rendering pipeline option (`option`) selecting the rasterizer variant [S1, unofficial].
*   **Outputs:** A trained set of 3D Gaussians with optimized attributes (including motion) that can be rendered to novel views [S1, unofficial].

**Data Structures:**
*   **Background Tensor:** A tensor of shape `(numchannels,)` with dtype `torch.float32` on CUDA, initialized to zeros. `numchannels` defaults to 9 [S1, unofficial].
*   **Time Tensor (`gaussians.ts`):** A tensor of shape `(1, 1, H, W)` with dtype `torch.float32` on CUDA, initialized to ones if not provided, where H and W are derived from the first test camera [S1, unofficial].
*   **Gaussian Model (`gaussians`):** Contains attributes `_xyz`, `_opacity`, `_rotation`, `_scaling`, `_sh`, `_omega` (motion), and potentially an `rgbdecoder` [S1, unofficial].

**Rendering Pipeline Selection:**
The pipeline retrieves the rasterizer and settings based on the `option` parameter [S1, unofficial]:
*   `train_ours_full`: Uses `diff_gaussian_rasterization_ch9` [S1, unofficial].
*   `train_ours_lite`: Uses `diff_gaussian_rasterization_ch3` [S1, unofficial].
*   `train_ours_fullss`: Uses `diff_gaussian_rasterization_ch9` [S1, unofficial].
*   `train_ours_litess`: Uses `diff_gaussian_rasterization_ch3` [S1, unofficial] [S1, unofficial].

**Training Steps:**

1.  **Initialization:**
    *   Initialize the Gaussian model using `getmodel(dataset.model)` with SH degree and RGB function [S1, unofficial].
    *   Load scene data into a `Scene` object with `shuffle=False`, `multiview=multiview`, `duration=duration`, and `loader=loader` [S1, unofficial].
    *   Initialize the `background` tensor to zeros on CUDA [S1, unofficial].
    *   If `gaussians.ts` is None, initialize it as a tensor of ones with shape `(1, 1, H, W)` on CUDA [S1, unofficial].
    *   If `gaussians.rgbdecoder` is not None, move it to CUDA and set it to eval mode [S1, unofficial].
    *   Retrieve the rendering pipeline via `getrenderpip(option)` [S1, unofficial].

2.  **Iteration Loop:**
    For each iteration `i`:
    *   **Densification Mode Check:** If `densify == 1` (n3d mode):
        *   At iteration 8001, compute `omegamask` by calling `gaussians.zero_omegabymotion()` to determine which Gaussians keep motion parameters and which are frozen. Store this in `gaussians.omegamask` [S1, unofficial].
        *   For iterations > 8001, freeze weights for `_omega` using `omegamask` and freeze weights for `_rotation` using the logical NOT of `omegamask` via `freezweightsbymasknounsqueeze` [S1, unofficial].
    *   **Densification and Pruning:**
        *   If `iteration > opt.densify_from_iter` and `iteration % opt.densification_interval == 0` and `flag < opt.desicnt`:
            *   Perform densification by calling `gaussians.densify_pruneclone(opt.densify_grad_threshold, opt.opthr, scene.cameras_extent, size_threshold)` [S1, unofficial].
            *   `size_threshold` is 20 if `iteration > opt.opacity_reset_interval`, else None [S1, unofficial].
        *   If `flag >= opt.desicnt` and `iteration < 7000`:
            *   Prune points with opacity below `opt.opthr` [S1, unofficial].
        *   If `iteration >= opt.densify_until_iter`:
            *   Freeze `_omega` and `_rotation` weights as described for iterations > 8001 [S1, unofficial].
            *   If `iteration % 1000 == 500`, prune points where `gaussians._xyz[:,2] < 4.5` [S1, unofficial].
    *   **Opacity Reset:**
        *   Every 3000 iterations, reset opacity via `gaussians.reset_opacity()` [S1, unofficial].
    *   **Rendering:**
        *   Render the current view using the selected rasterizer, passing `scaling_modifier` (default 1.0), `basicfunction` (default `trbfunction`), and `GRsetting`/`GRzer` from the pipeline [S1, unofficial].
    *   **Loss Calculation:**
        *   Compute loss $L$ based on `opt.reg` [S1, unofficial]:
            *   If `reg=1`: $L = (1 - \text{opt.lambda\_dssim}) L_{L1} + \text{opt.lambda\_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \frac{\sum \mathbf{g}_{\text{motion}}}{N}$ [S1, unofficial].
            *   If `reg=9`: $L = (1 - \text{opt.lambda\_dssim}) L_{L1} + \text{opt.lambda\_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \sum_{r>0} \mathbf{g}_{\omega}^2$ [S1, unofficial].
            *   If `reg=10`: $L = (1 - \text{opt.lambda\_dssim}) L_{L1} + \text{opt.lambda\_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \sum_{r>0} \mathbf{g}_{\text{motion}}^2$ [S1, unofficial].
            *   If `reg=4`: $L = (1 - \text{opt.lambda\_dssim}) L_{L1} + \text{opt.lambda\_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \frac{\sum \mathbf{g}_{\text{scaling}}}{N}$ [S1, unofficial].
            *   If `reg=6`: $L = (1 - r) L_{L1} + r (1 - \text{SSIM}(I, I_{gt}))$ where $r = \text{clamp}(\text{mean}(I_{gt}) - 0.5 + \text{opt.lambda\_dssim}, 0, 1)$ [S1, unofficial].
            *   If `reg=7`: $L_{L1}$ is normalized by $2 \cdot \text{mean}(I_{gt})$ [S1, unofficial].
            *   If `reg=8`: $L = (1 - \text{opt.lambda\_dssim}) L_{L1} + 0.0002 \cdot \text{opt.lambda\_dssim} \frac{\sum (\bar{x} - x)^2}{N}$ [S1, unofficial].
        *   Where $L_{L1}$ is the L1 loss between rendered image $I$ and ground truth $I_{gt}$, SSIM is the Structural Similarity Index, $\mathbf{g}_{\text{motion}}$ and $\mathbf{g}_{\omega}$ are motion-related gradients, $\mathbf{g}_{\text{scaling}}$ are scaling gradients, $N$ is the number of Gaussians, and $\text{opt.regl}$ is the regularization weight [S1, unofficial].
    *   **Optimization Step:**
        *   Perform gradient descent step using the computed loss [S1, unofficial].

**Parameters:**
*   `numchannels`: Number of channels for background color and potentially RGB decoder output. Default: 9 [S1, unofficial].
*   `scaling_modifier`: Passed to the render function. Default: 1.0 [S1, unofficial].
*   `basicfunction`: Passed to the render function. Default: `trbfunction` [S1, unofficial].
*   `opt.densify_from_iter`, `opt.densify_until_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, `opt.opthr`: Control thresholds and intervals for densification, pruning, and opacity resets [S1, unofficial].

**Edge Cases and Pitfalls:**
*   If `gaussians.rgbdecoder` is not None, it must be moved to CUDA and set to eval mode before rendering [S1, unofficial].
*   Pruning logic differs based on the densification phase. Before `opt.desicnt` is reached, densification is performed. After, pruning is based on opacity threshold if iteration < 7000. After `opt.densify_until_iter`, pruning is based on Z-coordinate < 4.5 if iteration % 1000 == 500 [S1, unofficial].
*   The `size_threshold` for densification changes dynamically based on whether the iteration exceeds `opt.opacity_reset_interval` [S1, unofficial].

## Subtopics

### SpacetimeGaussians Densification & Pruning Schedule
A training iteration schedule that controls Gaussian densification, pruning, and parameter freezing based on iteration count, mode selection, and visibility metrics [S1, unofficial]. It supports multiple densification modes (`densify` parameter: 0, 1, 2, or 3) [S1, unofficial]. In mode 1, it prunes points where `gaussians._xyz[:,2] < 4.5` at iteration 1000 and resets opacity every 3000 iterations [S1, unofficial]. In mode 3, it updates `max_radii2D` and `add_densification_stats` every iteration, densifies/prunes clones at intervals, prunes low-opacity points if iteration < 7000, resets opacity every `opt.opacity_reset_interval`, and calls `removeminmax` at iteration 10000 [S1, unofficial]. The `size_threshold` passed to `densify_pruneclone` is set to 20 if `iteration > opt.opacity_reset_interval`, otherwise None [S1, unofficial].

Scaling: Not given in the sources.
Strengths and limitations: The pipeline provides a structured approach to training dynamic Gaussians, including specific regularization terms for motion and a detailed densification/pruning schedule. However, the complexity of the schedule and the need for specific rasterizer variants (`ch9` vs `ch3`) may increase implementation difficulty.
When to use it and when not: Use when implementing the specific SpacetimeGaussians method for dynamic view synthesis. Not suitable for static scene rendering without modifications.

## Background
Origin (who, when, which paper): The method originates from the paper "Spacetime Gaussian Feature Splatting for Real-Time Dynamic View Synthesis" by Zhan Li, Zhang Chen, Zhong Li, and Yi Xu, published in the Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR) in June 2024 [S1, unofficial]. It builds on the original 3D Gaussian Splatting method by Kerbl et al. [S1, unofficial].
History and development: The code is associated with OPPO US Research [S1, unofficial].
Where it is used: Real-time dynamic view synthesis [S1, unofficial].
