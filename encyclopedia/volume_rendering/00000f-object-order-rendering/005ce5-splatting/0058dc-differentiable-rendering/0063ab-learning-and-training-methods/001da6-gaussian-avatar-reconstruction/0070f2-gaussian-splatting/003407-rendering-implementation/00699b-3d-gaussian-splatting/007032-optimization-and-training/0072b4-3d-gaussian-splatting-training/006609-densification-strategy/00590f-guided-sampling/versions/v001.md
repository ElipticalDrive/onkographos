# Guided Sampling

Also called: Sparse point cloud densification with depth guidance

## Overview
Guided sampling is a densification strategy for 3D Gaussian Splatting that addresses geometric gaps in sparse initial point clouds by spawning new primitives along the camera ray depth axis [S1]. Unlike standard gradient-based splitting which relies on local image-space error, this method explicitly samples depth values to populate regions where geometry is missing or poorly initialized, such as distant backgrounds or transparent surfaces [S1]. It serves as a complementary initialization step to gradient-driven densification, ensuring that the Gaussian representation covers the full volumetric extent of the scene rather than just the visible surface boundaries.

## How it works
**Inputs and Outputs:**
*   **Input:** The current set of 3D Gaussians $\mathcal{G}$, the camera intrinsics and extrinsics for the current training view, and the maximum depth $d$ present in that view.
*   **Output:** A set of new Gaussian primitives added to $\mathcal{G}$, positioned along the sampled depth rays.

**Data Structures:**
The method operates on the existing Gaussian buffer. New Gaussians are allocated with standard 3DGS attributes: mean $\mu \in \mathbb{R}^3$, covariance $\Sigma \in \mathbb{R}^{3 \times 3}$ (parameterized by scale and rotation), opacity $\alpha$, and spherical harmonic coefficients $\mathbf{c}$. The new Gaussians are typically initialized with small scales and low opacity, allowing the optimizer to refine them during subsequent training steps.

**Parameters:**
*   $d$: The maximum depth value present in the current training view [S1].
*   $s$: A scaling factor for the lower bound of the sampling range. Typically set to $0.7$ for most scenes [S1].
*   Upper bound multiplier: Fixed at $7.5$ [S1].

**Steps:**
1.  **Determine Depth Range:** Calculate the sampling interval $[s \cdot d, 7.5 \cdot d]$ [S1].
2.  **Sample Depths:** Uniformly sample depth values $z$ from this interval [S1].
3.  **Add Noise:** Add small random noise to each sampled depth value $z$ to prevent aliasing and ensure robust coverage [S1].
4.  **Back-Project:** For each sampled depth $z$, back-project the pixel coordinates to 3D space using the camera projection matrix to obtain the mean position $\mu$ [S1].
5.  **Initialize Gaussians:** Create new Gaussian primitives at $\mu$. The covariance and other attributes are initialized based on the local neighborhood or default small values, as the primary goal is spatial coverage [S1].
6.  **Integration:** Add the new Gaussians to the global set $\mathcal{G}$ [S1].

**Pseudocode:**
```python
def guided_sampling(Gaussians, camera, max_depth_d, scale_factor=0.7, noise_std=1e-3):
    """
    Spawns new Gaussians along depth rays to fill sparse regions.
    
    Args:
        Gaussians: Current list of 3D Gaussian primitives.
        camera: Camera object with projection and inverse projection methods.
        max_depth_d: Maximum depth value in the current training view.
        scale_factor: Lower bound multiplier (typically 0.7).
        noise_std: Standard deviation for depth noise.
        
    Returns:
        Updated list of Gaussians with new primitives added.
    """
    new_gaussians = []
    
    # Define sampling range [s * d, 7.5 * d]
    lower_bound = scale_factor * max_depth_d
    upper_bound = 7.5 * max_depth_d
    
    # Number of samples to spawn. Not specified in sources; 
    # typically proportional to image resolution or a fixed hyperparameter.
    # [G] Assuming a fixed number of samples per view or per pixel density.
    num_samples = 1000 
    
    for _ in range(num_samples):
        # Uniformly sample depth with noise
        z = random.uniform(lower_bound, upper_bound)
        z += random.gauss(0, noise_std)
        
        # Sample a random pixel coordinate (u, v) in the image plane
        u = random.randint(0, camera.width - 1)
        v = random.randint(0, camera.height - 1)
        
        # Back-project pixel to 3D point at depth z
        # This assumes a pinhole camera model; implementation details depend on 
        # the specific camera projection matrix used.
        point_3d = camera.unproject(u, v, z)
        
        # Initialize a new Gaussian at point_3d
        # [G] Scale and opacity are initialized to small values to allow 
        # optimization to refine them.
        new_g = Gaussian(
            mean=point_3d,
            scale=small_default_scale,
            opacity=small_default_opacity,
            rotation=identity_rotation,
            sh_coefficients=zero_sh
        )
        new_gaussians.append(new_g)

```

**Edge Cases and Pitfalls:**
*   **Blurring in Sparse Regions:** Guided sampling cannot fully eliminate blurring in areas insufficiently covered by the initial sparse point cloud, such as far content outside windows or flames [S1]. This occurs because accurate depth is unavailable, forcing Gaussians to spawn across a wide depth range [S1].
*   **Pruning of Misplaced Gaussians:** Gaussians spawned near the correct location may be pruned during subsequent training if they do not contribute significantly to the loss, leading to instability [S1].
*   **Mitigation:** Leveraging depth priors from learning-based depth estimation methods can constrain the spawning range and improve accuracy [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of sampled points. The back-projection operation is $O(1)$ per sample.
*   **Memory Complexity:** Increases the number of Gaussians by the number of samples. This can significantly increase memory usage if the sampling density is high.
*   **Strengths:** Effectively fills geometric gaps in sparse initializations; does not rely on gradient convergence which may stall in textureless regions.
*   **Limitations:** Prone to generating "floaters" or misplaced Gaussians in regions with ambiguous depth; requires careful tuning of the depth range to avoid sampling into empty space or occluded regions.
*   **When to Use:** When the initial point cloud is sparse or when standard gradient-based densification fails to populate distant or transparent geometry.

## Background
Guided sampling was introduced in the context of Spacetime Gaussian Feature Splatting for Real-Time Dynamic View Synthesis [S1]. It was developed to address the limitations of static 3D Gaussian Splatting when applied to dynamic scenes or scenes with sparse initial reconstructions, where gradient-based methods alone were insufficient to capture the full volumetric structure.
