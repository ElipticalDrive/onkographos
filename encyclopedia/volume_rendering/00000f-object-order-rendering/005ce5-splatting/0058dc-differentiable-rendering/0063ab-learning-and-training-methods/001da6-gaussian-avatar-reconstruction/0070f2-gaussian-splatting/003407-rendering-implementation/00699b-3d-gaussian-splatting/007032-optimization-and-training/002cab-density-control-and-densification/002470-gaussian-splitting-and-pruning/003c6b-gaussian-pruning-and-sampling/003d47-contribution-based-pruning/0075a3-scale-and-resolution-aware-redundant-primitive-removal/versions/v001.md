# Scale- and Resolution-aware Redundant Primitive Removal

Also called: Redundancy-based Culling, Redundant Primitive Removal

## Overview
A method to identify and prune redundant 3D Gaussian primitives during optimization by estimating spatial redundancy based on the scale and resolution of observed details, combined with low-opacity filtering [S1]. Unlike simple aggressive low-opacity filtering, this method estimates spatial redundancy to avoid regions with exorbitantly high numbers of Gaussians that contribute little to the rendered image [S1]. It sets itself apart from siblings like [Opacity Pruning](14627-opacity-pruning.md) and [Size-based Pruning](17737-size-based-pruning.md) by explicitly modeling the relationship between camera resolution, primitive scale, and local density to determine necessity [S1].

## How it works
**Inputs:**
*   Set of 3D Gaussian primitives $\mathcal{G} = \{G_i\}$, where each $G_i$ has mean position $\mu_i$, scale (covariance matrix $\Sigma_i$ or axis lengths/orientation), opacity $\alpha_i$, and other attributes.
*   Camera views (intrinsics and extrinsics) used during training.
*   Hyperparameters: $k_{nn}$ (number of neighbors for k-NN search, default 30), $k_{std}$ (standard deviation multiplier for threshold, default 1), $p_{min}$ (pixel footprint side length).

**Outputs:**
*   A subset of primitives $\mathcal{G}' \subset \mathcal{G}$ after pruning.

**Data Structures:**
*   **Primitive List:** Array of primitives with fields: `mean` (vec3), `scale` (vec3 or rotation matrix), `opacity` (float), `redundancy_score` (int).
*   **Spatial Index:** A structure supporting k-NN queries (e.g., KD-Tree or Octree) built on primitive means $\mu_i$.
*   **Redundancy Mask:** A boolean or integer array tracking which primitives intersect which spherical regions.

**Steps:**

1.  **Compute Pixel Footprint Radius:**
    For each Gaussian $G_i$, determine the closest camera view $V_{closest}$ in which $G_i$ is visible (inside the camera frustum). Calculate the pixel footprint side length $p_{min}$ at the depth of $G_i$ in this view. The sphere radius $r$ for the redundancy test is:
    $$ r = p_{min} \frac{\sqrt{3}}{2} $$
    This radius corresponds to half the diagonal of a cube with face area $p_{min}^2$ [S1].

2.  **Candidate Selection (k-NN):**
    For each $G_i$, perform a k-NN search on the set of all primitives $\mathcal{G}$ using their means $\mu$. Retrieve the $k_{nn}$ nearest neighbors (default 30). This limits the number of expensive intersection tests [S1].

3.  **Sphere-Ellipsoid Intersection Test:**
    For each candidate $G_j$ from step 2, test if it intersects the sphere centered at $\mu_i$ with radius $r$.
    *   Represent $G_j$ as an ellipsoid with center $\mu_j$ and axes/orientation defined by its scale and rotation [S1].
    *   **Approximation:** To limit computational cost, scale the ellipsoid's axes by the sphere radius $r$ and perform an ellipsoid-point intersection test (dot product) between the scaled ellipsoid and the point $\mu_i$ [S1].
    *   Let $I_{i,j}$ be a boolean flag: true if $G_j$ intersects the sphere around $G_i$, false otherwise.

4.  **Compute Local Redundancy:**
    For each $G_i$, count the number of primitives $G_j$ (including itself or excluding, depending on implementation detail not fully specified, but typically counting overlaps) that pass the intersection test. Let this count be $C_i$. This yields the spatial redundancy value for the spherical region centered around $G_i$ [S1].

5.  **Propagate Redundancy Scores:**
    Each primitive $G_k$ is assigned a final redundancy score $R_k$.
    *   Initialize $R_k = \infty$.
    *   For each $G_i$, iterate through all $G_j$ such that $I_{i,j}$ is true.
    *   Update $R_j = \min(R_j, C_i)$ [S1].
    *   This ensures that if a Gaussian overlaps a region with low redundancy, it retains a low score, reflecting its potential contribution to detail [S1].

6.  **Thresholding and Filtering:**
    *   Calculate the mean $\mu_R$ and standard deviation $\sigma_R$ of the redundancy scores $R$ for all primitives.
    *   Define an adaptive threshold $T$:
        $$ T = \max(\mu_R + k_{std} \cdot \sigma_R, 3) $$
        Using $k_{std} = 1$, primitives with $R_k > T$ are considered for pruning [S1]. The floor of 3 ensures primitives contributing to regions with very low density are not removed [S1].

7.  **Selective Deletion:**
    *   Identify the set of primitives $\mathcal{P}_{filter} = \{G_k \mid R_k > T\}$.
    *   Do not delete all primitives in $\mathcal{P}_{filter}$ to avoid excessive culling due to score dependency [S1].
    *   Delete only 50% of $\mathcal{P}_{filter}$.
    *   Select primitives to delete based on low opacity $\alpha_k$. Primitives with the lowest opacity in $\mathcal{P}_{filter}$ are removed [S1].

**Pseudocode:**

```python
import math
import numpy as np

def scale_and_resolution_aware_pruning(primitives, cameras, k_nn=30, k_std=1.0):
    """
    primitives: List of Gaussian objects with attributes:
        - mean: np.array([x, y, z])
        - opacity: float
        - scale: np.array([sx, sy, sz]) or rotation matrix
        - covariance: np.array(3x3) (optional, if not derived from scale/rot)
    cameras: List of camera objects with methods:
        - world_to_pixel(world_pos): returns pixel coordinates
        - pixel_to_world_depth(pixel, depth): returns world position
        - frustum_contains(world_pos): returns bool
    """
    n = len(primitives)
    redundancy_scores = np.full(n, np.inf)
    
    # Build spatial index for k-NN
    # [G] Assuming a standard KDTree implementation exists for numpy arrays
    means = np.array([p.mean for p in primitives])
    tree = KDTree(means)
    
    # Step 1-4: Compute local redundancy counts
    local_counts = np.zeros(n, dtype=int)
    
    for i in range(n):
        G_i = primitives[i]
        
        # Find closest view
        closest_view = None
        p_min = np.inf
        
        for cam in cameras:
            if cam.frustum_contains(G_i.mean):
                # Project mean to pixel space
                pixel = cam.world_to_pixel(G_i.mean)
                # Get depth at pixel for this camera to find world extent
                # [G] Assuming cam.get_depth_at_pixel returns depth in world units
                depth = cam.get_depth_at_pixel(pixel)
                
                # Calculate pixel footprint size p_min
                # [G] Assuming camera intrinsics allow calculating pixel size in world units
                # at the given depth. p_min is the side length of the pixel footprint cube face.
                pixel_size_world = cam.pixel_size_at_depth(depth)
                if pixel_size_world < p_min:
                    p_min = pixel_size_world
                    closest_view = cam
        
        if p_min == np.inf:
            continue # Primitive not visible in any camera
            
        # Sphere radius
        r = p_min * math.sqrt(3) / 2
        
        # Step 2: k-NN search
        # Find k_nn nearest neighbors indices
        dists, indices = tree.query(G_i.mean, k=k_nn)
        
        count = 0
        # Step 3: Intersection tests
        for idx in indices:
            G_j = primitives[idx]
            
            # Approximate sphere-ellipsoid intersection
            # Scale ellipsoid axes by r and test point intersection
            # Ellipsoid equation: (x-c)^T S^-1 (x-c) <= 1
            # Here we approximate by scaling axes.
            # Let's assume G_j has a covariance matrix Sigma_j or scale/rot.
            # If scale is (sx, sy, sz), the ellipsoid is defined by axes lengths.
            # The test is: is G_i inside the ellipsoid G_j scaled by r?
            # Or is the distance from G_j mean to G_i mean <= r in the metric of G_j?
            
            # [G] Standard approximation: transform G_i into G_j's local space,
            # then check if distance <= r.
            # If G_j has rotation R_j and scale S_j (diag matrix),
            # Local pos = R_j^T * (G_i.mean - G_j.mean)
            # Scaled pos = Local pos / (S_j * r) ? 
            # The text says "scaling the ellipsoids' axes by the sphere radius".
            # This implies we check if G_i is within the ellipsoid defined by 
            # axes = original_axes * r.
            # Actually, the text says "scaling the ellipsoids' axes by the sphere radius 
            # and performing an ellipsoid-point intersection test".
            # This usually means: Check if point G_i is inside ellipsoid E_j' where 
            # E_j' has axes = E_j.axes * r.
            # Wait, if we scale axes by r, the ellipsoid gets bigger.
            # Let's assume the standard dot product test:
            # d = G_i.mean - G_j.mean
            # In local coords of G_j: d_local = R_j^T @ d
            # Check: sum( (d_local_k / (scale_k * r))^2 ) <= 1
            
            # Extract scale and rotation for G_j
            # [G] Assuming primitives have 'scale' (vec3) and 'rotation' (quat or mat3)
            scale_j = G_j.scale
            rot_j = G_j.rotation # 3x3 matrix
            
            diff = G_i.mean - G_j.mean
            diff_local = rot_j.T @ diff
            
            # Check if inside scaled ellipsoid
            # Axes are scaled by r. So effective radius in each axis is scale_j * r
            # Condition: (diff_local_x / (scale_j_x * r))^2 + ... <= 1
            denom = scale_j * r
            # Avoid division by zero
            denom = np.maximum(denom, 1e-6)
            
            squared_dist = np.sum((diff_local / denom) ** 2)
            
            if squared_dist <= 1.0:
                count += 1
        
        local_counts[i] = count
        
    # Step 5: Propagate scores
    # For each i, for each j that intersected i, update R_j = min(R_j, count_i)
    # We need to re-run or store the intersection mask. 
    # To avoid O(N^2), we can iterate again or store masks. 
    # Given N is large, storing N x N mask is bad. 
    # We can iterate j for each i and update.
    
    # Reset scores
    redundancy_scores = np.full(n, np.inf)
    
    for i in range(n):
        if local_counts[i] == 0:
            continue
            
        G_i = primitives[i]
        # Re-find neighbors and intersections to update scores
        # [G] Optimization: In practice, one might store the list of intersecting j's
        # during the first pass. Here we recompute for clarity.
        dists, indices = tree.query(G_i.mean, k=k_nn)
        
        for idx in indices:
            G_j = primitives[idx]
            scale_j = G_j.scale
            rot_j = G_j.rotation
            diff = G_i.mean - G_j.mean
            diff_local = rot_j.T @ diff
            denom = scale_j * r # r is same for this i
            denom = np.maximum(denom, 1e-6)
            squared_dist = np.sum((diff_local / denom) ** 2)
            
            if squared_dist <= 1.0:
                if local_counts[i] < redundancy_scores[idx]:
                    redundancy_scores[idx] = local_counts[i]

    # Step 6: Thresholding
    mean_score = np.mean(redundancy_scores)
    std_score = np.std(redundancy_scores)
    T = max(mean_score + k_std * std_score, 3)
    
    # Identify filtered primitives
    filtered_indices = np.where(redundancy_scores > T)[0]
    
    if len(filtered_indices) == 0:
        return primitives
        
    # Step 7: Selective Deletion
    # Get opacities of filtered primitives
    filtered_opacities = np.array([primitives[i].opacity for i in filtered_indices])
    
    # Sort by opacity ascending
    sorted_order = np.argsort(filtered_opacities)
    
    # Delete 50%
    num_to_delete = len(filtered_indices) // 2
    indices_to_delete = filtered_indices[sorted_order[:num_to_delete]]
    
    # Remove from primitives list
    # [G] Assuming primitives is a list, we mark them or remove them
    # Return the remaining primitives
    keep_mask = np.ones(n, dtype=bool)
    keep_mask[indices_to_delete] = False
    
    return [p for i, p in enumerate(primitives) if keep_mask[i]]
```

## Operating characteristics
*   **Time Complexity:** Naïve computation is $O(N^2)$ due to pairwise intersection tests, which is prohibitively expensive for millions of Gaussians [S1]. The use of k-NN search reduces the candidate set per primitive to $k_{nn}$ (default 30), making it approximately $O(N \cdot k_{nn})$ for the intersection phase, plus the cost of building the spatial index [S1].
*   **Memory Complexity:** Requires storing the spatial index (e.g., KD-Tree) and the redundancy scores array [S1].
*   **Performance:** The method is applied periodically during training (e.g., every 1000 iterations) to reduce memory footprint while maintaining quality [S1].
*   **Strengths:** Effectively reduces memory usage by targeting regions with excessive Gaussian density that do not contribute to visual detail [S1]. It is more robust than simple opacity culling because it considers spatial context [S1].
*   **Limitations:** Computationally expensive if not optimized with k-NN and approximations [S1]. Deleting all filtered primitives can lead to excessive culling; thus, only 50% are removed, which may leave some redundancy [S1].

## Background
Originated in the paper "Reducing the Memory Footprint of 3D Gaussian Splatting" [S1]. The method addresses the issue of adaptive densification in 3D Gaussian Splatting leading to regions with exorbitantly high numbers of Gaussians [S1]. It was developed to provide a memory reduction strategy that preserves visual quality by identifying redundant primitives based on spatial redundancy and resolution awareness [S1].
