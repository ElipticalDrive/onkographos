# Surface-Aware Splat Graph Construction

Also called: Manifold-Aware Gaussian Graph Construction, Surface-Aligned Gaussian Connectivity

## Overview
Surface-Aware Splat Graph Construction establishes connectivity between 3D Gaussian primitives exclusively along the underlying surface manifold, filtering out spurious neighbors that are close in Euclidean space but distant along the surface [S1]. Unlike standard spatial proximity metrics (e.g., Euclidean or Mahalanobis distance) which fail in challenging geometric conditions, this method defines edges based on the geometric intersection of Gaussian kernels, ensuring that the resulting graph respects the topology of the reconstructed surface [S1].

## How it works
**Inputs:** A set of $N$ Gaussian kernels $\{G_i\}_{i=1}^N$ reconstructed from 2D images using a surface-aligned Gaussian Splatting method (specifically SpikingGS [S1]).
**Outputs:** A graph where edges connect Gaussian kernels $G_i$ and $G_j$ if their occupancy regions intersect within a tolerance $\epsilon$.

**Data Structures:**
Each Gaussian kernel $G_i$ is defined by:
- Position: $\mathbf{p}_i \in \mathbb{R}^3$
- Covariance: $\Sigma_i \in \mathbb{R}^{3 \times 3}$, factorized as $\Sigma_i = R_i S_i S_i^\top R_i^\top$
- Opacity: $\alpha_i \in \mathbb{R}$
- Rotation matrix: $R_i = [\mathbf{r}_{i,1}, \mathbf{r}_{i,2}, \mathbf{r}_{i,3}]$, where $\mathbf{r}_{i,3}$ is the surface normal direction.
- Scale matrix: $S_i = \text{diag}(\sigma_{i,1}, \sigma_{i,2}, 0)$. The zero eigenvalue indicates the rank-2 nature of the surface-aligned kernel.

**Parameters:**
- $c$: Minimum contribution threshold for rendered intensity. Typical value: $1/255$ [S1].
- $\bar{V}_{ip}$: Activation cut-off threshold from the spiking neuron in SpikingGS. It is a learnable parameter that suppresses low-opacity parts [S1].
- $\epsilon$: Tolerance for normal-wise offset to account for minor gaps between adjacent Gaussian kernels arising from joint optimization [S1].

**Steps:**

1.  **Define Occupancy Region:** For each kernel $G_i$, define the occupancy region $\Omega_i$ as the set of points $\mathbf{x} \in \mathbb{R}^3$ where the kernel is active. Activity is determined by two constraints:
    - The Gaussian value $G_i(\mathbf{x})$ must exceed the spiking threshold $\bar{V}_{ip}$.
    - The rendered intensity $\alpha_i G_i(\mathbf{x})$ must exceed the minimum contribution threshold $c$.
    
    The Gaussian value is defined as:
    $$
    G_i(\mathbf{x}) = \begin{cases} 
    0 & \text{if } G_i(\mathbf{x}) < \bar{V}_{ip} \\
    e^{-\frac{1}{2}(\mathbf{x}-\mathbf{p}_i)^\top \Sigma_i^{-1} (\mathbf{x}-\mathbf{p}_i)} & \text{otherwise}
    \end{cases}
    $$
    
    Combining these, the occupancy region $\Omega_i$ is:
    $$
    \Omega_i = \left\{ \mathbf{x} \in \mathbb{R}^3 \mid G_i(\mathbf{x}) > \max \left( \bar{V}_{ip}, \frac{c}{\alpha_i} \right) \right\}
    $$
    [S1]

2.  **Parameterize Occupancy Region:** Since $\Sigma_i$ is rank-2, $\Omega_i$ forms an ellipse in 3D space. Using the scale matrix $S_i = \text{diag}(\sigma_{i,1}, \sigma_{i,2}, 0)$ and rotation matrix $R_i = [\mathbf{r}_{i,1}, \mathbf{r}_{i,2}, \mathbf{r}_{i,3}]$, the region is parameterized as:
    $$
    \Omega_i = \left\{ \mathbf{p}_i + \lambda_i \rho (\sigma_{i,1} \cos \theta \, \mathbf{r}_{i,1} + \sigma_{i,2} \sin \theta \, \mathbf{r}_{i,2}) \;\middle|\; \rho \in [0, 1), \theta \in (0, 2\pi] \right\}
    $$
    where the scaling factor $\lambda_i$ is:
    $$
    \lambda_i = \sqrt{-2 \max \left( \ln |\bar{V}_{ip}|, \ln \left( \frac{c}{\alpha_i} \right) \right)}
    $$
    [S1]

3.  **Compute Normal-Wise Offset:** To determine connectivity between two kernels $G_i$ and $G_j$, compute the normal-wise offset $\delta_{ij}$ from $G_i$ to $G_j$. This offset measures the distance along the normal direction $\mathbf{r}_{i,3}$ of $G_i$ required to reach the occupancy region of $G_j$:
    $$
    \delta_{ij} := \inf \{ |t| \mid \exists \mathbf{x} \in \Omega_i : \mathbf{x} + t \mathbf{r}_{i,3} \in \Omega_j \}
    $$
    If no such point exists, $\delta_{ij} = +\infty$ [S1].

4.  **Establish Edges:** Two Gaussians $G_i$ and $G_j$ are considered intersecting (and thus connected in the graph) if $\delta_{ij} < \epsilon$. A zero offset $\delta_{ij} = 0$ denotes a perfect intersection [S1].

**Pseudocode:**

```python
import numpy as np

def compute_lambda(alpha, c, v_bar_ip):
    """
    Compute the scaling factor lambda_i for a Gaussian kernel.
    
    Args:
        alpha: Opacity of the kernel.
        c: Minimum contribution threshold (e.g., 1/255).
        v_bar_ip: Activation cut-off threshold from spiking neuron.
        
    Returns:
        lambda_i: Scaling factor.
    """
    # Calculate the max threshold for the log argument
    # Note: The source uses max(ln|V_bar_ip|, ln(c/alpha))
    # We assume V_bar_ip is positive in the log context or take absolute value as per source notation
    term1 = np.log(np.abs(v_bar_ip))
    term2 = np.log(c / alpha)
    max_val = max(term1, term2)
    
    # lambda_i = sqrt(-2 * max_val)
    # If max_val is positive, -2*max_val is negative, leading to NaN.
    # However, G_i(x) = exp(-...), so G_i(x) > threshold implies -0.5 * dist^2 > ln(threshold)
    # dist^2 < -2 * ln(threshold). For this to be valid, ln(threshold) must be negative.
    # Since thresholds are < 1, ln is negative. -2 * negative is positive.
    # The source formula: lambda_i = sqrt(-2 max(ln|V_bar_ip|, ln(c/alpha)))
    # This implies the arguments to ln are < 1.
    
    val = -2 * max_val
    if val < 0:
        return 0.0 # Should not happen if thresholds < 1
    return np.sqrt(val)

def is_intersecting(G_i, G_j, epsilon):
    """
    Determine if two Gaussian kernels intersect based on normal-wise offset.
    
    Args:
        G_i: Dictionary with keys 'p', 'R', 'S', 'alpha', 'v_bar_ip'
        G_j: Dictionary with keys 'p', 'R', 'S', 'alpha', 'v_bar_ip'
        epsilon: Tolerance for offset.
        
    Returns:
        bool: True if intersecting.
    """
    # Note: Exact geometric intersection of two elliptical cylinders in 3D is complex.
    # The source defines delta_ij as an infimum over a line.
    # For implementation, one might approximate or use numerical optimization.
    # Here we outline the logic as defined by the source formula.
    
    # 1. Define occupancy region Omega_i parameterization
    # Omega_i = p_i + lambda_i * rho * (s1*cos(theta)*r1 + s2*sin(theta)*r2)
    # This is a filled ellipse in the plane defined by r1, r2 at p_i.
    
    # 2. Compute normal-wise offset delta_ij
    # delta_ij = inf |t| such that exists x in Omega_i where x + t * r_i3 is in Omega_j
    
    # This requires solving for the minimum t such that the line L(t) = x + t * r_i3
    # intersects the ellipse Omega_j for some x in Omega_i.
    # This is equivalent to finding the distance between the two elliptical disks
    # projected along the normal r_i3.
    
    # Simplified geometric interpretation:
    # Project both ellipses onto the plane perpendicular to r_i3? No, the offset is along r_i3.
    # We are looking for the gap between the two surfaces along the normal of G_i.
    
    # Since exact analytical solution for arbitrary orientation is not provided in source,
    # we note that this step requires numerical optimization or geometric intersection routines.
    # [G] In practice, this is often solved by checking if the closest point on the boundary
    # of Omega_i to Omega_j, projected along r_i3, falls within Omega_j.
    
    # Placeholder for the complex geometric calculation defined by the infimum formula.
    # delta_ij = calculate_normal_offset(Omega_i, Omega_j, G_i['R'][:, 2])
    
    # For the purpose of this article, we assume a function `calculate_normal_offset` exists
    # that implements the infimum formula from the source.
    
    delta_ij = calculate_normal_offset(G_i, G_j)
    
    return delta_ij < epsilon

def calculate_normal_offset(G_i, G_j):
    """
    Calculates the normal-wise offset delta_ij from G_i to G_j.
    delta_ij := inf |t| | exists x in Omega_i : x + t * r_i3 in Omega_j
    """
    # Implementation detail:
    # 1. Get parameters for G_i
    p_i = G_i['p']
    r_i3 = G_i['R'][:, 2] # Normal vector
    s1_i, s2_i = G_i['S'][0, 0], G_i['S'][1, 1]
    r_i1 = G_i['R'][:, 0]
    r_i2 = G_i['R'][:, 1]
    alpha_i = G_i['alpha']
    v_bar_ip_i = G_i['v_bar_ip']
    c = 1/255
    
    lambda_i = compute_lambda(alpha_i, c, v_bar_ip_i)
    
    # 2. Get parameters for G_j
    p_j = G_j['p']
    r_j3 = G_j['R'][:, 2]
    s1_j, s2_j = G_j['S'][0, 0], G_j['S'][1, 1]
    r_j1 = G_j['R'][:, 0]
    r_j2 = G_j['R'][:, 1]
    alpha_j = G_j['alpha']
    v_bar_ip_j = G_j['v_bar_ip']
    
    lambda_j = compute_lambda(alpha_j, c, v_bar_ip_j)
    
    # 3. Solve for t
    # We want to find x in Omega_i such that x + t * r_i3 is in Omega_j.
    # x = p_i + lambda_i * rho * (s1_i * cos(theta) * r_i1 + s2_i * sin(theta) * r_i2)
    # Let y = x + t * r_i3. y must be in Omega_j.
    # y = p_j + lambda_j * rho' * (s1_j * cos(theta') * r_j1 + s2_j * sin(theta') * r_j2)
    
    # This is a system of equations.
    # Since the source does not provide a closed-form solution for delta_ij,
    # we return infinity as a placeholder for the complex geometric intersection check.
    # [G] In a real implementation, one would use a numerical solver (e.g., scipy.optimize)
    # to minimize |t| subject to the constraint that the point lies in both regions.
    
    return np.inf

def build_surface_aware_graph(Gaussians, epsilon):
    """
    Builds the surface-aware splat graph.
    
    Args:
        Gaussians: List of Gaussian kernel dictionaries.
        epsilon: Tolerance for intersection.
        
    Returns:
        edges: List of tuples (i, j) representing edges.
    """
    edges = []
    N = len(Gaussians)
    
    for i in range(N):
        for j in range(i + 1, N):
            if is_intersecting(Gaussians[i], Gaussians[j], epsilon):
                edges.append((i, j))
                
    return edges
```

## Operating characteristics
- **Time Complexity:** The graph construction requires checking intersections for all pairs of Gaussians, leading to $O(N^2)$ complexity in the worst case. However, spatial indexing structures (e.g., BVH) can be used to prune non-intersecting pairs, though the source does not specify the exact acceleration structure used for the intersection test [S1].
- **Memory Complexity:** The graph stores edges between intersecting Gaussians. The memory usage depends on the density of the surface and the connectivity threshold $\epsilon$ [S1].
- **Strengths:** It accurately captures surface topology by ignoring Euclidean proximity, which is crucial for deformation and editing tasks where preserving the manifold structure is essential [S1].
- **Limitations:** It relies on the quality of the initial surface-aligned reconstruction (e.g., SpikingGS). If the initial Gaussians are not well-aligned to the surface, the graph connectivity may be incorrect [S1]. The computation of the normal-wise offset is geometrically complex and may be computationally expensive [S1].

## Background
The method was introduced in "Proxy-Free Gaussian Splats Deformation with Splat-Based Surface Estimation" [S1]. It builds upon the SpikingGS method [19] for surface-aligned Gaussian Splatting. The core intuition is that Gaussian kernels proximate along the surface manifold will intersect, allowing for the construction of a graph that respects the surface topology without requiring explicit proxy meshes [S1].
