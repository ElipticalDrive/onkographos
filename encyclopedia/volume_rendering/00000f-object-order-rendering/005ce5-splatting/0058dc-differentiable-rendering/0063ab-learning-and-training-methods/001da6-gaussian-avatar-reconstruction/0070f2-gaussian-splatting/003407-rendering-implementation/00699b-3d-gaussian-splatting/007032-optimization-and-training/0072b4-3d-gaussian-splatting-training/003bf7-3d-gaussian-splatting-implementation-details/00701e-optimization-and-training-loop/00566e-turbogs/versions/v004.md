# TurboGS

Also called: Error-guided training framework for 3DGS

## Overview
TurboGS is an error-guided training framework for 3D Gaussian Splatting (3DGS) that accelerates optimization by dynamically focusing computation on perceptually informative pixels, addressing redundant computation in well-reconstructed regions and loss of fine details [S1, unofficial]. It sets itself apart from standard 3DGS by replacing dense per-tile rasterization with a sparse pixel sampling strategy guided by persistent error and age maps, while introducing a tile-level Normalized Cross-Correlation (NCC) loss and a moment-damped Levenberg-Marquardt solver to stabilize convergence under sparse supervision [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ground-truth images $\{I_v\}$, camera poses $\{C_v\}$, initial 3D Gaussians $\mathcal{G}_0$ derived from Structure-from-Motion (SfM), total training iterations $T$, view budget range $[K_{min}, K_{max}]$, and hyperparameters $\Theta$ (including tile size $S$, sampling rates $r_{hard}, r_{stable}$, EMA decay $\beta$, geometry-aware weights $\lambda_d, \lambda_\theta$, and effective learning rate scaling $\lambda_{base}$) [S1, unofficial].
*   **Outputs:** Optimized set of 3D Gaussians $\mathcal{G}$ [S1, unofficial].

**Data Structures:**
*   **Error Map ($E_v$):** Per-pixel reconstruction error history for each view $v$. Stored in contiguous GPU memory with half precision (float16) [S1, unofficial].
*   **Age Map ($A_v$):** Tracks how long it has been since a pixel was last sampled. Stored in contiguous GPU memory with uint16 precision [S1, unofficial].
*   **View Stack:** A shuffled list of candidate view indices used for geometry-aware sampling [S1, unofficial].

**Parameters:**
*   Tile size $S$: Typically $16 \times 16$ pixels [S1, unofficial].
*   Pixel sampling rate $r_t$: Dynamic rate per iteration [S1, unofficial].
*   Number of pixels per tile $N_{pix} = \max(1, \lfloor r_t \cdot S^2 \rfloor)$ [S1, unofficial].
*   Hard pixel fraction $r_{hard}$ and stable pixel fraction $r_{stable}$ [S1, unofficial].
*   EMA decay $\beta$ [S1, unofficial].
*   Geometry-aware weights $\lambda_d$ (position) and $\lambda_\theta$ (direction) [S1, unofficial].
*   Effective learning rate scaling $\lambda_{base}$ [S1, unofficial].

**Numbered Steps:**

1.  **Initialization:** Initialize error maps $E_v$ by densely evaluating the initial reconstruction error $e_{0,v}(p) = \|\hat{I}_{0,v}(p) - I_v(p)\|_1$ for all pixels rendered by $\mathcal{G}_0$. Initialize age maps $A_v(p) = 0$ [S1, unofficial].

2.  **Iteration Loop ($t = 0$ to $T-1$):**
    a.  **Progress Coefficient:** Compute $\rho_t = \min(1, t/\tau_{until})$ [S1, unofficial].
    b.  **Sampling Schedule:** Query the sampling schedule to determine the view budget $K_t$ and pixel sampling rate $r_t$ based on $K_{max}, K_{min}, E_{init}, \Theta, t$ [S1, unofficial].
    c.  **View Selection (GVS):**
        i.  Select an anchor view $v^*$ based on the average error: $v^* = \arg\max_v \bar{E}_v$, where $\bar{E}_v = \frac{1}{|\Omega|} \sum_{p \in \Omega} E_v(p)$ [S1, unofficial].
        ii. Sample $K-1$ remaining views from a candidate stack without replacement using the geometry-aware distribution:
        $$ \pi(u | v^*) \propto \exp\left(-\lambda_d \|c_u - c_{v^*}\|^2 - \lambda_\theta (1 - \langle d_u, d_{v^*} \rangle)\right) $$
        where $c_u, d_u$ are the camera center and viewing direction of view $u$ [S1, unofficial].
        iii. Maintain a shuffled view stack; refill and reshuffle when fewer than $K$ views remain [S1, unofficial].
    d.  **Tile-Wise Sparse Pixel Sampling (EPS):**
        i.  Partition the image into tiles of size $S \times S$. For each tile $\tau$ in each selected view $v \in V_t$:
        ii. Compute the error-based sampling distribution: $\pi_E(p | \tau, v) = \frac{E_v(p)}{\sum_{q \in \tau} E_v(q) + \epsilon}$ [S1, unofficial].
        iii. Select $N_{hard} = \lceil r_{hard} \cdot N_{pix} \rceil$ pixels with the highest error in tile $\tau$ as the hard set $H_{t,v}(\tau)$ [S1, unofficial].
        iv. Select $N_{stable} = \lfloor r_{stable} \cdot N_{pix} \rfloor$ pixels with the largest ages from the remaining pixels $\tau \setminus H_{t,v}(\tau)$ using $TopK(A_v(p), N_{stable})$ as the stable set $S_{t,v}(\tau)$ [S1, unofficial].
        v.  The final sampled pixels in tile $\tau$ are $P_{t,v}(\tau) = H_{t,v}(\tau) \cup S_{t,v}(\tau)$. The full set is $P_{t,v} = \bigcup_\tau P_{t,v}(\tau)$ [S1, unofficial].
    e.  **Sparse Forward Rasterization (FWD):**
        i.  Output sampled pixels in tile order. Compute tile-wise pixel offsets via prefix-sum to allow each CUDA block (tile) to access sparse pixels efficiently [S1, unofficial].
        ii. Render colors $\hat{I}_{t,v}(p)$ and depth $d$ for $p \in P_{t,v}$ [S1, unofficial].
    f.  **Sparse Loss & Gradients (L):**
        i.  Compute per-pixel L1 loss: $e_{t,v}(p) = \|\hat{I}_{t,v}(p) - I_v(p)\|_1$ [S1, unofficial].
        ii. Compute tile-level Structure-Aware Loss (S-NCC):
        $$ \mathcal{L}_{\tau}^{S-NCC} = 1 - NCC(\hat{I}_{t,v}(P_{t,v}(\tau)), I_v(P_{t,v}(\tau))) $$
        where $NCC$ is the Normalized Cross-Correlation computed over the sampled pixels in tile $\tau$ [S1, unofficial].
        iii. Compute gradient-balanced weighting for the NCC term within each tile:
        $$ \lambda_{\tau}^{ncc} = \text{clip}\left( \frac{\bar{g}_{\tau}^{\ell_1}}{\bar{g}_{\tau}^{S-NCC} + \epsilon}, 0, 1 \right) $$
        where $\bar{g}_{\tau}^{k} = \mathbb{E}_{p \in P_{t,v}(\tau)} \|\nabla_{\hat{I}}(p) \mathcal{L}_{\tau}^{k}(p)\|_1$ for $k \in \{\ell_1, S-NCC\}$ [S1, unofficial].
        iv. Calculate total pixel loss $\mathcal{L}_{pix}$ and gradients $\nabla c, \nabla d$ [S1, unofficial].
    g.  **EMA Error-Map Update (E):**
        i.  Update error map only at sampled locations:
        $$ E_v(p) \leftarrow (1 - \beta) E_v(p) + \beta e_{t,v}(p), \quad \forall p \in P_{t,v} $$
        ii. Increment age map globally: $A_v(p) \leftarrow A_v(p) + 1$. Reset age of sampled pixels: $A_v(p) \leftarrow 0$ for $p \in P_{t,v}$ [S1, unofficial].
    h.  **Gaussian Backward Pass (BWD):**
        i.  Retrieve sparse pixels within each tile through tile-pixel indexing.
        ii. Propagate gradients via warp shuffle only over sampled pixels to avoid dense rasterization replay [S1, unofficial].
        iii. Compute Gaussian gradients $\nabla \mathcal{G}$ and screen radii $r$ [S1, unofficial].
    i.  **Moment-Damped LM Solver:**
        i.  For each Gaussian $g$, form the local equation:
        $$ (J_g^T J_g + \text{diag}(\sqrt{v_g} + \epsilon)) \Delta g = -m_g $$
        where $m_g, v_g$ are Adam first and second moments, and $J_g$ is the local Jacobian estimated from accumulated gradients [S1, unofficial].
        ii. Solve for update deltas $\Delta g$ [S1, unofficial].
    j.  **Apply Gaussian Update:** $\mathcal{G} \leftarrow \mathcal{G} + \Delta \mathcal{G}$ [S1, unofficial].
    k.  **Error-Driven Density Control (EDC):**
        i.  Back-project pixel properties to Gaussians to get per-Gaussian error $e_G$, distance $D_G$, and opacity $\alpha_G$.
        ii. Normalize statistics by visibility $W_i = \sum_{v,p} w_{t,i}(p)$:
        $$ e_i(t) = \frac{E_i(t)}{W_i(t) + \epsilon}, \quad d_i(t) = \frac{D_i(t)}{W_i(t) + \epsilon} $$
        where $E_i(t)$ accumulates weighted errors and $D_i(t)$ accumulates weighted distances (conic Mahalanobis distance) [S1, unofficial].
        iii. Compute difficulty score: $s_i = e_i(t) + \lambda_{eff} d_i(t)$, where $\lambda_{eff} = \lambda_{base}(1 - \rho_t)$ [S1, unofficial].
        iv. Perform densification and pruning based on screen radii, back-projected properties, and difficulty scores [S1, unofficial].

**Pseudocode:**

```python
def turbogs_training(I, C, G_init, T, K_min, K_max, Theta):
    # Initialization
    E = initialize_error_maps(G_init, C, I) # Dense evaluation
    A = zeros_like(E, dtype=uint16)
    view_stack = shuffle(indices(C))
    
    for t in range(T):
        rho = min(1.0, t / tau_until)
        
        # 1. Sampling Parameters
        K_t, r_t = query_sampling_schedule(K_max, K_min, E, Theta, t)
        
        # 2. View Selection
        # Anchor view selection
        avg_errors = mean(E, axis=pixel_axis)
        v_star = argmax(avg_errors)
        
        # Neighbor view sampling
        V_t = [v_star]
        candidates = [v for v in C if v != v_star]
        # Sample K_t - 1 views from candidates using geometry-aware distribution
        # pi(u|v*) ~ exp(-lambda_d * ||c_u - c_v*||^2 - lambda_theta * (1 - <d_u, d_v*>))
        # Implementation detail: Pop from view_stack, refill if empty
        V_t.extend(sample_views_without_replacement(candidates, K_t - 1, v_star, Theta))
        
        # 3. Pixel Sampling
        P_t = {}
        for v in V_t:
            P_t[v] = []
            tiles = partition_image_into_tiles(S)
            for tau in tiles:
                # Hard pixels
                N_hard = ceil(Theta.r_hard * max(1, floor(Theta.r_t * S^2)))
                H = topk_error(E[v], tau, N_hard)
                
                # Stable pixels
                N_stable = floor(Theta.r_stable * max(1, floor(Theta.r_t * S^2)))
                remaining = tau \ H
                S_set = topk_age(A[v], remaining, N_stable)
                
                P_t[v].extend(H.union(S_set))
        
        # 4. Sparse Forward Rendering
        # Output sampled pixels in tile order
        # Compute tile-wise pixel offsets via prefix-sum
        I_hat, depth = sparse_rasterize_forward(G, V_t, P_t, Theta)
        
        # 5. Sparse Loss & Gradients
        L_pix = 0
        grad_c = {}
        grad_d = {}
        
        for v in V_t:
            for tau in P_t[v]: # Iterate over tiles containing sampled pixels
                # Per-pixel L1
                e_p = l1_loss(I_hat[v][tau], I[v][tau])
                
                # Tile-level S-NCC
                L_tau_S_NCC = 1 - ncc(I_hat[v][tau], I[v][tau])
                
                # Gradient-balanced weighting
                g_l1 = mean_norm(grad(I_hat[v][tau], L1))
                g_sncc = mean_norm(grad(I_hat[v][tau], L_tau_S_NCC))
                lambda_ncc = clip(g_l1 / (g_sncc + epsilon), 0, 1)
                
                # Total loss for tile
                L_tile = L1_loss + lambda_ncc * L_tau_S_NCC
                L_pix += L_tile
                
                grad_c[v][tau] = grad(I_hat[v][tau], L1)
                grad_d[v][tau] = grad(I_hat[v][tau], L_tau_S_NCC)
        
        # 6. EMA Error-Map Update
        for v in V_t:
            for p in P_t[v]:
                E[v][p] = (1 - Theta.beta) * E[v][p] + Theta.beta * l1_loss(I_hat[v][p], I[v][p])
        
        # Age update
        A += 1
        for v in V_t:
            for p in P_t[v]:
                A[v][p] = 0
                
        # 7. Gaussian Backward Pass
        # Retrieve sparse pixels, propagate gradients via warp shuffle
        grad_G = sparse_rasterize_backward(grad_c, grad_d, G, P_t, Theta)
        grad_screen, radii = get_gaussian_screen_properties(grad_G, G)
        
        # 8. Moment-Damped LM Solver
        delta_G = {}
        for g in G:
            m_g = adam_m1[g]
            v_g = adam_m2[g]
            J_g = local_jacobian(g, grad_G)
            # Solve (J_g^T J_g + diag(sqrt(v_g) + epsilon)) * delta_g = -m_g
            delta_G[g] = solve_linear_system(J_g.T @ J_g + diag(sqrt(v_g) + epsilon), -m_g)
            
        # 9. Apply Update
        for g in G:
            G[g] += delta_G[g]
            update_adam_moments(g, grad_G[g])
            
        # 10. Error-Driven Density Control
        # Back-project properties
        e_G, D_G, alpha_G = back_project_pixel_properties(G, V_t, P_t, I_hat, I)
        
        # Normalize
        for g in G:
            W_g = sum_weights(g, V_t, P_t)
            e_i = e_G[g] / (W_g + epsilon)
            d_i = D_G[g] / (W_g + epsilon)
            lambda_eff = Theta.lambda_base * (1 - rho)
            s_i = e_i + lambda_eff * d_i
            
        densify_and_prune(G, grad_screen, radii, e_G, D_G, alpha_G, t, Theta)
        
    return G
```

**Edge Cases and Pitfalls:**
*   **Sparse Supervision Artifacts:** Sparse supervision may introduce subtle rippling artifacts in low-frequency regions with weak texture variations (e.g., walls or ceilings) [S1, unofficial].
*   **Over-focusing:** The age map is crucial to avoid over-focusing on a small set of persistently high-error locations [S1, unofficial].
*   **Precision:** Error maps use float16 and age maps use uint16 to balance precision and memory bandwidth [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Significantly reduced compared to dense 3DGS due to sparse pixel sampling. TurboGS completes training within 80 seconds on the Mip-NeRF 360 Bicycle scene, compared to 891 seconds for vanilla 3DGS [S1, unofficial].
*   **Memory Complexity:** Reduced memory usage for rasterization buffers due to sparse pixel sets. Error and age maps are stored in compact formats (float16, uint16) [S1, unofficial].
*   **Performance:** Achieves competitive rendering quality (e.g., 27.57 PSNR on Mip-NeRF 360 Bicycle) with up to ~10x training speedup over vanilla 3DGS [S1, unofficial].
*   **Strengths:** Accelerates optimization by concentrating computation on perceptually informative pixels; preserves fine details via tile-level NCC loss; stabilizes training with moment-damped LM solver [S1, unofficial].
*   **Limitations:** May introduce rippling artifacts in low-frequency regions; requires careful tuning of sampling rates and loss weights [S1, unofficial].

## Background
TurboGS was introduced as an error-guided training framework for 3D Gaussian Splatting to address the high computational cost of dense rasterization in standard 3DGS training [S1, unofficial]. It builds on the observation that as training progresses, only a small subset of pixels remains difficult to reconstruct [S1, unofficial]. The method integrates tile-wise sparse pixel sampling, geometry-aware view selection, structure-aware sparse supervision, error-driven density control, and a hybrid optimizer [S1, unofficial].
