# Weight Freezing by Mask

Also called: freezweightsbymask, freezweightsbymasknounsqueeze

## Overview
Weight Freezing by Mask is a gradient modification technique used during the optimization of 3D Gaussian Splatting models to selectively disable updates for specific attributes. It solves the problem of unwanted parameter drift by zeroing out gradients for designated attributes (e.g., rotation, scale) via element-wise multiplication with a binary mask. It differs from [AbsGS](6127-absgs.md) by applying a static or dynamic mask to the gradient tensor rather than modifying the gradient magnitude based on absolute values, and from [Specular-Aware Gradient Gating](13432-specular-aware-gradient-gating.md) by operating on attribute-level tensors rather than pixel-level contributions.

## How it works
**Inputs and Outputs:**
*   **Input:** A list of attribute names (`screenlist`) to freeze, and their corresponding gradient tensors $\mathbf{G}$ from the backward pass.
*   **Output:** Modified gradient tensors $\mathbf{G}'$ where selected elements are zeroed.

**Data Structures:**
*   `screenlist`: A list of strings (e.g., `['_omega']`, `['_rotation']`) identifying the attributes.
*   `mask`: A binary tensor of the same shape as the gradient tensor $\mathbf{G}$, containing 1.0 for active parameters and 0.0 for frozen parameters.

**Steps:**
1.  Iterate through each attribute name in `screenlist`.
2.  Retrieve the gradient tensor $\mathbf{G}$ for the current attribute.
3.  Retrieve or generate the mask tensor $\mathbf{M}$ for this attribute.
4.  Apply the mask to the gradient:
    *   If using `freezweightsbymask`: Unsqueeze $\mathbf{M}$ by one dimension to match $\mathbf{G}$'s rank if necessary, then compute $\mathbf{G}' = \mathbf{G} \odot \mathbf{M}$.
    *   If using `freezweightsbymasknounsqueeze`: Compute $\mathbf{G}' = \mathbf{G} \odot \mathbf{M}$ directly without unsqueezing.
5.  Assign $\mathbf{G}'$ back to the attribute's gradient storage.

**Pseudocode:**
```python
def apply_weight_freezing_by_mask(gradients, screenlist, masks, mode='freezweightsbymask'):
    """
    gradients: dict mapping attribute name to gradient tensor
    screenlist: list of attribute names to freeze
    masks: dict mapping attribute name to mask tensor
    mode: 'freezweightsbymask' or 'freezweightsbymasknounsqueeze'
    """
    for attr in screenlist:
        if attr not in gradients:
            continue
        
        grad = gradients[attr]
        mask = masks[attr]
        
        if mode == 'freezweightsbymask':
            # Unsqueeze mask to match gradient dimensions if needed
            # Assuming mask is 1D or needs broadcasting expansion
            while mask.ndim < grad.ndim:
                mask = mask.unsqueeze(-1)
        
        # Element-wise multiplication
        # If mask is 0, gradient becomes 0 (frozen)
        # If mask is 1, gradient remains unchanged
        gradients[attr] = grad * mask
        
    return gradients
```

**Parameters:**
*   `screenlist`: List of attribute names. Typical values: `['_omega']` (rotation), `['_scale']`.
*   `mode`: String determining mask dimensionality handling.

**Edge Cases:**
*   **Dimension Mismatch:** If the mask shape does not broadcast correctly with the gradient tensor, `freezweightsbymask` handles this by unsqueezing. Implementers must ensure the mask covers all elements intended to be frozen [S1, unofficial].
*   **Missing Attributes:** If an attribute in `screenlist` is not present in the current gradient dictionary, it should be skipped [S1, unofficial].

## Subtopics

### Parameter Freezing
A simpler variant that freezes weights by setting `requires_grad` to `False` on specific named parameters. It iterates over the model's named parameters and disables gradients for keys starting with 'decoder' or equal to 'color_decoder' [S2, unofficial]. Unlike mask-based freezing, this prevents gradient computation entirely rather than zeroing it after computation.

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of elements in the masked attributes, due to element-wise multiplication.
*   **Memory Complexity:** $O(N)$ for storing the mask tensors.
*   **Strengths:** Allows fine-grained control over which attributes update during training. Useful for stabilizing training when certain attributes (like rotation) are noisy or when reusing pre-trained components.
*   **Limitations:** Requires manual definition of masks. Does not prevent the memory overhead of storing the gradient tensor itself, only the update.

## Background
Originating from implementations in SpacetimeGaussians [S1, unofficial], this method provides a flexible way to constrain the optimization landscape by selectively freezing weights. It is often used in conjunction with other gradient modification techniques to stabilize the training of complex Gaussian Avatar models.
