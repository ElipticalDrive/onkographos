# SpacetimeGaussians Training Pipeline


## Overview
The SpacetimeGaussians Training Pipeline is the specific optimization procedure for the SpacetimeGaussians method, which extends 3D Gaussian Splatting to dynamic scenes by incorporating time-dependent parameters. It solves the problem of real-time dynamic view synthesis by training Gaussians with motion parameters ($\omega$) and rotations that vary over time, using a specialized densification and pruning schedule to manage the increased complexity of the spatiotemporal representation. It differs from static 3D Gaussian Splatting by maintaining and optimizing motion coefficients and by employing a rigid freezing schedule for these parameters after initial convergence, and differs from other dynamic variants by its specific implementation of channel-based rasterization options and regularization terms for motion gradients.

## How it works
The pipeline initializes a Gaussian model and scene data, then iterates through training steps that alternate between rendering, loss computation, and adaptive density control. The core distinction lies in the handling of motion parameters ($\omega$) and the specific regularization losses applied to them.

### Inputs and Outputs
*   **Inputs:**
    *   Dataset containing multi-view images and camera poses.
    *   Optimization hyperparameters: `opt.lambda_dssim`, `opt.regl`, `opt.densify_from_iter`, `opt.densify_until_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, `opt.opthr`, `densify` mode.
    *   Rendering option: `'train_ours_full'`, `'train_ours_lite'`, `'train_ours_fullss'`, or `'train_ours_litess'`.
*   **Outputs:**
    *   Optimized Gaussian parameters: positions ($\mathbf{xyz}$), rotations ($\mathbf{r}$), scales ($\mathbf{s}$), opacities ($\alpha$), spherical harmonics coefficients, and motion parameters ($\omega$).
    *   Trained model state ready for inference.

### Data Structures
*   **Gaussian Model (`gaussians`):**
    *   `_xyz`: Tensor of shape $(N, 3)$, positions.
    *   `_rotation`: Tensor of shape $(N, 4)$, quaternions.
    *   `_scaling`: Tensor of shape $(N, 3)$, scaling factors.
    *   `_opacity`: Tensor of shape $(N, 1)$, opacity values.
    *   `_omega`: Tensor of shape $(N, \dots)$, motion parameters (specific dimensionality depends on implementation, typically related to deformation fields).
    *   `ts`: Time tensor, shape $(1, 1, H, W)$, initialized to ones if not provided.
    *   `omegamask`: Boolean mask of shape $(N,)$, indicating which Gaussians keep motion parameters.
*   **Background:**
    *   `background`: Tensor of shape `(numchannels,)`, dtype `torch.float32`, device `cuda`. Initialized to zeros. Default `numchannels` is 9.
*   **Render Pipeline:**
    *   Retrieved via `getrenderpip(option)`. Returns a training function, `GaussianRasterizationSettings`, and `GaussianRasterizer`.
    *   Options map to specific rasterization kernels:
        *   `train_ours_full`: `diff_gaussian_rasterization_ch9`
        *   `train_ours_lite`: `diff_gaussian_rasterization_ch3`
        *   `train_ours_fullss`: `diff_gaussian_rasterization_ch9`
        *   `train_ours_litess`: `diff_gaussian_rasterization_ch3`

### Pseudocode

```python
import torch
import numpy as np

def train_spacetime_gaussians(dataset, opt, iteration=0):
    """
    Main training loop for SpacetimeGaussians.
    """
    # 1. Initialization
    gaussians = getmodel(dataset.model)
    scene = Scene(dataset, gaussians, load_iteration=iteration, shuffle=False, 
                  multiview=True, duration=dataset.duration, loader=dataset.loader)
    
    # Initialize background color tensor
    numchannels = 9
    background = torch.zeros(numchannels, dtype=torch.float32, device='cuda')
    
    # Initialize time tensor if not present
    if gaussians.ts is None:
        H, W = scene.cameras[0].image_shape # Assuming first camera provides H, W
        gaussians.ts = torch.ones((1, 1, H, W), dtype=torch.float32, device='cuda')
        
    # Get rendering pipeline
    option = opt.render_option # e.g., 'train_ours_full'
    train_func, RasterizationSettings, Rasterizer = getrenderpip(option)
    
    # If RGB decoder is used, move to CUDA and set to eval
    if gaussians.rgbdecoder is not None:
        gaussians.rgbdecoder = gaussians.rgbdecoder.cuda()
        gaussians.rgbdecoder.eval()

    # 2. Training Loop
    for iteration in range(opt.iterations):
        
        # --- Densification and Pruning Logic ---
        densify_mode = opt.densify # 0, 1, 2, or 3
        
        if densify_mode == 1:
            # At iteration 8001, determine which Gaussians keep motion parameters
            if iteration == 8001:
                gaussians.zero_omegabymotion()
                gaussians.omegamask = gaussians.get_omegamask() # Store mask
            
            # Freeze weights based on mask
            if iteration > 8001:
                # Freeze _omega for Gaussians in mask, freeze _rotation for others
                freezweightsbymasknounsqueeze(gaussians._omega, gaussians.omegamask)
                freezweightsbymasknounsqueeze(gaussians._rotation, ~gaussians.omegamask)
        
        # Adaptive Density Control
        if iteration > opt.densify_from_iter and iteration % opt.densification_interval == 0:
            if gaussians.flag < opt.desicnt:
                # Determine size threshold
                if iteration > opt.opacity_reset_interval:
                    size_threshold = 20
                else:
                    size_threshold = None
                
                gaussians.densify_pruneclone(
                    opt.densify_grad_threshold, 
                    opt.opthr, 
                    scene.cameras_extent, 
                    size_threshold
                )
        
        # Pruning based on opacity
        if gaussians.flag >= opt.desicnt and iteration < 7000:
            gaussians.prune_points(opt.opthr)
            
        # Reset opacity periodically
        if iteration % 3000 == 0:
            gaussians.reset_opacity()
            
        # Final freezing and pruning
        if iteration >= opt.densify_until_iter:
            # Freeze _omega and _rotation
            freezweightsbymasknounsqueeze(gaussians._omega, gaussians.omegamask)
            freezweightsbymasknounsqueeze(gaussians._rotation, ~gaussians.omegamask)
            
            # Prune points with low Z-coordinate
            if iteration % 1000 == 500:
                mask = gaussians._xyz[:, 2] < 4.5
                gaussians.prune_points_by_mask(mask)

        elif densify_mode == 3:
            # Mode 3 specific logic
            gaussians.update_max_radii2D()
            gaussians.add_densification_stats()
            # Densify/prune clones at intervals
            if iteration % opt.densification_interval == 0:
                gaussians.densify_pruneclone(...)
            if iteration < 7000:
                gaussians.prune_points(opt.opthr)
            if iteration % opt.opacity_reset_interval == 0:
                gaussians.reset_opacity()
            if iteration == 10000:
                gaussians.removeminmax()

        # --- Rendering and Loss ---
        # Render image
        # Note: Implementation details for rendering depend on the specific rasterizer
        # returned by getrenderpip. Standard 3DGS rendering applies here with time input.
        rendered_image = train_func(
            gaussians=gaussians,
            scene=scene,
            background=background,
            scaling_modifier=1.0,
            basicfunction=trbfunction,
            GRsetting=RasterizationSettings,
            GR=Rasterizer
        )
        
        gt_image = scene.get_gt_image(iteration) # Ground truth image
        
        # Compute Loss
        reg_type = opt.reg
        lambda_dssim = opt.lambda_dssim
        regl = opt.regl
        
        # Base losses
        L1_loss = L1_loss(rendered_image, gt_image)
        SSIM_loss = 1 - SSIM(rendered_image, gt_image)
        
        if reg_type == 1:
            # L1 + D-SSIM + Motion Gradient Mean
            g_motion = compute_motion_gradient(gaussians) # Sum of motion gradients
            L = (1 - lambda_dssim) * L1_loss + lambda_dssim * SSIM_loss + regl * (g_motion / gaussians.N)
        elif reg_type == 9:
            # L1 + D-SSIM + Motion Gradient L2 (r>0)
            g_omega = compute_omega_gradient(gaussians) # Sum of squared omega gradients for r>0
            L = (1 - lambda_dssim) * L1_loss + lambda_dssim * SSIM_loss + regl * g_omega
        elif reg_type == 10:
            # L1 + D-SSIM + Motion Gradient L2 (motion)
            g_motion_sq = compute_motion_gradient_squared(gaussians)
            L = (1 - lambda_dssim) * L1_loss + lambda_dssim * SSIM_loss + regl * g_motion_sq
        elif reg_type == 4:
            # L1 + D-SSIM + Scaling Gradient Mean
            g_scaling = compute_scaling_gradient(gaussians)
            L = (1 - lambda_dssim) * L1_loss + lambda_dssim * SSIM_loss + regl * (g_scaling / gaussians.N)
        elif reg_type == 6:
            # Adaptive weighting based on GT mean
            r = clamp(mean(gt_image) - 0.5 + lambda_dssim, 0, 1)
            L = (1 - r) * L1_loss + r * SSIM_loss
        elif reg_type == 7:
            # Normalized L1
            L1_loss = L1_loss / (2 * mean(gt_image))
            L = (1 - lambda_dssim) * L1_loss + lambda_dssim * SSIM_loss
        elif reg_type == 8:
            # L1 + D-SSIM + Reconstruction Error of Mean
            mean_val = mean(rendered_image)
            recon_err = sum((mean_val - rendered_image)^2) / gaussians.N
            L = (1 - lambda_dssim) * L1_loss + 0.0002 * lambda_dssim * recon_err
        else:
            L = (1 - lambda_dssim) * L1_loss + lambda_dssim * SSIM_loss

        # Backpropagation
        L.backward()
        
        # Optimizer Step
        optimizer.step()
        optimizer.zero_grad()
        
        # Update learning rates if necessary
        update_learning_rates(optimizer, iteration)

def getrenderpip(option="train_ours_full"):

        from diff_gaussian_rasterization_ch9 import GaussianRasterizer  
        return train_ours_full, GaussianRasterizationSettings, GaussianRasterizer

        from diff_gaussian_rasterization_ch3 import GaussianRasterizationSettings 
        from diff_gaussian_rasterization_ch3 import GaussianRasterizer  
        return train_ours_lite, GaussianRasterizationSettings, GaussianRasterizer
    # ... other options ...
```

### Formulas
The total loss $L$ is a combination of L1 loss, D-SSIM loss, and optional regularization terms depending on `opt.reg`:

1.  **Base Losses:**
    $$ L_{L1} = \frac{1}{N} \sum_{i=1}^{N} |I_i - I_{gt,i}| $$
    $$ L_{SSIM} = 1 - \text{SSIM}(I, I_{gt}) $$

2.  **Regularization Terms:**
    *   **reg=1:** $$ L = (1 - \lambda_{dssim}) L_{L1} + \lambda_{dssim} L_{SSIM} + \lambda_{reg} \frac{\sum \mathbf{g}_{\text{motion}}}{N} $$
    *   **reg=9:** $$ L = (1 - \lambda_{dssim}) L_{L1} + \lambda_{dssim} L_{SSIM} + \lambda_{reg} \sum_{r>0} \mathbf{g}_{\omega}^2 $$
    *   **reg=10:** $$ L = (1 - \lambda_{dssim}) L_{L1} + \lambda_{dssim} L_{SSIM} + \lambda_{reg} \sum_{r>0} \mathbf{g}_{\text{motion}}^2 $$
    *   **reg=4:** $$ L = (1 - \lambda_{dssim}) L_{L1} + \lambda_{dssim} L_{SSIM} + \lambda_{reg} \frac{\sum \mathbf{g}_{\text{scaling}}}{N} $$
    *   **reg=6:** $$ L = (1 - r) L_{L1} + r L_{SSIM}, \quad r = \text{clamp}(\text{mean}(I_{gt}) - 0.5 + \lambda_{dssim}, 0, 1) $$
    *   **reg=7:** $$ L_{L1} \text{ is normalized by } 2 \cdot \text{mean}(I_{gt}) $$
    *   **reg=8:** $$ L = (1 - \lambda_{dssim}) L_{L1} + 0.0002 \cdot \lambda_{dssim} \frac{\sum (\bar{x} - x)^2}{N} $$

    Where $\mathbf{g}$ denotes gradients or gradient sums as specified, $\lambda_{dssim}$ is `opt.lambda_dssim`, and $\lambda_{reg}$ is `opt.regl`.

### Parameters
*   `numchannels`: Number of channels for background color. Default: 9.
*   `scaling_modifier`: Passed to render function. Default: 1.0.
*   `basicfunction`: Passed to render function. Default: `trbfunction`.
*   `size_threshold`: Used in densification. Set to 20 if `iteration > opt.opacity_reset_interval`, else `None`.
*   `opt.densify_from_iter`, `opt.densify_until_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, `opt.opthr`: Control thresholds and intervals for densification, pruning, and opacity resets.

### Edge Cases and Pitfalls
*   **RGB Decoder:** If `gaussians.rgbdecoder` is not None, it must be moved to CUDA and set to `eval` mode before rendering [S1, unofficial].
*   **Pruning Logic:** Pruning behavior changes based on the densification phase. Before `opt.desicnt` is reached, densification is prioritized. After `opt.desicnt`, pruning is based on opacity if `iteration < 7000`. After `opt.densify_until_iter`, pruning is based on Z-coordinate `< 4.5` if `iteration % 1000 == 500` [S1, unofficial].
*   **Time Tensor:** If `gaussians.ts` is None, it must be initialized as a tensor of ones with shape `(1, 1, H, W)` on CUDA, where H and W are from the first test camera [S1, unofficial].

## Subtopics

### SpacetimeGaussians Densification & Pruning Schedule
A training iteration schedule that controls Gaussian densification, pruning, and parameter freezing based on iteration count, mode selection, and visibility metrics. It supports four densification modes (`densify` parameter: 0, 1, 2, or 3). Mode 1 involves pruning points where `gaussians._xyz[:,2] < 4.5` at iteration 1000 and resetting opacity every 3000 iterations. Mode 3 updates `max_radii2D` and `add_densification_stats` every iteration, densifies/prunes clones at intervals, prunes low-opacity points if `iteration < 7000`, resets opacity every `opt.opacity_reset_interval`, and calls `removeminmax` at iteration 10000. Key parameters include `size_threshold` (20 if `iteration > opt.opacity_reset_interval`, else `None`), `opt.densify_until_iter`, `opt.densify_from_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, and `opt.opthr` [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The training time is dominated by the differentiable rasterization step, which is $O(N \cdot M)$ where $N$ is the number of Gaussians and $M$ is the number of pixels. The additional overhead from motion parameter optimization and regularization is linear in $N$.
*   **Memory Complexity:** Memory usage is $O(N)$ for Gaussian parameters. The use of specific rasterization kernels (`ch3` vs `ch9`) affects memory bandwidth but not asymptotic complexity.
*   **Performance:** Real-time dynamic view synthesis is achieved. The method scales with the number of Gaussians, which is managed by the adaptive density control.
*   **Strengths:** Efficient handling of dynamic scenes through explicit motion parameters. Flexible regularization options allow tuning for different scene characteristics.
*   **Limitations:** The freezing schedule for motion parameters may limit the ability to model complex, long-term temporal dependencies if not tuned correctly. The specific pruning logic based on Z-coordinate may remove valid geometry in certain camera configurations.
*   **When to use:** Suitable for real-time dynamic view synthesis where explicit motion modeling is beneficial and computational resources are limited compared to neural field-based methods.
*   **When not to use:** Not suitable for scenes with extremely complex, non-rigid deformations that cannot be captured by the Gaussian motion parameters, or when high-fidelity static rendering is required without temporal dynamics.

## Background
The SpacetimeGaussians method was introduced by Zhan Li, Zhang Chen, Zhong Li, and Yi Xu in their paper "Spacetime Gaussian Feature Splatting for Real-Time Dynamic View Synthesis" presented at CVPR 2024 [S1, unofficial]. It builds upon the 3D Gaussian Splatting framework  by extending it to handle dynamic scenes. The training pipeline described here is derived from the official implementation by OPPO US Research [S1, unofficial].
