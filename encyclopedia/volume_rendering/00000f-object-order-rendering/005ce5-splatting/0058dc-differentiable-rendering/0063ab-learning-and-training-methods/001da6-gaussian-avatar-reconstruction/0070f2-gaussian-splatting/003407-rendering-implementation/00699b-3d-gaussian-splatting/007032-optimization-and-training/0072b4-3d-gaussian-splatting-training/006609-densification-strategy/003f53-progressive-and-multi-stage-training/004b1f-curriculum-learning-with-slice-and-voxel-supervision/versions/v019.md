# Curriculum Learning with Slice and Voxel Supervision

Also called: Slice and Voxel Supervision Curriculum

## Overview
This method stabilizes the optimization of 3D Gaussian representations for volumetric data by alternating between local planar constraints and global volumetric guidance. It solves the instability caused by random sampling in dense volumes by first establishing local structural continuity via slice supervision, then anchoring the global geometry with sparse voxel supervision. It differs from sibling methods by explicitly leveraging the alignment between the training sampling strategy and the shear-warp rendering pipeline, ensuring the learned representation is optimized for the specific rendering process [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A volumetric dataset (e.g., MRI, Cryosection) represented as a voxel grid; a set of camera poses and intrinsics for target views.
*   **Output:** A set of 3D Gaussians $\mathcal{G} = \{G_1, \dots, G_m\}$, where each Gaussian $G_i$ has learnable parameters: mean $\mu_i$, covariance $\Sigma_i$, opacity $\alpha_i$, and spherical harmonics coefficients for color [S1].

**Data Structures:**
*   **Gaussian Set:** A list of $m$ Gaussian kernels. Each kernel is initialized at a sampled voxel position.
*   **Voxel Grid:** The source volume data used for sampling.

**Algorithm Steps:**
The training follows a two-stage curriculum:

1.  **Stage 1: Slice Supervision (Local Structure)**
    *   In each iteration, sample a plane with an arbitrary orientation.
    *   Select sparse pixels on this sampled plane.
    *   Map each selected pixel to a 3D voxel coordinate in the volume.
    *   Render the view using the current Gaussian set.
    *   Compute the loss between the rendered image and the ground truth slice/image.
    *   Update Gaussian parameters (means, covariances, opacities) to minimize this loss. This step captures spatially correlated regions and encodes geometric structure and texture continuity [S1].

2.  **Stage 2: Voxel Supervision (Global Guidance)**
    *   After sufficient convergence in Stage 1, introduce voxel supervision.
    *   Sample sparse voxels from the volume.
    *   Use these voxels to provide global spatial guidance, correcting the global approximation and ensuring volumetric consistency.
    *   Jointly optimize the Gaussian parameters using both slice and voxel losses [S1].

**Formulas:**
The total loss $\mathcal{L}$ is a combination of image reconstruction loss $\mathcal{L}_{img}$ and potentially voxel-based regularization.
$$ \mathcal{L} = \mathcal{L}_{img} + \lambda \mathcal{L}_{voxel} $$
Where $\lambda$ is a weighting factor. The exact formulation of $\mathcal{L}_{voxel}$ is not explicitly detailed in the sources beyond "sparse voxel supervision" [S1].

**Parameters:**
*   **Sampling Strategy:** Arbitrary orientation for planes; sparse pixel selection on planes; sparse voxel selection in volume.
*   **Curriculum Schedule:** The transition from Stage 1 to Stage 2 is not defined by a fixed step count in the provided notes, but implied by "progressively training" [S1].

**Edge Cases and Pitfalls:**
*   **Instability with Random Voxels First:** Applying random voxel supervision before stable global constraints are established leads to unstable learning of the volumetric structure [S1].
*   **Lack of Global Guidance with Only Slices:** Using only slice supervision limits accurate reconstruction of the full volumetric structure due to the lack of global spatial guidance [S1].
*   **Destabilization with Random Slices:** Random slice sampling combined with random voxel sampling can destabilize the learning of Gaussian parameters [S1].

**Pseudocode:**
```python
def train_gaussian_volumetric(volume_data, camera_poses, num_iterations):
    # Initialize Gaussians from voxel samples
    gaussians = initialize_gaussians_from_voxels(volume_data)
    
    # Stage 1: Slice Supervision
    for iteration in range(num_iterations // 2):
        # Sample a plane with arbitrary orientation
        plane = sample_arbitrary_plane()
        
        # Select sparse pixels on the plane
        pixels = select_sparse_pixels(plane)
        
        # Map pixels to 3D voxel coordinates
        voxel_coords = map_pixels_to_voxels(pixels, volume_data)
        
        # Render the view
        rendered_image = render_gaussians(gaussians, camera_poses)
        
        # Get ground truth for the slice/view
        gt_image = get_ground_truth_slice(volume_data, plane, camera_poses)
        
        # Compute loss
        loss = compute_image_loss(rendered_image, gt_image)
        
        # Update Gaussians
        gaussians = update_gaussians(gaussians, loss)
        
    # Stage 2: Voxel Supervision (Combined)
    for iteration in range(num_iterations // 2, num_iterations):
        # Sample sparse voxels
        voxels = sample_sparse_voxels(volume_data)
        
        # Render the view
        rendered_image = render_gaussians(gaussians, camera_poses)
        
        # Get ground truth
        gt_image = get_ground_truth_view(volume_data, camera_poses)
        
        # Compute combined loss (image + voxel regularization)
        # Note: Exact voxel loss formula is not provided in sources [S1]
        loss = compute_image_loss(rendered_image, gt_image) + \
               compute_voxel_loss(gaussians, voxels, volume_data)
        
        # Update Gaussians
        gaussians = update_gaussians(gaussians, loss)
        
    return gaussians
```

## Subtopics

### Curriculum Learning with Sparse Voxel and Slice Sampling
This variant explicitly defines the sampling strategy to align with shear-warp volume rendering. It uses sparse voxels for global coverage and slice samples for spatially correlated regions encoding geometric structure and texture continuity. In each iteration, a plane with arbitrary orientation is sampled, sparse pixels are selected on the plane, and each pixel is mapped to a 3D voxel coordinate. This ensures the Gaussian representation learns spatial continuity across neighboring regions, naturally aligning with the shear-warp rendering process which generates images from stacks of 2D slices [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Combining slice and voxel supervision yields higher PSNR and SSIM compared to using only slice supervision or random sampling strategies [S1].
*   **Strengths:** Efficiently learns both global volumetric consistency and local anatomical details; aligns with shear-warp rendering; stabilizes optimization compared to random sampling [S1].
*   **Limitations:** Requires careful scheduling of the curriculum; random voxel sampling can destabilize learning if not properly integrated [S1].
*   **When to Use:** For multimodal volumetric datasets (MRI, Cryosection) where efficient reconstruction and real-time visualization are required [S1].
*   **When Not to Use:** When random sampling is used without the structured slice supervision, as it leads to instability [S1].

## Background
The method originates from research on Gaussian Volumetric Representation for Efficient Shear-Warp Visualization [S1]. It is designed for multimodal volumetric datasets including MRI and Cryosection volumes. The approach leverages the fact that shear-warp rendering operates on stacks of 2D slices, making slice-based supervision a natural fit for training the Gaussian representation [S1].
