# Monocular Depth Scale Alignment

Also called: Global Scale Alignment, Metric Scale Correction

## Overview
Monocular Depth Scale Alignment is a post-optimization step in 3D Gaussian Splatting pipelines that resolves the up-to-scale ambiguity inherent in multi-view reconstruction by aligning the metric scale of optimized 3D Gaussians with metric-scale monocular depth estimates [S1, unofficial]. Unlike methods that integrate depth priors during training, this approach operates after the standard Gaussian optimization phase, fixing the Gaussian parameters and optimizing only a global scale factor [S1, unofficial].

## How it works
**Inputs:**
*   $\Theta$: The set of optimized 3D Gaussian parameters (means, covariances, opacities, colors) from the standard 3DGS training [S1, unofficial].
*   $\{I_i\}_{i=1}^{N_{\mathcal{I}}}$: A set of $N_{\mathcal{I}}$ input images [S1, unofficial].
*   $\{D^{mono}_i\}_{i=1}^{N_{\mathcal{I}}}$: Metric-scale monocular depth maps estimated from $I_i$ using an off-the-shelf estimator (e.g., DepthAnythingV2) [S1, unofficial].

**Outputs:**
*   $\Theta'$: Updated Gaussian parameters where only the mean positions and scale attributes are scaled by the global factor $a$ [S1, unofficial].

**Data Structures:**
*   $a \in \mathbb{R}$: A single scalar representing the global scene scale [S1, unofficial].

**Steps:**
1.  **Monocular Depth Estimation:** For each input image $I_i$, compute the metric depth map $D^{mono}_i$ using a pre-trained monocular depth estimation model [S1, unofficial].
2.  **Inverse Depth Conversion:** Convert metric depth maps to inverse depth maps to match the rendering convention by directly taking their reciprocal: $invD^{mono}_i = 1 / D^{mono}_i$ [S1, unofficial].
3.  **Rendered Inverse Depth:** Render the inverse depth map $invD^{rendered}_i$ for each view $i$ using the current 3D Gaussian parameters $\Theta$ [S1, unofficial].
4.  **Optimize Global Scale:** Optimize the global scale factor $a$ to minimize the $L_1$ distance between the monocular inverse depth and the scaled rendered inverse depth:
    $$ a^* = \arg \min_a \sum_{i=1}^{N_{\mathcal{I}}} \| invD^{mono}_i - a \cdot invD^{rendered}_i \|_1 $$
    This optimization is performed while keeping $\Theta$ fixed [S1, unofficial].
5.  **Update Gaussians:** Apply the optimal scale $a^*$ to the 3D Gaussians. Specifically, update the mean position $\mathbf{c}_i$ and the scale parameters of each Gaussian $i$ by multiplying them by $a^*$ [S1, unofficial].

    """
    Aligns 3D Gaussian Splatting scale with monocular depth estimates.
    
    Args:
        Gaussians: Object containing Gaussian parameters (means, scales, etc.)
        images: List of input images
        depth_estimator: Function to predict metric depth from image
        camera_params: List of camera intrinsic/extrinsic parameters for each view
        
    Returns:
        Gaussians: Updated Gaussian parameters with scaled means and scales
    """
    N = len(images)
    
    # Step 1 & 2: Get metric depth and convert to inverse depth
    inv_depth_mono = []
    for img in images:
        metric_depth = depth_estimator(img)
        # Avoid division by zero; clamp small values
        metric_depth = max(metric_depth, 1e-6)
        inv_depth_mono.append(1.0 / metric_depth)
        
    # Step 3 & 4: Optimize global scale 'a'
    a = 1.0
    lr = 0.01
    iterations = 100
    
    for _ in range(iterations):
        loss = 0.0
        grad_a = 0.0
        for i in range(N):
            # Differentiable rasterization of scaled Gaussians to get inverse depth
            inv_depth_rendered = differentiable_rasterize_inv_depth(Gaussians, a, camera_params[i])

            grad_a += (-inv_depth_rendered * diff).mean()
            
        a -= lr * grad_a
        
    a_optimal = a
    
    # Step 5: Update Gaussians
    # Only mean and scale attributes are changed
    Gaussians.means = Gaussians.means * a_optimal
    Gaussians.scales = Gaussians.scales * a_optimal
    
    return Gaussians

**Edge Cases and Pitfalls:**
*   **Pruning:** Unlike original 3DGS which may prune initial COLMAP points, this method avoids pruning to prevent affecting the distribution of optimized Gaussian parameters, ensuring fair comparison with other studies [S1, unofficial].
*   **Depth Estimator Choice:** The method relies on the quality of the monocular depth estimator. Using a metric-scale estimator (e.g., DepthAnythingV2 metric variant) is crucial, as opposed to relative depth estimators [S1, unofficial].
*   **Inverse Depth Convention:** Ensure consistency between the monocular depth output format and the rendered depth format. The source specifies using the reciprocal of metric depth maps to obtain inverse depth maps [S1, unofficial].

## Background
This method addresses the up-to-scale problem in neural rendering pipelines where multi-view reconstruction from images alone does not recover metric scale [S1, unofficial]. It builds on the observation that monocular depth estimation models can provide metric-scale depth maps, which can be used to align the relative scale of 3D Gaussians [S1, unofficial]. The approach is similar to depth alignment processes described in prior works [Chung et al., 2024; Kerbl et al., 2024], but specifically adapted for 3D Gaussian Splatting with a focus on avoiding pruning to maintain parameter distribution [S1, unofficial].
