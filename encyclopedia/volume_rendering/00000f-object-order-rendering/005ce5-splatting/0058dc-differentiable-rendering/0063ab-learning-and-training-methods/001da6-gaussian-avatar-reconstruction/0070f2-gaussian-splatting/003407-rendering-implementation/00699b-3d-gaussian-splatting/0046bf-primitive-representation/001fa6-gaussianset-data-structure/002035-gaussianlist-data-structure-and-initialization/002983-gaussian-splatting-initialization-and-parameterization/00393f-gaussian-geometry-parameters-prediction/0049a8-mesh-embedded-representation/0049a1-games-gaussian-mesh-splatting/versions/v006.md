# GaMeS (Gaussian Mesh Splatting)

Also called: Gaussian Mesh Splatting, Mesh-based adapting and modification of Gaussian Splatting

## Overview
GaMeS is a hybrid 3D representation that integrates Gaussian Splatting (GS) with mesh-based parameterization, allowing Gaussian components to be modified and deformed in the same manner as a traditional triangle mesh [S1]. Unlike standard GS, which treats Gaussians as independent entities, GaMeS anchors each Gaussian to the vertices of a canonical mesh face, ensuring that geometric transformations (rotation, scaling, deformation) applied to the mesh automatically propagate to the Gaussians' means and covariances [S1]. This distinguishes it from siblings like [SuGaR / Gaussian Frosting](13542-sugar-gaussian-frosting.md), which rely on expensive pre-processing and SDF regularization, by providing a direct, one-stage parameterization that supports real-time editing and animation [S1].

## How it works
GaMeS operates in two primary modes: **Mesh-Initialized Input** (baseline) and **Mesh-Free Input** (Triangle Soup). Both modes rely on parameterizing Gaussian attributes relative to a canonical triangle mesh $\mathcal{M}$ with vertices $V$, normals $n$, and faces $F$, as defined in the parent [Mesh-embedded representation](12559-mesh-embedded-representation.md).

### Inputs and Outputs
*   **Inputs:** A canonical triangle mesh $\mathcal{M}$ (for baseline) or a set of initial flat Gaussians (for Triangle Soup); input images for optimization.
*   **Outputs:** A set of Gaussians $G_M$ defined by their embedding on the mesh, including trainable parameters for position, scale, opacity, and color.

### Data Structures
For a mesh with $n$ faces, GaMeS defines a fixed number $k$ of Gaussian components per face, resulting in $k \cdot n$ total Gaussians [S1].

**Embedding Tuple:**
Each Gaussian $i$ on face $f$ is defined by:
*   $k$: Index of the triangle face in $F$.
*   $(\alpha_{1i}, \alpha_{2i}, \alpha_{3i})$: Trainable barycentric coordinates such that $\alpha_{1i} + \alpha_{2i} + \alpha_{3i} = 1$.
*   $\rho_i$: Trainable scale multiplier, $\rho_i \in \mathbb{R}^+$.
*   $\sigma_i$: Opacity.
*   $c_i$: Spherical Harmonic (SH) color coefficients.

**Canonical Geometry:**
The canonical mean $\mu_{cano}$ and normal $n_{cano}$ are computed via linear interpolation on the canonical mesh [Parent, S1]:
$$
\mu_{cano} = \alpha_{1i} v_1 + \alpha_{2i} v_2 + \alpha_{3i} v_3
$$
$$
n_{cano} = \frac{(v_2 - v_1) \times (v_3 - v_1)}{\|(v_2 - v_1) \times (v_3 - v_1)\|}
$$
where $v_1, v_2, v_3$ are the vertices of the face [S1].

**Posed State Computation:**
When the mesh is deformed via a deformation function $\text{Deform}(\cdot)$ (e.g., skeletal animation), the posed position is:
$$
\mu_{pose} = \text{Deform}(\mu_{cano})
$$
The posed rotation $q_{pose}$ and scale $s_{pose}$ are derived from mesh attributes to maintain coherence [Parent]. Specifically, the rotation is interpolated from per-vertex quaternions, and scale is proportional to the area change of the embedded triangle relative to the canonical state [Parent].

### Initialization and Parameterization

#### 1. Baseline: Mesh-Initialized Input
When a mesh is provided, Gaussians are placed directly on the mesh surface.

**Step 1: Construct Local Frame for Face $V$**
For a single triangle face with vertices $V = \{v_1, v_2, v_3\}$, construct an orthonormal basis $R_V = [r_1, r_2, r_3]$ [S1]:
1.  Calculate the normal $r_1$:
    $$
    r_1 = \frac{(v_2 - v_1) \times (v_3 - v_1)}{\|(v_2 - v_1) \times (v_3 - v_1)\|}
    $$
2.  Calculate the centroid $m = \text{mean}(v_1, v_2, v_3)$.
3.  Calculate the first tangent $r_2$ by normalizing the vector from the centroid to $v_1$:
    $$
    r_2 = \frac{v_1 - m}{\|v_1 - m\|}
    $$
4.  Calculate the second tangent $r_3$ using Gram-Schmidt orthogonalization of the vector from the centroid to $v_2$ against $r_1$ and $r_2$:
    $$
    r_3 = \frac{\text{orth}(v_2 - m; r_1, r_2)}{\|\text{orth}(v_2 - m; r_1, r_2)\|}
    $$
    Where $\text{orth}(x; r_1, r_2) = x - \text{proj}(x, r_1) - \text{proj}(x, r_2)$ and $\text{proj}(v, u) = \frac{\langle v, u \rangle}{\langle u, u \rangle} u$ [S1].

**Step 2: Define Base Covariance $\Sigma_V$**
Define the scaling matrix $S_V = \text{diag}(s_1, s_2, s_3)$ [S1]:
*   $s_1 = \epsilon$ (a small constant to avoid numerical issues, representing the normal direction).
*   $s_2 = \|m - v_1\|$.
*   $s_3 = \langle v_2, r_3 \rangle$.
The base covariance is $\Sigma_V = R_V S_V S_V^T R_V^T$ [S1].

**Step 3: Define Gaussians per Face**
For each of the $k$ Gaussians $i$ on face $V$, define the Gaussian $G_{Vi}$ [S1]:
$$
G_{Vi} = \mathcal{N}(\mu_{Vi}, \rho_i \Sigma_V)
$$
where $\mu_{Vi} = \alpha_{1i} v_1 + \alpha_{2i} v_2 + \alpha_{3i} v_3$ and $\alpha_{1i} + \alpha_{2i} + \alpha_{3i} = 1$ [S1]. The parameters $\{\alpha_{1i}, \alpha_{2i}, \alpha_{3i}, \rho_i, \sigma_i, c_i\}$ are trainable.

#### 2. Mesh-Free Input: Triangle Soup
When no mesh is available, GaMeS creates a "Triangle Soup" by estimating a mesh from flat Gaussians [S1].

**Step 1: Train Initial Flat Gaussians**
Train a standard GS with flat splats, setting the first scaling parameter $s_1 = \epsilon$ [S1].

**Step 2: Estimate Triangle Vertices**
For each Gaussian $G$ with mean $m$, rotation $R = [r_1, r_2, r_3]$, and scale $S = \text{diag}(\epsilon, s_2, s_3)$, define three vertices $V = [v_1, v_2, v_3]$ [S1]:
*   $v_1 = m$
*   $v_2 = m + s_2 r_2$
*   $v_3 = m + s_3 r_3$

**Step 3: Re-parameterize**
Freeze the vertices $V$ and re-parameterize the Gaussian $\hat{G}_V$ using the mesh-based approach [S1]:
1.  Set $\hat{m}_V = v_1$.
2.  Compute $\hat{r}_1 = \frac{(v_2 - v_1) \times (v_3 - v_1)}{\|(v_2 - v_1) \times (v_3 - v_1)\|}$.
3.  Compute $\hat{r}_3 = \text{orth}(v_3 - v_1; r_1, r_2)$ (using the original $r$ vectors from Step 1) [S1].
4.  Compute $\hat{r}_2 = \hat{r}_3 \times \hat{r}_1$ (implied by orthonormality, or derived via Gram-Schmidt as in baseline) [S1].
5.  Compute scales: $\hat{s}_1 = \epsilon$, $\hat{s}_2 = \|v_2 - v_1\|$, $\hat{s}_3 = \langle v_3 - v_1, \hat{r}_3 \rangle$.
6.  Construct $\hat{\Sigma}_V = \hat{R}_V \hat{S}_V \hat{S}_V^T \hat{R}_V^T$.
7.  Define $\hat{G}_V = \mathcal{N}(\hat{m}_V, \hat{\Sigma}_V)$ [S1].

The final set is $G_M = \bigcup_{V_i \in \hat{M}} \{\hat{G}_{V_i}, \sigma_i, c_i\}$ [S1].

### Pseudocode

```python
import numpy as np

def gram_schmidt_step(x, r1, r2):
    """Single step Gram-Schmidt orthogonalization."""
    def proj(v, u):
        return (np.dot(v, u) / np.dot(u, u)) * u
    return x - proj(x, r1) - proj(x, r2)

def compute_face_basis(v1, v2, v3):
    """Compute orthonormal basis for a triangle face."""
    # Normal
    edge1 = v2 - v1
    edge2 = v3 - v1
    r1 = edge1.cross(edge2)
    r1 = r1 / np.linalg.norm(r1)
    
    # Centroid
    m = (v1 + v2 + v3) / 3.0
    
    # First tangent
    vec1 = v1 - m
    r2 = vec1 / np.linalg.norm(vec1)
    
    # Second tangent
    vec2 = v2 - m
    r3 = gram_schmidt_step(vec2, r1, r2)
    r3 = r3 / np.linalg.norm(r3)
    
    return np.column_stack((r1, r2, r3))

def create_gaussian_mesh_splat(mesh_faces, k, epsilon=1e-4):
    """
    Initialize GaMeS Gaussians for a given mesh.
    
    Args:
        mesh_faces: List of triangles, each triangle is (v1, v2, v3) where v are (3,) arrays.
        k: Number of Gaussians per face.
        epsilon: Small constant for normal scaling.
        
    Returns:
        Gaussians: List of Gaussian objects/parameters.
    """
    gaussians = []
    
    for face_idx, (v1, v2, v3) in enumerate(mesh_faces):
        # 1. Compute Face Basis
        R_V = compute_face_basis(v1, v2, v3)
        r1, r2, r3 = R_V[:, 0], R_V[:, 1], R_V[:, 2]
        
        # 2. Compute Base Scaling
        m = (v1 + v2 + v3) / 3.0
        s1 = epsilon
        s2 = np.linalg.norm(m - v1)
        s3 = np.dot(v2, r3)
        
        S_V = np.diag([s1, s2, s3])
        Sigma_V = R_V @ S_V @ S_V.T @ R_V.T
        
        # 3. Create k Gaussians for this face
        for i in range(k):
            # Initialize barycentric coordinates (e.g., random or uniform)
            # Must satisfy alpha1 + alpha2 + alpha3 = 1
            alpha = np.random.dirichlet([1, 1, 1])
            
            # Mean
            mu = alpha[0] * v1 + alpha[1] * v2 + alpha[2] * v3
            
            # Scale multiplier (trainable)
            rho = np.random.uniform(0.5, 1.5)
            
            # Covariance
            Sigma = rho * Sigma_V
            
            # Opacity and Color (trainable)
            sigma = np.random.uniform(0.1, 0.9)
            color = np.random.rand(3) # Placeholder for SH coefficients
            
            gaussians.append({
                'face_idx': face_idx,
                'alpha': alpha,
                'rho': rho,
                'mu': mu,
                'Sigma': Sigma,
                'sigma': sigma,
                'color': color
            })
            
    return gaussians

def create_triangle_soup_from_gs(gs_list, epsilon=1e-4):
    """
    Convert standard GS to GaMeS Triangle Soup.
    
    Args:
        gs_list: List of standard GS objects with mean, rotation (3x3), scale (3,).
        epsilon: Small constant.
        
    Returns:
        GaMeS Gaussians (same structure as create_gaussian_mesh_splat).
    """
    gaussians = []
    
    for gs in gs_list:
        m = gs.mean
        R = gs.rotation # 3x3 matrix [r1, r2, r3]
        s = gs.scale    # [s1, s2, s3]
        
        r1, r2, r3 = R[:, 0], R[:, 1], R[:, 2]
        
        # Define vertices
        v1 = m
        v2 = m + s[1] * r2
        v3 = m + s[2] * r3
        
        # Re-parameterize
        # Compute new basis from vertices
        R_hat = compute_face_basis(v1, v2, v3)
        r_hat1, r_hat2, r_hat3 = R_hat[:, 0], R_hat[:, 1], R_hat[:, 2]
        
        # Compute new scales
        s_hat1 = epsilon
        s_hat2 = np.linalg.norm(v2 - v1)
        s_hat3 = np.dot(v3 - v1, r_hat3)
        
        S_hat = np.diag([s_hat1, s_hat2, s_hat3])
        Sigma_hat = R_hat @ S_hat @ S_hat.T @ R_hat.T
        
        # Create GaMeS Gaussian
        # Barycentric coords for a single Gaussian on a "face" (the estimated triangle)
        # Can be fixed to centroid or optimized
        alpha = np.array([1/3, 1/3, 1/3])
        mu = alpha[0]*v1 + alpha[1]*v2 + alpha[2]*v3
        
        gaussians.append({
            'face_idx': None, # No canonical mesh face index
            'alpha': alpha,
            'rho': 1.0,       # Implicit in scale calculation
            'mu': mu,
            'Sigma': Sigma_hat,
            'sigma': gs.opacity,
            'color': gs.color
        })
        
    return gaussians
```

### Edge Cases and Pitfalls
*   **Face Size Variation:** If mesh faces vary significantly in size, using a fixed number $k$ of Gaussians per face leads to poor resolution on large faces and redundancy on small ones. The solution is to subdivide large faces into smaller parts before initialization [S1].
*   **Numerical Stability:** The normal scaling parameter $s_1$ is set to $\epsilon$ rather than 0 to avoid numerical problems in the covariance matrix inversion or decomposition [S1].
*   **Cross-Triangle Handling:** As noted in the parent [Mesh-embedded representation](12559-mesh-embedded-representation.md), if optimization moves an embedding point across a triangle boundary, the embedding must be re-expressed in the neighboring triangle to maintain differentiability. Failure to do so causes Gaussians to stick to boundaries [Parent].

## Operating characteristics
*   **Time Complexity:** Initialization is $O(n \cdot k)$ where $n$ is the number of faces and $k$ is Gaussians per face. Rendering is $O(N)$ where $N = n \cdot k$ is the total number of Gaussians, identical to standard GS.
*   **Memory Complexity:** $O(N)$ for Gaussian attributes. The mesh storage is $O(F)$ where $F$ is the number of faces.
*   **Strengths:** Enables real-time editing and deformation of Gaussians via mesh manipulation; avoids expensive pre-processing stages required by methods like SuGaR [S1]; supports both mesh-initialized and mesh-free inputs [S1].
*   **Limitations:** Requires a mesh (or estimated mesh) as input; performance degrades if mesh faces are highly irregular in size without subdivision [S1].
*   **When to use:** When the goal is to edit, animate, or condition 3D Gaussians using mesh-based controls (e.g., facial expressions using FLAME) [S1].
*   **When not to use:** When no mesh structure is desired or available and Triangle Soup estimation is insufficient; when high-frequency details require adaptive Gaussian density not tied to mesh topology.

## Background
GaMeS was introduced in the paper "GaMeS: Mesh-based adapting and modification of Gaussian Splatting" [S1]. It addresses the limitation of standard Gaussian Splatting, which lacks a well-defined approach for conditioning hundreds of thousands of Gaussian components [S1]. The method was demonstrated on datasets including Mip-NeRF360 and synthetic objects, and specifically used for initializing human meshes using the FLAME framework to modify facial expressions [S1]. It differs from SuGaR by not requiring SDF regularization or two-stage training [S1].
