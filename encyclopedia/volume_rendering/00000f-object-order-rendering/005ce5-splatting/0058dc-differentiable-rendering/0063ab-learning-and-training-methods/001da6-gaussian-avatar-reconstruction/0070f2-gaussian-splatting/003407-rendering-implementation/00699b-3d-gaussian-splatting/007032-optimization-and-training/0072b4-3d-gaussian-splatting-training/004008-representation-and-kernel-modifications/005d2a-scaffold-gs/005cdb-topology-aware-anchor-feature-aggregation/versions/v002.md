# Topology-Aware Anchor Feature Aggregation

Also called: Anchor Feature Aggregation, Cross-level feature aggregation

## Overview
Topology-Aware Anchor Feature Aggregation is a mechanism for aggregating features across different levels of a hierarchical anchor structure to improve texture and edge consistency in large-scale 3D Gaussian Splatting, addressing feature isolation [S1, unofficial]. It sets itself apart from sibling methods like [Scaffold-GS Integration](12513-scaffold-gs-integration.md) by explicitly enforcing topological containment relations between anchors at adjacent hierarchical levels, ensuring that feature aggregation respects the spatial hierarchy rather than treating all nearby anchors equally [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A set of anchors $\mathcal{A}$ organized into levels $L$, where each anchor $a_i$ has a position $p_i \in \mathbb{R}^3$, a level $l_i \in \mathbb{Z}$, and a feature vector $f_i$ [S1, unofficial].
*   **Output:** Aggregated features for each anchor at level $l$, incorporating information from anchors at levels $l-1$ (parents) and $l+1$ (children) [S1, unofficial].

**Data Structures**
*   **Anchor Set:** A list of anchors, each containing position $p_i$, level $l_i$, and feature $f_i$ [S1, unofficial].
*   **Indicator Masks:** Two boolean arrays $m_{par}, m_{chi} \in \{0, 1\}^N$, where $N$ is the total number of anchors. $m_i^{par}=1$ if anchor $i$ acts as a parent, $m_i^{chi}=1$ if it acts as a child [S1, unofficial]. These masks depend only on anchor positions and levels and are cached while the anchor set remains unchanged [S1, unofficial].

**Steps**

1.  **Determine Anchor Activity (Parent/Child Roles):**
    For each anchor $a_i$ at level $l_i$:
    *   **Child Role:** $a_i$ is active as a child if there exists an anchor $a_j$ at level $l_i - 1$ such that $\text{round}((p_j - o)/v_{l_i-1}) = g_{i,par}$, where $o$ is the origin, $v_{l_i-1}$ is the voxel size at level $l_i-1$, and $g_{i,par}$ is the grid coordinate of the parent voxel of $a_i$ [S1, unofficial].
    *   **Parent Role:** Symmetrically, an anchor $a_j$ at level $l_j$ is active as a parent if at least one anchor $a_i$ at level $l_j + 1$ falls within its voxel [S1, unofficial].

2.  **Encode Roles using Indicator Masks:**
    Create two indicator masks $m_{par}, m_{chi} \in \{0, 1\}^N$ encoding the parent and child roles over the full anchor set [S1, unofficial]. If anchor $i$ satisfies the condition for being a parent, $m_i^{par} = 1$, else $0$ [S1, unofficial]. Similarly for $m_i^{chi}$ [S1, unofficial].

3.  **Efficient Containment Lookup:**
    To avoid pairwise comparisons of order $|V_l| \times |V_{l \pm 1}|$, encode each grid coordinate as a 64-bit integer using a spatial hash $h(g) = (g_x p_1) \oplus (g_y p_2) \oplus (g_z p_3)$, where $g_x, g_y, g_z$ are grid coordinates, $p_1, p_2, p_3$ are large primes, and $\oplus$ is bitwise XOR [S1, unofficial]. Perform sorted lookup by binary search on the hashed coordinates to determine containment relations [S1, unofficial]. The total cost for this lookup is $O(N \log N)$ [S1, unofficial].

4.  **Compute Per-Anchor Weights:**
    Calculate weights for parent and child roles using a parameter $\alpha \in [0, 1]$:
    $$ w_i^{par} = m_i^{par} + \alpha (1 - m_i^{par}) $$
    $$ w_i^{chi} = m_i^{chi} + \alpha (1 - m_i^{chi}) $$
    Here, $\alpha$ controls the weight assigned to topologically isolated anchors; $\alpha = 1$ recovers a uniform mean, while $\alpha = 0$ assigns zero weight to anchors not in a valid containment relation [S1, unofficial].

5.  **Soft-Weighted Aggregation:**
    Compute the aggregated features for anchors at level $l$ using soft-weighted means:
    $$ A(\{f_i\}_{i \in V_{l-1}}) = \frac{\sum_{i \in V_{l-1}} w_i^{par} f_i}{\max(\max_{i \in V_{l-1}} w_i^{par}, \varepsilon)} $$
    $$ A(\{f_i\}_{i \in V_{l+1}}) = \frac{\sum_{i \in V_{l+1}} w_i^{chi} f_i}{\max(\max_{i \in V_{l+1}} w_i^{chi}, \varepsilon)} $$
    where $V_{l-1}$ and $V_{l+1}$ are the sets of parent and child anchors respectively, and $\varepsilon$ is a stability constant [S1, unofficial].

**Parameters**
*   $\alpha \in [0, 1]$: Controls the weight for isolated anchors. Typical value determined empirically via ablation study [S1, unofficial].
*   $\varepsilon = 10^{-6}$: Numerical stability constant [S1, unofficial].
*   $p_1, p_2, p_3$: Large primes for spatial hashing [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Zero Context:** When $\alpha = 0$ and no active anchor is visible in the corresponding adjacent level, the resulting context is the zero vector [S1, unofficial].
*   **Mask Caching:** The masks $m_{par}$ and $m_{chi}$ depend only on anchor positions and levels and are cached while the anchor set remains unchanged [S1, unofficial].

**Pseudocode**

```python
import numpy as np

def spatial_hash(g, p1, p2, p3):
    """Encode grid coordinates as 64-bit integer using spatial hash."""
    gx, gy, gz = g[:, 0].astype(np.int64), g[:, 1].astype(np.int64), g[:, 2].astype(np.int64)
    return (gx * p1) ^ (gy * p2) ^ (gz * p3)

def compute_masks(anchors, origin, voxel_sizes, p1, p2, p3):
    """Determine parent and child activity masks using sorted hash lookup."""
    n = len(anchors)
    m_par = np.zeros(n, dtype=np.int32)
    m_chi = np.zeros(n, dtype=np.int32)

    # Group indices by level
    levels = sorted(set(a['level'] for a in anchors))
    by_level = {l: [] for l in levels}
    for i, a in enumerate(anchors):
        by_level[a['level']].append(i)

    for l in levels:
        if l == 0 or l == max(levels):
            continue
        parent_level = l - 1
        child_level = l + 1
        v_parent = voxel_sizes[parent_level]

        # Parent level anchors
        p_indices = by_level[parent_level]
        p_pos = np.array([anchors[i]['pos'] for i in p_indices])
        p_grid = np.round((p_pos - origin) / v_parent)
        p_hashes = spatial_hash(p_grid, p1, p2, p3)
        sorted_p_hashes = np.sort(p_hashes)

        # Child level anchors (for child role check)
        c_indices = by_level[child_level]
        c_pos = np.array([anchors[i]['pos'] for i in c_indices])
        c_grid_parent = np.round((c_pos - origin) / v_parent)
        c_hashes_parent = spatial_hash(c_grid_parent, p1, p2, p3)

        # Determine child role: anchor i at level l is child if its parent voxel hash matches any parent anchor
        for idx, i in enumerate(c_indices):
            pos = np.searchsorted(sorted_p_hashes, c_hashes_parent[idx])
            if pos < len(sorted_p_hashes) and sorted_p_hashes[pos] == c_hashes_parent[idx]:
                m_chi[i] = 1

        # Determine parent role: anchor j at level l-1 is parent if any child at level l falls in its voxel
        v_child = voxel_sizes[child_level]
        c_grid_child = np.round((c_pos - origin) / v_child)
        c_hashes_child = spatial_hash(c_grid_child, p1, p2, p3)
        sorted_c_hashes = np.sort(c_hashes_child)

        for idx, j in enumerate(p_indices):
            pos = np.searchsorted(sorted_c_hashes, p_hashes[idx])
            if pos < len(sorted_c_hashes) and sorted_c_hashes[pos] == p_hashes[idx]:
                m_par[j] = 1

    return m_par, m_chi

def aggregate_features(features, m_par, m_chi, alpha, epsilon):
    """Compute soft-weighted aggregated features per level."""
    # Group features by level
    levels = sorted(set(a['level'] for a in features))
    aggregated = {}
    
    for l in levels:
        if l == 0 or l == max(levels):
            continue
        parent_level = l - 1
        child_level = l + 1
        
        # Extract indices and features for adjacent levels
        p_indices = [i for i, a in enumerate(features) if a['level'] == parent_level]
        c_indices = [i for i, a in enumerate(features) if a['level'] == child_level]
        
        # Compute weights
        w_par = m_par[p_indices] + alpha * (1 - m_par[p_indices])
        w_chi = m_chi[c_indices] + alpha * (1 - m_chi[c_indices])
        
        # Soft-weighted mean for parent context
        if len(p_indices) > 0:
            num_par = np.sum(w_par[:, np.newaxis] * features[p_indices], axis=0)
            den_par = np.maximum(np.max(w_par), epsilon)
            aggregated[parent_level] = num_par / den_par
            
        # Soft-weighted mean for child context
        if len(c_indices) > 0:
            num_chi = np.sum(w_chi[:, np.newaxis] * features[c_indices], axis=0)
            den_chi = np.maximum(np.max(w_chi), epsilon)
            aggregated[child_level] = num_chi / den_chi
            
    return aggregated
```

## Operating characteristics
*   **Time Complexity:** The lookup cost for determining containment relations is $O(N \log N)$ due to the sorted binary search on hashed coordinates [S1, unofficial].
*   **Memory Complexity:** Requires storage for indicator masks $m_{par}, m_{chi}$ and cached hashes [S1, unofficial]. The masks are cached while the anchor set remains unchanged [S1, unofficial].
*   **Performance:** On the MatrixCity benchmark, TopoGS improves over Geo-GS by approximately 0.45 dB in PSNR [S1, unofficial]. On the WHU benchmark, it achieves 40.68 dB PSNR on WHU-Area 1, 40.61 dB on WHU-Area 4, and 37.18 dB on WHU-Area 5 [S1, unofficial]. It also reduces LPIPS from 0.137 to 0.084 on the Truck scene, a relative reduction of approximately 39% [S1, unofficial].
*   **Strengths:** Improves texture and edge consistency; produces smoother normals and cleaner depth without additional geometric supervision; stable across different scene types, capture modalities, and benchmark saturation levels [S1, unofficial].
*   **Limitations:** Performance depends on the hierarchical structure and anchor distribution; $\alpha$ needs empirical tuning [S1, unofficial].

## Background
Topology-Aware Anchor Feature Aggregation is used in TopoGS, which is built on the CityGS-X backbone [S1, unofficial]. It was introduced to address feature isolation in large-scale 3D Gaussian Splatting by leveraging the topological relationships between anchors at different hierarchical levels [S1, unofficial]. The method was proposed in the paper "TopoGS: Topology-Aware Anchor Feature Aggregation for Large-Scale 3D Gaussian Splatting" [S1, unofficial].
