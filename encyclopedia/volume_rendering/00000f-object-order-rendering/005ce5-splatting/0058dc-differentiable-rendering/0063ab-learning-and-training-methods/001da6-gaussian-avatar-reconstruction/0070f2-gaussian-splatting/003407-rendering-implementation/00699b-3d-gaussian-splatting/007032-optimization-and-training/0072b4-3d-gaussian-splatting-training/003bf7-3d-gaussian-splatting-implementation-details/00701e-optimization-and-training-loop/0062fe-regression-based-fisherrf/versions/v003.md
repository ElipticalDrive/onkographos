# Regression-based FisherRF

Also called: FisherRF with meta-regression, Modified FisherRF

## Overview
Regression-based FisherRF is a variant of the FisherRF uncertainty estimation method that replaces the direct aggregation of color parameter variances with a meta-regression model to predict pixel-wise uncertainty [S1, unofficial]. While standard FisherRF estimates uncertainty by summing the variances of all spherical harmonic parameters to determine color direction-dependence, this method groups Gaussian primitive parameter variances into six distinct categories and feeds them as feature maps into a regression network [S1, unofficial]. It is primarily used as a baseline for comparing uncertainty estimation quality in scene separation and out-of-scene generalization experiments [S1, unofficial].

## How it works
**Inputs:**
*   The set of $N$ 3D Gaussian primitives $\mathcal{G} = \{g_i\}_{i=1}^N$ optimized during training [S1, unofficial].
*   For each primitive $g_i$, the variance of its parameters: mean $\mathbf{p}_i$, scale $\mathbf{s}_i$, rotation $\mathbf{q}_i$, opacity $\alpha_i$, and spherical harmonic coefficients $\mathbf{c}_{i, l}$ [S1, unofficial].

**Outputs:**
*   A set of six uncertainty feature maps, one for each parameter group, which serve as input to a regression model to predict pixel-wise uncertainty [S1, unofficial].

**Data Structures:**
The method relies on grouping the variances of Gaussian parameters into six specific categories, originating from the standard 3D Gaussian Splatting implementation [S1, unofficial]:
1.  **Mean:** Variance of the position $\mathbf{p}_i \in \mathbb{R}^3$.
2.  **Scale:** Variance of the scale vector $\mathbf{s}_i \in \mathbb{R}^3$.
3.  **Rotation:** Variance of the rotation quaternion $\mathbf{q}_i \in \mathbb{R}^4$.
4.  **Opacity:** Variance of the opacity scalar $\alpha_i \in [0, 1]$.
5.  **SH Degree 0:** Variance of the spherical harmonic coefficients for degree zero (view-independent color).
6.  **SH Higher Degree:** Variance of the spherical harmonic coefficients for degrees $>0$ (view-dependent color).

Note that the Scale and Rotation groups correspond to the covariance matrix $\Sigma_i$ of the primitive [S1, unofficial].

**Steps:**
1.  **Compute Parameter Variances:** For each Gaussian primitive $g_i$, calculate the variance of each parameter group. Let $Var(\cdot)$ denote the variance operator.
    *   $V_{mean, i} = Var(\mathbf{p}_i)$
    *   $V_{scale, i} = Var(\mathbf{s}_i)$
    *   $V_{rot, i} = Var(\mathbf{q}_i)$
    *   $V_{op, i} = Var(\alpha_i)$
    *   $V_{sh0, i} = Var(\mathbf{c}_{i, 0})$
    *   $V_{sh>0, i} = Var(\{\mathbf{c}_{i, l}\}_{l > 0})$
2.  **Aggregate into Feature Maps:** Project the variances of all $N$ primitives onto the image plane using the standard differentiable rasterization/splatting pipeline . Aggregate the variances per pixel to form six uncertainty feature maps $F_1, \dots, F_6$. For a pixel $u$, the value of the $k$-th feature map is the sum of the variances of the $k$-th parameter group for all Gaussians splatting to $u$:
    $$ F_k(u) = \sum_{i \in \text{rasterized}(u)} V_{group_k, i} $$
    where $group_k \in \{mean, scale, rotation, opacity, sh0, sh>0\}$ [S1, unofficial].
3.  **Meta-Regression:** Feed the six feature maps $\{F_1, \dots, F_6\}$ into a regression model (e.g., a neural network) [S1, unofficial].
4.  **Predict Uncertainty:** The regression model outputs the predicted pixel-wise uncertainty [S1, unofficial].

**Pseudocode:**
```python
def regression_based_fisherrf(gaussians, rasterizer, regression_model):
    """
    gaussians: List of Gaussian primitives with parameters p, s, q, alpha, c_sh
    rasterizer: Function that projects 3D Gaussians to 2D image plane
    regression_model: A neural network taking 6 input channels and outputting uncertainty
    """
    # Step 1: Compute variances for each primitive
    # Note: In practice, these variances are obtained from the optimizer's state 
    # or accumulated gradients during training [S1, unofficial].
    variances = []
    for g in gaussians:
        v_mean = compute_variance(g.p)
        v_scale = compute_variance(g.s)
        v_rot = compute_variance(g.q)
        v_op = compute_variance(g.alpha)
        v_sh0 = compute_variance(g.c_sh[0])
        v_sh_high = compute_variance(g.c_sh[1:]) # All degrees > 0
        variances.append({
            'mean': v_mean,
            'scale': v_scale,
            'rotation': v_rot,
            'opacity': v_op,
            'sh0': v_sh0,
            'sh_high': v_sh_high
        })

    # Step 2: Aggregate variances into 6 feature maps
    # The rasterizer must support accumulating variance values, not just opacity/color
    feature_maps = [0.0] * 6
    for g in gaussians:
        v = variances[g.index]
        # Project variances to image plane
        # This step assumes a custom rasterizer that accumulates variance sums
        # similar to how it accumulates opacity and color
        projected = rasterizer.project_variance_sum(g, v)
        
        # Add projected variance to the corresponding feature map channels
        # Assuming projected is a tensor of shape (H, W, 6) or similar
        feature_maps[0] += projected['mean']
        feature_maps[1] += projected['scale']
        feature_maps[2] += projected['rotation']
        feature_maps[3] += projected['opacity']
        feature_maps[4] += projected['sh0']
        feature_maps[5] += projected['sh_high']

    # Step 3: Feed feature maps into regression model
    # Stack the 6 feature maps into a single tensor of shape (6, H, W)
    input_tensor = torch.stack(feature_maps, dim=0)
    
    # Step 4: Predict uncertainty
    predicted_uncertainty = regression_model(input_tensor)
    
    return predicted_uncertainty

def compute_variance(param):
    # [G] Placeholder for the specific variance calculation method.
    # In the context of FisherRF, this typically refers to the diagonal 
    # entries of the Fisher Information Matrix or the optimizer's 
    # accumulated second-moment estimates.
    return param.variance
```

**Edge Cases and Pitfalls:**
*   **Variance Calculation:** The method assumes access to the variance of the Gaussian parameters. In standard 3DGS, these are not explicitly stored as simple scalars but are derived from the Fisher Information Matrix or optimizer states [S1, unofficial]. The exact computation of $Var(\cdot)$ for quaternion and SH coefficients requires careful handling of their non-Euclidean or high-dimensional nature [G].
*   **Rasterization of Variance:** Standard splatting rasterizers accumulate opacity and color. A custom rasterizer is required to accumulate the *sum of variances* for each parameter group per pixel [S1, unofficial].
*   **Grouping Consistency:** The grouping must strictly follow the six categories defined in the original GS implementation to ensure fair comparison with other methods [S1, unofficial].

## Operating characteristics
*   **Complexity:** The method adds the overhead of a regression model inference step on top of the standard rasterization. The rasterization step itself must be modified to accumulate six variance channels instead of just opacity and color, increasing memory bandwidth and compute slightly [S1, unofficial].
*   **Performance:** No specific quantitative performance metrics (FPS, memory usage) are provided in the sources [S1, unofficial].
*   **Strengths:** Aligns the uncertainty estimation pipeline with modern meta-regression approaches (like PRIMU), allowing for fair comparison of feature map quality [S1, unofficial]. Separates uncertainty sources by parameter type (e.g., position vs. color), potentially providing more granular uncertainty signals than the original FisherRF which sums all color variances [S1, unofficial].
*   **Limitations:** Requires a custom rasterizer and a trained regression model, adding complexity compared to the direct summation method of original FisherRF [S1, unofficial].

## Background
*   **Origin:** Regression-based FisherRF was introduced in the study of Uncertainty Estimation (UE) for Gaussian Splatting, specifically in the context of the PRIMU method [S1, unofficial].
*   **History:** It is a modification of the original FisherRF method [11], which is based on the Fisher information matrix of a Gaussian Splatting primitive with respect to the gradient of the rendering function [S1, unofficial]. The original FisherRF used the sum of color parameter variances (including all SH parameters) to estimate direction-dependent uncertainty [S1, unofficial].
*   **Usage:** It is used as a baseline for UE scene separation studies and out-of-scene generalization experiments [S1, unofficial].
