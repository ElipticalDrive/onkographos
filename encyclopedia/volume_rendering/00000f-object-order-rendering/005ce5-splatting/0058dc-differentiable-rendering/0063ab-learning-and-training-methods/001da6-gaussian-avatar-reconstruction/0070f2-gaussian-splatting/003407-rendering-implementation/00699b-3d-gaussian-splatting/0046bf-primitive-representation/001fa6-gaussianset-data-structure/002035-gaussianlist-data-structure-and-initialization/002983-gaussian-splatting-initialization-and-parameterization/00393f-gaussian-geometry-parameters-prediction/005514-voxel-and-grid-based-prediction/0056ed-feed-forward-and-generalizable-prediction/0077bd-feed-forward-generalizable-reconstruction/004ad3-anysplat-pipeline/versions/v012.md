# AnySplat Pipeline

Also called: Feed-forward 3D Gaussian Splatting from Unconstrained Views

## Overview
The AnySplat Pipeline is a feed-forward method that predicts a dense set of 3D Gaussians directly from uncalibrated input images, bypassing iterative per-scene optimization [S1, unofficial]. It differs from sibling methods by explicitly predicting camera poses and depth alongside Gaussian parameters, using a differentiable voxelization step to regularize the output before rendering [S1, unofficial].

## How it works
The pipeline maps input images to a voxelized Gaussian field using a transformer-based encoder and three decoder heads.

**Inputs and Outputs**
*   **Input:** A tensor of $K$ uncalibrated images with shape $[1, K, 3, 448, 448]$ (batch, views, channels, height, width) [S1, unofficial].
*   **Outputs:** A set of voxelized 3D Gaussians and predicted camera poses (extrinsic and intrinsic matrices) [S1, unofficial].

**Data Structures**
The Gaussian parameters are predicted per-pixel, resulting in a parameter map. The specific fields for each Gaussian are mean position $\mu$, scale $\sigma$, rotation $r$, scale factor $s$, and color $c$ [S1, unofficial]. These are voxelized into "pre-voxel 3D Gaussians" [S1, unofficial].

**Steps**
1.  **Encoding:** Input images are normalized to $[-1, 1]$ and passed through a transformer-based geometry encoder [S1, unofficial].
2.  **Decoding:** Three decoder heads ($F_G, F_D, F_C$) predict:
    *   $F_G$: Gaussian parameters ($\mu, \sigma, r, s, c$) [S1, unofficial].
    *   $F_D$: A depth map $D$ [S1, unofficial].
    *   $F_C$: Camera poses $p$ [S1, unofficial].
3.  **Construction:** Pixel-wise 3D Gaussians are constructed from the predicted parameters [S1, unofficial].
4.  **Voxelization:** The constructed Gaussians are processed by a Differentiable Voxelization module to create pre-voxel 3D Gaussians [S1, unofficial].
5.  **Rendering:** Multi-view images and depth maps are rendered from the voxelized Gaussians using differentiable rasterization [S1, unofficial].
6.  **Loss Computation:**
    *   **RGB Loss:** Rendered images are compared against ground truth images [S1, unofficial].
    *   **Geometry Loss:** Rendered depth maps, decoded depth $D$, and predicted poses $p$ are used to compute geometry losses [S1, unofficial].
7.  **Supervision:** Geometries are supervised by pseudo-geometry priors obtained from a pretrained VGGT model [S1, unofficial].

*   Image resolution: 448x448 [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Uncalibrated Input:** The method handles uncalibrated images, but accuracy depends on the quality of the pseudo-geometry priors from VGGT [S1, unofficial].
*   **Voxelization:** The differentiable voxelization step is critical for regularizing the Gaussian distribution; skipping it may lead to artifacts [S1, unofficial].

## Subtopics

### [SubSplat](13524-subsplat.md)
SubSplat is a method for high-resolution novel-view synthesis that resolves the trade-off between network computational cost and rendering fidelity in pixel-aligned 3D Gaussian Splatting. It solves the problem of insufficient Gaussian density and artifacts when using low-resolution backbone inputs by introducing a Sub-pixel Gaussian Reparameterizer (SPGR). Unlike prior methods limited by fixed grids or image-space upsamplers, SubSplat subdivides each grid-anchored primary Gaussian into multiple fine-grained sub-pixel primitives, restoring structural density directly from low-resolution features while maintaining stable network latency.

### [Deformable Radial Kernel (DRK)](13699-deformable-radial-kernel-drk.md)
Deformable Radial Kernel (DRK) Splatting is a 3D scene representation method that replaces the fixed radial symmetry of Gaussian primitives with a flexible planar kernel defined by multiple radial basis functions. It solves the overparameterization and geometric fidelity limitations of Gaussian Splatting by allowing adaptive stretching, rotation, and sharp boundary control, enabling high-fidelity rendering with significantly fewer primitives. Unlike standard 2D Gaussian Splatting, which relies on smooth, elliptical distributions, DRK supports straight edges and sharp corners through L1/L2 norm blending and piecewise edge sharpening.
