# Sensitivity-Aware Vector Clustering

Also called: Niedemayr et al. compression, Niedermayr, Sensitivity-Aware Scene Compression, Sensitivity-Aware Vector Clustering for 3DGS Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering spherical harmonic (SH) coefficients and Gaussian shape parameters (scale and rotation) into compact codebooks [S1, S2]. It distinguishes itself from standard post-training quantization by deriving a sensitivity measure for each parameter to weight the clustering distance, thereby prioritizing the preservation of parameters that significantly affect image quality [S1, S2].

## How it works
**Inputs:** A set of optimized 3D Gaussians $\{G_i\}$, where each $G_i$ is defined by position $\mu_i$, scale $\hat{s}_i$, rotation $r_i$ (quaternion), opacity $o_i$, and SH coefficients $c_i$ [S1]. A training set of $N$ images with known camera parameters [S1].
**Outputs:** Two codebooks $C_{color}$ and $C_{shape}$, and for each Gaussian, two indices $idx_{color}$ and $idx_{shape}$ pointing to entries in these codebooks [S1].

**Data Structures:**
*   **Codebook Entry (Color):** Stores SH coefficients. The dimension $D$ depends on the SH degree (e.g., $D=48$ for degree 3) [S1].
*   **Codebook Entry (Shape):** Stores 7 scalar values: 4 for the quaternion (rotation) and 3 for the scaling vector [S1].
*   **Index:** Indices into the codebooks are stored as 32-bit unsigned integers [S1].

**Sensitivity Calculation:**
The sensitivity $S(p)$ of a parameter $p$ is defined as the normalized gradient of the total image energy $E$ with respect to $p$ [S1, S2]:
$$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p}}{\sum_{i=1}^{N} P_i} $$
where $E_i$ is the image energy (sum of RGB components) for image $i$, and $P_i$ is the number of pixels in image $i$ [S1, S2]. The sensitivity of a vector $x$ is defined as the maximum sensitivity over its components:
$$ S(x) = \max_d S(x_d) $$
This is computed via a single backward pass over each training image [S1].

**Clustering Algorithm:**
1.  **Initialization:** Initialize codebook centroids randomly with a uniform distribution within the minimum and maximum values of each parameter [S1].
2.  **Thresholding:** Calculate $S(x)$ for all vectors. Vectors with sensitivity higher than a threshold $\beta$ (e.g., $\beta_c$ for color, $\beta_g$ for shape) are excluded from clustering and added directly to the codebook [S1].
3.  **Weighted Distance:** For remaining vectors, the distance to a centroid $c_k$ is weighted by the vector's sensitivity:
    $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
4.  **Assignment:** Assign each vector $x$ to the centroid $c_k$ with the minimum weighted distance [S1].
5.  **Centroid Update:** Update centroids using a weighted average:
    $$ c_k = \frac{1}{\sum_{x_i \in A(k)} S(x_i)} \sum_{x_i \in A(k)} S(x_i) x_i $$
    where $A(k)$ is the set of vectors assigned to centroid $c_k$ [S1].
6.  **Batched Strategy:** To handle large datasets, a random subset of vectors is picked in each update step [S1]. Centroids are updated using a moving average with decay factor $\lambda_d$:
    $$ c_k^{new} = \lambda_d c_k^{old} + (1 - \lambda_d) c_k^{updated} $$
7.  **Renormalization:** For shape parameters, clustering normalized covariance matrices may result in non-unit scaling vectors due to floating-point errors [S1]. Each codebook vector is re-normalized after each update step by dividing it through the trace of the covariance metric [S1].
8.  **Decomposition:** After clustering, each codebook entry for shape is decomposed into rotation (quaternion) and scale parameters using eigenvalue decomposition [S1].

**Quantization-Aware Training (QAT):**
To recover quality lost during clustering, parameters are fine-tuned on the training set [S1, S2].
*   **Forward Pass:** Simulate quantization using Min-Max Quantization, considering a certain number of bits and the moving average of each parameter's min/max values [S2].
*   **Backward Pass:** Ignore simulated quantization and calculate gradients for the continuous parameters [S2].
*   **Loss:** Standard reconstruction loss plus a D-SSIM term with weight $\lambda$ (typically 0.2) [S2].

**Compression:**
1.  Store indices for each Gaussian [S1].
2.  Order Gaussians by Z-order (Morton order) to exploit spatial coherence [S1, S2].
3.  Compress the set of Gaussians and codebooks using DEFLATE (LZ77 + Huffman) [S1, S2].

**Pseudocode:**

```python
import numpy as np

def compute_morton_order(positions):
    """
    Compute Z-order (Morton) codes for 3D positions.
    positions: (N, 3) array of float32 coordinates.
    Returns: (N,) array of uint64 Morton codes.
    """
    min_pos = positions.min(axis=0)
    max_pos = positions.max(axis=0)
    range_pos = max_pos - min_pos + 1e-6
    int_pos = ((positions - min_pos) / range_pos * (2**21 - 1)).astype(np.uint32)
    
    morton = np.zeros(len(int_pos), dtype=np.uint64)
    for i in range(21):
        mask = 1 << i
        morton |= (int_pos[:, 0] & mask) << (2 * i)
        morton |= (int_pos[:, 1] & mask) << (2 * i + 1)
        morton |= (int_pos[:, 2] & mask) << (2 * i + 2)
    return morton

def sensitivity_aware_kmeans(vectors, sensitivities, centroids, lambda_d, max_iters, batch_size):
    """
    Perform sensitivity-aware k-Means clustering with batched updates.
    vectors: (N, D) array of input vectors.
    sensitivities: (N,) array of sensitivities for each vector.
    centroids: (K, D) array of initial centroids.
    lambda_d: decay factor for moving average.
    max_iters: maximum number of update steps.
    batch_size: number of vectors sampled per step.
    """
    K = centroids.shape[0]
    N = vectors.shape[0]
    
    for step in range(max_iters):
        # 1. Sample batch
        batch_idx = np.random.choice(N, batch_size, replace=False)
        batch_vecs = vectors[batch_idx]
        batch_sens = sensitivities[batch_idx]
        
        # 2. Compute weighted distances: D(x, ck) = S(x) * ||x - ck||^2
        diff = batch_vecs[:, np.newaxis, :] - centroids[np.newaxis, :, :]
        sq_dist = np.sum(diff**2, axis=2)
        weighted_dist = batch_sens[:, np.newaxis] * sq_dist
        
        # 3. Assign to nearest centroid
        assignments = np.argmin(weighted_dist, axis=1)
        
        # 4. Compute batch centroid updates
        new_centroids = centroids.copy()
        for k in range(K):
            mask = assignments == k
            if np.sum(mask) > 0:
                assigned_vecs = batch_vecs[mask]
                assigned_sens = batch_sens[mask]
                weight_total = np.sum(assigned_sens)
                centroid_update = np.sum(assigned_sens[:, np.newaxis] * assigned_vecs, axis=0) / weight_total
                # Moving average update
                new_centroids[k] = lambda_d * centroids[k] + (1 - lambda_d) * centroid_update
        
        centroids = new_centroids
        
        # 5. Renormalization for shape parameters (trace normalization)
        # Note: Applied only to shape codebook entries per source [S1]
        # traces = np.sqrt(np.sum(centroids**2, axis=1)) # Simplified for normalized vectors
        # centroids = centroids / traces[:, np.newaxis]
        
    return centroids

def compress_gaussians(gaussians, color_codebook, shape_codebook):
    """
    Compress Gaussians using indices and Morton order.
    """
    # 1. Find indices
    color_indices = np.argmin(np.linalg.norm(gaussians['color'][:, np.newaxis, :] - color_codebook[np.newaxis, :, :], axis=2), axis=1)
    shape_indices = np.argmin(np.linalg.norm(gaussians['shape'][:, np.newaxis, :] - shape_codebook[np.newaxis, :, :], axis=2), axis=1)
    
    # 2. Sort by Morton order
    morton_codes = compute_morton_order(gaussians['position'])
    sorted_indices = np.argsort(morton_codes)
    
    sorted_color_indices = color_indices[sorted_indices]
    sorted_shape_indices = shape_indices[sorted_indices]
    
    # 3. Compress the set of Gaussians and codebooks using DEFLATE (LZ77 + Huffman) [S1, S2].
    # compressed_data = deflate(np.concatenate([sorted_color_indices, sorted_shape_indices]))
    
    return sorted_color_indices, sorted_shape_indices
```

## Operating characteristics
*   **Compression Ratio:** Achieves up to 31× compression on real-world scenes with minimal visual degradation [S1].
*   **Rendering Speed:** Enables real-time rendering on lightweight GPUs, up to 4× higher framerates than optimized GPU compute pipelines for uncompressed scenes [S1].
*   **Memory:** Reduces storage from $N \times D$ floats to $N \times \text{bits}(\text{index}) + |C| \times D$ floats [S1].
*   **Strengths:** Preserves high-impact parameters, leading to better visual quality at low bitrates compared to uniform quantization [S1].
*   **Limitations:** Requires a sensitivity calculation step (backward pass) and iterative clustering, which adds to the preprocessing time [S1].
*   **Parameters:**
    *   Codebook size $K$: 4096 [S1].
    *   Decay factor $\lambda_d$: 0.8 [S1].
    *   Batch size (color): $2^{18}$ [S1].
    *   Batch size (shape): $2^{20}$ [S1].
    *   Sensitivity threshold $\beta_c$: $6 \times 10^{-7}$ [S1].
    *   Sensitivity threshold $\beta_g$: $3 \times 10^{-6}$ [S1].
    *   QAT steps: 5000 [S1].

## Background
Proposed by Niedemayr et al. in 2024, this method addresses the high memory consumption of 3D Gaussian Splatting, making it suitable for network streaming and low-power devices [S1]. It builds on the observation that SH coefficients and Gaussian shape parameters are highly redundant and that sensitivity to image quality varies significantly across parameters [S1].
