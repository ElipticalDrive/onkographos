# Hybrid and Diffusion Representations

Also called: TriplaneGaussian, GaussianDiffusion, Atomic-Continuous Priors

## Overview
This family addresses the generation and initialization of 3D Gaussian Splatting (3DGS) representations from implicit or single-view inputs, solving the problem of constructing high-fidelity, consistent 3D scenes without iterative per-scene optimization. It sets itself apart from sibling methods like [Adaptive Density Control](9188-adaptive-density-control.md) by replacing iterative densification heuristics with learned generative priors (diffusion or feed-forward networks) that directly output primitive attributes.

## Shared principles
All methods in this family operate on a set of 3D Gaussian primitives $\mathcal{G} = \{g_1, \dots, g_N\}$, where each $g_k$ is defined by a mean position $\mu_k \in \mathbb{R}^3$, a covariance matrix $\Sigma_k$ (parameterized by scale $s_k$ and rotation $q_k$), opacity $\alpha_k$, and spherical harmonic coefficients $\mathbf{c}_k$.

Unlike iterative optimization methods, these approaches typically employ a generative model (diffusion or feed-forward) to predict the parameters of $\mathcal{G}$ directly from a conditioning signal (e.g., text, single image, or previous frame). The core challenge is bridging the gap between continuous latent spaces (diffusion) or 2D feature grids (triplanes) and the discrete, unstructured set of 3D Gaussians.

Common mechanisms include:
1.  **Representation Conversion:** Mapping the continuous Gaussian set to a structured grid for processing. For diffusion models, this often involves voxelization via optimal transport to create a fixed-size representation (e.g., GaussianCube) [S1].
2.  **Structured Conditioning:** Incorporating multi-view consistency constraints during generation to mitigate artifacts like the "Janus problem" (inconsistent views) or "floaters" (spurious geometry) [S1].
3.  **Hybrid Feature Fusion:** Combining spatial feature encodings (e.g., tri-planes) with point cloud data to predict attributes, allowing the model to leverage 2D priors while maintaining 3D geometric flexibility [S1].

## Subtopics

### [TriplaneGaussian](7558-triplanegaussian.md)
TriplaneGaussian is a feed-forward method for generating 3D Gaussian Splatting (3DGS) representations from a single input image. It solves the problem of single-image 3D reconstruction by proposing a hybrid representation that combines a 3D point cloud with a tri-plane encoding of Gaussian attributes. Unlike methods that directly optimize texture or rely on multi-view inputs, TriplaneGaussian generates the point cloud and attribute encoding separately through dedicated decoders, then fuses them to produce the final 3DGS primitives. See [TriplaneGaussian](7558-triplanegaussian.md) for implementation details.

### [GaussianDiffusion](9190-gaussiandiffusion.md)
GaussianDiffusion is a method that trains a 3D diffusion model based on a GaussianCube representation to generate 3D Gaussian Splatting (3DGS) fields directly. It solves the problem of multi-view inconsistency (the "Janus problem") and the generation of spurious geometry ("floaters") common in text-to-3D pipelines by incorporating structured noises from multiple viewpoints and using variational 3DGS. It differs from its sibling TriplaneGaussian by operating on a voxelized Gaussian representation converted via optimal transport rather than a triplane-based feature grid. See [GaussianDiffusion](9190-gaussiandiffusion.md) for implementation details.

### Text2Immersion
#### definition
A scene generation method similar to LucidDreamer but with outlier removal and two-stage optimization [S1].
#### step
A process removes outliers in the point cloud [S1]. 3DGS optimization has two stages: training coarse 3DGS and refinement [S1].

### Atomic-Continuous Prior
#### definition
A probabilistic prior for VDB volumes that models the data as a mixture of a discrete atomic component (exact zeros for empty space) and a continuous component (real density values). It solves the problem where plain Gaussian diffusion smooths away faint wisps and leaks density into empty regions due to the mix of exact zeros and heavy-tailed densities [S2].
#### step
Amplitude companding: Apply a reversible log mapping to rebalance the training signal. This boosts the gradient on faint, low-density structures by a factor of $(1 + \lambda\tilde{x})^{-1}$ to prevent thin wisps from being smoothed away [S2]. Atomic mass supervision: Enforce sparsity by using a soft occupancy target to recover coarse shape and applying a leakage penalty that pushes density to exactly zero outside the boundary [S2]. Temporal conditioning (for sequences): Stack the previous frame onto the input as an extra channel. The network learns motion from this concatenated input without using 4D attention [S2].
#### formula
$p(x) = \pi_0\delta_0(x) + (1-\pi_0)p_{ac}(x)$, where $\pi_0$ is the probability mass at zero, $\delta_0(x)$ is the Dirac delta function at zero, and $p_{ac}(x)$ is the continuous probability density function for non-zero values [S2].

## Background
The need for hybrid and diffusion representations arises from the limitations of iterative 3DGS optimization, which is computationally expensive and prone to local minima or inconsistent geometry when initialized from sparse or single-view data. Early works like Text2Immersion [S1] introduced two-stage optimization with outlier removal to improve initial point cloud quality. Subsequent research explored generative models: TriplaneGaussian [S1] adapted 2D image priors (triplanes) to 3DGS generation, while GaussianDiffusion [S1] applied diffusion models to voxelized Gaussian representations to enforce multi-view consistency. In the context of volumetric data (VDB), Atomic-Continuous Priors [S2] addressed the specific challenge of modeling sparse, high-contrast volumes where standard diffusion fails to preserve sharp boundaries and empty space.
