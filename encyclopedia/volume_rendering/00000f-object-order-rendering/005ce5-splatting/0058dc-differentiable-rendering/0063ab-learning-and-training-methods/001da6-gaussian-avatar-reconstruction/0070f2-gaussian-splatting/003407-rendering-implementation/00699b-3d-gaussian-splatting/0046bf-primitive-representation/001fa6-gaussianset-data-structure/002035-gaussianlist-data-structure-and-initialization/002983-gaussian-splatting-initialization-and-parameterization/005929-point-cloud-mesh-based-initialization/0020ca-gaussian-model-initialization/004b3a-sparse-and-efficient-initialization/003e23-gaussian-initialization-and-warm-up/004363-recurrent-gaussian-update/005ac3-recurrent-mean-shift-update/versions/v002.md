# Recurrent Mean-Shift Update

Also called: Holistic separability update, Mean-shift update

## Overview
The Recurrent Mean-Shift Update is a regularization step applied to the descriptor parameters of 3D Gaussians to enforce holistic separability across the entire scene [S1]. It addresses the limitation where local segmentation losses only distinguish descriptors within individual image views, failing to ensure consistency for the same 3D plane instance across different camera viewpoints [S1]. By applying a mean-shift operation based on the von Mises-Fisher distribution, it globally aligns similar descriptors and separates dissimilar ones, improving plane instance segmentation [S1].

## How it works
**Inputs and Outputs:**
- Input: $\mathbf{Z}$, a matrix of shape $(N, D)$ containing the $D$-dimensional descriptor vectors for $N$ Gaussians [S1].
- Output: Updated $\mathbf{Z}$ with enhanced separability [S1].

**Data Structures:**
- $\mathbf{Z}$: Matrix where each row $\mathbf{z}_i$ is the descriptor for the $i$-th Gaussian [S1].
- $\mathbf{K}$: Kernel matrix of shape $(D, D)$ [S1].
- $\mathbf{D}$: Diagonal matrix of shape $(D, D)$ [S1].
- $\mathbf{I}$: Identity matrix of shape $(D, D)$ [S1].

**Parameters:**
- $\eta$ (eta): Update rate for the mean-shift equation [S1].
- $\gamma$ (gamma): Kernel bandwidth determining the smoothness of the kernel density estimation [S1].
- Typical values for $\eta$ and $\gamma$ are not given in the sources [S1].
- The number of update steps per cycle and the frequency $N$ are not given in the sources [S1].

**Formulas:**
The update rule is defined as [S1]:
$$ \mathbf{Z} \leftarrow \mathbf{Z} \cdot (\eta \cdot \mathbf{K} \cdot \mathbf{D}^{-1} + (1-\eta) \cdot \mathbf{I}) $$
Where:
1. $\mathbf{K}$ is the von Mises-Fisher (vMF) kernel matrix: $\mathbf{K} = \exp(\gamma \cdot \mathbf{Z}^T \cdot \mathbf{Z})$ [S1].
2. $\mathbf{D}$ is a diagonal matrix: $\mathbf{D} = \text{diag}(\mathbf{K}^T \cdot \mathbf{I})$ [S1].
3. $\mathbf{I}$ is the identity matrix [S1].

**Steps:**
1. Compute the pairwise dot product matrix $\mathbf{S} = \mathbf{Z}^T \cdot \mathbf{Z}$ [S1].
2. Compute the kernel matrix $\mathbf{K} = \exp(\gamma \cdot \mathbf{S})$ using element-wise exponentiation [S1].
3. Extract the diagonal elements of $\mathbf{K}$ to form the vector $\mathbf{d}$ [S1].
4. Construct the diagonal matrix $\mathbf{D}$ from $\mathbf{d}$ [S1].
5. Compute the update matrix $\mathbf{M} = \eta \cdot \mathbf{K} \cdot \mathbf{D}^{-1} + (1-\eta) \cdot \mathbf{I}$ [S1].
6. Update the descriptors: $\mathbf{Z} \leftarrow \mathbf{Z} \cdot \mathbf{M}$ [S1].
7. Repeat steps 1–6 for a few steps every $N$ iterations of the main optimization process [S1].

**Pseudocode:**
```python
import numpy as np

def recurrent_mean_shift_update(Z, eta, gamma, num_steps):
    """
    Applies the recurrent mean-shift update to Gaussian descriptors Z.
    
    Args:
        Z: numpy array of shape (N, D), descriptor matrix.
        eta: float, update rate.
        gamma: float, kernel bandwidth.
        num_steps: int, number of mean-shift iterations to perform.
        
    Returns:
        Z: Updated descriptor matrix.
    """
    # Compute pairwise dot products: Z^T @ Z yields shape (D, D)
    K = np.exp(gamma * (Z.T @ Z))
    
    # Extract diagonal of K and compute its inverse
    D_diag = np.diag(K)
    D_inv_diag = 1.0 / D_diag
    
    # Construct diagonal matrix D_inv
    D_inv_mat = np.diag(D_inv_diag)
    
    # Compute update matrix M
    I_D = np.eye(K.shape[0])
    M = eta * (K @ D_inv_mat) + (1 - eta) * I_D
    
    # Apply update for the specified number of steps
    for _ in range(num_steps):
        Z = Z @ M
        
    return Z
```

**Edge Cases and Pitfalls:**
- **Large N:** The number of Gaussians in the scene can be very large, requiring an efficient computation method for the update equation [S1].
- **Precision:** Division by zero in $\mathbf{D}^{-1}$ is avoided because the exponential function $\exp(\cdot)$ always yields positive values, ensuring diagonal elements of $\mathbf{K}$ are strictly positive [G].
- **Boundaries:** The update is applied every $N$ iterations rather than every optimization step to stabilize the training process [S1].

## Subtopics

### Holistic Separability of Gaussian Descriptors
This variant applies the Recurrent Mean-Shift Update to improve the separability of descriptors for all 3D plane instances across the entire scene [S1]. It models the descriptors using the von Mises-Fisher distribution on the sphere [S1]. It sets itself apart by enforcing global consistency across the scene rather than relying solely on local discriminative power within individual views [S1].

## Operating characteristics
- **Time and Memory Complexity:** Not given in the sources.
- **Measured Performance:** Ablation studies demonstrate that encouraging holistic separability provides effective performance improvement on plane segmentation [S1].
- **Strengths and Limitations:** The method improves segmentation accuracy by resolving ambiguities between planes that are not jointly visible in any single view [S1]. It requires tuning of $\eta$ and $\gamma$ [S1].
- **When to use:** It is used during the optimization of 3D plane instance segmentation when local view-based losses are insufficient for global descriptor consistency [S1].
- **When not to use:** It is not used when descriptors are not employed for plane segmentation tasks [S1].

## Background
The method originates from Planar Gaussian Splatting (PGS) [S1]. It builds on the concept of representing scenes using 3D planes defined by merging local geometries through 3D Gaussian distributions [S1]. The approach introduces a recurrent mean-shift update [18] to maintain holistic separability of descriptors without requiring explicit 2D or 3D plane annotations [S1].
