# iVR-GS Training

Also called: iVR-GS Optimization, Inverse Volume Rendering Gaussian Splatting Training

## Overview
iVR-GS Training is the optimization procedure for Inverse Volume Rendering Gaussian Splatting (iVR-GS), a method that extends 3D Gaussian Splatting with editable shading attributes for volume visualization [S1, S2]. It solves the instability and inefficiency of jointly optimizing base geometry and deformation-aware primitives by decoupling the process into two distinct stages: first establishing a robust base 3DGS model, then refining editable Gaussian primitives on top of it [S1]. This approach accelerates convergence and reduces memory footprint compared to one-stage training while maintaining reconstruction quality [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of input images/views of a scene, initial 3D Gaussian parameters (position $\mu$, scale $s$, rotation $q$, opacity $o$), and semantic segmentation masks for scene components [S1, S2].
*   **Outputs:** Optimized Gaussian parameters including geometry attributes $\{\mu_i, s_i, q_i, o_i\}$ and editable shading attributes $\{k_{ai}, k_{di}, k_{si}, \Delta c_i, \beta_i\}$, plus normal vectors $n_i$ [S2].

**Data Structures:**
Each Gaussian primitive $i$ stores:
*   Geometry: $\mu_i \in \mathbb{R}^3$ (center), $s_i \in \mathbb{R}^3$ (scale), $q_i \in \mathbb{R}^4$ (quaternion rotation), $o_i \in \mathbb{R}$ (opacity).
*   Shading/Editable: $k_{ai}, k_{di}, k_{si} \in \mathbb{R}$ (ambient, diffuse, specular coefficients), $\Delta c_i \in \mathbb{R}^3$ (color offset), $\beta_i \in \mathbb{R}$ (light magnitude scaling) [S2].
*   Normal: $n_i \in \mathbb{R}^3$ (unit normal vector) [S1, S2].

**Training Steps:**
1.  **Stage 1: Base 3DGS Optimization (30,000 iterations).**
    *   Optimize the base geometry attributes $\{\mu_i, s_i, q_i, o_i\}$ using the standard 3DGS optimization pipeline [S1].
    *   This stage establishes a stable geometric foundation without editable shading parameters [S1].
2.  **Stage 2: Editable Gaussian Optimization (10,000 iterations).**
    *   Initialize editable attributes $\{k_{ai}, k_{di}, k_{si}, \Delta c_i, \beta_i\}$ and normals $n_i$ [S1, S2].
    *   Optimize all attributes (geometry and shading) using the composite loss function defined below [S1].
    *   Geometry attributes are updated alongside shading attributes, but shading attributes have specific learning rates [S1].

**Loss Function:**
The total loss $L$ is a weighted sum of image reconstruction loss and regularization terms [S1]:
$$ L = \lambda_{L1} L_{L1} + \lambda_{SSIM} L_{SSIM} + \lambda_{L1\_reg} L_{L1\_reg} + \lambda_{norm} L_{norm} $$
Where:
*   $L_{L1}$ is the L1 reconstruction error between rendered and ground truth images.
*   $L_{SSIM}$ is the Structural Similarity Index Measure loss.
*   $L_{L1\_reg}$ is an L1 regularization term applied to editable Gaussian attributes during Stage 2.
*   $L_{norm}$ is the normal consistency loss [S1].

**Parameters:**
*   $\lambda_{L1} = 0.8$
*   $\lambda_{SSIM} = 0.2$
*   $\lambda_{L1\_reg} = 0.1$ (applied only in Stage 2)
*   $\lambda_{norm} = 0.01$ (applied only in Stage 2)
*   Learning rate for normal and shading attributes: $0.01$ [S1].
*   Learning rate for other attributes (e.g., opacity $o$): Same as original 3DGS optimization [S1].

**Pseudocode:**
```python
def train_ivr_gs(input_images, initial_gaussians, num_stages_iterations):
    """
    Train iVR-GS model in two stages.
    :param input_images: List of input view images.
    :param initial_gaussians: Initial Gaussian parameters.
    :param num_stages_iterations: Tuple (base_iters, editable_iters).
    :return: Optimized Gaussian parameters.
    """
    gaussians = initial_gaussians
    
    # Stage 1: Base 3DGS Optimization
    base_iters = num_stages_iterations[0]
    for i in range(base_iters):
        # Sample a random view from input_images
        view = sample_random_view(input_images)
        
        # Render image using current gaussians (geometry only, no shading edit)
        rendered_img = render_gaussians(gaussians, view)
        
        # Compute L1 and SSIM losses against ground truth
        loss = 0.8 * l1_loss(rendered_img, view.gt) + 0.2 * ssim_loss(rendered_img, view.gt)
        
        # Backpropagate and update geometry attributes (mu, s, q, o)
        # Shading attributes are not yet active or are fixed
        update_gaussians(gaussians, loss, lr=standard_3dgs_lr)
        
    # Stage 2: Editable Gaussian Optimization
    editable_iters = num_stages_iterations[1]
    # Initialize shading attributes and normals if not present
    initialize_shading_attributes(gaussians)
    
    for i in range(editable_iters):
        view = sample_random_view(input_images)
        
        # Render image using full iVR-GS model (geometry + shading)
        rendered_img = render_gaussians_ivr(gaussians, view)
        
        # Compute composite loss
        loss_recon = 0.8 * l1_loss(rendered_img, view.gt) + 0.2 * ssim_loss(rendered_img, view.gt)
        loss_reg = l1_loss(gaussians.shading_attributes) * 0.1
        loss_norm = normal_consistency_loss(gaussians.normals) * 0.01
        
        total_loss = loss_recon + loss_reg + loss_norm
        
        # Backpropagate and update all attributes
        # Shading and normal attributes use lr=0.01
        # Other attributes use standard 3DGS lr
        update_gaussians(gaussians, total_loss, 
                         lr_shading=0.01, 
                         lr_geometry=standard_3dgs_lr)
                         
    return gaussians
```

## Subtopics

### Composability of iVR-GS Models
A feature allowing multiple independently trained iVR-GS models (basic scenes) to be combined by simply concatenating their Gaussian parameters [S2]. To use this, train one basic iVR-GS model for each segmented component in the scene, then combine models by concatenating their Gaussian parameters to reconstruct the complete VolVis scene or view individual components [S2]. This enables users to view each semantic component individually or reconstruct the complete scene [S2].

## Operating characteristics
*   **Time Complexity:** Two-stage training requires 40,000 total iterations (30,000 base + 10,000 editable) [S1].
*   **Memory Complexity:** Depends on scene size and resolution. For example, on a $1024 \times 1024 \times 1080$ volume, CPU/GPU memory usage is 12.3 GB/7.1 GB [S1].
*   **Performance:** Rendering time varies by scene size; e.g., 361 ms for the largest tested volume ($2048 \times 2048 \times 2048$) [S1].
*   **Strengths:** Decoupled training improves stability and convergence speed compared to joint optimization [S1]. Supports composability for modular scene editing [S2].
*   **Limitations:** Requires semantic segmentation for composability [S2]. Two-stage process adds complexity to the training pipeline [S1].

## Background
iVR-GS Training was introduced in the iVR-GS paper [S1] and further applied in the NLI4VolVis framework [S2]. It builds upon the original 3DGS optimization method [S1] by adding editable shading attributes and a two-stage training strategy to handle volume visualization tasks [S1, S2]. The method is designed for explorable visualization via editable 3D Gaussian Splatting [S1].
