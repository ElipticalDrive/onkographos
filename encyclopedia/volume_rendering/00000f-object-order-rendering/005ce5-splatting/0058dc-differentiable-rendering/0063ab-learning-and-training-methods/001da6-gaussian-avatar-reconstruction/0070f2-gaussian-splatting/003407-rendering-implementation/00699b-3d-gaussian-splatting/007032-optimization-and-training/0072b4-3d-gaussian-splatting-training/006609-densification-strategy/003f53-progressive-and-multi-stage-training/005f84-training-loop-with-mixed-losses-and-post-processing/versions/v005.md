# Training Loop with Mixed Losses and Post-Processing

Also called: Mixed Loss Training Loop, Post-Processing Training Step

## Overview
This method defines the iterative optimization step for 3D Gaussian Splatting, combining photometric reconstruction, depth consistency, and regularization terms into a single loss function. It distinguishes itself from sibling methods by explicitly handling mixed supervision signals (RGB and depth) and applying post-processing strategies like bilateral grid slicing and opacity/scale regularization within the same backward pass, rather than relying solely on structural densification or curriculum learning. It builds on [Progressive and Multi-stage Training](9966-progressive-and-multi-stage-training.md) by executing the specific loss computations and parameter updates defined in each stage.

## How it works
**Inputs and Outputs:**
- **Inputs:** Current Gaussian set $\mathcal{G}$ (means $\mu$, scales $s$, quaternions $q$, opacities $\alpha$, SH coefficients $\mathbf{c}$), camera parameters, ground truth images $I_{gt}$, optional depth maps $D_{gt}$, current training step $t$, and configuration object `cfg`.
- **Outputs:** Updated $\mathcal{G}$, optimizer states, and optionally saved PLY files.

**Data Structures:**
- `splats`: Dictionary or struct containing tensors for $\mu$ (N, 3), $s$ (N, 3), $q$ (N, 4), $\alpha$ (N, 1), $\mathbf{c}$ (N, K, 3).
- `info`: Dictionary returned by rasterizer containing `radii` (N, 2), `gaussian_ids` (visible IDs), `alphas` (H, W, 1), and `render` (H, W, C).
- `cfg`: Configuration object with boolean and float flags: `sh_degree_interval`, `sh_degree`, `depth_loss`, `use_bilateral_grid`, `random_bkgd`, `use_l1_for_real_samples`, `ssim_lambda`, `depth_lambda`, `opacity_reg`, `scale_reg`, `visible_adam`, `packed`, `app_opt`, `save_ply`, `ply_steps`, `max_steps`.

**Numbered Steps:**

1.  **Spherical Harmonic Degree Selection:**
    Calculate the active SH degree $d$ for the current step:
    $$ d = \min\left(\left\lfloor \frac{t}{\text{cfg.sh\_degree\_interval}} \right\rfloor, \text{cfg.sh\_degree}\right) $$
    This determines the number of SH coefficients used per Gaussian.

2.  **Rasterization:**
    Rasterize the Gaussians $\mathcal{G}$ using the current camera parameters.
    - If `cfg.depth_loss` is true, render mode is 'RGB+ED' (RGB + Estimated Depth). Output: `renders` (H, W, 4) and `alphas` (H, W, 1).
    - Otherwise, render mode is 'RGB'. Output: `renders` (H, W, 3) and `alphas` (H, W, 1).
    - Split `renders` into `colors` and `depths`:
      - If `renders` has 4 channels: `colors = renders[..., 0:3]`, `depths = renders[..., 3:4]`.
      - Else: `colors = renders`, `depths = None`.

3.  **Bilateral Grid Slicing (Optional):**
    If `cfg.use_bilateral_grid` is true:
    - Compute grid coordinates `grid_xy` from the camera view.
    - Apply bilateral grid slicing to `colors`:
      $$ \text{colors} = \text{slice}(\text{self.bil\_grids}, \text{grid\_xy}, \text{colors}, \text{image\_ids})[\text{"rgb"}] $$
    - This refines color appearance based on spatial and intensity gradients.

4.  **Random Background Compositing (Optional):**
    If `cfg.random_bkgd` is true:
    - Generate random background color $\mathbf{b} \sim \mathcal{U}(0, 1)$ with shape (1, 3).
    - Composite:
      $$ \text{colors} = \text{colors} + \mathbf{b} \cdot (1.0 - \text{alphas}) $$

5.  **Pre-Backward Strategy Step:**
    Call `strategy.step_pre_backward(params, optimizers, state, t, info)`. This allows sibling methods (e.g., densification) to modify parameters or states before loss computation.

6.  **Reconstruction Loss:**
    Compute photometric loss between `colors` and $I_{gt}$.
    - If `is_nerf_sample.any()` is false (standard case):
      - Compute L1 or L2 loss based on `cfg.use_l1_for_real_samples`. Let this be $\mathcal{L}_{recon}$.
      - Compute SSIM loss $\mathcal{L}_{ssim}$.
      - Total reconstruction loss:
        $$ \mathcal{L}_{recon\_total} = \mathcal{L}_{recon} \cdot (1.0 - \text{cfg.ssim\_lambda}) + \mathcal{L}_{ssim} \cdot \text{cfg.ssim\_lambda} $$

7.  **Depth Loss (Optional):**
    If `cfg.depth_loss` is true and `is_nerf_sample.any()` is false:
    - Normalize 3D points to $[-1, 1]$.
    - Sample depths from the rendered depth map using `F.grid_sample`.
    - Compute disparity: $disp = 1.0 / \text{depths}$ (where $\text{depths} > 0$).
    - Compute ground truth disparity: $disp_{gt} = 1.0 / \text{depths}_{gt}$.
    - Depth loss:
      $$ \mathcal{L}_{depth} = \text{F.l1\_loss}(disp, disp_{gt}) \cdot \text{self.scene\_scale} $$
    - Add to total loss:
      $$ \mathcal{L}_{total} = \mathcal{L}_{recon\_total} + \mathcal{L}_{depth} \cdot \text{cfg.depth\_lambda} $$
    - Else:
      $$ \mathcal{L}_{total} = \mathcal{L}_{recon\_total} $$

8.  **Bilateral Grid Total Variation (Optional):**
    If `cfg.use_bilateral_grid` is true:
    - Compute total variation loss on the bilateral grid parameters:
      $$ \mathcal{L}_{tv} = 10 \cdot \text{total\_variation\_loss}(\text{self.bil\_grids.grids}) $$
    - Add to total loss:
      $$ \mathcal{L}_{total} = \mathcal{L}_{total} + \mathcal{L}_{tv} $$

9.  **Opacity Regularization (Optional):**
    If `cfg.opacity_reg > 0.0`:
    - Compute mean of sigmoid-applied opacities:
      $$ \mathcal{L}_{opacity} = \text{cfg.opacity\_reg} \cdot \text{mean}(\sigma(\text{self.splats["opacities"]})) $$
    - Add to total loss:
      $$ \mathcal{L}_{total} = \mathcal{L}_{total} + \mathcal{L}_{opacity} $$

10. **Scale Regularization (Optional):**
    If `cfg.scale_reg > 0.0`:
    - Compute mean of exponential-applied scales:
      $$ \mathcal{L}_{scale} = \text{cfg.scale\_reg} \cdot \text{mean}(\exp(\text{self.splats["scales"]})) $$
    - Add to total loss:
      $$ \mathcal{L}_{total} = \mathcal{L}_{total} + \mathcal{L}_{scale} $$

11. **Backward Pass:**
    Call `loss.backward()` to compute gradients for all trainable parameters.

12. **Visibility Masking (Optional):**
    If `cfg.visible_adam` is true:
    - Compute `visibility_mask` for Gaussians.
    - If `cfg.packed` is true: Scatter 1s at indices `info["gaussian_ids"]` in a zero tensor of shape equal to the number of opacities.
    - Else: Mask is `(info["radii"] > 0).all(-1).any(0)`.
    - This mask is used to zero out gradients for invisible Gaussians.

13. **Optimizer Step:**
    - If `cfg.visible_adam` is true: `optimizer.step(visibility_mask)`.
    - Else: `optimizer.step()`.
    - Zero gradients with `set_to_none=True`.

14. **Auxiliary Optimizer Steps:**
    - Step `pose_optimizers` and `bil_grid_optimizers` (if applicable), zeroing gradients.

15. **Scheduler Step:**
    - Step learning rate schedulers: `schedulers.step()`.

16. **Post-Backward Strategy Step:**
    Call `strategy.step_post_backward(...)`.
    - If `DefaultStrategy`: Pass `packed=cfg.packed`.
    - If `MCMCStrategy`: Pass `lr=schedulers[0].get_last_lr()[0]`.
    - This handles densification, pruning, or other structural updates.

17. **PLY Export (Optional):**
    If `step` in `cfg.ply_steps` or `step == max_steps - 1` and `cfg.save_ply`:
    - If `cfg.app_opt` is true:
      - Bake appearance by evaluating `app_module` at origin (directions = zeros).
      - Add `self.splats["colors"]`, apply sigmoid, convert to SH0, and create empty SHN.
    - Else:
      - Use `self.splats["sh0"]` and `self.splats["shN"]` directly.
    - Export splats with means, scales, quaternions, opacities, SH0, SHN.

**Pseudocode:**

```python
def training_step(splats, cameras, gt_images, gt_depths, step, cfg, strategy, optimizer, pose_optimizers, bil_grid_optimizers, schedulers):
    # 1. SH Degree
    sh_degree_to_use = min(step // cfg.sh_degree_interval, cfg.sh_degree)
    
    # 2. Rasterize
    if cfg.depth_loss:
        renders, alphas, info = rasterize_gaussians(splats, cameras, mode='RGB+ED')
        colors = renders[..., 0:3]
        depths = renders[..., 3:4]
    else:
        renders, alphas, info = rasterize_gaussians(splats, cameras, mode='RGB')
        colors = renders
        depths = None
        
    # 3. Bilateral Grid
    if cfg.use_bilateral_grid:
        grid_xy = compute_grid_coordinates(cameras)
        colors = slice_bilateral_grid(splats.bil_grids, grid_xy, colors, cameras.image_ids)["rgb"]
        
    # 4. Random Background
    if cfg.random_bkgd:
        bkgd = torch.rand(1, 3, device=colors.device)
        colors = colors + bkgd * (1.0 - alphas)
        
    # 5. Pre-Backward
    strategy.step_pre_backward(splats, optimizer, None, step, info)
    
    # 6. Reconstruction Loss
    is_nerf_sample = check_nerf_sample(gt_images) # Placeholder for specific sampling logic
    if not is_nerf_sample.any():
        if cfg.use_l1_for_real_samples:
            recon_loss = F.l1_loss(colors, gt_images)
        else:
            recon_loss = F.mse_loss(colors, gt_images)
        ssim_loss = compute_ssim(colors, gt_images)
        loss = recon_loss * (1.0 - cfg.ssim_lambda) + ssim_loss * cfg.ssim_lambda
    else:
        loss = torch.tensor(0.0, device=colors.device) # Or handle differently
        
    # 7. Depth Loss
    if cfg.depth_loss and not is_nerf_sample.any():
        # Normalize points and sample depths
        # This part requires access to 3D points and depth map sampling
        # Assuming helper functions exist for this specific pipeline
        disp = 1.0 / (depths + 1e-6)
        disp_gt = 1.0 / (gt_depths + 1e-6)
        depth_loss = F.l1_loss(disp, disp_gt) * splats.scene_scale
        loss = loss + depth_loss * cfg.depth_lambda
        
    # 8. Bilateral Grid TV
    if cfg.use_bilateral_grid:
        tv_loss = 10 * total_variation_loss(splats.bil_grids.grids)
        loss = loss + tv_loss
        
    # 9. Opacity Reg
    if cfg.opacity_reg > 0.0:
        opacity_reg = cfg.opacity_reg * torch.sigmoid(splats.opacities).mean()
        loss = loss + opacity_reg
        
    # 10. Scale Reg
    if cfg.scale_reg > 0.0:
        scale_reg = cfg.scale_reg * torch.exp(splats.scales).mean()
        loss = loss + scale_reg
        
    # 11. Backward
    loss.backward()
    
    # 12. Visibility Mask
    if cfg.visible_adam:
        if cfg.packed:
            visibility_mask = torch.zeros_like(splats.opacities)
            visibility_mask.scatter_(0, info["gaussian_ids"], 1.0)
        else:
            visibility_mask = (info["radii"] > 0).all(-1).any(0)
    else:
        visibility_mask = None
        
    # 13. Optimizer Step
    if visibility_mask is not None:
        optimizer.step(visibility_mask)
    else:
        optimizer.step()
    optimizer.zero_grad(set_to_none=True)
    
    # 14. Aux Optimizers
    if pose_optimizers:
        pose_optimizers.step()
        pose_optimizers.zero_grad(set_to_none=True)
    if bil_grid_optimizers:
        bil_grid_optimizers.step()
        bil_grid_optimizers.zero_grad(set_to_none=True)
        
    # 15. Scheduler
    for scheduler in schedulers:
        scheduler.step()
        
    # 16. Post-Backward
    if isinstance(strategy, DefaultStrategy):
        strategy.step_post_backward(packed=cfg.packed)
    elif isinstance(strategy, MCMCStrategy):
        lr = schedulers[0].get_last_lr()[0]
        strategy.step_post_backward(lr=lr)
        
    # 17. PLY Export
    if (step in cfg.ply_steps or step == cfg.max_steps - 1) and cfg.save_ply:
        if cfg.app_opt:
            # Bake appearance
            dirs = torch.zeros_like(cameras.directions)
            baked_colors = splats.app_module(dirs)
            sh0 = torch.sigmoid(baked_colors + splats.colors)
            shN = torch.zeros_like(sh0) # Empty higher order SH
        else:
            sh0 = splats.sh0
            shN = splats.shN
            
        export_ply(splats.means, splats.scales, splats.quats, splats.opacities, sh0, shN, step)
```

## Operating characteristics
- **Time Complexity:** Dominated by rasterization $O(N \cdot K)$ where $N$ is number of Gaussians and $K$ is number of pixels. Loss computation is $O(H \cdot W)$.
- **Memory Complexity:** $O(N)$ for Gaussian attributes. Rasterization requires $O(H \cdot W)$ for intermediate buffers.
- **Performance:** Efficient on GPU due to parallel rasterization. Bilateral grid and depth loss add overhead but improve convergence.
- **Strengths:** Handles mixed modalities (RGB/Depth), flexible regularization, supports appearance baking.
- **Limitations:** Requires careful tuning of regularization weights. Depth loss requires accurate depth maps.

## Background
Originated in the AugSplat project [S1, unofficial], this training loop extends standard 3D Gaussian Splatting by integrating depth supervision, bilateral grid appearance refinement, and structured regularization. It is used in high-fidelity Gaussian Avatar Reconstruction where photometric and geometric consistency are critical.
