# Warm-up stage

Also called: 3D Gaussian Initialization (Warm-up)

## Overview
The warm-up stage is a training adaptation in 3D Gaussian Splatting (3DGS) that improves distractor suppression and stabilizes convergence for dynamic scene reconstruction. It serves as a preliminary optimization phase before full dynamic training, preventing the model from getting stuck in poor local minima when dealing with non-unique inverse mappings or complex deformation fields [S1, S2]. Unlike standard single-stage optimization, it decouples the learning of static geometry from dynamic deformation, allowing the model to establish a robust baseline representation first [S2].

## How it works
The warm-up stage is primarily utilized in the context of 4D Gaussian Splatting (4D-GS) for dynamic scenes, particularly when Structure-from-Motion (SfM) point initialization is absent or insufficient [S2]. It involves optimizing 3D Gaussians before training the full 4D-GS model directly [S2].

### Inputs and Outputs
*   **Inputs:** Input image sequences, camera poses, and an initial set of 3D Gaussians (if SfM points are available) or a sparse initialization.
*   **Outputs:** Optimized 3D Gaussian parameters (position, covariance, opacity, color) and a suggested deformation field initialization [S2].

### Data Structures
The method operates on the standard 3D Gaussian representation $\mathcal{G}$, consisting of:
*   Mean position $\mu$
*   Covariance matrix $\Sigma$ (or rotation $R$ and scale $S$)
*   Opacity $\alpha$
*   Spherical harmonics coefficients for color $C$

In the dynamic context, these are extended to 4D Gaussians $\mathcal{G}'$ which include temporal deformation parameters decoded by a Gaussian deformation decoder $\mathcal{D}$ [S2].

### Steps
1.  **Initialization:** Initialize 3D Gaussians. If SfM points are absent, use a sparse random or grid-based initialization [S2].
2.  **Static Optimization:** Optimize the 3D Gaussian parameters ($\Gamma$) using standard 3DGS rendering loss (photometric loss) on the input frames. This stage focuses on learning the static geometry and appearance [S2].
3.  **Deformation Guidance:** During this phase, the optimization suggests deformation fields that pay more attention to the dynamic parts of the scene. This helps the subsequent 4D-GS training by providing a better initial state for the deformation network $\Delta$ [S2].
4.  **Stability Maintenance:** By keeping some 3D Gaussians in the dynamic part, the warm-up stage releases the pressure of learning large deformations directly with 4D Gaussians. This avoids numeric errors in optimizing the Gaussian deformation network $\Delta$ and keeps training stable [S2].
5.  **Transition:** The optimized 3D Gaussians serve as the initialization for the 4D-GS training stage, where temporal deformation is explicitly modeled [S2].

### Pseudocode
```python
def warmup_stage(input_frames, camera_poses, initial_gaussians):
    """
    Performs the warm-up stage for 4D Gaussian Splatting.
    
    Args:
        input_frames: List of input images.
        camera_poses: List of camera poses corresponding to input_frames.
        initial_gaussians: Initial set of 3D Gaussians (from SfM or random).
        
    Returns:
        optimized_gaussians: Optimized 3D Gaussian parameters.
        suggested_deformation: Initial deformation field suggestions.
    """
    # Initialize Gaussian parameters
    gaussians = initial_gaussians.copy()
    
    # Define loss function (standard 3DGS photometric loss)
    def compute_loss(gaussians, frames, poses):
        rendered_images = render(gaussians, poses)
        loss = sum((r - t)**2 for r, t in zip(rendered_images, frames))
        return loss
    
    # Optimization loop for static 3D Gaussians
    for step in range(num_warmup_steps):
        # Sample a random frame and pose
        idx = random_index(len(input_frames))
        frame = input_frames[idx]
        pose = camera_poses[idx]
        
        # Compute gradient and update Gaussians
        loss = compute_loss(gaussians, [frame], [pose])
        gradients = compute_gradients(loss, gaussians)
        gaussians = update_parameters(gaussians, gradients, learning_rate)
        
        # Optionally, track deformation suggestions based on residuals
        # This step is implicit in the optimization dynamics
        suggested_deformation = estimate_deformation_from_residuals(gaussians, frame, pose)
        
    return gaussians, suggested_deformation
```

### Parameters
*   **num_warmup_steps:** Number of optimization steps for the warm-up phase. Not given in the sources.
*   **learning_rate:** Learning rate for Gaussian parameter optimization. Not given in the sources.

### Edge Cases and Pitfalls
*   **Absence of SfM Points:** Without SfM initialization, direct 4D-GS training may cause convergence difficulty. The warm-up stage is critical in this scenario [S2].
*   **Numeric Errors:** Skipping the warm-up stage can lead to numeric errors in optimizing the Gaussian deformation network $\Delta$, causing training instability [S2].
*   **Underfitting:** If the warm-up stage does not properly suggest deformation fields, the subsequent 4D-GS training may underfit details during excessive stretching or fail to simulate microscopic object movements [S2].

## Subtopics

### 3D Gaussian Initialization (Warm-up)
This variant specifically refers to the use of warm-up when SfM points initialization is absent. It optimizes 3D Gaussians before training 4D-GS directly to prevent convergence difficulty. It keeps some 3D Gaussians in the dynamic part to release pressure of large deformation learning by 4D Gaussians, learns proper 3D Gaussians $\Gamma$ and suggests deformation fields to pay more attention to the dynamic part, and avoids numeric errors in optimizing the Gaussian deformation network $\Delta$ [S2].

## Operating characteristics
*   **Performance Impact:** Training without the warm-up coarse stage yields PSNR 31.91 dB, SSIM 0.97, LPIPS 0.03, training time 7.5 mins, 79 FPS, and 18 MB storage [S2]. The warm-up stage is intended to improve these metrics, particularly in scenarios without SfM points.
*   **Memory Costs:** The 4D Gaussian model incurs minimal memory costs, but rendering quality may suffer without proper initialization [S2].
*   **Strengths:** Stabilizes training, prevents convergence difficulty, improves distractor suppression [S1, S2].
*   **Limitations:** Adds an extra training stage, increasing total training time. Not given in the sources.

## Background
The warm-up stage is part of the broader effort to improve 3D Gaussian Splatting for dynamic scenes. It was introduced in the context of 4D Gaussian Splatting for Real-Time Dynamic Scene Rendering [S2]. The concept of using warm-up stages to improve training stability and performance is also discussed in the context of distractor suppression in SpotLessSplats [S1].
