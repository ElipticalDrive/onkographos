# GauHuman


## Overview
GauHuman is a method for dynamic digital human modeling from monocular video that builds on [3D Gaussian Splatting Training](3761-3d-gaussian-splatting-training.md) by redesigning the densification primitives to achieve efficient optimization [S1][S2, unofficial]. It sets itself apart from siblings like [GaussianBody](9209-gaussianbody.md) by focusing on re-engineering the prune/split/clone mechanisms and incorporating pose refinement and weight field modules for fine detail learning, rather than relying solely on physical-based priors in canonical space [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Monocular video sequence of a dynamic human; initial Gaussian parameters (position, covariance, opacity, spherical harmonics coefficients).
- **Outputs:** Optimized set of 3D Gaussians representing the dynamic human, including pose parameters and weight fields for fine details.

**Data Structures:**
- **Gaussian Attributes:** Position ($\mathbf{t}$), Covariance ($\mathbf{\Sigma}$), Opacity ($\alpha$), Spherical Harmonics coefficients ($\mathbf{c}$).
- **Pose Refinement Module:** Parameters for pose adjustment.
- **Weight Field Module:** Network or function mapping spatial coordinates to weight values for fine detail learning.

**Numbered Steps:**
1. **Initialization:** Initialize Gaussians based on the parent's custom initialization principles, likely mapping to a parametric mesh or using SfM points adapted for human anatomy [S1][S2, unofficial].
2. **Pose Refinement:** Incorporate a pose refinement module to adjust the pose of the Gaussians during optimization [S2, unofficial]. This ensures the Gaussians align correctly with the dynamic human's movements.
3. **Weight Field Integration:** Incorporate a weight field module to learn fine details. This module likely assigns weights to Gaussians based on their spatial location or other features to enhance detail preservation [S2, unofficial].
4. **Redesigned Densification:** Re-design the prune, split, and clone operations of the original 3DGS densification process [S1][S2, unofficial]. This involves modifying the criteria and thresholds for adding, removing, or splitting Gaussians to better suit the dynamic human domain, achieving more efficient optimization.
5. **Optimization:** Perform differentiable rendering optimization, minimizing the difference between rendered images and ground truth video frames. The loss function likely includes terms for pose refinement and weight field regularization [S1][S2, unofficial].
6. **Iteration:** Repeat steps 2-5 until convergence or a predefined number of iterations.

**Edge Cases and Pitfalls:**
- **Monocular Ambiguity:** Monocular input can lead to ambiguities in depth and pose. The pose refinement module helps mitigate this, but careful initialization and regularization are crucial [S1][S2, unofficial].
- **Dynamic Cloth Artifacts:** Dynamic cloth can cause artifacts. While [GaussianBody](9209-gaussianbody.md) uses physical-based priors, GauHuman relies on its redesigned densification and weight fields to handle this [S1][S2, unofficial].
- **Over-densification:** The redesigned prune/split/clone operations aim to prevent unbalanced aggregation of Gaussians, a common issue in standard 3DGS [S1][S2, unofficial].
