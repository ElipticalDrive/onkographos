# GaussianSet Data Structure

Also called: 3D Gaussian Representation, Gaussian Set

## Overview
The GaussianSet is the primary in-memory data structure used to store a collection of 3D Gaussian primitives for differentiable volume rendering [S1, unofficial]. It solves the problem of efficiently organizing geometric parameters (position, orientation, scale), appearance attributes (opacity, spherical harmonics), and precomputed derived data (covariance matrices) to enable batch processing during rasterization [S1, unofficial]. It sets itself apart from hierarchical variants like [Octree-GS / Scaffold-GS](6142-octree-gs-scaffold-gs.md) by using a flat, contiguous array layout, and from [GaussianList Data Structure and Initialization](2214-gaussianlist-data-structure-and-initialization.md) by defining the specific field composition and mathematical relationships required for the rendering pipeline [S1, unofficial].

## How it works
The GaussianSet stores the explicit parameters of $N$ 3D Gaussians. While the raw learnable parameters are often stored in a compressed or encoded form (e.g., logarithmic scales, sigmoided opacities), the `GaussianSet` typically holds the decoded, active parameters required for immediate computation, including the precomputed world-space covariance matrices [S1, unofficial].

### Inputs and Outputs
*   **Input**: A set of $N$ Gaussian primitives defined by their mean position, rotation, scale, opacity, and spherical harmonics coefficients.
*   **Output**: A structured data object containing tensors for all attributes, ready for projection and rasterization.

### Data Structures and Layout
The `GaussianSet` consists of the following fields, typically implemented as contiguous tensors (e.g., PyTorch `Tensor` or NumPy `ndarray`) [S1, unofficial]:

1.  **`means`**: `Float32[N, 3]`
    *   The 3D position $\boldsymbol{\mu}$ of each Gaussian.
2.  **`quats`**: `Float32[N, 4]`
    *   The orientation represented as unit quaternions $q = (w, x, y, z)$.
3.  **`scales`**: `Float32[N, 3]`
    *   The local scaling factors $s_x, s_y, s_z$.
4.  **`opacities`**: `Float32[N]`
    *   The scalar opacity $\alpha$ for each Gaussian.
5.  **`sh_coefficients`**: `Float32[N, S, 3]`
    *   Spherical Harmonics coefficients for view-dependent color, where $S$ is the number of SH bands (e.g., $S=16$ for degree 3).
6.  **`covariances`**: `Float32[N, 3, 3]`
    *   The precomputed $3 \times 3$ world-space covariance matrix $\Sigma$ for each Gaussian.

### Computation Steps
The `covariances` field is derived from `quats` and `scales` using the following steps [S1, unofficial]:

1.  **Normalize Quaternions**: Ensure $q$ is a unit quaternion.
    $$ q_{norm} = \frac{q}{\|q\|_2} $$
2.  **Convert Quaternion to Rotation Matrix**: Construct the $3 \times 3$ rotation matrix $R$ from $q_{norm}$ [G].
3.  **Construct Local Covariance Matrix**: Create the diagonal matrix $S$ from the scales.
    $$ S = \text{diag}(s_x^2, s_y^2, s_z^2) $$
4.  **Compute World Covariance**: Calculate the world-space covariance $\Sigma$.
    $$ \Sigma = R S R^T $$

### Pseudocode
The following Python-like pseudocode demonstrates the construction of the `covariances` field from the raw attributes [S1, unofficial][G].

```python
import torch

def compute_covariances(quats: torch.Tensor, scales: torch.Tensor) -> torch.Tensor:
    """
    Computes the world-space covariance matrix for a set of Gaussians.
    
    Args:
        quats: Tensor of shape (N, 4), unit quaternions (w, x, y, z).
        scales: Tensor of shape (N, 3), local scaling factors.
        
    Returns:
        covariances: Tensor of shape (N, 3, 3), world-space covariance matrices.
    """
    # 1. Normalize quaternions to ensure unit length
    quats = quats / torch.norm(quats, dim=1, keepdim=True)
    
    # 2. Convert quaternions to rotation matrices
    # Helper to convert quaternion to rotation matrix
    def quat_to_rot(q):
        w, x, y, z = q[:, 0], q[:, 1], q[:, 2], q[:, 3]
        # Construct rotation matrix elements
        # R = [[1-2(y^2+z^2), 2(xy-wz),     2(xz+wy)],
        #      [2(xy+wz),     1-2(x^2+z^2), 2(yz-wx)],
        #      [2(xz-wy),     2(yz+wx),     1-2(x^2+y^2)]]
        R = torch.zeros(q.shape[0], 3, 3, device=q.device)
        R[:, 0, 0] = 1 - 2 * (y**2 + z**2)
        R[:, 0, 1] = 2 * (x*y - w*z)
        R[:, 0, 2] = 2 * (x*z + w*y)
        R[:, 1, 0] = 2 * (x*y + w*z)
        R[:, 1, 1] = 1 - 2 * (x**2 + z**2)
        R[:, 1, 2] = 2 * (y*z - w*x)
        R[:, 2, 0] = 2 * (x*z - w*y)
        R[:, 2, 1] = 2 * (y*z + w*x)
        R[:, 2, 2] = 1 - 2 * (x**2 + y**2)
        return R

    R = quat_to_rot(quats)
    
    # 3. Construct local covariance matrix S (diagonal)
    # S = diag(sx^2, sy^2, sz^2)
    scales_sq = scales ** 2
    S = torch.zeros_like(R)
    S[:, 0, 0] = scales_sq[:, 0]
    S[:, 1, 1] = scales_sq[:, 1]
    S[:, 2, 2] = scales_sq[:, 2]
    
    # 4. Compute world covariance: Cov = R * S * R^T
    covariances = torch.bmm(R, torch.bmm(S, R.transpose(1, 2)))
    
    return covariances
```

### Parameters and Edge Cases
*   **Quaternion Normalization**: Quaternions must be normalized before conversion to rotation matrices to ensure valid rotation [S1, unofficial].
*   **Scale Exponentiation**: In many training pipelines (e.g., gsplat), raw stored scales are exponentiated (`torch.exp`) to ensure they remain positive [S1, unofficial]. The `GaussianSet` may store the exponentiated values directly or compute them on the fly.
*   **Opacity Sigmoid**: Raw stored opacities are often sigmoided (`torch.sigmoid`) to bound them between 0 and 1 [S1, unofficial].
*   **SH Concatenation**: Spherical harmonics coefficients from different degrees (e.g., degree 0 and degree 3) are concatenated along the band dimension [S1, unofficial].
*   **Precision**: Using `Float32` is standard, but `Float64` may be used for high-precision training to avoid gradient instability [G].

## Operating characteristics
*   **Memory Complexity**: $O(N \cdot D)$, where $N$ is the number of Gaussians and $D$ is the dimensionality of attributes (position, scale, rotation, opacity, SH). The precomputed covariance matrix adds a constant factor of $9 \times \text{sizeof(float)}$ per Gaussian.
*   **Time Complexity**: Computing the covariance matrix for all Gaussians is $O(N)$, with a constant factor determined by the matrix multiplication cost ($3 \times 3$).
*   **Strengths**: Flat array layout allows for efficient GPU batch processing and vectorized operations. Precomputed covariances avoid redundant calculations during rasterization.
*   **Limitations**: Storing all attributes explicitly can lead to high memory usage for large scenes. Compression techniques like [ECoNGS](2087-econgs-optimization-and-coding.md) are required for scalability.
*   **When to Use**: When real-time rendering is required and the scene size fits in memory.
*   **When Not to Use**: For extremely large scenes where memory bandwidth is a bottleneck; consider hierarchical or compressed representations.

## Background
The GaussianSet data structure is a core component of 3D Gaussian Splatting (3DGS), a method introduced by Kerbl et al. in 2023 [S1, unofficial]. It replaces the implicit neural fields of NeRF with discrete, differentiable volumetric splats, enabling real-time rendering through GPU-friendly tile-based rasterization [S1, unofficial]. The structure was designed to support end-to-end optimization from sparse Structure-from-Motion (SfM) point clouds [S1, unofficial].
