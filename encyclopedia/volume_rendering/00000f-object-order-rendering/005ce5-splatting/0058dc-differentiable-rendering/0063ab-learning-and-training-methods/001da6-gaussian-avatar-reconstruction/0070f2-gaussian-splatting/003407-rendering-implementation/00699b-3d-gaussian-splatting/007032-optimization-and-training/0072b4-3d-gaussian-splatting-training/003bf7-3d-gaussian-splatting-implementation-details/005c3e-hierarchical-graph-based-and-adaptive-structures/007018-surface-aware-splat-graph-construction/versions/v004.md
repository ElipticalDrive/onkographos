# Surface-Aware Splat Graph Construction

Also called: Manifold-Aware Gaussian Graph Construction, Surface-Aligned Gaussian Connectivity

## Overview
Surface-Aware Splat Graph Construction establishes connectivity between 3D Gaussian primitives exclusively along the underlying surface manifold, filtering out spurious neighbors that are close in Euclidean space but distant along the surface [S1]. Unlike standard 3D Gaussian Splatting (3DGS) which relies on rasterization order or Euclidean distance for neighbor queries, this method defines edges based on the geometric intersection of Gaussian kernels [S1]. It is chosen when faithful surface topology preservation is required for downstream tasks such as Laplacian-based deformation, where Euclidean kNN would introduce topological errors [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of $N$ 3D Gaussian kernels $\{G_i\}_{i=1}^N$ reconstructed from a surface-aligned Gaussian Splatting method (specifically SpikingGS [S1]). Each kernel $G_i$ is defined by mean position $\mu_i \in \mathbb{R}^3$, covariance $\Sigma_i \in \mathbb{R}^{3 \times 3}$, and opacity $\alpha_i$.
*   **Output:** An adjacency graph where an edge exists between $G_i$ and $G_j$ if their occupancy regions intersect (or are within a tolerance $\epsilon$).

**Data Structures**
*   **Gaussian Kernel $G_i$:**
    *   $\mu_i$: Position vector.
    *   $\Sigma_i$: Covariance matrix, factorized as $\Sigma_i = R_i S_i S_i^\top R_i^\top$.
    *   $R_i$: Rotation matrix with columns $r_{i,1}, r_{i,2}, r_{i,3}$.
    *   $S_i$: Scale matrix, typically $\text{diag}(\sigma_{i,1}, \sigma_{i,2}, 0)$ for rank-2 (surface-aligned) Gaussians [S1].
    *   $\alpha_i$: Opacity scalar.
    *   $\bar{V}_{ip}$: Learnable activation cut-off threshold from the spiking neuron model [S1].
*   **Graph:** Adjacency list or matrix derived from intersection checks.

**Parameters**
*   $c$: Minimum contribution threshold for rendered intensity. Typical value: $1/255$ [S1].
*   $\epsilon$: Tolerance for normal-wise offset to account for minor gaps between adjacent kernels arising from joint optimization. Value not explicitly given in sources [S1].

**Steps**
1.  **Scene Reconstruction:** Reconstruct the scene using a surface-aligned Gaussian Splatting method (e.g., SpikingGS) to obtain the initial set of $N$ Gaussian kernels $\{G_i\}_{i=1}^N$ [S1].
2.  **Define Occupancy Region $\Omega_i$:** For each kernel $G_i$, define the 3D canonical occupancy region $\Omega_i$ as the set of points $x$ where the kernel is active. Activity is determined by two constraints:
    *   The Gaussian value $G_i(x)$ must exceed the spiking neuron threshold $\bar{V}_{ip}$.
    *   The rendered intensity $\alpha_i G_i(x)$ must exceed the minimum contribution threshold $c$.
    
    The region is defined as:
    $$ \Omega_i = \left\{ x \in \mathbb{R}^3 \mid G_i(x) > \max \left( \bar{V}_{ip}, \frac{c}{\alpha_i} \right) \right\} $$
    where $G_i(x) = \exp\left( -\frac{1}{2} (x-\mu_i)^\top \Sigma_i^{-1} (x-\mu_i) \right)$ [S1].
3.  **Parameterize $\Omega_i$:** Since $\Sigma_i$ is rank-2 (surface-aligned), $\Omega_i$ is an ellipse. Using $S_i = \text{diag}(\sigma_{i,1}, \sigma_{i,2}, 0)$ and $R_i = [r_{i,1}, r_{i,2}, r_{i,3}]$, the region is parameterized as:
    $$ \Omega_i = \left\{ \mu_i + \lambda_i \rho (\sigma_{i,1} \cos \theta \, r_{i,1} + \sigma_{i,2} \sin \theta \, r_{i,2}) \;\middle|\; \rho \in [0, 1), \theta \in (0, 2\pi] \right\} $$
    where the scaling factor $\lambda_i$ is:
    $$ \lambda_i = \sqrt{-2 \max \left( \ln |\bar{V}_{ip}|, \ln \left( \frac{c}{\alpha_i} \right) \right)} $$
    [S1].
4.  **Compute Normal-Wise Offset $\delta_{ij}$:** To determine if $G_i$ and $G_j$ intersect, compute the offset $\delta_{ij}$ from $G_i$ to $G_j$ along the normal direction of $G_i$ (defined by $r_{i,3}$):
    $$ \delta_{ij} := \inf \{ |t| \mid \exists x \in \Omega_i : x + t r_{i,3} \in \Omega_j \} $$
    If no such $x$ exists, $\delta_{ij} = +\infty$ [S1].
5.  **Establish Connectivity:** Two Gaussians $G_i$ and $G_j$ are considered connected (intersecting) if $\delta_{ij} < \epsilon$. A value of $\delta_{ij} = 0$ denotes a perfect intersection [S1].

## Operating characteristics
*   **Complexity:** The method requires checking intersections between Gaussian pairs. A naive implementation is $O(N^2)$. Spatial acceleration structures (e.g., BVH) could be used to prune non-intersecting pairs, but the source does not specify an acceleration structure for the intersection test itself [S1].
*   **Strengths:** It accurately captures surface topology by ignoring Euclidean proximity that does not correspond to surface adjacency. This is critical for Laplacian-based deformation, where Euclidean kNN would create edges across gaps or through volume, leading to distorted deformations [S1].
*   **Limitations:** It relies on the quality of the initial surface-aligned reconstruction (e.g., SpikingGS). If the Gaussians are not well-aligned to the surface, the intersection logic may fail to capture true connectivity. The tolerance $\epsilon$ is a hyperparameter that requires tuning to balance gap tolerance vs. spurious connections [S1].
*   **Performance:** Not given in the sources [S1].

## Background
The method was introduced in "Proxy-Free Gaussian Splats Deformation with Splat-Based Surface Estimation" [S1]. It addresses the limitation of existing point-based distance metrics (Euclidean, Mahalanobis) in challenging conditions where they cannot reliably establish connectivity along the surface manifold [S1]. The approach builds upon SpikingGS [19] for its superior surface alignment quality [S1].
