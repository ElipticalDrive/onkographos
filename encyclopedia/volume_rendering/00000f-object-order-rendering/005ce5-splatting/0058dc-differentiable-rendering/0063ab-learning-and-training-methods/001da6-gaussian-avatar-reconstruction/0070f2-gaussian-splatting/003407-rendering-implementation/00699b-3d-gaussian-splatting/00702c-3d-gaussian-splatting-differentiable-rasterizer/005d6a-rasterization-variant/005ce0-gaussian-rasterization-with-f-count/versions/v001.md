# Gaussian Rasterization with F-Count

Also called: LightGaussian rasterization

## Overview
This variant of 3D Gaussian Splatting extends the standard differentiable rasterizer to output the number of times each Gaussian is activated (rendered) during the forward pass, alongside the standard color and radii tensors [S1, unofficial]. It is primarily used in LightGaussian to compute importance scores for Gaussian pruning and compression [S1, unofficial]. It differs from the standard rasterizer by invoking a specialized C++/CUDA kernel (`count_gaussians`) that tracks per-Gaussian activation counts, whereas siblings like Masked-Rasterization focus on visibility masking or Differentiable Radiative Rasterization focuses on radiative transfer physics [S1, 4366-masked-rasterization.md, 4526-differentiable-radiative-rasterization.md, unofficial].

## How it works
The method operates within the standard tile-based rasterization pipeline defined in [Rasterization Variant](17388-rasterization-variant.md). The divergence occurs in the argument construction and the specific CUDA kernel invocation.

### Inputs and Outputs
**Inputs:**
1.  `means3D`: $(N, 3)$ tensor of 3D Gaussian centers.
2.  `colors_precomp`: $(N, 3)$ tensor of precomputed colors (RGB).
3.  `opacities`: $(N, 1)$ tensor of Gaussian opacities.
4.  `scales`: $(N, 3)$ tensor of Gaussian scales.
5.  `rotations`: $(N, 4)$ tensor of Gaussian rotations (quaternions).
6.  `raster_settings`: A `GaussianRasterizationSettings` NamedTuple containing camera parameters and flags.
7.  `sh`: Spherical Harmonics coefficients (if `colors_precomp` is not used).
8.  `cov3Ds_precomp`: $(N, 6)$ tensor of precomputed 3D covariances (alternative to scales/rotations).

**Outputs:**
1.  `gaussians_count`: $(N, 1)$ tensor where each element $i$ stores the number of pixels for which Gaussian $i$ contributed to the final image (i.e., was "activated").
2.  `important_score`: $(N, 1)$ tensor derived from the counts (implementation-specific, often a function of the count).
3.  `color`: $(H, W, 3)$ rendered image tensor.
4.  `radii`: $(H, W)$ tensor of maximum radii for depth sorting.

### Data Structures
**GaussianRasterizationSettings**
A NamedTuple with the following fields [S1, unofficial]:
*   `bg`: `torch.Tensor` (3,) background color.
*   `image_height`: `int`.
*   `image_width`: `int`.
*   `tanfovx`: `float`.
*   `tanfovy`: `float`.
*   `viewmatrix`: `torch.Tensor` (4, 4) extrinsic matrix.
*   `projmatrix`: `torch.Tensor` (4, 4) intrinsic matrix.
*   `campos`: `torch.Tensor` (3,) camera position.
*   `scale_modifier`: `float`.
*   `sh_degree`: `int`.
*   `prefiltered`: `bool`.
*   `debug`: `bool`.
*   `f_count`: `bool`. When `True`, enables F-Count mode.

### Numbered Steps

1.  **Input Validation**:
    *   Verify that exactly one of `colors_precomp` or `sh` is provided. If both are `None` or both are not `None`, raise an exception [S1, unofficial].
    *   Verify that exactly one of the following pairs is provided: (`scales`, `rotations`) OR `cov3Ds_precomp`. If `(scales is None or rotations is None)` AND `cov3Ds_precomp is None`, OR if `(scales is not None or rotations is not None)` AND `cov3Ds_precomp is not None`, raise an exception [S1, unofficial].

2.  **Argument Construction**:
    *   Construct the `args` tuple for the C++ backend in the exact order specified below.
    *   If `raster_settings.f_count` is `True`, append `raster_settings.f_count` as the 20th element.
    *   Order:
        1.  `raster_settings.bg`
        2.  `means3D`
        3.  `colors_precomp`
        4.  `opacities`
        5.  `scales`
        6.  `rotations`
        7.  `raster_settings.scale_modifier`
        8.  `cov3Ds_precomp`
        9.  `raster_settings.viewmatrix`
        10. `raster_settings.projmatrix`
        11. `raster_settings.tanfovx`
        12. `raster_settings.tanfovy`
        13. `raster_settings.image_height`
        14. `raster_settings.image_width`
        15. `sh`
        16. `raster_settings.sh_degree`
        17. `raster_settings.campos`
        18. `raster_settings.prefiltered`
        19. `raster_settings.debug`
        20. `raster_settings.f_count` (only if true) [S1, unofficial].

3.  **Forward Execution**:
    *   If `raster_settings.f_count` is `True`, call `_C.count_gaussians(*args)` [S1, unofficial].
    *   Otherwise, call `_C.rasterize_gaussians(*args)` [S1, unofficial].
    *   The C++/CUDA kernel performs the standard projection, tile culling, sorting, and accumulation defined in [Rasterization Variant](17388-rasterization-variant.md).
    *   In F-Count mode, the kernel additionally increments a counter for each Gaussian $i$ every time it contributes to a pixel's color accumulation.

4.  **Result Extraction**:
    *   The C++ function returns a tuple: `(gaussians_count, important_score, num_rendered, color, radii, geomBuffer, binningBuffer, imgBuffer)` [S1, unofficial].
    *   If `f_count` is `True`, return `(gaussians_count, important_score, color, radii)` [S1, unofficial].
    *   If `f_count` is `False`, return `(color, radii)` [S1, unofficial].

5.  **Backward Pass**:
    *   Construct backward args tuple:
        1.  `raster_settings.bg`
        2.  `means3D`
        3.  `radii`
        4.  `colors_precomp`
        5.  `scales`
        6.  `rotations`
        7.  `raster_settings.scale_modifier`
        8.  `cov3Ds_precomp`
        9.  `raster_settings.viewmatrix`
        10. `raster_settings.projmatrix`
        11. `raster_settings.tanfovx`
        12. `raster_settings.tanfovy`
        13. `grad_out_color`
        14. `sh`
        15. `raster_settings.sh_degree`
        16. `raster_settings.campos`
        17. `geomBuffer`
        18. `num_rendered`
        19. `binningBuffer`
        20. `imgBuffer`
        21. `raster_settings.debug` [S1, unofficial].
    *   Call `_C.rasterize_gaussians_backward(*args)` [S1, unofficial].
    *   Return gradients: `(grad_means3D, grad_means2D, grad_sh, grad_colors_precomp, grad_opacities, grad_scales, grad_rotations, grad_cov3Ds_precomp, None)` [S1, unofficial].

### Pseudocode

```python
import torch
import copy

def gaussian_rasterization_with_f_count(
    means3D: torch.Tensor,
    colors_precomp: torch.Tensor,
    opacities: torch.Tensor,
    scales: torch.Tensor,
    rotations: torch.Tensor,
    raster_settings,
    sh: torch.Tensor = None,
    cov3Ds_precomp: torch.Tensor = None
) -> tuple:
    """
    Renders 3D Gaussians with F-Count support.
    
    Args:
        means3D: (N, 3)
        colors_precomp: (N, 3)
        opacities: (N, 1)
        scales: (N, 3)
        rotations: (N, 4)
        raster_settings: GaussianRasterizationSettings NamedTuple
        sh: (N, K, 3) Optional SH coefficients
        cov3Ds_precomp: (N, 6) Optional precomputed covariances
        
    Returns:
        (gaussians_count, important_score, color, radii) if f_count is True
        (color, radii) if f_count is False
    """
    
    # 1. Input Validation
    if colors_precomp is None and sh is None:
        raise ValueError("Either colors_precomp or sh must be provided.")
    if colors_precomp is not None and sh is not None:
        raise ValueError("Only one of colors_precomp or sh should be provided.")
        
    has_scale_rot = (scales is not None and rotations is not None)
    has_cov = cov3Ds_precomp is not None
    
    if (not has_scale_rot) and (not has_cov):
        raise ValueError("Either (scales and rotations) or cov3Ds_precomp must be provided.")
    if has_scale_rot and has_cov:
        raise ValueError("Only one of (scales and rotations) or cov3Ds_precomp should be provided.")

    # 2. Argument Construction
    args = [
        raster_settings.bg,
        means3D,
        colors_precomp,
        opacities,
        scales,
        rotations,
        raster_settings.scale_modifier,
        cov3Ds_precomp,
        raster_settings.viewmatrix,
        raster_settings.projmatrix,
        raster_settings.tanfovx,
        raster_settings.tanfovy,
        raster_settings.image_height,
        raster_settings.image_width,
        sh,
        raster_settings.sh_degree,
        raster_settings.campos,
        raster_settings.prefiltered,
        raster_settings.debug
    ]
    
    # Append f_count flag if enabled
    if raster_settings.f_count:
        args.append(raster_settings.f_count)
        
    # 3. Forward Execution
    try:
        if raster_settings.f_count:
            # Call specialized count kernel
            # Returns: (gaussians_count, important_score, num_rendered, color, radii, geomBuffer, binningBuffer, imgBuffer)
            out = _C.count_gaussians(*args)
            gaussians_count = out[0]
            important_score = out[1]
            color = out[3]
            radii = out[4]
            # Store buffers for backward pass if needed, though standard impl might handle this internally
            return gaussians_count, important_score, color, radii
        else:
            # Call standard rasterizer
            # Returns: (num_rendered, important_score/None, num_rendered, color, radii, geomBuffer, binningBuffer, imgBuffer)
            out = _C.rasterize_gaussians(*args)
            color = out[3]
            radii = out[4]
            return color, radii
            
    except Exception as e:
        if raster_settings.debug:
            # Deep copy args to CPU for debugging
            args_cpu = copy.deepcopy(args)
            torch.save(args_cpu, 'snapshot_fw.dump')
        raise e

def gaussian_rasterization_backward(
    grad_out_color: torch.Tensor,
    means3D: torch.Tensor,
    radii: torch.Tensor,
    colors_precomp: torch.Tensor,
    scales: torch.Tensor,
    rotations: torch.Tensor,
    raster_settings,
    sh: torch.Tensor = None,
    cov3Ds_precomp: torch.Tensor = None,
    geomBuffer=None,
    num_rendered=None,
    binningBuffer=None,
    imgBuffer=None
) -> tuple:
    """
    Backward pass for Gaussian Rasterization.
    """
    args = [
        raster_settings.bg,
        means3D,
        radii,
        colors_precomp,
        scales,
        rotations,
        raster_settings.scale_modifier,
        cov3Ds_precomp,
        raster_settings.viewmatrix,
        raster_settings.projmatrix,
        raster_settings.tanfovx,
        raster_settings.tanfovy,
        grad_out_color,
        sh,
        raster_settings.sh_degree,
        raster_settings.campos,
        geomBuffer,
        num_rendered,
        binningBuffer,
        imgBuffer,
        raster_settings.debug
    ]
    
    try:
        # Call standard backward kernel
        # Returns: (grad_means2D, grad_colors_precomp, grad_opacities, grad_means3D, grad_cov3Ds_precomp, grad_sh, grad_scales, grad_rotations)
        grads = _C.rasterize_gaussians_backward(*args)
        
        grad_means2D = grads[0]
        grad_colors_precomp = grads[1]
        grad_opacities = grads[2]
        grad_means3D = grads[3]
        grad_cov3Ds_precomp = grads[4]
        grad_sh = grads[5]
        grad_scales = grads[6]
        grad_rotations = grads[7]
        
        return (grad_means3D, grad_means2D, grad_sh, grad_colors_precomp, grad_opacities, grad_scales, grad_rotations, grad_cov3Ds_precomp, None)
        
    except Exception as e:
        if raster_settings.debug:
            args_cpu = copy.deepcopy(args)
            torch.save(args_cpu, 'snapshot_bw.dump')
        raise e
```

### Parameters
*   `f_count`: Boolean flag in `GaussianRasterizationSettings`. Default is `False`. When `True`, enables the counting mechanism [S1, unofficial].

### Edge Cases and Pitfalls
*   **Input Validation**: The forward pass raises an exception if both `shs` and `colors_precomp` are `None`, or if both are not `None` [S1, unofficial].
*   **Covariance Input**: The forward pass raises an exception if `(scales is None or rotations is None)` AND `cov3D_precomp is None`, OR if `(scales is not None or rotations is not None)` AND `cov3D_precomp is not None` [S1, unofficial].
*   **Debugging Snapshots**: If an exception occurs during the forward pass and `raster_settings.debug` is `True`, the arguments are deep-copied to CPU and saved to `snapshot_fw.dump` before re-raising [S1, unofficial]. Similarly, backward pass exceptions save to `snapshot_bw.dump` [S1, unofficial].

## Subtopics

### LightGaussian Pruning
Uses the `gaussians_count` output to identify and remove low-impact Gaussians, reducing model size and inference time [S1, unofficial].

### Importance Scoring
The `important_score` tensor is often derived from the activation counts to guide optimization or compression decisions [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: The forward pass adds negligible overhead to the standard rasterization, as the counting is performed within the same kernel pass over the pixels [S1, unofficial]. The backward pass is identical to the standard rasterizer [S1, unofficial].
*   **Memory Complexity**: Requires additional memory for the `gaussians_count` tensor $(N, 1)$ and `important_score` tensor $(N, 1)$ [S1, unofficial].
*   **Performance**: Measured performance depends on the scene resolution and number of Gaussians. The primary benefit is enabling efficient pruning, which reduces the number of Gaussians $N$ in subsequent iterations, leading to faster rendering times overall [S1, unofficial].
*   **Strengths**: Enables data-driven Gaussian simplification without requiring additional rendering passes [S1, unofficial].
*   **Limitations**: The counts are specific to the current view and lighting conditions; pruning based on counts from a single view may lead to artifacts in other views if not aggregated [S1, unofficial].

## Background
The F-Count rasterization variant was introduced as part of the LightGaussian project by Horizon Research [S1, unofficial]. It was developed to address the computational cost of large-scale 3D Gaussian Splatting models by providing a mechanism to identify and remove redundant Gaussians during training [S1, unofficial]. The method builds on the differentiable rasterization framework established in the original 3D Gaussian Splatting paper [4526-differentiable-radiative-rasterization.md].
