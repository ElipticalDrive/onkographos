# FisherRF

Also called: Active View Selection and Mapping with Radiance Fields Using Fisher Information, Expected Information Gain (EIG) via Fisher Information, FisherRF Uncertainty Estimation

## Overview
FisherRF is a method for estimating predictive uncertainty in 3D Gaussian Splatting (3DGS) parameters and selecting the next-best view by maximizing Expected Information Gain (EIG) [S1, S2]. It quantifies observed information on model parameters using the Fisher Information Matrix (FIM), approximated via a diagonal Gauss-Newton Hessian [S1, S2]. Unlike methods that rely on hypothetical perturbation fields or indirect approximations, FisherRF computes the Hessian of the loss function directly with respect to the radiance field parameters [S2]. This allows for efficient active view selection and uncertainty quantification, leveraging the sparsity of the rendering Jacobian to achieve performance comparable to back-propagation [S2].

## How it works
**Inputs:**
*   $\theta$: The set of trained 3DGS parameters (means, covariances, opacities, spherical harmonics coefficients) [S1].
*   $D$: The set of all rays cast from the training views observed so far [S1].
*   $\mathcal{V}_{cand}$: A pool of candidate views for selection [S2].

**Outputs:**
*   $v^*$: The selected next-best view [S1].
*   $U$: Predictive uncertainty for rendered views [S1].

**Data Structures:**
*   **Hessian ($H$):** A diagonal matrix approximating the precision (inverse covariance) of the parameter posterior [S1]. Stored as a 1D array of size equal to the number of parameters $|\theta|$ [S1].
*   **Jacobian ($J_r$):** For each ray $r$, the gradient of the rendered color $\hat{C}_r$ with respect to $\theta$, i.e., $\frac{\partial \hat{C}_r}{\partial \theta}$ [S1].

**Parameters:**
*   $\epsilon$: A small scalar prior term added to keep $H$ invertible [S1].
*   $\Lambda_r$: Confidence weight for ray $r$. In FisherRF, all rays share the same isotropic value, reducing the formulation to an unweighted squared-error loss [S1].

**Steps:**

1.  **Compute Global Hessian ($H$):**
    Calculate the diagonal Gauss-Newton Hessian of the rendering loss summed over all observed rays $D$ [S1]:
    $$
    \mathbf{H} = \sum_{r \in D} \left( \frac{\partial \hat{C}_r}{\partial \theta} \right)^{\!\top} \Lambda_r \left( \frac{\partial \hat{C}_r}{\partial \theta} \right) + \epsilon \mathbf{I}
    $$
    Since only the diagonal is kept for tractability, this simplifies to summing the squared gradients for each parameter [S1]. The term $\epsilon \mathbf{I}$ ensures invertibility [S1].

2.  **Compute Candidate Hessian ($H_v$):**
    For each candidate view $v \in \mathcal{V}_{cand}$, compute $H_v$ using only the rays associated with view $v$, calculated identically to step 1 but restricted to $v$'s rays [S1].

3.  **Calculate Expected Information Gain (EIG):**
    Compute the EIG for each candidate view $v$ using the approximation:
    $$
    \mathrm{EIG}(v) = \frac{1}{2} \log \det \left( \mathbf{I} + \mathbf{H}_v \mathbf{H}^{-1} \right)
    $$
    To avoid computing the full determinant, FisherRF uses an upper bound approximation based on the trace of the product of the Hessians, exploiting the sparsity of the matrices [S2]. Specifically, the decrease in entropy is approximated by the trace of the product of the candidate view's Hessian and the inverse of the global Hessian [S2].

4.  **Select Next-Best View:**
    Select the view $v^*$ that maximizes the EIG:
    $$
    v^* = \arg \max_{v} \mathrm{EIG}(v)
    $$
    [S1].

5.  **Predictive Uncertainty (Optional):**
    For a given view, predictive uncertainty $U$ is propagated through the rendering Jacobian $J$ using the inverse Hessian:
    $$
    U = J \mathbf{H}^{-1} J^{\top}
    $$
    [S1].

**Pseudocode:**

```python
def compute_fisher_hessian(rays, parameters, epsilon):
    """
    Computes the diagonal Fisher Information Matrix (Hessian) for a set of rays.
    
    Args:
        rays: List of rays, each containing indices of 3D Gaussians contributing to it.
        parameters: Current 3DGS parameters theta.
        epsilon: Small scalar for numerical stability.
        
    Returns:
        H: Diagonal Hessian vector of size len(parameters).
    """
    H = np.zeros(len(parameters))
    
    for ray in rays:
        # Compute rendering Jacobian for this ray: d(C_hat)/d(theta)
        # This requires differentiating the splatting function with respect to parameters.
        # In 3DGS, this is typically done via automatic differentiation or custom CUDA kernels.
        jacobian = compute_rendering_jacobian(ray, parameters)
        
        # Lambda_r is isotropic (constant) in FisherRF, so it can be absorbed or set to 1.
        # H += J^T * J (element-wise square for diagonal approximation)
        H += jacobian ** 2
        
    # Add prior
    H += epsilon
    return H

def compute_eig(h_global, h_candidate):
    """
    Computes the Expected Information Gain (EIG) using the trace approximation.
    
    Args:
        h_global: Diagonal Hessian of observed data (H).
        h_candidate: Diagonal Hessian of candidate view (H_v).
        
    Returns:
        eig: Approximate EIG value.
    """
    # Inverse of diagonal H is element-wise reciprocal
    h_inv = 1.0 / h_global
    
    # Approximation of log det(I + H_v H^-1) using trace
    # log det(I + A) approx trace(A) for small A, or more precisely:
    # The source [S2] states: "approximation of the decrease in entropy by its upper bound, 
    # which is the trace of the product of the Hessian of the candidate view times the Hessian 
    # with respect to all previous views."
    # Note: Strictly, EIG = 0.5 * log det(I + H_v H^-1).
    # If using trace approximation for the log-det term:
    # EIG approx 0.5 * trace(H_v * H^-1)
    
    # Element-wise multiplication of H_v and H^-1
    product = h_candidate * h_inv
    
    # Sum of diagonal elements (Trace)
    trace_val = np.sum(product)
    
    return 0.5 * trace_val

def select_next_best_view(candidate_views, h_global):
    """
    Selects the view with the highest Expected Information Gain.
    """
    best_view = None
    max_eig = -np.inf
    
    for view in candidate_views:
        # Compute Hessian for the candidate view
        h_candidate = compute_fisher_hessian(view.rays, parameters, epsilon)
        
        # Compute EIG
        eig = compute_eig(h_global, h_candidate)
        
        if eig > max_eig:
            max_eig = eig
            best_view = view
            
    return best_view
```

## Operating characteristics
*   **Time Complexity:** The computation of the Hessian is additive over rays [S2]. Due to the sparsity of the scene parameters with respect to disparate rays, the matrix trace computation is as cost-effective as back-propagation [S2].
*   **Performance:** When implemented with 3D Gaussian Splatting, the method evaluates views at 70 fps [S2]. A direct comparison shows FisherRF's efficient CUDA implementation for diagonal Hessian computation takes $11.3 \text{ ms} \pm 33.3 \text{ \mu s}$, compared to $1.1 \text{ s} \pm 2.5 \text{ ms}$ for methods relying on multiple PyTorch backward engine calls (e.g., Goli et al.) [S2].
*   **Memory Complexity:** By keeping only the diagonal elements of the Hessian, memory usage is reduced to $O(|\theta|)$, where $|\theta|$ is the number of parameters [S1].
*   **Strengths:** Direct quantification of observed information on parameters; efficient active view selection and mapping; state-of-the-art results in uncertainty quantification [S2].
*   **Limitations:** Relies on the diagonal approximation of the Hessian, ignoring parameter correlations [S1]. Assumes the posterior is Gaussian (Laplace approximation) [S1].

## Background
FisherRF was introduced to address the lack of literature on active "training" view selection for volumetric rendering [S2]. It leverages Fisher Information to directly quantify observed information on the parameters of Radiance Fields, selecting candidate views by maximizing Expected Information Gain (EIG) [S2]. The method is implemented on top of point-based 3D Gaussian Splatting and Plenoxels radiance field models [S2]. It improves upon previous approaches that relied on hypothetical perturbation fields and indirect approximations, which did not guarantee optimal information gain [S2]. The Hessian of the objective function in volumetric rendering is independent of ground truth data or actual image measurements, allowing information gain to be computed using only camera parameters of candidate views [S2].
