# Sensitivity-Aware Vector Clustering

Also called: Niedemayr et al. compression, Niedermayr, Sensitivity-Aware Scene Compression, Sensitivity-Aware Vector Clustering for 3DGS Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by grouping spherical harmonic (SH) coefficients and Gaussian shape parameters (scale and rotation) into compact codebooks using sensitivity-aware vector quantization [S1, S2]. It distinguishes itself from standard post-training quantization by deriving a sensitivity measure for each parameter to guide the clustering process, prioritizing the preservation of parameters that significantly affect image quality [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An optimized set of 3D Gaussians, each defined by position, opacity, SH coefficients (color), and shape parameters (rotation and scale) [S1].
*   **Output:** Two codebooks (one for color/SH, one for shape), indices mapping each Gaussian to its codebook entries, and the compressed bitstream [S1].

**Data Structures:**
*   **Codebook Entry (Shape):** 4 scalar values for quaternion (rotation) plus 3 scalar values for scaling [S1].
*   **Codebook Entry (Color):** SH coefficient vector [S1].
*   **Gaussian Index:** 32-bit unsigned integer pointing to an entry in the respective codebook [S1].

**Step 1: Sensitivity Calculation**
Calculate the sensitivity $S(p)$ for each scene parameter $p$ by computing its contribution to the training images [S1, S2]. The sensitivity is defined as the gradient of the total image energy with respect to the parameter, normalized by the number of pixels [S1, S2]:

$$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p_i}}{\sum_{i=1}^{N} P_i} $$

Where:
*   $N$ is the number of training images [S1, S2].
*   $E_i$ is the total image energy (sum of RGB components) for image $i$ [S1, S2].
*   $P_i$ is the number of pixels in image $i$ [S1, S2].
*   $\frac{\partial E_i}{\partial p_i}$ is the gradient of the energy with respect to parameter $p$ [S1, S2].

For a vector $x$ (e.g., a set of SH coefficients or a shape vector), the sensitivity $S(x)$ is defined as the maximum sensitivity over its components $d$ [S1]:

$$ S(x) = \max_d S(x_d) $$

This sensitivity is computed via a single backward pass over each of the training images [S1].

**Step 2: Codebook Initialization**
Initialize codebooks randomly with a uniform distribution within the minimum and maximum values of each parameter [S1].

**Step 3: Sensitivity-Aware Clustering**
Encode color information (SH coefficients) and Gaussian parameters (scale and rotation) into two separate codebooks via sensitivity-aware vector clustering [S1, S2].

1.  **Filtering High-Sensitivity Vectors:** Identify SH vectors with sensitivity higher than a threshold $\beta_c$. These vectors are not clustered but are added directly to the codebook to preserve critical visual details [S1]. A similar threshold $\beta_g$ is used for Gaussian shape parameters [S1].
2.  **Weighted Distance:** For the remaining vectors, compute the pairwise weighted distance $D(x, c_k)$ between a vector $x$ and a centroid $c_k$ [S1]:

    $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$

    Where $S(x)$ is the sensitivity of vector $x$ [S1].
3.  **Assignment:** Assign each vector to the centroid with the minimum distance [S1].
4.  **Centroid Update:** Update centroids using the weighted average formula [S1]:

    $$ c_k = \frac{1}{\sum_{x_i \in A(k)} S(x_i)} \sum_{x_i \in A(k)} S(x_i) x_i $$

    Where $A(k)$ is the set of vectors assigned to centroid $c_k$ [S1].

**Batched Clustering Strategy:**
To improve performance, use a batched clustering strategy [S1]:
1.  Pick a random subset of vectors (batch size $2^{18}$ for color features, $2^{20}$ for Gaussian parameters) [S1].
2.  Compute the update step for the centroids based on the batch [S1].
3.  Update the global centroids using a moving average with decay factor $\lambda_d$ [S1].

**Handling Normalization Errors:**
Clustering normalized covariance matrices can lead to non-unit scaling vectors due to floating-point errors [S1]. To counteract this, re-normalize each codebook vector after each update step by dividing it through the trace of the covariance metric [S1].

**Decomposition:**
After clustering, decompose each codebook entry (covariance matrix) into rotation and scale parameters using eigenvalue decomposition [S1]. This is required for quantization-aware training, as direct optimization of the matrix is not possible [S1]. The final codebook stores 4 scalar values for quaternion (rotation) and 3 scalar values for scaling [S1].

**Step 4: Quantization-Aware Fine-Tuning**
Fine-tune parameters on the training set using quantization-aware training with Min-Max Quantization to regain information lost during clustering [S1, S2].

1.  **Forward Pass:** Simulate quantization considering a certain number of bits and the moving average of each parameter's min/max values [S2].
2.  **Backward Pass:** Ignore simulated quantization and calculate the gradient for the parameter without quantization [S2].
3.  **Optimization:** Perform optimization steps (e.g., 5000 steps) to adjust the codebook entries and Gaussian parameters [S1].

**Step 5: Entropy Encoding**
Compress the set of Gaussians and codebooks using DEFLATE [S1, S2].
1.  Order the Gaussians by Z-order (Morton order) based on their positions to leverage spatial coherence [S1, S2].
2.  Apply DEFLATE (LZ77 + Huffman coding) to the ordered indices and codebook data [S1, S2].

**Pseudocode:**

```python
import numpy as np

def calculate_sensitivity(gradient_sum, pixel_counts):
    """
    Calculate sensitivity S(p) for a parameter p.
    gradient_sum: Sum of gradients dE/dp over all training images.
    pixel_counts: Sum of pixels P_i over all training images.
    """
    return gradient_sum / pixel_counts

def sensitivity_aware_kmeans(vectors, sensitivities, centroids, decay_factor, batch_size):
    """
    Perform one step of sensitivity-aware k-Means clustering.
    vectors: Array of shape (N, D) containing the vectors to cluster.
    sensitivities: Array of shape (N,) containing sensitivity S(x) for each vector.
    centroids: Array of shape (K, D) containing current centroids.
    decay_factor: Lambda_d for moving average update.
    batch_size: Number of vectors to process in this step.
    """
    # Select random batch
    indices = np.random.choice(len(vectors), size=batch_size, replace=False)
    batch_vectors = vectors[indices]
    batch_sensitivities = sensitivities[indices]
    
    # Compute distances: D(x, ck) = S(x) * ||x - ck||^2
    # Expand dimensions for broadcasting: (batch, 1, D) - (1, K, D)
    diff = batch_vectors[:, np.newaxis, :] - centroids[np.newaxis, :, :]
    sq_dist = np.sum(diff ** 2, axis=2)  # (batch, K)
    weighted_dist = sq_dist * batch_sensitivities[:, np.newaxis]  # (batch, K)
    
    # Assign to nearest centroid
    assignments = np.argmin(weighted_dist, axis=1)  # (batch,)
    
    # Update centroids using moving average
    for k in range(centroids.shape[0]):
        mask = assignments == k
        if np.sum(mask) > 0:
            assigned_vectors = batch_vectors[mask]
            assigned_sensitivities = batch_sensitivities[mask]
            
            # Weighted average for new centroid
            weight_sum = np.sum(assigned_sensitivities)
            new_centroid = np.sum(assigned_vectors * assigned_sensitivities[:, np.newaxis], axis=0) / weight_sum
            
            # Update global centroid with decay
            centroids[k] = (1 - decay_factor) * centroids[k] + decay_factor * new_centroid
            
            # Re-normalize if necessary (example for shape parameters)
            # centroids[k] = normalize_covariance(centroids[k])
            
    return centroids
```

**Parameters:**
*   $\lambda_d$: Decay factor for the moving average in batched clustering. Typical value: 0.8 [S1].
*   Batch size for color features: $2^{18}$ [S1].
*   Batch size for Gaussian parameters: $2^{20}$ [S1].
*   Codebook size $K$: 4096 [S1].
*   $\beta_c$: Sensitivity threshold for SH coefficients. Gaussians with sensitivity $> \beta_c$ are excluded from clustering and added directly to the codebook. Typical value: $6 \times 10^{-7}$ [S1].
*   $\beta_g$: Sensitivity threshold for Gaussian shape parameters. Typical value: $3 \times 10^{-6}$ [S1].
*   Optimization steps for quantization-aware fine-tuning: 5000 [S1].

**Edge Cases and Pitfalls:**
*   **Floating Point Errors:** Clustering normalized covariance matrices can lead to non-unit scaling vectors. This is handled by re-normalizing each codebook vector after each update step by dividing it through the trace of the covariance metric [S1].
*   **High Sensitivity Vectors:** A small percentage of SH coefficients (< 5%) have high sensitivity. These must be excluded from clustering and added directly to the codebook to maintain visual quality [S1].

## Operating characteristics
*   **Compression Ratio:** Achieves up to 31× compression on real-world scenes with minimal degradation of visual quality [S1].
*   **Rendering Speed:** Enables real-time rendering on lightweight GPUs, up to 4× higher framerates than the original 3DGS via an optimized GPU compute pipeline [S1].
*   **Memory:** Significantly reduces memory consumption, making it suitable for network streaming and low-power devices [S1].
*   **Strengths:** Preserves visual quality by prioritizing sensitive parameters; efficient rendering due to codebook lookups; suitable for web-based rendering (WebGPU) [S1].
*   **Limitations:** Requires a fine-tuning phase (quantization-aware training) which adds to the post-processing time; sensitivity calculation requires backward passes over training images [S1].

## Background
*   **Origin:** Proposed by Niedemayr et al. in 2024 [S1].
*   **Context:** Developed to address the high memory consumption of 3D Gaussian Splatting, making it suitable for applications like network streaming and rendering on low-power devices [S1].
*   **Relation to NeRF:** Inspired by volumetric radiance field compression methods that use vector clustering [S1].
