# Distance-based Gaussian Splatting

Also called: Mesh-based Gaussian Splatting, Tightly/Loosely-bound Gaussian Splatting

## Overview
Distance-based Gaussian Splatting is a method for high-quality rendering and geometric refinement that establishes a bidirectional connection between a pre-existing 3D mesh $\mathcal{M}$ and a set of 3D Gaussian splats $\mathcal{G}$ [S1]. It solves the problem of redundant or misaligned Gaussian primitives that typically arise when initializing splats on dense meshes or when standard densification creates geometry that deviates from the underlying surface [S1]. Unlike standard 3D Gaussian Splatting which treats all splats equally, this method classifies splats as either "tightly-bound" (aligned with the mesh surface) or "loosely-bound" (allowing for surface artifacts or fine details) based on their distance to the mesh, and masks out splats occluded by the opaque mesh surface [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A trained 3D Gaussian Splatting model $\mathcal{G} = \{G_i\}_{i=1}^M$ and a target mesh $\mathcal{M} = (\mathcal{V}, \mathcal{F})$ [S1].
*   **Output:** A refined set of Gaussian splats $\mathcal{G}'$ and rendered images that respect the mesh geometry while preserving appearance details [S1].

**Data Structures:**
Each Gaussian primitive $G_i$ retains the standard 3DGS attributes [Parent]:
*   Center position $\mathbf{p}_i \in \mathbb{R}^3$.
*   3D covariance matrix $\mathbf{\Sigma}_i \in \mathbb{R}^{3\times3}$, parameterized by rotation $\mathbf{R}_i$ (quaternion $\mathbf{q} \in \mathbb{R}^4$) and scale $\mathbf{S}_i \in \mathbb{R}^3$ such that $\mathbf{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^T \mathbf{R}_i^T$ [S1].
*   Opacity $o_i \in [0, 1]$.
*   View-dependent color $\mathbf{c}_i$ represented by spherical harmonics [S1].
*   Classification label: Tightly-bound ($G_{ti}$) or Loosely-bound ($G_{li}$) [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize a 3D Gaussian splat at the center $\mathbf{m}_j$ of each triangle face $\mathbf{f}_j$ of the mesh $\mathcal{M}$ [S1].
2.  **Occlusion Masking (Pre-rendering):** For a given viewpoint $\mathbf{P}_k$, render a depth map $D_k$ from the mesh $\mathcal{M}$. Mask out any Gaussian splats whose projected depth is greater than the mesh depth, assuming the mesh surface is entirely opaque [S1].
    *   *Note:* When applying this masking, add a small offset of $0.01$ to the depth $D_k$ to prevent self-occlusion artifacts due to precision issues [S1].
3.  **Visibility Assessment & Pruning:** Assess the visibility of all Gaussian splats across all training views. Identify splats located behind the mesh surface that are never observed by any training view. Remove these redundant splats at specific training iterations (e.g., every 500 iterations) [S1].
4.  **Distance Calculation:** Calculate the Euclidean distance $d_i$ between each Gaussian splat’s center $\mathbf{p}_i$ and the corresponding closest mesh face $\mathbf{f}_j$ [S1].
5.  **Classification:** Classify each Gaussian splat based on the distance threshold $d_{th}$:
    *   If $d_i < d_{th}$, classify as **Tightly-bound** ($G_{ti}$).
    *   If $d_i \ge d_{th}$, classify as **Loosely-bound** ($G_{li}$) [S1].
    *   *Typical Value:* $d_{th} = 0.01$ [S1].
6.  **Alignment (Tightly-bound):** For tightly-bound splats $G_{ti}$, flatten the splats and align them with the mesh surface. This is achieved by applying a normal consistency loss $\mathcal{L}_{nc}$ that refines the orientation of the Gaussian ellipsoids to match the mesh normal $\mathbf{n}_i$ [S1].
7.  **Rendering:** Render the image using alpha blending. The 2D Gaussian value $g_i(\mathbf{x})$ is computed in ray space.
    *   Transform camera space to ray space using the affine transformation $\mathbf{J}_i \in \mathbb{R}^{2\times3}$ defined by the camera position $\mathbf{p}_{ci}$.
    *   Compute the 2D covariance in ray space: $\mathbf{\Sigma}'_i = \mathbf{J}_i \mathbf{\Sigma}_{ic} \mathbf{J}_i^T$, where $\mathbf{\Sigma}_{ic}$ is the covariance in camera space [S1].
    *   The 2D Gaussian is defined as:
        $$ g_i(\mathbf{x}) = e^{-\frac{1}{2}(\mathbf{x}-\mathbf{p}'_i)^T {\mathbf{\Sigma}'_i}^{-1}(\mathbf{x}-\mathbf{p}'_i)} $$
    *   The final color $\mathbf{c}$ is computed via alpha blending:
        $$ \mathbf{c} = \sum_{i=1}^{n} \mathbf{c}_i \alpha_i \prod_{j=1}^{i-1} (1-\alpha_j), \quad \alpha_i = o_i g_i(\mathbf{x}) $$
        where $\mathbf{p}'_i$ is the 2D center and $\mathbf{\Sigma}'_i$ is the 2D covariance [S1].

**Parameters:**
*   $d_{th}$ (Distance threshold): Separates tightly-bound from loosely-bound splats. Typical value: $0.01$ [S1].
*   Pruning Interval: Frequency of removing occluded splats. Typical value: Every 500 iterations [S1].
*   Depth Offset: Added to mesh depth for masking. Typical value: $0.01$ [S1].
*   Loss Weights: $\lambda_{img} = 0.001$, $\lambda_{nc} = 0.1$, $\lambda_{min} = 0.1$, $\lambda_{max} = 10$, $\lambda_{proj} = 50$ [S1].

**Edge Cases and Pitfalls:**
*   **Self-occlusion:** Rendering depth from the mesh and comparing it to Gaussian depth can lead to precision errors where splats on the surface are incorrectly masked. Mitigated by adding an offset ($0.01$) to the mesh depth [S1].
*   **Mesh Artifacts:** Tightly binding all splats to the mesh can degrade rendering quality if the mesh contains severe artifacts. The loosely-bound category allows splats to deviate from the mesh to capture fine details or correct mesh errors [S1].
*   **Redundancy:** Initializing splats on every triangle of a high-resolution mesh (e.g., 44 million triangles) leads to excessive GPU memory usage and redundant splats. Pruning is essential [S1].

## Operating characteristics
*   **Time Complexity:** Rendering complexity is dominated by the sorting and alpha-blending of $N$ Gaussians, $O(N \log N)$ or $O(N)$ with spatial hashing, similar to standard 3DGS [S1]. The additional cost lies in the distance calculation to the mesh and occlusion checks, which are performed periodically (e.g., every 500 iterations) rather than per frame [S1].
*   **Memory Complexity:** Memory usage is proportional to the number of active Gaussians. By pruning occluded splats and classifying them, the method can reduce the effective number of splats contributing to rendering compared to a naive initialization on a dense mesh [S1].
*   **Strengths:** Reduces GPU memory usage by eliminating redundant splats behind the mesh. Improves geometric alignment for tightly-bound regions while preserving appearance quality in loosely-bound regions [S1].
*   **Limitations:** Dependent on the quality of the input mesh. If the mesh is poor, loosely-bound splats must compensate, potentially leading to less coherent geometry [S1].
*   **When to use:** When a high-quality, lightweight mesh is available and the goal is to render high-fidelity appearance while maintaining a connection to the underlying geometry [S1].
*   **When not to use:** When no mesh is available, or when the scene geometry is too complex/unstructured to be represented by a single coherent mesh [S1].

## Background
Distance-based Gaussian Splatting was introduced in the paper "MeshGS: Adaptive Mesh-Aligned Gaussian Splatting for High-Quality Rendering" by Jaehoon et al. [S1]. The method addresses the limitations of existing approaches like LTM (Lightweight Triangle Mesh) and SuGaR, which either require a large number of triangles/vertices to represent complex geometry or suffer from rapid GPU memory growth due to redundant Gaussian splats [S1]. It builds upon the standard 3D Gaussian Splatting framework [22] but introduces a classification mechanism based on the distance to a pre-reconstructed mesh [S1].
