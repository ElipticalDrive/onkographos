# Error-guided Guided Sampling

Also called: Error-guided multi-scale sampling, Guided sampling step, EMS

## Overview
Error-guided Guided Sampling (EMS) is a densification strategy for 3D Gaussian Splatting that replaces gradient-based refinement with SSIM-driven error localization. It identifies training views with low structural similarity, generates a pixel-wise error mask, and spawns new Gaussians exclusively in high-error regions using depth-aware placement to avoid occlusion artifacts. Unlike standard densification which relies on accumulated 2D positional gradients and radius thresholds, EMS uses a patch-based median depth estimator and a checkerboard center mask to control spatial density and prevent overlapping primitives [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   Current Gaussian set $\mathcal{G}$ with parameters $(\mu_k, \Sigma_k, \alpha_k, \mathbf{c}_k)$.
*   Current training iteration $I$.
*   Reference image $I_{gt}$ and rendered image $I_{render}$ for a selected viewpoint.
*   Depth map $D$ corresponding to the viewpoint.
*   Configuration parameters: $I_{start}$ (start iteration), $I_{max}$ (max iterations), $T_{ssim}$ (SSIM threshold, default 0.88), $T_{err}$ (error percentile), $N_{patch}$ (patch size, 16), $N_{spawn}$ (points per ray/region).

**Outputs:**
*   Updated Gaussian set $\mathcal{G}'$ with new primitives added in high-error regions.
*   Updated buffers: `visibility_filter`, `radii`, `viewspace_point_tensor`.

### Data Structures
*   **Error Mask ($M_{err}$):** Binary tensor of shape $(H, W)$, where $H, W$ are image dimensions. $M_{err}[i,j] = 1$ if pixel $(i,j)$ is in a high-error patch, else $0$.
*   **Center Mask ($M_{center}$):** Binary tensor of shape $(H, W)$ enforcing minimum spacing. Initialized to ones, then set to $0$ at every other pixel in a $16 \times 16$ grid pattern to prevent clustering.
*   **Depth Map ($D$):** Float tensor of shape $(H, W)$. Values equal to $15.0$ are treated as invalid [S1, unofficial].

### Steps
1.  **Trigger Check:**
    EMS is triggered if:
    *   $I > I_{start}$
    *   A specific flag `flag_ems` is set to $2$ [S1, unofficial].
    *   The number of EMS iterations performed $C_{ems} < I_{max}$.
    *   The current view is in the selected view list.
    *   $I - I_{last\_ems} > 100$ [S1, unofficial].
    
    If triggered, remove the view from the selection list, increment $C_{ems}$, update $I_{last\_ems} = I$, and compute the current SSIM score $S_{curr}$.

2.  **Error Mask Generation:**
    If $S_{curr} < T_{ssim}$:
    *   Normalize images: $I'_{adj} = I_{render} / (\text{mean}(I_{render}) + \epsilon)$ and $I'_{gt} = I_{gt} / (\text{mean}(I_{gt}) + \epsilon)$, where $\epsilon = 0.01$ [S1, unofficial].
    *   Compute absolute difference per channel: $D_{diff} = |I'_{adj} - I'_{gt}|$.
    *   Sum over channels: $D_{sum} = \sum_{c} D_{diff}[c]$.
    *   Flatten $D_{sum}$, sort values, and find the threshold $T_{th}$ at the $T_{err}$-th percentile.
    *   Create binary mask: $M_{raw}[i,j] = 1$ if $D_{sum}[i,j] > T_{th}$, else $0$.

3.  **Patch Processing:**
    *   Pad $M_{raw}$ to multiples of $N_{patch} \times N_{patch}$ using constant padding (value 0).
    *   Extract non-overlapping $16 \times 16$ patches.
    *   Filter patches: A patch is kept if the sum of its values $> 16 \times 16 \times 0.85$ [S1, unofficial].
    *   Broadcast the kept patch mask back to the full image resolution to form $M_{err}$.

4.  **Depth Estimation and Clamping:**
    *   Extract the depth map $D$ for the current view.
    *   Pad $D$ to multiples of $16 \times 16$.
    *   Extract $16 \times 16$ patches from $D$.
    *   Compute the median depth for each patch along the spatial dimensions.
    *   Broadcast the median depth back to the patch resolution and reshape to $(H, W)$.
    *   Crop to original dimensions.
    *   Identify invalid depth pixels ($D == 15.0$) and mask them out [S1, unofficial].
    *   Compute the 70th percentile of valid depths ($D_{med}$).
    *   Clamp depth values: $D_{clamped} = \min(D, D_{med})$ [S1, unofficial].

5.  **Center Mask Application:**
    *   Create $M_{center}$: Initialize with ones. Set $M_{center}[i,j] = 0$ for $i \in \{0, 2, \dots, 14\}$ and $j \in \{0, 2, \dots, 14\}$ within each $16 \times 16$ block.
    *   Apply border removal: Strip the top/bottom $10\%$ and left/right $10\%$ of $M_{center}$ to prevent edge artifacts [S1, unofficial].
    *   Combine masks: $M_{final} = M_{err} \land M_{center}$.

6.  **Gaussian Spawning:**
    *   Find indices $P_{bad}$ where $M_{final} > 0$.
    *   For each point in $P_{bad}$, spawn new Gaussians using the clamped depth $D_{clamped}$ and the original GT image.
    *   The number of points spawned per location is determined by $N_{spawn}$ (parameter `opt.farray`) [S1, unofficial].
    *   New Gaussians are added to $\mathcal{G}$.

7.  **Buffer Update:**
    *   Extend `visibility_filter` by concatenating zeros for the new points.
    *   Extend `radii` by concatenating zeros for the new points.
    *   Extend `viewspace_point_tensor` by concatenating zeros for the new points [S1, unofficial].

### Pseudocode

```python
def error_guided_guided_sampling(gaussians, iteration, viewpoint_cam, gt_image, render_image, depth_map, config):
    """
    Implements Error-guided Guided Sampling (EMS).
    
    Args:
        gaussians: Current Gaussian object containing xyz, opacity, scales, rotations, sh_coeffs.
        iteration: Current training iteration.
        viewpoint_cam: Camera object with image_name, intrinsics, etc.
        gt_image: Ground truth image tensor (H, W, 3).
        render_image: Rendered image tensor (H, W, 3).
        depth_map: Depth map tensor (H, W).
        config: Configuration object with EMS parameters.
        
    Returns:
        Updated gaussians object.
    """
    # 1. Trigger Check
    if iteration <= config.ems_start_from_iterations:
        return gaussians
    if config.flag_ems != 2:
        return gaussians
    if config.ems_cnt >= config.selected_length:
        return gaussians
    if viewpoint_cam.image_name not in config.select_views:
        return gaussians
    if iteration - config.last_ems_iteration <= 100:
        return gaussians

    # Update state
    config.select_views.remove(viewpoint_cam.image_name)
    config.ems_cnt += 1
    config.last_ems_iteration = iteration
    
    # Compute SSIM
    ssim_val = compute_ssim(render_image, gt_image)
    if ssim_val >= 0.88:
        return gaussians

    # 2. Error Mask Generation
    # Normalize
    eps = 0.01
    img_adj = render_image / (torch.mean(render_image) + eps)
    gt_adj = gt_image / (torch.mean(gt_image) + eps)
    
    # Diff
    diff = torch.abs(img_adj - gt_adj)
    diff_sum = torch.sum(diff, dim=0) # Sum over channels
    
    # Threshold
    flat_diff = diff_sum.flatten()
    threshold = torch.quantile(flat_diff, config.ems_thr)
    outmask = (diff_sum > threshold).float()

    # 3. Patch Processing
    kh, kw = 16, 16
    dh, dw = 16, 16
    
    # Pad to multiples of 16
    pad_h = (kh - outmask.shape[0] % kh) % kh
    pad_w = (kw - outmask.shape[1] % kw) % kw
    outmask_padded = torch.nn.functional.pad(outmask, (0, pad_w, 0, pad_h), mode='constant', value=0)
    
    # Unfold into patches
    patches = outmask_padded.unfold(0, kh, dh).unfold(1, kw, dw)
    # patches shape: (num_patches, kh, kw)
    patches = patches.reshape(-1, kh, kw)
    
    # Filter patches
    patch_sum = patches.sum(dim=(1, 2))
    patch_threshold = kh * kw * 0.85
    patch_mask = (patch_sum > patch_threshold).unsqueeze(1).unsqueeze(2) # (num_patches, 1, 1)
    
    # Broadcast back
    outmask_filtered = patches * patch_mask
    # Reshape back to image size
    # Note: Implementation details for reshaping unfold output back to spatial dims vary.
    # Assuming standard unfold->fold logic or manual reconstruction.
    # Here we assume a helper `fold_patches` exists or we reconstruct manually.
    # For self-contained pseudocode, we simulate the reconstruction:
    h_p, w_p = outmask_padded.shape
    num_patches_h = h_p // kh
    num_patches_w = w_p // kw
    
    reconstructed_mask = torch.zeros_like(outmask_padded)
    for i in range(num_patches_h):
        for j in range(num_patches_w):
            idx = i * num_patches_w + j
            reconstructed_mask[i*kh:(i+1)*kh, j*kw:(j+1)*kw] = outmask_filtered[idx]
            
    # Crop to original size
    outmask_final = reconstructed_mask[:outmask.shape[0], :outmask.shape[1]]

    # 4. Depth Processing
    depth_padded = torch.nn.functional.pad(depth_map, (0, pad_w, 0, pad_h), mode='constant', value=0)
    depth_patches = depth_padded.unfold(0, kh, dh).unfold(1, kw, dw).reshape(-1, kh*kw)
    
    # Median depth per patch
    median_depth_patches = torch.median(depth_patches, dim=1)
    
    # Broadcast median depth back to patch size
    median_depth_patches_expanded = median_depth_patches.unsqueeze(1).unsqueeze(2).repeat(1, kh, kw)
    
    # Reconstruct depth map
    reconstructed_depth = torch.zeros_like(depth_padded)
    for i in range(num_patches_h):
        for j in range(num_patches_w):
            idx = i * num_patches_w + j
            reconstructed_depth[i*kh:(i+1)*kh, j*kw:(j+1)*kw] = median_depth_patches_expanded[idx]
            
    depth_final = reconstructed_depth[:depth_map.shape[0], :depth_map.shape[1]]
    
    # Invalid depth mask (15.0)
    invalid_depth_mask = (depth_final == 15.0)
    
    # Clamp depth
    valid_depths = depth_final[~invalid_depth_mask]
    if valid_depths.numel() > 0:
        median_depth_global = torch.quantile(valid_depths, 0.7)
        depth_final = torch.where(depth_final > median_depth_global, median_depth_global, depth_final)
    else:
        median_depth_global = 0.0 # Fallback

    # 5. Center Mask
    midpatch = torch.ones_like(outmask_final)
    # Set every other pixel in 16x16 grid to 0
    # This is a checkerboard pattern within each 16x16 block
    for i in range(0, kh, 2):
        for j in range(0, kw, 2):
            # Apply to all blocks
            for block_i in range(num_patches_h):
                for block_j in range(num_patches_w):
                    r = block_i * kh + i
                    c = block_j * kw + j
                    if r < midpatch.shape[0] and c < midpatch.shape[1]:
                        midpatch[r, c] = 0
                        
    # Remove 10% border
    h, w = midpatch.shape
    offset_h = h // 10
    offset_w = w // 10
    center_mask = midpatch[offset_h:h-offset_h, offset_w:w-offset_w]
    outmask_final = outmask_final[offset_h:h-offset_h, offset_w:w-offset_w]
    
    # Combine
    final_mask = (outmask_final > 0) & (center_mask > 0)
    
    # 6. Spawn Gaussians
    bad_indices = torch.nonzero(final_mask, as_tuple=False).squeeze()
    if bad_indices.numel() == 0:
        return gaussians
        
    # Spawn new Gaussians
    # The actual spawning logic is encapsulated in add_gaussians
    # Parameters: bad_indices, viewpoint_cam, depth_final, gt_image, num_per_ray, ray_ends, depth_max, shuffle
    gaussians.add_gaussians(
        bad_indices=bad_indices,
        viewpoint_cam=viewpoint_cam,
        depth=depth_final,
        gt_image=gt_image,
        num_per_ray=config.farray,
        ray_ends=config.ray_ends,
        depth_max=config.depth_max,
        shuffle=config.shuffle_ems != 0
    )
    
    # 7. Buffer Update
    # Extend buffers with zeros for new points
    num_new = gaussians.get_xyz.shape[0] - gaussians.prev_xyz_count # Assuming prev_xyz_count tracks old size
    # Note: In the source, buffers are extended by concatenating zeros.
    # visibility_filter
    gaussians.visibility_filter = torch.cat([gaussians.visibility_filter, torch.zeros(num_new, device="cuda", dtype=torch.bool)])
    # radii
    gaussians.radii = torch.cat([gaussians.radii, torch.zeros(num_new, device="cuda")])
    # viewspace_point_tensor
    gaussians.viewspace_point_tensor = torch.cat([gaussians.viewspace_point_tensor, torch.zeros(num_new, 3, device="cuda")])
    
    return gaussians
```

### Parameters
*   `emsstartfromiterations`: Iteration index after which EMS begins. Not given in the sources.
*   `selectedlength`: Maximum number of EMS iterations. Not given in the sources.
*   `emsthr`: Percentile threshold for error mask generation. Controls sensitivity. Not given in the sources.
*   `farray`: Number of points to spawn per error region/ray. Not given in the sources.
*   `rayends`: Ray end parameter for Gaussian placement. Not given in the sources.
*   `shuffle_ems`: Boolean flag to shuffle spawning order. Not given in the sources.

### Edge Cases and Pitfalls
*   **Invalid Depth:** Depth values exactly equal to $15.0$ are treated as invalid and masked out to prevent spawning in occluded or missing geometry regions [S1, unofficial].
*   **Edge Artifacts:** A $10\%$ border is stripped from the center mask to prevent overlapping Gaussians at image boundaries [S1, unofficial].
*   **Clustering:** The center mask uses a checkerboard-like pattern (every other pixel set to $0$ in a $16 \times 16$ grid) to enforce minimum spacing between newly spawned Gaussians [S1, unofficial].
*   **Depth Clamping:** Depth values above the 70th percentile of valid depths are clamped to the median to prevent spawning in far-away erroneous regions [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The method involves SSIM computation, image normalization, and patch-based operations. The complexity is dominated by the patch extraction and depth median calculation, which is $O(H \cdot W)$ per view. The spawning step is proportional to the number of high-error pixels.
*   **Memory Complexity:** Requires storage for the error mask, depth map, and center mask, all of size $O(H \cdot W)$. Buffer extensions are $O(N_{new})$.
*   **Strengths:** Targets specific regions with low SSIM, which may correspond to structural errors missed by gradient-based methods. The depth-aware placement reduces artifacts from occlusion.
*   **Limitations:** Computationally more expensive than gradient-based densification due to SSIM and patch processing. Requires careful tuning of thresholds ($T_{ssim}$, $T_{err}$).
*   **When to Use:** Dynamic or 4D scenes where structural changes are significant and gradient-based methods may fail to capture them [S1, unofficial].
*   **When Not to Use:** Static scenes with simple geometry where gradient-based densification is sufficient.

## Background
Error-guided Guided Sampling was introduced in the context of SpacetimeGaussians, a method for training 3D Gaussian Splatting on dynamic/4D scenes [S1, unofficial]. It was developed by researchers at OPPO US Research. The method addresses limitations of standard 3DGS densification, which relies on 2D positional gradients and radius thresholds, by incorporating SSIM-based view selection and pixel-wise error thresholding.
