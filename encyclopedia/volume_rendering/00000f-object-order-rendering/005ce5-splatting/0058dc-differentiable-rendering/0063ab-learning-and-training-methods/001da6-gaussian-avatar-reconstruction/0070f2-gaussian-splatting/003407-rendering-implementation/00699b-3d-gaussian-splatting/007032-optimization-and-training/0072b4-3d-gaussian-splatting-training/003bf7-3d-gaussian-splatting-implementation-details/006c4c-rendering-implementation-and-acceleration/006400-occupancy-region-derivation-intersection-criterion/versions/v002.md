# Occupancy Region Derivation & ϵ-Intersection Criterion

Also called: Adaptive Threshold Intersection, Elliptic Occupancy Region

## Overview
This method defines a robust, surface-aligned elliptic occupancy region $\Omega_i$ for each 3D Gaussian primitive to determine splat intersections, avoiding strict binary overlap checks that are sensitive to minor misalignments [S1]. It differs from standard bounding-box or simple distance-based culling by using a normal-wise offset metric $\delta_{ij}$ combined with an adaptive threshold $\epsilon$ to declare intersections, ensuring stability in differentiable rendering pipelines [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   Gaussian primitive $G_i$ defined by mean $p_i$, covariance $\Sigma_i$, opacity $\alpha_i$, and normal $n_i$.
*   Covariance decomposition: $\Sigma_i = R_i S_i S_i^\top R_i^\top$, where $R_i = [r_1, r_2, r_3]$ is the rotation matrix and $S_i = \text{diag}(\sigma_1, \sigma_2, 0)$ is the scale matrix [S1].
*   Second Gaussian primitive $G_j$ (for intersection check).
*   Adaptive threshold parameter $\bar{V}_{ip}$ (passed through a sigmoid function) [S1].
*   Intersection tolerance $\epsilon > 0$ [S1].

**Outputs:**
*   Boolean intersection status between $G_i$ and $G_j$.
*   The occupancy region $\Omega_i$ (implicitly defined for computation) [S1].

### Data Structures
The method operates on 3D vectors and matrices. Key derived structures include:
*   **Local Coordinate System:** Defined by basis vectors $r_1, r_2$ (in-plane) and $n_i$ (normal).
*   **Occupancy Region $\Omega_i$:** Parametrized by center $p_i$, normal $n_i$, orthonormal in-plane directions $r_{i,1}, r_{i,2}$, and semi-axis lengths $a_i, b_i$ (derived from $\sigma_1, \sigma_2$ and $\lambda_i$) [S1].

### Steps

1.  **Compute Adaptive Threshold $T_i$:**
    Calculate the threshold $T_i$ using the opacity $\alpha_i$, the minimum rendering contribution threshold $c = 1/255$, and the adaptive threshold $\bar{V}_{ip}$ [S1]:
    $$
    T_i := \max \left( \bar{V}_{ip}, \ln \frac{c}{\alpha_i} \right)
    $$
    Note: Entries with $\alpha_i < c$ are discarded, and since $\bar{V}_{ip}$ is sigmoid-scaled, $T_i$ ensures $\lambda_i$ is strictly positive [S1].

2.  **Compute Eigenvalue Parameter $\lambda_i$:**
    $$
    \lambda_i := -2 \ln(T_i)
    $$
    [S1]

3.  **Define Occupancy Region $\Omega_i$:**
    The region $\Omega_i$ is the set of points $x$ satisfying the Gaussian density condition relative to $T_i$. In the local coordinate system $\xi = R_i^\top (x - p_i) = (\xi_1, \xi_2, 0)^\top$, the condition is:
    $$
    \frac{\xi_1^2}{\sigma_1^2} + \frac{\xi_2^2}{\sigma_2^2} < \lambda_i, \quad \xi_3 = 0
    $$
    Equivalently, using the Moore–Penrose pseudoinverse $\Sigma_i^+$ of the rank-2 covariance matrix:
    $$
    (x - p_i)^\top \Sigma_i^+ (x - p_i) < \lambda_i, \quad \xi_3 = 0
    $$
    [S1]
    
    The region can be parametrized for sampling or geometric queries using $\rho \in [0, 1)$ and $\theta \in (0, 2\pi]$:
    $$
    \Omega_i = \left\{ p_i + \sqrt{\lambda_i} \rho (\sigma_1 \cos \theta \, r_1 + \sigma_2 \sin \theta \, r_2) \mid \rho \in [0, 1), \theta \in (0, 2\pi] \right\}
    $$
    [S1]

4.  **Compute Normal-wise Offset $\delta_{ij}$:**
    To determine intersection robustness, compute the minimum translation distance $t$ along the normal $n_i$ required for $\Omega_j$ to touch $\Omega_i$:
    $$
    \delta_{ij} := \inf_{t \in \mathbb{R}} |t| \quad \text{such that} \quad \Omega_i \cap (\Omega_j - t n_i) \neq \emptyset
    $$
    [S1]
    
    **Numerical Approximation of $\delta_{ij}$:**
    To compute $\delta_{ij}$ efficiently, map the geometry to a local coordinate system aligned with $\Omega_i$. Define scalar coordinate functions for any point $x$:
    $$
    X(x) = \frac{\langle x - p_i, r_1 \rangle}{a_i}, \quad Y(x) = \frac{\langle x - p_i, r_2 \rangle}{b_i}, \quad Z(x) = \langle x - p_i, n_i \rangle
    $$
    where $a_i = \sqrt{\lambda_i}\sigma_1$ and $b_i = \sqrt{\lambda_i}\sigma_2$ are the effective semi-axis lengths [S1].
    
    In this system, $\Omega_i$ becomes the unit disk in the plane $Z=0$:
    $$
    \Omega'_i = \{ (X, Y, Z) \mid X^2 + Y^2 \le 1, Z = 0 \}
    $$
    [S1]
    
    $\Omega_j$ is mapped to an elliptic patch $\Omega'_j$. The offset $\delta_{ij}$ is the minimum absolute $Z$-value of points in $\Omega'_j$ that lie within the unit disk projection:
    $$
    \delta_{ij} = \inf \{ |Z(x)| \mid X(x)^2 + Y(x)^2 \le 1, x \in \Omega_j \}
    $$
    [S1]
    
    In practice, approximate this infimum by sampling points on $\Omega'_j$, filtering those with $X^2 + Y^2 \le 1$, and taking the minimum $|Z|$ value:
    $$
    \hat{\delta}_{ij} = \min_k |Z_k|
    $$
    where $Z_k$ are the $Z$-values of sampled points $x_k \in \Omega_j$ satisfying the projection constraint [S1].

5.  **Apply $\epsilon$-Intersection Criterion:**
    Declare that $G_i$ and $G_j$ intersect if:
    $$
    \hat{\delta}_{ij} \le \epsilon
    $$
    [S1]

### Pseudocode

```python
import math
import numpy as np

def compute_occupancy_region_params(gaussian_i, adaptive_threshold_V_ip):
    """
    Computes the parameters for the elliptic occupancy region of a Gaussian.
    
    Args:
        gaussian_i: Object containing mean p_i, rotation matrix R_i (3x3), 
                    scale sigma_1, sigma_2, opacity alpha_i.
        adaptive_threshold_V_ip: Scalar adaptive threshold.
        
    Returns:
        params: Dictionary with p_i, r1, r2, n_i, a_i, b_i, lambda_i.
    """
    c = 1.0 / 255.0
    alpha_i = gaussian_i.alpha
    V_ip = adaptive_threshold_V_ip
    
    # Step 1: Compute T_i
    # Note: Source implies V_ip is pre-sigmoided or handled such that T_i is valid.
    # If V_ip is raw, it should be sigmoid(V_ip). Assuming V_ip is the value 
    # passed through sigmoid as per source description.
    term1 = V_ip
    term2 = math.log(c / alpha_i)
    T_i = max(term1, term2)
    
    # Step 2: Compute lambda_i
    lambda_i = -2.0 * math.log(T_i)
    
    # Step 3: Extract basis vectors
    R_i = gaussian_i.R
    r1 = R_i[:, 0]
    r2 = R_i[:, 1]
    n_i = R_i[:, 2] # Normal is the third column of rotation matrix
    
    # Effective semi-axes
    sigma_1 = gaussian_i.sigma_1
    sigma_2 = gaussian_i.sigma_2
    a_i = math.sqrt(lambda_i) * sigma_1
    b_i = math.sqrt(lambda_i) * sigma_2
    
    return {
        'p_i': gaussian_i.p,
        'r1': r1,
        'r2': r2,
        'n_i': n_i,
        'a_i': a_i,
        'b_i': b_i,
        'lambda_i': lambda_i
    }

def sample_occupancy_region(params, num_samples=100):
    """
    Samples points from the occupancy region Omega_i.
    
    Args:
        params: Output from compute_occupancy_region_params.
        num_samples: Number of points to sample.
        
    Returns:
        points: Array of shape (num_samples, 3) containing points in Omega_i.
    """
    p_i = params['p_i']
    r1 = params['r1']
    r2 = params['r2']
    a_i = params['a_i']
    b_i = params['b_i']
    lambda_i = params['lambda_i']
    
    # Sample rho in [0, 1) and theta in (0, 2pi]
    rho = np.random.uniform(0, 1, num_samples)
    theta = np.random.uniform(0, 2 * math.pi, num_samples)
    
    # Parametric equation: p_i + sqrt(lambda_i) * rho * (sigma1*cos(theta)*r1 + sigma2*sin(theta)*r2)
    # Note: a_i = sqrt(lambda_i)*sigma1, b_i = sqrt(lambda_i)*sigma2
    # So the term is: rho * (a_i * cos(theta) * r1 + b_i * sin(theta) * r2)
    
    cos_theta = np.cos(theta)
    sin_theta = np.sin(theta)
    
    # Vectorized computation
    # term = rho * (a_i * cos_theta * r1 + b_i * sin_theta * r2)
    term_x = rho * (a_i * cos_theta * r1[0] + b_i * sin_theta * r2[0])
    term_y = rho * (a_i * cos_theta * r1[1] + b_i * sin_theta * r2[1])
    term_z = rho * (a_i * cos_theta * r1[2] + b_i * sin_theta * r2[2])
    
    points = np.zeros((num_samples, 3))
    points[:, 0] = p_i[0] + term_x
    points[:, 1] = p_i[1] + term_y
    points[:, 2] = p_i[2] + term_z
    
    return points

def compute_normalwise_offset(gaussian_i, gaussian_j, params_i, num_samples_j=100):
    """
    Computes the approximate normal-wise offset delta_ij between two Gaussians.
    
    Args:
        gaussian_i: First Gaussian (reference frame).
        gaussian_j: Second Gaussian.
        params_i: Occupancy region parameters for Gaussian i.
        num_samples_j: Number of samples to draw from Omega_j.
        
    Returns:
        delta_hat: Approximate delta_ij.
    """
    p_i = params_i['p_i']
    r1 = params_i['r1']
    r2 = params_i['r2']
    n_i = params_i['n_i']
    a_i = params_i['a_i']
    b_i = params_i['b_i']
    
    # Sample points from Omega_j
    # Note: In a real implementation, one would compute params_j and sample from it.
    # Here we assume a helper to sample from Gaussian j's occupancy region.
    params_j = compute_occupancy_region_params(gaussian_j, gaussian_i.adaptive_threshold_V_ip) # Use same V_ip or specific one
    points_j = sample_occupancy_region(params_j, num_samples_j)
    
    # Transform points_j to local coordinates of Omega_i
    # X(x) = <x - p_i, r1> / a_i
    # Y(x) = <x - p_i, r2> / b_i
    # Z(x) = <x - p_i, n_i>
    
    diff = points_j - p_i
    
    X = np.sum(diff * r1, axis=1) / a_i
    Y = np.sum(diff * r2, axis=1) / b_i
    Z = np.sum(diff * n_i, axis=1)
    
    # Filter points inside the unit disk of Omega_i
    inside_disk = (X**2 + Y**2) <= 1.0
    
    # Get Z values for these points
    Z_inside = Z[inside_disk]
    
    if len(Z_inside) == 0:
        # No intersection possible in this sample set, return infinity or large number
        return float('inf')
    
    # Delta is the minimum absolute Z
    delta_hat = np.min(np.abs(Z_inside))
    
    return delta_hat

def check_intersection(gaussian_i, gaussian_j, params_i, epsilon):
    """
    Checks if two Gaussians intersect using the epsilon-criterion.
    
    Args:
        gaussian_i, gaussian_j: Gaussian primitives.
        params_i: Occupancy params for i.
        epsilon: Tolerance.
        
    Returns:
        bool: True if intersecting.
    """
    delta = compute_normalwise_offset(gaussian_i, gaussian_j, params_i)
    return delta <= epsilon
```

### Parameters
*   $\epsilon > 0$: Intersection tolerance. A small positive value (e.g., $10^{-3}$ to $10^{-5}$ depending on scene scale) to allow for minor misalignments [S1].
*   $c = 1/255$: Minimum rendering contribution threshold [S1].
*   $\bar{V}_{ip}$: Adaptive threshold passed through a sigmoid function [S1].

### Edge Cases and Pitfalls
*   **Precision:** The calculation of $\lambda_i$ involves $\ln(c/\alpha_i)$. If $\alpha_i$ is very small, this term grows large, expanding the occupancy region. Ensure $\alpha_i$ is not zero to avoid division by zero or $\ln(0)$ [S1].
*   **Rank-2 Covariance:** The covariance matrix $\Sigma_i$ is rank-2 (singular) because $\sigma_3=0$. The use of the Moore–Penrose pseudoinverse $\Sigma_i^+$ is critical for the condition $(x - p_i)^\top \Sigma_i^+ (x - p_i) < \lambda_i$ [S1].
*   **Sampling Density:** The numerical approximation $\hat{\delta}_{ij}$ depends on the number of samples from $\Omega_j$. Insufficient samples may miss the closest point to $\Omega_i$, leading to false negatives (missing an intersection) [S1].
*   **Degenerate Input:** If $r_1$ or $r_2$ are not orthonormal, the coordinate transformation is invalid. Ensure $R_i$ is a proper rotation matrix [S1].

## Operating characteristics

*   **Time Complexity:** The intersection check involves sampling $\Omega_j$ and projecting points. With $N$ primitives, a naive all-pairs check is $O(N^2)$. The source notes that a fixed-radius search can accelerate this to approximately linear complexity $O(N)$ for typical scenes [S1].
*   **Memory Complexity:** Requires storing the parameters for each Gaussian ($p_i, R_i, \sigma_i, \alpha_i$) and the adaptive threshold. No large auxiliary structures are mentioned beyond the primitive data itself [S1].
*   **Strengths:** Robust to minor misalignments between splats due to the $\epsilon$-intersection criterion. Avoids strict binary overlap issues.
*   **Limitations:** The numerical approximation of $\delta_{ij}$ requires sampling, which can be computationally expensive if high precision is needed. The method relies on the assumption that the Gaussian is surface-aligned (rank-2 covariance) [S1].

## Background

This method was introduced in the context of proxy-free Gaussian splats deformation with splat-based surface estimation [S1]. It addresses the need for robust intersection detection in differentiable rendering pipelines where strict geometric overlaps can cause instability during optimization. The approach builds on the standard 3D Gaussian Splatting framework but refines the culling and intersection logic to support surface-preserving adaptation [S1].
