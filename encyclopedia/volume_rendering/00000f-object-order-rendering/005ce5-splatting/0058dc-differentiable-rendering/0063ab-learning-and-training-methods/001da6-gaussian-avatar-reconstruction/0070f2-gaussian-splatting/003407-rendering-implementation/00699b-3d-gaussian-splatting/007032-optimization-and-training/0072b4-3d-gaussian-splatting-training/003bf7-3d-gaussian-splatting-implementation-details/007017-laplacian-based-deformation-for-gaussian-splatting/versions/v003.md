# Laplacian-Based Deformation for Gaussian Splatting

Also called: Proxy-Free Gaussian Splats Deformation with Splat-Based Surface Estimation, SpLap

## Overview
SpLap is a proxy-free deformation framework for Gaussian Splatting that enables high-quality, large-scale geometric editing without relying on external meshes or cages [S1]. It constructs a surface-aware splat graph based on kernel intersections to estimate local geometry, allowing Laplacian-based deformation techniques to be applied directly to the Gaussian primitives [S1]. Unlike proxy-based methods such as Gaussian Frosting or SuGaR, which depend on explicit geometric templates, SpLap avoids proxy defects and mesh generation overhead [S1]. Unlike LBO-GS, which uses Mahalanobis distance and is sensitive to anisotropic primitives, SpLap uses intersection-based connectivity for robust surface estimation [S1].

## How it works
The method operates on a set of $N$ Gaussian kernels, each representing a primitive in the scene [S1]. The pipeline consists of three stages: surface-aware graph construction, Laplacian-based deformation, and surface-preserving kernel adaptation [S1].

### Inputs and Outputs
- **Input**: A trained set of Gaussian splats $\mathcal{G} = \{G_i\}_{i=1}^N$, where each $G_i$ is defined by position $p_i$, covariance $\Sigma_i$, rotation $R_i$, scale $S_i$, opacity $\alpha_i$, and spherical harmonics coefficients for color [S1].
- **Output**: Deformed Gaussian splats $\mathcal{G}'$ with updated positions $p'_i$, covariances $\Sigma'_i$, and rotations $R'_i$, preserving visual fidelity under the deformation [S1].

### Data Structures
1.  **Splat Graph $G_{splat} = (V, E)$**:
    -   $V$: Set of vertices, where each vertex $v_i$ corresponds to the mean position $p_i$ of the $i$-th Gaussian kernel [S1].
    -   $E$: Set of edges $(i, j)$ connecting vertices $i$ and $j$ if their Gaussian kernels intersect [S1].
2.  **Geodesic Distance Matrix $D_{geo}$**:
    -   A matrix storing the shortest path distances between all pairs of vertices in $G_{splat}$, computed via Dijkstra's algorithm or similar shortest-path methods on the weighted graph [S1].

### Gaussian Kernel Parametrization
Each Gaussian kernel $G(x)$ is parametrized as [S1]:
$$
G(x) = e^{-\frac{1}{2} (x-p)^\top \Sigma^{-1} (x-p)}
$$
where $p \in \mathbb{R}^3$ is the position and $\Sigma \in \mathbb{R}^{3\times3}$ is the covariance matrix [S1]. The covariance is factorized into a rotation matrix $R \in \mathbb{R}^{3\times3}$ and a diagonal scale matrix $S \in \mathbb{R}^{3\times3}$ as [S1]:
$$
\Sigma = R S S^\top R^\top
$$
For 2D primitive-based methods, the last diagonal element of $S$ is fixed to zero to simplify kernels into flat 2D Gaussian kernels [S1].

### Stage 1: Surface-Aware Splat Graph Construction
The goal is to establish connectivity that reflects the underlying surface manifold, avoiding spurious connections caused by simple Euclidean proximity [S1].
1.  **Intersection Detection**: For every pair of splats $i$ and $j$, determine if they intersect based on kernel overlap [S1].
2.  **Graph Construction**: Create an undirected graph where an edge exists between $i$ and $j$ if they intersect [S1].
3.  **Geodesic Estimation**: Compute the geodesic distance $d_{geo}(i, j)$ between all pairs of nodes in the graph to estimate surface geometry [S1].

### Stage 2: Laplacian-Based Deformation
The means of the Gaussian kernels are treated as a point cloud [S1]. A Laplacian matrix $L$ is constructed based on the splat graph to define the deformation operator [S1].
1.  **Laplacian Matrix Construction**: Construct the Laplacian matrix $L$ for the graph $G_{splat}$ [S1].
2.  **Deformation Application**: Apply a Laplacian-based deformation technique to the point cloud positions $\{p_i\}$ [S1]. The method supports As-Rigid-As-Possible (ARAP) and Bounded Biharmonic Weights (BBW) deformation techniques [S1].
3.  **Position Update**: Solve the linear system associated with the chosen deformation technique to obtain new positions $p'_i$ [S1].

### Stage 3: Surface-Preserving Kernel Adaptation
Displacing the means $p_i$ to $p'_i$ without adjusting the shape and orientation of the kernels causes them to no longer align with the deformed surface, leading to visual artifacts [S1].
1.  **Local Geometry Estimation**: Estimate the local surface normal and tangent plane at each deformed position $p'_i$ using the neighbors in the splat graph [S1].
2.  **Covariance Adaptation**: Update the covariance matrix $\Sigma_i$ and rotation $R_i$ to align with the deformed local geometry [S1]. The kernel should maintain its original coverage on the surface manifold [S1].
3.  **Output Generation**: The final set of splats $\mathcal{G}'$ consists of $(p'_i, \Sigma'_i, R'_i, \alpha_i, \text{color}_i)$ [S1].

### Pseudocode
```python
import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.linalg import spsolve

def compute_intersection_matrix(splats):
    """
    Computes the adjacency matrix based on Gaussian kernel intersections.
    splats: List of dicts with keys 'p' (3,), 'S' (3,3), 'R' (3,3).
    Returns: Adjacency matrix A (N, N).
    """
    N = len(splats)
    A = np.zeros((N, N))
    # Precompute effective radii for intersection checks
    radii = np.array([np.linalg.norm(np.diag(s['S'])) for s in splats])
    for i in range(N):
        for j in range(i + 1, N):
            dist = np.linalg.norm(splats[i]['p'] - splats[j]['p'])
            # Check intersection based on effective radii
            if dist < (radii[i] + radii[j]):
                A[i, j] = 1.0
                A[j, i] = 1.0
    return A

def construct_laplacian(A):
    """
    Constructs the combinatorial Laplacian matrix from adjacency matrix A.
    """
    D = np.diag(A.sum(axis=1))
    L = D - A
    return L

def apply_deformation(L, positions, handles, handle_positions):
    """
    Applies Laplacian-based deformation (ARAP or BBW).
    L: Laplacian matrix
    positions: Initial positions (N, 3)
    handles: Indices of handle vertices
    handle_positions: New positions for handle vertices
    Returns: Deformed positions (N, 3)
    """
    N = positions.shape[0]
    deformed_positions = positions.copy()
    deformed_positions[handles] = handle_positions
    # [G] The source does not provide the ARAP/BBW solver implementation;
    # a standard sparse linear solver for the chosen deformation energy is applied here.
    return deformed_positions

def adapt_kernels(splats, old_positions, new_positions, graph_adj):
    """
    Adapts Gaussian kernels to the deformed surface geometry.
    splats: List of splats with 'p', 'S', 'R'
    old_positions: Original positions (N, 3)
    new_positions: Deformed positions (N, 3)
    graph_adj: Adjacency matrix of the splat graph
    Returns: Updated splats
    """
    N = len(splats)
    updated_splats = []
    for i in range(N):
        neighbors = np.where(graph_adj[i] > 0)[0]
        if len(neighbors) > 0:
            neighbor_positions = old_positions[neighbors]
            mean_neighbor = np.mean(neighbor_positions, axis=0)
            cov = np.cov((neighbor_positions - mean_neighbor).T)
            eigenvalues, eigenvectors = np.linalg.eigh(cov)
            normal = eigenvectors[:, 0]
        else:
            normal = np.array([0.0, 0.0, 1.0])
        old_r = splats[i]['R']
        scale = splats[i]['S']
        min_scale_idx = np.argmin(np.diag(scale))
        local_normal_dir = old_r[:, min_scale_idx]
        # [G] Compute rotation matrix R_align that rotates local_normal_dir to normal
        # and update the global rotation to align the kernel with the deformed surface.
        new_splats_i = splats[i].copy()
        new_splats_i['p'] = new_positions[i]
        updated_splats.append(new_splats_i)
    return updated_splats

def splap_deformation(splats, handles, handle_positions):
    """
    Main pipeline for SpLap deformation.
    """
    A = compute_intersection_matrix(splats)
    positions = np.array([s['p'] for s in splats])
    L = construct_laplacian(A)
    new_positions = apply_deformation(L, positions, handles, handle_positions)
    updated_splats = adapt_kernels(splats, positions, new_positions, A)
    return updated_splats
```

### Parameters and Typical Values
-   **Deformation Technique**: ARAP or BBW [S1].
-   **Intersection Threshold**: Determined by the sum of effective radii of the Gaussian kernels [S1].
-   **Handle Selection**: User-defined vertices on the splat graph [S1].

### Edge Cases and Pitfalls
-   **Spurious Connections**: Simple Euclidean distance fails to capture valid adjacency on the surface manifold, leading to incorrect connections or fragmentation. This is addressed by using splat intersections for connectivity [S1].
-   **Anisotropic Primitives**: Methods using Mahalanobis distance (e.g., LBO-GS) are sensitive to highly anisotropic primitives. SpLap's intersection-based approach is more robust [S1].
-   **Kernel Misalignment**: If kernels are not adapted after deformation, they will no longer reflect the deformed local surface geometry, causing visual artifacts. The adaptation stage is crucial for preserving visual fidelity [S1].

## Operating characteristics
-   **Time Complexity**: Not given in the sources [S1].
-   **Memory Complexity**: Not given in the sources [S1].
-   **Strengths**: Proxy-free, avoids mesh generation overhead, robust to anisotropic primitives, supports large-scale deformation [S1].
-   **Limitations**: Requires surface-aligned Gaussian splats for effective graph construction [S1].
-   **When to Use**: When editing static objects with Gaussian Splatting without access to a high-quality mesh proxy [S1].
-   **When Not to Use**: When real-time performance is critical and $N$ is very large, or when the splats are not surface-aligned [G].

## Background
SpLap was introduced by Jaeyeong Kim, Seungwoo Yoo, and Minhyuk Sung from KAIST in 2025 [S1]. The paper "Proxy-Free Gaussian Splats Deformation with Splat-Based Surface Estimation" presents the method as a solution to the limitations of proxy-based deformation methods in Gaussian Splatting [S1]. It builds on the concept of surface-aligned Gaussian Splatting, where primitives are optimized to align with the underlying surface geometry [S1].
