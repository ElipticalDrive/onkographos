# Gaussian Geometry Parameters Prediction

Also called: EVolSplat, Efficient Volume-based Gaussian Splatting, GRM, Gaussian MLP Heads, Gaussian Representation Model

## Overview
Gaussian Geometry Parameters Prediction is a feed-forward method that predicts the geometric attributes (position, opacity, covariance) of 3D Gaussians from a global volumetric feature representation, rather than optimizing them per-scene or predicting them per-pixel from local cost volumes [S2]. It solves the problem of multi-view inconsistencies and ghosting artifacts common in existing feed-forward methods by accumulating depth information in 3D space and refining Gaussian locations via a recursive offset mechanism [S2]. Unlike NeRF-based methods or pixel-aligned 3DGS approaches, it explicitly models the global scene structure using a sparse 3D CNN and decouples geometry prediction from color decoding [S2].

## How it works
**Inputs:** A set of $N$ sparse input images $\{I_n\}_{n=1}^N$ with known camera poses (intrinsic matrices $\{K_n\}$ and extrinsic matrices $\{T_n = R_n | t_n\}$) [S2].
**Outputs:** A set of 3D Gaussians $\mathcal{G} = \{(\mu_i, \alpha_i, \Sigma_i, c_i)\}_{i=1}^{N_p}$, where $\mu_i$ is the mean position, $\alpha_i$ is the opacity, $\Sigma_i$ is the covariance matrix, and $c_i$ is the view-dependent color [S2].

**Data Structures:**
1.  **Global Point Cloud ($\mathcal{P}$):** A set of 3D points in world coordinates, $\mathcal{P} \in \mathbb{R}^{N_p \times 3}$, initialized from unprojected depth maps [S2].
2.  **Feature Volume ($\mathbf{F}$):** A sparse 3D tensor $H \times W \times D \times C$ extracted by a sparse 3D CNN, aligned with the world coordinate system [S2].
3.  **MLP Heads:** Three independent Multi-Layer Perceptrons:
    *   $\mathcal{D}_{pos}$: Predicts position offset $\Delta \mu_i$.
    *   $\mathcal{D}_{opa}$: Predicts opacity $\alpha_i$.
    *   $\mathcal{D}_{cov}$: Predicts covariance matrix $\Sigma_i$.

**Numbered Steps:**

1.  **Depth Estimation:** Use an off-the-shelf metric depth estimator to predict depth maps $\{D_n\}_{n=1}^N$ for each input image $I_n$ [S2].
2.  **Global Point Cloud Construction:** Unproject the RGB images into 3D space using the calibrated intrinsic and extrinsic matrices along with the depth maps to construct the global scene point cloud $\mathcal{P}$:
    $$ \mathcal{P} = \bigcup_{n=1}^N \pi^{-1}(I_n, D_n, T_n, K_n) $$
    where $\pi^{-1}$ denotes pixel unprojection [S2].
3.  **Filtering:**
    *   Apply a **uniform filter** to $\mathcal{P}$ to delete duplicate primitives while keeping the scene structure [S2].
    *   Apply a **statistical filter** to remove floating artifacts (floaters) from the processed primitives [S2].
4.  **Feature Volume Extraction:** Feed the filtered global point cloud $\mathcal{P}$ into a sparse 3D CNN (e.g., sparse U-Net) to extract the neural feature volume $\mathbf{F}$ [S2].
5.  **Initialization:** Initialize the Gaussian centers $\mu^{init}_i$ using the scene point cloud points $p_i \in \mathcal{P}$ (i.e., $\mu^{init}_i = p_i$) [S2].
6.  **Geometry Parameters Prediction (Training):**
    *   For each Gaussian $i$, query the feature volume $\mathbf{F}$ at the updated position $\mu^{init}_i + \Delta \mu^{prev}_i$ using trilinear interpolation to obtain the feature vector $\mathbf{f}_i$:
        $$ \mathbf{f}_i = \mathbf{F}(\mu^{init}_i + \Delta \mu^{prev}_i) $$
        where $\Delta \mu^{prev}_i$ is the position offset predicted in the previous iteration (initialized to 0 for the first iteration) [S2].
    *   Decode opacity and covariance using the MLP heads:
        $$ \alpha_i = \mathcal{D}_{opa}(\mathbf{f}_i), \quad \Sigma_i = \mathcal{D}_{cov}(\mathbf{f}_i) $$
    *   Decode the position offset $\Delta \mu_i$ using $\mathcal{D}_{pos}$, passed through a Tanh activation and scaled by the voxel size $v_{size}$:
        $$ \Delta \mu_i = \text{Tanh}(\mathcal{D}_{pos}(\mathbf{f}_i)) \cdot v_{size} $$
    *   Update the Gaussian mean:
        $$ \mu_i = \mu^{init}_i + \Delta \mu_i $$
    *   Track $\Delta \mu_i$ as $\Delta \mu^{prev}_i$ for the next iteration [S2].
7.  **Geometry Parameters Prediction (Inference):**
    *   Initialize $\Delta \mu^{prev}_i = 0$ [S2].
    *   Recursively execute the update rules (querying $\mathbf{f}_i$, predicting $\Delta \mu_i$, updating $\mu_i$, and then predicting $\alpha_i, \Sigma_i$) twice to obtain a converged $\Delta \mu_i$ [S2].
    *   Use the converged point to query $\alpha_i$ and $\Sigma_i$ [S2].
8.  **Color Prediction:** Project the 3D Gaussians to the nearest $K$ reference views to retrieve 2D context (color windows $\{c_k\}$ and visibility maps) and decode the Gaussian color $c_i$ [S2].
9.  **Background Modeling:** Model distant views and the sky with a generalizable hemisphere Gaussian model where geometry is fixed and color is predicted similarly to the foreground volume [S2].
10. **Rendering:** Compose the foreground and background Gaussians to reconstruct the full image using standard alpha blending:
    $$ c = \sum_{i \in \mathcal{G}} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $c$ is the rendered color, $\mathcal{G}$ is the set of 3D Gaussians, and the product term represents transmittance [S2].

**Parameters:**
*   $N$: Number of input images [S2].
*   $N_p$: Number of primitives in the global point cloud [S2].
*   $K$: Number of nearest reference views for color retrieval [S2].
*   $v_{size}$: Voxel size used to scale the position offset output [S2].

**Edge Cases and Pitfalls:**
*   **Ghosting Artifacts:** Pixel-aligned methods generate redundant and inconsistent primitives in overlapping regions. This method addresses this by using a global volume and filtering duplicates [S2].
*   **Depth Noise:** Monocular depth predictions contain noise and floating artifacts. This method handles this by applying statistical filtering after uniform filtering [S2].
*   **Recursive Convergence:** The position offset $\Delta \mu_i$ depends on the previous estimation. During inference, two recursive iterations are empirically sufficient for convergence [S2].

## Subtopics

### GSGEN
GSGEN is a text-to-3D generation method that represents 3D content as a set of 3D Gaussians and optimizes them progressively in two stages: geometry optimization and appearance refinement, using 2D and 3D diffusion priors [S1, S2]. It differs from NeRF-based methods (e.g., DreamFusion, Magic3D) by using explicit 3D Gaussians, which allows for the incorporation of direct 3D geometry priors and alleviates the Janus problem [S1]. It differs from DreamGaussian by focusing on incorporating 3D prior with more advanced representation, whereas DreamGaussian focuses on fast image-to-3D generation [S1].

### [Textured-GS](9436-textured-gs.md)
Textured-GS enhances the textural representation of individual 3D Gaussians by modeling spatially defined color and opacity variations across the Gaussian ellipsoidal surface using Spherical Harmonics (SH), without increasing the number of Gaussians or adding extra parameters beyond the existing SH framework. Unlike standard 3D Gaussian Splatting (3DGS) where each Gaussian retains a fixed opacity and shows a single color when viewed from a specific direction, Textured-GS enables color variation across the Gaussian ellipsoidal surface and opacity variations, allowing for deviations from the standard ellipsoidal shape such as 'unidirectional Gaussians' that are opaque on one side and transparent on the other. It differs from Gaussian Geometry Parameters Prediction by using the surface intersection vector for SH evaluation instead of the viewing vector, allowing spatial variation of color/opacity within a single Gaussian.

### [Deformable 3D Gaussian Splatting](10060-deformable-3d-gaussian-splatting.md)
Deformable 3D Gaussian Splatting is a method for dynamic scene reconstruction that learns 3D Gaussians in a canonical static space and models spatial-temporal deformation using an implicit deformation field implemented as a Multi-Layer Perceptron (MLP). Unlike static 3D Gaussian Splatting, which assumes a fixed geometry, this method makes Gaussian parameters time-dependent, enabling the reconstruction and real-time rendering of 4D scenes. It distinguishes itself from sibling methods like GSGEN or Textured-GS by explicitly predicting temporal offsets for geometric attributes (position, rotation, scale) via an MLP conditioned on time, rather than relying on explicit per-frame storage or texture-based extensions.

### [Fourier Splatting Primitive](11094-fourier-splatting-primitive.md)
The Fourier Splatting primitive is a planar surfel for radiance field rendering that replaces the fixed Gaussian or elliptical falloff with a boundary defined by a Fourier series, allowing the representation of arbitrary closed shapes. Unlike 3D Gaussian Splatting (3DGS) or 2D Gaussian Splatting (2DGS), which are limited to fixed elliptical or disc shapes, this primitive enables higher fidelity representation of complex geometry and fine-grained details. Its key differentiator is inherent scalability: the level of detail (LoD) is controlled by truncating Fourier coefficients at runtime, allowing a single trained model to be rendered at varying complexities without retraining or post-hoc compression.

### [Conditional Slicing Mechanism](11455-conditional-slicing-mechanism.md)
The Conditional Slicing Mechanism conditions a 7-dimensional Gaussian (defined over spatial, temporal, and angular dimensions) on observed time $t$ and view direction $d$ to yield a conditional 3D Gaussian governing the spatial component. This operation "slices" the full 7D distribution to integrate temporal dynamics and view-dependent effects into the traditional 3D rendering pipeline without introducing additional temporal dependencies in the spherical harmonics. It sets itself apart from static Gaussian Splatting variants by explicitly modeling the joint distribution of space, time, and view, allowing the spatial mean and covariance to shift based on the current rendering context.

### [Structure-Aware 3D Gaussian Splatting (SAGS)](11908-structure-aware-3d-gaussian-splatting-sags.md)
Structure-Aware 3D Gaussian Splatting (SAGS) is a novel-view synthesis method that implicitly encodes scene geometry using a local-global graph representation to facilitate learning complex scenes and enforce meaningful point displacements that preserve structure, thereby reducing floating-point artifacts and storage requirements. Unlike standard 3D Gaussian Splatting which optimizes each Gaussian independently, SAGS leverages inter- and intra-connectivity between 3D point positions via Graph Neural Networks (GNNs) to predict Gaussian attributes, outperforming 3D-GS and Scaffold-GS in capturing high-frequency details while significantly reducing memory footprint.

### [Mesh-embedded representation](12559-mesh-embedded-representation.md)
Mesh-embedded representations integrate explicit triangle mesh topology with 3D Gaussian Splatting (3DGS) primitives to enable coherent deformation, editing, and surface-aligned rendering. Unlike standard 3DGS, which treats Gaussians as independent entities in free space, this family binds Gaussian parameters (position, rotation, scale) to mesh geometry via barycentric coordinates or vertex parameterization, ensuring that mesh edits or animations propagate deterministically to the radiance field. This approach solves the problem of Gaussian drift and incoherent motion transfer during animation, while providing a bridge between implicit neural/radiance representations and explicit editable mesh assets.

### [Inverse Gaussian Splattling](13193-inverse-gaussian-splattling.md)
Inverse Gaussian Splattling is a method for initializing 3D Gaussian primitives by back-projecting optimized 2D Gaussian kernels from image space into world space. It solves the problem of generating high-quality initial geometric parameters (position, rotation, scale) for new 3D Gaussians from 2D renderings, specifically handling foreground-background ambiguity in boundary regions. It differs from standard initialization by using Weighted Principal Component Analysis (WPCA) on clustered 3D points derived from depth maps, followed by a scaling calibration step to align the projected 3D covariance with the original 2D target.

### [Occupancy-Opacity Factorization](13440-occupancy-opacity-factorization.md)
Occupancy-Opacity Factorization decouples a Gaussian primitive's geometric presence from its optical properties by splitting the single standard opacity parameter into two learnable attributes: geometric occupancy ($\sigma$) and optical opacity ($\alpha$). This solves the problem where a single opacity parameter cannot simultaneously model a surface that is geometrically solid (for sharp reflections) yet optically clear (for light transmission). It sets itself apart from siblings like Textured-GS and Oriented Gaussian Splatting by explicitly modeling the probabilistic interaction of rays with the Gaussian substance, enabling deferred shading for high-frequency reflection modeling.

### [QuickSplat](15256-quicksplat.md)
QuickSplat is a method for fast 3D surface reconstruction of large indoor scenes from multi-view images that combines three learned data prior networks (initializer, densifier, optimizer) in an iterative densification-optimization loop to accelerate convergence and improve geometry in under-observed regions. It differs from standard 3D Gaussian Splatting (3DGS) and its variants like 2DGS or SuGaR by replacing heuristic-based densification and gradient descent with learned networks that jointly predict new Gaussians and update vectors, thereby removing heuristics and handling textureless regions better. Unlike methods relying solely on photometric errors, QuickSplat leverages learned geometry priors to reconstruct flat wall structures and object details in large-scale indoor environments.

### [CAG-GS Semantic Mapping and Gaussian Generation](15260-cag-gs-semantic-mapping-and-gaussian-generation.md)
CAG-GS generates implicit 3D Gaussians from semantic anchors by encoding spatial positions into high-dimensional semantic vectors via a multi-resolution hash grid, which are then fused with anchor features to predict Gaussian attributes. It distinguishes itself from standard 3D Gaussian Splatting by incorporating semantic guidance and geometric consistency constraints (normal and flattening losses) to improve global consistency in large-scale scenes, utilizing a coarse-to-fine training strategy.

### [Geometry and orientation extension](15381-geometry-and-orientation-extension.md)
This family extends the standard 3D Gaussian primitive to better model explicit geometry, surface orientation, and directional asymmetry, which standard isotropic Gaussians lack. It sets itself apart from standard 3D Gaussian Splatting by introducing learnable normals, skewness, or mesh-constrained parameterizations to enable surface wrapping, mesh extraction, and view-dependent effects.

### [Voxel and Grid-Based Prediction](15382-voxel-and-grid-based-prediction.md)
Voxel and Grid-Based Prediction is a neural rendering method that combines voxel-based density representation with Multi-Plane Image (MPI) depth layers to perform efficient volume rendering. It solves the problem of slow convergence and poor surface quality in implicit neural representations by using explicit grid-based features alongside approximate Signed Distance Function (SDF) supervision. Unlike its sibling Voxel and Grid-Based Prediction, which typically predicts Gaussian parameters or raw densities, DirectMPIGO explicitly predicts an SDF value via a feature grid to enable robust surface extraction and regularization. It is significantly faster than implicit-only methods like NeuralRGB-D but requires larger memory footprints due to the explicit grid storage.

### [Attribute-Conditioned SH Enhancement](15410-attribute-conditioned-sh-enhancement.md)
The Attribute-Conditioned SH Enhancement module recovers high-frequency visual details lost during the compression of radiance fields into low-order Spherical Harmonics (SH), specifically targeting the limitations of first-order SH representations. It differs from dynamic neural view-dependent enhancement methods (e.g., Mobile-GS) by predicting view-independent offsets that are statically baked into Gaussian parameters before inference, thereby introducing zero additional computational overhead during rendering.

### [Functional Gaussian Splatting Representation](15572-functional-gaussian-splatting-representation.md)
Functional Gaussian Splatting (DiffGS Representation) solves the problem of representing discrete, unstructured 3D Gaussian Splatting (3DGS) primitives as continuous, differentiable functions to enable generative modeling. It disentangles the 3DGS representation into three specific functions: Gaussian Probability Function (GauPF) for geometry, Gaussian Color Function (GauCF) for appearance, and Gaussian Transform Function (GauTF) for structural attributes. Unlike sibling methods that modify the primitive shape or storage structure, this representation maps the discrete set of Gaussians to continuous fields, allowing the use of standard generative frameworks like Variational Autoencoders (VAEs) and Latent Diffusion Models (LDMs).

### [InnerGS Volumetric Rendering](15748-innergs-volumetric-rendering.md)
InnerGS is a volumetric rendering method that models continuous 3D density using 3D Gaussians to synthesize novel 2D slices at arbitrary depths, avoiding the discrete projection artifacts of standard 3D Gaussian Splatting (3DGS). Unlike standard 3DGS which renders pixels via perspective projection of splats onto a camera plane, InnerGS calculates the contribution of each Gaussian directly to a pixel on a 2D slice at a specific depth $t$ along a given axis. This approach enables seamless volumetric interpolation and explicit internal structure reconstruction, making it suitable for applications like medical imaging where internal slices are required.

### [Feed-forward and Generalizable Prediction](15832-feed-forward-and-generalizable-prediction.md)
Feed-forward and Generalizable Prediction refers to a family of methods that predict a complete 3D Gaussian Splatting (3DGS) scene representation directly from one or more input images in a single neural network forward pass, eliminating the need for per-scene gradient-based optimization. Unlike traditional 3D Gaussian Splatting which requires iterative optimization to fit a specific scene, these methods learn priors from large-scale datasets to generalize to unseen scenes [Parent]. They distinguish themselves from sibling methods by their specific architectural choices for handling multi-view consistency, pose estimation, and primitive types (2D vs 3D), as detailed in the subtopics.

### [Plenoptic Sampling Guided 3DGS Construction](16971-plenoptic-sampling-guided-3dgs-construction.md)
Plenoptic Sampling Guided 3DGS Construction is a method for initializing 3D Gaussian Splatting (3DGS) representations directly from mesh geometry, using plenoptic sampling theory to theoretically derive the minimum sampling rate for views and the optimal distribution of 3D Gaussians. Unlike heuristic initialization methods that rely on trial-and-error, this approach precisely constrains Gaussian density and camera sampling to achieve Nyquist-level performance for global illumination caching. It sets itself apart by grounding the initialization in signal processing principles, ensuring that the number of Gaussians and sampled views is minimized while maintaining high-fidelity rendering.

### [Geometry Guided Gaussian Points Generation](16972-geometry-guided-gaussian-points-generation.md)
Geometry Guided Gaussian Points Generation (MGadapter) is a method that generates structured 3D Gaussian point attributes from an intermediate triangular mesh, providing explicit geometric guidance to 3D Gaussian Splatting (3DGS). It solves the problem of vanilla 3DGS lacking deterministic geometry boundaries and explicit normal directions, which complicates light transport computation and hinders physically-based inverse rendering. Unlike sibling methods that rely on learned approximated normals or real-time optimization to maintain shape consistency, MGadapter uses a predefined heuristic function to map mesh triangles directly to Gaussian points, leveraging well-defined mesh normals for improved accuracy and stable training.

### BrightDreamer
BrightDreamer predicts the deviation of a set of fixed anchor points to determine the centers of Gaussians [S1]. The deviation of a set of fixed anchor points is predicted, and the centers of Gaussians are determined from these deviations [S1].

### Defocus Blur Modeling
Defocus Blur Modeling models optical defocus by adjusting the scale $s$ of 3D Gaussians based on their distance from the camera's focal plane [S3]. During training, larger scale values $\bar{s}_j$ are used to rasterize blurred images. During testing, smaller scale values $s_j$ are used to render sharp details [S3]. The scale $s$ controls dispersion; larger $s$ models out-of-focus points, smaller $s$ models in-focus points [S3]. Unlike a naive Gaussian kernel that blurs the entire image uniformly, this method selectively enlarges covariances only for Gaussians corresponding to blurred regions [S3].

### GaMeS Parametrization
GaMeS Parametrization is a parameterization of Gaussian components into flat triangle-face meshes, allowing GS to be visualized and manipulated as a triangle soup [S4, unofficial]. For mesh-bound Gaussians, means are assigned to mesh faces via learnable barycentric coordinates of vertices, ensuring they remain bound under deformation [S4, unofficial]. The orientation of mesh-bound Gaussians is defined by the face normal and two in-plane directions derived from the vertices [S4, unofficial].
Forward mapping $T(\cdot)$: Given Gaussian $N(m, R, S)$ with $R=[r_1, r_2, r_3]$ and $S=\text{diag}(\epsilon, s_2, s_3)$, the triangle vertices are $v_1 = m$, $v_2 = m + s_2 r_2$, and $v_3 = m + s_3 r_3$ [S4, unofficial].
Inverse mapping $T^{-1}(\cdot)$: Given triangle $V=[v_1, v_2, v_3]$, the Gaussian is recovered as $N(\hat{m}, \hat{R}, \hat{S})$ using formulas (2)-(4) for mean, rotation, and scaling [S4, unofficial].
Covariance matrix recovery: $\hat{\Sigma} = \hat{R}\hat{S}\hat{S}^T\hat{R}^T$ [S4, unofficial].

## Operating characteristics
*   **Time Complexity:** Feed-forward inference is significantly faster than per-scene optimization methods, as it avoids iterative gradient descent. The complexity is dominated by the sparse 3D CNN feature extraction and the MLP head predictions [S2].
*   **Memory Complexity:** Requires storing the global feature volume $\mathbf{F}$ and the set of Gaussians. The sparse 3D CNN reduces memory usage compared to dense volumes [S2].
*   **Measured Performance:** EVolSplat achieves real-time rendering speeds for urban scenes [S2]. It improves global consistency and reduces ghosting artifacts compared to pixel-aligned methods like MVSplat, Flash3D, and DrivingForward [S2].
*   **Strengths:** Handles large-scale urban scenes with large camera movements and small parallax; reduces ghosting artifacts through global volume accumulation; efficient feed-forward prediction [S2].
*   **Limitations:** Relies on the quality of off-the-shelf depth estimators; may lose high-frequency appearance details if primitives are downsampled too aggressively (addressed by IBR-based color prediction) [S2].
*   **When to use:** Efficient reconstruction of large-scale urban scenes from sparse views where real-time rendering is required and per-scene optimization is too slow [S2].
*   **When not to use:** Small-scale scenes with high overlap where per-scene optimization might yield higher fidelity; scenes where high-frequency texture details are critical and cannot be recovered by IBR [S2].

## Background
Gaussian Geometry Parameters Prediction, specifically in the form of EVolSplat, was introduced by Sheng Miao, Jiaxin Huang, Dongfeng Bai, Xu Yan, Hongyu Zhou, Yue Wang, Bingbing Liu, Andreas Geiger, and Yiyi Liao from Zhejiang University, Huawei Noah’s Ark Lab, and the University of Tübingen [S2]. The paper "EVolSplat: Efficient Volume-based Gaussian Splatting for Urban View Synthesis" was published in arXiv:2503.20168v1 on March 26, 2025 [S2]. It addresses the limitations of existing NeRF and 3DGS-based methods that require slow, per-scene optimization, particularly for autonomous driving-related applications [S2].
