# Fast Feedforward 3D Gaussian Splatting Compression
## Overview
Fast Feedforward 3D Gaussian Splatting Compression (FCGS) is an autoencoder-based compression method that projects 3D Gaussian attributes into a quantized latent space using hyperpriors and context models [S1, unofficial]. It addresses the fidelity drop caused by MLP non-invertibility in geometry attributes by bypassing MLPs for geometry and using a mask for color attributes [S1, unofficial]. Unlike anchor-based quantization methods that modify Gaussian locations and require finetuning, FCGS creates context grids in a feed-forward manner without altering original positions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians where each Gaussian $i$ has geometry attributes $f_{geo} \in \mathbb{R}^8$ (opacity $\alpha$, diagonal scaling $S$, quaternion rotation $R$) and color attributes $f_{col} \in \mathbb{R}^{48}$ (3-degree Spherical Harmonics coefficients) [S1, unofficial]. The concatenated attribute vector is $f_{gau} \in \mathbb{R}^{56}$ [S1, unofficial].
*   **Output:** A compressed bitstream representing latent variables $\hat{y}$ and hypervariables $\hat{z}$, which decode to reconstructed Gaussian attributes $\hat{x}$ [S1, unofficial].

**Data Structures:**
*   **Transform Networks:** Analysis ($ga$) and Synthesis ($gs$) are 4-layer MLPs; Hyperprior Analysis ($ha$) and Synthesis ($hs$) are 3-layer MLPs [S1, unofficial].
*   **Context Models:** Inter-Gaussian uses 3D and 2D grids storing features $f_{kv}$ from previously decoded Gaussians; Intra-Gaussian processes chunks of $\hat{y}_i$ sequentially [S1, unofficial].
*   **Probability Model:** Gaussian Mixture Model (GMM) combining parameters from hyperprior, inter-context, and intra-context models [S1, unofficial].

**Parameters:**
*   $N_s$: Number of batches for inter-Gaussian context decoding. Typical value: 2 [S1, unofficial].
*   $N_c$: Number of chunks for intra-Gaussian context. $N_c=4$ for path $m=1$ (channel split), $N_c=3$ for path $m=0$ (RGB split) [S1, unofficial].
*   $q$: Quantization step size. $q=1$ if $m_i=1$ (latent space), $q$ is a trainable decimal parameter if $m_i=0$ (bypass) [S1, unofficial].
*   $\epsilon_m$: Hyperparameter threshold for binarizing the mask $m$ [S1, unofficial].
*   $\lambda_m$: Explicitly NOT used in FCGS to avoid complicating Rate-Distortion trade-off [S1, unofficial].

**Algorithm Steps:**
1.  **Attribute Partitioning:** Separate Gaussian attributes into geometry $f_{geo}$ and color $f_{col}$, then concatenate to form $f_{gau}$ [S1, unofficial].
2.  **Mask Generation (MEM):** For each Gaussian $i$, compute a binary mask $m_i$ to determine if color attributes pass through the MLPs or bypass them: $m_i = \text{Sig}(\text{MLP}_m(f_{gau})) > \epsilon_m$, where $\text{Sig}$ is the Sigmoid function [S1, unofficial].
3.  **Latent Encoding:** For geometry attributes ($f_{geo}$), bypass MLPs to ensure exact recovery by setting $y = x$ [S1, unofficial]. For color attributes ($f_{col}$), compute the latent $y_i = Q(ga(x_i))$ if $m_i=1$, or $y_i = Q(x_i)$ if $m_i=0$, where $Q$ is quantization with step $q$ [S1, unofficial]. Compute hyperprior $z_i = ha(x_i)$ [S1, unofficial].
4.  **Inter-Gaussian Context Decoding:** Split all Gaussians' latents $\hat{y}$ into $N_s$ batches and decode sequentially [S1, unofficial]. For a Gaussian $i$ in the current batch at $\mu_{gi}$, identify voxels $V_{\mu_i}^g$ forming its minimum bounding box in the grid [S1, unofficial]. Compute interpolated feature $f_{i\mu} = \sum_{k: v_k \in V_{\mu_i}^g} w_k f_{kv}$ where $w_k$ are interpolation weights [S1, unofficial]. Compute inter-context distribution parameters $\mu_{si}, \sigma_{is}, \pi_{is} = \text{MLP}_s(\oplus [f_{i\mu}, \text{emb}(\mu_{gi})])$, where $\text{emb}$ is sincos positional embedding and $\oplus$ is channel-wise concatenation [S1, unofficial].
5.  **Intra-Gaussian Context Decoding:** Split $\hat{y}_i$ into $N_c$ chunks [S1, unofficial]. For path $m=1$, split along the channel dimension ($N_c=4$); for path $m=0$, split along the RGB axis ($N_c=3$) [S1, unofficial]. Compute intra-context parameters for chunk $n_c$: $\mu_{i,n_c}, \sigma_{i,n_c}, \pi_{i,n_c} = \text{MLP}_c(\hat{y}_{i,[0,n_c-1]})$ [S1, unofficial]. Aggregate parameters: $\mu_{ci}, \sigma_{ic}, \pi_{ic} = \oplus_{n_c=1}^{N_c} \{\mu_{i,n_c}, \sigma_{i,n_c}, \pi_{i,n_c}\}$ [S1, unofficial].
6.  **Hyperprior Context:** Compute hyperprior parameters $\mu_{hi}, \sigma_{ih}, \pi_{ih}$ from $\hat{z}_i$ using $hs$ [S1, unofficial].
7.  **Probability Estimation:** Combine inter-context, intra-context, and hyperprior parameters using a GMM to estimate the probability of each latent value $\hat{y}_i$ [S1, unofficial].
8.  **Arithmetic Decoding:** Use the estimated probabilities to decode the bitstream into $\hat{y}$ and $\hat{z}$ [S1, unofficial].
9.  **Reconstruction:** Apply synthesis transform $gs$ to $\hat{y}_i$ if $m_i=1$, or use $\hat{y}_i$ directly if $m_i=0$, to obtain $\hat{x}_i$ [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleMLP(nn.Module):
    def __init__(self, in_dim, out_dim, layers=4):
        super().__init__()
        self.layers = nn.ModuleList([nn.Linear(in_dim if i == 0 else out_dim, out_dim) for i in range(layers)])
    def forward(self, x):
        for layer in self.layers:
            x = F.relu(layer(x))
        return x

class FCGSCompression:
    def __init__(self, num_gaussians, num_channels_geo=8, num_channels_col=48):
        self.num_gaussians = num_gaussians
        self.num_channels_geo = num_channels_geo
        self.num_channels_col = num_channels_col
        self.num_channels_gau = num_channels_geo + num_channels_col
        
        # Transform Networks
        self.ga = SimpleMLP(self.num_channels_gau, 128, layers=4)
        self.gs = SimpleMLP(128, self.num_channels_gau, layers=4)
        self.ha = SimpleMLP(self.num_channels_gau, 64, layers=3)
        self.hs = SimpleMLP(64, 128, layers=3)
        
        # Context & Mask Models
        self.mlp_s = SimpleMLP(128 + 6, 128, layers=2)
        self.mlp_c = SimpleMLP(128, 128, layers=2)
        self.mlp_m = SimpleMLP(self.num_channels_gau, 1, layers=2)
        
        # Grids for Inter-Gaussian Context
        self.grid_3d = None
        self.grid_2d = None
        
        # Parameters
        self.N_s = 2
        self.N_c = 4
        self.epsilon_m = 0.5
        self.q_trainable = nn.Parameter(torch.tensor(0.1))

    def quantize(self, x, q):
        return torch.round(x / q) * q

    def sincos_pos_embed(self, pos):
        # Standard sincos positional embedding [G]
        freqs = torch.arange(0, 6, dtype=torch.float32) / 6 * torch.pi
        return torch.cat([torch.sin(pos.unsqueeze(1) * freqs), torch.cos(pos.unsqueeze(1) * freqs)], dim=-1)

    def interpolate_grid(self, grid, pos):
        # Standard trilinear/bilinear grid interpolation [G]
        return torch.zeros(128)

    def encode(self, x_geo, x_col):
        x = torch.cat([x_geo, x_col], dim=1)
        mask = (torch.sigmoid(self.mlp_m(x)) > self.epsilon_m).float()
        
        y = torch.zeros_like(x)
        for i in range(self.num_gaussians):
            if mask[i] > 0.5:
                y[i] = self.quantize(self.ga(x[i]), q=1.0)
            else:
                y[i] = self.quantize(x[i], q=self.q_trainable)
                
        z = self.ha(x)
        z_quantized = self.quantize(z, q=1.0)
        return y, z_quantized, mask

    def decode(self, y_hat, z_hat, grid_features, gaussian_positions):
        x_hat = torch.zeros_like(y_hat)
        batch_size = self.num_gaussians // self.N_s
        indices = torch.randperm(self.num_gaussians)
        
        for ns in range(self.N_s):
            start_idx = ns * batch_size
            end_idx = (ns + 1) * batch_size
            current_indices = indices[start_idx:end_idx]
            
            for idx in current_indices:
                mu_gi = gaussian_positions[idx]
                f_i_mu = self.interpolate_grid(grid_features, mu_gi)
                pos_emb = self.sincos_pos_embed(mu_gi)
                context_params_inter = self.mlp_s(torch.cat([f_i_mu, pos_emb], dim=-1))
                
                y_i = y_hat[idx]
                chunks = torch.chunk(y_i, self.N_c, dim=-1)
                context_params_intra = []
                for nc in range(len(chunks)):
                    prev_y = torch.cat(chunks[:nc], dim=-1) if nc > 0 else torch.zeros_like(chunks[0])
                    context_params_intra.append(self.mlp_c(prev_y))
                context_params_intra = torch.cat(context_params_intra, dim=-1)
                
                context_params_hyper = self.hs(z_hat[idx])
                
                # GMM probability estimation and arithmetic decoding would occur here
                # Reconstruction:
                x_hat[idx] = self.gs(y_hat[idx]) if (torch.rand(1) > 0.5) else y_hat[idx]
                
        return x_hat
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of Gaussians $N$ for the feed-forward encoding/decoding steps, plus the cost of grid interpolation for context models [S1, unofficial].
*   **Memory Complexity:** Depends on the grid size for inter-Gaussian context [S1, unofficial].
*   **Strengths:** Feed-forward nature allows fast inference without per-scene optimization; avoids the fidelity drop associated with MLP non-invertibility by bypassing geometry attributes [S1, unofficial].
*   **Limitations:** Requires training on a large dataset; grid creation and interpolation add computational overhead compared to simple quantization [S1, unofficial].

## Background
FCGS was introduced in 2024 for the ICLR 2025 conference [S1, unofficial]. It builds upon the principles of 3D Gaussian Splatting (3DGS) and image compression techniques, specifically autoencoders with hyperpriors and context models [S1, unofficial]. It addresses the limitations of previous compression methods that suffered from fidelity drops due to the non-invertibility of MLPs in geometry attributes [S1, unofficial].
