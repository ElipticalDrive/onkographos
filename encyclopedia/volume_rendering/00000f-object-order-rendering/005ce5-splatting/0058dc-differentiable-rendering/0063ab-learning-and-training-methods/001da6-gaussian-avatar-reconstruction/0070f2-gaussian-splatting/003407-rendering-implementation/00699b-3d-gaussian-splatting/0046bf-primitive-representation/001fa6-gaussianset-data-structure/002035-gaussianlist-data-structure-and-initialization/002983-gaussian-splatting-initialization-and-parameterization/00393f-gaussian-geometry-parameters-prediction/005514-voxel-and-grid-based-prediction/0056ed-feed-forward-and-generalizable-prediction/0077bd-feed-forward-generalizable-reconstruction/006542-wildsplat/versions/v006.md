# WildSplat

Also called: WildSplat: Feedforward Gaussian Splatting from Unposed In-the-Wild Images

## Overview
WildSplat is a feedforward 3D Gaussian Splatting framework for appearance-conditioned novel-view synthesis from sparse, unposed, in-the-wild images [S1]. It explicitly decouples geometry from appearance to handle inconsistent photometric conditions, such as varying weather and lighting, which typically cause entangled representations in existing feedforward methods to fail [S1]. Unlike optimization-based methods that require precomputed poses and dense inputs, or standard feedforward methods that assume photometric consistency, WildSplat jointly predicts camera poses, 3D Gaussian geometry, and reference-conditioned appearance in a single forward pass [S1].

## How it works
**Inputs and Outputs:**
The model takes a set of $N$ context images $\{I_i\}_{i=1}^N$ and a single reference image $I_{ref}$ [S1]. It outputs:
1.  3D Gaussian geometry attributes $\mathcal{G}$, consisting of positions $\mu \in \mathbb{R}^{G \times 3}$, rotations $q \in \mathbb{R}^{G \times 4}$, scales $s \in \mathbb{R}^{G \times 3}$, and opacities $\alpha \in \mathbb{R}^G$, where $G$ is the number of Gaussians [S1].
2.  Conditioned spherical harmonics coefficients $\mathcal{C}_{ref} \in \mathbb{R}^{G \times 3 \times (k+1)}$ of degree $k$, conditioned on $I_{ref}$ [S1].
3.  Camera poses $\{p_i\}$ for the context views [S1].

The mapping is defined as:
$$ f: \{I_i\}, I_{ref} \mapsto (\mathcal{G}, \mathcal{C}_{ref}, \{p_i\}) $$
[S1]

**Data Structures:**
*   **Patch Tokens:** $T_i^{(0)} \in \mathbb{R}^{P \times D}$, extracted from context image $I_i$ by the geometry encoder [S1].
*   **Camera Tokens:** $C_i \in \mathbb{R}^{5 \times D}$, learnable tokens concatenated with patch tokens for pose estimation [S1].
*   **Content Features:** $\mathbf{F}_{\text{content}}$, aggregated multi-scale representations from the geometry branch transformer layers, serving as the geometric scaffold [S1].
*   **Reference Tokens:** $T_{ref} \in \mathbb{R}^{P_a \times D}$, local dense appearance tokens extracted from $I_{ref}$ [S1].
*   **CLS Token:** $T_{[CLS]}$, global descriptor used for global pre-modulation [S1].

**Algorithm Steps:**

1.  **Geometry Branch Processing:**
    For each context image $I_i$:
    a. Encode $I_i$ using a DINOv2-based geometry encoder $E_{geo}$ to obtain initial patch tokens:
       $$ T_i^{(0)} = E_{geo}(I_i) $$
       [S1]
    b. Concatenate learnable camera tokens $C_i$ with $T_i^{(0)}$.
    c. Refine tokens through $L$ alternating attention blocks to obtain refined patch tokens $T_i^{(k)}$ and camera tokens $C_i^{(k)}$ for layer $k$ [S1].
    d. Aggregate multi-scale representations from a subset of transformer layers $\mathcal{K} = \{l_1, \dots, l_K\}$ to form the content features $\mathbf{F}_{\text{content}}$ [S1].

2.  **Appearance Injection (Dual-Branch Decoupling):**
    a. Extract reference appearance tokens $T_{ref}$ from $I_{ref}$ using an appearance encoder [S1].
    b. **Global Pre-modulation:** To prevent original photometric properties in $\mathbf{F}_{\text{content}}$ from interfering with target appearance, decode $T_{[CLS]}$ via an AdaLN-Zero layer into scale $\gamma$, shift $\beta$, and gating $\eta$ [S1]. Modulate the content features:
       $$ \tilde{\mathbf{T}}_i^{(k)} = \gamma \dots $$
       (Note: The source provides the parameters $\gamma, \beta, \eta$ but the exact element-wise formula for $\tilde{\mathbf{T}}$ is truncated in the provided text; standard AdaLN-Zero applies $\gamma \cdot \text{LayerNorm}(x) + \beta$ gated by $\eta$ [S1, G]).
    c. **Cross-Attention:** Use the modulated features $\tilde{\mathbf{T}}_i^{(k)}$ as queries ($Q$) and $T_{ref}$ as keys ($K$) and values ($V$) to aggregate condition-specific details into the content features [S1].

3.  **Geometry-Guided View Sampling (Training):**
    To ensure valid multi-view context for training, use Structure-from-Motion (SfM) points to construct an overlap matrix $S$ and a scale matrix $R$ [S1].
    a. Filter valid view pairs where $S \ge \tau_s$ and $R \ge \tau_r$ [S1].
    b. Select starting rows $C$ where the sum of valid columns $> \tau_n$ [S1].
    c. Initialize a queue with a uniform sample from $C$. Iteratively pop $u$, sample up to $K$ neighbors from valid unvisited views, push to queue, and add to index set $\mathcal{I}$ until $N$ views are selected [S1].
    *Pseudocode for View Sampling:*
    ```python
    def geometry_guided_view_sampling(S, R, N, K, tau_s, tau_r, tau_n):
        # S: overlap matrix, R: scale matrix
        # V: valid mask
        V = (S >= tau_s) & (R >= tau_r)
        
        # C: valid starting rows (indices i where sum of valid columns > tau_n)
        C = [i for i in range(len(S)) if sum(V[i]) > tau_n]
        
        if not C:
            return []
            
        # Initialize queue and index set
        import random
        c = random.choice(C)
        queue = [c]
        I = {c}
        
        while len(I) < N and queue:
            u = queue.pop(0)
            # Sample up to K neighbors from valid unvisited views
            candidates = [v for v in range(len(V[u])) if V[u, v] and v not in I]
            k_neighbors = random.sample(candidates, min(K, len(candidates)))
            
            for sk in k_neighbors:
                queue.append(sk)
                I.add(sk)
                
        return list(I)
    ```
    [S1]

4.  **Conditioned Rasterization:**
    Render novel views using tile-based differentiable rasterization $\mathcal{R}$ of 3D Gaussian Splatting with geometry $\mathcal{G}$, conditioned coefficients $\mathcal{C}_{ref}$, and target camera poses $\{p_i\}$ [S1]:
    $$ \{\hat{I}_i\} = \mathcal{R}(\mathcal{G}, \mathcal{C}_{ref}, \{p_i\}) $$
    [S1]

5.  **Joint Multi-Reference Supervision:**
    During training, randomly sample $M$ images $\{I_m\}$ from the batch as target references [S1]. Extract conditioned appearance $\{\mathcal{C}_{ref,m}\}$ for each. Render images $\{\hat{I}_m\}$ conditioned on their respective appearance. Apply color jittering to input images and random cropping to references prior to feature extraction to prevent appearance leakage [S1].

**Loss Function:**
The total loss is:
$$ \mathcal{L}_{total} = \mathcal{L}_{rgb} + \lambda_1 \mathcal{L}_{pose} $$
[S1]
Where photometric loss $\mathcal{L}_{rgb}$ is:
$$ \mathcal{L}_{rgb} = \lambda_2 \mathcal{L}_{MSE} + \lambda_3 \mathcal{L}_{SSIM} + \lambda_4 \mathcal{L}_{LPIPS} $$
[S1]
$\mathcal{L}_{pose}$ is a distillation loss to regularize camera pose estimation [S1].

**Parameters:**
*   $\lambda_1 = 10$ (pose weight)
*   $\lambda_2 = 1.0$ (MSE weight)
*   $\lambda_3 = 0.05$ (SSIM weight)
*   $\lambda_4 = 0.05$ (LPIPS weight)
[S1]

**Edge Cases and Pitfalls:**
*   **Varying Focal Lengths:** Standard sampling relying on camera extrinsics fails on in-the-wild datasets where minor pose shifts alter captured content due to varying focal lengths. Mitigated by the overlap-based sampling using SfM points [S1].
*   **Feature Entanglement:** Content features from the geometry branch retain original photometric properties, interfering with target appearance conditioning. Mitigated by global pre-modulation using AdaLN-Zero to shift features into the target appearance domain [S1].

## Operating characteristics
*   **Time Complexity:** Single forward pass for reconstruction and rendering, significantly faster than per-scene optimization methods [S1].
*   **Memory Complexity:** Depends on the number of Gaussians $G$ and the number of context images $N$. The dual-branch architecture requires storing features for both geometry and appearance branches [S1].
*   **Measured Performance:**
    *   On MegaScenes with 12 views: PSNR 19.20, SSIM 0.683, LPIPS 0.210 [S1].
    *   On Phototourism with 12 views: PSNR 21.47, SSIM 0.788, LPIPS 0.137 [S1].
*   **Strengths:** Handles sparse, unposed, in-the-wild images; decouples geometry and appearance to handle inconsistent lighting/weather; efficient feedforward inference [S1].
*   **Limitations:** Requires SfM points for view sampling during training; performance depends on the quality of the DINOv2 encoder and the reference image selection [S1].
*   **When to use:** When input images are sparse, unposed, and have varying illumination, and fast novel-view synthesis is required [S1].
*   **When not to use:** When dense, posed inputs are available and photometric consistency is guaranteed, other feedforward methods may be simpler; when high-precision pose estimation is required without ground truth supervision [S1].

## Background
WildSplat was introduced by X. Zhang et al. in the paper "WildSplat: Feedforward Gaussian Splatting from Unposed In-the-Wild Images" [S1]. It addresses the limitations of existing feedforward 3D reconstruction methods that falter under varying illumination and the inefficiency of optimization-based methods like NeRF-W and GS-W that require precomputed poses and dense images [S1]. It builds on the 3D Gaussian Splatting primitive representation and extends feedforward architectures (like pixelSplat, MVSplat) to handle in-the-wild conditions by explicitly decoupling geometry and appearance [S1].
