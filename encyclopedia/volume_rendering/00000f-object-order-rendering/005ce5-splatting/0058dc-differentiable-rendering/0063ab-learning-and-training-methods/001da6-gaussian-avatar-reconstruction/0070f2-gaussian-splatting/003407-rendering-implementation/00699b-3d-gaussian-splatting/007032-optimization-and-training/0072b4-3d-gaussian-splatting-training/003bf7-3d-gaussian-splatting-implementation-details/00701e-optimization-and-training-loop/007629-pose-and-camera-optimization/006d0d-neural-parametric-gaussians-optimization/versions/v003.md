# Neural Parametric Gaussians Optimization

Also called: two-stage optimization for monocular non-rigid reconstruction

## Overview
Neural Parametric Gaussians (NPGs) is a two-stage optimization procedure for monocular non-rigid object reconstruction that combines a coarse parametric point model regularized by a low-rank deformation basis with 3D Gaussians to model fine geometric and appearance details [S1]. It addresses the ill-posed nature of reconstructing non-rigid objects from monocular video by maintaining coarse geometry integrity over time, which distinguishes it from baselines like Nerfies, HyperNeRF, TiNeuVox, and HexPlane that often fail to capture correct geometry in such settings [S1].

## How it works
The method optimizes a representation in two distinct stages. Stage 1 learns a coarse parametric point model using a low-rank deformation basis. Stage 2 refines this representation using 3D Gaussians, building on the [Optimization and Training Loop](17791-optimization-and-training-loop.md) principles.

### Inputs and Outputs
**Inputs:**
*   Monocular video sequence of a non-rigid object.
*   Masks for dynamic objects (optional, used for sequences with static backgrounds like ground planes) [S1].
*   Hyperparameters: Deformation basis size $K$, learning rates, iteration counts.

**Outputs:**
*   Optimized coarse parametric point model (positions, deformation basis coefficients).
*   Optimized 3D Gaussian parameters (position, covariance, opacity, SH coefficients) attached to the deforming template.

### Data Structures
1.  **Coarse Parametric Point Model:**
    *   A set of $N_p = 1500$ points [S1].
    *   Each point $j$ has a base position $\mathbf{p}_j^0$ and a deformation basis coefficient vector $\mathbf{w}_j \in \mathbb{R}^K$ [S1].
    *   The deformation at timestep $t$ is computed via a 6-layer MLP $f_{MLP}$:
        $$ \mathbf{p}_j(t) = \mathbf{p}_j^0 + f_{MLP}(\mathbf{w}_j, t) $$
    *   The MLP takes the coefficient vector $\mathbf{w}_j$ and time $t$ as input [S1].

2.  **3D Gaussians:**
    *   Attached to the points of the coarse model.
    *   Parameters: Position $\mathbf{p}_i$, rotation quaternion $\mathbf{q}_i$, scale vector $\mathbf{s}_i$, opacity $\alpha_i$, and SH coefficients $\mathbf{c}_{i,l}$ [S1].
    *   Interpolation weights $\mathbf{w}$ link the Gaussians to the coarse model's deformation [S1].

### Numbered Steps

**Stage 1: Coarse Parametric Point Model Optimization**
1.  Initialize $N_p = 1500$ points [S1].
2.  Initialize a 6-layer MLP to compute deformation basis coefficients [S1].
3.  Optimize the point positions and MLP parameters to minimize reconstruction loss plus a rigidity loss.
    *   **Rigidity Loss:** Applied to keep the template consistent across timesteps [S1].
    *   **Optimizer:** Adam [S1].
    *   **Batch Size:** 10 [S1].
    *   **Learning Rate:** 0.0005 with cosine annealing and warm-up [S1].
    *   **Iterations:** 100,000 [S1].

**Stage 2: 3D Gaussian Refinement**
1.  Initialize 3D Gaussians on the optimized points from Stage 1.
2.  Optimize Gaussian parameters and interpolation weights $\mathbf{w}$.
    *   **Learning Rate for $\mathbf{w}$:** Matches the default point position learning rate in 3DGS [S1].
    *   **Learning Rate for Gaussian Scale:** 0.0005 [S1].
    *   **Scale Scheduler:** Exponential decay from a high initial value down to 0.0005 [S1].
    *   **Optimizer:** Adam (inherited from 3DGS schedule) [S1].
    *   **Iterations:** 70,000 [S1].
3.  **Optional Finetuning:** Continue optimizing Stage 1 parameters (MLP and base points) with a learning rate of 0.0001 to improve template accuracy [S1].

### Parameters
*   **Deformation Basis Size ($K$):** Controls regularization strength.
    *   Small $K$: Over-regularizes, restricting non-rigid deformations [S1].
    *   Large $K$: Overfits to observations, hindering novel view synthesis [S1].
    *   Typical Value: 25 (found optimal for the synthetic cactus sequence) [S1].
*   **Number of Coarse Points ($N_p$):** 1500 [S1].
*   **MLP Depth:** 6 layers [S1].

### Edge Cases and Pitfalls
*   **Template Collapse:** If the camera is very static, the optimized template may collapse to a flat surface, leading to incorrect deformation [S1].
*   **Static Backgrounds:** For sequences with large static ground planes, masks for dynamic objects only are required to obtain valid results [S1].

### Pseudocode

```python
def npgs_optimization(video_frames, masks, K=25):
    """
    Two-stage optimization for Neural Parametric Gaussians.
    
    Args:
        video_frames: List of images from monocular video.
        masks: Binary masks for dynamic objects (optional).
        K: Size of the deformation basis.
        
    Returns:
        optimized_gaussians: 3D Gaussian parameters.
        optimized_mlp: Trained MLP for deformation.
    """
    
    # --- Stage 1: Coarse Parametric Point Model ---
    N_p = 1500
    # Initialize base points p_0 and coefficients w
    p_0 = initialize_points(N_p)
    w = initialize_weights(N_p, K)
    
    # Initialize 6-layer MLP
    mlp = MLP(depth=6)
    
    # Stage 1 Hyperparameters
    lr_stage1 = 0.0005
    batch_size = 10
    iterations_stage1 = 100000
    optimizer_stage1 = Adam([p_0, w, mlp.parameters()], lr=lr_stage1)
    scheduler_stage1 = CosineAnnealingWarmupRestarts(optimizer_stage1, T_max=iterations_stage1)
    
    for step in range(iterations_stage1):
        # Sample batch of timesteps
        t_batch = sample_timesteps(batch_size)
        
        # Compute deformed points
        # p(t) = p_0 + MLP(w, t)
        deformations = mlp(w, t_batch)
        p_t = p_0 + deformations
        
        # Render coarse approximation (or use proxy loss)
        # Note: Specific rendering of coarse points is not detailed, 
        # but rigidity loss is applied here [S1].
        loss_coarse = compute_reconstruction_loss(p_t, video_frames[t_batch], masks)
        loss_rigidity = compute_rigidity_loss(p_t)
        
        loss = loss_coarse + loss_rigidity
        
        optimizer_stage1.zero_grad()
        loss.backward()
        optimizer_stage1.step()
        scheduler_stage1.step()
        
    # --- Stage 2: 3D Gaussian Refinement ---
    # Initialize Gaussians on optimized p_t from Stage 1
    gaussians = initialize_gaussians(p_t)
    
    # Stage 2 Hyperparameters
    lr_gaussian_scale = 0.0005
    lr_interp_weights = get_default_3dgs_point_lr() # From 3DGS schedule
    iterations_stage2 = 70000
    
    # Optimizer setup for Gaussians and interpolation weights
    optimizer_stage2 = Adam([gaussians.parameters(), gaussians.interpolation_weights], 
                            lr=lr_interp_weights)
    
    # Exponential scheduler for scales
    scale_scheduler = ExponentialDecayScheduler(initial_lr=high_value, final_lr=lr_gaussian_scale)
    
    for step in range(iterations_stage2):
        # Sample timesteps and views
        t_batch = sample_timesteps(batch_size)
        view_batch = sample_views(batch_size)
        
        # Compute deformed points using Stage 1 MLP
        deformations = mlp(w, t_batch)
        p_t = p_0 + deformations
        
        # Update Gaussian positions based on deformation
        gaussians.update_positions(p_t)
        
        # Render image
        rendered_image = splat_gaussians(gaussians, view_batch)
        
        # Compute Loss (Composite Loss from Parent)
        # L_img = (1 - lambda) * L_L1 + lambda * L_D-SSIM
        loss_img = compute_composite_loss(rendered_image, video_frames[t_batch][view_batch])
        
        # Note: Specific additional losses for Stage 2 are not detailed in sources [S1]
        loss = loss_img
        
        optimizer_stage2.zero_grad()
        loss.backward()
        optimizer_stage2.step()
        
        # Update scale learning rate
        current_scale_lr = scale_scheduler.get_lr(step)
        update_gaussian_scale_lr(gaussians, current_scale_lr)
        
    # --- Optional Finetuning Stage 1 ---
    lr_finetune = 0.0001
    optimizer_finetune = Adam([p_0, w, mlp.parameters()], lr=lr_finetune)
    
    # Run additional iterations if needed to improve template accuracy
    # Iterations not specified in sources [S1]
    for step in range(optional_finetune_iterations):
        t_batch = sample_timesteps(batch_size)
        deformations = mlp(w, t_batch)
        p_t = p_0 + deformations
        gaussians.update_positions(p_t)
        
        rendered_image = splat_gaussians(gaussians, view_batch)
        loss = compute_composite_loss(rendered_image, video_frames[t_batch][view_batch])
        
        optimizer_finetune.zero_grad()
        loss.backward()
        optimizer_finetune.step()
        
    return gaussians, mlp
```

## Operating characteristics
*   **Performance:** NPGs outperform Nerfies, HyperNeRF, TiNeuVox, and HexPlane on the Unbiased4D dataset (PSNR 22.348 vs 15.92–18.56) [S1].
*   **Strengths:** Keeps coarse geometry intact over the sequence and successfully fits high-frequency details [S1].
*   **Limitations:** Highly ill-posed for monocular video; performance depends on camera movement, lighting, speed, and extent of deformations [S1]. Fails if the camera is very static (template collapse) [S1].
*   **Complexity:** Uses a 6-layer MLP and low-rank basis ($K=25$) for regularization, which is computationally lighter than full neural radiance fields but requires careful tuning of $K$ to balance over-regularization and overfitting [S1].

## Background
Neural Parametric Gaussians (NPGs) was introduced in the paper "Neural Parametric Gaussians for Monocular Non-Rigid Object Reconstruction" [S1]. It targets the object-centric setting for monocular non-rigid reconstruction, addressing limitations of previous methods that struggle with geometry consistency in dynamic scenes captured by a single moving camera [S1].
