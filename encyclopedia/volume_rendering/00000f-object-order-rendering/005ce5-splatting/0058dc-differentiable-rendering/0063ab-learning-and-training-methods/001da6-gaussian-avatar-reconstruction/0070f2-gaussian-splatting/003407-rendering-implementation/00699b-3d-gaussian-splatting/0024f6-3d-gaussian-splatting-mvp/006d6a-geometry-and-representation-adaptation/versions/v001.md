# Geometry and Representation Adaptation

Also called: Geometry Adaptation, Representation Modification

## Overview
This family encompasses methods that modify the standard 3D Gaussian Splatting (3DGS) representation to address specific geometric or structural limitations, such as sparse initialization, dynamic human animation, or depth ambiguity in volumetric rendering. Unlike standard 3DGS, which maintains a fixed set of isotropic/anisotropic 3D Gaussians, these methods adapt the primitive type, storage mechanism, or optimization constraints to better fit the target data distribution.

## Shared principles
All methods in this family build on [3D Gaussian Splatting MVP](3410-3d-gaussian-splatting-mvp.md) but diverge in how they define the primitive's degrees of freedom or spatial relationship to the scene geometry.

1.  **Primitive Modification**: The core Gaussian parameters ($\mathbf{\mu}, \mathbf{q}, \mathbf{s}, \alpha, \mathbf{c}$) are either augmented (e.g., with height-field bases in H-2DGS) or decoupled from spatial coordinates (e.g., UV parameterization).
2.  **Geometric Supervision**: Standard photometric loss is insufficient. These methods introduce auxiliary losses or constraints:
    *   **Depth/Thickness Constraints**: Explicitly penalizing volumetric thickness or enforcing depth consistency to resolve ambiguity .
    *   **Structural Priors**: Using external geometry (meshes, TSDFs) to guide initialization or deformation .
3.  **Multi-Stage Optimization**: Many methods separate appearance learning from geometric refinement, using intermediate representations (e.g., volumetric 3DGS) to bootstrap a more constrained representation (e.g., surface patches) .

## Subtopics

### [3D Gaussian Splatting with Gaussian Unpooling](6133-3d-gaussian-splatting-with-gaussian-unpooling.md)
*   **What it is**: A method for reconstructing scenes from sparse input views by expanding sparse Structure-from-Motion (SfM) points into a denser Gaussian set.
*   **Distinction**: Addresses the "cold start" problem where standard 3DGS fails due to insufficient initialization coverage. It uses Gaussian unpooling to fill gaps and depth supervision to guide geometry.
*   **When to choose**: When input data is sparse (few camera views) and standard densification fails to cover the scene volume.

### [3D Gaussian Splatting with Mesh UV Parameterization](8046-3d-gaussian-splatting-with-mesh-uv-parameterization.md)
*   **What it is**: A method for animated human rendering that projects 3D Gaussian attributes into a 2D UV texture space defined by a parametric mesh (e.g., SMPL).
*   **Distinction**: Decouples appearance storage from 3D spatial coordinates. This allows for compact representation and efficient texture-based rendering of dynamic cloth and accessories, avoiding the need to store and update thousands of 3D Gaussians per frame.
*   **When to choose**: For real-time rendering of animated humans where topology is known and deformation is driven by a parametric skeleton.

### [H-2DGS (Height-Field 2D Gaussian Splatting)](21287-h-2dgs-height-field-2d-gaussian-splatting.md)
*   **What it is**: A three-stage pipeline that converts volumetric 3DGS into a thin, deformable cortical surface using curved height-field Gaussian primitives initialized on a Truncated Signed Distance Field (TSDF).
*   **Distinction**: Solves depth ambiguity and thick geometric bands in standard 3DGS under limited view coverage. It discards the volumetric representation in favor of an explicit height-field surface, enabling integration with medical imaging (MRI) and postoperative deformation.
*   **When to choose**: When high-fidelity, sharp surface geometry is required from limited views, or when the application requires explicit surface manipulation (e.g., medical simulation).

## Background
Standard 3D Gaussian Splatting [G] assumes dense, well-initialized point clouds and static scenes. These adaptations emerged to handle specific failure modes: sparse data (unpooling), dynamic topology (UV parameterization), and depth ambiguity (H-2DGS). The techniques represent a shift from pure volumetric rasterization to hybrid representations that incorporate explicit geometric priors or structured storage.
