# Standard 3DGS Training Configuration

Also called: Standard 3DGS Training

## Overview
Standard 3DGS Training Configuration defines the canonical hyperparameter settings for optimizing 3D Gaussian Splatting models, establishing the baseline for adaptive density control and gradient-based optimization. It differs from sibling methods like [Conditional 3DGS Optimization and Rendering](11459-conditional-3dgs-optimization-and-rendering.md) or [Blended Error Densification and Splitting](13892-blended-error-densification-and-splitting.md) by adhering strictly to the default parameters of the official implementation, specifically regarding densification frequency, gradient thresholds, and opacity management [S1].

## How it works
The method configures the training loop to balance reconstruction quality and computational efficiency through a fixed schedule of densification, pruning, and opacity resets.

**Inputs and Outputs**
*   **Inputs:** Initial point cloud (from SfM), training images, and hyperparameter configuration.
*   **Outputs:** Optimized set of 3D Gaussians (position, covariance, opacity, spherical harmonics coefficients) and a rendered image sequence.

**Data Structures**
The Gaussian representation maintains per-Gaussian attributes:
*   **Position:** 3D vector $\mathbf{x} \in \mathbb{R}^3$.
*   **Covariance:** 3D rotation $\mathbf{R}$ and scaling $\mathbf{s}$, stored as quaternions and scale vectors.
*   **Opacity:** Scalar $\alpha \in [0, 1]$.
*   **Color:** Spherical Harmonics (SH) coefficients.

**Parameters**
*   **Maximum Iterations:** 30,000 [S1].
*   **D-SSIM Loss Weight:** 0.2 [S1].
*   **Spherical Harmonics Degree:** 3 [S1].
*   **Background Color:** Black [S1].
*   **Densification Gradient Threshold:** 0.0002 [S1].
*   **Opacity Reset Interval:** 3000 iterations [S1].
*   **Densification Start Iteration:** 500 [S1].
*   **Densification Interval:** 100 iterations [S1].

**Steps**
1.  **Initialization:** Initialize Gaussians from Structure-from-Motion (SfM) points. Set all opacities to a small initial value (typically 0.1 or 0.01, though standard reset sets to 0.01).
2.  **Optimization Loop:** Iterate from $t = 1$ to $T_{max} = 30,000$.
3.  **Rendering:** Render the current Gaussian set to generate images.
4.  **Loss Calculation:** Compute the combined loss using RGB loss and D-SSIM loss with weight 0.2 [S1].
5.  **Gradient Accumulation:** Accumulate gradients for Gaussian positions and other attributes.
6.  **Densification Check:** If $t \ge 500$ and $(t - 500) \mod 100 == 0$:
    *   **Accumulate Statistics:** Track gradient magnitudes for each Gaussian.
    *   **Split/Clone:** For Gaussians with accumulated gradient magnitude exceeding the threshold (0.0002) [S1]:
        *   If the Gaussian is "large" (size > `percent_dense` $\times$ scene extent, default 0.01), split it into two smaller Gaussians with 80% of the original size [S2, Note: S2 defines this logic for modified config, but standard config uses default `percent_dense` of 0.01].
        *   If the Gaussian is "small", clone it identically.
    *   **Pruning:** Remove Gaussians with opacity below a minimum threshold (default 0.005) [S2, Note: S2 contrasts this with its own higher threshold, implying 0.005 is standard].
    *   **Opacity Reset:** Every 3000 iterations, reset the opacity of all Gaussians to 0.01 [S1].
7.  **Optimization Step:** Update Gaussian parameters using the accumulated gradients (typically Adam optimizer).
8.  **Termination:** Stop at iteration 30,000 [S1].

**Edge Cases and Pitfalls**
*   **Precision:** Gradient thresholds are small ($2 \times 10^{-4}$); ensure floating-point precision is sufficient to distinguish significant gradients from noise [S1].
*   **Boundary Conditions:** The densification start at iteration 500 prevents early instability [S1].
*   **Degenerate Input:** If SfM points are sparse, initial densification may create excessive Gaussians if the gradient threshold is too low; however, the standard threshold is fixed [S1].

**Pseudocode**
```python
def standard_3dgs_training(gaussians, images, max_iter=30000):
    # Hyperparameters from [S1]
    densify_start_iter = 500
    densify_interval = 100
    densify_grad_threshold = 0.0002
    opacity_reset_interval = 3000
    opacity_reset_value = 0.01
    d_ssim_weight = 0.2
    sh_degree = 3
    background_color = [0.0, 0.0, 0.0] # Black
    
    # Default parameters implied by [S2] contrast
    densify_min_opacity = 0.005
    percent_dense = 0.01
    
    accumulated_gradients = {g.id: 0.0 for g in gaussians}
    
    for t in range(1, max_iter + 1):
        # 1. Render
        rendered_images = render(gaussians, images, background_color)
        
        # 2. Compute Loss
        loss = compute_loss(rendered_images, images, d_ssim_weight)
        
        # 3. Backpropagate
        gradients = compute_gradients(loss, gaussians)
        
        # 4. Accumulate Gradients for Densification
        for g in gaussians:
            grad_mag = norm(gradients[g.id].position)
            accumulated_gradients[g.id] += grad_mag
            
        # 5. Densification and Pruning
        if t >= densify_start_iter and (t - densify_start_iter) % densify_interval == 0:
            new_gaussians = []
            for g in gaussians:
                if accumulated_gradients[g.id] > densify_grad_threshold:
                    # Split or Clone based on size
                    if is_large(g, percent_dense):
                        new_gaussians.extend(split_gaussian(g, factor=0.8))
                    else:
                        new_gaussians.append(clone_gaussian(g))
                else:
                    new_gaussians.append(g)
            
            # Prune low opacity Gaussians
            gaussians = [g for g in new_gaussians if g.opacity > densify_min_opacity]
            
            # Reset accumulated gradients
            accumulated_gradients = {g.id: 0.0 for g in gaussians}
            
        # 6. Opacity Reset
        if t % opacity_reset_interval == 0:
            for g in gaussians:
                g.opacity = opacity_reset_value
                
        # 7. Optimization Step
        optimize(gaussians, gradients)
        
    return gaussians
```

## Subtopics

### Modified 3DGS Densification
A parameter-tuning strategy that reduces the number of generated Gaussians and minimizes sorting time during training [S2]. It differs from the standard configuration by increasing the densification interval to 1000 (vs 100), lowering the densification gradient threshold to $7 \times 10^{-5}$ (vs $2 \times 10^{-4}$), raising the minimum opacity threshold to 0.1 (vs 0.005), deactivating the opacity reset (interval $\infty$ vs 3000), and increasing the `percent_dense` threshold to 0.1 (vs 0.01) [S2]. This configuration avoids regular pruning and creates fewer Gaussian splats overall [S2].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot I)$, where $N$ is the number of Gaussians and $I$ is the number of iterations (30,000) [S1]. Densification adds overhead every 100 iterations [S1].
*   **Memory Complexity:** $O(N)$, where $N$ grows during densification and shrinks during pruning [S1].
*   **Performance:** The standard configuration is computationally intensive due to frequent densification and pruning [S1]. It produces high-quality reconstructions but requires significant GPU memory [S1].
*   **Strengths:** Established baseline, high reconstruction quality, well-understood behavior [S1].
*   **Limitations:** High memory usage, long training times, potential for over-densification in complex scenes [S1, S2].
*   **When to Use:** When high-quality reconstruction is prioritized over training speed or memory efficiency [S1].
*   **When Not to Use:** When memory is constrained or training time is critical; consider [Modified 3DGS Densification](11076-hyperparameter-settings.md#modified-3dgs-densification) or [Sparse Matching Integration](14995-sparse-matching-integration.md) [S2].

## Background
The standard 3DGS training configuration originates from the official implementation of 3D Gaussian Splatting [S1]. It has been widely adopted as the baseline for evaluating new densification strategies and optimization techniques [S1, S2]. The configuration was standardized to ensure reproducibility across experiments [S1].
