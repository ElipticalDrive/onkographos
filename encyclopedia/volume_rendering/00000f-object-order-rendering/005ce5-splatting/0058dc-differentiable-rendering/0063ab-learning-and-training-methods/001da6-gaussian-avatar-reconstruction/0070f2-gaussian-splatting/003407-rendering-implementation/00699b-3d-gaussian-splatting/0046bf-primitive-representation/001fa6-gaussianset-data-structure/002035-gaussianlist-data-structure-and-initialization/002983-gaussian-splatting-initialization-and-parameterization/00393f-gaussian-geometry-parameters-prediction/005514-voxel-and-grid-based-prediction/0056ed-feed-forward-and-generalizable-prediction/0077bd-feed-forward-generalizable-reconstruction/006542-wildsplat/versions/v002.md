# WildSplat

Also called: WildSplat: Feedforward Gaussian Splatting from Unposed In-the-Wild Images

## Overview
WildSplat is a feedforward 3D Gaussian Splatting framework designed for appearance-conditioned novel-view synthesis from sparse, unposed, in-the-wild images [S1]. It solves the problem of inconsistent photometric conditions (varying lighting, weather, or season) that typically cause existing feedforward methods to fail by entangling geometry with appearance [S1]. Unlike optimization-based methods or prior feedforward approaches that assume photometric consistency, WildSplat explicitly decouples geometry from appearance using a dual-branch architecture, allowing it to reconstruct invariant 3D structure while conditioning the rendering appearance on a specific reference image [S1].

## How it works
**Inputs and Outputs:**
The model takes a set of context images $\{I_i\}_{i=1}^N$ and a single reference image $I_{ref}$ [S1]. It outputs:
1.  A 3D Gaussian representation $\mathcal{G}$ consisting of positions $\mu \in \mathbb{R}^{G \times 3}$, rotations $q \in \mathbb{R}^{G \times 4}$, scales $s \in \mathbb{R}^{G \times 3}$, and opacities $\alpha \in \mathbb{R}^G$, where $G$ is the number of Gaussians [S1].
2.  Conditioned spherical harmonics coefficients $\mathcal{C}_{ref} \in \mathbb{R}^{G \times 3 \times (k+1)}$ of degree $k$, conditioned on $I_{ref}$ [S1].
3.  Camera poses $\{p_i\}$ for the context views [S1].

The mapping is defined as:
$$ f: \{I_i\}, I_{ref} \mapsto (\mathcal{G}, \mathcal{C}_{ref}, \{p_i\}) $$
[S1]

**Data Structures:**
*   **Patch Tokens:** $T_i^{(0)} \in \mathbb{R}^{P \times D}$, dense patch-level tokens for view $i$, where $P$ is the number of patches and $D$ is the feature dimension [S1].
*   **Camera Tokens:** $C_i \in \mathbb{R}^{5 \times D}$, learnable tokens concatenated with patch tokens for pose estimation [S1].
*   **Content Features:** $\mathbf{F}_{\text{content}}$, aggregated multi-scale representations from the geometry branch, serving as the geometric scaffold [S1].
*   **Reference Tokens:** $T_{ref} \in \mathbb{R}^{P_a \times D}$, local dense appearance tokens extracted from the reference image, where $P_a$ is the number of reference patches [S1].
*   **Overlap/Scale Matrices:** $S$ (overlap ratio of shared SfM points) and $R$ (minimum depth ratio) used for view sampling [S1].

**Algorithm Steps:**

1.  **Geometry Branch (Structure & Pose):**
    *   Process each context image $I_i$ independently through a DINOv2-based geometry encoder $E_{geo}$ to obtain initial patch tokens:
        $$ T_i^{(0)} = E_{geo}(I_i) $$
        [S1]
    *   Concatenate learnable camera tokens $C_i$ with $T_i^{(0)}$. Refine through $L$ alternating attention blocks to produce refined patch tokens $T_i^{(k)}$ and camera tokens $C_i^{(k)}$ for layer $k$ [S1].
    *   Extract and aggregate multi-scale representations from a subset of transformer layers $K = \{l_1, \dots, l_K\}$ to form the content features $\mathbf{F}_{\text{content}}$ [S1].
    *   Decode camera poses $\{p_i\}$ from the final camera tokens $C_i^{(L)}$ [S1].

2.  **Appearance Branch (Conditioning):**
    *   Extract reference appearance tokens $T_{ref}$ from $I_{ref}$ using an appearance encoder [S1].
    *   **Global Pre-modulation:** To prevent the original photometric properties of $\mathbf{F}_{\text{content}}$ from interfering with the target appearance, apply an AdaLN-Zero layer [G: Adaptive Layer Normalization with Zero Initialization] to the global descriptor $T_{[CLS]}$ (derived from $\mathbf{F}_{\text{content}}$) to generate scale $\gamma$, shift $\beta$, and gating $\eta$ [S1]. Modulate the content features:
        $$ \tilde{T}_i^{(k)} = \gamma \cdot \mathbf{F}_{\text{content}} + \beta $$
        [S1] (Note: Source formula snippet implies modulation of features; exact vector operation is standard AdaLN-Z0 application).
    *   **Cross-Attention:** Use the modulated features $\tilde{T}_i^{(k)}$ as queries ($Q$) and reference tokens $T_{ref}$ as keys ($K$) and values ($V$) to inject appearance cues:
        $$ \text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{QK^T}{\sqrt{d}}\right)V $$
        [S1]
    *   The output of this process yields the conditioned spherical harmonics coefficients $\mathcal{C}_{ref}$ [S1].

3.  **Conditioned Rasterization:**
    *   Render novel views $\{\hat{I}_i\}$ using tile-based differentiable rasterization $\mathcal{R}$ of 3D Gaussian Splatting:
        $$ \{\hat{I}_i\} = \mathcal{R}(\mathcal{G}, \mathcal{C}_{ref}, \{p_i\}) $$
        [S1]

4.  **Geometry-guided View Sampling (Training Data Selection):**
    *   Construct overlap matrix $S$ and scale matrix $R$ using Structure-from-Motion (SfM) points [S1].
    *   Filter valid view pairs where $S \ge \tau_s$ and $R \ge \tau_r$ [S1].
    *   Select starting rows $C$ where the sum of valid columns $> \tau_n$ [S1].
    *   Initialize a queue with a uniform sample from $C$. Iteratively pop $u$, sample up to $K$ neighbors from valid unvisited views, push to queue, and add to index set $\mathcal{I}$ until $N$ views are selected [S1].

**Pseudocode:**

```python
def wildsplat_forward(context_images, reference_image):
    """
    context_images: List of N images {I_i}
    reference_image: Single image I_ref
    Returns: Gaussian set G, SH coefficients C_ref, poses {p_i}
    """
    # 1. Geometry Branch
    # Encode context images
    patch_tokens = []
    for I_i in context_images:
        T_i_0 = dino_v2_encoder(I_i) # E_geo
        patch_tokens.append(T_i_0)
    
    # Initialize camera tokens
    camera_tokens = [learnable_camera_tokens() for _ in context_images]
    
    # Refine through L attention blocks
    for k in range(L):
        new_patch_tokens = []
        new_camera_tokens = []
        for i in range(N):
            combined = concat(patch_tokens[i], camera_tokens[i])
            # Attention block refinement
            refined = attention_block(combined)
            new_patch_tokens.append(refined.patch_tokens)
            new_camera_tokens.append(refined.camera_tokens)
        patch_tokens = new_patch_tokens
        camera_tokens = new_camera_tokens
        
    # Extract content features from specific layers K
    content_features = aggregate_multi_scale(patch_tokens, layers=K)
    
    # Predict poses
    poses = predict_poses(camera_tokens)
    
    # 2. Appearance Branch
    # Encode reference image
    ref_tokens = appearance_encoder(reference_image)
    
    # Global pre-modulation using AdaLN-Zero
    cls_token = get_cls_token(content_features)
    gamma, beta, eta = adaln_zero(cls_token)
    modulated_features = gamma * content_features + beta
    
    # Cross-attention to inject appearance
    # Q: modulated_features, K/V: ref_tokens
    conditioned_features = cross_attention(modulated_features, ref_tokens, ref_tokens)
    
    # Decode SH coefficients
    C_ref = decode_sh(conditioned_features)
    
    # 3. Output
    G = extract_gaussian_attributes(content_features) # Positions, scales, etc.
    return G, C_ref, poses

def geometry_guided_view_sampling(sfm_points, num_views, thresholds):
    """
    Selects N views with sufficient overlap and scale consistency.
    """
    S = compute_overlap_matrix(sfm_points)
    R = compute_scale_matrix(sfm_points)
    
    tau_s, tau_r, tau_n = thresholds
    
    # Valid mask
    valid_mask = (S >= tau_s) & (R >= tau_r)
    
    # Valid starting rows
    valid_starts = [i for i in range(len(S)) if sum(valid_mask[i]) > tau_n]
    
    if not valid_starts:
        return []
        
    queue = [random.choice(valid_starts)]
    selected_indices = set(queue)
    
    while len(selected_indices) < num_views and queue:
        u = queue.pop(0)
        # Sample up to K neighbors from valid unvisited views
        candidates = [v for v in range(len(S)) 
                      if valid_mask[u, v] and v not in selected_indices]
        k_neighbors = random.sample(candidates, min(K, len(candidates)))
        
        for v in k_neighbors:
            queue.append(v)
            selected_indices.add(v)
            
    return list(selected_indices)
```

**Parameters:**
*   $\lambda_1 = 10$: Weight for pose loss $L_{pose}$ [S1].
*   $\lambda_2 = 1.0$: Weight for MSE loss $L_{MSE}$ [S1].
*   $\lambda_3 = 0.05$: Weight for SSIM loss $L_{SSIM}$ [S1].
*   $\lambda_4 = 0.05$: Weight for LPIPS loss $L_{LPIPS}$ [S1].
*   $N$: Number of context views (e.g., 12 in evaluation) [S1].
*   $K$: Number of neighbors sampled during view selection [S1].
*   $\tau_s, \tau_r, \tau_n$: Thresholds for overlap, scale, and connectivity [S1].

**Edge Cases and Pitfalls:**
*   **Varying Focal Lengths:** Standard sampling relying on camera extrinsics fails on in-the-wild datasets where minor pose shifts alter captured content due to varying focal lengths. Mitigated by overlap-based sampling using SfM points [S1].
*   **Photometric Interference:** Content features from the geometry branch retain original photometric properties, potentially interfering with target appearance conditioning. Mitigated by global pre-modulation using AdaLN-Zero to shift features into the target appearance domain [S1].
*   **Pose Estimation Instability:** Inconsistent inputs during training can adversely affect pose estimation. Mitigated by distillation loss $L_{pose}$ [S1].

## Operating characteristics
*   **Time Complexity:** Single forward pass for reconstruction and rendering, making it significantly faster than optimization-based methods like NeRF-W or GS-W which require per-scene optimization [S1].
*   **Memory Complexity:** Depends on the number of Gaussians $G$ and the feature dimensions $D, P$. The dual-branch architecture requires storing features for both geometry and appearance branches simultaneously during inference [S1].
*   **Measured Performance:**
    *   On MegaScenes (12 views): PSNR 19.20, SSIM 0.683, LPIPS 0.210 [S1].
    *   On Phototourism (12 views): PSNR 21.47, SSIM 0.788, LPIPS 0.137 [S1].
*   **Strengths:** Handles sparse, unposed, in-the-wild images; decouples geometry from appearance to handle varying illumination/weather; no per-scene optimization required [S1].
*   **Limitations:** Performance is lower than dense-view optimization-based methods on consistent datasets; relies on SfM points for view sampling during training [S1].
*   **When to use:** When input images are sparse, unposed, and exhibit significant photometric variations (e.g., different seasons, times of day) [S1].
*   **When not to use:** When dense, posed inputs with consistent lighting are available and higher fidelity is required via optimization [S1].

## Background
WildSplat was introduced by Zhang et al. in 2024 [S1]. It is the first feedforward 3D Gaussian Splatting framework capable of appearance-conditioned novel-view synthesis for unposed in-the-wild images [S1]. It builds upon the VGGT architecture for geometry estimation and integrates concepts from feedforward NeRF methods like pixelNeRF and MVSplat, but extends them to 3DGS with explicit geometry-appearance decoupling [S1]. The method addresses the limitations of optimization-based in-the-wild methods (e.g., NeRF-W, GS-W) which require precomputed poses and dense images, and prior feedforward methods that assume photometric consistency [S1].
