# GoF-based Dynamic 3DGS Video Construction

Also called: Group of Frames modeling, Temporal segmentation with deformation fields

## Overview
This method constructs dynamic 3D Gaussian Splatting (3DGS) video by temporally segmenting input sequences into Groups of Frames (GoFs) and independently training Gaussian deformation fields within each segment [S1]. It solves the problem of motion drift and geometric inconsistencies that occur when modeling long-range temporal dependencies with a single global deformation field [S1]. By limiting the motion degree within short segments, it prevents the deformation field from struggling to adapt to complex, long-sequence dynamics [S1]. It sets itself apart from global optimization approaches by decoupling static and dynamic components via weighted MLP parameters and separating foreground/background content to reduce training complexity [S1].

## How it works
**Inputs:** A dynamic video sequence with camera poses and intrinsics for each frame [G].
**Outputs:** A set of 3D Gaussian primitives with static attributes (position, base scale, base rotation, base opacity, base color) and dynamic attributes (deformation fields per GoF); a segmentation mask distinguishing foreground from background [S1, G].

**Data Structures:**
1. **GoF Segments:** The input sequence is divided into $N$ non-overlapping temporal segments $G_1, G_2, ..., G_N$ [S1].
2. **Static Scene Model:** A global set of Gaussians $\mathcal{G}_{static}$ capturing long-sequence static information [S1].
3. **Deformation Field MLP:** A Multi-Layer Perceptron $f_{\theta_i}(t, \mathbf{x})$ for each GoF $i$, parameterized by $\theta_i$ [S1].
4. **Tuning Parameters:** A set of scalar weights $\alpha$ applied to MLP parameters to modulate focus on dynamic elements [S1].
5. **Foreground/Background Mask:** A binary or probabilistic mask $M_{fg}$ identifying dynamic regions versus static background [S1].

**Steps:**
1. **Temporal Segmentation:** Divide the input video sequence into multiple GoFs $G_i$ [S1].
2. **Initial Static Modeling:** Construct an initial scene model $\mathcal{G}_{init}$ that captures overall information across the entire long sequence [S1].
3. **Foreground/Background Separation:** Analyze the video content to differentiate between foreground (dynamic elements like human bodies, interacting objects, animals) and background (static environment) [S1]. This separation reduces the complexity of the deformation field training [S1].
4. **GoF-Specific Initialization:** For each GoF $G_i$:
    *   Preserve the extensive static regions from $\mathcal{G}_{init}$ [S1].
    *   Identify dynamic areas within $G_i$ based on the foreground mask [S1].
    *   Initialize a GoF-specific model by exclusively fine-tuning the dynamic areas while keeping static regions fixed or lightly regularized [S1].
5. **Dynamic MLP Construction:** Construct a dynamic Multi-Layer Perceptron (MLP) for each GoF [S1]. The MLP takes time $t$ (normalized within the GoF) and spatial coordinates $\mathbf{x}$ as input to predict deformation offsets.
6. **Weighted Training:** During training, apply tuning parameters (weights) to the MLP parameters [S1]. These weights direct the optimization focus toward dynamic elements, effectively decoupling static and dynamic Gaussian components in a smoothly weighted fashion [S1].
7. **Deformation Field Derivation:** Train the MLP for each GoF to derive the corresponding deformation field [S1]. The deformation field maps the static Gaussian positions to their dynamic positions at time $t$ within the GoF using $\mathbf{p}_i(t) = \mathbf{p}_{static} + f_{\theta_i}(t, \mathbf{p}_{static})$ [G].
8. **Streaming Optimization (Optional):** For transmission, selectively stream only the foreground model (deformation fields and dynamic Gaussians) based on user interaction, while transmitting the static background model once or less frequently [S1].

**Pseudocode:**
```python
def gof_based_dynamic_3dgs(video_sequence, camera_poses):
    # Step 1: Temporal Segmentation
    segment_length = 10  # Not given in the sources.
    gofs = [video_sequence[i:i+segment_length] for i in range(0, len(video_sequence), segment_length)]

    # Step 2: Initial Static Modeling
    static_model = train_global_3dgs(video_sequence, camera_poses)

    # Step 3: Foreground/Background Separation
    fg_masks = compute_foreground_masks(video_sequence)

    gof_deformation_fields = {}
    gof_gaussian_updates = {}

    for i, gof in enumerate(gofs):
        # Step 4: GoF-Specific Initialization
        gof_model = copy_static_model(static_model)
        dynamic_gaussians = filter_gaussians(gof_model, fg_masks[i], region='foreground')
        static_gaussians = filter_gaussians(gof_model, fg_masks[i], region='background')

        # Step 5: Dynamic MLP Construction
        mlp = MLP(input_dim=4, hidden_dims=[64, 64, 32])

        # Step 6: Weighted Training
        tuning_weights = initialize_tuning_weights(mlp)

        # Step 7: Deformation Field Derivation
        num_epochs = 100  # Not given in the sources.
        lr = 0.01
        for epoch in range(num_epochs):
            for frame_idx, frame in enumerate(gof):
                t = frame_idx / len(gof)
                pose = camera_poses[gof.start_frame + frame_idx]
                positions = get_positions(dynamic_gaussians)
                deformation_offsets = mlp.forward(t, positions)
                deformed_positions = positions + deformation_offsets
                rendered_image = render_3dgs(static_gaussians, dynamic_gaussians, deformed_positions, pose)
                loss = compute_loss(rendered_image, frame)
                loss.backward()
                apply_weighted_update(mlp.parameters(), tuning_weights, lr)

        gof_deformation_fields[i] = mlp
        gof_gaussian_updates[i] = dynamic_gaussians

    return static_model, gof_deformation_fields, gof_gaussian_updates

# Helper definitions
def train_global_3dgs(seq, poses): return {}  # Standard 3DGS initialization [G]
def compute_foreground_masks(seq): return [mask for mask in seq]  # Standard segmentation [G]
def copy_static_model(model): return model.copy()
def filter_gaussians(model, mask, region): return [g for g in model if (g in mask) == (region == 'foreground')]
class MLP:
    def __init__(self, input_dim, hidden_dims):
        self.weights = [np.random.randn(input_dim if i==0 else hidden_dims[i-1], hidden_dims[i]) for i in range(len(hidden_dims))]
        self.biases = [np.zeros(hidden_dims[i]) for i in range(len(hidden_dims))]
    def forward(self, t, x):
        h = np.concatenate([np.full((x.shape[0], 1), t), x], axis=-1)
        for w, b in zip(self.weights, self.biases):
            h = np.maximum(0, h @ w + b)  # ReLU
        return h @ self.weights[-1] + self.biases[-1]  # Linear output
    def parameters(self): return self.weights + self.biases
def initialize_tuning_weights(mlp): return [np.ones_like(w) for w in mlp.parameters()]
def get_positions(gaussians): return np.stack([g.position for g in gaussians])
def render_3dgs(static, dynamic, deformed, pose): return {}  # Standard differentiable rasterizer [G]
def compute_loss(rendered, frame): return np.mean((rendered - frame) ** 2)
def apply_weighted_update(params, weights, lr):
    for p, w in zip(params, weights):
        p -= lr * w * p.grad
```

**Parameters:**
*   `segment_length`: The duration of each GoF. Not given in the sources. [S1]
*   `num_epochs`: Number of training epochs per GoF. Not given in the sources. [S1]
*   `tuning_weights`: Weights for MLP parameters. Not given in the sources. [S1]

**Edge Cases and Pitfalls:**
*   **Motion Drift:** If GoFs are too long, the deformation field may still suffer from long-range temporal dependencies and motion drift [S1].
*   **Static Region Corruption:** If static regions are not preserved during GoF-specific fine-tuning, geometric inconsistencies may arise across GoF boundaries [S1].
*   **Foreground/Background Boundary:** Errors in segmentation may lead to incorrect deformation of static background elements or lack of deformation for dynamic foreground elements [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [S1]
*   **Memory Complexity:** Not given in the sources. [S1]
*   **Strengths:** Prevents long-range temporal drift; handles complex motion variations better than global fields; reduces training complexity via foreground/background separation; enables efficient streaming by transmitting only dynamic foreground [S1].
*   **Limitations:** Requires accurate temporal segmentation and foreground/background separation; may introduce discontinuities at GoF boundaries if not handled carefully [S1].
*   **When to Use:** Dynamic video scenes with significant motion, especially where long-sequence modeling fails; scenarios requiring efficient streaming of dynamic content [S1].
*   **When Not to Use:** Static scenes; scenes with very short, simple motions where global optimization suffices; scenes where foreground/background separation is ambiguous [S1].

## Background
This method was proposed to address limitations in capturing long-range temporal dependencies in 3DGS video, which often cause motion drift and geometric inconsistencies [S1]. It builds on the idea of using deformation fields to model dynamic scenes but introduces temporal segmentation to limit the motion degree within each segment [S1]. The approach is detailed in "Adaptive 3-D Gaussian Splatting Video Streaming" [S1].
