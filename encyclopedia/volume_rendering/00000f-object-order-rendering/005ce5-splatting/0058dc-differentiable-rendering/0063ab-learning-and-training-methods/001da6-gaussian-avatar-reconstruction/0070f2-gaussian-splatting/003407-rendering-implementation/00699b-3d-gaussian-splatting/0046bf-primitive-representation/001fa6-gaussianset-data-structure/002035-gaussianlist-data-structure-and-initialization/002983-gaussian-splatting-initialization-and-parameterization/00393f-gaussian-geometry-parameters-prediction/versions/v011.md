# Gaussian Geometry Parameters Prediction

Also called: EVolSplat, Efficient Volume-based Gaussian Splatting, GRM, Gaussian MLP Heads, Gaussian Representation Model

## Overview
Gaussian Geometry Parameters Prediction is a feed-forward method that predicts the geometric attributes (position, opacity, covariance) of 3D Gaussians from a global volumetric feature representation, rather than regressing them per-pixel from local 2D features [S2]. It solves the problem of multi-view inconsistencies and ghosting artifacts common in pixel-aligned 3DGS methods by accumulating depth information into a unified 3D volume and refining primitive locations via learned offsets [S2]. Unlike standard initialization which sets static parameters, this method uses an iterative refinement loop to converge Gaussian centers to accurate surface locations before decoding appearance [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ sparse input images $\{I_n\}_{n=1}^N$ with known camera poses (intrinsic matrices $\{K_n\}$ and extrinsic matrices $\{T_n = R_n | t_n\}$).
*   **Outputs:** A set of 3D Gaussians $\mathcal{G} = \{(\mu_i, \alpha_i, \Sigma_i, c_i)\}_{i=1}^{N_p}$, where $\mu_i$ is the mean, $\alpha_i$ is opacity, $\Sigma_i$ is the covariance matrix, and $c_i$ is the view-dependent color.

**Data Structures:**
1.  **Global Point Cloud ($P$):** A set of 3D points in world coordinates, $P \in \mathbb{R}^{N_p \times 3}$, derived from unprojected depth maps.
2.  **Feature Volume ($F$):** A sparse 3D tensor $F \in \mathbb{R}^{H \times W \times D \times C}$ extracted by a sparse 3D CNN, aligned with the world coordinate system.
3.  **MLP Heads:** Three independent Multi-Layer Perceptrons:
    *   $\mathcal{D}_{pos}$: Predicts position offset.
    *   $\mathcal{D}_{opa}$: Predicts opacity.
    *   $\mathcal{D}_{cov}$: Predicts covariance matrix parameters.

**Numbered Steps:**

1.  **Depth Estimation and Filtering:**
    *   Use an off-the-shelf metric depth estimator to predict depth maps $\{D_n\}_{n=1}^N$ for each input image.
    *   Apply a depth consistency check to remove inconsistent values [S2].
    *   Unproject the RGB images and depth maps into 3D space using the camera matrices to construct a raw global point cloud:
        $$ P = \bigcup_{n=1}^N \pi^{-1}(I_n, D_n, T_n, K_n) $$
        where $\pi^{-1}$ denotes pixel unprojection [S2].
    *   Apply a **uniform filter** to $P$ to delete duplicate primitives while preserving scene structure.
    *   Apply a **statistical filter** to remove floating artifacts (noise) from the processed points [S2].

2.  **Feature Volume Construction:**
    *   Construct a sparse tensor from the filtered point cloud $P$.
    *   Pass the sparse tensor through a sparse 3D Convolutional Network (e.g., sparse U-Net) to extract the feature volume $F$ [S2].

3.  **Initialization:**
    *   Initialize the Gaussian centers using the filtered point cloud: $\mu^{init}_i = p_i \in P$ for each $i \in \{1, \dots, N_p\}$ [S2].

4.  **Geometry Parameters Prediction (Iterative Refinement):**
    *   For each Gaussian $i$, maintain a previous position offset $\Delta \mu^{prev}_i$ (initialized to 0 for the first iteration or inference start) [S2].
    *   **Query Feature:** Compute the feature vector $\mathbf{f}_i$ by querying the feature volume $F$ at the refined position $\mu^{init}_i + \Delta \mu^{prev}_i$ using trilinear interpolation:
        $$ \mathbf{f}_i = F(\mu^{init}_i + \Delta \mu^{prev}_i) $$
    *   **Decode Opacity and Covariance:**
        $$ \alpha_i = \mathcal{D}_{opa}(\mathbf{f}_i) $$
        $$ \Sigma_i = \mathcal{D}_{cov}(\mathbf{f}_i) $$
    *   **Decode Position Offset:**
        $$ \Delta \mu_i = \text{Tanh}(\mathcal{D}_{pos}(\mathbf{f}_i)) \cdot v_{\text{size}} $$
        where $v_{\text{size}}$ is the voxel size of the feature volume grid [S2].
    *   **Update Position:**
        $$ \mu_i = \mu^{init}_i + \Delta \mu_i $$
    *   **Convergence:** During training, $\Delta \mu^{prev}_i$ is updated to the newly predicted $\Delta \mu_i$ for the next iteration. During inference, initialize $\Delta \mu^{prev}_i = 0$ and recursively execute the query and update steps (typically twice) to obtain a converged $\Delta \mu_i$, then use the converged point to query $\alpha_i$ and $\Sigma_i$ [S2].

5.  **Color Prediction (Occlusion-Aware IBR):**
    *   Project the 3D Gaussians to the nearest $K$ reference views to retrieve 2D context, including color windows $\{c_k\}_{k=1}^K$ and visibility maps [S2].
    *   Decode the final color $c_i$ using the retrieved 2D context and the Gaussian's attributes [S2].

6.  **Background Modeling:**
    *   Model distant views and the sky using a generalizable hemisphere Gaussian model. The geometry is fixed, and color is predicted similarly to the foreground volume [S2].

7.  **Rendering:**
    *   Compose foreground and background Gaussians. Render the image using standard alpha blending:
        $$ c = \sum_{i \in G} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
        where $G$ is the set of sorted 3D Gaussians [S2].

def predict_gaussian_geometry(input_images, camera_poses, depth_estimator, sparse_3d_cnn, 
                              d_pos, d_opa, d_cov, voxel_size, num_refine_iters=2):
    """
    Predicts 3D Gaussian geometry parameters from input images using a global volume.
    
    Args:
        input_images: List of N RGB images.
        camera_poses: List of N camera poses (K, R, t).
        depth_estimator: Function to predict metric depth maps.
        sparse_3d_cnn: Sparse 3D CNN to extract feature volume.
        d_pos, d_opa, d_cov: MLP heads for position, opacity, covariance.
        voxel_size: Scaling factor for position offset.
        num_refine_iters: Number of refinement iterations for inference.
        
    Returns:
        Gaussians: List of dicts with keys 'mu', 'alpha', 'Sigma', 'color'.
    """
    # 1. Depth Estimation and Point Cloud Construction
    depth_maps = [depth_estimator(img) for img in input_images]
    
    # Unproject to 3D
    raw_points = []
    for img, depth, (K, R, t) in zip(input_images, depth_maps, camera_poses):
        # Unprojection logic: map pixel coordinates to 3D using depth and camera params
        points_3d = unproject_image(img, depth, K, R, t)
        raw_points.append(points_3d)
    
    P = concatenate(raw_points) # Shape: (N_p, 3)
    
    # 2. Filtering
    P = uniform_filter(P) # Remove duplicates
    P = statistical_filter(P) # Remove floaters
    
    # 3. Feature Volume Construction
    sparse_tensor = build_sparse_tensor(P)
    F = sparse_3d_cnn(sparse_tensor) # Feature volume aligned with world coords
    
    # 4. Initialization
    mu_init = P # mu_init_i = p_i
    N_p = len(mu_init)
    
    # Initialize offsets
    delta_mu_prev = np.zeros((N_p, 3))
    
    # 5. Iterative Refinement
    for iteration in range(num_refine_iters):
        mu_refined = mu_init + delta_mu_prev
        
        # Query features using trilinear interpolation
        # F is a sparse tensor or grid; query returns feature vector f_i for each point
        features = query_volume(F, mu_refined) # Shape: (N_p, C)
        
        # Decode parameters
        # d_pos, d_opa, d_cov are MLPs taking feature vector as input
        delta_mu_raw = d_pos(features)
        alpha = d_opa(features)
        Sigma = d_cov(features)
        
        # Apply Tanh and scale for position offset
        delta_mu = np.tanh(delta_mu_raw) * voxel_size
        
        # Update positions
        mu = mu_init + delta_mu
        
        # Prepare for next iteration (or final output)
        delta_mu_prev = delta_mu
        
    # 6. Final Query for Opacity and Covariance (if not done in loop)
    # In inference, we use the converged mu to query alpha and Sigma
    final_features = query_volume(F, mu)
    alpha = d_opa(final_features)
    Sigma = d_cov(final_features)
    
    # 7. Color Prediction (Simplified)
    # Retrieve 2D context from nearest reference views
    colors = predict_color_from_context(mu, alpha, Sigma, input_images, camera_poses)
    
    # 8. Background Hemisphere (Simplified)
    # Add background Gaussians with fixed geometry and predicted color
    
    return [{'mu': mu[i], 'alpha': alpha[i], 'Sigma': Sigma[i], 'color': colors[i]} for i in range(N_p)]

def unproject_image(image, depth, K, R, t):
    """
    Unprojects a 2D image and depth map to 3D points.
    """
    H, W = image.shape[:2]
    # Get pixel coordinates
    y, x = np.meshgrid(np.arange(H), np.arange(W), indexing='ij')
    # Homogeneous coordinates
    xy1 = np.stack([x, y, np.ones_like(x)], axis=-1) # (H, W, 3)
    # Intrinsic inverse
    K_inv = np.linalg.inv(K)
    # Ray directions in camera frame
    rays_cam = (K_inv @ xy1.reshape(-1, 3).T).T # (H*W, 3)
    rays_cam = rays_cam / np.linalg.norm(rays_cam, axis=1, keepdims=True)
    
    # Apply rotation and translation to get world rays
    rays_world = (R @ rays_cam.T).T
    origins_world = -(R @ t.reshape(3, 1)).T
    
    # Flatten depth
    depth_flat = depth.flatten()
    
    # 3D points
    points_3d = origins_world + rays_world * depth_flat[:, np.newaxis]
    return points_3d.reshape(H, W, 3)

*   $N$: Number of input images [S2].
*   $N_p$: Number of primitives in the global point cloud [S2].
*   $v_{\text{size}}$: Voxel size used to scale the position offset output of the Tanh activation [S2].

**Edge Cases and Pitfalls:**
*   **Ghosting Artifacts:** Pixel-aligned methods generate redundant and inconsistent primitives in overlapping regions. This method addresses this by using a global volume and filtering duplicates [S2].
*   **Depth Noise:** Monocular depth predictions contain noise and floating artifacts. This method handles this by applying a statistical filter to remove floaters after uniform filtering [S2].
*   **Convergence:** The recursive formulation of $\Delta \mu_i$ requires convergence. Empirically, two iterations are sufficient during inference [S2].

### GSGEN
A method introducing 3D SDS loss based on Point-E to mitigate the multi-face or Janus problem in text-to-3D generation. It adopts Point-E to initialize the point cloud as the initial geometry for optimization and refines the appearance with only the 2D image prior [S1].

### BrightDreamer
A method predicting the deviation of a set of fixed anchor points to determine the centers of Gaussians [S1].

### NeRF-Guided 3D Gaussian Splatting
Uses a pretrained NeRF as a teacher to guide feature distillation, improving alignment between geometry and semantics [S3, unofficial].

### Defocus Blur Modeling
Models optical defocus by adjusting the scale $s$ of 3D Gaussians based on their distance from the camera's focal plane. During training, larger scale values are used to rasterize blurred images; during testing, smaller scale values render sharp details. Unlike naive Gaussian blur, this selectively enlarges covariances only for Gaussians corresponding to blurred regions [S4].

### GauS (Gaussian Splatting Surface Reconstruction)
A render-then-fuse approach for high-fidelity mesh reconstruction from 3DGS inputs without fine-tuning. It uses volumetric fusion to convert 3D Gaussians into textured triangle meshes, serving as a plug-and-play module [S5, unofficial].

### Hybrid Scene Representation (Foreground/Background)
A scene representation comprising Gaussian foreground models and background models. The background models support diverse backends like environment maps, textured meshes, and neural representations. Specifically, sky background is built using spherical environment maps composed of Gaussians to reduce artifacts in unbounded outdoor scenes [S5, unofficial].

### Barycentric Splat Parameterization
A method to constrain 2D Gaussian Splat centers to lie on triangular mesh faces using barycentric coordinates. For a mesh face with vertices $v_1, v_2, v_3$, the splat center $m$ is computed as $m = u \cdot v_1 + w \cdot v_2 + (1 - u - w) \cdot v_3$, where $u, w \in [0, 1]$ and $u + w \le 1$ are barycentric coordinates [S6].

### In-Plane Rotation for Splats
A parameterization for the orientation of Gaussian Splats on the face plane using an in-plane rotation parameter $R_{2d}$. The final rotation matrix is $R = R_s \cdot R_{2d}$, where $R_s$ is the rotation matrix of the triangle faces [S6].

## Operating characteristics
*   **Time Complexity:** Feed-forward inference is significantly faster than iterative optimization-based 3DGS. The complexity is dominated by the sparse 3D CNN and MLP heads, which operate on the downsampled point cloud $N_p$ rather than the full pixel count [S2].
*   **Memory Complexity:** Uses a global volumetric feature representation, which scales with the scene volume rather than the number of pixels. Downsampling initial primitives reduces computation and memory compared to pixel-aligned methods [S2].
*   **Measured Performance:** EVolSplat achieves real-time rendering speeds for urban scenes. It improves global consistency and reduces ghosting artifacts compared to pixel-aligned methods like MVSplat, Flash3D, and DrivingForward [S2].
*   **Strengths:** Global consistency, reduced ghosting, efficient feed-forward inference, handles large-scale urban scenes with sparse inputs.
*   **Limitations:** Relies on the quality of monocular depth estimators; may lose high-frequency appearance details if primitives are downsampled too aggressively (mitigated by IBR-based color prediction) [S2].
*   **When to use:** Urban scene reconstruction, autonomous driving applications, large-scale scenes with sparse views where global consistency is critical.
*   **When not to use:** Small-scale scenes with dense views where iterative optimization might yield higher fidelity, or scenes with extreme textureless regions where depth estimation fails.

## Background
Gaussian Geometry Parameters Prediction, specifically as implemented in EVolSplat, was introduced by Sheng Miao, Jiaxin Huang, et al. in 2025 [S2]. It addresses the limitations of existing feed-forward 3DGS methods that suffer from multi-view inconsistencies and duplicated content due to per-pixel prediction. By predicting 3D Gaussians across multiple frames within a unified volume using a 3D convolutional network, it improves global consistency and reduces ghosting artifacts [S2].
