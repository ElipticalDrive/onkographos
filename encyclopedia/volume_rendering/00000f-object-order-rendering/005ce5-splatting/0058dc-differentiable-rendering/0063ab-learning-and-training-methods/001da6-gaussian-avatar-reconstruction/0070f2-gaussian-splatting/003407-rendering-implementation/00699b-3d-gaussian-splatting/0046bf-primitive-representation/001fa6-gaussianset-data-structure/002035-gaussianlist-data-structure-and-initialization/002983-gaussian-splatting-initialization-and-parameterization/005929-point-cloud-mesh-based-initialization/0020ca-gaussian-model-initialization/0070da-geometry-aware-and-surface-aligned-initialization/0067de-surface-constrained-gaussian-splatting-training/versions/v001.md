# Surface-Constrained Gaussian Splatting Training

Also called: surface splat training

## Overview
Surface-Constrained Gaussian Splatting Training is a method for initializing and optimizing 3D Gaussian splats from mesh surfaces or point clouds, enforcing geometric fidelity through surface constraints during training [S1, unofficial]. It differs from standard Gaussian Splatting by anchoring splats to known geometry and applying losses for depth, normal, and flatness consistency, making it suitable for high-fidelity avatar reconstruction where surface accuracy is critical [S1, unofficial].

## How it works
**Inputs:**
- `mesh_data`: Optional mesh with vertices, faces, and vertex colors.
- `point_cloud`: Optional point cloud with positions and colors.
- `colmap_dir`: Path to COLMAP dataset images and camera parameters.
- `iterations`: Total training steps (default: 3000) [S1, unofficial].
- `n_samples`: Number of points to sample/subsample (default: 50000) [S1, unofficial].
- `max_resolution`: Maximum resolution for image loading [S1, unofficial].
- `strategy_name`: Spawning/pruning strategy ('simple', 'mcmc', 'absgrad', 'mrnf', 'adaptive') (default: 'simple') [S1, unofficial].
- `target_splats`: Target splat count for MCMC (default: 0, uses cap 500000) [S1, unofficial].
- `multi_view`: Use multiple views per step (default: False) [S1, unofficial].
- `multi_view_count`: Views per step if `multi_view` is True (default: 2) [S1, unofficial].
- `CROP`: Random crop size (default: 0) [S1, unofficial].

**Outputs:**
- Optimized Gaussian splats (means, quaternions, scales, opacities, spherical harmonics coefficients).

**Data Structures:**
- `splats`: Dictionary or object containing:
  - `means`: Tensor of shape `(N, 3)`, 3D positions.
  - `quats`: Tensor of shape `(N, 4)`, unit quaternions for rotation.
  - `scales`: Tensor of shape `(N, 3)`, log-scale values.
  - `opacities`: Tensor of shape `(N, 1)`, pre-sigmoid opacity values.
  - `sh_coeffs`: Tensor of shape `(N, K, 3)`, spherical harmonics coefficients (K depends on degree).
- `anchor_pts`: Tensor of shape `(M, 3)`, initial mesh vertices or subsampled points.
- `splat_normals`: Tensor of shape `(N, 3)`, estimated surface normals for each splat.
- `cloud_pts_full`, `cloud_normals_full`, `cloud_colors_full`: Arrays for reservoir management during spawning.

**Parameters:**
- `anchor_weight_start`: Initial anchor loss weight (default: 0.1) [S1, unofficial].
- `anchor_weight_end`: Final anchor loss weight (default: 0.001) [S1, unofficial].
- `depth_lambda`: Depth loss weight (default: 0.5) [S1, unofficial].
- `aniso_lambda`: Anisotropy loss weight (default: 0.0) [S1, unofficial].
- `flatness_lambda`: Flatness loss weight (default: 0.01) [S1, unofficial].
- `normal_lambda`: Normal loss weight (default: 0.05) [S1, unofficial].
- `opacity_decay`: Opacity decay rate (default: 0.001) [S1, unofficial].
- `prune_threshold`: Minimum opacity for pruning (default: 0.002) [S1, unofficial].
- `max_scale`: Maximum allowed scale for splats (default: 2.0) [S1, unofficial].
- `coverage_lambda`: Coverage loss weight (default: 0.5) [S1, unofficial].
- `smooth_strength`: Smoothing strength (default: 0.0) [S1, unofficial].

**Steps:**

1. **Initialization:**
   - If `mesh_data` is provided:
     - Sample `n_samples` points from the mesh surface: `points, normals, scolors = sample_mesh_surface(verts, faces, colors_mesh, n_samples)` [S1, unofficial].
     - Set `anchor_pts = verts` (all mesh vertices) [S1, unofficial].
   - If `point_cloud` is provided:
     - If `len(cloud_pts) > n_samples`, subsample using random choice; else use all points [S1, unofficial].
     - Estimate normals using KNN (k=8): For each point, compute centered neighbors, perform SVD, take the smallest singular vector as the normal [S1, unofficial].
     - Normalize normals: `normals /= (np.linalg.norm(normals, axis=-1, keepdims=True) + 1e-8)` [S1, unofficial].
     - Set `anchor_pts = points` [S1, unofficial].
   - Build an anchor KD-tree: `anchor_tree = cKDTree(anchor_pts)` [S1, unofficial].
   - Load COLMAP dataset: `images, _, _ = load_colmap_dataset(colmap_dir, max_resolution=max_resolution)` [S1, unofficial].
   - Compute scene scale: `scene_scale = float(np.median(pdist(cam_centers)))` if `len(cam_centers) > 1` else `1.0` [S1, unofficial].
   - Compute depth priors: Render depth maps from all points (`anchor_pts + points`) for each image [S1, unofficial].
   - Initialize splats: `splats = init_surface_splats(points, normals, scolors, device)` [S1, unofficial].
   - Create optimizers: `optimizers = create_optimizers(splats, scene_scale)` [S1, unofficial].
   - Compute max allowed scale: `init_knn = knn_distances(points, k=3)`; `max_scale_abs = float(np.median(init_knn) * 3.0)` [S1, unofficial].
   - Store per-splat surface normals: `splat_normals = torch.from_numpy(normals / norm(normals))` [S1, unofficial].
   - Set up means scheduler: `means_scheduler = optim.lr_scheduler.ExponentialLR(optimizers['means'], gamma=0.01 ** (1.0 / iterations))` [S1, unofficial].
   - Initialize cloud reservoir: `cloud_pts_full = points.copy()`, `cloud_normals_full = n_norm.copy()`, `cloud_colors_full = scolors.copy()` [S1, unofficial].
   - Setup strategy based on `strategy_name`:
     - 'mcmc': Use `MCMCStrategy` with `cap_max`, `noise_lr`, refine intervals [S1, unofficial].
     - 'absgrad': Use `DefaultStrategy` with `absgrad=True`, `grow_grad2d=0.0008`, `grow_scale3d=0.01`, `prune_opa`, refine intervals, `reset_every` [S1, unofficial].
     - 'mrnf', 'adaptive', 'simple': Print strategy name (details not specified) [S1, unofficial].
   - Prepare image tensors: Convert `img['pixels']`, `img['K']`, `img['w2c']` to torch tensors on device [S1, unofficial].
   - Yield initial state with splat means, colors, scales [S1, unofficial].

2. **Training Loop (for each step `step` from 0 to `iterations-1`):**
   - Compute anchor weight decay: `anchor_w = anchor_weight_start + (anchor_weight_end - anchor_weight_start) * (step / max(iterations - 1, 1))` [S1, unofficial].
   - Extract splat parameters:
     - `means = splats['means']`
     - `quats = splats['quats']`
     - `scales = exp(splats['scales'])`
     - `opacities = sigmoid(splats['opacities'])`
   - Clamp scales: `splats['scales'].data.clamp_(min=-10.0, max=math.log(max_scale_abs))` [S1, unofficial].
   - For each selected view:
     - Handle random cropping if `not multi_view` and `CROP > 0` and `step % 50 != 0` [S1, unofficial].
     - Render Gaussians using `gsplat` if available, passing `sh_coeffs`, `viewmat`, `K`, `W`, `H`, `bg_color`, `sh_degree`, `absgrad`, `return_meta` [S1, unofficial].
     - If using `gsplat` strategy and `need_meta`, extract `view_info` from first view result [S1, unofficial].
   - Compute losses:
     - Anchor loss (weight `anchor_w`) [S1, unofficial].
     - Depth loss (weight `depth_lambda`) [S1, unofficial].
     - Anisotropy loss (weight `aniso_lambda`) [S1, unofficial].
     - Flatness loss (weight `flatness_lambda`) [S1, unofficial].
     - Normal loss (weight `normal_lambda`) [S1, unofficial].
     - Coverage loss (weight `coverage_lambda`) [S1, unofficial].
   - Apply opacity decay: Reduce opacity values by `opacity_decay` [S1, unofficial].
   - Prune splats with opacity below `prune_threshold` [S1, unofficial].
   - Spawn new splats based on strategy (e.g., MCMC, absgrad) [S1, unofficial].
   - Update optimizers [S1, unofficial].
   - Step scheduler: `means_scheduler.step()` [S1, unofficial].

import torch
import numpy as np
from scipy.spatial import cKDTree
from scipy.spatial.distance import pdist
import math

def surface_constrained_training(
    mesh_data=None,
    point_cloud=None,
    colmap_dir=None,
    iterations=3000,
    n_samples=50000,
    max_resolution=1024,
    strategy_name='simple',
    target_splats=0,
    multi_view=False,
    multi_view_count=2,
    CROP=0,
    anchor_weight_start=0.1,
    anchor_weight_end=0.001,
    depth_lambda=0.5,
    aniso_lambda=0.0,
    flatness_lambda=0.01,
    normal_lambda=0.05,
    opacity_decay=0.001,
    prune_threshold=0.002,
    max_scale=2.0,
    coverage_lambda=0.5,
    smooth_strength=0.0
):
    # 1. Initialization
    if mesh_data is not None:
        verts, faces, colors_mesh = mesh_data
        points, normals, scolors = sample_mesh_surface(verts, faces, colors_mesh, n_samples)
        anchor_pts = verts
    elif point_cloud is not None:
        cloud_pts, cloud_colors = point_cloud
        if len(cloud_pts) > n_samples:
            indices = np.random.choice(len(cloud_pts), n_samples, replace=False)
            points = cloud_pts[indices]
            scolors = cloud_colors[indices]
        else:
            points = cloud_pts
            scolors = cloud_colors
        # Estimate normals using KNN
        anchor_tree = cKDTree(points)
        dists, idxs = anchor_tree.query(points, k=8)
        neighbors = points[idxs]
        centered_neighbors = neighbors - points[:, np.newaxis, :]
        normals = np.zeros_like(points)
        for i in range(len(points)):
            cov = np.cov(centered_neighbors[i].T)
            eigvals, eigvecs = np.linalg.eigh(cov)
            normals[i] = eigvecs[:, np.argmin(eigvals)]
        # Normalize normals
        norms = np.linalg.norm(normals, axis=-1, keepdims=True) + 1e-8
        normals = normals / norms
        anchor_pts = points
    else:
        raise ValueError("Either mesh_data or point_cloud must be provided")

    # Build anchor KD-tree
    anchor_tree = cKDTree(anchor_pts)

    # Load COLMAP dataset
    images, cam_centers, _ = load_colmap_dataset(colmap_dir, max_resolution=max_resolution)

    # Compute scene scale
    if len(cam_centers) > 1:
        scene_scale = float(np.median(pdist(cam_centers)))
    else:
        scene_scale = 1.0

    # Compute depth priors
    depth_priors = render_depth_maps(anchor_pts, images)

    # Initialize splats
    splats = init_surface_splats(points, normals, scolors, device='cuda')

    # Create optimizers
    optimizers = create_optimizers(splats, scene_scale)

    # Compute max allowed scale
    init_knn = knn_distances(points, k=3)
    max_scale_abs = float(np.median(init_knn) * 3.0)

    # Store per-splat surface normals
    splat_normals = torch.from_numpy(normals / np.linalg.norm(normals, axis=-1, keepdims=True) + 1e-8).cuda()

    # Set up means scheduler
    means_scheduler = torch.optim.lr_scheduler.ExponentialLR(optimizers['means'], gamma=0.01 ** (1.0 / iterations))

    # Initialize cloud reservoir
    cloud_pts_full = points.copy()
    cloud_normals_full = normals.copy()
    cloud_colors_full = scolors.copy()

    # Setup strategy
    if strategy_name == 'mcmc':
        strategy = MCMCStrategy(cap_max=500000 if target_splats == 0 else target_splats, noise_lr=0.01, refine_intervals=[1000, 2000])
    elif strategy_name == 'absgrad':
        strategy = DefaultStrategy(absgrad=True, grow_grad2d=0.0008, grow_scale3d=0.01, prune_opa=prune_threshold, refine_intervals=[1000, 2000], reset_every=1000)
    else:
        print(f"Strategy {strategy_name} not fully implemented")
        strategy = SimpleStrategy()

    # Prepare image tensors
    image_tensors = []
    for img in images:
        pixels_t = torch.from_numpy(img['pixels']).float().cuda()
        K_t = torch.from_numpy(img['K']).float().cuda()
        w2c_t = torch.from_numpy(img['w2c']).float().cuda()
        image_tensors.append({'pixels_t': pixels_t, 'K_t': K_t, 'w2c_t': w2c_t})

    # Yield initial state
    yield splats['means'], splats['colors'], splats['scales']

    # Training Loop
    for step in range(iterations):
        # Compute anchor weight decay
        anchor_w = anchor_weight_start + (anchor_weight_end - anchor_weight_start) * (step / max(iterations - 1, 1))

        # Extract splat parameters
        means = splats['means']
        quats = splats['quats']
        scales = torch.exp(splats['scales'])
        opacities = torch.sigmoid(splats['opacities'])

        # Clamp scales
        splats['scales'].data.clamp_(min=-10.0, max=math.log(max_scale_abs))

        # Select views
        if multi_view:
            view_indices = np.random.choice(len(image_tensors), multi_view_count, replace=False)
        else:
            view_indices = [np.random.randint(len(image_tensors))]

        total_loss = 0.0
        for idx in view_indices:
            img = image_tensors[idx]
            # Handle random cropping
            if not multi_view and CROP > 0 and step % 50 != 0:
                # Crop logic here [G]
                pass

            # Render Gaussians
            rendered_img, meta = render_gaussians(
                splats['sh_coeffs'],
                img['w2c_t'],
                img['K_t'],
                img['pixels_t'].shape[1],
                img['pixels_t'].shape[0],
                bg_color=torch.tensor([0.0, 0.0, 0.0]).cuda(),
                sh_degree=2,
                absgrad=True,
                return_meta=True
            )

            # Extract view_info if needed
            if strategy_name == 'absgrad' and meta is not None:
                view_info = meta[0]

            # Compute losses
            # Anchor loss
            anchor_loss = compute_anchor_loss(means, anchor_tree, anchor_w)
            total_loss += anchor_loss

            # Depth loss
            depth_loss = compute_depth_loss(rendered_img, depth_priors[idx], depth_lambda)
            total_loss += depth_loss

            # Anisotropy loss
            aniso_loss = compute_anisotropy_loss(scales, aniso_lambda)
            total_loss += aniso_loss

            # Flatness loss
            flatness_loss = compute_flatness_loss(means, splat_normals, flatness_lambda)
            total_loss += flatness_loss

            # Normal loss
            normal_loss = compute_normal_loss(means, splat_normals, normal_lambda)
            total_loss += normal_loss

            # Coverage loss
            coverage_loss = compute_coverage_loss(rendered_img, coverage_lambda)
            total_loss += coverage_loss

        # Apply opacity decay
        splats['opacities'].data -= opacity_decay

        # Prune splats
        prune_mask = torch.sigmoid(splats['opacities']).squeeze(-1) > prune_threshold
        splats = prune_splats(splats, prune_mask)

        # Spawn new splats
        splats = strategy.spawn_splats(splats, view_info if 'view_info' in locals() else None)

        # Update optimizers
        total_loss.backward()
        for opt in optimizers.values():
            opt.step()
            opt.zero_grad()

        # Step scheduler
        means_scheduler.step()

        # Yield state periodically or at end
        if step % 100 == 0:
            yield splats['means'], splats['colors'], splats['scales']

    return splats

**Edge Cases and Pitfalls:**
- Precision: Use `float32` for most operations, but consider `float64` for SVD if normals are unstable [G].
- Boundaries: Clamp scales to prevent numerical instability (`min=-10.0`, `max=math.log(max_scale_abs)`) [S1, unofficial].
- Degenerate Input: If `len(cam_centers) <= 1`, set `scene_scale = 1.0` to avoid division by zero or undefined behavior [S1, unofficial].
- Normal Estimation: If KNN returns fewer than `k` neighbors (e.g., at boundaries), handle gracefully [G].

## Operating characteristics
- **Time Complexity:** O(N * I * V), where N is the number of splats, I is the number of iterations, and V is the number of views per step [S1, unofficial].
- **Memory Complexity:** O(N + M), where N is the number of splats and M is the number of anchor points [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of splats and views [S1, unofficial].
- **Strengths:** High geometric fidelity, suitable for avatar reconstruction [S1, unofficial].
- **Limitations:** Requires mesh or point cloud input, may be slower than standard Gaussian Splatting due to additional losses [S1, unofficial].
- **When to Use:** When surface accuracy is critical, e.g., avatar reconstruction [S1, unofficial].
- **When Not to Use:** When only images are available, or when speed is more important than geometric accuracy [S1, unofficial].
