# QuantumGS

Also called: Quantum 3D Gaussian Splatting

## Overview
QuantumGS is a hybrid quantum-classical framework that integrates Variational Quantum Circuits (VQCs) into the 3D Gaussian Splatting pipeline to capture high-frequency view-dependent effects, such as sharp reflections and transparency, which classical Multi-Layer Perceptrons (MLPs) struggle to model efficiently in low-parameter regimes [S1]. It distinguishes itself from standard view-dependent splatting by mapping viewing directions directly onto the Bloch sphere, leveraging the natural geometry of qubits to represent 3D directional data and achieving higher expressivity through quantum entanglement [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D Gaussian primitive with base color (encoded via Spherical Harmonics), opacity, position, covariance, and a normalized viewing direction vector $\mathbf{d} = [d_x, d_y, d_z]$ [S1].
*   **Output:** Refined color $c' = c + \Delta c(\mathbf{d})$ and opacity $\alpha' = \alpha + \Delta \alpha(\mathbf{d})$, where $\Delta c$ and $\Delta \alpha$ are view-dependent corrections derived from the quantum processing [S1].

**Data Structures:**
*   **Viewing Direction:** Normalized 3D vector $\mathbf{d} \in \mathbb{R}^3$ with $\|\mathbf{d}\| = 1$ [S1].
*   **Quantum State:** A 3-qubit state $|\psi\rangle \in \mathbb{C}^8$, represented as a superposition of basis states $|000\rangle$ to $|111\rangle$ [S1].
*   **VQC Parameters:** A set of rotation angles $\theta = \{\theta_{j,\ell}, \phi_{j,\ell}\}$ for $j \in \{0,1,2\}$ (qubits) and $\ell \in \{1,\dots,L\}$ (layers) [S1].
*   **Feature Vector:** A 3D vector $\mathbf{v}_{\text{quantum}} = (\langle Z_0 \rangle, \langle Z_1 \rangle, \langle Z_2 \rangle)$ where each component is in $[-1, 1]$ [S1].

**Numbered Steps:**

1.  **Directional Encoding:** Encode the normalized viewing direction $\mathbf{d}$ into a 3-qubit initial state $|\psi_{\text{enc}}\rangle$ by mapping the spherical coordinates of $\mathbf{d}$ to the Bloch sphere of each qubit [S1].
    *   Calculate polar angle $\theta = \arccos(d_z)$ and azimuthal angle $\phi = \operatorname{atan2}(d_y, d_x)$ [S1].
    *   Apply rotation gates to each qubit $j \in \{0, 1, 2\}$ initialized to $|0\rangle$:
        $$ |\psi_{\text{enc}}\rangle = \bigotimes_{j=0}^{2} R_z^{(j)}(\phi) R_y^{(j)}(\theta) |0\rangle^{\otimes 3} $$
    *   Here, $R_y(\theta) = \exp(-i \frac{\theta}{2} Y)$ and $R_z(\phi) = \exp(-i \frac{\phi}{2} Z)$, where $Y$ and $Z$ are Pauli matrices [S1]. This creates a diffeomorphic mapping that preserves the manifold structure of $S^2$ [S1].

2.  **Variational Quantum Circuit Processing:** Process $|\psi_{\text{enc}}\rangle$ through a VQC ansatz $U(\theta; L)$ consisting of $L=4$ layers [S1]. The full transformation is:
    $$ |\psi_{\text{out}}\rangle = U(\theta; L)|\psi_{\text{enc}}\rangle = U^{(L)}(\theta_L) \cdots U^{(1)}(\theta_1)|\psi_{\text{enc}}\rangle $$
    where each layer $U^{(\ell)}(\theta_\ell)$ is defined as:
    $$ U^{(\ell)}(\theta_\ell) = U_{\text{ent}}^{(\ell)} \bigotimes_{j=0}^{2} R_j(\theta_{j,\ell}, \phi_{j,\ell}) $$
    *   **Single-Qubit Rotations:** For each qubit $j$ and layer $\ell$, apply trainable rotations $R_j(\theta_{j,\ell}, \phi_{j,\ell})$ [S1]. These angles are learned parameters (generated by a hypernetwork in Pipeline I or shared in Pipeline II) that define how the viewing direction transforms [S1].
    *   **Circular Entanglement:** Apply a cyclic CNOT sequence to entangle all three qubits, creating correlations between color channels and opacity:
        $$ U_{\text{ent}} = \text{CNOT}_{0\to1} \text{CNOT}_{1\to2} \text{CNOT}_{2\to0} $$
        This ring topology ensures view-dependent effects emerge from the joint quantum state [S1].

3.  **Measurement:** Perform computational basis measurements of the output state $|\psi_{\text{out}}\rangle$ in the Z-basis [S1].
    *   Compute the expectation values $\langle Z_j \rangle$ for each qubit $j \in \{0, 1, 2\}$ [S1].
    *   Form the 3D quantum feature vector $\mathbf{v}_{\text{quantum}} = (\langle Z_0 \rangle, \langle Z_1 \rangle, \langle Z_2 \rangle) \in [-1, 1]^3$ [S1].

4.  **Classical Refinement:** Feed $\mathbf{v}_{\text{quantum}}$ into a lightweight classical Multi-Layer Perceptron (MLP) [S1].
    *   The MLP outputs view-dependent refinements $\Delta c(\mathbf{d})$ and $\Delta \alpha(\mathbf{d})$ [S1].
    *   Update the Gaussian attributes: $c' = c + \Delta c(\mathbf{d})$ and $\alpha' = \alpha + \Delta \alpha(\mathbf{d})$ [S1].

**Dual-Pipeline Framework:**
*   **Pipeline I (Per-Gaussian):** A hypernetwork generates unique VQC parameters (rotation angles) for each Gaussian, maximizing local expressivity [S1].
*   **Pipeline II (Global):** A shared VQC with hash-conditioned global parameters processes spatial and directional hash features to scale to real-world scenes [S1].

**Pseudocode:**

```python
import numpy as np

def encode_viewing_direction(d):
    """Encodes a normalized viewing direction d into a 3-qubit state."""
    dz, dx, dy = d[2], d[0], d[1]
    theta = np.arccos(np.clip(dz, -1.0, 1.0))
    phi = np.arctan2(dy, dx)
    cos_t2, sin_t2 = np.cos(theta / 2), np.sin(theta / 2)
    alpha = np.exp(-1j * phi / 2) * cos_t2
    beta = np.exp(1j * phi / 2) * sin_t2
    single_qubit_state = np.array([alpha, beta])
    return np.kron(np.kron(single_qubit_state, single_qubit_state), single_qubit_state)

def apply_vqc_layer(psi, angles):
    """Applies one layer of the VQC: single-qubit rotations followed by circular entanglement."""
    I = np.eye(2)
    ops = []
    for j in range(3):
        theta, phi = angles[j]
        cos_t2, sin_t2 = np.cos(theta / 2), np.sin(theta / 2)
        R_y = np.array([[cos_t2, -sin_t2], [sin_t2, cos_t2]])
        R_z = np.array([[np.exp(-1j * phi / 2), 0], [0, np.exp(1j * phi / 2)]])
        R_j = R_z @ R_y
        if j == 0: Op = np.kron(np.kron(R_j, I), I)
        elif j == 1: Op = np.kron(np.kron(I, R_j), I)
        else: Op = np.kron(np.kron(I, I), R_j)
        ops.append(Op)
    for Op in ops: psi = Op @ psi
    
    # Circular Entanglement: CNOT_0->1 CNOT_1->2 CNOT_2->0
    mat = np.zeros((8, 8), dtype=complex)
    for i in range(8):
        q0, q1, q2 = i & 1, (i >> 1) & 1, (i >> 2) & 1
        if q0 == 1: q1 ^= 1
        if q1 == 1: q2 ^= 1
        if q2 == 1: q0 ^= 1
        mat[q2 * 4 + q1 * 2 + q0, i] = 1.0
    return mat @ psi

def measure_quantum_state(psi):
    """Measures the state in the Z-basis and returns expectation values <Z_j>."""
    probs = np.abs(psi)**2
    z0 = np.sum(probs[[0, 2, 4, 6]]) - np.sum(probs[[1, 3, 5, 7]])
    z1 = np.sum(probs[[0, 1, 4, 5]]) - np.sum(probs[[2, 3, 6, 7]])
    z2 = np.sum(probs[[0, 1, 2, 3]]) - np.sum(probs[[4, 5, 6, 7]])
    return np.array([z0, z1, z2])

def quantumgs_forward(d, vqc_params):
    """Full QuantumGS forward pass."""
    psi = encode_viewing_direction(d)
    for layer_angles in vqc_params:
        psi = apply_vqc_layer(psi, layer_angles)
    v_quantum = measure_quantum_state(psi)
    # Lightweight classical MLP (implementation details not provided in sources) [G]
    delta_c = np.tanh(v_quantum)
    delta_alpha = np.tanh(v_quantum)
    return delta_c, delta_alpha
```

## Operating characteristics
*   **Complexity:** The quantum simulation of 3 qubits requires managing an 8-dimensional complex vector space, which is computationally lightweight for classical simulation but represents a high-dimensional feature space relative to the input [S1]. The VQC has $L=4$ layers with 3 qubits, resulting in a manageable number of trainable parameters per Gaussian in Pipeline I or globally in Pipeline II [S1].
*   **Performance:** The method achieves higher expressivity and better generalization for view-dependent effects compared to classical MLPs in low-parameter regimes [S1].
*   **Strengths:** Physically consistent basis for modeling light-surface interactions; captures high-frequency effects like sharp reflections and transparency; scalable via dual-pipeline approach (hypernetwork for local, hash-conditioned for global) [S1].
*   **Limitations:** Requires simulation of quantum circuits or access to quantum hardware [S1].
*   **When to use:** When modeling complex view-dependent appearance (specularities, transparency) with limited parameters is critical, and classical MLPs are insufficient [S1].

## Background
QuantumGS was introduced by Wilczyński et al. in 2026 as a novel hybrid framework integrating Variational Quantum Circuits into the 3D Gaussian Splatting pipeline [S1]. It addresses the limitations of Viewing Direction Gaussian Splatting (VDGS) and classical MLPs in capturing high-frequency view-dependent effects with low parameter counts [S1]. The work builds on the shift from implicit NeRFs to explicit 3DGS and relates to prior quantum graphics research like QKAN-GS, which focused on storage efficiency rather than view-dependent appearance [S1].
