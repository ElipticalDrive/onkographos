# Weighted Floater Removal


## Overview
Weighted Floater Removal (WFR) is an explicit post-processing method to eliminate 3D Gaussian floaters in whole-scene reconstruction by verifying multi-view depth consistency [S1]. Unlike TSDF Fusion, which incurs high computational costs by building voxel volumes and extracting meshes, WFR directly adjusts Gaussian opacities based on accumulated weights, avoiding rendering holes while maintaining geometric accuracy [S1]. It specifically addresses floaters introduced after the current view's processing in the incremental PTF module, which the parent [Advance Floater Pruning](17398-advance-floater-pruning.md) fails to remove [S1].

## How it works
**Inputs and Outputs**
- **Input**: Global 3D Gaussian primitives $\{\mu_g, \alpha_g, \omega_g\}$ obtained after unprojecting and fusing whole-scene input views via the PTF module; predicted depth maps $d_t^l$ for each input view; rendered depth maps $d_t^g$ for the global Gaussians [S1].
- **Output**: Adjusted global Gaussian opacities $\alpha_g$ with floaters suppressed [S1].

**Data Structures**
- **Global Gaussians**: A list or array of primitives, each containing:
  - $\mu_g$: 3D center coordinates $(x, y, z)$ [S1].
  - $\alpha_g$: Opacity scalar [S1].
  - $\omega_g$: Weight scalar (accumulated during PTF) [S1].
- **Depth Maps**: 2D arrays for each input view, indexed by pixel $(u, v)$, containing predicted depth $d_t^l(u,v)$ and rendered depth $d_t^g(u,v)$ [S1].

**Parameters**
- $\delta$: Pre-defined threshold to determine if predicted depth is significantly larger than the rendered depth of the nearest global Gaussian [S1]. Typical value: Not given in the sources.

**Algorithm Steps**
1. **Initialization**: Retrieve the global set of 3D Gaussian primitives $\{\mu_g, \alpha_g, \omega_g\}$ resulting from the PTF module [S1].
2. **Traversal**: Iterate through each input view $t$ in the scene [S1].
3. **Projection**: For the current view $t$, project all global Gaussian centers $\mu_g$ onto the 2D image plane [S1].
4. **Pixel-wise Processing**: For each pixel $i$ (coordinates $u, v$) in the current view:
   a. Define $S'_i$ as the set of 3D Gaussian primitives that project onto pixel $i$ [S1].
   b. Calculate the rendered depth of the nearest global Gaussian primitive in $S'_i$:
      $$ d_{g, \min}(i) = \min_{j \in S'_i} d_t^g(j) $$
      where $d_t^g(j)$ is the rendered depth of Gaussian $j$ [S1].
   c. Identify potential floaters $m'_i$ using the threshold $\delta$ and the predicted depth $d_t^l(i)$:
      $$ m'_i = \begin{cases} \arg \min_{j \in S'_i} d_t^g(j), & \text{if } d_t^l(i) - \min_{j \in S'_i} d_t^g(j) > \delta \\ \emptyset, & \text{otherwise} \end{cases} $$
      If $m'_i$ is not empty, the Gaussian at $m'_i$ is a potential floater because the predicted depth indicates a surface further away than the nearest rendered Gaussian, suggesting noise-induced misalignment [S1].
   d. Calculate the accumulated neighbor weight $\tilde{\omega}_g(m'_i)$ for the identified floater [S1]. This involves summing the weights $\omega_g$ of neighboring Gaussians to adaptively assign higher weights to correct primitives [S1].
   e. Reduce the opacity $\alpha_g$ of the floater $m'_i$ based on $\tilde{\omega}_g(m'_i)$ to eliminate its influence without creating holes [S1].

**Pseudocode**
```python
import math

def weighted_floater_removal(global_gaussians, input_views, delta):
    """
    global_gaussians: List of dicts with keys 'mu' (3D vector), 'alpha' (float), 'omega' (float)
    input_views: List of dicts with keys 'predicted_depth' (2D array), 'rendered_depth' (2D array), 'projection_matrix'
    delta: Float threshold
    """
    # Step 1: Global Gaussians are already provided from PTF

    # Step 2: Traverse input views
    for view in input_views:
        predicted_depth = view['predicted_depth']
        rendered_depth = view['rendered_depth']
        proj_matrix = view['projection_matrix']
        H, W = predicted_depth.shape

        # Step 3: Project global Gaussians to current view
        projected_gaussians = []
        for g in global_gaussians:
            u, v, depth_g = project_3d_to_2d(g['mu'], proj_matrix)
            if u is not None and 0 <= u < W and 0 <= v < H:
                projected_gaussians.append({
                    'index': global_gaussians.index(g),
                    'u': u,
                    'v': v,
                    'depth': depth_g,
                    'omega': g['omega'],
                    'alpha': g['alpha']
                })

        # Group Gaussians by pixel
        pixel_to_gaussians = {}
        for pg in projected_gaussians:
            key = (pg['u'], pg['v'])
            if key not in pixel_to_gaussians:
                pixel_to_gaussians[key] = []
            pixel_to_gaussians[key].append(pg)

        # Step 4: Pixel-wise processing
        for v in range(H):
            for u in range(W):
                d_t = predicted_depth[v, u]
                candidate_gaussian = None

                # Find nearest global Gaussian in S'_i
                if (u, v) in pixel_to_gaussians:
                    neighbors = pixel_to_gaussians[(u, v)]
                    min_neighbor = min(neighbors, key=lambda x: x['depth'])
                    d_g_min = min_neighbor['depth']

                    # Check floater condition
                    if d_t - d_g_min > delta:
                        candidate_gaussian = min_neighbor

                # If floater identified, adjust opacity
                if candidate_gaussian is not None:
                    # Calculate accumulated neighbor weight
                    neighbor_weights = get_neighbor_weights(candidate_gaussian, global_gaussians)
                    accumulated_weight = sum(neighbor_weights)

                    # [G] Exact opacity update formula not provided in sources;
                    # standard implementation scales alpha by accumulated weight ratio.
                    # candidate_gaussian['alpha'] *= accumulated_weight / (1.0 + accumulated_weight)
                    pass

def project_3d_to_2d(mu, proj_matrix):
    """Standard perspective projection: returns (u, v, depth) or (None, None, None) if behind camera."""
    h = [0.0, 0.0, 0.0, 0.0]
    for i in range(4):
        h[i] = sum(proj_matrix[i][j] * (mu[j] if j < 3 else 1.0) for j in range(4))
    if h[2] <= 0:
        return None, None, None
    u = int(h[0] / h[2])
    v = int(h[1] / h[2])
    return u, v, h[2]

def get_neighbor_weights(candidate, all_gaussians):
    """Returns list of omega for Gaussians within a fixed radius of candidate's center."""
    weights = []
    threshold = 0.5  # [G] Fixed radius for neighbor search; value not specified in sources
    for g in all_gaussians:
        dist = math.sqrt(sum((g['mu'][k] - candidate['mu'][k])**2 for k in range(3)))
        if dist < threshold:
            weights.append(g['omega'])
    return weights
```

**Edge Cases and Pitfalls**
- **Precision**: Depth comparison $d_t^l(i) - d_t^g(j)$ is sensitive to noise in predicted depth maps [S1].
- **Boundaries**: The method relies on the existence of projected Gaussians in $S'_i$; empty pixels are ignored [S1].

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of Gaussians and pixels, as it involves a single pass over input views and pixel-wise checks [S1].
- **Memory Complexity**: Requires storing global Gaussian attributes and depth maps; significantly lower than TSDF Fusion which requires voxel volumes [S1].
- **Strengths**: Explicitly removes floaters without high computational cost; avoids holes in renderings; seamlessly integrates with feed-forward 3DGS frameworks [S1].
- **Limitations**: Relies on the accuracy of predicted depth maps; sensitive to the threshold $\delta$ [S1].
- **When to use**: When reconstructing generalizable 3D scenes with feed-forward models where floaters are caused by depth prediction noise [S1].
- **When not to use**: When high-precision mesh extraction is required, as this method only adjusts opacities [S1].

## Background
Weighted Floater Removal was introduced in FreeSplat++ as part of a generalizable 3D Gaussian Splatting framework for efficient indoor scene reconstruction [S1]. It addresses the limitation of the PTF module, which only removes floaters added before the current view, by explicitly checking multi-view depth consistency [S1]. The method is inspired by TSDF Fusion but avoids its computational overhead by operating directly on Gaussian primitives [S1].
