# Vertex-level Pruning in Mixed-Primitive Gaussian Splatting

Also called: Mixed-Primitive Vertex Pruning

## Overview
Vertex-level pruning is a geometric simplification mechanism applied to mixed-primitive splats (Gaussian triangles and lines) during the training of 3D Gaussian Splatting. It removes redundant vertices from primitives that have collapsed or degenerated into lower-dimensional shapes, converting them into simpler primitives (ellipses or lines) to refine the surface representation. Unlike standard Gaussian Splatting, which only performs primitive-level opacity pruning, this method operates on the vertex level within the mixed-primitive framework [S1, unofficial].

## How it works
Vertex-level pruning is triggered concurrently with primitive-level pruning. It evaluates the geometric configuration of the vertices defining a mixed-primitive splat and simplifies the primitive if the vertices are spatially degenerate.

### Inputs and Outputs
*   **Input:** The set of active mixed-primitive splats, where each splat is defined by a set of vertex positions ($\mu_i$) and associated attributes.
*   **Output:** A modified set of splats where degenerate triangles and lines are converted to ellipses or simpler lines, reducing the total number of stored vertices.

### Data Structures
The method operates on the vertex coordinates of the primitives.
*   **Gaussian Triangle:** Defined by three vertices $\mu_1, \mu_2, \mu_3 \in \mathbb{R}^3$.
*   **Gaussian Line:** Defined by two vertices $\mu_1, \mu_2 \in \mathbb{R}^3$.
*   **Gaussian Ellipse:** Defined by a single center vertex $\mu_1 \in \mathbb{R}^3$ and a covariance matrix.

### Parameters
*   $\omega_{dist}$: The threshold for determining if vertices are "close". A set of vertices is considered close if their maximum pairwise L2 distance is below this value. Default: $0.5$ [S1, unofficial].
*   $\omega_{pear}$: The threshold for determining if Gaussian triangle vertices are collinear. Vertices are nearly collinear if the absolute value of the Pearson correlation coefficient computed from them exceeds this value. Default: $0.9$ [S1, unofficial].

### Algorithm
The pruning logic follows these steps for each primitive undergoing evaluation:

1.  **Trigger:** Perform vertex-level pruning whenever primitive-level pruning is performed [S1, unofficial].
2.  **Evaluate Gaussian Triangle:**
    *   Calculate the maximum pairwise L2 distance among $\mu_1, \mu_2, \mu_3$.
    *   If $\max(\|\mu_i - \mu_j\|_2) < \omega_{dist}$:
        *   Prune vertices $\mu_2$ and $\mu_3$.
        *   Convert the primitive into a Gaussian ellipse centered at $\mu_1$ [S1, unofficial].
    *   Else, check for collinearity:
        *   Compute the Pearson correlation coefficient $r$ from the coordinates of $\mu_1, \mu_2, \mu_3$.
        *   If $|r| > \omega_{pear}$:
            *   Convert the Gaussian triangle into a Gaussian line [S1, unofficial].
3.  **Evaluate Gaussian Line:**
    *   Calculate the L2 distance between $\mu_1$ and $\mu_2$.
    *   If $\|\mu_1 - \mu_2\|_2 < \omega_{dist}$:
        *   Prune vertex $\mu_2$.
        *   Reduce the primitive to a Gaussian ellipse centered at $\mu_1$ [S1, unofficial].

    """

        # Check if all three vertices are close
        dist_12 = l2_norm(mu1, mu2)
        dist_13 = l2_norm(mu1, mu3)
        dist_23 = l2_norm(mu2, mu3)
        max_dist = max(dist_12, dist_13, dist_23)
        
        if max_dist < omega_dist:
            # Convert to ellipse centered at mu1, pruning mu2 and mu3
            primitive.type = 'ellipse'
            primitive.vertices = [mu1]
            return primitive

        # Pearson correlation is computed on the coordinate arrays
        coords = [mu1, mu2, mu3]
        r = pearson_correlation(coords)
        
        if abs(r) > omega_pear:
            # Convert triangle to line
            primitive.type = 'line'
            # Keep mu1 and mu2 as the line endpoints
            primitive.vertices = [mu1, mu2]
            return primitive
            
    elif primitive.type == 'line':
        mu1, mu2 = primitive.vertices
        
        dist = l2_norm(mu1, mu2)
        
        if dist < omega_dist:
            # Reduce to ellipse centered at mu1
            primitive.type = 'ellipse'
            primitive.vertices = [mu1]
            return primitive
            
    return primitive

### Edge Cases and Pitfalls
*   **Degenerate Input:** If vertices are identical, the distance is 0, which is $< \omega_{dist}$, triggering conversion to an ellipse.
*   **Collinearity Calculation:** The exact method for computing the "Pearson correlation coefficient" from three 3D points is not explicitly defined in the source. It likely involves projecting the points onto their principal axis or using a multivariate extension. Implementers should ensure the correlation metric correctly identifies 3D collinearity [S1, unofficial].
*   **Interaction with Densification:** The pruning mechanism does not reduce the representation to only point-centered ellipses because the original densification mechanism (cloning and splitting) is integrated alongside pruning [S1, unofficial].

## Operating characteristics
*   **Storage Reduction:** The vertex pruning mechanism reduces the average storage size required to store vertex coordinates by 24% compared to the variant without pruning [S1, unofficial].
*   **Performance:** The method adds a lightweight geometric check during the pruning phase. It does not significantly impact rendering time as it is a training-time optimization.
*   **Accuracy:** The framework with vertex pruning performs better in surface reconstruction metrics (e.g., Chamfer distance) compared to the variant without it [S1, unofficial].

## Background
Vertex-level pruning was introduced in the Mixed-Primitive Gaussian Splatting (MP-GS) framework for surface reconstruction. It addresses the limitation of standard 3D Gaussian Splatting, which uses only point-centered primitives, by allowing for triangles and lines. As these mixed primitives evolve during training, they may become redundant, necessitating vertex-level simplification [S1, unofficial].
