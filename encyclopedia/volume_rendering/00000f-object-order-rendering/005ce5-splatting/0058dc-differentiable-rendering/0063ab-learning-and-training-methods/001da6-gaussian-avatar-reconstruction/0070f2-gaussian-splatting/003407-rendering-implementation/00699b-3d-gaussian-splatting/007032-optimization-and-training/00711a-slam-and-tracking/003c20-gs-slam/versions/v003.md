# GS-SLAM
## Overview
GS-SLAM is a Simultaneous Localization and Mapping (SLAM) method that simultaneously estimates camera poses and reconstructs 3D scenes using 3D Gaussians [S1][S2, unofficial]. It distinguishes itself from other radiance-field SLAM approaches by employing an adaptive 3D Gaussian expanding strategy to dynamically add new Gaussians and delete unreliable ones based on captured depth and rendered opacity [S1][S2, unofficial].
## How it works
**Inputs and Outputs:**
- Inputs: RGB-D image frames, initial camera poses, and an initial set of 3D Gaussians [G].
- Outputs: Optimized camera poses, updated 3D Gaussian parameters, and a dense 3D scene representation [G].

**Data Structures:**
- Active 3D Gaussians (position, scale, rotation, opacity, color) [G].
- Camera poses [G].
- Captured depth maps from the RGB-D sensor [S1].
- Rendered opacity maps [S1].

**Algorithm Steps:**
1. Render the current set of 3D Gaussians for the current camera pose to produce rendered opacity and expected depth images [G].
2. Compute the discrepancy between the rendered opacity/expected depth and the captured depth values [G].
3. Apply the adaptive 3D Gaussian expanding strategy to add new Gaussians into the training stage in regions identified by the discrepancy metrics [S1].
4. Delete unreliable Gaussians using the captured depths and rendered opacity values [S1].
5. Optimize the camera pose and all active Gaussian parameters [G].
6. Iterate steps 1–5 for subsequent frames [G].

**Edge Cases and Pitfalls:**
- **Duplicate Densification:** Without careful management, new Gaussians may be added in regions already well-represented [G].
- **Unreliable Gaussians:** Gaussians with low opacity or high depth error should be removed to maintain efficiency and accuracy [S1].

**Pseudocode:**
```python
def gs_slam(frames, initial_gaussians, initial_poses):
    gaussians = initial_gaussians
    poses = initial_poses
    for frame in frames:
        rgb = frame.rgb
        depth = frame.depth
        # [G] Standard differentiable volume rendering of 3D Gaussians
        rendered_opacity, rendered_depth = standard_3dgs_render(gaussians, poses[-1])
        # Compute discrepancy between rendered and captured depth
        depth_error = abs(rendered_depth - depth)
        # [G] Adaptive expanding: add new Gaussians where opacity is low or depth error is high
        expand_mask = (rendered_opacity < threshold_opacity) | (depth_error > threshold_depth)
        gaussians = standard_3dgs_densify(gaussians, poses[-1], depth, expand_mask)
        # Delete unreliable Gaussians using captured depths and rendered opacity values [S1]
        gaussians = standard_3dgs_prune(gaussians, rendered_opacity, depth_error)
        # [G] Joint optimization of camera pose and Gaussian parameters
        poses, gaussians = standard_slam_optimize(gaussians, poses, rgb, depth)
    return gaussians, poses
```

## Operating characteristics
- **Performance:** On the Replica dataset, GS-SLAM achieves a PSNR of 31.56, SSIM of 0.97, and LPIPS of 0.094 [S1].
- **Complexity:** Not given in the sources.
- **Strengths:** The adaptive 3D Gaussian expanding strategy dynamically adds new Gaussians and deletes unreliable ones using captured depths and rendered opacity values [S1][S2, unofficial].
- **Limitations:** Performance is lower than some other 3DGS SLAM methods like GaussianSplattingSLAM (PSNR 38.90) on the Replica dataset [S1].

## Background
GS-SLAM was proposed in the context of recent advances in 3D Gaussian Splatting for SLAM applications [S1][S2, unofficial].
