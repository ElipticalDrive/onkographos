# SplatQ

Also called: SplatQ: Post-training Gaussian pruning via QUBO

## Overview
SplatQ is a post-training pruning framework for 3D Gaussian Splatting (3DGS) that addresses spatial quality imbalance and ignores joint deletion effects inherent in global Top-K selection methods [S1, unofficial]. It partitions Gaussians into size-limited blocks based on spatial and appearance similarity, allocates retention quotas to balance regional budgets, and uses a Quadratic Unconstrained Binary Optimization (QUBO) model to jointly select Gaussians within each block, thereby accounting for pairwise interactions and overlapping contributions [S1, unofficial].

## How it works
**Inputs and outputs:**
*   **Input:** A pretrained 3DGS scene with $N$ Gaussians $\mathcal{G} = \{G_i\}_{i=1}^N$ and a target retention count $K$.
*   **Output:** A pruned set of $K$ Gaussians with optimized attributes.

**Data structures:**
Each Gaussian $G_i$ is defined by:
*   Center $\boldsymbol{\mu}_i$
*   Scale $s_i$
*   Rotation quaternion $\mathbf{r}_i$
*   Zeroth-order (DC) color coefficients $\mathbf{c}_i$
*   Higher-order spherical harmonic coefficients $\mathbf{h}_i$
*   Opacity $o_i$ [S1, unofficial]

The scene is partitioned into blocks $\mathcal{C}_b$. For each block $b$, a response matrix $\mathbf{R}_b$ is computed.

**Parameters:**
*   $N$: Total number of Gaussians.
*   $K$: Exact number of Gaussians to retain.
*   $M$: Maximum size (number of members) of each block $\mathcal{C}_b$.
*   $K_b$: Retention quota for block $b$, where $\sum_b K_b = K$.
*   $\mathbf{R}_b$: Response matrix for block $b$. [S1, unofficial]

**Steps:**

1.  **Partitioning:** Divide the $N$ Gaussians into size-limited blocks $\{\mathcal{C}_b\}$ of at most $M$ members each. Partitioning is guided by spatial proximity and appearance similarity to ensure potentially redundant Gaussians are evaluated together. A 3D grid and Morton ordering are used to efficiently identify related Gaussians without quadratic pairwise comparisons [S1, unofficial].

2.  **Opacity Response Modeling:** For each block $\mathcal{C}_b$, compute the response matrix $\mathbf{R}_b$. This is done by sampling pixels from multiple views to estimate individual deletion effects and pairwise interactions. The matrix approximates joint rendering effects by measuring changes in representative pixel colors relative to changes in Gaussian opacity [S1, unofficial].

3.  **Budget Allocation:** Assign a retention quota $K_b$ to every block such that $\sum_b K_b = K$. An initial quota is derived from importance estimates, then smoothed to prevent excessive budget concentration in regions with consistently higher scores, ensuring balanced representational capacity across the scene [S1, unofficial].

4.  **Quadratic Selection:** For each block $\mathcal{C}_b$, formulate a QUBO objective. Let $x_i \in \{0, 1\}$ be a binary variable for each Gaussian $G_i \in \mathcal{C}_b$, where $x_i=1$ if retained and $x_i=0$ if deleted. The objective incorporates:
    *   Individual responses (from $\mathbf{R}_b$).
    *   Pairwise interactions (from $\mathbf{R}_b$).
    *   Quota penalties to enforce $\sum_{i \in \mathcal{C}_b} x_i = K_b$.
    
    Solve the QUBO using Simulated Annealing (SA) or a Coherent Ising Machine (CIM) to determine the optimal set of $K_b$ members to retain [S1, unofficial].

5.  **Fine-tuning:** Fine-tune the attributes ($\boldsymbol{\mu}_i, s_i, \mathbf{r}_i, \mathbf{c}_i, \mathbf{h}_i, o_i$) of the retained Gaussians without changing their count to recover rendering quality [S1, unofficial].

**Edge cases and pitfalls:**
*   **Spatial Quality Imbalance:** Global ranking methods concentrate the budget in regions with high scores, leaving other regions with insufficient capacity [S1, unofficial]. SplatQ mitigates this via blockwise quota smoothing.
*   **Joint Deletion Effects:** Independent scoring fails to capture that multiple Gaussians may jointly support the same pixel. Degradation from removing multiple Gaussians is not strictly additive [S1, unofficial]. SplatQ addresses this via the quadratic interaction terms in the QUBO objective.
*   **Scalability:** Formulating the optimization over all $N$ Gaussians requires an $N \times N$ matrix, which is impractical for millions of Gaussians. Partitioning into blocks of size $M$ reduces this complexity [S1, unofficial].

## Operating characteristics
*   **Complexity:** The method decomposes the global $O(N^2)$ pairwise interaction problem into smaller block-wise problems of size $M$. However, the partitioning step uses a 3D grid and Morton ordering to avoid quadratic pairwise comparisons for grouping [S1, unofficial]. The QUBO solving step (SA or CIM) complexity depends on the block size $M$ and the solver used.
*   **Performance:** Experiments are conducted on 5 benchmark datasets (specific metrics not provided in the abstract) [S1, unofficial].
*   **Strengths:** Ensures balanced reconstruction quality across the scene; accounts for joint rendering effects and overlapping contributions; prevents spatial quality imbalance.
*   **Limitations:** Requires post-training optimization (fine-tuning); relies on sampling for response matrix estimation; QUBO solving may be computationally intensive depending on the solver and block size.
*   **When to use:** When balanced spatial quality is critical and the scene contains significant overlapping Gaussian contributions that global Top-K methods fail to handle correctly.

## Background
SplatQ was proposed by Hongbin Ye, Haixu Liu, Shenwei Kang, Wenxiu Wei, Tinglan Wang, Hongdong Zhu, Fan Tang, Qi Gao, Yin Ma, Kai Wen, Hai Wei, Nuo Qian, Wei-Shi Zheng, Shaobo Chen, Fa-Ting Hong, and Jingke Meng. It was presented as an unofficial preprint on arXiv in October 2026 [S1, unofficial]. The method addresses limitations in existing 3DGS pruning techniques, which primarily rely on global Top-K selection based on independent importance scores, lacking regional budget control and ignoring joint deletion effects [S1, unofficial].
