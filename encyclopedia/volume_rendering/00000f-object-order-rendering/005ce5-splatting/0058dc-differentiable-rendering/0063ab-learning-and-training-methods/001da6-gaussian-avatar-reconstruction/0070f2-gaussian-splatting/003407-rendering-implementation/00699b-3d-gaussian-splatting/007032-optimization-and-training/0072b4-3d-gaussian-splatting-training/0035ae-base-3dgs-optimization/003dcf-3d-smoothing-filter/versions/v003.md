# 3D Smoothing Filter

Also called: Maximal sampling rate filter, Mip-Splatting 3D filter

## Overview
The 3D Smoothing Filter prevents 3D Gaussian primitives from becoming smaller than the maximal sampling frequency induced by the training images, thereby mitigating aliasing artifacts during rendering at varying sampling rates [S1, S2, unofficial]. It differs from its siblings, [iVR-GS Training](7578-ivr-gs-training.md) and [Two-stage Gaussian-Surfel (GES) Optimization](23119-two-stage-gaussian-surfel-ges-optimization.md), by explicitly constraining the Gaussian scale based on camera geometry rather than relying on separate shading attribute optimization or surfel-specific regularization [S1, S2, unofficial].

## How it works
**Inputs:**
- $\mathbf{s}_k$: The scale vector of the $k$-th Gaussian.
- $o_k$: The opacity of the $k$-th Gaussian.
- $\mu_k$: The 3D center position of the $k$-th Gaussian.
- $\{K_n, C_n\}_{n=1}^N$: Intrinsics (focal length $f_n$) and extrinsics of $N$ training views.
- $\kappa_{3D}$: Hyperparameter controlling variance (default 0.2) [S1, unofficial].

**Outputs:**
- $\hat{\mathbf{s}}_k$: Filtered scale vector.
- $\hat{o}_k$: Filtered opacity (optional, see Simplified version).

**Data Structures:**
- No persistent data structures required beyond standard Gaussian attributes. The filter computes $\hat{\nu}_k$ on-the-fly or caches it for periodic updates.

**Steps:**

1. **Compute Maximal Sampling Rate ($\hat{\nu}_k$):**
   For each Gaussian $k$, calculate the maximum sampling rate across all $N$ training images:
   $$
   \hat{\nu}_k = \max \left( \left\{ \mathbb{1}_n(\mu_k) \cdot \frac{f_n}{d_n} \right\}_{n=1}^N \right)
   $$
   Where:
   - $\mathbb{1}_n(\mu_k)$ is an indicator function returning 1 if $\mu_k$ is visible in view $n$, 0 otherwise [S1, unofficial].
   - $f_n$ is the focal length of view $n$ in pixels [S1, unofficial].
   - $d_n$ is the z-depth of $\mu_k$ relative to the camera frame of view $n$ [S1, unofficial].

2. **Apply Filter (Standard Version):**
   Update the scale and opacity to incorporate the low-pass filter effect:
   $$
   \hat{\mathbf{s}}_k = \sqrt{\mathbf{s}_k^2 + \frac{\kappa_{3D}}{\hat{\nu}_k^2}}
   $$
   $$
   \hat{o}_k = \sqrt{\frac{|\text{diag}(\mathbf{s}_k^2)|}{|\text{diag}(\mathbf{s}_k^2 + \frac{\kappa_{3D}}{\hat{\nu}_k})|}} o_k
   $$
   Note: The opacity adjustment is often omitted in practice [S1, unofficial].

3. **Apply Filter (Simplified/In-place Version):**
   Instead of modifying opacity and recomputing full scale variance, clip the scales from below after each optimizer step:
   $$
   \mathbf{s}_k = \max\left(\mathbf{s}_k, \frac{\sqrt{\kappa_{3D}}}{\hat{\nu}_k}\right)
   $$
   This is computationally cheaper and independent of gradient computations [S1, unofficial].

4. **Update Frequency:**
   Recompute $\hat{\nu}_k$ for all Gaussians every 100 training iterations, as $\mu_k$ changes during optimization [S1, unofficial].

**Pseudocode:**

```python
def compute_max_sampling_rate(mu_k, training_views, kappa_3d=0.2):
    """
    Computes the maximal sampling rate nu_hat_k for a Gaussian.
    mu_k: (3,) array, Gaussian center.
    training_views: List of dicts with keys 'focal_length', 'extrinsics', 'intrinsic_matrix'.
    kappa_3d: Hyperparameter (default 0.2).
    Returns: nu_hat_k (float), s_min (float)
    """
    max_nu = 0.0
    for view in training_views:
        # Check visibility (simplified: assume visible if depth > 0)
        # In practice, use a proper visibility check (e.g., frustum culling or depth test)
        depth = transform_depth(mu_k, view['extrinsics'])
        if depth <= 0:
            continue
            
        f_n = view['focal_length']
        nu = f_n / depth
        if nu > max_nu:
            max_nu = nu
            
    # Avoid division by zero
    if max_nu == 0:
        max_nu = 1e-6
        
    s_min = sqrt(kappa_3d) / max_nu
    return max_nu, s_min

def apply_3d_smoothing_filter(gaussians, training_views, iteration, kappa_3d=0.2):
    """
    Applies the 3D smoothing filter to Gaussian attributes.
    gaussians: Object with attributes .scales (N, 3), .opacities (N,), .centers (N, 3)
    training_views: List of view parameters.
    iteration: Current training iteration.
    """
    # Recompute max sampling rate every 100 iterations
    if iteration % 100 == 0:
        s_mins = []
        for i in range(len(gaussians)):
            nu_hat, s_min = compute_max_sampling_rate(
                gaussians.centers[i], training_views, kappa_3d
            )
            s_mins.append(s_min)
        gaussians.s_mins = array(s_mins) # Cache for use in optimizer step
        
    # In-place clipping after optimizer step (simplified version)
    # This is typically called after the gradient update step
    for i in range(len(gaussians)):
        s_min = gaussians.s_mins[i]
        # Clip each dimension of the scale vector
        for j in range(3):
            if gaussians.scales[i, j] < s_min:
                gaussians.scales[i, j] = s_min
```

**Edge Cases and Pitfalls:**
- **Visibility:** The indicator function $\mathbb{1}_n$ must correctly handle occlusions. If a Gaussian is occluded in all views, $\hat{\nu}_k$ may be undefined or zero, leading to division by zero. Initialize $\hat{\nu}_k$ with a small epsilon or handle invisible Gaussians separately [S1, unofficial].
- **Depth Approximation:** For 4D Gaussians, depth $d_n(t)$ is approximated using the primitive center $p_k(t)$, which may introduce errors if the primitive is large or deforming significantly [S2, unofficial].
- **Opacity Adjustment:** The opacity formula in the standard version is complex and often unnecessary. The simplified in-place clipping is preferred for performance and stability [S1, unofficial].

## Subtopics

### [Adaptive Anisotropic Spatial Low-Pass Filter](20042-adaptive-anisotropic-spatial-low-pass-filter.md)
This filter prevents artifacts such as holes caused by undersampling of high-frequency features in Gaussian radiance fields during deformation. It differs from fixed isotropic low-pass filters by adapting to varying spatial sampling intervals, thereby reducing blurring and preserving high-frequency signals.

## Operating characteristics
- **Time Complexity:** Recomputing $\hat{\nu}_k$ for all Gaussains takes $O(N \cdot M)$ per iteration, where $N$ is the number of Gaussians and $M$ is the number of training views. This is done every 100 iterations [S1, unofficial].
- **Memory Complexity:** Requires storing $\hat{\nu}_k$ or $s_{min}$ for each Gaussian, $O(N)$ [S1, unofficial].
- **Performance:** The simplified in-place clipping is significantly cheaper than the full opacity/scale update and is independent of gradient computations [S1, unofficial]. A fused CUDA implementation by Hahlbohm et al. can accelerate the computation of $\hat{\nu}_k$ [S1, unofficial].
- **Strengths:** Effectively prevents aliasing artifacts when rendering at different sampling rates (e.g., zooming or changing focal length) [S1, unofficial].
- **Limitations:** Does not address aliasing caused by 2D projection gaps (handled by the 2D Mip filter) [S1, unofficial]. The approximation of depth in 4D Gaussians may be inaccurate for large deformations [S2, unofficial].

## Background
The 3D Smoothing Filter was introduced by Yu et al. in Mip-Splatting [S1, unofficial]. It was designed to extend the original 3D Gaussian Splatting method by preventing Gaussians from becoming smaller than the maximal sampling frequency induced by the training images, thus mitigating aliasing artifacts during rendering at varying sampling rates [S1, unofficial]. The method has been further adapted for 4D Gaussian Splatting to handle temporal variations in camera parameters and primitive positions [S2, unofficial].
