# Hybrid Coarse-to-Fine Strategy

Also called: Multi-stage point cloud refinement

## Overview
A training strategy that refines a point-based radiance field representation through multiple stages of densification, rather than optimizing a fixed or single-stage point cloud [S1]. It addresses the instability and poor convergence of initializing dense point clouds from scratch by starting with a sparse, structured representation and progressively adding detail [S1]. Compared to single-stage training, it yields significantly higher rendering quality, particularly in preserving fine geometric details and reducing artifacts [S1].

## How it works
The method operates on a mesh or point cloud representation that is iteratively densified. The specific implementation detailed in the sources involves a mesh-based coarse-to-fine densification process [S2].

**Inputs and Outputs:**
*   **Input:** A sparse initial mesh (vertices and triangles), target images, and camera poses.
*   **Output:** A refined mesh with increased vertex count and optimized vertex features (e.g., color, opacity, or neural texture coefficients).

**Data Structures:**
*   **Mesh:** Defined by a set of vertices $V$ and a set of triangles $T$.
*   **Triangle Properties:** Each triangle $t$ tracks the number of pixels it covers, $|\text{pixels}_t|$, and its mean structural dissimilarity, $\overline{\text{DSSIM}}_t$.

**Numbered Steps:**

1.  **Sparse Initialization:**
    *   Compute Sobel gradient magnitudes on a downsampled target image [S2].
    *   Sample initial vertex positions proportionally to edge strength, applying a small uniform floor to ensure coverage in low-gradient regions [S2].
    *   Create a Delaunay triangulation of the sampled points, adding boundary vertices to ensure full image coverage [S2].

2.  **Iterative Densification Loop:**
    *   The densification occurs every 500 iterations, starting at iteration 1,500 and ending at iteration 15,000 [S2].
    *   **Scoring:** For each triangle $t$, calculate a score using the formula:
        $$ \text{score}_t = \overline{\text{DSSIM}}_t \cdot |\text{pixels}_t|^\alpha $$
        where $\alpha = 0.75$ is the area-weighting exponent [S2].
    *   **Filtering:** Exclude triangles with fewer than 3 pixels from scoring [S2].
    *   **Vertex Insertion:** Identify the top-scoring triangles. Insert centroid vertices for these triangles. The number of new vertices is capped at $0.35 \times V$, where $V$ is the current vertex count [S2].
    *   **Feature Initialization:** Initialize the features of new centroid vertices by averaging the features of the parent triangle's vertices [S2].
    *   **Re-triangulation:** Re-run Delaunay triangulation on the full set of vertices (old and new) [S2].
    *   **Degeneracy Check:** Detect if the mesh becomes degenerate (e.g., colinear vertices) and re-mesh if necessary, though this is rare [S2].

**Pseudocode:**

```python
def hybrid_coarse_to_fine_training(mesh, target_images, cameras, total_iterations=15000):
    """
    mesh: Initial sparse mesh with vertices V and triangles T.
    target_images: List of target RGB images.
    cameras: List of camera poses.
    """
    alpha = 0.75
    densify_interval = 500
    start_iter = 1500
    end_iter = 15000
    
    # Step 1: Sparse Initialization
    # Compute Sobel gradients on downsampled image
    gradients = compute_sobel_gradients(downsample(target_images[0]))
    # Sample vertices proportional to gradient strength + uniform floor
    vertices = sample_vertices_proportional_to_gradients(gradients, floor=0.01)
    # Add boundary vertices for full coverage
    vertices = add_boundary_vertices(vertices, image_bounds)
    # Create initial Delaunay triangulation
    mesh = create_delaunay_triangulation(vertices)
    
    for iter in range(1, total_iterations + 1):
        # Standard training step (rendering, loss computation, gradient descent)
        render(mesh, cameras)
        compute_loss_and_update_features()
        
        # Step 2: Iterative Densification
        if start_iter <= iter <= end_iter and (iter - start_iter) % densify_interval == 0:
            densify_mesh(mesh, alpha)
            
    return mesh

def densify_mesh(mesh, alpha):
    triangles = mesh.triangles
    current_vertex_count = len(mesh.vertices)
    
    # Calculate scores for valid triangles
    candidates = []
    for t in triangles:
        pixel_count = t.covered_pixel_count
        if pixel_count < 3:
            continue
        
        # Mean DSSIM is computed during rendering/loss step
        dssim = t.mean_dssim
        
        score = dssim * (pixel_count ** alpha)
        candidates.append((score, t))
    
    # Sort by score descending
    candidates.sort(key=lambda x: x[0], reverse=True)
    
    # Determine how many triangles to split
    # Insert up to 0.35 * V new vertices
    max_new_vertices = int(0.35 * current_vertex_count)
    num_to_split = min(len(candidates), max_new_vertices)
    
    new_vertices = []
    new_triangles = []
    
    for i in range(num_to_split):
        score, t = candidates[i]
        
        # Calculate centroid
        centroid = (t.v1 + t.v2 + t.v3) / 3.0
        
        # Initialize features by averaging parent vertex features
        new_feat = (t.v1.features + t.v2.features + t.v3.features) / 3.0
        
        # Create new vertex object
        new_v = Vertex(position=centroid, features=new_feat)
        new_vertices.append(new_v)
        
        # Note: The specific re-triangulation logic (Delaunay) is handled by the mesh library
        # We just mark the triangle for removal and the centroid for insertion
        t.mark_for_removal()
        
    # Remove marked triangles
    mesh.triangles = [t for t in mesh.triangles if not t.marked_for_removal()]
    
    # Add new vertices
    mesh.vertices.extend(new_vertices)
    
    # Re-run Delaunay triangulation on the full vertex set
    mesh = create_delaunay_triangulation(mesh.vertices)
    
    # Check for degeneracy (e.g., colinear vertices)
    if is_degenerate(mesh):
        mesh = remesh_degenerate_mesh(mesh)
```

**Parameters:**
*   $\alpha = 0.75$: Area-weighting exponent [S2].
*   Densification interval: Every 500 iterations [S2].
*   Start iteration: 1,500 [S2].
*   End iteration: 15,000 [S2].
*   Max new vertices per step: $0.35 \times V$ [S2].
*   Minimum pixels per triangle: 3 [S2].

**Edge Cases and Pitfalls:**
*   **Degeneracy:** Vertices may become colinear during densification, requiring re-meshing [S2].
*   **Tiny Triangles:** Triangles with fewer than 3 pixels are excluded from scoring to prevent over-splitting in low-detail areas [S2].
*   **Precision:** The area weighting exponent $\alpha$ prevents repeated splitting of tiny, high-error triangles, distributing vertices more evenly [S2].

## Subtopics

### Coarse-to-Fine Densification
A specific variant where a sparse mesh is progressively refined by inserting centroid vertices for high-scoring triangles and re-running Delaunay triangulation [S2]. It is chosen when a structured, mesh-based initialization is preferred over random point cloud initialization. It differs from other variants by explicitly using geometric error (DSSIM) and area weighting to guide densification [S2].

## Operating characteristics
*   **Time Complexity:** The densification step involves scoring all triangles and re-running Delaunay triangulation, which is $O(V \log V)$ or similar depending on the triangulation algorithm, where $V$ is the vertex count. This adds overhead to every 500 iterations.
*   **Memory Complexity:** Increases as the number of vertices grows. The cap of $0.35 \times V$ new vertices per step controls the growth rate.
*   **Measured Performance:** On the Blender dataset, removing the hybrid strategy ('w/o hybrid') reduces PSNR from 30.3 dB to 26.6 dB, SSIM from 0.945 to 0.925, and increases LPIPS from 0.078 to 0.163 [S1].
*   **Strengths:** Significantly better rendering quality than single-stage training [S1]. Stabilizes learning by starting with a sparse, well-structured representation [S2].
*   **Limitations:** Requires careful tuning of densification parameters (interval, start/end iterations, $\alpha$). More complex to implement than single-stage training.
*   **When to use:** When high-quality view synthesis is required and the scene has complex geometry or fine details that are hard to capture with a sparse initial point cloud.
*   **When not to use:** When computational resources are extremely limited and single-stage training is sufficient for the required quality.

## Background
The hybrid coarse-to-fine strategy was introduced in the context of differentiable point-based radiance fields [S1]. It departs from volumetric representations and coordinate-network representations that require ray-marching [S1]. The strategy was validated through ablation experiments showing its contribution to rendering quality [S1]. The mesh-based variant was introduced in the context of neural harmonic textures for high-quality primitive-based neural reconstruction [S2].
