# Dynamic Neural Radiance Fields

Also called: 4D Facial Avatar Reconstruction, Dynamic Neural Scene Representation Network

## Overview
Dynamic Neural Radiance Fields (Dynamic NeRF) is a method for modeling the appearance and dynamics of a human face using an implicit volumetric representation [S1]. It solves the problem of synthesizing novel viewpoints and expressions from monocular video input by combining a neural scene representation network with a low-dimensional morphable model [S1]. Unlike explicit geometry methods that struggle with hair and mouth interiors, or static NeRF methods that cannot handle temporal dynamics, this approach conditions the neural network on morphable model expression parameters and a per-frame latent code to capture time-varying surfaces [S1].

## How it works
**Inputs:**
1.  A monocular portrait video sequence.
2.  A static background image (captured without the person) [S1].
3.  Pre-computed pose and expression parameters for each frame, estimated via a 3D morphable model (3DMM) [S1].

**Outputs:**
Synthesized images of the face at novel viewpoints and expressions [S1].

**Data Structures:**
*   **Dynamic Radiance Field MLP ($D_\theta$):** A multi-layer perceptron that maps canonical coordinates and conditioning variables to color and density.
*   **Positional Encoding:** A deterministic function applied to position and view direction inputs to map them to a higher-dimensional space. The source specifies 10 frequencies for position and 4 for view direction [S1].
*   **Morphable Model Parameters:**
    *   Pose parameters: Rotation and translation vectors used to transform rays into canonical space [S1].
    *   Expression parameters ($\delta$): A vector of coefficients representing facial deformations. The source specifies $\delta \in \mathbb{R}^{76}$, derived from a low-dimensional delta-blendshape basis [S1].
*   **Per-frame Latent Code ($\gamma$):** A learnable vector input to the MLP, optimized during training to compensate for errors in facial expression and pose estimation [S1].

**Algorithm:**

1.  **Preprocessing (Tracking):**
    For each frame in the input video sequence, apply facial expression tracking using a 3D morphable model to estimate the pose parameters (rotation, translation) and expression parameters $\delta$ [S1].

2.  **Ray Casting (Canonical Space):**
    For a target frame to be synthesized:
    a.  Determine the desired camera pose.
    b.  Use the estimated pose parameters (rotation, translation) to transform the viewing rays from the camera space into a shared canonical space [S1]. This canonical space is where the neural scene representation network is embedded [S1].

3.  **Sampling:**
    Sample points along each transformed viewing ray. Let a sample point be $p$ and the view direction be $\vec{v}$ [S1].

4.  **Neural Field Evaluation:**
    For each sample point, compute the output of the dynamic radiance field MLP $D_\theta$. The inputs are:
    *   Positional encoding of the canonical position $p$.
    *   Positional encoding of the view direction $\vec{v}$.
    *   The expression parameters $\delta$ for the current frame.
    *   The per-frame learnable latent code $\gamma$ [S1].

    The MLP outputs the color (RGB) and density ($\sigma$) for that sample point:
    $$ D_\theta (p, \vec{v} , \delta, \gamma) = (RGB, \sigma) $$
    [S1]

    *Note:* Instead of directly inputting $p$ and $\vec{v}$, positional encoding is used as introduced by Mildenhall et al. [S1].

5.  **Volumetric Integration:**
    Perform volumetric integration of the density and color values predicted by the MLP along the rays to generate the final pixel color [S1]. This follows the standard volume rendering equation used in static NeRF [S1].

6.  **Background Handling:**
    For the last sample point of each ray (representing the background), set the color to the corresponding value from the static background image. The density contribution of the background is handled by the integration process terminating or being overridden by this fixed color value [S1].

**Edge Cases and Pitfalls:**
*   **Pose/Expression Errors:** The method includes a per-frame learnable latent code $\gamma$ specifically to compensate for errors in the facial expression and pose estimation from the 3DMM [S1].
*   **Discretization Artifacts:** Unlike discrete voxel grids, the implicit representation does not suffer from discretization artifacts [S1].
*   **Complex Geometry:** The volumetric representation is capable of capturing hair and mouth interiors, which are problematic for explicit geometry methods [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** The method allows for photo-realistic image generation that surpasses the quality of state-of-the-art video-based reenactment methods [S1].
*   **Strengths:**
    *   Captures complex geometry like hair and mouth interiors [S1].
    *   Handles dynamically changing surfaces [S1].
    *   Does not suffer from discretization artifacts of voxel grids [S1].
    *   Can synthesize 3D-consistent content with large head pose changes [S1].
    *   Works from monocular input data only, without specialized capture setup [S1].
*   **Limitations:**
    *   Relies on a 3D morphable model for pose and expression estimation, which models coarse geometric surface changes but does not model changes such as eye orientation [S1].
*   **When to use:** When high-quality, 3D-consistent novel view synthesis of a dynamic human face is required from monocular video, particularly for AR/VR telepresence applications [S1].
*   **When not to use:** When explicit control over fine details not captured by the morphable model (e.g., eye orientation) is critical, or when computational resources for MLP evaluation are severely constrained (though specific benchmarks are not provided in the sources).

## Background
*   **Origin:** The method was introduced in the paper "Dynamic Neural Radiance Fields for Monocular 4D Facial Avatar Reconstruction" [S1].
*   **History:** It builds upon the static Neural Radiance Fields (NeRF) by Mildenhall et al. [S1]. The authors note that while follow-up work extended NeRF with different positional encodings and in-the-wild data, and concurrent work used sinusoidal activations, this method specifically addresses the dynamically changing surface of a face [S1].
*   **Usage:** 4D avatars are essential for augmented reality (AR) and virtual reality (VR) telepresence applications [S1]. The method enables viewpoint synthesis in VR, pose changes in videos, and facial reenactment [S1].
