# SLAM and Mapping
Also called: Neural SLAM, Gaussian SLAM, Radiance Field SLAM

## Overview
This family encompasses methods that simultaneously estimate camera poses and reconstruct 3D scene representations using radiance fields (NeRFs, 3D Gaussians, or hybrid neural fields) within a Simultaneous Localization and Mapping (SLAM) framework. Unlike traditional SLAM which outputs sparse point clouds or dense meshes, these methods optimize continuous or explicit volumetric representations to enable high-fidelity novel view synthesis and real-time rendering [S1, S3]. They are distinguished from standard offline reconstruction by their incremental, online nature, where mapping and tracking are coupled to handle dynamic environments and drift correction in real-time [S3].

## Shared principles
All methods in this family share the core SLAM loop:
1.  **Tracking:** Estimate the current camera pose $T_t$ relative to the world or previous frame using photometric or geometric consistency with the current scene representation.
2.  **Mapping:** Update the scene representation (NeRF weights, Gaussian parameters, or neural points) using new observations and the estimated pose.
3.  **Loop Closure:** Detect revisited locations to correct accumulated drift in the pose graph and scene representation [S3].

Common technical components include:
*   **Differentiable Rendering:** The scene representation must be differentiable with respect to camera parameters and scene parameters to allow gradient-based optimization [S1, S3].
*   **Pose Parameterization:** Camera poses are typically parameterized by translation $t$ and rotation quaternion $q$ [S5].
*   **Loss Functions:** Tracking and mapping losses often combine photometric terms (L1/L2 on RGB), depth terms, and regularization terms (SSIM, entropy) [S5, S6].

## Subtopics

### [Mapping Strategies](9321-mapping-strategies.md)
Mapping strategies define the correspondence mechanism used to align pixels or features between two distinct scenes or views during radiance field optimization and editing. They solve the problem of establishing spatial alignment when direct geometric priors are insufficient or when transferring attributes between different scene representations. Unlike standard SLAM mapping which optimizes geometry for a single scene, these strategies focus on cross-scene or cross-view correspondence, often leveraging semantic information to handle misalignment that identity-based methods miss. See [Mapping Strategies](9321-mapping-strategies.md).

### [Neural Radiance Field (NeRF) Representation](12096-neural-radiance-field-nerf-representation.md)
Neural Radiance Field (NeRF) representation refers to methods that model 3D scenes using neural networks or explicit geometric primitives to enable novel view synthesis and mapping. The term broadly encompasses two distinct paradigms: **Photon Field Networks**, which use implicit neural networks to approximate indirect global illumination in volumetric media, and **3D Gaussian Splatting** (often associated with Instant Neural Graphics Primitives), which represents scenes explicitly as millions of 3D Gaussians for real-time rendering. While standard NeRF methods store scene information implicitly within a neural network, Gaussian Splatting stores it explicitly as a set of blobs, trading higher memory usage for significantly faster training and rendering speeds. See [Neural Radiance Field (NeRF) Representation](12096-neural-radiance-field-nerf-representation.md).

### CG-SLAM
**Definition:** A SLAM method that introduces an uncertainty map into the training process based on the rendered depth, which greatly improves reconstruction quality [S1].

### Combined ORB-SLAM + 3DGS
**Definition:** Combines an existing frame-based tracking system (ORB-SLAM) with 3DGS mapping. ORB-SLAM recovers poses, and 3DGS is trained with poses and sensor depth of keyframes, equivalent to offline splatting [S2, unofficial].
**Comparison:** On EuRoC Machine Hall (Stereo Depth), ORB-SLAM3 achieves an ATE RMSE of 0.052m, while the combined approach yields 3.190m. Point-SLAM fails on all sequences. Although ORB-SLAM achieves the best ATE, there is no significant difference in rendering metrics compared to unified 3DGS SLAM. The unified approach is preferred for exploring 3DGS throughout the entire algorithm [S2, unofficial].

### CP-SLAM
**Definition:** A neural point-based hybrid neural field SLAM system enabling multi-agent cooperative localization and mapping with loop closure [S3].
**Steps:**
1.  Uses a keyframe-associated neural point representation inspired by PointNeRF, allowing per-point features to be adjusted during pose graph optimization [S3].
2.  Employs a two-stage distributed-to-centralized training scheme: initial decoders are trained separately for each agent, then fused and fine-tuned jointly [S3].
3.  Integrates odometry, loop detection, sub-map fusion, and global refinement into a unified framework [S3].

### MNE-SLAM
**Definition:** The first fully distributed multi-agent neural SLAM framework enabling accurate collaborative mapping and robust camera tracking without centralized training or raw data exchange [S3].
**Steps:**
1.  Uses a triplane+MLP hybrid neural field representation as a mapping module [S3].
2.  Introduces an intra-to-inter loop closure strategy to reduce pose drift and align submaps across agents through peer-to-peer feature sharing and global consistency loss [S3].

### HERO-SLAM
**Definition:** A SLAM method employing a novel multiscale patch-based loss that aligns feature points, maps, and RGB-D pixels through warpings [S3].
**Steps:** Uses an INGP-like multiresolution hybrid feature grid+MLP representation for neural SDF learning [S3].

### PIN-SLAM
**Definition:** A globally consistent SLAM system using a point-based implicit neural (PIN) representation [S3].
**Steps:**
1.  Replaces grid structures with neural feature points, offering spatial flexibility and elastic correction during loop closure [S3].
2.  Mapping alternates with odometry [S3].
3.  Mapping step is based on a hybrid neural SDF representation with explicit neural points and implicit MLP decoders [S3].
4.  Odometry is performed correspondence-free via second-order scan-to-map optimization [S3].
5.  A sliding window replay buffer ensures stable incremental updates [S3].
6.  Loop closures trigger pose graph optimization and elastic deformation of neural points, enabling consistent large-scale mapping [S3].

### Active 3D Reconstruction Algorithm
**Steps:**
1.  **Initialization:** Initialize 3D bounding box, uniformly sample goal-state candidates $S_g$ from view space, initialize DVGO coarse model $M(c)$ and agent state $s_0$, append initial image to database $\{I\}$ [S4, unofficial].
2.  **Global Policy:** Select next-best-view $s^*_g$ from goal candidates $S_g$ using criterion: $s^*_g = \arg\min_{s_g \in S_g} (\lambda_{cp} l_{cp}(x_{s_g}) - \lambda_{ig} E_s(s_g))$, where $x_{s_g}$ is 3D location of $s_g$ [S4, unofficial].
3.  **Local Policy:** Execute planning optimization to obtain optimized trajectory $S^*$ and local next-best view $s^*$ [S4, unofficial].
4.  **Action:** Move agent to $s^*$ [S4, unofficial].
5.  **Observation:** Obtain new image observation $I_t$ [S4, unofficial].
6.  **Update Database:** Add new observation to database $\{I\}_{i=0}^{t+1}$ [S4, unofficial].
7.  **Mapping Optimization:** Optimize DVGO model $M_t$ to $M_{t+1}$ by sampling pixels from database, including synchronizing entropy volume $V(E,c)$ [S4, unofficial].
8.  **Stop Check:** Stop if (1) change in entropy volume is below threshold, or (2) maximum information gain of feasible goal candidates is below threshold [S4, unofficial].
9.  **Fine Stage:** After exploration, initialize DVGO fine model $M(f)$ with trained coarse model $M_T(c)$. Perform stochastic training by sampling pixels from database $\{I\}_{i=0}^T$ for $N$ iterations, optimizing every $m$ iterations [S4, unofficial].

### Lightness-Decoupled Camera Tracking
**Definition:** A camera tracking method that decouples lightness from the image to handle lighting changes, by converting images to LAB space and discarding the L (lightness) channel during comparison [S5].
**Steps:**
1.  Parameterize camera pose as $T = (t, q)$ with 3D translation $t$ and rotation quaternion $q$ [S5].
2.  Initialize camera pose assuming constant camera velocity [S5].
3.  Convert input image $C$ and rendered image $\hat{C}$ to LAB space using $\rho$ [S5].
4.  Discard the L channel [S5].
5.  Minimize $L_{tracking}$ using color (A/B channels) and depth differences [S5].
**Formula:** $L_{tracking} = \lambda_{color} |\rho(\hat{C}) - \rho(C)| + \lambda_{depth} |\hat{D} - D|$, where $\rho$ is the operation of converting the image from RGB to LAB space, $C$ is the input image, $\hat{C}$ is the rendered image, $D$ is the input depth, and $\hat{D}$ is the rendered depth [S5].
**Parameters:** $\lambda_{color} = 0.5$, weight for the color term in the tracking loss; $\lambda_{depth} = 1.0$, weight for the depth term in the tracking loss [S5].

### Active Mapping with 3D Gaussian Splatting
**Steps:**
1.  Reconstruct environment using 3D Gaussians (e.g., via SplaTAM) [S6].
2.  Propose path candidates using frontier-based exploration [S6].
3.  Sample cameras along the path concerning the mobility of the agent [S6].
4.  Compute EIG for each path and choose the one with the highest EIG to continue exploration [S6].
**Formula:** $P_j = \arg \max_{P_j} \text{tr} \left( \sum_{x_{acq_i} \in P_j} H''[y_{i\_acq}|x_{acq_i}, w^*] \right) H''[w^*|D_{train}]^{-1}$ [S6].

## Background
SLAM with radiance fields emerged as a convergence of neural rendering and visual SLAM. Early works like iNeRF [S5] demonstrated the feasibility of optimizing NeRFs online for tracking. The introduction of 3D Gaussian Splatting (3DGS) [S2, unofficial] provided a differentiable, explicit representation that enabled real-time rendering and faster optimization, leading to methods like SplaTAM and GS-SLAM [S5]. Recent developments focus on multi-agent systems (CP-SLAM, MNE-SLAM) [S3], hybrid representations (PIN-SLAM, HERO-SLAM) [S3], and active mapping strategies using information gain (ActiveRMAP, FisherRF) [S4, unofficial][S6].
