# GaussianDiffusion

Also called: GaussianCube

## Overview
GaussianDiffusion is a method that trains a 3D diffusion model based on a GaussianCube representation to generate 3D Gaussian Splatting (3DGS) fields directly [S1]. It solves the problem of multi-view inconsistency (the "Janus problem") and the generation of spurious geometry ("floaters") common in text-to-3D pipelines by incorporating structured noises from multiple viewpoints and using variational 3DGS [S1]. It differs from its sibling TriplaneGaussian by operating on a voxelized Gaussian representation converted via optimal transport rather than a triplane-based feature grid [S1].

## How it works
**Inputs and Outputs:**
- Input: Text prompts or reference images (implied by diffusion context [S1]).
- Output: A set of 3D Gaussians defined by position, covariance, color, and opacity.

**Data Structures:**
- **GaussianCube:** A voxelized representation of a constant number of Gaussians. The conversion from the continuous Gaussian set to the voxel grid is performed via optimal transport [S1].
- **Structured Noise:** Noise tensors aligned with multiple viewpoints to enforce consistency [S1].

**Steps:**
1. **Representation Conversion:** Convert a fixed number of 3D Gaussians into the GaussianCube representation using optimal transport voxelization [S1].
2. **Diffusion Training:** Train a 3D diffusion model on the GaussianCube representation [S1].
3. **Noise Incorporation:** Incorporate structured noises from multiple viewpoints during the diffusion process to alleviate the Janus problem [S1].
4. **Generation:** Use variational 3DGS during the generation phase to mitigate floaters and improve result quality [S1].

**Parameters:**
- Not given in the sources.

**Edge Cases and Pitfalls:**
- The Janus problem (inconsistent views) is addressed by structured noise [S1].
- Floaters (spurious geometry) are mitigated by variational 3DGS [S1].

## Subtopics

### [Direct 3D Generation](11810-direct-3d-generation.md)
Direct 3D Generation refers to methods that learn a feedforward or diffusion model to output 3D Gaussian Splatting (3DGS) fields directly from text or images, bypassing the explicit intermediate step of generating a set of multi-view images. By training on large collections of synthetic or reconstructed data, these models amortize the reconstruction cost and naturally promote multi-view coherence, enabling near-real-time sampling at test time. This approach differs from traditional two-stage pipelines (image generation followed by 3D reconstruction) by optimizing directly for the structured Gaussian output space, addressing challenges such as high-dimensional outputs (positions, anisotropic covariance, colors, opacity) and maintaining controllability.

### Gaussian Masking
Gaussian Masking is a technique used to prune Gaussians during training [S2]. It is applied at every densification step and for every 500 iterations after densification stops [S2]. The method uses a loss weight $\lambda_m = 0.05$, a threshold $\epsilon_m = 0.05$, and a learning rate of 0.5 for the Gaussian masks [S2].
