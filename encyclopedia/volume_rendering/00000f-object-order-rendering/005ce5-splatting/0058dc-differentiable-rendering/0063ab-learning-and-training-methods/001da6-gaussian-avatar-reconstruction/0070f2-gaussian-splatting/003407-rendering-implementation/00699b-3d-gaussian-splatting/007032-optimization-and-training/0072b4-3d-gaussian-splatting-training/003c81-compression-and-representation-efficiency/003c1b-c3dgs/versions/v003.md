# C3DGS

Also called: Compact 3D Gaussian Splatting

## Overview
C3DGS is a compression method for 3D Gaussian Splatting that reduces storage requirements by applying residual vector quantization (R-VQ) to geometric attributes, specifically scaling and rotation [S1][S2, unofficial]. It distinguishes itself from siblings such as [Mini-Splatting](7850-mini-splatting.md) and [CompGS](18575-compgs.md) by preserving the full set of primitives and quantizing their attributes rather than reducing the Gaussian count via sampling or pruning [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A trained set of $N$ 3D Gaussians with full-precision attributes: position $\mathbf{p}$, rotation $\mathbf{R}$, scale $\mathbf{s}$, opacity $\alpha$, and spherical harmonic coefficients $\mathbf{c}_{lm}$ [G].
*   **Output:** A compressed representation using codebooks and residuals, achieving a scene size of 48.8 MB on the MipNeRF360 dataset [S1].

**Data Structures:**
1.  **Codebook:** A finite set of representative vectors for scaling and rotation [S1][S2, unofficial].
2.  **Indices:** Quantized indices pointing to entries in the codebook [G].
3.  **Residuals:** Small correction values stored for each Gaussian to recover precision [G].

**Method Steps:**
1.  **Attribute Selection:** Identify geometric attributes for quantization: scaling $\mathbf{s}$ and rotation $\mathbf{R}$ [S1][S2, unofficial].
2.  **Residual Vector Quantization (R-VQ):**
    *   Cluster the geometric attributes into a codebook using R-VQ [S1][S2, unofficial].
    *   For each Gaussian, find the nearest codebook entry.
    *   Compute the residual between the original attribute and the codebook entry.
    *   Store the codebook index and the residual [G].
3.  **Non-Quantized Attributes:** Position $\mathbf{p}$ and opacity $\alpha$ are not quantized [S1][S2, unofficial]. Sharing these attributes across Gaussians would result in overlapping Gaussians, which degrades quality [S1][S2, unofficial].
4.  **Reconstruction:** Retrieve the codebook entry and add the residual to recover the full-precision attribute [G].

**Pseudocode:**
```python
def compress_c3dgs(gaussians):
    # Codebook training: Not given in the sources.
    codebook_s = [] # Placeholder for trained scaling codebook
    codebook_R = [] # Placeholder for trained rotation codebook
    
    compressed_gaussians = []
    for g in gaussians:
        # Find nearest codebook entry
        idx_s = min(range(len(codebook_s)), key=lambda i: norm(g.s - codebook_s[i]))
        idx_R = min(range(len(codebook_R)), key=lambda i: norm(g.R - codebook_R[i]))
        
        # Compute residuals
        res_s = g.s - codebook_s[idx_s]
        res_R = g.R - codebook_R[idx_R]
        
        # Store compressed data
        compressed_gaussians.append({
            'p': g.p,
            'alpha': g.alpha,
            'c_lm': g.c_lm,
            'idx_s': idx_s,
            'idx_R': idx_R,
            'res_s': res_s,
            'res_R': res_R
        })
    return compressed_gaussians, codebook_s, codebook_R

def decompress_c3dgs(compressed_gaussians, codebook_s, codebook_R):
    gaussians = []
    for cg in compressed_gaussians:
        s = codebook_s[cg['idx_s']] + cg['res_s']
        R = codebook_R[cg['idx_R']] + cg['res_R']
        gaussians.append({
            'p': cg['p'],
            'R': R,
            's': s,
            'alpha': cg['alpha'],
            'c_lm': cg['c_lm']
        })
    return gaussians
```

**Parameters:**
*   Codebook size: Not given in the sources.
*   Residual precision: Not given in the sources.

**Edge Cases:**
*   Overlapping Gaussians: Avoid quantizing position and opacity to prevent this [S1][S2, unofficial].

## Operating characteristics
*   **Size:** 48.8 MB on MipNeRF360 [S1].
*   **Quality:** SSIM 0.798, PSNR 27.08, LPIPS 0.247 on MipNeRF360 [S1].
*   **Comparison:** Outperforms 3DGS (750 MB) in size while maintaining competitive quality [S1]. Compact3D size is not provided in the sources.

## Background
C3DGS was introduced in [54] according to [S1], while [S2, unofficial] cites it as [56]. It builds on the principle of vector quantization in signal processing, which involves clustering multidimensional data into a finite set of representations [S1][S2, unofficial].
