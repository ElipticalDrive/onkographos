# InfiniSplat v2

Also called: InfiniSplat

## Overview
InfiniSplat v2 is a feed-forward Gaussian reconstruction method for arbitrary input views that decouples geometry and attribute prediction, uses ground-truth (GT) camera poses for alignment during training, and employs large-angle target view supervision to improve rendering quality under large viewpoint changes [S1, unofficial]. It differs from its parent [Feed-forward Generalizable Reconstruction](16746-feed-forward-generalizable-reconstruction.md) and sibling [DA3-GS](16423-splatt3r.md) by freezing the geometry branch to prevent geometric degradation caused by joint optimization, and by using GT poses to avoid pose errors that misguide the network under large-angle supervision [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $N$ input RGB images $I_C = \{I_i\}_{i \in C}$ and optional pose conditions $Q_C$ (camera intrinsics and poses). In the pose-free setting, $Q_C = \emptyset$ [S1, unofficial].
*   **Outputs:** A set of $M$ 3D Gaussians $\mathcal{G} = \{(\mu_m, \xi_m)\}_{m=1}^M$, where $\mu_m \in \mathbb{R}^3$ is the center and $\xi_m = (\alpha_m, s_m, q_m, c_m)$ contains opacity, three-axis scale, rotation (quaternion), and zeroth-order spherical-harmonic (SH) color [S1, unofficial].

**Data Structures:**
*   **Gaussian Set:** Each Gaussian $m$ is defined by $\mu_m, \alpha_m, s_m, q_m, c_m$.
*   **Hidden State:** A 16-dimensional vector $h$ per Gaussian, updated during Stage II refinement [S1, unofficial].
*   **KNN Graph:** A global graph storing neighbor indices for each Gaussian, used for Stage II feature aggregation [S1, unofficial].

**Parameters:**
*   Voxel merging side length: $0.004$ in the scale-normalized reconstruction frame [S1, unofficial].
*   Opacity pruning threshold: $\tau_\alpha = 0.01$ [S1, unofficial].
*   Mask thresholds: $\tau_{abs} = 0.03$, $\tau_{rel} = 0.01$ [S1, unofficial].
*   Learning rates: Stage I: $10^{-6}$ (last 10 attribute blocks), $2 \times 10^{-4}$ (Gaussian head). Stage II: $2 \times 10^{-4}$ [S1, unofficial].
*   AdamW: $\beta = (0.9, 0.95)$, global batch size 16, L2 gradient clipping at 1.0 [S1, unofficial].

**Algorithm:**

The method consists of two stages. Stage I initializes the scene using a dual-branch architecture. Stage II refines attributes using input-view feedback.

### Stage I: Initialization

1.  **Feature Extraction:**
    Initialize two branches, $\Phi_{geo}$ and $\Phi_{attr}$, from the same pretrained DA3 weights [S1, unofficial].
    *   Freeze $\Phi_{geo}$. Compute predicted depths $\hat{D}$ and cameras $\hat{\Pi}_C$:
        $$ (\hat{D}, \hat{\Pi}_C) = \Phi_{geo}(I_C; Q_C) $$
    *   Fine-tune only the last $K$ Transformer blocks of $\Phi_{attr}$. Compute features $F_C$:
        $$ F_C = \Phi_{attr}(I_C; Q_C) $$
    [S1, unofficial]

2.  **Scale Alignment:**
    To align predicted geometry with GT supervision, fit a scale factor $s_C$ using an Umeyama similarity transform from the GT trajectory to the normalized predicted trajectory, using only input-camera center correspondences [S1, unofficial].
    *   Normalize predicted depths and translations by $s_{norm} > 0$.
    *   Apply scale to translations only, preserving GT intrinsics and reference-relative rotations:
        $$ R^\star_v = R^\star_v, \quad t^\star_v = s_C t^\star_v $$
    [S1, unofficial]

3.  **Point Construction and Pruning:**
    *   Construct initial Gaussian centers $\mu_m$ from normalized predicted $z$-depth, GT intrinsics, and scale-aligned GT poses [S1, unofficial].
    *   Predict initial attributes $\xi_m$ from $F_C$ using a DPT decoder [S1, unofficial].
    *   Perform voxel merging with side length $0.004$ [S1, unofficial].
    *   Prune Gaussians with opacity $\alpha_m < \tau_\alpha = 0.01$ [S1, unofficial].
    *   Let the initial scene be $\mathcal{G}_0$ with $M$ Gaussians [S1, unofficial].

4.  **Rendering and Masking:**
    *   Render $\mathcal{G}_0$ into input views $C$ and target views $T$:
        $$ \hat{I}_v = \mathcal{R}(\mathcal{G}_0; \Pi^\star_v), \quad v \in V = C \cup T $$
        where $\Pi^\star_v$ are the scale-aligned GT poses [S1, unofficial].
    *   Construct visibility masks $M_v$. A target pixel is retained if:
        1.  GT depth $> 10^{-6}$ and passes validity mask.
        2.  At least one input view places it in front of the camera and within bounds.
        3.  $|z_{proj} - d_{src}| \leq \max(\tau_{abs}, \tau_{rel} d_{src})$, where $z_{proj}$ is point depth in input camera and $d_{src}$ is sampled depth [S1, unofficial].

5.  **Stage I Loss:**
    Compute LPIPS spatial distance map $d_v = \text{LPIPS}_{spatial}(M_v \odot \hat{I}_v, M_v \odot I_v)$, zeroing invalid regions before normalization [S1, unofficial].
    Aggregate losses over valid pixels:
    $$ \mathcal{L}_I = \frac{\sum_{v \in V} \sum_{p} M_v(p) [e_v(p) + d_v(p)]}{\max(1, \sum_{v \in V} \sum_{p} M_v(p))} $$
    where $e_v(p)$ is the RGB-channel-averaged absolute error [S1, unofficial].
    Train for 25,000 steps with linear warmup (2,000 steps) and cosine decay [S1, unofficial].

### Stage II: Refinement

1.  **Feature Aggregation:**
    *   Project DPT features to 8 channels via learnable $1 \times 1$ conv, merged using Gaussian voxel groups/weights [S1, unofficial].
    *   Initialize 16-dim hidden state $h$ via linear projection [S1, unofficial].
    *   Concatenate image features, current attributes, gradient feedback, neighbor distances, and hidden states. Project to 64 dims [S1, unofficial].
    *   Process through four KNN Transformer blocks. Each block uses single-head attention over 8 neighbors, LayerNorm, MLP, and residual connections [S1, unofficial].
    *   Concatenate output with input, and use MLP to predict attribute increments $\Delta \xi$ and hidden-state increments $\Delta h$ [S1, unofficial].

2.  **Attribute Updates:**
    *   **Scales:** $s_{new} = s_{old} \exp(\Delta \log s)$ without residual clipping [S1, unofficial].
    *   **Other Attributes:** Opacity-logit, local rotation-vector, and RGB-logit increments use $\text{tanh}(raw)$ scaled by $a \in \{0.1, 0.25, 1.0\}$ respectively. Hidden-state increments use $0.1 \text{tanh}(raw)$ [S1, unofficial].
    *   Clamp logit inputs to $[10^{-6}, 1-10^{-6}]$ [S1, unofficial].
    *   Gaussian centers, counts, and correspondence remain fixed [S1, unofficial].

3.  **Feedback and Loss:**
    *   Render current scene into input views. Compute feedback loss:
        $$ \ell_{fb} = 0.8 \mathcal{L}_1 + 0.2 \mathcal{L}_{DSSIM} $$
        where $\mathcal{L}_{DSSIM} = (1 - \text{SSIM})/2$ over valid regions [S1, unofficial].
    *   Normalize and detach gradients w.r.t. Gaussian attributes before entering the updater [S1, unofficial].
    *   **First-Order Surrogate Loss:** To stabilize training, compute rendering gradients on independent leaf copies $z_k = \text{sg}(x_k)$:
        $$ r_k = \text{sg}(\nabla_z \mathcal{L}_{render}(z_k)) $$
        $$ \mathcal{L}_{kproxy} = \text{sg}(\mathcal{L}_{render}(z_k)) + \langle x_k - \text{sg}(x_k), r_k \rangle $$
        where $x_k$ collects updated log-scale, opacity-logit, local-rotation, and RGB-logit parameters [S1, unofficial].
    *   **Outer Loss:** For each supervised view:
        $$ \ell_{out} = 0.8 \mathcal{L}_1 + 0.2 \mathcal{L}_{DSSIM} + 0.5 \mathcal{L}_{LPIPS} $$
        Input and target views receive weight 0.5 each [S1, unofficial].
    *   **Multi-Step Objective:**
        $$ \mathcal{L}_{II} = \sum_{k=1}^{K_r} 0.9^{K_r-k} \mathcal{L}_{krender} + 0.1 \mathcal{L}_{opacity} $$
        where $\mathcal{L}_{opacity} = \frac{1}{M} \sum_{m=1}^M [\text{logit}_\epsilon(\alpha_{m, K_r}) - \text{logit}_\epsilon(\alpha_{m, 0})]^2$, $\epsilon=10^{-6}$ [S1, unofficial].

4.  **Execution:**
    *   Sample $K_r \in \{1, 2, 3\}$ updates during training; use 3 updates at inference [S1, unofficial].
    *   **Chunked Execution:** Reuse global KNN graph. Sort along longest voxel-coordinate axis. Expand core sets of at most 200,000 points with 4-hop neighborhoods. Recursively bisect chunks exceeding 300,000 points by point count along core sets' longest axes. Retain only core-point outputs. Use gradient checkpointing [S1, unofficial].
    *   Train for 5,000 steps with cosine decay [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def stage_i_init(I_C, Q_C, Phi_geo, Phi_attr, GT_poses, GT_intrinsics):
    """
    Stage I: Initialize Gaussian scene.
    """
    # 1. Feature Extraction
    # Phi_geo is frozen
    D_hat, Pi_hat_C = Phi_geo(I_C, Q_C)
    
    # Phi_attr: only last K blocks fine-tuned
    F_C = Phi_attr(I_C, Q_C)
    
    # 2. Scale Alignment
    # Normalize predicted depths and translations
    D_norm = D_hat / s_norm
    T_norm = Pi_hat_C.t / s_norm
    
    # Fit Umeyama transform from GT trajectory to normalized predicted trajectory
    # using only input-camera center correspondences
    s_C = fit_umeyama_scale(GT_poses.c, T_norm.c)
    
    # Apply scale to translations only
    Pi_star = copy(GT_poses)
    Pi_star.t = s_C * Pi_star.t
    # Rotations and intrinsics remain from GT
    
    # 3. Point Construction
    # Back-project normalized depth using GT intrinsics and scale-aligned GT poses
    mu = back_project(D_norm, GT_intrinsics, Pi_star)
    
    # Predict attributes from features
    xi = DPT_decoder(F_C)
    
    # Voxel merging
    mu, xi = voxel_merge(mu, xi, side_length=0.004)
    
    # Pruning
    mask = xi.alpha > 0.01
    mu = mu[mask]
    xi = xi[mask]
    
    return mu, xi, Pi_star

def stage_ii_refine(mu, xi, I_C, Phi_refiner, KNN_graph, K_r=3):
    """
    Stage II: Refine Gaussian attributes using input-view feedback.
    """
    h = init_hidden_state(xi) # 16-dim vector per Gaussian
    
    for k in range(1, K_r + 1):
        # 1. Feature Aggregation
        # Project features, merge, concatenate with attributes, gradients, neighbors, h
        # Project to 64 dims
        agg_input = prepare_refiner_input(xi, h, KNN_graph)
        
        # Process through 4 KNN Transformer blocks
        delta_xi, delta_h = Phi_refiner(agg_input)
        
        # 2. Attribute Updates
        # Scales
        xi.s = xi.s * torch.exp(delta_xi.log_s)
        
        # Other attributes with tanh scaling
        xi.alpha_logit = clamp(xi.alpha_logit + 0.1 * torch.tanh(delta_xi.alpha_raw), 1e-6, 1-1e-6)
        xi.rot_vec = clamp(xi.rot_vec + 0.25 * torch.tanh(delta_xi.rot_raw), -1, 1) # Assuming local rotation vector
        xi.rgb_logit = clamp(xi.rgb_logit + 1.0 * torch.tanh(delta_xi.rgb_raw), 1e-6, 1-1e-6)
        
        # Hidden state
        h = h + 0.1 * torch.tanh(delta_h)
        
        # 3. Loss Computation (for training)
        # Render scene
        I_rendered = render(mu, xi, I_C_cameras)
        
        # Feedback loss
        L_fb = 0.8 * L1_loss(I_rendered, I_C) + 0.2 * DSSIM_loss(I_rendered, I_C)
        
        # Detach gradients for updater
        grad_xi = normalize_detach_gradients(L_fb, xi)
        
        # Update xi using grad_xi (simplified update rule based on description)
        # In practice, this is handled by the optimizer or explicit update step
        # The description implies a shared updater that uses these gradients
        xi = update_attributes(xi, grad_xi)
        
        # Outer Loss for supervision (using surrogate for stability)
        x_k = get_current_params(xi)
        z_k = x_k.detach() # sg(x_k)
        L_render_zk = render_loss(render(mu, z_k, I_C), I_C)
        r_k = torch.autograd.grad(L_render_zk, z_k, retain_graph=True)[0].detach()
        L_proxy = L_render_zk.detach() + torch.dot(x_k - x_k.detach(), r_k)
        
        # Opacity regularization
        L_opacity = torch.mean((xi.alpha_logit - xi.alpha_logit_initial)**2)
        
        # Total loss for this step
        L_step = 0.9**(K_r-k) * L_proxy + 0.1 * L_opacity
        
        # Backpropagate L_step to Phi_refiner parameters
        L_step.backward()
        
    return xi, h

def fit_umeyama_scale(gt_centers, pred_centers):
    """
    Fit scale factor s_C using Umeyama similarity transform.
    """
    # Center the points
    gt_c = gt_centers - torch.mean(gt_centers, dim=0)
    pred_c = pred_centers - torch.mean(pred_centers, dim=0)
    
    # Compute covariance matrix
    H = torch.mm(gt_c.T, pred_c)
    
    # SVD
    U, S, Vt = torch.linalg.svd(H)
    
    # Scale
    d = torch.ones(3)
    d[-1] = torch.sign(torch.det(torch.mm(Vt.T, U.T)))
    scale = torch.sum(S * d) / torch.sum(torch.square(gt_c))
    
    return scale.item()
```

## Operating characteristics
*   **Time Complexity:** Stage I is dominated by the forward pass of the DA3 backbone and DPT decoder. Stage II involves iterative refinement with KNN graph operations. Chunked execution limits memory usage but adds overhead for sorting and neighborhood computation [S1, unofficial].
*   **Memory Complexity:** Depends on the number of Gaussians $M$. Chunked execution with core sets of at most 200,000 points and 4-hop neighborhoods helps manage memory for large scenes [S1, unofficial].
*   **Performance:** Achieves state-of-the-art mean LPIPS and DISTS on six datasets in both pose-conditioned and pose-free settings. In the pose-conditioned setting, LPIPS and DISTS decrease by 25.8% and 32.9% respectively compared to the strongest baselines [S1, unofficial].
*   **Strengths:** Decoupled geometry and attribute prediction prevents geometric degradation. GT pose alignment avoids pose errors. Large-angle supervision improves rendering under large viewpoint changes. Opacity learning suppresses geometrically inconsistent points [S1, unofficial].
*   **Limitations:** Requires GT camera poses during training for alignment. Pose-free setting relies on reference input cameras for scale estimation and evaluation frame, not reconstruction [S1, unofficial].

## Background
InfiniSplat v2 is a feed-forward Gaussian reconstruction method that improves upon InfiniSplat and DA3-GS. It was introduced to address limitations in Gaussian attribute learning, specifically flying-point artifacts and pose errors under large viewpoint changes [S1, unofficial]. The method builds on the shared principles of feed-forward generalizable reconstruction, mapping input images to 3D Gaussian parameters without per-scene gradient descent [16746-feed-forward-generalizable-reconstruction.md].
