# VRP-UDF Training & Rendering Setup

Also called: UDF-Gaussian Joint Training, Volume Rendering Prior Network

## Overview
This method uses a neural network-based volume rendering prior (VRP) to learn unsigned distance functions (UDFs) and guide 3D Gaussian Splatting optimization by providing dense queries around the UDF zero-level set [S1]. It addresses inaccurate surface reconstruction and depth estimation in Gaussian splatting by regularizing primitives with a differentiable UDF field, ensuring unbiased learning from ground truth UDFs and depths [S1]. Unlike sibling methods like [MVSplat](9213-mvsplat.md), it avoids standard SDF-based normal estimation ambiguities by explicitly excluding normals from the color network input [S1].

## How it works
### Inputs and Outputs
*   **Inputs:** Multi-view images, camera poses, and ground truth unsigned distance values or depth maps [S1].
*   **Outputs:** Optimized 3D Gaussian primitives (position, scale, rotation, opacity, spherical harmonics coefficients) and the learned UDF and color fields [S1].

### Data Structures and Network Layout
The volume rendering prior consists of four MLPs, all utilizing 256 hidden units [S1]:
1.  **Feature Network ($f_{w1}$):** 3 layers. Input: 3D coordinates. Output: feature vectors.
2.  **Weight Network ($f_{w2}$):** 6 layers with skip connections. Input: feature vectors and 3D coordinates. Output: weights for UDF and color prediction.
3.  **UDF Network ($f_u$):** 8 layers with skip connections. Input: feature vectors and 3D coordinates. Output: unsigned distance value. A Softplus activation is applied after the final layer to enforce non-negative outputs ($d \ge 0$) [S1].
4.  **Color Network ($f_c$):** 2 layers. Input: feature vectors and 3D coordinates. Normal vectors are explicitly excluded from the input because normals are ambiguous at the zero-level set due to UDF non-differentiability [S1]. Output: color values.

### Training Schedule and Parameters
The training process runs for 30,000 iterations total [S1]:
1.  **Initial Phase (Iterations 0–9,000):** Standard Gaussian Splatting optimization proceeds without the UDF prior.
2.  **Prior Introduction (Iteration 9,000):** Training of the UDF network ($f_u$) and color network ($f_c$) begins [S1]. The learning rate and decay scheduler for $f_u$ and $f_c$ follow previous works [1, 24], though exact numerical values are not specified [S1].
3.  **Refinement Phase (Iterations 20,000–30,000):** During the final 10,000 iterations, Gaussians are refined by casting rays with a batch size of 2,048, sampling 64 points along each ray [S1]. The UDF and color networks are queried at these points to compute volume rendering losses, which are backpropagated to update both Gaussian parameters and network weights [S1].

### Pseudocode
The following pseudocode outlines the joint training loop. Standard differentiable rendering primitives are assumed; steps not detailed in the sources are marked with comments.

```python
import math

def softplus(x):
    """Enforce non-negative output for UDF as specified in [S1]."""
    return math.log(1 + math.exp(x))

def train_vrp_udf_gaussian(gaussians, cameras, images, total_iterations=30000,
                           udf_start_iter=9000, refinement_start_iter=20000):
    # Initialize MLPs with 256 hidden units as specified in [S1]
    fw1 = MLP(layers=3, hidden=256)
    fw2 = MLP(layers=6, hidden=256, skip_connections=True)
    fu = MLP(layers=8, hidden=256, skip_connections=True)
    fc = MLP(layers=2, hidden=256)

    opt_gaussians = Optimizer(gaussians.parameters())
    opt_networks = Optimizer([fw1, fw2, fu, fc].parameters())

    for iteration in range(1, total_iterations + 1):
        batch_cameras, batch_images = sample_batch(cameras, images)

        # Standard Gaussian Splatting forward pass
        rendered_images, rendered_depths = render_gaussians(gaussians, batch_cameras)
        loss_gs = compute_gaussian_losses(rendered_images, batch_images, rendered_depths)

        if iteration >= udf_start_iter:
            # Sample 64 points along each ray as specified in [S1]
            sample_points = get_sample_points(gaussians, batch_cameras, num_samples=64)

            # Forward passes through prior networks
            features = fw1(sample_points)
            weights = fw2(features, sample_points)
            udf_values = fu(features, sample_points)
            udf_values = softplus(udf_values)  # Enforce non-negativity [S1]
            colors = fc(features, sample_points)  # Normals excluded from input [S1]

            # Compute losses against ground truth UDFs and colors
            loss_udf = compute_udf_loss(udf_values, ground_truth_udfs)
            loss_color = compute_color_loss(colors, ground_truth_colors)

            # Combine losses for backpropagation
            total_loss = loss_gs + loss_udf + loss_color

            opt_networks.zero_grad()
            opt_gaussians.zero_grad()
            total_loss.backward()
            opt_networks.step()
            opt_gaussians.step()
        else:
            opt_gaussians.zero_grad()
            loss_gs.backward()
            opt_gaussians.step()

# Minimal definitions for standard operations to ensure self-contained validity
class MLP:
    def __init__(self, layers, hidden, skip_connections=False):
        self.layers = layers
        self.hidden = hidden
        self.skip_connections = skip_connections
    def __call__(self, x, *args):
        # Standard linear transformation with activation; skip connections handled internally
        return x

class Optimizer:
    def __init__(self, params):
        self.params = params
    def zero_grad(self):
        for p in self.params: p.grad = 0.0
    def step(self):
        for p in self.params: p.data -= 0.001 * p.grad

def sample_batch(cameras, images): return cameras[:1], images[:1]
def render_gaussians(gaussians, cameras): return [], []
def compute_gaussian_losses(rendered, target, depth): return 0.0
def get_sample_points(gaussians, cameras, num_samples): return []
```

### Edge Cases and Pitfalls
*   **Normal Ambiguity:** Normal vectors must not be included in the input to the color network ($f_c$) because the gradient is non-differentiable at the zero-level set of a UDF, making normals ambiguous and degrading color prediction [S1].
*   **Sampling Inaccuracies:** Random hierarchical sampling and the ill-defined nature of UDF fields near surfaces cause rendering inaccuracies, a common issue across volume rendering frameworks that leads to depth discrepancies even with theoretically unbiased mappings [S1].
*   **Convergence Parameters:** Excessively large convergence parameters (e.g., the "flip factor" in NeuralUDF) cause the UDF to flip into an SDF prematurely before the true surface, resulting in depth rendering errors [S1].

## Operating characteristics
*   **Time Complexity:** The method adds significant computational overhead during the refinement phase due to forward passes through four MLPs ($f_{w1}, f_{w2}, f_u, f_c$) for every sample point [S1]. Training is fixed at 30,000 iterations, with the prior active for the latter 21,000 iterations [S1].
*   **Memory Complexity:** Memory usage increases due to the storage of the four MLPs (19 layers total with 256 hidden units) and the gradients for both the Gaussians and the networks [S1].
*   **Performance:** The method achieves the best accuracy among tested renderers for UDFs and SDFs [S1]. It outperforms baselines like NeUDF and VRPrior on complex indoor scenes and thin structures (e.g., eggshells, plant branches) [S1].
*   **Limitations:** Practical inaccuracies persist due to sampling noise and UDF ill-definition near surfaces [S1]. It may struggle to capture extremely thin structures completely without advanced extraction techniques [S1].

## Background
The VRP-UDF method originates from the paper "VRP-UDF: Toward Unbiased Learning of Unsigned Distance Functions From Multi-View Images With Volume Rendering Priors" [S1]. It builds on differentiable volume rendering and UDF learning, extending them to 3D Gaussian Splatting [S1]. The approach addresses limitations in previous UDF-based methods, specifically premature flipping and normal ambiguity, to enable high-fidelity reconstruction [S1]. It is applied to tasks requiring precise geometric details from multi-view images, such as digital heritage and complex indoor scene reconstruction [S1].
