# GaussianHair

Also called: Gaussian Hair Scattering Model

## Overview
GaussianHair is a strand-aware hair rendering method that combines the Marschner Hair Model with Unreal Engine 4’s real-time hair rendering pipeline to create the Gaussian Hair Scattering Model [S2, unofficial]. It uses a hybrid strand + Gaussian Splat (GS) representation to capture complex hair geometry and appearance, enabling fast rasterization and volumetric rendering [S1, unofficial][S2, unofficial]. It is distinguished from general GS variants by its specific focus on hair topology and physically-based scattering, enabling applications such as editing and relighting [S2, unofficial].

## Subtopics

### Marschner Hair Model
A physically-based model for hair appearance that defines light scattering, transmission, and reflection within hair fibers [S2, unofficial]. It provides the optical foundation for the scattering component of GaussianHair [S2, unofficial].

### UE4 Real-Time Hair Rendering
A rendering technique for real-time hair in Unreal Engine 4 that provides the performance optimization framework for GaussianHair [S2, unofficial].
