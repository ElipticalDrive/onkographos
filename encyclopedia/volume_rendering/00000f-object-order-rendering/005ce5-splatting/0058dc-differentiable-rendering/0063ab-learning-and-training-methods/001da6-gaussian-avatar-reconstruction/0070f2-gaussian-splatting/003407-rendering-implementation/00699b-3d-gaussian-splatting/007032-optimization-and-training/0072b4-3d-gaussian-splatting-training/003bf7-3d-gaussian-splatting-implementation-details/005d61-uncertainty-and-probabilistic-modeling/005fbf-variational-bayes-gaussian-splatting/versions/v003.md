# Variational Bayes Gaussian Splatting


## Overview
Variational Bayes Gaussian Splatting (VBGS) frames the training of Gaussian splats as variational inference over the parameters of a Gaussian Mixture Model (GMM), rather than optimizing for a maximum likelihood solution via backpropagation [S1, unofficial]. By leveraging the conjugacy properties of multivariate Gaussians, VBGS derives closed-form update rules that enable continual learning from sequentially streamed 2D and 3D data without catastrophic forgetting or the need for replay buffers [S1, unofficial]. Unlike [3D Gaussian Splatting](17380-3d-gaussian-splatting.md) which relies on gradient-based optimization through a differentiable renderer, VBGS models a distribution over all features and parameters, allowing for efficient, order-invariant updates from partial observations [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A stream of observed data points $x_n = (s_n, c_n)$, where $s_n$ is the spatial coordinate (2D for images, 3D for point clouds) and $c_n$ is the color (RGB). For 3D data, RGBD data is required [S1, unofficial].
*   **Outputs:** The variational posterior distributions $q(z, \mu_s, \Sigma_s, \mu_c, \Sigma_c, \pi)$ over the mixture component assignments and Gaussian parameters.

**Data Structures:**
Each Gaussian component $k$ is represented by the natural parameters of its variational posterior distributions. The method uses 29 parameters per component to represent the Normal-Inverse-Wishart (NIW) likelihoods for color and position, and the Dirichlet prior for assignments [S1, unofficial].

*   **Spatial Parameters ($q(\mu_{k,s}, \Sigma_{k,s})$):** Modeled as NIW.
    *   Natural parameter $\eta_{0,s} = (\kappa_{0,s} \cdot m_{0,s}, V_{0,s} + \kappa_{0,s} \cdot m_{0,s} \cdot m_{0,s}^T)$
    *   Natural parameter $\nu_{0,s} = (\kappa_{0,s}, n_{0,s} + D_s + 1)$
    *   Where $m_{0,s}$ is the mean, $\kappa_{0,s}$ is the concentration, $n_{0,s}$ is degrees of freedom, $V_{0,s}$ is the inverse scale matrix, and $D_s$ is the dimensionality of space ($D_s=2$ or $3$).
*   **Color Parameters ($q(\mu_{k,c}, \Sigma_{k,c})$):**
    *   The mean $\mu_{k,c}$ is modeled as Normal.
    *   The covariance $\Sigma_{k,c}$ is fixed using a Delta distribution $\Delta(\epsilon I)$ to prevent color blending [S1, unofficial].
    *   Natural parameter $\eta_{0,c} = (\kappa_{0,c} \cdot m_{0,c}, V_{0,c} + \kappa_{0,c} \cdot m_{0,c} \cdot m_{0,c}^T)$
    *   Natural parameter $\nu_{0,c} = (\kappa_{0,c}, n_{0,c} + D_c + 1)$ (Note: $n_{k,c}$ and $V_{k,c}$ are kept fixed due to the Delta distribution).
*   **Assignment Parameters ($q(\pi)$):** Modeled as Dirichlet with natural parameter $\eta_{0,z} = \alpha$.
*   **Assignment Probabilities ($q(z_n)$):** Categorical distribution with parameters $\gamma_n$.

**Algorithm Steps:**
The training is implemented as Coordinate Ascent Variational Inference (CAVI), decomposed into two steps: computing model assignments and computing parameter updates [S1, unofficial].

1.  **Compute Assignments (E-step equivalent):**
    For each data point $n$ and component $k$, compute the unnormalized log-probability $\hat{\gamma}_n$:
    $$ \log \hat{\gamma}_{n,k} = \mathbb{E}_{q(\mu_{k,s}, \Sigma_{k,s})} [\log p(s_n | \mu_{k,s}, \Sigma_{k,s})] + \mathbb{E}_{q(\mu_{k,c}, \Sigma_{k,c})} [\log p(c_n | \mu_{k,c}, \Sigma_{k,c})] + \mathbb{E}_{q(\pi)} [\log p(z_n=k)] $$
    Normalize to get $\gamma_{n,k}$:
    $$ \gamma_{n,k} = \frac{\hat{\gamma}_{n,k}}{\sum_{j} \hat{\gamma}_{n,j}} $$
    The expectations for the MVN log-likelihoods under NIW posteriors are computed using standard variational inference identities [S1, unofficial].

2.  **Update Parameters (M-step equivalent):**
    Update the natural parameters of the posteriors by aggregating the prior natural parameters with the data sufficient statistics weighted by the assignments $\gamma_{n,k}$:
    $$ \eta_{k} = \eta_{0,k} + \sum_{n \in D} \gamma_{n,k} T(x_n) $$
    $$ \nu_{k} = \nu_{0,k} + \sum_{n \in D} \gamma_{n,k} $$
    Where $T(x_n)$ are the sufficient statistics ($T(s_n) = (s_n, s_n s_n^T)$ and $T(c_n) = (c_n, c_n c_n^T)$) [S1, unofficial].

3.  **Continual Learning and Reassignment:**
    *   Updates are order-invariant. Assignments $q(z)$ are always computed with respect to the *initial* posterior over parameters, ensuring components without prior assignments can still model data and avoiding catastrophic forgetting [S1, unofficial].
    *   **Reassignment:** To mitigate poor coverage in streaming settings, a fraction of unused components (those where concentration parameters $\alpha_k$ equal their prior value) are reassigned. The means of $n$ components (where $n$ is a fraction, e.g., 0.01 or 0.05, of unused components) are replaced by the location and color of data points sampled proportional to the negative ELBO [S1, unofficial]. After reassignment, CAVI is run again.

4.  **Rendering:**
    *   For 3D rendering, the 3D renderer from Kerbl et al. [2023] is used [S1, unofficial].
    *   Since VBGS does not optimize on image reconstruction, standard alpha blending is not sensible. The alpha value for all Gaussians is set to 1, making all components opaque [S1, unofficial].
    *   The spatial component is projected to the image plane, and color values are combined via alpha blending along a casted ray using the estimated depth for occlusion handling [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def vbgs_update(data_points, components, hyperparams):
    """
    Performs one CAVI step for VBGS.
    
    Args:
        data_points: Array of shape (N, D_s + D_c) containing (s_n, c_n).
        components: List of component objects containing current natural parameters.
        hyperparams: Dict containing epsilon, reassign_fraction, etc.
        
    Returns:
        Updated components and assignment probabilities.
    """
    N = data_points.shape[0]
    K = len(components)
    
    # 1. Compute Assignments
    # Initialize log probabilities
    log_gamma = np.zeros((N, K))
    
    for k in range(K):
        comp = components[k]
        
        # Extract NIW parameters for spatial
        # eta_s = (kappa_s * m_s, V_s + kappa_s * m_s * m_s^T)
        # nu_s = (kappa_s, n_s + D_s + 1)
        # We need expectations E[log p(s|mu, Sigma)] under NIW
        # Standard identity: E[log N(x|mu, Sigma)] = ...
        # For brevity, assume helper function computes this expectation
        exp_log_p_s = compute_mvn_expectation(data_points[:, :D_s], comp.mu_s, comp.Sigma_s)
        
        # Extract parameters for color
        # Color covariance is fixed Delta(epsilon I)
        # Expectation for color is log N(c|mu, epsilon I)
        exp_log_p_c = compute_mvn_expectation(data_points[:, D_s:], comp.mu_c, hyperparams['epsilon'] * np.eye(D_c))
        
        # Expectation for log Dirichlet (log pi_k)
        # E[log pi_k] = psi(alpha_k) - psi(sum(alpha))
        exp_log_pi = compute_dirichlet_log_expectation(comp.alpha)
        
        # Combine
        log_gamma[:, k] = exp_log_p_s + exp_log_p_c + exp_log_pi
        
    # Normalize
    log_gamma_max = np.max(log_gamma, axis=1, keepdims=True)
    log_gamma -= log_gamma_max # Numerical stability
    gamma_hat = np.exp(log_gamma)
    gamma = gamma_hat / np.sum(gamma_hat, axis=1, keepdims=True)
    
    # 2. Update Parameters
    for k in range(K):
        comp = components[k]
        
        # Sufficient statistics for spatial
        s_data = data_points[:, :D_s]
        T_s = np.stack([s_data, np.einsum('ni,nj->nij', s_data, s_data)], axis=1) # Shape (N, 2, D_s, D_s) or similar structure
        
        # Update natural parameters
        # eta_new = eta_0 + sum(gamma * T(x))
        # nu_new = nu_0 + sum(gamma)
        
        # Spatial Update
        comp.eta_s = comp.eta_s_0 + np.sum(gamma[:, k:k+1] * T_s, axis=0)
        comp.nu_s = comp.nu_s_0 + np.sum(gamma[:, k:k+1], axis=0)
        
        # Color Update
        c_data = data_points[:, D_s:]
        T_c = np.stack([c_data, np.einsum('ni,nj->nij', c_data, c_data)], axis=1)
        
        comp.eta_c = comp.eta_c_0 + np.sum(gamma[:, k:k+1] * T_c, axis=0)
        comp.nu_c = comp.nu_c_0 + np.sum(gamma[:, k:k+1], axis=0)
        
        # Dirichlet Update
        # T(x) = 1 for assignment
        comp.alpha = comp.alpha_0 + np.sum(gamma[:, k:k+1], axis=0)
        
    # 3. Reassignment (if needed)
    # Identify unused components (alpha_k == alpha_0)
    unused_indices = np.where(np.all(components[k].alpha == components[k].alpha_0 for k in range(K)))[0]
    if len(unused_indices) > 0:
        n_reassign = int(hyperparams['reassign_fraction'] * len(unused_indices))
        if n_reassign > 0:
            # Sample n_reassign unused components
            reassign_indices = np.random.choice(unused_indices, n_reassign, replace=False)
            
            # Sample data points proportional to negative ELBO
            # ELBO contribution for point n and component k is log_gamma[n, k]
            # Negative ELBO -> higher probability for points with low log_gamma
            neg_elbo = -log_gamma
            probs = np.exp(neg_elbo - np.max(neg_elbo, axis=1, keepdims=True))
            probs = probs / np.sum(probs, axis=1, keepdims=True)
            
            # Sample data points
            data_indices = np.random.choice(N, n_reassign, p=np.mean(probs, axis=1))
            
            for i, k in enumerate(reassign_indices):
                comp = components[k]
                point = data_points[data_indices[i]]
                s_point = point[:D_s]
                c_point = point[D_s:]
                
                # Reset means to data point
                # Update natural parameters to reflect this strong prior on mean
                # Effectively setting kappa to a large value or just setting mean
                # The paper says "replace means... with location and color"
                # We update the NIW parameters to center on this point
                comp.mu_s = s_point
                comp.mu_c = c_point
                # Reset other parameters to prior or adjust kappa to reflect certainty?
                # Paper implies resetting to prior for unused components, then updating.
                # Here we just set mean and keep prior covariance structure but update natural params
                comp.eta_s = (hyperparams['kappa_0'] * s_point, hyperparams['V_0'] + hyperparams['kappa_0'] * np.outer(s_point, s_point))
                comp.nu_s = (hyperparams['kappa_0'], hyperparams['n_0'] + D_s + 1)
                
                comp.eta_c = (hyperparams['kappa_0'] * c_point, hyperparams['V_0'] + hyperparams['kappa_0'] * np.outer(c_point, c_point))
                comp.nu_c = (hyperparams['kappa_0'], hyperparams['n_0'] + D_c + 1)
                
                comp.alpha = hyperparams['alpha_0'] # Reset Dirichlet
                
    return components, gamma

def compute_mvn_expectation(data, mean, cov):
    """
    Computes E[log N(x|mu, Sigma)] for a batch of data points.
    Formula: -0.5 * D * log(2*pi) - 0.5 * log|Sigma| - 0.5 * sum_i (x_i - mu)^T Sigma^-1 (x_i - mu)
    """
    D = data.shape[1]
    log_det = np.linalg.slogdet(cov)[1]
    inv_cov = np.linalg.inv(cov)
    
    diff = data - mean
    mahal = np.sum(diff @ inv_cov * diff, axis=1)
    
    return -0.5 * D * np.log(2 * np.pi) - 0.5 * log_det - 0.5 * mahal

def compute_dirichlet_log_expectation(alpha):
    """
    Computes E[log alpha_k] for Dirichlet(alpha).
    """
    psi_alpha = np.vectorize(lambda x: scipy.special.digamma(x))(alpha)
    psi_sum_alpha = scipy.special.digamma(np.sum(alpha))
    return psi_alpha - psi_sum_alpha
```

## Operating characteristics
*   **Time Complexity:** Model assignment computation is $O(nm)$, where $n$ is the number of data points and $m$ is the number of Gaussian components. Parameter update computation is $O(n)$ [S1, unofficial].
*   **Memory Complexity:** Memory requirements are increased by a factor of 2 compared to the gradient baseline (3DGS) for the same number of Gaussians, due to representing a distribution over parameters (29 parameters per component vs. 14 in 3DGS) [S1, unofficial].
*   **Performance:** On the Tiny ImageNet validation set, VBGS wall-clock time is $0.03 \pm 0.03$ s compared to Gradient $0.05 \pm 0.02$ s (NVIDIA GeForce RTX 4090) [S1, unofficial]. In 3D continual learning on Blender dataset, VBGS (Random Init) average reconstruction error is $11.19 \pm 3.53$ dB, while Gradient (Random Init) is $21.26 \pm 1.76$ dB [S1, unofficial].
*   **Strengths:** Enables continual learning without catastrophic forgetting; no replay buffers needed; faster than gradient baseline when all data fits in memory; robust to streaming data.
*   **Limitations:** Relies on RGBD data rather than just RGB; memory intensive; in large-scale 3D datasets, batched processing is necessary, which reduces the competitive advantage in update speed [S1, unofficial].

## Background
VBGS was proposed as a novel approach to optimize Gaussian splats by framing training as variational inference over model parameters [S1, unofficial]. It addresses the limitation of backpropagation-based methods like 3DGS, which struggle with catastrophic forgetting when dealing with continuous streams of data [S1, unofficial]. The method leverages the conjugacy properties of multivariate Gaussians (Normal-Inverse-Wishart and Dirichlet) to derive closed-form update rules [S1, unofficial]. It is particularly suited for applications requiring real-time adaptation and learning, such as autonomous navigation, augmented reality, and robotics [S1, unofficial].
