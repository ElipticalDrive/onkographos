# Semantic and Language Embeddings

Also called: SAM-guided Gaussian Grouping

## Overview
This family extends 3D Gaussian Splatting by attaching high-dimensional feature vectors $\mathbf{f}_i$ to each Gaussian primitive, enabling the rendering of semantic, linguistic, or latent feature maps rather than just color [S1, unofficial][S2]. It solves the problem of integrating 2D vision-language models (e.g., CLIP, LSeg) into a 3D representation, allowing for real-time open-vocabulary semantic segmentation and phrase grounding [S1, unofficial]. It differs from sibling methods like [Human and Articulated Avatars](8209-human-and-articulated-avatars.md) by focusing on semantic understanding and language queryability rather than deformation and animation, building on the shared principles of [Semantic and Structural Extensions](17384-semantic-and-structural-extensions.md).

## Shared principles
All methods in this family rely on the differentiable alpha-blending accumulation of feature vectors during the rasterization step. For a pixel $p$, the rendered vector $\mathbf{V}(p)$ is computed by sorting overlapping Gaussians $\mathcal{O}_p$ front-to-back and applying:

$$
\mathbf{V}(p) = \sum_{i \in \mathcal{O}_p} \mathbf{v}_i \cdot \alpha_i \cdot \prod_{j=1}^{i-1} (1 - \alpha_j)
$$

where:
*   $\mathbf{v}_i$ is the feature vector $\mathbf{f}_i \in \mathbb{R}^d$ of the $i$-th Gaussian.
*   $\alpha_i$ is the opacity of the $i$-th Gaussian.
*   $\prod_{j=1}^{i-1} (1 - \alpha_j)$ is the transmittance from all preceding Gaussians $j < i$.
*   If $\mathcal{O}_p$ is empty, $\mathbf{V}(p) = \mathbf{0}$.

The feature vectors $\mathbf{f}_i$ are optimized during training via photometric loss or distillation losses from teacher networks (e.g., NeRFs or VLMs) to align with semantic or language spaces [S1, unofficial].

## Subtopics

### [3D Gaussian Splatting with Feature Vectors](8060-3d-gaussian-splatting-with-feature-vectors.md)
Extends 3DGS by attaching feature vectors $\mathbf{f}_i$ to enable rendering of semantic/latent maps. It serves as the foundational rasterization mechanism for the family, hard-coding alignment between geometry and semantics to eliminate boundary bleeding.

### [Language Embedded 3D Gaussians](8103-language-embedded-3d-gaussians.md)
Encodes object-level embeddings for phrase grounding in addition to pixel-level features, enabling zero-shot semantic reasoning by querying rendered maps with natural language.

### [LangSplat](8104-langsplat.md)
Pioneers real-time open-vocabulary segmentation by rendering feature maps compared against CLIP text embeddings. It learns a scene-specific latent space via an autoencoder to align with natural language, operating in text-embedding space using inner products.

### [3D Vision-Language GS](8105-3d-vision-language-gs.md)
Enables 3D visual question answering by training a joint embedding space. It focuses on querying the continuous feature field with natural language for open-vocabulary segmentation and reasoning, distinct from object-level grounding.

### [Text Embedding Generation with Directional Views](8239-text-embedding-generation-with-directional-views.md)
Encodes text prompts into latent embeddings using a frozen CLIP text encoder and generates directional view embeddings by appending view descriptors (e.g., "front view") to prompts, solving view-dependent semantic grounding.

### [LSeg Feature Encoding](12078-lseg-feature-encoding.md)
Utilizes the LSeg zero-shot segmentation model as a teacher to distill semantic features into a 3D neural representation, solving the need for per-scene manual annotations by leveraging pretrained vision-language models.

### [VLM-Augmented Segmentation](15758-vlm-augmented-segmentation.md)
Augments 3D Gaussians with compact language features distilled from a medical VLM via a scene-specific autoencoder. It reduces memory consumption compared to explicit high-dimensional modeling and focuses on volumetric consistency.

### CLIP-Based 3D Model Search
Searches a database of 3D models (3D-FUTURE) to find assets matching segmented objects in an input image using CLIP embeddings [S2]. It encodes all renderings from the 3D-FUTURE database (10,000+ artist-made models) into normalized 768-dimensional vectors using CLIP [S2]. To search for an appropriate model, it crops a target image around each object's mask from the input image, encodes the crop using CLIP, and selects Nearest Neighbors using cosine distance in CLIP space to find the closest assets [S2].

## Background
The integration of semantic and language embeddings into 3D Gaussian Splatting emerged to bridge the gap between geometric reconstruction and high-level scene understanding. Early works like Feature-3DGS and LangSplat demonstrated that per-Gaussian feature vectors could be optimized to align with 2D vision-language models like CLIP and LSeg, enabling open-vocabulary segmentation without explicit 3D annotations [S1, unofficial]. Subsequent methods such as LE3DG and 3D Vision-Language GS refined this by introducing object-level grounding and joint embedding spaces for reasoning [S1, unofficial]. The family also includes specialized approaches for view-dependent semantics [S1, unofficial][S2] and domain-specific applications like medical imaging [S1, unofficial].
