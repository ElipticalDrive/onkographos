# Mipmap-GS

Also called: Mipmap-Gaussian Splatting

## Overview
Mipmap-GS is a test-time adaptation method that deforms pre-trained 3D Gaussian primitives to resolve aliasing artifacts (zoom-in spikes and zoom-out thickness) caused by fixed Gaussian distributions at varying zoom factors [S1]. Unlike sibling methods that apply post-processing filters or hierarchical level-of-detail selection, Mipmap-GS self-adjusts primitive properties (color, shape, size) and distribution (position) by optimizing against scale-specific mipmap-like pseudo ground-truth, effectively informing the Gaussians of the new sampling rate [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $K$ base 3D Gaussians $\{G_k\}_{k=1}^K$ trained at basic scale ($\times 1$), a set of novel viewpoints $\{V_j\}_{j=1}^J$, and a target zoom factor $N$.
*   **Output:** A set of optimized, scale-adaptive Gaussians $\{G^{opt}_k\}_{k=1}^K$ [S1].

**Data Structures:**
The method operates on the standard 3DGS primitive representation [G]. Each Gaussian $G_k$ is defined by:
*   Mean position $\mu_k \in \mathbb{R}^3$.
*   Covariance $\Sigma_k \in \mathbb{R}^{3 \times 3}$, parameterized by rotation $R_k$ and scale $S_k$.
*   Opacity $\alpha_k \in [0, 1]$.
*   Color coefficients $c_k$ (typically spherical harmonics).
No additional data structures (e.g., trees, graphs) are introduced; the method modifies the attributes of the existing flat list of Gaussians [S1].

**Parameters:**
*   $N$: The zoom factor. For zoom-in, $N > 1$ (upsampling by $\times N$). For zoom-out, $N < 1$ (downsampling by $\times 1/N$) [S1].
*   $S$: The number of adaptation iterations. Typically $S = 1000$ (1K iterations) [S1].
*   $\beta$: The learning rate for the optimization step [S1].
*   $r(x)$: The mipmap resizing function. For zoom-in, super-resolution methods like SwinIR are used [S1]. For zoom-out, bilinear interpolation is used [S1].

**Algorithm:**
The method constructs a mipmap-like pseudo ground-truth from the base rendering and optimizes the Gaussians to match this target at the new scale.

1.  **Base Rendering:** Render the base Gaussians $\{G_k\}$ at the basic scale ($\times 1$) for a randomly selected viewpoint $v_j$ to obtain the base image $\hat{x}_j$ [S1].
2.  **Pseudo-GT Construction:** Apply the resizing function $r(\cdot)$ to $\hat{x}_j$ to generate the scale-specific pseudo ground-truth $r(\hat{x}_j)$.
    *   If zooming in ($N > 1$), upsample $\hat{x}_j$ by $\times N$ using a super-resolution network (e.g., SwinIR) [S1].
    *   If zooming out ($N < 1$), downsample $\hat{x}_j$ by $\times 1/N$ using bilinear interpolation [S1].
3.  **Adaptive Rendering:** Render the current set of optimized Gaussians $\{G^{opt}_k\}$ (initially identical to $\{G_k\}$) at the new scale to produce the rendered image $x_j$ [S1].
4.  **Loss Calculation:** Compute the scale-aware guidance loss $L$ between the rendered image $x_j$ and the pseudo ground-truth $r(\hat{x}_j)$ using the L2 norm [S1]:
    $$ L(x_j, r(\hat{x}_j)) = \| x_j - r(\hat{x}_j) \|_2 $$
5.  **Optimization Step:** Update the Gaussian parameters $\{G^{opt}_k\}$ using gradient descent [S1]:
    $$ G^{opt} = G - \beta \nabla L(x, r(\hat{x})) $$
    where $G$ represents the current parameters of the optimized Gaussians [S1].
6.  **Pruning:** Every 100 iterations ($i \mod 100 == 0$), perform active densify or prune operations to maintain a compact representation. This active pruning continues throughout the entire optimization process, unlike standard 3DGS which stops pruning halfway [S1].
7.  **Termination:** Repeat steps 1-6 for $S$ iterations (typically 1000). The deformation from base Gaussians to optimized Gaussians is completed within these iterations [S1].

**Pseudocode:**
```python
def mipmap_gs_optimize(base_gaussians, viewpoints, zoom_factor, iterations=1000, learning_rate=0.01):
    """
    Deforms base 3D Gaussians to be adaptive for a specific zoom scale.
    
    Args:
        base_gaussians: List of Gaussian primitives {G_k} trained at scale x1.
        viewpoints: List of novel viewpoints {V_j}.
        zoom_factor: N. >1 for zoom-in, <1 for zoom-out.
        iterations: S, number of optimization steps.
        learning_rate: beta.
        
    Returns:
        optimized_gaussians: List of deformed Gaussian primitives {G_opt_k}.
    """
    # Initialize optimized Gaussians as a copy of base Gaussians
    optimized_gaussians = copy(base_gaussians)
    
    # Define resizing function r(x) based on zoom direction
    if zoom_factor > 1:
        # Zoom-in: Upsample using super-resolution (e.g., SwinIR)
        resize_func = super_resolution_upsample # e.g., SwinIR
    else:
        # Zoom-out: Downsample using bilinear interpolation
        resize_func = bilinear_downsample
        
    for i in range(iterations):
        # 1. Select a random viewpoint
        v_j = random_choice(viewpoints)
        
        # 2. Render base Gaussians at basic scale (x1)
        # This produces the base image x_hat_j
        x_hat_j = render_gaussians(base_gaussians, v_j, scale=1.0)
        
        # 3. Construct mipmap-like pseudo-GT
        # Apply resizing function to create scale-specific target
        pseudo_gt = resize_func(x_hat_j, zoom_factor)
        
        # 4. Render optimized Gaussians at the new scale
        # This produces the current rendered image x_j
        x_j = render_gaussians(optimized_gaussians, v_j, scale=zoom_factor)
        
        # 5. Calculate Loss: L2 distance between rendered image and pseudo-GT
        loss = l2_loss(x_j, pseudo_gt)
        
        # 6. Optimize Gaussians
        # Compute gradients of loss w.r.t Gaussian parameters
        gradients = compute_gradients(loss, optimized_gaussians)
        
        # Update parameters: G_opt = G - beta * grad(L)
        optimized_gaussians = apply_gradient_descent(optimized_gaussians, gradients, learning_rate)
        
        # 7. Active Pruning every 100 iterations
        if i % 100 == 0:
            optimized_gaussians = densify_and_prune(optimized_gaussians)
            
    return optimized_gaussians
```

**Edge Cases and Pitfalls:**
*   **Zoom-in Spikes:** Caused by varying shrinkage bias leading to confusion during accumulation when sampling rates change. The method addresses this by deforming Gaussians to match the higher sampling rate [S1].
*   **Zoom-out Thickness:** Caused by constant dilation leading to excessively wide coverage and thick structures. The method addresses this by deforming Gaussians to match the lower sampling rate [S1].
*   **High-Frequency Loss:** Unlike Mip-Splatting which uses heuristic 2D/3D smoothing filters that suppress high-frequency components, Mipmap-GS preserves finer details by deriving pseudo-GT on the fly [S1].

## Operating characteristics
*   **Time Complexity:** The method requires $S$ iterations of optimization. Each iteration involves rendering at two scales (base and target) and a resize operation. The deformation converges within 1K iterations, which is approximately 3% of the iterations required for training from scratch [S1].
*   **Memory Complexity:** The method does not introduce new hierarchical data structures. It modifies the attributes of the existing $K$ Gaussians. Active pruning during optimization reduces the final number of Gaussians, particularly for zoom-out scenarios, leading to a more compact representation than standard 3DGS [S1].
*   **Performance:** On the NeRF Synthetic dataset, Mipmap-GS outperforms standard 3DGS in PSNR by an average of 9.25 dB for zoom-in and 10.40 dB for zoom-out [S1].
    *   At $\times 1/2$ zoom-out on NeRF Synthetic: SSIM 0.971, PSNR 32.71, LPIPS 0.026 (vs. 3DGS SSIM 0.951, PSNR 27.14, LPIPS 0.031) [S1].
    *   At $\times 1/2$ zoom-out on Mip-NeRF 360: SSIM 0.854, PSNR 28.57 (vs. 3DGS SSIM 0.774, PSNR 26.66) [S1].
*   **Strengths:** Plug-in module applicable to any 3DGS model; solves aliasing essentially by informing the new sampling rate rather than filtering; preserves high-frequency details; compact representation via active pruning.
*   **Limitations:** Requires test-time optimization (1K iterations) for each new zoom factor; relies on the quality of the super-resolution network for zoom-in upsampling [S1].

## Background
Mipmap-GS was proposed to address the severe aliasing or blurriness in 3D Gaussian Splatting when zooming in or out, a problem arising from the mismatch between fixed Gaussian distributions and varying pixel coverage [S1]. Traditional methods like Mip-Splatting use heuristic filters, while Octree-GS uses hierarchical level-of-detail, but neither adapts the source signal itself [S1]. Mipmap-GS introduces a unified optimization method that makes Gaussians adaptive for arbitrary scales by self-adjusting primitive properties and distribution using scale-specific mipmap-like pseudo ground-truth [S1]. It is published in the 2025 IEEE International Conference on 3D Vision (3DV) [S1].
