# 3D Half-Gaussian Splatting Covariance Transformation and Regularization

Also called: 3D-HGS

## Overview
This method regularizes 3D Gaussian kernels into "half-Gaussians" by transforming their covariance matrices to align with local surface normals, effectively modeling sharp transitions between object surfaces and empty space [S1]. It sets itself apart from sibling methods like [Geometry Regularization](14222-geometry-regularization.md) by explicitly enforcing a planar cut in the covariance structure rather than just penalizing geometric deviations, resulting in kernels that behave like surfels [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The standard 3D Gaussian parameters: center $\mathbf{c}$, rotation matrix $\mathbf{R}$, scale vector $\mathbf{s}$, opacity $\alpha$, and color $\mathbf{c}_{color}$. The covariance matrix $\Sigma$ is derived from $\mathbf{R}$ and $\mathbf{s}$ as $\Sigma = \mathbf{R} \mathbf{S} \mathbf{S}^T \mathbf{R}^T$, where $\mathbf{S}$ is a diagonal matrix of scales [S1].
*   **Output:** A regularized covariance matrix $\sigma$ that represents a half-Gaussian, and adjusted opacity parameters.

**Data Structures:**
The method operates on $3 \times 3$ symmetric covariance matrices. The transformation constructs a local basis matrix.

**Algorithm Steps:**
The regularization is applied to the covariance matrix $\Sigma$ to produce $\sigma$. This process is performed every 5000 iterations [S1].

1.  **Compute Local Basis:**
    Let $\mathbf{n}$ be the normal vector associated with the Gaussian (typically derived from the gradient of the scene or a surface estimate). Normalize it:
    $$ \mathbf{n} \leftarrow \mathbf{n} / \|\mathbf{n}\| $$
    Construct two orthogonal vectors $\mathbf{v}_1$ and $\mathbf{v}_2$ to form a basis aligned with $\mathbf{n}$:
    *   If $n_x = 0$ and $n_y = 0$:
        $$ \mathbf{v}_1 = (1, 0, 0) $$
        $$ \mathbf{v}_2 = (0, 1, 0) $$
    *   Else:
        $$ \mathbf{v}_1 \leftarrow (n_y, -n_x, 0) / \|(n_y, -n_x, 0)\| $$
        $$ \mathbf{v}_2 \leftarrow \mathbf{n} \times \mathbf{v}_1 / \|\mathbf{n} \times \mathbf{v}_1\| $$
    Concatenate these vectors to form the basis matrix $\mathbf{B}$:
    $$ \mathbf{B} = [\mathbf{v}_1, \mathbf{v}_2, \mathbf{n}] $$

2.  **Transform Covariance to Basis Space:**
    Project the original covariance $\Sigma$ into the basis coordinate system:
    $$ \text{cov} \leftarrow \mathbf{B}^T \Sigma \mathbf{B} $$
    Here, $\text{cov}$ is a $3 \times 3$ matrix where the element at index $[i, j]$ corresponds to the covariance component along the $i$-th and $j$-th basis vectors.

3.  **Compute Modified Diagonal and Off-Diagonal Elements:**
    Calculate the regularized components $a'$, $b'$, and $c'$ by removing the influence of the normal direction (index 2) from the tangential plane (indices 0 and 1):
    $$ a' \leftarrow \text{cov}[0, 0] - \frac{\text{cov}[0, 2]^2}{\text{cov}[2, 2]} $$
    $$ b' \leftarrow \text{cov}[0, 1] - \frac{\text{cov}[0, 2] \cdot \text{cov}[1, 2]}{\text{cov}[2, 2]} $$
    $$ c' \leftarrow \text{cov}[1, 1] - \frac{\text{cov}[1, 2]^2}{\text{cov}[2, 2]} $$

4.  **Construct Regularized Covariance in Basis Space:**
    Create the matrix $\sigma_{\text{basis}}$ using the computed values. The tangential components are preserved in the top-left $2 \times 2$ block, while the normal components are zeroed out except for a scaled minimum of the tangential variances:
    $$
    \sigma_{\text{basis}} = \begin{bmatrix}
    a' & b' & 0 \\
    b' & c' & 0 \\
    0 & 0 & \min(a', c') / 100
    \end{bmatrix}
    $$
    Note: The element at $[0,1]$ and $[1,0]$ is $b'$. The elements at $[0,2], [1,2], [2,0], [2,1]$ are $0$. The element at $[2,2]$ is $\min(a', c') / 100$.

5.  **Transform Back to World Space:**
    $$ \sigma \leftarrow \mathbf{B} \sigma_{\text{basis}} \mathbf{B}^T $$

6.  **Opacity Adjustments:**
    To improve training efficiency and reduce noise, adjust the opacity thresholds:
    *   Increase the opacity threshold for densification and pruning to $0.01$ [S1].
    *   Reset the initial opacity value for half-Gaussians to $0.02$ [S1].

**Pseudocode:**
```python
def regularize_covariance(cov_matrix: Matrix3x3, normal: Vector3) -> Matrix3x3:
    """
    Transforms a 3D Gaussian covariance matrix into a half-Gaussian covariance
    aligned with the given normal vector.
    
    Args:
        cov_matrix: The original 3x3 covariance matrix Sigma.
        normal: The 3D normal vector n.
        
    Returns:
        The regularized 3x3 covariance matrix sigma.
    """
    # 1. Normalize normal
    n = normal / norm(normal)
    
    # 2. Compute basis vectors v1 and v2
    if n.x == 0 and n.y == 0:
        v1 = Vector3(1, 0, 0)
        v2 = Vector3(0, 1, 0)
    else:
        v1_raw = Vector3(n.y, -n.x, 0)
        v1 = v1_raw / norm(v1_raw)
        cross = cross_product(n, v1)
        v2 = cross / norm(cross)
        
    # 3. Construct basis matrix B
    # B is 3x3, columns are v1, v2, n
    B = Matrix3x3(v1, v2, n)
    
    # 4. Transform covariance to basis space
    cov_basis = transpose(B) @ cov_matrix @ B
    
    # 5. Compute modified elements
    # Accessing elements as cov_basis[i, j]
    a_prime = cov_basis[0, 0] - (cov_basis[0, 2] ** 2) / cov_basis[2, 2]
    b_prime = cov_basis[0, 1] - (cov_basis[0, 2] * cov_basis[1, 2]) / cov_basis[2, 2]
    c_prime = cov_basis[1, 1] - (cov_basis[1, 2] ** 2) / cov_basis[2, 2]
    
    # 6. Construct regularized covariance in basis space
    min_val = min(a_prime, c_prime)
    sigma_basis = Matrix3x3(
        row0=[a_prime, b_prime, 0],
        row1=[b_prime, c_prime, 0],
        row2=[0, 0, min_val / 100.0]
    )
    
    # 7. Transform back to world space
    sigma = B @ sigma_basis @ transpose(B)
    
    return sigma
```

**Parameters:**
*   **Regularization Interval:** Every 5000 iterations [S1].
*   **Opacity Threshold (Densification/Pruning):** $0.01$ [S1].
*   **Half-Gaussian Opacity Reset:** $0.02$ [S1].

**Edge Cases and Pitfalls:**
*   **Degenerate Normal:** If the normal vector is zero or near-zero, the basis construction fails. The code explicitly checks for $n_x=0$ and $n_y=0$ to provide a fallback basis, but generally, a valid surface normal is required [S1].
*   **Division by Zero:** The calculation of $a', b', c'$ involves division by $\text{cov}[2, 2]$. If the covariance component along the normal is zero or near-zero, this will cause numerical instability. [G] In practice, a small epsilon should be added to the denominator if $\text{cov}[2, 2]$ is extremely small.
*   **Precision:** The transformation involves multiple matrix multiplications and divisions. Floating-point precision errors may accumulate, particularly when $\text{cov}[2, 2]$ is small.

## Operating characteristics
*   **Time Complexity:** The transformation involves fixed-size matrix operations ($3 \times 3$), so it is $O(1)$ per Gaussian per regularization step. Since it is applied every 5000 iterations, the overhead per frame is negligible compared to the rasterization cost.
*   **Memory Complexity:** No additional memory is required beyond the standard Gaussian parameters.
*   **Performance:** On the Mip-NeRF 360 dataset, 3D-HGS with an Efficient Rasterizer achieves 125 FPS and 29.66 PSNR using 3.8M kernels, compared to 3DGS which uses 3.2M kernels (FPS/PSNR for 3DGS not explicitly listed in the specific row but implied lower or comparable with fewer kernels) [S1]. On the Tank & Dengin dataset, it achieves 160 FPS and 24.45 PSNR using 1.8M kernels [S1]. On the Tank & Blending dataset, it achieves 126 FPS and 29.76 PSNR using 2.6M kernels [S1].
*   **Strengths:** Consistently outperforms original 3D Gaussian Splatting across all metrics (PSNR, etc.) on evaluated datasets [S1]. The splitting planes align well with scene surface normals, effectively modeling sharp transitions [S1].
*   **Limitations:** Requires the computation of surface normals, which may not be available in all scenes without additional estimation steps. The regularization is applied periodically, not every step, which may lead to transient artifacts if the interval is too long.

## Background
The method was introduced in the paper "3D-HGS: 3D Half-Gaussian Splatting" [S1]. It builds on the principles of 3D Gaussian Splatting but introduces a novel kernel shape to better handle surface boundaries. The approach is evaluated against Scaffold, mip-splatting, and MCMC architectures [S1].
