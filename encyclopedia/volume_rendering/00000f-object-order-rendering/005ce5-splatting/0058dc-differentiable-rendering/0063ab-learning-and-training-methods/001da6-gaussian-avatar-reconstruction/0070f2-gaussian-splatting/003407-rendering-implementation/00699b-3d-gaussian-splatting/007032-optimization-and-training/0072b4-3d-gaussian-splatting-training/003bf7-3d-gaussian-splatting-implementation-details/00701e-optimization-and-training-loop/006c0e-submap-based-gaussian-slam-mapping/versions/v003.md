# Submap-based Gaussian SLAM Mapping

Also called: Gaussian-SLAM mapping process, Incremental submap optimization

## Overview
This method manages the incremental construction of a 3D Gaussian Splatting model within a Simultaneous Localization and Mapping (SLAM) framework by dividing the scene into manageable spatial or temporal segments called "submaps" [S1, unofficial]. It solves the problem of unbounded memory growth and optimization instability in long-sequence SLAM by resetting the optimization state periodically while maintaining global consistency through keyframe integration [S1, unofficial]. It differs from standard batch training by interleaving tracking and mapping steps, and from continuous global optimization by using localized submap resets to prevent drift accumulation in the Gaussian parameters [S1, unofficial].

## How it works
The method processes a sequence of RGB-D frames and estimated camera poses. It maintains a list of keyframes and a current Gaussian model. The core loop operates on a per-frame basis, deciding whether to start a new submap based on motion heuristics or fixed frame intervals.

### Inputs and Outputs
**Inputs:**
- Sequence of frames: RGB color tensors, depth tensors.
- Estimated camera poses: Camera-to-World matrices ($\mathbf{T}_{c2w}$).
- Camera intrinsics: Focal lengths, principal point, image dimensions.
- Configuration parameters: `new_submap_every`, `mapping` settings, `tracking` settings.

**Outputs:**
- Updated 3D Gaussian model $\mathcal{G}$ (positions, covariances, opacities, SH coefficients).
- Optimized camera poses (if joint optimization is enabled, though typically poses are provided by the tracker).
- Visualization images and metrics (PSNR, loss).

### Data Structures
1.  **Gaussian Model ($\mathcal{G}$):**
    -   Positions: $\mathbf{p}_i \in \mathbb{R}^3$
    -   Scales: $\mathbf{s}_i \in \mathbb{R}^3$
    -   Rotations: $\mathbf{q}_i \in \mathbb{R}^4$ (unit quaternion)
    -   Opacities: $\alpha_i \in [0, 1]$
    -   SH Coefficients: $\mathbf{c}_{i, l}$ for view-dependent color.
2.  **Keyframe Dictionary:**
    -   Color tensor: Normalized to $[0, 1]$, moved to CUDA.
    -   Depth tensor: Moved to CUDA.
    -   Render settings: Derived from intrinsics and world-to-camera matrix ($\mathbf{T}_{w2c} = \mathbf{T}_{c2w}^{-1}$).
3.  **Submap State:**
    -   `submap_frame_ids`: List of frame IDs triggering new submaps.
    -   `estimated_c2ws`: Array of estimated camera-to-world poses.
    -   `gaussian_model`: Current state of Gaussians.

### Numbered Steps
1.  **Initialization:**
    -   Determine submap trigger frame IDs: `submap_frame_ids = frame_ids[::config["mapping"]["new_submap_every"]] + [n_frames - 1]` [S1, unofficial].
    -   Initialize logger and mapper/tracker components [S1, unofficial].
    -   Set up output paths for mapping and tracking visualizations [S1, unofficial].

2.  **Per-Frame Loop:**
    For each frame $i$ with ID $f_i$:
    a.  **Retrieve Data:** Get ground truth color, depth, and estimated $\mathbf{T}_{c2w}$ [S1, unofficial]. Compute $\mathbf{T}_{w2c} = \mathbf{T}_{c2w}^{-1}$ [S1, unofficial].
    b.  **Check Submap Start:** Determine if a new submap should start using `should_start_new_submap(f_i)` [S1, unofficial].
        -   **Motion Heuristic:** If enabled, check if rotation difference $> 50^\circ$ or translation difference $> 0.5$ units between current pose and the last submap start pose [S1, unofficial].
        -   **Fixed Interval:** If heuristic disabled, check if $f_i$ is in `submap_frame_ids` [S1, unofficial].
    c.  **Start New Submap (if triggered):**
        -   Call `start_new_submap(f_i, gaussian_model)` [S1, unofficial].
        -   Save current submap checkpoint.
        -   Reset Gaussian model (clear existing Gaussians) [S1, unofficial].
        -   Update `submap_count` [S1, unofficial].
    d.  **Construct Keyframe Dictionary:**
        -   Normalize color to $[0, 1]$ and move to CUDA.
        -   Move depth to CUDA.
        -   Store render settings derived from intrinsics and $\mathbf{T}_{w2c}$ [S1, unofficial].
    e.  **Seeding:**
        -   Compute a seeding mask based on the current Gaussian model and the keyframe [S1, unofficial].
        -   Call `seed_new_gaussians` with ground truth color, depth, intrinsics, camera pose, seeding mask, and submap flag [S1, unofficial]. This adds new 3D points (Gaussians) to the model.
    f.  **Outlier Filtering:**
        -   Enable statistical outlier filtering if dataset is TUM_RGBD or ScanNet AND it is not a new submap [S1, unofficial].
    g.  **Optimize Submap:**
        -   Call `optimize_submap` with the current frame, all existing keyframes, the Gaussian model, and `max_iterations` [S1, unofficial].
        -   `max_iterations` is `self.new_submap_iterations` if `is_new_submap` is true, otherwise `self.iterations` [S1, unofficial].
    h.  **Update Keyframes:**
        -   Append the current frame and its keyframe dictionary to the list of keyframes [S1, unofficial].
    i.  **Visualization & Logging:**
        -   Render the current Gaussian model using the keyframe's render settings to generate visualization color and depth images [S1, unofficial].
        -   Calculate PSNR between rendered color and ground truth color [S1, unofficial].
        -   Log mapping iteration statistics: frame ID, new points count, model size, optimization time, and loss dictionary [S1, unofficial].

### Pseudocode
```python
def process_frame(frame_id, color, depth, c2w_pose, intrinsics, gaussian_model, keyframes, config):
    # 1. Compute world-to-camera matrix
    w2c_pose = inverse(c2w_pose)
    
    # 2. Check if new submap needed
    is_new_submap = should_start_new_submap(frame_id, c2w_pose, keyframes, config)
    
    if is_new_submap:
        start_new_submap(frame_id, gaussian_model)
        # Reset Gaussian model state here [G]
    
    # 3. Construct keyframe dictionary
    keyframe_dict = {
        "color": normalize_to_01(color).to_cuda(),
        "depth": depth.to_cuda(),
        "w2c": w2c_pose,
        "intrinsics": intrinsics
    }
    
    # 4. Seed new Gaussians
    seeding_mask = compute_seeding_mask(gaussian_model, keyframe_dict)
    new_points = seed_new_gaussians(
        color=keyframe_dict["color"],
        depth=keyframe_dict["depth"],
        intrinsics=intrinsics,
        pose=c2w_pose,
        mask=seeding_mask,
        is_new_submap=is_new_submap
    )
    gaussian_model.add_points(new_points)
    
    # 5. Outlier filtering
    if is_outlier_filtering_enabled(config["dataset"], is_new_submap):
        gaussian_model.remove_outliers()
        
    # 6. Optimize submap
    max_iter = config["mapping"]["new_submap_iterations"] if is_new_submap else config["mapping"]["iterations"]
    optimize_submap(
        current_frame=keyframe_dict,
        all_keyframes=keyframes,
        gaussian_model=gaussian_model,
        max_iterations=max_iter
    )
    
    # 7. Update keyframes
    keyframes.append(keyframe_dict)
    
    # 8. Render and Log
    render_color, render_depth = render(gaussian_model, keyframe_dict)
    psnr = calculate_psnr(render_color, color)
    log_stats(frame_id, len(new_points), gaussian_model.size(), psnr)
    
    return gaussian_model, keyframes
```

### Parameters
-   `max_iterations`: Number of optimization iterations per submap step.
    -   If `is_new_submap`: `self.new_submap_iterations` [S1, unofficial].
    -   Else: `self.iterations` [S1, unofficial].
-   `new_submap_every`: Interval for fixed-interval submap creation [S1, unofficial].
-   Motion thresholds: Rotation $> 50^\circ$, Translation $> 0.5$ units [S1, unofficial].

### Edge Cases and Pitfalls
-   **Precision:** Depth tensors must be moved to CUDA and handled with appropriate precision to avoid artifacts during seeding [S1, unofficial].
-   **Boundaries:** The last frame of the sequence is always included in `submap_frame_ids` to ensure the final submap is processed [S1, unofficial].
-   **Degenerate Input:** If the camera pose is invalid, `inverse(c2w_pose)` may fail. [G] Ensure pose validity checks are performed before inversion.

## Operating characteristics
-   **Time Complexity:** Linear with respect to the number of frames processed, but each frame involves optimization over the current submap's Gaussians and all keyframes. Complexity per step is $O(N_{submap} \cdot N_{keyframes})$ for rendering and optimization [S1, unofficial].
-   **Memory Complexity:** Bounded by the size of the current submap and the number of keyframes, rather than the entire scene history. This prevents unbounded memory growth [S1, unofficial].
-   **Strengths:** Enables long-sequence SLAM by managing memory; reduces optimization drift by resetting submaps; leverages keyframes for global consistency.
-   **Limitations:** Requires careful tuning of submap frequency; motion heuristics may fail in low-texture or fast-motion scenarios; outlier filtering is dataset-specific [S1, unofficial].
-   **When to use:** Long-sequence RGB-D SLAM where memory is constrained and drift needs to be managed.
-   **When not to use:** Short sequences or batch reconstruction where global optimization is feasible.

## Background
This method is implemented in the **Gaussian-SLAM** framework by Vladimir Yugay [S1, unofficial]. It adapts the 3D Gaussian Splatting rendering technique for incremental SLAM, addressing the challenge of maintaining a consistent 3D model over time without re-optimizing the entire history. The approach builds on the principles of differentiable rendering and Gaussian primitives, integrating them with SLAM-specific constraints like keyframe management and submap resets.
