# Gaussian Sampling for Surface Patch Anchors

Also called: Anchor sampling with Gaussian distribution, Pulled Queries, Surface Patch Generation, Surface Patch Sensing via Gaussian Sampling

## Overview
This method creates a denser, more continuous surface representation than single-point ray intersection by pulling randomly sampled queries around 3D anchor points derived from back-projected geometry cues [S1]. It solves the problem of sparse supervision at the zero level set by generating a local surface patch for volume rendering constraints [S1]. It is distinguished from sibling methods like [Angle-pose Cuboid Uniform Initialization](4503-angle-pose-cuboid-uniform-initialization-acui.md) by its reliance on isotropic Gaussian sampling around specific geometric anchors rather than uniform cuboid distributions, and from [Geometry-Aware and Surface-Aligned Initialization](15765-geometry-aware-and-surface-aligned-initialization.md) by its explicit use of "pulled queries" to form a patch rather than aligning to a mesh or SDF gradient directly [S1].

## How it works
**Inputs:**
*   3D anchor points $q$ obtained by backprojecting geometry cues (predicted monocular depth or dataset-provided sensor cues) to 3D world coordinates [S1].
*   Number of points per patch $J$ [S1].
*   Variance parameter $\tau^2$ controlling the spread of the Gaussian distribution [S1].

**Outputs:**
*   A set of $J$ points $s = \{p'_j \mid j \in [1, J]\}$ forming a surface patch around each anchor $q$ [S1].

**Data Structures:**
*   The surface patch $s$ is a list or array of $J$ 3D points. Each point $p'_j$ is a vector in $\mathbb{R}^3$ [S1].

**Steps:**
1.  **Obtain Anchor Points:** For each posed view, backproject geometry cues to obtain 3D anchor points $q$ [S1].
2.  **Define Distribution:** Define an isotropic Gaussian distribution $\mathcal{N}(q, \tau^2)$ centered at the anchor point $q$ with variance $\tau^2$ [S1].
3.  **Sample Points:** Sample $J$ points from this distribution to form the surface patch $s$ [S1].
4.  **Initialize Parameters:** Set $\tau^2$ to the distance between two other pixels in the 3D world coordinate as a baseline [S1]. Set $J=9$ as the typical value [S1].

**Formulas:**
The position of the $j$-th point $p'_j$ in the patch is sampled from:
$$ p'_j \sim \mathcal{N}(q, \tau^2) $$
where $q$ is the 3D anchor point and $\tau^2$ is the variance [S1].

**Parameters:**
*   $J$: Number of points sampled per surface patch. Typical value: 9. Other tested values: 1, 16, 25 [S1].
*   $\tau^2$: Variance of the isotropic Gaussian distribution. Baseline: distance between two other pixels in the 3D world coordinate. Tested candidates: $\{0.5\tau^2, \tau^2, 2\tau^2, 3\tau^2\}$ [S1].

**Pseudocode:**
```python
import numpy as np

def generate_surface_patch(anchor_q, variance_tau2, num_points_J):
    """
    Generates a surface patch by sampling points from an isotropic Gaussian distribution.
    
    Args:
        anchor_q (np.ndarray): 3D anchor point [x, y, z].
        variance_tau2 (float): Variance of the Gaussian distribution.
        num_points_J (int): Number of points to sample.
        
    Returns:
        np.ndarray: Array of shape (J, 3) containing the sampled points.
    """
    # Sample J points from a 3D isotropic Gaussian distribution centered at anchor_q
    # The standard deviation is sqrt(variance_tau2) for each dimension
    std_dev = np.sqrt(variance_tau2)
    
    # Generate random noise from standard normal distribution
    noise = np.random.normal(loc=0.0, scale=1.0, size=(num_points_J, 3))
    
    # Scale by standard deviation and shift by anchor
    patch_points = anchor_q + noise * std_dev
    
    return patch_points

def initialize_parameters():
    """
    Initializes the parameters for Gaussian sampling based on source evidence.
    """
    # J: Number of points per patch
    J = 9
    
    # tau2: Variance. Baseline is distance between two other pixels in 3D world coords.
    # This value must be computed from the specific scene geometry or sensor data.
    # Not given in the sources: How to compute the exact "distance between two other pixels".
    # [G] Assume a function get_pixel_distance() exists or is derived from sensor calibration.
    tau2 = get_pixel_distance() 
    
    return J, tau2
```

**Edge Cases and Pitfalls:**
*   If $\tau^2$ is too small, the patch does not cover a large enough area, degrading inference performance [S1].
*   If $\tau^2$ is too large, points may be ruled out by masks (see [Mask and Weight Filtering for Patch Points](16626-mask-and-weight-filtering-for-patch-points.md)), decreasing efficiency and performance [S1].
*   A small variance may not cover a large enough area, degenerating inference performance [S1].
*   A large variance covers too large an area, causing points to be ruled out by masks, decreasing efficiency and performance [S1].

## Subtopics

### [Mask and Weight Filtering for Patch Points](16626-mask-and-weight-filtering-for-patch-points.md)
Applies a binary mask $w_j$ to rule out outliers during the pulling step, and a scalar weight $\eta_j$ to focus the network on the most important point $p'_j$ on the patch surface.

## Operating characteristics
**Time and Memory Complexity:**
*   The complexity is proportional to the number of points sampled $J$ per anchor [S1].
*   A too large number of points may not improve performance further but increases time complexity [S1].

**Measured Performance:**
*   On the Replica dataset, optimal sampling at $J=9, \tau^2=\tau^2$ yields: Acc=0.036, Comp=0.039, CD-L1=0.037, Prec=0.820, Recall=0.777, F-score=0.797 [S1].
*   Patch-level photo consistency achieves better performance than pixel-level photo consistency [S1].

**Strengths and Limitations:**
*   **Strengths:** Provides a denser and more continuous surface representation than single-point intersection; is more geometry-aware than single-point intersection and points back-projected from a depth patch [S1].
*   **Limitations:** Performance degrades if variance is too small (insufficient coverage) or too large (points ruled out by masks) [S1].

**When to Use:**
*   Use when a denser, more continuous surface representation is needed for volume rendering constraints, specifically when leveraging SDF gradients and signed distance to move points onto the zero level set [S1].

## Background
This method was introduced in the paper "Sensing Surface Patches in Volume Rendering for Inferring Signed Distance Functions" [S1]. It addresses the limitation of zero level set supervision where only a single point gets supervised during differentiable rendering [S1]. The method leverages the character of SDF to move points onto the zero level set, referencing prior work by Ma et al. (2021, 2022a,b) and Chou, Chugunov, and Heide (2022) [S1].
