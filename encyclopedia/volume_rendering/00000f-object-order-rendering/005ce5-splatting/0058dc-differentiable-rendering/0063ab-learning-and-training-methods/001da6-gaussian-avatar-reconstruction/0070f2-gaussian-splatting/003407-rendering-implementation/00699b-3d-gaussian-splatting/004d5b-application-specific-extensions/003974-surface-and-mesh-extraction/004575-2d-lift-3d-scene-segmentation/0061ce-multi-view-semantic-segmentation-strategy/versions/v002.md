# Multi-View Semantic Segmentation Strategy

Also called: Multi-view segmentation for iVR-GS, SAM 2 based multi-view segmentation

## Overview
This strategy enables open-vocabulary querying and interactive scene editing in Volume Visualization (VolVis) by segmenting multi-view images to train independent, editable 3D Gaussian Splatting (iVR-GS) models for each object [S1]. It differs from direct 3DGS segmentation methods by maintaining method-agnostic segmentation and scalability, avoiding modifications to the underlying Gaussian structure [S1]. It addresses the view inconsistencies inherent in framewise 2D segmentation by treating multi-view images as a video sequence for tracking [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:** Multi-view images (typically generated by a Neural Volume Rendering/Synthesis model along a continuous circular camera trajectory) and a user-selected segmentation method [S1].
- **Outputs:** Segmented multi-view images or masks for each distinct object, used to train independent iVR-GS models [S1].

**Data Structures:**
- **Multi-view Image Sequence:** Frames sampled along a continuous circular camera trajectory, treated as a video sequence [S1].
- **iVR-GS Models:** Independent 3DGS models, one per segmented object, assembled to form the final scene [S1].

**Steps:**
1. Select a segmentation method suitable for the specific dataset from the following categories: pre-segmented, Transfer Function (TF)-based, voxel-based, cross-frame tracking, or direct 3DGS segmentation [S1].
2. If using pre-segmented datasets (e.g., medical imaging benchmarks like FLARE), apply the provided ground-truth semantic labels directly [S1].
3. If using TF-based segmentation, rely on voxel intensity and derived attributes, noting that this lacks semantic awareness and is generally unsuitable for object-level segmentation [S1].
4. If using voxel-based techniques (e.g., voxel2vec), extract features using voxel coordinates, scalar values, gradients, and neighborhood information, noting that this lacks semantic awareness and is poorly suited for NVS pipelines that operate on multi-view images rather than raw voxels [S1].
5. If using cross-frame tracking, sample multi-view images along a continuous circular camera trajectory to form a video sequence [S1]. Apply a video object segmentation and tracking model, specifically SAM 2, to segment and track objects across frames [S1]. This improves consistency compared to independent framewise segmentation [S1].
6. If using direct 3DGS segmentation, leverage 2D foundation models to integrate semantic features into 3D Gaussian representations, noting that this modifies the underlying Gaussian structure and reduces flexibility [S1].
7. Train iVR-GS models using the segmented multi-view renderings (e.g., from LangSplat or SAGD) rather than directly segmenting iVR-Gaussians [S1]. Assemble the final scene by combining these component models [S1].

**Parameters:**
- **Camera Trajectory:** Continuous circular trajectory for sampling multi-view images [S1].
- **Segmentation Model:** SAM 2 for video object segmentation and tracking [S1]. LangSplat or SAGD for mask generation [S1].

**Edge Cases and Pitfalls:**
- **View Inconsistencies:** Framewise segmentation using 2D foundation models on individual viewpoints results in mask variations between neighboring frames due to occlusions, lighting changes, or segmentation artifacts [S1].
- **Transparent/Nested Objects:** SAM 2 struggles with these object types, which are common in VolVis [S1].
- **Semantic Limitations:** TF-based and voxel-based techniques rely on voxel intensity and derived attributes rather than learned semantics, failing to segment objects based on semantic meaning [S1].
- **Compatibility:** Direct segmentation in 3DGS modifies the underlying Gaussian structure, reducing flexibility and compatibility with other segmentation methods [S1].
- **Quality Trade-off:** The method-agnostic approach of training iVR-GS from segmented renderings may result in some loss of visualization quality compared to direct segmentation [S1].

## Operating characteristics
- **Flexibility:** The strategy is method-agnostic, allowing users to select the segmentation technique best suited for their specific dataset [S1].
- **Consistency:** Using SAM 2 for cross-frame tracking improves segmentation consistency across viewpoints compared to independent framewise segmentation [S1].
- **Scalability:** Training independent iVR-GS models from segmented multi-view images maintains scalability and interoperability without modifying the 3DGS structure directly [S1].
- **Quality Trade-off:** The method-agnostic approach may result in some loss of visualization quality compared to direct segmentation methods [S1].
- **Limitations:** SAM 2 struggles with transparent and nested objects [S1]. TF-based and voxel-based methods lack semantic awareness and generalization to complex real-world scenes [S1].

## Background
This strategy originates from the NLI4VolVis pipeline, which enables natural language interaction for volume visualization via LLM multi-agents and editable 3D Gaussian Splatting [S1]. It addresses the need for efficient semantic segmentation across diverse VolVis scenarios to support open-vocabulary querying and interactive scene editing [S1]. The approach was developed to overcome the limitations of one-size-fits-all segmentation in VolVis, where datasets vary widely (e.g., medical imaging vs. arbitrary scenes) [S1].
