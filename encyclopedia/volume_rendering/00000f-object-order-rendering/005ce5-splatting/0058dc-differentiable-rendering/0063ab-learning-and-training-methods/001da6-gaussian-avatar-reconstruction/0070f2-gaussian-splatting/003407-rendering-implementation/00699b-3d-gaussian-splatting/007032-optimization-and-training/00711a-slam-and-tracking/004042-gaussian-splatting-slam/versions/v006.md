# Gaussian Splatting SLAM

Also called: Gaussian Splatting SLAM Tracking and Mapping Optimization, GaussianSplattingSLAM, Monocular Gaussian SLAM, RGB-D SLAM with Gaussian Splatting

## Overview
Gaussian Splatting SLAM is a simultaneous localization and mapping method that represents the scene as a collection of 3D Gaussians, optimizing camera poses and Gaussian parameters jointly [S2, unofficial]. It distinguishes itself from sibling methods by explicitly incorporating an isotropic scale regularization term to stabilize optimization [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Current camera pose estimate $T_{CW}$, current Gaussian map $\mathcal{G}$, new RGB image $I_{rgb}$, and optionally depth map $D_{depth}$ [S2, unofficial].
*   **Outputs:** Updated camera pose $T_{CW}'$, updated Gaussian map $\mathcal{G}'$, and keyframe list [S2, unofficial].

**Data Structures:**
Each Gaussian $g_i$ stores mean position $\boldsymbol{\mu}_i \in \mathbb{R}^3$, covariance matrix $\boldsymbol{\Sigma}_i \in \mathbb{R}^{3 \times 3}$ (parameterized by rotation $R_i \in SO(3)$ and scale $S_i \in \mathbb{R}^3$), opacity $\alpha_i \in [0, 1]$, and spherical harmonics coefficients $c_{i,lm}$ for view-dependent color [G]. Keyframes store poses, RGB/depth images, and visible Gaussian indices $\mathcal{G}_k^v$ [S2, unofficial].

**Algorithm Steps:**
The method alternates between Tracking and Mapping phases.

1.  **Tracking:**
    Optimize the camera pose $T_{CW}$ to minimize the weighted sum of photometric and geometric residuals [S2, unofficial]:
    $$ \min_{T_{CW} \in SE(3)} \lambda_{pho} E_{pho} + (1 - \lambda_{pho}) E_{geo} $$
    where $E_{pho}$ is the photometric error and $E_{geo}$ is the geometric error [S2, unofficial].
    *   Perform up to 100 tracking iterations per frame [S2, unofficial].
    *   Terminate early if the magnitude of the pose update $\|\Delta T\| < 10^{-4}$ [S2, unofficial].
    *   In monocular settings, increase the learning rate of Gaussian positions $\boldsymbol{\mu}_W$ by a factor of 10 [S2, unofficial].

2.  **Mapping:**
    Optimize the Gaussian parameters $\mathcal{G}$ and keyframe poses $T_{CW}^k$ for a sliding window $\mathcal{W}$ [S2, unofficial]. The objective minimizes:
    $$ \min_{\mathcal{G}, T_{CW}^k \forall k \in \mathcal{W}} \sum_{k \in \mathcal{W}} (\lambda_{pho} E_{pho}^k + (1 - \lambda_{pho}) E_{geo}^k) + \lambda_{iso} E_{iso} $$
    where $E_{iso}$ is the isotropic regularization loss [S1].
    *   Perform 150 iterations for single-process implementations [S2, unofficial].
    *   Apply $E_{iso}$ to encourage isotropic Gaussians, stabilizing localization and mapping [S1].

3.  **Keyframe Management:**
    Select new keyframes based on Gaussian covisibility to limit computational cost [S2, unofficial]. For two keyframes $i$ and $j$, compute:
    $$ IOU_{cov}(i, j) = \frac{|\mathcal{G}_i^v \cap \mathcal{G}_j^v|}{|\mathcal{G}_i^v \cup \mathcal{G}_j^v|}, \quad OC_{cov}(i, j) = \frac{|\mathcal{G}_i \cap \mathcal{G}_j|}{\min(|\mathcal{G}_i^v|, |\mathcal{G}_j^v|)} $$
    where $\mathcal{G}_i^v$ is the set of Gaussians visible in keyframe $i$ [S2, unofficial]. A new frame is added as a keyframe if the covisibility with existing keyframes falls below a threshold [S2, unofficial].

**Parameters:**
*   Photometric loss weight $\lambda_{pho} = 0.9$ for RGB-D experiments [S2, unofficial].
*   Isotropic regularization weight $\lambda_{iso} = 10$ for both monocular and RGB-D experiments [S2, unofficial].
*   Camera pose learning rates: 0.003 for rotation, 0.001 for translation [S2, unofficial].
*   Gaussian learning rates: Default from original Gaussian Splatting, except monocular position learning rate is multiplied by 10 [S2, unofficial].

**Pseudocode:**
```python
def gaussian_splatting_slam(current_rgb, current_depth, current_pose, gaussian_map, keyframes):
    # 1. Tracking Phase
    pose = current_pose
    for i in range(100):
        rendered_rgb, rendered_depth = differentiable_volume_render(gaussian_map, pose)
        e_pho = mean_absolute_error(rendered_rgb, current_rgb)
        e_geo = mean_absolute_error(rendered_depth, current_depth) if current_depth is not None else 0.0
        loss = 0.9 * e_pho + 0.1 * e_geo
        delta_pose = gradient_descent_step(loss, pose, lr=0.003)
        pose = compose_transformation(pose, delta_pose)
        if vector_magnitude(delta_pose) < 1e-4:
            break
    current_pose = pose

    # 2. Mapping Phase
    for i in range(150):
        total_loss = 0.0
        for kf in keyframes:
            rendered_rgb, rendered_depth = differentiable_volume_render(gaussian_map, kf.pose)
            e_pho = mean_absolute_error(rendered_rgb, kf.rgb)
            e_geo = mean_absolute_error(rendered_depth, kf.depth) if kf.depth is not None else 0.0
            e_iso = isotropic_scale_regularization(gaussian_map)
            total_loss += 0.9 * e_pho + 0.1 * e_geo + 10.0 * e_iso
        gradient_descent_step(total_loss, gaussian_map, lr=0.001)
        gradient_descent_step(total_loss, [kf.pose for kf in keyframes], lr=0.001)

    # 3. Keyframe Selection
    if evaluate_covisibility(current_pose, gaussian_map, keyframes):
        keyframes.append(Keyframe(current_rgb, current_depth, current_pose, gaussian_map))
    return current_pose, gaussian_map
```

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Performance:** On the Replica dataset, the method achieves a PSNR of 38.90, SSIM of 0.99, and LPIPS of 0.07 [S1].
*   **Strengths:** High-fidelity reconstruction due to explicit Gaussian representation; robust tracking via isotropic regularization [S1].
*   **Limitations:** Computational cost increases with the number of Gaussians and keyframes; requires careful tuning of learning rates, especially in monocular settings [S2, unofficial].

## Background
Gaussian Splatting SLAM builds on the principles of 3D Gaussian Splatting [S1]. The specific implementation details are documented in a preprint [S2, unofficial]. It leverages differentiable volume rendering for joint optimization [G].
