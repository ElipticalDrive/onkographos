# Voxel and Grid-Based Prediction

Also called: Voxel Transformer, Voxel-Aligned Prediction, GS-LRM
## Overview
This family of methods predicts 3D Gaussian Splatting parameters by conditioning on a discrete voxel or grid representation, rather than generating them directly from continuous features or pixel-aligned projections. It solves the problem of spatial coherence and efficient memory usage in feed-forward reconstruction by localizing predictions to grid cells. It differs from its siblings by explicitly using a voxel grid as the primary latent structure for attribute prediction, contrasting with [Textured-GS](9436-textured-gs.md) which uses triplanes, and [3D Skew-Normal Splatting](10045-3d-skew-normal-splatting.md) which focuses on distributional properties rather than grid alignment.
## Shared principles
The core mechanism involves discretizing the 3D space into a voxel grid. For each voxel (or active voxel), a neural network (typically an MLP or Transformer) predicts a set of Gaussian parameters. These parameters are often residuals or offsets relative to the voxel's geometric center or initial attributes, ensuring that the final Gaussians remain localized within the voxel's influence region. The output dimensionality is fixed per voxel, typically comprising center offsets, opacity, covariance, and color coefficients.
## Subtopics

### Gaussian Splatting Attribute Prediction
A voxel transformer that predicts residuals added to initial Gaussian rendering attributes on voxels, rather than generating new attributes directly [S1]. This approach stabilizes training by refining coarse initial attributes rather than learning them from scratch.

**Definition**
The method uses a voxel transformer to predict residuals $\Delta \mathbf{G}_j$ which are added to initial Gaussian rendering attributes $\mathbf{G}_j$ obtained via a Splat Fusion procedure [S1]. The input to the transformer includes the fused voxel attributes $\mathbf{E}_j$ and an offset vector $\mathbf{O}_j$ [S1].

**Formula**
The residual is computed as:
$$ \Delta \mathbf{G}_j = \text{MLP}_{fine}([\mathbf{O}_j, \mathbf{E}_j]) $$
where $\text{MLP}_{fine}$ is a multi-layer perceptron, and $[\mathbf{O}_j, \mathbf{E}_j]$ denotes the concatenation of offset $\mathbf{O}_j$ and voxel attribute $\mathbf{E}_j$ [S1].

The final splat rendering parameter $\mathbf{G}'_j$ is:
$$ \mathbf{G}'_j = \mathbf{G}_j + \Delta \mathbf{G}_j $$
where $\mathbf{G}_j$ is the initial rendering parameter and $\Delta \mathbf{G}_j$ is the predicted residual [S1].

**Context**
The offset vector $\mathbf{O}_j$ is normalized using a grid size $h$ to the range $[-1, 1]$ [S1]. The method is part of a history-aware streaming system that can generalize to dynamic scenes [S1].

### 3D Gaussians Prediction from Voxels
Predicts a set of learnable Gaussian parameters for each voxel $v$, including center offset, opacity, covariance, and spherical harmonic color [S2]. This method, known as VolSplat, aligns Gaussians with voxel geometry to ensure spatial consistency [S2].

**Definition**
The network outputs a set of learnable Gaussian parameters $\{[\bar{\mu}_j, \bar{\alpha}_j, \Sigma_j, c_j] \in \mathbb{R}^{38}\}$ for each voxel $v$ [S2]. These include the offset of the Gaussian center $\bar{\mu}_j$, opacity $\bar{\alpha}_j$, covariance $\Sigma_j$, and spherical harmonic color representation $c_j$ [S2].

**Step**
1. Predict raw offsets and attributes for each voxel.
2. Transform the raw center offset $\bar{\mu}_j$ into the final center $\mu_j$ using a sigmoid activation and scaling.
3. Transform raw opacity $\bar{\alpha}_j$ using sigmoid.

**Formula**
The final 3D Gaussian center $\mu_j$ is computed as:
$$ \mu_j = r \cdot (\sigma(\bar{\mu}_j) - 0.5) + \text{Center}_j $$
where $\mu_j$ is the final center, $\sigma$ is the sigmoid function, $\bar{\mu}_j$ is the predicted offset, $\text{Center}_j$ is the voxel centroid, and $r$ is a scaling factor [S2].

The opacity $\alpha_j$ is:
$$ \alpha_j = \sigma(\bar{\alpha}_j) $$
[ S2]

**Parameter**
The output dimension per Gaussian is 38, comprising offset (3), opacity (1), covariance (6), and spherical harmonic color (28) [S2]. The scaling factor $r$ is set to 3 times the voxel size [S2].

**Pitfall**
The sigmoid activation restricts the learnable offset to a localized neighborhood [S2]. The $-0.5$ shift facilitates symmetrical, bi-directional movement from the voxel center [S2].

### GS-LRM / Long-LRM
Predicts 3D Gaussians directly from image features, bypassing the intermediate triplane representation used by methods like TripoSR or InstantMesh [S3, unofficial]. This direct prediction enables faster downstream rendering compared to triplane-based approaches [S3, unofficial].

**Definition**
Unlike triplane-based methods that convert features to occupancy and then to Gaussians, GS-LRM predicts Gaussian parameters directly [S3, unofficial].

**Comparison**
It is faster for downstream rendering than triplane-to-Gaussian pipelines [S3, unofficial].

## Background
The concept of using voxel grids for 3D representation has a long history in computer graphics. In the context of 3D Gaussian Splatting, voxel-based prediction emerged as a way to improve the efficiency and coherence of feed-forward reconstruction methods. VolSplat [S2] and similar methods [S1] introduced the idea of predicting Gaussian residuals or offsets aligned with voxel centers to ensure spatial consistency. GS-LRM [S3, unofficial] represents a more recent trend of direct Gaussian prediction, avoiding intermediate representations like triplanes.
