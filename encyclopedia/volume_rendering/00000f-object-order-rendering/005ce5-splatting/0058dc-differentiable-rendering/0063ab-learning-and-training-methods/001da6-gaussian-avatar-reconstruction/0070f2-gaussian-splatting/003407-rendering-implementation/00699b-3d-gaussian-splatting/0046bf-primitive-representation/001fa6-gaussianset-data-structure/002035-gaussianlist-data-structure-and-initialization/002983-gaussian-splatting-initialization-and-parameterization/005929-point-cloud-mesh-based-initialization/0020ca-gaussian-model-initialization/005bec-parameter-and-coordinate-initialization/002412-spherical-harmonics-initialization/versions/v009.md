# Spherical Harmonics Initialization


## Overview
Spherical Harmonics (SH) Initialization sets the initial view-dependent color coefficients for 3D Gaussian splats by assigning input RGB colors to the zeroth-order (DC) term while zeroing all higher-order coefficients [S1, unofficial]. It differs from [Spherical Harmonics Evaluation](3848-spherical-harmonics-evaluation.md) by being a setup routine rather than a rendering step, and from [Splat Initialization from Normalized Coordinates](3595-splat-initialization-from-normalized-coordinates.md) by deriving color from external RGB values rather than spatial coordinates [S1, unofficial].

## How it works
**Inputs:**
- `N`: Number of 3D Gaussians.
- `colors`: Array of shape $(N, 3)$ containing the initial RGB color for each Gaussian.

**Outputs:**
- `sh_coeffs`: Tensor of shape $(N, 27)$ containing the initialized spherical harmonic coefficients.

**Data Structures:**
- The SH coefficients are stored in a flattened tensor of shape $(N, 27)$, corresponding to 9 coefficients per RGB channel (degree 0 and 1, $3 \times 3 = 9$).

**Steps:**
1. Allocate a zero tensor `sh_coeffs` of shape $(N, 3, 9)$ for $N$ Gaussians, 3 RGB channels, and 9 SH coefficients per channel [S1, unofficial].
2. Compute the DC coefficient $c_0$ for each RGB channel using the normalization constant $k = 0.28209479177387814$ [S1, unofficial]:
   $$ c_0 = \frac{\text{RGB}}{k} $$
3. Assign $c_0$ to the index 0 of the SH coefficient array for all channels [S1, unofficial].
4. Flatten the last two dimensions of the tensor to produce the final output of shape $(N, 27)$ [S1, unofficial].

**Pseudocode:**
```python
import torch

def initialize_sh(colors: torch.Tensor) -> torch.Tensor:
    """
    Initialize spherical harmonic coefficients for 3D Gaussian splatting.
    
    Args:
        colors: Tensor of shape (N, 3) with RGB values.
        
    Returns:
        Tensor of shape (N, 27) with SH coefficients.
    """
    N = colors.shape[0]
    # Allocate zero tensor for N Gaussians, 3 channels, 9 coefficients
    sh_coeffs = torch.zeros(N, 3, 9, device=colors.device)
    
    # Normalization constant for zeroth-order SH basis
    k = 0.28209479177387814
    
    # Assign DC coefficient (index 0) for all channels
    # c0 = RGB / k
    sh_coeffs[:, :, 0] = colors / k
    
    # Flatten to (N, 27)
    sh_coeffs = sh_coeffs.view(N, -1)
    
    return sh_coeffs
```

**Parameters:**
- `0.28209479177387814`: Normalization constant for the zeroth-order spherical harmonic basis function [S1, unofficial].

**Edge Cases:**
- If `colors` contains values outside the standard $[0, 1]$ range, the resulting DC coefficients will be scaled accordingly. No clamping is specified in the source [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of Gaussians.
- **Memory Complexity:** $O(N)$, storing 27 coefficients per Gaussian.
- **Strengths:** Simple, deterministic initialization that provides a valid starting point for view-dependent color optimization.
- **Limitations:** Only initializes the DC term; higher-order coefficients remain zero and must be learned during training.
- **When to use:** At the start of 3D Gaussian Splatting training.
- **When not to use:** When pre-computed view-dependent colors are available or when using a different parameterization.

## Background
This method is part of the 3D Gaussian Splatting pipeline, specifically within the Gaussian Splatting Initialization and Parameterization stage [S1, unofficial]. It ensures that the initial color representation is consistent with the spherical harmonic basis functions used for view-dependent rendering.
