# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the photometric difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images by replacing implicit neural fields with explicit, differentiable Gaussian kernels [S5, unofficial]. Unlike NeRF-based methods which require volumetric sampling, 3DGS training relies on analytic rasterization of projected 2D Gaussians, offering significantly faster training and real-time rendering speeds [S2][S5, unofficial]. It sets itself apart from static initialization methods by actively modifying the primitive set (splitting, cloning, pruning) during optimization to balance reconstruction fidelity against computational cost [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images (or video frames) with known camera poses (extrinsics $R_{cw}, t_{cw}$ and intrinsics $K$) [S6, unofficial]. Initial 3D Gaussian parameters are derived from Structure from Motion (SfM) point clouds [S2][S6, unofficial].
*   **Outputs:** Optimized 3D Gaussian parameters: positions $\mathbf{p}_w$, rotations $q$, scales $s$, opacities $\alpha$, and spherical harmonic coefficients $h$ [S6, unofficial].

**Data Structures:**
Each Gaussian primitive $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$ (initialized from SfM) [S6, unofficial].
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion) [S6, unofficial].
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$ (initialized between 0 and 1) [S2].
*   Opacity $\alpha_i \in [0, 1]$ (initialized as a constant) [S6, unofficial].
*   Appearance: Spherical Harmonic coefficients $h_i$ (degree $D$) [S6, unofficial].
*   Covariance $\Sigma_i$ is computed from $q_i$ and $s_i$ [S2].

**Formulas:**
The optimization minimizes a loss function $\mathcal{L}$ between the rendered image $\gamma$ and ground truth $\gamma_{gt}$ [S6, unofficial]:
$$ \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM} $$
where $\lambda$ is the SSIM weight (default 0.2) [S6, unofficial].

The rotation matrix $R$ from quaternion $q = (q_r, q_i, q_j, q_k)$ is:
$$ R(q) = 2 \begin{bmatrix} \frac{1}{2} - (q_j^2 + q_k^2) & q_i q_j - q_r q_k & q_i q_k + q_r q_j \\ q_i q_j + q_r q_k & \frac{1}{2} - (q_i^2 + q_k^2) & q_j q_k - q_r q_i \\ q_i q_k - q_r q_j & q_j q_k + q_r q_i & \frac{1}{2} - (q_i^2 + q_j^2) \end{bmatrix} $$
[S2]

The pixel color $\gamma_j$ is computed via alpha blending of $N$ projected Gaussians sorted by depth:
$$ \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij}, \quad \tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj}) $$
[S6, unofficial]

**Parameters:**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `sh_degree`: Spherical harmonic degree. Default: 3 [S4, unofficial].
*   `sh_degree_interval`: Steps between increasing SH degree. Default: 1,000 [S4, unofficial].
*   `resolutionSchedule`: Steps between doubling image resolution. Default: 3,000 [S3, S4, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S3, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: $\min(15000, \text{numIters}/2)$ [S3, unofficial].
*   `refineEvery`: Steps between densification/pruning operations. Default: 500 [S3, unofficial].
*   `densify_grad_thresh`: Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold for densification. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size splitting stops. Default: 4,000 [S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].
*   `bg_color`: Background color. Default: [0.613, 0.010, 0.398] (magenta) [S4, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Initialize positions $\mathbf{p}_w$ from SfM points in normalized bounds $[-1, 1]$. Initialize scales $s \in [0, 1]$, rotations $q$ as unit quaternions, and opacities $\alpha$ as constants [S2][S6, unofficial].
2.  **Iteration Loop:** For step $i$ from 1 to `numIters`:
    a.  **Camera Selection:** Select a training camera $V$ and ground truth image $\hat{I}$ using a shuffled round-robin iterator [S2][S4, unofficial]. Apply downscaling if $i <$ `resolutionSchedule` [S4, unofficial].
    b.  **Rendering:** Rasterize the Gaussians using camera $V$ to obtain rendered image $I$ [S2]. This involves projecting 3D Gaussians to 2D screen space, sorting by depth, and alpha blending [Parent].
    c.  **Loss Computation:** Compute loss $\mathcal{L}$ between $I$ and $\hat{I}$ [S2].
    d.  **Backpropagation:** Compute gradients $\nabla \mathcal{L}$ for all parameters ($q, s, h, \alpha, \mathbf{p}_w$) using the chain rule [S6, unofficial].
    e.  **Optimization Step:** Update parameters using the Adam optimizer [S2].
    f.  **Adaptive Density Control:** If $i$ is a refinement iteration (e.g., $i \% \text{refineEvery} == 0$) and $i \ge \text{densifyFrom}$:
        i.  **Pruning:** For each Gaussian, if $\alpha < \epsilon$ or the Gaussian is too large (screen size $> \text{split\_screen\_size}$ or covariance norm $||S|| > \tau_S$), prune it [S2].
        ii. **Densification:** If the positional gradient $\nabla_{\mathbf{p}} \mathcal{L} > \tau_p$:
            *   **Over-reconstruction:** If $||S|| > \tau_S$, split the Gaussian into two [S2].
            *   **Under-reconstruction:** Else, clone the Gaussian [S2].
        iii. **Stop Condition:** If $i > \text{densifyUntil}$, skip densification [S3, unofficial].
    g.  **Scheduler Update:** Advance learning rate schedulers [S4, unofficial].

**Pseudocode:**
```python
def train_3dgs(training_data, config):
    # 1. Initialization
    gaussians = []
    for point in training_data.sfm_points:
        g = Gaussian()
        g.position = point # Initialized from SfM
        g.rotation = unit_quaternion()
        g.scale = random_uniform(0, 1)
        g.opacity = constant_initial_opacity
        g.sh_coeffs = init_sh(point.color, config.sh_degree)
        gaussians.append(g)
    
    optimizer = Adam(gaussians.parameters(), lr=config.initial_lr)
    
    # 2. Training Loop
    for step in range(1, config.num_iters + 1):
        # Camera Selection
        cam_idx = camera_iterator.next()
        cam = training_data.cameras[cam_idx]
        gt_image = training_data.get_image(cam_idx, step)
        
        # Rendering
        rendered_image = rasterize(gaussians, cam)
        
        # Loss Computation
        loss = compute_loss(rendered_image, gt_image, config.ssim_weight)
        
        # Backpropagation
        loss.backward()
        
        # Optimization Step
        optimizer.step()
        optimizer.zero_grad()
        
        # Adaptive Density Control
        if is_refinement_iteration(step, config):
            prune_gaussians(gaussians, config)
            densify_gaussians(gaussians, step, config)
            
        # Scheduler Update
        scheduler.step()
        
        # Checkpointing
        if step % config.save_every == 0:
            save_gaussians(gaussians, step)

def prune_gaussians(gaussians, config):
    to_remove = []
    for g in gaussians:
        if g.opacity < config.opacity_threshold:
            to_remove.append(g)
        elif get_screen_size(g) > config.split_screen_size:
            to_remove.append(g)
    gaussians.remove(to_remove)

def densify_gaussians(gaussians, step, config):
    if step > config.densify_until:
        return
    for g in gaussians:
        grad_norm = get_gradient_norm(g.position)
        if grad_norm > config.densify_grad_thresh:
            if get_covariance_norm(g) > config.densify_size_thresh:
                split_gaussian(g) # Over-reconstruction
            else:
                clone_gaussian(g) # Under-reconstruction
```

### HUGS
HUGS creates a coarse-to-fine deformation module using linear blend skinning and local learning-based refinement for animating virtual human avatars based on 3DGS [S1]. It utilizes a tri-plane representation to factorize the canonical space, reconstructing the person and scene from monocular video (50-100 frames) within 30 minutes [S1]. It achieves state-of-the-art human neural rendering performance at 20 FPS [S1].

### Wolf et al. Stereo Method
This method trains a 3DGS to render stereo-calibrated novel views, applies stereo depth estimation on the rendered views, and fuses the estimated dense depth maps using a Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
A labeling pipeline that generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for the densification and pruning processes of 3D-GS optimization [S8, unofficial].

### Cross-View Pruning Mechanism
A mechanism comprising a Cross-View Consistency Loss and adaptive pruning to reduce Gaussian redundancy and ensure geometric validity [S9]. It selects adjacent view pairs with SSIM > 0.6, computes a Cross-View Consistent Loss ($L_{CVC}$) to penalize residual discrepancies, and prunes Gaussians based on depth/distance consistency conditions ($d^i_p < 0.01 \land d^j_p < 0.5 \lor d^i_p > 3\sigma$) [S9].

### Structure-View Co-learning
A module combining structural and view-dependent gradients for robust joint optimization of Gaussian positions and appearance [S9]. The loss is $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$, where $\mathcal{L}_V$ is view gradient loss and $\mathcal{L}_S$ is structure gradient loss [S9].

### Single-view Mini-batch Strategy
A training data sampling strategy where data is organized per viewpoint, and a mini-batch consists of data from only a single viewpoint [S10, unofficial]. For each viewpoint $i$, datasets $D_i$ are collected, and a mini-batch $B_{3DGS}$ is sampled from $D = \{D_i\}$ with count=1 [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is significantly faster than NeRFs, often completing in under an hour for complex scenes [S5, unofficial]. The original implementation takes ~30,000 iterations [S3, S4, unofficial]. Optimized implementations (e.g., Msplat) can train in ~90 seconds on high-end hardware (M4 Max) [S4, unofficial].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians. Default max is 5,000,000 [S3, unofficial]. Sinc splatting variants consume less memory than standard Gaussians [S7].
*   **Performance:** Achieves comparable image quality to NeRFs but with much faster training and real-time rendering [S2]. On the Replica dataset, SGS-SLAM achieves PSNR 34.15, SSIM 0.97, and LPIPS 0.096 [S1].
*   **Hardware:** Supports CUDA, MPS, and CPU. CPU execution is ~100x slower than GPU [S3, S4, unofficial].
*   **Strengths:** Real-time rendering, fast training, high fidelity.
*   **Limitations:** Can produce "floaters" or over-reconstruction artifacts if densification is not properly controlled [S2]. Sensitive to initialization and camera poses .

## Background
3D Gaussian Splatting was introduced as a method for real-time radiance field rendering [9]. The original method initializes positions using sparse point clouds from SfM tools like COLMAP [S2][S6, unofficial]. It differs from NeRFs by using explicit Gaussian primitives rather than implicit neural fields, enabling faster training and rendering [S2][S5, unofficial]. The training process involves iterative optimization of Gaussian parameters to minimize photometric loss, with adaptive density control to manage the number of primitives [S2].
