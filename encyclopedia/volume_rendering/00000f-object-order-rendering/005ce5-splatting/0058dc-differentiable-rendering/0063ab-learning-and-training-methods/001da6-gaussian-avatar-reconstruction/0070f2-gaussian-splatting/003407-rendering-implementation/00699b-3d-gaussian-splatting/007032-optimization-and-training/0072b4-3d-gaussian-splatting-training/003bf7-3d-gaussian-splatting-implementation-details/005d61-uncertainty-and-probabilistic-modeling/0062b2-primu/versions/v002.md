# PRIMU

Also called: Primitive-based Representations of Uncertainty

## Overview
PRIMU is a post-hoc uncertainty estimation (UE) framework for 3D Gaussian Splatting (GS) that constructs primitive-level representations of error and visibility/coverage from training views to estimate uncertainties for novel views [S1, unofficial]. Unlike methods that estimate per-primitive uncertainty during training via Fisher information or learned distributions, PRIMU operates entirely as post-processing, requiring no GS retraining [S1, unofficial]. It extracts 13 optionally direction-dependent Gaussian-primitive features from training-view coverage and reconstruction error, renders them as uncertainty feature maps, and aggregates them via pixel-wise regression on holdout data [S1, unofficial]. This approach yields accurate, generalizable depth and rendering uncertainty estimates, outperforming state-of-the-art methods, particularly for depth UE and foreground objects [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** A trained 3D Gaussian Splatting model (means $\bar{\mu}$, covariances $\bar{\Sigma}$, opacities $g$, colors $c_k(\vec{d})$), a set of training views $\Omega$, and their corresponding rendered images and depth maps.
*   **Outputs:** Per-pixel uncertainty estimates for novel views (color and depth), or uncertainty feature maps for active view selection.

**Data Structures**
The method extracts 13 features per Gaussian primitive $k$. These features are stored as attributes on the Gaussian primitives. The features are derived from:
1.  **Field-of-View (FoV) Count:** $F(k) = |\Omega_k|$, where $\Omega_k$ is the set of training views in which the $k$-th Gaussian primitive lies within the viewing cone [S1, unofficial].
2.  **Training-View Coverage:** $V(k)$, representing how well the Gaussian is covered in training data.
3.  **Rendering Error:** $E(k)$, representing the reconstruction error weighted by the Gaussian's contribution.
4.  **Direction-Dependent Features:** Optionally, features can be direction-dependent, though the base formulation aggregates over views [S1, unofficial].

**Numbered Steps**
1.  **Project Training Errors and Coverage:** For each Gaussian primitive $k$, compute its contribution factors $\alpha_k(\bar{x}) T_k(\bar{x})$ over visible pixels in each training view $v \in \Omega$.
    *   Compute the **Training-View Coverage** $V(k)$:
        $$ V(k) = \max_{v \in \Omega} \text{agg}_{\bar{x} \in v^{(k)}} \alpha_k(\bar{x}) T_k(\bar{x}) $$
        where $v^{(k)}$ are pixels in view $v$ where the opacity of the $k$-th Gaussian exceeds a small threshold, and $\text{agg} \in \{\text{max, sum, mean}\}$ [S1, unofficial].
    *   Compute the **Rendering Error** $E(k)$:
        $$ E(k) = \text{mean}_{v \in \Omega} \text{agg}_{\bar{x} \in v^{(k)}} e_{\bar{x}} \alpha_k(\bar{x}) T_k(\bar{x}) $$
        where $e_{\bar{x}}$ is the per-pixel $\ell_1$ reconstruction error [S1, unofficial].
    *   Compute the **FoV Count** $F(k)$:
        $$ F(k) = |\Omega_k| $$
        where $\Omega_k$ is the set of training views where the $k$-th Gaussian is within the viewing cone [S1, unofficial].
    *   Extract additional features to reach a total of 13 features. These may include direction-dependent variants of the above or other statistical aggregates [S1, unofficial].

2.  **Render Uncertainty Feature Maps:** For a novel viewpoint, project the 3D Gaussians to 2D splats. Render the 13 primitive-level features using the standard alpha-blending accumulation, producing 13 uncertainty feature maps.
    *   The opacity of a Gaussian primitive at pixel $\bar{x}$ is:
        $$ \alpha(\bar{x}) = g \Phi(\bar{x}; \bar{\mu}, \bar{\Sigma}) $$
        where $\Phi$ is the 2D Gaussian density with mean $\bar{\mu}$ and covariance $\bar{\Sigma}$ [S1, unofficial].
    *   The accumulated transparency is:
        $$ T_k(\bar{x}) = \prod_{j=1}^{k-1} (1 - \alpha_j(\bar{x})) $$
    *   The final rendered value for a feature $f$ at pixel $\bar{x}$ is:
        $$ F_{\text{map}}(\bar{x}) = \sum_{k=1}^{K} f_k \alpha_k(\bar{x}) T_k(\bar{x}) $$
        where $f_k$ is the value of the feature for the $k$-th Gaussian [S1, unofficial].

3.  **Aggregate via Regression:** Use a gradient boosting regression model trained on holdout data to map the 13 uncertainty feature maps to final uncertainty estimates.
    *   The regression model takes the 13 feature map values at each pixel as input and outputs the predicted uncertainty (e.g., depth error or rendering error).
    *   The model is trained on a subset of views (holdout data) where the true error is known.

4.  **Active View Selection (Optional):** Use the uncertainty feature maps directly to guide active view selection (AVS) by prioritizing viewpoints with high uncertainty indicators, without training a regression model [S1, unofficial].

**Pseudocode**
```python
def compute_primu_features(gaussians, training_views):
    """
    Compute 13 primitive-level features for each Gaussian.
    gaussians: List of Gaussian objects with attributes:
        - mean (3D)
        - covariance (3x3)
        - opacity (scalar)
        - color (SH coefficients)
    training_views: List of view objects with attributes:
        - camera pose
        - intrinsics
        - rendered_image
        - rendered_depth
    """
    features = []
    for k, G in enumerate(gaussians):
        # Initialize feature vector
        f = [0.0] * 13
        
        # 1. FoV Count
        fov_count = 0
        for v in training_views:
            if is_in_fov(G, v):
                fov_count += 1
        f[0] = fov_count
        
        # 2. Training-View Coverage (V(k))
        max_agg_coverage = 0.0
        for v in training_views:
            # Get pixels where G is visible
            visible_pixels = get_visible_pixels(G, v)
            if not visible_pixels:
                continue
            # Aggregate contribution factors
            contributions = []
            for x in visible_pixels:
                alpha = compute_opacity(G, x)
                T = compute_transparency(G, x, v) # Requires sorting
                contributions.append(alpha * T)
            agg_val = max(contributions) # Using max aggregation
            if agg_val > max_agg_coverage:
                max_agg_coverage = agg_val
        f[1] = max_agg_coverage
        
        # 3. Rendering Error (E(k))
        total_error_weighted = 0.0
        total_weight = 0.0
        for v in training_views:
            visible_pixels = get_visible_pixels(G, v)
            if not visible_pixels:
                continue
            for x in visible_pixels:
                alpha = compute_opacity(G, x)
                T = compute_transparency(G, x, v)
                error = get_pixel_error(v, x) # L1 error
                weight = alpha * T
                total_error_weighted += error * weight
                total_weight += weight
        if total_weight > 0:
            f[2] = total_error_weighted / total_weight
        else:
            f[2] = 0.0
            
        # 4-13. Additional features (direction-dependent or other aggregates)
        # Not specified in detail in sources, but total is 13.
        # Placeholder for additional features [G]
        for i in range(3, 13):
            f[i] = 0.0 # Placeholder
            
        features.append(f)
    return features

def render_uncertainty_maps(gaussians, novel_view, features):
    """
    Render 13 uncertainty feature maps for a novel view.
    """
    # Sort Gaussians front-to-back
    sorted_gaussians = sort_front_to_back(gaussians, novel_view)
    
    # Initialize 13 feature maps
    feature_maps = [np.zeros((H, W)) for _ in range(13)]
    
    # Alpha blending accumulation
    T = np.ones((H, W))
    for k, G in enumerate(sorted_gaussians):
        f = features[k]
        # Project G to 2D
        alpha_map = compute_alpha_map(G, novel_view)
        # Accumulate
        for i in range(13):
            feature_maps[i] += f[i] * alpha_map * T
        T *= (1 - alpha_map)
        
    return feature_maps

def predict_uncertainty(feature_maps, regression_model):
    """
    Predict uncertainty using gradient boosting regression.
    """
    # Flatten feature maps to pixel-wise features
    pixel_features = np.stack([fm.flatten() for fm in feature_maps], axis=1)
    # Predict
    uncertainty = regression_model.predict(pixel_features)
    return uncertainty.reshape(feature_maps[0].shape)
```

**Parameters**
*   **Number of features:** 13 [S1, unofficial].
*   **Aggregation functions:** max, sum, or mean for contribution factors [S1, unofficial].
*   **Regression model:** Gradient boosting regression [S1, unofficial].
*   **Threshold:** Small threshold for visibility in training views (value not specified) [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Geometry Misalignment:** Gaussian splats may misalign with scene geometry even when rendered appearance is correct, leading to depth error between true geometry and splat distribution [S1, unofficial].
*   **Undefined Depth Error:** Undefined depth error is represented as light gray in visualizations, indicating regions where depth cannot be reliably estimated [S1, unofficial].
*   **Generalization:** The regression model shows generalization capabilities to unseen scenes, enabling UE without additional holdout data [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Post-processing step is efficient as it involves projecting existing Gaussians and rendering feature maps. Regression is fast for gradient boosting.
*   **Memory Complexity:** Requires storing 13 additional features per Gaussian primitive.
*   **Performance:** Outperforms state-of-the-art methods for depth UE and foreground objects [S1, unofficial].
*   **Strengths:** No retraining required; generalizes to unseen scenes; effective for active view selection.
*   **Limitations:** Relies on the quality of the initial GS reconstruction; may not capture all sources of uncertainty if training data is insufficient.

## Background
PRIMU was introduced by Stehr et al. in 2025 [S1, unofficial]. It addresses the need for reliable uncertainty estimation in safety-critical domains such as robotics and medicine [S1, unofficial]. The method builds on the principles of Gaussian Splatting [14] and extends them with post-hoc uncertainty representations.
