# BoundedGS Leaf Loss and Gradient Management

Also called: Adam with Compact Storage

## Overview
BoundedGS Leaf Loss and Gradient Management is a training optimization for 3D Gaussian Splatting that reduces memory overhead by organizing Gaussians into spatial groups (leaves) and using compact gradient storage [S1, unofficial]. It decouples gradient accumulation to leaf boundaries and maps only necessary gradient rows to the Adam optimizer via a global ID system, while retaining dense gradients for opacity to support global regularization [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Inputs**: 3D Gaussian parameters (position, scale, rotation, opacity, spherical harmonic coefficients), camera views, current training step, and survivor set [S1, unofficial].
- **Outputs**: Updated Gaussian parameters via Adam optimizer, densification statistics based on accumulated screen gradients [S1, unofficial].

**Data Structures**
- **Compact ID Set ($U$)**: The deduplicated union of screened candidate Gaussian IDs across all active groups [S1, unofficial].
- **ID Map**: An `int32` array of length $N$ (total Gaussians) mapping global IDs to indices in the compact gradient storage [S1, unofficial].
- **Gradient Storage**: Position, spherical-harmonic coefficients, log scale, and quaternion use row-sparse gradients with shared candidate IDs; only rows corresponding to IDs in $U$ are stored [S1, unofficial]. Opacity retains a dense gradient because of global regularization [S1, unofficial].
- **Adam State**: Maintained in the standard dense layout inherited from ImprovedGS to ensure compatibility with the optimizer's internal momentum tracking [S1, unofficial].

**Formulas**
1. **Leaf Loss ($L_R$)**: $L_R = 0.8 L1_R + 0.2(1 - SSIM_R)$, where $L1_R$ is the L1 loss and $SSIM_R$ is the SSIM loss computed over the leaf's own image region at its boundary [S1, unofficial].
2. **View Objective ($L_v$)**: $L_v = \frac{1}{HW} \sum_{R \in R_v} L_R + L_{global}$, where $R_v$ is the set of all leaves for view $v$, $HW$ is image height times width, and $L_{global}$ is the global regularization term [S1, unofficial].
3. **Global Regularization ($L_{global}$)**: $L_{global} = \frac{\beta_t}{|S_t|} \sum_{i \in S_t} z_{it}$, where $S_t$ is the current survivor set, $z_{it}$ is the pre-activation opacity parameter for Gaussian $i$ at step $t$, and $\beta_t$ is the coefficient following GNS's target-budget feedback [S1, unofficial].

**Parameters**
- **Global Regularization Coefficient ($\beta_{15K}$)**: Starts at 0.002 during the 15K–19K pruning window [S1, unofficial].
- **Opacity Learning Rate**: Increases fivefold from 0.025 to 0.125 during the 15K–19K pruning window [S1, unofficial].
- **Adam Optimizer**: $\beta_1 = 0.9$, $\beta_2 = 0.999$, $\epsilon = 10^{-15}$ [S1, unofficial].

**Numbered Steps**
1. Compute leaf loss $L_R$ using L1 and SSIM on the leaf's own image region at its boundary [S1, unofficial].
2. Apply global regularizer $L_{global}$ once per view at every step of the 15K–19K pruning window [S1, unofficial].
3. Each leaf obtains an image gradient; explicit rasterization backward adds its contribution to the group’s projected gradients [S1, unofficial].
4. Allocate parameter gradients immediately before projection backward to avoid coexistence with the current group’s earlier leaf state [S1, unofficial].
5. Projection backward runs once after all leaves in that group finish, using direct gradient accumulation of 3DGS, applying activation derivatives within CUDA, and mapping contributions to final candidate gradient rows [S1, unofficial].
6. BoundedGS feeds compact gradient rows through global IDs to the CUDA Adam [S1, unofficial].
7. Adam updates every Gaussian row; a row outside the candidates has zero current image gradient while its first- and second-order momentum continue to update [S1, unofficial].
8. View visibility is a union of global IDs; screen gradients are accumulated by ID across groups before forming each Gaussian’s densification statistic [S1, unofficial].

**Pseudocode**
```python
import math

def compute_l1_loss(rendered, target):
    return math.mean(abs(rendered - target))

def compute_ssim_loss(rendered, target):
    # Standard SSIM implementation assumed [G]
    return math.mean((rendered - target) ** 2)

def compute_image_gradient(leaf):
    # Standard backward pass computes gradient w.r.t. rendered image [G]
    return leaf.rendered_image - leaf.target_image

def boundedgs_leaf_loss_and_gradient_management(gaussians, views, step, survivor_set):
    N = len(gaussians)
    compact_ids = set()
    id_map = {}
    adam_m1 = [0.0] * N
    adam_m2 = [0.0] * N

    for view in views:
        view_loss = 0.0
        # [G] Standard spatial grouping logic to assign Gaussians to leaves per view
        leaves = [g for g in gaussians if g.visible_in_view(view)]

        for leaf in leaves:
            # 1. Leaf Loss Computation
            l1_r = compute_l1_loss(leaf.rendered_image, leaf.target_image)
            ssim_r = compute_ssim_loss(leaf.rendered_image, leaf.target_image)
            l_r = 0.8 * l1_r + 0.2 * (1.0 - ssim_r)
            view_loss += l_r

            # 3. Leaf Gradient Accumulation
            leaf_grad = compute_image_gradient(leaf)
            # Explicitly add contribution to group's projected gradients
            for gid in leaf.gaussian_ids:
                compact_ids.add(gid)

        # 2. Global Regularization
        if 15000 <= step <= 19000:
            beta_t = 0.002
            sum_z = sum(gaussians.opacity_pre_activation[i] for i in survivor_set)
            l_global = (beta_t / len(survivor_set)) * sum_z
            view_loss += l_global

        # 4. Gradient Allocation
        # Allocate parameter gradients immediately before projection backward
        # to avoid coexistence with the current group's earlier leaf state
        compact_idx = 0
        for gid in sorted(compact_ids):
            id_map[gid] = compact_idx
            compact_idx += 1

        # 5. Projection Backward
        # Runs once after all leaves in that group finish
        # Maps contributions to final candidate gradient rows
        for gid in compact_ids:
            compact_idx = id_map[gid]
            gaussians.grad_sparse[compact_idx] = gaussians.grad_dense[gid]

        # 6 & 7. Compact Gradient Mapping & Adam Update
        for gid in range(N):
            if gid in compact_ids:
                grad = gaussians.grad_sparse[id_map[gid]]
            else:
                grad = 0.0

            # Adam updates every Gaussian row; momentum continues even if grad is zero
            adam_m1[gid] = 0.9 * adam_m1[gid] + 0.1 * grad
            adam_m2[gid] = 0.999 * adam_m2[gid] + 0.001 * (grad ** 2)
            bc1 = 1.0 / (1.0 - 0.9 ** (step + 1))
            bc2 = 1.0 / (1.0 - 0.999 ** (step + 1))
            update = adam_m1[gid] * bc1 / (math.sqrt(adam_m2[gid] * bc2) + 1e-15)
            gaussians.update(gid, update)

        # 8. Densification Statistics
        # Screen gradients accumulated by ID across groups before forming densification statistic
        for gid in compact_ids:
            gaussians.densification_stat[gid] = gaussians.grad_dense[gid]

    return gaussians, adam_m1, adam_m2
```

**Edge Cases and Pitfalls**
- **Layout Rebuild**: Changes in image size, group grid, or budget require rebuilding the layout [S1, unofficial].
- **Merger Validation**: Proposed mergers are rechecked before use to ensure consistency [S1, unofficial].
- **Empty Regions**: If a leaf has no pixels or invalid geometry, the L1/SSIM computation should handle empty regions gracefully [G].
- **State Coexistence**: Failing to allocate gradients immediately before projection backward may cause conflicts with earlier leaf states [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Significantly reduces memory usage for gradient storage by using row-sparse gradients for most parameters. Opacity retains dense gradients, which is a trade-off for global regularization [S1, unofficial].
- **Measured Performance**: Not given in the sources.
- **Strengths**: Memory efficiency for gradient storage, compatibility with standard Adam optimizer, support for global regularization [S1, unofficial].
- **Limitations**: Requires maintaining an `int32` ID map and compact gradient storage layout [S1, unofficial].
- **When to use**: High-resolution training where memory is constrained [S1, unofficial].
- **When not to use**: Scenes where global regularization is not desired or memory is abundant [S1, unofficial].

## Background
BoundedGS was introduced in the paper "BoundedGS: Memory-Efficient High-Resolution Training for 3D Gaussian Splatting" (Deng et al., 2025) [S1, unofficial]. It builds on ImprovedGS and GNS (Gaussian Neural Splatting) techniques [S1, unofficial]. The method addresses the memory limitations of standard 3DGS training by organizing Gaussians into leaves and using compact gradient storage [S1, unofficial].
