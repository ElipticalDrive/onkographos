# Optimization and Parallelization

Also called: Training Optimization, Distributed Training, Backprop Parallelization

## Overview
This family encompasses the computational strategies required to efficiently train 3D Gaussian Splatting (3DGS) models, focusing on the optimization loop, gradient computation, and parallel execution across hardware. It addresses the high memory and compute demands of differentiable rasterization by optimizing the backward pass, distributing Gaussian primitives across multiple GPUs, and refining the training pipeline for stability and speed. It differs from sibling methods by covering the broad infrastructure of training (pipelines, distributed systems) rather than specific parameter updates or loss variants.

## Shared principles
The training process relies on a differentiable rasterizer that renders images from a set of 3D Gaussians. The core optimization mechanism involves computing the gradient of a loss function $\mathcal{L}$ (e.g., L1, SSIM) with respect to the Gaussian parameters (position, covariance, opacity, color, SH coefficients) and any auxiliary parameters.

Key shared mathematical components include:
1.  **Alpha Blending**: The color contribution of a Gaussian $i$ is modulated by its opacity $\alpha_i$ and transmittance $T_i$ from preceding Gaussians.
2.  **Gradient Propagation**: Gradients flow from the loss through the pixel color, through the alpha-blending chain, to the individual Gaussian attributes.
3.  **Parallelization Granularity**: Computation is parallelized across pixels, splats (Gaussians), or batches of views. The standard approach is per-pixel backpropagation, but alternatives exist [S2].
4.  **Memory Management**: Large scenes require managing the Gaussian list in memory, potentially across multiple GPUs or via out-of-core techniques.

## Subtopics

### [MaskGaussian Gradient Computation](4254-maskgaussian-gradient-computation.md)
Computes gradients for probabilistic masks $\mathcal{M}_i$ that modulate Gaussian opacity, enabling adaptive pruning. It explicitly accounts for the interaction between mask-modulated Gaussian contributions and background color transmittance.

### [Training Pipeline](5325-training-pipeline.md)
Defines the high-level iterative loop (view sampling, rasterization, loss computation, backpropagation, densification). It orchestrates the training state, distinct from specific gradient or parallelization optimizations.

### [Parallelization for Backpropagation](5989-parallelization-for-backpropagation.md)
Shifts gradient computation granularity from per-pixel to per-splat (per-Gaussian) to improve speed and numerical efficiency.

### [Grendel-GS](7349-grendel-gs.md)
A distributed framework partitioning Gaussians across multiple GPUs to overcome single-device memory limits, using inter-GPU communication for boundary rendering.

### [3D Gaussian Splatting Implementation Details](9128-3d-gaussian-splatting-implementation-details.md)
Provides concrete hyperparameters, half-precision rasterization techniques, and scene extent controls for stable training.

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [S10, unofficial]. The optimization and parallelization techniques described here evolved to address the method's initial limitations in training speed, memory consumption, and scalability to large scenes. Subsequent works like Grendel-GS and MaskGaussian extended the core framework to support distributed training and adaptive representation [S1, S3, S7].
