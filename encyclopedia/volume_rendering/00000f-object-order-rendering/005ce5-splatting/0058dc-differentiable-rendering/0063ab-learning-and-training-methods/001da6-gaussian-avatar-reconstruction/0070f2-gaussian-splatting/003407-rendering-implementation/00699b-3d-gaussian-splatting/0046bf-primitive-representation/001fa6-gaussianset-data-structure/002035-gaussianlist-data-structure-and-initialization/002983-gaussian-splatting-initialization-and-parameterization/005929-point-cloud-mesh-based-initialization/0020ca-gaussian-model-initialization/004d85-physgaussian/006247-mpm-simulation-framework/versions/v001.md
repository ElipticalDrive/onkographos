# MPM Simulation Framework

Also called: Material Point Method

## Overview
The MPM Simulation Framework is a physics-based simulation method used within PhysGaussian to model deformable materials such as cloth, jelly, sand, and snow [S1, unofficial]. It solves the problem of simulating complex continuum mechanics by tracking deformation gradients on particles, allowing for the integration of various constitutive and plasticity models into the rendering pipeline [S1, unofficial]. It is distinguished from its sibling GASP by its specific use of the Material Point Method to handle large deformations and plasticity in a unified representation [S1, unofficial].

## How it works
The framework operates on MPM particles, tracking the deformation gradient $\mathbf{F}$ to measure distortion relative to the initial state [S1, unofficial]. Internal forces are derived from Cauchy stress $\mathbf{T}$, which is computed based on the chosen constitutive model [S1, unofficial]. For plastic materials, the deformation gradient is constrained within an elastic region; if the deformation exceeds this region, a return mapping $Z$ is applied to project the deformation gradient back onto the yield surface [S1, unofficial].

### Inputs and Outputs
*   **Inputs:** Initial particle positions, velocities, deformation gradients $\mathbf{F}$, material parameters (e.g., Lame parameters, yield stress), and time step $\Delta t$.
*   **Outputs:** Updated particle positions, velocities, and deformation gradients for the next simulation step.

### Data Structures
*   **Particle:** Stores position $\mathbf{x}$, velocity $\mathbf{v}$, deformation gradient $\mathbf{F}$, and mass.
*   **Grid:** A background grid used for momentum conservation and advection, storing velocity and force fields.

### Steps
1.  **Grid Initialization:** Map particle mass and momentum to the background grid.
2.  **Force Computation:** Compute internal forces from Cauchy stress $\mathbf{T}$ and external forces (e.g., gravity).
3.  **Grid Update:** Update grid velocities using the forces.
4.  **Advection:** Map grid velocities back to particles to update particle positions and velocities.
5.  **Plasticity Check:** For plastic models, check if the deformation gradient $\mathbf{F}$ exceeds the elastic region.
6.  **Return Mapping:** If the elastic limit is exceeded, apply the return mapping $Z(\mathbf{F})$ to constrain $\mathbf{F}$ [S1, unofficial].

### Formulas
The Cauchy stress $\mathbf{T}$ is defined by the deformation gradient $\mathbf{F}$ [S1, unofficial].

**Neo-Hookean Elasticity:**
$$ \mathbf{T} = \mu(\mathbf{F}\mathbf{F}^T) + (\lambda \log(J) - \mu)\mathbf{I} $$
where $J = \det(\mathbf{F})$, $\mathbf{I}$ is the identity tensor, and $\mu, \lambda$ are Lame parameters [S1, unofficial].

**Lame Parameters:**
$$ \mu = \frac{E}{2(1 + \nu)} $$
$$ \lambda = \frac{\nu E}{(1 + \nu)(1 - 2\nu)} $$
where $E$ is Young’s modulus and $\nu$ is Poisson’s ratio [S1, unofficial].

**StVK + von-Mises Plasticity:**
$$ \mathbf{T} = \mathbf{U}(2\mu\mathbf{\epsilon} + \lambda \text{Tr}(\mathbf{\epsilon}))\mathbf{U}^T $$
where $\mathbf{F} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}$ is the SVD of $\mathbf{F}$, and $\mathbf{\epsilon} = \log(\mathbf{\Sigma})$ is the Hencky strain [S1, unofficial].

**Yield Condition:**
$$ \delta\gamma = \|\hat{\mathbf{\epsilon}}\| - \frac{\tau_Y}{2\mu} > 0 $$
where $\hat{\mathbf{\epsilon}}$ is the normalized Hencky strain and $\tau_Y$ is the yield stress [S1, unofficial].

**Return Mapping (Plasticity):**
$$ Z(\mathbf{F}) = \begin{cases} \mathbf{F} & \delta\gamma \le 0 \\ \mathbf{U} \exp\left(\hat{\mathbf{\epsilon}} - \delta\gamma \frac{\hat{\mathbf{\epsilon}}}{\|\hat{\mathbf{\epsilon}}\|}\right)\mathbf{V}^T & \text{otherwise} \end{cases} $$
Note: The source text provides a garbled formula for the return mapping: `U exp ( 1 2µ ˆ + d Tr(ε)1)V` [S1, unofficial]. The standard interpretation for von-Mises plasticity is used above, but the exact source text is cited as garbled [S1, unofficial].

### Parameters
*   $\mu, \lambda$: Lame parameters [S1, unofficial].
*   $E$: Young’s modulus [S1, unofficial].
*   $\nu$: Poisson’s ratio [S1, unofficial].
*   $\tau_Y$: Yield stress for plasticine [S1, unofficial].
*   $\eta$: Viscosity for viscoplastic models [S1, unofficial].
*   $\Delta t$: Time step [S1, unofficial].

### Edge Cases and Pitfalls
*   **Precision:** Numerical stability in computing $\log(J)$ and SVD decomposition of $\mathbf{F}$ is critical, especially for large deformations [S1, unofficial].
*   **Boundaries:** Handling boundary conditions for particles near the grid edges or domain boundaries requires careful implementation to prevent artifacts [G].
*   **Degenerate Input:** If $\det(\mathbf{F}) \le 0$, the material is inverted, which is physically invalid and requires clamping or reinitialization [G].

## Subtopics

### Neo-Hookean Elasticity
A constitutive model for elastic objects using Cauchy stress defined by deformation gradient $\mathbf{F}$ [S1, unofficial]. It is chosen for modeling elastic materials like rubber or soft tissue. The stress is given by $\mathbf{T} = \mu(\mathbf{F}\mathbf{F}^T) + (\lambda \log(J) - \mu)\mathbf{I}$ [S1, unofficial].

### StVK + von-Mises Plasticity Model
Simulates plasticine using the St.Venant-Kirchhoff (StVK) constitutive model combined with von-Mises plastic return mapping [S1, unofficial]. It is chosen for materials that exhibit plastic deformation after a yield stress is exceeded. The stress is $\mathbf{T} = \mathbf{U}(2\mu\mathbf{\epsilon} + \lambda \text{Tr}(\mathbf{\epsilon}))\mathbf{U}^T$ [S1, unofficial].

### Viscoplastic Model
Models non-Newtonian fluid with yield stress using a viscoplastic model (Yue et al., 2015) with von-Mises criteria for the elastic region [S1, unofficial]. It is chosen for materials like dough or mud that flow under stress. The return mapping is defined as $Z(\mathbf{F}) = \mathbf{U} \exp\left(\frac{1}{2\mu}\hat{\mathbf{\epsilon}} + \frac{1}{d}\text{Tr}(\mathbf{\epsilon})\mathbf{I}\right)\mathbf{V}^T$ if $\delta\gamma > 0$, otherwise $Z(\mathbf{F}) = \mathbf{F}$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of particles and grid cells. Typically $O(N)$ per time step, where $N$ is the number of particles.
*   **Memory Complexity:** $O(N)$ for particle data and $O(M)$ for grid data, where $M$ is the number of grid cells.
*   **Strengths:** Supports complex constitutive and plasticity models; handles large deformations well.
*   **Limitations:** Computationally expensive for high-resolution simulations; requires careful tuning of material parameters.
*   **When to Use:** When simulating materials with significant plastic deformation or complex rheology (e.g., plasticine, non-Newtonian fluids).
*   **When Not to Use:** For purely elastic, small-deformation scenarios where simpler methods suffice.

## Background
The Material Point Method (MPM) was introduced as a numerical technique for simulating continuum mechanics [S1, unofficial]. It has been integrated into neural rendering frameworks like PAC-NeRF to provide physics-based constraints for geometry reconstruction [S1, unofficial]. The specific implementation in PhysGaussian draws from continuum mechanics literature, including works on continuum foam and non-Newtonian fluids [S1, unofficial].
