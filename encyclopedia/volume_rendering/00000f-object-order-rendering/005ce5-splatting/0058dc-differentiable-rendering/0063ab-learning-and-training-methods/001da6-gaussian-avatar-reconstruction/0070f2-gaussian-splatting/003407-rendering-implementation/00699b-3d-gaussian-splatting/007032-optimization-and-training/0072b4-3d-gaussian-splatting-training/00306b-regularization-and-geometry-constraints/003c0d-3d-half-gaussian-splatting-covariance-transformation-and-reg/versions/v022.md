# 3D Half-Gaussian Splatting Covariance Transformation and Regularization

Also called: 3D-HGS

## Overview
This method modifies the covariance matrix of 3D Gaussians to enforce a "half-Gaussian" shape, effectively cutting the ellipsoid along a plane defined by the local surface normal. This addresses the geometric validity issue in [Base 3DGS Optimization](7549-base-3dgs-optimization.md) where full ellipsoids bleed into empty space, causing artifacts and noise. Unlike [Frequency Regularization](6130-frequency-regularization.md) which targets spectral fidelity, this method directly constrains the spatial support of the kernel to align with surface geometry, improving surface alignment and reducing "dust" artifacts.

## How it works
The method transforms the standard 3D Gaussian covariance matrix $\Sigma$ into a local coordinate system aligned with the surface normal, modifies the diagonal elements to zero out the component along the normal, and transforms it back. This operation is applied periodically during training.

### Inputs and Outputs
*   **Input**: The original covariance matrix $\Sigma$ (3x3 symmetric positive definite), the surface normal vector $n$ (3x1).
*   **Output**: The regularized covariance matrix $\sigma$ (3x3).

### Data Structures
*   **Covariance Matrix**: A 3x3 matrix. In the source, it is stored as a dense matrix.
*   **Basis Matrix**: A 3x3 matrix formed by concatenating two tangent vectors $v_1, v_2$ and the normal $n$.

### Parameters
*   **Regularization Interval**: The transformation is performed every 5000 iterations [S1].
*   **Opacity Threshold**: Increased to 0.01 for densification and pruning to eliminate noise [S1].
*   **Half-Gaussian Opacity Reset**: Set to 0.02 for newly created half-Gaussians [S1].
*   **Scaling Factor**: The minimum of the modified diagonal elements is divided by 100 for the normal component [S1].

### Algorithm Steps
1.  **Normalize Normal**: Compute $n \leftarrow n / \|n\|$.
2.  **Construct Basis Vectors**:
    *   If $n_x = 0$ and $n_y = 0$, set $v_1 = (1, 0, 0)$ and $v_2 = (0, 1, 0)$.
    *   Otherwise, compute $v_1 \leftarrow (n_y, -n_x, 0) / \|(n_y, -n_x, 0)\|$ and $v_2 \leftarrow (n \times v_1) / \|n \times v_1\|$.
3.  **Form Basis Matrix**: Construct $B = [v_1, v_2, n]$ (columns are $v_1, v_2, n$).
4.  **Transform to Basis Space**: Compute $C = B^T \Sigma B$.
5.  **Compute Modified Diagonal Elements**:
    *   $a' = C_{0,0} - C_{0,2}^2 / C_{2,2}$
    *   $b' = C_{0,1} - (C_{0,2} C_{1,2}) / C_{2,2}$
    *   $c' = C_{1,1} - C_{1,2}^2 / C_{2,2}$
6.  **Construct Regularized Matrix in Basis Space**:
    *   Create matrix $\sigma_{local}$ where:
        *   $\sigma_{local}[0,0] = a'$
        *   $\sigma_{local}[0,1] = b'$
        *   $\sigma_{local}[1,0] = b'$
        *   $\sigma_{local}[1,1] = c'$
        *   $\sigma_{local}[2,2] = \min(a', c') / 100$
        *   All other elements are 0.
7.  **Transform Back to World Space**: Compute $\sigma = B \sigma_{local} B^T$.

### Pseudocode
```python
import numpy as np

def regularize_covariance(cov_matrix: np.ndarray, normal: np.ndarray) -> np.ndarray:
    """
    Transforms a 3D Gaussian covariance matrix into a half-Gaussian shape
    aligned with the given surface normal.
    
    Args:
        cov_matrix: 3x3 symmetric covariance matrix Sigma.
        normal: 3x1 surface normal vector n.
        
    Returns:
        3x3 regularized covariance matrix sigma.
    """
    # 1. Normalize normal
    n = normal / np.linalg.norm(normal)
    
    # 2. Construct basis vectors v1, v2
    if n[0] == 0 and n[1] == 0:
        v1 = np.array([1.0, 0.0, 0.0])
        v2 = np.array([0.0, 1.0, 0.0])
    else:
        # v1 is perpendicular to n in the xy-plane projection
        v1_raw = np.array([n[1], -n[0], 0.0])
        v1 = v1_raw / np.linalg.norm(v1_raw)
        
        # v2 is perpendicular to both n and v1
        v2_raw = np.cross(n, v1)
        v2 = v2_raw / np.linalg.norm(v2_raw)
        
    # 3. Form Basis Matrix B (columns are v1, v2, n)
    B = np.column_stack((v1, v2, n))
    
    # 4. Transform to basis space: C = B^T * Sigma * B
    C = B.T @ cov_matrix @ B
    
    # 5. Compute modified elements
    # Note: Source assumes C[2,2] is non-zero. If C[2,2] is near zero, 
    # this division may be unstable. [G] Guard against division by zero.
    if C[2, 2] < 1e-8:
        # Fallback: return original or identity-like regularization if normal component is negligible
        # This is a safeguard not explicitly in source but necessary for stability.
        return cov_matrix 
        
    a_prime = C[0, 0] - (C[0, 2] ** 2) / C[2, 2]
    b_prime = C[0, 1] - (C[0, 2] * C[1, 2]) / C[2, 2]
    c_prime = C[1, 1] - (C[1, 2] ** 2) / C[2, 2]
    
    # 6. Construct regularized matrix in basis space
    sigma_local = np.zeros((3, 3))
    sigma_local[0, 0] = a_prime
    sigma_local[0, 1] = b_prime
    sigma_local[1, 0] = b_prime
    sigma_local[1, 1] = c_prime
    sigma_local[2, 2] = min(a_prime, c_prime) / 100.0
    
    # 7. Transform back to world space: sigma = B * sigma_local * B^T
    sigma = B @ sigma_local @ B.T
    
    return sigma
```

### Edge Cases and Pitfalls
*   **Division by Zero**: The calculation of $a', b', c'$ involves division by $C_{2,2}$. If the covariance has no variance along the normal direction (or is numerically unstable), this will fail. A guard is required [G].
*   **Degenerate Normals**: If the normal vector is zero or near-zero, the basis construction fails. The normal must be normalized first [S1].
*   **Precision**: The subtraction of terms in $a', b', c'$ can lead to loss of precision if $C_{0,2}^2/C_{2,2}$ is close to $C_{0,0}$.

## Operating characteristics
*   **Time Complexity**: The transformation involves matrix multiplications ($3 \times 3$) and vector operations, which is $O(1)$ per Gaussian. However, it is only applied every 5000 iterations, so the average overhead per iteration is negligible.
*   **Memory Complexity**: No additional memory is required beyond the existing Gaussian parameters.
*   **Performance**: On the Mip-NeRF 360 dataset, 3D-HGS with an efficient rasterizer achieves 125 FPS and 29.66 PSNR using 3.8M kernels, compared to 3DGS which uses 3.2M kernels [S1]. On Tank & Dengin, it achieves 160 FPS and 24.45 PSNR with 1.8M kernels [S1]. On Tank & Blending, it achieves 126 FPS and 29.76 PSNR with 2.6M kernels [S1].
*   **Strengths**: Reduces noise and "dust" artifacts by enforcing surface alignment. Improves PSNR over original 3DGS [S1].
*   **Limitations**: Requires accurate surface normals. If normals are noisy, the regularization may distort the geometry incorrectly.

## Background
3D Half-Gaussian Splatting (3D-HGS) was introduced to address the limitations of full 3D Gaussians in representing sharp surface boundaries. By cutting the Gaussian ellipsoid along the surface normal, it better models the transition between object surfaces and empty space. The method was evaluated against Scaffold, mip-splatting, and MCMC architectures [S1].
