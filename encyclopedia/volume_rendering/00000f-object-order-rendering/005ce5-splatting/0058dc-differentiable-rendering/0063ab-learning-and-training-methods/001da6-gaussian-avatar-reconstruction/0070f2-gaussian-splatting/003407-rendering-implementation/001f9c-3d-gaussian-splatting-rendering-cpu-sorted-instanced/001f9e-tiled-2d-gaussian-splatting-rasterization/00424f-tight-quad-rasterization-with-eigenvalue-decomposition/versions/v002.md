# Tight Quad Rasterization with Eigenvalue Decomposition

Also called: Eigenvalue-based Tight Quad Rasterization

## Overview
This method renders 3D Gaussians as tightly fitted, non-axis-aligned quads to minimize overdraw and improve rendering performance, particularly on mobile hardware. It differs from standard axis-aligned bounding box approaches by computing a rotated rectangle that incorporates the splat's alpha value, ensuring only relevant pixels are processed.

## How it works
**Inputs:** 3D Gaussian parameters (mean $\mathbf{\mu}$, 3D covariance $\Sigma$, opacity $\alpha$, color $C$); camera projection matrix $P$; clipping threshold $\tau_\lambda$.
**Outputs:** Rasterized image with alpha-blended Gaussians.

**Data Structures:**
*   **Gaussian:** Struct containing `mean` (vec3), `covariance` (mat3), `opacity` (float), `color` (vec3).
*   **Quad:** Defined by center $\mathbf{c}$, two orthogonal basis vectors $\mathbf{u}, \mathbf{v}$, and half-extents $h_u, h_v$.

**Steps:**
1.  **Cull Negative Opacity:** Discard Gaussians where $\alpha < 0$ [S1].
2.  **Project Covariance:** Compute the 2D screen-space covariance matrix $\Sigma_{2D}$ using the Jacobian of the projection. Let $J$ be the Jacobian of the projection transform at $\mathbf{\mu}$. Then $\Sigma_{2D} = J \Sigma_{3D} J^T$ [S1, implied by standard EWA].
3.  **Eigen Decomposition:** Compute eigenvalues $\lambda_1, \lambda_2$ and eigenvectors $\mathbf{e}_1, \mathbf{e}_2$ of $\Sigma_{2D}$ [S1].
4.  **Compute Basis and Extents:**
    *   The eigenvectors $\mathbf{e}_1, \mathbf{e}_2$ define the orientation of the quad.
    *   The eigenvalues determine the scale. The half-extents are derived from the square roots of the eigenvalues, scaled by a factor that incorporates the alpha value to ensure a tight fit [S1]. Let $k$ be a scaling factor (e.g., 3 for 3-sigma coverage). The half-extents are $h_u = k \sqrt{\lambda_1}$ and $h_v = k \sqrt{\lambda_2}$.
5.  **Clipping Check:** Calculate the maximum axis length $L_{max} = \max(h_u, h_v)$. If $L_{max} > \tau_\lambda$, discard the Gaussian [S1]. This prevents processing Gaussians with large splats that extend outside the view frustum but have means outside it.
6.  **Emit Quad:** Construct a non-axis-aligned quad centered at the projected mean $\mathbf{p}$, with axes $\mathbf{u} = \mathbf{e}_1$ and $\mathbf{v} = \mathbf{e}_2$, and extents $h_u, h_v$.
7.  **Rasterize:** Render the quad to the fragment shader. The fragment shader computes the alpha value based on the distance from the center in the eigenbasis and blends it into the frame buffer.

**Pseudocode:**
```python
def render_tight_quad(gaussian, projection_matrix, tau_lambda):
    # 1. Cull negative opacity
    if gaussian.opacity < 0:
        return None

    # 2. Project 3D covariance to 2D
    # J is the Jacobian of the projection at gaussian.mean
    J = compute_projection_jacobian(gaussian.mean, projection_matrix)
    Sigma_2D = J @ gaussian.covariance @ J.T

    # 3. Eigen decomposition
    eigenvalues, eigenvectors = torch.linalg.eigh(Sigma_2D)
    # eigenvalues are sorted ascending by default in some libraries, ensure order
    lambda_1, lambda_2 = eigenvalues[1], eigenvalues[0] # Assuming largest first for clarity
    e_1, e_2 = eigenvectors[:, 1], eigenvectors[:, 0]

    # 4. Compute extents incorporating alpha
    # The source mentions incorporating alpha into the bound rectangle.
    # A common implementation uses a scaling factor k (e.g., 3) and potentially
    # a function of alpha to tighten the bound.
    k = 3.0
    h_u = k * torch.sqrt(lambda_1)
    h_v = k * torch.sqrt(lambda_2)

    # 5. Clipping check
    max_axis = max(h_u, h_v)
    if max_axis > tau_lambda:
        return None

    # 6. Emit Quad
    projected_mean = project_point(gaussian.mean, projection_matrix)
    quad = Quad(
        center=projected_mean,
        axis_u=e_1,
        axis_v=e_2,
        half_extent_u=h_u,
        half_extent_v=h_v
    )
    return quad
```

A rasterization method for 3D Gaussians that projects the 3D covariance to 2D, computes eigenvalues and eigenvectors to determine basis vectors, and emits a quad per splat to the fragment shader for alpha-based blending.

## Operating characteristics
*   **Time Complexity:** Dominated by eigen decomposition per Gaussian, which is $O(1)$ for 2x2 matrices but involves square roots and trigonometric operations.
*   **Memory Complexity:** Minimal overhead per Gaussian for storing the quad parameters.
*   **Performance:** Reduces overdraw compared to axis-aligned boxes, leading to faster fragment shading. The clipping threshold $\tau_\lambda$ significantly speeds up rendering on mobile hardware by culling large, distant splats [S1].
*   **Limitations:** Requires careful tuning of $\tau_\lambda$ and the scaling factor for the alpha incorporation. Eigen decomposition can be numerically unstable if the covariance is near-singular.

## Background
This method is described in "Shape-Shifting Splats: Realtime Context Translation for Gaussian Splatting in VR" [S1]. It builds on the standard 3D Gaussian Splatting rasterization pipeline but optimizes the bounding volume for tighter fitting. It references EWA Splatting [60] and modern implementations like GSplat [54] as predecessors in using non-axis-aligned quads.
