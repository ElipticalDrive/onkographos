# Active View Selection for 3D Gaussian Splatting

Also called: PRIMU Active View Selection, PRIMU-AVS

## Overview
Active View Selection (AVS) for 3D Gaussian Splatting (3DGS) identifies a subset of training views that maximizes final reconstruction quality while limiting the total number of views used [S1, unofficial]. PRIMU-AVS distinguishes itself from the full PRIMU method by omitting the gradient boosting regressor, thereby avoiding the need for an additional hold-out view for training [S1, unofficial]. It relies on a single direction-dependent coverage feature map with max aggregation and dropped opacity to guide view selection [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A set of candidate training views with camera poses, and the current state of 3D Gaussian primitives (position, covariance, opacity, spherical harmonics coefficients) after a specified number of training iterations [S1, unofficial].
*   **Output:** A selected training view from the candidates [S1, unofficial].

**Data Structures**
*   **Coverage Feature Map ($V_{max}$):** A 2D image buffer with the same resolution as the target rendering. Each pixel stores a scalar value representing the maximum direction-dependent coverage of Gaussian primitives [S1, unofficial].
*   **Candidate Views:** A list of camera poses excluding the currently selected training views and the reserved evaluation views [S1, unofficial].

**Parameters**
*   **Total Training Views ($N_{\text{total}}$):** 20 [S1, unofficial].
*   **Initial Views:** 4 (1 fixed + 3 distance-maximized) [S1, unofficial].
*   **Selection Interval:** A new view is added after $100 \times N_{\text{current}}$ iterations, where $N_{\text{current}}$ is the number of views already selected [S1, unofficial].
*   **Opacity Drop:** Opacity is set to $\alpha=1$ (dropped) during coverage calculation [S1, unofficial].

**Steps**
1.  **Initialization:** Select one fixed view as the first training view, then select three additional views by maximizing the Euclidean distance to the camera centers of the existing views [S1, unofficial].
2.  **Initial Training:** Begin training with these 4 views [S1, unofficial].
3.  **Iterative Selection:** Continue training until the iteration count reaches the threshold for the next view selection [S1, unofficial].
4.  **Coverage Rendering:** For each candidate view, render the $V_{max}$ feature map [S1, unofficial].
5.  **Scoring:** Calculate the mean value across all pixels of the rendered map [S1, unofficial].
6.  **Selection:** Select the candidate view with the lowest mean value, which corresponds to the view with the lowest overall coverage from already selected views [S1, unofficial].
7.  **Update:** Add the selected view to the training set [S1, unofficial].
8.  **Termination:** Repeat steps 3-7 until 20 training views are reached [S1, unofficial].

**Pseudocode**
```python
def select_training_views(candidates, current_primitives, current_iterations, n_total=20):
    # 1. Initialization
    selected_views = [candidates[0]]  # Fixed first view [S1, unofficial]
    for _ in range(3):
        best_view = None
        max_min_dist = -1.0
        for cand in candidates:
            if cand in selected_views:
                continue
            min_dist = min(distance(cand.camera_center, sv.camera_center) for sv in selected_views)
            if min_dist > max_min_dist:
                max_min_dist = min_dist
                best_view = cand
        selected_views.append(best_view)

    # 2. Iterative Selection
    current_n = len(selected_views)
    next_threshold = 100 * current_n  # Threshold for next selection [S1, unofficial]

    while current_n < n_total:
        if current_iterations < next_threshold:
            return None  # Training continues [G]

        candidate_scores = {}
        for cand in candidates:
            if cand in selected_views:
                continue
            # Render V_max: direction-dependent coverage, max aggregation, dropped opacity (alpha=1) [S1, unofficial]
            coverage_map = render_coverage_map(cand, current_primitives)
            mean_val = sum(val for row in coverage_map for val in row) / (len(coverage_map) * len(coverage_map[0]))
            candidate_scores[cand] = mean_val

        best_view = min(candidate_scores, key=candidate_scores.get)
        selected_views.append(best_view)
        current_n += 1
        next_threshold += 100 * current_n  # Interval increases by 100 per view [S1, unofficial]

    return selected_views
```

**Edge Cases and Pitfalls**
*   **Evaluation View Reservation:** Every eighth view is removed from the candidate pool and reserved for evaluation to ensure comparability with baselines like FisherRF [S1, unofficial].
*   **Spherical Harmonics Degree:** The interval for raising the spherical harmonics degree is increased from 1000 to 5000 iterations to mitigate overfitting caused by the limited number of views [S1, unofficial].

## Operating characteristics
*   **Performance:** On the MipNeRF360 dataset, PRIMU-AVS achieved PSNR 20.721, SSIM 0.625, and LPIPS 0.34 [S1, unofficial].
*   **Comparison:** It outperforms FisherRF (PSNR 20.392, SSIM 0.586, LPIPS 0.363) and manifold (PSNR 20.102, SSIM 0.610, LPIPS 0.351) [S1, unofficial].
*   **Complexity:** The selection step requires rendering a coverage map for all candidate views, adding computational overhead proportional to the number of candidates and the feature map resolution [S1, unofficial].
*   **Strengths:** Conceptual simplicity, independence from primitives' spatial extent due to max aggregation, and no requirement for a hold-out view for training a regression model [S1, unofficial].
*   **Limitations:** Reliance on a single feature map, potentially missing complex uncertainty correlations captured by the full PRIMU method's 13 feature maps and gradient boosting regressor [S1, unofficial].

## Background
PRIMU-AVS is part of the PRIMU framework, a post-hoc technique for uncertainty estimation in Gaussian splatting [S1, unofficial]. The full PRIMU method uses 13 handcrafted Gaussian primitive-based feature maps to capture training-view coverage and projected error [S1, unofficial]. PRIMU-AVS simplifies this by using only the coverage feature map for view selection, aiming to maximize total coverage of Gaussian primitives across chosen training views [S1, unofficial].
