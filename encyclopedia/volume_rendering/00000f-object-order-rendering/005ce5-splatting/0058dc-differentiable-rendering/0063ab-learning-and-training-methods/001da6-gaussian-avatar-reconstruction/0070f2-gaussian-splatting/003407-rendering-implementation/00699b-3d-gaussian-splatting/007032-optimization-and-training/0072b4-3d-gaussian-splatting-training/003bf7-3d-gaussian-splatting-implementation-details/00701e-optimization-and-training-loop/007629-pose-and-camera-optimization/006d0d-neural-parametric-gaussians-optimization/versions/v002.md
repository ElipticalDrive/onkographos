# Neural Parametric Gaussians Optimization

Also called: two-stage optimization for monocular non-rigid reconstruction

## Overview
Neural Parametric Gaussians (NPGs) is a two-stage optimization procedure designed for high-fidelity monocular non-rigid object reconstruction [S1]. It addresses the ill-posed nature of reconstructing dynamic geometry from single-view video by combining a coarse parametric point model, regularized by a low-rank deformation basis, with 3D Gaussians to capture fine geometric and appearance details [S1]. Unlike standard 3D Gaussian Splatting which treats Gaussians as independent entities, NPGs anchors the representation to a structured template, preventing the geometric collapse often seen in static-camera scenarios [S1].

## How it works
The method optimizes a hybrid representation consisting of a coarse parametric point model and a set of 3D Gaussians. The optimization is split into two distinct stages.

### Inputs and Outputs
**Inputs:**
*   A sequence of monocular images $\{I_t\}_{t=1}^T$ with known camera poses.
*   (Optional) Masks for dynamic objects if static backgrounds are present [S1].
*   Hyperparameters: Deformation basis size $K$, learning rates, iteration counts.

**Outputs:**
*   Coarse parametric point model parameters (positions, deformation basis coefficients).
*   3D Gaussian parameters (positions, covariances, opacities, SH coefficients) relative to the coarse model.

### Data Structures
1.  **Coarse Parametric Point Model:**
    *   A set of $N_p = 1500$ points $\{\mathbf{p}_j\}_{j=1}^{N_p}$ representing the coarse geometry [S1].
    *   A 6-layer Multi-Layer Perceptron (MLP) $\mathcal{M}$ that maps a latent code or timestep to deformation basis coefficients [S1].
    *   Deformation basis size $K$ (typically 25) [S1].
2.  **3D Gaussian Cloud:**
    *   A set of $N_g$ Gaussians $\{g_i\}_{i=1}^{N_g}$.
    *   Each Gaussian $i$ has parameters: position $\mathbf{p}_i$, rotation $\mathbf{q}_i$, scale $\mathbf{s}_i$, opacity $\alpha_i$, and spherical harmonic coefficients $\mathbf{c}_{i,l}$ [S1].
    *   Interpolation weights $\mathbf{w}$ linking Gaussians to the coarse points [S1].

### Numbered Steps

**Stage 1: Coarse Parametric Model Optimization**
1.  **Initialization:** Initialize $N_p = 1500$ points to model the coarse object geometry [S1]. Initialize the 6-layer MLP for deformation basis coefficients [S1].
2.  **Rigidity Loss Application:** Apply a rigidity loss to maintain template consistency across timesteps [S1].
3.  **Optimization Loop:**
    *   Sample a batch of views (batch size 10) [S1].
    *   Render the coarse model and compute loss against ground truth [S1].
    *   Update parameters using the Adam optimizer [S1].
    *   **Parameters:**
        *   Optimizer: Adam [S1].
        *   Learning Rate: $0.0005$ with cosine annealing and warm-up [S1].
        *   Iterations: $100,000$ [S1].
        *   Basis Size $K$: Controls regularization. $K=25$ is optimal for synthetic cactus; smaller $K$ over-regularizes, larger $K$ overfits [S1].

**Stage 2: Gaussian Refinement**
1.  **Initialization:** Initialize 3D Gaussians based on the coarse model from Stage 1 [S1].
2.  **Optional Finetuning:** Optionally finetune Stage 1 parameters during Stage 2 to improve template accuracy [S1].
    *   **Parameters:** Learning rate $0.0001$ for Stage 1 parameters [S1].
3.  **Optimization Loop:**
    *   Sample views and render using the differentiable rasterizer [S1].
    *   Compute photometric loss $\mathcal{L}_{img} = (1 - \lambda) \mathcal{L}_{L1} + \lambda \mathcal{L}_{D-SSIM}$ with $\lambda = 0.2$ [S1].
    *   Backpropagate gradients [S1].
    *   Update parameters using Adam [S1].
    *   **Parameters:**
        *   Iterations: $70,000$ [S1].
        *   Interpolation Weights $\mathbf{w}$ LR: Same as default point position LR in 3DGS [S1].
        *   Gaussian Scale LR: $0.0005$ [S1].
        *   Scale Scheduler: Exponential decay from a high initial value down to $0.0005$ [S1].
        *   Other LRs: Follow default 3DGS schedules [S1].

### Edge Cases and Pitfalls
*   **Template Collapse:** If the camera is very static, the optimized template may collapse to a flat surface, leading to incorrect deformation [S1]. This is a primary failure mode for highly ill-posed monocular setups [S1].
*   **Basis Size Selection:** Choosing $K$ incorrectly leads to either over-regularization (restricting non-rigid deformations) or overfitting (hindering novel view synthesis) [S1].

## Operating characteristics
*   **Performance:** NPGs achieves state-of-the-art results on the Unbiased4D dataset (PSNR 22.348) compared to baselines like Nerfies, HyperNeRF, TiNeuVox, and HexPlane (PSNR 15.92–18.56) [S1].
*   **Strengths:** Successfully keeps coarse geometry intact over the sequence and fits high-frequency details, which previous methods fail to do [S1].
*   **Limitations:** Highly sensitive to camera motion; static cameras can cause template collapse [S1]. Performance depends on the correct selection of the deformation basis size $K$ [S1].
*   **Complexity:** Uses a two-stage process (100k + 70k iterations), which is computationally intensive but necessary for regularization [S1].

## Background
Neural Parametric Gaussians (NPGs) was introduced to address the challenges of monocular non-rigid object reconstruction, a problem that is highly ill-posed due to the lack of multi-view cues [S1]. The method builds upon 3D Gaussian Splatting [S1] but introduces a coarse parametric point model regularized by a low-rank deformation basis to provide structural stability [S1]. It was presented in the paper "Neural Parametric Gaussians for Monocular Non-Rigid Object Reconstruction" [S1].
