# Training Objective and Densification

Also called: MeshGS Training, Tightly/Loosely-bound Training

## Overview
This method defines the optimization objective and densification strategy for **MeshGS** [S1], a variant of 3D Gaussian Splatting that aligns primitives with an explicit mesh surface. It solves the problem of Gaussian splats drifting away from geometry or expanding uncontrollably in free space by introducing surface-aligned constraints. It differs from standard 3DGS [22] by partitioning the Gaussian set $\mathcal{G}$ into **tightly-bound** splats (constrained to the mesh) and **loosely-bound** splats (free to densify via standard rules), and by replacing standard gradient-based densification for the former with mesh-aware sampling [S1].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   A set of training images $I_i$ and their camera poses.
    *   An explicit mesh $M$ consisting of faces $F$ and vertices $V$.
    *   The current set of Gaussian splats $\mathcal{G}$, partitioned into tightly-bound splats $\mathcal{G}^t$ and loosely-bound splats $\mathcal{G}^l$.
*   **Outputs:**
    *   Updated Gaussian parameters (position, scale, rotation, opacity, spherical harmonics) after one optimization step.
    *   Updated partition of $\mathcal{G}$ based on densification/pruning.

### Data Structures
*   **Gaussian Splat $g_i$**: Contains center $P_i$, scale $S_i = (s_1, s_2, s_3) \in \mathbb{R}^3$, rotation $R_i$ (quaternion or matrix), opacity $\alpha_i$, and color coefficients.
*   **Mesh $M$**: Defined by a set of triangular faces $F$. Each face $f_j$ is defined by vertices $v_{j,0}, v_{j,1}, v_{j,2}$ and has a normal $n_{f_j}$.
*   **Distance Threshold $d_{th}$**: Scalar value used to classify splats. Default: $0.01$ [S1].

### Formulas and Definitions

**1. Image Loss ($L_{img}$)**
Combines L1 loss and D-SSIM [S1]:
$$ L_{img} = (1-\lambda_{img})L_{1}(\hat{I}_{i},I_{i}) + \lambda_{img}SSIM(\hat{I}_{i}, I_{i}) $$
Where $\hat{I}_i$ is the rendered image, $I_i$ is the ground truth image, and $\lambda_{img}$ is the weight.

**2. Normal Consistency Loss ($L_{nc}$)**
Aligns tightly-bound splat normals with mesh face normals [S1]:
$$ L_{nc} = \sum_{i \in \mathcal{G}^t, f \in F} (1 - n_{i} \cdot n_{f}) $$
Where $n_i$ is the estimated normal of the splat, and $n_f$ is the normal of the closest mesh face $f$.

**3. Scale Regularization Loss ($L_{scale}$)**
Constrains the scale of tightly-bound splats to match the mesh surface thickness [S1]:
$$ L_{scale} = \sum_{i \in \mathcal{G}^t}(\lambda_{min}|\text{min}(s_{1}, s_{2}, s_{3})| + \lambda_{max}|\text{max}(s_{1}, s_{2}, s_{3}) - \rho |) $$
Where $\lambda_{min}, \lambda_{max}$ are weights, and $\rho$ is the target maximum scale threshold.

**4. Projection Loss ($L_{proj}$)**
Pulls tightly-bound splat centers toward the mesh surface [S1]:
$$ s_{i} = P_{i} + ((P_{i} - v_{i}) \cdot f_{j}) \cdot f_{j} $$
$$ L_{proj} = \sum_{i \in \mathcal{G}^t}\parallel s_{i} - P_{i} \parallel _{2} $$
*Note: The source formula for $s_i$ appears to be a simplified projection onto a face normal vector $f_j$ from a vertex $v_i$. In implementation, $s_i$ is the closest point on the mesh surface to $P_i$.*

**5. Total Loss ($L$)**
$$ L = L_{img} + \lambda_{nc} L_{nc} + L_{scale} + \lambda_{proj} L_{proj} $$

### Parameters
*   $\lambda_{img} = 0.001$ [S1]
*   $\lambda_{nc} = 0.1$ [S1]
*   $\lambda_{min} = 0.1$ [S1]
*   $\lambda_{max} = 10$ [S1]
*   $\lambda_{proj} = 50$ [S1]
*   $\rho = 0.1$ (threshold for max scale) [S1]
*   $d_{th} = 0.01$ (distance threshold for classification) [S1]
*   Total iterations: 30,000 [S1]

### Steps

1.  **Classify Splats**: For each Gaussian $g_i \in \mathcal{G}$, calculate the distance $d_i$ to the nearest point on the mesh surface.
    *   If $d_i \le d_{th}$, classify $g_i$ as tightly-bound ($g_i \in \mathcal{G}^t$).
    *   Otherwise, classify $g_i$ as loosely-bound ($g_i \in \mathcal{G}^l$).
    *   [G] This classification is performed at the start of the training loop or periodically.

2.  **Estimate Splat Normals ($n_i$)**: For each $g_i \in \mathcal{G}^t$:
    *   Identify the axis index $k$ corresponding to the minimum scale value in $S_i = (s_1, s_2, s_3)$.
    *   Extract the basis vector $e_k$ (e.g., $[1,0,0]$ if $k=0$) from the local coordinate system.
    *   Transform $e_k$ to world coordinates using the rotation $R_i$: $n_i = R_i e_k$.

3.  **Compute Losses**:
    *   Render the image $\hat{I}_i$ and compute $L_{img}$.
    *   For each $g_i \in \mathcal{G}^t$, find the closest mesh face $f_j$ and its normal $n_{f_j}$. Compute $L_{nc}$ using the dot product $n_i \cdot n_{f_j}$.
    *   Compute $L_{scale}$ using the min/max of $S_i$ for all $g_i \in \mathcal{G}^t$.
    *   For each $g_i \in \mathcal{G}^t$, compute the closest point $s_i$ on the mesh surface. Compute $L_{proj}$ as the Euclidean distance $\parallel s_i - P_i \parallel_2$.
    *   Sum losses to get $L$.

4.  **Optimize Parameters**: Perform gradient descent on $L$ with respect to all trainable Gaussian parameters (positions, scales, rotations, opacities, colors).

5.  **Densification**:
    *   **For $\mathcal{G}^l$ (Loosely-bound)**: Apply the standard 3DGS densification strategy (clone/split based on gradient magnitude and opacity thresholds) [S1].
    *   **For $\mathcal{G}^t$ (Tightly-bound)**:
        *   Identify regions requiring densification (e.g., high gradient or high error).
        *   Instead of cloning/splitting in 3D space, sample new points from the corresponding mesh triangles.
        *   **Cloning**: Copy the position, scale, rotation, and other attributes from the parent splat to the new splat, initializing the new position at the sampled point on the mesh.
        *   **Splitting**: Create two new splats. Initialize their positions at sampled points on the mesh. Divide the parent's scale by a factor of 1.6. Copy other attributes.
        *   [G] Ensure new splats are added to $\mathcal{G}^t$ and classified correctly.

6.  **Pruning**: Prune splats with low opacity or large distance from the mesh (if they drift into $\mathcal{G}^l$ and fail to densify) [S1].

### Pseudocode

```python
def meshgs_training_step(mesh, gaussians, images, cameras, params):
    """
    One step of MeshGS training.
    """
    # 1. Classify Splats
    G_tight = []
    G_loose = []
    for g in gaussians:
        dist = distance_to_mesh(g.position, mesh)
        if dist <= params.d_th:
            G_tight.append(g)
        else:
            G_loose.append(g)

    # 2. Compute Losses
    loss_img = 0.0
    loss_nc = 0.0
    loss_scale = 0.0
    loss_proj = 0.0

    # Image Loss (standard for all, or weighted)
    rendered_image = render(gaussians, cameras)
    loss_img = (1 - params.lambda_img) * l1_loss(rendered_image, images) + \
               params.lambda_img * ssim_loss(rendered_image, images)

    # Tightly-bound specific losses
    for g in G_tight:
        # Estimate normal: min scale axis rotated to world
        min_scale_idx = argmin(g.scale)
        local_axis = identity_matrix[:, min_scale_idx]
        g.normal = g.rotation @ local_axis

        # Find closest face and normal
        closest_face, face_normal = mesh.get_closest_face_and_normal(g.position)

        # Normal Consistency
        loss_nc += (1.0 - dot(g.normal, face_normal))

        # Scale Regularization
        min_s = min(g.scale)
        max_s = max(g.scale)
        loss_scale += params.lambda_min * abs(min_s) + \
                      params.lambda_max * abs(max_s - params.rho)

        # Projection Loss
        closest_point = mesh.project_point(g.position)
        loss_proj += norm(closest_point - g.position)

    # Total Loss
    total_loss = loss_img + \
                 params.lambda_nc * loss_nc + \
                 loss_scale + \
                 params.lambda_proj * loss_proj

    # 3. Backpropagate and Update
    total_loss.backward()
    optimizer.step()

    # 4. Densification
    # Loosely-bound: Standard 3DGS densification
    densify_loose(G_loose, params)

    # Tightly-bound: Mesh-aware densification
    densify_tight(G_tight, mesh, params)

    # 5. Pruning
    prune_gaussians(gaussians, params)

    return gaussians
```

## Operating characteristics
*   **Time Complexity**: Dominated by rendering and gradient computation. The additional mesh queries (closest point, normal) for $L_{proj}$ and $L_{nc}$ add overhead proportional to the number of tightly-bound splats. [S1]
*   **Memory Complexity**: Standard 3DGS memory plus storage for the mesh structure. [S1]
*   **Performance**: Trained for 30k iterations [S1]. Outperforms LTM [7] and SuGaR [13] in rendering quality on Mip-NeRF360 and Deep Blending datasets [S1].
*   **Strengths**: Prevents splats from drifting off the mesh surface; ensures normals align with geometry; controls scale to prevent excessive expansion. [S1]
*   **Limitations**: Requires an explicit mesh input; densification for tightly-bound splats is more complex than standard 3DGS. [S1]

## Background
Originated in **MeshGS: Adaptive Mesh-Aligned Gaussian Splatting for High-Quality Rendering** [S1]. It builds on the original 3DGS [22] and addresses limitations in methods like SuGaR [13] by explicitly separating splats into tightly-bound and loosely-bound categories to better handle mesh-aligned reconstruction.
