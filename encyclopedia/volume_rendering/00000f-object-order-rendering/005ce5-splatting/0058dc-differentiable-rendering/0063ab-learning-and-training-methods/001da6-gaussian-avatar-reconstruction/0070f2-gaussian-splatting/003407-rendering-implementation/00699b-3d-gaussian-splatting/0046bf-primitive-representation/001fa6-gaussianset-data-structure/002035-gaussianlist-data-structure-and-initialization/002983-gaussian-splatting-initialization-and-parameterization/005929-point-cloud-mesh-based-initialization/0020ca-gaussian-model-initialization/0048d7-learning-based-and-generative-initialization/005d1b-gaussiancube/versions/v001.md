# GaussianCube

Also called: Differentiable 3D Gaussian Splatting, GaussianCube representation

## Overview
GaussianCube is a scene representation method that utilizes an unstructured, explicit set of 3D Gaussians to enable real-time, differentiable radiance field rendering [S1, unofficial]. It solves the problem of high-quality novel-view synthesis by combining the flexibility of point-based models with the volumetric properties of neural radiance fields, avoiding the computational overhead of volumetric ray-marching [S1, unofficial]. Unlike its siblings, it relies on a specific initialization and optimization pipeline where the Gaussian parameters are derived from sparse Structure-from-Motion (SfM) points and refined through interleaved density control, rather than being generated directly from a latent code or voxel grid as in [SF-VAE](14701-sf-vae-spherical-folding-variational-autoencoder.md) or [Volume Prior Initialization](10162-volume-prior-initialization.md).

## How it works
**Inputs and Outputs:**
*   **Input:** A set of images of a static scene and corresponding camera poses calibrated via Structure-from-Motion (SfM), which yields a sparse point cloud [S1, unofficial].
*   **Output:** A set of $N$ 3D Gaussians, each defined by position, covariance, opacity, and spherical harmonic coefficients, optimized to minimize rendering error [S1, unofficial].

**Data Structures:**
Each Gaussian $i$ in the set is defined by the following fields:
1.  **Position ($\mu_i$):** A 3D vector $(x, y, z)$ in world space [S1, unofficial].
2.  **Covariance ($\Sigma_i$):** A $3 \times 3$ symmetric positive-definite matrix, parameterized for optimization by:
    *   **Scale ($s_i$):** A 3D vector $(s_x, s_y, s_z)$ [S1, unofficial].
    *   **Rotation ($q_i$):** A unit quaternion $(w, x, y, z)$ [S1, unofficial].
    *   The matrix is reconstructed as $\Sigma = R S S^T R^T$, where $R$ is the rotation matrix derived from $q_i$ and $S$ is the diagonal scaling matrix derived from $s_i$ [S1, unofficial].
3.  **Opacity ($\alpha_i$):** A scalar value constrained to $(0, 1)$ [S1, unofficial].
4.  **Spherical Harmonics Coefficients ($c_i$):** Coefficients representing directional color appearance [S1, unofficial].

**Initialization:**
1.  Initialize the set of Gaussians using the sparse point cloud produced by SfM [S1, unofficial].
2.  Set the initial covariance matrix $\Sigma$ for each Gaussian to be isotropic, with axes equal to the mean distance to the three closest neighboring points [S1, unofficial].
3.  Initialize positions with an exponential decay schedule [S1, unofficial].

**Optimization Steps:**
The method employs an interleaved optimization process between parameter refinement and adaptive density control [S1, unofficial].

1.  **Parameter Update:**
    *   Compute the rendered image using the current Gaussian set.
    *   Calculate the loss $\mathcal{L}$ between the rendered image and the ground truth image:
        $$ \mathcal{L} = (1 - \lambda)\mathcal{L}_1 + \lambda\mathcal{L}_{\text{D-SSIM}} $$
        where $\lambda = 0.2$ [S1, unofficial].
    *   Update parameters using Stochastic Gradient Descent (SGD) [S1, unofficial].
    *   Apply activation functions to ensure valid parameters:
        *   Opacity $\alpha$ is constrained via a sigmoid activation: $\alpha = \sigma(\alpha_{raw})$ [S1, unofficial].
        *   Scale $s$ is constrained via an exponential activation: $s = \exp(s_{raw})$ [S1, unofficial].
    *   Normalize the rotation quaternion $q$ to maintain unit length [S1, unofficial].

2.  **Adaptive Density Control (Interleaved):**
    *   **Add:** Create new Gaussians in regions with high reprojection error or low opacity [S1, unofficial].
    *   **Clone/Copy:** Duplicate existing Gaussians in regions with high gradient magnitude to increase density [S1, unofficial].
    *   **Prune:** Remove Gaussians with opacity below a threshold [S1, unofficial].
    *   **Split:** Split Gaussians with large covariance scales into smaller Gaussians to capture fine details [S1, unofficial].

**Rendering:**
1.  **Projection:**
    *   For each Gaussian, compute the 2D covariance matrix $\Sigma'$ in camera space:
        $$ \Sigma' = J W \Sigma W^T J^T $$
        where $W$ is the viewing transformation matrix and $J$ is the Jacobian of the affine approximation of the projective transformation [S1, unofficial].
    *   Discard the third row and column of $\Sigma'$ to obtain the $2 \times 2$ 2D covariance matrix [S1, unofficial].

2.  **Sorting:**
    *   Sort Gaussians by depth relative to the camera to respect visibility order [S1, unofficial].

3.  **Rasterization (Splatting):**
    *   Project each Gaussian to 2D to form an elliptical "splat" [S1, unofficial].
    *   Perform alpha blending for each pixel covered by the splats:
        $$ C = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i $$
        where $\mathbf{c}_i$ is the color of the $i$-th Gaussian, $\alpha_i = (1 - \exp(-\sigma_i \delta_i))$ is the opacity contribution, and $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the accumulated transmittance [S1, unofficial].

4.  **Backward Pass:**
    *   Track accumulated transmittance values to compute gradients for all splats contributing to a pixel, enabling fast and accurate backpropagation [S1, unofficial].

**Pseudocode:**

```python
def initialize_gaussians(sfm_points):
    """
    Initialize Gaussian set from SfM point cloud.
    """
    gaussians = []
    for point in sfm_points:
        # Calculate initial isotropic covariance based on neighbors
        dists = compute_distances_to_k_nearest_neighbors(point, k=3)
        scale_init = mean(dists)
        
        # Create Gaussian object
        g = {
            'mu': point.position,
            's_raw': log(scale_init), # Log-scale for exponential activation
            'q_raw': [1.0, 0.0, 0.0, 0.0], # Identity quaternion
            'alpha_raw': logit(0.5), # Logit for sigmoid activation
            'sh_coeffs': zeros(SH_DIMENSION)
        }
        gaussians.append(g)
    return gaussians

def update_covariance(g):
    """
    Reconstruct 3D covariance matrix from scale and rotation.
    """
    # Exponential activation for scale
    s = exp(g['s_raw'])
    S = diag(s)
    
    # Normalize quaternion
    q = normalize(g['q_raw'])
    R = quaternion_to_rotation_matrix(q)
    
    # Sigma = R * S * S^T * R^T
    Sigma = R @ S @ S.T @ R.T
    return Sigma

def project_to_2d(g, camera):
    """
    Project 3D Gaussian to 2D camera space.
    """
    Sigma_3d = update_covariance(g)
    
    # Viewing transformation W
    W = camera.view_matrix
    
    # Jacobian J of projective transformation
    J = compute_jacobian(camera, g['mu'])
    
    # Sigma' = J * W * Sigma * W^T * J^T
    Sigma_prime = J @ W @ Sigma_3d @ W.T @ J.T
    
    # Return 2x2 matrix (skip 3rd row/col)
    return Sigma_prime[:2, :2]

def render(gaussians, camera, image_width, image_height):
    """
    Render scene using tile-based rasterization and alpha blending.
    """
    # 1. Project all Gaussians to 2D
    projected_gaussians = []
    for g in gaussians:
        g_2d = project_to_2d(g, camera)
        projected_gaussians.append((g, g_2d))
        
    # 2. Sort by depth
    projected_gaussians.sort(key=lambda x: x[0]['mu'].z)
    
    # 3. Rasterize
    image = zeros((image_height, image_width, 3))
    
    # Tile-based processing (simplified)
    for tile in get_tiles(image_width, image_height):
        tile_gaussians = filter_gaussians_in_tile(projected_gaussians, tile)
        
        for pixel in tile.pixels:
            transmittance = 1.0
            color = zeros(3)
            
            for g, g_2d in tile_gaussians:
                # Check if pixel is inside Gaussian ellipse
                if not is_inside_ellipse(pixel, g_2d):
                    continue
                
                # Compute opacity
                alpha_raw = g['alpha_raw']
                alpha = sigmoid(alpha_raw)
                
                # Compute color from SH coefficients
                c = evaluate_sh(g['sh_coeffs'], camera.direction_to_pixel(pixel))
                
                # Alpha blending
                color += transmittance * alpha * c
                transmittance *= (1 - alpha)
                
                # Early exit if fully opaque
                if transmittance < 1e-4:
                    break
            
            image[tile.y, tile.x] = color
            
    return image

def optimize(gaussians, images, cameras, lambda_dssim=0.2):
    """
    Interleaved optimization of Gaussian parameters.
    """
    for step in range(num_steps):
        # 1. Render and Compute Loss
        rendered_image = render(gaussians, camera, width, height)
        loss = (1 - lambda_dssim) * l1_loss(rendered_image, ground_truth) + \
               lambda_dssim * dssim_loss(rendered_image, ground_truth)
        
        # 2. Backpropagate and Update Parameters
        gradients = compute_gradients(loss, gaussians)
        update_parameters(gaussians, gradients)
        
        # 3. Adaptive Density Control
        gaussians = adaptive_density_control(gaussians, gradients)
        
    return gaussians
```

**Parameters:**
*   $\lambda$ (SSIM weight): 0.2 [S1, unofficial].
*   Typical scene size: 1-5 million Gaussians [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Covariance Validity:** Directly optimizing the covariance matrix $\Sigma$ is invalid because gradient descent cannot easily constrain it to remain positive semi-definite, leading to invalid matrices [S1, unofficial]. This is mitigated by parameterizing $\Sigma$ via scale and rotation [S1, unofficial].
*   **Opacity Constraints:** Opacity must be constrained to $(0, 1)$; using a sigmoid activation function ensures this [S1, unofficial].
*   **Scale Constraints:** Scale must be positive; using an exponential activation function ensures this [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering is $O(N)$ per pixel where $N$ is the number of Gaussians, but optimized via tile-based rasterization and sorting, achieving real-time performance ($\ge 30$ fps) at 1080p [S1, unofficial].
*   **Memory Complexity:** $O(N)$ where $N$ is the number of Gaussians (1-5 million) [S1, unofficial].
*   **Strengths:** Real-time rendering, high visual quality, differentiable, handles anisotropic structures efficiently, no need for MVS data (only SfM) [S1, unofficial].
*   **Limitations:** Unstructured representation can be less compact than voxel-based methods for very large scenes; requires careful density control to avoid over/under-representation [S1, unofficial].
*   **When to use:** Real-time novel-view synthesis, training data generation for downstream tasks, scenes with complex geometry where volumetric ray-marching is too slow [S1, unofficial].
*   **When not to use:** Scenes requiring extremely high compression or where a structured grid representation is preferred for downstream processing [S1, unofficial].

## Background
Gaussian Splatting was introduced by Kerbl, Kopanas, Leimkühler, and Drettos in 2023 [S1, unofficial]. It builds on the principles of point-based rendering and neural radiance fields, aiming to combine the best of both worlds: the explicit, rasterizable nature of points and the volumetric, differentiable nature of NeRFs [S1, unofficial]. The term "GaussianCube" appears in later literature (e.g., [S2, unofficial]) to describe a specific application or variant where a constant number of Gaussians are converted to a voxelized representation via optimal transport for use in 3D diffusion models [S2, unofficial].
