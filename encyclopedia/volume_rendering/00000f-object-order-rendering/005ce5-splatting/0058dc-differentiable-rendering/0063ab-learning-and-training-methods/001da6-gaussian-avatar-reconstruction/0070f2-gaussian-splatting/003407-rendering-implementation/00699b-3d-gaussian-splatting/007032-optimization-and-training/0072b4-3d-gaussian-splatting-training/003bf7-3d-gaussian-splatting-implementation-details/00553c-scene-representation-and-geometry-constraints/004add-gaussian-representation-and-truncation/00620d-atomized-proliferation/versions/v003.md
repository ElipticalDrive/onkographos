# Atomized Proliferation

Also called: Atom Gaussian Densification, AtomGS, Atomizing Gaussian Splatting for High-Fidelity Radiance Field

## Overview
Atomized Proliferation is a densification and optimization strategy for 3D Gaussian Splatting that enhances geometric precision by constraining fine-detail Gaussians into uniformly-sized "Atom Gaussians" while merging large Gaussians to cover smooth surfaces [S2, unofficial]. It distinguishes itself from standard 3DGS by replacing free-form splitting with a structured proliferation schedule guided by an Edge-Aware Normal Loss, ensuring Gaussians align strictly with scene geometry rather than drifting [S1][S2, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of $N$ 3D Gaussians $\{G_i\}$, each defined by mean $\boldsymbol{\mu}_i$, covariance $\boldsymbol{\Sigma}_i$, color $\mathbf{c}_i$, and opacity $\alpha_i$; input Structure-from-Motion (SfM) points; ground truth RGB images; and pre-optimized normal maps from a base 3DGS reconstruction.
*   **Outputs:** An optimized set of Gaussians with refined geometry, where fine details are represented by isotropic Atom Gaussians and smooth surfaces by merged anisotropic Gaussians.

**Data Structures and Parameters**
The method maintains the standard Gaussian set but introduces specific control parameters [S2, unofficial]:
*   **Clone Threshold ($\tau_c$):** Gradient threshold for cloning. Default: $0.002$.
*   **Split Threshold ($\tau_s$):** Base gradient threshold for splitting. Default: $0.002$.
*   **Prune Threshold ($\varepsilon$):** Opacity threshold for pruning. Default: $0.005$ (or $0.5$ for DTU dataset) [S2, unofficial].
*   **Atom Scale ($S$):** The maximum allowed minimum covariance norm for a Gaussian to be considered an Atom Gaussian. Calculated as the $i$-th percentile of distances between input SfM points: $S = P_i(d)$. Default: $P_1(d)$ (1st percentile) [S2, unofficial].
*   **Atomized Proliferation Duration ($t_a$):** Iteration limit for atomization. Default: $7000$.
*   **Warm-Up Duration ($t_w$):** Iteration limit for the linear warm-up of the split threshold. Default: $7000$ [S2, unofficial].
*   **Optimization Weights:** $\lambda_{ms-ssim} = 0.1$, $\lambda_{normal} = 0.1$ [S2, unofficial].

**Algorithm Steps**
The method operates iteratively over training steps $i$. It combines densification (cloning, splitting, atomization) and pruning [S2, unofficial].

1.  **Calculate Atom Scale:** Compute $S$ from the input SfM point cloud distances $d$. $S = P_1(d)$ [S2, unofficial].
2.  **Iterate Gaussians:** For each Gaussian $G_i$ with properties $(\boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i, \mathbf{c}_i, \alpha_i)$:
    *   **Pruning:** If $\alpha_i < \varepsilon$ or the covariance $\boldsymbol{\Sigma}_i$ is excessively large (determined by `IsTooLarge`), remove the Gaussian [S2, unofficial].
    *   **Cloning:** If the positional loss gradient $\nabla_p \mathcal{L} \ge \tau_c$, clone the Gaussian to bridge geometry gaps [S2, unofficial].
    *   **Splitting:** If $\nabla_p \mathcal{L} \ge \min\left(\frac{i}{t_w}\tau_s, \tau_s\right)$ AND the maximum covariance norm $\|\boldsymbol{\Sigma}\|_{\max} > S$, split the Gaussian. The threshold uses a linear warm-up during $i < t_w$ to encourage aggressive initial densification [S2, unofficial].
    *   **Atomization:** If the minimum covariance norm $\|\boldsymbol{\Sigma}\|_{\min} \le S$ AND $i < t_a$, designate the Gaussian as an Atom Gaussian. Its scale is fixed and updated via geometric progression rather than backpropagation:
        $$ S_n = S_{n-1} \cdot r^{n-1} $$
        where $r = p^{1/t_a}$, $p$ is the final proportion to the initial $S$, and $n$ is the current atomization iteration. This ensures Atom Gaussians shrink progressively to refine fine details [S2, unofficial].
3.  **Geometry-Guided Optimization:** Update Gaussian positions and orientations using a composite loss function that includes the Edge-Aware Normal Loss [S1][S2, unofficial].

**Edge-Aware Normal Loss**
To guide optimization, the method computes an Edge-Aware Normal Loss. Let $\mathbf{N}_{pred}$ be the normal map derived from the pre-optimized 3DGS Gaussians, and $\mathbf{E}_{gt}$ be the edge map derived from the gradient magnitude of the ground truth RGB image. The loss is:
$$ \mathcal{L}_{normal} = \mathbf{N}_{pred} \odot \mathbf{E}_{gt} $$
This integrates 2D edge weights into the curvature map, imposing stricter constraints on Gaussians aligned with flat surfaces while allowing flexibility for irregular shapes [S2, unofficial].

**Pseudocode**
```python
def atomized_proliferation(Gaussians, SfM_points, gt_images, pre_opt_normals, 
                           tau_c=0.002, tau_s=0.002, epsilon=0.005, 
                           ta=7000, tw=7000, lambda_ms_ssim=0.1, lambda_normal=0.1):
    # 1. Calculate Atom Scale S from SfM points
    distances = compute_pairwise_distances(SfM_points)
    S = percentile(distances, 1)  # P1(d)
    
    # 2. Initialize optimization state
    for i in range(total_iterations):
        # 2a. Compute Losses
        rendered_images = render(Gaussians)
        loss_rgb = compute_l1_loss(rendered_images, gt_images)
        loss_ms_ssim = compute_ms_ssim_loss(rendered_images, gt_images)
        
        # Compute Edge-Aware Normal Loss
        pred_normals = render_normals(Gaussians)
        edge_maps = compute_gradient_magnitude(gt_images)
        loss_normal = sum(pred_normals * edge_maps)
        
        total_loss = loss_rgb + lambda_ms_ssim * loss_ms_ssim + lambda_normal * loss_normal
        
        # 2b. Compute Positional Gradients
        gradients = compute_gradients(total_loss, Gaussians.mu)
        
        # 2c. Iterate and Modify Gaussians
        new_gaussians = []
        for G in Gaussians:
            mu, Sigma, c, alpha = G
            
            # Pruning
            if alpha < epsilon or is_too_large(Sigma):
                continue # Prune
            
            # Cloning
            if gradients[G] >= tau_c:
                clone = clone_gaussian(G)
                new_gaussians.append(clone)
            
            # Splitting (with warm-up)
            current_split_threshold = min((i / tw) * tau_s, tau_s)
            if gradients[G] >= current_split_threshold and max_norm(Sigma) > S:
                split_gaussians = split_gaussian(G)
                new_gaussians.extend(split_gaussians)
            
            # Atomization
            if min_norm(Sigma) <= S and i < ta:
                atomized = atomize_gaussian(G, S, i, ta)
                new_gaussians.append(atomized)
            else:
                new_gaussians.append(G)
        
        # 2d. Update Gaussians via Backprop (except Atom scales)
        # Note: Atom Gaussian scales are updated via geometric progression, not backprop
        Gaussians = optimize_step(new_gaussians, total_loss)
        
        # Update Atom scales geometrically if needed
        for G in Gaussians:
            if is_atom(G):
                G.scale = geometric_progression_update(G.scale, ta)

    return Gaussians

def atomize_gaussian(G, S, i, ta):
    # Designate as Atom Gaussian
    G.is_atom = True
    # Scale is fixed in backprop, but tracked for geometric progression
    # Initial size s = S^(1/3) is implied by the isotropic constraint
    return G

def geometric_progression_update(current_scale, ta):
    # r = p^(1/ta). p is final proportion. 
    # In the paper, Sn = Sn-1 * r^(n-1). 
    # This implies the scale shrinks over iterations.
    # Exact p is not explicitly defined as a constant, but r is derived from ta.
    # We assume r is a constant decay factor per atomization step.
    # Note: The paper states r = t^(1/a) where ta is total iterations. 
    # This likely means r is a fixed base for the geometric series.
    # Implementation detail: r is typically a small constant < 1.
    # Since exact p is "final proportion", we assume r is precomputed.
    return current_scale * r 
```
*[G] The pseudocode assumes `is_too_large`, `split_gaussian`, and `clone_gaussian` follow standard 3DGS implementations. The geometric progression update for Atom scales requires a precomputed decay factor $r$. The paper defines $r = p^{1/t_a}$ where $p$ is the final proportion to initial $S$. In practice, $p$ is often set to a small value (e.g., 0.1 or 0.01) to ensure atoms shrink sufficiently.]*

**Edge Cases and Pitfalls**
*   **DTU Dataset:** For object-centered datasets like DTU, the Prune Threshold $\varepsilon$ should be increased to $0.5$ to avoid over-pruning, and the Atom Scale $S$ should be set to $P_{10}(d)$ (10th percentile) [S2, unofficial].
*   **Scale Learning Rate:** For object-centered datasets, set the scale learning rate $\eta_s = 0$ to maximize geometric accuracy, as scale optimization can introduce noise [S2, unofficial].
*   **Warm-up Phase:** If $t_w$ is too short, the split threshold may not ramp up correctly, leading to insufficient initial densification. If too long, it may delay necessary splitting [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to or faster than standard 3DGS. On Mip-NeRF360, AtomGS averages 0.28 hours vs. 3DGS's 0.40 hours [S2, unofficial].
*   **Memory Complexity:** Model size is similar or slightly smaller. AtomGS averages 749MB vs. 3DGS's 869MB on Mip-NeRF360 [S2, unofficial].
*   **Strengths:** Provides precise geometric guidance, reducing noisy meshes and blurry artifacts. The warm-up strategy stabilizes densification, leading to a declining and stabilizing Gaussian count [S2, unofficial].
*   **Limitations:** Requires pre-optimized normal maps and ground truth edges for the loss function. May struggle with very large, featureless backgrounds if not properly merged [S2, unofficial].
*   **When to Use:** When high-fidelity geometry reconstruction is required alongside rendering quality, particularly for scenes with fine details and smooth surfaces.
*   **When Not to Use:** When training speed is the primary constraint and geometric accuracy is secondary, or when ground truth edges/normals are unavailable.

## Background
Atomized Proliferation was introduced by Liu et al. in the paper "AtomGS: Atomizing Gaussian Splatting for High-Fidelity Radiance Field" [S2, unofficial]. It addresses the issue of standard 3DGS Gaussians drifting and splitting freely, which leads to noisy geometry and slower convergence. The method builds on the standard 3DGS representation but introduces structured densification and geometry-guided optimization [S1][S2, unofficial].
