# Parameter Initialization

Also called: Emission, Roughness, and Specular Initialization, Median Texture Initialization for Diffuse Color

## Overview
Parameter initialization establishes neutral or geometrically consistent starting states for inverse rendering pipelines to prevent optimization from converging to poor local minima or suffering from vanishing/saturated gradients [S1, S2]. It differs from sibling techniques by focusing on specific statistical properties of BRDF lobes and environment map sampling (e.g., spherical Fibonacci lattices) rather than general coordinate or spherical harmonic basis initialization [S1, S2]. Builds on [Parameter and Coordinate Initialization](17024-parameter-and-coordinate-initialization.md).

## How it works
The method initializes parameters for inverse rendering systems that estimate geometry (SDF), material properties (diffuse albedo, specular BRDF), and lighting (environment map) [S1, S2].

### Inputs and Outputs
- **Inputs**: Input reference images (potentially with varying exposure), object bounding box, number of environment map lobes [S1, S2].
- **Outputs**: Initialized SDF weights $\Theta$, diffuse albedo function $a(x; \Phi)$, specular BRDF parameters ($\lambda, \mu$), environment map lobes, and pre-scaled input images [S1, S2].

Not given in the sources.

### Steps
1. **Input Image Scaling** [S1]: Scale all input images by a constant factor such that the median intensity of all scaled images is $0.5$ to handle varying exposure across captures.
2. **SDF Initialization** [S1]: Initialize SDF weights $\Theta$ using the method from [12] to ensure the initial shape is roughly a sphere.
3. **Diffuse Albedo Initialization** [S1, S2]: Initialize the diffuse albedo $a(x; \Phi)$ such that the predicted albedo is $\sim 0.5$ at all locations inside the object bounding box. For spatially-varying color, build a median texture by iterating over all available reference pictures and projecting them into texture space. Use an online median estimator to manage memory for tens of thousands of views. The median is preferred over the mean to suppress view-dependent effects like specular reflections [S2].
4. **Specular BRDF Initialization** [S1]: Initialize lobe sharpness $\lambda$ randomly from the interval $[95, 125]$. Initialize specular albedo $\mu$ randomly from the interval $[0.18, 0.26]$.
5. **Environment Map Initialization** [S1]: Initialize lobes to distribute uniformly on the unit sphere using a spherical Fibonacci lattice [18]. Assign monochrome colors to the lobes. Scale the randomly initialized lobes' amplitudes so that the initial rendered pixel intensity output by the pipeline is $\sim 0.5$.
6. **Neutral Material Parameters** [S2]: Initialize emission to $0$. Initialize roughness to $0.5$. Initialize specular to $0.5$.

### Pseudocode
```python
import math
import random

def initialize_parameters(input_images, bounding_box, num_env_lobe):
    # Step 1: Scale input images
    all_pixels = [pixel for img in input_images for pixel in img.flatten()]
    median_intensity = sorted(all_pixels)[len(all_pixels) // 2]
    scale_factor = 0.5 / median_intensity
    scaled_images = [[pixel * scale_factor for pixel in img_row] for img_row in input_images]

    # Step 2: SDF Initialization
    # [G] Specific SDF initialization method from [12] is not detailed in the sources.
    sdf_weights = None

    # Step 3: Diffuse Albedo Initialization
    # Option A: Constant ~0.5 (S1)
    diffuse_albedo_init = 0.5

    # Option B: Median Texture (S2)
    # [G] Online median estimator implementation details are not provided in the sources.
    diffuse_texture = None

    # Step 4: Specular BRDF Initialization
    lambda_sharpness = random.uniform(95, 125)
    mu_albedo = random.uniform(0.18, 0.26)

    # Step 5: Environment Map Initialization
    # Generate positions using spherical Fibonacci lattice [G]
    env_positions = []
    for i in range(num_env_lobe):
        y = 1 - (i / (num_env_lobe - 1)) * 2
        radius = (y * y * 0.5 + 0.5) ** 0.5
        theta = 6.2831853 * i * 2.3999632
        x = math.cos(theta) * radius
        z = math.sin(theta) * radius
        env_positions.append((x, y, z))

    # Initialize monochrome colors (e.g., gray)
    env_colors = [(1.0, 1.0, 1.0) for _ in range(num_env_lobe)]

    # Randomly initialize amplitudes
    env_amplitudes = [random.uniform(0, 1) for _ in range(num_env_lobe)]

    # Scale amplitudes so initial render intensity is ~0.5
    # [G] Exact scaling procedure requires a forward pass or gain estimation of the specific pipeline.
    max_amp = max(env_amplitudes) if env_amplitudes else 1.0
    env_amplitudes = [amp * (0.5 / max_amp) for amp in env_amplitudes]

    # Step 6: Neutral Material Parameters
    emission = 0.0
    roughness = 0.5
    specular = 0.5

    return {
        'sdf_weights': sdf_weights,
        'diffuse_albedo': diffuse_albedo_init,
        'lambda': lambda_sharpness,
        'mu': mu_albedo,
        'env_map': {'positions': env_positions, 'colors': env_colors, 'amplitudes': env_amplitudes},
        'emission': emission,
        'roughness': roughness,
        'specular': specular,
        'scaled_images': scaled_images
    }
```

### Edge Cases and Pitfalls
- **Environment Map Intensity** [S1]: If the initial environment map is too bright or too dark, the diffuse albedo MLP may get stuck, predicting all zeros or ones during training. The scaling step (Step 5) is critical to avoid this.
- **Memory Constraints** [S2]: When dealing with tens of thousands of views, storing all projected textures in memory is infeasible. An online median estimator must be used instead of batch processing.

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Not given in the sources.
- **Strengths**: Prevents gradient saturation in MLPs; handles varying exposure in input data; suppresses specular artifacts in diffuse color initialization [S1, S2].
- **Limitations**: Requires a forward pass or gain estimation to scale environment map amplitudes correctly [S1].

## Background
This initialization strategy originates from inverse rendering pipelines that use neural representations for geometry and materials. PhySG [S1] introduced the specific initialization for SDFs, specular BRDF lobes, and environment maps using spherical Fibonacci lattices to ensure stable training. Material and Lighting Reconstruction [S2] contributed the median texture initialization for spatially-varying diffuse color and the neutral parameter settings for emission, roughness, and specular.
