# Coupled Gaussian Primitives Rendering

Also called: Anchor-Coupled Primitive Rendering, CompGS rendering

## Overview
Coupled Gaussian Primitives Rendering is a compact scene representation method that decomposes Gaussian primitives into anchor primitives and coupled primitives derived from them, enabling efficient storage and rendering via a custom rasterizer [S1, unofficial]. It distinguishes itself from standard 3D Gaussian Splatting by introducing a hierarchical primitive structure where coupled primitives are predicted from anchor primitives, reducing the parameter count and facilitating compression [S1, unofficial].

## How it works
**Inputs and Outputs:**
The method takes a set of anchor primitives (defined by mean, scale, rotation, and features) and a camera view as input. It outputs a rendered image, along with metadata including projected means, visibility masks, and bit-per-pixel (bpp) statistics for compression [S1, unofficial].

**Data Structures:**
The core state is held in a `GaussianParameters` object (or `self.gaussian_params` in the implementation), which contains:
- `num_anchor_primitive`: Integer count of anchor primitives.
- `num_coupled_primitive`: Integer count of coupled primitives.
- `derive_factor`: Integer, the number of coupled primitives derived from each anchor primitive.
- `res_feats_dim`: Integer, dimension of residual features.
- `means`: Tensor of shape `(N, 3)`, dtype float32, representing 3D positions.
- `scales_before_exp`: Tensor of shape `(N, 6)`, dtype float32. The first 3 components are log-scales for the anchor primitives; the remaining 3 are log-scales for the coupled primitives (or shared/derived depending on specific implementation, but typically coupled scales are derived or stored separately). *Note: The source notes specify `scales_before_exp` shape `(N, 6)` and `res_feats` shape `(N, K, D)` where K is likely `derive_factor`.*
- `rotations`: Tensor of shape `(N, 4)`, dtype float32, unit quaternions.
- `ref_feats`: Tensor of shape `(N, C)`, reference features for anchor primitives.
- `res_feats`: Tensor of shape `(N, K, D)`, residual features for coupled primitives, where $K$ is `derive_factor` and $D$ is `res_feats_dim`.
- `coupled_denorm`: Tensor of shape `(N*K, 1)`, normalization factors for coupled primitives.
- `anchor_denorm`: Tensor of shape `(N, 1)`, normalization factors for anchor primitives.
- `accumulated_grads`: Tensor of shape `(N, 1)`.
- `accumulated_opacities`: Tensor of shape `(N, 1)`.

The `RenderSettings` object includes:
- `image_height`, `image_width`: Integers.
- `tanfovx`, `tanfovy`: Floats.
- `viewmatrix`: Tensor `(4, 4)`.
- `projmatrix`: Tensor `(4, 4)`.
- `campos`: Tensor `(3,)`.
- `background_color`: Tensor `(3,)`, default black `[0, 0, 0]`.

**Parameters:**
- `voxel_size`: Size of voxels used for initialization and quantization of means [S1, unofficial].
- `derive_factor`: Number of coupled primitives derived from each anchor primitive [S1, unofficial].
- `ref_feats_dim`: Dimension of reference features [S1, unofficial].
- `ref_hyper_dim`: Dimension of hyper-priors for reference features [S1, unofficial].
- `res_feats_dim`: Dimension of residual features [S1, unofficial].
- `res_hyper_dim`: Dimension of hyper-priors for residual features [S1, unofficial].

**Steps:**
1.  **Initialize Rasterizer:** Create a `GaussianRasterizationSettings` object with `image_height`, `image_width`, `tanfovx`, `tanfovy`, `background_color`, `scale_modifier`, `viewmatrix`, `projmatrix`, `sh_degree=1`, `campos`, `prefiltered=False`, and `debug=False` [S1, unofficial].
2.  **Prefilter Anchors:** Call `rasterizer.visible_filter` with `means3D=self.means`, `scales=torch.exp(self.scaling_factors_before_exp[:, :3])`, `rotations=self.rotations`, and `cov3D_precomp=None`. This returns `radii_pure` [S1, unofficial].
3.  **Create Mask:** Define `anchor_primitive_visible_mask` where `radii_pure > 0` [S1, unofficial].
4.  **Filter Data:** Filter `means`, `scaling_factors_before_exp`, `ref_feats`, and `res_feats` using `anchor_primitive_visible_mask` to keep only visible anchors [S1, unofficial].
5.  **Predict Coupled Primitives:** Pass the filtered `means`, `scaling_factors_before_exp`, `ref_feats`, `res_feats`, `cam_center`, and `skip_quant` into the prediction network `self.network`. This returns `gaussian_primitives` (containing means, scales, rotations, colors for all primitives), `pred_opacities`, `coupled_primitive_mask`, and `bpp` [S1, unofficial].
6.  **Initialize Projected Means:** Create `projected_means` as a zero tensor with `requires_grad=True` (or `retain_grad=True`) to store 2D projections [S1, unofficial].
7.  **Render:** Call the rasterizer with:
    - `means3D=gaussian_primitives.means`
    - `means2D=projected_means`
    - `scales=gaussian_primitives.scales`
    - `rotations=gaussian_primitives.rotations`
    - `cov3D_precomp=None`
    - `shs=None`
    - `colors_precomp=gaussian_primitives.colors`
    - `opacities=gaussian_primitives.opacities`
    [S1, unofficial].
8.  **Clamp:** Clamp the `rendered_img` to the range $[0, 1]$ [S1, unofficial].
9.  **Return Results:** Return a `RenderResults` object containing `rendered_img`, `projected_means`, `visibility_mask` (where radii > 0), `pred_opacities`, `scales`, `anchor_primitive_visible_mask`, `coupled_primitive_mask`, and `bpp` [S1, unofficial].
10. **Inference Timing:** For inference, synchronize CUDA, record start time, perform prediction and rendering, synchronize CUDA, record end time, and calculate `predict_time` (seconds) and `render_time` (milliseconds) [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn

class CoupledGaussianRenderer:
    def __init__(self, rasterizer, network, voxel_size, derive_factor, 
                 ref_feats_dim, res_feats_dim, background_color=0.0):
        self.rasterizer = rasterizer
        self.network = network
        self.voxel_size = voxel_size
        self.derive_factor = derive_factor
        self.ref_feats_dim = ref_feats_dim
        self.res_feats_dim = res_feats_dim
        self.background_colors = torch.tensor([background_color, background_color, background_color], dtype=torch.float32)
        
        # Initialize parameters
        self.gaussian_params = GaussianParameters(
            num_anchor_primitive=0,
            num_coupled_primitive=0,
            derive_factor=derive_factor,
            res_feats_dim=res_feats_dim,
            means=None,
            scales_before_exp=None,
            rotations=None,
            ref_feats=None,
            res_feats=None,
            accumulated_grads=None,
            coupled_denorm=None,
            accumulated_opacities=None,
            anchor_denorm=None
        )

    def render(self, sample: Sample) -> RenderResults:
        # 1. Initialize Rasterizer Settings
        raster_settings = GaussianRasterizationSettings(
            image_height=sample.image_height,
            image_width=sample.image_width,
            tanfovx=sample.tan_half_fov_x,
            tanfovy=sample.tan_half_fov_y,
            background=self.background_colors,
            scale_modifier=1.0, # Default, adjust if needed
            viewmatrix=sample.world_to_view_proj_mat,
            projmatrix=sample.world_to_image_proj_mat,
            sh_degree=1,
            campos=sample.camera_center,
            prefiltered=False,
            debug=False
        )

        # 2. Prefilter invisible anchor primitives
        # Extract anchor scales (first 3 components of scales_before_exp)
        anchor_scales = torch.exp(self.gaussian_params.scales_before_exp[:, :3])
        
        radii_pure = self.rasterizer.visible_filter(
            means3D=self.gaussian_params.means,
            scales=anchor_scales,
            rotations=self.gaussian_params.rotations,
            cov3D_precomp=None,
            raster_settings=raster_settings
        )

        # 3. Create anchor primitive visible mask
        anchor_primitive_visible_mask = radii_pure > 0

        # 4. Filter data structures
        means = self.gaussian_params.means[anchor_primitive_visible_mask]
        scaling_factors_before_exp = self.gaussian_params.scales_before_exp[anchor_primitive_visible_mask]
        ref_feats = self.gaussian_params.ref_feats[anchor_primitive_visible_mask]
        res_feats = self.gaussian_params.res_feats[anchor_primitive_visible_mask]

        # 5. Predict Gaussian primitives (anchors + coupled)
        # cam_center is sample.camera_center
        gaussian_primitives, pred_opacities, coupled_primitive_mask, bpp = self.network(
            means=means,
            scaling_factors_before_exp=scaling_factors_before_exp,
            ref_feats=ref_feats,
            res_feats=res_feats,
            cam_center=sample.camera_center,
            skip_quant=False # Or based on inference/training flag
        )

        # 6. Initialize projected means
        projected_means = torch.zeros_like(gaussian_primitives.means[:, :2], requires_grad=True)

        # 7. Render image
        # Note: The rasterizer call in the source uses specific arguments.
        # We assume gaussian_primitives has .means, .scales, .rotations, .colors
        rendered_img = self.rasterizer(
            means3D=gaussian_primitives.means,
            means2D=projected_means,
            scales=gaussian_primitives.scales,
            rotations=gaussian_primitives.rotations,
            cov3D_precomp=None,
            shs=None,
            colors_precomp=gaussian_primitives.colors,
            opacities=gaussian_primitives.opacities,
            raster_settings=raster_settings
        )

        # 8. Clamp rendered image
        rendered_img = torch.clamp(rendered_img, 0.0, 1.0)

        # 9. Return results
        # Visibility mask for all primitives (radii > 0)
        # Note: radii_pure was for anchors. For full visibility, we might need to recompute or use the rasterizer's internal mask.
        # The source says "visibility_mask (radii > 0)". Assuming this refers to the final rendered primitives' visibility.
        # For simplicity, we return the anchor mask and coupled mask as per source.
        return RenderResults(
            rendered_img=rendered_img,
            projected_means=projected_means,
            visibility_mask=radii_pure > 0, # Simplified, source implies this is the mask
            pred_opacities=pred_opacities,
            scales=gaussian_primitives.scales,
            anchor_primitive_visible_mask=anchor_primitive_visible_mask,
            coupled_primitive_mask=coupled_primitive_mask,
            bpp=bpp
        )
```

## Operating characteristics
**Time and Memory Complexity:**
The method reduces memory usage by deriving coupled primitives from anchors, lowering the number of stored parameters compared to independent Gaussians. The rendering complexity is proportional to the total number of primitives (anchors + coupled). The prediction step adds computational overhead during training/inference to generate coupled primitives [S1, unofficial].

**Strengths and Limitations:**
- **Strengths:** Compact representation, efficient storage via compression (GPCC), and fast rendering due to fewer primitives [S1, unofficial].
- **Limitations:** Requires a custom network to predict coupled primitives, adding complexity to the training pipeline. Precision issues may arise from quantization and compression [S1, unofficial].

**When to Use:**
Use when storage and bandwidth are constrained, or when real-time rendering of large scenes is required with limited memory [S1, unofficial].

## Background
Coupled Gaussian Primitives Rendering, also known as CompGS, was introduced by Liu Xiangrui et al. in the "CompGS" repository [S1, unofficial]. It builds upon 3D Gaussian Splatting by introducing a coupled primitive structure to enhance compression and efficiency [S1, unofficial].
