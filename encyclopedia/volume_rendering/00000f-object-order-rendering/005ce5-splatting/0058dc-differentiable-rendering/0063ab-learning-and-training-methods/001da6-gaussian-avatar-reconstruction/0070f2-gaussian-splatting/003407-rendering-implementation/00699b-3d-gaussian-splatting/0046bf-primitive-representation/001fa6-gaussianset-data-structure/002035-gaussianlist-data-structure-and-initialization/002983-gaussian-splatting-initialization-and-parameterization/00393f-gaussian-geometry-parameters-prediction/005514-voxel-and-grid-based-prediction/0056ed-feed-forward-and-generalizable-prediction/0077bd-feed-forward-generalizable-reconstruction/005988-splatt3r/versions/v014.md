# Splatt3R

Also called: Splatt3R: Zero-Shot Gaussian Splatting from Uncalibrated Image Pairs

## Overview
Splatt3R is a feed-forward method that predicts 3D Gaussian Splat primitives directly from a pair of uncalibrated natural images, without requiring camera intrinsics, extrinsics, or depth information [S1, unofficial]. It extends the MASt3R foundation model by adding a parallel "Gaussian head" to predict per-pixel Gaussian attributes, enabling novel view synthesis for both interpolated and extrapolated viewpoints [S1, unofficial]. Unlike existing generalizable methods that are limited to interpolating between input views, Splatt3R uses a loss masking strategy to supervise reconstruction on extrapolated views where parts of the scene may be obscured or outside the input frustums [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Two uncalibrated RGB images $I_1, I_2 \in \mathbb{R}^{H \times W \times 3}$ with resolution $512 \times 512$ [S1, unofficial].
*   **Output:** A set of 3D Gaussian primitives $\mathcal{G}$, defined by mean $\mu$, covariance $\Sigma$, opacity $\alpha$, and color $c$ [S1, unofficial].

**Data Structures:**
The method predicts parameters per pixel for each input image. For each pixel $j$ in image $i$ ($i \in \{1, 2\}$), the network outputs:
*   Base 3D position $x_j \in \mathbb{R}^3$ (in the coordinate frame of the first image) [S1, unofficial].
*   Position offset $\Delta x_j \in \mathbb{R}^3$ [S1, unofficial].
*   Rotation quaternion $q_j \in \mathbb{R}^4$ [S1, unofficial].
*   Scale vector $s_j \in \mathbb{R}^3$ [S1, unofficial].
*   Opacity $\alpha_j \in \mathbb{R}$ [S1, unofficial].
*   Color $c_j \in \mathbb{R}^3$ (constant view-independent color) [S1, unofficial].

**Algorithm:**
1.  **Feature Encoding:** Encode $I_1$ and $I_2$ using a shared Vision Transformer (ViT) encoder and cross-attention transformers. These components are frozen during training, inheriting weights from the pre-trained MASt3R model [S1, unofficial].
2.  **Point Cloud Prediction:** Use the frozen MASt3R backbone to predict base 3D point locations $\hat{X}_1, \hat{X}_2$ and confidence maps $C_1, C_2$ in the coordinate frame of the first image [S1, unofficial].
3.  **Gaussian Parameter Prediction:** Pass the encoded features through a parallel "Gaussian head" (using DPT architecture) to predict offsets $\Delta$, rotations $q$, scales $s$, opacities $\alpha$, and colors $c$ for each pixel [S1, unofficial].
4.  **Primitive Construction:** Construct the final set of Gaussian primitives as the union of primitives predicted from both input images [S1, unofficial]. The mean position $\mu_j$ for each Gaussian is calculated as:
    $$ \mu_j = x_j + \Delta x_j $$
    where $x_j$ is the base position from MASt3R and $\Delta x_j$ is the predicted offset [S1, unofficial].
5.  **Covariance Reparameterization:** The covariance matrix $\Sigma_j$ is constructed from the predicted rotation $q_j$ and scale $s_j$ to ensure positive semi-definiteness:
    $$ \Sigma_j = R(q_j) S(s_j) S(s_j)^T R(q_j)^T $$
    where $R(q_j)$ is the rotation matrix derived from quaternion $q_j$, and $S(s_j)$ is a diagonal matrix with scale components [S1, unofficial].
6.  **Activation Functions:** Apply specific activations to ensure valid parameter ranges:
    *   Normalization for quaternions $q_j$ [S1, unofficial].
    *   Exponential activation for scales $s_j$ and offsets $\Delta x_j$ [S1, unofficial].
    *   Sigmoid activation for opacities $\alpha_j$ [S1, unofficial].
    *   No activation (or residual prediction) for color $c_j$ [S1, unofficial].

**Training Procedure:**
1.  **Dataset Selection:** Select context images (input pair) such that at least $\phi\%$ of pixels in the second image have correspondences in the first. Select target images (novel views) such that at least $\psi\%$ of pixels are present in at least one context image [S1, unofficial]. Typical thresholds: Close $(\phi=0.9, \psi=0.9)$, Medium $(0.7, 0.7)$, Wide $(0.5, 0.5)$, Very Wide $(0.3, 0.3)$ [S1, unofficial].
2.  **Loss Masking:** Calculate a binary loss mask $M$ for each target image. A pixel is included in the mask if:
    *   It is inside the frustum of at least one context view.
    *   Its unprojected 3D point reprojects onto a context image with a depth that matches the ground truth depth within a tolerance.
    *   The pixel has valid depth in the dataset [S1, unofficial].
3.  **Loss Calculation:** Compute the total loss $L$ using only masked pixels:
    $$ L = \lambda_{MSE} L_{MSE}(M \odot \hat{I}, M \odot I) + \lambda_{LPIPS} L_{LPIPS}(M \odot \hat{I}, M \odot I) $$
    where $\hat{I}$ is the rendered image, $I$ is the ground truth target image, and $\odot$ denotes element-wise multiplication [S1, unofficial].
4.  **Optimization:** Train only the Gaussian head. The MASt3R backbone (ViT, cross-attention, point cloud head) remains frozen [S1, unofficial].

**Pseudocode:**
```python
def splatt3r_forward(I1, I2, frozen_mast3r, gaussian_head):
    """
    Forward pass of Splatt3R.
    I1, I2: Input images [H, W, 3]
    Returns: List of Gaussian primitives (mu, sigma, alpha, color)
    """
    # 1. Encode images using frozen MASt3R backbone
    features = frozen_mast3r.encode(I1, I2)
    
    # 2. Predict base point cloud and confidence (frozen)
    x1, c1 = frozen_mast3r.point_head(features) # x1 in frame of I1
    # x2 is also predicted but typically transformed or handled via union
    
    # 3. Predict Gaussian attributes using parallel head
    # Outputs: offsets, quaternions, scales, opacities, colors
    delta, q, s, alpha, color = gaussian_head(features)
    
    # 4. Construct Gaussians for Image 1
    gaussians_i1 = []
    for j in range(H * W):
        # Mean: base position + offset
        mu = x1[j] + delta[j]
        
        # Covariance: from quaternion and scale
        R_q = quaternion_to_rotation_matrix(q[j])
        S_s = diag(s[j])
        sigma = R_q @ S_s @ S_s.T @ R_q.T
        
        # Opacity: sigmoid activation applied during head output
        alpha_val = alpha[j]
        
        # Color: constant view-independent
        color_val = color[j]
        
        gaussians_i1.append((mu, sigma, alpha_val, color_val))
        
    # 5. Construct Gaussians for Image 2
    # Note: MASt3R predicts points in I1's frame. 
    # The paper states covariances and SH are in I1's frame.
    # The final set is the union of primitives from both images.
    # Implementation detail: x2 must be transformed to I1's frame 
    # or the head outputs parameters relative to I1's frame for both.
    # Based on S1: "predicted covariances and spherical harmonics are 
    # considered as being in the first image’s camera frame."
    # And "final set ... is the union of the Gaussian primitives predicted from both images."
    
    x2, c2 = frozen_mast3r.point_head(features) # x2 in frame of I1
    
    gaussians_i2 = []
    for j in range(H * W):
        mu = x2[j] + delta[j] # Assuming delta is also predicted for I2's pixels
        R_q = quaternion_to_rotation_matrix(q[j])
        S_s = diag(s[j])
        sigma = R_q @ S_s @ S_s.T @ R_q.T
        alpha_val = alpha[j]
        color_val = color[j]
        gaussians_i2.append((mu, sigma, alpha_val, color_val))
        
    # 6. Union
    all_gaussians = gaussians_i1 + gaussians_i2
    return all_gaussians

def compute_loss_mask(target_depth, target_pose, context_depths, context_poses, H, W):
    """
    Compute loss mask M based on frustum culling and covisibility.
    """
    M = zeros(H, W)
    for u, v in pixels(H, W):
        # Unproject target pixel to 3D
        pt_3d = unproject(target_depth[u,v], target_pose, u, v)
        
        visible = False
        for k in range(len(context_depths)):
            # Reproject to context k
            u_k, v_k, d_k = project(pt_3d, context_poses[k])
            
            if is_inside_frustum(u_k, v_k, context_poses[k], H, W):
                # Check depth consistency
                if abs(d_k - context_depths[k][u_k, v_k]) < tolerance:
                    visible = True
                    break
        
        if visible:
            M[u, v] = 1
    return M
```

## Operating characteristics
*   **Time Complexity:** Single forward pass of the network. Construction/export runtime is approximately 1.10 seconds on ScanNet++ with 2 views [S2].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** On ScanNet++ test scenes with 2 views:
    *   Close overlap ($\phi=0.9, \psi=0.9$): PSNR 19.66, SSIM 0.757, LPIPS 0.234 [S1, unofficial].
    *   General 2-view result: PSNR 23.30, SSIM 0.823, LPIPS 0.125 [S2].
*   **Strengths:**
    *   Pose-free: Does not require camera intrinsics or extrinsics [S1, unofficial].
    *   Generalizable: Trained on ScanNet++, generalizes to uncalibrated in-the-wild images [S1, unofficial].
    *   Extrapolation: Can synthesize views beyond the stereo baseline, unlike many siblings that only interpolate [S1, unofficial].
*   **Limitations:**
    *   Requires a pair of images; not designed for single-image reconstruction [S1, unofficial].
    *   Performance degrades with very wide baselines (lower overlap) [S1, unofficial].
    *   Uses constant view-independent color in main experiments, limiting view-dependent appearance fidelity compared to spherical harmonics (though ablated) [S1, unofficial].

## Background
Splatt3R was introduced in 2024 by Brandon, Zheng, Iro, and Victor from the University of Oxford [S1, unofficial]. It builds upon the MASt3R foundation model for 3D geometry reconstruction [S1, unofficial]. The method addresses the limitation of existing generalizable 3D-GS methods that rely on calibrated camera poses or are restricted to interpolating between input views [S1, unofficial]. It is trained on the ScanNet++ dataset [S1, unofficial].
