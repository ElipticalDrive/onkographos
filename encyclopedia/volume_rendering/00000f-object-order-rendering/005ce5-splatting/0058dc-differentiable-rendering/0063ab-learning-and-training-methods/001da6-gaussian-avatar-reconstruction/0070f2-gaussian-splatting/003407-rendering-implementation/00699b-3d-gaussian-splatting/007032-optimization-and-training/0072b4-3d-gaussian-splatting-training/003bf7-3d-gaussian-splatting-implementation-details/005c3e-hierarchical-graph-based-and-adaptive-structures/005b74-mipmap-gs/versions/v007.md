# Mipmap-GS

Also called: Mipmap-Gaussian Splatting

## Overview
Mipmap-GS is a test-time adaptation method that deforms pre-trained 3D Gaussian primitives to resolve aliasing artifacts (spikes during zoom-in and excessive thickness during zoom-out) caused by the mismatch between fixed Gaussian distributions and varying pixel sampling rates [S1]. Unlike methods that apply post-processing filters or hierarchical level-of-detail selection, Mipmap-GS self-adjusts primitive properties (color, shape, size) and distribution (position) by optimizing against scale-specific mipmap-like pseudo ground-truth, ensuring visual consistency across arbitrary zoom factors without retraining from scratch [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of base 3D Gaussians $\{G_k\}_{k=1}^K$ trained at a basic scale ($\times 1$), a target zoom factor $N$, and a set of viewpoints $\{V_j\}$.
*   **Output:** Optimized Gaussians $\{G^{opt}_k\}_{k=1}^K$ adapted to the target scale.

**Data Structures:**
The method operates on the standard 3D Gaussian representation. Each Gaussian $G_k$ is defined by:
*   Position $\mu_k \in \mathbb{R}^3$
*   Covariance $\Sigma_k \in \mathbb{R}^{3 \times 3}$ (parameterized by rotation $R_k \in SO(3)$ and scale $s_k \in \mathbb{R}^3$)
*   Opacity $\alpha_k \in [0, 1]$
*   Spherical Harmonics coefficients for color $c_k$

**Algorithm Steps:**
The optimization is performed iteratively for $S$ iterations (typically 1,000). In each iteration, the following steps are executed:

1.  **Base Rendering:** Select a viewpoint $v_j$ randomly from $\{V_j\}$. Render the current base Gaussians $\{G_k\}$ (or current optimized Gaussians in subsequent iterations) to obtain a basic-scale image $\hat{x}_j$ at resolution $\times 1$.
2.  **Pseudo-GT Construction:** Apply a mipmap resizing function $r(\cdot)$ to $\hat{x}_j$ to generate the scale-specific pseudo ground-truth $r(\hat{x}_j)$.
    *   For **zoom-in** (target resolution $N > 1$): Upsample $\hat{x}_j$ by a factor of $N$ using a super-resolution method (e.g., SwinIR) [S1].
    *   For **zoom-out** (target resolution $N < 1$): Downsample $\hat{x}_j$ by a factor of $1/N$ using bilinear interpolation [S1].
3.  **Adaptive Rendering:** Render the current set of Gaussians $\{G^{(i)}_k\}$ to the *new* target scale image $x_j$. This involves projecting the Gaussians and accumulating colors based on the new pixel coverage defined by the zoom factor [S1].
4.  **Loss Calculation:** Compute the scale-aware guidance loss $L$ between the rendered image $x_j$ and the pseudo-GT $r(\hat{x}_j)$:
    $$ L(x_j, r(\hat{x}_j)) = \| x_j - r(\hat{x}_j) \|_2^2 $$
    where $\| \cdot \|_2^2$ denotes the squared L2 norm [S1].
5.  **Optimization Step:** Update the Gaussian parameters $\{G^{(i)}_k\}$ using gradient descent:
    $$ G^{(i+1)}_k = G^{(i)}_k - \beta \nabla_{G^{(i)}_k} L(x_j, r(\hat{x}_j)) $$
    where $\beta$ is the learning rate [S1].
6.  **Active Pruning:** If the iteration count $i$ is a multiple of 100, perform densification or pruning operations to maintain a compact representation [S1].

**Pseudocode:**

```python
def mipmap_gs_optimize(base_gaussians, viewpoints, zoom_factor, iterations):
    """
    Deforms base 3D Gaussians to adapt to a specific zoom scale.
    
    Args:
        base_gaussians: List of Gaussian primitives {G_k} with position, covariance, opacity, color.
        viewpoints: List of camera viewpoints {V_j}.
        zoom_factor: Float N. N > 1 for zoom-in (upsampling), N < 1 for zoom-out (downsampling).
        iterations: Integer S, total number of optimization steps (default 1000).
        
    Returns:
        optimized_gaussians: List of deformed Gaussian primitives {G_opt_k}.
    """
    current_gaussians = copy.deepcopy(base_gaussians)
    learning_rate = 0.01  # [G] Typical learning rate for 3DGS optimization; not explicitly specified in [S1] but implied by gradient descent context.
    
    for i in range(iterations):
        # 1. Select viewpoint
        v_j = random.choice(viewpoints)
        
        # 2. Render base image at basic scale (x1)
        # Render function projects current_gaussians and accumulates splats at standard resolution.
        image_basic = render(current_gaussians, v_j, scale=1.0)
        
        # 3. Construct mipmap-like pseudo-GT
        if zoom_factor > 1.0:
            # Zoom-in: Upsample using super-resolution (e.g., SwinIR)
            # [S1] specifies SwinIR for zoom-in.
            pseudo_gt = super_resolution_upsample(image_basic, factor=zoom_factor)
        else:
            # Zoom-out: Downsample using bilinear interpolation
            # [S1] specifies bilinear interpolation for zoom-out.
            pseudo_gt = bilinear_downsample(image_basic, factor=1.0/zoom_factor)
            
        # 4. Render optimized Gaussians at the new target scale
        # The rendering must account for the new pixel coverage/sampling rate.
        image_new_scale = render(current_gaussians, v_j, scale=zoom_factor)
        
        # 5. Compute Loss
        # L(x, r(x_hat)) = ||x - r(x_hat)||_2^2
        loss = mean_squared_error(image_new_scale, pseudo_gt)
        
        # 6. Optimize Gaussians
        # G_opt = G - beta * grad(L)
        gradients = compute_gradients(loss, current_gaussians)
        current_gaussians = apply_gradient(current_gaussians, gradients, learning_rate)
        
        # 7. Active Pruning every 100 iterations
        if i % 100 == 0:
            current_gaussians = densify_or_prune(current_gaussians)
            
    return current_gaussians
```

**Parameters:**
*   **Zoom Factor ($N$):** Determines the target scale. $N > 1$ for zoom-in, $N < 1$ for zoom-out [S1].
*   **Iterations ($S$):** The number of adaptation steps. The deformation converges within 1,000 iterations [S1].
*   **Learning Rate ($\beta$):** Step size for gradient descent. Not explicitly given in sources [G].
*   **Mipmap Function ($r(x)$):**
    *   Zoom-in: Super-resolution (e.g., SwinIR) [S1].
    *   Zoom-out: Bilinear interpolation [S1].

**Edge Cases and Pitfalls:**
*   **Zoom-in Spikes:** Caused by varying shrinkage bias during accumulation when sampling rates change. The fixed Gaussian field may sample signals incorrectly, leading to confusion during accumulation [S1].
*   **Zoom-out Thickness:** Caused by constant dilation. The 2D dilation operation in standard 3DGS amplifies tiny Gaussians to cover pixels. At zoom-out, this leads to excessively wide coverage and thick structures, including Gaussians that should not contribute to specific pixels [S1].
*   **Computational Cost:** While faster than training from scratch, the method requires rendering at two scales (basic and target) and applying super-resolution/downsampling per iteration [S1].

## Operating characteristics
*   **Time Complexity:** The method adds an optimization loop of $S$ iterations (typically 1,000) to the rendering pipeline. Each iteration requires two render passes (basic scale and target scale) and a resizing operation. It converges within 1K iterations, using only 3% of the iterations required for training from scratch [S1].
*   **Memory Complexity:** The method does not increase the storage size of the Gaussian representation itself. However, active pruning during optimization reduces the number of Gaussians, particularly in zoom-out scenarios where decreased spatial resolution requires fewer primitives [S1].
*   **Performance:**
    *   On the NeRF Synthetic dataset, Mipmap-GS outperforms standard 3DGS by an average of 9.25 dB PSNR for zoom-in and 10.40 dB PSNR for zoom-out [S1].
    *   At $\times 1/2$ zoom-out on NeRF Synthetic: SSIM 0.971, PSNR 32.71, LPIPS 0.026 (vs. 3DGS: 0.951, 27.14, 0.031) [S1].
    *   At $\times 1/2$ zoom-out on Mip-NeRF 360: SSIM 0.854, PSNR 28.57 (vs. 3DGS: 0.774, 26.66) [S1].
*   **Strengths:** Plug-in module applicable to any 3DGS model; solves aliasing essentially by informing the new sampling rate rather than filtering; preserves finer details compared to heuristic filters; compact representation via active pruning [S1].
*   **Limitations:** Requires test-time adaptation (optimization) for each new zoom factor; relies on external super-resolution models for zoom-in [S1].

## Background
Mipmap-GS was proposed to address the severe aliasing or blurriness suffered by 3D Gaussian Splatting (3DGS) when zooming in or out [S1]. Standard 3DGS uses fixed Gaussian distributions and constant dilation, which mismatch with varying pixel coverage at different zoom levels. Previous methods like Mip-Splatting used heuristic 2D/3D smoothing filters that suppress high-frequency components, while Octree-GS used hierarchical Level-of-Detail (LoD) selection which is sensitive to hyper-parameters [S1]. Mipmap-GS introduces a unified optimization method that makes Gaussians adaptive for arbitrary scales by self-adjusting primitive properties and distribution using scale-specific mipmap-like pseudo ground-truth [S1]. It is described as a plug-in module that can be applied to any 3DGS model, including variants like Scaffold-GS [S1].
