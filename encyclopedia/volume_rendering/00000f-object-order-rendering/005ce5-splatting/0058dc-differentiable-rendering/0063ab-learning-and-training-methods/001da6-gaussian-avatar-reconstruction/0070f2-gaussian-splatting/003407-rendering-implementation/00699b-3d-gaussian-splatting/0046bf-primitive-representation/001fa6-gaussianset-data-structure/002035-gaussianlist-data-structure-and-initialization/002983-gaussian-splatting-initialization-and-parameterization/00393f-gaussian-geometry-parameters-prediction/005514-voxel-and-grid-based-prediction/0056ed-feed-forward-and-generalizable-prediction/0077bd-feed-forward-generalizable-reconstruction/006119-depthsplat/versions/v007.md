# DepthSplat


## Overview
DepthSplat is a feed-forward method for 3D Gaussian splatting reconstruction that connects Gaussian splatting with depth estimation by leveraging pre-trained monocular depth features to augment multi-view feature matching [S1]. It solves the problem of artifacts and scale ambiguities in multi-view reconstruction by using monocular features only as an augmentation to multi-view matching, ensuring multi-view consistency while improving robustness in low-textured or reflective areas [S1]. Unlike TranSplat, which uses monocular features to refine coarse depth (vulnerable to error propagation), DepthSplat combines cost volumes and monocular features early in the pipeline [S1]. Unlike GS-LRM, which relies heavily on training data and compute, DepthSplat uses explicit feature matching and is cheaper to train [S1].

## How it works
**Inputs:** $N$ input images $\{I_i\}_{i=1}^N$, where $I_i \in \mathbb{R}^{H \times W \times 3}$, and their corresponding projection matrices $\{P_i\}_{i=1}^N$, where $P_i \in \mathbb{R}^{3 \times 4}$ (computed from intrinsic and extrinsic matrices) [S1].

**Outputs:** A set of 3D Gaussians $\{(\mu_j, \alpha_j, \Sigma_j, c_j)\}_{j=1}^{H \times W}$ for each image, where $\mu_j$ is the position, $\alpha_j$ is the opacity, $\Sigma_j$ is the covariance, and $c_j$ is the color [S1]. These Gaussians are used to render novel views.

**Data Structures:**
1.  **Monocular Features:** Extracted per-view using a Vision Transformer (ViT).
2.  **Cost Volumes:** For each view $i$, a cost volume $C_i \in \mathbb{R}^{\frac{H}{s} \times \frac{W}{s} \times D}$, where $s$ is the downsampling factor and $D$ is the number of depth candidates [S1].
3.  **Depth Maps:** Dense per-pixel depth $D_i \in \mathbb{R}^{H \times W}$ predicted by a 2D U-Net [S1].

**Parameters:**
*   **Downsampling factor $s$:** Controlled by the number of stride-2 $3 \times 3$ convolutions in feature extraction. $s=4$ if two convolutions are used; $s=8$ if three are used [S1].
*   **Depth candidates $D$:** Uniformly sampled from near/far depth ranges [S1].
*   **Multi-view Transformer:** Contains six stacked self- and cross-attention layers [S1].
*   **Neighbor views:** For $N > 2$, the top-2 nearest neighboring views are selected based on camera distance to the reference view [S1].

**Steps:**
1.  **Monocular Feature Extraction:** For each view $i$, extract features $F_i$ using a pre-trained monocular depth model (ViT) [S1].
2.  **Depth Candidate Sampling:** For each view $i$, uniformly sample $D$ depth candidates $\{d_m\}_{m=1}^D$ from the near and far depth ranges [S1].
3.  **Feature Warping:** For each view $i$ and each neighboring view $j$, warp the feature $F_j$ to view $i$ using the projection matrix $P_i$ and each depth candidate $d_m$ to obtain warped features $\{F_{j \to i}^m\}_{m=1}^D$ [S1].
4.  **Cost Volume Construction:** Measure feature correlations via dot-product between $F_i$ and the warped features $F_{j \to i}^m$ [S1]. Stack these correlations to form the cost volume $C_i \in \mathbb{R}^{\frac{H}{s} \times \frac{W}{s} \times D}$ for image $i$ [S1].
    *   For $N > 2$ views, select the top-2 nearest neighboring views based on camera distance to reference view $i$. Compute correlations only for these views. Combine the correlation values from the selected views with averaging [S1].
5.  **Feature Concatenation:** Concatenate the multi-view cost volumes $C_i$ with the extracted monocular features $F_i$ [S1].
6.  **Depth Regression:** Perform depth regression using a 2D U-Net architecture followed by a softmax layer to predict dense per-pixel depth $D_i$ [S1].
7.  **Unprojection:** Unproject the predicted depth maps $D_i$ to 3D space using camera parameters $P_i$ to obtain Gaussian centers $\mu_j$ [S1].
8.  **Gaussian Parameter Prediction:** Predict remaining Gaussian parameters (opacity $\alpha_j$, covariance $\Sigma_j$, color $c_j$) using an additional lightweight network/head in parallel with the depth regression [S1].
9.  **Rendering:** Render novel views using the splatting operation with the predicted 3D Gaussians [S1].

**Pseudocode:**

```python
def depthsplat(images, projection_matrices):
    """
    images: List of N images, shape (H, W, 3)
    projection_matrices: List of N matrices, shape (3, 4)
    Returns: List of 3D Gaussians (mu, alpha, Sigma, c)
    """
    N = len(images)
    H, W = images[0].shape[:2]
    s = 4  # Example downsampling factor
    D = 128  # Number of depth candidates, Not given in the sources.
    
    # Step 1: Monocular Feature Extraction
    monocular_features = []
    for i in range(N):
        # Extract features using pre-trained ViT
        F_i = extract_monocular_features(images[i])
        monocular_features.append(F_i)
        
    # Step 2-4: Cost Volume Construction
    cost_volumes = []
    for i in range(N):
        # Step 2: Sample depth candidates
        depth_candidates = sample_depth_candidates(D, near=0.1, far=100.0) # Ranges not given in sources [G]
        
        # Step 3-4: Warp and Correlate
        # Select neighbors
        if N > 2:
            neighbors = get_top_2_nearest_views(i, projection_matrices)
        else:
            neighbors = [j for j in range(N) if j != i]
            
        correlations = []
        for j in neighbors:
            F_j = monocular_features[j]
            warped_features = []
            for d_m in depth_candidates:
                # Warp F_j to view i using P_i and d_m
                F_warped = warp_feature(F_j, projection_matrices[i], d_m)
                warped_features.append(F_warped)
            
            # Dot-product correlation
            F_i_downsampled = downsample(monocular_features[i], s)
            # Correlation shape: (H/s, W/s, D)
            corr = dot_product_correlation(F_i_downsampled, warped_features)
            correlations.append(corr)
            
        # Average correlations if multiple neighbors
        if len(correlations) > 1:
            C_i = average(correlations)
        else:
            C_i = correlations[0]
        cost_volumes.append(C_i)
        
    # Step 5: Concatenation
    # Concatenate cost volumes with monocular features
    # Note: Dimensions must be aligned. Monocular features are likely upsampled or cost volumes downsampled.
    # The source states concatenation, implying compatible spatial dimensions or channel concatenation.
    # Assuming cost volumes are at resolution H/s x W/s and monocular features are processed accordingly.
    concatenated_features = []
    for i in range(N):
        # Upsample monocular features to match cost volume spatial size if necessary
        F_i_aligned = upsample(monocular_features[i], target_size=(H//s, W//s))
        concat = concatenate(cost_volumes[i], F_i_aligned, axis=-1)
        concatenated_features.append(concat)
        
    # Step 6: Depth Regression
    depth_maps = []
    for i in range(N):
        # 2D U-Net followed by softmax
        D_i = depth_regression(concatenated_features[i])
        depth_maps.append(D_i)
        
    # Step 7: Unprojection
    gaussian_centers = []
    for i in range(N):
        # Unproject depth map D_i using P_i
        mu_j = unproject_depth(depth_maps[i], projection_matrices[i])
        gaussian_centers.append(mu_j)
        
    # Step 8: Gaussian Parameter Prediction
    gaussian_params = []
    for i in range(N):
        # Predict alpha, Sigma, c using lightweight head
        alpha_j, Sigma_j, c_j = predict_gaussian_params(concatenated_features[i])
        gaussian_params.append((gaussian_centers[i], alpha_j, Sigma_j, c_j))
        
    return gaussian_params
```

**Edge Cases and Pitfalls:**
*   **Occlusions, Low-Texture, Non-Lambertian Surfaces:** Multi-view depth estimation fails in these areas. DepthSplat mitigates this by augmenting multi-view cost volumes with monocular features [S1].
*   **Scale Ambiguities:** Monocular depth estimation suffers from scale ambiguities across multiple views. DepthSplat maintains multi-view consistency by using monocular features only as an augmentation to multi-view matching [S1].
*   **Error Propagation:** Unlike TranSplat, which refines coarse depth with monocular features (vulnerable to error propagation), DepthSplat combines cost volume and monocular features early to avoid this [S1].

## Subtopics

### [Gaussian Graph Network](18863-gaussian-graph-network.md)
Gaussian Graph Network (GGN) is a feed-forward method that generates efficient and generalizable 3D Gaussian representations from multi-view images by modeling relations between Gaussian groups from different views using a Gaussian Graph structure. It solves the problem of artifacts and excessive memory costs caused by previous methods that simply combine pixel-aligned Gaussians from multiple views without capturing their inter-view relations. Unlike sibling methods that treat multi-view Gaussians as independent sets, GGN performs message passing and aggregation at the Gaussian level, allowing each Gaussian to benefit from connected groups in other views.

## Operating characteristics
*   **Reconstruction Speed:** 0.6 seconds for feed-forward reconstruction from 12 input views at 512x960 resolution [S1].
*   **Training Cost:** Trained in 2 days with 4 GPUs, compared to GS-LRM which requires 64 A100 GPUs for 2 days [S1].
*   **Scalability:** For $N > 2$ views, the method selects top-2 nearest neighbors to keep computation tractable and scale efficiently [S1].
*   **Strengths:** Robust in challenging situations (low-textured, reflective surfaces) due to monocular feature augmentation; maintains multi-view consistency; efficient training [S1].
*   **Limitations:** Relies on pre-trained monocular depth model; multi-view depth estimation still fundamentally limited by occlusions and non-Lambertian surfaces, though mitigated [S1].
*   **When to Use:** Large-scale scene reconstruction from multiple views where efficiency and robustness are required [S1].
*   **When Not to Use:** Single-image reconstruction (Flash3D targets this); per-scene optimization (orthogonal approach) [S1].

## Background
DepthSplat was introduced to connect Gaussian splatting and depth estimation, studying their interactions [S1]. It addresses the isolation of these two fields by leveraging pre-trained monocular depth features to enhance multi-view depth prediction, leading to high-quality feed-forward 3D Gaussian splatting reconstructions [S1]. The method also demonstrates that Gaussian splatting can serve as an unsupervised pre-training objective for learning powerful depth models from large-scale multi-view posed datasets [S1]. It was validated on TartanAir, ScanNet, RealEstate10K, and DL3DV datasets, achieving state-of-the-art results [S1]. The work contrasts with TranSplat (which refines coarse depth) and GS-LRM (which relies heavily on data/compute) [S1].
