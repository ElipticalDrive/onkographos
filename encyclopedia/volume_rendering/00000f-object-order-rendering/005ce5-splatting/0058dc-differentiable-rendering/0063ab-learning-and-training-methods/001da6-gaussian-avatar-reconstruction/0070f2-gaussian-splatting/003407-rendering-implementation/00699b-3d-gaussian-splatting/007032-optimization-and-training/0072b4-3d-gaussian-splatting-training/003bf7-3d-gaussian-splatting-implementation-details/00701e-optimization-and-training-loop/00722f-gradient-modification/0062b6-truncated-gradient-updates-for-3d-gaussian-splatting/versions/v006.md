# Truncated Gradient Updates for 3D Gaussian Splatting

Also called: TruncGradGS

## Overview
Truncated Gradient Updates is a gradient modification technique that applies a surrogate "truncated" gradient to 'dead' Gaussians (those with low opacity) to enable long-range movement and convergence, addressing vanishing gradients in dynamic scenes or poor initialization [S1]. It sets itself apart from standard 3D Gaussian Splatting by intercepting the backward pass to provide gradient signals to Gaussians that are rasterization-filtered out due to low opacity or distance, while strictly limiting this effect to inactive primitives to prevent model divergence [S1].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   Gaussian parameters $\mathcal{G} = \{g_i\}_{i=1}^N$, where each $g_i$ includes mean $\mu_i$, covariance $\Sigma_i$, opacity $\sigma_i$, spherical harmonics coefficients, and scale.
    *   Pixel center coordinates $p = (p_x, p_y)$ in the image plane.
    *   Loss gradient with respect to alpha $\frac{\partial L}{\partial \alpha_i}$.
    *   Pruning threshold $\tau_{pruning}$ for opacity.
    *   Slope parameter $m$ controlling the decay of the truncated gradient.
    *   Coefficients $a, b, c$ derived from the Gaussian covariance projection (Eq. 8 in [S1]).
*   **Outputs:**
    *   Modified gradients $\nabla \mu_i$ for the Gaussian means, used by the optimizer (e.g., Adam).

### Data Structures
The method operates on the standard 3D Gaussian Splatting data structures. No new persistent data structures are required, but runtime flags are used to identify "dead" Gaussians.
*   **Dead Gaussian Flag:** A boolean or opacity check $\sigma_i < \tau_{pruning}$ determines if a Gaussian is eligible for truncated gradients.
*   **Motion Masks (Dynamic Scenes):** For dynamic methods, a binary mask per pixel indicating static vs. dynamic regions, computed via frame-difference and image processing on input videos [S1].

### Numbered Steps

1.  **Identify Eligible Gaussians:**
    For each Gaussian $i$ contributing to a pixel $p$ (or filtered out), check if it is a "dead" Gaussian:
    $$ \text{is\_dead} = (\sigma_i < \tau_{pruning}) $$
    If `is_dead` is false, proceed to the Normal Path. If true, proceed to Step 2.

2.  **Calculate Mahalanobis Distance:**
    Compute the squared Mahalanobis distance $r_s$ between the Gaussian mean $\mu_i$ and the pixel center $p$:
    $$ r_s = \|\mu_i - p\|_2^2 $$
    Compute the quadratic form $K$ using coefficients $a, b, c$ from the projected covariance:
    $$ K = a(\mu_{ix} - p_x)^2 + 2b(\mu_{ix} - p_x)(\mu_{iy} - p_y) + c(\mu_{iy} - p_y)^2 $$
    Determine the cut-off threshold condition. The source defines the solution for the cut-off point $x$ where the gradient surrogate equals the threshold $\tau$. The condition for applying the truncated gradient is based on whether the distance exceeds this threshold. Specifically, the method distinguishes between cases where the splat is filtered out due to low opacity/density.

3.  **Check Alpha Gradient Sign:**
    Evaluate the gradient with respect to alpha: $\frac{\partial L}{\partial \alpha_i}$.
    *   If $\frac{\partial L}{\partial \alpha_i} \ge 0$, do **not** apply the truncated gradient. Applying it when positive would cause a long-range push, making Gaussians repel each other [S1].
    *   If $\frac{\partial L}{\partial \alpha_i} < 0$, proceed to determine the update path.

4.  **Determine Gradient Update Path:**
    Evaluate the product of opacity $\sigma_i$ and alpha $\alpha_i$ (where $\alpha_i$ is the alpha value computed during forward rasterization, typically $\alpha_i = \sigma_i (1 - \exp(-\beta \dots))$ or similar, but the source uses $\sigma \alpha$ as a proxy for contribution strength, specifically referencing the threshold $1/255$) relative to the threshold $1/255$ and the Mahalanobis distance.

    *   **Normal Path:**
        If $\sigma_i \alpha_i \ge 1/255$ (high-pass filter, i.e., significant contribution):
        *   Use the standard gradient $\nabla \mu_i$ computed via automatic differentiation.
        *   Do not apply truncated gradient.

    *   **Truncated Path:**
        If $\sigma_i \alpha_i < 1/255$ (low density or low opacity) **AND** the Mahalanobis distance $r_s$ is above the cut-off threshold (meaning the Gaussian is far from the pixel center but still relevant for long-range correction):
        *   Apply the truncated gradient.
        *   If the low contribution is due to low opacity $\sigma_i$ (specifically if $\sigma_i$ is the primary factor), compute the gradient only for the opacity $\sigma_i$ component, or apply the surrogate gradient field for the mean [S1].
        *   The truncated gradient is a linear surrogate function. The cut-off gradient is defined as $G'(x)$, where $x$ is the solution to $G(x) = \tau$. The slope $m$ influences the range: lower $m$ yields a near-constant long-range gradient; higher $m$ yields a sharp decay [S1].

    *   **Skip Path:**
        If $\sigma_i \alpha_i < 1/255$ **AND** the Mahalanobis distance $r_s$ is below the threshold (i.e., the Gaussian is close but effectively invisible due to low opacity):
        *   Do not receive any gradients. This prevents noise from perturbing well-placed but low-opacity Gaussians [S1].

5.  **Expand Tile-Coverage Radius (Implementation Detail):**
    For dead Gaussians whose radius is below a threshold, expand the tile-coverage radius. This addresses tile-based culling of the rasterizer, enabling long-distance pixel error contributions to be registered by the truncated gradient field [S1].

6.  **Interleaved Optimization Strategy:**
    To prevent divergence and allow dead Gaussians to converge before pruning:
    *   Alternate between optimization steps using truncated gradients and normal optimization steps with Adaptive Density Control (ADC) turned on.
    *   Delay the pruning of primitives until the end of training. This allows dead Gaussians to receive long-range gradients and move to distant pixels before being removed [S1].

7.  **Dynamic Scene Optimization (Optional):**
    For dynamic scenes, create viewpoint-dependent motion masks via frame-difference and image processing. Ignore contributions of static pixels to reduce computation overhead [S1].

def compute_truncated_gradients(gaussians, pixels, loss_grad_alpha, tau_pruning, m, a, b, c):
    """
    Computes modified gradients for Gaussian means using truncated gradient updates.
    
    Args:
        gaussians: List of Gaussian objects with attributes:
            - mu: (2,) mean in image plane
            - sigma: float opacity
            - alpha: float alpha value from forward pass
            - is_dead: bool, True if sigma < tau_pruning
        pixels: List of pixel centers (px, py)
        loss_grad_alpha: Gradient of loss w.r.t alpha for each Gaussian-pixel pair
        tau_pruning: Opacity threshold for pruning
        m: Slope parameter for truncated gradient decay
        a, b, c: Coefficients from projected covariance
        
    Returns:
        modified_grad_mu: List of gradient vectors for each Gaussian mean
    """
    modified_grad_mu = [np.zeros(2) for _ in gaussians]
    
    for i, g in enumerate(gaussians):
        grad_accum = np.zeros(2)
        
        # Iterate over relevant pixels (or all pixels if not using tile culling)
        # In practice, this is done per pixel during the backward pass
        for p in pixels:
            px, py = p
            
            # Step 1: Check if Gaussian is dead
            if g.sigma >= tau_pruning:
                # Normal Gaussians receive standard gradients from AD
                # This logic is handled by the standard backward pass
                # We only modify gradients for dead Gaussians or those in specific paths
                continue
            
            # Step 2: Calculate Mahalanobis Distance components
            dx = g.mu[0] - px
            dy = g.mu[1] - py
            K = a * dx**2 + 2 * b * dx * dy + c * dy**2
            r_s = dx**2 + dy**2 # Euclidean squared distance, but threshold logic uses K-based solution
            
            # Determine if distance is above cut-off threshold

            # For implementation, we check if the Gaussian is "far" enough.
            # The source states: "If the distance is greater than the cut-off threshold, apply the truncated gradient"
            # We assume a function is_dist_above_threshold(r_s, K, tau) exists or is approximated.
            # Based on Eq 16/17, the solution x is derived from K.
            # Let's assume a boolean flag `is_far` is determined by comparing r_s to a threshold derived from K and tau.
            # Since exact threshold formula is complex, we use the logical structure:

            # Step 3: Check Alpha Gradient Sign
            if loss_grad_alpha[i] >= 0:

                continue

            # Threshold for contribution: 1/255
            contribution_threshold = 1.0 / 255.0
            
            if g.sigma * g.alpha >= contribution_threshold:
                # Normal Path: High contribution. Use standard AD gradient.
                # (Handled by standard backward pass, so we skip modification here)
                continue
            else:
                # Low contribution
                if is_far:
                    # Truncated Path
                    # Compute truncated gradient
                    # The truncated gradient is a linear surrogate.
                    # G'(x) where x is solution to G(x) = tau.
                    # Slope m influences the decay.
                    # For implementation, we approximate the direction towards the pixel
                    # and scale by a factor determined by m and the distance.
                    
                    # Direction from Gaussian to Pixel
                    direction = np.array([px - g.mu[0], py - g.mu[1]])
                    dist = np.linalg.norm(direction)
                    if dist == 0:
                        continue
                    
                    unit_direction = direction / dist
                    
                    # Calculate magnitude of truncated gradient
                    # The source defines cut-off gradient G'(x).
                    # A lower m yields near-constant gradient; higher m yields sharp decay.
                    # We approximate this as:
                    # grad_mag = m * exp(-m * dist) or similar decay function
                    # However, the source says "approximating the cut-off gradient".
                    # Let's use a simplified surrogate:
                    # grad_mag = base_grad * decay(m, dist)
                    
                    # Since exact G'(x) formula is not fully explicit in text, we use the structural intent:
                    # Apply a gradient pointing towards the pixel, scaled by m.
                    truncated_grad = unit_direction * m * np.exp(-m * dist)
                    
                    # If low opacity is the cause, gradient is computed for opacity sigma
                    # But for mean update, we apply the truncated mean gradient.
                    grad_accum += truncated_grad
                else:
                    # Skip Path: Low contribution, close distance. No gradient.
                    pass
        
        modified_grad_mu[i] = grad_accum
        
    return modified_grad_mu

### Parameters
*   **Slope parameter $m$:** Influences the range of action of the truncated gradient in the image plane. A lower $m$ yields a near-constant long-range gradient approximating the cut-off gradient; a higher $m$ yields a sharp decay from the cut-off gradient [S1].
*   **Pruning Threshold $\tau_{pruning}$:** Opacity threshold below which a Gaussian is considered "dead" and eligible for truncated gradients [S1].
*   **Contribution Threshold:** $1/255$. Used to distinguish between high-pass (normal) and low-pass (truncated/skip) paths [S1].

### Edge Cases and Pitfalls
*   **Model Divergence:** Accumulated truncated gradients may surpass the true gradient, especially for "very bad fits" (no normal gradients) or "good fits" (true gradient near zero). This is prevented by applying the truncated gradient **only** for dead Gaussians ($\sigma_i < \tau_{pruning}$) [S1].
*   **Repulsion:** Applying truncated gradients when $\frac{\partial L}{\partial \alpha_i} \ge 0$ causes Gaussians to repel each other. The sign check is critical [S1].
*   **Tile Culling:** Dead Gaussians with small radii may be culled by the rasterizer, preventing them from receiving any gradient. Expanding the tile-coverage radius for dead Gaussians addresses this [S1].
*   **Performance Overhead:** Without optimizations, the method can be significantly slower. Restricting radius expansion and truncated gradient computation to dead Gaussians, and using motion masks for dynamic scenes, reduces this to 1–10× slower than baseline [S1].

## Operating characteristics

*   **Time Complexity:** The method adds overhead to the backward pass. It is 1–10× slower to train than the baseline 3D Gaussian Splatting, depending on the scene and primitive count [S1]. Inference speed is unaffected [S1].
*   **Memory Complexity:** No significant additional memory overhead, as it reuses existing Gaussian structures and only adds runtime flags/masks [S1].
*   **Measured Performance:**
    *   **Static Scenes (Mip-NeRF360, Random Init):** PSNR 25.16 (vs 24.74), SSIM 0.8511 (vs 0.8351), LPIPS 0.1974 (vs 0.2106), #GS 0.799M (vs 1.126M) [S1].
    *   **Dynamic Scenes (Neural 3D Video):** PSNR 31.70 (vs 30.22), SSIM 0.9493 (vs 0.9443), LPIPS 0.1339 (vs 0.1360), #GS 1.733M (vs 2.806M) [S1].
*   **Strengths:** Improves optimization robustness, allows recovery of poorly initialized or weakly constrained Gaussians, and handles large spatio-temporal divergence in dynamic scenes. It is a plug-and-play module compatible with 3DGS, 2DGS, 4DGS, CEM-4DGS, and 4DScaffold [S1].
*   **Limitations:** Training time increases. Requires careful tuning of the slope parameter $m$ and pruning threshold. May not be necessary for well-initialized static scenes with good COLMAP reconstruction [S1].

## Background

*   **Origin:** The method was introduced in "TruncGradGS: Improved 3D Gaussian Splatting via Truncated Gradient Updates" by T. Morales, N.-Q. Le-Pham, R. Atkins & B.-S. Hua, published in Eurographics 2026 [S1].
*   **History:** It addresses the limitation of standard 3D Gaussian Splatting where Gaussians with low opacity or those filtered out by rasterization receive no gradient signal, leading to poor convergence in dynamic scenes or with random initialization.
*   **Usage:** Used as a plug-and-play module on top of various Gaussian Splatting variants for both static and dynamic scene reconstruction [S1].
