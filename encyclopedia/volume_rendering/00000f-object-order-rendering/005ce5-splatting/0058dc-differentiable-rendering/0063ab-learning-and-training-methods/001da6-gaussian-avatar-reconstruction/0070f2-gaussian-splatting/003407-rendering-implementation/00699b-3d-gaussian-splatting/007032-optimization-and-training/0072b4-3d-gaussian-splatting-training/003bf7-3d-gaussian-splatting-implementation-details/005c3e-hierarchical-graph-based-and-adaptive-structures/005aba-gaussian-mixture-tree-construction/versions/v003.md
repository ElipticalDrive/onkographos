# Gaussian Mixture Tree Construction

Also called: Hierarchically Merging Gaussians

## Overview
Gaussian Mixture Tree (GMT) Construction is a method for organizing 3D Gaussian primitives into a hierarchical tree structure to identify distinct 3D plane instances in a scene [S1]. It solves the problem of spatially scattered Gaussian centers by grouping them into coherent planar surfaces, enabling probabilistic modeling of the scene geometry [S1]. Unlike sibling methods that rely on spatial proximity or feature matching for connectivity [14454-tragraph-gs.md, 22007-surface-aware-splat-graph-construction.md], GMT uses statistical merging criteria based on Bhattacharya distance and plane descriptor similarity to build a multi-level representation from leaf clusters to the root [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of $N_s$ leaf nodes, where each leaf node $G_i$ represents a local cluster of Gaussian primitives. Each node $G_i$ is defined by parameters: mean position $\mu_i \in \mathbb{R}^3$, covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$, normal vector $n_i \in \mathbb{R}^3$, and a learnable plane descriptor $z_i \in \mathbb{R}^k$ (typically $k=3$) [S1].
*   **Output:** A Gaussian Mixture Tree $G$ containing parent nodes $G_{s_k}$ and a counter $L$ representing the number of merged plane nodes [S1].

**Data Structures**
*   **Leaf Node:** A cluster of Gaussians. Raw optimized Gaussians are not used directly as leaves due to computational expense; they are first grouped into local clusters [S1].
*   **Tree Node:** Represents a Gaussian distribution $G_p(\mu_p, \Sigma_p)$ encompassing the center points of its children [S1].

**Parameters**
*   $\epsilon_B$: Threshold for the Bhattacharya distance [S1].
*   $\epsilon_z$: Threshold for the difference in cosine similarity between plane descriptors ($1 - \langle z_i \cdot z_j \rangle \le \epsilon_z$) [S1].
*   Typical values for $\epsilon_B$ and $\epsilon_z$ are not given in the sources.

**Algorithm Steps**
1.  Initialize $L = 0$ and the set of plane nodes $G = \emptyset$ [S1].
2.  Iterate through each leaf node $i$ from $1$ to $N_s$:
    a.  Check if node $i$ is already a descendant of any existing node in $G$. If it is, skip to the next $i$ [S1].
    b.  If not, iterate through each subsequent leaf node $j$ from $i+1$ to $N_s$:
        i.  Check if node $j$ is already a descendant of any existing node in $G$. If it is, skip to the next $j$ [S1].
        ii. If not, calculate the Bhattacharya distance $D_B(G_i, G_j)$ and the cosine similarity difference between descriptors $z_i$ and $z_j$ [S1].
        iii. If $D_B(G_i, G_j) \le \epsilon_B$ AND $1 - \langle z_i \cdot z_j \rangle \le \epsilon_z$:
            1.  Merge $G_i$ and $G_j$ into a parent node $G_{ij}^p(\mu_p, \Sigma_p)$ using the Gaussian Mixture Model formulas [S1].
            2.  Update $G_i \leftarrow G_{ij}^p$ [S1].
            3.  Break the inner loop (stop checking further $j$ for this $i$) [S1].
    c.  Insert the current node $G_i$ (which may have been merged) into the set $G$ [S1].
    d.  Increment $L$ by 1 [S1].

**Formulas**
The merging of two Gaussian distributions $G_i(\mu_i, \Sigma_i)$ and $G_j(\mu_j, \Sigma_j)$ into a parent $G_p(\mu_p, \Sigma_p)$ is defined as [S1]:

$$
\mathbf{\Sigma}_p = \mathbf{\Sigma}_j \cdot (\mathbf{\Sigma}_i + \mathbf{\Sigma}_j)^{-1} \cdot \mathbf{\Sigma}_i
$$

$$
\mathbf{\mu}_p = \mathbf{\Sigma}_j \cdot (\mathbf{\Sigma}_i + \mathbf{\Sigma}_j)^{-1} \cdot \mathbf{\mu}_i + \mathbf{\Sigma}_i \cdot (\mathbf{\Sigma}_i + \mathbf{\Sigma}_j)^{-1} \cdot \mathbf{\mu}_j
$$

The Bhattacharya distance $D_B(G_i, G_j)$ used as a merging criterion is [S1]:

$$
D_B(G_i, G_j) = \frac{1}{8}(\mathbf{\mu}_i - \mathbf{\mu}_j)^{T}\mathbf{\Sigma}^{-1}(\mathbf{\mu}_i - \mathbf{\mu}_j) + \frac{1}{2}\ln \left( \frac{\det \mathbf{\Sigma}}{\sqrt{\det \mathbf{\Sigma}_i \det \mathbf{\Sigma}_j}} \right)
$$

where $\mathbf{\Sigma} = (\mathbf{\Sigma}_i + \mathbf{\Sigma}_j)/2$ [S1].

**Pseudocode**
```python
def construct_gaussian_mixture_tree(leaf_nodes, epsilon_b, epsilon_z):
    """
    Constructs a Gaussian Mixture Tree from leaf nodes.
    
    Args:
        leaf_nodes: List of dicts, each containing 'mu' (3,), 'Sigma' (3,3), 
                    'n' (3,), 'z' (k,).
        epsilon_b: Float, Bhattacharya distance threshold.
        epsilon_z: Float, Cosine similarity difference threshold.
        
    Returns:
        plane_nodes: List of merged Gaussian nodes.
        L: Integer, count of plane nodes.
    """
    N_s = len(leaf_nodes)
    plane_nodes = []
    L = 0
    
    # Track which original indices have been merged into a parent
    # to avoid re-processing descendants.
    # Since the algorithm modifies G_i in place, we need to track 
    # which nodes are "active" leaves vs those already incorporated.
    # The source algorithm checks if i is a descendant of existing G_sk.
    # We implement this by maintaining a list of processed nodes.
    
    # Note: The source algorithm iterates i from 1 to Ns.
    # If i is not a descendant of any node in G, it tries to merge with j > i.
    # If merged, G_i becomes the parent. Then G_i is added to G.
    # This implies a greedy, single-pass hierarchical merging.
    
    # To implement "is descendant of any existing node in G":
    # We can track the set of indices that have been merged into a parent.
    # However, the source updates G_i to be the parent. 
    # Let's follow the source logic strictly.
    
    # We need to know which original leaf indices are covered by current plane_nodes.
    # But the source doesn't explicitly track indices, it tracks nodes.
    # Let's assume leaf_nodes are immutable references, and we build new nodes.
    
    # Re-reading source: "if i is NOT descendant of {G_sk}"
    # This implies we need to know the spatial extent or membership of G_sk.
    # Since G_sk is a Gaussian distribution, "descendant" likely means 
    # the original leaf node i was one of the inputs to create G_sk.
    # We will track the set of original indices included in each plane node.
    
    plane_node_indices = [] # List of sets of original indices
    
    for i in range(N_s):
        # Check if i is already covered by an existing plane node
        is_descendant = False
        for indices in plane_node_indices:
            if i in indices:
                is_descendant = True
                break
        
        if not is_descendant:
            current_node = leaf_nodes[i].copy()
            current_indices = {i}
            
            # Try to merge with subsequent nodes
            for j in range(i + 1, N_s):
                # Check if j is already covered
                is_j_descendant = False
                for indices in plane_node_indices:
                    if j in indices:
                        is_j_descendant = True
                        break
                
                if not is_j_descendant:
                    # Calculate distances
                    dist_b = bhattacharya_distance(current_node, leaf_nodes[j])
                    cos_diff = 1.0 - cosine_similarity(current_node['z'], leaf_nodes[j]['z'])
                    
                    if dist_b <= epsilon_b and cos_diff <= epsilon_z:
                        # Merge
                        merged_mu, merged_sigma = merge_gaussians(current_node, leaf_nodes[j])
                        
                        # Update current_node to be the parent
                        current_node['mu'] = merged_mu
                        current_node['Sigma'] = merged_sigma
                        # Note: Source doesn't specify how n and z are updated for the parent.
                        # [G] Assuming z and n are not updated or remain from the first child,
                        # or are recomputed. Source says "G_ij_p(mu_p, Sigma_p) <- Gi + Gj".
                        # It does not specify z_p or n_p. We leave them as current_node's values.
                        
                        current_indices.add(j)
                        break # Break inner loop
            
            # Add to plane nodes
            plane_nodes.append(current_node)
            plane_node_indices.append(current_indices)
            L += 1
            
    return plane_nodes, L

def bhattacharya_distance(node_i, node_j):
    mu_i = node_i['mu']
    mu_j = node_j['mu']
    Sigma_i = node_i['Sigma']
    Sigma_j = node_j['Sigma']
    
    Sigma = (Sigma_i + Sigma_j) / 2.0
    
    # Compute inverse of Sigma
    Sigma_inv = np.linalg.inv(Sigma)
    
    term1 = 0.125 * (mu_i - mu_j).T @ Sigma_inv @ (mu_i - mu_j)
    
    det_Sigma = np.linalg.det(Sigma)
    det_Sigma_i = np.linalg.det(Sigma_i)
    det_Sigma_j = np.linalg.det(Sigma_j)
    
    term2 = 0.5 * np.log(det_Sigma / np.sqrt(det_Sigma_i * det_Sigma_j))
    
    return term1 + term2

def cosine_similarity(z_i, z_j):
    return np.dot(z_i, z_j) / (np.linalg.norm(z_i) * np.linalg.norm(z_j))

def merge_gaussians(node_i, node_j):
    mu_i = node_i['mu']
    mu_j = node_j['mu']
    Sigma_i = node_i['Sigma']
    Sigma_j = node_j['Sigma']
    
    Sigma_sum = Sigma_i + Sigma_j
    Sigma_sum_inv = np.linalg.inv(Sigma_sum)
    
    Sigma_p = Sigma_j @ Sigma_sum_inv @ Sigma_i
    mu_p = Sigma_j @ Sigma_sum_inv @ mu_i + Sigma_i @ Sigma_sum_inv @ mu_j
    
    return mu_p, Sigma_p
```

**Edge Cases and Pitfalls**
*   **Computational Expense:** Raw Gaussian primitives cannot be used as leaf nodes due to the large number of Gaussians in a scene; they must be pre-clustered into local clusters [S1].
*   **Descriptor Learning:** The plane descriptors $z$ and normal vectors $n$ are learned during optimization using 2D normal maps (via Omnidata) and 2D SAM masks, respectively [S1]. If these are not available, the merging criteria cannot be fully applied.
*   **Precision:** The Bhattacharya distance involves matrix inversion and logarithms of determinants. Degenerate covariances (singular matrices) will cause numerical instability [G].

## Subtopics

### Hierarchical 3D Gaussian BVH Construction
Builds a bounding volume hierarchy for efficient ray traversal, differing from GMT which focuses on semantic plane merging [17260-hierarchical-anchor-coupling.md].

### Surface-Aware Splat Graph Construction
Defines edges based on geometric intersection and feature matching, whereas GMT uses statistical distance for merging [22007-surface-aware-splat-graph-construction.md].

### TraGraph-GS
Connects Gaussians via feature matching, providing structural connectivity rather than hierarchical aggregation [14454-tragraph-gs.md].

## Operating characteristics
*   **Time Complexity:** The algorithm involves nested loops over $N_s$ leaf nodes, resulting in $O(N_s^2)$ comparisons in the worst case. Each comparison involves matrix inversion and determinant calculation, which is $O(1)$ for fixed 3D Gaussians but costly in practice.
*   **Memory Complexity:** Requires storing the tree structure and the parameters for each node. The number of nodes decreases as merging proceeds.
*   **Strengths:** Identifies distinct 3D plane instances, enabling a more compact and semantically meaningful representation of the scene [S1].
*   **Limitations:** Relies on the quality of the initial clustering and the learned descriptors. The greedy merging strategy may not find the globally optimal tree structure.
*   **When to use:** When semantic plane segmentation is required for downstream tasks like editing or compression.
*   **When not to use:** When real-time rendering speed is the primary concern and semantic structure is not needed.

## Background
The Gaussian Mixture Tree was introduced in "Planar Gaussian Splatting" (WACV 2025) by the authors of [S1]. It extends standard 3D Gaussian Splatting by adding a hierarchical structure to identify planar surfaces, leveraging 2D priors from normal estimation and segmentation models [S1].
