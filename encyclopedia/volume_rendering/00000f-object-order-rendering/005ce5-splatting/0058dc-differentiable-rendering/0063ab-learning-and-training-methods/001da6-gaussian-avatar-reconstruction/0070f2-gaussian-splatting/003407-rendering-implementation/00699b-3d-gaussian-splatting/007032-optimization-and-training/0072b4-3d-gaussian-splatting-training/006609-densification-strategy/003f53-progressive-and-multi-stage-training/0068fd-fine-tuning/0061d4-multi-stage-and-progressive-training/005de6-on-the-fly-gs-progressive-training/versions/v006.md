# On-the-Fly GS Progressive Training

Also called: On-the-Fly Gaussian Splatting

## Overview
On-the-Fly GS Progressive Training is a method for optimizing 3D Gaussian Splatting (3DGS) fields in a streaming or sequential acquisition context, enabling near real-time reconstruction as new images arrive [S1]. It solves the problem of catastrophic forgetting and overfitting when incrementally adding Gaussians to an existing scene representation by decoupling the optimization into initialization, progressive incremental updates, and final global refinement [S1]. Unlike static training methods, it dynamically allocates training resources and learning rates based on hierarchical image overlap weights and introduces a load-balancing loss to prevent Gaussian accumulation in specific regions [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A sequence of incoming RGB images.
*   An existing 3DGS field (initially empty or initialized from a sparse subset).
*   A sparse point cloud and camera poses, updated by an external "On-the-Fly SfM" module [S1].
*   Hyperparameters: $N_0$ (initial image count), $T_I$ (iterations per new image), $N_m$ (key images), $T_a$ (satisfactory iterations threshold), $\eta^0, \eta^f$ (learning rates), $\lambda_1, \lambda_{ssim}, \lambda_{load}$ (loss weights) [S1].

**Outputs:**
*   A refined 3DGS field (Gaussians with position, covariance, opacity, and spherical harmonics coefficients) optimized for the accumulated image sequence [S1].

### Data Structures
*   **3DGS Field:** Standard 3DGS representation containing a list of Gaussians. Each Gaussian stores position ($\mathbf{p}$), rotation ($\mathbf{q}$), scale ($\mathbf{s}$), opacity ($\alpha$), and color coefficients (SH) [S1].
*   **Sparse Point Cloud:** A set of 3D points $\{\mathbf{X}_k\}$ with associated 2D image coordinates from the SfM pipeline [S1].
*   **Search Tree:** A spatial index (e.g., KD-Tree) built over the existing sparse point cloud to efficiently query distances for new points [S1].
*   **Image Overlap Matrix ($M$):** A matrix where $M_{i,j}$ stores the number of matched feature points between image $i$ and image $j$ [S1].
*   **Training State:** Per-image counters for iterations completed ($T_j$) and current learning rates ($\eta_j$) [S1].

### Numbered Steps

#### Phase 1: Initial 3DGS Training
1.  **Initialization:** The On-the-Fly SfM module estimates poses and generates a sparse point cloud for the first $N_0$ images [S1].
2.  **Training:** Train an initial 3DGS field using the standard 3DGS optimization algorithm on these $N_0$ images [S1].
3.  **Constraint:** Limit training to a strict number of iterations (typically 2,000) to prevent overfitting to the small initial subset [S1].

#### Phase 2: Progressive 3DGS Training (Per New Image)
For each newly acquired image $n$:
1.  **Pose and Cloud Update:** The On-the-Fly SfM module updates the camera poses for image $n$ and its neighbors via local Bundle Adjustment (BA), and refines the global sparse point cloud [S1].
2.  **Tree Construction:** Build or update a search tree (e.g., KD-Tree) for the existing sparse point cloud [S1].
3.  **New Point Identification:** Query the sparse points from image $n$ against the search tree. Points with a shortest distance to the existing cloud exceeding a predefined threshold are classified as **newly added points** [S1].
4.  **Gaussian Initialization:** Initialize new Gaussians for these newly added points and append them to the current 3DGS field [S1].
5.  **Weight Calculation:** Compute hierarchical weights for the current image $n$ and all previously registered images to determine training priority [S1]:
    *   **Layer 1 (New Image):** Weight $\omega_{11} = 1$ [S1].
    *   **Layer 2 (Direct Overlap):** For images $i$ with direct overlap ($M_{i,n} \neq 0$), calculate weight:
        $$ \omega_{2i} = M_{i,n} $$
        where $M_{i,n}$ is the number of matched feature points between image $i$ and new image $n$ [S1].
    *   **Layer $k$ (Indirect Overlap, $k \ge 3$):** For images $i$ in layer $k$, calculate weight based on layer $k-1$:
        $$ \omega_{ki} = \frac{\sum_{j=1}^{N_{k-1}} \omega_{j}^{(k-1)} \times M_{j,ki}^{(k-1)}}{N_{k-1}} $$
        where $\omega_{j}^{(k-1)}$ is the weight of image $j$ in layer $k-1$, $M_{j,ki}^{(k-1)}$ is the match count between image $j$ and image $i$, and $N_{k-1}$ is the number of images in layer $k-1$ [S1].
6.  **Optimization Allocation:** Perform $T_I$ total training iterations on the current 3DGS field, distributed as follows [S1]:
    *   **Local Optimization ($T_I/2$ iterations):** Select the top $N_m$ images with the highest weights. For each key image $i$ with weight $\omega_i$, allocate iterations $T_{im}$:
        $$ T_{im} = \frac{1 - e^{-\omega_i}}{\sum_{j=1}^{N_m} (1 - e^{-\omega_j})} \times T_I $$
        Train these images for their allocated $T_{im}$ iterations [S1].
    *   **Semi-Global Optimization ($T_I/2$ iterations):** Distribute the remaining $T_I/2$ iterations evenly among all other registered images (those not in the top $N_m$) [S1].
7.  **Adaptive Learning Rate Update:** For each image $j$ trained for $T_j$ iterations, update its learning rate $\eta_j$ [S1]:
    *   Calculate progress $t_i$:
        $$ t_i = \begin{cases} 1 & \text{if } T_j > T_a \\ T_j / T_a & \text{if } T_j \le T_a \end{cases} $$
    *   Calculate base learning rate $\eta_j^c$:
        $$ \eta_j^c = (\eta_j^0)^{1-t_i} \times (\eta_j^f)^{t_i} $$
    *   Adjust for overlapping images. Let $I$ be the set of overlapping images with $M_{i,j} > 0$ and $N_I = |I|$. The final learning rate $\eta_j$ is:
        $$ \eta_j = \frac{\eta_j^c + \sum_{i \in I} M_{i,j} \times \eta_i^c}{N_I + 1} $$
        [S1].

#### Phase 3: Final Optimization
1.  **Global BA:** Once all images are acquired, perform global Bundle Adjustment on the estimated poses [S1].
2.  **Rapid Refinement:** Apply additional optimization iterations to the current 3DGS field to rapidly improve overall rendering quality [S1].

### Formulas Summary
*   **Direct Overlap Weight:** $\omega_{2i} = M_{i,n}$ [S1].
*   **Indirect Overlap Weight:** $\omega_{ki} = \frac{\sum_{j=1}^{N_{k-1}} \omega_{j}^{(k-1)} \times M_{j,ki}^{(k-1)}}{N_{k-1}}$ [S1].
*   **Key Image Iterations:** $T_{im} = \frac{1 - e^{-\omega_i}}{\sum_{j=1}^{N_m} (1 - e^{-\omega_j})} \times T_I$ [S1].
*   **Base Learning Rate:** $\eta_j^c = (\eta_j^0)^{1-t_i} \times (\eta_j^f)^{t_i}$ with $t_i = \min(1, T_j / T_a)$ [S1].
*   **Adjusted Learning Rate:** $\eta_j = \frac{\eta_j^c + \sum_{i \in I} M_{i,j} \times \eta_i^c}{N_I + 1}$ [S1].
*   **Load-Balancing-Loss:** $L_{load} = \text{std}(G_p)$, where $G_p$ is the number of Gaussians associated with pixel $p$ in the current image [S1].
*   **Total Loss:** $L_{total} = \lambda_1 L_1 + \lambda_{ssim} L_{ssim} + \lambda_{load} L_{load}$ [S1].

### Parameters and Typical Values
*   $N_0$: Number of initial images. Typical value: 30 [S1].
*   Initial Training Iterations (Phase 1): Typical value: 2,000 [S1].
*   $T_I$: Total training iterations per new image. Typical value: 200 [S1].
*   $N_m$: Number of top-weighted key images. Typical value: 10 [S1].
*   $T_a$: Iterations for satisfactory quality. Typical value: 200 [S1].
*   $\eta^0$: Initial learning rate. Typical value: $1.6 \times 10^{-4}$ [S1].
*   $\eta^f$: Final learning rate. Typical value: $1.6 \times 10^{-6}$ [S1].
*   $\lambda_1$: L1-Loss weight. Typical value: 0.47 [S1].
*   $\lambda_{ssim}$: SSIM-Loss weight. Typical value: 0.12 [S1].
*   $\lambda_{load}$: Load-Balancing-Loss weight. Typical value: 0.41 [S1].

### Edge Cases and Pitfalls
*   **Overfitting in Phase 1:** Training too long on the initial $N_0$ images leads to poor generalization for subsequent images. The strict iteration limit (e.g., 2,000) is critical [S1].
*   **Threshold Selection:** The distance threshold for identifying "new" points in Phase 2 must be tuned. Too low, and existing points are re-initialized, causing instability. Too high, and new geometry is missed [S1].
*   **Gradient Contention:** Standard per-pixel gradient accumulation causes thread contention. The method requires implementing **Splatting-based Parallelism**, where gradients are accumulated per Gaussian, to maintain performance [S1].
*   **Gaussian Accumulation:** Without the Load-Balancing-Loss, Gaussians may accumulate abnormally in specific regions, increasing memory usage and slowing training. The loss term $L_{load}$ mitigates this [S1].

import math
import numpy as np

def on_the_fly_gs_training(image_sequence, initial_sfm_module, initial_gs_field):
    """
    Main loop for On-the-Fly GS Progressive Training.
    
    Args:
        image_sequence: List of incoming images.
        initial_sfm_module: Object providing pose estimation and sparse point cloud.
        initial_gs_field: Initial 3DGS field (empty or from Phase 1).
        
    Returns:
        final_gs_field: Optimized 3DGS field.
    """
    
    # Hyperparameters
    N0 = 30
    phase1_iters = 2000
    TI = 200
    Nm = 10
    Ta = 200
    eta0 = 1.6e-4
    eta_f = 1.6e-6
    lambda1 = 0.47
    lambda_ssim = 0.12
    lambda_load = 0.41
    
    # State
    gs_field = initial_gs_field
    sparse_cloud = []
    image_poses = {}
    overlap_matrix = {} # M[i, j]
    image_iterations = {} # T_j for each image j
    image_learning_rates = {} # eta_j for each image j
    
    # Phase 1: Initial Training
    print("Phase 1: Initial Training")
    first_n_images = image_sequence[:N0]
    
    # Get initial poses and sparse cloud
    poses, sparse_cloud = initial_sfm_module.estimate_poses_and_cloud(first_n_images)
    image_poses.update({i: poses[i] for i in range(N0)})
    
    # Train initial field
    gs_field = train_3dgs(gs_field, first_n_images, image_poses, sparse_cloud, phase1_iters)
    
    # Initialize state for first N0 images
    for i in range(N0):
        image_iterations[i] = phase1_iters
        image_learning_rates[i] = eta_f # Assume converged or use formula if T_j > Ta
        
    # Build initial overlap matrix for first N0 images
    overlap_matrix = compute_overlap_matrix(first_n_images)
    
    # Phase 2: Progressive Training
    print("Phase 2: Progressive Training")
    for idx, new_image in enumerate(image_sequence[N0:], start=N0):
        print(f"Processing new image {idx}")
        
        # 1. Update SfM
        new_pose, updated_sparse_cloud = initial_sfm_module.update_pose_and_cloud(new_image, sparse_cloud)
        image_poses[idx] = new_pose
        sparse_cloud = updated_sparse_cloud
        
        # 2. Construct Search Tree
        search_tree = build_search_tree(sparse_cloud)
        
        # 3. Identify New Points
        new_points = identify_new_points(new_image, sparse_cloud, search_tree, threshold=0.05) # Threshold not given, assume small value
        
        # 4. Initialize New Gaussians
        new_gaussians = initialize_gaussians_from_points(new_points)
        gs_field.append_gaussians(new_gaussians)
        
        # 5. Calculate Weights
        weights = calculate_hierarchical_weights(idx, overlap_matrix, image_poses, sparse_cloud)
        
        # 6. Optimization Allocation
        # Local Optimization
        top_images = get_top_n_images(weights, Nm)
        local_iters = TI // 2
        total_weight_factor = sum(1 - math.exp(-weights[i]) for i in top_images)
        
        local_training_images = []
        for i in top_images:
            if total_weight_factor == 0:
                tim = 0
            else:
                tim = ((1 - math.exp(-weights[i])) / total_weight_factor) * TI
            local_training_images.append((i, int(tim)))
            
        # Semi-Global Optimization
        other_images = [i for i in image_poses.keys() if i not in top_images]
        semi_global_iters_per_image = (TI - sum(t for _, t in local_training_images)) // max(len(other_images), 1)
        
        training_plan = local_training_images + [(i, semi_global_iters_per_image) for i in other_images]
        
        # 7. Adaptive Learning Rate Update & Training
        for img_idx, num_iters in training_plan:
            if num_iters <= 0:
                continue
                
            # Update iterations count
            image_iterations[img_idx] = image_iterations.get(img_idx, 0) + num_iters
            
            # Calculate Learning Rate
            T_j = image_iterations[img_idx]
            t_i = min(1.0, T_j / Ta)
            eta_c = (eta0 ** (1 - t_i)) * (eta_f ** t_i)
            
            # Adjust for overlaps
            overlapping_imgs = [i for i in image_poses.keys() if i != img_idx and overlap_matrix.get((i, img_idx), 0) > 0]
            N_I = len(overlapping_imgs)
            
            sum_overlap_eta = 0
            for i in overlapping_imgs:
                M_ij = overlap_matrix.get((i, img_idx), 0)
                # Get eta_i^c for overlapping image i
                T_i = image_iterations.get(i, 0)
                t_i_over = min(1.0, T_i / Ta)
                eta_i_c = (eta0 ** (1 - t_i_over)) * (eta_f ** t_i_over)
                sum_overlap_eta += M_ij * eta_i_c
                
            eta_j = (eta_c + sum_overlap_eta) / (N_I + 1)
            image_learning_rates[img_idx] = eta_j
            
            # Train
            gs_field = train_3dgs_step(gs_field, img_idx, image_poses[img_idx], num_iters, eta_j, lambda1, lambda_ssim, lambda_load)
            
        # Update overlap matrix with new image
        for i in image_poses.keys():
            if i != idx:
                overlap_matrix[(i, idx)] = compute_feature_matches(image_sequence[i], new_image)
                overlap_matrix[(idx, i)] = overlap_matrix[(i, idx)]

    # Phase 3: Final Optimization
    print("Phase 3: Final Optimization")
    # Global BA
    image_poses = initial_sfm_module.global_bundle_adjustment(image_poses, sparse_cloud)
    
    # Rapid additional optimization
    gs_field = train_3dgs(gs_field, image_sequence, image_poses, sparse_cloud, iterations=500) # Iterations not specified, assume reasonable amount
    
    return gs_field

def calculate_hierarchical_weights(new_img_idx, overlap_matrix, image_poses, sparse_cloud):
    """
    Calculates hierarchical weights for all registered images relative to new_img_idx.
    """
    weights = {}
    weights[new_img_idx] = 1.0 # Layer 1
    
    # Layer 2: Direct Overlap
    layer_2_images = []
    for i in image_poses.keys():
        if i != new_img_idx:
            M_in = overlap_matrix.get((i, new_img_idx), 0)
            if M_in > 0:
                weights[i] = M_in
                layer_2_images.append(i)
    
    # Layer 3+: Indirect Overlap
    current_layer = layer_2_images
    layer_k = 3
    while current_layer:
        next_layer = []
        for i in image_poses.keys():
            if i not in weights:
                # Check if i overlaps with any image in current_layer
                # M_{j, i}^{(k-1)} where j is in current_layer
                sum_weighted_matches = 0
                count_j = 0
                for j in current_layer:
                    M_ji = overlap_matrix.get((j, i), 0)
                    if M_ji > 0:
                        sum_weighted_matches += weights[j] * M_ji
                        count_j += 1
                
                if count_j > 0:
                    weights[i] = sum_weighted_matches / count_j
                    next_layer.append(i)
        
        current_layer = next_layer
        layer_k += 1
        
    return weights

def train_3dgs_step(gs_field, img_idx, pose, num_iters, eta, lambda1, lambda_ssim, lambda_load):
    """
    Performs a single step of 3DGS training for a specific image with splatting-based parallelism.
    """
    # Render image using current GS field and pose
    rendered_image, depth, alpha = render_gs(gs_field, pose)
    target_image = get_target_image(img_idx)
    
    # Compute Losses
    l1_loss = compute_l1_loss(rendered_image, target_image)
    ssim_loss = compute_ssim_loss(rendered_image, target_image)
    
    # Load Balancing Loss
    # Record Gaussian count Gp per pixel p
    gaussian_counts_per_pixel = get_gaussian_counts_per_pixel(gs_field, pose)
    load_loss = np.std(gaussian_counts_per_pixel)
    
    total_loss = lambda1 * l1_loss + lambda_ssim * ssim_loss + lambda_load * load_loss
    
    # Backpropagation with Splatting-based Parallelism
    # Gradients are accumulated per Gaussian, not per pixel
    gradients = compute_gradients(total_loss, gs_field, rendered_image, target_image, pose)
    
    # Update Gaussians
    gs_field.update_parameters(gradients, eta)
    
    return gs_field

## Operating characteristics

*   **Time Complexity:** The method is designed for near real-time optimization. Each new image triggers $T_I$ iterations (typically 200) on the *entire* current 3DGS field, not just the new region [S1]. This makes the per-image cost constant but dependent on the total number of Gaussians. The use of Splatting-based Parallelism reduces gradient accumulation overhead compared to per-pixel accumulation [S1].
*   **Memory Complexity:** Memory usage grows linearly with the number of images and the density of the scene. The Load-Balancing-Loss helps control the total number of Gaussians by preventing abnormal accumulation [S1].
*   **Measured Performance:** Evaluated on RGB datasets (3DGS, Mip-NeRF 360, On-the-Fly SfM, Replica) using an RTX 4090 GPU [S1]. It outperforms offline training solutions like Adr-Gaussian and Taming-3DGS in speed while maintaining competitive PSNR/SSIM, and is comparable to SLAM-based methods like GS-SLAM and RTG-SLAM [S1].
*   **Strengths:**
    *   Enables incremental, streaming 3DGS reconstruction.
    *   Prevents catastrophic forgetting via hierarchical weighting and semi-global optimization [S1].
    *   Reduces training time via Splatting-based Parallelism [S1].
    *   Controls Gaussian density via Load-Balancing-Loss [S1].
*   **Limitations:**
    *   Requires an external On-the-Fly SfM module for pose estimation and sparse cloud generation [S1].
    *   Performance depends on the quality of the SfM module and the feature matching (overlap matrix) [S1].
    *   The method assumes a sequential input order [S1].

## Background

*   **Origin:** The method was proposed in the paper "Gaussian On-the-Fly Splatting: A Progressive Framework for Robust Near Real-Time 3DGS Optimization" [S1].
*   **History:** It builds upon the original 3D Gaussian Splatting (3DGS) method [3] and addresses its limitation of requiring offline, batch training. It integrates concepts from Taming 3DGS [7] for parallelism and On-the-Fly SfM [1, 22] for streaming pose estimation.
*   **Usage:** It is used in applications requiring real-time or near real-time 3D reconstruction from sequential image streams, such as UAV mapping, VSLAM (Visual Simultaneous Localization and Mapping), and interactive 3D scanning [S1].
