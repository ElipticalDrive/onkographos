# iMAP

Also called: iMAP SLAM

## Overview
iMAP is the first NeRF-based dense online Simultaneous Localization and Mapping (SLAM) model, jointly optimizing camera pose and an implicit scene representation in the form of a Neural Radiance Field (NeRF) [S1, S2]. It uses an iterative two-step approach: tracking (pose optimization with respect to NeRF) and mapping (bundle adjustment for joint optimization of pose and NeRF parameters) [S1]. Unlike siblings using explicit structures or hybrid representations, iMAP relies on a single Multilayer Perceptron (MLP) for the entire map [S2]. The tracking step runs in parallel with the slower mapping step, allowing pose estimation to approach camera framerate [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A stream of RGB images from a moving camera [S1].
*   **Outputs:** A sequence of estimated camera poses and a NeRF model representing the scene's geometry and appearance [S1, S2].

**Data Structures:**
*   **NeRF Model:** A single Multilayer Perceptron (MLP) [S2].
    *   **Architecture:** 4 hidden layers, each with 256 neurons [S2].
    *   **Input:** 3D spatial coordinates $(x, y, z)$ [S2].
    *   **Output:** Volume density $\sigma$ and RGB color $(r, g, b)$ [S1, S2].
    *   **Note:** The model does not take viewing direction as input, meaning it assumes isotropic appearance and does not model reflections or view-dependent effects [S2].
*   **Memory Bank:** A set of selected keyframes used for continuous backend map optimization [S2].

**Parameters:**
*   **Learning Rate:** Not given in the sources.
*   **Batch Size:** Not given in the sources.
*   **Keyframe Selection Criteria:** The system optimizes on a sparse and incrementally selected set of images [S1]. Specific selection thresholds are not given in the sources.

**Algorithm Steps:**
The method operates in an iterative loop for each new frame, consisting of two parallel or sequential stages:

1.  **Initialization:**
    *   Initialize the NeRF MLP with random weights [G].
    *   Set the initial camera pose for the first frame to identity or a known starting position [G].
    *   Initialize an empty memory bank for keyframes [S2].

2.  **Tracking (Pose Optimization):**
    *   For the current incoming RGB image $I_t$:
    *   Sample rays through the current NeRF model using the current estimated camera pose $P_t$ [G].
    *   Render the predicted image $\hat{I}_t$ using volume rendering [G].
    *   Compute the photometric loss between $I_t$ and $\hat{I}_t$ [G].
    *   Optimize the camera pose $P_t$ by minimizing the loss with respect to the pose parameters (rotation and translation) [S1].
    *   This step is designed to be fast, aiming for near-camera-framerate speed [S1].

3.  **Mapping (Bundle Adjustment):**
    *   Select a subset of keyframes from the memory bank and the current frame to form a training batch [S1].
    *   Add the current frame to the memory bank if it meets selection criteria [S1].
    *   Sample rays through the NeRF model using the poses of the selected keyframes [G].
    *   Render the predicted images for these keyframes [G].
    *   Compute the photometric loss for the batch [G].
    *   Perform joint optimization (bundle adjustment) to minimize the loss with respect to both the NeRF MLP weights and the camera poses of the keyframes in the batch [S1].
    *   This step is slower and runs less frequently or in parallel with tracking [S1].

4.  **Loop:**
    *   Repeat for the next frame.

**Pseudocode:**

```python
import numpy as np

class NeRFMLP:
    """Simple MLP representing the iMAP implicit scene representation."""
    def __init__(self, hidden_layers=4, neurons_per_layer=256):
        self.hidden_layers = hidden_layers
        self.neurons_per_layer = neurons_per_layer
        # Weights initialized randomly [G]
        self.weights = [np.random.randn(neurons_per_layer, neurons_per_layer) for _ in range(hidden_layers)]
        self.biases = [np.zeros(neurons_per_layer) for _ in range(hidden_layers)]
        self.out_w = np.random.randn(4, neurons_per_layer) # 3 for RGB, 1 for density
        self.out_b = np.zeros(4)

    def forward(self, points):
        """Query MLP at 3D points. Returns (density, color)."""
        x = points
        for w, b in zip(self.weights, self.biases):
            x = np.maximum(0, x @ w.T + b) # ReLU activation [G]
        out = x @ self.out_w.T + self.out_b
        density = np.exp(out[:, 3]) # Ensure positive density [G]
        color = np.sigmoid(out[:, :3]) # Clamp color to [0, 1] [G]
        return density, color

class iMAP:
    def __init__(self, hidden_layers=4, neurons_per_layer=256, step_size=0.5, max_dist=100.0):
        self.neural_network = NeRFMLP(hidden_layers, neurons_per_layer)
        self.keyframe_bank = []
        self.current_pose = np.eye(4)
        self.initial_pose = np.eye(4)
        self.step_size = step_size
        self.max_dist = max_dist

    def render_volume(self, ray_o, ray_d):
        """
        Fixed-step volume rendering. Accumulates color and transmittance along the ray.
        Returns [R, G, B, Transmittance].
        """
        accumulated_color = np.zeros(3)
        accumulated_transmittance = 1.0
        current_dist = 0.0
        final_result = np.zeros(4)
        
        while current_dist < self.max_dist:
            point = ray_o + ray_d * current_dist
            density, color = self.neural_network.forward(point.reshape(1, -3)).squeeze()
            alpha = 1.0 - np.exp(-density * self.step_size)
            contribution = accumulated_transmittance * alpha * color
            accumulated_color += contribution
            accumulated_transmittance *= (1.0 - alpha)
            current_dist += self.step_size
            final_result = np.concatenate([accumulated_color, [accumulated_transmittance]])
            
        return final_result

    def track(self, current_image):
        """Fast tracking step: Optimize camera pose for the current frame."""
        # Generate rays from camera pose [G]
        # For simplicity, assume a single central ray or batch of rays is generated here
        ray_o = np.array([0.0, 0.0, 0.0])
        ray_d = np.array([0.0, 0.0, -1.0])
        
        # Render predicted image
        predicted_image = self.render_volume(ray_o, ray_d)
        
        # Compute photometric loss [G]
        loss = np.sum((current_image - predicted_image[:3]) ** 2)
        
        # Optimize current_pose to minimize loss [G]
        # Gradient descent on pose parameters
        self.current_pose = self.current_pose # Placeholder for actual optimizer step [G]
        
        return self.current_pose

    def map(self, current_image, current_pose):
        """Slower mapping step: Jointly optimize NeRF weights and keyframe poses."""
        # Add current frame to keyframe bank if selected [S1]
        if len(self.keyframe_bank) == 0 or np.linalg.norm(current_pose[:3, 3]) > 0.1:
            self.keyframe_bank.append({
                'image': current_image,
                'pose': current_pose.copy()
            })
        
        # Select a sparse subset of keyframes for optimization [S1]
        selected_keyframes = self.keyframe_bank[-10:] if len(self.keyframe_bank) > 10 else self.keyframe_bank
        
        # Joint optimization (Bundle Adjustment) [S1]
        for keyframe in selected_keyframes:
            # Sample rays using keyframe pose [G]
            ray_o = np.array([0.0, 0.0, 0.0])
            ray_d = np.array([0.0, 0.0, -1.0])
            
            predicted_image = self.render_volume(ray_o, ray_d)
            loss = np.sum((keyframe['image'] - predicted_image[:3]) ** 2)
            
            # Update NeRF weights and keyframe pose [G]
            self.neural_network.weights = self.neural_network.weights # Placeholder for optimizer step [G]
            keyframe['pose'] = keyframe['pose'] # Placeholder for optimizer step [G]
            
        return self.neural_network

    def process_frame(self, current_image):
        # Step 1: Tracking (Fast)
        self.current_pose = self.track(current_image)
        
        # Step 2: Mapping (Slow, can be parallelized or deferred)
        self.map(current_image, self.current_pose)
        
        return self.current_pose, self.neural_network
```

**Edge Cases and Pitfalls:**
*   **Forgetting:** The single MLP suffers from severe catastrophic forgetting as new data is added [S2]. iMAP addresses this partially by organizing keyframes into a memory bank for continuous backend optimization [S2].
*   **Scene Size:** The representation capability of a single MLP is limited, restricting iMAP to small scenes [S2]. It struggles with large-scale unobserved features like walls and floors [S1].
*   **Real-time Performance:** While tracking is fast, the combined system is far from real-time due to the slow NeRF-based mapping step [S1].
*   **View Dependence:** The model does not consider viewing direction, so it cannot model reflections or view-dependent effects [S2].

## Subtopics

### [NICER-SLAM](12004-nicer-slam.md)
NICER-SLAM is an end-to-end dense Simultaneous Localization and Mapping (SLAM) system that performs simultaneous tracking and mapping using only RGB inputs. It improves upon Nice-SLAM by introducing a hierarchical neural implicit representation based on Signed Distance Functions (SDFs), enabling detailed 3D geometry reconstruction and photorealistic novel view synthesis. Unlike its predecessor, which relied on mixed explicit/implicit representations with pre-allocated voxels, NICER-SLAM leverages monocular geometric cues, optical flow, and a locally adaptive SDF-to-density transformation to guide optimization without depth supervision.

## Operating characteristics
*   **Time Complexity:** Tracking is fast, close to camera framerate [S1]. Mapping is slow, as it involves optimizing a NeRF model [S1].
*   **Memory Complexity:** Depends on the size of the memory bank and the NeRF model. The single MLP is relatively small (4 layers, 256 neurons) [S2], but the memory bank grows with the number of keyframes [S2].
*   **Measured Performance:** iMAP achieves lower pose estimation errors and better scene reconstruction results than its predecessors [S1]. However, it is far from real-time performance [S1].
*   **Scaling:** Limited to small scenes due to the single MLP's representation capability and forgetting problem [S2].
*   **Strengths:** First NeRF-based dense online SLAM; joint optimization of pose and map; fast tracking [S1, S2].
*   **Limitations:** Severe forgetting; limited to small scenes; not real-time; no view-dependent effects [S1, S2].
*   **When to use:** Small-scale indoor scenes where real-time performance is not critical and high-quality dense reconstruction is desired [S2].
*   **When not to use:** Large-scale outdoor scenes, real-time applications, or scenes with strong view-dependent effects [S1, S2].

## Background
iMAP was published in March 2021 [S1]. It is a pioneering work in the field of NeRF-based SLAM, being the first to use a single MLP for implicit map representation in a SLAM context [S2]. It was introduced by Sucar et al. [S1]. The method builds on the concept of Neural Radiance Fields (NeRF) [S1]. It was followed by improvements such as NICE-SLAM (December 2021) and NeRF-SLAM (October 2022) [S1].
