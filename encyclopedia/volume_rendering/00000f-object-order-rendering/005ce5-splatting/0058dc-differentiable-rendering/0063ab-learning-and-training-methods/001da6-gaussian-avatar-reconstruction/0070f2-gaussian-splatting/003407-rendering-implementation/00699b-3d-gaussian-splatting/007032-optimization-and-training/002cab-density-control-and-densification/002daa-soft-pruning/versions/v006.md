# Soft Pruning

Also called: Hessian-aware pruning, L1 loss pruning

## Overview
Soft Pruning is a density control method in 3D Gaussian Splatting that removes Gaussians with low contribution to the training loss to maintain a robust Hessian approximation and reduce model size [S1, S2]. It differs from its sibling [Hard Pruning](5591-hard-pruning.md) by occurring *during* the densification stage (specifically before opacity resets) rather than after, allowing subsequent refinement iterations to recover performance [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** The current set of Gaussians $\mathcal{G}$, the accumulated L1 loss $\mathcal{L}_1$ for each Gaussian, and the current training iteration $t$.
*   **Output:** A reduced set of Gaussians $\mathcal{G}'$ with a specified pruning ratio.

**Data Structures:**
*   Each Gaussian $G_i$ stores its accumulated L1 loss $\mathcal{L}_{1,i}$ over the current training phase (since the last opacity reset or start of training).
*   A global counter or flag tracks the specific iterations designated for pruning.

**Steps:**
1.  **Check Trigger:** At iterations $t \in \{6000, 9000, 12000\}$, immediately before the opacity reset operation [S1].
2.  **Calculate Score:** For each Gaussian $G_i$, compute its contribution score based on the accumulated L1 loss $\mathcal{L}_{1,i}$ [S1]. The method assumes that Gaussians with small L1 loss are less significant for the current Hessian approximation [S1].
3.  **Rank and Select:** Sort all Gaussians by their L1 loss in ascending order. Select the bottom $r$ fraction of Gaussians for removal, where $r$ is the pruning ratio [S1].
4.  **Remove:** Delete the selected Gaussians from the scene representation [S1].
5.  **Proceed:** Continue training. The remaining Gaussians are refined in the subsequent iterations [S1].

**Parameters:**
*   **Pruning Ratio ($r$):** The fraction of Gaussians to remove. A ratio of 80% (removing 80% of Gaussians) preserves visual fidelity in experiments [S1].
*   **Trigger Iterations:** Fixed iterations 6000, 9000, and 12000 [S1].

**Pseudocode:**
```python
def soft_pruning(gaussians, current_iteration, pruning_ratio=0.8):
    """
    Prunes Gaussians with low L1 loss before opacity resets.
    
    Args:
        gaussians: List of Gaussian objects, each having an attribute 'l1_loss'.
        current_iteration: Integer, current training step.
        pruning_ratio: Float, fraction of Gaussians to remove (e.g., 0.8).
        
    Returns:
        List of remaining Gaussian objects.
    """
    # Check if pruning is triggered
    if current_iteration not in [6000, 9000, 12000]:
        return gaussians
    
    # Get number of Gaussians to prune
    num_to_prune = int(len(gaussians) * pruning_ratio)
    
    if num_to_prune == 0:
        return gaussians
        
    # Sort Gaussians by accumulated L1 loss (ascending)
    # Gaussians with lower loss are considered less important for Hessian approximation
    sorted_gaussians = sorted(gaussians, key=lambda g: g.l1_loss)
    
    # Identify Gaussians to keep (those with higher loss)
    # The bottom 'num_to_prune' are removed
    gaussians_to_keep = sorted_gaussians[num_to_prune:]
    
    return gaussians_to_keep
```

**Edge Cases and Pitfalls:**
*   **Opacity Reset Interaction:** Pruning must occur *before* the opacity reset to ensure the Hessian approximation remains robust for the remaining Gaussians [S1].
*   **Loss Accumulation:** The L1 loss must be accumulated correctly since the last reset. If loss is not accumulated properly, the ranking will be incorrect [S1].
*   **High Pruning Ratio:** While 80% pruning is effective, higher ratios may degrade quality. The sources do not specify a maximum safe ratio beyond the experimental 80% [S1].

## Subtopics

### [Hard Pruning](5591-hard-pruning.md)
Occurs after the densification stage, relying on refinement iterations to recover performance.

## Operating characteristics
*   **Time Complexity:** Sorting Gaussians by loss takes $O(N \log N)$, where $N$ is the number of Gaussians. Selection is $O(N)$.
*   **Memory Complexity:** $O(N)$ to store the list and sort it.
*   **Performance:** Reduces the number of Gaussians by approximately 90% when combined with Hard Pruning, increasing rendering and training speed [S2].
*   **Strengths:** Maintains visual fidelity even with high pruning ratios (80%) [S1]. Integrates seamlessly into the standard 3D-GS training pipeline [S2].
*   **Limitations:** Requires specific iteration checkpoints (6000, 9000, 12000) [S1]. Effectiveness depends on the L1 loss converging quickly [S2].

## Background
Soft Pruning was introduced in the "Speedy-Splat" paper [S1, S2]. It was developed to address the need for faster rendering and training speeds by reducing the number of primitives without significant quality loss. The method leverages the observation that L1 loss becomes small after iteration 6000, except after opacity resets [S1].
