# Sensitivity-Aware Vector Clustering

Also called: Niedemayr et al. compression, Niedermayr, Sensitivity-Aware Scene Compression, Sensitivity-Aware Vector Clustering for 3DGS Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering Spherical Harmonic (SH) coefficients and Gaussian shape parameters (scale and rotation) into compact codebooks using sensitivity-aware vector quantization [S1, S2]. It distinguishes itself from standard post-training quantization by deriving a sensitivity measure for each scene parameter to guide the clustering process, prioritizing the preservation of parameters that significantly affect image quality [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of optimized 3D Gaussians $\{G_i\}_{i=1}^N$ with SH coefficients for color and parameters for shape (rotation and scale) [S1].
*   **Output:** Two codebooks (one for color/SH, one for shape) and a set of indices mapping each Gaussian to entries in these codebooks, along with uncompressed position, opacity, and other attributes [S1].

**Data Structures:**
*   **Codebook Entry (Shape):** 4 scalar values for quaternion (rotation) plus 3 scalar values for scaling [S1].
*   **Codebook Entry (Color):** SH coefficients vector [S1].
*   **Indices:** 32-bit unsigned integers stored alongside Gaussian data [S1].

**Parameters:**
*   $K$: Codebook size. Typical value: 4096 [S1].
*   $\lambda_d$: Decay factor for moving average in batched clustering. Typical value: 0.8 [S1].
*   Batch size (color features): $2^{18}$ [S1].
*   Batch size (Gaussian parameters): $2^{20}$ [S1].
*   $\beta_c$: Sensitivity threshold for SH coefficients. Gaussians with sensitivity $> \beta_c$ are excluded from clustering and added directly to the codebook. Typical value: $6 \times 10^{-7}$ [S1].
*   $\beta_g$: Sensitivity threshold for Gaussian shape parameters. Typical value: $3 \times 10^{-6}$ [S1] (Note: [S1] mentions $\beta_g$ in text but does not provide a formula for shape sensitivity distinct from the general parameter sensitivity definition; [S2] does not specify $\beta_g$).
*   Update steps: 800 for Gaussians, 100 for SH coefficients [S1].
*   Fine-tuning steps: 5000 optimization steps of quantization-aware fine-tuning [S1].

**Method Steps:**

1.  **Sensitivity Calculation:**
    Calculate the sensitivity $S(p)$ for each scene parameter $p$ by computing its contribution to the training images [S1, S2]. The sensitivity is defined as the sum of the gradients of the total image energy $E$ with respect to the parameter $p$, normalized by the number of pixels [S1, S2]:
    $$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p_i}}{\sum_{i=1}^{N} P_i} $$
    where $N$ is the number of training images, $P_i$ is the number of pixels in image $i$, and $E_i$ is the total image energy (sum of RGB components) for image $i$ [S1, S2]. The sensitivity of a vector $x$ is defined as the maximum sensitivity over its components:
    $$ S(x) = \max_d S(x_d) $$
    where $S(x_d)$ is the sensitivity of component $d$ [S1]. This is computed via a single backward pass over each training image [S1].

2.  **Codebook Initialization:**
    Initialize codebooks randomly with a uniform distribution within the minimum and maximum values of each parameter [S1].

3.  **Sensitivity-Aware Clustering (k-Means):**
    *   **Distance Metric:** Use a weighted distance between a vector $x$ and a centroid $c_k$:
        $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
        where $S(x)$ is the sensitivity of vector $x$ [S1].
    *   **Assignment:** Assign each vector to the centroid with the minimum distance [S1].
    *   **Update:** Update centroids using the weighted average:
        $$ c_k = \frac{1}{\sum_{x_i \in A(k)} S(x_i)} \sum_{x_i \in A(k)} S(x_i) x_i $$
        where $A(k)$ is the set of vectors assigned to centroid $c_k$ [S1].
    *   **Batched Strategy:** For performance, use a batched clustering strategy. Pick a random subset of vectors, compute the update step, and update centroids using a moving average with decay factor $\lambda_d$ [S1].
    *   **High-Sensitivity Handling:** Identify SH vectors with sensitivity higher than $\beta_c$ and Gaussian shape vectors with sensitivity higher than $\beta_g$. These vectors are not clustered but are added directly to the codebook after the clustering process [S1].
    *   **Normalization:** For shape parameters, re-parameterize the scaling vector $s = \eta \hat{s}$, where $\eta = \|s\|_2$ and $\hat{s}$ is the normalized scaling vector. The normalized covariance matrix is used for clustering. Due to floating-point errors, non-unit scaling vectors may arise; re-normalize each codebook vector after each update step by dividing it through the trace of the covariance metric [S1].
    *   **Decomposition:** After clustering, decompose each codebook entry (covariance matrix) into rotation (quaternion) and scale parameters using eigenvalue decomposition for quantization-aware training [S1].

4.  **Quantization-Aware Fine-Tuning:**
    Fine-tune parameters on the training set using quantization-aware training with Min-Max Quantization to regain information lost during clustering [S1, S2].
    *   **Forward Pass:** Simulate quantization considering a certain number of bits and the moving average of each parameter's min/max values [S2].
    *   **Backward Pass:** Ignore simulated quantization and calculate the gradient for the parameter without quantization [S2].

5.  **Compression:**
    Compress the set of Gaussians and codebooks using DEFLATE [S1, S2]. Order Gaussians by Z-order (Morton order) to leverage spatial coherence before compression [S1, S2].

import numpy as np

def calculate_sensitivity(optimization_data, training_images):
    """
    Calculate sensitivity S(p) for each parameter p.
    optimization_data: dict containing gradients dE/dp for each training image.
    training_images: list of images with pixel counts P_i.
    Returns: sensitivity map for each parameter.
    """
    # Sum gradients over all training images
    sum_gradients = np.zeros_like(optimization_data['gradients'])
    sum_pixels = 0
    
    for img_data in training_images:
        sum_gradients += img_data['gradient']
        sum_pixels += img_data['pixel_count']
        
    sensitivity = sum_gradients / sum_pixels
    return sensitivity

def sensitivity_aware_kmeans(vectors, sensitivities, k, lambda_d, batch_size, max_steps):
    """
    Perform sensitivity-aware k-Means clustering.
    vectors: array of shape (N, D)
    sensitivities: array of shape (N,)
    k: number of centroids
    lambda_d: decay factor
    batch_size: number of vectors per update step
    max_steps: number of update steps
    Returns: centroids (K, D)
    """
    # Initialize centroids randomly within min/max of vectors
    centroids = np.random.uniform(vectors.min(axis=0), vectors.max(axis=0), size=(k, vectors.shape[1]))
    
    for step in range(max_steps):
        # Pick random subset
        indices = np.random.choice(vectors.shape[0], size=batch_size, replace=False)
        batch_vectors = vectors[indices]
        batch_sensitivities = sensitivities[indices]
        
        # Compute distances: D(x, ck) = S(x) * ||x - ck||^2
        # Shape: (batch_size, k)
        distances = np.zeros((batch_vectors.shape[0], k))
        for j in range(k):
            diff = batch_vectors - centroids[j]
            distances[:, j] = batch_sensitivities * np.sum(diff**2, axis=1)
            
        # Assign to nearest centroid
        assignments = np.argmin(distances, axis=1)
        
        # Update centroids using moving average
        new_centroids = centroids.copy()
        for j in range(k):
            mask = assignments == j
            if np.sum(mask) > 0:
                assigned_vectors = batch_vectors[mask]
                assigned_sens = batch_sensitivities[mask]
                weighted_sum = np.sum(assigned_vectors * assigned_sens[:, np.newaxis], axis=0)
                weight_total = np.sum(assigned_sens)
                new_centroid = weighted_sum / weight_total
                
                # Moving average update
                new_centroids[j] = (1 - lambda_d) * centroids[j] + lambda_d * new_centroid
                
        centroids = new_centroids
        
    return centroids

def decompose_covariance_matrix(covariance_matrix):
    """
    Decompose covariance matrix into quaternion and scale.
    covariance_matrix: (3, 3) symmetric positive definite matrix
    Returns: quaternion (4,), scale (3,)
    """
    # Eigenvalue decomposition
    eigenvalues, eigenvectors = np.linalg.eigh(covariance_matrix)
    
    # Ensure positive eigenvalues for scaling
    eigenvalues = np.maximum(eigenvalues, 1e-6)
    
    # Scale is sqrt of eigenvalues
    scale = np.sqrt(eigenvalues)
    
    # Rotation matrix from eigenvectors
    rotation_matrix = eigenvectors
    
    # Convert rotation matrix to quaternion
    quaternion = rotation_matrix_to_quaternion(rotation_matrix)
    
    return quaternion, scale

def rotation_matrix_to_quaternion(R):
    """
    Convert 3x3 rotation matrix to quaternion.
    R: (3, 3)
    Returns: quaternion (4,) [w, x, y, z]
    """
    trace = np.trace(R)
    if trace > 0:
        S = np.sqrt(trace + 1.0) * 2
        w = 0.25 * S
        x = (R[2, 1] - R[1, 2]) / S
        y = (R[0, 2] - R[2, 0]) / S
        z = (R[1, 0] - R[0, 1]) / S
    elif (R[0, 0] > R[1, 1]) and (R[0, 0] > R[2, 2]):
        S = np.sqrt(1.0 + R[0, 0] - R[1, 1] - R[2, 2]) * 2
        w = (R[2, 1] - R[1, 2]) / S
        x = 0.25 * S
        y = (R[0, 1] + R[1, 0]) / S
        z = (R[0, 2] + R[2, 0]) / S
    elif R[1, 1] > R[2, 2]:
        S = np.sqrt(1.0 + R[1, 1] - R[0, 0] - R[2, 2]) * 2
        w = (R[0, 2] - R[2, 0]) / S
        x = (R[0, 1] + R[1, 0]) / S
        y = 0.25 * S
        z = (R[1, 2] + R[2, 1]) / S
    else:
        S = np.sqrt(1.0 + R[2, 2] - R[0, 0] - R[1, 1]) * 2
        w = (R[1, 0] - R[0, 1]) / S
        x = (R[0, 2] + R[2, 0]) / S
        y = (R[1, 2] + R[2, 1]) / S
        z = 0.25 * S
        
    return np.array([w, x, y, z])

## Operating characteristics
*   **Time Complexity:** Clustering is iterative. Batched k-Means reduces per-step cost. Fine-tuning adds 5000 optimization steps [S1].
*   **Memory Complexity:** Codebook size $K=4096$ for both SH and shape [S1]. Indices are 32-bit unsigned integers [S1].
*   **Measured Performance:** Achieves compression rate of up to 31× on real-world scenes with minimal visual quality degradation [S1]. Enables rendering at up to 4× higher framerates than uncompressed via optimized GPU compute pipeline [S1].
*   **Strengths:** Reduces storage significantly while maintaining visual quality. Efficient rendering on lightweight GPUs [S1].
*   **Limitations:** Requires sensitivity calculation via backward pass, which can be computationally expensive during the initial compression phase [S1].
*   **When to use:** When storage or bandwidth is constrained, and real-time rendering on low-power devices is required [S1].
*   **When not to use:** When maximum possible visual fidelity is required without any compression artifacts, or when computational resources for the initial compression phase are limited [S1].

## Background
Sensitivity-Aware Vector Clustering was proposed by Niedemayr et al. in 2024 [S1]. It builds on previous work on volumetric radiance field compression and deep network weight quantization [S1]. The method is designed to make 3D Gaussian Splatting suitable for applications like network streaming and rendering on low-power devices by significantly reducing memory consumption and improving rendering efficiency [S1].
