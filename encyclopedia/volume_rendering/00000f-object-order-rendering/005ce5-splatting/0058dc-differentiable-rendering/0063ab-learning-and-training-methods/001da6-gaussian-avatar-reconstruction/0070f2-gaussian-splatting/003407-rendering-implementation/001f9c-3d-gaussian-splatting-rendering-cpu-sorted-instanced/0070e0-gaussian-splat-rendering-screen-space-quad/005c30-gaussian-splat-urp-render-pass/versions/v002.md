# Gaussian Splat URP Render Pass

Also called: GSRenderPass, GaussianSplatURPFeature

## Overview
A Unity Universal Render Pipeline (URP) `ScriptableRendererFeature` that renders Gaussian splats into a temporary render target and composites it onto the camera color target [S1, unofficial].

## How it works
### Inputs and Outputs
- **Input**: Camera data (`CameraData`), XR state, and a `GaussianSplatSystem` instance containing splat data and sorting logic [S1, unofficial].
- **Output**: The composited Gaussian splats appear in the final camera color target [S1, unofficial].

### Data Structures
The feature maintains a dictionary of render passes keyed by eye ID to support XR multipass rendering [S1, unofficial].
```python
# Internal state
m_PassPerEye = {}  # Dictionary mapping eye ID to GSRenderPass instances
m_Cmb = None       # Command buffer for the current frame
m_RenderTarget = None  # Temporary target for splat accumulation
matComposite = None  # Material for blitting splats to screen
```
The temporary render target `m_RenderTarget` is configured with:
- Format: `R16G16B16A16_SFloat` [S1, unofficial].
- Dimensions: `Tex2D` [S1, unofficial].
- Depth buffer: None (`depthBufferBits=0`) [S1, unofficial].
- MSAA: Disabled (`msaaSamples=1`) [S1, unofficial].
- Name: `"_GaussianSplatRT"` [S1, unofficial].

### Numbered Steps
1. **Initialization**: In `OnCameraSetup`, allocate `m_RenderTarget` if needed using the descriptor above [S1, unofficial]. Set it as a global texture [S1, unofficial]. Configure the render pass to render to `m_RenderTarget` and read from the camera depth buffer [S1, unofficial]. Clear the target with `Color(0,0,0,0)` [S1, unofficial].
2. **Pass Creation**: In `GetOrCreatePass`, determine the `eyeId` [S1, unofficial]. If `eyeId` is not in `m_PassPerEye`, create a new `GSRenderPass` with the specified `renderPassEvent` and a named `CommandBuffer` (`'RenderGaussianSplats_{eyeId}'`) [S1, unofficial]. Store and return it [S1, unofficial].
3. **Event Hooking**: In `OnCameraPreCull`, if the camera is a Preview, return [S1, unofficial]. Otherwise, call `GetOrCreatePass` for `GetEyeId(cameraData)` [S1, unofficial]. In `AddRenderPasses`, if Preview, return [S1, unofficial]. Get `eyeId`, get/create the pass, set `pass.m_Renderer = renderer`, and enqueue the pass [S1, unofficial].
4. **Execution**: In the pass's `Execute` method, if `m_Cmb` is null, return [S1, unofficial]. Get the system and camera [S1, unofficial]. Call `system.GatherSplatsForCamera(cam)` [S1, unofficial]. If it returns false, return [S1, unofficial]. Clear `m_Cmb` [S1, unofficial]. Call `system.SortAndRenderSplats(cam, m_Cmb)` to populate the command buffer and retrieve `matComposite` [S1, unofficial]. If `matComposite` is null, return [S1, unofficial]. Begin profiling sample `s_ProfCompose` [S1, unofficial]. Blit `m_RenderTarget` to `cameraColorTargetHandle` using `matComposite` pass 0 [S1, unofficial]. End profiling sample [S1, unofficial]. Execute `m_Cmb` [S1, unofficial].
5. **Eye ID Logic**: `GetEyeId` returns `cameraData.xr.multipassId` if XR is enabled, otherwise `cameraData.camera.GetInstanceID()` [S1, unofficial].

### Pseudocode
```python
class GaussianSplatURPFeature:
    def __init__(self):
        self.m_PassPerEye = {}
        self.m_RenderTarget = None
        self.matComposite = None
        self.renderPassEvent = "BeforeRenderingTransparents"

    def OnCameraSetup(self, cameraData, renderTargetDescriptor):
        desc = {
            'width': renderTargetDescriptor['width'],
            'height': renderTargetDescriptor['height'],
            'graphicsFormat': 'R16G16B16A16_SFloat',
            'dimension': 'Tex2D',
            'volumeDepth': 1,
            'vrUsage': None
        }
        if self.m_RenderTarget is None or not self.m_RenderTarget.is_created():
            self.m_RenderTarget = create_texture(desc)
            self.m_RenderTarget.name = '_GaussianSplatRT'
            set_global_shader_texture('_GaussianSplatRT', self.m_RenderTarget)
        configure_render_target(self.m_RenderTarget, cameraData.depth_buffer)
        clear_render_target(self.m_RenderTarget, color=(0, 0, 0, 0))

    def GetEyeId(self, cameraData):
        if cameraData.xr.enabled:
            return cameraData.xr.multipassId
        return cameraData.camera.get_instance_id()

    def GetOrCreatePass(self, eyeId):
        if eyeId not in self.m_PassPerEye:
            new_pass = GSRenderPass()
            new_pass.renderPassEvent = self.renderPassEvent
            new_pass.commandBuffer = CommandBuffer()
            new_pass.commandBuffer.name = f'RenderGaussianSplats_{eyeId}'
            self.m_PassPerEye[eyeId] = new_pass
        return self.m_PassPerEye[eyeId]

    def OnCameraPreCull(self, cameraData):
        if cameraData.cameraType == 'Preview':
            return
        self.GetOrCreatePass(self.GetEyeId(cameraData))

    def AddRenderPasses(self, renderer, cameraData):
        if cameraData.cameraType == 'Preview':
            return
        eye_id = self.GetEyeId(cameraData)
        pass_instance = self.GetOrCreatePass(eye_id)
        pass_instance.renderer = renderer
        renderer.enqueue_pass(pass_instance)

    class GSRenderPass:
        def __init__(self):
            self.m_Cmb = CommandBuffer()
            self.matComposite = None

        def Execute(self, context, refData):
            if self.m_Cmb is None:
                return
            system = get_gaussian_splat_system()
            camera = refData.camera
            if not system.gather_splats_for_camera(camera):
                return
            self.m_Cmb.clear()
            self.matComposite = system.sort_and_render_splats(camera, self.m_Cmb)
            if self.matComposite is None:
                return
            profiler.begin_sample('s_ProfCompose')
            blit_texture(self.m_RenderTarget, refData.cameraColorTargetHandle, self.matComposite, pass_index=0)
            profiler.end_sample()
            context.execute_command_buffer(self.m_Cmb)
```

### Parameters
- `renderPassEvent`: `RenderPassEvent.BeforeRenderingTransparents` [S1, unofficial].

### Edge Cases and Pitfalls
- **Preview Cameras**: The feature explicitly skips execution for `CameraType.Preview` to avoid overhead in the editor [S1, unofficial].
- **XR Multipass**: The use of `multipassId` ensures separate render passes for each eye in VR, preventing cross-eye contamination [S1, unofficial].
