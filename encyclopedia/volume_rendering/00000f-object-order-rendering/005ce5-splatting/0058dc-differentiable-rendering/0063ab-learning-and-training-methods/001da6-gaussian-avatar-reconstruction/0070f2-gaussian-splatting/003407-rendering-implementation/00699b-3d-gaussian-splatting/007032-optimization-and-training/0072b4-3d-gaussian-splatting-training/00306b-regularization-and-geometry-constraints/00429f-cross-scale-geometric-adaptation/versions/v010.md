# Cross-scale geometric adaptation

Also called: Lgeo, Reprojection error supervision, Reprojection-based cross-scale geometric adaptation

## Overview
Cross-scale geometric adaptation is a self-adaptive regularization technique that uses reprojection errors across multiple voxel scales to guide geometry learning without requiring complex scheduling or explicit depth ground truth [S1]. It selects render depths with minimal reprojection error across different scales as pseudo labels, ensuring geometric integrity and significantly reducing floaters compared to training without this adaptation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Training views $i$ and $j$ (where $j$ is a novel or different training view), camera intrinsics $K_i, K_j$, camera poses $(R_i, t_i), (R_j, t_j)$, RGB maps $C_i, C_j$, and a set of voxel scales $l \in \{0, \dots, L\}$ (typically low, mid, high resolution) [S1].
*   **Outputs:** A geometric adaptation loss $L_{geo}$ and pseudo-ground truth depth $D'(r_{train})$ for each training ray $r_{train}$ [S1].

**Data Structures:**
*   **Voxels:** Multi-scale voxels capturing varying scene frequencies. Low-resolution voxels represent coarse geometry, while high-resolution voxels capture details [S1].
*   **Depth Maps:** Rendered depth $D_{il}(p_i)$ at scale $l$ for pixel $p_i$ in frame $i$ [S1].

**Numbered Steps:**
1.  **Early Training Strategy:** Use low-resolution voxels as pseudo-ground truth to guide coarse geometry learning in early training iterations. Medium- and high-resolution voxels gradually refine details as training advances [S1].
2.  **3D Point Reconstruction (Frame $i$):** For a 2D pixel coordinate $p_i$ in frame $i$, compute its homogeneous augmentation $\tilde{p}_i$. Calculate the 3D point in camera coordinates of frame $i$ at scale $l$:
    $$x_{li} = D_{il}(p_i) K_i^{-1} \tilde{p}_i$$
    where $D_{il}(p_i)$ is the depth at scale $l$ from volume rendering and $K_i$ are camera intrinsics [S1].
3.  **World Coordinate Transformation:** Transform the 3D point to world coordinates using frame $i$'s rotation $R_i$ and translation $t_i$:
    $$x_l = R_i x_{li} + t_i$$
    Alternatively, the point can be determined directly from the ray defined by starting point $o_i(p_i)$ and direction $v_i(p_i)$:
    $$x_l = o_i(p_i) + D_{il}(p_i)v_i(p_i)$$
    [S1].
4.  **Reprojection to Frame $j$:** Transform the world coordinate point $x_l$ to the camera coordinates of frame $j$ using frame $j$'s rotation $R_j$ and translation $t_j$:
    $$x_{li \to j} = R_j^T (x_l - t_j)$$
    [S1].
5.  **2D Projection:** Project the 3D point back to the 2D pixel coordinate system of frame $j$:
    $$\tilde{p}_{li \to j} = \pi(K_j x_{li \to j})$$
    where $\pi([x, y, z]^T) = [x/z, y/z]^T$ [S1].
6.  **Reprojection Error Calculation:** Compute the reprojection error for scale $l$ as the difference between the original RGB pixel and the warped pixel from frame $j$:
    $$e_l(p_i) = C_i(p_i) - C_j(\tilde{p}_{li \to j})$$
    where $C_i$ and $C_j$ are the RGB maps of frames $i$ and $j$ [S1].
7.  **Pseudo-GT Depth Selection:** For each training ray, select the pseudo-ground truth depth $D'(r_{train})$ corresponding to the scale $l$ with the minimum reprojection error:
    $$D'(r_{train}) = \arg \min_l (e_l(r_{train}))$$
    [S1].
8.  **Loss Computation:** Compute the geometric adaptation loss $L_{geo}$ as the Mean Squared Error (MSE) between the rendered depth $D_l(r_{train})$ and the selected pseudo-GT depth $D'(r_{train})$ across all training rays $r_{train}$:
    $$L_{geo}(r_{train}) = \sum_{r_{train} \in R_{train}} \| \hat{D}_l(r_{train}) - D'(r_{train}) \|^2$$
    [S1].

**Pseudocode:**
```python
def compute_cross_scale_geometric_adaptation_loss(
    frames, # List of frame objects containing K, R, t, C (RGB map)
    voxels, # Multi-scale voxel structure providing depth D_l(p)
    training_rays # List of rays or pixel coordinates p_i for training views
):
    L_geo_total = 0.0
    
    for frame_i in frames:
        for frame_j in frames:
            if frame_i == frame_j:
                continue
            
            # Iterate over training rays/pixels in frame i
            for p_i in training_rays:
                min_error = infinity
                best_depth = 0
                
                # Iterate over voxel scales l
                for l in range(num_scales):
                    # Step 2: Get depth at scale l
                    D_il = voxels.get_depth(p_i, scale=l)
                    
                    # Step 2: Reproject to 3D camera coords of frame i
                    # Homogeneous coordinate
                    p_i_hom = [p_i.x, p_i.y, 1.0]
                    inv_K_i = inverse(frame_i.K)
                    x_li = D_il * (inv_K_i @ p_i_hom) # Simplified vector-matrix mult
                    
                    # Step 3: Transform to world coords
                    # x_l = R_i * x_li + t_i
                    x_l = frame_i.R @ x_li + frame_i.t
                    
                    # Step 4: Transform to camera coords of frame j
                    # x_li_j = R_j^T * (x_l - t_j)
                    x_li_j = frame_j.R.T @ (x_l - frame_j.t)
                    
                    # Step 5: Project to 2D pixel coords of frame j
                    # p_j = K_j * x_li_j
                    p_j_hom = frame_j.K @ x_li_j
                    # Normalize
                    p_j_x = p_j_hom[0] / p_j_hom[2]
                    p_j_y = p_j_hom[1] / p_j_hom[2]
                    
                    # Step 6: Compute reprojection error
                    # C_i(p_i) - C_j(p_j)
                    # Assuming C returns RGB vector
                    color_i = frame_i.C.sample(p_i)
                    color_j = frame_j.C.sample([p_j_x, p_j_y])
                    error = color_i - color_j
                    e_l = norm(error)
                    
                    # Step 7: Select scale with min error
                    if e_l < min_error:
                        min_error = e_l
                        best_depth = D_il
                
                # Step 8: Compute loss against best depth
                # L_geo = sum( (D_l - D')^2 )
                # Note: In implementation, D_l is the rendered depth at the selected scale l
                # The source implies D_l in the loss formula corresponds to the scale l
                # that produced the min error.
                D_l = voxels.get_depth(p_i, scale=best_scale_index) # best_scale_index tracked in loop
                L_geo_total += (D_l - best_depth)**2
                
    return L_geo_total
```

**Parameters:**
*   **Voxel Scales:** Typically low, mid, and high resolution [S1].
*   **Loss Weight:** Not given in the sources.
*   **Frame Pairs:** Any pair of training views $(i, j)$ can be used [S1].

**Edge Cases and Pitfalls:**
*   **Camera Poses:** The method relies on accurate camera poses. In scenarios with significant viewpoint changes or sparse training views, generalization may be challenging [S1].
*   **Local Minima:** Omitting novel view rays risks local minima, causing incorrect geometry [S1].
*   **Scale Mismatches:** Using only depth prior $L_d$ can suffer from higher error later in training due to scale mismatches, whereas $L_{geo}$ refines depth progressively [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Significantly reduces floaters and improves convergence quality across scales compared to training without geometric adaptation [S1]. Achieves lower final depth error than depth prior $L_d$ alone [S1].
*   **Scaling:** Low-frequency components from low-resolution voxels guide coarse geometry early in training, with mid- and high-frequency components refining details later [S1].
*   **Strengths:** Self-adaptive, no complex scheduling required, robust to geometric noise compared to feature-warping methods like GeCoNeRF [S1].
*   **Limitations:** Requires accurate camera poses; performance may decline without novel view regularizations [S1].

## Background
Cross-scale geometric adaptation was proposed in **FrugalNeRF** (2025) by the authors of [S1]. It is designed for extreme few-shot novel view synthesis to accelerate and regularize training without external priors. The method uses weight-sharing voxels across scales and adapts geometry via reprojection errors [S1].
