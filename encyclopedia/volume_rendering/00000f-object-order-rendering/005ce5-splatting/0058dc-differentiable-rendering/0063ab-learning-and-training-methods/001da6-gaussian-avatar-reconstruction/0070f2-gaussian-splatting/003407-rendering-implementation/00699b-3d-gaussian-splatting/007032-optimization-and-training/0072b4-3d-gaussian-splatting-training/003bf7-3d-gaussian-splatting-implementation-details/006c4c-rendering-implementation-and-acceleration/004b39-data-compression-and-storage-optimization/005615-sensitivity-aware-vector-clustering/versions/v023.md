# Sensitivity-Aware Vector Clustering

Also called: Niedemayr et al. compression, Niedermayr, Sensitivity-Aware Scene Compression, Sensitivity-Aware Vector Clustering for 3DGS Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering spherical harmonic (SH) coefficients and Gaussian shape parameters (scale and rotation) into compact codebooks using sensitivity-aware vector quantization [S1, S2]. It distinguishes itself from post-training quantization methods by deriving a sensitivity measure for each scene parameter to guide the clustering process, prioritizing the preservation of parameters that significantly affect image quality [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of optimized 3D Gaussians $\{G_i\}_{i=1}^N$ with positions, opacities, scales, rotations, and SH coefficients for color, along with a set of training images and their camera parameters [S1].
*   **Output:** Two codebooks (one for SH coefficients, one for shape parameters) and a compressed representation of the scene where each Gaussian is defined by indices into these codebooks, alongside uncompressed position, opacity, and other attributes [S1].

**Data Structures:**
*   **Codebook Entry (Shape):** 4 scalar values for a quaternion (rotation) plus 3 scalar values for scaling [S1].
*   **Codebook Entry (Color):** SH coefficients (e.g., 48 coefficients for degree 3) [S1].
*   **Indices:** 32-bit unsigned integers storing the index into the respective codebook for each Gaussian [S1].

**Sensitivity Calculation:**
The sensitivity $S(p)$ of a parameter $p$ is calculated based on its contribution to the training images [S1, S2]. The total image energy $E$ is the sum of RGB components over all pixels in all training images [S1]. The sensitivity is defined as:

$$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p_i}}{\sum_{i=1}^{N} P_i} $$

where $N$ is the number of training images, $P_i$ is the number of pixels in image $i$, and $E_i$ is the energy contribution of image $i$ [S1, S2]. The gradient $\frac{\partial E_i}{\partial p_i}$ is computed via a single backward pass over each training image [S1]. For a vector $x$ with components $x_d$, the sensitivity is the maximum over its component sensitivities:

$$ S(x) = \max_d S(x_d) $$

**Clustering Algorithm:**
The method uses two separate codebooks: one for SH coefficients (color) and one for Gaussian shape features (scale and rotation) [S1].

1.  **Initialization:** Codebooks are initialized randomly with a uniform distribution within the minimum and maximum values of each parameter [S1]. The codebook size $K$ is typically 4096 [S1].
2.  **Sensitivity Thresholding:** SH vectors (and shape vectors, if a separate threshold $\beta_g$ is used) with sensitivity higher than a threshold $\beta_c$ are identified [S1]. These high-sensitivity vectors are not clustered but are added directly to the codebook after the clustering process to preserve critical details [S1]. Typical value for $\beta_c$ is $6 \cdot 10^{-7}$ [S1].
3.  **Weighted Distance:** For the remaining vectors, the distance between a vector $x$ and a centroid $c_k$ is weighted by the sensitivity of $x$:
    $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
4.  **Assignment:** Each vector is assigned to the centroid with the minimum weighted distance [S1].
5.  **Centroid Update:** The centroid $c_k$ is updated using the weighted average of the assigned vectors $A(k)$:
    $$ c_k = \frac{1}{\sum_{x_i \in A(k)} S(x_i)} \sum_{x_i \in A(k)} S(x_i) x_i $$
6.  **Batched Clustering:** To handle large datasets, a batched strategy is used [S1]. In each update step, a random subset of vectors is picked. Centroids are updated using a moving average with a decay factor $\lambda_d$ (typical value 0.8) [S1].
    *   Batch size for color features: $2^{18}$ [S1].
    *   Batch size for Gaussian parameters: $2^{20}$ [S1] [S2].
7.  **Normalization:** Clustering normalized covariance matrices can lead to non-unit scaling vectors due to floating-point errors. Each codebook vector is re-normalized after each update step by dividing it through the trace of the covariance metric [S1].
8.  **Decomposition:** After clustering, each codebook entry for shape is decomposed into rotation (quaternion) and scale parameters using eigenvalue decomposition, as direct optimization of the matrix is not possible [S1].

**Quantization-Aware Training:**
To recover information lost during clustering, parameters are fine-tuned on the training set using quantization-aware training [S1, S2].
*   **Forward Pass:** Quantization is simulated considering a certain number of bits and the moving average of each parameter's min/max values (Min-Max Quantization) [S2].
*   **Backward Pass:** The simulated quantization is ignored, and the gradient is calculated for the parameter without quantization [S2].
*   **Optimization:** Typically 5000 optimization steps are performed [S1]. The D-SSIM loss weight $\lambda$ is typically 0.2 [S2].

**Compression and Encoding:**
1.  **Linearization:** Gaussians are ordered by their positions along a Z-order curve (Morton order) to exploit spatial coherence [S1, S2].
2.  **Entropy Encoding:** The set of Gaussians and codebooks are compressed using DEFLATE (LZ77 + Huffman coding) [S1, S2].

import numpy as np

def compute_sensitivity(ground_truth_images, rendered_images, parameters):
    """
    Compute sensitivity S(p) for each parameter p.
    E is the sum of RGB components.
    """
    # Calculate total image energy E for each training image
    # E_i = sum(RGB components of image i)
    energies = [np.sum(img) for img in ground_truth_images]
    
    # Compute gradients of energy with respect to parameters
    # This requires a backward pass through the differentiable renderer
    gradients = compute_gradients(ground_truth_images, rendered_images, parameters)
    
    # Sum of gradients and normalization factors
    sum_gradients = np.sum(gradients, axis=0) # Sum over images
    sum_pixels = np.sum([img.size for img in ground_truth_images]) # Sum of pixels P_i
    
    # Sensitivity S(p)
    sensitivity = sum_gradients / sum_pixels
    return sensitivity

def sensitivity_aware_kmeans(vectors, sensitivities, k, decay_factor=0.8, batch_size=2**18):
    """
    Perform sensitivity-aware k-Means clustering.
    """
    # Initialize centroids randomly within min/max of vectors
    centroids = np.random.uniform(vectors.min(), vectors.max(), (k, vectors.shape[1]))
    
    num_updates = 800 # For Gaussians, 100 for SH [S1]
    
    for step in range(num_updates):
        # Pick random subset (batch)
        indices = np.random.choice(len(vectors), size=batch_size, replace=False)
        batch_vectors = vectors[indices]
        batch_sensitivities = sensitivities[indices]
        
        # Compute weighted distances
        # D(x, ck) = S(x) * ||x - ck||^2
        distances = np.zeros((len(batch_vectors), k))
        for j in range(k):
            diff = batch_vectors - centroids[j]
            distances[:, j] = batch_sensitivities * np.sum(diff**2, axis=1)
        
        # Assign to nearest centroid
        assignments = np.argmin(distances, axis=1)
        
        # Update centroids using moving average
        new_centroids = np.zeros_like(centroids)
        for j in range(k):
            cluster_vectors = batch_vectors[assignments == j]
            cluster_sensitivities = batch_sensitivities[assignments == j]
            
            if len(cluster_vectors) > 0:
                # Weighted average
                total_weight = np.sum(cluster_sensitivities)
                weighted_sum = np.sum(cluster_vectors * cluster_sensitivities[:, np.newaxis], axis=0)
                new_centroid = weighted_sum / total_weight
                
                # Moving average update
                centroids[j] = decay_factor * centroids[j] + (1 - decay_factor) * new_centroid
            else:
                # Keep old centroid if no vectors assigned
                new_centroids[j] = centroids[j]
        
        centroids = new_centroids
        
        # Re-normalize shape codebook entries if necessary
        # Divide by trace of covariance metric to counteract floating point errors
        centroids = re_normalize_shape_centroids(centroids)
        
    return centroids

def compress_scene(gaussians, sh_codebook, shape_codebook, beta_c=6e-7):
    """
    Compress the 3D Gaussian scene.
    """
    # 1. Calculate sensitivities for SH coefficients and shape parameters
    sh_sensitivities = compute_sensitivity_for_sh(gaussians.sh_coeffs)
    shape_sensitivities = compute_sensitivity_for_shape(gaussians.shape_params)
    
    # 2. Identify high-sensitivity vectors
    high_sens_sh_indices = np.where(sh_sensitivities > beta_c)[0]
    high_sens_shape_indices = np.where(shape_sensitivities > beta_c)[0] # beta_g typically 3e-6 [S1]
    
    # 3. Cluster remaining vectors
    remaining_sh = np.delete(gaussians.sh_coeffs, high_sens_sh_indices, axis=0)
    remaining_shape = np.delete(gaussians.shape_params, high_sens_shape_indices, axis=0)
    
    sh_centroids = sensitivity_aware_kmeans(remaining_sh, sh_sensitivities[~(sh_sensitivities > beta_c)], k=4096)
    shape_centroids = sensitivity_aware_kmeans(remaining_shape, shape_sensitivities[~(shape_sensitivities > beta_c)], k=4096)
    
    # 4. Add high-sensitivity vectors to codebooks
    final_sh_codebook = np.vstack([sh_centroids, gaussians.sh_coeffs[high_sens_sh_indices]])
    final_shape_codebook = np.vstack([shape_centroids, gaussians.shape_params[high_sens_shape_indices]])
    
    # 5. Decompose shape codebook entries into quaternion and scale

## Operating characteristics
*   **Compression Ratio:** Achieves up to 31× compression on real-world scenes with minimal visual degradation [S1].
*   **Rendering Speed:** Enables real-time rendering on lightweight GPUs, up to 4× higher framerates than optimized GPU compute pipelines for uncompressed scenes [S1].
*   **Memory:** Significantly reduces VRAM usage by replacing high-dimensional SH coefficients and shape matrices with small integer indices and compact codebooks [S1].
*   **Strengths:** Preserves visual quality better than uniform quantization by focusing on sensitive parameters; efficient hardware rasterization support [S1].
*   **Limitations:** Requires an initial training phase to compute sensitivities and perform quantization-aware fine-tuning; batched clustering may introduce approximation errors if batch sizes are too small [S1].

## Background
Sensitivity-Aware Vector Clustering was proposed by Niedemayr et al. in 2024 [S1]. It builds on the observation that 3D Gaussian splatting representations contain significant redundancy in SH coefficients and shape parameters [S1]. The method draws inspiration from volumetric radiance field compression and deep network weight quantization [S1]. It is designed to make 3D Gaussian representations suitable for network streaming and rendering on low-power devices [S1].
