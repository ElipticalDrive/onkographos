# Inpainting for Displaced Objects

Also called: GSP Inpainting, LaMa Inpainting

## Overview
Inpainting for Displaced Objects remedies black smudges and dirty textures caused by displaced objects exposing previously unseen areas, which standard 3D Gaussian Splatting (3DGS) cannot recover from input images [S1]. Unlike vanilla 3DGS, which leaves empty spots and blended artifacts from irrelevant kernels when objects move, this method uses generative AI inpainting to fill these gaps [S1]. It is primarily used in dynamic scenarios involving rigid body displacement, such as falling objects or moving furniture, where the camera captures the background behind the object only after it moves [S1].

## How it works
**Inputs:**
*   A set of 3D Gaussian kernels representing the scene, including a subset identified as the "displaced object" (e.g., via segmentation or semantic mask).
*   A rendered image of the scene with the displaced object removed (or masked out).
*   A generative inpainting model (specifically LaMa [S1] or Stable Diffusion [S2]).

**Outputs:**
*   Updated Gaussian kernels for the displaced object with corrected diffuse colors, opacity, and specular properties.
*   A hole-free rendered image.

**Data Structures:**
*   **Gaussian Kernel:** Contains position, covariance (or scale/rotation), diffuse color ($c_{diff}$), specular color ($c_{spec}$), and opacity ($\alpha$).
*   **Rendered Image:** A 2D array of pixel colors and an alpha mask indicating valid/invalid regions.
*   **Ray History:** A mapping from pixel coordinates to the first Gaussian kernel index encountered during rendering.

**Steps:**
1.  **Remove Displaced Kernels:** Identify all Gaussian kernels belonging to the object that may be displaced. Remove these kernels from the scene representation [S1].
2.  **Render Base Scene:** Render the remaining scene (background and static objects) to generate a base image with holes where the object was [S1].
3.  **Generative Inpainting:** Use a generative inpainting model (LaMa [S1]) to fill the holes in the rendered image, generating plausible texture for the missing object [S1].
4.  **Ray Casting and Color Sampling:** For each pixel in the inpainted region:
    *   Emit a ray from the camera through the pixel [S1].
    *   Identify the first Gaussian kernel encountered by this ray in the *original* scene (before removal) or a reference geometry [S1].
    *   Record the new color value from the inpainted image for this pixel [S1].
5.  **Color Aggregation:** For each Gaussian kernel identified in Step 4:
    *   Collect all recorded colors from pixels whose rays hit this kernel [S1].
    *   Compute the average of these colors to determine the new diffuse color ($c_{diff}$) for the kernel [S1].
6.  **Attribute Update:**
    *   Set the opacity ($\alpha$) of the displaced object's kernels to 1 [S1].
    *   Set the specular color ($c_{spec}$) to 0 to prevent highlights, ensuring the object blends with the inpainted texture [S1].
7.  **Re-insertion:** Re-insert the updated kernels into the scene representation [S1].

**Pseudocode:**
```python
def inpaint_displaced_objects(gaussians, camera, inpaint_model):
    # 1. Identify and remove displaced object kernels
    displaced_indices = identify_displaced_kernels(gaussians)
    original_kernels = [g for i, g in enumerate(gaussians) if i in displaced_indices]
    remaining_gaussians = [g for i, g in enumerate(gaussians) if i not in displaced_indices]
    
    # 2. Render the scene without the displaced object
    # This produces an image with holes and an alpha mask
    base_image, alpha_mask, ray_hits = render_scene(remaining_gaussians, camera)
    
    # 3. Inpaint the holes using generative AI
    # LaMa is used in GSP [S1]
    inpainted_image = inpaint_model(base_image, alpha_mask)
    
    # 4. Map inpainted colors back to kernels
    # We need to know which kernel corresponds to which pixel in the original scene
    # ray_hits maps (x, y) -> kernel_index
    
    kernel_colors = {idx: [] for idx in displaced_indices}
    
    for y in range(image_height):
        for x in range(image_width):
            if alpha_mask[y, x] == 0: # Hole region
                kernel_idx = ray_hits[y, x]
                if kernel_idx is not None and kernel_idx in displaced_indices:
                    new_color = inpainted_image[y, x]
                    kernel_colors[kernel_idx].append(new_color)
    
    # 5. Update kernel attributes
    for idx in displaced_indices:
        if kernel_colors[idx]:
            avg_color = mean(kernel_colors[idx], axis=0)
            gaussians[idx].diffuse_color = avg_color
            gaussians[idx].opacity = 1.0
            gaussians[idx].specular_color = 0.0
        else:
            # Fallback if no rays hit (e.g., completely occluded in all views)
            # Not specified in sources, but necessary for robustness [G]
            gaussians[idx].opacity = 0.0
            
    return gaussians
```

**Edge Cases and Pitfalls:**
*   **Precision:** The accuracy of the color assignment depends on the precision of the ray-kernel intersection test. If the ray does not hit a specific kernel due to discretization, the color may be lost [S1].
*   **Boundaries:** The method assumes the displaced object is fully segmented. Incomplete segmentation leads to artifacts where the object is partially removed [S1].
*   **Degenerate Input:** If the object is never visible from any angle (e.g., always occluded), no rays will hit it, and no color information can be recovered [S1].

## Subtopics

### 3D Inpainting Pipeline
A sequential pipeline designed for sparse novel view synthesis that maintains 3D consistency by leveraging the constraint that Gaussians do not hallucinate details [S2]. Unlike the single-step LaMa approach, this method uses Stable Diffusion for inpainting, estimates monocular depth on the inpainted image, and uses Poisson blending with depth gradients to fill rendered depth in masked regions [S2]. It then projects Gaussians using the inpainted depth and image, repeating the process sequentially for several novel views until the scene is 3D consistent and renderable from any view without holes [S2]. This is chosen when 3D consistency across multiple novel views is critical, such as in sparse view synthesis [S2].

## Operating characteristics
*   **Time Complexity:** Dominated by the generative inpainting step (LaMa or Stable Diffusion), which is significantly slower than standard differentiable rasterization [S1, S2].
*   **Memory Complexity:** Requires storing the inpainted images and intermediate depth maps, but does not increase the Gaussian kernel count [S1, S2].
*   **Strengths:** Effectively removes black smudges and dirty textures that standard optimization cannot fix [S1]. Maintains 3D consistency when used sequentially [S2].
*   **Limitations:** Relies on external generative models, which may introduce hallucinated details if not constrained [S2]. Does not recover true geometric information, only appearance [S1].
*   **When to Use:** When displaced objects expose unseen background areas that result in visual artifacts in standard 3DGS [S1].
*   **When Not to Use:** When real-time rendering is required, as inpainting is computationally expensive [S1].

## Background
This method was introduced in "Gaussian Splashing: Unified Particles for Versatile Motion Synthesis and Rendering" (2025) to handle dynamic scenes with rigid body displacement [S1]. It addresses a specific failure mode of 3DGS where moving objects leave behind artifacts because the training data does not contain the background behind the object at all times [S1]. A variant using Stable Diffusion and depth consistency was later proposed in "CoherentGS: Sparse Novel View Synthesis with Coherent 3D Gaussians" (2025) for sparse view synthesis [S2].
