# Fine-tuning

Also called: 3DGS Fine-tuning, Fine-tuning Strategy, Gaussian Splatting Fine-tuning

## Overview
Fine-tuning in the context of 3D Gaussian Splatting (3DGS) refers to the phase of optimization where a pre-initialized or pre-trained set of Gaussian primitives is refined to match specific target data or to adapt to new domains. It solves the problem of initializing a high-quality radiance field from limited or noisy data by leveraging prior knowledge (e.g., from ImageNet or other datasets) or by iteratively correcting reconstruction errors. It sets itself apart from initial training by typically starting with a dense or structured set of Gaussians (generated via feed-forward networks or grid-based volumes) and focusing on attribute optimization, densification, and pruning to achieve photorealism or domain-specific accuracy [S2][S6, unofficial].

## How it works
The fine-tuning process generally follows a protocol of initialization, iterative optimization with densification/pruning, and potentially multi-stage or multi-modal refinement.

### Inputs and Outputs
*   **Inputs:** A set of initial 3D Gaussian primitives $\mathcal{G}_{init}$ (with means $\mu$, covariances $\Sigma$, opacities $\alpha$, and spherical harmonic coefficients $\mathbf{c}$), a set of training images/views, and often a pre-trained neural network backbone or grid-based volume [S2, S4][S6, unofficial].
*   **Outputs:** A refined set of Gaussians $\mathcal{G}_{final}$ optimized for the target scene or visual mode [S2][S6, unofficial].

### Data Structures
The Gaussian set $\mathcal{G}$ is stored as a contiguous array or list of primitives. Each primitive $g_k$ contains:
*   $\mu_k \in \mathbb{R}^3$: Mean position.
*   $\Sigma_k \in \mathbb{R}^{3 \times 3}$: Covariance matrix, parameterized by scale $s_k$ and rotation $q_k$ [Parent].
*   $\alpha_k \in [0, 1]$: Opacity.
*   $\mathbf{c}_k$: Spherical Harmonic coefficients [Parent].
*   Additional attributes may include deformation fields or specific mode identifiers if using multi-modal fine-tuning [S6, unofficial].

### Steps
1.  **Initialization:**
    *   Generate initial Gaussians. This can be done via a direct feed-forward process predicting geometry and color attributes [S2], or by populating a grid-based volume [S4].
    *   If using a pre-trained backbone, load the weights [S2][S6, unofficial].
2.  **Iterative Optimization:**
    *   Render images from the current Gaussian set using differentiable rasterization [S2].
    *   Compute loss between rendered images and ground truth. Common losses include L1 color loss, SSIM, and depth loss [S3, S2].
    *   Backpropagate to update Gaussian attributes ($\mu, \Sigma, \alpha, \mathbf{c}$) [S2].
3.  **Densification and Pruning (Adaptive Density Control):**
    *   Periodically evaluate metrics (e.g., gradient magnitude, opacity, rendering error) to determine if densification is needed [Parent].
    *   **Splitting/Cloning:** If a region has high error or gradient, split or clone Gaussians [Parent, S4].
    *   **Pruning:** Remove Gaussians with low opacity or high redundancy [Parent, S2].
    *   Specific strategies may include rendering-guided densification for unobserved regions or high-error areas [S3].
4.  **Multi-Modal/Mode-Specific Refinement (Optional):**
    *   If the scene has multiple visual modes (e.g., different physical properties in volume rendering), generate multiple radiance fields using transfer functions $TF_h$ [S6, unofficial].
    *   Render supervision data for each mode and fine-tune the corresponding Gaussian set $G_h$ [S6, unofficial].

### Formulas
*   **Rendering Loss (L1 + SSIM):**
    $$ L_{mapping} = \lambda_{color} \| \hat{C} - C \|_1 + \lambda_{depth} \| \hat{D} - D \|_1 + \lambda_{SSIM} SSIM(\hat{C}, C) $$
    where $\hat{C}, \hat{D}$ are rendered color and depth, and $C, D$ are ground truth [S3].
*   **Opacity Rendering:**
    $$ O(x, y) = \sum_{i \in N} \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $N$ are 2D Gaussians overlapping the pixel $(x,y)$ [S3, S4].
*   **Depth Error Normalization:**
    $$ E_{depth}(x, y) = \frac{\| \hat{D}(x, y) - D(x, y) \|}{D(x, y)} $$
    Used to compensate for scale variations when determining densification thresholds [S3].
*   **Transfer Function Application:**
    $$ RF_h = TF_h(F) $$
    Where $RF_h$ is the radiance field for mode $h$ and $F$ is the physical field [S6, unofficial].

### Parameters
*   **Learning Rate:** Typically $1 \times 10^{-3}$ for Adam optimizer [S2, S5].
*   **Fine-tuning Iterations:** Can range from 10,000 steps for naive fine-tuning [S5] to standard 3DGS training durations (e.g., 30,000 iterations) [S2].
*   **Thresholds:**
    *   Opacity threshold $\tau_{opa}$ for hole detection [S3].
    *   Depth error threshold $\tau_{depth}$ [S3].
    *   Color error threshold $\tau_{color}$ [S3].
*   **Transfer Functions:** 5 transfer functions are typically selected for each volume in multi-modal fine-tuning [S6, unofficial].

### Edge Cases and Pitfalls
*   **Forgetting:** In continuous mapping or incremental fine-tuning, Gaussians may overfit to the latest frame, causing quality drops for previous frames [S3]. Regularization is needed [S3].
*   **Overfitting:** Naive fine-tuning of all weights can lead to overfitting if not regularized [S5].
*   **Sparse Initialization:** If initial SfM points are sparse, densification may fail to populate distant or low-texture regions without supplementary point addition [S4, S12323-supplementary-point-addition-for-sparse-point-clouds.md].

### Pseudocode
```python
def fine_tune_gaussians(initial_gaussians, training_data, config):
    """
    Fine-tune 3D Gaussian Splatting primitives.
    
    Args:
        initial_gaussians: List of Gaussian primitives with initial attributes.
        training_data: List of (image, depth, pose) tuples.
        config: Configuration dictionary with learning_rate, iterations, thresholds, etc.
    
    Returns:
        refined_gaussians: Optimized list of Gaussian primitives.
    """
    gaussians = initial_gaussians
    optimizer = Adam(gaussians.parameters(), lr=config.learning_rate)
    
    for iteration in range(config.iterations):
        # 1. Sample a random training view
        image, depth, pose = sample_random_view(training_data)
        
        # 2. Render current Gaussians
        rendered_color, rendered_depth, rendered_opacity = render(gaussians, pose)
        
        # 3. Compute Loss
        color_loss = L1(rendered_color, image)
        depth_loss = L1(rendered_depth, depth)
        ssim_loss = SSIM(rendered_color, image)
        total_loss = config.lambda_color * color_loss + \
                     config.lambda_depth * depth_loss + \
                     config.lambda_ssim * ssim_loss
        
        # 4. Backpropagate
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
        # 5. Densification and Pruning (every N iterations)
        if iteration % config.refine_every == 0:
            # Evaluate gradients and opacities
            gradients = compute_gradient_magnitude(gaussians, training_data)
            opacities = get_opacities(gaussians)
            
            # Identify regions for densification
            split_candidates = []
            prune_candidates = []
            
            for i, g in enumerate(gaussians):
                # Check for high gradient (needs split/clone)
                if gradients[i] > config.gradient_threshold:
                    split_candidates.append(i)
                
                # Check for low opacity (needs prune)
                if opacities[i] < config.opacity_threshold:
                    prune_candidates.append(i)
            
            # Perform Splitting/Cloning
            new_gaussians = []
            for i, g in enumerate(gaussians):
                if i in split_candidates:
                    # Split into children
                    children = split_gaussian(g)
                    new_gaussians.extend(children)
                else:
                    new_gaussians.append(g)
            
            # Perform Pruning
            gaussians = [g for i, g in enumerate(new_gaussians) if i not in prune_candidates]
            
            # Optional: Rendering-guided densification for holes/high error
            if config.use_rendering_guided_densification:
                gaussians = densify_by_rendering_error(gaussians, training_data, config)

    return gaussians

def densify_by_rendering_error(gaussians, training_data, config):
    """
    Add new Gaussians to regions with high rendering error or low opacity.
    """
    densified_gaussians = list(gaussians)
    
    for image, depth, pose in training_data:
        rendered_color, rendered_depth, rendered_opacity = render(densified_gaussians, pose)
        
        # Check for holes (low opacity)
        hole_mask = rendered_opacity < config.threshold_opa
        
        # Check for high color error
        color_error = abs(rendered_color - image)
        high_color_error_mask = color_error > config.threshold_color
        
        # Check for high depth error (normalized)
        depth_error = abs(rendered_depth - depth) / depth
        high_depth_error_mask = depth_error > config.threshold_depth
        
        # Union of all error regions
        error_mask = hole_mask | high_color_error_mask | high_depth_error_mask
        
        # Add new Gaussians in error regions
        for x, y in indices_where(error_mask):
            # Project depth directly for new Gaussians
            z = depth[y, x]
            new_g = create_gaussian_from_pixel(x, y, z, pose)
            densified_gaussians.append(new_g)
            
    return densified_gaussians
```

## Subtopics

### [Exponentially Ascending Gradient Threshold](9684-exponentially-ascending-gradient-threshold.md)
A densification control mechanism that uses an exponentially ascending gradient threshold to regulate splitting and cloning during training. It allows aggressive densification when few Gaussians exist and restricts it as the scene becomes dense, solving the trade-off between early-stage convergence speed and late-stage overfitting.

### [SplatFormer Training Objective & Refinement](11745-splatformer-training-objective-refinement.md)
A learning-based, feed-forward 3D neural module that refines initial 3DGS representations to enable robust novel view synthesis from out-of-distribution (OOD) camera angles. It addresses the bias of standard 3DGS optimization by applying a point transformer network that predicts attribute residuals, ensuring geometric consistency.

### [MCMC-based 3DGS / SGLD for 3DGS](11917-mcmc-based-3dgs-sgld-for-3dgs.md)
Reforms 3DGS by treating Gaussians as MCMC samples drawn from an underlying probability distribution. It converts updates into Stochastic Gradient Langevin Dynamics (SGLD) by introducing noise, removing the need for manual densification heuristics like cloning and splitting.

### [Deblurring 3D Gaussian Splatting](12318-deblurring-3d-gaussian-splatting.md)
A real-time deblurring framework that reconstructs sharp 3D scenes from blurry input images by manipulating covariance matrices and means using a small MLP during training. It uses differentiable rasterization for real-time inference and handles defocus and camera motion blur.

### [Supplementary Point Addition for Sparse Point Clouds](12323-supplementary-point-addition-for-sparse-point-clouds.md)
A densification technique that injects synthetic points into empty or sparse regions after a fixed number of training iterations, compensating for poor SfM extraction in defocused areas. It ensures distant objects are represented by initial Gaussians, preventing them from being ignored during adaptive density control.

### [Augmented Radiance Field](13218-augmented-radiance-field.md)
A post-enhancement framework that improves 3DGS by adding Gaussian kernels with view-dependent opacity to explicitly model specular components. It solves the problem of standard SH not decoupling diffuse and specular radiance, avoiding memory and stability issues of high-order SH.

### [Frequency Regularization for Densification](13484-frequency-regularization-for-densification.md)
Addresses over-reconstruction by minimizing the discrepancy between the frequency spectrum of the rendered image and the ground truth in Fourier space. This increases pixel gradients within over-reconstruction regions, enabling a coarse-to-fine densification process guided by progressive frequency annealing.

### [Error-Guided Redistribution](14037-error-guided-redistribution.md)
A family of strategies that dynamically adjusts the spatial distribution of Gaussian primitives based on rendering errors or gradient magnitudes. It targets regions with persistent coarse-scale errors or "hard" gradients, either by reallocating a fixed budget of Gaussians or controlling density via online sparse statistics.

### CoherentGS
A regularized optimization method for sparse novel view synthesis that introduces structural coherency by constraining Gaussian movement in 2D image space [S1]. It solves instability and "needle-like" artifacts in standard 3DGS when trained on extremely sparse input views by enforcing single-view and multi-view consistency [S1].

### [Pruning and Sparsity Control](14431-pruning-and-sparsity-control.md)
Methods that reduce the number of active 3D Gaussians to lower memory consumption and storage requirements while maintaining rendering quality. They actively eliminate redundant primitives throughout optimization using explicit geometric or volume-based criteria rather than gradient magnitude alone [14019-visibility-based-pruning-for-3d-gaussian-splatting.md].

### [Rendering-Free Pruning via Hessian Importance](14447-rendering-free-pruning-via-hessian-importance.md)
A post-processing framework that identifies and removes unimportant Gaussian primitives without performing forward rendering passes. It quantifies primitive importance using an analytically approximated Hessian field, achieving a 3,000× reduction in computational complexity and a ~20× speedup in device latency.

### [GoF-based Dynamic 3DGS Video Construction](14770-gof-based-dynamic-3dgs-video-construction.md)
Constructs dynamic 3DGS video by temporally segmenting input sequences into Groups of Frames (GoFs) and independently training Gaussian deformation fields within each segment. It solves motion drift and geometric inconsistencies by limiting motion degree within short segments and decoupling static and dynamic components.

### [Two-stage Optimization](14857-two-stage-optimization.md)
A training protocol for inverse rendering with 3D Gaussians that decouples geometric and appearance optimization from material and lighting decomposition. It prevents entanglement of distinct physical properties during early training by introducing normal gradient-based densification and PBR-specific loss terms.

### [TIP-Editor](14859-tip-editor.md)
A method for editing existing 3DGS scenes using intuitive text and image prompts. It solves the problem of achieving accurate local editing while maintaining multi-view consistency by employing a stepwise 2D personalization strategy with LoRA-based reference image alignment and localization loss.

### StylizedGS
A controllable 3D stylization method that performs color matching with a reference style image while utilizing a 3DGS filter to remove artifacts [S1]. It explicitly optimizes for nearest neighbor feature matching and depth preservation, ensuring the stylized output retains geometric structure [S1].

### [SGD (Street View Synthesis with Gaussian Splatting and Diffusion Prior)](15522-sgd-street-view-synthesis-with-gaussian-splatting-and-diffus.md)
A novel view synthesis method for street scenes that enhances 3DGS by fine-tuning a Stable Diffusion model on driving data and using it to regularize 3DGS training at unseen viewpoints. It addresses the sparse-view reconstruction problem by using adjacent frames and LiDAR depth for direct fine-tuning on driving data.

### [Backbone Fine-tuning](16908-backbone-fine-tuning.md)
Adapts the weights of a pre-trained 3D generator (backbone) alongside the decoder to generate Gaussian Splatting attributes. It addresses the fact that splats have scale and rotation that influence adjacent regions, unlike NeRF's local color/density, by modifying the generative prior itself.

### [Equivalent Distribution Reorganization](16968-equivalent-distribution-reorganization.md)
A post-training reorganization method that addresses "parameterization degeneration" by rebuilding centers, covariances, and the visibility structure by resampling from the empirical distribution. It preserves the original scene support asymptotically while reducing parameter coupling and opacity barriers, delivering up to 0.5 dB higher training PSNR and a 12.8% rendering speedup.

### [S2Gaussian](17154-s2gaussian.md)
A two-stage framework for reconstructing high-quality 3D scenes from sparse and low-resolution input views. It handles this hybrid scenario by initializing high-resolution Gaussians from a densified low-resolution representation and refining them using super-resolved supervision, introducing a "Gaussian Shuffle Split" densification strategy.

### [On-the-Fly GS Progressive Training](17502-on-the-fly-gs-progressive-training.md)
A method for optimizing 3DGS fields in a continuous, incremental manner as new images are acquired, enabling near real-time reconstruction without retraining from scratch. It solves catastrophic forgetting and overfitting in sequential SLAM-based 3DGS by structuring training into three phases: initial sparse training, progressive fly-in updates with hierarchical weighting, and final global optimization.

### [FreeFix](17532-freefix.md)
A fine-tuning-free method to improve the rendering quality of extrapolated views in 3DGS by leveraging pretrained 2D image diffusion models (IDMs). It solves the problem of artifacts in rendered RGBs and inconsistency across frames by using a 2D–3D interleaved refinement strategy with per-pixel confidence masks derived from Fisher information.

#### Gaussian Densification via Rendering Loss
A strategy to add new 3D Gaussians to the map by identifying unobserved regions (holes) and regions with high rendering error, using opacity, color, and depth thresholds [S3]. It densifies regions where rendered opacity is below a threshold, or where normalized depth error or color error exceeds predefined thresholds [S3].

#### Point Densification
A process in original 3DGS that adaptively controls the number of Gaussian points through clone and split operations to convert a sparse set into a denser one [S4]. In HO-Gaussian, point densification is performed at regular intervals to provide new positions to the Gaussian pipeline, populating problematic regions [S4].

#### Naive Fine-tuning
A naive generator fine-tuning method identical to model rewriting except freely optimizing all weights of the generator [S5]. It is typically optimized over 10,000 steps with a learning rate of $10^{-3}$ [S5].

#### Image-space Gaussian Fine-tuning
A fine-tuning process to account for different visual modes in the volume by generating multiple radiance fields using different transfer functions and optimizing the Gaussian set against rendered images [S6, unofficial]. It involves selecting a series of transfer functions, generating radiance fields, rendering supervision data, and backpropagating to update the Gaussian set [S6, unofficial].

## Operating characteristics
*   **Time Complexity:** Fine-tuning typically requires fewer iterations than initial training if a good initialization is provided, but densification and pruning operations add overhead [S2, S5].
*   **Memory Complexity:** Depends on the number of Gaussians. Fine-tuning with pruning can reduce memory consumption compared to dense initializations [S2].
*   **Performance:** Can achieve photorealism on par with or surpassing other methods when leveraging powerful pretrained weights [S2].
*   **Strengths:** Accelerates network training and enables faster convergence compared to other test-time optimization methods [S2]. Allows adaptation to specific domains or visual modes [S6, unofficial].
*   **Limitations:** Can suffer from forgetting in continuous mapping [S3]. Naive fine-tuning can overfit if not regularized [S5].

## Background
Fine-tuning in deep learning generally refers to adapting a pre-trained model to a specific task by updating some or all of its weights [S1]. In the context of 3D Gaussian Splatting, it has been adapted to refine initial Gaussian representations for better reconstruction quality, domain adaptation, or handling specific challenges like blurriness or sparse views [S2, S3, S5][S6, unofficial]. The concept of using transfer learning with fixed lower layers and fine-tuned upper layers originates from CNNs [S1].
