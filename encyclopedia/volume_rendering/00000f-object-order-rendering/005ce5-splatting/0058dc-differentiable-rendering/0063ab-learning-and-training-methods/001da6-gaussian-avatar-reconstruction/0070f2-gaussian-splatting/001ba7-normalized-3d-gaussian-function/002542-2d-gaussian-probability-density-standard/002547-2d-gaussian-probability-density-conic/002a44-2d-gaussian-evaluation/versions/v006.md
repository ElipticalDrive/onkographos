# 2D Gaussian Evaluation
Also called: 2D Gaussian PDF exponent

## Overview
Computes the exponent term of the 2D Gaussian probability density function at given 2D points, used for rasterization or shading [S1, unofficial]. It differs from its parent [2D Gaussian Probability Density (Conic)](3475-2d-gaussian-probability-density-conic.md) by explicitly calculating the quadratic form $-\frac{1}{2} \mathbf{x}_m^T C_{2D}^{-1} \mathbf{x}_m$ from the covariance matrix, whereas the conic variant typically operates on pre-computed conic components (inverse covariance elements) directly in screen space to avoid matrix inversion during rendering [S1, unofficial].

## How it works
**Inputs:**
- `points_2D`: Tensor of shape $(N, 2)$ containing the 2D query coordinates for $N$ points.
- `means_2D`: Tensor of shape $(N, 2)$ containing the 2D mean positions of the Gaussians.
- `cov_2D`: Tensor of shape $(N, 2, 2)$ containing the 2D covariance matrices for each Gaussian.

**Outputs:**
- `power`: Tensor of shape $(N,)$ containing the exponent values $P$.

**Data Structures:**
- Standard dense tensors. No bit-packing or sparse structures are specified for this specific evaluation step [S1, unofficial].

**Steps:**
1. Compute the difference vector between query points and 2D means:
   $$ \mathbf{x}_m = \text{points\_2D} - \text{means\_2D} $$
   Where $\mathbf{x}_m$ has shape $(N, 2)$.

2. Reshape the difference vector for batched matrix multiplication:
   - Create $\mathbf{x}_m^{\text{row}}$ by unsqueezing $\mathbf{x}_m$ at the last dimension: shape $(N, 2, 1)$.
   - Create $\mathbf{x}_m^{\text{col}}$ by unsqueezing $\mathbf{x}_m$ at the second-to-last dimension: shape $(N, 1, 2)$.

**Formula:**
$$ P = -\frac{1}{2} (\mathbf{x}_m^T C_{2D}^{-1} \mathbf{x}_m) $$
Where:
- $\mathbf{x}_m$ is the $2 \times 1$ difference vector (or $1 \times 2$ row vector depending on orientation).
- $C_{2D}^{-1}$ is the $2 \times 2$ inverse covariance matrix.
- $P$ is the exponent value.

**Pseudocode:**
```python
import torch

def evaluate_2d_gaussian(points_2d: torch.Tensor, means_2d: torch.Tensor, cov_2d: torch.Tensor) -> torch.Tensor:
    """
    Computes the exponent term of the 2D Gaussian PDF.
    
    Args:
        points_2d: (N, 2) tensor of query points.
        means_2d: (N, 2) tensor of Gaussian means.
        cov_2d: (N, 2, 2) tensor of covariance matrices.
        
    Returns:
        power: (N,) tensor of exponent values.
    """
    # Step 1: Difference vector
    xm = points_2d - means_2d  # (N, 2)
    
    # Step 2: Reshape for batched matrix multiplication
    # xm_row: (N, 1, 2)
    xm_row = xm.unsqueeze(-2)
    # xm_col: (N, 2, 1)
    xm_col = xm.unsqueeze(-1)
    
    # Step 3: Inverse covariance
    # cov_2d_inv: (N, 2, 2)
    cov_2d_inv = torch.inverse(cov_2d)
    
    # Step 4: Quadratic form
    # (N, 1, 2) @ (N, 2, 2) -> (N, 1, 2)
    # (N, 1, 2) @ (N, 2, 1) -> (N, 1, 1)
    quadratic = torch.matmul(xm_row, torch.matmul(cov_2d_inv, xm_col))
    
    # Squeeze to (N,) and scale
    power = -0.5 * quadratic.squeeze(-1).squeeze(-1)
    
    return power
```

**Parameters:**
- No explicit tuning parameters; depends on the input covariance and means.

**Edge Cases and Pitfalls:**
- **Singular Covariance:** If `cov_2d` is singular or near-singular, `torch.inverse` may produce NaNs or Inf. A small regularization term (e.g., $\epsilon I$) is often added to the diagonal before inversion in practice, though not explicitly stated in the source [G].
- **Precision:** Batched matrix multiplication can be memory-intensive for large $N$.

## Subtopics

### [Generalized Gaussian Particles](9164-generalized-gaussian-particles.md)
Generalized Gaussian Particles replace the standard quadratic exponent in the 2D Gaussian probability density function with a power-law exponent controlled by a degree parameter $n$. This modification allows for steeper and narrower density fall-off, enabling denser particle packing and finer control over the trade-off between rendering quality and computational speed compared to standard Gaussians.

### [2D Gaussian Evaluation (Rotated/Anisotropic)](12462-2d-gaussian-evaluation-rotated-anisotropic.md)
This method computes the alpha component of a rotated, anisotropic 2D Gaussian function at specific 2D texture coordinates, primarily for generating brush-stroke textures in stroke-based splatting. It differs from standard isotropic splatting by applying a rotation matrix to the coordinate system before evaluating the decay, allowing for directional brush strokes. It builds on [2D Gaussian Evaluation](4728-2d-gaussian-evaluation.md) by adding explicit rotational transformation of the input coordinates [G].

### [Opacity Modulating Parameter for Surfel Optimization](23121-opacity-modulating-parameter-for-surfel-optimization.md)
This method solves the non-differentiability of optimizing opaque surfel geometry directly from image color loss by introducing a gradual opacity modulation parameter $w_i$ that evolves translucent surfels into opaque ones. It differs from standard 2D Gaussian Evaluation by using $w_i$ to control the transition from a soft Gaussian profile to a hard-edged circular disc, enabling gradient flow through semi-transparent regions during early training.

### Gaussian RBF Base Function
A radial basis function used as the base activation/weight function for spacetime Gaussian rendering [S2, unofficial].
**Formula:**
$$ f(x) = \exp(-x^2) $$
where $x$ is the input tensor [S2, unofficial].
**Usage:**
Passed as `basicfunction=rbfbasefunction` to the render pipeline in `train.py` [S2, unofficial].

### Gaussian Opacity Fields
Calculates a randomly sampled point’s opacity value from the opacity of 3D Gaussians [S3, unofficial].
**Steps:**
1. Convert the discrete 3D Gaussians into a continuous opacity field [S3, unofficial].
2. Transform the continuous opacity field into an explicit surface [S3, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ for $N$ points, dominated by the matrix inverse ($O(1)$ per Gaussian for $2 \times 2$) and matrix multiplications.
- **Memory Complexity:** $O(N)$ to store the difference vectors and intermediate tensors.
- **Strengths:** Differentiable, allowing gradients to flow back to the covariance parameters during optimization. Efficient for batched evaluation.
- **Limitations:** Requires explicit covariance inversion, which can be numerically unstable if not regularized. Does not handle occlusion or depth sorting itself; that is handled by the rasterizer using these values.

## Background
Originated in the context of 3D Gaussian Splatting for differentiable rendering, specifically in implementations like the one by Fhz2346 [S1, unofficial]. It is a core component of the rasterization pipeline where Gaussians are projected to 2D and their contribution to each pixel is computed.
