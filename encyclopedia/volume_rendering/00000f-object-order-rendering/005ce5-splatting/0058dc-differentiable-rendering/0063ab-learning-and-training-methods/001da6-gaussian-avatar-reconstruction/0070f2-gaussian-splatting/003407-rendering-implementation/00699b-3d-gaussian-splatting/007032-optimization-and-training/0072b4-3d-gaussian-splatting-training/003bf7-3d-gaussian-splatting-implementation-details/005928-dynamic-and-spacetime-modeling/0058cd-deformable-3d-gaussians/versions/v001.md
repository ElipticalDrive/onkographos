# Deformable 3D Gaussians

Also called: Deformable-GS

## Overview
Deformable 3D Gaussians is a framework for modeling monocular dynamic scenes that extends static 3D Gaussian Splatting by learning time-independent 3D Gaussians in a canonical space and using a learned deformation field to model time-varying geometry [S1]. It decouples the radiance field from the deformation field, allowing for real-time rendering and high-fidelity reconstruction of dynamic scenes, unlike implicit methods which suffer from slow convergence and overfitting [S1]. It incorporates an Annealing Smooth Training (AST) mechanism to mitigate temporal jitter caused by inaccurate camera poses in real-world datasets [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of images of a monocular dynamic scene, time labels for each image, camera poses calibrated via Structure from Motion (SfM) [S1], and a sparse point cloud generated by SfM [S1].
*   **Outputs:** A set of deformed 3D Gaussians and a deformation network, enabling differentiable rendering of dynamic scenes at arbitrary times [S1].

**Data Structures**
1.  **3D Gaussians ($G$):** Defined in canonical space by:
    *   Center position: $\mathbf{x}$
    *   Opacity: $\sigma$
    *   Rotation: Quaternion $\mathbf{r}$
    *   Scaling: 3D vector $\mathbf{s}$
    *   View-dependent appearance: Spherical Harmonics (SH) coefficients [S1].
    *   The 3D covariance matrix $\Sigma$ is derived from $\mathbf{r}$ and $\mathbf{s}$ as $\Sigma = \mathbf{R}\mathbf{S}\mathbf{S}^T\mathbf{R}^T$, where $\mathbf{R}$ is the rotation matrix from $\mathbf{r}$ and $\mathbf{S}$ is the scaling matrix from $\mathbf{s}$ [S1].
2.  **Deformation Network ($F_\theta$):** An MLP with depth $D=8$ and hidden layer dimension $W=256$ [S1].
    *   Input: Positional encoding of canonical position $\gamma(\text{sg}(\mathbf{x}))$ and time $\gamma(t)$ [S1].
    *   Output: Offsets $(\delta\mathbf{x}, \delta\mathbf{r}, \delta\mathbf{s})$ [S1].

**Positional Encoding**
The positional encoding function $\gamma(\mathbf{p})$ is defined as:
$$ \gamma(\mathbf{p}) = (\sin(2^k \pi \mathbf{p}), \cos(2^k \pi \mathbf{p}))_{k=0}^{L-1} $$
*   For synthetic scenes: $L=10$ for position $\mathbf{x}$, $L=6$ for time $t$ [S1].
*   For real scenes: $L=10$ for both $\mathbf{x}$ and $t$ [S1].

**Algorithm Steps**
1.  **Initialization:** Initialize 3D Gaussians $G(\mathbf{x}, \mathbf{r}, \mathbf{s}, \sigma)$ from the SfM sparse point cloud or random generation [S1].
2.  **Warm-up Phase:** For the first 3,000 iterations, optimize only the 3D Gaussians using the differential Gaussian rasterization pipeline. Do not optimize the deformation field [S1].
3.  **Joint Optimization:** After the warm-up phase, jointly optimize the deformation field and the 3D Gaussians using the fast differential Gaussian rasterization pipeline, including adaptive density control [S1].
    *   **Deformation:** Compute offsets $(\delta\mathbf{x}, \delta\mathbf{r}, \delta\mathbf{s}) = F_\theta(\gamma(\text{sg}(\mathbf{x})), \gamma(t))$ [S1].
    *   **Deformation with AST (Real-world):** If using Annealing Smooth Training, compute:
        $$ \Delta = F_\theta(\gamma(\text{sg}(\mathbf{x})), \gamma(t + X(i))) $$
        where $X(i) = \mathcal{N}(0, 1) \cdot \beta \cdot \Delta t \cdot (1 - i/\tau)$ [S1].
        *   $\mathcal{N}(0, 1)$: Standard Gaussian distribution [S1].
        *   $\beta$: Scaling factor, empirically set to 0.1 [S1].
        *   $\Delta t$: Mean time interval [S1].
        *   $\tau$: Threshold iteration for annealing, empirically set to 20,000 [S1].
        *   $i$: Current training iteration [S1].
    *   **Deformed Gaussians:** The deformed Gaussians are $G(\mathbf{x} + \delta\mathbf{x}, \mathbf{r} + \delta\mathbf{r}, \mathbf{s} + \delta\mathbf{s}, \sigma)$ [S1].
    *   **Rendering:** Project 3D Gaussians to 2D using the covariance matrix $\Sigma' = \mathbf{J}\mathbf{V}\Sigma\mathbf{V}^T\mathbf{J}^T$, where $\mathbf{J}$ is the Jacobian of the affine approximation of the projective transformation, $\mathbf{V}$ is the view matrix, and $\Sigma$ is the 3D covariance matrix [S1]. Render pixel color $C(\mathbf{p})$ via alpha blending:
        $$ C(\mathbf{p}) = \sum_{i \in \mathcal{N}} T_i \alpha_i c_i $$
        where $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the transmittance, $\alpha_i = \sigma_i e^{-\frac{1}{2}(\mathbf{p}-\boldsymbol{\mu}_i)^T \Sigma'^{-1} (\mathbf{p}-\boldsymbol{\mu}_i)}$ is the opacity, $c_i$ is the color, and $\mathcal{N}$ is the set of Gaussians along the ray [S1].
    *   **Adaptive Density Control:**
        *   **Pruning:** Remove transparent Gaussians based on opacity $\sigma$ [S1].
        *   **Densification:** Clone small Gaussians and move them in the direction of positional gradients if their positional gradient exceeds threshold $t_{\text{pos}} = 0.0002$ [S1].
        *   **Splitting:** Split large overlapping Gaussians by dividing their scale by hyperparameter $\xi = 1.6$ [S1].
4.  **Optimization Parameters:** Use the Adam optimizer [S1].
    *   Learning rate for 3D Gaussians: Same as standard 3D Gaussian Splatting [S1].
    *   Learning rate for deformation network: Exponential decay from $8 \times 10^{-4}$ to $1.6 \times 10^{-6}$ [S1].
    *   Adam $\beta$ values: $(0.9, 0.999)$ [S1].
    *   Total iterations: Typically 40,000 [S1].

class PositionalEncoding(nn.Module):
    def __init__(self, L):
        super().__init__()
        self.L = L

    def forward(self, p):
        # p shape: (..., 1)
        freq_bands = 2.0 ** torch.arange(self.L, device=p.device).float()
        # sin(2^k * pi * p), cos(2^k * pi * p)
        out = []
        for k in range(self.L):
            freq = freq_bands[k]
            out.append(torch.sin(freq * torch.pi * p))
            out.append(torch.cos(freq * torch.pi * p))
        return torch.cat(out, dim=-1)

## Operating characteristics
*   **Time Complexity:** Training involves joint optimization of Gaussians and a deformation MLP. The rasterization is tile-based and efficient, similar to static 3D-GS [S1].
*   **Memory Complexity:** Stores 3D Gaussians (position, rotation, scale, opacity, SH coefficients) and the deformation network parameters (8 layers, 256 hidden units) [S1].
*   **Performance:** Achieves real-time rendering speeds and high-fidelity reconstruction, outperforming existing implicit methods in both quality and speed [S1].
*   **Strengths:** Decouples time and radiance field, enabling efficient representation of non-dramatic action variations. AST mechanism improves temporal smoothness without extra computational overhead [S1].
*   **Limitations:** Relies on accurate SfM poses; while AST mitigates jitter, severe pose inaccuracies may still impact results. The method is designed for monocular dynamic scenes [S1].
*   **When to use:** High-fidelity reconstruction of monocular dynamic scenes where real-time rendering is required.
*   **When not to use:** Multi-view static scenes (use standard 3D-GS) or scenes with dramatic, non-rigid deformations that cannot be captured by a canonical space deformation field [S1].

## Background
Deformable 3D Gaussians was proposed to address the limitations of implicit methods (like NeRF) in dynamic scene modeling, which suffer from slow convergence, overfitting, and lack of real-time rendering capabilities [S1]. It builds on the seminal work of 3D Gaussian Splatting [15] and extends it to dynamic scenes by introducing a deformation field and canonical space representation [S1]. The method was introduced in the paper "Deformable 3D Gaussians for High-Fidelity Monocular Dynamic Scene Reconstruction" [S1].
