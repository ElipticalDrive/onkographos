# Texture and Appearance Representation

Also called: View-Dependent Appearance, View-Dependent Gaussian Splatting, Neural BRDF for 3D Gaussian Splatting, Neural Texture Splatting

## Overview
This family extends the standard 3D Gaussian Splatting primitive by replacing or augmenting the static isotropic color attribute with mechanisms that model high-frequency appearance details and view-dependent effects. While standard 3DGS uses low-order Spherical Harmonics (SH) for view-dependent color, these methods decouple geometric representation from appearance, enabling specular highlights, anisotropic reflections, and high-resolution textures without increasing the number of primitives.

## Shared principles
All methods in this family share the following mechanism and data structure extensions:

1.  **Extended Primitive Attributes**: Each 3D Gaussian primitive $i$ stores additional appearance attributes $\mathbf{a}_i$ alongside the standard geometric parameters (position $\mathbf{\mu}_i$, covariance $\mathbf{\Sigma}_i$, opacity $\alpha_i$).
2.  **View-Dependent Evaluation**: The final color $C(p)$ at pixel $p$ is computed by querying $\mathbf{a}_i$ with the viewing direction $\mathbf{v}$ and potentially other parameters (e.g., light direction $\mathbf{l}$, surface normal $\mathbf{n}$), rather than using a static isotropic color vector.
3.  **Alpha-Blending**: The rendering equation remains a front-to-back alpha blending process, but the contribution $c_i$ of each Gaussian is modulated by the appearance function:
    $$ C(p) = \sum_{i \in \text{sorted}} c_i(\mathbf{v}, \mathbf{a}_i) \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $c_i$ is the color contribution derived from the specific appearance representation [S1].
4.  **Trade-off**: The choice of representation involves a trade-off between storage bandwidth, computational cost during decoding, and the complexity of the appearance being modeled [S1].

## Subtopics

### [Textured Gaussians](8061-textured-gaussians.md)
Textured Gaussians replace spherical harmonic (SH) coefficients with explicit 2D textures mapped onto each 3D Gaussian primitive to resolve artifacts in semi-transparent scenes and enable high-frequency appearance details without increasing the number of primitives. Unlike standard 3D Gaussian Splatting which uses low-order SH for view-dependent color, this method decouples geometric representation from high-fidelity appearance, allowing for detailed texture sampling based on local UV coordinates.

### [Spec-Gaussian](8087-spec-gaussian.md)
Spec-Gaussian is an appearance representation for 3D Gaussian Splatting that models complex view-dependent shading, specifically specular highlights and anisotropic reflections, by replacing the standard isotropic color attribute with Anisotropic Spherical Gaussians (ASGs). Unlike standard 3D Gaussian Splatting which uses a single static color vector per primitive, Spec-Gaussian captures high-frequency radiance variations, addressing the limitation of basic splatting in rendering shiny or metallic surfaces.

### [View-Dependent Appearance Representations](14602-view-dependent-appearance-representations.md)
This family encompasses methods for modeling view-dependent appearance within 3D Gaussian splats, addressing the limitation of static isotropic color vectors in standard Gaussian Splatting. It distinguishes itself from sibling methods like [Spec-Gaussian](8087-spec-gaussian.md) by providing a modular framework for various encoding strategies, including fixed basis functions, neural feature vectors, explicit caching structures, and codebook quantization.

#### View-Dependent Gaussian Splatting
- [S1] Models 3DGS to represent 3D shapes and predicts attributes like view-dependent color and opacity using a NeRF-like neural network, replacing the Spherical Harmonic (SH) coefficients used in original 3DGS.

#### Neural BRDF for 3D Gaussian Splatting
- [S2, unofficial] Simplifies the BRDF to a neural shader that predicts specular and diffuse components directly from the view direction and a learnable material feature.

#### Neural Texture Splatting
- [S2, unofficial] Encodes textures as small neural networks evaluated at Gaussian coordinates, which can be deformed to model dynamic appearances and fine geometric displacements.

## Background
Standard 3D Gaussian Splatting uses Spherical Harmonics (SH) to approximate view-dependent color, which can struggle with high-frequency details and specular highlights. Recent advances have introduced various appearance representations to overcome these limitations. View-Dependent Gaussian Splatting (VDGS) proposes modeling 3DGS to represent 3D shapes and predict attributes like view-dependent color and opacity with a NeRF-like neural network instead of SH coefficients [S1]. Scaffold-GS initializes a voxel grid and attaches learnable features onto each voxel point, determining all Gaussian attributes via interpolated features and lightweight neural networks [S1]. Octree-GS introduces a level-of-detail strategy based on Scaffold-GS [S1].

For specular and anisotropic effects, methods like GaussianShader simplify the BRDF to a neural shader that predicts specular and diffuse components directly from the view direction and a learnable material feature [S2, unofficial]. Other approaches, such as GS-IR, perform inverse rendering by jointly optimizing Gaussian geometry and an environment light probe [S2, unofficial]. Geo-Splatting guides inverse rendering with explicit geometric priors, adding a normal consistency loss [S2, unofficial].

To handle high-frequency textures, some methods replace SH coefficients with explicit 2D textures mapped onto each primitive, sampling color according to local UV coordinates [S2, unofficial]. Neural Texture Splatting further encodes textures as small neural networks evaluated at Gaussian coordinates, allowing for dynamic appearance modeling and fine geometric displacements [S2, unofficial].
