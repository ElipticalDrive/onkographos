# Gaussian Mixture Tree Construction

Also called: Hierarchically Merging Gaussians

## Overview
Gaussian Mixture Tree (GMT) Construction is a hierarchical scene representation method that organizes 3D Gaussian primitives into a tree structure to identify distinct 3D plane instances [S1]. Unlike standard 3D Gaussian Splatting which treats primitives as independent entities, GMT recursively merges leaf nodes (local clusters of Gaussians) into parent nodes based on statistical similarity and geometric consistency, enabling plane-aware rendering and deformation [S1]. It is distinguished from sibling methods like [TraGraph-GS](14454-tragraph-gs.md) and [Surface-Aware Splat Graph Construction](22007-surface-aware-splat-graph-construction.md) by its explicit tree hierarchy derived from Gaussian Mixture Models rather than graph adjacency or spatial containment [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N_s$ leaf nodes $\{G_i\}_{i=1}^{N_s}$, where each leaf node $G_i$ represents a local cluster of 3D Gaussian primitives. Each node $G_i$ is defined by mean $\mu_i \in \mathbb{R}^3$, covariance $\Sigma_i \in \mathbb{R}^{3 \times 3}$, normal vector $n_i \in \mathbb{R}^3$, and plane descriptor $z_i \in \mathbb{R}^k$ (typically $k=3$) [S1].
*   **Output:** A Gaussian Mixture Tree $G$ containing merged parent nodes and a counter $L$ representing the number of plane nodes [S1].

**Data Structures:**
*   **Leaf Node:** A cluster of Gaussians. Raw optimized Gaussians are not used directly as leaves due to computational expense; instead, they are grouped into local clusters [S1].
*   **Tree Node:** Represents a Gaussian distribution $G_p(\mu_p, \Sigma_p)$ encompassing its children. Nodes store $\mu, \Sigma, n, z$ [S1].

**Parameters:**
*   $\epsilon_B$: Threshold for Bhattacharya distance. Not given in the sources.
*   $\epsilon_z$: Threshold for cosine similarity difference. Used in the condition $1 - \langle z_i \cdot z_j \rangle \le \epsilon_z$ [S1].

**Algorithm Steps:**
1.  Initialize level counter $L = 0$ and tree $G = \emptyset$ [S1].
2.  Iterate through each leaf node $i$ from $1$ to $N_s$:
    a.  Check if node $i$ is already a descendant of any existing node in $G$. If yes, skip to the next $i$ [S1].
    b.  Iterate through each leaf node $j$ from $i+1$ to $N_s$:
        i.  Check if node $j$ is already a descendant of any existing node in $G$. If yes, skip to the next $j$ [S1].
        ii. Calculate the Bhattacharya distance $D_B(G_i, G_j)$ and the cosine similarity difference between plane descriptors [S1].
        iii. If $D_B(G_i, G_j) \le \epsilon_B$ AND $1 - \langle z_i \cdot z_j \rangle \le \epsilon_z$:
            *   Merge $G_i$ and $G_j$ into a parent node $G_{ij}^p$ with parameters $(\mu_p, \Sigma_p)$ using the Gaussian Mixture Model merging formulas [S1].
            *   Update $G_i \leftarrow G_{ij}^p$ [S1].
            *   Break the inner loop (stop searching for $j$ for this $i$) [S1].
    c.  Insert the resulting node $G_i$ into $G$ as a plane node [S1].
    d.  Increment $L \leftarrow L + 1$ [S1].

**Formulas:**
The merging of two Gaussian distributions $G_i(\mu_i, \Sigma_i)$ and $G_j(\mu_j, \Sigma_j)$ into a parent $G_p(\mu_p, \Sigma_p)$ is defined as [S1]:

$$
\Sigma_p = \Sigma_j \cdot (\Sigma_i + \Sigma_j)^{-1} \cdot \Sigma_i
$$

$$
\mu_p = \Sigma_j \cdot (\Sigma_i + \Sigma_j)^{-1} \cdot \mu_i + \Sigma_i \cdot (\Sigma_i + \Sigma_j)^{-1} \cdot \mu_j
$$

The merging criterion uses the Bhattacharya distance $D_B(G_i, G_j)$ [S1]:

$$
D_B(G_i, G_j) = \frac{1}{8}(\mu_i - \mu_j)^T \Sigma^{-1}(\mu_i - \mu_j) + \frac{1}{2}\ln \left( \frac{\det \Sigma}{\sqrt{\det \Sigma_i \det \Sigma_j}} \right)
$$

where $\Sigma = (\Sigma_i + \Sigma_j)/2$ [S1].

**Edge Cases and Pitfalls:**
*   **Computational Expense:** Using raw optimized Gaussians as leaf nodes is computationally expensive due to the large number of primitives. Clustering is required to form leaf nodes [S1].
*   **Missing Parameters:** The threshold $\epsilon_B$ for the Bhattacharya distance is not provided in the sources [S1].
*   **Descriptor Derivation:** The method for deriving the normal vector $n_p$ and plane descriptor $z_p$ of a parent node from its children is not explicitly defined in the merging step, only that they are introduced for primitives [S1].

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Performance:** Not given in the sources.
*   **Strengths:** Identifies distinct 3D plane instances, enabling plane-aware applications like deformation and segmentation [S1].
*   **Limitations:** Requires additional parameters (normal, plane descriptor) and learning processes (lifting 2D normals, SAM masks) not present in standard 3DGS [S1].

## Background
*   **Origin:** Proposed in "Planar Gaussian Splatting" [S1].
*   **History:** The method uses a probabilistic approach to model the 3D scene recursively from leaf nodes to the root node using Gaussian Mixture Models [S1].
*   **Usage:** Used to identify distinct 3D plane instances for applications requiring geometric understanding of the scene [S1].
