# GaussianRasterizer_w_pose


## Overview
A variant of the Gaussian rasterizer that accepts camera rotation and translation deltas to render the scene with pose perturbations, returning an additional count of touched pixels (`n_touched`) [S1, unofficial]. It differs from the standard [3D Gaussian Splatting Rasterization (GPU)](13469-3d-gaussian-splatting-rasterization-gpu.md) by exposing pose perturbation inputs and tracking pixel coverage statistics for optimization feedback [S1, unofficial].

## How it works
**Inputs:**
- `means3D`: 3D Gaussian means, shape $(N, 3)$ [S1, unofficial].
- `means2D`: 2D projected means, shape $(N, 2)$, initialized with `requires_grad=True` and `retain_grad()` to enable gradients for 2D means [S1, unofficial].
- `shs` or `colors_precomp`: Spherical Harmonics coefficients or precomputed RGB colors [S1, unofficial].
- `opacities`: Opacity values, shape $(N, 1)$ [S1, unofficial].
- `scales` and `rotations`: Scale and rotation parameters, or `cov3D_precomp` if `pipe.compute_cov3D_python` is true [S1, unofficial].
- `theta`, `rho`: Camera rotation and translation deltas [S1, unofficial].
- `viewpoint_cam`: Camera object providing FoV and projection matrix [S1, unofficial].
- `pipe`: Configuration object controlling SH evaluation and covariance computation [S1, unofficial].

**Outputs:**
- Dictionary with keys: `render` (rendered image), `viewspace_points` (screenspace points), `visibility_filter` (boolean mask where radii > 0), `radii`, `rendered_depth`, `rendered_alpha`, and `n_touched` (pixel touch count) [S1, unofficial].

**Steps:**
1. Initialize `screenspace_points` tensor with `requires_grad=True` and call `retain_grad()` to enable gradients for 2D means [S1, unofficial].
2. Compute `tanfovx` and `tanfovy` from `viewpoint_cam.FoVx` and `viewpoint_cam.FoVy` [S1, unofficial].
3. Construct `GaussianRasterizationSettings_w_pose` including `projmatrix_raw`, `sh_degree`, `campos`, and `prefiltered=False` [S1, unofficial].
4. Instantiate `GaussianRasterizer_w_pose` with the raster settings [S1, unofficial].
5. Determine covariance representation: if `pipe.compute_cov3D_python` is true, compute `cov3D_precomp` from `pc.get_covariance(scaling_modifier)`; otherwise, pass `scales` and `rotations` separately [S1, unofficial].
6. Determine color representation: if `override_color` is None and `pipe.convert_SHs_python` is true, convert SHs to RGB in Python using `eval_sh` and clamp; otherwise, pass `shs` directly to the rasterizer [S1, unofficial].
7. Call the rasterizer with `means3D`, `means2D`, `shs`/`colors_precomp`, `opacities`, `scales`/`rotations`/`cov3D_precomp`, and pose deltas `theta` and `rho` [S1, unofficial].

def render_w_pose(means3D, means2D, shs, opacities, scales, rotations,

        sh_degree=pipe.SH_degree,
        campos=viewpoint_cam.camera_center,
        prefiltered=False,
        debug=False
    )
    
    # Step 4: Instantiate rasterizer
    rasterizer = GaussianRasterizer_w_pose(raster_settings=raster_settings)
    
    # Step 5: Determine covariance representation
    if pipe.compute_cov3D_python:
        cov3D_precomp = pc_get_covariance(scaling_modifier=1.0) # [G] scaling_modifier assumed 1.0 if not specified
    else:
        cov3D_precomp = None
        
    # Step 6: Determine color representation
    if override_color is None and pipe.convert_SHs_python:
        colors_precomp = torch.clamp(eval_sh(pipe.SH_degree, shs, means3D), 0.0, 1.0)
    else:
        colors_precomp = shs if override_color is None else override_color
        
    # Step 7: Call rasterizer
    render_pkg = rasterizer(
        means3D=means3D,
        means2D=means2D,
        shs=colors_precomp,
        opacities=opacities,
        scales=scales,
        rotations=rotations,
        cov3D_precomp=cov3D_precomp,
        theta=theta,
        rho=rho
    )
    
    return render_pkg
