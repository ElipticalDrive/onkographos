# Mapping Strategies

Also called: Pixel mapping strategies, Scene alignment strategies

## Overview
Mapping strategies define the correspondence mechanism used to align pixels or features between two distinct scenes or frames for the purpose of fusion, editing, or SLAM initialization. They solve the problem of establishing spatial and semantic consistency when direct geometric alignment is ambiguous or unavailable. Unlike sibling methods that focus on the continuous representation of a single scene (e.g., [NeRF Representation](12096-neural-radiance-field-nerf-representation.md)) or semantic enrichment ([Semantic-aware mapping](12053-semantic-aware-mapping.md)), mapping strategies specifically address the *inter-scene* or *inter-frame* registration step, ranging from naive pixel identity to dense semantic feature matching.

## How it works
The method consists of establishing a correspondence map $M$ between a source image/scene $I_S$ and a target image/scene $I_T$. The specific strategy determines how $M$ is computed.

### Inputs and Outputs
- **Inputs:** Source image $I_S$, Target image $I_T$, and optionally depth maps $D_S, D_T$ or semantic features.
- **Outputs:** A correspondence map $M$ where $M(u, v)$ indicates the matched location in $I_T$ for pixel $(u, v)$ in $I_S$.

### Strategies
Three primary strategies are identified in the literature [S1]:

1.  **Identity Mapping:**
    -   **Definition:** Assumes direct pixel correspondence based on coordinate indices. $M(u, v) = (u, v)$.
    -   **Characteristics:** Computationally trivial but lacks spatial alignment accuracy. It fails when the scenes are not perfectly registered or have undergone geometric transformations.
    -   **Use Case:** Baseline comparison or when scenes are pre-aligned with high precision.

2.  **Semantic Correspondence-based Mapping:**
    -   **Definition:** Uses deep learning models to extract dense semantic features, which are then matched to improve spatial alignment.
    -   **Steps:**
        1.  Extract dense semantic features from $I_S$ and $I_T$ using Vision Transformers (ViT) [Dosovitskiy 2020] and DINO [Amir et al. 2021]. Let $F_S$ and $F_T$ be the feature maps.
        2.  Compute a similarity matrix $S$ between features: $S_{ij} = \text{sim}(F_S[i], F_T[j])$.
        3.  Find the best match for each pixel in $I_S$ by maximizing similarity in $S$.
    -   **Characteristics:** Improves alignment robustness in textureless or repetitive regions by leveraging semantic context.

3.  **Co-segmentation-based Mapping:**
    -   **Definition:** Refines alignment by segmenting images into semantically meaningful parts using clustering on DINO features, then mapping within segments.
    -   **Steps:**
        1.  Apply DINO-based clustering to segment $I_S$ and $I_T$ into coherent regions.
        2.  Establish correspondences between corresponding semantic segments.
        3.  Map pixels within matched segments, maintaining semantic boundaries.
    -   **Characteristics:** Yields finer correspondence than dense feature matching alone and preserves semantic boundaries, preventing "bleeding" of attributes across object edges.

### Resampling for Alignment (Variant)
When mapping involves geometry fusion (e.g., color-geometry consistency), simple pixel mapping is insufficient. A **density-based resampling** strategy is used [S1]:
1.  Identify density peaks along corresponding rays in the source and target scenes.
2.  Adjust sampling points along the ray to align these key geometric points.
3.  This ensures that color attributes are fused with consistent geometry, avoiding artifacts from misalignment.

### Pseudocode: Semantic Correspondence Mapping
```python
def semantic_correspondence_mapping(I_S, I_T, model):
    """
    Computes correspondence map using DINO/ViT features.
    I_S, I_T: Input images (H, W, 3)
    model: Pretrained DINO/ViT model
    """
    # 1. Extract features
    # model returns dense feature maps of size (H, W, C)
    F_S = model.extract_features(I_S)
    F_T = model.extract_features(I_T)
    
    H, W, C = F_S.shape
    
    # 2. Flatten features
    # F_S_flat: (H*W, C)
    F_S_flat = F_S.reshape(-1, C)
    F_T_flat = F_T.reshape(-1, C)
    
    # 3. Compute similarity matrix
    # Normalize features for cosine similarity
    F_S_norm = F_S_flat / (norm(F_S_flat) + epsilon)
    F_T_norm = F_T_flat / (norm(F_T_flat) + epsilon)
    
    # Similarity: (H*W, H*W)
    Sim = matmul(F_S_norm, transpose(F_T_norm))
    
    # 4. Find best matches
    # Indices of max similarity for each pixel in S
    Match_Indices = argmax(Sim, axis=1)
    
    # 5. Convert flat indices to 2D coordinates
    Match_Y = Match_Indices // W
    Match_X = Match_Indices % W
    
    # 6. Construct map
    # Map stores (x, y) for each pixel in S
    Map = stack([Match_X, Match_Y], axis=-1)
    
    return Map
```

## Subtopics

### [iMAP](11979-imap.md)
iMAP is the first NeRF-based dense online SLAM model that jointly optimizes camera pose and an implicit scene representation. It treats the scene as a continuous radiance field rather than a discrete mesh or point cloud. It sets itself apart by introducing the iterative two-step approach of tracking and mapping to NeRF-based SLAM, serving as the foundation for methods like NICE-SLAM. Link: [iMAP](11979-imap.md).

### [RNR-Map Construction](16526-rnr-map-construction.md)
RNR-Map Construction embeds visual information from an RGB-D image into a 2D grid map using a pretrained encoder and inverse camera projection. It differs from [iMAP](11979-imap.md) by operating directly on latent codes, bypassing the computationally expensive differentiable rendering step required for alignment, thus enabling high-frequency mapping. Link: [RNR-Map Construction](16526-rnr-map-construction.md).

### Joint Mapping and Pose Update
A mapping subroutine that fuses tracked RGB-D frames into an existing scene map by jointly optimizing scene geometry, camera poses, and feature embeddings using a sliding window of keyframes [S2]. It addresses online incremental learning forgetting by optimizing the scene network and embeddings simultaneously [S2].
- **Steps:**
    1.  Randomly select $N_{kf}$ keyframes to form an optimization window with the current frame [S2].
    2.  For each frame in the window, randomly sample $N_m$ rays [S2].
    3.  Transform rays to the world coordinate system using estimated poses [S2].
    4.  Sample points within sparse voxels, render pixels, and calculate loss functions [S2].
- **Parameters:**
    -   $N_{kf}$: Number of keyframes in the optimization window [S2].
    -   $N_m$: Number of rays sampled per frame [S2].
Link: [Vox-Fusion](12097-vox-fusion.md) (implied context from source).

## Operating characteristics
- **Identity Mapping:** $O(1)$ time complexity per pixel. No memory overhead. Fails under misalignment.
- **Semantic Correspondence:** $O(H \cdot W \cdot C)$ for feature extraction and $O((HW)^2)$ for similarity matrix computation if done naively, though optimized with locality-sensitive hashing or approximate nearest neighbors. High memory usage for feature maps. Robust to geometric variation.
- **Co-segmentation:** Higher computational cost due to clustering and segmentation steps. Provides superior semantic boundary preservation.
- **Joint Mapping (Vox-Fusion):** Complexity depends on the number of keyframes $N_{kf}$ and rays $N_m$. Uses sparse voxel structures (octrees) to manage memory, focusing only on observed surfaces [S2].

## Background
Mapping strategies in radiance fields emerged with the need to align multiple scenes or frames for editing and SLAM. The Generalized TensoRF paper [S1] explicitly categorized these strategies (Identity, Semantic, Co-segmentation) for multi-scene radiance field editing. Vox-Fusion [S2] introduced joint mapping and pose update for dense tracking and mapping using voxel-based neural implicit representations, addressing the issue of network forgetting in online SLAM.
