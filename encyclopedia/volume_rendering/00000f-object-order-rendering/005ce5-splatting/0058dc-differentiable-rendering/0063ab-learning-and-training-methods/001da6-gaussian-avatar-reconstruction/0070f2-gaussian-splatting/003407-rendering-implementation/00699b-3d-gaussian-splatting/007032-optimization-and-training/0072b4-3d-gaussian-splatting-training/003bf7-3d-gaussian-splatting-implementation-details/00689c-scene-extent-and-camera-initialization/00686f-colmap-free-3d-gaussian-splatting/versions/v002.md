# COLMAP-Free 3D Gaussian Splatting

Also called: CF-3DGS

## Overview
COLMAP-Free 3D Gaussian Splatting (CF-3DGS) is a method for novel view synthesis and camera pose estimation from unposed video sequences, eliminating the need for Structure-from-Motion (SfM) preprocessing [S1]. Unlike standard 3D Gaussian Splatting which relies on pre-computed sparse point clouds and known camera poses, CF-3DGS leverages temporal continuity in video and explicit point cloud representation to progressively "grow" a global 3D Gaussian set frame-by-frame [S1]. It sets itself apart by estimating relative camera poses via differentiable rendering of local Gaussian sets, allowing it to handle significant camera motion where traditional unposed methods may fail [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A sequence of unposed video frames $I_t$ for $t \in \{1, \dots, T\}$, and camera intrinsics $K$ [S1].
*   **Output:** A global set of 3D Gaussians representing the scene, and estimated camera poses for all frames [S1].

**Data Structures**
Each 3D Gaussian $i$ is defined by the following parameters [S1]:
*   Center position: $\mu_i \in \mathbb{R}^3$ [S1]
*   Rotation: $r_i \in \mathbb{R}^4$ (unit quaternion) [S1]
*   Scale: $s_i \in \mathbb{R}^3$ [S1]
*   Opacity: $\alpha_i \in \mathbb{R}$ [S1]
*   Color: Spherical Harmonics (SH) coefficients $c_i \in \mathbb{R}^k$ [S1]

The covariance matrix $\Sigma_i$ is derived from rotation and scale [S1]:
$$ \Sigma_i = R_i S_i S_i^{\top} R_i^{\top} $$
where $S_i = \text{diag}([s_{ix}, s_{iy}, s_{iz}])$ and $R_i$ is the rotation matrix constructed from quaternion $r_i$ [S1].

**Algorithm Steps**
The method processes frames sequentially [S1]. For each frame $t$, it performs two main steps:

1.  **Initialization from a Single View (Frame 1):**
    *   Given frame $I_1$, generate monocular depth $D_1$ using an off-the-shelf network (e.g., DPT) [S1].
    *   Initialize 3D Gaussians by lifting points from $D_1$ using camera intrinsics $K$ and an identity camera pose [S1].
    *   Optimize the parameters of this local set $G_1$ to minimize photometric loss between the rendered image and $I_1$ [S1].

2.  **Sequential Growth (Frames $t > 1$):**
    *   **Local Optimization:** Construct a local 3D Gaussian set from frame $t-1$ [S1]. Sample frame $t$. Learn an affine transformation (representing the relative camera pose between $t-1$ and $t$) that transforms the Gaussians from $t-1$ to render frame $t$ [S1]. This is done by minimizing photometric loss using differentiable rendering [S1].
    *   **Global Aggregation:** Infer the absolute pose of frame $t$ by accumulating relative poses [S1]. Aggregate the current frame's Gaussian information into the global set [S1].
    *   **Global Optimization:** Optimize the global set using all previous frames and their estimated poses [S1].

**Rendering Formula**
To render a pixel, Gaussians overlapping the pixel are sorted by depth [S1]. The final color $C_{pix}$ is computed via alpha blending [S1]:
$$ C_{pix} = \sum_{i=1}^{N} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
where $N$ is the number of overlapping Gaussians, $c_i$ is the color, and $\alpha_i$ is the opacity of the $i$-th Gaussian [S1].

The 2D covariance $\Sigma^{\text{2D}}$ in camera coordinates is computed as [S1]:
$$ \Sigma^{\text{2D}} = J W \Sigma W^{\top} J^{\top} $$
where $W$ is the viewing transform (camera pose), and $J$ is the Jacobian of the affine approximation of the projective transformation [S1].

```python
import numpy as np

class Gaussian:
    def __init__(self, mu, alpha, sh_coeffs, scale, rotation):
        self.mu = np.array(mu, dtype=np.float32)
        self.alpha = float(alpha)
        self.sh_coeffs = np.array(sh_coeffs, dtype=np.float32)
        self.scale = np.array(scale, dtype=np.float32)
        self.rotation = np.array(rotation, dtype=np.float32)

def quaternion_to_rotation_matrix(q):
    w, x, y, z = q[0], q[1], q[2], q[3]
    return np.array([
        [1 - 2*(y**2 + z**2), 2*(x*y - w*z), 2*(x*z + w*y)],
        [2*(x*y + w*z), 1 - 2*(x**2 + z**2), 2*(y*z - w*x)],
        [2*(x*z - w*y), 2*(y*z + w*x), 1 - 2*(x**2 + y**2)]
    ])

def compute_2d_covariance(gaussian, camera_pose, intrinsics):
    # Sigma_3D from scale and rotation
    R = quaternion_to_rotation_matrix(gaussian.rotation)
    S = np.diag(gaussian.scale)
    Sigma_3D = R @ S @ S.T @ R.T
    
    # Viewing transform W (camera pose)
    W = camera_pose
    
    # Jacobian J of affine approximation of projective transformation
    # J depends on the center point in camera coordinates
    mu_cam = W @ np.append(gaussian.mu, 1.0)[:3]
    z = mu_cam[2]
    # Standard perspective projection Jacobian approximation
    J = np.array([
        [1.0/z, 0, -mu_cam[0]/(z**2)],
        [0, 1.0/z, -mu_cam[1]/(z**2)],
        [0, 0, 0]
    ])
    
    # Sigma_2D = J @ W @ Sigma @ W.T @ J.T
    Sigma_2D = J @ W @ Sigma_3D @ W.T @ J.T
    return Sigma_2D

def project_to_image(mu_cam, intrinsics):
    # mu_2D = K * (W * mu) / (W * mu)_z
    z = mu_cam[2]
    mu_2d = (intrinsics @ mu_cam) / z
    return mu_2d[:2]

def pixels_covered_by_gaussian(mu_2d, sigma_2d, height, width):
    # Compute bounding box from 2D covariance (2-sigma ellipse)
    std_x = np.sqrt(sigma_2d[0, 0]) * 2.0
    std_y = np.sqrt(sigma_2d[1, 1]) * 2.0
    x_min = max(0, int(mu_2d[0] - std_x))
    x_max = min(width, int(mu_2d[0] + std_x))
    y_min = max(0, int(mu_2d[1] - std_y))
    y_max = min(height, int(mu_2d[1] + std_y))
    
    pixels = []
    for y in range(y_min, y_max):
        for x in range(x_min, x_max):
            pixels.append((y, x))
    return pixels

def photometric_loss(rendered, ground_truth):
    # Standard L1 loss
    return np.mean(np.abs(rendered - ground_truth))

def optimize_gaussians(gaussians, frame, intrinsics, pose, lr=0.001, steps=100):

def render_gaussians(gaussians, camera_pose, intrinsics):
    height, width = 1080, 1920  # [G] Typical resolution, inferred from context
    image = np.zeros((height, width, 3), dtype=np.float32)
    accumulated_alpha = np.zeros((height, width), dtype=np.float32)
    
    # Project and sort by depth
    projected = []
    for g in gaussians:
        mu_cam = camera_pose @ np.append(g.mu, 1.0)[:3]
        sigma_2d = compute_2d_covariance(g, camera_pose, intrinsics)
        mu_2d = project_to_image(mu_cam, intrinsics)
        projected.append({
            'mu_2d': mu_2d,
            'sigma_2d': sigma_2d,
            'alpha': g.alpha,
            'sh_coeffs': g.sh_coeffs,
            'depth': mu_cam[2]
        })
    
    projected.sort(key=lambda x: x['depth'])
    
    # Alpha blending
    for g in projected:
        pixels = pixels_covered_by_gaussian(g['mu_2d'], g['sigma_2d'], height, width)
        for y, x in pixels:
            # Compute Gaussian value at pixel
            diff = np.array([x, y]) - g['mu_2d']
            exponent = -0.5 * diff.T @ np.linalg.inv(g['sigma_2d']) @ diff
            gaussian_val = np.exp(exponent)
            
            # Color from SH coefficients (simplified to base color for implementation)
            c_i = g['sh_coeffs'][:3]
            alpha_i = g['alpha'] * gaussian_val
            
            # C_pix = sum(c_i * alpha_i * prod(1 - alpha_j))
            weight = alpha_i * (1 - accumulated_alpha[y, x])
            image[y, x] += c_i * weight
            accumulated_alpha[y, x] += alpha_i
            
    return image

def train_cf_3dgs(frames, intrinsics, num_steps=50):
    global_gaussians = []
    
    # Step 1: Initialize with first frame
    depth_1 = predict_monocular_depth(frames[0])
    h, w = depth_1.shape
    global_gaussians = initialize_gaussians_from_depth(depth_1, intrinsics, h, w)
    global_gaussians = optimize_gaussians(global_gaussians, frames[0], intrinsics, np.eye(4), steps=100)
    
    current_pose = np.eye(4)
    
    # Step 2: Process subsequent frames
    for t in range(1, len(frames)):
        frame_prev = frames[t-1]
        frame_curr = frames[t]
        
        # Local optimization to estimate relative pose
        local_gaussians = [Gaussian(g.mu.copy(), g.alpha, g.sh_coeffs.copy(), g.scale, g.rotation) for g in global_gaussians]
        relative_pose = np.eye(4)
        
        for step in range(num_steps):
            rendered = render_gaussians(local_gaussians, relative_pose, intrinsics)
            loss = photometric_loss(rendered, frame_curr)
            # [G] Gradient update on relative_pose parameters
            relative_pose = update_pose(relative_pose, loss)
            
        # Update global pose
        current_pose = current_pose @ relative_pose
        
        # Aggregate new Gaussians from current frame
        depth_curr = predict_monocular_depth(frame_curr)
        new_gaussians = initialize_gaussians_from_depth(depth_curr, intrinsics, h, w)
        
        # Transform new Gaussians to global coordinate system
        for g in new_gaussians:
            g.mu = (current_pose @ np.append(g.mu, 1.0))[:3]
            
        global_gaussians.extend(new_gaussians)
        
        # Global optimization with all frames up to t
        global_gaussians = optimize_global_gaussians(global_gaussians, frames[:t+1], intrinsics, steps=50)
        
    return global_gaussians, current_pose

def initialize_gaussians_from_depth(depth_map, intrinsics, height, width):
    gaussians = []
    for i in range(height):
        for j in range(width):
            z = depth_map[i, j]
            if z > 0:
                # Unproject using identity pose and intrinsics
                pt = np.linalg.inv(intrinsics) @ np.array([j, i, 1.0]) * z
                g = Gaussian(
                    mu=pt,
                    alpha=0.5,
                    sh_coeffs=np.zeros(3),
                    scale=np.array([0.01, 0.01, 0.01]),
                    rotation=np.array([1.0, 0.0, 0.0, 0.0])
                )
                gaussians.append(g)
    return gaussians

def optimize_global_gaussians(gaussians, frame_sequence, intrinsics, steps=50):
    # Optimizes global set using all previous frames and poses
    for _ in range(steps):
        total_loss = 0.0
        for t, frame in enumerate(frame_sequence):
            pose = np.eye(4)  # [G] Accumulated pose for frame t
            rendered = render_gaussians(gaussians, pose, intrinsics)
            total_loss += photometric_loss(rendered, frame)
        # [G] Backpropagation updates all Gaussian attributes
        pass
    return gaussians
```

**Edge Cases and Pitfalls**
*   **Large Camera Motion:** The method performs well when camera motion is large, unlike some unposed methods [S1].
*   **Depth Accuracy:** Relies on the accuracy of the monocular depth network (DPT) for initialization [S1].
*   **Accumulation of Errors:** Sequential pose estimation may accumulate errors over time, though the global optimization step helps mitigate this [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1].
*   **Memory Complexity:** Not given in the sources [S1].
*   **Performance:** Performs on par with Nope-NeRF for small camera motion and outperforms it significantly for large camera changes (e.g., 360-degree videos) [S1].
*   **Strengths:** No SfM preprocessing required; handles large camera motions; leverages temporal continuity [S1].
*   **Limitations:** Requires video input (temporal continuity); relies on monocular depth estimation [S1].
*   **When to Use:** When camera poses are unknown and SfM is not feasible or desired, especially for video sequences with significant motion [S1].
*   **When Not to Use:** When static images are available with known poses (standard 3DGS is faster and more accurate); when monocular depth estimation is unreliable [S1].
