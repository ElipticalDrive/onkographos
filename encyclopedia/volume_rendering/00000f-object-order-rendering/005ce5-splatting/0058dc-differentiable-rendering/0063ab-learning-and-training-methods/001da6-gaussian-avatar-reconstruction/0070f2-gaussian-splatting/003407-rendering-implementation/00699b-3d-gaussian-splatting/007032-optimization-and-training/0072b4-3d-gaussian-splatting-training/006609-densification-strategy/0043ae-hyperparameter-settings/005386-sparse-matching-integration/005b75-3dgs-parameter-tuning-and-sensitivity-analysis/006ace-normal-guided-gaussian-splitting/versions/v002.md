# Normal-Guided Gaussian Splitting

Also called: Geometry-aware splitting with normal guidance, Normal-guided positioning

## Overview
Normal-Guided Gaussian Splitting is a densification strategy for 3D Gaussian Splatting that determines the initial 3D position of a newly split child Gaussian by projecting a randomly sampled candidate onto the tangent plane of the parent Gaussian, weighted by the local image gradient [S1]. It solves the problem of noisy or misplaced Gaussian splats in weakly textured regions where standard random splitting lacks visual constraints [S1]. Unlike methods relying on true-scaled depth priors from Structure-from-Motion (SfM), this approach avoids errors from unreliable SfM points or scale inconsistencies across frames [S1].

## How it works
**Inputs:**
- Parent Gaussian $G_a$ with mean $\mu_a$ and covariance $\Sigma_a$ [S1].
- Reference view $V^{(a)}$ (camera pose and intrinsics) [S1].
- Reference image $I_V^{(a)}$ [S1].
- Normal map $N_V^{(a)}$ corresponding to the reference view [S1].
- A randomly sampled candidate position $\mu_b^c$ within the elliptical scale of $G_a$ [S1].

**Outputs:**
- Optimized child Gaussian mean $\mu_c$ [S1].

**Data Structures:**
- $\mu_a \in \mathbb{R}^3$: Parent mean [S1].
- $\mu_b^c \in \mathbb{R}^3$: Randomly sampled candidate mean [S1].
- $N_V^{(a)}(\bar{x}_a) \in \mathbb{R}^3$: Normal vector at projected pixel $\bar{x}_a$ [S1].
- $\nabla I_V^{(a)}(\bar{x}_c) \in \mathbb{R}$: Scalar image gradient magnitude at projected pixel $\bar{x}_c$ [S1].

**Steps:**
1. **Project Parent:** Project the parent Gaussian $G_a$ to the reference view $V^{(a)}$ to obtain the 2D pixel coordinate $\bar{x}_a$ [S1].
2. **Project Candidate:** Project the randomly sampled candidate position $\mu_b^c$ to the reference view $V^{(a)}$ to obtain the 2D pixel coordinate $\bar{x}_c$ [S1].
3. **Retrieve Normal:** Retrieve the surface normal vector $N_V^{(a)}(\bar{x}_a)$ from the normal map at pixel $\bar{x}_a$ [S1].
4. **Retrieve Gradient:** Retrieve the image gradient magnitude $\nabla I_V^{(a)}(\bar{x}_c)$ from the reference image at pixel $\bar{x}_c$ [S1].
5. **Compute Tangent Projection:** Calculate the perpendicular projection $\mu^\perp$ of the candidate $\mu_b^c$ onto the tangent plane of the parent Gaussian. The tangent plane is defined by point $\mu_a$ and normal $N_V^{(a)}(\bar{x}_a)$ [S1].
6. **Compute Final Position:** Calculate $\mu_c$ using the weighted combination of the candidate and the tangent projection, weighted by the image gradient [S1].

**Formulas:**
The tangent projection $\mu^\perp$ is computed as:
$$ \mu^\perp = \mu_b^c - ((\mu_b^c - \mu_a) \cdot N_V^{(a)}(\bar{x}_a))N_V^{(a)}(\bar{x}_a) $$
where $N_V^{(a)}(\bar{x}_a)$ is the unit normal vector [S1].

The final child mean $\mu_c$ is computed as:
$$ \mu_c = (\mu_b^c - \mu^\perp)\nabla I_V^{(a)}(\bar{x}_c) + \mu^\perp $$
where $\nabla I_V^{(a)}(\bar{x}_c)$ acts as a weight [S1].

**Parameters:**
- Image gradient $\nabla I$: Serves as a dynamic weight. In weakly textured regions (small gradients), the child stays close to the geometric surface ($\mu_c \approx \mu^\perp$). In fully textured areas (large gradients), the randomness of sampling is preserved ($\mu_c \approx \mu_b^c$) [S1].

**Edge Cases and Pitfalls:**
- **Weakly Textured Regions:** Standard splitting may place splats incorrectly due to lack of visual details. This method handles it by enforcing proximity to the parent's geometric surface via the normal vector [S1].
- **Scale Inconsistency:** Unlike methods using true-scaled depth priors (e.g., DAv2 alignment), this method does not require true scale, avoiding errors from unreliable SfM points or scale inconsistency across frames [S1].

**Pseudocode:**
```python
def normal_guided_splitting(parent_mean, candidate_mean, normal_map, image, camera_intrinsics, camera_pose):
    # Step 1: Project parent to reference view
    parent_h = list(parent_mean) + [1.0]
    parent_cam = mat_vec_mul(camera_pose, parent_h)
    x_bar_a = project_to_pixel(parent_cam[:3], camera_intrinsics)

    # Step 2: Project candidate to reference view
    candidate_h = list(candidate_mean) + [1.0]
    candidate_cam = mat_vec_mul(camera_pose, candidate_h)
    x_bar_c = project_to_pixel(candidate_cam[:3], camera_intrinsics)

    # Step 3: Retrieve normal at parent's projected pixel
    normal_vec = normal_map(x_bar_a)

    # Step 4: Retrieve image gradient at candidate's projected pixel
    grad_mag = compute_gradient_magnitude(image, x_bar_c)

    # Step 5: Compute perpendicular projection mu_perp
    diff = [candidate_mean[i] - parent_mean[i] for i in range(3)]
    projection_scalar = dot_product(diff, normal_vec)
    mu_perp = [candidate_mean[i] - projection_scalar * normal_vec[i] for i in range(3)]

    # Step 6: Compute final child mean mu_c
    child_mean = [(candidate_mean[i] - mu_perp[i]) * grad_mag + mu_perp[i] for i in range(3)]

    return child_mean

def mat_vec_mul(M, v):
    return [sum(M[i][j] * v[j] for j in range(4)) for i in range(4)]

def dot_product(u, v):
    return sum(u[i] * v[i] for i in range(len(u)))

def project_to_pixel(point_cam, K):
    x, y, z = point_cam[0], point_cam[1], point_cam[2]
    if z == 0:
        z = 1e-6
    u = K[0][0] * (x / z) + K[0][2]
    v = K[1][1] * (y / z) + K[1][2]
    return [u, v]

def compute_gradient_magnitude(image, pixel):
    u, v = pixel[0], pixel[1]
    # Standard finite difference gradient magnitude [G]
    Ix = image[v][u + 1] - image[v][u - 1]
    Iy = image[v + 1][u] - image[v - 1][u]
    return (Ix ** 2 + Iy ** 2) ** 0.5
```

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** Produces cleaner, more reasonably and accurately distributed splats, offering superior rendering quality (SSIM, PSNR, LPIPS) compared to methods relying on true-scaled depth priors [S1].
- **Strengths:** Effective in weakly textured regions; avoids errors from unreliable SfM points [S1].
- **Limitations:** Relies on the availability and accuracy of normal maps and image gradients [S1].

## Background
Originated in the GeoTexDensifier paper, which combines texture-aware densification and geometry-aware splitting strategies [S1]. It was developed to address the limitations of standard random splitting in 3D Gaussian Splatting, particularly in areas with low visual detail [S1].
