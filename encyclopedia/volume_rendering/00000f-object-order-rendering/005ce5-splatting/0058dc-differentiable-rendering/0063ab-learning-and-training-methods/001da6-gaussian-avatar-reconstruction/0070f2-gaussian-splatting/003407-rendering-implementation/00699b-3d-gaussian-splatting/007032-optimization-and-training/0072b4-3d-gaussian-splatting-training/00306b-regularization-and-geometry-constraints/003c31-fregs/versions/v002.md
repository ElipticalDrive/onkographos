# FreGS

Also called: Frequency-aware regularization for 3DGS, Progressive frequency regularization

## Overview
FreGS is a training optimization method for 3D Gaussian Splatting that prevents overfitting and high-frequency artifacts by applying progressive frequency regularization to the primitives [S1, unofficial][S2]. It addresses over-reconstruction by regularizing frequency discrepancies in rendered images, focusing on the frequency domain [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Current 3D Gaussian primitives (position, covariance, opacity, color), camera parameters, ground truth image, and frequency regularization weight $\lambda$ [G].
*   **Output:** Updated Gaussian parameters after one training step [G].

**Data Structures:**
*   **Gaussian Cloud:** Standard 3DGS primitive list [G].
*   **Frequency Domain Representation:** 2D complex arrays from Fourier transforms of rendered and ground truth images [G].

**Method Steps:**
1.  **Render:** Render the current Gaussian cloud to obtain image $I_{render}$ [G].
2.  **Transform:** Compute the 2D Fourier Transform of $I_{render}$ to get $F_{render}$ and of the ground truth $I_{gt}$ to get $F_{gt}$ [G].
3.  **Compute Discrepancy:** Calculate the frequency discrepancy $\mathcal{L}_{freq}$ between $F_{render}$ and $F_{gt}$ [S2].
4.  **Regularize:** Add $\lambda \mathcal{L}_{freq}$ to the total loss [S1, unofficial][S2].
5.  **Backpropagate:** Compute gradients with respect to Gaussian parameters and update them [G].

**Formulas:**
The total loss is:
$$
\mathcal{L}_{total} = \mathcal{L}_{photometric} + \lambda \mathcal{L}_{freq}
$$
where $\mathcal{L}_{freq}$ measures the difference in the frequency domain [S2]. The specific formulation of $\mathcal{L}_{freq}$ is not detailed in the provided sources, but it is described as regularizing frequency discrepancies [S2].

**Parameters:**
*   $\lambda$: Weight for frequency regularization. Typical value not given in sources.

**Edge Cases and Pitfalls:**
*   **Over-smoothing:** Excessive regularization may remove valid high-frequency details [S1, unofficial].
*   **Precision:** Fourier transforms require careful handling of numerical precision [G].

**Pseudocode:**
```python
import numpy as np
import torch

def fregs_step(gaussians, camera, gt_image, lambda_freq):
    # 1. Render current Gaussian cloud to image I_render [G]
    I_render = standard_3dgs_rasterize(gaussians, camera)
    
    # 2. Compute 2D Fourier transforms [G]
    F_render = np.fft.fft2(I_render)
    F_gt = np.fft.fft2(gt_image)
    
    # 3. Compute frequency discrepancy L_freq [S2]
    # Exact formula not provided in sources; standard spectral magnitude difference [G]
    L_freq = np.mean(np.abs(F_render) - np.abs(F_gt))
    
    # 4. Compute total loss [S1, unofficial][S2]
    L_photometric = np.mean(np.abs(I_render - gt_image))
    L_total = L_photometric + lambda_freq * L_freq
    
    # 5. Backpropagate and update parameters [G]
    grads = torch.autograd.grad(L_total, gaussians.parameters)
    gaussians.optimizer_step(grads)
```

## Background
FreGS was introduced to address over-reconstruction in 3D Gaussian Splatting by regularizing frequency discrepancies [S2]. It applies progressive frequency regularization to primitives to prevent overfitting and high-frequency artifacts during training [S1, unofficial].
