# Sensitivity-Aware Vector Clustering

Also called: Niedemayr et al. compression, Niedermayr, Sensitivity-Aware Scene Compression, Sensitivity-Aware Vector Clustering for 3DGS Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering spherical harmonic (SH) coefficients and Gaussian shape parameters (scale and rotation) into compact codebooks [S1, S2]. It distinguishes itself from standard vector quantization by weighting the clustering distance with a sensitivity measure derived from the gradient of the image energy, thereby prioritizing the preservation of parameters that significantly impact rendering quality [S1, S2].

## How it works
**Inputs and Outputs**
*   **Input:** An optimized set of 3D Gaussians, each defined by position, opacity, SH coefficients (color), and shape parameters (rotation quaternion, scale vector) [S1].
*   **Output:** Two codebooks (one for color/SH, one for shape) and a list of Gaussians where each Gaussian stores two indices (32-bit unsigned integers) pointing to entries in the respective codebooks, alongside uncompressed position, opacity, and other attributes [S1].

**Data Structures**
*   **Codebook Entry (Shape):** 4 scalar values for the rotation quaternion plus 3 scalar values for the scaling vector [S1].
*   **Codebook Entry (Color):** The full vector of SH coefficients [S1].
*   **Gaussian Record:** Position (3 floats), Opacity (1 float), Index to Color Codebook (uint32), Index to Shape Codebook (uint32) [S1].

**Algorithm Steps**

1.  **Sensitivity Calculation:**
    Compute the sensitivity $S(p)$ for each parameter $p$ of each Gaussian. This is done by calculating the gradient of the total image energy $E$ with respect to $p$ over all training images [S1, S2].
    $$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p_i}}{\sum_{i=1}^{N} P_i} $$
    Where:
    *   $N$ is the number of training images.
    *   $E_i$ is the total image energy (sum of RGB components) for image $i$.
    *   $P_i$ is the number of pixels in image $i$.
    *   The gradient $\frac{\partial E_i}{\partial p_i}$ is computed via a single backward pass [S1].

2.  **Vector Sensitivity:**
    For a vector $x$ (e.g., a set of SH coefficients or a shape vector), define its sensitivity $S(x)$ as the maximum sensitivity among its components $d$:
    $$ S(x) = \max_d S(x_d) $$
    [S1]

3.  **Codebook Initialization:**
    Initialize codebooks randomly with a uniform distribution within the minimum and maximum values of each parameter [S1].

4.  **Sensitivity-Aware Clustering (k-Means):**
    Perform k-Means clustering using a weighted distance metric.
    *   **Distance Metric:** The distance between a vector $x$ and a centroid $c_k$ is:
        $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
        [S1]
    *   **Centroid Update:** The centroid $c_k$ is updated as the weighted average of assigned vectors:
        $$ c_k = \frac{1}{\sum_{x_i \in A(k)} S(x_i)} \sum_{x_i \in A(k)} S(x_i) x_i $$
        Where $A(k)$ is the set of vectors assigned to centroid $c_k$ [S1].
    *   **Batched Strategy:** To improve performance, use a batched clustering strategy. In each update step, pick a random subset of vectors, compute the update, and update centroids using a moving average with decay factor $\lambda_d$ [S1].
    *   **Normalization Guard:** For shape parameters, clustering normalized covariance matrices may result in non-unit scaling vectors due to floating-point errors. Re-normalize each codebook vector after each update step by dividing it through the trace of the covariance metric [S1].

5.  **High-Sensitivity Exclusion:**
    Identify vectors with sensitivity higher than a threshold $\beta_c$ (for SH coefficients) or $\beta_g$ (for shape). These vectors are excluded from the clustering process and added directly to the codebook to preserve high-impact features [S1].

6.  **Decomposition:**
    After clustering, decompose each codebook entry for shape parameters (covariance matrix) into rotation and scale parameters using eigenvalue decomposition. This is required for quantization-aware training [S1]. The final codebook entry stores 4 quaternion values and 3 scaling values [S1].

7.  **Quantization-Aware Fine-Tuning:**
    Fine-tune the scene parameters (including codebook entries) on the training set to recover information lost during clustering [S1, S2].
    *   **Forward Pass:** Simulate quantization considering a specific number of bits and the moving average of each parameter's min/max values (Min-Max Quantization) [S2].
    *   **Backward Pass:** Ignore the simulated quantization and calculate the gradient for the parameter without quantization [S2].
    *   **Loss:** Use a combined loss function including D-SSIM (typically $\lambda=0.2$) [S2].

8.  **Entropy Encoding:**
    Order the Gaussians according to their positions along a Z-order curve (Morton order) to exploit spatial coherence [S1, S2]. Compress the set of Gaussians and codebooks using DEFLATE (LZ77 + Huffman) [S1, S2].

import numpy as np

def compute_sensitivity(optimization_state, training_images, num_images):
    """
    Computes sensitivity S(p) for each parameter p.
    optimization_state: dict containing gradients dE/dp for all training images.
    training_images: list of image objects with pixel counts P_i.
    """
    total_grad = 0.0
    total_pixels = 0.0
    
    for i in range(num_images):
        # Sum gradients over all pixels in image i
        # Note: In practice, this aggregates the gradient magnitude
        grad_sum = np.sum(optimization_state['gradients'][i])
        total_grad += grad_sum
        total_pixels += training_images[i].pixel_count
        
    sensitivity = total_grad / total_pixels
    return sensitivity

def sensitivity_aware_kmeans(vectors, sensitivities, k, decay_factor, batch_size, max_iterations):
    """
    Performs sensitivity-aware k-Means clustering.
    vectors: array of shape (N, D)
    sensitivities: array of shape (N,)
    k: number of centroids
    decay_factor: lambda_d for moving average update
    """
    # Initialize centroids randomly within min/max of vectors
    centroids = np.random.uniform(vectors.min(axis=0), vectors.max(axis=0), size=(k, vectors.shape[1]))
    
    for iteration in range(max_iterations):
        # Batched strategy: pick random subset
        indices = np.random.choice(vectors.shape[0], size=batch_size, replace=False)
        batch_vectors = vectors[indices]
        batch_sens = sensitivities[indices]
        
        # Assign vectors to nearest centroid using weighted distance
        # D(x, ck) = S(x) * ||x - ck||^2
        # Argmin over k
        distances = np.zeros((batch_vectors.shape[0], k))
        for j in range(k):
            diff = batch_vectors - centroids[j]
            distances[:, j] = batch_sens * np.sum(diff**2, axis=1)
            
        assignments = np.argmin(distances, axis=1)
        
        # Update centroids using moving average
        new_centroids = centroids.copy()
        for j in range(k):
            mask = assignments == j
            if np.sum(mask) > 0:
                assigned_vecs = batch_vectors[mask]
                assigned_sens = batch_sens[mask]
                # Weighted average
                weight_sum = np.sum(assigned_sens)
                weighted_mean = np.sum(assigned_vecs * assigned_sens[:, np.newaxis], axis=0) / weight_sum
                
                # Moving average update
                new_centroids[j] = (1 - decay_factor) * centroids[j] + decay_factor * weighted_mean
                
        centroids = new_centroids
        
        # Renormalize shape codebook entries if applicable

    return centroids

**Parameters**
*   $\lambda_d$: Decay factor for the moving average in batched clustering. Typical value: 0.8 [S1].
*   Batch size for color features: $2^{18}$ [S1].
*   Batch size for Gaussian parameters: $2^{20}$ [S1].
*   Codebook size $K$: 4096 [S1].
*   $\beta_c$: Sensitivity threshold for SH coefficients. Gaussians with sensitivity $> \beta_c$ are excluded from clustering. Typical value: $6 \times 10^{-7}$ [S1].
*   $\beta_g$: Sensitivity threshold for shape parameters. Typical value: $3 \times 10^{-6}$ [S1].
*   $\lambda$: Weight for the D-SSIM loss term in fine-tuning. Typical value: 0.2 [S2].

**Edge Cases and Pitfalls**
*   **Floating Point Errors:** Clustering normalized covariance matrices can lead to non-unit scaling vectors. This is handled by re-normalizing each codebook vector after each update step by dividing it through the trace of the covariance metric [S1].
*   **High Sensitivity Vectors:** A small percentage (< 5%) of SH coefficients may have very high sensitivity. These must be excluded from clustering and added directly to the codebook to prevent significant rendering errors [S1].

## Operating characteristics
*   **Compression Ratio:** Achieves up to 31× compression on real-world scenes with minimal visual degradation [S1].
*   **Rendering Speed:** Enables real-time rendering on lightweight GPUs, up to 4× higher framerates than optimized GPU compute pipelines for uncompressed 3DGS [S1].
*   **Training Time:** Requires additional steps for sensitivity calculation and quantization-aware fine-tuning (e.g., 5000 optimization steps) [S1].
*   **Strengths:** Significantly reduces memory consumption and improves rendering efficiency for network streaming and low-power devices [S1]. Preserves high-impact features via sensitivity weighting.
*   **Limitations:** Requires access to training images and gradients for sensitivity calculation. The clustering process is iterative and may be slower than simple post-training quantization [S1].

## Background
*   **Origin:** Proposed by Niedemayr et al. in "Compressed 3D Gaussian Splatting for Accelerated Novel View Synthesis" (CVPR 2024) [S1].
*   **History:** Builds on earlier work in volumetric radiance field compression and deep network weight quantization [S1]. It addresses the high storage requirements of 3D Gaussian Splatting, which is dominated by SH coefficients and Gaussian shape parameters [S1].
*   **Usage:** Used for compressed 3D Gaussian splat representations suitable for applications like network streaming and rendering on low-power devices [S1].
