# SH Coefficient Interleaving

Also called: SH Data Layout Interleaving, SH Interleaving

## Overview
SH Coefficient Interleaving packs spherical harmonic (SH) coefficients into a single contiguous array by grouping coefficients by channel rather than by degree [S1, unofficial]. It solves the problem of efficient memory access during rendering by ensuring that all color channels for a specific SH degree are stored adjacently [S1, unofficial]. It differs from non-interleaved layouts by optimizing for vectorized processing of the RGB triplet during the final color computation step [S1, unofficial].

## How it works
**Inputs:**
- `sh_dc`: A 3-component vector representing the zeroth-degree (DC) spherical harmonic coefficients [S1, unofficial].
- `sh_rest`: A 1D array containing the higher-order SH coefficients, with a total size of `3 * coeffs_per_channel` [S1, unofficial].
- `coeffs_per_channel`: The number of higher-order coefficients per channel [S1, unofficial].

**Outputs:**
- `result`: A 1D array containing the interleaved SH data, with a total size of `3 + (3 * coeffs_per_channel)` [S1, unofficial].

**Data Structure:**
The output array is structured as follows:
1. The first 3 elements are `sh_dc.x`, `sh_dc.y`, `sh_dc.z` [S1, unofficial].
2. The remaining elements are filled by iterating through the SH degrees (indices `i` from `0` to `coeffs_per_channel - 1`) [S1, unofficial]. For each degree `i`, the coefficients for all 3 channels are appended in order: `sh_rest[0 * coeffs_per_channel + i]`, `sh_rest[1 * coeffs_per_channel + i]`, `sh_rest[2 * coeffs_per_channel + i]` [S1, unofficial].

**Algorithm:**
1. Initialize an empty list `result`.
2. Append `sh_dc.x`, `sh_dc.y`, `sh_dc.z` to `result` [S1, unofficial].
3. For `i` from `0` to `coeffs_per_channel - 1`:
    a. For `j` from `0` to `2`:
        i. Calculate the index in the source array: `index = j * coeffs_per_channel + i` [S1, unofficial].
        ii. Append `sh_rest[index]` to `result` [S1, unofficial].

**Pseudocode:**
```python
def interleave_sh_coefficients(sh_dc, sh_rest, coeffs_per_channel):
    result = []
    result.append(sh_dc[0])
    result.append(sh_dc[1])
    result.append(sh_dc[2])
    for i in range(coeffs_per_channel):
        for j in range(3):
            index = j * coeffs_per_channel + i
            result.append(sh_rest[index])
    return result
```

**Parameters:**
- `coeffs_per_channel`: The number of higher-order coefficients per channel [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** Ensure `sh_rest` has exactly `3 * coeffs_per_channel` elements [S1, unofficial]. Accessing `sh_rest[index]` where `index >= len(sh_rest)` will cause an out-of-bounds error [S1, unofficial].
- **Degenerate Input:** If `coeffs_per_channel` is 0, only the DC coefficients are written [S1, unofficial].
