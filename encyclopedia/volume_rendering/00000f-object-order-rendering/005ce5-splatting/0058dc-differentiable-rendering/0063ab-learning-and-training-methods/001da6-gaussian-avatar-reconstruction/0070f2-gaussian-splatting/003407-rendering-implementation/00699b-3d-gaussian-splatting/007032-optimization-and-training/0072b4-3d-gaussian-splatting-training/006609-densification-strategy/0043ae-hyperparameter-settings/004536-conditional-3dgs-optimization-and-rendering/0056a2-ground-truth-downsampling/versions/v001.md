# Ground Truth Downsampling

Also called: Anti-alias Ground Truth Downsampling

## Overview
Ground Truth Downsampling is a technique to adapt a pre-trained 3D Gaussian Splatting (3DGS) model for anti-aliased rendering at lower resolutions (zoom-out) by generating pseudo-ground truth through downsampling high-resolution renderings [S1]. It prevents misguidance from aliased supervision during the optimization of low-resolution (LR) Gaussian renderings [S2]. Unlike Mip-Splatting, which uses filters that only mitigate dilation artifacts, this method achieves better visual effects and improves PSNR by 5dB compared to baseline 3DGS [S1].

## How it works
**Inputs and Outputs:**
- **Input:** A pre-trained 3DGS model (trained on full-resolution $1\times$ images) and the original high-resolution ground truth images.
- **Output:** An adapted 3DGS model optimized for specific lower resolutions (e.g., $1/2\times, 1/4\times, 1/8\times$).

**Data Structures:**
- **3D Gaussians:** Standard 3DGS representation (position, covariance, opacity, spherical harmonics coefficients). No structural changes are required; the adaptation modifies the existing parameters [S1, S2].
- **Pseudo-GT:** Images generated by rendering the scene at the target resolution and then downsampling, or by downsampling the original ground truth images using an anti-aliasing filter [S1, S2].

**Steps:**
1. **Baseline Training:** Train the initial 3DGS model on full-resolution ($1\times$) images [S1].
2. **High-Resolution Rendering:** Render the scene from the trained model at the target lower resolutions (e.g., $1/2\times, 1/4\times, 1/8\times$) [S1].
3. **Pseudo-GT Generation:**
   - **Method A (Mipmap-GS approach):** Downsample the high-resolution renderings generated in Step 2 to create pseudo-ground truth for the target resolution [S1].
   - **Method B (DashGaussian approach):** Downsample the original ground truth images using PyTorch's official anti-alias downsampling algorithm before computing the loss [S2].
4. **Adaptation Optimization:** Optimize the 3D Gaussians using the generated pseudo-GT as supervision for the target resolution [S1, S2].

**Formulas:**
Let $I_{HR}$ be the high-resolution rendering or ground truth image.
Let $D_{AA}(\cdot)$ be the anti-alias downsampling operator.
The pseudo-ground truth $I_{pseudo}$ for a target resolution is:
$$ I_{pseudo} = D_{AA}(I_{HR}) $$
The loss function $\mathcal{L}$ during adaptation is computed between the low-resolution rendering $I_{LR}$ and $I_{pseudo}$:
$$ \mathcal{L} = \mathcal{L}_{recon}(I_{LR}, I_{pseudo}) + \lambda \mathcal{L}_{other} $$
Where $\mathcal{L}_{recon}$ is typically a combination of L1 and D-SSIM losses, and $\mathcal{L}_{other}$ includes standard 3DGS regularization terms [S1, S2].

**Parameters:**
- **Target Resolutions:** $1/2\times, 1/4\times, 1/8\times$ [S1].
- **Downsampling Algorithm:** PyTorch's official anti-alias downsampling implementation [S2].
- **Learning Rate:** Modified schedule specific to the LR optimization stage (details vary by implementation, e.g., DashGaussian uses a distinct learning rate schedule) [S2].

**Edge Cases and Pitfalls:**
- **Dataset Dependency:** The quality of pseudo-GT varies by dataset. For the Blender dataset (isolated objects), supervision is intensive and high quality. For Mip-NeRF 360, pseudo-GT has limited quality and provides weaker guidance [S1].
- **Aliased Supervision:** Failing to use anti-aliasing when downsampling ground truth can lead to misguidance that hinders optimization [S2].
- **Convergence Speed:** Convergence is faster for zoom-out tasks compared to zoom-in tasks [S1].

**Pseudocode:**
```python
def ground_truth_downsampling_adaptation(model, gt_images, target_scales):
    """
    Adapts a pre-trained 3DGS model for lower resolutions using ground truth downsampling.
    
    Args:
        model: Pre-trained 3DGS model.
        gt_images: List of high-resolution ground truth images.
        target_scales: List of target resolution scales (e.g., [0.5, 0.25, 0.125]).
        
    Returns:
        adapted_model: The model optimized for the target scales.
    """
    # Step 1: Baseline model is already trained on 1x resolution
    
    for scale in target_scales:
        # Step 2: Render at target resolution (or use HR renderings if available)
        # Note: In Mipmap-GS, renderings are generated at the target resolution first
        hr_renderings = render_scene(model, resolution=1.0 / scale)
        
        # Step 3: Generate Pseudo-GT
        # Method A: Downsample HR renderings (Mipmap-GS)
        pseudo_gt = anti_alias_downsample(hr_renderings, scale_factor=scale)
        
        # Method B: Downsample original GT (DashGaussian)
        # pseudo_gt = anti_alias_downsample(gt_images, scale_factor=scale)
        
        # Step 4: Optimize Gaussians using Pseudo-GT
        adapted_model = optimize_gaussians(
            model=model,
            pseudo_gt=pseudo_gt,
            loss_function=combined_loss, # L1 + D-SSIM
            learning_rate_schedule=get_lr_schedule_for_lr_optimization()
        )
        
        # Update model for next scale if sequential, or keep separate models
        model = adapted_model
        
    return adapted_model

def anti_alias_downsample(image, scale_factor):
    """
    Applies PyTorch's official anti-alias downsampling.
    """
    # Using PyTorch's functional API for anti-alias downsampling
    # This typically involves a Gaussian filter followed by strided sampling
    import torch.nn.functional as F
    
    # Ensure image is in correct format (N, C, H, W)
    # Apply Gaussian blur with kernel size dependent on scale_factor
    kernel_size = int(4 * (1 / scale_factor))
    if kernel_size % 2 == 0:
        kernel_size += 1
    sigma = 0.5 * (1 / scale_factor)
    
    blurred = F.gaussian_blur(image, kernel_size=kernel_size, sigma=sigma)
    
    # Downsample by striding
    downsampled = blurred[:, :, ::int(1/scale_factor), ::int(1/scale_factor)]
    
    return downsampled
```

## Subtopics

### Mip-Splatting
Uses filters to mitigate dilation artifacts in zoom-out rendering. Less effective than Ground Truth Downsampling in visual quality and PSNR [S1].

### DashGaussian
Applies Ground Truth Downsampling to optimize 3DGS in 200 seconds, using PyTorch's anti-alias downsampling on ground truth images [S2].

### Scaffold-GS
Improves full-resolution rendering with revised primitive growth but lacks multi-scale deformation, making it less robust for unseen settings like zoom-out [S1].

### Pixel-GS
Similar to Scaffold-GS, improves full-resolution quality but compromises robustness for multi-scale rendering [S1].

## Operating characteristics
- **Time Complexity:** Convergence is faster for zoom-out tasks compared to zoom-in tasks [S1].
- **Memory Complexity:** Not specified. However, keeping active pruning throughout optimization can reduce the number of splatted Gaussians by up to 25% without influencing rendering performance [S1].
- **Measured Performance:** Improves PSNR by 5dB over baseline 3DGS on zoom-out tasks [S1].
- **Scaling:** Effective for resolutions $1/2\times, 1/4\times, 1/8\times$ [S1].
- **Strengths:** Achieves best visual effects for zoom-out; mitigates dilation artifacts better than Mip-Splatting; faster convergence for zoom-out [S1].
- **Limitations:** Performance depends on dataset quality (Blender vs. Mip-NeRF 360); pseudo-GT for complex scenes like Mip-NeRF 360 provides weaker guidance [S1].
- **When to Use:** When anti-aliased zoom-out rendering is required for a pre-trained 3DGS model.
- **When Not to Use:** When zoom-in rendering is the primary goal (convergence is slower) or when dataset characteristics (e.g., complex backgrounds) limit pseudo-GT quality [S1].

## Background
Originated from Mip-NeRF 360 and 3DGS research, Ground Truth Downsampling was introduced to address the issue of aliasing in 3D Gaussian Splatting when rendering at lower resolutions (zoom-out) [S1]. It was further refined in DashGaussian to optimize 3DGS efficiently [S2]. The method leverages the fact that downsampling from high-resolution images involves minimal loss of information, preserving essential scene details [S1].
