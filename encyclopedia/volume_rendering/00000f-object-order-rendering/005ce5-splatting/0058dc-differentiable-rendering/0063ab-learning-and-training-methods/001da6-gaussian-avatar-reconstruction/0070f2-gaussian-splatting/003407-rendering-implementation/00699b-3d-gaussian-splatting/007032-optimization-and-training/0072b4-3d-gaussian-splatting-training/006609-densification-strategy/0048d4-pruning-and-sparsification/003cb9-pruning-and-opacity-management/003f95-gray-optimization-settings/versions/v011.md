# GRay Optimization Settings

Also called: GRayLQ, GRayHQ

## Overview
GRay Optimization Settings define the hyperparameter configurations for training the GRay ray-tracing renderer, which differs from standard 3D Gaussian Splatting (3DGS) by omitting opacity resets and size-based pruning [S1]. It provides two distinct presets: GRayLQ for high-speed, low-quality training and GRayHQ for high-quality reconstruction, allowing users to balance initialization time, optimization duration, and final rendering fidelity [S1].

## How it works
The optimization process manages Gaussian attributes through specific thresholds for alpha values, pruning, and scale decay, alongside spherical harmonic (SH) stepping laziness [S1].

**Inputs and Outputs:**
*   **Inputs:** Training images, initial Gaussian cloud, preset configuration (LQ or HQ).
*   **Outputs:** Optimized Gaussian positions, scales, rotations, opacities, and SH coefficients.

**Data Structures:**
The implementation relies on standard 3DGS attribute buffers (position, scale, rotation, opacity, SH coefficients) but modifies the update logic by disabling opacity resets and size-based pruning [S1].

**Parameters:**
The specific parameter values for each preset are defined below.

**GRayLQ Preset:**
*   Minimum alpha threshold: $\alpha_{\text{min}} = 0.02$ [S1]
*   Generalized exponent: $\alpha_{\text{expo}} = 3$ [S1]
*   Pruning threshold: $\mu_{\text{prune}} = 5 \times 10^{-7}$ [S1]
*   Scale decay factor: $\eta_{\text{decay}} = 0.9998$ [S1]
*   SH stepping laziness threshold: $\alpha_{\text{lazy}} = 12$ [S1]
*   Total iterations: 7500 [S1]
*   Resolution: Half resolution [S1]

**GRayHQ Preset:**
*   Minimum alpha threshold: $\alpha_{\text{min}} = 0.001$ [S1]
*   Generalized exponent: $\alpha_{\text{expo}} = 1$ (matching 3DGS) [S1]
*   Minimum truncation threshold: $\tau_{\text{min}} = 0.001$ (matching 3DGRT) [S1]
*   Initialization binning: Disabled [S1]
*   Pruning threshold: $\mu_{\text{prune}} = 10^{-9}$ [S1]
*   Scale decay: Disabled entirely [S1]
*   Resolution: Half resolution [S1]

**Algorithm Steps:**
1.  Initialize Gaussian cloud. If using GRayHQ, disable initialization binning [S1].
2.  For each iteration $i$ from 1 to $N_{\text{iter}}$:
    a. Render image using ray tracing.
    b. Compute loss against ground truth.
    c. Update Gaussian attributes via gradient descent.
    d. Apply scale decay if enabled (GRayLQ only): $s_{new} = s_{old} \times \eta_{\text{decay}}$ [S1].
    e. Prune Gaussians with opacity below $\mu_{\text{prune}}$ [S1].
    f. If using GRayLQ, apply SH stepping laziness: only update SH coefficients if opacity $> \alpha_{\text{lazy}}$ [S1].
    g. If using GRayHQ, ensure $\tau_{\text{min}}$ constraints are met for ray truncation [S1].
3.  Return final Gaussian set.

**Edge Cases and Pitfalls:**
*   **Convergence Failure:** Disabling the Differentiable Hash Table (DHT) or setting $\tau_{\text{min}}$ too high (e.g., $\ge 0.04$) causes rapid Gaussian expansion and catastrophic quality deterioration (PSNR drops to ~22-24) [S1].
*   **Resolution Dependency:** Experiments are conducted at half resolution; full-resolution performance metrics may vary [S1].

## Subtopics

### GRayLQ Preset
A high-speed, low-quality configuration designed for rapid training. It uses aggressive pruning ($\mu_{\text{prune}} = 5 \times 10^{-7}$), higher alpha thresholds ($\alpha_{\text{min}} = 0.02$), and SH stepping laziness to reduce computation. It is chosen when training time is critical and final visual fidelity is secondary. It trains in under a minute and doubles 3DGS frame rates [S1].

### GRayHQ Preset
A high-quality configuration that matches 3DGS's alpha exponent ($\alpha_{\text{expo}} = 1$) and 3DGRT's truncation threshold ($\tau_{\text{min}} = 0.001$). It disables scale decay and initialization binning, and uses a very low pruning threshold ($\mu_{\text{prune}} = 10^{-9}$) to retain more Gaussians. It is chosen when high PSNR/SSIM is required, accepting significantly longer optimization times (36+ minutes) [S1].

## Operating characteristics
**Time and Memory Complexity:**
*   **GRayLQ:** Initialization time ~1m 58s; Optimization time ~46s. Final Gaussian count: 0.48M (from 3.27M init) [S1].
*   **GRayHQ:** Initialization time ~1m 58s; Optimization time ~36m 11s. Final Gaussian count: 3.79M (from 3.97M init) [S1].

**Measured Performance (Half Resolution):**
*   **GRayLQ:** PSNR 26.23, SSIM 0.839, LPIPS 0.191, FPS 1051 [S1].
*   **GRayHQ:** PSNR 27.41, SSIM 0.847, LPIPS 0.154, FPS 55 [S1].

**Scaling and Trade-offs:**
GRayLQ achieves >2x the frame rate of 3DGS with significantly reduced training time, at the cost of lower PSNR and higher LPIPS [S1]. GRayHQ improves quality over standard GRay settings and approaches 3DGS-DI quality but does not surpass it, with much slower FPS [S1].

**Strengths and Limitations:**
*   **Strengths:** GRay avoids opacity resets and size-based pruning, simplifying the optimization loop [S1]. GRayLQ offers extreme speed.
*   **Limitations:** GRayHQ is slow to optimize. Disabling DHT or using high truncation thresholds leads to instability [S1].

## Background
GRay is a ray-tracing based renderer for 3D Gaussians, introduced in the paper "GRay: Ray Tracing 3D Gaussians Near the Speed of Splats" [S1]. It was developed to provide an alternative to splatting-based rendering while maintaining competitive performance through optimized training settings [S1].
