# InfiniSplat v2
Also called: InfiniSplat

## Overview
InfiniSplat v2 is a feed-forward Gaussian reconstruction method for arbitrary input views that decouples geometry and attribute prediction, uses ground-truth (GT) camera poses for alignment during training, and employs large-angle target view supervision to improve rendering quality under large viewpoint changes [S1, unofficial]. It differs from its parent [Feed-forward Generalizable Reconstruction](16746-feed-forward-generalizable-reconstruction.md) and sibling [DA3-GS](16423-splatt3r.md) by freezing the geometry branch to prevent geometric degradation caused by joint optimization, and by using GT poses to avoid pose errors that misguide the network under large-angle supervision [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $N$ input RGB images $I_C = \{I_i\}_{i \in C}$ and optional pose conditions $Q_C$ (camera intrinsics and poses). In the pose-free setting, $Q_C = \emptyset$ [S1, unofficial].
*   **Outputs:** A set of $M$ 3D Gaussians $\mathcal{G} = \{(\mu_m, \xi_m)\}_{m=1}^M$, where $\mu_m \in \mathbb{R}^3$ is the center and $\xi_m = (\alpha_m, s_m, q_m, c_m)$ contains opacity, three-axis scale, rotation (quaternion), and zeroth-order spherical harmonic (SH) color [S1, unofficial].

**Data Structures:**
*   **Gaussian Set:** Each Gaussian $m$ is defined by $\mu_m, \alpha_m, s_m, q_m, c_m$.
*   **Hidden State:** A 16-dimensional vector $h$ per Gaussian, used in Stage II refinement [S1, unofficial].
*   **KNN Graph:** Global graph storing neighbor indices for the refiner [S1, unofficial].

**Parameters:**
*   Voxel merging side length: $0.004$ in scale-normalized reconstruction frame [S1, unofficial].
*   Opacity pruning threshold $\tau_\alpha$: $0.01$ [S1, unofficial].
*   Mask thresholds: $\tau_{abs} = 0.03$, $\tau_{rel} = 0.01$ [S1, unofficial].
*   $gsplat$ `eps2d`: $10^{-2}$ [S1, unofficial].
*   Stage I learning rates: $10^{-6}$ (last 10 attribute Transformer blocks), $2 \times 10^{-4}$ (Gaussian head) [S1, unofficial].
*   Stage I steps: 25,000 (2,000 warmup, cosine decay to 0.1) [S1, unofficial].
*   Stage II learning rate: $2 \times 10^{-4}$ (cosine decay to 0.1) [S1, unofficial].
*   Stage II steps: 5,000 [S1, unofficial].
*   AdamW: $\beta = (0.9, 0.95)$, global batch size 16, L2 gradient clipping 1.0 [S1, unofficial].
*   Stage II updates: $K_r$ sampled uniformly from $\{1, 2, 3\}$ during training, 3 at inference [S1, unofficial].

**Method Steps:**

1.  **Dual-Branch Feature Extraction:**
    Initialize two branches from pretrained DA3 weights [S1, unofficial].
    *   **Geometry Branch ($\Phi_{geo}$):** Frozen. Predicts depths $\hat{D}$ and cameras $\hat{\Pi}_C$ from $I_C$ and $Q_C$ [S1, unofficial].
    *   **Attribute Branch ($\Phi_{attr}$):** Trainable (last $K$ Transformer blocks fine-tuned). Produces multi-layer patch features $F_C$ from $I_C$ and $Q_C$ [S1, unofficial].

2.  **Scale Alignment and Point Construction (Stage I):**
    *   Express predicted and GT poses relative to their respective reference cameras (first input view in sorted order) [S1, unofficial].
    *   Normalize predicted depths and translations by $s_{norm} > 0$ [S1, unofficial].
    *   Fit an Umeyama similarity transform from the GT trajectory to the normalized predicted trajectory using only input-camera center correspondences. Retain the scale factor $s_C$ [S1, unofficial].
    *   Align GT translations: $t^\star_v = s_C t^\star_v$, while rotations remain unchanged $R^\star_v = R^\star_v$ [S1, unofficial].
    *   Construct Gaussian centers $\mu_m$ from normalized predicted $z$-depth, GT intrinsics, and scale-aligned GT poses [S1, unofficial].
    *   Use a DPT decoder to map $F_C$ to per-pixel attributes $\xi$ [S1, unofficial].
    *   Merge Gaussians using voxel merging (side length 0.004) [S1, unofficial].
    *   Prune Gaussians with opacity $\alpha < \tau_\alpha = 0.01$ [S1, unofficial].
    *   Let the initial scene be $\mathcal{G}_0$ [S1, unofficial].

3.  **Stage I Rendering and Loss:**
    *   Render $\mathcal{G}_0$ into input and target views $v \in V = C \cup T$: $\hat{I}_v = \mathcal{R}(\mathcal{G}_0; \Pi^\star_v)$ [S1, unofficial].
    *   Construct visibility masks $M_v$:
        *   Retain pixel if GT depth $> 10^{-6}$ and passes validity mask.
        *   Retain if at least one input view places it in front of camera, within bounds, with valid sampled depth $d_{src}$, and satisfies $|z_{proj} - d_{src}| \le \max(\tau_{abs}, \tau_{rel} d_{src})$ [S1, unofficial].
    *   Compute LPIPS spatial distance map $d_v = \text{LPIPS}_{spatial}(M_v \odot \hat{I}_v, M_v \odot I_v)$, zeroing invalid regions before normalization [S1, unofficial].
    *   Compute Stage I loss $\mathcal{L}_I$ (Eq. 12 in [S1, unofficial]):
        $$ \mathcal{L}_I = \frac{\sum_{v \in V} \sum_{p} M_v(p) [e_v(p) + d_v(p)]}{\max(1, \sum_{v \in V} \sum_{p} M_v(p))} $$
        where $e_v(p)$ is the RGB-channel-averaged absolute error [S1, unofficial].
    *   Update $\Phi_{attr}$ and Gaussian head.

4.  **Stage II Refinement Architecture:**
    *   Project DPT features to 8 channels via learnable $1 \times 1$ conv, merge using Gaussian voxel groups/weights, and reuse [S1, unofficial].
    *   Initialize 16-dim hidden state $h$ via linear projection [S1, unofficial].
    *   Concatenate: image features, current attributes, gradient feedback, neighbor distances, and hidden states. Project to 64 dims [S1, unofficial].
    *   Process through four KNN Transformer blocks. Each block: single-head attention over 8 neighbors, LayerNorm, MLP, residual connections [S1, unofficial].
    *   Concatenate output with original input. MLP predicts attribute increments $\Delta \xi$ and hidden-state increments $\Delta h$ [S1, unofficial].

5.  **Stage II Feedback and Updates:**
    *   Render current scene into input views. Compute feedback loss $\ell_{fb} = 0.8 L_1 + 0.2 L_{DSSIM}$, where $L_{DSSIM} = (1 - \text{SSIM})/2$ over valid regions [S1, unofficial].
    *   Compute gradients w.r.t Gaussian attributes. Normalize and detach them before entering the shared updater [S1, unofficial].
    *   **Attribute Updates:**
        *   Scales: $s_{new} = s_{old} \exp(\Delta \log s)$ [S1, unofficial].
        *   Opacity-logit, local rotation-vector, RGB-logit: $a \tanh(\text{raw})$ with $a = 0.1, 0.25, 1.0$ respectively [S1, unofficial].
        *   Hidden-state: $0.1 \tanh(\text{raw})$ [S1, unofficial].
        *   Clamp logit inputs to $[10^{-6}, 1-10^{-6}]$ [S1, unofficial].
        *   Gaussian centers, counts, and correspondence remain fixed [S1, unofficial].
    *   **First-Order Surrogate Loss:**
        *   Let $x_k$ collect updated log-scale, opacity-logit, local-rotation, and RGB-logit parameters [S1, unofficial].
        *   Compute rendering gradients on independent leaf copies $z_k = \text{sg}(x_k)$: $r_k = \text{sg}(\nabla_z \mathcal{L}_{render}(z_k))$ [S1, unofficial].
        *   Proxy loss: $\mathcal{L}_{kproxy} = \text{sg}(\mathcal{L}_{render}(z_k)) + \langle x_k - \text{sg}(x_k), r_k \rangle$ [S1, unofficial].
    *   **Multi-Step Objective:**
        *   Outer loss per view: $\ell_{out} = 0.8 L_1 + 0.2 L_{DSSIM} + 0.5 L_{LPIPS}$ [S1, unofficial].
        *   Grouped outer loss after update $k$: $\mathcal{L}_{krender}$ [S1, unofficial].
        *   Total Stage II loss: $\mathcal{L}_{II} = \sum_{k=1}^{K_r} 0.9^{K_r-k} \mathcal{L}_{krender} + 0.1 \mathcal{L}_{opacity}$ [S1, unofficial].
        *   Opacity Regularization: $\mathcal{L}_{opacity} = \frac{1}{M} \sum_{m=1}^M [\text{logit}_\epsilon(\alpha_{m, K_r}) - \text{logit}_\epsilon(\alpha_{m, 0})]^2$, $\epsilon=10^{-6}$ [S1, unofficial].

6.  **Chunked Execution:**
    *   Reuse global KNN graph [S1, unofficial].
    *   Stable sort along longest voxel-coordinate axis [S1, unofficial].
    *   Expand core sets of at most 200,000 points with four-hop neighborhoods [S1, unofficial].
    *   Recursively bisect chunks exceeding 300,000 points by point count along core sets' longest axes, recomputing neighborhoods [S1, unofficial].
    *   Retain only core-point outputs [S1, unofficial].
    *   Use gradient checkpointing during training [S1, unofficial].

## Subtopics

### Feed-forward Generalizable Reconstruction
The parent family of methods that map input images to 3D Gaussians without per-scene optimization. InfiniSplat v2 is a specific instance within this family. [Link](16746-feed-forward-generalizable-reconstruction.md)

### DA3-GS
A sibling method that uses shared multi-view features for depth, camera, and per-pixel Gaussian prediction. InfiniSplat v2 differs by freezing the geometry branch to decouple geometry from attributes. [Link](16423-splatt3r.md)

## Operating characteristics
*   **Time Complexity:** Stage I involves feed-forward encoding and decoding. Stage II involves iterative KNN-based refinement. Chunked execution limits memory usage but adds sorting/neighborhood computation overhead.
*   **Memory Complexity:** Depends on the number of Gaussians $M$. Chunked execution caps core set size to 200,000 points, with recursive bisection for larger sets.
*   **Performance:** Achieves state-of-the-art mean LPIPS and DISTS on six datasets in both pose-conditioned and pose-free settings. In pose-conditioned setting, reduces LPIPS and DISTS by 25.8% and 32.9% respectively compared to strongest baselines [S1, unofficial].
*   **Strengths:** Robust to large viewpoint changes due to large-angle supervision and GT pose alignment. Decoupled geometry prevents flying-point artifacts caused by joint optimization.
*   **Limitations:** Requires GT poses during training for alignment. Pose-free setting relies on reference cameras only for evaluation frame and scale estimation.
*   **When to use:** When high-quality novel view synthesis under large viewpoint changes is required, and GT poses are available for training.
*   **When not to use:** When per-scene optimization is acceptable and GT poses are not available for training (though pose-free inference is supported, training alignment uses GT).

## Background
InfiniSplat v2 was introduced by Lin et al. in 2025/2026 as an improvement over DA3-GS and InfiniSplat. It addresses limitations in Gaussian attribute learning, specifically flying-point artifacts and pose errors under large-angle supervision. The method builds on Depth Anything 3 (DA3) [S1, unofficial].
