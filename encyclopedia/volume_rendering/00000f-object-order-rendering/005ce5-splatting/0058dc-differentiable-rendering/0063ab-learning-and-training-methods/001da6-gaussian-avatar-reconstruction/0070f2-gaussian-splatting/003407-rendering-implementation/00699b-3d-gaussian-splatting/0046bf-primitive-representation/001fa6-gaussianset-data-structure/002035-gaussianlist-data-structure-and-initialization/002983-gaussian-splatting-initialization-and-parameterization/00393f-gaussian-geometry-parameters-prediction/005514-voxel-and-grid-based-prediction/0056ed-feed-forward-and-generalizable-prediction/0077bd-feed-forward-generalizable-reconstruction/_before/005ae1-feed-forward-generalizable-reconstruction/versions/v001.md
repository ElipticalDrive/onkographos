# Feed-forward Generalizable Reconstruction

Also called: Generalizable 3D Gaussian Splatting, Feed-forward 3DGS

## Overview
This family of methods reconstructs 3D Gaussian Splatting (3DGS) representations from input images in a single forward pass, eliminating the per-scene iterative optimization required by standard 3DGS [15832-feed-forward-and-generalizable-prediction.md]. Unlike inverse rendering methods that optimize scene parameters for a specific scene, these models learn a generalizable mapping from image features to Gaussian parameters, enabling real-time reconstruction of unseen scenes [15832-feed-forward-and-generalizable-prediction.md]. They differ from iterative methods by trading per-scene adaptability for inference speed and generalization to novel scenes [15832-feed-forward-and-generalizable-prediction.md].

## Shared principles
All methods in this family share the core objective of mapping input image features to a set of 3D Gaussian parameters $\mathcal{G} = \{\mu, \Sigma, \alpha, c\}$ without per-scene gradient descent.

1.  **Input Representation:** Inputs are typically one or more RGB images $I \in \mathbb{R}^{H \times W \times 3}$. Some methods require known camera poses $P$, while others (e.g., [Splatt3R](16423-splatt3r.md), [ZeroGS](16425-zerogs.md)) predict poses or operate on uncalibrated inputs.
2.  **Feature Encoding:** A shared encoder (e.g., Vision Transformer, CNN) extracts multi-scale features from the input images. Cross-attention or cost volumes are often used to aggregate multi-view information .
3.  **Primitive Prediction:** A decoder head predicts Gaussian attributes. These attributes are usually:
    *   **Mean ($\mu$):** 3D position.
    *   **Covariance ($\Sigma$):** Defined by scale $s$ and rotation $r$ (quaternion or 6D).
    *   **Opacity ($\alpha$):** Scalar.
    *   **Color ($c$):** Spherical Harmonics (SH) coefficients or constant RGB.
4.  **Differentiable Rendering:** The predicted Gaussians are rendered into target views using differentiable rasterization to compute reconstruction losses (e.g., L1, SSIM, LPIPS) for training the network .
5.  **Generalization:** The network is trained on a large dataset of scenes to learn priors about geometry and appearance, allowing inference on unseen scenes .

## Subtopics

### [AnySplat Pipeline](12847-anysplat-pipeline.md)
A transformer-based method that reconstructs 3D Gaussians from uncalibrated multi-view images, predicting poses and depth in a single pass. It differs from others by handling uncalibrated inputs and using a differentiable voxelization module.

### [SparSplat](15813-sparsplat.md)
A sparse-view method using 2D Gaussians to enable coherent TSDF mesh reconstruction. It differs from 3DGS-based siblings by optimizing for surface consistency via 2D primitives, allowing explicit mesh extraction which 3DGS methods fail to provide coherently.

### [Splatt3R](16423-splatt3r.md)
A method for uncalibrated stereo pairs that uses a frozen MASt3R backbone for point cloud prediction. It differs by supervising extrapolated viewpoints beyond the stereo baseline and avoiding camera intrinsics/extrinsics.

### [GlobalSplat](16571-globalsplat.md)
A framework for large-context scenes using a fixed set of global latent tokens. It differs by using an iterative dual-branch encoder to prevent representation bloat and ensure global consistency, unlike methods relying on full self-attention.

## Background
The family originates from the need to accelerate 3D Gaussian Splatting, which traditionally requires minutes of per-scene optimization [15832-feed-forward-and-generalizable-prediction.md]. Early generalizable methods adapted MVSNet-like architectures to predict Gaussian parameters directly . Recent developments incorporate foundation models (MASt3R, DINOv2) to improve geometric priors in sparse or uncalibrated settings [16423-splatt3r.md, 15813-sparsplat.md].
