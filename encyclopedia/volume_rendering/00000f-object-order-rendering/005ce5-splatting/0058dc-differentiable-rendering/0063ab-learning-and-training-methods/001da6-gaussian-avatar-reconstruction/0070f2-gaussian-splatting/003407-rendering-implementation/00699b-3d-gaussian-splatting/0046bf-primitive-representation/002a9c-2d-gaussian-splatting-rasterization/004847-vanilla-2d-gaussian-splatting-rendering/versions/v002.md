# Vanilla 2D Gaussian Splatting Rendering

Also called: 2DGS Renderer, Vanilla2DGSRenderer

## Overview
Renders a scene using 2D Gaussian primitives to compute RGB, alpha, normals, and depth maps via a custom rasterizer [S1, unofficial]. It operates on surfels projected into screen space and accumulates color and geometric attributes via front-to-back alpha compositing [Parent].

## How it works
**Inputs:**
- `means3D`: 3D mean positions of Gaussians [S1, unofficial].
- `means2D`: 2D screen-space mean positions [S1, unofficial].
- `shs` or `colors_precomp`: Spherical Harmonics coefficients or pre-computed colors [S1, unofficial].
- `opacities`: Per-primitive opacity values [S1, unofficial].
- `scales`: Per-primitive scaling factors [S1, unofficial].
- `rotations`: Per-primitive rotations (quaternions) [S1, unofficial].
- `cov3D_precomp`: Pre-computed 3D covariance (optional; if `None`, computed from scales/rotation) [S1, unofficial].
- Camera parameters: Intrinsics (FOV, image dimensions), extrinsics (view/projection matrices) [S1, unofficial].
- `background_color`: Background color for alpha compositing [S1, unofficial].
- `scaling_modifier`: Scaling factor for Gaussian sizes [S1, unofficial].
- `depth_ratio`: Weighting factor for depth estimation (1 for bounded/median, 0 for unbounded/expected) [S1, unofficial].

**Outputs:**
- `render_image`: RGB image [S1, unofficial].
- `render_alpha`: Alpha channel [S1, unofficial].
- `rend_normal`: View-space normals [S1, unofficial].
- `view_normal`: World-space normals [S1, unofficial].
- `rend_dist`: Expected depth [S1, unofficial].
- `surf_depth`: Surface depth (weighted combination) [S1, unofficial].
- `surf_normal`: Surface normals derived from surface depth [S1, unofficial].
- `radii`: Visibility filter (pixels covered by Gaussians) [S1, unofficial].
- `allmap`: Intermediate tensor containing depth, alpha, normals, and distortion [S1, unofficial].

**Data Structures:**
- `allmap`: Tensor with layout: index 0 is expected depth, index 1 is alpha, indices 2-4 are view-space normals, index 5 is median depth, index 6 is depth distortion [S1, unofficial].

**Steps:**
1. Initialize `means2D` with `requires_grad=True` to capture gradients for 2D means [S1, unofficial].
2. Compute `tan_fov_x` and `tan_fov_y` from horizontal and vertical fields of view [S1, unofficial].
3. Configure rasterization settings with image dimensions, FOV tangents, background color, scaling modifier, view/projection matrices, SH degree, camera position, and `prefiltered=False` [S1, unofficial].
4. Instantiate the rasterizer with the configured settings [S1, unofficial].
5. Set `cov3D_precomp` to `None` to allow the rasterizer to compute covariance from scales and rotation [S1, unofficial].
6. Call the rasterizer with `means3D`, `means2D`, `shs`/`colors_precomp`, `opacities`, `scales`, `rotations`, and `cov3D_precomp` to obtain `render_image`, `radii`, and `allmap` [S1, unofficial].
7. Extract `render_alpha` from `allmap` index 1 [S1, unofficial].
8. Extract view-space normals from `allmap` indices 2-4 and transform to world space by multiplying by the transpose of the camera's world-to-camera rotation matrix [S1, unofficial].
9. Extract median depth from `allmap` index 5 and replace NaNs with 0 [S1, unofficial].
10. Extract expected depth from `allmap` index 0, divide by `render_alpha`, and replace NaNs with 0 [S1, unofficial].
11. Compute `surf_depth` as a weighted sum: `surf_depth = depth_ratio * median_depth + (1 - depth_ratio) * expected_depth` [S1, unofficial].
12. Compute `surf_normal` from `surf_depth` using `depth_to_normal`, then multiply by detached `render_alpha` [S1, unofficial].
13. Return dictionary containing all outputs [S1, unofficial].

**Helper Functions:**
- `depth_to_normal(depth_map)`: Reconstruct 3D points from depth map using camera intrinsics and extrinsics, compute spatial derivatives (dx, dy) of the 3D points, compute normal as cross product of derivatives, and normalize [S1, unofficial].
- `depths_to_points(depth_map)`: Compute NDC to pixel projection matrix, create meshgrid of pixel coordinates, compute ray directions, and scale by depth to reconstruct 3D points [S1, unofficial].

    cam_rot_inv = camera.world_to_cam_rotation_matrix.t()
    view_normal = torch.matmul(cam_rot_inv, view_normal)

    # Step 9: Extract median depth [S1, unofficial]
    median_depth = allmap[:, 5, :, :]
    median_depth = torch.nan_to_num(median_depth, nan=0.0)

    # Step 10: Extract and compute expected depth [S1, unofficial]
    expected_depth = allmap[:, 0, :, :]
    expected_depth = torch.where(render_alpha > 0, expected_depth / render_alpha, 0.0)

    # Step 11: Compute surface depth [S1, unofficial]
    surf_depth = depth_ratio * median_depth + (1 - depth_ratio) * expected_depth

    # Step 12: Compute surface normal [S1, unofficial]
    surf_normal = depth_to_normal(surf_depth, camera)
    surf_normal = surf_normal * render_alpha.detach()

    # Step 13: Return results [S1, unofficial]
    return {
        "render_image": render_image, "viewspace_points": means2D,
        "visibility_filter": radii > 0, "radii": radii, "rend_alpha": render_alpha,
        "rend_normal": view_normal, "view_normal": view_normal, "rend_dist": expected_depth,
        "surf_depth": surf_depth, "surf_normal": surf_normal

def depth_to_normal(depth_map, camera):
    # Reconstruct 3D points [S1, unofficial]
    points_3d = depths_to_points(depth_map, camera)
    # Compute spatial derivatives [S1, unofficial]
    dx = torch.diff(points_3d, dim=-2, prepend=points_3d[:, :, -1:, :])
    dy = torch.diff(points_3d, dim=-1, prepend=points_3d[:, :, :, -1:])
    # Compute normal via cross product [S1, unofficial]
    normal = torch.cross(dx, dy, dim=-1)
    return torch.nn.functional.normalize(normal, dim=-1)

def depths_to_points(depth_map, camera):
    # Compute NDC to pixel projection matrix and meshgrid [S1, unofficial]
    h, w = depth_map.shape[-2:]
    y, x = torch.meshgrid(torch.arange(h), torch.arange(w), indexing='ij')
    pixel_coords = torch.stack([x, y], dim=-1).float().to(depth_map.device)
    # Compute ray directions using camera intrinsics [G]
    fx, fy = camera.intrinsics[0, 0], camera.intrinsics[1, 1]
    cx, cy = camera.intrinsics[0, 2], camera.intrinsics[1, 2]
    ray_dirs = torch.stack([
        (pixel_coords[..., 0] - cx) / fx,
        (pixel_coords[..., 1] - cy) / fy,
        torch.ones_like(pixel_coords[..., 0])
    ], dim=-1)
    # Scale by depth [S1, unofficial]
    points_3d = ray_dirs * depth_map.unsqueeze(-1)
    # Transform to world space using camera extrinsics [G]
    points_3d_world = points_3d @ camera.extrinsics[:3, :3].t() + camera.extrinsics[:3, 3]
    return points_3d_world

## Background
Originated from the implementation of 2D Gaussian Splatting in the `gaussian-splatting-lightning` repository [S1, unofficial]. It extends the 3D Gaussian Splatting framework to handle 2D primitives, providing a way to render surfels with geometric attributes [S1, unofficial].
