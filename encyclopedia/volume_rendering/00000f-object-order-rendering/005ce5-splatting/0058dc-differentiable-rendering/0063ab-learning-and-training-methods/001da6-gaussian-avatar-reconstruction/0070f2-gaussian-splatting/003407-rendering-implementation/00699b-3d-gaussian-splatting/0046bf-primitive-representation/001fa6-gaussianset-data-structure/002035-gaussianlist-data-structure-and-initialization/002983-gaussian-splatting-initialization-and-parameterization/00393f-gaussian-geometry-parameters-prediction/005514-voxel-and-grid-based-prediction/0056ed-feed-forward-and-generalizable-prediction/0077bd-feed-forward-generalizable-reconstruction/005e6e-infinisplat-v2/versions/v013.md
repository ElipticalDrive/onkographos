# InfiniSplat v2

Also called: InfiniSplat

## Overview
InfiniSplat v2 is a feed-forward Gaussian reconstruction method for arbitrary input views that decouples geometry and attribute prediction, uses ground-truth (GT) camera poses for alignment during training, and employs large-angle target view supervision to improve rendering quality under large viewpoint changes [S1, unofficial]. It differs from its parent [Feed-forward Generalizable Reconstruction](23796-feed-forward-generalizable-reconstruction.md) and siblings like [DA3-GS](12847-anysplat-pipeline.md) by freezing the geometry branch to prevent geometric degradation caused by joint optimization, and by using GT poses to avoid pose errors that misguide the network under large-angle supervision [S1, unofficial].

## How it works
**Inputs and Outputs:**
The method takes $N$ input RGB images $I_C = \{I_i\}_{i \in C}$ and optional pose conditions $Q_C$ (camera intrinsics and poses). In the pose-free setting, $Q_C = \emptyset$ [S1, unofficial]. The output is a Gaussian scene $G$ consisting of $M$ Gaussians, where each Gaussian $m$ has a center $\mu_m$ and attributes $\xi_m = (\alpha_m, s_m, q_m, c_m)$, representing opacity, three-axis scale, rotation, and zeroth-order spherical-harmonic (SH) color [S1, unofficial].

**Data Structures:**
The scene is represented as a list of Gaussians. Each Gaussian is defined by:
- $\mu_m \in \mathbb{R}^3$: Center position.
- $\alpha_m \in \mathbb{R}$: Opacity.
- $s_m \in \mathbb{R}^3$: Scale (three axes).
- $q_m \in \mathbb{R}^4$: Rotation (quaternion).
- $c_m$: SH color coefficients (zeroth-order, i.e., RGB).

During Stage II, a hidden state $h \in \mathbb{R}^{16}$ is maintained per Gaussian. The KNN graph is stored globally, with core sets and neighborhoods defined by voxel coordinates [S1, unofficial].

**Parameters:**
- Voxel merging side length: $0.004$ in the scale-normalized reconstruction frame [S1, unofficial].
- Opacity pruning threshold $\tau_\alpha$: $0.01$ [S1, unofficial].
- Mask thresholds: $\tau_{abs} = 0.03$, $\tau_{rel} = 0.01$ [S1, unofficial].
- $gspal$ $eps_{2d}$: $10^{-2}$ [S1, unofficial].
- Stage I learning rates: $10^{-6}$ for last ten attribute-backbone Transformer blocks, $2 \times 10^{-4}$ for Gaussian head [S1, unofficial].
- Stage I training steps: $25,000$ steps, $2,000$ steps linear warmup, cosine decay to $0.1$ times peaks [S1, unofficial].
- Stage II learning rate: $2 \times 10^{-4}$, cosine decay to $0.1$ times initial value, $5,000$ steps [S1, unofficial].
- AdamW parameters: $\beta = (0.9, 0.95)$, global batch size $16$, global L2 gradient clipping at $1.0$ [S1, unofficial].

**Steps:**

1. **Initialization and Geometry Prediction:**
   Initialize two branches from pretrained DA3 weights: a frozen geometry branch $\Phi_{geo}$ and a trainable attribute branch $\Phi_{attr}$ [S1, unofficial].
   Predict depths $\hat{C}$ and cameras $\hat{\Pi}_C$ using $\Phi_{geo}(I_C; Q_C)$ [S1, unofficial].
   Predict multi-layer patch features $F_C$ using $\Phi_{attr}(I_C; Q_C)$ [S1, unofficial]. Only the last $K$ Transformer blocks of $\Phi_{attr}$ are fine-tuned; $\Phi_{geo}$ remains frozen [S1, unofficial].

2. **Scale Alignment:**
   Express predicted and GT poses relative to their respective reference cameras (first input view in sorted order) [S1, unofficial].
   Normalize predicted depths and translations by $s_{norm} > 0$ [S1, unofficial].
   Fit an Umeyama similarity transform from the GT trajectory to the normalized predicted trajectory using only input-camera center correspondences, retaining its scale $s_C$ [S1, unofficial].
   Apply scale alignment to translations: $t^\star_v = s_C t^\star_v$, while rotations remain unchanged: $R^\star_v = R^\star_v$ [S1, unofficial].

3. **Gaussian Construction (Stage I):**
   Construct Gaussian centers from normalized predicted $z$-depth, GT intrinsics, and scale-aligned GT poses [S1, unofficial].
   Use Feature projection and a DPT decoder to map $F_C$ to per-pixel attributes $\xi$ [S1, unofficial].
   Perform voxel merging with side length $0.004$ in the scale-normalized reconstruction frame [S1, unofficial].
   Prune Gaussians with opacity below $\tau_\alpha = 0.01$ after merging and before refinement [S1, unofficial]. Let the initial scene be $G_0$ with $M$ Gaussians [S1, unofficial].

4. **Stage I Rendering and Loss:**
   Render initial scene $G_0$ into input and target views $v \in V = C \cup T$: $I^b_v = R(G_0; \Pi^\star_v)$ [S1, unofficial].
   Construct visibility masks $M_v$. A target pixel is retained if it has finite GT depth $> 10^{-6}$, passes validity mask, and satisfies $|z_{proj} - d_{src}| \leq \max(\tau_{abs}, \tau_{rel} d_{src})$ where $z_{proj}$ is point depth in input camera, $d_{src}$ is sampled depth [S1, unofficial].
   Compute LPIPS spatial distance map $d_v = \text{LPIPS}_{spatial}(M_v \odot I^b_v, M_v \odot I_v)$, with invalid regions zeroed before normalization [S1, unofficial].
   Compute Stage I loss $\mathcal{L}_I$ aggregating absolute error $e_v(p)$ and $d_v(p)$ over valid pixels:
   $$ \mathcal{L}_I = \frac{\sum_{v \in V} \sum_p M_v(p) [e_v(p) + d_v(p)]}{\max(1, \sum_{v \in V} \sum_p M_v(p))} $$
   [S1, unofficial].

5. **Stage II Feature Preparation:**
   Project DPT features to 8 channels by learnable $1 \times 1$ conv, merge using Gaussian voxel groups/weights, and reuse [S1, unofficial].
   Initialize 16-dim hidden state via linear projection [S1, unofficial].

6. **Stage II Refinement Loop (Iterative):**
   For each step $k$ (training samples $K_r \in \{1, 2, 3\}$ uniformly, inference uses $K_r=3$):
   
   a. **Feature Concatenation and Processing:**
      Concatenate image features, current attributes, gradient feedback, neighbor distances, and hidden states. Project to 64 dims [S1, unofficial].
      Process by four KNN Transformer blocks. Each block contains single-head attention over eight neighbors, LayerNorm, MLP, and residual connections [S1, unofficial].
      Concatenate output with original input, and use MLP to predict attribute and hidden-state increments [S1, unofficial].

   b. **Attribute Updates:**
      Scales update as $s_{new} = s_{old} \exp(\Delta \log s)$ without residual clipping [S1, unofficial].
      Opacity-logit, local rotation-vector, and RGB-logit increments use elementwise $a \tanh(\text{raw})$, with $a = 0.1, 0.25, 1.0$ respectively [S1, unofficial].
      Hidden-state increments use $0.1 \tanh(\text{raw})$ [S1, unofficial].
      Logit inputs clamped to $[10^{-6}, 1-10^{-6}]$ [S1, unofficial].
      Gaussian centers, counts, and correspondence remain fixed [S1, unofficial].

   c. **Loss Computation:**
      Render current scene into input and target views.
      Compute feedback loss $\ell_{fb} = 0.8 L_1 + 0.2 L_{DSSIM}$, where $L_{DSSIM} = (1 - \text{SSIM})/2$ over valid regions [S1, unofficial].
      Gradients w.r.t Gaussian attributes are normalized and detached before entering shared updater [S1, unofficial].
      Compute outer loss for each supervised view: $\ell_{out} = 0.8 L_1 + 0.2 L_{DSSIM} + 0.5 L_{LPIPS}$ [S1, unofficial].
      Input and target groups each receive weight $0.5$, with equal weights within each group; invalid views are skipped and remaining weights renormalized [S1, unofficial].
      Compute multi-step objective:
      $$ \mathcal{L}_{II} = \sum_{k=1}^{K_r} 0.9^{K_r-k} \mathcal{L}_k^{render} + 0.1 \mathcal{L}_{opacity} $$
      [S1, unofficial].
      Opacity regularization:
      $$ \mathcal{L}_{opacity} = \frac{1}{M} \sum_{m=1}^{M} [\text{logit}_\epsilon(\alpha_m^{K_r}) - \text{logit}_\epsilon(\alpha_m^{0})]^2, \quad \epsilon=10^{-6} $$
      [S1, unofficial].

   d. **First-Order Surrogate Loss:**
      Let $x_k$ collect updated log-scale, opacity-logit, local-rotation, and RGB-logit parameters [S1, unofficial].
      Compute rendering gradients on independent leaf copies $z_k = \text{sg}(x_k)$ to form $r_k = \text{sg}(\nabla_z \mathcal{L}_{render}(z_k))$ [S1, unofficial].
      Proxy loss: $\mathcal{L}_k^{proxy} = \text{sg}(\mathcal{L}_{render}(z_k)) + \langle x_k - \text{sg}(x_k), r_k \rangle$ [S1, unofficial].
      Gradient for trainable parameters $\theta$: $\nabla_\theta \mathcal{L}_k^{proxy} = \begin{pmatrix} r_k \end{pmatrix}^\top \frac{\partial x}{\partial \theta}$ [S1, unofficial].

7. **Chunked Execution:**
   Reuse global KNN graph across steps [S1, unofficial].
   After stable sorting along longest voxel-coordinate axis, expand core sets of at most $200,000$ points with four-hop neighborhoods [S1, unofficial].
   Chunks exceeding $300,000$ points are recursively bisected by point count along core sets' longest axes, with neighborhoods recomputed [S1, unofficial].
   Only core-point outputs retained; training uses gradient checkpointing [S1, unofficial].

**Pseudocode:**

```python
def infinisplat_v2(input_images, gt_poses=None, is_pose_free=False):
    # 1. Initialization
    # Initialize frozen geometry branch and trainable attribute branch from DA3 weights
    phi_geo = load_da3_frozen()
    phi_attr = load_da3_trainable()
    
    # 2. Geometry and Feature Prediction
    pred_depths, pred_cameras = phi_geo(input_images, gt_poses)
    features = phi_attr(input_images, gt_poses)
    
    # 3. Scale Alignment
    # Normalize predicted depths and translations
    s_norm = normalize_scale(pred_depths, pred_cameras)
    norm_pred_depths = pred_depths / s_norm
    norm_pred_trans = pred_cameras.trans / s_norm
    
    # Fit Umeyama transform from GT to normalized predicted using input camera centers
    # Only scale s_C is retained
    s_C = fit_umeyama_scale(gt_poses.trans, norm_pred_trans)
    
    # Apply scale to GT translations for alignment
    aligned_gt_trans = gt_poses.trans * s_C
    aligned_gt_poses = Camera(intrinsics=gt_poses.K, pose=aligned_gt_trans)
    
    # 4. Gaussian Construction
    # Back-project normalized predicted depth using aligned GT poses and intrinsics
    centers = back_project(norm_pred_depths, aligned_gt_poses.K, aligned_gt_poses.P)
    
    # Decode attributes from features
    attributes = decode_attributes(features)
    
    # Voxel merging
    gaussians = voxel_merge(centers, attributes, voxel_side=0.004)
    
    # Prune low opacity
    gaussians = prune_opacity(gaussians, threshold=0.01)
    
    # 5. Stage I Training (Simplified)
    # Render G0 to input and target views
    rendered = render(gaussians, aligned_gt_poses)
    
    # Construct masks
    masks = construct_masks(rendered, gt_depths, tau_abs=0.03, tau_rel=0.01)
    
    # Compute LPIPS
    lpips_map = compute_lpips(rendered, gt_images, masks)
    
    # Compute Loss L_I
    loss_I = compute_loss_I(rendered, gt_images, lpips_map, masks)
    
    # Update phi_attr (last K blocks) and Gaussian head
    update_parameters(phi_attr, gaussians.head, loss_I)
    
    # 6. Stage II Refinement
    # Project features to 8 channels
    projected_features = project_features(features, channels=8)
    
    # Initialize hidden state
    hidden_states = zeros(M, 16)
    
    # KNN Graph construction
    knn_graph = build_knn_graph(gaussians)
    
    for step in range(3): # Inference uses 3 updates
        # Concatenate features, attributes, gradients, distances, hidden states
        input_concat = concatenate(projected_features, gaussians.attributes, 
                                   gradients, neighbor_distances, hidden_states)
        
        # Project to 64 dims
        input_64 = linear_project(input_concat, out_dim=64)
        
        # Process through 4 KNN Transformer blocks
        output = knn_transformer_blocks(input_64, knn_graph, num_blocks=4)
        
        # Predict increments
        attr_increments, hidden_increments = predict_increments(output)
        
        # Update attributes
        # Scales: s_new = s_old * exp(delta_log_s)
        gaussians.scales = gaussians.scales * exp(attr_increments.log_scale)
        
        # Opacity, Rotation, RGB: a * tanh(raw)
        gaussians.opacity_logits = clamp(gaussians.opacity_logits + 0.1 * tanh(attr_increments.opacity_raw), 1e-6, 1-1e-6)
        gaussians.rotation_vec = gaussians.rotation_vec + 0.25 * tanh(attr_increments.rot_raw)
        gaussians.rgb_logits = clamp(gaussians.rgb_logits + 1.0 * tanh(attr_increments.rgb_raw), 1e-6, 1-1e-6)
        
        # Hidden state update
        hidden_states = hidden_states + 0.1 * tanh(hidden_increments)
        
        # Compute Loss L_II
        rendered_refined = render(gaussians, aligned_gt_poses)
        loss_fb = compute_feedback_loss(rendered_refined, gt_images)
        loss_out = compute_outer_loss(rendered_refined, gt_images, masks)
        loss_opacity = compute_opacity_reg(gaussians)
        loss_II = weighted_sum(loss_out, loss_opacity)
        
        # First-order surrogate
        z_k = stop_gradient(gaussians.attributes)
        r_k = stop_gradient(gradient(render(z_k, aligned_gt_poses), z_k))
        proxy_loss = stop_gradient(render(gaussians, aligned_gt_poses)) + dot(gaussians.attributes - stop_gradient(gaussians.attributes), r_k)
        
        update_parameters(phi_attr.refiner, gaussians.refiner_head, proxy_loss)
        
        # Chunked execution for next step (recompute KNN if needed, but graph is reused)
        # Only core points retained
        gaussians = retain_core_points(gaussians)

    return gaussians
```

## Operating characteristics
**Time and Memory Complexity:**
The method uses chunked execution with a global KNN graph. Core sets are limited to $200,000$ points, and chunks exceeding $300,000$ points are recursively bisected [S1, unofficial]. Training uses gradient checkpointing [S1, unofficial].

**Measured Performance:**
Evaluated on six datasets (DL3DV, ETH3D, NRGBD, Mip-NeRF 360, RE10K, DTU) with $N=4, 8, 16$ input views [S1, unofficial]. In the pose-conditioned setting, mean LPIPS and DISTS decrease by $25.8\%$ and $32.9\%$, respectively, compared with the strongest evaluated baselines [S1, unofficial].

**Strengths and Limitations:**
- **Strengths:** Improves rendering quality under large viewpoint changes; decouples geometry and attribute prediction to prevent geometric degradation; uses GT poses to avoid pose errors; effective in both pose-conditioned and pose-free settings [S1, unofficial].
- **Limitations:** Requires GT camera poses for alignment during training; joint optimization of geometry and attributes is avoided, which may limit flexibility in some scenarios [S1, unofficial].

**When to Use:**
Use when high-quality novel view rendering under large viewpoint changes is required, and GT camera poses are available for training alignment [S1, unofficial].

**When Not to Use:**
Avoid if GT camera poses are not available and pose-free performance is critical without the specific large-angle supervision benefits [S1, unofficial].

## Background
InfiniSplat v2 was introduced by Lin et al. in 2025/2026 as an improvement over DA3-GS and InfiniSplat [S1, unofficial]. It addresses limitations in Gaussian attribute learning, such as flying-point artifacts and pose errors, by freezing the geometry branch, using GT poses for alignment, and employing large-angle target view supervision [S1, unofficial].
