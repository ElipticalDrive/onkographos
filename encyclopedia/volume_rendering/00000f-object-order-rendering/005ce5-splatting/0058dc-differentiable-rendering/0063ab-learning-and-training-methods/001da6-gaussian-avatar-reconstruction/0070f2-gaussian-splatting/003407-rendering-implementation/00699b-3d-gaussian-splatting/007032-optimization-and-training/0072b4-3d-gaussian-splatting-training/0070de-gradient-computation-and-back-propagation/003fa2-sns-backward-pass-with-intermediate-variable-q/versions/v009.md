# SNS Backward Pass with Intermediate Variable Q

Also called: SNS Gradient Computation, Skew-Normal 2D Gradient Computation

## Overview
The SNS Backward Pass with Intermediate Variable Q computes exact gradients for 3D Skew-Normal Splatting (SNS) parameters by decoupling the complex interaction between rotation and scale matrices [S1, unofficial]. Unlike standard 3D Gaussian Splatting (3DGS), which computes gradients with respect to the inverse covariance matrix $\Omega^{-1}$ before backpropagating to rotation $R$ and scale $S$, this method introduces an intermediate variable $Q = ARS$ to reformulate the 2D Skew-Normal density [S1, unofficial]. This allows for direct, closed-form gradient computation of the skew parameter $k$, the mean $\mu$, and the shape matrix $Q$, avoiding the high computational complexity of differentiating the coupled $RS$ terms directly [S1, unofficial].

## How it works
The backward pass follows the standard 3DGS architecture, divided into a **rendering stage** and a **preprocessing stage** [S1, unofficial]. The rendering stage evaluates shared auxiliary algebraic terms, and the preprocessing stage uses these terms to compute exact gradients for 3D learnable parameters using derived closed-form expressions [S1, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   Loss gradient w.r.t. rendered color: $\frac{\partial L}{\partial C} \in \mathbb{R}^3$ (per pixel) [S1, unofficial].
    *   2D pixel coordinate: $u \in \mathbb{R}^2$ [S1, unofficial].
    *   2D mean: $\mu^{2D} \in \mathbb{R}^2$ [S1, unofficial].
    *   Intermediate shape matrix: $Q \in \mathbb{R}^{2 \times 2}$, where $Q = ARS$ ($A$ is projection, $R$ rotation, $S$ scale) [S1, unofficial].
    *   Skew parameter: $k \in \mathbb{R}^2$ [S1, unofficial].
    *   Opacity: $o \in \mathbb{R}$ [S1, unofficial].
    *   Color: $c \in \mathbb{R}^3$ [S1, unofficial].
    *   Transmittance up to previous Gaussian: $T_{k-1} = \prod_{j=1}^{k-1} (1 - a_j(u))$ [S1, unofficial].
    *   Opacity gradient: $\frac{\partial L}{\partial a}$, computed by the standard alpha-compositing backward pass over sorted Gaussians [S1, unofficial].
*   **Outputs:**
    *   Gradients: $\frac{\partial L}{\partial c}, \frac{\partial L}{\partial o}, \frac{\partial L}{\partial \mu}, \frac{\partial L}{\partial Q}, \frac{\partial L}{\partial k}$ [S1, unofficial].

### Data Structures and Definitions
Let $\Delta = u - \mu^{2D} \in \mathbb{R}^2$ [S1, unofficial].
Let $\Omega^{2D} = Q Q^\top \in \mathbb{R}^{2 \times 2}$ be the 2D covariance matrix [S1, unofficial].
Let $G_2(\Delta; \Omega^{2D}) = \frac{1}{2\pi \sqrt{\det(\Omega^{2D})}} \exp\left(-\frac{1}{2} \Delta^\top (\Omega^{2D})^{-1} \Delta\right)$ be the standard 2D Gaussian component [S1, unofficial].
Let $\Phi(z) = \frac{1}{2} \left[ 1 + \text{erf}\left(\frac{z}{\sqrt{2}}\right) \right]$ be the cumulative distribution function of the standard normal distribution [S1, unofficial].
Let $m = m^{2D} = \frac{(\Omega^{2D})^{-1} Q k}{\sqrt{1 + k^\top k - k^\top Q^\top (\Omega^{2D})^{-1} Q k}} \in \mathbb{R}^2$ [S1, unofficial].
Let $D = \sqrt{1 + k^\top k - k^\top Q^\top (\Omega^{2D})^{-1} Q k}$ [S1, unofficial].

The 2D Skew-Normal density is:
$$ SN^{2D}(u) = G_2(\Delta; \Omega^{2D}) \cdot \Phi(m^\top \Delta) $$
The opacity is $a(u) = o \cdot SN^{2D}(u)$ [S1, unofficial].

### Auxiliary Variables
To simplify gradient expressions, four auxiliary variables are computed in the rendering stage [S1, unofficial]:

1.  $c_\Delta = \Phi \cdot G_2 \cdot (\Omega^{2D})^{-1} \Delta \in \mathbb{R}^2$
2.  $M_\Delta = \Phi \cdot G_2 \cdot ((\Omega^{2D})^{-1} \Delta) ((\Omega^{2D})^{-1} \Delta)^\top \in \mathbb{R}^{2 \times 2}$
3.  $s_\Delta = \frac{G_2}{\sqrt{2\pi}} \exp \left( -\frac{1}{2} (m^\top \Delta)^2 \right) \in \mathbb{R}$
4.  $p_\Delta = \frac{G_2}{\sqrt{2\pi}} \exp \left( -\frac{1}{2} (m^\top \Delta)^2 \right) \cdot (\Omega^{2D})^{-1} \Delta \in \mathbb{R}^2$

### Numbered Steps

1.  **Compute Gradient w.r.t. Skew-Normal Density:**
    The gradient $\frac{\partial L}{\partial a}$ is provided by the standard compositing backward pass [S1, unofficial].
    $$ \frac{\partial L}{\partial SN^{2D}} = \frac{\partial L}{\partial a} \cdot o $$
    [S1, unofficial]

2.  **Compute Gradient w.r.t. Mean $\mu^{2D}$:**
    Using the auxiliary variables $c_\Delta$ and $s_\Delta$:
    $$ \frac{\partial SN^{2D}}{\partial \mu^{2D}} = c_\Delta - s_\Delta \cdot m $$
    $$ \frac{\partial L}{\partial \mu^{2D}} = \frac{\partial L}{\partial SN^{2D}} \cdot \frac{\partial SN^{2D}}{\partial \mu^{2D}} $$
    [S1, unofficial]

3.  **Compute Gradient w.r.t. Skew Parameter $k$:**
    Using auxiliary variables $p_\Delta$, $m$, $k$, $Q$, $\Omega^{2D}$, and scalar $D$:
    $$ \frac{\partial SN^{2D}}{\partial k} = \frac{1}{D} Q^\top \left( p_\Delta + (p_\Delta^\top \Omega^{2D} m) \cdot m \right) - \frac{1}{D^2} \cdot (p_\Delta^\top \Omega^{2D} m) \cdot k $$
    $$ \frac{\partial L}{\partial k} = \frac{\partial L}{\partial SN^{2D}} \cdot \frac{\partial SN^{2D}}{\partial k} $$
    [S1, unofficial]

4.  **Compute Gradient w.r.t. Shape Matrix $Q$:**
    Using auxiliary variables $M_\Delta$, $p_\Delta$, $m$, $k$, $Q$, and scalar $D$:
    $$ \frac{\partial SN^{2D}}{\partial Q} = \left( M_\Delta - p_\Delta m^\top - m p_\Delta^\top - (p_\Delta^\top \Omega^{2D} m) \cdot m m^\top \right) Q + \frac{1}{D} \left( p_\Delta + (p_\Delta^\top \Omega^{2D} m) \cdot m \right) k^\top $$
    $$ \frac{\partial L}{\partial Q} = \frac{\partial L}{\partial SN^{2D}} \cdot \frac{\partial SN^{2D}}{\partial Q} $$
    [S1, unofficial]

5.  **Compute Gradient w.r.t. Color $c$ and Opacity $o$:**
    $$ \frac{\partial L}{\partial c} = \frac{\partial L}{\partial C} \cdot a(u) \cdot T_{k-1} $$
    $$ \frac{\partial L}{\partial o} = \frac{\partial L}{\partial C} \cdot SN^{2D}(u) \cdot T_{k-1} $$
    [S1, unofficial]

6.  **Map $Q$ Gradients to $R$ and $S$ (Preprocessing Stage):**
    Since $Q = ARS$, and $A$ is constant, gradients w.r.t $R$ and $S$ are derived from $\frac{\partial L}{\partial Q}$ [S1, unofficial].
    $$ \frac{\partial L}{\partial S} = A^\top \frac{\partial L}{\partial Q} R^\top $$
    $$ \frac{\partial L}{\partial R} = A^\top \frac{\partial L}{\partial Q} S^\top $$
    [G] (Exact mapping depends on the parameterization of $R$ and $S$; if $R$ is a quaternion or axis-angle, further chain rule steps are required.)

### Pseudocode

```python
import math
import numpy as np

def compute_sns_gradients(
    dL_da,          # Scalar - Gradient of Loss w.r.t. opacity a (from standard compositing backward pass)
    grad_L_C,       # Shape (3,) - Gradient of Loss w.r.t Rendered Color
    c,              # Shape (3,) - Color
    o,              # Scalar - Opacity
    u,              # Shape (2,) - Pixel coordinate
    mu_2d,          # Shape (2,) - 2D Mean
    Q,              # Shape (2, 2) - Intermediate shape matrix ARS
    k,              # Shape (2,) - Skew parameter
    T_prev          # Scalar - Transmittance from previous Gaussians
):
    """
    Computes gradients for SNS backward pass.
    Returns: grad_c, grad_o, grad_mu, grad_Q, grad_k
    """
    
    # 1. Basic quantities
    Delta = u - mu_2d  # Shape (2,)
    Omega_2D = Q @ Q.T # Shape (2, 2)
    Omega_inv = np.linalg.inv(Omega_2D)
    
    # Gaussian component G2
    det_Omega = np.linalg.det(Omega_2D)
    exponent = -0.5 * (Delta @ Omega_inv @ Delta)
    G2 = (1.0 / (2.0 * np.pi * np.sqrt(det_Omega))) * np.exp(exponent)
    
    # Skew term m
    numerator_m = Omega_inv @ Q @ k
    D_squared = 1.0 + k.T @ k - k.T @ Q.T @ Omega_inv @ Q @ k
    D = np.sqrt(D_squared)
    m = numerator_m / D
    
    # Phi(m^T Delta)
    z = m.T @ Delta
    Phi = 0.5 * (1.0 + math.erf(z / math.sqrt(2.0)))
    
    # 2. Auxiliary Variables
    v = Omega_inv @ Delta
    c_delta = Phi * G2 * v
    M_delta = Phi * G2 * np.outer(v, v)
    s_delta = (G2 / math.sqrt(2.0 * np.pi)) * np.exp(-0.5 * z**2)
    p_delta = s_delta * v
    
    # 3. Gradient w.r.t SN2D
    dL_dSN2D = dL_da * o
    
    # 4. Gradient w.r.t mu_2d
    dSN2D_dmu = c_delta - s_delta * m
    grad_mu = dL_dSN2D * dSN2D_dmu
    
    # 5. Gradient w.r.t k
    term_p_Om_m = np.dot(p_delta, Omega_2D @ m)
    term1 = p_delta + term_p_Om_m * m
    grad_k = dL_dSN2D * ((1.0 / D) * (Q.T @ term1) - (1.0 / D**2) * term_p_Om_m * k)
    
    # 6. Gradient w.r.t Q
    term_mm = term_p_Om_m * np.outer(m, m)
    matrix_part = M_delta - np.outer(p_delta, m) - np.outer(m, p_delta) - term_mm
    grad_Q = dL_dSN2D * (matrix_part @ Q + (1.0 / D) * np.outer(term1, k))
    
    # 7. Gradient w.r.t c and o
    SN2D_val = G2 * Phi
    a_val = o * SN2D_val
    grad_c = grad_L_C * a_val * T_prev
    grad_o = grad_L_C * SN2D_val * T_prev
    
    return grad_c, grad_o, grad_mu, grad_Q, grad_k
```

### Edge Cases and Pitfalls
*   **Singularity in $D$:** If $D \approx 0$, the division by $D$ and $D^2$ in gradients for $k$ and $Q$ becomes unstable. This occurs when $1 + k^\top k - k^\top Q^\top (\Omega^{2D})^{-1} Q k \approx 0$. A small epsilon should be added to $D$ or $D^2$ for numerical stability [G].
*   **Covariance Inversion:** $(\Omega^{2D})^{-1}$ must be computed stably. If $\Omega^{2D}$ is near-singular, use a regularized inverse or SVD-based inversion [G].
*   **Sign of $\mu$ Gradient:** The derivation $\frac{\partial \Delta}{\partial \mu^{2D}} = -I$ is critical. The final formula $c_\Delta - s_\Delta m$ already incorporates this sign. Implementers must ensure they do not negate it again [S1, unofficial].
*   **Batching:** The pseudocode assumes a single pixel. For batched rendering, operations must be vectorized (e.g., using `np.einsum` or batched matrix multiplications) [G].

## Operating characteristics
*   **Time Complexity:** The auxiliary variables require $O(1)$ operations per Gaussian per pixel (matrix inversions are $2 \times 2$). The gradient computations are also $O(1)$. This is comparable to standard 3DGS but avoids the iterative or complex chain-rule steps for $R$ and $S$ inversion [S1, unofficial].
*   **Memory Complexity:** Requires storing auxiliary variables $c_\Delta, M_\Delta, s_\Delta, p_\Delta$ per Gaussian per pixel during the rendering stage. This is slightly higher than standard 3DGS but allows for efficient reuse in the preprocessing stage [S1, unofficial].
*   **Strengths:** Decouples $R$ and $S$ optimization, leading to more stable gradients for shape parameters. Provides closed-form solutions for skew parameter $k$, which is absent in standard 3DGS [S1, unofficial].
*   **Limitations:** Requires careful handling of the skew parameter $k$ and the intermediate variable $Q$. The complexity of the gradient expressions for $Q$ is higher than standard 3DGS covariance gradients [S1, unofficial].

## Background
The SNS (Skew-Normal Splatting) method was introduced to address the limitations of standard 3D Gaussian Splatting in modeling asymmetric shapes [S1, unofficial]. Standard 3DGS uses symmetric 2D Gaussians, which cannot capture skewness [S1, unofficial]. The SNS method introduces a 2D Skew-Normal distribution [S1, unofficial]. The backward pass with intermediate variable $Q$ was proposed to simplify the gradient computation for the shape parameters (rotation and scale) which are coupled in the covariance matrix [S1, unofficial]. This approach was detailed in the paper "3D Skew-Normal Splatting" [S1, unofficial].
