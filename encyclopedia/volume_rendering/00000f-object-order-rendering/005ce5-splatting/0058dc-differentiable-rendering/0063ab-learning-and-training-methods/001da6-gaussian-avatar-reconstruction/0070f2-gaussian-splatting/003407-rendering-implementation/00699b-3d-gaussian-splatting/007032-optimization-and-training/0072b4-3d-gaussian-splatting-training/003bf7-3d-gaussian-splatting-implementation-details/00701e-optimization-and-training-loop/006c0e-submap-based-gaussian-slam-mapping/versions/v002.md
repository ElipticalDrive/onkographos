# Submap-based Gaussian SLAM Mapping

Also called: Gaussian-SLAM mapping process, Incremental submap optimization

## Overview
This method manages the incremental construction of a 3D Gaussian Splatting (3DGS) model within a Simultaneous Localization and Mapping (SLAM) framework by partitioning the scene into localized "submaps" [S1, unofficial]. Unlike global optimization approaches that re-optimize the entire Gaussian set against all historical data, this method restricts optimization to a local subset of Gaussians and keyframes, enabling real-time or near-real-time mapping for large-scale environments [S1, unofficial]. It sets itself apart from standard 3DGS training by integrating depth supervision, camera pose estimation feedback, and dynamic submap lifecycle management (creation, optimization, and checkpointing) [S1, unofficial].

## How it works
The method operates as a loop within a SLAM pipeline, triggered by specific frame intervals or motion heuristics. It relies on a `Mapper` class that processes keyframes, manages the `GaussianModel`, and handles optimization [S1, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   Current frame: Ground truth color tensor, depth tensor, and estimated camera-to-world pose ($T_{c2w}$) [S1, unofficial].
    *   Dataset intrinsics and dimensions [S1, unofficial].
    *   Existing Gaussian model $\mathcal{G}$ [S1, unofficial].
    *   List of existing keyframes [S1, unofficial].
    *   Configuration parameters: `max_iterations`, `new_submap_every`, `new_submap_iterations`, `iterations` [S1, unofficial].
*   **Outputs:**
    *   Updated Gaussian model $\mathcal{G}'$ [S1, unofficial].
    *   Updated list of keyframes [S1, unofficial].
    *   Optimization statistics (PSNR, loss, timing) [S1, unofficial].

### Data Structures
*   **Keyframe Dictionary:** Contains:
    *   `color`: Tensor normalized to $[0, 1]$ and moved to CUDA [S1, unofficial].
    *   `depth`: Tensor moved to CUDA [S1, unofficial].
    *   `render_settings`: Derived from dataset dimensions, intrinsics, and the world-to-camera matrix ($T_{w2c} = T_{c2w}^{-1}$) [S1, unofficial].
*   **Seeding Mask:** A binary mask indicating regions where new Gaussians should be initialized, computed based on the current Gaussian model and the keyframe's depth/color data [S1, unofficial].

### Algorithm Steps
1.  **Keyframe Construction:** Retrieve the current frame's color, depth, and estimated $T_{c2w}$. Compute $T_{w2c} = T_{c2w}^{-1}$. Construct the keyframe dictionary with normalized color, depth, and render settings [S1, unofficial].
2.  **Submap Decision:** Determine if a new submap should be started. This occurs if:
    *   The frame ID matches a predefined interval (`frame_id % new_submap_every == 0` or specific IDs in `new_submap_frame_ids`), OR
    *   A motion heuristic is enabled and the camera motion from the last submap start exceeds thresholds (rotation $> 50^\circ$, translation $> 0.5$ units) [S1, unofficial].
3.  **Submap Initialization (if new):** If `should_start_new_submap` is true, call `start_new_submap`. This saves the current submap's checkpoint, resets the Gaussian model for the new submap, and updates the submap count [S1, unofficial].
4.  **Seeding:** Compute the seeding mask using the current Gaussian model and the keyframe. Call `seed_new_gaussians` with the ground truth color, depth, intrinsics, camera pose, seeding mask, and a `submap` flag to initialize new 3D points (Gaussians) [S1, unofficial].
5.  **Outlier Filtering:** Determine if statistical outlier filtering is applied. This is enabled if the dataset is `TUM_RGBD` or `ScanNet` AND it is not a new submap [S1, unofficial].
6.  **Submap Growth:** Integrate new points from the current keyframe into the Gaussian model. This step grows the submap by adding the seeded Gaussians [S1, unofficial].
7.  **Optimization:** Call `optimize_submap` with the current frame, all existing keyframes, the Gaussian model, and `max_iterations`.
    *   If `is_new_submap` is true, `max_iterations` = `self.new_submap_iterations`.
    *   Otherwise, `max_iterations` = `self.iterations` [S1, unofficial].
    *   The optimization process minimizes the photometric loss (L1 + D-SSIM) and potentially depth loss, using the Adam optimizer [S1, unofficial].
8.  **Keyframe Update:** Append the current frame and its keyframe dictionary to the list of keyframes [S1, unofficial].
9.  **Visualization & Logging:** Render the current Gaussian model using the keyframe's render settings to generate visualization color and depth images. Calculate the PSNR between the rendered color image and the ground truth color image. Log mapping iteration statistics (frame ID, new points count, model size, optimization time, loss) [S1, unofficial].

### Pseudocode

```python
def process_frame(frame_id, current_frame, gaussian_model, keyframes, config, tracker):
    """
    Processes a single frame in the Submap-based Gaussian SLAM mapping loop.
    
    Args:
        frame_id: int, ID of the current frame.
        current_frame: dict, containing 'color', 'depth', 'c2w' (camera-to-world pose).
        gaussian_model: GaussianModel instance.
        keyframes: list of Keyframe dictionaries.
        config: dict, configuration parameters.
        tracker: Tracker instance, provides estimated poses.
        
    Returns:
        gaussian_model: Updated GaussianModel.
        keyframes: Updated list of keyframes.
        stats: dict, optimization statistics.
    """
    # 1. Keyframe Construction
    c2w = current_frame['c2w']
    w2c = inverse(c2w)
    
    # Normalize color to [0, 1] and move to CUDA
    color_tensor = normalize_to_01(current_frame['color']).to('cuda')
    depth_tensor = current_frame['depth'].to('cuda')
    
    # Derive render settings from intrinsics and w2c
    render_settings = derive_render_settings(
        dataset_dims=config['data']['dims'],
        intrinsics=config['data']['intrinsics'],
        w2c=w2c
    )
    
    keyframe = {
        'color': color_tensor,
        'depth': depth_tensor,
        'render_settings': render_settings,
        'frame_id': frame_id
    }
    
    # 2. Submap Decision
    is_new_submap = should_start_new_submap(
        frame_id=frame_id,
        new_submap_frame_ids=tracker.new_submap_frame_ids,
        submap_using_motion_heuristic=config['mapping']['submap_using_motion_heuristic'],
        estimated_c2ws=tracker.estimated_c2ws,
        rot_thre=50,
        trans_thre=0.5
    )
    
    # 3. Submap Initialization (if new)
    if is_new_submap:
        start_new_submap(
            frame_id=frame_id,
            gaussian_model=gaussian_model,
            config=config
        )
        # Note: start_new_submap resets gaussian_model and saves checkpoint
        
    # 4. Seeding
    seeding_mask = compute_seeding_mask(
        gaussian_model=gaussian_model,
        keyframe=keyframe
    )
    
    new_points_count = seed_new_gaussians(
        color=color_tensor,
        depth=depth_tensor,
        intrinsics=config['data']['intrinsics'],
        camera_pose=c2w,
        seeding_mask=seeding_mask,
        gaussian_model=gaussian_model,
        is_new_submap=is_new_submap
    )
    
    # 5. Outlier Filtering
    apply_outlier_filtering = (
        config['data']['dataset_type'] in ['TUM_RGBD', 'ScanNet'] and 
        not is_new_submap
    )
    
    if apply_outlier_filtering:
        gaussian_model.apply_statistical_outlier_filtering()
        
    # 6. Submap Growth
    # seed_new_gaussians typically integrates points, but explicit growth step is noted
    gaussian_model.grow_submap(new_points_count)
    
    # 7. Optimization
    if is_new_submap:
        max_iterations = config['mapping']['new_submap_iterations']
    else:
        max_iterations = config['mapping']['iterations']
        
    optimize_submap(
        current_frame=current_frame,
        keyframes=keyframes,
        gaussian_model=gaussian_model,
        max_iterations=max_iterations,
        config=config
    )
    
    # 8. Keyframe Update
    keyframes.append(keyframe)
    
    # 9. Visualization & Logging
    vis_color, vis_depth = render_gaussian_model(
        gaussian_model=gaussian_model,
        render_settings=keyframe['render_settings']
    )
    
    psnr = calculate_psnr(vis_color, current_frame['color'])
    
    stats = {
        'frame_id': frame_id,
        'new_points_count': new_points_count,
        'model_size': gaussian_model.num_gaussians,
        'optimization_time': get_last_optimization_time(),
        'psnr': psnr,
        'loss': get_last_loss()
    }
    
    log_mapping_stats(stats)
    
    return gaussian_model, keyframes, stats
```

### Parameters
*   `max_iterations`: Number of optimization iterations. Set to `self.new_submap_iterations` if `is_new_submap` is true, otherwise `self.iterations` [S1, unofficial].
*   `new_submap_every`: Interval (in frames) for potential new submap creation [S1, unofficial].
*   `rot_thre`: Rotation threshold for motion heuristic ($50^\circ$) [S1, unofficial].
*   `trans_thre`: Translation threshold for motion heuristic ($0.5$ units) [S1, unofficial].

### Edge Cases and Pitfalls
*   **Motion Heuristic Failure:** If the camera moves slowly, submaps may not be created frequently enough, leading to large, slow-to-optimize submaps. If it moves too fast, excessive submaps may be created, fragmenting the model [S1, unofficial].
*   **Outlier Filtering:** Applying outlier filtering on new submaps is disabled for TUM_RGBD/ScanNet to avoid removing valid new points during initialization [S1, unofficial].
*   **Pose Estimation Error:** The method relies on the tracker's estimated $T_{c2w}$. Errors in pose estimation will propagate into the Gaussian positions and submap alignment [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Optimization is limited to the current submap and keyframes, reducing the number of Gaussians and views processed per iteration compared to global optimization. However, the overhead of submap management and seeding adds constant cost per frame [S1, unofficial].
*   **Memory Complexity:** Memory usage is bounded by the size of the current submap and the keyframe buffer, rather than the entire scene. This allows for mapping of larger scenes than global 3DGS [S1, unofficial].
*   **Strengths:** Enables real-time or near-real-time SLAM by localizing computation. Handles large-scale environments by partitioning the scene.
*   **Limitations:** Potential for drift if submaps are not aligned correctly. Quality may suffer in areas with high motion or insufficient overlap between submaps.
*   **When to Use:** Large-scale SLAM applications where global optimization is too slow or memory-intensive.
*   **When Not to Use:** Small-scale scenes where global optimization is feasible and provides higher accuracy.

## Background
This method is implemented in the `Gaussian-SLAM` repository by Vladimir Yugay [S1, unofficial]. It adapts the 3D Gaussian Splatting rendering and optimization framework to a SLAM context, introducing submap-based optimization to handle incremental scene construction. The approach builds on the principles of 3DGS training but adds SLAM-specific components like pose estimation, keyframe management, and submap lifecycle control [S1, unofficial].
