# Backward Pass for Gaussian Gradients

Also called: Gaussian Splatting Backpropagation, Gradient Computation for Gaussian Parameters, Gaussian Rasterization Backward Pass, Splatter Backpropagation, Splatter backward pass

## Overview
Computes the gradients of a scalar loss with respect to the input 3D Gaussian parameters (color, opacity, mean, scale, rotation) by propagating pixel-level loss gradients backward through the differentiable rasterization process [S2, unofficial]. It enables end-to-end training of Gaussian Splatting models by providing exact analytic gradients for the 2D covariance matrix, 2D means, and 3D attributes via the chain rule [S2, unofficial]. Unlike parent methods that focus on forward projection, this method specifically handles the reverse accumulation of gradients through the alpha-compositing and projection steps [S5, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Gradient of the loss $\mathcal{L}$ with respect to the rendered pixel colors $\frac{\partial \mathcal{L}}{\partial C_i} \in \mathbb{R}^3$ for each pixel $i$ [S4, unofficial]. Saved tensors from the forward pass: `colors_precomp`, `means3D`, `scales`, `rotations`, `cov3Ds_precomp`, `radii`, `dc`, `sh`, `geomBuffer`, `binningBuffer`, `imgBuffer`, `sampleBuffer` [S1, unofficial].
*   **Output:** A tuple of gradients: `grad_means3D`, `grad_means2D`, `grad_dc`, `grad_sh`, `grad_colors_precomp`, `grad_opacities`, `grad_scales`, `grad_rotations`, `grad_cov3Ds_precomp`, and three `None` values [S1, unofficial].

**Data Structures:**
The backward pass operates on the same Gaussian attributes as the forward pass. Key intermediate values saved from the forward pass include the transmittance $T_n$ and the accumulated color contribution $S_n$ for each Gaussian $n$ contributing to a pixel [S2, unofficial]. Gradient tensors are allocated with exact layouts: `dL_dconic` is a float32 tensor of shape $[P, 2, 2]$ storing the 2D conic matrix gradients, and `dL_drotations` is a float32 tensor of shape $[P, 4]$ storing quaternion gradient components [S3, unofficial].

**Numbered Steps:**

1.  **Initialization:** Restore `num_rendered`, `num_buckets`, `raster_settings`, and the saved tensors from the forward pass [S1, unofficial]. Pack arguments for the backward kernel call [S1, unofficial]. Extract $P = \text{means3D.size}(0)$ and $M = \text{sh.size}(1)$ if $\text{sh.size}(0) \neq 0$ else $0$ [S3, unofficial]. Allocate gradient tensors: `dL_dmeans2D` $[P, 3]$, `dL_dcolors` $[P, 3]$, `dL_dopacity` $[P, 1]$, `dL_dmeans3D` $[P, 3]$, `dL_dcov3D` $[P, 6]$, `dL_dsh` $[P, M, 3]$, `dL_dscales` $[P, 3]$, `dL_drotations` $[P, 4]$, `dL_dconic` $[P, 2, 2]$ [S3, unofficial].
2.  **Null Pointer Handling:** Nullify `radii_p`, `colors_p`, and `cov3D_precomp_p` if their respective shape0 dimensions are zero [S3, unofficial].
3.  **Focal Length Calculation:** Calculate focal lengths: $\text{focal\_y} = \text{height} / (2.0 \times \text{tan\_fovy})$ and $\text{focal\_x} = \text{width} / (2.0 \times \text{tan\_fov\_x})$ [S4, unofficial].
4.  **Pixel to Gaussian Gradient Propagation (Back-to-Front):** Iterate through the Gaussians contributing to each pixel in reverse order (back to front) [S5, unofficial].
    *   **Transmittance Update:** Compute $T_{n-1}$ from the saved $T_n$ using:
        $$T_{n-1} = \frac{T_n}{1 - \alpha_{n-1}} \quad (23)$$
        where $\alpha_n$ is the opacity of Gaussian $n$ at the pixel [S5, unofficial].
    *   **Accumulated Color Update:** Compute $S_{n-1}$ iteratively:
        $$S_N(k) = 0$$
        $$S_{n-1}(k) = c_n(k)\alpha_n T_n + S_n(k) \quad (25)$$
        where $c_n(k)$ is the color of Gaussian $n$ in channel $k$ [S5, unofficial].
    *   **Color Gradient:** Compute $\frac{\partial \mathcal{L}}{\partial c_n(k)}$:
        $$\frac{\partial C_i(k)}{\partial c_n(k)} = \alpha_n \cdot T_n \quad (22)$$
    *   **Opacity Gradient:** Compute $\frac{\partial \mathcal{L}}{\partial \alpha_n}$:
        $$\frac{\partial C_i(k)}{\partial \alpha_n} = c_n(k) \cdot T_n - \frac{S_n(k)}{1 - \alpha_n} \quad (24)$$
    *   **Opacity Parameter Gradient:** Compute $\frac{\partial \mathcal{L}}{\partial o_n}$ and $\frac{\partial \mathcal{L}}{\partial \sigma_n}$ (where $\sigma_n$ is the exponent term in the Gaussian PDF):
        $$\frac{\partial \alpha_n}{\partial o_n} = \exp(-\sigma_n)$$
        $$\frac{\partial \alpha_n}{\partial \sigma_n} = -o_n \exp(-\sigma_n) \quad (26)$$
5.  **2D Covariance Gradient:** Compute the gradient of $\sigma_n$ with respect to the inverse 2D covariance matrix $\mathbf{Y} = (\boldsymbol{\Sigma}'_n)^{-1}$:
    $$\frac{\partial \sigma_n}{\partial \mathbf{Y}} = \frac{1}{2} \Delta_n \Delta_n^\top \quad (28)$$
    where $\Delta_n = \mathbf{p}_{(x,y)} - \boldsymbol{\mu}'_n$ is the vector from the 2D mean to the pixel center [S5, unofficial].
    Using the identity $\frac{\partial \mathbf{Y}}{\partial x} = -\mathbf{Y} \frac{\partial \boldsymbol{\Sigma}'_n}{\partial x} \mathbf{Y}$, compute the gradient with respect to $\boldsymbol{\Sigma}'_n$:
    $$\frac{\partial \sigma_n}{\partial \boldsymbol{\Sigma}'_n} = -\frac{1}{2} \boldsymbol{\Sigma}'_n^{-1} \Delta_n \Delta_n^\top \boldsymbol{\Sigma}'_n^{-1} \quad (31)$$
6.  **2D Mean Gradient:** Compute the gradient of $\sigma_n$ with respect to the 2D mean $\boldsymbol{\mu}'_n$:
    $$\frac{\partial \sigma_n}{\partial \boldsymbol{\mu}'_n} = \boldsymbol{\Sigma}'_n^{-1} \Delta_n \quad (27)$$
7.  **Projection Gradient (3D to 2D):** Propagate gradients from 2D space ($\boldsymbol{\mu}', \boldsymbol{\Sigma}'$) to 3D camera coordinates $\mathbf{t}$ and view matrix $\mathbf{T}_{cw}$ [S5, unofficial].
    *   **2D Mean Contribution to $\mathbf{t}$:**
        $$\frac{\partial \mathcal{L}_{\mu'}}{\partial \mathbf{t}} = \frac{1}{2} \mathbf{P}^\top \begin{bmatrix} w/t_w & 0 & 0 & -w \cdot t_x / t_w^2 \\ 0 & h/t_w & 0 & -w \cdot t_y / t_w^2 \end{bmatrix}^\top \frac{\partial \mathcal{L}}{\partial \boldsymbol{\mu}'} \quad (33)$$
        where $\mathbf{P}$ is the projection matrix, $w, h$ are image dimensions, and $t_w$ is the homogeneous coordinate [S5, unofficial].
    *   **2D Covariance Contribution to $\mathbf{t}$:** Compute Jacobians of the projection matrix $\mathbf{J}$ with respect to camera coordinates $t_x, t_y, t_z, t_u$ (Equations 37, 38 in [S5, unofficial]) and aggregate with $\frac{\partial \mathcal{L}}{\partial \boldsymbol{\Sigma}'}$ [S5, unofficial].
    *   **View Matrix and 3D Mean:**
        $$\frac{\partial \mathcal{L}}{\partial \mathbf{T}_{cw}} = \frac{\partial \mathcal{L}}{\partial \mathbf{t}} \mathbf{q}^\top$$
        $$\frac{\partial \mathcal{L}}{\partial \boldsymbol{\mu}} = \mathbf{R}_{cw}^\top \left[ \frac{\partial \mathcal{L}}{\partial t_x} \quad \frac{\partial \mathcal{L}}{\partial t_y} \quad \frac{\partial \mathcal{L}}{\partial t_z} \right]^\top \quad (40)$$
        where $\mathbf{q} = [\boldsymbol{\mu}, 1]^\top$ and $\mathbf{R}_{cw}$ is the rotation component of $\mathbf{T}_{cw}$ [S5, unofficial].
8.  **Scale and Rotation Gradients:** Decompose the 3D covariance $\boldsymbol{\Sigma} = \mathbf{M}\mathbf{M}^\top$ into rotation $\mathbf{R}$ and scale $\mathbf{S}$ [S5, unofficial].
    *   Compute gradients with respect to $\mathbf{R}$ and $\mathbf{S}$ using:
        $$\frac{\partial \mathcal{L}}{\partial \mathbf{R}} = \frac{\partial \mathcal{L}}{\partial \mathbf{M}} \mathbf{S}^\top, \quad \frac{\partial \mathcal{L}}{\partial \mathbf{S}} = \mathbf{R}^\top \frac{\partial \mathcal{L}}{\partial \mathbf{M}} \quad (44)$$
    *   Compute Jacobians of $\mathbf{R}$ with respect to quaternion components $w, x, y, z$ (Equations 45, 46 in [S5, unofficial]) to get gradients for rotations [S5, unofficial].
9.  **Execution:** Call the CUDA backward kernel `_C.rasterize_gaussians_backward` with the unpacked arguments to compute gradients for all Gaussian parameters [S4, unofficial]. Return the tuple of computed gradients [S1, unofficial].

**Pseudocode:**
```python
def backward_pass(dL_dpix, saved_tensors):
    # 1. Restore state and allocate gradient tensors
    P = saved_tensors['means3D'].shape[0]
    M = saved_tensors['sh'].shape[1] if saved_tensors['sh'].shape[0] != 0 else 0
    dL_dmeans2D = torch.zeros(P, 3)
    dL_dcolors = torch.zeros(P, 3)
    dL_dopacity = torch.zeros(P, 1)
    dL_dmeans3D = torch.zeros(P, 3)
    dL_dcov3D = torch.zeros(P, 6)
    dL_dsh = torch.zeros(P, M, 3)
    dL_dscales = torch.zeros(P, 3)
    dL_drotations = torch.zeros(P, 4)
    dL_dconic = torch.zeros(P, 2, 2)
    
    # 2. Handle null pointers for precomputed attributes
    if saved_tensors['radii'].shape[0] == 0: saved_tensors['radii'] = None
    if saved_tensors['colors_precomp'].shape[0] == 0: saved_tensors['colors_precomp'] = None
    if saved_tensors['cov3Ds_precomp'].shape[0] == 0: saved_tensors['cov3Ds_precomp'] = None
    
    # 3. Compute focal lengths
    focal_y = saved_tensors['height'] / (2.0 * saved_tensors['tan_fovy'])
    focal_x = saved_tensors['width'] / (2.0 * saved_tensors['tan_fovx'])
    
    # 4. Iterate pixels and back-to-front Gaussians
    for pixel_idx in range(saved_tensors['height'] * saved_tensors['width']):
        dL_dpix_pixel = dL_dpix[pixel_idx]
        gaussians = saved_tensors['geomBuffer'].pixel_gaussians[pixel_idx]
        T_n = 1.0
        S_n = torch.zeros(3)
        
        for n in reversed(gaussians):
            alpha_n = saved_tensors['conic_opacity'][n, 0]
            c_n = saved_tensors['colors_precomp'][n] if saved_tensors['colors_precomp'] is not None else saved_tensors['geomState'].rgb[n]
            
            # Transmittance and Accumulation updates
            T_n_1 = T_n / (1.0 - alpha_n)
            S_n = c_n * alpha_n * T_n + S_n
            
            # Color gradient
            dL_dc_n = dL_dpix_pixel * alpha_n * T_n
            dL_dcolors[n] += dL_dc_n
            
            # Opacity gradient
            dL_dalpha_n = dL_dpix_pixel * (c_n * T_n - S_n / (1.0 - alpha_n))
            dL_dopacity[n] += dL_dalpha_n
            
            # 2D Mean and Covariance gradients
            delta = saved_tensors['means2D'][n] - pixel_coords
            sigma_grad = -0.5 * torch.inverse(saved_tensors['cov2D'][n]) @ delta @ delta.T @ torch.inverse(saved_tensors['cov2D'][n])
            dL_dconic[n] += sigma_grad
            dL_dmeans2D[n] += torch.inverse(saved_tensors['cov2D'][n]) @ delta
            
            T_n = T_n_1
            
        # 5. Project 2D gradients to 3D space
```

**Edge Cases and Pitfalls:**
*   **Precision:** The computation involves matrix inverses ($\boldsymbol{\Sigma}'_n^{-1}$) and divisions by $(1-\alpha_n)$, which can be numerically unstable if $\alpha_n \approx 1$ [S5, unofficial].
*   **Boundaries:** Gradients for Gaussians outside the viewing frustum or with zero radius are typically zero or undefined, requiring careful handling in the kernel [S4, unofficial].
*   **Degenerate Input:** If a Gaussian has a singular covariance matrix, the inverse in Equation (31) fails [S5, unofficial].

## Subtopics

### Skip Invisible Gaussian Updates
An optional extension that skips parameter updates for Gaussians that are not visible in the current view during the backward pass, based on the idea by Mallick et al. [S7, unofficial]. It identifies invisible Gaussians and omits their parameter update computation [S7, unofficial]. This speeds up training and reduces VRAM usage but slightly degrades quality and can cause inconsistencies and performance regressions compared to the original 3DGS implementation [S7, unofficial]. On Mip-NeRF360 outdoor scenes (RTX 4090), it reduces training time from 5m31s to 3m03s, VRAM from 6.0GiB to 5.1GiB, and Gaussian count from 3.87M to 3.34M, while PSNR drops from 24.72 to 24.59 [S7, unofficial].

### Gradient Derivation for Masked Gaussian Attributes
Analytical derivation of gradients for Gaussian attributes (e.g., mean $\boldsymbol{\mu}$) during rendering, accounting for the multiplicative effect of the selection mask and 2D projection coefficients [S8]. It computes the gradient for $\mu_i$ using the derived formula, substituting the respective attribute for other parameters [S8]. The effective opacity is $\hat{o}_i = o_i \cdot \hat{M}_i$ [S8]. The loss is $L_s = |I_{es} - I_{GT}|$ [S8]. The gradient is:
$$\frac{\partial L_s}{\partial \mu_i} = G_2 \cdot \left( \frac{\partial L_s}{\partial \hat{o}_i} \cdot o_i \cdot \hat{M}_i \right) + o_i \cdot \hat{M}_i \cdot \left( \frac{\partial L_s}{\partial G_2} \cdot \frac{\partial G_2}{\partial \mu_i} \right)$$
where $G_2(i, p)$ is the effect coefficient of the 2D projection of Gaussian $i$ onto pixel $p$ [S8].

### Numerical Stability Handling for Backward Pass
A technique to prevent numerical instabilities during gradient computation by reconstructing intermediate opacity values and clamping/skipping low-opacity Gaussians [S9, unofficial]. In both forward and backward passes, skip blending updates for any Gaussian where opacity $\alpha < \epsilon$ [S9, unofficial]. Clamp opacity $\alpha$ from above with 0.99 [S9, unofficial]. Before including a Gaussian in the forward rasterization pass, compute the accumulated opacity if it were included; stop front-to-back blending before it exceeds 0.9999 [S9, unofficial]. Naïvely reconstructing intermediate opacity by dividing accumulated opacity by Gaussian $\alpha$ is prone to numerical instabilities, such as division by zero [S9, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of Gaussians and pixels, dominated by the C++ kernel execution [S1, unofficial].
*   **Memory Complexity:** Requires saving forward pass intermediates (transmittance, accumulated color) for each Gaussian-pixel interaction, increasing VRAM usage [S2, unofficial].
*   **Measured Performance:** On an RTX 4090, the standard backward pass is the bottleneck for training speed [S4, unofficial]. Skipping invisible Gaussians reduces training time by ~45% and VRAM by ~15% [S4, unofficial].
*   **Strengths:** Provides exact analytic gradients, enabling stable and efficient optimization of Gaussian parameters [S2, unofficial].
*   **Limitations:** High VRAM usage due to saved tensors; potential numerical instability near $\alpha=1$ [S5, unofficial]. Skipping updates can degrade quality [S7, unofficial].
*   **When to use:** When training 3D Gaussian Splatting models and gradients are needed for optimization [S2, unofficial].
*   **When not to use:** When memory is severely constrained and quality degradation from skipping updates is unacceptable [S7, unofficial].

## Background
Originated with the 3D Gaussian Splatting paper by Kerbl et al. (2023), which introduced the differentiable rasterization pipeline [S2, unofficial]. The backward pass implementation was detailed in the appendix of the gsplat library documentation and subsequent analyses [S5, S4, unofficial]. It is a core component of the training loop for Gaussian Avatar Reconstruction and other 3DGS-based methods [S2, unofficial].
