# Feed-forward and Generalizable Prediction

Also called: Feed-forward 3D Gaussian Splatting, Generalizable 3DGS

## Overview
This family encompasses methods that predict a complete 3D Gaussian Splatting (3DGS) representation directly from a set of input images in a single forward pass, eliminating the iterative optimization required by standard 3DGS [Parent](8442-gaussian-geometry-parameters-prediction.md). Unlike iterative approaches, these models generalize across scenes, enabling real-time novel view synthesis and 3D reconstruction from sparse or uncalibrated inputs. They differ from sibling methods by their specific architectural choices for handling multi-view consistency, such as AnySplat's explicit pose prediction and voxelization [12847-anysplat-pipeline.md], FineSplat's dual-stage token grouping [15257-finesplat.md], and SparSplat's use of 2D primitives for surface reconstruction [15813-sparsplat.md].

## Shared principles
All methods in this family share the core mechanism of replacing the iterative optimization loop with a neural network $\Phi$ that maps input images $I$ to Gaussian parameters $\Theta = \{\mu, s, r, \alpha, c\}$.

1.  **Input Representation:** The input is a set of $N$ images $\{I_i\}_{i=1}^N$. Some variants (e.g., [AnySplat](12847-anysplat-pipeline.md)) accept uncalibrated images and predict camera poses, while others (e.g., [FineSplat](15257-finesplat.md), [SparSplat](15813-sparsplat.md)) assume known or predicted poses.
2.  **Feature Extraction:** A shared backbone (often transformer-based or CNN-based) extracts multi-scale features from the input images. Foundation models like DINOv2 or MASt3R are frequently integrated to provide semantic or dense correspondence priors [15813-sparsplat.md].
3.  **Multi-View Aggregation:** To achieve generalization, features from different views are aggregated. Common strategies include:
    *   **Cost Volumes:** Warping features to a target view and computing a cost volume for depth estimation [15813-sparsplat.md].
    *   **Attention Mechanisms:** Using view-wise or 3D spatial attention to exchange information between tokens representing different views [15257-finesplat.md].
    *   **Homography Warping:** Warping features based on relative camera poses [15813-sparsplat.md].
4.  **Parameter Prediction:** The aggregated features are decoded into Gaussian parameters. This often involves predicting depth maps first, which are then unprojected to determine Gaussian means $\mu$, while other parameters ($s, r, \alpha, c$) are predicted per-pixel or per-token [12847-anysplat-pipeline.md, 15257-finesplat.md, 15813-sparsplat.md].
5.  **Differentiable Rendering:** The predicted Gaussians are rendered using differentiable rasterization to compute losses (RGB, depth, geometry) for training the network [12847-anysplat-pipeline.md, 15257-finesplat.md, 15813-sparsplat.md].

## Subtopics

### [AnySplat Pipeline](12847-anysplat-pipeline.md)
AnySplat is a feed-forward method that predicts a complete 3D Gaussian Splatting (3DGS) representation directly from a set of uncalibrated input images, eliminating the need for iterative optimization or known camera poses [12847-anysplat-pipeline.md]. It differs from sibling methods like [FineSplat](15257-finesplat.md) and [SparSplat](15813-sparsplat.md) by explicitly predicting camera poses and depth maps alongside Gaussian parameters, using a differentiable voxelization module to resolve density artifacts common in low-resolution feature backends [12847-anysplat-pipeline.md].

### [FineSplat](15257-finesplat.md)
FineSplat is a feed-forward 3D Gaussian Splatting (3DGS) framework that predicts a set of 3D Gaussian primitives from $N$ context views to enable novel view synthesis [15257-finesplat.md]. It addresses the trade-off between fine-grained visual detail and the computational cost of global multi-view attention by employing a dual-grouping strategy: view-wise token grouping in Stage 1 preserves local detail, while 3D spatial grouping in Stage 2 enables cross-view interaction without global attention costs [15257-finesplat.md]. Unlike sibling methods like YoNoSplat and ZipSplat that use coarser 14x14 patches, FineSplat uses 4x4 patches to maintain higher resolution, achieving superior quality with fewer primitives [15257-finesplat.md].

### [SparSplat](15813-sparsplat.md)
SparSplat is a generalizable, feed-forward model that maps a set of sparse input images to planar surface elements (2D Gaussian Splatting parameters) in a single forward pass to perform 3D shape reconstruction and novel view synthesis [15813-sparsplat.md]. It differs from its sibling [AnySplat Pipeline](12847-anysplat-pipeline.md) and [FineSplat](15257-finesplat.md) by explicitly targeting surface reconstruction via 2D primitives rather than novel view synthesis alone, leveraging 2DGS to ensure multi-view depth consistency required for TSDF fusion [15813-sparsplat.md].

### 3D-aware Image Synthesis via Sparse Voxel Grids
#### definition
- [S1] A 3D-aware image synthesis generator that predicts color and density values on a sparse voxel grid, conditioned on camera pose.
#### step
- [S1] Use a mapping network with 2 layers and 64 channels.
- [S1] Set the channel base to 4000 (reduced from StyleGAN2's 32768) to account for higher parameter count in 3D convolutions.
- [S1] Implement skip connections that add an upsampled version of the output grid of the previous layer to the input of the next layer.
- [S1] Condition the generator on a camera pose represented by a rotation matrix and a translation vector, yielding a 12-dimensional input vector.
- [S1] Output coefficients of spherical harmonics for color; use degree 0 (single coefficient per color channel).
- [S1] Multiply the network's density output by a factor of 30 to facilitate generating high density values for sharp surfaces.

## Background
Feed-forward generalizable 3DGS emerged as a solution to the high computational cost and time requirements of iterative 3D Gaussian Splatting optimization. Traditional 3DGS requires per-scene optimization, which is impractical for large-scale or real-time applications. Early works in generalizable depth estimation and neural radiance fields (NeRF) laid the groundwork for learning scene representations directly from images. The integration of 3D Gaussians into this paradigm allows for faster rendering and explicit geometric representation. Methods like [AnySplat](12847-anysplat-pipeline.md) and [FineSplat](15257-finesplat.md) represent recent advancements in handling uncalibrated inputs and multi-view consistency, respectively. [SparSplat](15813-sparsplat.md) extends this to 2D Gaussians for improved surface reconstruction. The [3D-aware Image Synthesis via Sparse Voxel Grids](#3d-aware-image-synthesis-via-sparse-voxel-grids) variant, described in [VoxGRAF](S1), explores sparse voxel grids for efficient 3D-aware generation, sharing the goal of fast, generalizable 3D representation but using a different primitive structure.
