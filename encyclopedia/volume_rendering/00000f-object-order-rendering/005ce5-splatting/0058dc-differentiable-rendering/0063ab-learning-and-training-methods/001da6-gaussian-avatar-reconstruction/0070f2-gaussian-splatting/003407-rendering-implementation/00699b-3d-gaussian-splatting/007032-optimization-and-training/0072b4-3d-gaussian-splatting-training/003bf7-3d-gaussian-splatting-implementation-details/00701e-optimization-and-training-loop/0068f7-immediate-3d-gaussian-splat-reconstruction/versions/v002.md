# Immediate 3D Gaussian Splat Reconstruction

Also called: Immediate 3D Gaussian Splat Reconstruction Pipeline, Incremental 3D Gaussian Splatting Reconstruction, Incremental 3DGS with Loop Closure, Main Pipeline for Immediate 3D Gaussian Splat Reconstruction, Real-time 3DGS Reconstruction, Streaming 3D Gaussian Splatting Pipeline, Two-Level Matching 3DGS

## Overview
Immediate 3D Gaussian Splat Reconstruction is a streaming pipeline that processes an unordered sequence of RGB images to produce a real-time 3D Gaussian Splatting (3DGS) model [S1]. It addresses the problem of incremental reconstruction from pose-free inputs by maintaining global consistency through loop closure and a covisibility graph, while optimizing Gaussian primitives in real-time [S1]. Unlike batch reconstruction methods, it processes images one by one, ensuring the delay between capture and processing start remains below the time to handle two keyframes (<0.8 s) [S1]. It distinguishes itself from standard 3DGS training by integrating SLAM-like components (feature matching, bundle adjustment, loop closure) directly into the Gaussian optimization loop, enabling immediate reconstruction of large-scale scenes without pre-computed camera poses [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A stream of unordered RGB images $\{I_1, I_2, \dots\}$ [S1].
*   **Output:** A 3DGS reconstruction consisting of optimized Gaussian primitives and camera poses [S1].

**Data Structures:**
1.  **Registered Keyframes ($M$):** A set of keyframes that have been successfully registered to the global map [S1].
2.  **Covisibility Graph ($G_{graph}$):** Structured as a triple $(M, E, W)$, where $M$ is the set of registered keyframes, $E$ is the set of edges between them, and $W$ represents edge weights (covisibility strength) [S1].
3.  **Active Gaussian Primitives ($G_{prims}$):** The set of 3D Gaussians currently in the scene [S1].
4.  **Gaussian Hierarchy ($H$):** A hierarchical structure managing Gaussian primitives based on the graph and image updates [S1].
5.  **Shelf ($Shelf$):** A buffer for unmatched frames that could not be registered in the current step [S1].

**Parameters:**
*   $N=20$: The fixed number of keyframes selected for local bundle adjustment [S1].
*   $\tau_{lc} = 5$: The threshold for the minimum graph distance (hops) between clusters to trigger loop closure [S1].
*   $\tau_v$: The threshold for the minimum number of valid matching pairs required to trigger loop closure [S1].
*   Welding Window ($W$): Defined as the union of the top $N/2$ keyframes from cluster $C_1$ and the top $N/2$ keyframes from cluster $C_2$ [S1].

**Pitfalls:**
*   **Variable Name Collision:** The source pseudocode uses $G$ for both the covisibility graph and active Gaussian primitives. Implementers must distinguish them (e.g., $G_{graph}$ vs $G_{prims}$) to avoid overwriting [S1].
*   **Accumulated Drift:** Without loop closure, accumulated drift causes Gaussians to be optimized incorrectly, introducing spiky artifacts and superimposition [S1].
*   **Memory Constraints:** While the method is efficient, related feed-forward methods (e.g., AnySplat) may run out of memory on high-end hardware (H100) for large scenes like StaticHikes due to VRAM limitations and image size constraints (448x448) [S1].

**Algorithm Steps:**

1.  **Initialization:** Initialize $M \leftarrow \emptyset$, $G_{graph} \leftarrow (\emptyset, \emptyset, \emptyset)$, $G_{prims} \leftarrow \emptyset$, $H \leftarrow \emptyset$, and $Shelf \leftarrow \emptyset$ [S1].
2.  **Bootstrap:** Process the first 8 well-connected keyframes to initialize the reconstruction [S1].
3.  **Iteration:** For each incoming image $I_q$:
    a.  **Matching:** Compute feature matches $V$ and corresponding keyframe indices $K'$ using TwoLevelMatching against $M$ [S1].
        *   *Rotation Invariance:* Extract MixVPR and XFeat features for four rotations (0°, 90°, 180°, 270°). Use MixVPR to detect orientation, then select corresponding XFeat features for matching [S1].
    b.  **Shelving:** If $V = \emptyset$, add $I_q$ to $Shelf$ and skip further processing for this iteration [S1].
    c.  **Graph Update:** Update $G_{graph}$ with $I_q$ and $V$ [S1].
    d.  **Loop Detection:** Call LoopDetection($I_q, K', G_{graph}$) to return a boolean loop flag and two clusters $C_1, C_2$ [S1].
        *   *Condition:* A loop is detected if $d_G(C_1, C_2) > \tau_{lc}$ AND $\min(|C_1|, |C_2|) > \tau_v$, where $d_G$ is the minimum shortest path length (hops) in $G_{graph}$ [S1].
    e.  **Keyframe Selection:** Select a subset $S$ of $N=20$ keyframes from the neighborhood for Local Bundle Adjustment [S1].
    f.  **Local Bundle Adjustment:** Perform LocalBA($S$) [S1].
        *   *Fast BA:* To scale to $N=20$, allow each landmark to be observed by a fixed subset of keyframes in the local window, selected based on covisibility, rather than all keyframes [S1].
    g.  **Loop Closure Handling:** If a loop is detected:
        i.  **Welding:** Execute WeldingBA($C_1, C_2, G_{graph}$) to align the disjoint clusters [S1].
        ii. **Anchor Selection:** Select anchor keyframes $I_{a1} \in C_1$ and $I_{a2} \in C_2$ based on their connection count $c(I, W)$ to the welding window $W$ [S1].
        iii. **Similarity Transform:** Estimate rigid transform $T_\Delta$ and scale change $s_\Delta$ from landmark depth variations. Compose into $S_\Delta = \text{Sim3}(T_\Delta, s_\Delta)$ [S1].
        iv. **Backbone Construction:** Build a backbone path $B$ between $I_{a1}$ and $I_{a2}$ using Dijkstra’s algorithm on $G_{graph}$ with smallest cumulative edge weights [S1].
        v.  **Interpolation:** For each backbone node $I_b$, calculate weight $\alpha(I_b) = \frac{d_G(I_b, I_{a2})}{d_G(I_{a1}, I_{a2})}$ [S1]. Interpolate rotation using 6D representation and scale linearly: $s_{\Delta,b} = s_\Delta^{\alpha(I_b)}$ [S1]. Compute $S_{\Delta,b} = \text{interpSim3}(I, S_\Delta, \alpha(I_b))$ [S1].
        vi. **Propagation:** For keyframes $I_i \notin W$, find closest backbone node $I_b^* = \arg\min_{I_b \in B} d_G(I_i, I_b)$ and apply $T_i^{\text{new}} = S_{\Delta,b^*} \circ T_i^{\text{old}}$ [S1].
    h.  **Gaussian Placement:** Place new Gaussian primitives for $I_q$ into the scene using $G_{graph}$ [S1].
    i.  **Registration:** Add $I_q$ to $M$ [S1].
    j.  **Hierarchy Update:** Update $H$ based on $G_{graph}$ and $I_q$ [S1].
    k.  **Optimization:** Optimize $G_{prims}$ using $M$ and $G_{graph}$ [S1].
    l.  **Shelf Retry:** Attempt to process previously shelved frames using RetryShelved($Shelf, M, G_{graph}$) [S1].
        *   *Shelving Logic:* Continuously compute the best MixVPR match between shelved frames and $M$. If the best match cosine similarity is above the last registered image's similarity, attempt to add the shelved frame. After capture ends, process remaining frames starting from the best VPR match [S1].

**Pseudocode:**

```python
def main_pipeline(image_stream):
    # Initialization
    M = set()
    G_graph = Graph(nodes=set(), edges=set(), weights={})
    G_prims = set()
    H = Hierarchy()
    Shelf = []
    
    # Bootstrap
    bootstrap_images = get_first_8_well_connected_images(image_stream)
    for img in bootstrap_images:
        process_image(img, M, G_graph, G_prims, H, Shelf)
        
    # Stream Processing
    for img in image_stream:
        process_image(img, M, G_graph, G_prims, H, Shelf)

def process_image(I_q, M, G_graph, G_prims, H, Shelf):
    # 1. Matching
    V, K_prime = TwoLevelMatching(I_q, M)
    
    # 2. Shelving
    if not V:
        Shelf.append(I_q)
        return
        
    # 3. Graph Update
    UpdateGraph(G_graph, I_q, V)
    
    # 4. Loop Detection
    loop_flag, C1, C2 = LoopDetection(I_q, K_prime, G_graph)
    
    # 5. Keyframe Selection
    S = SelectKeyframes({I_q}, G_graph, N=20)
    
    # 6. Local Bundle Adjustment
    LocalBA(S, G_graph)
    
    # 7. Loop Closure Handling
    if loop_flag:
        WeldingBA(C1, C2, G_graph)
        BackbonePropagation(G_graph, C1, C2, G_prims)
        
    # 8. Gaussian Placement
    PlaceGaussians(I_q, G_graph, G_prims)
    
    # 9. Registration
    M.add(I_q)
    
    # 10. Hierarchy Update
    UpdateHierarchy(G_graph, H, I_q)
    
    # 11. Optimization
    OptimizeGaussians(M, G_graph, G_prims)
    
    # 12. Shelf Retry
    RetryShelved(Shelf, M, G_graph)

def TwoLevelMatching(I_q, M):
    # Extract MixVPR and XFeat features for 4 rotations
    features_0 = extract_features(I_q, rot=0)
    features_90 = extract_features(I_q, rot=90)
    features_180 = extract_features(I_q, rot=180)
    features_270 = extract_features(I_q, rot=270)
    
    # Detect orientation using MixVPR
    orientation = MixVPR_detect(I_q, M)
    
    # Select corresponding XFeat features based on orientation
    selected_features = get_rotated_features(features_0, features_90, features_180, features_270, orientation)
    
    # Match against registered keyframes
    V, K_prime = match_XFeat(selected_features, M)
    return V, K_prime

def LoopDetection(I_q, K_prime, G_graph):
    # Identify clusters in the covisibility graph
    C1, C2 = find_disjoint_clusters(K_prime, G_graph)
    
    # Check loop closure conditions
    d_G = min_shortest_path_hops(C1, C2, G_graph)
    min_cluster_size = min(len(C1), len(C2))
    
    if d_G > 5 and min_cluster_size > tau_v:
        return True, C1, C2
    return False, None, None

def BackbonePropagation(G_graph, C1, C2, G_prims):
    # Select anchors
    I_a1 = argmax_{I in C1} connection_count(I, W)
    I_a2 = argmax_{I in C2} connection_count(I, W)
    
    # Compute similarity transform
    T_delta = compute_rigid_transform(I_a1)
    s_delta = compute_scale_change(I_a1)
    S_delta = Sim3(T_delta, s_delta)
    
    # Build backbone
    B = Dijkstra(I_a1, I_a2, G_graph)
    
    # Interpolate and propagate
    for I_b in B:
        alpha = distance(I_b, I_a2) / distance(I_a1, I_a2)
        S_delta_b = interpolate_sim3(S_delta, alpha)
        apply_transform(I_b, S_delta_b)
        
    # Propagate to non-welding keyframes
    for I_i in G_graph.nodes - W:
        I_b_star = argmin_{I_b in B} distance(I_i, I_b)
        T_i_new = S_delta_b_star * T_i_old
        update_pose(I_i, T_i_new)
        
    # Relocate Gaussians to correct drift
    relocate_gaussians(G_prims, G_graph)

def LocalBA(S, G_graph):
    # Select landmarks observed by covisibility-based subset
    landmarks = select_covisible_landmarks(S, G_graph)
    # Solve bundle adjustment for keyframes in S
    solve_ba(S, landmarks)
```

## Operating characteristics
*   **Time Complexity:** The method scales linearly with the number of keyframes in the local window for bundle adjustment, unlike previous fast BA solutions that scale quadratically [S1]. The delay between capture and processing start is kept below 0.8 s [S1].
*   **Memory Complexity:** Not given in the sources. However, related feed-forward methods may require significant VRAM for large scenes [S1].
*   **Measured Performance:**
    *   **MipNeRF360:** PSNR 26.29, SSIM 0.839, LPIPS 0.241 in 0:01:17 [S1].
    *   **TUM:** PSNR 24.51, SSIM 0.861, LPIPS 0.174 in 0:01:36 [S1].
    *   **StaticHikes:** PSNR 23.78, SSIM 0.760, LPIPS 0.242 in 0:01:49 [S1].
*   **Strengths:** Real-time incremental reconstruction, robust to rotation via MixVPR/XFeat, handles loop closures to prevent drift, efficient local BA scaling.
*   **Limitations:** Requires feature matching (may fail in textureless regions), dependent on covisibility graph quality, may struggle with very large scenes if memory is constrained (though less so than feed-forward methods).
*   **When to use:** Immediate/incremental 3D reconstruction from unordered image collections, specifically targeting pose-free methods and large-scale scenes [S1].
*   **When not to use:** When pre-computed camera poses are available and batch processing is acceptable, or when real-time incremental updates are not required.

## Background
The method was introduced by Andreas Meuleman, Linus Franke, Boris Zhestiankin, Camille Montemagni, and George Drettakis in the paper "Immediate 3D Gaussian Splat Reconstruction of Unordered Input with Global Consistency" [S1]. It builds on the principles of 3D Gaussian Splatting [Parent] and integrates them with SLAM techniques to enable immediate reconstruction from unordered images. The approach addresses the limitations of previous fast BA solutions by scaling linearly with keyframes and incorporating loop closure to maintain global consistency.
