# 3D Half-Gaussian Splatting Covariance Transformation and Regularization

Also called: 3D-HGS

## Overview
This method modifies the covariance matrix of 3D Gaussians to enforce a "half-Gaussian" geometry, effectively modeling surfaces as half-ellipsoids that are cut by a plane aligned with the surface normal. It solves the problem of volumetric floaters and noise in empty space by ensuring that Gaussian kernels do not extend into empty space behind surfaces, thereby improving geometric accuracy and training efficiency. It sets itself apart from sibling methods like [Frequency Regularization](6130-frequency-regularization.md) and [Hard and Soft Depth Regularization](9178-hard-and-soft-depth-regularization.md) by directly altering the shape of the primitive itself rather than relying solely on external loss terms or depth supervision.

## How it works
The method transforms the standard 3D Gaussian covariance matrix $\Sigma$ into a local coordinate system defined by the surface normal, modifies the diagonal elements to zero out the component along the normal direction (creating a half-ellipsoid), and transforms it back. This transformation is applied periodically during training.

### Inputs and Outputs
*   **Input**: The original 3D Gaussian covariance matrix $\Sigma$ (a $3 \times 3$ symmetric positive-definite matrix) and the surface normal vector $\mathbf{n}$ at the Gaussian's center.
*   **Output**: The regularized covariance matrix $\sigma$ representing a half-Gaussian.

### Data Structures
*   **Covariance Matrix**: A $3 \times 3$ matrix. In the basis space, it is stored as a dense $3 \times 3$ array.
*   **Basis Matrix**: A $3 \times 3$ orthogonal matrix constructed from two tangent vectors and the normal vector.

### Parameters
*   **Regularization Interval**: The transformation is performed every 5000 iterations [S1].
*   **Opacity Threshold**: Increased to 0.01 for densification and pruning to eliminate noise [S1].
*   **Half-Gaussian Opacity Reset**: Set to 0.02 for newly created half-Gaussians [S1].
*   **Scaling Factor**: The minimum of the modified diagonal elements is divided by 100 for the normal component in the basis space [S1].

### Algorithm Steps
1.  **Normalize Normal**: Normalize the surface normal vector $\mathbf{n}$ to unit length: $\mathbf{n} \leftarrow \mathbf{n}/\|\mathbf{n}\|$.
2.  **Construct Basis Vectors**:
    *   If $n_x = 0$ and $n_y = 0$, set $\mathbf{v}_1 = (1, 0, 0)$ and $\mathbf{v}_2 = (0, 1, 0)$.
    *   Otherwise, compute $\mathbf{v}_1 \leftarrow (n_y, -n_x, 0)/\|(n_y, -n_x, 0)\|$ and $\mathbf{v}_2 \leftarrow \mathbf{n} \times \mathbf{v}_1 / \|\mathbf{n} \times \mathbf{v}_1\|$.
3.  **Form Basis Matrix**: Concatenate $\mathbf{v}_1, \mathbf{v}_2, \mathbf{n}$ as columns to form the basis matrix $B$.
4.  **Transform to Basis Space**: Compute $cov \leftarrow B^T \Sigma B$.
5.  **Compute Modified Diagonal Elements**:
    *   $a' \leftarrow cov[0, 0] - \frac{cov[0, 2]^2}{cov[2, 2]}$
    *   $b' \leftarrow cov[0, 1] - \frac{cov[0, 2] \cdot cov[1, 2]}{cov[2, 2]}$
    *   $c' \leftarrow cov[1, 1] - \frac{cov[1, 2]^2}{cov[2, 2]}$
6.  **Construct Regularized Covariance in Basis Space**:
    *   Create a new $3 \times 3$ matrix $\sigma_{basis}$.
    *   Set $\sigma_{basis}[0, 0] = a'$, $\sigma_{basis}[1, 1] = c'$, $\sigma_{basis}[0, 1] = b'$, $\sigma_{basis}[1, 0] = b'$.
    *   Set $\sigma_{basis}[0, 2] = 0$, $\sigma_{basis}[1, 2] = 0$, $\sigma_{basis}[2, 0] = 0$, $\sigma_{basis}[2, 1] = 0$.
    *   Set $\sigma_{basis}[2, 2] = \min(a', c') / 100$.
    *   Set all other elements to 0.
7.  **Transform Back to World Space**: Compute $\sigma \leftarrow B \sigma_{basis} B^T$.

### Pseudocode

```python
import numpy as np

def transform_covariance_to_half_gaussian(cov_matrix: np.ndarray, normal: np.ndarray) -> np.ndarray:
    """
    Transforms a 3D Gaussian covariance matrix into a half-Gaussian covariance matrix
    aligned with the given surface normal.
    
    Args:
        cov_matrix: 3x3 symmetric positive-definite covariance matrix Sigma.
        normal: 3D vector representing the surface normal n.
        
    Returns:
        3x3 regularized covariance matrix sigma.
    """
    # Step 1: Normalize normal
    n = normal / np.linalg.norm(normal)
    
    # Step 2: Construct basis vectors
    if n[0] == 0 and n[1] == 0:
        v1 = np.array([1.0, 0.0, 0.0])
        v2 = np.array([0.0, 1.0, 0.0])
    else:
        # v1 is perpendicular to n in the xy-plane projection
        v1_raw = np.array([n[1], -n[0], 0.0])
        v1 = v1_raw / np.linalg.norm(v1_raw)
        # v2 is perpendicular to both n and v1
        v2_cross = np.cross(n, v1)
        v2 = v2_cross / np.linalg.norm(v2_cross)
        
    # Step 3: Form basis matrix B (columns are v1, v2, n)
    B = np.column_stack((v1, v2, n))
    
    # Step 4: Transform to basis space
    cov_basis = B.T @ cov_matrix @ B
    
    # Step 5: Compute modified elements
    # cov_basis is 3x3. Indices are [row, col]
    a_prime = cov_basis[0, 0] - (cov_basis[0, 2]**2) / cov_basis[2, 2]
    b_prime = cov_basis[0, 1] - (cov_basis[0, 2] * cov_basis[1, 2]) / cov_basis[2, 2]
    c_prime = cov_basis[1, 1] - (cov_basis[1, 2]**2) / cov_basis[2, 2]
    
    # Step 6: Construct regularized covariance in basis space
    sigma_basis = np.zeros((3, 3))
    sigma_basis[0, 0] = a_prime
    sigma_basis[1, 1] = c_prime
    sigma_basis[0, 1] = b_prime
    sigma_basis[1, 0] = b_prime
    sigma_basis[2, 2] = min(a_prime, c_prime) / 100.0
    
    # Step 7: Transform back to world space
    sigma = B @ sigma_basis @ B.T
    
    return sigma
```

### Edge Cases and Pitfalls
*   **Degenerate Normal**: If the normal vector is zero or near-zero, normalization fails. The code handles the specific case where $n_x=0$ and $n_y=0$ by using standard basis vectors, but general near-zero normals should be guarded against [G].
*   **Singular Covariance**: The division by $cov[2, 2]$ assumes the covariance is non-singular in the basis space. If $cov[2, 2]$ is zero or near-zero, numerical instability occurs [G].
*   **Precision**: The transformation involves matrix multiplications and divisions. Floating-point precision errors may accumulate, especially when $cov[2, 2]$ is small.

## Operating characteristics
*   **Time Complexity**: The transformation involves $O(1)$ matrix operations (3x3 matrices). It is applied every 5000 iterations, so the overhead per iteration is negligible.
*   **Memory Complexity**: No additional memory is required beyond the existing Gaussian parameters.
*   **Performance**: On the Mip-NeRF 360 dataset, 3D-HGS with an efficient rasterizer achieves 125 FPS and 29.66 PSNR using 3.8M kernels, compared to 3DGS which uses 3.2M kernels [S1]. On the Tank & Dengin dataset, it achieves 160 FPS and 24.45 PSNR using 1.8M kernels [S1]. On the Tank & Blending dataset, it achieves 126 FPS and 29.76 PSNR using 2.6M kernels [S1].
*   **Strengths**: Consistently outperforms original 3D Gaussian Splatting across all metrics (PSNR, etc.) on evaluated datasets [S1]. The half-Gaussian geometry effectively models sharp transitions between object surfaces and empty space, reducing floaters [S1].
*   **Limitations**: Requires accurate surface normals for the transformation. The method is evaluated against Scaffold, mip-splatting, and MCMC architectures, but direct comparison with other regularization methods is not provided in the sources [S1].

## Background
The method was introduced in the paper "3D-HGS: 3D Half-Gaussian Splatting" [S1]. It builds on the principles of [Regularization and Geometry Constraints](6269-regularization-and-geometry-constraints.md) by modifying the shape of the Gaussian primitives themselves. The visualization of splitting planes shows that the normals of the splitting planes generally align well with the normals of the scene surfaces, indicating that the half ellipsoids effectively model the sharp transitions between the object surfaces and the empty space [S1].
