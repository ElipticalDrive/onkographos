# SplaTAM

Also called: SplaTAM: RGB-D SLAM and Mapping using 3D Gaussian Splatting

## Overview
SplaTAM is an RGB-D Simultaneous Localization and Mapping (SLAM) method that represents the world as a collection of 3D Gaussians [S2, unofficial]. It solves the problem of online tracking and mapping by using depth and photometric Iterative Closest Point (ICP) for pose estimation and densification [S2, unofficial]. It is distinguished from sibling methods like Gaussian-SLAM and Gaussian Splatting SLAM by its specific use of view-independent colors and a densification mask to prevent duplicate Gaussian creation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** RGB-D image frames, initial camera poses.
*   **Outputs:** Camera trajectory, 3D Gaussian map (positions, covariances, opacities, view-independent colors).

**Data Structures:**
*   **Gaussian Set:** A list of $N$ Gaussians. Each Gaussian $i$ has:
    *   Position $\mu_i \in \mathbb{R}^3$
    *   Covariance $\Sigma_i \in \mathbb{R}^{3 \times 3}$ (or rotation $\mathbf{R}_i$ and scale $\mathbf{s}_i$)
    *   Opacity $\alpha_i \in [0, 1]$
    *   Color $c_i \in \mathbb{R}^3$ (view-independent)
*   **Densification Mask:** A binary mask or probability map indicating regions in the new frame that require new Gaussians based on the discrepancy between current Gaussians and captured depth.

**Steps:**
1.  **Initialization:** Initialize Gaussians from the first frame's depth data [S1].
2.  **Tracking:** Estimate the current camera pose using depth and photometric ICP against the existing Gaussian map [S2, unofficial].
3.  **Rendering:** Render the current frame from the estimated pose using differentiable Gaussian rasterization to obtain rendered depth and color [S2, unofficial].
4.  **Densification Decision:** Compute a densification mask by comparing the rendered depth/opacity with the captured depth of the new frame [S1].
5.  **Densification:** Add new Gaussians in regions indicated by the mask where current Gaussians do not adequately cover the captured depth [S1].
6.  **Optimization:** Optimize Gaussian parameters (position, scale, opacity, color) and camera pose using photometric and depth losses [S2, unofficial].
7.  **Pruning:** Remove unreliable Gaussians based on opacity or other criteria (implied by general 3DGS optimization, though SplaTAM specifically focuses on avoiding duplicate densification) [S1].

**Formulas:**
*   **Photometric Loss:** $L_{photo} = || I_{rendered} - I_{captured} ||_1$
*   **Depth Loss:** $L_{depth} = || D_{rendered} - D_{captured} ||_1$
*   **Total Loss:** $L = L_{photo} + \lambda L_{depth}$

**Parameters:**
*   $\lambda$: Weight for depth loss. Not given in the sources.
*   Densification threshold: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Duplicate Densification:** SplaTAM avoids this by using view-independent colors and a specific densification mask [S1].
*   **Precision:** Standard floating-point precision is assumed. Not given in the sources.

**Pseudocode:**
```python
def splatam_step(rgb_frame, depth_frame, gaussian_map, camera_pose):
    # 1. Tracking: Estimate pose using depth and photometric ICP
    # Uses current gaussian_map to render depth and color
    # Minimizes difference between rendered and captured depth/color
    new_camera_pose = estimate_pose_icp(gaussian_map, rgb_frame, depth_frame)
    
    # 2. Render current frame with new pose
    rendered_depth, rendered_color = render_gaussians(gaussian_map, new_camera_pose)
    
    # 3. Compute densification mask
    # Compare rendered depth with captured depth
    # Mask indicates pixels where current Gaussians are insufficient
    densification_mask = compute_densification_mask(rendered_depth, depth_frame, gaussian_map)
    
    # 4. Densify: Add new Gaussians where mask is true
    # Uses view-independent colors to avoid duplicate optimization issues
    gaussian_map = densify_gaussians(gaussian_map, rgb_frame, depth_frame, densification_mask)
    
    # 5. Optimize: Update Gaussian parameters and pose
    # Minimize photometric and depth losses
    gaussian_map, new_camera_pose = optimize_gaussians_and_pose(
        gaussian_map, new_camera_pose, rgb_frame, depth_frame
    )
    
    return gaussian_map, new_camera_pose
```

## Operating characteristics
*   **Time Complexity:** Online, real-time capable. Not given in the sources.
*   **Memory Complexity:** Scales with the number of Gaussians. Not given in the sources.
*   **Measured Performance:** On the Replica dataset, SplaTAM achieves PSNR 34.11, SSIM 0.97, and LPIPS 0.10 [S1].
*   **Strengths:** Online mapping, real-time performance, high-quality reconstruction [S2, unofficial].
*   **Limitations:** Requires RGB-D input [S2, unofficial].

## Background
SplaTAM was introduced as an RGB-D SLAM method that maps the world as 3D Gaussians [S2, unofficial]. It uses depth and photometric ICP to track and densify online [S2, unofficial]. The method is cited in "Recent advances in 3D Gaussian splatting" [S1].
