# Fast Gaussian Rasterization (Covariance Eigen-decomposition and Quad Emission)
Also called: dendenxu/fast-gaussian-rasterization

## Overview
A rasterization method for 3D Gaussians that projects the 3D covariance to 2D, computes eigenvalues and eigenvectors to determine basis vectors, and emits a quad per splat to the fragment shader for alpha-based blending [S1, unofficial].

## How it works
**Inputs and Outputs:**
* **Input:** A set of 3D Gaussians, each defined by a mean position, a 3D covariance matrix (or its decomposition), and color/opacity attributes [S1, unofficial].
* **Output:** A 2D image with alpha-blended colors [S1, unofficial].

**Data Structures:**
The method uses standard OpenGL shader inputs and outputs [S1, unofficial].
* **Geometry Shader Inputs:**
  * `in vec2 basisVector0[]`: First basis vector scaled by $\sqrt{8}$ standard deviations.
  * `in vec2 basisVector1[]`: Second basis vector scaled by $\sqrt{8}$ standard deviations.
  * `in vec4 gColor[]`: Color and opacity of the splat.
  * `in float gDepth[]`: Depth of the splat center.
* **Geometry Shader Outputs:**
  * `out vec2 vPosition`: Normalized position within the quad.
  * `flat out vec4 vColor`: Interpolated color and opacity.
  * `flat out float vDepth`: Interpolated depth.
* **Fragment Shader Uniforms:**
  * `uniform bool useDepth`: Flag for depth visualization mode.
  * `uniform bool solidMode`: Flag for solid opacity mode.
  * `uniform bool edgeMode`: Flag for edge visualization mode.
  * `uniform float eight`: Constant value 8.0.
  * `uniform float minAlpha`: Minimum opacity threshold for discard (Default: 0.004) [S1, unofficial].
  * `uniform float maxAlpha`: Maximum opacity cap (Default: 0.99) [S1, unofficial].
  * `uniform float edgeThreshold`: Threshold for edge mode (Default: 0.025) [S1, unofficial].

**Steps:**

1. **Project Covariance and Compute Eigenvalues:**
   In the vertex shader or pre-processing step, extract the 2D covariance components from the projected covariance matrix `cov2Dv`:
   $$ a = \text{cov2Dv}.x $$
   $$ d = \text{cov2Dv}.z $$
   $$ b = \text{cov2Dv}.y $$
   Compute the determinant $D$:
   $$ D = a \cdot d - b^2 $$
   Compute the trace and the term for eigenvalue calculation:
   $$ \text{trace} = a + d $$
   $$ \text{traceOver2} = 0.5 \cdot \text{trace} $$
   $$ \text{term2} = \sqrt{\max(0.1, \text{traceOver2}^2 - D)} $$
   Compute the eigenvalues $\lambda_0$ and $\lambda_1$ (where $\lambda_0 \ge \lambda_1$):
   $$ \lambda_0 = \text{traceOver2} + \text{term2} $$
   $$ \lambda_1 = \text{traceOver2} - \text{term2} $$

2. **Compute Eigenvectors:**
   Compute the first eigenvector $\mathbf{e}_0$:
   $$ \mathbf{e}_0 = \text{normalize}(\text{vec2}(b, \lambda_0 - a)) $$
   Derive the orthogonal second eigenvector $\mathbf{e}_1$:
   $$ \mathbf{e}_1 = \text{vec2}(\mathbf{e}_0.y, -\mathbf{e}_0.x) $$

3. **Compute Basis Vectors:**
   Scale the eigenvectors by $\sqrt{8}$ standard deviations, capped at `maxScreenSpaceSplatSize`:
   $$ \text{basisVector0} = \mathbf{e}_0 \cdot \min(\sqrt{8} \cdot \sqrt{\lambda_0}, \text{maxScreenSpaceSplatSize}) $$
   $$ \text{basisVector1} = \mathbf{e}_1 \cdot \min(\sqrt{8} \cdot \sqrt{\lambda_1}, \text{maxScreenSpaceSplatSize}) $$
   The factor $\sqrt{8}$ is used instead of the more common 3 standard deviations to eliminate more of the splat with very low opacity [S1, unofficial].

4. **Validate and Prune:**
   Check for illegal covariance matrices or degenerate splats. If any of the following conditions are met, prune the splat by setting `gColor.a = 0.0` and returning early:
   * $D \le 0.0$
   * $a \le 0.0$
   * $d \le 0.0$
   * $\lambda_0 \le 0.01$
   * $\lambda_1 \le 0.01$
   * $\lambda_0 < \lambda_1$
   * Aspect ratio $\frac{\lambda_0}{\lambda_1} > 10000.0$

5. **Emit Quad in Geometry Shader:**
   For each of the 4 corners of the quad, defined by `vPosition` in $\{-1, 1\} \times \{-1, 1\}$:
   * **Discard Check:** If `gColor[0].a < discardAlpha` (0.0001), return without emitting vertices [S1, unofficial].
   * **Compute NDC Offset:**
     $$ \text{ndcOffset} = (\text{vPosition}.x \cdot \text{basisVector0} + \text{vPosition}.y \cdot \text{basisVector1}) \cdot \text{basisViewport} \cdot 2.0 $$
   * **Set Position:**
     $$ \text{gl\_Position} = \text{vec4}(\text{ndcCenter}.xy + \text{ndcOffset}, \text{ndcCenter}.z, 1.0) $$
   * **Pass Attributes:** Scale `vPosition` by $\sqrt{8}$ and pass through `vColor` (from `gColor`) and `vDepth` (from `gDepth`) [S1, unofficial].

6. **Apply Mode-Specific Overrides (Geometry Shader):**
   * If `solidMode` is true, set opacity = 1.0.
   * If `useDepth` is true, set color = `vec3(vDepth)`.
   * If `edgeMode` is true and $\exp(\text{power}) < \text{edgeThreshold}$, set color = `vec3(0.0, 0.0, 0.0)` and opacity = 1.0 [S1, unofficial].

7. **Fragment Shader Processing:**
   * **Alpha Clipping:** If the interpolated alpha `vColor.a < minAlpha` (0.004), discard the fragment.
   * **Alpha Capping:** If `vColor.a > maxAlpha` (0.99), cap it to `maxAlpha`.
   * **Blending:** Perform standard alpha blending using the fragment's color and alpha against the existing framebuffer content [S1, unofficial].

**Pseudocode:**

```python
import math

def compute_eigen_and_basis(cov2Dv, maxScreenSpaceSplatSize):
    """
    cov2Dv: tuple/list (x=a, y=b, z=d, w=unused)
    Returns: basisVector0, basisVector1, eigenValue0, eigenValue1
    """
    a = cov2Dv[0]
    b = cov2Dv[1]
    d = cov2Dv[2]
    
    # Determinant
    D = a * d - b * b
    
    # Eigenvalues
    trace = a + d
    traceOver2 = 0.5 * trace
    # Use max(0.1, ...) to avoid numerical instability for very small traces
    term2 = math.sqrt(max(0.1, traceOver2 * traceOver2 - D))
    eigenValue0 = traceOver2 + term2
    eigenValue1 = traceOver2 - term2
    
    # Eigenvectors
    # e0 = normalize(vec2(b, eigenValue0 - a))
    # Handle potential zero vector if eigenValue0 == a and b == 0
    norm_e0 = math.sqrt(b*b + (eigenValue0 - a)**2)
    if norm_e0 < 1e-6:
        eigenVector0 = (1.0, 0.0)
    else:
        eigenVector0 = (b / norm_e0, (eigenValue0 - a) / norm_e0)
    
    # e1 is orthogonal to e0
    eigenVector1 = (eigenVector0[1], -eigenVector0[0])
    
    # Basis vectors scaled by sqrt(8)
    sqrt8 = math.sqrt(8.0)
    scale0 = min(sqrt8 * math.sqrt(eigenValue0), maxScreenSpaceSplatSize)
    scale1 = min(sqrt8 * math.sqrt(eigenValue1), maxScreenSpaceSplatSize)
    
    basisVector0 = (eigenVector0[0] * scale0, eigenVector0[1] * scale0)
    basisVector1 = (eigenVector1[0] * scale1, eigenVector1[1] * scale1)
    
    return basisVector0, basisVector1, eigenValue0, eigenValue1

def emit_quad(basisVector0, basisVector1, gColor, gDepth, ndcCenter, basisViewport, discardAlpha):
    """
    Emits 4 vertices for the quad.
    Returns list of vertex attributes: (vPosition, vColor, vDepth)
    """
    vertices = []
    
    # Check for early discard
    if gColor[3] < discardAlpha:
        return vertices
    
    # Corners of the quad in local space {-1, 1} x {-1, 1}
    corners = [(-1, -1), (1, -1), (1, 1), (-1, 1)]
    sqrt8 = math.sqrt(8.0)
    
    for vx, vy in corners:
        # NDC Offset calculation
        offset_x = (vx * basisVector0[0] + vy * basisVector1[0]) * basisViewport * 2.0
        offset_y = (vx * basisVector0[1] + vy * basisVector1[1]) * basisViewport * 2.0
        
        # Final NDC Position
        final_x = ndcCenter[0] + offset_x
        final_y = ndcCenter[1] + offset_y
        
        # vPosition is scaled by sqrt(8) for fragment shader evaluation
        vPosition = (vx * sqrt8, vy * sqrt8)
        
        # Pass through color and depth
        vColor = gColor
        vDepth = gDepth
        
        vertices.append((vPosition, vColor, vDepth))
        
    return vertices

def fragment_shader(vPosition, vColor, vDepth, useDepth, solidMode, edgeMode, edgeThreshold, minAlpha, maxAlpha):
    """
    Returns final color and alpha. Returns (None, None) to discard.
    """
    color = list(vColor[:3])
    alpha = vColor[3]
    
    # Mode overrides
    if solidMode:
        alpha = 1.0
    elif useDepth:
        color = [vDepth, vDepth, vDepth]
    elif edgeMode:
        # power is typically the squared distance from center in fragment space [G]
        power = vPosition[0]**2 + vPosition[1]**2
        if math.exp(power) < edgeThreshold:
            color = [0.0, 0.0, 0.0]
            alpha = 1.0
            
    # Alpha capping
    if alpha > maxAlpha:
        alpha = maxAlpha
        
    # Alpha clipping
    if alpha < minAlpha:
        return None, None  # discard fragment
        
    return color, alpha
```

## Subtopics

### [Gaussian Rasterization via OpenGL Geometry Shader](19838-gaussian-rasterization-via-opengl-geometry-shader.md)
This method renders 3D Gaussian splats as screen-space quads by leveraging the fixed-function OpenGL rasterizer via a vertex-geometry-fragment shader pipeline, offloading clipping, interpolation, and blending from software to hardware. Performance metrics and synchronization overhead details are not given in the sources.

## Operating characteristics
* **Time Complexity:** $O(N)$ for $N$ splats, dominated by the geometry shader emission and fragment shader blending. The eigen-decomposition is $O(1)$ per splat [G].
* **Memory Complexity:** $O(N)$ for storing splat attributes and intermediate buffers [G].
* **Measured Performance:** Not given in the sources.
* **Strengths:** Tight quad bounding box ($\sqrt{8}$ std devs) reduces overdraw compared to larger bounding boxes [S1, unofficial]. Simple eigen-decomposition avoids iterative solvers [G].
* **Limitations:** Pruning conditions (aspect ratio, eigenvalue thresholds) may discard valid splats in edge cases if thresholds are too aggressive [S1, unofficial]. Not given in the sources.
* **When to Use:** Real-time rendering of 3D Gaussian Avatars where performance is critical and OpenGL is available [G].
* **When Not to Use:** When maximum compatibility with non-OpenGL APIs is required, or when the scene has extremely low pixel-to-point ratios where software sorting might be more efficient [G].
