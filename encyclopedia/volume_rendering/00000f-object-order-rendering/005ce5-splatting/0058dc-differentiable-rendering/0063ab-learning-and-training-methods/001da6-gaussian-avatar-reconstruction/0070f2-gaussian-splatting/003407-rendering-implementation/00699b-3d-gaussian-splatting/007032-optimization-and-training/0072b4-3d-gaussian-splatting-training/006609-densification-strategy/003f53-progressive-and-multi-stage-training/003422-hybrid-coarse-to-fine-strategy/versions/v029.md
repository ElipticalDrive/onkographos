# Hybrid Coarse-to-Fine Strategy


## Overview
The Hybrid Coarse-to-Fine Strategy is a multi-stage training approach for differentiable point-based radiance fields that refines the primitive set progressively rather than in a single pass [S1]. It solves the instability and suboptimal convergence associated with initializing and densifying a point cloud simultaneously, ensuring that the spatial distribution of primitives adapts to scene complexity over time [S1]. Unlike single-stage training, it decouples initialization from refinement, yielding significantly higher rendering quality [S1].

## How it works
The method operates on the Gaussian set $\mathcal{G}$ defined in [Densification Strategy](6234-densification-strategy.md). It partitions the optimization into sequential stages, modifying the trainable parameters and supervision signals to transition from a coarse representation to a fine-grained one.

**Inputs and Outputs:**
*   **Input:** Initial sparse point cloud $\mathcal{P}_0$, camera poses $\mathcal{C}$, and ground-truth images $\mathcal{I}$.
*   **Output:** Optimized Gaussian set $\mathcal{G}$ with refined positions, covariances, opacities, and spherical harmonic coefficients.

**Data Structures:**
The state is maintained in the Gaussian set $\mathcal{G}$. Each Gaussian $i$ contains:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$
*   Covariance $\mathbf{\Sigma}_i \in \mathbb{R}^{3 \times 3}$ (or rotation $\mathbf{q}_i$ and scale $\mathbf{s}_i$)
*   Opacity $\alpha_i \in [0, 1]$
*   Spherical Harmonics coefficients $\mathbf{c}_{i, l}$ for $l=0 \dots L$

**Numbered Steps:**
1.  **Initialization:** Initialize a sparse point cloud $\mathcal{P}_0$ from the input data (e.g., via structure-from-motion or uniform sampling). This forms the coarse stage [S1].
2.  **Coarse Training:** Train the initial point cloud parameters using a standard differentiable rendering loss. During this stage, the geometry is roughly established [S1].
3.  **Hybrid Refinement:** Transition to the fine stage. This involves densification operations (as defined in [Densification Strategy](6234-densification-strategy.md)) to insert new primitives at high-error locations, refining the topology [S1].
4.  **Fine Training:** Continue optimization with the densified set, allowing the spherical harmonics and detailed geometry to converge [S1].
5.  **Consistency Filtering:** Apply a consistency filter function during training to maintain coherence between stages and prevent artifacts [S1].

**Formulas:**
The rendering loss $\mathcal{L}$ is minimized. The total loss typically includes photometric error and potentially regularization terms. The specific hybrid strategy modifies the training loop to alternate or sequence these phases.

**Parameters:**
*   Number of stages: Not given in the sources.
*   Densification threshold: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Single-Stage Degradation:** Removing the hybrid strategy results in significant quality drops. On the Blender dataset, "w/o hybrid" reduces PSNR from 30.3 dB to 26.6 dB, SSIM from 0.945 to 0.925, and increases LPIPS from 0.078 to 0.163 [S1].
*   **Initialization Sensitivity:** The quality of the coarse initialization impacts the final result, necessitating the consistency filter [S1].

**Pseudocode:**
```python
# Initialize sparse point cloud P_0
G = initialize_sparse_point_cloud(P_0)

# Stage 1: Coarse Training
for epoch in range(coarse_epochs):
    # Render image from current G
    rendered_image = render(G, cameras)
    # Compute loss (photometric)
    loss = compute_loss(rendered_image, ground_truth)
    # Backpropagate and update G
    update_parameters(G, loss)

# Stage 2: Hybrid Refinement (Densification)
# Insert new primitives based on error metrics
G = densify(G, cameras, ground_truth)

# Stage 3: Fine Training
for epoch in range(fine_epochs):
    # Render image
    rendered_image = render(G, cameras)
    # Compute loss
    loss = compute_loss(rendered_image, ground_truth)
    # Apply consistency filter if needed
    G = apply_consistency_filter(G)
    # Backpropagate and update G
    update_parameters(G, loss)
```

## Subtopics

### [Coarse-to-Fine Densification](9135-coarse-to-fine-densification.md)
A strategy that progressively refines a sparse mesh by inserting new vertices at high-error locations. It decouples initialization from refinement, allowing the topology to adapt to scene complexity. Choose this when uniform distribution of vertices proportional to spatial impact is required.

## Operating characteristics
*   **Performance:** The hybrid strategy yields better rendering quality than single-stage training [S1].
*   **Metrics:** On the Blender dataset, the full method achieves PSNR 30.3 dB, SSIM 0.945, and LPIPS 0.078 [S1].
*   **Comparison:** Removing the strategy ("w/o hybrid") degrades performance to PSNR 26.6 dB, SSIM 0.925, and LPIPS 0.163 [S1].
*   **Strengths:** Improved view synthesis performance, stable convergence, better handling of complex geometries.
*   **Limitations:** Requires multiple training stages, potentially increasing total training time compared to a single-stage approach.

## Background
The method originates from research on differentiable point-based radiance fields for efficient view synthesis [S1]. It addresses the limitations of volumetric representations and coordinate-networks by leveraging points without sacrificing end-to-end differentiability [S1]. The approach was introduced to improve upon single-stage point cloud training, which suffers from lower quality and instability.
