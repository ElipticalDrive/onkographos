# SpacetimeGaussians Training Pipeline


## Overview
The SpacetimeGaussians Training Pipeline is the optimization procedure for the Spacetime Gaussian Feature Splatting method, designed to reconstruct dynamic 3D scenes from multi-view video sequences [S1, unofficial]. It extends standard 3D Gaussian Splatting by introducing time-dependent deformation fields and adaptive density control schedules to handle non-rigid motion [S1, unofficial]. Unlike static Gaussian splatting, this pipeline manages temporal parameters (`_omega`) and employs specific pruning and freezing strategies to stabilize training and prevent overfitting to noise in dynamic regions [S1, unofficial]. It differs from sibling methods like [Deformable 3D Gaussians](16260-deformable-3d-gaussians.md) by its specific implementation of motion parameter freezing and the use of distinct rasterization backends for full and lite training modes [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   Multi-view video frames (images and camera poses) [S1, unofficial].
*   Initial Gaussian model parameters (position, rotation, scale, opacity, color features) [S1, unofficial].
*   Training hyperparameters: `opt.densify_from_iter`, `opt.densify_until_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, `opt.opthr`, `opt.reg`, `opt.lambda_dssim`, `opt.regl` [S1, unofficial].
*   Rendering pipeline option: `'train_ours_full'`, `'train_ours_lite'`, `'train_ours_fullss'`, or `'train_ours_litess'` [S1, unofficial].

**Outputs:**
*   Optimized set of 3D Gaussians with time-dependent parameters [S1, unofficial].
*   Trained neural networks for color decoding (if applicable) [S1, unofficial].

### Data Structures
*   **Gaussian Model (`gaussians`):** Contains tensors for position (`_xyz`), rotation (`_rotation`), scale (`_scaling`), opacity (`_opacity`), and motion parameters (`_omega`) [S1, unofficial].
*   **Background Tensor (`background`):** Shape `(numchannels,)`, dtype `torch.float32`, device `cuda`. Initialized to zeros [S1, unofficial].
*   **Time Tensor (`gaussians.ts`):** Shape `(1, 1, H, W)`, dtype `torch.float32`, device `cuda`. Initialized to ones if `None` [S1, unofficial].
*   **Omega Mask (`gaussians.omegamask`):** Boolean tensor indicating which Gaussians retain motion parameters [S1, unofficial].

### Numbered Steps

1.  **Initialization:**
    *   Initialize the Gaussian model using `getmodel(dataset.model)` with specified SH degree and RGB function [S1, unofficial].
    *   Load scene data into a `Scene` object with `multiview=True` and appropriate duration/loader settings [S1, unofficial].
    *   Initialize `background` tensor to zeros [S1, unofficial].
    *   If `gaussians.ts` is `None`, initialize it as a tensor of ones with shape `(1, 1, H, W)` on CUDA [S1, unofficial].
    *   Retrieve the rendering pipeline and rasterizer settings via `getrenderpip(option)` [S1, unofficial].
    *   If `gaussians.rgbdecoder` is not `None`, move it to CUDA and set to eval mode [G].

2.  **Iteration Loop:**
    For each training iteration `iteration`:
    *   **Densification Mode Check:** If `densify == 1` (n3d mode):
        *   At `iteration == 8001`: Compute `omegamask` by calling `gaussians.zero_omegabymotion()` to determine which Gaussians keep motion parameters [S1, unofficial]. Store in `gaussians.omegamask` [S1, unofficial].
        *   For `iteration > 8001`: Freeze weights for `_omega` using `omegamask` and freeze weights for `_rotation` using `~omegamask` via `freezweightsbymasknounsqueeze` [S1, unofficial].
    *   **Densification:**
        *   If `iteration > opt.densify_from_iter` and `iteration % opt.densification_interval == 0` and `flag < opt.desicnt`:
            *   Calculate `size_threshold`: 20 if `iteration > opt.opacity_reset_interval`, else `None` [S1, unofficial].
            *   Call `gaussians.densify_pruneclone(opt.densify_grad_threshold, opt.opthr, scene.cameras_extent, size_threshold)` [S1, unofficial].
    *   **Pruning:**
        *   If `flag >= opt.desicnt` and `iteration < 7000`: Prune points with opacity below `opt.opthr` [S1, unofficial].
        *   If `iteration >= opt.densify_until_iter`:
            *   Freeze `_omega` and `_rotation` weights as described in step 2a [S1, unofficial].
            *   If `iteration % 1000 == 500`: Prune points where `gaussians._xyz[:,2] < 4.5` [S1, unofficial].
    *   **Opacity Reset:**
        *   Every 3000 iterations, call `gaussians.reset_opacity()` [S1, unofficial].
    *   **Rendering:**
        *   Render the scene using the selected rasterizer (`diff_gaussian_rasterization_ch9` for full, `diff_gaussian_rasterization_ch3` for lite) [S1, unofficial].
        *   Pass `scaling_modifier=1.0` and `basicfunction=trbfunction` to the render function [S1, unofficial].
    *   **Loss Calculation:**
        *   Compute loss based on `opt.reg` [S1, unofficial]:
            *   `reg=1`: $L = (1 - \text{opt.lambda\_dssim}) L_{L1} + \text{opt.lambda\_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \frac{\sum \mathbf{g}_{\text{motion}}}{N}$
            *   `reg=9`: $L = (1 - \text{opt.lambda\_dssim}) L_{L1} + \text{opt.lambda\_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \sum_{r>0} \mathbf{g}_{\omega}^2$
            *   `reg=10`: $L = (1 - \text{opt.lambda\_dssim}) L_{L1} + \text{opt.lambda\_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \sum_{r>0} \mathbf{g}_{\text{motion}}^2$
            *   `reg=4`: $L = (1 - \text{opt.lambda\_dssim}) L_{L1} + \text{opt.lambda\_dssim} (1 - \text{SSIM}(I, I_{gt})) + \text{opt.regl} \frac{\sum \mathbf{g}_{\text{scaling}}}{N}$
            *   `reg=6`: $L = (1 - r) L_{L1} + r (1 - \text{SSIM}(I, I_{gt}))$ where $r = \text{clamp}(\text{mean}(I_{gt}) - 0.5 + \text{opt.lambda\_dssim}, 0, 1)$
            *   `reg=7`: $L_{L1}$ is normalized by $2 \cdot \text{mean}(I_{gt})$
            *   `reg=8`: $L = (1 - \text{opt.lambda\_dssim}) L_{L1} + 0.0002 \cdot \text{opt.lambda\_dssim} \frac{\sum (\bar{x} - x)^2}{N}$
        *   Where $\mathbf{g}_{\text{motion}}$ and $\mathbf{g}_{\omega}$ refer to motion-related gradients/parameters [S1, unofficial].
    *   **Backpropagation:**
        *   Perform backward pass and optimizer step [S1, unofficial].

### Pseudocode

```python
def train_spacetime_gaussians(dataset, opt, option="train_ours_full"):
    # 1. Initialization
    gaussians = getmodel(dataset.model)
    scene = Scene(dataset, gaussians, load_iteration=0, shuffle=False, multiview=True, duration=None, loader=None)
    
    # Initialize background tensor
    numchannels = 9
    background = torch.zeros(numchannels, dtype=torch.float32, device="cuda")
    
    # Initialize time tensor if None
    if gaussians.ts is None:
        H, W = scene.cameras[0].image_height, scene.cameras[0].image_width
        gaussians.ts = torch.ones((1, 1, H, W), dtype=torch.float32, device="cuda")
    
    # Get rendering pipeline
    train_func, RasterizationSettings, Rasterizer = getrenderpip(option)
    
    # Handle RGB decoder
    if gaussians.rgbdecoder is not None:
        gaussians.rgbdecoder.to("cuda")
        gaussians.rgbdecoder.eval()
    
    # 2. Training Loop
    for iteration in range(opt.max_iterations):
        # Densification Mode 1 (n3d) specific logic
        if opt.densify == 1:
            if iteration == 8001:
                gaussians.omegamask = gaussians.zero_omegabymotion()
            
            if iteration > 8001:
                # Freeze omega where mask is True, freeze rotation where mask is False
                freezweightsbymasknounsqueeze(gaussians._omega, gaussians.omegamask)
                freezweightsbymasknounsqueeze(gaussians._rotation, ~gaussians.omegamask)
        
        # Densification
        if (iteration > opt.densify_from_iter and 
            iteration % opt.densification_interval == 0 and 
            flag < opt.desicnt):
            
            size_threshold = 20 if iteration > opt.opacity_reset_interval else None
            gaussians.densify_pruneclone(
                opt.densify_grad_threshold, 
                opt.opthr, 
                scene.cameras_extent, 
                size_threshold
            )
        
        # Pruning
        if flag >= opt.desicnt and iteration < 7000:
            prune_points_with_opacity_below(gaussians, opt.opthr)
        
        if iteration >= opt.densify_until_iter:
            # Re-freeze weights if not already done in n3d mode
            if opt.densify != 1 or iteration <= 8001:
                freezweightsbymasknounsqueeze(gaussians._omega, gaussians.omegamask if opt.densify == 1 else torch.ones_like(gaussians.omegamask, dtype=torch.bool))
                freezweightsbymasknounsqueeze(gaussians._rotation, ~gaussians.omegamask if opt.densify == 1 else torch.zeros_like(gaussians.omegamask, dtype=torch.bool))
            
            if iteration % 1000 == 500:
                prune_points_with_z_below(gaussians, 4.5)
        
        # Opacity Reset
        if iteration % 3000 == 0:
            gaussians.reset_opacity()
        
        # Rendering
        # Select camera for current iteration
        camera = scene.get_random_camera()
        
        # Render using selected pipeline
        raster_settings = RasterizationSettings(
            image_height=H,
            image_width=W,
            tanfovx=camera.tanfovx,
            tanfovy=camera.tanfovy,
            bg=background,
            scale_modifier=1.0,
            viewmatrix=camera.world_view_transform,
            projmatrix=camera.full_proj_transform,
            sh_degree=gaussians.active_sh_degree,
            campos=camera.camera_center,
            prefiltered=False
        )
        
        rendered_image, radii = Rasterizer(raster_settings, gaussians)
        
        # Loss Calculation
        gt_image = camera.image
        loss = compute_loss(rendered_image, gt_image, opt.reg, opt.lambda_dssim, opt.regl, gaussians)
        
        # Backpropagation
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
        
        flag += 1

def compute_loss(rendered, gt, reg, lambda_dssim, regl, gaussians):
    l1_loss = L1Loss(rendered, gt)
    ssim_loss = 1 - SSIM(rendered, gt)
    
    if reg == 1:
        motion_grad = gaussians.get_motion_gradients()
        N = motion_grad.shape[0]
        reg_term = regl * (torch.sum(motion_grad) / N)
    elif reg == 9:
        omega_grad = gaussians.get_omega_gradients()
        reg_term = regl * torch.sum(omega_grad[omega_grad > 0] ** 2)
    elif reg == 10:
        motion_grad = gaussians.get_motion_gradients()
        reg_term = regl * torch.sum(motion_grad[motion_grad > 0] ** 2)
    elif reg == 4:
        scaling_grad = gaussians.get_scaling_gradients()
        N = scaling_grad.shape[0]
        reg_term = regl * (torch.sum(scaling_grad) / N)
    elif reg == 6:
        mean_gt = torch.mean(gt)
        r = torch.clamp(mean_gt - 0.5 + lambda_dssim, 0, 1)
        return (1 - r) * l1_loss + r * ssim_loss
    elif reg == 7:
        mean_gt = torch.mean(gt)
        l1_loss = l1_loss / (2 * mean_gt)
        return (1 - lambda_dssim) * l1_loss + lambda_dssim * ssim_loss
    elif reg == 8:
        # Assuming x is rendered and x_bar is gt or vice versa based on context
        # Source says sum((x_bar - x)^2)/N. Let's assume x_bar is gt, x is rendered
        x_bar = gt
        x = rendered
        N = x.shape[0] * x.shape[1] * x.shape[2]
        reg_term = regl * 0.0002 * lambda_dssim * (torch.sum((x_bar - x) ** 2) / N)
        return (1 - lambda_dssim) * l1_loss + reg_term
    else:
        reg_term = 0.0
        
    return (1 - lambda_dssim) * l1_loss + lambda_dssim * ssim_loss + reg_term
```

### Parameters
*   `numchannels`: Number of channels for background color. Default: 9 [S1, unofficial].
*   `scaling_modifier`: Passed to render function. Default: 1.0 [S1, unofficial].
*   `basicfunction`: Passed to render function. Default: `trbfunction` [S1, unofficial].
*   `opt.densify_from_iter`: Iteration to start densification [S1, unofficial].
*   `opt.densify_until_iter`: Iteration to stop densification and freeze motion [S1, unofficial].
*   `opt.densification_interval`: Interval between densification steps [S1, unofficial].
*   `opt.opacity_reset_interval`: Interval for opacity reset [S1, unofficial].
*   `opt.desicnt`: Counter for densification steps [S1, unofficial].
*   `opt.densify_grad_threshold`: Gradient threshold for densification [S1, unofficial].
*   `opt.opthr`: Opacity threshold for pruning [S1, unofficial].
*   `opt.reg`: Regularization type selector [S1, unofficial].
*   `opt.lambda_dssim`: Weight for D-SSIM loss [S1, unofficial].
*   `opt.regl`: Weight for regularization term [S1, unofficial].

### Edge Cases and Pitfalls
*   **RGB Decoder:** If `gaussians.rgbdecoder` is not `None`, it must be moved to CUDA and set to eval mode before rendering [S1, unofficial].
*   **Pruning Logic:** Pruning behavior changes based on the densification phase. Before `opt.desicnt` is reached, densification is prioritized. After `opt.desicnt`, pruning is based on opacity if `iteration < 7000`. After `opt.densify_until_iter`, pruning is based on Z-coordinate < 4.5 if `iteration % 1000 == 500` [S1, unofficial].
*   **Motion Freezing:** In `densify == 1` mode, motion parameters (`_omega`) are frozen after iteration 8001 based on `omegamask`. Failure to correctly apply this mask can lead to unstable motion or overfitting [S1, unofficial].

## Subtopics

### SpacetimeGaussians Densification & Pruning Schedule
A training iteration schedule that controls Gaussian densification, pruning, and parameter freezing based on iteration count, mode selection, and visibility metrics [S1, unofficial]. It supports multiple densification modes (`densify` parameter: 0, 1, 2, or 3) [S1, unofficial]. In mode 1, it prunes points with `xyz[:,2] < 4.5` at iteration 1000 and resets opacity every 3000 iterations [S1, unofficial]. In mode 3, it updates `max_radii2D` and `add_densification_stats` every iteration, densifies/prunes clones at intervals, prunes low-opacity points if `iteration < 7000`, resets opacity every `opt.opacity_reset_interval`, and calls `removeminmax` at iteration 10000 [S1, unofficial]. Key parameters include `size_threshold` (20 if `iteration > opt.opacity_reset_interval`, else `None`), `opt.densify_until_iter`, `opt.densify_from_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, and `opt.opthr` [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources for the base training pipeline.
*   **Strengths:** The explicit schedule for freezing motion parameters and pruning helps stabilize training for dynamic scenes, preventing noise accumulation in static regions [S1, unofficial]. The support for multiple rasterization backends (full/lite) allows for flexibility in hardware constraints [S1, unofficial].
*   **Limitations:** The rigid iteration-based schedule (e.g., freezing at 8001, pruning at 7000) may not be optimal for all scenes [S1, unofficial]. The method relies on specific hyperparameters that may require tuning [S1, unofficial].
*   **When to use:** When reconstructing dynamic scenes with significant non-rigid motion and needing a stable training process with explicit control over densification and motion parameter updates [S1, unofficial].
*   **When not to use:** For static scenes where standard 3D Gaussian Splatting is sufficient, or for scenes with very short durations where the complex densification schedule may not converge [S1, unofficial].

## Background
The SpacetimeGaussians Training Pipeline is part of the Spacetime Gaussian Feature Splatting method, introduced by Li et al. in CVPR 2024 [S1, unofficial]. It builds on the 3D Gaussian Splatting representation [S1, unofficial]. The method was developed to address the challenges of real-time dynamic view synthesis, extending the static Gaussian splatting framework to handle temporal dynamics through deformation fields and adaptive training strategies [S1, unofficial].
