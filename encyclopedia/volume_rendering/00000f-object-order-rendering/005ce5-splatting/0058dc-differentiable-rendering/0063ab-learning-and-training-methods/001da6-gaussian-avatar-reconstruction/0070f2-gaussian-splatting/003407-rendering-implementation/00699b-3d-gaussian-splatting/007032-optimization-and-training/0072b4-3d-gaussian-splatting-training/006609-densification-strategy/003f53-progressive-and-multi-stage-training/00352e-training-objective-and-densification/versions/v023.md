# Training Objective and Densification

Also called: MeshGS Training, Tightly/Loosely-bound Training

## Overview
This method defines the loss function and densification strategy for **MeshGS** [S1], a variant of 3D Gaussian Splatting that aligns primitives with an explicit mesh surface. It solves the problem of Gaussian splats drifting away from geometry or expanding excessively by introducing surface-aware regularization and projection losses. It differs from standard 3DGS [S8, unofficial] by splitting the primitive set into **tightly-bound** ($G^t$) and **loosely-bound** ($G^l$) subsets, applying mesh-aligned constraints only to $G^t$, while retaining the original gradient-based densification for $G^l$.

## How it works
**Inputs:**
*   Rendered image $\hat{I}_i$ and ground truth image $I_i$.
*   Set of tightly-bound Gaussians $G^t$ and loosely-bound Gaussians $G^l$.
*   Mesh $M$ consisting of faces $F$, where each face $f_j$ has vertices $v_i$ and normal $n_f$.
*   For each Gaussian $k \in G^t$: mean position $P_k$, scale parameters $S_k = (s_1, s_2, s_3)$, rotation matrix $R_k$.

**Outputs:**
*   Total loss $L$ for backpropagation.
*   Updated Gaussian set after densification steps.

**Data Structures:**
*   $G^t$: List of Gaussians satisfying distance threshold $d_{th} = 0.01$ from mesh surface [S1].
*   $G^l$: List of Gaussians not satisfying $d_{th}$ [S1].

**Parameters:**
*   $\lambda_{img} = 0.001$ [S1].
*   $\lambda_{nc} = 0.1$ [S1].
*   $\lambda_{min} = 0.1$ [S1].
*   $\lambda_{max} = 10$ [S1].
*   $\lambda_{proj} = 50$ [S1].
*   $\rho = 0.1$ (scale threshold) [S1].
*   Split scale factor: $1.6$ [S1].
*   Training iterations: $30,000$ [S1].
*   Densification frequency: Every $500$ iterations [S1].

**Steps:**

1.  **Compute Image Loss ($L_{img}$):**
    Calculate the combination of L1 loss and D-SSIM [S1]:
    $$ L_{img} = (1 - \lambda_{img}) L_1(\hat{I}_i, I_i) + \lambda_{img} \text{SSIM}(\hat{I}_i, I_i) $$

2.  **Compute Normal Consistency Loss ($L_{nc}$) for $G^t$:**
    For each Gaussian $i \in G^t$:
    a. Identify the minimum scale axis index from $S_i$.
    b. Extract the corresponding axis vector from the rotation matrix $R_i$ to estimate the normal $n_i$ in world coordinates [S1].
    c. Find the closest mesh face $f$ with normal $n_f$.
    d. Accumulate cosine similarity loss:
    $$ L_{nc} = \sum_{i \in G^t, f \in F} (1 - n_i \cdot n_f) $$

3.  **Compute Scale Regularization Loss ($L_{scale}$) for $G^t$:**
    For each Gaussian $i \in G^t$ with scales $S_i = (s_1, s_2, s_3)$:
    $$ L_{scale} = \sum_{i \in G^t} \left( \lambda_{min} |\min(s_1, s_2, s_3)| + \lambda_{max} |\max(s_1, s_2, s_3) - \rho| \right) $$
    This suppresses excessive expansion and aligns scales with the mesh surface [S1].

4.  **Compute Projection Loss ($L_{proj}$) for $G^t$:**
    For each Gaussian $i \in G^t$ with center $P_i$:
    a. Project $P_i$ to the closest point $s_i$ on the mesh surface defined by face $f_j$ and vertex $v_i$ [S1]:
    $$ s_i = P_i + ((P_i - v_i) \cdot f_j) \cdot f_j $$
    b. Calculate distance loss:
    $$ L_{proj} = \sum_{i \in G^t} \| s_i - P_i \|_2 $$

5.  **Compute Total Loss:**
    $$ L = L_{img} + \lambda_{nc} L_{nc} + L_{scale} + \lambda_{proj} L_{proj} $$

6.  **Densification (Every 500 iterations) [S1]:**
    *   **For $G^l$ (Loosely-bound):** Apply the standard 3DGS densification strategy based on gradient magnitude and opacity [S1].
    *   **For $G^t$ (Tightly-bound):**
        *   Identify Gaussians requiring splitting or cloning based on gradient metrics (implied by "follows original 3DGS" context for logic, but specific initialization differs) [S1].
        *   **Cloning:** Create a copy of the parent Gaussian. Copy all attributes ($\mu, \Sigma, \alpha, \mathbf{c}$) to the new Gaussian [S1].
        *   **Splitting:** Replace the parent with children. Sample new positions from the mesh triangle associated with the parent Gaussian. Initialize new Gaussians at these sampled positions. Divide the parent's scale by a factor of $1.6$ [S1].

**Pseudocode:**

```python
def compute_loss(G_t, G_l, mesh, rendered_image, ground_truth_image):
    # 1. Image Loss (applied to all, but primarily drives G_l optimization in standard 3DGS)
    l1_loss = L1(rendered_image, ground_truth_image)
    ssim_loss = SSIM(rendered_image, ground_truth_image)
    L_img = (1 - 0.001) * l1_loss + 0.001 * ssim_loss

    L_nc = 0.0
    L_scale = 0.0
    L_proj = 0.0

    for g in G_t:
        # 2. Normal Consistency
        # Identify min scale axis
        min_scale_idx = argmin(g.scale)
        # Extract normal from rotation matrix R at min_scale_idx
        n_i = g.rotation_matrix[:, min_scale_idx]
        
        # Find closest mesh face f with normal n_f
        f, n_f = mesh.get_closest_face_and_normal(g.position)
        
        L_nc += (1.0 - dot(n_i, n_f))

        # 3. Scale Regularization
        s_min = min(g.scale)
        s_max = max(g.scale)
        L_scale += (0.1 * abs(s_min) + 10.0 * abs(s_max - 0.1))

        # 4. Projection Loss
        # Project position to mesh surface
        # Note: Simplified projection assuming f is the closest face
        # s_i = P_i + ((P_i - v_i) . f_j) * f_j
        # In practice, this requires finding the specific vertex v_i of face f_j
        # closest to P_i or using barycentric projection. 
        # Source formula implies a specific vertex v_i associated with the face.
        v_i = mesh.get_vertex_for_projection(g.position, f)
        f_j = f.normal
        s_i = g.position + dot(g.position - v_i, f_j) * f_j
        L_proj += norm(s_i - g.position)

    # 5. Total Loss
    L = L_img + 0.1 * L_nc + L_scale + 50.0 * L_proj
    return L

def densify(G_t, G_l, mesh, iteration):
    if iteration % 500 != 0:
        return

    # Densify Loosely-bound Gaussians using standard 3DGS strategy
    G_l = densify_standard_3dgs(G_l)

    # Densify Tightly-bound Gaussians
    new_G_t = []
    for g in G_t:
        if needs_splitting(g):
            # Find associated mesh triangle
            triangle = mesh.get_closest_triangle(g.position)
            
            # Sample points from triangle for new positions
            num_children = 2 # Standard split count
            for _ in range(num_children):
                new_pos = sample_point_from_triangle(triangle)
                
                # Create child
                child = Gaussian()
                child.position = new_pos
                child.rotation = g.rotation
                child.scale = g.scale / 1.6 # Divide by 1.6
                child.opacity = g.opacity
                child.sh_coeffs = g.sh_coeffs
                new_G_t.append(child)
                
        elif needs_cloning(g):
            # Clone attributes
            clone = Gaussian()
            clone.position = g.position
            clone.rotation = g.rotation
            clone.scale = g.scale
            clone.opacity = g.opacity
            clone.sh_coeffs = g.sh_coeffs
            new_G_t.append(clone)
        else:
            new_G_t.append(g)
            
    G_t = new_G_t
    return G_t
```

## Operating characteristics
*   **Time Complexity:** Dominated by the projection loss calculation, which requires finding the closest mesh face/point for every tightly-bound Gaussian at every iteration. This is more expensive than standard 3DGS which relies only on gradient accumulation.
*   **Memory Complexity:** Requires storing the mesh geometry ($F, V$) alongside the Gaussian attributes.
*   **Performance:** Evaluated on Mip-NeRF360 and Deep Blending datasets for 30k iterations [S1].
*   **Strengths:** Prevents Gaussian splats from drifting off the mesh surface and controls scale expansion, leading to better geometry alignment [S1].
*   **Limitations:** Dependent on the quality of the input mesh. The projection step adds computational overhead.

## Background
Originated in **MeshGS: Adaptive Mesh-Aligned Gaussian Splatting for High-Quality Rendering** [S1]. It extends the original 3DGS [S8, unofficial] by incorporating explicit mesh supervision to improve rendering quality and geometric fidelity in large-scale scenes.
