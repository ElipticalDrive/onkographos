# Mip-Splatting Training Loop & Evaluation Pipeline

Also called: 3D Gaussian Splatting Training Schedule, Mip-3DGS Training Loop

## Overview
This method defines the complete training iteration and evaluation procedure for Mip-Splatting, handling camera sampling, subpixel-aware rendering, hybrid loss computation, adaptive densification/pruning, and quantitative metric reporting [S1, unofficial]. It distinguishes itself from standard 3D Gaussian Splatting by integrating subpixel ray jittering and ground truth resampling to mitigate aliasing artifacts during optimization [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of training cameras (`trainCameras`), a Gaussian scene representation (`gaussians`), optimization hyperparameters (`opt`), and pipeline settings (`pipe`).
*   **Outputs:** Updated Gaussian parameters, rendered images, and quantitative metrics (SSIM, PSNR, LPIPS) logged to TensorBoard and JSON files.

**Data Structures**
*   `gaussians`: Contains attributes `max_radii2D` (tensor, size $N$), `optimizer` (Adam instance), and methods for SH degree management and densification.
*   `viewpoint_stack`: A list of camera objects used for training sampling.
*   `subpixel_offset`: A tensor of shape $(H, W, 2)$ with values in $[-0.5, 0.5]$, generated on CUDA if `ray_jitter` is enabled [S1, unofficial].

**Parameters**
*   `opt.iterations`: Total training steps. Default: 30,000 [S1, unofficial].
*   `opt.densify_from_iter`: Iteration to start densification. Default: 500 [S1, unofficial].
*   `opt.densify_until_iter`: Iteration to stop densification. Default: 15,000 [S1, unofficial].
*   `opt.densification_interval`: Frequency of densification steps. Default: 100 [S1, unofficial].
*   `opt.opacity_reset_interval`: Frequency of opacity resets. Default: 3,000 [S1, unofficial].
*   `opt.densify_grad_threshold`: Gradient threshold for densification. Default: 0.0002 [S1, unofficial].
*   `opt.lambda_dssim`: Weight for D-SSIM loss. Default: 0.2 [S1, unofficial].
*   `dataset.kernel_size`: Kernel size for rendering. Default: 0.1 [S1, unofficial].
*   `dataset.ray_jitter`: Boolean flag to enable subpixel offset generation. Default: False [S1, unofficial].
*   `dataset.resample_gt_image`: Boolean flag to resample ground truth. Default: False [S1, unofficial].
*   `dataset.sample_more_highres`: Boolean flag to increase high-res sampling probability. Default: False [S1, unofficial].
*   `dataset.white_background`: Boolean flag for background handling. Default: False [S1, unofficial].
*   `--test_iterations`: Validation checkpoints. Default: `[7000, 30000]` [S1, unofficial].
*   `--save_iterations`: Model save checkpoints. Default: `[7000, 30000]` [S1, unofficial].
*   `--checkpoint_iterations`: Optimizer checkpoint save points. Default: `[]` [S1, unofficial].

**Numbered Steps**
1.  **Learning Rate Update:** Update the learning rate for all Gaussian parameters using `gaussians.update_learning_rate(iteration)` [S1, unofficial].
2.  **SH Degree Increase:** Every 1,000 iterations, increment the spherical harmonics degree using `gaussians.oneupSHdegree()` [S1, unofficial].
3.  **Camera Sampling:** Pop a random camera from `viewpoint_stack`. If `dataset.sample_more_highres` is true and `random.random() < 0.3`, override the selection with a high-resolution camera from `trainCameras[highresolution_index]` [S1, unofficial].
4.  **Subpixel Offset Generation:** If `dataset.ray_jitter` is enabled, generate a subpixel offset tensor of shape $(H, W, 2)$ with uniform random values in $[-0.5, 0.5]$ on CUDA. Otherwise, set `subpixel_offset = None` [S1, unofficial].
5.  **Rendering:** Render the scene by calling `render(viewpoint_cam, gaussians, pipe, background, kernel_size=dataset.kernel_size, subpixel_offset=subpixel_offset)`. Extract the rendered `image`, `viewspace_point_tensor`, `visibility_filter`, and `radii` from the returned dictionary [S1, unofficial].
6.  **Ground Truth Resampling:** If `dataset.resample_gt_image` is true, resample the ground truth image using the `subpixel_offset` via `create_offset_gt(gt_image, subpixel_offset)` before loss computation [S1, unofficial].
7.  **Statistics Tracking:**
    *   Update max image-space radii for pruning: `gaussians.max_radii2D[visibility_filter] = torch.max(gaussians.max_radii2D[visibility_filter], radii[visibility_filter])` [S1, unofficial].
    *   Add densification statistics: `gaussians.add_densification_stats(viewspace_point_tensor, visibility_filter)` [S1, unofficial].
8.  **Densification and Pruning:** If `iteration > opt.densify_from_iter` and `iteration % opt.densification_interval == 0`:
    *   Compute `size_threshold = 20` if `iteration > opt.opacity_reset_interval`, else `size_threshold = None` [S1, unofficial].
    *   Call `gaussians.densify_and_prune(opt.densify_grad_threshold, 0.005, scene.cameras_extent, size_threshold)` [S1, unofficial].
    *   Call `gaussians.compute_3D_filter(cameras=trainCameras)` [S1, unofficial].
9.  **Opacity Reset:** Reset opacities if `iteration % opt.opacity_reset_interval == 0` or if `dataset.white_background` is true and `iteration == opt.densify_from_iter` [S1, unofficial].
10. **3D Filter Update (Late Stage):** After densification stops (`iteration > opt.densify_until_iter`), if `iteration % 100 == 0` and `iteration < opt.iterations - 100`, update the 3D filter via `gaussians.compute_3D_filter(cameras=trainCameras)` [S1, unofficial].
11. **Optimization Step:** Perform the optimizer step and zero gradients: `gaussians.optimizer.step()` followed by `gaussians.optimizer.zero_grad(set_to_none=True)` [S1, unofficial].
12. **Evaluation:** During evaluation phases (defined by `--test_iterations`):
    *   Load rendered images from `test_preds_{scale}` and ground truth from `gt_{scale}` directories [S1, unofficial].
    *   Compute per-image SSIM, PSNR, and LPIPS (using VGG network) [S1, unofficial].
    *   Average metrics across all images in the view set [S1, unofficial].
    *   Log to TensorBoard and save to `results.json` and `per_view.json` [S1, unofficial].

**Loss Function**
The total loss $\mathcal{L}$ is defined as:
$$ \mathcal{L} = (1 - \lambda_{\text{dssim}}) \mathcal{L}_{\text{L1}} + \lambda_{\text{dssim}} (1 - \text{SSIM}(I_{\text{render}}, I_{\text{gt}})) $$
where $\mathcal{L}_{\text{L1}}$ is the L1 loss between rendered and ground truth images, $\lambda_{\text{dssim}}$ is the DSSIM weight (default 0.2), and SSIM is the structural similarity index [S1, unofficial].

**Pseudocode**
```python
def mip_splatting_training_loop(gaussians, train_cameras, opt, dataset, pipe, background, iteration):
    # 1. Update Learning Rate
    gaussians.update_learning_rate(iteration)
    
    # 2. Increase SH Degree every 1000 iterations
    if iteration % 1000 == 0:
        gaussians.oneupSHdegree()
        
    # 3. Sample Camera
    if len(viewpoint_stack) > 0:
        viewpoint_cam = viewpoint_stack.pop(0)
    else:
        viewpoint_cam = train_cameras[0] # Fallback
        
    if dataset.sample_more_highres and random.random() < 0.3:
        viewpoint_cam = train_cameras[highresolution_index]
        
    # 4. Generate Subpixel Offset
    if dataset.ray_jitter:
        subpixel_offset = torch.rand(H, W, 2, device='cuda') - 0.5
    else:
        subpixel_offset = None
        
    # 5. Render
    render_dict = render(
        viewpoint_cam, 
        gaussians, 
        pipe, 
        background, 
        kernel_size=dataset.kernel_size, 
        subpixel_offset=subpixel_offset
    )
    image = render_dict["render"]
    viewspace_point_tensor = render_dict["viewspace_points"]
    visibility_filter = render_dict["visibility_filter"]
    radii = render_dict["radii"]
    
    # 6. Resample Ground Truth
    gt_image = load_gt_image(viewpoint_cam)
    if dataset.resample_gt_image:
        gt_image = create_offset_gt(gt_image, subpixel_offset)
        
    # 7. Track Statistics
    gaussians.max_radii2D[visibility_filter] = torch.max(
        gaussians.max_radii2D[visibility_filter], 
        radii[visibility_filter]
    )
    gaussians.add_densification_stats(viewspace_point_tensor, visibility_filter)
    
    # 8. Densification and Pruning
    if iteration > opt.densify_from_iter and iteration % opt.densification_interval == 0:
        if iteration > opt.opacity_reset_interval:
            size_threshold = 20
        else:
            size_threshold = None
            
        gaussians.densify_and_prune(
            opt.densify_grad_threshold, 
            0.005, 
            scene.cameras_extent, 
            size_threshold
        )
        gaussians.compute_3D_filter(cameras=train_cameras)
        
    # 9. Opacity Reset
    if iteration % opt.opacity_reset_interval == 0:
        gaussians.reset_opacities()
    elif dataset.white_background and iteration == opt.densify_from_iter:
        gaussians.reset_opacities()
        
    # 10. Late Stage 3D Filter Update
    if iteration > opt.densify_until_iter:
        if iteration % 100 == 0 and iteration < opt.iterations - 100:
            gaussians.compute_3D_filter(cameras=train_cameras)
            
    # 11. Optimization Step
    loss = compute_loss(image, gt_image, opt.lambda_dssim)
    loss.backward()
    gaussians.optimizer.step()
    gaussians.optimizer.zero_grad(set_to_none=True)
    
    return loss
```

## Operating characteristics
*   **Time Complexity:** Dominated by the rendering step and the periodic densification/filter updates. The subpixel offset generation and GT resampling add minor overhead proportional to image resolution $H \times W$.
*   **Memory Complexity:** Requires storage for `max_radii2D` (size $N$) and temporary tensors for subpixel offsets $(H, W, 2)$.
*   **Strengths:** The subpixel jittering and GT resampling reduce aliasing artifacts, leading to higher quality reconstructions at high resolutions compared to standard splatting [S1, unofficial].
*   **Limitations:** The additional sampling and resampling steps increase per-iteration time. The method relies on specific dataset flags (`ray_jitter`, `resample_gt_image`) which may not be available in all standard pipelines [S1, unofficial].
*   **When to use:** When training 3D Gaussian Splatting models where high-frequency details and aliasing suppression are critical, and sufficient computational resources are available for the extra overhead [S1, unofficial].

## Background
Mip-Splatting extends the original 3D Gaussian Splatting framework by addressing aliasing issues through subpixel-aware rendering techniques. The training loop described here is implemented in the `mip-splatting` repository, which provides an unofficial but widely used reference implementation for this variant [S1, unofficial].
