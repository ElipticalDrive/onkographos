# UltraGauss Rendering

Also called: 3D Gaussian Splatting for Ultrasound, Ultrasound Gaussian Splatting

## Overview
UltraGauss Rendering is a domain-specific adaptation of 3D Gaussian Splatting designed for reconstructing and rendering 3D ultrasound volumes [S1, unofficial]. Unlike standard RGB Gaussian Splatting, which projects 3D Gaussians onto a 2D image plane to model occlusion and depth-based transparency, UltraGauss treats the ultrasound probe plane as a 3D intersection target [S1, unofficial]. It evaluates Gaussian opacity using a 3D Mahalanobis distance to detect intersections with the probe plane, thereby avoiding the incorrect occlusion modeling inherent in standard alpha-blending for volumetric ultrasound data [S1, unofficial]. This method replaces view-dependent spherical harmonics with view-independent scalar attributes, as ultrasound intensity is primarily determined by tissue properties rather than viewing angle [S1, unofficial].

## How it works
### Inputs and Outputs
*   **Inputs:** A set of $M$ 3D Gaussians $\mathcal{G} = \{G_i\}_{i=1}^M$, where each Gaussian $i$ is defined by position $\mu_i$, covariance $\Sigma_i$, color $c_i$, and opacity $\alpha_i$. A probe transformation matrix $W$ mapping world coordinates to the probe's local coordinate frame.
*   **Outputs:** A 2D rendered image with color $\hat{c}(x)$ and accumulated opacity $\hat{\alpha}(x)$ for each pixel $x$ in the probe's pixel grid.

### Data Structures
Each Gaussian $i$ stores:
*   $\mu_i \in \mathbb{R}^3$: Position.
*   $L_i \in \mathbb{R}^{3 \times 3}$: Lower-triangular matrix parameterizing the inverse covariance $\Sigma_i^{-1} = L_i L_i^T$. The diagonal elements are constrained to be positive via regularization $\beta$.
*   $c_i \in \mathbb{R}^3$: Color (scalar intensity in grayscale ultrasound, or RGB if colorized).
*   $\alpha_i \in \mathbb{R}$: Opacity, constrained to $[0, 1]$ via sigmoid activation during optimization.

The probe plane is defined in its local coordinate system where the $z$-axis is normal to the plane ($z=0$).

### Parameters
*   $\beta$: Regularization constant added to diagonal elements of $L$ to ensure positive definiteness. Value not explicitly given, but implied $>0$ [S1, unofficial].
*   $p$: Probability density percentage for bounding box calculation. Typically $95\%$, corresponding to a chi-squared bound $\chi_{3,1-p}^2 = 7.815$ for 3 degrees of freedom [S1, unofficial].
*   $\alpha_{BG}$: Background opacity coefficient. Added to avoid division by zero in the final color blending equation and improve numerical stability [S1, unofficial]. Value not explicitly given [S1, unofficial].
*   $c_{BG}$: Background color. Value not explicitly given [S1, unofficial].

### Steps

1.  **Coordinate Transformation:**
    For each Gaussian $i$, transform its parameters into the probe's local coordinate frame using the inverse of the probe's extrinsic matrix $W$.
    $$ \mu_i^{3D} = W^{-1} \mu_i $$
    $$ \Sigma_i^{3D} = W \Sigma_i W^T $$
    Note: The source text contains a typo in the mean transformation formula ($\mu_i^{3D} = W^{-1} (W \mu_i)$), which simplifies to $\mu_i$. The correct transformation from world to probe frame is $\mu_i^{3D} = W^{-1} \mu_i$ [S1, unofficial]. The covariance transforms as a tensor: $\Sigma_i^{3D} = W \Sigma_i W^T$ [S1, unofficial].

2.  **Inverse Covariance Parameterization:**
    Compute the inverse covariance matrix $\Sigma_i^{3D^{-1}}$ using the lower-triangular factorization $L_i^{3D}$ derived from $\Sigma_i^{3D}$. To ensure numerical stability and positive definiteness, $L$ is parameterized such that:
    $$ \Sigma_i^{3D^{-1}} = L_i^{3D} (L_i^{3D})^T $$
    where $L_i^{3D}$ is a lower-triangular matrix. The diagonal elements are regularized:
    $$ L_{jj} = \tilde{L}_{jj}^2 + \beta $$
    This avoids the numerical instabilities associated with quaternion normalization used in standard 3DGS [S1, unofficial].

3.  **Bounding Box Calculation (Rejection Phase):**
    Calculate the 3D bounding box for each Gaussian in the probe frame. The box encloses the ellipsoid containing $p\%$ of the probability density.
    $$ b^{\min/\max}_i = \mu_i^{3D} \pm \sqrt{\lambda v} $$
    where $\lambda = \frac{\chi_{3,1-p}^2}{\det(\Sigma_i^{3D})}$ and $v$ represents the eigenvectors scaled by eigenvalues (specifically, the bounding box is derived from the ellipsoid equation $(x-\mu)^T \Sigma^{-1} (x-\mu) \leq \chi^2$) [S1, unofficial].
    *   **Rejection:** If the Gaussian's bounding box does not intersect the probe plane ($z=0$), specifically if $b^{\min}_3 > 0$ or $b^{\max}_3 < 0$, the Gaussian is rejected and excluded from rasterization [S1, unofficial].

4.  **Rasterization (Intersection Phase):**
    For each accepted Gaussian, determine the 2D bounding box on the probe plane ($z=0$) defined by $b^{\min}_{1,2}$ and $b^{\max}_{1,2}$. Iterate over all pixels $x = (x_1, x_2)$ within this 2D bounding box.
    *   **Lift to 3D:** Lift the 2D pixel coordinate to the probe's 3D coordinate frame: $x_{|0} = [x_1, x_2, 0]^T$.
    *   **Compute Opacity:** Calculate the opacity contribution $\hat{\alpha}_i(x)$ using the 3D Mahalanobis distance:
        $$ \hat{\alpha}_i(x) = \alpha_i \exp \left( -\frac{1}{2} (x_{|0} - \mu_i^{3D})^T (\Sigma_i^{3D})^{-1} (x_{|0} - \mu_i^{3D}) \right) $$
    *   **Accumulate:** Atomically add $\hat{\alpha}_i(x) c_i$ to the color accumulator and $\hat{\alpha}_i(x)$ to the opacity accumulator for pixel $x$ [S1, unofficial].

5.  **Final Blending:**
    After processing all Gaussians, compute the final color and opacity for each pixel $x$:
    $$ \hat{\alpha}(x) = \sum_i^n \hat{\alpha}_i(x) + \alpha_{BG} $$
    $$ \hat{c}(x) = \frac{1}{\hat{\alpha}(x)} \left( \sum_i^n \hat{\alpha}_i(x) c_i + \alpha_{BG} c_{BG} \right) $$
    where $n$ is the number of accepted Gaussians intersecting the pixel [S1, unofficial].

### Edge Cases and Pitfalls
*   **Numerical Instability:** Quaternion normalization for covariance parameterization causes numerical instabilities in this setting. The method uses a lower-triangular matrix $L$ with $\beta$ regularization instead [S1, unofficial].
*   **Ill-Conditioned Inversion:** Explicitly inverting $\Sigma^{-1}$ for resampling is numerically unstable. The lower-triangular factorization $L$ allows efficient inversion via forward substitution [S1, unofficial].
*   **Occlusion Modeling:** Standard alpha-blending assumes occlusion. In ultrasound, the probe plane intersects the volume, and occlusions do not play the same role. Using standard depth sorting and transmittance $T(x)$ is incorrect. The method relies on intersection detection, not projection [S1, unofficial].
*   **Division by Zero:** If no Gaussians intersect a pixel, $\hat{\alpha}(x)$ could be zero, causing division by zero in the color blending equation. The background term $\alpha_{BG}$ prevents this [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The method avoids the nested iteration over all pixels and all Gaussians by using bounding box rejection and tile-based load balancing. The complexity is proportional to the number of Gaussians intersecting the probe plane times the average number of pixels per intersection [S1, unofficial].
*   **Memory Complexity:** Stores $M$ Gaussians. The source supports up to 2 million Gaussians on an NVIDIA RTX A4000 GPU [S1, unofficial].
*   **Performance:** The custom CUDA kernels allow for efficient rendering. The method is faster than naive evaluation of the 3D Mahalanobis distance for all Gaussians [S1, unofficial].
*   **Strengths:** Accurate reconstruction of 3D ultrasound volumes; handles volumetric data without incorrect occlusion modeling; efficient via bounding box rejection.
*   **Limitations:** Specific to ultrasound/volumetric data; requires careful initialization of Gaussians within the volume boundaries; lacks view-dependent color modeling (spherical harmonics are omitted) [S1, unofficial].

## Background
UltraGauss was introduced to address the limitations of applying standard 3D Gaussian Splatting to ultrasound imaging. Standard 3DGS projects Gaussians to 2D, which is suitable for surface-based visual spectrum images but incorrect for ultrasound, where the probe plane intersects the volume [S1, unofficial]. The method was developed to enable ultrafast Gaussian reconstruction of 3D ultrasound volumes, utilizing clinical datasets (volumetric scans and freehand video sequences) for validation [S1, unofficial]. It was implemented in PyTorch with custom CUDA kernels [S1, unofficial].
