# Neural Radiance Field (NeRF) Representation

Also called: 3D Gaussian scene representation, Differentiable 3D Gaussian Splatting, INGP, Instant Neural Graphics Primitives, Multi-resolution Hash Map NeRF, NeRF Scene Representation, Photon Field Networks, Photon Fields

## Overview
Neural Radiance Fields (NeRF) represent a 3D scene as a continuous volumetric function that maps spatial coordinates and view directions to color and volume density, enabling high-quality novel view synthesis via differentiable volume rendering [S4]. While the term broadly covers implicit neural representations, in the context of this article's specific source material, it also encompasses explicit variants like 3D Gaussian Splatting, which replaces neural network evaluation with differentiable rasterization of 3D Gaussians to achieve real-time performance [S2, unofficial][S3]. Unlike traditional ray-marching NeRFs that evaluate a neural network at hundreds of points per ray, 3D Gaussian Splatting projects explicit 3D Gaussian blobs onto the screen, avoiding neural inference during rendering [S3].

## How it works
The method varies significantly depending on whether the representation is implicit (standard NeRF/Photon Fields) or explicit (3D Gaussian Splatting). The following sections detail both, as both are cited under the "NeRF Representation" umbrella in the provided sources.

### Inputs and Outputs
*   **Inputs:** A set of 2D images with known camera poses (typically obtained via Structure-from-Motion, SfM) [S3]. For Photon Fields, additional inputs include light source positions and phase function coefficients [S1].
*   **Outputs:** A rendered RGB image for a novel viewpoint, or a trained scene representation (neural network weights or 3D Gaussian parameters) [S4, S3].

### Data Structures

#### Implicit Representation (Photon Fields / Standard NeRF)
*   **Neural Network:** A Multi-Layer Perceptron (MLP) or hash-grid encoded network [S1, S4].
    *   *Photon Fields:* 5-layer MLP, 64 neurons per layer, ReLU activations [S1].
    *   *Standard NeRF (Active Scout):* 2-layer MLP, 128 neurons per layer [S4].
*   **Encoding:** Multi-resolution hash map encoding for positions (3D) and directions (2D) [S1, S4].
    *   *Photon Fields:* 16 grid levels, 8 features per level, 2x scaling factor, hash table size $2^{19}$ [S1].
*   **Photon Map (Photon Fields only):** A collection of photons stored in a GPU-accelerated kd-tree for spatial queries [S1]. Each photon stores position, direction, intensity, and a phase coefficient $g$ [S1].

#### Explicit Representation (3D Gaussian Splatting)
*   **3D Gaussian Primitive:** Each Gaussian is defined by learnable parameters [S3]:
    *   **Position:** Mean $\mu \in \mathbb{R}^3$ [S3].
    *   **Covariance:** $\Sigma \in \mathbb{R}^{3 \times 3}$, parameterized by a rotation matrix $R$ and scale vector $S$ such that $\Sigma = R S S^T R^T$ to ensure positive semi-definiteness [S3].
    *   **Opacity:** $\alpha \in [0, 1)$, constrained via sigmoid activation [S3].
    *   **Color:** Spherical Harmonics (SH) coefficients for view-dependent color [S3].
*   **Scene Size:** 1–5 million Gaussians for typical scenes [S3]. Each Gaussian stores approximately 59 learnable numbers [S2, unofficial].

### Steps

#### 1. Initialization
*   **Standard NeRF/Photon Fields:** Initialize the neural network weights randomly [S1, S4].
*   **3D Gaussian Splatting:** Initialize the set of 3D Gaussians using the sparse point cloud generated by SfM [S3]. Each SfM point becomes the mean position $\mu$ of one Gaussian [S2, unofficial].

#### 2. Training Data Generation (Photon Fields Specific)
*   Generate batches of size $2^{16}$ containing uniformly sampled grid coordinates $x \in [0,1]^3$, random uniform directions $\vec{\omega}$, and phase coefficients $g$ [S1].
*   Compute ground truth radiance $L_i(x, \vec{\omega})$ using a KNN query on the photon map with $K=1024$ neighbors [S1].
*   Encode the target radiance logarithmically to $[0,1]$ using precision parameter $\psi$ (typically 4–6) [S1]:
    $$
    L_i'(x, \vec{\omega}) = \begin{cases} -\frac{\log_{10}(L_i(x, \vec{\omega}))}{\psi} & \text{if } L_i(x, \vec{\omega}) > 10^{-\psi} \\ 1 & \text{otherwise} \end{cases}
    $$
    [S1]

#### 3. Rendering

**Implicit (Ray Marching):**
1.  For each pixel, cast a ray from the camera.
2.  Sample points $x(s)$ along the ray [S4].
3.  Query the neural network $F$ at each point to get color $\mathbf{c}$ and density $\sigma$ [S4].
4.  Compute transmittance $T_i = \prod_{j=1}^{i-1} \exp(-\sigma_j \delta_j)$ and accumulated color [S4].

**Explicit (3D Gaussian Splatting):**
1.  **Projection:** Project each 3D Gaussian to 2D. The 2D covariance $\Sigma'$ in camera coordinates is computed using the Jacobian $J$ of the affine approximation of the projective transformation and the viewing transformation $W$:
    $$
    \Sigma' = J W \Sigma W^T J^T
    $$
    [S3]
2.  **Tiling:** Divide the screen into tiles (e.g., 16x16 pixels). Assign each Gaussian to overlapping tiles [S2, unofficial].
3.  **Sorting:** Sort Gaussians within each tile by depth (front-to-back) using a fast GPU sort [S2, unofficial].
4.  **Rasterization/Blending:** For each pixel, blend colors front-to-back using alpha compositing [S2, unofficial]:
    $$
    C = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
    $$
    where $\alpha_i$ is the opacity of the $i$-th Gaussian at the pixel [S3].

#### 4. Optimization
*   **Loss Function:** Minimize the difference between rendered and ground truth images.
    *   *Standard NeRF:* $\ell = \lambda_1 \ell_{rgb} + \lambda_2 \ell_{depth}$, using L1 loss for both [S4].
    *   *3D Gaussian Splatting:* L1 loss combined with Structural Similarity (SSIM) [S2, unofficial].
*   **Gradient Update:**
    *   *Implicit:* Update network weights via Stochastic Gradient Descent (SGD) [S4].
    *   *Explicit:* Backpropagate gradients directly to Gaussian parameters (position, covariance, opacity, SH coefficients) [S3]. Gradients are computed explicitly to avoid overhead [S3].
*   **Adaptive Density Control (3D Gaussian Splatting only):**
    *   *Cloning:* Clone small Gaussians in under-reconstructed regions [S2, unofficial].
    *   *Splitting:* Split large Gaussians that cover too much detail [S2, unofficial].
    *   *Pruning:* Remove Gaussians that become nearly transparent [S2, unofficial].
    *   These steps are interleaved with optimization to maintain compactness and handle geometry ambiguities [S3].

### Parameters
*   **$\psi$ (Precision):** Maximum desired floating point precision digits beyond zero. Values 4–6 are sufficient [S1].
*   **$G$ (Phase Coefficients):** Discrete set of scattering coefficients. $\{-0.75, 0.0, 0.75\}$ is a common choice [S1].
*   **$\lambda_1, \lambda_2$:** Loss weights, tuned to balance $\ell_{rgb}$ and $\ell_{depth}$ magnitudes [S4].
*   **Batch Size:** $2^{16}$ for Photon Fields training batches [S1].

### Edge Cases and Pitfalls
*   **Covariance Validity:** Directly optimizing the covariance matrix $\Sigma$ is invalid because gradient descent cannot easily constrain it to be positive semi-definite. It must be parameterized via $R$ and $S$ [S3].
*   **Unbounded Scenes:** For scenes with sky/infinity, rays extend indefinitely, causing density mismatches. Solution: Model occupancy as a Bernoulli random variable to handle the probability of hitting an obstacle vs. going to infinity [S4].
*   **Artifacts:** 3D Gaussian Splatting may produce floating artifacts and needle-like Gaussians in regions seen by few cameras, and aliasing when zooming [S2, unofficial].
*   **SAM Inaccuracy:** In Mask Inverse Rendering variants, if the Segment Anything Model (SAM) is inaccurate, the projection loss fails. A negative refinement term is required to ensure consistency across views [S5].

## Subtopics

### [Scene NeRF](12484-scene-nerf.md)
Isolates static background by training exclusively on background pixels, using an emptiness regularizer.

### [NeRF-OSR](14477-nerf-osr.md)
Outdoor scene relighting that decomposes scene into geometry, albedo, and illumination for physical relighting.

### [Explicit Volumetric Rendering with Multiple View Aggregation](15335-explicit-volumetric-rendering-with-multiple-view-aggregation.md)
Models scene as an explicit RGB$\alpha$ volume to amortize rendering across views, enabling real-time rendering and SSIM losses.

### [Dynamic Neural Radiance Fields](16398-dynamic-neural-radiance-fields.md)
Models dynamic human faces using a morphable model conditioned on expression parameters and latent codes, requiring only monocular input.

### [Neural Network Pruning for NeRF](17703-neural-network-pruning-for-nerf.md)
Compresses NeRF by pruning small-magnitude MLP weights, reducing storage and inference time.

### [Scene Auto-Encoder](17789-scene-auto-encoder.md)
Encodes RGB images into discrete density and feature voxel grids via 2D CNN encoder and frustum lifting.

### [Bi-level Neural Volume Fusion](19888-bi-level-neural-volume-fusion.md)
Incrementally integrates noisy depth maps into a global neural implicit representation using local weighted averaging and global neural rendering optimization.

### [Neural Radiance Field Codebooks (NRC)](21345-neural-radiance-field-codebooks-nrc.md)
Maps continuous spatial features to a discrete codebook for scalable, object-centric representations with constant rendering compute.

### Mask Inverse Rendering
Projects 2D masks from SAM into 3D space to form 3D masks. Optimizes volume values $V(r(t))$ or mask values $m_{gi}$ to increase confidence where SAM predicts foreground. Uses loss $L_{proj} = - \sum_{r \in R(I)} MSAM(r) \cdot M(r)$, potentially with a negative refinement term $\lambda \sum (1 - MSAM(r)) \cdot M(r)$ to handle SAM inaccuracies [S5].

## Operating characteristics
*   **Time Complexity:**
    *   *Standard NeRF:* Training takes many hours (e.g., 48 hours for Mip-NeRF360 quality) [S3]. Rendering is slow (seconds per image) due to ray marching and network evaluation [S2, unofficial].
    *   *3D Gaussian Splatting:* Training is competitive with fast methods (e.g., InstantNGP), achieving SOTA quality in ~51 minutes [S3]. Rendering is real-time ($\ge 30$ fps at 1080p) [S3].
*   **Memory Complexity:**
    *   *Standard NeRF:* Low memory usage (few megabytes for network weights) [S2, unofficial].
    *   *3D Gaussian Splatting:* High memory usage (hundreds of megabytes for millions of Gaussians) [S2, unofficial].
*   **Strengths:**
    *   High visual quality comparable to SOTA NeRF methods [S3].
    *   Real-time rendering capability (Gaussian Splatting) [S3].
    *   No need for MVS data; works with sparse SfM points [S3].
    *   Explicit representation allows flexible geometry creation/destruction [S3].
*   **Limitations:**
    *   Gaussian Splatting lacks a clean surface/mesh extraction [S2, unofficial].
    *   Aliasing issues when zooming in/out [S2, unofficial].
    *   Floating artifacts in sparse-view regions [S2, unofficial].
*   **When to Use:**
    *   Use Standard NeRF for high-quality offline rendering with limited memory.
    *   Use 3D Gaussian Splatting for real-time applications (VR, robotics, web) where training speed and rendering FPS are critical [S2, unofficial].

## Background
Neural Radiance Fields were introduced by Mildenhall et al. in 2020, revolutionizing novel view synthesis by representing scenes as continuous volumetric functions [S4]. The field has evolved to include implicit global illumination methods like Photon Field Networks (2023), which use neural networks to approximate in-scattered radiance [S1], and explicit methods like 3D Gaussian Splatting, introduced by Kerbl et al. at SIGGRAPH 2023, which replaced neural evaluation with differentiable rasterization for real-time performance [S2, unofficial][S3]. These methods are used in virtual reality, film, robotics, and cultural heritage [S2, unofficial].
