# Deformable 3D Gaussians

Also called: Deformable-GS

## Overview
Deformable 3D Gaussians is a framework for modeling monocular dynamic scenes that extends static 3D Gaussian Splatting by learning time-independent 3D Gaussians in a canonical space and using a neural deformation field to model time-varying geometry [S1]. It solves the problem of high-fidelity, real-time rendering of dynamic scenes from monocular video sequences, where traditional implicit methods suffer from slow convergence and overfitting, and frame-by-frame reconstruction lacks temporal continuity [S1]. Unlike entangled methods that condition a radiance field directly on time, this method decouples the static geometry (represented by discrete 3D Gaussians) from the dynamic motion (represented by a deformation field), enabling efficient differentiable rendering and adaptive density control [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of images from a monocular dynamic scene, corresponding time labels $t$, camera poses calibrated by Structure from Motion (SfM) [S1], and a sparse point cloud generated by SfM [S1].
*   **Outputs:** A rendered image for a given camera pose and time $t$, and a set of optimized 3D Gaussians and deformation network parameters [S1].

**Data Structures**
1.  **3D Gaussians ($G$):** Defined in canonical space. Each Gaussian $i$ is stored as:
    *   Center position: $\mathbf{x}_i \in \mathbb{R}^3$
    *   Opacity: $\sigma_i \in \mathbb{R}$
    *   Rotation: Quaternion $\mathbf{r}_i \in \mathbb{R}^4$
    *   Scaling: Vector $\mathbf{s}_i \in \mathbb{R}^3$
    *   Color: Spherical Harmonics (SH) coefficients [S1].
    *   The 3D covariance matrix $\Sigma_i$ is derived from $\mathbf{r}_i$ and $\mathbf{s}_i$ as $\Sigma_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^T \mathbf{R}_i^T$, where $\mathbf{R}_i$ is the rotation matrix from $\mathbf{r}_i$ and $\mathbf{S}_i$ is the diagonal scaling matrix from $\mathbf{s}_i$ [S1].
2.  **Deformation Network ($F_\theta$):** A Multi-Layer Perceptron (MLP) with depth $D=8$ and hidden layer dimension $W=256$ [S1].
    *   Input: Concatenated positional encodings of the canonical position $\gamma(\text{sg}(\mathbf{x}))$ and time $\gamma(t)$ [S1].
    *   Output: Offsets $(\delta\mathbf{x}, \delta\mathbf{r}, \delta\mathbf{s})$ [S1].

**Positional Encoding**
The positional encoding function $\gamma(\mathbf{p})$ is defined as:
$$ \gamma(\mathbf{p}) = (\sin(2^k \pi \mathbf{p}), \cos(2^k \pi \mathbf{p}))_{k=0}^{L-1} $$
where $L$ is the number of frequency bands [S1].
*   For synthetic scenes: $L=10$ for position $\mathbf{x}$, $L=6$ for time $t$ [S1].
*   For real scenes: $L=10$ for both position $\mathbf{x}$ and time $t$ [S1].

**Numbered Steps**

1.  **Initialization:** Initialize the set of 3D Gaussians $G(\mathbf{x}, \mathbf{r}, \mathbf{s}, \sigma)$ from the SfM sparse point cloud or random generation. The view-dependent appearance is represented via spherical harmonics [S1].
2.  **Warm-up Phase (Iterations $0$ to $3000$):** Optimize only the parameters of the 3D Gaussians (position, rotation, scale, opacity, SH coefficients) using the standard differentiable Gaussian rasterization pipeline. The deformation field parameters are frozen or not updated [S1].
3.  **Joint Optimization (Iterations $3000+$):**
    *   For each training iteration $i$:
        *   Sample a random image, its time label $t$, and camera pose [S1].
        *   **Deformation Calculation:** Compute the deformation offsets using the deformation network. To handle pose inaccuracies in real-world datasets, apply the Annealing Smooth Training (AST) mechanism [S1]:
            $$ \Delta = F_\theta (\gamma(\text{sg}(\mathbf{x})), \gamma(t + X(i))) $$
            where $X(i)$ is linearly decaying Gaussian noise:
            $$ X(i) = \mathcal{N}(0, 1) \cdot \beta \cdot \Delta t \cdot (1 - i/\tau) $$
            Here, $\mathcal{N}(0, 1)$ is standard Gaussian noise, $\beta=0.1$, $\Delta t$ is the mean time interval between frames, and $\tau=20,000$ iterations [S1].
        *   **Deformation Application:** Transform the canonical Gaussians to the deformed space:
            $$ G_{\text{deformed}} = G(\mathbf{x} + \delta\mathbf{x}, \mathbf{r} + \delta\mathbf{r}, \mathbf{s} + \delta\mathbf{s}, \sigma) $$
            where $(\delta\mathbf{x}, \delta\mathbf{r}, \delta\mathbf{s})$ are the outputs of $F_\theta$ [S1].
        *   **Rendering:** Project the deformed 3D Gaussians to 2D screen space. The 2D covariance matrix $\Sigma'$ is computed as:
            $$ \Sigma' = \mathbf{J} \mathbf{V} \Sigma \mathbf{V}^T \mathbf{J}^T $$
            where $\mathbf{J}$ is the Jacobian of the affine approximation of the projective transformation, $\mathbf{V}$ is the view matrix, and $\Sigma$ is the 3D covariance matrix of the deformed Gaussian [S1].
        *   **Rasterization:** Render the image using alpha blending. The color $C(\mathbf{p})$ for a pixel $\mathbf{p}$ is:
            $$ C(\mathbf{p}) = \sum_{i \in N} T_i \alpha_i c_i $$
            where $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the transmittance, $\alpha_i = \sigma_i e^{-\frac{1}{2}(\mathbf{p}-\boldsymbol{\mu}_i)^T \Sigma'^{-1} (\mathbf{p}-\boldsymbol{\mu}_i)}$ is the opacity of the $i$-th Gaussian, $c_i$ is the color, and $N$ is the set of Gaussians along the ray [S1].
        *   **Loss Computation:** Compute the loss using L1 and D-SSIM metrics between the rendered image and the ground truth [S1].
        *   **Backpropagation:** Compute gradients for both the 3D Gaussian parameters and the deformation network parameters $F_\theta$ using the customized differential Gaussian rasterization pipeline [S1].
        *   **Optimization Step:** Update parameters using the Adam optimizer ($\beta_1=0.9, \beta_2=0.999$) [S1].
            *   Learning rate for 3D Gaussians: Standard value (same as static 3D-GS) [S1].
            *   Learning rate for Deformation Network: Exponential decay from $8 \times 10^{-4}$ to $1.6 \times 10^{-6}$ [S1].
4.  **Adaptive Density Control:** Applied iteratively during optimization [S1]:
    *   **Pruning:** Remove Gaussians with opacity $\sigma$ below a threshold [S1].
    *   **Densification:** For Gaussians with positional gradient magnitude $> t_{\text{pos}} = 0.0002$ and small scale, clone the Gaussian and move it in the direction of the positional gradient [S1].
    *   **Splitting:** For Gaussians with large scale and high overlap, split them by dividing their scale by $\xi = 1.6$ [S1].

import torch
import torch.nn as nn
import torch.optim as optim

class PositionalEncoding(nn.Module):
    def __init__(self, L):
        super().__init__()
        self.L = L

    def forward(self, p):
        # p shape: (..., 1)
        freq_bands = 2.0 ** torch.arange(self.L, device=p.device).float()
        # sin(2^k * pi * p), cos(2^k * pi * p)
        sines = torch.sin(freq_bands * torch.pi * p)
        cosines = torch.cos(freq_bands * torch.pi * p)
        return torch.cat([sines, cosines], dim=-1)

class DeformationNetwork(nn.Module):
    def __init__(self, input_dim_x, input_dim_t, hidden_dim=256, depth=8):
        super().__init__()
        self.pe_x = PositionalEncoding(input_dim_x) # L=10 or 6
        self.pe_t = PositionalEncoding(input_dim_t) # L=10 or 6
        
        # Input dim is 2 * L_x + 2 * L_t
        total_input_dim = 2 * input_dim_x + 2 * input_dim_t
        
        layers = []
        for _ in range(depth):
            layers.append(nn.Linear(total_input_dim, hidden_dim))
            layers.append(nn.ReLU())
            total_input_dim = hidden_dim
        # Output: delta_x (3), delta_r (4), delta_s (3) -> 10 dims
        layers.append(nn.Linear(hidden_dim, 10))
        self.net = nn.Sequential(*layers)

        # x_canonical: (N, 3), t: scalar or (N,)
        # Apply stop-gradient to x
        x_enc = self.pe_x(x_canonical.detach())
        
        t_val = t

## Operating characteristics
*   **Time Complexity:** Training is significantly faster than implicit dynamic NeRF methods due to the discrete nature of 3D Gaussians and the use of a tile-based rasterizer [S1]. The deformation network adds minimal overhead compared to the rasterization cost [S1].
*   **Memory Complexity:** Memory usage is proportional to the number of 3D Gaussians, which is managed via adaptive density control (pruning and splitting) [S1]. The deformation network is small (8 layers, 256 hidden units) [S1].
*   **Performance:** Achieves real-time rendering speeds on standard hardware (e.g., NVIDIA GPUs) [S1]. High-fidelity reconstruction quality comparable to or exceeding implicit methods, particularly in preserving fine details [S1].
*   **Strengths:** Decouples geometry and motion, allowing for stable canonical space representation. The AST mechanism effectively mitigates jitter caused by inaccurate SfM poses in real-world data without extra computational cost during inference [S1].
*   **Limitations:** Relies on the quality of SfM poses; while AST helps, severe pose inaccuracies may still impact results. The method is designed for monocular dynamic scenes; multi-view setups may require different handling [S1]. The deformation field assumes continuous motion, which may struggle with highly discontinuous or non-rigid deformations outside the training distribution [S1].
*   **When to use:** Suitable for reconstructing and rendering dynamic scenes from monocular video where real-time performance and high fidelity are required, and where SfM provides reasonably accurate poses [S1].
*   **When not to use:** Not suitable for scenes with extreme non-rigid deformations that cannot be captured by a local deformation field, or when multi-view static scene reconstruction is the goal (static 3D-GS is more appropriate) [S1].

## Background
Deformable 3D Gaussians was proposed in the paper "Deformable 3D Gaussians for High-Fidelity Monocular Dynamic Scene Reconstruction" [S1]. It builds upon the seminal work of 3D Gaussian Splatting [S1], which introduced efficient differentiable rasterization for static scenes. The method addresses the limitations of implicit representations (like NeRF) for dynamic scenes, which suffer from slow convergence and overfitting [S1]. It is part of the broader trend of using discrete structures (voxels, planes, points) for dynamic scene modeling to improve efficiency [S1]. The specific contribution of this method is the decoupling of 3D Gaussians and the deformation field, along with the introduction of Annealing Smooth Training (AST) to handle real-world pose inaccuracies [S1].
