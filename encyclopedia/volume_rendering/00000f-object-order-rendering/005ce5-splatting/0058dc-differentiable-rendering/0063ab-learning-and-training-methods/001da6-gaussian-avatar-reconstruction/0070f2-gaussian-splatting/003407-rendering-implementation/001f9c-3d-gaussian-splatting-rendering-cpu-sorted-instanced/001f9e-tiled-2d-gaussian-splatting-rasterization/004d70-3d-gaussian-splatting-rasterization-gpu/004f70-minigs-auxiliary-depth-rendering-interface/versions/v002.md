# MiniGS Auxiliary & Depth Rendering Interface

Also called: MiniGS depth rasterization, MiniGS rasterization auxiliary

## Overview
The MiniGS Auxiliary & Depth Rendering Interface is a validation and dispatch layer for MiniGS-specific rasterizer entry points that return auxiliary statistics for blur-aware splitting and depth back-sampling [S1, unofficial]. It distinguishes itself from standard rendering by enforcing strict preconditions on the input configuration and attribute tensors before dispatching to the appropriate rasterization kernel [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs**: `means3D`, `means2D`, `dc`, `shs`, `opacities`, `scales`, `rotations`, and `raster_settings` [S1, unofficial].
*   **Outputs**: The result of the dispatched rasterization function, which returns auxiliary statistics and depth data [S1, unofficial].

**Data Structures**
*   `raster_settings`: Contains `inference_only` (bool) and `pixel_weights` (tensor) [S1, unofficial].

**Numbered Steps**
1.  Check `raster_settings.inference_only`; it must be `False` [S1, unofficial].
2.  Check `raster_settings.pixel_weights`; it must be `None` or empty [S1, unofficial].
3.  Validate that `dc`, `shs`, `scales`, and `rotations` are not `None` [S1, unofficial].
4.  Dispatch to `minigs_rasterize_gaussians_aux` or `minigs_rasterize_gaussians_depth` with `means3D`, `means2D`, `dc`, `shs`, `opacities`, `scales`, `rotations`, and `raster_settings` [S1, unofficial].

**Pseudocode**
```python
def minigs_auxiliary_depth_interface(
    means3D, means2D, dc, shs, opacities, scales, rotations, raster_settings
):
    # Step 1: Validate inference mode
    if raster_settings.inference_only:
        raise Exception("MiniGS auxiliary rendering does not support inference_only=True.")
    # Step 2: Validate pixel weights
    if raster_settings.pixel_weights is not None and raster_settings.pixel_weights.numel() > 0:
        raise Exception("MiniGS auxiliary rendering does not support pixel_weights.")
    # Step 3: Validate attribute tensors
    if dc is None or shs is None or scales is None or rotations is None:
        raise ValueError("dc, shs, scales, and rotations must not be None.")
    # Step 4: Dispatch to auxiliary or depth rasterizer
    # Source does not specify the exact selection logic between the two kernels [G]
    return minigs_rasterize_gaussians_aux(
        means3D, means2D, dc, shs, opacities, scales, rotations, raster_settings
    )
```

**Parameters**
*   `inference_only`: `bool`. Must be `False` [S1, unofficial].
*   `pixel_weights`: `tensor`. Must be `None` or empty [S1, unofficial].
*   `dc`: `tensor`. Diffuse color [S1, unofficial].
*   `shs`: `tensor`. Spherical harmonics coefficients [S1, unofficial].
*   `scales`: `tensor`. Gaussian scales [S1, unofficial].
*   `rotations`: `tensor`. Gaussian rotations [S1, unofficial].

**Edge Cases and Pitfalls**
*   The interface explicitly fails if `inference_only=True` [S1, unofficial].
*   The interface explicitly fails if `pixel_weights` are provided and non-empty [S1, unofficial].
*   The method requires all five Gaussian attribute tensors (`dc`, `shs`, `scales`, `rotations`, `opacities`) to be present; failure to provide them results in errors [S1, unofficial].

## Background
The interface is part of the MiniGS implementation and is integrated into the training loop of the Improved-GS project [S1, unofficial]. It is specifically designed to support training-time operations such as blur-aware splitting and depth back-sampling [S1, unofficial].
