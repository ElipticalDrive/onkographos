# Global 3DGS with Progressively Growing

Also called: Progressive Global 3DGS, Sequential Global 3DGS

## Overview
Global 3DGS with Progressively Growing is a sequential reconstruction method that learns a global 3D Gaussian Splatting (3DGS) model by incrementally integrating frames, using estimated relative poses to update the scene representation and densify Gaussians to cover new views [S1]. It differs from standard global 3DGS by avoiding the dramatic impact of noisy relative poses on whole-scene optimization; instead, it grows the model frame-by-frame, aligning densification intervals with the addition of new frames to ensure continuous coverage of unobserved regions [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:** A sequence of images $\{I_t\}$ [S1].
- **Outputs:** A global set of 3D Gaussians $\mathcal{G}$ with all attributes and estimated camera poses for all frames [S1].

**Data Structures:**
- **3D Gaussian Set $\mathcal{G}$:** A collection of $K$ Gaussians. Each Gaussian $k$ has position $\mu_k \in \mathbb{R}^3$, rotation $R_k \in SO(3)$, scale $S_k \in \mathbb{R}^3$, opacity $\alpha_k \in [0, 1]$, and spherical harmonics coefficients $c_k$ [G].
- **Camera Poses:** For each frame $t$, a pose $P_t$ consisting of rotation $q_t \in SO(3)$ (quaternion) and translation $t_t \in \mathbb{R}^3$ [S1].

**Parameters:**
- $N$: Number of optimization iterations per step. Set equal to the interval between adding new frames and performing densification [S1].
- Initial learning rate for pose optimization: $10^{-5}$, gradually decaying to $10^{-6}$ until convergence [S1].
- Densification threshold: Based on the average magnitude of viewspace position gradients [S1].

**Steps:**
1. **Initialization:** Start with the first frame $I_0$. Initialize a set of 3D Gaussian points with the camera pose set as orthogonal [S1].
2. **Relative Pose Estimation:** Use Local 3DGS to estimate the relative camera pose between the current frame $I_t$ and the next frame $I_{t+1}$ [S1].
3. **Global Update:** Update the global 3D Gaussian set $\mathcal{G}$ and all its attributes over $N$ iterations using the estimated relative pose and the two observed frames ($I_t, I_{t+1}$) as inputs [S1].
4. **Pose Representation:** Camera poses are optimized in the representation of quaternion rotation $q \in SO(3)$ and translation vector $t \in \mathbb{R}^3$ [S1].
5. **Progression:** When the next frame $I_{t+2}$ becomes available, repeat the process: estimate the relative pose between $I_{t+1}$ and $I_{t+2}$, and infer the relative pose between $I_t$ and $I_{t+2}$ [S1].
6. **Densification:** Densify the global 3DGS every $N$ steps (aligned with the pace of adding new frames) [S1]. Candidates for densification are determined by the average magnitude of viewspace position gradients [S1].
7. **Opacity Reset:** Keep resetting the opacity of Gaussians until the end of the training process to enable integration of new frames into the existing model [S1].
8. **Continuous Growth:** Continue growing the 3D Gaussian points (densification) until the end of the input sequence, rather than stopping in the middle of training [S1].

**Pseudocode:**

def global_3dgs_progressive_growth(image_sequence):
    # Initialize 3D Gaussian points from the first frame with an orthogonal camera pose [S1]
    G = GaussianSet(points=generate_points(image_sequence[0]), poses={0: 'orthogonal'})
    
    # Parameters: N steps for adding frames equals densification intervals [S1]
    N = 1000  # Not given in the sources; typical value for 3DGS
    lr_pose_init = 1e-5
    lr_pose_final = 1e-6
    
    for t in range(len(image_sequence) - 1):
        I_curr = image_sequence[t]
        I_next = image_sequence[t + 1]
        
        # Estimate relative camera pose between I_curr and I_next using Local 3DGS [S1]
        relative_pose = optimize_pose(I_curr, I_next)
        
        for step in range(N):
            # Decay learning rate for pose optimization [S1]
            lr_pose = lr_pose_init * (lr_pose_final / lr_pose_init) ** (step / N)
            
            # Optimize global 3D Gaussian set and all attributes over N iterations [S1]
            for g in G:
                g.pos -= lr_pose * g.pos_grad
                # Update other attributes similarly
            # Update camera poses using quaternion representation q in SO(3) and t in R^3 [S1]
            
            # Reset opacity to enable integration of new frames [S1]
            for g in G:
                g.opacity = 0.0
        
        # Densify global 3DGS every N steps, aligned with adding new frames [S1]
        threshold = mean(abs(g.pos_grad) for g in G)
        for g in G:
            if abs(g.pos_grad) > threshold:
                split_or_clone(g)  # Standard 3DGS densification operation [G]
        
    return G

**Edge Cases and Pitfalls:**
- **Noisy Relative Poses:** Noisy relative poses can dramatically impact whole-scene optimization [S1]. The sequential progressive approach tackles this by updating the model frame-by-frame rather than inferring all poses globally at once [S1].
- **Under-reconstruction:** Unobserved frames may contain regions not yet well reconstructed. The optimization tries to move Gaussians to correct this with large gradient steps, which is why densification targets these regions [S1].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** Evaluated on Tanks and Temples and CO3D-V2 datasets [S1]. Achieves photo-realistic reconstruction and accurate camera pose estimation [S1].
- **Strengths:** Avoids dramatic impact of noisy relative poses; continuously covers new views; integrates new frames effectively [S1].
- **Limitations:** Requires sequential processing; densification must be carefully timed with frame addition [S1].

## Background
- **Origin:** Proposed in "COLMAP-Free 3D Gaussian Splatting" (CVPR 2024) [S1].
- **History:** Builds on 3D Gaussian Splatting [17] and Local 3DGS [S1]. Addresses issues with global 3DGS optimization when relative poses are noisy [S1].
- **Usage:** Used for novel view synthesis and pose estimation on real-world datasets like Tanks and Temples and CO3D-V2 [S1].
