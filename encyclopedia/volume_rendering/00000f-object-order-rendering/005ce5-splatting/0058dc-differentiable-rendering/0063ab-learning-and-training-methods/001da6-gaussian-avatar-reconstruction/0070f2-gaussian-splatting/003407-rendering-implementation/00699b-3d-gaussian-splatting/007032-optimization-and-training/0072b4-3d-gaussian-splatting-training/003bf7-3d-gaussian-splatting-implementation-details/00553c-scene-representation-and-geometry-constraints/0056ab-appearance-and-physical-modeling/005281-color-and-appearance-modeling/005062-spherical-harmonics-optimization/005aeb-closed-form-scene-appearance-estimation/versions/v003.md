# Closed-Form Scene Appearance Estimation

Also called: Global LLS System, Normal System Solution

## Overview
This method solves for the spherical harmonic (SH) coefficients of mesh vertices by formulating a global weighted least-squares problem that jointly fits RGB observations from all calibrated training views [S1, unofficial]. It distinguishes itself from iterative gradient-based optimization by providing an analytical solution to the appearance estimation sub-problem, utilizing adaptive regularization to handle varying angular support across the mesh surface [S1, unofficial].

## How it works
**Inputs:**
*   A mesh $M$ with $N_v$ vertices.
*   $K$ calibrated RGB images $\{I_k\}_{k=1}^K$.
*   SH degree $L$ (typically up to degree 2, i.e., $s=0,1,2$).
*   Regularization strengths $\gamma_s$ (supported) and $\gamma_u$ (under-supported), where $0 < \gamma_s \ll \gamma_u$ [S1, unofficial].
*   Minimum confidence weight threshold $\epsilon_w$ [S1, unofficial].

**Outputs:**
*   Estimated SH coefficients $X^*$ for each vertex.

**Data Structures:**
*   **Rasterization Records ($R$):** Stores per-pixel data including vertex indices $i_{s,k,r}$, SH basis evaluations $\phi_{s,k,r}$, and confidence weights $w_{k,r}$.
*   **Global Matrices:**
    *   $A \in \mathbb{R}^{(K \cdot H \cdot W) \times (q N_v)}$: The design matrix mapping vertex SH coefficients to pixel observations. $q$ is the number of SH coefficients per vertex.
    *   $B \in \mathbb{R}^{(K \cdot H \cdot W) \times 3}$: The observation vector containing flattened RGB pixel values.
    *   $W \in \mathbb{R}^{(K \cdot H \cdot W) \times (K \cdot H \cdot W)}$: A diagonal matrix of confidence weights.
    *   $\Lambda \in \mathbb{R}^{(q N_v) \times (q N_v)}$: A block-diagonal regularization matrix.
    *   $H \in \mathbb{R}^{(q N_v) \times (q N_v)}$: The normal matrix (Hessian approximation).
    *   $G \in \mathbb{R}^{(q N_v) \times 3}$: The right-hand side vector.

**Steps:**

1.  **Initialization:** Initialize rasterization records $R$ and view counts $\{n^v_i\}_{i=1}^{N_v}$ for each vertex [S1, unofficial].
2.  **Per-View Rasterization and Assembly:**
    For each view $k = 1 \dots K$:
    a. Rasterize mesh $M$ to establish pixel-to-triangle/vertex correspondence. Initialize per-view matrix $A_k$ [S1, unofficial].
    b. For each valid pixel $p_{k,r}$:
       i. Retrieve SH features $\{i_{s,k,r}, \lambda_{s,k,r}\}_{s=0}^2$ associated with the covering triangle/vertex [S1, unofficial].
       ii. Compute the SH basis evaluation: $\phi_{s,k,r} \leftarrow \lambda_{s,k,r} Y(\mathbf{d}_k)$, where $\mathbf{d}_k$ is the viewing direction [S1, unofficial].
       iii. Populate the design matrix row: $[A_k]_{r, i_{s,k,r}} \leftarrow (\phi_{s,k,r})^\top$ [S1, unofficial].
       iv. Compute confidence weight $w_{k,r}$ (e.g., based on grazing angle or depth consistency) [S1, unofficial].
       v. Store $\{i_{s,k,r}, \phi_{s,k,r}\}_{s=0}^2$, $w_{k,r}$ in $R$ [S1, unofficial].
    c. Construct per-view observation vector $B_k \leftarrow [I_k(p_{k,1}) \dots I_k(p_{k,HW})]^\top$ [S1, unofficial].
    d. Construct per-view weight matrix $W_k \leftarrow \text{diag}(w_{k,1}, \dots, w_{k,HW})$ [S1, unofficial].
    e. Update view counts $\{n^v_i\}$ based on pixels covering each vertex [S1, unofficial].
3.  **Global Assembly:**
    a. Assemble global matrices:
       $$ A \leftarrow [A_1^\top \dots A_K^\top]^\top $$
       $$ B \leftarrow [B_1^\top \dots B_K^\top]^\top $$
       $$ W \leftarrow \text{blkdiag}(W_1, \dots, W_K) $$
    b. Construct the global regularization matrix $\Lambda$:
       For each vertex $i = 1 \dots N_v$:
       i. Construct block $\Lambda_i$ using the view count $n^v_i$, $\gamma_s$, and $\gamma_u$ [S1, unofficial].
       ii. Vertices with sufficient angular support use $\gamma_s$; those with insufficient support use $\gamma_u$ [S1, unofficial].
    c. Assemble $\Lambda \leftarrow \text{blkdiag}(\Lambda_1, \dots, \Lambda_{N_v})$ [S1, unofficial].
4.  **Normal System Construction:**
    Compute the components of the normal system:
    $$ H \leftarrow A^\top W A + \Lambda $$
    $$ G \leftarrow A^\top W B $$
    Here, $H$ is strictly positive definite due to the positive weights $W$ and the positive regularization $\Lambda$, guaranteeing a unique global minimizer [S1, unofficial].
5.  **Solution:**
    Solve the linear system $H X^* = G$ for $X^*$ [S1, unofficial].
    *Note:* Explicit inversion $H^{-1}$ is computationally prohibitive for large scenes. Instead, a matrix-free Preconditioned Conjugate Gradient (PCG) solver is used [S1, unofficial].

**Pseudocode:**

```python
def closed_form_appearance_estimation(mesh, images, sh_degree, gamma_s, gamma_u, epsilon_w):
    """
    Estimates SH coefficients for mesh vertices using global least-squares.
    """
    N_v = mesh.num_vertices
    K = len(images)
    H, W, R_records = None, None, None
    
    # 1. Initialize
    view_counts = [0] * N_v
    global_A_rows = []
    global_B_rows = []
    global_W_diag = []
    
    # 2. Per-view processing
    for k in range(K):
        I_k = images[k]
        # Rasterize mesh to get pixel-to-vertex mapping
        # Returns: list of valid pixels with attributes:
        # vertex_idx, viewing_direction d_k, triangle_barycentrics
        pixels = rasterize(mesh, I_k)
        
        A_k_rows = []
        B_k_vals = []
        W_k_vals = []
        
        for p in pixels:
            # 2b-i: Obtain SH features
            # lambda_s are scaling factors, Y(d) are basis functions
            phi_s = []
            for s in range(sh_degree + 1):
                # Y(d_k) evaluated at viewing direction
                basis_eval = spherical_harmonics_basis(p.d_k, s)
                phi_s.append(p.lambda_s[s] * basis_eval)
            
            # 2b-iii: Populate A_k
            # Assuming q coefficients per vertex, map to global column index
            col_idx = p.vertex_idx * (sh_degree + 1)**2
            for s in range(sh_degree + 1):
                # phi_s[s] is a vector of size (2s+1) or similar depending on SH convention
                # Here we assume flattened row structure matching A's column layout
                A_k_rows.append(phi_s[s])
            
            # 2b-iv: Compute confidence weight
            w = compute_confidence_weight(p, epsilon_w)
            
            # 2b-v: Store and append
            R_records.append({
                'vertex_idx': p.vertex_idx,
                'phi': phi_s,
                'w': w
            })
            
            B_k_vals.append(I_k[p.pixel_coord])
            W_k_vals.append(w)
            
            # Update view counts
            view_counts[p.vertex_idx] += 1
            
        global_A_rows.extend(A_k_rows)
        global_B_rows.extend(B_k_vals)
        global_W_diag.extend(W_k_vals)
        
    # 3. Global Assembly
    A = np.array(global_A_rows)
    B = np.array(global_B_rows)
    W = np.diag(global_W_diag)
    
    # 4. Construct Lambda
    Lambda_blocks = []
    for i in range(N_v):
        n_v = view_counts[i]
        # Determine if supported or under-supported
        # Logic depends on specific thresholding of n_v or angular coverage
        # For this implementation, we assume a simple threshold or direct mapping
        if is_supported(n_v):
            reg_strength = gamma_s
        else:
            reg_strength = gamma_u
            
        # Construct block Lambda_i based on reg_strength
        # Lambda_i is typically diagonal or block-diagonal per SH band
        Lambda_i = construct_regularization_block(i, reg_strength)
        Lambda_blocks.append(Lambda_i)
        
    Lambda = block_diag(Lambda_blocks)
    
    # 5. Normal System
    # H = A^T W A + Lambda
    # G = A^T W B
    # To avoid forming H explicitly if too large, we define matrix-vector products
    # However, for clarity, we show the construction.
    # In practice, TrianglePCG is called directly.
    
    # 6. Solve
    X_star = triangle_pcg_solver(A, B, W, Lambda, R_records)
    
    return X_star

def triangle_pcg_solver(A, B, W, Lambda, R_records):
    """
    Solves (A^T W A + Lambda) X = A^T W B using PCG.
    """
    # Define matrix-vector product for H = A^T W A + Lambda
    def H_matvec(v):
        # Compute A^T W A v
        # Av = A @ v
        Av = A @ v
        # W_Av = W @ Av
        W_Av = W * Av # Element-wise since W is diagonal
        # A_T_W_Av = A^T @ W_Av
        A_T_W_Av = A.T @ W_Av
        # Lambda v
        Lambda_v = Lambda @ v
        return A_T_W_Av + Lambda_v

    # Define RHS G = A^T W B
    W_B = W @ B
    G = A.T @ W_B
    
    # Initialize PCG
    X = np.zeros_like(G)
    
    # Solve for each color channel (R, G, B) separately as H is shared
    for c in range(3):
        g_c = G[:, c]
        r = g_c.copy()
        p = r.copy()
        r_dot_r = np.dot(r, r)
        
        # Preconditioner setup (simplified identity or diagonal approximation)
        # In CF-Splat, a triangle-structured preconditioner is used [S1, unofficial]
        # Here we use a simple diagonal preconditioner for completeness
        # P_inv = diag(1 / diag(H))
        # For efficiency, we assume P_solve(r) is available
        def P_solve(vec):
            # Placeholder for triangle-structured preconditioner
            # Returns P^{-1} vec
            return vec # Identity for now, replace with actual preconditioner
        
        z = P_solve(r)
        sigma = np.dot(r, z)
        
        max_iter = 100
        tol = 1e-6 * r_dot_r
        
        for t in range(max_iter):
            h = H_matvec(p)
            alpha = sigma / np.dot(p, h)
            X[:, c] += alpha * p
            r -= alpha * h
            
            if np.dot(r, r) < tol:
                break
                
            z = P_solve(r)
            sigma_new = np.dot(r, z)
            beta = sigma_new / sigma
            p = z + beta * p
            sigma = sigma_new
            
    return X
```

## Operating characteristics
*   **Complexity:** The setup cost is $O(KHWq^2 + N_v q^3)$, where $K$ is views, $H,W$ image dimensions, $q$ SH coefficients per vertex, and $N_v$ vertices [S1, unofficial]. Each PCG iteration costs $O(KHWq + N_v q^2)$ [S1, unofficial]. Total solve time is $T_{solve} = O(KHWq^2 + N_v q^3) + O(T_{pcg}(KHWq + N_v q^2)) + O(KHWq + N_v q)$ [S1, unofficial].
*   **Strengths:** Provides a closed-form solution, avoiding iterative gradient descent for appearance. Adaptive regularization prevents overfitting in regions with sparse view coverage [S1, unofficial].
*   **Limitations:** Requires all views to be processed to assemble the global system, which can be memory-intensive for high-resolution scenes. The PCG solver requires careful preconditioning for convergence [S1, unofficial].
*   **When to use:** When a mesh representation is available and global consistency of appearance across views is desired without iterative per-vertex optimization [S1, unofficial].

## Background
The method originates from "CF-Splat: Closed-Form Triangle Splatting with Mesh Priors" [S1, unofficial]. It addresses the limitation of coarse triangles in mesh-based appearance representation by introducing gradient-guided densification and a global least-squares solver with adaptive SH regularization [S1, unofficial].
