# GaussianDreamer


## Overview
GaussianDreamer is a training procedure for 3D Gaussian Splatting (3DGS) that combines 2D and 3D diffusion model priors to optimize scene representations from text or image prompts [S1]. It sets itself apart from standard 3DGS by using a generative model (Shap-E) to initialize the point cloud instead of Structure from Motion (SfM), and by optimizing Gaussian parameters via 2D Score Distillation Sampling (SDS) [S1, S2].

## How it works
**Inputs and outputs:**
- Input: A text or image prompt, a pre-trained 2D diffusion model, and a 3D Gaussian Splatting representation initialized from a generative point cloud [S1, S2].
- Output: An optimized 3D Gaussian Splatting representation with updated positions, scales, colors, opacities, and rotations [S2].

**Data structures:**
- 3D Gaussian Splatting primitives: Each primitive $i$ is defined by position $\mathbf{\mu}_i$, covariance matrix $\mathbf{\Sigma}_i$ (parameterized by scale $\mathbf{s}_i$ and rotation $\mathbf{R}_i$), opacity $\alpha_i$, and spherical harmonics coefficients for color $\mathbf{c}_i$ [G].
- Diffusion Model: A 2D text-to-image or image-to-image model (e.g., Stable Diffusion) used for Score Distillation Sampling (SDS) [G].

**Numbered steps:**
1. **Initialization:** Use Shap-E [S1] to generate an initial point cloud, which serves as the initial geometry for the 3DGS optimization [S1].
2. **Densification:** Because the generated initial point cloud is relatively sparse, apply noisy point growth and color perturbation to densify it [S1].
3. **Optimization Loop:** Optimize the 3DGS parameters using 2D SDS [S1].
    - Sample a random camera pose.
    - Render the current 3DGS representation to obtain a 2D image.
    - Compute the SDS gradient, which approximates the gradient of the diffusion model's log-likelihood with respect to the rendered image pixels [G].
    - Back-propagate the gradient through the differentiable renderer to update the Gaussian parameters (positions, scales, colors, opacities) [S2].
4. **Reconstruction Loss:** Optionally, incorporate an RGB reconstruction loss if ground-truth images are available, alongside the diffusion guidance [S2].

**Formulas:**
- The SDS loss is computed as:
  $$ \mathcal{L}_{SDS} = \mathbb{E}_{t, \epsilon} \left[ w(t) \cdot \mathbb{E}_{z_t \sim p_t(z|x)} \left[ \nabla_{z_t} \log p_\theta(z_t | x) \cdot \frac{\partial z_t}{\partial \mathbf{\theta}_{GS}} \right] \right] $$
  where $z_t$ is the noisy image at timestep $t$, $p_\theta$ is the diffusion model, $w(t)$ is a timestep weighting function, and $\mathbf{\theta}_{GS}$ are the Gaussian parameters [G].
- The total loss combines the SDS guidance and RGB reconstruction loss:
  $$ \mathcal{L} = \mathcal{L}_{RGB} + \lambda \mathcal{L}_{SDS} $$
  where $\lambda$ is a weighting factor balancing the two terms [G].

**Parameters:**
- Learning rate: Not given in the sources.
- SDS weighting $\lambda$: Not given in the sources.
- Number of optimization steps: Not given in the sources.

**Edge cases and pitfalls:**
- The generated initial point cloud is relatively sparse, requiring densification to prevent poor initialization [S1].
- The Janus problem (multi-face artifact) may still exist during optimization if views are sampled one by one, even if 3D SDS loss is introduced [S1].
- Per-scene fitting incurs heavy computational cost, typically taking minutes to hours per prompt [S2].
- The method is prone to over-smoothing or texture oversaturation unless additional regularizers, multi-view diffusion priors, or geometry-aware constraints are applied [S2].

## Subtopics

### [Diffusion Prior Guidance for Pseudo Views](15501-diffusion-prior-guidance-for-pseudo-views.md)
This method is a training procedure for 3D Gaussian Splatting (3DGS) that uses a fine-tuned Diffusion Model to generate guidance images from randomly sampled "pseudo-views," regularizing the Gaussian model parameters to improve unseen view synthesis. It sets itself apart from standard 3DGS by introducing a diffusion-based prior loss computed on rendered views that do not correspond to ground-truth images, thereby preventing the model from getting stuck in local minima and enhancing the scene's comprehensive observation. Unlike methods relying on Structure from Motion (SfM) point clouds for initialization, this approach exclusively uses LiDAR data to avoid prior bias.

### Optimization-based Generation
A generation paradigm where a powerful 2D or multi-view diffusion model is queried from many camera poses, and its gradients are back-propagated through the differentiable GS renderer to update Gaussian parameters [S2]. Early pipelines such as DreamGaussian and GaussianDreamer treat each scene independently and directly optimize positions, scales, colors, and opacities to match diffusion-model guidance while respecting RGB reconstruction losses [S2].

## Operating characteristics
- **Time Complexity:** Heavy computational cost, taking minutes to hours per prompt [S2].
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Yields high-fidelity geometry and appearance for object- and scene-level content [S2]. Can be naturally extended to dynamic or 4D generation with temporal regularization [S2].
- **Limitations:** Prone to Janus ambiguity, over-smoothing, or texture oversaturation unless additional regularizers, multi-view diffusion priors, or geometry-aware constraints are applied [S2]. The initial point cloud is sparse, requiring densification steps [S1].

## Background
GaussianDreamer was introduced as an early text- and image-to-3D pipeline that combines the priors of 2D and 3D diffusion models [S1]. It utilizes Shap-E to generate the initial point cloud and optimizes 3DGS using 2D SDS [S1]. The method is part of the broader category of optimization-based generation methods in GS-based generation [S2].
