# Opacity Pruning

Also called: Opacity and Scale Pruning

## Overview
Opacity Pruning is a density control strategy for 3D Gaussian Splatting that removes redundant primitives based on their learned opacity values. It solves the problem of excessive Gaussian count and memory usage by culling Gaussians that contribute negligibly to the final image. It differs from its parent, Contribution-based Pruning, by relying solely on the scalar opacity attribute rather than a complex, multi-view loss-driven score, making it a simpler but potentially more aggressive baseline.

## How it works
**Inputs and Outputs:**
- Input: A set of $N$ 3D Gaussians $\{G_i\}_{i=1}^N$, where each Gaussian $G_i$ has attributes: position $\mathbf{x}_i$, rotation $\mathbf{q}_i$, scale $\mathbf{s}_i$, opacity $\alpha_i$, and spherical harmonic coefficients $\mathbf{c}_i$.
- Input (Optional): A binary visibility mask $M \in \{0, 1\}^{H \times W}$ indicating valid pixels.
- Input (Optional): A depth threshold or distance function for free-space pruning.
- Output: A subset of Gaussians $\{G_i\}$ where $G_i$ is retained if it passes the pruning criteria.

**Data Structures:**
- Gaussian Array: A contiguous array or list of objects/tensors. Each element stores:
  - `xyz`: float32[3]
  - `rot`: float32[4] (normalized quaternion)
  - `scale`: float32[3]
  - `opacity`: float32 (scalar, typically in $[0, 1]$)
  - `sh_coeffs`: float32[$K$] (where $K$ depends on SH degree)

**Steps:**
1. **Opacity Thresholding:** For each Gaussian $G_i$, check if its opacity $\alpha_i$ is below a predefined threshold $o_{min}$.
   $$ \text{keep}_i = (\alpha_i \ge o_{min}) $$
2. **Visibility Masking (Optional):** If a visibility mask $M$ is provided:
   a. Project all Gaussians to 2D screen space to determine which pixels they cover.
   b. For each Gaussian $G_i$, determine if it projects onto any pixel $(u, v)$ where $M[u, v] = 0$ (masked/invalid region).
   c. If $G_i$ projects *only* onto masked pixels, mark it for removal.
   $$ \text{visible}_i = \bigvee_{(u,v) \in \text{proj}(G_i)} M[u, v] $$
   d. Update keep condition: $\text{keep}_i = \text{keep}_i \land \text{visible}_i$.
3. **Depth/Free-Space Pruning (Optional):** If depth information is available:
   a. Compute the depth $z_i$ of each Gaussian's center.
   b. If $z_i$ indicates the Gaussian is in free space (e.g., beyond a max depth or in a region with no surface geometry), mark it for removal.
   c. Alternatively, control density by distance from the camera (e.g., prune Gaussians too far away).
4. **Pruning:** Remove all Gaussians $G_i$ where $\text{keep}_i$ is false.

**Parameters:**
- $o_{min}$: The opacity threshold. Typical values are not explicitly given in the sources, but standard 3DGS implementations often use values between $10^{-3}$ and $10^{-2}$. [S1, unofficial]
- $M$: Binary visibility mask. [S1, unofficial]
- Depth threshold: Scene-dependent. [S1, unofficial]

**Pitfalls:**
- **Aggressive Pruning:** Using only $o_{min}$ can lead to aggressive pruning and a performance slump, as noted in the context of Moderate Pruning. [S2]
- **Precision:** Opacity values can be very small; ensure floating-point precision does not cause premature culling of valid but low-opacity Gaussians. [G]
- **Boundary Conditions:** Gaussians projected exactly on the boundary of a mask may be ambiguous; consistent projection logic is required. [G]

**Pseudocode:**
```python
def opacity_pruning(gaussians, o_min, visibility_mask=None, depth_threshold=None):
    """
    Prune Gaussians based on opacity, visibility mask, and depth.
    
    Args:
        gaussians: List of Gaussian objects with attributes .opacity, .xyz, .rot, .scale
        o_min: Float, opacity threshold
        visibility_mask: Optional 2D array (H, W) of 0/1, 1 means visible
        depth_threshold: Optional float, max depth to keep Gaussians
        
    Returns:
        List of pruned Gaussians
    """
    pruned_gaussians = []
    
    for g in gaussians:
        # Step 1: Opacity check
        if g.opacity < o_min:
            continue
            
        # Step 2: Visibility mask check
        if visibility_mask is not None:
            # Project Gaussian to screen space (simplified)
            # In practice, this involves camera projection and rasterization
            projected_pixels = project_to_screen(g, camera_params)
            
            # Check if any projected pixel is valid
            is_visible = False
            for u, v in projected_pixels:
                if 0 <= u < visibility_mask.shape[1] and 0 <= v < visibility_mask.shape[0]:
                    if visibility_mask[v, u] == 1:
                        is_visible = True
                        break
            
            if not is_visible:
                continue
                
        # Step 3: Depth check
        if depth_threshold is not None:
            # Compute depth of Gaussian center in camera space
            depth = compute_depth(g.xyz, camera_params)
            if depth > depth_threshold:
                continue
                
        pruned_gaussians.append(g)
        
    return pruned_gaussians
```

## Subtopics

### Moderate Pruning
A pruning strategy that uses a multi-view and loss-driven pruning score $S^-$ to eliminate non-contributing or artifact-inducing Gaussians while preserving essential scene geometry, avoiding the aggressive pruning and performance slump of standard opacity thresholds. It defines a final pruning mask $\mathcal{M}_{prune}$ as:
$$ \mathcal{M}_{prune} = (o_i < o_{min}) \land \left( S^- > Q_\tau^-(S^-) \right) $$
where $o_i$ is the opacity of Gaussian $i$, $o_{min}$ is the opacity threshold, $S^-$ is the pruning score, and $Q_\tau^-(S^-)$ is the quantile of the pruning score distribution. [S2]

## Operating characteristics
- **Time Complexity:** $O(N)$ for opacity check, where $N$ is the number of Gaussians. Visibility mask check requires projection and rasterization, which is $O(N \cdot A)$ where $A$ is the average number of pixels covered by a Gaussian. Depth check is $O(N)$.
- **Memory Complexity:** $O(N)$ to store Gaussian attributes. No additional large data structures required.
- **Performance:** Simple opacity pruning is fast but can lead to significant quality loss if $o_{min}$ is too high. Moderate pruning is more computationally expensive due to the need for multi-view loss calculation but preserves quality better. [S2]
- **Strengths:** Simple to implement, effective at reducing Gaussian count, integrates easily into existing pipelines. [S1, unofficial]
- **Limitations:** Standard opacity pruning can be too aggressive, leading to artifacts or loss of detail. [S2]
- **When to use:** When computational resources are limited and a quick reduction in Gaussian count is needed, or as a baseline. Use Moderate Pruning when quality preservation is critical.

## Background
Opacity Pruning is a technique used in 3D Gaussian Splatting frameworks to manage the number of Gaussians. It was discussed in the context of Gaussian Surface Reconstruction and compression. [S1, unofficial] The concept of using opacity thresholds for pruning is a standard practice in 3DGS, but its aggressive nature led to the development of more moderate strategies like Moderate Pruning.
