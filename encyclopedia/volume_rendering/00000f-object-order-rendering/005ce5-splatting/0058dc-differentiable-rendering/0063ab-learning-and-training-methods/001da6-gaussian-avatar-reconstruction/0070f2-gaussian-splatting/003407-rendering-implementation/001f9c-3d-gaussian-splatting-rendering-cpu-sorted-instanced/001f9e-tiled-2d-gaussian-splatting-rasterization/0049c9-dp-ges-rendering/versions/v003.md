# DP-GES Rendering

Also called: DP-GES depth peeling pass, Depth Peeling for Gaussian-Enhanced Surfels, Depth Peeling for High-Fidelity Gaussian-Enhanced Surfel Rendering, Depth Peeling for Surfel Rendering, Ours

## Overview
DP-GES is a sort-free rendering method that combines 2D surfels with semi-transparent boundaries and 3D Gaussians to achieve high-fidelity novel view synthesis, eliminating aliasing and popping artifacts while enabling correct transmittance modulation [S1, unofficial]. It sets itself apart from its parent [Tiled 2D Gaussian Splatting Rasterization](2061-tiled-2d-gaussian-splatting-rasterization.md) and sibling [Non-Tiled 2D Gaussian Splatting with Transmittance Culling](2067-non-tiled-2d-gaussian-splatting-with-transmittance-culling.md) by introducing a two-stage pipeline: Stage 1 uses z-buffer-based depth peeling to extract the nearest three layers of depth, color, and opacity from surfels, and Stage 2 splats 3D Gaussians without sorting, modulating their weights by the transmittance from the peeled surfel layers [S1, unofficial]. Unlike Gaussian-Enhanced Surfels (GES), which uses fully opaque surfels, DP-GES uses semi-transparent boundaries to mitigate aliasing from depth testing and allow differentiable joint optimization [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 2D surfels $S$, a set of 3D Gaussians $G$, and camera parameters (position, orientation, intrinsics) [G].
*   **Outputs:** Final rendered image color $C$ and weight $W$ (normalized to produce color) [S1, unofficial].

**Data Structures:**
*   **Surfel Set $S$:** $S = \{p_i, r_i, s_i, B_i\}_{i=1}^N$ [S1, unofficial].
    *   $p_i \in \mathbb{R}^3$: Position [S1, unofficial].
    *   $r_i \in \mathbb{R}^4$: Rotation quaternion [S1, unofficial].
    *   $s_i \in \mathbb{R}^2$: Anisotropic scaling [S1, unofficial].
    *   $B_i$: Spherical Beta parameters for view-dependent color [S1, unofficial].
*   **Gaussian Set $G$:** $G = \{p_i, \sigma_i, r_i, s_i, B_i\}_{i=1}^M$ [S1, unofficial].
    *   $p_i \in \mathbb{R}^3$: Position [S1, unofficial].
    *   $\sigma_i$: Scale (implied from 3DGS context) [S1, unofficial].
    *   $r_i \in \mathbb{R}^4$: Rotation quaternion [S1, unofficial].
    *   $s_i \in \mathbb{R}^2$: Scaling [S1, unofficial].
    *   $B_i$: Spherical Beta parameters [S1, unofficial].
*   **Texture Buffers:** A four-channel texture storing peeled depth maps $\{D_i^s\}_{i=1}^2$ and transmittance maps $\{T_i^s\}_{i=1}^2$ [S1, unofficial]. $D_3^s$ and $T_3^s$ are not stored because Gaussians beyond the third layer are culled by hardware depth testing [S1, unofficial]. Depth and color/opacity buffers are allocated for the three intermediate peeling layers [S1, unofficial].

**Parameters:**
*   **Number of depth peeling layers:** 3. This balances quality and efficiency; 2 layers cause background leakage, and 4 layers drop FPS significantly due to memory bandwidth issues in OpenGL [S1, unofficial].
*   **Opacity modulation parameter $w$:** Fixed constant shared by all surfels. Default value is 30. If $w < 1$, the surfel is fully translucent; if $w = 255$, it is completely opaque [S1, unofficial].
*   **Depth margin $\epsilon_s$:** A tiny depth margin for culling and depth buffer updates [S1, unofficial].

**Steps:**

1.  **Stage 1: Surfel Rasterization via Depth Peeling** [S1, unofficial].
    *   Initialize depth buffer with far plane [G].
    *   For layer $k = 1$ to 3:
        *   Clear color and opacity buffers for layer $k$ [G].
        *   Rasterize all surfels $S$.
        *   For each surfel fragment at pixel $(x,y)$:
            *   Calculate local coordinates $(x,y)$ on the surfel disc [G].
            *   Compute opacity $\alpha_i(x,y) = \min(1, w \cdot G(x,y))$, where $G(x,y) = \exp(-\frac{x^2+y^2}{2})$ [S1, unofficial].
            *   Perform depth test against the current depth buffer [G]. If the surfel depth $d_i$ is greater than the stored depth $d_{stored}$ by a small margin, discard [G]. To handle interleaved surfels correctly, surfel IDs are also written to the buffer to identify intersections [S1, unofficial].
            *   Write depth $d_i$, color $C_i$ (from $B_i$), opacity $\alpha_i$, and surfel ID to the buffers for layer $k$ [S1, unofficial].
            *   Update the depth buffer with $d_i + \epsilon_s$ for subsequent layers [S1, unofficial].
        *   After rasterizing all surfels, the buffers contain the $k$-th peeled layer's depth $D_k^s$, color $C_k^s$, and opacity $A_k^s$ [S1, unofficial].
    *   **Post-processing (Surfel Compositing):**
        *   Alpha-blend the 3 peeled layers using front-to-back compositing (same as 3DGS) to obtain final surfel color $C_S$ and transmittance maps $\{T_i^s\}_{i=0}^3$:
            $$ C_S = \sum_{i=1}^3 A_{si} T_{i-1} C_{is} + T_3^s C_b $$
            $$ T_i^s = \begin{cases} 1 & \text{if } i=0 \\ \prod_{j=1}^i (1 - A_{sj}) & \text{otherwise} \end{cases} $$
            where $C_b$ is the background color [S1, unofficial].
        *   Pack $D_1^s, D_2^s, T_1^s, T_2^s$ into a four-channel texture. Note: $T_0^s = 1$ is implicit [S1, unofficial].

2.  **Stage 2: Sort-Free Gaussian Splatting** [S1, unofficial].
    *   Clear final color and weight accumulators [G].
    *   Enable depth testing, disable depth writing [S1, unofficial].
    *   For each pixel $\hat{x}$ (or in parallel via fragment shader):
        *   Initialize $C_G(\hat{x}) = 0$, $W_G(\hat{x}) = 0$ [G].
        *   For each Gaussian $i$ covering pixel $\hat{x}$:
            *   Calculate Gaussian weight $\alpha_i(\hat{x})$ (standard 2D Gaussian projection) [G].
            *   Determine Gaussian center depth $d_i$ [G].
            *   Query transmittance $t_s(\hat{x})$ based on $d_i$ and peeled depths $\{D_j^s\}$:
                $$ t_s(\hat{x}) = \begin{cases} T_0^s(\hat{x}) & \text{if } d_i < D_1^s(\hat{x}) \\ T_1^s(\hat{x}) & \text{if } D_1^s(\hat{x}) \le d_i < D_2^s(\hat{x}) \\ T_2^s(\hat{x}) & \text{otherwise} \end{cases} $$
            *   Perform depth culling: Calculate indicator $1_{dt}(\hat{x}) = 1$ if $d_i < d_s(\hat{x}) + \epsilon_s$, else 0 [S1, unofficial].
                *   $d_s(\hat{x})$ is the depth of the nearest peeled layer $i$ where $T_i^s(\hat{x}) = 0$. If all $T_i^s > 0$, $d_s(\hat{x}) = D_3^s(\hat{x})$ [S1, unofficial].
            *   If $1_{dt}(\hat{x}) == 1$ and $t_s(\hat{x}) > 0$:
                *   Get Gaussian color $c_i$ from $B_i$.
                *   Accumulate:
                    $$ C_G(\hat{x}) \leftarrow C_G(\hat{x}) + 1_{dt}(\hat{x}) c_i \alpha_i(\hat{x}) t_s(\hat{x}) $$
                    $$ W_G(\hat{x}) \leftarrow W_G(\hat{x}) + 1_{dt}(\hat{x}) \alpha_i(\hat{x}) t_s(\hat{x}) $$
    *   **Final Post-processing:**
        *   Calculate total weight $W_{total} = W_S + W_G$, where $W_S = \sum_{i=1}^3 A_{si} T_{i-1}$ is the constant sum of surfel color weights [S1, unofficial].
        *   Normalize and output final color: $C = \frac{C_S + C_G}{W_S + W_G}$ [S1, unofficial].

**Pseudocode:**
```python
import math

def render_dp_ges(surfels, gaussians, width, height, far_plane, epsilon_s):
    # Stage 1: Depth Peeling for Surfels
    # layer_depths[k][y][x], layer_colors[k][y][x], layer_opacities[k][y][x] for k=0,1,2
    layer_depths = [[[0.0] * width for _ in range(height)] for _ in range(3)]
    layer_colors = [[[0.0, 0.0, 0.0] for _ in range(width)] for _ in range(height) for _ in range(3)]
    layer_opacities = [[[0.0] * width for _ in range(height)] for _ in range(3)]
    current_depth_buffer = [[far_plane] * width for _ in range(height)]

    for k in range(3):
        # Clear buffers for layer k
        for y in range(height):
            for x in range(width):
                layer_depths[k][y][x] = 0.0
                layer_colors[k][y][x] = [0.0, 0.0, 0.0]
                layer_opacities[k][y][x] = 0.0

        for surfel in surfels:
            for y in range(max(0, surfel.screen_y_min), min(height, surfel.screen_y_max)):
                for x in range(max(0, surfel.screen_x_min), min(width, surfel.screen_x_max)):
                    local_x, local_y = surfel.to_local(x, y)
                    alpha = min(1.0, surfel.w * math.exp(-(local_x**2 + local_y**2) / 2.0))
                    if surfel.depth > current_depth_buffer[y][x] + epsilon_s:
                        continue
                    layer_depths[k][y][x] = surfel.depth
                    layer_colors[k][y][x] = surfel.get_color()
                    layer_opacities[k][y][x] = alpha
                    current_depth_buffer[y][x] = surfel.depth + epsilon_s

    # Post-processing: Alpha blend peeled layers
    T = [1.0] * 4
    C_S = [[[0.0, 0.0, 0.0] for _ in range(width)] for _ in range(height)]

    for i in range(1, 4):
        for y in range(height):
            for x in range(width):
                A = layer_opacities[i-1][y][x]
                T[i] = T[i-1] * (1.0 - A)
                C_S[y][x][0] += A * T[i-1] * layer_colors[i-1][y][x][0]
                C_S[y][x][1] += A * T[i-1] * layer_colors[i-1][y][x][1]
                C_S[y][x][2] += A * T[i-1] * layer_colors[i-1][y][x][2]

    packed_texture = [[[layer_depths[0][y][x], layer_depths[1][y][x], T[1], T[2]] for x in range(width)] for y in range(height)]

    # Stage 2: Sort-Free Gaussian Splatting
    C_G = [[[0.0, 0.0, 0.0] for _ in range(width)] for _ in range(height)]
    W_G = [[0.0] * width for _ in range(height)]

    culling_depths = [[0.0] * width for _ in range(height)]
    for y in range(height):
        for x in range(width):
            d_s = layer_depths[2][y][x]
            for i in range(3):
                if T[i+1] < 1e-6:
                    d_s = layer_depths[i][y][x]
                    break
            culling_depths[y][x] = d_s

    for gaussian in gaussians:
        for y in range(max(0, gaussian.screen_y_min), min(height, gaussian.screen_y_max)):
            for x in range(max(0, gaussian.screen_x_min), min(width, gaussian.screen_x_max)):
                alpha = gaussian.weight(x, y)
                d_i = gaussian.depth
                if d_i < layer_depths[0][y][x]:
                    t_s = T[0]
                elif d_i < layer_depths[1][y][x]:
                    t_s = T[1]
                else:
                    t_s = T[2]
                if d_i < culling_depths[y][x] + epsilon_s and t_s > 0:
                    c = gaussian.get_color()
                    C_G[y][x][0] += c[0] * alpha * t_s
                    C_G[y][x][1] += c[1] * alpha * t_s
                    C_G[y][x][2] += c[2] * alpha * t_s
                    W_G[y][x] += alpha * t_s

    # Final Normalization
    W_S = [[0.0] * width for _ in range(height)]
    for y in range(height):
        for x in range(width):
            for i in range(1, 4):
                W_S[y][x] += layer_opacities[i-1][y][x] * T[i-1]

    Total_W = [[0.0] * width for _ in range(height)]
    Final_Color = [[[0.0, 0.0, 0.0] for _ in range(width)] for _ in range(height)]
    for y in range(height):
        for x in range(width):
            Total_W[y][x] = W_S[y][x] + W_G[y][x]
            if Total_W[y][x] < 1e-6:
                Total_W[y][x] = 1e-6
            Final_Color[y][x][0] = (C_S[y][x][0] + C_G[y][x][0]) / Total_W[y][x]
            Final_Color[y][x][1] = (C_S[y][x][1] + C_G[y][x][1]) / Total_W[y][x]
            Final_Color[y][x][2] = (C_S[y][x][2] + C_G[y][x][2]) / Total_W[y][x]

    return Final_Color
```

**Edge Cases and Pitfalls:**
*   **Interleaved Surfels:** Two intersecting surfels might be peeled only once along their intersection line if IDs are not tracked. Solution: Write surfel ID into the buffer during rasterization to correctly identify and handle interleaved surfels [S1, unofficial].
*   **Background Color Leakage:** If $T_3$ is not zero, background color leaks through. The loss $L_t$ encourages surfels to separate, driving $T_3$ to zero. For pixels covered by fewer than 2 surfel layers, gradients for $L_t$ are masked out [S1, unofficial].
*   **4-Layer Peeling:** Breaks 4-float alignment packing in OpenGL, increasing memory bandwidth usage and dropping FPS [S1, unofficial].
*   **Transparent Objects:** Shows artifacts because surfels are mainly opaque [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The surfel rendering is $O(N_s \cdot P)$ across 3 passes, where $N_s$ is the number of surfels and $P$ is pixels. Gaussian rendering is $O(N_g \cdot P)$ but sort-free. Overall, it is faster than sorting-based methods [S1, unofficial].
*   **Memory Complexity:** Requires storage for 3 layers of depth/color/opacity during peeling, plus the packed texture for Stage 2. Surfel count is typically <10% of Gaussian count, so peeling cost is negligible [S1, unofficial].
*   **Measured Performance:** On RTX 4090 for Mip-NeRF360 dataset: >470 FPS at 1080p. 2.5x faster than vanilla 3DGS and 3x faster than DBS [S1, unofficial]. Ablation FPS (1080p): Full 472, 2 layers 578, 4 layers 278 [S1, unofficial].
*   **Strengths:** Sort-free, high fidelity, eliminates popping and aliasing, differentiable joint optimization, integrable into existing engines (OpenGL) [S1, unofficial].
*   **Limitations:** Artifacts on transparent/semi-transparent objects (e.g., glass), slightly higher FLIP error than GES due to view-dependent effects, requires extra initialization and longer training time compared to 2DGS [S1, unofficial].

## Background
DP-GES was proposed by Keyang Ye, Hongzhi Wu, and Kun Zhou from Zhejiang University and Hangzhou Research Institute of Holographic and AI Technology. It was published on arXiv in May 2026 [S1, unofficial]. It is an improved variant of Gaussian-Enhanced Surfels (GES) [42], addressing GES's limitations of aliasing artifacts and suboptimal reconstruction by introducing semi-transparent surfel boundaries and depth peeling.
