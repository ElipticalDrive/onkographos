# Rasterization Variant
## Overview
This family defines the specific algorithmic variations of the differentiable rasterization pipeline used to render 3D Gaussians, extending the standard alpha-compositing logic of [3D Gaussian Splatting Differentiable Rasterizer](2813-3d-gaussian-splatting-differentiable-rasterizer.md) [S1, unofficial]. It addresses specialized requirements such as dynamic pruning gradients, X-ray physics, hybrid sigma fallbacks, and importance scoring, which the base rasterizer does not natively support [S1, unofficial].
## Shared principles
All variants in this family operate on the same fundamental data structures: a set of 3D Gaussians defined by mean $\boldsymbol{\mu}$, covariance $\boldsymbol{\Sigma}$, opacity $\alpha$, and color/features [S1, unofficial]. They share the initial projection step, transforming 3D parameters to 2D screen space using extrinsic/intrinsic matrices and Jacobian transformations to compute 2D covariances [S1, unofficial]. They all utilize a tile-based sorting and accumulation strategy to ensure depth ordering and correct alpha blending [S1, unofficial]. The core divergence lies in how the alpha value $\alpha_i$ is computed, how the blending loop modifies the transmittance $T$ and color $C$, and what auxiliary data (masks, counts, or physics parameters) is propagated [S1, unofficial].
## Subtopics

### [Masked-Rasterization](4366-masked-rasterization.md)
Allows "masked" (probabilistically inactive) 3D Gaussians to participate in the rasterization pipeline and receive gradient updates, rather than being permanently filtered out. It solves the problem of outdated Gaussians in dynamic pruning scenarios where standard alpha-filtering prevents unsampled Gaussians from adjusting their existence probability. Choose this method when training requires dynamic Gaussian culling without breaking gradient flow to pruned primitives.

### [Differentiable Radiative Rasterization](4526-differentiable-radiative-rasterization.md)
A GPU-accelerated rasterization method designed to render novel X-ray projections from radiative 3D Gaussian point clouds. It adapts the splatting pipeline to model radiation intensity rather than visible light color, using a specific Jacobian for X-ray projection and radiative intensity accumulation. Choose this method for differentiable volume rendering in X-ray imaging or non-visible spectrum applications.

### [3D/2D Hybrid Gaussian Rasterization with Fallback Sigma](4812-3d-2d-hybrid-gaussian-rasterization-with-fallback-sigma.md)
Renders 3D Gaussians by combining a screen-space 2D Gaussian approximation with a ray-surfel 3D sigma calculation to determine the tighter bounding sigma for alpha attenuation. It computes a fallback 2D sigma based on pre-computed screen-space means and selects the minimum of the 3D and 2D sigmas. Choose this method when numerical stability or approximation accuracy is critical for distant or degenerate Gaussians.

### [Gaussian Rasterization with F-Count](17250-gaussian-rasterization-with-f-count.md)
Extends the standard differentiable rasterizer to output the number of times each 3D Gaussian is activated during the forward pass, alongside standard color and radii tensors. It invokes a specialized backend kernel to track per-Gaussian activation counts and importance scores. Choose this method when implementing Gaussian pruning, compression, or importance sampling based on rendering frequency.

### Analytic Tau Rasterization
A rasterization branch (`use_analytic_tau`) that computes the per-pixel accumulated analytic line-integral optical thickness $\tau$ along the view ray. Alpha is derived physically as $\text{alpha} = 1 - \text{exp}(-\tau)$ using Beer-Lambert extinction, rather than using heuristic alpha values [S1, unofficial]. Choose this method when physically accurate alpha compositing based on optical thickness is required over standard heuristic splatting.

## Background
The base differentiable rasterizer for 3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [G]. The variants described here emerge from subsequent research into optimizing training dynamics (Masked-Rasterization, F-Count), extending the representation to non-visible spectra (DRR), and improving numerical stability or approximation accuracy (Hybrid Sigma, Analytic Tau) [S1, unofficial]. The codebase structure, particularly the CUDA extensions in `diff-gaussian-rasterization`, supports these variants through conditional compilation or runtime flags, as seen in the `4DGS-Volume-Cloud` repository which integrates analytic-tau and other channels [S1, unofficial].
