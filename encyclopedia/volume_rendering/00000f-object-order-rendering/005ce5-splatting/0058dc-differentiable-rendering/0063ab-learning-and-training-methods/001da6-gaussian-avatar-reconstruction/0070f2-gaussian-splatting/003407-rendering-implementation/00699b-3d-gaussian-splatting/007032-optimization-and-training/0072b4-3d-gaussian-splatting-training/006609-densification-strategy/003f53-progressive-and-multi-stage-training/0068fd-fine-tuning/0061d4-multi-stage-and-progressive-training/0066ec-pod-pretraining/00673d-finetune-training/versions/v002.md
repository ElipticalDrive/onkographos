# Finetune Training

Also called: Cross-stage coordination, Finetuning Phase, Image-space Finetuning, POD + Finetune

## Overview
Finetune Training is a lightweight optimization phase applied after POD (Progressive Optimization Distillation) pretraining to refine the multi-stage Gaussian predictor using direct image-space rendering supervision [S1, unofficial]. It solves the problem of limited cross-stage coordination in distillation-based methods by allowing gradients from the final cumulative rendering to propagate back to earlier stages, thereby redistributing the reconstruction burden and improving the final output quality [S1, unofficial]. Unlike POD, which stabilizes training via local residual targets, finetuning enables joint optimization across all stages, sacrificing intermediate standalone PSNR for superior final-stage reconstruction [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A multi-stage feed-forward predictor $P$ initialized by POD pretraining, which predicts Gaussian increments $\Delta G_i$ at each stage $i$ based on residual features $E_{i-1}$ [S1, unofficial].
*   **Output:** An optimized predictor $P'$ with parameters adjusted to minimize image-space rendering loss [S1, unofficial].

**Data Structures:**
The predictor maintains a sequence of accumulated Gaussian sets $G_i$ and their corresponding rendered images $I_i$ [S1, unofficial].
*   $G_i = G_{i-1} \cup \Delta G_i$, where $G_0 = \emptyset$ [S1, unofficial].
*   $I_i = \mathcal{R}(G_i)$, where $\mathcal{R}$ is the differentiable volume rendering operator [S1, unofficial].
*   The loss is computed for every intermediate stage $i \in \{1, \dots, N\}$ [S1, unofficial].

**Parameters:**
*   **Image-space reconstruction loss coefficient ($\lambda_i$):** Set to 1 uniformly across all stages [S1, unofficial].
*   **Rendering Loss ($L_{render}$):** A weighted combination of pixel-wise distortion and structural similarity:
    $$ L_{render} = 0.7 L_1 + 0.3 (1 - \text{SSIM}) $$
    where $L_1$ is the L1 distance between predicted and ground-truth images, and SSIM is the Structural Similarity Index [S1, unofficial].

**Steps:**
1.  **Remove Short-Horizon Optimization:** Disable the local Gaussian refinement optimizer used during POD pretraining, eliminating the costly iterative refinement loop [S1, unofficial].
2.  **Forward Pass:** For each training batch, pass the input through the multi-stage predictor [S1, unofficial]. At each stage $i$, compute the accumulated Gaussian set $G_i$ and render the image $I_i = \mathcal{R}(G_i)$ [S1, unofficial].
3.  **Compute Loss:** Calculate the rendering loss $L_{render}(I_i, I_{gt})$ for every intermediate stage $i$ [S1, unofficial]. The total loss is the sum of losses across all active stages:
    $$ L_{total} = \sum_{i=1}^{N} \lambda_i L_{render}(I_i, I_{gt}) $$
    With $\lambda_i = 1$ for all $i$ [S1, unofficial].
4.  **Backpropagation:** Compute gradients of $L_{total}$ with respect to the predictor parameters [S1, unofficial]. Because $I_i$ depends on all preceding increments $\Delta G_1, \dots, \Delta G_i$, gradients propagate back to earlier stages, enabling joint optimization [S1, unofficial].
5.  **Update:** Update predictor parameters using an optimizer (e.g., AdamW) [S1, unofficial].

**Pseudocode:**
```python
def finetune_step(predictor, image_gt, optimizer, num_stages):
    """
    One step of Finetune Training.
    predictor: Multi-stage Gaussian predictor initialized by POD.
    image_gt: Ground truth image.
    optimizer: Optimizer instance (e.g., AdamW).
    num_stages: Total number of prediction stages.
    """
    optimizer.zero_grad()
    total_loss = 0.0
    current_gaussians = []  # G_0 = empty set
    
    for i in range(num_stages):
        # Predict increment from residual features
        delta_g = predictor.predict_stage(i, current_gaussians)
        
        # Accumulate Gaussians: G_i = G_{i-1} U delta_g
        current_gaussians.extend(delta_g)
        
        # Render intermediate result: I_i = R(G_i)
        rendered_image = render_gaussians(current_gaussians)
        
        # Compute loss for this stage: L_render = 0.7 * L1 + 0.3 * (1 - SSIM)
        l1_dist = mean_absolute_error(rendered_image, image_gt)
        ssim_val = structural_similarity(rendered_image, image_gt)
        stage_loss = 0.7 * l1_dist + 0.3 * (1.0 - ssim_val)
        
        total_loss += stage_loss
        
    # Backpropagate through all stages jointly
    total_loss.backward()
    optimizer.step()
    
    return total_loss.item()

def render_gaussians(gaussians):
    """[G] Standard differentiable volume rendering via alpha-compositing."""
    return alpha_composite(gaussians)

def mean_absolute_error(img1, img2):
    """[G] Standard L1 distance computation."""
    return sum(abs(img1 - img2)) / len(img1)

def structural_similarity(img1, img2):
    """[G] Standard SSIM computation."""
    return compute_ssim_metric(img1, img2)
```

**Edge Cases and Pitfalls:**
*   **Gradient Scale:** In POD, distillation loss is scaled by 100 to match gradient scales [S1, unofficial]. In finetuning, the coefficient is 1, so the learning rate must be adjusted accordingly to avoid instability [S1, unofficial].
*   **Early Stage Degradation:** Early stages (Stage 1, 2) may show lower PSNR compared to "Only POD" because they sacrifice standalone accuracy to provide a better basis for later residual correction [S1, unofficial]. This is expected and indicates successful cross-stage coordination [S1, unofficial].

## Subtopics

### Finetuning and Quantization
A post-training variant where the costly short-horizon optimization is removed, and the model is trained with direct image-space supervision to refine reconstruction and enable learned quantization [S1, unofficial]. The steps are: 1) Remove POD optimization steps; 2) Train with direct image-space supervision (cross-stage rendering finetuning); 3) Apply learned quantization to compress the Gaussian representation [S1, unofficial]. This allows for compact storage and transmission of the predicted Gaussian parameters [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
*   **Time:** Per-iteration cost is significantly reduced compared to POD because the short-horizon local optimization loop is removed [S1, unofficial]. However, it requires rendering at every intermediate stage, which adds overhead compared to single-stage methods [S1, unofficial].
*   **Memory:** Requires storing intermediate Gaussian sets $G_i$ and rendered images $I_i$ for backpropagation through all stages [S1, unofficial].

**Measured Performance:**
*   On DIV2K, POD+Finetune lowers cumulative PSNR after Stage 1 (25.58 dB vs 26.58 dB for Only POD) and Stage 2 (27.89 dB vs 28.29 dB), but improves later stages, reaching 30.76 dB at Stage 4 compared to 29.48 dB for Only POD [S1, unofficial].
*   Finetuning redistributes the reconstruction burden, leading to specialized roles: Stage-1 features show clearer structural patterns, while Stage-4 features contain more high-frequency residual responses [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Enables joint optimization across stages; improves final reconstruction quality; reduces per-iteration training cost; supports learned quantization [S1, unofficial].
*   **Limitations:** Early-stage PSNR may degrade; requires careful tuning of learning rates due to gradient scale changes [S1, unofficial].

**When to Use:**
Use when the goal is to maximize the final accumulated reconstruction quality and enable efficient storage via quantization, and when the computational cost of local refinement in POD is prohibitive [S1, unofficial]. Do not use if strong intermediate-stage standalone accuracy is required [S1, unofficial].

## Background
Finetune Training was introduced in the AIR (Amortized Image Reconstruction Framework) paper as a successor to POD pretraining [S1, unofficial]. It addresses the limitation of distillation-based methods where later stages must compensate for upstream errors [S1, unofficial]. The method builds on the observation that supervising cumulative results encourages cross-stage coordination [S1, unofficial]. It is used in self-supervised feed-forward 2D Gaussian Splatting frameworks to achieve high-quality reconstruction with efficient storage [S1, unofficial].
