# Cross-scale geometric adaptation

Also called: Lgeo, Reprojection error supervision, Reprojection-based cross-scale geometric adaptation

## Overview
Cross-scale geometric adaptation is a self-adaptive regularization method that uses reprojection errors across multiple voxel scales to guide geometry learning without requiring explicit depth ground truth [S1]. It selects render depths with minimal reprojection error across different scales as pseudo labels, ensuring geometric integrity and reducing floaters more robustly than single-scale depth priors [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Training views $i$ and $j$ (where $j$ is a neighboring or novel view), camera intrinsics $K_i, K_j$, camera poses $(R_i, t_i), (R_j, t_j)$, RGB maps $C_i, C_j$, and a multi-scale voxel representation with render depths $D_{il}(p_i)$ at scale $l$ for pixel $p_i$ [S1].
*   **Outputs:** Geometric adaptation loss $\mathcal{L}_{geo}$ and the selected pseudo-ground truth depth $D'(r_{train})$ for each training ray $r_{train}$ [S1].

**Data Structures:**
*   **Multi-scale Voxels:** A hierarchy of voxel grids at low, medium, and high resolutions, often using weight-sharing across scales to capture varying scene frequencies [S1].
*   **Ray Data:** For each training ray $r_{train}$, the system stores the 2D pixel coordinate $p_i$ in frame $i$ [S1].

**Numbered Steps:**
1.  **Reprojection to 3D (Frame $i$):** For a pixel $p_i$ in frame $i$, compute its homogeneous coordinate $\tilde{p}_i$ [S1]. Calculate the 3D point in the camera coordinate system of frame $i$ ($x_{li}$) using the depth $D_{il}(p_i)$ at scale $l$ and camera intrinsics $K_i$ [S1]:
    $$
    x_{li} = D_{il}(p_i) K_i^{-1} \tilde{p}_i
    $$
    Alternatively, the 3D point can be determined directly from the ray origin $o_i(p_i)$ and direction $v_i(p_i)$ [S1]:
    $$
    x_l = o_i(p_i) + D_{il}(p_i) v_i(p_i)
    $$
2.  **Transform to World Coordinates:** Transform $x_{li}$ to world coordinates $x_l$ using frame $i$'s rotation $R_i$ and translation $t_i$ [S1]:
    $$
    x_l = R_i x_{li} + t_i
    $$
3.  **Reproject to Frame $j$:** Transform the world coordinate point $x_l$ to the camera coordinate system of frame $j$ using frame $j$'s rotation $R_j$ and translation $t_j$ [S1]:
    $$
    x_{li \to j} = R_j^T (x_l - t_j)
    $$
4.  **Project to 2D (Frame $j$):** Project $x_{li \to j}$ back to the 2D pixel coordinate system of frame $j$ using intrinsics $K_j$ and the projection function $\pi([x, y, z]^T) = [x/z, y/z]^T$ [S1]:
    $$
    \tilde{p}_{li \to j} = \pi(K_j x_{li \to j})
    $$
5.  **Compute Reprojection Error:** Calculate the error $e_l(p_i)$ for scale $l$ as the difference between the original RGB pixel $C_i(p_i)$ and the warped RGB pixel $C_j(\tilde{p}_{li \to j})$ from frame $j$ [S1]:
    $$
    e_l(p_i) = C_i(p_i) - C_j(\tilde{p}_{li \to j})
    $$
6.  **Select Pseudo-Ground Truth:** Identify the scale $l$ that minimizes the reprojection error for the given ray [S1]. This scale's depth is selected as the pseudo-ground truth depth $D'(r_{train})$ [S1]:
    $$
    D'(r_{train}) = \arg \min_l (e_l(r_{train}))
    $$
7.  **Compute Loss:** Calculate the geometric adaptation loss $\mathcal{L}_{geo}$ as the Mean Squared Error (MSE) between the rendered depth $\hat{D}_l(r_{train})$ and the selected pseudo-ground truth depth $D'(r_{train})$ across all scales $l$ for each training ray [S1]:
    $$
    \mathcal{L}_{geo}(r_{train}) = \sum_{l=0}^{L} \| \hat{D}_l(r_{train}) - D'(r_{train}) \|^2
    $$

**Parameters:**
*   **Scales:** Typically includes Low, Medium, and High resolution voxels [S1].
*   **Weighting Factor $\lambda$:** Part of the total loss $\mathcal{L}_{total} = \mathcal{L}_{photometric} + \lambda \mathcal{L}_{geo}$ [S1]. Value not given in sources.

**Edge Cases and Pitfalls:**
*   **Sparse Views:** The method relies on accurate camera poses [S1]. In scenarios with significant viewpoint changes or sparse training views (e.g., 360° datasets), generalization may be challenging [S1].
*   **Local Minima:** Omitting novel view rays risks local minima, causing incorrect geometry [S1].
*   **Scale Mismatch:** Using a single scale depth prior ($\mathcal{L}_d$) alone can suffer from higher error later in training due to scale mismatches, whereas $\mathcal{L}_{geo}$ refines depth progressively [S1].

**Pseudocode:**
```python
def compute_cross_scale_geo_loss(rays, voxel_grids, intrinsics, poses, rgb_maps):
    """
    rays: list of dicts with keys 'p_i' (2D array), 'frame_i' (str), 'frame_j' (str)
    voxel_grids: list of callables that return depth for a pixel and frame
    intrinsics: dict mapping frame_id to 3x3 matrix
    poses: dict mapping frame_id to (R, t) tuples
    rgb_maps: dict mapping frame_id to 2D array of RGB values (H, W, 3)
    """
    total_loss = 0.0
    INF = float('inf')

    for ray in rays:
        p_i = ray['p_i']
        fid_i, fid_j = ray['frame_i'], ray['frame_j']
        K_i, K_j = intrinsics[fid_i], intrinsics[fid_j]
        R_i, t_i = poses[fid_i]
        R_j, t_j = poses[fid_j]
        C_i, C_j = rgb_maps[fid_i], rgb_maps[fid_j]

        min_error_sq = INF
        best_scale_depth = None
        scale_depths = []

        for l, render_depth_fn in enumerate(voxel_grids):
            # 1. Get depth at scale l for pixel p_i in frame i
            D_il = render_depth_fn(p_i, fid_i)
            scale_depths.append(D_il)

            # 2. Reproject to 3D in camera coordinates of frame i
            p_i_hom = [p_i[0], p_i[1], 1.0]
            inv_K_i = _inverse_3x3(K_i)
            vec = _mat_vec_mul(inv_K_i, p_i_hom)
            x_li = [D_il * v for v in vec]

            # 3. Transform to World Coordinates
            x_l = _mat_vec_mul(R_i, x_li)
            x_l = [x_l[k] + t_i[k] for k in range(3)]

            # 4. Transform to Camera Coordinates of frame j
            diff = [x_l[k] - t_j[k] for k in range(3)]
            x_li_j = _mat_vec_mul(_transpose(R_j), diff)

            # 5. Project to 2D in frame j
            if abs(x_li_j[2]) < 1e-6:
                continue
            p_j = [x_li_j[0] / x_li_j[2], x_li_j[1] / x_li_j[2]]

            # 6. Compute Reprojection Error (Squared L2)
            # Note: Sources do not specify interpolation method; nearest-neighbor used here [G]
            row_i, col_i = int(round(p_i[1])), int(round(p_i[0]))
            row_j, col_j = int(round(p_j[1])), int(round(p_j[0]))
            C_i_val = C_i[row_i][col_i]
            C_j_val = C_j[row_j][col_j]
            error_sq = sum((C_i_val[k] - C_j_val[k])**2 for k in range(3))

            if error_sq < min_error_sq:
                min_error_sq = error_sq
                best_scale_depth = D_il

        # 7. Compute Loss against best scale depth
        if best_scale_depth is not None:
            for D_l in scale_depths:
                total_loss += (D_l - best_scale_depth) ** 2

    return total_loss

def _inverse_3x3(M): return M  # Standard linear algebra routine
def _mat_vec_mul(M, v): return [sum(M[i][j]*v[j] for j in range(3)) for i in range(3)]
def _transpose(M): return [[M[j][i] for j in range(3)] for i in range(3)]
```

## Operating characteristics
*   **Time Complexity:** Increases with the number of scales and the cost of reprojection for each scale per ray [S1]. Requires rendering depth at multiple scales and performing coordinate transformations for each [S1].
*   **Memory Complexity:** Requires storing multi-scale voxel grids and RGB maps for training views [S1].
*   **Performance:** Significantly reduces floaters and improves convergence quality across scales compared to training without geometric adaptation [S1]. Achieves lower final depth error than single-scale depth priors ($\mathcal{L}_d$) [S1].
*   **Strengths:** Self-adaptive; does not require complex scheduling or external depth priors [S1]. Robust to geometric noise compared to feature-warping methods like GeCoNeRF [S1].
*   **Limitations:** Relies on accurate camera poses [S1]. Performance may degrade in few-shot scenarios with sparse views or large viewpoint changes [S1].

## Background
*   **Origin:** Proposed in **FrugalNeRF** [S1].
*   **History:** Developed to accelerate and regularize training in extreme few-shot novel view synthesis without learned priors [S1]. It addresses the issue of floaters and sub-optimal convergence in multi-scale voxel-based NeRFs [S1].
*   **Usage:** Used in FrugalNeRF for few-shot NeRF training, often combined with novel view regularization and weight-sharing voxels [S1].
