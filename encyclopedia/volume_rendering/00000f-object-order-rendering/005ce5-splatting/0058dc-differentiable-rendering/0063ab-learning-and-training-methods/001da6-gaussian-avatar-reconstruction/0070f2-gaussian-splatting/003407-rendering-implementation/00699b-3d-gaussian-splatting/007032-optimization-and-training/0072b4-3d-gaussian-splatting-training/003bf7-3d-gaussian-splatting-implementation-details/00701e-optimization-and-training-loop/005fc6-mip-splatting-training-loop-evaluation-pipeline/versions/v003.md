# Mip-Splatting Training Loop & Evaluation Pipeline

Also called: 3D Gaussian Splatting Training Schedule, Mip-3DGS Training Loop

## Overview
This method defines the complete training iteration and evaluation procedure for Mip-Splatting, handling camera sampling, subpixel-aware rendering, hybrid loss computation, adaptive densification/pruning, and quantitative metric reporting [S1, unofficial]. It distinguishes itself from standard 3D Gaussian Splatting by incorporating subpixel jittering during rendering and ground truth resampling to mitigate aliasing artifacts, alongside a specific schedule for spherical harmonics degree incrementation and opacity resetting [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 3D Gaussians $\mathcal{G}$ with parameters (position, covariance, opacity, SH coefficients); a dataset of training images and camera poses; optimization hyperparameters (learning rates, thresholds, intervals); and pipeline flags (SH conversion mode, kernel size).
*   **Outputs:** Updated Gaussian parameters; rendered images; quantitative metrics (SSIM, PSNR, LPIPS) logged to TensorBoard and JSON files.

**Data Structures:**
*   `gaussians`: Object containing optimizer state, Gaussian attributes (`xyz`, `features_dc`, `features_rest`, `opacity`, `scaling`, `rotation`), and tracking tensors (`max_radii2D`, `grads`).
*   `viewpoint_stack`: A list or queue of training camera objects.
*   `trainCameras`: List of all training camera objects, indexed by resolution level.
*   `pipe`: Pipeline configuration object containing flags `convert_SHs_python` and `compute_cov3D_python`.

**Parameters (Default Values from [S1, unofficial]):**
*   `iterations`: 30,000
*   `densify_from_iter`: 500
*   `densify_until_iter`: 15,000
*   `densification_interval`: 100
*   `opacity_reset_interval`: 3,000
*   `densify_grad_threshold`: 0.0002
*   `lambda_dssim`: 0.2
*   `kernel_size`: 0.1 (dataset parameter)
*   `ray_jitter`: False (dataset parameter)
*   `resample_gt_image`: False (dataset parameter)
*   `sample_more_highres`: False (dataset parameter)
*   `white_background`: False (dataset parameter)
*   `test_iterations`: [7000, 30000]
*   `save_iterations`: [7000, 30000]

**Numbered Steps:**

1.  **Learning Rate Update:** Update the learning rates for all Gaussian parameters based on the current iteration count using `gaussians.update_learning_rate(iteration)` [S1, unofficial].
2.  **SH Degree Increment:** If `iteration % 1000 == 0`, increase the active spherical harmonics degree by one using `gaussians.oneupSHdegree()` [S1, unofficial].
3.  **Camera Sampling:** Pop a random camera from `viewpoint_stack`. If `dataset.sample_more_highres` is true and `random.random() < 0.3`, override the selected camera with a high-resolution camera from `trainCameras[highresolution_index]` [S1, unofficial].
4.  **Subpixel Offset Generation:** If `dataset.ray_jitter` is enabled, generate a subpixel offset tensor of shape `(H, W, 2)` with values uniformly sampled from `[-0.5, 0.5]` on CUDA. Otherwise, set `subpixel_offset = None` [S1, unofficial].
5.  **Rendering:** Render the scene by calling `render(viewpoint_cam, gaussians, pipe, background, kernel_size=dataset.kernel_size, subpixel_offset=subpixel_offset)`. Extract the rendered image `image`, viewspace points `viewspace_point_tensor`, visibility filter `visibility_filter`, and screen-space radii `radii` from the returned dictionary [S1, unofficial].
6.  **Ground Truth Resampling:** If `dataset.resample_gt_image` is true, resample the ground truth image `gt_image` using the `subpixel_offset` via `create_offset_gt(gt_image, subpixel_offset)` to align the target with the jittered sampling [S1, unofficial].
7.  **Tracking and Statistics:**
    *   Update the maximum image-space radii for pruning: `gaussians.max_radii2D[visibility_filter] = torch.max(gaussians.max_radii2D[visibility_filter], radii[visibility_filter])` [S1, unofficial].
    *   Accumulate gradient statistics for densification: `gaussians.add_densification_stats(viewspace_point_tensor, visibility_filter)` [S1, unofficial].
8.  **Loss Computation:** Compute the hybrid loss $\mathcal{L}$:
    $$ \mathcal{L} = (1 - \lambda_{\text{dssim}}) \mathcal{L}_{\text{L1}} + \lambda_{\text{dssim}} (1 - \text{SSIM}(I_{\text{render}}, I_{\text{gt}})) $$
    where $\mathcal{L}_{\text{L1}}$ is the L1 loss between the rendered image $I_{\text{render}}$ and the ground truth $I_{\text{gt}}$, and $\lambda_{\text{dssim}}$ is the DSSIM weight (default 0.2) [S1, unofficial].
9.  **Backpropagation:** Compute gradients $\nabla \mathcal{L}$ with respect to all Gaussian parameters using automatic differentiation [S1, unofficial].
10. **Densification and Pruning:** If `iteration > opt.densify_from_iter` and `iteration % opt.densification_interval == 0`:
    *   Determine `size_threshold`: If `iteration > opt.opacity_reset_interval`, set `size_threshold = 20`; otherwise, set `size_threshold = None` [S1, unofficial].
    *   Call `gaussians.densify_and_prune(opt.densify_grad_threshold, 0.005, scene.cameras_extent, size_threshold)` [S1, unofficial].
    *   Recompute 3D filters: `gaussians.compute_3D_filter(cameras=trainCameras)` [S1, unofficial].
11. **Opacity Reset:** If `iteration % opt.opacity_reset_interval == 0` or (`dataset.white_background` is true and `iteration == opt.densify_from_iter`), reset the opacities of the Gaussians [S1, unofficial].
12. **3D Filter Update (Post-Densification):** If `iteration > opt.densify_until_iter`, `iteration % 100 == 0`, and `iteration < opt.iterations - 100`, update the 3D filter: `gaussians.compute_3D_filter(cameras=trainCameras)` [S1, unofficial].
13. **Optimizer Step:** Perform the optimizer step and zero gradients: `gaussians.optimizer.step()` followed by `gaussians.optimizer.zero_grad(set_to_none=True)` [S1, unofficial].
14. **Evaluation:** At iterations specified in `--test_iterations`:
    *   Load rendered images from `test_preds_{scale}` and ground truth images from `gt_{scale}` directories [S1, unofficial].
    *   Compute per-image SSIM, PSNR, and LPIPS (using VGG network) [S1, unofficial].
    *   Average metrics across all images in the view set [S1, unofficial].
    *   Log to TensorBoard and save to `results.json` and `per_view.json` [S1, unofficial].

**Pseudocode:**

```python
def train_mip_splatting(gaussians, dataset, opt, pipeline, train_cameras, test_iterations, save_iterations):
    """
    Main training loop for Mip-Splatting.
    """
    viewpoint_stack = list(train_cameras) # Initialize stack with training cameras
    iteration = 0
    max_iterations = opt.iterations
    
    # Pre-calculate high-res index if needed
    highres_index = 0 # Placeholder for specific high-res camera index logic
    num_train_cameras = len(train_cameras)

    while iteration < max_iterations:
        iteration += 1
        
        # 1. Update Learning Rates
        gaussians.update_learning_rate(iteration)
        
        # 2. Increment SH Degree every 1000 iterations
        if iteration % 1000 == 0:
            gaussians.oneupSHdegree()
            
        # 3. Sample Camera
        if viewpoint_stack:
            viewpoint_cam = viewpoint_stack.pop()
        else:
            viewpoint_cam = train_cameras[0] # Fallback, though usually stack is replenished or sampled differently
            
        if dataset.sample_more_highres and random.random() < 0.3:
            viewpoint_cam = train_cameras[highres_index]
            
        # 4. Subpixel Offset
        subpixel_offset = None
        if dataset.ray_jitter:
            H, W = viewpoint_cam.image_height, viewpoint_cam.image_width
            # Generate random offsets in [-0.5, 0.5]
            subpixel_offset = torch.rand(2, H, W, device='cuda') - 0.5
            
        # 5. Render
        render_output = render(
            viewpoint_cam=viewpoint_cam,
            gaussians=gaussians,
            pipe=pipeline,
            background=torch.tensor([0.0, 0.0, 0.0], device='cuda'), # Default background
            kernel_size=dataset.kernel_size,
            subpixel_offset=subpixel_offset
        )
        
        rendered_image = render_output['render']
        viewspace_point_tensor = render_output['viewspace_points']
        visibility_filter = render_output['visibility_filter']
        radii = render_output['radii']
        
        # 6. Resample Ground Truth
        gt_image = viewpoint_cam.original_image # Assume this attribute exists
        if dataset.resample_gt_image and subpixel_offset is not None:
            gt_image = create_offset_gt(gt_image, subpixel_offset)
            
        # 7. Track Stats
        # Update max radii for pruning
        if visibility_filter.any():
            gaussians.max_radii2D[visibility_filter] = torch.max(
                gaussians.max_radii2D[visibility_filter], 
                radii[visibility_filter]
            )
        # Add densification stats
        gaussians.add_densification_stats(viewspace_point_tensor, visibility_filter)
        
        # 8. Loss Computation
        lambda_dssim = opt.lambda_dssim
        l1_loss = torch.abs(rendered_image - gt_image).mean()
        ssim_loss = 1 - compute_ssim(rendered_image, gt_image) # Assuming compute_ssim returns scalar
        loss = (1 - lambda_dssim) * l1_loss + lambda_dssim * ssim_loss
        
        # 9. Backpropagation
        loss.backward()
        
        # 10. Densification and Pruning
        if iteration > opt.densify_from_iter and iteration % opt.densification_interval == 0:
            size_threshold = None
            if iteration > opt.opacity_reset_interval:
                size_threshold = 20
                
            gaussians.densify_and_prune(
                grad_threshold=opt.densify_grad_threshold,
                opacity_threshold=0.005,
                extent=scene.cameras_extent, # Assuming scene object is accessible
                size_threshold=size_threshold
            )
            gaussians.compute_3D_filter(cameras=train_cameras)
            
        # 11. Opacity Reset
        if iteration % opt.opacity_reset_interval == 0:
            gaussians.reset_opacities()
        elif dataset.white_background and iteration == opt.densify_from_iter:
            gaussians.reset_opacities()
            
        # 12. 3D Filter Update (Post-Densification)
        if iteration > opt.densify_until_iter and iteration % 100 == 0 and iteration < max_iterations - 100:
            gaussians.compute_3D_filter(cameras=train_cameras)
            
        # 13. Optimizer Step
        gaussians.optimizer.step()
        gaussians.optimizer.zero_grad(set_to_none=True)
        
        # 14. Evaluation and Saving
        if iteration in test_iterations:
            evaluate_and_log(gaussians, train_cameras, test_iterations, iteration)
            
        if iteration in save_iterations:
            save_gaussian_model(gaussians, iteration)

def evaluate_and_log(gaussians, cameras, test_iterations, current_iter):
    """
    Evaluate metrics and save results.
    """
    ssim_scores = []
    psnr_scores = []
    lpips_scores = []
    
    for cam in cameras:
        # Render at test resolution
        render_output = render(cam, gaussians, pipeline, background=None)
        rendered_img = render_output['render']
        gt_img = cam.original_image
        
        # Compute metrics
        ssim = compute_ssim(rendered_img, gt_img)
        psnr = compute_psnr(rendered_img, gt_img)
        lpips_val = compute_lpips(rendered_img, gt_img) # Requires VGG network
        
        ssim_scores.append(ssim)
        psnr_scores.append(psnr)
        lpips_scores.append(lpips_val)
        
    avg_ssim = sum(ssim_scores) / len(ssim_scores)
    avg_psnr = sum(psnr_scores) / len(psnr_scores)
    avg_lpips = sum(lpips_scores) / len(lpips_scores)
    
    # Log to TensorBoard
    log_scalar('Metrics/SSIM', avg_ssim, current_iter)
    log_scalar('Metrics/PSNR', avg_psnr, current_iter)
    log_scalar('Metrics/LPIPS', avg_lpips, current_iter)
    
    # Save to JSON
    save_results({
        'iteration': current_iter,
        'ssim': avg_ssim,
        'psnr': avg_psnr,
        'lpips': avg_lpips
    }, 'results.json')
    save_per_view_results({
        'iteration': current_iter,
        'images': [{'ssim': s, 'psnr': p, 'lpips': l} for s, p, l in zip(ssim_scores, psnr_scores, lpips_scores)]
    }, 'per_view.json')
```

## Operating characteristics
*   **Time Complexity:** Dominated by the rasterization step per iteration, which is $O(N)$ where $N$ is the number of Gaussians, but heavily dependent on the number of visible Gaussians per pixel. The subpixel jittering and GT resampling add constant overhead per pixel. Densification occurs every 100 iterations, adding $O(N)$ complexity for splitting/pruning operations.
*   **Memory Complexity:** $O(N)$ for storing Gaussian parameters and gradients. The `max_radii2D` tensor adds $O(N)$ memory.
*   **Measured Performance:** The method is designed to improve reconstruction quality (SSIM/PSNR) by reducing aliasing, particularly at high resolutions or when viewing angles change rapidly. The specific performance numbers depend on the dataset and hardware, but the subpixel jittering is intended to provide smoother gradients and better convergence [S1, unofficial].
*   **Strengths:** Mitigates aliasing artifacts through subpixel sampling; adaptive densification ensures detail is captured where needed; SH degree increment allows for gradual increase in view-dependent detail.
*   **Limitations:** Increased computational overhead per iteration due to jittering and resampling; requires careful tuning of densification thresholds to avoid overfitting or excessive Gaussian count.
*   **When to Use:** When high-fidelity reconstruction is required, especially for scenes with fine details or when training on high-resolution images.
*   **When Not to Use:** When training speed is the primary constraint and lower resolution/quality is acceptable.

## Background
Mip-Splatting extends the original 3D Gaussian Splatting framework by addressing aliasing issues through subpixel-aware rendering. The training loop described here is based on the implementation details provided in the Mip-Splatting repository [S1, unofficial]. The core optimization principles (SGD, Adam optimizer, hybrid loss) are inherited from the original 3D Gaussian Splatting paper [S1, unofficial].
