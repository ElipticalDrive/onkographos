# Shape Completion Training

Also called: Decoder-based Shape Completion, Folding Grid Expansion for Shape Completion

## Overview
Shape Completion Training is a decoder-based method that predicts all 14 Gaussian attributes from partial input views without requiring target coordinates, utilizing a folding grid expansion to increase primitive density [S1, unofficial]. It distinguishes itself from sibling methods by predicting the full set of Gaussian parameters directly from a frozen encoder's features via a transformer decoder, rather than relying on dense depth estimation or iterative optimization from scratch [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Partial input images $I$ (with missing regions/masks) and their corresponding masks.
*   **Output:** A set of 1,024 3D Gaussians, each defined by mean position $\mu_i$, scale $s_i$, rotation $r_i$ (quaternion), opacity $\alpha_i$, and color coefficients $c_i$ (DC and spherical harmonics).

**Data Structures:**
*   **Coarse Primitives:** A set of 256 intermediate primitives predicted by the decoder.
*   **Final Gaussians:** A set of 1,024 Gaussians generated by expanding the coarse primitives.

**Algorithm Steps:**
1.  **Freeze Encoder:** Use a pretrained encoder (e.g., DINOv2 or MASt3R) and freeze its weights.
2.  **Feature Extraction:** Pass the input images through the frozen encoder to extract multi-scale features $F^l$ [S1, unofficial].
3.  **Decoder Processing:** Process the features through a decoder consisting of 4 Transformer layers (width 256, 8 attention heads) to predict 256 coarse primitives [S1, unofficial].
4.  **Folding Grid Expansion:** Expand the 256 coarse primitives to 1,024 Gaussians using a fixed $2 \times 2$ folding grid. This step increases the density of the representation without additional learnable parameters for the expansion itself [S1, unofficial].
5.  **Attribute Prediction:** The decoder predicts all 14 Gaussian attributes for the expanded set. No target coordinates are provided as input to the decoder; it predicts absolute positions [S1, unofficial].
6.  **Loss Calculation:** Compute the total loss $\mathcal{L}$ as a combination of Chamfer distance, nearest-neighbor attribute matching, and direct attribute losses:
    $$ \mathcal{L} = \mathcal{L}_{Chamfer}^{2} + \mathcal{L}_{NN} + 0.1 \left( \mathcal{L}_{L1}(\alpha, s, c) + \mathcal{L}_{sign\text{-}inv}(q) \right) $$
    where:
    *   $\mathcal{L}_{Chamfer}^{2}$ is the squared $\ell_2$ Chamfer distance between predicted and target points.
    *   $\mathcal{L}_{NN}$ is the nearest-neighbor attribute matching loss.
    *   $\mathcal{L}_{L1}(\alpha, s, c)$ is the $\ell_1$ loss applied to opacity $\alpha$, scale $s$, and DC color coefficients $c$.
    *   $\mathcal{L}_{sign\text{-}inv}(q)$ is the sign-invariant quaternion similarity loss for rotation $q$.
    *   The aggregate attribute term is weighted by 0.1 [S1, unofficial].
7.  **Optimization:** Optimize the decoder parameters using AdamW.

**Pseudocode:**
```python
def shape_completion_training(input_images, masks, target_gaussians):
    # 1. Freeze Encoder
    encoder = load_pretrained_encoder()
    encoder.eval()
    for param in encoder.parameters():
        param.requires_grad = False

    # 2. Initialize Decoder
    decoder = TransformerDecoder(num_layers=4, d_model=256, nhead=8)
    optimizer = AdamW(decoder.parameters(), lr=1e-3, weight_decay=0.05)

    # 3. Training Loop
    for epoch in range(80):
        # Warm-up for first 5 epochs
        if epoch < 5:
            adjust_lr_warmup(optimizer, epoch, total_epochs=5, base_lr=1e-3)

        # Forward Pass
        features = encoder(input_images)
        coarse_primitives = decoder(features) # Predicts 256 primitives
        
        # Expand to 1024 Gaussians using fixed 2x2 folding grid
        gaussians = expand_folding_grid(coarse_primitives, expansion_factor=4)
        
        # Render or compute losses directly on Gaussians
        # Note: The source implies direct attribute loss and Chamfer distance
        # against target points/Gaussians
        
        # Compute Losses
        chamfer_loss = squared_l2_chamfer(gaussians.mean, target_gaussians.mean)
        nn_loss = nearest_neighbor_attribute_loss(gaussians, target_gaussians)
        
        attr_loss_alpha = l1_loss(gaussians.opacity, target_gaussians.opacity)
        attr_loss_scale = l1_loss(gaussians.scale, target_gaussians.scale)
        attr_loss_color = l1_loss(gaussians.color_dc, target_gaussians.color_dc)
        attr_loss_rot = sign_invariant_quaternion_loss(gaussians.rotation, target_gaussians.rotation)
        
        total_attr_loss = attr_loss_alpha + attr_loss_scale + attr_loss_color + attr_loss_rot
        
        total_loss = chamfer_loss + nn_loss + 0.1 * total_attr_loss
        
        # Backward Pass
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()

    return decoder
```

**Parameters:**
*   **Decoder Architecture:** 4 Transformer layers, width 256, 8 attention heads [S1, unofficial].
*   **Expansion:** 256 coarse primitives to 1,024 Gaussians via fixed $2 \times 2$ folding grid [S1, unofficial].
*   **Optimizer:** AdamW, learning rate $10^{-3}$, weight decay 0.05, 5 warm-up epochs, batch size 64 [S1, unofficial].
*   **Training Duration:** 80 epochs [S1, unofficial].
*   **Seeds:** Three decoder seeds are trained per frozen encoder [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Missing Ratios:** The method is evaluated at visible ratios of 0.3, 0.5, and 0.7. Performance may degrade at extreme occlusion levels not covered in the primary evaluation [S1, unofficial].
*   **Coordinate Prediction:** Since the decoder predicts absolute coordinates without target guidance, initialization and feature alignment are critical [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training involves 80 epochs of forward/backward passes through a transformer decoder. The expansion step is fixed and lightweight.
*   **Memory Complexity:** Depends on the encoder's feature map size and the batch size (64). The decoder is relatively small (4 layers, width 256).
*   **Performance:** Evaluated on 520 held-out objects. Render metrics are reported using the seed-0 decoder at 50% visibility and four fixed views per object [S1, unofficial].
*   **Strengths:** Fast inference compared to iterative optimization methods; leverages pretrained semantic features.
*   **Limitations:** Relies on the quality of the frozen encoder; limited to the capacity of the transformer decoder to predict absolute 3D structure from 2D features.

## Background
Shape Completion Training is part of the Gaussian-JEPA framework, which applies Joint-Embedding Predictive Architecture (JEPA) principles to 3D Gaussian Splatting. It was introduced to enable robust 3D reconstruction from partial views by predicting Gaussian attributes directly from high-level features, bypassing the need for dense depth maps or iterative per-scene optimization [S1, unofficial].
