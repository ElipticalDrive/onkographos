# Conditional 3D Gaussian Splatting Generation

Also called: Conditional Generation (Text/Image/Partial), DiffGS Conditional

## Overview
Conditional 3D Gaussian Splatting Generation refers to methods that synthesize 3D Gaussian Splatting (3DGS) representations directly from conditioning signals such as text prompts, input images, or partial 3DGS inputs with large occlusions [S1]. Unlike standard 3DGS which requires multi-view images for optimization, these methods leverage diffusion models or feedforward networks to predict Gaussian attributes (position, covariance, color, opacity) conditioned on the input [S1]. This approach is distinct from implicit NeRF feature fields by operating on explicit Gaussian primitives, allowing for direct manipulation and high-fidelity geometry recovery [S1].

## How it works
The core methodology, as defined by DiffGS [S1], involves encoding conditioning signals into embeddings and training a diffusion model (DiffGS) to denoise Gaussian attributes.

**Inputs and Outputs:**
*   **Inputs:** Text prompts, input images, or partial 3DGS point clouds.
*   **Outputs:** A set of 3D Gaussians defined by mean $\mu$, covariance $\Sigma$ (or scale/rotation), color $c$, and opacity $\alpha$.

**Data Structures:**
The Gaussian field is represented as a list of primitives. Each primitive $i$ contains:
*   $\mu_i \in \mathbb{R}^3$: Center position.
*   $s_i \in \mathbb{R}^3$: Scale.
*   $r_i \in \mathbb{R}^4$: Rotation (quaternion).
*   $c_i \in \mathbb{R}^3$: Color (SH coefficients).
*   $\alpha_i \in \mathbb{R}$: Opacity.

**Custom Encoders:**
To handle different conditioning modalities, frozen pre-trained encoders are used as custom encoders $\gamma$:
1.  **Text/Image:** Frozen CLIP [S1] encoders serve as $\gamma_{text}$ and $\gamma_{image}$ to produce text/image embeddings [S1].
2.  **Partial 3DGS:** A modified PointNet [S1] serves as $\gamma_{partial}$ to encode partial 3DGS inputs [S1].

**Optimization Objective:**
The model is trained using a conditional diffusion objective (Eq. 8 in [S1]), where the noise prediction is conditioned on the embeddings from $\gamma$.

**Pseudocode for Conditional Encoding and Training Loop:**
```python
# Pseudocode based on DiffGS [S1]
# Note: The specific diffusion architecture (e.g., U-Net) and noise schedule are assumed standard for diffusion models.

def get_condition_embedding(condition_type, condition_data):
    if condition_type == "text":
        # Use frozen CLIP text encoder
        embedding = clip_text_encoder(condition_data)
    elif condition_type == "image":
        # Use frozen CLIP image encoder
        embedding = clip_image_encoder(condition_data)
    elif condition_type == "partial_3dgs":
        # Use modified PointNet encoder
        embedding = pointnet_encoder(condition_data)
    else:
        raise ValueError("Unsupported condition type")
    return embedding

def train_diffgs(model, dataset, condition_type):
    optimizer = Adam(model.parameters())
    for epoch in range(num_epochs):
        for batch in dataset:
            # 1. Get conditioning signal
            condition_data = batch['condition']
            c_embedding = get_condition_embedding(condition_type, condition_data)
            
            # 2. Sample noise and timestep
            t = sample_timestep()
            noise = sample_noise()
            
            # 3. Forward pass through diffusion model with conditioning
            # The model predicts noise given noisy Gaussians, timestep, and condition embedding
            predicted_noise = model(noisy_gaussians, t, c_embedding)
            
            # 4. Compute loss (conditional diffusion objective, Eq. 8 in [S1])
            loss = compute_diffusion_loss(noise, predicted_noise)
            
            # 5. Backpropagate
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
```

**Edge Cases and Pitfalls:**
*   **Partial Input Occlusion:** The method must handle highly occluded inputs where large portions of the geometry are missing [S1]. The PointNet encoder $\gamma_{partial}$ is specifically modified to handle this [S1].
*   **Semantic Alignment:** The method must accurately recover semantics described in text prompts [S1].

## Subtopics

### [Promptable Explicit Scene Representation](15906-promptable-explicit-scene-representation.md)
A mechanism for 3D editing (extraction, deletion, appearance modification) in 3DGS by computing activation scores of 3D Gaussians based on prompts (text, points, boxes) using cosine similarity and softmax. It differs from implicit NeRF feature fields by operating on explicit Gaussian primitives, allowing direct manipulation of color and opacity parameters for specific semantic subsets.

### Interactive3D
A method operating in two stages for interactive 3D object generation and refinement, optimizing 3D objects through 3DGS and SDS in first stage, then transforming model into InstantNGP structure with interactive hash refinement module in second stage [S2].

### 3D Gaussian Splatting (Text-to-3D Implementation)
A reimplementation of 3D Gaussian Splatting adapted for text-to-3D generation, modified to support a learnable MLP background and specific gradient propagation [S3].
*   **Gradient Propagation:** Calculates gradients in the forward rendering order, rather than the inverse order used in the official code [S3]. This simplifies per-pixel background integration [S3].
*   **Depth Rendering:** Depth maps are rendered by sampling the view-space depth at the centers of the Gaussians [S3].
*   **Z-Variance:** A z-variance renderer is implemented to compute z-variance for use in a z-var loss term during optimization [S3].
*   **Opacity Clamping:** Gaussian opacity is clamped to a fixed range during rendering and optimization to stabilize gradients and prevent numerical overflow/underflow [S3].
*   **Gaussian Count:** The target number of Gaussians after densification during training is around $10^5$ to $10^6$ [S3].

### Gaussian Pulling to Zero-Level Set
A technique that pulls Gaussian centers onto the zero-level set of a neural SDF field to prevent floating ellipsoids and achieve accurate geometry estimation. It also pulls query points to Gaussian disks rather than centers to bridge the gap between continuous SDF fields and sparse Gaussian distributions [S4].
*   **Steps:**
    1.  Pull Gaussian centers to the zero-level set of the SDF field [S4].
    2.  Pull neighboring space/query points onto Gaussian disks [S4].
    3.  Use normalized SDF gradient for the pulling operation [S4].
*   **Comparison:** Differs from NeuralPull [45], which pulls query points to Gaussian centers. This method pulls query points to Gaussian disks, better bridging continuous SDF fields and sparse Gaussian distributions [S4].
*   **Constraints:** The orthogonal loss helps learn a more regularized SDF field, while thin and tangent loss align Gaussian disk orientation with the SDF gradient on zero-level sets [S4]. Adding an Eikonal term to constrain gradient length can degenerate results because the method depends on both predicted SDF values and gradient directions [S4].

## Operating characteristics
*   **Performance:** DiffGS produces significantly more visual-appealing and high-fidelity generations in terms of rendering and geometry qualities compared to DiffTF [S1].
*   **Dataset:** Experiments are conducted on the ShapeNet chair class with commonly used data splits [S1].
*   **Complexity:** Not given in the sources.
*   **Strengths:** Capable of recovering complex geometries and detailed appearances from highly occluded 3DGS [S1]. Accurately recovers semantics and geometries described in text prompts and images [S1].
*   **Limitations:** Not given in the sources.

## Background
The concept of conditional generation for 3D Gaussian Splatting was introduced by DiffGS [S1]. Gaussian Splatting completion is a task introduced by DiffGS, aiming to infer complete and dense 3DGS from partial ones to improve rendering quality at invisible viewpoints [S1]. The method leverages frozen CLIP encoders for text/image conditions and a modified PointNet for partial 3DGS conditions [S1].
