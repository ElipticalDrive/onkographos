# 3D Instance Segmentation with Contrastive Learning

Also called: Contrastive 3DGS Segmentation

## Overview
This method segments 3D Gaussian primitives into distinct semantic instances by training per-Gaussian features using contrastive learning on 2D masks [S1]. It solves the problem of object-level segmentation in 3D Gaussian Splatting (3DGS) scenes, where primitives do not strictly model geometry and may be placed around surfaces or shared between objects [S1]. It sets itself apart from sibling methods like [DeSplat](12925-desplat.md) by relying on feature similarity in a learned contrastive space rather than geometric clustering or explicit boundary detection, enabling interactive segmentation via single-click queries [S1].

## How it works
The method consists of three phases: 2D mask generation, contrastive feature training, and interactive segmentation with post-processing.

### Inputs and Outputs
**Inputs:**
- A pre-trained 3DGS scene (Gaussians with position, covariance, opacity, scaling, and SH coefficients).
- Training views (images and camera poses).
- Text queries for instances (e.g., "pillar") [S1].

**Outputs:**
- A set of segmented instances, each defined as a subset of Gaussian primitives [S1].
- 2D masks for each instance in each training view [S1].

### Data Structures
- **Gaussian Features:** Each Gaussian $i$ has a trainable feature vector $f_i \in \mathbb{R}^d$. The dimension $d$ is not specified in the sources [S1].
- **2D Masks:** Binary masks $M_{q,j}$ for instance $q$ in view $j$, generated via SAM-HQ and refined by feature similarity [S1].

### Steps

1. **Generate 2D Masks:**
   - For each training view, use GroundingDINO with a text query to output bounding boxes [S1].
   - Feed bounding boxes to SAM-HQ to output 2D masks per instance [S1].
   - Define the "background" mask as the complement of the union of all instance masks [S1].

2. **Regularize 3DGS Training (Pre-requisite):**
   - During the initial 3DGS training, add L1 regularization to opacity and scaling to discourage low-opacity occluded Gaussians and large shared Gaussians [S1].
   - The regularization term is:
     $$ \lambda_{\text{opacity}} \frac{1}{N} \sum_{i=1}^N \mathbf{o}_i + \lambda_{\text{scale}} \frac{1}{N} \sum_{i=1}^N \mathbf{s}_i $$
     where $N$ is the number of Gaussian primitives, $\mathbf{o}_i$ is opacity, and $\mathbf{s}_i$ is scaling [S1].

3. **Train Per-Gaussian Features:**
   - Rasterize trainable per-Gaussian features into per-pixel features $\hat{f}$ [S1].
   - Sample pixel pairs in input images. The sampling strategy uses two parameters: $M_u$ pixels uniformly in the image (to favor larger masks) and $M_s$ pixels per mask (to ensure small masks have enough samples) [S1]. Set $M_u = M_s = 4096$ [S1].
   - Compute contrastive loss based on the 2D masks:
     - **Pull Loss:** If pixels belong to the same 2D mask, pull their features together. Weighted by the ratio of negative-to-positive pairs to counter imbalance [S1].
     - **Push Loss:** If pixels belong to different masks, push their features apart. Includes a margin of 0.3 [S1].
     - **Hard Case Loss:** Add extra loss terms for hard cases where the distance between features is larger than 0.5 [S1].
   - Include a regularization term to encourage rendered features $\hat{f}$ to be unit norm [S1].

4. **Interactive Segmentation:**
   - User clicks inside the mask of an instance in any training view [S1].
   - Select the rendered feature $f_q$ corresponding to the clicked pixel as the query feature [S1].
   - Compute 2D masks for instances: For each instance $q$ and training view $j$, compare rendered features with query feature $f_q$ to generate 2D masks $M_{q,j}$ [S1].

5. **3D Instance Selection:**
   - Segment instance $I_q$ by selecting all Gaussians with contrastive features $f_i$ such that:
     $$ d(f_i, f_q) \leq \tau $$
     where $d$ is cosine distance and $\tau = 0.1$ [S1].

6. **Post-processing (Space Carving):**
   - Remove residual Gaussians from the background reconstruction that affect instance rendering [S1].
   - For each Gaussian, check if at least one of the following conditions is met in *every* training image:
     1. Center projects inside instance 2D masks $\{M_{q,j}\}$.
     2. Center projects outside image boundary.
     3. Center is not visible in current camera (e.g., behind camera) [S1].
   - If met for all views, remove the Gaussian from the background [S1].

### Pseudocode

```python
def generate_2d_masks(view, text_query):
    """
    Generate 2D masks for a single view using GroundingDINO and SAM-HQ.
    """
    # Use GroundingDINO to get bounding boxes from text query
    boxes = grounding_dino.detect(view.image, text_query)
    
    # Use SAM-HQ to get masks from boxes
    instance_masks = sam_hq.segment(view.image, boxes)
    
    # Background is complement of union of all instance masks
    background_mask = ~union(instance_masks)
    
    return instance_masks, background_mask

def contrastive_loss(pixels, masks, features):
    """
    Compute contrastive loss for sampled pixels.
    pixels: list of (x, y) coordinates
    masks: 2D mask map (pixel -> mask_id)
    features: per-pixel features from rasterization
    """
    pull_loss = 0.0
    push_loss = 0.0
    hard_loss = 0.0
    
    positive_pairs = []
    negative_pairs = []
    
    for i in range(len(pixels)):
        for j in range(i + 1, len(pixels)):
            mask_i = masks[pixels[i]]
            mask_j = masks[pixels[j]]
            
            dist = cosine_distance(features[pixels[i]], features[pixels[j]])
            
            if mask_i == mask_j and mask_i != background_id:
                positive_pairs.append((i, j))
                pull_loss += dist
            else:
                negative_pairs.append((i, j))
                push_loss += max(0, margin - dist)
                if dist > hard_threshold:
                    hard_loss += dist
    
    # Weight pull loss by negative-to-positive ratio
    if len(positive_pairs) > 0:
        pull_loss = pull_loss * (len(negative_pairs) / len(positive_pairs))
    
    total_loss = pull_loss + push_loss + hard_loss
    return total_loss

def train_contrastive_features(gaussians, views, masks, num_samples_per_view=4096, num_samples_per_mask=4096):
    """
    Train per-Gaussian features using contrastive learning.
    """
    optimizer = Adam(gaussians.features, lr=0.01)
    
    for epoch in range(num_epochs):
        for view in views:
            # Sample pixels
            pixels = sample_pixels(view, num_samples_per_view, num_samples_per_mask, masks)
            
            # Rasterize features
            rendered_features = rasterize_features(gaussians, view.camera, pixels)
            
            # Compute loss
            loss = contrastive_loss(pixels, masks, rendered_features)
            
            # Add feature norm regularization
            norm_reg = mean_squared_norm(rendered_features)
            loss += lambda_norm * norm_reg
            
            # Backpropagate
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

def segment_instance(query_view, query_pixel, gaussians, threshold=0.1):
    """
    Segment an instance based on a user click.
    """
    # Get query feature from clicked pixel
    query_feature = rasterize_feature(gaussians, query_view.camera, query_pixel)
    
    # Select Gaussians with similar features
    instance_gaussians = []
    for gaussian in gaussians:
        dist = cosine_distance(gaussian.feature, query_feature)
        if dist <= threshold:
            instance_gaussians.append(gaussian)
            
    return instance_gaussians

def space_carving(gaussians, instance_masks, views):
    """
    Remove residual Gaussians from background using space carving.
    """
    gaussians_to_remove = []
    
    for gaussian in gaussians:
        remove = True
        for view in views:
            projected_center = project(gaussian.center, view.camera)
            
            # Check if center is inside any instance mask
            inside_instance = False
            for mask in instance_masks:
                if is_inside_mask(projected_center, mask):
                    inside_instance = True
                    break
            
            # Check if center is outside image boundary
            outside_boundary = not is_inside_image(projected_center, view.image_size)
            
            # Check if center is not visible (e.g., behind camera)
            not_visible = is_behind_camera(gaussian.center, view.camera)
            
            # If at least one condition is met, this view supports removal
            if not (inside_instance or outside_boundary or not_visible):
                remove = False
                break
        
        if remove:
            gaussians_to_remove.append(gaussian)
            
    return gaussians_to_remove
```

### Parameters
- **Push loss margin:** 0.3 [S1].
- **Hard case threshold:** 0.5. Extra loss terms are added for hard cases where the distance between features is larger than 0.5 [S1].
- **Pull loss weighting:** Weighted by the ratio of negative-to-positive pairs to counter imbalance due to more negative pairs [S1].
- **Pixel sampling:** Uniformly sample $M_u$ pixels in the image (so larger masks get more samples) and $M_s$ pixels per mask (so small masks get enough samples). Set $M_u = M_s = 4096$ [S1].
- **Segmentation threshold $\tau$:** 0.1. Segment instance $I_q$ by selecting all Gaussians with contrastive features $f_i$ such that $d(f_i, f_q) \leq \tau$ [S1].
- **Regularization weights:** $\lambda_{\text{opacity}}$ and $\lambda_{\text{scale}}$ for L1 regularization on opacity and scaling. Values not given in the sources [S1].
- **Feature norm regularization weight:** Not given in the sources [S1].

### Edge Cases and Pitfalls
- **Low-opacity Gaussians:** Under the surface of objects, these do not receive enough gradients because they are occluded. Addressed by L1 regularization on opacity [S1].
- **Large Shared Gaussians:** Gaussians shared among different objects get conflicting gradients. Addressed by L1 regularization on scaling [S1].
- **Border Artifacts:** Gaussian primitives at the border between an instance and the background are "left behind," resulting in visual artifacts. Addressed by space carving post-processing [S1].
- **Mask Imbalance:** Contrastive methods are sensitive to the number of pixels sampled per mask. Addressed by dual sampling strategy ($M_u$ and $M_s$) [S1].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Not given in the sources.
- **Strengths:**
  - Interactive segmentation with single-click queries [S1].
  - Aggregates information from all views to produce better 2D masks than SAM-HQ alone [S1].
  - Regularization and post-processing improve visual quality [S1].
- **Limitations:**
  - Requires pre-trained 3DGS scene [S1].
  - Requires text queries for initial mask generation [S1].
  - Sensitive to mask sampling strategy [S1].
- **When to use:** When interactive, instance-level segmentation of a 3DGS scene is required, and text-based initial segmentation is acceptable [S1].
- **When not to use:** When real-time segmentation without user interaction is needed, or when text queries are not available [S1].
