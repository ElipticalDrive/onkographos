# Duplex-GS

Also called: Proxy-Guided Weighted Blending for Real-Time Order-Independent Gaussian Splatting

## Overview
Duplex-GS is a dual-hierarchy rendering framework for real-time order-independent Gaussian Splatting that combines alpha-blending with a reformulated Weighted-Sum Rendering (WSR) strategy [S1]. It solves the transparency artifacts and lack of early termination inherent in vanilla Order-Independent Transparency (OIT) methods, while reducing the sorting overhead of standard alpha-blending [S1]. Unlike Sort-free Gaussian Splatting which uses linear depth decay, Duplex-GS uses ellipsoidal cell proxies to establish a coarse spatial order, enabling physically grounded transmittance decay and early termination [S1].

## How it works
**Inputs:** Scene represented by $N$ ellipsoidal cells (proxies) and camera parameters. Each cell $n$ has a latent feature vector $f_n$, position $x_n$, scale $S_n$, quaternion $Q_n$, and calibration scalar $v_n$.
**Outputs:** Final rendered color $\mathcal{C}$ for each pixel.

**Data Structures:**
*   **Cell Proxy:** Parameterized by $(x_n, S_n, Q_n, v_n, f_n)$.
*   **Neural Gaussian:** Emitted by cell $n$, indexed by $k \in \{1, \dots, K\}$. Attributes: center $\mu_{n,k}$, opacity $\sigma_{n,k}$, color $\mathcal{C}_{n,k}$, scale $s_{n,k}$, quaternion $q_{n,k}$.
*   **MLPs:** Shared scene-wise MLPs $F_\sigma, F_c, F_s, F_q$ decode Gaussian attributes from $f_n$, viewing distance $\delta_n$, and viewing direction $d_n$ (or $\mathbf{r}_n$).

**Numbered Steps:**

1.  **Cell Initialization and Gaussian Emission:**
    *   Initialize cells from SfM points.
    *   For each cell $n$ and emitted Gaussian $k$:
        *   Compute Gaussian center: $\mu_{n,k} = x_n + \mathcal{O}_{n,k}^{\text{pos}} \cdot S_n$, where $\mathcal{O}_{n,k}^{\text{pos}} \in [-1, 1]$ is a learned offset [S1].
        *   Decode opacity: $\{\sigma_{n,1}, \dots, \sigma_{n,K}\} = F_\sigma(f_n, \delta_n, \mathbf{r}_n)$, activated by Tanh [S1].
        *   Decode color: $\{c^{n,1}, \dots, c^{n,K}\} = F_c(f_n, \delta_n, d_n)$ [S1].
        *   Decode scale ratio: $\{\mathcal{O}_{n,1}^{\text{state}}, \dots, \mathcal{O}_{n,K}^{\text{state}}\} = F_s(f_n, \delta_n, d_n)$, activated by sigmoid [S1].
        *   Compute Gaussian scale: $s_{n,k} = \mathcal{O}_{n,k}^{\text{scale}} * S_n$ [S1].
        *   Clamp scale ratio to ensure Gaussian stays inside cell: $\mathcal{O}_{n,k}^{\text{scale}} = \min \left( \mathcal{O}_{n,k}^{\text{scale}}, 1 - \|\mathcal{O}_{n,k}^{\text{pos}}\| \right)$ [S1].
        *   Decode quaternion: $\{\mathbf{q}_{n,1}, \dots, \mathbf{q}_{n,K}\} = F_q(f_n, \delta_n, d_n)$ [S1].
        *   Update cell quaternion as weighted average: $Q_n = \text{norm}\left(\sum_k^K q_{n,k} * \sigma_{n,k}\right)$ [S1].

2.  **Layer I: Cell Rasterization (Coarse Sorting):**
    *   Project cells to screen space.
    *   Assign visible cells to tiles.
    *   Apply radix sort to the cell sequence based on depth [S1]. This establishes a coarse spatial order.

3.  **Layer II: Physical OIT Blending (Local Order-Independent Rendering):**
    *   For each tile, iterate through sorted cells $n=1 \dots N$.
    *   Compute cell-level transmittance $T_n^{\text{cell}}$ from preceding cells:
        $$T_n^{\text{cell}} = \prod_{i=1}^{n-1} \prod_{k=1}^{n-1} (1 - v_i \cdot \alpha_{i,k})$$
        where $v_i$ is the learnable calibration scalar for cell $i$, and $\alpha_{i,k}$ is the opacity of the $k$-th Gaussian in cell $i$ (derived from $\sigma_{i,k}$ and 2D Gaussian kernel) [S1].
    *   **Early Termination:** If $T_n^{\text{cell}} < \epsilon$ (predefined threshold), stop processing further cells for this pixel/tile [S1].
    *   Compute cell weight: $w_n = v_n \cdot T_n^{\text{cell}}$ [S1].
    *   Decode Gaussian attributes for intersected cells using MLPs [S1].
    *   Aggregate Gaussians inside each cell using Weighted-Sum Rendering (WSR). The final color $\mathcal{C}$ is:
        $$\mathcal{C} = \frac{\sum_{n=1}^N w_n \sum_{k=1}^K \alpha_{n,k} \mathcal{C}_{n,k}}{\sum_{n=1}^N w_n \sum_{k=1}^K \alpha_{n,k}}$$
        where $\mathcal{C}_{n,k}$ is the color of the $k$-th Gaussian in cell $n$ [S1].

**Parameters:**
*   $K$: Predefined number of neural Gaussians emitted per anchor/cell [S1].
*   $v_n$: Learnable calibration scalar for cell $n$, parameterized using spherical harmonic coefficients to capture directional variation [S1].
*   $\epsilon$: Predefined threshold for early termination [S1].

**Pitfalls:**
*   Order confusion caused by overlap among cells is addressed by the calibration scalar $v_n$ and the physically grounded transmittance model [S1].
*   Vanilla OIT-based Gaussian Splatting suffers from transparency artifacts and lack of early termination; Duplex-GS handles this by ensuring transmittance decays rapidly for opaque objects [S1].

def duplex_gs_render(cells, camera, epsilon=1e-4):
    H, W = camera['height'], camera['width']
    tiles = [(y, x) for y in range(0, H, 16) for x in range(0, W, 16)]
    tile_cells = {t: [] for t in tiles}
    
    # Layer I: Cell Projection and Assignment
    for cell in cells:
        # Project cell center and compute 2D bounding box
        cell_cam = transform_to_camera(cell['pos'], camera['view_matrix'])
        # Approximate cell extent based on scale S_n and quaternion Q_n
        # [G] Simplified projection for ellipsoidal proxy
        sigma_2d = project_covariance(cell['Sigma'], camera['view_matrix'], cell_cam['z'])
        bbox = compute_2d_bbox(cell_cam['xy'], sigma_2d)
        
        for t in tiles:
            if intersects_bbox(bbox, t, 16):
                tile_cells[t].append(cell)
    
    # Layer I: Coarse Sorting of Cells
    for t in tiles:
        tile_cells[t].sort(key=lambda c: transform_to_camera(c['pos'], camera['view_matrix'])['z'])
    
    image = zeros((H, W, 3))
    
    # Layer II: Physical OIT Blending
    for t in tiles:
        sorted_cells = tile_cells[t]
        for y in range(t[0], min(t[0] + 16, H)):
            for x in range(t[1], min(t[1] + 16, W)):
                pixel_pos = vec2(x, y)
                accumulated_color = zeros(3)
                accumulated_weight = 0.0
                T_cell = 1.0
                
                for cell in sorted_cells:
                    # Early Termination
                    if T_cell < epsilon:
                        break
                    
                    # Decode Gaussian attributes for this cell
                    # [G] MLPs F_sigma, F_c, F_s, F_q are assumed defined elsewhere
                    # Inputs: cell['f_n'], viewing distance, viewing direction
                    gaussians = decode_neural_gaussians(cell, camera)
                    
                    # Compute cell weight w_n = v_n * T_cell
                    # v_n is learned scalar, possibly direction-dependent
                    v_n = cell['v_n']
                    w_n = v_n * T_cell
                    
                    cell_contribution = zeros(3)
                    cell_alpha_sum = 0.0
                    
                    for g in gaussians:
                        # Compute 2D Gaussian value alpha_{n,k}
                        diff = pixel_pos - g['center_2d']
                        inv_sig = inverse_2x2(g['sigma_2d'])
                        g_val = exp(-0.5 * dot(diff, inv_sig @ diff))
                        alpha = g['opacity'] * g_val
                        
                        # Accumulate for WSR
                        cell_contribution += alpha * g['color']
                        cell_alpha_sum += alpha
                    
                    # Update transmittance for next cell
                    # T_{n+1} = T_n * product(1 - v_i * alpha_{i,k})
                    # [G] Simplified: T_cell decays by the total opacity of current cell weighted by v_n
                    # Exact formula: T_n^{cell} = prod_{i=1}^{n-1} prod_{k=1}^{n-1} (1 - v_i * alpha_{i,k})
                    # We update T_cell for the NEXT iteration
                    total_cell_alpha = cell_alpha_sum
                    T_cell *= (1.0 - v_n * total_cell_alpha)
                    
                    # Add to final color
                    accumulated_color += w_n * cell_contribution
                    accumulated_weight += w_n * cell_alpha_sum
                
                if accumulated_weight > 0:
                    image[y, x] = accumulated_color / accumulated_weight
                else:
                    image[y, x] = zeros(3)
                    
    return image

## Subtopics

### AAA-Gaussians
A method that eliminates sorting analytically by pre-integrating the alpha blending equation to compute an equivalent order-independent transparency through a rational polynomial approximation of the visibility term, suppressing popping artifacts without per-pixel depth sorting [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Reduced sorting overhead compared to standard 3DGS because sorting is performed on $N$ cells rather than $M$ Gaussians ($N \ll M$) [S1]. Early termination further accelerates rendering in opaque regions [S1].
*   **Memory Complexity:** Lower memory consumption for sorting buffers due to the smaller number of cell proxies [S1].
*   **Strengths:** Eliminates transparency artifacts and popping artifacts common in vanilla OIT and sort-free methods [S1]. Enables real-time performance on resource-constrained devices [S1].
*   **Limitations:** Requires additional MLPs for decoding Gaussian attributes from cell features [S1]. Calibration scalar $v_n$ adds learnable parameters [S1].
*   **When to use:** When real-time order-independent rendering is required with high visual fidelity, avoiding transparency artifacts [S1].

## Background
Duplex-GS was introduced as a dual-hierarchy framework to address limitations in neural Gaussian frameworks and vanilla OIT-based Gaussian Splatting [S1]. It builds on Scaffold-GS, which uses anchors to emit neural Gaussians [S1]. The method was submitted to IEEE for publication in 2026 [S1].
