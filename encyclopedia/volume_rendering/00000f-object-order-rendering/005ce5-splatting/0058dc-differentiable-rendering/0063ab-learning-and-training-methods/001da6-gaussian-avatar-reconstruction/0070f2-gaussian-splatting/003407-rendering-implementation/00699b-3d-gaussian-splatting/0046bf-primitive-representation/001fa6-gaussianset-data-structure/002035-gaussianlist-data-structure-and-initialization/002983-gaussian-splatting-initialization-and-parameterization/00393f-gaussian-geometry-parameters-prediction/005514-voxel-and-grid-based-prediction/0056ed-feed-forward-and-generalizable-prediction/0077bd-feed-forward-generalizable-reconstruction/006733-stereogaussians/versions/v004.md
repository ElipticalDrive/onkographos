# StereoGaussians

Also called: StereoGaussians: Feed-Forward 3D Gaussian Splatting from Stereo Images

## Overview
StereoGaussians is a feed-forward method that predicts a metric 3D Gaussian Splatting (3DGS) representation from a single calibrated stereo pair, enabling nearby-view extrapolation without per-scene optimization [S1, unofficial]. It sets itself apart from siblings like [AnySplat Pipeline](12847-anysplat-pipeline.md) and [Splatt3R](16423-splatt3r.md) by explicitly leveraging frozen pretrained stereo features to anchor geometry while using a two-layer Gaussian prediction and an expanded image canvas to handle disoccluded and outside-field-of-view content [S1, unofficial]. Unlike [DepthSplat](18278-depthsplat.md), which refines inverse depth through a composer, StereoGaussians fixes the front-layer stereo depth and bounds image-plane offsets to provide a structural prior [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A calibrated rectified stereo pair $(I_L, I_R)$, camera intrinsics $K$ (focal lengths $f_x, f_y$, principal point $c_x, c_y$), and baseline $B$.
*   **Outputs:** A set of $N$ Gaussians $G = \{(x_i, s_i, q_i, \alpha_i, c_i)\}$ in the left-camera frame, where $x_i$ is position, $s_i$ is scale, $q_i$ is rotation, $\alpha_i$ is opacity, and $c_i$ is color [S1, unofficial].

**Data Structures:**
*   **Stereo Features:** Multiscale features $\{F_s\}$, disparity map $d$, and context/recurrent features from the frozen encoder.
*   **Descriptor:** A dense full-resolution descriptor $\Phi \in \mathbb{R}^{C \times H \times W}$ (typically $C=128$) generated by a DPT-style decoder.
*   **Gaussian Attributes:** Predicted as residuals. Each layer outputs 37 channels: 1 for opacity, 2 for image-plane offsets $(\delta_u, \delta_v)$, 3 for scale, 4 for quaternion, and 27 for degree-2 spherical harmonic (SH) coefficients [S1, unofficial].

**Parameters:**
*   **Padding ($P$):** Default 16 pixels per side for canvas expansion [S1, unofficial].
*   **Neighborhood ($N_9$):** 9x9 spatial neighborhood for back-layer depth estimation [S1, unofficial].
*   **Optimizer:** AdamW with learning rate $4 \times 10^{-4}$, weight decay 0.01, $\beta_1=0.9, \beta_2=0.999$ [S1, unofficial].
*   **Scheduler:** OneCycleLR with 2,700 warm-up steps, initial division factor 25, final division factor 100 [S1, unofficial].
*   **Loss:** $L = \text{MSE}(I_T, \hat{I}_T) + 0.05 \text{LPIPS}_{VGG}(I_T, \hat{I}_T)$ [S1, unofficial].

**Steps:**

1.  **Stereo Feature Extraction:** Encode the stereo inputs using a frozen pretrained stereo encoder (e.g., FoundationStereo) to obtain a left-reference disparity map $d$ and aligned multiscale features $\{F_s\}$ [S1, unofficial].
2.  **Descriptor Generation:** At each feature scale $s$, concatenate the encoder features $F_s$ with resized reference RGB ($\downarrow_s I_L$) and stereo depth $z$. Resize RGB bilinearly and depth by nearest-neighbor interpolation. Project to 128 channels via a $1\times1$ convolution, group normalization, and GELU. Fuse coarse-to-fine using residual convolution units to yield the descriptor $\Phi$:
    $$ \Phi = D \{[F_s, \downarrow_s I_L, \downarrow_s z]\}_s \in \mathbb{R}^{C \times H \times W} $$
    where $D$ is the DPT-style decoder and $[ \cdot, \cdot ]$ denotes channel concatenation [S1, unofficial].
3.  **Canvas Extension:** Extend the reference RGB $I_L$, processed depth $z$, and descriptor $\Phi$ by edge-replication padding $P$ on each side to size $(H + 2P) \times (W + 2P)$. Let the extended inputs be $\tilde{I}_L, \tilde{z}, \tilde{\Phi}$. Update canvas intrinsics: focal lengths remain unchanged, principal point shifts to $\tilde{c}_x = c_x + P, \tilde{c}_y = c_y + P$ [S1, unofficial].
4.  **Attribute Prediction:** Pass extended inputs through a convolutional predictor $H$. A shared regressor with two $3\times3$ convolutions and intermediate GELU maps $[\tilde{I}_L, \tilde{z}, \tilde{\Phi}]$ to a 128-channel tensor $h$. Three output branches process $[h, \tilde{I}_L, \tilde{\Phi}]$ using a $3\times3$ convolution, group normalization, GELU, and a final $3\times3$ convolution. The branches output attribute residuals for the front layer ($\theta_{front}$), back layer ($\theta_{back}$), and a scalar back-layer depth offset ($\Delta z$):
    $$ (\theta_{front}, \theta_{back}, \Delta z) = H([\tilde{I}_L, \tilde{z}, \tilde{\Phi}]) $$
    [S1, unofficial].
5.  **Front Layer Geometry:** For each pixel $p=(u,v)$, compute metric depth $z(p)$ from disparity $d(p)$:
    $$ z(p) = \text{clip}\left(\frac{f_x B}{d(p)}, z_{min}, z_{max}\right) $$
    The front layer depth is $\tilde{z}_{front} = \tilde{z}$. Compute image-plane offsets $(\delta_{u,front}, \delta_{v,front}) = \sigma(o_{front}) - 0.5$, bounded to half a canvas pixel. The center is:
    $$ x_{front}(p) = \tilde{z}_{front}(p) \tilde{K}^{-1} [u + \delta_{u,front}, v + \delta_{v,front}, 1]^\top $$
    where $\tilde{K}$ uses the shifted principal point [S1, unofficial].
6.  **Back Layer Geometry:** Compute back layer depth as the local maximum in a 9x9 neighborhood $\mathcal{N}_9(p)$ plus a learned positive offset:
    $$ z_{back}(p) = \max_{q \in \mathcal{N}_9(p)} \tilde{z}(q) + \text{softplus}(\Delta z(p)) $$
    The center $x_{back}(p)$ is computed similarly using $z_{back}$ and offsets from $\theta_{back}$ [S1, unofficial].
7.  **Gaussian Attributes:** Define isotropic base scale $s_{0,\ell} = \kappa z_\ell / (f_x f_y)$. Predict attributes as residuals around a reference-image DC base with degree-2 SH residuals: bounded multiplicative scale updates, additive quaternion updates, and opacity updates in logit space [S1, unofficial].
8.  **Rendering:** Concatenate front and back layers. Render target views using both layers without an edge mask restricting the back layer. Supervision is applied via differentiable Gaussian rendering against target images [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class StereoGaussians:
    def __init__(self, encoder, predictor, padding=16):
        self.encoder = encoder  # Frozen stereo encoder
        self.predictor = predictor  # Trainable predictor H
        self.padding = padding
        self.decoder = DPTDecoder()  # Generates descriptor Phi

    def forward(self, I_L, I_R, K, B, target_view=None):
        # 1. Stereo Feature Extraction
        # Returns disparity d, multiscale features {F_s}
        d, F_s = self.encoder(I_L, I_R)
        
        # 2. Descriptor Generation
        # Resize inputs for each scale s
        # RGB bilinear, depth nearest-neighbor
        desc_inputs = []
        for s in scales:
            I_L_s = F.interpolate(I_L, scale_factor=1/s, mode='bilinear', align_corners=False)
            z_s = F.interpolate(d_to_depth(d, K, B), scale_factor=1/s, mode='nearest')
            desc_inputs.append(torch.cat([F_s[s], I_L_s, z_s], dim=1))
        
        Phi = self.decoder(desc_inputs) # Output: [C, H, W]
        
        # 3. Canvas Extension
        P = self.padding
        I_L_ext = F.pad(I_L, (P, P, P, P), mode='replicate')
        z_ext = F.pad(d_to_depth(d, K, B), (P, P, P, P), mode='replicate')
        Phi_ext = F.pad(Phi, (P, P, P, P), mode='replicate')
        
        # Update intrinsics for extended canvas
        K_ext = K.clone()
        K_ext[:, 2] += P # cx, cy shift
        
        # 4. Attribute Prediction
        # Predictor H takes [I_L_ext, z_ext, Phi_ext]
        theta_front, theta_back, delta_z = self.predictor(I_L_ext, z_ext, Phi_ext)
        
        # 5. Front Layer Geometry
        # theta_front contains: opacity(1), offsets(2), scale(3), quat(4), SH(27)
        offsets_front = theta_front[:, 1:3, :, :] # (2, H+2P, W+2P)
        # Bounded to half canvas pixel
        offsets_front = torch.clamp(offsets_front, -0.5, 0.5)
        
        # Compute centers using extended intrinsics
        # x = z * K^-1 * [u + du, v + dv, 1]^T
        centers_front = compute_centers(z_ext, K_ext, offsets_front)
        
        # 6. Back Layer Geometry
        # Local max in 9x9 neighborhood + softplus(delta_z)
        # Assuming z_ext is already processed depth
        z_back = local_max_pool(z_ext, kernel_size=9) + F.softplus(delta_z)
        
        offsets_back = theta_back[:, 1:3, :, :]
        offsets_back = torch.clamp(offsets_back, -0.5, 0.5)
        centers_back = compute_centers(z_back, K_ext, offsets_back)
        
        # 7. Gaussian Attributes
        # Base scale s0 = kappa * z / (fx * fy)
        # Residuals applied to base
        gaussians_front = build_gaussians(centers_front, theta_front, z_ext)
        gaussians_back = build_gaussians(centers_back, theta_back, z_back)
        
        # 8. Rendering
        all_gaussians = torch.cat([gaussians_front, gaussians_back], dim=0)
        rendered_img = render_gaussians(all_gaussians, target_view.K, target_view.R, target_view.T)
        
        return rendered_img

def d_to_depth(d, K, B):
    fx = K[0, 0]
    return torch.clamp((fx * B) / d, min=z_min, max=z_max)

def compute_centers(z, K_inv, offsets):
    # z: [1, H, W]
    # offsets: [2, H, W]
    # K_inv: [3, 3]
    H, W = z.shape[1], z.shape[2]
    u, v = torch.meshgrid(torch.arange(W), torch.arange(H), indexing='ij')
    u = u.float().to(z.device) + offsets[0]
    v = v.float().to(z.device) + offsets[1]
    
    # Homogeneous coordinates
    pts = torch.stack([u, v, torch.ones_like(u)], dim=-1) # [H, W, 3]
    pts = pts.unsqueeze(0).unsqueeze(0) # [1, 1, H, W, 3]
    
    # Apply inverse intrinsics
    # K_inv is [3,3], pts is [1,1,H,W,3]
    # Reshape for matmul
    pts_flat = pts.view(1, 1, H*W, 3)
    pts_cam = torch.matmul(pts_flat, K_inv.transpose(-2, -1)) # [1, 1, H*W, 3]
    pts_cam = pts_cam.view(1, 1, H, W, 3)
    
    # Scale by depth
    z_expanded = z.unsqueeze(-1) # [1, 1, H, W, 1]
    centers = pts_cam * z_expanded # [1, 1, H, W, 3]
    
    return centers.squeeze(0).squeeze(0) # [H, W, 3]

def build_gaussians(centers, theta, z):
    # theta: [37, H, W]
    # 1: opacity, 2: offsets, 3: scale, 4: quat, 27: SH
    opacity = theta[0]
    scale_res = theta[1:4]
    quat_res = theta[4:8]
    sh_res = theta[8:]
    
    # Base scale
    fx = 1.0 # Placeholder, assume normalized or passed
    fy = 1.0
    kappa = 1.0
    s0 = kappa * z / (fx * fy)
    
    # Apply residuals
    # Multiplicative scale
    s = s0 * (1 + scale_res)
    # Additive quaternion (normalized)
    q = normalize(quat_res)
    # Opacity in logit space
    alpha = sigmoid(opacity)
    
    return {
        'xyz': centers,
        'scales': s,
        'quats': q,
        'opacities': alpha,
        'sh_coeffs': sh_res
    }
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of pixels and Gaussians. The predictor $H$ is a convolutional network, making inference fast and parallelizable on GPUs.
*   **Memory Complexity:** Proportional to the number of Gaussians $N$ and the feature map sizes. The expanded canvas increases memory usage by a factor of $(H+2P)(W+2P)/HW$.
*   **Performance:** On StereoNVS, StereoGaussians achieves 21.261 PSNR, 0.9447 SSIM, and 0.0818 LPIPS. On ReplicaGS, it achieves 30.266 PSNR, 0.9447 SSIM, and 0.0818 LPIPS [S1, unofficial].
*   **Strengths:** Enables nearby-view extrapolation without per-scene optimization; handles disoccluded and outside-FoV content effectively; leverages pretrained stereo features for robust geometry.
*   **Limitations:** Fixed front-layer depth limits stereo-error correction; teacher artifacts can persist; evaluation focuses on nearby views [S1, unofficial].
*   **When to use:** When real-time or near-real-time novel view synthesis from a single stereo pair is required, and per-scene optimization is prohibitive.
*   **When not to use:** When large viewpoint changes are expected, or when high-fidelity geometry correction for stereo errors is critical [S1, unofficial].

## Background
StereoGaussians was introduced in the paper "StereoGaussians: Feed-Forward 3D Gaussian Splatting from Stereo Images" [S1, unofficial]. It builds on the foundation of feed-forward 3DGS methods like Charatan et al. (2024) and Chen et al. (2024), adapting them for stereo inputs. The method uses the SceneSplat-Stereo dataset for training, which pairs stereo inputs with nearby target views from quality-filtered 3DGS teachers [S1, unofficial]. It compares favorably against baselines like DepthSplat and LVSM [S1, unofficial].
