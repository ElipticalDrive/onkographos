# GSEdit

## Overview
GSEdit is a method for editing 3D Gaussian Splatting (3DGS) representations or texture meshes using text or image instructions. It solves the problem of applying high-fidelity, semantically meaningful edits to existing 3D scenes by leveraging 2D diffusion models. Unlike sibling methods that may rely on geometric consistency constraints like depth maps [S1, unofficial] or intrinsic decomposition [S2], GSEdit primarily utilizes a score distillation sampling (SDS) loss driven by Instruct-Pix2Pix to update the input representation directly.

## How it works
**Inputs:** A pre-trained 3D Gaussian Splatting representation or a textured mesh. A text or image instruction defining the desired edit.
**Outputs:** An updated 3D Gaussian Splatting representation or textured mesh reflecting the edit.

**Data Structures:**
The input 3DGS consists of a set of Gaussians $\mathcal{G} = \{g_i\}$. Each Gaussian $g_i$ is defined by:
- Mean position $\mu_i \in \mathbb{R}^3$
- Covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$ (or rotation $R_i$ and scale $s_i$)
- Opacity $\alpha_i \in [0, 1]$
- Spherical harmonics coefficients for color $c_i$

**Steps:**
1. **Initialization:** Load the input 3DGS or textured mesh.
2. **Instruction Processing:** Use Instruct-Pix2Pix [S1, unofficial] to generate edited 2D images based on the input instruction and the rendered views of the current 3DGS. Instruct-Pix2Pix takes an input image and a text instruction to produce an edited image.
3. **Loss Calculation:** Compute the Score Distillation Sampling (SDS) loss [S1, unofficial]. The SDS loss encourages the rendered images from the 3DGS to match the distribution of the edited images generated by Instruct-Pix2Pix.
   $$ \nabla_{x} \mathcal{L}_{SDS} = \mathbb{E}_{t, \epsilon} \left[ w(t) (\epsilon_{\theta}(x_t, t, c) - \epsilon) \right] $$
   Where $x_t$ is the noisy version of the rendered image, $t$ is the timestep, $\epsilon$ is the predicted noise, and $c$ is the conditioning (instruction).
4. **Optimization:** Update the parameters of the 3DGS (positions, covariances, opacities, colors) or the mesh texture using gradient descent to minimize the SDS loss.
5. **Iteration:** Repeat steps 2-4 for a fixed number of iterations or until convergence.

**Parameters:**
- Number of optimization iterations: Not given in the sources.
- Learning rate: Not given in the sources.
- Instruct-Pix2Pix model: Used as the source of editing guidance [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Inconsistency:** GSEdit may suffer from multi-view inconsistency issues, as it relies on 2D diffusion without explicit 3D consistency constraints [S1, unofficial].
- **Precision:** The method updates the input representation directly, which may lead to artifacts if the edit is complex or conflicts with the underlying geometry.

## Subtopics

### Albedo Editing via Proxy Plane Spawning
This variant focuses on editing the albedo (color) of the 3DGS. It initializes new Gaussians on a textured proxy plane and places them in 3D space using proxy depth. Additional albedo Gaussians are spawned by randomly sampling 20% of the pixels covered by the edit in the edited view. The augmented set of albedo Gaussians is then re-optimized to match the edited albedo images rendered from multiple viewpoints [S2]. This approach is chosen when the goal is to modify only the appearance (albedo) without altering the geometry. The spawn rate is 20% of pixels covered by the edit [S2].

## Operating characteristics
**Time and Memory Complexity:**
- Time complexity: Depends on the number of optimization iterations and the cost of running Instruct-Pix2Pix and rendering the 3DGS. Not given in the sources.
- Memory complexity: Proportional to the number of Gaussians in the 3DGS representation. Not given in the sources.

**Measured Performance:**
- Not given in the sources.

**Scaling:**
- Not given in the sources.

**Strengths and Limitations:**
- **Strengths:** Leverages powerful 2D diffusion models for high-quality edits. Simple to implement if Instruct-Pix2Pix is available.
- **Limitations:** May produce multi-view inconsistent results. Relies on the quality of the 2D diffusion model.

**When to use it and when not:**
- Use when you have a pre-trained 3DGS or texture mesh and want to apply semantic edits using text instructions.
- Do not use when multi-view consistency is critical and other methods like GaussCtrl [S1, unofficial] are available.

## Background
GSEdit was introduced in [S1, unofficial] as a method for editing 3D Gaussian Splatting representations. It builds on previous work in NeRF editing, such as InstructNeRF2NeRF [S1, unofficial], and adapts the approach to 3DGS. The method uses Instruct-Pix2Pix and SDS loss to update the input mesh or 3DGS. It is part of the broader field of 3D editing and generation using diffusion models.
