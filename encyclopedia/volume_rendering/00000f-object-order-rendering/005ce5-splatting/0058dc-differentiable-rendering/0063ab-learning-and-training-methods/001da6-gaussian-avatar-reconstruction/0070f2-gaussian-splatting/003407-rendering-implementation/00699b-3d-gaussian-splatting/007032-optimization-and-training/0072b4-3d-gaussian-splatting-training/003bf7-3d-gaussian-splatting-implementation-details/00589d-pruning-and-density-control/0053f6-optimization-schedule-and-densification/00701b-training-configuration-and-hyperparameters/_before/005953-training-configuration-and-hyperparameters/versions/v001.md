# Training Configuration and Hyperparameters

Also called: Decoder Training Setup, Training Configuration for Gaussian Splatting Decoder

## Overview
This method defines the standardized hyperparameter configurations and optimization schedules required to train 3D Gaussian Splatting decoders for downstream tasks, such as classification, part segmentation, and integration with generative adversarial networks (GANs). It addresses the problem of transferring pre-trained Gaussian representations to specific domains by specifying primitive counts, grouping strategies, and optimizer settings. It differs from general radiance-field optimization by focusing on fixed-epoch fine-tuning protocols for discrete Gaussian inputs rather than continuous densification schedules.

## How it works
The method specifies two primary training regimes: standard downstream protocols for 3D shape analysis and decoder training for 3D-aware GANs.

### Inputs and Outputs
*   **Inputs:** Pre-trained Gaussian encoders (e.g., Gaussian-MAE, Gaussian-JEPA) or target GAN latent spaces; dataset-specific camera sampling distributions.
*   **Outputs:** Trained Gaussian primitives optimized for specific task losses (classification, segmentation, or GAN consistency).

### Data Structures
The Gaussian inputs are organized into groups to facilitate processing.
*   **Grouping Structure:** A list of groups, where each group contains a fixed number of Gaussians.
*   **Attributes:** Each Gaussian retains its standard 14 attributes (position, scale, rotation, opacity, spherical harmonics coefficients) unless specified otherwise [S1, unofficial].

### Parameters and Typical Values
The configuration varies by dataset and task:

1.  **ModelNet10/40 (Classification/Segmentation):**
    *   **Primitive Count:** 1,024 Gaussians [S1, unofficial].
    *   **Grouping:** 64 groups of 32 Gaussians each [S1, unofficial].
    *   **Optimizer:** AdamW [S1, unofficial].
    *   **Learning Rate:** $1 \times 10^{-3}$ [S1, unofficial].
    *   **Weight Decay:** 0.05 [S1, unofficial].
    *   **Batch Size:** 256 [S1, unofficial].
    *   **Epochs:** 300 [S1, unofficial].
    *   **Warm-up:** 5 epochs [S1, unofficial].
    *   **Probing:** Linear and three-layer MLP probing freeze the encoder and update only the classifier [S1, unofficial].

2.  **ShapeNet-Part (Part Segmentation):**
    *   **Primitive Count:** 2,048 Gaussians [S1, unofficial].
    *   **Grouping:** 128 groups of 32 Gaussians each [S1, unofficial].
    *   **Optimizer:** AdamW [S1, unofficial].
    *   **Learning Rate:** $1 \times 10^{-4}$ [S1, unofficial].
    *   **Batch Size:** 16 [S1, unofficial].
    *   **Epochs:** 300 [S1, unofficial].

3.  **GAN Decoder Training (EG3D, PanoHead):**
    *   **Iterations:** 500,000 [S2].
    *   **Optimizer:** Adam [S2].
    *   **Learning Rate:** 0.0009 [S2].
    *   **Loss Weights:** $(\lambda_1, \lambda_2, \lambda_3, \lambda_4, \lambda_5) = (0.2, 0.5, 1.0, 1.0, 0.2)$ [S2].
    *   **Camera Sampling:**
        *   **PanoHead:** Random cameras sampled all around the head (360°) [S2].
        *   **EG3D:** Cameras sampled mainly from frontal views with small vertical and horizontal rotations [S2].

### Pseudocode
The following pseudocode outlines the training loop for the GAN decoder configuration, which serves as the general template for the iterative optimization.

```python
def train_gaussian_decoder(gan_model, dataset, iterations=500000, lr=0.0009):
    """
    Trains a Gaussian Splatting decoder integrated with a pre-trained GAN.
    
    Args:
        gan_model: Pre-trained GAN (e.g., EG3D or PanoHead).
        dataset: Dataset providing ground truth images and camera poses.
        iterations: Total number of training iterations.
        lr: Learning rate for the Adam optimizer.
    """
    # Initialize Gaussian primitives based on GAN latent code or initialization protocol
    gaussians = initialize_gaussians(gan_model)
    
    # Configure Adam optimizer
    optimizer = Adam(params=gaussians.parameters(), lr=lr)
    
    # Define loss weights
    loss_weights = {
        'lambda1': 0.2,
        'lambda2': 0.5,
        'lambda3': 1.0,
        'lambda4': 1.0,
        'lambda5': 0.2
    }
    
    for i in range(iterations):
        # Sample batch from dataset
        batch = dataset.sample_batch()
        
        # Sample camera poses based on target domain
        if gan_model.name == "PanoHead":
            # Sample random cameras all around the head (360 degrees)
            cameras = sample_cameras_360(batch.num_views)
        elif gan_model.name == "EG3D":
            # Sample mainly frontal views with small rotations
            cameras = sample_cameras_frontal(batch.num_views)
        
        # Render images using Gaussian Splatting
        rendered_images = render_gaussians(gaussians, cameras)
        
        # Compute loss against GAN discriminator and ground truth
        loss = compute_gan_loss(rendered_images, gan_model, cameras, loss_weights)
        
        # Backpropagate and update
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    return gaussians
```

### Edge Cases and Pitfalls
*   **ModelNet Variance:** Fine-tuning on ModelNet exhibits appreciable run-to-run variation. Results should be interpreted with caution, and small cross-environment differences should not be treated as method gains [S1, unofficial].
*   **Camera Distribution Mismatch:** Using frontal-only camera sampling for tasks requiring full 360° consistency (like PanoHead) will lead to poor reconstruction in non-frontal views [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of iterations (500k for GANs, 300 epochs for classification) and the number of Gaussians.
*   **Memory Complexity:** Proportional to the number of Gaussians (1K–2K) and the batch size.
*   **Strengths:** Standardized protocols allow for reproducible comparison across different Gaussian-based methods (e.g., Gaussian-MAE vs. Gaussian-JEPA) [S1, unofficial].
*   **Limitations:** Fixed primitive counts (1K/2K) may limit the fidelity of complex scenes compared to densification-based methods [S1, unofficial].

## Background
This configuration originates from the evaluation protocols established for Gaussian-JEPA and Gaussian-MAE, which standardized the use of 1K–4K Gaussians for downstream tasks [S1, unofficial]. It was further adapted for integrating Gaussian Splatting decoders into 3D-aware GANs like EG3D and PanoHead to leverage explicit 3D space rendering [S2].
