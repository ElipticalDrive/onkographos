# Active View Selection and Residual Learning for 3DGS

Also called: SA-ResGS (Self-augmented Residual 3D Gaussian Splatting), Self-augmented Residual 3D Gaussian Splatting

## Overview
SA-ResGS is a training framework for 3D Gaussian Splatting that combines active view selection with residual learning to improve reconstruction quality under sparse view conditions. It addresses the instability of standard active view selection methods by introducing a self-augmented pre-filtering mechanism (SA-HashGS) and a residual supervision signal. Unlike standard training loops that use fixed or randomly selected views, SA-ResGS dynamically selects a subset of training views to maximize reconstruction fidelity while limiting computational cost. It sets itself apart from sibling methods like [Uncertainty-Guided Residual Learning for 3DGS](20901-uncertainty-guided-residual-learning-for-3dgs.md) by explicitly coupling the view selection process with a residual learning objective that stabilizes training in ambiguous regions.

## How it works
SA-ResGS operates within the standard 3D Gaussian Splatting optimization loop but modifies the view sampling strategy and introduces a residual loss component. The method relies on two key components: SA-HashGS for stable view candidate selection and ResGS for residual supervision.

**Inputs and Outputs:**
*   **Input:** A set of available training views (images and camera poses) from a COLMAP SfM initialization.
*   **Output:** A set of optimized 3D Gaussians $\mathcal{G}$ and a selected sequence of training views.

**Data Structures:**
*   **Gaussian Set $\mathcal{G}$:** Standard 3DGS parameters (position, covariance, opacity, SH coefficients).
*   **View Pool:** The set of all available training views.
*   **Selected Views:** A subset of views actively used for training at each stage.
*   **Hash Grid (for SA-HashGS):** Used to compute Fisher uncertainty features.

**Algorithm Steps:**

1.  **Initialization:**
    *   Initialize all Gaussians with a random seed and COLMAP SfM initialization [S1].
    *   Set the initial view configuration to 4 uniformly distributed views from the available pool [S1].
    *   Initialize the SA-HashGS module to compute view candidates based on Fisher uncertainty.

2.  **Active View Selection (SA-HashGS):**
    *   Compute Fisher uncertainty for all unselected views in the pool.
    *   Restrict the candidate set for view selection using the SA-HashGS pre-filtering mechanism. This stabilizes selection by focusing on views that provide high information gain relative to the current Gaussian state [S1].
    *   Select the next best view from the restricted candidate set.

3.  **View Addition Schedule:**
    *   Train the current set of selected views for 100 epochs.
    *   Add 1 new view from the selected candidate set to the training pool.
    *   Repeat until the total number of training views reaches 20 [S1].

4.  **Residual Learning (ResGS):**
    *   During rendering, compute the standard photometric loss $\mathcal{L}_{img}$ between the rendered image $\hat{I}$ and the ground truth $I_{gt}$ [S1].
    *   Compute a residual loss $\mathcal{L}_{res}$ that supervises the difference between the current prediction and a reference or previous state. This helps stabilize training in sparse or ambiguous regions where standard photometric loss may be insufficient [S1].
    *   The total loss is a combination of the photometric and residual losses:
        $$ \mathcal{L}_{total} = \mathcal{L}_{img} + \lambda_{res} \mathcal{L}_{res} $$
        where $\lambda_{res}$ is a weighting factor for the residual loss. The specific value is not given in the sources.

5.  **Optimization:**
    *   Compute gradients $\nabla \mathcal{L}_{total}$ with respect to all Gaussian parameters.
    *   Update parameters using the Adam optimizer with $\beta_1 = 0.9$ and $\beta_2 = 0.99$ [S1].
    *   Apply densification and pruning as per the standard 3DGS protocol [S1].

6.  **Iteration:**
    *   Repeat steps 2-5 for 20,000 iterations total [S1].
    *   Ensure consistency by using the same random seed and COLMAP initialization across all experiments [S1].

**Pseudocode:**

```python
def train_sa_resgs(available_views, total_iterations=20000, initial_views=4, max_views=20, add_view_every=100):
    # Initialize Gaussians with COLMAP SfM and random seed
    gaussians = initialize_gaussians(available_views)
    
    # Select initial 4 uniformly distributed views
    selected_views = select_uniform_views(available_views, initial_views)
    
    # Initialize SA-HashGS for view selection
    sa_hashgs = SA_HashGS(gaussians)
    
    for iteration in range(1, total_iterations + 1):
        # Render current view set
        rendered_images = []
        for view in selected_views:
            rendered_images.append(render_gaussians(gaussians, view))
        
        # Compute losses
        total_loss = 0
        for rendered, gt in zip(rendered_images, get_ground_truth(selected_views)):
            # Standard photometric loss
            l_img = compute_photometric_loss(rendered, gt)
            
            # Residual loss
            l_res = compute_residual_loss(rendered, gt, gaussians)
            
            total_loss += l_img + lambda_res * l_res
        
        # Backpropagation and update
        gradients = compute_gradients(total_loss, gaussians)
        update_gaussians(gaussians, gradients)
        
        # View selection schedule
        if iteration % add_view_every == 0 and len(selected_views) < max_views:
            # Use SA-HashGS to select next best view
            next_view = sa_hashgs.select_next_view(gaussians, available_views, selected_views)
            selected_views.append(next_view)
            
    return gaussians
```

**Edge Cases and Pitfalls:**
*   **Sparse Views:** Standard active view selection may fail in sparse view settings due to high uncertainty. SA-HashGS mitigates this by restricting the candidate set [S1].
*   **Ambiguous Regions:** Residual learning is crucial for stabilizing training in regions with ambiguous geometry or texture [S1].
*   **Consistency:** Experiments must be repeated with the same random seed and COLMAP initialization to ensure fair comparison [S1].

## Subtopics

### [Active View Selection for 3D Gaussian Splatting](21848-active-view-selection-for-3d-gaussian-splatting.md)
Active View Selection (AVS) for 3D Gaussian Splatting (3DGS) identifies a subset of training views that maximizes final reconstruction quality while limiting the total number of views used. PRIMU-AVS distinguishes itself from the full PRIMU method by omitting the gradient boosting regressor, thereby avoiding the need for an additional hold-out view for training. It relies on a single direction-dependent coverage feature map with max aggregation and dropped opacity to guide view selection.

## Operating characteristics
*   **Time Complexity:** The method adds overhead for view selection (SA-HashGS) and residual loss computation. However, by limiting the number of training views to 20, it reduces the per-iteration rendering cost compared to using all available views.
*   **Memory Complexity:** Standard 3DGS memory usage plus overhead for the SA-HashGS module and residual buffers.
*   **Performance:** SA-ResGS shows improved reconstruction quality (PSNR, SSIM) compared to baselines like FisherRF and ACP, especially in sparse view settings [S1]. The synergy between SA-HashGS and ResGS leads to better results than using either component alone [S1].
*   **Strengths:** Stabilizes view selection, improves reconstruction in sparse/ambiguous regions, reduces computational cost by limiting views.
*   **Limitations:** Requires careful tuning of the residual loss weight. Performance depends on the quality of the SA-HashGS uncertainty estimation.
*   **When to Use:** When training data is limited (sparse views) and reconstruction quality is critical.
*   **When Not to Use:** When computational resources are extremely limited and view selection overhead is prohibitive, or when a large number of training views are available and standard training is sufficient.

## Background
SA-ResGS was introduced in the paper "SA-ResGS: Self-augmented Residual 3D Gaussian Splatting for Next Best View Selection" [S1]. It builds upon the 3D Gaussian Splatting framework [S1] and addresses limitations in active view selection methods. The method combines ideas from residual learning and self-augmented pre-filtering to improve robustness.
