# InfiniSplat v2

Also called: InfiniSplat

## Overview
InfiniSplat v2 is a feed-forward Gaussian reconstruction method for arbitrary input views that decouples geometry and attribute prediction, uses ground-truth (GT) camera poses for alignment during training, and employs large-angle target view supervision to improve rendering quality under large viewpoint changes [S1, unofficial]. It differs from its parent [Feed-forward Generalizable Reconstruction](23725-feed-forward-generalizable-reconstruction.md) and siblings like [DA3-GS](link) by freezing the geometry branch to prevent geometric degradation caused by joint optimization, and by using GT poses to avoid pose errors that misguide the network under large-angle supervision [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** $N$ input RGB images $I_C = \{I_i\}_{i \in C}$ and optional pose conditions $Q_C$ (camera intrinsics and poses). In the pose-free setting, $Q_C = \emptyset$ [S1, unofficial].
- **Outputs:** A Gaussian scene $G = \{(\mu_m, \xi_m)\}_{m=1}^M$, where $\mu_m \in \mathbb{R}^3$ is the center and $\xi_m = (\alpha_m, s_m, q_m, c_m)$ contains opacity, three-axis scale, rotation, and zeroth-order spherical-harmonic (SH) color [S1, unofficial].

**Data Structures:**
- **Gaussian Scene:** A list of $M$ Gaussians. Each Gaussian $m$ has center $\mu_m$ and attributes $\xi_m$.
- **KNN Graph:** A global graph used for the refiner, reused across steps.
- **Hidden State:** A 16-dimensional vector per Gaussian, updated by the refiner.

**Parameters:**
- Voxel merging side length: $0.004$ in the scale-normalized reconstruction frame [S1, unofficial].
- Opacity pruning threshold $\tau_\alpha$: $0.01$ [S1, unofficial].
- `gsplat` `eps2d`: $10^{-2}$ [S1, unofficial].
- Mask thresholds: $\tau_{abs} = 0.03$, $\tau_{rel} = 0.01$ [S1, unofficial].
- Stage I learning rates: $10^{-6}$ for last ten attribute-backbone Transformer blocks, $2 \times 10^{-4}$ for Gaussian head [S1, unofficial].
- Stage I training steps: $25,000$ steps, $2,000$ steps linear warmup, cosine decay to $0.1$ times peaks [S1, unofficial].
- Stage II learning rate: $2 \times 10^{-4}$, cosine decay to $0.1$ times initial value, $5,000$ steps [S1, unofficial].
- AdamW parameters: $\beta = (0.9, 0.95)$, global batch size $16$, global L2 gradient clipping at $1.0$ [S1, unofficial].

**Steps:**

1.  **Dual-Branch Prediction:**
    Initialize two branches from the same pretrained DA3 weights [S1, unofficial].
    -   **Frozen Geometry Branch:** $\Phi_{geo}$ predicts depths $\hat{C}$ and cameras $\hat{\Pi}_C$ from $I_C$ and $Q_C$. This branch is frozen [S1, unofficial].
    -   **Trainable Attribute Branch:** $\Phi_{attr}$ produces multi-layer patch features $F_C$. Only the last $K$ Transformer blocks of $\Phi_{attr}$ are fine-tuned [S1, unofficial].
    -   A DPT decoder maps $F_C$ to per-pixel attributes $\xi$ [S1, unofficial].

2.  **Scale Alignment and Point Construction (Stage I):**
    -   Predicted and GT poses are expressed relative to their respective reference cameras (first input view in sorted order) [S1, unofficial].
    -   Predicted depths and translations are normalized by $s_{norm} > 0$ [S1, unofficial].
    -   Fit an Umeyama similarity transform from the GT trajectory to the normalized predicted trajectory using only input-camera center correspondences. Retain its scale $s_C$ [S1, unofficial].
    -   Apply scale alignment to translations: $t^\star_v = s_C t^\star_v$, while rotations remain unchanged: $R^\star_v = R^\star_v$ [S1, unofficial].
    -   Construct Gaussian centers $\mu_m$ from normalized predicted $z$-depth, GT intrinsics, and scale-aligned GT poses [S1, unofficial].
    -   Merge Gaussians using voxel merging with side length $0.004$ [S1, unofficial].
    -   Prune Gaussians with opacity $\alpha_m < \tau_\alpha = 0.01$ [S1, unofficial].
    -   Let the initial scene be $G_0$ [S1, unofficial].

3.  **Stage I Rendering and Loss:**
    -   Render $G_0$ into input and target views $v \in V = C \cup T$: $\hat{I}_{bv} = R(G_0; \Pi^\star_v)$ [S1, unofficial].
    -   Construct visibility masks $M_v$. A target pixel is retained if:
        -   GT depth $> 10^{-6}$ and passes validity mask.
        -   At least one input view places it in front of the camera and within bounds.
        -   $|z_{proj} - d_{src}| \leq \max(\tau_{abs}, \tau_{rel} d_{src})$, where $z_{proj}$ is point depth in input camera, $d_{src}$ is sampled depth [S1, unofficial].
    -   Compute LPIPS spatial distance map $d_v = \text{LPIPS}_{spatial}(M_v \odot \hat{I}_v, M_v \odot I_v)$, with invalid regions zeroed before normalization [S1, unofficial].
    -   Compute Stage I loss $\mathcal{L}_I$ (equal weights for L1 and LPIPS over valid pixels) [S1, unofficial].
    -   Optimize Stage I parameters for $25,000$ steps [S1, unofficial].

4.  **Stage II Refinement Architecture:**
    -   Project DPT features to 8 channels via learnable $1 \times 1$ conv, merge using Gaussian voxel groups/weights, and reuse [S1, unofficial].
    -   Initialize 16-dim hidden state via linear projection [S1, unofficial].
    -   Concatenate: image features, current attributes, gradient feedback, neighbor distances, and hidden states. Project to 64 dims [S1, unofficial].
    -   Process by four KNN Transformer blocks. Each block: single-head attention over 8 neighbors, LayerNorm, MLP, residual connections [S1, unofficial].
    -   Concatenate output with original input, MLP predicts attribute and hidden-state increments [S1, unofficial].

5.  **Stage II Optimization Loop:**
    -   Sample $K_r$ uniformly from $\{1, 2, 3\}$ updates during training; use 3 updates at inference [S1, unofficial].
    -   For each step $k$:
        -   Render current scene into input views for feedback loss $\ell_{fb} = 0.8 L_1 + 0.2 L_{DSSIM}$, where $L_{DSSIM} = (1 - \text{SSIM})/2$ over valid regions [S1, unofficial].
        -   Compute gradients w.r.t Gaussian attributes, normalize, and detach [S1, unofficial].
        -   Update attributes using the refiner's predicted increments:
            -   Scales: $s_{new} = s_{old} \exp(\Delta \log s)$ without residual clipping [S1, unofficial].
            -   Opacity-logit, local rotation-vector, RGB-logit: $a \tanh(\text{raw})$ with $a = 0.1, 0.25, 1.0$ respectively [S1, unofficial].
            -   Hidden-state increments: $0.1 \tanh(\text{raw})$ [S1, unofficial].
            -   Logit inputs clamped to $[10^{-6}, 1-10^{-6}]$ [S1, unofficial].
        -   Compute outer loss for supervised views: $\ell_{out} = 0.8 L_1 + 0.2 L_{DSSIM} + 0.5 L_{LPIPS}$ [S1, unofficial].
        -   Compute multi-step objective: $\mathcal{L}_{II} = \sum_{k=1}^{K_r} 0.9^{K_r-k} \mathcal{L}_k^{render} + 0.1 \mathcal{L}_{opacity}$ [S1, unofficial].
        -   Opacity regularization: $\mathcal{L}_{opacity} = \frac{1}{M} \sum_{m=1}^M [\text{logit}_\epsilon(\alpha_m^{K_r}) - \text{logit}_\epsilon(\alpha_m^0)]^2$, where $\epsilon=10^{-6}$ [S1, unofficial].
        -   Use first-order surrogate loss for rendering gradients: $r_k = \text{sg}(\nabla_z \mathcal{L}_{render}(z_k))$ where $z_k = \text{sg}(x_k)$ [S1, unofficial].
    -   Optimize Stage II parameters for $5,000$ steps [S1, unofficial].

6.  **Chunked Execution:**
    -   Reuse global KNN graph [S1, unofficial].
    -   Stable sort along longest voxel-coordinate axis.
    -   Expand core sets of at most $200,000$ points with four-hop neighborhoods [S1, unofficial].
    -   Chunks exceeding $300,000$ points are recursively bisected by point count along core sets' longest axes, with neighborhoods recomputed [S1, unofficial].
    -   Retain only core-point outputs; use gradient checkpointing during training [S1, unofficial].

## Operating characteristics
- **Time and Memory Complexity:** The method uses chunked execution with a global KNN graph. Core sets are limited to 200,000 points, and chunks exceeding 300,000 points are bisected. This limits memory usage and allows for gradient checkpointing [S1, unofficial].
- **Measured Performance:** On six datasets, InfiniSplat v2 achieves state-of-the-art mean LPIPS and DISTS in both pose-conditioned and pose-free settings. In the pose-conditioned setting, mean LPIPS and DISTS decrease by 25.8% and 32.9%, respectively, compared to the strongest evaluated baselines [S1, unofficial].
- **Scaling:** The method is feed-forward, allowing for fast inference. Training requires 25,000 steps for Stage I (~48 hours) and 5,000 steps for Stage II (~13 hours) on 16 H20 GPUs [S1, unofficial].
- **Strengths:** Decoupling geometry and attribute prediction prevents geometric degradation. Using GT poses for alignment avoids pose errors under large-angle supervision. Large-angle target view supervision improves rendering quality under large viewpoint changes. Opacity learning suppresses geometrically inconsistent points (outliers) [S1, unofficial].
- **Limitations:** Jointly optimizing geometry and Gaussian attributes leads to geometric degradation and flying-point artifacts, which this method mitigates by freezing the geometry branch [S1, unofficial]. Using predicted camera poses during training introduces pose errors that misguide the network under large-angle supervision [S1, unofficial].

## Background
InfiniSplat v2 is a feed-forward Gaussian reconstruction method for arbitrary input views. It builds on DA3-GS, which uses shared multi-view features for depth, camera, and per-pixel Gaussian prediction [S1, unofficial]. InfiniSplat v2 improves upon this by freezing the geometry branch, using GT camera poses for alignment during training, and adopting large-angle target view supervision [S1, unofficial]. It is evaluated on six datasets: DL3DV, ETH3D, NRGBD, Mip-NeRF 360, RE10K, and DTU [S1, unofficial].
