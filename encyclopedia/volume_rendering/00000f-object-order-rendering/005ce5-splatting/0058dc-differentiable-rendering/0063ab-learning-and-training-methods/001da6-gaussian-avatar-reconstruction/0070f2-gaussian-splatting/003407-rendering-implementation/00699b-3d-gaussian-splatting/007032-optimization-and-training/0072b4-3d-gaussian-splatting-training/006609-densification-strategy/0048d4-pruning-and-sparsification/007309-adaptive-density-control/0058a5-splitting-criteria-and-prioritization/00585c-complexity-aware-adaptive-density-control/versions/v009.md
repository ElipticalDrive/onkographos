# Complexity-Aware Adaptive Density Control

Also called: Complexity-Aware Density Control, Complexity-Aware Level of Details, Complexity-Guided Relocation

## Overview
Complexity-Aware Adaptive Density Control is a training strategy for 3D Gaussian Splatting that replaces opacity-only heuristics with a multi-signal importance score combining opacity, scale, and local image complexity [S1, unofficial]. It solves the problem where standard methods concentrate primitives in already-resolved high-opacity regions while neglecting unresolved areas, and where low-complexity regions are degraded disproportionately under limited budgets [S1, unofficial]. It sets itself apart from siblings like [Multi-View Density Control Criterion](5663-multi-view-density-control-criterion.md) by explicitly modeling spatial complexity as a surrogate for reconstruction error to guide both relocation probabilities and budgeted pruning [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Set of 3D Gaussians $G = \{g_j\}$, each with mean $\mu_j$, covariance (scale $s(g_j)$), and opacity $\alpha_j$; a set of training views $\Pi_i$; current training step parameters.
*   **Outputs:** Updated complexity field $C_j$ for each Gaussian; updated set of Gaussians for the next training step based on relocation and pruning decisions.

**Data Structures:**
*   **Complexity Field:** A scalar value $C_j$ stored per Gaussian. Initialized to 0.
*   **Normalized Complexity:** $\tilde{C}_j \in [0, 1]$, derived from min-max normalization of $C_j$.

**Numbered Steps:**

1.  **Complexity Map Computation:** For each training view $\Pi_i$, compute a 2D complexity map $C_i^{2D}(u)$ over the image plane. The source specifies this is computed using "delentropy" [S1, unofficial].
2.  **Complexity Update:** After rendering a view, project the mean $\mu_j$ of each contributing Gaussian into the image plane to obtain pixel coordinate $u = \pi_i(\mu_j)$. Update the complexity of each Gaussian using an exponential moving average [S1, unofficial]:
    $$ C_j \leftarrow (1 - \eta) C_j + \eta C_i^{2D}(\pi_i(\mu_j)) $$
    where $\eta \in (0, 1]$ is the learning rate. Only particles whose centers project within the current view's frustum are updated. Over time, $C_j$ converges to a multi-view average complexity [S1, unofficial].
3.  **Relocation Sampling:** When selecting a Gaussian $g_j$ to act as a source for splitting or cloning (relocation destination), sample with probability [S1, unofficial]:
    $$ p(g_j) = \alpha_j \cdot \exp(\tilde{C}_j) $$
    where $\tilde{C}_j$ is the min-max normalized complexity. To prevent collapse onto fixed complex regions, apply **complexity dropout**: with probability $\delta = 0.2$, set $\tilde{C}_j = 0$ for that candidate, scoring it by opacity alone [S1, unofficial].
4.  **Importance Scoring for Pruning/LoD:** To determine which Gaussians survive under a limited budget (Level of Details, $\tau < 1$), compute the importance score $S(g_j)$ [S1, unofficial]:
    $$ S(g_j) = \alpha_j + \lambda \cdot \frac{s(g_j)}{\exp(\tilde{C}_j(\mu_j))} $$
    where:
    *   $\alpha_j$ is the opacity.
    *   $s(g_j)$ is the max-normalized scale of the Gaussian.
    *   $\tilde{C}_j(\mu_j)$ is the normalized complexity at the Gaussian's mean.
    *   $\lambda = 2$ is a fixed scalar weight [S1, unofficial].
    *   In high-complexity regions, $\exp(\tilde{C}_j)$ attenuates the scale term, prioritizing opacity. In low-complexity regions, $\exp(\tilde{C}_j) \to 1$, restoring weight to large primitives that efficiently cover simple areas [S1, unofficial].
5.  **Variance Loss Minimization:** To ensure uniform degradation across different Levels of Details (LoD), minimize the spatial variance of the reconstruction error residual between full-capacity and budgeted renders [S1, unofficial]:
    $$ L_{var} = \text{Var}_{u \in \Omega} \Delta_i(u) $$
    where $\Delta_i = E(I_i^{full}) - E(I_i^{\tau})$ is the residual between the full-capacity error $E(I_i^{full})$ and the budgeted error $E(I_i^{\tau})$ at step $i$.
6.  **Total Training Objective:** The total loss combines the standard photometric losses with the variance loss [S1, unofficial]:
    $$ \text{Total Loss} = \text{Average}(\mathcal{L}_{L1} + \mathcal{L}_{D-SSIM}) + \lambda_{var} L_{var} $$
    This is computed on both full ($\tau=1$) and budgeted ($\tau<1$) renders [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def update_complexity(gaussians, view, complexity_map, eta):
    """
    Update complexity field for Gaussians contributing to a view.
    :param gaussians: List of Gaussian objects with attributes .mean, .complexity
    :param view: Camera object with method .project(mean) -> (u, v)
    :param complexity_map: 2D array of complexity values for the view
    :param eta: Learning rate for EMA
    """
    for g in gaussians:
        # Project mean to image plane
        u, v = view.project(g.mean)
        
        # Check if projection is within frustum/image bounds
        if view.is_in_frustum(u, v):
            # Get complexity at projected location
            # Note: Implementation detail for 'delentropy' complexity map access
            c_2d = complexity_map[v, u] 
            # Exponential Moving Average update
            g.complexity = (1 - eta) * g.complexity + eta * c_2d

def normalize_complexity(gaussians):
    """
    Min-max normalize complexity values across all Gaussians.
    """
    complexities = [g.complexity for g in gaussians]
    min_c = min(complexities)
    max_c = max(complexities)
    
    # Handle edge case where all complexities are identical
    if max_c == min_c:
        for g in gaussians:
            g.normalized_complexity = 0.0
    else:
        for g in gaussians:
            g.normalized_complexity = (g.complexity - min_c) / (max_c - min_c)

def compute_relocation_probability(gaussian, dropout_prob=0.2):
    """
    Compute probability for selecting a Gaussian as a relocation source.
    """
    alpha = gaussian.opacity
    c_norm = gaussian.normalized_complexity
    
    # Apply complexity dropout
    if np.random.random() < dropout_prob:
        c_norm = 0.0
        
    # Probability formula
    prob = alpha * np.exp(c_norm)
    return prob

def compute_importance_score(gaussian, lambda_weight=2.0):
    """
    Compute importance score for pruning/LoD selection.
    """
    alpha = gaussian.opacity
    scale = gaussian.max_normalized_scale
    c_norm = gaussian.normalized_complexity
    
    # Score formula
    score = alpha + lambda_weight * (scale / np.exp(c_norm))
    return score

def compute_variance_loss(full_render, budgeted_render, tau):
    """
    Compute spatial variance of reconstruction error residual.
    """
    # E(I_full) and E(I_tau) are error maps (e.g., L1 error per pixel)
    # Assuming full_render and budgeted_render are error maps
    residual = full_render - budgeted_render
    
    # Variance over the image domain Omega
    var_loss = np.var(residual)
    return var_loss
```

**Parameters:**
*   $\eta \in (0, 1]$: Learning rate for complexity EMA update. Value not given in sources.
*   $\delta = 0.2$: Complexity dropout probability. Prevents collapse onto fixed complex regions [S1, unofficial].
*   $\lambda = 2$: Scalar weight for the scale term in the importance score [S1, unofficial].
*   $\lambda_{var}$: Weight for the variance loss. Value not given in sources.
*   $\tau$: Level of Details budget factor. $\tau=1$ for full capacity, $\tau<1$ for budgeted rendering [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Complexity Convergence:** Complexity values $C_j$ must be updated online as Gaussian positions change during training; static pre-computed complexity is insufficient [S1, unofficial].
*   **Dropout Impact:** Setting $\delta=1$ scores all candidates by opacity alone; $\delta=0$ uses no dropout. The default $\delta=0.2$ is ablated in the source [S1, unofficial].
*   **LoD Variance:** The scoring function alone does not guarantee uniform degradation; the variance loss $L_{var}$ is required to ensure this when varying $\tau$ [S1, unofficial].

## Subtopics

### Multi-View Density Control Criterion
Uses multi-view consistency to guide densification. Choose when multi-view coherence is more critical than per-view complexity. [Link](5663-multi-view-density-control-criterion.md)

### Average Contribution Criterion
Ranks Gaussians by their average contribution to the loss. Choose for simpler, opacity-scale based pruning without complexity modeling. [Link](16892-average-contribution-criterion.md)

### Frequency-Aware Adaptive Splat Spawning
Uses frequency domain analysis to spawn splats. Choose when high-frequency detail preservation is the primary goal. [Link](19904-frequency-aware-adaptive-splat-spawning.md)

## Operating characteristics
*   **Time Complexity:** Adds overhead for computing the 2D complexity map (delentropy) and updating the EMA for each Gaussian per view. The relocation and scoring steps are $O(N)$ where $N$ is the number of Gaussians.
*   **Memory Complexity:** Requires storing the complexity field $C_j$ and normalized complexity $\tilde{C}_j$ per Gaussian.
*   **Performance:** At full capacity, performs on par with other methods. At lower budgets (e.g., 10%, 1%, 0.1%), it generally outperforms baselines in PSNR, SSIM, and LPIPS [S1, unofficial].
*   **Strengths:** Prevents collapse onto fixed complex regions; ensures uniform degradation across LoD levels; effectively retains simple regions at low budgets.
*   **Limitations:** Requires computing a complex 2D map (delentropy); sensitive to the choice of $\delta$ and $\lambda$; requires varying $\tau$ during training for LoD-awareness [S1, unofficial].
*   **When to use:** When training 3D Gaussian Splatting models with limited budget constraints or when uniform quality degradation across different levels of detail is required.
*   **When not to use:** When computational resources are extremely limited and the overhead of complexity map computation is prohibitive; when opacity-only heuristics are sufficient for the target quality.

## Background
Originated in the paper "KoalaGS: Complexity-Aware Continuous Level of Detail for Gaussian Splatting" [S1, unofficial]. The method addresses limitations in standard 3DGS variants that rely on opacity as a proxy for reconstruction error, which leads to under-served unresolved regions and disproportionate degradation in low-complexity areas under budget constraints [S1, unofficial]. It builds on the concept of using complexity as a surrogate for error, extending it to online training updates and LoD-aware pruning [S1, unofficial].
