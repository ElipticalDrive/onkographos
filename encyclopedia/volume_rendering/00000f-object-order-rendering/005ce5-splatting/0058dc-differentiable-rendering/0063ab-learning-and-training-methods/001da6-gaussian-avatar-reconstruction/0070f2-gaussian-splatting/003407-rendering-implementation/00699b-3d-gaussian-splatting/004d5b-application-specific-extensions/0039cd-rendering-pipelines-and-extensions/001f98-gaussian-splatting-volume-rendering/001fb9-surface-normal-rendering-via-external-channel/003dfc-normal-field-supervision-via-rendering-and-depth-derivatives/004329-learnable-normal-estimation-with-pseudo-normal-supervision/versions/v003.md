# Learnable Normal Estimation with Pseudo-Normal Supervision

Also called: Learnable Unit Normal with Depth Gradient Supervision, Phys3DGS Normal Regularizer, Pseudo-Normal Supervision

## Overview
This method assigns a learnable unit normal to each 3D Gaussian to replace noisy gradient-based estimates, preventing optimization from overfitting to training lighting conditions by aligning rendered normals with geometry priors derived from depth gradients [S1, unofficial][S2]. It differs from pure gradient-based approaches by explicitly optimizing normal attributes per Gaussian and using expected depth to generate stable pseudo-normal targets for supervision [S2].

## How it works
**Inputs and Outputs:**
- **Input:** 3D Gaussian parameters (position, covariance, opacity $\alpha$, view-dependent color), camera parameters, ground truth RGB images, and binary image masks $M$ indicating valid pixels [S1, unofficial][S2].
- **Output:** Optimized Gaussian normals $\mathbf{n}_i$, rendered normal maps, and the normal loss value [S1, unofficial][S2].

**Data Structures:**
- **Gaussian Normal:** Each Gaussian $i$ stores a learnable unit normal vector $\mathbf{n}_i \in \mathbb{R}^3$ [S2].
- **Rendered Normal:** A 2D image buffer where each pixel stores a 3D vector $\mathbf{n}_i$ (pre-normalization) or the final normalized normal [S1, unofficial][S2].

**Steps:**
1. **Compute Expected Depth:** For each pixel, compute the expected depth $z_E$ along the ray using the weighted sum of Gaussian depths $z_i$ [S2]:
   $$ z_E = \frac{\sum_{i \in N} w_i z_i}{\sum_{i \in N} w_i} $$
   where $w_i = T_i g_i \alpha_i$ are the splatting weights, $T_i$ is transmittance, $g_i$ is the Gaussian density, and $\alpha_i$ is opacity. $N$ is the set of Gaussians overlapping the pixel [S2].
2. **Compute Pseudo-Normals:** Calculate the image-space gradients of the expected depth $\nabla z_E = (\partial_x z_E, \partial_y z_E)$ [S2]. Convert these gradients into world-space pseudo-normals $\mathbf{n}'_i$ (or $\hat{\mathbf{n}}_\nabla$) using the camera projection matrix [G].
3. **Splat Learnable Normals:** For each pixel, accumulate the learnable normals $\mathbf{n}_i$ from overlapping Gaussians using the splatting weights $w_i$ [S2]:
   $$ \tilde{\mathbf{n}} = \frac{\sum_{i \in N} w_i \mathbf{n}_i}{\sum_{i \in N} w_i + \epsilon_n} $$
   where $\epsilon_n$ is a small constant for numerical stability [S2].
4. **Normalize Rendered Normals:** L2-normalize the accumulated normal $\tilde{\mathbf{n}}$ to ensure unit length, as alpha-blending does not preserve unit length [S1, unofficial]:
   $$ \hat{\mathbf{n}} = \frac{\tilde{\mathbf{n}}}{\|\tilde{\mathbf{n}}\|_2 + \epsilon_n} $$
5. **Compute Loss:** Calculate the normal loss $L_n$ as the sum of the pseudo-normal alignment loss and a total variation smoothness term [S2]:
   $$ L_{n-p} = \|\hat{\mathbf{n}} - \hat{\mathbf{n}}_\nabla\| $$
   $$ L_n = L_{n-p} + \lambda_{n-TV} TV_{normal} $$
   Alternatively, as described in [S1, unofficial], the loss can be formulated as minimizing the negative dot product (maximizing cosine similarity) between the normalized rendered normal and the pseudo-normal:
   $$ L_{normal} = -\sum_{i \in M} \left( \frac{\mathbf{n}_i}{\|\mathbf{n}_i\|} \cdot \mathbf{n}'_i \right) $$
   where $M$ is the binary image mask selecting valid pixels [S1, unofficial]. The sources present slightly different formulations for the alignment term ($L_{n-p}$ vs $L_{normal}$), but both aim to align the rendered normal with the depth-derived pseudo-normal [S1, unofficial][S2].

**Parameters:**
- $\epsilon_n$: Small constant for numerical stability in normalization denominator [S2]. Typical value: $10^{-6}$ [G].
- $\lambda_{n-TV}$: Weight for the total variation loss [S2]. Not given in the sources.

**Pseudocode:**
```python
def compute_normal_loss(gaussians, camera, mask):
    epsilon_n = 1e-6
    lambda_n_tv = 0.1  # Not given in sources [G]
    expected_depth = {}
    acc_normal = {}
    acc_weight = {}
    
    # Rasterization pass: accumulate depth and normals per pixel
    for x, y in mask:
        w_sum = 0.0
        z_sum = 0.0
        n_sum = [0.0, 0.0, 0.0]
        for g in gaussians:
            if not is_inside_frustum(g, x, y): continue
            w = g.transmittance * g.density * g.opacity
            w_sum += w
            z_sum += w * g.depth
            n_sum[0] += w * g.normal[0]
            n_sum[1] += w * g.normal[1]
            n_sum[2] += w * g.normal[2]
        expected_depth[(x, y)] = z_sum / w_sum if w_sum > 0 else 0.0
        acc_normal[(x, y)] = n_sum
        acc_weight[(x, y)] = w_sum

    # Compute pseudo-normals from depth gradients
    pseudo_normals = {}
    for (x, y) in expected_depth:
        dz_dx = expected_depth.get((x + 1, y), expected_depth[(x, y)]) - expected_depth[(x, y)]
        dz_dy = expected_depth.get((x, y + 1), expected_depth[(x, y)]) - expected_depth[(x, y)]
        # Convert image-space gradients to world-space pseudo-normal using camera projection [G]
        pseudo_normals[(x, y)] = normalize([dz_dx, dz_dy, 1.0])

    # Compute loss
    loss = 0.0
    tv_loss = 0.0
    for (x, y) in acc_normal:
        n_vec = acc_normal[(x, y)]
        norm_val = math.sqrt(n_vec[0]**2 + n_vec[1]**2 + n_vec[2]**2) + epsilon_n
        n_hat = [n_vec[0]/norm_val, n_vec[1]/norm_val, n_vec[2]/norm_val]
        
        p_n = pseudo_normals.get((x, y), [0.0, 0.0, 0.0])
        dot = n_hat[0]*p_n[0] + n_hat[1]*p_n[1] + n_hat[2]*p_n[2]
        loss -= dot
        
        for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            neighbor = (x + dx, y + dy)
            if neighbor in acc_normal:
                n_n = acc_normal[neighbor]
                n_norm = math.sqrt(n_n[0]**2 + n_n[1]**2 + n_n[2]**2) + epsilon_n
                n_neighbor_hat = [n_n[0]/n_norm, n_n[1]/n_norm, n_n[2]/n_norm]
                tv_loss += math.sqrt((n_hat[0]-n_neighbor_hat[0])**2 + (n_hat[1]-n_neighbor_hat[1])**2 + (n_hat[2]-n_neighbor_hat[2])**2)
    
    return loss + lambda_n_tv * tv_loss

def is_inside_frustum(g, x, y):
    # Standard rasterization overlap check [G]
    return True

def normalize(v):
    norm = math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
    return [v[0]/norm, v[1]/norm, v[2]/norm] if norm > 0 else [0.0, 0.0, 0.0]
```

**Edge Cases and Pitfalls:**
- **Precision:** The normalization denominator must include a small epsilon to avoid division by zero [S2].
- **Degenerate Input:** If a pixel has no overlapping Gaussians, the accumulated normal is zero, leading to undefined normalization. The mask $M$ selects valid pixels for the loss summation, ensuring only pixels with valid geometry contribute [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Additional overhead per pixel for accumulating normals and computing depth gradients. The depth gradient computation is $O(HW)$, and the normal accumulation is part of the standard rasterization pass [S2].
- **Memory Complexity:** Requires storing an additional learnable normal vector per Gaussian and rendering buffers for expected depth and accumulated normals [S2].
- **Strengths:** Prevents overfitting to lighting conditions by providing a geometry prior [S1, unofficial]. More stable than pure gradient-based normals [S2].
- **Limitations:** Requires additional parameters per Gaussian. The quality of pseudo-normals depends on the accuracy of expected depth [S2].
- **When to use:** When accurate surface normals are needed for inverse rendering or PBR, and to prevent normal rotation from overfitting to training light conditions [S1, unofficial].
- **When not to use:** When computational resources are extremely limited, as it adds overhead to the rasterization pass [S2].

## Background
The method originates from ECCV 2024 Submission #12158 [S1, unofficial] and VisibilitySplat [S2], which aim to improve the geometric consistency of 3D Gaussian Splatting for inverse rendering tasks. It addresses the issue that gradient-based normals are noisy and inconsistent across views [S2].
