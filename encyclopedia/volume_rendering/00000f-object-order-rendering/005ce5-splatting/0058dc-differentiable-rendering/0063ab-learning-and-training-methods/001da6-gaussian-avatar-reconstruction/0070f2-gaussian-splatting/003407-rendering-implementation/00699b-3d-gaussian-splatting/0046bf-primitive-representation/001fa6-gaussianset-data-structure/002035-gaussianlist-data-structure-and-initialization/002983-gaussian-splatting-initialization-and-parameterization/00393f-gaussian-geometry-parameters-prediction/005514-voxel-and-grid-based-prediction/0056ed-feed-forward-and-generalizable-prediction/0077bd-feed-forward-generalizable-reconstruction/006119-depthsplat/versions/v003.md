# DepthSplat


## Overview
DepthSplat is a feed-forward method that reconstructs 3D Gaussian splatting representations from multi-view images by integrating pre-trained monocular depth features into a multi-view cost volume framework [S1]. It solves the problem of robust depth estimation in challenging scenes (occlusions, low-texture, non-Lambertian surfaces) where standard multi-view stereo fails, and scale ambiguity where monocular estimation fails [S1]. Unlike TranSplat, which uses monocular features to refine coarse depth (vulnerable to error propagation), DepthSplat combines cost volumes and monocular features early in the pipeline [S1]. Unlike GS-LRM, which discards explicit feature matching for data-driven priors, DepthSplat uses explicit feature matching and is significantly cheaper to train (4 GPUs vs 64 A100s) [S1].

## How it works
**Inputs:** $N$ input images $\{I_i\}_{i=1}^N$ with corresponding projection matrices $\{P_i\}_{i=1}^N$. Each image $I_i \in \mathbb{R}^{H \times W \times 3}$.
**Outputs:** A set of 3D Gaussians $\{(\mu_j, \alpha_j, \Sigma_j, c_j)\}_{j=1}^{H \times W}$ per view, where $\mu_j$ is position, $\alpha_j$ is opacity, $\Sigma_j$ is covariance, and $c_j$ is color. These are rendered to novel views.

**Data Structures:**
1.  **Monocular Features:** Extracted per view using a Vision Transformer (ViT).
2.  **Cost Volume:** $C_i \in \mathbb{R}^{\frac{H}{s} \times \frac{W}{s} \times D}$ for each view $i$.
3.  **Depth Map:** $D_i \in \mathbb{R}^{H \times W}$.
4.  **Gaussian Parameters:** Predicted in parallel to depth.

**Parameters:**
*   $N$: Number of input views.
*   $D$: Number of depth candidates.
*   $s$: Downsampling factor. $s=4$ if two stride-2 $3 \times 3$ convolutions are used; $s=8$ if three are used [S1].
*   Multi-view Transformer: Contains six stacked self- and cross-attention layers [S1].

**Steps:**

1.  **Monocular Feature Extraction:**
    For each view $i$, extract features $F_i$ using a pre-trained monocular depth model (ViT-based) [S1].

2.  **Cost Volume Construction (Multi-View Branch):**
    For each reference view $i$:
    a. Uniformly sample $D$ depth candidates $\{d_m\}_{m=1}^D$ from near/far depth ranges [S1].
    b. For each neighboring view $j$ (see Step 2c), warp features $F_j$ to view $i$ using $P_i$ and each depth candidate $d_m$ to obtain warped features $\{F_{j \to i}^m\}_{m=1}^D$ [S1].
    c. **Neighbor Selection:** If $N > 2$, select the top-2 nearest neighboring views based on camera distance to reference view $i$. Compute correlations only for these views [S1].
    d. Measure feature correlations via dot-product between $F_i$ and warped features $F_{j \to i}^m$ [S1].
    e. If multiple neighbors are used, combine correlation values with averaging [S1].
    f. Stack correlations to form cost volume $C_i \in \mathbb{R}^{\frac{H}{s} \times \frac{W}{s} \times D}$ [S1].

3.  **Feature Concatenation:**
    Concatenate the multi-view cost volumes $C_i$ with the extracted monocular features $F_i$ [S1].

4.  **Depth Regression:**
    Perform depth regression using a 2D U-Net architecture followed by a softmax layer to predict dense per-pixel depth $D_i$ [S1].

5.  **Gaussian Unprojection and Parameter Prediction:**
    a. Unproject the predicted depth maps $D_i$ to 3D space using camera parameters $P_i$ to obtain Gaussian centers $\mu_j$ [S1].
    b. Predict remaining Gaussian parameters (opacity $\alpha_j$, covariance $\Sigma_j$, color $c_j$) using an additional lightweight network/head in parallel with the depth regression [S1].

6.  **Rendering:**
    Render novel views using the splatting operation with the predicted 3D Gaussians [S1].

## Subtopics

### [Gaussian Graph Network](18863-gaussian-graph-network.md)
Gaussian Graph Network (GGN) is a feed-forward method that generates efficient and generalizable 3D Gaussian representations from multi-view images by modeling relations between Gaussian groups from different views using a Gaussian Graph structure. It solves the problem of artifacts and excessive memory costs caused by previous methods that simply combine pixel-aligned Gaussians from multiple views without capturing their inter-view relations. Unlike sibling methods that treat multi-view Gaussians as independent sets, GGN performs message passing and aggregation at the Gaussian level, allowing each Gaussian to benefit from connected groups in other views.

## Operating characteristics
**Time and Memory Complexity:**
*   **Training Cost:** Significantly cheaper than data-driven methods like GS-LRM. Trained in 2 days with 4 GPUs, compared to 64 A100 GPUs for 2 days for GS-LRM [S1].
*   **Inference Speed:** Fast feed-forward reconstruction. Achieves 0.6 seconds for reconstruction from 12 input views at 512x960 resolution [S1].
*   **Scalability:** For $N > 2$ views, the method selects only the top-2 nearest neighboring views for cost volume computation, making it tractable and scalable to larger numbers of input views [S1].

**Strengths and Limitations:**
*   **Strengths:** Robust in challenging situations such as low-textured regions and reflective surfaces by augmenting multi-view cost volumes with monocular features [S1]. Maintains multi-view consistency while leveraging monocular priors [S1]. Enables unsupervised pre-training of depth models using Gaussian splatting as a pre-training objective [S1].
*   **Limitations:** Multi-view depth estimation still fundamentally struggles with occlusions, low-textured areas, and non-Lambertian surfaces, though DepthSplat mitigates this [S1]. Monocular depth estimation inherently suffers from scale ambiguities, which DepthSplat addresses by using monocular features only as an augmentation to multi-view matching [S1].

**When to Use:**
*   Use when robust multi-view depth prediction is needed for feed-forward 3D Gaussian splatting reconstruction, especially in scenes with low texture or reflections [S1].
*   Use when computational resources for training are limited compared to methods like GS-LRM [S1].

**When Not to Use:**
*   Avoid if explicit feature matching is not desired or if the scene has severe occlusions that cannot be handled by the top-2 neighbor selection strategy [S1].

## Background
DepthSplat was introduced to connect Gaussian splatting and depth estimation, studying their interactions [S1]. It addresses the isolation in which these two techniques are typically studied [S1]. The method leverages pre-trained monocular depth features to augment multi-view feature matching, leading to high-quality feed-forward 3D Gaussian splatting reconstructions [S1]. It also demonstrates that Gaussian splatting can serve as an unsupervised pre-training objective for learning powerful depth models from large-scale multi-view posed datasets [S1]. The method was validated on TartanAir, ScanNet, RealEstate10K, and DL3DV datasets, achieving state-of-the-art performance on ScanNet and RealEstate10K [S1]. It contrasts with TranSplat, which uses monocular features to refine coarse depth, and Flash3D, which targets single-image reconstruction [S1].
