# Masked-Rasterization


## Overview
Masked-Rasterization is a differentiable rendering technique for 3D Gaussians that applies probabilistic masks during the alpha-compositing blending process, rather than modifying Gaussian attributes prior to rasterization. It solves the problem of "stale" Gaussians in pruning frameworks: when Gaussians are masked out (set to zero opacity/scale) in previous methods, they are filtered out before rasterization and receive no gradients, preventing them from updating their existence probability. By allowing masked Gaussians to participate in rasterization and receive gradients based on their "virtual contribution," this method enables dynamic assessment of their importance and prevents premature removal [S1]. It sets itself apart from siblings like [Gaussian Splat Rasterization (Vertex Shader)](3253-gaussian-splat-rasterization-vertex-shader.md) by specifically addressing the gradient flow for unselected Gaussians during the blending stage, rather than just optimizing the forward pass of visible splats.

## How it works
**Inputs:**
- Set of $N$ 3D Gaussians $G_i$, each defined by mean $\boldsymbol{\mu}_i$, covariance $\boldsymbol{\Sigma}_i$, opacity $\sigma_i$, and spherical harmonics coefficients for color $\mathbf{c}_i$.
- A probabilistic mask $m_i \in [0, 1]$ for each Gaussian, representing its probability of existence.
- Camera parameters for projection.

**Outputs:**
- Rendered image color $C$.
- Gradients for Gaussian attributes ($\boldsymbol{\mu}, \boldsymbol{\Sigma}, \sigma, \mathbf{c}$) and mask probabilities $m$.

**Data Structures:**
- **Gaussian Attributes:** Standard 3DGS representation.
- **Mask Array:** A float array of size $N$, storing $m_i$.
- **Tile/Screen Buffer:** Standard rasterization buffers for depth, transmittance, and accumulated color.

**Steps:**
1. **Projection and Alpha Computation:**
   For each Gaussian $G_i$, project the 3D mean $\boldsymbol{\mu}_i$ and covariance $\boldsymbol{\Sigma}_i$ to 2D screen space using the Jacobian of the projection transformation. Compute the 2D alpha value $\alpha_i$ based on the projected Gaussian's density, opacity, and scale.
   $$ \alpha_i = \sigma_i \exp\left(-\frac{1}{2} \mathbf{x}^T \boldsymbol{\Sigma}_{2D}^{-1} \mathbf{x}\right) $$
   where $\mathbf{x}$ is the vector from the pixel center to the Gaussian mean in screen space.

2. **Zero-Alpha Filtering:**
   Filter out any splats where $\alpha_i = 0$. All remaining splats (both masked and unmasked) proceed to rasterization. Note: If opacity or scale is set to zero *before* this step, $\alpha_i$ becomes zero, and the Gaussian is filtered out, preventing gradient updates [S1].

3. **Masked Rasterization (Blending):**
   For each pixel, iterate through the sorted list of splats. For each splat $G_i$ with mask $m_i$:
   - **Transmittance Update:** The transmittance $T$ is attenuated by the mask. If the Gaussian is masked ($m_i \approx 0$), it does not block light, but its presence is tracked for gradient purposes.
     $$ T_{i+1} = T_i (1 - m_i \alpha_i) $$
   - **Color Accumulation:** The color contribution is scaled by the mask.
     $$ C_{i+1} = C_i + m_i \alpha_i T_i \mathbf{c}_i $$
   - **Gradient Flow:**
     - If $m_i = 0$, the Gaussian does not contribute to the final color $C$ or transmittance $T$ in the forward pass (effectively invisible). However, the differentiable mask allows gradients to flow back to $m_i$ based on the "virtual" contribution it *would* have made if present. This updates the existence probability.
     - If $m_i > 0$, standard gradients apply to $\alpha_i$ and $\mathbf{c}_i$.
     - Crucially, masked Gaussians ($m_i=0$) do *not* receive gradients for $\alpha_i$ (and thus do not update $\boldsymbol{\mu}, \boldsymbol{\Sigma}, \sigma$) in this step, but they *do* receive gradients for $m_i$ [S1].

4. **Mask Update:**
   Use the computed gradients for $m_i$ to update the existence probability of each Gaussian via an optimizer (e.g., Adam). This allows previously unselected Gaussians to increase their probability of existence if they are deemed important by the gradient signal.

**Parameters:**
- **Mask Sampling:** Masks are sampled from a distribution based on the current existence probability of each Gaussian [S1].
- **Pruning Threshold:** Not explicitly defined in the method description, but experiments show pruning ratios of 62.4%–75.3% are achievable [S1].

**Edge Cases:**
- **Zero Alpha Filtering:** If a Gaussian's opacity or scale is set to zero *before* rasterization, $\alpha_i$ becomes zero, and the Gaussian is filtered out. This prevents it from receiving any gradient updates, which is the pitfall Masked-Rasterization aims to avoid [S1].
- **Mask Value 0:** If $m_i=0$, the Gaussian is invisible but still participates in the gradient computation for $m_i$. It does not update its geometric attributes ($\boldsymbol{\mu}, \boldsymbol{\Sigma}$) via $\alpha_i$ gradients [S1].

## Operating characteristics
- **Time Complexity:** Similar to standard 3D Gaussian Splatting rasterization, as all Gaussians are still splatted and sorted. The masking adds minimal overhead (multiplication operations).
- **Memory Complexity:** Requires storing an additional mask array of size $N$ [S1].
- **Performance:** Experiments show rendering speedups of $2.05\times$ to $3.16\times$ on datasets like Mip-NeRF360, Tanks & Temples, and Deep Blending, with pruning ratios of 62.4%–75.3% and only a 0.02 PSNR decline on the first two datasets [S1].
- **Strengths:** Enables effective pruning by allowing unselected Gaussians to update their existence probability, preventing them from becoming stale. Outperforms methods that multiply masks with opacity/scale [S1].
- **Limitations:** Requires careful implementation of gradient flow for masks. If not implemented correctly, masked Gaussians may not receive meaningful gradients.

## Background
Masked-Rasterization was introduced in the **MaskGaussian** paper by researchers from Shanghai AI Laboratory. It addresses limitations in previous 3D Gaussian pruning methods where multiplying masks with Gaussian attributes (opacity/scale) led to zero density values, causing Gaussians to be filtered out and preventing gradient updates. The method models Gaussians as probabilistic entities, allowing for dynamic assessment of their contribution to the evolving scene [S1].
