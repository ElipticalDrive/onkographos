# AnySplat Pipeline

Also called: Feed-forward 3D Gaussian Splatting from Unconstrained Views

## Overview
AnySplat is a feed-forward method that predicts a set of 3D Gaussian primitives directly from uncalibrated input images, bypassing the need for known camera poses or depth priors during inference [S1, unofficial]. It differs from sibling methods like [Splatt3R](16423-splatt3r.md) and [ZeroGS](16425-zerogs.md) by explicitly regressing camera poses and depth maps alongside Gaussian parameters, using a differentiable voxelization module to bridge the gap between pixel-wise predictions and a renderable 3D scene representation [S1, unofficial].

## How it works
**Inputs and Outputs:**
The network takes a batch of $K$ uncalibrated RGB images as input. The output is a set of 3D Gaussians $\mathcal{G}$ and predicted camera poses $\mathbf{p}$ [S1, unofficial].

**Data Structures:**
*   **Input Tensor:** Shape $[1, K, 3, 448, 448]$ representing batch size, number of views, channels, height, and width [S1, unofficial].
*   **Gaussian Parameters:** Each Gaussian $k$ is defined by position $\mu_k$, scale $\sigma_k$, rotation $r_k$, opacity $s_k$, and color $c_k$ [S1, unofficial].
*   **Camera Poses:** Predicted extrinsic matrices $\mathbf{P}_{ext}$ and intrinsic matrices $\mathbf{P}_{int}$ for each view [S1, unofficial].

**Steps:**
1.  **Feature Extraction:** Input images are processed by a transformer-based geometry encoder to extract multi-scale features [S1, unofficial].
2.  **Parameter Regression:** Three decoder heads ($F_G, F_D, F_C$) predict:
    *   $F_G$: Gaussian parameters $(\mu, \sigma, r, s, c)$ [S1, unofficial].
    *   $F_D$: Depth map $D$ [S1, unofficial].
    *   $F_C$: Camera poses $\mathbf{p}$ [S1, unofficial].
3.  **Gaussian Construction:** Pixel-wise 3D Gaussians are constructed using the predicted parameters and depth [S1, unofficial].
4.  **Differentiable Voxelization:** The pixel-wise Gaussians are voxelized into "pre-voxel" 3D Gaussians using a differentiable voxelization module to handle density and occlusion [S1, unofficial].
5.  **Rendering:** Multi-view images and depth maps are rendered from the voxelized Gaussians using differentiable rasterization [S1, unofficial].
6.  **Loss Computation:**
    *   **RGB Loss:** Photometric loss between rendered and ground truth images.
    *   **Geometry Loss:** Computed between rendered depth, decoded depth $D$, and predicted poses $\mathbf{p}$, supervised by pseudo-geometry priors from a pretrained VGGT model [S1, unofficial].

**Pseudocode:**
```python
def anysplat_pipeline(images):
    """
    images: Tensor of shape [1, K, 3, 448, 448] with values in [-1, 1]
    Returns: gaussians (3D Gaussian primitives), pred_context_pose (camera poses)
    """
    # Normalize input from [-1, 1] to [0, 1]
    normalized_images = (images + 1) * 0.5
    
    # Run inference through the model
    # model.inference returns the set of 3D Gaussians and predicted camera poses
    gaussians, pred_context_pose = model.inference(normalized_images)
    
    return gaussians, pred_context_pose
```

**Parameters:**
*   Input resolution: $448 \times 448$ pixels [S1, unofficial].
*   Number of views $K$: Variable, typically small (e.g., 3-5) for inference [S1, unofficial].

**Edge Cases:**
*   **Uncalibrated Input:** The method handles unknown camera intrinsics and extrinsics by predicting them, but accuracy depends on the quality of the pseudo-geometry priors from VGGT [S1, unofficial].
*   **Voxelization Artifacts:** Improper voxelization can lead to gaps or overlaps in the Gaussian set, affecting rendering quality [S1, unofficial].

## Subtopics

### [SubSplat](13524-subsplat.md)
A high-resolution variant that uses a Sub-pixel Gaussian Reparameterizer to increase Gaussian density from low-resolution features.

### [Deformable Radial Kernel (DRK)](13699-deformable-radial-kernel-drk.md)
A variant replacing fixed Gaussians with deformable radial kernels for better geometric fidelity with fewer primitives.

## Operating characteristics
*   **Time Complexity:** Inference is fast as it is a single forward pass through a neural network, independent of scene complexity [S1, unofficial].
*   **Memory Complexity:** Depends on the number of predicted Gaussians and the voxel grid resolution [S1, unofficial].
*   **Strengths:** Handles uncalibrated images; end-to-end differentiable training; generalizes across scenes [S1, unofficial].
*   **Limitations:** Relies on pseudo-geometry priors which may be inaccurate in ambiguous scenes; voxelization step adds computational overhead [S1, unofficial].
*   **When to Use:** Novel view synthesis from unconstrained, uncalibrated image sets where traditional SfM is unreliable or unavailable [S1, unofficial].
*   **When Not to Use:** When high-precision camera poses are already known and a simpler feed-forward method without pose regression is sufficient [S1, unofficial].

## Background
AnySplat was introduced by InternRobotics as a feed-forward approach to 3D Gaussian Splatting that does not require calibrated input [S1, unofficial]. It builds on the principles of differentiable rendering and neural radiance fields, extending them to handle uncalibrated inputs by jointly predicting geometry and camera parameters [S1, unofficial]. The method leverages pretrained vision foundation models (VGGT) to provide geometric supervision during training [S1, unofficial].
