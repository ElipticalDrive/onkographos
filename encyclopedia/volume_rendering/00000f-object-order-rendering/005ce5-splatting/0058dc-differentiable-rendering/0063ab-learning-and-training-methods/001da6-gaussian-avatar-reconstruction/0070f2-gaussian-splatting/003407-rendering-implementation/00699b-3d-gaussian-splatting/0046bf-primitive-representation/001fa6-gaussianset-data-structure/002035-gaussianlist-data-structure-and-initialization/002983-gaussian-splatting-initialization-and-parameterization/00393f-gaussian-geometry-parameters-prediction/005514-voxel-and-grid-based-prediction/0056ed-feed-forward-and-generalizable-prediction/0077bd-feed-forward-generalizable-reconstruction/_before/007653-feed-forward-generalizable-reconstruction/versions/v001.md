# Feed-forward Generalizable Reconstruction

Also called: Feed-forward 3D Gaussian Splatting, Generalizable 3DGS, One-shot 3D Reconstruction

## Overview
Feed-forward Generalizable Reconstruction methods map input images directly to a set of 3D Gaussian primitives $\mathcal{G}$ in a single inference pass, eliminating the per-scene gradient descent optimization required by standard 3D Gaussian Splatting [Parent]. This family solves the latency and scalability bottlenecks of iterative optimization, enabling real-time reconstruction and novel view synthesis for unseen scenes by leveraging priors learned from large-scale datasets [Parent]. Unlike iterative methods, these approaches trade the potential for perfect per-scene fidelity for inference speed and generalization capability [Parent].

## Shared principles
All methods in this family share the core objective of mapping input image features to a set of 3D Gaussian parameters $\mathcal{G} = \{\mu, \Sigma, \alpha, c\}$ without per-scene gradient descent [Parent].

1.  **Input Representation:** Inputs are typically one or more RGB images $I \in \mathbb{R}^{H \times W \times 3}$. Some methods require known camera poses $P$, while others (e.g., [Splatt3R](16423-splatt3r.md), [ZeroGS](16425-zerogs.md)) predict poses or operate on uncalibrated inputs [Parent].
2.  **Feature Encoding:** A shared encoder (e.g., Vision Transformer, CNN) extracts multi-scale features from the input images. Cross-attention or cost volumes are often used to aggregate multi-view information [Parent].
3.  **Primitive Prediction:** A decoder head predicts Gaussian attributes. These attributes are usually:
    *   **Mean ($\mu$):** 3D position.
    *   **Covariance ($\Sigma$):** Defined by scale $s$ and rotation $r$ (quaternion or 6D).
    *   **Opacity ($\alpha$):** Scalar.
    *   **Color ($c$):** Spherical Harmonics (SH) coefficients or constant RGB [Parent].
4.  **Differentiable Rendering:** The predicted Gaussians are rendered into target views using differentiable rasterization to compute reconstruction losses (e.g., L1, SSIM, LPIPS) for training the network [Parent].
5.  **Generalization:** The network is trained on a large dataset of scenes to learn priors about geometry and appearance, allowing inference on unseen scenes [Parent].

## Subtopics

### [AnySplat Pipeline](12847-anysplat-pipeline.md)
AnySplat is a feed-forward method for reconstructing 3D scenes from uncalibrated, unconstrained image collections by directly predicting 3D Gaussian primitives and camera poses. It differs from iterative optimization-based Gaussian Splatting by using a transformer-based encoder-decoder to infer scene parameters in a single forward pass, and from other generalizable methods by explicitly predicting camera poses alongside geometry to handle uncalibrated inputs.

### [Splatt3R](16423-splatt3r.md)
Splatt3R is a feed-forward, pose-free method for 3D reconstruction and novel view synthesis that predicts 3D Gaussian primitives directly from a pair of uncalibrated natural images. It solves the problem of generalizable reconstruction without requiring camera intrinsics, extrinsics, or depth maps, avoiding the local minima and per-scene optimization typical of iterative 3D Gaussian Splatting. Unlike sibling methods that restrict supervision to viewpoints between input stereo views, Splatt3R extends to extrapolated viewpoints using a novel loss masking strategy based on frustum culling and covisibility testing.

### [RLSplat](16575-rlsplat.md)
RLSplat is a resource-linear, budget-controllable feed-forward 3D Gaussian Splatting (FF3DGS) framework that ensures inference latency, peak memory, and representation size all decrease linearly as the target Gaussian budget $B$ is reduced. Unlike prior budget-controllable methods that predict a dense set of candidates and prune them—resulting in nearly constant inference costs regardless of the budget—RLSplat learns a Gaussian allocation policy to distribute exactly $B$ Gaussians across local scene regions from the start. It then refines these Gaussians using a resource-linear decoder based on local cross-attention with a hierarchical neighbor search.

### [LGTM (Less Gaussians, Texture More)](17426-lgtm-less-gaussians-texture-more.md)
LGTM is a feed-forward framework that predicts compact 2D Gaussian primitives coupled with per-primitive texture maps, decoupling geometric complexity from rendering resolution to enable high-fidelity 4K novel view synthesis without per-scene optimization. It solves the problem where existing feed-forward 3DGS methods suffer from quadratic growth in primitive count as resolution increases, making high-resolution synthesis intractable due to memory and compute limits. Unlike standard 3DGS which couples appearance and geometry within each primitive, LGTM allows a compact set of geometric primitives to represent rich texture regions via per-primitive textures.

### [InfiniSplat v2](17642-infinisplat-v2.md)
InfiniSplat v2 is a feed-forward Gaussian reconstruction method for arbitrary input views that decouples geometry and attribute prediction, uses ground-truth (GT) camera poses for alignment during training, and employs large-angle target view supervision to improve rendering quality under large viewpoint changes. It differs from its parent [Feed-forward Generalizable Reconstruction](23462-feed-forward-generalizable-reconstruction.md) and siblings like [DA3-GS](12847-anysplat-pipeline.md) by freezing the geometry branch to prevent geometric degradation caused by joint optimization, and by using GT poses to avoid pose errors that misguide the network under large-angle supervision.

### [DepthSplat](18278-depthsplat.md)
DepthSplat is a feed-forward method for 3D Gaussian splatting reconstruction that connects Gaussian splatting with depth estimation by leveraging pre-trained monocular depth features to augment multi-view feature matching. It solves the problem of artifacts and scale ambiguities in multi-view reconstruction by using monocular features only as an augmentation to multi-view matching, ensuring multi-view consistency while improving robustness in low-textured or reflective areas. Unlike TranSplat, which uses monocular features to refine coarse depth (vulnerable to error propagation), DepthSplat combines cost volumes and monocular features early in the pipeline. Unlike GS-LRM, which relies heavily on training data and compute, DepthSplat uses explicit feature matching and is cheaper to train.

### [VG2GT](18425-vg2gt.md)
VG2GT is a feed-forward, non-pixel-aligned 3D Gaussian Splatting (3DGS) reconstruction framework that directly regresses geometrically accurate Gaussian scenes and camera parameters from an arbitrary number of unposed and uncalibrated images. It distinguishes itself from sibling methods like AnySplat by avoiding intermediate pixel-aligned representations; instead, it directly decodes Gaussian primitives from structured voxel features, thereby mitigating the uneven Gaussian distributions and cross-view inconsistencies inherent in pixel-aligned formulations.

### [WildSplat](19321-wildsplat.md)
WildSplat is a feedforward 3D Gaussian Splatting framework for appearance-conditioned novel-view synthesis from sparse, unposed, in-the-wild images. It explicitly decouples geometry from appearance to handle inconsistent photometric conditions, such as varying weather and lighting, which typically cause entangled representations in existing methods to fail. Unlike optimization-based methods that require precomputed poses and dense inputs, or prior feedforward methods that assume photometric consistency, WildSplat reconstructs a 3D Gaussian representation and predicts camera poses in a single forward pass using a dual-branch architecture.

### [StereoGaussians](19766-stereogaussians.md)
StereoGaussians is a feed-forward method that predicts a metric 3D Gaussian Splatting (3DGS) representation from a single calibrated stereo pair, enabling nearby-view extrapolation without per-scene optimization. It sets itself apart from siblings like [AnySplat Pipeline](12847-anysplat-pipeline.md) and [Splatt3R](16423-splatt3r.md) by explicitly leveraging frozen pretrained stereo features to anchor geometry while using a two-layer Gaussian prediction and an expanded image canvas to handle disoccluded and outside-field-of-view content. Unlike [DepthSplat](18278-depthsplat.md), which refines inverse depth through a composer, StereoGaussians fixes the front-layer stereo depth and bounds image-plane offsets to provide a structural prior.

## Background
The field of generalizable 3D reconstruction has evolved from iterative optimization-based methods like 3D Gaussian Splatting [Parent], which require per-scene tuning, to feed-forward approaches that learn scene priors from large datasets. Early works in generalizable depth and stereo estimation laid the groundwork for feature-based correspondence [Parent]. The introduction of 3D Gaussian Splatting as a differentiable rendering primitive enabled new opportunities for explicit 3D representation learning [Parent]. Recent developments focus on improving generalization to uncalibrated inputs, reducing computational complexity, and handling complex appearance variations [Parent].
