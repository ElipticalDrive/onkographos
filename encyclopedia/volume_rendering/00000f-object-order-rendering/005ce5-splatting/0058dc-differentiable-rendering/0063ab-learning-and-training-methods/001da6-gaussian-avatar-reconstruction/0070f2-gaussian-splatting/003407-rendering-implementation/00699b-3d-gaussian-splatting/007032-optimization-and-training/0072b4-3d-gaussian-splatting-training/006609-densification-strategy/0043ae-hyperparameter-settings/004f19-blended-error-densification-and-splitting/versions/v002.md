# Blended Error Densification and Splitting

Also called: Blended Error Splitting

## Overview
Blended Error Densification and Splitting is a strategy for growing Gaussian primitives in 3D Gaussian Splatting that uses an auxiliary per-pixel error metric to drive densification decisions, rather than relying on positional gradient magnitudes [S1]. It solves the limitation of gradient-based methods, which are sensitive to error changes but blind to absolute error values in high-frequency areas, by redistributing per-pixel errors to primitives proportional to their rendering contribution [S1]. This method is distinct from sibling strategies like [Conditional 3DGS Optimization and Rendering](11459-conditional-3dgs-optimization-and-rendering.md) by explicitly utilizing accumulated L1 error norms as probability weights for splitting [S1].

## How it works
**Inputs:**
- Current set of Gaussian primitives $\mathcal{G} = \{g_i\}$, where each primitive $g_i$ has mean $\mu_i$, covariance $\Sigma_i$ (defined by scales $\sigma_{i,1}, \sigma_{i,2}, \sigma_{i,3}$ and rotation), opacity $\alpha_i$, and color/feature coefficients.
- Per-pixel rendering error $E_{pixel}$ from the current iteration (typically L1 loss against ground truth).
- Blended error accumulator $B_i$ for each primitive (initialized to 0).

**Outputs:**
- Updated set of primitives $\mathcal{G}'$, where a subset of primitives has been split into two.

**Data Structures:**
- `blended_errors`: Array of floats, size $N$ (number of primitives). Stores the accumulated scalar error value for each primitive.
- `primitive_list`: List of primitive objects containing fields: `mean` (vec3), `scale` (vec3), `rotation` (quat), `opacity` (float), `colors` (tensor), `gamma` (float).

**Steps:**

1. **Backward Pass Error Calculation:**
   During the backward pass of each training iteration, compute the blended L1 error for each primitive. This involves redistributing the per-pixel L1 error $E_{pixel}$ to the contributing primitives proportional to their rendering contribution (opacity and depth weighting) as defined by Rota Bulò et al. [S1]. Let $b_i$ be the blended error contribution for primitive $i$ in the current iteration.

2. **Accumulation:**
   Update the accumulated blended error for each primitive by adding the current iteration's contribution, rather than taking the maximum:
   $$ B_i^{(t)} = B_i^{(t-1)} + b_i^{(t)} $$
   where $t$ is the iteration index [S1].

3. **Normalization and Sampling:**
   Normalize the accumulated blended errors to form probability weights. Let $B_{max} = \max_i(B_i)$. The probability $p_i$ of selecting primitive $i$ for splitting is:
   $$ p_i = \frac{B_i}{\sum_j B_j} $$
   Sample a subset of primitives for splitting. The target fraction of primitives to split is 5% of the current total count $N$ [S1]. Specifically, select $K = \lfloor 0.05 \times N \rfloor$ primitives. Selection is performed by sampling indices from the distribution defined by $p_i$ without replacement, or by thresholding if a deterministic approach is preferred, though the source specifies sampling based on normalized weights [S1].

4. **Splitting Operation:**
   For each selected primitive $i$:
   a. Identify the principal axis of the covariance matrix. Let the scales be sorted such that $\sigma_{i,1} \ge \sigma_{i,2} \ge \sigma_{i,3}$. The split occurs along the longest axis (associated with $\sigma_{i,1}$) [S1].
   b. Let $v_{i,1}$ be the unit vector corresponding to the eigenvector of $\Sigma_i$ associated with $\sigma_{i,1}$ [S1].
   c. Create two new primitives, $g_{i,a}$ and $g_{i,b}$, with the following properties:
      - **Scales:** Both new primitives have scales $(\frac{\sigma_{i,1}}{2}, \sigma_{i,2}, \sigma_{i,3})$ [S1].
      - **Means:**
        $$ \mu_{i,a} = \mu_i - \frac{\sigma_{i,1}}{2} v_{i,1} $$
        $$ \mu_{i,b} = \mu_i + \frac{\sigma_{i,1}}{2} v_{i,1} $$
      - **Other Properties:** Copy all other properties from the original primitive $i$, including opacity, color coefficients, rotation (relative to the new mean), and the $\gamma$ value [S1].
   d. Remove the original primitive $i$ from the list and insert $g_{i,a}$ and $g_{i,b}$ [S1].

**Pseudocode:**

```python
def blended_error_densification(primitives, blended_errors, iteration_errors):
    """
    primitives: List of Primitive objects
    blended_errors: List[float], accumulated error per primitive
    iteration_errors: List[float], blended L1 error contribution per primitive for current step
    
    Returns: Updated list of primitives
    """
    # Step 2: Accumulate errors
    for i in range(len(primitives)):
        blended_errors[i] += iteration_errors[i]
        
    # Step 3: Normalize and sample
    total_error = sum(blended_errors)
    if total_error == 0:
        return primitives
        
    probabilities = [e / total_error for e in blended_errors]
    
    # Sample 5% of primitives
    num_to_split = max(1, int(0.05 * len(primitives)))
    # Note: Standard sampling without replacement from categorical distribution
    # Implementation detail: Use numpy.random.choice or similar
    indices_to_split = sample_without_replacement(len(primitives), probabilities, num_to_split)
    
    new_primitives = []
    for i, prim in enumerate(primitives):
        if i in indices_to_split:
            # Step 4: Split
            # Assume scales are stored as [sigma1, sigma2, sigma3] with sigma1 >= sigma2 >= sigma3
            # v1 is the eigenvector corresponding to sigma1
            sigma1 = prim.scale[0]
            v1 = prim.eigenvector_0 # Unit vector for longest axis
            
            # New scales: halve the longest axis
            new_scale = [sigma1 / 2.0, prim.scale[1], prim.scale[2]]
            
            # New means
            offset = (sigma1 / 2.0) * v1
            mean_a = prim.mean - offset
            mean_b = prim.mean + offset
            
            # Create new primitives
            prim_a = Primitive(
                mean=mean_a,
                scale=new_scale,
                rotation=prim.rotation, # Copy rotation
                opacity=prim.opacity,
                colors=prim.colors,
                gamma=prim.gamma
            )
            
            prim_b = Primitive(
                mean=mean_b,
                scale=new_scale,
                rotation=prim.rotation, # Copy rotation
                opacity=prim.opacity,
                colors=prim.colors,
                gamma=prim.gamma
            )
            
            new_primitives.append(prim_a)
            new_primitives.append(prim_b)
        else:
            new_primitives.append(prim)
            
    return new_primitives
```

**Edge Cases and Pitfalls:**
- If $\sigma_{i,1}$ is very small, the split displacement is small, potentially leading to overlapping primitives.
- The assumption $\sigma_{i,1} \ge \sigma_{i,2}$ must be enforced or checked before splitting to ensure the correct axis is chosen [S1].
- Precision issues may arise if $B_i$ values vary significantly in magnitude; normalization helps but underflow/overflow should be monitored [G].

## Subtopics

## Operating characteristics
- **Time Complexity:** $O(N)$ for accumulation and normalization, where $N$ is the number of primitives. Sampling is $O(K)$ where $K=0.05N$. Splitting is $O(K)$ as it involves constant-time geometric operations per split.
- **Memory Complexity:** Increases by 5% per densification step (since each split replaces 1 primitive with 2).
- **Performance:** The method effectively targets high-error regions, improving reconstruction quality in textured areas [S1]. It avoids the noise sensitivity of pure gradient-based methods [S1].
- **Limitations:** Relies on the accuracy of the blended error calculation from the backward pass. If the error metric is noisy, densification may be erratic [S1].

## Background
This method is described in the context of "Nexels: Neurally-Textured Surfels for Real-Time Novel View Synthesis with Sparse Primitives" [S1]. It builds upon the densification strategies of 3D Gaussian Splatting but introduces a specific error-based splitting heuristic inspired by 3DGS-MCMC [S1]. The error redistribution logic references the work of Rota Bulò et al. .
