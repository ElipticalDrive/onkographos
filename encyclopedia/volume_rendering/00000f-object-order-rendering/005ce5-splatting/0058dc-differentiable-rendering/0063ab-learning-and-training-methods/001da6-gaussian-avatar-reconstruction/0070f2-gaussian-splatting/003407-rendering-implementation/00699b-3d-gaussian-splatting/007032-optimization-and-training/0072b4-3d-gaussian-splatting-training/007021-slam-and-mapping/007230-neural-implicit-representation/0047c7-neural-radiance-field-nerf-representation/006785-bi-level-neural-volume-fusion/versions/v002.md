# Bi-level Neural Volume Fusion

Also called: BNV-Fusion

## Overview
Bi-level Neural Volume Fusion (BNV-Fusion) is a dense 3D reconstruction method that incrementally integrates noisy depth maps into a global neural implicit representation using a bi-level fusion strategy [S1]. It combines local-level weighted averaging for efficient integration with global-level neural rendering optimization to ensure geometric coherence [S1]. Unlike sibling methods that either rely solely on latent code integration (e.g., NeuralFusion, DI-Fusion) or single-MLP global representations (e.g., iMAP), BNV-Fusion uses a volume of latent codes to encode local geometry, improving detail and scalability while maintaining near real-time performance [S1].

## How it works
**Inputs:** A sequence of depth maps $\{D_0, ..., D_n\}$ and associated extrinsic camera-to-world transformation matrices $\{T_{cw}^0, ..., T_{cw}^n\}$, where $T_{cw}^t$ denotes the rigid transformation from camera $c_t$ to the world coordinate [S1].

**Outputs:** A global implicit neural volume $V_w$ representing the scene geometry, from which a mesh can be extracted via Marching Cubes [S1].

**Data Structures:**
1.  **Implicit Neural Volume ($V_w$):** Defined as a weighted sum of decoder outputs conditioned on latent codes. It consists of a grid of latent codes $\{\bm{l}_i\}$ located at positions $\{\bm{p}_i\}$ [S1].
2.  **Local Shape Embedding:** Comprises an encoder $E$ (modified PointNet) and a decoder $\mathcal{D}$ (4-layer MLP) [S1].
3.  **Single-View Neural Volume ($V_c^t$):** A set of latent codes representing local geometry for a specific depth map $D_t$ [S1].

**Method Steps:**

1.  **Encoding:** For each depth map $D_t$ at frame $t$: unproject the depth map into a point cloud; pass the point cloud through the encoder $E$ to extract deep features for each point by aggregating information within a local region; map these features to a set of latent codes to form the single-view neural volume $V_c^t$ [S1].
2.  **Local-Level Fusion:** Integrate $V_c^t$ into the global volume $V_w$ by performing weighted averaging of the new latent codes into the global volume using weights $W_c^t$ [S1]. This step efficiently integrates new information but is susceptible to depth outliers as it lacks global context [S1].
3.  **Global-Level Fusion:** Optimize the global volume $V_w$ by iteratively minimizing the discrepancy between Signed Distance Function (SDF) values extracted from the volume $s_i$ and actual depth measurements $\bar{s}_i$ along camera rays [S1]. The decoder $\mathcal{D}$ parameters are frozen during this optimization; only the latent codes are updated [S1]. This step encourages coherent global reconstruction and corrects errors from the local-level fusion [S1].

**Implicit Neural Volume Definition:**
The SDF value $s$ at a query point is computed using trilinear interpolation of latent codes [S1]:

$$ s = \sum_{i=0}^{N=7} w(\bar{\bm{x}}_i, \bm{p}_i)\mathcal{D}(\bm{l}_i, \bar{\bm{x}}_i) $$

Where:
*   $N=7$: The number of neighboring latent codes used for trilinear interpolation [S1].
*   $w(\cdot, \cdot)$: The weight function for trilinear interpolation, dependent on the query point $\bar{\bm{x}}_i$ and the latent code position $\bm{p}_i$ [S1].
*   $\mathcal{D}$: The decoder network (MLP) that maps a latent code and a 3D coordinate to an SDF value [S1].
*   $\bm{l}_i$: The latent code for the $i$-th neighbor [S1].
*   $\bar{\bm{x}}_i$: The 3D coordinate of the query point relative to the $i$-th latent code [S1].

**Local Shape Embedding Training:**
The encoder $E$ and decoder $\mathcal{D}$ are trained jointly in a supervised manner using object CAD models from ShapeNet [S1]. The loss function for a training sample pair $(\bm{p}, \bm{x})$ is:

$$ \mathcal{L}(\theta_{\mathcal{E}}, \theta_{\mathcal{D}}) = \|\mathcal{D}_{\theta_{\mathcal{D}}}(\mathcal{E}_{\theta_{\mathcal{E}}}(\bm{p}), \bm{x}) - s^{gt}_{\bm{x}} \|_1 $$

Where:
*   $\bm{p}$: A local point cloud with normals of a local surface patch [S1].
*   $\bm{x}$: A sampled point around the surface [S1].
*   $s^{gt}_{\bm{x}}$: The ground-truth SDF value for the sampled point $\bm{x}$ around the surface [S1].

**Pseudocode:**

```python
# Standard mathematical operations
def trilinear_weight_and_decode(grid, query_pt, decoder_D):
    # Compute 8 surrounding grid cells and trilinear weights
    base_ix = int((query_pt[0] - grid.bounds[0]) / grid.res)
    base_iy = int((query_pt[1] - grid.bounds[1]) / grid.res)
    base_iz = int((query_pt[2] - grid.bounds[2]) / grid.res)
    sdf_val = 0.0
    for dx in range(2):
        for dy in range(2):
            for dz in range(2):
                key = (base_ix + dx, base_iy + dy, base_iz + dz)
                if key in grid.cells:
                    l_i = grid.cells[key]
                    p_i = np.array([
                        grid.bounds[0] + (base_ix + dx) * grid.res,
                        grid.bounds[1] + (base_iy + dy) * grid.res,
                        grid.bounds[2] + (base_iz + dz) * grid.res
                    ])
                    # Trilinear interpolation weights
                    fx = (query_pt[0] - p_i[0]) / grid.res
                    fy = (query_pt[1] - p_i[1]) / grid.res
                    fz = (query_pt[2] - p_i[2]) / grid.res
                    w = (1.0 - fx if dx == 0 else fx) * \
                        (1.0 - fy if dy == 0 else fy) * \
                        (1.0 - fz if dz == 0 else fz)
                    rel_coord = query_pt - p_i
                    sdf_val += w * decoder_D(l_i, rel_coord)
    return sdf_val

def unproject_depth(depth_map, K, T_cw):
    points = []
    for u in range(depth_map.shape[1]):
        for v in range(depth_map.shape[0]):
            z = depth_map[v, u]
            if z > 0:
                x_cam = (u - K[0, 2]) * z / K[0, 0]
                y_cam = (v - K[1, 2]) * z / K[1, 1]
                pt_cam = np.array([x_cam, y_cam, z, 1.0])
                pt_world = T_cw @ pt_cam
                points.append(pt_world[:3])
    return points

# Main Algorithm
class NeuralVolumeGrid:
    def __init__(self, bounds, resolution):
        self.cells = {}
        self.bounds = bounds
        self.res = resolution
    def get_or_create(self, pos):
        ix = int((pos[0] - self.bounds[0]) / self.res)
        iy = int((pos[1] - self.bounds[1]) / self.res)
        iz = int((pos[2] - self.bounds[2]) / self.res)
        key = (ix, iy, iz)
        if key not in self.cells:
            self.cells[key] = np.zeros(LATENT_DIM)
        return self.cells[key], key

global_volume = NeuralVolumeGrid(bounds=[-10, -10, -10, 10, 10, 10], resolution=0.05)
decoder_D = load_pretrained_mlp()
encoder_E = load_pretrained_pointnet()

for t in range(num_frames):
    D_t = get_depth_map(t)
    T_cw_t = get_pose(t)
    
    # Step 1: Encoding
    point_cloud = unproject_depth(D_t, K, T_cw_t)
    latent_codes = encoder_E(point_cloud)
    
    # Step 2: Local-Level Fusion
    for code, pos in zip(latent_codes, point_cloud):
        cell, key = global_volume.get_or_create(pos)
        cell[:] = (cell * W_c_t + code * (1.0 - W_c_t))
        
    # Step 3: Global-Level Fusion
    measurement_points = unproject_depth(D_t, K, T_cw_t)
    measurement_sdfs = depth_to_sdf(D_t, measurement_points)
    
    for iteration in range(K):
        loss = 0.0
        for pt in measurement_points:
            pred_sdf = trilinear_weight_and_decode(global_volume, pt, decoder_D)
            loss += (pred_sdf - measurement_sdfs[pt]) ** 2
        update_latent_codes(global_volume, loss)

mesh = marching_cubes(global_volume)
```

## Operating characteristics
*   **Time Complexity:** The method runs in near real-time, approximately 2 Hz without proper code optimization [S1].
*   **Memory Complexity:** The implicit neural volume allows surface extraction at any resolution via Marching Cubes without increasing memory usage, unlike TSDF volumes which discretize at a pre-defined resolution [S1].
*   **Strengths:** Improves reconstruction quality over existing methods; captures fine details that traditional volumetric fusion approaches tend to miss; scalable due to volume-based representation of local geometry [S1].
*   **Limitations:** Local-level fusion is susceptible to depth outliers because it only integrates measured surfaces and their surroundings without global context [S1]. Updating the global representation in the latent space using an additive scheme does not always lead to correct geometry [S1].
*   **When to use:** Dense 3D reconstruction from depth maps where global consistency and fine detail are required, and incremental integration is needed [S1].
*   **When not to use:** When robustness to severe depth outliers is critical without the global optimization step, or when real-time performance significantly faster than 2 Hz is required [S1].

## Background
Bi-level Neural Volume Fusion (BNV-Fusion) was introduced to address the limitations of TSDF volume representations in balancing robustness to noisy measurements and maintaining level of detail [S1]. It leverages recent advances in neural implicit representations and neural rendering for dense 3D reconstruction [S1]. The method was evaluated on 312 sequences of various indoor environments in the ScanNet dataset [S1]. It differs from NeuralFusion and DI-Fusion by optimizing latent codes via neural rendering for global consistency, rather than only integrating measurements in the latent code domain [S1]. It also differs from iMAP by using a volume of latent codes to encode local geometry, improving detail and scalability, whereas iMAP uses a single MLP that loses details and does not scale well [S1].
