# Neural Implicit Representation

Also called: Neural Implicit Mapping, Neural Scene Representation

## Overview
Neural Implicit Representation encodes a 3D scene as a continuous function (typically a Neural Radiance Field or Signed Distance Function) rather than a discrete voxel grid or point cloud, enabling high-fidelity novel view synthesis and dense SLAM mapping from sparse inputs [S1]. It solves the problem of joint camera pose estimation and 3D reconstruction by optimizing neural network parameters and camera poses simultaneously using photometric and geometric constraints, differing from explicit point-based siblings like Gaussian Splatting by requiring ray marching for rendering .

## Shared principles
The family relies on a neural network $F$ that maps spatial coordinates $\mathbf{x}$ to scene properties. For appearance, $F$ outputs color $\mathbf{c}$ and volume density $\sigma$ (or occupancy) . For geometry, $F$ may output a Signed Distance Function (SDF) value [S1]. Rendering is performed via volume rendering or ray marching: points are sampled along camera rays, properties are predicted by $F$, and results are aggregated using alpha compositing or weighted sums . Optimization jointly updates the network weights and camera poses $T_t$ to minimize photometric ($\ell_{rgb}$) and geometric ($\ell_{depth}$ or SDF) losses .

## Subtopics

### [Neural Radiance Field (NeRF) Representation](12096-neural-radiance-field-nerf-representation.md)
Encodes scenes as continuous volumetric functions or explicit Gaussian primitives. It supports both implicit neural field evaluation and explicit GPU-friendly Gaussian splatting, trading memory for speed while maintaining competitive training times.

### [Neural Implicit SLAM](22159-neural-implicit-slam.md)
Represents the scene as a continuous neural implicit function (NeRF or SDF) for joint localization and mapping. It differs from Gaussian Splatting by using continuous volumetric representation requiring ray marching, whereas Gaussian Splatting uses explicit, differentiable 3D Gaussians for object-order rendering.

### PIN-SLAM
A globally consistent SLAM system using a point-based implicit neural (PIN) representation [S1]. It replaces grid structures with neural feature points, offering spatial flexibility and elastic correction during loop closure [S1]. Mapping alternates with odometry; the mapping step uses a hybrid neural SDF representation with explicit neural points and implicit MLP decoders [S1]. Odometry is performed correspondence-free via second-order scan-to-map optimization [S1]. A sliding window replay buffer ensures stable incremental updates [S1]. Loop closures trigger pose graph optimization and elastic deformation of neural points, enabling consistent large-scale mapping [S1].

## Background
Neural Radiance Fields (NeRF) were introduced by Mildenhall et al. in 2020, establishing the paradigm of learning continuous volumetric representations for novel view synthesis [S1]. The approach has since been adapted for SLAM, where the implicit representation allows for dense, consistent mapping without explicit mesh extraction, as seen in systems like PIN-SLAM (2024) [S1].
