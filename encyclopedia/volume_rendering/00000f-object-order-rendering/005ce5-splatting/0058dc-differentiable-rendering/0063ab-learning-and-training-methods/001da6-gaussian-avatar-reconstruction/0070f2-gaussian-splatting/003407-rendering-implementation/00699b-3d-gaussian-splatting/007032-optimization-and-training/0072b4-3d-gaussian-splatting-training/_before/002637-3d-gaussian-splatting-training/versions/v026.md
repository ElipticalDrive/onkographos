# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the photometric difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity radiance fields from sparse or dense image collections by replacing implicit neural networks with explicit, differentiable geometric primitives [S5, unofficial]. Unlike NeRF-based methods which require iterative volume rendering per pixel, 3DGS training leverages a differentiable rasterizer that projects Gaussians to 2D screen space, enabling significantly faster convergence and real-time rendering capabilities [S2][S5, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images with known camera poses (rotation $R_{cw}$, translation $t_{cw}$, intrinsic matrix $K$) and initial 3D Gaussian parameters derived from Structure from Motion (SfM) [S2][S6, unofficial].
*   **Outputs:** Optimized Gaussian parameters: positions $\mathbf{p}_i$, rotations $q_i$, scales $\mathbf{s}_i$, opacities $\alpha_i$, and spherical harmonic coefficients $h_i$ [S6, unofficial].

**Data Structures:**
Each Gaussian primitive $i$ is stored with the following fields:
*   $\mathbf{p}_i \in \mathbb{R}^3$: 3D position (mean).
*   $q_i \in \mathbb{R}^4$: Unit quaternion for rotation.
*   $\mathbf{s}_i \in \mathbb{R}^3$: Scale (standard deviation) for each axis.
*   $\alpha_i \in [0, 1]$: Opacity.
*   $h_i$: Spherical Harmonic coefficients for view-dependent color.
*   $\mathbf{c}_i$: View-independent color (or derived from $h_i$).

**Parameters:**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `sh_degree`: Spherical harmonic degree. Default: 3 [S4, unofficial].
*   `sh_degree_interval`: Steps between increasing SH degree. Default: 1,000 [S4, unofficial].
*   `resolutionSchedule`: Steps between doubling image resolution. Default: 3,000 [S3, S4, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S3, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: $\min(15000, \text{numIters} / 2)$ [S3, unofficial].
*   `refineEvery`: Frequency of densification/pruning operations. Default: 500 [S3, S4, unofficial].
*   `densify_grad_thresh`: Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold for densification. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size splitting stops. Default: 4,000 [S4, unofficial].
*   `ssim_weight`: Weight for SSIM loss. Default: 0.2 [S3, S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].

**Algorithm:**

1.  **Initialization:**
    *   Initialize positions $\mathbf{p}_i$ from SfM point cloud (e.g., COLMAP) within normalized bounds $[-1, 1]$ [S2][S6, unofficial].
    *   Initialize scales $\mathbf{s}_i$ between 0 and 1 [S2].
    *   Initialize rotations $q_i$ as unit quaternions [S2].
    *   Initialize opacities $\alpha_i$ and colors $\mathbf{c}_i$ (or $h_i$) via `InitAttributes()` [S2].
    *   Set iteration counter $i = 0$ [S2].

2.  **Training Loop:**
    While $i < \text{numIters}$:
    1.  **Camera Sampling:** Select a training camera $V$ and its ground truth image $\hat{I}$ [S2]. Cameras are sampled via round-robin with periodic shuffling [S4, unofficial].
    2.  **Resolution Scaling:** Compute downscale factor based on current step $i$ and `resolutionSchedule` [S4, unofficial]. Retrieve ground truth image at this resolution [S4, unofficial].
    3.  **Rendering:**
        *   Project 3D Gaussians to 2D screen space using camera $V$.
        *   Sort Gaussians by depth.
        *   Alpha blend to produce rendered image $I$ [S2][S6, unofficial].
        *   Pixel color $\gamma_j$ for pixel $j$ is computed as:
            $$ \gamma_j = \sum_{k \in N} \alpha'_{kj} c_k \tau_{kj}, \quad \tau_{kj} = \prod_{m=1}^{k-1} (1 - \alpha'_{mj}) $$
            where $N$ is the set of Gaussians covering pixel $j$, sorted by depth, and $\alpha'_{kj}$ is the effective opacity [S6, unofficial].
    4.  **Loss Computation:**
        *   Compute loss $\mathcal{L}$ between $I$ and $\hat{I}$:
            $$ \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM} $$
            where $\lambda$ is `ssim_weight` (default 0.2) [S6, unofficial].
    5.  **Backpropagation:**
        *   Compute gradients $\frac{\partial \mathcal{L}}{\partial \theta}$ for all parameters $\theta \in \{\mathbf{p}, q, \mathbf{s}, \alpha, h\}$ using the chain rule [S6, unofficial].
        *   Key Jacobians include:
            $$ \frac{\partial \mathcal{L}}{\partial q_i} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial \sigma_i} \frac{\partial \sigma_i}{\partial q_i} $$
            $$ \frac{\partial \mathcal{L}}{\partial \mathbf{p}_{w,i}} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial u_i} \frac{\partial u_i}{\partial p_{c,i}} \frac{\partial p_{c,i}}{\partial p_{w,i}} + \dots \quad (\text{3 terms}) $$
            [S6, unofficial].
    6.  **Optimizer Step:**
        *   Update parameters using the Adam optimizer [S2][S6, unofficial].
    7.  **Adaptive Density Control (Refinement):**
        *   If $i$ is a refinement iteration (every `refineEvery` steps) and $i \ge \text{densifyFrom}$:
            *   For each Gaussian $i$:
                *   **Pruning:** If $\alpha_i < \epsilon$ or the Gaussian is too large (`IsTooLarge`), remove it [S2].
                *   **Densification:** If positional gradient $\|\nabla_{\mathbf{p}} \mathcal{L}\| > \tau_p$ (`densify_grad_thresh`):
                    *   **Over-reconstruction:** If covariance norm $\|\mathbf{S}\| > \tau_S$ (`densify_size_thresh`), **Split** the Gaussian into two [S2].
                    *   **Under-reconstruction:** Else, **Clone** the Gaussian [S2].
        *   If $i$ is a refinement iteration and $i \ge \text{densifyUntil}$, stop densification [S3, unofficial].
    8.  **Increment:** $i \leftarrow i + 1$ [S2].

**Pseudocode:**

```python
def train_3dgs(cameras, initial_gaussians, num_iters=30000, sh_degree=3, sh_degree_interval=1000, 
               resolution_schedule=3000, refine_every=500, densify_from=500, densify_until=-1,
               densify_grad_thresh=0.0002, densify_size_thresh=0.01, split_screen_size=0.05,
               stop_screen_size_at=4000, ssim_weight=0.2, max_gaussians=5000000):
    
    if densify_until == -1:
        densify_until = min(15000, num_iters // 2)
        
    gaussians = initial_gaussians  # Contains p, q, s, alpha, h
    camera_iterator = InfiniteRandomIterator(cameras)
    
    for step in range(1, num_iters + 1):
        # 1. Camera and Resolution Selection
        cam = camera_iterator.next()
        downscale_factor = compute_downscale_factor(step, resolution_schedule)
        gt_image = get_ground_truth(cam, downscale_factor)
        
        # 2. Rendering
        rendered_image = rasterize(gaussians, cam, downscale_factor)
        
        # 3. Loss Computation
        loss = compute_loss(rendered_image, gt_image, ssim_weight)
        
        # 4. Backpropagation and Optimization
        gradients = compute_gradients(loss, gaussians)
        gaussians = adam_update(gaussians, gradients)
        
        # 5. Adaptive Density Control
        if step % refine_every == 0 and step >= densify_from:
            gradients_per_gaussian = compute_gradient_magnitudes(gaussians, gradients)
            
            for g in gaussians:
                # Pruning
                if g.opacity < epsilon or is_too_large(g.scale):
                    remove_gaussian(g)
                    continue
                
                # Densification
                if step < densify_until and gradients_per_gaussian[g] > densify_grad_thresh:
                    if step < stop_screen_size_at and screen_size(g) > split_screen_size:
                        # Over-reconstruction: Split
                        split_gaussian(g)
                    else:
                        # Under-reconstruction: Clone
                        clone_gaussian(g)
                        
        # 6. SH Degree Increase
        if step % sh_degree_interval == 0 and step // sh_degree_interval <= sh_degree:
            increase_sh_degree(gaussians, step // sh_degree_interval)
            
    return gaussians
```

### HUGS
Uses a coarse-to-fine deformation module with linear blend skinning and local learning-based refinement to animate virtual human avatars from monocular video (50-100 frames) in ~30 minutes, achieving 20 FPS [S1].

### Wolf et al. Stereo Method
Trains 3DGS to render stereo-calibrated views, applies stereo depth estimation, and fuses dense depth maps via Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
Generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for densification and pruning during optimization [S8, unofficial].

### Cross-View Pruning Mechanism
Uses a Cross-View Consistency Loss and adaptive pruning to reduce redundancy. Selects adjacent view pairs with SSIM > 0.6, computes loss $L_{CVC}$, and prunes based on depth consistency $d^i_p < 0.01 \land d^j_p < 0.5 \lor d^i_p > 3\sigma$ [S9].

### Structure-View Co-learning
Combines structural and view-dependent gradients for joint optimization. Loss: $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$ [S9].

### Single-view Mini-batch Strategy
Organizes data per viewpoint and samples mini-batches from only a single viewpoint to improve training efficiency [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training typically requires 30,000 iterations [S3, S4, unofficial]. On GPU, training is significantly faster than NeRFs, often completing in minutes to hours depending on scene size [S2][S5, unofficial]. CPU execution is ~100x slower than GPU [S3, unofficial].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians. Default max is 5,000,000 [S3, unofficial]. Sinc splatting variants consume less memory than standard Gaussians [S7].
*   **Performance:** Achieves comparable image quality to NeRFs but with much faster training and real-time rendering speeds [S2]. On Replica dataset, SGS-SLAM achieves PSNR 34.15, SSIM 0.97, LPIPS 0.096 [S1].
*   **Strengths:** Real-time rendering, fast convergence, high fidelity.
*   **Limitations:** Sensitive to initialization; prone to "floaters" in empty space if not pruned; requires careful tuning of densification thresholds [S2].

## Background
3D Gaussian Splatting was introduced as a method for real-time radiance field rendering [9]. It initializes positions using sparse point clouds from SfM tools like COLMAP [21, S2]. The training process minimizes a combination of L1 and D-SSIM losses using the Adam optimizer [S6, unofficial]. It has been widely adopted for applications ranging from static scene reconstruction to SLAM and dynamic human avatars [S1].
