# Mesh Extraction via Poisson Reconstruction

Also called: Poisson Mesh Extraction, Poisson Reconstruction from Gaussians, Poisson Surface Reconstruction

## Overview
This method extracts a textured triangular mesh from an optimized 3D Gaussian Splatting (3DGS) scene by converting rendered 2D depth and normal maps into a 3D oriented point cloud, which is then reconstructed into a surface using Poisson surface reconstruction [S1][S2, unofficial]. It differs from implicit field-based siblings like [Gaussian Opacity Fields (GOF) Mesh Extraction](3692-gaussian-opacity-fields-gof-mesh-extraction.md) by relying on explicit geometric back-projection rather than density thresholding, and from [Distance-based Gaussian Splatting](7411-distance-based-gaussian-splatting.md) by not requiring distance-field regularization during training [G].

## How it works
**Inputs:** An optimized set of 3D Gaussians $\mathcal{G} = \{G_i\}_{i=1}^M$, where each $G_i$ has position $\mathbf{p}_i$, covariance $\mathbf{\Sigma}_i$, opacity $\alpha_i$, and color attributes [G]. A set of training views with known camera poses and intrinsics [G].

**Outputs:** A textured triangular mesh [S1][S2, unofficial].

**Data Structures:**
1. **Rendered Depth Map:** A 2D array $D \in \mathbb{R}^{H \times W}$ storing the median depth of splats projected to each pixel [S3, unofficial].
2. **Rendered Normal Map:** A 2D array $N \in \mathbb{R}^{H \times W \times 3}$ storing the surface normal in camera space for each pixel [S3, unofficial].
3. **Oriented Point Cloud:** A list of points $P = \{(\mathbf{x}_j, \mathbf{n}_j, \mathbf{c}_j)\}_{j=1}^K$, where $\mathbf{x}_j$ is the 3D position, $\mathbf{n}_j$ is the normal, and $\mathbf{c}_j$ is the color [S3, unofficial].

**Steps:**
1. **Render Depth:** For each training view, project all 3D Gaussians to 2D. The projected 2D covariance is computed as $\mathbf{\hat{\Sigma}}_i = J W \mathbf{\Sigma}_i W^T J^T$, where $J$ is the Jacobian of the affine approximation of the projection and $W$ is the rotation part of the extrinsic matrix [S3, unofficial]. Render the depth map $D$ by computing the median depth value of all splats contributing to each pixel [S3, unofficial].
2. **Derive Normals:** Convert the rendered depth map $D$ back into 3D space to derive the corresponding normal map $N$ [S3, unofficial].
3. **Back-Project to Point Cloud:** For each pixel $(u, v)$ in the training views:
   * Retrieve the depth $d = D[u, v]$ and normal $\mathbf{n}_{cam} = N[u, v]$ [S3, unofficial].
   * Unproject the pixel coordinates and depth to obtain the 3D position $\mathbf{x}$ in world space [G].
   * Transform the normal $\mathbf{n}_{cam}$ to world space [G].
   * Retrieve the color $\mathbf{c}$ from the RGB image at $(u, v)$ [S3, unofficial].
   * Add $(\mathbf{x}, \mathbf{n}, \mathbf{c})$ to the point cloud $P$ [S3, unofficial].
4. **Poisson Reconstruction:** Input the oriented colored point cloud $P$ into the Poisson extraction method to create the textured mesh [S3, unofficial].

**Parameters:**
* **Depth Level:** The depth of the octree used in Poisson reconstruction. Typical value: 9 [S1].
* **Point Count:** The number of points in the input cloud. Typical value: 2 million [S1].

**Edge Cases:** Not given in the sources [S1][S2, S3, unofficial].

## Subtopics

### Screened Poisson Equation Framework
A framework introduced by Mechrez et al. that effectively preserves structural fidelity while achieving stylization [S4].

## Operating characteristics
* **Time Complexity:** Not given in the sources [S1][S2, S3, unofficial].
* **Memory Complexity:** Not given in the sources [S1][S2, S3, unofficial].
* **Performance:** Fast and scalable, preserving details better than the Marching Cubes algorithm usually applied to extract meshes from Neural SDFs [S2, unofficial].
* **Strengths:** Simple pipeline leveraging existing Poisson solvers; produces watertight meshes [S1][S2, unofficial].
* **Limitations:** Not given in the sources [S1][S2, S3, unofficial].
* **When to use:** When a textured mesh is required from a 3DGS model and training data includes depth/normal priors [S1][S3, unofficial].
* **When not to use:** Not given in the sources [S1][S2, S3, unofficial].

## Background
Originated from the application of Poisson surface reconstruction [18] to 3DGS scenes, as described in DN-Splatter [S1] and SuGaR [S2, unofficial]. The method leverages geometric regularization from depth and normal priors during optimization to align Gaussian positions with the scene surface [S1].
