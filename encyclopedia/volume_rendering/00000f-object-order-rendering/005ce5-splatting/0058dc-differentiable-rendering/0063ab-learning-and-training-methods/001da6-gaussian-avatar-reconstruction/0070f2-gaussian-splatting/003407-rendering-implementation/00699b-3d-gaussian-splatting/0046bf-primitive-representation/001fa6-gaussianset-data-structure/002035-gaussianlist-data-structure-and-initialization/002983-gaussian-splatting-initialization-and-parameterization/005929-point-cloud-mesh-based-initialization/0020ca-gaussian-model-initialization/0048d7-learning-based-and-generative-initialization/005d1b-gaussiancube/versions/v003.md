# GaussianCube

Also called: Differentiable 3D Gaussian Splatting, GaussianCube representation

## Overview
GaussianCube is a scene representation method that utilizes an unstructured, explicit set of 3D Gaussians to achieve real-time, high-quality novel-view synthesis [S1, unofficial]. It solves the problem of efficient radiance field rendering by replacing continuous volumetric ray-marching with differentiable rasterization of anisotropic splats [S1, unofficial]. Unlike NeRF methods that rely on costly random sampling of continuous representations, GaussianCube uses discrete points that allow for flexible geometry creation and destruction without volumetric overhead [S1, unofficial]. It is distinct from its siblings, Volume Prior Initialization and SF-VAE, by explicitly optimizing the Gaussian parameters (position, covariance, opacity, SH) via interleaved density control rather than relying solely on latent space encoding or spherical folding priors for initialization [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of images of a static scene and corresponding camera poses calibrated via Structure-from-Motion (SfM) [S1, unofficial]. SfM produces a sparse point cloud used for initialization [S1, unofficial].
*   **Output:** A rendered image $C$ for a given camera view, and a trained set of 3D Gaussians representing the scene [S1, unofficial].

**Data Structures:**
Each 3D Gaussian $i$ is defined by the following parameters:
1.  **Position:** Mean vector $\mu_i \in \mathbb{R}^3$ [S1, unofficial].
2.  **Covariance:** A full 3D covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$, parameterized for optimization as:
    *   A scaling vector $s_i \in \mathbb{R}^3$ [S1, unofficial].
    *   A rotation quaternion $q_i \in \mathbb{R}^4$ (normalized to unit length) [S1, unofficial].
    *   The matrix is reconstructed as $\Sigma_i = R S S^T R^T$, where $R$ is the rotation matrix derived from $q_i$ and $S$ is the diagonal scaling matrix derived from $s_i$ [S1, unofficial].
3.  **Opacity:** A scalar $\alpha_i \in (0, 1)$, constrained via a sigmoid activation function during optimization [S1, unofficial].
4.  **Color:** Spherical Harmonics (SH) coefficients representing directional appearance [S1, unofficial].

**Initialization:**
1.  Initialize the set of Gaussians using the sparse point cloud from SfM [S1, unofficial].
2.  Estimate the initial covariance matrix as an isotropic Gaussian where the axes are equal to the mean distance to the closest three neighboring points [S1, unofficial].
3.  Apply an exponential decay scheduling technique to the positions [S1, unofficial].

**Rendering Algorithm:**
The rendering process uses a tile-based rasterizer that respects visibility order [S1, unofficial].

1.  **Projection:** For each Gaussian $i$, project the 3D covariance $\Sigma_i$ to 2D camera space.
    *   Compute the viewing transformation $W$ and the Jacobian $J$ of the affine approximation of the projective transformation [S1, unofficial].
    *   Compute the 2D covariance: $\Sigma' = J W \Sigma_i W^T J^T$ [S1, unofficial].
    *   Extract the $2 \times 2$ upper-left submatrix of $\Sigma'$ as the 2D covariance $\Sigma_{2D}$ [S1, unofficial].
2.  **Sorting:** Sort all Gaussians by depth (distance to camera center) within each tile [S1, unofficial].
3.  **Rasterization:** For each pixel in a tile, iterate through the sorted Gaussians overlapping the pixel.
    *   Compute the opacity contribution $\alpha_i$ for the Gaussian at the pixel location. The image formation model is equivalent to NeRF's volume rendering:
        $$C = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i$$
        where $\mathbf{c}_i$ is the color of the $i$-th Gaussian evaluated at the pixel's direction using SH coefficients [S1, unofficial].
    *   The opacity $\alpha_i$ is derived from the density $\sigma_i$ and step size $\delta_i$ (or directly from the Gaussian value at the pixel):
        $$\alpha_i = (1 - \exp(-\sigma_i \delta_i))$$
    *   The transmittance $T_i$ is the accumulated transparency from previous splats:
        $$T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$$
    *   Accumulate the color contribution $T_i \alpha_i \mathbf{c}_i$ to the pixel color [S1, unofficial].
4.  **Backward Pass:** Compute gradients by tracking accumulated transmittance values for all splats in a pixel, allowing gradients to flow to all contributing Gaussians [S1, unofficial].

**Optimization:**
The method uses Stochastic Gradient Descent (SGD) with custom CUDA kernels [S1, unofficial]. The loss function combines L1 and D-SSIM terms:
$$\mathcal{L} = (1 - \lambda)\mathcal{L}_1 + \lambda\mathcal{L}_{\text{D-SSIM}}$$
with $\lambda = 0.2$ [S1, unofficial].

The optimization interleaves parameter updates with adaptive density control steps:
1.  **Add:** Create new Gaussians in regions with high reprojection error or low opacity [S1, unofficial].
2.  **Clone:** Duplicate Gaussians in high-error regions to increase density [S1, unofficial].
3.  **Prune:** Remove Gaussians with opacity below a threshold [S1, unofficial].
4.  **Split:** Split Gaussians in high-error regions to refine geometry [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def initialize_gaussians(sfm_points):
    """
    Initialize 3D Gaussians from SfM sparse point cloud.
    Returns list of Gaussian objects with pos, scale, rot, opacity, sh_coeffs.
    """
    gaussians = []
    for point in sfm_points:
        g = Gaussian()
        g.pos = point.position
        # Estimate initial isotropic covariance based on neighbor distances
        dists = compute_distances_to_closest_neighbors(point, sfm_points, k=3)
        g.scale = np.mean(dists) * np.ones(3)
        g.rot = np.array([1.0, 0.0, 0.0, 0.0]) # Identity quaternion
        g.opacity = 0.1 # Initial low opacity
        g.sh_coeffs = np.zeros(12) # Default SH coefficients (order 1)
        gaussians.append(g)
    return gaussians

def project_covariance(gaussian, camera_matrix, view_matrix):
    """
    Project 3D covariance to 2D camera space.
    """
    # Reconstruct 3D covariance from scale and rotation
    R = quaternion_to_rotation_matrix(gaussian.rot)
    S = np.diag(gaussian.scale)
    Sigma_3d = R @ S @ S.T @ R.T
    
    # Compute Jacobian J of projective transformation and View matrix W
    # Note: J depends on camera intrinsics and Gaussian position
    J = compute_jacobian(camera_matrix, gaussian.pos)
    W = view_matrix
    
    # Projected covariance
    Sigma_prime = J @ W @ Sigma_3d @ W.T @ J.T
    
    # Return 2x2 upper-left submatrix
    return Sigma_prime[:2, :2]

def render_tile(gaussians_in_tile, camera_matrix, view_matrix, image_width, image_height, tile_size):
    """
    Render a single tile using alpha blending of sorted Gaussians.
    """
    # Sort Gaussians by depth (z-coordinate in camera space)
    sorted_gaussians = sort_by_depth(gaussians_in_tile, view_matrix)
    
    # Initialize tile output buffer
    tile_color = np.zeros((tile_size, tile_size, 3))
    tile_alpha = np.zeros((tile_size, tile_size))
    
    for g in sorted_gaussians:
        # Project covariance
        Sigma_2d = project_covariance(g, camera_matrix, view_matrix)
        
        # Compute bounding box of the 2D Gaussian in pixel space
        bbox = compute_bounding_box(g.pos, Sigma_2d, camera_matrix)
        
        # Clip bbox to tile boundaries
        bbox = clip_to_tile(bbox, tile_size)
        
        # Rasterize the Gaussian into the tile
        for y in range(bbox.y_min, bbox.y_max):
            for x in range(bbox.x_min, bbox.x_max):
                # Compute 2D position relative to Gaussian center
                pixel_pos = get_pixel_center(x, y)
                dist_sq = compute_squared_distance(pixel_pos, g.pos_2d, Sigma_2d)
                
                # Compute opacity alpha_i
                # sigma_i is the Gaussian density at the pixel
                sigma_i = np.exp(-0.5 * dist_sq)
                delta_i = 1.0 # Simplified step size for point-based rendering
                alpha_i = 1.0 - np.exp(-sigma_i * delta_i)
                
                # Get color from SH coefficients
                color_i = evaluate_sh(g.sh_coeffs, g.view_direction)
                
                # Update pixel color and alpha
                # T_i is implicitly handled by the accumulated alpha buffer
                current_alpha = tile_alpha[y, x]
                transmittance = 1.0 - current_alpha
                
                contribution = transmittance * alpha_i * color_i
                tile_color[y, x] += contribution
                tile_alpha[y, x] += transmittance * alpha_i
                
    return tile_color

def optimize_gaussians(gaussians, images, cameras, loss_weights):
    """
    Interleaved optimization of Gaussian properties and density control.
    """
    lambda_dssim = 0.2
    for iteration in range(num_iterations):
        # 1. Forward pass: Render images
        rendered_images = []
        for camera in cameras:
            # Assign Gaussians to tiles
            tiles = assign_gaussians_to_tiles(gaussians, camera)
            tile_outputs = []
            for tile in tiles:
                out = render_tile(tile.gaussians, camera.intrinsics, camera.extrinsics, ...)
                tile_outputs.append(out)
            rendered_images.append(compose_tiles(tile_outputs))
        
        # 2. Compute Loss
        loss = 0
        for rendered, target in zip(rendered_images, images):
            l1 = np.mean(np.abs(rendered - target))
            dssim = compute_dssim(rendered, target)
            loss += (1 - lambda_dssim) * l1 + lambda_dssim * dssim
        
        # 3. Backward pass: Compute gradients
        gradients = compute_gradients(loss, gaussians, rendered_images, images)
        
        # 4. Update parameters using SGD
        for g in gaussians:
            g.pos -= learning_rate * gradients.pos
            g.scale -= learning_rate * gradients.scale
            g.rot -= learning_rate * gradients.rot
            g.opacity -= learning_rate * gradients.opacity
            g.sh_coeffs -= learning_rate * gradients.sh_coeffs
            
            # Apply constraints
            g.opacity = sigmoid(g.opacity) # Constrain to (0, 1)
            g.scale = np.exp(g.scale)     # Constrain to positive values
            g.rot = normalize_quaternion(g.rot)
            
        # 5. Adaptive Density Control
        # Add, clone, prune, split Gaussians based on error and opacity thresholds
        gaussians = adaptive_density_control(gaussians, rendered_images, images, cameras)
```

## Operating characteristics
*   **Time Complexity:** Rendering is $O(N)$ where $N$ is the number of Gaussians, but optimized via tile-based sorting and rasterization to be highly efficient on GPU [S1, unofficial]. Training time is competitive with NeRF methods but allows real-time rendering during training [S1, unofficial].
*   **Memory Complexity:** The representation size is typically 1-5 million Gaussians for tested scenes [S1, unofficial]. Each Gaussian stores position (12 bytes), scale (12 bytes), rotation (16 bytes), opacity (4 bytes), and SH coefficients (variable, e.g., 48 bytes for order 1). Total memory is proportional to $N$.
*   **Performance:** Achieves real-time rendering ($\ge 30$ fps) at 1080p resolution on standard GPUs [S1, unofficial].
*   **Strengths:** High visual quality, real-time rendering speed, explicit representation allows easy manipulation (add/remove/move), no need for MVS data (only SfM) [S1, unofficial].
*   **Limitations:** Requires careful tuning of density control parameters; large scenes may require significant VRAM for millions of Gaussians; anisotropic splatting can introduce artifacts if not properly sorted [S1, unofficial].
*   **When to use:** When real-time novel-view synthesis is required and high-quality results are needed from SfM data alone.
*   **When not to use:** When memory is extremely constrained and a compact implicit representation is preferred, or when dynamic scenes with complex temporal coherence are the primary focus (though extensions exist) [S1, unofficial].

## Background
Gaussian Splatting (the method underlying GaussianCube) was introduced by Kerbl, Kopanas, Leimkühler, and Drettos in 2023 [S1, unofficial]. It combines the best of point-based rendering and neural radiance fields, using explicit 3D Gaussians for efficient rasterization while preserving the differentiable volumetric properties of NeRFs [S1, unofficial]. The term "GaussianCube" appears in subsequent literature referring to training 3D diffusion models based on a GaussianCube representation converted from Gaussians via voxelization and optimal transport [S2, unofficial].
