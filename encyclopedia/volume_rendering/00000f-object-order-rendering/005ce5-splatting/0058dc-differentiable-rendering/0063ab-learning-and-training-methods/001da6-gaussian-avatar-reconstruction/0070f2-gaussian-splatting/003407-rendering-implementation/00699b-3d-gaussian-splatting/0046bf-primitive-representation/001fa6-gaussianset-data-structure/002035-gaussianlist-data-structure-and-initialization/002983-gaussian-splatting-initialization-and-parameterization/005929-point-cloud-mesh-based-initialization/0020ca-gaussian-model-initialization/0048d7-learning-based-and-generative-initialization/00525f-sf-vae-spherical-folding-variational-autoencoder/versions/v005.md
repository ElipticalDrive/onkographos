# SF-VAE (Spherical Folding Variational Autoencoder)
Also called: SFVAE, Spherical Folding VAE

## Overview
SF-VAE is a learning-based initialization method that encodes 3D Gaussian parameters into a latent space and decodes them using a spherical folding grid to reconstruct geometry and color [S1, unofficial]. It replaces random point placement with a structured, prior-driven initialization by mapping input Gaussian distributions to a compact latent vector, which is then decoded into a set of Gaussians [S1, unofficial]. It differs from [Volume Prior Initialization](10162-volume-prior-initialization.md) by using a neural decoder with a specific spherical folding mechanism rather than direct volume grid sampling, and from [GaussianCube](17297-gaussiancube.md) by operating on a continuous latent space decoded via folding rather than discrete voxel-based representations.

## How it works
**Inputs and Outputs:**
The model takes a set of 3D Gaussian parameters as input. Each sample is represented as a 7-dimensional vector containing centroid coordinates (3), scale parameters (3), and opacity (1) [S1, unofficial]. The output is a reconstructed set of Gaussians (geometry and potentially color) and a latent vector $z$ [S1, unofficial].

**Data Structures:**
*   **SFModel Input:** A tensor of shape $(N, 7)$, where $N$ is the batch size. The 7 features correspond to $[x, y, z, s_x, s_y, s_z, \alpha]$ (centroid, scale, opacity) [S1, unofficial].
*   **Latent Space:** A vector $z$ of dimension `embedding_dim` (default 32) [S1, unofficial].
*   **SFDecoder Grid:** A 2D grid of shape $[D^2, 2]$, where $D$ is `grid_dim` (default 24). This grid represents local coordinates on a sphere, repeated for the batch size [S1, unofficial].

**Parameters:**
*   `embedding_dim`: Dimensionality of the latent feature vector $z$. Default: 32 [S1, unofficial].
*   `grid_dim`: Dimension of the spherical folding grid. Default: 24 [S1, unofficial].
*   `norm_weight`: Weight for the normalization loss term. Default: 0 [S1, unofficial].
*   `geo_weight`: Weight for the Chamfer loss term. Default: 0.5 [S1, unofficial].

**Algorithm Steps:**
1.  **Encoding:** The input Gaussian parameters are passed through an encoder network to produce the mean $\mu$ and log-variance $\log \sigma^2$ of the latent distribution.
2.  **Reparameterization:** A latent vector $z$ is sampled from $\mathcal{N}(\mu, \sigma^2)$ using the reparameterization trick: $z = \mu + \sigma \odot \epsilon$, where $\epsilon \sim \mathcal{N}(0, I)$ [S1, unofficial].
3.  **Decoding (Spherical Folding):** The latent vector $z$ is passed to the SFDecoder. The decoder utilizes a spherical folding grid to map the latent features to 3D space. The grid coordinates are used to interpolate or project the latent features into reconstructed Gaussian parameters [S1, unofficial].
4.  **Loss Calculation:**
    *   **Chamfer Loss:** Compute the Chamfer distance between the input points and the reconstructed points. The loss is weighted by `geo_weight` (0.5) [S1, unofficial].
    *   **KL Divergence:** If in VAE mode, compute the KL divergence loss between the latent distribution and a standard normal distribution:
        $$
        L_{KL} = -0.5 \times \frac{1}{N} \sum_{i=1}^{N} \left( 1 + \log \sigma_i^2 - \mu_i^2 - \sigma_i^2 \right)
        $$
        where $N$ is the batch size [S1, unofficial].
    *   **Normalization Loss:** If `norm_weight` > 0, apply a normalization loss term [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SFVAE(nn.Module):
    def __init__(self, embedding_dim=32, grid_dim=24, norm_weight=0.0, geo_weight=0.5):
        super().__init__()
        self.embedding_dim = embedding_dim
        self.grid_dim = grid_dim
        self.norm_weight = norm_weight
        self.geo_weight = geo_weight
        
        # Encoder: Maps 7D input to latent mean and log-variance
        # Input shape: (Batch, 7)
        self.encoder = nn.Sequential(
            nn.Linear(7, 64),
            nn.ReLU(),
            nn.Linear(64, 64),
            nn.ReLU(),
            nn.Linear(64, 2 * embedding_dim) # Output: [mu, logvar]
        )
        
        # Decoder: Maps latent vector to reconstructed Gaussians
        # Uses spherical folding grid internally
        self.decoder = SFDecoder(embedding_dim, grid_dim)
        
        # Loss criterion
        self.criterion = ChamferLoss()

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std

    def forward(self, x):
        """
        x: Input Gaussian parameters, shape (Batch, 7)
        """
        # Encode
        params = self.encoder(x)
        mu = params[:, :self.embedding_dim]
        logvar = params[:, self.embedding_dim:]
        
        # Sample latent vector
        z = self.reparameterize(mu, logvar)
        
        # Decode
        reconstructed_x = self.decoder(z)
        
        return reconstructed_x, mu, logvar

    def loss(self, x, reconstructed_x, mu, logvar):
        # Chamfer Loss
        chamfer_loss = self.criterion(x[:, :3], reconstructed_x[:, :3]) # Assuming first 3 dims are xyz
        chamfer_loss = chamfer_loss * self.geo_weight
        
        # KL Divergence Loss
        kl_loss = -0.5 * torch.mean(1 + logvar - mu.pow(2) - logvar.exp())
        
        # Normalization Loss (if enabled)
        norm_loss = torch.tensor(0.0, device=x.device)
        if self.norm_weight > 0:
            # Placeholder for specific normalization logic not detailed in source
            # [G] Assuming a standard L2 normalization penalty on the reconstructed geometry
            norm_loss = torch.mean(reconstructed_x[:, :3].pow(2))
            
        total_loss = chamfer_loss + kl_loss + self.norm_weight * norm_loss
        return total_loss

class SFDecoder(nn.Module):
    def __init__(self, embedding_dim, grid_dim):
        super().__init__()
        self.grid_dim = grid_dim
        # Create spherical folding grid
        # Grid shape: (grid_dim^2, 2) representing local coordinates
        self.grid = self._create_spherical_grid(grid_dim)
        
        # Decoder network
        self.decoder_net = nn.Sequential(
            nn.Linear(embedding_dim + 2, 64), # Concatenate latent z and grid coords
            nn.ReLU(),
            nn.Linear(64, 64),
            nn.ReLU(),
            nn.Linear(64, 7) # Output 7D Gaussian params
        )

    def _create_spherical_grid(self, dim):
        # [G] Generate a grid of points on a sphere. 
        # The source mentions a 2D grid of shape [grid_dim^2, 2] representing local coordinates.
        # This likely refers to a parameterization of the sphere (e.g., theta, phi)
        # or a 2D texture map folded onto a sphere.
        # For implementation, we generate a regular grid in 2D and map to sphere.
        u = torch.linspace(0, 1, dim)
        v = torch.linspace(0, 1, dim)
        u, v = torch.meshgrid(u, v, indexing='ij')
        grid_2d = torch.stack([u, v], dim=-1).reshape(-1, 2)
        return grid_2d

    def forward(self, z):
        """
        z: Latent vector, shape (Batch, embedding_dim)
        """
        batch_size = z.shape[0]
        # Repeat grid for batch size
        grid = self.grid.repeat(batch_size, 1, 1) # Shape: (Batch, grid_dim^2, 2)
        
        # Expand z to match grid dimensions for broadcasting
        # z: (Batch, embedding_dim) -> (Batch, 1, embedding_dim)
        z_expanded = z.unsqueeze(1)
        
        # Concatenate z and grid coordinates
        # Input to decoder: (Batch, grid_dim^2, embedding_dim + 2)
        input_features = torch.cat([z_expanded, grid], dim=-1)
        
        # Decode
        reconstructed = self.decoder_net(input_features) # Shape: (Batch, grid_dim^2, 7)
        
        # [G] The source implies the output is "Reconstructed points". 
        # It is unclear if the entire grid is returned or if a subset/aggregation is used.
        # Assuming the full grid of reconstructed Gaussians is returned for loss calculation.
        return reconstructed
```

**Edge Cases and Pitfalls:**
*   **Precision:** The use of `logvar` requires ensuring numerical stability when computing `exp(logvar)` and `log` operations.
*   **Boundaries:** The spherical folding grid must cover the relevant angular space. Degenerate inputs (e.g., zero scale) may cause issues in the decoder if not handled.
*   **Initialization:** The random seed should be set for reproducibility [S1, unofficial].

## Subtopics

### Gaussian VAE
A Variational Auto-encoder that compresses Gaussian Splatting Functions into a regularized latent space, mapping functions of each shape into one latent vector [S2]. It uses an Encoder and Decoder with Triplane representation [S2]. Unlike SF-VAE which uses a spherical folding grid, Gaussian VAE (as part of DiffGS) uses Triplanes to represent the Gaussian probability, colors, and transforms separately, enabling integration with a Latent Diffusion Model (LDM) for generative tasks [S2].

## Operating characteristics
*   **Time Complexity:** Depends on the depth of the encoder/decoder networks and the size of the spherical folding grid ($D^2$). Encoding is $O(N \cdot d_{in} \cdot d_{hidden})$, decoding is $O(N \cdot D^2 \cdot (d_{latent} + 2) \cdot d_{hidden})$.
*   **Memory Complexity:** $O(N \cdot D^2 \cdot 7)$ for storing the reconstructed grid, plus $O(N \cdot d_{latent})$ for the latent vector.
*   **Strengths:** Provides a structured, learnable initialization that can capture complex geometric priors. The spherical folding mechanism allows for efficient decoding of angular information.
*   **Limitations:** Requires training data to learn the prior. The choice of `grid_dim` affects resolution and memory usage.
*   **When to use:** When a structured, data-driven initialization is preferred over random or uniform sampling, and when the geometry can be effectively represented by a spherical folding prior.

## Background
SF-VAE was introduced in the unofficial repository `cilix-ai/gs-embedding` [S1, unofficial]. It is part of the family of learning-based initialization methods for 3D Gaussian Splatting, aiming to improve reconstruction quality by leveraging neural networks to predict Gaussian parameters from a latent space.
