# Surface-Constrained Gaussian Splatting

Also called: Surface-Anchor Gaussian Splatting

## Overview
Surface-Constrained Gaussian Splatting is a method for initializing and regularizing 3D Gaussian Splatting representations using a pre-existing mesh surface to eliminate floating artifacts and improve geometric fidelity [S1, unofficial]. It differs from standard 3D Gaussian Splatting by anchoring Gaussian means to mesh vertices and enforcing planar constraints via specific loss functions, whereas siblings like [Mesh-adsorbed Gaussian](20320-mesh-adsorbed-gaussian.md) may use different adsorption mechanisms and [Surface Reconstruction via SDF](22162-surface-reconstruction-via-sdf.md) relies on signed distance fields rather than explicit mesh anchoring.

## How it works
**Inputs:**
- A triangle mesh $M$ with vertices $V$ and triangles $T$.
- Initial RGB colors for each Gaussian (typically derived from the mesh texture or vertex colors).
- Training images and camera poses.

**Outputs:**
- A set of $N$ 3D Gaussians $\{G_i\}_{i=1}^N$ optimized for rendering.

**Data Structures:**
- **Gaussian Attributes:** For each Gaussian $i$:
  - Mean $\boldsymbol{\mu}_i \in \mathbb{R}^3$
  - Covariance $\boldsymbol{\Sigma}_i$ parameterized by rotation quaternion $\mathbf{q}_i \in \mathbb{R}^4$ and scale vector $\mathbf{s}_i \in \mathbb{R}^3$.
  - Opacity $\alpha_i \in [0, 1]$.
  - Spherical Harmonics coefficients $\mathbf{c}_i$ (initially only $SH_0$ is non-zero).
- **Mesh Cache:**
  - Triangle list for area-weighted sampling.
  - KNN structure for nearest neighbor queries (used for scale initialization and Laplacian smoothing).
  - Mesh point cache for surface anchor loss (updated every 50 steps).

**Initialization Steps:**
1. **Sample Points:** Sample points uniformly on the mesh surface using area-weighted sampling. For each triangle, generate random barycentric coordinates $bary = [1 - \sqrt{r_1}, \sqrt{r_1}(1 - r_2), \sqrt{r_1}r_2]$ where $r_1, r_2 \sim U[0,1]$ [S1, unofficial].
2. **Initialize Means:** Set $\boldsymbol{\mu}_i$ to the sampled 3D points.
3. **Initialize Scales:** Compute KNN distances for each point. Set scales as:
   $$ s_{xy} = \log(\text{avg\_dist} \times 1.0) $$
   $$ s_{z} = \log(\text{avg\_dist} \times 0.2) $$
   This creates flat discs that overlap with neighbors [S1, unofficial].
4. **Initialize Rotations:** Compute quaternions aligning the Gaussian Z-axis to the surface normal at $\boldsymbol{\mu}_i$. Use the half-angle Rodrigues formula:
   $$ q_w = \sqrt{\frac{1+\cos\theta}{2}}, \quad \mathbf{q}_{xyz} = \sqrt{\frac{1-\cos\theta}{2}} \cdot \text{axis} $$
   where $\theta$ is the angle between the initial Z-axis and the surface normal. **Pitfall:** If the normal is anti-aligned ($\cos\theta < -0.999$), set $\mathbf{q} = [0, 1, 0, 0]$ (180-degree rotation around X) to avoid numerical instability [S1, unofficial].
5. **Initialize Opacity:** Set $\alpha_i = 0.5$ to prevent premature pruning during early training [S1, unofficial].
6. **Initialize Colors:** Compute $SH_0$ from the initial RGB colors using `rgb_to_sh` and set higher-order SH coefficients to zero [S1, unofficial].

**Training Steps:**
1. **Render:** Render the scene using standard differentiable Gaussian splatting.
2. **Compute Losses:**
   - **Reconstruction Loss:** Standard L1/SSIM loss between rendered and ground truth images.
   - **Flatness Loss:** Penalize the ratio of the thinnest axis scale to the middle axis scale to enforce disc-like shapes [S1, unofficial].
   - **Normal Alignment Loss:** Penalize deviation of the thin axis (Z-axis in local space) from the surface normal:
     $$ L_{normal} = 1 - |\text{dot}(\text{thin\_axis}, \text{normal})| $$
   - **Surface Anchor Loss:** Compute L2 distance between Gaussian means $\boldsymbol{\mu}_i$ and the nearest points on the mesh. This cache is updated every 50 training steps [S1, unofficial].
3. **Regularization:** Apply Laplacian smoothing to scales, quaternions, and $SH_0$ using k-nearest neighbors with a specified strength parameter [S1, unofficial].
4. **Adaptive Control:** Spawn new splats at pixels with high frequency gaps or low alpha using weighted multinomial sampling [S1, unofficial].

**Pseudocode:**

```python
import torch
import numpy as np

def initialize_gaussians_from_mesh(mesh, num_samples):
    """
    Initialize Gaussians on a mesh surface.
    Args:
        mesh: Object with triangles (V, 3, 3) and normals (V, 3).
        num_samples: Number of Gaussians to create.
    Returns:
        means, scales, quaternions, opacities, sh_coeffs
    """
    # 1. Sample points on mesh
    triangles = mesh.triangles # (T, 3, 3)
    triangle_areas = compute_triangle_areas(triangles)
    triangle_probs = triangle_areas / triangle_areas.sum()
    
    sampled_indices = np.random.choice(len(triangles), size=num_samples, p=triangle_probs)
    selected_triangles = triangles[sampled_indices]
    
    # Barycentric coordinates
    r1 = np.random.uniform(0, 1, num_samples)
    r2 = np.random.uniform(0, 1, num_samples)
    bary = np.stack([1 - np.sqrt(r1), np.sqrt(r1) * (1 - r2), np.sqrt(r1) * r2], axis=1)
    
    # Interpolate vertices
    v0 = selected_triangles[:, 0]
    v1 = selected_triangles[:, 1]
    v2 = selected_triangles[:, 2]
    means = (bary[:, 0:1] * v0 + bary[:, 1:2] * v1 + bary[:, 2:3] * v2)
    
    # 2. Initialize Scales using KNN
    # Compute KNN distances (simplified for illustration)
    avg_dist = compute_knn_distance(means, k=5)
    scales_xy = np.log(avg_dist * 1.0)
    scales_z = np.log(avg_dist * 0.2)
    scales = np.stack([scales_xy, scales_xy, scales_z], axis=1)
    
    # 3. Initialize Rotations
    # Get surface normals at sampled points (interpolate from vertex normals)
    normals = interpolate_normals(mesh.vertex_normals, sampled_indices, bary)
    # Align Z-axis (0,0,1) to normal
    quaternions = align_z_to_vector(normals)
    
    # 4. Initialize Opacity
    opacities = np.full(num_samples, 0.5)
    
    # 5. Initialize Colors (placeholder)
    sh_coeffs = np.zeros((num_samples, 3, 16)) # Only SH0 used initially
    # sh_coeffs[:, :, 0] = rgb_to_sh(initial_colors)
    
    return means, scales, quaternions, opacities, sh_coeffs

def align_z_to_vector(vectors):
    """
    Compute quaternion rotating Z-axis (0,0,1) to vectors.
    Handles anti-alignment.
    """
    z_axis = np.array([0, 0, 1])
    # Normalize vectors
    norms = np.linalg.norm(vectors, axis=1, keepdims=True)
    v_norm = vectors / norms
    
    # Dot product
    cos_theta = np.sum(z_axis * v_norm, axis=1, keepdims=True)
    
    # Cross product
    cross = np.cross(z_axis, v_norm)
    
    # Handle anti-alignment
    anti_aligned = cos_theta < -0.999
    if np.any(anti_aligned):
        # Set quaternion to [0, 1, 0, 0] for anti-aligned points
        # w, x, y, z
        quaternions = np.zeros((len(vectors), 4))
        quaternions[anti_aligned.squeeze()] = [0, 1, 0, 0]
        
        # Compute for non-anti-aligned
        non_aligned_mask = ~anti_aligned.squeeze()
        v_non_aligned = v_norm[non_aligned_mask]
        cos_non_aligned = cos_theta[non_aligned_mask]
        cross_non_aligned = cross[non_aligned_mask]
        
        w = np.sqrt((1 + cos_non_aligned.squeeze()) / 2)
        sin_half = np.sqrt((1 - cos_non_aligned.squeeze()) / 2)
        axis = cross_non_aligned / (np.linalg.norm(cross_non_aligned, axis=1, keepdims=True) + 1e-8)
        xyz = sin_half * axis
        
        quaternions[non_aligned_mask] = np.stack([w, xyz[:, 0], xyz[:, 1], xyz[:, 2]], axis=1)
        return quaternions
    else:
        w = np.sqrt((1 + cos_theta.squeeze()) / 2)
        sin_half = np.sqrt((1 - cos_theta.squeeze()) / 2)
        axis = cross / (np.linalg.norm(cross, axis=1, keepdims=True) + 1e-8)
        xyz = sin_half * axis
        return np.stack([w, xyz[:, 0], xyz[:, 1], xyz[:, 2]], axis=1)

def compute_triangle_areas(triangles):
    """Compute area of each triangle."""
    v0 = triangles[:, 0]
    v1 = triangles[:, 1]
    v2 = triangles[:, 2]
    cross = np.cross(v1 - v0, v2 - v0)
    return 0.5 * np.linalg.norm(cross, axis=1)

    """Interpolate vertex normals using barycentric coordinates."""
    # triangle_indices maps to the triangle index in the mesh
    # barycentric_coords are [w0, w1, w2]
    # vertex_normals are (V, 3)
    # triangles are (T, 3, 3) -> indices of vertices
    tri_verts = mesh.triangle_vertex_indices[triangle_indices] # (N, 3)
    v0_n = vertex_normals[tri_verts[:, 0]]
    v1_n = vertex_normals[tri_verts[:, 1]]
    v2_n = vertex_normals[tri_verts[:, 2]]
    
    normals = (barycentric_coords[:, 0:1] * v0_n +

    return normals
```

## Operating characteristics
- **Time Complexity:** Initialization is $O(N \log N)$ due to KNN queries. Training adds overhead for surface anchor loss computation (nearest mesh point query) every 50 steps.
- **Memory Complexity:** Requires storing the mesh geometry and a cache of nearest mesh points for all Gaussians.
- **Strengths:** Effectively removes floating artifacts common in standard 3DGS when reconstructing scenes with clear surfaces. Improves geometric consistency.
- **Limitations:** Requires a high-quality input mesh. Performance degrades if the mesh is noisy or incomplete. The surface anchor loss may constrain the Gaussians too rigidly, preventing them from adapting to view-dependent effects or slight misalignments.
- **When to use:** When a reliable mesh is available and geometric accuracy is prioritized over pure photometric fidelity.
- **When not to use:** For scenes without a clear surface structure or when the mesh quality is poor.

## Background
Surface-Constrained Gaussian Splatting was introduced as an unofficial extension to 3D Gaussian Splatting to address the issue of floating artifacts in rendered scenes [S1, unofficial]. It builds on the standard 3DGS representation but incorporates explicit geometric constraints derived from a mesh. The method is part of a broader effort to integrate explicit geometry into differentiable rendering pipelines.
