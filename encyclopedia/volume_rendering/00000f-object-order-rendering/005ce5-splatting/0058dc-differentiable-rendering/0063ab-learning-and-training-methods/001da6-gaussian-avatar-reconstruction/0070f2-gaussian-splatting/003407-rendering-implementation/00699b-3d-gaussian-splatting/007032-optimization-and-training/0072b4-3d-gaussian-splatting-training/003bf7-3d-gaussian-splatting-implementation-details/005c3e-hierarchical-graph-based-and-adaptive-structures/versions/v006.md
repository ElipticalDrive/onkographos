# Hierarchical, Graph-Based, and Adaptive Structures

Also called: Adaptive Spatial Partitioning, Gaussian Mixture Trees, Elastic Inference, Scale-Adaptive Splatting

## Overview
This family of methods extends standard 3D Gaussian Splatting (3DGS) by introducing structural organization, adaptive scaling, or dynamic selection to address limitations in memory efficiency, rendering fidelity at varying scales, and large-scale scene representation. While standard 3DGS treats primitives as independent entities, these methods impose hierarchies, graphs, or learned selectors to optimize storage, enable real-time performance on constrained hardware, or eliminate aliasing artifacts. They differ from [Pruning and Density Control](16215-pruning-and-density-control.md) by using learned or structural criteria rather than fixed heuristics, and from [Rendering Implementation and Acceleration](21069-rendering-implementation-and-acceleration.md) by focusing on the semantic or geometric organization of the primitives themselves rather than just the rasterization pipeline.

## Shared principles
The core principle across this family is the modification of the standard 3DGS primitive set $\{G_i\}$ through external constraints or structures.
1.  **Structural Connectivity:** Methods like [TraGraph-GS](14454-tragraph-gs.md) and [Surface-Aware Splat Graph Construction](22007-surface-aware-splat-graph-construction.md) define edges between Gaussians based on feature matching or geometric intersection, rather than relying solely on spatial proximity for rendering.
2.  **Hierarchical Aggregation:** Methods like [Gaussian Mixture Tree Construction](16717-gaussian-mixture-tree-construction.md) and [Hierarchical 3D Gaussian BVH Construction](minor-variants) merge primitives into parent nodes using statistical or spatial criteria to create multi-level representations.
3.  **Adaptive Deformation:** Methods like [Mipmap-GS](16893-mipmap-gs.md) and [Laplacian-Based Deformation](minor-variants) modify Gaussian parameters (position, scale, covariance) dynamically based on view-dependent factors (zoom level, surface geometry) to maintain visual consistency.
4.  **Elastic Selection:** Methods like [FlexGS](16110-flexgs.md) introduce learnable selectors that dynamically choose a subset of Gaussians and transform their attributes to fit a target computational budget, decoupling model size from fixed pruning ratios.

## Subtopics

### [TraGraph-GS](14454-tragraph-gs.md)
TraGraph-GS is a high-quality rendering method for arbitrary large-scale scenes that employs graph-based adaptive spatial partitioning, regularization constraints, and adaptive region selection to maintain real-time performance and visual fidelity across vastly different scales. It distinguishes itself from standard 3DGS by decoupling the scene into connected subgraphs based on camera feature matching, enabling independent local training and a progressive rendering strategy for novel viewpoints that avoids boundary artifacts. Unlike [FlexGS](16110-flexgs.md) which focuses on dynamic adaptivity, or [Mipmap-GS](16893-mipmap-gs.md) which handles scale via mipmaps, TraGraph-GS explicitly models the structural connectivity of input images to partition the scene and uses a coarse global representation combined with sorted local contributions for novel view synthesis.

### [FlexGS](16110-flexgs.md)
FlexGS is an elastic inference method for 3DGS that enables a single trained model to adapt to varying computational constraints at inference time by selecting and transforming a subset of Gaussians based on a desired model size ratio, without requiring additional fine-tuning. It solves the problem that standard 3DGS models are too memory-intensive for devices with restricted resources (e.g., smartphones, VR headsets) and that previous compression methods require costly separate fine-tuning runs for each target compression ratio. Unlike post-hoc pruning methods that use fixed heuristics to retain Top-K Gaussians, FlexGS jointly trains a learnable selector and a transformation field to dynamically adjust the primitive set.

### [Gaussian Mixture Tree Construction](16717-gaussian-mixture-tree-construction.md)
Gaussian Mixture Tree (GMT) Construction is a post-processing method that organizes 3D Gaussian primitives into a hierarchical tree structure to identify distinct 3D plane instances. Unlike standard 3DGS which treats primitives as independent entities, GMT recursively merges leaf nodes using Gaussian Mixture Models to create parent nodes that encompass child distributions. It is distinguished from siblings like [TraGraph-GS](14454-tragraph-gs.md) by its explicit probabilistic merging of Gaussians into a tree, rather than graph-based connectivity or grid-based organization.

### [Mipmap-GS](16893-mipmap-gs.md)
Mipmap-GS is a test-time adaptation method that deforms pre-trained 3D Gaussians into scale-adaptive primitives to eliminate aliasing artifacts (zoom-in spikes and zoom-out thickness) caused by fixed Gaussian distributions at varying zoom factors. Unlike methods that apply post-processing filters or hierarchical level-of-detail selection, Mipmap-GS self-adjusts primitive properties and distribution by optimizing against scale-specific mipmap-like pseudo ground-truth, effectively informing the Gaussians of the new sampling rate.

### [Hierarchical Anchor Coupling](17260-hierarchical-anchor-coupling.md)
Hierarchical Anchor Coupling (HAC) is a module that establishes cross-level gradient pathways in structured 3D Gaussian splatting by aggregating context from adjacent octree levels and broadcasting a residual feature adjustment to all visible anchors at a specific level. It solves the problem of feature isolation, where backpropagation graphs in anchor-based octree pipelines lack connections between features at level $l_i$ and adjacent levels $l_i \pm 1$. Unlike sibling methods that may modify primitive geometry or rendering equations, HAC operates exclusively on the feature aggregation stage, introducing a shared residual component that preserves intra-level variation while enabling cross-level information flow.

### [Self-Organizing Gaussian Grids](19022-self-organizing-gaussian-grids.md)
Self-Organizing Gaussian Grids is a compact 3D scene representation that reorganizes the high-dimensional parameters of 3DGS into a 2D grid with local homogeneity to drastically reduce storage size without compromising visual quality. It differs from fixed-ordering methods like Z-order curves or tri-planes by using an unsupervised learning model to determine the grid layout per scene, thereby preserving topological relationships and exploiting perceptual redundancies in natural scenes.

### [Surface-Aware Splat Graph Construction](22007-surface-aware-splat-graph-construction.md)
Surface-Aware Splat Graph Construction establishes connectivity exclusively along the surface manifold by defining adjacency as the geometric intersection of Gaussian kernels, filtering out spurious neighbors that are close in Euclidean space but distant along the underlying surface. Unlike standard nearest-neighbor graphing which relies on Euclidean or Mahalanobis distances, this method leverages the rank-2 elliptical shape of surface-aligned Gaussians to ensure that links only form between primitives that are proximate along the manifold. It builds on [Hierarchical, Graph-Based, and Adaptive Structures](17106-hierarchical-graph-based-and-adaptive-structures.md) by introducing a topological structure derived from surface geometry rather than raw point proximity.

### KoalaGS
KoalaGS is a minor variant that utilizes a specific deformation technique to handle proxy-free editing. It builds a Laplacian operator directly on the collection of Gaussian kernel means $\{\pi_i\}_{i=1}^N$, treating them as a point cloud, using geodesic distance on the splat graph to reflect the underlying surface faithfully [S1]. The method constructs the Laplacian operator $\Delta$ on the set of Gaussian kernel means, integrating the surface-aware splat graph into off-the-shelf point cloud Laplacian methods. It uses graph geodesic distance rather than raw graph connectivity for robustness against missing edges, computing the cotangent Laplacian on a local triangulation using NonManifold [S1]. The means are deformed through a Laplacian-based deformation map $\phi_\Delta$ obtained by solving a system such as ARAP or BBW using the Laplacian operator $\Delta$ [S1]. A key pitfall is that simply displacing the positions of the primitives leads to severe visual artifacts because the covariances of the Gaussian kernels are not adapted properly [S1].

### Hierarchical 3D Gaussian BVH Construction
Hierarchical 3D Gaussian BVH Construction is a minor variant that builds an Axis-Aligned Bounding Box (AABB) Bounding Volume Hierarchy (BVH) top-down over 3DGS primitives [S2]. The resulting BVH tree ensures that the children of each interior node will be spatially compact [S2]. The construction initializes the root node as the AABB of all Gaussians, using 3$\times$ their stored size to capture their extent [S2]. To obtain child nodes, it recursively performs a binary median split on the current node by projecting the means of all Gaussians in the group onto the longest axis of their bounding box and partitioning the group based on the position of the projected mean with respect to the median of all projections [S2]. Finally, it computes intermediate node Gaussians from their respective children, starting from the leaves and recursively merging up the tree [S2].

## Background
The need for hierarchical and adaptive structures in 3D Gaussian Splatting arises from the limitations of the original method in handling large-scale scenes, varying viewing distances, and constrained hardware. Standard 3DGS requires a fixed number of Gaussians, which can lead to memory overflow in large scenes or aliasing artifacts when zooming [S1, S2]. The concept of using graphs for connectivity was introduced to improve geometric consistency in surface-aligned representations [S1]. Hierarchical structures like BVHs were adapted from traditional ray tracing to accelerate rendering in very large datasets [S2]. Elastic inference methods were developed to address the deployment challenges of 3DGS on mobile and VR devices, where fixed model sizes are impractical [S1].
