# HumanGaussian
## Overview
HumanGaussian is a text-to-3D method for generating textured human avatars using 3D Gaussian Splatting [S1][S2, unofficial]. It addresses the oversaturation issue common in diffusion-based 3D generation by employing negative prompt guidance [S1][S2, unofficial]. Unlike general object generators, it leverages a parametric human body model (SMPL-X) to ensure anatomical plausibility during initialization [S1][S2, unofficial].

## How it works
**Inputs:** A text prompt describing the desired human appearance [S1][S2, unofficial].
**Outputs:** A set of 3D Gaussians representing the human avatar [S1][S2, unofficial].

**Data Structures:**
*   **3D Gaussians:** Initialized as a point cloud where each point $i$ has position $\mathbf{t}_i$, covariance matrix $\mathbf{\Sigma}_i$ (parameterized as rotation $\mathbf{R}_i$ and scale $\mathbf{S}_i$), opacity $\alpha_i$, and spherical harmonic coefficients for color [G].
*   **SMPL-X Template:** A parametric human mesh model used as the geometric prior [S1][S2, unofficial].

**Steps:**
1.  **Initialization:** Randomly sample points on the surface of the SMPL-X template [S1][S2, unofficial]. These points serve as the initial centers $\mathbf{t}_i$ for the 3D Gaussians [S1][S2, unofficial].
2.  **Extended Diffusion Model:** Extend Stable Diffusion to generate both RGB and depth maps simultaneously from the text prompt [S1][S2, unofficial].
3.  **Dual-Branch SDS Construction:** Construct a dual-branch Score Distillation Sampling (SDS) loss to guide the optimization [S1][S2, unofficial]. This involves rendering the current Gaussian set to obtain predicted RGB and depth, and comparing them against the diffusion model's predictions [S1][S2, unofficial].
4.  **Negative Prompt Guidance:** Combine the classifier score provided by the null text prompt and the negative score provided by the negative prompt to construct negative prompt guidance [S1][S2, unofficial]. This combined guidance addresses the oversaturation issue [S1][S2, unofficial].
5.  **Optimization:** Optimize the Gaussian parameters using the combined SDS loss and negative prompt guidance [S1][S2, unofficial].
6.  **Geometry Refinement:** Convert the Gaussian opacity to a signed distance field through a NeuS-like method to provide geometry constraints and extract detailed textured meshes [S1][S2, unofficial].

**Parameters:**
*   **SMPL-X Template:** Used for initialization [S1][S2, unofficial].
*   **Negative Prompt:** Used to mitigate oversaturation [S1][S2, unofficial].
*   **NeuS-like Method:** Used for geometry refinement and mesh extraction [S1][S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Oversaturation:** A known issue in diffusion-based 3D generation that HumanGaussian specifically addresses via negative prompt guidance [S1][S2, unofficial].

**Pseudocode:**
```python
def human_gaussian_optimization(text_prompt, negative_prompt, num_iterations):
    # Step 1: Initialize Gaussians from SMPL-X template
    smpl_mesh = get_smpl_x_template()
    points = random_sample_surface_points(smpl_mesh)
    gaussians = initialize_gaussians_from_points(points)
    
    # Step 2: Setup Extended Stable Diffusion for RGB and Depth
    diffusion_model = extend_stable_diffusion_for_rgb_depth()
    
    for step in range(num_iterations):
        # Render current Gaussians
        rendered_rgb, rendered_depth = render_gaussians(gaussians)
        
        # Get diffusion predictions for RGB and Depth
        pred_rgb, pred_depth = diffusion_model.sample(
            rendered_rgb, rendered_depth, text_prompt, negative_prompt
        )
        
        # Step 3: Compute Dual-Branch SDS Loss
        # Combines guidance from RGB and Depth branches
        rgb_grad = compute_sds_gradient(rendered_rgb, pred_rgb, text_prompt, negative_prompt)
        depth_grad = compute_sds_gradient(rendered_depth, pred_depth, text_prompt, negative_prompt)
        sds_loss = rgb_grad + depth_grad
        
        # Step 4: Compute Negative Prompt Guidance
        # Combines classifier score from null text prompt and negative score from negative prompt
        null_score = diffusion_model.get_classifier_score(rendered_rgb, null_text_prompt="")
        negative_score = diffusion_model.get_negative_score(rendered_rgb, negative_prompt)
        guidance_loss = null_score + negative_score
        
        # Step 5: Optimize Gaussians
        loss = sds_loss + guidance_loss
        gaussians = optimize_gaussians(gaussians, loss)
        
    return gaussians

# Standard helper definitions
def get_smpl_x_template(): return SMPL_X_TEMPLATE
def random_sample_surface_points(mesh): return uniform_sampling_on_mesh(mesh)
def initialize_gaussians_from_points(points): return create_gaussian_parameters(points)
def extend_stable_diffusion_for_rgb_depth(): return StableDiffusionRGBDepth()
def render_gaussians(gaussians): return standard_gaussian_rasterization(gaussians)
def compute_sds_gradient(rendered, predicted, text, neg_text): return standard_sds_gradient(rendered, predicted, text, neg_text)
def optimize_gaussians(gaussians, loss): return standard_gradient_descent(gaussians, loss)
```

## Background
HumanGaussian is part of the recent advances in 3D Gaussian Splatting for text-to-3D generation [S1][S2, unofficial]. It builds on the foundation of 3D Gaussian Splatting [Gaussian Splatting](5996-gaussian-splatting.md) and extends it to the domain of human avatar generation [S1][S2, unofficial]. It addresses limitations in previous methods by incorporating a parametric human model and advanced guidance techniques from diffusion models [S1][S2, unofficial].
