# GaussianPro

Also called: 3D Gaussian Splatting with Progressive Propagation

## Overview
GaussianPro is a training optimization method for 3D Gaussian Splatting that improves geometric fidelity by introducing a progressive propagation strategy [S1, S2]. Unlike standard densification which relies solely on position gradients, GaussianPro utilizes propagated depth and normal maps from neighboring views to guide the growth and adjustment of Gaussians [S2]. It sets itself apart by explicitly enforcing normal consistency between neighboring views and introducing planar constraints, ensuring that the discrete Gaussian representation aligns more closely with continuous surface geometry [S1, S2].

## How it works
GaussianPro integrates geometric priors into the densification and optimization pipeline [S2]. It generates initial depth and normal maps, propagates these values across neighboring pixels using patch matching, and uses the propagated information to identify regions requiring new Gaussians [S2].

### Inputs and Outputs
*   **Inputs:** Set of 3D Gaussians $\mathcal{G}$, input images from multiple views, and initial depth and normal estimates [S2].
*   **Outputs:** Optimized set of 3D Gaussians $\mathcal{G}'$ with improved geometric alignment [S2].

### Data Structures
The method relies on standard 3D Gaussian Splatting data structures augmented with geometric filters [G].
*   **Gaussian Attributes:** Standard fields: $\mathbf{c} \in \mathbb{R}^3$, $\mathbf{q} \in \mathbb{R}^4$ (quaternion), $\mathbf{s} \in \mathbb{R}^3$ (scale), $\alpha \in \mathbb{R}$, $\mathbf{c}_{sh} \in \mathbb{R}^{K \times 3}$ (SH coefficients) [G].
*   **Geometric Maps:** Depth map $D \in \mathbb{R}^{H \times W}$ and Normal map $N \in \mathbb{R}^{H \times W \times 3}$ for each view [S2].
*   **Propagated Maps:** $D_{prop}$ and $N_{prop}$, generated via patch matching [S2].

### Numbered Steps
1.  **Generate Initial Geometric Priors:** Compute initial depth $D$ and normal $N$ maps for each input view [S2].
2.  **Patch Matching Propagation:** Propagate depth and normal information from neighboring pixels in adjacent views to generate $D_{prop}$ and $N_{prop}$ [S2].
3.  **Geometric Filtering and Selection:** Identify pixels requiring additional Gaussians by comparing rendered and propagated maps [S2].
4.  **Gaussian Initialization:** Initialize new Gaussians at selected pixels using the propagated depth and normal information [S2].
5.  **Optimization with Geometric Losses:** Minimize the total loss $\mathcal{L}_{total} = \mathcal{L}_{rgb} + \lambda_{planar} \mathcal{L}_{planar} + \lambda_{norm} \mathcal{L}_{norm}$ during training [S1, S2].

### Formulas and Definitions
*   **Normal Consistency Loss ($\mathcal{L}_{norm}$):** Enforces consistency between the Gaussian's rendered normal $\mathbf{n}_{rendered}$ and the propagated normal $\mathbf{n}_{prop}$ [S2].
    $$ \mathcal{L}_{norm} = \|\mathbf{n}_{rendered} - \mathbf{n}_{prop}\|_1 + (1 - \mathbf{n}_{rendered} \cdot \mathbf{n}_{prop}) $$
*   **Planar Loss ($\mathcal{L}_{planar}$):** Encourages Gaussians to conform to planar structures by minimizing the distance of Gaussian centers to fitted planes or penalizing deviations from local planarity [S2].
*   **Progressive Propagation:** The strategy updates Gaussians iteratively during training by considering normal consistency between neighboring views [S1, S2].

### Parameters
*   $\lambda_{planar}$: Weight for the planar loss [G].
*   $\lambda_{norm}$: Weight for the normal consistency loss [G].
*   Patch matching window size: Not given in the sources [S2].

### Edge Cases and Pitfalls
*   **Popping Artifacts:** Standard 3DGS can suffer from popping Gaussians due to discrete depth sorting, which GaussianPro mitigates through consistent geometric alignment [S1].
*   **Degenerate Input:** In textureless or reflective regions, depth and normal estimation may fail, requiring robust patch matching and geometric filtering [S2].

### Pseudocode
```python
def gaussian_pro_step(gaussians, views, cameras, initial_depth, initial_normal):
    # 1. Render current Gaussians
    rendered_image, rendered_depth, rendered_normal = render_gaussians(gaussians, cameras)
    
    # 2. Propagate geometric information from neighboring views
    propagated_depth, propagated_normal = patch_match_propagation(initial_depth, initial_normal, cameras)
    
    # 3. Compute Photometric Loss
    loss_rgb = photometric_loss(rendered_image, views[0].target)
    
    # 4. Compute Normal Consistency Loss
    loss_norm = l1_loss(rendered_normal, propagated_normal) + angular_loss(rendered_normal, propagated_normal)
    
    # 5. Compute Planar Loss
    loss_planar = planar_loss(gaussians)
    
    # 6. Total Loss and Backpropagation
    total_loss = loss_rgb + lambda_norm * loss_norm + lambda_planar * loss_planar
    gaussians.backward(total_loss)
    
    # 7. Densification based on Geometric Filtering
    pixels_to_densify = geometric_filter(rendered_depth, propagated_depth, rendered_normal, propagated_normal)
    
    for p in pixels_to_densify:
        new_g = initialize_gaussian(p, propagated_depth[p], propagated_normal[p], cameras)
        gaussians.add(new_g)
        
    return total_loss

def render_gaussians(gaussians, cameras):
    # Standard 3DGS tile-based splatting
    rendered_image = torch.zeros_like(cameras.target)
    rendered_depth = torch.zeros_like(cameras.target)
    rendered_normal = torch.zeros_like(cameras.target)
    for g in gaussians:
        proj = project_to_screen(g, cameras)
        splat = compute_splat(proj, g.covariance)
        rendered_image += splat * g.opacity
        rendered_depth += splat * g.depth
        rendered_normal += splat * g.normal
    return rendered_image, rendered_depth, rendered_normal

def patch_match_propagation(depth, normal, cameras):
    # Iterative patch matching across neighboring views
    propagated_depth = depth.clone()
    propagated_normal = normal.clone()
    for view in cameras.neighboring_views:
        for p in depth.shape:
            best_match = find_best_patch(depth, view.depth, p)
            propagated_depth[p] = view.depth[best_match]
            propagated_normal[p] = view.normal[best_match]
    return propagated_depth, propagated_normal

def geometric_filter(rendered_depth, propagated_depth, rendered_normal, propagated_normal):
    depth_diff = torch.abs(rendered_depth - propagated_depth)
    normal_diff = 1 - torch.cosine_similarity(rendered_normal, propagated_normal, dim=-1)
    threshold = 0.05
    return (depth_diff > threshold) | (normal_diff > threshold)

def initialize_gaussian(p, depth, normal, cameras):
    # Back-project pixel to 3D using propagated depth and camera intrinsics
    c = unproject_pixel(p, depth, cameras)
    q = normal_to_quaternion(normal)
    s = torch.ones(3) * 0.1
    alpha = 0.8
    c_sh = torch.zeros(3, 3)
    return Gaussian(c=c, q=q, s=s, alpha=alpha, c_sh=c_sh)

def planar_loss(gaussians):
    # Penalize deviation from local planar surfaces
    loss = 0.0
    for g in gaussians:
        plane = fit_local_plane(g.neighbors)
        loss += torch.abs(torch.dot(g.c - plane.origin, plane.normal))
    return loss

def l1_loss(a, b):
    return torch.mean(torch.abs(a - b))

def angular_loss(a, b):
    return torch.mean(1 - torch.cosine_similarity(a, b, dim=-1))

def photometric_loss(rendered, target):
    return torch.mean(torch.abs(rendered - target))
```

## Subtopics

### Surface and Geometry Alignment
Aligns discrete Gaussians with continuous geometric priors using positional and normal consistency losses [S1]. Choose when standard photometric optimization yields geometrically inconsistent surfaces [G]. [9267-surface-and-geometry-alignment.md]

### NeuSG
Uses neural implicit surfaces to guide Gaussian placement rather than explicit depth/normal propagation [S2]. Choose when implicit representations better capture complex topology [G]. [9172-neusg.md]

### GSDF
Uses a signed distance function to guide densification instead of propagated maps [S2]. Choose when explicit SDF supervision is available and preferred [G]. [9205-gsdf.md]

## Operating characteristics
*   **Time Complexity:** Increased per-step time due to patch matching propagation and additional loss computations [S2].
*   **Memory Complexity:** Standard 3DGS memory overhead, plus storage for depth/normal maps and propagated values [S2].
*   **Strengths:** Reduces popping artifacts, improves geometric accuracy, and handles complex surfaces better than standard 3DGS [S1, S2].
*   **Limitations:** Relies on the quality of initial depth/normal estimates; patch matching can be computationally expensive [S2].
*   **When to Use:** When high geometric fidelity is required, or when standard 3DGS produces artifacts like popping or poor surface reconstruction [S1, S2].

## Background
GaussianPro was introduced to improve the reconstruction quality of 3D Gaussian Splatting by addressing geometric inconsistencies in discrete representations [S1]. It builds on the observation that physical-based constraints and geometric priors can mitigate artifacts [S1]. The method was cited in surveys of recent advances in 3D Gaussian Splatting [S1] and compression methods [S2].
