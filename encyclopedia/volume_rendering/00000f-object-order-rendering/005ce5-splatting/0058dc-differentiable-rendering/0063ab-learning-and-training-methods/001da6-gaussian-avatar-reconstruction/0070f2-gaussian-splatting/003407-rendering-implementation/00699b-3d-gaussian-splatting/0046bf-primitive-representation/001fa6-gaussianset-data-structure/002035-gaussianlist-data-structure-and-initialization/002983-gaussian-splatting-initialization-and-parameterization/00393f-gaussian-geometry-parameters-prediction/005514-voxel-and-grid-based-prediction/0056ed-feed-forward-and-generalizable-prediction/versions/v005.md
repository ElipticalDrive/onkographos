# Feed-forward and Generalizable Prediction

Also called: Feed-forward 3D Gaussian Splatting, Generalizable 3DGS, One-shot 3DGS

## Overview
This family encompasses methods that predict a complete 3D Gaussian Splatting (3DGS) representation directly from a set of input images in a single forward pass, eliminating the iterative optimization loop required by standard 3DGS [Parent](8442-gaussian-geometry-parameters-prediction.md). Unlike iterative approaches, these models generalize across scenes, enabling real-time novel view synthesis and 3D reconstruction from sparse or uncalibrated views. They differ from sibling methods by their specific architectural choices for handling multi-view consistency, such as [FineSplat](15257-finesplat.md)'s dual-stage token grouping, [SparSplat](15813-sparsplat.md)'s use of 2D primitives for surface reconstruction, and [AnySplat Pipeline](12847-anysplat-pipeline.md)'s prediction of camera poses from uncalibrated inputs.

## Shared principles
All methods in this family share the core mechanism of replacing the per-scene optimization of 3DGS with a learned neural network $\Phi$ that maps input images $I$ to Gaussian parameters $\theta$. The general pipeline involves:
1.  **Multi-view Feature Extraction:** Encoding input images into a shared feature space, often using transformers or CNNs with attention mechanisms to capture cross-view relationships.
2.  **Parameter Prediction:** Decoding features into Gaussian attributes (mean $\mu$, scale $s$, rotation $r$, opacity $\alpha$, color $c$).
3.  **Differentiable Rendering:** Using differentiable rasterization to render the predicted Gaussians back to the input views (and potentially target views) to compute a loss.
4.  **End-to-End Training:** Optimizing the network weights via backpropagation through the renderer.

Key challenges addressed by this family include:
*   **Scale Ambiguity:** Feed-forward models often require scene normalization (e.g., rescaling camera translations to $[-1, 1]^3$) to handle unknown absolute scale [S1].
*   **Multi-view Consistency:** Ensuring that Gaussians predicted from different views agree in 3D space, often achieved through depth supervision, cost volumes, or 3D spatial attention [S1].
*   **Computational Efficiency:** Reducing the quadratic complexity of global attention by using local grouping, sparse convolutions, or hierarchical token structures [S1].

## Subtopics

### [AnySplat Pipeline](12847-anysplat-pipeline.md)
AnySplat is a feed-forward method that predicts a complete 3D Gaussian Splatting (3DGS) representation directly from a set of uncalibrated input images, eliminating the need for iterative optimization or known camera poses. It differs from sibling methods like [FineSplat](15257-finesplat.md) and [SparSplat](15813-sparsplat.md) by explicitly predicting camera poses and depth maps alongside Gaussian parameters, using a differentiable voxelization module to resolve density artifacts common in low-resolution feature backbones.

### [FineSplat](15257-finesplat.md)
FineSplat is a feed-forward 3D Gaussian Splatting (3DGS) framework that predicts a set of 3D Gaussian primitives from $N$ context views to enable novel view synthesis. It addresses the trade-off between fine-grained visual detail and the computational cost of global multi-view attention by employing a dual-grouping strategy: view-wise token grouping in Stage 1 preserves local detail, while 3D spatial grouping in Stage 2 enables cross-view interaction without global attention costs. Unlike sibling methods like YoNoSplat and ZipSplat that use coarser 14x14 patches, FineSplat uses 4x4 patches to maintain higher resolution, achieving superior quality with fewer primitives.

### [SparSplat](15813-sparsplat.md)
SparSplat is a generalizable, feed-forward model that maps a set of sparse input images to planar surface elements (2D Gaussian Splatting parameters) in a single forward pass to perform 3D shape reconstruction and novel view synthesis. It differs from its sibling [AnySplat Pipeline](12847-anysplat-pipeline.md) and [FineSplat](15257-finesplat.md) by explicitly targeting surface reconstruction via 2D primitives rather than novel view synthesis alone, leveraging 2DGS to ensure multi-view depth consistency required for TSDF fusion.

### 3D-aware Image Synthesis via Sparse Voxel Grids
#### definition

#### step

## Background
The shift from iterative to feed-forward 3D Gaussian Splatting emerged to address the high computational cost and time required for per-scene optimization in standard 3DGS. Early generalizable approaches adapted techniques from neural radiance fields (NeRF) and 3D-aware generative models. For instance, [VoxGRAF](https://doi.org/10.52202/068431-2464) demonstrated the use of sparse voxel grids and 3D convolutions for fast 3D-aware synthesis, influencing later Gaussian-based methods [S1]. Recent works like FineSplat, SparSplat, and AnySplat have refined these approaches by introducing specialized architectures for Gaussian parameter prediction, such as token-based transformers, cost volumes for depth estimation, and differentiable voxelization for artifact reduction. These methods enable real-time applications in robotics, AR/VR, and large-scale scene reconstruction where rapid inference is critical.
