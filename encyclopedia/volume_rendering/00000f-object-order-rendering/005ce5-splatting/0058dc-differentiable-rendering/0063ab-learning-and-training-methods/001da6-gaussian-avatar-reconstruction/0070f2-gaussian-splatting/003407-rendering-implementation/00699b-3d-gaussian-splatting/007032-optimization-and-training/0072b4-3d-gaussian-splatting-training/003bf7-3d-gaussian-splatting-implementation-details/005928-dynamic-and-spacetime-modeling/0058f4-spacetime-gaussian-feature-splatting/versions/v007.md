# Spacetime Gaussian Feature Splatting

Also called: Spacetime Gaussians

## Overview
Spacetime Gaussian Feature Splatting (STG) is a dynamic scene representation that extends 3D Gaussian Splatting into the 4D spacetime domain to enable real-time novel view synthesis of dynamic scenes [S2]. It solves the problem of modeling temporal evolution, emerging/vanishing content, and complex motion by parameterizing Gaussian attributes (position, rotation, opacity) as functions of time, while replacing spherical harmonics with a compact neural feature representation [S2]. Unlike sibling methods that rely on deformation fields or linear motion models, STG uses explicit polynomial parameterization for motion and a lightweight MLP for view/time-dependent appearance, offering superior temporal stability and lower memory consumption compared to training independent 3DGS models [S1, S2].

## How it works
### Inputs and Outputs
**Inputs:** Multi-view video sequences (images and camera poses) across multiple timestamps. Initialization uses Structure-from-Motion (SfM) sparse point clouds from all available timestamps [S2].
**Outputs:** A set of Spacetime Gaussians (STGs) and a small Multi-Layer Perceptron (MLP) $\Phi$, capable of rendering photorealistic images at novel viewpoints and arbitrary timestamps [S2].

### Data Structures
Each Spacetime Gaussian $i$ stores the following parameters:
1.  **Spatial Opacity:** $\sigma_{is} \in \mathbb{R}$ (time-independent base opacity) [S2].
2.  **Temporal Opacity Parameters:** $\mu_{\tau i} \in \mathbb{R}$ (temporal center), $s_{\tau i} \in \mathbb{R}$ (temporal scaling) [S2].
3.  **Position:** $\mu_i \in \mathbb{R}^3$ (initial 3D position) [S2].
4.  **Motion Coefficients:** $\{b_{i,k}\}_{k=0}^{n_p} \subset \mathbb{R}^3$ (polynomial coefficients for position trajectory) [S2].
5.  **Rotation:** $q_i \in \mathbb{R}^4$ (initial quaternion) [S2].
6.  **Rotation Coefficients:** $\{c_{i,k}\}_{k=0}^{n_q} \subset \mathbb{R}^4$ (polynomial coefficients for rotation trajectory) [S2].
7.  **Scaling:** $s_i \in \mathbb{R}^3$ (3D scaling vector, time-independent) [S2].
8.  **Features:** $f_i(t) \in \mathbb{R}^9$ (time-dependent features, see below) [S2].
    *   $f_{base} \in \mathbb{R}^3$: Base RGB color.
    *   $f_{dir} \in \mathbb{R}^3$: View-direction dependent features.
    *   $f_{time} \in \mathbb{R}^3$: Time-dependent features [S2].
9.  **MLP $\Phi$:** A shallow, narrow network mapping splatted features and view direction to final color [S2].

### Formulas and Definitions
**Temporal Opacity:**
The temporal opacity $\sigma_i(t)$ is modeled using a 1D Gaussian function [S2]:
$$ \sigma_i(t) = \sigma_{is} \exp \left( -s_{\tau i} |t - \mu_{\tau i}|^2 \right) $$
where $\sigma_{is}$ is the spatial opacity, $\mu_{\tau i}$ is the timestamp of maximum visibility, and $s_{\tau i}$ controls the effective duration [S2].

**Position Trajectory:**
The position $\mu_i(t)$ at time $t$ is defined by a polynomial [S2]:
$$ \mu_i(t) = \sum_{k=0}^{n_p} b_{i,k} (t - \mu_{\tau i})^k $$
In implementation, $n_p = 3$ [S2].

**Rotation Trajectory:**
The rotation is parameterized by a quaternion $q_i(t)$ using a polynomial [S2]:
$$ q_i(t) = \sum_{k=0}^{n_q} c_{i,k} (t - \mu_{\tau i})^k $$
In implementation, $n_q = 1$ [S2]. The quaternion is normalized and converted to a rotation matrix $R_i(t)$ [S2].

**Covariance:**
The scaling matrix $S_i$ is kept time-independent [S2]. The covariance matrix $\Sigma_i(t)$ is computed as [S2]:
$$ \Sigma_i(t) = R_i(t) S_i S_i^T R_i^T(t) $$
where $S_i$ is a diagonal matrix parameterized by $s_i$ [S2].

**Spacetime Opacity:**
The opacity of an STG at spacetime point $(x, t)$ is [S2]:
$$ \alpha_i(t) = \sigma_i(t) \exp \left( -\frac{1}{2} (x - \mu_i(t))^T \Sigma_i(t)^{-1} (x - \mu_i(t)) \right) $$

**Projection:**
The 3D Gaussian is projected to 2D image space. Let $W$ be the viewing transformation and $K$ be the projection matrix. The 2D center $\mu^{2D}_i$ and covariance $\Sigma^{2D}_i$ are [S2]:
$$ \mu^{2D}_i = \left( K \left( \frac{W \mu_i(t)}{(W \mu_i(t))_z} \right) \right)_{1:2} $$
$$ \Sigma^{2D}_i = \left( J W \Sigma_i(t) W^T J^T \right)_{1:2,1:2} $$
where $J$ is the Jacobian of the projective transformation [S2].

**Feature Splatting:**
The feature vector $f_i(t)$ for each STG is constructed as [S2]:
$$ f_i(t) = \left[ f_{base}, f_{dir}, (t - \mu_{\tau i}) f_{time} \right]^T \in \mathbb{R}^9 $$
During rasterization, features are splatted to the image plane. At each pixel, the splatted features are split into $F_{base}, F_{dir}, F_{time}$ [S2].

**Rendering:**
The final color $I$ is computed by volume rendering the splatted features through the MLP $\Phi$, which takes the view direction $r$ as input [S2]:
$$ I = F_{base} + \Phi(F_{dir}, F_{time}, r) $$
If the "lite-version" is used, $\Phi$ is dropped, and $I = F_{base}$ [S2].

### Numbered Steps
1.  **Initialization:** Initialize STGs using SfM sparse point clouds from all available timestamps [S2].
2.  **Training Loop:**
    a. Sample a timestamp $t$ and camera pose.
    b. Compute time-dependent parameters $\mu_i(t)$, $R_i(t)$, and $\sigma_i(t)$ using the polynomial and Gaussian formulas.
    c. Project STGs to 2D and rasterize features $f_i(t)$ to the image plane using differentiable splatting [S2].
    d. Compute final pixel colors using the MLP $\Phi$ (or directly from $F_{base}$ in lite-version) [S2].
    e. Calculate loss: $L = L_{L1} + L_{D-SSIM}$ between rendered and ground truth images [S2].
    f. Backpropagate gradients to optimize STG parameters and $\Phi$ using Adam optimizer [S2].
3.  **Density Control:** Interleave training with aggressive pruning to reduce Gaussian count and model size [S2].
4.  **Guided Sampling (Optional):**
    a. After training loss stabilizes, identify pixels with large errors.
    b. Aggregate errors patch-wise to prioritize substantial errors [S2].
    c. Use coarse depth maps to determine depth ranges for these patches [S2].
    d. Sample new Gaussians uniformly along rays within these depth ranges, adding small noise to centers [S2].
    e. Repeat this process no more than 3 times [S2].

### Pseudocode
```python
def compute_stg_parameters(stg, t):
    """
    Computes time-dependent attributes for a Spacetime Gaussian.
    """
    # Temporal Opacity
    temporal_opacity = stg.sigma_is * exp(-stg.s_tau_i * (t - stg.mu_tau_i)**2)
    
    # Position
    pos = zeros(3)
    for k in range(0, 4): # n_p = 3, so k=0,1,2,3
        pos += stg.b[i,k] * (t - stg.mu_tau_i)**k
    
    # Rotation (Quaternion)
    quat = zeros(4)
    for k in range(0, 2): # n_q = 1, so k=0,1
        quat += stg.c[i,k] * (t - stg.mu_tau_i)**k
    quat = normalize(quat)
    rot_matrix = quaternion_to_rotation_matrix(quat)
    
    # Covariance
    # S_i is time-independent
    S_i = diag(stg.s_i)
    Sigma_t = rot_matrix @ (S_i @ S_i.T) @ rot_matrix.T
    
    return temporal_opacity, pos, Sigma_t

def feature_splatting(stgs, camera, t):
    """
    Rasterizes Spacetime Gaussians to image space.
    """
    image_height, image_width = camera.resolution
    features_image = zeros((image_height, image_width, 9))
    alphas_image = zeros((image_height, image_width))
    
    # Sort STGs by depth
    sorted_stgs = sort_by_depth(stgs, camera, t)
    
    for stg in sorted_stgs:
        # Compute time-dependent attributes
        alpha_3d, mu_t, Sigma_t = compute_stg_parameters(stg, t)
        
        # Project to 2D
        mu_2d = project_2d(mu_t, camera.W, camera.K)
        Sigma_2d = project_covariance(Sigma_t, camera.W, camera.J)
        
        # Compute 2D opacity
        alpha_2d = alpha_3d * gaussian_2d_pdf(mu_2d, Sigma_2d)
        
        # Construct feature vector
        f_base = stg.f_base
        f_dir = stg.f_dir
        f_time = stg.f_time
        f_t = concat([f_base, f_dir, (t - stg.mu_tau_i) * f_time])
        
        # Rasterize
        features_image, alphas_image = rasterize_gaussian(
            features_image, alphas_image, 
            mu_2d, Sigma_2d, alpha_2d, f_t
        )
        
    return features_image, alphas_image

def render(features_image, view_directions):
    """
    Computes final color from splatted features.
    """
    # Split features
    F_base = features_image[:, :, 0:3]
    F_dir = features_image[:, :, 3:6]
    F_time = features_image[:, :, 6:9]
    
    # Lite version: return base color only
    # return F_base
    
    # Full version: use MLP
    # Concatenate F_dir, F_time and view direction
    input_to_mlp = concat([F_dir, F_time, view_directions], axis=-1)
    color = F_base + MLP_phi(input_to_mlp)
    return color

def train_step(stgs, camera, gt_image, t):
    # 1. Rasterize
    features, alphas = feature_splatting(stgs, camera, t)
    
    # 2. Render
    view_dirs = compute_view_directions(camera)
    pred_image = render(features, view_dirs)
    
    # 3. Loss
    l1_loss = L1(pred_image, gt_image)
    dssim_loss = DSSIM(pred_image, gt_image)
    loss = l1_loss + dssim_loss
    
    # 4. Backprop
    loss.backward()
    
    # 5. Update
    optimizer.step()
    
    return loss
```

### Parameters
*   **Polynomial degree for motion ($n_p$):** 3 [S2].
*   **Polynomial degree for rotation ($n_q$):** 1 [S2].
*   **Feature dimension:** 9 per STG (3 base, 3 dir, 3 time) [S2].
*   **Optimizer:** Adam [S2].
*   **Pruning:** More aggressive than standard 3DGS [S2].
*   **Guided Sampling:** Conducted no more than 3 times [S2].

### Edge Cases and Pitfalls
*   **Scaling Matrix:** The scaling matrix $S_i$ is kept time-independent. Applying time-conditioned functions to scaling did not observe improvement in rendering quality [S2].
*   **Temporal Flickering:** Training independent 3DGS models per frame causes flickering; STG resolves this by enforcing coherent movement via polynomials [S1].
*   **Sparse Initialization:** Areas with sparse Gaussians at initialization (often distant) are challenging to converge. Guided sampling is required to address this [S2].

## Operating characteristics
*   **Time Complexity:** Training time is 40-60 minutes for a 50-frame sequence on a single NVIDIA A6000 GPU [S2].
*   **Memory Complexity:** Significantly lower memory consumption than 3DGS, Plenoxels, and Nerfacto because a single model represents all frames [S1]. Feature size is 9 parameters per STG vs 48 for 3-degree Spherical Harmonics [S2].
*   **Rendering Speed:** 140 FPS at 1352 × 1014 resolution on the Neural 3D Video Dataset [S2]. 66 FPS at 8K resolution on an Nvidia RTX 4090 GPU (lite-version) [S2].
*   **Strengths:** Real-time high-resolution rendering, compact model size, better temporal stability than independent frame training, handles emerging/vanishing content [S2].
*   **Limitations:** Requires multi-view video input. Polynomial motion model may be less flexible than deformation fields for highly complex non-rigid deformations, though it offers higher quality than linear models [S2].
*   **When to use:** Real-time dynamic view synthesis where temporal consistency and rendering speed are critical.
*   **When not to use:** Scenes with extremely complex, non-polynomial motion that cannot be approximated by low-degree polynomials, or single-view dynamic reconstruction (STG is designed for multi-view).

## Background
Spacetime Gaussian Feature Splatting was introduced by Zhan Li, Zhang Chen, Zhong Li, and Yi Xu from OPPO US Research Center and Portland State University in the paper "Spacetime Gaussian Feature Splatting for Real-Time Dynamic View Synthesis" (arXiv:2312.16812v2, Apr 4 2024) [S2]. It builds upon 3D Gaussian Splatting [41] by extending it to the 4D spacetime domain. The method addresses limitations of grid-like representations (e.g., K-Planes, HexPlane) which cannot fully adapt to dynamic scene structures, and linear motion models (e.g., 4D Gaussians) which are less expressive [S2].
