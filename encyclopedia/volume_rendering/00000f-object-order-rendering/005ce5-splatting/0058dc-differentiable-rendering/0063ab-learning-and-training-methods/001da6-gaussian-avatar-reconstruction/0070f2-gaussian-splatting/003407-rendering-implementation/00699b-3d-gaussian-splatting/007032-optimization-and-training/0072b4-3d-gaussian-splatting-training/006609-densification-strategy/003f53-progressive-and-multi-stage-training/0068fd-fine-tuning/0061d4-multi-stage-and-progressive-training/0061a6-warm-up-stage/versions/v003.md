# Warm-up stage

Also called: 3D Gaussian Initialization (Warm-up)

## Overview
A training adaptation that improves convergence stability and distractor suppression in 3D Gaussian Splatting (3DGS) by decoupling the initialization of static geometry from dynamic deformation learning [S1, S2]. It sets apart from single-stage optimization by preventing the gradient conflict between coarse geometric fitting and complex temporal deformation, particularly in dynamic scenes or when SfM initialization is absent [S2].

## How it works
The warm-up stage serves as a preliminary optimization phase before engaging the full dynamic model (e.g., 4D-GS). It addresses convergence difficulties that arise when training 4D-Gaussian representations directly without prior geometric grounding [S2].

**Inputs and Outputs:**
*   **Input:** Raw image sequence; optionally sparse SfM points (if available). If SfM points are absent, random or heuristic initialization is used [S2].
*   **Output:** Optimized static 3D Gaussian parameters ($\Gamma$) and initial deformation field estimates, which serve as the starting state for the subsequent dynamic training stage [S2].

**Data Structures:**
*   **3D Gaussians ($\Gamma$):** Defined by position $\mathbf{p}$, scale $\mathbf{s}$, rotation $\mathbf{q}$, opacity $\alpha$, and color $\mathbf{c}$ [S2].
*   **Deformation Network ($\Delta$):** An MLP or structure (e.g., HexPlane) that predicts deformation offsets based on spatial-temporal features [S2].

**Steps:**
1.  **Static Initialization:** Initialize 3D Gaussians. If SfM points are missing, use a coarse initialization strategy to avoid convergence failure [S2].
2.  **Warm-up Optimization:** Optimize the static 3D Gaussian parameters ($\Gamma$) using standard 3DGS rendering loss (L1/SSIM) for a fixed number of iterations. During this phase, the deformation network $\Delta$ is either frozen or trained with minimal influence to suggest initial deformation directions [S2].
3.  **Dynamic Transition:** Transition to the full 4D-GS training. The optimized $\Gamma$ from the warm-up stage is retained, while the deformation network $\Delta$ is activated to model temporal changes [S2].

**Formulas:**
The rendering of a deformed Gaussian $\mathcal{G}'$ at time $t$ is given by:
$$ \mathcal{G}'_i = \mathcal{D}(\mathcal{H}(\mathbf{p}_i, t)) $$
where $\mathcal{H}$ is the spatial-temporal structure encoder and $\mathcal{D}$ is the Gaussian deformation decoder, consisting of separate MLPs $\{\phi_x, \phi_r, \phi_s\}$ for position, rotation, and scale changes [S2].

**Parameters:**
*   **Warm-up Iterations:** Not given in the sources.
*   **Loss Function:** Standard 3DGS photometric and structural similarity losses [S2].

**Edge Cases and Pitfalls:**
*   **Absence of SfM Points:** Direct 4D-GS training without a warm-up stage leads to convergence difficulty [S2].
*   **Numeric Errors:** Skipping the warm-up stage can cause numeric errors in optimizing the Gaussian deformation network $\Delta$ [S2].

**Pseudocode:**
```python
def warm_up_stage(images, initial_gaussians, num_iterations):
    """
    Optimizes static 3D Gaussians before dynamic training.
    """
    gaussians = initial_gaussians
    deformation_network = initialize_deformation_network()
    
    for step in range(num_iterations):
        # Sample a random view from the image sequence
        view = sample_view(images)
        
        # Render current static Gaussians
        rendered_image = render_3d_gaussians(gaussians, view)
        
        # Compute loss against ground truth
        loss = compute_loss(rendered_image, view.gt_image)
        
        # Backpropagate to update static Gaussians
        # Note: Deformation network gradients are minimized or frozen
        # to focus on geometric initialization [S2]
        update_parameters(gaussians, loss)
        
    return gaussians, deformation_network
```

## Subtopics

### 3D Gaussian Initialization (Warm-up)
A specific variant used in 4D-GS when SfM points initialization is absent. It prevents convergence difficulty by optimizing 3D Gaussians first. It keeps some 3D Gaussians in the dynamic part to release pressure on large deformation learning, learns proper 3D Gaussians $\Gamma$, and suggests deformation fields to focus on dynamic parts, avoiding numeric errors in the deformation network $\Delta$ [S2].

## Operating characteristics
*   **Performance Impact:** Training without the warm-up coarse stage yields PSNR 31.91 dB, SSIM 0.97, LPIPS 0.03, training time 7.5 mins, 79 FPS, and 18 MB storage [S2].
*   **Complexity:** Adds an initial optimization phase, increasing total training time but improving final convergence quality and stability [S2].
*   **Strengths:** Prevents convergence failure in dynamic scenes without SfM; stabilizes deformation network training [S2].
*   **Limitations:** Requires additional training iterations for the warm-up phase [S2].

## Background
The warm-up stage is a training adaptation introduced in the context of 4D Gaussian Splatting for real-time dynamic scene rendering [S2]. It addresses the challenge of initializing dynamic Gaussian representations when sparse SfM points are unavailable, ensuring that the deformation network does not start from a degenerate state [S2]. It is also noted as an adaptation in distractor suppression methods like SpotLessSplats, where it contributes to improved distractor suppression [S1].
