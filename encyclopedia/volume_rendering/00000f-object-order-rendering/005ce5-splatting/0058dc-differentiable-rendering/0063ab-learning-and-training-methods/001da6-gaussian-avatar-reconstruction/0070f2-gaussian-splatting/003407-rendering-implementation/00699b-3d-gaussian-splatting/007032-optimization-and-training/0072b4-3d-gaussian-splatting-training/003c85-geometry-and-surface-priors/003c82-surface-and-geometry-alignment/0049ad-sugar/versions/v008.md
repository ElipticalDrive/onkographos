# SuGaR

Also called: SuGaR: Surface-Aligned Gaussian Splatting for Realistic Head Avatar Reconstruction, Surface-Aligned Gaussian Splatting

## Overview
SuGaR is a post-hoc surface alignment method that extracts a high-quality triangle mesh from a trained 3D Gaussian Splatting (3DGS) scene by enforcing geometric priors during a refinement phase [S1, S2]. It solves the problem that vanilla 3DGS produces discrete, floating ellipsoids with no explicit surface structure, making mesh extraction difficult and resulting in geometry that is often inferior to implicit methods [S1, S2]. Unlike sibling methods that integrate geometry constraints directly into the training loop (e.g., [Geo-Splatting](9201-geo-splatting.md)) or replace primitives with 2D disks [2D Gaussian Splatting](52-2d-gaussian-splatting.md), SuGaR operates as a separate optimization stage on the existing 3DGS representation, flattening and pinning Gaussians to a reconstructed surface to enable mesh-based editing while maintaining real-time rendering capabilities [S2].

## How it works
**Inputs:** A fully trained 3DGS scene (set of $N$ Gaussians with centers $\mathbf{c}_i$, covariances $\Sigma_i$, opacities $\alpha_i$, and spherical harmonics coefficients $\mathbf{c}_{SH,i}$) and multi-view input images with known camera poses [S1, S2].
**Outputs:** A refined set of Gaussians aligned to a surface and a reconstructed triangle mesh [S2].

**Data Structures:**
The Gaussian representation remains identical to standard 3DGS:
- $\mathbf{c}_i \in \mathbb{R}^3$: Center position.
- $\mathbf{q}_i \in \mathbb{R}^4$: Rotation quaternion (defining orientation).
- $\mathbf{s}_i \in \mathbb{R}^3$: Scaling vector.
- $\alpha_i \in \mathbb{R}$: Opacity.
- $\mathbf{c}_{SH,i}$: SH coefficients for color.

**Method Steps:**
1. **Initial Surface Estimation:** Render depth maps from the trained 3DGS scene using standard volume rendering [G].
2. **Self-Regularization Loss:** Introduce a loss term that constrains the distance between the camera and the closest Gaussian to match the corresponding pixel's depth value in the rendered depth map [S1]. For each pixel, the Gaussian contributing most to the accumulated opacity is identified as the closest representative [S1].
3. **Flattening and Alignment:** Apply a penalty term to force Gaussians to become flat and aligned with the local surface normal [S2][S3, unofficial]. This regularizes the covariance matrix $\Sigma_i$ to have one dominant eigenvalue and two near-zero eigenvalues, effectively turning 3D ellipsoids into 2D surfels [S3, unofficial].
4. **Mesh Extraction:** Perform Poisson surface reconstruction on the aligned Gaussian centers and their estimated normals to generate a watertight triangle mesh [S2][S3, unofficial].
5. **Hybrid Representation:** Pin the flattened Gaussians to the surface of the extracted mesh [S2]. This creates a hybrid representation where the mesh provides structural editability and the Gaussians provide high-fidelity rendering [S2].

**Formulas:**
The total loss for the refinement phase combines photometric and geometric terms, following the family's shared principle:
$$ \mathcal{L}_{total} = \mathcal{L}_{rgb} + \lambda_{geo} \mathcal{L}_{geo} + \lambda_{norm} \mathcal{L}_{norm} $$
Where:
- $\mathcal{L}_{rgb}$ is the standard photometric loss (e.g., L1 + SSIM) [G].
- $\mathcal{L}_{geo}$ is the self-regularization loss that enforces positional consistency by minimizing the discrepancy between the camera-to-Gaussian distance and the rendered pixel depth [S1].
- $\mathcal{L}_{norm}$ enforces normal consistency, aligning Gaussian orientations with surface normals derived from the depth map or extracted mesh [S1, S2].
- $\lambda_{geo}, \lambda_{norm}$ are hyperparameters balancing photometric fidelity against geometric accuracy [G].

**Pseudocode:**
```python
def sugar_refine(gaussians, images, cameras, lambda_geo=1.0, lambda_norm=1.0, num_iterations=1000):
    # Initialize Gaussians from trained 3DGS
    # Render initial depth and color maps
    depth_map, color_map = standard_3dgs_rasterize(gaussians, cameras)
    
    for iteration in range(num_iterations):
        # Sample a batch of pixels
        pixel_indices = random_sample(len(images[0].width * images[0].height))
        
        # Forward pass
        rendered_color, rendered_depth, contributions = standard_3dgs_rasterize_batch(gaussians, pixel_indices, cameras)
        
        # Compute photometric loss
        loss_rgb = l1_loss(rendered_color, ground_truth_color[pixel_indices]) + ssim_loss(rendered_color, ground_truth_color[pixel_indices])
        
        # Compute geometric loss: align closest Gaussian distance to rendered depth
        loss_geo = 0.0
        for p in pixel_indices:
            # Find Gaussian with max accumulated opacity contribution at pixel p
            k = argmax(contributions[:, p])
            # Distance from camera center to Gaussian center
            dist_cam_to_gauss = norm(cameras[p].position - gaussians[k].center)
            loss_geo += abs(dist_cam_to_gauss - rendered_depth[p])
        
        # Compute normal loss: align Gaussian normal with surface normal
        loss_norm = 0.0
        for p in pixel_indices:
            # Extract Gaussian normal from rotation quaternion
            gauss_normal = quaternion_to_normal(gaussians[k].rotation)
            # Estimate surface normal from rendered depth map gradient
            surf_normal = compute_depth_normal(rendered_depth, p)
            loss_norm += 1.0 - dot(gauss_normal, surf_normal)
            
        # Backward pass
        loss = loss_rgb + lambda_geo * loss_geo + lambda_norm * loss_norm
        loss.backward()
        optimizer.step()
        
    # Post-processing: Flatten Gaussians and extract mesh
    gaussians = flatten_gaussians(gaussians)
    mesh = poisson_surface_reconstruction(gaussians)
    gaussians = pin_gaussians_to_mesh(gaussians, mesh)
    return gaussians, mesh

def flatten_gaussians(gaussians):
    for g in gaussians:
        eigvals, eigvecs = torch.linalg.eigh(g.covariance)
        # Suppress smallest two eigenvalues to enforce planarity
        eigvals[1:] = 1e-4
        g.covariance = eigvecs @ torch.diag(eigvals) @ eigvecs.T
    return gaussians

def pin_gaussians_to_mesh(gaussians, mesh):
    for g in gaussians:
        # Project Gaussian center onto nearest mesh face
        g.center = mesh.nearest_point(g.center)
    return gaussians
```

**Edge Cases and Pitfalls:**
- **Degenerate Gaussians:** Flattening can lead to numerical instability if eigenvalues become too small; a minimum threshold for eigenvalues is required [G].
- **Volumetric Effects:** SuGaR is a surface-based representation and struggles with fuzzy materials or volumetric effects, leading to performance drops compared to vanilla 3DGS in such regions [S2].
- **Precision:** The accuracy of the extracted mesh depends heavily on the quality of the initial depth maps and the resolution of the input images [S1].

## Background
SuGaR was introduced by Guédon and Lepetit in 2024 as a method to bridge the gap between the high-quality rendering of 3DGS and the structural editability of triangle meshes [S2]. It addresses the limitation that vanilla 3DGS lacks a continuous surface representation, which is a standard requirement in many 3D graphics applications [S2]. The method builds on the 3DGS framework by adding a self-regularization loss to align Gaussians with the surface, followed by Poisson meshing [S1][S3, unofficial]. It is particularly useful for head avatar reconstruction and other applications requiring explicit geometry [S2].
