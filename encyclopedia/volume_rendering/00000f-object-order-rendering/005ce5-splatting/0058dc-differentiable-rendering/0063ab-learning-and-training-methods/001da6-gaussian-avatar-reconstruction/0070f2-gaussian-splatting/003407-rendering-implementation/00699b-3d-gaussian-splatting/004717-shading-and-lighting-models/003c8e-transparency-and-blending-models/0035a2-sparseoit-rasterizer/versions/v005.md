# SparseOIT Rasterizer

Also called: GPU software rasterization of 3D Gaussians with pre-rendering

## Overview
SparseOIT Rasterizer is a rendering technique for 3D Gaussian Splatting that computes a blended image using Order-Independent Transparency (OIT) without sorting Gaussians by depth [S1, unofficial]. It differs from standard 3DGS rasterization, which requires sorting by distance to camera to correctly accumulate transmittance, by eliminating the sorting step entirely in favor of a weighted average that approximates the order-dependent result [S1, unofficial]. It achieves this by simultaneously computing a final OIT color and a pre-rendered image state using Blend-and-Normalize (BAN) and Blend-and-Update (BAU) functions [S1, unofficial].

## How it works
The method operates on 3D Gaussian primitives defined by mean $\boldsymbol{\mu}$, covariance $\boldsymbol{\Sigma}$ (or scales and orientation), opacity $o$, and color $\mathbf{c}$ [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   Image dimensions: width $w$, height $h$ [S1, unofficial].
*   Gaussian attributes: 3D means $M$, covariances $S$, colors $C$, opacities $A$ [S1, unofficial].
*   View matrix $V$ [S1, unofficial].

**Outputs:**
*   Rendered image $I$ [S1, unofficial].
*   Pre-rendered image state $I_{pre}$ (used for accumulation/updates) [S1, unofficial].

### Data Structures
*   **Tiles ($T$):** A grid partitioning the image of size $w \times h$. The specific tile size is not given in the sources [S1, unofficial].
*   **Gaussian List ($L$):** A list of Gaussian data structures duplicated and keyed by tile ID [S1, unofficial].
*   **Keys ($K$):** Tile IDs assigned to each Gaussian entry in $L$ [S1, unofficial].
*   **Ranges ($R$):** Start and end indices in $L$ for each tile $t$ [S1, unofficial].

### Steps
1.  **CullGaussian(p, V):** Cull Gaussians based on position $p$ and view $V$ [S1, unofficial].
2.  **ScreenspaceGaussians(M, S, V):** Project 3D means $M$ and covariances $S$ to screen space, yielding $M'$ and $S'$ [S1, unofficial].
3.  **CreateTiles(w, h):** Create tiles for image dimensions $w, h$ [S1, unofficial].
4.  **DuplicateWithKeys(M', T):** Duplicate Gaussian data and assign tile keys [S1, unofficial].
5.  **SortByKeys(K, L):** Sort Gaussians only by tile ID [S1, unofficial].
6.  **IdentifyTileRanges(T, K):** Identify ranges of Gaussians for each tile [S1, unofficial].
7.  **Initialize:** Set rendered image $I$ to zero [S1, unofficial].
8.  **Loop over all tiles $t$ in $T$:**
9.    **Loop over all pixels $i$ in $t$:**
10.    **GetTileRange(R, t):** Get range of Gaussians for tile $t$ [S1, unofficial].
11.    **BAN:** Compute final color $I[i]$ using the Blend-and-Normalize function [S1, unofficial].
12.    **BAU:** Update pre-rendered state $I_{pre}[i]$ using the Blend-and-Update function [S1, unofficial].

### Formulas
The final color $\mathbf{C}$ is computed as [S1, unofficial]:

$$
\mathbf{C} = T \mathbf{c}_0 + (1-T)F
$$

where:
*   $\mathbf{c}_0$ is the background color [S1, unofficial].
*   $T$ is the accumulated opacity/transmittance factor [S1, unofficial].
*   $F$ is the weighted average color:
    $$
    F = \frac{P}{Q}
    $$
    $$
    P = \sum_{i=1}^{N} \mathbf{c}_i \alpha_i w_i
    $$
    $$
    Q = \sum_{i=1}^{N} \alpha_i w_i
    $$
*   $\mathbf{c}_i$ is the color of the $i$-th Gaussian [S1, unofficial].
*   $\alpha_i$ is the opacity of the $i$-th Gaussian [S1, unofficial].
*   $w_i$ is the weight of the $i$-th Gaussian [S1, unofficial].

The gradients for backpropagation are [S1, unofficial]:

$$
\frac{\partial \mathbf{C}}{\partial \mathbf{c}_i} = (1-T)\frac{\alpha_i w_i}{Q}
$$

$$
\frac{\partial \mathbf{C}}{\partial \alpha_i} = \frac{T}{1-\alpha_i}(F-\mathbf{c}_0) + (1-T)\frac{w_i}{Q}(\mathbf{c}_i - F)
$$

$$
\frac{\partial \mathbf{C}}{\partial w_i} = (1-T)\frac{\alpha_i}{Q}(\mathbf{c}_i - F)
$$

### Parameters
*   **BAN (Blend and Normalize):** Function that computes the final OIT color [S1, unofficial].
*   **BAU (Blend and Update):** Function that updates the pre-rendered image state for subsequent blending or accumulation [S1, unofficial].
*   **Update Interval:** In most cases, the update interval is not specified, but for scenes like train, room, and bonsai, it is set to 600 to ensure correct execution [S1, unofficial].

### Pseudocode
```python
def SparseOITRasterizer(w, h, M, S, C, A, V):
    # 1. CullGaussian: Remove Gaussians outside view frustum or too small [G]
    valid = [i for i, p in enumerate(M) if in_frustum(p, V) and size(p, S) > threshold]
    M_c, S_c, C_c, A_c = M[valid], S[valid], C[valid], A[valid]

    # 2. ScreenspaceGaussians: Project 3D means and covariances to screen space [G]
    M_prime, S_prime = project_to_screen(M_c, S_c, V)

    # 3. CreateTiles: Partition image into grid tiles [G]
    T = create_tile_grid(w, h)

    # 4. DuplicateWithKeys: Assign each Gaussian to the tile containing its center [G]
    L, K = [], []
    for i, m in enumerate(M_prime):
        tile_id = get_tile_containing(m, T)
        L.append((i, m, S_prime[i], C_c[i], A_c[i]))
        K.append(tile_id)

    # 5. SortByKeys: Sort list L only by tile keys K [G]
    combined = sorted(zip(K, L), key=lambda x: x[0])
    K, L = zip(*combined) if combined else ([], [])

    # 6. IdentifyTileRanges: Compute start/end indices in L for each tile [G]
    R = {}
    for t in T:
        indices = [j for j, k in enumerate(K) if k == t]
        R[t] = (indices[0], indices[-1] + 1) if indices else (0, 0)

    # 7. Initialize rendered image I to zero
    I = [[0.0, 0.0, 0.0] for _ in range(w * h)]
    I_pre = [[0.0, 0.0, 0.0, 0.0] for _ in range(w * h)] # [T, F_r, F_g, F_b]

    # 8-12. Loop over tiles and pixels
    for t in T:
        r_start, r_end = R[t]
        for y in range(t.y_min, t.y_max):
            for x in range(t.x_min, t.x_max):
                i = y * w + x
                r = L[r_start:r_end]
                # 11. BAN: Compute final color
                I[i] = BAN(i, r, M_prime, S_prime, C_c, A_c, I_pre[i])
                # 12. BAU: Update pre-rendered state
                I_pre[i] = BAU(i, r, M_prime, S_prime, C_c, A_c, I_pre[i])

    return I, I_pre

def BAN(i, r, M_prime, S_prime, C_c, A_c, I_pre):
    # Computes final OIT color using weighted average [S1, unofficial]
    P = [0.0, 0.0, 0.0]
    Q = 0.0
    for idx, m, s, c, a in r:
        w_i = evaluate_gaussian(m, s, i) # [G] Standard 2D Gaussian PDF at pixel i
        P[0] += c[0] * a * w_i
        P[1] += c[1] * a * w_i
        P[2] += c[2] * a * w_i
        Q += a * w_i
    F = [P[j] / Q if Q > 0 else 0.0 for j in range(3)]
    T = I_pre[0]
    c0 = [0.0, 0.0, 0.0] # [G] Background color
    return [T * c0[j] + (1 - T) * F[j] for j in range(3)]

def BAU(i, r, M_prime, S_prime, C_c, A_c, I_pre):
    # Updates pre-rendered state for subsequent blending [S1, unofficial]
    alpha_sum = 0.0
    color_sum = [0.0, 0.0, 0.0]
    for idx, m, s, c, a in r:
        w_i = evaluate_gaussian(m, s, i) # [G]
        alpha_sum += a * w_i
        color_sum[0] += c[0] * a * w_i
        color_sum[1] += c[1] * a * w_i
        color_sum[2] += c[2] * a * w_i
    new_T = 1.0 - min(1.0, alpha_sum)
    new_F = [color_sum[j] / alpha_sum if alpha_sum > 0 else 0.0 for j in range(3)]
    return [new_T, new_F[0], new_F[1], new_F[2]]
```

### Edge Cases and Pitfalls
*   **Gradient Independence:** The variables of each Gaussian are mutually independent in the backward propagation equation, allowing for parallel computation [S1, unofficial].
*   **Update Interval:** For specific scenes (train, room, bonsai), the update interval must be set to 600 to ensure correct execution, exceeding twice the number of training views [S1, unofficial].

## Subtopics

### [Weighted Order-Independent Transparency for 3DGS](7772-weighted-order-independent-transparency-for-3dgs.md)
Weighted Order-Independent Transparency (OIT) for 3D Gaussian Splatting (3DGS) is a rendering technique that computes a blended image without sorting Gaussians by depth, using a learnable weight function to approximate correct transparency blending. It differs from standard 3DGS rasterization, which requires sorting by distance to camera to correctly accumulate transmittance, by eliminating the sorting step entirely in favor of a weighted average that approximates the order-dependent result. It builds on [SparseOIT Rasterizer](7562-sparseoit-rasterizer.md).

## Operating characteristics
*   **Time Complexity:** The sorting step is reduced to sorting by tile ID only, which is significantly faster than full depth sorting [S1, unofficial]. The blending process is independent of depth order, allowing for parallel computation of gradients [S1, unofficial].
*   **Memory Complexity:** Requires storing the rendered image $I$ and pre-rendered state $I_{pre}$ [S1, unofficial].
*   **Strengths:** Eliminates the expensive depth sorting step required by standard 3DGS rasterization [S1, unofficial]. Allows for parallel computation of gradients due to mutual independence of Gaussian variables in the backward propagation [S1, unofficial].
*   **Limitations:** The specific tile size and the exact implementation of the BAN and BAU functions are not detailed in the sources [S1, unofficial].
*   **When to Use:** When order-independent transparency is desired and the computational cost of depth sorting is prohibitive [S1, unofficial].

## Background
The SparseOIT Rasterizer was introduced in the paper "SparseOIT: Improving Order-Independent Transparency 3DGS via Active Set Method" [S1, unofficial]. It is a rasterization algorithm for 3D Gaussians that computes a weighted blended order-independent transparency (OIT) image and a pre-rendered image simultaneously, using a blend-and-normalize (BAN) function and a blend-and-update (BAU) function [S1, unofficial].
