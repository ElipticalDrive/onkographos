# Initial Time Scaling

Also called: Time variance initialization

## Overview
Initial Time Scaling adjusts the temporal variance of initialized 4D Gaussians to match the scene duration, preventing excessive Gaussian proliferation over long videos [S1, unofficial]. It leverages the anisotropic characteristic of Gaussians to maintain tractable Gaussian counts as video length increases, distinguishing it from methods that rely on rigid 3D bounding boxes or dynamic object segmentations [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Total scene duration $T_{total}$ (in frames or time units).
- Output: Initial temporal variance parameter $\sigma_t$ for the 4D Gaussian initialization.

**Data Structures:**
The 4D Gaussian is defined by mean $\mu \in \mathbb{R}^4$ and covariance $\Sigma \in \mathbb{R}^{4 \times 4}$. The temporal variance is the element $\Sigma_{33}$ (assuming spatial dimensions 0-2 and time dimension 3).

**Steps:**
1. Determine the total duration of the input video sequence, denoted as $T_{total}$.
2. Calculate the initial time scaling factor $\sigma_t$ as half of the total scene duration:
   $$ \sigma_t = \frac{T_{total}}{2} $$
3. Initialize the temporal variance of each 4D Gaussian using $\sigma_t$.

**Parameters:**
- $T_{total}$: The length of the video in frames or time units.
- $\sigma_t$: Initial temporal variance. Typical value is $0.5 \times T_{total}$.

**Edge Cases and Pitfalls:**
- If $T_{total}$ is very large, failing to scale $\sigma_t$ appropriately leads to intractable Gaussian counts [S1, unofficial].
- The method assumes the Gaussian has local support in time, similar to 3D Gaussians in space [S1, unofficial].

**Pseudocode:**
```python
def initialize_temporal_variance(total_duration: float) -> float:
    """
    Calculate initial temporal variance for 4D Gaussians.
    
    Args:
        total_duration: Total length of the video in frames or time units.
        
    Returns:
        Initial temporal variance sigma_t.
    """
    # Set initial time scaling to half of the scene's duration
    sigma_t = total_duration / 2.0
    return sigma_t
```

## Operating characteristics
**Time and Memory Complexity:**
The initialization step is $O(1)$ per Gaussian. The primary benefit is reducing the number of Gaussians required to cover the temporal domain, thus lowering memory usage and rendering time for long videos [S1, unofficial].

**Measured Performance:**
Specific performance metrics are not provided in the sources. However, the method enables high-fidelity rendering for both dynamic and static regions [S1, unofficial].

**Strengths and Limitations:**
- Strengths: Prevents Gaussian proliferation; leverages anisotropy; unified representation for dynamic and static regions.
- Limitations: Relies on the assumption of local temporal support; may not be optimal for scenes with non-uniform temporal activity.

**When to Use:**
Use when rendering long videos where Gaussian count becomes intractable.

**When Not to Use:**
Not applicable for short clips where Gaussian count is already manageable.

## Background
Originated in "Real-time Photorealistic Dynamic Scene Representation and Rendering with 4D Gaussian Splatting" [S1, unofficial]. The method addresses the issue that if 4D Gaussians have only local support in time, their number may become intractable as video length increases [S1, unofficial]. By setting the initial time scaling to half the scene duration, the method avoids this predicament [S1, unofficial].
