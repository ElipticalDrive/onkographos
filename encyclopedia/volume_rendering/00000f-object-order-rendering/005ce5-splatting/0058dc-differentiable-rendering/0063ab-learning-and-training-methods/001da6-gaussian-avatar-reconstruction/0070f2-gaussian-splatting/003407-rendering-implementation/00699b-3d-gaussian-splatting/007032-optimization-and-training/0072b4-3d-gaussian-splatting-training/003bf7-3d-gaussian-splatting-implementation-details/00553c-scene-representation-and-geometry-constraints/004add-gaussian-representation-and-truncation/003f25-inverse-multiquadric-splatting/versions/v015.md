# Inverse Multiquadric Splatting

Also called: 3DIQS, Inverse Multiquadric

## Overview
Inverse Multiquadric Splatting replaces the standard Gaussian density function with an inverse multiquadric radial basis function to modify the alpha blending behavior during rendering [S1]. It sets itself apart from base Gaussian Splatting by using a different radial basis function that requires a correction factor to scale the 3D covariance matrix [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians defined by mean $\boldsymbol{\mu}$, 3D covariance $\boldsymbol{\Sigma}$, opacity $\alpha_{base}$, and color, along with their 2D projected mean $\boldsymbol{\mu}'$ and 2D covariance $\boldsymbol{\Sigma}'_{2 \times 2}$ [S1].
*   **Output:** The final alpha value $\alpha$ for the splat, and gradients for the mean and covariance matrices during backpropagation [S1].

**Data Structures:**
The method operates on the standard 3DGS conic matrix representation for the 2D projection [S1]. The conic matrix $\mathbf{C}$ is the inverse of the 2D covariance matrix, stored in a compact symmetric format [S1]. Let $\mathbf{C} = \begin{bmatrix} a & b \\ b & c \end{bmatrix}$, where the entries correspond to the inverse covariance elements [S1]. The 2D distance vector is $\mathbf{d} = \mathbf{x} - \boldsymbol{\mu}' = (d.x, d.y)$ [S1].

**Parameters:**
*   `correctionFactor`: A scalar multiplier applied to the covariance matrices. Value: $1.38$ [S1].
*   `ellipse_max`: The upper bound for the ellipse term to skip distant splats. Value: $9.0$ [S1].
*   `alpha_max`: The maximum clamped alpha value. Value: $0.99$ [S1].

**Formulas:**
The 3D inverse multiquadric function is defined as [S1]:
$$ f(d_M) = \frac{1}{\frac{1}{\xi} (d_M)^2 + 1} $$
where $d_M \geq 0$. The 2D splat weight $w$ is calculated as [S1]:
$$ w = \frac{1}{\left[ \frac{1}{\xi} (\mathbf{x} - \boldsymbol{\mu}')^T (\boldsymbol{\Sigma}'_{2 \times 2})^{-1} (\mathbf{x} - \boldsymbol{\mu}') + 1 \right]} $$
In the CUDA implementation, the term $\frac{1}{\xi} (\mathbf{x} - \boldsymbol{\mu}')^T (\boldsymbol{\Sigma}'_{2 \times 2})^{-1} (\mathbf{x} - \boldsymbol{\mu}')$ is computed as `ellipse` [S1]. The final alpha is [S1]:
$$ \alpha = \min(0.99, \alpha_{base} \cdot \frac{1}{ellipse + 1}) $$

**Steps:**
1.  **Covariance Scaling:** Multiply the 3D covariance matrix $\boldsymbol{\Sigma}$ and the projected 2D covariance matrix $\boldsymbol{\Sigma}'_{2 \times 2}$ by `correctionFactor` ($1.38$) [S1].
2.  **Ellipse Calculation:** Compute the quadratic form `ellipse` using the conic matrix entries ($a, b, c$) and the 2D distance vector $\mathbf{d} = (d.x, d.y)$ [S1]:
    $$ ellipse = a \cdot d.x^2 + c \cdot d.y^2 + 2b \cdot d.x \cdot d.y $$
3.  **Boundary Checks:**
    *   If $ellipse \leq 0$, skip the splat [S1].
    *   If $ellipse \geq 9.0$, skip the splat [S1].
4.  **Alpha Computation:** Calculate the weight $G$ (or $w$) and the final alpha [S1]:
    $$ G = \frac{1}{ellipse + 1} $$
    $$ \alpha = \min(0.99, \alpha_{base} \cdot G) $$

**Pseudocode:**
```python
def inverse_multiquadric_forward(con_o, d, alpha_base, correction_factor=1.38):
    """
    con_o: tuple (a, b, c, w) representing the 2x2 symmetric conic matrix and base opacity.
    d: tuple (dx, dy) representing the 2D distance vector.
    alpha_base: The base opacity of the gaussian.
    """
    a, b, c, w = con_o
    dx, dy = d

    # 1. Calculate ellipse term (quadratic form)
    ellipse = a * dx * dx + c * dy * dy + 2.0 * b * dx * dy

    # 2. Boundary checks
    if ellipse <= 0.0 or ellipse >= 9.0:
        return None, None

    # 3. Compute weight and alpha
    G = 1.0 / (ellipse + 1.0)
    alpha = min(0.99, w * G)

    return alpha, G

def inverse_multiquadric_backward(alpha, G, dL_dalpha, con_o, d, correction_factor=1.38):
    """
    alpha: The computed alpha.
    G: The weight 1/(ellipse+1).
    dL_dalpha: Gradient of loss w.r.t alpha.
    con_o: tuple (a, b, c, w) representing the 2x2 symmetric conic matrix and base opacity.
    d: tuple (dx, dy) representing the 2D distance vector.
    """
    a, b, c, w = con_o
    dx, dy = d

    # 1. Gradient w.r.t G
    dL_dG = w * dL_dalpha

    # 2. Compute ellipse value again for gradients
    ellipse = a * dx * dx + c * dy * dy + 2.0 * b * dx * dy

    # 3. Gradient of G w.r.t ellipse
    # dG/d(ellipse) = -1 / (ellipse + 1)^2
    denom_sq = (ellipse + 1.0) ** 2
    dL_dellipse = -dL_dG / denom_sq

    # 4. Gradient w.r.t mean (dx, dy)
    # d(ellipse)/d(dx) = 2*(a*dx + b*dy)
    # d(ellipse)/d(dy) = 2*(c*dy + b*dx)
    dL_dmean_x = dL_dellipse * 2.0 * (a * dx + b * dy)
    dL_dmean_y = dL_dellipse * 2.0 * (c * dy + b * dx)

    # 5. Gradient w.r.t conic matrix entries (a, b, c)
    # d(ellipse)/da = dx^2
    # d(ellipse)/db = 2*dx*dy
    # d(ellipse)/dc = dy^2
    dL_da = dL_dellipse * dx * dx
    dL_db = dL_dellipse * 2.0 * dx * dy
    dL_dc = dL_dellipse * dy * dy

    # 6. Apply correction factor to conic gradients
    dL_da *= correction_factor
    dL_db *= correction_factor
    dL_dc *= correction_factor

    return dL_dmean_x, dL_dmean_y, dL_da, dL_db, dL_dc
```

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Splats with $ellipse \leq 0$ or $ellipse \geq 9.0$ are skipped [S1].
*   **Covariance Scaling:** The correction factor $1.38$ must be applied to the covariance matrices before projection/inversion [S1].

## Background
Inverse Multiquadric Splatting was introduced in the paper "DARB-Splatting: Generalizing Splatting with Decaying Anisotropic Radial Basis Functions" [S1]. It is part of a family of methods that generalize the radial basis functions used in splatting beyond the standard Gaussian [S1].
