# 3D Gaussian Splatting Self-Shadowing (T_light)

Also called: 光源视角自阴影 (T_light)

## Overview
Calculates the self-shadowing transmittance $T_{light}$ for each Gaussian along a directional sun direction, representing the 'front occlusion transmittance' to model self-shadowing effects in volume rendering [S1, unofficial]. It differs from standard rasterization by performing a dedicated light-space pass that accumulates front-to-back occlusion without modifying the main camera's sampling expansion or applying amplitude compensation [S1, unofficial]. Builds on [Shading and Lighting Models](11924-shading-and-lighting-models.md) [G] and contrasts with [Ref-Gaussian Deferred Surfel Rendering with Split-Sum IBL](4464-ref-gaussian-deferred-surfel-rendering-with-split-sum-ibl.md) and [Light Space Rasterization for T_light](4489-light-space-rasterization-for-t-light.md) by explicitly tracking front occlusion transmittance per Gaussian footprint rather than deferred surface buffers or alternative light-space projections [S1, unofficial].

## How it works
**Inputs:**
- 3D Gaussian primitives (position, covariance, opacity, color) [G].
- Sun direction vector [S1, unofficial].
- Configuration flags (`--tlight_voxel` for fallback, default rasterization) [S1, unofficial].

**Outputs:**
- Per-Gaussian self-shadowing transmittance $T_{light}$ (stored in `record_front_tau` channel) [S1, unofficial].
- Updated Gaussian attributes with gradients enabled for training [S1, unofficial].

**Data Structures:**
- `record_front_tau`: A buffer aligned with the Gaussian buffer, storing the accumulated front transmittance weighted by weight (energy-weighted mean over the sun-facing footprint) [S1, unofficial].

**Steps:**
1. **Light Camera Setup:** Construct a virtual perspective camera to simulate a directional sun light source. Place it at a large distance with a narrow field of view (FOV) to minimize parallax error to below 2% and avoid modifying the EWA Jacobian [S1, unofficial].
2. **Rasterization Pass:** Perform a CUDA rasterization pass from the sun camera's perspective. Traverse Gaussians in depth order relative to the sun camera [S1, unofficial].
3. **Transmittance Accumulation:** For each Gaussian, calculate its contribution to the front occlusion. Record the accumulated front transmittance $\tau$ weighted by $\tau \times \text{weight}$ into the `record_front_tau` channel. This represents an energy-weighted mean over the entire sun-facing footprint, not just a center point sample [S1, unofficial].
4. **Gradient Handling:** Enable full continuous gradients by default. This includes gradients for $\tau$, weights, normalization, weak density backup transmittance, and projection position/scale/rotation. However, treat sun camera framing, sorting, coverage, and threshold branches as constants to prevent incorrect gradient propagation [S1, unofficial].
5. **Covariance Handling:** Do not expand the projection covariance by $0.3I$ during this light pass, and do not apply amplitude compensation. Keep the sampling expansion from the main camera pass as is [S1, unofficial].
6. **Deeply Buried Gaussians:** Handle deeply buried Gaussians (where early termination causes $wsum=0$) by explicitly mapping them to full shadow to prevent inversion artifacts [S1, unofficial].
7. **Fallback Mode:** If the `--tlight_voxel` flag is passed, use the old $128^3$ voxel cache path. This is compatible with models trained before rasterization support was added [S1, unofficial].

**Pseudocode:**
```python
def compute_tlight(gaussians, sun_direction, use_voxel_fallback=False):
    """
    Compute self-shadowing transmittance T_light for Gaussians.
    
    Args:
        gaussians: List of Gaussian primitives with position, weight, id.
        sun_direction: 3D vector representing the sun direction.
        use_voxel_fallback: Boolean flag to use old voxel cache path.
        
    Returns:
        t_light: Array of transmittance values for each Gaussian.
    """
    if use_voxel_fallback:
        # Fallback to old 128^3 voxel cache path (implementation not provided in sources)
        return [0.0] * len(gaussians)
    
    light_camera = PerspectiveCamera(sun_direction, distance=1e6, fov=1.0)
    sorted_gaussians = sort_by_depth(gaussians, light_camera)
    
    t_light = [0.0] * len(gaussians)
    tau = 1.0
    
    for gaussian in sorted_gaussians:
        weight = gaussian.weight
        tau *= (1.0 - weight)
        
        # Handle deeply buried Gaussians where early termination causes wsum=0
        if tau < 1e-6:
            t_light[gaussian.id] = 0.0
        else:
            # Record accumulated front transmittance weighted by tau * weight
            t_light[gaussian.id] = tau * weight
            
    return t_light

def PerspectiveCamera(direction, distance, fov):
    """Standard perspective camera setup [G]."""
    return {"position": direction * distance, "fov": fov}

def sort_by_depth(gaussians, camera):
    """Sort Gaussians by depth relative to camera [G]."""
    depths = [gaussian.position.dot(camera["position"]) for gaussian in gaussians]
    indices = sorted(range(len(depths)), key=lambda k: depths[k])
    return [gaussians[i] for i in indices]
```

**Parameters:**
- `--tlight_voxel`: Flag to enable old $128^3$ voxel cache fallback path [S1, unofficial].
- `--tlight auto|voxel|raster`: Viewer flag to control shadow source (auto reads training cfg_args) [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Deeply Buried Gaussians:** If early termination causes $wsum=0$, explicitly map to full shadow to prevent inversion artifacts [S1, unofficial].
- **Gradient Propagation:** Treat sun camera framing, sorting, coverage, and threshold branches as constants to prevent incorrect gradient propagation [S1, unofficial].
- **Covariance Expansion:** Do not expand projection covariance by $0.3I$ or apply amplitude compensation during the light pass [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of Gaussians and the rasterization pass. The light-space rasterization adds an additional pass over the Gaussians [S1, unofficial].
- **Memory Complexity:** Requires additional buffer for `record_front_tau` aligned with the Gaussian buffer [S1, unofficial].
- **Strengths:** Provides accurate self-shadowing effects in volume rendering. Compatible with existing training pipelines [S1, unofficial].
- **Limitations:** Requires additional computation for the light pass. Fallback mode may be less efficient or accurate than rasterization [S1, unofficial].
- **When to Use:** When self-shadowing effects are desired in 3D Gaussian Splatting scenes [S1, unofficial].
- **When Not to Use:** When performance is critical and self-shadowing is not necessary [S1, unofficial].

## Background
Developed for volume cloud rendering to model self-shadowing effects in 3D Gaussian Splatting [S1, unofficial]. The method was introduced to address the lack of front occlusion modeling in standard splatting pipelines by introducing a dedicated light-space accumulation pass [S1, unofficial]. It is used in real-time volume cloud viewers and training frameworks that require physically plausible shadowing without modifying the primary camera's EWA projection [S1, unofficial].
