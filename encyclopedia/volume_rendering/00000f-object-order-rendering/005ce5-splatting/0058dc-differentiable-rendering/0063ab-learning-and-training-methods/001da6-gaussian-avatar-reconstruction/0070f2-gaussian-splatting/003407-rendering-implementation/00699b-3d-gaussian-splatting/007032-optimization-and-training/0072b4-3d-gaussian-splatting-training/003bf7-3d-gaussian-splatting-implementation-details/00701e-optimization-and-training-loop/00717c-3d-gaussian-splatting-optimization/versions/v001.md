# 3D Gaussian Splatting Optimization

Also called: 3DGS Optimization, 3DGS Training Procedure

## Overview
This method defines the specific training protocol for 3D Gaussian Splatting, addressing the instability of optimizing anisotropic covariance matrices and view-dependent spherical harmonics (SH) from sparse or incomplete input views. It distinguishes itself from standard differentiable rendering optimization by employing a staged SH introduction schedule and a resolution warm-up phase to prevent incorrect diffuse color estimation in scenes with missing angular coverage [S1, unofficial].

## How it works
**Inputs:** A set of $N$ training images with known camera poses $\{I_i, C_i\}_{i=1}^N$.
**Outputs:** A set of $M$ 3D Gaussians, each defined by mean position $\mu \in \mathbb{R}^3$, covariance matrix $\Sigma \in \mathbb{R}^{3 \times 3}$ (parameterized as rotation $R \in SO(3)$ and scale $s \in \mathbb{R}^3$), opacity $\alpha \in [0, 1]$, and spherical harmonics coefficients $c_{l,m}$ for $l=0..3, m=-l..l$.

**Data Structures:**
*   **Gaussian Attributes:** Stored in contiguous arrays for GPU access.
    *   $\mu$: Float32, size $3M$.
    *   $R$: Quaternion representation (Float32, size $4M$), normalized to unit length after every update.
    *   $s$: Float32, size $3M$.
    *   $\alpha$: Float32, size $M$.
    *   $c$: Float32, size $M \times 16 \times 3$ (4 bands $\times$ 7 coefficients $\times$ 3 RGB channels). Note: The zero-order band ($l=0$) has 1 coefficient; higher bands have 3, 5, 7.
*   **Optimizer State:** Adam optimizer states (mean and variance estimates) for $\mu, R, s, \alpha, c$.

**Initialization:**
1.  **Synthetic Bounded Scenes:** Initialize $M_0 = 100,000$ Gaussians with positions $\mu$ uniformly distributed within the bounding volume of the scene. Opacity $\alpha$ is initialized to a small value. Covariance is isotropic initially. These are automatically pruned to 6,000–10,000 meaningful Gaussians during early training [S1, unofficial].
2.  **Real-World Scenes:** Initialize from Structure-from-Motion (SfM) points. Each point becomes a Gaussian with isotropic covariance scaled by a factor. Opacity is initialized to 0.5 [S1, unofficial].

**Optimization Steps:**
The optimization runs for a fixed budget of 30,000 iterations.

1.  **Resolution Warm-up:**
    *   Start training at $1/4$ of the target image resolution.
    *   Upsample resolution by a factor of 2 after iteration 250.
    *   Upsample resolution by a factor of 2 after iteration 500.
    *   This stabilizes the optimization of high-frequency details [S1, unofficial].

2.  **Staged Spherical Harmonics Introduction:**
    *   To prevent incorrect zero-order SH (diffuse color) values due to missing angular regions (e.g., corners, inside-out captures), only the zero-order SH band ($l=0$) is optimized initially.
    *   After every 1,000 iterations, one additional SH band is enabled for optimization.
    *   Bands are introduced in order: $l=0$, then $l=1$, $l=2$, and finally $l=3$.
    *   Coefficients for disabled bands are frozen or not updated [S1, unofficial].

3.  **Per-Iteration Loop:**
    For each iteration $t$:
    a. **Sampling:** Randomly select a training image $I_{gt}$ and its camera pose $C$.
    b. **Rendering:** Project all active Gaussians to 2D. Sort by depth. Alpha-blend to produce $\hat{I}$.
    c. **Loss Computation:** Compute photometric loss:
       $$ \mathcal{L} = (1 - \lambda) \mathcal{L}_{L1}(\hat{I}, I_{gt}) + \lambda \mathcal{L}_{D-SSIM}(\hat{I}, I_{gt}) $$
       where $\lambda = 0.2$ [S1, unofficial].
    d. **Backpropagation:** Compute gradients $\nabla \mathcal{L}$ with respect to all trainable parameters.
       *   **Critical Constraint:** Gradients are computed for *all* depth-composited Gaussians, not just the front-most $N$ points. Limiting gradient computation to the front-most points (e.g., $N=10$) causes unstable optimization and severe quality degradation (e.g., 11dB PSNR drop in the Truck scene) [S1, unofficial].
    e. **Update:** Apply Adam optimizer updates with $\beta_1 = 0.9, \beta_2 = 0.99$.
    f. **Densification/Pruning:** (See [3D Gaussian Splatting Training Loop](15139-3d-gaussian-splatting-training-loop.md) for specific frequency and thresholds).

**Pseudocode:**

```python
def optimize_3dgs(gaussians, training_images, num_iterations=30000):
    # Initialize Adam optimizer for mu, R, s, alpha, SH_coeffs
    optimizer = Adam(gaussians.parameters(), lr=1e-4, betas=(0.9, 0.99))
    
    # Resolution warm-up schedule
    current_res_scale = 0.25
    if iteration == 250: current_res_scale = 0.5
    if iteration == 500: current_res_scale = 1.0
    
    # SH band introduction schedule
    # 0: l=0, 1: l=0+1, 2: l=0+1+2, 3: l=0+1+2+3
    current_sh_band = 0 
    
    for t in range(num_iterations):
        # 1. Sampling
        img_idx = random.choice(range(len(training_images)))
        gt_image, camera = training_images[img_idx]
        
        # 2. Resolution Scaling
        render_width = int(gt_image.width * current_res_scale)
        render_height = int(gt_image.height * current_res_scale)
        
        # 3. Rendering (Differentiable Rasterization)
        # Projects Gaussians, sorts by depth, alpha-blends
        rendered_image = rasterize(gaussians, camera, render_width, render_height)
        
        # 4. Loss Computation
        # L1 and D-SSIM losses
        l1_loss = l1_loss(rendered_image, gt_image)
        ssim_loss = d_ssim_loss(rendered_image, gt_image)
        loss = 0.8 * l1_loss + 0.2 * ssim_loss
        
        # 5. Backpropagation
        # Compute gradients for ALL composited Gaussians
        loss.backward()
        
        # 6. Update Parameters
        optimizer.step()
        optimizer.zero_grad()
        
        # 7. Staged SH Introduction
        # Enable one SH band every 1000 iterations
        if t > 0 and t % 1000 == 0:
            if current_sh_band < 3:
                current_sh_band += 1
                enable_sh_band(gaussians, current_sh_band)
        
        # 8. Densification/Pruning (Periodic)
        if t % 100 == 0: # Example frequency
            densify_and_prune(gaussians, camera, rendered_image, gt_image)
            
        # 9. Regularization (if applicable, e.g., opacity penalty)
        # Apply opacity regularization to prevent opacity explosion
        apply_opacity_regularization(gaussians)
```

**Edge Cases and Pitfalls:**
*   **Missing Angular Coverage:** In scenes with missing views (e.g., corners), optimizing all SH bands from the start leads to incorrect diffuse colors. The staged introduction mitigates this [S1, unofficial].
*   **Gradient Limiting:** Limiting gradient computation to the front-most $N$ Gaussians (as done in some other splatting methods like Pulsar) is detrimental. It causes unstable optimization and significant PSNR drops (e.g., 11dB in Truck scene) [S1, unofficial].
*   **Popping Artifacts:** Large Gaussians created during optimization can cause popping artifacts, often due to trivial rejection via guard bands in the rasterizer and depth order switches. A more principled culling approach is needed [S1, unofficial].
*   **Isotropic vs. Anisotropic:** Optimizing a single scalar radius (isotropic) instead of the full covariance matrix (anisotropic) significantly reduces alignment with surfaces and rendering quality [S1, unofficial].

## Operating characteristics
*   **Training Time:**
    *   Synthetic NeRF scenes: 30,000 iterations take approximately 35–45 minutes on a single NVIDIA A6000 GPU [S1, unofficial].
    *   Mip-NeRF360 scenes: 48 hours on a single GPU (equivalent to 12 hours on a 4-GPU A100 node) [S1, unofficial].
    *   Tanks & Temples scenes: ~7 minutes [S1, unofficial].
*   **Rendering Speed:** Trained synthetic scenes render at 180–300 FPS on an A6000 GPU [S1, unofficial]. Mip-NeRF360 renders at 10s/frame [S1, unofficial].
*   **Model Size:**
    *   Synthetic scenes: 200,000–500,000 Gaussians after 30,000 iterations [S1, unofficial].
    *   Compactness: Uses ~1/4 the point count of Zhang et al. [2022] for comparable PSNR, resulting in 3.8 MB vs 9 MB model size [S1, unofficial].
*   **Strengths:**
    *   Fast convergence compared to NeRF-based methods (InstantNGP, Plenoxels) [S1, unofficial].
    *   Anisotropic covariance allows better surface alignment [S1, unofficial].
    *   SH bands effectively model view-dependent effects [S1, unofficial].
*   **Limitations:**
    *   Popping artifacts in regions with view-dependent appearance [S1, unofficial].
    *   Elongated artifacts or "splotchy" Gaussians in poorly observed regions [S1, unofficial].
    *   Quality degrades significantly if gradient computation is limited to front-most points [S1, unofficial].

## Background
3D Gaussian Splatting optimization was introduced in the paper "3D Gaussian Splatting for Real-Time Radiance Field Rendering" by Kerbl et al. [2023]. The method builds on differentiable rasterization techniques extended from Kopanas et al. [2021] and uses NVIDIA CUB sorting routines for Radix sort [Merrill and Grimshaw 2010]. It was evaluated on 13 real scenes (Mip-NeRF360, Tanks&Temples, Hedman et al.) and synthetic Blender dataset scenes, using an A6000 GPU for most results [S1, unofficial].
