# Barycentric Splat Parameterization

Also called: GeoSplatting Face-Sampling, Heuristic Gaussian sampling from triangles, Mesh-Gaussian binding via midpoints, Splat center derivation from mesh faces

## Overview
Barycentric Splat Parameterization constrains 2D Gaussian Splat centers to lie on triangular mesh faces using barycentric coordinates, allowing splats to move freely on the face while preserving per-splat attributes [S1]. It differs from sibling methods by deriving Gaussian geometry directly from mesh topology via heuristic midpoint sampling rather than learning orientation vectors or skewness parameters [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangular mesh face $F_i$ with vertices $v_1, v_2, v_3$, vertex positions $\mathbf{P}_i = (v_1, v_2, v_3)$, vertex normals $\mathbf{N}_i = (n_1, n_2, n_3)$, and hyperparameters $u, v, \alpha_{jk}, \beta_{jk}, \delta_{jk}$.
*   **Output:** A set of 3D Gaussians sampled from the face, defined by center $\mu$, covariance (via scaling $s$ and rotation $R$), and opacity/color attributes interpolated from vertices.

**Data Structures:**
*   **Barycentric Coordinates:** Scalars $u, w \in [0, 1]$ such that $u + w \le 1$.
*   **Midpoints:** Six midpoints $m_{jk}$ per triangle, defined by specific barycentric weights.
*   **Attributes:** Vertex attributes $\mathbf{A}_i = (a_{i1}, a_{i2}, a_{i3})$ (e.g., color, normal).

**Steps:**

1.  **Compute Midpoints:**
    Calculate the barycentric coordinates for six midpoints $m_{jk}$ associated with the triangle edges and internal structure. The sources define these as:
    $$
    \begin{aligned}
    m_{12} &= ((1-u)/2, (1-u)/2, u) \\
    m_{23} &= ((1-u)/2, (1-u)/2, u) \\
    m_{31} &= ((1-u)/2, u, (1-u)/2) \\
    m_{45} &= ((1-v)/2, (1-v)/2, v) \\
    m_{56} &= ((1-v)/2, (1-v)/2, v) \\
    m_{64} &= ((1-v)/2, v, (1-v)/2)
    \end{aligned}
    $$
    [S2] Note: The source [S2] lists identical coordinates for $m_{12}$ and $m_{23}$, and for $m_{45}$ and $m_{56}$. This is preserved as written in the source.

2.  **Interpolate Attributes:**
    For any barycentric coordinate $(q_1, q_2, q_3)$, interpolate an attribute $\mathbf{A}_i$ defined at the triangle vertices:
    $$
    (q_1, q_2, q_3) \odot \mathbf{A}_i = q_1 \mathbf{a}_{i1} + q_2 \mathbf{a}_{i2} + q_3 \mathbf{a}_{i3}
    $$
    [S2]

3.  **Sample Gaussian Parameters:**
    For each midpoint $m_{jk}$, compute the Gaussian parameters using the heuristic function $T$:
    $$
    \begin{aligned}
    \text{centerPos} &= m_{jk} \odot \mathbf{P}_i \\
    \text{normal} &= m_{jk} \odot \mathbf{N}_i \\
    \text{scaling}_x &= \alpha_{jk} \| \mathbf{b}_k \odot \mathbf{P}_i - m_{jk} \odot \mathbf{P}_i \|_2 \\
    \text{rotation}_x &= \frac{\mathbf{b}_k \odot \mathbf{P}_i - m_{jk} \odot \mathbf{P}_i}{\| \mathbf{b}_k \odot \mathbf{P}_i - m_{jk} \odot \mathbf{P}_i \|_2} \\
    \text{scaling}_y &= \frac{\text{Area}(F_i)}{\beta_{jk} \| \mathbf{b}_k \odot \mathbf{P}_i - m_{jk} \odot \mathbf{P}_i \|_2} \\
    \text{rotation}_y &= \text{normal} \times \text{rotation}_x \\
    \text{scaling}_z &= \delta_{jk} \\
    \text{rotation}_z &= \text{normal}
    \end{aligned}
    $$
    [S2]
    *   $\mathbf{b}_k$ is not explicitly defined in the provided text but is used in the vector difference. In the context of barycentric interpolation, $\mathbf{b}_k$ likely refers to a specific vertex or basis vector associated with the midpoint index $k$. Given the structure, $\mathbf{b}_k \odot \mathbf{P}_i$ represents a vertex position. For midpoints on edges, $\mathbf{b}_k$ corresponds to one of the edge vertices. [G] Implementation note: $\mathbf{b}_k$ should be mapped to the appropriate vertex index based on the midpoint definition (e.g., for $m_{12}$, $\mathbf{b}_k$ might be $v_1$ or $v_2$). The source uses $\mathbf{b}_k$ generically.

4.  **Alternative Center Parameterization (Free Movement):**
    To allow splats to move freely on the face, the center $m$ can be parameterized directly using barycentric coordinates $u, w$:
    $$
    m = u \cdot v_1 + w \cdot v_2 + (1 - u - w) \cdot v_3
    $$
    [S1]

5.  **Scale Constraints:**
    To prevent discrepancies between Gaussian scales and mesh face scales, impose bounds:
    $$
    s = s_{rel} \odot s_0
    $$
    where $s_{rel} \in [s_{min}, s_{max}] \times [s_{min}, s_{max}]$ and $s_0$ is a predefined scale derived from the mesh faces. [S1]

6.  **In-Plane Rotation:**
    Introduce an in-plane rotation parameter $R_{2d}$ to model orientation on the face plane, transformed to world space. [S1]

**Parameters:**
Typical hyperparameters for generalized geometric alignment [S2]:
*   $u = 0.07$
*   $v = 0.22$
*   $\alpha_{12}=\alpha_{23}=\alpha_{31}=0.80$
*   $\alpha_{45}=\alpha_{56}=\alpha_{64}=2.08$
*   $\beta_{12}=\beta_{23}=\beta_{31}=15.0$
*   $\beta_{45}=\beta_{56}=\beta_{64}=13.0$
*   $\delta_{12}=\delta_{23}=\delta_{31}=\delta_{45}=\delta_{56}=\delta_{64}=4.5 \times 10^{-5}$

**Edge Cases and Pitfalls:**
*   **Degenerate Triangles:** If $\text{Area}(F_i) \approx 0$, $\text{scaling}_y$ becomes undefined or extremely large. Guard against division by zero.
*   **Zero-Length Edges:** If $\| \mathbf{b}_k \odot \mathbf{P}_i - m_{jk} \odot \mathbf{P}_i \|_2 \approx 0$, $\text{rotation}_x$ and $\text{scaling}_x$ become undefined. [G] Add a small epsilon to the denominator.
*   **Mesh Removal:** When a face is removed, all splats mapped to it must be flagged for removal. [S1]

## Operating characteristics
*   **Time Complexity:** Linear in the number of mesh faces, as each face generates a fixed number of Gaussians (6 midpoints).
*   **Memory Complexity:** Proportional to the number of mesh faces.
*   **Strengths:** Ensures geometric consistency by binding Gaussians to explicit mesh geometry. Allows for efficient initialization and updates based on mesh changes.
*   **Limitations:** Relies on the quality of the input mesh. Heuristic parameters may require tuning for different scenes. The source [S2] notes identical coordinates for some midpoints, which may be a typo or specific design choice not fully explained.

## Background
Originated in GeoSplatting [S2] and OMeGa [S1] for robust scene-level surface reconstruction and physically-based inverse rendering. It addresses the lack of inherent geometry boundaries in standard 3DGS by deriving Gaussians from mesh faces.
