# Steerable Densification with Sampling

Also called: Score-based ranking densification

## Overview
Steerable Densification with Sampling is a density control method for 3D Gaussian Splatting that uses image loss and per-Gaussian attributes to rank primitives for resampling, executed at a significantly reduced frequency to prevent over-densification [S1]. It differs from standard 3DGS densification by replacing deterministic gradient-based splitting with a probabilistic, score-weighted sampling process, allowing for more interpretable and stable convergence [S1].

## How it works
**Inputs:**
*   Set of $M$ 3D Gaussians $\mathcal{G} = \{g_j\}_{j=1}^M$.
*   Set of $N$ training camera views $\mathcal{V} = \{v_i\}_{i=1}^N$.
*   Rendered images $\mathcal{R} = \{r_i\}_{i=1}^N$ corresponding to $\mathcal{V}$.
*   Ground truth images $\mathcal{I} = \{I_i\}_{i=1}^N$.
*   Densification budget $B$ (number of new primitives to add).
*   Hyperparameters: $\lambda_1=0.5, \lambda_2=0.5$ (saliency weights), scoring weights $w_{\nabla}=50, w_{c}=0.1, w_{D}=50, w_{S}=10, w_{B}=50, w_{z}=5, w_{o}=100, w_{s}=25$ [S1].

**Outputs:**
*   Updated set of Gaussians $\mathcal{G}'$ with $M+B$ primitives (before pruning).

**Data Structures:**
*   Per-view saliency matrix $S_v \in \mathbb{R}^{H \times W}$ for each view $v$.
*   Global score vector $S_G \in \mathbb{R}^M$, where $S_{G,j}$ is the score for Gaussian $g_j$.

**Steps:**

1.  **Compute Per-View Saliency Matrices:**
    For each view $v_i \in \mathcal{V}$:
    *   Compute L1 loss map: $L_1(v_i, r_i) = |I_i - r_i|$.
    *   Compute Laplacian filter map: $E(v_i)$ (high-pass filter on $r_i$ or $I_i$).
    *   Define binary ROI mask $\mathbb{1}_{ROI} \in \{0,1\}^{H \times W}$.
    *   Calculate saliency:
        $$ S_{v_i} = \mathbb{1}_{ROI} \odot (\lambda_1 L_1(v_i, r_i) + \lambda_2 E(v_i)) $$
        [S1]

2.  **Compute Gaussian Scores:**
    Initialize $S_G = \mathbf{0} \in \mathbb{R}^M$.
    For each Gaussian $g_j \in \mathcal{G}$:
    *   Perform an auxiliary rendering pass or use cached projection data to obtain per-pixel attributes for all views $v_i$ where $g_j$ contributes.
    *   For each contributing pixel $p$ in view $v_i$:
        *   Retrieve attributes:
            *   $\nabla_{g_j}$: Positional gradient magnitude.
            *   $c_{g_j, i}$: Number of pixels covered by $g_j$ in view $i$.
            *   $\mathbb{1}_{g_j}$: Binary mask of pixels covered by $g_j$.
            *   $D_{g_j}$: Distance of pixel $p$ to the center of $g_j$.
            *   $S_{v_i}$: Saliency value at pixel $p$.
            *   $B_{g_j}$: Blending weight of $g_j$ at pixel $p$.
            *   $z_{g_j}$: Depth of $g_j$ in view $i$.
            *   $o_{g_j}$: Opacity of $g_j$.
            *   $s_{g_j}$: Scale of $g_j$.
        *   Apply median scaling to remove outliers for each attribute across the dataset or view [S1].
        *   Compute local score contribution $F$:
            $$ F = \sum_{k \in \text{attrs}} w_k \cdot \text{scaled}(attr_k) \cdot L_1(v_i, r_i) $$
            Where $w_k$ are the predefined weights [S1].
        *   Accumulate to Gaussian score:
            $$ S_{G,j} \leftarrow S_{G,j} + \sum_{p \in \text{covered}} F $$
    *   Normalize $S_G$ if necessary for sampling [G].

3.  **Resampling (Densification):**
    *   Sample $B$ indices from $\{1, \dots, M\}$ using $S_G$ as probability weights (with replacement or without, typically with replacement for budgeted addition) [S1].
    *   For each sampled Gaussian $g_{src}$:
        *   Clone $g_{src}$ to create a new Gaussian $g_{new}$.
        *   Set $g_{new}$ position, scale, rotation identical to $g_{src}$ [G].
        *   Set $g_{new}$ opacity to $o_{src} / 2$ [G, consistent with parent principles].
    *   Add $g_{new}$ to $\mathcal{G}$ [S1].

4.  **Pruning:**
    *   Apply standard pruning rules from parent method: remove Gaussians with opacity $< \tau_{opac}$ or excessive size [3034-adaptive-densification.md].

**Pseudocode:**

```python
def steerable_densification(Gaussians, Views, Rendered, GroundTruth, Budget, Iteration):
    # Step 1: Compute Saliency Matrices
    SaliencyMatrices = []
    for v in Views:
        L1_Loss = abs(GroundTruth[v] - Rendered[v])
        Laplacian = apply_laplacian_filter(Rendered[v])
        ROI_Mask = get_roi_mask(v) # Binary matrix
        S_v = ROI_Mask * (0.5 * L1_Loss + 0.5 * Laplacian)
        SaliencyMatrices.append(S_v)

    # Step 2: Compute Gaussian Scores
    GaussianScores = zeros(len(Gaussians))
    
    # Weights for scoring function
    weights = {
        'grad': 50, 'count': 0.1, 'dist': 50, 'saliency': 10,
        'blend': 50, 'depth': 5, 'opacity': 100, 'scale': 25
    }
    
    # Median scaling factors (computed globally or per attribute)
    # Note: In practice, these are computed from the current set of attributes
    median_scales = compute_median_scales(Gaussians, Views, SaliencyMatrices)

    for j, g in enumerate(Gaussians):
        score = 0.0
        # Retrieve per-pixel data for this Gaussian across all views
        # This requires an auxiliary pass or cached projection data
        pixels_data = get_gaussian_pixel_data(g, Views)
        
        for view_idx, view in enumerate(Views):
            if view not in pixels_data: continue
            
            L1_val = L1_Loss_map[view_idx] # Per-pixel L1 loss
            S_v = SaliencyMatrices[view_idx]
            
            for p in pixels_data[view]:
                # Get attributes
                grad_mag = p.grad_magnitude
                count = p.pixel_count # c_gi
                dist = p.distance_to_center
                saliency_val = S_v[p.y, p.x]
                blend_weight = p.blending_weight
                depth = p.depth
                opacity = g.opacity
                scale = g.scale
                
                # Median scaling
                scaled_grad = grad_mag / median_scales['grad']
                scaled_count = count / median_scales['count']
                scaled_dist = dist / median_scales['dist']
                scaled_saliency = saliency_val / median_scales['saliency']
                scaled_blend = blend_weight / median_scales['blend']
                scaled_depth = depth / median_scales['depth']
                scaled_opacity = opacity / median_scales['opacity']
                scaled_scale = scale / median_scales['scale']
                
                # Weighted sum
                local_score = (
                    weights['grad'] * scaled_grad +
                    weights['count'] * scaled_count +
                    weights['dist'] * scaled_dist +
                    weights['saliency'] * scaled_saliency +
                    weights['blend'] * scaled_blend +
                    weights['depth'] * scaled_depth +
                    weights['opacity'] * scaled_opacity +
                    weights['scale'] * scaled_scale
                )
                
                # Multiply by photometric loss (L1)
                # Note: L1_val is per-pixel, so we sum over pixels
                score += local_score * L1_val[p.y, p.x]
                
        GaussianScores[j] = score

    # Step 3: Resampling
    # Normalize scores to probabilities
    total_score = sum(GaussianScores)
    if total_score > 0:
        probs = GaussianScores / total_score
    else:
        probs = ones(len(Gaussians)) / len(Gaussians)
        
    # Sample B indices
    sampled_indices = random_choice(len(Gaussians), size=Budget, p=probs)
    
    new_gaussians = []
    for idx in sampled_indices:
        src_g = Gaussians[idx]
        new_g = clone(src_g)
        new_g.opacity /= 2.0
        new_gaussians.append(new_g)
        
    Gaussians.extend(new_gaussians)
    
    # Step 4: Pruning (from parent method)
    Gaussians = prune_low_opacity(Gaussians, threshold=0.005)
    Gaussians = prune_large_gaussians(Gaussians)
    
    return Gaussians
```

## Operating characteristics
*   **Time Complexity:** Adds an $O(N \times W \times H)$ step for computing saliency matrices, plus an auxiliary rendering pass to obtain per-Gaussian attributes for scoring [S1].
*   **Frequency:** Densification is executed every 500 iterations, which is one-fifth of the standard 3DGS frequency (every 100 iterations) [S1].
*   **Views:** Uses $N=10$ uniformly sampled training views for computing saliency scores [S1].
*   **Strengths:** Reduces wasteful duplication of misplaced Gaussians by lowering frequency and using loss-guided sampling; improves generalizability to unseen views [S1].
*   **Limitations:** Higher computational overhead per densification step due to saliency computation and auxiliary pass [S1].

## Background
Proposed in "Taming 3DGS: High-Quality Radiance Fields with Limited Resources" (2024) [S1]. The method addresses the issue that frequent densification guided solely by gradients can lead to superfluous Gaussians and poor generalization [S1]. It introduces a score-based ranking system to steer densification based on image loss and geometric attributes.
