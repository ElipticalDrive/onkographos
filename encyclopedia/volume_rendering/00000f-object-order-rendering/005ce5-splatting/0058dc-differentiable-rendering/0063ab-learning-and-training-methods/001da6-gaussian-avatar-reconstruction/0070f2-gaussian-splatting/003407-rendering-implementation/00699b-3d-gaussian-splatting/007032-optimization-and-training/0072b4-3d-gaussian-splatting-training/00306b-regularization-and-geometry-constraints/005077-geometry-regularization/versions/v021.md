# Geometry Regularization

Also called: Gaussian Flattening, Normal Consistency and Flattening

## Overview
Geometry regularization improves the geometric validity and smoothness of 3D Gaussian Splatting models by constraining the shape and orientation of the Gaussians, distinct from depth supervision which only constrains their location [S1, unofficial]. It sets itself apart from sibling methods like [Frequency Regularization](6130-frequency-regularization.md) by focusing on spatial surface alignment rather than spectral fidelity, and from [Hard and Soft Depth Regularization](9178-hard-and-soft-depth-regularization.md) by enforcing normal consistency and kernel flattening rather than just depth buffer matching.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Per-Gaussian scaling factors $s \in \mathbb{R}^3$, per-Gaussian normals $n_g$, rendered depth map $D$, and rendered normal map $N_r$.
*   **Outputs:** Gradient updates for Gaussian parameters to enforce surface alignment and flattening.

**Data Structures:**
*   **Gaussian Parameters:** Each Gaussian $i$ has a scaling vector $s_i = [s_{i,x}, s_{i,y}, s_{i,z}]^T$ and a normal vector $n_{g,i}$.
*   **Rendered Maps:** Depth $D(u,v)$ and Normal $N_r(u,v)$ at pixel coordinates $(u,v)$.

**Steps:**
1.  **Enable Flag:** Check if `use_normal_loss` is true in `OptimizationParams` [S1, unofficial].
2.  **Depth Normal Consistency:**
    *   Compute normals $N_r$ from the rendered depth map $D$ using finite differences or a differentiable normal estimator.
    *   For each pixel $(u,v)$, identify the contributing Gaussians.
    *   Calculate the alignment loss between the rendered normal $N_r(u,v)$ and the per-Gaussian normal $n_{g,i}$ of the dominant Gaussian at that pixel.
    *   Loss term: $L_{normal} = \sum_{u,v} (1 - N_r(u,v) \cdot n_{g, \text{dominant}(u,v)})$ [S1, unofficial].
3.  **Flattening Surface:**
    *   For each Gaussian $i$, identify the smallest component of the scaling factor $s_i$. Let $s_{min,i} = \min(s_{i,x}, s_{i,y}, s_{i,z})$ [S2, unofficial].
    *   Minimize $s_{min,i}$ towards zero during optimization. This flattens the Gaussian into a 3D surfel aligned with the surface [S2, unofficial].
    *   Loss term: $L_{flatten} = \sum_i s_{min,i}$ [S2, unofficial].
4.  **Total Loss:** Combine with photometric loss. $L_{total} = L_{photo} + \lambda_{norm} L_{normal} + \lambda_{flat} L_{flatten}$.

**Parameters:**
*   `use_normal_loss`: Boolean flag to enable geometry regularization [S1, unofficial].
*   $\lambda_{norm}, \lambda_{flat}$: Weights for normal consistency and flattening losses. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Depth Refitting:** Depth maps must be refitted against a prior point cloud to the same scale before use. Depth maps that fail refitting are discarded [S1, unofficial].
*   **Precision:** Minimizing scaling factors to zero can lead to numerical instability if not clamped. Not given in the sources.

**Pseudocode:**
```python
def geometry_regularization_loss(gaussians, rendered_depth, rendered_normal, params):
    """
    Computes geometry regularization loss for 3D Gaussian Splatting.
    
    Args:
        gaussians: Object containing per-Gaussian properties.
            - gaussians.s: Scaling factors, shape (N, 3).
            - gaussians.n: Normals, shape (N, 3).
        rendered_depth: Rendered depth map, shape (H, W).
        rendered_normal: Rendered normal map, shape (H, W, 3).
        params: Optimization parameters.
            - params.use_normal_loss: Boolean.
            
    Returns:
        loss: Scalar loss value.
    """
    if not params.use_normal_loss:
        return 0.0

    loss = 0.0
    
    # 1. Depth Normal Consistency
    # Note: rendered_normal is assumed to be pre-computed from rendered_depth
    # or passed directly. We align it with per-Gaussian normals.
    # In practice, this requires identifying the dominant Gaussian per pixel.
    # For simplicity, we assume a mask or weighting is available.
    # Here we compute the dot product loss for all pixels where depth is valid.
    
    valid_mask = rendered_depth > 0
    if not np.any(valid_mask):
        return 0.0
        
    # Get dominant Gaussian normals for valid pixels
    # This step requires a 'get_dominant_gaussian_normals' function which is
    # not explicitly defined in sources but implied by "per-Gaussian normals"
    # alignment. We assume this helper exists or is implemented via alpha blending.
    # [G] Placeholder for dominant Gaussian selection logic.
    dominant_normals = get_dominant_gaussian_normals(gaussians, rendered_depth)
    
    # Compute normal consistency loss
    # Dot product should be 1 for aligned normals
    dot_products = np.sum(dominant_normals * rendered_normal, axis=-1)
    normal_loss = np.mean(1.0 - dot_products[valid_mask])
    
    # 2. Flattening Surface
    # Minimize the smallest component of the scaling factor towards zero
    s = gaussians.s # Shape (N, 3)
    min_s = np.min(s, axis=1) # Shape (N,)
    flatten_loss = np.mean(min_s)
    
    # Combine losses
    # [G] Typical weights are not specified in sources. Using 1.0 for demonstration.
    loss = normal_loss + flatten_loss
    
    return loss
```

## Subtopics

### Scaling Loss for Geometry Modeling
A regularization technique to flatten Gaussian kernels into 3D surfels aligned with the surface by minimizing the smallest component of the scaling factor towards zero [S2, unofficial]. This aids in determining Gaussian normals by selecting the shortest scaled edge [S2, unofficial]. It is chosen when explicit normal supervision is unavailable or to complement it with shape constraints. It is a core component of Geometry Regularization [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Adds overhead proportional to the number of Gaussians and pixels for normal computation and scaling factor analysis. Not given in the sources.
*   **Memory Complexity:** Requires storing rendered depth and normal maps. Not given in the sources.
*   **Strengths:** Improves geometric smoothness, reduces floaters, and disentangles sky/background from foreground geometry [S1, unofficial].
*   **Limitations:** Requires accurate depth maps and normal estimation. Depth refitting failures can lead to discarded data [S1, unofficial].
*   **When to use:** When geometric accuracy is critical and depth/normal priors are available.
*   **When not to use:** When depth maps are unreliable or unavailable without prior point cloud refitting.

## Background
Originated in the context of improving 3D Gaussian Splatting training stability and geometric fidelity.
