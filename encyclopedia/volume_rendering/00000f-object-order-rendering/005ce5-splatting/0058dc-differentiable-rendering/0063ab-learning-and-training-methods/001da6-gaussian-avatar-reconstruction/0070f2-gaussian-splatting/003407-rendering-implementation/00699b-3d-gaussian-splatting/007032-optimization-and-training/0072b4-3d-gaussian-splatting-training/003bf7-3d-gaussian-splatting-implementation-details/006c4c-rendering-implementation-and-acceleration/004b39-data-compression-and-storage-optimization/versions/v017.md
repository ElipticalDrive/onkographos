# Data Compression and Storage Optimization

Also called: 3DGS Compression, Gaussian Quantization, Codebook-Based Compression

## Overview
This family of methods reduces the storage footprint and transmission bandwidth of 3D Gaussian Splatting models by compressing geometric attributes (position, scale, rotation), opacity, and view-dependent color (spherical harmonic coefficients) [S1, S2, unofficial]. Unlike [Hardware and Computational Acceleration](16214-hardware-and-computational-acceleration.md) which focuses on rendering speed, or [Occupancy Region Derivation & ϵ-Intersection Criterion](19020-occupancy-region-derivation-intersection-criterion.md) which optimizes visibility, these techniques address the linear scaling of Gaussian counts and the high dimensionality of SH coefficients [S1, unofficial]. They achieve compression ratios of ~10× to 25× with minimal quality loss by using quantization, codebooks, and pruning [S1, S2, unofficial].

## Shared principles
All methods in this family operate on the set of $N$ 3D Gaussians $\{G_i\}$, where each $G_i$ is defined by mean $\mu_i$, covariance $\Sigma_i$ (derived from scale $\hat{s}_i$ and rotation $r_i$), opacity $\alpha_i$, and spherical harmonic coefficients $c_i$ [S1, unofficial]. The core principle is replacing high-precision, per-primitive storage with compact representations:
1.  **Codebook/Vector Quantization:** Geometric and color attributes are clustered into a small set of representative vectors (codebooks). Each Gaussian stores only an index into the codebook rather than the full attribute vector [S1, S2, unofficial].
2.  **Quantization-Aware Training (QAT):** To recover quality lost during discretization, models are often fine-tuned using simulated quantization in the forward pass and continuous gradients in the backward pass [S1, S2, unofficial].
3.  **Pruning:** Redundant Gaussians are removed based on importance scores or learnable masks, reducing $N$ [S1, S2, unofficial].
4.  **Spatial Compression:** Indices are sorted using Z-order (Morton) codes to exploit spatial coherence before applying lossless compression (e.g., DEFLATE) [S1, S2, unofficial].

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
A technique for optimizing data transmission speed by encoding numerical attributes into ASCII strings using base-95 and base-94 integer/floating-point encoding. It accepts a trade-off where complex structures like color matrices are only partially compressed due to traversal overhead.

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
A compression scheme that reduces storage by clustering SH coefficients and shape parameters into compact codebooks, weighted by a sensitivity measure derived from the normalized gradient of image energy. It prioritizes preserving parameters that significantly affect image quality, distinguishing it from standard post-training quantization.

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
Reduces storage and latency by pruning redundant primitives and exploiting spatial redundancy. It replaces per-Gaussian SH storage with a hash-based neural field and quantizes geometry via a shared codebook, achieving over 25× compression. It specifically targets the linear scaling of Gaussian counts and high-dimensional SH coefficients.

### [Monte Carlo Specular Energy Aggregator](15439-monte-carlo-specular-energy-aggregator.md)
Compresses high-order (third-order) SH radiance into a compact lower-order (first-order) subspace by mapping specular energy residuals via Monte Carlo projection. It preserves specular features without pre-training or distillation, replacing teacher-student distillation to improve training efficiency.

### Sparse Adaptive Scalable Compact Gaussian Splatting
A compression method that utilizes vector clustering to encode color and geometric attributes into two codebooks, employing a sensitivity-aware k-means method [S1, unofficial].

### 3DGS Quantization Compression
Reduces storage footprint by quantizing per-Gaussian attributes and using codebooks, achieving ~10× smaller sizes without significant quality loss [S2, unofficial]. Layout includes position (FP16), scales (FP16), opacity (INT8), and SH coefficients (INT8 or codebook-based) [S2, unofficial].

## Background
The explosion of Gaussian counts in 3DGS (often millions) creates storage and transmission bottlenecks [S1, unofficial]. Early compression efforts focused on post-training quantization and pruning [S1, unofficial]. Recent advances integrate compression into the training loop via QAT and sensitivity-aware clustering to maintain visual fidelity [S1, S2, unofficial]. Methods like C3DGS and MC-SEA address specific inefficiencies in SH representation and geometric redundancy [S1, unofficial].
