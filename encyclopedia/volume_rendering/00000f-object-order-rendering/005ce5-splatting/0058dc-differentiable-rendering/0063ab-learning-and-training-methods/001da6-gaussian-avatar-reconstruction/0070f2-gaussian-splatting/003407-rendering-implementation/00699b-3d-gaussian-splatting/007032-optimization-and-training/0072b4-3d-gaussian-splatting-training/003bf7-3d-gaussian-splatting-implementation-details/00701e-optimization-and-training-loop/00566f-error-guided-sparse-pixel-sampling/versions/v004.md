# Error-Guided Sparse Pixel Sampling

Also called: Err-SPS, Tile-Wise Pixel Sampling (EPS), Tile-wise Sparse Pixel Sampling, sparse pixel training

## Overview
Error-Guided Sparse Pixel Sampling (Err-SPS) is a training optimization strategy for 3D Gaussian Splatting that replaces dense per-pixel rasterization and supervision with a sparse, error-guided sampling strategy [S1, unofficial]. It dynamically reallocates computation from well-reconstructed regions to challenging regions, significantly reducing training time and Gaussian count while preserving high-frequency details when combined with structure-aware losses [S1, unofficial]. It differs from sibling methods by specifically defining the tile-wise sampling logic and the associated EMA update rules for the error and age maps, which serve as the foundation for the broader TurboGS framework [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Current set of 3D Gaussians $G$, camera views $V_t$ for tile $t$, ground truth images $I$, current Error Map $E$, current Age Map $A$, training progress $\rho_t \in [0, 1)$, and sampling schedule parameters $K_{max}, K_{min}$ [S1, unofficial].
*   **Outputs:** A subset of sampled pixels $P_{t,v}$ per view $v$ in tile $t$, updated Error Map $E$, updated Age Map $A$, and gradients for the sampled pixels [S1, unofficial].

**Data Structures:**
*   **Error Map ($E$):** A 2D array storing the per-pixel reconstruction error from previous iterations [S1, unofficial].
*   **Age Map ($A$):** A 2D array storing the number of consecutive iterations a pixel has not been sampled [S1, unofficial].
*   **Sampling Schedule:** Parameters $K_{max}$ (max pixels to sample) and $K_{min}$ (min pixels to sample) control the sparsity level based on training progress $\rho_t$ [S1, unofficial].

**Algorithm Steps:**
1.  **Query Sampling Rate:** Determine the number of pixels to sample $K_t$ for the current tile based on the schedule using $K_{max}, K_{min}, E_{init}, \Theta, t$ [S1, unofficial].
2.  **View Selection:** Select views $V_t$ for the tile [S1, unofficial]. While Err-SPS focuses on pixel sampling, TurboGS employs Geometry-Aware View Sampling (GVS) to anchor by error and sample by pose/distance [S1, unofficial].
3.  **Tile-Wise Pixel Sampling:** Select $K_t$ pixels $P_{t,v}$ for each view $v \in V_t$ within the tile [S1, unofficial]. Pixels are prioritized based on Error ($E$) and Age ($A$), ordered by tile indices [S1, unofficial].
4.  **Gather Ground Truth and Error:** Retrieve ground truth colors $c^*$ and compute current errors $e^*$ for the sampled pixels $P_{t,v}$ [S1, unofficial].
5.  **Sparse Forward Rendering:** Perform rasterization restricted to the sampled pixel set $\{(v, p) | v \in V_t, p \in P_{t,v}\}$, preserving tile-parallel forward execution [S1, unofficial].
6.  **Sparse Loss and Gradients:** Compute loss $L$ only over sampled pixels [S1, unofficial]. The loss formulation is:
    $$ L = E_{v \in V_t, p \in P_{t,v}} \ell_1(p) + E_{v \in V_t, \tau} \lambda_\tau^{ncc} L_\tau^{S-NCC} $$
    where $E$ denotes the expectation (or sum) over the specified sets, $\ell_1$ is the L1 loss, $\lambda_\tau^{ncc}$ is a weighting coefficient, and $L_\tau^{S-NCC}$ is the sparse normalized cross-correlation term computed over sampled pixels within a tile [S1, unofficial].
7.  **EMA Error-Map Update:** Update the Error Map using Exponential Moving Average (EMA) for the sampled pixels [S1, unofficial].
8.  **Age Map Update:** Update the Age Map using online EMA updates alongside the error map [S1, unofficial].
9.  **Gaussian Backward:** Compute gradients for Gaussian properties using a per-Gaussian backward mechanism (splat-parallel computation) restricted to the sampled pixels [S1, unofficial].

**Pseudocode:**
```python
def error_guided_sparse_pixel_sampling(G, V_t, I, E, A, rho_t, K_max, K_min, beta):
    # 1. Query sampling rate
    # [G] Linear interpolation schedule between K_max and K_min based on progress
    K_t = max(K_min, int(K_max * (1.0 - rho_t)))
    
    P_t = {} # Dict mapping view index to list of sampled pixel indices
    
    # 3. Tile-Wise Pixel Sampling
    for v in V_t:
        tile_h, tile_w = E[v].shape
        scores = E[v] + A[v] # Higher score = higher priority
        flat_indices = scores.flatten()
        top_k_indices = flat_indices.argsort()[-K_t:][::-1]
        # Convert flat indices back to 2D tile coordinates
        P_t[v] = [(idx // tile_w, idx % tile_w) for idx in top_k_indices]
        
    # 4 & 5. Gather GT Color & Sparse Forward Rendering
    c_star = {}
    e_star = {}
    for v, indices in P_t.items():
        # [G] Differentiable rasterizer restricted to indices
        rendered = rasterize(G, v, indices) 
        gt = I[v][indices]
        # Per-pixel L1 error
        e_star[v] = [abs(rendered[k] - gt[k]) for k in range(len(indices))]
        c_star[v] = gt
        
    # 6. Sparse Loss & Grads
    # [G] Autograd through rasterizer computes dL/dG
    loss_l1 = sum(sum(e_star[v]) for v in V_t) / len(V_t)
    loss_ncc = compute_sparse_ncc(G, V_t, P_t, I) # [G] Structure-aware term
    L = loss_l1 + loss_ncc
    grads = L.backward()
    
    # 7. EMA Error-Map Update
    for v, indices in P_t.items():
        for p_idx, p_coord in enumerate(indices):
            E[v][p_coord] = (1 - beta) * E[v][p_coord] + beta * e_star[v][p_idx]
            
    # 8. Age Map Update
    for v, indices in P_t.items():
        for p_coord in indices:
            # Reset age for sampled pixels
            A[v][p_coord] = (1 - beta) * A[v][p_coord] + beta * 0.0
        # [G] Increment age for unsampled pixels in the tile
        tile_h, tile_w = E[v].shape
        for y in range(tile_h):
            for x in range(tile_w):
                if (y, x) not in indices:
                    A[v][y, x] += 1.0
                    
    # 9. Gaussian Backward & Update
    # [G] Standard optimizer step (e.g., Adam) applies grads to G
    G = apply_optimizer_step(G, grads)
    
    return G, E, A
```

**Parameters:**
*   $\beta$ (EMA decay): Not given in the sources.
*   $\lambda_\tau^{ncc}$: Weighting coefficient for S-NCC. Not given in the sources.
*   $K_{max}, K_{min}$: Max/min pixels to sample. Not given in the sources.

**Edge Cases and Pitfalls:**
*   Relying solely on sparse-pixel L1 supervision degrades reconstruction quality, particularly high-frequency details [S1, unofficial].
*   Sparse supervision may introduce subtle rippling artifacts in low-frequency regions with weak texture variations (e.g., walls or ceilings) [S1, unofficial].
*   Replacing Err-SPS with random pixel sampling (RPS) causes failure to preserve high-frequency details and drops in PSNR [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Significantly reduces training time [S1, unofficial]. On Mip-NeRF 360, Err-SPS reduces training time from 891s to 85s compared to vanilla 3DGS [S1, unofficial].
*   **Memory Complexity:** Reduces the number of Gaussians (NGS) from 2.73M to 0.76M on Mip-NeRF 360, indicating a lower memory footprint for the scene representation [S1, unofficial].
*   **Scaling:** The method scales with the number of tiles and views, but the sparsity factor $K_t$ controls the computational load per iteration [S1, unofficial].
*   **Strengths:** Accelerates training by avoiding redundant gradient computation on well-reconstructed pixels; preserves high-frequency details when combined with S-NCC [S1, unofficial].
*   **Limitations:** May introduce artifacts in low-texture regions; requires complementary structure-aware losses to maintain quality [S1, unofficial].
*   **When to use:** When training time is a bottleneck and the scene has sufficient texture for error-guided sampling to be effective [S1, unofficial].
*   **When not to use:** For scenes with large uniform regions where error maps may not accurately reflect reconstruction difficulty without additional regularization [S1, unofficial].

## Background
Error-Guided Sparse Pixel Sampling was introduced as part of the TurboGS framework by Hanson et al. in 2026 [S1, unofficial]. It is motivated by the observation that as training progresses, only a small subset of pixels remains difficult to reconstruct, while most become well-explained and yield marginal gradients [S1, unofficial]. The method builds on the principles of sparse pixel training and per-Gaussian backward mechanisms [S1, unofficial].
