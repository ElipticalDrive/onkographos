# Opacity Decay

Also called: Sigmoid Opacity Decay, Subtractive Opacity Decay

## Overview
Opacity Decay is a regularization step that reduces Gaussian opacity to prevent over-saturation, applied either via sigmoid scaling for the 'mrnf' strategy or direct subtraction for others [S1, unofficial]. It distinguishes itself from hard pruning by allowing gradual adjustment of opacity parameters, stabilizing training, while differing from visibility-aware variants by applying decay uniformly based on training strategy rather than per-frame visibility metrics [G].

## How it works
### Inputs and Outputs
- **Input**: The `splats['opacities']` tensor (logits), `strategy_name`, `opacity_decay`, and `lr` [S1, unofficial].
- **Output**: Updated `splats['opacities']` tensor with reduced values [S1, unofficial].

### Data Structures
- **Splats**: A collection of Gaussian primitives where each primitive $k$ has a learnable opacity logit $\tilde{o}_k$ [G].
- **Tensor Layout**: `splats['opacities']` is a 1D tensor of shape $(N)$ containing $\tilde{o}_k$ for $N$ Gaussians [G].

### Steps
The application of opacity decay depends on the selected `strategy_name` [S1, unofficial].
1. **Strategy: 'mrnf' (Sigmoid Scaling)**
   a. Compute the current alpha: $\alpha_k = \sigma(\tilde{o}_k) = \frac{1}{1 + e^{-\tilde{o}_k}}$ [S1, unofficial].
   b. Apply decay: $\alpha'_k = \alpha_k \times \text{decay\_factor}$ [S1, unofficial].
   c. Convert back to logit: $\tilde{o}'_k = \log\left(\frac{\alpha'_k}{1.0 - \alpha'_k + 10^{-8}}\right)$ [S1, unofficial].
   d. Update the logit: $\tilde{o}_k \leftarrow \tilde{o}'_k$ [S1, unofficial].
2. **Strategy: Subtractive (Direct Decay)**
   a. Compute the decay amount: $\Delta = \text{opacity\_decay} \times \text{lr}$ [S1, unofficial].
   b. Update the logit: $\tilde{o}_k \leftarrow \tilde{o}_k - \Delta$ [S1, unofficial].

### Formulas
- Sigmoid scaling: $\alpha_k = \sigma(\tilde{o}_k)$, $\alpha'_k = \alpha_k \cdot \text{decay\_factor}$, $\tilde{o}'_k = \log\left(\frac{\alpha'_k}{1.0 - \alpha'_k + 10^{-8}}\right)$ [S1, unofficial].
- Direct subtraction: $\tilde{o}_k \leftarrow \tilde{o}_k - \text{opacity\_decay} \cdot \text{lr}$ [S1, unofficial].

### Parameters
- **`opacity_decay`**: Decay factor multiplier [S1, unofficial].
- **`decay_factor`**: Multiplicative factor applied to the sigmoid opacity in the 'mrnf' strategy [S1, unofficial].
- **`lr`**: Learning rate scalar used in the subtractive strategy [S1, unofficial].

### Edge Cases and Pitfalls
- **Numerical Stability**: When converting back to logit in the 'mrnf' strategy, the $+10^{-8}$ term prevents division by zero or $\log(0)$ when $\alpha'_k$ approaches boundaries [S1, unofficial].
- **Over-decay**: If `opacity_decay` or `decay_factor` is too large, Gaussians may become effectively invisible prematurely, leading to holes in the rendered scene [G].
- **Strategy Mismatch**: Applying the wrong formula for the chosen strategy name will result in incorrect opacity values; the 'mrnf' strategy involves a non-linear transformation while subtractive is linear in logit space [G].

### Pseudocode
```python
import torch

def apply_opacity_decay(splats_opacities_logit: torch.Tensor, 
                        strategy_name: str, 
                        opacity_decay: float, 
                        decay_factor: float, 
                        lr: float) -> torch.Tensor:
    """
    Applies opacity decay to Gaussian splats.
    
    Args:
        splats_opacities_logit: Tensor of shape (N,) containing logit opacities.
        strategy_name: 'mrnf' or 'subtractive'.
        opacity_decay: Scalar decay multiplier for subtractive strategy.
        decay_factor: Multiplicative factor for mrnf strategy.
        lr: Current learning rate scalar.
        
    Returns:
        Updated tensor of logit opacities.
    """
    new_opacities = splats_opacities_logit.clone()
    
    if strategy_name == 'mrnf':
        # 1. Convert logit to alpha
        alpha = torch.sigmoid(new_opacities)
        # 2. Multiply by decay factor
        alpha_decayed = alpha * decay_factor
        # 3. Convert back to logit (evidence uses +1e-8 in denominator)
        new_opacities = torch.log(alpha_decayed / (1.0 - alpha_decayed + 1e-8))
    else:
        # Subtractive strategy
        # 1. Subtract decay amount from logit
        new_opacities = new_opacities - opacity_decay * lr
        
    return new_opacities
```

## Subtopics

### Visibility-Aware Decay
A variant that decays evidence only for substantially visible Gaussians, preserving occluded primitives [S2, unofficial]. It checks if the total weight $W_i^{(t)}$ of Gaussian $i$ exceeds a threshold $w_{min}$ [S2, unofficial]. If visible, evidence $H_{i,j}$ is multiplied by decay rate $\gamma$ ($H_{i,j} \leftarrow \gamma \cdot H_{i,j}$); otherwise, it remains unchanged [S2, unofficial]. This prevents erosion of occluded primitives [S2, unofficial]. Parameter $\gamma$ is typically 0.95 [S2, unofficial]. A pitfall is that if $0 < W_i^{(t)} \le w_{min}$, no decay occurs, and evidence can grow without bound if votes are small and consistent [S2, unofficial].

### Gaussian Opacity Scaling
Scales the opacity of selected Gaussians by a weight factor and converts back to logit space [S3, unofficial]. It clips the logit to $[-60, 60]$, converts to alpha, multiplies by the selection weight, clips alpha to $[10^{-6}, 1-10^{-6}]$, and computes the new logit as $o_{new} = \log(\alpha_{new}) - \log(1 - \alpha_{new})$ [S3, unofficial]. Parameters include `opacity_weight_floor` and `opacity_weight_min` [S3, unofficial].

### Gaussian Opacity Regularization
A regularization term that penalizes low-opacity Gaussians using an entropy loss $L_{ent} = \lambda_6 \sum_k (-o_k \ln(o_k))$ to drive opacities toward binary values (0 or 1) [S4]. Opacity is parameterized as $o_k = \sigma(\tilde{o}_k)$ [S4]. Gaussians with opacity below a threshold $\tau = 0.05$ are periodically pruned [S4]. This ensures centroids align with object surfaces for accurate SDF learning [S4]. Parameter $\lambda_6$ is typically 0.01 [S4].

### Dynamic-scene decay
A pure composition of tensor multiply and topology prune operators to fade old observations so moving objects stop persisting, implemented as a per-tick operation with no integrator-side code [S5, unofficial]. Parameter `decay` is a value in $(0, 1)$ with a typical value of 0.5 [S5, unofficial]. Parameter `thresh` is the prune threshold with a typical value of 0.05 [S5, unofficial]. On KITTI seq 00 at 10 cm voxels, applying decay every 25 frames reduced persistent active voxel count from 48.6 M to 10.6 M (78% reduction) and bounded it at ~10 M, whereas the no-decay baseline grew monotonically to 49 M at 500 frames [S5, unofficial].

## Operating characteristics
- **Time Complexity**: $O(N)$ per update step, where $N$ is the number of Gaussians, as operations are element-wise tensor updates [G].
- **Memory Complexity**: $O(1)$ additional memory, as updates are performed on a clone of the existing opacity tensor [G].
- **Performance**: Reduces the number of redundant, semi-transparent Gaussians, potentially speeding up rendering by allowing earlier culling of low-opacity primitives [G]. It stabilizes training by preventing opacity saturation [G].
- **Strengths**: Prevents over-saturation; stabilizes training gradients; reduces redundancy [G].
- **Limitations**: Requires careful tuning of decay rates; aggressive decay can lead to under-reconstruction (holes) [G].
- **When to use**: During the training phase of 3D Gaussian Splatting, particularly when Gaussians tend to become overly opaque or when redundancy needs to be managed without hard pruning shocks [G].
- **When not to use**: During inference/rendering only (unless for post-processing); not suitable for methods requiring precise preservation of semi-transparent structures (use Visibility-Aware Decay instead) [G].

## Background
Opacity Decay originated as a regularization technique in the optimization of 3D Gaussian Splatting models to address Gaussian primitives becoming over-saturated or persisting as redundant artifacts [S1, unofficial]. The 'mrnf' strategy and subtractive decay are documented in unofficial implementations and adaptations of 3DGS training pipelines [S1, unofficial]. Variants like Visibility-Aware Decay were developed for open-vocabulary segmentation tasks to handle occlusion [S2, unofficial]. Gaussian Opacity Regularization was introduced in the context of learning Signed Distance Fields (SDFs) from splatting, where surface alignment is critical [S4]. Dynamic-scene decay was developed for voxel-sequential integration to manage temporal coherence in dynamic scenes [S5, unofficial].
