# Smoothed 2D Supervision

Also called: Adaptive Gaussian blur strategy, Progressive Gaussian Blurring

## Overview
Smoothed 2D Supervision is a regularization technique that enhances the robustness of joint optimization by smoothing the 2D supervision signal [S1][S2, unofficial]. It solves the problem of unstable camera alignment and noisy gradients during the early stages of training by blurring training images with a scheduled set of 2D Gaussian kernels [S2, unofficial]. Unlike standard photometric loss which penalizes high-frequency discrepancies immediately, this method restricts the spectrum of the learned 3D scene to low frequencies initially, stabilizing convergence before gradually introducing higher frequencies [S2, unofficial][S3]. It is experimentally proven crucial for successful pose refinement [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Ground truth 2D training images $I_{gt}$, current Gaussian parameters (centers $\mu$, covariances $\Sigma$, opacities $\alpha$, colors), and iteration counter $t$.
*   **Output:** A smoothed supervision image $I_{smooth}$ used to compute the photometric loss $\mathcal{L}_{photometric}$.

**Data Structures:**
*   **Gaussian Schedule:** A sequence of kernel parameters $(\sigma_t, k_t)$ defined for iteration $t$.
*   **Gaussian Kernel:** A 2D separable Gaussian kernel $K(x, y)$ with standard deviation $\sigma$ and support size $k \times k$.

**Parameters:**
*   **Initial Standard Deviation ($\sigma_0$):** 2.4 [S4].
*   **Initial Kernel Size ($k_0$):** 9x9 [S4].
*   **Decay Interval ($k_b$):** 100 iterations [S4].
*   **End Iteration ($T_{end}$):** 19,500 iterations [S4].
*   **Downsampling Scale ($s$):** Applied if image downsampling is active [S4].

**Steps:**
1.  **Initialize Kernel:** At $t=0$, set $\sigma = \sigma_0 = 2.4$ and kernel size $k = 9$.
2.  **Schedule Update:** For every $k_b = 100$ iterations, reduce the blur intensity. The sources describe this as "exponentially reduced to 0" [S2, unofficial] or "progressively reduce the standard variance" [S3]. Specifically, the kernel size and/or $\sigma$ are lowered until $t=19,500$ [S4].
3.  **Apply Downsampling Adjustment:** If image downsampling is activated, lower the kernel size by the scale of downsampling $s$ at the current stage, as the initial hyperparameter choice is based on original image resolutions [S4].
4.  **Pre-Densification Adjustment:** Lower the blurring kernel size before densifying Gaussians to introduce extra signal on the gradient of erroneous Gaussians as the noise level reduces [S4].
5.  **Convolution:** Convolve the ground truth image $I_{gt}$ with the current 2D Gaussian kernel $K_t$ to produce the smoothed image $I_{smooth}$:
    $$ I_{smooth} = I_{gt} * K_t $$
6.  **Loss Computation:** Compute the photometric loss $\mathcal{L}_{photometric}$ between the rendered image $I_{render}$ and $I_{smooth}$:
    $$ \mathcal{L}_{photometric} = \| I_{render} - I_{smooth} \|_1 $$
7.  **Gradient Propagation:** Backpropagate through the smoothed supervision to update Gaussian parameters. The smoothed gradients stabilize camera alignment and restrict the learned spectrum [S2, unofficial].

**Pseudocode:**
```python
def get_smoothed_supervision(gt_image, iteration, current_downscale_scale=1.0):
    """
    Computes the smoothed 2D supervision image based on the current iteration.
    
    Args:
        gt_image: The ground truth 2D training image (H, W, C).
        iteration: Current training iteration number.
        current_downscale_scale: Scale factor if image downsampling is active (default 1.0).
        
    Returns:
        smoothed_image: The blurred ground truth image.
    """
    # Initial parameters from [S4]
    sigma_0 = 2.4
    k_0 = 9
    decay_interval = 100
    end_iteration = 19500
    
    # Calculate current sigma and kernel size based on schedule
    # The schedule reduces blur over time. 
    # Note: Exact decay function (linear vs exponential) varies by source [S2, unofficial][S3, S4].
    # S4 specifies reducing kernel size every 100 iterations until 19500.
    # S2 mentions exponential reduction to 0 at 10k iterations.
    # We implement a linear decay of sigma to 0 as a common interpretation of "progressive reduction".
    
    if iteration < end_iteration:
        # Linear decay of sigma from sigma_0 to 0 over end_iteration
        progress = iteration / end_iteration
        sigma = sigma_0 * (1.0 - progress)
        
        # Kernel size is typically 2 * ceil(3 * sigma) + 1 for 3-sigma support
        # Adjusted by downsampling scale [S4]
        raw_kernel_size = 2 * int(3 * sigma) + 1
        # Ensure minimum kernel size of 1
        kernel_size = max(1, raw_kernel_size)
        
        # Apply downsampling scale adjustment [S4]
        # "lower the kernel size by the scale of downsampling"
        # This likely means dividing the effective kernel size or adjusting sigma
        # Implementation: scale down the sigma effectively
        effective_sigma = sigma / current_downscale_scale
    else:
        # After end_iteration, no blur (sigma=0)
        effective_sigma = 0.0
        kernel_size = 1

    # Apply Gaussian Blur
    if effective_sigma > 0:
        # Create 2D Gaussian kernel
        # Using separable convolution for efficiency [S1]
        x = np.arange(-kernel_size//2 + 1, kernel_size//2 + 1)
        y = np.arange(-kernel_size//2 + 1, kernel_size//2 + 1)
        xx, yy = np.meshgrid(x, y)
        
        # 2D Gaussian function
        kernel_2d = np.exp(-(xx**2 + yy**2) / (2 * effective_sigma**2))
        kernel_2d /= np.sum(kernel_2d)
        
        # Convolve
        smoothed_image = convolve2d(gt_image, kernel_2d, mode='same')
    else:
        smoothed_image = gt_image
        
    return smoothed_image
```

**Edge Cases and Pitfalls:**
*   **Precision:** Ensure $\sigma$ does not become negative. If $\sigma \to 0$, the kernel becomes a delta function, effectively switching to raw supervision.
*   **Boundaries:** Use 'same' padding or appropriate boundary handling during convolution to avoid edge artifacts in the supervision signal.
*   **Degenerate Input:** If the ground truth image is empty or all black, the gradient signal will be zero, providing no regularization benefit.

## Subtopics

### [Randomly Scaled Kernel Parameter](7875-randomly-scaled-kernel-parameter.md)
A regularization technique used during joint optimization to mitigate weak and noisy gradient signals. It addresses the insufficiency of using a single-size kernel for diverse real-world scene structures, where a fixed kernel may be overly aggressive in some contexts and overly gentle in others. By randomly scaling the kernel size, it allows combinations of different-sized kernels to guide the optimization, resulting in a more robust training schedule. See [Randomly Scaled Kernel Parameter](7875-randomly-scaled-kernel-parameter.md).

### [Multiscale Pre-convolved Representation](10911-multiscale-pre-convolved-representation.md)
A regularization technique for neural illumination fields that stabilizes the decomposition of object materials from environmental illumination by enforcing consistency with pre-computed, roughness-adapted background reflections. It addresses the ambiguity where diffuse object color is incorrectly absorbed into the estimated environment map, a problem inherent to high-dimensional neural illumination representations. Unlike methods that ignore the background or treat it as static, this method explicitly models the relationship between rough refractive surfaces and the convolved background, allowing for realistic specular reflections even when roughness exceeds the kernel scale. The technique builds on [Smoothed 2D Supervision](7213-smoothed-2d-supervision.md) by applying discrete Gaussian blur kernels to the background to stabilize convergence. See [Multiscale Pre-convolved Representation](10911-multiscale-pre-convolved-representation.md).

### [Soft Rasterization](13687-soft-rasterization.md)
Soft rasterization is a differentiable rendering technique that mitigates the discontinuities inherent in standard rasterization by blending facet contributions for pixels near primitive edges. It solves the problem of sparse and vanishing gradients caused by the non-uniformity of bilinear interpolation operands, which typically have similar values except at object boundaries. Unlike standard hard rasterization, it yields slightly distorted images but allows backpropagating more useful gradients, thereby stabilizing optimization and preventing gradient vanishing at edges. See [Soft Rasterization](13687-soft-rasterization.md).

### Platonic GAN (pGAN)
A learning-based method for 2D supervision per class of reconstructed objects, used here to pre-train a network for per-frame supervision of rising smoke [S5]. It addresses the lack of details and temporal incoherence in single-view reconstructions by providing learned structural priors [S5]. However, due to the lack of constraints over time, solutions may be incoherent and not align with the input sequence, leading to high FID scores if used in isolation [S5]. See [Platonic GAN](7875-randomly-scaled-kernel-parameter.md) (Note: No dedicated article exists for pGAN in the provided tree, so it is listed here as a minor variant without a link).

## Operating characteristics
*   **Time Complexity:** Adds $O(k^2)$ per pixel convolution cost, where $k$ is the kernel size. Since $k$ is small (max 9x9) and decreases over time, the overhead is minimal [S4].
*   **Memory Complexity:** Requires storing the ground truth images and the current kernel parameters. No additional large data structures are needed [S1].
*   **Measured Performance:** Achieves 19.72 PSNR on DTU 3-view, improving over the Baseline (19.54) [S3]. It reduces training iterations to 50k compared to 200k for previous MLP-based methods, reducing overall training time to 25% [S1].
*   **Strengths:** Stabilizes camera alignment [S2, unofficial], restricts the learned spectrum to prevent high-frequency noise [S2, unofficial], and is crucial for pose refinement [S1].
*   **Limitations:** The strategy is handcrafted and cannot fully align frequency relationships between positional encodings and pixel supervision compared to adaptive methods [S3].
*   **When to Use:** When joint optimization of camera poses and scene geometry is unstable, or when training requires significant reduction in iteration count [S1].
*   **When Not to Use:** When high-frequency details are critical from the start and the scene is well-initialized, as the initial blur may slow down convergence of fine details [S3].

## Background
Smoothed 2D Supervision was introduced to improve the robustness of joint optimization in radiance field reconstruction [S1][S2, unofficial]. It was inspired by spectral analysis showing that blurring 2D training images produces smoothed image gradients, which stabilize camera alignment and restrict the spectrum of the learned 3D scene [S2, unofficial]. The technique is similar to the Gaussian schedule used in 3D radiance fields [S2, unofficial]. It has been applied in various contexts including joint pose refinement [S1], adaptive rendering loss regularization [S3], and efficient Gaussian Splatting training [S4].
