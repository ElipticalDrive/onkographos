# Opacity Split for Cloning

Also called: Cloning Strategy for Gaussian Splatting, Revising Densification Opacity Initialization

## Overview
Opacity Split for Cloning is a densification strategy that clones a Gaussian into $N$ copies while minimizing the difference between the rasterization outcomes before and after cloning, ensuring the rendering result remains unchanged [S1]. It specifically addresses the opacity initialization of cloned Gaussians to maintain transmittance consistency, preventing the cloned child from having less impact than the parent alone due to increased alpha-blending bias [S2]. Unlike standard 3D Gaussian Splatting where cloned children inherit the parent's full opacity, this method adjusts opacities to preserve the cumulative transmittance of the parent-child group [S2].

## How it works
**Inputs:**
- Original Gaussian $G_{old}$ with opacity $o_{old}$, covariance $\Sigma_{old}$, and central color value $C_{old}(\mu)$.
- Number of clones $N$ (typically $N=2$ in standard implementations, but the formula generalizes).

**Outputs:**
- $N$ cloned Gaussians $G_{new}^{(i)}$ for $i=1 \dots N$.

**Data Structures:**
- Each Gaussian is defined by:
  - Mean position $\mu$ (3D vector).
  - Covariance matrix $\Sigma$ (3x3 symmetric positive definite, or equivalently scale $s$ and rotation $R$).
  - Opacity $o$ (scalar in $[0, 1]$).
  - Color $C$ (RGB vector).

**Steps:**

1. **Initialize Geometry and Color:**
   Set the covariance and central color of all cloned Gaussians equal to the original:
   $$ \Sigma_{new}^{(i)} = \Sigma_{old} $$
   $$ C_{new}^{(i)}(\mu) = C_{old}(\mu) $$
   [S1]

2. **Calculate New Opacity:**
   Determine the new opacity $o_{new}$ for each cloned Gaussian (and the parent, if it is retained) to preserve transmittance. The relationship required to preserve rasterization intensity at the center $\mu$ is derived from the alpha-blending transmittance equation:
   $$ (1 - o_{new})^N = 1 - o_{old} $$
   Solving for $o_{new}$:
   $$ o_{new} = 1 - (1 - o_{old})^{1/N} $$
   For the common case of $N=2$ clones (splitting one into two):
   $$ o_{new} = 1 - \sqrt{1 - o_{old}} $$
   [S1, S2]
   
   *Note:* In the $N=2$ case, both the parent and the clone child are assigned this new opacity $o_{new}$ [S2].

3. **Adjust Covariance (Optional/Advanced):**
   Equation (11) alone is insufficient to preserve rasterization because Gaussians are not point sources; the covariance $\Sigma$ must also be altered to match the integrated intensity profile [S1]. To achieve this without solving the complex mean squared error integral:
   $$ \text{minimize } \int_{-\infty}^{\infty} \|\mathbf{C}^{new}(\mathbf{x}) - \mathbf{C}^{old}(\mathbf{x})\|_2^2 d\mathbf{x} $$
   The method minimizes the error of integrated 1D slices passing through the Gaussian centers, inspired by sliced Wasserstein methods [S1]:
   $$ \text{minimize } \left\| \int_{-\infty}^{\infty} \mathbf{C}^{new}(x) dx - \int_{-\infty}^{\infty} \mathbf{C}^{old}(x) dx \right\|_2^2, \quad \forall \mathcal{S} $$
   where $\mathcal{S}$ represents arbitrary slices and $x = S(x)$ denotes points along the slice [S1]. This provides a simple analytical solution for updating the scales [S1].

**Pitfalls:**
- **Transmittance Bias:** In standard 3D Gaussian Splatting, if the cloned child inherits the parent's opacity $o_{old}$, the combined transmittance of the parent and child becomes $(1-o_{old})^2$, which is significantly lower than the parent's original transmittance $(1-o_{old})$. This decreases the impact of any subsequent Gaussian in the alpha blending process [S2].
- **Point Source Assumption:** Using only the opacity split formula without adjusting covariance leads to rendering artifacts because the spatial extent (covariance) of the mass is distributed differently [S1].

**Pseudocode:**

```python
def clone_gaussian_with_opacity_split(gaussian_old, num_clones=2):
    """
    Clones a Gaussian, adjusting opacity to preserve transmittance.
    
    Args:
        gaussian_old: Object with attributes .opacity, .covariance, .color, .mean
        num_clones: Integer N, number of copies to create.
        
    Returns:
        List of N new Gaussian objects.
    """
    o_old = gaussian_old.opacity
    # Calculate new opacity to satisfy (1 - o_new)^N = 1 - o_old
    o_new = 1.0 - (1.0 - o_old) ** (1.0 / num_clones)
    
    new_gaussians = []
    for i in range(num_clones):
        g_new = Gaussian()
        # Copy geometry and color
        g_new.covariance = gaussian_old.covariance
        g_new.color = gaussian_old.color
        g_new.mean = gaussian_old.mean
        # Set new opacity
        g_new.opacity = o_new
        new_gaussians.append(g_new)
        
    return new_gaussians
```

## Operating characteristics
- **Time Complexity:** The opacity calculation is $O(1)$. Cloning is $O(N)$ where $N$ is the number of clones. If covariance adjustment via slice integration is performed, it adds overhead proportional to the number of slices and their length.
- **Memory Complexity:** Increases by a factor of $N$ for the cloned Gaussians' attributes.
- **Strengths:** Prevents the "shadowing" effect where cloned Gaussians incorrectly block background rays due to accumulated opacity, leading to more accurate color and depth reconstruction during densification [S2].
- **Limitations:** Requires careful handling of covariance if strict rasterization fidelity is needed beyond just the center point [S1].

## Background
The strategy originates from the observation that standard 3D Gaussian Splatting's densification, which simply clones Gaussians and inherits opacity, introduces a bias in the alpha-blending process [S2]. Bulo et al. (2024) proposed adapting the opacity initialization for newly cloned Gaussians to counteract this bias [S2]. Additionally, the 3D Gaussian Splatting as Markov Chain Monte Carlo paper formalized the cloning strategy by deriving the opacity relationship $(1 - o^{new})^N = 1 - o^{old}$ and discussing the need for covariance adjustment to minimize rasterization error [S1].
