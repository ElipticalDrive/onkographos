# Bézier-boundary gradient approximation

Also called: Bézier-boundary gradient approximation strategy

## Overview
This method approximates the gradients of a discontinuous indicator function $g(\cdot)$ with respect to cubic Bézier curve control points, enabling backpropagation in Gaussian Splatting despite the function being piecewise constant and non-differentiable [S1]. It sets itself apart from standard differentiable rendering by explicitly handling the non-differentiable boundary conditions of discontinuity-aware alpha-blending, whereas standard Gaussian Splatting [Link to 3D Gaussian Splatting] assumes smooth differentiability throughout the rendering pipeline.

## How it works
**Inputs and Outputs:**
*   **Input:** The raw gradient of the loss with respect to the Bézier curve output, $\frac{\partial L}{\partial g_{sc}}$; the current control point coordinates $c_{curve}$; the query point $p=(x_p, y_p)$; and the current curve evaluation $g_{sc}(p)$.
*   **Output:** The approximated gradient of the indicator function with respect to the first control point's x-coordinate, $\frac{\partial g}{\partial c_{curve}[0,0]}$.

**Data Structures:**
*   $c_{curve}$: Attribute storing control point coordinates. For 2D GS, shape is $\mathbb{R}^{4M \times 2}$. For 3D GS, shape is $\mathbb{R}^{4M \times 3}$. $M$ is the number of control points per Gaussian (typically $M=3$) [S1].
*   $g_{sc}(\cdot)$: The cubic Bézier curve function defined by control points $c_{curve}[0], c_{curve}[1], c_{curve}[2], c_{curve}[3]$.

**Algorithm:**
The approximation focuses on $\frac{\partial g}{\partial c_{curve}[0,0]}$. By the chain rule:
$$
\frac{\partial g}{\partial c_{curve}[0,0]} = \frac{\partial g}{\partial g_{sc}(p)} \times \frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]}
$$
Since $g(\cdot)$ is differentiable with respect to its input $g_{sc}(p)$, the core task is approximating $\frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]}$ [S1].

1.  **Check Modification Necessity:** Determine if $g_{sc}(p)$ needs modification by checking if the gradient should be zeroed out. Set $\frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]} = 0$ if any of the following hold:
    *   $\frac{\partial L}{\partial g_{sc}} = 0$ (optimal state).
    *   $\frac{\partial L}{\partial g_{sc}} > 0$ and $g_{sc}(p) = 0$ (already at minimum).
    *   $\frac{\partial L}{\partial g_{sc}} < 0$ and $g_{sc}(p) = 1$ (already at maximum) [S1].

2.  **Solve for Target Value $\phi$:** If modification is needed, find the target value $\phi$ for $c_{curve}[0,0]$ such that the Bézier curve passes through $p=(x_p, y_p)$. Solve the system of equations derived from the cubic Bézier definition for parameter $t$ and $\phi$ in $O(1)$ time [S1]:
    $$
    x_p = (1-t)^3 \phi + 3(1-t)^2 t c_{curve}[1,0] + 3(1-t)t^2 c_{curve}[2,0] + t^3 c_{curve}[3,0]
    $$
    $$
    y_p = (1-t)^3 c_{curve}[0,1] + 3(1-t)^2 t c_{curve}[1,1] + 3(1-t)t^2 c_{curve}[2,1] + t^3 c_{curve}[3,1]
    $$
    Collect all real number solutions for $\phi$ into a set $S_\phi$ [S1].

3.  **Approximate Gradient Based on $S_\phi$:**
    *   **No Side:** If $S_\phi = \emptyset$, set $\frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]} = 0$. No real value of $c_{curve}[0,0]$ can cause the curve to pass through $p$ [S1].
    *   **Single Side:** If all solutions in $S_\phi$ lie on the same side of $c_{curve}[0,0]$, let $\phi_e$ be the solution nearest to $c_{curve}[0,0]$. Approximate via linear interpolation:
        $$
        \frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]} = \frac{g_{sc}(p) - \hat{g}_{sc}(p)}{\phi_e - c_{curve}[0,0] + \epsilon}
        $$
        where $\hat{g}_{sc}(p) = 1$ if $g_{sc}(p)=0$ else $0$, and $\epsilon = 10^{-5}$ if $\phi_e > c_{curve}[0,0]$ else $-10^{-5}$ [S1].
    *   **Both Sides:** If solutions exist on both left and right sides of $c_{curve}[0,0]$, let $\phi_1$ be the nearest solution from the left and $\phi_2$ be the nearest from the right. Approximate as the sum of two interpolation terms:
        $$
        \frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]} = \frac{g_{sc}(p) - \hat{g}_{sc}(p)}{\phi_1 - c_{curve}[0,0] + \epsilon_1} + \frac{g_{sc}(p) - \hat{g}_{sc}(p)}{\phi_2 - c_{curve}[0,0] + \epsilon_2}
        $$
        where $\epsilon_1, \epsilon_2$ follow the same sign rule as $\epsilon$ above [S1].

**Pseudocode:**
```python
import numpy as np

def bezier_boundary_gradient_approximation(
    dL_dgsc: float,
    gsc_p: float,
    c_curve: np.ndarray, # Shape (4M, 3) or (4M, 2)
    p: np.ndarray,       # Query point (x, y)
    M: int = 3           # Hyperparameter for control points per Gaussian
) -> float:
    """
    Approximates dg/dc_curve[0,0] for the Bézier-boundary gradient method.
    
    Args:
        dL_dgsc: Gradient of loss w.r.t. the Bézier curve output g_sc(p).
        gsc_p: Current value of the Bézier curve function at p.
        c_curve: Array of control point coordinates.
        p: Query point (x_p, y_p).
        M: Number of control points per Gaussian.
        
    Returns:
        Approximated gradient dg/dc_curve[0,0].
    """
    # Step 1: Check if modification is needed
    # If optimal state or already at bound with pushing gradient, return 0
    if dL_dgsc == 0:
        return 0.0
    if dL_dgsc > 0 and gsc_p == 0:
        return 0.0
    if dL_dgsc < 0 and gsc_p == 1:
        return 0.0

    # Extract relevant control points for the curve segment
    # Assuming c_curve stores points sequentially. 
    # Note: The source implies solving for the specific curve segment associated with the indicator function.
    # We assume c_curve[0:4] corresponds to the control points for the current evaluation context.
    c0 = c_curve[0]
    c1 = c_curve[1]
    c2 = c_curve[2]
    c3 = c_curve[3]
    
    xp, yp = p[0], p[1]
    c0_x, c0_y = c0[0], c0[1]
    c1_x, c1_y = c1[0], c1[1]
    c2_x, c2_y = c2[0], c2[1]
    c3_x, c3_y = c3[0], c3[1]
    
    # Step 2: Solve for t and phi
    # The y-equation does not depend on phi (c_curve[0,0]):
    # yp = (1-t)^3 * c0_y + 3(1-t)^2 t * c1_y + 3(1-t)t^2 * c2_y + t^3 * c3_y
    # This is a cubic equation in t.
    # Coefficients for t^3, t^2, t^1, t^0
    # Expand: yp = c0_y + t(3c1_y - 3c0_y) + t^2(3c2_y - 6c1_y + 3c0_y) + t^3(c3_y - 3c2_y + 3c1_y - c0_y)
    a_t = c3_y - 3*c2_y + 3*c1_y - c0_y
    b_t = 3*c2_y - 6*c1_y + 3*c0_y
    c_t = 3*c1_y - 3*c0_y
    d_t = c0_y - yp
    
    # Solve cubic equation a*t^3 + b*t^2 + c*t + d = 0
    # Using numpy roots for robustness in implementation, though O(1) analytic solution exists
    coeffs_t = [a_t, b_t, c_t, d_t]
    t_roots = np.roots(coeffs_t)
    
    # Filter for real t in [0, 1]
    valid_t = []
    for t in t_roots:
        if np.isreal(t):
            t_val = np.real(t)
            if 0.0 <= t_val <= 1.0:
                valid_t.append(t_val)
    
    # If no valid t, the curve cannot pass through p for any phi? 
    # Actually, if no t exists, the curve geometry doesn't allow passing through p's y-coordinate.
    # In this case, S_phi will be empty.
    if not valid_t:
        return 0.0 # No side situation implicitly handled if S_phi is empty
        
    # For each valid t, solve for phi from the x-equation:
    # xp = (1-t)^3 * phi + 3(1-t)^2 t * c1_x + 3(1-t)t^2 * c2_x + t^3 * c3_x
    # phi = (xp - 3(1-t)^2 t * c1_x - 3(1-t)t^2 * c2_x - t^3 * c3_x) / (1-t)^3
    
    S_phi = []
    for t_val in valid_t:
        denom = (1 - t_val)**3
        if abs(denom) < 1e-9:
            continue # Avoid division by zero, though t=1 implies denom=0, handled by limits or skipping
        phi = (xp - 3*(1-t_val)**2 * t_val * c1_x - 3*(1-t_val)*t_val**2 * c2_x - t_val**3 * c3_x) / denom
        S_phi.append(phi)
        
    if not S_phi:
        return 0.0 # No side situation
        
    # Step 3: Approximate gradient based on S_phi
    current_c0_x = c0_x
    g_hat = 1.0 if gsc_p == 0 else 0.0
    numerator = gsc_p - g_hat
    
    # Classify solutions
    left_solutions = [phi for phi in S_phi if phi < current_c0_x]
    right_solutions = [phi for phi in S_phi if phi > current_c0_x]
    
    # Handle equality cases if any (phi == current_c0_x)
    # If phi == current_c0_x, the curve already passes through p with current control point.
    # This is a degenerate case. The source doesn't explicitly define epsilon behavior for 0 distance.
    # We assume strict inequality for "left" and "right".
    
    if not left_solutions and not right_solutions:
        # All solutions are equal to current_c0_x? Or empty?
        # If S_phi had values but they were all equal to current, it's a boundary case.
        # Assuming standard "single side" or "both sides" logic requires strict inequality.
        # If no strict sides, treat as single side with dist 0? 
        # Source says "lie on the same side". If dist is 0, it's ambiguous.
        # Given epsilon logic, we might treat as single side with very small dist.
        # However, if S_phi contains current_c0_x, the gradient is undefined/infinite without epsilon.
        # We will assume S_phi does not contain current_c0_x exactly in typical training steps,
        # or fall back to 0 if indistinguishable.
        return 0.0

    if not left_solutions:
        # Single side (Right)
        phi_e = min(right_solutions)
        epsilon = 1e-5 if (phi_e - current_c0_x) > 0 else -1e-5
        grad = numerator / (phi_e - current_c0_x + epsilon)
    elif not right_solutions:
        # Single side (Left)
        phi_e = max(left_solutions)
        epsilon = 1e-5 if (phi_e - current_c0_x) > 0 else -1e-5
        grad = numerator / (phi_e - current_c0_x + epsilon)
    else:
        # Both sides
        phi_1 = max(left_solutions) # Nearest from left
        phi_2 = min(right_solutions) # Nearest from right
        
        eps_1 = 1e-5 if (phi_1 - current_c0_x) > 0 else -1e-5
        eps_2 = 1e-5 if (phi_2 - current_c0_x) > 0 else -1e-5
        
        grad = numerator / (phi_1 - current_c0_x + eps_1) + numerator / (phi_2 - current_c0_x + eps_2)
        
    return grad
```

**Parameters:**
*   $\epsilon$: Small value to prevent gradient explosion when distance between target $\phi$ and current control point is small. Value: $10^{-5}$ if target $>$ current, $-10^{-5}$ otherwise [S1].
*   $M$: Hyperparameter for the number of control points per Gaussian. Value: $3$ [S1].

**Edge Cases and Pitfalls:**
*   **No Real Solutions:** If $S_\phi$ is empty, the gradient is set to 0. This occurs when no real value of $c_{curve}[0,0]$ can cause the curve to pass through $p$ [S1].
*   **Division by Zero:** The epsilon term $\epsilon$ prevents division by zero when $\phi_e \approx c_{curve}[0,0]$ [S1].
*   **Non-differentiability:** The indicator function $g(\cdot)$ is piecewise constant. Standard backpropagation yields zero gradients. This method approximates the boundary crossing [S1].

## Subtopics

### [Learned Static–Dynamic Partition](20807-learned-static-dynamic-partition.md)
A method to jointly optimize a binary gate $g_i$ and motion parameters to classify Gaussians as static or dynamic, using a hard-concrete relaxation with straight-through estimator. It solves the problem of incorrectly treating moving Gaussians as static, which leaves frozen copies of moving objects in the scene, by learning a sparse static-dynamic partition. It sets itself apart from sibling methods by explicitly maintaining a binary classification per Gaussian that is committed and frozen after training, enabling efficient rendering of static background without temporal overhead.

## Operating characteristics
*   **Time Complexity:** The core approximation step involves solving a cubic equation for $t$ and then a linear equation for $\phi$, both solvable in $O(1)$ time [S1].
*   **Memory Complexity:** Requires storing control points $c_{curve}$ ($\mathbb{R}^{4M \times 2}$ or $\mathbb{R}^{4M \times 3}$) and intermediate solutions $S_\phi$ [S1].
*   **Strengths:** Enables learning of discontinuity-aware rendering in Gaussian Splatting, which is otherwise non-differentiable. Consistently outperforms existing methods on PSNR, SSIM, and LPIPS metrics on novel view synthesis tasks [S1].
*   **Limitations:** Relies on approximation of non-differentiable functions, which may introduce artifacts if the approximation is poor. Requires careful tuning of $\epsilon$ [S1].
*   **When to Use:** When training Gaussian Splatting models that require explicit handling of discontinuities (e.g., edges, boundaries) via modified alpha-blending functions [S1].
*   **When Not to Use:** For standard Gaussian Splatting where smooth differentiability is sufficient and discontinuities are not explicitly modeled via indicator functions [S1].

## Background
*   **Origin:** Proposed in "DisC-GS: Discontinuity-aware Gaussian Splatting" [S1].
*   **History:** Standard Gaussian Splatting relies on differentiable rendering. DisC-GS introduces a discontinuous indicator function $g(\cdot)$ for modified alpha-blending, which breaks differentiability. This method was developed to approximate the gradients of this function to enable end-to-end training [S1].
*   **Usage:** Applied in 2D and 3D Gaussian Splatting frameworks to improve novel view synthesis quality by handling discontinuities [S1].
