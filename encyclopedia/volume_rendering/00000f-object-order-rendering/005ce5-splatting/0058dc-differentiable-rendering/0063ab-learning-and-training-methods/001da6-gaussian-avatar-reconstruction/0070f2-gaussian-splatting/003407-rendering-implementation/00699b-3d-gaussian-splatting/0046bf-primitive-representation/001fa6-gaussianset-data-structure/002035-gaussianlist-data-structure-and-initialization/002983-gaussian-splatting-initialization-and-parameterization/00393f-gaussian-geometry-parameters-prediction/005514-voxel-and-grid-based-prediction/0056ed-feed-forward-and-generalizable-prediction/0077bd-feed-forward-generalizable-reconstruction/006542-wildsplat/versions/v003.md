# WildSplat

Also called: WildSplat: Feedforward Gaussian Splatting from Unposed In-the-Wild Images

## Overview
WildSplat is a feedforward 3D Gaussian Splatting framework designed for appearance-conditioned novel-view synthesis from sparse, unposed, in-the-wild images [S1]. It solves the problem of inconsistent photometric conditions (e.g., varying weather, lighting, or time of day) that typically cause existing feedforward methods to fail or entangle geometry with appearance [S1]. Unlike optimization-based methods (e.g., NeRF-W, GS-W) that require precomputed poses and dense inputs, or standard feedforward methods (e.g., pixelSplat, MVSplat) that assume photometric consistency, WildSplat explicitly decouples geometry from appearance using a dual-branch architecture [S1]. This allows it to reconstruct appearance-invariant 3D geometry and jointly predict camera poses from unposed inputs, while conditioning the rendered appearance on a designated reference image [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ context images $\{I_i\}_{i=1}^N$ and one reference image $I_{ref}$ [S1].
*   **Outputs:**
    *   3D Gaussian geometry attributes $\mathcal{G}$: positions $\mu \in \mathbb{R}^{G \times 3}$, rotations $q \in \mathbb{R}^{G \times 4}$ (quaternions), scales $s \in \mathbb{R}^{G \times 3}$, and opacities $\alpha \in \mathbb{R}^G$ [S1].
    *   Conditioned spherical harmonics coefficients $\mathcal{C}_{ref} \in \mathbb{R}^{G \times 3 \times (k+1)}$ of degree $k$, conditioned on $I_{ref}$ [S1].
    *   Camera poses $\{p_i\}$ for the context views [S1].
    *   The mapping is defined as $f: \{I_i\}, I_{ref} \mapsto (\mathcal{G}, \mathcal{C}_{ref}, \{p_i\})$ [S1].

**Data Structures:**
*   **Patch Tokens:** $T_i^{(0)} = E_{geo}(I_i) \in \mathbb{R}^{P \times D}$, where $P$ is the number of patches and $D$ is the feature dimension [S1].
*   **Camera Tokens:** Learnable tokens $C_i \in \mathbb{R}^{5 \times D}$ concatenated with patch tokens [S1].
*   **Content Features:** Aggregated multi-scale representations $\mathbf{F}_{content}$ extracted from a subset of transformer layers $K = \{l_1, \dots, l_K\}$ [S1].
*   **Reference Tokens:** Local dense appearance tokens $T_{ref} \in \mathbb{R}^{P_a \times D}$ extracted from $I_{ref}$ [S1].
*   **Global Descriptor:** $T_{[CLS]}$ used for global pre-modulation [S1].

**Algorithm Steps:**

1.  **Geometry Branch (Appearance-Invariant Structure):**
    1.  Process each context image $I_i$ independently through a DINOv2-based geometry encoder $E_{geo}$ to obtain initial patch tokens $T_i^{(0)}$ [S1].
    2.  Concatenate learnable camera tokens $C_i \in \mathbb{R}^{5 \times D}$ with $T_i^{(0)}$ [S1].
    3.  Refine the combined tokens through $L$ alternating attention blocks. Let $T_i^{(k)}$ and $C_i^{(k)}$ denote the patch and camera tokens after the $k$-th layer [S1].
    4.  Extract and aggregate multi-scale representations from a subset of transformer layers $K$ to form the content features $\mathbf{F}_{content}$ [S1].
    5.  Predict Gaussian geometry $\mathcal{G}$ ($\mu, q, s, \alpha$) and camera poses $\{p_i\}$ from the refined tokens [S1].

2.  **Appearance Branch (Target Appearance Conditioning):**
    1.  Extract features from the reference image $I_{ref}$ using an appearance encoder to obtain reference tokens $T_{ref}$ [S1].
    2.  **Global Pre-modulation:** To prevent the original photometric properties of $\mathbf{F}_{content}$ from interfering with the target appearance, apply an AdaLN-Zero layer [G: Adaptive Layer Normalization with Zero Initialization] to the global descriptor $T_{[CLS]}$ [S1]. Decode $T_{[CLS]}$ into scale $\gamma$, shift $\beta$, and adaptive gating $\eta$ [S1]. Modulate the content features:
        $$ \tilde{T}_i^{(k)} = \gamma \cdot \text{LayerNorm}(\mathbf{F}_{content}) + \beta $$
        [S1] (Note: The source specifies $\tilde{T}_i^{(k)} = \gamma \dots$ but the exact normalization operation is implied by AdaLN-Zero standard usage; the source text cuts off at $\gamma \dots$. Standard AdaLN-Zero applies $\gamma$ and $\beta$ to the normalized features. We assume standard LayerNorm is applied before modulation).
    3.  **Cross-Attention Injection:** Use the modulated features $\tilde{T}_i^{(k)}$ as queries ($Q$) and the reference tokens $T_{ref}$ as keys ($K$) and values ($V$) in a cross-attention mechanism to inject target appearance cues into the content features [S1].
    4.  Predict the conditioned spherical harmonics coefficients $\mathcal{C}_{ref}$ from the attended features [S1].

3.  **Conditioned Rasterization:**
    1.  Render novel views using tile-based differentiable rasterization $\mathcal{R}$ of 3D Gaussian Splatting [S1].
    2.  Input the decoupled geometry $\mathcal{G}$, conditioned coefficients $\mathcal{C}_{ref}$, and predicted camera poses $\{p_i\}$ [S1].
    3.  Output predicted images $\{\hat{I}_i\} = \mathcal{R}(\mathcal{G}, \mathcal{C}_{ref}, \{p_i\})$ [S1].

**Training Strategy:**
1.  **Geometry-Guided View Sampling:**
    *   Construct an overlap matrix $S$ and scale matrix $R$ using Structure-from-Motion (SfM) points [S1].
    *   Filter valid view pairs where $S \ge \tau_s$ and $R \ge \tau_r$ [S1].
    *   Select starting rows $C$ where the sum of valid columns $> \tau_n$ [S1].
    *   Initialize a queue with a uniform sample from $C$ [S1].
    *   Iteratively pop $u$, sample up to $K$ neighbors from valid unvisited views, push to queue, and add to index set $\mathcal{I}$ until $N$ views are selected [S1].
    *   *Pseudocode for Sampling:*
        ```python
        # Input: Matrices S (overlap), R (scale), num_views N, sample_count K, thresholds tau_s, tau_r, tau_n
        # Output: Selected indices I
        V = (S >= tau_s) & (R >= tau_r)  # Valid mask
        C = [i for i in range(len(S)) if sum(V[i]) > tau_n]  # Valid starting rows
        if not C:
            return [] # Edge case: no valid views
        queue = [random.choice(C)]
        I = set(queue)
        while len(I) < N and queue:
            u = queue.pop(0)
            # Sample up to K valid unvisited neighbors
            candidates = [v for v in range(len(V[u])) if V[u][v] and v not in I]
            sample = random.sample(candidates, min(K, len(candidates)))
            queue.extend(sample)
            I.update(sample)
        return list(I)
        ```
2.  **Joint Multi-Reference Supervision:**
    *   Randomly sample $M$ images $\{I_m\}$ from the batch as target references [S1].
    *   Extract conditioned appearance $\{\mathcal{C}_{ref,m}\}$ for each [S1].
    *   Render images $\{\hat{I}_m\}$ conditioned on their respective appearance [S1].
    *   Apply color jittering to input images and random cropping to references prior to feature extraction to prevent appearance leakage [S1].

**Loss Functions:**
*   Total Loss: $\mathcal{L}_{total} = \mathcal{L}_{rgb} + \lambda_1 \mathcal{L}_{pose}$ [S1].
*   Photometric Loss: $\mathcal{L}_{rgb} = \lambda_2 \mathcal{L}_{MSE} + \lambda_3 \mathcal{L}_{SSIM} + \lambda_4 \mathcal{L}_{LPIPS}$ [S1].
*   $\mathcal{L}_{pose}$ is a distillation loss to regularize camera pose estimation [S1].
*   Parameters: $\lambda_1 = 10$, $\lambda_2 = 1.0$, $\lambda_3 = 0.05$, $\lambda_4 = 0.05$ [S1].

**Edge Cases and Pitfalls:**
*   **Varying Focal Lengths:** Standard sampling relying on camera extrinsics fails on in-the-wild datasets with varying focal lengths, where minor pose shifts alter captured content [S1]. Mitigated by overlap-based sampling using SfM points [S1].
*   **Feature Entanglement:** Content features from the geometry branch retain original photometric properties, potentially interfering with target appearance conditioning [S1]. Mitigated by global pre-modulation using AdaLN-Zero to shift features into the target appearance domain [S1].

## Operating characteristics
*   **Time Complexity:** Single forward pass for inference, making it significantly faster than optimization-based methods (e.g., NeRF-W, GS-W) which require per-scene gradient descent [S1].
*   **Memory Complexity:** Depends on the number of Gaussians $G$ and the number of context images $N$. The dual-branch architecture requires storing features for both geometry and appearance branches [S1].
*   **Measured Performance:**
    *   On MegaScenes with 12 views: PSNR 19.20, SSIM 0.683, LPIPS 0.210 [S1].
    *   On Phototourism with 12 views: PSNR 21.47, SSIM 0.788, LPIPS 0.137 [S1].
*   **Strengths:** Handles sparse, unposed, in-the-wild images; decouples geometry from appearance to handle inconsistent lighting/weather; enables appearance editing via reference image conditioning [S1].
*   **Limitations:** Requires a reference image for appearance conditioning; performance depends on the quality of SfM points for view sampling; may struggle with extreme occlusions or lack of overlap [S1].
*   **When to Use:** Novel-view synthesis from sparse, unposed photo collections with varying illumination where appearance consistency is required [S1].
*   **When Not to Use:** When dense, posed inputs are available and photometric consistency is guaranteed (simpler methods may suffice); when real-time per-scene optimization is not a constraint and higher fidelity is needed via iterative optimization [S1].

## Background
WildSplat was introduced by X. Zhang et al. in the paper "WildSplat: Feedforward Gaussian Splatting from Unposed In-the-Wild Images" [S1]. It is the first feedforward 3D Gaussian Splatting framework capable of appearance-conditioned novel-view synthesis for unposed in-the-wild images [S1]. The method addresses the limitations of previous feedforward methods (e.g., pixelSplat, MVSplat) that assume photometric consistency and optimization-based methods (e.g., NeRF-W, GS-W) that require precomputed poses and dense inputs [S1]. It builds on the shared principles of feedforward generalizable reconstruction, mapping input features to 3D Gaussian parameters without per-scene gradient descent [Parent].
