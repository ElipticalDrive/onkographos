# GSurf

Also called: GSurf: Learning Signed Distance Fields from Splatting Opaque Gaussians for High-quality 3D Reconstruction

## Overview
GSurf is a single-branch framework for high-fidelity 3D surface reconstruction that jointly optimizes discrete 2D Gaussian primitives and a continuous Signed Distance Field (SDF) without an additional volume-rendering branch [S1]. It solves the trade-off between the computational intensity of neural implicit surfaces and the fragmented geometry of standard Gaussian Splatting by using Gaussian centroids for direct SDF supervision and opacity entropy regularization to create a compact, opaque surface shell [S1]. Unlike hybrid approaches that rely on heavy volumetric sampling (e.g., NeuS, VolSDF, GSDF), GSurf eliminates the volume rendering branch, avoiding redundancy and extended training times while producing sharper geometric details than point-cloud deformation methods like GS-Pull [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of multi-view images.
*   **Outputs:** A set of optimized 2D Gaussian primitives (positions, tangents, scales, opacities) and a trained SDF MLP, enabling view-dependent color rendering and surface extraction.

**Data Structures:**
1.  **2D Gaussian Primitives:** Each primitive $k$ is defined by:
    *   Central position: $p_k \in \mathbb{R}^3$
    *   Two principal tangent vectors: $t_u, t_v \in \mathbb{R}^3$
    *   Two scaling factors: $s_u, s_v \in \mathbb{R}$
    *   Opacity: $o_k \in \mathbb{R}$
    *   The local transformation matrix $H \in \mathbb{R}^{4 \times 4}$ is constructed as:
        $$ H = \begin{bmatrix} R_k S_k & 0 \\ p_k & 1 \end{bmatrix} $$
        where $R_k = [t_u, t_v, t_u \times t_v]$ is the rotation matrix and $S_k = \text{diag}(s_u, s_v, 0)$ is the scaling matrix [S1].
2.  **SDF Network:** A Multi-Layer Perceptron (MLP) that takes 3D coordinates as input and outputs the signed distance value. It also outputs geometric features (normals) used for appearance modeling [S1].
3.  **Appearance Network:** An MLP that integrates geometry cues (normals and geometric features derived from the SDF) and viewing directions to predict view-dependent colors [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize a set of 2D Gaussian primitives using 2DGS [23] parameters ($p_k, t_u, t_v, s_u, s_v, o_k$). Initialize the SDF MLP and Appearance MLP [S1].
2.  **SDF Supervision:** Feed the Gaussian centroids $p_k$ into the SDF MLP. Compute the SDF loss $L_{sdf}$ by supervising the SDF values at these centroids. This directly links the continuous SDF to the discrete Gaussian positions [S1].
3.  **Opacity Regularization:** Compute the opacity entropy loss $L_{ent}$ to regularize Gaussian opacities. This drives opacities toward binary values (0 or 1), effectively binarizing primitives into an opaque bounding shell and removing semi-transparent primitives that do not support the surface [S1].
4.  **Pruning:** Periodically prune low-opacity branches (Gaussians with opacity below a threshold) to retain a compact set of mostly opaque, surface-supporting primitives [S1].
5.  **Appearance Modeling:** For each Gaussian, extract normals and geometric features from the SDF MLP. Combine these with the viewing direction and feed them into the Appearance MLP to predict the color $c_i$ for the Gaussian [S1]. Note: Unlike vanilla 2DGS which uses spherical harmonics, GSurf uses this MLP for view-dependent color [S1].
6.  **Rendering:**
    *   Sort the 2D Gaussians based on the depth of their centers [S1].
    *   For a pixel $x$, cast a ray and accumulate color using volumetric alpha blending:
        $$ c(x) = \sum_{i=1}^{N} w_i c_i $$
        where the weight $w_i$ for the $i$-th Gaussian is:
        $$ w_i = o_i G_i(u(x)) \prod_{j=1}^{i-1} (1 - o_j G_j(u(x))) $$
        Here, $G_i(u(x))$ is the 2D Gaussian value at the projected point $u(x)$ in the local plane, computed as:
        $$ G(u) = \exp \left( -\frac{u^2 + v^2}{2} \right) $$
        where $u = (u, v)^T$ is the coordinate in the local tangent plane defined by $P(u, v) = p_k + s_u t_u u + s_v t_v v = H(u, v, 1, 1)^T$ [S1].
7.  **Loss Calculation:** Compute the total image reconstruction loss $L_{gs}$:
    $$ L_{gs} = L_{rgb} + L_{dep} + L_{dnc} $$
    where $L_{rgb}$ is the color loss, $L_{dep}$ is the depth distortion regularization, and $L_{dnc}$ is the depth-normal consistency regularization (as defined in 2DGS [23]) [S1].
8.  **Optimization:** Minimize the combined loss $L = L_{gs} + \lambda_1 L_{sdf} + \lambda_2 L_{ent}$ with respect to Gaussian parameters, SDF MLP weights, and Appearance MLP weights [S1].

**Pseudocode:**

```python
import numpy as np

def compute_gaussian_value(u, v):
    """Compute the 2D Gaussian value at local coordinates (u, v)."""
    return np.exp(-(u**2 + v**2) / 2.0)

def transform_to_local(p_k, t_u, t_v, s_u, s_v, world_point):
    """
    Transform a world point to local (u, v) coordinates of the Gaussian.
    P(u, v) = p_k + s_u * t_u * u + s_v * t_v * v
    Solving for u, v requires inverting the basis formed by s_u*t_u and s_v*t_v.
    For simplicity, assuming orthonormal t_u, t_v and orthogonal to p_k normal.
    """
    # Vector from center to point
    diff = world_point - p_k
    # Project onto tangent vectors
    u = np.dot(diff, t_u) / s_u
    v = np.dot(diff, t_v) / s_v
    return u, v

def render_pixel(ray_origin, ray_direction, gaussians, sdf_mlp, appearance_mlp):
    """
    Render a single pixel by splatting 2D Gaussians.
    Returns color c(x).
    """
    # 1. Sort Gaussians by depth along ray
    # Calculate intersection depth for each Gaussian center
    depths = []
    for g in gaussians:
        # Simple depth projection for sorting (source says "depth of their centers")
        # In practice, this involves ray-Gaussian intersection or center projection
        # Assuming pre-computed depth or simple z-depth in camera space
        depth = np.dot(g.p_k - ray_origin, ray_direction) 
        depths.append((depth, g))
    depths.sort(key=lambda x: x[0])
    
    accumulated_alpha = 0.0
    color = np.array([0.0, 0.0, 0.0])
    
    for depth, g in depths:
        # 2. Compute 2D Gaussian value at ray intersection
        # Find intersection point of ray with Gaussian plane? 
        # Source simplifies to G(u(x)) where u(x) is local coord.
        # We need the (u,v) on the Gaussian plane corresponding to the ray hit.
        # For a 2D Gaussian (disk), we project the ray onto the plane.
        
        # Plane normal is n = t_u x t_v
        n = np.cross(g.t_u, g.t_v)
        # Distance from ray origin to plane
        # Plane equation: n . (X - p_k) = 0
        # Ray: O + t*D
        # n . (O + t*D - p_k) = 0 => t = n . (p_k - O) / n . D
        denom = np.dot(n, ray_direction)
        if abs(denom) < 1e-6:
            continue # Ray parallel to plane
            
        t_hit = np.dot(n, g.p_k - ray_origin) / denom
        hit_point = ray_origin + t_hit * ray_direction
        
        # Get local coordinates (u, v) of hit_point
        u, v = transform_to_local(g.p_k, g.t_u, g.t_v, g.s_u, g.s_v, hit_point)
        
        # 3. Compute Gaussian weight
        g_val = compute_gaussian_value(u, v)
        weight = g.o * g_val
        
        # 4. Alpha blending
        alpha = weight * (1.0 - accumulated_alpha)
        if alpha < 1e-4:
            continue
            
        # 5. Get Color from Appearance MLP
        # Input: SDF features (normal, geo) + viewing direction
        # Get SDF features at Gaussian center
        sdf_val, geo_features = sdf_mlp(g.p_k)
        normal = geo_features # Assuming MLP returns normal as part of features or derived
        view_dir = ray_direction
        
        color_i = appearance_mlp(normal, view_dir, geo_features)
        
        color += alpha * color_i
        accumulated_alpha += alpha
        
        if accumulated_alpha > 0.99:
            break
            
    return color

def train_step(gaussians, sdf_mlp, appearance_mlp, images, targets):
    """
    Perform one optimization step.
    """
    # Forward pass to render images
    rendered_images = []
    for img_idx, (ray_origins, ray_dirs) in enumerate(images):
        # Render all pixels (simplified loop)
        pixel_colors = []
        for origin, direction in zip(ray_origins, ray_dirs):
            c = render_pixel(origin, direction, gaussians, sdf_mlp, appearance_mlp)
            pixel_colors.append(c)
        rendered_images.append(np.array(pixel_colors))
        
    # Compute Losses
    L_rgb = compute_color_loss(rendered_images, targets)
    
    # SDF Supervision: Feed centroids to SDF
    sdf_losses = []
    for g in gaussians:
        sdf_val = sdf_mlp(g.p_k)
        # Target SDF value for surface is 0. 
        # Source says "supervised by L_sdf". Typically |SDF(p_k)|^2 or similar.
        sdf_losses.append(sdf_val**2) 
    L_sdf = np.mean(sdf_losses)
    
    # Opacity Entropy Regularization
    # Drive opacities to 0 or 1
    entropies = []
    for g in gaussians:
        o = g.o
        # Binary entropy: -o*log(o) - (1-o)*log(1-o)
        # Avoid log(0)
        o = np.clip(o, 1e-6, 1-1e-6)
        h = -o * np.log(o) - (1-o) * np.log(1-o)
        entropies.append(h)
    L_ent = np.mean(entropies)
    
    # Appearance/Geometry Losses (L_dep, L_dnc from 2DGS)
    # These require depth and normal outputs from rendering, omitted for brevity
    L_gs = L_rgb + L_dep + L_dnc 
    
    # Total Loss
    L_total = L_gs + lambda1 * L_sdf + lambda2 * L_ent
    
    # Backpropagate and update
    update_parameters(gaussians, sdf_mlp, appearance_mlp, L_total)
    
    # Periodic Pruning
    if step % prune_interval == 0:
        prune_low_opacity_gaussians(gaussians, threshold=0.01)
```

**Parameters:**
*   $\lambda_1, \lambda_2$: Weights for $L_{sdf}$ and $L_{ent}$. Not given in the sources.
*   Pruning threshold: Not given in the sources.
*   Pruning interval: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Reflective Surfaces:** Standard depth/normal consistency may fail on reflective surfaces. GSurf uses reflective viewpoints to model view-dependent appearance, mitigating artifacts common in 2DGS and GOF [S1].
*   **Semi-transparent Objects:** GSurf is designed for opaque surfaces. Semi-transparent objects may be reconstructed as smooth envelopes rather than accurate internal structures [S1].
*   **Precision:** The 2D Gaussian formulation assumes the primitive is a disk in the tangent plane. Degenerate tangents (collinear $t_u, t_v$) must be avoided during initialization or optimization [S1].

## Subtopics

### 2D Gaussian Splatting (2DGS)
The base rendering method used by GSurf, representing objects as elliptical disks rather than 3D ellipsoids. It provides the local tangent plane parameterization and sorting mechanism. [Link](2D-Gaussian-Splatting.md)

### Signed Distance Field (SDF)
The continuous geometric representation supervised by GSurf. It provides smooth geometry and normals for appearance modeling. [Link](Signed-Distance-Field.md)

### Opacity Entropy Regularization
A technique to binarize Gaussian opacities, ensuring only surface-supporting primitives remain opaque. [Link](Opacity-Entropy-Regularization.md)

## Operating characteristics
*   **Time Complexity:** $O(N_{gs})$ per pixel, where $N_{gs}$ is the number of Gaussians. This is significantly faster than hybrid methods like VolSDF which are $O(N_{ray} N_{smp})$ due to ray marching [S1].
*   **Memory Complexity:** Proportional to the number of Gaussians and MLP parameters. GSurf produces fewer Gaussians than standard 3DGS or GS+SDF approaches, reducing memory usage [S1].
*   **Training Time:** Requires less training time than existing GS+SDF approaches (which can take 2-16 hours) due to the elimination of the volume rendering branch [S1].
*   **Strengths:** High-quality surface reconstruction, fewer primitives, faster convergence, robust handling of reflective surfaces, and sharper details compared to GS-Pull [S1].
*   **Limitations:** May produce an "outermost envelope" for highly ill-posed or semi-transparent scenes, potentially missing internal structures [S1].
*   **When to use:** Multi-view surface reconstruction where geometry continuity and training efficiency are prioritized over volumetric transparency.
*   **When not to use:** Scenes requiring accurate modeling of semi-transparent internal structures or where volumetric appearance is critical.

## Background
GSurf was proposed by Baixin Xu, Jiangbei Hu, Jiaze Li, and Ying He from Nanyang Technological University and Dalian University of Technology. It was published on arXiv in November 2024 (v4 in July 2026) [S1]. The method addresses the limitations of neural implicit surfaces (computational intensity) and 3D Gaussian Splatting (fragmented geometry) by coupling continuous SDF learning with discrete Gaussian splatting. It builds on 2DGS [23] and aims to improve upon GS-Pull [85] and VolSDF [76] by eliminating the volume rendering branch and using direct centroid supervision [S1].
