# Regression-based FisherRF

Also called: FisherRF with meta-regression, Modified FisherRF

## Overview
Regression-based FisherRF is a variant of the FisherRF uncertainty estimation method that replaces the direct aggregation of color parameter variances with a meta-regression model to predict pixel-wise uncertainty [S1, unofficial]. While original FisherRF estimates uncertainty by summing the variances of all spherical harmonic parameters to capture direction-dependent color uncertainty, this method groups Gaussian primitive parameter variances into six distinct categories and feeds them into a regression network [S1, unofficial]. It is primarily used as a baseline for comparing uncertainty estimation (UE) quality in scene separation and out-of-scene generalization experiments [S1, unofficial].

## How it works
**Inputs:**
*   A set of 3D Gaussians $\mathcal{G} = \{g_i\}_{i=1}^N$ optimized via the training loop [S1, unofficial].
*   Each Gaussian $g_i$ is defined by position $\mathbf{p}_i$, covariance $\Sigma_i$ (parameterized by scale $\mathbf{s}_i$ and rotation $\mathbf{q}_i$), opacity $\alpha_i$, and spherical harmonic coefficients $\mathbf{c}_{i, l}$ .
*   The rendered image $\hat{I}$ and the ground-truth image $I_{gt}$ are available to compute gradients, from which parameter variances are derived [S1, unofficial].

**Outputs:**
*   A set of six uncertainty feature maps, one for each parameter group.
*   A final pixel-wise uncertainty map predicted by the meta-regression model.

**Data Structures:**
*   **Parameter Variance Map:** For each Gaussian $i$, the variance of its parameters is computed. The sources do not specify the exact mathematical formulation of the variance (e.g., diagonal elements of the Fisher Information Matrix or gradient-based variance estimates), only that they correspond to the variances of the Gaussian primitive parameters [S1, unofficial].
*   **Feature Maps:** Six 2D feature maps are generated, corresponding to the screen-space projection of the variances of the six parameter groups.

**Steps:**
1.  **Compute Parameter Variances:** For each Gaussian primitive $i$, compute the variance of its parameters. The sources state that the diagonal entries of the Fisher Information Matrix correspond to these variances [S1, unofficial].
2.  **Group Variances:** Aggregate the variances per primitive into six categories based on the original Gaussian Splatting implementation [14]:
    1.  Mean ($\mathbf{p}_i$)
    2.  Scale ($\mathbf{s}_i$)
    3.  Rotation ($\mathbf{q}_i$)
    4.  Opacity factor ($\alpha_i$)
    5.  Spherical harmonics color parameters of degree zero ($\mathbf{c}_{i, 0}$)
    6.  Higher degree spherical harmonics color parameters ($\mathbf{c}_{i, l>0}$)
    
    Note: The scale and rotation groups correspond to the primitive's covariance matrix $\Sigma_i$ [S1, unofficial].
3.  **Form Feature Maps:** Aggregate these grouped variances per primitive to form six uncertainty feature maps. This involves projecting the 3D variances to 2D screen space, similar to the rendering process [S1, unofficial].
4.  **Meta-Regression:** Feed the six feature maps into a regression model. The model architecture is not detailed in the sources, but it is described as being used "in the same manner as for our uncertainty feature maps obtained by our method" (referring to the PRIMU method) [S1, unofficial].
5.  **Predict Uncertainty:** The regression model outputs the final pixel-wise uncertainty map [S1, unofficial].

## Subtopics

### FisherRF
The original method that sums all color parameter variances for direction-dependent uncertainty. It is the predecessor to this variant [S1, unofficial].

### PRIMU
The method that uses a meta-regression model for uncertainty estimation. Regression-based FisherRF is modified to align with PRIMU's pipeline for fair comparison [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Used as a baseline for uncertainty estimation quality evaluation. Specific performance metrics are not provided in the sources [S1, unofficial].
*   **Strengths:** Aligns with the PRIMU pipeline, allowing for fair comparison of feature map quality for uncertainty estimation [S1, unofficial].
*   **Limitations:** Relies on a regression model, which may introduce additional computational overhead and complexity compared to direct variance summation [S1, unofficial].

## Background
Regression-based FisherRF was introduced in the context of the PRIMU paper, which focuses on uncertainty estimation for novel views in Gaussian Splatting [S1, unofficial]. It was developed to provide a baseline for comparing uncertainty estimation methods by modifying the original FisherRF approach to use a meta-regression model, similar to the PRIMU method itself [S1, unofficial].
