# Sensitivity-Aware Vector Clustering

Also called: Niedemayr et al. compression, Niedermayr, Sensitivity-Aware Scene Compression, Sensitivity-Aware Vector Clustering for 3DGS Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by grouping spherical harmonic (SH) coefficients and Gaussian shape parameters (scale and rotation) into compact codebooks [S1, S2]. It distinguishes itself from standard vector quantization by using a gradient-based sensitivity measure to weight the distance metric during clustering, prioritizing the preservation of parameters that significantly impact image quality [S1]. This method is typically followed by quantization-aware fine-tuning and entropy encoding to achieve high compression ratios with minimal visual degradation [S1].

## How it works

### Inputs and Outputs
**Inputs:**
- A set of optimized 3D Gaussians, each defined by position, opacity, scale, rotation, and SH coefficients for color [S1].
- A set of training images with known camera parameters [S1].
- Hyperparameters: Codebook size $K$, sensitivity thresholds $\beta_c$ (for color) and $\beta_g$ (for shape), decay factor $\lambda_d$, batch sizes, and number of update steps [S1].

**Outputs:**
- Two codebooks: one for SH coefficients (color) and one for Gaussian shape parameters (rotation and scale) [S1].
- For each Gaussian, two indices pointing to the respective codebook entries [S1].
- Compressed scene data (indices and codebooks) encoded using DEFLATE [S1].

### Data Structures
1.  **Codebook Entry (Shape):** Stores 7 scalar values: 4 for the quaternion (rotation) and 3 for the scaling vector [S1].
2.  **Codebook Entry (Color):** Stores the SH coefficient vector (e.g., 48 values for degree 3) [S1].
3.  **Gaussian Record:** Stores position, opacity, and two 32-bit unsigned integer indices pointing to the color and shape codebooks [S1].

### Algorithm Steps

1.  **Sensitivity Calculation:**
    Compute the sensitivity $S(p)$ for each parameter $p$ of every Gaussian. The sensitivity is defined as the normalized sum of the gradients of the total image energy $E$ with respect to the parameter $p$ over all training images [S1, S2]:
    $$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p_i}}{\sum_{i=1}^{N} P_i} $$
    where $N$ is the number of training images, $P_i$ is the number of pixels in image $i$, and $E_i$ is the total image energy (sum of RGB components) for image $i$ [S1, S2].
    
    For a vector $x$ (e.g., a set of SH coefficients or a shape parameter vector), the sensitivity $S(x)$ is the maximum sensitivity among its components $d$:
    $$ S(x) = \max_d S(x_d) $$
    This is computed via a single backward pass over the training images for each parameter [S1].

2.  **Codebook Initialization:**
    Initialize the codebooks randomly with a uniform distribution within the minimum and maximum values observed for each parameter in the scene [S1].

3.  **Sensitivity-Aware Clustering (k-Means):**
    Perform k-Means clustering to populate the codebooks. The clustering uses a weighted distance metric $D(x, c_k)$ between a vector $x$ and a centroid $c_k$:
    $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
    where $S(x)$ is the sensitivity of vector $x$ [S1].
    
    **Handling High-Sensitivity Vectors:**
    - For SH coefficients: Identify vectors with sensitivity higher than threshold $\beta_c$. These are excluded from the standard clustering process and added directly to the codebook [S1].
    - For Shape parameters: Identify vectors with sensitivity higher than threshold $\beta_g$. These are also excluded from clustering and added directly to the codebook [S1].
    - Cluster the remaining vectors using the weighted distance metric [S1].

    **Batched Update Strategy:**
    Due to memory constraints, a batched strategy is used [S1]:
    - Pick a random subset (batch) of vectors.
    - Compute the assignment of these vectors to the nearest centroids based on $D(x, c_k)$.
    - Update centroids using a moving average with decay factor $\lambda_d$:
      $$ c_k^{new} = \lambda_d c_k^{old} + (1 - \lambda_d) \frac{\sum_{x_i \in A(k)} S(x_i) x_i}{\sum_{x_i \in A(k)} S(x_i)} $$
      where $A(k)$ is the set of vectors assigned to centroid $c_k$ in the current batch [S1].
    - Repeat for the specified number of update steps [S1].

    **Normalization:**
    After each update step, re-normalize each codebook vector representing a covariance matrix by dividing it through the trace of the covariance metric to counteract floating-point errors that may lead to non-unit scaling vectors [S1].

4.  **Decomposition:**
    Decompose each codebook entry for shape parameters (covariance matrices) into rotation (quaternion) and scale (vector) parameters using eigenvalue decomposition. This is required for quantization-aware training [S1].

5.  **Quantization-Aware Fine-Tuning:**
    Fine-tune the scene parameters (including codebook entries) on the training set to recover information lost during clustering [S1, S2].
    - **Forward Pass:** Simulate quantization using Min-Max Quantization. Consider a specific number of bits and the moving average of each parameter's min/max values [S2].
    - **Backward Pass:** Ignore the simulated quantization and calculate the gradient for the parameter without quantization [S2].
    - Optimize position, opacity, scaling, color, and codebook entries [S2].

6.  **Entropy Encoding:**
    - Order the Gaussians according to their positions along a Z-order curve (Morton order) to exploit spatial coherence [S1, S2].
    - Compress the set of Gaussians (indices) and codebooks using DEFLATE (LZ77 + Huffman coding) [S1, S2].

def compute_sensitivity(ground_truth_images, rendered_images, params):
    """
    Computes sensitivity S(p) for each parameter p.
    params: list of parameter vectors (e.g., SH coeffs, shape params).
    """
    # E is total image energy (sum of RGB)
    # Gradient of E w.r.t p is computed via backprop
    sensitivities = {}
    for p in params:
        # Compute gradient of energy w.r.t p
        grad = compute_gradient(ground_truth_images, rendered_images, p)
        # Sum gradients over all images
        sum_grad = np.sum(np.abs(grad))
        # Normalize by number of pixels (simplified, assuming equal P_i for brevity)
        # In practice, P_i varies per image
        sensitivities[p] = sum_grad
    return sensitivities

def sensitivity_aware_kmeans(vectors, sensitivities, K, lambda_d, batch_size, num_steps):
    """
    Performs sensitivity-aware k-Means clustering.
    vectors: array of shape (N, D)
    sensitivities: array of shape (N,)
    K: codebook size
    lambda_d: decay factor
    """
    # Initialize centroids randomly within min/max of vectors
    centroids = np.random.uniform(vectors.min(), vectors.max(), (K, vectors.shape[1]))
    
    for step in range(num_steps):
        # Pick random batch
        indices = np.random.choice(vectors.shape[0], batch_size, replace=False)
        batch_vectors = vectors[indices]
        batch_sens = sensitivities[indices]
        
        # Compute weighted distances
        # D(x, ck) = S(x) * ||x - ck||^2
        # Expand dimensions for broadcasting
        diff = batch_vectors[:, np.newaxis, :] - centroids[np.newaxis, :, :] # (B, K, D)
        sq_dist = np.sum(diff**2, axis=2) # (B, K)
        weighted_dist = sq_dist * batch_sens[:, np.newaxis] # (B, K)
        
        # Assign to nearest centroid
        assignments = np.argmin(weighted_dist, axis=1) # (B,)
        
        # Update centroids using moving average
        for k in range(K):
            mask = assignments == k
            if np.sum(mask) > 0:
                assigned_vectors = batch_vectors[mask]
                assigned_sens = batch_sens[mask]
                
                # Weighted average
                sum_weighted = np.sum(assigned_sens[:, np.newaxis] * assigned_vectors, axis=0)
                sum_weights = np.sum(assigned_sens)
                new_centroid = sum_weighted / sum_weights
                
                # Moving average update

### Edge Cases and Pitfalls
- **Floating Point Errors:** Clustering normalized covariance matrices can lead to non-unit scaling vectors due to floating-point errors. This is mitigated by re-normalizing each codebook vector after each update step by dividing it through the trace of the covariance metric [S1].
- **High Sensitivity Vectors:** A small percentage (<5%) of SH coefficients have very high sensitivity. These must be excluded from clustering and added directly to the codebook to prevent significant rendering errors [S1].

## Operating characteristics

### Time and Memory Complexity
- **Memory:** The method reduces storage by a factor of up to 31× on real-world scenes [S1]. The primary memory saving comes from replacing full SH and shape vectors with indices into small codebooks (size $K=4096$) [S1].
- **Time:** Clustering is performed in batches to manage memory. The batched strategy with moving average updates allows for efficient processing of large scenes [S1]. Rendering speed can be up to 4× higher than uncompressed versions on lightweight GPUs due to reduced memory bandwidth requirements [S1].

### Strengths and Limitations
- **Strengths:** Achieves high compression rates with minimal visual quality degradation [S1]. Enables real-time rendering on low-power devices and web browsers via WebGPU [S1]. The sensitivity-aware approach ensures that critical visual details are preserved [S1].
- **Limitations:** Requires a training phase for sensitivity calculation and clustering [S1]. The method is specific to 3D Gaussian Splatting representations [S1].

### When to Use
- Use when storage or bandwidth is constrained, and real-time rendering on limited hardware is required [S1].
- Use when the scene has high redundancy in color and shape parameters [S1].

### When Not to Use
- Use when the scene has very few high-sensitivity features that dominate the visual quality, as clustering might still introduce artifacts if not handled carefully (though the method addresses this with $\beta_c$) [S1].
- Use when dynamic scenes require frequent updates to the codebooks, as clustering is a static compression technique [S1].

## Background

### Origin
Sensitivity-Aware Vector Clustering was proposed by Niedemayr et al. in 2024 [S1]. The paper "Compressed 3D Gaussian Splatting for Accelerated Novel View Synthesis" introduced this method as part of a broader compression pipeline for 3D Gaussian Splatting [S1].

### History and Development
The method builds on the observation that SH coefficients and Gaussian shape parameters in 3DGS are highly redundant [S1]. It draws inspiration from volumetric NeRF compression and deep network weight quantization [S1]. The sensitivity measure is derived from the gradient of the image energy, similar to techniques used in neural network pruning and quantization [S1].

### Applications
The method is used for compressed 3D Gaussian Splatting representations, enabling efficient storage and transmission of 3D scenes for applications like network streaming and rendering on low-power devices [S1]. It has been implemented in WebGPU for browser-based rendering [S1].
