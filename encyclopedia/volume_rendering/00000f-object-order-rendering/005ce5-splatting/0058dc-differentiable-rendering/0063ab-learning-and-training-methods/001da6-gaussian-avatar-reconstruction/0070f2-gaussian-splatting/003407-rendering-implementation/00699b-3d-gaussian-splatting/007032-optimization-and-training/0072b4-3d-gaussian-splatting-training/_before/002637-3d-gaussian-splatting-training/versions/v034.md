# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the photometric difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing high-fidelity 3D scenes from 2D images by optimizing position, rotation, scale, opacity, and appearance (spherical harmonics) using gradient descent [S5, S6, unofficial]. It sets itself apart from implicit radiance field methods like NeRF by using explicit, differentiable rasterization of Gaussian ellipsoids, which enables significantly faster training and real-time rendering speeds [S2][S5, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images with known camera poses (extrinsics $R_{cw}, t_{cw}$ and intrinsics $K$) and initial 3D Gaussian parameters. The initial positions $\mathbf{p}_w$ are typically derived from Structure-from-Motion (SfM) point clouds (e.g., COLMAP) [S2][S6, unofficial].
*   **Outputs:** Optimized Gaussian parameters (means $\mathbf{p}$, covariances $\Sigma$ or scale/rotation, opacities $\alpha$, and spherical harmonic coefficients $\mathbf{h}$) stored in a format such as PLY [S4, S6, unofficial].

**Data Structures:**
Each Gaussian primitive $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion)
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$
*   Opacity $\alpha_i \in [0, 1]$
*   Appearance parameters $\mathbf{h}_i$ (Spherical Harmonic coefficients) [Parent]

**Parameters:**
*   `numIters`: Total optimization steps. Default: 30,000 [S3, S4, unofficial].
*   `sh_degree`: Spherical harmonic degree. Default: 3 [S3, S4, unofficial].
*   `shDegreeInterval`: Steps between increasing SH degree. Default: 1,000 [S3, S4, unofficial].
*   `densifyFrom`: Step after which densification begins. Default: 500 [S3, unofficial].
*   `densifyUntil`: Step after which densification stops. Default: $\min(15000, \text{numIters}/2)$ [S3, unofficial].
*   `refineEvery`: Frequency of densification/pruning operations. Default: 500 [S3, unofficial].
*   `densify_grad_thresh`: Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   `densify_size_thresh`: Size threshold for densification. Default: 0.01 [S4, unofficial].
*   `split_screen_size`: Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   `stop_screen_size_at`: Step at which screen-size splitting stops. Default: 4,000 [S4, unofficial].
*   `ssim_weight`: Weight for SSIM loss. Default: 0.2 [S3, S4, unofficial].
*   `maxGaussians`: Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].

**Numbered Steps:**

1.  **Initialization:** Initialize positions $\mathbf{p}_w$ from SfM points in normalized bounds $[-1, 1]$. Initialize scales $\mathbf{s}$ between 0 and 1. Initialize rotations $q$ as unit quaternions and opacities $\alpha$ as constants [S2][S6, unofficial].
2.  **Camera Sampling:** Select a training camera $V$ and its ground truth image $\hat{I}$ using a round-robin iterator with periodic shuffling [S2][S4, unofficial].
3.  **Rendering:** Project the 3D Gaussians to 2D screen space using the camera matrix. Sort Gaussians by depth. Compute pixel colors $\gamma_j$ via alpha blending [Parent, S6]:
    $$ \gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij}, \quad \tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj}) $$
    where $\alpha'_{ij} = g \alpha_i$ is the effective opacity, $g$ is the 2D Gaussian weight, and $c_i$ is the color [S6, unofficial].
4.  **Loss Computation:** Compute the loss $\mathcal{L}$ between rendered image $\gamma$ and ground truth $\hat{I}$:
    $$ \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM} $$
    where $\lambda$ is the SSIM weight (default 0.2) [S6, unofficial].
5.  **Backpropagation:** Compute gradients $\frac{\partial \mathcal{L}}{\partial \theta}$ for all parameters $\theta \in \{\mathbf{p}, q, \mathbf{s}, \alpha, \mathbf{h}\}$ using the chain rule [S6, unofficial].
6.  **Optimization Step:** Update parameters using the Adam optimizer [S2][S6, unofficial].
7.  **Adaptive Density Control:** If the current step is a refinement iteration (e.g., every 100 steps or based on `refineEvery`), perform densification and pruning [S2]:
    *   **Pruning:** If $\alpha_i < \epsilon$ or the Gaussian is too large, remove it [S2].
    *   **Densification Check:** If the positional gradient magnitude $\|\nabla_{\mathbf{p}} \mathcal{L}\| > \tau_p$ (default 0.0002) [S2][S4, unofficial]:
        *   **Over-reconstruction:** If the scale norm $\|\mathbf{s}\| > \tau_s$ (default 0.01), split the Gaussian into two [S2].
        *   **Under-reconstruction:** Else, clone the Gaussian [S2].
8.  **Progression:** Increment step counter. If step < `numIters`, repeat from Step 2.

**Pseudocode:**

```python
def train_3dgs(training_data, num_iters=30000, sh_degree=3, sh_interval=1000,
               densify_from=500, densify_until=15000, refine_every=100,
               grad_thresh=0.0002, size_thresh=0.01, split_screen_size=0.05,
               stop_screen_size_at=4000, ssim_weight=0.2, max_gaussians=5000000):
    
    # 1. Initialization
    # Initialize positions from SfM, scales, rotations, opacities, colors
    gaussians = initialize_gaussians(training_data.sfm_points)
    optimizer = Adam(gaussians.parameters())
    
    # Camera iterator
    cam_indices = list(range(len(training_data.cameras)))
    cam_iter = InfiniteRandomIterator(cam_indices)
    
    step = 1
    while step <= num_iters:
        # 2. Camera Sampling
        cam_idx = cam_iter.next()
        camera = training_data.cameras[cam_idx]
        gt_image = training_data.get_image(cam_idx, step)
        
        # 3. Rendering
        rendered_image = render(gaussians, camera)
        
        # 4. Loss Computation
        loss = compute_loss(rendered_image, gt_image, ssim_weight)
        
        # 5. Backpropagation
        loss.backward()
        
        # 6. Optimization Step
        optimizer.step()
        optimizer.zero_grad()
        
        # 7. Adaptive Density Control
        if step % refine_every == 0 and step >= densify_from and step <= densify_until:
            densify_and_prune(gaussians, grad_thresh, size_thresh, 
                              split_screen_size, stop_screen_size_at, max_gaussians)
        
        # 8. Progression
        if step % sh_interval == 0 and step < sh_degree * sh_interval:
            increase_sh_degree(gaussians, step)
            
        step += 1
        
    return gaussians

def densify_and_prune(gaussians, grad_thresh, size_thresh, split_screen_size, 
                      stop_screen_size_at, max_gaussians):
    for g in gaussians:
        # Pruning
        if g.opacity < 0.005 or g.screen_size > split_screen_size and step > stop_screen_size_at:
            gaussians.remove(g)
            continue
            
        # Densification
        if g.gradient_norm > grad_thresh:
            if g.scale_norm > size_thresh:
                # Over-reconstruction: Split
                gaussians.split(g)
            else:
                # Under-reconstruction: Clone
                gaussians.clone(g)
                
    # Enforce max gaussians limit if necessary
    if len(gaussians) > max_gaussians:
        gaussians.prune_low_opacity()
```

**Formulas:**
*   **Rotation Matrix from Quaternion:**
    $$ R(q) = 2 \begin{bmatrix} \frac{1}{2} - (q_j^2 + q_k^2) & q_i q_j - q_r q_k & q_i q_k + q_r q_j \\ q_i q_j + q_r q_k & \frac{1}{2} - (q_i^2 + q_k^2) & q_j q_k - q_r q_i \\ q_i q_k - q_r q_j & q_j q_k + q_r q_i & \frac{1}{2} - (q_i^2 + q_j^2) \end{bmatrix} $$ [S2]
*   **Jacobian for Position:**
    $$ \frac{\partial \mathcal{L}}{\partial p_{w,i}} = \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial u_i} \frac{\partial u_i}{\partial p_{c,i}} \frac{\partial p_{c,i}}{\partial p_{w,i}} + \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial c_i} \frac{\partial c_i}{\partial p_{w,i}} + \sum_j \frac{\partial \mathcal{L}}{\partial \gamma_j} \frac{\partial \gamma_j}{\partial \alpha'_{ij}} \frac{\partial \alpha'_{ij}}{\partial \sigma'_i} \frac{\partial \sigma'_i}{\partial p_{c,i}} \frac{\partial p_{c,i}}{\partial p_{w,i}} $$ [S6, unofficial]

## Subtopics

### [Physical Parameter Optimization](4111-physical-parameter-optimization.md)
Replaces standard SH color and opacity with physical quantities (extinction, albedo, scattering) to enable dynamic relighting by solving the radiative transfer equation.

### [WildGaussians](6064-wildgaussians.md)
Models image-dependent appearance variations via a lightweight MLP and separates static scene geometry from transient occluders using learnable opacity variation, solving photometric inconsistency in unconstrained photo collections.

### [Non-Pinhole Camera Training](6088-non-pinhole-camera-training.md)
Extends 3DGS to handle non-standard camera models (fisheye, uncentered) by integrating differentiable image-space warping and masking into the training loop.

### [AbsGS](6127-absgs.md)
Recovers fine details and thin structures by replacing signed gradient averaging with absolute sums across multiple views to identify "fence-sitting" Gaussians and sharpen edges.

### [Densification Strategy](6234-densification-strategy.md)
Dynamically adjusts the number and distribution of Gaussians during training by spawning, splitting, or removing primitives based on optimization metrics like gradient magnitude and opacity, balancing fidelity and cost.

### [Regularization and Geometry Constraints](6269-regularization-and-geometry-constraints.md)
Targets 3D position and opacity parameters to recover accurate scene geometry in sparse-view scenarios by enforcing structural constraints like flattening and normal alignment [Parent, 14222-geometry-regularization.md].

### [Base 3DGS Optimization](7549-base-3dgs-optimization.md)
Initializes geometric attributes with an explicit normal attribute optimized via normal consistency loss, accelerating convergence for editable Gaussian optimization.

### [GSP Training Loss](9156-gsp-training-loss.md)
Extends the standard color reconstruction loss with normal consistency and anisotropy regularization to prevent artifacts from excessive kernel elongation in dynamic or physically-based contexts.

### [GPS-Gaussian](9197-gps-gaussian.md)
Estimates novel views from sparse source views without per-scene fine-tuning by predicting Gaussian parameters directly from input images using a neural network, focusing on human subjects.

### [Optimization and Training Efficiency](9264-optimization-and-training-efficiency.md)
Accelerates training and scales to large scenes by replacing per-pixel gradient accumulation with per-splat accumulation, partitioning primitives across GPUs, and computing gradients for probabilistic masks [6233-optimization-and-parallelization, 5989-parallelization-for-backpropagation, 7349-grendel-gs, 4254-maskgaussian-gradient-computation].

### [Dynamic and Temporal Modeling](9265-dynamic-and-temporal-modeling.md)
Extends static 3DGS to handle non-rigid motion by parameterizing Gaussian attributes as functions of time or mapping dynamic coordinates to a canonical space via deformation networks.

### [Compression and Representation Efficiency](9266-compression-and-representation-efficiency.md)

### [SLAM and Mapping](9268-slam-and-mapping.md)
Integrates simultaneous localization and mapping by optimizing dense Gaussian representations alongside camera poses in real-time, leveraging differentiable rendering for feedback.

### [Application-Specific Reconstructions](9269-application-specific-reconstructions.md)
Modifies the training loop for domain-specific challenges like dynamic human avatars or robotics simulation using custom initialization, deformation priors, and generative repair [Parent].

### [Geometry and Surface Priors](9270-geometry-and-surface-priors.md)
Addresses the lack of explicit geometric boundaries in standard 3DGS by enforcing positional and normal consistency with continuous priors (SDFs, depth maps) to extract watertight meshes.

### [Neural Network and Feed-Forward Approaches](9526-neural-network-and-feed-forward-approaches.md)
Replaces iterative gradient descent with neural networks that regress Gaussian parameters directly from input images or use neural priors to guide optimization [Parent].

### [ClipGS](9546-clipgs.md)
Enables real-time interactive cinematic visualization of volumetric medical data with dynamic clipping planes by treating the clipping plane as a geometric visibility constraint managed via a learnable truncation scheme.

### [Representation and Kernel Modifications](10145-representation-and-kernel-modifications.md)
Modifies the standard 3DGS representation or kernel to improve geometric fidelity, storage efficiency, or modeling flexibility, such as using negative primitives or alternative radial basis functions [Parent].

### [TideGS Trajectory Ordering](10176-tidegs-trajectory-ordering.md)
Improves optimization stability for large-scale scenes by replacing randomized view shuffling with a trajectory-aware ordered sequence of views based on clustered traveling-salesperson ordering.

### [Gradient Computation and Back-Propagation](10202-gradient-computation-and-back-propagation.md)
Defines the mathematical mechanisms for propagating loss gradients from rendered pixels back to Gaussian parameters and camera poses, enabling end-to-end training [Parent].

### [VisibilitySplat](10927-visibilitysplat.md)
Augments the rasterization pipeline with a sparse visibility oracle (BVH-accelerated ray tracer) to estimate transmittance-weighted occlusion for material and light decomposition.

### [MCMC-based 3D Gaussian Splatting](11914-mcmc-based-3d-gaussian-splatting.md)
Reforms training as a Markov Chain Monte Carlo process, replacing heuristic densification with stochastic exploration via noise injection and relocation to avoid local minima [Parent].

### [3D Gaussian Splatting as Markov Chain Monte Carlo (MCMC)](11915-3d-gaussian-splatting-as-markov-chain-monte-carlo-mcmc.md)
Reinterprets training as sampling from a target distribution, treating discrete structural changes as valid state transitions to preserve probability mass and avoid gradient discontinuities.

### [Sliced Wasserstein-based Gaussian Cloning Update](11919-sliced-wasserstein-based-gaussian-cloning-update.md)
Determines scale updates for cloned Gaussians by minimizing the difference between integrated colors along arbitrary 1D slices, ensuring rasterization integral conservation.

### [Cross-Structure Collaboration Module](12071-cross-structure-collaboration-module.md)
Integrates global tri-plane features with local context-aware grid features to generate Hierarchical Dense Embedded features, solving feature misalignment in large-scale scenes.

#### HUGS
Creates a coarse-to-fine deformation module using linear blend skinning and local learning-based refinement for animating virtual human avatars based on 3DGS. It utilizes tri-plane representation to factorize the canonical space and reconstructs from monocular video (50-100 frames) within 30 minutes, achieving 20 FPS [S1].

#### Wolf et al. Stereo Method
Trains a 3DGS to render stereo-calibrated novel views, applies stereo depth estimation on the rendered views, and fuses the estimated dense depth maps using Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

#### Pseudo Ground Truth Acquisition for Gaussians
A labeling pipeline that generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for the densification and pruning processes of 3D-GS optimization [S8, unofficial].

#### Cross-View Pruning Mechanism
Reduces Gaussian redundancy and ensures geometric validity using a Cross-View Consistency Loss and adaptive pruning. It selects adjacent view pairs with SSIM > 0.6, computes the loss to penalize residual discrepancies, and prunes based on depth consistency conditions [S9].

#### Structure-View Co-learning
Combines structural and view-dependent gradients for robust joint optimization of Gaussian positions and appearance. The loss is $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$, where $\mathcal{L}_V$ is view gradient loss and $\mathcal{L}_S$ is structure gradient loss [S9].

#### Single-view Mini-batch Strategy
Organizes training data per viewpoint and samples mini-batches containing data from only a single viewpoint to improve training efficiency [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training typically takes 15-60 minutes for standard scenes (e.g., Mip-NeRF 360) on modern GPUs, significantly faster than NeRF which can take hours [S2][S5, unofficial].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians. Default limit is 5,000,000 Gaussians [S3, unofficial]. Large scenes may require out-of-core or distributed training strategies [9264-optimization-and-training-efficiency.md].
*   **Performance:** Achieves comparable image quality to NeRF but with much faster training and real-time rendering speeds (100x faster than CPU) [S2][S3, unofficial].
*   **Strengths:** Fast training, real-time rendering, high fidelity.
*   **Limitations:** Sensitive to initialization (SfM quality), can produce floaters in dynamic scenes, requires careful tuning of densification thresholds [S2][S5, unofficial].
*   **When to use:** Static or slowly changing scenes with good initial SfM reconstruction.
*   **When not to use:** Highly dynamic scenes without temporal modeling, or scenes with poor initial point clouds.

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [9]. It builds on the concept of radiance fields but uses explicit 3D Gaussian primitives instead of implicit neural networks. The method initializes positions using sparse point clouds from SfM tools like COLMAP [S2][S6, unofficial]. It has since been extended to various domains including SLAM, dynamic scenes, and human avatars [S1].
