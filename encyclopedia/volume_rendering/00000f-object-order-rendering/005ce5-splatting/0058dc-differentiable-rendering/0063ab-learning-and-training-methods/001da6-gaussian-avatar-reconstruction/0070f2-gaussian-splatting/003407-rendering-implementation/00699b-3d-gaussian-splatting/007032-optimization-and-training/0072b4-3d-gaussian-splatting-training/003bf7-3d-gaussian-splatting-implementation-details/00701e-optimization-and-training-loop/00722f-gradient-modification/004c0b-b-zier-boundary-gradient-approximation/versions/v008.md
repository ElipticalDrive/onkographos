# Bézier-boundary gradient approximation

Also called: BBGA

## Overview
Bézier-boundary gradient approximation is a technique for approximating the gradients of a discontinuous indicator function $g(\cdot)$ with respect to the control point coordinates of a cubic Bézier curve, enabling backpropagation in Gaussian Splatting [S1]. It solves the problem that $g(\cdot)$ is piecewise constant and non-differentiable, which causes standard automatic differentiation to yield zero gradients that fail to guide the learning of curve parameters [S1]. Unlike standard Gaussian Splatting, which relies on differentiable rendering, this method allows the network to learn discontinuity-aware representations by approximating the derivative $\frac{\partial g}{\partial c_{\text{curve}}}$ through geometric boundary analysis [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The current control point coordinates $c_{\text{curve}} \in \mathbb{R}^{4M \times D}$ (where $D=2$ for 2D or $3$ for 3D), the point $p$ being evaluated, the current output of the Bézier curve function $g_{sc}(p)$, and the gradient of the loss with respect to the curve output $\frac{\partial \mathcal{L}}{\partial g_{sc}}$.
*   **Output:** The approximated gradient $\frac{\partial g}{\partial c_{\text{curve}}[0,0]}$ (and similarly for other coordinates).

**Data Structures:**
*   $c_{\text{curve}}$: Attribute storing control point coordinates. For 2D GS, shape is $\mathbb{R}^{4M \times 2}$. For 3D GS, shape is $\mathbb{R}^{4M \times 3}$ [S1].
*   $M$: Hyperparameter for the number of control points per Gaussian. Value: 3 [S1].

**Algorithm:**
The approximation focuses on the partial derivative of the indicator function $g(\cdot)$ with respect to the x-coordinate of the first control point, denoted as $\frac{\partial g}{\partial c_{\text{curve}}[0,0]}$. By the chain rule:
$$ \frac{\partial g}{\partial c_{\text{curve}}[0,0]} = \frac{\partial g}{\partial g_{sc}} \cdot \frac{\partial g_{sc}}{\partial c_{\text{curve}}[0,0]} $$
where $g_{sc}(p)$ is the cubic Bézier curve function evaluated at $p$ [S1]. The core task is approximating $\frac{\partial g_{sc}}{\partial c_{\text{curve}}[0,0]}$.

1.  **Check Modification Necessity:** Determine if $g_{sc}(p)$ needs modification. If any of the following conditions hold, set $\frac{\partial g_{sc}}{\partial c_{\text{curve}}[0,0]} = 0$ and terminate:
    *   $\frac{\partial \mathcal{L}}{\partial g_{sc}} = 0$ (optimal state).
    *   $\frac{\partial \mathcal{L}}{\partial g_{sc}} > 0$ and $g_{sc}(p) = 0$ (already at minimum).
    *   $\frac{\partial \mathcal{L}}{\partial g_{sc}} < 0$ and $g_{sc}(p) = 1$ (already at maximum) [S1].

2.  **Solve for Target Value:** If modification is needed, identify the target value $\phi$ for $c_{\text{curve}}[0,0]$ such that the Bézier curve passes through $p=(x_p, y_p)$. Solve the system of equations derived from the cubic Bézier definition for $t$ and $\phi$ in $O(1)$ time [S1]:
    $$ x_p = (1-t)^3 \phi + 3(1-t)^2 t c[1,0] + 3(1-t)t^2 c[2,0] + t^3 c[3,0] $$
    $$ y_p = (1-t)^3 c[0,1] + 3(1-t)^2 t c[1,1] + 3(1-t)t^2 c[2,1] + t^3 c[3,1] $$
    Collect all real number solutions for $\phi$ into a set $S_\phi$ [S1].

3.  **Approximate Gradient:** Based on the solutions in $S_\phi$, apply one of three cases:

    *   **No Side:** If $S_\phi = \emptyset$, set $\frac{\partial g_{sc}}{\partial c_{\text{curve}}[0,0]} = 0$. This implies no real value of $c_{\text{curve}}[0,0]$ can cause the curve to pass through $p$ [S1].

    *   **Single Side:** If all solutions in $S_\phi$ lie on the same side of $c_{\text{curve}}[0,0]$, let $\phi_e$ be the solution nearest to $c_{\text{curve}}[0,0]$. Approximate the gradient via linear interpolation:
        $$ \frac{\partial g_{sc}}{\partial c_{\text{curve}}[0,0]} = \frac{g_{sc}(p) - \hat{g}_{sc}(p)}{\phi_e - c_{\text{curve}}[0,0] + \epsilon} $$
        where $\hat{g}_{sc}(p) = 1$ if $g_{sc}(p)=0$ else $0$, and $\epsilon = 10^{-5}$ if $\phi_e > c_{\text{curve}}[0,0]$ else $-10^{-5}$ [S1].

    *   **Both Sides:** If solutions exist on both left and right sides of $c_{\text{curve}}[0,0]$, let $\phi_1$ be the nearest solution from the left and $\phi_2$ be the nearest from the right. Approximate the gradient as the sum of two interpolation terms:
        $$ \frac{\partial g_{sc}}{\partial c_{\text{curve}}[0,0]} = \frac{g_{sc}(p) - \hat{g}_{sc}(p)}{\phi_1 - c_{\text{curve}}[0,0] + \epsilon_1} + \frac{g_{sc}(p) - \hat{g}_{sc}(p)}{\phi_2 - c_{\text{curve}}[0,0] + \epsilon_2} $$
        where $\epsilon_1$ and $\epsilon_2$ follow the same sign rule as $\epsilon$ above [S1].

**Pseudocode:**
```python
import numpy as np

def bezier_boundary_gradient_approx(c_curve, p, g_sc_val, dL_dg_sc, M=3):
    """
    Approximates the gradient of the discontinuous indicator function 
    with respect to the first control point's x-coordinate.
    
    Args:
        c_curve: Array of control points, shape (4*M, D).
        p: Point (x, y) to evaluate.
        g_sc_val: Current output of the Bézier curve at p.
        dL_dg_sc: Gradient of loss w.r.t. g_sc.
        M: Number of control points per Gaussian.
        
    Returns:
        approx_grad: Approximated gradient d(g_sc)/d(c_curve[0,0]).
    """
    # Step 1: Check modification necessity
    if dL_dg_sc == 0:
        return 0.0
    if dL_dg_sc > 0 and g_sc_val == 0:
        return 0.0
    if dL_dg_sc < 0 and g_sc_val == 1:
        return 0.0

    # Step 2: Solve for target value phi
    # The system involves solving for t and phi.
    # y_p equation does not depend on phi (x-coord of control points), 
    # so we solve for t first using the y-coordinates.
    # y_p = (1-t)^3 * c[0,1] + 3(1-t)^2 * t * c[1,1] + 3(1-t) * t^2 * c[2,1] + t^3 * c[3,1]
    
    c_y = c_curve[:, 1] # y-coordinates of control points
    y_p = p[1]
    
    # Coefficients for cubic equation in t: A*t^3 + B*t^2 + C*t + D = 0
    # Expanding Bernstein basis:
    # (1-t)^3 = 1 - 3t + 3t^2 - t^3
    # 3(1-t)^2 t = 3t - 6t^2 + 3t^3
    # 3(1-t)t^2 = 3t^2 - 3t^3
    # t^3 = t^3
    
    # Coeff for t^3: -c0 + 3c1 - 3c2 + c3
    # Coeff for t^2: 3c0 - 6c1 + 3c2
    # Coeff for t: -3c0 + 3c1
    # Constant: c0
    
    c0, c1, c2, c3 = c_y[0], c_y[1], c_y[2], c_y[3]
    
    A = -c0 + 3*c1 - 3*c2 + c3
    B = 3*c0 - 6*c1 + 3*c2
    C = -3*c0 + 3*c1
    D = c0 - y_p
    
    # Solve cubic equation A*t^3 + B*t^2 + C*t + D = 0
    # Using numpy roots for robustness, though O(1) analytical solution exists
    coeffs = [A, B, C, D]
    t_roots = np.roots(coeffs)
    
    # Filter for real t in [0, 1]
    valid_t = t_roots[np.isreal(t_roots) & (np.real(t_roots) >= 0) & (np.real(t_roots) <= 1)]
    
    S_phi = []
    
    # For each valid t, solve for phi in the x-equation
    # x_p = (1-t)^3 * phi + 3(1-t)^2 * t * c[1,0] + 3(1-t) * t^2 * c[2,0] + t^3 * c[3,0]
    # phi = (x_p - rest) / (1-t)^3
    
    c_x = c_curve[:, 0] # x-coordinates of control points
    
    for t in valid_t:
        t_val = np.real(t)
        denom = (1 - t_val)**3
        
        if abs(denom) < 1e-9:
            continue
            
        rest = 3*(1-t_val)**2 * t_val * c_x[1] + 3*(1-t_val)*t_val**2 * c_x[2] + t_val**3 * c_x[3]
        x_p = p[0]
        phi = (x_p - rest) / denom
        S_phi.append(phi)
        
    if not S_phi:
        return 0.0
        
    # Step 3: Approximate gradient based on S_phi
    current_c0 = c_curve[0, 0]
    g_hat = 1.0 if g_sc_val == 0 else 0.0
    numerator = g_sc_val - g_hat
    
    # Sort solutions
    S_phi_sorted = sorted(S_phi)
    
    # Check sides
    left_sols = [phi for phi in S_phi_sorted if phi < current_c0]
    right_sols = [phi for phi in S_phi_sorted if phi > current_c0]
    
    # Handle equality case (phi == current_c0) - technically not a side, 
    # but if it exists, the distance is 0. The source implies strict inequality for sides.
    # If solutions are exactly on the point, gradient is undefined/infinite, 
    # but source focuses on left/right separation.
    
    if not left_sols and not right_sols:
        # All solutions are exactly at current_c0? Or empty?
        # If S_phi is not empty but no left/right, they are equal.
        # Source doesn't explicitly cover phi == current_c0, 
        # but "single side" implies strict inequality. 
        # If all are equal, distance is 0. We treat as single side with dist 0?
        # Or no side? If phi == current_c0, the curve already passes through p.
        # This implies g_sc(p) should be the target. 
        # If g_sc(p) != target, then it's impossible? 
        # Given the logic, if phi == current_c0, the curve passes through p.
        # If it doesn't, then no solution. So if we are here, it passes through.
        # If it passes through, g_sc(p) is likely correct or boundary.
        # Let's assume this case falls into single side with very small epsilon or handled by no side logic if not reachable.
        # For implementation safety, if no strict sides, return 0.
        return 0.0

    if not left_sols:
        # Single side (right)
        phi_e = min(right_sols)
        epsilon = 1e-5 if (phi_e - current_c0) > 0 else -1e-5
        return numerator / (phi_e - current_c0 + epsilon)
        
    elif not right_sols:
        # Single side (left)
        phi_e = max(left_sols)
        epsilon = 1e-5 if (phi_e - current_c0) > 0 else -1e-5
        return numerator / (phi_e - current_c0 + epsilon)
        
    else:
        # Both sides
        phi_1 = max(left_sols) # Nearest from left
        phi_2 = min(right_sols) # Nearest from right
        
        epsilon_1 = 1e-5 if (phi_1 - current_c0) > 0 else -1e-5
        epsilon_2 = 1e-5 if (phi_2 - current_c0) > 0 else -1e-5
        
        term1 = numerator / (phi_1 - current_c0 + epsilon_1)
        term2 = numerator / (phi_2 - current_c0 + epsilon_2)
        
        return term1 + term2
```

**Parameters:**
*   $\epsilon$: Small value to prevent gradient explosion. Value: $10^{-5}$ if target $>$ current, $-10^{-5}$ otherwise [S1].
*   $M$: Hyperparameter for the number of control points per Gaussian. Value: 3 [S1].
*   Initial learning rate for $c_{\text{curve}}$: $2 \times 10^{-4}$ [S1].

**Edge Cases and Pitfalls:**
*   **No Real Solutions:** If $S_\phi$ is empty, the gradient is set to 0, as no real value of the control point can cause the curve to pass through $p$ [S1].
*   **Gradient Explosion:** The $\epsilon$ term prevents division by zero when the target $\phi$ is very close to the current control point coordinate [S1].
*   **Densification:** When a Gaussian is cloned or split, both new Gaussians are assigned the same $c_{\text{curve}}$ attribute as the original [S1].

## Subtopics

### [Learned Static–Dynamic Partition](20807-learned-static-dynamic-partition.md)
A method to jointly optimize a binary gate $g_i$ and motion parameters to classify Gaussians as static or dynamic, using a hard-concrete relaxation with straight-through estimator. It solves the problem of incorrectly treating moving Gaussians as static, which leaves frozen copies of moving objects in the scene, by learning a sparse static-dynamic partition. It sets itself apart from sibling methods by explicitly maintaining a binary classification per Gaussian that is committed and frozen after training, enabling efficient rendering of static background without temporal overhead.

## Operating characteristics
*   **Time Complexity:** The core approximation step involves solving a cubic equation for $t$ and then solving for $\phi$, which is stated to be $O(1)$ time complexity [S1].
*   **Memory Complexity:** Requires storing the control point coordinates $c_{\text{curve}}$ for each Gaussian, with shape $\mathbb{R}^{4M \times D}$ [S1].
*   **Strengths:** Enables the learning of discontinuity-aware representations in Gaussian Splatting, which standard differentiable rendering cannot handle natively [S1]. Consistently outperforms other methods on PSNR, SSIM, and LPIPS metrics on novel view synthesis tasks [S1].
*   **Limitations:** Relies on the approximation of a non-differentiable function, which may introduce artifacts if the boundary conditions are not well-defined. The method is specific to the discontinuity-aware rendering framework (DisC-GS) [S1].
*   **When to Use:** When the scene contains sharp discontinuities (e.g., occlusion boundaries, thin structures) that standard Gaussian Splatting fails to render accurately due to the non-differentiable nature of the indicator function [S1].

## Background
Bézier-boundary gradient approximation was introduced in the DisC-GS (Discontinuity-aware Gaussian Splatting) paper [S1]. It addresses the limitation of standard Gaussian Splatting, which requires the rendering process to be differentiable. The incorporation of a discontinuous indicator function $g(\cdot)$ into the $\alpha$-blending function makes the rendering process non-differentiable, as $g(\cdot)$ is piecewise constant [S1]. The method was inspired by previous work on handling discontinuities [28, 34, 50, 44] cited in the source [S1]. It is used in the context of 3D scene representation learning from source images, specifically for novel view synthesis [S1].
