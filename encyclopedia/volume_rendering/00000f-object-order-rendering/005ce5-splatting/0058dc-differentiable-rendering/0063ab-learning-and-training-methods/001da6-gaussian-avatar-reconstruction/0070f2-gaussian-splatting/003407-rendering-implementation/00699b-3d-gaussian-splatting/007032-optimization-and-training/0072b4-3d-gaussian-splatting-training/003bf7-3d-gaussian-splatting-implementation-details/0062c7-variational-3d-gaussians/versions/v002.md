# Variational 3D Gaussians

Also called: Variational Gaussian Splatting

## Overview
Variational 3D Gaussians encode a scene as a set of $N$ semantic 3D Gaussians where uncertainty is modeled by storing parameters for a normal distribution of spherical harmonic coefficients rather than explicit feature vectors [S1, unofficial]. This approach allows the representation of a distribution of possible 3D reconstructions conditioned on reference views, enabling consistent multi-view rendering of specific samples while providing plausible details in regions outside the reference view frustums [S1, unofficial]. It differs from standard Gaussian Splatting by replacing deterministic feature vectors with probabilistic distributions over spherical harmonic coefficients, facilitating gradient backpropagation through sampling operations [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   Two reference view images $I_1, I_2$ and their corresponding camera poses [S1, unofficial].
*   A target camera pose for novel view synthesis [S1, unofficial].

**Outputs:**
*   A set of $N$ variational Gaussians $\mathcal{G}$ [S1, unofficial].
*   Rendered feature images $\mathbf{F}$ and RGB images for the target view [S1, unofficial].

### Data Structures
The scene is represented as a set of $N$ variational Gaussians [S1, unofficial]:

$$
\mathcal {G} = \{(\mathbf {x}, \mathbf {S}, \mathbf {R}, o, \mathbf {c}, \mathbf {h}_\mu , \mathbf {h}_\sigma )_i\}_{1\leq i \leq N}
$$

Each Gaussian $i$ contains the following fields [S1, unofficial]:
*   $\mathbf {x} \in \mathbb {R}^3$: Three-dimensional location (mean).
*   $\mathbf {S} \in \mathbb {R}^{3\times 3}$: Diagonal scale matrix.
*   $\mathbf {R} \in \mathbb {R}^{3\times 3}$: Orientation matrix.
*   $o \in [0, 1]$: Opacity.
*   $\mathbf {c} \in \mathbb {R}^K$: Spherical harmonic coefficients for view-dependent colors.
*   $\mathbf {h}_\mu \in \mathbb {R}^4$: Mean of the normal distribution for semantic features.
*   $\mathbf {h}_\sigma \in \mathbb {R}^4$: Standard deviation of the normal distribution for semantic features.

The covariance matrix $\mathbf{C}$ is derived from scale and rotation as [S1, unofficial]:
$$
\mathbf{C} = \mathbf{R}\mathbf{S}\mathbf{S}^\top \mathbf{R}^\top
$$

The feature distributions are modeled as $\mathcal{N}(\mathbf{h}_\mu, \text{diag}(\mathbf{h}_\sigma))$ [S1, unofficial].

### Steps

1.  **Encoding:** An encoder (adapted from pixelSplat [S1, unofficial]) predicts the parameters $\mathbf{x}, \mathbf{S}, \mathbf{R}, o, \mathbf{c}, \mathbf{h}_\mu, \mathbf{h}_\sigma$ for $N$ Gaussians based on the input reference views $I_1, I_2$ and their poses [S1, unofficial]. The encoder predicts Gaussians within the field of view of the two reference views [S1, unofficial].
2.  **Sampling Semantic Gaussians:** To render a specific reconstruction, explicit spherical harmonic coefficients $\mathbf{h}$ for the semantic features are sampled from the variational distributions using the reparameterization trick [S1, unofficial]:
    $$
    \mathbf {h} = \mathbf {h}_\mu + \epsilon \cdot \mathbf {h}_\sigma \quad \quad \epsilon \sim \mathcal {N}(0, \mathbf {1})
    $$
    This step produces a set of "semantic Gaussians" with deterministic features $\mathbf{h}$, allowing consistent multi-view rendering of one possible reconstruction [S1, unofficial]. Gradients backpropagate from the sampled coefficients to the reference view encoder [S1, unofficial].
3.  **Rendering:** The set of semantic Gaussians is rendered using an efficient Gaussian splatting renderer [S1, unofficial]. The renderer is extended to handle feature vectors in addition to RGB colors [S1, unofficial].
    *   The spherical harmonic basis is used to decode the per-Gaussian coefficients $\mathbf{h}$ into view-dependent features [S1, unofficial].
    *   These features are splatted into pixel space [S1, unofficial].
4.  **Filling Empty Regions:** Regions in the rendered image that have no Gaussians (because they are outside all reference view frustums) are filled by sampling from a normal distribution [S1, unofficial]:
    $$
    \mathbf {F} = \mathbf {F}^\textnormal {ren} + \sqrt {1-\mathbf {O}}\odot \epsilon \,, \quad \quad \epsilon \sim \mathcal {N}(\mathbf {0}, \mathbf {1})
    $$
    where $\mathbf {F}$ is the final feature image, $\mathbf {F}^\textnormal {ren}$ is the rendered features from existing Gaussians, and $\mathbf {O}$ is the opacity [S1, unofficial]. This provides plausible reconstruction details for empty areas, supported by a GAN-based decoder [S1, unofficial].

### Pseudocode

```python
import numpy as np

def sample_semantic_gaussians(variational_gaussians):
    """
    Converts variational Gaussians to semantic Gaussians by sampling features.
    """
    semantic_gaussians = []
    for g in variational_gaussians:
        # Sample epsilon from standard normal distribution
        epsilon = np.random.normal(0, 1, size=4)
        # Reparameterization trick
        h = g['h_mu'] + epsilon * g['h_sigma']
        # Create semantic Gaussian
        semantic_gaussians.append({
            'x': g['x'], 'S': g['S'], 'R': g['R'], 'o': g['o'],
            'c': g['c'], 'h': h
        })
    return semantic_gaussians

def render_with_filling(semantic_gaussians, camera_intrinsics, camera_extrinsics, image_shape):
    """
    Renders semantic Gaussians and fills empty regions.
    """
    H, W, C = image_shape
    F_ren = np.zeros((H, W, C))
    O = np.zeros((H, W, 1))
    
    for g in semantic_gaussians:
        # 1. Project 3D Gaussian to 2D screen space (standard Gaussian splatting step)
        # Transform mean_3d to camera space, project to screen, and compute 2D covariance
        # via Jacobian of projection: C_2d = J @ (R @ S @ S^T @ R^T) @ J^T
        center_2d, cov_2d = project_gaussian_to_screen(g['x'], g['S'], g['R'], camera_intrinsics, camera_extrinsics)
        
        # 2. Decode view-dependent features and colors using spherical harmonics
        view_dir = normalize(camera_extrinsics[:3, 3] - g['x'])
        features = decode_spherical_harmonics(g['h'], view_dir)
        colors = decode_spherical_harmonics(g['c'], view_dir)
        
        # 3. Splat into image buffers
        bbox = compute_bounding_box(center_2d, cov_2d, image_shape)
        for y in range(bbox.y_min, bbox.y_max):
            for x in range(bbox.x_min, bbox.x_max):
                dx, dy = x - center_2d[0], y - center_2d[1]
                sigma_inv = np.linalg.inv(cov_2d)
                exponent = -0.5 * np.array([dx, dy]) @ sigma_inv @ np.array([dx, dy])
                weight = np.exp(exponent)
                
                F_ren[y, x] += weight * features
                O[y, x] += weight * g['o']
                
    # Fill empty regions using reparameterization trick
    epsilon = np.random.normal(0, 1, size=(H, W, C))
    O_clamped = np.clip(O.squeeze(), 0, 1)
    F = F_ren + np.sqrt(np.maximum(1 - O_clamped, 0))[:, :, np.newaxis] * epsilon
    
    return F, O

def project_gaussian_to_screen(mean_3d, scale, rot, K, W_ext):
    # Standard Gaussian splatting projection:
    # 1. Transform mean_3d to camera space: mean_c = W_ext @ [mean_3d; 1]
    # 2. Project to screen: mean_s = K @ mean_c
    # 3. Compute 2D covariance: C_2d = J @ (R @ S @ S^T @ R^T) @ J^T
    #    where J is the Jacobian of the projection.
    # Returns 2D mean and 2x2 covariance matrix.
    return np.zeros(2), np.eye(2)

def decode_spherical_harmonics(coeffs, view_dir):
    # Standard SH basis computation for order 3 (16 coefficients)
    basis = compute_sh_basis(view_dir)
    return basis @ coeffs

def compute_sh_basis(view_dir):
    # Standard SH basis computation for order 3 (16 coefficients)
    # Returns array of 16 basis values
    return np.zeros(16)

def normalize(v):
    return v / np.linalg.norm(v)

def compute_bounding_box(center_2d, cov_2d, image_shape):
    # Standard bounding box computation from 2D covariance
    class BBox:
        def __init__(self, y_min, y_max, x_min, x_max):
            self.y_min, self.y_max, self.x_min, self.x_max = y_min, y_max, x_min, x_max
    return BBox(0, image_shape[0], 0, image_shape[1])
```

### Parameters
*   $N$: Number of Gaussians. Not given in the sources.
*   $K$: Dimension of spherical harmonic coefficients for color. Not given in the sources.
*   Feature dimension: 4 (for $\mathbf{h}_\mu, \mathbf{h}_\sigma$) [S1, unofficial].
*   $\epsilon$: Standard normal noise $\mathcal{N}(0, \mathbf{1})$ [S1, unofficial].

### Edge Cases and Pitfalls
*   **Empty Regions:** When rendering novel views, regions may have no Gaussians because they are outside all reference view frustums [S1, unofficial]. These areas must be filled by sampling from a normal distribution based on rendered features and opacity to provide plausible reconstruction [S1, unofficial].
*   **Gradient Flow:** The reparameterization trick is essential for backpropagating gradients from the sampled coefficients to the reference view encoder [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Models uncertainty in feature space; provides plausible details in unseen regions via probabilistic filling; allows consistent multi-view rendering of specific samples [S1, unofficial].
*   **Limitations:** Requires a GAN-based decoder for plausible filling in empty areas; uncertainty modeling adds complexity to the representation [S1, unofficial].
*   **When to use:** When dealing with limited reference views (e.g., two views) and needing to synthesize novel views with plausible details in occluded or unseen regions [S1, unofficial].
*   **When not to use:** When high-fidelity deterministic features are required without probabilistic modeling; when computational resources for GAN decoding are unavailable [S1, unofficial].

## Background
Variational 3D Gaussians were introduced in the paper "latentSplat: Latent 3D Gaussian Splatting for Memory Efficient Novel View Synthesis" by C. Wewer et al. [S1, unofficial]. The method adapts the encoder from pixelSplat to predict variational Gaussian parameters [S1, unofficial]. It is used for novel view synthesis from a small number of reference views, leveraging the efficiency of Gaussian splatting [S1, unofficial].
