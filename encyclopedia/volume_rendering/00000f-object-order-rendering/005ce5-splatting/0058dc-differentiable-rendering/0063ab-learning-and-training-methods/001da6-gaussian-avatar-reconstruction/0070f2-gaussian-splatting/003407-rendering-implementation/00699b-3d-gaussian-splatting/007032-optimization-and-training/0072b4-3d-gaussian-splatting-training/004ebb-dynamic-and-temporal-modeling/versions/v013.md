# Dynamic and Temporal Modeling

Also called: Dynamic Scene Reconstruction, 4D Gaussian Splatting, Time-dependent NeRF

## Overview
Dynamic and Temporal Modeling extends static radiance field representations (such as NeRF and 3D Gaussian Splatting) to handle scenes that change geometry or appearance over time. It solves the problem of reconstructing and rendering dynamic content from static image or video sequences by explicitly modeling temporal evolution [S1, S2, S3]. Unlike sibling methods that isolate motion to specific objects or rely on explicit parametric functions for simple motions, this family generally relies on learned implicit functions or canonical space mappings to handle complex, non-rigid, and global deformations [S1, S2]. It sets itself apart from static baselines by introducing time as a conditioning variable or deformation field, allowing for novel view synthesis at arbitrary timestamps [S1, S3].

## Shared principles
The family shares the following core mechanisms for handling temporal dynamics:

1.  **Temporal Parameterization:** Attributes that vary with time, such as position $\mathbf{c}$, rotation $\mathbf{q}$, opacity $\alpha$, density $\sigma$, or color $\mathbf{c}$, are expressed as functions of time $t$ [S1, S2, S3]. Common functional forms include:
    *   **Polynomial/Linear:** $\mathbf{q}(t) = \mathbf{q}_0 + \mathbf{m}t$ [S2].
    *   **Fourier Series:** $\mathbf{c}(t) = \mathbf{c}_0 + \sum_{k=0}^{K} (\mathbf{a}_k \cos(k \omega t) + \mathbf{b}_k \sin(k \omega t))$ [S2].
    *   **Neural Deformation:** A neural network $\Psi_t(x, t)$ predicts a displacement $\Delta x$ to warp dynamic coordinates to a canonical space [S1, S3].
    *   **Implicit Fields:** Time-dependent NeRFs map $(x, d, t)$ to density and color, often using local neighborhoods of frames .

2.  **Canonical Space Mapping:** Many methods (e.g., D-NeRF, Nerfies) introduce a canonical configuration, typically at $t=0$, where the scene is static. A deformation network maps dynamic coordinates $x$ at time $t$ to canonical coordinates $x'$:
    $$ x' = x + \Psi_t(x, t) $$
    The radiance field is then queried in the canonical space: $[\sigma, c] = \Psi_x(x', d)$ [S1, S3].

3.  **Rendering with Dynamics:** The rendering process integrates time-dependent attributes. For Gaussian-based methods, position and rotation are computed for the specific time $t$ of the camera ray before rasterization [S2]. For NeRF-based methods, density $\sigma$ and color $c$ are queried at the deformed or time-conditioned point [S1].

4.  **Loss Functions:** Optimization typically minimizes photometric loss (L1 or LPIPS) between rendered and ground truth images [S1, S2]. Additional constraints often include:
    *   **Temporal Smoothness:** Penalizing abrupt changes in attributes between adjacent frames [S1].
    *   **Rigid/Flow Constraints:** Using optical flow or KNN rigid loss to guide deformation [S1].
    *   **Regularization:** Elastic or background regularization to prevent overfitting in deformation fields .

## Subtopics

### [Projected Color-Guided Dynamic NeRF](7523-projected-color-guided-dynamic-nerf.md)
**What it is:** An on-the-fly training method for dynamic scenes that replaces temporal deformation fields with a NeRF model conditioned on multi-view projected colors. By leveraging the invariance of projected color for corresponding 3D points across consecutive frames, the model implicitly tracks correspondence, allowing it to utilize radiance fields from previous frames to render the current frame with minimal optimization iterations.
**Distinction:** Unlike sibling methods that use explicit temporal inputs or deformation networks which extrapolate poorly to unseen times, OD-NeRF requires the minimum number of optimization iterations per new frame.
**When to choose:** When streaming dynamic scenes is required and computational efficiency per frame is critical, particularly for synthetic datasets where occupancy grids can be transited.

### [On-the-Fly Dynamic NeRF Training](7582-on-the-fly-dynamic-nerf-training.md)
**What it is:** A method for training dynamic Neural Radiance Fields concurrently with the acquisition of training frames, enabling the streaming of dynamic scenes as they unfold. It estimates the radiance field for the current time step $t_k$ using only the images up to $t_k$ and the radiance field from the previous step $t_{k-1}$.
**Distinction:** It is distinguished by its application of a first-order Markov assumption to decouple current estimation from the entire history, allowing for minimal optimization iterations per frame and interactive-speed streaming.
**When to choose:** For real-time or near-real-time reconstruction of dynamic scenes where full offline 4D reconstruction is not feasible.

### [D-NeRF](8660-d-nerf.md)
**What it is:** A method for synthesizing novel views at an arbitrary point in time of dynamic scenes with complex non-rigid geometries, optimized from a sparse set of input monocular views without ground-truth geometry or multi-view images. It solves the problem of extending static Neural Radiance Fields (NeRF) to dynamic environments by decomposing the learning process into two modules: a deformation network that maps scene points to a canonical space, and a canonical network that regresses density and color from that space.
**Distinction:** Unlike naive extensions of NeRF that map $(x, y, z, t)$ directly to density and radiance, D-NeRF exploits temporal redundancy by anchoring all time instances to a common canonical configuration (typically $t=0$), allowing it to handle rigid, articulated, and non-rigid motions from a single camera moving around the scene.
**When to choose:** When reconstructing dynamic scenes from sparse monocular video inputs where explicit multi-view correspondence is unavailable.

### [DaReNeRF](13782-darenerf.md)
**What it is:** A method for novel view synthesis of dynamic scenes that addresses the shift variance and direction ambiguity inherent in traditional Discrete Wavelet Transforms (DWT) by employing a direction-aware representation. It differs from standard plane-based decompositions by capturing scene dynamics from six distinct orientations using an inverse dual-tree complex wavelet transformation (DTCWT), thereby eliminating the checkerboard artifacts and ghosting associated with DWT.
**Distinction:** It uses a direction-aware 4D decomposition rather than standard 3D spatial or simple temporal interpolation, specifically targeting artifacts caused by motion and camera movement in wavelet-based representations.
**When to choose:** When high-fidelity reconstruction of dynamic scenes with significant motion is required, and standard plane-based or DWT-based NeRFs exhibit ghosting or shift-variance artifacts.

### [Blur and Transient Modeling](13851-blur-and-transient-modeling.md)
**What it is:** This family addresses the limitations of standard 3D Gaussian Splatting (3DGS) when applied to dynamic scenes, non-line-of-sight (NLOS) imaging, and real-world captures with optical artifacts. It extends the static Gaussian representation to handle temporal dynamics, transient occluders, and blur effects.
**Distinction:** It differs from sibling NeRF-based methods (e.g., [D-NeRF](8660-d-nerf.md)) by maintaining a unified, explicit Gaussian representation rather than a neural field, which yields efficiency and state-of-the-art results on diverse photo scenes without requiring explicit transient labels.
**When to choose:** When working with 3DGS and needing to handle real-world artifacts like motion blur or transient objects without switching to a NeRF-based pipeline.

### [Deformation Field Modeling](13852-deformation-field-modeling.md)
**What it is:** Deformation Field Modeling addresses the problem of reconstructing and rendering dynamic scenes from static image or video sequences by explicitly modeling the temporal evolution of geometry and appearance. It solves the limitation of static radiance fields by mapping dynamic, time-varying coordinates to a static canonical space where the radiance field is defined.
**Distinction:** What sets this approach apart from siblings like [Dynamic Object Embedding in Static Scenes](8796-dynamic-object-embedding-in-static-scenes.md) (which isolates motion to specific objects) or [Dynamic 3D Gaussian Splatting](9168-dynamic-3d-gaussian-splatting-katsumata-et-al.md) (which uses explicit parametric functions) is its reliance on a learned implicit function (typically an MLP) to predict continuous displacement vectors or feature transformations, allowing for complex, non-rigid, and global deformations without assuming a specific motion prior.
**When to choose:** When the scene exhibits complex, non-rigid motion that cannot be easily modeled by simple parametric functions or object-specific embeddings.

#### Temporal 3D Gaussian Splatting
- [S1] A method that introduces a temporal radial basis function to represent temporal opacity, modeling emerging or vanishing content. Polynomial functions model motion and rotation.
- [S1] Spherical harmonics are replaced with features consisting of base color, view-related feature, and time-related feature. The latter two are translated into residual color through an MLP added to the base color.
- [S1] During optimization, new 3D Gaussians are sampled at under-optimized positions based on training error and coarse depth.

#### 3DGStream
- [S1] A method that allows online training of 3DGS into dynamic scene reconstruction by modeling the transformation between frames as a neural transformation cache and adaptively adding 3D Gaussians to handle emerging objects.

#### Multi-scale Motion-Compensated Reconstruction
- [S2] A procedure coupled with the two-step DynART/P-DVC algorithm to handle large displacement amplitudes by resolving large-scale features first and progressively enriching with finer details.

#### Time-dependent NeRF
- [S3] A NeRF variant that represents scene geometry and appearance at each specific time step t, trained using neighboring frames around time t, to capture local scene geometry and motion.
- [S3] Represent scene appearance using mapping function c = ϕc(x, d) taking point x ∈ R3 and viewing direction d ∈ R2 to predict color c ∈ R3.
- [S3] Represent scene geometry via mapping function s = ϕg(x) which maps a 3D point x to a signed distance value s ∈ R.
- [S3] For a camera ray r(h) = o + hd, sample K 3D points {xi(r) = r(hi) | i = 1, ..., K, hi < hi+1}.
- [S3] Use the time-dependent NeRF to compute SDF flows, which are used to constrain the learning of continuous camera motion via the linear relationship between SDF flow and scene flow.
- [S3] Convert signed distance si to density σi using: σi = max((Φ(si) - Φ(si+1))/Φ(si), 0), where Φ(s) = 1/(1+e^(1-γs)), γ is a learnable parameter, and i is the point index.
- [S3] Render pixel color Ĉ(r) via volume rendering: Ĉ(r) = Σ(i=1 to K) Li σi ci, where Li = Π(j=1 to i-1) (1 - σj) is the accumulated transmittance.

## Background
Dynamic scene reconstruction has evolved from static NeRF and 3DGS representations to handle temporal variations. Early approaches like D-NeRF [S1, S3] introduced canonical space mapping to handle non-rigid motion from monocular views. Subsequent methods like OD-NeRF [S1] focused on on-the-fly training for streaming applications, utilizing Markov assumptions to reduce computational load. In the Gaussian Splatting domain, methods like Temporal 3DGS [S1] and 3DGStream [S1] adapted the explicit representation to handle dynamic content through temporal basis functions and neural caches. DaReNeRF [S1] addressed specific artifacts in wavelet-based dynamic representations. More recent work, such as Time-dependent NeRF [S3], integrates continuous camera motion estimation with local scene geometry representation using SDF flows. The field continues to expand with specialized techniques for blur, transients, and multi-scale motion compensation [S1, S2, S3].
