# Closed-Form Scene Appearance Estimation

Also called: Global LLS System, Normal System Solution

## Overview
This method estimates spherical harmonic (SH) coefficients for mesh vertices by solving a global weighted least-squares problem that jointly fits RGB observations from all calibrated views [S1, unofficial]. It distinguishes itself from iterative optimization approaches by providing an analytical closed-form solution, utilizing adaptive regularization to constrain SH bands based on the directional support available at each vertex [S1, unofficial].

## How it works
**Inputs:**
*   A mesh $M$ with $N_v$ vertices [S1, unofficial].
*   $K$ calibrated RGB images $\{I_k\}_{k=1}^K$ [S1, unofficial].
*   SH degree $L$ (typically up to order 2, i.e., $s=0,1,2$) [S1, unofficial].
*   Regularization strengths $\gamma_s$ (supported) and $\gamma_u$ (under-supported) [S1, unofficial].
*   Minimum confidence weight threshold $\epsilon_w$ [S1, unofficial].

**Outputs:**
*   Estimated SH coefficients $X^*$ for each vertex [S1, unofficial].

**Data Structures:**
*   **Rasterization Records ($R$):** Stores per-pixel data including vertex indices $i_{s,k,r}$, SH basis features $\phi_{s,k,r}$, and confidence weights $w_{k,r}$ [S1, unofficial].
*   **View Counts ($n^v_i$):** Integer count of views contributing to vertex $i$ [S1, unofficial].
*   **Global Matrices:**
    *   $A \in \mathbb{R}^{(KHW) \times (qN_v)}$: The design matrix mapping vertex SH coefficients to pixel observations [S1, unofficial].
    *   $B \in \mathbb{R}^{(KHW) \times 3}$: The observation matrix containing pixel RGB values [S1, unofficial].
    *   $W \in \mathbb{R}^{(KHW) \times (KHW)}$: A diagonal matrix of confidence weights [S1, unofficial].
    *   $\Lambda \in \mathbb{R}^{(qN_v) \times (qN_v)}$: Block-diagonal regularization matrix [S1, unofficial].
    *   $H \in \mathbb{R}^{qN_v \times qN_v}$: The normal matrix ($A^\top W A + \Lambda$) [S1, unofficial].
    *   $G \in \mathbb{R}^{qN_v \times 3}$: The right-hand side ($A^\top W B$) [S1, unofficial].

**Parameters:**
*   $\gamma_s$: Supported SH regularization strength. Typical value: $0 < \gamma_s \ll \gamma_u$ [S1, unofficial].
*   $\gamma_u$: Under-supported SH regularization strength. Typical value: $\gamma_u \gg \gamma_s$ [S1, unofficial].
*   $\delta$: PCG convergence tolerance [S1, unofficial].
*   $T_{max}$: Maximum PCG iterations [S1, unofficial].

**Steps:**

1.  **Preprocessing (Gradient-Guided Densification):**
    *   For each triangle $j$ and view $k$, identify pixels $\Omega_{k,j}$ covered by the triangle [S1, unofficial].
    *   Compute multiview image-space variation: $S_j \triangleq \sum_{k=1}^K \sum_{p \in \Omega_{k,j}} \|\nabla I_k(p)\|^2$ [S1, unofficial].
    *   Select triangles with large $S_j$ for subdivision [S1, unofficial].
    *   Place new vertices at the mean of surface samples mapped from covered pixels using barycentric weights [S1, unofficial].
    *   Replace parent triangles with three child triangles [S1, unofficial].
    *   Re-rasterize after densification rounds [S1, unofficial].

2.  **Initialization:**
    *   Initialize rasterization records $R$ and view counts $\{n^v_i\}_{i=1}^{N_v}$ to zero [S1, unofficial].

3.  **Per-View Rasterization and Matrix Assembly:**
    *   For each view $k = 1 \dots K$:
        *   Rasterize mesh $M$ to initialize per-view matrix $A_k$ [S1, unofficial].
        *   For each valid pixel $p_{k,r}$:
            *   Retrieve vertex indices $i_{s,k,r}$ and scaling factors $\lambda_{s,k,r}$ for SH orders $s=0,1,2$ [S1, unofficial].
            *   Compute SH basis features: $\phi_{s,k,r} \leftarrow \lambda_{s,k,r} Y(d_k)$, where $Y(d_k)$ is the SH basis evaluated at view direction $d_k$ [S1, unofficial].
            *   Set row $r$ of $A_k$ at column $i_{s,k,r}$ to $(\phi_{s,k,r})^\top$ [S1, unofficial].
            *   Compute confidence weight $w_{k,r}$ using the method's specific weighting equation (Eq. 19 in source) [S1, unofficial].
            *   Store $\{i_{s,k,r}, \phi_{s,k,r}\}_{s=0}^2$ and $w_{k,r}$ in $R$ [S1, unofficial].
        *   Construct observation vector $B_k \leftarrow [I_k(p_{k,1}) \dots I_k(p_{k,HW})]^\top$ [S1, unofficial].
        *   Construct weight matrix $W_k \leftarrow \text{diag}(w_{k,1}, \dots, w_{k,HW})$ [S1, unofficial].
        *   Update view counts $\{n^v_i\}$ based on rasterized pixels [S1, unofficial].

4.  **Global Matrix Assembly:**
    *   Assemble global matrices:
        *   $A \leftarrow [A_1^\top \dots A_K^\top]^\top$ [S1, unofficial].
        *   $B \leftarrow [B_1^\top \dots B_K^\top]^\top$ [S1, unofficial].
        *   $W \leftarrow \text{blkdiag}(W_1, \dots, W_K)$ [S1, unofficial].

5.  **Regularization Construction:**
    *   For each vertex $i = 1 \dots N_v$:
        *   Construct regularization block $\Lambda_i$ using $n^v_i$, $\gamma_s$, and $\gamma_u$ according to Eq. (26) in the source [S1, unofficial].
        *   Assign $\gamma_s$ if the vertex has sufficient directional support, otherwise $\gamma_u$ [S1, unofficial].
    *   Assemble global regularization matrix: $\Lambda \leftarrow \text{blkdiag}(\Lambda_1, \dots, \Lambda_{N_v})$ [S1, unofficial].

6.  **Normal System Formation:**
    *   Compute $H \leftarrow A^\top W A + \Lambda$ [S1, unofficial].
    *   Compute $G \leftarrow A^\top W B$ [S1, unofficial].
    *   Here, $H \in \mathbb{R}^{qN_v \times qN_v}$ is the shared normal matrix for three color channels, and $G \in \mathbb{R}^{qN_v \times 3}$ contains weighted observation terms for R, G, B channels [S1, unofficial].

7.  **Solution:**
    *   Solve for $X^*$ using the Preconditioned Conjugate Gradient (PCG) method. Explicit inversion of $H$ is avoided due to computational cost [S1, unofficial].

**Pseudocode:**

    """
    Estimates SH coefficients for mesh vertices via global LLS.
    """
    N_v = mesh.num_vertices
    K = len(images)
    q = 9  # Number of SH coefficients per vertex for order 2
    
    # Step 1: Gradient-Guided Densification
    # [S1, unofficial] Compute S_j for all triangles, subdivide high-variation triangles, re-rasterize
    refined_mesh = gradient_guided_densification(mesh, images)
    
    # Step 2: Initialization
    rasterization_records = []
    view_counts = [0] * N_v
    
    # Step 3 & 4: Per-View Rasterization and Global Assembly
    A_rows = []
    B_rows = []
    W_diag = []
    
    for k in range(K):
        I_k = images[k]
        pixels = rasterize(refined_mesh, view=k)
        
        for p in pixels:
            if not p.is_valid:
                continue
                
            i_s, lambda_s = get_sh_features(p, view_direction=p.view_dir)
            phi_s = [lambda_s[s] * spherical_harmonic_basis(p.view_dir, s) for s in range(q)]
            
            row_A = []
            for s in range(q):
                row_A.append((i_s[s], phi_s[s]))
            A_rows.append(row_A)
            
            B_rows.append(I_k[p.pixel_coords])
            w = compute_confidence_weight(p, I_k)
            W_diag.append(w)
            
            for s in range(q):
                view_counts[i_s[s]] += 1
                
            rasterization_records.append({
                'vertex_indices': i_s,
                'phi': phi_s,
                'weight': w
            })
            
    # Step 5: Regularization Construction
    Lambda_blocks = []
    for i in range(N_v):
        n_v = view_counts[i]
        Lambda_i = construct_regularization_block(n_v, gamma_s, gamma_u)
        Lambda_blocks.append(Lambda_i)
        
    # Step 6 & 7: Normal System and PCG Solution
    X_star = triangle_pcg_solver(rasterization_records, Lambda_blocks, view_counts, gamma_s, gamma_u, delta, t_max)
    return X_star

def triangle_pcg_solver(records, Lambda_blocks, view_counts, gamma_s, gamma_u, delta, t_max):
    # Solves H X = G using matrix-free PCG with triangle structure
    # [S1, unofficial]
    X = [0.0] * (len(view_counts) * 3) # Flattened solution for R, G, B channels
    
    for channel in range(3):
        # Extract G channel vector from global assembly
        g = extract_G_channel(records, channel)
        r = g[:]
        eta = dot(r, r)
        
        # Preconditioner solve Pz = r (using diagonal of Lambda as preconditioner [G])
        z = preconditioner_solve(r, Lambda_blocks)
        p = z[:]
        sigma = dot(r, z)
        
        for t in range(t_max):
            # h = H p
            h = triangle_normal_product(p, records, Lambda_blocks)
            
            alpha = sigma / dot(p, h)
            for i in range(len(X)):
                X[i] += alpha * p[i]
            for i in range(len(r)):
                r[i] -= alpha * h[i]
                
            if dot(r, r) <= delta * delta * eta:
                break
                
            z = preconditioner_solve(r, Lambda_blocks)
            sigma_new = dot(r, z)
            beta = sigma_new / sigma
            for i in range(len(p)):
                p[i] = z[i] + beta * p[i]
            sigma = sigma_new
            
    return X

def triangle_normal_product(p, records, Lambda_blocks):
    # Computes H * p without forming H explicitly
    # H = A^T W A + Lambda
    result = [0.0] * len(p)
    
    # Add Lambda * p
    offset = 0
    for block in Lambda_blocks:
        size = len(block)
        for i in range(size):
            for j in range(size):
                result[offset + i] += block[i][j] * p[offset + j]
        offset += size

## Operating characteristics
*   **Complexity:** The global LLS solve complexity is dominated by PCG iterations. Setup is $O(KHWq^2 + N_v q^3)$ [S1, unofficial]. Each PCG iteration is $O(KHWq + N_v q^2)$ [S1, unofficial]. Total solve time $T_{solve} = O(KHWq^2 + N_v q^3) + O(T_{pcg}(KHWq + N_v q^2)) + O(KHWq + N_v q)$ [S1, unofficial].
*   **Strengths:** Provides an analytical solution, avoiding iterative gradient descent. Adaptive regularization ensures the normal matrix is strictly positive definite, guaranteeing a unique global minimizer [S1, unofficial].
*   **Limitations:** Requires a mesh prior. Explicit formation of $H^{-1}$ is avoided, but assembling $A$ and $B$ can be memory-intensive for high-resolution scenes [S1, unofficial]. The method assumes calibrated views [S1, unofficial].

## Background
This method originates from "CF-Splat: Closed-Form Triangle Splatting with Mesh Priors" [S1, unofficial]. It addresses the limitation of coarse triangles in mesh-based appearance representation by introducing gradient-guided densification and a global least-squares formulation with adaptive SH regularization [S1, unofficial].
