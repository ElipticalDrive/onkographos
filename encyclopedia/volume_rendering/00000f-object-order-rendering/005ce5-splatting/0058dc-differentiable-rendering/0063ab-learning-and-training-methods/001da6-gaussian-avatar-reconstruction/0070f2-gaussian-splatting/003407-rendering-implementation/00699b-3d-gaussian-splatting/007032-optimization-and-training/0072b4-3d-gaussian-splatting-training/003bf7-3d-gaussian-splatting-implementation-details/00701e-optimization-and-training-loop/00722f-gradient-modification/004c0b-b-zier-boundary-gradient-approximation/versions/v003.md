# Bézier-boundary gradient approximation

Also called: DisC-GS gradient approximation, discontinuity-aware gradient approximation

## Overview
This method approximates the gradients of a discontinuous indicator function $g(\cdot)$ with respect to the control point coordinates of a cubic Bézier curve, enabling backpropagation in Gaussian Splatting despite the function being piecewise constant and non-differentiable [S1]. It sets itself apart from standard differentiable rendering by explicitly handling the non-differentiable boundary transitions of discontinuity-aware alpha-blending, whereas standard Gaussian Splatting assumes smooth, differentiable rendering primitives [S1].

## How it works
**Inputs and Outputs**
*   **Input:** The current control point coordinates $\mathbf{c}_{\text{curve}} \in \mathbb{R}^{4M \times 3}$ (for 3D) or $\mathbb{R}^{4M \times 2}$ (for 2D), where $M$ is the number of control points per Gaussian [S1]. The target 2D point $\mathbf{p} = (x_p, y_p)$ in the image plane [S1]. The current output of the Bézier curve function $g_{sc}(\mathbf{p})$ and its gradient with respect to the curve output $\frac{\partial \mathcal{L}}{\partial g_{sc}}$ [S1].
*   **Output:** The approximated gradient $\frac{\partial g}{\partial \mathbf{c}_{\text{curve}}[0,0]}$ (and similarly for other coordinates) [S1].

**Data Structures**
*   $\mathbf{c}_{\text{curve}}$: Attribute storing control point coordinates. For 2D GS, shape is $\mathbb{R}^{4M \times 2}$. For 3D GS, shape is $\mathbb{R}^{4M \times 3}$ [S1].
*   $S_\phi$: A set of real number solutions for the target control point value $\phi$ [S1].

**Parameters**
*   $M$: Hyperparameter for the number of control points per Gaussian. Value: 3 [S1].
*   $\epsilon$: Small value to prevent gradient explosion. Value: $10^{-5}$ if target > current, $-10^{-5}$ otherwise [S1].

**Steps**
The strategy approximates the partial derivative $\frac{\partial g}{\partial \mathbf{c}_{\text{curve}}[0,0]}$ using the chain rule:
$$ \frac{\partial g}{\partial \mathbf{c}_{\text{curve}}[0,0]} = \frac{\partial g}{\partial g_{sc}} \times \frac{\partial g_{sc}}{\partial \mathbf{c}_{\text{curve}}[0,0]} $$
where $g_{sc}(\mathbf{p})$ is the cubic Bézier curve function evaluated at $\mathbf{p}$ [S1]. The approximation of $\frac{\partial g_{sc}}{\partial \mathbf{c}_{\text{curve}}[0,0]}$ proceeds as follows:

1.  **Check Modification Necessity:** Determine if $g_{sc}(\mathbf{p})$ needs modification. If any of the following hold, set $\frac{\partial g_{sc}}{\partial \mathbf{c}_{\text{curve}}[0,0]} = 0$ and terminate:
    *   $\frac{\partial \mathcal{L}}{\partial g_{sc}} = 0$ (optimal state) [S1].
    *   $\frac{\partial \mathcal{L}}{\partial g_{sc}} > 0$ and $g_{sc}(\mathbf{p}) = 0$ (already at minimum) [S1].
    *   $\frac{\partial \mathcal{L}}{\partial g_{sc}} < 0$ and $g_{sc}(\mathbf{p}) = 1$ (already at maximum) [S1].

2.  **Solve for Target Value:** If modification is needed, identify the target value $\phi$ for $\mathbf{c}_{\text{curve}}[0,0]$ such that the Bézier curve passes through $\mathbf{p}$. Solve the system derived from the cubic Bézier definition for $t$ and $\phi$ in $O(1)$ time [S1]:
    $$ x_p = (1-t)^3 \phi + 3(1-t)^2 t c[1,0] + 3(1-t)t^2 c[2,0] + t^3 c[3,0] $$
    $$ y_p = (1-t)^3 c[0,1] + 3(1-t)^2 t c[1,1] + 3(1-t)t^2 c[2,1] + t^3 c[3,1] $$
    Collect all real number solutions for $\phi$ into a set $S_\phi$ [S1].

3.  **Approximate Gradient:** Based on the contents of $S_\phi$, apply one of the following cases:
    *   **No Side:** If $S_\phi$ is empty, set $\frac{\partial g_{sc}}{\partial \mathbf{c}_{\text{curve}}[0,0]} = 0$. This implies no real value of $\mathbf{c}_{\text{curve}}[0,0]$ can cause the curve to pass through $\mathbf{p}$ [S1].
    *   **Single Side:** If all solutions in $S_\phi$ lie on the same side of $\mathbf{c}_{\text{curve}}[0,0]$, let $\phi_e$ be the solution nearest to $\mathbf{c}_{\text{curve}}[0,0]$. Approximate the gradient via linear interpolation:
        $$ \frac{\partial g_{sc}}{\partial \mathbf{c}_{\text{curve}}[0,0]} = \frac{g_{sc}(\mathbf{p}) - \hat{g}_{sc}(\mathbf{p})}{\phi_e - \mathbf{c}_{\text{curve}}[0,0] + \epsilon} $$
        where $\hat{g}_{sc}(\mathbf{p}) = 1$ if $g_{sc}(\mathbf{p})=0$ else $0$, and $\epsilon = 10^{-5}$ if $\phi_e > \mathbf{c}_{\text{curve}}[0,0]$ else $-10^{-5}$ [S1].
    *   **Both Sides:** If solutions exist on both left and right sides of $\mathbf{c}_{\text{curve}}[0,0]$, let $\phi_1$ be the nearest solution from the left and $\phi_2$ be the nearest from the right. Approximate the gradient as the sum of two interpolation terms:
        $$ \frac{\partial g_{sc}}{\partial \mathbf{c}_{\text{curve}}[0,0]} = \frac{g_{sc}(\mathbf{p}) - \hat{g}_{sc}(\mathbf{p})}{\phi_1 - \mathbf{c}_{\text{curve}}[0,0] + \epsilon_1} + \frac{g_{sc}(\mathbf{p}) - \hat{g}_{sc}(\mathbf{p})}{\phi_2 - \mathbf{c}_{\text{curve}}[0,0] + \epsilon_2} $$
        where $\epsilon_1$ and $\epsilon_2$ follow the sign rule defined in the Single Side case [S1].

**Pseudocode**
```python
import numpy as np

def bezier_boundary_gradient_approximation(c_curve, p, g_sc_val, dL_dg_sc, M=3):
    """
    Approximates the gradient of the discontinuous indicator function g with respect to 
    the first control point's x-coordinate c_curve[0,0].
    
    Args:
        c_curve: Array of control points, shape (4*M, 3) for 3D or (4*M, 2) for 2D.
        p: Target 2D point (x_p, y_p).
        g_sc_val: Current output of the Bézier curve function g_sc(p).
        dL_dg_sc: Gradient of the loss with respect to g_sc(p).
        M: Number of control points per Gaussian.
        
    Returns:
        approx_grad: Approximated gradient d(g_sc)/d(c_curve[0,0]).
    """
    # Step 1: Check if modification is needed
    if dL_dg_sc == 0:
        return 0.0
    if dL_dg_sc > 0 and g_sc_val == 0:
        return 0.0
    if dL_dg_sc < 0 and g_sc_val == 1:
        return 0.0

    # Step 2: Solve for target value phi
    # The system is:
    # x_p = (1-t)^3 * phi + 3*(1-t)^2 * t * c[1,0] + 3*(1-t) * t^2 * c[2,0] + t^3 * c[3,0]
    # y_p = (1-t)^3 * c[0,1] + 3*(1-t)^2 * t * c[1,1] + 3*(1-t) * t^2 * c[2,1] + t^3 * c[3,1]
    
    # Extract control points
    c0 = c_curve[0]
    c1 = c_curve[1]
    c2 = c_curve[2]
    c3 = c_curve[3]
    
    x_p, y_p = p[0], p[1]
    
    # Solve for t using the y-coordinate equation (independent of phi)
    # y_p = (1-t)^3 * c0[1] + 3*(1-t)^2 * t * c1[1] + 3*(1-t) * t^2 * c2[1] + t^3 * c3[1]
    # This is a cubic equation in t: A*t^3 + B*t^2 + C*t + D = 0
    # Coefficients for t^3, t^2, t, constant term
    # Expand:
    # (1-t)^3 = 1 - 3t + 3t^2 - t^3
    # 3(1-t)^2 t = 3t - 6t^2 + 3t^3
    # 3(1-t)t^2 = 3t^2 - 3t^3
    # t^3 = t^3
    
    # Coeff for t^3: -c0[1] + 3*c1[1] - 3*c2[1] + c3[1]
    # Coeff for t^2: 3*c0[1] - 6*c1[1] + 3*c2[1]
    # Coeff for t: -3*c0[1] + 3*c1[1]
    # Constant: c0[1]
    
    a_t = -c0[1] + 3*c1[1] - 3*c2[1] + c3[1]
    b_t = 3*c0[1] - 6*c1[1] + 3*c2[1]
    c_t = -3*c0[1] + 3*c1[1]
    d_t = c0[1] - y_p
    
    # Solve cubic equation a_t*t^3 + b_t*t^2 + c_t*t + d_t = 0
    # Using numpy roots for robustness in implementation
    coeffs_t = [a_t, b_t, c_t, d_t]
    t_roots = np.roots(coeffs_t)
    
    # Filter for real roots within [0, 1]
    valid_t = t_roots[np.isreal(t_roots) & (np.real(t_roots) >= 0) & (np.real(t_roots) <= 1)]
    
    S_phi = []
    
    for t in valid_t:
        t = np.real(t)
        # Solve for phi using the x-coordinate equation
        # x_p = (1-t)^3 * phi + K
        # where K = 3*(1-t)^2 * t * c1[0] + 3*(1-t) * t^2 * c2[0] + t^3 * c3[0]
        K = 3*(1-t)**2 * t * c1[0] + 3*(1-t) * t**2 * c2[0] + t**3 * c3[0]
        denom = (1-t)**3
        
        if abs(denom) > 1e-9:
            phi = (x_p - K) / denom
            S_phi.append(phi)
        else:
            # If denom is 0, check if x_p == K. If so, any phi works (degenerate), 
            # but practically we might ignore or handle as boundary. 
            # The source implies solving for phi, so we assume valid t yields valid phi.
            pass
            
    S_phi = np.array(S_phi)
    
    # Step 3: Approximate gradient based on S_phi
    c0_x = c_curve[0, 0]
    
    if len(S_phi) == 0:
        # No side situation
        return 0.0
    
    # Check sides
    left_sols = S_phi[S_phi < c0_x]
    right_sols = S_phi[S_phi > c0_x]
    
    # Define helper for hat_g
    def get_hat_g(g_val):
        return 1.0 if g_val == 0 else 0.0
        
    g_hat = get_hat_g(g_sc_val)
    numerator = g_sc_val - g_hat
    
    if len(left_sols) == 0 or len(right_sols) == 0:
        # Single side situation
        # Find nearest solution
        if len(left_sols) > 0:
            phi_e = left_sols[np.argmin(np.abs(left_sols - c0_x))]
        else:
            phi_e = right_sols[np.argmin(np.abs(right_sols - c0_x))]
            
        # Determine epsilon
        if phi_e > c0_x:
            eps = 1e-5
        else:
            eps = -1e-5
            
        grad = numerator / (phi_e - c0_x + eps)
        return grad
        
    else:
        # Both sides situation
        # Nearest left
        phi_1 = left_sols[np.argmin(np.abs(left_sols - c0_x))]
        # Nearest right
        phi_2 = right_sols[np.argmin(np.abs(right_sols - c0_x))]
        
        # Epsilon for left
        if phi_1 > c0_x: # Should be false, but for safety
            eps_1 = 1e-5
        else:
            eps_1 = -1e-5
            
        # Epsilon for right
        if phi_2 > c0_x:
            eps_2 = 1e-5
        else:
            eps_2 = -1e-5
            
        grad_1 = numerator / (phi_1 - c0_x + eps_1)
        grad_2 = numerator / (phi_2 - c0_x + eps_2)
        
        return grad_1 + grad_2
```

## Operating characteristics
*   **Time Complexity:** The core approximation step involves solving a cubic equation for $t$ and a linear equation for $\phi$, both performed in $O(1)$ time [S1].
*   **Memory Complexity:** Requires storing the control points $\mathbf{c}_{\text{curve}}$ and the set of solutions $S_\phi$, which is bounded by the degree of the polynomial (constant size) [S1].
*   **Strengths:** Enables the learning of discontinuity-aware rendering in Gaussian Splatting by providing non-zero gradients where standard backpropagation would yield zero [S1].
*   **Limitations:** The approximation relies on the existence of real solutions for the Bézier curve passing through the target point; if none exist, the gradient is zero, potentially stalling learning for certain configurations [S1].
*   **When to use:** Use when implementing DisC-GS or other methods incorporating discontinuous indicator functions into Gaussian Splatting [S1]. Do not use for standard smooth Gaussian Splatting where differentiable rendering is sufficient [S1].

## Background
The method was introduced in **DisC-GS: Discontinuity-aware Gaussian Splatting** by the authors of [S1] in 2024. It addresses the limitation of standard Gaussian Splatting, which relies on differentiable rendering and fails to handle discontinuities natively because the indicator function $g(\cdot)$ is piecewise constant with zero gradients [S1]. The approach is inspired by prior work on gradient approximation for discontinuous functions [S1, Ref 28 in source]. It is used in the context of 3D scene representation learning from source images, specifically for novel view synthesis tasks involving discontinuities [S1].
