# Opacity Decay

Also called: Sigmoid Opacity Decay, Subtractive Opacity Decay

## Overview
Opacity Decay is a regularization step in 3D Gaussian Splatting training that reduces Gaussian opacity to prevent over-saturation and stabilize the optimization landscape [S1, unofficial]. It serves as the core mechanism for gradually pruning low-confidence primitives, building on the smoother pruning approach of [Smooth Opacity Decay](15326-smooth-opacity-decay.md) by applying a controlled reduction to the opacity parameters during training iterations [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Current Gaussian splatting data structure (`splats`), containing an `opacities` tensor (logits), the current learning rate (`lr`), and a strategy configuration (`strategy_name`).
- Output: Updated `splats['opacities']` tensor with reduced opacity values.

**Data Structures:**
- `splats['opacities']`: A 1D tensor of shape $(N,)$ containing the logit-space opacity values for $N$ Gaussians. The actual probability opacity is $\sigma(x) = \frac{1}{1 + e^{-x}}$.

**Parameters:**
- `strategy_name`: String identifier for the decay method. Typical value: `'mrnf'` or other strategy names [S1, unofficial].
- `opacity_decay`: Float multiplier for the decay magnitude. Typical value: Not given in the sources [S1, unofficial].
- `lr`: Current learning rate for the opacity parameter [S1, unofficial].

**Steps:**
1. Retrieve the current opacity logits: `opa = splats['opacities'].data`.
2. If `strategy_name` is `'mrnf'`:
   a. Convert logits to probabilities: `opa_sig = sigmoid(opa)`.
   b. Apply decay factor (implicit in the source as a multiplication, though the specific factor value is not explicitly named, the operation is defined as multiplying by a decay factor): `opa_sig_decayed = opa_sig * decay_factor`. [S1, unofficial]
   c. Convert back to logit space: `opa_new = log(opa_sig_decayed / (1.0 - opa_sig_decayed + 1e-8))`.
   d. Update `splats['opacities'].data = opa_new`.
3. Else if `opacity_decay > 0`:
   a. Subtract the decay amount from the logits: `opa_new = opa - opacity_decay * lr`.
   b. Update `splats['opacities'].data = opa_new`.

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def apply_opacity_decay(splats, strategy_name, opacity_decay, lr, decay_factor=0.9):
    """
    Applies opacity decay to 3D Gaussians.
    
    Args:
        splats: Object containing 'opacities' tensor (logits).
        strategy_name: String, e.g., 'mrnf'.
        opacity_decay: Float, decay multiplier for non-mrnf strategies.
        lr: Float, current learning rate.
        decay_factor: Float, factor to multiply sigmoid opacity by (default 0.9).
        
    Returns:
        Updated splats object.
    """
    opa = splats['opacities'].data.clone()
    
    if strategy_name == 'mrnf':
        # Convert logits to probabilities
        opa_sig = torch.sigmoid(opa)
        
        # Apply decay factor
        # Note: The source [S1, unofficial] mentions multiplying by decay_factor but does not specify
        # where this factor is defined. We assume a standard decay factor like 0.9.
        opa_sig_decayed = opa_sig * decay_factor
        
        # Clip to avoid log(0) or log(1) issues
        opa_sig_decayed = torch.clamp(opa_sig_decayed, min=1e-8, max=1-1e-8)
        
        # Convert back to logits
        opa_new = torch.log(opa_sig_decayed / (1.0 - opa_sig_decayed))
        
        splats['opacities'].data = opa_new
    elif opacity_decay > 0:
        # Direct subtraction from logits
        opa_new = opa - opacity_decay * lr
        splats['opacities'].data = opa_new
        
    return splats
```

**Edge Cases and Pitfalls:**
- **Sigmoid Saturation:** When using the `'mrnf'` strategy, if `opa_sig` is very close to 0 or 1, the logit conversion can result in extreme values or NaNs if not clamped. A small epsilon ($1e-8$) is added to the denominator to prevent division by zero [S1, unofficial].
- **Logit Space vs Probability Space:** The subtraction method operates directly on logits, which is computationally cheaper but may have different convergence properties than probability space decay.
- **Strategy Selection:** The choice between `'mrnf'` and direct subtraction depends on the specific training pipeline configuration [S1, unofficial].

## Subtopics

### Visibility-Aware Decay
A variant of opacity decay that selectively reduces evidence only for sufficiently visible Gaussians to prevent the erosion of occluded primitives [S2, unofficial]. It operates on the evidence tensor $H_{i,j}$ rather than Gaussian opacity logits.
- **Definition:** Decay is applied to evidence $H_{i,j}$ only if the total weight $W^{(t)}_i$ of the Gaussian exceeds a threshold $w_{min}$ [S2, unofficial].
- **Formula:** $H_{i,j} \leftarrow \gamma \cdot H_{i,j}$ if $W^{(t)}_i > w_{min}$, else $H_{i,j}$ [S2, unofficial].
- **Parameters:** $\gamma$ (decay factor, typically 0.95), $w_{min}$ (visibility threshold) [S2, unofficial].
- **Pitfall:** If $0 < W^{(t)}_i \le w_{min}$, no decay occurs. In streams with small, consistent votes, evidence can grow without bound because the state is not uniformly bounded [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ per iteration, where $N$ is the number of Gaussians, as it involves element-wise operations on the opacity tensor [S1, unofficial].
- **Memory Complexity:** $O(N)$ for storing the opacity tensor [S1, unofficial].
- **Strengths:** Prevents over-saturation of Gaussian opacities, leading to more stable training and better final reconstruction quality by pruning low-confidence primitives [S1, unofficial].
- **Limitations:** The choice of strategy (`'mrnf'` vs. direct subtraction) and parameters ($\gamma$, $w_{min}$) can significantly impact convergence speed and final model sparsity [S1, unofficial][S2, unofficial].

## Background
Opacity Decay is a technique used in the training of 3D Gaussian Splatting models, particularly in pipelines that involve densification and pruning strategies. It was introduced as part of the optimization process to manage the opacity parameters of Gaussians, preventing them from becoming too large or too small, which can hinder the learning process [S1, unofficial]. The visibility-aware variant was proposed in the context of open-vocabulary 3D segmentation to handle occlusion and evidence accumulation [S2, unofficial].
