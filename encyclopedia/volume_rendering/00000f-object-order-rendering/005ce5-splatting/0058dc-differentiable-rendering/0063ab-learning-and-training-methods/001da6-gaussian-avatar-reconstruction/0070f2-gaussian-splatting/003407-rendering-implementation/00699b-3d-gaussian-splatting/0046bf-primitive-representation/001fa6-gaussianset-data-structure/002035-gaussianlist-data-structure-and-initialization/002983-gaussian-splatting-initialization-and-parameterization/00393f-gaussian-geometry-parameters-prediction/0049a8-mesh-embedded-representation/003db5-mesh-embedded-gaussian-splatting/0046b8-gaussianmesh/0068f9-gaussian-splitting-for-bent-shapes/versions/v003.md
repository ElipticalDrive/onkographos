# Gaussian Splitting for Bent Shapes

Also called: Bent Gaussian Splitting

## Overview
A procedure to split bent Gaussians into multiple well-formed ellipsoids to approximate non-rigid warping shapes that a single Gaussian cannot represent, preventing visual artifacts [S1, unofficial]. It addresses the limitation where a single transformed Gaussian fails to properly represent bent shapes caused by non-rigid warping, which leads to visual artifacts [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians, each represented by a proxy point cloud $AP_d$ after initial deformation (e.g., cage-based deformation) [S1, unofficial]. The proxy points include the deformed center $c'_d$ and deformed points on the principal axes (e.g., $x'_1, x'_2$ for the x-axis) [S1, unofficial].
*   **Output:** A refined set of Gaussians where bent primitives have been split into multiple smaller, well-formed ellipsoids, ready for MVC (Mean Value Coordinates) transformation [S1, unofficial].

**Data Structures:**
*   **Proxy Point Cloud ($AP_d$):** A set of points representing the Gaussian ellipsoid [S1, unofficial]. For a Gaussian with semi-principal axes $a, b, c$, the proxy points typically include the center and points along the axes at distances proportional to the axis lengths [S1, unofficial].
*   **Gaussian Parameters:** Mean position, covariance matrix (or semi-principal axes $a, b, c$ and orientation), opacity, and color [G].

**Parameters:**
*   **Splitting Threshold:** $175^\circ$ [S1, unofficial]. Splitting is required if the calculated angle falls below this value [S1, unofficial].
*   **Scaling Factor ($k$):** $1/2$ [S1, unofficial]. Although theoretically derived as $(1/2)^{1/3}$, setting $k=1/2$ produces marginally better results [S1, unofficial].
*   **Minimum Axis Length:** $1e-2$ [S1, unofficial]. Axes with lengths below this threshold are not split for numerical stability [S1, unofficial].

**Steps:**
1.  **Identify Bent Gaussians:** For each Gaussian, calculate the angle between vectors from the deformed center $c'_d$ to two deformed points $x'_1$ and $x'_2$ on the same axis (e.g., x-axis) in the deformed point cloud $AP_d$ [S1, unofficial].
    *   Vector 1: $\vec{v}_1 = x'_1 - c'_d$
    *   Vector 2: $\vec{v}_2 = x'_2 - c'_d$
    *   Angle $\theta = \arccos\left(\frac{\vec{v}_1 \cdot \vec{v}_2}{\|\vec{v}_1\| \|\vec{v}_2\|}\right)$ [S1, unofficial].
    *   If $\theta < 175^\circ$, the Gaussian is considered bent and requires splitting on this axis [S1, unofficial].
2.  **Split the Ellipsoid:** Divide the pre-MVC Gaussian ellipsoid into two smaller ellipsoids along the chosen axis [S1, unofficial].
    *   Each new ellipsoid has axis lengths reduced by factor $k$ [S1, unofficial].
    *   Both new ellipsoids are positioned to meet at the center of the original ellipsoid along the splitting axis [S1, unofficial].
    *   Specifically, if splitting along the x-axis with original semi-axis $a$, the new semi-axes are $ka, b, c$ [S1, unofficial]. The centers are shifted by $\pm (a - ka)/2$ along the x-axis relative to the original center [S1, unofficial].
3.  **Apply MVC Transformation:** Apply the MVC transformation again to the resulting two smaller ellipsoids for further processing [S1, unofficial].
4.  **Repeat for All Axes:** Run the identification and splitting process across all axes (x, y, z) to ensure Gaussians requiring splitting on multiple axes are split more than once [S1, unofficial].

**Formulas:**
*   **Volume Preservation Constraint:** The combined volume of two smaller ellipsoids approximates the original volume [S1, unofficial].
    $$ L_V = \frac{2}{3}\pi abc - 2 \cdot \frac{2}{3}\pi (k_1 a)(k_2 b)(k_3 c) \approx 0 $$
    Simplified: $k_1 k_2 k_3 = 1/2$ [S1, unofficial].
*   **Shape Preservation Constraint:** Each smaller ellipsoid maintains shape similar to original [S1, unofficial].
    $$ \frac{k_1}{a} \approx \frac{k_2}{b} \quad \text{and} \quad \frac{k_1}{a} \approx \frac{k_3}{c} $$
    (Constraints ensure shape similarity, leading to $k_1=k_2=k_3$) [S1, unofficial].
*   **Scaling Factor:**
    $$ k_1 = k_2 = k_3 = \sqrt[3]{\frac{1}{2}} $$
    In practice, $k = 1/2$ is used [S1, unofficial].

**Pseudocode:**
```python
import math

def split_bent_gaussians(gaussians, threshold=175.0, k=0.5, min_axis=1e-2):
    """
    Splits bent Gaussians into multiple well-formed ellipsoids.
    
    Args:
        gaussians: List of dicts with keys:
            'center': list of 3 floats
            'axes': list of 3 vectors (each list of 3 floats) representing semi-principal axes
            'proxy_points': list of 3D vectors (center + 2 points per axis)
        threshold: Angle threshold in degrees for splitting (default 175)
        k: Scaling factor for splitting (default 0.5)
        min_axis: Minimum axis length to avoid splitting (default 1e-2)
        
    Returns:
        List of Gaussian dicts (split Gaussians replace originals)
    """
    def dot(v1, v2):
        return v1[0]*v2[0] + v1[1]*v2[1] + v1[2]*v2[2]
    
    def norm(v):
        return math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
    
    def copy_gaussian(g):
        return {
            'center': list(g['center']),
            'axes': [list(a) for a in g['axes']],
            'proxy_points': list(g['proxy_points'])
        }
    
    def get_axis_points(proxy_points, axis_idx):
        # proxy_points[0] is center, proxy_points[1+2*axis_idx] and [2+2*axis_idx] are x1, x2
        return proxy_points[1 + 2*axis_idx], proxy_points[2 + 2*axis_idx]
    
    new_gaussians = []
    
    for g in gaussians:
        split_axes = []
        center = g['center']
        
        for i in range(3):
            p1, p2 = get_axis_points(g['proxy_points'], i)
            if p1 is None or p2 is None:
                continue
                
            v1 = [p1[j] - center[j] for j in range(3)]
            v2 = [p2[j] - center[j] for j in range(3)]
            
            cos_angle = dot(v1, v2) / (norm(v1) * norm(v2))
            cos_angle = max(-1.0, min(1.0, cos_angle))
            angle = math.degrees(math.acos(cos_angle))
            
            if angle < threshold:
                split_axes.append(i)
        
        if not split_axes:
            new_gaussians.append(g)
            continue
            
        # Split sequentially per axis as described: "run across all axes to ensure ... split more than once"
        current_batch = [g]
        for axis_idx in split_axes:
            next_batch = []
            for curr in current_batch:
                original_axis = list(curr['axes'][axis_idx])
                axis_len = norm(original_axis)
                
                if axis_len < min_axis:
                    next_batch.append(curr)
                    continue
                
                # Scale axis by k
                new_axis = [original_axis[j] * k for j in range(3)]
                curr['axes'][axis_idx] = new_axis
                
                # Shift centers to meet at the original center along the splitting axis
                # Shift magnitude is half the difference between original and new axis length
                shift_mag = (axis_len - k * axis_len) / 2.0
                shift = [original_axis[j] * (shift_mag / axis_len) for j in range(3)]
                
                g1 = copy_gaussian(curr)
                g2 = copy_gaussian(curr)
                
                g1['center'] = [curr['center'][j] + shift[j] for j in range(3)]
                g2['center'] = [curr['center'][j] - shift[j] for j in range(3)]
                
                next_batch.append(g1)
                next_batch.append(g2)
            current_batch = next_batch
            
        new_gaussians.extend(current_batch)
        
    return new_gaussians
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of Gaussians and axes checked [G]. Splitting increases the number of Gaussians, potentially doubling the count for heavily bent regions [S1, unofficial].
*   **Memory Complexity:** Increases proportionally to the number of splits [G].
*   **Strengths:** Prevents visual artifacts from non-rigid warping; no architectural changes or retraining needed; can work in real-time with caching [S1, unofficial].
*   **Limitations:** Increases the number of primitives, which may impact rendering performance if many splits occur [G].
*   **When to use:** When deforming 3DGS Gaussians using cage-based deformation or other methods that cause non-rigid warping, leading to bent Gaussians [S1, unofficial].
*   **When not to use:** When deformation is rigid or minimal, as splitting adds unnecessary complexity [G].

## Background
Originated in GSDeformer: Direct Cage-based Deformation for 3D Gaussian Splatting [S1, unofficial]. The method was developed to address artifacts in 3DGS deformation caused by non-rigid warping, where a single Gaussian cannot represent bent shapes [S1, unofficial]. It operates directly on the primitives of 3DGS, allowing integration with other 3DGS variants without retraining [S1, unofficial].
