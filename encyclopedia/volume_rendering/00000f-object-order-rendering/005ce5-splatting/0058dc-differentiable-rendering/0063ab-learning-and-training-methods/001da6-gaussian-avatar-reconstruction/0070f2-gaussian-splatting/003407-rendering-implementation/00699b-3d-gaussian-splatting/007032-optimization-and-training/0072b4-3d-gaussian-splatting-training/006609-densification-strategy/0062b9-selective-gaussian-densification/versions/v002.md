# Selective Gaussian Densification

Also called: Non-steady state densification

## Overview
Selective Gaussian Densification is a training strategy for 3D Gaussian Splatting that classifies primitives into 'steady' and 'non-steady' states to determine if densification is needed, replacing the vanilla 3DGS view-space position gradient threshold with a sum-of-norms metric to avoid redundant Gaussians [S1]. It selectively splits or creates new Gaussians only for non-steady-state Gaussians exhibiting a large magnitude of internal conflicts, while preserving converged steady-state Gaussians to reduce redundant processing and Gaussian count [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The current set of 3D Gaussians $\mathcal{G}$, the accumulated view-space position gradients $\frac{\partial L}{\partial \mu_k}$ for each Gaussian $k$ over the training views, and the threshold $\tau_s$.
*   **Output:** An updated set $\mathcal{G}'$ where non-steady-state Gaussians with high internal conflict are split or cloned, while steady-state Gaussians are preserved.

**Data Structures:**
*   **Gaussian State:** Each Gaussian $g_k$ retains its standard parameters: mean $\mu_k$, covariance $\Sigma_k$ (scale $s_k$, rotation $q_k$), opacity $\alpha_k$, and spherical harmonic coefficients $\mathbf{c}_k$ [Parent].
*   **Gradient Buffer:** For each Gaussian $k$, a scalar metric $S_g$ is maintained, representing the sum of the norms of the view-space position gradients across all views where the Gaussian contributes [S1].

**Step-by-Step Method:**

1.  **Calculate Internal Conflict Metric ($S_g$):**
    For each Gaussian $g_k$, compute the sum of the norms of the view-space position gradients from all pixels $I$ covered by the Gaussian in all views $M$. This metric represents the magnitude of internal conflicts within the Gaussian's footprint [S1].
    $$
    S_g = \frac{1}{|M|} \sum_{I \in M} \left\| \frac{\partial L}{\partial \mu_k} \right\|_2
    $$
    Where:
    *   $M$ is the set of pixels/views covering the Gaussian.
    *   $\frac{\partial L}{\partial \mu_k}$ is the view-space position gradient for the Gaussian with respect to the loss $L$.
    *   $|M|$ is the number of such pixels/views.

2.  **Classify State:**
    Compare $S_g$ against the threshold $\tau_s$ to classify the Gaussian as steady or non-steady [S1]:
    *   If $S_g > \tau_s$, the Gaussian is **non-steady** (high internal conflict, needs refinement).
    *   If $S_g \le \tau_s$, the Gaussian is **steady** (converged, low internal conflict).

3.  **Selective Densification:**
    Only process Gaussians classified as **non-steady** ($S_g > \tau_s$) for densification [S1].
    *   **Decision:** For each non-steady Gaussian, decide whether to **clone** or **split** based on its scale $s_k$, identical to the vanilla 3DGS strategy [S1].
        *   If $s_k$ is large (coarse), **split** the Gaussian into children sampled from $\mathcal{N}(\mu_k, \Sigma_k)$ with reduced scale [Parent].
        *   If $s_k$ is small (fine), **clone** the Gaussian to increase sampling frequency without changing spatial footprint [Parent].
    *   **Preservation:** Gaussians classified as **steady** ($S_g \le \tau_s$) are **not** densified, even if they have non-zero gradients, preventing the creation of redundant primitives [S1].

**Parameters:**
*   $\tau_s$: Threshold to divide steady and non-steady states. Typical value: $0.0007$ [S1].
*   Densification Frequency: Performed periodically (e.g., every 100 iterations) to allow optimizer stabilization [Parent].

**Pseudocode:**
```python
def selective_densification(gaussians, gradients, tau_s=0.0007):
    """
    gaussians: List of Gaussian objects with attributes .mu, .scale, .opacity, etc.
    gradients: Dict mapping gaussian_id to accumulated view-space position gradient vector.
    tau_s: Threshold for steady/non-steady classification.
    """
    to_densify = []
    
    for g in gaussians:
        # Step 1: Calculate S_g (Sum of Norms of Gradients)
        # gradients[g.id] is the accumulated gradient vector over all views/pixels
        grad_vec = gradients[g.id]
        S_g = np.linalg.norm(grad_vec)
        
        # Step 2: Classify State
        if S_g > tau_s:
            # Non-steady state: High internal conflict
            to_densify.append(g)
        else:
            # Steady state: Converged, preserve
            pass
            
    # Step 3: Selective Densification
    new_gaussians = []
    for g in to_densify:
        # Decide clone vs split based on scale (vanilla 3DGS logic)
        if g.scale > threshold_scale:
            # Split: Create children
            children = split_gaussian(g)
            new_gaussians.extend(children)
        else:
            # Clone: Create exact copy
            clone = clone_gaussian(g)
            new_gaussians.append(clone)
            
    # Add steady-state Gaussians unchanged
    for g in gaussians:
        if g not in to_densify:
            new_gaussians.append(g)
            
    return new_gaussians
```

**Edge Cases and Pitfalls:**
*   **Vanilla 3DGS Failure Mode:** Vanilla 3DGS uses the magnitude of the *sum* of view-space position gradients ($E_g$). This fails because a Gaussian can have a near-zero sum gradient (appearing steady due to cancellation) while still having large individual pixel gradients (non-steady), leading to under-densification [S1]. Conversely, it can over-densify steady Gaussians if the threshold is too low [S1]. Selective Densification avoids this by using the *sum of norms* ($S_g$), which does not suffer from vector cancellation [S1].
*   **Threshold Selection:** A too-high $\tau_s$ leads to decreased rendering quality because non-steady Gaussians fail to be densified [S1]. A too-low $\tau_s$ results in excessive densification of steady Gaussians, creating redundancy and straining rendering/training [S1].

## Operating characteristics
*   **Time Complexity:** Reduces training time by avoiding unnecessary densification operations on steady-state Gaussians [S1].
*   **Memory Complexity:** Reduces peak GPU memory overhead and storage requirements due to a lower total Gaussian count [S1].
*   **Performance:** Improves rendering quality and accelerates both training and rendering speeds compared to vanilla 3DGS [S1].
*   **Strengths:** Effectively handles large-scale high-resolution scenes by minimizing redundant primitives [S1].
*   **Limitations:** Requires accurate gradient accumulation; performance depends on the proper tuning of $\tau_s$ [S1].

## Background
Selective Gaussian Densification was proposed in **EfficientGS** (2025) as part of a method to streamline Gaussian Splatting for large-scale high-resolution scene representation [S1]. It addresses the inefficiency of vanilla 3DGS densification, which often generates redundant Gaussians due to the limitations of using the sum of gradients as a convergence metric [S1].
