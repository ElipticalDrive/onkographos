# Surface-Aware Splat Graph Construction

Also called: Manifold-Aware Gaussian Graph Construction, Surface-Aligned Gaussian Connectivity

## Overview
Surface-Aware Splat Graph Construction establishes connectivity exclusively along the surface manifold by defining adjacency as the geometric intersection of Gaussian kernels, filtering out spurious neighbors that are close in Euclidean space but distant along the underlying surface [S1]. It differs from standard nearest-neighbor graphing by using the physical extent of the splats to determine topological links, ensuring the graph respects the 2D surface structure embedded in 3D space [S1].

## How it works
**Inputs:** A set of $N$ Gaussian kernels $\{G_i\}_{i=1}^N$ reconstructed from 2D images using a surface-aligned method (e.g., SpikingGS) [S1].
**Outputs:** A connectivity graph where edges represent surface-adjacent intersections between kernels [S1].

**Data Structures:**
Each kernel $G_i$ is defined by:
- Position $p_i \in \mathbb{R}^3$
- Covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$, factorized as $\Sigma_i = R_i S_i S_i^\top R_i^\top$
  - $R_i = [r_{i,1}, r_{i,2}, r_{i,3}]$ is a rotation matrix (orthonormal basis)
  - $S_i = \text{diag}(\sigma_{i,1}, \sigma_{i,2}, 0)$ is a scale matrix (rank-2)
- Opacity $\alpha_i \in [0, 1]$
- Activation cut-off threshold $\bar{V}_{ip}$ (learnable parameter from SpikingGS) [S1]

**Parameters:**
- $c$: Minimum contribution threshold for rendered intensity. Typical value: $1/255$ [S1].
- $\epsilon$: Tolerance for normal-wise offset to account for minor gaps arising from joint optimization. Value not given in the sources [S1].

**Steps:**

1.  **Define Occupancy Region:** For each kernel $G_i$, define the occupancy region $\Omega_i$ as the set of points $x \in \mathbb{R}^3$ where the kernel is active. A point is active if the Gaussian value exceeds the spiking threshold $\bar{V}_{ip}$ AND the rendered intensity exceeds $c$ [S1]:
    $$
    \Omega_i = \left\{ x \in \mathbb{R}^3 \mid G_i(x) > \max \left( \bar{V}_{ip}, \frac{c}{\alpha_i} \right) \right\}
    $$
    where $G_i(x) = \exp\left( -\frac{1}{2} (x-p_i)^\top \Sigma_i^{-1} (x-p_i) \right)$ [S1].

2.  **Parameterize Ellipse:** Since $\Sigma_i$ is rank-2, $\Omega_i$ forms an ellipse in the plane spanned by $r_{i,1}$ and $r_{i,2}$. Define $\lambda_i$ as:
    $$
    \lambda_i = \sqrt{-2 \max \left( \ln |\bar{V}_{ip}|, \ln \left( \frac{c}{\alpha_i} \right) \right)}
    $$
    The region $\Omega_i$ is parameterized as:
    $$
    \Omega_i = \left\{ p_i + \lambda_i \rho (\sigma_{i,1} \cos \theta \, r_{i,1} + \sigma_{i,2} \sin \theta \, r_{i,2}) \;\middle|\; \rho \in [0, 1), \theta \in (0, 2\pi] \right\}
    $$
    [S1].

3.  **Compute Normal-Wise Offset:** For every pair of kernels $(G_i, G_j)$, compute the normal-wise offset $\delta_{ij}$ from $G_i$ to $G_j$. This is the minimum displacement $t$ along the normal direction of $G_i$ (vector $r_{i,3}$) required to reach the occupancy region of $G_j$:
    $$
    \delta_{ij} := \inf \{ |t| \mid \exists x \in \Omega_i : x + t r_{i,3} \in \Omega_j \}
    $$
    If no such $x$ exists, $\delta_{ij} = +\infty$ [S1].

4.  **Establish Connectivity:** Create an edge between $G_i$ and $G_j$ if $\delta_{ij} < \epsilon$. A zero offset indicates perfect intersection; the tolerance $\epsilon$ accounts for gaps due to optimization artifacts [S1].

**Pseudocode:**

```python
import math
import numpy as np

def compute_occupy_region_params(kernel):
    """
    Computes lambda_i for a single kernel.
    kernel: dict with keys 'p', 'R', 'S', 'alpha', 'V_bar_ip'
    R is 3x3 rotation matrix [r1, r2, r3]
    S is diagonal scale [sigma1, sigma2, 0]
    """
    p = kernel['p']
    R = kernel['R']
    sigma1 = kernel['S'][0]
    sigma2 = kernel['S'][1]
    alpha = kernel['alpha']
    V_bar_ip = kernel['V_bar_ip']
    
    c = 1.0 / 255.0
    
    # Calculate threshold max
    term1 = math.log(abs(V_bar_ip))
    term2 = math.log(c / alpha)
    max_val = max(term1, term2)
    
    # Lambda calculation
    # Note: max_val should be negative for valid log arguments in typical GS contexts
    # If max_val >= 0, lambda is 0 or undefined, implying empty region.
    # Assuming valid inputs where Gaussian values are < 1.
    lambda_i = math.sqrt(-2 * max_val)
    
    return {
        'p': p,
        'R': R,
        'sigma1': sigma1,
        'sigma2': sigma2,
        'lambda': lambda_i
    }

def point_in_ellipse_3d(params, x):
    """
    Checks if point x is inside the parameterized ellipse region Omega_i.
    params: dict from compute_occupy_region_params
    x: numpy array (3,)
    """
    p = params['p']
    R = params['R']
    s1 = params['sigma1']
    s2 = params['sigma2']
    lam = params['lambda']
    
    # Vector from center
    v = x - p
    
    # Project onto local basis vectors r1, r2
    r1 = R[:, 0]
    r2 = R[:, 1]
    
    coord1 = np.dot(v, r1)
    coord2 = np.dot(v, r2)
    
    # Check if (coord1, coord2) is within the scaled ellipse
    # Equation: (u/s1)^2 + (v/s2)^2 <= lambda^2
    # Note: The parameterization uses rho in [0, 1), so max radius is lambda.
    # The ellipse boundary is lambda * sqrt( (u/s1)^2 + (v/s2)^2 ) = lambda ?
    # Actually, the parameterization is: p + lambda * rho * (s1 cos t r1 + s2 sin t r2)
    # So the max extent in direction (cos t, sin t) is lambda * sqrt( (s1 cos t)^2 + (s2 sin t)^2 )
    # Inverse check: (x_proj / (lambda * s1))^2 + (y_proj / (lambda * s2))^2 <= 1 ?
    # Let's use the explicit parameterization inverse.
    # u = coord1, v = coord2
    # We need to find if there exists rho < 1, theta such that:
    # u = lambda * rho * s1 * cos(theta)
    # v = lambda * rho * s2 * sin(theta)
    # => (u / (lambda * s1))^2 + (v / (lambda * s2))^2 = rho^2 <= 1
    
    if lam == 0:
        return False
        
    val = (coord1 / (lam * s1))**2 + (coord2 / (lam * s2))**2
    return val <= 1.0

def compute_normal_offset(params_i, params_j):
    """
    Computes delta_ij: inf |t| such that exists x in Omega_i where x + t * r_i3 is in Omega_j.
    """
    p_i = params_i['p']
    R_i = params_i['R']
    r_i3 = R_i[:, 2] # Normal of i
    
    # This is a complex geometric intersection problem.
    # The source defines it as an infimum.
    # A naive implementation would sample points on the boundary of Omega_i
    # and check distance to Omega_j along r_i3.
    # However, the source implies a direct geometric relationship.
    # Since exact closed-form for infimum is not provided, we approximate
    # or note that this step requires geometric solver.
    
    # For the purpose of this article, we state the definition.
    # Implementation detail: [G] In practice, this is often approximated by
    # checking if the projection of the center of j onto the plane of i
    # falls within the ellipse of i, or by sampling the boundary of Omega_i.
    
    # Placeholder for complex geometric solver not fully detailed in source
    # The source states: delta_ij := inf |t| | exists x in Omega_i : x + t r_i3 in Omega_j
    return 0.0 # Placeholder

def build_splat_graph(kernels, epsilon):
    """
    Builds the surface-aware splat graph.
    """
    N = len(kernels)
    graph = [[] for _ in range(N)]
    
    # Precompute parameters
    params_list = [compute_occupy_region_params(k) for k in kernels]
    
    for i in range(N):
        for j in range(i + 1, N):
            # Compute offset
            # Note: The source defines delta_ij from i to j.
            # Symmetry is not guaranteed if normals differ, but connectivity is usually undirected.
            # We check if delta_ij < epsilon OR delta_ji < epsilon?
            # Source says: "consider two Gaussians to be intersecting if their offset delta_ij falls below a tolerance"
            # It implies checking the specific direction or both. 
            # Given "intersection", it's likely symmetric in intent.
            
            delta_ij = compute_normal_offset(params_list[i], params_list[j])
            
            if delta_ij < epsilon:
                graph[i].append(j)
                graph[j].append(i)
                
    return graph
```

**Edge Cases and Pitfalls:**
- **Rank-2 Covariance:** The method relies on $\Sigma_i$ being rank-2 (planar). If the reconstruction yields non-planar Gaussians, the ellipse parameterization fails [S1].
- **Tolerance $\epsilon$:** Choosing $\epsilon$ is critical. Too small, and gaps from optimization break connectivity; too large, and non-surface neighbors connect [S1].
- **Spiking Threshold:** The method depends on $\bar{V}_{ip}$ being well-calibrated. If $\bar{V}_{ip}$ is too high, the occupancy region shrinks, potentially breaking intersections [S1].

## Operating characteristics
- **Time Complexity:** Building the graph requires checking intersections for all pairs of $N$ kernels, leading to $O(N^2)$ pairwise checks. Each check involves geometric intersection tests between ellipses [S1].
- **Memory Complexity:** Stores the graph adjacency list, $O(N + E)$ where $E$ is the number of edges. The graph is sparse as only surface-adjacent kernels connect [S1].
- **Strengths:** Eliminates spurious connections in noisy or non-manifold reconstructions by enforcing surface proximity [S1]. Enables direct application of Laplacian-based deformation techniques without proxy meshes [S1].
- **Limitations:** Dependent on the quality of the surface-aligned reconstruction (e.g., SpikingGS). If the initial Gaussians are not well-aligned to the surface, the graph may be incorrect [S1]. Requires tuning of tolerance $\epsilon$ [S1].

## Background
The method was introduced in "Proxy-Free Gaussian Splats Deformation with Splat-Based Surface Estimation" (2026) [S1]. It builds on surface-aligned Gaussian Splatting methods like SpikingGS [S1] to enable proxy-free deformation by constructing a Laplacian operator directly on the Gaussian kernels [S1].
