# 3D Gaussian Splatting Training

Also called: 3DGS Learning, G Splats

## Overview
3D Gaussian Splatting Training is the iterative optimization process that adjusts the parameters of a set of 3D Gaussian primitives to minimize the photometric difference between rendered images and ground truth views [S2][S6, unofficial]. It solves the problem of reconstructing a high-fidelity 3D scene from a sparse set of 2D images by optimizing position, rotation, scale, opacity, and appearance (spherical harmonics) [S5, S6, unofficial]. Unlike implicit radiance fields such as NeRF, which require volumetric sampling and neural network inference for every pixel, 3D Gaussian Splatting uses differentiable rasterization of explicit ellipsoids, enabling significantly faster training and real-time rendering speeds [S2][S5, unofficial]. The method relies on adaptive density control to dynamically manage the number and size of Gaussians during optimization [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images (or video frames) with known camera poses (extrinsics $R_{cw}, t_{cw}$ and intrinsics $K$) [S6, unofficial]. Initial 3D Gaussian parameters are derived from Structure from Motion (SfM) point clouds [S2][S6, unofficial].
*   **Outputs:** A set of optimized 3D Gaussian primitives (position $\mathbf{p}$, rotation $q$, scale $\mathbf{s}$, opacity $\alpha$, spherical harmonic coefficients $h$) stored in a format such as PLY [S4, S6, unofficial].

**Data Structures:**
Each Gaussian primitive $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$
*   Rotation $q_i \in \mathbb{R}^4$ (unit quaternion)
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$
*   Opacity $\alpha_i \in [0, 1]$
*   Appearance parameters $h_i$ (Spherical Harmonic coefficients) [Parent]

**Formulas:**
The optimization minimizes a loss function $\mathcal{L}$ between the rendered image $\gamma$ and the ground truth image $\gamma_{gt}$ [S6, unofficial]:
$$
\mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_{D-SSIM}
$$
where $\lambda$ is the SSIM weight (typically 0.2) [S4, S6, unofficial].

The rotation matrix $R$ from a unit quaternion $q = (q_r, q_i, q_j, q_k)$ is computed as [S2]:
$$
R(q) = 2 \begin{bmatrix} \frac{1}{2} - (q_j^2 + q_k^2) & q_i q_j - q_r q_k & q_i q_k + q_r q_j \\ q_i q_j + q_r q_k & \frac{1}{2} - (q_i^2 + q_k^2) & q_j q_k - q_r q_i \\ q_i q_k - q_r q_j & q_j q_k + q_r q_i & \frac{1}{2} - (q_i^2 + q_j^2) \end{bmatrix}
$$

The pixel color $\gamma_j$ is computed via alpha blending of $N$ projected Gaussians sorted by depth [S6, unofficial]:
$$
\gamma_j = \sum_{i \in N} \alpha'_{ij} c_i \tau_{ij}, \quad \text{where } \tau_{ij} = \prod_{k=1}^{i-1} (1 - \alpha'_{kj})
$$
Here, $\alpha'_{ij}$ is the effective opacity, $c_i$ is the color, and $\tau_{ij}$ is the accumulated transmittance [S6, unofficial].

**Parameters:**
*   **numIters:** Total number of optimization steps. Default: 30,000 [S3, S4, unofficial].
*   **sh_degree:** Spherical harmonic degree. Default: 3 [S4, unofficial].
*   **sh_degree_interval:** Steps between increasing SH degree. Default: 1,000 [S4, unofficial].
*   **resolutionSchedule:** Steps between doubling image resolution. Default: 3,000 [S3, S4, unofficial].
*   **densifyFrom:** Step after which densification begins. Default: 500 [S3, unofficial].
*   **densifyUntil:** Step after which densification stops. Default: $\min(15000, \text{numIters} / 2)$ [S3, unofficial].
*   **refineEvery:** Steps between densification/pruning operations. Default: 500 [S3, unofficial].
*   **densify_grad_thresh:** Gradient threshold for densification. Default: 0.0002 [S4, unofficial].
*   **densify_size_thresh:** Size threshold for densification. Default: 0.01 [S4, unofficial].
*   **split_screen_size:** Screen size threshold for splitting. Default: 0.05 [S4, unofficial].
*   **stop_screen_size_at:** Step at which screen-size splitting stops. Default: 4,000 [S4, unofficial].
*   **maxGaussians:** Maximum number of Gaussians. Default: 5,000,000 [S3, unofficial].
*   **bg_color:** Background color. Default: [0.613, 0.010, 0.398] (magenta) [S4, unofficial].

**Steps:**
1.  **Initialization:** Initialize Gaussian positions $\mathbf{p}$ from SfM point clouds in normalized bounds $[-1, 1]$. Initialize scales $\mathbf{s}$ between 0 and 1. Initialize rotations $q$ as unit quaternions and opacities $\alpha$ as constants [S2][S6, unofficial].
2.  **Camera Sampling:** Select a training camera $V$ and its ground truth image $\hat{I}$ using a round-robin strategy with periodic shuffling [S2][S4, unofficial].
3.  **Rendering:** Rasterize the Gaussians using camera $V$ to obtain the rendered image $I$. This involves projecting 3D Gaussians to 2D screen space, sorting by depth, and alpha blending [Parent, S2].
4.  **Loss Computation:** Compute the loss $\mathcal{L}$ between $I$ and $\hat{I}$ using the combined L1 and D-SSIM loss [S2][S6, unofficial].
5.  **Backpropagation:** Compute gradients $\frac{\partial \mathcal{L}}{\partial \theta}$ for all parameters $\theta \in \{\mathbf{p}, q, \mathbf{s}, h, \alpha\}$ using the chain rule [S6, unofficial].
6.  **Optimization Step:** Update parameters using the Adam optimizer [S2][S6, unofficial].
7.  **Adaptive Density Control:** If the current step is a refinement iteration (e.g., every 100 steps or based on `refineEvery`), perform densification and pruning [S2]:
    *   **Pruning:** If opacity $\alpha_i < \epsilon$ or the Gaussian is too large, remove it [S2].
    *   **Densification:** If the positional gradient $\nabla_{\mathbf{p}} \mathcal{L} > \tau_p$:
        *   **Over-reconstruction:** If the covariance norm $\|\mathbf{S}\| > \tau_S$, split the Gaussian into two [S2].
        *   **Under-reconstruction:** Otherwise, clone the Gaussian [S2].
8.  **Resolution Schedule:** Increase image resolution and SH degree according to schedules [S4, unofficial].
9.  **Repeat:** Continue until convergence or `numIters` is reached [S2].

**Pseudocode:**
```python
def train_3dgs(images, cameras, num_iters=30000, sh_degree=3, sh_degree_interval=1000,
               resolution_schedule=3000, densify_from=500, densify_until=15000,
               refine_every=100, densify_grad_thresh=0.0002, densify_size_thresh=0.01,
               split_screen_size=0.05, stop_screen_size_at=4000, max_gaussians=5000000,
               bg_color=[0.613, 0.010, 0.398]):
    # 1. Initialization
    # Initialize positions from SfM in [-1, 1], scales in [0, 1], quaternions as unit, opacities as constants
    gaussians = initialize_gaussians_from_sfm(images)
    
    # Setup camera iterator (round-robin with shuffle)
    cam_indices = list(range(len(cameras)))
    shuffle(cam_indices)
    cam_iter = iter(cam_indices)
    
    step = 1
    while step <= num_iters:
        # 2. Camera Sampling
        try:
            cam_idx = next(cam_iter)
        except StopIteration:
            shuffle(cam_indices)
            cam_iter = iter(cam_indices)
            cam_idx = next(cam_iter)
            
        cam = cameras[cam_idx]
        gt_image = images[cam_idx]
        
        # 3. Rendering
        # Project Gaussians, sort by depth, alpha blend
        rendered_image = rasterize(gaussians, cam, bg_color)
        
        # 4. Loss Computation
        # L = (1 - lambda) * L1 + lambda * L_D-SSIM
        loss = compute_loss(rendered_image, gt_image, ssim_weight=0.2)
        
        # 5. Backpropagation
        gradients = compute_gradients(loss, gaussians, cam)
        
        # 6. Optimization Step
        update_gaussians(gaussians, gradients, optimizer='adam')
        
        # 7. Adaptive Density Control
        if step % refine_every == 0 and densify_from <= step <= densify_until:
            densify_and_prune(gaussians, gradients, 
                              grad_thresh=densify_grad_thresh, 
                              size_thresh=densify_size_thresh,
                              screen_size_thresh=split_screen_size,
                              stop_screen_size_at=stop_screen_size_at,
                              max_gaussians=max_gaussians)
        
        # 8. Resolution and SH Schedule
        current_sh_degree = min(sh_degree, step // sh_degree_interval)
        current_resolution_scale = 2 ** (step // resolution_schedule)
        
        # 9. Advance
        step += 1
        
    return gaussians

def densify_and_prune(gaussians, gradients, grad_thresh, size_thresh, screen_size_thresh, stop_screen_size_at, max_gaussians):
    for g in gaussians:
        # Pruning
        if g.opacity < epsilon or is_too_large(g):
            remove_gaussian(g)
            continue
            
        # Densification
        if norm(g.position_gradient) > grad_thresh:
            if step > stop_screen_size_at and screen_size(g) > screen_size_thresh:
                split_gaussian(g)
            elif norm(g.covariance) > size_thresh:
                split_gaussian(g)
            else:
                clone_gaussian(g)
```

### HUGS
Creates a coarse-to-fine deformation module using linear blend skinning and local learning-based refinement for virtual human avatars [S1]. Utilizes tri-plane representation to factorize canonical space, reconstructing from monocular video (50-100 frames) within 30 minutes at 20 FPS [S1].

### Wolf et al. Stereo Method
Trains a 3DGS to render stereo-calibrated novel views, applies stereo depth estimation, and fuses dense depth maps via Truncated Signed Distance Function (TSDF) to form a triangular mesh [S1].

### Pseudo Ground Truth Acquisition for Gaussians
A labeling pipeline that generates Gaussian-specific pseudo ground truth labels from original point cloud labels, accounting for densification and pruning processes [S8, unofficial].

### Cross-View Pruning Mechanism
Uses a Cross-View Consistency Loss and adaptive pruning to reduce redundancy. Selects adjacent view pairs with SSIM > 0.6, computes loss to penalize residual discrepancies, and prunes based on depth/distance consistency [S9].

### Structure-View Co-learning
Combines structural and view-dependent gradients for robust joint optimization. Loss is $\mathcal{L} = \lambda (\lambda_V \mathcal{L}_V + \lambda_S \mathcal{L}_S)$, where $\mathcal{L}_V$ is view gradient loss and $\mathcal{L}_S$ is structure gradient loss [S9].

### Single-view Mini-batch Strategy
Organizes data per viewpoint and samples mini-batches from only a single viewpoint to improve training efficiency [S10, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is significantly faster than NeRFs, typically completing in minutes to hours depending on scene size and resolution [S2][S5, unofficial]. The original implementation takes approximately 10-20 minutes for standard scenes [S5, unofficial].
*   **Memory Complexity:** Memory usage scales with the number of Gaussians. Default limit is 5,000,000 Gaussians [S3, unofficial]. Sinc splatting variants consume less memory than standard Gaussians [S7].
*   **Performance:** Achieves real-time rendering speeds (30-100+ FPS) on consumer hardware [S5, unofficial]. On the Replica dataset, SGS-SLAM achieves PSNR 34.15, SSIM 0.97, and LPIPS 0.096 [S1].
*   **Hardware:** GPU-accelerated (CUDA/Metal) is standard; CPU execution is ~100x slower [S3, S4, unofficial].
*   **Strengths:** Fast training, real-time rendering, high visual fidelity, explicit representation allows for easy editing [S2][S5, unofficial].
*   **Limitations:** Can produce "floaters" or artifacts in dynamic scenes or with insufficient views; requires careful densification tuning to avoid over-reconstruction [S2][S5, unofficial].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [9]. It builds on the concept of radiance fields but replaces neural networks with explicit 3D Gaussians [S5, unofficial]. The method initializes positions using sparse point clouds from SfM tools like COLMAP [S2][S6, unofficial]. It has since been extended to various domains including SLAM, dynamic scenes, and human avatars [S1].
