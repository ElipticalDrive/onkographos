# Training Loop with Mixed Losses and Post-Processing

Also called: Mixed Loss Training Loop, Post-Processing Training Step

## Overview
This method defines the iterative optimization step for 3D Gaussian Splatting, integrating photometric reconstruction, depth supervision, appearance regularization, and adaptive densification. It distinguishes itself from sibling methods by explicitly managing the progressive activation of spherical harmonic degrees, optional bilateral grid post-processing for view-dependent effects, and visibility-aware optimizer stepping to handle sparse gradients in large scenes [S1, unofficial].

## How it works
**Inputs:**
- Current set of 3D Gaussians $\mathcal{G}$ with parameters: means $\mu$, scales $s$, rotations $q$, opacities $\alpha$, and spherical harmonic coefficients $\mathbf{c}$.
- Camera poses and intrinsics for the current batch of views.
- Ground truth images $I_{gt}$ and optionally depth maps $D_{gt}$.
- Configuration flags: `sh_degree_interval`, `sh_degree`, `depth_loss`, `use_bilateral_grid`, `random_bkgd`, `use_l1_for_real_samples`, `ssim_lambda`, `depth_lambda`, `opacity_reg`, `scale_reg`, `visible_adam`, `packed`, `app_opt`, `save_ply`, `ply_steps`, `max_steps`.
- Strategy object implementing `step_pre_backward` and `step_post_backward`.

**Outputs:**
- Updated Gaussian parameters $\mathcal{G}'$.
- Optimizer states updated.
- Optional PLY file export.

**Data Structures:**
- `splats`: Dictionary or struct containing tensors for `means` ($N \times 3$), `scales` ($N \times 3$), `quats` ($N \times 4$), `opacities` ($N \times 1$), `sh0` ($N \times 3$), `shN` ($N \times C_{SH}$).
- `info`: Dictionary returned by rasterizer containing `radii` ($N \times 1$), `gaussian_ids` (indices of visible Gaussians), `alphas` ($H \times W \times 1$), `renders` ($H \times W \times 3$ or $H \times W \times 4$).
- `bil_grids`: Optional bilateral grid structure if `use_bilateral_grid` is enabled.

**Numbered Steps:**

1.  **Spherical Harmonic Degree Calculation:**
    Determine the active SH degree for the current training step $t$:
    $$ d_{SH} = \min\left(\left\lfloor \frac{t}{\text{cfg.sh\_degree\_interval}} \right\rfloor, \text{cfg.sh\_degree}\right) $$
    This controls the complexity of view-dependent appearance modeling [S1, unofficial].

2.  **Rasterization:**
    Rasterize the current Gaussians $\mathcal{G}$ using the camera parameters.
    - If `cfg.depth_loss` is true, render mode is `'RGB+ED'` (RGB + Estimated Depth), producing a 4-channel output.
    - Otherwise, render mode is `'RGB'`, producing a 3-channel output.
    - Let the output be $R$. Let $A$ be the accumulated alpha channel. Let $I_{info}$ be auxiliary info (radii, gaussian IDs) [S1, unofficial].

3.  **Split Renders:**
    - If $R$ has 4 channels:
      $$ C_{raw} = R[..., 0:3] $$
      $$ D_{raw} = R[..., 3:4] $$
    - Else:
      $$ C_{raw} = R $$
      $$ D_{raw} = \text{None} $$

4.  **Bilateral Grid Post-Processing (Optional):**
    If `cfg.use_bilateral_grid` is true:
    - Compute grid coordinates $G_{xy}$ for the image plane.
    - Apply bilateral grid slicing to $C_{raw}$ using the current bilateral grid parameters $B$:
      $$ C = \text{slice}(B, G_{xy}, C_{raw}, \text{image\_ids})["rgb"] $$
    - Else:
      $$ C = C_{raw} $$
    [S1, unofficial]

5.  **Random Background Composite (Optional):**
    If `cfg.random_bkgd` is true:
    - Sample a random background color $b \sim \text{Uniform}(0, 1)^3$.
    - Composite the foreground render $C$ with the background using the alpha channel $A$:
      $$ C_{final} = C + b \cdot (1.0 - A) $$
    - Else:
      $$ C_{final} = C $$
    [S1, unofficial]

6.  **Pre-Backward Strategy Step:**
    Call `strategy.step_pre_backward(params, optimizers, state, t, I_{info})`. This allows the densification strategy to modify parameters or states before loss computation [S1, unofficial].

7.  **Reconstruction Loss:**
    Identify valid pixels (non-NaN, non-Inf) in ground truth. Let $M_{valid}$ be the mask where `is_nerf_sample` is false (or valid).
    - Compute predicted color $C_{pred}$ (from $C_{final}$) and ground truth $C_{gt}$.
    - Compute L1 or L2 loss $L_{L1/L2}$ based on `cfg.use_l1_for_real_samples`.
    - Compute SSIM loss $L_{SSIM}$ between $C_{pred}$ and $C_{gt}$.
    - Combine:
      $$ L_{recon} = L_{L1/L2} \cdot (1.0 - \text{cfg.ssim\_lambda}) + L_{SSIM} \cdot \text{cfg.ssim\_lambda} $$
    [S1, unofficial]

8.  **Depth Loss (Optional):**
    If `cfg.depth_loss` is true and valid depth data exists:
    - Normalize scene points to $[-1, 1]$ range.
    - Sample predicted depths $D_{pred}$ from the rendered depth map using `F.grid_sample` with the normalized 2D coordinates of the ground truth depth points.
    - Compute disparity:
      $$ \text{disp}_{pred} = \frac{1.0}{D_{pred}} \quad \text{where } D_{pred} > 0 $$
      $$ \text{disp}_{gt} = \frac{1.0}{D_{gt}} $$
    - Compute L1 loss on disparity:
      $$ L_{depth} = \text{L1Loss}(\text{disp}_{pred}, \text{disp}_{gt}) \cdot \text{scene\_scale} $$
    - Add to total loss:
      $$ L_{total} = L_{recon} + L_{depth} \cdot \text{cfg.depth\_lambda} $$
    - Else:
      $$ L_{total} = L_{recon} $$
    [S1, unofficial]

9.  **Bilateral Grid Total Variation (Optional):**
    If `cfg.use_bilateral_grid` is true:
    - Compute total variation loss on the bilateral grid parameters $B$:
      $$ L_{TV} = 10 \cdot \text{TotalVariation}(B) $$
    - Add to total loss:
      $$ L_{total} \leftarrow L_{total} + L_{TV} $$
    [S1, unofficial]

10. **Opacity Regularization (Optional):**
    If `cfg.opacity_reg > 0.0`:
    - Compute mean sigmoid of raw opacities:
      $$ \bar{\alpha} = \text{Mean}(\sigma(\alpha_{raw})) $$
    - Add to loss:
      $$ L_{total} \leftarrow L_{total} + \text{cfg.opacity\_reg} \cdot \bar{\alpha} $$
    [S1, unofficial]

11. **Scale Regularization (Optional):**
    If `cfg.scale_reg > 0.0`:
    - Compute mean exponential of raw scales:
      $$ \bar{s} = \text{Mean}(\exp(s_{raw})) $$
    - Add to loss:
      $$ L_{total} \leftarrow L_{total} + \text{cfg.scale\_reg} \cdot \bar{s} $$
    [S1, unofficial]

12. **Backward Pass:**
    - Call `L_total.backward()`.
    [S1, unofficial]

13. **Visibility Mask Calculation (Optional):**
    If `cfg.visible_adam` is true:
    - If `cfg.packed` is true:
      - Create a zero tensor of shape equal to the number of opacities.
      - Scatter 1s at indices specified by `info["gaussian_ids"]`.
    - Else:
      - Compute mask where `info["radii"] > 0` for any pixel.
    [S1, unofficial]

14. **Optimizer Step:**
    - If `cfg.visible_adam` is true:
      - Pass `visibility_mask` to `optimizer.step(visibility_mask)`.
    - Else:
      - Call `optimizer.step()`.
    - Zero gradients with `set_to_none=True`.
    [S1, unofficial]

15. **Pose and Bilateral Grid Optimization:**
    - Step `pose_optimizers` and `bil_grid_optimizers` if they exist.
    - Zero their gradients.
    [S1, unofficial]

16. **Scheduler Step:**
    - Step all learning rate schedulers.
    [S1, unofficial]

17. **Post-Backward Strategy Step:**
    - Call `strategy.step_post_backward`.
    - If `DefaultStrategy`: pass `packed=cfg.packed`.
    - If `MCMCStrategy`: pass `lr=schedulers[0].get_last_lr()[0]`.
    [S1, unofficial]

18. **PLY Export (Optional):**
    If `step` is in `cfg.ply_steps` or `step == max_steps - 1` and `cfg.save_ply`:
    - If `cfg.app_opt` is true:
      - Bake appearance: Evaluate `app_module` at origin (directions = zeros).
      - Add `self.splats["colors"]`.
      - Apply sigmoid.
      - Convert to SH0.
      - Create empty SHN.
    - Else:
      - Use `self.splats["sh0"]` and `self.splats["shN"]`.
    - Export splats with means, scales, quats, opacities, sh0, shN.
    [S1, unofficial]

**Pseudocode:**

```python
def training_step(step, splats, cameras, gt_images, gt_depths, cfg, strategy, optimizer, pose_optimizer, bil_grid_optimizer, schedulers, scene_scale):
    # 1. SH Degree
    sh_degree_to_use = min(step // cfg.sh_degree_interval, cfg.sh_degree)

    # 2. Rasterize
    render_mode = 'RGB+ED' if cfg.depth_loss else 'RGB'
    renders, alphas, info = rasterize(splats, cameras, render_mode=render_mode)

    # 3. Split Renders
    if renders.shape[-1] == 4:
        colors_raw = renders[..., 0:3]
        depths_raw = renders[..., 3:4]
    else:
        colors_raw = renders
        depths_raw = None

    # 4. Bilateral Grid
    if cfg.use_bilateral_grid:
        grid_xy = compute_grid_coordinates()
        colors = slice_bilateral_grid(cfg.bil_grids, grid_xy, colors_raw, cameras.image_ids)["rgb"]
    else:
        colors = colors_raw

    # 5. Random Background
    if cfg.random_bkgd:
        bkgd = torch.rand(1, 3, device=colors.device)
        colors = colors + bkgd * (1.0 - alphas)

    # 6. Pre-Backward
    strategy.step_pre_backward(splats, optimizer, {}, step, info)

    # 7. Reconstruction Loss
    valid_mask = ~torch.isnan(gt_images).any(dim=-1) # Simplified mask logic
    if valid_mask.any():
        pred_color = colors[valid_mask]
        gt_color = gt_images[valid_mask]
        l1_loss = F.l1_loss(pred_color, gt_color) if cfg.use_l1_for_real_samples else F.mse_loss(pred_color, gt_color)
        ssim_loss = ssim_loss_function(pred_color, gt_color)
        loss = l1_loss * (1.0 - cfg.ssim_lambda) + ssim_loss * cfg.ssim_lambda
    else:
        loss = torch.tensor(0.0, device=colors.device)

    # 8. Depth Loss
    if cfg.depth_loss and depths_raw is not None and gt_depths is not None:
        # Normalize and sample depths
        # Note: Exact normalization depends on scene bounds, assumed handled by scene_scale
        disp_pred = 1.0 / (depths_raw + 1e-6)
        disp_gt = 1.0 / (gt_depths + 1e-6)
        depth_loss = F.l1_loss(disp_pred, disp_gt) * scene_scale
        loss = loss + depth_loss * cfg.depth_lambda

    # 9. Bilateral Grid TV
    if cfg.use_bilateral_grid:
        tv_loss = 10 * total_variation(cfg.bil_grids.grids)
        loss = loss + tv_loss

    # 10. Opacity Reg
    if cfg.opacity_reg > 0.0:
        opacity_reg = cfg.opacity_reg * torch.sigmoid(splats["opacities"]).mean()
        loss = loss + opacity_reg

    # 11. Scale Reg
    if cfg.scale_reg > 0.0:
        scale_reg = cfg.scale_reg * torch.exp(splats["scales"]).mean()
        loss = loss + scale_reg

    # 12. Backward
    loss.backward()

    # 13. Visibility Mask
    visibility_mask = None
    if cfg.visible_adam:
        if cfg.packed:
            visibility_mask = torch.zeros_like(splats["opacities"])
            visibility_mask.scatter_(0, info["gaussian_ids"], 1.0)
        else:
            visibility_mask = (info["radii"] > 0).any(dim=0)

    # 14. Optimizer Step
    if cfg.visible_adam:
        optimizer.step(visibility_mask)
    else:
        optimizer.step()
    optimizer.zero_grad(set_to_none=True)

    # 15. Pose and Bil Grid Step
    if pose_optimizer:
        pose_optimizer.step()
        pose_optimizer.zero_grad(set_to_none=True)
    if bil_grid_optimizer:
        bil_grid_optimizer.step()
        bil_grid_optimizer.zero_grad(set_to_none=True)

    # 16. Scheduler Step
    for scheduler in schedulers:
        scheduler.step()

    # 17. Post-Backward
    if isinstance(strategy, DefaultStrategy):
        strategy.step_post_backward(packed=cfg.packed)
    elif isinstance(strategy, MCMCStrategy):
        current_lr = schedulers[0].get_last_lr()[0]
        strategy.step_post_backward(lr=current_lr)

    # 18. PLY Export
    if cfg.save_ply and (step in cfg.ply_steps or step == cfg.max_steps - 1):
        if cfg.app_opt:
            # Bake appearance
            dirs = torch.zeros_like(cameras.directions)
            baked_colors = cfg.app_module(dirs)
            final_colors = torch.sigmoid(baked_colors + splats["colors"])
            sh0 = final_colors
            shN = torch.zeros_like(sh0) # Empty SHN
        else:
            sh0 = splats["sh0"]
            shN = splats["shN"]
        
        export_ply(
            means=splats["means"],
            scales=splats["scales"],
            quats=splats["quats"],
            opacities=splats["opacities"],
            sh0=sh0,
            shN=shN,
            filename=f"step_{step}.ply"
        )
```

**Edge Cases and Pitfalls:**
- **Depth Division by Zero:** When computing disparity $1/D$, ensure $D > 0$ or add a small epsilon to avoid NaNs [S1, unofficial].
- **Visibility Mask Shape:** If `cfg.packed` is true, the visibility mask must be created with the correct size corresponding to the packed Gaussian indices, not the image dimensions [S1, unofficial].
- **SH Degree Progression:** If `sh_degree_interval` is 0, division by zero occurs. It must be $>0$ [S1, unofficial].
- **Bilateral Grid Slicing:** The `slice` function must correctly handle the expansion of `grid_xy` to match the batch/image dimensions [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by rasterization $O(N \cdot H \cdot W)$ and backward pass. SH degree increase adds $O(N \cdot d_{SH}^2)$ to gradient computation.
- **Memory Complexity:** $O(N \cdot d_{SH}^2)$ for SH coefficients. Bilateral grid adds $O(H \cdot W \cdot C_{grid})$.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with number of Gaussians $N$ and image resolution $H \cdot W$.
- **Strengths:** Explicit SH degree progression balances quality and speed. Visibility-aware Adam reduces memory and computation for sparse scenes. Bilateral grid enhances view-dependent effects.
- **Limitations:** Requires careful tuning of regularization weights. Depth loss requires accurate ground truth depth.
- **When to Use:** Standard 3D Gaussian Splatting training with optional depth and appearance enhancements.
- **When Not to Use:** When computational resources are extremely limited and SH degree progression is too costly.
