# Gaussian Representation and Truncation

Also called: 3D Gaussian Splatting Primitives, 3DGS Representation

## Overview
This article defines the fundamental data structure and rendering primitives used in 3D Gaussian Splatting (3DGS) and its variants. It specifies how a scene is represented as a set of $N$ learnable 3D Gaussians, detailing the parameters (position, rotation, scale, opacity, color), the construction of the covariance matrix, and the projection to 2D for rasterization. It also defines the standard truncation logic used to optimize rendering speed by discarding fragments with negligible contribution. This representation serves as the foundation for all sibling methods in the [Scene Representation and Geometry Constraints](15421-scene-representation-and-geometry-constraints.md) family and the child methods listed below.

## Shared principles
All methods in this family operate on a set of $N$ 3D Gaussian primitives. Each primitive $i$ is defined by learnable parameters describing its geometry, appearance, and position.

**Data Structure:**
Each Gaussian $g_i$ is represented by the following attributes [S1]:
*   **Position ($\mu_i$):** A 3D vector $\mathbb{R}^3$ representing the centroid in world space.
*   **Rotation ($q_i$):** A unit quaternion $\mathbb{R}^4$ representing orientation.
*   **Scale ($s_i$):** A 3D vector $\mathbb{R}^3$ representing anisotropic scaling factors along principal axes.
*   **Opacity ($\omega_i$):** A scalar $\mathbb{R} \in [0, 1]$ representing maximum opacity.
*   **Color ($c_i$):** Represented by Spherical Harmonic (SH) coefficients (typically degree 3, 48 coefficients for RGB) for view-dependent appearance.

**Covariance Matrix:**
The spatial spread is defined by a 3D covariance matrix $\Sigma_i$, constructed from scale and rotation:
$$ \Sigma_i = R_i S_i S_i^T R_i^T $$
where $S_i = \text{diag}(s_i)$ is the scaling matrix and $R_i$ is the rotation matrix derived from $q_i$ [S1].

**Projection to 2D:**
During rendering, the 3D covariance $\Sigma_i$ is projected to the 2D image plane using the Jacobian $J$ of the affine approximation of the projective transformation:
$$ \Sigma' = J \Sigma_i J^T $$
The relevant part for rasterization is the top-left $2 \times 2$ submatrix $\Sigma'_{2 \times 2}$ [S1].

**Spatial Response (Kernel Function):**
The contribution of a Gaussian to a pixel at screen coordinates $x$ is determined by:
$$ R(x) = \exp\left(-\frac{1}{2} (x - \mu')^T (\Sigma'_{2 \times 2})^{-1} (x - \mu')\right) $$
where $\mu'$ is the projected 2D mean [S1].

**Alpha Compositing:**
The final opacity $\alpha$ contributed by a Gaussian is:
$$ \alpha = \omega_i \cdot R(x) $$
The pixel color is computed via alpha blending with primitives sorted back-to-front:
$$ C_{pixel} = \sum_i T_i \alpha_i C_i, \quad T_i = \prod_{j < i} (1 - \alpha_j) $$
where $C_i$ is evaluated using SH coefficients based on view direction [S1].

**Truncation:**
To optimize speed, fragments are discarded if $\alpha < \tau_\alpha$ (typically $1/255$), limiting rendering to a region of approximately $3.33\sigma$ [S1].

**Density Estimation for Mesh Extraction:**
The scene density $\sigma(\mathbf{x})$ is the superposition of Gaussian contributions:
$$ \sigma(\mathbf{x}) = \sum_{i=1}^{N} \alpha_i \exp\left(-\frac{1}{2} (\mathbf{x} - \mathbf{p}_i)^T \Sigma_i^{-1} (\mathbf{x} - \mathbf{p}_i)\right) $$
where $\alpha_i$ is opacity, $\mathbf{p}_i$ is the mean, and $\Sigma_i$ is the covariance [S1].

## Subtopics

### [Inverse Multiquadric Splatting](9910-inverse-multiquadric-splatting.md)
Replaces the Gaussian radial basis function with an inverse multiquadric function to reduce artifacts in high-density regions.

### [Opacity-Independent Gaussian Truncation](10266-opacity-independent-gaussian-truncation.md)
Modifies truncation logic to check spatial response $R(x)$ independently of opacity, allowing truncation at fewer standard deviations.

### [Content-Aware Texturing for Gaussian Splatting](12606-content-aware-texturing-for-gaussian-splatting.md)
Augments primitives with spatially varying texture maps to capture high-frequency details beyond SH capabilities.

### [Directed Distance Field (DDF) for Gaussian Splatting](12854-directed-distance-field-ddf-for-gaussian-splatting.md)
Uses a neural implicit representation as a constant-time ray oracle for secondary rays, replacing explicit Gaussian traversal.

### [Atomized Proliferation](12924-atomized-proliferation.md)
Constrains fine-detail Gaussians to isotropic "Atom Gaussians" and guides proliferation to align with scene geometry.

### [Pruning and Reduction](14909-pruning-and-reduction.md)
Methods to decrease the number of primitives for efficiency, including POG, AtomGS, View-Dependent Opacity Kernel, and GS-IR.

### POG (Potentially Over-large Gaussians)
POG is a pruning strategy that identifies and removes potentially over-large Gaussians to reduce redundancy. In ablation studies on Tanks&Temples, POG yields PSNR 26.26, SSIM 0.879, LPIPS 0.121, whereas Hard Gaussian (HG) yields PSNR 26.36, SSIM 0.880, LPIPS 0.126 [S1]. POG improves LPIPS slightly but degrades PSNR significantly because it causes overgrowth in already learned areas, making them susceptible to redundant Gaussians [S1].

### AtomGS
AtomGS introduces Atomized Proliferation, which constrains ellipsoid Gaussians of various sizes into uniformly-sized Atom Gaussians to enhance fine feature representation [S2, unofficial]. It retains larger anisotropic Gaussians for backgrounds while smaller ones become Atom Gaussians [S2, unofficial]. It also uses Geometry-Guided Optimization with an Edge-Aware Normal Loss to smooth flat surfaces and preserve details [S2, unofficial]. During pruning, it merges Gaussians covering large, less detailed surfaces, reducing the total count while maintaining quality [S2, unofficial]. Unlike standard 3DGS, it provides precise guidance for 3D geometry optimization [S2, unofficial].

### View-Dependent Opacity Kernel
This method models view-dependent opacity using a half-period cosine function to approximate specular reflectance lobes, adding 5 learnable parameters to the standard configuration [S3, unofficial]. The opacity is defined as:
$$ \hat{\alpha}(\theta, \beta, T, \alpha) = \alpha \cdot \frac{\cos(\max(0, \min(\frac{2\theta}{T}, \pi)))+1}{2}\exp(\beta) $$
where $\alpha$ is base opacity, $\theta$ is the angle between view direction and lobe orientation, $T$ controls angular span, and $\beta$ modulates sharpness [S3, unofficial]. $T$ is initialized as $c\bar{\theta}_i/\pi$ and $\beta$ to zero [S3, unofficial]. As $\theta$ increases, transparency diminishes to zero, preventing artifacts outside the lobe's influence [S3, unofficial].

### GS-IR Representation
GS-IR extends the vanilla 3DGS representation by adding a normal vector $n$ and material properties $M=\{a, \rho, m\}$ (albedo, roughness, metallicity) to the geometric parameters $T=\{p, s, q, n\}$ and appearance parameters $A=\{\alpha, f_c\}$ [S4]. It uses an initial stage to optimize geometry and appearance, followed by a decomposition stage to optimize material properties [S4].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [S1]. It represents scenes as a set of 3D Gaussians optimized via differentiable rasterization. The representation allows for real-time rendering and high-quality novel view synthesis. The standard truncation threshold of $1/255$ corresponds to approximately $3.33$ standard deviations [S1]. Subsequent works have modified this representation to address artifacts, improve geometry, or enhance rendering efficiency.
