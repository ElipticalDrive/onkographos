# SpacetimeGaussians Training Pipeline


## Overview
The SpacetimeGaussians Training Pipeline is the optimization procedure for reconstructing dynamic 3D scenes using 3D Gaussian Splatting, specifically designed to handle temporal dynamics through spacetime feature encoding [S1, unofficial]. It differs from static 3D Gaussian Splatting by incorporating time-dependent parameters and a specialized densification schedule that freezes motion parameters after an initial learning phase to stabilize the representation [S1, unofficial]. Unlike sibling methods such as [Deformable 3D Gaussians](16260-deformable-3d-gaussians.md) which rely on deformation fields, or [Spacetime Gaussian Feature Splatting](16313-spacetime-gaussian-feature-splatting.md) which uses a different feature encoding strategy, this pipeline explicitly manages the lifecycle of Gaussian primitives (creation, splitting, pruning, and freezing) based on iteration-specific thresholds and visibility metrics [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   Dataset containing multi-view video frames and camera poses.
*   Initial Gaussian model parameters (position, covariance, opacity, SH coefficients) initialized from SfM point clouds [S1, unofficial].
*   Training options: `densify` mode (0-3), `reg` type (1, 4, 6, 7, 8, 9, 10), `opt.lambda_dssim`, `opt.regl`, `opt.densify_from_iter`, `opt.densify_until_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, `opt.opthr` [S1, unofficial].

**Outputs:**
*   Optimized Gaussian parameters (xyz, rotation, scaling, opacity, SH coefficients, and motion parameters $\omega$) representing the dynamic scene.
*   Trained background color tensor and RGB decoder (if enabled) [S1, unofficial].

### Data Structures
*   **Gaussian Model (`gaussians`):** Contains tensors for position (`_xyz`), rotation (`_rotation`), scaling (`_scaling`), opacity (`_opacity`), SH coefficients (`_features_dc`, `_features_rest`), and motion parameters (`_omega`) [S1, unofficial].
*   **Time Tensor (`gaussians.ts`):** Shape `(1, 1, H, W)`, dtype `torch.float32`, device `cuda`. Initialized to ones if not provided, representing the time coordinate for each pixel [S1, unofficial].
*   **Background Tensor (`background`):** Shape `(numchannels,)`, dtype `torch.float32`, device `cuda`. Initialized to zeros. `numchannels` defaults to 9 [S1, unofficial].
*   **Omega Mask (`gaussians.omegamask`):** Boolean tensor used to freeze motion parameters for specific Gaussians after iteration 8001 [S1, unofficial].

### Pseudocode

```python
def train_spacetime_gaussians(dataset, opt, iteration=0):
    """
    Main training loop for SpacetimeGaussians.
    """
    # 1. Initialization
    gaussians = getmodel(dataset.model) # Initialize with SH degree and RGB function
    scene = Scene(dataset, gaussians, load_iteration=iteration, shuffle=False, 
                  multiview=multiview, duration=duration, loader=loader)
    
    # Initialize background color
    numchannels = 9
    background = torch.zeros(numchannels, dtype=torch.float32, device='cuda')
    
    # Initialize time tensor if not present
    if gaussians.ts is None:
        H, W = scene.cameras[0].image_height, scene.cameras[0].image_width
        gaussians.ts = torch.ones((1, 1, H, W), dtype=torch.float32, device='cuda')
    
    # Select rendering pipeline
    option = opt.render_option # e.g., 'train_ours_full', 'train_ours_lite'
    train_func, GaussianRasterizationSettings, GaussianRasterizer = getrenderpip(option)
    
    # Setup RGB decoder if used
    if gaussians.rgbdecoder is not None:
        gaussians.rgbdecoder.to('cuda')
        gaussians.rgbdecoder.eval()

    # 2. Training Loop
    for iteration in range(opt.iterations):
        
        # A. Densification and Pruning Logic
        if opt.densify == 1: # n3d mode
            # Freeze motion parameters at iteration 8001
            if iteration == 8001:
                omegamask = gaussians.zero_omegabymotion()
                gaussians.omegamask = omegamask
            
            # Freeze weights based on mask for iterations > 8001
            if iteration > 8001:
                freezweightsbymasknounsqueeze(gaussians._omega, omegamask)
                freezweightsbymasknounsqueeze(gaussians._rotation, ~omegamask)
            
            # Densification steps
            if (iteration > opt.densify_from_iter and 
                iteration % opt.densification_interval == 0 and 
                flag < opt.desicnt):
                
                size_threshold = 20 if iteration > opt.opacity_reset_interval else None
                gaussians.densify_pruneclone(
                    opt.densify_grad_threshold, 
                    opt.opthr, 
                    scene.cameras_extent, 
                    size_threshold
                )
            
            # Pruning based on opacity
            if flag >= opt.desicnt and iteration < 7000:
                gaussians.prune(opthr=opt.opthr)
            
            # Reset opacity periodically
            if iteration % 3000 == 0:
                gaussians.reset_opacity()
            
            # Final freezing and Z-pruning
            if iteration >= opt.densify_until_iter:
                freezweightsbymasknounsqueeze(gaussians._omega, torch.ones_like(gaussians._omega, dtype=torch.bool))
                freezweightsbymasknounsqueeze(gaussians._rotation, torch.zeros_like(gaussians._rotation, dtype=torch.bool))
                
                if iteration % 1000 == 500:
                    # Prune points below Z=4.5
                    mask = gaussians._xyz[:, 2] < 4.5
                    gaussians.prune_by_mask(mask)
        
        elif opt.densify == 3:
            # Update densification stats every iteration
            update_max_radii2D_and_add_densification_stats(gaussians)
            
            # Densify/prune clones at intervals
            if iteration % opt.densification_interval == 0:
                gaussians.densify_pruneclone(...)
            
            # Prune low opacity if early stage
            if iteration < 7000:
                gaussians.prune(opthr=opt.opthr)
            
            # Reset opacity
            if iteration % opt.opacity_reset_interval == 0:
                gaussians.reset_opacity()
            
            # Remove min/max at 10000
            if iteration == 10000:
                gaussians.removeminmax()

        # B. Rendering and Loss Calculation
        # Render image using selected pipeline
        # Inputs: gaussians, scene, background, scaling_modifier=1.0, basicfunction=trbfunction
        rendered_image = train_func(gaussians, scene, background, 
                                    scaling_modifier=1.0, basicfunction=trbfunction)
        
        # Calculate Loss based on opt.reg
        L1_loss = calculate_l1_loss(rendered_image, gt_image)
        SSIM_loss = 1 - calculate_ssim(rendered_image, gt_image)
        
        if opt.reg == 1:
            # L1 + D-SSIM + Motion Gradient Sum
            L = (1 - opt.lambda_dssim) * L1_loss + \
                opt.lambda_dssim * SSIM_loss + \
                opt.regl * (torch.sum(gaussians._motion_gradients) / N)
        elif opt.reg == 9:
            # L1 + D-SSIM + Omega Gradient Squared Sum
            L = (1 - opt.lambda_dssim) * L1_loss + \
                opt.lambda_dssim * SSIM_loss + \
                opt.regl * torch.sum(gaussians._omega_gradients ** 2)
        elif opt.reg == 10:
            # L1 + D-SSIM + Motion Gradient Squared Sum
            L = (1 - opt.lambda_dssim) * L1_loss + \
                opt.lambda_dssim * SSIM_loss + \
                opt.regl * torch.sum(gaussians._motion_gradients ** 2)
        elif opt.reg == 4:
            # L1 + D-SSIM + Scaling Gradient Sum
            L = (1 - opt.lambda_dssim) * L1_loss + \
                opt.lambda_dssim * SSIM_loss + \
                opt.regl * (torch.sum(gaussians._scaling_gradients) / N)
        elif opt.reg == 6:
            # Adaptive D-SSIM weight
            r = clamp(torch.mean(gt_image) - 0.5 + opt.lambda_dssim, 0, 1)
            L = (1 - r) * L1_loss + r * SSIM_loss
        elif opt.reg == 7:
            # Normalized L1
            L1_loss = L1_loss / (2 * torch.mean(gt_image))
            L = (1 - opt.lambda_dssim) * L1_loss + opt.lambda_dssim * SSIM_loss
        elif opt.reg == 8:
            # L1 + D-SSIM + Position Variance
            L = (1 - opt.lambda_dssim) * L1_loss + \
                0.0002 * opt.lambda_dssim * (torch.sum((gaussians._xyz_mean - gaussians._xyz) ** 2) / N)
        else:
            L = (1 - opt.lambda_dssim) * L1_loss + opt.lambda_dssim * SSIM_loss

        # C. Optimization Step
        L.backward()
        optimizer.step()
        optimizer.zero_grad()
        
        # Update iteration counters and flags
        iteration += 1
        update_flag_if_needed()
```

### Parameters
*   `numchannels`: Number of channels for background color and RGB decoder output. Default: 9 [S1, unofficial].
*   `scaling_modifier`: Passed to the render function. Default: 1.0 [S1, unofficial].
*   `basicfunction`: Passed to the render function. Default: `trbfunction` [S1, unofficial].
*   `GRsetting` and `GRzer`: Retrieved from `getrenderpip`, used for rasterization settings [S1, unofficial].
*   `opt.densify_from_iter`: Iteration at which densification begins [S1, unofficial].
*   `opt.densify_until_iter`: Iteration at which densification stops and parameters are frozen [S1, unofficial].
*   `opt.densification_interval`: Interval between densification steps [S1, unofficial].
*   `opt.opacity_reset_interval`: Interval for resetting opacity [S1, unofficial].
*   `opt.desicnt`: Counter for densification attempts [S1, unofficial].
*   `opt.densify_grad_threshold`: Gradient threshold for densification [S1, unofficial].
*   `opt.opthr`: Opacity threshold for pruning [S1, unofficial].

### Edge Cases and Pitfalls
*   **RGB Decoder:** If `gaussians.rgbdecoder` is not None, it must be moved to CUDA and set to `eval` mode before rendering to prevent gradient issues or device mismatches [S1, unofficial].
*   **Pruning Logic:** Pruning behavior changes dynamically. Before `opt.desicnt` is reached, densification is prioritized. After `opt.desicnt`, pruning is based on opacity if `iteration < 7000`. After `opt.densify_until_iter`, pruning is based on Z-coordinate (`_xyz[:,2] < 4.5`) if `iteration % 1000 == 500` [S1, unofficial].
*   **Time Tensor:** If `gaussians.ts` is not provided, it must be initialized as a tensor of ones with shape `(1, 1, H, W)` on CUDA, where H and W are derived from the first test camera [S1, unofficial].

## Subtopics

### SpacetimeGaussians Densification & Pruning Schedule
A training iteration schedule that controls Gaussian densification, pruning, and parameter freezing based on iteration count, mode selection, and visibility metrics [S1, unofficial].
*   **Mode Selection:** Controlled by the `densify` parameter (0, 1, 2, or 3).
*   **Mode 1 (n3d):** Prunes points where `gaussians._xyz[:,2] < 4.5` at iteration 1000 and resets opacity every 3000 iterations [S1, unofficial].
*   **Mode 3:** Updates `max_radii2D` and `add_densification_stats` every iteration. Performs densification/pruning clones at intervals. Prunes low-opacity points if `iteration < 7000`. Resets opacity every `opt.opacity_reset_interval`. Calls `removeminmax` at iteration 10000 [S1, unofficial].
*   **Parameters:** `size_threshold` is set to 20 if `iteration > opt.opacity_reset_interval`, otherwise `None`. Other thresholds include `opt.densify_until_iter`, `opt.densify_from_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, and `opt.opthr` [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources for the base SpacetimeGaussians pipeline. Note that related streaming methods like GIFStream achieve 89.75 rFPS on N3DV flame_steak with offline optimization [S4], and IGS achieves 126.74 rFPS with online updates [S4], but these are distinct methods.
*   **Strengths:** Explicit control over the lifecycle of Gaussians via densification modes; ability to freeze motion parameters to stabilize training; support for various regularization terms (reg=1, 4, 6, 7, 8, 9, 10) to handle different scene properties [S1, unofficial].
*   **Limitations:** Complex hyperparameter tuning required for densification schedules (`opt.densify_from_iter`, `opt.desicnt`, etc.); pruning logic is iteration-dependent and may require scene-specific adjustments (e.g., Z-coordinate threshold) [S1, unofficial].
*   **When to use:** When reconstructing dynamic scenes with significant motion where static Gaussian Splatting fails, and when explicit control over Gaussian density and motion parameter stability is required [S1, unofficial].
*   **When not to use:** For static scenes where standard 3D Gaussian Splatting is sufficient; for real-time streaming applications requiring lower latency than the offline optimization of this pipeline might allow (though the pipeline itself is for training) [S1, unofficial][S4].

## Background
The SpacetimeGaussians Training Pipeline originates from the paper "Spacetime Gaussian Feature Splatting for Real-Time Dynamic View Synthesis" by Li et al., presented at CVPR 2024 [S1, unofficial]. It builds upon the 3D Gaussian Splatting framework [G] and extends it to handle dynamic scenes by incorporating time-dependent features and a specialized training schedule. The method was developed by researchers at OPPO US Research [S1, unofficial]. It is used for real-time dynamic view synthesis, allowing for the reconstruction and rendering of dynamic 3D scenes from multi-view video inputs [S1, unofficial].
