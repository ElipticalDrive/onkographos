# Smoothed 2D Supervision

Also called: Adaptive Gaussian blur strategy, Progressive Gaussian Blurring

## Overview
Smoothed 2D Supervision is a regularization technique that enhances the robustness of joint optimization in differentiable rendering by smoothing the 2D ground-truth supervision signal [S1][S2, unofficial]. It solves the problem of unstable camera alignment and high-frequency noise in early training stages, which often leads to "floaters" and geometric inconsistency [S2, unofficial]. Unlike methods that constrain 3D geometry directly (e.g., [3D Half-Gaussian Splatting Covariance Transformation and Regularization](9150-3d-half-gaussian-splatting-covariance-transformation-and-reg.md)) or penalize spectral discrepancies (e.g., [Frequency Regularization](6130-frequency-regularization.md)), this method restricts the spectrum of the learned 3D scene by progressively reducing the variance of a Gaussian blur kernel applied to the input images [S3].

## How it works
**Inputs:**
- Training images $I_{raw}$ (resolution $W \times H$).
- Camera poses and intrinsics.
- Current 3D Gaussian scene representation.
- Hyperparameters: initial kernel size $K_{init}$, initial standard deviation $\sigma_{init}$, decay interval $k_b$, total iterations $T_{total}$, and optional downsampling scale $s$.

**Outputs:**
- Smoothed supervision images $I_{smooth}$ used in the photometric loss $\mathcal{L}_{photo}$.

**Data Structures:**
- The supervision signal is a 2D image tensor of the same resolution as the input.
- The blur kernel is a 2D Gaussian kernel $G(x, y; \sigma)$.

**Parameters:**
- $K_{init}$: Initial kernel size (e.g., $9 \times 9$) [S4].
- $\sigma_{init}$: Initial standard deviation (e.g., $2.4$) [S4].
- $k_b$: Iteration interval for kernel reduction (e.g., $100$) [S4].
- $T_{decay}$: Iteration at which blurring stops or reduces significantly (e.g., $19500$) [S4].

**Steps:**
1. **Initialize Kernel:** Set current kernel size $K = K_{init}$ and standard deviation $\sigma = \sigma_{init}$ [S4].
2. **Iterate Training:** For each training iteration $t$ from $1$ to $T_{total}$:
    a. **Update Kernel:** If $t$ is a multiple of $k_b$ and $t < T_{decay}$:
        - Reduce $\sigma$ (and potentially $K$) to decrease blur intensity [S4].
        - If downsampling is active with scale $s$, adjust $K$ by dividing by $s$ to maintain effective coverage relative to the original resolution [S4].
    b. **Generate Supervision:** Apply the 2D Gaussian blur with current $\sigma$ to $I_{raw}$ to produce $I_{smooth}$ [S2, unofficial].
    c. **Render:** Render the current 3D Gaussians to produce $I_{render}$ [S2, unofficial].
    d. **Compute Loss:** Calculate photometric loss $\mathcal{L}_{photo} = \| I_{render} - I_{smooth} \|$ (e.g., L1 or SSIM) [S2, unofficial].
    e. **Optimize:** Update 3D Gaussian parameters (position, covariance, opacity, color) using gradients from $\mathcal{L}_{total} = \mathcal{L}_{photo} + \lambda \mathcal{L}_{reg}$ [S1][S2, unofficial].

**Pseudocode:**
```python
def smoothed_2d_supervision(training_images, initial_sigma=2.4, kernel_size=9, decay_interval=100, total_iterations=19500, downsampling_scale=1.0):
    """
    Generates smoothed supervision images for a given training iteration.
    """
    # Initialize kernel parameters
    current_sigma = initial_sigma
    current_kernel_size = kernel_size
    
    # Pre-compute Gaussian kernel for the initial sigma
    # Note: In practice, the kernel is recomputed or interpolated as sigma changes
    kernel = create_gaussian_kernel(current_kernel_size, current_sigma)
    
    for t in range(1, total_iterations + 1):
        # Update kernel schedule
        if t % decay_interval == 0 and t < total_iterations:
            # Gradually reduce sigma
            # The exact reduction function is not specified, but it is exponential or linear decay
            # [S2, unofficial] mentions exponential reduction to 0 at 10k iterations in one context, 
            # but [S4] specifies reduction until 19500. We follow the progressive reduction logic.
            current_sigma = reduce_sigma(current_sigma, t) 
            
            # Adjust kernel size if downsampling is active
            # [S4]: "lower the kernel size by the scale of downsampling"
            if downsampling_scale > 1.0:
                current_kernel_size = max(1, int(current_kernel_size / downsampling_scale))
            
            # Recompute kernel with new parameters
            kernel = create_gaussian_kernel(current_kernel_size, current_sigma)
        
        # Apply blur to the raw training image
        # [S2, unofficial]: "blurring the 2D training image with a parallel set of scheduled 2D Gaussian kernels"
        smoothed_image = apply_2d_gaussian_blur(training_images, kernel)
        
        yield smoothed_image

def reduce_sigma(current_sigma, iteration):
    """
    Placeholder for the specific decay schedule.
    [S2, unofficial] suggests exponential reduction. [S4] suggests gradual reduction.
    """
    # Example: Linear decay to 0 over the decay interval
    # This is a [G] implementation detail as the exact formula is not provided in sources
    return max(0.0, current_sigma * 0.9) 
```

**Edge Cases and Pitfalls:**
- **Precision:** Using a large kernel size with small $\sigma$ can be computationally expensive. Separable convolution should be used [S1].
- **Boundaries:** Gaussian blur introduces boundary artifacts. Ensure padding or edge handling is consistent with the rendering pipeline [G].
- **Degenerate Input:** If the input images are already noisy, excessive blurring may remove valid high-frequency details needed for final convergence. The schedule must terminate or reduce $\sigma$ to near-zero before the end of training [S4].

## Subtopics

### [Randomly Scaled Kernel Parameter](7875-randomly-scaled-kernel-parameter.md)
A regularization technique used during joint optimization to mitigate weak and noisy gradient signals. It addresses the insufficiency of using a single-size kernel for diverse real-world scene structures, where a fixed kernel may be overly aggressive in some contexts and overly gentle in others. By randomly scaling the kernel size, it allows combinations of different-sized kernels to guide the optimization, resulting in a more robust training schedule.

### [Multiscale Pre-convolved Representation](10911-multiscale-pre-convolved-representation.md)
A regularization technique for neural illumination fields that stabilizes the decomposition of object materials from environmental illumination by enforcing consistency with pre-computed, roughness-adapted background reflections. It addresses the ambiguity where diffuse object color is incorrectly absorbed into the estimated environment map, a problem inherent to high-dimensional neural illumination representations. Unlike methods that ignore the background or treat it as static, this method explicitly models the relationship between rough refractive surfaces and the convolved background, allowing for realistic specular reflections even when roughness exceeds the kernel scale. The technique builds on [Smoothed 2D Supervision](7213-smoothed-2d-supervision.md) by applying discrete Gaussian blur kernels to the background to stabilize convergence.

### [Soft Rasterization](13687-soft-rasterization.md)
Soft rasterization is a differentiable rendering technique that mitigates the discontinuities inherent in standard rasterization by blending facet contributions for pixels near primitive edges. It solves the problem of sparse and vanishing gradients caused by the non-uniformity of bilinear interpolation operands, which typically have similar values except at object boundaries. Unlike standard hard rasterization, it yields slightly distorted images but allows backpropagating more useful gradients, thereby stabilizing optimization and preventing gradient vanishing at edges.

### Platonic GAN (pGAN)
A learning-based method for 2D supervision per class of reconstructed objects, used here to pre-train a network for per-frame supervision of rising smoke [S5]. It improves depth artifacts but lacks temporal constraints, leading to incoherent solutions if not integrated with temporal self-supervision [S5].

## Operating characteristics
- **Time Complexity:** The addition of 2D Gaussian blur increases the per-iteration cost. However, using separable convolution reduces this to $O(K \cdot W \cdot H)$ per image, where $K$ is the kernel size [S1].
- **Memory Complexity:** Minimal additional memory, as the smoothed image can be computed on-the-fly or cached [S1].
- **Measured Performance:** On DTU 3-view, Smoothed 2D Supervision (Adaptive Gaussian Blur) achieves 19.72 PSNR, improving over the Baseline (19.54) [S3].
- **Scaling:** The method is effective for joint optimization of camera poses and scene parameters, reducing training iterations required for convergence (e.g., 50k vs 200k in some MLP-based methods) [S1].
- **Strengths:** Stabilizes camera alignment, restricts high-frequency noise, and improves robustness in early training stages [S2, unofficial].
- **Limitations:** Handcrafted schedule may not fully align frequency relationships between positional encodings and pixel supervision compared to adaptive methods [S3].

## Background
Smoothed 2D Supervision was introduced as a technique to enhance the robustness of joint optimization in differentiable rendering [S1][S2, unofficial]. It is inspired by the analysis of spectral modulation in radiance fields, where blurring the 2D training images helps stabilize the optimization process [S2, unofficial]. The method has been applied in various contexts, including joint pose refinement [S1] and efficient Gaussian Splatting training [S4].
