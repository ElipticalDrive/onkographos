# StereoGaussians


## Overview
StereoGaussians is a feed-forward method that predicts a metric 3D Gaussian Splatting (3DGS) representation from a single calibrated stereo pair, enabling nearby-view extrapolation without per-scene optimization [S1, unofficial]. It sets itself apart from sibling methods by transferring frozen stereo features into metric 3DGS prediction using a two-layer Gaussian structure and an expanded image canvas to support disoccluded and outside-field-of-view content [S1, unofficial]. Unlike methods that synthesize images directly (e.g., LVSM) or refine inverse depth through a composer (e.g., SHARP), StereoGaussians uses explicit feed-forward multi-view Gaussian prediction with fixed front-layer stereo depth and bounded image-plane offsets [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A calibrated rectified stereo pair $(I_L, I_R)$, camera intrinsics $K$ (focal lengths $f_x, f_y$, principal point $c_x, c_y$), and baseline $B$.
*   **Outputs:** A set of $N$ Gaussians $\mathcal{G} = \{(x_i, s_i, q_i, \alpha_i, c_i)\}$ in the left-camera frame, where $x_i$ is position, $s_i$ is scale, $q_i$ is rotation (quaternion), $\alpha_i$ is opacity, and $c_i$ is color (Spherical Harmonics coefficients) [S1, unofficial].

**Data Structures:**
The method operates on an expanded image canvas of size $(H + 2P) \times (W + 2P)$, where $P$ is the padding per side (default 16 pixels) [S1, unofficial].
*   **Descriptor $\Phi$:** A dense full-resolution feature map of size $C \times H \times W$ (default $C=128$) [S1, unofficial].
*   **Gaussian Attributes:** Predicted as residuals. Each layer outputs 37 channels per pixel: 1 for opacity, 2 for image-plane offsets, 3 for scale, 4 for quaternion, and 27 for degree-2 Spherical Harmonic (SH) coefficients [S1, unofficial].

**Numbered Steps:**

1.  **Stereo Feature Extraction:** Encode the stereo inputs using a frozen pretrained stereo encoder (e.g., FoundationStereo) to obtain a left-reference disparity map $d$ and aligned multiscale features $\{F_s\}$ [S1, unofficial].
    *   *Note:* For the Fast-FoundationStereo variant, only left-reference image features and RGB-D are used; context and recurrent features are excluded [S1, unofficial].
2.  **Metric Depth Calculation:** Compute metric depth $z(p)$ for each pixel $p=(u,v)$ using the disparity $d(p)$:
    $$ z(p) = \text{clip}\left( \frac{f_x B}{d(p)}, z_{\min}, z_{\max} \right) $$
    where $f_x$ is the horizontal focal length in pixels, $B$ is the baseline, and $z_{\min}, z_{\max}$ are clipping bounds [S1, unofficial].
3.  **Descriptor Generation:** Construct the dense descriptor $\Phi$ by concatenating each feature scale $F_s$ with resized reference RGB ($\downarrow_s I_L$) and stereo depth $z$, then passing through a DPT-style decoder $D$:
    $$ \Phi = D \left[ \{F_s, \downarrow_s I_L, \downarrow_s z\}_s \right] \in \mathbb{R}^{C \times H \times W} $$
    Here, $\downarrow_s$ resizes inputs to feature scale $s$ (e.g., $s=4$ yields $H/4 \times W/4$) [S1, unofficial].
    *   *Implementation Detail:* At each scale, concatenate encoder features with resized RGB (bilinear) and depth (nearest-neighbor). Project to 128 channels via $1\times1$ convolution, group normalization, and GELU. Use residual convolution units and coarse-to-fine fusion blocks [S1, unofficial].
4.  **Canvas Extension:** Extend the reference RGB $I_L$, processed depth $z$, and descriptor $\Phi$ by edge-replication padding $P$ on each side to size $(H + 2P) \times (W + 2P)$ [S1, unofficial].
    *   Update canvas intrinsics: Focal lengths remain unchanged. Principal point shifts to $\tilde{c}_x = c_x + P$, $\tilde{c}_y = c_y + P$ [S1, unofficial].
    *   Let the extended inputs be denoted with tildes: $\tilde{I}_L, \tilde{z}, \tilde{\Phi}$ [S1, unofficial].
5.  **Gaussian Prediction:** Pass extended inputs through a convolutional predictor $H$ to obtain attribute residuals for two Gaussian layers and a back-layer depth offset:
    $$ (\theta_{\text{front}}, \theta_{\text{back}}, \Delta z) = H([\tilde{I}_L, \tilde{z}, \tilde{\Phi}]) $$
    *   *Regressor:* A shared regressor with two $3\times3$ convolutions and intermediate GELU maps $[\tilde{I}_L, \tilde{z}, \tilde{\Phi}]$ to a 128-channel tensor $h$ [S1, unofficial].
    *   *Output Branches:* Each branch processes $[h, \tilde{I}_L, \tilde{\Phi}]$ using a $3\times3$ convolution, group normalization, GELU, and a final $3\times3$ convolution [S1, unofficial].
6.  **Front Layer Geometry:**
    *   Set front layer depth: $z_{\text{front}} = \tilde{z}$ [S1, unofficial].
    *   Compute image-plane offsets: $(\delta_{u,\ell}, \delta_{v,\ell}) = \sigma(o_\ell) - 1/2$, where $o_\ell$ is the 2-channel offset output for layer $\ell$, bounded to half a canvas pixel per axis [S1, unofficial].
    *   Compute center:
        $$ x_{\text{front}}(p) = z_{\text{front}}(p) \tilde{K}^{-1} [u + \delta_{u,\text{front}}, v + \delta_{v,\text{front}}, 1]^\top $$
        where $\tilde{K}$ is the extended canvas intrinsic matrix [S1, unofficial].
7.  **Back Layer Geometry:**
    *   Compute back layer depth using a local maximum in a $9\times9$ neighborhood $N_9(p)$ plus a learned positive offset:
        $$ z_{\text{back}}(p) = \max_{q \in N_9(p)} \tilde{z}(q) + \text{softplus}(\Delta z(p)) $$
        where $\Delta z(p)$ is the scalar output from the separate back-layer depth offset branch [S1, unofficial].
    *   Compute center:
        $$ x_{\text{back}}(p) = z_{\text{back}}(p) \tilde{K}^{-1} [u + \delta_{u,\text{back}}, v + \delta_{v,\text{back}}, 1]^\top $$
8.  **Gaussian Attributes:**
    *   **Base Scale:** Isotropic base scale $s_{0,\ell} = \kappa z_\ell / (f_x f_y)$, following the metric pixel footprint [S1, unofficial].
    *   **Residuals:** Predict attributes as residuals around a reference-image DC base:
        *   Scale: Bounded multiplicative updates.
        *   Rotation: Additive quaternion updates.
        *   Opacity: Updates in logit space.
        *   Color: Degree-2 SH residuals [S1, unofficial].
9.  **Rendering:** Concatenate front and back layers. Render target views using both layers without an edge mask restricting the back layer, allowing learned attributes and visibility to determine contributions [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class StereoGaussians:
    def __init__(self, encoder, predictor, padding=16):
        """
        Args:
            encoder: Frozen stereo encoder (e.g., FoundationStereo).
            predictor: Trainable convolutional predictor H.
            padding: Number of pixels to pad the canvas per side (default 16).
        """
        self.encoder = encoder
        self.predictor = predictor
        self.padding = padding
        # Constants for metric depth and scale
        self.z_min = 0.1
        self.z_max = 100.0
        self.kappa = 1.0 # Metric pixel footprint constant

    def forward(self, I_L, I_R, K, B, target_views=None):
        """
        Args:
            I_L, I_R: Input stereo images (H, W, 3) in [0, 1].
            K: Intrinsics matrix (3, 3).
            B: Baseline distance.
            target_views: Optional list of target view data for training.
        Returns:
            Gaussians: List of Gaussian parameters for front and back layers.
        """
        # 1. Stereo Feature Extraction
        # Encoder outputs: disparity d, multiscale features {F_s}
        # Note: Input normalization (ImageNet) is handled by the encoder internally
        # or applied before encoding.
        d, features = self.encoder(I_L, I_R)
        
        # 2. Metric Depth Calculation
        f_x = K[0, 0]
        # Clip disparity to valid depth range
        d_clipped = torch.clamp(d, min=1e-3, max=1e3) # Avoid division by zero
        z = torch.clamp((f_x * B) / d_clipped, min=self.z_min, max=self.z_max)
        
        # 3. Descriptor Generation
        # Resize RGB and Depth to each feature scale s
        # features is a list of tensors [F_s]
        descriptor_inputs = []
        for s in features:
            # Resize I_L and z to match feature spatial size
            # Use bilinear for RGB, nearest for depth
            I_L_resized = F.interpolate(I_L.permute(0, 3, 1, 2), size=s.shape[2:], mode='bilinear', align_corners=False)
            z_resized = F.interpolate(z.unsqueeze(1), size=s.shape[2:], mode='nearest')
            # Concatenate feature, resized RGB, resized depth
            concat = torch.cat([s, I_L_resized, z_resized], dim=1)
            # Project to 128 channels (simplified DPT decoder step)
            # In practice, this involves 1x1 conv, GroupNorm, GELU, and fusion
            # Here we assume a placeholder projection for clarity
            proj = self._project_to_128(concat)
            descriptor_inputs.append(proj)
        
        # Coarse-to-fine fusion to get full-resolution descriptor
        Phi = self._coarse_to_fine_fusion(descriptor_inputs)
        
        # 4. Canvas Extension
        P = self.padding
        H, W = I_L.shape[1], I_L.shape[2]
        
        # Pad I_L, z, Phi with edge replication
        pad = nn.ReplicationPad2d(P)
        I_L_padded = pad(I_L.permute(0, 3, 1, 2)).permute(0, 2, 3, 1) # (H+2P, W+2P, 3)
        z_padded = pad(z.unsqueeze(1)).squeeze(1) # (H+2P, W+2P)
        Phi_padded = pad(Phi.permute(0, 2, 3, 1)).permute(0, 2, 3, 1) # (H+2P, W+2P, C)
        
        # Update intrinsics for canvas
        K_tilde = K.clone()
        K_tilde[0, 2] += P
        K_tilde[1, 2] += P
        
        # 5. Gaussian Prediction
        # Concatenate inputs for predictor
        # Predictor H takes [I_L_padded, z_padded, Phi_padded]
        # Note: Predictor expects specific channel layouts; adjust as needed
        predictor_input = torch.cat([I_L_padded, z_padded.unsqueeze(-1), Phi_padded], dim=-1)
        
        # Output: theta_front, theta_back, delta_z
        theta_front, theta_back, delta_z = self.predictor(predictor_input)
        
        # 6. Front Layer Geometry
        z_front = z_padded
        # Compute offsets: sigma(o) - 0.5, bounded to half canvas pixel
        # o_front is 2 channels (u, v offsets)
        o_front = theta_front[..., :2]
        delta_uv_front = torch.sigmoid(o_front) - 0.5
        # Bound to half canvas pixel (approximate for implementation)
        # In practice, this might be a hard clamp or learned bound
        # delta_uv_front = torch.clamp(delta_uv_front, -0.5, 0.5) 
        
        # Compute centers
        # x = z * K_tilde^-1 * [u + du, v + dv, 1]^T
        # This is done per pixel. We use grid coordinates.
        u, v = torch.meshgrid(torch.arange(W + 2*P), torch.arange(H + 2*P), indexing='ij')
        u = u.float().to(I_L.device)
        v = v.float().to(I_L.device)
        
        # Normalize to camera coordinates
        # K_tilde^-1 * [u, v, 1]^T
        # Assuming K_tilde is 3x3
        inv_K_tilde = torch.linalg.inv(K_tilde.unsqueeze(0)) # (1, 3, 3)
        
        # Homogeneous coordinates
        coords_front = torch.stack([u + delta_uv_front[..., 0], v + delta_uv_front[..., 1], torch.ones_like(u)], dim=-1) # (H+2P, W+2P, 3)
        coords_front = coords_front.unsqueeze(-1) # (H+2P, W+2P, 3, 1)
        
        # Transform
        cam_coords_front = torch.matmul(inv_K_tilde, coords_front).squeeze(-1) # (H+2P, W+2P, 3)
        x_front = cam_coords_front * z_front.unsqueeze(-1) # (H+2P, W+2P, 3)
        
        # 7. Back Layer Geometry
        # Local max in 9x9 neighborhood
        # Pad z_padded for max pooling
        z_padded_padded = F.pad(z_padded.unsqueeze(0).unsqueeze(0), (4, 4, 4, 4), mode='replicate')
        z_max_pool = F.max_pool2d(z_padded_padded, kernel_size=9, stride=1).squeeze(0).squeeze(0)
        
        # Add softplus of delta_z
        z_back = z_max_pool + torch.nn.functional.softplus(delta_z)
        
        # Compute centers for back layer
        o_back = theta_back[..., :2]
        delta_uv_back = torch.sigmoid(o_back) - 0.5
        # delta_uv_back = torch.clamp(delta_uv_back, -0.5, 0.5)
        
        coords_back = torch.stack([u + delta_uv_back[..., 0], v + delta_uv_back[..., 1], torch.ones_like(u)], dim=-1)
        coords_back = coords_back.unsqueeze(-1)
        cam_coords_back = torch.matmul(inv_K_tilde, coords_back).squeeze(-1)
        x_back = cam_coords_back * z_back.unsqueeze(-1)
        
        # 8. Gaussian Attributes
        # Base scale
        s_base = self.kappa * z_padded / (f_x * K[1, 1]) # f_y = K[1,1]
        
        # Residuals
        # theta_front has 37 channels: 1 alpha, 2 offset, 3 scale, 4 quat, 27 SH
        # We already used offset. Extract others.
        # Note: The exact channel order must match the predictor output definition
        # Assuming: [alpha, offset, scale, quat, SH]
        
        # Front Layer Attributes
        alpha_front_raw = theta_front[..., 0]
        scale_res = theta_front[..., 2:5]
        quat_res = theta_front[..., 5:9]
        sh_res = theta_front[..., 9:]
        
        # Apply residuals to base
        alpha_front = torch.sigmoid(alpha_front_raw) # Opacity in logit space
        s_front = s_base * torch.exp(scale_res) # Multiplicative scale
        q_front = normalize_quaternion(quat_res) # Additive quaternion update (simplified)
        c_front = compute_sh_color(sh_res) # Degree-2 SH residuals
        
        # Back Layer Attributes
        alpha_back_raw = theta_back[..., 0]
        scale_res_back = theta_back[..., 2:5]
        quat_res_back = theta_back[..., 5:9]
        sh_res_back = theta_back[..., 9:]
        
        alpha_back = torch.sigmoid(alpha_back_raw)
        s_back = s_base * torch.exp(scale_res_back)
        q_back = normalize_quaternion(quat_res_back)
        c_back = compute_sh_color(sh_res_back)
        
        # 9. Return Gaussians
        # Flatten to list of Gaussians
        front_gaussians = {
            'x': x_front,
            's': s_front,
            'q': q_front,
            'alpha': alpha_front,
            'c': c_front
        }
        back_gaussians = {
            'x': x_back,
            's': s_back,
            'q': q_back,
            'alpha': alpha_back,
            'c': c_back
        }
        
        return front_gaussians, back_gaussians

    def _project_to_128(self, x):
        # Placeholder for 1x1 conv, GroupNorm, GELU
        return x # Simplified

    def _coarse_to_fine_fusion(self, features):
        # Placeholder for DPT-style decoder
        return features[-1] # Simplified

def normalize_quaternion(q):
    # Normalize quaternion to unit length
    return q / (torch.norm(q, dim=-1, keepdim=True) + 1e-8)

def compute_sh_color(sh_coeffs):
    # Placeholder for SH color evaluation
    return sh_coeffs[..., :3] # Simplified to RGB
```

**Parameters:**
*   **Padding $P$:** 16 pixels (default) [S1, unofficial].
*   **Learning Rate:** $4 \times 10^{-4}$ for AdamW [S1, unofficial].
*   **Weight Decay:** 0.01 [S1, unofficial].
*   **Momentum:** $(\beta_1, \beta_2) = (0.9, 0.999)$ [S1, unofficial].
*   **Scheduler:** OneCycleLR with 2,700 warm-up steps (9% of training), initial LR division factor 25, final LR division factor 100 [S1, unofficial].
*   **Training Steps:** 30,000 [S1, unofficial].
*   **Batch Size:** 32 [S1, unofficial].
*   **Loss:** MSE + $0.05 \times$ LPIPS [S1, unofficial].
*   **Decoder Channels:** 128 [S1, unofficial].
*   **Output Channels per Branch:** 37 (1 opacity, 2 offset, 3 scale, 4 quaternion, 27 SH) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Padding:** Without padding, empty target-border bands appear in rendered views; padding fills these newly exposed regions [S1, unofficial]. Removing 16-pixel padding lowers PSNR by 3.168 dB on StereoNVS and 8.732 dB on ReplicaGS [S1, unofficial].
*   **Fixed Front-Layer Depth:** Limits stereo-error correction [S1, unofficial].
*   **Teacher Artifacts:** Can persist despite reconstruction-quality filtering [S1, unofficial].
*   **Descriptor:** Without the DPT descriptor, tabletop distortions and foreground-boundary artifacts occur [S1, unofficial].

## Background
StereoGaussians was introduced in 2026 by authors associated with the paper "StereoGaussians: Feed-Forward 3D Gaussian Splatting from Stereo Images" [S1, unofficial]. It builds on the principles of feed-forward 3DGS and leverages pretrained stereo networks (FoundationStereo) to predict Gaussian attributes. The method was trained on the SceneSplat-Stereo dataset, which pairs stereo inputs with nearby target views from 803 training scenes [S1, unofficial]. It is used on StereoNVS and ReplicaGS datasets [S1, unofficial].
