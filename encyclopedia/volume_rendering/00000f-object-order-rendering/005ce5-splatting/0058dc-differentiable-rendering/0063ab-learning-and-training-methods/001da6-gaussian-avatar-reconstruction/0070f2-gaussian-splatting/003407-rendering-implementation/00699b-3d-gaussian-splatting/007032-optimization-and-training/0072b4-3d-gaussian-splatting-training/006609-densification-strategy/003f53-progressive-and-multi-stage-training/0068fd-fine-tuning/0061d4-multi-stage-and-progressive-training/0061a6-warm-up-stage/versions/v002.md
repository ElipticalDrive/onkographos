# Warm-up stage
Also called: 3D Gaussian Initialization (Warm-up)

## Overview
The warm-up stage is a training adaptation used in 3D Gaussian Splatting (3DGS) and its dynamic variants (4D-GS) to stabilize optimization and improve convergence, particularly when initial SfM points are sparse or absent [S1, S2]. It serves as a preliminary phase where static 3D Gaussians are optimized before introducing complex temporal deformation networks [S2]. This approach is distinct from direct 4D optimization by decoupling spatial initialization from temporal dynamics, thereby preventing convergence difficulties and reducing numeric errors in deformation networks [S2]. It also contributes to distractor suppression in methods like SpotLessSplats [S1].

## How it works
### Inputs and Outputs
- **Inputs**: Initial set of 3D Gaussians (often derived from SfM points or random initialization if SfM is absent), camera poses, and training images [S2].
- **Outputs**: Optimized static 3D Gaussian parameters (position, covariance, opacity, color) and initial deformation field suggestions [S2].

### Data Structures
The method operates on the standard 3D Gaussian representation $\mathcal{G}$, defined by:
- Position $\mu \in \mathbb{R}^3$
- Covariance $\Sigma \in \mathbb{R}^{3 \times 3}$ (often parameterized by rotation $R$ and scale $S$)
- Opacity $\alpha \in [0, 1]$
- Spherical harmonics coefficients for color $c$

In the context of 4D-GS warm-up, the structure may include a subset of Gaussians designated as "dynamic" to relieve pressure on the deformation network [S2].

### Steps
1. **Initialization**: Initialize 3D Gaussians from SfM points. If SfM points are absent, initialize randomly or using a coarse estimation [S2].
2. **Static Optimization**: Optimize the 3D Gaussian parameters ($\mu, \Sigma, \alpha, c$) using standard 3DGS rendering loss (e.g., L1 loss + SSIM) for a fixed number of iterations or until convergence [S2].
3. **Deformation Field Suggestion**: During this phase, the optimization suggests initial deformation fields that pay attention to dynamic parts of the scene, preparing the network for subsequent 4D training [S2].
4. **Stabilization**: This stage avoids numeric errors in optimizing the Gaussian deformation network $\Delta$ by ensuring the static base is stable before introducing temporal complexity [S2].

### Formulas
The optimization minimizes a loss function $\mathcal{L}$:
$$ \mathcal{L} = \mathcal{L}_{1} + \lambda \mathcal{L}_{\text{SSIM}} $$
where $\mathcal{L}_{1}$ is the L1 loss between rendered and ground truth images, and $\mathcal{L}_{\text{SSIM}}$ is the structural similarity index [S2].

### Parameters
- **Iterations**: Not specified in sources.
- **Learning Rate**: Not specified in sources.
- **$\lambda$**: SSIM weight, typically 0.2 in standard 3DGS, but not explicitly stated for warm-up [S2].

### Edge Cases and Pitfalls
- **Absence of SfM Points**: Direct 4D-GS training without warm-up leads to convergence difficulty [S2].
- **Numeric Errors**: Skipping warm-up can cause numeric errors in the deformation network $\Delta$ [S2].
- **Underfitting**: Without proper warm-up, excessive stretching may lead to underfitting of details [S2].

### Pseudocode
```python
def warm_up_stage(gaussians, images, poses, iterations):
    """
    Optimizes static 3D Gaussians before 4D training.
    """
    # Initialize Gaussians from SfM or random
    if sfm_points_available:
        gaussians = initialize_from_sfm(sfm_points)
    else:
        gaussians = initialize_random()

    # Optimize static parameters
    for i in range(iterations):
        # Sample a random camera pose
        cam_idx = random_choice(poses)
        pose = poses[cam_idx]
        gt_image = images[cam_idx]

        # Render current Gaussians
        rendered_image = render(gaussians, pose)

        # Compute loss
        loss = compute_loss(rendered_image, gt_image)

        # Backpropagate and update Gaussians
        update_gaussians(gaussians, loss)

    # Return optimized Gaussians and suggested deformation hints
    return gaussians, get_deformation_hints(gaussians)
```

## Subtopics

### 3D Gaussian Initialization (Warm-up)
A specific variant where the warm-up stage is explicitly used to optimize 3D Gaussians before training 4D-GS directly, primarily when SfM points initialization is absent to prevent convergence difficulty [S2]. It keeps some 3D Gaussians in the dynamic part to release pressure of large deformation learning by 4D Gaussians, learns proper 3D Gaussians $\Gamma$ and suggests deformation fields to pay more attention to the dynamic part, and avoids numeric errors in optimizing the Gaussian deformation network $\Delta$ [S2].

## Operating characteristics
- **Time Complexity**: Adds an initial optimization phase, increasing total training time. However, it may reduce overall time by preventing convergence failures in later stages [S2].
- **Memory Complexity**: No significant additional memory overhead compared to standard 3DGS, as it uses the same Gaussian representation [S2].
- **Performance**: Training without the warm-up coarse stage yields PSNR 31.91 dB, SSIM 0.97, LPIPS 0.03, training time 7.5 mins, 79 FPS, and 18 MB storage [S2]. With warm-up, convergence is more stable, though specific metrics for the warm-up case are not provided in the sources [S2].
- **Strengths**: Prevents convergence difficulty, stabilizes deformation network optimization, handles scenes without SfM points [S2].
- **Limitations**: Adds an extra training phase, potentially increasing total training time [S2].

## Background
The warm-up stage was introduced in the context of 4D Gaussian Splatting for real-time dynamic scene rendering [S2]. It addresses the challenge of training 4D-GS directly when SfM points are absent, which can lead to convergence difficulties [S2]. The method is also referenced in SpotLessSplats as one of several adaptations that show improvements in distractor suppression [S1].
