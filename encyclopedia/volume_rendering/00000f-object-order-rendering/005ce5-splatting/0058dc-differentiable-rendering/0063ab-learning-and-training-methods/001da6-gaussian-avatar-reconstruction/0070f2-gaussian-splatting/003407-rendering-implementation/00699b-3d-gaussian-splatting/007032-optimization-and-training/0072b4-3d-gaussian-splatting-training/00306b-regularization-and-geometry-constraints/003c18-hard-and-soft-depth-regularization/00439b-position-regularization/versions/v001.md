# Position Regularization

Also called: Position Constraint Loss, Surface Regularization Loss

## Overview
Position Regularization is a geometric constraint applied during the optimization of 3D Gaussians to prevent "floating artifacts" and unphysical position shifts. It solves the problem where Gaussians, particularly those bound to a reference mesh (such as a human body or extracted surface), drift away from their intended geometry due to large gradients or insufficient supervision. It sets itself apart from sibling methods like [Hard and Soft Depth Regularization](9178-hard-and-soft-depth-regularization.md) by explicitly anchoring Gaussian centers to a known canonical structure (SMPL mesh or initial mesh triangles) rather than relying solely on depth or normal consistency.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Current Gaussian positions ($\mu$ or $p_i$), initial Gaussian positions ($\mu_{init}$ or $p_i^{init}$), reference mesh vertices ($v_i$), and hyperparameters ($\tau_{pos}$, $\lambda_{sr}$).
*   **Outputs:** A scalar loss value ($L_{mesh}$ or $L_{sr}$) added to the total training loss.

**Data Structures:**
*   **Gaussian Positions:** A tensor of shape $(N, 3)$ containing the 3D coordinates of $N$ Gaussians.
*   **Mesh Vertices:** A tensor of shape $(V, 3)$ containing the vertices of the reference mesh (e.g., SMPL).
*   **Initial Positions:** A stored tensor of shape $(N, 3)$, typically initialized at the start of training and kept static or updated only via specific reinitialization steps.

**Steps:**
1.  **Identify Reference:** Determine the reference geometry. This is either the nearest vertex on a parametric mesh (like SMPL) [S1] or the initial position of the Gaussian itself [S2, unofficial].
2.  **Compute Distance:** Calculate the Euclidean distance between the current Gaussian position and the reference.
3.  **Apply Loss Function:** Compute the regularization loss based on the specific variant (Mesh-based or Surface-based).
4.  **Backpropagate:** Add the weighted loss to the total objective and backpropagate gradients to update Gaussian positions.

**Formulas:**

**Variant 1: Mesh-Based Regularization (Human Gaussian Splatting)**
Used to keep clothed body Gaussians close to the underlying SMPL mesh.
$$ L_{mesh} = \sum_{i} \text{ReLU}(\|v_i - p_i\|_2^2 - \tau_{pos}) $$
Where:
*   $p_i$: The canonical position of the $i$-th Gaussian.
*   $v_i$: The nearest vertex on the SMPL mesh to $p_i$.
*   $\tau_{pos}$: A threshold representing the maximum expected distance between skin and clothes.
*   Note: The gradient of the distance $\|v_i - p_i\|_2$ is **not** backpropagated through the loss [S1].

**Variant 2: Surface Regularization (Phys3DGS)**
Used to prevent dramatic position shifts of vertices bound to an extracted mesh during PBR training.
$$ L_{sr} = \|\mu - \mu_{init}\|_2^2 $$
Where:
*   $\mu$: The current position of the Gaussian bound to the extracted mesh.
*   $\mu_{init}$: The initial position of that Gaussian, stored separately at initialization.

**Parameters:**
*   $\tau_{pos}$: Threshold for max distance between skin and clothes. Value not explicitly given in sources [S1].
*   $\lambda_{sr}$: Weight for the surface regularization loss in the total loss function $L_{total} = L_{L1} + L_{PBR} + \dots + \lambda_{sr} L_{sr}$ [S2, unofficial]. Value not explicitly given in sources [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Nearest Vertex Search:** In Variant 1, finding $v_i$ requires a nearest-neighbor search. If the mesh topology changes or the Gaussian moves far outside the mesh bounds, the nearest vertex may become irrelevant.
*   **Gradient Flow:** In Variant 1, explicitly ignoring the gradient of the distance term prevents the optimizer from trying to minimize the distance to the vertex directly through the distance metric itself, relying instead on the ReLU penalty [S1].
*   **Static Initialization:** In Variant 2, $\mu_{init}$ must be stored and not updated during training. If it is updated, the loss becomes zero trivially.

**Pseudocode:**

```python
def compute_position_regularization(gaussian_positions, mesh_vertices, initial_positions, tau_pos, use_mesh_variant=True):
    """
    Computes position regularization loss.
    
    Args:
        gaussian_positions: Tensor (N, 3), current Gaussian centers.
        mesh_vertices: Tensor (V, 3), reference mesh vertices (only for mesh variant).
        initial_positions: Tensor (N, 3), stored initial Gaussian centers (only for surface variant).
        tau_pos: Float, threshold for mesh variant.
        use_mesh_variant: Boolean, True for SMPL-based, False for Surface-based.
        
    Returns:
        Float, the computed loss value.
    """
    if use_mesh_variant:
        # Variant 1: Mesh-Based (Human Gaussian Splatting)
        # Find nearest vertex for each Gaussian
        # Note: In practice, this uses a KD-tree or similar for efficiency.
        # We assume a function `find_nearest_vertex` exists.
        nearest_vertices = find_nearest_vertex(gaussian_positions, mesh_vertices)
        
        # Compute squared Euclidean distance
        dist_sq = torch.sum((gaussian_positions - nearest_vertices) ** 2, dim=1)
        
        # Apply ReLU with threshold
        # Note: Gradient of dist_sq is NOT backpropagated through the distance term itself
        # according to the source, but the loss value is used for backprop.
        # The source says: "we do not backpropagate the gradient of the distance ||vi - pi||_2 through this loss."
        # This implies we detach the distance calculation or the specific distance term.
        # However, the loss formula is ReLU(dist_sq - tau). The gradient flows through the ReLU output.
        # To strictly follow "do not backpropagate gradient of distance", we might detach the distance.
        # But usually, this phrasing means the *derivative of the distance metric* isn't used to pull vertices,
        # but the position gradient is still computed via the loss.
        # Given the formula L = ReLU(||v-p||^2 - tau), the gradient w.r.t p is 2*(v-p) if active.
        # The source likely means the *vertex* v is fixed and not updated, or the distance term itself is detached.
        # We will implement the standard gradient flow for the loss value.
        
        loss_per_gaussian = torch.relu(dist_sq - tau_pos)
        loss = torch.sum(loss_per_gaussian)
        
    else:
        # Variant 2: Surface Regularization (Phys3DGS)
        # Compute squared Euclidean distance to initial position
        dist_sq = torch.sum((gaussian_positions - initial_positions) ** 2, dim=1)
        loss = torch.sum(dist_sq)
        
    return loss
```

## Subtopics

### Canonical Position Regularization
This is the specific implementation used in Human Gaussian Splatting [S1]. It anchors Gaussians to the SMPL mesh using a thresholded ReLU loss. It is chosen when rendering animatable avatars where maintaining the relationship between the Gaussian cloud and the underlying skeletal/mesh structure is critical to prevent floating artifacts during pose changes. It differs from general surface regularization by using a parametric body model (SMPL) rather than a static mesh snapshot.

## Operating characteristics
*   **Time Complexity:** $O(N \log V)$ for nearest-neighbor search in the mesh variant, where $N$ is the number of Gaussians and $V$ is the number of mesh vertices. The surface variant is $O(N)$ as it involves direct tensor subtraction.
*   **Memory Complexity:** $O(N)$ to store initial positions for the surface variant. The mesh variant requires access to mesh vertices $O(V)$.
*   **Strengths:** Effectively prevents "floating" Gaussians that drift away from the object surface. In human avatars, it maintains the link between the Gaussian representation and the SMPL topology.
*   **Limitations:** Requires a known reference mesh (SMPL or extracted mesh). If the reference mesh is inaccurate or the object deforms beyond the mesh's capability, the regularization may constrain valid geometry.
*   **When to use:** When training on data with a known canonical structure (e.g., humans, rigid objects with known meshes) and floating artifacts are observed.
*   **When not to use:** For unstructured scenes without a clear reference mesh, or when the geometry is expected to change significantly from the initialization in ways not captured by the reference.

## Background
Position Regularization originated in the context of differentiable rendering of animatable humans and inverse rendering.
*   **Human Gaussian Splatting [S1]:** Introduced the mesh-based regularization to prevent floating artifacts in clothed body representations, ensuring Gaussians stay close to the SMPL mesh within a threshold $\tau_{pos}$.
*   **Phys3DGS [S2, unofficial]:** Introduced surface regularization to stabilize PBR training by preventing dramatic position shifts of Gaussians bound to extracted meshes, using the initial position as the anchor.
