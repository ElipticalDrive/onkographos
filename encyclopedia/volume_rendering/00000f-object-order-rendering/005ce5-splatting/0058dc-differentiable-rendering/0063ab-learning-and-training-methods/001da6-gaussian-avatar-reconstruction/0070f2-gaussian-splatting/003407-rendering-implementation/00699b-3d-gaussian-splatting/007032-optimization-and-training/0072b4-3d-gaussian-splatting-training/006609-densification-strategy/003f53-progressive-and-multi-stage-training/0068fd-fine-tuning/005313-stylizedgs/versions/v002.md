# StylizedGS


## Overview
StylizedGS is a controllable 3D stylization method for 3D Gaussian Splatting (3DGS) models that performs color matching with a reference style image while utilizing a 3DGS filter to remove artifacts [S1]. It distinguishes itself from other stylization approaches by explicitly optimizing for nearest neighbor feature matching and depth preservation [S1].

## How it works
**Inputs and Outputs:** The method takes a pre-trained 3DGS model and a reference style image as input, and outputs a stylized 3DGS model [S1].

**Data Structures:** The method operates on the standard 3DGS representation, consisting of $N$ Gaussians defined by position, covariance, opacity, and spherical harmonics coefficients [G]. StylizedGS modifies the color and feature attributes of these Gaussians during optimization [S1].

**Optimization Steps:**
1. Extract features from the reference style image.
2. Render the current 3DGS model to compute losses.
3. Compute the total loss as a weighted combination of a nearest neighbor feature match loss, a depth preservation loss, and a 3DGS filter loss for artifact removal [S1].
4. Optimize the 3DGS parameters to minimize the total loss [S1].

**Formulas:** The exact mathematical formulation of the loss components and the weighting hyperparameters are not given in the sources [S1].

**Parameters:** Not given in the sources.

**Edge Cases and Pitfalls:** Without the 3DGS filter, stylization may introduce visual artifacts, which the method explicitly addresses [S1].

## Subtopics

### StyleGaussian
StyleGaussian is a method for real-time 3D style transfer with strict multi-view consistency [S1]. It differs from StylizedGS by embedding VGG features directly into 3D Gaussians and using an efficient rendering strategy that initially renders lower-dimensional features before mapping them to high-dimensional ones [S1]. It aligns stylized features with a style image using an AdaIN-like mechanism and decodes features back to RGB using a KNN-based 3D CNN [S1].

## Background
StylizedGS belongs to the broader effort to apply artistic stylization to 3D Gaussian Splatting models [S1]. It builds on the efficiency of 3DGS while addressing challenges in visual fidelity and computational efficiency that are common in earlier NeRF-based methods [S1].
