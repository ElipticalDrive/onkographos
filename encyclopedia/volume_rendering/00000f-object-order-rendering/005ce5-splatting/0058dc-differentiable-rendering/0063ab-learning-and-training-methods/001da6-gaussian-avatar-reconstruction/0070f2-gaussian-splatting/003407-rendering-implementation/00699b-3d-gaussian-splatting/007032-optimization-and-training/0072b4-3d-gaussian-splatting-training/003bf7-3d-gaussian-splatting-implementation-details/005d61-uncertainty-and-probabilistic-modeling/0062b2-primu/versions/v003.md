# PRIMU

Also called: Primitive-based Representations of Uncertainty

## Overview
PRIMU is a post-hoc uncertainty estimation (UE) framework for 3D Gaussian Splatting (GS) that constructs primitive-level representations of error and visibility/coverage from training views, renders them to produce uncertainty feature maps, and aggregates them via pixel-wise regression on holdout data to estimate uncertainties for novel views [S1, unofficial]. It differs from sibling methods like FisherRF and Variational Bayes Gaussian Splatting by operating entirely as post-processing without requiring GS retraining, allowing it to be applied to existing trained models [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A trained 3D Gaussian Splatting model (parameters $\mu, \Sigma, \alpha, c$), a set of training views with known poses and ground-truth images/depths, and optionally a small set of holdout views for training the regression model.
*   **Outputs:** Per-pixel uncertainty estimates for novel views (color and depth), and/or uncertainty feature maps for active view selection.

**Data Structures:**
The method operates on the standard 3D Gaussian primitives. For each primitive $k$, the following attributes are stored:
*   Mean position $\mu_k \in \mathbb{R}^3$.
*   Covariance matrix $\Sigma_k \in \mathbb{R}^{3 \times 3}$ (or rotation/scale representation).
*   Opacity factor $g_k \in \mathbb{R}$.
*   Color coefficients $c_k$ (encoded via spherical harmonics).
*   **Primitive Features:** A vector of 13 scalar features extracted per primitive, which may be direction-dependent [S1, unofficial]. These features represent coverage and error statistics aggregated from training views.

**Numbered Steps:**

1.  **Project Training Errors and Coverage to Primitives:**
    For each training view $v \in \Omega$ (where $\Omega$ is the set of training views):
    a. Render the view using the trained GS model to obtain predicted color $C_v(\bar{x})$ and depth $D_v(\bar{x})$ for each pixel $\bar{x}$.
    b. Compute per-pixel reconstruction errors $e_{\bar{x}}$ (e.g., $\ell_1$ error for color or depth) against ground truth.
    c. For each Gaussian primitive $k$ visible in view $v$ (i.e., $\bar{x} \in v^{(k)}$ where opacity $\alpha_k(\bar{x})$ exceeds a small threshold):
       i. Calculate the contribution factor of primitive $k$ at pixel $\bar{x}$: $w_{k,\bar{x}} = \alpha_k(\bar{x}) T_k(\bar{x})$, where $T_k(\bar{x}) = \prod_{j=1}^{k-1} (1 - \alpha_j(\bar{x}))$ is the accumulated transparency [S1, unofficial].
       ii. Aggregate these contributions across all pixels $\bar{x}$ in view $v$ where primitive $k$ is visible. Use an aggregation function $\text{agg} \in \{\text{max, sum, mean}\}$ [S1, unofficial].
       iii. Compute the **Training-View Coverage** representation $V(k)$ for primitive $k$:
       $$ V(k) = \max_{v \in \Omega} \left( \text{agg}_{\bar{x} \in v^{(k)}} \left( \alpha_k(\bar{x}) T_k(\bar{x}) \right) \right) $$
       This captures the maximum aggregated contribution of primitive $k$ in any single training view [S1, unofficial].
       iv. Compute the **Rendering-Error** representation $E(k)$ for primitive $k$:
       $$ E(k) = \text{mean}_{v \in \Omega} \left( \text{agg}_{\bar{x} \in v^{(k)}} \left( e_{\bar{x}} \cdot \alpha_k(\bar{x}) T_k(\bar{x}) \right) \right) $$
       This captures the error-weighted contribution of primitive $k$ averaged over all training views [S1, unofficial].
    d. Compute the **Field-of-View (FoV) Count** representation $F(k)$:
    $$ F(k) = |\Omega_k| $$
    where $\Omega_k$ is the set of training views in which primitive $k$ lies within the viewing cone [S1, unofficial].

2.  **Render Uncertainty Feature Maps:**
    For a novel viewpoint:
    a. Project all Gaussian primitives onto the image plane using standard splatting [S1, unofficial].
    b. For each primitive $k$, use its computed feature vector (including $V(k)$, $E(k)$, $F(k)$, and potentially 10 other direction-dependent features) as the "color" or value to be rendered.
    c. Accumulate these values using the standard alpha-blending equation to produce uncertainty feature maps (e.g., a map of aggregated coverage, a map of aggregated error) [S1, unofficial].

3.  **Aggregate via Pixel-wise Regression:**
    a. Collect the rendered uncertainty feature maps for a set of holdout views.
    b. For each pixel $\bar{x}$, form an input vector from the feature maps.
    c. Train a **Gradient Boosting Regression** model to predict the true error (color or depth) at pixel $\bar{x}$ given the feature maps [S1, unofficial].
    d. Apply the trained regression model to the feature maps of novel views to output the final uncertainty estimate [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def compute_primitive_features(primitives, training_views, ground_truth_images, ground_truth_depths):
    """
    Computes 13 primitive-level features based on training view coverage and error.
    primitives: List of Gaussian primitives with attributes: mean, cov, opacity_factor, color_coeffs
    training_views: List of view dicts with 'pose', 'intrinsics', 'image', 'depth'
    ground_truth_images: List of numpy arrays (H, W, 3)
    ground_truth_depths: List of numpy arrays (H, W)
    """
    num_primitives = len(primitives)
    # Initialize feature storage. 13 features total.
    # Features 0-2: FoV count, Max Coverage, Mean Error (scalar)
    # Features 3-12: Direction-dependent variants (simplified here as scalar for structure)
    features = np.zeros((num_primitives, 13))
    
    agg_funcs = ['max', 'sum', 'mean'] # Options for aggregation
    
    for k, prim in enumerate(primitives):
        v_max = 0.0
        e_sum = 0.0
        e_count = 0
        fov_count = 0
        
        for v_idx, view in enumerate(training_views):
            # 1. Render primitive k for this view
            # Get 2D projection parameters (mu_bar, Sigma_bar) for primitive k in view v
            mu_bar, sigma_bar = project_gaussian_2d(prim, view['pose'], view['intrinsics'])
            
            # Check if primitive is in viewing cone (simple bounding box check or distance check)
            if not is_in_fov(mu_bar, view['image_shape']):
                continue
            
            fov_count += 1
            
            # 2. Render contribution map for primitive k
            # Create a blank map
            contrib_map = np.zeros(view['image_shape'])
            error_map = np.zeros(view['image_shape'])
            
            # Render alpha and T for primitive k
            # Note: In full GS, T depends on all primitives. 
            # PRIMU approximates by using the primitive's own alpha and assuming T is handled by aggregation logic or pre-computed.
            # However, Eq 4 and 5 use alpha_k * T_k. T_k requires front-to-back sorting.
            # For post-hoc, we might approximate T_k or use the full render to get T_k for each pixel.
            
            # Full render to get T_k and alpha_k for all pixels
            alpha_map, T_map = render_primitives_for_view(primitives, view['pose'], view['intrinsics'])
            
            # Extract alpha_k and T_k for primitive k specifically?
            # Standard GS render returns composite C. We need per-primitive contribution.
            # This requires storing intermediate render states or re-rendering per primitive (expensive).
            # Assuming a helper `get_primitive_contribution` exists which returns alpha_k(x) * T_k(x) for all x.
            contrib_values = get_primitive_contribution(k, alpha_map, T_map, view['image_shape'])
            
            # 3. Compute Error Map
            pred_image = render_color(primitives, view['pose'], view['intrinsics'])
            gt_image = ground_truth_images[v_idx]
            pixel_error = np.abs(pred_image - gt_image).mean(axis=2) # L1 error, mean over channels
            
            # 4. Aggregate for Coverage V(k)
            # Find pixels where alpha_k > threshold
            visible_pixels = contrib_values > 1e-6
            if np.any(visible_pixels):
                vals = contrib_values[visible_pixels]
                # Use 'max' aggregation across pixels for V(k) as per Eq 4 logic (max agg)
                # But Eq 4 says max over views of agg over pixels.
                v_val = np.max(vals) 
                if v_val > v_max:
                    v_max = v_val
            
            # 5. Aggregate for Error E(k)
            if np.any(visible_pixels):
                # Weighted error
                weighted_errors = pixel_error[visible_pixels] * contrib_values[visible_pixels]
                e_sum += np.mean(weighted_errors) # Mean agg over pixels
                e_count += 1
                
        # Finalize scalar features
        features[k, 0] = fov_count
        features[k, 1] = v_max
        if e_count > 0:
            features[k, 2] = e_sum / e_count
        else:
            features[k, 2] = 0.0

def render_uncertainty_maps(primitives, features, novel_view):
    """
    Renders the primitive features to produce uncertainty feature maps.
    """
    # Initialize maps for each feature channel
    num_features = features.shape[1]
    H, W = novel_view['image_shape']
    feature_maps = np.zeros((H, W, num_features))
    
    # Sort primitives front-to-back
    sorted_indices = sort_primitives_front_to_back(primitives, novel_view['pose'])
    
    # Standard Alpha Blending Accumulation
    T_acc = np.ones((H, W))
    
    for k in sorted_indices:
        prim = primitives[k]
        feat_vec = features[k]
        
        # Project primitive
        mu_bar, sigma_bar = project_gaussian_2d(prim, novel_view['pose'], novel_view['intrinsics'])
        
        # Evaluate 2D Gaussian density for all pixels
        # Phi(x; mu, Sigma)
        density_map = evaluate_2d_gaussian(mu_bar, sigma_bar, H, W)
        
        # Opacity alpha_k
        alpha_k = prim.opacity_factor * density_map
        
        # Contribution = alpha_k * T_acc
        # We render each feature channel separately
        for f_idx in range(num_features):
            val = feat_vec[f_idx]
            contribution = alpha_k * T_acc * val
            feature_maps[:, :, f_idx] += contribution
            
        # Update Transparency
        T_acc *= (1 - alpha_k)
        
    return feature_maps

def predict_uncertainty(feature_maps, regression_model):
    """
    Aggregates feature maps via pixel-wise regression.
    """
    H, W, num_features = feature_maps.shape
    predictions = np.zeros((H, W))
    
    for y in range(H):
        for x in range(W):
            input_vec = feature_maps[y, x, :]
            # Gradient Boosting Regression
            predictions[y, x] = regression_model.predict(input_vec)
            
    return predictions
```

**Parameters:**
*   **Number of features:** 13 [S1, unofficial].
*   **Aggregation functions:** max, sum, or mean [S1, unofficial].
*   **Regression model:** Gradient boosting regression [S1, unofficial].
*   **Threshold:** Small threshold for visibility (value not specified) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Geometry Misalignment:** Gaussian splats may misalign with scene geometry even when rendered appearance is correct, leading to depth error between true geometry and splat distribution [S1, unofficial]. PRIMU's error-based features help identify these regions.
*   **Undefined Depth Error:** Regions with undefined depth error (e.g., background) are represented as light gray in visualizations, indicating high uncertainty or lack of data [S1, unofficial].
*   **Generalization:** While trained on holdout data, the regression models show generalization capabilities to unseen scenes, enabling UE without additional holdout data for specific scenes [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The feature computation step requires rendering each training view and computing per-primitive contributions, which is $O(N_{views} \cdot N_{primitives} \cdot H \cdot W)$ if done naively, but optimized via rasterization. The regression step is $O(H \cdot W \cdot N_{trees})$ per novel view.
*   **Memory Complexity:** Requires storing 13 features per primitive and the rendered feature maps for holdout views during training.
*   **Strengths:** Post-hoc nature allows application to any trained GS model without retraining. Strong correlation with true errors, especially for depth UE and foreground objects. Generalizes to unseen scenes.
*   **Limitations:** Requires a small set of holdout views for training the regression model (though generalization reduces this need). Computationally more expensive than variance-based methods during the estimation phase due to rendering and regression.
*   **When to use:** Safety-critical domains like robotics and medical imaging where reliable uncertainty is essential. Active View Selection (AVS) to improve reconstruction quality and data efficiency.
*   **When not to use:** Real-time applications where the overhead of rendering feature maps and regression is prohibitive.

## Background
PRIMU was introduced by Stehr et al. in 2025 [S1, unofficial]. It addresses the open challenge of uncertainty estimation in Gaussian Splatting, which is critical for deploying GS in robotics and medicine. Existing methods often estimate per-primitive uncertainty during training using Fisher information or learned distributions. PRIMU departs from this by using post-hoc primitive-level representations of error and coverage. It is used for uncertainty estimation in robotics and medical imaging domains and for active view selection [S1, unofficial].
