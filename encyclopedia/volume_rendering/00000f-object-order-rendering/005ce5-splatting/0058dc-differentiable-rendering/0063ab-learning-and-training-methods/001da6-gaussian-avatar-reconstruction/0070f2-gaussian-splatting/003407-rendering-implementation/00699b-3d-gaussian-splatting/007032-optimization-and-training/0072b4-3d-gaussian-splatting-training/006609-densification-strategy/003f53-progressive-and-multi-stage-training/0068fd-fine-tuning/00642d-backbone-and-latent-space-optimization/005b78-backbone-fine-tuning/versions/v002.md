# Backbone Fine-tuning

Also called: Tri-plane Feature Adaptation

## Overview
Backbone Fine-tuning adapts the weights of a pre-trained 3D generator (backbone) alongside the decoder to generate Gaussian Splatting attributes, addressing the fact that splats have scale and rotation that influence adjacent regions, unlike NeRF's local color/density [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Pre-trained 3D generator weights, decoder network, and training data [S1].
*   **Output:** Fine-tuned backbone weights and decoder weights that produce Gaussian attributes for splatting [S1].

**Data Structures:**
*   **Backbone Copy:** A duplicate of the pre-trained 3D generator's weight tensor [S1].
*   **Decoder:** A network mapping features to Gaussian attributes [S1].

**Steps:**
1.  **Initialization:** Create an exact copy of the pre-trained 3D generator's weights [S1]. Initialize the decoder network [S1].
2.  **Joint Optimization:** During the training process, optimize the weights of both the backbone copy and the decoder simultaneously [S1].
3.  **Feature Adaptation:** The backbone adapts its tri-plane features to provide a basis suitable for Gaussian attributes, which require spatial extent (scale/rotation) beyond point-wise density/color [S1].

**Parameters:**
*   **Learning Rate:** Not given in the sources [S1].
*   **Optimizer:** Not given in the sources [S1].

**Edge Cases and Pitfalls:**
*   **Geometry Drift:** If the geometry branch is not frozen, fine-tuning can lead to positional updates that compensate for attribute errors, causing local blur and depth distortions [S2, unofficial].
*   **Misalignment:** Errors in predicted back-projection poses introduce misalignment with ground truth supervision cameras [S2, unofficial].

**Pseudocode:**
```python
# Helper: Deep copy of model weights
def copy_weights(source_model):
    return {k: v.clone().detach() for k, v in source_model.state_dict().items()}

# Helper: Initialize decoder network
def initialize_decoder():
    return GaussianDecoder()

# Helper: 3D Gaussian Splatting rasterization
def render(gaussian_attributes, camera_params):
    return rasterize(gaussian_attributes, camera_params)

# Helper: L1 + SSIM loss
def compute_loss(rendered_image, ground_truth_image):
    return 0.8 * l1_loss(rendered_image, ground_truth_image) + 0.2 * ssim_loss(rendered_image, ground_truth_image)

# Main procedure
pre_trained_3d_generator = load_pretrained_model()
backbone_copy = copy_weights(pre_trained_3d_generator)
decoder = initialize_decoder()
optimizer = torch.optim.Adam(list(backbone_copy.parameters()) + list(decoder.parameters()))
training_data = DataLoader(dataset, batch_size=1)

for batch in training_data:
    features = backbone_copy(batch.input_images, batch.pose_conditions)
    gaussian_attributes = decoder(features)
    rendered_image = render(gaussian_attributes, batch.camera_params)
    loss = compute_loss(rendered_image, batch.gt_image)
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()
```

## Subtopics

### Dual-branch Architecture for Attribute Learning
A variant that uses two independently parameterized branches initialized from the same pretrained DA3 weights to preserve depth and camera estimates while adapting Gaussian attributes [S2, unofficial]. It sets itself apart by explicitly freezing the geometry branch to prevent the positional distortions seen in standard backbone fine-tuning [S2, unofficial]. Choose this when preserving the original 3D generator's geometric accuracy is critical [S2, unofficial].
*   **Definition:** Two branches (geometry and attribute) initialized from pretrained DA3 weights [S2, unofficial].
*   **Steps:**
    1.  Initialize $\Phi_{geo}$ and $\Phi_{attr}$ from the same pretrained DA3 weights [S2, unofficial].
    2.  Freeze $\Phi_{geo}$, including its depth and camera heads [S2, unofficial].
    3.  Fine-tune only the last $K$ Transformer blocks of $\Phi_{attr}$ [S2, unofficial].
    4.  Map attribute features $F_C$ to per-pixel attributes $\xi$ using a DPT Gaussian decoder [S2, unofficial].
    5.  Obtain points by back-projection without predicted positional offsets; scales and rotations remain learnable [S2, unofficial].
*   **Formulas:**
    *   Geometry branch: $\hat{D}, \hat{\Pi}_C = \Phi_{geo}(I_C; Q_C)$ [S2, unofficial].
    *   Attribute branch: $F_C = \Phi_{attr}(I_C; Q_C)$ [S2, unofficial].
*   **Parameters:**
    *   $K$: Number of last Transformer blocks in the attribute branch to fine-tune. Typical value: 10 [S2, unofficial].
*   **Pitfalls:** Fine-tuning the geometry branch or learning positional offsets worsens metrics (LPIPS increases by 16.6% and 23.2% on ETH3D/DTU) because positional updates compensate for attribute errors [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Increases training time due to the optimization of the backbone weights in addition to the decoder and Gaussian parameters [S1].
*   **Memory Complexity:** Requires storing the backbone weights and their gradients, effectively doubling the memory footprint for the generative model compared to a frozen backbone [S1].
*   **Scaling:** Allows the generative prior to adapt to the specific statistical distribution of Gaussian attributes, potentially improving generalization to diverse scenes [S1].
*   **Strengths:** Adapts the tri-plane features to better support the spatial extent of Gaussians, which NeRF-style local features do not inherently provide [S1].
*   **Limitations:** Risk of geometric distortion if geometry is not frozen; requires careful tuning of the number of fine-tuned blocks ($K$) in dual-branch variants [S2, unofficial].
*   **When to use:** When using a pre-trained 3D generator and standard decoding fails to produce high-quality Gaussian attributes due to mismatched feature semantics [S1].
*   **When not to use:** When geometric fidelity of the original generator is paramount and cannot be preserved by freezing [S2, unofficial].

## Background
Originated in the context of adapting 3D-aware generative models for Gaussian Splatting [S1]. The method was introduced to address the fundamental mismatch between NeRF-style local density/color representations and the extended, oriented nature of 3D Gaussians [S1]. It is used in feed-forward 3DGS reconstruction pipelines where a pre-trained 3D generator serves as the backbone [S1][S2, unofficial].
