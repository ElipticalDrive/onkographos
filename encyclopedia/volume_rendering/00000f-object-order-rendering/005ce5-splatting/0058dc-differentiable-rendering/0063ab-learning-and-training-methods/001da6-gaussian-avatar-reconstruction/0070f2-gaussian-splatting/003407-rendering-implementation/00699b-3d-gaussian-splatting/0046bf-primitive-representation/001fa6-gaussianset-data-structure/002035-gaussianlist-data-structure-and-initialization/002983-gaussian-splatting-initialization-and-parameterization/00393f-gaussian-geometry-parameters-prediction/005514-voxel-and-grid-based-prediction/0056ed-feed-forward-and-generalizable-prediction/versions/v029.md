# Feed-forward and Generalizable Prediction

Also called: GRM, Generalizable Reconstruction Method

## Overview
Feed-forward and generalizable prediction maps input images directly to a set of 3D Gaussian parameters $\mathcal{G} = \{\mu, \Sigma, \alpha, c\}$ in a single inference pass, eliminating the per-scene gradient descent optimization required by standard 3D Gaussian Splatting [16746-feed-forward-generalizable-reconstruction.md]. This family is distinguished from iterative optimization by its reliance on learned priors from large-scale datasets to generalize to unseen scenes, and from direct pixel-wise regression by its use of structured intermediate representations (such as voxel grids or latent spaces) to resolve cross-view inconsistencies and geometric ambiguities [16746-feed-forward-generalizable-reconstruction.md].

## Shared principles
All methods in this family share the core objective of mapping input image features to a set of 3D Gaussian parameters $\mathcal{G} = \{\mu, \Sigma, \alpha, c\}$ without per-scene gradient descent [16746-feed-forward-generalizable-reconstruction.md].

1.  **Input Representation:** Inputs are typically one or more RGB images $I \in \mathbb{R}^{H \times W \times 3}$. Some methods require known camera poses $P$, while others (e.g., [Splatt3R](16423-splatt3r.md), [ZeroGS](16425-zerogs.md)) predict poses or operate on uncalibrated inputs [16746-feed-forward-generalizable-reconstruction.md].
2.  **Feature Encoding:** A shared encoder (e.g., Vision Transformer, CNN) extracts multi-scale features from the input images. Cross-attention or cost volumes are often used to aggregate multi-view information [16746-feed-forward-generalizable-reconstruction.md].
3.  **Primitive Prediction:** A decoder head predicts Gaussian attributes. These attributes are usually:
    *   **Mean ($\mu$):** 3D position.
    *   **Covariance ($\Sigma$):** Defined by scale $s$ and rotation $r$ (quaternion or 6D).
    *   **Opacity ($\alpha$):** Scalar.
    *   **Color ($c$):** Spherical Harmonics (SH) coefficients or constant RGB [16746-feed-forward-generalizable-reconstruction.md].
4.  **Differentiable Rendering:** The predicted Gaussians are rendered into target views using differentiable rasterization to compute reconstruction losses (e.g., L1, SSIM, LPIPS) for training the network [16746-feed-forward-generalizable-reconstruction.md].
5.  **Generalization:** The network is trained on a large dataset of scenes to learn priors about geometry and appearance, allowing inference on unseen scenes [16746-feed-forward-generalizable-reconstruction.md].

## Subtopics

### [HFGaussian](16422-hfgaussian.md)
HFGaussian is a generalizable, feed-forward framework for real-time 3D human avatar reconstruction that simultaneously estimates novel views, 3D pose, and biomechanical features (such as dense pose and 3D keypoints) from sparse input images. Unlike sibling methods that rely on parametric body models (e.g., SMPL) or fail to integrate structural biomechanics, HFGaussian uses Gaussian splatting to represent the human subject and its associated features directly. It builds on [Feed-forward and Generalizable Prediction](15832-feed-forward-and-generalizable-prediction.md) by introducing a "feature splatting" mechanism that decouples human feature learning from the geometric Gaussian parameters, allowing different frequencies of features to be rendered efficiently without per-subject optimization.

### ZeroGS
ZeroGS is a pipeline for training 3D Gaussian Splatting (3DGS) from hundreds of unposed and unordered images without requiring Structure-from-Motion (SfM) tools like COLMAP [S1, unofficial]. It differs from its siblings by leveraging a pretrained foundation model (Spann3R) as a neural scene representation and employing an incremental training buffer to progressively register images and refine poses [S1, unofficial]. Unlike [ACE0](16422-ace0.md), which predicts sparse points using CNNs, ZeroGS predicts dense pointmaps and 3D Gaussians using transformers and optimizes the scene via rendering loss rather than reprojection error [S1, unofficial].

### [Deformation Field MLP](16430-deformation-field-mlp.md)
The Deformation Field MLP is a coordinate-based neural network that predicts spatial offsets for 3D Gaussian primitives to model dynamic geometry or correct canonical shapes. It maps input coordinates (and optionally time) to deviations in position, rotation, and scale, serving as a smooth prior to prevent overfitting to sparse or noisy views. Unlike grid-based methods, it uses a compact MLP structure, making it suitable for dynamic scenes with high-rank variations where explicit point-based rendering exacerbates complexity.

### [Shape Completion Training](16514-shape-completion-training.md)
Shape Completion Training is a feed-forward method that predicts all 14 3D Gaussian attributes from partial inputs without requiring target coordinates or per-scene optimization. It distinguishes itself from sibling methods by employing a fixed 2×2 folding grid to expand a small set of coarse primitives into a dense Gaussian set, enabling reconstruction of missing geometry in occluded or sparse scenes.

### [Feed-forward Generalizable Reconstruction](16746-feed-forward-generalizable-reconstruction.md)
Feed-forward generalizable reconstruction maps input images directly to a set of 3D Gaussian parameters $\mathcal{G} = \{\mu, \Sigma, \alpha, c\}$ in a single inference pass, eliminating the per-scene gradient descent optimization required by standard 3D Gaussian Splatting [16746-feed-forward-generalizable-reconstruction.md]. This family is distinguished from iterative optimization by its reliance on learned priors from large-scale datasets to generalize to unseen scenes, and from direct pixel-wise regression by its use of structured intermediate representations (such as voxel grids or latent spaces) to resolve cross-view inconsistencies and geometric ambiguities [16746-feed-forward-generalizable-reconstruction.md].

### [Feature Uplifting via Forward Rendering](16969-feature-uplifting-via-forward-rendering.md)
Feature Uplifting via Forward Rendering is a method to estimate 3D language features $f \in \mathbb{R}^d$ for 3D Gaussians from observed 2D features $F_{2D} \in \mathbb{R}^d$ by formulating the problem as a Maximum Likelihood (ML) or Maximum-a-Posteriori (MAP) estimation, assuming uniform prior and Gaussian noise. It differs from back-projection methods (e.g., conventional semantic feature learning) by leveraging the forward rendering process to establish precise correspondence, eliminating costly back-projection or iterative optimization. It builds on [Feed-forward and Generalizable Prediction](15832-feed-forward-and-generalizable-prediction.md).

### [Occam's LGS](16973-occam-s-lgs.md)
Occam's LGS is a training-free method for lifting 2D language features to 3D Gaussian representations by applying Occam’s razor to the forward rendering process of 3D Gaussian Splatting. It solves the problem of expensive iterative optimization in feature space by computing weighted multi-view feature aggregation directly from the alpha blending weights of the standard color rendering pass. Unlike sibling methods that rely on scene-specific autoencoders, quantization, or costly semantic feature rendering, Occam's LGS supports arbitrary-dimensional uncompressed features without compromising training speed, achieving a two-order-of-magnitude speed-up while maintaining state-of-the-art performance for open-set vision-language tasks.

### [Fast Feedforward 3D Gaussian Splatting Compression](19199-fast-feedforward-3d-gaussian-splatting-compression.md)
Fast Feedforward 3D Gaussian Splatting Compression (FCGS) is an autoencoder-based compression method that encodes 3D Gaussian attributes into a latent space using hyperpriors and context models, addressing the fidelity drop caused by the non-invertibility of MLPs in geometry attributes. Unlike anchor-based quantization methods that modify Gaussian locations and require finetuning, FCGS creates context grids in a feed-forward manner without altering the original Gaussian positions.

### SHARE
SHARE is a pose-free framework for generalizable 3D Gaussian splatting that estimates camera poses via predicted rays and uses anchor-aligned coarse-to-fine geometry estimation to predict 3D Gaussian parameters without ground-truth poses [S1, unofficial]. It sets itself apart from sibling methods like [PixelSplat](16423-pixelsplat.md) and [MVSplat](16423-mvsplat.md) by explicitly embedding pose awareness into multi-view cost volumes via Plücker rays, making it robust to pose inaccuracies where generalizable 3D Gaussian splatting methods are highly sensitive [S1, unofficial].

### [Feed-Forward Hierarchical Gaussian Diffusion](19615-feed-forward-hierarchical-gaussian-diffusion.md)
HiGDiff is a feed-forward reconstruction method for computed tomography (CT) that predicts a set of 3D Gaussian primitives from degraded projections without per-scene optimization. It solves the problem of sparse-view, low-dose, or limited-angle CT reconstruction by using two explicit Gaussian banks (structure and detail) initialized from anatomical cues and refined via a sequential structure-to-detail diffusion hierarchy. It differs from single-bank Gaussian reconstruction by maintaining separate banks for global attenuation geometry and residual detail, and from dense voxel diffusion by operating on explicit Gaussian primitives with a sequential hierarchy.

### [Amortized Image Reconstruction (AIR)](19780-amortized-image-reconstruction-air.md)
Amortized Image Reconstruction (AIR) is a self-supervised feed-forward framework that reconstructs a target image into a set of 2D Gaussian primitives in a single network pass, eliminating the costly per-image iterative optimization required by prior methods like GaussianImage. Unlike Instant-GI, which relies on handcrafted priors and pseudo-labels for initialization, AIR uses a stage-wise residual architecture to progressively predict Gaussian primitives from reconstruction residuals, achieving higher quality with encoding times of 160–300 ms.

### UniQueR
UniQueR is a feedforward framework for fast 3D reconstruction from unposed images using sparse learnable 3D queries [S1, unofficial]. It predicts camera-to-world transforms and per-view local point maps, then uses queries to spawn Gaussians rendered via differentiable splatting for supervision [S1, unofficial]. It sets itself apart from siblings like [TokenGS](16422-tokengs.md) by decoupling 3D Gaussian prediction from pixels with learnable implicit tokens, and avoids the quadratic complexity of full self-attention on concatenated tokens by using decoupled attention between image tokens and 3D queries [S1, unofficial].

### GS3
GS3 is an efficient self-supervised learning framework for learning point cloud representations by integrating fast 3D Gaussian Splatting into a rendering-based pretext task [S1, unofficial]. It solves the problem of high computational cost and memory intensity inherent in existing volume rendering-based self-supervised methods [S1, unofficial]. Unlike its sibling [Ponder](16421-ponder.md), which uses differentiable volume rendering with ray marching, GS3 employs a tile-based rasterizer to render 3D Gaussians, achieving significantly faster pre-training speeds and lower memory usage [S1, unofficial].

### [DIF-Gaussian](20639-dif-gaussian.md)
DIF-Gaussian is a feed-forward neural network that reconstructs a 3D volume from multi-view 2D projections by predicting 3D Gaussian parameters at sampled points and decoding features via Gaussian interpolation. It differs from sibling methods by explicitly modeling the feature aggregation step as a differentiable Gaussian splatting operation, allowing the network to learn spatial priors directly in the Gaussian domain rather than through standard grid-based or point-based interpolation.

### [Compact Feed-Forward 3D Gaussians via Saliency-Guided Primitive Merging](20687-compact-feed-forward-3d-gaussians-via-saliency-guided-primit.md)
Compact Feed-Forward 3D Gaussians via Saliency-Guided Primitive Merging is a post-processing pipeline that consolidates redundant, per-pixel 3D Gaussians produced by any feed-forward Gaussian predictor into a compact, content-adaptive set. It solves the inefficiency of per-pixel primitives by grouping spatially coherent Gaussians via saliency-guided superpixel segmentation, compressing them into latent representations, and merging them across views, retaining visual quality at approximately 1/20th of the original primitive count. Unlike uniform discretization or detection-based reduction methods, it is backbone-agnostic and operates as a plug-in module without retraining the underlying feed-forward network.

### 3D-aware Image Synthesis via Sparse Voxel Grids
A 3D-aware image synthesis generator that predicts color and density values on a sparse voxel grid, conditioned on camera pose [S2]. It uses a mapping network with 2 layers and 64 channels, setting the channel base to 4000 (reduced from StyleGAN2's 32768) to account for higher parameter count in 3D convolutions [S2]. It implements skip connections that add an upsampled version of the output grid of the previous layer to the input of the next layer [S2]. It conditions the generator on a camera pose represented by a rotation matrix and a translation vector, yielding a 12-dimensional input vector [S2]. It outputs coefficients of spherical harmonics for color, using degree 0 (single coefficient per color channel) [S2]. It multiplies the network's density output by a factor of 30 to facilitate generating high density values for sharp surfaces [S2].

### RnD-Avatar
A 3DGS-based human avatar modeling framework that reconstructs animatable and relightable human avatars from monocular video by decomposing geometry and appearance attributes and using dynamic skinning weights for pose-variant deformation [S3]. It encodes Gaussian attributes using the Gaussian Attributes Encoder $D_G$, which consists of two sub-encoders $D_g$ and $D_a$. Both are multi-layer perceptrons (MLPs) that take the Gaussian position $x$ as input and output the corresponding geometric and appearance attributes, respectively [S3]. It articulates the human avatar by applying Linear Blend Skinning (LBS) transformations using the dynamic skinning weights $W_{\Theta_t}$ to deform the 3D Gaussians from canonical space to posed space [S3]. It optimizes the RnD-Avatar through a Physically-Based Rendering (PBR) process to optimize geometric attributes (position and normal) and appearance attributes (albedo, roughness, and visibility) [S3]. It renders photorealistic images given an environmental light by performing a PBR process on the optimized avatar [S3].

### Learned Refinement
Starts from the same feed-forward scene initialization [S4, unofficial]. It keeps the Gaussian centers fixed during all updates [S4, unofficial]. It averages over $N = 4, 8, 16$ input views during evaluation [S4, unofficial]. On ETH3D, learned refinement improves PSNR by 0.64 dB compared to the feed-forward baseline [S4, unofficial]. It outperforms Direct Gradient Descent (Adam) on all four metrics (PSNR, SSIM, LPIPS, DISTS) and yields stronger surface quality with fewer artifacts [S4, unofficial].

### Surfel Renderer Property Extraction
Retrieves Gaussian attributes: xyz, opacity, scale, rot, and features (SHs) [S5, unofficial]. If `compute_cov3D_python` is true, it computes pre-computed covariance: `cov3D_precomp = gaussian_model.get_covariance(self.scaling_modifier)`. Otherwise, it keeps scales and rotations separate [S5, unofficial]. If `convert_SHs_python` is true, it converts spherical harmonics to RGB: reshapes features to `(-1, 3, (gaussian_model.max_sh_degree+1)**2)`, computes view direction `dir_pp = (xyz - camera_center)`, normalizes it, evaluates SHs using `eval_sh`, and clamps result to `[0.0, 1.0]` via `torch.clamp_min(sh2rgb + 0.5, 0.0)` [S5, unofficial]. If `convert_SHs_python` is false, it keeps SHs as raw features: `shs = gaussian_model.get_features` [S5, unofficial]. Default parameters are: kernel_size: 0, scaling_modifier: 1, white_background: False, convert_SHs_python: False, compute_cov3D_python: False [S5, unofficial].

### Neural Gaussians
Neural fields used to predict the anisotropic shape and view-dependent color of 3D Gaussians within the HyRF framework [S6].

### 3D Gaussian Prediction from Point Cloud Features
Predicts scene 3D Gaussian parameters from point cloud features in a point-aligned manner, allowing simultaneous optimization of multiple scenes without per-scene optimization [S7, unofficial]. It uses a cost volume module or epipolar line transformer to perform cross-view feature encoding on input features $F_1, F_2$ to produce encoded features $\hat{F}_1, \hat{F}_2$ [S7, unofficial]. It passes encoded features $\hat{F}$ through feed-forward network $f_\theta$ to predict Gaussian parameters [S7, unofficial]. The mapping is defined as $f_\theta : \hat{F}_i^{(H \times W)} \mapsto k \times \{ (\Delta \mu_j, \Sigma_j, \alpha_j, c_j) \}_{j=1}^{(H \times W)}$ where $f_\theta$ is a feed-forward network, $\hat{F}_i$ are encoded point cloud features, $k$ is the number of Gaussians per point, and parameters are mean offset $\Delta \mu$, covariance $\Sigma$, opacity $\alpha$, and SH coefficients $c$ [S7, unofficial]. The mean is computed as $\mu_j = p_i + \Delta \mu_j$ where $p_i$ is the 3D coordinate of the $j$-th point and $\Delta \mu_j$ is the offset between the point and the predicted Gaussian center $\mu_j$ [S7, unofficial]. The total number of 3D Gaussians is $k \times (H \times W) \times N$ for $N$-view input RGB-D images with shape $H \times W$ [S7, unofficial].
