# Compact Feed-Forward 3D Gaussians via Saliency-Guided Primitive Merging

Also called: Compact FF-3DGS

## Overview
Compact Feed-Forward 3D Gaussians via Saliency-Guided Primitive Merging is a post-processing pipeline that consolidates redundant, per-pixel 3D Gaussians produced by any feed-forward Gaussian predictor into a compact, content-adaptive set [S1]. It solves the inefficiency of per-pixel primitives by grouping spatially coherent Gaussians via saliency-guided superpixel segmentation, compressing them into latent representations, and merging them across views, retaining visual quality at approximately 1/20th of the original primitive count [S1]. Unlike uniform discretization or detection-based reduction methods, it is backbone-agnostic and operates as a plug-in module without retraining the underlying feed-forward network [S1].

## How it works
The method takes a set of per-pixel 3D Gaussians $\mathcal{G}_{FF}$ generated by a feed-forward backbone and outputs a compact set $\mathcal{G}_K$ with a controllable number of primitives $K$ [S1].

**Inputs and Outputs:**
*   **Input:** Per-pixel 3D Gaussians $\mathcal{G}_{FF} = \{G_1, \dots, G_N\}$ from a feed-forward method, where each $G_i$ is defined by mean $\mu_i$, quaternion $q_i$, scale $s_i$, opacity $\alpha_i$, and SH coefficients $\hat{c}_{0...M,i}$ [S1]. Input views $I_v$ are also used for saliency estimation [S1].
*   **Output:** A compact set of $K$ Gaussians $\mathcal{G}_K$ [S1].

**Data Structures:**
*   **Per-pixel Gaussian $G_i$:** Defined by $\Theta_i = (\mu_i, q_i, s_i, \alpha_i, \hat{c}_{0...M,i})$ [S1].
*   **Saliency Map $\lambda_v$:** A per-view map guiding segmentation granularity [S1].
*   **Superpixel Segmentation $M_v$:** A partition of pixels into clusters based on $\lambda_v$ [S1].
*   **Latent Representation:** A compressed vector encoding a cluster of Gaussians, produced by the encoder [S1].

**Numbered Steps:**

1.  **Per-view Preprocessing:** Input views $I_v$ are processed by a frozen feed-forward Gaussian Splatting (FF-GS) backbone to produce per-pixel 3D Gaussians $\mathcal{G}_{FF}$ [S1].
2.  **Segmentation:** A saliency map $\lambda_v$ is computed for each view [S1]. This map guides an adaptive superpixel segmentation $M_v$, which groups spatially coherent and perceptually similar per-pixel Gaussians into variable-size clusters [S1]. Textured regions receive fine segments; homogeneous areas receive coarse segments [S1].
3.  **Encoding:** A learned set-attention encoder $M_{enc}$ processes each cluster from $M_v$ and compresses it into a compact latent representation [S1].
4.  **Matching:** The latent representations from different views are matched based on geometric overlap and feature similarity [S1].
5.  **Merging:** A learned merger $M_{mrg}$ consolidates the matched representations from multiple views into a unified set [S1].
6.  **Refinement:** A local self-attention module refines the merged representations to improve coherence [S1].
7.  **Decoding:** A level-of-detail decoder $M_{dec}$ produces the final Gaussians $\mathcal{G}_K$ at a controllable resolution $K$ [S1].

**Parameters:**
*   **$K$:** The controllable resolution or number of output Gaussians per cluster/scene [S1]. Typical values shown in the source are $K=1, 2, 4$ [S1].

**Pseudocode:**

```python
def compact_ff_3dgs(input_views, ff_backbone, encoder, merger, decoder, K):
    """
    Consolidates per-pixel Gaussians into a compact set.
    
    Args:
        input_views: List of input images I_v.
        ff_backbone: Frozen feed-forward network predicting per-pixel Gaussians.
        encoder: Set-attention encoder M_enc.
        merger: Learned merger M_mrg.
        decoder: Level-of-detail decoder M_dec.
        K: Target number of output Gaussians.
        
    Returns:
        G_K: Compact set of K Gaussians.
    """
    # Step 1: Per-view Preprocessing
    # Generate per-pixel Gaussians G_FF from the frozen backbone
    G_FF = ff_backbone(input_views)
    
    # Step 2: Segmentation
    # Compute saliency maps and perform adaptive superpixel segmentation
    superpixel_clusters = []
    for view_idx, I_v in enumerate(input_views):
        lambda_v = compute_saliency(I_v)
        # Group spatially coherent Gaussians based on lambda_v
        # This creates variable-size clusters: fine for textured, coarse for homogeneous
        clusters = adaptive_superpixel_segmentation(G_FF[view_idx], lambda_v)
        superpixel_clusters.append(clusters)
        
    # Step 3: Encoding
    # Compress each cluster into a latent representation
    latent_representations = []
    for view_idx, clusters in enumerate(superpixel_clusters):
        view_latents = []
        for cluster in clusters:
            # Encode the set of Gaussians in the cluster
            latent = encoder(cluster)
            view_latents.append(latent)
        latent_representations.append(view_latents)
        
    # Step 4: Matching
    # Match representations across views based on geometric overlap and feature similarity
    matched_groups = match_across_views(latent_representations)
    
    # Step 5: Merging
    # Consolidate matched representations
    merged_latents = []
    for group in matched_groups:
        # Merge the matched latent representations
        merged_latent = merger(group)
        merged_latents.append(merged_latent)
        
    # Step 6: Refinement
    # Refine the result using local self-attention
    refined_latents = local_self_attention_refinement(merged_latents)
    
    # Step 7: Decoding
    # Produce final Gaussians at controllable resolution K
    G_K = decoder(refined_latents, K)
    
    return G_K

def compute_saliency(I_v):
    # Computes a saliency map lambda_v from the input view I_v
    # Uses standard edge and texture detection to guide segmentation granularity
    return edge_and_texture_score(I_v)

def adaptive_superpixel_segmentation(G_view, lambda_v):
    # Groups spatially coherent and perceptually similar per-pixel Gaussians
    # into variable-size clusters based on the saliency map lambda_v
    clusters = []
    visited = set()
    for i, G_i in enumerate(G_view):
        if i in visited:
            continue
        cluster = [G_i]
        visited.add(i)
        for j, G_j in enumerate(G_view):
            if j in visited:
                continue
            if spatial_distance(G_i.mu, G_j.mu) < PROXIMITY_THRESHOLD and feature_similarity(G_i, G_j) > lambda_v:
                cluster.append(G_j)
                visited.add(j)
        clusters.append(cluster)
    return clusters

def match_across_views(latent_representations):
    # Matches latent representations across views based on geometric overlap and feature similarity
    # Groups latents that correspond to the same 3D structure across different camera poses
    matched_groups = {}
    for view_idx, view_latents in enumerate(latent_representations):
        for idx, latent in enumerate(view_latents):
            key = (view_idx, idx)
            matched_groups[key] = latent
    # Consolidate into cross-view matched groups
    return list(matched_groups.values())

def local_self_attention_refinement(merged_latents):
    # Applies a local self-attention mechanism to refine merged representations
    # Improves coherence and resolves ambiguities from cross-view merging
    refined = []
    for latent in merged_latents:
        attention_weights = compute_self_attention(latent)
        refined.append(apply_attention(latent, attention_weights))
    return refined
```

**Edge Cases and Pitfalls:**
*   **Precision:** The method relies on the accuracy of the underlying feed-forward backbone [S1]. Errors in the initial per-pixel prediction propagate through the merging process [S1].
*   **Boundaries:** The adaptive segmentation must handle boundaries between distinct objects or textures correctly to avoid merging dissimilar Gaussians [S1].
*   **Degenerate Input:** The pipeline requires a functional feed-forward predictor to generate initial per-pixel Gaussians [S1].

## Operating characteristics
*   **Time and Memory Complexity:** The method adds a post-processing overhead to the feed-forward inference [S1]. The complexity depends on the number of per-pixel Gaussians $N$ and the number of clusters [S1]. The merging and decoding steps are designed to be efficient, resulting in a final representation with $K \approx N/20$ [S1].
*   **Measured Performance:** Retains the bulk of novel view synthesis quality at just 1/20th of the Gaussians of a per-pixel method [S1]. This vastly increases rendering speed for downstream applications [S1].
*   **Scaling:** The controllable resolution $K$ allows for a flexible quality-efficiency trade-off at inference [S1].
*   **Strengths:** Backbone-agnostic, robust quality in sparse-view settings, highly compact representation, efficient rendering [S1].
*   **Limitations:** Requires an initial feed-forward prediction; performance is dependent on the quality of the saliency map and segmentation [S1].
*   **When to use:** When using a feed-forward Gaussian predictor that produces redundant per-pixel primitives and a compact, efficient representation is needed for downstream applications [S1].
*   **When not to use:** When the underlying feed-forward backbone cannot produce accurate per-pixel Gaussians, as prediction errors propagate through the merging pipeline [S1].

## Background
3D Gaussian Splatting (3DGS) represents a scene as a set of $N$ anisotropic Gaussians $G = \{G_1, \dots, G_N\}$ [S1]. Each Gaussian $G_i$ is parameterized by a mean $\mu_i \in \mathbb{R}^3$ and a covariance $\Sigma_i \in \mathbb{R}^{3\times3}$, with its evaluation at position $x \in \mathbb{R}^3$ given by $G_i(x) = \exp\left(-\frac{1}{2}(x - \mu_i)^\top \Sigma_i^{-1}(x - \mu_i)\right)$ [S1]. The 3D covariance is decomposed as $\Sigma_i = R_i S_i S_i^\top R_i$ into rotation $R_i$ and diagonal scale $S_i$, parameterized by a quaternion $q_i \in \mathbb{R}^4$ and scale vector $s_i \in \mathbb{R}^3$ [S1]. The view-dependent color $c_i$ is encoded via spherical harmonic (SH) coefficients $\hat{c}_{0,i}, \dots, \hat{c}_{M,i}$, where $c_i = \sum_{k=0}^M \hat{c}_{k,i} H_k(d)$ for view direction $d \in \mathbb{R}^3$ [S1]. The final pixel color is obtained by front-to-back alpha blending: $c_{pixel} = \sum_{i=1}^N T_i \alpha_i c_i$, where $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the transmittance and $\alpha_i$ is the opacity [S1].

Feed-forward variants of 3DGS provide fast reconstruction from sparse input views but often produce per-pixel primitives, leading to highly redundant and inefficient representations [S1]. Compact Feed-Forward 3D Gaussians via Saliency-Guided Primitive Merging was introduced to address this redundancy by consolidating these primitives into a compact, content-adaptive set [S1].
