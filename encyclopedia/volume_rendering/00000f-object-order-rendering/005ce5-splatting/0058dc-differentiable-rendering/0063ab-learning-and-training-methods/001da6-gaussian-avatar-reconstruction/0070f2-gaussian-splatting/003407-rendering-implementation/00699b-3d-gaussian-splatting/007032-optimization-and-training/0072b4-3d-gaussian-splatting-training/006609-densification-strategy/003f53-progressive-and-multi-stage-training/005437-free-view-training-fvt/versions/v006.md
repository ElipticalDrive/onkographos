# Free-View Training (FVT)
## Overview
Free-View Training (FVT) is a training strategy for generalizable 3D Gaussian Splatting (3DGS) that adds geometrical constraints on Gaussian localization to disentangle model performance from the specific number of input views [S1, S2]. It enables robust novel view synthesis across broader view ranges regardless of the input view count by supervising image renderings in broader view interpolations [S1, S2]. Unlike methods that fix the number of context views, FVT trains on long sequences to improve generalization [S2].
## How it works
**Inputs:** A set of training images (long sequences), camera poses, and intrinsic parameters.
**Outputs:** A set of 3D Gaussian primitives $\mathcal{G}$ with optimized attributes (position, covariance, opacity, spherical harmonics coefficients).

**Data Structures:**
The method operates on the Gaussian set $\mathcal{G}$ defined in [Densification Strategy](6234-densification-strategy.md). Each Gaussian $g_i$ typically contains position $\mathbf{p}_i$, covariance matrix $\mathbf{\Sigma}_i$ (or rotation $\mathbf{R}_i$ and scale $\mathbf{s}_i$), opacity $\alpha_i$, and color coefficients.

**Parameters:**
- $T$: The number of context views randomly sampled during training. Typical value: $T \in [2, 8]$ [S1].

**Steps:**
1. **Context View Sampling:** For each training iteration, randomly sample $T$ context views from the available sequence [S1].
2. **Feature Extraction and Aggregation:** Extract features from the sampled context views. The efficiency of this step allows for long-sequence training [S1].
3. **Gaussian Initialization/Update:** Initialize or update the 3D Gaussian primitives based on the aggregated features. In FreeSplat, this may involve predicting initial Gaussian triplets via low-cost cross-view aggregation [S2].
4. **Rendering:** Render images from novel viewpoints (broader view interpolations) using the current set of Gaussians $\mathcal{G}$ [S1].
5. **Supervision:** Compute the loss between the rendered images and the ground truth images from the broader view interpolations. The supervision is applied on full resolution to encourage high-resolution renderings, even if lower-resolution maps are used for unprojection [S1].
6. **Optimization:** Update the Gaussian parameters (and potentially the feature extractor weights) using gradient descent to minimize the rendering loss [S1, S2].
7. **Iteration:** Repeat steps 1-6 for the duration of the training, ensuring the model is exposed to varying numbers of views and broader view ranges [S2].

**Pseudocode:**
```python
def free_view_training(G, context_images, camera_poses, intrinsics, T=4, num_iterations=10000):
    """
    G: Set of 3D Gaussian primitives
    context_images: List of all available training images
    camera_poses: List of camera poses for all images
    intrinsics: Camera intrinsics
    T: Number of context views to sample per iteration
    num_iterations: Total number of training steps
    """
    for iteration in range(num_iterations):
        # Step 1: Randomly sample T context views
        sampled_indices = random.sample(range(len(context_images)), T)
        sampled_images = [context_images[i] for i in sampled_indices]
        sampled_poses = [camera_poses[i] for i in sampled_indices]
        
        # Step 2 & 3: Feature extraction and Gaussian initialization/update
        # This step depends on the specific architecture (e.g., FreeSplat's triplet fusion)
        # [G] Assuming a function that takes sampled views and returns updated Gaussians
        G = feature_extraction_and_aggregation(sampled_images, sampled_poses, G)
        
        # Step 4: Render from broader view interpolations
        # [G] Select a novel view or a set of novel views for supervision
        novel_view_idx = random.choice(range(len(context_images)))
        target_image = context_images[novel_view_idx]
        target_pose = camera_poses[novel_view_idx]
        
        rendered_image = render_3dgs(G, target_pose, intrinsics)
        
        # Step 5: Compute loss
        loss = compute_rendering_loss(rendered_image, target_image)
        
        # Step 6: Optimize
        gradients = compute_gradients(loss, G)
        G = update_gaussians(G, gradients)
        
    return G
```

**Edge Cases and Pitfalls:**
- **Precision:** Supervision on full resolution requires sufficient memory and computational resources [S1].
- **Boundaries:** The random sampling of $T$ views must ensure sufficient overlap for robust feature matching [S2].
- **Degenerate Input:** If the sequence has insufficient geometric diversity, the geometrical constraints may not be effective [S1].

## Operating characteristics
- **Time Complexity:** Depends on the number of Gaussians and the resolution of the rendered images. The efficient feature extraction allows for long-sequence training [S1].
- **Memory Complexity:** Proportional to the number of Gaussians and the size of the feature maps [S2].
- **Measured Performance:** State-of-the-art novel view synthesis performance in color map quality and depth map accuracy across different numbers of input views on indoor datasets like ScanNet and Replica [S2].
- **Scaling:** Enables inference more efficiently and reduces redundant Gaussians, offering the possibility of feed-forward large scene reconstruction without depth priors [S2].
- **Strengths:** Disentangles generalizable 3DGS from specific view counts; robust view synthesis across broader view ranges; efficient inference [S1, S2].
- **Limitations:** Requires efficient feature extraction to handle long sequences [S1].
- **When to use:** When generalizable 3DGS is needed for varying numbers of input views and broader view ranges [S1, S2].
- **When not to use:** When the scene is static and the number of input views is fixed and sufficient [G].

## Background
Free-View Training (FVT) was proposed in the context of generalizable 3D Gaussian Splatting for efficient indoor scene reconstruction [S1, S2]. It was introduced to address the limitation of 3DGS models that are tied to a specific number of input views, enabling them to generalize to broader view ranges [S1, S2]. The method is part of the FreeSplat and FreeSplat++ frameworks [S1, S2].
