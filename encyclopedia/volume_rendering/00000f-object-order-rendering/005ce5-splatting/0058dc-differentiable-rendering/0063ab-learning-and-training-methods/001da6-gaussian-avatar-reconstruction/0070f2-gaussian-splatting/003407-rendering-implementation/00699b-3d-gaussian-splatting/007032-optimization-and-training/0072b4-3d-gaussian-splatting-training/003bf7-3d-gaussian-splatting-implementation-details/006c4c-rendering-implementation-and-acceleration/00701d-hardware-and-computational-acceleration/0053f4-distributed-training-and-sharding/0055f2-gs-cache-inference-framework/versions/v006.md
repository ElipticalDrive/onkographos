# GS-Cache Inference Framework

Also called: GS-Cache

## Overview
GS-Cache is a holistic rendering framework designed to support real-time rendering of large-scale 3D Gaussian Splatting (3DGS) models at the city level, achieving >72 FPS at binocular 2K resolution by using a cache-centric de-redundancy pipeline and elastic parallel scheduling [S1, unofficial]. It specifically targets 'Structured Gaussian derivation methods' (like Scaffold-GS and Octree-GS) which use anchors to derive neural Gaussians, addressing the bottleneck of the 'Gaussian Derivation Stage' (decoding anchor features) which dominates computation time [S1, unofficial]. Unlike native 3DGS or unstructured methods, GS-Cache optimizes the derivation stage by caching decoded parameters, while leaving the rasterization stage uncached to preserve visual quality against occlusion changes [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Camera pose (view/projection matrices), structured 3DGS model (anchors, MLP weights $\theta$, anchor features), previous frame's cache state [S1, unofficial].
*   **Output:** Rendered image (binocular 2K), updated cache state [S1, unofficial].

**Data Structures:**
*   **Cache:** Stores decoded Gaussian parameters indexed by anchor ID, mapping anchor indices to cache indices [S1, unofficial]. Exact memory layout, fields, sizes, and bit packing are Not given in the sources.
*   **Anchor Set ($X$):** The set of anchors required for decoding in the current frame [S1, unofficial].
*   **Newly Decoded Anchors ($X_k'$):** The subset of anchors from $X$ that were newly decoded from the previous $k$ frames [S1, unofficial].

**Steps:**
1.  **Binocular De-redundancy:** Process camera inputs to identify unique view frustums, reducing redundant anchor queries for binocular rendering [S1, unofficial].
2.  **Anchor Filtering:** Compute anchor indices from the camera input to filter the global anchor set and identify $X$ [S1, unofficial].
3.  **Index Mapping:** Translate anchor indices to cache indices to locate existing Gaussian parameters in the cache [S1, unofficial].
4.  **Cache Scheduling:** The cache scheduler loads necessary model parameters (MLP weights $\theta$) for anchors not in the cache based on the filtered anchors [S1, unofficial].
5.  **Dynamic Cache Depth Scheduling:** Calculate the expected reuse depth using the heuristic function $H$ and the update rate [S1, unofficial]:
    $$ \text{depth} = H\left(\frac{|X_k'|}{|X|}\right) $$
    where $|X_k'|$ is the number of newly decoded anchors from the previous $k$ frames, and $|X|$ is the total anchor set for decoding in the current frame [S1, unofficial]. The function $H$ adjusts the depth of reuse and cached parameters according to the intensity of decoding calculations [S1, unofficial].
6.  **Anchor Decoding (Derivation Stage):** For anchors in the cache, retrieve cached Gaussian parameters [S1, unofficial]. For anchors not in the cache, decode anchor features into neural Gaussian parameters using the MLP with weights $\theta$ [S1, unofficial]. Update the cache with newly decoded parameters [S1, unofficial]. Flush cache entries that have exceeded the dynamic reuse depth to prevent significant rendering errors due to viewpoint changes [S1, unofficial].
7.  **Gaussian Rasterization (Rasterization Stage):** Project the decoded 3D Gaussians to 2D and perform alpha compositing to generate the final image [S1, unofficial]. This stage is not accelerated by caching because slight perspective changes significantly affect occlusion, and caching here would degrade visual quality [S1, unofficial].

**Pseudocode:**
```python
def gs_cache_render(camera_pose, model, prev_cache, k, H_func):
    # 1. Binocular De-redundancy and Anchor Filtering
    # Compute anchor indices from camera input and filter global set to X
    anchor_indices = [a.id for a in model.anchors if in_view_frustum(a, camera_pose)] # [G] standard frustum culling (not given in sources)
    X = set(anchor_indices)
    
    # 2. Index Mapping and Cache Lookup
    # Translate anchor indices to cache indices
    cache_indices = {aid: aid for aid in X} # [G] direct mapping per source (not given in sources)
    cached_params = {aid: prev_cache.get(aid) for aid in X if aid in prev_cache}
    
    # 3. Identify Newly Decoded Anchors (from previous k frames logic)
    # Track anchors decoded in the last k frames to compute |X_k'|
    num_recently_decoded = prev_cache.count_recently_decoded(k) # [G] sliding window counter (not given in sources)
    
    # 4. Dynamic Cache Depth Scheduling
    update_rate = num_recently_decoded / len(X) if len(X) > 0 else 0.0
    expected_reuse_depth = H_func(update_rate)
    
    # 5. Cache Scheduling and Decoding
    mlp_weights = model.get_mlp_weights() # weights theta
    new_gaussians = {}
    for anchor_id in X:
        if anchor_id in cached_params:
            # Hit: Use cached parameters
            gaussian = cached_params[anchor_id]
        else:
            # Miss: Decode anchor features using MLP
            anchor_feature = model.get_anchor_feature(anchor_id)
            # MLP forward pass: gaussian = MLP(anchor_feature, mlp_weights)
            gaussian = anchor_feature @ mlp_weights
            new_gaussians[anchor_id] = gaussian
            
    # 6. Update Cache
    # Flush old entries based on expected_reuse_depth to prevent appearance errors
    prev_cache.flush(expected_reuse_depth)
    # Insert new/updated entries
    prev_cache.update(new_gaussians)
    
    # 7. Rasterization (Uncached)
    # Combine cached and newly decoded Gaussians
    all_gaussians = {**cached_params, **new_gaussians}
    # Project all Gaussians to 2D and perform alpha compositing
    # [G] standard 3DGS rasterization pipeline (not given in sources)
    projected = [project_to_2d(g, camera_pose) for g in all_gaussians.values()] # [G] standard perspective projection (not given in sources)
    projected.sort(key=lambda g: g.depth) # [G] depth sorting (not given in sources)
    image = alpha_composite(projected) # [G] standard alpha compositing (not given in sources)
    
    return image, prev_cache
```

**Parameters:**
*   $k$: The number of previous frames from which newly decoded anchors ($X_k'$) are considered for the update rate calculation [S1, unofficial].
*   $H$: The guiding function of the heuristic cache reuse depth scheduling strategy [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Viewpoint Correlation:** Neural Gaussian appearance has viewpoint correlation. Reusing cached results without restraint can cause rendering errors (e.g., around centered targets). The dynamic cache depth scheduling suppresses rapid appearance changes caused by cache flushing [S1, unofficial].
*   **Occlusion Sensitivity:** The rasterization stage cannot be cached because occlusion changes significantly with slight perspective shifts. Caching rasterization results would degrade visual quality [S1, unofficial].

## Operating characteristics
*   **Performance:** Achieves an average frame rate exceeding 72 FPS at binocular 2K resolution for large-scale city-level scenes [S1, unofficial].
*   **Complexity:** The framework reduces inter-frame redundancy in the derivation stage, which is the dominant computation time for structured Gaussian derivation methods [S1, unofficial].
*   **Strengths:** Enables real-time photo-realistic rendering of large-scale 3DGS models, particularly for VR applications requiring binocular stereo [S1, unofficial]. It is model-agnostic regarding the specific pipeline structure, relying on a heuristic strategy [S1, unofficial].
*   **Limitations:** Specifically targets structured Gaussian derivation methods (Scaffold-GS, Octree-GS). It does not accelerate the rasterization stage, which remains compute-bound [S1, unofficial].

## Background
GS-Cache was introduced in the paper "A GS-Cache Inference Framework for Large-Scale Gaussian Splatting Models" [S1, unofficial]. It addresses the challenges of real-time rendering of large-scale 3DGS models, particularly in VR applications where binocular 2K resolution is required [S1, unofficial]. The framework was developed to overcome the bottleneck of the Gaussian Derivation Stage in structured Gaussian derivation methods, which becomes increasingly computationally intensive as scene scale and anchor feature parameters increase [S1, unofficial].
