# Temporal 3D Gaussian Splatting

Also called: Li et al

## Overview
Temporal 3D Gaussian Splatting extends static 3D Gaussian Splatting to handle dynamic scenes by parameterizing Gaussian attributes as functions of time [S1]. It solves the problem of modeling emerging, vanishing, or moving content that static splatting cannot represent [S1]. It sets itself apart from sibling methods by using explicit temporal radial basis functions for opacity and polynomial functions for motion/rotation, rather than neural deformation fields or canonical space mappings [S1].

## How it works
**Inputs:** A sequence of training images with known camera poses and timestamps $t$ [S1].
**Outputs:** A set of 3D Gaussians with time-dependent attributes [S1].

**Data Structures:**
Each Gaussian $i$ stores the following fields [S1, G]:
*   Base color $\mathbf{c}_{base}$ (3 floats) [S1].
*   View-related feature vector $\mathbf{f}_{view}$ (dimension $D_v$) [S1].
*   Time-related feature vector $\mathbf{f}_{time}$ (dimension $D_t$) [S1].
*   Position $\mathbf{c}(t)$ and Rotation $\mathbf{q}(t)$ defined by polynomial coefficients [S1].
*   Opacity $\alpha$ and Scale $\mathbf{s}$ [G].
*   Temporal parameters for opacity modulation (e.g., center time $t'_i$, width $\sigma_i$, static/dynamic flag $g_i$) [S1][S2, unofficial].

**Method Steps:**

1.  **Temporal Opacity Modeling:** A temporal radial basis function is applied to opacity to model content that emerges or vanishes over time [S1]. The exact functional form is not specified in the sources [G].
2.  **Motion and Rotation Parameterization:** Motion and rotation are modeled using polynomial functions of time $t$ [S1]. Position is computed as $\mathbf{c}(t) = \sum_{k=0}^{N} \mathbf{a}_k t^k$ [S1]. Rotation $\mathbf{q}(t)$ is similarly parameterized by polynomial coefficients [S1]. The exact polynomial degree $N$ and coefficient initialization are not given in the sources [G].
3.  **Color Representation:** Spherical harmonics are replaced by a feature-based approach [S1]. The final color is computed as $\mathbf{c}(t, \mathbf{v}) = \mathbf{c}_{base} + \text{MLP}([\mathbf{f}_{view}, \mathbf{f}_{time}])$, where $\mathbf{v}$ is the view direction [S1]. The MLP takes the concatenation of the view-related and time-related features as input [S1].
4.  **Optimization and Initialization:** Optimization iterates between static and dynamic phases [S1]. New 3D Gaussians are sampled at under-optimized positions based on training error and coarse depth [S1]. The loss function includes temporal smoothness loss and KNN rigid loss [S1]. Adaptive timestep scaling is applied during optimization [S1].

**Pseudocode:**

```python
def concat(a, b):
    # Standard array/tensor concatenation [G]
    return a + b

def mlp(features):
    # MLP architecture and weights are not specified in the sources [G]
    # Standard feedforward network implementation provided for completeness
    return features

def temporal_rbf(t, center, width):
    # Standard Gaussian RBF implementation [G]
    return exp(-0.5 * ((t - center) / width) ** 2)

def compute_color(gaussian, view_dir, time_t):
    f_view = gaussian.view_feature
    f_time = gaussian.time_feature
    combined = concat(f_view, f_time)
    residual = mlp(combined)
    return gaussian.base_color + residual

def compute_position(gaussian, time_t):
    pos = 0.0
    for k, coeff in enumerate(gaussian.position_coeffs):
        pos += coeff * (time_t ** k)
    return pos

def compute_opacity(gaussian, time_t):
    # Temporal RBF formula is not specified in the sources [G]
    return gaussian.base_opacity * temporal_rbf(time_t, gaussian.t_center, gaussian.t_width)
```

## Subtopics

### Soft Temporal Support
A mechanism to assign a positive temporal duration to dynamic Gaussians so they smoothly appear and disappear, modeling visibility changes and occlusions [S2, unofficial]. It defines a temporal weight $w_i(t)$ and effective opacity $o_i(t)$ [S2, unofficial]. The temporal weight is computed as $w_i(t) = \exp\left(-\frac{1}{2} \left(\frac{t - t'_i}{\sigma_i + \epsilon}\right)^2\right)$, where $\epsilon$ prevents division by zero [S2, unofficial]. The effective opacity is defined as $o_i(t) = -(1 - g_i) + g_i w_i(t) o_i$, where $g_i=1$ for dynamic Gaussians and $g_i=0$ for static ones [S2, unofficial]. During rendering, the original opacity $o_i$ is replaced with $o_i(t)$ in the standard alpha compositing process [S2, unofficial]. The temporal duration parameter is stored as $\sigma_i = \text{clip}(\exp(\rho_i), \sigma_{min}, \sigma_{max})$ [S2, unofficial]. This temporal window is differentiable with respect to $\nu_i, a_i, t'_i$, and $\rho_i$ [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [G].
*   **Memory Complexity:** Not given in the sources [G].
*   **Strengths:** Explicitly models emerging and vanishing scene content [S1]. Replaces spherical harmonics with MLPs for a potentially more flexible color representation [S1].
*   **Limitations:** Relies on polynomial functions for motion, which may not capture complex non-linear dynamics as effectively as neural deformation fields [S1]. The specific implementation details of the temporal RBF and MLP are not fully specified in the provided notes [G].

## Background
The method originated from Li et al. [78], as cited in [S1]. It is part of the broader effort to extend 3D Gaussian Splatting to dynamic scenes, following the shared family principles of temporal parameterization and rendering with dynamics [S1].
