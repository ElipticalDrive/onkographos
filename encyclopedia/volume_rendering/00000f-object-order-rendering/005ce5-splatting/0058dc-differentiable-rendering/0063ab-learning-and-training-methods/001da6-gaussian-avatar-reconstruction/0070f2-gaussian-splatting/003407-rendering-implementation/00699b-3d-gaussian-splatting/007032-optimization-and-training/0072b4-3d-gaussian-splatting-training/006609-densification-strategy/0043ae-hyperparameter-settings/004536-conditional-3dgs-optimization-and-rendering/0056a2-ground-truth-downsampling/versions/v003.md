# Ground Truth Downsampling

Also called: Anti-alias Ground Truth Downsampling

## Overview
Ground Truth Downsampling is a supervision strategy used during the low-resolution optimization stage of 3D Gaussian Splatting to prevent optimization misguidance caused by aliased ground truth images [S1]. It explicitly downscalesthe target images using an anti-aliasing filter before computing the loss against the rendered low-resolution output, distinguishing it from standard fixed-resolution training that directly compares high-resolution ground truth to low-resolution renders [G].

## How it works
**Inputs and Outputs:**
- **Input:** High-resolution ground truth image $I_{HR}$ and the rendered low-resolution image $I_{LR}$ from the current Gaussian scene representation [G].
- **Output:** Downsampled ground truth image $I_{LR}^{GT}$ used for loss computation [G].

**Data Structures:**
- $I_{HR}$: Tensor of shape $(H, W, C)$, typically 3-channel RGB [G].
- $I_{LR}$: Tensor of shape $(h, w, C)$, where $h = H/s$ and $w = W/s$ for a scale factor $s$ [G].
- $I_{LR}^{GT}$: Tensor of shape $(h, w, C)$ [G].

**Steps:**
1. **Resolution Selection:** Determine the target low resolution $(h, w)$ for the current optimization stage, typically managed by a resolution scheduler [G].
2. **Anti-Aliased Downsampling:** Apply PyTorch's official anti-alias downsampling algorithm to $I_{HR}$ to produce $I_{LR}^{GT}$ [S1].
3. **Loss Computation:** Compute the reconstruction loss between the rendered image $I_{LR}$ and the downsampled ground truth $I_{LR}^{GT}$ [S1].
   $$ \mathcal{L} = \| I_{LR} - I_{LR}^{GT} \| $$
4. **Optimization Step:** Update the Gaussian parameters (position, scale, rotation, opacity, color) using the gradient of the loss with respect to the rendered image [G].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def ground_truth_downsampling(gt_hr, render_lr):
    """
    Downsamples high-resolution ground truth to match the resolution of the low-resolution rendering.
    
    Args:
        gt_hr (torch.Tensor): High-resolution ground truth image, shape (C, H, W) or (B, C, H, W).
        render_lr (torch.Tensor): Rendered low-resolution image, shape (C, h, w) or (B, C, h, w).
        
    Returns:
        torch.Tensor: Downsampled ground truth image, shape (C, h, w).
    """
    # PyTorch's official anti-alias downsampling expects channels-first format.
    # F.interpolate with antialias=True applies a low-pass filter before subsampling.
    gt_lr = F.interpolate(
        gt_hr, 
        size=(render_lr.shape[-2], render_lr.shape[-1]), 
        mode='bilinear', 
        align_corners=False, 
        antialias=True
    )
    return gt_lr

def compute_loss(render_lr, gt_lr):
    """
    Computes the reconstruction loss between rendered and downsampled ground truth.
    """
    return torch.mean(torch.abs(render_lr - gt_lr))
```

**Parameters:**
- **Anti-aliasing Filter:** PyTorch's official anti-alias downsampling algorithm is used [S1].
- **Scale Factor:** Determined by the resolution scheduler [G].

**Edge Cases and Pitfalls:**
- **Precision:** Ensure ground truth and rendered images use consistent normalization ranges (e.g., [0, 1]) before downsampling [G].
- **Boundary Conditions:** The anti-aliasing filter may introduce slight blurring at image edges, which is expected for anti-aliasing but should be considered if edge fidelity is critical [G].
- **Degenerate Input:** If the ground truth is already at the target resolution, the downsampling step should be skipped or mapped to an identity operation [G].

## Subtopics

### [Zoom-out Adaptation](16897-zoom-out-adaptation.md)
A post-training optimization technique that adapts a pre-trained 3D Gaussian Splatting model to render anti-aliased images at lower resolutions. It solves geometric dilation and aliasing artifacts (e.g., thick spokes on wheels) that occur when a high-resolution model is viewed at a distance. Unlike [Mip-Splatting](15762-mip-splatting.md), which uses filters to mitigate dilation, this method generates pseudo-ground truth by downsampling high-resolution renderings and re-optimizes the Gaussians to fit this multi-scale supervision. Choose it when rendering zoomed-out views of a trained model to prevent aliasing artifacts.

## Operating characteristics
- **Time Complexity:** The downsampling operation is performed once per optimization step before loss computation, adding negligible overhead compared to the rendering and optimization steps [G].
- **Memory Complexity:** Requires storing the intermediate downsampled ground truth tensor, which scales linearly with the target resolution and channels [G].
- **Strengths:** Prevents high-frequency aliasing artifacts in the optimization process, leading to more stable convergence at low resolutions [S1].
- **Limitations:** Relies on the quality and behavior of the anti-aliasing filter provided by the deep learning framework [G].
- **When to Use:** During the low-resolution optimization stages of 3D Gaussian Splatting training, particularly when using a multi-resolution schedule [S1].

## Background
Ground Truth Downsampling was introduced as part of the DashGaussian method, which aims to optimize 3D Gaussian Splatting in 200 seconds [S1]. The method addresses the issue of aliased supervision hindering optimization when training at low resolutions [S1]. It is a key component of the DashGaussian framework, which also includes modifications to learning rate schedules, resolution schedulers, primitive growth schedules, and densification operations [S1].
