# Complexity-Aware Adaptive Density Control

Also called: Complexity-Aware Density Control, Complexity-Aware Level of Details, Complexity-Guided Relocation

## Overview
Complexity-Aware Adaptive Density Control is a method for managing the density of 3D Gaussian primitives during training by using image complexity as a surrogate for reconstruction error [S1, unofficial]. It addresses the limitation of standard opacity-based scoring, which fails to distinguish between regions that are difficult to reconstruct (high complexity) and those that are simple, leading to inefficient primitive allocation [S1, unofficial]. It sets itself apart from siblings like [Average Contribution Criterion](16892-average-contribution-criterion.md) by explicitly modeling spatial complexity to bias relocation and pruning, ensuring that high-complexity regions receive more primitives while simple regions are covered efficiently by larger primitives [S1, unofficial].

## How it works
The method operates within the Adaptive Density Control loop defined by [Splitting Criteria and Prioritization](16226-splitting-criteria-and-prioritization.md). It introduces two key components: an online complexity field update and a complexity-aware importance scoring function for pruning and relocation.

### Inputs and Outputs
*   **Inputs:**
    *   Set of 3D Gaussians $\mathcal{G} = \{g_j\}$, where each $g_j$ has mean $\mu_j$, covariance $\Sigma_j$, opacity $\alpha_j$, and scale $s(g_j)$.
    *   Training view $i$ with image $I_i$.
    *   Full-capacity render $I_i^{full}$ and budgeted render $I_i^{\tau}$ (where $\tau < 1$).
    *   Complexity map $C_i^{2D}$ for view $i$, computed using delentropy [S1, unofficial].
    *   Hyperparameters: EMA learning rate $\eta \in (0, 1]$, scalar weight $\lambda = 2$, complexity dropout probability $\delta = 0.2$, variance loss weight $\lambda_{var}$ [S1, unofficial].
*   **Outputs:**
    *   Updated complexity values $C_j$ for each Gaussian.
    *   Importance scores $S(g_j)$ for sorting and pruning.
    *   Relocation probabilities $p(g_j)$ for densification.

### Data Structures
*   **Complexity Field:** Each Gaussian $g_j$ maintains a scalar field $C_j$, initialized to 0. This value converges to the multi-view average complexity [S1, unofficial].
*   **Normalized Complexity:** $\tilde{C}_j \in [0, 1]$, derived from min-max normalization of $C_j$ across the current batch or training set [S1, unofficial].

### Steps

1.  **Complexity Update:**
    After rendering a view $\Pi_i$, project the means $\mu_j$ of all contributing Gaussians into the image plane. For each Gaussian $g_j$ whose center projects within the view's frustum, update its complexity $C_j$ using an exponential moving average [S1, unofficial]:
    $$
    C_j \leftarrow (1 - \eta) C_j + \eta C_i^{2D}(\pi_i(\mu_j))
    $$
    where $C_i^{2D}(\pi_i(\mu_j))$ is the complexity value at the projected pixel location [S1, unofficial]. Gaussians outside the frustum are not updated [S1, unofficial].

2.  **Importance Score Calculation (Pruning):**
    Compute the importance score $S(g_j)$ for each Gaussian to determine retention under a limited budget $\tau < 1$. The score combines opacity, scale, and complexity [S1, unofficial]:
    $$
    S(g_j) = \alpha_j + \lambda \cdot \frac{s(g_j)}{\exp(\tilde{C}_j(\mu_j))}
    $$
    where:
    *   $\alpha_j$ is the opacity.
    *   $s(g_j)$ is the max-normalized scale of the Gaussian.
    *   $\tilde{C}_j$ is the normalized complexity.
    *   $\lambda = 2$ is a fixed scalar weight [S1, unofficial].
    
    In high-complexity regions, $\exp(\tilde{C}_j)$ is large, attenuating the scale term and reducing the score toward opacity, preventing large, blurring primitives from dominating [S1, unofficial]. In low-complexity regions, $\exp(\tilde{C}_j) \to 1$, restoring weight to large primitives that efficiently cover simple areas [S1, unofficial].

3.  **Relocation Probability (Densification):**
    When selecting a Gaussian for splitting or relocation, sample with probability $p(g_j)$ biased towards complex regions [S1, unofficial]:
    $$
    p(g_j) = \alpha_j \cdot \exp(\tilde{C}_j)
    $$
    To prevent collapse onto fixed complex regions, apply complexity dropout: with probability $\delta = 0.2$, set $\tilde{C}_j = 0$ for that candidate, scoring it by opacity alone [S1, unofficial].

4.  **Variance Loss Minimization:**
    To ensure uniform degradation across levels of detail, minimize the spatial variance of the reconstruction error residuals [S1, unofficial]. Compute the residual $\Delta_i$ between the full-capacity error $E(I_i^{full})$ and the budgeted error $E(I_i^{\tau})$:
    $$
    \Delta_i = E(I_i^{full}) - E(I_i^{\tau})
    $$
    The variance loss is:
    $$
    L_{var} = \text{Var}_{u \in \Omega} \Delta_i(u)
    $$
    where $\Omega$ is the image domain [S1, unofficial].

5.  **Total Training Objective:**
    The total loss combines the standard photometric loss with the variance loss [S1, unofficial]:
    $$
    \text{Total Loss} = \text{Average}(L1 + D\text{-}SSIM) + \lambda_{var} L_{var}
    $$
    This is computed on both full-capacity ($\tau=1$) and budgeted ($\tau<1$) renders [S1, unofficial].

### Pseudocode

```python
def update_complexity(gaussians, view_i, complexity_map_2d, eta):
    """
    Updates the complexity field C_j for Gaussians contributing to view_i.
    """
    for g in gaussians:
        # Project mean mu_j to 2D pixel coordinates
        pixel_coords = project_2d(g.mu, view_i.camera_params)
        
        # Check if projection is within frustum/image bounds
        if is_in_frustum(pixel_coords, view_i):
            # Get complexity value from pre-computed 2D map
            c_2d = complexity_map_2d.get_value(pixel_coords)
            
            # Exponential Moving Average update
            g.C = (1 - eta) * g.C + eta * c_2d

def compute_importance_score(gaussian, lambda_weight=2.0):
    """
    Computes the importance score S(g) for pruning under limited budget.
    """
    alpha = gaussian.alpha
    s = gaussian.scale # Max-normalized scale
    C_norm = gaussian.C_normalized # Min-max normalized complexity in [0, 1]
    
    # Formula: S(g) = alpha + lambda * s / exp(C_norm)
    score = alpha + lambda_weight * (s / math.exp(C_norm))
    return score

def sample_relocation_candidate(gaussians, dropout_prob=0.2):
    """
    Selects a Gaussian for densification based on opacity and complexity.
    """
    # Calculate weights for all Gaussians
    weights = []
    for g in gaussians:
        C_norm = g.C_normalized
        
        # Apply complexity dropout
        if random() < dropout_prob:
            C_norm_effective = 0.0
        else:
            C_norm_effective = C_norm
            
        # Probability: p(g) = alpha * exp(C_norm)
        w = g.alpha * math.exp(C_norm_effective)
        weights.append(w)
        
    # Normalize weights to sum to 1
    total_w = sum(weights)
    probs = [w / total_w for w in weights]
    
    # Sample index
    idx = sample_categorical(probs)
    return gaussians[idx]

def compute_variance_loss(render_full, render_budget, error_func):
    """
    Computes the spatial variance of reconstruction error residuals.
    """
    # Compute error maps
    error_full = error_func(render_full)
    error_budget = error_func(render_budget)
    
    # Residual map
    residual = error_full - error_budget
    
    # Variance over all pixels u in image domain Omega
    variance = compute_variance(residual)
    return variance
```

### Parameters and Edge Cases
*   **$\eta$ (Learning Rate):** Controls the convergence speed of the complexity field. Not given in the sources.
*   **$\lambda$ (Scale Weight):** Fixed at 2 [S1, unofficial].
*   **$\delta$ (Dropout):** Fixed at 0.2 [S1, unofficial].
*   **Complexity Map:** Computed using delentropy [S1, unofficial]. The exact implementation of delentropy is not detailed in the provided notes.
*   **Normalization:** $\tilde{C}_j$ is min-max normalized [S1, unofficial]. The range of normalization (global vs. per-batch) is not specified.
*   **Edge Case:** If a Gaussian has very low opacity, its contribution to the score is low regardless of complexity, preventing it from being prioritized for relocation [S1, unofficial].
*   **Edge Case:** If complexity is not yet converged (early training), scores may be noisy. The EMA helps smooth this [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Adds overhead for computing the 2D complexity map and updating the EMA for each Gaussian per view. The complexity map computation (delentropy) is not detailed, but typically involves local variance or entropy calculations [S1, unofficial].
*   **Memory Complexity:** Requires storing a scalar $C_j$ per Gaussian [S1, unofficial].
*   **Performance:** On the Tanks and Temples, Mip-NeRF 360, and DB datasets, the method performs on par with full-LoD methods at full capacity and generally better at lower budgets (e.g., 10%, 1%, 0.1%) compared to baselines like OctreeGS, FlexGS, 3DGS-MCMC, LightGaussian, and MGS [S1, unofficial].
*   **Strengths:** Provides uniform degradation across LODs; efficiently allocates primitives to complex regions; prevents collapse on fixed complex regions via dropout.
*   **Limitations:** Requires computing 2D complexity maps; relies on the assumption that complexity is a good surrogate for reconstruction error.

## Background
The method is introduced in "KoalaGS: Complexity-Aware Continuous Level of Detail for Gaussian Splatting" [S1, unofficial]. It addresses the issue in standard 3DGS variants where opacity is used as a proxy for error, causing under-served regions to remain unresolved because they have not yet been resolved [S1, unofficial]. The method builds on the observation that particle count grows exponentially with complexity [S1, unofficial].
