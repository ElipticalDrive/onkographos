# Pruning and Reduction

Also called: Gaussian Splatting Pruning, Mixed-Primitive Pruning, SplatQ, Vertex Pruning, Gaussian Reduction with Learnable Mask, 3DGS Visibility Pruning

## Overview
Pruning and reduction methods aim to decrease the memory footprint and computational cost of 3D Gaussian Splatting (3DGS) representations by removing redundant or low-impact Gaussians during or after training. Unlike the parent family's focus on color and opacity modeling, this family focuses on geometry simplification and sparsity. Key distinctions include vertex-level simplification for mixed primitives [13983-vertex-level-pruning-in-mixed-primitive-gaussian-splatting.md], joint optimization of retention via quadratic programming [14415-splatq.md], and visibility-based or learnable-mask strategies for general 3DGS [S2].

## Shared principles
All methods in this family operate on the standard 3D Gaussian Splatting representation, where the scene is defined by a set of $N$ 3D Gaussians $\{G_i\}_{i=1}^N$. Each Gaussian $G_i$ is defined by its mean $\boldsymbol{\mu}_i$, covariance matrix $\boldsymbol{\Sigma}_i$ (derived from rotation $\mathbf{R}_i$ and scale $\mathbf{S}_i$), opacity $\alpha_i$, and view-dependent color $\mathbf{c}_i(\omega)$.

The rendering process evaluates the Gaussian density along a ray $\mathbf{r}(t) = \mathbf{o} + t\omega$ and integrates contributions. The Gaussian density function is:
$$ G(\mathbf{x}) = \exp\left(-\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})\right) $$

The core variation across methods lies in the definition, storage, and optimization of $\mathbf{c}_i(\omega)$ and potentially $\alpha_i$, moving beyond the fixed SH coefficients used in base 3DGS. Common strategies include:
1.  **Post-Processing Transformation:** Applying a learned affine transformation to the rendered image based on 3D position and view embedding [14740-color-and-appearance-modeling.md].
2.  **Factorized Illumination:** Separating scene lighting (via a tensor grid) from material properties (via BRDF features) to model specular effects [14740-color-and-appearance-modeling.md].
3.  **Image-Conditioned Modulation:** Using an MLP and per-image embeddings to modulate Gaussian color and opacity, enabling transient object removal and appearance synthesis [14740-color-and-appearance-modeling.md].
4.  **Neural Field Substitution:** Replacing per-Gaussian SH with a shared grid-based neural field to reduce parameters and improve generalization [14740-color-and-appearance-modeling.md].
5.  **Volumetric Attenuation:** Modifying the alpha-blending equation to incorporate medium properties, such as direct attenuation $B_d$ and backscatter parameters $B_\infty, B_b$, to model light transport in non-vacuum media [15148-physics-and-optical-modeling.md].

## Subtopics

### [Vertex-level Pruning in Mixed-Primitive Gaussian Splatting](13983-vertex-level-pruning-in-mixed-primitive-gaussian-splatting.md)
Vertex-level pruning is a geometric simplification mechanism applied to mixed-primitive splats (Gaussian triangles and lines) during the training of 3D Gaussian Splatting. It removes redundant vertices from primitives that have collapsed or degenerated into lower-dimensional shapes, converting them into simpler primitives (ellipses or lines) to refine the surface representation. Unlike standard Gaussian Splatting, which only performs primitive-level opacity pruning, this method operates on the vertex level within the mixed-primitive framework [13983-vertex-level-pruning-in-mixed-primitive-gaussian-splatting.md].

### SplatQ
SplatQ is a post-training pruning framework for 3D Gaussian Splatting (3DGS) that addresses the spatial quality imbalance and loss of joint rendering effects inherent in global Top-K selection methods [14415-splatq.md]. Unlike sibling methods that rank Gaussians independently, SplatQ partitions primitives into size-limited blocks based on spatial and appearance similarity, allocates retention quotas to balance regional quality, and solves a Quadratic Unconstrained Binary Optimization (QUBO) problem within each block to jointly select Gaussians under a fixed global budget [14415-splatq.md].

### Gaussian Reduction with Learnable Mask
#### definition
- [S2] A method to reduce the number of Gaussians using a learnable mask during optimization, targeting small-sized kernels for removal.
#### step
- [S2] Apply binary masks M to the opacities and scale attributes of the kernels at every densification step.
- [S2] Use residual vector quantization with L stages of vector quantization for geometric attributes like scale and rotation.
- [S2] Represent view-dependent colors via a grid-based neural field using hash grids for input positions, features, and view direction, fed into an MLP.
#### formula
- [S2] The end-to-end loss is: L = L_ren + λ_m L_m + L_r + L_s, where L_ren is L1+SSIM loss, L_m is masking loss (1/N Σ σ(m_n)), and L_r, L_s are rotation and scale objective functions.
#### parameter
- [S2] ε: Masking threshold for the sigmoid function in the learnable mask.
- [S2] λ_m: Weight for the masking loss term, typically 5 × 10^-4.

### 3DGS Visibility Pruning
#### definition
- [S2] Application of visibility-based pruning to 3D Gaussian Splatting, using Gaussian centroids as reference points for visibility calculation.
#### step
- [S2] Represent each Gaussian kernel by its centroid position, scaling matrix $S$, and rotation matrix $R$ defining the covariance $\Sigma$.
- [S2] Use the Gaussian centroids as the 3D points $p_i$ in the visibility mask computation algorithm.

## Background
The need for pruning in 3D Gaussian Splatting arises from the high memory cost of storing thousands to millions of Gaussians. Standard 3DGS uses adaptive density control (cloning and splitting) which can lead to redundancy. Early approaches focused on post-training Top-K selection, but these often caused spatial quality imbalance. Subsequent works introduced mixed-primitive frameworks requiring vertex-level pruning to handle degenerate geometries [S1, unofficial]. Other approaches integrated pruning into the optimization loop using visibility masks [S2] or learnable masks with compression techniques like vector quantization and neural fields [S2]. SplatQ introduced a block-based QUBO approach to preserve joint rendering effects [14415-splatq.md].
