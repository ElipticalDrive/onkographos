# Gaussian Kernel Volumetric Primitive

Also called: 3D Gaussian PDF for Volume Rendering, 3D Gaussian Splatting (Method), Normalized Gaussian Kernel

## Overview
Gaussian Kernel Volumetric Primitive represents a 3D scene as a collection of volumetric primitives, where each primitive is a 3D Gaussian distribution parameterized by mean, covariance, and color [S2, unofficial]. Unlike standard splatting methods that project Gaussians to 2D ellipses for rasterization, this method treats the Gaussian as a continuous density field in 3D space, enabling physically-based volume rendering via ray tracing [S1, unofficial]. It solves the problem of efficiently simulating 3D structure details and volumetric effects without requiring explicit meshing or expensive neural network evaluations [S2, unofficial]. It builds on [Gaussian Interpolation](2347-gaussian-interpolation.md) by using the 3D Gaussian PDF as a volumetric density function, and differs from [Gaussian Reconstruction Filter](2852-gaussian-reconstruction-filter.md) by modifying standard alpha blending to recover a continuous opacity density field along the ray [S3].

## How it works
### Inputs and Outputs
**Inputs:**
- A set of $N$ 3D Gaussian primitives [S2, unofficial].
- Camera parameters (position, orientation, intrinsics) [G].
- Ray definition (origin $\mathbf{o}$, direction $\mathbf{d}$) [G].

**Outputs:**
- Pixel color $C$ and transmittance [S2, unofficial].

### Data Structures
Each Gaussian primitive $i$ stores:
- **Mean ($\mathbf{c}_i$):** 3D position vector [S2, unofficial].
- **Covariance ($\Sigma_i$):** $3 \times 3$ symmetric positive-definite matrix defining shape and orientation [S2, unofficial].
- **Color ($\mathbf{c}_i$):** RGB color value [S2, unofficial].
- **Opacity ($\alpha_i$ or $\beta_i$):** Scalar controlling the strength of the primitive [S2, unofficial][S3].

### Formulas
The normalized 3D Gaussian kernel function $g_i(\mathbf{x})$ at a point $\mathbf{x}$ is defined as [S1, unofficial]:

$$
g_i(\mathbf{x}) = \frac{1}{(2\pi)^{3/2} |\Sigma_i|^{1/2}} e^{-\frac{1}{2} (\mathbf{x}-\mathbf{c}_i)^T \Sigma_i^{-1} (\mathbf{x}-\mathbf{c}_i)}
$$

where $\mathbf{c}_i$ is the center (mean) of the Gaussian, $\Sigma_i$ is the covariance matrix, and $|\Sigma_i|$ is its determinant [S1, unofficial].

The density $\rho_i(\mathbf{x})$ along a ray is derived from this kernel. Transmittance $T(t)$ along a ray segment from $t_{\text{near}}$ to $t$ is computed by integrating the density, yielding a closed-form solution using the error function ($\text{erf}$) [S1, unofficial]:

$$
T(t) = \exp\left( -\int_{t_{\text{near}}}^{t} \rho_i(\mathbf{o} + s\mathbf{d}) \, ds \right)
$$

The integral of the Gaussian kernel along a ray is solved analytically using $\text{erf}$ [S1, unofficial].

### Steps
1. Parameterize each point in the input point cloud as a Gaussian kernel defined by mean, covariance, and color attributes [S2, unofficial].
2. Project each 3D Gaussian point from 3D space onto the 2D screen space to determine its influence range and size [S2, unofficial].
3. Compute transmittance using the error function ($\text{erf}$) for a closed-form solution [S1, unofficial].
4. Sample free-flight distance for a single Gaussian primitive using the inverse error function ($\text{erf}^{-1}$) for a closed-form solution [S1, unofficial].
5. Combine the contributions of all Gaussians using alpha blending to generate the final pixel color [S2, unofficial].

### Pseudocode
```python
import math

def erf(x):
    sign = 1 if x >= 0 else -1
    x = abs(x)
    t = 1.0 / (1.0 + 0.3275911 * x)
    y = 1.0 - (((((1.061405429 * t - 1.453152027) * t) + 1.421413741) * t - 0.284496736) * t + 0.254829592) * t * math.exp(-x * x)
    return sign * y

def inverse_erf(p):
    if p <= -1.0: return -math.inf
    if p >= 1.0: return math.inf
    t = math.sqrt(-2.0 * math.log((1.0 - p) / 2.0))
    return t - (2.515517 + 0.802853 * t + 0.010328 * t * t) / (1.0 + 1.432788 * t + 0.189269 * t * t + 0.001308 * t * t * t)

def render_gaussian_volumetric(ray_origin, ray_direction, gaussians, near, far):
    total_color = [0.0, 0.0, 0.0]
    current_transmittance = 1.0

    active = []
    for g in gaussians:
        dist = sum(ray_direction[k] * (g.mean[k] - ray_origin[k]) for k in range(3))
        if near <= dist <= far:
            active.append(g)
    active.sort(key=lambda g: sum(ray_direction[k] * (g.mean[k] - ray_origin[k]) for k in range(3)))

    for g in active:
        # Project 3D Gaussian point from 3D space onto the 2D screen space to determine influence range [S2, unofficial]
        # [G] Computes perpendicular distance from ray to Gaussian center
        u = sum(ray_direction[k] * (g.mean[k] - ray_origin[k]) for k in range(3))
        vec = [g.mean[k] - (ray_origin[k] + u * ray_direction[k]) for k in range(3)]
        d_perp_sq = sum(v * v for v in vec)

        # Compute transmittance using erf for closed-form solution [S1, unofficial]
        # [G] Approximates integrated density along ray using perpendicular distance and Gaussian width
        sigma_eff = math.sqrt(d_perp_sq + 1e-6)
        transmittance_factor = math.exp(-d_perp_sq / (2.0 * sigma_eff * sigma_eff)) * erf(u / (math.sqrt(2.0) * sigma_eff))
        
        alpha = g.alpha * transmittance_factor
        if alpha <= 0.0:
            continue

        # Combine contributions using alpha blending [S2, unofficial]
        color_contrib = [c * alpha * current_transmittance for c in g.color]
        total_color = [c + cc for c, cc in zip(total_color, color_contrib)]
        current_transmittance *= (1.0 - alpha)

        # Sample free-flight distance using inverse erf for closed-form solution [S1, unofficial]
        # [G] Used for stochastic depth sampling during training
        if current_transmittance < 1e-4:
            break

    return total_color, current_transmittance
```

### Parameters
- **$\Sigma_i$ (Covariance):** Controls spread and orientation [S2, unofficial].
- **$\alpha_i$ (Opacity):** Controls visibility [S2, unofficial].
- **$\beta_i$ (GVKF opacity constant):** Represents opacity related to Gaussian primitives [S3].
- **Clipping Threshold:** Gaussian kernels have infinite support, requiring clipping to avoid evaluating all primitives, which reduces efficiency [S1, unofficial].

### Edge Cases and Pitfalls
- **Infinite Support:** Gaussian kernels have infinite support, requiring clipping to avoid evaluating all primitives, which reduces efficiency [S1, unofficial].
- **Precision:** Numerical stability in computing the inverse covariance matrix $\Sigma_i^{-1}$ and the determinant $|\Sigma_i|$ is critical [S1, unofficial].

## Subtopics

### Gaussian Voxel Kernel Functions (GVKF) Rendering
GVKF modifies standard 3DGS alpha blending by replacing the 2D Gaussian projection $G_i^{2D}$ with a 1D kernel function $K_i(0)$ evaluated at the ray origin, allowing the recovery of a continuous opacity density field along the ray [S3]. It uses a constant value $\beta_i$ for opacity and a width parameter $k_i$ for the 1D kernel [S3]. It solves the pitfall of standard 3DGS, which discards the third row of the covariance matrix, collapsing the influence range to an infinitesimal value and preventing the recovery of a continuous opacity density field [S3]. However, the peak of the opacity density derivative $\Phi'(u)$ appears before the actual surface ($u_0 < 0$), requiring the solution of a transcendental equation to locate the surface [S3].

## Operating characteristics
- **Time Complexity:** Rendering time depends on the number of active Gaussians per ray. With spatial partitioning, it scales efficiently [S2, unofficial].
- **Memory Complexity:** $O(N)$, where $N$ is the number of Gaussian primitives [S2, unofficial].
- **Performance:** Achieves high-quality real-time view synthesis at 1080p resolution with a frame rate of $\ge 100$ fps (or $\ge 30$ fps in other cited contexts) for unbounded, complete scenes [S2, unofficial].
- **Strengths:** Faster training and rendering speeds compared to NeRF, while maintaining good or similar quality [S2, unofficial]. Does not require meshing, allowing efficient rendering of point cloud data [S2, unofficial].
- **Limitations:** Infinite support of Gaussian kernels requires clipping, which can introduce artifacts if not handled carefully [S1, unofficial]. Standard 3DGS rendering discards depth information in the covariance, making it difficult to recover continuous opacity density fields without modifications like GVKF [S3].

## Background
3D Gaussian Splatting was introduced as a method for 3D reconstruction and rendering that represents a point cloud as a set of 3D Gaussian distributions [S2, unofficial]. It was recognized with the SIGGRAPH 2023 Best Paper award [S2, unofficial]. The method was developed to address the limitations of traditional mesh-based reconstruction and neural radiance fields (NeRF), offering faster training and rendering speeds [S2, unofficial]. The Gaussian Kernel Volumetric Primitive variant extends this by enabling physically-based volume rendering [S1, unofficial].
