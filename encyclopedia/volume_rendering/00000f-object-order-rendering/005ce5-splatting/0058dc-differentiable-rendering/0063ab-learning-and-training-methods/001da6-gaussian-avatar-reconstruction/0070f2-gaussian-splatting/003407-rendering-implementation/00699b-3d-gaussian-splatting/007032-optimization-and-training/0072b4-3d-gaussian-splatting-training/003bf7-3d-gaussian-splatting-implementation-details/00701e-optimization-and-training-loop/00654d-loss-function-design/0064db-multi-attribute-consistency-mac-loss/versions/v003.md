# Multi-Attribute Consistency (MAC) Loss

Also called: MAC loss, MAC-Splat loss

## Overview
The Multi-Attribute Consistency (MAC) loss is a regularization objective for 3D Gaussian Splatting that enforces geometric and photometric agreement between matched Gaussians across different views [S1]. It solves the ambiguity problem in sparse-view reconstruction by using high-confidence 2D pixel correspondences as anchors to jointly constrain position, shape, and appearance in a common world coordinate frame [S1]. Unlike standard photometric losses that only supervise rendered pixels, MAC loss directly supervises the underlying Gaussian parameters, providing robust stability against outliers and preventing geometric degeneracy [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of matched pixel pairs $M = \{ (p_1^k, p_2^k) \}_{k=1}^K$ between two training images $I_1$ and $I_2$, where each pair has an associated joint confidence weight $w_k$ [S1]. Camera-to-world transformation matrices $T_{wc}^v = [R^v | t^v]$ for each view $v \in \{1, 2\}$ [S1]. Predicted dense parameter maps for each view, containing centroid $\boldsymbol{\mu}_{\text{cam}}$, covariance $\boldsymbol{\Sigma}_{\text{cam}}$, opacity $\alpha$, and spherical harmonic coefficients $\boldsymbol{c}$ [S1].
*   **Outputs:** A scalar loss value $\mathcal{L}_{\text{MAC}}$ and gradients with respect to the Gaussian parameters [S1].

**Data Structures**
*   **Parameter Maps:** Dense grids aligned with the descriptor grid of the input images. Each cell $(u,v)$ stores:
    *   $\boldsymbol{\mu}_{\text{cam}} \in \mathbb{R}^3$: Camera-space centroid.
    *   $\boldsymbol{\Sigma}_{\text{cam}} \in \text{Sym}^+(3)$: Camera-space covariance matrix (6 unique elements due to symmetry).
    *   $\alpha \in \mathbb{R}$: Opacity.
    *   $\boldsymbol{c} \in \mathbb{R}^D$: Spherical harmonic coefficients (dimension $D$ depends on the order of SH used).
*   **Match Set $M$:** A list of tuples $(p_1^k, p_2^k, w_k)$, where $p$ are 2D pixel coordinates and $w_k$ is the confidence score [S1].

**Numbered Steps**
1.  **Gaussian Sampling:** For each matched pixel pair $k$ with coordinates $(p_1^k, p_2^k)$, bilinearly sample the predicted parameter maps for view 1 and view 2 to obtain two Gaussians $G_1^k$ and $G_2^k$ [S1].
    $$ G_v^k = \left( \boldsymbol{\mu}_{\text{cam}}^{v,k}, \boldsymbol{\Sigma}_{\text{cam}}^{v,k}, \alpha^{v,k}, \boldsymbol{c}^{v,k} \right), \quad v \in \{1, 2\} $$
2.  **World-Space Transformation:** Transform the centroids and covariances from camera space to world space using the camera-to-world matrices $T_{wc}^v = [R^v | t^v]$ [S1].
    *   Centroid:
        $$ \boldsymbol{\mu}_{\text{world}}^{v,k} = R^v \boldsymbol{\mu}_{\text{cam}}^{v,k} + t^v $$
    *   Covariance:
        $$ \boldsymbol{\Sigma}_{\text{world}}^{v,k} = R^v \boldsymbol{\Sigma}_{\text{cam}}^{v,k} (R^v)^\top $$
3.  **Depth Validation:** Check if both centroids lie in front of their respective cameras ($z_{\text{cam}} > 0$). If not, skip the positional loss for this pair [S1].
4.  **Positional Consistency:** Compute the Huber loss between the world-space centroids [S1].
    $$ \mathcal{L}_{\text{pos}}^{(k)} = \mathcal{H}\left( \| \boldsymbol{\mu}_{\text{world}}^{1,k} - \boldsymbol{\mu}_{\text{world}}^{2,k} \|_1 \right) $$
    where $\mathcal{H}$ is the Huber loss function [S1].
5.  **Shape Consistency:** Compute the loss based on the log-eigenvalues of the world-space covariance matrices. Let $\lambda_1^{v,k}, \lambda_2^{v,k}, \lambda_3^{v,k}$ be the eigenvalues of $\boldsymbol{\Sigma}_{\text{world}}^{v,k}$ [S1].
    $$ \mathcal{L}_{\text{shape}}^{(k)} = \sum_{i=1}^3 \mathcal{H}\left( | \log \lambda_i^{1,k} - \log \lambda_i^{2,k} | \right) $$
    *Note: Euclidean distance between covariance matrices is avoided as it does not respect the geometry of $\text{Sym}^+(3)$ or invariance to rotation/scaling [S1].*
6.  **Appearance Consistency:** Compute the L1 loss between opacity and spherical harmonic coefficients [S1].
    $$ \mathcal{L}_{\text{app}}^{(k)} = \| \alpha^{1,k} - \alpha^{2,k} \|_1 + \| \boldsymbol{c}^{1,k} - \boldsymbol{c}^{2,k} \|_1 $$
7.  **Aggregation:** Combine the terms weighted by the match confidence $w_k$ [S1].
    $$ \mathcal{L}_{\text{MAC}} = \frac{\sum_{k=1}^K w_k \left( \lambda_p \mathcal{L}_{\text{pos}}^{(k)} + \lambda_s \mathcal{L}_{\text{shape}}^{(k)} + \lambda_a \mathcal{L}_{\text{app}}^{(k)} \right)}{\sum_{k=1}^K w_k + \epsilon} $$
    where $\lambda_p, \lambda_s, \lambda_a$ are scalar weights and $\epsilon$ is a small constant [S1].

**Pseudocode**
```python
def compute_mac_loss(matched_pairs, param_maps, camera_to_world_matrices):
    """
    matched_pairs: List of tuples (p1, p2, w_k)
                   p1, p2: (u, v) coordinates
                   w_k: float confidence
    param_maps: Dict mapping view_id -> {
        'mu': (H, W, 3), 'Sigma': (H, W, 6), 'alpha': (H, W, 1), 'c': (H, W, D)
    }
    camera_to_world_matrices: Dict mapping view_id -> (R, t)
    """
    total_loss = 0.0
    total_weight = 0.0
    epsilon = 1e-8
    
    for p1, p2, w_k in matched_pairs:
        # 1. Sample parameters from dense maps
        mu_cam_1 = bilinear_sample(param_maps['1']['mu'], p1)
        Sigma_cam_1 = bilinear_sample_cov(param_maps['1']['Sigma'], p1)
        alpha_1 = bilinear_sample(param_maps['1']['alpha'], p1)
        c_1 = bilinear_sample(param_maps['1']['c'], p1)
        
        mu_cam_2 = bilinear_sample(param_maps['2']['mu'], p2)
        Sigma_cam_2 = bilinear_sample_cov(param_maps['2']['Sigma'], p2)
        alpha_2 = bilinear_sample(param_maps['2']['alpha'], p2)
        c_2 = bilinear_sample(param_maps['2']['c'], p2)
        
        # 2. Transform to world space
        R1, t1 = camera_to_world_matrices['1']
        R2, t2 = camera_to_world_matrices['2']
        
        mu_world_1 = R1 @ mu_cam_1 + t1
        mu_world_2 = R2 @ mu_cam_2 + t2
        
        Sigma_world_1 = R1 @ Sigma_cam_1 @ R1.T
        Sigma_world_2 = R2 @ Sigma_cam_2 @ R2.T
        
        # 3. Depth validation (check z_cam > 0)
        # Note: z_cam is the third component of mu_cam in camera coordinates
        if mu_cam_1[2] <= 0 or mu_cam_2[2] <= 0:
            continue
            
        # 4. Positional Loss
        pos_diff = np.linalg.norm(mu_world_1 - mu_world_2, ord=1)
        l_pos = huber_loss(pos_diff)
        
        # 5. Shape Loss (Log-Eigenvalues)
        eig_1 = np.linalg.eigvalsh(Sigma_world_1)
        eig_2 = np.linalg.eigvalsh(Sigma_world_2)
        # Ensure positive eigenvalues for log
        eig_1 = np.maximum(eig_1, epsilon)
        eig_2 = np.maximum(eig_2, epsilon)
        
        l_shape = 0.0
        for i in range(3):
            l_shape += huber_loss(np.abs(np.log(eig_1[i]) - np.log(eig_2[i])))
            
        # 6. Appearance Loss
        l_app = np.linalg.norm(alpha_1 - alpha_2, ord=1) + np.linalg.norm(c_1 - c_2, ord=1)
        
        # 7. Aggregate
        # Weights lambda_p, lambda_s, lambda_a are assumed to be global constants
        weighted_term = w_k * (lambda_p * l_pos + lambda_s * l_shape + lambda_a * l_app)
        total_loss += weighted_term
        total_weight += w_k
        
    if total_weight < epsilon:
        return 0.0
        
    return total_loss / (total_weight + epsilon)
```

**Parameters**
*   $\lambda_p, \lambda_s, \lambda_a$: Scalar weights for positional, shape, and appearance consistency. Values not given in the sources.
*   $\epsilon$: Small constant to prevent division by zero. Value not given in the sources.
*   $\tau_{\text{conf}}$: Confidence threshold for filtering matches. If no match survives ($w_k > \tau_{\text{conf}}$), the loss for that region falls back to zero [S1].

**Edge Cases and Pitfalls**
*   **Geometric Degeneracy:** As a Gaussian's smallest eigenvalue $\lambda_{\min}$ approaches zero, the gradient of the log-eigenvalue shape loss scales inversely with $\lambda$ ($|\partial \mathcal{L}/\partial \lambda| \propto 1/\lambda$) [S1]. This creates a strong repulsive effect that pushes $\lambda_{\min}$ away from zero, preventing collapsed artifacts [S1].
*   **Ambiguous Regions:** If no match survives the confidence gating, the MAC loss is zero for that region, allowing the network to rely solely on photometric supervision [S1].
*   **Coordinate Systems:** Covariance matrices must be transformed using the rotation matrix $R$ from $T_{wc}$ to maintain consistency in the world frame [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of matched pixel pairs $K$ and the cost of bilinear sampling and eigenvalue decomposition. Eigenvalue decomposition of $3 \times 3$ symmetric matrices is constant time.
*   **Memory Complexity:** Requires storing dense parameter maps for all views involved in the matching process.
*   **Strengths:** Robust to outliers due to Huber loss and confidence weighting. Prevents geometric degeneracy. Improves performance under sparse-view conditions and large camera pose gaps [S1].
*   **Limitations:** Requires reliable 2D correspondences (e.g., from MASt3R/DINOv3). Performance degrades if correspondences are inaccurate or if confidence estimation is poor [S1].
*   **When to use:** Sparse-view reconstruction where photometric loss alone is ambiguous.
*   **When not to use:** Dense-view scenarios with abundant, unambiguous correspondences where photometric loss is sufficient.

## Background
The MAC loss was introduced in "MAC-Splat: Multi-Attribute Consistency for High-Fidelity Sparse-View Reconstruction" [S1]. It builds on the MASt3R geometric backbone and a frozen DINOv3 encoder to obtain semantically informed 2D correspondences [S1]. The method is designed to resolve ambiguities in 3D optimization for sparse-view reconstruction by leveraging semantic information [S1].
