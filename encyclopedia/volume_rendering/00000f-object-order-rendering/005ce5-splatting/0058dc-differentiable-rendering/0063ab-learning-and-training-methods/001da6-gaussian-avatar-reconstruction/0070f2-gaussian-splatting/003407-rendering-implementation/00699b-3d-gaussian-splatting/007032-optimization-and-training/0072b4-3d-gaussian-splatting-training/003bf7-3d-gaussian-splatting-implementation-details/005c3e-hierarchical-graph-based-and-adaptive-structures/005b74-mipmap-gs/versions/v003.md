# Mipmap-GS

Also called: Mipmap-Gaussian Splatting

## Overview
Mipmap-GS is a test-time adaptation method that deforms pre-trained 3D Gaussians into scale-adaptive primitives to eliminate aliasing artifacts (spikes during zoom-in and excessive thickness during zoom-out) caused by fixed Gaussian distributions and constant dilation at varying zoom factors [S1]. Unlike sibling methods that apply heuristic 2D/3D smoothing filters or hierarchical Level-of-Detail selection, Mipmap-GS self-adjusts primitive properties (color, shape, size) and distribution (position) by supervising the deformation against scale-specific mipmap-like pseudo ground-truth, thereby preserving high-frequency details while accommodating arbitrary sampling rates [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of single-scale trained base Gaussians $\mathcal{G} = \{G_k\}_{k=1}^K$, where each $G_k$ is defined by mean position $\mathbf{X}_k$, covariance $\Sigma_k$ (parameterized by rotation $\mathbf{R}_k$ and scaling $\mathbf{S}_k$), opacity $\alpha_k$, and color $\mathbf{c}_k$; a set of novel view viewpoints $\mathcal{V} = \{v_j\}_{j=1}^J$; a target zoom factor $N$; and the number of adaptation iterations $S$ [S1].
*   **Output:** A set of optimized, scale-adaptive Gaussians $\mathcal{G}^{opt} = \{G^{opt}_k\}_{k=1}^K$ [S1].

**Data Structures:**
The method operates on the standard 3DGS primitive representation. No new hierarchical data structures (like trees or graphs) are introduced; the adaptation modifies the parameters of the existing flat list of Gaussians [S1].

**Parameters:**
*   $N$: The zoom factor. For zoom-in, $N > 1$ (upsampling); for zoom-out, $N < 1$ (downsampling, often specified as $1/N$ where $N>1$) [S1].
*   $S$: Number of adaptation iterations. The sources specify $S = 1000$ (1K iterations) [S1].
*   $\beta$: Learning rate for the optimization step [S1].
*   $r(\cdot)$: The mipmap resizing function. For zoom-in, super-resolution methods like SwinIR are used; for zoom-out, bilinear interpolation is used [S1].

**Algorithm Steps:**
1.  **Base Rendering:** For a randomly selected viewpoint $v_j$, render the base Gaussians $\mathcal{G}$ to obtain a basic scale image $\hat{x}_j$ [S1].
2.  **Pseudo-GT Construction:** Apply the resizing function $r(\cdot)$ to $\hat{x}_j$ to create the scale-specific pseudo ground-truth $r(\hat{x}_j)$. If zooming in by factor $N$, upsample $\hat{x}_j$ by $\times N$. If zooming out by factor $1/N$, downsample $\hat{x}_j$ by $\times 1/N$ [S1].
3.  **Adaptive Rendering:** Render the current optimized Gaussians $\mathcal{G}^{opt}$ (initially $\mathcal{G}$) to the target scale to produce image $x_j$ [S1].
4.  **Loss Computation:** Calculate the scale-aware guidance loss $L(x_j, r(\hat{x}_j))$ using the L2 norm between the rendered image $x_j$ and the pseudo-GT $r(\hat{x}_j)$ [S1].
5.  **Optimization Step:** Update the Gaussians using gradient descent:
    $$ G^{opt} = G - \beta \nabla L(x, r(\hat{x})) $$
    where $G$ represents the parameters of the Gaussians being optimized [S1].
6.  **Pruning/Densification:** If the current iteration $i$ is a multiple of 100 ($i \mod 100 == 0$), perform densification or pruning operations to maintain a compact representation [S1].
7.  **Iteration:** Repeat steps 1–6 for $S$ iterations.

**Pseudocode:**
```python
def mipmap_gs_optimize(base_gaussians, viewpoints, zoom_factor, iterations):
    """
    Deforms base Gaussians to be adaptive for a specific zoom scale.
    
    Args:
        base_gaussians: List of Gaussian primitives {G_k}.
        viewpoints: List of camera viewpoints {v_j}.
        zoom_factor: Float N. >1 for zoom-in (upsample), <1 for zoom-out (downsample).
                     Note: The source uses N for upsampling factor and 1/N for downsampling.
                     Here we assume zoom_factor is the multiplier for the image resolution.
        iterations: Integer S (default 1000).
        
    Returns:
        optimized_gaussians: List of deformed Gaussian primitives.
    """
    current_gaussians = copy(base_gaussians)
    
    for i in range(iterations):
        # 1. Select viewpoint
        v_j = random.choice(viewpoints)
        
        # 2. Render base Gaussians to basic scale image x_hat
        # This renders the ORIGINAL base Gaussians, not the currently optimized ones,
        # to generate the stable pseudo-GT source.
        x_hat_j = render(base_gaussians, v_j)
        
        # 3. Construct mipmap-like pseudo-GT r(x_hat)
        if zoom_factor > 1:
            # Zoom-in: Upsample using super-resolution (e.g., SwinIR)
            pseudo_gt = super_resolution_upsample(x_hat_j, factor=zoom_factor)
        else:
            # Zoom-out: Downsample using bilinear interpolation
            # zoom_factor is effectively 1/N where N > 1
            downsample_factor = 1.0 / zoom_factor
            pseudo_gt = bilinear_downsample(x_hat_j, factor=downsample_factor)
            
        # 4. Render optimized Gaussians to new scale image x
        # The rendering must account for the new scale. In standard splatting,
        # this is achieved by adjusting the projection matrix or the Gaussian
        # covariance scaling relative to the pixel grid.
        x_j = render(current_gaussians, v_j, scale=zoom_factor)
        
        # 5. Compute Loss L(x, r(x_hat)) = ||x - r(x_hat)||_2
        loss = l2_loss(x_j, pseudo_gt)
        
        # 6. Optimize Gaussians
        # G_opt = G - beta * grad(L)
        gradients = compute_gradients(loss, current_gaussians)
        current_gaussians = apply_gradient(current_gaussians, gradients, learning_rate=beta)
        
        # 7. Active Pruning/Densification every 100 iterations
        if i % 100 == 0:
            current_gaussians = densify_or_prune(current_gaussians)
            
    return current_gaussians
```

**Edge Cases and Pitfalls:**
*   **Zoom-in Spikes:** Caused by varying shrinkage bias during accumulation when sampling rates change. The fixed Gaussian field samples signals differently at higher resolutions, leading to confusion in accumulation [S1].
*   **Zoom-out Thickness:** Caused by constant dilation. The 2D dilation operation in standard 3DGS amplifies tiny Gaussians to cover at least one pixel. At zoom-out, this constant dilation leads to excessively wide coverage and thick structures, including Gaussians that should not contribute to the pixel [S1].
*   **High-Frequency Loss:** Unlike methods using smoothing filters (e.g., Mip-Splatting), Mipmap-GS avoids suppressing high-frequency components by deriving pseudo-GT on the fly, but improper resizing functions could introduce artifacts [S1].

## Subtopics

### Mip-Splatting
Uses heuristic 2D Mip filters and 3D smooth filters to suppress high-frequency components for anti-aliasing. It does not deform the Gaussians themselves. Mipmap-GS is chosen when preserving finer details is critical, as Mip-Splatting sacrifices them [S1].

### Octree-GS
Uses a hierarchical Level-of-Detail (LoD) architecture to arrange Gaussians. It selects LoDs based on distance/scale. Mipmap-GS is chosen when a plug-in solution that deforms the existing Gaussians without restructuring the scene hierarchy is preferred, as Octree-GS is sensitive to hyper-parameters and may have inaccurate pixel coverage selection [S1].

## Operating characteristics
*   **Time Complexity:** The method requires 1K iterations of optimization per novel view or scene scale. This is significantly faster than training from scratch, requiring only 3% of the iterations [S1].
*   **Memory Complexity:** The method maintains the same memory footprint as the base 3DGS representation, plus the storage for the resized pseudo-GT images during the brief optimization window. Active pruning during optimization reduces the final number of Gaussians, particularly for zoom-out scenarios, leading to a more compact representation than standard 3DGS [S1].
*   **Performance:** On the NeRF Synthetic dataset, Mipmap-GS outperforms standard 3DGS by an average of 9.25 dB in PSNR for zoom-in and 10.40 dB for zoom-out [S1]. Specifically, at $\times 1/2$ zoom-out on NeRF Synthetic, it achieves SSIM 0.971, PSNR 32.71, LPIPS 0.026, compared to 3DGS's SSIM 0.951, PSNR 27.14, LPIPS 0.031 [S1]. On Mip-NeRF 360 at $\times 1/2$ zoom-out, it achieves SSIM 0.854, PSNR 28.57, compared to 3DGS's SSIM 0.774, PSNR 26.66 [S1].
*   **Strengths:** Plug-in compatibility with any 3DGS model; no need for retraining from scratch; preserves high-frequency details better than filtering-based methods; active pruning ensures compactness [S1].
*   **Limitations:** Requires test-time optimization for each new scale/view, which adds latency compared to static inference; relies on the quality of the super-resolution/downsampling function $r(x)$ [S1].

## Background
Mipmap-GS was proposed by the authors of the paper "Mipmap-GS: Let Gaussians Deform with Scale-Specific Mipmap for Anti-Aliasing Rendering" [S1]. It addresses the limitations of standard 3D Gaussian Splatting [25] and related anti-aliasing methods like Mip-Splatting [67] and Octree-GS [43]. The method was developed to solve the aliasing artifacts inherent in fixed Gaussian representations when viewed at arbitrary zoom levels, leveraging the concept of mipmap-like pseudo ground-truth for self-supervised test-time adaptation [S1].
