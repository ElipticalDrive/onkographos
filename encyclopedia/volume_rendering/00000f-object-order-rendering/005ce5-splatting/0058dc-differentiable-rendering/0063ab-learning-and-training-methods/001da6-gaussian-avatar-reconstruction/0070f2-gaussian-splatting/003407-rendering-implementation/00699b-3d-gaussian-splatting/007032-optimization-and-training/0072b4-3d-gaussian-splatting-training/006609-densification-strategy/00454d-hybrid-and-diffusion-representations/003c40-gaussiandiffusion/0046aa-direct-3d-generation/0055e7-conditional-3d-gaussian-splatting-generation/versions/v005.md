# Conditional 3D Gaussian Splatting Generation

Also called: Conditional Generation (Text/Image/Partial), DiffGS Conditional

## Overview
Conditional 3D Gaussian Splatting Generation learns a feedforward or diffusion model to output 3D Gaussian Splatting (3DGS) representations directly conditioned on text prompts, input images, or partial 3DGS inputs containing large occlusions [S1]. It differs from its parent [Direct 3D Generation](11810-direct-3d-generation.md) by explicitly supporting completion tasks (inferring dense 3DGS from partial inputs) and leveraging specific encoders (CLIP, PointNet) to map diverse conditions into the Gaussian attribute space [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Text prompts, single/multiple reference images, or partial 3DGS point clouds/attributes [S1].
*   **Outputs:** A set of 3D Gaussians defined by position $\mathbf{p}$, covariance $\mathbf{\Sigma}$ (or rotation $\mathbf{R}$ and scale $\mathbf{S}$), opacity $\alpha$, and spherical harmonics coefficients $\mathbf{c}$ [S1].

**Data Structures:**
The method utilizes custom encoders to produce condition embeddings:
1.  **Text Encoder ($\gamma_{\text{text}}$):** A frozen CLIP text encoder [S1].
2.  **Image Encoder ($\gamma_{\text{image}}$):** A frozen CLIP image encoder [S1].
3.  **Partial Encoder ($\gamma_{\text{partial}}$):** A modified PointNet architecture used to encode partial 3DGS inputs [S1].

**Steps:**
1.  **Condition Encoding:**
    *   For text/image conditions, pass the input through the frozen CLIP encoders to obtain embeddings [S1].
    *   For partial 3DGS completion, pass the partial Gaussian attributes through the modified PointNet encoder $\gamma_{\text{partial}}$ to obtain a latent representation [S1].
2.  **Diffusion/Generation Training:**
    *   Train the DiffGS model using the conditional optimization objective defined in Eq.(8) of the source [S1]. The objective aligns the generated Gaussian field with the condition embedding [S1].
3.  **Inference:**
    *   Sample from the trained diffusion model or feedforward network using the encoded condition to predict the full set of Gaussian attributes [S1].

**Parameters:**
*   **Dataset:** Experiments are conducted on the ShapeNet chair class with commonly used data splits [S1].
*   **Encoder State:** CLIP encoders are frozen [S1].

**Edge Cases and Pitfalls:**
*   **Partial Input Occlusion:** The method must handle highly occluded inputs where significant geometry is missing; the PointNet encoder is specifically modified to address this [S1].
*   **Numerical Stability:** In related text-to-3D implementations, Gaussian opacity is clamped to a fixed range (e.g., $[0.004, 0.99]$) during rendering and optimization to ensure stable gradients and prevent overflow/underflow [S3].

## Subtopics

### [Gaussian Pulling to Zero-Level Set](15791-gaussian-pulling-to-zero-level-set.md)
A training optimization technique for 3D Gaussian Splatting that enforces geometric consistency by aligning Gaussian primitives with a neural Signed Distance Function (SDF) field. It solves the problem of "floating ellipsoids" and inaccurate surface estimation in standard 3DGS by pulling Gaussian centers onto the zero-level set of the SDF and pulling query points onto Gaussian disks rather than centers. This approach bridges the gap between continuous SDF representations and sparse Gaussian distributions, providing a denser, more continuous surface representation than single-point ray intersection.

### [Promptable Explicit Scene Representation](15906-promptable-explicit-scene-representation.md)
A mechanism for 3D editing (extraction, deletion, appearance modification) in 3D Gaussian Splatting by computing activation scores of 3D Gaussians based on prompts (text, points, boxes) using cosine similarity and softmax. It differs from implicit NeRF feature fields by operating on explicit Gaussian primitives, allowing direct manipulation of color and opacity parameters for specific semantic subsets.

### Interactive3D
A method operating in two stages for interactive 3D object generation and refinement [S2]. In the first stage, it optimizes 3D objects through 3DGS and SDS (Score Distillation Sampling), allowing flexible interactions like adding/removing parts, geometry transformation, deformable/rigid dragging, and semantic editing [S2]. In the second stage, the model is transformed into an InstantNGP structure with an interactive hash refinement module applied to improve specific details [S2].

### 3D Gaussian Splatting (Text-to-3D Implementation)
A reimplementation of 3D Gaussian Splatting adapted for text-to-3D generation, modified to support a learnable MLP background and specific gradient propagation [S3]. It differs from the official implementation by calculating gradients in the forward rendering order rather than the inverse order, which simplifies per-pixel background integration [S3]. Depth maps are rendered by sampling the view-space depth at the centers of the Gaussians, and a z-variance renderer is implemented to compute z-variance for a z-var loss term [S3]. The target number of Gaussians after densification is typically between $10^5$ and $10^6$ [S3].

## Background
The method originates from DiffGS (Functional Gaussian Splatting Diffusion) [S1]. It was developed to address the limitations of previous diffusion-based 3D generation methods (like DiffTF) which produced blurry results [S1]. The work explores conditional generation capabilities including text/image-conditional generation and Gaussian Splatting completion, claiming to be the first to focus on the latter task [S1]. Related implementations for text-to-3D have been adapted to support learnable backgrounds and specific gradient propagation strategies [S3].
