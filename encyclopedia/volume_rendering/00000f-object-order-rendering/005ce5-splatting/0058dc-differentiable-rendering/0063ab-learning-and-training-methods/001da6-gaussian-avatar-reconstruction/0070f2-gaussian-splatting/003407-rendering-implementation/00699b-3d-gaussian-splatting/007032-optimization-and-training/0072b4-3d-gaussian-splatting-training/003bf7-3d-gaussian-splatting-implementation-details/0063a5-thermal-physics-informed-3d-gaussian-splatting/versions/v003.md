# Thermal-Physics-Informed 3D Gaussian Splatting

Also called: TPI-GS

## Overview
Thermal-Physics-Informed 3D Gaussian Splatting (TPI-GS) is a framework that embeds infrared radiative transfer modeling into the 3D Gaussian Splatting (3DGS) representation, transforming Gaussian primitives into thermophysical radiative elements to enable physically interpretable infrared scene representation and novel view synthesis [S1]. Unlike standard 3DGS, which relies on view-dependent color blending via spherical harmonics to approximate photometric appearance, TPI-GS replaces this with physics-driven radiance integration based on Planck’s law, explicitly modeling atmospheric attenuation and sensor response [S1]. This approach bridges classical infrared simulation theory with neural point-based rendering, allowing for joint optimization of geometric structure and thermal radiation fields under multi-view supervision [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view infrared images of a scene; initial 3D Gaussian point cloud (position, covariance, opacity) derived from Structure-from-Motion (SfM) or similar initialization [S1].
*   **Outputs:** A set of 3D Gaussian primitives parameterized by geometric attributes and thermophysical fields, capable of rendering novel-view infrared images with radiometric coherence [S1].

**Data Structures:**
Each 3D Gaussian primitive $i$ is augmented with the following learnable parameters in addition to the standard 3DGS geometric parameters (position $\mathbf{p}_i$, rotation $\mathbf{q}_i$, scale $\mathbf{s}_i$, opacity $\alpha_i$):
1.  **Emissivity ($\epsilon_i$):** A scalar or vector parameter modeling surface thermal radiation properties [S1].
2.  **Temperature ($T_i$):** A scalar parameter modeling the thermal state of the primitive [S1].
3.  **Thermal Texture ($\mathbf{t}_i$):** A parameter modeling spatial thermal variations [S1].

**Step-by-Step Method:**
1.  **Thermophysical Parameterization:** Initialize each Gaussian primitive with learnable emissivity $\epsilon_i$, temperature $T_i$, and thermal texture $\mathbf{t}_i$ [S1]. These parameters are optimized jointly with geometric parameters [S1].
2.  **Spectral Radiance Calculation:** For each Gaussian primitive, compute the spectral radiant exitance $M_{\lambda, i}$ using Planck’s law [S1]:
    $$ M_{\lambda, i} = \epsilon_i \frac{2hc^2}{\lambda^5} \frac{1}{e^{\frac{hc}{\lambda k_B T_i}} - 1} $$
    Where $h$ is Planck’s constant, $c$ is the speed of light, $k_B$ is Boltzmann’s constant, $\lambda$ is the wavelength of the infrared radiation, $T_i$ is the temperature of the primitive, and $\epsilon_i$ is the emissivity of the primitive [S1].
3.  **Radiance Accumulation (Rendering):** Render the infrared image by accumulating radiance along the viewing ray [S1]. Unlike standard 3DGS which blends spherical harmonic coefficients, TPI-GS performs physics-driven radiance integration [S1]. The total radiance $L_{total}$ reaching the camera is computed by summing the contributions of all splatted Gaussians using front-to-back alpha compositing, modified by atmospheric attenuation and sensor response [S1]:
    $$ L_{total} = \sum_{i \in \text{sorted}} M_{\lambda, i} \cdot \tau_{atm}(d_i) \cdot \alpha_i \prod_{j < i} (1 - \alpha_j) + L_{sensor} $$
    Where $\alpha_i$ is the opacity of the $i$-th Gaussian, $M_{\lambda, i}$ is the spectral radiant exitance of the $i$-th Gaussian, $\tau_{atm}(d_i)$ is the atmospheric transmittance factor at distance $d_i$ explicitly modeled to account for path-dependent attenuation, and $L_{sensor}$ accounts for sensor response [S1].
4.  **Frequency-Domain Supervision:** To mitigate the inherent smoothing effect of Gaussian splatting and improve high-frequency texture fidelity, apply a Discrete Wavelet Transform (DWT) to the rendered infrared images and the ground truth [S1]. Compute a loss in the frequency domain to supervise the reconstruction [S1].
5.  **Joint Optimization:** Optimize the geometric parameters ($\mathbf{p}_i, \mathbf{q}_i, \mathbf{s}_i, \alpha_i$) and thermophysical parameters ($\epsilon_i, T_i, \mathbf{t}_i$) simultaneously using gradient descent [S1]. The loss function combines photometric error in infrared space and the DWT-based frequency supervision loss under multi-view constraints [S1].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def planck_radiance(wavelength, temperature, emissivity):
    h, c, k_B = 6.62607015e-34, 299792458.0, 1.380649e-23
    exponent = torch.clamp((h * c) / (wavelength * k_B * temperature), max=700.0)
    return emissivity * (2 * h * c**2) / (wavelength**5) / (torch.exp(exponent) - 1)

def render_tpi_gs(gaussians, camera_intrinsics, camera_extrinsics, wavelength, attenuation_coeff):
    # 1. Project 3D Gaussians to 2D screen space and sort by depth [G]
    centers_3d = gaussians.position
    centers_cam = (camera_extrinsics @ torch.cat([centers_3d, torch.ones_like(centers_3d[:, :1])], dim=1).T).T[:, :3]
    centers_2d = (camera_intrinsics @ centers_cam.T).T
    centers_2d = centers_2d[:, :2] / centers_2d[:, 2:]
    depths = centers_cam[:, 2]
    sort_idx = torch.argsort(depths)
    sorted_gaussians = gaussians[sort_idx]
    sorted_centers_2d = centers_2d[sort_idx]
    sorted_depths = depths[sort_idx]

    H, W = int(camera_intrinsics[0, 0]), int(camera_intrinsics[1, 1])
    rendered_image = torch.zeros((H, W), device=gaussians.position.device)
    accumulated_alpha = torch.zeros((H, W), device=gaussians.position.device)

    # 2. Front-to-back alpha compositing with physics-driven radiance [G]
    for i in range(len(sorted_gaussians)):
        g = sorted_gaussians[i]
        center = sorted_centers_2d[i]
        depth = sorted_depths[i]

        # Compute spectral radiance via Planck's law [S1]
        L_lambda = planck_radiance(wavelength, g.temperature, g.emissivity)

        # Apply atmospheric attenuation [S1]
        tau = torch.exp(-attenuation_coeff * depth)
        L_eff = L_lambda * tau

        # Compute 2D Gaussian weights for pixels in bounding box [G]
        x_min, y_min = max(0, int(center[0] - 3 * torch.sqrt(g.cov_2d[0, 0]))), max(0, int(center[1] - 3 * torch.sqrt(g.cov_2d[1, 1])))
        x_max, y_max = min(W, int(center[0] + 3 * torch.sqrt(g.cov_2d[0, 0]))), min(H, int(center[1] + 3 * torch.sqrt(g.cov_2d[1, 1])))
        for y in range(y_min, y_max):
            for x in range(x_min, x_max):
                dx, dy = x - center[0], y - center[1]
                weight = torch.exp(-0.5 * torch.tensor([dx, dy]) @ torch.linalg.inv(g.cov_2d) @ torch.tensor([dx, dy]))
                alpha_contribution = g.opacity * weight
                if accumulated_alpha[y, x] < 1.0:
                    rendered_image[y, x] += L_eff * alpha_contribution * (1.0 - accumulated_alpha[y, x])
                    accumulated_alpha[y, x] += alpha_contribution
    return rendered_image

def compute_dwt_loss(rendered, ground_truth):
    def haar_dwt2(img):
        h, w = img.shape
        cA = F.avg_pool2d(img.unsqueeze(0), 2).squeeze(0)
        cH = F.avg_pool2d((img[:, :-1] - img[:, 1:]).unsqueeze(0), 2).squeeze(0)
        cV = F.avg_pool2d((img[:-1, :] - img[1:, :]).unsqueeze(0), 2).squeeze(0)
        cD = F.avg_pool2d(((img[:-1, :-1] - img[1:, 1:]) - (img[:-1, 1:] - img[1:, :-1])).unsqueeze(0), 2).squeeze(0)
        return cA, cH, cV, cD
    coeffs_r = haar_dwt2(rendered)
    coeffs_gt = haar_dwt2(ground_truth)
    return sum(torch.mean(torch.abs(cr - cg)) for cr, cg in zip(coeffs_r, coeffs_gt))

def compute_loss(rendered_image, ground_truth_image):
    photometric_loss = torch.mean(torch.abs(rendered_image - ground_truth_image))
    freq_loss = compute_dwt_loss(rendered_image, ground_truth_image)
    return photometric_loss + 0.1 * freq_loss
```
