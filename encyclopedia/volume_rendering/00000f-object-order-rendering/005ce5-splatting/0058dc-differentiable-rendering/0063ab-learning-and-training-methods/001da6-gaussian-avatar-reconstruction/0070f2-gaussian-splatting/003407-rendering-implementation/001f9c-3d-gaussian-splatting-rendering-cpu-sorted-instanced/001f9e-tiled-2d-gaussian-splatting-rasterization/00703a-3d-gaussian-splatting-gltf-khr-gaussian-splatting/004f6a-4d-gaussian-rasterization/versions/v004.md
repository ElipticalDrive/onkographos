# 4D Gaussian Rasterization

Also called: 3D Gaussian Rasterization, 4D Gaussian Splatting Forward Pass, 4DGS Render, Gaussian Rasterization Rendering, Q1 Render

## Overview
4D Gaussian Rasterization renders a scene represented by 4D Gaussians (3D spatial + 1D temporal) into a 2D image for a specific viewpoint and timestamp [S2, unofficial]. It extends the static 3D Gaussian Splatting rendering pipeline by handling time-dependent opacity, position offsets, and spherical harmonics evaluation in 4D [S2, unofficial]. It differs from its parent method by supporting dynamic scenes through temporal attributes and 4D covariance transformations, while maintaining the differentiable rasterization core of [3D Gaussian Splatting Rendering (CPU-Sorted, Instanced)](52-3d-gaussian-splatting-rendering.md).

## How it works
**Inputs:**
- `viewpoint_camera`: Object containing `FoVx`, `FoVy`, `image_height`, `image_width`, `world_view_transform` (4x4), `full_proj_transform` (4x4), `camera_center` (3,), `timestamp` (float), `time_duration` (float).
- `pc`: GaussianModel object containing attributes: `get_xyz` (N,3), `get_opacity` (N,), `get_scaling` (N,3 or N,1), `get_rotation` (N,4), `get_features` (N, K), `active_sh_degree` (int), `active_sh_degree_t` (int), `rot_4d` (bool), `gaussian_dim` (int, 3 or 4), `force_sh_3d` (bool), `time_duration` (tuple/list), `prefilter_var` (float, optional).
- `pipe`: Configuration object containing `compute_cov3D_python` (bool), `convert_SHs_python` (bool), `env_map_res` (int, optional).
- `bg_color`: torch.Tensor (3,), background color on GPU.
- `scaling_modifier`: float, default 1.0.

**Outputs:**
- Dictionary with keys: `render` (C, H, W), `viewspace_points` (N,2), `visibility_filter` (N, bool), `radii` (N,), `depth` (H, W), `alpha` (H, W), `flow` (H, W, 2, optional), `covs_com` (optional).

**Data Structures:**
- `GaussianRasterizationSettings`: Struct holding image dimensions, FOV tangents, background, scale modifier, view/projection matrices, SH degrees, camera position, timestamp, time duration, 4D rotation flag, Gaussian dimension, and debug flags.
- `GaussianRasterizer`: CUDA kernel wrapper initialized with settings.
- `screenspace_points`: Zero tensor on CUDA with `requires_grad=True`, shape (N, 2), storing gradients of 2D screen-space means.

**Steps:**

1. **Initialization**: If `pc.get_xyz.shape[0] == 0`, return `None` [S1, unofficial]. Initialize `screenspace_points` as a zero tensor on CUDA with `requires_grad=True` [S2, unofficial].
2. **Camera Parameters**: Compute tangent FOV values:
   $$ \text{tanfovx} = \tan(\text{viewpoint\_camera.FoVx} \times 0.5) $$
   $$ \text{tanfovy} = \tan(\text{viewpoint\_camera.FoVy} \times 0.5) $$
   [S1, S2, unofficial].
3. **Rasterization Settings**: Construct `GaussianRasterizationSettings` with:
   - `image_height`, `image_width` from `viewpoint_camera`.
   - `tanfovx`, `tanfovy`.
   - `bg`: `bg_color` if `pipe.env_map_res` is not set, else `torch.zeros(3, device="cuda")` [S2, unofficial].
   - `scale_modifier`: `scaling_modifier`.
   - `viewmatrix`: `viewpoint_camera.world_view_transform`.
   - `projmatrix`: `viewpoint_camera.full_proj_transform`.
   - `sh_degree`: `pc.active_sh_degree`.
   - `sh_degree_t`: `pc.active_sh_degree_t`.
   - `campos`: `viewpoint_camera.camera_center`.
   - `timestamp`: `viewpoint_camera.timestamp`.
   - `time_duration`: `pc.time_duration[1] - pc.time_duration[0]` [S2, unofficial].
   - `rot_4d`: `pc.rot_4d`.
   - `gaussian_dim`: `pc.gaussian_dim`.
   - `force_sh_3d`: `pc.force_sh_3d`.
   - `prefiltered`: Boolean indicating if prefiltering is applied [S2, unofficial].
   [S2, unofficial].
4. **Rasterizer Initialization**: Initialize `GaussianRasterizer` with the configured settings [S2, unofficial].
5. **Attribute Retrieval & Preprocessing**:
   - Retrieve `means3D = pc.get_xyz`, `opacity = pc.get_opacity` [S1, unofficial].
   - If `pipe.compute_cov3D_python` is true:
     - Compute `cov3D_precomp = pc.get_covariance(scaling_modifier)` [S1, unofficial].
     - If `pc.gaussian_dim == 4`, apply mean offset to `means3D` if `pc.rot_4d` is true [S2, unofficial].
     - If `pc.gaussian_dim == 4`, multiply `opacity` by marginal time probability `marginal_t` [S2, unofficial].
   - Else (`pipe.compute_cov3D_python` is false):
     - Set `cov3D_precomp = None` [S1, unofficial].
     - Retrieve raw `scales`, `rotations`, and if `pc.gaussian_dim == 4`, retrieve `scales_t`, `ts`, and `rotations_r` if `pc.rot_4d` is true [S2, unofficial].
     - Retrieve `prefilter_var` if `pc.prefilter_var > 0` [S2, unofficial].
   - If `pc.get_scaling.shape[-1] == 1`, `scales = pc.get_scaling.repeat(1, 3)`, else `scales = pc.get_scaling` [S1, unofficial].
   - `rotations = pc.get_rotation` [S1, unofficial].
6. **Prefiltering (Optional)**:
   - If `pipe.compute_cov3D_python` and `pc.gaussian_dim == 4`:
     - Create boolean mask where `marginal_t[:, 0] > 0.05` [S2, unofficial].
     - Filter all relevant tensors (`means2D`, `means3D`, `ts`, `shs`, `colors_precomp`, `opacity`, `scales`, `scales_t`, `rotations`, `rotations_r`, `cov3D_precomp`, `flow_2d`) using this mask [S2, unofficial].
7. **Color Computation**:
   - If `pipe.convert_SHs_python` is true:
     - Extract SH features: `shs_view = pc.get_features.transpose(1, 2).view(-1, 3, (pc.max_sh_degree + 1)^2)` [S1, unofficial].
     - Compute direction vectors `dir_pp = pc.get_xyz - viewpoint_camera.camera_center.repeat(N, 1)` [S1, unofficial].
     - Normalize: `dir_pp_normalized = dir_pp / dir_pp.norm(dim=1, keepdim=True)` [S1, unofficial].
     - If `pc.gaussian_dim == 3` or `force_sh_3d`:
       - `sh2rgb = eval_sh(pc.active_sh_degree, shs_view, dir_pp_normalized)` [S1, S2, unofficial].
     - If `pc.gaussian_dim == 4`:
       - Compute temporal direction `dir_t` [S2, unofficial].
       - `sh2rgb = eval_shfs_4d(spatial_dir=dir_pp_normalized, temporal_dir=dir_t, sh=shs_view, degree=pc.active_sh_degree, degree_t=pc.active_sh_degree_t, timestamp=viewpoint_camera.timestamp, time_duration=time_duration)` [S2, unofficial].
     - `colors_precomp = clamp_min(sh2rgb + 0.5, 0.0)` [S1, S2, unofficial].
   - Else:
     - `shs = pc.get_features` [S1, unofficial].
     - `colors_precomp = None` [S1, unofficial].
8. **Rasterization Call**:
   - Call `rasterizer` with inputs:
     - `means3D`, `means2D` (screenspace_points), `shs` (if `colors_precomp` is None), `colors_precomp` (if `shs` is None), `flows` (if available), `opacity`, `ts`, `scales`, `scales_t`, `rotations`, `rotations_r`, `scale_modifier`, `cov3D_precomp`, `prefilter_var`, `viewmatrix`, `projmatrix`, `tan_fovx`, `tan_fovy`, `image_height`, `image_width`, `sh` (if `colors_precomp` is None), `degree`, `degree_t`, `campos`, `timestamp`, `time_duration`, `rot_4d`, `gaussian_dim`, `force_sh_3d`, `prefiltered`, `debug` [S2, unofficial].
   - Returns `rendered_image`, `radii`, `depth`, `alpha`, `flow`, `covs_com` [S2, unofficial].
9. **Post-Processing**:
   - If `pipe.env_map_res` is set:
     - Compute environment map background. Calculate ray intersection with sphere radius $R=60$ using `rays_o` and `rays_d`. Compute intersection parameter `t_inter` and point `xyz_inter`. Convert to spherical coordinates `tu` (theta) and `tv` (phi) normalized to [-1, 1]. Sample `pc.env_map` using `F.grid_sample`. Add to `rendered_image` weighted by `(1 - alpha)` [S2, unofficial].
   - Construct `radii_all`: Zero-initialize tensor of size `mask.shape` (if prefiltered) or use original `radii`. If prefiltered, assign original `radii` to positions indicated by `mask` [S2, unofficial].
   - Return dictionary: `rendered_image`, `viewspace_points` (screenspace_points), `visibility_filter` (`radii_all > 0`), `radii_all`, `depth`, `alpha`, `flow` [S1, S2, unofficial].

**Pseudocode:**

```python
import torch
import math
from torch.nn import functional as F

def render_4d_gaussian(viewpoint_camera, pc, pipe, bg_color, scaling_modifier=1.0):
    # 1. Initialization
    if pc.get_xyz.shape[0] == 0:
        return None
    
    screenspace_points = torch.zeros_like(pc.get_xyz, dtype=pc.get_xyz.dtype, requires_grad=True, device="cuda") + 0
    try:
        screenspace_points.retain_grad()
    except:
        pass

    # 2. Camera Parameters
    tanfovx = math.tan(viewpoint_camera.FoVx * 0.5)
    tanfovy = math.tan(viewpoint_camera.FoVy * 0.5)

    # 3. Rasterization Settings
    raster_settings = GaussianRasterizationSettings(
        image_height=int(viewpoint_camera.image_height),
        image_width=int(viewpoint_camera.image_width),
        tanfovx=tanfovx,
        tanfovy=tanfovy,
        bg=bg_color if not pipe.env_map_res else torch.zeros(3, device="cuda"),
        scale_modifier=scaling_modifier,
        viewmatrix=viewpoint_camera.world_view_transform,
        projmatrix=viewpoint_camera.full_proj_transform,
        sh_degree=pc.active_sh_degree,
        sh_degree_t=pc.active_sh_degree_t,
        campos=viewpoint_camera.camera_center,
        timestamp=viewpoint_camera.timestamp,
        time_duration=pc.time_duration[1] - pc.time_duration[0],
        rot_4d=pc.rot_4d,
        gaussian_dim=pc.gaussian_dim,
        force_sh_3d=pc.force_sh_3d,
        prefiltered=False # Placeholder, determined in step 6
    )

    # 4. Rasterizer Initialization
    rasterizer = GaussianRasterizer(raster_settings=raster_settings)

    # 5. Attribute Retrieval & Preprocessing
    means3D = pc.get_xyz
    opacity = pc.get_opacity
    
    if pipe.compute_cov3D_python:
        cov3D_precomp = pc.get_covariance(scaling_modifier)
        if pc.gaussian_dim == 4 and pc.rot_4d:
            # Apply mean offset to means3D [S2, unofficial]
            # Note: Exact offset logic depends on pc implementation, assumed available
            means3D = means3D + pc.get_mean_offset() 
        if pc.gaussian_dim == 4:
            marginal_t = compute_marginal_time_probability(pc, viewpoint_camera.timestamp)
            opacity = opacity * marginal_t[:, 0]
    else:
        cov3D_precomp = None
        scales = pc.get_scaling
        if scales.shape[-1] == 1:
            scales = scales.repeat(1, 3)
        rotations = pc.get_rotation
        if pc.gaussian_dim == 4:
            scales_t = pc.get_scales_t()
            ts = pc.get_ts()
            rotations_r = pc.get_rotations_r() if pc.rot_4d else None
        prefilter_var = pc.prefilter_var if hasattr(pc, 'prefilter_var') else 0.0

    # 6. Prefiltering (Optional)
    mask = None
    if pipe.compute_cov3D_python and pc.gaussian_dim == 4:
        marginal_t = compute_marginal_time_probability(pc, viewpoint_camera.timestamp)
        mask = marginal_t[:, 0] > 0.05
        if mask is not None:
            means3D = means3D[mask]
            opacity = opacity[mask]
            cov3D_precomp = cov3D_precomp[mask] if cov3D_precomp is not None else None
            # Filter other attributes if not precomputed
            if not pipe.compute_cov3D_python:
                scales = scales[mask]
                rotations = rotations[mask]
                if pc.gaussian_dim == 4:
                    scales_t = scales_t[mask]
                    ts = ts[mask]
                    if pc.rot_4d:
                        rotations_r = rotations_r[mask]

    # 7. Color Computation
    if pipe.convert_SHs_python:
        shs_view = pc.get_features.transpose(1, 2).view(-1, 3, (pc.max_sh_degree + 1)**2)
        dir_pp = pc.get_xyz - viewpoint_camera.camera_center.repeat(pc.get_xyz.shape[0], 1)
        dir_pp_normalized = dir_pp / dir_pp.norm(dim=1, keepdim=True)
        
        if pc.gaussian_dim == 3 or pc.force_sh_3d:
            sh2rgb = eval_sh(pc.active_sh_degree, shs_view, dir_pp_normalized)
        elif pc.gaussian_dim == 4:
            dir_t = compute_temporal_direction(pc, viewpoint_camera.timestamp, raster_settings.time_duration)
            sh2rgb = eval_shfs_4d(dir_pp_normalized, dir_t, shs_view, pc.active_sh_degree, pc.active_sh_degree_t, viewpoint_camera.timestamp, raster_settings.time_duration)
        
        colors_precomp = torch.clamp(sh2rgb + 0.5, min=0.0)
        shs = None
    else:
        shs = pc.get_features
        colors_precomp = None

    # 8. Rasterization Call
    # Note: In 4DGS, the rasterizer kernel handles 4D covariance and SH evaluation internally if configured
    # The following arguments map to the CUDA kernel signature in [S2, unofficial]
    rendered_image, radii, depth, alpha, flow, covs_com = rasterizer(
        means3D=means3D,
        means2D=screenspace_points,
        shs=shs,
        colors_precomp=colors_precomp,
        flows=None, # Placeholder if flow is not used
        opacity=opacity,
        ts=ts if pc.gaussian_dim == 4 else None,
        scales=scales if not pipe.compute_cov3D_python else None,
        scales_t=scales_t if pc.gaussian_dim == 4 and not pipe.compute_cov3D_python else None,
        rotations=rotations if not pipe.compute_cov3D_python else None,
        rotations_r=rotations_r if pc.gaussian_dim == 4 and pc.rot_4d and not pipe.compute_cov3D_python else None,
        scale_modifier=scaling_modifier,
        cov3D_precomp=cov3D_precomp,
        prefilter_var=prefilter_var if not pipe.compute_cov3D_python else 0.0,
        viewmatrix=raster_settings.viewmatrix,
        projmatrix=raster_settings.projmatrix,
        tan_fovx=raster_settings.tanfovx,
        tan_fovy=raster_settings.tanfovy,
        image_height=raster_settings.image_height,
        image_width=raster_settings.image_width,
        degree=raster_settings.sh_degree,
        degree_t=raster_settings.sh_degree_t,
        campos=raster_settings.campos,
        timestamp=raster_settings.timestamp,
        time_duration=raster_settings.time_duration,
        rot_4d=raster_settings.rot_4d,
        gaussian_dim=raster_settings.gaussian_dim,
        force_sh_3d=raster_settings.force_sh_3d,
        prefiltered=mask is not None,
        debug=False
    )

    # 9. Post-Processing
    if pipe.env_map_res:
        # Compute env map background
        # rays_o, rays_d derived from camera and pixel coordinates
        # t_inter, xyz_inter computed
        # tu, tv normalized
        # env_bg = F.grid_sample(pc.env_map, ...)
        # rendered_image = rendered_image + env_bg * (1 - alpha)
        pass

    radii_all = radii.clone()
    if mask is not None:
        radii_all_full = torch.zeros(pc.get_xyz.shape[0], device="cuda")
        radii_all_full[mask] = radii
        radii_all = radii_all_full
    
    visibility_filter = radii_all > 0

    return {
        'render': rendered_image,
        'viewspace_points': screenspace_points,
        'visibility_filter': visibility_filter,
        'radii': radii_all,
        'depth': depth,
        'alpha': alpha,
        'flow': flow
    }

def compute_marginal_time_probability(pc, timestamp):
    # Placeholder for marginal time probability calculation
    # Typically involves Gaussian PDF over time dimension
    return torch.ones_like(pc.get_opacity)

def compute_temporal_direction(pc, timestamp, time_duration):
    # Placeholder for temporal direction vector
    return torch.zeros_like(pc.get_xyz)
```

**Edge Cases and Pitfalls:**
- **Precision**: 4D covariance computation can suffer from numerical instability if not handled via block matrix inversion [S1, unofficial].
- **Boundaries**: Timestamps outside `time_duration` range may require clamping or extrapolation [S2, unofficial].
- **Degenerate Input**: Zero Gaussians return `None` [S1, unofficial].

## Subtopics

### [4D Gaussian Splatting (DreamGaussian4D)](14897-4d-gaussian-splatting-dreamgaussian4d.md)
4D Gaussian Splatting, specifically the DreamGaussian4D method, generates dynamic 4D scenes from a single reference image or video. It differs from sibling methods like AYG by learning motion from a driving video generated by an image-to-video model rather than using a video diffusion prior directly on the scene. It builds on [3D Gaussian Splatting Rendering (CPU-Sorted, Instanced)](52-3d-gaussian-splatting-rendering.md) by extending the static representation to 4D using HexPlane deformations.

### [DOF Gaussian Rendering Interface](21453-dof-gaussian-rendering-interface.md)
The DOF Gaussian Rendering Interface is the entry point for rendering a scene with Depth-of-Field Gaussian Splatting, accepting camera, model, pipeline, and optical parameters. It extends standard 3D Gaussian Splatting by allowing the focal distance to be varied post-training, decoupling the rendered focus plane from the camera's optical center. It enables refocusing, defocus rendering, and blur removal by incorporating circle-of-confusion (CoC) alpha and depth-dependent scaling.

### [4D Gaussian Slicing](23170-4d-gaussian-slicing.md)
4D Gaussian Slicing is a method to calculate the 3D center position and 3D covariance of a 4D Gaussian at a specific time $t$ by intercepting the 4D Gaussian with the $t$-plane. It enables the rendering of dynamic scenes represented by 4D Gaussians (3D spatial + 1D temporal) into a 2D image for a specific viewpoint and timestamp. It sets itself apart from static 3D Gaussian Splatting by handling time-dependent opacity, position offsets, and spherical harmonics evaluation in 4D, and from other 4D methods like [4D Gaussian Splatting (DreamGaussian4D)](14897-4d-gaussian-splatting-dreamgaussian4d.md) by explicitly deriving the 3D Gaussian parameters via block matrix inversion to avoid numerical instability.

### Dynamic Reconstruction with Deformation Field
An extension to dynamic MRI data modeling temporal variations of anatomical structures from time-resolved MRI sequences using a static set of 3D Gaussians and a learned deformation field network [S4, unofficial]. It initializes a static set of 3D Gaussians representing canonical anatomy, pretrained on slices from the first frame to provide a stable anatomical prior. A learned deformation field network (spatiotemporal encoder + lightweight MLP) predicts per-frame changes in position, covariance, color, and opacity [S4, unofficial]. Baseline: Ground-truth image from the preceding timestamp (t-1) used as prediction for current test frame t. Simulates an oracle model memorizing prior structure [S4, unofficial]. Wrist Motion MRI: 38 temporal frames, 12 wrist slice views per frame, resolution 64x64. 33 frames for training, every 8th frame held out for testing. 35^3 3D Gaussians initialized. Training time ~45 minutes [S4, unofficial]. Wrist Motion MRI Performance: At Time=32, Ours SSIM=0.9224 vs Baseline 0.8909; PSNR=26.9297 vs Baseline 24.5761. At Time=16, Ours SSIM=0.9864 vs Baseline 0.9706; PSNR=39.0909 vs Baseline 34.4965 [S4, unofficial].

### SpacetimeGaussians Rendering Pipeline
Retrieves the rendering pipeline and rasterizer settings via `getrenderpip(option)`. Options include 'test_ours_full' (using `diff_gaussian_rasterization_ch9`), 'test_ours_lite' (using `forward_lite`), 'test_ours_full_fused' (using `forward_full`), 'test_ours_fullss' (using `diff_gaussian_rasterization_ch9`), 'test_ours_fullss_fused' (using `forward_full`), and 'test_ours_litess' (using `forward_lite`) [S5, unofficial]. For each view in the test set, calls the `render` function with the view, gaussians, pipeline, background, `scaling_modifier=1.0`, `basicfunction=rbfbasefunction`, `GRsetting`, and `GRzer`. The output is a dictionary containing the rendered image at key 'render' with shape `(C, H, W)` [S5, unofficial]. Saves the rendered image as a PNG file with a zero-padded 5-digit index in the render path [S5, unofficial]. `rgbfunction`: String specifying the RGB function. Default value is 'rgbv1' [S5, unofficial]. `loader`: String specifying the data loader. Default value is 'colmap' [S5, unofficial].

### Efficient4D
Directly converts 3D Gaussian into 4D Gaussian [S6, unofficial]. Enhances the temporal continuity of SyncDreamer by fusing spatial volumes of adjacent timestamps [S6, unofficial]. Achieves synchronization to generate better cross-time multi-view images for supervision [S6, unofficial].

## Operating characteristics
- **Time Complexity**: Linear in the number of Gaussians $N$ and image pixels $H \times W$, dominated by the CUDA rasterization kernel [S1, S2, unofficial].
- **Memory Complexity**: Linear in $N$ for Gaussian attributes and $H \times W$ for the output image and intermediate buffers [S1, S2, unofficial].
- **Measured Performance**: Not given in the sources.
- **Scaling**: Higher `gaussians_per_splat` (if applicable) increases speed but also GPU memory consumption [S3, unofficial].
- **Strengths**: Real-time rendering of dynamic scenes, differentiable, supports 4D SH evaluation [S2, unofficial].
- **Limitations**: Numerical instability in 4D covariance without proper handling [S1, unofficial].
- **When to use**: Dynamic view synthesis, 4D scene reconstruction [S2, unofficial].
- **When not to use**: Static scenes where 3DGS is sufficient [S2, unofficial].

## Background
Originated from the extension of 3D Gaussian Splatting to 4D for dynamic scene representation [S2, unofficial]. The method handles time-dependent opacity, position offsets, and spherical harmonics evaluation in 4D [S2, unofficial]. It builds on [3D Gaussian Splatting Rendering (CPU-Sorted, Instanced)](52-3d-gaussian-splatting-rendering.md) by extending the static representation to 4D [S1, unofficial].
