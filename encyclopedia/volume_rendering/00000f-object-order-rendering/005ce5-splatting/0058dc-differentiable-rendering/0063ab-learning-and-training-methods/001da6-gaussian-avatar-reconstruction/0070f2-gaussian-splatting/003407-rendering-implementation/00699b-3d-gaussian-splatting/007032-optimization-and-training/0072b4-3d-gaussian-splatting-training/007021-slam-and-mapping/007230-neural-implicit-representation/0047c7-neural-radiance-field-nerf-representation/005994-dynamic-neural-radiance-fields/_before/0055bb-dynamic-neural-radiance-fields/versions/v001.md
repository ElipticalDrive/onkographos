# Dynamic Neural Radiance Fields

Also called: Dynamic NeRF, Dynamic Neural Radiance Fields for Monocular 4D Facial Avatar Reconstruction

## Overview
Dynamic Neural Radiance Fields (Dynamic NeRF) is a method for learning and rendering controllable 4D facial avatars from a single fixed camera view, such as a webcam [S1]. It solves the problem of capturing arbitrary geometry and topology (e.g., hair, eyewear, hats) that static radiance fields or morphable models cannot handle, while avoiding the need for expensive calibrated multi-view rigs [S1]. Unlike static NeRF, which requires ~100 posed images, this method generalizes over a space of expression vectors, requiring a larger training corpus to capture temporal dynamics [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A video sequence of a face from a single fixed camera. The training data consists of frames with associated facial expression coefficients $\delta$.
*   **Output:** A 4D radiance field representation that can render novel views and expressions.

**Data Structures and Network Architecture:**
The dynamic neural radiance field is represented as a Multi-Layer Perceptron (MLP) [S1]. The network takes the following inputs:
1.  Viewing direction $\mathbf{d}$.
2.  Sample position $(x, y, z)$.
3.  Expression coefficients $\delta$.
4.  Learned latent codes $\gamma$ [S1].

The position $(x, y, z)$ and viewing direction $\mathbf{d}$ are encoded using positional encoding [S1, 22]. The expression coefficients $\delta$ and latent codes $\gamma$ are concatenated with the encoded position to form the input vector $\mathbf{I}$ for the backbone [S1].

**Network Layout:**
1.  **Backbone:** An 8-layer MLP. Each layer is linear with 256 neurons and uses ReLU non-linearity [S1]. The input is the concatenated vector $\mathbf{I}$ (position, expression, latent code) [S1].
2.  **Density Output:** A single linear layer takes the backbone output to compute density $\sigma$ [S1].
3.  **Color Branch:** A 4-layer MLP branch. Each layer has 128 neurons and uses ReLU activations [S1]. The input to this branch is the concatenation of the backbone output and the encoded viewing direction $\mathbf{d}$ [S1]. The output is the color $\mathbf{c}$ [S1].

**Training and Rendering Steps:**
1.  **Data Preparation:** Collect a video sequence. Extract expression coefficients $\delta$ for each frame. [S1].
2.  **Latent Code Initialization:** Learn a set of latent codes $\gamma$. Note: During test time, the latent code from the first frame of the training set is always employed [S1].
3.  **Optimization:** Train the MLP parameters by minimizing the difference between rendered images and ground truth images from the training sequence. The loss function typically involves photometric error [S1]. The model must generalize over the space of expression vectors $\delta$ [S1].
4.  **Rendering:** To render a frame:
    *   Select the latent code $\gamma$ from the first training frame [S1].
    *   For each pixel, cast a ray.
    *   Sample points along the ray.
    *   For each sample point, compute position $(x,y,z)$ and viewing direction $\mathbf{d}$.
    *   Retrieve the expression coefficients $\delta$ for the target time/expression.
    *   Feed $\mathbf{d}$, $(x,y,z)$, $\delta$, and $\gamma$ into the MLP to get $\sigma$ and $\mathbf{c}$.
    *   Perform volumetric rendering (alpha compositing) to obtain the final pixel color [S1].

**Parameters:**
*   **Training Data Size:** Requires significantly more data than static NeRF. Static NeRF needs ~100 posed images [S1]. Dynamic NeRF requires a large training corpus to generalize over expression vectors. Experiments show quality degrades if trained on only the first half or quarter of the training sequences [S1].
*   **Acquisition Time:** Suitable for capturing avatars using only 2 minutes of user time [S1].

**Edge Cases and Pitfalls:**
*   **Latent Code Selection:** At test time, the latent code from the *first frame* of the training set must be used, not a per-frame latent code [S1].
*   **Data Scarcity:** Training on insufficient data (e.g., limited expression variety) leads to significant quality degradation [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** The method achieves photo-realistic rendering under novel poses and expressions, beating state-of-the-art facial reenactment methods quantitatively and qualitatively [S1].
*   **Scaling:** Performance benefits significantly from a larger training corpus [S1].
*   **Strengths:** Supports arbitrary geometry and topology (hair, eyewear, hats) [S1]. Requires only a single view from a fixed camera (e.g., webcam), making it suitable for end-user capture at home [S1].
*   **Limitations:** Requires more training data than static NeRF [S1].

## Background
Dynamic Neural Radiance Fields were introduced in the paper "Dynamic Neural Radiance Fields for Monocular 4D Facial Avatar Reconstruction" [S1]. The method builds on the concept of Neural Radiance Fields (NeRF) [22] but extends it to handle dynamic scenes, specifically facial expressions, using a single camera. It differs from morphable model-based methods by supporting complex topology and from other volumetric approaches by not requiring multi-view rigs [S1].
