# Spherical Harmonic Data Creation and Formatting

Also called: CreateSHDataJob, SH Data Encoding, SH Format Conversion

## Overview
This method converts raw spherical harmonic (SH) coefficients from input splat data into a specific binary format for storage in a Gaussian Splat asset [S1, unofficial]. It supports multiple encoding formats (`Float32`, `Float16`, `Norm11`, `Norm6`) to balance precision and memory usage [S1, unofficial]. It differs from sibling methods by focusing on the final serialization step into a contiguous byte array, rather than the interleaving of coefficients or the optimization of the splat parameters themselves [S1, unofficial]. It builds on [SH Coefficient Interleaving](15882-sh-coefficient-interleaving.md) by taking the interleaved coefficients and packing them into a platform-native layout [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: `NativeArray<InputSplatData>` containing splat data with fields `sh1` through `shF` (15 coefficients per splat) [S1, unofficial].
- Output: `NativeArray<byte>` containing the serialized SH data [S1, unofficial].
- Format Selector: `GaussianSplatAsset.SHFormat` enum defining the target encoding [S1, unofficial].

**Data Structures:**
The output is structured as an array of `SHTableItem` variants, depending on the format:
- `SHTableItemFloat32`: Contains 15 `float3` fields (`sh1` to `shF`) and one `float3` padding field (`shPadding`) [S1, unofficial].
- `SHTableItemFloat16`: Contains 15 `half3` fields (`sh1` to `shF`) and one `half3` padding field (`shPadding`) [S1, unofficial].
- `SHTableItemNorm11`: Contains 15 `uint` fields (encoded via `EncodeFloat3ToNorm11`) and one `uint` padding field (`shPadding`) [S1, unofficial].
- `SHTableItemNorm6`: Contains 15 `uint` fields (encoded via `EncodeFloat3ToNorm565`) and one `uint` padding field (`shPadding`) [S1, unofficial].

**Steps:**
1. Determine if clustered SH data is available [S1, unofficial]. If `clusteredSHs` exists, calculate size as `clusteredSHs.Length * SizeOf<SHTableItemFloat16>`, create a byte array, copy `clusteredSHs` reinterpreted as bytes, and return [S1, unofficial].
2. If no clustered data, calculate `dataLen` using `GaussianSplatAsset.CalcSHDataSize(inputSplats.Length, shFormat)` [S1, unofficial].
3. Create a `NativeArray<byte> data` of size `dataLen` [S1, unofficial].
4. Instantiate a `CreateSHDataJob` with `m_Input`, `m_Format`, and `m_Output` (the byte array) [S1, unofficial].
5. Schedule the job with `job.Schedule(inputSplats.Length, 8192)` [S1, unofficial].
6. Complete the job and copy `data` to a result byte array [S1, unofficial].
7. Dispose of the `NativeArray<byte>` and return the result [S1, unofficial].

**Job Execution (Parallel Step):**
For each index in the input array:
1. Read `splat = m_Input[index]` [S1, unofficial].
2. Switch on `m_Format`:
   - **Float32**: Create `SHTableItemFloat32 res` [S1, unofficial]. Copy `splat.sh1` through `splat.shF` to `res.sh1` through `res.shF` [S1, unofficial]. Set `res.shPadding = default` [S1, unofficial]. Write `res` to `m_Output` at the correct byte offset [S1, unofficial].
   - **Float16**: Cast `splat.sh1` through `splat.shF` to `half3` [S1, unofficial]. Copy to `SHTableItemFloat16` [S1, unofficial]. Set `shPadding = default` [S1, unofficial]. Write to output [S1, unofficial].
   - **Norm11**: Encode `splat.sh1` through `splat.shF` using `EncodeFloat3ToNorm11` [S1, unofficial]. Copy to `SHTableItemNorm11` [S1, unofficial]. Write to output [S1, unofficial].
   - **Norm6**: Encode `splat.sh1` through `splat.shF` using `EncodeFloat3ToNorm565` [S1, unofficial]. Copy to `SHTableItemNorm6` [S1, unofficial]. Set `shPadding = default` [S1, unofficial]. Write to output [S1, unofficial].

```python
class float3: x: float; y: float; z: float
class half3: x: float; y: float; z: float  # half precision storage [G]
class uint: value: int

class SHTableItemFloat32:
    sh1: float3; sh2: float3; sh3: float3; sh4: float3; sh5: float3; sh6: float3
    sh7: float3; sh8: float3; sh9: float3; shA: float3; shB: float3; shC: float3
    shD: float3; shE: float3; shF: float3; shPadding: float3

class SHTableItemFloat16:
    sh1: half3; sh2: half3; sh3: half3; sh4: half3; sh5: half3; sh6: half3
    sh7: half3; sh8: half3; sh9: half3; shA: half3; shB: half3; shC: half3
    shD: half3; shE: half3; shF: half3; shPadding: half3

class SHTableItemNorm11:
    sh1: uint; sh2: uint; sh3: uint; sh4: uint; sh5: uint; sh6: uint
    sh7: uint; sh8: uint; sh9: uint; shA: uint; shB: uint; shC: uint
    shD: uint; shE: uint; shF: uint; shPadding: uint

class SHTableItemNorm6:
    sh1: uint; sh2: uint; sh3: uint; sh4: uint; sh5: uint; sh6: uint
    sh7: uint; sh8: uint; sh9: uint; shA: uint; shB: uint; shC: uint
    shD: uint; shE: uint; shF: uint; shPadding: uint

def EncodeFloat3ToNorm11(v: float3) -> uint:
    # Standard 11-bit float quantization [G]
    return uint(int(v.x * 2047) & 0x7FF)  # Simplified for illustration [G]

def EncodeFloat3ToNorm565(v: float3) -> uint:
    # Standard 5-6-5 RGB quantization [G]
    r = int(v.x * 31) & 0x1F
    g = int(v.y * 63) & 0x3F
    b = int(v.z * 31) & 0x1F
    return uint((r << 11) | (g << 5) | b)

def sizeof(type_name: str) -> int:
    # Returns byte size of the struct [G]
    sizes = {"SHTableItemFloat32": 192, "SHTableItemFloat16": 96, "SHTableItemNorm11": 64, "SHTableItemNorm6": 64}
    return sizes.get(type_name, 0)

def CalcSHDataSize(num_splats: int, format: str) -> int:
    # Calculates total byte size [G]
    item_sizes = {"Float32": 192, "Float16": 96, "Norm11": 64, "Norm6": 64}
    return num_splats * item_sizes.get(format, 0)

def CreateSHData(inputSplats: list, shFormat: str, clusteredSHs: list = None) -> bytes:
    if clusteredSHs is not None:
        item_size = sizeof("SHTableItemFloat16")
        size = len(clusteredSHs) * item_size
        result = bytearray(size)
        for i in range(len(clusteredSHs)):
            src_bytes = bytearray(clusteredSHs[i])
            result[i*item_size:(i+1)*item_size] = src_bytes
        return result

    data_len = CalcSHDataSize(len(inputSplats), shFormat)
    output_data = bytearray(data_len)

    for index in range(len(inputSplats)):
        splat = inputSplats[index]
        offset = index * sizeof(f"SHTableItem{shFormat}")
        
        if shFormat == "Float32":
            res = SHTableItemFloat32()
            res.sh1 = splat.sh1; res.sh2 = splat.sh2; res.sh3 = splat.sh3
            res.sh4 = splat.sh4; res.sh5 = splat.sh5; res.sh6 = splat.sh6
            res.sh7 = splat.sh7; res.sh8 = splat.sh8; res.sh9 = splat.sh9
            res.shA = splat.shA; res.shB = splat.shB; res.shC = splat.shC
            res.shD = splat.shD; res.shE = splat.shE; res.shF = splat.shF
            res.shPadding = float3(0.0, 0.0, 0.0)
            output_data[offset:offset+sizeof("SHTableItemFloat32")] = serialize(res)
            
        elif shFormat == "Float16":
            res = SHTableItemFloat16()
            res.sh1 = half3(splat.sh1.x, splat.sh1.y, splat.sh1.z)
            res.sh2 = half3(splat.sh2.x, splat.sh2.y, splat.sh2.z)
            res.sh3 = half3(splat.sh3.x, splat.sh3.y, splat.sh3.z)
            res.sh4 = half3(splat.sh4.x, splat.sh4.y, splat.sh4.z)
            res.sh5 = half3(splat.sh5.x, splat.sh5.y, splat.sh5.z)
            res.sh6 = half3(splat.sh6.x, splat.sh6.y, splat.sh6.z)
            res.sh7 = half3(splat.sh7.x, splat.sh7.y, splat.sh7.z)
            res.sh8 = half3(splat.sh8.x, splat.sh8.y, splat.sh8.z)
            res.sh9 = half3(splat.sh9.x, splat.sh9.y, splat.sh9.z)
            res.shA = half3(splat.shA.x, splat.shA.y, splat.shA.z)
            res.shB = half3(splat.shB.x, splat.shB.y, splat.shB.z)
            res.shC = half3(splat.shC.x, splat.shC.y, splat.shC.z)
            res.shD = half3(splat.shD.x, splat.shD.y, splat.shD.z)
            res.shE = half3(splat.shE.x, splat.shE.y, splat.shE.z)
            res.shF = half3(splat.shF.x, splat.shF.y, splat.shF.z)
            res.shPadding = half3(0.0, 0.0, 0.0)
            output_data[offset:offset+sizeof("SHTableItemFloat16")] = serialize(res)
            
        elif shFormat == "Norm11":
            res = SHTableItemNorm11()
            res.sh1 = EncodeFloat3ToNorm11(splat.sh1); res.sh2 = EncodeFloat3ToNorm11(splat.sh2)
            res.sh3 = EncodeFloat3ToNorm11(splat.sh3); res.sh4 = EncodeFloat3ToNorm11(splat.sh4)
            res.sh5 = EncodeFloat3ToNorm11(splat.sh5); res.sh6 = EncodeFloat3ToNorm11(splat.sh6)
            res.sh7 = EncodeFloat3ToNorm11(splat.sh7); res.sh8 = EncodeFloat3ToNorm11(splat.sh8)
            res.sh9 = EncodeFloat3ToNorm11(splat.sh9); res.shA = EncodeFloat3ToNorm11(splat.shA)
            res.shB = EncodeFloat3ToNorm11(splat.shB); res.shC = EncodeFloat3ToNorm11(splat.shC)
            res.shD = EncodeFloat3ToNorm11(splat.shD); res.shE = EncodeFloat3ToNorm11(splat.shE)
            res.shF = EncodeFloat3ToNorm11(splat.shF)
            res.shPadding = uint(0)
            output_data[offset:offset+sizeof("SHTableItemNorm11")] = serialize(res)
            
        elif shFormat == "Norm6":
            res = SHTableItemNorm6()
            res.sh1 = EncodeFloat3ToNorm565(splat.sh1); res.sh2 = EncodeFloat3ToNorm565(splat.sh2)
            res.sh3 = EncodeFloat3ToNorm565(splat.sh3); res.sh4 = EncodeFloat3ToNorm565(splat.sh4)
            res.sh5 = EncodeFloat3ToNorm565(splat.sh5); res.sh6 = EncodeFloat3ToNorm565(splat.sh6)
            res.sh7 = EncodeFloat3ToNorm565(splat.sh7); res.sh8 = EncodeFloat3ToNorm565(splat.sh8)
            res.sh9 = EncodeFloat3ToNorm565(splat.sh9); res.shA = EncodeFloat3ToNorm565(splat.shA)
            res.shB = EncodeFloat3ToNorm565(splat.shB); res.shC = EncodeFloat3ToNorm565(splat.shC)
            res.shD = EncodeFloat3ToNorm565(splat.shD); res.shE = EncodeFloat3ToNorm565(splat.shE)
            res.shF = EncodeFloat3ToNorm565(splat.shF)
            res.shPadding = uint(0)
            output_data[offset:offset+sizeof("SHTableItemNorm6")] = serialize(res)

    return output_data

def serialize(obj) -> bytes:
    # Packs struct fields into a contiguous byte array [G]
    import struct
    if isinstance(obj, SHTableItemFloat32):
        return struct.pack('<16f', obj.sh1.x, obj.sh1.y, obj.sh1.z, obj.sh2.x, obj.sh2.y, obj.sh2.z,
                           obj.sh3.x, obj.sh3.y, obj.sh3.z, obj.sh4.x, obj.sh4.y, obj.sh4.z,
                           obj.sh5.x, obj.sh5.y, obj.sh5.z, obj.sh6.x, obj.sh6.y, obj.sh6.z,

                           obj.shB.x, obj.shB.y, obj.shB.z, obj.shC.x, obj.shC.y, obj.shC.z,
                           obj.shD.x, obj.shD.y, obj.shD.z, obj.shE.x, obj.shE.y, obj.shE.z,
                           obj.shF.x, obj.shF.y, obj.shF.z, obj.shPadding.x, obj.shPadding.y, obj.shPadding.z)
    elif isinstance(obj, SHTableItemFloat16):
        return struct.pack('<16f', obj.sh1.x, obj.sh1.y, obj.sh1.z, obj.sh2.x, obj.sh2.y, obj.sh2.z,
                           obj.sh3.x, obj.sh3.y, obj.sh3.z, obj.sh4.x, obj.sh4.y, obj.sh4.z,
                           obj.sh5.x, obj.sh5.y, obj.sh5.z, obj.sh6.x, obj.sh6.y, obj.sh6.z,
                           obj.sh7.x, obj.sh7.y, obj.sh7.z, obj.sh8.x, obj.sh8.y, obj.sh8.z,
                           obj.sh9.x, obj.sh9.y, obj.sh9.z, obj.shA.x, obj.shA.y, obj.shA.z,
                           obj.shB.x, obj.shB.y, obj.shB.z, obj.shC.x, obj.shC.y, obj.shC.z,
                           obj.shD.x, obj.shD.y, obj.shD.z, obj.shE.x, obj.shE.y, obj.shE.z,
                           obj.shF.x, obj.shF.y, obj.shF.z, obj.shPadding.x, obj.shPadding.y, obj.shPadding.z)
    elif isinstance(obj, SHTableItemNorm11):
        return struct.pack('<16I', obj.sh1.value, obj.sh2.value, obj.sh3.value, obj.sh4.value,
                           obj.sh5.value, obj.sh6.value, obj.sh7.value, obj.sh8.value,

    elif isinstance(obj, SHTableItemNorm6):
        return struct.pack('<16I', obj.sh1.value, obj.sh2.value, obj.sh3.value, obj.sh4.value,
                           obj.sh5.value, obj.sh6.value, obj.sh7.value, obj.sh8.value,
                           obj.sh9.value, obj.shA.value, obj.shB.value, obj.shC.value,
                           obj.shD.value, obj.shE.value, obj.shF.value, obj.shPadding.value)
    return b''
```

**Parameters:**
- `m_Format`: The encoding format (`Float32`, `Float16`, `Norm11`, `Norm6`) [S1, unofficial].
- Batch size for job scheduling: 8192 [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision loss in `Norm11` and `Norm6` formats may affect visual quality for high-dynamic-range SH coefficients [S1, unofficial].
- The `shPadding` field must be initialized to default values to ensure memory alignment and avoid undefined behavior in downstream readers [S1, unofficial].
- If `clusteredSHs` is present, the method bypasses the job and assumes `Float16` format for the clustered data [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of splats, $O(N)$, where $N$ is the number of input splats [S1, unofficial].
- **Memory Complexity:** Linear with respect to the number of splats, $O(N)$, for the output byte array [S1, unofficial].
- **Performance:** The use of a compute job with a batch size of 8192 allows for parallel processing on the GPU, improving performance for large datasets [S1, unofficial].
- **Strengths:** Supports multiple formats for flexibility in precision vs. memory trade-offs [S1, unofficial].

## Background
This method is part of the Unity Gaussian Splatting implementation by World Labs [S1, unofficial]. It is used to serialize spherical harmonic coefficients for efficient storage and rendering in real-time applications [S1, unofficial].
