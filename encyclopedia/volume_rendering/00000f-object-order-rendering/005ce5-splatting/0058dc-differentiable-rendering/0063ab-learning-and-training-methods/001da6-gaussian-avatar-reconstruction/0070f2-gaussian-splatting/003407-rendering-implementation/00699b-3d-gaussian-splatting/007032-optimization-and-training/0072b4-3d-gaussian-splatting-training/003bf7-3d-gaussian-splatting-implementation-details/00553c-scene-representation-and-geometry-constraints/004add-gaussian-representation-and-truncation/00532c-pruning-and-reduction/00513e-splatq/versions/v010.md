# SplatQ

Also called: SplatQ: Post-training Gaussian pruning via QUBO

## Overview
SplatQ is a post-training pruning framework for 3D Gaussian Splatting (3DGS) that addresses the spatial quality imbalance and loss of joint rendering effects inherent in global Top-K selection methods [S1, unofficial]. Unlike sibling methods that rank Gaussians independently, SplatQ partitions primitives into size-limited blocks based on spatial and appearance similarity, allocates retention quotas to balance regional quality, and solves a Quadratic Unconstrained Binary Optimization (QUBO) problem within each block to jointly select Gaussians under a fixed global budget [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A pretrained 3DGS model consisting of $N$ Gaussians $\mathcal{G} = \{G_i\}_{i=1}^N$, a target retention count $K$, and a maximum block size $M$.
*   **Output:** A pruned set of $K$ Gaussians with optimized attributes.

**Data Structures**
Each Gaussian $G_i$ is defined by the parameter set [S1, unofficial]:
$$ G_i = (\mu_i, s_i, r_i, c_i, h_i, o_i) $$
where:
*   $\mu_i \in \mathbb{R}^3$: Center position.
*   $s_i \in \mathbb{R}^3$: Scale (anisotropic).
*   $r_i \in \mathbb{R}^4$: Rotation quaternion.
*   $c_i \in \mathbb{R}^3$: Zeroth-order (DC) spherical harmonic coefficients (color).
*   $h_i$: Higher-order spherical harmonic coefficients.
*   $o_i \in [0, 1]$: Opacity.

The method operates on blocks $\mathcal{C}_b$, subsets of Gaussians with $|\mathcal{C}_b| \le M$. For each block, a response matrix $\mathbf{R}_b$ is computed.

**Steps**

1.  **Partitioning**
    Divide the $N$ Gaussians into blocks $\{\mathcal{C}_b\}$ of size at most $M$. To ensure spatial and appearance coherence, Gaussians are ordered using a 3D grid and Morton ordering (Z-order curve) to efficiently identify neighbors without computing all pairwise distances [S1, unofficial]. This groups potentially redundant or jointly contributing Gaussians into the same block.

2.  **Opacity Response Modeling**
    For each block $\mathcal{C}_b$, compute the response matrix $\mathbf{R}_b$ to estimate individual deletion effects and pairwise interactions.
    *   Sample pixels from multiple views.
    *   Estimate how the rendered color changes when specific Gaussians are deleted.
    *   The matrix $\mathbf{R}_b$ captures the sensitivity of pixel colors to the opacity of Gaussians within the block, approximating the joint rendering effects [S1, unofficial].

3.  **Budget Allocation**
    Assign a retention quota $K_b$ to each block $\mathcal{C}_b$ such that $\sum_b K_b = K$.
    *   Derive an initial quota for each block based on importance estimates derived from $\mathbf{R}_b$.
    *   Smooth the distribution of quotas to prevent the budget from concentrating in regions with consistently high scores, which causes spatial quality imbalance [S1, unofficial].

4.  **Quadratic Selection**
    For each block $\mathcal{C}_b$, select exactly $K_b$ Gaussians to retain by solving a QUBO problem.
    *   Define binary variables $x_i \in \{0, 1\}$ for each Gaussian $G_i \in \mathcal{C}_b$, where $1$ indicates retention and $0$ indicates deletion.
    *   Construct the objective function incorporating:
        *   Individual responses (from $\mathbf{R}_b$).
        *   Pairwise interactions (joint deletion effects).
        *   Quota penalties (to enforce $\sum_{i \in \mathcal{C}_b} x_i = K_b$).
    *   Solve the QUBO using Simulated Annealing (SA) or a Coherent Ising Machine (CIM) [S1, unofficial].

5.  **Fine-tuning**
    Perform standard 3DGS training (rasterization and gradient descent) on the retained set of $K$ Gaussians. Attributes ($\mu, s, r, c, h, o$) are updated to recover rendering quality, while the count $K$ remains fixed [S1, unofficial].

## Operating characteristics
*   **Complexity:** The method decomposes a global $N \times N$ optimization problem into smaller block-wise problems of size $M \times M$. This reduces memory requirements and makes the QUBO solving step tractable for large $N$ [S1, unofficial].
*   **Performance:** SplatQ ensures balanced reconstruction quality across different regions of the scene, avoiding the spatial quality imbalance seen in global Top-K methods [S1, unofficial].
*   **Strengths:**
    *   Accounts for joint rendering effects (pairwise interactions) rather than independent scores.
    *   Guarantees exact global retention count $K$.
    *   Prevents budget concentration in high-score regions.
*   **Limitations:**
    *   Requires post-training optimization (fine-tuning) to recover quality.
    *   Solving QUBO (via SA or CIM) adds computational overhead during the pruning phase compared to simple sorting [S1, unofficial].
*   **When to use:** When aggressive pruning is required and maintaining uniform quality across the entire scene (near and far regions) is critical.
*   **When not to use:** If real-time pruning without fine-tuning is required, or if the scene has very few Gaussians where global Top-K is sufficient.

## Background
SplatQ was proposed by Hongbin Ye, Haixu Liu, Shenwei Kang, et al. and presented as a conference paper at ICLR 2027 [S1, unofficial]. It addresses limitations in existing 3DGS pruning methods, which primarily rely on global Top-K selection based on independent importance scores (e.g., Fan et al., 2024; Hanson et al., 2025b; Chen et al., 2026) [S1, unofficial]. Previous methods fail to capture joint deletion effects and often result in spatial quality imbalance [S1, unofficial].
