# Gradient Modification

Also called: Gradient Smoothing, Gradient Regularization, Gradient Filtering

## Overview
Gradient modification techniques adjust the raw gradients $\nabla \mathcal{L}$ computed via automatic differentiation to mitigate optimization instability, gradient confusion, and vanishing gradients in 3D Gaussian Splatting. These methods address specific failure modes such as non-differentiable boundaries in indicator functions, divergence of "dead" Gaussians with low opacity, and perturbations from imperfect supervision or pseudo-views. They set themselves apart from standard training by intervening in the update step to reshape the gradient signal before it reaches the optimizer, rather than altering the loss function or the rasterizer's forward pass directly.

## Shared principles
All methods in this family share the core mechanism of stochastic gradient descent (SGD) applied to the parameters of a set of 3D Gaussians $\mathcal{G} = \{g_i\}_{i=1}^N$. Each Gaussian $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$
*   Covariance $\Sigma_i$ (often parameterized as rotation $\mathbf{q}_i$ and scale $\mathbf{s}_i$)
*   Opacity $\alpha_i \in [0, 1]$
*   Spherical Harmonics (SH) coefficients $\mathbf{c}_{i, l}$ for view-dependent color

The optimization loop typically follows these steps:
1.  **Sampling:** Randomly select one or more training views (images and camera poses) from the dataset [S1].
2.  **Rendering:** Project the 3D Gaussians to 2D screen space and alpha-blend them using a differentiable rasterizer to produce a rendered image $\hat{I}$ [S1].
3.  **Loss Computation:** Compute a loss $\mathcal{L}$ between $\hat{I}$ and the ground-truth image $I_{gt}$ [S1]. The standard photometric loss is a weighted sum:
    $$ \mathcal{L}_{img} = (1 - \lambda) \mathcal{L}_{L1} + \lambda \mathcal{L}_{D-SSIM} $$
    where $\mathcal{L}_{L1}$ is the L1 loss and $\mathcal{L}_{D-SSIM}$ is the differentiable Structural Similarity index loss [S1]. The weight $\lambda$ is typically 0.2 [S1].
4.  **Backpropagation:** Compute gradients $\nabla \mathcal{L}$ with respect to all Gaussian parameters using automatic differentiation through the rasterizer [S1].
5.  **Update:** Update the Gaussian parameters using the Adam optimizer with $\beta_1 = 0.9$ and $\beta_2 = 0.99$ [S1].
6.  **Densification/Pruning:** Periodically (e.g., every $k$ iterations), evaluate gradient magnitudes and opacity thresholds to split high-gradient Gaussians or prune low-opacity ones, adapting the density of the representation [S1].

## Subtopics

### [Bézier-boundary gradient approximation](13137-b-zier-boundary-gradient-approximation.md)
*   **What it is:** A method that approximates the gradients of a discontinuous indicator function $g(\cdot)$ with respect to cubic Bézier curve control points, enabling backpropagation in Gaussian Splatting despite the function being piecewise constant and non-differentiable.
*   **What sets it apart:** It explicitly handles the non-differentiable boundary conditions of discontinuity-aware alpha-blending, whereas standard Gaussian Splatting [3D Gaussian Splatting](52-3d-gaussian-splatting.md) assumes smooth differentiability throughout the rendering pipeline.
*   **When to choose it:** When using Bézier curves to define alpha-blending boundaries or visibility masks that introduce discontinuities.
*   **Link:** [Bézier-boundary gradient approximation](13137-b-zier-boundary-gradient-approximation.md)

### [Truncated Gradient Updates for 3D Gaussian Splatting](18661-truncated-gradient-updates-for-3d-gaussian-splatting.md)
*   **What it is:** A technique that applies truncated gradients to 'dead' Gaussians (those with low opacity) to enable long-range movement and convergence, addressing vanishing gradients in dynamic scenes or poor initialization.
*   **What sets it apart:** It introduces a surrogate linear gradient field for Gaussians that fall outside the rasterizer's tile-coverage threshold, allowing them to be pulled toward distant pixels rather than remaining static or diverging. Unlike sibling methods that might apply such updates globally, this method strictly restricts truncated gradients to dead Gaussians to prevent model divergence.
*   **When to choose it:** When dealing with sparse initializations, dynamic scenes, or Gaussians that have become "dead" (low opacity) and are not receiving sufficient gradient updates from the rasterizer.
*   **Link:** [Truncated Gradient Updates for 3D Gaussian Splatting](18661-truncated-gradient-updates-for-3d-gaussian-splatting.md)

### Gradient Flag Optimization
#### definition
An optimization strategy that augments Gaussian primitives with a flag gradient attribute to mitigate gradient confusion and perturbations caused by imperfect supervision from pseudo-views [S1].

#### step
For each Gaussian in one optimization step, compute the cosine similarity between the current gradient for each attribute $g_{ic}$ and the corresponding flag gradient $\nabla(g_i)$ stored in $\nabla$ [S1]. If the cosine similarity is greater than zero, indicating that the gradient update trends are aligned, the gradient $g_{ic}$ will be directly used [S1]. If the cosine similarity is less than or equal to zero, indicating potential disturbances, the current gradient will be scaled down by a factor of $\epsilon$ to slow the parameter updates, and $\nabla(g_i)$ will be updated as follows:
$$ g_{ic} = \epsilon g_{ic}, \quad \nabla(g_i) = (1 - \epsilon)\nabla(g_i) + \epsilon g_{ic} $$
[ S1]. Pass the modified gradients ($g_{ic\_new}$) to the gradient-based optimizer (e.g., Adam) [S1]. Eliminate the flag gradient attribute $\nabla$ after optimization is complete to avoid affecting rendering speed and storage [S1].

#### parameter
$\epsilon$: The scaling factor for gradients with negative cosine similarity, set to 0.1 [S1].

#### layout
Augment canonical Gaussian primitives $\{\mu, s, q, \sigma, c\}$ with an additional per-Gaussian attribute flag gradient $\nabla \in \mathbb{R}^{11+k_c}$, where $\nabla$ records gradient trends for $\mu, s, q, \sigma$, and $k_c$ SH coefficients [S1].

## Background
Gradient modification in 3D Gaussian Splatting emerged to address specific optimization instabilities not covered by the standard training loop. The concept of handling non-differentiable boundaries via approximation was introduced in the context of Bézier-boundary methods [S1]. The idea of truncated gradients for dead Gaussians was proposed to solve the problem of Gaussians failing to converge to distant pixels due to tile-based culling and low opacity [S1]. Gradient flag optimization was introduced in S2Gaussian to mitigate gradient confusion caused by imperfect supervision from pseudo-views in sparse-view super-resolution tasks [S1]. These methods are primarily used in advanced 3D Gaussian Splatting implementations, particularly in dynamic scenes, sparse-view reconstruction, and methods requiring discontinuous alpha-blending.
