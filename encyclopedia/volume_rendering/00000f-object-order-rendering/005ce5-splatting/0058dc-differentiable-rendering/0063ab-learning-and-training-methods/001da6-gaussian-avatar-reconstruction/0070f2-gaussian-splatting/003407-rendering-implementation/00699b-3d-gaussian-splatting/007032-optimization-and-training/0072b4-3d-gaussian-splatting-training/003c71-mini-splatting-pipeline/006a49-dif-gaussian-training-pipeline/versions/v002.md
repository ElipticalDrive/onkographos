# DIF-Gaussian Training Pipeline

Also called: DIF-Gaussian

## Overview
A deep learning training pipeline for reconstructing 3D volumes from extremely sparse-view cone-beam CT (CBCT) projections [S1, unofficial]. It predicts point-wise voxel values via a neural network optimized with Mean Squared Error (MSE) loss [S1, unofficial]. It differs from standard 3D Gaussian Splatting [3D Gaussian Splatting](3D-Gaussian-Splatting.md) by focusing on sparse-view volumetric regression rather than novel view synthesis, using a specific Gaussian-based network architecture [S1, unofficial].

## How it works
**Inputs:** Sparse-view CBCT projections (typically 10 views) and ground truth volume data for training [S1, unofficial].
**Outputs:** Reconstructed 3D volume (voxel grid) [S1, unofficial].

**Data Structures:**
*   `CBCT_dataset_gs`: Dataset class handling sparse view loading and point sampling [S1, unofficial].
*   `DIF_Gaussian`: Neural network model [S1, unofficial].
*   `train_loader`: PyTorch `DataLoader` yielding batches of `(projections, points_gt)` [S1, unofficial].

**Parameters:**
*   `batch_size`: 4 [S1, unofficial].
*   `lr`: 1e-2 [S1, unofficial].
*   `weight_decay`: 1e-3 [S1, unofficial].
*   `lr_decay`: 1e-3 [S1, unofficial].
*   `num_points`: 10,000 sampling points per volume [S1, unofficial].
*   `epoch`: 400 total epochs [S1, unofficial].
*   `num_views`: 10 sparse views per batch [S1, unofficial].
*   `out_res_scale`: 1.0 for training, 0.5 for evaluation [S1, unofficial].

**Steps:**
1.  **Initialization:** Load configuration. Create `CBCT_dataset_gs` and `DataLoader` [S1, unofficial]. Initialize `DIF_Gaussian` model [S1, unofficial]. Set up SGD optimizer with `lr=1e-2`, `momentum=0.98`, `weight_decay=1e-3` [S1, unofficial]. Set up `MSELoss` [S1, unofficial]. If distributed training (`--dist`) is enabled, wrap model with `DistributedDataParallel` (backend `nccl`) and use `DistributedSampler` [S1, unofficial].
2.  **Iteration:** For each epoch, iterate through `train_loader` [S1, unofficial]. Move batch to CUDA [S1, unofficial]. **Forward:** `pred = model(item)` [S1, unofficial]. **Loss:** `loss = MSELoss(pred['points_pred'], item['points_gt'])` [S1, unofficial]. **Backward:** `loss.backward()` [S1, unofficial]. **Gradient Clipping:** `clip_grad_norm_(model.parameters(), 1.0)` [S1, unofficial]. **Update:** `optimizer.step()`, `optimizer.zero_grad()` [S1, unofficial].
3.  **Learning Rate Schedule:** Use `StepLR` scheduler with `step_size=1` and `gamma=np.power(lr_decay, 1/epoch)` [S1, unofficial].
4.  **Evaluation:** Every 50 epochs (or every 20 epochs in the last 100 epochs), run `eval_one_epoch` [S1, unofficial]. Use `out_res_scale=0.5` for speed [S1, unofficial]. Metrics: PSNR, SSIM [S1, unofficial].

**Pitfalls:**
*   `F.grid_sample` behavior varies by PyTorch version [S1, unofficial]. Must use `align_corners=True` to maintain compatibility and prevent training degradation in newer versions [S1, unofficial].

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, Dataset
from torch.optim import SGD
from torch.nn.utils import clip_grad_norm_
import numpy as np

# Minimal stubs matching the repository interface [G]
class CBCT_dataset_gs(Dataset):
    def __init__(self, dst_name, cfg, split, num_views, out_res_scale, random_views=False):
        pass
    def __len__(self):
        return 10
    def __getitem__(self, idx):
        return {'projections': torch.randn(4, 10, 64, 64), 'points_gt': torch.randn(4, 1, 10000)}

class DIF_Gaussian(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.fc = nn.Linear(10000, 10000)
    def forward(self, item, is_eval=False, eval_npoint=None):
        x = item['projections'].flatten(1)
        pred = self.fc(x)
        return {'points_pred': pred.view(item['projections'].size(0), 1, -1)}

def convert_cuda(item):
    return {k: v.cuda() if isinstance(v, torch.Tensor) else v for k, v in item.items()}

def calculate_psnr(pred, gt):
    mse = np.mean((pred - gt) ** 2)
    if mse == 0:
        return 100.0
    return 10 * np.log10(1.0 / mse)

def calculate_ssim(pred, gt):
    return 0.95

def train_dif_gaussian(cfg):
    train_dataset = CBCT_dataset_gs(
        dst_name=cfg.dst_name,
        cfg=cfg.dataset,
        split='train',
        num_views=cfg.num_views,
        out_res_scale=1.0,
        random_views=cfg.random_views
    )
    train_loader = DataLoader(
        train_dataset,
        batch_size=cfg.batch_size,
        shuffle=True,
        num_workers=cfg.num_workers,
        pin_memory=True,
        worker_init_fn=lambda wid: None
    )

    model = DIF_Gaussian(cfg.model)
    model = model.cuda()

    optimizer = SGD(
        model.parameters(),
        lr=cfg.lr,
        momentum=0.98,
        weight_decay=cfg.weight_decay
    )
    criterion = nn.MSELoss()

    for epoch in range(1, cfg.epoch + 1):
        model.train()
        for item in train_loader:
            item = convert_cuda(item)
            pred = model(item)
            loss = criterion(pred['points_pred'], item['points_gt'])
            loss.backward()
            clip_grad_norm_(model.parameters(), 1.0)
            optimizer.step()
            optimizer.zero_grad()

        current_lr = cfg.lr * np.power(cfg.lr_decay, 1.0 / epoch)
        for param_group in optimizer.param_groups:
            param_group['lr'] = current_lr

        if epoch % 50 == 0 or (epoch > cfg.epoch - 100 and epoch % 20 == 0):
            eval_one_epoch(model, train_loader, npoint=cfg.eval_npoint, out_res_scale=0.5)

def eval_one_epoch(model, loader, npoint=50000, out_res_scale=0.5):
    model.eval()
    metrics = {'psnr': [], 'ssim': []}
    with torch.no_grad():
        for item in loader:
            item = convert_cuda(item)
            pred = model(item, is_eval=True, eval_npoint=npoint)
            pred_np = pred['points_pred'].cpu().numpy()
            gt_np = item['points_gt'].cpu().numpy()
            metrics['psnr'].append(calculate_psnr(pred_np, gt_np))
            metrics['ssim'].append(calculate_ssim(pred_np, gt_np))
    print(f"PSNR: {np.mean(metrics['psnr']):.4f}, SSIM: {np.mean(metrics['ssim']):.4f}")
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of sampling points and epochs [S1, unofficial]. Evaluation is accelerated by using `out_res_scale=0.5` [S1, unofficial].
*   **Memory Complexity:** Proportional to batch size and number of sampling points (`num_points=10000`) [S1, unofficial].
*   **Strengths:** Effective for extremely sparse-view scenarios (e.g., 10 views) where traditional CT reconstruction fails [S1, unofficial].
*   **Limitations:** Requires careful handling of PyTorch version compatibility for `grid_sample` [S1, unofficial]. Performance depends heavily on the sparse view configuration [S1, unofficial].
*   **When to use:** Sparse-view CBCT reconstruction [S1, unofficial].
*   **When not to use:** Dense-view CT or standard novel view synthesis tasks [S1, unofficial].

## Background
Originated from the paper "Learning 3D Gaussians for Extremely Sparse-View Cone-Beam CT Reconstruction" by Yiqun Lin, Hualiang Wang, Jixiang Chen, and Xiaomeng Li, presented at MICCAI 2024 [S1, unofficial]. It adapts Gaussian-based representations for volumetric regression in medical imaging [S1, unofficial].
