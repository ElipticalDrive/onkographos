# Feed-forward and Generalizable Prediction

Also called: GRM, Generalizable Reconstruction Method

## Overview
Feed-forward and Generalizable Prediction refers to a family of methods that map input images directly to a 3D Gaussian Splatting (3DGS) representation without per-scene optimization, enabling instant novel view synthesis on unseen scenes [Parent]. Unlike traditional 3DGS which requires iterative gradient descent for each new scene, these methods use a learned neural network to predict Gaussian parameters ($\mu, \Sigma, \alpha, c$) in a single forward pass [Parent]. This family is distinguished from sibling methods like [Triplane-LRM](16746-feed-forward-generalizable-reconstruction.md) by its explicit prediction of explicit Gaussian primitives rather than latent field representations, and from optimization-based methods by its inference speed and lack of per-scene tuning [Parent].

## Shared principles
All methods in this family share the core objective of mapping input image features to a set of 3D Gaussian parameters $\mathcal{G} = \{\mu, \Sigma, \alpha, c\}$ without per-scene gradient descent [Parent].

1.  **Input Representation:** Inputs are typically one or more RGB images $I \in \mathbb{R}^{H \times W \times 3}$. Some methods require known camera poses $P$, while others (e.g., [Splatt3R](16423-splatt3r.md), [ZeroGS](16425-zerogs.md)) predict poses or operate on uncalibrated inputs [Parent].
2.  **Feature Encoding:** A shared encoder (e.g., Vision Transformer, CNN) extracts multi-scale features from the input images. Cross-attention or cost volumes are often used to aggregate multi-view information [Parent].
3.  **Primitive Prediction:** A decoder head predicts Gaussian attributes. These attributes are usually:
    *   **Mean ($\mu$):** 3D position.
    *   **Covariance ($\Sigma$):** Defined by scale $s$ and rotation $r$ (quaternion or 6D).
    *   **Opacity ($\alpha$):** Scalar.
    *   **Color ($c$):** Spherical Harmonics (SH) coefficients or constant RGB [Parent].
4.  **Differentiable Rendering:** The predicted Gaussians are rendered into target views using differentiable rasterization to compute reconstruction losses (e.g., L1, SSIM, LPIPS) for training the network [Parent].
5.  **Generalization:** The network is trained on a large dataset of scenes to learn priors about geometry and appearance, allowing inference on unseen scenes [Parent].

## Subtopics

### [HFGaussian](16422-hfgaussian.md)
[HFGaussian](16422-hfgaussian.md) is a generalizable, feed-forward framework for real-time 3D human avatar reconstruction that simultaneously estimates novel views, 3D pose, and biomechanical features (such as dense pose and 3D keypoints) from sparse input images. Unlike sibling methods that rely on parametric body models (e.g., SMPL) or fail to integrate structural biomechanics, HFGaussian uses Gaussian splatting to represent the human subject and its associated features directly. It builds on [Feed-forward and Generalizable Prediction](15832-feed-forward-and-generalizable-prediction.md) by introducing a "feature splatting" mechanism that decouples human feature learning from the geometric Gaussian parameters, allowing different frequencies of features to be rendered efficiently without per-subject optimization.

### [ZeroGS](16425-zerogs.md)
[ZeroGS](16425-zerogs.md) is a pipeline for training 3D Gaussian Splatting (3DGS) from hundreds of unposed and unordered images without requiring Structure-from-Motion (SfM) tools like COLMAP. It differs from its siblings by leveraging a pretrained foundation model (Spann3R) as a neural scene representation and employing an incremental training buffer to progressively register images and refine poses. Unlike [ACE0](16422-ace0.md), which predicts sparse points using CNNs, ZeroGS predicts dense pointmaps and 3D Gaussians using transformers and optimizes the scene via rendering loss rather than reprojection error.

### [Deformation Field MLP](16430-deformation-field-mlp.md)
[Deformation Field MLP](16430-deformation-field-mlp.md) is a coordinate-based neural network that predicts spatial offsets for 3D Gaussian primitives to model dynamic geometry or correct canonical shapes. It maps input coordinates (and optionally time) to deviations in position, rotation, and scale, serving as a smooth prior to prevent overfitting to sparse or noisy views. Unlike grid-based methods, it uses a compact MLP structure, making it suitable for dynamic scenes with high-rank variations where explicit point-based rendering exacerbates complexity.

### [Shape Completion Training](16514-shape-completion-training.md)
[Shape Completion Training](16514-shape-completion-training.md) is a feed-forward method that predicts all 14 3D Gaussian attributes from partial, incomplete inputs without requiring target coordinates or per-scene optimization. It distinguishes itself from sibling methods by employing a fixed 2×2 folding grid to expand a small set of coarse primitives into a dense Gaussian set, enabling robust reconstruction of missing geometry in occluded or sparse scenes.

### [Feed-forward Generalizable Reconstruction](16746-feed-forward-generalizable-reconstruction.md)
[Feed-forward Generalizable Reconstruction](16746-feed-forward-generalizable-reconstruction.md) maps input images directly to a 3D Gaussian Splatting (3DGS) representation without per-scene optimization, enabling instant novel view synthesis on unseen scenes [Parent]. Unlike traditional 3DGS which requires iterative gradient descent for each new scene, these methods use a learned neural network to predict Gaussian parameters ($\mu, \Sigma, \alpha, c$) in a single forward pass [Parent]. This family is distinguished from sibling methods like [Triplane-LRM](16746-feed-forward-generalizable-reconstruction.md) by its explicit prediction of explicit Gaussian primitives rather than latent field representations, and from optimization-based methods by its inference speed and lack of per-scene tuning [Parent].

### [Feature Uplifting via Forward Rendering](16969-feature-uplifting-via-forward-rendering.md)
[Feature Uplifting via Forward Rendering](16969-feature-uplifting-via-forward-rendering.md) is a method to estimate 3D language features $f \in \mathbb{R}^d$ for 3D Gaussians from observed 2D features $F_{2D} \in \mathbb{R}^d$ by formulating the problem as a Maximum Likelihood (ML) or Maximum-a-Posteriori (MAP) estimation, assuming uniform prior and Gaussian noise. It differs from back-projection methods (e.g., conventional semantic feature learning) by leveraging the forward rendering process to establish precise correspondence, eliminating costly back-projection or iterative optimization. It builds on [Feed-forward and Generalizable Prediction](15832-feed-forward-and-generalizable-prediction.md).

### [Occam's LGS](16973-occam-s-lgs.md)
[Occam's LGS](16973-occam-s-lgs.md) is a training-free method for lifting 2D language features to 3D Gaussian representations by applying Occam’s razor to the forward rendering process of 3D Gaussian Splatting. It solves the problem of expensive iterative optimization in feature space by computing weighted multi-view feature aggregation directly from the alpha blending weights of the standard color rendering pass. Unlike sibling methods that rely on scene-specific autoencoders, quantization, or costly semantic feature rendering, Occam's LGS supports arbitrary-dimensional uncompressed features without compromising training speed, achieving a two-order-of-magnitude speed-up while maintaining state-of-the-art performance for open-set vision-language tasks.

### [Fast Feedforward 3D Gaussian Splatting Compression](19199-fast-feedforward-3d-gaussian-splatting-compression.md)
[Fast Feedforward 3D Gaussian Splatting Compression](19199-fast-feedforward-3d-gaussian-splatting-compression.md) is an autoencoder-based compression method that encodes 3D Gaussian attributes into a latent space using hyperpriors and context models, addressing the fidelity drop caused by the non-invertibility of MLPs in geometry attributes. Unlike anchor-based quantization methods that modify Gaussian locations and require finetuning, FCGS creates context grids in a feed-forward manner without altering the original Gaussian positions.

### [SHARE](19401-share.md)
[SHARE](19401-share.md) is a pose-free framework for generalizable 3D Gaussian splatting that estimates camera poses via predicted rays and uses anchor-aligned coarse-to-fine geometry estimation to predict 3D Gaussian parameters without ground-truth poses. It sets itself apart from sibling methods like [PixelSplat](16423-pixelsplat.md) and [MVSplat](16423-mvsplat.md) by explicitly embedding pose awareness into multi-view cost volumes via Plücker rays, making it robust to pose inaccuracies where generalizable 3D Gaussian splatting methods are highly sensitive.

### [Feed-Forward Hierarchical Gaussian Diffusion](19615-feed-forward-hierarchical-gaussian-diffusion.md)
[Feed-Forward Hierarchical Gaussian Diffusion](19615-feed-forward-hierarchical-gaussian-diffusion.md) is a feed-forward reconstruction method for computed tomography (CT) that predicts a set of 3D Gaussian primitives from degraded projections without per-scene optimization. It solves the problem of sparse-view, low-dose, or limited-angle CT reconstruction by using two explicit Gaussian banks (structure and detail) initialized from anatomical cues and refined via a sequential structure-to-detail diffusion hierarchy. It differs from single-bank Gaussian reconstruction by maintaining separate banks for global attenuation geometry and residual detail, and from dense voxel diffusion by operating on explicit Gaussian primitives with a sequential hierarchy.

### [Amortized Image Reconstruction (AIR)](19780-amortized-image-reconstruction-air.md)
[Amortized Image Reconstruction (AIR)](19780-amortized-image-reconstruction-air.md) is a self-supervised feed-forward framework that reconstructs a target image into a set of 2D Gaussian primitives in a single network pass, eliminating the costly per-image iterative optimization required by prior methods like GaussianImage. Unlike Instant-GI, which relies on handcrafted priors and pseudo-labels for initialization, AIR uses a stage-wise residual architecture to progressively predict Gaussian primitives from reconstruction residuals, achieving higher quality with encoding times of 160–300 ms.

### [UniQueR](20146-uniquer.md)
[UniQueR](20146-uniquer.md) is a feedforward framework for fast 3D reconstruction from unposed images using sparse learnable 3D queries. It predicts camera-to-world transforms and per-view local point maps, then uses queries to spawn Gaussians rendered via differentiable splatting for supervision. It sets itself apart from siblings like [HFGaussian](16422-hfgaussian.md) and [ZeroGS](16425-zerogs.md) by decoupling the attention mechanism between image tokens and 3D queries to handle high-resolution inputs efficiently, avoiding the quadratic complexity of full self-attention on concatenated tokens.

### [GS3](20638-gs3.md)
[GS3](20638-gs3.md) is an efficient self-supervised learning framework for learning point cloud representations by integrating fast 3D Gaussian Splatting into a rendering-based pretext task. It solves the problem of high computational cost and memory intensity inherent in existing volume rendering-based self-supervised methods. Unlike its sibling [Ponder](16421-ponder.md), which uses differentiable volume rendering with ray marching, GS3 employs a tile-based rasterizer to render 3D Gaussians, achieving significantly faster pre-training speeds and lower memory usage.

### [DIF-Gaussian](20639-dif-gaussian.md)
[DIF-Gaussian](20639-dif-gaussian.md) is a feed-forward neural network that reconstructs a 3D volume from multi-view 2D projections by predicting 3D Gaussian parameters at sampled points and decoding features via Gaussian interpolation. It differs from sibling methods by explicitly modeling the feature aggregation step as a differentiable Gaussian splatting operation, allowing the network to learn spatial priors directly in the Gaussian domain rather than through standard grid-based or point-based interpolation.

### [Compact Feed-Forward 3D Gaussians via Saliency-Guided Primitive Merging](20687-compact-feed-forward-3d-gaussians-via-saliency-guided-primit.md)
[Compact Feed-Forward 3D Gaussians via Saliency-Guided Primitive Merging](20687-compact-feed-forward-3d-gaussians-via-saliency-guided-primit.md) is a post-processing pipeline that consolidates redundant, per-pixel 3D Gaussians produced by any feed-forward Gaussian predictor into a compact, content-adaptive set. It solves the inefficiency of per-pixel primitives by grouping spatially coherent Gaussians via saliency-guided superpixel segmentation, compressing them into latent representations, and merging them across views, retaining visual quality at approximately 1/20th of the original primitive count. Unlike uniform discretization or detection-based reduction methods, it is backbone-agnostic and operates as a plug-in module without retraining the underlying feed-forward network.

## Background
The concept of generalizable reconstruction from images has evolved from multi-view stereo (MVS) to neural radiance fields (NeRF) and now to 3D Gaussian Splatting. Traditional 3DGS requires per-scene optimization, which is computationally expensive and slow for large-scale or real-time applications [Parent]. Feed-forward methods address this by training a neural network to predict Gaussian parameters directly from images, leveraging large datasets to learn scene priors [Parent]. The term "GRM" (Generalizable Reconstruction Method) appears in literature referring to approaches that utilize existing multi-view generation models to train a pixel-aligned Gaussian representation for faithful 3D generation using a single feed-forward pass [S1, unofficial]. This family includes methods for human avatars [S1, unofficial], pose-free reconstruction [S1, unofficial], and specialized applications like CT [S1, unofficial] and language feature lifting [S1, unofficial].
