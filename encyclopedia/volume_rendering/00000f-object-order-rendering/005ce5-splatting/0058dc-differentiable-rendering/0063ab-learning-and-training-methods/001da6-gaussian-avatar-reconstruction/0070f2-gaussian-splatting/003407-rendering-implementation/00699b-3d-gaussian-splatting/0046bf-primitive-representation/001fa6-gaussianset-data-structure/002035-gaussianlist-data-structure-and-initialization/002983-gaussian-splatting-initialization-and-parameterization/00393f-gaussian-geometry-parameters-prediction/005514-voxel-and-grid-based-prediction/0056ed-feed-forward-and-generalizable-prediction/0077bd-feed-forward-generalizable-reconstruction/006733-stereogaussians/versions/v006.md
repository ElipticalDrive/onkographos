# StereoGaussians

Also called: StereoGaussians: Feed-Forward 3D Gaussian Splatting from Stereo Images

## Overview
StereoGaussians is a feed-forward method that predicts a metric 3D Gaussian Splatting (3DGS) representation from a single calibrated stereo pair, enabling nearby-view extrapolation without per-scene optimization [S1, unofficial]. It distinguishes itself from siblings like [AnySplat Pipeline](12847-anysplat-pipeline.md) and [Splatt3R](16423-splatt3r.md) by explicitly leveraging frozen pretrained stereo features for geometry anchoring and introducing a second Gaussian layer with an expanded image canvas to handle disoccluded and outside-field-of-view content [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A calibrated rectified stereo pair (left image $I_L$, right image $I_R$), camera intrinsics $K$ (focal lengths $f_x, f_y$, principal point $c_x, c_y$), and baseline $B$.
*   **Outputs:** A set of $N$ Gaussians $G = \{(x_i, s_i, q_i, \alpha_i, c_i)\}$ in the left-camera frame, where $x_i$ is position, $s_i$ is scale, $q_i$ is rotation (quaternion), $\alpha_i$ is opacity, and $c_i$ is color [S1, unofficial].

**Data Structures:**
The method operates on a dense descriptor $\Phi$ and Gaussian attributes.
*   **Descriptor $\Phi$:** A tensor of shape $C \times H \times W$ (default $C=128$) at original image resolution.
*   **Gaussian Attributes:** Predicted as residuals. Each layer outputs 37 channels per pixel: 1 for opacity, 2 for image-plane offsets, 3 for scale, 4 for quaternion, and 27 for degree-2 spherical harmonic (SH) coefficients [S1, unofficial].

**Algorithm Steps:**

1.  **Stereo Feature Extraction:**
    Pass the stereo inputs through a frozen pretrained stereo encoder (e.g., FoundationStereo) to obtain a left-reference disparity map $d$ and aligned multiscale features $\{F_s\}$ [S1, unofficial].
    *   *Note:* For the Fast-FoundationStereo variant, only left-reference image features and RGB-D are used; context and recurrent features are excluded [S1, unofficial].

2.  **Metric Depth Calculation:**
    Compute metric depth $z(p)$ for each pixel $p=(u,v)$ using the disparity $d(p)$:
    $$ z(p) = \text{clip}\left( \frac{f_x B}{d(p)}, z_{\min}, z_{\max} \right) $$
    where $f_x$ is the horizontal focal length in pixels, $B$ is the baseline, and $z_{\min}, z_{\max}$ are clipping bounds [S1, unofficial].

3.  **Descriptor Generation:**
    Construct the dense descriptor $\Phi$ by concatenating stereo features with resized reference RGB and depth at each scale $s$, then passing through a DPT-style decoder $D$:
    $$ \Phi = D \left[ \{F_s, \downarrow_s I_L, \downarrow_s z\}_s \right] \in \mathbb{R}^{C \times H \times W} $$
    Here, $[\cdot, \cdot]$ denotes channel concatenation, and $\downarrow_s$ resizes inputs to feature scale $s$ (e.g., $s=4$ implies $H/4 \times W/4$ resolution) [S1, unofficial].
    *   *Implementation Detail:* At each scale, concatenate encoder features with resized RGB (bilinear) and depth (nearest-neighbor). Project to 128 channels via $1\times1$ convolution, group normalization, and GELU. Use residual convolution units and coarse-to-fine fusion to yield the final 128-channel descriptor [S1, unofficial].

4.  **Canvas Extension (Extrapolation-Aware Prediction):**
    Extend the reference RGB $I_L$, processed depth $z$, and descriptor $\Phi$ by edge-replication padding $P$ on each side to size $(H + 2P) \times (W + 2P)$. Let the extended inputs be $\tilde{I}_L, \tilde{z}, \tilde{\Phi}$ [S1, unofficial].
    *   *Canvas Intrinsics:* Update the principal point to $\tilde{c}_x = c_x + P, \tilde{c}_y = c_y + P$. Focal lengths remain unchanged [S1, unofficial].
    *   *Default Padding:* $P = 16$ pixels [S1, unofficial].

5.  **Gaussian Attribute Prediction:**
    Pass the extended inputs through a convolutional predictor $H$ to predict attribute residuals for two Gaussian layers and a back-layer depth offset:
    $$ (\theta_{\text{front}}, \theta_{\text{back}}, \Delta z) = H([\tilde{I}_L, \tilde{z}, \tilde{\Phi}]) $$
    *   *Predictor Architecture:*
        1.  **Regressor:** Two $3\times3$ convolutions with intermediate GELU map $[\tilde{I}_L, \tilde{z}, \tilde{\Phi}]$ to a 128-channel tensor $h$ [S1, unofficial].
        2.  **Output Branches:** Three branches process $[h, \tilde{I}_L, \tilde{\Phi}]$. Each branch uses a $3\times3$ convolution, group normalization, GELU, and a final $3\times3$ convolution [S1, unofficial].
        3.  **Front/Back Branches:** Output 37 channels each [S1, unofficial].
        4.  **Depth Offset Branch:** Outputs a scalar $\Delta z$ [S1, unofficial].

6.  **Gaussian Center and Depth Calculation:**
    For each canvas pixel $p$, compute centers for the front and back layers:
    *   **Front Layer:**
        *   Depth: $z_{\text{front}}(p) = \tilde{z}(p)$ [S1, unofficial].
        *   Image-plane offsets: $(\delta_{u,\text{front}}, \delta_{v,\text{front}}) = \sigma(o_{\text{front}}) - 0.5$, bounded to half a canvas pixel per axis, where $o_{\text{front}}$ is the 2-channel offset output [S1, unofficial].
        *   Center: $x_{\text{front}}(p) = z_{\text{front}}(p) \tilde{K}^{-1} [u + \delta_{u,\text{front}}, v + \delta_{v,\text{front}}, 1]^\top$, where $\tilde{K}$ is the extended canvas intrinsic matrix [S1, unofficial].
    *   **Back Layer:**
        *   Depth: $z_{\text{back}}(p) = \max_{q \in N_9(p)} \tilde{z}(q) + \text{softplus}(\Delta z(p))$, where $N_9(p)$ is a $9\times9$ neighborhood [S1, unofficial].
        *   Center: $x_{\text{back}}(p) = z_{\text{back}}(p) \tilde{K}^{-1} [u + \delta_{u,\text{back}}, v + \delta_{v,\text{back}}, 1]^\top$, using back-layer offsets [S1, unofficial].

7.  **Gaussian Attribute Composition:**
    Predict attributes as residuals around a reference-image base:
    *   **Base Scale:** Isotropic base scale $s_{0,\ell} = \kappa z_\ell / (f_x f_y)$, following the metric pixel footprint [S1, unofficial].
    *   **Residuals:**
        *   Scale: Bounded multiplicative updates.
        *   Rotation: Additive quaternion updates.
        *   Opacity: Updates in logit space.
        *   Color: Degree-2 spherical harmonic (SH) residuals around a reference-image DC base [S1, unofficial].

8.  **Rendering:**
    Concatenate front and back layers. Render target views using both layers without an edge mask restricting the back layer, allowing learned attributes and visibility to determine contributions [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Padding:** Without padding, empty target-border bands appear in rendered views; padding fills these newly exposed regions [S1, unofficial].
*   **Fixed Depth:** Fixed front-layer depth limits stereo-error correction [S1, unofficial].
*   **Teacher Artifacts:** Teacher artifacts can persist despite reconstruction-quality filtering [S1, unofficial].
*   **Descriptor:** Without the DPT descriptor, tabletop distortions and foreground-boundary artifacts occur [S1, unofficial].

## Background
StereoGaussians was introduced by Charatan et al. (2024) in the paper "StereoGaussians: Feed-Forward 3D Gaussian Splatting from Stereo Images" [S1, unofficial]. It builds on the concept of feed-forward 3DGS prediction, adapting it for stereo inputs by leveraging frozen pretrained stereo networks. The method was trained on the SceneSplat-Stereo dataset, which pairs stereo inputs with nearby target views from 803 training scenes [S1, unofficial]. It is used on StereoNVS and ReplicaGS datasets [S1, unofficial].
