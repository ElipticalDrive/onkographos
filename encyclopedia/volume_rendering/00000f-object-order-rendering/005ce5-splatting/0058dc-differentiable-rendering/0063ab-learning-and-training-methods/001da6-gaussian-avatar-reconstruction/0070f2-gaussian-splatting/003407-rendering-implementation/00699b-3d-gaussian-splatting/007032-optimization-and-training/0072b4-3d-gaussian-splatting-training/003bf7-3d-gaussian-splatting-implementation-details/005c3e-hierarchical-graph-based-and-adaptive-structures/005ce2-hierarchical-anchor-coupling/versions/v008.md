# Hierarchical Anchor Coupling

Also called: Per-level hierarchical anchor coupling

## Overview
Hierarchical Anchor Coupling (HAC) is a module that establishes cross-level gradient pathways in structured 3D Gaussian splatting by aggregating context from adjacent octree levels and broadcasting a residual feature adjustment to all visible anchors at a specific level [S1, unofficial]. It solves the problem of feature isolation, where backpropagation graphs in anchor-based octree pipelines lack connections between features at level $l_i$ and those at adjacent levels $l_i \pm 1$ [S1, unofficial]. Unlike sibling methods that may use per-anchor spatial lookups or graph-based neighbor interactions, HAC operates at a per-level granularity, invoking a shared MLP once per visible level to compute a uniform adjustment, which acts as an implicit regularizer against over-parameterization in scenes with dense, repetitive structures [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** The set of visible anchors $V$ for a training camera, where each anchor $i \in V$ has an octree level $l_i$ and a base feature vector $f_i \in \mathbb{R}^d$.
*   **Output:** Enhanced feature vectors $\hat{f}_i$ for all $i \in V$, which replace $f_i$ as input to the downstream Neural Gaussian decoding MLPs.

**Data Structures:**
*   **Visible Anchor Set ($V$):** A collection of anchors currently visible to the camera.
*   **Level Set ($L_V$):** The set of unique octree levels present in $V$, defined as $L_V = \{l_i : i \in V\}$.
*   **Level-Specific Visible Set ($V_l$):** The subset of anchors visible at level $l$, defined as $V_l = \{i \in V : l_i = l\}$.
*   **Context Vectors:** For each level $l \in L_V$, three context vectors are computed: self-context $c^l_{self}$, coarser-level context $c^l_{par}$, and finer-level context $c^l_{chi}$. These are concatenated into a triplet $t_l \in \mathbb{R}^{3d}$.
*   **Adjustment Vector ($\delta^l$):** A residual adjustment vector computed for each level $l \in L_V$.

**Parameters:**
*   **MLP ($g_\theta$):** A two-layer Multi-Layer Perceptron mapping $\mathbb{R}^{3d} \to \mathbb{R}^d \to \mathbb{R}^d$ with ReLU activation [S1, unofficial].
    *   Hidden dimension $d=32$ [S1, unofficial].
    *   Total parameters added by $g_\theta$: 4,160 [S1, unofficial].
*   **Granularity:** Per-level (default) or Per-anchor. Per-level computes a shared $\delta_l$ for every visible level. Per-anchor computes a distinct $\delta_i$ for every visible anchor [S1, unofficial].
*   **Aggregation Operators ($A^l_{par}, A^l_{chi}$):** Operators that incorporate octree topology to aggregate features from adjacent levels. These are specified by the Structure-Aware Containment Aggregation (SACA) module [S1, unofficial]. *Note: The specific implementation of SACA is external to HAC but required for the context vectors.*

**Numbered Steps:**
1.  **Identify Visible Levels and Anchors:** For the current training camera, identify the set of octree levels present in the visible anchor set $V$, denoted $L_V$. For each level $l \in L_V$, identify the visible anchors at that level, $V_l$.
2.  **Compute Self-Context:** Calculate the uniform mean of the base features of all visible anchors at level $l$:
    $$ c^l_{self} = \frac{1}{|V_l|} \sum_{i \in V_l} f_i $$
3.  **Compute Adjacent Contexts:**
    *   Calculate the coarser-level context $c^l_{par}$ by aggregating features from level $l-1$ using operator $A^l_{par}$:
        $$ c^l_{par} = A^l_{par}(\{f_i\}_{i \in V_{l-1}}) $$
    *   Calculate the finer-level context $c^l_{chi}$ by aggregating features from level $l+1$ using operator $A^l_{chi}$:
        $$ c^l_{chi} = A^l_{chi}(\{f_i\}_{i \in V_{l+1}}) $$
    *   **Edge Case:** If level $l$ is a boundary level in $L_V$ lacking an adjacent coarser level ($l-1 \notin L_V$) or finer level ($l+1 \notin L_V$), the corresponding context vector defaults to the self-context $c^l_{self}$ [S1, unofficial].
4.  **Form Context Triplet:** Concatenate the three context vectors into a single triplet for level $l$:
    $$ t_l = [c^l_{par}; c^l_{self}; c^l_{chi}] \in \mathbb{R}^{3d} $$
5.  **Compute Feature Adjustment:** Pass the triplet $t_l$ through the shared MLP $g_\theta$ to compute the level-wise adjustment:
    $$ \delta^l = g_\theta(t_l) $$
6.  **Broadcast and Enhance:** Broadcast the adjustment $\delta^l$ as a residual to all visible anchors at level $l$ to produce enhanced features:
    $$ \hat{f}_i = f_i + \delta^{l_i}, \quad \forall i \in V $$
7.  **Decode:** Pass the enhanced features $\{\hat{f}_i\}_{i \in V}$ to the standard Neural Gaussian decoding MLPs for rasterization.

**Pseudocode:**
```python
def hierarchical_anchor_coupling(visible_anchors, level_set, aggregation_ops, mlp_g_theta):
    """
    visible_anchors: List of anchor objects, each with attributes .level (int) and .feature (Tensor[d])
    level_set: Set of unique levels present in visible_anchors
    aggregation_ops: Dictionary mapping level l to (A_par, A_chi) operators
    mlp_g_theta: Two-layer MLP function taking R^{3d} and returning R^d
    
    Returns: List of enhanced features corresponding to visible_anchors
    """
    # Group anchors by level
    anchors_by_level = {}
    for anchor in visible_anchors:
        l = anchor.level
        if l not in anchors_by_level:
            anchors_by_level[l] = []
        anchors_by_level[l].append(anchor)

    # Compute context triplets for each visible level
    level_adjustments = {}
    
    for l in level_set:
        anchors_l = anchors_by_level[l]
        
        # 1. Self-context: Mean of features at current level
        features_l = [a.feature for a in anchors_l]
        c_self = sum(features_l) / len(features_l)
        
        # 2. Coarser-level context (l-1)
        if (l - 1) in anchors_by_level:
            anchors_par = anchors_by_level[l - 1]
            features_par = [a.feature for a in anchors_par]
            # A_par is assumed to be a function that aggregates features based on topology
            # If not provided by source, we assume a mean aggregation for implementation completeness
            # [G] Assuming mean aggregation if specific topology operator is not defined in HAC scope
            c_par = sum(features_par) / len(features_par) 
        else:
            c_par = c_self # Boundary case: default to self-context
            
        # 3. Finer-level context (l+1)
        if (l + 1) in anchors_by_level:
            anchors_chi = anchors_by_level[l + 1]
            features_chi = [a.feature for a in anchors_chi]
            # [G] Assuming mean aggregation if specific topology operator is not defined in HAC scope
            c_chi = sum(features_chi) / len(features_chi)
        else:
            c_chi = c_self # Boundary case: default to self-context
            
        # 4. Concatenate triplet
        # Note: In PyTorch, this would be torch.cat([c_par, c_self, c_chi], dim=-1)
        triplet = concatenate([c_par, c_self, c_chi])
        
        # 5. Compute adjustment via MLP
        delta_l = mlp_g_theta(triplet)
        
        level_adjustments[l] = delta_l

    # 6. Broadcast adjustments to anchors
    enhanced_features = []
    for anchor in visible_anchors:
        l = anchor.level
        delta = level_adjustments[l]
        enhanced_f = anchor.feature + delta
        enhanced_features.append(enhanced_f)
        
    return enhanced_features
```

## Subtopics

### Per-level vs. Per-anchor Granularity
Per-level computes a shared adjustment $\delta_l$ for all anchors at level $l$, invoking the MLP once per visible level. Per-anchor computes a distinct adjustment $\delta_i$ for each anchor, invoking the MLP once per visible anchor. Per-level is chosen for its efficiency and regularization benefits in repetitive structures, while per-anchor may offer slight gains in simpler geometry [S1, unofficial].

### Structure-Aware Containment Aggregation (SACA)
The mechanism used to compute $c^l_{par}$ and $c^l_{chi}$. It incorporates octree topology via binary masks or soft-weighting schemes to reduce the influence of topologically isolated anchors. While not part of HAC's core definition, it is the required input provider for the adjacent context vectors [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The MLP evaluation cost scales with the number of visible levels $|L_V|$, not the number of visible anchors $|V|$. Computing level-wise means and broadcasting residuals scales linearly with $|V|$ [S1, unofficial]. A per-anchor alternative would scale linearly with $|V|$ for MLP evaluation.
*   **Memory Complexity:** Adds 4,160 parameters (for $d=32$) to the model, which is less than 0.1% of the total parameters [S1, unofficial].
*   **Performance:** On the Mill19-Building scene, HAC alone yields a PSNR improvement of +1.91 dB over the baseline [S1, unofficial].
*   **Granularity Trade-offs:**
    *   **Per-level:** +1.06 dB on Building (dense repetitive structures); ~20% faster training than per-anchor [S1, unofficial].
    *   **Per-anchor:** +0.21 dB on Rubble (simpler geometry) [S1, unofficial].
*   **Strengths:** Alleviates feature isolation; improves PSNR significantly; low parameter overhead; efficient training time due to level-granularity MLP invocation.
*   **Limitations:** Performance gain is scene-dependent (per-level may underperform per-anchor in simple geometries); relies on the correctness of the adjacent level aggregation (SACA).
*   **When to use:** When using structured 3DGS backbones (e.g., CityGS-X, Octree-GS, Proxy-GS) and training on scenes with dense, repetitive structures where cross-level consistency is beneficial.
*   **When not to use:** If the scene has very simple geometry where per-anchor adjustments might be more precise and the performance gain from per-level is negligible or negative.

## Background
Hierarchical Anchor Coupling was introduced in the paper "TopoGS: Topology-Aware Anchor Feature Aggregation for Large-Scale 3D Gaussian Splatting" [S1, unofficial]. It is integrated into the TopoGS framework, which also includes the Structure-Aware Containment Aggregation (SACA) module. The method was designed to address the lack of cross-level gradient pathways in existing anchor-based octree pipelines, which led to feature isolation and suboptimal reconstruction quality. It has been demonstrated to be transferable to other backbones such as Octree-GS and Proxy-GS [S1, unofficial].
