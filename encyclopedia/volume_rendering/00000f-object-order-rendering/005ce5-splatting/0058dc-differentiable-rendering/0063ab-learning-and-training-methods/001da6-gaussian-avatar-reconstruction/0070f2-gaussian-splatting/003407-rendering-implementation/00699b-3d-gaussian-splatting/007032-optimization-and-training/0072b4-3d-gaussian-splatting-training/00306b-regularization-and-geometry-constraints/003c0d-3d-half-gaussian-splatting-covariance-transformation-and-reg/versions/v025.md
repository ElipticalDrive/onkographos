# 3D Half-Gaussian Splatting Covariance Transformation and Regularization

Also called: 3D-HGS

## Overview
3D Half-Gaussian Splatting (3D-HGS) addresses the geometric inconsistency and "floaters" (Gaussians in empty space) inherent in standard 3D Gaussian Splatting by enforcing that Gaussians act as half-ellipsoids aligned with local surface normals [S1]. Unlike sibling methods that rely on external depth supervision or frequency penalties, 3D-HGS modifies the covariance structure directly during optimization to constrain the Gaussian volume to one side of a tangent plane, effectively modeling sharp surface transitions [S1]. It builds on [Regularization and Geometry Constraints](6269-regularization-and-geometry-constraints.md) by introducing a specific covariance transformation that projects the ellipsoid onto a half-space defined by the surface normal.

## How it works
The method transforms the standard 3D Gaussian covariance matrix $\Sigma$ into a regularized form $\sigma$ that represents a half-Gaussian. This transformation is applied periodically during training to enforce geometric priors.

### Inputs and Outputs
*   **Input:** The original covariance matrix $\Sigma \in \mathbb{R}^{3 \times 3}$ (symmetric positive definite), and the surface normal vector $\mathbf{n} \in \mathbb{R}^3$.
*   **Output:** The regularized covariance matrix $\sigma \in \mathbb{R}^{3 \times 3}$.

### Data Structures
The covariance matrix is stored as a $3 \times 3$ symmetric matrix. In implementation, this is often stored as 6 unique values or a full 9-value matrix with symmetry constraints. The basis matrix is a $3 \times 3$ orthogonal matrix.

### Parameters
*   **Regularization Interval:** The transformation is applied every 5000 training iterations [S1].
*   **Opacity Threshold (Densification/Pruning):** Increased to 0.01 to eliminate noise [S1].
*   **Initial Opacity (Half-Gaussians):** Reset to 0.02 [S1].
*   **Scaling Factor:** The minimum diagonal element in the normal direction is divided by 100 [S1].

### Algorithm Steps
1.  **Normalize Normal:** Normalize the input normal vector $\mathbf{n}$ to unit length: $\mathbf{n} \leftarrow \mathbf{n} / \|\mathbf{n}\|$.
2.  **Construct Basis:** Create an orthonormal basis $\{\mathbf{v}_1, \mathbf{v}_2, \mathbf{n}\}$ where $\mathbf{v}_1$ and $\mathbf{v}_2$ span the tangent plane.
    *   If $n_x = 0$ and $n_y = 0$ (normal is parallel to Z-axis), set $\mathbf{v}_1 = (1, 0, 0)$ and $\mathbf{v}_2 = (0, 1, 0)$.
    *   Otherwise, compute $\mathbf{v}_1 = (n_y, -n_x, 0) / \|(n_y, -n_x, 0)\|$ and $\mathbf{v}_2 = \mathbf{n} \times \mathbf{v}_1 / \|\mathbf{n} \times \mathbf{v}_1\|$.
    *   Form the basis matrix $B = [\mathbf{v}_1, \mathbf{v}_2, \mathbf{n}]$.
3.  **Transform to Basis Space:** Project the covariance into the tangent basis: $C = B^T \Sigma B$.
4.  **Compute Modified Diagonal/Off-Diagonal Elements:** Calculate the Schur complement-like terms for the tangent plane components:
    *   $a' = C_{0,0} - \frac{C_{0,2}^2}{C_{2,2}}$
    *   $b' = C_{0,1} - \frac{C_{0,2} C_{1,2}}{C_{2,2}}$
    *   $c' = C_{1,1} - \frac{C_{1,2}^2}{C_{2,2}}$
5.  **Construct Regularized Covariance in Basis Space:** Create a new matrix $\sigma_{basis}$:
    *   $\sigma_{basis}[0,0] = a'$
    *   $\sigma_{basis}[0,1] = b'$
    *   $\sigma_{basis}[1,0] = b'$
    *   $\sigma_{basis}[1,1] = c'$
    *   $\sigma_{basis}[2,2] = \min(a', c') / 100$
    *   All other elements (specifically $\sigma_{basis}[0,2], \sigma_{basis}[1,2], \sigma_{basis}[2,0], \sigma_{basis}[2,1]$) are set to 0.
6.  **Transform Back to World Space:** $\sigma = B \sigma_{basis} B^T$.

### Pseudocode
```python
import numpy as np

def transform_covariance_to_half_gaussian(cov_matrix: np.ndarray, normal: np.ndarray) -> np.ndarray:
    """
    Transforms a 3D Gaussian covariance matrix into a half-Gaussian covariance
    aligned with the given surface normal.
    
    Args:
        cov_matrix: 3x3 symmetric positive definite covariance matrix Sigma.
        normal: 3D vector representing the surface normal n.
        
    Returns:
        3x3 regularized covariance matrix sigma.
    """
    # 1. Normalize normal
    n = normal / np.linalg.norm(normal)
    
    # 2. Construct basis
    # Check if normal is parallel to Z-axis
    if np.isclose(n[0], 0.0) and np.isclose(n[1], 0.0):
        v1 = np.array([1.0, 0.0, 0.0])
        v2 = np.array([0.0, 1.0, 0.0])
    else:
        # v1 is orthogonal to n and lies in XY plane projection
        v1_raw = np.array([n[1], -n[0], 0.0])
        v1 = v1_raw / np.linalg.norm(v1_raw)
        # v2 is orthogonal to both n and v1
        v2 = np.cross(n, v1)
        v2 = v2 / np.linalg.norm(v2)
        
    # Basis matrix B = [v1, v2, n] as columns
    B = np.column_stack((v1, v2, n))
    
    # 3. Transform covariance to basis space
    # cov = B^T * Sigma * B
    cov = B.T @ cov_matrix @ B
    
    # 4. Compute modified elements
    # Avoid division by zero if cov[2,2] is extremely small, though typically positive definite
    denom = cov[2, 2]
    if denom < 1e-8:
        denom = 1e-8
        
    a_prime = cov[0, 0] - (cov[0, 2] ** 2) / denom
    b_prime = cov[0, 1] - (cov[0, 2] * cov[1, 2]) / denom
    c_prime = cov[1, 1] - (cov[1, 2] ** 2) / denom
    
    # 5. Construct regularized covariance in basis space
    sigma_basis = np.zeros((3, 3))
    sigma_basis[0, 0] = a_prime
    sigma_basis[0, 1] = b_prime
    sigma_basis[1, 0] = b_prime
    sigma_basis[1, 1] = c_prime
    sigma_basis[2, 2] = min(a_prime, c_prime) / 100.0
    
    # 6. Transform back to world space
    sigma = B @ sigma_basis @ B.T
    
    return sigma
```

### Edge Cases and Pitfalls
*   **Degenerate Normals:** If the normal vector is zero or near-zero, normalization fails. The code must handle this by defaulting to a standard basis or skipping regularization [S1].
*   **Positive Definiteness:** The transformation involves a Schur complement. If the original covariance is not well-conditioned, $C_{2,2}$ might be very small, leading to numerical instability in the division. A small epsilon floor is recommended [G].
*   **Iteration Frequency:** The regularization is not applied every iteration but every 5000 iterations. Applying it too frequently may hinder convergence of the covariance shape [S1].

## Operating characteristics
*   **Time Complexity:** The transformation involves matrix multiplications ($3 \times 3$) and is applied periodically (every 5000 iterations), adding negligible overhead to the per-step rendering cost. The primary cost remains the rasterization of the half-Gaussians.
*   **Memory Complexity:** No additional significant memory overhead compared to standard 3DGS, as it modifies existing covariance parameters.
*   **Performance:** On the Mip-NeRF 360 dataset, 3D-HGS with an efficient rasterizer achieves 125 FPS and 29.66 PSNR using 3.8M kernels, compared to 3DGS which uses 3.2M kernels [S1]. On Tank & Dengin, it achieves 160 FPS and 24.45 PSNR with 1.8M kernels [S1]. On Tank & Blending, it achieves 126 FPS and 29.76 PSNR with 2.6M kernels [S1].
*   **Strengths:** Effectively eliminates floaters and produces sharper surface boundaries by aligning Gaussians with surface normals. Consistently outperforms original 3DGS in PSNR and other metrics [S1].
*   **Limitations:** Requires accurate surface normals for the transformation. If normals are noisy or unavailable, the regularization may distort the geometry. The method relies on the efficient rasterizer for optimal performance [S1].

## Background
3D Half-Gaussian Splatting (3D-HGS) was introduced to improve the geometric fidelity of 3D Gaussian Splatting. Standard 3DGS optimizes for photometric loss, often resulting in volumetric blobs rather than thin surfaces. 3D-HGS modifies the Gaussian kernel to be a half-ellipsoid, constrained by a splitting plane defined by the surface normal. This approach was evaluated against architectures like Scaffold, mip-splatting, and MCMC, demonstrating superior performance in reconstructing sharp surfaces [S1].
