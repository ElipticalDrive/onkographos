# Inpainting for Displaced Objects

Also called: GSP Inpainting, LaMa Inpainting

## Overview
This method remedies black smudges and dirty textures caused by displaced objects exposing unseen areas that 3D Gaussian Splatting (3DGS) cannot recover from input images [S1]. Unlike vanilla 3DGS, which leaves empty spots and dirty textures blended from irrelevant kernels when objects are displaced, this technique ameliorates the issue using generative AI inpainting [S1]. It is primarily used in dynamic scenarios where rigid or deformable objects move, revealing background regions that were occluded in the training data [S1].

## How it works
**Inputs:**
*   A set of 3D Gaussian kernels representing the scene, including those belonging to objects that may be displaced.
*   A rendered image of the scene with the displaced objects removed (or masked out).
*   A generative inpainting model (specifically LaMa [S1] or Stable Diffusion [S2]).

**Outputs:**
*   Updated Gaussian kernels with corrected diffuse colors, opacity set to 1, and specular color set to 0.

**Data Structures:**
*   **Gaussian Kernel:** Standard 3DGS attributes: mean $\mu$, covariance $\Sigma$, opacity $\alpha$, spherical harmonics coefficients $\mathbf{c}$ (split into diffuse $\mathbf{c}_{diff}$ and specular $\mathbf{c}_{spec}$ components for this method).
*   **Rendered Image:** A 2D array of pixel colors corresponding to the camera view.
*   **Ray History:** A mapping from pixel coordinates to the first Gaussian kernel index encountered by the ray during the initial render.

**Steps:**
1.  **Remove Displaced Kernels:** Identify and remove all Gaussian kernels belonging to the object(s) that may be displaced from the scene representation [S1].
2.  **Render Base Image:** Render the remaining scene from the camera viewpoint. This results in an image with holes (black smudges) where the displaced objects were previously visible [S1].
3.  **Record Ray Intersections:** For each pixel in the rendered image, record the index of the first Gaussian kernel encountered by the ray emitted from the camera through that pixel [S1]. This is necessary to map inpainted colors back to 3D geometry.
4.  **Generative Inpainting:** Use a generative inpainting model (LaMa [S1] or Stable Diffusion [S2]) to fill the holes in the rendered image.
    *   *Note:* If using Stable Diffusion, an alpha mask indicating the holes is required [S2].
5.  **Extract Inpainted Colors:** Obtain the new colors for the pixels that were originally in the holes (the inpainted regions) [S1].
6.  **Assign Colors to Kernels:** For each pixel in the inpainted region, retrieve the recorded Gaussian kernel index from Step 3. Assign the inpainted color of that pixel to the diffuse color component of the corresponding Gaussian kernel [S1].
7.  **Average Colors:** If multiple rays (from different views or iterations) map to the same Gaussian kernel, average the recorded diffuse colors assigned to that kernel [S1].
8.  **Update Attributes:**
    *   Set the opacity $\alpha$ of the affected Gaussian kernels to 1 [S1].
    *   Set the specular color component $\mathbf{c}_{spec}$ to 0 to prevent highlights in the inpainted regions [S1].
    *   Update the diffuse color component $\mathbf{c}_{diff}$ with the averaged colors from Step 7 [S1].

**Pseudocode:**
```python
def inpaint_displaced_objects(gaussians, camera, inpaint_model):
    """
    Remedy black smudges caused by displaced objects by removing kernels,
    inpainting the view, and reassigning colors.
    
    Args:
        gaussians: List of Gaussian kernels with attributes (mu, sigma, alpha, c_diff, c_spec)
        camera: Camera parameters for rendering
        inpaint_model: Generative model (e.g., LaMa) capable of inpainting holes
        
    Returns:
        Updated gaussians list
    """
    # Step 1: Identify and remove kernels of displaced objects
    # This requires external segmentation or prior knowledge of which objects are displaced
    displaced_kernel_indices = identify_displaced_kernels(gaussians)
    active_gaussians = [g for i, g in enumerate(gaussians) if i not in displaced_kernel_indices]
    
    # Step 2 & 3: Render and record ray intersections
    # Render the scene with only active_gaussians
    rendered_image, ray_hits = render_with_ray_history(active_gaussians, camera)
    # ray_hits: dict mapping (u, v) -> kernel_index
    
    # Step 4: Inpaint the holes
    # The holes are implicitly the areas where no kernel was hit or masked out
    # For LaMa, the holes are typically defined by the absence of valid color or a mask
    inpainted_image = inpaint_model(rendered_image, mask=get_holes_mask(rendered_image))
    
    # Step 5, 6, 7: Assign colors to kernels
    # Initialize color accumulation for affected kernels
    color_accumulators = {} # kernel_index -> list of colors
    
    for (u, v), kernel_idx in ray_hits.items():
        # Check if this pixel was in a hole (i.e., originally had no kernel or was displaced)
        # In the context of GSP, we assume the holes correspond to the displaced object area
        if is_in_hole(u, v, rendered_image):
            new_color = inpainted_image[u, v]
            if kernel_idx not in color_accumulators:
                color_accumulators[kernel_idx] = []
            color_accumulators[kernel_idx].append(new_color)
            
    # Step 8: Update attributes
    for kernel_idx, colors in color_accumulators.items():
        # Find the original kernel object (note: indices may shift if list was modified, 
        # so we assume we track original indices or re-map)
        kernel = get_kernel_by_original_index(kernel_idx)
        
        # Average the recorded colors
        avg_color = sum(colors) / len(colors)
        
        # Update diffuse color
        kernel.c_diff = avg_color
        
        # Set opacity to 1
        kernel.alpha = 1.0
        
        # Set specular color to 0
        kernel.c_spec = 0.0
        
    return gaussians
```

**Parameters:**
*   **Inpainting Model:** LaMa [S1] is the primary model cited. Stable Diffusion is used in the 3D Inpainting Pipeline variant [S2].
*   **Opacity:** Fixed to 1 [S1].
*   **Specular Color:** Fixed to 0 [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** The method relies on accurate ray-kernel intersection recording. If the ray history is not stored or mapped correctly, colors will be assigned to the wrong kernels [S1].
*   **Boundaries:** The method assumes the displaced object is fully segmented and removed. Partial removal may lead to artifacts [S1].
*   **Degenerate Input:** If the inpainting model fails to generate plausible textures for the holes, the resulting colors may be incorrect, leading to visual artifacts [S1].

## Subtopics

### 3D Inpainting Pipeline
A sequential pipeline to fill occluded/missing regions in rendered novel views while maintaining 3D consistency, leveraging the constraint that Gaussians do not hallucinate details [S2]. Unlike the single-view LaMa approach, this method uses Stable Diffusion for texture generation and monocular depth estimation for geometric consistency [S2]. It is chosen when 3D consistency across multiple novel views is required [S2].

**Steps:**
1.  Render a novel view with holes and an alpha mask [S2].
2.  Use Stable Diffusion inpainting to generate missing texture in the masked regions [S2].
3.  Estimate monocular depth on the inpainted image [S2].
4.  Use the gradient of this depth to fill in rendered depth in the masked regions using Poisson blending [S2].
5.  Project Gaussians to the scene using the inpainted depth and image [S2].
6.  Repeat the process sequentially for a few novel views until the scene is 3D consistent and renderable from any view without holes [S2].

## Operating characteristics
*   **Time Complexity:** Depends on the generative inpainting model. LaMa is generally faster than Stable Diffusion [S1, S2].
*   **Memory Complexity:** Requires storing the ray history for all pixels, which is $O(W \times H)$ where $W, H$ are image dimensions [S1].
*   **Strengths:** Effectively removes black smudges and dirty textures caused by displaced objects [S1]. Maintains 3D consistency in the 3D Inpainting Pipeline variant [S2].
*   **Limitations:** Requires external generative models. The method assumes the displaced object can be fully segmented and removed [S1].
*   **When to Use:** When dynamic objects move and expose unseen background areas that 3DGS cannot recover from input images [S1].
*   **When Not to Use:** When the displaced object is not fully segmented or when real-time performance is critical and generative models are too slow [S1, S2].

## Background
The method was introduced in "Gaussian Splashing: Unified Particles for Versatile Motion Synthesis and Rendering" (2025) by Law et al. [S1]. It addresses a specific limitation of 3DGS where displaced objects expose unseen areas, leading to black smudges and dirty textures [S1]. The technique uses LaMa, a state-of-the-art inpainting model, to fill these gaps [S1]. A variant using Stable Diffusion and depth estimation was later proposed in "CoherentGS: Sparse Novel View Synthesis with Coherent 3D Gaussians" (2025) [S2].
