# Prior-Conditioned Parameterization (I)
Also called: I operator, Initialization Operator, Prior-Conditioned Gaussian Parameterization

## Overview
Prior-Conditioned Parameterization (I) is an initialization method that seeds anisotropic Gaussians by estimating local surface statistics (normals and scales) from a dense prior $P$, front-loading structure discovery [S1, unofficial]. It addresses the problem where standard 3D Gaussian Splatting initializes isotropic Gaussians from interpoint distances, leaving local surface scale and rotation to be recovered during optimization, which consumes available updates under short iteration horizons [S1, unofficial]. By mapping the dense prior $P$ to a surface-aligned anisotropic set $\Theta_0$, it provides spatial support, scale, and rotation before optimization, supporting rapid early convergence [S1, unofficial]. It sets itself apart from sibling methods by explicitly constructing disc-like covariance structures aligned to estimated normals, rather than relying on isotropic scaling or post-initialization densification to find surface geometry [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: A dense geometric prior point cloud $P = \{\mathbf{p}_i\}$, constructed by the Geometry Operator (G) [S1, unofficial].
*   **Output**: An initialized Gaussian set $\Theta_0 = \{(\boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i, \mathbf{c}_i, \alpha_i)\}$, where $\boldsymbol{\mu}_i$ is the position, $\boldsymbol{\Sigma}_i$ is the covariance, $\mathbf{c}_i$ is the color, and $\alpha_i$ is the opacity [S1, unofficial].

**Data Structures**
The method operates on the `GaussianList` data structure. For each point $\mathbf{p}_i \in P$:
*   $\boldsymbol{\mu}_i = \mathbf{p}_i$ (Position initialized to the prior point).
*   $\mathbf{q}_i$ (Quaternion rotation): Initialized to align the Gaussian's local z-axis with the estimated surface normal $\mathbf{n}_i$ [S1, unofficial].
*   $\mathbf{s}_i = [s_t, s_t, s_n]$ (Scale vector): Optimized in log-space for positivity [S1, unofficial].
*   $\alpha_i$: Opacity initialized to the logit of 0.1, i.e., $\alpha_i = \log(0.1 / (1 - 0.1))$ [S1, unofficial].
*   $\mathbf{c}_i$: Color is typically copied from the prior or a default value; the source focuses on geometry parameterization [S1, unofficial].

**Parameters**
*   $K_n = 16$: Number of neighbors for normal estimation. A larger neighborhood suppresses sampling noise [S1, unofficial].
*   $K_s = 3$: Number of neighbors for tangential scale estimation. Tracks local density to avoid over-smoothing thin structures [S1, unofficial].
*   $r_{\text{normal}}$: A constant factor for the normal-direction scale relative to the tangential scale. The exact numerical value is not specified in the source text [S1, unofficial].

**Steps**
1.  **Estimate Local Surface Statistics**: For each point $\mathbf{p}_i$ in the dense prior $P$:
    a.  Identify $K_n$ nearest neighbors $\{\mathbf{p}_{i,k}\}_{k=1}^{K_n}$ and $K_s$ nearest neighbors $\{\mathbf{p}_{i,k}\}_{k=1}^{K_s}$ within $P$ [S1, unofficial].
    b.  Compute the centroid of the normal neighbors: $\bar{\mathbf{p}}_i = \frac{1}{K_n} \sum_{k=1}^{K_n} \mathbf{p}_{i,k}$ [S1, unofficial].
    c.  Compute the local covariance matrix $\mathbf{C}_i$:
        $$ \mathbf{C}_i = \frac{1}{K_n} \sum_{k=1}^{K_n} (\mathbf{p}_{i,k} - \bar{\mathbf{p}}_i)(\mathbf{p}_{i,k} - \bar{\mathbf{p}}_i)^T $$
    d.  Extract the local surface normal $\mathbf{n}_i$ as the eigenvector corresponding to the smallest eigenvalue of $\mathbf{C}_i$ [S1, unofficial].
    e.  Compute the tangential scale $s_t$:
        $$ s_t = \frac{1}{K_s} \sum_{k=1}^{K_s} \|\mathbf{p}_i - \mathbf{p}_{i,k}\| $$
    f.  Compute the normal-direction scale $s_n$:
        $$ s_n = r_{\text{normal}} s_t $$
2.  **Seed Gaussians**: For each point $\mathbf{p}_i$:
    a.  Initialize position $\boldsymbol{\mu}_i = \mathbf{p}_i$ [S1, unofficial].
    b.  Initialize rotation $\mathbf{q}_i$ such that the Gaussian's local z-axis aligns with $\mathbf{n}_i$ [S1, unofficial].
    c.  Initialize scale $\mathbf{s}_i = [s_t, s_t, s_n]$. The Gaussian is seeded as a thin disc-like ellipsoid tangent to the local surface [S1, unofficial].
    d.  Initialize opacity $\alpha_i = \text{logit}(0.1)$ [S1, unofficial].

**Pseudocode**
```python
import numpy as np

def prior_conditioned_parameterization(points: np.ndarray, K_n: int = 16, K_s: int = 3, r_normal: float = 0.1) -> dict:
    """
    Seeds anisotropic Gaussians from a dense prior point cloud.
    
    Args:
        points: Array of shape (N, 3) containing the dense prior points P.
        K_n: Number of neighbors for normal estimation.
        K_s: Number of neighbors for tangential scale estimation.
        r_normal: Constant factor for normal-direction scale.
        
    Returns:
        A dictionary containing initialized Gaussian parameters:
        - positions: (N, 3)
        - scales: (N, 3) in linear space [s_t, s_t, s_n]
        - rotations: (N, 4) quaternions aligning z-axis with normals
        - opacities: (N,) logit values
    """
    N = points.shape[0]
    positions = points.copy()
    scales = np.zeros((N, 3))
    rotations = np.zeros((N, 4))
    opacities = np.log(0.1 / (1 - 0.1)) * np.ones(N)
    
    # Precompute KNN indices for efficiency. 
    # In a real implementation, use a KDTree or similar structure.
    # Here we assume a helper function get_knn_indices returns indices for all points.
    knn_indices_n = get_knn_indices(points, K_n) 
    knn_indices_s = get_knn_indices(points, K_s)
    
    for i in range(N):
        # 1. Estimate Normal
        neighbors_n = points[knn_indices_n[i]]
        centroid_n = np.mean(neighbors_n, axis=0)
        
        # Local covariance matrix
        diff = neighbors_n - centroid_n
        C_i = (diff.T @ diff) / K_n
        
        # Eigendecomposition to find smallest eigenvalue eigenvector
        eigenvalues, eigenvectors = np.linalg.eigh(C_i)
        # eigenvectors are columns; smallest eigenvalue is at index 0
        normal = eigenvectors[:, 0]
        
        # 2. Estimate Scales
        neighbors_s = points[knn_indices_s[i]]
        # Tangential scale: average distance to Ks nearest neighbors
        distances = np.linalg.norm(neighbors_s - points[i], axis=1)
        s_t = np.mean(distances)
        
        # Normal-direction scale
        s_n = r_normal * s_t
        
        # 3. Seed Gaussian
        scales[i] = [s_t, s_t, s_n]
        
        # Initialize rotation to align z-axis (0,0,1) with normal
        # Using quaternion rotation from vector v1 to v2
        rotations[i] = quaternion_from_vectors(np.array([0, 0, 1]), normal)
        
    return {
        "positions": positions,
        "scales": scales,
        "rotations": rotations,
        "opacities": opacities
    }

def get_knn_indices(points: np.ndarray, k: int) -> np.ndarray:
    """
    Helper to get KNN indices. 
    Note: In a production environment, this would use scipy.spatial.cKDTree or similar.
    This is a placeholder for the algorithmic step described in the source.
    """
    # Implementation detail: [G] Using a simple brute-force for clarity, 
    # though the source notes the scheme is "embarrassingly parallel and memory-bounded".
    # A KDTree is recommended for performance.
    from scipy.spatial import cKDTree
    tree = cKDTree(points)
    distances, indices = tree.query(points, k=k+1) # +1 because the point itself is the nearest neighbor
    # Remove the point itself (index 0) if it's included in the query
    return indices[:, 1:]

def quaternion_from_vectors(v1: np.ndarray, v2: np.ndarray) -> np.ndarray:
    """
    Computes the quaternion representing the rotation from v1 to v2.
    """
    v1 = v1 / np.linalg.norm(v1)
    v2 = v2 / np.linalg.norm(v2)
    cross = np.cross(v1, v2)
    w = np.sqrt((1 + np.dot(v1, v2)) * 2)
    x, y, z = cross[0], cross[1], cross[2]
    return np.array([x/w, y/w, z/w, 0.5 * w])
```

**Edge Cases and Pitfalls**
*   **Normals as Initialization Only**: Estimated normals are used only for initialization and never as training constraints [S1, unofficial].
*   **Scale Positivity**: Scales are optimized in log-space to ensure positivity [S1, unofficial].
*   **Noise Sensitivity**: The choice of $K_n$ is critical; too small a neighborhood may lead to noisy normal estimates, while too large may smooth out fine details [S1, unofficial].
*   **Thin Structures**: $K_s$ is kept small (3) to track local density and avoid over-smoothing thin structures [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: The normal estimation involves KNN queries and eigendecomposition for each point. With fixed $K_n$ and $K_s$, this is $O(N \cdot K \log N)$ or $O(N \cdot K)$ depending on the KNN implementation, where $N$ is the number of points. The source notes the scheme is "embarrassingly parallel and memory-bounded" [S1, unofficial].
*   **Memory Complexity**: $O(N)$ for storing the Gaussian parameters. The KNN structures add $O(N \cdot K)$ overhead [S1, unofficial].
*   **Performance**: The method is designed for mobile devices, targeting strict runtime and memory constraints. It reduces reliance on in-loop densification by providing a geometry-informed warm start [S1, unofficial].
*   **Strengths**: Rapid early convergence under short iteration horizons; reduces the need for scale and rotation correction during optimization; hardware-aligned for mobile GPUs [S1, unofficial].
*   **Limitations**: Relies on the quality of the dense prior $P$; if $P$ is noisy or incomplete, the initialization may be suboptimal. The exact value of $r_{\text{normal}}$ is not specified, requiring empirical tuning [S1, unofficial].

## Background
Prior-Conditioned Parameterization (I) is part of the PocketGS pipeline, a high-fidelity on-device training method for 3D Gaussian Splatting [S1, unofficial]. It was introduced in the paper "PocketGS: High-Fidelity On-Device Training for 3D Gaussian Splatting" [S1, unofficial]. The method addresses the limitations of standard 3DGS initialization on resource-constrained devices by front-loading geometry discovery [S1, unofficial].
