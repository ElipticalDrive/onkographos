# Chunk-scale Training


## Overview
Chunk-scale Training addresses the optimization challenges of large, sparse, unbounded scenes by dividing the environment into independent spatial chunks, each trained separately to handle low capture density and non-object-centric data [S1]. It distinguishes itself from standard 3D Gaussian Splatting (3DGS) by introducing a skybox for environmental consistency, modifying densification policies to handle sparse gradients, and applying monocular depth regularization for unobserved surfaces [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A large scene dataset with sparse camera poses, Structure-from-Motion (SfM) points, and image observations [S1].
*   **Output:** Optimized 3D Gaussian primitives for a specific spatial chunk, ready for hierarchical consolidation [S1].

**Data Structures:**
*   **Chunk Bounds:** A spatial region defining the extent of the current training unit [S1].
*   **Skybox:** A set of 3D Gaussian primitives placed on a sphere surrounding the scene [S1].
*   **Coarse Environment:** A pre-optimized representation of the scene outside the current chunk, used to provide context and prevent sky inconsistencies [S1].

**Parameters:**
*   **Skybox Size:** 100,000 3DGS primitives [S1].
*   **Skybox Radius:** A sphere with a diameter 10× the diameter of the scene extent [S1].
*   **Camera Selection Threshold:** Cameras are included if they are inside the chunk bounds or within 2× the chunk bounds, provided they have more than 50 SfM points within the chunk bounds [S1].
*   **Densification Metric:** Maximum of observed screen-space gradients (replacing the mean used in standard 3DGS) [S1].

**Steps:**
1.  **Define Skybox:** Place 100,000 3DGS primitives on a sphere with a diameter 10× the scene extent to capture sky effects and prevent inconsistent sky content across chunks [S1].
2.  **Select Cameras:** Identify cameras for the current chunk by including cameras inside the chunk bounds or within 2× the chunk bounds that have >50 SfM points within the chunk bounds [S1].
3.  **Initialize Coarse Environment:** Load the coarse optimization of the scene outside the current chunk, which remains fixed in geometry but is temporarily optimized for opacity and SH coefficients during chunk training to ensure consistency [S1].
4.  **Train Chunk Content:** Perform 3DGS optimization for the content inside the chunk using correct anti-aliasing techniques [S1].
5.  **Temporary Environment Optimization:** Perform a small, temporary optimization of the coarse environment and skybox outside the chunk, optimizing only opacity and SH coefficients without modifying geometry [S1].
6.  **Apply Modified Densification:** Use the maximum of the observed screen-space gradient for densification decisions, rather than the mean, to address sparse capture issues where mean gradients are unreliable [S1].
7.  **Depth Regularization:** Perform monocular depth prediction, scale and shift the predicted depth based on available SfM points, and use this depth map to regularize the optimization, particularly for unobserved surfaces like streets [S1].

**Pseudocode:**
```python
import math

def is_point_in_box(point, bounds):
    return bounds.min.x <= point.x <= bounds.max.x and bounds.min.y <= point.y <= bounds.max.y and bounds.min.z <= point.z <= bounds.max.z

def distance_to_box_center(point, bounds):
    return math.sqrt((point.x - bounds.center.x)**2 + (point.y - bounds.center.y)**2 + (point.z - bounds.center.z)**2)

def count_sfm_points_in_box(points, bounds):
    return sum(1 for p in points if is_point_in_box(p, bounds))

def create_skybox_primitives(count, radius):
    primitives = []
    for i in range(count):
        phi = math.acos(1 - 2 * (i + 0.5) / count)
        theta = 2 * math.pi * i / count
        x = radius * math.sin(phi) * math.cos(theta)
        y = radius * math.sin(phi) * math.sin(theta)
        z = radius * math.cos(phi)
        primitives.append(Gaussian(position=(x,y,z), opacity=1.0, sh=[0.0]*3, scale=(1.0,1.0,1.0), rot=(0,0,0,1)))
    return primitives

def load_coarse_optimization_outside(chunk_bounds):
    return load_saved_gaussians_outside(chunk_bounds)

def initialize_gaussians_from_sfm(sfm_points, chunk_bounds):
    return [Gaussian.from_sfm_point(p) for p in sfm_points if is_point_in_box(p, chunk_bounds)]

def render_gaussians(gaussians, camera):
    return rasterize(gaussians, camera)

def compute_l1_loss(rendered, target):
    return sum(abs(r - t) for r, t in zip(rendered, target)) / len(rendered)

def compute_max_screen_space_gradients(gaussians):
    return max(g.grad_screen for g in gaussians)

def densify_gaussians(gaussians, max_grad, threshold):
    if max_grad > threshold:
        split_and_clone_gaussians(gaussians)

def predict_monocular_depth(image):
    return depth_network(image)

def scale_shift_depth(pred_depth, sfm_points):
    return align_depth_to_sfm(pred_depth, sfm_points)

def chunk_scale_training(chunk_bounds, scene_sfm_points, images, cameras, scene_diameter):
    skybox_primitives = create_skybox_primitives(100000, 5 * scene_diameter)
    selected_cameras = []
    for cam in cameras:
        if is_point_in_box(cam.position, chunk_bounds):
            selected_cameras.append(cam)
        elif distance_to_box_center(cam.position, chunk_bounds) <= 2.0 * chunk_bounds.radius:
            if count_sfm_points_in_box(cam.sfm_points, chunk_bounds) > 50:
                selected_cameras.append(cam)

    coarse_env = load_coarse_optimization_outside(chunk_bounds)
    chunk_gaussians = initialize_gaussians_from_sfm(scene_sfm_points, chunk_bounds)

    # Not given in the sources.
    for iteration in range(30000):
        for cam in selected_cameras:
            rendered_image = render_gaussians(chunk_gaussians + coarse_env + skybox_primitives, cam)
            target_image = get_image(cam)
            loss = compute_l1_loss(rendered_image, target_image)
            loss.backward()

            max_gradients = compute_max_screen_space_gradients(chunk_gaussians)
            densify_gaussians(chunk_gaussians, max_gradients, threshold=0.0002)

            pred_depth = predict_monocular_depth(target_image)
            scaled_depth = scale_shift_depth(pred_depth, scene_sfm_points)
            depth_loss = compute_l1_loss(render_gaussians(chunk_gaussians, cam).depth, scaled_depth)
            loss += 0.5 * depth_loss
            loss.backward()

        optimizer.step()
        optimizer.zero_grad()
        optimize_coarse_env_opacity_sh(coarse_env)

    return chunk_gaussians
```

**Edge Cases and Pitfalls:**
*   **Sparse Capture:** Standard mean-based densification rarely discourages densification in unbounded scenes and has low tendency in sparse captures, leading to poor quality in areas like streets [S1]. The maximum gradient policy addresses this [S1].
*   **Inconsistency:** Without a skybox and coarse environment, chunks may create inconsistent sky content [S1].
*   **Unobserved Surfaces:** Sparse camera captures lack information for good quality reconstruction of large unobserved areas (e.g., roads) [S1]. Depth regularization is required [S1].

## Operating characteristics
*   **Time Complexity:** Training is performed per chunk, allowing for parallelization across chunks, while temporary optimization of the coarse environment and skybox adds overhead per chunk [S1].
*   **Memory Complexity:** Memory usage is bounded by the size of a single chunk plus the skybox and coarse environment, making it feasible for very large datasets that would not fit in memory as a single 3DGS model [S1].
*   **Strengths:** Handles large, sparse, unbounded scenes, prevents sky inconsistencies, and improves quality in unobserved areas via depth regularization [S1].
*   **Limitations:** Requires careful chunk boundary definition, relies on monocular depth prediction which may be inaccurate, and temporary optimization of the coarse environment adds computational cost [S1].
*   **When to Use:** Large-scale urban or outdoor scenes with sparse camera captures and non-object-centric data [S1].
*   **When Not to Use:** Small, dense, object-centric scenes where standard 3DGS performs well [S1].

## Background
Chunk-scale Training was introduced in "A Hierarchical 3D Gaussian Representation for Real-Time Rendering of Very Large Datasets" by Kerbl et al. (2024) [S1]. It was developed to extend 3D Gaussian Splatting to very large datasets, addressing the limitations of the original method which assumed dense, object-centric captures [S1]. The method builds on the hierarchical structure and consolidation techniques described in the same work [S1].
