# Light Space Rasterization for T_light

Also called: Front Tau Rasterization, Light Space Shadow Rasterization, T_light Rasterization (Light Space)

## Overview
Light Space Rasterization computes $T_{light}$, the front-facing occlusion transmittance for each Gaussian along a directional sun direction, enabling physically based self-shadowing in 3D Gaussian Splatting [S1, unofficial]. It differs from its siblings, [Ref-Gaussian Deferred Surfel Rendering with Split-Sum IBL](4464-ref-gaussian-deferred-surfel-rendering-with-split-sum-ibl.md) and [3D Gaussian Splatting Self-Shadowing (T_light)](4487-3d-gaussian-splatting-self-shadowing-t-light.md), by using a dedicated light-space rasterization pass that provides full continuous gradients and zero EWA expansion by default, avoiding the inversion artifacts associated with early-termination in deep occlusion [S1, unofficial].

## How it works
**Inputs:**
*   3D Gaussian primitives (position, covariance, opacity, color) [G].
*   Sun direction vector [S1, unofficial].
*   Camera parameters for the "sun camera" (see below) [S1, unofficial].

**Outputs:**
*   $T_{light}$ value for each Gaussian (or pixel coverage thereof) [S1, unofficial].
*   Shadowed RGB image [G].

**Data Structures:**
*   **Sun Camera:** A perspective camera with a narrow Field of View (FOV) placed at a large distance to simulate parallel sun rays. The parallax error is kept below 2% to avoid changing the EWA Jacobian [S1, unofficial].
*   **Splat Buffer:** Standard Gaussian splat attributes [G].
*   **Material Buffer:** Parallel buffer storing normal, roughness, reflectance, and albedo for relighting, aligned with the Splat Buffer [G].
*   **T_light Buffer:** Stores the computed front tau ($\tau$) and transmittance [S1, unofficial].

**Steps:**
1.  **Camera Setup:** Construct the sun camera. The framing, sorting, coverage, and threshold branches are treated as constants during the pass to prevent incorrect gradient propagation [S1, unofficial].
2.  **Sorting:** Sort Gaussians by depth relative to the sun camera. This ensures correct front-to-back accumulation for shadowing [S1, unofficial].
3.  **Rasterization Pass:**
    *   Project Gaussians into light space.
    *   **Crucial Difference:** Do **not** expand the projection covariance by $0.3I$ and do **not** apply amplitude compensation. This preserves the main camera pass's sampling expansion [S1, unofficial].
    *   Traverse Gaussians in depth order.
    *   For each Gaussian, accumulate front $\tau$ (optical depth) weighted by $\alpha \cdot T$. This is an energy-weighted mean over the entire sun-facing footprint, not a center-point sample [S1, unofficial].
    *   Use the `record_front_tau` channel logic [S1, unofficial].
4.  **Shadow Application:** Combine $T_{light}$ with the base color [G].
    *   **Pitfall Handling:** Deeply buried Gaussians (where early-termination results in $wsum=0$) are explicitly mapped to full shadow to prevent inversion artifacts [S1, unofficial].

**Pseudocode:**
```python
import math

def compute_t_light(gaussians, sun_camera):
    # 1. Camera Setup: narrow FOV perspective camera at large distance [S1, unofficial]
    # 2. Sorting: depth-ordered traversal relative to sun camera [S1, unofficial]
    sorted_gaussians = sorted(gaussians, key=lambda g: dot(g.position, sun_camera.view_direction))
    
    # 3. Initialize buffers
    tau_accum = [0.0] * len(gaussians)
    t_light_buffer = [0.0] * len(gaussians)
    
    # 4. Rasterization Pass
    for i, g in enumerate(sorted_gaussians):
        # Project to light space
        pos_light = sun_camera.project(g.position)
        # Transform covariance: do NOT expand by 0.3*I, do NOT apply amplitude compensation [S1, unofficial]
        cov_light = transform_covariance_2d(g.covariance_3d, sun_camera.rotation_matrix)
        # Compute coverage and alpha
        alpha = evaluate_2d_gaussian(pos_light, cov_light, g.opacity)
        # Accumulate front tau weighted by alpha * T (energy-weighted mean over footprint) [S1, unofficial]
        T_current = math.exp(-tau_accum[i])
        tau_accum[i] += alpha * T_current
        
    # 5. Shadow Application & Pitfall Handling
    for i, g in enumerate(gaussians):
        t_light_buffer[i] = math.exp(-tau_accum[i])
        # Deeply buried Gaussians (early-termination resulting in wsum=0)
        # are explicitly mapped to full shadow to prevent inversion artifacts [S1, unofficial]
        if tau_accum[i] == 0.0:
            t_light_buffer[i] = 0.0
            
    return t_light_buffer

# Standard helper operations
def dot(v1, v2): return sum(a * b for a, b in zip(v1, v2))
def transform_covariance_2d(cov_3d, rot_mat):
    # Extract 2x2 rotation block and transform covariance
    R = rot_mat[:2, :2]
    return R @ cov_3d[:2, :2] @ R.T
def evaluate_2d_gaussian(pos, cov, opacity):
    det = cov[0][0] * cov[1][1] - cov[0][1]**2
    inv_det = 1.0 / max(det, 1e-8)
    # Standard 2D Gaussian evaluation without 0.3I expansion or amplitude compensation
    exponent = -0.5 * (pos[0]**2 * cov[1][1] * inv_det + pos[1]**2 * cov[0][0] * inv_det - 2 * pos[0] * pos[1] * cov[0][1] * inv_det)
    return opacity * math.sqrt(inv_det) * math.exp(exponent) / (2 * math.pi)
```

**Parameters:**
*   **Sun Camera FOV:** Narrow, to approximate parallel rays [S1, unofficial].
*   **Sun Camera Distance:** Large, to minimize parallax [S1, unofficial].
*   **Covariance Expansion:** None (0.0) for this pass [S1, unofficial].
*   **Amplitude Compensation:** None [S1, unofficial].
*   **Gradient Handling:** Full continuous gradients are enabled by default, including gradients for $\tau$, weights, normalization, weak density backup transmittance, and projected position/scale/rotation [S1, unofficial].

**Edge Cases:**
*   **Deep Occlusion:** If a Gaussian is deeply buried, early termination might result in $wsum=0$. Explicitly map these to full shadow ($T_{light}=0$) to avoid inversion artifacts [S1, unofficial].
*   **Gradient Propagation:** Sun camera framing, sorting, coverage, and threshold branches are treated as constants to ensure stable gradients [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [G].
*   **Memory Complexity:** Not given in the sources [G].
*   **Performance:** Provides full continuous gradients and zero expansion by default, which is more accurate than voxel fallbacks [S1, unofficial].
*   **Strengths:** Physically plausible self-shadowing, differentiable, no need for specific training parameters like voxelization [S1, unofficial].
*   **Limitations:** Requires an additional rasterization pass [G]. Sensitive to sun camera placement (parallax error) [S1, unofficial].

## Background
This method is part of the 4DGS-Volume-Cloud framework for rendering volumetric clouds with 3D Gaussian Splatting [S1, unofficial]. It enables relighting and self-shadowing, which are not possible with pure emission SH reconstruction (VPRF) [S1, unofficial]. The method was introduced in the context of training on datasets like `CloudDatasetUniform` with held-out sun directions for generalization testing [S1, unofficial]. It builds on [Shading and Lighting Models](11924-shading-and-lighting-models.md) [G].
