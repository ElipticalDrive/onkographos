# Promptable Explicit Scene Representation

Also called: Semantic Prompting

## Overview
A mechanism for 3D editing (extraction, deletion, appearance modification) in 3D Gaussian Splatting by computing activation scores of 3D Gaussians based on prompts (text, points, boxes) using cosine similarity and softmax [S1]. It differs from implicit NeRF feature fields by operating on explicit Gaussian primitives, allowing direct manipulation of color and opacity parameters for specific semantic subsets [S1].

## How it works
**Inputs:**
- A set of $N$ 3D Gaussians $\{x_i\}_{i=1}^N$, where each Gaussian $x$ has a semantic feature vector $f(x)$, color $c(x)$, and opacity $\alpha(x)$ [S1].
- A prompt $\tau$ (text, point, or box) [S1].
- For text prompts: A ViT-B/32 CLIP encoder to generate query vectors $q(\tau)$ [S1].
- A set of possible labels $\mathcal{T}$ (e.g., text labels for segmentation or pixel coordinates for point prompts) [S1].

**Outputs:**
- A "Gaussian mask" identifying Gaussians associated with the prompt [S1].
- An edited radiance field with updated $\{c_i\}$ and $\{\alpha_i\}$ for selected Gaussians, where the count $n < N$ [S1].

**Data Structures:**
- **Gaussian Feature:** Each Gaussian $x$ stores a semantic feature vector $f(x)$ [S1].
- **Query Vector:** For text, $q(\tau)$ is the CLIP text embedding [S1]. For points/boxes, $q(\tau)$ corresponds to features queried from the distilled 3D feature field [S1].

**Steps:**
1. **Encode Prompt:** For text, compute $q(\tau)$ using the CLIP ViT-B/32 encoder [S1]. For points or boxes, retrieve the corresponding feature from the distilled 3D feature field [S1].
2. **Compute Activation Score:** For each Gaussian $x$, calculate the cosine similarity between its semantic feature $f(x)$ and the query vector $q(\tau)$:
   $$ s = \frac {f(x) \cdot q(\tau )}{\|f(x)\| \|q(\tau )\|} $$
   where $s$ is the activation score [S1].
3. **Compute Probability:** If a set of labels $\mathcal{T}$ is provided, compute the probability $\mathbf {p}(\tau | x)$ using softmax over all scores $s_j \in \mathcal{T}$:
   $$ \mathbf {p}(\tau | x) = \text {softmax} (s) = \frac {\exp \left ( s \right )}{\sum _{s_j \in \mathcal {T}} \exp \left (s_j\right )} $$
   [S1].
4. **Generate Gaussian Mask:** Filter Gaussians based on the computed probabilities or scores [S1]. Two selection modes are supported [S1]:
   - **Soft Selection:** Threshold the score matrix to include Gaussians with scores above a certain value [S1].
   - **Hard Selection:** Filter based on the highest score across $K$ categories (where $K$ is the number of object categories) [S1].
5. **Edit Scene:** Update the color $c(x)$ and opacity $\alpha(x)$ of the selected Gaussians [S1].
6. **Render:** Render the edited radiance field using point-based $\alpha$-blending with the updated set $\{c_i\}_{i=1}^n$ and $\{\alpha_i\}_{i=1}^n$, where $n < N$ [S1].

**Pseudocode:**
```python
import math

def dot(a, b):
    return sum(ai * bi for ai, bi in zip(a, b))

def norm(a):
    return math.sqrt(sum(ai * ai for ai in a))

def softmax(scores):
    max_s = max(scores)
    exp_scores = [math.exp(s - max_s) for s in scores]
    sum_exp = sum(exp_scores)
    return [e / sum_exp for e in exp_scores]

def promptable_editing(gaussians, prompt, clip_encoder, labels=None, threshold=None):
    """
    gaussians: List of objects with .feature, .color, .opacity
    prompt: Text string, or (x, y) point, or (x1, y1, x2, y2) box
    clip_encoder: Callable returning feature vector for text
    labels: Optional list of text labels for softmax normalization
    threshold: Optional float for soft selection
    """
    # Step 1: Encode Prompt
    if isinstance(prompt, str):
        query_vector = clip_encoder(prompt)
    else:
        # For point/box, retrieve feature from the distilled 3D feature field
        # Not given in the sources.
        query_vector = [0.0] * len(gaussians[0].feature)

    selected_indices = []
    scores = []

    # Step 2 & 3: Compute Scores and Probabilities
    for i, g in enumerate(gaussians):
        f = g.feature
        q = query_vector

        # Step 2: Cosine similarity
        f_norm = norm(f)
        q_norm = norm(q)
        if f_norm == 0 or q_norm == 0:
            s = 0.0
        else:
            s = dot(f, q) / (f_norm * q_norm)
        scores.append(s)

        # Step 3: Softmax probability if labels provided
        prob = s
        if labels is not None:
            all_scores = []
            for label in labels:
                q_label = clip_encoder(label)
                q_label_norm = norm(q_label)
                if q_label_norm == 0:
                    all_scores.append(0.0)
                else:
                    all_scores.append(dot(f, q_label) / (f_norm * q_label_norm))
            probs = softmax(all_scores)
            try:
                idx = labels.index(prompt)
                prob = probs[idx]
            except ValueError:
                prob = 0.0

        # Step 4: Generate Mask
        is_selected = False
        if threshold is not None:
            if prob >= threshold:
                is_selected = True
        else:
            # Hard selection: highest score across K categories
            if labels is not None:
                max_prob = max(probs)
                if prob == max_prob:
                    is_selected = True

        if is_selected:
            selected_indices.append(i)

    # Step 5: Edit Scene
    # Update the color c(x) and opacity alpha(x) of the selected Gaussians
    for i in selected_indices:
        gaussians[i].opacity = 0.0  # Example for extraction [G]
        # gaussians[i].color = ...  # Example for appearance modification [G]

    # Step 6: Render
    # Render the edited radiance field using point-based alpha-blending
    # Not given in the sources.
    image = None
    return image, selected_indices
```

**Edge Cases and Pitfalls:**
- **Zero Norm:** If $f(x)$ or $q(\tau)$ has zero norm, the cosine similarity is undefined. Handle by setting score to 0 [G].
- **Distillation Dependency:** The quality of $f(x)$ depends on the teacher-student distillation process [S1].
- **NeRF Interference Avoidance:** Unlike NeRF-based feature fields where the feature branch shares layers with the radiance field (potentially causing interference), this method uses explicit Gaussian features to avoid such overlap issues [S1].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Requires storing semantic features $f(x)$ for each Gaussian, increasing memory usage compared to standard 3DGS [S1].
- **Strengths:** Enables direct 3D editing (extraction, deletion, modification) using 2D prompts (points, boxes) or text [S1]. Avoids interference from shared NeRF branches [S1].
- **Limitations:** Relies on the accuracy of the distilled feature field [S1]. Text prompts require CLIP encoding [S1]. Hard selection may be less flexible than soft thresholding [S1].

## Background
Originated in "Feature 3DGS: Supercharging 3D Gaussian Splatting to Enable Distilled Feature Fields" (CVPR 2024) [S1]. It extends 2D pixel-level promptable editing (from SAM and CLIP) into the 3D realm by distilling 2D features into a 3D feature field associated with 3D Gaussians [S1].
