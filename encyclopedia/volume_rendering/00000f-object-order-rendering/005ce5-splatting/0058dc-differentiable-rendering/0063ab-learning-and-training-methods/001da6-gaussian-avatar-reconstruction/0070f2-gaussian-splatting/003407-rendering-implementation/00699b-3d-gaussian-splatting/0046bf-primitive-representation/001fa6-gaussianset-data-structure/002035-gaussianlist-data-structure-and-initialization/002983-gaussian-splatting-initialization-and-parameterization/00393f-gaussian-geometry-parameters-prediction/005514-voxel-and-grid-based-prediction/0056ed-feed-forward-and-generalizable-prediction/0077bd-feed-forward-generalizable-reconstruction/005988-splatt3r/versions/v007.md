# Splatt3R

Also called: Splatt3R: Zero-Shot Gaussian Splatting from Uncalibrated Image Pairs

## Overview
Splatt3R is a feed-forward model that predicts 3D Gaussian Splat parameters directly from a pair of uncalibrated natural images, without requiring camera intrinsics, extrinsics, or depth information [S1, unofficial]. It solves the problem of generalizable novel view synthesis by bypassing iterative per-scene optimization, instead leveraging a pretrained foundation geometry model (MASt3R) to predict point clouds and extending it with a Gaussian head for appearance and covariance attributes [S1, unofficial]. Unlike sibling methods that typically supervise only interpolated viewpoints between input views, Splatt3R supports extrapolation to viewpoints outside the stereo baseline by employing a novel loss masking strategy based on frustum culling and covisibility testing [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A pair of uncalibrated RGB images $I = \{I_1, I_2\}$, where $I_i \in \mathbb{R}^{H \times W \times 3}$. The images have unknown camera parameters.
*   **Output:** A set of 3D Gaussian primitives $\mathcal{G}$ representing the scene geometry and appearance. Each primitive is defined by mean position $\mu$, covariance $\Sigma$, opacity $\alpha$, and color $S$.

**Data Structures:**
The method operates on a per-pixel basis. For each image, it predicts:
1.  3D point locations $\hat{X}_1, \hat{X}_2 \in \mathbb{R}^{H \times W \times 3}$ in the coordinate frame of the first image.
2.  Confidence maps $C_1, C_2 \in \mathbb{R}^{H \times W}$.
3.  Gaussian parameters for each pixel:
    *   Offsets $\Delta \in \mathbb{R}^{H \times W \times 3}$.
    *   Rotation quaternions $q \in \mathbb{R}^{H \times W \times 4}$.
    *   Scales $s \in \mathbb{R}^{H \times W \times 3}$.
    *   Opacities $\alpha \in \mathbb{R}^{H \times W}$.
    *   Spherical Harmonics coefficients $S \in \mathbb{R}^{H \times W \times 3 \times d}$ (or constant color $S \in \mathbb{R}^{H \times W \times 3}$).

**Numbered Steps:**

1.  **Feature Encoding:** Encode the two input images $I_1$ and $I_2$ using a shared Vision Transformer (ViT) encoder and cross-attention transformers. These components are based on the MASt3R architecture and are frozen during training [S1, unofficial].
2.  **Point Cloud Prediction:** Use the frozen MASt3R backbone to predict 3D point locations $\hat{X}_1, \hat{X}_2$ and confidence maps $C_1, C_2$ for both images. The points are predicted in the coordinate frame of the first image $I_1$ [S1, unofficial].
3.  **Gaussian Parameter Prediction:** Pass the encoded features through a parallel "Gaussian head" (using a DPT architecture) to predict the residual offsets $\Delta$, rotations $q$, scales $s$, opacities $\alpha$, and spherical harmonics $S$ for each pixel [S1, unofficial].
4.  **Parameter Activation:** Apply specific activation functions to ensure valid parameter ranges:
    *   Normalization for quaternions $q$.
    *   Exponential activation for scales $s$ and offsets $\Delta$.
    *   Sigmoid activation for opacities $\alpha$.
    *   [G] For spherical harmonics, if used, coefficients are typically output directly or with a linear activation, as they represent view-dependent color variations. The source notes constant view-independent color $S \in \mathbb{R}^3$ was used in primary experiments [S1, unofficial].
5.  **Construct Gaussian Primitives:** For each pixel, compute the final Gaussian parameters:
    *   Mean position: $\mu = \hat{x} + \Delta$, where $\hat{x}$ is the predicted 3D point from Step 2.
    *   Covariance matrix: $\Sigma = R(q) S(s) S(s)^T R(q)^T$, where $R(q)$ is the rotation matrix derived from quaternion $q$, and $S(s)$ is the diagonal scaling matrix from vector $s$. This ensures $\Sigma$ is positive semi-definite [S1, unofficial].
    *   The final set of Gaussian primitives is the union of the primitives predicted from both input images $I_1$ and $I_2$ [S1, unofficial].
6.  **Differentiable Rendering:** Render the predicted Gaussian set into target views using a differentiable rasterizer (e.g., Gaussian Splatting rasterizer) to produce rendered images $\hat{I}$ [S1, unofficial].
7.  **Loss Masking (Training Only):** Calculate a binary loss mask $M$ to restrict supervision to feasibly reconstructed regions:
    *   Unproject target image points to 3D.
    *   Reproject these 3D points onto the context images ($I_1, I_2$).
    *   A pixel is marked valid (included in $M$) if:
        1.  It is inside the frustum of at least one context image.
        2.  The reprojected depth matches the ground truth depth within a tolerance.
        3.  The pixel has valid depth in the dataset [S1, unofficial].
8.  **Loss Calculation:** Compute the total loss $L$ using the mask $M$:
    $$ L = \lambda_{MSE} L_{MSE}(M \odot \hat{I}, M \odot I) + \lambda_{LPIPS} L_{LPIPS}(M \odot \hat{I}, M \odot I) $$
    where $L_{MSE}$ is Mean Squared Error and $L_{LPIPS}$ is Learned Perceptual Image Patch Similarity [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def normalize_quaternion(q):
    """Normalize quaternion to unit length."""
    return F.normalize(q, p=2, dim=-1)

def quaternion_to_rotation_matrix(q):
    """Convert quaternion to 3x3 rotation matrix.
    q shape: (..., 4)
    Returns shape: (..., 3, 3)
    """
    # Standard conversion from quaternion to rotation matrix
    # q = [w, x, y, z]
    w, x, y, z = q[..., 0:1], q[..., 1:2], q[..., 2:3], q[..., 3:4]
    N = w*w + x*x + y*y + z*z
    w, x, y, z = w/N, x/N, y/N, z/N
    
    xx, yy, zz = x*x, y*y, z*z
    xy, xz, yz = x*y, x*z, y*z
    wx, wy, wz = w*x, w*y, w*z
    
    R = torch.stack([
        1 - 2*(yy + zz), 2*(xy - wz),     2*(xz + wy),
        2*(xy + wz),     1 - 2*(xx + zz), 2*(yz - wx),
        2*(xz - wy),     2*(yz + wx),     1 - 2*(xx + yy)
    ], dim=-1).reshape(*q.shape[:-1], 3, 3)
    return R

def splatt3r_forward(images, gaussian_head, masts3r_backbone):
    """
    images: tuple of (I1, I2), each (B, 3, H, W)
    Returns: Gaussian primitives (mu, sigma, alpha, color)
    """
    # 1. Encode images using frozen MASt3R backbone
    # masts3r_backbone includes ViT encoder and cross-attention
    features = masts3r_backbone.encode(images)
    
    # 2. Predict 3D points and confidences (frozen)
    # Returns X_hat_1, X_hat_2 in frame of I1
    X_hat_1, C_1 = masts3r_backbone.predict_points(images[0], features)
    X_hat_2, C_2 = masts3r_backbone.predict_points(images[1], features)
    
    # 3. Predict Gaussian parameters using Gaussian Head (DPT)
    # Inputs: features from both images
    offsets_1, q_1, s_1, alpha_1, S_1 = gaussian_head(images[0], features)
    offsets_2, q_2, s_2, alpha_2, S_2 = gaussian_head(images[1], features)
    
    # 4. Apply activations
    offsets_1 = torch.exp(offsets_1)
    s_1 = torch.exp(s_1)
    alpha_1 = torch.sigmoid(alpha_1)
    q_1 = normalize_quaternion(q_1)
    
    offsets_2 = torch.exp(offsets_2)
    s_2 = torch.exp(s_2)
    alpha_2 = torch.sigmoid(alpha_2)
    q_2 = normalize_quaternion(q_2)
    
    # 5. Construct Gaussians
    # Mean: mu = x + delta
    mu_1 = X_hat_1 + offsets_1
    mu_2 = X_hat_2 + offsets_2
    
    # Covariance: Sigma = R(q) S(s) S(s)^T R(q)^T
    R_1 = quaternion_to_rotation_matrix(q_1)
    S_mat_1 = torch.diag_embed(s_1) # (B, H, W, 3, 3)
    Sigma_1 = R_1 @ S_mat_1 @ S_mat_1.transpose(-2, -1) @ R_1.transpose(-2, -1)
    
    R_2 = quaternion_to_rotation_matrix(q_2)
    S_mat_2 = torch.diag_embed(s_2)
    Sigma_2 = R_2 @ S_mat_2 @ S_mat_2.transpose(-2, -1) @ R_2.transpose(-2, -1)
    
    # Color: S (constant view-independent in experiments)
    color_1 = S_1
    color_2 = S_2
    
    # 6. Union of primitives
    # Combine parameters from both images
    mu = torch.cat([mu_1, mu_2], dim=0)
    Sigma = torch.cat([Sigma_1, Sigma_2], dim=0)
    alpha = torch.cat([alpha_1, alpha_2], dim=0)
    color = torch.cat([color_1, color_2], dim=0)
    
    return mu, Sigma, alpha, color

def compute_loss_mask(target_depth, target_pose, context_depths, context_poses, H, W):
    """
    Compute loss mask M for target view.
    target_depth: (B, H, W)
    target_pose: (B, 4, 4)
    context_depths: list of (B, H, W)
    context_poses: list of (B, 4, 4)
    Returns: M (B, H, W) binary mask
    """
    B, H, W = target_depth.shape
    M = torch.zeros_like(target_depth, dtype=torch.bool)
    
    # Unproject target points to 3D
    # Assuming standard pinhole camera model with known intrinsics for masking
    # (Intrinsics are not needed for prediction but for masking during training)
    # This is a placeholder for the specific unprojection logic
    points_3d = unproject_points(target_depth, target_pose) # (B, H, W, 3)
    
    for depth, pose in zip(context_depths, context_poses):
        # Reproject to context view
        points_2d, z_context = project_points(points_3d, pose) # (B, H, W, 2), (B, H, W)
        
        # Check frustum (valid coordinates)
        valid_frustum = (points_2d[..., 0] >= 0) & (points_2d[..., 0] < W) & \
                        (points_2d[..., 1] >= 0) & (points_2d[..., 1] < H)
        
        # Check depth consistency
        # Sample depth from context depth map at projected coordinates
        context_depth_vals = bilinear_sample(depth, points_2d) # (B, H, W)
        
        # Match depth (allow tolerance)
        depth_match = torch.abs(context_depth_vals - z_context) < 0.05 # Example tolerance
        
        # Combine conditions
        valid_pixels = valid_frustum & depth_match
        
        # Union with existing mask
        M = M | valid_pixels
        
    return M

def train_step(images, target_images, target_depths, target_poses, 
               gaussian_head, masts3r_backbone, lambda_mse, lambda_lpips):
    """
    Single training step.
    """
    # Forward pass to get Gaussians
    mu, Sigma, alpha, color = splatt3r_forward(images, gaussian_head, masts3r_backbone)
    
    # Render target views
    rendered_images = render_gaussians(mu, Sigma, alpha, color, target_poses)
    
    # Compute loss mask
    M = compute_loss_mask(target_depths, target_poses, 
                          [masts3r_backbone.get_context_depths()], 
                          [masts3r_backbone.get_context_poses()])
    
    # Compute losses
    masked_rendered = rendered_images * M
    masked_target = target_images * M
    
    loss_mse = F.mse_loss(masked_rendered, masked_target)
    loss_lpips = lpips_loss(masked_rendered, masked_target)
    
    total_loss = lambda_mse * loss_mse + lambda_lpips * loss_lpips
    
    return total_loss
```

**Parameters:**
*   **Input Resolution:** 512 × 512 pixels [S1, unofficial].
*   **Training Dataset:** ScanNet++ [S1, unofficial].
*   **Color Parameterization:** Constant, view-independent color $S \in \mathbb{R}^3$ is used in primary experiments. View-dependent spherical harmonics are ablated but supported [S1, unofficial].
*   **Overlap Thresholds:** Hyperparameters $\phi$ and $\psi$ control the selection of context and target images during training.
    *   $\phi$: Minimum percentage of pixels in the second context image with correspondences in the first.
    *   $\psi$: Minimum percentage of pixels in the target image present in at least one context image.
    *   Typical values: Close (0.9, 0.9), Medium (0.7, 0.7), Wide (0.5, 0.5), Very Wide (0.3, 0.3) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Supervising Unseen Regions:** Supervising rendering loss for pixels not visible in context views (obscured or outside frustums) is counterproductive and can destroy model performance. This is addressed by the loss masking strategy [S1, unofficial].
*   **Local Minima:** Unlike methods that predict depth distributions, Splatt3R directly supervises positions using ground-truth point clouds, providing a direct path of monotonically decreasing loss to the correct position, avoiding local minima common in optimizing 3D Gaussians from stereo views [S1, unofficial].
*   **Uncalibrated Input:** The method does not require camera intrinsics or extrinsics for inference, but these are required during training to compute the loss mask [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Inference is a single forward pass, making it $O(1)$ with respect to scene complexity (dependent on image resolution). The model runs at 4 FPS for 512 × 512 resolution [S1, unofficial].
*   **Memory Complexity:** Memory usage is proportional to the number of pixels in the input images, as it predicts per-pixel Gaussians. The union of Gaussians from two images doubles the count compared to a single image [S1, unofficial].
*   **Performance:** On ScanNet++ test scenes, Splatt3R achieves PSNR 19.66, SSIM 0.757, LPIPS 0.234 for Close view overlap ($\phi=0.9, \psi=0.9$) [S1, unofficial].
*   **Strengths:**
    *   Pose-free: No camera parameters required.
    *   Generalizable: Trained on large datasets, works on unseen scenes.
    *   Extrapolation: Can render views outside the stereo baseline, unlike many siblings [S1, unofficial].
*   **Limitations:**
    *   Per-pixel Gaussians can be dense and memory-intensive compared to sparse representations.
    *   Performance may degrade in regions with poor overlap or large baselines if the loss mask excludes too much supervision [S1, unofficial].

## Background
Splatt3R was introduced in 2024 by Brandon, Zheng, Iro, and Victor from the University of Oxford [S1, unofficial]. It builds upon the MASt3R architecture, a foundation model for 3D geometry reconstruction from uncalibrated image pairs. The method was developed to address the limitations of existing generalizable 3D-GS methods that rely on iterative optimization or require calibrated inputs. By extending MASt3R with a Gaussian head and a novel loss masking strategy, Splatt3R enables zero-shot, feed-forward 3D reconstruction and novel view synthesis from in-the-wild images [S1, unofficial].
