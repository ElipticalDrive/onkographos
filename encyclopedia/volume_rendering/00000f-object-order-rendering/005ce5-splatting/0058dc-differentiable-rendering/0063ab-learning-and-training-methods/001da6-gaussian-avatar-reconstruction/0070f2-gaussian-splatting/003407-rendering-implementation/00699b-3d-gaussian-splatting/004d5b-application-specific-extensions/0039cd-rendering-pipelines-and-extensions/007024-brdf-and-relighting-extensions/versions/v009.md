# BRDF and Relighting Extensions

Also called: Physically-based 3D Gaussian Splatting, Relightable 3D Gaussian, Inverse Rendering with Gaussians

## Overview
BRDF and Relighting Extensions extend 3D Gaussian Splatting [3D Gaussian Splatting](3D-gaussian-splatting.md) by replacing the standard view-dependent emission-absorption model with physically based rendering (PBR) parameters, enabling dynamic relighting and accurate specular shading synthesis [S1, unofficial]. Unlike standard 3DGS, which bakes lighting conditions into spherical harmonics coefficients and fails on highly reflective surfaces, these methods decompose geometry, material, and lighting [S1, unofficial]. They are distinguished from sibling methods like [GaussianShader](8013-gaussianshader-material-model.md) by their specific strategies for embedding incident lighting and material properties, such as using precomputed visibility or split-sum approximations for indirect light [S1, S2, unofficial].

## How it works
The method retains the core 3D Gaussian primitive representation $\mathcal{G} = \{G_i\}_{i=1}^M$ [G]. Each kernel $G_i$ is defined by position $\mathbf{p}_i$, rotation $\mathbf{R}_i$, scale $\mathbf{S}_i$, and covariance $\mathbf{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^\top \mathbf{R}_i^\top$ [G]. The geometric projection computes the 2D covariance $\mathbf{\hat{\Sigma}}_i$ using the Jacobian $J$ and extrinsic rotation $W$ [G].

### Inputs and Outputs
*   **Inputs:** Multi-view images of a scene; optionally, ground-truth physical attributes (albedo, roughness, normals) if available [S1, unofficial].
*   **Outputs:** A set of Gaussians with PBR attributes (base color, metalness, roughness, normal) and an environment light map or SH coefficients for indirect illumination [S2, unofficial]. Rendered images under novel lighting conditions.

### Data Structures
Each Gaussian $G_i$ stores:
*   $\mathbf{p}_i \in \mathbb{R}^3$: Position [G].
*   $\mathbf{R}_i \in \mathbb{R}^{3 \times 3}$: Rotation [G].
*   $\mathbf{S}_i \in \mathbb{R}^{3 \times 3}$: Scale [G].
*   $\mathbf{c}_{base, i} \in \mathbb{R}^3$: Base color (albedo) [S2, unofficial].
*   $m_i \in [0, 1]$: Metalness [S2, unofficial].
*   $r_i \in [0.09, 1]$: Roughness [S2, unofficial].
*   $\mathbf{n}_i \in \mathbb{R}^3$: Surface normal [S1, S2, unofficial].
*   $\mathbf{L}_{indirect, i}$: Indirect illumination coefficients (e.g., SH) [S2, unofficial].

### Rendering Steps
1.  **Projection:** Transform 3D Gaussians to camera space. Compute projected 2D covariance $\mathbf{\hat{\Sigma}}_i$ [G].
2.  **Rasterization:** Sort Gaussians by depth. Project to screen space and compute coverage [G].
3.  **Attribute Retrieval:** For each pixel covered by a Gaussian, retrieve $\mathbf{c}_{base}$, $m$, $r$, and $\mathbf{n}$ [S2, unofficial].
4.  **BRDF Evaluation:**
    *   If physical attributes are available, use a simplified Disney principle-based BRDF model [S1, unofficial].
    *   Calculate Normal Distribution Function (NDF), Fresnel term, and Geometry term using Neilf's formula [S1, unofficial].
    *   If physical attributes are lacking, use MLPs or LSTMs to regress BRDF as a light reflection weight based on incident and reflected light energy distribution [S1, unofficial].
5.  **Lighting Integration:**
    *   Compute direct lighting using the environment map and surface normal [S2, unofficial].
    *   Compute indirect lighting using precomputed visibility and SH coefficients [S2, S1, unofficial].
    *   Combine diffuse and specular components.
6.  **Compositing:** Alpha composite the resulting colors along the ray [G].

### Training Steps (Phys3DGS Pipeline)
1.  **Stage 1:** Optimize standard 3DGS geometry and view-dependent color [S2, unofficial].
2.  **Stage 2:** Train PBR parameters (albedo, metalness, roughness, indirect SH) using a deferred rendering pipeline [S2, unofficial].
    *   **Light Sampling:** Use Fibonacci sampling for random incoming light during training [S2, unofficial]. For relighting evaluation, use Multiple Importance Sampling (MIS) with equal light importance and GGX importance rays [S2, unofficial].
    *   **Loss:** Apply bilateral smoothness loss to BRDF parameters [S2, unofficial].
    *   **Constraints:** Clamp base color and metalness to $[0, 1]$. Scale roughness to $[0.09, 1]$ to prevent excessively strong specular reflectance [S2, unofficial].
3.  **Denoising:** Apply a non-parametric bilateral denoiser to handle low samples per point (spp) [S2, unofficial].

### Pseudocode
```python
def render_gaussian_pbr(gaussians, camera, light_env):
    """
    Renders a scene using PBR 3D Gaussians.
    gaussians: List of Gaussian objects with attributes (p, R, S, c_base, m, r, n, L_indirect)
    camera: Camera object with projection matrix and view matrix
    light_env: Environment map or SH coefficients for lighting
    """
    image = zeros_like(screen_resolution)
    
    # 1. Project and Sort
    projected_gaussians = []
    for g in gaussians:
        # Compute 2D covariance using Jacobian J and extrinsic W [G]
        Sigma_3d = g.R @ g.S @ g.S.T @ g.R.T
        Sigma_2d = J @ W @ Sigma_3d @ W.T @ J.T
        
        # Project mean position
        p_2d = project(g.p, camera)
        
        projected_gaussians.append({
            'p_2d': p_2d,
            'Sigma_2d': Sigma_2d,
            'depth': g.p.z,
            'c_base': g.c_base,
            'm': g.m,
            'r': g.r,
            'n': g.n,
            'L_indirect': g.L_indirect
        })
    
    projected_gaussians.sort(key=lambda x: x['depth'])
    
    # 2. Rasterize and Composite
    for g_proj in projected_gaussians:
        # Compute coverage and alpha
        alpha = compute_gaussian_alpha(g_proj['Sigma_2d'], g_proj['p_2d'])
        if alpha < threshold: continue
        
        # Retrieve BRDF parameters
        base_color = g_proj['c_base']
        metalness = g_proj['m']
        roughness = g_proj['r']
        normal = g_proj['n']
        
        # 3. Evaluate BRDF
        # Direct Lighting
        light_dir = sample_light_direction(light_env) # Fibonacci or MIS
        radiance_direct = evaluate_brdf(base_color, metalness, roughness, normal, light_dir)
        
        # Indirect Lighting
        radiance_indirect = evaluate_indirect_light(normal, g_proj['L_indirect'])
        
        # Composite
        color = radiance_direct + radiance_indirect
        image = composite_pixel(image, color, alpha)
        
    return image

def evaluate_brdf(base_color, metalness, roughness, normal, light_dir):
    """
    Evaluates Disney-style BRDF using Neilf's formula components [S1, unofficial].
    """
    # Calculate NDF (Normal Distribution Function)
    ndf = ggx_ndf(normal, light_dir, roughness)
    
    # Calculate Fresnel term
    fresnel = schlick_fresnel(metalness, normal, light_dir)
    
    # Calculate Geometry term
    geometry = smith_geometry(normal, light_dir, roughness)
    
    # Combine
    # Simplified Disney model
    diffuse = base_color * (1.0 - metalness)
    specular = fresnel * ndf * geometry / (4.0 * dot(normal, light_dir) * dot(normal, view_dir) + epsilon)
    
    return diffuse + specular
```

### Parameters
*   **Roughness Range:** $[0.09, 1]$ [S2, unofficial].
*   **Samples per Pixel (spp):** 64 spp with denoiser for real-time rendering; 1,024 spp for comparison with voxel-based methods [S2, unofficial].
*   **Training Steps:** 10k steps for PBR training [S2, unofficial].

### Edge Cases and Pitfalls
*   **Highlight Loss:** Direct training of reflection weights without physical constraints may lead to loss of highlight information [S1, unofficial]. Mitigate by applying a brightening operation to training images: multiply pixels with gray values surpassing a threshold by a brightness coefficient [S1, unofficial].
*   **Degenerate Geometry:** Imperfect surface mesh quality and large gradients in HDR space can cause dramatic position shifts of vertices, impairing visibility [S2, unofficial].
*   **Specular Strength:** Unconstrained roughness can lead to exceedingly strong specular reflectance. Clamp roughness to $[0.09, 1]$ [S2, unofficial].

## Subtopics

### [3D Gaussian Splatting with BRDF Embedding](1174-3d-gaussian-splatting-with-brdf-embedding.md)
Extends 3DGS by embedding physically based rendering parameters into each Gaussian primitive, enabling per-point BRDF evaluation and dynamic relighting. It addresses the limitation of standard 3DGS, which uses an emission-absorption model that bakes lighting conditions into spherical harmonics coefficients, thereby limiting performance on highly reflective surfaces and preventing relighting. It is distinguished from sibling methods like [GaussianShader](8013-gaussianshader-material-model.md) by its specific embedding of incident lighting alongside material properties.

### [3D Gaussian Splatting with Reflection and Relighting](5873-3d-gaussian-splatting-with-reflection-and-relighting.md)
Extends 3DGS by incorporating classical PBR concepts to address limitations with highly reflective surfaces and enable relighting under novel illumination. Unlike standard 3DGS, which bakes lighting into spherical harmonics via an emission-absorption model, this approach decomposes geometry, material, and lighting, allowing for dynamic specular shading synthesis. It distinguishes itself from NeRF-based PBR methods by leveraging the Gaussian kernel’s natural normal estimation, avoiding the time-consuming training and slow rendering speeds associated with gradient-based normal estimation in volumetric representations.

### [Relightable 3D Gaussian](6001-relightable-3d-gaussian.md)
Extends 3D Gaussian Splatting to support dynamic lighting and physically-based materials by assigning per-Gaussian BRDF parameters and precomputed visibility for shadows. It differs from standard 3D Gaussian Splatting by enabling relighting capabilities, setting it apart from siblings like [3D Gaussian Splatting with BRDF Embedding](1174-3d-gaussian-splatting-with-brdf-embedding.md) which may use different embedding strategies, and [Inverse Rendering with Gaussians (GS-IR / GIR)](6153-inverse-rendering-with-gaussians-gs-ir-gir.md) which focuses on inverse rendering with split-sum approximations.

### [Inverse Rendering with Gaussians (GS-IR / GIR)](6153-inverse-rendering-with-gaussians-gs-ir-gir.md)
Employs 3D Gaussian Splatting inverse rendering techniques to accurately estimate details such as material properties and lighting conditions. It solves the problem of recovering physically plausible scene parameters (geometry, BRDF, illumination) from images by jointly optimizing Gaussian geometry and an environment light probe. What sets it apart from its siblings is its use of a split-sum approximation to handle indirect light, allowing it to model inter-reflections more accurately than methods relying solely on simplified direct-light equations or learned light approximations.

### [GaussianShader Material Model](8013-gaussianshader-material-model.md)
Enhances 3D Gaussian Splatting (3DGS) by incorporating trainable material parameters—diffuse color, specular intensity, roughness, and surface normal—alongside a global environment map to enable physically-based rendering (PBR). It distinguishes itself from standard 3DGS by binding these material properties directly to the Gaussian kernels, allowing for the accurate modeling of specular reflections and complex lighting interactions that standard opacity-based splatting cannot capture.

### [BRDF-SMAE](12538-brdf-smae.md)
A method for spatially varying BRDF decomposition in neural volumes, where a single BRDF embedding is stored at each point to enable spatially varying material representation. It differs from standard neural volume rendering by explicitly encoding material properties via an auto-encoder structure rather than implicit color or density fields, allowing for disentangled material analysis. It builds on [BRDF Decoder Strategies](8147-brdf-decoder-strategies.md).

### Deferred Rendering Pipeline for Phys3DGS
A rendering pipeline used to train PBR parameters, involving multiple importance sampling for light rays and post-processing denoising [S2, unofficial].
*   **Light Sampling:** Use Fibonacci sampling for random incoming light sampling during training. For relighting, adopt NVDiffrecMC’s multiple importance sampling by casting an equal amount of light importance rays and GGX importance rays [S2, unofficial].
*   **Denoising:** Apply a non-parametric bilateral denoiser to the PBR result to cope with low samples per point (spp), enabling real-time rendering [S2, unofficial].
*   **Parameter:** 64 spp used for real-time rendering with denoiser, compared to 1,024 spp for voxel grid-based methods [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering is real-time compatible with low samples per pixel (64 spp) when combined with denoising [S2, unofficial]. Training takes approximately 30 minutes for 10k steps on a single NVIDIA RTX 4090 [S2, unofficial].
*   **Memory Complexity:** Higher than standard 3DGS due to additional per-Gaussian attributes (albedo, metalness, roughness, normal, indirect SH) [S2, unofficial].
*   **Performance:** Outperforms voxel grid-based methods in complex geometry scenes (e.g., Ficus) with higher PSNR (24.296 vs 29.124 to 31.927) [S2, unofficial].
*   **Strengths:** Enables dynamic relighting, accurate specular reflections, and physically plausible material representation [S1, unofficial].
*   **Limitations:** Sensitive to mesh quality; imperfect geometry can lead to degenerate cases during PBR training [S2, unofficial]. Direct training of reflection weights may lose highlight information without mitigation [S1, unofficial].

## Background
Originating from the need to overcome the limitations of standard 3D Gaussian Splatting's emission-absorption model, which bakes lighting into spherical harmonics and fails on reflective surfaces [S1, unofficial], these extensions integrate PBR principles into the Gaussian representation [S2, unofficial]. The Phys3DGS method [S2, unofficial] and STensoRRF [S1, unofficial] represent key developments in applying inverse rendering and BRDF embedding to 3D Gaussians, leveraging the efficiency of splatting while maintaining physical accuracy.
