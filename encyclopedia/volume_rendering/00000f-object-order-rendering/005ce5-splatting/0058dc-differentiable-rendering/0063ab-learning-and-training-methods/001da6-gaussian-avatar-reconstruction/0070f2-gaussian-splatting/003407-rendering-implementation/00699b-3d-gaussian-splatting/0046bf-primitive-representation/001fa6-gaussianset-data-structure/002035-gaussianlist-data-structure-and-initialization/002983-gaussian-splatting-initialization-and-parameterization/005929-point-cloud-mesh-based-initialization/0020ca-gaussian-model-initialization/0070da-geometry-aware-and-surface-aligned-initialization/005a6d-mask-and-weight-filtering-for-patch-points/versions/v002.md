# Mask and Weight Filtering for Patch Points

Also called: $w_j$ and $\eta_j$ filtering, $w_j$ and $η_j$ filtering

## Overview
This method refines geometric constraints applied to surface patch points during Signed Distance Field (SDF) optimization by filtering outliers and prioritizing critical surface locations [S1]. It addresses noisy or degenerate sampled points on a local surface patch that degrade reconstructed geometry accuracy [S1]. Unlike the parent method, which samples points around a 3D anchor, this technique modifies the loss calculation by applying a binary mask $w_j$ to exclude outliers and a scalar weight $\eta_j$ to emphasize points with strong gradient alignment to the ground truth normal [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   $q$: The 3D anchor point $[x, y, z]$ [S1].
    *   $J$: The number of sampled points on the patch [S1].
    *   $p'_j$: The $j$-th pulled point on the zero level set, derived from $q$ [S1].
    *   $f_\theta$: The SDF function parameterized by $\theta$ [S1].
    *   $e(q)$: The eye position or camera pose associated with point $q$ [S1].
    *   $\nabla f_\theta(p'_j, e(p'_j))$: The gradient of the SDF at the pulled point [S1].
    *   $N^k_{GT}(r)$: The ground truth normal at pixel $r$ corresponding to the view [S1].
*   **Outputs:**
    *   $w_j$: A binary mask value for each point $j \in [1, J]$ [S1].
    *   $\eta_j$: A scalar weight value for each point $j \in [1, J]$ [S1].

**Data Structures**
*   The mask $w$ is a vector of size $J$ with binary values $\{0, 1\}$ [S1].
*   The weight $\eta$ is a vector of size $J$ with scalar values in $[0, 1]$ derived from cosine similarity [S1].

**Steps**
1.  **Pull Points to Zero Level Set:** For each anchor point $q$, compute the pulled point $p'_j$ on the zero level set of the SDF using the signed distance and gradient [S1]:
    $$ p'_j = q - f_\theta(q, e(q)) \frac{\nabla f_\theta(q, e(q))}{\|\nabla f_\theta(q, e(q))\|} $$
    The calculation of $\nabla f_\theta(p'_j, e(p'_j))$ involves second-order derivatives due to the dependency of $p'_j$, which helps the network find better solutions [S1].
2.  **Compute Weight $\eta_j$:** Calculate the cosine similarity between the SDF gradient at the pulled point and the ground truth normal to determine point importance [S1]:
    $$ \eta_j = \cos(\nabla f_\theta(p'_j, e(p'_j)), N^k_{GT}(r)) $$
    This weight focuses the network on points where the gradient is well-aligned with the surface normal [S1].
3.  **Compute Mask $w_j$:** Apply a binary mask to rule out outlier points during the pulling step [S1]. The exact thresholding logic is not provided in the sources [S1].
4.  **Apply to Loss Function:** Use $w_j$ and $\eta_j$ to modulate the surface fitting loss or other constraints [S1]. Points with $w_j=0$ are excluded, and points with higher $\eta_j$ contribute more significantly to the optimization [S1].

**Pseudocode**
```python
import math

def compute_mask_and_weight(p_prime_j, f_theta, e_q, N_GT):
    """
    Computes the mask w_j and weight eta_j for a single pulled point p'_j.
    Args:
        p_prime_j: 3D pulled point on the zero level set.
        f_theta: SDF function returning signed distance.
        e_q: Eye position/camera pose.
        N_GT: Ground truth normal at the corresponding pixel.
    Returns:
        w: Binary mask value.
        eta: Scalar weight value.
    """
    # Compute gradient at pulled point (involves second-order derivatives)
    grad_p_prime = [0.0, 0.0, 0.0]
    for k in range(3):
        eps = 1e-5
        pp_p = list(p_prime_j); pp_p[k] += eps
        pp_m = list(p_prime_j); pp_m[k] -= eps
        grad_p_prime[k] = (f_theta(pp_p, e_q) - f_theta(pp_m, e_q)) / (2 * eps)

    # Compute weight eta_j
    dot_val = sum(grad_p_prime[k] * N_GT[k] for k in range(3))
    norm_grad_pp = math.sqrt(sum(g**2 for g in grad_p_prime))
    norm_N = math.sqrt(sum(n**2 for n in N_GT))
    cos_sim = dot_val / (norm_grad_pp * norm_N) if (norm_grad_pp * norm_N) != 0 else 0.0
    eta = cos_sim

    # Compute mask w_j
    # The source states w_j rules out outliers but does not provide the exact thresholding rule.
    w = 1.0

    return w, eta
```

**Parameters**
*   $J$: Number of sampled points. The source indicates performance varies with $J$ (Table 5 in [S1]), but the optimal value is not explicitly stated in the notes, only that it affects performance [S1].
*   $\lambda_1 \dots \lambda_6$: Weights for the total loss function $L = L_{RGB} + \lambda_1 L_{DR} + \lambda_2 L_N + \lambda_3 L_{Eik} + \lambda_4 L_{DC} + \lambda_5 L_{NCC} + \lambda_6 L_{Fit}$ [S1]. The mask and weight specifically modulate the surface fitting or normal-related terms [S1].

**Edge Cases and Pitfalls**
*   Removing $w_j$ degrades performance due to unfiltered outliers [S1].
*   Removing $\eta_j$ degrades performance due to lack of focus on critical surface points [S1].
*   The calculation of $\nabla f_\theta(p'_j, e(p'_j))$ involves second-order derivatives, which can be computationally expensive or numerically unstable if not handled carefully [S1].

## Subtopics

### Pulling Mechanism for Zero Level Set Alignment
This variant refers to the specific geometric operation of moving points from a $d$-level set to the zero level set of the SDF [S1]. It sets itself apart by explicitly using the SDF gradient and signed distance to enforce surface constraints on the pulled points $p'_j$ rather than the original anchor $q$ [S1]. It should be chosen when explicit surface alignment is required to improve geometry accuracy [S1]. The formula is $p'_j = q - f_\theta(q, e(q)) \frac{\nabla f_\theta(q, e(q))}{\|\nabla f_\theta(q, e(q))\|}$ [S1]. Disabling this mechanism (imposing constraints directly on $q$) results in lower accuracy (F-score 0.753 vs 0.794 on Replica) [S1].

## Operating characteristics
**Time and Memory Complexity**
*   The method adds computational overhead due to the calculation of gradients at pulled points, which involves second-order derivatives [S1].
*   Memory usage increases slightly to store the mask $w$ and weight $\eta$ vectors for each patch [S1].

**Measured Performance**
*   On the Replica dataset, the full method yields Acc=0.037, Comp=0.038, CD-L1=0.037, Prec=0.797, Recall=0.777, F-score=0.794 [S1].
*   Removing $w_j$ ('No $w_j$') yields Acc=0.039, Comp=0.041, CD-L1=0.038, Prec=0.764, Recall=0.790, F-score=0.772 [S1].
*   Removing $\eta_j$ ('No $\eta_j$') yields Acc=0.039, Comp=0.042, CD-L1=0.038, Prec=0.733, Recall=0.772, F-score=0.753 [S1].
*   Disabling pulling ('No pulling') yields Acc=0.039, Comp=0.042, CD-L1=0.038, Prec=0.733, Recall=0.772, F-score=0.753 [S1].

**Strengths and Limitations**
*   **Strengths:** Improves accuracy by filtering outliers and focusing on geometrically consistent points. Enhances the capture of finer geometry details [S1].
*   **Limitations:** Requires the computation of second-order derivatives, which may be costly. The specific thresholding logic for the mask $w_j$ is not provided, making implementation dependent on heuristic choices [S1].

**When to Use**
*   Use when high-fidelity surface reconstruction is required and the SDF is being optimized with multi-view constraints [S1].
*   Use when the sampled points on the patch are prone to outliers or noise [S1].

**When Not to Use**
*   Use with caution if computational resources are limited due to the second-order derivative calculation [S1].
*   Do not use if the ground truth normals are unreliable, as $\eta_j$ depends on $N^k_{GT}(r)$ [S1].

## Background
This method was proposed in the paper "Sensing Surface Patches in Volume Rendering for Inferring Signed Distance Functions" by Ma et al. [S1]. It builds upon the concept of using SDFs to define local patches around ray-surface intersections, enabling explicit surface constraints in volume rendering [S1]. The method leverages the gradient and signed distance characteristics of SDFs to pull points onto the zero level set, enhancing accuracy and capturing finer geometry details [S1]. It is part of a broader effort to infer SDFs from multi-view images via volume rendering [S1].
