# 3iGS (Factorised Tensorial Illumination for 3D Gaussian Splatting)


## Overview
3iGS enhances 3D Gaussian Splatting by modeling outgoing radiance as a function of a continuous local illumination field and individual Gaussian BRDF attributes, rather than optimizing radiance in isolation [S1]. It differs from siblings like [DAVIGS](12021-davigs.md) and [SWAG](14315-swag-splatting-in-the-wild-images-with-appearance-conditione.md) by explicitly separating scene lighting (via a factorized tensor grid) from material properties (via BRDF features) to accurately capture specular view-dependent effects [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 3D Gaussians (initialized from SfM points or random), camera poses, and training images.
*   **Outputs:** Rendered pixel colors $\hat{\mathbf{C}}$ and optimized parameters for Gaussians and the illumination field.

**Data Structures:**
1.  **3D Gaussians:** Each Gaussian $i$ stores:
    *   Mean position $\boldsymbol{\mu}_i \in \mathbb{R}^3$.
    *   Opacity $\alpha_i \in \mathbb{R}$.
    *   Scaling matrix $\mathbf{S}_i \in \mathbb{R}^{3 \times 3}$ (diagonal) and Rotation matrix $\mathbf{R}_i \in \mathbb{R}^{3 \times 3}$ (orthogonal, represented as quaternion or rotation matrix).
    *   Diffuse color $\mathbf{c}_{d,i} \in \mathbb{R}^3$.
    *   BRDF features $\boldsymbol{\rho}_i$: Repurposed 16 SH coefficients (48 values) plus 4 additional parameters for base color and roughness [S1].
2.  **Illumination Grid $\mathcal{G}_l$:** A factorized tensor grid representing the continuous local illumination field.
    *   Resolution: Coarse grid of $150^3$ voxels [S1].
    *   Structure: Vector-Matrix spatial factorization with $R_L$ feature channels [S1].
    *   Parameters: Feature tensors $\mathbf{A}_{L,r}^X, \mathbf{A}_{L,r}^Y, \mathbf{A}_{L,r}^Z$ and feature vectors $\mathbf{b}_{3r-2}, \mathbf{b}_{3r-1}, \mathbf{b}_{3r}$ for $r=1 \dots R_L$ [S1].
3.  **Neural Renderer $\mathcal{F}$:** A small neural network mapping BRDF features, illumination, and viewing direction to specular color [S1].

**Numbered Steps:**

1.  **Covariance Transformation:**
    Compute the 3D covariance matrix $\boldsymbol{\Sigma}$ from learned scaling $\mathbf{S}$ and rotation $\mathbf{R}$:
    $$ \boldsymbol{\Sigma} = \mathbf{R}\mathbf{S}\mathbf{S}^T\mathbf{R}^T $$
    Transform to camera coordinates using viewing transformation $\mathbf{W}$ and affine approximation of projective transformation $\mathbf{J}$:
    $$ \boldsymbol{\Sigma}' = \mathbf{J}\mathbf{W}\boldsymbol{\Sigma}\mathbf{W}^T\mathbf{J}^T $$
    [S1]

2.  **Illumination Query:**
    For each Gaussian $i$ with mean $\mathbf{x}_i$, query the illumination grid $\mathcal{G}_l$ to obtain incoming illumination $L_i$. The grid is defined by:
    $$ \mathcal{G}_l = \sum_{r=1}^{R_L} \mathbf{A}_{L,r}^X \circ \mathbf{b}_{3r-2} + \mathbf{A}_{L,r}^Y \circ \mathbf{b}_{3r-1} + \mathbf{A}_{L,r}^Z \circ \mathbf{b}_{3r} $$
    where $\circ$ denotes the outer product or appropriate tensor contraction depending on implementation, and interpolation is used to query continuous values from the discrete grid [S1].

3.  **Shading (Specular Color):**
    Encode the viewing direction $\omega_o$ using Integrated Directional Encoding (IDE) [S1]. Compute the specular color $\mathbf{c}_{s,i}$ using the neural network $\mathcal{F}$:
    $$ \mathcal{F} : \{ \boldsymbol{\rho}_i, L_i, \omega_o \} \mapsto \mathbf{c}_{s,i} $$
    [S1]

4.  **Radiance Composition:**
    Compute the total outgoing radiance $\mathbf{c}_i(\omega_o)$ by linearly adding diffuse and specular components:
    $$ \mathbf{c}_i(\omega_o) = \mathbf{c}_{d,i} + \mathbf{c}_{s,i} $$
    [S1]

5.  **Rendering:**
    Render the scene using the standard 3DGS rasterization pipeline. For a pixel $\mathbf{u}$, compute color $\hat{\mathbf{C}}$ via alpha blending of $N$ ordered Gaussians:
    $$ \hat{\mathbf{C}} = \sum_{i \in N} T_i g_i(\mathbf{u} | \boldsymbol{\mu}', \boldsymbol{\Sigma}') \alpha_i \mathbf{c}_i(\omega_o) $$
    $$ T_i = \prod_{j=1}^{i-1} (1 - g_j(\mathbf{u} | \boldsymbol{\mu}', \boldsymbol{\Sigma}') \alpha_j) $$
    where $g_i$ is the 2D projected Gaussian density [S1].

6.  **Optimization Training Strategy:**
    *   **Phase 1 (Iterations 0–3,000):** Train the model using only the diffuse color $\mathbf{c}_{d,i}$. Optimize means, opacity, covariance, and diffuse color [S1].
    *   **Phase 2 (Iterations 3,000–30,000):** Add specular colors. Optimize BRDF features $\boldsymbol{\rho}_i$ and the illumination grid $\mathcal{G}_l$ [S1].
    *   **Grid Boundary Management:** Define an initial boundary encapsulating the scene bounding box. Midway through training, shrink the illumination grid to fit the Gaussians and resample the grid with the same number of voxels [S1].

7.  **Loss Function:**
    Minimize the combined loss:
    $$ \mathcal{L} = (1 - \lambda)\mathcal{L}_1 + \lambda \mathcal{L}_{\text{D-SSIM}} $$
    with $\lambda = 0.2$ [S1].

**Edge Cases and Pitfalls:**
*   **Grid Boundary:** If the illumination grid is not shrunk midway through training, it may cover empty space, wasting memory and potentially causing interpolation artifacts at the boundaries [S1].
*   **Initialization:** The initial boundary must encapsulate the scene bounding box to ensure all Gaussians are queried correctly during the early training phase [S1].
*   **Precision:** The factorized tensor representation relies on accurate interpolation; ensure the interpolation method (e.g., trilinear) is consistent with the factorization scheme [S1].

## Operating characteristics
*   **Time Complexity:** Rendering speed is comparable to 3DGS because illumination is pre-calculated and stored in the grid, avoiding per-ray tracing [S1]. Training involves optimizing the grid and BRDF features, which adds overhead compared to base 3DGS but remains efficient due to the compact tensor representation [S1].
*   **Memory Complexity:** The illumination field uses $150^3$ voxels, which is 87.5% less than TensoRF on synthetic datasets [S1]. The memory footprint is low compared to the number of optimized Gaussians [S1].
*   **Performance:** On the Shiny Blender dataset, 3iGS achieves PSNR 27.51, SSIM 0.930, and LPIPS 0.045 [S1]. It outperforms 3DGS in scenes with reflective surfaces [S1].
*   **Strengths:** Accurate modeling of specular view-dependent effects; fast rendering; compact memory usage [S1].
*   **Limitations:** Requires careful tuning of grid boundary and training phases; may not generalize as well to unseen lighting conditions as methods using explicit light probes [S1].

## Background
3iGS was introduced by Z.J. Tang and T.J. Cham [S1]. It builds on the limitations of 3DGS, which optimizes outgoing radiance in isolation without accounting for scene lighting or adjacent Gaussians [S1]. It differs from GaussianShader [13], which uses global environment lights and SH-based color, by using local grid-based tensors for illumination [S1].
