# OTS+SAtn Densification
Also called: Densification for Real-World Scenes

## Overview
OTS+SAtn Densification is a density control strategy adapted from the OTS+SAtn splatting technique to operate within the standard 3D Gaussian Splatting (3DGS) framework for real-world scene reconstruction [S1]. It addresses the problem of unbounded primitive growth and scene-specific overfitting by imposing strict caps on the total number of Gaussians and adapting densification thresholds to match 3DGS conventions [S1]. Unlike standard 3DGS which may allow indefinite growth, this method stops densification once a predefined maximum count (e.g., 100k, 500k, 1m, or 5m) is reached, ensuring controlled memory usage while maintaining competitive reconstruction quality [S1].

## How it works
The method integrates the OTS+SAtn rendering logic with a densification schedule that mirrors the standard 3DGS adaptive control but with specific constraints for real-world datasets like MipNeRF360 [S1].

**Inputs and Outputs:**
*   **Input:** Set of $N$ 3D Gaussians, each with position $\mathbf{p}$, covariance $\mathbf{S}$ (or scale/rotation), opacity $\alpha$, and view-space positional gradient $\nabla_{\mathbf{p}} \mathcal{L}$.
*   **Output:** Updated set of Gaussians with modified positions, scales, opacities, and potentially new primitives added or removed.

**Data Structures:**
*   **Gaussian Set:** List of primitives. Each primitive stores $\mathbf{p} \in \mathbb{R}^3$, $\mathbf{S} \in \mathbb{R}^{3 \times 3}$ (symmetric positive definite), $\alpha \in [0,1]$, and $\nabla_{\mathbf{p}} \mathcal{L} \in \mathbb{R}^3$.
*   **Thresholds:**
    *   $N_{max}$: Maximum allowed primitives (e.g., 100,000, 500,000, 1,000,000, 5,000,000) [S1].
    *   $\tau_{grad}$: Gradient threshold for densification candidates.
    *   $\tau_{opac}$: Opacity threshold for pruning.
    *   $\tau_{size}$: Size threshold for splitting/pruning.

**Parameters:**
*   **Densification Interval:** Typically every 100 iterations, starting after a warm-up period (e.g., iteration 100), consistent with 3DGS [S1, 3034-adaptive-densification.md].
*   **Gradient Threshold:** $\tau_{grad} = 1.5 \times 10^{-4}$ [S2].
*   **Opacity Pruning Threshold:** $\tau_{opac} = 0.025$ [S2].
*   **Size Threshold:** Primitives larger than 40% of the scene diagonal or 20 pixels in screen space are considered for removal/splitting [S2].
*   **Cloning Threshold:** Primitives smaller than 1% of the scene diagonal are candidates for cloning [S2].
*   **Splitting Scale Factor:** New primitives have a relative size of $1.2^{-1}$ compared to the parent [S2].

**Steps:**
1.  **Check Limit:** If current primitive count $N \ge N_{max}$, skip densification entirely [S1].
2.  **Evaluate Candidates:** Identify Gaussians where $|\nabla_{\mathbf{p}} \mathcal{L}| > \tau_{grad}$ [S2].
3.  **Classify Candidates:**
    *   **Small:** If size (e.g., standard deviation or diagonal of $\mathbf{S}$) $< 1\%$ of scene diagonal, mark for **Cloning** [S2].
    *   **Large:** If size $> 40\%$ of scene diagonal or $> 20$ pixels, mark for **Splitting** [S2].
    *   **Prune:** If $\alpha < \tau_{opac}$, mark for **Removal** [S2].
4.  **Execute Cloning:**
    *   For each "Small" candidate, create a new Gaussian at $\mathbf{p}$ with identical $\mathbf{S}$ and $q$.
    *   Set new opacity $\alpha_{new} = \alpha / 2$ [3034-adaptive-densification.md].
5.  **Execute Splitting:**
    *   For each "Large" candidate, remove the original Gaussian.
    *   Create two new Gaussians.
    *   **Position Sampling:**
        *   If using octahedra representation: Sample position from $\mathcal{N}(\mathbf{p}, \mathbf{S})$ where standard deviations are aligned with and equal to the distances in each dimension [S2].
        *   If using tetrahedra representation: Sample position from $\mathcal{N}(\mathbf{p}, \mathbf{S})$ where standard deviations are equal to half of the largest distance [S2].
    *   **Scale Adjustment:** Set new scale such that the relative size is $1.2^{-1}$ of the original [S2].
    *   **Opacity:** Distribute opacity (typically halved) [3034-adaptive-densification.md].
6.  **Execute Pruning:** Remove all Gaussians marked for removal [S2].
7.  **Gradient Handling:** Do not propagate gradients through the density normalization factor [S2].

**Pseudocode:**
```python
def ots_satn_densification(gaussians, scene_diagonal, max_primitives, iteration):
    """
    Perform densification for OTS+SAtn adapted to 3DGS.
    """
    if iteration < 100: # Warm-up period
        return gaussians
    
    if len(gaussians) >= max_primitives:
        return gaussians # Stop densification if limit reached [S1]

    candidates = []
    to_remove = []
    
    for g in gaussians:
        grad_norm = norm(g.gradient)
        size = get_size(g) # e.g., max diagonal of covariance
        
        # Pruning [S2]
        if g.opacity < 0.025:
            to_remove.append(g)
            continue
            
        # Densification Candidates [S2]
        if grad_norm > 1.5e-4:
            if size < 0.01 * scene_diagonal: # Small [S2]
                candidates.append(('clone', g))
            elif size > 0.40 * scene_diagonal or size > 20: # Large [S2]
                candidates.append(('split', g))
                
    # Execute Cloning [S2]
    new_gaussians = []
    for action, g in candidates:
        if action == 'clone':
            # Clone at same position, same scale/rotation, halved opacity [3034-adaptive-densification.md]
            clone = Gaussian(
                position=g.position,
                covariance=g.covariance,
                rotation=g.rotation,
                opacity=g.opacity / 2.0,
                gradient=g.gradient
            )
            new_gaussians.append(clone)
            
        elif action == 'split':
            # Remove original, add two new ones [S2]
            # Position sampling depends on representation [S2]
            if g.representation == 'octahedra':
                std_devs = get_dimension_distances(g.covariance)
                pos1 = sample_normal(g.position, std_devs)
                pos2 = sample_normal(g.position, std_devs)
            elif g.representation == 'tetrahedra':
                max_dist = max(get_dimension_distances(g.covariance))
                std_devs = [max_dist / 2.0, max_dist / 2.0, max_dist / 2.0]
                pos1 = sample_normal(g.position, std_devs)
                pos2 = sample_normal(g.position, std_devs)
            
            # Scale reduction by factor 1.2^-1 [S2]
            scale_factor = 1.2 ** -1
            new_cov1 = g.covariance * (scale_factor ** 2) # Assuming scale affects covariance quadratically
            new_cov2 = g.covariance * (scale_factor ** 2)
            
            new_gaussians.append(Gaussian(
                position=pos1,
                covariance=new_cov1,
                rotation=g.rotation,
                opacity=g.opacity / 2.0,
                gradient=g.gradient
            ))
            new_gaussians.append(Gaussian(
                position=pos2,
                covariance=new_cov2,
                rotation=g.rotation,
                opacity=g.opacity / 2.0,
                gradient=g.gradient
            ))

    # Remove pruned and add new
    remaining = [g for g in gaussians if g not in to_remove]
    final_gaussians = remaining + new_gaussians
    
    return final_gaussians
```

## Subtopics

### [Gradient-based Densification Control](3182-gradient-based-densification-control.md)
Gradient-based Densification Control is a mechanism for allocating 3D Gaussian primitives to regions with high reconstruction error by using the magnitude of the photometric loss gradient. It ensures efficient spatial allocation by triggering cloning or splitting operations only when primitives exhibit significant gradients, thereby adapting the representation density to the scene's geometric complexity. It differs from fixed-scale splitting methods by relying on gradient magnitude rather than a static fraction of scene extent, allowing for adaptive refinement based on learning progress.

## Operating characteristics
*   **Time Complexity:** Densification is periodic (e.g., every 100 iterations). The cost is proportional to the number of candidates, which is a subset of $N$.
*   **Memory Complexity:** Bounded by $N_{max}$. The method explicitly stops densification at 100k, 500k, 1m, or 5m primitives [S1].
*   **Performance:** On MipNeRF360, OTS+SAtn with this densification differs from standard 3DGS by at most 4% PSNR across all tested sizes and scenes [S1]. Average training times are slightly lower (2%) for OTS+SAtn [S1]. Rendering times are balanced [S1].
*   **Strengths:** Prevents unbounded growth, suitable for large real-world scenes, maintains competitive quality.
*   **Limitations:** The strict cap $N_{max}$ may limit detail in extremely complex scenes if the cap is too low. The specific thresholds (1.5e-4, 0.025) are tuned for real-world scenes and may not be optimal for synthetic data [S2].

## Background
The method originates from the OTS+SAtn paper, which explores alternative splatting techniques for differentiable rendering [S1]. The authors adapted their densification variables to match 3DGS as closely as possible to evaluate performance on real-world datasets like MipNeRF360 and ScanNet++ v2 [S1]. The specific thresholds and logic are further detailed in the LinPrim paper, which introduces linear primitives and anti-aliasing strategies, noting that gradients are not propagated through the density normalization factor [S2].
