# LiDAR-Guided Structural Initialization


## Overview
LiDAR-Guided Structural Initialization is a method for initializing the geometric structure and density priors of a sparse voxel grid for driving scene reconstruction within the DrivingVoxels framework [S1, unofficial].

## How it works
**Inputs:** LiDAR point cloud $P_{\text{LiDAR}}$, camera poses and intrinsics for training views, asset bounding boxes for dynamic objects, and a minimum voxel size threshold $s_{\min} = 30$ cm [S1, unofficial].
**Outputs:** A sparse voxel grid structure with initialized densities $v_{\text{geo}}$ [S1, unofficial].

**Data Structures:**
- **Voxel Grid:** A hierarchical structure where each voxel is defined by its spatial bounds and a density value $v_{\text{geo}}$ stored at its corners [S1, unofficial].
- **Inner Region:** A uniform coarse grid covering the scene volume containing all camera poses [S1, unofficial].
- **Outer Region:** Two coarse resolution levels representing far-away structures [S1, unofficial].
- **Asset Grids:** Uniform voxel grids aligned with local coordinate systems for each asset [S1, unofficial].

**Steps:**
1. Initialize the inner region as a coarse uniform voxel grid aligned with the global coordinate system, bounded by the scene extent containing all training camera poses [S1, unofficial].
2. Prune voxels in the inner region if they are not visible by any training camera or fall below a minimum camera-height reference threshold [S1, unofficial].
3. Represent the outer region at two coarse resolution levels and apply the same frustum and height filters to prune voxels [S1, unofficial].
4. Iterate through rounds of subdivision on the remaining inner region voxels: subdivide voxels closer than a distance threshold to a LiDAR point, producing a progressively finer shell on physical surfaces while retaining coarse resolution in empty space [S1, unofficial]. Continue subdivision rounds until the minimum voxel size falls below $30$ cm [S1, unofficial].
5. Initialize voxel corner densities by proximity to the LiDAR point cloud: for each grid corner, compute the Euclidean distance $d$ to the nearest LiDAR point and map it to an initial density using the soft density initialization prior [S1, unofficial].
6. For each dynamic asset, create a uniform voxel grid aligned with its local bounding box coordinate system, set the boundary to the largest dimension of the bounding box scaled outward by $20\%$, and initialize all voxel corners with a uniform empty density [S1, unofficial].

**Formula:**
$$v_{\text{geo}}^{\text{init}} = v_{\text{far}} + (v_{\text{close}} - v_{\text{far}}) \cdot \exp \left (-\frac {2d^2}{s^2}\right )$$
where $s$ is the minimum voxel size ($30$ cm) [S1, unofficial].

**Parameters:**
- $v_{\text{close}} = -2.0$: Density value for voxel corners close to LiDAR points [S1, unofficial].
- $v_{\text{far}} = -10.0$: Empty density value for distant voxel corners [S1, unofficial].
- $s_{\min} = 30$ cm: Minimum voxel size threshold for subdivision [S1, unofficial].
- Asset boundary scale: $20\%$ outward from the largest bounding box dimension [S1, unofficial].

**Edge Cases and Pitfalls:**
- LiDAR sparsity results in high $d$, yielding $v_{\text{geo}} \approx v_{\text{far}} = -10.0$, which preserves the ability for the optimizer to recover surfaces missed by the LiDAR sensor [S1, unofficial].
- The exponential decay $\exp(-2d^2/s^2)$ can produce very small density values for large $d$, requiring sufficient floating-point precision [G].
- The $20\%$ margin ensures asset geometry coverage; insufficient margins may clip asset boundaries [S1, unofficial].

**Pseudocode:**
```python
import math

def initialize_lidar_guided_structure(lidar_points, camera_poses, asset_bboxes, s_min=0.3):
    # Step 1: Inner Region Initialization
    inner_grid = create_coarse_uniform_grid(scene_extent_from_cameras(camera_poses))
    # Step 2: Visibility Pruning (Inner)
    inner_grid = prune_voxels(inner_grid, camera_poses, min_height=get_ground_height(lidar_points))
    # Step 3: Outer Region Initialization
    outer_grids = [prune_voxels(create_coarse_grid(level), camera_poses, min_height=get_ground_height(lidar_points)) for level in [1, 2]]
    # Step 4: Proximity-Based Voxel Subdivision
    inner_grid = subdivide_by_lidar(inner_grid, lidar_points, s_min)
    # Step 5: Soft Density Initialization
    inner_grid = init_densities(inner_grid, lidar_points, s_min)
    # Step 6: Asset Initialization
    asset_grids = [init_asset_grid(bbox) for bbox in asset_bboxes]
    return inner_grid, outer_grids, asset_grids

def scene_extent_from_cameras(cameras):
    # [G] Standard bounding box calculation from camera positions
    xs, ys, zs = zip(*[c.position for c in cameras])
    return (min(xs), min(ys), min(zs), max(xs), max(ys), max(zs))

def get_ground_height(points):
    # [G] Minimum height threshold derived from LiDAR ground points
    return min(p[2] for p in points)

def create_coarse_uniform_grid(bounds):
    # [G] Standard grid creation logic
    return {"bounds": bounds, "voxels": []}

def create_coarse_grid(level):
    # [G] Standard coarse grid creation
    return {"bounds": None, "voxels": [], "level": level}

def prune_voxels(grid, cameras, min_height):
    valid = []
    for v in grid["voxels"]:
        visible = any(v_in_frustum(v, c) for c in cameras)
        if visible and v.center[2] >= min_height:
            valid.append(v)
    grid["voxels"] = valid
    return grid

def v_in_frustum(voxel, camera):
    # [G] Standard AABB-camera frustum intersection test
    return True

def subdivide_by_lidar(grid, lidar_points, s_min):
    current_voxels = grid["voxels"]
    while True:
        subdividable = [v for v in current_voxels if v.size > s_min]
        if not subdividable:
            break
        new_voxels = []
        for v in subdividable:
            min_dist = min(math.sqrt((v.center[0]-p[0])**2 + (v.center[1]-p[1])**2 + (v.center[2]-p[2])**2) for p in lidar_points)
            if min_dist < v.size:
                new_voxels.extend(subdivide_voxel(v))
            else:
                new_voxels.append(v)
        non_subdividable = [v for v in current_voxels if v.size <= s_min or (v.size > s_min and min(math.sqrt((v.center[0]-p[0])**2 + (v.center[1]-p[1])**2 + (v.center[2]-p[2])**2) for p in lidar_points) >= v.size)]
        current_voxels = new_voxels + non_subdividable
    grid["voxels"] = current_voxels
    return grid

def subdivide_voxel(v):
    # [G] Standard octree subdivision into 8 children
    return [v.copy() for _ in range(8)]

def init_densities(grid, lidar_points, s_min):
    v_close = -2.0
    v_far = -10.0
    for v in grid["voxels"]:
        for corner in v.corners:
            d = min(math.sqrt((corner[0]-p[0])**2 + (corner[1]-p[1])**2 + (corner[2]-p[2])**2) for p in lidar_points)
            exponent = -2.0 * (d ** 2) / (s_min ** 2)
            corner.density = v_far + (v_close - v_far) * math.exp(exponent)
    return grid

def init_asset_grid(bbox):
    # [G] Standard grid creation from bounding box scaled by 1.2
    grid = create_coarse_uniform_grid(bbox)
    for v in grid["voxels"]:
        for corner in v.corners:
            corner.density = -10.0
    return grid
```

## Operating characteristics
- **Time Complexity:** The subdivision step is iterative and depends on LiDAR point density and scene geometry, approaching $O(N \log N)$ or higher with spatial indexing [G]. Density initialization is $O(V)$ where $V$ is the number of voxel corners [G].
- **Memory Complexity:** Memory usage scales with the number of voxels in the sparse grid, which is significantly less than a dense grid, with the outer region using two coarse levels to further reduce footprint [S1, unofficial].
- **Performance:** The method enables high rendering efficiency by providing a sparse structure that a tile-based rasterizer maps into a strictly ordered front-to-back sequence via Morton ordering [S1, unofficial].
- **Strengths:** Provides a geometrically plausible starting point for optimization, handles dynamic assets separately from the static background, and uses LiDAR to guide structure, reducing the need for extensive densification later [S1, unofficial].
- **Limitations:** Relies on the quality and coverage of the LiDAR point cloud, and fixed parameters ($v_{\text{close}}$, $v_{\text{far}}$, $s_{\min}$) may not be optimal for all scenes [S1, unofficial].

## Background
The method originates from the DrivingVoxels paper, which introduces compositional sparse voxel rasterization for dynamic driving scene reconstruction [S1, unofficial]. It builds on the SVRaster implementation for visibility pruning and frustum culling [S1, unofficial]. The approach is tailored for autonomous driving scenarios where LiDAR data is abundant and dynamic objects require separate handling from the static background [S1, unofficial].
