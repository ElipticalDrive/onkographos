# Tuning-Free Model-Size Control for 3D Gaussian Splatting

Also called: Budget-controlled 3DGS, Lagrangian relaxation for 3DGS pruning

## Overview
This method controls the final number of 3D Gaussian primitives in a scene to a user-specified budget $B$ without per-scene hyperparameter tuning, using a Lagrangian relaxation of the population constraint and a dual ascent controller [S1, unofficial]. It differs from standard 3D Gaussian Splatting [3DGS Parameter Tuning and Sensitivity Analysis](16894-3dgs-parameter-tuning-and-sensitivity-analysis.md) by replacing fixed sparsity penalties with a dynamic budget constraint that guarantees an exact primitive count across all scenes, and from [PSCD-GS](18934-pscd-gs.md) by employing a closed-loop controller rather than static pruning criteria [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input:** Target budget $B$ (integer number of primitives); standard 3DGS training data (images, poses) [S1, unofficial].
- **Output:** A set of exactly $B$ 3D Gaussian primitives with optimized parameters (position, scale, rotation, opacity, spherical harmonics coefficients) [S1, unofficial].

**Data Structures**
- **Primitives:** Standard 3DGS representation. Each primitive $i$ has an inclusion probability $p_i$ derived from its opacity/logits [S1, unofficial].
- **Mask Indicator $m_i$:** Binary variable indicating if primitive $i$ is active ($1$) or pruned ($0$) [S1, unofficial].
- **Dual Multiplier $\lambda_t$:** Scalar value controlling the strength of the budget penalty at iteration $t$ [S1, unofficial].
- **Live Count Estimate $\hat{N}_t$:** Exponential moving average of the number of active primitives [S1, unofficial].

**Parameters**
The method uses a fixed set of hyperparameters for all scenes and budgets [S1, unofficial]:
- Base gain $\eta = 0.05$ [S1, unofficial]
- Margin $\mu = 0.15$ [S1, unofficial]
- Update interval $K = 100$ iterations [S1, unofficial]
- Dead band threshold $\epsilon = 0.02$ [S1, unofficial]
- Log-domain clip range $\delta = 0.02$ [S1, unofficial]
- Asymmetric release ratio $\rho = 3$ [S1, unofficial]
- Initial multiplier $\lambda_0 = 10^{-3}$ [S1, unofficial]
- Terminal projection iteration $T_{lock} = 28,000$ [S1, unofficial]
- Sparsity weight $\lambda_D = 5 \times 10^{-4}$ [S1, unofficial]

**Formulas**
The loss function replaces the fixed sparsity penalty with a Lagrangian relaxation of the constraint $\sum_i m_i \le B$ [S1, unofficial]:

$$
L = (1 - \lambda_D)L_1 + \lambda_D L_{D-SSIM} + \frac{\lambda_t}{B} \sum_i m_i
$$

Here, $L_1$ and $L_{D-SSIM}$ are the reconstruction and D-SSIM losses, $\lambda_D$ is the standard sparsity weight, and $m_i$ is the mask indicator [S1, unofficial]. The penalty term is linear and normalized by $B$, ensuring the gradient $\lambda_t/B$ is independent of the current population size [S1, unofficial].

The dual multiplier $\lambda_t$ is updated every $K$ iterations using multiplicative dual ascent in the log domain [S1, unofficial]:

$$
e_t = \log \left( \frac{\hat{N}_t}{B^\star} \right)
$$

$$
\lambda_{t+K} = \text{clip} \left( \lambda_t \exp \left( \text{clip}(\eta_t e_t, \pm \delta) \right), \lambda_{\min}, \lambda_{\max} \right)
$$

The gain $\eta_t$ is asymmetric to account for the irreversibility of pruning [S1, unofficial]:

$$
\eta_t = \begin{cases} 
\eta & \text{if } e_t > 0 \quad (\text{above budget: tighten}) \\
\rho \eta & \text{if } e_t < 0 \quad (\text{below budget: release})
\end{cases}
$$

The setpoint $B^\star$ is inflated by margin $\mu$ [S1, unofficial]:

$$
B^\star = (1 + \mu)B
$$

The inclusion probability $p_i$ is computed as [S1, unofficial]:

$$
p_i = \text{softmax}(s_i)^0
$$

where $s_i$ are the logits. The mask is defined by the mode: $m_i = 1$ if $p_i > 1/2$, else $0$ [S1, unofficial].

**Numbered Steps**
1. **Initialization:** Initialize 3DGS primitives [S1, unofficial]. Set $\lambda_0 = 10^{-3}$, $\hat{N}_0 = 0$ [S1, unofficial]. Set target budget $B$ [S1, unofficial].
2. **Setpoint Calculation:** Compute $B^\star = (1 + 0.15)B$ [S1, unofficial].
3. **Training Loop (Iteration $t$):**
    a. Render image and compute $L_1$ and $L_{D-SSIM}$ losses [S1, unofficial].
    b. Compute mask indicators $m_i$ based on $p_i > 1/2$ [S1, unofficial].
    c. Compute current live count $N_t = \sum_i m_i$ [S1, unofficial].
    d. Update exponential moving average $\hat{N}_t$ using standard EMA update [G].
    e. If $t$ is a multiple of $K=100$:
        i. Compute error $e_t = \log(\hat{N}_t / B^\star)$ [S1, unofficial].
        ii. If $|e_t| < \epsilon$, set $e_t = 0$ [S1, unofficial].
        iii. Determine $\eta_t$: if $e_t > 0$, $\eta_t = 0.05$; if $e_t < 0$, $\eta_t = 0.15$ ($3 \times 0.05$) [S1, unofficial].
        iv. Update $\lambda_{t+K} = \text{clip}(\lambda_t \exp(\text{clip}(\eta_t e_t, \pm 0.02)), \lambda_{\min}, \lambda_{\max})$ [S1, unofficial].
    f. Compute total loss $L$ using current $\lambda_t$ [S1, unofficial].
    g. Perform gradient descent step [G].
    h. **Pruning/Deletion Floor:** If standard densification/pruning occurs:
        i. Identify primitives to delete based on opacity/score [S1, unofficial].
        ii. **Guard:** If deleting these primitives would reduce the total count below $B$, spare the primitives with the highest inclusion probability $p_i$ until the count is exactly $B$ [S1, unofficial].
4. **Terminal Projection (Iteration $T_{lock} = 28,000$):**
    a. Sort all primitives by inclusion probability $p_i$ [S1, unofficial].
    b. Keep the top $B$ primitives [S1, unofficial].
    c. Delete the rest [S1, unofficial].
    d. Set $\lambda_t = 0$ for all subsequent iterations [S1, unofficial].
5. **Refinement:** Continue training for 2,000 iterations with fixed topology (no densification/pruning) to refine parameters of the remaining $B$ primitives [S1, unofficial].
6. **Export:** Output the $B$ remaining primitives [S1, unofficial].

**Edge Cases and Pitfalls**
- **Irreversibility of Pruning:** Mask-based pruning behaves like hard pruning with a delay. If the population falls below the budget $B$, relieving sparsity pressure does not recover lost primitives because the gradient reaching masked logits is negligible compared to what is needed to reverse logits driven negative by Adam over thousands of steps [S1, unofficial].
- **Overshoot:** A controller aiming exactly at $B$ may overshoot before reacting. Since deficits cannot be restored, the population must settle above $B$ (using margin $\mu$) to ensure the final projection can remove primitives to reach $B$ [S1, unofficial].
- **Stochastic Export:** Exporting primitives based on a single stochastic draw (as in MaskGaussian) makes the delivered size a random variable. The method exports the mode ($p_i > 1/2$) to ensure the measured size matches the shipped size [S1, unofficial].

## Subtopics

### Budget-Controlled Training
The core loop using dual ascent to maintain population near $B^\star$ [S1, unofficial]. It is distinguished from static pruning methods by its closed-loop feedback mechanism [S1, unofficial]. Choose it when exact model size is required without per-scene tuning [S1, unofficial]. See [3DGS Parameter Tuning and Sensitivity Analysis](16894-3dgs-parameter-tuning-and-sensitivity-analysis.md).

### Terminal Projection
The final step at $T_{lock}$ to enforce exact count $B$ [S1, unofficial]. It is distinguished from soft masking export by guaranteeing deterministic output [S1, unofficial]. Choose it when deterministic output is critical [S1, unofficial]. See [3DGS Parameter Tuning and Sensitivity Analysis](16894-3dgs-parameter-tuning-and-sensitivity-analysis.md).

## Operating characteristics
- **Time Complexity:** Training is 1.3× faster than standard 3DGS and 1.2× faster than MaskGaussian because fewer primitives are carried through the second half of the schedule [S1, unofficial].
- **Memory Complexity:** Model size is exactly $B$ primitives. For $B=600,000$, disk size is 142 MB, compared to 709 MB for 3DGS and 318 MB for MaskGaussian [S1, unofficial].
- **Performance:** Rendering is 2.3× faster than 3DGS and 1.4× faster than MaskGaussian for the same budget [S1, unofficial].
- **Quality:** Quality parity is maintained. Mean PSNR moves by -0.014 dB against MaskGaussian and +0.014 dB against 3D-GS. The 95% confidence interval for the paired mean difference between seeds is [-0.076, +0.085] dB [S1, unofficial].
- **Strengths:** Deterministic model size across all scenes and seeds; zero deviation from target budget $B$; no per-scene hyperparameter tuning required [S1, unofficial].

## Background
The method was introduced in "One Setting, Any Scene: Tuning-Free Model-Size Control for 3D Gaussian Splatting" [S1, unofficial]. It addresses the variability in model size produced by standard 3DGS and MaskGaussian, which can vary by a factor of 7.8x across scenes for a fixed sparsity penalty [S1, unofficial]. The approach leverages Lagrangian relaxation and dual ascent, concepts from optimization theory, applied to the population control of Gaussian primitives [S1, unofficial].
