# SpacetimeGaussians Training Pipeline


## Overview
The SpacetimeGaussians Training Pipeline is the optimization procedure for the Spacetime Gaussian Feature Splatting method, which renders dynamic scenes by learning time-dependent Gaussian primitives [S1, unofficial]. It differs from static 3D Gaussian Splatting by explicitly modeling temporal dynamics through motion parameters and a joint training regime that optimizes geometry and appearance simultaneously [S1, unofficial][S2]. The pipeline supports multiple rasterization backends (full vs. lite) and implements a structured densification, pruning, and parameter-freezing schedule to manage Gaussian density over time [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   Dataset containing multi-view video frames and camera poses.
*   Initial Gaussian model parameters (position, rotation, scale, opacity, SH coefficients).
*   Training options: `densify` mode (0-3), `reg` type (1, 4, 6, 7, 8, 9, 10), `lambda_dssim`, `regl`, `opt.densify_from_iter`, `opt.densify_until_iter`, `opt.densification_interval`, `opt.opacity_reset_interval`, `opt.desicnt`, `opt.densify_grad_threshold`, `opt.opthr`.
*   Rasterization option: `train_ours_full`, `train_ours_lite`, `train_ours_fullss`, or `train_ours_litess` [S1, unofficial].

**Outputs:**
*   Optimized Gaussian primitives (positions, rotations, scales, opacities, SH coefficients, and motion parameters).
*   Trained background color tensor and RGB decoder (if used) [S1, unofficial].

### Data Structures
*   **Gaussian Model (`gaussians`):** Contains learnable parameters including `_xyz` (positions), `_rotation` (quaternions), `_scaling` (scales), `_opacity`, `_sh` (SH coefficients), and `_omega` (motion parameters) [S1, unofficial].
*   **Time Tensor (`gaussians.ts`):** Shape `(1, 1, H, W)`, dtype `torch.float32`, device `cuda`. Initialized to ones if `None` [S1, unofficial].
*   **Background Tensor (`background`):** Shape `(numchannels,)`, dtype `torch.float32`, device `cuda`. Initialized to zeros. Default `numchannels` is 9 [S1, unofficial].
*   **Omega Mask (`gaussians.omegamask`):** Boolean tensor indicating which Gaussians retain motion parameters and which are frozen [S1, unofficial].

```python
import numpy as np

def train_spacetime_gaussians(dataset, opt, iteration=0):
    """
    Main training loop for SpacetimeGaussians.
    """
    # 1. Initialize Model and Scene
    # [G] getmodel is assumed to initialize Gaussian attributes including motion params if dynamic
    gaussians = getmodel(dataset.model)
    
    # Load scene data

        shuffle=False,

    )
    
    # Initialize background color tensor
    numchannels = 9  # Default value
    background = torch.zeros(numchannels, dtype=torch.float32, device='cuda')
    
    # Initialize time tensor if not present
    if gaussians.ts is None:
        # H, W from first test camera
        H, W = scene.cameras[0].image_height, scene.cameras[0].image_width
        gaussians.ts = torch.ones((1, 1, H, W), dtype=torch.float32, device='cuda')
        
    # Setup RGB decoder if used
    if gaussians.rgbdecoder is not None:
        gaussians.rgbdecoder = gaussians.rgbdecoder.cuda().eval()
        
    # Get rendering pipeline
    render_func, GRsetting, GRzer = getrenderpip(option=opt.render_option)
    
    # Training loop
    for iteration in range(opt.max_iterations):
        
        # 2. Densification and Pruning Logic
        if opt.densify == 1:  # n3d mode
            # At iteration 8001, determine which Gaussians keep motion params
            if iteration == 8001:
                omegamask = gaussians.zero_omegabymotion()
                gaussians.omegamask = omegamask
            else:
                # Freeze weights based on mask
                # Freeze _omega where omegamask is True
                # Freeze _rotation where omegamask is False
                freezweightsbymasknounsqueeze(gaussians._omega, omegamask)
                freezweightsbymasknounsqueeze(gaussians._rotation, ~omegamask)
                
            # Densification check
            if (iteration > opt.densify_from_iter and 
                iteration % opt.densification_interval == 0 and 
                flag < opt.desicnt):
                
                # Determine size threshold
                if iteration > opt.opacity_reset_interval:
                    size_threshold = 20
                else:
                    size_threshold = None
                    
                gaussians.densify_pruneclone(
                    grad_threshold=opt.densify_grad_threshold,
                    opthr=opt.opthr,
                    extent=scene.cameras_extent,
                    size_threshold=size_threshold
                )
                
            # Pruning logic
            if flag >= opt.desicnt and iteration < 7000:
                gaussians.prune_opacity(threshold=opt.opthr)
                
            # Opacity reset
            if iteration % 3000 == 0:
                gaussians.reset_opacity()
                
            # Final freezing and pruning
            if iteration >= opt.densify_until_iter:
                # Freeze _omega and _rotation
                freezweightsbymasknounsqueeze(gaussians._omega, omegamask)
                freezweightsbymasknounsqueeze(gaussians._rotation, ~omegamask)
                
                # Prune based on Z-coordinate
                if iteration % 1000 == 500:
                    gaussians.prune_z_coordinate(threshold=4.5)
                    
        elif opt.densify == 3:
            # Update densification stats every iteration
            update_max_radii2D(gaussians)
            add_densification_stats(gaussians)

            if iteration % opt.densification_interval == 0:
                gaussians.densify_pruneclone(...)
                
            # Prune low opacity if iteration < 7000
            if iteration < 7000:
                gaussians.prune_opacity(threshold=opt.opthr)
                
            # Reset opacity
            if iteration % opt.opacity_reset_interval == 0:
                gaussians.reset_opacity()
                
            # Remove min/max at iteration 10000
            if iteration == 10000:
                gaussians.removeminmax()
                
        # 3. Render and Compute Loss
        # Render image
        # [G] render_func expects gaussians, camera, background, scaling_modifier, basicfunction, GRsetting, GRzer
        rendering = render_func(
            gaussians=gaussians,
            camera=scene.get_camera(iteration),
            background=background,
            scaling_modifier=1.0,
            basicfunction=trbfunction,
            GRsetting=GRsetting,
            GRzer=GRzer
        )
        I = rendering.image
        I_gt = scene.get_gt_image(iteration)
        
        # Compute Loss based on reg type
        L = compute_loss(I, I_gt, opt)
        
        # Backpropagate
        L.backward()
        
        # Update parameters
        gaussians.step(opt)

def compute_loss(I, I_gt, opt):
    """
    Compute loss based on reg type.
    """
    lambda_dssim = opt.lambda_dssim
    regl = opt.regl
    
    # Base losses
    L_L1 = torch.abs(I - I_gt).mean()
    L_DSSIM = 1 - SSIM(I, I_gt)
    
    if opt.reg == 1:
        # Motion regularization: mean of motion gradients
        g_motion = gaussians.get_motion_gradients()
        N = gaussians.count
        L_reg = regl * (torch.sum(g_motion) / N)
        return (1 - lambda_dssim) * L_L1 + lambda_dssim * L_DSSIM + L_reg
        
    elif opt.reg == 9:
        # Motion regularization: sum of squared omega gradients
        g_omega = gaussians.get_omega_gradients()
        L_reg = regl * torch.sum(g_omega[g_omega > 0] ** 2)
        return (1 - lambda_dssim) * L_L1 + lambda_dssim * L_DSSIM + L_reg
        
    elif opt.reg == 10:
        # Motion regularization: sum of squared motion gradients
        g_motion = gaussians.get_motion_gradients()
        L_reg = regl * torch.sum(g_motion[g_motion > 0] ** 2)
        return (1 - lambda_dssim) * L_L1 + lambda_dssim * L_DSSIM + L_reg
        
    elif opt.reg == 4:
        # Scaling regularization: mean of scaling gradients
        g_scaling = gaussians.get_scaling_gradients()
        N = gaussians.count
        L_reg = regl * (torch.sum(g_scaling) / N)
        return (1 - lambda_dssim) * L_L1 + lambda_dssim * L_DSSIM + L_reg
        
    elif opt.reg == 6:
        # Adaptive lambda
        r = torch.clamp(torch.mean(I_gt) - 0.5 + lambda_dssim, 0, 1)
        return (1 - r) * L_L1 + r * L_DSSIM
        
    elif opt.reg == 7:
        # Normalized L1
        L_L1_norm = L_L1 / (2 * torch.mean(I_gt))
        return (1 - lambda_dssim) * L_L1_norm + lambda_dssim * L_DSSIM
        
    elif opt.reg == 8:
        # Variance regularization
        # [G] x is assumed to be Gaussian position or feature, x_bar is mean
        # This formula is ambiguous in source; assuming x refers to some feature vector
        # and x_bar is its mean over N
        x = gaussians.get_features()
        x_bar = torch.mean(x, dim=0, keepdim=True)
        N = x.shape[0]
        L_var = torch.sum((x - x_bar) ** 2) / N
        return (1 - lambda_dssim) * L_L1 + 0.0002 * lambda_dssim * L_var
        
    else:
        return (1 - lambda_dssim) * L_L1 + lambda_dssim * L_DSSIM
```

### Parameters
*   **`numchannels`**: Number of channels for background color. Default: 9 [S1, unofficial].
*   **`scaling_modifier`**: Passed to render function. Default: 1.0 [S1, unofficial].
*   **`basicfunction`**: Passed to render function. Default: `trbfunction` [S1, unofficial].
*   **`densify`**: Mode selector (0, 1, 2, 3). 1 enables n3d mode with specific pruning/freezing [S1, unofficial].
*   **`reg`**: Loss regularization type (1, 4, 6, 7, 8, 9, 10) [S1, unofficial].
*   **`opt.densify_from_iter`**: Iteration to start densification [S1, unofficial].
*   **`opt.densify_until_iter`**: Iteration to stop densification and freeze parameters [S1, unofficial].
*   **`opt.densification_interval`**: Interval between densification steps [S1, unofficial].
*   **`opt.opacity_reset_interval`**: Interval for opacity reset [S1, unofficial].
*   **`opt.desicnt`**: Counter for densification steps [S1, unofficial].
*   **`opt.densify_grad_threshold`**: Gradient threshold for densification [S1, unofficial].
*   **`opt.opthr`**: Opacity threshold for pruning [S1, unofficial].

### Edge Cases and Pitfalls
*   **RGB Decoder:** If `gaussians.rgbdecoder` is not None, it must be moved to CUDA and set to eval mode before rendering [S1, unofficial].
*   **Pruning Logic:** Pruning behavior changes based on the densification phase. Before `opt.desicnt` is reached, densification is prioritized. After `opt.desicnt` and before iteration 7000, pruning is based on opacity. After `opt.densify_until_iter`, pruning is based on Z-coordinate < 4.5 at specific iterations (500, 1500, etc.) [S1, unofficial].
*   **Time Tensor:** If `gaussians.ts` is None, it must be initialized to ones with shape `(1, 1, H, W)` using dimensions from the first test camera [S1, unofficial].

## Subtopics

### SpacetimeGaussians Densification & Pruning Schedule
A training iteration schedule that controls Gaussian densification, pruning, and parameter freezing based on iteration count, mode selection, and visibility metrics [S1, unofficial].
*   **Mode 1 (n3d):** Prunes points where `gaussians._xyz[:,2] < 4.5` at iteration 1000 and resets opacity every 3000 iterations [S1, unofficial].
*   **Mode 3:** Updates `max_radii2D` and `add_densification_stats` every iteration. Densifies/prunes clones at intervals. Prunes low-opacity points if iteration < 7000. Resets opacity every `opt.opacity_reset_interval`. Calls `removeminmax` at iteration 10000 [S1, unofficial].
*   **Parameters:** `size_threshold` is 20 if `iteration > opt.opacity_reset_interval`, otherwise `None` [S1, unofficial].

## Background
The SpacetimeGaussians method was introduced by Li et al. in CVPR 2024 [S1, unofficial]. It builds on 3D Gaussian Splatting to handle dynamic scenes by learning time-dependent Gaussian primitives. The training pipeline includes specific mechanisms for densification, pruning, and regularization to manage the increased complexity of dynamic scenes [S1, unofficial].
