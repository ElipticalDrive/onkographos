# Content-Aware Texturing for Gaussian Splatting

Also called: Content-Aware Texturing, Ours

## Overview
This method augments 2D Gaussian primitives with spatially varying texture maps to capture high-frequency appearance details that spherical harmonics alone cannot represent, while dynamically managing texture resolution based on scene content [S1]. Unlike fixed-budget texturing methods, it adapts texel density to local error and frequency, avoiding the convergence issues of cloning-based densification by using splitting [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of $N$ 2D Gaussian primitives $\{G_i\}_{i=1}^N$, where each primitive $i$ is defined by mean $\boldsymbol{\mu}_i$, scale $\mathbf{S}_i$, rotation $\mathbf{R}_i$, opacity $\alpha_i$, and spherical harmonic coefficients for color [S1].
*   A set of input views $\Pi$ with corresponding ground truth images [S1].
*   Hyperparameters: $\lambda_{SSIM}=0.2$, $\lambda_{opacity}$, $\lambda_{texture}$, threshold $\tau_{ds}$, threshold $\tau_{tr}$, and minimum pixel size $k_{min}$ [S1].

**Outputs:**
*   Optimized primitive parameters (position, scale, rotation, opacity, SH coefficients, texel size $k_i$) [S1].
*   Texture maps $T_i$ for each primitive, stored in a jagged tensor structure [S1].
*   Rendered images and metrics (SSIM, PSNR, LPIPS) [S1].

### Data Structures
**Primitive Parameters:**
Each primitive stores 59 parameters, each as a 4-byte float [S1]:
1.  Position: 3 floats ($\boldsymbol{\mu}_x, \boldsymbol{\mu}_y, \boldsymbol{\mu}_z$) [S1].
2.  Scale: 2 floats (log-scale factors for the 2D plane) [S1].
3.  Rotation: 4 floats (quaternion) [S1].
4.  Opacity: 1 float ($\alpha_i$) [S1].
5.  Color: 48 floats (Spherical Harmonics coefficients) [S1].
6.  Texel Size: 1 float ($k_i$) [S1].

**Texture Storage:**
*   Texture maps $T_i$ are stored in a custom "jagged" tensor data structure to handle varying resolutions per primitive [S1].
*   Each texel stores 3 floats (RGB offsets) [S1].
*   Texel values are constrained to $[-1, 1]$ via a sigmoid activation on unactivated features $c'_{Ti}$: $c_{Ti} = 2\sigma(c'_{Ti}) - 1$ [S1].

### Coordinate Systems
To facilitate operations, the method uses four coordinate systems [S1]:
1.  **World Space ($p_w$):** Intersection point in world coordinates.
2.  **World Space Centered ($p_{w0}$):** $p_{w0} = p_w - \boldsymbol{\mu}$ [S1].
3.  **Local Axis-Aligned ($p_l$):** $p_l = \mathbf{R}^{-1} p_{w0}$. Since the primitive is 2D, the last component is 0, so $p_l \in \mathbb{R}^2$ [S1].
4.  **Local Normalized/Canonical ($p_c$):** $p_c = \mathbf{S}^{-1} p_l$, where $\mathbf{S} = \text{diag}(\sigma)$ [S1].

### Rendering
The color of a ray $\mathbf{r}$ is computed by alpha blending primitives sorted by depth [S1]:
$$ C(\mathbf{r}) = \sum_i w_i(p_i) \mathbf{c}_i(\mathbf{d}) = \sum_i T_i \alpha_i G_i(p_i) \mathbf{c}_i(\mathbf{d}) $$
where $T_i = \prod_{j<i} (1 - \alpha_j G_j(p_j))$ is the transmittance, and $G(\mathbf{x}) = e^{-\frac{1}{2}(\mathbf{x}^\top \mathbf{x})}$ [S1].

The color $\mathbf{c}_i$ of primitive $i$ is the sum of the spherical harmonic color and a texture offset [S1]:
$$ \mathbf{c}_i = \text{SH}(\mathbf{d}) + \text{bilerp}(T_i, \mathbf{u}) $$
where $\mathbf{u}$ are the UV coordinates in texture space [S1].

### Texture Coordinate Calculation
To avoid texture stretching during optimization, the texel size $k_i$ is fixed in world space, decoupling texture parameters from primitive shape parameters [S1]. The UV coordinate $\mathbf{u}$ is calculated as [S1]:
$$ \mathbf{u} = \frac{p_l}{k_i} + \mathbf{T}_{\text{offset}} $$
where $k_i$ is the texel size in world space units (same units as primitive scales $\sigma$), and $\mathbf{T}_{\text{offset}}$ centers the texture map [S1].

The texel size $k$ is derived from the minimum pixel size $k_{min}$ and a texel size-to-pixel size ratio $t2_{pr}$ [S1]:
$$ k = k_{min} \cdot t2_{pr} $$
$t2_{pr}$ takes values that are powers of two, with a lower bound of 1 [S1].

### Training Loss
The total loss $\mathcal{L}$ is the sum of RGB loss, texture sparsity loss, and opacity regularization [S1]:
$$ \mathcal{L} = \mathcal{L}_{RGB} + \mathcal{L}_{texture} + \mathcal{L}_{opacity} $$

1.  **RGB Loss:** Weighted sum of L1 and SSIM losses [S1]:
    $$ \mathcal{L}_{RGB} = (1 - \lambda_{SSIM}) \mathcal{L}_1 + \lambda_{SSIM} \mathcal{L}_{SSIM} $$
    with $\lambda_{SSIM} = 0.2$ [S1].

2.  **Texture Sparsity Loss:** Pushes texel values towards zero to allow downsampling [S1]:
    $$ \mathcal{L}_{texture} = \lambda_{texture} \sum_i |c_{Ti}| $$
    where $c_{Ti}$ are the constrained texel values [S1].

3.  **Opacity Regularization:** Encourages low-contribution primitives to disappear [S1]:
    $$ \mathcal{L}_{opacity} = \lambda_{opacity} \frac{1}{N} \sum_i \alpha_i $$

### Primitive Management and Densification
The method uses splitting instead of cloning to avoid superimposition issues [S1].

**Error Calculation:**
For a primitive $i$, the error $E_i$ is a weighted sum of per-view errors [S1]:
$$ E_i = \frac{\sum_{\pi \in \Pi} E_i^\pi w_i^\pi}{\sum_{\pi \in \Pi} w_i^\pi} $$
where $w_i^\pi = \sum_{\mathbf{r} \in P_i} w_i^\pi(\mathbf{r})$ is the total contribution of primitive $i$ in view $\pi$, and $E_i^\pi$ is the error in view $\pi$ [S1]. This differs from taking the maximum error over views [S1].

**Upscaling (Appearance Error):**
If a primitive is in the top 10% of highest error, and its texture resolution exceeds $\tau_{tr}$, it is upscaled by halving $t2_{pr}$ (increasing resolution by factor of 4) [S1]. Upscaling is only allowed if $t2_{pr} \ge 2$ [S1].

**Downscaling (Low Frequency):**
To reduce parameters, the method checks if a texture can be reconstructed with lower resolution. It computes the error $E_d$ between the original texture $T_{orig}$ and a low-pass filtered version $T_{lowpass}$, weighted by Gaussian falloff [S1]:
$$ E_d = \frac{\sum_p G(p) (T_{orig}(p) - T_{lowpass}(p))}{\sum_p G(p)} $$
If $E_d < \tau_{ds}$, $t2_{pr}$ is doubled (resolution halved) [S1].

**Splitting (Geometric Error):**
If a primitive in the top 10% of highest error has a texture resolution exceeding $\tau_{tr}$, it is split into two new primitives [S1].
1.  **Action:** Replace primitive $i$ with two new primitives.
2.  **Displacement:** Each new primitive is displaced by $\pm 1$ standard deviation of the Gaussian along the axis [S1].
3.  **Properties:**
    *   Scale: Half the scale in the corresponding axis [S1].
    *   Texture Resolution: Half the texture resolution [S1].
    *   Opacity: $G(1)$ times the original opacity [S1].
    *   Texture Initialization: The new texture maps are created by sampling the original point at the respective locations [S1].

### Pseudocode

```python
def train_gaussian_splatting_with_texturing(primitives, views, hyperparams):
    """
    primitives: List of Gaussian primitives. Each has:
        - pos (3), scale (2), rot (4), opacity (1), sh_coeffs (48), texel_size_k (1)
        - texture_map: Jagged tensor of RGB offsets
    views: List of camera poses and ground truth images
    hyperparams: {lambda_ssim, lambda_opacity, lambda_texture, tau_ds, tau_tr, k_min}
    """
    for iteration in range(max_iterations):
        # 1. Render
        rendered_images = []
        for view in views:
            # Sort primitives by depth
            sorted_prims = sort_by_depth(primitives, view.camera)
            image = zeros(view.resolution)
            transmittance = 1.0
            
            for prim in sorted_prims:
                # Compute intersection in camera space
                # Unlike 2DGS, use Eq 1 directly in camera space [S1]
                p_w = ray_primitive_intersection(view.ray, prim)
                if p_w is None: continue
                
                # Transform to local space
                p_w0 = p_w - prim.pos
                p_l = inverse(prim.rot) @ p_w0
                # p_l is 2D (ignore z)
                
                # Compute Gaussian weight
                # Canonical space for Gaussian evaluation
                p_c = inverse(prim.scale) @ p_l
                g_val = exp(-0.5 * dot(p_c, p_c))
                
                # Compute UV coordinates for texture
                # k is derived from t2_pr and k_min
                k = hyperparams.k_min * prim.t2_pr
                u = (p_l / k) + prim.t_offset
                
                # Sample texture
                # Clamp u to texture bounds; if out of bounds, use zero-padding (DC color) [S1]
                texel_offset = bilerp(prim.texture_map, u)
                
                # Compute color
                sh_color = spherical_harmonics(prim.sh_coeffs, view.direction)
                c_i = sh_color + texel_offset
                
                # Alpha blend
                alpha = prim.opacity * g_val
                color_contrib = alpha * transmittance * c_i
                image += color_contrib
                transmittance *= (1.0 - alpha)
            
            rendered_images.append(image)
        
        # 2. Compute Loss
        loss_rgb = compute_l1_ssim_loss(rendered_images, views.gt_images, hyperparams.lambda_ssim)
        loss_texture = hyperparams.lambda_texture * sum(abs(texel) for prim in primitives for texel in prim.texture_map)
        loss_opacity = hyperparams.lambda_opacity * mean([prim.opacity for prim in primitives])
        total_loss = loss_rgb + loss_texture + loss_opacity
        
        # 3. Backpropagate
        gradients = compute_gradients(total_loss)
        update_parameters(primitives, gradients)
        
        # 4. Primitive Management (every 100 iterations) [S1]
        if iteration % 100 == 0:
            manage_primitives(primitives, views, hyperparams)

def manage_primitives(primitives, views, hyperparams):
    # Compute per-primitive error
    errors = []
    for prim in primitives:
        # Weighted sum of per-view errors [S1]
        total_weight = 0
        weighted_error = 0
        for view in views:
            # Project primitive to view
            pixels_covered = get_pixels_covered(prim, view)
            if not pixels_covered: continue
            
            # Compute error contribution
            # E_i^pi = sum(E_pi(r) * w_i^pi(r)) for r in P_i [S1]
            view_error = 0
            view_weight = 0
            for pixel in pixels_covered:
                # Get rendered error and weight for this pixel
                err, weight = get_pixel_error_and_weight(prim, pixel, view)
                view_error += err * weight
                view_weight += weight
            
            weighted_error += view_error
            total_weight += view_weight
        
        if total_weight > 0:
            error = weighted_error / total_weight
        else:
            error = 0
        errors.append((prim, error))
    
    # Sort by error descending
    errors.sort(key=lambda x: x[1], reverse=True)
    
    # Select top 10%
    top_10_count = int(len(errors) * 0.1)
    top_prims = errors[:top_10_count]
    
    for prim, error in top_prims:
        # Check if texture resolution exceeds threshold
        # Texture resolution is related to t2_pr. 
        # If t2_pr is small, resolution is high.
        # The paper says: "check which of these exceed a threshold tau_tr for texture resolution" [S1]
        # Assuming high resolution means small t2_pr.
        # Let's define resolution metric R = 1/t2_pr. If R > tau_tr, split.
        # Or simply check if t2_pr is below a threshold corresponding to tau_tr.
        # The text says: "If the error is still high despite upscaling, we interpret the remaining error as geometric."
        # And: "check which of these exceed a threshold tau_tr for texture resolution."
        # This implies if the primitive is already at high texture resolution (small t2_pr) and still has error, split.
        
        if prim.t2_pr <= threshold_from_tau_tr(hyperparams.tau_tr):
            # Split primitive
            split_primitive(prim)
        else:
            # Upscale texture
            if prim.t2_pr >= 2: # Only upscale if t2_pr >= 2 [S1]
                prim.t2_pr /= 2
                # Reallocate texture map with higher resolution
                # Initialize new texels by sampling original point [S1]
                upscale_texture(prim)
    
    # Downscaling pass for all primitives
    for prim in primitives:
        # Compute E_d
        # Sample original texture and low-pass filtered texture
        t_orig = prim.texture_map
        t_lowpass = lowpass_filter(t_orig)
        
        # Compute weighted error E_d [S1]
        # E_d = sum(G(p) * (T_orig(p) - T_lowpass(p))) / sum(G(p))
        # This requires iterating over pixels covered by the primitive
        numerator = 0
        denominator = 0
        for view in views:
            pixels_covered = get_pixels_covered(prim, view)
            for pixel in pixels_covered:
                p_w = ray_pixel_intersection(view.ray, pixel)
                if p_w is None: continue
                
                # Compute Gaussian weight G(p)
                p_w0 = p_w - prim.pos
                p_l = inverse(prim.rot) @ p_w0
                p_c = inverse(prim.scale) @ p_l
                g_val = exp(-0.5 * dot(p_c, p_c))
                
                # Get texture values at this pixel
                k = hyperparams.k_min * prim.t2_pr
                u = (p_l / k) + prim.t_offset
                t_val = bilerp(t_orig, u)
                t_lp_val = bilerp(t_lowpass, u)
                
                diff = t_val - t_lp_val
                numerator += g_val * diff
                denominator += g_val
        
        if denominator > 0:
            e_d = numerator / denominator
            if e_d < hyperparams.tau_ds:
                # Downscale
                prim.t2_pr *= 2
                # Reallocate texture map with lower resolution
                downscale_texture(prim)

def split_primitive(prim):
    # Create two new primitives
    # Displaced by +/- 1 standard deviation along the axis
    # The axis is determined by the scale with the largest extent? 
    # The text says: "performed separately for each axis" [S1]
    # "If a primitive... happens to have a texture resolution greater than tau_tr in both axes"
    # This implies splitting can happen along X or Y or both.
    # For simplicity, we split along the axis with the largest scale.
    
    axis = argmax(prim.scale)
    std_dev = prim.scale[axis]
    
    # New positions
    pos1 = prim.pos + std_dev * get_axis_vector(axis)
    pos2 = prim.pos - std_dev * get_axis_vector(axis)
    
    # New scales: half the scale in the corresponding axis
    scale1 = prim.scale.copy()
    scale1[axis] /= 2
    scale2 = prim.scale.copy()
    scale2[axis] /= 2
    
    # New opacity: G(1) times original opacity
    # G(1) = exp(-0.5)
    g1 = exp(-0.5)
    alpha1 = prim.opacity * g1
    alpha2 = prim.opacity * g1
    
    # New rotation: same as original
    rot1 = prim.rot
    rot2 = prim.rot
    
    # New texture: sample original point at respective locations
    # This requires sampling the original texture map at the new local coordinates
    # Since the new primitives are displaced, their local coordinates relative to the old center are different.
    # However, the texture is attached to the primitive.
    # "The texture map of the newly added primitives is created by sampling the original point at the respective locations." [S1]
    # This likely means sampling the *original primitive's texture* at the offset corresponding to the displacement.
    
    # For prim1: displacement is +std_dev along axis.
    # In local space, this is +1 standard deviation.
    # So we sample the original texture at u_offset = (std_dev / k) along the axis.
    
    k = prim.t2_pr * hyperparams.k_min
    offset = std_dev / k
    u1 = get_uv_offset(axis, offset)
    u2 = get_uv_offset(axis, -offset)
    
    tex1 = sample_texture_at_offset(prim.texture_map, u1)
    tex2 = sample_texture_at_offset(prim.texture_map, u2)
    
    # Create new primitives
    new_prim1 = Primitive(pos1, scale1, rot1, alpha1, prim.sh_coeffs, prim.t2_pr, tex1)
    new_prim2 = Primitive(pos2, scale2, rot2, alpha2, prim.sh_coeffs, prim.t2_pr, tex2)
    
    # Replace original with new ones
    remove_primitive(prim)
    add_primitive(new_prim1)
    add_primitive(new_prim2)
```

## Operating characteristics

**Time and Memory Complexity:**
*   **Memory:** Each primitive has 59 parameters (4 bytes each) plus texture storage. Texture storage is jagged, with 3 floats per texel. The number of texels is dynamic [S1].
*   **Training Time:** 1.5-2x slower than 2DGS due to per-ray texture querying overhead [S1].
*   **Rendering Time:** 25% slower than 2DGS due to the same overhead [S1].

**Measured Performance:**
*   **DeepBlending:** SSIM 0.907, PSNR 30.03, LPIPS 0.303, 222K points, 21.6M texels, 78.1M params, 70 FPS [S1].
*   **Mip-Nerf-360:** SSIM 0.795, PSNR 27.00, LPIPS 0.263, 218K points, 46.6M texels, 152.6M params, 67 FPS [S1].
*   **Tanks&Temples:** SSIM 0.835, PSNR 23.43, LPIPS 0.225, 164K points, 10.4M texels, 41.1M params, 121 FPS [S1].

**Strengths and Limitations:**
*   **Strengths:** Captures high-frequency details with fewer parameters than fixed-budget methods (e.g., GSTex, BBSplat) [S1]. Avoids texture stretching by decoupling texel size from primitive shape [S1].
*   **Limitations:** Slower training and rendering than 2DGS [S1]. Cloning-based densification is incompatible [S1].

**When to Use:**
*   When high-frequency appearance details are required and fixed-budget texturing is insufficient [S1].
*   When memory efficiency is important compared to methods like GSTex [S1].

**When Not to Use:**
*   When training speed is critical, as it is 1.5-2x slower than 2DGS [S1].
*   When using cloning-based densification strategies [S1].

## Background

**Origin:**
The method was introduced by Panagiotis Papantonakis, Georgios Kopanas, Frédo Durand, and George Drettakis in the paper "Content-Aware Texturing for Gaussian Splatting" [S1].

**History and Development:**
The method builds on 2D Gaussian Splatting (2DGS) [S1]. It addresses limitations in existing texturing methods like GSTex (which uses a fixed texel budget on a pretrained point cloud) and BBSplat (which uses a fixed texel-to-primitive ratio) [S1]. It also avoids the convergence issues of cloning-based densification used in other methods [S1].

**Usage:**
Implemented using the 3DGS codebase, introducing 2D primitives as in 2DGS [S1].
