# Volume Prior Initialization

Also called: Gradient-based Gaussian Initialization with Volume Prior

## Overview
Volume Prior Initialization is a method for initializing 3D Gaussian primitives by leveraging a dense ground-truth volume representation to guide the placement and orientation of Gaussians before optimization begins. It solves the problem of poor initial convergence in sparse or noisy data by using gradient information from the volume to seed anisotropic Gaussians aligned with local surface structures. It sets itself apart from isotropic initialization methods by explicitly estimating local geometry (normals and scales) from the volume gradients, providing spatial support and rotation priors that accelerate early convergence [S1].

## How it works
The method operates in two phases: an initialization phase that extracts geometric priors from a ground-truth volume, and an optimization phase that refines the Gaussian representation using volume-based losses.

**Inputs:**
- Ground-truth volume $\mathbf{V}_{\text{gt}}$: A dense 3D voxel grid representing the target scene or object.
- Initial point cloud: Generated from the gradients of $\mathbf{V}_{\text{gt}}$.

**Outputs:**
- Initial set of 3D Gaussians $\Theta_0$: A set of Gaussians with centroids, covariances (anisotropic), opacities, and spherical harmonics coefficients.

**Data Structures:**
- **Gaussian Set**: Each Gaussian $i$ is defined by:
  - Centroid $\mathbf{\mu}_i \in \mathbb{R}^3$
  - Covariance matrix $\mathbf{\Sigma}_i \in \mathbb{R}^{3 \times 3}$ (symmetric positive definite)
  - Opacity $\alpha_i \in [0, 1]$
  - Spherical Harmonics coefficients $\mathbf{c}_i$
- **Voxel Grid**: A 3D array representing $\mathbf{V}_{\text{gt}}$ and the current reconstruction $\mathbf{V}_r$.

**Steps:**

1. **Gradient Extraction**: Compute the spatial gradients of the ground-truth volume $\mathbf{V}_{\text{gt}}$ to identify surface locations. This is done using a variant of gradient-based Gaussian initialization [S1]. The gradients indicate the direction of maximum intensity change, which corresponds to surface normals.
2. **Initial Gaussian Placement**: Place Gaussian centroids at locations where the gradient magnitude exceeds a threshold. The initial covariance matrices are aligned with the gradient directions to form disc-like structures, providing anisotropic shape priors [S1].
3. **Optimization Loop**: For each optimization step:
   a. **Voxelization**: Render the current Gaussian representation $\Theta$ into a 3D volume $\mathbf{V}_r$ by voxelizing the Gaussians. This involves projecting each Gaussian onto the voxel grid and accumulating contributions [S1].
   b. **Loss Computation**: Evaluate the difference between $\mathbf{V}_r$ and $\mathbf{V}_{\text{gt}}$ using a combined loss function:
      $$
      \mathcal{L}_{\text{total}} = \mathcal{L}_1(\mathbf{V}_r, \mathbf{V}_{\text{gt}}) + \alpha_{\text{SSIM}} \mathcal{L}_{\text{SSIM}}(\mathbf{V}_r, \mathbf{V}_{\text{gt}})
      $$
      where $\mathcal{L}_1$ is the L1 loss, $\mathcal{L}_{\text{SSIM}}$ is the 3D Structural Similarity Index Measure loss, and $\alpha_{\text{SSIM}}$ is a weighting parameter [S1].
   c. **Gradient Update**: Compute gradients of $\mathcal{L}_{\text{total}}$ with respect to the Gaussian parameters and update them using an optimizer (e.g., Adam) [S1].

**Parameters:**
- $\alpha_{\text{SSIM}}$: Weight for the 3D SSIM loss. Typical values are not specified in the sources.
- Gradient threshold: For selecting initial Gaussian locations. Not given in the sources.

**Edge Cases and Pitfalls:**
- **Precision**: Voxelization can introduce discretization errors. The sources note that voxelization becomes fast enough for regular use during fitting, implying that performance is a concern [S1].
- **Boundaries**: Gradient extraction may be noisy at volume boundaries. Proper smoothing or filtering of $\mathbf{V}_{\text{gt}}$ may be required before gradient computation.
- **Degenerate Input**: If $\mathbf{V}_{\text{gt}}$ is sparse or noisy, gradient-based initialization may produce poor initial Gaussians.

**Pseudocode:**

```python
def volume_prior_initialization(V_gt, alpha_ssim, num_iterations, optimizer):
    """
    Initialize and optimize 3D Gaussians using volume prior.
    
    Args:
        V_gt: Ground-truth 3D volume (numpy array or tensor)
        alpha_ssim: Weight for SSIM loss
        num_iterations: Number of optimization steps
        optimizer: Optimization function (e.g., Adam)
        
    Returns:
        Gaussians: Final set of 3D Gaussians
    """
    # Step 1: Extract gradients from ground-truth volume
    gradients = compute_gradients(V_gt)
    gradient_magnitude = np.linalg.norm(gradients, axis=-1)
    
    # Step 2: Initialize Gaussians based on gradients
    # Select points where gradient magnitude is high
    threshold = np.percentile(gradient_magnitude, 90) # [G] Example threshold
    initial_points = np.argwhere(gradient_magnitude > threshold)
    
    # Convert voxel coordinates to world coordinates
    # [G] Assuming voxel size is 1 and origin is at (0,0,0)
    centroids = initial_points.astype(float)
    
    # Initialize covariances aligned with gradients
    # [G] Simple isotropic initialization for covariance; 
    # anisotropic alignment would use gradient direction
    covariances = np.eye(3)[np.newaxis, :, :] * 0.1
    
    # Initialize other parameters
    opacities = np.ones(len(centroids))
    sh_coeffs = np.zeros((len(centroids), 12)) # [G] Assuming 3rd order SH
    
    Gaussians = {
        'centroids': centroids,
        'covariances': covariances,
        'opacities': opacities,
        'sh_coeffs': sh_coeffs
    }
    
    # Step 3: Optimization loop
    for i in range(num_iterations):
        # Voxelize current Gaussians
        V_r = voxelize_gaussians(Gaussians, V_gt.shape)
        
        # Compute losses
        l1_loss = np.mean(np.abs(V_r - V_gt))
        ssim_loss = compute_3d_ssim(V_r, V_gt)
        total_loss = l1_loss + alpha_ssim * ssim_loss
        
        # Compute gradients of loss w.r.t. Gaussian parameters
        # [G] This requires differentiable voxelization
        grads = compute_gradients_of_loss(total_loss, Gaussians)
        
        # Update Gaussians
        Gaussians = optimizer.step(Gaussians, grads)
        
    return Gaussians

def compute_gradients(V):
    """Compute spatial gradients of a 3D volume."""
    # [G] Using finite differences
    dx = np.gradient(V, axis=0)
    dy = np.gradient(V, axis=1)
    dz = np.gradient(V, axis=2)
    return np.stack([dx, dy, dz], axis=-1)

def voxelize_gaussians(Gaussians, grid_shape):
    """Voxelize a set of 3D Gaussians into a volume."""
    # [G] Simplified voxelization
    # For each Gaussian, project its contribution to the voxel grid
    volume = np.zeros(grid_shape)
    for i in range(len(Gaussians['centroids'])):
        centroid = Gaussians['centroids'][i]
        cov = Gaussians['covariances'][i]
        opacity = Gaussians['opacities'][i]
        # [G] Evaluate Gaussian at each voxel center and accumulate
        # This is computationally expensive; in practice, use efficient rasterization
        for x in range(grid_shape[0]):
            for y in range(grid_shape[1]):
                for z in range(grid_shape[2]):
                    point = np.array([x, y, z])
                    diff = point - centroid
                    val = opacity * np.exp(-0.5 * diff @ np.linalg.inv(cov) @ diff)
                    volume[x, y, z] += val
    return volume

def compute_3d_ssim(V1, V2):
    """Compute 3D SSIM between two volumes."""
    # [G] Placeholder for SSIM computation
    # SSIM involves local windows, mean, variance, and covariance
    # This is a simplified placeholder
    return np.mean((V1 - V2)**2)
```

## Subtopics

### [Prior-Conditioned Parameterization (I)](21550-prior-conditioned-parameterization-i.md)
Prior-Conditioned Parameterization (I) is an initialization method that seeds anisotropic Gaussians by estimating local surface statistics (normals and scales) from a dense prior $P$, front-loading structure discovery. It addresses the problem where standard 3D Gaussian Splatting initializes isotropic Gaussians from interpoint distances, leaving local surface scale and rotation to be recovered during optimization, which consumes available updates under short iteration horizons. By mapping the dense prior $P$ to a surface-aligned anisotropic set $\Theta_0$, it provides spatial support, scale, and rotation before optimization, supporting rapid early convergence. It sets itself apart from sibling methods by explicitly constructing disc-like covariance structures aligned to estimated normals, rather than relying on isotropic scaling or post-initialization densification to find surface geometry.

## Operating characteristics
- **Time Complexity**: The voxelization step is $O(N \cdot V)$, where $N$ is the number of Gaussians and $V$ is the number of voxels. This makes a single optimization step slower than standard splatting, but the improved initialization may reduce the total number of iterations required [S1].
- **Memory Complexity**: Requires storing the ground-truth volume $\mathbf{V}_{\text{gt}}$ and the current reconstruction $\mathbf{V}_r$, both of size $O(V)$.
- **Measured Performance**: Not given in the sources.
- **Strengths**: Provides geometrically informed initial Gaussians, leading to faster convergence and better reconstruction quality for structured scenes [S1].
- **Limitations**: Computationally expensive due to voxelization; requires a dense ground-truth volume, which may not be available in all scenarios [S1].
- **When to use**: When a dense ground-truth volume is available and fast convergence is critical.
- **When not to use**: When computational resources are limited or when no ground-truth volume is available.

## Background
Volume Prior Initialization was introduced in the context of Fast and Scalable CT Reconstruction with Gaussian Splatting (FaCT-GS) [S1]. The method leverages the availability of ground-truth volumes in CT reconstruction tasks to guide the initialization of 3D Gaussians, improving the efficiency and quality of the reconstruction process.
