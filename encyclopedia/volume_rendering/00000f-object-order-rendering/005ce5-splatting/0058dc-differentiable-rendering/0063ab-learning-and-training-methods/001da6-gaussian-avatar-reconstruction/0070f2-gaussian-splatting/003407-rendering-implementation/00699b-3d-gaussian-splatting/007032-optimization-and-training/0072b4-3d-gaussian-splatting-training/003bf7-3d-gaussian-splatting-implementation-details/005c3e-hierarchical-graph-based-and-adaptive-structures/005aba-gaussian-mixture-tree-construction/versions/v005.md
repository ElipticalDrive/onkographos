# Gaussian Mixture Tree Construction

Also called: Hierarchically Merging Gaussians

## Overview
Gaussian Mixture Tree (GMT) construction is a hierarchical clustering method that organizes 3D Gaussian primitives into a tree structure to identify distinct 3D plane instances in a scene [S1]. It solves the problem of spatial redundancy and geometric inconsistency in flat Gaussian splatting by grouping primitives into local clusters and recursively merging them based on probabilistic similarity [S1]. Unlike sibling methods that rely on graph connectivity or fixed grid structures, GMT uses a bottom-up agglomerative approach driven by the Bhattacharya distance and plane descriptor similarity to build a hierarchy where parent nodes encompass child center points [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N_s$ leaf nodes, where each leaf node $G_i$ represents a local cluster of Gaussian primitives. Each node $G_i$ is defined by mean $\mu_i$, covariance $\Sigma_i$, normal vector $n_i \in \mathbb{R}^3$, and plane descriptor $z_i \in \mathbb{R}^k$ (typically $k=3$) [S1].
*   **Output:** A Gaussian Mixture Tree $G$ containing merged parent nodes $G_{s_k}$ and a count $L$ of the resulting plane nodes [S1].

**Data Structures:**
Each node in the tree stores:
*   $\mu \in \mathbb{R}^3$: Mean position.
*   $\Sigma \in \mathbb{R}^{3 \times 3}$: Covariance matrix.
*   $n \in \mathbb{R}^3$: Surface normal vector.
*   $z \in \mathbb{R}^k$: Plane descriptor vector.

**Parameters:**
*   $\epsilon_B$: Threshold for the Bhattacharya distance. Not given in the sources.
*   $\epsilon_z$: Threshold for the difference in cosine similarity between plane descriptors. Not given in the sources.

**Merging Criteria:**
Two nodes $G_i$ and $G_j$ are merged if:
1.  The Bhattacharya distance $D_B(G_i, G_j) \le \epsilon_B$.
2.  The angular difference between their plane descriptors satisfies $1 - \langle z_i \cdot z_j \rangle \le \epsilon_z$, where $\langle z_i \cdot z_j \rangle$ is the dot product of normalized descriptors [S1].

**Formulas:**
The Bhattacharya distance between two multivariate Gaussian distributions $G_i$ and $G_j$ is calculated as [S1]:
$$
D_B(G_i, G_j) = \frac{1}{8}(\mu_i - \mu_j)^T \Sigma^{-1} (\mu_i - \mu_j) + \frac{1}{2} \ln \left( \frac{\det \Sigma}{\sqrt{\det \Sigma_i \det \Sigma_j}} \right)
$$
where $\Sigma = \frac{\Sigma_i + \Sigma_j}{2}$ [S1].

When nodes $G_i$ and $G_j$ are merged, the parent node $G_p(\mu_p, \Sigma_p)$ is computed as [S1]:
$$
\Sigma_p = \Sigma_j (\Sigma_i + \Sigma_j)^{-1} \Sigma_i
$$
$$
\mu_p = \Sigma_j (\Sigma_i + \Sigma_j)^{-1} \mu_i + \Sigma_i (\Sigma_i + \Sigma_j)^{-1} \mu_j
$$

**Algorithm Steps:**
1.  Initialize $L = 0$ and the set of merged nodes $G = \emptyset$.
2.  Iterate $i$ from $1$ to $N_s$:
    a.  Check if node $i$ is already a descendant of any existing node in $G$. If yes, skip to the next $i$.
    b.  Iterate $j$ from $i+1$ to $N_s$:
        i.  Check if node $j$ is already a descendant of any existing node in $G$. If yes, skip to the next $j$.
        ii. Calculate $D_B(G_i, G_j)$ and the descriptor similarity $1 - \langle z_i \cdot z_j \rangle$.
        iii. If $D_B(G_i, G_j) \le \epsilon_B$ AND $1 - \langle z_i \cdot z_j \rangle \le \epsilon_z$:
            1.  Compute $\mu_p$ and $\Sigma_p$ using the formulas above.
            2.  Create parent node $G_{ij}^p$ with these parameters.
            3.  Update $G_i \leftarrow G_{ij}^p$ (effectively merging $j$ into $i$).
            4.  Break the inner loop (stop checking further $j$ for this $i$).
    c.  Insert the resulting node $G_i$ into $G$.
    d.  Increment $L$ by 1.

**Pseudocode:**
```python
def construct_gaussian_mixture_tree(leaf_nodes, epsilon_b, epsilon_z):
    """
    Constructs a Gaussian Mixture Tree from leaf nodes.
    
    Args:
        leaf_nodes: List of Node objects, each with attributes:
            - mu: array-like, shape (3,)
            - Sigma: array-like, shape (3, 3)
            - z: array-like, shape (k,)
            - is_merged: boolean, initially False
        epsilon_b: float, Bhattacharya distance threshold
        epsilon_z: float, plane descriptor similarity threshold
            
    Returns:
        merged_nodes: List of Node objects representing the tree leaves (plane instances)
    """
    merged_nodes = []
    
    # Helper to calculate Bhattacharya distance
    def bhattacharya_distance(node_i, node_j):
        mu_i = node_i.mu
        mu_j = node_j.mu
        Sigma_i = node_i.Sigma
        Sigma_j = node_j.Sigma
        
        # Sigma = (Sigma_i + Sigma_j) / 2
        Sigma = (Sigma_i + Sigma_j) / 2.0
        
        # Term 1: Mahalanobis distance part
        diff = mu_i - mu_j
        # Solve Sigma * x = diff for x, then dot(diff, x)
        # Or directly: diff^T * Sigma^{-1} * diff
        Sigma_inv = np.linalg.inv(Sigma)
        term1 = 0.25 * np.dot(diff, np.dot(Sigma_inv, diff))
        
        # Term 2: Determinant part
        det_Sigma = np.linalg.det(Sigma)
        det_Sigma_i = np.linalg.det(Sigma_i)
        det_Sigma_j = np.linalg.det(Sigma_j)
        
        # Handle potential numerical issues with det
        if det_Sigma <= 0 or det_Sigma_i <= 0 or det_Sigma_j <= 0:
            return float('inf')
            
        term2 = 0.5 * np.log(det_Sigma / np.sqrt(det_Sigma_i * det_Sigma_j))
        
        return term1 + term2

    # Helper to calculate merged Gaussian parameters
    def merge_gaussians(node_i, node_j):
        mu_i = node_i.mu
        mu_j = node_j.mu
        Sigma_i = node_i.Sigma
        Sigma_j = node_j.Sigma
        
        Sigma_sum = Sigma_i + Sigma_j
        Sigma_sum_inv = np.linalg.inv(Sigma_sum)
        
        # Sigma_p = Sigma_j * (Sigma_i + Sigma_j)^-1 * Sigma_i
        Sigma_p = np.dot(Sigma_j, np.dot(Sigma_sum_inv, Sigma_i))
        
        # Mu_p = Sigma_j * (Sigma_i + Sigma_j)^-1 * Mu_i + Sigma_i * (Sigma_i + Sigma_j)^-1 * Mu_j
        Mu_p = np.dot(Sigma_j, np.dot(Sigma_sum_inv, mu_i)) + np.dot(Sigma_i, np.dot(Sigma_sum_inv, mu_j))
        
        return Mu_p, Sigma_p

    N = len(leaf_nodes)
    
    for i in range(N):
        # Skip if already merged into a previous node
        if leaf_nodes[i].is_merged:
            continue
            
        current_node = leaf_nodes[i]
        
        for j in range(i + 1, N):
            # Skip if j is already merged
            if leaf_nodes[j].is_merged:
                continue
                
            # Check Bhattacharya distance
            db_dist = bhattacharya_distance(current_node, leaf_nodes[j])
            
            # Check plane descriptor similarity
            # Normalize descriptors for dot product
            z_i = current_node.z / (np.linalg.norm(current_node.z) + 1e-8)
            z_j = leaf_nodes[j].z / (np.linalg.norm(leaf_nodes[j].z) + 1e-8)
            cosine_sim = np.dot(z_i, z_j)
            sim_diff = 1.0 - cosine_sim
            
            if db_dist <= epsilon_b and sim_diff <= epsilon_z:
                # Merge j into i
                mu_p, Sigma_p = merge_gaussians(current_node, leaf_nodes[j])
                
                # Update current_node to be the parent
                current_node.mu = mu_p
                current_node.Sigma = Sigma_p
                # Note: Normal and descriptor updates are not specified in the source for the merge step [G]
                # Typically, these might be weighted averages or kept from the dominant child, 
                # but the source only defines Mu and Sigma for the merge [S1].
                
                # Mark j as merged
                leaf_nodes[j].is_merged = True
                
                # Break inner loop as i has been merged with j
                break
        
        # Add the resulting node (either original or merged) to the output list
        merged_nodes.append(current_node)
        
    return merged_nodes
```

**Edge Cases and Pitfalls:**
*   **Computational Expense:** Raw Gaussian primitives from optimization are not used as leaf nodes due to their large number; they must be pre-clustered into local clusters [S1].
*   **Descriptor Learning:** Plane descriptors $z$ and normals $n$ are learned via auxiliary losses (normal loss from 2D normal maps, descriptor loss from 2D SAM masks) during the optimization phase, not during tree construction [S1].
*   **Numerical Stability:** Inverting covariance matrices and computing determinants can be unstable if matrices are singular or near-singular. [G] Regularization or checking condition numbers is recommended.

## Operating characteristics
*   **Time Complexity:** The algorithm involves nested loops over $N_s$ leaf nodes, resulting in $O(N_s^2)$ comparisons in the worst case. Each comparison involves matrix inversion and determinant calculation, which is $O(1)$ for fixed 3D dimensions but costly in practice.
*   **Memory Complexity:** $O(N_s)$ to store the leaf nodes and the resulting tree structure.
*   **Strengths:** Explicitly models 3D plane instances, improving geometric consistency and enabling plane-aware rendering or compression.
*   **Limitations:** Requires pre-clustering of primitives. The merging criteria depend on learned descriptors, which adds complexity to the training pipeline.
*   **When to use:** When geometric structure (planes) is important for the application, such as in architectural scenes or when compressing Gaussians by merging planar regions.

## Background
The Gaussian Mixture Tree was introduced in "Planar Gaussian Splatting" [S1]. The method builds on the standard 3D Gaussian Splatting framework but adds a probabilistic hierarchical modeling step to identify distinct 3D planes. It uses Gaussian Mixture Models to join nodes recursively from leaves to the root. The plane descriptors are learned by leveraging 2D Segment Anything Model (SAM) masks and normal maps [S1].
