# Scaffold-GS

Also called: Scaffold-Gaussian Splatting, Structured 3D Gaussians, Structured 3D Gaussians for View-Adaptive Rendering

## Overview
Scaffold-GS is a Gaussian-based scene representation that utilizes anchor points to establish a hierarchical and region-aware 3D scene structure, predicting neural Gaussian attributes on-the-fly based on viewing direction and distance [S2]. Unlike vanilla 3D-GS, which allows 3D Gaussians to freely drift and split, Scaffold-GS exploits scene structure to guide and constrain the distribution of 3D Gaussians while allowing local adaptation to varying viewing angles [S2]. It achieves comparable or superior rendering quality to 3D-GS with significantly reduced storage requirements and real-time rendering speeds [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Sparse Structure-from-Motion (SfM) point cloud $P \in \mathbb{R}^{M \times 3}$ [S2].
*   **Output:** A set of anchor points with learnable features, and a rendering pipeline that dynamically spawns and rasterizes neural Gaussians [S2].

**Data Structures:**
1.  **Voxel Grid:** Created from SfM points. Each voxel center $v \in V \in \mathbb{R}^{N \times 3}$ serves as an anchor point [S2].
2.  **Anchor Attributes:** Each anchor $v$ stores:
    *   Local context feature $f_v \in \mathbb{R}^{32}$ [S2].
    *   Scaling factor $l_v \in \mathbb{R}^3$ [S2].
    *   $k$ learnable offsets $O_v \in \mathbb{R}^{k \times 3}$ [S2].
3.  **Neural Gaussians:** Spawned dynamically from anchors. Each Gaussian $i$ has position $\mu_i$, opacity $\alpha_i$, color $c_i$, quaternion $q_i$, and scale $s_i$ [S2].

**Parameters:**
*   $k$: Number of neural Gaussians spawned per visible anchor. Default: 10 [S2].
*   $\epsilon$: Voxel size for initialization [S2].
*   $\epsilon_g$: Base voxel size for growing operation [S2].
*   $\tau_g$: Gradient threshold for anchor growing. Default: $64\epsilon$ (or $16\epsilon$ for intricate/texture-less scenes) [S2].
*   $N$: Number of training iterations over which gradients/opacity are averaged for growing/pruning. Default: 100 [S2].
*   $\tau_\alpha$: Opacity threshold for rasterization. Only Gaussians with $\alpha \ge \tau_\alpha$ are rasterized [S2].
*   MLP Architecture: All MLPs ($F_\alpha, F_c, F_q, F_s, F_w$) are 2-layer MLPs with ReLU activation. Hidden unit dimensions are 32 [S2].
*   Loss weights: $\lambda_{SSIM} = 0.2$, $\lambda_{vol} = 0.001$ [S2].

**Steps:**

1.  **Anchor Initialization:**
    Voxelize the input SfM point cloud $P$ to create voxel centers $V$:
    $$ V = \{ \lfloor P / \epsilon \rfloor \cdot \epsilon \} $$
    Remove duplicate entries [S2]. For each voxel $v$, initialize anchor attributes: $f_v \in \mathbb{R}^{32}$, $l_v \in \mathbb{R}^3$, and $O_v \in \mathbb{R}^{k \times 3}$ [S2].

2.  **Neural Gaussian Derivation (On-the-fly Prediction):**
    For each camera position $x_c$ and visible anchor $x_v$ within the view frustum:
    a. Calculate relative distance $\delta_{vc}$ and viewing direction $\vec{d}_{vc}$:
    $$ \delta_{vc} = \| x_v - x_c \|_2 $$
    $$ \vec{d}_{vc} = \frac{x_v - x_c}{\| x_v - x_c \|_2} $$
    b. Create a multi-resolution feature bank $\{ f_v, f_{v\downarrow 1}, f_{v\downarrow 2} \}$, where $\downarrow n$ denotes $f_v$ down-sampled by $2^n$ factors [S2].
    c. Predict view-dependent blending weights using MLP $F_w$:
    $$ \{ w, w_1, w_2 \} = \text{Softmax}(F_w(\delta_{vc}, \vec{d}_{vc})) $$
    d. Compute integrated anchor feature $\hat{f}_v$:
    $$ \hat{f}_v = w \cdot f_v + w_1 \cdot f_{v\downarrow 1} + w_2 \cdot f_{v\downarrow 2} $$
    e. Spawn $k$ neural Gaussians. Positions are calculated as:
    $$ \{ \mu_0, \dots, \mu_{k-1} \} = x_v + \{ O_0, \dots, O_{k-1} \} \cdot l_v $$
    f. Decode attributes (opacity $\alpha$, color $c$, quaternion $q$, scale $s$) in one-pass from $\hat{f}_v$, $\delta_{vc}$, and $\vec{d}_{vc}$ via MLPs $F_\alpha, F_c, F_q, F_s$. For example:
    $$ \{ \alpha_0, \dots, \alpha_{k-1} \} = F_\alpha(\hat{f}_v, \delta_{vc}, \vec{d}_{vc}) $$
    g. Filter Gaussians: Only keep those with $\alpha \ge \tau_\alpha$ [S2].

3.  **Rendering:**
    Project the 3D Gaussians to 2D using the covariance matrix $\Sigma = RSS^T R^T$ [S2]. Render using alpha-blending:
    $$ C(x') = \sum_{i \in N} c_i \sigma_i \prod_{j=1}^{i-1} (1 - \sigma_j) $$
    where $\sigma_i = \alpha_i G'_i(x')$ and $G'_i(x')$ is the 2D Gaussian kernel [S2, Parent].

4.  **Anchor Refinement (Growing and Pruning):**
    Performed every $N$ iterations [S2].
    a. **Growing:** Quantize neural Gaussians into multi-resolution voxels of size $\epsilon_g^{(m)} = \epsilon_g / 4^{m-1}$ for levels $m \in \{1, 2, 3\}$. Compute averaged gradients $\nabla_g$ over $N$ iterations. If $\nabla_g > \tau_g^{(m)} = \tau_g \cdot 2^{m-1}$, deploy a new anchor at the voxel center if none exists. Apply random elimination to candidates to regulate addition [S2].
    b. **Pruning:** Accumulate opacity values of neural Gaussians associated with an anchor over $N$ iterations. If accumulated opacity $< 0.5$, remove the anchor [S2].

5.  **Optimization:**
    Optimize learnable parameters and MLPs using the loss function:
    $$ L = L_1 + \lambda_{SSIM} L_{SSIM} + \lambda_{vol} L_{vol} $$
    Train for 30k iterations [S2].

## Subtopics

### [Scaffold-GS Integration](12513-scaffold-gs-integration.md)
Applies DART and AGE modules to the Scaffold-GS backbone. It augments the anchor-seeding SfM cloud before optimization and gates primitive growth during it, without modifying the rendering path or the optimizer. It is distinct from representation-level changes by operating as a backbone-agnostic add-on targeting sparse initialization regions.

## Operating characteristics
*   **Time Complexity:** Rendering speed is around 100 FPS at 1K resolution, comparable to original 3D-GS with little computational overhead [S2].
*   **Memory Complexity:** Storage requirements are significantly reduced. On Mip-NeRF360, storage is reduced by 4.4x (156 MB vs 693 MB); on Deep Blending, by 10.2x (66 MB vs 676 MB) [S2].
*   **Strengths:** Exploits scene structure to guide Gaussian distribution, robust to view changes, real-time rendering, compact storage [S2].
*   **Limitations:** Relies on initial SfM points; performance may vary if SfM initialization is poor (though growing/pruning helps) [S2].
*   **When to use:** When storage efficiency and real-time rendering are critical, and scene structure is well-captured by SfM [S2].
*   **When not to use:** If SfM initialization is very sparse or noisy and growing/pruning cannot recover the structure efficiently [S2].

## Background
Scaffold-GS was introduced by Tao Lu, Mulin Yu, Linning Xu, Yuanbo Xiangli, Limin Wang, Dahua Lin, and Bo Dai from Shanghai Artificial Intelligence Laboratory, The Chinese University of Hong Kong, Nanjing University, and Cornell University [S2]. It was published in CVPR 2024 (arXiv:2312.00109v1, Nov 2023) [S2]. The method addresses the limitations of vanilla 3D-GS, such as free drifting of Gaussians and lack of structural constraints, by introducing a hierarchical representation anchored to a sparse grid derived from SfM points [S2].
