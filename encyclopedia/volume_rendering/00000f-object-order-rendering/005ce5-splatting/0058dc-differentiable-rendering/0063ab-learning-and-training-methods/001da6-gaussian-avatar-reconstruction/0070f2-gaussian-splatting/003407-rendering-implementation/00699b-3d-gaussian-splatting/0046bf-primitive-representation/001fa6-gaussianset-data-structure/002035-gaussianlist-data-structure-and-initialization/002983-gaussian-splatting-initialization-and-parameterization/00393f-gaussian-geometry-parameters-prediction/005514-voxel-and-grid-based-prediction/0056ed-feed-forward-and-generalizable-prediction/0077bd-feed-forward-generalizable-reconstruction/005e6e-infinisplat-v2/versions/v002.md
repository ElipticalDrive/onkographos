# InfiniSplat v2
Also called: InfiniSplat

## Overview
InfiniSplat v2 is a feed-forward Gaussian reconstruction method for arbitrary input views that decouples geometry and attribute prediction, uses ground-truth (GT) camera poses for alignment during training, and employs large-angle target view supervision to improve rendering quality under large viewpoint changes [S1, unofficial]. It differs from its siblings by freezing the geometry branch to prevent geometric degradation caused by joint optimization, and by using GT poses for alignment to avoid pose errors that misguide the network under large-angle supervision [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $N$ input RGB images $I_C = \{I_i\}_{i \in C}$ and optional pose conditions $Q_C$ (camera intrinsics and poses). In the pose-free setting, $Q_C = \emptyset$ [S1, unofficial].
*   **Outputs:** A set of $M$ 3D Gaussians $\mathcal{G} = \{(\mu_m, \xi_m)\}_{m=1}^M$, where $\mu_m \in \mathbb{R}^3$ is the center and $\xi_m = (\alpha_m, s_m, q_m, c_m)$ contains opacity, three-axis scale, rotation (quaternion), and zeroth-order spherical harmonic (SH) color [S1, unofficial].

**Data Structures:**
*   **Gaussian Set:** A list of $M$ Gaussians. Each Gaussian stores $\mu_m, \alpha_m, s_m, q_m, c_m$ [S1, unofficial].
*   **KNN Graph:** A global graph used for Stage II refinement. Nodes are Gaussians. Edges connect each point to its 8 nearest neighbors in feature space [S1, unofficial].
*   **Hidden State:** A 16-dimensional vector $h_m$ per Gaussian, updated during Stage II [S1, unofficial].

**Parameters:**
*   Voxel merging side length: $0.004$ (in scale-normalized reconstruction frame) [S1, unofficial].
*   Opacity pruning threshold $\tau_\alpha$: $0.01$ [S1, unofficial].
*   Mask thresholds: $\tau_{abs} = 0.03$, $\tau_{rel} = 0.01$ [S1, unofficial].
*   Stage I learning rates: $10^{-6}$ for last 10 attribute-backbone Transformer blocks, $2 \times 10^{-4}$ for Gaussian head [S1, unofficial].
*   Stage I training steps: $25,000$ steps, $2,000$ steps linear warmup, cosine decay to $0.1$ times peaks [S1, unofficial].
*   Stage II learning rate: $2 \times 10^{-4}$, cosine decay to $0.1$ times initial value, $5,000$ steps [S1, unofficial].
*   Optimizer: AdamW with $\beta = (0.9, 0.95)$, global batch size $16$, global L2 gradient clipping at $1.0$ [S1, unofficial].
*   Rendering: `gsplat` with `eps2d` = $10^{-2}$ [S1, unofficial].

**Steps:**

1.  **Dual-Branch Feature Extraction:**
    *   Initialize two branches from pretrained DA3 weights [S1, unofficial].
    *   **Geometry Branch ($\Phi_{geo}$):** Frozen. Predicts depths $\hat{C}$ and cameras $\hat{\Pi}_C$ from $I_C$ and $Q_C$ [S1, unofficial].
    *   **Attribute Branch ($\Phi_{attr}$):** Trainable (last $K$ Transformer blocks fine-tuned). Produces multi-layer patch features $F_C$ from $I_C$ and $Q_C$ [S1, unofficial].

2.  **Scale Alignment and Point Construction (Stage I):**
    *   Express predicted and GT poses relative to their respective reference cameras (first input view in sorted order) [S1, unofficial].
    *   Normalize predicted depths and translations by $s_{norm} > 0$ [S1, unofficial].
    *   Fit an Umeyama similarity transform from the GT trajectory to the normalized predicted trajectory using only input-camera center correspondences. Retain its scale $s_C$ [S1, unofficial].
    *   Apply scale alignment to GT translations: $t^\star_v = s_C t^\star_v$, while rotations remain unchanged: $R^\star_v = R^\star_v$ [S1, unofficial].
    *   Construct Gaussian centers $\mu_m$ from normalized predicted $z$-depth, GT intrinsics, and scale-aligned GT poses [S1, unofficial].
    *   Use a DPT decoder to map $F_C$ to per-pixel attributes $\xi$ [S1, unofficial].
    *   Merge Gaussians using voxel merging with side length $0.004$ [S1, unofficial].
    *   Prune Gaussians with opacity $\alpha_m < \tau_\alpha = 0.01$ [S1, unofficial].
    *   Let the initial scene be $\mathcal{G}_0$ with $M$ Gaussians [S1, unofficial].

3.  **Stage I Rendering and Loss:**
    *   Render $\mathcal{G}_0$ into input views $C$ and target views $T$: $\hat{I}_{bv} = \mathcal{R}(\mathcal{G}_0; \Pi^\star_v)$ for $v \in V = C \cup T$ [S1, unofficial].
    *   Construct visibility masks $M_v$ for target views:
        *   Retain pixel if GT depth $> 10^{-6}$ and passes validity mask [S1, unofficial].
        *   Retain if at least one input view places it in front of camera and within bounds [S1, unofficial].
        *   Retain if $|z_{proj} - d_{src}| \le \max(\tau_{abs}, \tau_{rel} d_{src})$, where $z_{proj}$ is point depth in input camera, $d_{src}$ is sampled depth [S1, unofficial].
    *   Compute LPIPS spatial distance map $d_v = \text{LPIPS}_{spatial}(M_v \odot \hat{I}_v, M_v \odot I_v)$, zeroing invalid regions before normalization [S1, unofficial].
    *   Compute Stage I loss $\mathcal{L}_I$ aggregating L1 error $e_v$ and $d_v$ over valid pixels $M_v(p)$ [S1, unofficial]:
        $$ \mathcal{L}_I = \frac{\sum_{v \in V} \sum_p M_v(p) [e_v(p) + d_v(p)]}{\max(1, \sum_{v \in V} \sum_p M_v(p))} $$
    *   Update $\Phi_{attr}$ and Gaussian head using $\mathcal{L}_I$ [S1, unofficial].

4.  **Stage II Refinement (Iterative):**
    *   **Feature Projection:** Project DPT features to 8 channels via learnable $1 \times 1$ conv, merge using Gaussian voxel groups/weights, and reuse [S1, unofficial].
    *   **Initialization:** Linear projection initializes 16-dim hidden state $h_m$ for each Gaussian [S1, unofficial].
    *   **Input to Refiner:** Concatenate image features, current attributes ($\xi_m$), gradient feedback, neighbor distances, and hidden states $h_m$. Project to 64 dims [S1, unofficial].
    *   **KNN Transformer Blocks:** Process through four blocks. Each block:
        *   Single-head attention over 8 neighbors [S1, unofficial].
        *   LayerNorm, MLP, residual connections [S1, unofficial].
        *   Output concatenated with original input, MLP predicts attribute increments $\Delta \xi_m$ and hidden-state increments $\Delta h_m$ [S1, unofficial].
    *   **Attribute Updates:**
        *   Scales: $s_{new} = s_{old} \exp(\Delta \log s)$ without residual clipping [S1, unofficial].
        *   Opacity-logit, local rotation-vector, RGB-logit increments: $a \tanh(\text{raw})$ with $a = 0.1, 0.25, 1.0$ respectively [S1, unofficial].
        *   Hidden-state increments: $0.1 \tanh(\text{raw})$ [S1, unofficial].
        *   Logit inputs clamped to $[10^{-6}, 1-10^{-6}]$ [S1, unofficial].
        *   Gaussian centers, counts, and correspondence remain fixed [S1, unofficial].
    *   **Feedback Loss:** Render current scene into input views. Compute $\ell_{fb} = 0.8 L_1 + 0.2 L_{DSSIM}$, where $L_{DSSIM} = (1 - \text{SSIM})/2$ over valid regions [S1, unofficial].
    *   **Gradient Handling:** Gradients w.r.t Gaussian attributes are normalized and detached before entering the shared updater [S1, unofficial].
    *   **Outer Loss:** For each supervised view (input and target, weight 0.5 each), compute $\ell_{out} = 0.8 L_1 + 0.2 L_{DSSIM} + 0.5 L_{LPIPS}$ [S1, unofficial].
    *   **Multi-step Objective:** Sample $K_r \in \{1, 2, 3\}$ updates during training, use 3 at inference.
        $$ \mathcal{L}_{II} = \sum_{k=1}^{K_r} 0.9^{K_r-k} \mathcal{L}_k^{render} + 0.1 \mathcal{L}_{opacity} $$
        where $\mathcal{L}_k^{render}$ is the grouped outer loss after update $k$ [S1, unofficial].
    *   **Opacity Regularization:**
        $$ \mathcal{L}_{opacity} = \frac{1}{M} \sum_{m=1}^M [\text{logit}_\epsilon(\alpha_m^{K_r}) - \text{logit}_\epsilon(\alpha_m^0)]^2, \quad \epsilon = 10^{-6} $$
        where $\text{logit}_\epsilon(x) = \log(x / (1-x))$ clamped to valid range [S1, unofficial].
    *   **First-Order Surrogate Loss:** To stabilize training, rendering gradients are computed on independent leaf copies $z_k = \text{sg}(x_k)$ (where $x_k$ collects updated parameters):
        $$ r_k = \text{sg}(\nabla_z \mathcal{L}_{render}(z_k)) $$
        $$ \mathcal{L}_k^{proxy} = \text{sg}(\mathcal{L}_{render}(z_k)) + \langle x_k - \text{sg}(x_k), r_k \rangle $$
        Gradients flow through $\mathcal{L}_k^{proxy}$ [S1, unofficial].
    *   **Chunked Execution:**
        *   Reuse global KNN graph [S1, unofficial].
        *   Stable sort along longest voxel-coordinate axis [S1, unofficial].
        *   Expand core sets of at most $200,000$ points with four-hop neighborhoods [S1, unofficial].
        *   Recursively bisect chunks exceeding $300,000$ points by point count along core sets' longest axes, recomputing neighborhoods [S1, unofficial].
        *   Retain only core-point outputs. Use gradient checkpointing [S1, unofficial].

import torch
import torch.nn as nn
import torch.nn.functional as F

def umeyama_scale(source, target):
    """Compute scale s from Umeyama alignment between source and target point sets."""
    mu_s = source.mean(dim=0)
    mu_t = target.mean(dim=0)
    X = source - mu_s
    Y = target - mu_t
    H = X.T @ Y
    U, S, Vt = torch.linalg.svd(H)
    d = (torch.linalg.det(U) * torch.linalg.det(Vt.T)) < 0.0
    if d:
        S[-1] = -S[-1]
        U[:, -1] = -U[:, -1]
    R = U @ Vt
    var_s = torch.sum(X**2, dim=1).mean()
    return torch.sum(S) / var_s

def logit(x, eps=1e-6):
    x = torch.clamp(x, min=eps, max=1-eps)
    return torch.log(x / (1 - x))

def sigmoid(x):
    return 1.0 / (1.0 + torch.exp(-x))

def vec_to_quat(v):
    return v  # Simplified: assumes v is already a valid quaternion representation

def logit_to_rgb(x):
    return sigmoid(x)

def back_project(depth, intrinsics, poses):
    """Back-project depth map to 3D points using intrinsics and poses."""
    H, W = depth.shape
    y, x = torch.meshgrid(torch.arange(H), torch.arange(W), indexing='ij')
    fx, fy, cx, cy = intrinsics
    z = depth
    X = (x - cx) * z / fx
    Y = (y - cy) * z / fy
    points = torch.stack([X, Y, z], dim=-1).reshape(-1, 3)
    # Apply pose transformation (simplified for pseudocode)
    return points

def merge_voxels(centers, attributes, voxel_size=0.004):
    """Merge Gaussians within voxel grid."""
    # Simplified: returns inputs as-is for structural clarity
    return centers, attributes

def prune_opacity(centers, attributes, threshold=0.01):
    """Remove Gaussians with opacity below threshold."""
    mask = attributes[:, 0] >= threshold
    return centers[mask], attributes[mask]

def project_features(features):
    """Project features to 8 channels via 1x1 conv."""
    return F.conv2d(features, nn.Parameter(torch.randn(8, features.shape[1], 1, 1)))

def build_knn_graph(points, k=8):
    """Build KNN graph for points."""
    # Simplified: returns dummy indices for structural clarity
    return torch.arange(points.shape[0]).unsqueeze(1).repeat(1, k)

def prepare_refiner_input(features, attributes, hidden_states, knn_indices):
    """Concatenate image features, attributes, hidden states, and neighbor distances."""
    # Simplified concatenation logic
    return torch.cat([features, attributes, hidden_states], dim=-1)

def predict_increments(output_tensor):
    """MLP predicts attribute and hidden-state increments."""
    # Simplified: splits output tensor
    delta_attributes = output_tensor[..., :4]
    delta_hidden = output_tensor[..., 4:]
    return delta_attributes, delta_hidden

def compute_feedback_loss(rendered, gt, masks):
    """Compute feedback loss: 0.8*L1 + 0.2*L_DSSIM."""
    l1 = torch.abs(rendered - gt)
    dssim = (1 - ssim(rendered, gt)) / 2
    return 0.8 * l1 + 0.2 * dssim

def compute_outer_loss(rendered, gt, masks):
    """Compute outer loss: 0.8*L1 + 0.2*L_DSSIM + 0.5*L_LPIPS."""
    l1 = torch.abs(rendered - gt)
    dssim = (1 - ssim(rendered, gt)) / 2
    lpips = lpips_spatial(rendered, gt)
    return 0.8 * l1 + 0.2 * dssim + 0.5 * lpips

def opacity_regularization(opacity_logit):
    """Compute opacity regularization loss."""
    eps = 1e-6
    return torch.mean((logit(opacity_logit) - logit(opacity_logit.detach()))**2)

def construct_visibility_mask(view, gt_depths, tau_abs=0.03, tau_rel=0.01):

    mask = (gt_depths > 1e-6).float()

    return mask

    return torch.zeros_like(rendered)

    """Compute SSIM."""
    # Simplified: returns dummy tensor for structural clarity
    return torch.ones_like(rendered)

class InfiniSplatV2:
    def __init__(self):
        self.phi_geo = None
        self.phi_attr = None
        self.gaussian_head = None
        self.refiner = None

    def stage_i(self, images, gt_poses=None):
        pred_depth, pred_cameras = self.phi_geo(images)
        features = self.phi_attr(images)
        
        # Scale alignment
        s_C = umeyama_scale(gt_poses.translation, pred_cameras.translation)
        aligned_gt_poses = gt_poses.clone()
        aligned_gt_poses.translation *= s_C
        
        # Point construction
        centers = back_project(pred_depth, gt_poses.intrinsics, aligned_gt_poses)
        
        # Attribute prediction
        attributes = self.gaussian_head(features)
        
        # Voxel merging and pruning
        centers, attributes = merge_voxels(centers, attributes, voxel_size=0.004)
        centers, attributes = prune_opacity(centers, attributes, threshold=0.01)
        
        return centers, attributes

    def stage_i_loss(self, centers, attributes, images, gt_poses, target_views):
        rendered_images = {v: render(centers, attributes, v.pose, v.intrinsics) for v in target_views}
        masks = {v: construct_visibility_mask(v, gt_poses, tau_abs=0.03, tau_rel=0.01) for v in target_views}
        
        total_loss = 0.0
        total_weight = 0
        for v in target_views:
            mask = masks[v]
            l1_error = torch.abs(rendered_images[v] - v.gt_image)
            lpips = lpips_spatial(mask * rendered_images[v], mask * v.gt_image)
            valid_pixels = mask.sum()
            if valid_pixels > 0:
                loss_v = (mask * (l1_error + lpips)).sum() / valid_pixels
                total_loss += loss_v
                total_weight += 1
        return total_loss / max(1, total_weight)

    def stage_ii_refine(self, centers, attributes, images, gt_poses, target_views, num_steps=3):
        hidden_states = torch.zeros(centers.shape[0], 16)
        projected_features = project_features(self.phi_attr(images))
        knn_indices = build_knn_graph(centers, k=8)
        
        for step in range(num_steps):
            input_tensor = prepare_refiner_input(projected_features, attributes, hidden_states, knn_indices)
            output_tensor = self.refiner(input_tensor)
            delta_attributes, delta_hidden = predict_increments(output_tensor)
            
            # Update scales
            attributes.scales = attributes.scales * torch.exp(delta_attributes.log_scale)
            # Update logits with tanh scaling
            attributes.opacity_logit = attributes.opacity_logit + 0.1 * torch.tanh(delta_attributes.opacity_logit)
            attributes.rotation_vec = attributes.rotation_vec + 0.25 * torch.tanh(delta_attributes.rotation_vec)
            attributes.rgb_logit = attributes.rgb_logit + 1.0 * torch.tanh(delta_attributes.rgb_logit)
            attributes.opacity_logit = torch.clamp(attributes.opacity_logit, min=1e-6, max=1-1e-6)

                total_loss = 0.9**(num_steps-1-step) * outer_loss + 0.1 * opacity_loss
        return centers, attributes

## Operating characteristics
*   **Time and Memory Complexity:** Stage I is dominated by the forward pass of the DA3 backbone and DPT decoder, which is $O(N \cdot H \cdot W)$ for $N$ input images. Stage II involves iterative refinement with KNN graph operations. The chunked execution limits memory usage by processing core sets of at most $200,000$ points and recursively bisecting larger chunks. The global KNN graph is reused, reducing recomputation [S1, unofficial].
*   **Measured Performance:** On six datasets (DL3DV, ETH3D, NRGBD, Mip-NeRF 360, RE10K, DTU), InfiniSplat v2 achieves state-of-the-art mean LPIPS and DISTS in both pose-conditioned and pose-free settings. In the pose-conditioned setting, mean LPIPS and DISTS decrease by 25.8% and 32.9%, respectively, compared to the strongest evaluated baselines [S1, unofficial].
*   **Scaling:** The method scales to $N=4, 8, 16$ input views. Training uses 16 H20 GPUs with a global batch size of 16. Stage I takes ~48 hours, Stage II takes ~13 hours [S1, unofficial].
*   **Strengths:** Decoupling geometry and attribute prediction prevents geometric degradation. Using GT poses for alignment avoids pose errors under large-angle supervision. Large-angle target view supervision improves rendering quality under large viewpoint changes. Opacity learning suppresses geometrically inconsistent points (outliers) [S1, unofficial].
*   **Limitations:** Relies on GT camera poses for alignment during training, which may not be available in fully pose-free settings (though it supports pose-free inference by using reference cameras for scale estimation). Joint optimization of geometry and attributes is avoided, which might limit the ability to correct gross geometric errors [S1, unofficial].
*   **When to use:** When high-quality novel view rendering under large viewpoint changes is required, and GT camera poses are available for training alignment [S1, unofficial].
*   **When not to use:** When computational resources for training are limited (Stage I and II training are non-trivial). When GT poses are not available and pose-free inference quality is critical without the benefit of GT alignment during training (though it supports pose-free inference, the alignment strategy is specific to training) [S1, unofficial].

## Background
InfiniSplat v2 was introduced by Lin et al. in 2025/2026 as an improvement over DA3-GS and InfiniSplat. It addresses limitations in Gaussian attribute learning, specifically flying-point artifacts and poor performance under large viewpoint changes. The method builds on the Depth Anything 3 (DA3) backbone [S1, unofficial].
