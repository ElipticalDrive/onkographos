# Smoothed 2D Supervision

Also called: Adaptive Gaussian blur strategy, Progressive Gaussian Blurring

## Overview
Smoothed 2D Supervision is a regularization technique that stabilizes the joint optimization of camera poses and 3D scene representations by blurring 2D training images with scheduled Gaussian kernels [S2, unofficial][S3]. It solves the problem of noisy gradients and high-frequency overfitting during early training stages, which can destabilize camera alignment and lead to poor geometric fidelity [S2, unofficial]. Unlike [Frequency Regularization](6130-frequency-regularization.md), which operates in the Fourier domain using positional encodings, Smoothed 2D Supervision applies spatial-domain smoothing directly to the target images, providing a simpler, handcrafted alternative that restricts the spectrum of the learned scene [S3].

## How it works
**Inputs and Outputs:**
*   **Input:** 2D training images $I_{raw}$, current iteration $t$, total iterations $T_{max}$, kernel schedule parameters ($\sigma_{start}, \sigma_{end}, k_b$), and image resolution.
*   **Output:** Smoothed supervision images $I_{smooth}$ used in the rendering loss calculation.

**Data Structures:**
*   **Gaussian Kernel:** A 2D separable Gaussian kernel $K(x, y)$ defined by standard deviation $\sigma$ and kernel size $N \times N$.
    *   $N$ is typically odd (e.g., 9).
    *   $\sigma$ controls the spread of the blur.

**Algorithm Steps:**
1.  **Initialize Schedule:** Define the initial standard deviation $\sigma_{start}$ and final standard deviation $\sigma_{end}$ (often 0). Define the interval $k_b$ (e.g., 100 iterations) at which the kernel parameters are updated [S4].
2.  **Compute Current $\sigma$:** For the current iteration $t$, calculate the current standard deviation $\sigma_t$.
    *   Linear decay: $\sigma_t = \sigma_{start} - \frac{\sigma_{start} - \sigma_{end}}{T_{max}} \cdot t$ [S2, unofficial][S4].
    *   Note: Some implementations reduce $\sigma$ exponentially or keep it constant until a certain threshold [S2, unofficial].
3.  **Compute Kernel Size:** Determine the kernel size $N_t$.
    *   Standard practice: Start with $N=9$ and reduce it as $\sigma$ decreases [S4].
    *   If downsampling is active, scale the kernel size by the downsampling factor to maintain effective coverage relative to the original resolution [S4].
4.  **Apply Blur:** Convolve the raw training image $I_{raw}$ with the 2D Gaussian kernel $K_t$ defined by $\sigma_t$ and $N_t$ to produce $I_{smooth}$ [S2, unofficial].
    *   $I_{smooth} = I_{raw} * K_t$
5.  **Compute Loss:** Calculate the rendering loss (e.g., L1 or L2) between the rendered image $I_{render}$ and the smoothed image $I_{smooth}$ [S2, unofficial][S3].
6.  **Update:** Backpropagate the loss to update Gaussian parameters and camera poses [S2, unofficial].

**Pseudocode:**
```python
def compute_smoothed_supervision(raw_image, iteration, total_iterations, 
                                 sigma_start=2.4, sigma_end=0.0, 
                                 kernel_start_size=9, kb=100, 
                                 downsampling_scale=1.0):
    """
    Computes the smoothed 2D supervision image for the current iteration.
    
    Args:
        raw_image: 2D numpy array of the training image.
        iteration: Current training iteration index.
        total_iterations: Total number of training iterations.
        sigma_start: Initial standard deviation for the Gaussian kernel.
        sigma_end: Final standard deviation (usually 0).
        kernel_start_size: Initial kernel size (N x N).
        kb: Number of iterations between kernel size updates.
        downsampling_scale: Factor by which the image is downsampled (1.0 for no downsampling).
        
    Returns:
        smoothed_image: The blurred version of raw_image.
    """
    # 1. Calculate current sigma
    # Linear decay from sigma_start to sigma_end over total_iterations
    if total_iterations > 0:
        sigma = sigma_start - (sigma_start - sigma_end) * (iteration / total_iterations)
    else:
        sigma = sigma_start
        
    # Clamp sigma to be non-negative
    sigma = max(0.0, sigma)
    
    # 2. Determine kernel size
    # Reduce kernel size every kb iterations
    # The kernel size should also account for downsampling to maintain effective resolution
    # Note: Exact formula for kernel size reduction is not explicitly detailed in sources,
    # but it is stated to be lowered before densification and scaled by downsampling.
    # A common implementation reduces N as sigma decreases.
    # Here we assume a linear reduction of kernel size proportional to sigma,
    # or a step-wise reduction. The source [S4] mentions lowering kernel size.
    # We implement a simple linear scaling of kernel size based on sigma ratio.
    
    sigma_ratio = sigma / sigma_start if sigma_start > 0 else 0.0
    current_kernel_size = int(kernel_start_size * sigma_ratio)
    
    # Ensure kernel size is at least 1 and odd
    if current_kernel_size < 1:
        current_kernel_size = 1
    if current_kernel_size % 2 == 0:
        current_kernel_size += 1
        
    # Adjust for downsampling: if image is downsampled, the effective kernel size
    # in the original resolution space is larger, but we apply blur on the 
    # downsampled image. The source [S4] says "lower the kernel size by the scale 
    # of downsampling at the current stage". This implies the kernel size parameter
    # passed to the blur function should be smaller if the image is smaller.
    # However, standard convolution applies the kernel to the input image.
    # If we are blurring the downsampled image, we use the kernel size relative to that image.
    # The note suggests adjusting the hyperparameter choice. 
    # Let's assume the kernel size is scaled down by the downsampling factor.
    adjusted_kernel_size = max(1, int(current_kernel_size / downsampling_scale))
    if adjusted_kernel_size % 2 == 0:
        adjusted_kernel_size += 1
        
    # 3. Apply Gaussian Blur
    # Create a 2D Gaussian kernel
    # Since the kernel is separable, we can apply 1D blurs sequentially for efficiency
    kernel_1d = create_gaussian_kernel_1d(adjusted_kernel_size, sigma)
    
    # Apply horizontal blur
    blurred_image = apply_1d_convolution(raw_image, kernel_1d, axis=1)
    # Apply vertical blur
    smoothed_image = apply_1d_convolution(blurred_image, kernel_1d, axis=0)
    
    return smoothed_image

def create_gaussian_kernel_1d(size, sigma):
    """Creates a 1D Gaussian kernel."""
    center = size // 2
    kernel = np.exp(-0.5 * ((np.arange(size) - center) / sigma) ** 2)
    return kernel / np.sum(kernel)

def apply_1d_convolution(image, kernel, axis):
    """Applies 1D convolution along a specific axis."""
    # Padding is required to maintain image size
    pad_size = len(kernel) // 2
    if axis == 1: # Horizontal
        padded = np.pad(image, ((0, 0), (pad_size, pad_size)), mode='reflect')
        # Convolve each row
        result = np.zeros_like(image)
        for i in range(image.shape[0]):
            result[i, :] = np.convolve(padded[i, :], kernel, mode='valid')
        return result
    else: # Vertical
        padded = np.pad(image, ((pad_size, pad_size), (0, 0)), mode='reflect')
        # Convolve each column
        result = np.zeros_like(image)
        for j in range(image.shape[1]):
            result[:, j] = np.convolve(padded[:, j], kernel, mode='valid')
        return result
```

**Parameters:**
*   $\sigma_{start}$: Initial standard deviation. Typical value: 2.4 [S4].
*   $\sigma_{end}$: Final standard deviation. Typical value: 0 [S2, unofficial][S4].
*   $k_b$: Iteration interval for kernel updates. Typical value: 100 [S4].
*   $T_{max}$: Total iterations. Typical value: 19,500 or 20,000 [S4].
*   Kernel Size: Starts at 9x9 [S4].

**Edge Cases and Pitfalls:**
*   **Precision:** When $\sigma$ approaches 0, the kernel size should also approach 1 to avoid unnecessary computation and potential artifacts from zero-padding with large kernels [S2, unofficial].
*   **Boundaries:** Use reflective or replicate padding when applying convolution to avoid edge artifacts in the supervision signal [G].
*   **Downsampling:** If the training images are downsampled, the kernel size must be adjusted to maintain the same effective blur radius in the original resolution space [S4]. Failure to do so results in inconsistent frequency regularization across scales.
*   **Densification:** The kernel size should be lowered before densifying Gaussians to introduce extra signal on the gradient of erroneous Gaussians as the noise level reduces [S4].

## Operating characteristics
*   **Time Complexity:** The blurring operation is $O(N \cdot H \cdot W)$ per image per iteration, where $N$ is the kernel size and $H, W$ are image dimensions. Since the kernel is separable, it is $O(2 \cdot N \cdot H \cdot W)$. The kernel size $N$ decreases over time, reducing computational cost in later stages [S1, S4].
*   **Memory Complexity:** Requires storing the smoothed image, which is $O(H \cdot W)$ per image. This is negligible compared to the storage of 3D Gaussians [S2, unofficial].
*   **Measured Performance:** On DTU 3-view, Smoothed 2D Supervision (Adaptive Gaussian Blur) achieved 19.72 PSNR, improving over the baseline of 19.54 PSNR [S3].
*   **Strengths:** Stabilizes camera alignment by producing smoothed image gradients [S2, unofficial]. Restricts the spectrum of the learned 3D scene, preventing high-frequency noise [S2, unofficial]. Experimentally proven crucial for successful pose refinement [S1].
*   **Limitations:** It is a handcrafted strategy and cannot fully align the frequency relationship between positional encodings and pixel supervision as effectively as adaptive methods [S3].
*   **When to Use:** When joint optimization of camera poses and scene geometry is unstable, or when high-frequency noise dominates the early training stages [S2, unofficial].
*   **When Not to Use:** When computational resources are extremely limited and the overhead of blurring is prohibitive, or when an adaptive frequency-aware method is available and preferred [S3].

## Background
Smoothed 2D Supervision was introduced as part of techniques to improve the robustness of joint optimization in radiance fields and Gaussian Splatting [S1][S2, unofficial]. It is inspired by the analysis of frequency content in radiance fields, where blurring the 2D training images helps to stabilize the optimization process [S2, unofficial]. The method is similar to the Gaussian schedule used for smoothing 3D radiance fields [S2, unofficial]. It has been used in various contexts, including joint pose optimization [S1][S2, unofficial] and efficient Gaussian Splatting training [S4].
