# Multi-View Density Control Criterion

Also called: Absolute-gradient split proxy, FastGS criterion, Multi-view Adaptive Density Control (ADC)

## Overview
The Multi-View Density Control Criterion is a densification strategy for 3D Gaussian Splatting designed to resolve invalid vector arithmetic that occurs when applying standard Adaptive Density Control (ADC) to multi-view training. Standard ADC sums 2D positional gradients from pixels covering a Gaussian; however, in multi-view training, a single Gaussian is projected onto multiple image planes, and adding 2D vectors from different coordinate spaces is mathematically invalid and can result in nullified gradients [S1, unofficial]. This criterion replaces vector addition with the summation of squared norms, providing a space-independent error metric that correctly identifies Gaussians requiring densification across multiple views [S1, unofficial]. It yields higher reconstruction quality with fewer primitives compared to the standard positional-gradient rule [S2, unofficial].

## How it works
The method computes a scalar error metric $E_1(G)$ for each Gaussian $G$ by aggregating gradient information from all training views that project onto $G$.

**Inputs:**
*   Set of active Gaussians $\mathcal{G}$.
*   Set of training viewpoints $\mathcal{V} = \{V_1, \dots, V_N\}$.
*   For each Gaussian $G$ and viewpoint $V_k$, the set of pixels $\Pi_{G,k}$ in image plane $V_k$ covered by $G$.
*   For each pixel $p \in \Pi_{G,k}$, the 2D positional gradient $\nabla_p L$ with respect to the Gaussian parameters.

**Outputs:**
*   Scalar metric $E_1(G)$ for each $G \in \mathcal{G}$.

**Data Structures:**
*   $E_1(G)$: A scalar float value stored per Gaussian.

**Steps:**
1.  Initialize $E_1(G) = 0$ for all $G \in \mathcal{G}$.
2.  For each Gaussian $G$:
    a. For each viewpoint $V_k$ in $\mathcal{V}$:
    b. For each pixel $p$ in $\Pi_{G,k}$:
    c. Compute the squared Euclidean norm of the 2D positional gradient: $n_p = \|\nabla_p L\|^2$.
    d. Add $n_p$ to $E_1(G)$.
3.  Return $E_1(G)$.

**Formula:**
The error metric is defined as:
$$ E_1(G) = \sum_{k=1}^{N} \sum_{p \in \Pi_{G,k}} \|\nabla_p L\|^2 $$
where:
*   $N$ is the number of viewpoints.
*   $\nabla_p L$ is the 2D positional gradient at pixel $p$.
*   $\|\cdot\|$ denotes the Euclidean norm.

**Parameters:**
*   The threshold for splitting is controlled by the Densification Strategy Threshold (DSTH). The default value is 30 [S3, unofficial]. For the "playroom" scene in the DeepBlending dataset, it is set to 60; other scenes use 30 [S3, unofficial].

**Edge Cases and Pitfalls:**
*   **Invalid Vector Addition:** The primary pitfall avoided by this method is the addition of 2D positional gradients from different image planes. As shown in [S1, unofficial], adding vectors from different spaces can result in a zero vector even if the underlying 3D gradients are identical and large, leading to missed densification opportunities.
*   **Precision:** Summing squared norms avoids cancellation errors inherent in vector addition.

**Pseudocode:**
```python
def compute_multiview_density_control_metric(gaussians, views, gradients):
    """
    Computes the Multi-View Density Control Criterion metric E1(G) for each Gaussian.
    
    Args:
        gaussians: List of Gaussian objects.
        views: List of view indices or identifiers.
        gradients: Dictionary mapping (gaussian_id, view_id, pixel_id) to 2D gradient vector.
        
    Returns:
        Dictionary mapping gaussian_id to scalar metric E1.
    """
    metrics = {g.id: 0.0 for g in gaussians}
    
    for g in gaussians:
        metric_sum = 0.0
        for view in views:
            # Get pixels covering this Gaussian in this view
            # In practice, this is determined by rasterization or projection
            pixels = get_pixels_covering_gaussian(g, view)
            
            for p in pixels:
                # Retrieve 2D positional gradient for this pixel and Gaussian
                grad = gradients[(g.id, view, p.id)]
                
                # Compute squared norm
                # grad is a 2D vector (dx, dy)
                squared_norm = grad.x**2 + grad.y**2
                
                metric_sum += squared_norm
        
        metrics[g.id] = metric_sum
        
    return metrics
```

## Subtopics

### DS Threshold (DSTH)
A hyperparameter threshold that controls the densification constraints of Gaussians. Increasing the threshold imposes stricter constraints, reducing the number of Gaussians (NGS), rendering quality, and training time [S3, unofficial]. The default value is 30 [S3, unofficial]. For the "playroom" scene in the DeepBlending dataset, it is set to 60; other scenes use 30 [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** The metric computation requires iterating over all pixels covering all Gaussians across all views. The cost is proportional to the total number of rasterized pixels.
*   **Memory Complexity:** Requires storing the scalar metric $E_1(G)$ per Gaussian.
*   **Performance:** On the "garden" scene, the multi-view criterion yields 0.67 dB higher PSNR (27.06 vs 26.83) and 0.028 lower LPIPS (0.1247 vs 0.1303) while using 28% fewer primitives (148,658 vs 240,075) compared to the standard positional-gradient rule [S2, unofficial].
*   **Strengths:** Resolves the nullification of gradients in multi-view settings; reduces primitive count without sacrificing quality.
*   **Limitations:** Requires access to gradients from multiple views simultaneously, which may increase memory overhead during training if not managed carefully.
*   **Usage:** Applied during the teacher training phase to control primitive count and distribution [S2, unofficial].

## Background
The method was proposed in "Efficient multi-view training for 3D Gaussian Splatting" [S1, unofficial] to address the incompatibility of standard ADC with multi-view training. Standard ADC sums 2D positional gradients, which is invalid when gradients come from different image planes [S1, unofficial]. The multi-view criterion uses norms and sums of norms to create a space-independent error metric. It has been adopted in subsequent works such as "Bake It Till You Make It: Ultrafast Spatial Texture-Atlas Splatting" [S2, unofficial] and "Loss-Guided Density Control and Efficient Backward Optimisation for Compact Gaussian Splatting" [S3, unofficial].
