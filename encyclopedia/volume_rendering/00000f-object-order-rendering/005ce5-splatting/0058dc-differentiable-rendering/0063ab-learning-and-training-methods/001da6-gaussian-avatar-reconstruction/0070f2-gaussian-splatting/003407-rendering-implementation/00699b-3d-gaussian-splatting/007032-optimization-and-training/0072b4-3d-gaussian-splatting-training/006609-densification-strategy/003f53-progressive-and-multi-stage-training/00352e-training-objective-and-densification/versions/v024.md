# Training Objective and Densification

Also called: MeshGS Training, Tightly/Loosely-bound Training

## Overview
This method defines the specific loss functions and densification protocols for **MeshGS** [S1], a variant of 3D Gaussian Splatting that aligns primitives with an explicit mesh surface. It solves the problem of Gaussian primitives drifting away from geometry or expanding excessively in unstructured regions by introducing mesh-aware constraints. It differs from standard 3D Gaussian Splatting [22] by splitting the primitive set into **tightly-bound** ($G^t$) and **loosely-bound** ($G^l$) subsets, applying distinct densification and regularization strategies to each, and incorporating projection and normal consistency losses. It builds on [Progressive and Multi-stage Training](9966-progressive-and-multi-stage-training.md) by providing the specific objective and update rules for the mesh-aligned phase.

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   Set of 3D Gaussians $\mathcal{G} = \{g_1, \dots, g_N\}$, where each $g_k$ has mean $\mu_k$, covariance $\Sigma_k$ (scale $s_k$, rotation $q_k$), opacity $\alpha_k$, and spherical harmonic coefficients $\mathbf{c}_k$ .
    *   Explicit mesh $M$ defined by a set of faces $F$, where each face $f_j$ has vertices $v_{j,1}, v_{j,2}, v_{j,3}$ and normal $n_{f_j}$ [S1].
    *   Ground truth images $I_i$ and rendered images $\hat{I}_i$ [S1].
    *   Distance threshold $d_{th} = 0.01$ to classify Gaussians [S1].
    *   Loss weights: $\lambda_{img} = 0.001$, $\lambda_{nc} = 0.1$, $\lambda_{min} = 0.1$, $\lambda_{max} = 10$, $\lambda_{proj} = 50$ [S1].
    *   Scale threshold $\rho = 0.1$ [S1].
*   **Outputs:**
    *   Updated set of Gaussians $\mathcal{G}'$ with optimized parameters.
    *   Rendered images $\hat{I}_i$ minimizing the total loss $L$ [S1].

### Data Structures
*   **Gaussian Attributes:** Each Gaussian $g_k$ stores:
    *   $\mu_k \in \mathbb{R}^3$: Position.
    *   $s_k \in \mathbb{R}^3$: Scale (log-space or raw, typically raw in loss calculations).
    *   $q_k \in \mathbb{R}^4$: Rotation (quaternion).
    *   $\alpha_k \in [0, 1]$: Opacity.
    *   $\mathbf{c}_k$: Spherical Harmonic coefficients.
*   **Mesh Attributes:**
    *   $F$: List of faces.
    *   For each face $f_j$: Vertices $V_j = \{v_{j,1}, v_{j,2}, v_{j,3}\}$, Normal $n_{f_j}$.
*   **Classification Buffer:**
    *   Boolean flag `is_tightly_bound[k]` for each Gaussian $k$, true if distance to mesh $< d_{th}$, false otherwise [S1].

### Numbered Steps

1.  **Classification:** For each Gaussian $g_k$ with center $P_k$, compute the minimum distance to the mesh surface. If distance $< d_{th}$, classify $g_k \in G^t$ (tightly-bound); else $g_k \in G^l$ (loosely-bound) [S1].
2.  **Rendering:** Render images $\hat{I}_i$ from current $\mathcal{G}$ using standard differentiable volume rendering [S1].
3.  **Loss Calculation:** Compute total loss $L = L_{img} + \lambda_{nc} L_{nc} + L_{scale} + \lambda_{proj} L_{proj}$ [S1].
    *   **Image Loss ($L_{img}$):**
        $$L_{img} = (1-\lambda_{img})L_1(\hat{I}_i, I_i) + \lambda_{img}SSIM(\hat{I}_i, I_i)$$
        where $L_1$ is the L1 norm and $SSIM$ is the Structural Similarity Index [S1].
    *   **Normal Consistency Loss ($L_{nc}$):**
        For each $g_k \in G^t$:
        1.  Identify the minimum scale axis index $m = \arg\min(s_{k,1}, s_{k,2}, s_{k,3})$ [S1].
        2.  Construct the rotation matrix $R_k$ from quaternion $q_k$ .
        3.  Compute the splat normal $n_k = R_k \cdot e_m$, where $e_m$ is the unit vector along axis $m$ [S1].
        4.  Find the closest mesh face $f_j$ to $g_k$ [S1].
        5.  Compute $L_{nc} = \sum_{k \in G^t} \sum_{f \in F_{closest}} (1 - n_k \cdot n_f)$ [S1].
    *   **Scale Regularization Loss ($L_{scale}$):**
        For each $g_k \in G^t$ with scales $s_{k,1}, s_{k,2}, s_{k,3}$:
        $$L_{scale} = \sum_{k \in G^t} \left( \lambda_{min} |\min(s_{k,1}, s_{k,2}, s_{k,3})| + \lambda_{max} |\max(s_{k,1}, s_{k,2}, s_{k,3}) - \rho| \right)$$
        This suppresses excessive expansion and aligns scales with the mesh surface resolution $\rho$ [S1].
    *   **Projection Loss ($L_{proj}$):**
        For each $g_k \in G^t$ with center $P_k$:
        1.  Find the closest point $s_k$ on the mesh surface. If the closest face is $f_j$ with vertices $v_{j,1}, v_{j,2}, v_{j,3}$, project $P_k$ onto the plane of $f_j$ or use barycentric projection [S1]. The source formula implies a plane projection: $s_k = P_k + ((P_k - v_{j,1}) \cdot n_{f_j}) \cdot n_{f_j}$ (Note: Source [S1] writes $((P_i - v_i) \cdot f_j) \cdot f_j$ where $f_j$ is likely the normal, as dotting with a face vector is undefined; standard projection uses the normal) [S1].
        2.  Compute $L_{proj} = \sum_{k \in G^t} \| s_k - P_k \|_2$ [S1].
4.  **Optimization Step:** Update Gaussian parameters using an optimizer (e.g., Adam) with gradients $\nabla L$ [S1].
5.  **Densification (Periodic, e.g., every 500 iterations [S1]):**
    *   **For $G^l$ (Loosely-bound):** Apply standard 3DGS densification:
        *   Compute gradient magnitude $\tau_k$ .
        *   **Clone:** If $\tau_k$ is high and $\alpha_k$ is low, clone $g_k$ (copy $\mu, \Sigma, \alpha, \mathbf{c}$) .
        *   **Split:** If $\tau_k$ is high and scale is small, split $g_k$ into children. Sample child means from $\mathcal{N}(\mu_k, \Sigma_k)$ . Reduce scale by factor $1/\sqrt{N_{children}}$ .
    *   **For $G^t$ (Tightly-bound):** Apply mesh-aligned densification [S1]:
        *   Identify Gaussians requiring densification based on gradient or error metrics (implied by "adopt... strategy" but specific metric not detailed beyond standard 3DGS for $G^l$; assume similar gradient-based trigger) [S1].
        *   **Clone:** For selected $g_k \in G^t$:
            1.  Find the closest mesh face $f_j$ [S1].
            2.  Sample a point $p_{new}$ uniformly from the triangle $f_j$ [S1].
            3.  Create new Gaussian $g_{new}$ with $\mu_{new} = p_{new}$, and copy $\Sigma, \alpha, \mathbf{c}$ from $g_k$ [S1].
        *   **Split:** For selected $g_k \in G^t$:
            1.  Find the closest mesh face $f_j$ [S1].
            2.  Sample $N_{children}$ points $\{p_1, \dots, p_{N_{children}}\}$ uniformly from triangle $f_j$ [S1].
            3.  Create children $g_{child, i}$ with $\mu_{child, i} = p_i$.
            4.  Copy $\alpha, \mathbf{c}$ from $g_k$ [S1].
            5.  Set scale $s_{child, i} = s_k / 1.6$ [S1].
6.  **Pruning:** Remove Gaussians with $\alpha_k < \alpha_{min}$ (standard 3DGS threshold, e.g., 0.005) [S1].

### Pseudocode

```python
def meshgs_training_step(gaussians, mesh, gt_images, camera, iteration):
    """
    One training step for MeshGS.
    """
    # 1. Classification
    tightly_bound = []
    loosely_bound = []
    for g in gaussians:
        dist = min_distance_to_mesh(g.mu, mesh)
        if dist < 0.01: # d_th
            tightly_bound.append(g)
        else:
            loosely_bound.append(g)
            
    # 2. Rendering
    rendered_images = render(gaussians, camera)
    
    # 3. Loss Calculation
    loss_img = 0.0
    for render_img, gt_img in zip(rendered_images, gt_images):
        l1 = L1_loss(render_img, gt_img)
        ssim = SSIM_loss(render_img, gt_img)
        loss_img += (1 - 0.001) * l1 + 0.001 * ssim # lambda_img = 0.001
    loss_img /= len(gt_images)
    
    loss_nc = 0.0
    for g in tightly_bound:
        # Estimate normal: min scale axis
        min_scale_idx = argmin(g.scale)
        R = quaternion_to_rotation_matrix(g.rotation)
        e_m = identity_matrix[:, min_scale_idx]
        n_g = R @ e_m
        
        # Find closest face
        face = get_closest_face(g.mu, mesh)
        n_f = face.normal
        
        loss_nc += (1.0 - dot(n_g, n_f))
        
    loss_scale = 0.0
    for g in tightly_bound:
        s_min = min(g.scale)
        s_max = max(g.scale)
        rho = 0.1
        loss_scale += 0.1 * abs(s_min) + 10.0 * abs(s_max - rho) # lambda_min=0.1, lambda_max=10
        
    loss_proj = 0.0
    for g in tightly_bound:
        # Project center to mesh surface
        closest_point = project_point_to_mesh(g.mu, mesh)
        loss_proj += norm(closest_point - g.mu)
        
    total_loss = loss_img + 0.1 * loss_nc + loss_scale + 50.0 * loss_proj # lambda_nc=0.1, lambda_proj=50
    
    # 4. Optimization
    total_loss.backward()
    optimizer.step()
    optimizer.zero_grad()
    
    # 5. Densification (every 500 iterations)
    if iteration % 500 == 0:
        densify(gaussians, tightly_bound, loosely_bound, mesh)
        
    # 6. Pruning
    prune(gaussians, threshold=0.005)
    
    return total_loss

def densify(gaussians, tightly_bound, loosely_bound, mesh):
    # Loosely-bound: Standard 3DGS
    for g in loosely_bound:
        if g.gradient_magnitude > threshold and g.opacity < threshold:
            clone_gaussian(g, gaussians)
        elif g.gradient_magnitude > threshold and g.scale < threshold:
            split_gaussian(g, gaussians)
            
    # Tightly-bound: Mesh-aligned
    for g in tightly_bound:
        if g.gradient_magnitude > threshold: # Assumed trigger
            face = get_closest_face(g.mu, mesh)
            
            # Clone
            if g.opacity < threshold:
                p_new = sample_point_from_triangle(face)
                g_new = clone(g)
                g_new.mu = p_new
                gaussians.append(g_new)
                
            # Split
            if g.scale < threshold:
                for i in range(2): # N_children = 2 typically
                    p_child = sample_point_from_triangle(face)
                    g_child = clone(g)
                    g_child.mu = p_child
                    g_child.scale = g.scale / 1.6
                    gaussians.append(g_child)
```

### Parameters
*   $\lambda_{img} = 0.001$ [S1].
*   $\lambda_{nc} = 0.1$ [S1].
*   $\lambda_{min} = 0.1$ [S1].
*   $\lambda_{max} = 10$ [S1].
*   $\lambda_{proj} = 50$ [S1].
*   $\rho = 0.1$ [S1].
*   $d_{th} = 0.01$ [S1].
*   Training iterations: 30,000 [S1].
*   Densification frequency: Every 500 iterations [S1].

### Edge Cases and Pitfalls
*   **Projection Ambiguity:** The source formula for $L_{proj}$ uses $f_j$ in a dot product, which is ambiguous if $f_j$ is a face (3 vertices) rather than a normal. The implementation must use the face normal $n_{f_j}$ for projection [S1].
*   **Scale Division:** Splitting divides scale by 1.6, not the standard $\sqrt{2} \approx 1.414$. This results in larger children than standard 3DGS, potentially affecting convergence [S1].
*   **Normal Estimation:** Using the minimum scale axis for normal estimation assumes the Gaussian is elongated along the surface tangent, which may fail for isotropic Gaussians [S1].

## Operating characteristics
*   **Time Complexity:** Dominated by rendering and gradient computation. Mesh projection and closest-face queries add overhead, typically $O(N \log M)$ or $O(N)$ with spatial hashing for mesh queries [S1].
*   **Memory Complexity:** $O(N)$ for Gaussians, $O(M)$ for mesh. No significant additional buffers beyond standard 3DGS [S1].
*   **Performance:** Evaluated on Mip-NeRF360 and Deep Blending datasets [S1]. 30k iterations required for convergence [S1].
*   **Strengths:** Improved alignment with explicit mesh geometry, reduced drift, better surface detail preservation [S1].
*   **Limitations:** Requires a pre-existing mesh. Tightly-bound strategy may be sensitive to mesh quality and $d_{th}$ selection [S1].

## Background
MeshGS was introduced in "Adaptive Mesh-Aligned Gaussian Splatting for High-Quality Rendering" [S1]. It extends 3D Gaussian Splatting [22] by integrating explicit mesh representations, addressing the lack of geometric constraints in standard 3DGS. The method distinguishes between tightly-bound and loosely-bound splats to apply appropriate regularization and densification [S1].
