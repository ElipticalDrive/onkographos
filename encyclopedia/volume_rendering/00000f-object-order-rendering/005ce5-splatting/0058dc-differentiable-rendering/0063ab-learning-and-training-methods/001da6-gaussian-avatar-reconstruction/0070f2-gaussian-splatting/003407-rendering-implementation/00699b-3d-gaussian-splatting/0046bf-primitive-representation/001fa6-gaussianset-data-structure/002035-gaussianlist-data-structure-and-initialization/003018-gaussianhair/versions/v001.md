# GaussianHair

Also called: Gaussian Hair Scattering Model

## Overview
GaussianHair is a strand-aware hair rendering method that combines the Marschner Hair Model with Unreal Engine 4’s real-time hair rendering pipeline to create the Gaussian Hair Scattering Model [S2, unofficial]. It uses a hybrid strand + Gaussian Splat (GS) representation to capture complex hair geometry and appearance, enabling fast rasterization and volumetric rendering [S1, unofficial][S2, unofficial]. It is distinguished from general GS variants by its specific focus on hair topology and physically-based scattering, enabling applications such as editing and relighting [S2, unofficial].

## How it works
**Inputs:** Hair geometry data (strands), camera parameters, lighting conditions.
**Outputs:** Rendered image with hair appearance.

**Data Structures:**
The method employs a hybrid representation:
1.  **Strands:** Explicit geometric representation of hair fibers.
2.  **Gaussian Splats:** Volumetric primitives attached to or representing the strands, parameterized for rasterization.
*Note: Exact field layouts for the Gaussian primitives in GaussianHair are not specified in the provided sources [G].*

**Steps:**
1.  **Representation Construction:** Combine explicit strand geometry with Gaussian Splatting primitives to form a strand-aware representation [S1, unofficial][S2, unofficial].
2.  **Scattering Model Integration:** Integrate the Marschner Hair Model [S2, unofficial] with UE4’s real-time hair rendering techniques [S2, unofficial] to define the Gaussian Hair Scattering Model. This model captures complex light interaction (scattering, transmission, reflection) within the hair volume.
3.  **Rendering:** Perform fast rasterization and volumetric rendering using the combined representation [S2, unofficial].
4.  **Application:** Enable post-processing tasks such as editing and relighting [S2, unofficial].
