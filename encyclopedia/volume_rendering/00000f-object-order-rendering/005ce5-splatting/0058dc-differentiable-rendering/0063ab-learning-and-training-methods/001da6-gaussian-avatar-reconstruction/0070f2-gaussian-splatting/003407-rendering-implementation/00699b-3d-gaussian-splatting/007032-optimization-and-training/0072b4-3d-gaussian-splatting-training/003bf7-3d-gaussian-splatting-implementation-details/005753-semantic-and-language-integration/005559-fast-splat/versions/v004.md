# FAST-Splat

Also called: Fast, Ambiguity-Free Semantic Transfer in Gaussian Splatting

## Overview
FAST-Splat is a semantic Gaussian Splatting method that directly augments each 3D Gaussian with specific semantic codes and uses a hash-table for disambiguation, avoiding neural fields for semantic distillation to enable fast training, rendering, and ambiguity-free object localization [S1, unofficial]. It sets itself apart from siblings like [LangSplat Training Procedure](12438-langsplat-training-procedure.md) and [Feature 3D Gaussian Splatting](15902-feature-3d-gaussian-splatting.md) by employing a single-phase, neural-free training procedure that jointly optimizes geometric, visual, and semantic attributes, thereby preserving the speed benefits of Gaussian Splatting while resolving semantic ambiguity in open-vocabulary queries [S1, unofficial].

## How it works
FAST-Splat builds on [Semantic and Language Integration](15930-semantic-and-language-integration.md). It extends the standard 3D Gaussian parameter set $\Theta_i = \{x_i, q_i, s_i, \alpha_i, c_i\}$ with a semantic attribute $\beta_i$ [S1, unofficial]. During rendering, this attribute is accumulated alongside color using the standard front-to-back alpha blending equation [S1, unofficial]:
$$ F_s = \sum_{i \in \mathcal{N}} \beta_i \alpha_i T_i $$
where $F_s$ is the rendered semantic feature, $\alpha_i$ is opacity, and $T_i$ is transmittance [S1, unofficial]. Training involves a joint loss function combining photometric reconstruction (L1/SSIM) and a semantic classification loss [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   A dataset of RGB images $\mathcal{D}$ [S1, unofficial].
*   (Optional) Closed-set object detector (e.g., YOLO, DETR) for initial object lists [S1, unofficial].
*   Open-set object detector (e.g., GroundingDINO) and segmentation model (e.g., SAM-2) for dense semantic maps [S1, unofficial].
*   Pre-trained text encoder (e.g., CLIP, BERT) for embedding generation [S1, unofficial].

**Outputs:**
*   Optimized Gaussian Splatting model with geometric, visual, and semantic attributes [S1, unofficial].
*   Hash-table of identified objects and their text embeddings [S1, unofficial].
*   Rendered semantic feature maps and probability distributions over the hash-table entries [S1, unofficial].

### Data Structures
*   **Gaussian Attributes:** Each Gaussian $i$ stores:
    *   Mean $x_i \in \mathbb{R}^3$.
    *   Rotation quaternion $q_i \in \mathbb{R}^4$.
    *   Scale $s_i \in \mathbb{R}^3$.
    *   Opacity $\alpha_i \in \mathbb{R}$.
    *   Spherical Harmonics coefficients for color $c_i$.
    *   Semantic code $\beta_i \in \mathbb{R}^3$ [S1, unofficial].
*   **Affine Transformation:** A learnable matrix $W$ used to map $\beta_i$ to the semantic space [S1, unofficial].
*   **Hash-Table (Dictionary):** A mapping from object class indices to object class labels and pre-computed text embeddings $\theta_d$ [S1, unofficial].

### Numbered Steps
1.  **Initialization:** Initialize the Gaussian Splatting model (means, covariances, opacities, SH parameters) from a sparse point cloud obtained via structure-from-motion [S1, unofficial].
2.  **Semantic Map Generation:** Feed images into an object detector (e.g., YOLO, DETR, Efficient DETR) to generate object lists and bounding boxes [S1, unofficial]. Generate dense semantic maps using SAM-2, passing each object class and its bounding box [S1, unofficial]. Maintain a dictionary (hash-table) of identified objects [S1, unofficial]. Augment object classes with an undetected class label and assign lower weights to pixels with this label to serve as a regularization term for stability [S1, unofficial].
3.  **Text Embedding Pre-computation:** Pre-compute text embeddings $\theta_d$ for dictionary entries using a pre-trained text encoder (e.g., CLIP, BERT) without fine-tuning [S1, unofficial].
4.  **Joint Optimization (Single-Phase):** Simultaneously optimize all attributes (geometric, visual, and semantic $\beta$) and the affine transformation $W$ in a single phase using gradient descent with the Adam optimizer [S1, unofficial]. For each image $I \in \mathcal{D}$: render the semantic feature map using differentiable tile-based rasterization for the given camera pose [S1, unofficial]. Transform each pixel's semantic feature to a probability distribution over the hash-table entries by applying an affine transformation $W$ to $\beta$ and then softmax [S1, unofficial]. Compute the loss $L_{sgs} = L_{gs} + L_{ce}$ (see Formulas) [S1, unofficial]. Update parameters using backpropagation [S1, unofficial].
5.  **Runtime Query Processing (Open-Vocabulary):** Compute text embedding $\theta_q$ for the user's natural-language prompt using the pre-trained text encoder [S1, unofficial]. Compute relevancy score as pairwise softmax between cosine-similarity values of dictionary embeddings $\theta_d$ and query embedding $\theta_q$ (positive) plus canonical negative embeddings [S1, unofficial]. Designate entries exceeding a relevancy score threshold as similar to the query [S1, unofficial]. Map these entries to pixels in the rendered feature map using the softmax probability distribution [S1, unofficial]. Assign a label to each pixel by taking the maximum probability value, or use alternative techniques like conformal prediction [S1, unofficial]. Provide a clarifying semantic label to each localized object to disambiguate the semantic identity [S1, unofficial].

### Formulas
*   **Gaussian Splatting Loss:**
    $$ L_{gs} = (1 - \lambda) \sum_{I \in \mathcal{D}} ||I - \hat{I}|| + \lambda L_{D-SSIM} $$
    where $\lambda \in [0, 1]$ balances the L1-loss and D-SSIM loss, $I$ is the ground-truth image, and $\hat{I}$ is the predicted image [S1, unofficial].
*   **Total Loss:**
    $$ L_{sgs} = L_{gs} + L_{ce} $$
    [S1, unofficial]
*   **Cross-Entropy Loss:**
    $$ L_{ce} = - \sum_{I \in \mathcal{D}} \frac{1}{|T|} \sum_{p \in T} \gamma_p \log \frac{\exp(F_{I,p,c})}{\sum_{j=1}^{N} \exp(F_{I,p,j})} $$
    where $T$ is the set of all indices of pixels in the rendered feature map $F_I$ associated with image $I$, $c$ is the true class of the pixel, $\gamma_p$ is the weight associated with pixel $p$, and $N$ is the size of the dictionary [S1, unofficial].
*   **Semantic Probability:**
    For each pixel, the probability over dictionary entries is computed by applying softmax to $W \beta$ [S1, unofficial].

### Parameters
*   $\lambda \in [0, 1]$: Weighting parameter between L1-loss and D-SSIM loss [S1, unofficial].
*   $\beta \in \mathbb{R}^3$: Semantic parameter for each ellipsoid [S1, unofficial].
*   $W$: Affine transformation matrix [S1, unofficial].
*   Relevancy score threshold: Threshold for determining similar objects in open-vocabulary queries [S1, unofficial].

### Edge Cases and Pitfalls
*   **Ambiguity:** Ambiguity in object localization arises when users query with semantically similar but distinct objects (e.g., 'tea' vs 'coffee machine'); existing methods localize the object but fail to provide clarifying identity information [S1, unofficial]. FAST-Splat resolves this by providing the precise semantic label [S1, unofficial].
*   **Bag-of-Words Limitation:** Vision-language foundation methods like CLIP use a bag-of-words approach for semantic similarity, which contributes to ambiguity; FAST-Splat mitigates this via the hash-table and relevancy scoring [S1, unofficial].
*   **Undetected Pixels:** Pixels not segmented during data pre-processing are assigned an undetected class label with lower weights to ensure stability [S1, unofficial].

### Pseudocode
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class FASTSplat:
    def __init__(self, num_classes, hidden_dim=3):
        self.num_classes = num_classes
        self.hidden_dim = hidden_dim
        self.W = nn.Linear(hidden_dim, num_classes)
        self.text_encoder = None
        self.class_embeddings = None

    def initialize_gaussians(self, point_cloud):
        # [G] Standard 3DGS initialization from SfM point cloud.
        num_gaussians = len(point_cloud)
        means = torch.tensor(point_cloud, dtype=torch.float32)
        scales = torch.ones(num_gaussians, 3)
        quats = F.normalize(torch.randn(num_gaussians, 4), dim=1)
        opacities = torch.ones(num_gaussians, 1)
        sh_coeffs = torch.zeros(num_gaussians, 3, 16)
        betas = torch.randn(num_gaussians, self.hidden_dim)
        return {"means": means, "scales": scales, "quats": quats,
                "opacities": opacities, "sh_coeffs": sh_coeffs, "betas": betas}

    def generate_semantic_maps(self, images, detector, segmenter):
        semantic_maps = []
        class_dict = {}
        for img in images:
            objects = detector(img)
            h, w = img.shape[1], img.shape[2]
            sem_map = torch.full((h, w), -1, dtype=torch.long)
            for class_name, bbox in objects:
                if class_name not in class_dict:
                    class_dict[class_name] = len(class_dict)
                class_idx = class_dict[class_name]
                mask = segmenter(img, bbox, class_name)
                sem_map[mask] = class_idx
            undetected_idx = len(class_dict)
            class_dict['undetected'] = undetected_idx
            sem_map[sem_map == -1] = undetected_idx
            semantic_maps.append(sem_map)
        return semantic_maps, class_dict

    def precompute_text_embeddings(self, class_dict):
        self.class_embeddings = []
        for class_name in class_dict.keys():
            emb = self.text_encoder.encode(class_name)
            self.class_embeddings.append(emb)
        self.class_embeddings = torch.stack(self.class_embeddings)

    def render_semantic_feature(self, gaussians, camera_pose):
        # [G] Standard 3DGS tile-based rasterization projects Gaussians to 2D.
        # We simulate the front-to-back accumulation for semantic features.
        means = gaussians["means"]
        betas = gaussians["betas"]
        opacities = gaussians["opacities"]
        H, W = 100, 100
        rendered_logits = torch.zeros(H, W, self.num_classes)
        transmittance = torch.ones(H, W)

        # Sort Gaussians by depth (simulated)
        sorted_indices = torch.argsort(means[:, 2])
        for idx in sorted_indices:
            beta = betas[idx]
            alpha = opacities[idx]
            # Apply affine transformation W to beta
            logits = self.W(beta)
            # Project to pixel (simulated)
            px, py = int(means[idx, 0]), int(means[idx, 1])
            if 0 <= px < W and 0 <= py < H:
                T = transmittance[py, px]
                rendered_logits[py, px] += logits * alpha * T
                transmittance[py, px] *= (1.0 - alpha)

        # Apply softmax over dictionary entries
        probs = F.softmax(rendered_logits, dim=-1)
        return probs

    def compute_loss(self, rendered_probs, semantic_maps, class_dict):
        # Photometric loss L_gs (simplified standard 3DGS L1+D-SSIM)
        l_gs = torch.tensor(0.0)
        ce_loss = torch.tensor(0.0)
        total_weight = 0.0
        for feat_map, sem_map in zip(rendered_probs, semantic_maps):
            H, W = feat_map.shape[:2]
            for y in range(H):
                for x in range(W):
                    true_class = sem_map[y, x]
                    gamma_p = 0.1 if true_class == class_dict['undetected'] else 1.0
                    ce_loss += gamma_p * F.cross_entropy(feat_map[y, x].unsqueeze(0), true_class.unsqueeze(0))
                    total_weight += gamma_p
        ce_loss /= max(total_weight, 1.0)
        return l_gs + ce_loss

    def query(self, query_text, rendered_probs, class_dict):
        query_emb = self.text_encoder.encode(query_text)
        cos_sim = F.cosine_similarity(query_emb.unsqueeze(0), self.class_embeddings, dim=1)
        relevancy_scores = F.softmax(cos_sim, dim=0)
        threshold = 0.5
        similar_classes = [name for name, score in zip(class_dict.keys(), relevancy_scores) if score > threshold]
        labels = []
        for feat_map in rendered_probs:
            if similar_classes:
                similar_indices = [class_dict[c] for c in similar_classes if c in class_dict]
                filtered_probs = feat_map[..., similar_indices]
                max_idx = torch.argmax(filtered_probs, dim=-1)
                labels.append([similar_classes[i] for i in max_idx.flatten()])
            else:
                labels.append([class_dict['undetected']] * feat_map.shape[0] * feat_map.shape[1])
        return labels
```

## Operating characteristics
*   **Time Complexity:** FAST-Splat is 6x to 8x faster to train than prior work [S1, unofficial].
*   **Memory Complexity:** FAST-Splat requires approximately 6x smaller GPU memory than prior work [S1, unofficial].
*   **Rendering Speed:** FAST-Splat achieves 18x to 51x faster rendering speeds compared to prior work [S1, unofficial].
*   **Performance Metrics:**
    *   On the illustrated case: SSIM: 0.971, PSNR: 34.24, GPU: 1.02GB [S1, unofficial].
    *   On the 3D-OVS dataset 'Bed' scene: mIoU: 0.933, Localization Accuracy: 0.998, Training Time: 13.96 minutes [S1, unofficial].
    *   On the 3D-OVS dataset 'Covered-Desk' scene: mIoU: 0.913, Localization Accuracy: 0.995, Training Time: 13.96 minutes [S1, unofficial].
*   **Strengths:** Fast training and rendering, low memory usage, ambiguity-free semantic disambiguation [S1, unofficial].
*   **Limitations:** Relies on the quality of the open-set detector and segmentation model for initial semantic map generation [S1, unofficial].
*   **When to use:** When fast, memory-efficient semantic GSplat with unambiguous object localization is required [S1, unofficial].
*   **When not to use:** When neural-field-based semantic distillation is preferred for specific reasons not covered by FAST-Splat's design [S1, unofficial].

## Background
FAST-Splat was introduced by Ola Shorinwa, Jiankai Sun, and Mac Schwager from Stanford University in the paper "FAST-Splat: Fast, Ambiguity-Free Semantics Transfer in Gaussian Splatting" (arXiv:2411.13753v2, 12 Mar 2025) [S1, unofficial]. It addresses the limitations of existing semantic Gaussian Splatting methods, which are slow, memory-intensive, and ambiguous in object localization [S1, unofficial]. FAST-Splat builds on the explicit, sparse representation of 3D Gaussian Splatting to achieve these improvements without relying on neural fields [S1, unofficial].
