# Splatt3R

Also called: Splatt3R: Zero-Shot Gaussian Splatting from Uncalibrated Image Pairs

## Overview
Splatt3R is a feed-forward model that predicts 3D Gaussian Splat parameters directly from a pair of uncalibrated natural images, without requiring camera intrinsics, extrinsics, or depth information [S1, unofficial]. It solves the problem of pose-free novel view synthesis by extending the MASt3R foundation model with a parallel "Gaussian head" to output geometry and appearance attributes for each pixel [S1, unofficial]. Unlike sibling methods that typically supervise only interpolated viewpoints between input views, Splatt3R is designed to extrapolate to viewpoints beyond the stereo baseline using a novel loss masking strategy [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A pair of uncalibrated RGB images $I_1, I_2 \in \mathbb{R}^{H \times W \times 3}$ (typically $512 \times 512$) [S1, unofficial].
*   **Output:** A set of 3D Gaussian primitives $\mathcal{G}$, defined by mean positions $\mu$, covariance matrices $\Sigma$ (parameterized by rotation $q$ and scale $s$), opacities $\alpha$, and colors $S$ [S1, unofficial].

**Data Structures:**
The method predicts parameters per-pixel for both input images. The final Gaussian set is the union of primitives predicted from $I_1$ and $I_2$ [S1, unofficial].
*   **Point Cloud Head (Frozen):** Predicts 3D point locations $\hat{X}_1, \hat{X}_2 \in \mathbb{R}^{H \times W \times 3}$ and confidence maps $C_1, C_2 \in \mathbb{R}^{H \times W}$ in the coordinate frame of the first image [S1, unofficial].
*   **Gaussian Head (Trainable):** A DPT-based decoder predicting offsets $\Delta \in \mathbb{R}^{H \times W \times 3}$, rotations $q \in \mathbb{R}^{H \times W \times 4}$, scales $s \in \mathbb{R}^{H \times W \times 3}$, opacities $\alpha \in \mathbb{R}^{H \times W}$, and spherical harmonics $S \in \mathbb{R}^{H \times W \times 3 \times d}$ (or constant color $S \in \mathbb{R}^{H \times W \times 3}$) [S1, unofficial].

**Numbered Steps:**
1.  **Feature Extraction:** Encode $I_1$ and $I_2$ using a shared Vision Transformer (ViT) encoder and cross-attention transformers. These components are frozen during training [S1, unofficial].
2.  **Point Prediction:** Use the frozen MASt3R backbone to predict 3D point locations $\hat{X}_1, \hat{X}_2$ and confidence maps $C_1, C_2$ in the coordinate frame of the first image [S1, unofficial].
3.  **Gaussian Parameter Prediction:** Pass features through the parallel Gaussian head to predict offsets $\Delta$, rotations $q$, scales $s$, opacities $\alpha$, and colors $S$ for each pixel [S1, unofficial].
4.  **Mean Position Calculation:** Compute the mean position $\mu$ for each Gaussian as the sum of the predicted point and the offset:
    $$ \mu = \hat{x} + \Delta $$
    where $\hat{x}$ is the point location from Step 2 [S1, unofficial].
5.  **Covariance Reparameterization:** Construct the covariance matrix $\Sigma$ using the rotation quaternion $q$ and scale $s$ to ensure positive semi-definiteness:
    $$ \Sigma = R(q) S(s) S(s)^T R(q)^T $$
    where $R(q)$ is the rotation matrix derived from quaternion $q$, and $S(s)$ is a diagonal matrix with scale components [S1, unofficial].
6.  **Gaussian Set Construction:** The final set of Gaussian primitives is the union of the primitives predicted from both input images. Covariances and spherical harmonics are considered in the first image's camera frame [S1, unofficial].
7.  **Differentiable Rendering:** Render the Gaussian set to target views using differentiable rasterization [S1, unofficial].
8.  **Loss Masking:** Calculate a binary loss mask $M$ to restrict supervision to feasibly reconstructed regions:
    *   Unproject target image points.
    *   Reproject them onto context images.
    *   Check if the pixel is inside the frustum of at least one context view.
    *   Check if the rendered depth matches the ground truth depth.
    *   Pixels satisfying these conditions are marked as valid [S1, unofficial].
9.  **Loss Calculation:** Compute the total loss $L$ using the mask:
    $$ L = \lambda_{MSE} L_{MSE}(M \odot \hat{I}, M \odot I) + \lambda_{LPIPS} L_{LPIPS}(M \odot \hat{I}, M \odot I) $$
    where $\hat{I}$ is the rendered image, $I$ is the ground truth target image, and $\odot$ denotes element-wise multiplication [S1, unofficial].

**Parameters:**
*   **Activation Functions:** Normalization for quaternions $q$, exponential for scales $s$ and offsets $\Delta$, and sigmoid for opacities $\alpha$ [S1, unofficial].
*   **Color:** Constant, view-independent color $S \in \mathbb{R}^3$ is used in experiments, with ablation for view-dependent spherical harmonics [S1, unofficial].
*   **Overlap Thresholds:** Hyperparameters $\phi$ and $\psi$ control context/target selection. Typical values: Close $(0.9, 0.9)$, Medium $(0.7, 0.7)$, Wide $(0.5, 0.5)$, Very Wide $(0.3, 0.3)$ [S1, unofficial].

**Pseudocode:**
```python
def splatt3r_forward(I1, I2, frozen_mast3r, gaussian_head):
    # 1. Feature Extraction (Frozen)
    features = frozen_mast3r.encode(I1, I2)
    
    # 2. Point Prediction (Frozen)
    # Predicts points in I1's coordinate frame
    X_hat_1, C_1 = frozen_mast3r.point_head(features, image=I1)
    X_hat_2, C_2 = frozen_mast3r.point_head(features, image=I2)
    
    # 3. Gaussian Parameter Prediction (Trainable)
    # Outputs offsets, rotations, scales, opacities, colors
    Delta_1, q_1, s_1, alpha_1, S_1 = gaussian_head(features, image=I1)
    Delta_2, q_2, s_2, alpha_2, S_2 = gaussian_head(features, image=I2)
    
    # 4. Mean Position Calculation
    mu_1 = X_hat_1 + Delta_1
    mu_2 = X_hat_2 + Delta_2
    
    # 5. Covariance Reparameterization
    # R(q) constructs rotation matrix from quaternion q
    # S(s) constructs diagonal scale matrix from vector s
    Sigma_1 = quaternion_to_rotation_matrix(q_1) @ scale_matrix(s_1) @ scale_matrix(s_1).T @ quaternion_to_rotation_matrix(q_1).T
    Sigma_2 = quaternion_to_rotation_matrix(q_2) @ scale_matrix(s_2) @ scale_matrix(s_2).T @ quaternion_to_rotation_matrix(q_2).T
    
    # 6. Gaussian Set Construction
    # Union of primitives from both images
    Gaussians = []
    for i in range(H*W):
        # From Image 1
        Gaussians.append(Gaussian(
            mu=mu_1[i],
            sigma=Sigma_1[i],
            alpha=alpha_1[i],
            color=S_1[i]
        ))
        # From Image 2
        Gaussians.append(Gaussian(
            mu=mu_2[i],
            sigma=Sigma_2[i],
            alpha=alpha_2[i],
            color=S_2[i]
        ))
        
    return Gaussians

def compute_loss_mask(target_depth, target_pose, context_depths, context_poses, H, W):
    """
    Computes loss mask M for a target view.
    M[i] = 1 if pixel i is visible and depth-consistent in context views.
    """
    M = zeros(H, W)
    
    # Unproject target points to 3D
    target_points_3d = unproject(target_depth, target_pose)
    
    for each context view (depth, pose):
        # Reproject 3D points to context view
        u, v, depth_rendered = project(target_points_3d, context_pose)
        
        # Check frustum bounds
        valid_frustum = (u >= 0) & (u < W) & (v >= 0) & (v < H)
        
        # Check depth consistency
        # Compare rendered depth with context ground truth depth
        depth_match = abs(depth_rendered - context_depth[u, v]) < threshold
        
        # Combine conditions
        valid_pixels = valid_frustum & depth_match
        
        # Update mask (union of valid pixels across contexts)
        M[valid_pixels] = 1
        
    return M
```

**Edge Cases and Pitfalls:**
*   **Extrapolation Loss:** Supervising rendering loss for pixels not visible in context views (obscured or outside frustums) is counterproductive and destructive to model performance [S1, unofficial]. This is addressed by the loss masking strategy [S1, unofficial].
*   **Local Minima:** Unlike methods that tie probabilistic density to opacity, Splatt3R directly supervises positions using ground-truth point clouds to ensure a monotonically decreasing loss path to the correct location [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Inference is a single forward pass, achieving 4 FPS at $512 \times 512$ resolution [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On ScanNet++ test scenes, Splatt3R achieves PSNR 19.66, SSIM 0.757, LPIPS 0.234 for Close view overlap ($\phi=0.9, \psi=0.9$) [S1, unofficial].
*   **Strengths:** Pose-free operation; generalizes to uncalibrated, in-the-wild images; supports extrapolation beyond stereo baseline [S1, unofficial].
*   **Limitations:** Requires training on datasets with ground truth depth/poses (ScanNet++) to learn the masking strategy; performance degrades with very wide baselines (e.g., PSNR 18.56 for Very Wide overlap) [S1, unofficial].
*   **When to use:** When camera parameters are unknown and a fast, feed-forward reconstruction is needed from a stereo pair.
*   **When not to use:** When high-precision calibrated reconstruction is required, or when the input images have extremely low overlap.

## Background
Splatt3R was introduced in 2024 by Brandon, Zheng, Iro, and Victor from the University of Oxford [S1, unofficial]. It builds upon the MASt3R architecture, a foundation model for 3D geometry reconstruction [S1, unofficial]. The method was developed to address the limitations of existing generalizable 3D-GS methods that only supervise interpolated viewpoints, by enabling extrapolation through loss masking [S1, unofficial]. It is trained on the ScanNet++ dataset [S1, unofficial].
