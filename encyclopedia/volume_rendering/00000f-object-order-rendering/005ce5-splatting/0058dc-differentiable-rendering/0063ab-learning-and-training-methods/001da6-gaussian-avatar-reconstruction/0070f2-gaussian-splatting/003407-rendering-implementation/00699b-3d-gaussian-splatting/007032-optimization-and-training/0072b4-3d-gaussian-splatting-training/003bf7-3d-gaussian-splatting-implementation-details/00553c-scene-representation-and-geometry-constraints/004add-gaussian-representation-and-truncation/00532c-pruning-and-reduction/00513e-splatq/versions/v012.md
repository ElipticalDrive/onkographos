# SplatQ

Also called: SplatQ: Post-training Gaussian pruning via QUBO

## Overview
SplatQ is a post-training pruning framework for 3D Gaussian Splatting that fixes the spatial quality imbalance and ignored joint deletion effects of global Top-K methods [S1, unofficial]. It partitions Gaussians into size-limited blocks based on spatial and appearance similarity, allocates retention quotas to balance regional budget, and uses a Quadratic Unconstrained Binary Optimization (QUBO) model to jointly select Gaussians within each block, thereby accounting for pairwise interactions and overlapping contributions [S1, unofficial].

## How it works
**Inputs:** A pretrained 3DGS model with $N$ Gaussians $\mathcal{G} = \{G_i\}_{i=1}^N$, where each Gaussian $G_i$ is defined by center $\boldsymbol{\mu}_i$, scale $s_i$, rotation quaternion $\mathbf{r}_i$, zeroth-order (DC) color coefficients $\mathbf{c}_i$, higher-order spherical harmonic (SH) coefficients $\mathbf{h}_i$, and opacity $o_i$ [S1, unofficial]. A target retention count $K$ and a maximum block size $M$ [S1, unofficial].

**Outputs:** A pruned set of $K$ Gaussians and their optimized attributes [S1, unofficial].

**Data Structures:**
*   **Gaussian List:** Array of $N$ Gaussian objects [S1, unofficial].
*   **Blocks:** A partition of the Gaussian indices into sets $\mathcal{C}_b$, where $|\mathcal{C}_b| \le M$ [S1, unofficial].
*   **Response Matrix $\mathbf{R}_b$:** For each block $\mathcal{C}_b$, a matrix storing individual deletion responses and pairwise interaction coefficients derived from sampled pixel renderings [S1, unofficial].
*   **Quotas:** A vector $\mathbf{K} = [K_b]$ where $\sum_b K_b = K$ [S1, unofficial].

**Steps:**

1.  **Partitioning:** Divide the $N$ Gaussians into blocks $\{\mathcal{C}_b\}$ of size at most $M$ [S1, unofficial]. Partitioning uses spatial proximity and appearance similarity to group potentially redundant Gaussians together [S1, unofficial]. To avoid the quadratic cost of all-pairs comparison, a 3D grid and Morton ordering are used to efficiently generate the blocks [S1, unofficial].
2.  **Opacity Response Modeling:** For each block $\mathcal{C}_b$, compute the response matrix $\mathbf{R}_b$ [S1, unofficial]. This involves sampling pixels from multiple views and estimating the change in rendered color when individual Gaussians are deleted and when pairs of Gaussians are deleted jointly [S1, unofficial].
3.  **Budget Allocation:** Assign a retention quota $K_b$ to each block $\mathcal{C}_b$ such that $\sum_b K_b = K$ [S1, unofficial]. Initial quotas are derived from importance estimates, then smoothed to prevent the budget from concentrating in regions with consistently high scores, which causes spatial quality imbalance [S1, unofficial].
4.  **Quadratic Selection:** For each block $\mathcal{C}_b$, formulate a QUBO objective to select exactly $K_b$ Gaussians to retain [S1, unofficial]. The objective incorporates individual responses, pairwise interaction terms from $\mathbf{R}_b$, and a penalty for deviating from $K_b$ [S1, unofficial]. Solve the QUBO using Simulated Annealing (SA) or a Coherent Ising Machine (CIM) [S1, unofficial].
5.  **Fine-tuning:** Fine-tune the attributes ($\boldsymbol{\mu}_i, s_i, \mathbf{r}_i, \mathbf{c}_i, \mathbf{h}_i, o_i$) of the retained Gaussians without changing the count $K$ to recover rendering quality [S1, unofficial].

**Formulas:**

The Gaussian representation is:
$$ G_i = (\boldsymbol{\mu}_i, s_i, \mathbf{r}_i, \mathbf{c}_i, \mathbf{h}_i, o_i) $$
where $\boldsymbol{\mu}_i$ is the center, $s_i$ is the scale, $\mathbf{r}_i$ is the rotation quaternion, $\mathbf{c}_i$ and $\mathbf{h}_i$ are the zeroth-order and higher-order spherical-harmonic coefficients, and $o_i$ is the opacity [S1, unofficial].

The QUBO objective for a block $\mathcal{C}_b$ with binary retention variables $x_i \in \{0, 1\}$ (1 if retained, 0 if deleted) is:
$$ \min_{\mathbf{x}} \left( \sum_{i \in \mathcal{C}_b} w_i x_i + \sum_{i, j \in \mathcal{C}_b, i < j} w_{ij} x_i x_j + \lambda \left( \sum_{i \in \mathcal{C}_b} x_i - K_b \right)^2 \right) $$
where $w_i$ represents the individual deletion response (cost of removing $G_i$), $w_{ij}$ represents the pairwise interaction effect, and $\lambda$ is a penalty weight enforcing the quota $K_b$ [S1, unofficial].

**Parameters:**
*   $N$: Total number of Gaussians in the pretrained model [S1, unofficial].
*   $K$: Exact number of Gaussians to retain [S1, unofficial].
*   $M$: Maximum size of each block $\mathcal{C}_b$ [S1, unofficial].
*   $K_b$: Retention quota for block $b$ [S1, unofficial].
*   $\mathbf{R}_b$: Response matrix for block $b$ [S1, unofficial].

**Pitfalls:**
*   **Spatial Quality Imbalance:** Global ranking methods concentrate the budget in regions with high scores, leaving other regions with insufficient capacity [S1, unofficial].
*   **Non-Additive Degradation:** Independent scoring fails to capture joint effects because overlapping Gaussians may jointly support a pixel; removing multiple Gaussians is not strictly additive [S1, unofficial].

def splatq_prune(gaussians, target_count, max_block_size):
    """
    Prune 3D Gaussians using SplatQ.
    
    Args:
        gaussians: List of N Gaussian objects with attributes (mu, s, r, c, h, o).
        target_count: Exact number of Gaussians to retain (K).
        max_block_size: Maximum size of each block (M).
        
    Returns:
        pruned_gaussians: List of K Gaussian objects with optimized attributes.
    """
    N = len(gaussians)
    
    # Stage 1: Partitioning
    # Use 3D grid and Morton ordering to group by spatial proximity and appearance similarity
    # to avoid O(N^2) pairwise comparisons.
    blocks = partition_by_similarity(gaussians, max_block_size)
    
    # Stage 2: Opacity Response Modeling
    # For each block, compute response matrix Rb using sampled pixels from multiple views.
    # Rb stores individual deletion effects and pairwise interactions.
    response_matrices = {}
    for block in blocks:
        response_matrices[block.id] = compute_response_matrix(block, gaussians)
        
    # Stage 3: Budget Allocation
    # Assign retention quota Kb to each block such that sum(Kb) = K.
    # Smooth importance-based quotas to prevent concentration in high-score regions.
    quotas = allocate_budget(blocks, response_matrices, target_count)
    
    # Stage 4: Quadratic Selection
    # For each block, solve QUBO to select Kb Gaussians.
    retained_gaussians = []
    for block in blocks:
        Kb = quotas[block.id]
        Rb = response_matrices[block.id]
        
        # Formulate QUBO: min sum(wi*xi) + sum(wij*xi*xj) + lambda*(sum(xi) - Kb)^2
        # Solve using Simulated Annealing (SA) or Coherent Ising Machine (CIM)
        selected_indices = solve_qubo(Rb, Kb)
        
        # Add selected Gaussians to the retained list
        for idx in selected_indices:
            retained_gaussians.append(block.gaussians[idx])
            
    # Stage 5: Fine-tuning
    # Fine-tune attributes of retained Gaussians without changing count K.
    pruned_gaussians = fine_tune(retained_gaussians, gaussians)
    
    return pruned_gaussians

## Operating characteristics
*   **Complexity:** The partitioning step avoids $O(N^2)$ pairwise comparisons by using a 3D grid and Morton ordering [S1, unofficial]. The QUBO solving is performed per block, with block size limited to $M$, making it scalable to millions of Gaussians where a global $N \times N$ matrix would be impractical [S1, unofficial].
*   **Performance:** SplatQ ensures balanced reconstruction quality across scene regions, unlike global Top-K methods which may leave distant or low-score regions with insufficient capacity [S1, unofficial].
*   **Strengths:** Accounts for joint deletion effects and pairwise interactions, which independent scoring methods ignore [S1, unofficial]. Guarantees exact global retention count $K$ [S1, unofficial].
*   **Limitations:** Requires multiple rendering passes for response matrix estimation [S1, unofficial]. Relies on heuristic smoothing for budget allocation [S1, unofficial].

## Background
SplatQ was proposed by Hongbin Ye et al. and presented at ICLR 2027 (preprint arXiv:2610.13503, October 2026) [S1, unofficial]. It addresses limitations in existing 3DGS pruning methods that rely on global Top-K selection based on independent importance scores, which fail to ensure balanced reconstruction quality and ignore joint deletion effects [S1, unofficial].
