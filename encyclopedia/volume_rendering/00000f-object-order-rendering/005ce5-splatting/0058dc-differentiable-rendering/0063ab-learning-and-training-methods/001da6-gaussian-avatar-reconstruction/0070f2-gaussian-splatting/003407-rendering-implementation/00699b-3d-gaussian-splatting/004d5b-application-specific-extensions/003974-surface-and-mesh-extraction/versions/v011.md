# Surface and Mesh Extraction

Also called: Gaussian Mesh Extraction, 3DGS Meshing

## Overview
This family provides methods to convert the continuous, volumetric representation of 3D Gaussian Splatting into explicit, manifold triangular meshes. While standard 3DGS renders images efficiently, it lacks a native geometric boundary, making it unsuitable for applications requiring explicit topology, collision detection, or standard mesh-based rendering pipelines. These methods differ from sibling approaches by their underlying geometric prior: some treat the opacity field as a volumetric density for implicit surface extraction, others enforce explicit distance-based alignment to pre-existing meshes, and others reconstruct geometry from rendered depth/normal cues.

## Shared principles
All methods in this family operate on the output of a trained 3D Gaussian Splatting model $\mathcal{G} = \{G_i\}_{i=1}^M$. Each primitive $G_i$ is defined by its mean position $\mathbf{p}_i$, covariance matrix $\mathbf{\Sigma}_i$ (derived from rotation $\mathbf{R}_i$ and scale $\mathbf{S}_i$), opacity $\alpha_i$, and color attributes [Parent]. The rendering pipeline remains consistent: Gaussians are projected into 2D screen space using the Jacobian $J$ of the projection and the camera extrinsic rotation $W$, yielding the projected 2D covariance $\mathbf{\hat{\Sigma}}_i = J W \mathbf{\Sigma}_i W^T J^T$ [Parent].

Unlike the standard RGB-opacity rendering model, these methods repurpose the Gaussian attributes for geometric inference. The opacity $\alpha_i$ is often interpreted as a volumetric density contribution, or the spatial distribution of $\mathbf{p}_i$ and $\mathbf{\Sigma}_i$ is used to estimate surface normals and depth. The core divergence lies in how the continuous Gaussian field is discretized or constrained to produce a discrete mesh $\mathcal{M} = (\mathcal{V}, \mathcal{F})$.

## Subtopics

### [Gaussian Opacity Fields (GOF) Mesh Extraction](3692-gaussian-opacity-fields-gof-mesh-extraction.md)
A training-free method that extracts a mesh by treating the Gaussian opacity field as a continuous volumetric density function. It constructs a 3D voxel grid, accumulates Gaussian contributions into this grid, and extracts an isosurface using marching cubes. It is chosen when a quick, topology-agnostic mesh is needed from a standard radiance field without external geometric priors.

### [Distance-based Gaussian Splatting](7411-distance-based-gaussian-splatting.md)
Also known as MeshGS, this method constructs a radiance field by establishing a topological connection between a pre-existing large-scale mesh and 3D Gaussian splats. It classifies splats as "tightly-bound" or "loosely-bound" based on their distance to the mesh surface, allowing for adaptive alignment and occlusion culling. It is chosen when high-fidelity alignment to a known geometry is required, solving issues of redundant memory and geometric artifacts in noisy mesh reconstructions.

### [2D-Lift-3D Scene Segmentation](11513-2d-lift-3d-scene-segmentation.md)
A training-free method for segmenting 3D Gaussian primitives by lifting 2D segmentation masks from a reference view into 3D space using multi-view voting. It solves the problem of partial scene editing by decomposing the scene into distinct Gaussian groups. It is chosen when explicit mesh extraction is not the goal, but rather the isolation of specific semantic parts for independent editing, leveraging foundation models like SAM.

### [Mesh Extraction via Poisson Reconstruction](12790-mesh-extraction-via-poisson-reconstruction.md)
This method extracts a textured 3D mesh by converting rendered 2D depth and normal maps into a 3D oriented point cloud, which is then reconstructed into a manifold mesh using Poisson surface reconstruction. It differs from direct Gaussian-to-mesh approaches by relying on explicit geometric priors derived from rendered views. It is chosen when high-fidelity surface topology is required from a radiance field that lacks explicit geometric regularization.

## Background
The ability to extract meshes from 3D Gaussian Splatting emerged as a necessary extension to address the lack of explicit geometry in the original 3DGS formulation [Parent]. Early adaptations focused on using the opacity field as a density proxy for implicit surface extraction, leading to methods like GOF. Concurrently, hybrid approaches like MeshGS integrated explicit mesh priors to improve geometric consistency in large-scale scenes. Other approaches leveraged differentiable rendering to extract depth and normal cues, utilizing established techniques like Poisson reconstruction to finalize the mesh. These methods collectively bridge the gap between efficient neural rendering and traditional computer graphics pipelines.
