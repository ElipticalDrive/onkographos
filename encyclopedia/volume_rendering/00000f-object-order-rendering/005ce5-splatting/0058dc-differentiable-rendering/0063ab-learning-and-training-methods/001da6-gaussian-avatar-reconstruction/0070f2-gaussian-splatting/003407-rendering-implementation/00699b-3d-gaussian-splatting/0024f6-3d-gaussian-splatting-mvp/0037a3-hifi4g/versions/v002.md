# HiFi4G


## Overview
HiFi4G is a 3D Gaussian Splatting method that combines 3DGS with a dual-graph mechanism for non-rigid tracking to achieve high-fidelity rendering [S1][S2, unofficial]. It successfully preserves spatial-temporal consistency in a more compact manner than standard 3DGS [S1][S2, unofficial].

## How it works
**Inputs:**
- Monocular video sequence (typically 50–100 frames) [S1][S2, unofficial].

**Outputs:**
- High-fidelity rendered frames with preserved spatial-temporal consistency [S1][S2, unofficial].

**Data Structures:**
- **Tri-plane Representation:** Factorizes the canonical space to reconstruct the person and scene [S1][S2, unofficial].
- **Dual-Graph Mechanism:** Provides non-rigid tracking for the Gaussians across frames [S1][S2, unofficial].

**Steps:**
1. Factorize the canonical space using a tri-plane representation [S1][S2, unofficial].
2. Combine 3D Gaussian Splatting with the dual-graph mechanism for non-rigid tracking [S1][S2, unofficial].
3. Reconstruct the person and scene from the monocular video input [S1][S2, unofficial].
4. Render frames while preserving spatial-temporal consistency in a compact manner [S1][S2, unofficial].

**Parameters:**
- Video length: 50–100 frames [S1][S2, unofficial].
- Reconstruction time: ~30 minutes [S1][S2, unofficial].

**Edge Cases:**
- Not given in the sources.
