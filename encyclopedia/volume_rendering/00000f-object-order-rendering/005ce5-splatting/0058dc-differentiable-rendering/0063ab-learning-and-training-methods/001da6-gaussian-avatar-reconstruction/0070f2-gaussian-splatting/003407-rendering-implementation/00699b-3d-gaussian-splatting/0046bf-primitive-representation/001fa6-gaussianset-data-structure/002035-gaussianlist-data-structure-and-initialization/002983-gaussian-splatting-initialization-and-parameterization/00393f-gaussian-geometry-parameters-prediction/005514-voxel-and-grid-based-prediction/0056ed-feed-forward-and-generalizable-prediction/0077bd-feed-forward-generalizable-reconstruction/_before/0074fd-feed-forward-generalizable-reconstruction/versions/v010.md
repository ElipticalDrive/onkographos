# Feed-forward Generalizable Reconstruction

Also called: Feed-forward 3D Gaussian Splatting, Instant 3DGS, Generalizable 3DGS

## Overview
Feed-forward generalizable reconstruction methods map input images directly to a set of 3D Gaussian parameters $\mathcal{G} = \{\mu, \Sigma, \alpha, c\}$ without per-scene gradient descent [Parent]. This solves the latency and compute bottlenecks of iterative optimization-based 3D Gaussian Splatting (3DGS), enabling instant reconstruction from arbitrary image sets [23168-feed-forward-generalizable-reconstruction]. Unlike traditional 3DGS which requires iterative optimization per scene, these methods generalize across scenes using pretrained geometry encoders [23168-feed-forward-generalizable-reconstruction].

## Shared principles
All methods in this family share the core objective of mapping input image features to a set of 3D Gaussian parameters $\mathcal{G} = \{\mu, \Sigma, \alpha, c\}$ without per-scene gradient descent [Parent].

1.  **Input Representation:** Inputs are typically one or more RGB images $I \in \mathbb{R}^{H \times W \times 3}$. Some methods require known camera poses $P$, while others (e.g., [Splatt3R](16423-splatt3r.md), [ZeroGS](16425-zerogs.md)) predict poses or operate on uncalibrated inputs [Parent].
2.  **Feature Encoding:** A shared encoder (e.g., Vision Transformer, CNN) extracts multi-scale features from the input images. Cross-attention or cost volumes are often used to aggregate multi-view information [Parent].
3.  **Primitive Prediction:** A decoder head predicts Gaussian attributes. These attributes are usually:
    *   **Mean ($\mu$):** 3D position.
    *   **Covariance ($\Sigma$):** Defined by scale $s$ and rotation $r$ (quaternion or 6D).
    *   **Opacity ($\alpha$):** Scalar.
    *   **Color ($c$):** Spherical Harmonics (SH) coefficients or constant RGB [Parent].
4.  **Differentiable Rendering:** The predicted Gaussians are rendered into target views using differentiable rasterization to compute reconstruction losses (e.g., L1, SSIM, LPIPS) for training the network [Parent].
5.  **Generalization:** The network is trained on a large dataset of scenes to learn priors about geometry and appearance, allowing inference on unseen scenes [Parent].

## Subtopics

### [Direct Pixel-Wise Regression](18786-direct-pixel-wise-regression.md)
Direct Pixel-Wise Regression is a feed-forward method that predicts a set of 3D Gaussian primitives directly from input image patches, establishing a one-to-one correspondence between 2D pixels and 3D Gaussians [18786-direct-pixel-wise-regression]. It differs from sibling methods like [Triplane-LRM](16746-feed-forward-generalizable-reconstruction.md) by avoiding fixed-resolution latent representations (e.g., triplanes), thereby enabling pixel-aligned prediction of per-Gaussian colors and scaling Gaussian count with input resolution to capture high-frequency details [18786-direct-pixel-wise-regression].

### [Latent Space Representation](19901-latent-space-representation.md)
Latent Space Representation methods map input images to a compact, structured latent code (tokens, features, or distributions) which is subsequently decoded into explicit 3D Gaussian primitives, enabling generalizable reconstruction without per-scene optimization [19901-latent-space-representation]. Unlike sibling methods that predict Gaussians directly from pixel-wise features or cost volumes, this family explicitly models the scene as a set of learnable latent entities (e.g., tokens or entropy-coded features) to enforce global consistency, reduce representation bloat, or handle ambiguity [19901-latent-space-representation].

### Sliding Window Large-scale Reconstruction
Use sliding windows to process the sequence and construct a unified large-scale Gaussian scene [S2, unofficial]. Successfully applied to a KITTI street sequence containing over 1,000 frames [S2, unofficial].

## Background
SplatterImage [105] works on single-view data by utilizing a U-Net [106] network to translate the input image into attributes on Gaussians [S1, unofficial]. It can be extended to multi-view inputs by aggregating predicted Gaussians from different viewpoints via warping operations [S1, unofficial]. InfiniSplat v2 applies the feed-forward reconstructor to a KITTI street sequence of over 1,000 frames using sliding windows to construct a large-scale Gaussian scene [S2, unofficial].
