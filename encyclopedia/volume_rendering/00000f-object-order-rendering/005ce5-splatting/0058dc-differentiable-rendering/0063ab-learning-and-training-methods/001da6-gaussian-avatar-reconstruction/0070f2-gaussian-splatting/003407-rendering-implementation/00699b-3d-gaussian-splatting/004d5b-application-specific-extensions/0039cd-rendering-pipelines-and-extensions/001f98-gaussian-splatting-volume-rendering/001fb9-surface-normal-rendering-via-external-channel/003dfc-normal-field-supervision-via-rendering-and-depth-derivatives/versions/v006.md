# Normal Field Supervision via Rendering and Depth Derivatives

Also called: Learnable Unit Normal with Depth Gradient Supervision, Lemma 2, Phys3DGS Normal Regularizer, Pseudo-Normal Supervision, Supervision of Normal Field

## Overview
This method supervises the learnable surface normal attributes of 3D Gaussians by enforcing consistency between the rendered normal map and the geometric normals derived from the rendered depth map [S1, unofficial][S2]. It differs from pure gradient-based approaches by explicitly optimizing normal attributes per Gaussian and supervising them against pseudo-normals computed from the median depth [S2].

## How it works
**Inputs:**
- Rendered depth map $\hat{D}$ of resolution $W \times H$ [S2].
- Rendered normal map $\hat{N}$ of resolution $W \times H$, obtained by rasterizing the 3D Gaussian Splatting representation with learnable unit normals $n_i$ using alpha-blending [S2].

**Outputs:**
- Normal consistency loss $L_n$ used for gradient-based optimization of Gaussian parameters [S1, unofficial].

**Data Structures:**
- $\hat{D}$: 2D array of floats, where $\hat{D}(x,y)$ stores the median depth at pixel $(x,y)$ [S2].
- $\hat{N}$: 2D array of 3D vectors, where $\hat{N}(x,y)$ stores the alpha-blended normal at pixel $(x,y)$ [S2].
- $n_i$: 3D vector, the learnable unit normal attribute of the $i$-th Gaussian [S1, unofficial].

**Steps:**
1. **Render Normal Map:** Rasterize the 3D Gaussian Splatting representation. For each pixel, compute the alpha-blended normal $\hat{N}(x,y)$ using the learnable normals $n_i$ of the contributing Gaussians [S2].
2. **Compute Pseudo-Normal:** Calculate the pseudo-ground truth normal $\tilde{N}(x,y)$ from the gradient of the rendered depth map $\hat{D}$ under a local planarity assumption [S1, unofficial].
   - Compute the image gradients of the depth map: $\nabla_x d$ and $\nabla_y d$ [S1, unofficial].
   - Construct 3D tangent vectors from the gradients: $\mathbf{v}_x = (1, 0, \nabla_x d)$ and $\mathbf{v}_y = (0, 1, \nabla_y d)$ [G].
   - Compute the cross product of these vectors and normalize the result to get $\tilde{N}(x,y)$ [S1, unofficial]:
     $$ \tilde{N}(x, y) = \frac{\nabla_x d \times \nabla_y d}{|\nabla_x d \times \nabla_y d|} $$
     where $d$ are nearby depth points of pixel $(x, y)$ [S1, unofficial].
3. **Compute Loss:** Quantify the normal consistency as an L1 loss between the rendered normal $\hat{N}$ and the pseudo-normal $\tilde{N}$ [S1, unofficial]:
   $$ L_n = |\hat{N} - \tilde{N}| $$
   This loss encourages the rendered normal field to match the true normal of the surface at the 0.5-isosurface of the transmittance [S2].

**Parameters:**
- **Depth Metric:** The depth used for gradient computation is the median value of the free-flight distance $t^*_{o,w}$, not the expectancy, for robustness to outliers [S2].
- **Median Depth Definition:** The median depth $t$ is the infimum of $t$ such that transmittance $T_{o,w}(t) \leq 0.5$ [S2]. In point-based rendering, this is the depth $t^G_{o,w}$ of the first Gaussian along the ray for which the transmittance reaches the 0.5 threshold [S2].

**Pseudocode:**
```python
def cross(a, b):
    return [a[1]*b[2] - a[2]*b[1], a[2]*b[0] - a[0]*b[2], a[0]*b[1] - a[1]*b[0]]

def norm(v):
    return (v[0]**2 + v[1]**2 + v[2]**2)**0.5

def compute_normal_loss(rendered_depth, rendered_normal):
    H, W = len(rendered_depth), len(rendered_depth[0])
    loss_sum = 0.0
    count = 0
    for y in range(H):
        for x in range(W):
            # Finite difference gradients with edge replication
            dx = rendered_depth[y][min(x+1, W-1)] - rendered_depth[y][max(x-1, 0)]
            dy = rendered_depth[min(y+1, H-1)][x] - rendered_depth[max(y-1, 0)][x]
            # Construct 3D vectors from gradients
            vx = [1.0, 0.0, dx]
            vy = [0.0, 1.0, dy]
            pseudo = cross(vx, vy)
            p_norm = norm(pseudo)
            # Handle degenerate gradients
            if p_norm < 1e-8:
                pseudo = [0.0, 0.0, 1.0]
            else:
                pseudo = [p / p_norm for p in pseudo]
            # L1 loss
            diff = sum(abs(rendered_normal[y][x][i] - pseudo[i]) for i in range(3))
            loss_sum += diff
            count += 1
    return loss_sum / count
```

**Edge Cases and Pitfalls:**
- **Degenerate Gradients:** If the depth map is flat or noisy, the cross product may be near zero, leading to unstable normals. The normalization step includes a clamp to prevent division by zero [G].
- **Boundary Conditions:** Depth gradients at image boundaries require padding or special handling to maintain spatial alignment with the normal map [G].
- **Under-reconstructed Regions:** Artifacts in the normal field correspond to under-reconstructed parts of the scene, such as specular spots, TV screens, or sky regions, where depth estimates are unreliable [S2].

## Subtopics

### [Learnable Normal Estimation with Pseudo-Normal Supervision](10917-learnable-normal-estimation-with-pseudo-normal-supervision.md)
This method assigns a learnable unit normal to each 3D Gaussian to replace noisy gradient-based estimates, preventing the optimization from overfitting to training lighting conditions by aligning rendered normals with geometry priors derived from expected depth gradients. It differs from pure gradient-based approaches by explicitly optimizing normal attributes per Gaussian and supervising them against pseudo-normals computed from expected depth. It is chosen when stable normal attributes are required across varying lighting conditions.

- **Limitations:** Relies on the accuracy of the rendered depth map. Artifacts in the normal field correspond to under-reconstructed parts of the scene [S2].

## Background
The method originates from the formulation of normal field supervision in oriented Gaussian representations [S2] and is applied in reflection-aware rendering pipelines [S1, unofficial]. It leverages the relationship between depth derivatives and surface normals, a concept well-established in computer vision [S2]. The specific formulation using median depth for robustness is detailed in [S2].
