# Neural Radiance Field (NeRF) Representation

Also called: Instant Neural Graphics Primitives (INGP), Photon Field Networks, Photon Fields

## Overview
Neural Radiance Field (NeRF) representation is a method for encoding 3D scenes as continuous volumetric functions using neural networks, enabling high-quality novel view synthesis from sparse 2D images [S1]. While standard NeRF implicitly maps position and view direction to color and density via a Multi-Layer Perceptron (MLP), variants like Photon Field Networks extend this to model indirect global illumination by mapping position, view direction, and phase function coefficients to radiance [S1]. In the context of the parent tree (Gaussian Splatting), the term "NeRF Representation" often refers to the implicit baseline against which explicit Gaussian representations are compared, or specifically to the INGP architecture used in SLAM systems for efficient neural mapping [S3].

## How it works
The implementation of NeRF representation varies significantly between the implicit MLP-based approach (standard NeRF/INGP) and the photon-field-based approach (Photon Field Networks). The following details cover the standard implicit NeRF/INGP architecture, which is the foundational method for SLAM and mapping contexts, alongside the specific Photon Field Network variant cited in the sources.

### Inputs and Outputs
*   **Inputs:** A set of $N$ calibrated images with known camera poses $T_i$, intrinsics, and optionally depth maps or semantic labels.
*   **Outputs:** A neural network (or set of networks) that, given a 3D point $x$ and view direction $\vec{\omega}$, outputs color $C$ and volume density $\sigma$. For Photon Fields, the output is indirect radiance $L_i$ conditioned on a phase coefficient $g$.

### Data Structures
1.  **Neural Network (MLP):**
    *   **Structure:** A Multi-Layer Perceptron. Standard INGP uses a hashgrid encoding followed by an MLP [S1, S3].
    *   **Encoding:** Hashgrid encoding for positions (3D) and directions (2D). Typical configuration: 16 grid levels, 8 features per level, 2x scaling factor between levels, hash table size $2^{19}$ [S1].
    *   **Network Layers:** 5-layer perceptron, 64 neurons per layer, ReLU activations between hidden layers, no output activation [S1].
    *   **Parameters:** The network weights are the primary learnable parameters.

2.  **3D Gaussian Splatting Representation (Explicit Alternative):**
    *   **Structure:** A set of $M$ 3D Gaussians $\mathcal{G}$.
    *   **Layout:** Each Gaussian stores ~59 learnable numbers:
        *   Position: 3 floats (center in 3D space).
        *   Scale: 3 floats.
        *   Rotation: 4 floats (quaternion).
        *   Opacity: 1 float.
        *   Color: Spherical Harmonics coefficients (view-dependent color).
    *   **Covariance:** Constructed as $R S S^T R^T$ to ensure positive semi-definiteness, where $R$ is the rotation matrix and $S$ is the scale matrix [S2, unofficial].

### Numbered Steps (Implicit NeRF/INGP)
1.  **Initialization:** Initialize the neural network weights. For SLAM applications, initialize the network with a coarse estimate or random weights [S3].
2.  **Ray Sampling:** For a target pixel, cast a ray from the camera origin through the pixel. Sample $K$ points along the ray within the scene bounds.
3.  **Encoding:** Encode the 3D position $x$ and view direction $\vec{\omega}$ using the hashgrid encoder.
4.  **Network Inference:** Pass encoded inputs through the MLP to predict density $\sigma$ and color $C$.
    *   *Note:* For Photon Fields, the input also includes a phase coefficient $g$, and the output is indirect radiance $L_i$ [S1].
5.  **Volume Rendering:** Compute the pixel color $C$ using alpha compositing:
    $$ C = \sum_{i=1}^K T_i \left( 1 - e^{-\sigma_i \delta_i} \right) C_i $$
    where $T_i = e^{-\sum_{j=1}^{i-1} \sigma_j \delta_j}$ is the accumulated transmittance, and $\delta_i$ is the distance between samples [S1].
6.  **Loss Computation:** Compare the rendered image with the ground truth image using an L1 loss combined with a Structural Similarity (SSIM) term [S2, unofficial].
7.  **Optimization:** Backpropagate the error to update the network weights (and potentially camera poses in SLAM) via gradient descent [S3].

### Numbered Steps (Photon Field Networks Variant)
1.  **Photon Tracing:** Generate a photon map by tracing photons from light sources. Store photons past their first interaction with the medium. Assign each photon a phase coefficient $g$ from a discrete set $G = \{-0.75, 0.0, 0.75\}$ [S1].
2.  **KD-Tree Construction:** Construct a GPU-based KD-tree on the photon map for fast spatial queries [S1].
3.  **Sample Generation:** Generate training batches of size $2^{16}$. Each batch contains uniformly sampled grid coordinates $x \in [0,1]$, random uniform directions $\vec{\omega}$, and phase coefficients $g$ [S1].
4.  **Ground Truth Estimation:** For each sample, compute ground truth radiance using a KNN query ($K=1024$) on the photon map:
    $$ L_i(x, \vec{\omega}) \approx \sum_{n=1}^K p_g(x, \vec{\omega}, \vec{\omega}_n) \frac{\Phi_n}{4\pi r^3} $$
    where $r$ is the distance to the farthest photon, $\Phi_n$ is photon intensity, and $p_g$ is the Henyey-Greenstein phase function [S1].
5.  **Target Encoding:** Normalize radiance values logarithmically:
    $$ L_i'(x, \vec{\omega}) = \begin{cases} -\frac{\log_{10}(L_i(x, \vec{\omega}))}{\psi} & \text{if } L_i(x, \vec{\omega}) > \frac{1}{10^{\psi}} \\ 1 & \text{otherwise} \end{cases} $$
    where $\psi \in [4, 6]$ is the precision parameter [S1].
6.  **Network Training:** Train the 5-layer MLP to predict $L_i'$. Decode output using $L_i(x, \vec{\omega}) = 10^{-L_i'(x, \vec{\omega})} \cdot \Psi$ [S1].

### Formulas
*   **Photon Field Mapping:**
    $$ P_{\theta}(x, g, \vec{\omega}) = (R, G, B) $$
    where $x \in [0,1]^3$, $g \in [-1,1]$, $\vec{\omega}$ is view direction [S1].
*   **Indirect Radiance Approximation:**
    $$ P_{\theta}(x, g, \vec{\omega}) \approx L_i(x, \vec{\omega}) = \int_{\Omega_{4\pi}} p_g(x, \vec{\omega}, \vec{\omega}_i) L(x, \vec{\omega}_i) d\omega_i $$
    [S1].
*   **Gaussian Covariance:**
    $$ \Sigma = R S S^T R^T $$
    [S2, unofficial].

### Parameters
*   **Batch Size:** $2^{16}$ for Photon Fields [S1].
*   **KNN Neighbors:** $K=1024$ [S1].
*   **Precision Parameter ($\psi$):** 4 to 6 [S1].
*   **Phase Coefficients ($G$):** $\{-0.75, 0.0, 0.75\}$ [S1].
*   **Tile Size:** 16x16 pixels for Gaussian Splatting rasterization [S2, unofficial].

### Edge Cases and Pitfalls
*   **Floating Artifacts:** Gaussian Splatting can produce floating artifacts and needle-like Gaussians in regions seen by few cameras [S2, unofficial].
*   **Aliasing:** Zooming in or out can cause aliasing in Gaussian Splatting [S2, unofficial].
*   **Mesh Extraction:** Neither standard NeRF nor Gaussian Splatting directly provides a clean surface or mesh [S2, unofficial].
*   **High-Frequency Renderings:** In NeRF-based SLAM, high-frequency renderings can hinder image alignment; addressed by KL regularization over ray termination distribution in SLAIM [S3].

## Subtopics

### [Scene NeRF](12484-scene-nerf.md)
Isolates static background by training exclusively on background pixels, excluding dynamic foreground.

### [NeRF-OSR](14477-nerf-osr.md)
Outdoor scene relighting, decomposing scene into albedo, geometry, and lighting for physical relighting.

### [Explicit Volumetric Rendering with Multiple View Aggregation](15335-explicit-volumetric-rendering-with-multiple-view-aggregation.md)
Uses explicit RGB$\alpha$ volume for real-time rendering, amortizing computation across views.

### [Dynamic Neural Radiance Fields](16398-dynamic-neural-radiance-fields.md)
Models dynamic human faces using morphable model parameters and per-frame latent codes.

### [Neural Network Pruning for NeRF](17703-neural-network-pruning-for-nerf.md)
Compresses NeRF by pruning MLP weights with smallest magnitudes.

### SLAIM
A SLAM method introducing a coarse-to-fine tracking pipeline and improving photometric bundle adjustment for NeRF-based mapping. It maintains NeRF’s volume density formulation but adds KL regularization over ray termination distribution to address high-frequency rendering issues hindering image alignment [S3].

### SNI-SLAM
A dense NeRF-based RGB-D SLAM system for real-time 3D semantic mapping. It uses hierarchical semantic encoding and cross-attention to reinforce appearance, geometry, and semantics, with a one-way decoder to prevent reverse interference [S3].

### KN-SLAM
A NeRF-based SLAM method integrating local feature correspondences for coarse pose initialization and joint optimization. It uses global image features and local matches for loop detection, followed by pose graph optimization [S3].

### VI-NeRF-SLAM
Merges traditional SLAM with NeRF mapping for immediate, dense 3D reconstruction without prior training. It estimates depth and pose via feature reprojection constraints, refines scenes with ray integration, and includes dynamic IMU error correction and closed-loop management. It outperforms benchmarks on Euroc and Replica datasets, especially in grayscale scenarios [S4].

## Operating characteristics
*   **Time Complexity:** Standard NeRF training is slow (hours to days) due to per-ray MLP evaluations [S2, unofficial]. Gaussian Splatting reduces training to tens of minutes and rendering to >100 FPS [S2, unofficial]. Photon Fields replace costly scattering path evaluations with constant-time neural inference [S1].
*   **Memory Complexity:** Standard NeRF uses a few megabytes for the network [S2, unofficial]. Gaussian Splatting requires hundreds of megabytes for millions of Gaussians [S2, unofficial]. Photon Fields require storage for the photon map and KD-tree [S1].
*   **Strengths:** High-quality novel view synthesis, support for complex lighting (Photon Fields), real-time rendering (Gaussian Splatting), semantic integration (SNI-SLAM) [S1][S2, unofficial][S3].
*   **Limitations:** No direct mesh extraction, potential artifacts (floating, aliasing), high memory usage for explicit methods [S2, unofficial].

## Background
NeRF was introduced by Mildenhall et al. in 2020, representing scenes as continuous volumetric functions [S1][S2, unofficial]. Gaussian Splatting was introduced by Kerbl et al. at SIGGRAPH 2023 as an explicit alternative [S2, unofficial]. Photon Field Networks were introduced to handle dynamic real-time volumetric global illumination [S1]. NeRF-based SLAM methods (SLAIM, SNI-SLAM, KN-SLAM, VI-NeRF-SLAM) have been developed from 2023 to 2024 to integrate neural representations into simultaneous localization and mapping [S3, S4].
