# Training Loop with Mixed Losses and Post-Processing

Also called: Mixed Loss Training Loop, Post-Processing Training Step

## Overview
This method defines the iterative optimization step for 3D Gaussian Splatting, integrating photometric reconstruction, depth consistency, and appearance regularization into a unified loss function. It distinguishes itself from simpler training loops by explicitly handling multi-modal supervision (RGB + Depth) and post-rasterization appearance corrections (Bilateral Grids), while managing the progressive update of Spherical Harmonic (SH) coefficients. It builds on [Progressive and Multi-stage Training](9966-progressive-and-multi-stage-training.md) by implementing the specific loss weighting and parameter updates that occur within a single training stage.

## How it works
**Inputs:**
- Current iteration step `step`.
- Gaussian primitive set $\mathcal{G}$ containing means $\mu$, scales $\sigma$, rotations $q$, opacities $\alpha$, and SH coefficients $c_{0..D}$.
- Camera parameters (view/projection matrices, intrinsics).
- Ground truth images $I_{gt}$ and optional depth maps $D_{gt}$.
- Configuration object `cfg` containing hyperparameters (e.g., `sh_degree`, `depth_lambda`, `opacity_reg`).

**Outputs:**
- Updated Gaussian parameters $\mathcal{G}'$.
- Optimizer states.

**Data Structures:**
- `splats`: Dictionary or tensor batch holding $\mu, \sigma, q, \alpha, c$.
- `info`: Dictionary returned by the rasterizer, containing `radii` (visibility mask), `gaussian_ids`, `alphas` (accumulated opacity), and `rendered_rgb`.

**Numbered Steps:**

1.  **Spherical Harmonic Degree Selection:**
    Determine the active SH degree $d$ for the current step to ensure progressive detail refinement:
    $$ d = \min\left(\left\lfloor \frac{step}{\text{cfg.sh\_degree\_interval}} \right\rfloor, \text{cfg.sh\_degree}\right) $$
    [S1, unofficial]

2.  **Rasterization:**
    Render the scene using the differentiable rasterizer. The render mode is determined by the presence of depth supervision:
    - If `cfg.depth_loss` is true, render mode is `'RGB+ED'` (RGB + Estimated Depth).
    - Otherwise, render mode is `'RGB'`.
    Let the output be `renders`, `alphas`, and `info`.
    [S1, unofficial]

3.  **Signal Separation:**
    If the render mode includes depth (4 channels), split `renders` into color $C_{raw}$ and depth $Z_{raw}$:
    $$ C_{raw} = \text{renders}[:, 0:3] $$
    $$ Z_{raw} = \text{renders}[:, 3:4] $$
    Otherwise, $C_{raw} = \text{renders}$ and $Z_{raw} = \text{None}$.
    [S1, unofficial]

4.  **Bilateral Grid Correction (Optional):**
    If `cfg.use_bilateral_grid` is true, compute grid coordinates $xy$ for each pixel and apply bilateral grid slicing to refine colors:
    $$ C_{bg} = \text{slice}(\text{self.bil\_grids}, xy, C_{raw}, \text{image\_ids}) $$
    [S1, unofficial]
    *Note: This step modifies the color signal before loss computation but does not directly update Gaussian parameters.*

5.  **Background Compositing (Optional):**
    If `cfg.random_bkgd` is true, generate a random background color $B \sim \mathcal{U}(0,1)^3$. Composite the foreground render onto this background:
    $$ C_{final} = C_{bg} + B \cdot (1.0 - \text{alphas}) $$
    [S1, unofficial]

6.  **Pre-Backward Strategy Hook:**
    Call `strategy.step_pre_backward(params, optimizers, state, step, info)`. This allows external strategies (e.g., MCMC or custom densification logic) to modify gradients or parameters before loss calculation.
    [S1, unofficial]

7.  **Reconstruction Loss Calculation:**
    Identify valid pixels (non-Nerf samples) using `is_nerf_sample`. For valid pixels, compute the photometric loss. If `cfg.use_l1_for_real_samples` is true, use L1; otherwise, use L2. Combine with Structural Similarity (SSIM) loss:
    $$ L_{recon} = L_{1/2}(C_{final}, I_{gt}) \cdot (1.0 - \text{cfg.ssim\_lambda}) + L_{SSIM}(C_{final}, I_{gt}) \cdot \text{cfg.ssim\_lambda} $$
    [S1, unofficial]

8.  **Depth Loss Calculation (Optional):**
    If `cfg.depth_loss` is true and valid pixels exist:
    a. Normalize 3D points to $[-1, 1]$ coordinate space.
    b. Sample ground truth depth $Z_{gt}$ from the depth map using bilinear interpolation (`F.grid_sample`).
    c. Compute disparity from rendered depth: $D_{raw} = 1.0 / Z_{raw}$ (where $Z_{raw} > 0$).
    d. Compute ground truth disparity: $D_{gt} = 1.0 / Z_{gt}$.
    e. Calculate L1 loss on disparity, scaled by scene scale:
    $$ L_{depth} = L_1(D_{raw}, D_{gt}) \cdot \text{self.scene\_scale} $$
    f. Add to total loss:
    $$ L_{total} = L_{recon} + L_{depth} \cdot \text{cfg.depth\_lambda} $$
    [S1, unofficial]

9.  **Bilateral Grid Total Variation (Optional):**
    If `cfg.use_bilateral_grid` is true, add a total variation regularization term to the bilateral grid parameters to prevent noisy artifacts:
    $$ L_{tv} = 10 \cdot \text{total\_variation\_loss}(\text{self.bil\_grids.grids}) $$
    $$ L_{total} = L_{total} + L_{tv} $$
    [S1, unofficial]

10. **Opacity Regularization (Optional):**
    If `cfg.opacity_reg > 0.0`, penalize high opacity values to encourage transparency where appropriate:
    $$ L_{opacity} = \text{cfg.opacity\_reg} \cdot \mathbb{E}[\sigma(\alpha)] $$
    where $\sigma$ is the sigmoid function.
    [S1, unofficial]

11. **Scale Regularization (Optional):**
    If `cfg.scale_reg > 0.0`, penalize large scales to prevent explosion:
    $$ L_{scale} = \text{cfg.scale\_reg} \cdot \mathbb{E}[\exp(\sigma)] $$
    [S1, unofficial]

12. **Backward Pass:**
    Compute gradients:
    $$ L_{total} = L_{recon} + L_{opacity} + L_{scale} + \dots $$
    $$ L_{total}.backward() $$
    [S1, unofficial]

13. **Visibility Masking (Optional):**
    If `cfg.visible_adam` is true, compute a mask $M$ of visible Gaussians to prevent gradient updates for invisible primitives:
    - If `cfg.packed`: $M$ is a sparse tensor with 1s at indices `info["gaussian_ids"]`.
    - Else: $M = (\text{info["radii"] > 0}).all(-1).any(0)$.
    [S1, unofficial]

14. **Optimizer Step:**
    Update Gaussian parameters:
    - If `cfg.visible_adam`: `optimizer.step(visibility_mask)`.
    - Else: `optimizer.step()`.
    - Zero gradients with `set_to_none=True`.
    [S1, unofficial]

15. **Auxiliary Optimizer Steps:**
    Step pose optimizers and bilateral grid optimizers, zeroing their gradients.
    [S1, unofficial]

16. **Scheduler Step:**
    Update learning rate schedulers.
    [S1, unofficial]

17. **Post-Backward Strategy Hook:**
    Call `strategy.step_post_backward`.
    - If `DefaultStrategy`: pass `packed=cfg.packed`.
    - If `MCMCStrategy`: pass `lr=schedulers[0].get_last_lr()[0]`.
    [S1, unofficial]

18. **Checkpointing (Conditional):**
    If `step` is in `cfg.ply_steps` or is the final step, and `cfg.save_ply` is true:
    - If `cfg.app_opt` is true: Bake appearance by evaluating the appearance module at the origin (view direction $\vec{d} = \vec{0}$), add to base colors, apply sigmoid, convert to SH0, and initialize empty SHN.
    - Else: Use stored `self.splats["sh0"]` and `self.splats["shN"]`.
    - Export PLY file with means, scales, quaternions, opacities, and SH coefficients.
    [S1, unofficial]

**Pseudocode:**

```python
def training_step(step, splats, cameras, gt_images, gt_depths, cfg, strategy, optimizer, pose_optimizers, bil_grid_optimizers, schedulers):
    # 1. SH Degree
    sh_degree_to_use = min(step // cfg.sh_degree_interval, cfg.sh_degree)
    
    # 2. Rasterize
    render_mode = 'RGB+ED' if cfg.depth_loss else 'RGB'
    renders, alphas, info = rasterize_gaussians(splats, cameras, render_mode)
    
    # 3. Split
    if renders.shape[-1] == 4:
        colors_raw = renders[..., 0:3]
        depths_raw = renders[..., 3:4]
    else:
        colors_raw = renders
        depths_raw = None
        
    # 4. Bilateral Grid (Optional)
    if cfg.use_bilateral_grid:
        grid_xy = compute_grid_coordinates(cameras)
        colors = slice_bilateral_grid(self.bil_grids, grid_xy, colors_raw, cameras.image_ids)
    else:
        colors = colors_raw
        
    # 5. Random Background (Optional)
    if cfg.random_bkgd:
        bkgd = torch.rand(1, 3, device=colors.device)
        colors = colors + bkgd * (1.0 - alphas)
        
    # 6. Pre-backward hook
    strategy.step_pre_backward(splats, optimizer, {}, step, info)
    
    # 7. Reconstruction Loss
    is_nerf_sample = detect_nerf_samples(cameras) # Placeholder for specific detection logic
    if not is_nerf_sample.any():
        if cfg.use_l1_for_real_samples:
            recon_loss = F.l1_loss(colors, gt_images)
        else:
            recon_loss = F.mse_loss(colors, gt_images)
        ssim_loss = compute_ssim(colors, gt_images)
        loss = recon_loss * (1.0 - cfg.ssim_lambda) + ssim_loss * cfg.ssim_lambda
    else:
        loss = torch.tensor(0.0, device=colors.device) # No valid pixels
        
    # 8. Depth Loss (Optional)
    if cfg.depth_loss and not is_nerf_sample.any():
        # Normalize points and sample depth
        points_3d = ... # From camera setup
        points_norm = normalize_to_ndc(points_3d)
        depths_gt_sampled = F.grid_sample(gt_depths, points_norm)
        disp_raw = 1.0 / (depths_raw + 1e-6)
        disp_gt = 1.0 / (depths_gt_sampled + 1e-6)
        depth_loss = F.l1_loss(disp_raw, disp_gt) * self.scene_scale
        loss = loss + depth_loss * cfg.depth_lambda
        
    # 9. Bilateral Grid TV (Optional)
    if cfg.use_bilateral_grid:
        tv_loss = 10 * total_variation_loss(self.bil_grids.grids)
        loss = loss + tv_loss
        
    # 10. Opacity Reg (Optional)
    if cfg.opacity_reg > 0.0:
        opacity_reg = cfg.opacity_reg * torch.sigmoid(splats["opacities"]).mean()
        loss = loss + opacity_reg
        
    # 11. Scale Reg (Optional)
    if cfg.scale_reg > 0.0:
        scale_reg = cfg.scale_reg * torch.exp(splats["scales"]).mean()
        loss = loss + scale_reg
        
    # 12. Backward
    loss.backward()
    
    # 13. Visibility Mask (Optional)
    if cfg.visible_adam:
        if cfg.packed:
            visibility_mask = torch.zeros_like(splats["opacities"])
            visibility_mask.scatter_(0, info["gaussian_ids"], 1.0)
        else:
            visibility_mask = (info["radii"] > 0).all(-1).any(0)
    else:
        visibility_mask = None
        
    # 14. Optimizer Step
    if visibility_mask is not None:
        optimizer.step(visibility_mask)
    else:
        optimizer.step()
    optimizer.zero_grad(set_to_none=True)
    
    # 15. Aux Optimizers
    if pose_optimizers:
        for opt in pose_optimizers:
            opt.step()
            opt.zero_grad()
    if bil_grid_optimizers:
        for opt in bil_grid_optimizers:
            opt.step()
            opt.zero_grad()
            
    # 16. Schedulers
    for scheduler in schedulers:
        scheduler.step()
        
    # 17. Post-backward hook
    if isinstance(strategy, MCMCStrategy):
        lr = schedulers[0].get_last_lr()[0]
        strategy.step_post_backward(lr=lr)
    else:
        strategy.step_post_backward(packed=cfg.packed)
        
    # 18. Checkpointing
    if step in cfg.ply_steps or step == cfg.max_steps - 1:
        if cfg.save_ply:
            if cfg.app_opt:
                # Bake appearance
                dirs = torch.zeros_like(cameras.directions)
                app_colors = evaluate_app_module(splats, dirs)
                final_colors = torch.sigmoid(app_colors + splats["colors"])
                sh0 = final_colors
                shN = torch.zeros_like(splats["shN"])
            else:
                sh0 = splats["sh0"]
                shN = splats["shN"]
            export_ply(splats["means"], splats["scales"], splats["quats"], 
                       splats["opacities"], sh0, shN, step)
```

## Operating characteristics
- **Time Complexity:** Dominated by rasterization $O(N \cdot P)$ where $N$ is the number of Gaussians and $P$ is the number of pixels. The bilateral grid slicing adds overhead proportional to the grid resolution.
- **Memory Complexity:** $O(N)$ for Gaussian parameters. Bilateral grids add $O(G)$ where $G$ is the grid size.
- **Strengths:** Explicit depth supervision improves geometric consistency. Bilateral grids allow for high-frequency appearance details without increasing Gaussian count. Progressive SH degree prevents early-stage instability.
- **Limitations:** Depth loss requires accurate ground truth depth. Bilateral grids introduce additional hyperparameters and potential artifacts if not regularized.
- **When to use:** When high-fidelity appearance and geometric consistency are required, and ground truth depth is available.

## Background
This training loop is derived from the implementation details of the AugSplat project, which extends 3D Gaussian Splatting with appearance optimization and depth supervision. It integrates concepts from differentiable rendering and multi-stage training strategies.
