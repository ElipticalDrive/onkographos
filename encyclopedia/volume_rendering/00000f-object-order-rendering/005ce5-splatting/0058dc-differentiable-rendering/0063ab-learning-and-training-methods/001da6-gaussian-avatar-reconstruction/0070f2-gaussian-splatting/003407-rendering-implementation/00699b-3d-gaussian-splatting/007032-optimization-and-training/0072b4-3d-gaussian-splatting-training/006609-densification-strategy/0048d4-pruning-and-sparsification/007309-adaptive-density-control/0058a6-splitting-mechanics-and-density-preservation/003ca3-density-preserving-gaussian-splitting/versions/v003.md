# Density-preserving Gaussian splitting

Also called: BOGausS splitting, density-preserving split

## Overview
Density-preserving Gaussian splitting is a densification strategy that modifies the parameters of split Gaussian children to maintain the volumetric density of the parent Gaussian, thereby preventing loss function perturbations and Gaussian clustering [S1]. Unlike standard 3D Gaussian Splatting (3DGS) which uses both cloning and splitting, this method discards cloning entirely and relies exclusively on splitting with learned opacity and size adaptations [S1].

## How it works
**Inputs and Outputs**
*   **Input**: A parent Gaussian $g_{mother}$ with size $\sigma_{mother}$ and opacity $o_{mother}$, and a shift constant $\alpha$.
*   **Output**: Two child Gaussians $g_{child,1}$ and $g_{child,2}$ with adjusted sizes $\sigma_{child}$ and opacities $o_{child}$.

**Data Structures**
*   **Gaussian Properties**: Each Gaussian is defined by position $\mu$, scale $s$ (or covariance $\Sigma$), opacity $\alpha$, rotation $q$, and spherical harmonics coefficients $c$ [Parent].
*   **Split Adaptation Function**: A mapping $(\sigma_{child}, o_{child}) = \text{SplitAdaptation}(\sigma_{mother}, o_{mother})$ [S1]. The specific functional form is learned offline [S1].

**Steps**
1.  **Identify Split Axis**: Determine the longest principal axis of the parent Gaussian's covariance matrix [S1].
2.  **Shift Means**: Calculate the shift magnitude $\Delta = \alpha \sigma$, where $\sigma$ is the size of the parent Gaussian along the splitting axis [S1].
3.  **Compute Child Positions**: Create two child positions by shifting the parent mean $\mu_{mother}$ along the principal axis:
    $$ \mu_{child,1} = \mu_{mother} + \alpha \sigma \hat{u} $$
    $$ \mu_{child,2} = \mu_{mother} - \alpha \sigma \hat{u} $$
    where $\hat{u}$ is the unit vector of the longest principal axis [S1].
4.  **Adapt Parameters**: Compute the child size $\sigma_{child}$ and opacity $o_{child}$ using the offline-learned adaptation function to ensure the sum of the children's densities approximates the parent's density [S1]:
    $$ (\sigma_{child}, o_{child}) = \text{SplitAdaptation}(\sigma_{mother}, o_{mother}) $$
    This step explicitly accounts for opacity variations, unlike some prior methods [S1].
5.  **Replace Parent**: Remove the parent Gaussian and insert the two children into the scene representation [S1].

**Parameters**
*   **$\alpha$**: Constant controlling the mean shift magnitude. Typical value: $0.3$ [S1].

**Edge Cases and Pitfalls**
*   **Clustering**: Standard splitting can lead to clusters of Gaussians. This method prevents such clusters by preserving density and discarding cloning [S1].
*   **Loss Perturbation**: Original splitting operations cause perturbations in the loss function. The density-preserving adaptation limits these perturbations [S1].
*   **Opacity Reset**: This method replaces the opacity reset mechanism used in 3DGS. Instead, it relies on pruning based on an opacity threshold [S1].

**Pseudocode**
```python
def density_preserving_split(gaussian, alpha=0.3):
    """
    Splits a Gaussian into two children while preserving density.
    
    Args:
        gaussian: Object with attributes .mu (position), .cov (covariance matrix), 
                  .sigma (size vector), .opacity.
        alpha: Shift constant (default 0.3).
        
    Returns:
        List of two new Gaussian objects.
    """
    # 1. Identify longest principal axis
    eigenvalues, eigenvectors = np.linalg.eigh(gaussian.cov)
    # Get index of largest eigenvalue
    longest_axis_idx = np.argmax(eigenvalues)
    u = eigenvectors[:, longest_axis_idx]
    
    # 2. Get size along splitting axis
    # sigma is typically the scale vector; assume sigma[longest_axis_idx] corresponds to the axis
    sigma_axis = gaussian.sigma[longest_axis_idx]
    
    # 3. Shift means
    shift = alpha * sigma_axis * u
    mu1 = gaussian.mu + shift
    mu2 = gaussian.mu - shift
    
    # 4. Adapt parameters using offline-learned function
    # SplitAdaptation is a black-box function learned offline
    sigma_child, opacity_child = SplitAdaptation(gaussian.sigma, gaussian.opacity)
    
    # 5. Construct children
    child1 = Gaussian(
        mu=mu1,
        cov=gaussian.cov, # Covariance may also need adjustment, but sources specify size/opacity
        sigma=sigma_child,
        opacity=opacity_child,
        rotation=gaussian.rotation,
        sh_coeffs=gaussian.sh_coeffs
    )
    
    child2 = Gaussian(
        mu=mu2,
        cov=gaussian.cov,
        sigma=sigma_child,
        opacity=opacity_child,
        rotation=gaussian.rotation,
        sh_coeffs=gaussian.sh_coeffs
    )
    
    return [child1, child2]
```

## Operating characteristics
*   **Complexity**: Splitting increases the number of Gaussians by 1 per operation. The adaptation function is $O(1)$ if pre-computed or simple.
*   **Strengths**: Prevents loss perturbations and Gaussian clustering associated with naive splitting and cloning [S1].
*   **Limitations**: Requires offline learning of the adaptation function [S1]. Discards cloning, which may affect under-reconstruction handling compared to standard 3DGS [S1].
*   **When to use**: When training stability is a concern due to loss perturbations or when Gaussian clustering is observed [S1].

## Background
This method is introduced in BOGausS (Better Optimized Gaussian Splatting) [S1]. It addresses issues identified in original 3DGS splitting, such as loss perturbations and clustering [S1]. It builds on correction mechanisms proposed in [5, 9] and inspired by [16] [S1]. It differs from [17] by accounting for opacity variations [S1].
