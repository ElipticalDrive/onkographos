# Hybrid Radiance Fields (HyRF)


## Overview
Hybrid Radiance Fields (HyRF) is a scene representation method that decomposes a scene into a compact set of explicit 3D Gaussians storing critical high-frequency parameters and grid-based neural fields that predict the remaining properties [S1]. It addresses the memory overhead and limited representational capacity of standard 3D Gaussian Splatting by decoupling geometry and appearance into separate neural fields, enabling a 20× reduction in model size while maintaining real-time rendering speeds and state-of-the-art quality [S1].

## How it works
The method takes a set of training images and camera poses as input, and produces a rendered image for a target camera pose along with an optimized scene representation consisting of explicit Gaussian parameters and neural field weights [S1].

**Data Structures**
Explicit Gaussians store exactly 8 parameters per Gaussian: position $p_e \in \mathbb{R}^3$, diffuse color $c_e \in \mathbb{R}^3$, isotropic scale $s_e \in \mathbb{R}$, and opacity $\alpha_e \in \mathbb{R}$ [S1]. Rotation is not stored explicitly but is predicted by the neural field [S1]. Two separate neural fields, $\Theta_{geo}$ and $\Theta_{rad}$, use multi-resolution hash encoding for coordinate compression [S1]. $\Theta_{geo}$ predicts geometry properties (scale, opacity, rotation), while $\Theta_{rad}$ predicts appearance properties (view-dependent color) [S1].

**Coordinate Preprocessing**
Before querying the neural fields, 3D points are normalized and contracted to the range $(0, 1)$ to handle unbounded scenes [S1]. The axis-aligned bounding box (AABB) $B_0$ is defined as the minimum and maximum camera positions of the scene [S1]. The point $p_i$ is normalized using $B_0$, then contracted to $p'_i$ using the formula [S1]:

$$
\text{contract}(p_i) = 
\begin{cases} 
0.25 \cdot p_i + 1 & \text{if } \|p_i\| \le 1 \\
\frac{p_i}{0.25 \cdot (2 - \|p_i\|) + 1} & \text{otherwise}
\end{cases}
$$

**Hybrid Rendering Pipeline**
The rendering process operates in three stages [S1].
1. Visibility Pre-culling: Eliminates explicit Gaussians outside the current view frustum to reduce computational overhead of querying neural fields [S1].
2. Neural Property Prediction & Combination: For remaining visible Gaussians, queries their positions through the neural fields to predict missing properties, then combines them with stored explicit parameters to recover high-frequency details [S1]. $\Theta_{geo}$ is queried with the contracted position to predict scale, opacity, and rotation [S1]. $\Theta_{rad}$ is queried with the contracted position and view direction to predict view-dependent color [S1]. Predicted geometry is combined with explicit geometry, and predicted color is combined with explicit diffuse color [S1].
3. Background Compositing: The neural field generates a background map projected onto a background sphere, which is composited with the foreground Gaussian rendering through alpha blending to address insufficient background modeling for distant objects [S1].

**Alpha Blending**
The final pixel color $C$ is computed using standard point-based alpha blending [S1]:

$$
C = \sum_{i \in N} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j)
$$

Where $C$ is the final predicted pixel color, $N$ is the set of sorted Gaussians projected onto the pixel, $c_i$ is the color of the $i$-th Gaussian, and $\alpha_i$ is the opacity of the $i$-th Gaussian [S1].

**Pseudocode**

```python
import math

def contract(p):
    norm = math.sqrt(p[0]**2 + p[1]**2 + p[2]**2)
    if norm <= 1.0:
        return (0.25 * p[0] + 1.0, 0.25 * p[1] + 1.0, 0.25 * p[2] + 1.0)
    denom = 0.25 * (2.0 - norm) + 1.0
    return (p[0] / denom, p[1] / denom, p[2] / denom)

def frustum_cull(gaussians, camera):
    visible = []
    for g in gaussians:
        if camera.min_x <= g.pos[0] <= camera.max_x and \
           camera.min_y <= g.pos[1] <= camera.max_y and \
           camera.min_z <= g.pos[2] <= camera.max_z:
            visible.append(g)
    return visible

def render_background_sphere(theta_rad, hash_table, camera, resolution=256):
    bg_image = [[(0.0, 0.0, 0.0) for _ in range(resolution)] for _ in range(resolution)]
    for y in range(resolution):
        for x in range(resolution):
            theta = math.pi * (y + 0.5) / resolution
            phi = 2.0 * math.pi * (x + 0.5) / resolution
            dir_vec = (math.sin(theta) * math.cos(phi), math.sin(theta) * math.sin(phi), math.cos(theta))
            bg_image[y][x] = theta_rad.query(dir_vec, hash_table)
    return bg_image

def alpha_blend_gaussians(gaussians, camera):
    height, width = camera.height, camera.width
    image = [[(0.0, 0.0, 0.0) for _ in range(width)] for _ in range(height)]
    for g in gaussians:
        alpha = g.opacity
        color = g.color
        for y in range(g.screen_y, g.screen_y + g.screen_h):
            for x in range(g.screen_x, g.screen_x + g.screen_w):
                if 0 <= y < height and 0 <= x < width:
                    r, gc, b = image[y][x]
                    image[y][x] = (r * (1 - alpha) + color[0] * alpha,
                                   gc * (1 - alpha) + color[1] * alpha,
                                   b * (1 - alpha) + color[2] * alpha)
    return image

def render_hyrf(camera, explicit_gaussians, theta_geo, theta_rad, hash_table):
    # Stage 1: Visibility Pre-culling
    visible_gaussians = frustum_cull(explicit_gaussians, camera)

    # Stage 2: Neural Property Prediction & Combination
    processed_gaussians = []
    for g in visible_gaussians:
        p_norm = (g.pos[0] / camera.aabb_scale, g.pos[1] / camera.aabb_scale, g.pos[2] / camera.aabb_scale)
        p_contracted = contract(p_norm)

        pred_geo = theta_geo.query(p_contracted, hash_table)
        final_scale = g.scale * pred_geo.scale
        final_opacity = g.opacity * pred_geo.opacity
        final_rotation = pred_geo.rotation

        view_dir = (g.pos[0] - camera.position[0], g.pos[1] - camera.position[1], g.pos[2] - camera.position[2])
        v_len = math.sqrt(view_dir[0]**2 + view_dir[1]**2 + view_dir[2]**2)
        view_dir = (view_dir[0]/v_len, view_dir[1]/v_len, view_dir[2]/v_len)
        pred_color = theta_rad.query(p_contracted, view_dir, hash_table)
        final_color = (g.color_diffuse[0] + pred_color[0], g.color_diffuse[1] + pred_color[1], g.color_diffuse[2] + pred_color[2])

        processed_gaussians.append({
            'pos': g.pos, 'color': final_color, 'scale': final_scale,
            'opacity': final_opacity, 'rotation': final_rotation
        })

    # Stage 3: Background Compositing
    foreground_image = alpha_blend_gaussians(processed_gaussians, camera)
    background_image = render_background_sphere(theta_rad, hash_table, camera)

    final_image = [[(0.0, 0.0, 0.0) for _ in range(camera.width)] for _ in range(camera.height)]
    for y in range(camera.height):
        for x in range(camera.width):
            fg = foreground_image[y][x]
            bg = background_image[y][x]
            final_image[y][x] = (fg[0] + bg[0] * (1 - fg[2]), fg[1] + bg[1] * (1 - fg[2]), fg[2] + bg[2] * (1 - fg[2]))
    return final_image
```

**Parameters**
Neural field encoding uses multi-resolution hash encoding [S1].

**Edge Cases and Pitfalls**
Predicting all Gaussian properties through a single neural field fails due to weak correlation between geometry and appearance attributes, necessitating the decoupled architecture [S1]. Standard Gaussian representations have insufficient background modeling for distant objects, addressed by the background sphere compositing [S1]. Failing to pre-cull Gaussians leads to significant computational overhead when querying neural fields for invisible regions [S1].

## Operating characteristics
The method reduces model size by over 20× compared to standard 3D Gaussian Splatting (3DGS) [S1]. It maintains real-time rendering speeds [S1]. It achieves state-of-the-art rendering quality [S1].

## Background
Hybrid Radiance Fields (HyRF) was introduced to address the limitations of explicit Gaussian representations in terms of memory overhead and representational capacity for fine details [S1]. It builds on the principles of 3D Gaussian Splatting and integrates them with neural radiance fields (NeRF) concepts, specifically multi-resolution hash encoding [S1]. The method was developed to provide a memory-efficient and high-quality novel view synthesis solution [S1].
