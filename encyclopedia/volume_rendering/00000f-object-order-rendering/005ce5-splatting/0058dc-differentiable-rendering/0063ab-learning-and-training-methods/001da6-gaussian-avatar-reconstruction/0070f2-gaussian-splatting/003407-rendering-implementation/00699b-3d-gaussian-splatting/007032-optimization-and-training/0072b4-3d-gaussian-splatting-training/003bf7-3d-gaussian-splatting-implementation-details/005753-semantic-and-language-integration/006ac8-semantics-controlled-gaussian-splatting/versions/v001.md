# Semantics-Controlled Gaussian Splatting


## Overview
Semantics-Controlled Gaussian Splatting (SCGS) is a method that integrates semantic segmentation directly into the 3D Gaussian Splatting representation by assigning class IDs to individual 3D Gaussians [S1]. It modifies the standard rasterization pipeline to render both RGB colors and semantic maps simultaneously, enabling differentiable training of semantic labels via cross-entropy loss [S1]. Unlike sibling methods that rely on post-hoc classification or convex hulls for object removal, SCGS allows for direct, large-scale scene editing and extraction of specific semantic classes in 3D space, which is particularly advantageous for non-circular capturing setups where traditional geometric removal methods fail [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sparse point cloud (from COLMAP), camera poses, and 2D semantic segmentation masks (e.g., from SAM DEVA) for the input images [S1].
*   **Outputs:** A set of 3D Gaussians, each containing position, covariance, density, spherical harmonics (SH) for RGB, and a semantic class ID [S1]. Rendered RGB images and semantic maps [S1].

**Data Structures:**
Each Gaussian $G$ in the scene representation stores:
1.  **Center Position:** 3D vector $\mathbf{x}$ [S1].
2.  **Covariance Matrix:** 3D covariance matrix $\Sigma$ (derived from rotation and scaling matrices) [S1].
3.  **Density:** Scalar $\sigma$ [S1].
4.  **Appearance:** Spherical Harmonics (SH) coefficients for RGB color encoding [S1].
5.  **Semantics:** A discrete class ID (or probability distribution over classes) $s$ [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize 3D Gaussians from a sparse point cloud. Each Gaussian $G$ is defined by its 3D center $\mathbf{x}$, 3D covariance matrix $\Sigma$, density $\sigma$, and SH coefficients for RGB [S1].

2.  **2D Projection:** For each Gaussian, compute the 2D rasterized covariance $\Sigma'$ using the Jacobian $J$ of the affine approximation of the projection and the world-to-camera transformation matrix $W$:
    $$ \Sigma' = J W \Sigma W^T J^T $$
    [S1]

3.  **RGB Rasterization:** Convert SH coefficients to RGB values $c_i$ for each Gaussian. Splat the Gaussians onto the 2D image plane using alpha blending to retrieve pixel color $RGB$:
    $$ RGB = \sum_{i \in N} T_i \alpha_i c_i $$
    where $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the accumulated transmittance, $\alpha_i$ is the opacity of the $i$-th Gaussian, and $N$ is the set of Gaussians sorted by depth [S1].

4.  **Semantic Rasterization:** Perform a parallel rasterization process for the semantic map. Set the SH components to zero to isolate semantic attributes. Compute the segmentation value for each pixel by alpha blending the class probabilities $s_{ic}$ (probability of class $c$ for Gaussian $i$):
    $$ SEGMENTATION_c = \sum_{i \in N} T_i \alpha_i s_{ic} $$
    [S1]

5.  **Loss Calculation:** Apply cross-entropy loss to supervise the 3D Gaussian segmentation. Let $s_{ic}$ be the predicted probability for class $c$ at pixel $i$, and $s_{ic}^{gt}$ be the ground truth segmentation for class $c$ at pixel $i$. The loss is computed over all pixels and classes [S1].

6.  **Optimization:** Backpropagate the loss through the differentiable rendering pipeline to update the Gaussian parameters (position, covariance, density, SH, and semantic class assignments) [S1].

7.  **Scene Editing (Optional):** To remove an object or class, filter the Gaussians using an indicator function. For a removed class ID $c_r$, the new set of Gaussians $G_{new}$ is:
    $$ G_{new}(\mathbf{x}; \Sigma) = G(\mathbf{x}; \Sigma) \cdot I(s_i \neq c_r) $$
    where $I(\cdot)$ is the indicator function that retains only Gaussians not belonging to the removed class [S1].

**Edge Cases and Pitfalls:**
*   **Non-Circular Capture:** Traditional convex hull methods for object removal may remove too much of the scene or fail in non-circular capturing setups. SCGS avoids this by using direct class-based removal [S1].
*   **Feature Similarity:** SCGS addresses challenges related to feature space similarities, especially in outdoor scenes with significant reflections, by assigning class IDs directly during training rather than relying on separate classifiers [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** SCGS outperforms baseline methods using continuous labels from SAM DEVA on all tested outdoor scenes in terms of PSNR, SSIM, and LPIPS [S1]. It also outperforms existing work on one out of five scenes and performs competitively on all other scenes on the 3D-OVS dataset in terms of mIoU [S1].
*   **Strengths:** Direct class assignment enables large-scale removal of complete classes without feature similarity issues. It works well in non-circular capturing setups. It improves NVS quality on outdoor scenes [S1].
*   **Limitations:** Not given in the sources.
*   **When to Use:** When semantic segmentation and direct object removal are required in 3D Gaussian Splatting, especially for outdoor scenes or non-circular capture setups [S1].
*   **When Not to Use:** When computational resources are limited to less than 24GB VRAM per scene, or when circular capture setups are used and convex hull methods are sufficient [S1].

## Background
*   **Origin:** SCGS was introduced in the paper "Semantics-Controlled Gaussian Splatting for Outdoor Scene Reconstruction and Rendering in Virtual Reality" [S1].
*   **History and Development:** The method builds on 3D Gaussian Splatting [20] and integrates semantic information by extending the conventional RGB rasterization process [S1]. It diverges from traditional classification-based approaches [60, 63] by assigning class IDs consistently during training [S1].
*   **Usage:** It is used for accurate scene editing, extraction of large scene parts, and VR experiences in non-circular capturing setups [S1].
