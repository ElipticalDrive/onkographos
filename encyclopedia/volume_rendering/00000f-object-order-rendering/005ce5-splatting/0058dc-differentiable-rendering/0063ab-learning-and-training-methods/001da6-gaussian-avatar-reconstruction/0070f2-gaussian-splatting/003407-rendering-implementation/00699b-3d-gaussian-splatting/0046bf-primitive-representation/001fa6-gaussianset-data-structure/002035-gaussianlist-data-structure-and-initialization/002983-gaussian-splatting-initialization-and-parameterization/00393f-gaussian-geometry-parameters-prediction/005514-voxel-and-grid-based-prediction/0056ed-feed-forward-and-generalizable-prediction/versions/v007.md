# Feed-forward and Generalizable Prediction

Also called: Feed-forward Gaussian Splatting, Generalizable 3D Gaussian Splatting

## Overview
This family of methods predicts 3D Gaussian Splatting parameters directly from a set of input images in a single forward pass, eliminating the iterative per-scene optimization required by standard 3D Gaussian Splatting. It differs from iterative optimization by trading per-scene adaptability for inference speed and generalization to unseen scenes, and from other feed-forward approaches by the specific architectural choices (e.g., voxelization, spatial grouping, or 2D primitives) used to bridge 2D image features to 3D geometry.

## Shared principles
All methods in this family share the following mechanism:
1.  **Input:** A set of $N$ RGB images $\{I_i\}_{i=1}^N$ with associated camera poses (intrinsics and extrinsics) or uncalibrated inputs.
2.  **Feature Extraction:** A backbone network (e.g., Transformer, CNN) extracts multi-scale features from the input images.
3.  **Parameter Prediction:** A decoder network predicts Gaussian parameters $\Theta = \{\mu, \sigma, r, s, c, \alpha\}$ (mean, scale, rotation, spherical harmonics/color, opacity) either per-pixel, per-token, or as a global set.
4.  **Differentiable Rendering:** The predicted Gaussians are rendered to images using differentiable rasterization to compute reconstruction losses.
5.  **Training:** The network is trained end-to-end using photometric losses (e.g., L1, LPIPS) and often geometry losses (depth, pose consistency) derived from pseudo-labels or ground truth.

## Subtopics

### [AnySplat Pipeline](12847-anysplat-pipeline.md)
AnySplat predicts 3D Gaussian Splatting parameters, camera poses, and depth maps from uncalibrated input images. It differs from siblings like [FineSplat](15257-finesplat.md) by explicitly handling unconstrained views with unknown intrinsics/extrinsics using a differentiable voxelization module to bridge pixel-wise predictions and global scene representation. Choose it when camera parameters are unknown or when robustness to uncalibrated inputs is required.

### [FineSplat](15257-finesplat.md)
FineSplat is a feed-forward framework that predicts 3D Gaussians from $N$ context views using a dual-grouping strategy. It distinguishes itself from siblings like [YoNoSplat](15813-sparsplat.md) by employing high-resolution 4x4 patch tokens and a two-stage process that restricts attention scope to avoid the prohibitive cost of global multi-view attention while ensuring fine-grained interactions. Choose it for high-fidelity reconstruction from a moderate number of context views where computational efficiency of attention is critical.

### [SparSplat](15813-sparsplat.md)
SparSplat maps a sparse set of input images to 2D Gaussian Splatting (2DGS) parameters in a single forward pass. It differs from its sibling [MVSGaussian](12847-anysplat-pipeline.md) by using 2D primitives instead of 3D Gaussians, ensuring multi-view depth consistency required for coherent TSDF mesh fusion. Choose it when explicit 3D mesh reconstruction is a primary goal alongside novel view synthesis.

### [HFGaussian](16422-hfgaussian.md)
A human-centric Gaussian framework that estimates 3D human avatars with integrated biomechanical features (3D skeleton, 3D keypoints, dense pose) and 3D pose in real time from sparse input images, without fine-tuning on unseen data.

### [Splatt3R](16423-splatt3r.md)
A feed-forward model that takes two uncalibrated images as input and outputs 3D Gaussian parameters for geometry and appearance, without requiring camera intrinsics, extrinsics, or depth.

### 3D-aware Image Synthesis via Sparse Voxel Grids

- [S1] A 3D-aware image synthesis generator that predicts color and density values on a sparse voxel grid, conditioned on camera pose.

## Background
Feed-forward generalizable models for 3D Gaussian Splatting emerged as a solution to the high computational cost and time required for per-scene optimization in standard 3DGS. Early works like [Splatt3R](16423-splatt3r.md) and [AnySplat](12847-anysplat-pipeline.md) focused on removing the dependency on calibrated camera inputs, leveraging pseudo-geometry priors from models like VGGT. Subsequent methods like [FineSplat](15257-finesplat.md) introduced sophisticated attention mechanisms to handle multi-view consistency at scale. [SparSplat](15813-sparsplat.md) shifted the primitive representation to 2D Gaussians to improve mesh reconstruction quality via TSDF fusion. The family also includes specialized variants for human avatars ([HFGaussian](16422-hfgaussian.md)) and 3D-aware synthesis using sparse voxel grids ([S1]).
