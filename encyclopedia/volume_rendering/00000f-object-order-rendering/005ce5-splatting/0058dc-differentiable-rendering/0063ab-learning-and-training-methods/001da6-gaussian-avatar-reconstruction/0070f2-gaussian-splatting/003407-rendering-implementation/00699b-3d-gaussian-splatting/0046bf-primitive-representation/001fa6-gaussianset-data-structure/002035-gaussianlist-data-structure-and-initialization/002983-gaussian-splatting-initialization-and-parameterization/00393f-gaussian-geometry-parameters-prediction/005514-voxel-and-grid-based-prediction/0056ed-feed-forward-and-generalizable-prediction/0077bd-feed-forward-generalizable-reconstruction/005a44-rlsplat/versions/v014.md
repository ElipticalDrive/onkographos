# RLSplat

Also called: Resource-Linear Budget Control for Feed-forward 3D Gaussian Splatting

## Overview
RLSplat is a resource-linear, budget-controllable feed-forward 3D Gaussian Splatting (FF3DGS) framework that ensures inference latency, peak memory, and representation size all decrease linearly as the target Gaussian budget $B$ is reduced [S1, unofficial]. Unlike prior budget-controllable methods that predict a dense set of candidates and prune them—resulting in nearly constant inference costs regardless of the budget—RLSplat learns a Gaussian allocation policy to distribute exactly $B$ Gaussians across local scene regions from the start [S1, unofficial]. It then refines these Gaussians using a resource-linear decoder based on local cross-attention with a hierarchical neighbor search [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $V$ uncalibrated context images $\{I_i\}_{i=1}^V$ and a target integer Gaussian budget $B$.
*   **Outputs:** A set of $B$ 3D Gaussians $\mathcal{G} = \{g_b\}_{b=1}^B$ and the context camera parameters $\{P_i\}_{i=1}^V$. Each Gaussian $g_b$ consists of a 3D center, opacity, scale, rotation, and color coefficients [S1, unofficial].

**Data Structures:**
1.  **Anchor Tokens:** The geometry backbone encodes the input images into $N$ anchor tokens $\{a_n\}_{n=1}^N$. Each anchor represents a local 3D region of the scene [S1, unofficial].
2.  **Allocation Vector:** A discrete allocation vector $\mathbf{k} \in \mathbb{Z}_{\ge 0}^N$, where $k_n$ is the number of Gaussians assigned to anchor $n$. The constraint is $\sum_{n=1}^N k_n = B$ [S1, unofficial].
3.  **Gaussian Tokens:** Each anchor $n$ spawns $k_n$ Gaussian tokens. The total number of Gaussian tokens is exactly $B$ [S1, unofficial].
4.  **Hierarchical Neighbor Search Structures:** Used to find the $K_{gs}$ nearest Gaussian neighbors and $K_{anc}$ nearest anchor neighbors efficiently [S1, unofficial].

**Parameters:**
*   $B$: Target Gaussian budget. Typical evaluation values are 2,048 (2K) and 64,000 (64K). On the ACID dataset (8 views), $B=8,192$ (1,024 per view) is used. On RE10K, $B=8,000$ is used [S1, unofficial].
*   $K_{gs}$: Number of nearest Gaussian neighbors each token attends to during refinement. Default ablation value is 16. This can be changed at inference without retraining [S1, unofficial].
*   $K_{anc}$: Number of anchor neighbors used in the hierarchical neighbor search. Fixed value in ablations is 16 [S1, unofficial].
*   $C$: Number of rollouts (candidate allocations) drawn per training step for the Group Sequence Policy Optimization (GSPO) [S1, unofficial].

**Algorithm Steps:**

1.  **Geometry Encoding:** Given context images $\{I_i\}$, a geometry backbone (e.g., Burzio et al., 2026) encodes them into $N$ anchor tokens $\{a_n\}_{n=1}^N$ and predicts camera parameters $\{P_i\}$ [S1, unofficial].
2.  **Gaussian Allocation:** A Gaussian allocation policy $\pi_\psi$ assesses the local significance of each anchor (based on image features like texture complexity) to predict a discrete allocation $\mathbf{k}$. The policy is trained using GSPO to ensure $\sum k_n = B$. At training time, $C$ candidate allocations are sampled from the policy: $\mathbf{k}^{(c)} \sim \pi_{old} = \text{Mult}(B, \text{sg}(p))$, where $\text{sg}(\cdot)$ stops gradients [S1, unofficial].
3.  **Token Spawning:** For each anchor $n$, $k_n$ Gaussian tokens are spawned. The total number of Gaussian tokens is exactly $B$ [S1, unofficial].
4.  **Resource-Linear Decoding:**
    *   **Initialization:** The decoder instantiates initial Gaussians from the tokens.
    *   **Hierarchical Neighbor Search:** For each Gaussian token, the system finds its $K_{gs}$ nearest Gaussian neighbors and $K_{anc}$ nearest anchor neighbors using an efficient hierarchical search [S1, unofficial].
    *   **Local Refinement:** Each Gaussian token refines its state through local cross-attention over its $K_{gs}$ nearest Gaussian neighbors. This avoids global self-attention, reducing complexity from $O(B^2)$ to $O(B \cdot K_{gs})$ [S1, unofficial].
5.  **Loss Computation (Training):** For each rollout $c$, the 3DGS representation $\mathcal{G}^{(c)}$ is rendered at novel target views to produce $\hat{I}^{(c)}$. The reconstruction loss $\mathcal{L}_{recon}$ against ground truth $I$ is computed without gradient tracking. This loss serves as the reward signal for the policy optimization [S1, unofficial]. Additional losses include an offset loss ($\mathcal{L}_{offset}$), a Voronoi loss ($\mathcal{L}_{vor}$), and a projection loss ($\mathcal{L}_{proj}$) which ties anchors to their encoded image regions [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Training Failure:** Removing the projection loss ($\mathcal{L}_{proj}$) causes training to fail entirely, as it ties an anchor's Gaussians to the image region it was encoded from [S1, unofficial].
*   **Neighbor Search Accuracy:** Removing the Voronoi loss ($\mathcal{L}_{vor}$) causes a significant PSNR drop (2.51 dB) because Gaussians leave their anchor's cell, and the hierarchical search no longer retrieves their true neighbors [S1, unofficial].
*   **Refinement Necessity:** Removing the local refinement module lowers PSNR by 0.96 dB, as Gaussians cannot be made consistent with their neighbors if predicted from their own token alone [S1, unofficial].
*   **Precision:** The allocation policy uses reinforcement learning (GSPO) to handle non-differentiable discrete allocations [S1, unofficial].

## Subtopics

### Gaussian Allocation Policy
A policy trained with GSPO that distributes exactly $B$ Gaussians across anchors based on local significance (e.g., texture complexity), concentrating capacity where fine geometric details require it [S1, unofficial].

### Resource-Linear Decoder
A decoder that refines Gaussians through local cross-attention over $K_{gs}$ nearest neighbors found via hierarchical neighbor search, ensuring decoding cost scales as $O(B \cdot K_{gs})$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The decoding cost is $O(B \cdot K_{gs})$, scaling linearly with the Gaussian budget $B$. This is a significant improvement over global self-attention, which costs $O(B^2)$ [S1, unofficial].
*   **Memory Complexity:** Peak memory scales linearly with $B$ [S1, unofficial].
*   **Measured Performance:**
    *   At $B=2,048$ (2K), RLSplat achieves higher PSNR than F4 Splat while using 9.6× less peak memory and running 4.1× faster [S1, unofficial].
    *   On ACID ($B=8,192$), RLSplat achieves PSNR 22.84 dB, SSIM 0.643, LPIPS 0.353 [S1, unofficial].
    *   On RE10K ($B=8,000$), RLSplat achieves full-view PSNR 26.51 dB, compared to 23.42 dB for F4 Splat and 21.82 dB for EcoSplat [S1, unofficial].
*   **Scaling:** Inference cost (latency and peak memory) scales linearly with the Gaussian budget $B$ [S1, unofficial].
*   **Strengths:**
    *   True resource-linearity: Latency and memory decrease as $B$ decreases.
    *   Superior quality at low budgets: Allocates more Gaussians to high-frequency structures (e.g., 5,388 vs. 2,521/3,026 for thin stair balusters) and fewer on smooth walls [S1, unofficial].
    *   Efficient neighbor search: Hierarchical search is 27× faster than exact search (8.1 ms vs. 219.6 ms at 65,536 Gaussians) [S1, unofficial].
*   **Limitations:**
    *   Requires reinforcement learning training for the allocation policy [S1, unofficial].
    *   Performance depends on the quality of the hierarchical neighbor search [S1, unofficial].
*   **Usage:** Suitable for applications requiring limited resource budgets, such as AR/VR, robotics, and digital content creation [S1, unofficial].

## Background
RLSplat was proposed by Bae, Park, and Kim from KAIST. It addresses the limitations of prior budget-controllable FF3DGS methods like EcoSplat and F4 Splat, which predict dense sets of Gaussians and then prune them, resulting in nearly constant inference latency and memory regardless of the target budget [S1, unofficial]. RLSplat introduces a resource-linear approach by learning a Gaussian allocation policy and using a resource-linear decoder with hierarchical neighbor search [S1, unofficial].
