# Deformation Field MLP

Also called: Coordinate MLP

## Overview
The Deformation Field MLP is a coordinate-based neural network that predicts spatial offsets for 3D Gaussian primitives to model dynamic geometry or correct canonical shapes [S1][S2]. It maps input coordinates (and optionally time) to deviations in position, rotation, and scale, serving as a smooth prior to prevent overfitting to sparse or noisy views [S1][S2]. Unlike grid-based methods, it uses a compact MLP structure, making it suitable for dynamic scenes with high-rank variations where explicit point-based rendering exacerbates complexity [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Canonical 3D Gaussian position $\mu$ [S2]. In dynamic variants, time $t$ is concatenated with $\mu$ [S1].
*   **Output:** Position offset $\Delta\mu$ [S2]. In dynamic variants, offsets for position $\delta_x$, rotation $\delta_r$ (or quaternion $\delta_q$), and scaling $\delta_s$ [S1][S2].

**Data Structures:**
*   **Network Parameters ($\theta$):** Weights and biases for an 8-layer Multi-Layer Perceptron (MLP) [S1][S2].
*   **Hidden Dimension:** 256 neurons per layer [S1][S2].
*   **Storage Overhead:** Approximately 2 MB compared to standard 3D Gaussians [S1].

**Algorithm:**
The network applies sinusoidal positional encoding to the input, processes it through two blocks of linear layers with a skip connection, and predicts the final offset.

1.  **Positional Encoding:** Apply sinusoidal positional encoding $\gamma(\cdot)$ to the input coordinate $\mu$ [S2]. For dynamic scenes, encode the concatenated vector $(\mu, t)$ [S1].
2.  **Feature Extraction (Layers 1–4):** Pass the encoded input through the first four of eight fully connected layers with ReLU activations and a hidden dimension of 256 [S1][S2].
3.  **Skip Connection:** Concatenate the positional encoding $\gamma(\cdot)$ with the hidden feature vector output from Layer 4 [S1].
4.  **Feature Refinement (Layers 5–8):** Pass the concatenated vector through four additional fully connected layers with ReLU activations and a hidden dimension of 256 [S1][S2].
5.  **Offset Prediction:** Pass the final feature vector through linear output head(s) without activation [S1][S2]. Static/canonical correction uses a single linear layer to output $\Delta\mu$ [S2]. Dynamic deformation uses three separate linear layers to output $\delta_x$, $\delta_r$, and $\delta_s$ [S1].
6.  **Deformation Application:**
    *   **Static:** Compute the deformed position $\mu' = \mu + \Delta\mu$ [S2].
    *   **Dynamic:** Apply offsets to canonical Gaussian parameters: $x_o = x_c + \delta_x$, $s_o = s_c \cdot \exp(\delta_s)$, $q_o = q_c \cdot \delta_q$ [S2].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import math

class SinusoidalPositionalEncoding(nn.Module):
    def __init__(self, num_bands=10):
        super().__init__()
        self.num_bands = num_bands

    def forward(self, x):
        # x shape: (..., D) where D=3 (pos) or D=4 (pos+time)
        # Standard NeRF-style PE [G]
        freq_bands = torch.exp(torch.linspace(0, math.log(10000), self.num_bands) * -math.log(10000))
        freq_bands = freq_bands.view(1, 1, -1)
        x = x.unsqueeze(-1) * freq_bands
        pe = torch.cat([torch.sin(x), torch.cos(x)], dim=-1)
        return pe

class DeformationFieldMLP(nn.Module):
    def __init__(self, input_dim=3, output_dim=3, hidden_dim=256, num_bands=10, is_dynamic=False):
        super().__init__()
        self.pe = SinusoidalPositionalEncoding(num_bands)
        self.is_dynamic = is_dynamic
        self.pe_dim = input_dim * 2 * num_bands
        
        # Layers 1-4
        self.layers_1_4 = nn.Sequential(
            nn.Linear(self.pe_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU()
        )
        
        # Layers 5-8: Input dimension doubles due to skip connection concatenation
        self.layers_5_8 = nn.Sequential(
            nn.Linear(hidden_dim + self.pe_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU()
        )
        
        # Output head
        if is_dynamic:
            self.head = nn.Linear(hidden_dim, output_dim * 3) # pos, rot, scale
        else:
            self.head = nn.Linear(hidden_dim, output_dim) # pos only

    def forward(self, x):
        # x: (..., input_dim)
        pe = self.pe(x)
        
        # Layers 1-4
        h = self.layers_1_4(pe)
        
        # Skip connection: concat input PE with hidden features
        h = torch.cat([h, pe], dim=-1)
        
        # Layers 5-8
        h = self.layers_5_8(h)
        
        # Output
        delta = self.head(h)
        return delta

# Usage for static canonical correction
# model = DeformationFieldMLP(input_dim=3, output_dim=3, is_dynamic=False)
# delta_mu = model(mu)
# mu_prime = mu + delta_mu

# Usage for dynamic deformation
# model = DeformationFieldMLP(input_dim=4, output_dim=3, is_dynamic=True) # 3 pos + 1 time
# delta = model(torch.cat([mu, t], dim=-1))
# delta_x, delta_r, delta_s = torch.split(delta, 3, dim=-1)
```

**Parameters:**
*   **MLP Depth:** 8 layers [S1][S2].
*   **Hidden Width:** 256 neurons [S1][S2].
*   **PE Frequency Bands:** 10 [S2][S3, unofficial].
*   **Activation:** ReLU for hidden layers, none for output layers [S1][S2].
*   **Deformation Learning Rate:** $1.6 \times 10^{-5}$ [S2][S3, unofficial].
*   **Loss Weight ($\lambda$):** 0.2 for D-SSIM in L1+D-SSIM loss [S1][S2].

**Edge Cases and Pitfalls:**
*   **Initialization:** The output head must be initialized such that $\Delta\mu \approx 0$ (identity) to prevent the network from absorbing pose errors at the start of training [S2].
*   **Pose Accuracy:** Inaccurate camera poses can lead to convergence failure, as the deformation field may struggle to correct for large geometric mismatches [S1].
*   **Dynamic Rank:** Grid/plane-based structures are avoided because dynamic scenes have higher rank than static scenes, and explicit point-based rendering exacerbates this [S1].

## Operating characteristics
*   **Memory:** Adds approximately 2 MB of storage overhead compared to standard 3D Gaussians [S1].
*   **Complexity:** Time complexity is linear with respect to the number of Gaussians, as each Gaussian is processed independently through the MLP [G].
*   **Strengths:** Injects a spatial smoothness prior, helping to avoid overfitting to sparse training views [S2]. Compact structure suitable for dynamic scenes [S1].
*   **Limitations:** Performance degrades with significantly inaccurate camera poses [S1]. May not outperform grid-based methods in static, low-rank scenes [S1].
*   **When to Use:** Dynamic scene reconstruction [S1] or sparse-view reconstruction aided by canonical CAD models [S2].
*   **When Not to Use:** Static scenes with high-quality dense input where grid-based methods may be more efficient [S1].

## Background
The Deformation Field MLP was introduced in the context of deformable 3D Gaussian splatting for dynamic scene reconstruction [S1] and later adapted for sparse-view reconstruction aided by CAD models [S2]. It draws inspiration from coordinate-based MLPs used in NeRF [S1] and other implicit representations. The method was developed to address the limitations of explicit point-based rendering in dynamic scenarios, where high-rank variations make grid-based approaches less effective [S1].
