# SAES (Sliding-Window-Averaged Early Stopping)

Also called: SAES trigger, Structure-Aware Early Stopping, structural saturation detection

## Overview
SAES is an intrinsic training termination criterion for 3D Gaussian Splatting that prevents over-training and the accumulation of needle-like primitives caused by null-space ambiguity in sparse-view reconstruction [S1, unofficial]. Unlike projection-based metrics such as PSNR, which can continue to improve artificially by exploiting geometric ambiguities, SAES monitors the internal dynamics of Gaussian population growth to detect structural saturation, allowing for early stopping without ground-truth volumetric metrics [S1, unofficial].

## How it works
SAES operates by monitoring the rate at which new Gaussian primitives are added during the densification phase [S1, unofficial]. When this growth rate saturates, it indicates that the Gaussian field has converged structurally, and further densification yields diminishing returns or harmful artifacts [S1, unofficial].

### Inputs and Outputs
*   **Input:** The sequence of active Gaussian counts $N_j$ at specific monitoring steps $j$ [S1, unofficial].
*   **Output:** A trigger iteration $t_s$ and final training iteration $T_{final}$ [S1, unofficial].

### Data Structures
The method relies on a sliding window buffer to store recent normalized growth rates [S1, unofficial].
*   **Buffer:** A list or queue of capacity $W$ storing values of $\bar{g}_j$ [G].
*   **State Variables:**
    *   $t$: Current training iteration [G].
    *   $N_t$: Number of active Gaussian primitives at iteration $t$ [S1, unofficial].
    *   $t_{last\_monitor}$: Iteration of the last monitoring step [G].

### Parameters
*   $\Delta = 100$: Monitoring interval in iterations. The growth rate is calculated every $\Delta$ iterations [S1, unofficial].
*   $W = 5$: Sliding window size for smoothing the growth rate [S1, unofficial].
*   $\tau = 10^{-3}$: Threshold for the sliding-window-averaged growth rate to trigger stopping [S1, unofficial].
*   $t_{min} = 2,000$: Minimum iteration count before SAES can trigger, preventing premature stopping during early structure formation [S1, unofficial].
*   $\gamma_{cool} = 0.2$: Learning-rate cooldown factor applied to position and scale learning rates ($\eta_{xyz}, \eta_{scale}$) upon triggering [S1, unofficial].

### Algorithm Steps
1.  **Initialization:** Set $t_{last\_monitor} = 0$ [G]. Initialize an empty sliding window buffer $B$ of capacity $W$ [G].
2.  **Monitoring Loop:** At each training iteration $t$:
    *   If $t > t_{last\_monitor} + \Delta$:
        *   Calculate the normalized population growth rate $g_j$ for the current monitoring step $j$ [S1, unofficial].
        *   Append $g_j$ to buffer $B$ [G].
        *   If $|B| > W$, remove the oldest element from $B$ [G].
        *   Update $t_{last\_monitor} = t$ [G].
        *   Compute the sliding-window-averaged growth rate $\bar{g}_j$ using the buffer contents [S1, unofficial].
        *   Check SAES trigger condition [S1, unofficial].
3.  **Trigger Condition:** SAES triggers at iteration $t_s$ if the current iteration $t > t_{min}$ and the sliding-window-averaged growth rate $\bar{g}_j < \tau$ [S1, unofficial].
4.  **Post-Trigger Actions:**
    *   Set $t_s = t$ [S1, unofficial].
    *   Set the final densification iteration $T_{densify} = t_s$ [S1, unofficial]. No further densification (splitting/cloning) occurs after $t_s$ [S1, unofficial].
    *   Set the final training iteration $T_{final} = 2 \times t_s$ [S1, unofficial]. Training continues until $T_{final}$ for refinement [S1, unofficial].
    *   Apply learning-rate cooldown: Multiply current learning rates by $\gamma_{cool}$ [S1, unofficial].

### Formulas
**Normalized Population Growth Rate ($g_j$):**
The growth rate is normalized to account for the scale of the Gaussian population [S1, unofficial]. Let $N_j$ be the active Gaussian count at monitoring step $j$, and $N_{j-1}$ be the count at the previous monitoring step [S1, unofficial]. The normalized growth rate is:

$$ g_j = \frac{N_j - N_{j-1}}{N_{j-1}} $$

**Sliding-Window-Averaged Growth Rate ($\bar{g}_j$):**
Let $B = [b_1, b_2, \dots, b_k]$ be the current buffer contents, where $k \le W$ [G]. The averaged rate is:

$$ \bar{g}_j = \frac{1}{k} \sum_{i=1}^{k} b_i $$

The trigger condition is $\bar{g}_j < \tau$ [S1, unofficial].

### Pseudocode
```python
def check_saes_trigger(current_iter, active_gaussian_count, last_monitor_iter, prev_gaussian_count, buffer, params):
    """
    Checks if SAES should trigger based on Gaussian population growth.
    
    Args:
        current_iter (int): Current training iteration t.
        active_gaussian_count (int): Number of active Gaussians N_t.
        last_monitor_iter (int): Iteration of the last monitoring step.
        prev_gaussian_count (int): Active Gaussian count at the previous monitoring step.
        buffer (list): List of recent normalized growth rates.
        params (dict): Contains delta, window_size, threshold, t_min, cooldown_factor.
        
    Returns:
        bool: True if SAES triggers, False otherwise.
        int: Updated last_monitor_iter.
        int: Updated prev_gaussian_count.
        list: Updated buffer.
        float: Sliding-window-averaged growth rate (or None if not monitored).
    """
    delta = params['delta']          # 100
    window_size = params['window_size'] # 5
    threshold = params['threshold']  # 1e-3
    t_min = params['t_min']          # 2000
    
    if current_iter - last_monitor_iter < delta:
        return False, last_monitor_iter, prev_gaussian_count, buffer, None

    if prev_gaussian_count == 0:
        growth_rate = 0.0
    else:
        growth_rate = (active_gaussian_count - prev_gaussian_count) / prev_gaussian_count

    buffer.append(growth_rate)
    if len(buffer) > window_size:
        buffer.pop(0)

    last_monitor_iter = current_iter
    prev_gaussian_count = active_gaussian_count

    avg_growth = sum(buffer) / len(buffer)

    if current_iter > t_min and avg_growth < threshold:
        return True, last_monitor_iter, prev_gaussian_count, buffer, avg_growth

    return False, last_monitor_iter, prev_gaussian_count, buffer, avg_growth
```

### Edge Cases and Pitfalls
*   **Division by Zero:** If the initial Gaussian population $N_{j-1}$ is zero, the normalized growth rate is undefined [G]. The implementation should handle this by setting the growth rate to 0.0 or skipping the check until a non-zero population exists [G].
*   **Premature Triggering:** The parameter $t_{min} = 2,000$ prevents triggering during the early phase where the population is still establishing basic structure [S1, unofficial]. Ignoring this guard can cause premature stopping before structural convergence, leading to volumetric underfitting [S1, unofficial].
*   **Stability:** The sliding window $W=5$ smooths out iteration-to-iteration noise in densification [S1, unofficial]. The stopping behavior is stable around $W=5$, indicating the threshold is not narrowly tuned [S1, unofficial].

### Subtopics
*   **Termination Entropy Criterion:** A method that uses termination entropy to calculate information gain for active 3D reconstruction, serving as the broader criterion framework for SAES [S1, unofficial]. While SAES specifically monitors population growth rate for early stopping, the Termination Entropy Criterion provides the theoretical basis for determining when information gain is sufficient [S1, unofficial]. Use when integrating SAES into a pipeline that already utilizes entropy-based active reconstruction strategies [G]. Link: [Termination entropy criterion](12065-termination-entropy-criterion.md).

## Operating characteristics
*   **Time Complexity:** SAES adds negligible computational overhead per iteration, as it only requires counting active Gaussians and maintaining a small buffer of 5 floats [G]. The primary benefit is a reduction in total training time [S1, unofficial].
*   **Memory Complexity:** Minimal. Requires storing a buffer of size $W=5$ and a few scalar state variables [G].
*   **Measured Performance:**
    *   On the FIPS dataset with 25 views, SAES triggers at approximately $t_s \approx 5,133$ iterations (mean across objects), leading to $T_{final} \approx 10,267$ [S1, unofficial].
    *   This results in a ~64% reduction in wallclock training time compared to R2-Gaussian, which runs for a fixed 30,000 iterations [S1, unofficial].
    *   SAES is stable across different view counts (10, 20, 25 views) for the same object, with trigger iterations varying by less than 5% for complex objects like Walnut [S1, unofficial].
*   **Strengths:**
    *   Prevents over-training and the formation of needle-like primitives that exploit null-space ambiguity [S1, unofficial].
    *   Does not require ground-truth volumetric metrics for evaluation [S1, unofficial].
    *   Significantly reduces training time without sacrificing reconstruction quality (PSNR/SSIM) [S1, unofficial].
*   **Limitations:**
    *   Relies on the assumption that population growth saturation correlates with structural convergence, which may not hold for all scene types or initialization strategies [G].
    *   Requires careful tuning of $t_{min}$ to avoid early stopping [G].
*   **When to use:** Sparse-view 3D Gaussian tomography or reconstruction where training time is a constraint and null-space ambiguity is a concern [S1, unofficial].
*   **When not to use:** Dense-view settings where the Gaussian population may continue to refine structure significantly beyond initial saturation, or when ground-truth volumetric metrics are available and preferred [G].

## Background
SAES was introduced in the context of diagnosing and controlling optimization drift in sparse-view 3D Gaussian tomography, specifically as part of the LADES framework [S1, unofficial]. The method addresses the Projection-Volume Fidelity Divergence (PVFD) problem, where projection fidelity (PSNR) continues to improve while volumetric fidelity degrades due to the formation of anisotropic, needle-like primitives [S1, unofficial]. By monitoring intrinsic Gaussian population dynamics rather than external projection metrics, SAES provides a robust, ground-truth-free stopping criterion [S1, unofficial].
