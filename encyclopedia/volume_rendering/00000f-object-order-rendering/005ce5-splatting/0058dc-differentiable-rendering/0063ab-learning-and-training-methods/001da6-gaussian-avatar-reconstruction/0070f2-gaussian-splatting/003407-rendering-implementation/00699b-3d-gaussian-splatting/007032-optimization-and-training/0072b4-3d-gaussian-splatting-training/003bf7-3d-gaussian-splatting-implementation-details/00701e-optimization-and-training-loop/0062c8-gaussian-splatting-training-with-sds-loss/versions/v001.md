# Gaussian Splatting Training with SDS Loss

Also called: SDS-based Gaussian Splatting Training, Score Distillation Sampling for 3D Gaussian Splatting

## Overview
This method optimizes 3D Gaussian Splatting (3DGS) scene parameters using Score Distillation Sampling (SDS) from a pretrained 2D diffusion model, enabling text-to-3D generation without ground-truth images [S1, unofficial]. It differs from supervised 3DGS training by replacing L1 pixel loss with a diffusion-based gradient signal that guides the 3D structure to match a text prompt, while retaining the differentiable splatting renderer for gradient backpropagation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** A text prompt, a pretrained Stable Diffusion 2.1 model (VAE, Text Encoder, UNet, DDIM Scheduler), and an initial set of 3D Gaussians (typically initialized from a point cloud).
- **Outputs:** Optimized Gaussian parameters: means, colors, opacities, and scales.

**Data Structures:**
The scene consists of $N$ Gaussians. Each Gaussian is defined by:
- **Mean:** $\mu \in \mathbb{R}^3$
- **Rotation:** $q \in \mathbb{R}^4$ (unit quaternion)
- **Scale:** $s \in \mathbb{R}^3$
- **Opacity:** $\alpha \in [0, 1]$
- **Color:** $c \in \mathbb{R}^3$ (SH coefficients or RGB)

Parameters are stored as "pre-activation" values to ensure constraints during optimization:
- `pre_act_opacities`: Optimized variable; opacity is $\sigma(\text{pre\_act\_opacities})$.
- `pre_act_scales`: Optimized variable; scale is $\exp(\text{pre\_act\_scales})$.
- `pre_act_quats`: Optimized variable; rotation is $\text{normalize}(\text{pre\_act\_quats})$.
- `colours`: Optimized variable; direct RGB values.

**Numbered Steps:**

1. **Initialization:**
   - Load Stable Diffusion 2.1 components: VAE, tokenizer, text encoder, UNet, and DDIM scheduler [S1, unofficial].
   - Initialize Gaussians from point cloud data with `isotropic=True` [S1, unofficial].
   - Enable gradient tracking for `means`, `colours`, `pre_act_opacities`, and `pre_act_scales` [S1, unofficial].

2. **Rendering:**
   - Render the scene using differentiable Gaussian splatting [S1, unofficial].
   - Project 3D Gaussians to 2D:
     - Compute 2D covariance: $C_{2D} = J W C_{3D} W^T J^T$, where $J$ is the Jacobian of the projection, $W$ is the view matrix, and $C_{3D}$ is the 3D covariance derived from quaternions and scales [S1, unofficial].
     - Add $0.3$ to diagonal elements of $C_{2D}$ to ensure minimum pixel coverage [S1, unofficial].
     - Compute 2D means: $\mu_{2D} = \text{transform\_points\_screen}(\mu_{3D})$ [S1, unofficial].
   - Compute alpha values for each pixel:
     - Calculate Mahalanobis distance: $P = -0.5 (\mathbf{x} - \mu_{2D})^T C_{2D}^{-1} (\mathbf{x} - \mu_{2D})$ [S1, unofficial].
     - Compute $\alpha = \min(0.99, \max(0, \sigma(\text{opacity}) \cdot \exp(P)))$ [S1, unofficial].
   - Composite colors using alpha blending with transmittance $T_i = \prod_{j < i} (1 - \alpha_j)$ [S1, unofficial].
   - Output rendered image $I_{rendered}$ with background $(0,0,0)$ [S1, unofficial].

3. **SDS Loss Computation:**
   - **Encode Image:** Normalize $I_{rendered}$ from $[0, 1]$ to $[-1, 1]$. Encode via VAE to get latent $z$. Scale by $s_{vae}$: $z_{scaled} = z \cdot s_{vae}$ [S1, unofficial].
   - **Encode Text:** Tokenize prompt with padding to `max_length`. Pass through text encoder to get text embedding $t$ [S1, unofficial].
   - **Diffusion Step:**
     - Sample timestep $t_{step}$ uniformly from $[0.02 \cdot T, 0.98 \cdot T]$, where $T$ is total timesteps [S1, unofficial].
     - Add noise to $z_{scaled}$ to get $z_t$ at timestep $t_{step}$ [S1, unofficial].
     - Predict noise $\epsilon_\theta(z_t, t_{step}, t)$ using UNet [S1, unofficial].
     - Compute SDS gradient: $\nabla_{z_{scaled}} \mathbb{E}_{\epsilon \sim \mathcal{N}(0,1)} [w(t) (\epsilon_\theta(z_t, t_{step}, t) - \epsilon)]$ [S1, unofficial].
     - Guidance scale $s = 100$ [S1, unofficial].
   - **Backpropagate:**
     - Compute gradient of SDS loss w.r.t. $I_{rendered}$.
     - Backpropagate through the differentiable splatting renderer to update Gaussian parameters [S1, unofficial].

4. **Optimization Step:**
   - Update parameters using Adam optimizer ($\epsilon = 10^{-15}$) [S1, unofficial].
   - Zero gradients [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F
from diffusers import StableDiffusionPipeline

def train_gaussian_splatting_sds(gaussians, prompt, num_iterations=1000, guidance_scale=100):
    # 1. Load Diffusion Model
    pipe = StableDiffusionPipeline.from_pretrained("stabilityai/stable-diffusion-2-1-base")
    pipe = pipe.to("cuda")
    vae = pipe.vae
    text_encoder = pipe.text_encoder
    tokenizer = pipe.tokenizer
    unet = pipe.unet
    scheduler = pipe.scheduler
    
    # 2. Initialize Optimizer
    optimizer = torch.optim.Adam([
        {'params': gaussians.means, 'lr': 0.001},
        {'params': gaussians.colours, 'lr': 0.01},
        {'params': gaussians.pre_act_opacities, 'lr': 0.01},
        {'params': gaussians.pre_act_scales, 'lr': 0.01}
    ], eps=1e-15)
    
    # 3. Training Loop
    for i in range(num_iterations):
        # Render Scene
        camera = get_random_camera() # Helper to get random view
        rendered_image = render_scene(gaussians, camera) # Differentiable splatting
        
        # Encode Image
        img_normalized = rendered_image * 2.0 - 1.0 # [0,1] to [-1,1]
        with torch.no_grad():
            latent_dist = vae.encode(img_normalized)
            latent = latent_dist.sample() * vae.config.scaling_factor
            
        # Encode Text
        text_input = tokenizer(prompt, padding="max_length", max_length=tokenizer.model_max_length, return_tensors="pt")
        with torch.no_grad():
            text_emb = text_encoder(text_input.input_ids.to("cuda"))[0]
            
        # SDS Loss
        t = torch.randint(0, scheduler.config.num_train_timesteps, (1,)).item()
        noise = torch.randn_like(latent)
        latent_noisy = scheduler.add_noise(latent, noise, t)
        
        with torch.no_grad():
            noise_pred = unet(latent_noisy, t, encoder_hidden_states=text_emb).sample
            
        # Compute SDS gradient
        # w(t) is typically (1 - alpha_t) or similar weighting from scheduler
        w_t = scheduler.alphas_cumprod[t].sqrt() / (1 - scheduler.alphas_cumprod[t]) # Approximation
        grad = w_t * (noise_pred - noise)
        
        # Backpropagate through VAE decoder to image space
        # Note: In practice, gradients are often computed via the VAE decoder's output
        # or by approximating the gradient w.r.t. the image directly.
        # Here we assume a helper `compute_grad_wrt_image` exists which backprops
        # from the latent noise prediction to the image pixels.
        grad_image = compute_grad_wrt_image(vae, grad, latent)
        
        # Backpropagate through Renderer
        grad_image = grad_image.detach() # If using straight-through or if gradients are handled differently
        # Actually, we need gradients w.r.t. Gaussians.
        # rendered_image.requires_grad = True is not needed if we backprop from grad_image
        # But rendered_image is a function of Gaussians.
        
        # Compute loss and backprop
        loss = (rendered_image * grad_image).mean() # Simplified gradient application
        loss.backward()
        
        optimizer.step()
        optimizer.zero_grad()
        
        if i % 20 == 0:
            visualize(gaussians)

def compute_grad_wrt_image(vae, grad_latent, latent):
    # Decode latent to image to get gradients w.r.t. image
    # This is a simplified representation. In reality, one might use
    # the VAE decoder's gradients directly.
    with torch.enable_grad():
        latent.requires_grad = True
        image_decoded = vae.decode(latent / vae.config.scaling_factor).sample
        loss = (image_decoded * grad_latent).mean()
        loss.backward()
    return latent.grad
```

**Parameters:**
- Learning rates: `pre_act_opacities`=0.01, `pre_act_scales`=0.01, `colours`=0.01, `means`=0.001 [S1, unofficial].
- Training iterations: 1000 [S1, unofficial].
- SDS Guidance scale: 100 [S1, unofficial].
- SDS Inference steps: 50 (default in scheduler) [S1, unofficial].
- SDS Timestep range: $[0.02 T, 0.98 T]$ [S1, unofficial].
- Precision: `torch.float32` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Numerical Stability:** Alphas are clamped to $[0, 0.99]$ and transmittance to $[0, 10^{-4}]$ to prevent NaNs [S1, unofficial].
- **Precision:** Using `float32` is critical for diffusion model stability [S1, unofficial].
- **Boundary Conditions:** Background color is set to $(0,0,0)$ to avoid interference with SDS gradients [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by the diffusion model inference (UNet forward pass) per iteration. Rendering is $O(N \cdot H \cdot W)$ but optimized via sorting and rasterization.
- **Memory Complexity:** $O(N)$ for Gaussian parameters plus memory for the diffusion model (approx. 6-10 GB for SD 2.1) [S1, unofficial].
- **Performance:** Slower than supervised 3DGS due to diffusion inference, but faster than NeRF-based SDS methods due to efficient splatting [S1, unofficial].
- **Strengths:** High-quality text-to-3D generation, fast convergence compared to NeRFs, explicit scene representation.
- **Limitations:** Requires large GPU memory for diffusion model, potential for "over-saturation" or artifacts if guidance scale is too high [S1, unofficial].

## Background
Originated from the application of Score Distillation Sampling (SDS) to 3D Gaussian Splatting, leveraging the efficiency of 3DGS rendering with the generative power of Stable Diffusion [S1, unofficial]. This approach bridges the gap between implicit NeRF-based text-to-3D and explicit Gaussian-based methods, offering faster training and rendering [S1, unofficial].
