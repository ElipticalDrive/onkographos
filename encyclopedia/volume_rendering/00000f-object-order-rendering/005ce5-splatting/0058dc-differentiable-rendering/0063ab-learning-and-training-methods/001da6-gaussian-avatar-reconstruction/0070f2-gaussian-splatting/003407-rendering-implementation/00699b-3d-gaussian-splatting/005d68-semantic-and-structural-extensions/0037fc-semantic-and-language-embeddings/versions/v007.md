# Semantic and Language Embeddings

Also called: SAM-guided Gaussian Grouping

## Overview
This family extends 3D Gaussian Splatting [3D Gaussian Splatting Rendering (Software)](2805-3d-gaussian-splatting-rendering-software.md) by attaching high-dimensional feature vectors to Gaussian primitives, enabling the rendering of semantic, language, or latent feature maps alongside color. It solves the problem of integrating 2D vision-language models (such as CLIP or LSeg) into 3D representations, allowing for real-time open-vocabulary semantic segmentation and phrase grounding. It differs from standard 3DGS by accumulating feature vectors via differentiable alpha-blending rather than just color, and from sibling methods like [3D Gaussian Splatting MVP](3410-3d-gaussian-splatting-mvp.md) by focusing on semantic alignment rather than geometric or appearance fidelity.

## Shared principles
All methods in this family rely on the differentiable alpha-blending accumulation of feature vectors during rasterization. For each pixel $p$, the set of overlapping Gaussians $\mathcal{O}_p$ is sorted front-to-back. The accumulated feature vector $\mathbf{F}(p)$ is computed as:

$$
\mathbf{F}(p) = \sum_{i \in \mathcal{O}_p} \mathbf{f}_i \cdot \alpha_i \cdot \prod_{j=1}^{i-1} (1 - \alpha_j)
$$

where $\mathbf{f}_i$ is the feature vector of the $i$-th Gaussian and $\alpha_i$ is its opacity. This formula is identical to the color blending in the parent renderer [3D Gaussian Splatting Rendering (Software)](2805-3d-gaussian-splatting-rendering-software.md), but operates on $\mathbb{R}^d$ vectors instead of RGB. The feature dimension $d$ varies by method (e.g., 512 for CLIP, 768 for LSeg/CLIP text encoders).

## Subtopics

### [3D Gaussian Splatting with Feature Vectors](8060-3d-gaussian-splatting-with-feature-vectors.md)
Attaches a high-dimensional feature vector $\mathbf{f}_i$ to each Gaussian, enabling the rendering of semantic or latent feature maps [8060-3d-gaussian-splatting-with-feature-vectors.md]. It differs from [LSeg Feature Encoding](12078-lseg-feature-encoding.md) by relying on direct differentiable alpha-blending of learned or distilled features without explicit 2D-to-3D lifting networks during inference. Choose this for general open-vocabulary segmentation where the feature space is pre-defined (e.g., CLIP).

### [LangSplat](8104-langsplat.md)
Pioneers real-time open-vocabulary semantic segmentation by rendering high-dimensional feature maps and comparing them against text embeddings from CLIP [8104-langsplat.md]. It differs from siblings by explicitly leveraging the speed of the 3DGS rasterizer to distill 2D vision-model features into a 3D representation, enabling direct comparison with text queries without intermediate decoding heads for segmentation. Choose this for zero-shot segmentation tasks requiring fast inference.

### [Text Embedding Generation with Directional Views](8239-text-embedding-generation-with-directional-views.md)
Generates semantic text embeddings conditioned on specific camera viewing directions to enable view-dependent semantic understanding [8239-text-embedding-generation-with-directional-views.md]. It differs from standard text encoding by injecting explicit spatial context into the latent space, and from feature vector methods by operating at the prompt level rather than the Gaussian attribute level. Choose this when semantic appearance varies significantly with viewpoint.

### [LSeg Feature Encoding](12078-lseg-feature-encoding.md)
Generates semantic feature maps by distilling knowledge from a pretrained 2D vision-and-language model (LSeg) into the scene's feature fields [12078-lseg-feature-encoding.md]. It differs from siblings by using a specific 2D teacher network (LSeg) to provide dense pixel-level semantic supervision during the distillation process, rather than relying solely on ray-based CLIP gradients or directional view embeddings. Choose this for high-accuracy segmentation using LSeg's strong generalization capabilities.

### [VLM-Augmented Segmentation](15758-vlm-augmented-segmentation.md)
Enables open-vocabulary 3D segmentation by augmenting 3D Gaussians with compact language features distilled from a Vision-Language Model (VLM) [15758-vlm-augmented-segmentation.md]. It differs from [3D Gaussian Splatting with Feature Vectors](8060-3d-gaussian-splatting-with-feature-vectors.md) by specifically targeting language/semantic alignment via VLM distillation rather than generic feature learning, and from [Text Embedding Generation with Directional Views](8239-text-embedding-generation-with-directional-views.md) by operating on per-Gaussian latent attributes rather than view-dependent directional embeddings. Choose this to mitigate memory explosion from high-dimensional VLM embeddings.

### Language Embedded 3D Gaussians
Expands feature blending to full scene understanding, encoding object-level embeddings for phrase grounding in addition to pixel-level features [S2, unofficial].

### 3D Vision-Language GS
Projects vision-language models into the 3DGS framework, training a joint embedding space where rendered feature maps can be queried with natural language [S2, unofficial]. It enables tasks like 3D visual question answering and zero-shot semantic reasoning [S2, unofficial].

## Background
The integration of semantic and language embeddings into 3D Gaussian Splatting emerged as a solution to the limitations of color-only representations for high-level vision tasks. Early work focused on attaching feature vectors to Gaussians to enable open-vocabulary segmentation [S1, unofficial]. Subsequent methods like LangSplat and LSeg-based approaches leveraged the differentiable rasterization to distill features from 2D vision-language models (CLIP, LSeg) into the 3D structure [S2, unofficial]. More recent variants address view-dependency [8239-text-embedding-generation-with-directional-views.md] and memory efficiency through latent compression [15758-vlm-augmented-segmentation.md]. The family is often associated with SAM-guided grouping for instance-level semantics [S1, unofficial].
