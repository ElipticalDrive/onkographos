# RadSplat


## Overview
RadSplat is a method for initializing 3D Gaussian Splatting (3DGS) scenes by leveraging a pre-trained Neural Radiance Field (NeRF) to generate a dense, topologically correct point cloud, which is then converted into Gaussians [S1, S2, unofficial]. It solves the problem of poor initialization quality and topological artifacts inherent in raw Structure-from-Motion (SfM) point clouds, enabling high-quality rendering with unprecedented speed [S1, unofficial]. Unlike feed-forward methods like MVSplat that regress parameters directly, RadSplat uses a hybrid approach that bypasses the per-scene gradient descent loop for initialization [S1, unofficial].

## How it works
RadSplat operates in two main phases: initialization via NeRF-derived point clouds and subsequent Gaussian conversion with pruning.

**Inputs:**
- Sparse multi-view images.
- Camera poses (from SfM).
- A pre-trained NeRF model for the target scene.

**Outputs:**
- A set of 3D Gaussians (position, covariance, opacity, spherical harmonics coefficients) ready for rasterization.

**Data Structures:**
- **Point Cloud:** A dense set of 3D points $\mathbf{p}_i$ derived from the NeRF.
- **Gaussian Primitive:** Defined by mean $\boldsymbol{\mu}$, covariance matrix $\boldsymbol{\Sigma}$ (or rotation $\mathbf{R}$ and scale $\mathbf{S}$), opacity $\alpha$, and color coefficients $\mathbf{c}$.

**Steps:**
1. **NeRF Training:** Train a NeRF on the sparse multi-view images to learn the scene's implicit volume [S1, unofficial].
2. **Dense Point Cloud Generation:** Extract a dense point cloud from the trained NeRF. This is typically done by sampling points along rays or using marching cubes on the NeRF's density field to ensure topological correctness and high density in visible regions [S1, S2, unofficial].
3. **Gaussian Conversion:** Convert each point $\mathbf{p}_i$ in the cloud into a 3D Gaussian.
   - Set the Gaussian mean $\boldsymbol{\mu}_i = \mathbf{p}_i$.
   - Initialize covariance $\boldsymbol{\Sigma}_i$ based on local point density or a fixed small kernel [G].
   - Initialize opacity $\alpha_i$ and color $\mathbf{c}_i$ based on the NeRF's output at $\mathbf{p}_i$ [G].
4. **Pruning:** Apply a multi-view importance score to prune Gaussians that contribute little to the final rendering [S2, unofficial].
   - Calculate an importance score for each Gaussian based on its visibility and contribution across multiple views [S2, unofficial].
   - Remove Gaussians with scores below a threshold [S2, unofficial].

**Parameters:**
- NeRF training iterations: Not given in the sources.
- Pruning threshold: Not given in the sources.

**Edge Cases:**
- **NeRF Quality:** The quality of the initialization depends heavily on the NeRF's ability to reconstruct the scene from sparse views. Poor NeRF reconstruction leads to poor Gaussian initialization [S1, unofficial].
- **Computational Cost:** Training the NeRF adds significant overhead before Gaussian rendering can begin [S1, unofficial].

## Operating characteristics
- **Speed:** Achieves 900+ FPS rendering [S1, unofficial].
- **Quality:** High-quality rendering due to robust initialization [S1, unofficial].
- **Memory:** Not given in the sources.
- **Strengths:** Circumvents topological pitfalls of raw SfM; high rendering speed; high quality [S1, unofficial].
- **Limitations:** Requires pre-training a NeRF, which is computationally expensive and time-consuming [S1, unofficial].

## Background
RadSplat was introduced as a method to improve the initialization of 3D Gaussian Splatting by using a NeRF to generate a dense point cloud [S1, S2, unofficial]. It addresses the limitations of raw SfM initialization, which can suffer from topological errors and sparse coverage [S1, unofficial]. The method is cited in surveys on 3D Gaussian Splatting rasterization and recent advances in the field [S1, S2, unofficial].
