# Differentiable DOF Rendering

Also called: Differentiable Depth of Field Rendering

## Overview
Differentiable DOF Rendering generates blurred images by convolving projected 2D Gaussians with depth-dependent blur kernels derived from a finite-aperture camera model, enabling the differentiable optimization of camera parameters and scene geometry [S1]. It differs from standard Gaussian Splatting [3D Gaussian Splatting](3D-Gaussian-Splatting.md) by explicitly modeling defocus blur via the Circle of Confusion (CoC), allowing the system to learn camera intrinsics (aperture, focal distance) alongside scene structure [S1].

## How it works
**Inputs:**
*   Set of 3D Gaussians $\mathcal{S}$ with means $\boldsymbol{\mu}$, covariances $\boldsymbol{\Sigma}$, colors, and opacities.
*   Camera parameters: focal length $F$, aperture $A$, and focal distance $f$.
*   Image resolution $Q$ (pixel dimensions).

**Outputs:**
*   Rendered color image $\tilde{\mathbf{I}}$.
*   Rendered depth map $\tilde{\mathbf{D}}$.
*   Rendered CoC map $\tilde{\mathbf{M}}^{(coc)}$.

**Data Structures:**
*   **2D Gaussian $G_k'$**: Result of projecting 3D Gaussian $k$ to screen space. Defined by mean $\boldsymbol{\mu}_p$, covariance $\boldsymbol{\Sigma}'$, color $\mathbf{c}_k$, and opacity $\alpha_k$.
*   **Blur Kernel $G_k^{(coc)}$**: An isotropic 2D Gaussian kernel centered at $\boldsymbol{\mu}_p$ with covariance $\Sigma_k^{(coc)} = a \mathbf{I}$.
*   **Convolved Gaussian $G_k''$**: The result of $G_k' * G_k^{(coc)}$.

**Steps:**

1.  **Projection:** Transform each 3D Gaussian $G_k$ to 2D screen space to obtain $G_k'$ using the view transformation and projection Jacobian as defined in [Camera and Projection Models](23322-camera-and-projection-models.md) [S1].
2.  **CoC Radius Calculation:** For each projected 2D Gaussian $G_k'$, calculate the Circle of Confusion radius $R_k^{(coc)}$ based on its center depth $z_k$ (the $z$-coordinate of the transformed mean in camera space) [S1]:
    $$ R_k^{(coc)} = \frac{1}{2} Q \left| \frac{1}{z_k} - \frac{1}{f} \right| $$
    where $Q = \frac{F}{A}$ is the simplified aperture parameter, $F$ is the lens focal length, $A$ is the aperture, and $f$ is the focal distance [S1].
3.  **Blur Kernel Construction:** Construct the isotropic blur kernel $G_k^{(coc)}$ with covariance $\Sigma_k^{(coc)} = a \mathbf{I}$ [S1]:
    $$ G_k^{(coc)}(\mathbf{x}) = \exp \left( -\frac{1}{2} \mathbf{x}^T \Sigma_k^{(coc)} \mathbf{x} \right) $$
    The scalar $a$ is determined by minimizing the $L_2$ distance between the Gaussian kernel and a uniform intensity distribution within the CoC radius $R_k^{(coc)}$ [S1]:
    $$ a = \frac{(R_k^{(coc)})^2}{2 \ln 4} $$
4.  **Convolution:** Convolve the projected 2D Gaussian $G_k'$ with the blur kernel $G_k^{(coc)}$ to obtain the convolved Gaussian $G_k''$ [S1]:
    $$ G_k'' = G_k' * G_k^{(coc)} $$
    Since the convolution of two Gaussians is a Gaussian, $G_k''$ remains a valid 2D Gaussian primitive, preserving the rasterization consistency [S1].
5.  **Re-evaluation of Pixel Associations:** Because convolution changes the spatial support of the Gaussians, re-evaluate the set of Gaussians linked to each pixel, denoted as $N_{x'}$ [S1].
6.  **Compositing:** Accumulate contributions from the convolved Gaussians to compute the final color $\tilde{\mathbf{I}}$, depth $\tilde{\mathbf{D}}$, and CoC map $\tilde{\mathbf{M}}^{(coc)}$ for each pixel $\mathbf{x}$ [S1]:
    $$ \tilde{\mathbf{I}}(\mathbf{x}) = \sum_{i=1}^{N_{x'}} \mathbf{c}_i \alpha_i' T_i' $$
    $$ \tilde{\mathbf{D}}(\mathbf{x}) = \frac{\sum_{i=1}^{N_{x'}} \alpha_i' T_i' z_i}{\sum_{i=1}^{N_{x'}} \alpha_i' T_i'} $$
    $$ \tilde{\mathbf{M}}^{(coc)}(\mathbf{x}) = \sum_{i=1}^{N_{x'}} \alpha_i' T_i' R_i^{(coc)} $$
    where $\alpha_i' = G_i''(\mathbf{x})$ is the opacity of the convolved Gaussian at pixel $\mathbf{x}$, $T_i' = \prod_{j=1}^{i-1} (1 - \alpha_j')$ is the transmittance, and $z_i$ is the depth of the $i$-th Gaussian [S1].

```python
def differentiable_dof_render(gaussians_3d, camera_params, image_resolution):
    """
    gaussians_3d: List of 3D Gaussian objects with attributes:
                  - mu: (3,) mean in world space
                  - Sigma: (3,3) covariance in world space
                  - color: (3,) color
                  - opacity: scalar
    camera_params: Object with attributes:
                   - F: float, focal length
                   - A: float, aperture
                   - f: float, focal distance
    image_resolution: (H, W) tuple
    """
    Q = camera_params.F / camera_params.A
    
    # Step 1: Project 3D Gaussians to 2D (Assuming standard GS projection logic)
    gaussians_2d = []
    for g in gaussians_3d:
        # Transform mean and covariance to camera space
        mu_c = transform_to_camera_space(g.mu, camera_params.W, camera_params.b)
        Sigma_c = transform_covariance(g.Sigma, camera_params.W)
        
        # Project to 2D screen space
        mu_p, Sigma_p = project_to_screen(mu_c, Sigma_c, camera_params.J)
        
        # Get depth z_k (z-coordinate of transformed mean)
        z_k = mu_c[2]
        
        gaussians_2d.append({
            'mu': mu_p,
            'Sigma': Sigma_p,
            'color': g.color,
            'opacity': g.opacity,
            'z': z_k
        })
    
    # Step 2 & 3: Calculate CoC and Blur Kernel parameters
    convolved_gaussians = []
    for g2d in gaussians_2d:
        z_k = g2d['z']
        f = camera_params.f
        
        # Calculate CoC radius
        # Handle division by zero or invalid depth if necessary [G]
        if z_k == 0:
            R_coc = 0.0
        else:
            R_coc = 0.5 * image_resolution[0] * abs(1.0/z_k - 1.0/f)
        
        # Calculate scalar 'a' for isotropic covariance
        # a = R_coc^2 / (2 * ln(4))
        a = (R_coc ** 2) / (2.0 * math.log(4))
        
        # The blur kernel is isotropic: Sigma_k^(coc) = a * I
        # Convolution of two Gaussians with covariances Sigma1 and Sigma2
        # results in a Gaussian with covariance Sigma1 + Sigma2.
        # Here, Sigma1 is the projected 2D Gaussian Sigma_p.
        # Sigma2 is the blur kernel covariance a*I.
        Sigma_conv = g2d['Sigma'] + (a * np.eye(2))
        
        convolved_gaussians.append({
            'mu': g2d['mu'],
            'Sigma': Sigma_conv,
            'color': g2d['color'],
            'opacity': g2d['opacity'],
            'z': g2d['z'],
            'R_coc': R_coc
        })
    
    # Step 4 & 5: Rasterize convolved Gaussians
    # Re-evaluate pixel associations based on new Sigma_conv
    # Perform tile-based alpha blending
    image = np.zeros((image_resolution[1], image_resolution[2], 3))
    depth_map = np.zeros((image_resolution[1], image_resolution[2]))
    coc_map = np.zeros((image_resolution[1], image_resolution[2]))
    
    # Sort convolved_gaussians by depth for correct alpha blending [G]
    convolved_gaussians.sort(key=lambda x: x['z'])
    
    for g_conv in convolved_gaussians:
        # Evaluate Gaussian at each pixel within its bounding box
        # This is typically done via CUDA kernel for efficiency [S1]
        pixels = get_pixels_in_support(g_conv['mu'], g_conv['Sigma'])
```

**Edge Cases and Pitfalls:**
*   **Depth Zero:** Division by $z_k$ in the CoC radius formula requires handling $z_k=0$ [G].
*   **Precision:** CUDA-customized rasterization is used to incorporate Gaussian convolution and derivative calculations for efficiency and differentiability [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Enables differentiable optimization of camera parameters ($f, Q$) and scene geometry [S1]. Mitigates reconstruction artifacts caused by defocus blur [S1].
*   **Limitations:** Requires re-evaluation of pixel-Gaussian associations after convolution, increasing computational overhead compared to standard splatting [S1].
*   **When to use:** When training data contains natural defocus blur and the goal is to reconstruct a scene with accurate camera intrinsics or to perform post-capture refocusing [S1].

## Background
Originated in "DOF-GS: Adjustable Depth-of-Field 3D Gaussian Splatting for Post-Capture Refocusing, Defocus Rendering and Blur Removal" [S1]. The method extends 3D Gaussian Splatting by integrating a finite-aperture camera model to simulate depth-of-field effects, allowing the system to learn from blurred images [S1].
