# Inverse Gaussian Splattling

Also called: 2D to 3D Back-projection, Back-projection of 2D Gaussians, Geometric Back-projection, Inverse Gaussian Splattering, Inverse splatting

## Overview
Inverse Gaussian Splattling is a method for initializing 3D Gaussian primitives by back-projecting optimized 2D Gaussian kernels from image space into world space [S1, unofficial]. It solves the problem of generating high-quality initial geometric parameters (position, rotation, scale) for new 3D Gaussians from 2D renderings, specifically handling foreground-background ambiguity in boundary regions [S1, unofficial]. It differs from standard initialization by using Weighted Principal Component Analysis (WPCA) on clustered 3D points derived from depth maps, followed by a scaling calibration step to align the projected 3D covariance with the original 2D target [S1, unofficial].

## How it works
**Inputs:**
- `gaussian_2d`: A 2D Gaussian primitive with center $(u, v)$, covariance matrix $\hat{\Sigma}_{2D}$, and opacity/weight distribution [S1, unofficial].
- `depth_map`: A rendered depth map corresponding to the camera view [S1, unofficial].
- `camera`: Camera intrinsic and extrinsic parameters [S1, unofficial].

**Outputs:**
- `position`: 3D world-space coordinates [S1, unofficial].
- `rotation`: 3D Gaussian rotation (quaternion) [S1, unofficial].
- `scaling`: 3D Gaussian scaling factors [S1, unofficial].
- `lobe_orientation`: Unit vector for opacity lobe orientation [S1, unofficial].
- `T`: Opacity lobe width parameter [S1, unofficial].
- `beta`: Opacity lobe sharpness parameter [S1, unofficial].
- `color`: Base color [S1, unofficial].
- `opacity`: Base opacity [S1, unofficial].
- `sh_coeffs`: Higher-order spherical harmonic coefficients [S1, unofficial].

**Data Structures:**
- `pixels_world`: List of dictionaries containing 3D position, depth, and 2D Gaussian weight for each covered pixel [S1, unofficial].
- `groups`: List of clusters from hierarchical clustering [S1, unofficial].

**Parameters:**
- `threshold`: Initial clustering distance threshold set to $5 \cdot \delta_d$, where $\delta_d$ is the world-space distance between adjacent pixels at the Gaussian center's depth [S1, unofficial].
- `threshold_multiplier`: Factor by which to increase the clustering threshold if clustering fails. Value: 1.5 [S1, unofficial].

**Steps:**

1. **Compute 3D Coordinates:**
   For all pixels covered by the 2D Gaussian kernel, compute the 3D world coordinates using the depth map and camera parameters [S1, unofficial]. Assign each point a weight equal to the 2D Gaussian distribution value at that pixel [S1, unofficial].

2. **Foreground-Background Separation (Clustering):**
   Initialize `threshold` to $5 \cdot \delta_d$ [S1, unofficial]. Perform hierarchical clustering using single-linkage merging on `pixels_world` using `threshold` as the distance limit [S1, unofficial]. Check if any cluster contains at least 3 points and covers the Gaussian center's pixel [S1, unofficial]. If no such cluster exists, select the largest cluster with at least 3 points [S1, unofficial]. If clustering fails to produce a valid cluster, increase `threshold` by multiplying by 1.5 and repeat clustering [S1, unofficial].

3. **Weighted PCA (WPCA):**
   Select the valid cluster from Step 2 as `filtered_points` [S1, unofficial]. Determine if the Gaussian center's pixel is included in `filtered_points` (boolean `INCLUDE_CENTER`) [S1, unofficial]. Compute WPCA on `filtered_points` using the 2D Gaussian weights [S1, unofficial]. The principal axes form the rotation matrix $R$ (converted to quaternion) [S1, unofficial]. The standard deviations $\sigma_1, \sigma_2, \sigma_3$ from WPCA form the base scaling vector [S1, unofficial].

4. **Position Determination:**
   If `INCLUDE_CENTER` is true, sample the depth value $d$ from the `depth_map` at the Gaussian center $(u, v)$ [S1, unofficial]. If `INCLUDE_CENTER` is false, compute the weighted average depth $\bar{d}$ of `filtered_points`, where weights are the 2D Gaussian distribution values [S1, unofficial]. Convert $(u, v, d)$ to world space using the camera parameters to get `position` [S1, unofficial].

5. **Scaling Calibration:**
   Project the current 3D Gaussian (defined by `position`, `rotation`, and base `scaling` from WPCA) into the 2D image space to obtain the projected covariance matrix $\Sigma_{2D}$ [S1, unofficial]. The relationship is given by:
   $$ \Sigma_{2D} = J W R S (J W R S)^T $$
   where $J \in \mathbb{R}^{2\times3}$ is the Jacobian of the projective transformation, $W$ is the world-to-view matrix, $R$ is the rotation matrix, and $S = \text{diag}(\sigma_1, \sigma_2, \sigma_3)$ is the scaling diagonal matrix [S1, unofficial]. Define $Q = \Sigma_{2D} / k^2$, where $k$ is the target scaling coefficient [S1, unofficial]. Minimize the Frobenius norm between the projected covariance and the target 2D covariance $\hat{\Sigma}_{2D}$:
   $$ \min_k ||\Sigma_{2D} - \hat{\Sigma}_{2D}||_F $$
   The solution for $k$ is:
   $$ k = \sqrt{\frac{\sum_{ij} Q_{ij} \hat{\Sigma}_{2D_{ij}}}{||Q||_F^2}} $$
   where $||Q||_F$ is the Frobenius norm of $Q$ [S1, unofficial]. Update the scaling: $S_{final} = k \cdot \text{diag}(\sigma_1, \sigma_2, \sigma_3)$ [S1, unofficial].

6. **Opacity Lobe and Color Initialization:**
   - **Opacity Lobe Orientation:** Set to the unit vector from the Gaussian centroid to the camera [S1, unofficial].
   - **Width $T$:** Initialize as $c \bar{\theta}_i / \pi$, where $\bar{\theta}_i$ is the minimum angle between the viewing vector and the lobe orientation for visible cameras $C_i$, and $c$ is a constant [S1, unofficial].
   - **Sharpness $\beta$:** Initialize to 0 [S1, unofficial].
   - **Color/Opacity:** Initialize base color and opacity to the 2D primitive counterparts [S1, unofficial]. Zero-initialize higher-order spherical harmonic coefficients [S1, unofficial].

**Pseudocode:**

```python
def inverse_splatting(gaussian_2d, depth_map, camera):
    # Step 1: Compute 3D coordinates for all pixels covered by the 2D Gaussian
    pixels_world = []
    for u, v in gaussian_2d.support_pixels():
        d = depth_map[u, v]
        if d > 0:
            pixels_world.append({
                'pos': camera.unproject(u, v, d),
                'depth': d,
                'weight': gaussian_2d.density(u, v)
            })

    # Initial threshold: 5 * world-space distance between adjacent pixels at center depth
    center_depth = depth_map[gaussian_2d.center]
    delta_d = camera.pixel_distance_at_depth(center_depth)
    threshold = 5.0 * delta_d

    groups = []
    while True:
        groups = cluster_points(pixels_world, threshold)
        center_3d = camera.unproject(gaussian_2d.center[0], gaussian_2d.center[1], center_depth)
        valid_cluster = None
        
        # Priority: cluster with >=3 points covering center
        for cluster in groups:
            if len(cluster) >= 3 and any(dist(p['pos'], center_3d) < 1e-6 for p in cluster):
                valid_cluster = cluster
                break
                
        if valid_cluster is None:
            # Fallback: largest cluster with >=3 points
            valid_clusters = [c for c in groups if len(c) >= 3]
            if valid_clusters:
                valid_cluster = max(valid_clusters, key=len)
            else:
                threshold = threshold * 1.5
                continue
        break

    filtered_points = valid_cluster
    INCLUDE_CENTER = any(dist(p['pos'], center_3d) < 1e-6 for p in filtered_points)

    # Step 2: Weighted Principal Component Analysis (WPCA)
    rotation, scaling_base = WPCA(filtered_points)

    # Step 3: Position determination
    if INCLUDE_CENTER:
        depth = center_depth
    else:
        total_weight = sum(p['weight'] for p in filtered_points)
        depth = sum(p['depth'] * p['weight'] for p in filtered_points) / total_weight

    position = camera.unproject(gaussian_2d.center[0], gaussian_2d.center[1], depth)

    # Step 4: Scaling calibration
    # Q = Sigma_2D / k^2. Computing with base scaling (k=1) yields Q directly.
    Q = project_covariance(rotation, scaling_base, position, camera)
    numerator = sum(Q[i][j] * gaussian_2d.cov[i][j] for i in range(2) for j in range(2))
    denominator = frobenius_norm(Q) ** 2
    k = sqrt(numerator / denominator)
    scaling = k * scaling_base

    # Step 5: Opacity Lobe and Color Initialization
    lobe_orientation = normalize(camera.position - position)
    
    # T initialization: c * min_angle / pi
    visible_cameras = camera.get_frustum_visible_cameras()
    min_angle = min(angle_between(camera.view_vector(c), lobe_orientation) for c in visible_cameras)
    T = c * min_angle / pi
    
    beta = 0.0
    color = gaussian_2d.color
    opacity = gaussian_2d.opacity
    sh_coeffs = [0.0] * (gaussian_2d.sh_degree + 1) ** 2

    return position, rotation, scaling, lobe_orientation, T, beta, color, opacity, sh_coeffs

# Helper functions
def cluster_points(points, threshold):
    groups = []
    for p in points:
        found = False
        for g in groups:
            if any(dist(p['pos'], q['pos']) <= threshold for q in g):
                g.append(p)
                found = True
                break
        if not found:
            groups.append([p])
    return groups

def WPCA(points):
    total_weight = sum(p['weight'] for p in points)
    centroid = sum(p['pos'] * p['weight'] for p in points) / total_weight
    cov = sum((p['pos'] - centroid) @ (p['pos'] - centroid).T * p['weight'] for p in points) / total_weight
    eigenvalues, eigenvectors = torch.linalg.eigh(cov)
    rotation = matrix_to_quaternion(eigenvectors)
    scaling_base = sqrt(eigenvalues)
    return rotation, scaling_base

def project_covariance(rotation, scaling, position, camera):
    R = quaternion_to_matrix(rotation)
    S = torch.diag(scaling)
    W = camera.extrinsics
    J = camera.jacobian(position)
    Sigma_3D = R @ S @ S.T @ R.T
    Sigma_2D = J @ W @ Sigma_3D @ W.T @ J.T
    return Sigma_2D[:2, :2]

def frobenius_norm(M):
    return sqrt(sum(M[i][j]**2 for i in range(M.shape[0]) for j in range(M.shape[1])))

def dist(a, b):
    return sqrt(sum((a[i]-b[i])**2 for i in range(3)))

def normalize(v):
    return v / sqrt(sum(x**2 for x in v))

def angle_between(a, b):
    cos_theta = sum(a[i]*b[i] for i in range(len(a))) / (sqrt(sum(x**2 for x in a)) * sqrt(sum(x**2 for x in b)))
    return acos(max(-1.0, min(1.0, cos_theta)))
```

## Background
Inverse Gaussian Splattling was introduced in "Augmented Radiance Field: A General Framework for Enhanced Gaussian Splatting" (ICLR 2026) [S1, unofficial]. It addresses the limitations of standard 3D Gaussian Splatting initialization by incorporating view-dependent opacity models (based on Phong shading) which require careful initialization of opacity lobes [S1, unofficial]. The method back-projects 2D Gaussians optimized in image space to 3D space to serve as initializations for new 3D Gaussians, improving reconstruction fidelity, particularly in complex radiance distributions [S1, unofficial]. During the final joint optimization stage, learning rates are configured as 0.000016 for position, 0.001 for diffuse color, 0.001/20 for higher-order spherical harmonic coefficients, 0.02 for opacity, 0.002 for scaling, 0.0005 for rotation, 0.001 for opacity lobe orientation, 0.0002 for opacity lobe width $T$, and 0.002 for sharpness $\beta$ [S1, unofficial].
