# CoherentGS
## Overview
CoherentGS is a regularized optimization method for sparse novel view synthesis that introduces structural coherency to explicit 3D Gaussian representations by constraining Gaussian movement in 2D image space [S1]. It solves the instability and needle-like artifacts common in standard 3D Gaussian Splatting when trained on extremely sparse input views by enforcing single-view and multi-view consistency, thereby preventing overfitting and allowing for the identification of occluded regions suitable for inpainting [S1]. Unlike NeRF-based sparse methods that rely on implicit MLPs and produce blurry occluded regions, CoherentGS maintains an explicit representation that can be cleanly segmented for diffusion-based inpainting [S1].

## How it works
**Inputs:**
*   $N$ sparse input images with known camera poses [S1].
*   Monocular depth estimates for each input view [S1].
*   Dense flow correspondences between all pairs of input images [S1].
*   Binary segmentation masks derived from thresholding the monocular depth estimates to preserve sharp discontinuities [S1].

**Outputs:**
*   A set of 3D Gaussians defined by position $\mathbf{x}$, covariance $\Sigma$, opacity $\alpha$, and color $\mathbf{c}$ [S1].

**Data Structures:**
The method assigns exactly one Gaussian to every pixel of every input image, creating a structured representation [S1].
*   Let $\mathcal{G}$ be the set of Gaussians [S1].
*   For each input image $n \in \{1, \dots, N\}$ and each pixel $\mathbf{p}$ in that image, there is a corresponding Gaussian $g_{n,\mathbf{p}} \in \mathcal{G}$ [S1].
*   The position $\mathbf{x}_{n,\mathbf{p}}$ of each Gaussian is constrained to lie on the ray connecting the camera center of view $n$ to pixel $\mathbf{p}$ [S1].
*   Initial positions are determined by the monocular depth estimate $D_{init}(n, \mathbf{p})$ [S1].

**Numbered Steps:**

1.  **Depth-based Initialization:**
    For each input image $n$ and pixel $\mathbf{p}$, initialize the 3D position $\mathbf{x}_{n,\mathbf{p}}$ using the monocular depth estimate $D_{init}(n, \mathbf{p})$ [S1]. The depth is relative, so the initialization places Gaussians in world space consistent with the camera pose [S1].

2.  **Implicit Decoder Setup:**
    Initialize an implicit convolutional decoder [S1]. This decoder takes the 2D image coordinate $\mathbf{p}$ and the camera pose of the input view $n$ as input [S1].

3.  **Regularized Optimization Loop:**
    Minimize the optimization objective to update Gaussian parameters $\Sigma, \alpha, \mathbf{x}, \mathbf{c}$ [S1]. The objective function is:
    $$ \Sigma^*, \alpha^*, \mathbf{x}^*, \mathbf{c}^* = \arg\min_{\Sigma, \alpha, \mathbf{x}, \mathbf{c}} \sum_{\mathbf{p} \in \mathcal{P}} \mathcal{L}(R_{\Sigma, \alpha, \mathbf{x}, \mathbf{c}}(\mathbf{p}), R(\mathbf{p})) $$
    where $\mathcal{P}$ contains all pixels of every input image, $R(\mathbf{p})$ is the reference pixel color, and $\mathcal{L}$ is the combination of L1 and SSIM losses [S1].

    During optimization, the rendering equation for a pixel $\mathbf{p}$ is:
    $$ R_{\Sigma, \alpha, \mathbf{x}, \mathbf{c}}(\mathbf{p}) = \sum_{i \in \mathcal{N}(\mathbf{p})} \mathbf{c}_i \gamma_i \prod_{j=1}^{i-1}(1-\gamma_j) $$
    where $\mathcal{N}(\mathbf{p})$ is the set of ordered Gaussians overlapping pixel $\mathbf{p}$, and $\gamma_k = f(\Sigma_k, \alpha_k, \mathbf{x}_k, \mathbf{p})$ computes the effective opacity by evaluating the Gaussian at $\mathbf{p}$ and multiplying by global opacity $\alpha$ [S1].

    To enforce coherency, the following constraints are applied to the gradients or directly to the parameters:

    *   **Single-View Coherency:**
        Pass the input view coordinate $\mathbf{p}$ and camera pose to the implicit decoder to predict a residual depth value $\Delta D$ [S1]. The updated depth $D$ is $D_{init} + \Delta D$ [S1]. Gaussians with similar initial depth are forced to move together by the decoder's output, ensuring smooth depth variations within a single view [S1]. Binary segmentation masks are applied to the decoder output to preserve sharp discontinuities [S1].

    *   **Multi-View Coherency:**
        Compute a depth map for all Gaussians for each view [S1]. Apply a Total Variation (TV) loss to the rendered depth across all Gaussians to ensure smoothness and consistency across views [S1].

    *   **Flow-based Loss:**
        Use the pre-computed dense flow correspondences between image pairs [S1]. Apply a flow-based loss to constrain optimization by ensuring that corresponding pixels in two images have similar Gaussian positions [S1]. This enforces cross-view consistency [S1].

**Pseudocode:**

```python
def coherent_gs_optimization(input_images, camera_poses, monocular_depths, flow_correspondences, num_iterations, lr):
    N = len(input_images)
    H, W = input_images[0].shape[:2]
    
    # Data structure: gaussians[n][p] = {'x': [x,y,z], 'sigma': [[...]], 'alpha': float, 'c': [r,g,b]}
    gaussians = {}
    for n in range(N):
        gaussians[n] = {}
        for y in range(H):
            for x in range(W):
                p = (x, y)
                ray_origin = camera_poses[n].origin
                ray_dir = unproject_ray(camera_poses[n], p)
                depth_init = monocular_depths[n][y, x]
                gaussians[n][p] = {
                    'x': [ray_origin[i] + ray_dir[i] * depth_init for i in range(3)],
                    'sigma': [[1.0 if i==j else 0.0 for j in range(3)] for i in range(3)],
                    'alpha': 0.5,
                    'c': list(input_images[n][y, x])
                }

    def predict_residual_depth(p, camera_idx):
        # [G] Forward pass of implicit convolutional decoder
        return 0.0 

    for iteration in range(num_iterations):
        total_loss = 0.0
        
        # Photometric loss (L1 + SSIM)
        for n in range(N):
            rendered_color = render_color(gaussians, camera_poses[n], H, W)
            total_loss += l1_loss(rendered_color, input_images[n])
            # SSIM loss added per [S1]
        
        # Single-View Coherency
        for n in range(N):
            masks = compute_segmentation_masks(monocular_depths[n])
            for y in range(H):
                for x in range(W):
                    p = (x, y)
                    delta_d = predict_residual_depth(p, n)
                    # Apply binary masks to preserve sharp discontinuities
                    if masks[y, x] < 0.5:
                        delta_d = 0.0
                    # Loss penalizes deviation from predicted smooth depth field
                    total_loss += abs(delta_d)
                    
        # Multi-View Coherency (TV on rendered depth)
        for n in range(N):
            rendered_depth = render_depth(gaussians, camera_poses[n], H, W)
            tv_loss = compute_total_variation(rendered_depth)
            total_loss += tv_loss
            
        # Flow-based Loss
        for (n1, n2), flow_map in flow_correspondences.items():
            for y in range(H):
                for x in range(W):
                    p1 = (x, y)
                    dx, dy = flow_map[y, x]
                    p2 = (x + int(dx), y + int(dy))
                    if 0 <= p2[0] < W and 0 <= p2[1] < H:
                        # Ensure corresponding pixels have similar Gaussian positions
                        total_loss += distance(gaussians[n1][p1]['x'], gaussians[n2][p2]['x'])
                        
        # [G] Standard automatic differentiation and parameter update
        grads = compute_gradients(total_loss, gaussians)
        update_gaussians(gaussians, grads, lr)
        
    return gaussians

def unproject_ray(camera, p):
    # [G] Convert pixel to normalized coordinates and transform to world ray direction
    return [1.0, 0.0, 0.0]

def render_color(gaussians, camera, H, W):
    # [G] Standard 3DGS alpha compositing per pixel
    color = [[0.0, 0.0, 0.0] for _ in range(H)]
    for y in range(H):
        for x in range(W):
            p = (x, y)
            # Gather all Gaussians from all views that project to pixel p
            overlapping = []
            for n in range(len(gaussians)):
                if p in gaussians[n]:
                    overlapping.append(gaussians[n][p])
            # Sort Gaussians overlapping p by depth
            overlapping.sort(key=lambda g: dot(g['x'], camera.view_dir))
            accum_alpha = 0.0
            for g in overlapping:
                gamma = gaussian_opacity(g, camera, p)
                color[y][x] = [c + g['c'][i] * gamma * (1 - accum_alpha) for i, c in enumerate(color[y][x])]
                accum_alpha += gamma * (1 - accum_alpha)
    return color

def render_depth(gaussians, camera, H, W):
    # [G] Standard depth compositing
    depth = [[0.0] * W for _ in range(H)]
    for y in range(H):
        for x in range(W):
            p = (x, y)
            overlapping = []
            for n in range(len(gaussians)):
                if p in gaussians[n]:
                    overlapping.append(gaussians[n][p])
            overlapping.sort(key=lambda g: dot(g['x'], camera.view_dir))
            accum_alpha = 0.0
            for g in overlapping:
                gamma = gaussian_opacity(g, camera, p)
                depth[y][x] += g['x'][2] * gamma * (1 - accum_alpha)
                accum_alpha += gamma * (1 - accum_alpha)
    return depth

def gaussian_opacity(g, camera, p):
    # [G] Evaluate Gaussian at pixel p and multiply by global opacity
    return 0.5

def l1_loss(rendered, target):
    return sum(abs(rendered[i][j][k] - target[i][j][k]) for i in range(len(rendered)) for j in range(len(rendered[0])) for k in range(3))

def compute_segmentation_masks(depth_map):
    threshold = 0.5
    return [[1.0 if d > threshold else 0.0 for d in row] for row in depth_map]

def compute_total_variation(depth_map):
    tv = 0.0
    for y in range(len(depth_map)):
        for x in range(len(depth_map[0]) - 1):
            tv += abs(depth_map[y][x] - depth_map[y][x+1])
    return tv

def distance(v1, v2):
    return sum((v1[i] - v2[i])**2 for i in range(3))**0.5

def compute_gradients(loss, params):
    # [G] Standard automatic differentiation or finite difference approximation
    return params

def update_gaussians(params, grads, lr):
    for n in params:
        for p in params[n]:
            params[n][p]['x'] = [params[n][p]['x'][i] - lr * grads[n][p]['x'][i] for i in range(3)]
```

**Parameters:**
*   $N$: Number of sparse input images. Typically 3 or 4 [S1].
*   Learning rate: Not given in the sources [S1].
*   Number of iterations: Not given in the sources [S1].

**Edge Cases and Pitfalls:**
*   **Optimization Instability:** Constraining unstructured Gaussians directly in 3D space causes optimization instability [S1]. CoherentGS avoids this by mapping constraints to 2D image space [S1].
*   **Occluded Regions:** Because the constraints prevent Gaussians from moving freely in 3D space, the method does not reconstruct areas that are occluded in all input images [S1]. This is a feature, not a bug, as it allows these regions to be identified and inpainted using diffusion models [S1].
*   **Relative Depth:** Monocular depth estimates are relative and lack consistency across views [S1]. The depth-based initialization positions Gaussians in world space, but the regularized optimization is required to encourage coherent updates [S1].

## Subtopics

### [MVGS (Multi-view-regulated Gaussian Splatting)](15778-mvgs-multi-view-regulated-gaussian-splatting.md)
MVGS is a plug-and-play optimization method that improves Novel View Synthesis (NVS) performance for existing Gaussian-based methods by constraining the optimization of 3D Gaussians with multi-view information. It sets itself apart from its parent [CoherentGS](14072-coherentgs.md), which enforces 2D image-space coherency, by explicitly leveraging cross-view consistency through a cross-intrinsic guidance scheme and multi-view cross-ray densification to enhance detail and stability.

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1].
*   **Memory Complexity:** Not given in the sources [S1].
*   **Measured Performance:** CoherentGS yields high-quality synthesized views compared to state-of-the-art sparse-view NeRF-based approaches (e.g., FreeNeRF, SparseNeRF) on a variety of scenes [S1].
*   **Scaling:** The method is designed for extremely sparse input views (e.g., 3 images) [S1].
*   **Strengths:** Prevents overfitting to input images; allows identification of fully occluded areas for inpainting; avoids blurry occluded regions common in NeRF-based methods; improves texture and geometry reconstruction [S1].
*   **Limitations:** Does not reconstruct areas occluded in all input images (requires inpainting); relies on pre-trained monocular depth and flow models [S1].
*   **When to use:** Sparse novel view synthesis (3-4 input images) in static scenes [S1].
*   **When not to use:** Scenes where fully automatic reconstruction of all occluded regions without inpainting is required [S1].

## Background
CoherentGS was proposed by A. Paliwal et al. during an internship at Meta Reality Labs [S1]. The work addresses the limitation of 3D Gaussian Splatting (3DGS) in extremely sparse input settings, where the unstructured representation leads to artifacts [S1]. It builds on the explicit representation of 3DGS [23] and integrates concepts from implicit decoders [5, 30, 37] and monocular depth prediction [60] and flow estimation [45] to enforce coherency [S1].
