# Parallel Differentiable Rasterization

Also called: F_HDR / F_LDR, HDR-GS rasterization

## Overview
Parallel Differentiable Rasterization is a rendering method that jointly generates High Dynamic Range (HDR) and Low Dynamic Range (LDR) images from a set of 3D Gaussian primitives using two parallel rasterization pipelines, $F_{HDR}$ and $F_{LDR}$ [S1]. It differs from standard differentiable rasterization by decoupling the color representation into independent HDR and LDR streams that share the same geometric projection and alpha-blending logic, allowing for simultaneous optimization of high-intensity and standard-range views [S1].

## How it works
**Inputs:**
*   Set of $N$ 3D Gaussians $\{G_i\}_{i=1}^N$, where each $G_i$ has mean $\boldsymbol{\mu}_i$, covariance $\boldsymbol{\Sigma}_i$, opacity $\alpha_i$, HDR color $\mathbf{c}_{hi}$, and LDR color $\mathbf{c}_{li}(\Delta t)$ [S1].
*   Extrinsic matrix $\mathbf{M}_{ext} \in \mathbb{R}^{4 \times 4}$ [S1].
*   Intrinsic matrix $\mathbf{M}_{int} \in \mathbb{R}^{3 \times 4}$ [S1].
*   Exposure time $\Delta t$ for LDR rendering [S1].
*   Image dimensions $H \times W$ [S1].

**Outputs:**
*   Rendered HDR image $\mathbf{I}_h \in \mathbb{R}^{H \times W \times 3}$ [S1].
*   Rendered LDR image $\mathbf{I}_l(\Delta t) \in \mathbb{R}^{H \times W \times 3}$ [S1].

**Data Structures:**
*   **Tile Grid:** The image plane is divided into non-overlapping tiles (e.g., $16 \times 16$ pixels) [S1].
*   **Gaussian List per Tile:** For each tile, a list of Gaussians whose 2D bounding boxes overlap the tile [S1].
*   **Sorted List:** Within each tile, Gaussians are sorted by view-space depth (front-to-back) [S1].

**Steps:**

1.  **Probability Evaluation:** For a point $\mathbf{x} \in \mathbb{R}^3$, compute the probability density of the $i$-th Gaussian [S1]:
    $$
    P(\mathbf{x} | \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i) = \exp\left(-\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu}_i)^\top \boldsymbol{\Sigma}_i^{-1} (\mathbf{x} - \boldsymbol{\mu}_i)\right)
    $$

2.  **Projection of Mean:** Transform the mean $\boldsymbol{\mu}_i$ from world to camera coordinates $\mathbf{v}_i$, then to image coordinates $\mathbf{u}_i$ [S1]:
    $$
    \tilde{\mathbf{e}}_i = [\mathbf{v}_i, 1]^\top = \mathbf{M}_{ext} [\boldsymbol{\mu}_i, 1]^\top
    $$
    $$
    \tilde{\mathbf{u}}_i = [\mathbf{u}_i, 1]^\top = \mathbf{M}_{int} \mathbf{v}_i
    $$
    where $\mathbf{u}_i \in \mathbb{R}^2$ and $\mathbf{v}_i \in \mathbb{R}^3$ [S1].

3.  **Covariance Transformation:** Transform the 3D covariance $\boldsymbol{\Sigma}_i$ to the camera coordinate system $\boldsymbol{\Sigma}'_i$ using the Jacobian $\mathbf{J}_i$ of the affine approximation of $\mathbf{M}_{int}\mathbf{M}_{ext}$ and the viewing transformation $\mathbf{W}_i$ (first 3 rows/cols of $\mathbf{M}_{ext}$) [S1]:
    $$
    \boldsymbol{\Sigma}'_i = \mathbf{J}_i \mathbf{W}_i \boldsymbol{\Sigma}_i \mathbf{W}_i^\top \mathbf{J}_i^\top
    $$

4.  **2D Covariance Derivation:** Derive the 2D covariance $\boldsymbol{\Sigma}''_i \in \mathbb{R}^{2 \times 2}$ by removing the third row and column from $\boldsymbol{\Sigma}'_i$ [S1].

5.  **Tiling and Assignment:** Assign each Gaussian to tiles where its 2D projection (defined by $\mathbf{u}_i$ and $\boldsymbol{\Sigma}''_i$) overlaps [S1].

6.  **Sorting:** Sort the assigned Gaussians in each tile by view-space depth (z-coordinate in camera space) [S1].

7.  **Rasterization (Blending):** For each pixel $\mathbf{p}$, identify the set $\mathcal{N}$ of ordered Gaussians overlapping $\mathbf{p}$ in the corresponding tile. Compute the opacity contribution $\sigma_j$ for the $j$-th Gaussian [S1]:
    $$
    \sigma_j = \alpha_j P(\mathbf{x}_j | \boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)
    $$
    where $\mathbf{x}_j$ is the intersection point between the ray from the camera optical center through $\mathbf{p}$ and the $j$-th Gaussian [S1].

    Compute the final colors by alpha blending [S1]:
    $$
    \mathbf{I}_h(\mathbf{p}) = \sum_{j \in \mathcal{N}} \mathbf{c}_{hj} \sigma_j \prod_{k=1}^{j-1} (1 - \sigma_k)
    $$
    $$
    \mathbf{I}_l(\mathbf{p}|\Delta t) = \sum_{j \in \mathcal{N}} \mathbf{c}_{lj}(\Delta t) \sigma_j \prod_{k=1}^{j-1} (1 - \sigma_k)
    $$
    where $\mathbf{c}_{hj}$ is the HDR color and $\mathbf{c}_{lj}(\Delta t)$ is the LDR color with exposure time $\Delta t$ [S1].

**Pseudocode:**

```python
def parallel_differentiable_rasterization(gaussians, M_ext, M_int, delta_t, tile_size):
    """
    gaussians: List of Gaussian objects with attributes:
        mu: (3,) mean position
        Sigma: (3,3) covariance
        alpha: scalar opacity
        c_h: (3,) HDR color
        c_l: (3,) LDR color
    M_ext: (4,4) extrinsic matrix
    M_int: (3,4) intrinsic matrix
    delta_t: float exposure time
    tile_size: int size of square tiles (e.g., 16)
    
    Returns:
        I_h: (H, W, 3) HDR image
        I_l: (H, W, 3) LDR image
    """
    H, W = image_dimensions # Derived from M_int and scene bounds
    num_tiles_h = ceil(H / tile_size)
    num_tiles_w = ceil(W / tile_size)
    
    # Initialize tile lists
    # tile_gaussians[tile_idx] = list of gaussian indices
    tile_gaussians = [[] for _ in range(num_tiles_h * num_tiles_w)]
    
    # Precompute projections for all Gaussians
    projected_gaussians = []
    for i, g in enumerate(gaussians):
        # 1. Project Mean
        mu_hom = np.append(g.mu, 1.0)
        v_hom = M_ext @ mu_hom
        v = v_hom[:3]
        u_hom = M_int @ v_hom
        u = u_hom[:2]
        
        # 2. Transform Covariance
        # W_i is first 3 rows/cols of M_ext
        W_i = M_ext[:3, :3]
        # J_i is Jacobian of affine approx of M_int @ M_ext
        # For standard pinhole, J_i is often approximated or computed via partial derivatives
        # Here we assume J_i is provided or computed as the top 3x3 of M_int @ M_ext
        # Note: The source defines J_i as Jacobian of affine approximation.
        # In practice, for perspective, this is complex. We assume J_i is available.
        J_i = compute_jacobian_affine_approx(M_int, M_ext, v) 
        
        Sigma_prime = J_i @ W_i @ g.Sigma @ W_i.T @ J_i.T
        
        # 3. 2D Covariance
        Sigma_2d = Sigma_prime[:2, :2]
        
        # 4. Determine Tile Coverage
        # Calculate bounding box of 2D Gaussian (e.g., 3-sigma)
        # Eigen decomposition of Sigma_2d to get axes
        eigenvalues, eigenvectors = np.linalg.eigh(Sigma_2d)
        # Bounding box half-widths
        half_widths = 3.0 * np.sqrt(eigenvalues)
        min_x = u[0] - half_widths[0]
        max_x = u[0] + half_widths[0]
        min_y = u[1] - half_widths[1]
        max_y = u[1] + half_widths[1]
        
        # Clip to image bounds
        min_x = max(0, min_x)
        max_x = min(W, max_x)
        min_y = max(0, min_y)
        max_y = min(H, max_y)
        
        # Assign to tiles
        tile_start_x = int(min_x // tile_size)
        tile_end_x = int(max_x // tile_size)
        tile_start_y = int(min_y // tile_size)
        tile_end_y = int(max_y // tile_size)
        
        for ty in range(tile_start_y, tile_end_y + 1):
            for tx in range(tile_start_x, tile_end_x + 1):
                if 0 <= ty < num_tiles_h and 0 <= tx < num_tiles_w:
                    tile_idx = ty * num_tiles_w + tx
                    tile_gaussians[tile_idx].append(i)
        
        projected_gaussians.append({
            'idx': i,
            'u': u,
            'v': v,
            'Sigma_2d': Sigma_2d,
            'alpha': g.alpha,
            'c_h': g.c_h,
            'c_l': g.c_l
        })

    # Initialize output images
    I_h = np.zeros((H, W, 3))
    I_l = np.zeros((H, W, 3))
    
    # Rasterize each tile
    for ty in range(num_tiles_h):
        for tx in range(num_tiles_w):
            tile_idx = ty * num_tiles_w + tx
            g_indices = tile_gaussians[tile_idx]
            
            if not g_indices:
                continue
                
            # Sort by view-space depth (z in camera coords)
            # v is camera coordinate, v[2] is depth
            sorted_indices = sorted(g_indices, key=lambda i: projected_gaussians[i]['v'][2])
            
            # Determine pixel range for this tile
            y_start = ty * tile_size
            y_end = min((ty + 1) * tile_size, H)
            x_start = tx * tile_size
            x_end = min((tx + 1) * tile_size, W)
            
            # For each pixel in tile
            for y in range(y_start, y_end):
                for x in range(x_start, x_end):
                    # Ray from camera center through pixel
                    # This requires inverse intrinsic matrix
                    # u_pixel = [x, y, 1]
                    # v_ray = M_int^-1 @ [x, y, 1]
                    # Normalize or use as direction
                    # Intersection x_j is needed for P(x_j | mu, Sigma)
                    # In standard 3DGS, P is evaluated at the projected center or intersection.
                    # Source says x_j is intersection point.
                    
                    # Approximation: Use the 2D Gaussian evaluation at pixel center relative to projected mean
                    # Or compute exact intersection. Source implies exact intersection.
                    # For implementation simplicity in this pseudocode, we use the 2D Gaussian PDF
                    # evaluated at the pixel coordinate relative to the projected mean,
                    # scaled by the determinant of the 2D covariance if necessary, 
                    # but the source formula uses P(x_j | mu, Sigma) which is 3D.
                    # However, the blending formula uses sigma_j = alpha_j * P(x_j | mu_j, Sigma_j).
                    # In many rasterizers, this is approximated by the 2D Gaussian value.
                    # Let's stick to the source's definition: x_j is intersection.
                    
                    # Compute ray direction
                    ray_dir = compute_ray_direction(x, y, M_int)
                    
                    # Find intersection with Gaussian j
                    # This is complex. Standard 3DGS rasterizers often approximate P(x_j) 
                    # by evaluating the 2D Gaussian at the pixel.
                    # The source formula: sigma_j = alpha_j * P(x_j | mu_j, Sigma_j)
                    # where x_j is the intersection.
                    
                    # To make this implementable from text:
                    # We will approximate P(x_j) by the 2D Gaussian density at the pixel.
                    # P_2d(u | u_j, Sigma_2d) = 1/(2*pi*sqrt(det)) * exp(...)
                    # The source doesn't specify the normalization constant for the 2D projection 
                    # explicitly in the blending formula, but P is defined as 3D density.
                    # Usually, the alpha blending uses the projected alpha.
                    
                    # Let's assume the standard 3DGS approach where sigma_j is the 
                    # projected alpha at the pixel.
                    
                    cum_alpha = 0.0
                    color_h = np.zeros(3)
                    color_l = np.zeros(3)
                    
                    for idx in sorted_indices:
                        pg = projected_gaussians[idx]
                        
                        # Compute distance from pixel (x,y) to projected mean (u_x, u_y)
                        dist_sq = (x - pg['u'][0])**2 + (y - pg['u'][1])**2
                        
                        # Evaluate 2D Gaussian
                        # Sigma_2d is 2x2
                        try:
                            inv_Sigma = np.linalg.inv(pg['Sigma_2d'])
                            diff = np.array([x - pg['u'][0], y - pg['u'][1]])
                            exponent = -0.5 * diff @ inv_Sigma @ diff
                            # Note: Source uses P(x_j | mu, Sigma) which is 3D.
                            # If we use 2D approximation, we might need scaling.
                            # However, for differentiability, the 2D PDF is standard.
                            # We will use the 2D PDF value.
                            # P_2d = exp(exponent) / (2 * pi * sqrt(det(Sigma_2d)))
                            det_Sigma = np.linalg.det(pg['Sigma_2d'])
                            if det_Sigma <= 0:
                                pdf_val = 0.0
                            else:
                                pdf_val = np.exp(exponent) / (2 * np.pi * np.sqrt(det_Sigma))
                        except:
                            pdf_val = 0.0
                            
                        sigma_j = pg['alpha'] * pdf_val
                        
                        # Alpha blending
                        weight = sigma_j * (1 - cum_alpha)
                        color_h += weight * pg['c_h']
                        color_l += weight * pg['c_l']
                        cum_alpha += weight
                        
                        if cum_alpha > 0.99: # Early exit
                            break
                    
                    I_h[y, x] = color_h
                    I_l[y, x] = color_l

    return I_h, I_l

def compute_jacobian_affine_approx(M_int, M_ext, v):
    # Approximation: J_i is the top 3x3 of M_int @ M_ext
    # This is an affine approximation of the projective transform
    return (M_int @ M_ext)[:3, :3]

def compute_ray_direction(x, y, M_int):
    # Inverse intrinsic to get direction in camera space
    # Assuming M_int is 3x3 for direction, or 3x4 with last col 0
    # Standard pinhole: x_cam = f * X/Z + cx
    # Direction is inverse of projection
    inv_M_int = np.linalg.inv(M_int[:3, :3])
    pixel_hom = np.array([x, y, 1.0])
    dir_cam = inv_M_int @ pixel_hom
    return dir_cam / np.linalg.norm(dir_cam)
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of Gaussians $N$ and pixels $H \times W$, dominated by the sorting and blending steps within tiles. Tiling reduces the sorting overhead from $O(N \log N)$ to $O(N_{tile} \log N_{tile})$ per tile.
*   **Memory Complexity:** $O(N)$ to store Gaussian parameters and $O(H \times W)$ for the image buffers. Tile-based processing allows for lower peak memory usage if tiles are processed sequentially.
*   **Strengths:** Enables joint optimization of HDR and LDR views, which is critical for high-fidelity novel view synthesis in varying lighting conditions. The parallel structure allows efficient GPU implementation.
*   **Limitations:** Requires careful handling of the exposure time $\Delta t$ for LDR rendering. The approximation of the 2D covariance by skipping the third row/column may introduce artifacts for highly oblique views [S1].

## Background
Parallel Differentiable Rasterization was introduced in the context of HDR-GS (HDR Gaussian Splatting) to address the limitations of standard 3D Gaussian Splatting in high dynamic range scenarios [S1]. Traditional methods struggle with the wide range of intensities found in HDR scenes, often clipping highlights or losing detail in shadows. By maintaining separate color streams for HDR and LDR, this method allows the model to learn and render both representations simultaneously, leveraging the differentiability of the rasterization process for end-to-end training [S1].
