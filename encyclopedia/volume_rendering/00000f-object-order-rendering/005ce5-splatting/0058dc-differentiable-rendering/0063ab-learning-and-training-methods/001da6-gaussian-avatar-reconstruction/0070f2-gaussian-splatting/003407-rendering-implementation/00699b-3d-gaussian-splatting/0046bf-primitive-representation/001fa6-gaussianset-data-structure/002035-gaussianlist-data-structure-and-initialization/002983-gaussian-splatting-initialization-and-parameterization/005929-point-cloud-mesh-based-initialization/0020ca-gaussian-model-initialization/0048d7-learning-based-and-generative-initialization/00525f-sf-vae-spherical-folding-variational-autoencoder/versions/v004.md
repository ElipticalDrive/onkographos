# SF-VAE (Spherical Folding Variational Autoencoder)
Also called: SFVAE, Spherical Folding VAE

## Overview
SF-VAE is a neural network architecture that encodes 3D Gaussian parameters into a latent space and decodes them using a spherical folding grid to reconstruct the geometry and color of the Gaussians [S1, unofficial]. It serves as a learning-based initialization method for 3D Gaussian Splatting, replacing random placement with a data-driven prior that ensures the generated primitives align with target surface geometry [S1, unofficial]. Unlike sibling methods that may use volume priors or cubic representations, SF-VAE explicitly models the spatial distribution of Gaussians via a folding mechanism, allowing for compact latent representations of complex shapes [S1, unofficial].

## How it works
**Inputs and Outputs:**
The model takes a set of 3D points (representing the target geometry) as input. The input data structure is a tensor of shape $(N, 7)$, where $N$ is the batch size (number of samples) and 7 represents the features per sample (typically 3 for centroid coordinates, 3 for scale, and 1 for opacity, or similar feature combinations depending on the specific implementation variant) [S1, unofficial]. The output is a set of reconstructed 3D Gaussian parameters (centroid, scale, rotation, opacity, and color) that approximate the input geometry [S1, unofficial].

**Data Structures:**
*   **SFModel:** The core model class.
    *   `input_dim`: 7 (features per point).
    *   `feature_dim`: `embedding_dim` (dimensionality of the latent vector $z$). Default: 32 [S1, unofficial].
    *   `grid_dim`: Dimension of the spherical folding grid. Default: 24 [S1, unofficial].
    *   `vae`: Boolean flag indicating if VAE loss is applied.
    *   `deterministic`: Boolean flag for sampling behavior.
*   **SFDecoder Grid:** A 2D grid of shape `[grid_dim^2, 2]` representing local coordinates on the sphere, repeated for the batch size [S1, unofficial].
*   **Latent Space:** A vector $z \in \mathbb{R}^{32}$ [S1, unofficial].

**Parameters:**
*   `embedding_dim`: Dimensionality of the latent feature vector $z$. Default: 32 [S1, unofficial].
*   `norm_weight`: Weight for the normalization loss term. Default: 0 [S1, unofficial].
*   `geo_weight`: Weight for the Chamfer loss term. Default: 0.5 [S1, unofficial].
*   `grid_dim`: Dimension of the folding grid. Default: 24 [S1, unofficial].

**Algorithm Steps:**
1.  **Encoding:** The input point cloud (or Gaussian parameters) is processed by an encoder network to produce the mean $\mu$ and log-variance $\log \sigma^2$ of the latent distribution.
2.  **Reparameterization:** A latent vector $z$ is sampled from the distribution $\mathcal{N}(\mu, \sigma^2)$ using the reparameterization trick: $z = \mu + \sigma \odot \epsilon$, where $\epsilon \sim \mathcal{N}(0, I)$ [S1, unofficial].
3.  **Decoding (Spherical Folding):** The latent vector $z$ is decoded using the SFDecoder. The decoder utilizes a spherical folding grid to map the latent features back to 3D space. The grid coordinates are used to interpolate or fold the latent features into spatial positions and attributes [S1, unofficial].
4.  **Reconstruction:** The decoder outputs the reconstructed Gaussian parameters (centroid, scale, rotation, opacity, color) [S1, unofficial].
5.  **Loss Calculation:**
    *   **Chamfer Loss:** Compute the Chamfer distance between the input points and the reconstructed points.
        $$ L_{Chamfer} = \frac{1}{N} \sum_{x \in X} \min_{y \in Y} \|x - y\|^2 + \frac{1}{M} \sum_{y \in Y} \min_{x \in X} \|y - x\|^2 $$
        where $X$ is the input set and $Y$ is the reconstructed set [S1, unofficial].
    *   **KL Divergence:** If VAE mode is enabled, compute the KL divergence loss:
        $$ L_{KL} = -0.5 \times \frac{1}{N} \sum_{i=1}^{N} \left( 1 + \log \sigma_i^2 - \mu_i^2 - \sigma_i^2 \right) $$
        where $N$ is the batch size, and $\mu_i, \sigma_i$ are the mean and standard deviation for the $i$-th dimension of the latent vector [S1, unofficial].
    *   **Total Loss:**
        $$ L_{Total} = L_{Chamfer} \times \text{geo\_weight} + L_{KL} \times \text{kl\_weight} + L_{Norm} \times \text{norm\_weight} $$
        where $L_{Norm}$ is the normalization loss (default weight 0) [S1, unofficial].

**Pseudocode:**

import torch
import torch.nn as nn
import torch.nn.functional as F

class SFVAE(nn.Module):
    def __init__(self, embedding_dim=32, grid_dim=24, vae=True, geo_weight=0.5, norm_weight=0.0):
        super(SFVAE, self).__init__()
        self.embedding_dim = embedding_dim
        self.grid_dim = grid_dim
        self.vae = vae
        self.geo_weight = geo_weight
        self.norm_weight = norm_weight
        
        # Encoder: Maps input (N, 7) to latent parameters (N, embedding_dim * 2)
        self.encoder = nn.Sequential(
            nn.Linear(7, 128),
            nn.ReLU(),
            nn.Linear(128, 256),
            nn.ReLU(),
            nn.Linear(256, embedding_dim * 2) # mu and logvar
        )
        
        # Decoder: Maps latent (N, embedding_dim) to reconstructed points (N, 7)
        # Uses spherical folding grid internally
        self.decoder = SFDecoder(embedding_dim, grid_dim)
        
        # Loss criterion
        self.criterion = ChamferLoss()

    def forward(self, x):
        """
        x: Input tensor of shape (N, 7)
        """
        # Encode
        params = self.encoder(x) # (N, embedding_dim * 2)
        mu = params[:, :self.embedding_dim]
        logvar = params[:, self.embedding_dim:]
        
        # Reparameterization
        if self.training and self.vae:
            std = torch.exp(0.5 * logvar)
            eps = torch.randn_like(std)
            z = mu + eps * std
        else:
            z = mu
            
        # Decode
        reconstructed = self.decoder(z) # (N, 7)
        
        return reconstructed, mu, logvar

    def loss(self, x, reconstructed, mu, logvar):
        # Chamfer Loss
        chamfer = self.criterion(x, reconstructed)
        loss_chamfer = chamfer * self.geo_weight
        
        # KL Divergence
        if self.vae:
            kl_loss = -0.5 * torch.mean(1 + logvar - mu.pow(2) - logvar.exp())
        else:
            kl_loss = torch.tensor(0.0, device=x.device)
            
        # Normalization Loss (if applicable)

        if self.norm_weight > 0:

            pass
            
        total_loss = loss_chamfer + kl_loss + norm_loss * self.norm_weight
        return total_loss

class SFDecoder(nn.Module):
    def __init__(self, embedding_dim, grid_dim):
        super(SFDecoder, self).__init__()
        self.grid_dim = grid_dim
        # Create spherical folding grid
        # Grid shape: (grid_dim^2, 2) representing local coordinates
        self.grid = self._create_grid(grid_dim)
        
        # Neural network to map latent z to grid weights/features
        self.fc = nn.Sequential(
            nn.Linear(embedding_dim, 128),
            nn.ReLU(),
            nn.Linear(128, grid_dim * grid_dim) # Weights for grid interpolation
        )

    def _create_grid(self, dim):
        # Create a grid of points on a sphere or local coordinates
        # This is a simplified representation; actual implementation may use spherical coordinates
        theta = torch.linspace(0, 2 * torch.pi, dim)
        phi = torch.linspace(0, torch.pi, dim)
        theta_grid, phi_grid = torch.meshgrid(theta, phi)
        # Convert to Cartesian or keep as local coords depending on folding logic
        # For simplicity, assume 2D local coords for folding
        grid = torch.stack([theta_grid.flatten(), phi_grid.flatten()], dim=1)
        return grid

    def forward(self, z):
        # z: (N, embedding_dim)
        # Compute weights for each grid point
        weights = self.fc(z) # (N, grid_dim^2)
        
        # Normalize weights
        weights = F.softmax(weights, dim=1)
        
        # Fold: Reconstruct points by weighted sum of grid coordinates
        # grid: (grid_dim^2, 2)
        # weights: (N, grid_dim^2)
        # reconstructed_local: (N, 2)
        reconstructed_local = torch.matmul(weights, self.grid)

class ChamferLoss(nn.Module):
    def __init__(self):
        super(ChamferLoss, self).__init__()

    def forward(self, x, y):
        # x, y: (N, 7)
        # Compute pairwise distances

        dist_x = torch.cdist(x, y, p=2) # (N, N)
        dist_y = torch.cdist(y, x, p=2) # (N, N)
        
        # Chamfer distance
        chamfer_x = torch.mean(torch.min(dist_x, dim=1)[0])

**Edge Cases and Pitfalls:**
*   **Precision:** Ensure that the latent space sampling does not produce degenerate Gaussians (e.g., zero scale or negative opacity). Clamping or sigmoid activation for opacity is recommended [S1, unofficial].
*   **Boundaries:** The spherical folding grid must cover the relevant spatial domain. If the input geometry extends beyond the grid's coverage, reconstruction quality will degrade.
*   **Degenerate Input:** If the input point cloud is sparse or noisy, the encoder may produce poor latent representations. Preprocessing (e.g., downsampling, noise reduction) may be necessary [S1, unofficial].

## Subtopics
#### Gaussian VAE
A Variational Auto-encoder that compresses the Gaussian Splatting Functions into a regularized latent space, mapping functions of each shape into one latent vector [S2]. It uses an Encoder and Decoder with a Triplane representation [S2]. This variant is part of the DiffGS framework, which also includes a conditional latent diffusion model (LDM) for generating novel 3DGS shapes [S2]. It is chosen when the goal is to generate diverse 3DGS shapes conditionally or unconditionally, rather than just initializing a single scene [S2].

## Operating characteristics
*   **Time Complexity:** Encoding and decoding are dominated by the neural network forward passes. The Chamfer loss computation is $O(N^2)$ for naive implementation, but can be optimized with approximate nearest neighbor search.
*   **Memory Complexity:** Depends on the latent dimension (`embedding_dim`) and grid size (`grid_dim`). For default values (32, 24), memory usage is relatively low.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Compact latent representation; data-driven initialization improves quality over random placement; flexible to different shapes.
*   **Limitations:** Requires training data; inference time includes neural network evaluation; may struggle with very high-frequency details if the latent space is too small.
*   **When to use:** When initializing 3D Gaussian Splatting for scenes with known geometric priors or when generating novel shapes via diffusion models.
*   **When not to use:** For real-time rendering where inference latency is critical and pre-computed Gaussians are available; for scenes with no prior geometric information.

## Background
SF-VAE was introduced in the context of 3D Gaussian Splatting initialization and generative modeling. The method is described in the unofficial source [S1, unofficial] as part of the `gs-embedding` project. The Gaussian VAE variant is part of the DiffGS framework, described in [S2]. These methods aim to improve the quality and efficiency of 3D Gaussian Splatting by leveraging learned priors.
