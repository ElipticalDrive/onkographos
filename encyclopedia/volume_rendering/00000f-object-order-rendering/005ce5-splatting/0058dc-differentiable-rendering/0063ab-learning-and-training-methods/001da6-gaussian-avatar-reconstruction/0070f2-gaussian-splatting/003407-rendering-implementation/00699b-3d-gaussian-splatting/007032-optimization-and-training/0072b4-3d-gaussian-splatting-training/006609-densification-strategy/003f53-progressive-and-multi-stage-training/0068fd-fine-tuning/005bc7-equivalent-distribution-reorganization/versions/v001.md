# Equivalent Distribution Reorganization

Also called: ReorgGS

## Overview
Equivalent Distribution Reorganization (ReorgGS) is a post-training reorganization method for converged 3D Gaussian Splatting (3DGS) models that addresses "parameterization degeneration," a failure mode where high-opacity floaters attenuate gradients to true surfaces and redundant overlapping clusters create strongly coupled parameter blocks [S1, unofficial]. Unlike standard opacity reset, which only rescales opacity on the old overlap graph, ReorgGS rebuilds centers, covariances, and the visibility structure by resampling from the empirical distribution, thereby changing the graph itself [S1, unofficial]. It preserves the original scene support asymptotically while reducing parameter coupling and opacity barriers, delivering up to 0.5 dB higher training PSNR and a 12.8% rendering speedup in representative settings [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A converged 3DGS model $G = \{g_i\}_{i=1}^N$ with parameters $\{\mu_i, \Sigma_i, \alpha_i, C_i\}_{i=1}^N$ that has reached the middle-to-late stage of training, converged, or entered a plateau [S1, unofficial].
*   **Output:** A new Gaussian set $G' = \{g'_j\}_{j=1}^M$ with parameters $\{\mu'_j, \Sigma'_j, \alpha'_j, C'_j\}_{j=1}^M$, where $M=N$ [S1, unofficial]. The induced field $q(x) = \sum_{j=1}^M \alpha'_j \mathcal{N}(x | \mu'_j, \Sigma'_j)$ approximately preserves the support of the original empirical distribution $P(x)$ [S1, unofficial].

**Data Structures**
*   **Original Gaussians:** Stored as a list of $N$ primitives. Each primitive $i$ contains:
    *   $\mu_i \in \mathbb{R}^3$: Center coordinates.
    *   $\Sigma_i \in \mathbb{R}^{3 \times 3}$: Covariance matrix (parameterized as $R_i S_i S_i^T R_i^T$ in standard 3DGS, where $R_i$ is rotation and $S_i$ is scale).
    *   $\alpha_i \in [0, 1]$: Opacity.
    *   $C_i$: Appearance parameters (e.g., spherical harmonics coefficients).
*   **New Gaussians:** Same structure as input, but with reorganized parameters.

**Parameters**
*   $\alpha_0$: Initial opacity for all new primitives. Default value: $0.01$ [S1, unofficial].
*   $k$: Number of nearest neighbors used for covariance estimation. Default value: Not explicitly stated as a single integer in the primary text, but the notation implies $k$ is the count. Ablation mentions $k=3$ as an altered scale, implying $k$ is a tunable parameter. The method uses $k$ nearest neighbors [S1, unofficial].

**Steps**
1.  **GMM Modeling:** View the current Gaussian set as an empirical Gaussian-mixture field defined as $P(x) \approx \sum_{i=1}^N \alpha_i \mathcal{N}(x | \mu_i, \Sigma_i)$. Define its normalized form as $\hat{p}(x) = P(x) / Z$, where $Z = \int P(x)dx$. In implementation, the continuous integral $Z$ does not need to be computed explicitly; sampling only requires the discrete mixture weights [S1, unofficial].
2.  **Categorical Sampling:** Sample a latent variable $z_j \in \{1, \dots, N\}$ from a categorical distribution $P(z_j = k) = \frac{\alpha_k}{\sum_{l=1}^N \alpha_l}$. Use only opacity $\alpha_k$ as the categorical weight and do not multiply it by the Gaussian volume. This ignores volume to reduce sampling bias towards abnormally large Gaussians that correspond to blurred regions or artifacts [S1, unofficial].
3.  **Gaussian Coordinate Sampling:** After choosing category $z_j = k$, sample a new center from the corresponding 3D Gaussian $x_j \sim \mathcal{N}(\mu_k, \Sigma_k)$. In practice, use the reparameterized form $x_j = \mu_k + L_k \epsilon$, where $\epsilon \sim \mathcal{N}(0, I)$ and $L_k$ is the Cholesky factor of $\Sigma_k$. Alternatively, since 3DGS parameterizes $\Sigma_k = R_k S_k S_k^T R_k^T$, use $R_k S_k$ as the sampling transform [S1, unofficial].
4.  **Anisotropic Initialization:** Perform a $k$-Nearest Neighbors (kNN) query for each sampled point $x_j$ within the new point set $\{x_j\}_{j=1}^M$ to obtain its $k$ nearest neighbors $\{x_{j1}, \dots, x_{jk}\}$. Estimate the new covariance $\Sigma'_j$ using the local second moment:
    $$ \Sigma'_j = \frac{1}{k} \sum_{l=1}^k (x_{jl} - x_j)(x_{jl} - x_j)^T $$
    [S1, unofficial].
5.  **Constructing the Reorganized Distribution:** Set the new mean $\mu'_j = x_j$. Set the new opacity $\alpha'_j = \alpha_0$, where $\alpha_0$ is a small opacity value (default $0.01$). The spatial scale is determined by $\Sigma'_j$. Inherit the appearance parameter $C'_j$ from the nearest old Gaussian: $NN(x_j) = \arg \min_i \|x_j - \mu_i\|^2$, $C'_j = C_{NN(x_j)}$ [S1, unofficial].
6.  **Recovering Scale and Rotation:** Perform eigendecomposition on the estimated covariance: $\Sigma'_j = U_j \Lambda_j U_j^T$. Set the new rotation $R'_j = U_j$ and the new scale $S'_j = \Lambda_j$ (diagonal matrix of eigenvalues), such that $\Sigma'_j = R'_j S'_j (S'_j)^T (R'_j)^T$. Reinitialize the optimizer state for the new parameters [S1, unofficial].

**Pseudocode**
```python
import numpy as np

def reorg_gs(gaussians, alpha_0=0.01, k=4):
    """
    Reorganizes a converged 3D Gaussian Splatting model.
    
    Args:
        gaussians: List of dicts or objects with fields:
            mu: (3,) array, center
            R: (3,3) array, rotation matrix
            S: (3,) array, scale
            alpha: float, opacity
            C: appearance parameters
        alpha_0: float, initial opacity for new Gaussians
        k: int, number of nearest neighbors for covariance estimation
        
    Returns:
        new_gaussians: List of dicts with reorganized parameters
    """
    N = len(gaussians)
    new_gaussians = []
    
    # Step 1 & 2: Categorical Sampling based on opacity
    # Normalize opacities to form a probability distribution
    alphas = np.array([g['alpha'] for g in gaussians])
    probs = alphas / np.sum(alphas)
    
    # Sample N indices from the categorical distribution
    # We resample exactly N points to maintain capacity M=N
    selected_indices = np.random.choice(N, size=N, p=probs)
    
    # Step 3: Gaussian Coordinate Sampling
    sampled_centers = []
    for idx in selected_indices:
        g = gaussians[idx]
        mu_k = g['mu']
        # Sigma_k = R_k @ diag(S_k**2) @ R_k.T
        # For sampling x ~ N(mu, Sigma), we can use Cholesky or R*S
        # Using R*S transform as suggested in source
        # S_k is scale, so standard deviation is S_k. 
        # Sigma = R * S^2 * R^T. Cholesky of Sigma is R * S (if S is diagonal sqrt of variances)
        # In 3DGS, S is usually the scale factors (std devs).
        # So L = R @ diag(S)
        L_k = g['R'] * g['S'][np.newaxis, :] # Broadcasting: R * S_i for each column
        
        epsilon = np.random.normal(0, 1, 3)
        x_j = mu_k + L_k @ epsilon
        sampled_centers.append(x_j)
        
    sampled_centers = np.array(sampled_centers) # Shape (N, 3)
    
    # Step 4: Anisotropic Initialization (kNN Covariance)
    # Compute kNN for each sampled point within the NEW point set
    # Note: This requires a kNN data structure on sampled_centers
    # Assuming a function get_knn_indices(points, k) returns indices of k nearest neighbors
    # for each point in points.
    knn_indices = get_knn_indices(sampled_centers, k) # Shape (N, k)
    
    new_covariances = []
    for j in range(N):
        x_j = sampled_centers[j]
        neighbors = sampled_centers[knn_indices[j]] # Shape (k, 3)
        
        # Estimate covariance using local second moment
        # Sigma' = (1/k) * sum (x_nl - x_j)(x_nl - x_j)^T
        diffs = neighbors - x_j # Shape (k, 3)
        # Outer product for each neighbor and sum
        cov = np.zeros((3, 3))
        for l in range(k):
            diff = diffs[l]
            cov += np.outer(diff, diff)
        cov /= k
        
        new_covariances.append(cov)
        
    # Step 5 & 6: Construct new Gaussians
    for j in range(N):
        x_j = sampled_centers[j]
        cov_j = new_covariances[j]
        
        # Eigendecomposition to get R' and S'
        # Sigma = U @ Lambda @ U^T
        # R' = U, S' = diag(sqrt(Lambda)) ? 
        # Source says: S'_j = Lambda (diagonal matrix of eigenvalues)
        # But standard 3DGS parameterization is Sigma = R S S^T R^T
        # If S is diagonal matrix of scales, then S S^T = diag(s^2) = Lambda
        # So S = sqrt(diag(Lambda))
        # However, source explicitly says: "set R'_j = U_j and S'_j = Lambda_j"
        # This implies S'_j in the source context might be the squared scale or 
        # the parameterization is Sigma = R S R^T where S is diagonal of variances.
        # Standard 3DGS uses S as scale (std dev). 
        # Let's follow the source's explicit instruction: S'_j = Lambda_j (diagonal matrix of eigenvalues).
        # This means the 'S' parameter in the output Gaussian object represents the variance spectrum, 
        # or the source assumes a specific parameterization where S is squared scale.
        # Given "Sj' = Lambda_j (diagonal matrix of eigenvalues)", we assign eigenvalues to S.
        
        eigenvalues, eigenvectors = np.linalg.eigh(cov_j)
        U_j = eigenvectors
        Lambda_j = np.diag(eigenvalues)
        
        R_prime = U_j
        # If S is scale, S = sqrt(eigenvalues). If S is variance, S = eigenvalues.
        # Source: "Sj' = Lambda_j". We will store eigenvalues as S.
        S_prime = eigenvalues 
        
        # Inherit appearance from nearest OLD Gaussian
        # NN(x_j) = arg min_i ||x_j - mu_i||^2
        dists = np.linalg.norm(sampled_centers[:, np.newaxis, :] - np.array([g['mu'] for g in gaussians]), axis=2)
        nearest_old_idx = np.argmin(dists, axis=1)[j]
        C_prime = gaussians[nearest_old_idx]['C']
        
        new_gaussians.append({
            'mu': x_j,
            'R': R_prime,
            'S': S_prime, # Storing eigenvalues as per source instruction
            'alpha': alpha_0,
            'C': C_prime
        })
        
    return new_gaussians

def get_knn_indices(points, k):
    """
    Simple O(N^2) kNN for clarity. In practice, use efficient GPU kNN.
    Returns indices of k nearest neighbors for each point.
    """
    N = points.shape[0]
    dists = np.linalg.norm(points[:, np.newaxis, :] - points[np.newaxis, :, :], axis=2)
    # Set diagonal to infinity to exclude self
    np.fill_diagonal(dists, np.inf)
    # Get indices of k smallest distances
    indices = np.argpartition(dists, k, axis=1)[:, :k]
    return indices
```

**Edge Cases and Pitfalls**
*   **Abnormally Large Gaussians:** Degenerate 3DGS optimization can produce abnormally large Gaussians corresponding to blurred regions or artifacts. Volume-weighted sampling would amplify these large-scale abnormal structures. This is handled by ignoring volume in the categorical probability calculation, using only opacity $\alpha_k$ [S1, unofficial].
*   **Opacity Barriers:** High-opacity floaters in degenerate distributions can create an opacity barrier where $T_{gp}(r) \to 0$, cutting off optimization paths to surfaces behind them. ReorgGS mitigates this by reducing accumulated foreground opacity $A_{qd}(r)$ [S1, unofficial].
*   **Precision:** The kNN covariance estimation relies on the local density of sampled points. If $M$ is small or $k$ is too small, the covariance estimate may be noisy. The source assumes $k \to \infty$ and $k/M \to 0$ for asymptotic consistency [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The core algorithmic module (resampling and covariance re-estimation) takes only a few seconds for millions of Gaussians, leveraging efficient GPU kNN implementations [S1, unofficial]. However, as a post-training method, it adds approximately 5 minutes per stage for the LiteGS architecture on an NVIDIA A100 GPU due to subsequent gradient descent steps [S1, unofficial].
*   **Memory Complexity:** The method maintains the same number of Gaussians ($M=N$), so memory usage is comparable to the baseline model [S1, unofficial].
*   **Performance:** ReorgGS delivers up to 0.5 dB higher training PSNR and 0.14 dB higher test PSNR over direct continuation [S1, unofficial]. It also provides up to 12.8% rendering speedup (e.g., from 10.75s to 9.37s on LiteGS/A100) due to reduced redundant alpha compositing [S1, unofficial].
*   **Strengths:** Improves gradient accessibility, reduces parameter coupling, suppresses persistent floaters, and reduces rendering redundancy without changing the renderer or increasing capacity [S1, unofficial].
*   **Limitations:** It is a post-training intervention, requiring a halt in optimization. It does not address the root cause of degeneration during training but mitigates its effects. The improvement is larger under reduced Gaussian budgets where each Gaussian carries more representational pressure [S1, unofficial].

## Background
ReorgGS was proposed to address "parameterization degeneration," a late-stage bottleneck in 3D Gaussian Splatting where converged models retain floaters, redundant overlap, and poor gradient accessibility [S1, unofficial]. The method treats distributional equivalence as distinct from optimization equivalence, arguing that reorganizing the parameterization (opacity-density allocation, local overlap, alpha-compositing transmittance, and covariance alignment) is necessary to break fitting ceilings [S1, unofficial]. It is evaluated on vanilla 3DGS, GOF, Taming-3DGS, 3DGS-MCMC, and LiteGS backbones across Mip-NeRF 360, Blender, and Tanks&Temples datasets [S1, unofficial].
