# Mesh-Embedded Gaussian Initialization and Deformation

Also called: Gaussian Embedding, Triangle Embedding

## Overview
This method anchors 3D Gaussians to a triangle mesh using barycentric coordinates and normal displacement, enabling deformation tracking through mesh topology rather than direct vertex positions [S1, unofficial]. It solves the problem of Gaussians drifting off-mesh or piling up at triangle edges during optimization and animation by defining a local triangle space [S1, unofficial]. Unlike methods relying on precise mesh accuracy, it ensures robust results even with inaccurate meshes by binding Gaussians to the surface .

## How it works
**Inputs:** Canonical triangle mesh (vertices $V$, normals $n$, indices), initial Gaussian count (e.g., 10,000).
**Outputs:** Set of Gaussians defined by embedding $E_i = \{k, u, v, d\}$ and canonical parameters $\bar{q}, \bar{s}$.

**Data Structures:**
*   **Mesh:** Array of vertices $V_i \in \mathbb{R}^3$, normals $n_i \in \mathbb{R}^3$, and triangles $T_k = (V_1, V_2, V_3)$.
*   **Embedding:** For each Gaussian $i$, store triangle index $k$, barycentric coordinates $(u, v)$, and normal displacement $d$.
*   **Per-Vertex Quaternions:** $q_V$ for each mesh vertex, computed via area-weighted average of surrounding neighbor triangles [S1, unofficial].

**Steps:**

1.  **Initialization:**
    *   Randomly select 10,000 pairs of triangle indices $k$ and barycentric coordinates $(u, v)$ on the canonical mesh [S1, unofficial].
    *   Initialize normal displacement $d = 0$ for all Gaussians [S1, unofficial].
    *   Compute per-vertex quaternions $q_V$ for the mesh vertices using area-weighted averaging from surrounding triangles [S1, unofficial].

2.  **Canonical Position and Normal:**
    *   Calculate the canonical position $P$ and normal $n$ on triangle $k$ using Phong interpolation [S1, unofficial]:
        $$ P = \mathcal{V}(k, u, v) = u V_1 + v V_2 + (1 - u - v) V_3 $$
        $$ n = \mathcal{N}(k, u, v) = u n_1 + v n_2 + (1 - u - v) n_3 $$
    *   The canonical mean $\mu_{cano}$ is displaced along the normal:
        $$ \mu_{cano} = P + d \cdot n $$

3.  **Deformation (Posed State):**
    *   For a posed frame $t$, compute the rotation matrix $R_k$ from the triangle's tangent, bitangent, and normal to track rotation from canonical to pose [S1, unofficial]. Convert to quaternion.
    *   Compute the barycentric interpolated rotation $\delta q_{i,t}$ using per-vertex quaternions $q_1, q_2, q_3$ of the triangle vertices:
        $$ \delta q_{i,t} = u q_1 + v q_2 + (1 - u - v) q_3 $$
    *   The posed rotation $q_{pose}$ combines the interpolated rotation with the canonical Gaussian rotation $\bar{q}$:
        $$ q_{pose} = \delta q_{i,t} * \bar{q} $$
    *   The posed scale $s_{pose}$ is derived from the area change of the embedded triangle:
        $$ s_{pose} = \left( \frac{A_{pose}}{A_{cano}} \right) \bar{s} $$
        where $A_{pose}$ and $A_{cano}$ are the areas of the triangle in the posed and canonical states, respectively [S1, unofficial].

4.  **Boundary Handling:**
    *   If optimization moves the embedding point across a triangle boundary ($u < 0$, $v < 0$, or $u+v > 1$), re-express the embedding in the neighboring triangle to maintain differentiability [S1, unofficial]. Failure to do so causes Gaussians to stick to boundaries and pile up [S1, unofficial].

**Parameters:**
*   **Color:** Spherical harmonics are turned off for simplicity [S1, unofficial].
*   **Initialization Count:** 10,000 Gaussians [S1, unofficial].

**Pseudocode:**
```python
def initialize_gaussians(mesh, num_gaussians=10000):
    # mesh: object with vertices, normals, triangles
    # Returns list of embeddings and canonical params
    
    gaussians = []
    for i in range(num_gaussians):
        # Step 1: Random selection
        k = random_triangle_index(mesh)
        u, v = random_barycentric_coords()
        d = 0.0
        
        # Get vertices and normals for triangle k
        V1, V2, V3 = mesh.vertices[k]
        n1, n2, n3 = mesh.normals[k]
        
        # Step 2: Canonical Position
        P = u * V1 + v * V2 + (1 - u - v) * V3
        n = u * n1 + v * n2 + (1 - u - v) * n3
        mu_cano = P + d * n
        
        # Canonical rotation and scale (initialized randomly or from mesh)
        q_cano = identity_quaternion() # [G]
        s_cano = 1.0 # [G]
        
        gaussians.append({
            'k': k, 'u': u, 'v': v, 'd': d,
            'mu_cano': mu_cano,
            'q_cano': q_cano,
            's_cano': s_cano
        })
    return gaussians

def deform_gaussian(gaussian, mesh, frame_t):
    # Step 3: Deformation
    k = gaussian['k']
    u = gaussian['u']
    v = gaussian['v']
    
    # Get posed vertices and normals
    V1_p, V2_p, V3_p = mesh.get_posed_vertices(k, frame_t)
    n1_p, n2_p, n3_p = mesh.get_posed_normals(k, frame_t)
    
    # Interpolate rotation
    q1, q2, q3 = mesh.get_posed_vertex_quaternions(k, frame_t)
    delta_q = u * q1 + v * q2 + (1 - u - v) * q3
    
    q_pose = delta_q * gaussian['q_cano']
    
    # Compute scale from area change
    A_cano = triangle_area(V1, V2, V3) # From canonical vertices
    A_pose = triangle_area(V1_p, V2_p, V3_p)
    s_pose = (A_pose / A_cano) * gaussian['s_cano']
    
    return q_pose, s_pose
```

## Subtopics

### [Walking on Triangle](9700-walking-on-triangle.md)
A constraint mechanism that binds Gaussians to triangle boundaries, ensuring they remain within their corresponding triangles during optimization and deformation. It prevents drifting and piling up, offering robustness even with inaccurate meshes.

## Operating characteristics
*   **Complexity:** Linear in the number of Gaussians for initialization and deformation. Triangle lookup and barycentric interpolation are constant time per Gaussian.
*   **Strengths:** Enables efficient deformation tracking via mesh topology; avoids the need to optimize per-vertex positions for every Gaussian [S1, unofficial].
*   **Limitations:** Requires handling boundary crossings to maintain differentiability; performance depends on mesh quality and triangle distribution [S1, unofficial].
*   **When to use:** When animating or deforming a mesh-based avatar or object and wanting to maintain surface consistency [S1, unofficial].

## Background
Originated in SplattingAvatar, which introduced Gaussian embeddings on triangle meshes for dynamic human avatars [S1, unofficial]. It builds on Phong interpolation for surface definition and quaternion averaging for rotation [S1, unofficial].
