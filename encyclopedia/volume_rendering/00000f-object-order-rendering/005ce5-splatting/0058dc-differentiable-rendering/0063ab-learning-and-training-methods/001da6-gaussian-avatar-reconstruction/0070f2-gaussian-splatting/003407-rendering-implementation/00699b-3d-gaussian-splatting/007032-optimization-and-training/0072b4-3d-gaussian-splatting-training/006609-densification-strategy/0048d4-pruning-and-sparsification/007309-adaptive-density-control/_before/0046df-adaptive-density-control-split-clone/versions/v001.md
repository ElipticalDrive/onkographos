# Adaptive Density Control (Split & Clone)

Also called: Clone

## Overview
Adaptive Density Control (Split & Clone) is a densification strategy for 3D Gaussian Splatting that adjusts Gaussian density by either splitting large Gaussians into smaller children or cloning (duplicating) small Gaussians to match local scene complexity [S2, unofficial]. It distinguishes itself from pure-split methods by retaining the clone operation to preserve thin structures, though recent variants argue for dropping clones to avoid opacity bias and floater artifacts [S1, unofficial].

## How it works
**Inputs:**
- Set of visible Gaussians $\mathcal{G}$ from the previous optimization interval.
- Per-Gaussian accumulated view-space positional gradient magnitudes $\|\nabla_{\mu_{2D}} \mathcal{L}\|$.
- Scene extent $E$ (bounding box or point cloud bounds).
- Thresholds: gradient threshold $T_{grad}$, opacity threshold $T_{opacity}$, size thresholds for "large" and "small" relative to $E$.

**Outputs:**
- Updated set of Gaussians $\mathcal{G}'$ with modified positions, scales, opacities, and counts.

**Data Structures:**
- Gaussian $g_k$: position $\mu_k$, scale $\sigma_k$ (3D covariance matrix or diagonal), opacity $\alpha_k$, spherical harmonics coefficients.
- Gradient accumulator $G_k$: scalar, sum of $\|\nabla_{\mu_{2D}} \mathcal{L}\|$ since last densification step.
- Visibility counter $V_k$: scalar, number of views the Gaussian contributed to since last densification step.

**Steps:**
1. **Warm-up:** Skip densification for the first $T_{warmup}$ iterations [S1, unofficial].
2. **Gradient Accumulation:** For each visible Gaussian $g_k$, accumulate $\|\nabla_{\mu_{2D}} \mathcal{L}\|$ into $G_k$ and increment $V_k$ [S1, unofficial].
3. **Selection:** Compute average gradient $\bar{g}_k = G_k / V_k$. If $\bar{g}_k < T_{grad}$, skip $g_k$. Otherwise, mark $g_k$ for densification.
4. **Classification:** Determine if $g_k$ is "large" or "small" relative to scene extent $E$.
   - If $g_k$ is large (Over-Reconstruction): proceed to Split.
   - If $g_k$ is small (Under-Reconstruction): proceed to Clone [S2, unofficial].
5. **Clone Operation:**
   - Duplicate $g_k$ to create $g_{new}$.
   - Set $g_{new}.\mu = g_k.\mu$.
   - Set $g_{new}.\sigma = g_k.\sigma$.
   - Set $g_{new}.\alpha = g_k.\alpha / \sqrt{2}$ (or 2) to prevent opacity sum > 1 [S1, unofficial].
   - Remove $g_k$ from $\mathcal{G}$ and add $g_{new}$ to $\mathcal{G}'$.
6. **Split Operation:**
   - Sample two child positions $\mu_{c1}, \mu_{c2}$ from the parent's Gaussian distribution $\mathcal{N}(\mu_k, \Sigma_k)$ [S1, unofficial].
   - Set child scales $\sigma_{c1} = \sigma_{c2} = \sigma_k / \sqrt{2}$ (or similar downsampling factor).
   - Set child opacities $\alpha_{c1} = \alpha_{c2} = \alpha_k / 2$ (or $\alpha_k / \sqrt{2}$) [S1, unofficial].
   - Remove $g_k$ from $\mathcal{G}$ and add $g_{c1}, g_{c2}$ to $\mathcal{G}'$.
7. **Pruning:**
   - Remove any Gaussian $g_j$ where $\alpha_j < T_{opacity}$ (default 0.005) [S1, unofficial].
   - Optionally remove Gaussians with screen-space radius or world-space scale exceeding fixed thresholds [S1, unofficial].
   - Optional: Reset opacities to near zero (0.01) every 3000 iterations to clear floaters [S1, unofficial].

**Pseudocode:**
```python
def adaptive_density_control_split_clone(Gaussians, gradients, scene_extent, T_grad, T_opacity, T_warmup, iteration):
    if iteration < T_warmup:
        return Gaussians
    
    # Reset accumulators for new interval
    for g in Gaussians:
        g.G_k = 0.0
        g.V_k = 0
    
    # Accumulate gradients
    for g in Gaussians:
        if g.visible:
            g.G_k += gradients[g.id]
            g.V_k += 1
    
    to_densify = []
    for g in Gaussians:
        if g.V_k > 0:
            avg_grad = g.G_k / g.V_k
            if avg_grad > T_grad:
                to_densify.append(g)
    
    new_gaussians = []
    for g in to_densify:
        is_large = is_large_relative_to_scene(g, scene_extent)
        
        if is_large:
            # Split
            mu_c1, mu_c2 = sample_from_gaussian_distribution(g.mu, g.sigma, 2)
            alpha_child = g.alpha / 2.0
            sigma_child = g.sigma / sqrt(2.0)
            
            new_gaussians.append(Gaussian(mu_c1, sigma_child, alpha_child))
            new_gaussians.append(Gaussian(mu_c2, sigma_child, alpha_child))
        else:
            # Clone
            alpha_child = g.alpha / sqrt(2.0)
            new_gaussians.append(Gaussian(g.mu, g.sigma, alpha_child))
    
    # Pruning
    final_gaussians = []
    for g in new_gaussians:
        if g.alpha >= T_opacity:
            final_gaussians.append(g)
    
    return final_gaussians

def is_large_relative_to_scene(g, scene_extent):
    # Not given in the sources. Typically compares g.scale to scene_extent dimensions.
    return g.scale > scene_extent * threshold_factor
```

**Parameters:**
- $T_{grad}$: Gradient threshold. Not given in the sources.
- $T_{opacity}$: Opacity threshold. Default 0.005 [S1, unofficial].
- $T_{warmup}$: Warm-up iterations. Not given in the sources.
- Opacity division factor: $\sqrt{2}$ or 2 [S1, unofficial].

**Edge Cases:**
- Cloning can introduce opacity bias and cause large floater clusters if scene extent is not well matched to detail size [S1, unofficial].
- Removing clone operation primarily breaks thin structures (e.g., bicycle spokes) [S2, unofficial].
- Removing split operation primarily degrades background quality, causing blurry regions [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ per densification step, where $N$ is the number of Gaussians. Gradient accumulation is $O(N)$ per iteration.
- **Memory Complexity:** Increases with densification. Cloning doubles the count of selected Gaussians; splitting triples it (1 removed, 2 added). Pruning reduces count.
- **Measured Performance:** On Average-30K dataset, Full method achieves PSNR 26.05. No-Split drops to 23.90. No-Clone drops to 25.91 [S2, unofficial].
- **Strengths:** Clone operation preserves thin structures [S2, unofficial]. Split operation handles large regions efficiently.
- **Limitations:** Cloning can cause floaters and opacity bias [S1, unofficial]. Requires careful tuning of scene extent thresholds.
- **When to use:** When thin structures are important and scene extent is well-defined.
- **When not to use:** When floaters are a major issue or scene extent is poorly defined; consider split-only variants [S1, unofficial].

## Background
Originated in 3D Gaussian Splatting [S1, unofficial]. The clone operation was later criticized for opacity bias [S1, unofficial]. Recent works like EFA-GS and Deng et al. propose dropping the clone operation entirely [S1, unofficial].
