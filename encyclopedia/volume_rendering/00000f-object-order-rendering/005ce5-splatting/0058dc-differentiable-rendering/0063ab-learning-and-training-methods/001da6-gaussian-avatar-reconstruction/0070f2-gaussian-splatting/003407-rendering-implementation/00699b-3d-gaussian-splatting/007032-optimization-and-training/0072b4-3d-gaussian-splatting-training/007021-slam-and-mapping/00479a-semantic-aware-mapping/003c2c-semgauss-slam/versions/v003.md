# SemGauss-SLAM

Also called: SGS-SLAM, NEDS-SLAM

## Overview
SemGauss-SLAM is a simultaneous localization and mapping (SLAM) method that integrates semantic information into the 3D Gaussian Splatting pipeline [S1]. It solves the problem of geometric ambiguity in SLAM by distilling 2D semantic labels into the 3D Gaussian representation [S2, unofficial]. Unlike standard 3DGS which only optimizes for photometric consistency, SemGauss-SLAM uses semantic priors to guide Gaussian initialization, splitting, and pose estimation, resulting in more semantically consistent and geometrically accurate maps [S1].

## How it works
SemGauss-SLAM extends the standard 3D Gaussian Splatting optimization by adding a semantic loss term to the objective function. The method operates on a sequence of RGB-D images and their corresponding 2D semantic segmentation masks.

**Inputs:**
- A sequence of RGB-D frames $\{I_t, D_t\}$ with known or estimated camera poses $T_t$.
- Corresponding 2D semantic segmentation masks $\{M_t\}$ for each frame, obtained from a pre-trained 2D segmentation model or dataset annotations [S2, unofficial].

**Outputs:**
- A set of 3D Gaussians $\mathcal{G}$, where each Gaussian $i$ is defined by position $\mu_i$, covariance $\Sigma_i$ (parameterized by scale $s$ and rotation $R$), opacity $\alpha_i$, spherical harmonic coefficients for color $c_i$, and a semantic feature vector or class probability distribution $s_i$ [S2, unofficial].
- Optimized camera poses $\{T_t\}$.

**Data Structures:**
- **Gaussian Attributes:** Each Gaussian stores $\mu_i \in \mathbb{R}^3$, $s_i \in \mathbb{R}^3$, $q_i \in \mathbb{R}^4$ (quaternion), $\alpha_i \in \mathbb{R}$, $c_i \in \mathbb{R}^{3 \cdot K}$ (colors), and $sem_i \in \mathbb{R}^{C}$ (semantic logits for $C$ classes) [S2, unofficial].
- **Voxel Grid:** An optimizable size-adaptive voxel grid may be used to manage Gaussian density and initialization, similar to LIVGaussMap [S1].

**Optimization Steps:**
1. **Initialization:** Initialize Gaussians using depth maps or LiDAR points. Assign initial semantic attributes based on projected 2D labels [S1].
2. **Rendering:** For each camera view, render the RGB image and the semantic feature map by splatting the 3D Gaussians onto the 2D plane [S2, unofficial]. The semantic rendering aggregates the semantic attributes of contributing Gaussians weighted by their opacity and projected area.
3. **Loss Calculation:** Compute the total loss $\mathcal{L}$:
   $$
   \mathcal{L} = \mathcal{L}_{rgb} + \lambda_{sem} \mathcal{L}_{sem} + \lambda_{scale} \mathcal{L}_{scale}
   $$
   where:
   - $\mathcal{L}_{rgb}$ is the photometric reconstruction loss (e.g., L1 or SSIM) between rendered and ground-truth RGB images [S2, unofficial].
   - $\mathcal{L}_{sem}$ is the semantic loss, typically a cross-entropy or Dice loss between the rendered semantic probabilities and the ground-truth 2D semantic mask $M_t$ [S2, unofficial].
   - $\mathcal{L}_{scale}$ is a regularization loss encouraging isotropic Gaussians [S2, unofficial].
   - $\lambda_{sem}$ and $\lambda_{scale}$ are weighting hyperparameters [S2, unofficial].
4. **Backpropagation and Update:** Compute gradients of $\mathcal{L}$ with respect to all Gaussian parameters ($\mu, s, R, \alpha, c, sem$) and camera poses $T_t$. Update parameters using an optimizer (e.g., Adam) [S2, unofficial].
5. **Adaptive Control:** Use semantic consistency to guide Gaussian splitting and pruning. Gaussians with high semantic uncertainty or low opacity may be pruned, while those in semantically distinct regions may be split [S1].

**Pseudocode:**
```python
def sem_gauss_slam_step(gaussians, camera_pose, rgb_image, depth_image, semantic_mask, lambda_sem, lambda_scale):
    # 1. Render RGB and Semantic features
    rendered_rgb, rendered_sem_probs = render_gaussians(gaussians, camera_pose)
    
    # 2. Compute Photometric Loss
    loss_rgb = l1_loss(rendered_rgb, rgb_image)
    
    # 3. Compute Semantic Loss
    # rendered_sem_probs: [H, W, C], semantic_mask: [H, W] (class indices)
    loss_sem = cross_entropy_loss(rendered_sem_probs, semantic_mask)
    
    # 4. Compute Scale Regularization
    loss_scale = isotropic_regularization(gaussians.scales)
    
    # 5. Total Loss
    total_loss = loss_rgb + lambda_sem * loss_sem + lambda_scale * loss_scale
    
    # 6. Backpropagate
    total_loss.backward()
    
    # 7. Update Gaussians and Camera Pose
    optimizer.step()
    
    # 8. Adaptive Control (Simplified)
    if needs_splitting(gaussians, semantic_mask):
        gaussians = split_gaussians(gaussians, semantic_mask)
    if needs_pruning(gaussians):
        gaussians = prune_gaussians(gaussians)
        
    return gaussians, camera_pose
```

## Operating characteristics
- **Time Complexity:** Similar to 3DGS per iteration, but with additional overhead for semantic rendering and loss computation. Semantic rendering requires aggregating semantic attributes, which is lightweight compared to color SH evaluation.
- **Memory Complexity:** Increased by storing semantic attributes ($C$ dimensions) per Gaussian.
- **Strengths:** Improves geometric accuracy in textureless or repetitive regions by leveraging semantic priors. Enhances map consistency for downstream tasks like navigation and relocalization [S1].
- **Limitations:** Relies on the quality of 2D semantic segmentation. Errors in 2D labels can propagate to 3D. Computationally more expensive than non-semantic SLAM.

## Background
SemGauss-SLAM (also referred to as SGS-SLAM or NEDS-SLAM in literature) was introduced as part of the recent advances in 3D Gaussian Splatting for SLAM [S1]. It builds upon the foundation of 3DGS [S2, unofficial] and integrates semantic information to address limitations in pure geometric reconstruction. The method is cited alongside LIVGaussMap and CG-SLAM as a state-of-the-art approach for semantic-aware mapping [S1].
