# 2D Gaussian Splatting Rasterization

Also called: 2D Gaussian Splatting Surfel Rasterization, 2D-GS, Gaussian Surfel Splatting, Gaussian Surfels (2DGS), standard 2DGS

## Overview
This method renders a scene represented by 2D Gaussian primitives (surfels) into RGB, alpha, and normal maps using a custom rasterizer [S3, unofficial]. It differs from standard 3D Gaussian Splatting by operating on surfels projected into screen space, accumulating color and geometric attributes via front-to-back alpha compositing [S5]. It serves as the Tier-1 NumPy reference implementation for 2D Gaussian Splatting, performing ray-surfel intersection per pixel using the projection matrix [S3, unofficial].

## How it works
**Inputs:**
- `means`: 3D positions of $N$ surfels, shape $[N, 3]$ [S3, unofficial].
- `quats`: Unit quaternions $(w, x, y, z)$ defining orientation, shape $[N, 4]$ [S3, unofficial].
- `scales`: Local scaling factors, shape $[N, 3]$ [S3, unofficial].
- `opacities`: Per-surfel opacity values, shape $[N]$ [S3, unofficial].
- `colors`: Per-surfel colors, shape $[N, D]$ (where $D$ is color channels, typically 3) or spherical harmonic coefficients if `sh_degree` is provided [S3, unofficial].
- `viewmats`: Camera-to-world transformation matrices, shape $[C, 4, 4]$ (where $C$ is number of cameras) [S3, unofficial].
- `Ks`: Camera intrinsic matrices, shape $[C, 3, 3]$ [S3, unofficial].
- `width`, `height`: Image dimensions [S3, unofficial].
- `tile_size`: Integer, default 16. Side length of tiles for rasterization [S3, unofficial].
- `near_plane`: Float, default 0.01. Near clipping plane distance [S3, unofficial].
- `far_plane`: Float, default 1e10. Far clipping plane distance [S3, unofficial].
- `sh_degree`: Integer or None. If not None, spherical harmonics are evaluated; otherwise, direct colors are used [S3, unofficial].
- `backgrounds`: Background color for each camera, shape $[C, 3]$ [S3, unofficial].
- `campos`: Camera positions, shape $[C, 3]$, derived from `viewmats` [S3, unofficial].

**Outputs:**
- `render_colors`: Shape $[C, H, W, 3]$ [S3, unofficial].
- `render_alphas`: Shape $[C, H, W, 1]$ [S3, unofficial].
- `render_normals`: Shape $[C, H, W, 3]$ [S3, unofficial].

**Data Structures:**
- `means2d`: Projected 2D centers, shape $[C, N, 2]$, 8 B [S2, unofficial].
- `ray_transforms`: 3×3 affine matrix mapping pixel-space UV to splat coordinates, shape $[C, N, 3, 3]$, 36 B [S2, unofficial].
- `opacities`: Alpha transparency value, shape $[C, N]$, 4 B [S2, unofficial].
- `colors`: RGB color, shape $[C, N, 3]$, 12 B [S2, unofficial].
- `radii`: Maximum projected radius in pixels for culling/LOD, shape $[C, N]$, 4 B [S2, unofficial].
- `depths`: Z-depth of the Gaussian center for depth sorting, shape $[C, N]$, 4 B [S2, unofficial].
- `normals`: Surface normal in camera space for lighting/back-face culling, shape $[C, N, 3]$, 12 B [S2, unofficial].
- `isect_offsets`: Encoded intersection offsets for tile-based processing, shape $[C, \text{tile\_height}, \text{tile\_width}]$ [S3, unofficial].
- `flatten_ids`: Flattened indices of surfels intersecting tiles, shape $[C, \text{num\_intersecting}]$ [S3, unofficial].

**Steps:**

1. **Projection:** Project 2D Gaussian surfels to 2D screen space using `fully_fused_projection_2dgs`, passing `means`, `quats`, `scales`, `viewmats`, `Ks`, `width`, `height`, `near_plane`, and `far_plane` [S3, unofficial]. It outputs `radii`, `means2d`, `depths`, `ray_transforms`, and `normals` [S3, unofficial].

2. **Opacity Broadcasting:** Broadcast scalar per-surfel opacities $[N]$ to per-camera $[C, N]$ using `mx.broadcast_to(mx.expand_dims(opacities, axis=0), (C, N))` [S3, unofficial].

3. **Color Evaluation:**
   - If `sh_degree` is not None: Compute view directions $\text{dirs} = \text{means}[\text{None}, :, :] - \text{campos}[:, \text{None}, :]$, normalize `dirs`, broadcast color coefficients to $[C, N, K, 3]$ (where $K$ is SH coefficient count), evaluate spherical harmonics $\text{rgb} = \text{spherical\_harmonics}(\text{sh\_degree}, \text{dirs}, \text{coeffs\_broadcast})$ to get $\text{rgb} [C, N, 3]$, and clamp with $\text{rgb} = \max(\text{rgb} + 0.5, 0.0)$ [S3, unofficial].
   - If `sh_degree` is None: Broadcast colors $[N, D]$ to $[C, N, D]$ or use colors $[C, N, D]$ directly as `colors_for_raster` [S3, unofficial].

4. **Tile Intersection:** Compute tile dimensions $\text{tile\_width} = \lceil \text{width} / \text{tile\_size} \rceil$, $\text{tile\_height} = \lceil \text{height} / \text{tile\_size} \rceil$ [S3, unofficial]. Call `isect_tiles(means2d, radii, depths, tile_size, tile_width, tile_height, sort=True)` to get `tiles_per_gauss`, `isect_ids`, and `flatten_ids` [S3, unofficial].

5. **Offset Encoding:** Encode intersection offsets using `isect_offset_encode(isect_ids, C, tile_width, tile_height)` to get `isect_offsets` $[C, \text{tile\_height}, \text{tile\_width}]$ [S3, unofficial].

6. **Rasterization:** Call `rasterize_to_pixels_2dgs` with `means2d`, `ray_transforms`, `colors_for_raster`, `normals`, `opacities_cn`, `width`, `height`, `tile_size`, `isect_offsets`, `flatten_ids`, and `backgrounds` [S3, unofficial]. This function performs the per-pixel ray-surfel intersection and accumulation [S3, unofficial].

**Per-Pixel Ray-Surfel Intersection (Inside `rasterize_to_pixels_2dgs`):**
For each surfel `gid` in depth order:
1. Compute ray-surfel intersection vectors using the projection matrix $M_g$ (from `ray_transforms`):
   $$h_u = -M_g[0, :3] + M_g[2, :3] \cdot p_x$$
   $$h_v = -M_g[1, :3] + M_g[2, :3] \cdot p_y$$
   where $p_x, p_y$ are pixel coordinates [S3, unofficial].
2. Compute cross product and guard against degenerate case:
   $$tmp = \text{cross}(h_u, h_v)$$
   If $|tmp[2]| < 10^{-10}$, skip this intersection [S3, unofficial].
3. Compute intersection coordinates:
   $$u_s = tmp[0] / tmp[2]$$
   $$v_s = tmp[1] / tmp[2]$$
4. Compute 3D sigma from intersection:
   $$\sigma_{3d} = u_s^2 + v_s^2$$
5. Compute 2D fallback sigma from distance to center:
   $$\sigma_{2d} = 2.0 \cdot (dx^2 + dy^2)$$
   where $dx, dy$ are distances from pixel to surfel center [S3, unofficial].
6. Take tighter bound:
   $$\sigma = 0.5 \cdot \min(\sigma_{3d}, \sigma_{2d})$$
7. Compute alpha clamped to `MAX_ALPHA`:
   $$\alpha = \min(\text{opacity} \cdot \exp(-\sigma), \text{MAX\_ALPHA})$$
   Negative sigma values are skipped to prevent invalid alpha computation [S3, unofficial].
8. Accumulate color, alpha, and normal maps via front-to-back alpha compositing [S3, unofficial]. For normals and depth, use weighted accumulation: $\{D, N\} = \sum T_i a_i w_i \{d_i, n_i\}$, where $w_i = \frac{1}{\sum T_i a_i}$ [S6].

**Pseudocode:**

```python
import numpy as np
import math

def rasterize_to_pixels_2dgs(
    means2d: np.ndarray,
    ray_transforms: np.ndarray,
    colors_for_raster: np.ndarray,
    normals: np.ndarray,
    opacities_cn: np.ndarray,
    width: int,
    height: int,
    tile_size: int,
    isect_offsets: np.ndarray,
    flatten_ids: np.ndarray,
    backgrounds: np.ndarray,
) -> tuple:
    """
    Rasterize 2D Gaussian surfels to pixels.
    Returns: (render_colors, render_alphas, render_normals)
    """
    C = means2d.shape[0]
    H, W = height, width
    tile_h = math.ceil(H / tile_size)
    tile_w = math.ceil(W / tile_size)
    
    render_colors = np.zeros((C, H, W, 3), dtype=np.float32)
    render_alphas = np.zeros((C, H, W, 1), dtype=np.float32)
    render_normals = np.zeros((C, H, W, 3), dtype=np.float32)
    
    acc_alpha = np.zeros((C, H, W, 1), dtype=np.float32)
    acc_color = np.zeros((C, H, W, 3), dtype=np.float32)
    acc_normal = np.zeros((C, H, W, 3), dtype=np.float32)
    
    for c in range(C):
        surfel_indices = flatten_ids[c]
        num_surfels = len(surfel_indices)
        
        for i in range(num_surfels):
            gid = surfel_indices[i]
            
            m2d = means2d[c, gid]
            rt = ray_transforms[c, gid]
            color = colors_for_raster[c, gid]
            normal = normals[c, gid]
            opacity = opacities_cn[c, gid]
            
            # Determine tile bounds for this surfel
            # In the reference, isect_offsets points to the start of each tile's surfel list.
            # Here we iterate over pixels covered by the surfel's bounding box for simplicity,
            # matching the reference's per-pixel intersection logic.
            radius = 2.0 # Simplified radius for bounding box; reference uses exact tile intersection
            min_x = max(0, int(m2d[0] - radius))
            max_x = min(W, int(m2d[0] + radius))
            min_y = max(0, int(m2d[1] - radius))
            max_y = min(H, int(m2d[1] + radius))
            
            for y in range(min_y, max_y):
                for x in range(min_x, max_x):
                    px = float(x)
                    py = float(y)
                    
                    h_u = -rt[0, :3] + rt[2, :3] * px
                    h_v = -rt[1, :3] + rt[2, :3] * py
                    
                    tmp = np.cross(h_u, h_v)
                    
                    if abs(tmp[2]) < 1e-10:
                        continue
                    
                    us = tmp[0] / tmp[2]
                    vs = tmp[1] / tmp[2]
                    
                    sigma_3d = us * us + vs * vs
                    dx = x - m2d[0]
                    dy = y - m2d[1]
                    sigma_2d = 2.0 * (dx * dx + dy * dy)
                    
                    sigma = 0.5 * min(sigma_3d, sigma_2d)
                    
                    if sigma < 0:
                        continue
                        
                    alpha = min(opacity * np.exp(-sigma), 1.0)
                    
                    alpha_in = acc_alpha[c, y, x, 0]
                    if alpha_in >= 1.0:
                        continue
                        
                    weight = alpha * (1.0 - alpha_in)
                    
                    acc_color[c, y, x] += color * weight
                    acc_normal[c, y, x] += normal * weight
                    acc_alpha[c, y, x, 0] += weight
                    
                    if acc_alpha[c, y, x, 0] >= 1.0:
                        break
        
        for y in range(H):
            for x in range(W):
                alpha_final = acc_alpha[c, y, x, 0]
                if alpha_final < 1.0:
                    bg = backgrounds[c]
                    render_colors[c, y, x] = acc_color[c, y, x] + bg * (1.0 - alpha_final)
                else:
                    render_colors[c, y, x] = acc_color[c, y, x]
                
                render_alphas[c, y, x, 0] = alpha_final
                render_normals[c, y, x] = acc_normal[c, y, x] / (alpha_final + 1e-8)

    return render_colors, render_alphas, render_normals
```

## Subtopics

### [Per-Primitive Texture Mapping for Reflective Gaussian Splatting](8629-per-primitive-texture-mapping-for-reflective-gaussian-splatt.md)
Enhances 2D Gaussian Splatting by replacing single attribute values per primitive with spatially varying texture maps for material properties and normals. Unlike methods that assign constant attributes to each primitive, this approach decouples geometric representation from appearance, enabling high-frequency specular reconstruction and accurate reflections in reflective scenes without increasing the primitive count. It builds on [2D Gaussian Splatting Rasterization](4815-2d-gaussian-splatting-rasterization.md) by leveraging the closed-form ray-splat intersection to map screen pixels to local texture coordinates, allowing hardware-accelerated rendering via texture atlases.

### [ToF Gaussian Rasterization Forward Pass](9261-tof-gaussian-rasterization-forward-pass.md)
This method implements the forward pass of the C++/CUDA rasterizer for Time-of-Flight Gaussian Splatting. It restructures scene and camera parameters into a single tuple, invokes the CUDA kernel, and returns rendered maps including color, phasor, depth, and auxiliary buffers.

### [Vanilla 2D Gaussian Splatting Rendering](12208-vanilla-2d-gaussian-splatting-rendering.md)
Renders a scene represented by 2D Gaussian primitives into RGB, alpha, normal, and depth maps using a custom rasterizer. It differs from standard 3D Gaussian Splatting by operating on surfels (2D Gaussians) projected into screen space, accumulating color and geometric attributes via front-to-back alpha compositing [Parent].

### [Nexels](13877-nexels.md)
Nexels is a novel view synthesis method that decouples geometry and appearance to achieve a compact representation using a fixed number of primitives per pixel. It uses surfels with a generalized Gaussian kernel for geometry and a shared neural field (Instant-NGP) for view-dependent appearance, rendered via a two-pass process to handle sparse primitives efficiently. Unlike sibling methods that couple appearance to primitives or use slower neural field lookups, Nexels textures only the top-$K$ primitives per pixel, ensuring real-time performance while matching the perceptual quality of 3D Gaussian Splatting with significantly fewer primitives.

## Operating characteristics
- **Time Complexity:** $O(N \cdot H \cdot W)$ in the naive reference implementation, where $N$ is the number of surfels and $H, W$ are image dimensions. Tile-based optimization reduces this to $O(K \cdot H \cdot W)$ where $K$ is the average number of surfels per tile.
- **Memory Complexity:** $O(N + H \cdot W)$ for storing surfel properties and output buffers.
- **Measured Performance:** Not given in the sources.
- **Strengths:** Provides a clear, differentiable (via MLX autodiff in the reference) reference implementation for 2D Gaussian Splatting. Handles multiple camera models (pinhole, fisheye, orthographic) [S3, unofficial].
- **Limitations:** The NumPy reference implementation is not differentiable and is slow for large scenes.
- **When to use:** For debugging, testing, and educational purposes.
- **When not to use:** When real-time performance is required and the optimized implementation is not available.

## Background
The method is part of the 2D Gaussian Splatting framework, which extends 3D Gaussian Splatting by using surfels (2D Gaussians) instead of 3D ellipsoids. The reference implementation is provided by the `gsplat-mlx` library [S3, unofficial].
