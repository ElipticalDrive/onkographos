# DepthSplat


## Overview
DepthSplat is a feed-forward method for 3D Gaussian Splatting reconstruction that connects Gaussian splatting and depth estimation by leveraging pre-trained monocular depth features to augment multi-view feature matching [S1]. It solves the problem of artifacts and scale ambiguities in multi-view depth prediction, particularly in occlusions, low-textured areas, and non-Lambertian surfaces, by integrating monocular cues early in the pipeline [S1]. Unlike TranSplat, which uses monocular features to refine coarse depth (vulnerable to error propagation), DepthSplat combines cost volumes and monocular features early, and unlike GS-LRM, it relies on explicit feature matching rather than heavy training data/compute [S1].

## How it works
**Inputs:** $N$ input images $\{I_i\}_{i=1}^N$, where $I_i \in \mathbb{R}^{H \times W \times 3}$, and their corresponding projection matrices $\{P_i\}_{i=1}^N$, where $P_i \in \mathbb{R}^{3 \times 4}$ (computed from intrinsic and extrinsic matrices) [S1].

**Outputs:** A set of 3D Gaussians $\{(\mu_j, \alpha_j, \Sigma_j, c_j)\}_{j=1}^{H \times W}$ for each view, where $\mu_j$ is the 3D position, $\alpha_j$ is opacity, $\Sigma_j$ is covariance, and $c_j$ is color [S1]. These are rendered to produce novel views [S1].

**Data Structures:**
*   **Cost Volume $C_i$:** A 3D tensor of size $\frac{H}{s} \times \frac{W}{s} \times D$, where $s$ is the downsampling factor and $D$ is the number of depth candidates [S1].
*   **Monocular Features:** Extracted per-view features $F_i$ using a Vision Transformer (ViT) [S1].
*   **Warped Features:** $F_{j \to i}^m$, the feature from view $j$ warped to view $i$ using depth candidate $d_m$ [S1].

**Parameters:**
*   **Downsampling factor $s$:** Controlled by the number of stride-2 $3 \times 3$ convolutions in the feature extraction. $s=4$ if two convolutions are used; $s=8$ if three are used [S1].
*   **Depth candidates $D$:** Uniformly sampled from near/far depth ranges [S1].
*   **Multi-view Transformer:** Contains six stacked self- and cross-attention layers [S1].
*   **Neighbor Selection:** For $N > 2$ views, the top-2 nearest neighboring views are selected based on camera distance to the reference view [S1].

**Steps:**
1.  **Monocular Feature Extraction:** For each view $i$, extract features $F_i$ using a pre-trained monocular depth model (ViT) [S1].
2.  **Depth Candidate Sampling:** For each view $i$, uniformly sample $D$ depth candidates $\{d_m\}_{m=1}^D$ from the near and far depth ranges [S1].
3.  **Feature Warping:** For each view $i$ and each neighboring view $j$, warp the feature $F_j$ to view $i$ using the camera projection matrix $P_i$ and each depth candidate $d_m$ to obtain warped features $\{F_{j \to i}^m\}_{m=1}^D$ [S1].
    *   *Note:* If $N > 2$, select only the top-2 nearest neighboring views for view $i$ based on camera distance [S1].
4.  **Cost Volume Construction:** Measure feature correlations via dot-product between $F_i$ and warped features $F_{j \to i}^m$ [S1]. Stack correlations to build cost volume $C_i \in \mathbb{R}^{\frac{H}{s} \times \frac{W}{s} \times D}$ [S1].
    *   If multiple neighbors are used ($N > 2$), combine correlation values from selected views with averaging [S1].
5.  **Feature Concatenation:** Concatenate the multi-view cost volumes $C_i$ with the extracted monocular features $F_i$ [S1].
6.  **Depth Regression:** Perform depth regression using a 2D U-Net architecture followed by a softmax layer to predict dense per-pixel depth $D_i$ [S1].
7.  **Unprojection:** Unproject the predicted depth maps $D_i$ to 3D space using camera parameters $P_i$ to obtain Gaussian centers $\mu_j$ [S1].
8.  **Parameter Prediction:** Predict remaining Gaussian parameters (opacity $\alpha_j$, covariance $\Sigma_j$, color $c_j$) using an additional lightweight network/head in parallel with the depth regression [S1].
9.  **Rendering:** Render novel views using the splatting operation with the predicted 3D Gaussians [S1].

**Pseudocode:**
```python
def depth_splat(images, projection_matrices):
    """
    images: List of N images, shape (H, W, 3)
    projection_matrices: List of N matrices, shape (3, 4)
    Returns: List of 3D Gaussians (mu, alpha, Sigma, color)
    """
    N = len(images)
    H, W = images[0].shape[:2]
    s = 4  # Example downsampling factor
    D = 128  # Number of depth candidates, Not given in the sources.
    
    # Step 1: Monocular Feature Extraction
    # Pre-trained ViT model assumed available
    monocular_features = [vit_extract(I) for I in images]
    
    # Step 2-4: Cost Volume Construction
    cost_volumes = []
    for i in range(N):
        # Sample depth candidates
        depth_candidates = sample_depth_candidates(D, near=0.1, far=100.0) # Ranges not given in sources [G]
        
        # Select neighbors
        if N > 2:
            neighbors = get_top_2_neighbors(i, projection_matrices)
        else:
            neighbors = [j for j in range(N) if j != i]
            
        correlations = []
        for j in neighbors:
            # Step 3: Warp features
            warped_features = []
            for d in depth_candidates:
                # Warp feature F_j to view i using P_i and d
                # Implementation detail: inverse projection and interpolation
                F_warped = warp_feature(images[j], projection_matrices[j], projection_matrices[i], d)
                warped_features.append(F_warped)
            
            # Step 4: Correlation
            # Dot product between F_i and warped features
            F_i_downsampled = downsample(monocular_features[i], s)
            corr = dot_product_correlation(F_i_downsampled, warped_features)
            correlations.append(corr)
            
        # Average correlations if multiple neighbors
        if len(correlations) > 1:
            cost_vol = mean(correlations, axis=0)
        else:
            cost_vol = correlations[0]
            
        cost_volumes.append(cost_vol)
        
    # Step 5: Concatenation
    # Concatenate cost volumes with monocular features
    # Note: Dimensions must be aligned. Monocular features are likely upsampled or processed to match cost vol size.
    # The source states "Concatenate the multi-view cost volumes C_i with the extracted monocular features."
    # Assuming monocular features are processed to match spatial resolution of cost volumes.
    concatenated_features = [concatenate(cost_volumes[i], upsample_monocular(monocular_features[i], s)) for i in range(N)]
    
    # Step 6: Depth Regression
    # 2D U-Net + Softmax
    depth_maps = []
    for i in range(N):
        # U-Net output is logits over depth bins
        logits = u_net(concatenated_features[i])
        # Softmax to get probability distribution over depth candidates
        probs = softmax(logits, dim=-1)
        # Expected depth
        depth_map = sum(depth_candidates * probs)
        depth_maps.append(depth_map)
        
    # Step 7: Unprojection
    gaussians = []
    for i in range(N):
        # Unproject depth map to 3D points
        centers = unproject_depth(depth_maps[i], projection_matrices[i])
        
        # Step 8: Predict remaining parameters
        # Lightweight head in parallel
        # Input to head could be the concatenated features or the depth map
        # Source says "in parallel", implying same input stage or derived from it
        params = gaussian_head(concatenated_features[i])
        
        alpha = params['alpha']
        Sigma = params['covariance']
        color = params['color']
        
        gaussians.append((centers, alpha, Sigma, color))
        
    return gaussians
```

**Edge Cases and Pitfalls:**
*   **Occlusions/Low-texture:** Multi-view depth estimation fails in these areas. DepthSplat mitigates this by augmenting multi-view cost volumes with monocular features [S1].
*   **Scale Ambiguity:** Monocular depth estimation suffers from scale ambiguities. DepthSplat maintains multi-view consistency by using monocular features only as an augmentation to multi-view matching [S1].
*   **Computational Cost:** For $N > 2$ views, computing correlations for all pairs is expensive. DepthSplat selects only the top-2 nearest neighbors to maintain tractability [S1].

## Subtopics

### [Gaussian Graph Network](18863-gaussian-graph-network.md)
Gaussian Graph Network (GGN) is a feed-forward method that generates efficient and generalizable 3D Gaussian representations from multi-view images by modeling relations between Gaussian groups from different views using a Gaussian Graph structure. It solves the problem of artifacts and excessive memory costs caused by previous methods that simply combine pixel-aligned Gaussians from multiple views without capturing their inter-view relations. Unlike sibling methods that treat multi-view Gaussians as independent sets, GGN performs message passing and aggregation at the Gaussian level, allowing each Gaussian to benefit from connected groups in other views.

## Operating characteristics
*   **Speed:** Feed-forward reconstruction from 12 input views at 512x960 resolution takes 0.6 seconds [S1].
*   **Training Cost:** Trained in 2 days with 4 GPUs, compared to GS-LRM which requires 64 A100 GPUs for 2 days [S1].
*   **Strengths:** Robust to occlusions, low-textured areas, and non-Lambertian surfaces due to monocular feature augmentation; efficient training; fast feed-forward inference [S1].
*   **Limitations:** Relies on pre-trained monocular depth model; multi-view depth estimation still fundamentally limited by photometric consistency assumptions in extreme cases (though mitigated) [S1].
*   **When to use:** Large-scale scene reconstruction from multiple views where speed and robustness to textureless regions are prioritized [S1].
*   **When not to use:** Single-image reconstruction (DepthSplat targets multi-view); scenes with extreme non-Lambertian properties where even monocular features fail [S1].

## Background
DepthSplat was introduced to connect Gaussian splatting and depth estimation, studying their interactions [S1]. It addresses the isolation of these two fields by leveraging pre-trained monocular depth features to enhance multi-view depth prediction, leading to high-quality feed-forward 3D Gaussian splatting reconstructions [S1]. The method also demonstrates that Gaussian splatting can serve as an unsupervised pre-training objective for learning powerful depth models from large-scale multi-view posed datasets [S1]. It was validated on TartanAir, ScanNet, RealEstate10K, and DL3DV datasets [S1].
