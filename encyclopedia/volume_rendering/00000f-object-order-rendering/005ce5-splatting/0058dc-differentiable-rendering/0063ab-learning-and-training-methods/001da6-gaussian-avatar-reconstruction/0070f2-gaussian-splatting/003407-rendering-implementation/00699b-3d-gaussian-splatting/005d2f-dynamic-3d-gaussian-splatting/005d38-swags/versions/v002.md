# SWAGS


## Overview
SWAGS is a dynamic 3D Gaussian Splatting method that partitions a dynamic sequence into distinct windows based on motion amount [S1][S2, unofficial]. It trains separate dynamic 3DGS models for each window, each with its own canonical space and deformation field [S1][S2, unofficial]. The deformation field employs a tunable MLP that focuses on modeling the dynamic part of the scene [S1][S2, unofficial]. Temporal consistency across windows is ensured through fine-tuning on overlapping frames [S1][S2, unofficial].

## How it works
**Inputs and outputs**: Input is a sequence of frames with timestamps and a motion partitioning criterion. Output is a set of window-specific models, each containing canonical Gaussians, a tunable MLP deformation field, and 4D rendering parameters.

**Data structures**: Each window maintains a canonical space (reference geometry), a tunable MLP deformation field, and a set of 3D Gaussians. Time-varying parameters are computed at render time. The 4D scaling matrix is diagonal, formed by appending a time-dimension scaling factor to the 3D scaling matrix diagonal [S1][S2, unofficial]. View-dependent color uses a 4D spherical harmonics extension, combining 3D SH with 1D time basis functions [S1][S2, unofficial].

**Numbered steps**:
1. Partition the dynamic sequence into windows based on motion amount [S1][S2, unofficial].
2. For each window, initialize a canonical space and a tunable MLP deformation field [S1][S2, unofficial].
3. Train a separate dynamic 3DGS model per window, optimizing canonical Gaussians and MLP parameters [S1][S2, unofficial].
4. Identify overlapping frames between adjacent windows [S1][S2, unofficial].
5. Fine-tune the models using overlapping frames to enforce temporal consistency [S1][S2, unofficial]. During this phase, freeze the MLP parameters and optimize only the canonical representation [S1][S2, unofficial].

**Formulas**:
- 4D scaling matrix: $S_{4D} = \text{diag}(S_{3D}, s_t)$, where $s_t$ is the time-dimension scaling factor [S1][S2, unofficial].
- 4D spherical harmonics: $SH_{4D}(\omega, t) = SH_{3D}(\omega) \otimes B_1(t)$, combining 3D SH with 1D time basis functions $B_1(t)$ [S1][S2, unofficial].

**Parameters**: Motion threshold for window partitioning (typical values not given in the sources).

**Edge cases and pitfalls**: Insufficient overlap between windows or inadequate fine-tuning iterations may cause temporal discontinuities at window boundaries. Precision in time-dimension scaling and basis function evaluation must be maintained to avoid artifacts.

**Pseudocode**:
```python
def swags_train(sequence_frames, motion_threshold):
    # Step 1: Divide sequence into windows based on motion amount
    windows = []
    current_window = []
    for frame in sequence_frames:
        current_window.append(frame)
        if len(current_window) >= motion_threshold:
            windows.append(current_window)
            current_window = []
    if current_window:
        windows.append(current_window)

    trained_models = []
    for window_frames in windows:
        # Step 2: Initialize canonical space and deformation field
        canonical_gaussians = initialize_canonical_gaussians(window_frames)
        deformation_mlp = TunableMLP()
        model = Dynamic3DGSModel(canonical_gaussians, deformation_mlp, window_frames)
        # Step 3: Train separate dynamic 3DGS model
        model.train()
        trained_models.append(model)

    # Step 4 & 5: Fine-tune for temporal consistency
    for i in range(len(trained_models) - 1):
        overlap_frames = find_overlap_frames(trained_models[i].frames, trained_models[i+1].frames)
        if overlap_frames:
            trained_models[i].freeze_mlp()
            trained_models[i+1].freeze_mlp()
            trained_models[i].optimize_canonical(overlap_frames)
            trained_models[i+1].optimize_canonical(overlap_frames)

    return trained_models

class TunableMLP:
    def __init__(self):
        self.weights = initialize_weights()
    def forward(self, canonical_pos, time_t):
        return apply_mlp(self.weights, canonical_pos, time_t)

class Dynamic3DGSModel:
    def __init__(self, canonical_gaussians, deformation_mlp, frames):
        self.canonical_gaussians = canonical_gaussians
        self.deformation_mlp = deformation_mlp
        self.frames = frames
        self.mlp_frozen = False
    def freeze_mlp(self):
        self.mlp_frozen = True
    def train(self):
        for frame in self.frames:
            rendered = render_frame(self.canonical_gaussians, self.deformation_mlp, frame)
            loss = compute_rendering_loss(rendered, frame.image)
            update_parameters(loss, self.canonical_gaussians, self.deformation_mlp)
    def optimize_canonical(self, overlap_frames):
        for frame in overlap_frames:
            rendered = render_frame(self.canonical_gaussians, self.deformation_mlp, frame)
            loss = compute_rendering_loss(rendered, frame.image)
            update_parameters(loss, self.canonical_gaussians, frozen_mlp=self.deformation_mlp)
    def render_frame(self, canonical_gaussians, deformation_mlp, frame):
        world_gaussians = []
        for g in canonical_gaussians:
            t_mu = g.position + deformation_mlp.forward(g.position, frame.time)
            S_4d = construct_4d_scaling_matrix(g.scale, frame.time)
            sh_4d = compute_4d_sh(g.sh_3d, frame.time)
            world_gaussians.append(Gaussian(t_mu, g.rotation, S_4d, g.opacity, sh_4d))
        return rasterize_gaussians(world_gaussians, frame.camera_pose)

def construct_4d_scaling_matrix(scale_3d, time_t):
    return diagonal_matrix(scale_3d + [time_scaling_factor(time_t)])

def compute_4d_sh(sh_3d, time_t):
    return combine_sh_basis(sh_3d, time_basis(time_t))
```

## Operating characteristics
*   **Complexity**: Memory and compute scale linearly with the number of windows and the size of each window's Gaussian set [S1][S2, unofficial]. Exact complexity bounds are not given in the sources.
*   **Strengths**: Isolating motion into windows allows effective handling of scenes with varying motion intensities [S1][S2, unofficial]. The MLP's focus on dynamic parts enables efficient motion representation [S1][S2, unofficial].
*   **Limitations**: Requires careful motion-based window partitioning. Temporal consistency depends on sufficient overlap and fine-tuning; poor overlap or insufficient iterations can cause discontinuities [S1][S2, unofficial].
*   **Performance**: Not given in the sources.

## Background
SWAGS is introduced as a window-based dynamic 3DGS method [S1][S2, unofficial]. It has been applied to medical fields, including markerless motion reconstruction for infants and neonates, utilizing additional mask and depth supervisions [S1][S2, unofficial].
