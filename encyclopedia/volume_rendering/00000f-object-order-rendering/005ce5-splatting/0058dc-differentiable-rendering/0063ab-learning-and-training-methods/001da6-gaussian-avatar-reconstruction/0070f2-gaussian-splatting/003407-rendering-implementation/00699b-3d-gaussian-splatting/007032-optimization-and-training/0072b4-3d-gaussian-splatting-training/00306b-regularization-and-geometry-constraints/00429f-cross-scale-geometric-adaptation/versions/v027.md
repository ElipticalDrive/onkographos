# Cross-scale geometric adaptation

Also called: Lgeo, Reprojection error supervision, Reprojection-based cross-scale geometric adaptation

## Overview
Cross-scale geometric adaptation is a self-adaptive regularization technique that uses reprojection errors across multiple voxel scales to guide geometry learning without requiring explicit depth ground truth [S1]. It selects render depths with minimal reprojection error across different scales as pseudo labels, ensuring geometric integrity and significantly reducing floaters compared to training without geometric adaptation [S1]. Unlike sibling methods that may rely on complex scheduling or external priors, this method adapts multi-scale voxel geometry by leveraging the consistency of low-frequency components early in training and high-frequency details later [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Training views with known camera poses (rotation $R_i$, translation $t_i$) and intrinsics $K_i$; rendered RGB images $C_i$ and depth maps $D_{il}$ at multiple scales $l$ (Low, Mid, High); training rays $r_{train}$.
*   **Outputs:** Geometric adaptation loss $\mathcal{L}_{geo}$; updated pseudo-ground truth depth $D'(r_{train})$.

**Data Structures:**
*   **Multi-scale Voxels:** The scene is represented by voxels at $L$ scales (e.g., $l=0$ Low, $l=1$ Mid, $l=2$ High). Each scale $l$ provides a rendered depth map $D_{il}$ and RGB map $C_i$ for frame $i$.
*   **Ray Data:** For each training ray $r_{train}$, the method stores the 2D pixel coordinate $p_i$ in frame $i$.

**Numbered Steps:**
1.  **Reproject to 3D (Frame $i$):** For a given training ray $r_{train}$ originating from pixel $p_i$ in frame $i$, compute the 3D point in the camera coordinate system of frame $i$ ($x_{li}$) for each scale $l$. This is done using the rendered depth $D_{il}(p_i)$ and camera intrinsics $K_i$:
    $$ x_{li} = D_{il}(p_i) K_i^{-1} \tilde{p}_i $$
    where $\tilde{p}_i$ is the homogeneous augmentation of $p_i$ [S1]. Alternatively, this point can be computed directly from the ray origin $o_i(p_i)$ and direction $v_i(p_i)$:
    $$ x_l = o_i(p_i) + D_{il}(p_i) v_i(p_i) $$
    [S1].

2.  **Transform to World Coordinates:** Transform the 3D point $x_{li}$ from frame $i$'s camera coordinates to the world coordinate system using frame $i$'s rotation $R_i$ and translation $t_i$:
    $$ x_l = R_i x_{li} + t_i $$
    [S1].

3.  **Reproject to Frame $j$:** Transform the world coordinate point $x_l$ to the camera coordinate system of a reference frame $j$ (where $j \neq i$) using frame $j$'s rotation $R_j$ and translation $t_j$:
    $$ x_{li \to j} = R_j^T (x_l - t_j) $$
    [S1].

4.  **Project to 2D (Frame $j$):** Project the 3D point $x_{li \to j}$ back to the 2D pixel coordinate system of frame $j$ to obtain $\tilde{p}_{li \to j}$:
    $$ \tilde{p}_{li \to j} = \pi(K_j x_{li \to j}) $$
    where $\pi([x, y, z]^T) = [x/z, y/z]^T$ [S1].

5.  **Compute Reprojection Error:** Calculate the reprojection error $e_l(p_i)$ for scale $l$ as the difference between the original RGB pixel $C_i(p_i)$ and the warped pixel $C_j(\tilde{p}_{li \to j})$ from frame $j$:
    $$ e_l(p_i) = C_i(p_i) - C_j(\tilde{p}_{li \to j}) $$
    [S1].

6.  **Select Pseudo-Ground Truth Depth:** Identify the scale $l'$ that minimizes the reprojection error for the ray. This scale's depth is selected as the pseudo-ground truth depth $D'(r_{train})$:
    $$ D'(r_{train}) = \arg \min_l (e_l(r_{train})) $$
    [S1].

7.  **Compute Loss:** Calculate the geometric adaptation loss $\mathcal{L}_{geo}$ as the Mean Squared Error (MSE) between the rendered depth $D_{il}(r_{train})$ at each scale and the selected pseudo-ground truth depth $D'(r_{train})$:
    $$ \mathcal{L}_{geo}(r_{train}) = \sum_{l=0}^{L} \| \hat{D}_l(r_{train}) - D'(r_{train}) \|^2 $$
    [S1]. Note: The sources indicate $\hat{D}_l$ corresponds to the rendered depth $D_{il}$.

**Pseudocode:**
```python
def compute_cross_scale_geometric_adaptation_loss(
    rays: List[Ray],
    frames: List[Frame],
    scales: List[Scale],
    intrinsics: List[Matrix],
    poses: List[Pose]
) -> Tensor:
    """
    Computes the cross-scale geometric adaptation loss L_geo.
    
    Args:
        rays: List of training rays, each containing pixel coordinate p_i.
        frames: List of training frames (i, j, ...).
        scales: List of scales (Low, Mid, High).
        intrinsics: Camera intrinsics K_i for each frame.
        poses: Camera poses (R_i, t_i) for each frame.
        
    Returns:
        Scalar loss value L_geo.
    """
    total_loss = 0.0
    
    for ray in rays:
        p_i = ray.pixel_coordinate
        frame_i = ray.source_frame
        K_i = intrinsics[frame_i.id]
        R_i, t_i = poses[frame_i.id].rotation, poses[frame_i.id].translation
        
        # Step 1: Reproject to 3D in Frame i's camera coordinates for all scales
        # D_il is the rendered depth at scale l for pixel p_i in frame i
        # x_l is the 3D point in world coordinates (computed once per ray)
        x_l_world = None
        
        for scale in scales:
            D_il = ray.rendered_depth[scale] # D_il(p_i)
            
            # Homogeneous coordinate
            p_i_hom = np.array([p_i.x, p_i.y, 1.0])
            
            # Inverse projection to camera coordinates
            # x_li = D_il * K_i^-1 * p_i_hom
            # Note: D_il is a scalar depth value
            x_li_cam = D_il * np.linalg.inv(K_i) @ p_i_hom
            
            # Step 2: Transform to World Coordinates
            # x_l = R_i * x_li + t_i
            x_l_world = R_i @ x_li_cam + t_i
            
            # Store world coordinate for this ray (same for all scales if geometry is consistent,
            # but here we use the depth from scale l to define the point)
            # Actually, the method selects the best scale later. 
            # We need to compute reprojection error for EACH scale to find the best one.
        
        # Re-evaluate for each scale to find min reprojection error
        min_error = float('inf')
        best_scale_idx = -1
        best_depth = None
        
        for scale_idx, scale in enumerate(scales):
            D_il = ray.rendered_depth[scale]
            p_i_hom = np.array([p_i.x, p_i.y, 1.0])
            x_li_cam = D_il * np.linalg.inv(K_i) @ p_i_hom
            x_l_world = R_i @ x_li_cam + t_i
            
            # Step 3 & 4: Reproject to Frame j (use a different frame j from frames list)
            # For simplicity, assume we iterate over other frames in the training set
            # The source implies using "frame j" generally. In implementation, 
            # one might average over multiple j or pick a specific j.
            # Let's assume we pick one reference frame j != i for the error calculation.
            # If multiple j are available, the error might be aggregated. 
            # The source formula e_l(p_i) uses C_j.
            
            # Let's assume we have a set of other frames J_other
            error_sum = 0.0
            count = 0
            
            for frame_j in frames:
                if frame_j.id == frame_i.id:
                    continue
                
                K_j = intrinsics[frame_j.id]
                R_j, t_j = poses[frame_j.id].rotation, poses[frame_j.id].translation
                
                # Step 3: Transform to Frame j camera coordinates
                # x_li_j = R_j^T * (x_l_world - t_j)
                x_li_j_cam = R_j.T @ (x_l_world - t_j)
                
                # Step 4: Project to 2D
                # p_li_j = pi(K_j * x_li_j_cam)
                p_li_j_hom = K_j @ x_li_j_cam
                p_li_j = np.array([p_li_j_hom[0]/p_li_j_hom[2], p_li_j_hom[1]/p_li_j_hom[2]])
                
                # Step 5: Compute Reprojection Error
                # e_l = C_i(p_i) - C_j(p_li_j)
                # C_i and C_j are RGB maps.
                c_i = ray.rendered_rgb[scale] # Or original image if available
                c_j = ray.warped_rgb[scale] # Need to sample C_j at p_li_j
                
                # Assuming we have access to rendered RGB maps C_i and C_j
                # In practice, C_i is the input image, C_j is rendered from the current model
                error = c_i - c_j
                error_sum += np.linalg.norm(error)
                count += 1
            
            if count > 0:
                avg_error = error_sum / count
                if avg_error < min_error:
                    min_error = avg_error
                    best_scale_idx = scale_idx
                    best_depth = D_il
        
        # Step 6 & 7: Compute Loss against best depth
        # L_geo = sum_l || D_l - D' ||^2
        # D' is the depth of the best scale
        D_prime = best_depth
        
        for scale_idx, scale in enumerate(scales):
            D_il = ray.rendered_depth[scale]
            loss_term = (D_il - D_prime) ** 2
            total_loss += loss_term
            
    return total_loss
```

**Parameters:**
*   **Scales:** Typically 3 scales (Low, Mid, High) [S1].
*   **Loss Weight:** $\lambda$ for $\mathcal{L}_{geo}$ in the total loss $\mathcal{L}_{total} = \mathcal{L}_{photo} + \lambda \mathcal{L}_{geo}$ [S1].

**Edge Cases and Pitfalls:**
*   **Camera Pose Accuracy:** The method relies on accurate camera poses. In scenarios with significant viewpoint changes or sparse training views, generalization may be challenging [S1].
*   **Scale Mismatch:** Using a single depth prior (Ld) can suffer from scale mismatches later in training, whereas Lgeo refines depth progressively [S1].
*   **Local Minima:** Omitting novel view rays risks local minima, causing incorrect geometry. Novel view regularizations add guidance, reducing overfitting [S1].

## Operating characteristics
*   **Time Complexity:** The method requires reprojection calculations for each training ray across multiple scales and reference frames. This adds computational overhead per iteration compared to standard photometric loss alone.
*   **Memory Complexity:** Requires storing rendered depth and RGB maps for all scales and potentially warping images for reference frames.
*   **Performance:** Significantly reduces floaters and improves convergence quality across scales compared to training without geometric adaptation [S1]. Achieves lower final depth error than using depth prior (Ld) alone [S1]. Combining Lgeo with Ld yields the best results [S1].
*   **Strengths:** Self-adaptive; no complex scheduling required; robust to geometric noise compared to methods like GeCoNeRF [S1].
*   **Limitations:** Relies on accurate camera poses; performance may degrade in few-shot scenarios with sparse views [S1].

## Background
Cross-scale geometric adaptation was proposed in the context of FrugalNeRF, a framework for synthesizing novel views from extremely few inputs [S1]. It was introduced to accelerate and regularize training without external priors [S1]. The method leverages weight-sharing voxels across scales and uses reprojection errors to guide multi-scale geometry [S1]. It addresses the issue of floaters and sub-optimal convergence seen in methods without geometric adaptation [S1].
