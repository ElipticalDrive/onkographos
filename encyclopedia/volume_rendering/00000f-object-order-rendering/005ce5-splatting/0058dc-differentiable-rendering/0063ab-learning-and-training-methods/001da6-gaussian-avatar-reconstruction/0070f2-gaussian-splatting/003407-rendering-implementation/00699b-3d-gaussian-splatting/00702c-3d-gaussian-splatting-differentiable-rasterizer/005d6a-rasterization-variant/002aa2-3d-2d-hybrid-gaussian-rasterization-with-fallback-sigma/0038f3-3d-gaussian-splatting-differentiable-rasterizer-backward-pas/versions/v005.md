# 3D Gaussian Splatting Differentiable Rasterizer > Backward Pass

Also called: Backward Pass of Gaussian Rasterizer, Gaussian Rasterization (Backward), ToF Gaussian Rasterization Backward Pass

## Overview
The backward pass computes gradients for all input parameters (means, colors, opacities, scales, rotations, covariances, and SH coefficients) with respect to the output color gradient [S1, unofficial]. It enables end-to-end differentiable training by propagating loss gradients from the rendered image back to the 3D scene representation [S1, unofficial]. It builds on [3D/2D Hybrid Gaussian Rasterization with Fallback Sigma](4812-3d-2d-hybrid-gaussian-rasterization-with-fallback-sigma.md) by providing the necessary gradient flow for the hybrid rasterization variant [G].

## How it works
The backward pass is implemented as a Python wrapper around a C++/CUDA kernel [S1, unofficial]. It retrieves cached tensors from the forward pass context, restructures arguments to match the kernel's expected layout, invokes the native routine, and returns a tuple of gradients matching the forward pass input order [S2, unofficial].

### Inputs and Outputs
**Inputs:**
1. **Gradients from downstream loss:** `grad_out_color`, `grad_out_phasor`, `grad_out_depth`, `grad_out_normal`, `grad_out_acc`, `grad_entropy`, `grad_depth_distortion`, `grad_amp_distortion` [S2, unofficial].
2. **Forward Pass Context (Saved Tensors):** `means3D`, `scales`, `rotations`, `cov3Ds_precomp`, `radii`, `colors_precomp`, `phasors_precomp`, `sh`, `sh_p`, `geomBuffer`, `binningBuffer`, `imgBuffer`, `num_rendered`, `phase_offset`, `dc_offset` [S1, unofficial][S2, unofficial].
3. **Raster Settings:** `bg`, `viewmatrix`, `projmatrix`, `tanfovx`, `tanfovy`, `campos`, `scale_modifier`, `sh_degree`, `use_view_dependent_phase`, `debug`, `near_n`, `far_n`, `depth_range` [S1, unofficial][S2, unofficial].

**Outputs:**
A tuple of gradients corresponding to the forward pass inputs: `grad_means3D`, `grad_means2D`, `grad_sh`, `grad_sh_p`, `grad_colors_precomp`, `grad_phasors_precomp`, `grad_opacities`, `grad_scales`, `grad_rotations`, `grad_cov3Ds_precomp`, `grad_phase_offset` (or `None`), `grad_dc_offset` (or `None`), and `None` for `raster_settings` [S1, unofficial][S2, unofficial].

### Data Structures and Layout
The C++ kernel expects arguments in a specific order [S2, unofficial]. The Python wrapper restructures the inputs into a single tuple before invoking the native routine [S2, unofficial].

**Argument Order for the Backward Kernel:**
`bg`, `means3D`, `radii`, `colors_precomp`, `phasors_precomp`, `scales`, `rotations`, `scale_modifier`, `cov3Ds_precomp`, `viewmatrix`, `projmatrix`, `tanfovx`, `tanfovy`, `grad_out_color`, `grad_out_phasor`, `grad_out_depth`, `grad_out_normal`, `grad_out_acc`, `grad_entropy`, `grad_depth_distortion`, `grad_amp_distortion`, `sh`, `sh_p`, `sh_degree`, `campos`, `geomBuffer`, `num_rendered`, `binningBuffer`, `imgBuffer`, `debug`, `near_n`, `far_n`, `depth_range`, `use_view_dependent_phase`, `phase_offset`, `dc_offset` [S2, unofficial].

### Steps
1. **Restore Context:** Retrieve all saved tensors and settings from the forward pass context [S1, unofficial][S2, unofficial].
2. **Restructure Arguments:** Pack the inputs into the tuple order defined above [S2, unofficial].
3. **Invoke Kernel:** Call the native backward rasterization function `_C.rasterize_gaussians_backward(*args)` [S1, unofficial][S2, unofficial].
4. **Construct Return Tuple:** Create a tuple of gradients in the order expected by the autograd engine, matching the forward pass input signature [S2, unofficial]. If `optimize_phase_offset` is false, `grad_phase_offset` is `None` [S2, unofficial]. If `optimize_dc_offset` is false, `grad_dc_offset` is `None` [S2, unofficial]. The last element is `None` for `raster_settings` [S1, unofficial].

def backward(
    grad_out_color, grad_out_phasor, grad_out_depth, grad_out_normal,
    grad_out_acc, grad_entropy, grad_depth_distortion, grad_amp_distortion,
    bg, means3D, radii, colors_precomp, phasors_precomp, scales, rotations,
    scale_modifier, cov3Ds_precomp, viewmatrix, projmatrix, tanfovx, tanfovy,
    sh, sh_p, sh_degree, campos, geomBuffer, num_rendered, binningBuffer,
    imgBuffer, debug, near_n, far_n, depth_range, use_view_dependent_phase,
    phase_offset, dc_offset, optimize_phase_offset, optimize_dc_offset
):
    # Step 1: Restore context and restructure arguments
    args = (
        bg, means3D, radii, colors_precomp, phasors_precomp, scales, rotations,
        scale_modifier, cov3Ds_precomp, viewmatrix, projmatrix, tanfovx, tanfovy,
        grad_out_color, grad_out_phasor, grad_out_depth, grad_out_normal,
        grad_out_acc, grad_entropy, grad_depth_distortion, grad_amp_distortion,
        sh, sh_p, sh_degree, campos, geomBuffer, num_rendered, binningBuffer,
        imgBuffer, debug, near_n, far_n, depth_range, use_view_dependent_phase,
        phase_offset, dc_offset
    )

    # Step 2: Debug handling
    if debug:
        args_cpu = tuple(x.cpu().clone() if hasattr(x, 'cpu') else x for x in args)
        try:
            grads = rasterize_gaussians_backward_native(*args_cpu)
        except Exception as e:
            import pickle
            with open('snapshot_bw.dump', 'wb') as f:
                pickle.dump(args_cpu, f)
            print(f"Exception in backward pass: {e}")
            raise e
    else:
        grads = rasterize_gaussians_backward_native(*args)

    # Step 3: Construct return tuple matching forward pass input order
    grad_means3D = grads[0]
    grad_means2D = grads[1]
    grad_sh = grads[2]
    grad_sh_p = grads[3]
    grad_colors_precomp = grads[4]
    grad_phasors_precomp = grads[5]
    grad_opacities = grads[6]
    grad_scales = grads[7]
    grad_rotations = grads[8]
    grad_cov3Ds_precomp = grads[9]

    grad_phase_offset = grads[10] if optimize_phase_offset else None
    grad_dc_offset = grads[11] if optimize_dc_offset else None
    grad_raster_settings = None

    return (
        grad_means3D, grad_means2D, grad_sh, grad_sh_p, grad_colors_precomp,
        grad_phasors_precomp, grad_opacities, grad_scales, grad_rotations,
        grad_cov3Ds_precomp, grad_phase_offset, grad_dc_offset, grad_raster_settings

### Edge Cases and Pitfalls
* **Debug Mode Overhead:** If `debug` is true, all tensors are deep-copied to CPU to allow saving a snapshot if an exception occurs [S1, unofficial][S2, unofficial].
* **Missing Gradients:** The kernel expects all gradient tensors; unused gradients should be passed as `None` or zero tensors depending on the implementation [S2, unofficial].
* **Gradient Order:** The order of gradients returned by the kernel must exactly match the forward pass input signature to ensure correct autograd integration [S2, unofficial].
* **Non-Optimized Parameters:** If `phase_offset` or `dc_offset` are not optimized, their gradients are returned as `None` to prevent PyTorch from updating non-trainable parameters [S2, unofficial].

* **Time Complexity:** Not given in the sources.

* **Strengths:** Fully differentiable rasterization enabling gradient propagation [S1, unofficial].
* **Limitations:** Requires saving forward pass context tensors for gradient computation [S1, unofficial][S2, unofficial].
* **When to Use:** Training 3D Gaussian Splatting models requiring gradient computation [S1, unofficial].
* **When Not to Use:** Inference-only applications where gradients are not needed [G].

## Background
The backward pass implementation is provided in the EGGS repository [S1, unofficial] and extended in gftorf to support Time-of-Flight rendering and additional modalities [S2, unofficial]. It is a critical component for optimizing the 3D scene representation from 2D images during differentiable training [S1, unofficial].
