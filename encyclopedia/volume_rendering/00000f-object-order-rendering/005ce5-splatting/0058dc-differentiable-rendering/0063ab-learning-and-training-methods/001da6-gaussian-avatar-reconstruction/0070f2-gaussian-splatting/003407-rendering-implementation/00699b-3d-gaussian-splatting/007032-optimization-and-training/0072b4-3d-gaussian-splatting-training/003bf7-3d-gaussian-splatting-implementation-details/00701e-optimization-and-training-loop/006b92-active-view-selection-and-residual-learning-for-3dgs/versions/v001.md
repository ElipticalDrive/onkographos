# Active View Selection and Residual Learning for 3DGS

Also called: SA-ResGS (Self-augmented Residual 3D Gaussian Splatting), Self-augmented Residual 3D Gaussian Splatting

## Overview
SA-ResGS is a framework that combines residual learning with self-augmented pre-filtering to improve active view selection and 3D reconstruction quality in 3D Gaussian Splatting (3DGS) [S1]. It distinguishes itself from sibling methods like [Uncertainty-Guided Residual Learning for 3DGS](20901-uncertainty-guided-residual-learning-for-3dgs.md) by integrating a reliable view selection sequence (via SA-HashGS) that enables residual supervision to further improve reconstruction in sparse or ambiguous regions [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of training images and camera poses (initially sparse), COLMAP SfM initialization, and a fixed iteration budget.
*   **Output:** Optimized 3D Gaussian parameters (position, covariance, opacity, SH coefficients) and a selected subset of training views.

**Data Structures:**
*   **Gaussian Set:** Standard 3DGS representation (position $\mathbf{x}$, covariance $\mathbf{\Sigma}$, opacity $\alpha$, spherical harmonics $\mathbf{c}$) [S1].
*   **View Selection State:** Tracks the current set of active training views and the iteration count.

**Parameters:**
*   **Initial Views:** 4 uniformly distributed views [S1].
*   **View Addition Schedule:** Add 1 view every 100 epochs until reaching 20 training views [S1].
*   **Total Iterations:** 20,000 iterations per experiment [S1].
*   **Random Seed:** Fixed for reproducibility across all experiments [S1].

**Algorithm Steps:**
1.  **Initialization:** Initialize all models with the same random seed and the same COLMAP SfM initialization [S1]. Set the active view set to the 4 initial uniformly distributed views [S1].
2.  **Active View Selection (SA-HashGS):**
    *   Use SA-HashGS to restrict the candidate set for Fisher uncertainty [S1].
    *   Select the next best view from the remaining unselected views based on the restricted uncertainty metric [S1].
    *   Add the selected view to the active training set [S1].
3.  **Training Loop (per iteration):**
    *   **Sampling:** Randomly select one or more training images and camera poses from the *current* active view set [S1].
    *   **Rendering:** Project the 3D Gaussians to 2D and alpha-blend them using a differentiable rasterizer to produce a rendered image $\hat{I}$ [S1].
    *   **Loss Computation:** Compute the photometric loss $\mathcal{L}$ between $\hat{I}$ and the ground-truth image $I_{gt}$ [S1]. The standard loss is a weighted sum:
        $$ \mathcal{L}_{img} = (1 - \lambda) \mathcal{L}_{L1} + \lambda \mathcal{L}_{D-SSIM} $$
        where $\mathcal{L}_{L1}$ is the L1 loss and $\mathcal{L}_{D-SSIM}$ is the differentiable Structural Similarity index loss [S1]. The weight $\lambda$ is typically 0.2 [S1].
    *   **Residual Learning:** Apply residual supervision to improve reconstruction in sparse or ambiguous regions [S1]. This involves computing a residual loss term that guides the optimization based on the current reconstruction error or uncertainty [S1].
    *   **Backpropagation:** Compute gradients $\nabla \mathcal{L}$ with respect to all Gaussian parameters using automatic differentiation through the rasterizer [S1].
    *   **Update:** Update parameters using the Adam optimizer with $\beta_1 = 0.9$ and $\beta_2 = 0.99$ [S1].
    *   **Densification/Pruning:** Periodically evaluate gradient magnitudes and opacity thresholds to split high-gradient Gaussians or prune low-opacity ones, adapting the scene density [S1].
4.  **View Addition Check:** Every 100 epochs, if the number of active views is less than 20, select and add the next best view using SA-HashGS [S1].
5.  **Termination:** Stop after 20,000 iterations [S1].

**Pseudocode:**
```python
def train_sa_resgs(colmap_init, all_training_views, total_iterations=20000, initial_views=4, view_add_freq=100, max_views=20):
    # Initialize Gaussians with COLMAP SfM and fixed random seed
    gaussians = initialize_gaussians(colmap_init, seed=42)
    
    # Initial view selection: 4 uniformly distributed views
    active_views = select_initial_uniform_views(all_training_views, n=initial_views)
    selected_views = set(active_views)
    
    for iteration in range(total_iterations):
        # Sample from active views
        view = random.choice(active_views)
        gt_image = get_image(view)
        camera_pose = get_pose(view)
        
        # Render
        rendered_image = render(gaussians, camera_pose)
        
        # Compute Loss
        loss_l1 = compute_l1_loss(rendered_image, gt_image)
        loss_dssim = compute_dssim_loss(rendered_image, gt_image)
        lambda_weight = 0.2
        loss_img = (1 - lambda_weight) * loss_l1 + lambda_weight * loss_dssim
        
        # Residual Learning
        # Note: Specific residual loss formula not provided in sources [S1]
        # Assuming a residual term based on reconstruction error or uncertainty
        loss_residual = compute_residual_loss(gaussians, rendered_image, gt_image) 
        loss = loss_img + loss_residual
        
        # Backpropagation and Update
        gradients = compute_gradients(loss, gaussians)
        update_gaussians_adam(gaussians, gradients, beta1=0.9, beta2=0.99)
        
        # Densification/Pruning (periodic)
        if iteration % densification_freq == 0:
            densify_and_prune(gaussians)
            
        # View Addition Schedule
        if iteration % view_add_freq == 0 and len(active_views) < max_views:
            # Use SA-HashGS to select next view
            next_view = select_next_view_sa_hashgs(gaussians, all_training_views, selected_views)
            active_views.append(next_view)
            selected_views.add(next_view)
            
    return gaussians, active_views
```

## Subtopics

### [Active View Selection for 3D Gaussian Splatting](21848-active-view-selection-for-3d-gaussian-splatting.md)
Active View Selection (AVS) for 3D Gaussian Splatting (3DGS) identifies a subset of training views that maximizes final reconstruction quality while limiting the total number of views used. PRIMU-AVS distinguishes itself from the full PRIMU method by omitting the gradient boosting regressor, thereby avoiding the need for an additional hold-out view for training. It relies on a single direction-dependent coverage feature map with max aggregation and dropped opacity to guide view selection.

## Operating characteristics
*   **Time Complexity:** The method adds overhead for view selection (SA-HashGS) and residual loss computation at each step. The view selection is performed periodically (every 100 epochs), not every iteration.
*   **Memory Complexity:** Standard 3DGS memory usage plus storage for the view selection state and residual loss calculations.
*   **Performance:** SA-ResGS shows synergy with SA-HashGS, providing a reliable view sequence that enables residual supervision to further improve reconstruction in sparse or ambiguous regions [S1]. It outperforms purely dynamic selection (+ResGS) and other baselines like FisherRF, ACP, and 2D-based methods (MUSIQ, CrossScore) [S1].
*   **Strengths:** Improves reconstruction quality in sparse/ambiguous regions by combining reliable view selection with residual learning.
*   **Limitations:** Requires careful tuning of the view addition schedule and residual loss weight. The specific residual loss formula is not detailed in the sources [S1].
*   **When to use:** When reconstruction quality in sparse regions is critical and computational resources allow for the additional overhead of view selection and residual learning.
*   **When not to use:** When real-time performance is paramount and the overhead of view selection is unacceptable.

## Background
SA-ResGS was introduced in the paper "SA-ResGS: Self-augmented Residual 3D Gaussian Splatting for Next Best View Selection" [S1]. It builds upon the principles of 3D Gaussian Splatting and active view selection, aiming to address the limitations of existing methods in handling sparse or ambiguous regions during reconstruction.
