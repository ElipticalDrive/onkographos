# Variational Bayes Gaussian Splatting

Also called: VBGS

## Overview
Variational Bayes Gaussian Splatting (VBGS) is a continual learning method for Gaussian Splatting that frames training as variational inference over model parameters, leveraging the conjugacy of multivariate Gaussians to derive closed-form update rules [S1, unofficial]. Unlike standard 3D Gaussian Splatting (3DGS) which relies on backpropagation through a differentiable renderer and suffers from catastrophic forgetting in streaming data scenarios, VBGS updates component parameters by aggregating prior natural parameters with data sufficient statistics, enabling continuous learning without replay buffers [S1, unofficial]. It is distinguished by its reliance on RGBD data and its representation of a distribution over parameters rather than point estimates, making it suitable for real-time adaptation in robotics and autonomous navigation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A stream of RGBD data points (spatial coordinates $s \in \mathbb{R}^3$ or $\mathbb{R}^2$, and color $c \in \mathbb{R}^3$). For 2D images, $s$ is pixel location; for 3D, $s$ is Cartesian coordinates [S1, unofficial].
*   **Outputs:** A Gaussian Mixture Model (GMM) where each component $k$ has a variational posterior distribution over its spatial parameters $(\mu_{k,s}, \Sigma_{k,s})$, color parameters $(\mu_{k,c}, \Sigma_{k,c})$, and mixture weight $\pi$. The rendered output is generated by projecting these 3D Gaussians and combining colors via alpha blending [S1, unofficial].

**Data Structures:**
Each Gaussian component $k$ stores 29 parameters representing the Natural-Inverse-Wishart (NIW) likelihood for color and position, and the Dirichlet prior for assignments [S1, unofficial].
*   **Spatial Parameters ($q(\mu_{k,s}, \Sigma_{k,s})$):** NIW distribution parameterized by natural parameters $\eta_{0,s}$ and $\nu_{0,s}$.
    *   $\eta_{0,s} = (\kappa_{0,s} \cdot m_{0,s}, V_{0,s} + \kappa_{0,s} \cdot m_{0,s} \cdot m_{0,s}^T)$
    *   $\nu_{0,s} = (\kappa_{0,s}, n_{0,s} + D_s + 1)$
    *   Where $m_{0,s}$ is mean, $\kappa_{0,s}$ is concentration, $n_{0,s}$ is degrees of freedom, $V_{0,s}$ is inverse scale matrix, and $D_s$ is dimensionality [S1, unofficial].
*   **Color Parameters ($q(\mu_{k,c}, \Sigma_{k,c})$):**
    *   Mean $\mu_{k,c}$ follows a Normal distribution.
    *   Covariance $\Sigma_{k,c}$ is fixed as a Delta distribution $\delta(\epsilon I)$ to prevent color blending [S1, unofficial].
    *   Natural parameters $\eta_{0,c}$ and $\nu_{0,c}$ are defined similarly to spatial, but $n_{k,c}$ and $V_{k,c}$ are kept fixed [S1, unofficial].
*   **Assignment Parameters ($q(\pi)$):** Dirichlet distribution with natural parameter $\eta_{0,z} = \alpha$ [S1, unofficial].
*   **Assignments ($q(z_n)$):** Categorical distribution with parameters $\gamma_n$ [S1, unofficial].

**Algorithm Steps:**
The method uses Coordinate Ascent Variational Inference (CAVI) to maximize the Evidence Lower Bound (ELBO) [S1, unofficial].

1.  **Initialization:** Initialize $K$ components. For continual learning, unused components (where concentration parameters $\alpha_k$ equal prior values) are available for reassignment [S1, unofficial].
2.  **E-Step (Assignment):** Compute assignment log-probabilities for each data point $n$ and component $k$:
    $$ \log \gamma_n = \log q(z_n = k) = \mathbb{E}_{q(\mu_{k,s}, \Sigma_{k,s})}[\log p(s_n | \mu_{k,s}, \Sigma_{k,s})] + \mathbb{E}_{q(\mu_{k,c}, \Sigma_{k,c})}[\log p(c_n | \mu_{k,c}, \Sigma_{k,c})] + \mathbb{E}_{q(\pi)}[\log p(\pi)] - \log Z_n $$
    Normalize to get $\gamma_n = \hat{\gamma}_n / \sum \hat{\gamma}_n$ [S1, unofficial].
3.  **M-Step (Parameter Update):** Update natural parameters using sufficient statistics $T(x_n)$ of the data assigned to component $k$:
    $$ \eta_{k} = \eta_{0,k} + \sum_{x_n \in D} \gamma_{k,n} T(x_n) $$
    $$ \nu_{k} = \nu_{0,k} + \sum_{x_n \in D} \gamma_{k,n} $$
    For spatial likelihood, $T(s_n) = (s_n, s_n s_n^T)$. For color, $T(c_n) = (c_n, c_n c_n^T)$. For assignments, $T(x) = 1$ [S1, unofficial].
4.  **Continual Update:** For streaming data, updates are order-invariant. Assignments $q(z)$ are always computed with respect to the *initial* posterior over parameters to avoid catastrophic forgetting [S1, unofficial].
5.  **Component Reassignment (Heuristic):** To mitigate poor coverage in unknown scenes, replace the means of $n$ unused components with the location and color of $n$ data points sampled proportional to the negative ELBO. $n$ is a fraction (e.g., 0.01 or 0.05) of unused components [S1, unofficial].
6.  **Rendering:** Project 3D Gaussians to the image plane. Set alpha value for all Gaussians to 1 (opaque) because the method does not optimize on image reconstruction directly [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def vbgs_update(components, data_points, hyperparams):
    """
    Perform one CAVI step for VBGS.
    components: List of dicts, each containing 'eta_s', 'nu_s', 'eta_c', 'nu_c', 'alpha'
    data_points: Array of shape (N, 6) where columns are [s_x, s_y, s_z, c_r, c_g, c_b]
    hyperparams: Dict containing 'epsilon', 'reassign_fraction'
    """
    N = len(data_points)
    K = len(components)
    
    # 1. E-Step: Compute Assignments
    # Calculate log-probabilities for each data point and component
    # log_gamma[n, k]
    log_gamma = np.zeros((N, K))
    
    for k in range(K):
        # Extract NIW parameters for component k
        # eta_s = (kappa * m, V + kappa * m * m^T)
        # nu_s = (kappa, n + D + 1)
        eta_s_k = components[k]['eta_s']
        nu_s_k = components[k]['nu_s']
        
        eta_c_k = components[k]['eta_c']
        nu_c_k = components[k]['nu_c']
        
        alpha_k = components[k]['alpha'] # Dirichlet natural param
        
        # Compute expected log likelihood for spatial part
        # E[log N(s | mu, Sigma)] under NIW prior
        # This requires computing expectations of log-det(Sigma) and (s-mu)^T Sigma^-1 (s-mu)
        # For NIW, E[log det Sigma] and E[mu] are known functions of natural params
        # Simplified: Use standard MVN log-likelihood with expected parameters if exact NIW expectation is complex
        # However, source implies exact variational updates. 
        # We assume helper functions exist for NIW expectations.
        
        # Expected mean and covariance for spatial
        mu_s_exp, Sigma_s_exp = niw_expectations(eta_s_k, nu_s_k)
        
        # Expected mean and covariance for color
        # Note: Sigma_c is fixed Delta(epsilon I)
        mu_c_exp = components[k]['mu_c_mean'] # Derived from eta_c, nu_c
        Sigma_c_exp = hyperparams['epsilon'] * np.eye(3)
        
        # Log likelihoods
        log_p_s = mvn_log_prob(data_points[:, :3], mu_s_exp, Sigma_s_exp)
        log_p_c = mvn_log_prob(data_points[:, 3:], mu_c_exp, Sigma_c_exp)
        
        # Log prior for assignment (Dirichlet)
        # E[log pi_k] = psi(alpha_k) - psi(sum(alpha))
        log_p_z = dirichlet_log_prob(alpha_k)
        
        log_gamma[:, k] = log_p_s + log_p_c + log_p_z

    # Normalize
    log_gamma -= logsumexp(log_gamma, axis=1, keepdims=True)
    gamma = np.exp(log_gamma) # Shape (N, K)

    # 2. M-Step: Update Parameters
    new_components = []
    
    for k in range(K):
        # Get assigned data
        assigned_s = data_points[:, :3]
        assigned_c = data_points[:, 3:]
        weights = gamma[:, k]
        
        # Update Spatial NIW
        # eta_s_new = eta_s_0 + sum(gamma * T(s))
        # T(s) = [s, s s^T]
        sum_s = np.sum(weights[:, None] * assigned_s, axis=0)
        sum_ss = np.sum(weights[:, None, None] * (assigned_s[:, :, None] * assigned_s[:, None, :]), axis=0)
        
        # Prior natural params (stored in component or hyperparams)
        # Assuming components store current posterior params which act as priors for next step in continual setting
        # Or strictly: eta_0 is fixed prior. 
        # Source says: "aggregating prior natural parameters with data sufficient statistics"
        # In continual learning, the "prior" is the previous posterior.
        
        current_eta_s = components[k]['eta_s']
        current_nu_s = components[k]['nu_s']
        
        # Update
        # eta_s is a tuple (eta1, eta2) where eta1 = kappa*m, eta2 = V + kappa*m*m^T
        # nu_s is a tuple (kappa, nu)
        
        # Update kappa and m
        # new_kappa = old_kappa + sum(weights)
        # new_kappa * new_m = old_kappa * old_m + sum(weights * s)
        
        old_kappa_s = current_nu_s[0]
        old_nu_df = current_nu_s[1]
        
        new_kappa_s = old_kappa_s + np.sum(weights)
        new_m_s = (current_eta_s[0] + sum_s) / new_kappa_s
        
        # Update V and nu
        # new_nu = old_nu + sum(weights)
        # new_V = old_V + sum(weights * s s^T) + (old_kappa * sum(weights) / new_kappa) * (old_m - new_m)(old_m - new_m)^T
        # Note: Formula (25) in source: eta_k = eta_0 + sum gamma T(x)
        # This implies we add to the *prior* natural params. 
        # In continual setting, the "prior" for step t is the posterior from t-1.
        
        new_nu_df = old_nu_df + np.sum(weights)
        
        # Calculate sufficient statistics sum
        # T(s) = [s, s s^T]
        # eta_s = (kappa*m, V + kappa*m*m^T)
        # So we add sum(weights * s) to eta_s[0]
        # And sum(weights * s s^T) to eta_s[1]
        
        new_eta_s_0 = current_eta_s[0] + sum_s
        new_eta_s_1 = current_eta_s[1] + sum_ss
        
        # Reconstruct V from eta_s_1 and new_m
        # eta_s_1 = V + kappa * m * m^T
        # V = eta_s_1 - kappa * m * m^T
        new_V_s = new_eta_s_1 - new_kappa_s * np.outer(new_m_s, new_m_s)
        
        new_nu_s = (new_kappa_s, new_nu_df)
        new_eta_s = (new_eta_s_0, new_V_s + new_kappa_s * np.outer(new_m_s, new_m_s))
        
        # Update Color NIW (Sigma fixed)
        # Similar to spatial but Sigma_c is Delta
        # We only update mean mu_c
        old_kappa_c = components[k]['nu_c'][0]
        new_kappa_c = old_kappa_c + np.sum(weights)
        new_m_c = (components[k]['eta_c'][0] + np.sum(weights[:, None] * assigned_c, axis=0)) / new_kappa_c
        
        # Store color mean separately as Sigma is fixed
        # eta_c_0 = kappa * m
        new_eta_c_0 = new_kappa_c * new_m_c
        # eta_c_1 is V + kappa*m*m^T, but V is fixed? 
        # Source: "nk,c and Vk,c are kept fixed"
        # So we just update the mean part of the NIW representation for the Normal distribution over mu_c
        
        new_components.append({
            'eta_s': new_eta_s,
            'nu_s': new_nu_s,
            'eta_c': (new_eta_c_0, components[k]['eta_c'][1]), # Keep second part fixed
            'nu_c': (new_kappa_c, components[k]['nu_c'][1]), # Keep df fixed
            'alpha': components[k]['alpha'], # Update alpha if needed, usually Dirichlet update
            'mu_c_mean': new_m_c
        })
        
        # Update Dirichlet alpha
        # eta_z = alpha
        # alpha_new = alpha_0 + sum(weights)
        # Assuming alpha_0 is stored or is 1/K
        # Source: T(x)=1 for Dirichlet
        # alpha_new = alpha_old + sum(weights)
        new_alpha = components[k]['alpha'] + np.sum(weights)
        new_components[-1]['alpha'] = new_alpha

    # 3. Component Reassignment (if needed)
    # Identify unused components (alpha == prior_alpha)
    # Replace means with data points sampled by negative ELBO
    # This is a heuristic step, not part of standard CAVI
    if hyperparams.get('reassign'):
        reassign_fraction = hyperparams['reassign_fraction']
        # ... implementation of reassignment logic ...
        pass

    return new_components

def niw_expectations(eta, nu):
    """
    Compute E[mu] and E[Sigma] from NIW natural parameters.
    eta = (eta1, eta2), nu = (kappa, nu_df)
    """
    kappa = nu[0]
    nu_df = nu[1]
    eta1 = eta[0]
    eta2 = eta[1]
    
    # E[mu] = eta1 / kappa
    mu = eta1 / kappa
    
    # E[Sigma] = V / (nu_df - D - 1)
    # V = eta2 - kappa * mu * mu^T
    V = eta2 - kappa * np.outer(mu, mu)
    D = V.shape[0]
    Sigma = V / (nu_df - D - 1)
    
    return mu, Sigma

def mvn_log_prob(x, mu, Sigma):
    """Log probability of x under MVN(mu, Sigma)"""
    D = len(mu)
    diff = x - mu
    # Use log det and inverse
    sign, logdet = np.linalg.slogdet(Sigma)
    inv_Sigma = np.linalg.inv(Sigma)
    mahal = np.sum(diff @ inv_Sigma * diff, axis=1)
    log_prob = -0.5 * (D * np.log(2 * np.pi) + logdet + mahal)
    return log_prob

def dirichlet_log_prob(alpha):
    """E[log alpha_k] for Dirichlet(alpha)"""
    # psi is digamma
    return scipy.special.digamma(alpha) - scipy.special.digamma(np.sum(alpha))

def logsumexp(a, axis=None, keepdims=False):
    """Numerically stable log-sum-exp"""
    a_max = np.max(a, axis=axis, keepdims=True)
    tmp = np.exp(a - a_max)
    return np.log(np.sum(tmp, axis=axis, keepdims=True)) + a_max
```

**Parameters:**
*   $\epsilon$: Hyperparameter for the fixed covariance of the color component's Delta distribution, ensuring components commit to a particular color [S1, unofficial].
*   $K$: Number of mixture components (e.g., 10K, 100K) [S1, unofficial].
*   Reassign fraction: Fraction of unused components to reassign (e.g., 0.01 for Replica, 0.05 for Habitat) [S1, unofficial].
*   Learning rate: Not used in VBGS (closed-form), but used for Gradient baseline comparison (0.1) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Intractable Posterior:** Exact posterior is intractable; mean-field approximation is required to avoid combinatorial growth [S1, unofficial].
*   **Color Blending:** Without fixing color covariance, components might blend neighboring colors. Solved by using a Delta distribution for $q(\Sigma_{k,c})$ [S1, unofficial].
*   **Alpha Blending:** Standard alpha blending is not sensible as VBGS does not optimize on image reconstruction. Alpha is set to 1 for all Gaussians [S1, unofficial].
*   **Memory:** Memory requirements increase by a factor of 2 compared to gradient baseline due to distribution representation [S1, unofficial].
*   **Large-scale Data:** In large-scale 3D datasets, batched processing is necessary, which may reduce the speed advantage over gradient methods [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Model assignment is $O(nm)$ where $n$ is data points and $m$ is components. Parameter update is $O(n)$ [S1, unofficial].
*   **Memory Complexity:** Increased by a factor of 2 compared to gradient baseline (29 parameters per component vs 14) [S1, unofficial].
*   **Performance:** On Tiny ImageNet, VBGS wall-clock time is $0.03 \pm 0.03$ s vs Gradient $0.05 \pm 0.02$ s (RTX 4090) [S1, unofficial]. On Blender 3D Objects (100K components), VBGS (Data Init) PSNR ranges from 19.50 to 24.78 dB, comparable to Gradient (Data Init) [S1, unofficial]. In continual learning (Random Init), VBGS average reconstruction error is $11.19 \pm 3.53$ dB vs Gradient $21.26 \pm 1.76$ dB [S1, unofficial].
*   **Strengths:** Enables continual learning without catastrophic forgetting; no replay buffers needed; closed-form updates are fast for single-step updates [S1, unofficial].
*   **Limitations:** Requires RGBD data (not just RGB); memory intensive; batched processing reduces speed advantage on large datasets [S1, unofficial].
*   **When to Use:** Streaming data, robotics, AR, autonomous navigation where continual learning is required [S1, unofficial].
*   **When Not to Use:** Static scene reconstruction with full batch access where gradient-based 3DGS is more efficient and uses less memory [S1, unofficial].

## Background
VBGS was introduced as a novel approach to optimize Gaussian splats by framing training as variational inference, leveraging conjugacy properties of multivariate Gaussians [S1, unofficial]. It addresses the limitation of 3DGS which relies on backpropagation and struggles with catastrophic forgetting in continuous data streams [S1, unofficial]. The method is benchmarked on TinyImageNet, Blender 3D models, and Habitat scenes [S1, unofficial].
