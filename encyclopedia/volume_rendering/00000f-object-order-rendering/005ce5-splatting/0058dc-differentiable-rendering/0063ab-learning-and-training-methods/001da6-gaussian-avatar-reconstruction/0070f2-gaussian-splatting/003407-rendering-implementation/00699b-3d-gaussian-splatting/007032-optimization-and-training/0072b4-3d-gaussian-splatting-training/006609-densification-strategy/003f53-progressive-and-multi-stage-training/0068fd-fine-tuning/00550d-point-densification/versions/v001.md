# Point Densification

Also called: Clone and Split, Densification Strategies, Point Densitification

## Overview
Point densification is an adaptive optimization strategy in 3D Gaussian Splatting (3DGS) that dynamically controls the number of Gaussian primitives by converting a sparse initial set into a denser representation [S2]. It solves the problem of incomplete scene reconstruction caused by sparse Structure-from-Motion (SfM) initialization by filling empty areas and removing over-reconstructed regions [S2]. Unlike static initialization methods, it distinguishes between splitting large Gaussians for background reconstruction and cloning small Gaussians for thin structures [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Current set of 3D Gaussians $\{G_i\}$, each defined by position $\mathbf{p}_i$, covariance $\mathbf{\Sigma}_i$ (or rotation $\mathbf{R}_i$ and scale $\mathbf{s}_i$), opacity $\alpha_i$, and spherical harmonic coefficients for color. Gradient magnitudes $\nabla_{\mathbf{p}_i} \mathcal{L}$ and $\nabla_{\alpha_i} \mathcal{L}$ accumulated from rendering steps.
*   **Output:** Updated set of Gaussians with modified count, positions, and parameters.

**Data Structures:**
*   Gaussian attributes: $\mathbf{p} \in \mathbb{R}^3$, $\mathbf{q} \in \mathbb{R}^4$ (quaternion for rotation), $\mathbf{s} \in \mathbb{R}^3$ (scale), $\alpha \in \mathbb{R}$ (opacity), $\mathbf{c} \in \mathbb{R}^k$ (color coefficients).
*   Accumulated gradients: $\mathbf{g}_p$ (position), $\mathbf{g}_\alpha$ (opacity).

**Parameters:**
*   $N_{clone}$: Threshold for position gradient magnitude to trigger cloning.
*   $N_{split}$: Threshold for position gradient magnitude to trigger splitting.
*   $N_{opacity}$: Threshold for opacity to prune or reset.
*   $T_{interval}$: Number of training steps between densification checks.
*   *Note: Exact numerical values for thresholds are not given in the sources [S1, S2].*

**Steps:**
1.  **Accumulate Gradients:** During rendering, accumulate gradients for position and opacity for each Gaussian visible in the training views.
2.  **Check Interval:** If current step $t$ is a multiple of $T_{interval}$, proceed to densification; otherwise, skip.
3.  **Identify Candidates:**
    *   **Clone Candidates:** Gaussians with high position gradient magnitude ($\|\mathbf{g}_p\| > N_{clone}$) and low opacity ($\alpha < N_{opacity}$). These represent thin structures or areas needing finer detail without adding volume [S1].
    *   **Split Candidates:** Gaussians with high position gradient magnitude ($\|\mathbf{g}_p\| > N_{split}$) and large scale (volume exceeds a threshold). These represent areas needing higher resolution, particularly backgrounds [S1].
4.  **Execute Clone:** For each clone candidate $G_i$:
    *   Create a new Gaussian $G_{new}$ with identical parameters to $G_i$.
    *   Perturb the position $\mathbf{p}_{new}$ slightly (e.g., random noise or offset) to avoid exact overlap [G].
    *   Reset opacity $\alpha_{new}$ to a low initial value.
    *   Remove $G_i$ from the set (or keep it, depending on implementation; standard 3DGS usually keeps the parent and adds the child, but the source implies replacing or adding to allow convergence [S1]). *Correction based on standard 3DGS: Cloning typically adds a new Gaussian while keeping the original, or replaces it. The source says "cloning the small Gaussians... allows for better and faster convergence". We assume adding a copy.*
5.  **Execute Split:** For each split candidate $G_i$:
    *   Remove $G_i$ from the set.
    *   Create two new Gaussians $G_{a}, G_{b}$.
    *   Set positions $\mathbf{p}_a, \mathbf{p}_b$ to $\mathbf{p}_i \pm \delta \mathbf{v}$, where $\mathbf{v}$ is a random unit vector and $\delta$ is a small offset [G].
    *   Scale down the covariance (reduce scale $\mathbf{s}$) by a factor (e.g., 1.6) [G].
    *   Copy color and opacity from $G_i$.
    *   Add $G_a, G_b$ to the set.
6.  **Pruning (Implicit in Densification Pipeline):** Gaussians with opacity $\alpha < N_{opacity}$ are removed to prevent floaters [S2].

**Pseudocode:**
```python
def densify_gaussians(gaussians, gradients, step, interval, clone_thresh, split_thresh, opacity_thresh):
    if step % interval != 0:
        return gaussians

    to_clone = []
    to_split = []
    to_prune = []

    for g in gaussians:
        grad_norm = magnitude(gradients.position[g.id])
        
        # Pruning
        if g.opacity < opacity_thresh:
            to_prune.append(g.id)
            continue
            
        # Densification logic
        if grad_norm > clone_thresh and is_small(g):
            to_clone.append(g)
        elif grad_norm > split_thresh and is_large(g):
            to_split.append(g)

    # Execute Pruning
    for gid in to_prune:
        gaussians.remove(gid)

    # Execute Clone
    for g in to_clone:
        new_g = clone(g)
        new_g.position += random_noise() # [G]
        new_g.opacity = initial_opacity
        gaussians.add(new_g)

    # Execute Split
    for g in to_split:
        gaussians.remove(g)
        g1, g2 = split(g)
        gaussians.add(g1)
        gaussians.add(g2)

    return gaussians

def is_small(g):
    # Check if scale/volume is below a threshold
    return volume(g.covariance) < small_threshold # [G]

def is_large(g):
    # Check if scale/volume is above a threshold
    return volume(g.covariance) > large_threshold # [G]
```

## Subtopics

### Exponentially Ascending Gradient Threshold
Uses a dynamic threshold that increases over time to control densification rate, differing from fixed thresholds. [Link](9684-exponentially-ascending-gradient-threshold.md)

### SplatFormer Training Objective & Refinement
Integrates densification with a transformer-based refinement, focusing on structural consistency rather than just gradient magnitude. [Link](11745-splatformer-training-objective-refinement.md)

### MCMC-based 3DGS / SGLD for 3DGS
Uses stochastic gradient Langevin dynamics for densification, providing a probabilistic approach to point placement. [Link](11917-mcmc-based-3dgs-sgld-for-3dgs.md)

### Error-Guided Redistribution
Densifies points based on rendering error maps rather than gradients, targeting visible artifacts directly. [Link](14037-error-guided-redistribution.md)

### Localized Point Management (LPM)
Manages point density locally using spatial hashing, reducing global memory overhead during densification. [Link](17850-localized-point-management-lpm.md)

## Operating characteristics
*   **Time Complexity:** $O(N)$ per densification step, where $N$ is the number of Gaussians. Densification occurs only at intervals $T_{interval}$, so average cost is $O(N / T_{interval})$ per step.
*   **Memory Complexity:** Increases linearly with the number of cloned/split Gaussians. Pruning helps bound this growth.
*   **Strengths:** Effectively fills gaps in sparse SfM initialization; adapts to scene complexity; fast convergence for thin structures via cloning [S1].
*   **Limitations:** Relies on accurate gradient accumulation; can introduce floaters if opacity pruning is insufficient; original method struggles with sky/distant areas if initialization is poor [S2].
*   **When to use:** When initial SfM points are sparse or unevenly distributed; when thin structures (e.g., wires, branches) are present.
*   **When not to use:** When initialization is dense and uniform; when computational budget is extremely tight and densification overhead is prohibitive.

## Background
Point densification was introduced as a key contribution in the original 3D Gaussian Splatting paper [S1]. It was designed to mitigate the dependency on high-quality initial SfM points by allowing the Gaussian set to adaptively grow. The method distinguishes between splitting (for background/geometry) and cloning (for thin structures/convergence speed) [S1]. Later works like HO-Gaussian noted that the original method relies on accurate initialization and can leave holes in low-texture or sky regions, leading to hybrid optimization approaches that incorporate densification at regular intervals to populate problematic regions [S2].
