# 3D Language Gaussian Splatting

Also called: LangSplat
## Overview
3D Language Gaussian Splatting (LangSplat) constructs a 3D language field using 3D Gaussians to enable precise, efficient open-vocabulary querying in 3D spaces [S1]. It addresses the imprecise boundaries and slow rendering speeds of NeRF-based methods like LERF by leveraging tile-based splatting and a scene-specific autoencoder to compress high-dimensional CLIP embeddings into a low-dimensional latent space [S1].
## How it works
### Inputs and Outputs
**Inputs:**
*   A set of $T$ multi-view 2D images $\{I_t\}_{t=1}^T$ of a 3D scene.
*   Camera poses for each input image.
*   A text query (optional, for inference).

**Outputs:**
*   A set of 3D language Gaussians, each defined by mean $\mu$, covariance $\Sigma$, opacity $\alpha$, and three latent language embeddings $\{f^s, f^p, f^w\} \in \mathbb{R}^d$.
*   Rendered 2D language feature maps $\mathbf{F}^l$ for semantic levels $l \in \{s, p, w\}$.
*   Recovered CLIP embeddings $\Psi(\mathbf{F}^l)$ for open-vocabulary querying.

### Data Structures
**3D Language Gaussian $G_i$:**
*   $\mu_i \in \mathbb{R}^3$: Mean position.
*   $\Sigma_i \in \mathbb{R}^{3 \times 3}$: Covariance matrix (often parameterized by rotation $R$ and scale $S$).
*   $\alpha_i \in [0, 1]$: Opacity.
*   $f^s_i, f^p_i, f^w_i \in \mathbb{R}^d$: Latent language embeddings for subpart, part, and whole semantic levels.
*   Note: The dimension $d$ is significantly smaller than the original CLIP dimension $D$ (typically $d=3$).

**Scene-Specific Autoencoder:**
*   Encoder $E: \mathbb{R}^D \to \mathbb{R}^d$.
*   Decoder $\Psi: \mathbb{R}^d \to \mathbb{R}^D$.

### Steps

1.  **Hierarchical Semantic Extraction:**
    For each input image $I_t$:
    a.  Feed a regular grid of $32 \times 32$ point prompts into the Segment Anything Model (SAM) to obtain initial masks at three semantic levels: subpart ($M^0_s$), part ($M^0_p$), and whole ($M^0_w$) [S1].
    b.  Remove redundant masks from each set based on predicted IoU score, stability score, and overlap rate [S1].
    c.  Perform comprehensive full-image segmentation for each filtered mask set to generate three segmentation maps: $M^s_t, M^p_t, M^w_t$ [S1].
    d.  Extract CLIP features for each segmented region using the CLIP image encoder $V$ to obtain pixel-aligned language embeddings $\mathbf{L}^l_t(v)$:
        $$ \mathbf{L}^l_t(v) = V(I_t \odot M^l_t(v)), \quad l \in \{s, p, w\} $$
        where $M^l_t(v)$ is the mask region pixel $v$ belongs to at semantic level $l$ [S1].

2.  **Autoencoder Training:**
    Train a lightweight scene-wise autoencoder to map high-dimensional CLIP features to a low-dimensional latent space:
    a.  The encoder $E$ maps $\mathbf{L}^l_t(v) \in \mathbb{R}^D$ to $\mathbf{H}^l_t(v) = E(\mathbf{L}^l_t(v)) \in \mathbb{R}^d$.
    b.  The decoder $\Psi$ reconstructs the original embeddings.
    c.  Minimize the reconstruction loss $\mathcal{L}_{ae}$ using both L1 and cosine distance:
        $$ \mathcal{L}_{ae} = \sum_{l \in \{s,p,w\}} \sum_{t=1}^T d_{ae}(\Psi(E(\mathbf{L}^l_t(v))), \mathbf{L}^l_t(v)) $$
        where $d_{ae}()$ combines L1 and cosine distance [S1].
    d.  Transform all CLIP embeddings $\{\mathbf{L}^l_t\}$ into scene-specific latent features $\{\mathbf{H}^l_t\}$ using the trained encoder $E$ [S1].

3.  **Gaussian Initialization and Optimization:**
    a.  Initialize 3D Gaussians using standard 3D Gaussian Splatting initialization (e.g., from SfM points) [S1].
    b.  Augment each Gaussian $G_i$ with three language embeddings $\{f^s_i, f^p_i, f^w_i\}$ in the latent space $\mathbb{R}^d$ [S1].
    c.  Render the language embeddings to 2D using tile-based splatting. For a pixel $v$ and semantic level $l$:
        $$ \mathbf{F}^l(v) = \sum_{i \in \mathcal{N}} \mathbf{f}^l_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
        where $\mathcal{N}$ is the set of Gaussians in the tile, $\mathbf{f}^l_i$ is the language embedding of the $i$-th Gaussian, and $\alpha_i = o_i G^{2D}_i(v)$ is the projected opacity [S1].
    d.  Optimize Gaussian parameters by minimizing the language loss $\mathcal{L}_{lang}$:
        $$ \mathcal{L}_{lang} = \sum_{l \in \{s,p,w\}} \sum_{t=1}^T d_{lang}(\mathbf{F}^l_t(v), \mathbf{H}^l_t(v)) $$
        where $d_{lang}()$ is the distance function for 3D Language Gaussians (typically cosine or L1) [S1].

4.  **Inference and Querying:**
    a.  Render language embeddings $\mathbf{F}^l$ from 3D to 2D.
    b.  Use the trained decoder $\Psi$ to recover CLIP embeddings $\Psi(\mathbf{F}^l_t) \in \mathbb{R}^D$ [S1].
    c.  Compute relevancy scores for a text query $\phi_{qry}$ against rendered embeddings $\phi_{img}$:
        $$ \text{score} = \min_i \frac{\exp(\phi_{img} \cdot \phi_{qry})}{\exp(\phi_{img} \cdot \phi_{qry}) + \exp(\phi_{img} \cdot \phi^{\text{canon}}_i)} $$
        where $\phi^{\text{canon}}_i$ are CLIP embeddings of predefined canonical phrases ("object", "things", "stuff", "texture") [S1].
    d.  Select the semantic level ($s, p, w$) yielding the highest relevancy score [S1].
    e.  For localization, choose the point with the highest relevance score. For segmentation, filter points below a threshold [S1].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class LangSplat:
    def __init__(self, clip_dim=512, latent_dim=3, num_views=100):
        self.clip_dim = clip_dim
        self.latent_dim = latent_dim
        self.num_views = num_views
        
        # Scene-specific autoencoder
        self.encoder = nn.Sequential(
            nn.Linear(clip_dim, 256),
            nn.ReLU(),
            nn.Linear(256, latent_dim)
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.ReLU(),
            nn.Linear(256, clip_dim)
        )
        
        # 3D Gaussians (simplified representation)
        # Each Gaussian has: mean (3), cov (6 for symmetric), opacity (1), 
        # and 3 latent features (3 * latent_dim)
        self.gaussians = None 
        
        # SAM and CLIP models would be loaded externally
        self.sam_model = None 
        self.clip_encoder = None 

    def extract_hierarchical_semantics(self, images):
        """
        Extracts hierarchical semantic masks and CLIP features for a batch of images.
        Returns: dict of {level: tensor of shape (T, H, W, D)}
        """
        features = {'s': [], 'p': [], 'w': []}
        
        for img in images:
            # 1. SAM Segmentation
            # Feed 32x32 grid prompts to SAM
            masks_s, masks_p, masks_w = self.sam_model.segment_grid_prompts(img)
            
            # 2. Filter redundant masks
            masks_s = self.filter_masks(masks_s)
            masks_p = self.filter_masks(masks_p)
            masks_w = self.filter_masks(masks_w)
            
            # 3. Full-image segmentation maps
            seg_map_s = self.full_segmentation(masks_s)
            seg_map_p = self.full_segmentation(masks_p)
            seg_map_w = self.full_segmentation(masks_w)
            
            # 4. Extract CLIP features
            # V is CLIP image encoder, I is image, M is mask
            feat_s = self.clip_encoder(img * seg_map_s)
            feat_p = self.clip_encoder(img * seg_map_p)
            feat_w = self.clip_encoder(img * seg_map_w)
            
            features['s'].append(feat_s)
            features['p'].append(feat_p)
            features['w'].append(feat_w)
            
        return {k: torch.stack(v) for k, v in features.items()}

    def train_autoencoder(self, clip_features):
        """
        Trains the scene-specific autoencoder on CLIP features.
        clip_features: dict of {level: tensor (T, H, W, D)}
        """
        self.encoder.train()
        self.decoder.train()
        
        total_loss = 0
        for level in ['s', 'p', 'w']:
            feats = clip_features[level] # (T, H, W, D)
            # Flatten for training
            feats_flat = feats.view(-1, self.clip_dim)
            
            # Encode
            latent = self.encoder(feats_flat)
            # Decode
            recon = self.decoder(latent)
            
            # Loss: L1 + Cosine
            l1_loss = F.l1_loss(recon, feats_flat)
            cosine_loss = 1 - F.cosine_similarity(recon, feats_flat, dim=1).mean()
            
            total_loss += l1_loss + cosine_loss
            
        total_loss.backward()
        # Optimizer step would be called here
        return total_loss.item()

    def render_language_features(self, gaussians, camera):
        """
        Renders language features using tile-based splatting.
        gaussians: list of Gaussian objects
        camera: camera parameters
        Returns: dict of {level: tensor (H, W, D)}
        """
        rendered = {'s': None, 'p': None, 'w': None}
        
        for level in ['s', 'p', 'w']:
            # Get latent features for this level from all Gaussians
            f_level = torch.stack([g.f[level] for g in gaussians]) # (N, d)
            alphas = torch.stack([g.alpha * g.projected_opacity(camera) for g in gaussians]) # (N)
            
            # Tile-based rasterization
            # This is a simplified representation of the standard 3DGS rasterizer
            # In practice, this involves sorting Gaussians per tile and alpha blending
            rendered[level] = self.tile_rasterizer(f_level, alphas, gaussians, camera)
            
        return rendered

    def optimize_gaussians(self, gaussians, target_latents, camera):
        """
        Optimizes 3D Gaussians to match target latent features.
        target_latents: dict of {level: tensor (T, H, W, d)}
        """
        rendered = self.render_language_features(gaussians, camera)
        
        total_loss = 0
        for level in ['s', 'p', 'w']:
            # Target is the encoded CLIP feature from training step
            target = target_latents[level]
            pred = rendered[level]
            
            # Language loss (cosine or L1)
            loss = F.cosine_similarity(pred, target, dim=-1).mean() # Simplified
            total_loss += loss
            
        total_loss.backward()
        # Optimizer step would be called here
        return total_loss.item()

    def query(self, rendered_features, text_query):
        """
        Performs open-vocabulary query on rendered features.
        rendered_features: dict of {level: tensor (H, W, D)} (decoded)
        text_query: string
        Returns: dict of {level: tensor (H, W)} relevancy scores
        """
        # Encode text query
        phi_qry = self.clip_text_encoder(text_query)
        
        # Canonical phrases
        canonical_phrases = ["object", "things", "stuff", "texture"]
        phi_canon = torch.stack([self.clip_text_encoder(p) for p in canonical_phrases])
        
        scores = {}
        for level, feat_2d in rendered_features.items():
            # feat_2d: (H, W, D)
            # Compute cosine similarity with query
            sim_q = F.cosine_similarity(feat_2d, phi_qry, dim=-1) # (H, W)
            
            # Compute min similarity with canonical phrases
            sims_canon = [F.cosine_similarity(feat_2d, phi_c, dim=-1) for phi_c in phi_canon]
            sim_min_canon = torch.stack(sims_canon).min(dim=0)[0] # (H, W)
            
            # Relevancy score
            # score = min(exp(sim_q) / (exp(sim_q) + exp(sim_min_canon)))
            # Note: The formula in source uses min over i of the softmax-like term
            # Here we approximate the min over canonical phrases
            exp_q = torch.exp(sim_q)
            exp_c = torch.exp(sim_min_canon)
            score = exp_q / (exp_q + exp_c)
            
            scores[level] = score
            
        return scores
```

### Parameters
*   **$d$**: Dimension of the scene-specific latent space. Typical value: $d=3$ [S1].
*   **$D$**: Dimension of the CLIP embedding space (typically 512) [S1].
*   **$\phi^{\text{canon}}$**: CLIP embeddings of predefined canonical phrases chosen from 'object', 'things', 'stuff', and 'texture' [S1].
*   **Grid Size**: $32 \times 32$ point prompts for SAM [S1].

### Pitfalls
*   **Memory Exhaustion**: Directly learning 512-dimensional CLIP features increases memory requirements for storing 3D Gaussians by over 35 times compared to RGB colors without spherical harmonics, easily leading to L1 cache memory exhaustion [S1].
*   **Point Ambiguity**: Without hierarchical segmentation, points may lack precise semantic context, leading to vague language fields [S1].

## Operating characteristics
*   **Speed**: LangSplat is 199x faster than LERF at 1440x1080 resolution [S1].
*   **Memory**: Significantly reduced memory cost compared to directly modeling D-dimensional CLIP embeddings by using a scene-specific autoencoder to compress features to latent space $d$ [S1].
*   **Accuracy**:
    *   Localization accuracy on LERF dataset: LangSplat 84.3% overall vs LERF 73.6% vs LSeg 21.1% [S1].
    *   3D semantic segmentation IoU on LERF dataset: LangSplat 51.4% overall vs LERF 37.4% vs LSeg 16.6% [S1].
*   **Strengths**: Precise object boundaries, efficient real-time rendering, open-vocabulary querying without extensive scale search [S1].
*   **Limitations**: Requires SAM and CLIP models for preprocessing; dependent on the quality of SAM segmentation [S1].
