# Scaffold-GS

Also called: Scaffold-Gaussian Splatting, Structured 3D Gaussians, Structured 3D Gaussians for View-Adaptive Rendering

## Overview
Scaffold-GS is a Gaussian-based scene representation that utilizes anchor points to establish a hierarchical and region-aware 3D scene structure, predicting neural Gaussian attributes on-the-fly based on viewing direction and distance [S2]. Unlike vanilla 3D-GS, which allows Gaussians to drift and split freely, Scaffold-GS exploits scene structure to guide and constrain Gaussian distribution while allowing local adaptation to varying viewing angles [S2]. It achieves comparable or superior reconstruction quality to 3D-GS with significantly reduced storage requirements and real-time rendering speeds [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Sparse Structure-from-Motion (SfM) point cloud $P \in \mathbb{R}^{M \times 3}$ [S2].
*   **Output:** A set of anchor points with learnable features, and a rendering pipeline that dynamically spawns and rasterizes neural Gaussians [S2].

**Data Structures:**
1.  **Voxel Grid:** Created from SfM points. Centers $V \in \mathbb{R}^{N \times 3}$ are computed by voxelizing $P$ with size $\epsilon$ and removing duplicates [S2].
2.  **Anchor Point $v$:** Each voxel center $v$ is an anchor point equipped with:
    *   Local context feature $f_v \in \mathbb{R}^{32}$ [S2].
    *   Scaling factor $l_v \in \mathbb{R}^3$ [S2].
    *   $k$ learnable offsets $O_v \in \mathbb{R}^{k \times 3}$ [S2].
3.  **Neural Gaussian:** A 3D Gaussian defined by position $\mu$, opacity $\alpha$, covariance-related quaternion $q$, scaling $s$, and color $c$ [S2].

**Method Steps:**

1.  **Anchor Initialization:**
    Voxelize the input SfM point cloud $P$ to create voxel centers $V$:
    $$ V = \left\{ \lfloor P / \epsilon \rfloor \cdot \epsilon \right\} $$
    Remove duplicate entries to reduce redundancy [S2].

2.  **Neural Gaussian Derivation (On-the-fly Prediction):**
    For each visible anchor $v$ within the viewing frustum:
    a.  **Feature Bank Creation:** Create a multi-resolution feature bank $\{f_v, f_{v\downarrow1}, f_{v\downarrow2}\}$, where $\downarrow n$ denotes $f_v$ down-sampled by $2^n$ factors [S2].
    b.  **View-Dependent Blending:** Calculate relative distance $\delta_{vc}$ and viewing direction $\vec{d}_{vc}$ between anchor $x_v$ and camera $x_c$:
        $$ \delta_{vc} = \|x_v - x_c\|_2, \quad \vec{d}_{vc} = \frac{x_v - x_c}{\|x_v - x_c\|_2} $$
        Predict blending weights using a 2-layer MLP $F_w$ (hidden dim 32, ReLU):
        $$ \{w, w_1, w_2\} = \text{Softmax}(F_w(\delta_{vc}, \vec{d}_{vc})) $$
        Compute integrated feature:
        $$ \hat{f}_v = w \cdot f_v + w_1 \cdot f_{v\downarrow1} + w_2 \cdot f_{v\downarrow2} $$
    c.  **Spawn Neural Gaussians:** Spawn $k$ neural Gaussians from anchor $x_v$. Positions are calculated as:
        $$ \{\mu_0, \dots, \mu_{k-1}\} = x_v + \{O_0, \dots, O_{k-1}\} \cdot l_v $$
        where $O_i$ are learnable offsets and $l_v$ is the scaling factor [S2].
    d.  **Attribute Decoding:** Decode attributes ($\alpha, c, q, s$) in one-pass from $\hat{f}_v$, $\delta_{vc}$, and $\vec{d}_{vc}$ via MLPs $F_\alpha, F_c, F_q, F_s$ (all 2-layer MLPs, hidden dim 32, ReLU). Example for opacity:
        $$ \{\alpha_0, \dots, \alpha_{k-1}\} = F_\alpha(\hat{f}_v, \delta_{vc}, \vec{d}_{vc}) $$
        Colors, quaternions, and scales are derived similarly [S2].
    e.  **Filtering:** Only keep neural Gaussians with opacity $\alpha \geq \tau_\alpha$ to cut computational load [S2].

3.  **Anchor Refinement (Growing and Pruning):**
    Performed every $N$ training iterations [S2].
    a.  **Growing:** Quantize neural Gaussians into multi-resolution voxels of size $\epsilon_g^{(m)} = \epsilon_g / 4^{m-1}$ for levels $m \in \{1, 2, 3\}$. Compute averaged gradients $\nabla_g$ over $N$ iterations. If $\nabla_g > \tau_g^{(m)} = \tau_g \cdot 2^{m-1}$, deploy a new anchor at the voxel center if none exists. Apply random elimination to candidates to curb rapid expansion [S2].
    b.  **Pruning:** Accumulate opacity values of neural Gaussians associated with an anchor over $N$ iterations. If accumulated opacity $< 0.5$, remove the anchor [S2].

4.  **Rendering:**
    Project 3D Gaussians to 2D ellipses. The covariance matrix $\Sigma$ is formulated as $\Sigma = RSS^T R^T$ to maintain positive semi-definiteness [S2]. Render via alpha-blending of sorted 2D Gaussians:
    $$ C(x') = \sum_{i \in N} c_i \sigma_i \prod_{j=1}^{i-1} (1 - \sigma_j) $$
    where $\sigma_i = \alpha_i G'_i(x')$ and $G'(x')$ is the 2D Gaussian [S2].

5.  **Optimization:**
    Minimize total loss:
    $$ L = L_1 + \lambda_{SSIM} L_{SSIM} + \lambda_{vol} L_{vol} $$
    where $\lambda_{SSIM} = 0.2$ and $\lambda_{vol} = 0.001$ [S2].

**Parameters:**
*   $k$: Number of neural Gaussians per anchor. Default: 10 [S2].
*   $\tau_\alpha$: Opacity threshold for rasterization. Not given in the sources.
*   $N$: Iterations for gradient/opacity averaging. Default: 100 [S2].
*   $\tau_g$: Gradient threshold for growing. Default: $64\epsilon$. For intricate/texture-less scenes: $16\epsilon$ [S2].
*   $\epsilon$: Voxel size for initialization. Not given in the sources.
*   $\epsilon_g$: Voxel size for growing quantization. Not given in the sources.

**Pseudocode:**

```python
import numpy as np

def scaffold_gs_render(sfm_points, camera, epsilon, k, tau_alpha, tau_g, N, epsilon_g):
    """
    Renders a frame using Scaffold-GS.
    Note: This pseudocode assumes the anchor grid and MLPs are already initialized/trained.
    """
    # 1. Initialize Anchor Grid (One-time or during refinement)
    # Voxelize SfM points
    voxel_centers = np.unique(np.floor(sfm_points / epsilon) * epsilon, axis=0)
    anchors = []
    for v in voxel_centers:
        # Each anchor has f_v (32), l_v (3), O_v (k x 3)
        # These are learnable parameters stored in the model
        anchors.append(Anchor(v))
    
    # 2. For each visible anchor, spawn and render neural Gaussians
    all_gaussians = []
    
    for anchor in anchors:
        # Check if anchor is in view frustum (omitted for brevity)
        
        # Calculate view-dependent info
        delta_vc = np.linalg.norm(anchor.pos - camera.pos)
        d_vc = (anchor.pos - camera.pos) / delta_vc
        
        # Feature blending
        # f_v_down1, f_v_down2 are pre-computed down-sampled features
        weights = softmax(MLP_Fw(delta_vc, d_vc))
        f_hat = weights[0]*anchor.f_v + weights[1]*anchor.f_v_down1 + weights[2]*anchor.f_v_down2
        
        # Spawn k Gaussians
        for i in range(k):
            # Position
            mu = anchor.pos + anchor.O_v[i] * anchor.l_v
            
            # Attributes via MLPs
            alpha = MLP_Falpha(f_hat, delta_vc, d_vc)[i]
            color = MLP_Fc(f_hat, delta_vc, d_vc)[i]
            quat = MLP_Fq(f_hat, delta_vc, d_vc)[i]
            scale = MLP_Fs(f_hat, delta_vc, d_vc)[i]
            
            # Filter by opacity
            if alpha >= tau_alpha:
                all_gaussians.append(Gaussian(mu, alpha, color, quat, scale))
    
    # 3. Rasterize
    # Project to 2D, sort by depth, alpha blend
    image = tile_based_rasterize(all_gaussians, camera)
    return image

def scaffold_gs_refine(anchors, gaussians, gradients, opacities, N, tau_g, epsilon_g):
    """
    Refines anchors based on accumulated gradients and opacities.
    """
    # Growing
    # Quantize Gaussians into voxels of size epsilon_g^(m)
    for m in [1, 2, 3]:
        voxel_size = epsilon_g / (4 ** (m - 1))
        threshold = tau_g * (2 ** (m - 1))
        
        # Compute avg gradients per voxel
        voxel_gradients = compute_voxel_gradients(gaussians, voxel_size)
        
        for voxel, grad in voxel_gradients.items():
            if grad > threshold and not voxel_has_anchor(voxel):
                # Add new anchor with random initialization
                add_anchor(voxel.center)
                
    # Pruning
    for anchor in anchors:
        if anchor.accumulated_opacity < 0.5:
            remove_anchor(anchor)
```

## Operating characteristics
*   **Time Complexity:** Rendering speed is around 100 FPS at 1K resolution, comparable to original 3D-GS with little computational overhead [S2].
*   **Memory Complexity:** Storage is significantly reduced. On Mip-NeRF360, storage is reduced by 4.4x; on Deep Blending, by 10.2x compared to 3D-GS [S2].
*   **Performance:** Achieves comparable PSNR/SSIM to 3D-GS on Mip-NeRF360 but surpasses SOTA on Tanks&Temples and DeepBlending [S2].
*   **Strengths:** Robust to view changes, compact storage, real-time rendering [S2].
*   **Limitations:** Relies on initial SfM points; performance may vary if SfM initialization is poor (though refinement helps) [S2].

## Background
Scaffold-GS was introduced by Tao Lu, Mulin Yu, Linning Xu, Yuanbo Xiangli, Limin Wang, Dahua Lin, and Bo Dai from the Shanghai Artificial Intelligence Laboratory, The Chinese University of Hong Kong, Nanjing University, and Cornell University [S2]. It was published on arXiv on November 30, 2023, and later in CVPR 2024 [S2]. The method addresses the limitations of vanilla 3D-GS, such as unstructured Gaussian distribution and high storage costs, by introducing a structured, anchor-based representation [S2].
