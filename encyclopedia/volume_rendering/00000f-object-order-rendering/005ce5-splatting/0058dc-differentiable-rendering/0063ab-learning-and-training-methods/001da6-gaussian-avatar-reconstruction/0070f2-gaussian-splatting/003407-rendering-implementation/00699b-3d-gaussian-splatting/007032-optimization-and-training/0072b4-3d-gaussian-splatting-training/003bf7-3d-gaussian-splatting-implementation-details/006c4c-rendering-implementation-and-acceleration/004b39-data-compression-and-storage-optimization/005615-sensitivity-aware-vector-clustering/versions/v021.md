# Sensitivity-Aware Vector Clustering

Also called: Niedemayr et al. compression, Niedermayr, Sensitivity-Aware Scene Compression, Sensitivity-Aware Vector Clustering for 3DGS Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering spherical harmonic (SH) coefficients and Gaussian shape parameters (scale and rotation) into compact codebooks [S1, S2]. It distinguishes itself from standard post-training quantization by deriving a sensitivity measure for each scene parameter to guide the clustering process, prioritizing the preservation of parameters that significantly affect image quality [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of optimized 3D Gaussians $\{G_i\}_{i=1}^N$ with positions, opacities, scales, rotations, and SH coefficients for color. A set of training images with known camera parameters.
*   **Output:** Two codebooks (one for SH coefficients, one for shape parameters) and a compressed representation of the scene where each Gaussian is defined by indices into these codebooks, along with uncompressed position, opacity, and scale factors.

**Data Structures:**
1.  **Codebook Entry (Shape):** 4 scalar values for a quaternion (rotation) plus 3 scalar values for scaling (normalized scale vector and scalar magnitude) [S1].
2.  **Codebook Entry (Color):** Vector of SH coefficients [S1].
3.  **Scene Representation:** For each Gaussian, two 32-bit unsigned integer indices pointing to the respective codebook entries, stored alongside uncompressed position, opacity, and scalar scale [S1].

**Sensitivity Calculation:**
The sensitivity $S(p)$ of a parameter $p$ is calculated to determine its contribution to the training images [S1, S2]. It is defined as:
$$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p_i}}{\sum_{i=1}^{N} P_i} $$
where $N$ is the number of training images, $E_i$ is the total image energy (sum of RGB components) for image $i$, and $P_i$ is the number of pixels in image $i$ [S1, S2]. The gradient $\frac{\partial E_i}{\partial p_i}$ is computed via a single backward pass over each training image [S1].

For a vector $x$ (e.g., a set of SH coefficients or a shape parameter vector), the sensitivity $S(x)$ is defined as the maximum sensitivity over its components $d$:
$$ S(x) = \max_d S(x_d) $$
where $S(x_d)$ is the sensitivity of component $d$ [S1].

**Clustering Algorithm (Sensitivity-Aware k-Means):**
The method uses two separate codebooks: one for SH coefficients (color) and one for Gaussian shape features (scale and rotation) [S1].

1.  **Initialization:** Codebooks are initialized randomly with a uniform distribution within the minimum and maximum values of each parameter [S1]. The codebook size $K$ is typically 4096 [S1].
2.  **Sensitivity Thresholding:** SH vectors (and shape vectors) with sensitivity higher than a threshold $\beta_c$ (typically $6 \cdot 10^{-7}$ for SH, $3 \cdot 10^{-6}$ for shape) are identified [S1]. These high-sensitivity vectors are not clustered but are added directly to the codebook to preserve critical details [S1, S2].
3.  **Weighted Distance:** For the remaining vectors, the distance between a vector $x$ and a centroid $c_k$ is weighted by the vector's sensitivity:
    $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
    [S1].
4.  **Assignment:** Each vector is assigned to the centroid with the minimum weighted distance [S1].
5.  **Centroid Update:** Centroids are updated using a weighted average of the assigned vectors:
    $$ c_k = \frac{1}{\sum_{x_i \in A(k)} S(x_i)} \sum_{x_i \in A(k)} S(x_i) x_i $$
    where $A(k)$ is the set of vectors assigned to centroid $c_k$ [S1].
6.  **Batched Clustering:** To handle large datasets, a batched strategy is used [S1]. In each update step, a random subset of vectors is picked. The centroids are updated using a moving average with a decay factor $\lambda_d$ (typically 0.8) [S1].
    *   Batch size for color features: $2^{18}$ [S1].
    *   Batch size for Gaussian parameters: $2^{20}$ [S1]
7.  **Normalization:** Clustering normalized covariance matrices can lead to floating-point errors resulting in non-unit scaling vectors. After each update step, each codebook vector is re-normalized by dividing it through the trace of the covariance metric [S1].
8.  **Decomposition:** After clustering, each codebook entry for shape is decomposed into rotation (quaternion) and scale parameters using eigenvalue decomposition, as direct optimization of the matrix is not possible [S1].

**Quantization-Aware Training (Fine-Tuning):**
To recover information lost during clustering, parameters are fine-tuned on the training set using quantization-aware training [S1, S2].
1.  **Forward Pass:** Quantization is simulated considering a certain number of bits and the moving average of each parameter's min/max values [S2].
2.  **Backward Pass:** The simulated quantization is ignored, and the gradient for the parameter is calculated without quantization [S2].
3.  **Optimization:** 5000 optimization steps are typically performed [S1]. The loss function may include a D-SSIM term with weight $\lambda$ (typically 0.2) [S2].

**Compression and Encoding:**
1.  **Linearization:** Gaussians are ordered by their positions along a Z-order curve (Morton order) to exploit spatial coherence [S1, S2].
2.  **Entropy Encoding:** The set of Gaussians and codebooks are compressed using DEFLATE (LZ77 + Huffman coding) [S1, S2].

import numpy as np

def calculate_sensitivity(gradient_sum, pixel_counts):
    """
    Calculate sensitivity S(p) for a parameter p.
    gradient_sum: Sum of gradients dE/dp over all training images.
    pixel_counts: Sum of pixels P_i over all training images.
    """
    return gradient_sum / pixel_counts

def sensitivity_aware_kmeans(vectors, sensitivities, k, decay_factor, batch_size, max_iterations):
    """
    Perform sensitivity-aware k-Means clustering.
    vectors: Array of shape (N, D) containing the vectors to cluster.
    sensitivities: Array of shape (N,) containing sensitivity S(x) for each vector.
    k: Number of centroids (codebook size).
    decay_factor: Lambda_d for moving average update.
    batch_size: Number of vectors per update step.
    max_iterations: Maximum number of update steps.
    """
    n, d = vectors.shape
    # Initialize centroids randomly within min/max of vectors
    centroids = np.random.uniform(vectors.min(axis=0), vectors.max(axis=0), size=(k, d))
    
    for iteration in range(max_iterations):
        # Pick a random subset of vectors
        indices = np.random.choice(n, size=min(batch_size, n), replace=False)
        batch_vectors = vectors[indices]
        batch_sensitivities = sensitivities[indices]
        
        # Assign vectors to nearest centroid using weighted distance
        # D(x, ck) = S(x) * ||x - ck||^2
        # We minimize this, which is equivalent to minimizing S(x) * ||x - ck||^2
        # Distance matrix: (batch_size, k)
        # Expand dims for broadcasting: (batch_size, 1, D) - (1, k, D)
        diff = batch_vectors[:, np.newaxis, :] - centroids[np.newaxis, :, :]
        sq_dist = np.sum(diff ** 2, axis=2) # (batch_size, k)
        weighted_dist = sq_dist * batch_sensitivities[:, np.newaxis]
        
        assignments = np.argmin(weighted_dist, axis=1)
        
        # Update centroids using moving average
        new_centroids = centroids.copy()
        for j in range(k):
            mask = assignments == j
            if np.sum(mask) > 0:
                assigned_vectors = batch_vectors[mask]
                assigned_sens = batch_sensitivities[mask]
                # Weighted average
                sum_sens = np.sum(assigned_sens)
                weighted_sum = np.sum(assigned_vectors * assigned_sens[:, np.newaxis], axis=0)
                new_centroid = weighted_sum / sum_sens
                
                # Re-normalize if necessary (for shape parameters)
                # Assuming new_centroid represents a covariance matrix or similar structure
                # For simplicity, if it's a vector, we might need specific normalization logic
                # based on the source's mention of trace of covariance metric.
                # Here we assume a generic re-normalization step if needed.
                # new_centroid = re_normalize(new_centroid) 
                
                # Moving average update
                new_centroids[j] = (1 - decay_factor) * centroids[j] + decay_factor * new_centroid
        
        centroids = new_centroids
        
    return centroids

## Operating characteristics
*   **Compression Ratio:** Achieves compression rates of up to 31× on real-world scenes with minimal visual degradation [S1].
*   **Rendering Performance:** Enables real-time rendering on lightweight GPUs, achieving up to 4× higher framerates than the baseline optimized GPU compute pipeline [S1].
*   **Memory:** Significantly reduces VRAM usage by replacing high-precision SH coefficients and shape parameters with compact indices [S1].
*   **Strengths:** Preserves high-frequency details by excluding high-sensitivity parameters from clustering; efficient batched clustering allows scalability; quantization-aware training recovers quality loss [S1, S2].
*   **Limitations:** Requires an initial training phase for sensitivity calculation and fine-tuning; clustering is an approximation and may introduce artifacts if sensitivity thresholds are not tuned correctly [S1].
*   **When to use:** When storage or bandwidth constraints are critical, and real-time rendering on low-power devices is required [S1].
*   **When not to use:** When maximum possible visual fidelity is required without any compression artifacts, or when the scene is too small to benefit from compression overhead [S1].

## Background
Sensitivity-Aware Vector Clustering was proposed by Niedemayr et al. in 2024 [S1]. It builds on the observation that 3D Gaussian splatting representations contain significant redundancy in SH coefficients and shape parameters [S1]. The method draws inspiration from volumetric NeRF compression and deep network weight quantization [S1]. It is used to enable efficient network streaming and rendering on low-power devices [S1].
