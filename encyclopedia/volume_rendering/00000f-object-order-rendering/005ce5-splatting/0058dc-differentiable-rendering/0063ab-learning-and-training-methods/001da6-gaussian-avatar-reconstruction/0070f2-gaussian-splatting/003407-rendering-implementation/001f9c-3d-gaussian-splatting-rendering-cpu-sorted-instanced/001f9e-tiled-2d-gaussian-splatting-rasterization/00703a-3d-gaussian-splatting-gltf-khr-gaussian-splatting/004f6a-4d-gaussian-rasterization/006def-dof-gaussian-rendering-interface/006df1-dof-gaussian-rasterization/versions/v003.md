# DOF Gaussian Rasterization

Also called: Adjustable Depth-of-Field 3D Gaussian Splatting

## Overview
DOF Gaussian Rasterization is a differentiable CUDA-accelerated rasterization method for 3D Gaussians that supports adjustable depth-of-field, enabling refocusing, defocus rendering, and blur removal by incorporating circle-of-confusion (CoC) alpha and depth-dependent scaling [S1, unofficial]. It builds on [DOF Gaussian Rendering Interface](21453-dof-gaussian-rendering-interface.md) and extends standard 3D Gaussian Splatting by decoupling the rendered focus plane from the camera's optical center, allowing focal distance to be varied post-training [S1, unofficial].

## How it works
The method operates as a CUDA-accelerated rasterizer that processes a set of 3D Gaussians into a 2D image [S1, unofficial]. It differs from standard splatting by computing a depth-dependent alpha mask (CoC alpha) that modulates the contribution of each Gaussian based on its distance from the specified focal plane [S1, unofficial].

### Inputs and Outputs
**Inputs:**
- Scene data: 3D means ($\mu$), precomputed colors ($C$), opacities ($\alpha$), scales ($s$), rotations ($q$), and spherical harmonics coefficients ($SH$) or precomputed colors [S1, unofficial].
- Camera parameters: View matrix ($V$), projection matrix ($P$), intrinsic matrix ($K$), focal length ($F$), camera position ($c$), image dimensions ($H, W$), and field of view tangents ($\tan \theta_x, \tan \theta_y$) [S1, unofficial].
- DoF parameters: Focal distance ($d_f$), circle-of-confusion coefficient ($k_{coc}$), kernel size, and subpixel offset [S1, unofficial].

**Outputs:**
- Forward pass: Rendered color image ($I$), depth map ($D$), 2D coordinates ($xy$), radii ($r$), radii derivatives ($r_{diff}$), CoC alpha mask ($\alpha_{coc}$), and buffers for backward pass ($geomBuffer, binningBuffer, imgBuffer$) [S1, unofficial].
- Backward pass: Gradients for means ($\nabla \mu$), colors ($\nabla C$), opacities ($\nabla \alpha$), scales ($\nabla s$), rotations ($\nabla q$), covariances ($\nabla \Sigma$), SH coefficients ($\nabla SH$), and camera intrinsics ($\nabla K, \nabla F$) [S1, unofficial].

### Numbered Steps

1.  **Input Validation**: Ensure exactly one of either SH coefficients or precomputed colors is provided [S1, unofficial]. Ensure exactly one of either scale/rotation pairs or precomputed 3D covariances is provided [S1, unofficial].
2.  **Argument Restructuring (Forward)**: Pack the following arguments into a tuple for the C++/CUDA kernel:
    - `raster_settings.bg`
    - `means3D`
    - `colors_precomp`
    - `opacities`
    - `scales`
    - `rotations`
    - `raster_settings.scale_modifier`
    - `cov3Ds_precomp`
    - `raster_settings.viewmatrix`
    - `raster_settings.projmatrix`
    - `F` (Focal length)
    - `K` (Intrinsics)
    - `raster_settings.vIdx`
    - `raster_settings.tanfovx`
    - `raster_settings.tanfovy`
    - `raster_settings.kernel_size`
    - `raster_settings.subpixel_offset`
    - `raster_settings.image_height`
    - `raster_settings.image_width`
    - `sh` (Spherical Harmonics coefficients) [S1, unofficial]
    - `raster_settings.sh_degree`
    - `raster_settings.campos`
    - `raster_settings.prefiltered`
    - `raster_settings.debug`
3.  **Forward Rasterization**: Invoke the C++/CUDA forward rasterization kernel `_C.rasterize_gaussians(*args)` [S1, unofficial]. This computes the projected 2D Gaussians, sorts them by depth, and renders the image [S1, unofficial]. It returns `num_rendered`, `color`, `depth`, `xy`, `radii`, `radii_diff`, `coc_alpha`, `geomBuffer`, `binningBuffer`, and `imgBuffer` [S1, unofficial].
4.  **Save Tensors**: Store `colors_precomp`, `means3D`, `scales`, `rotations`, `cov3Ds_precomp`, `radii`, `sh`, `F`, `K`, `geomBuffer`, `binningBuffer`, `imgBuffer`, and `num_rendered` for use in the backward pass [S1, unofficial].
5.  **Argument Restructuring (Backward)**: Pack the following arguments for the backward kernel:
    - `raster_settings.bg`
    - `means3D`
    - `radii`
    - `colors_precomp`
    - `scales`
    - `rotations`
    - `raster_settings.scale_modifier`
    - `cov3Ds_precomp`
    - `raster_settings.viewmatrix`
    - `raster_settings.projmatrix`
    - `F`
    - `K`
    - `raster_settings.coc2z_coeff`
    - `raster_settings.vIdx`
    - `raster_settings.tanfovx`
    - `raster_settings.tanfovy`
    - `raster_settings.kernel_size`
    - `raster_settings.subpixel_offset`
    - `grad_out_color` (Gradient from loss w.r.t. color) [S1, unofficial]
    - `grad_depth` (Gradient from loss w.r.t. depth) [S1, unofficial]
    - `grad_xy` (Gradient from loss w.r.t. 2D coordinates) [S1, unofficial]
    - `sh`
    - `raster_settings.sh_degree`
    - `raster_settings.campos`
    - `geomBuffer`
    - `num_rendered`
    - `binningBuffer`
    - `imgBuffer`
    - `raster_settings.debug`
6.  **Backward Rasterization**: Invoke the C++/CUDA backward rasterization kernel `_C.rasterize_gaussians_backward(*args)` [S1, unofficial]. This computes gradients for all input parameters, including specific gradients for camera intrinsics ($K, F$) enabled by the differentiable DoF formulation [S1, unofficial].

### Formulas
The core innovation is the **Circle-of-Confusion Alpha** ($\alpha_{coc}$) [S1, unofficial]. The forward pass computes a depth-dependent scaling factor that modulates the alpha contribution of each Gaussian based on its depth $z$ relative to the focal depth $z_f$ [S1, unofficial]. The exact forward formula is not explicitly detailed in the provided text, but it functions as a depth-dependent alpha mask [S1, unofficial]. The parameter `coc2z_coeff` is used in the backward pass to convert $\alpha_{coc}$ gradients into depth gradients ($\nabla z$) [S1, unofficial].

### Parameters
- `coc2z_coeff`: A float parameter in `raster_settings` used in the backward pass to convert circle-of-confusion alpha to depth gradients [S1, unofficial].
- `subpixel_offset`: A `torch.Tensor` parameter in `raster_settings`, used for sub-pixel sampling or jittering during rasterization [S1, unofficial].
- `kernel_size`: Kernel size used additionally within the gaussian rasterizer [S1, unofficial].

### Edge Cases and Pitfalls
- **Input Validation**: The method requires exactly one of either SHs or precomputed colors, and exactly one of either scale/rotation or precomputed 3D covariance [S1, unofficial].
- **Debug Mode**: If `raster_settings.debug` is true, tensors are copied to CPU before C++ invocation to allow saving a snapshot on exception [S1, unofficial]. This significantly impacts performance and should be disabled in production [S1, unofficial].

### Pseudocode
```python
import torch

class DOFGaussianRasterizer:
    def __init__(self, raster_settings):
        self.raster_settings = raster_settings

    def forward(self, means3D, colors_precomp, opacities, scales, rotations, 
                cov3Ds_precomp, sh, F, K):
        # 1. Input Validation [S1, unofficial]
        has_sh = sh is not None
        has_colors = colors_precomp is not None
        if has_sh == has_colors:
            raise ValueError("Exactly one of either SHs or precomputed colors must be provided.")
        
        has_cov = cov3Ds_precomp is not None
        has_scales = scales is not None
        if has_cov == has_scales:
            raise ValueError("Exactly one of either scale/rotation pair or precomputed 3D covariance must be provided.")

        # 2. Restructure arguments for C++ rasterizer [S1, unofficial]
        args = (
            self.raster_settings.bg,
            means3D,
            colors_precomp,
            opacities,
            scales,
            rotations,
            self.raster_settings.scale_modifier,
            cov3Ds_precomp,
            self.raster_settings.viewmatrix,
            self.raster_settings.projmatrix,
            F,
            K,
            self.raster_settings.vIdx,
            self.raster_settings.tanfovx,
            self.raster_settings.tanfovy,
            self.raster_settings.kernel_size,
            self.raster_settings.subpixel_offset,
            self.raster_settings.image_height,
            self.raster_settings.image_width,
            sh,
            self.raster_settings.sh_degree,
            self.raster_settings.campos,
            self.raster_settings.prefiltered,
            self.raster_settings.debug
        )

        # 3. Invoke C++/CUDA forward rasterization [S1, unofficial]
        # Returns: num_rendered, color, depth, xy, radii, radii_diff, coc_alpha, 
        #          geomBuffer, binningBuffer, imgBuffer
        num_rendered, color, depth, xy, radii, radii_diff, coc_alpha, \
            geomBuffer, binningBuffer, imgBuffer = _C.rasterize_gaussians(*args)

        # 4. Save tensors for backward pass [S1, unofficial]
        self.saved_tensors = (
            colors_precomp, means3D, scales, rotations, cov3Ds_precomp, 
            radii, sh, F, K, geomBuffer, binningBuffer, imgBuffer, num_rendered
        )
        
        self.saved_attrs = {
            'bg': self.raster_settings.bg,
            'scale_modifier': self.raster_settings.scale_modifier,
            'viewmatrix': self.raster_settings.viewmatrix,
            'projmatrix': self.raster_settings.projmatrix,
            'vIdx': self.raster_settings.vIdx,
            'tanfovx': self.raster_settings.tanfovx,
            'tanfovy': self.raster_settings.tanfovy,
            'kernel_size': self.raster_settings.kernel_size,
            'subpixel_offset': self.raster_settings.subpixel_offset,
            'image_height': self.raster_settings.image_height,
            'image_width': self.raster_settings.image_width,
            'sh_degree': self.raster_settings.sh_degree,
            'campos': self.raster_settings.campos,
            'prefiltered': self.raster_settings.prefiltered,
            'debug': self.raster_settings.debug,
            'coc2z_coeff': self.raster_settings.coc2z_coeff
        }

        return color, depth, xy, radii, radii_diff, coc_alpha

    def backward(self, grad_out_color, grad_depth, grad_xy):
        # Retrieve saved tensors [S1, unofficial]
        (colors_precomp, means3D, scales, rotations, cov3Ds_precomp, 
         radii, sh, F, K, geomBuffer, binningBuffer, imgBuffer, num_rendered) = self.saved_tensors
        
        attrs = self.saved_attrs

        # 5. Restructure args for backward C++ call [S1, unofficial]
        args = (
            attrs['bg'],
            means3D,
            radii,
            colors_precomp,
            scales,
            rotations,
            attrs['scale_modifier'],
            cov3Ds_precomp,
            attrs['viewmatrix'],
            attrs['projmatrix'],
            F,
            K,
            attrs['coc2z_coeff'],
            attrs['vIdx'],
            attrs['tanfovx'],
            attrs['tanfovy'],
            attrs['kernel_size'],
            attrs['subpixel_offset'],
            grad_out_color,
            grad_depth,
            grad_xy,
            sh,
            attrs['sh_degree'],
            attrs['campos'],
            geomBuffer,
            num_rendered,
            binningBuffer,
            imgBuffer,
            attrs['debug']
        )

        # 6. Invoke C++/CUDA backward rasterization [S1, unofficial]
        # Returns: grad_means2D, grad_colors_precomp, grad_opacities, grad_means3D, 
        #          grad_cov3Ds_precomp, grad_sh, grad_scales, grad_rotations, 
        #          grad_K, grad_F
        grad_means2D, grad_colors_precomp, grad_opacities, grad_means3D, \
            grad_cov3Ds_precomp, grad_sh, grad_scales, grad_rotations, \
            grad_K, grad_F = _C.rasterize_gaussians_backward(*args)

        return grad_means3D, grad_colors_precomp, grad_opacities, grad_scales, \
               grad_rotations, grad_cov3Ds_precomp, grad_sh, grad_K, grad_F
```

## Operating characteristics
- **Time Complexity**: Not given in the sources [S1, unofficial].

- **Strengths**: Enables post-training refocusing and defocus effects without retraining [S1, unofficial]. Differentiable with respect to camera intrinsics ($K, F$), allowing for joint optimization of scene and camera parameters [S1, unofficial].
- **Limitations**: Requires careful tuning of `coc2z_coeff` and `kernel_size` [S1, unofficial]. Debug mode significantly slows down execution [S1, unofficial]. The method relies on a C++/CUDA extension, which may have portability issues [S1, unofficial].

## Background
DOF Gaussian Splatting (DOF-GS) was introduced by Yujie Wang, Praneeth Chakravarthula, and Baoquan Chen in a paper titled "DOF-GS: Adjustable Depth-of-Field 3D Gaussian Splatting for Refocusing, Defocus Rendering and Blur Removal" presented at CVPR 2025 [S1, unofficial]. The implementation is primarily based on the official codebase for 3D Gaussian Splatting (3DGS) and draws inspiration from Mip-Splatting [S1, unofficial]. It addresses the limitation of standard 3DGS, which renders scenes with a fixed focus determined by the camera's focal plane, by introducing adjustable depth-of-field capabilities [S1, unofficial].
