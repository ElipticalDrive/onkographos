# Depth Rendering with Constant Opacity

Also called: Depth-Only Rendering Mode

## Overview
Depth Rendering with Constant Opacity is a specialized rendering pass for 3D Gaussian Splatting that produces clean depth maps by forcing all Gaussians to have uniform opacity and color [S1, unofficial]. Unlike standard alpha-blending which weights depth by Gaussian opacity and transmittance, this method ensures that depth accumulation is driven purely by geometric distance and rasterization order, eliminating shading artifacts and opacity-induced depth bias [S1, unofficial]. It is distinct from [Depth Rendering with Variable Opacity](12622-depth-rendering-with-variable-opacity.md), which respects the learned alpha values of the Gaussians [S1, unofficial].

## How it works
The method modifies the standard Gaussian rasterization pipeline to strip away appearance information (color and variable opacity) and gradient information related to scale and rotation, leaving only the geometric position and a constant alpha value to drive the depth accumulation.

### Inputs and Outputs
**Inputs:**
*   `pc`: Gaussian model object providing `get_xyz`, `get_scaling`, `get_rotation`, `get_covariance`, and `active_sh_degree` [S1, unofficial].
*   `viewpoint_camera`: Camera object providing `FoVx`, `FoVy`, `image_width`, `image_height`, `world_view_transform`, `full_proj_transform`, and `camera_center` [S1, unofficial].
*   `value`: Constant opacity multiplier for all Gaussians (default 0.95) [S1, unofficial].
*   `pipe`: Pipeline configuration object containing `compute_cov3D_python` and `debug` flags [S1, unofficial].
*   `background`: Background color tensor, typically `[1, 1, 1]` or `[0, 0, 0]` [S1, unofficial].

**Outputs:**
*   `render`: Rendered image tensor (uniform due to constant color input) [S1, unofficial].
*   `depth`: Accumulated depth buffer in NDC coordinates [S1, unofficial].
*   `alpha`: Accumulated opacity buffer [S1, unofficial].
*   `viewspace_points`: Tensor of 2D screen-space points initialized for gradient tracking [S1, unofficial].
*   `visibility_filter`: Boolean mask indicating visible Gaussians (`radii > 0`) [S1, unofficial].
*   `radii`: Screen-space bounding box radii for each Gaussian [S1, unofficial].

### Data Structures
*   `screenspace_points`: Tensor of shape `(num_gaussians, 3)` initialized to zeros with `requires_grad=True` and `retain_grad()` enabled to allow gradient flow to 2D mean positions during optimization, even though forward depth computation does not use these gradients [S1, unofficial].
*   `opacity`: Tensor of shape `(num_gaussians, 1)` filled with the constant `value` [S1, unofficial].
*   `colors_precomp`: Tensor of shape `(num_gaussians, 3)` filled with ones to strip color information [S1, unofficial].
*   `scales`, `rotations`, `cov3D_precomp`: Set to `None` or detached tensors within a no-gradient context to prevent gradient leakage into depth estimation [S1, unofficial].

### Steps
1. Initialize `screenspace_points` with zeros and enable gradient retention: `screenspace_points = torch.zeros_like(pc.get_xyz, dtype=pc.get_xyz.dtype, requires_grad=True, device="cuda") + 0`; apply `screenspace_points.retain_grad()` if supported [S1, unofficial].
2. Compute tangent field of view values from the viewpoint camera: `tanfovx = math.tan(viewpoint_camera.FoVx * 0.5)` and `tanfovy = math.tan(viewpoint_camera.FoVy * 0.5)` [S1, unofficial].
3. Configure `GaussianRasterizationSettings` with image dimensions, `tanfovx`, `tanfovy`, `background` color, `scale_modifier`, view/projection matrices, `sh_degree`, `camera_position`, `prefiltered=False`, and `debug` flag [S1, unofficial].
4. Set `means3D` to `pc.get_xyz` and `means2D` to the initialized `screenspace_points` tensor [S1, unofficial].
5. Set `opacity` to a tensor of ones with shape `(num_gaussians, 1)` multiplied by `value`: `opacity = torch.ones(pc.get_xyz.shape[0], 1, device=pc.get_xyz.device) * value` [S1, unofficial].
6. Within `torch.no_grad()`, set `scales`, `rotations`, and `cov3D_precomp` to `None`. If `pipe.compute_cov3D_python` is true, compute `cov3D_precomp = pc.get_covariance(scaling_modifier)`; otherwise, set `scales = pc.get_scaling.detach()` and `rotations = pc.get_rotation.detach()` [S1, unofficial].
7. Set `shs` to `None` and `colors_precomp` to a tensor of ones with the same shape as `pc.get_xyz`: `colors_precomp = torch.ones_like(pc.get_xyz)` [S1, unofficial].
8. Call the rasterizer with `means3D`, `means2D`, `shs=None`, `colors_precomp`, `opacities`, `scales`, `rotations`, and `cov3D_precomp` to obtain `rendered_image`, `radii`, `rendered_depth`, and `rendered_alpha` [S1, unofficial].
9. Return a dictionary containing `render` (`rendered_image`), `depth` (`rendered_depth`), `alpha` (`rendered_alpha`), `viewspace_points`, `visibility_filter` (`radii > 0`), and `radii` [S1, unofficial].

### Formulas
$$ \text{tanfovx} = \tan\left(\frac{\text{FoVx}}{2}\right) $$
$$ \text{tanfovy} = \tan\left(\frac{\text{FoVy}}{2}\right) $$
where $\text{FoVx}$ and $\text{FoVy}$ are the horizontal and vertical field of view angles in radians [S1, unofficial].

### Parameters
*   `value`: Constant opacity multiplier assigned to all Gaussians. Default is 0.95 [S1, unofficial].

### Edge Cases and Pitfalls
*   **Gradient Leakage:** Failing to detach `scales` and `rotations` or set them to `None` inside `torch.no_grad()` allows gradients to flow into the depth estimation process, corrupting optimization [S1, unofficial].
*   **Coordinate System:** Depth values are returned in NDC (Normalized Device Coordinates); downstream consumers must convert to metric depth if required [G].
*   **Uniform Opacity Accumulation:** Setting opacity to a constant value (e.g., 0.95) means final accumulated opacity depends on the number of overlapping Gaussians and their rasterization order, which can saturate alpha values in dense regions [S1, unofficial].
*   **Color Output:** Since `colors_precomp` is set to ones, the `render` output is a uniform mask and not a valid color image; only `depth` and `alpha` buffers are useful [S1, unofficial].

### Pseudocode
```python
import torch
import math

def render_depth_constant_opacity(pc, viewpoint_camera, value=0.95, pipe=None, background=None):
    """
    Render depth map with constant opacity.
    
    Args:
        pc: GaussianModel object with methods get_xyz, get_scaling, get_rotation, get_covariance.
        viewpoint_camera: Camera object with FoVx, FoVy, projection matrices.
        value: Constant opacity multiplier (default 0.95).
        pipe: PipelineParams object.
        background: Tensor of background color.
        
    Returns:
        dict: Render results including depth, alpha, etc.
    """
    # Guard: initialize defaults if not provided [G]
    if background is None:
        background = torch.tensor([1.0, 1.0, 1.0], dtype=torch.float32, device="cuda")
    if pipe is None:
        pipe = type('obj', (object,), {'compute_cov3D_python': False, 'debug': False})()

    num_gaussians = pc.get_xyz.shape[0]
    device = pc.get_xyz.device

    # Step 1: Initialize screenspace_points with gradient retention
    screenspace_points = torch.zeros_like(pc.get_xyz, dtype=pc.get_xyz.dtype, requires_grad=True, device=device) + 0
    try:
        screenspace_points.retain_grad()
    except AttributeError:
        pass

    # Step 2: Compute FOV tangents
    tanfovx = math.tan(viewpoint_camera.FoVx * 0.5)
    tanfovy = math.tan(viewpoint_camera.FoVy * 0.5)

    # Step 3: Configure rasterization settings
    rasterization_settings = {
        "image_width": viewpoint_camera.image_width,
        "image_height": viewpoint_camera.image_height,
        "tanfovx": tanfovx,
        "tanfovy": tanfovy,
        "bg": background,
        "scale_modifier": 1.0,
        "viewmatrix": viewpoint_camera.world_view_transform,
        "projmatrix": viewpoint_camera.full_proj_transform,
        "sh_degree": pc.active_sh_degree,
        "camera_position": viewpoint_camera.camera_center,
        "prefiltered": False,
        "debug": pipe.debug
    }

    # Step 4: Prepare attributes
    means3D = pc.get_xyz
    means2D = screenspace_points
    opacity = torch.ones((num_gaussians, 1), dtype=torch.float32, device=device) * value
    colors_precomp = torch.ones_like(pc.get_xyz)
    shs = None

    # Step 5: Handle scales and rotations under no_grad
    with torch.no_grad():
        if pipe.compute_cov3D_python:
            cov3D_precomp = pc.get_covariance(1.0)
            scales = None
            rotations = None
        else:
            cov3D_precomp = None
            scales = pc.get_scaling.detach()
            rotations = pc.get_rotation.detach()

    # Step 6: Rasterize
    # The sources do not provide the exact kernel invocation signature for the rasterizer.
    # In practice, this calls the C++/CUDA GaussianRasterization kernel with the prepared arguments.
    # rendered_image, radii, rendered_depth, rendered_alpha = gaussian_rasterizer(...)
    rendered_image, radii, rendered_depth, rendered_alpha = None, None, None, None

    # Step 7: Return results
    visibility_filter = radii > 0
    return {
        "render": rendered_image,
        "depth": rendered_depth,
        "alpha": rendered_alpha,
        "viewspace_points": screenspace_points,
        "visibility_filter": visibility_filter,
        "radii": radii
    }
```

## Subtopics

### [Normalized Depth Rendering](8298-normalized-depth-rendering.md)
Computes a depth map by dividing the accumulated depth buffer by the accumulated opacity buffer to correct for transparency artifacts in Gaussian splatting renders.

### [Depth Rendering with Variable Opacity](12622-depth-rendering-with-variable-opacity.md)
Extends Gaussian Splatting rasterization to produce a per-pixel depth buffer while respecting the variable opacity of the Gaussians, unlike this method which forces uniform opacity to drive depth accumulation by geometric distance.

### [Depth Rendering with Weighted Average](17682-depth-rendering-with-weighted-average.md)
Computes a depth map by calculating a weighted average of Gaussian depths along a ray, where weights are determined by the alpha-compositing process, differing from this method by allowing opacity to influence depth accumulation.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Produces clean, unbiased depth maps that reflect the geometric distribution of Gaussians rather than their learned opacity, useful for depth supervision and optimization [S1, unofficial].
*   **Limitations:** Does not account for actual scene transparency; depth accumulation is driven purely by geometric distance and rasterization order [S1, unofficial].
*   **When to Use:** Training Gaussian Splatting models with depth supervision or extracting depth maps for downstream geometric tasks where opacity bias is undesirable [S1, unofficial].
*   **When Not to Use:** Visualizing scene appearance or when actual transparency is required for depth interpretation [S1, unofficial].

## Background
The method originates from the need to extract reliable depth information from 3D Gaussian Splatting models for training and optimization purposes [S1, unofficial]. Standard alpha-blending depth rendering can be biased by learned opacity values that may not accurately reflect the geometric surface [S1, unofficial]. By forcing constant opacity, depth accumulation becomes a function of geometric distance and rasterization order, providing a stable signal for gradient-based optimization [S1, unofficial]. Implementation details, including gradient retention for `screenspace_points` and detaching scales/rotations, are documented in the DNGaussian repository [S1, unofficial].
