# Hierarchical, Graph-Based, and Adaptive Structures

Also called: Adaptive Spatial Partitioning, Dynamic Gaussian Selection, Scale-Adaptive Splatting, Cross-Level Feature Coupling

## Overview
This family addresses standard 3D Gaussian Splatting (3DGS) limitations in memory efficiency, scale-dependent rendering quality, and structural coherence for large scenes [S1]. While standard 3DGS maintains a flat Gaussian list, these methods introduce hierarchical partitioning, graph connectivity, or dynamic adaptation to reduce memory footprint and eliminate aliasing or boundary artifacts [S1]. They differ from siblings like [TurboGS](15697-turbogs.md) and [Data Compression](12943-data-compression-and-storage-optimization.md) by modifying the geometric representation or optimization graph rather than rasterization speed or storage formats [G].

## Shared principles
All methods in this family modify the standard 3DGS primitive set or its optimization pipeline to introduce structure or adaptivity [S1].
*   **Primitive Representation:** Gaussians are defined by mean $\mathbf{\mu}$, covariance $\mathbf{\Sigma}$ (derived from scale $\mathbf{s}$ and rotation $\mathbf{q}$), opacity $\alpha$, and spherical harmonics coefficients $\mathbf{c}$ [G].
*   **Rendering Equation:** The color $C$ for a pixel is computed via alpha-blending of overlapping Gaussians sorted by depth:
    $$ C = \sum_{i \in N_{active}} \mathbf{c}_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $N_{active}$ are the Gaussians overlapping the pixel [G].
*   **Adaptivity:** Methods either partition the scene (graph/tree), select a subset of primitives (dynamic), or deform primitives based on view scale (adaptive) [S1].

## Subtopics

### [TraGraph-GS](14454-tragraph-gs.md)
TraGraph-GS handles large-scale scenes by decoupling training into local regions using a camera connectivity graph. It constructs a graph $G=(V, E, w)$ where vertices are images and edge weights are feature match counts. It segments this graph into $k$ regions using BFS. Local Gaussians are trained per region with multi-view (NCC) and multi-scale constraints. A global coarse representation is trained on downsampled data. Novel views are rendered by combining local and global Gaussians using a progressive weighting strategy based on a matching score $S$ and overlap threshold $\beta$ to eliminate boundary artifacts.

### [FlexGS](16110-flexgs.md)
FlexGS enables dynamic inference-time adaptation to memory constraints without retraining. It uses a learnable Gaussian selector (trained with Gumbel-Softmax relaxation) to choose a subset of $K=eN$ Gaussians based on a target ratio $e$. A ratio-dependent transformation field then adjusts the parameters (position, scale, opacity) of the selected Gaussians to compensate for the visual loss of the pruned ones. This allows a single model to serve varying hardware constraints (e.g., mobile vs. desktop).

### [Mipmap-GS](16893-mipmap-gs.md)
Mipmap-GS eliminates aliasing artifacts (zoom-in spikes, zoom-out thickness) by deforming pre-trained Gaussians at test time. It optimizes the Gaussians against scale-specific "pseudo ground-truth" images generated by resizing the base rendering: super-resolution (SwinIR) for zoom-in and bilinear interpolation for zoom-out. The optimization minimizes the L2 loss between the rendered image at the target scale and the pseudo-GT, updating Gaussians via gradient descent for 1,000 iterations.

### [Hierarchical Anchor Coupling](17260-hierarchical-anchor-coupling.md)
Hierarchical Anchor Coupling (HAC) solves feature isolation in octree-based 3DGS. It aggregates context from adjacent octree levels (coarser and finer) to compute a per-level feature adjustment $\delta^l$. This adjustment is broadcast as a residual to all visible anchors at that level: $\hat{f}_i = f_i + \delta^{l_i}$. The context is computed using Structure-Aware Containment Aggregation (SACA) operators. If a level lacks an adjacent neighbor (boundary case), the self-context is used. This injects shared structural information while preserving per-anchor variation.

### Laplacian-Based Deformation
Laplacian-Based Deformation builds a Laplacian operator directly on the collection of Gaussian kernel means $\{\pi_i\}_{i=1}^N$, treating them as a point cloud [S1]. It integrates a surface-aware splat graph into off-the-shelf point cloud Laplacian methods, using graph geodesic distance rather than raw connectivity for robustness against missing edges [S1]. It computes the cotangent Laplacian on a local triangulation using NonManifold [S1]. The means are deformed through a Laplacian-based deformation map $\phi_\Delta$ obtained by solving a system such as ARAP or BBW using the Laplacian operator $\Delta$ [S1]. Simply displacing the positions of the primitives leads to severe visual artifacts because the covariances of the Gaussian kernels are not adapted properly [S1].

## Background
3D Gaussian Splatting [G] introduced a fast, differentiable rendering technique using explicit Gaussian primitives. However, standard 3DGS suffers from high memory usage, boundary artifacts in large scenes, and aliasing at varying zoom levels [S1]. Recent research has focused on hierarchical structures (octrees, graphs) and adaptive mechanisms to improve scalability and quality [S1]. TraGraph-GS addresses large-scale scene partitioning [S1]. FlexGS addresses dynamic memory constraints [S1]. Mipmap-GS addresses scale-dependent aliasing [S1]. Hierarchical Anchor Coupling addresses feature propagation in hierarchical representations [S1].
