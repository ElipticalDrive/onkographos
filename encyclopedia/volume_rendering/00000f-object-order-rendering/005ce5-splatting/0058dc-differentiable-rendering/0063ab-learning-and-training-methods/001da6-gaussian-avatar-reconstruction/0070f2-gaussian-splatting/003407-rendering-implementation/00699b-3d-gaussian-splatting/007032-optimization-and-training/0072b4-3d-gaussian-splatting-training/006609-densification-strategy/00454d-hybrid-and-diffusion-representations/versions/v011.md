# Hybrid and Diffusion Representations

Also called: TriplaneGaussian, GaussianDiffusion, Text2Immersion, Atomic-Continuous Prior

## Overview
This family addresses the problem of generating 3D Gaussian Splatting (3DGS) representations from single images, text, or sparse inputs without relying on iterative per-scene optimization. It sets itself apart from sibling methods like [Densification and Splitting](13466-densification-and-splitting.md) by replacing iterative gradient-based refinement with learned generative priors, either through hybrid feature grids or diffusion models, enabling near-real-time generation [S1].

## Shared principles
All methods in this family operate on a set of 3D Gaussian primitives $\mathcal{G} = \{g_1, \dots, g_N\}$, where each $g_k$ is defined by a mean position $\mu_k \in \mathbb{R}^3$, a covariance matrix $\Sigma_k$ (parameterized by scale $s_k$ and rotation $q_k$), opacity $\alpha_k$, and spherical harmonic coefficients $\mathbf{c}_k$ [Parent].

Unlike iterative optimization, these methods predict Gaussian attributes directly from a conditioning signal (image, text, or noise) using a neural network. The core mechanism involves mapping the conditioning signal to a structured intermediate representation (such as a tri-plane grid or a voxelized GaussianCube) which is then decoded into the final Gaussian set [S1].

## Subtopics

### [TriplaneGaussian](7558-triplanegaussian.md)
TriplaneGaussian is a feed-forward method for generating 3D Gaussian Splatting (3DGS) representations from a single input image. It solves the problem of direct 3D generation by employing a hybrid representation that combines a sparse point cloud with a dense tri-plane feature grid. Unlike sibling methods that rely on iterative optimization or multi-view consistency constraints (e.g., [GaussianDiffusion](9190-gaussiandiffusion.md)), TriplaneGaussian directly predicts Gaussian attributes via a transformer-based decoder, leveraging the structural priors of tri-planes to ensure geometric consistency.

**Inputs:** A single RGB image $I$.
**Outputs:** A set of 3D Gaussians $\mathcal{G} = \{g_1, \dots, g_N\}$, where each $g_k$ is defined by mean position $\mu_k$, covariance $\Sigma_k$ (scale $s_k$, rotation $q_k$), opacity $\alpha_k$, and spherical harmonic coefficients $\mathbf{c}_k$.

**Data Structures:**
1.  **Tri-plane:** Three 2D feature grids $T_x, T_y, T_z \in \mathbb{R}^{C \times H \times W}$ encoding 3D spatial attributes. The dimensions $C, H, W$ are hyperparameters of the decoder.
2.  **Point Cloud:** A set of 3D points $P = \{p_1, \dots, p_M\}$ representing initial Gaussian centers.
3.  **MLP:** A multi-layer perceptron mapping augmented features to Gaussian attributes.

**Steps:**
1.  **Image Encoding:** The input image $I$ is processed by a vision encoder to extract image features $F_{img}$.
2.  **Hybrid Generation:** A transformer-based architecture generates two components in parallel:
    *   A coarse point cloud $P$ via a point cloud decoder.
    *   A tri-plane feature grid $T = \{T_x, T_y, T_z\}$ via a tri-plane decoder.
3.  **Densification:** The coarse point cloud $P$ is upsampled using an upsampling method to increase density $M$.
4.  **Feature Querying:** For each point $p_k \in P$, its 3D coordinates are projected onto the three planes of $T$. Features are sampled from $T_x, T_y, T_z$ at these projected locations and aggregated to form a point-specific feature vector $f_k$.
5.  **Feature Augmentation:** The queried feature $f_k$ is augmented by projecting the image features $F_{img}$ onto the point $p_k$ (or using $p_k$ to sample $F_{img}$) to obtain augmented features $f'_k$.
6.  **Attribute Prediction:** The augmented features $f'_k$ are passed through an MLP to predict the final Gaussian attributes: $\mu_k, s_k, q_k, \alpha_k, \mathbf{c}_k$.

**Pseudocode:**
```python
def triplane_gaussian_generate(image: Tensor) -> List[Gaussian]:
    # 1. Encode image
    F_img = vision_encoder(image)
    
    # 2. Generate hybrid representation
    # Point cloud decoder outputs initial centers
    P_coarse = point_cloud_decoder(F_img)
    
    # Tri-plane decoder outputs 3 feature grids
    T = tri_plane_decoder(F_img)
    
    # 3. Densify point cloud
    P = upsampling_method(P_coarse)
    
    gaussians = []
    for p in P:
        # 4. Query tri-plane features
        # Project 3D point p onto XY, YZ, XZ planes
        # Sample features from T at projected coordinates
        f_triplane = query_triplane(T, p)
        
        # 5. Augment with image features
        # Project p to 2D image space to sample F_img
        f_img = project_and_sample(F_img, p)
        
        f_augmented = concatenate(f_triplane, f_img)
        
        # 6. Predict attributes
        attrs = mlp(f_augmented)
        gaussians.append(Gaussian(attrs))
        
    return gaussians
```

**Parameters:**
*   Tri-plane resolution ($H, W$): Not given in the sources.
*   Tri-plane channels ($C$): Not given in the sources.
*   Upsampling factor: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Precision:** The projection of 3D points to 2D planes and image space requires accurate coordinate transformation matrices [G].
*   **Boundaries:** Points outside the camera frustum or tri-plane domain must be handled during querying [G].

### [GaussianDiffusion](9190-gaussiandiffusion.md)
GaussianDiffusion is a method that trains a 3D diffusion model based on a GaussianCube representation to generate 3D Gaussian primitives directly from conditioning signals. It solves the problem of multi-view inconsistency (the "Janus problem") and spurious geometry ("floaters") common in single-view or text-to-3D generation by incorporating structured noise from multiple viewpoints and using variational 3DGS. Unlike iterative optimization methods, it amortizes generation cost over a trained network, enabling near-real-time sampling.

**Inputs and Outputs:**
- Input: Conditioning signal (e.g., text, single image).
- Output: A set of 3D Gaussians $\mathcal{G} = \{g_1, \dots, g_N\}$, where each $g_k$ is defined by mean $\mu_k$, covariance $\Sigma_k$ (scale $s_k$, rotation $q_k$), opacity $\alpha_k$, and spherical harmonic coefficients $\mathbf{c}_k$.

**Data Structures:**
- **GaussianCube:** A structured grid representation created by converting a constant number of Gaussians into a voxelized format via optimal transport. This fixed-size representation allows the diffusion model to process the unstructured Gaussian set as a dense 3D volume.

**Steps:**
1. **Representation Conversion:** Convert the input or intermediate set of 3D Gaussians into a GaussianCube using voxelization via optimal transport.
2. **Diffusion Process:** Train a 3D diffusion model on GaussianCube representations. During inference, the model denoises a latent GaussianCube to predict the target geometry.
3. **Structured Noise Incorporation:** Incorporate structured noise from multiple viewpoints during the diffusion process to enforce multi-view consistency and alleviate the Janus problem.
4. **Variational Refinement:** Apply variational 3DGS techniques to the generated Gaussians to mitigate floaters and improve generation quality.

**Parameters:**
- Not given in the sources.

**Edge Cases and Pitfalls:**
- The difference between the diffusion prior and the training process of the diffusion model can impair generation quality.
- Single-step reconstruction can suffer from high error if not properly supervised.

#### Text2Immersion
**Definition:** A scene generation method similar to LucidDreamer but with outlier removal and two-stage optimization [S1].
**Steps:** A process removes outliers in the point cloud [S1]. 3DGS optimization has two stages: training coarse 3DGS and refinement [S1].

#### Atomic-Continuous Prior
**Definition:** A probabilistic prior for VDB volumes that models the data as a mixture of a discrete atomic component (exact zeros for empty space) and a continuous component (real density values). It solves the problem where plain Gaussian diffusion smooths away faint wisps and leaks density into empty regions due to the mix of exact zeros and heavy-tailed densities [S2].
**Steps:**
*   **Amplitude companding:** Apply a reversible log mapping to rebalance the training signal. This boosts the gradient on faint, low-density structures by a factor of $(1 + \lambda\tilde{x})^{-1}$ to prevent thin wisps from being smoothed away [S2].
*   **Atomic mass supervision:** Enforce sparsity by using a soft occupancy target to recover coarse shape and applying a leakage penalty that pushes density to exactly zero outside the boundary [S2].
*   **Temporal conditioning (for sequences):** Stack the previous frame onto the input as an extra channel. The network learns motion from this concatenated input without using 4D attention [S2].
**Formula:** $p(x) = \pi_0\delta_0(x) + (1-\pi_0)p_{ac}(x)$, where $\pi_0$ is the probability mass at zero, $\delta_0(x)$ is the Dirac delta function at zero, and $p_{ac}(x)$ is the continuous probability density function for non-zero values [S2].

## Background
The need for hybrid and diffusion representations arises from the limitations of iterative optimization methods like [Densification and Splitting](13466-densification-and-splitting.md), which are computationally expensive and require multi-view inputs or extensive tuning for single-view generation. TriplaneGaussian [S1] and GaussianDiffusion [S1] represent a shift towards feed-forward and generative approaches, respectively, to achieve real-time 3D scene synthesis. Text2Immersion [S1] and Atomic-Continuous Prior [S2] address specific artifacts such as outliers and VDB-specific sparsity issues in generated volumes.
