# Semantic-Aware Gaussian Splatting (SA-GS)

Also called: SA-GS, SAM-GS

## Overview
SA-GS is a 3D Gaussian Splatting variant that incorporates semantic masks and geometric complexity constraints to refine Gaussian shapes and reduce the number of splats, thereby improving geometric reconstruction quality and reducing GPU memory consumption [S1, unofficial]. It differs from vanilla 3DGS by adding semantic-aware shape constraints (disk-like for low frequency, stick/dot for high frequency) and alpha-based point extraction instead of using Gaussian means directly [S1, unofficial].

## How it works
**Inputs:** A set of $N$ input images $I = \{I_1, I_2, \dots, I_N\}$, text captions $c$ for semantic classes, and hyperparameters $\lambda_{gc}=0.2, \lambda_{dssim}=0.2, \lambda_{l1}=0.6, k_1=3, k_2=1$ [S1, unofficial].
**Outputs:** A set of 3D Gaussians $\{G_i\}$ with optimized parameters, and a point cloud extracted via hierarchical sampling [S1, unofficial].

**Data Structures:**
*   **Semantic Masks $M$:** A tensor of shape $H \times W \times N$, where $M_i(x,y)$ stores the integer class ID for pixel $(x,y)$ in image $i$ [S1, unofficial].
*   **Gaussian Parameters:** Standard 3DGS parameters: mean $\mu_i$, covariance $\Sigma_i$ (parameterized as scale $s$ and rotation $q$), opacity $\alpha_i$, and spherical harmonics coefficients [G].
*   **Edge Counts $e_{ij}$:** A scalar for each image $i$ and semantic group $j$, representing the number of Canny edge pixels in that group [S1, unofficial].

**Steps:**

1.  **Semantic and Geometric Property Extraction (Pre-training):**
    *   Extract semantic masks $M$ for all input images using GroundingSAM [S1, unofficial].
    *   Classify pixels into $C$ semantic groups based on caption embeddings $E(c)$ [S1, unofficial]. For pixels where GroundingSAM fails, assign a default embedding [S1, unofficial].
    *   For each semantic group $j$, compute the edge count $e_{ij}$ for each image $i$ using Canny Edge detection [S1, unofficial].
    *   Calculate the perplexity $P_j$ for group $j$ as the sum of edge counts across all images:
        $$ P_j = \sum_{i} e_{ij} $$
    *   Calculate the pixel count $p_j$ for group $j$ [S1, unofficial].
    *   Determine expected aspect ratios $a_1$ and $a_2$ for Gaussians in group $j$ using:
        $$ \frac{1}{p_j} = \frac{k_1 a_1}{P_j} \quad \text{and} \quad \frac{1}{p_j} = \frac{k_2 a_2}{P_j} $$
        where $k_1=3, k_2=1$ are constants, and $a_1 = s_x/s_z, a_2 = s_y/s_z$ [S1, unofficial].

2.  **Geometric Complexity Aware Training:**
    *   Modify the CUDA rasterization kernel to dynamically extract the projected mean of each Gaussian during rasterization [S1, unofficial].
    *   Map projected pixels to semantic masks to assign expected shapes online [S1, unofficial]. This avoids inconsistency from separate training [S1, unofficial].
    *   Compute the geometric complexity loss $L_{gc}$:
        $$ L_{gc} = \sigma\left(\frac{k_1}{P_i} - a_1\right) + \sigma\left(\frac{k_2}{P_i} - a_2\right) $$
        where $\sigma$ is a weighting or activation function [S1, unofficial].
    *   Combine with rendering losses:
        $$ L_{total} = \lambda_{gc} L_{gc} + \lambda_{dssim} L_{dssim} + \lambda_{l1} L_{l1} $$
    *   Pruning: Rank Gaussians by opacity and remove low-opacity splats. Decrease the count linearly to the expected number after the first 6000 iterations [S1, unofficial].

3.  **Probability Density Point Extraction (Post-training):**
    *   Construct a multinomial distribution $P(i)$ based on Gaussian opacity $\alpha_i$:
        $$ P(i) = \frac{\alpha_i}{\sum \alpha} $$
    *   Sample indices $i$ according to $P(i)$ [S1, unofficial]. High $\alpha_i$ Gaussians are sampled multiple times; low $\alpha_i$ Gaussians may be sampled zero or once [S1, unofficial].
    *   For each sampled Gaussian $i$, draw points from its density function $\phi(x)$:
        $$ \phi(x) = \alpha_i \exp\left(-\frac{1}{2}(x - \mu_i)^T \Sigma_i^{-1} (x - \mu_i)\right) $$
    *   The final point cloud consists of these sampled points [S1, unofficial].

**Pseudocode:**

```python
def sa_gs_training(input_images, captions, k1=3, k2=1, lambda_gc=0.2, lambda_dssim=0.2, lambda_l1=0.6):
    # Stage 1: Semantic and Geometric Property Extraction
    masks = extract_semantic_masks(input_images, model="GroundingSAM")
    semantic_groups = classify_masks(masks, captions)
    
    edge_counts = {}
    pixel_counts = {}
    for group in semantic_groups:
        edge_counts[group] = 0
        pixel_counts[group] = 0
        for img_idx, img in enumerate(input_images):
            group_mask = masks[img_idx][group]
            edges = canny_edge_detection(group_mask)
            edge_counts[group] += len(edges)
            pixel_counts[group] += len(group_mask)
            
    perplexity = {g: edge_counts[g] for g in semantic_groups}
    
    # Stage 2: Geometric Complexity Aware Training
    gaussians = initialize_gaussians(input_images)
    
    for iteration in range(max_iterations):
        # Modified CUDA kernel extracts projected mean and assigns semantic mask online
        projected_means, semantic_labels = rasterize_with_semantic_mask(gaussians, input_images)
        
        # Compute aspect ratios from perplexity
        aspect_ratios = {}
        for group in semantic_groups:
            p_j = pixel_counts[group]
            P_j = perplexity[group]
            a1 = P_j / (k1 * p_j)
            a2 = P_j / (k2 * p_j)
            aspect_ratios[group] = (a1, a2)
            
        # Compute losses
        L_gc = 0
        for g in semantic_groups:
            a1, a2 = aspect_ratios[g]
            P_j = perplexity[g]
            # sigma function implementation not specified in source [S1, unofficial]
            L_gc += sigma(k1/P_j - a1) + sigma(k2/P_j - a2)
            
        L_dssim = compute_dssim_loss(gaussians, input_images)
        L_l1 = compute_l1_loss(gaussians, input_images)
        
        L_total = lambda_gc * L_gc + lambda_dssim * L_dssim + lambda_l1 * L_l1
        optimize_gaussians(L_total)
        
        # Pruning
        if iteration > 6000:
            prune_low_opacity_gaussians(gaussians, target_count=expected_count)
            
    return gaussians

def extract_point_cloud(gaussians, num_points):
    # Stage 3: Probability Density Point Extraction
    alphas = [g.alpha for g in gaussians]
    total_alpha = sum(alphas)
    probs = [a / total_alpha for a in alphas]
    
    # Multinomial sampling based on alpha distribution
    sampled_indices = multinomial_sample(probs, num_points)
    
    points = []
    for idx in sampled_indices:
        g = gaussians[idx]
        # Sample point from Gaussian density
        point = sample_from_gaussian_density(g.mu, g.Sigma)
        points.append(point)
        
    return points

def multinomial_sample(probs, n):
    # Standard CDF-based multinomial sampling
    cdf = [sum(probs[:i+1]) for i in range(len(probs))]
    indices = []
    for _ in range(n):
        r = random.random()
        idx = bisect.bisect_right(cdf, r)
        indices.append(idx)
    return indices

def sample_from_gaussian_density(mu, Sigma):
    # Standard 3D normal distribution sampling
    return numpy.random.multivariate_normal(mu, Sigma)
```

**Edge Cases and Pitfalls:**
*   **GroundingSAM Failure:** Pixels without correspondence must be assigned a default embedding [S1, unofficial].
*   **Inconsistency:** Training semantic groups separately causes inconsistency; dynamic online assignment via modified CUDA kernel is required [S1, unofficial].
*   **Sigma Function:** The exact form of $\sigma$ in $L_{gc}$ is not specified in the source [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time and memory consumption remain the same as vanilla Gaussian Splatting due to the efficient online mask assignment in the CUDA kernel [S1, unofficial].
*   **Memory:** Reduces GPU memory consumption by pruning low-opacity splats and controlling the total number of Gaussians based on semantic complexity [S1, unofficial].
*   **Performance:** Improves geometric reconstruction quality, particularly in large-scale scenes, by aligning Gaussian shapes with semantic and geometric features [S1, unofficial].
*   **Strengths:** Effective for large-scale scenes; reduces over-reconstruction in low-frequency areas and under-reconstruction in high-frequency areas [S1, unofficial].
*   **Limitations:** Relies on the accuracy of GroundingSAM and Canny Edge detection; requires modification of the rasterization kernel [S1, unofficial].

## Background
SA-GS was introduced in the paper "SA-GS: Semantic-Aware Gaussian Splatting for Large Scene Reconstruction with Geometry Constrain" [S1, unofficial]. It extends previous work like LangSplat and LeGaussian, which use large vision models for object-level semantics, by applying semantic and geometric data to large-scale scenes [S1, unofficial]. It addresses the issue of uniform Gaussian distribution by adapting shapes to local geometric complexity [S1, unofficial].
