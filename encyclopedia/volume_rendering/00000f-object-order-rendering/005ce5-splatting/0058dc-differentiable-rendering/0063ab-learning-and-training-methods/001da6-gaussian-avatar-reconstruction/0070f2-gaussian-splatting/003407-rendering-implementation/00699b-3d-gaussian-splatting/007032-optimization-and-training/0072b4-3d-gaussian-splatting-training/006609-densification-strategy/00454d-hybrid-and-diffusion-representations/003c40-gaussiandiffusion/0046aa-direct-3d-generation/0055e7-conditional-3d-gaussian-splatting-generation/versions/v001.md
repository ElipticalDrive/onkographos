# Conditional 3D Gaussian Splatting Generation

Also called: Conditional Generation (Text/Image/Partial), DiffGS Conditional

## Overview
Conditional 3D Gaussian Splatting Generation extends the DiffGS framework to produce 3D Gaussian Splatting (3DGS) representations conditioned on external signals such as text prompts, input images, or partial 3DGS inputs containing large occlusions [S1]. It differs from unconditional generation by leveraging frozen encoders (CLIP or PointNet) to map conditions into embeddings that guide the diffusion process, enabling controllable synthesis and completion [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:** A condition $c$ (text, image, or partial 3DGS) and a noise level $t$.
- **Outputs:** A set of 3D Gaussian parameters (mean $\mu$, covariance $\Sigma$, opacity $\alpha$, spherical harmonics coefficients) representing the complete scene [S1].

**Data Structures:**
- **Condition Embedding:** A vector produced by the custom encoder $\gamma$.
- **DiffGS State:** The latent representation of the Gaussian field being denoised.

**Method Steps:**
1. **Condition Encoding:**
   - If the condition is text or image, use a frozen CLIP encoder [S1].
     - Text: $\mathbf{e}_{text} = \gamma_{text}(text)$ [S1].
     - Image: $\mathbf{e}_{image} = \gamma_{image}(image)$ [S1].
   - If the condition is partial 3DGS, use a modified PointNet [S1].
     - Partial 3DGS: $\mathbf{e}_{partial} = \gamma_{partial}(partial\_3DGS)$ [S1].
2. **Conditional Diffusion Training:**
   - Train the DiffGS model using the conditional optimization objective defined in Eq. (8) of the source [S1]. The specific formula for Eq. (8) is not provided in the sources [G: Assume standard conditional diffusion loss formulation where the noise prediction network is conditioned on $\mathbf{e}$].
3. **Generation:**
   - Sample noise and iteratively denoise conditioned on $\mathbf{e}$ to produce the final Gaussian field [S1].

**Parameters:**
- **Dataset:** ShapeNet chair class with commonly used data splits [S1].
- **Encoders:** Frozen CLIP (text/image), Modified PointNet (partial 3DGS) [S1].

**Edge Cases and Pitfalls:**
- **Partial Input Occlusion:** The method must handle highly occluded inputs; the PointNet encoder $\gamma_{partial}$ is specifically modified to address this [S1].
- **Semantic Consistency:** The model must accurately recover semantics described in text prompts, which requires robust conditioning [S1].

## Subtopics

### Interactive3D
A method operating in two stages for interactive 3D object generation and refinement [S2]. In the first stage, it optimizes 3D objects through 3DGS and Score Distillation Sampling (SDS), allowing flexible interactions like adding/removing parts, geometry transformation, deformable/rigid dragging, and semantic editing [S2]. In the second stage, the model is transformed into an InstantNGP structure with an interactive hash refinement module applied to improve specific details [S2].

## Operating characteristics
- **Strengths:** Produces significantly more visual-appealing and high-fidelity generations in terms of rendering and geometry qualities compared to prior methods like DiffTF [S1]. Capable of recovering complex geometries and detailed appearances from highly occluded 3DGS [S1].
- **Limitations:** Specific quantitative performance metrics (PSNR, SSIM, FID) are not provided in the sources [S1].
- **Use Cases:** Text/image-controlled 3D generation, 3DGS completion from partial data [S1].

## Background
Originated from the DiffGS paper [S1], which introduced functional Gaussian Splatting diffusion. The conditional generation capabilities were explored to enable controllable synthesis and completion tasks [S1]. The method builds on the unconditional DiffGS framework [S1].
