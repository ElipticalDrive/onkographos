# Curriculum Learning with Slice and Voxel Supervision

Also called: Slice and Voxel Supervision Curriculum

## Overview
This method stabilizes the optimization of 3D Gaussian representations for volumetric data by decoupling the supervision signal into structured planar constraints and global volumetric coverage. It solves the instability caused by random voxel sampling and the lack of global guidance in slice-only training [S1]. It sets itself apart from siblings like [Hybrid Coarse-to-Fine Strategy](7173-hybrid-coarse-to-fine-strategy.md) by explicitly leveraging the geometric alignment between slice-based sampling and shear-warp rendering, rather than relying on resolution or SH degree progression [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussian primitives $\mathcal{G} = \{g_1, \dots, g_m\}$ initialized from voxel samples, where each $g_i$ has mean $\mu_i$, covariance $\Sigma_i$, opacity $\alpha_i$, and color coefficients [S1]. Volumetric data (e.g., MRI, Cryosection) [S1].
*   **Output:** Optimized Gaussian parameters $\mathcal{G}$ that reconstruct the volume via shear-warp rendering [S1].

**Data Structures:**
*   **Gaussian Set:** $m$ Gaussians. Each Gaussian $g_i$ is defined by learnable parameters: mean $\mu \in \mathbb{R}^3$, covariance $\Sigma \in \mathbb{R}^{3 \times 3}$ (or rotation/scale decomposition), opacity $\alpha \in [0,1]$, and spherical harmonic coefficients for color [S1].
*   **Voxel Grid:** Implicit or explicit grid from which samples are drawn [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize one Gaussian kernel centered at each sampled voxel position from the input volumetric data [S1].
2.  **Stage 1 - Slice Supervision:**
    *   Sample a plane with arbitrary orientation [S1].
    *   Select sparse pixels on the sampled plane [S1].
    *   Map each selected pixel to a 3D voxel coordinate [S1].
    *   Render the image using these slice-aligned constraints and compute loss [S1].
    *   *Rationale:* This progressively incorporates finer structural details through planar constraints, aligning with shear-warp rendering which operates on stacks of 2D slices [S1].
3.  **Stage 2 - Voxel Supervision:**
    *   After slice supervision has established local continuity, introduce voxel supervision [S1].
    *   Sample voxars using a dense approximation strategy (not random) [S1].
    *   Compute loss against these global volumetric samples [S1].
    *   *Rationale:* This establishes global spatial guidance, correcting the lack of volumetric consistency seen in slice-only training [S1].

**Formulas:**
*   **Gaussian Initialization:** For $k$ voxel samples, initialize $m=k$ Gaussians. The mean $\mu_k$ is the voxel position [S1].
*   **Loss:** Standard differentiable rendering loss (e.g., L1 + SSIM) computed between rendered slice/voxel views and ground truth [S1].

**Parameters:**
*   **Sampling Strategy:** "Sparse pixels" on planes; "Dense approximation" for voxels [S1].
*   **Order:** Slice first, then Voxel [S1].

**Edge Cases and Pitfalls:**
*   **Random Voxel Sampling:** Using random voxel sampling instead of dense approximation leads to unstable global approximation and destabilizes learning [S1].
*   **Slice-Only:** Using only slice supervision (A4) limits accurate reconstruction of the full volumetric structure due to lack of global spatial guidance [S1].
*   **Wrong Order:** Applying slice supervision before stable global voxel constraints (A3) results in unstable learning of the volumetric structure, as limited planar information cannot be sufficiently corrected by later random voxels [S1].

**Pseudocode:**
```python
def train_gaussian_volumetric(data, initial_gaussians):
    # Initialize Gaussians from voxel samples
    G = initialize_gaussians_from_voxels(data)
    
    # Stage 1: Slice Supervision
    # Sample plane with arbitrary orientation
    plane = sample_arbitrary_plane()
    # Select sparse pixels on the plane
    sparse_pixels = select_sparse_pixels(plane)
    # Map pixels to 3D voxel coordinates
    voxel_coords = map_pixels_to_voxels(sparse_pixels, plane)
    
    # Render and compute loss based on slice constraints
    # This aligns with shear-warp rendering structure
    loss_slice = compute_rendering_loss(G, voxel_coords, data)
    optimize(G, loss_slice)
    
    # Stage 2: Voxel Supervision
    # Sample voxels using dense approximation (not random)
    dense_voxels = sample_dense_voxels(data)
    
    # Render and compute loss based on global voxel constraints
    loss_voxel = compute_rendering_loss(G, dense_voxels, data)
    optimize(G, loss_voxel)
    
    return G
```

## Subtopics

### Curriculum Learning with Sparse Voxel and Slice Sampling
This variant explicitly defines the sampling strategy as a combination of sparse voxels and structured slices. Sparse voxels provide global coverage of the volume, while slice samples capture spatially correlated regions that encode geometric structure and texture continuity [S1]. This aligns with shear-warp volume rendering, which generates images from stacks of 2D slices [S1]. In each iteration, a plane with arbitrary orientation is sampled, sparse pixels are selected, and mapped to 3D voxel coordinates [S1]. This allows the Gaussian representation to learn spatial continuity across neighboring regions [S1].

## Operating characteristics
*   **Performance:** Combining both slice and voxel supervision yields higher PSNR/SSIM than using only slice supervision [S1].
*   **Stability:** Random voxel sampling destabilizes learning; dense approximation is required for stability [S1].
*   **Applicability:** Applicable to multimodal volumetric datasets including MRI and Cryosection volumes [S1].
*   **Limitations:** Slice-only supervision lacks global spatial guidance [S1]. Random voxel sampling leads to unstable global approximation [S1].

## Background
Originated in the context of Gaussian Volumetric Representation for Efficient Shear-Warp Visualization [S1]. The method leverages the natural alignment between slice-based sampling and shear-warp rendering to improve the learning of anatomical structures [S1]. It addresses the limitations of previous approaches that either lacked global guidance (slice-only) or suffered from instability (random voxel sampling) [S1].
