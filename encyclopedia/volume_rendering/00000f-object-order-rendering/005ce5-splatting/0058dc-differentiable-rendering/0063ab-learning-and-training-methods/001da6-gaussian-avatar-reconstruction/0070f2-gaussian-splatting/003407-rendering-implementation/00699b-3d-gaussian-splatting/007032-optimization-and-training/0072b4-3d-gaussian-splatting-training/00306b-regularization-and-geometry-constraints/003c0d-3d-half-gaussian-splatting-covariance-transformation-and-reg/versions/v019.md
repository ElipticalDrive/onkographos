# 3D Half-Gaussian Splatting Covariance Transformation and Regularization

Also called: 3D-HGS

## Overview
This method modifies the covariance matrix of 3D Gaussian primitives to enforce a "half-Gaussian" shape, effectively creating half-ellipsoids that better approximate surface boundaries and reduce volume artifacts in empty space. It solves the problem of Gaussian Splatting primitives extending unnaturally into free space, which causes visual artifacts and inefficient memory usage. It sets itself apart from sibling methods like [Hard and Soft Depth Regularization](9178-hard-and-soft-depth-regularization.md) by explicitly altering the primitive's geometric shape via covariance transformation rather than relying solely on external depth supervision or spectral constraints.

## How it works
The method transforms the standard 3D Gaussian covariance matrix into a local basis aligned with the surface normal, modifies the diagonal elements to zero out the extent in the normal direction, and transforms it back. This creates a flattened, half-ellipsoid shape.

### Inputs and Outputs
- **Input**: The original covariance matrix $\Sigma$ (3x3 symmetric positive definite) and the surface normal vector $n$ (3x1).
- **Output**: The regularized covariance matrix $\sigma$ (3x3 symmetric).

### Data Structures
The covariance matrix is stored as a 3x3 symmetric matrix. In implementation, this is often represented by 6 unique values or a full 3x3 array. The basis matrix is a 3x3 orthogonal matrix.

### Parameters
- **Regularization Interval**: The transformation is applied every 5000 training iterations [S1].
- **Opacity Thresholds**:
  - Densification/Pruning threshold: Increased to 0.01 [S1].
  - Half-Gaussian initial opacity: Reset to 0.02 [S1].

### Algorithm Steps
1. **Normalize Normal**: Ensure the input normal vector $n$ is unit length: $n \leftarrow n / \|n\|$.
2. **Construct Basis**: Create an orthonormal basis $\{v_1, v_2, n\}$ where $v_1$ and $v_2$ are tangent to the surface.
   - If $n_x = 0$ and $n_y = 0$ (i.e., $n$ is parallel to the Z-axis):
     - $v_1 = (1, 0, 0)$
     - $v_2 = (0, 1, 0)$
   - Else:
     - $v_1 = (n_y, -n_x, 0) / \|(n_y, -n_x, 0)\|$
     - $v_2 = n \times v_1 / \|n \times v_1\|$
   - Construct the basis matrix $B$ by concatenating these vectors as columns: $B = [v_1, v_2, n]$.
3. **Transform to Basis Space**: Project the original covariance $\Sigma$ into the local basis:
   - $\text{cov} = B^T \Sigma B$
4. **Compute Modified Diagonal Elements**: Calculate the Schur complement-like terms for the tangent plane components:
   - $a' = \text{cov}_{0,0} - \frac{\text{cov}_{0,2}^2}{\text{cov}_{2,2}}$
   - $b' = \text{cov}_{0,1} - \frac{\text{cov}_{0,2} \cdot \text{cov}_{1,2}}{\text{cov}_{2,2}}$
   - $c' = \text{cov}_{1,1} - \frac{\text{cov}_{1,2}^2}{\text{cov}_{2,2}}$
5. **Construct Regularized Covariance in Basis Space**: Create a new 3x3 matrix $\sigma_{local}$:
   - $\sigma_{local,0,0} = a'$
   - $\sigma_{local,0,1} = b'$
   - $\sigma_{local,0,2} = 0$
   - $\sigma_{local,1,0} = b'$
   - $\sigma_{local,1,1} = c'$
   - $\sigma_{local,1,2} = 0$
   - $\sigma_{local,2,0} = 0$
   - $\sigma_{local,2,1} = 0$
   - $\sigma_{local,2,2} = \min(a', c') / 100$
   - All other elements are 0.
6. **Transform Back to World Space**:
   - $\sigma = B \sigma_{local} B^T$

### Pseudocode
```python
import numpy as np

def regularize_covariance(cov: np.ndarray, normal: np.ndarray) -> np.ndarray:
    """
    Transforms a 3D Gaussian covariance into a half-Gaussian shape
    aligned with the given surface normal.
    
    Args:
        cov: 3x3 symmetric covariance matrix.
        normal: 3x1 normal vector.
        
    Returns:
        Regularized 3x3 covariance matrix.
    """
    # 1. Normalize normal
    n = normal / np.linalg.norm(normal)
    
    # 2. Construct basis
    # Check if normal is parallel to Z-axis
    if np.isclose(n[0], 0.0) and np.isclose(n[1], 0.0):
        v1 = np.array([1.0, 0.0, 0.0])
        v2 = np.array([0.0, 1.0, 0.0])
    else:
        # v1 is perpendicular to n and lies in XY plane
        v1_raw = np.array([n[1], -n[0], 0.0])
        v1 = v1_raw / np.linalg.norm(v1_raw)
        # v2 is perpendicular to both n and v1
        v2 = np.cross(n, v1)
        v2 = v2 / np.linalg.norm(v2)
        
    # Basis matrix B = [v1, v2, n]
    B = np.column_stack((v1, v2, n))
    
    # 3. Transform to basis space
    cov_local = B.T @ cov @ B
    
    # 4. Compute modified elements
    # Avoid division by zero if cov[2,2] is extremely small, though typically positive definite
    cov_22 = cov_local[2, 2]
    if cov_22 < 1e-8:
        cov_22 = 1e-8 # [G] Guard against numerical instability
        
    a_prime = cov_local[0, 0] - (cov_local[0, 2]**2) / cov_22
    b_prime = cov_local[0, 1] - (cov_local[0, 2] * cov_local[1, 2]) / cov_22
    c_prime = cov_local[1, 1] - (cov_local[1, 2]**2) / cov_22
    
    # 5. Construct regularized covariance in basis space
    sigma_local = np.zeros((3, 3))
    sigma_local[0, 0] = a_prime
    sigma_local[0, 1] = b_prime
    sigma_local[1, 0] = b_prime
    sigma_local[1, 1] = c_prime
    sigma_local[2, 2] = min(a_prime, c_prime) / 100.0
    
    # 6. Transform back to world space
    sigma = B @ sigma_local @ B.T
    
    return sigma
```

### Edge Cases and Pitfalls
- **Degenerate Normal**: If the normal vector is zero or undefined, the basis construction fails. The code assumes a valid normal is provided.
- **Numerical Stability**: Division by $\text{cov}_{2,2}$ requires this value to be non-zero. Since $\Sigma$ is positive definite, this should generally hold, but a small epsilon guard is recommended [G].
- **Frequency**: The transformation is computationally expensive. It is applied only every 5000 iterations to mitigate this [S1].

## Operating characteristics
- **Time Complexity**: The transformation involves matrix multiplications (3x3) and is applied sparsely (every 5000 iterations). The overhead per iteration is negligible, but the cumulative cost depends on the number of Gaussians.
- **Memory Complexity**: No additional memory structures are required beyond the existing Gaussian attributes.
- **Performance**:
  - On Mip-NeRF 360: 125 FPS and 29.66 PSNR with 3.8M kernels (vs 3DGS 3.2M kernels) [S1].
  - On Tank & Dengin: 160 FPS and 24.45 PSNR with 1.8M kernels [S1].
  - On Tank & Blending: 126 FPS and 29.76 PSNR with 2.6M kernels [S1].
- **Strengths**: Improves geometric fidelity by aligning primitives with surfaces, reducing "floaters" and noise. Consistently outperforms original 3DGS in PSNR [S1].
- **Limitations**: Requires accurate surface normals for the transformation to be effective. The method increases the number of kernels compared to standard 3DGS in some datasets (e.g., Mip-NeRF 360) to achieve higher quality.

## Background
The method was introduced in the paper "3D-HGS: 3D Half-Gaussian Splatting" [S1]. It builds upon the original 3D Gaussian Splatting framework by modifying the primitive shape to better handle surface boundaries. The approach is evaluated against Scaffold, mip-splatting, and MCMC architectures [S1].
