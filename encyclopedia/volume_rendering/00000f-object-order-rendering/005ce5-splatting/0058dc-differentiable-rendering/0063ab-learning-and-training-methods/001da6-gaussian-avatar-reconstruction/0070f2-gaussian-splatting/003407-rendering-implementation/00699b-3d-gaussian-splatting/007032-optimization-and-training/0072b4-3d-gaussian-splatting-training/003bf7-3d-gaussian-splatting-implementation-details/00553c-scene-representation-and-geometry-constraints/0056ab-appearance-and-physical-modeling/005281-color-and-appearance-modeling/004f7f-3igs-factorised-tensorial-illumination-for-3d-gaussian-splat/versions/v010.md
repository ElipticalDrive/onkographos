# 3iGS (Factorised Tensorial Illumination for 3D Gaussian Splatting)


## Overview
3iGS enhances 3D Gaussian Splatting by modeling outgoing radiance as a function of a continuous local illumination field and individual Gaussian BRDF attributes, rather than optimizing radiance in isolation [S1]. It differs from [DAVIGS](12021-davigs.md) and [SWAG](14315-swag-splatting-in-the-wild-images-with-appearance-conditione.md) by explicitly separating scene lighting (via a factorized tensor grid) from material properties (via BRDF features) to accurately capture specular effects [S1].

## How it works
**Inputs:**
*   A set of 3D Gaussians, each defined by mean $\boldsymbol{\mu}_i$, opacity $\alpha_i$, scaling matrix $\mathbf{S}_i$, rotation matrix $\mathbf{R}_i$, diffuse color $\mathbf{c}_{d,i}$, and BRDF features $\boldsymbol{\rho}_i$.
*   A learnable factorized tensor illumination grid $\mathcal{G}_l$.
*   A neural network $\mathcal{F}$ for specular shading.
*   Camera parameters (view matrix $\mathbf{W}$, affine projection approximation $\mathbf{J}$).

**Outputs:**
*   Rendered pixel colors $\hat{\mathbf{C}}$.
*   Optimized Gaussian parameters and grid weights.

**Data Structures:**
1.  **3D Gaussian $i$:**
    *   $\boldsymbol{\mu}_i \in \mathbb{R}^3$: Mean coordinates.
    *   $\alpha_i \in \mathbb{R}$: Opacity.
    *   $\mathbf{S}_i \in \mathbb{R}^{3 \times 3}$: Scaling matrix (diagonal).
    *   $\mathbf{R}_i \in \mathbb{R}^{3 \times 3}$: Rotation matrix (orthonormal).
    *   $\mathbf{c}_{d,i} \in \mathbb{R}^3$: Diffuse color.
    *   $\boldsymbol{\rho}_i \in \mathbb{R}^{16 \times 3 + 4}$: BRDF features. This consists of 16 SH coefficients (repurposed from base 3DGS) and 4 additional parameters for base color and roughness used in Integrated Directional Encoding (IDE) [S1].
2.  **Illumination Grid $\mathcal{G}_l$:**
    *   Represented using vector-matrix spatial factorization.
    *   Resolution: $150^3$ voxels (coarse) [S1].
    *   Parameters: Feature tensors $\mathbf{A}_{L,r}^X, \mathbf{A}_{L,r}^Y, \mathbf{A}_{L,r}^Z$ and feature vectors $\mathbf{b}_k$.
    *   Rank: $R_L$ (Not given in the sources).
3.  **Neural Network $\mathcal{F}$:**
    *   Input: $\boldsymbol{\rho}_i$, $L_i$, viewing direction $\omega_o$.
    *   Output: Specular color $\mathbf{c}_{s,i}$.
    *   Architecture: Small neural network (specific architecture details not given in the sources) [S1].

**Formulas:**
*   **Covariance:** $\mathbf{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^T \mathbf{R}_i^T$ [S1].
*   **Projected Covariance:** $\mathbf{\Sigma}'_i = \mathbf{J} \mathbf{W} \mathbf{\Sigma}_i \mathbf{W}^T \mathbf{J}^T$ [S1].
*   **Gaussian Density:** $g_i(\mathbf{x} | \boldsymbol{\mu}_i, \mathbf{\Sigma}_i) = e^{-\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu}_i)^T \mathbf{\Sigma}_i^{-1} (\mathbf{x} - \boldsymbol{\mu}_i)}$ [S1].
*   **Illumination Field Query:** The incoming illumination $L_i$ at Gaussian mean $\mathbf{x}_i$ is computed by interpolating from $\mathcal{G}_l$:
    $$ \mathcal{G}_l = \sum_{r=1}^{R_L} \mathbf{A}_{L,r}^X \circ \mathbf{b}_{3r-2} + \mathbf{A}_{L,r}^Y \circ \mathbf{b}_{3r-1} + \mathbf{A}_{L,r}^Z \circ \mathbf{b}_{3r} $$
    where $\circ$ denotes the outer product or appropriate tensor contraction as defined by the factorization [S1].
*   **Outgoing Radiance:**
    $$ \mathbf{c}_i(\omega_o) = \mathbf{c}_{d,i} + \mathbf{c}_{s,i}(\omega_o) $$
    where $\mathbf{c}_{s,i} = \mathcal{F}(\boldsymbol{\rho}_i, L_i, \omega_o)$ [S1].
*   **Rendering:** Alpha blending of $N$ ordered Gaussians:
    $$ \hat{\mathbf{C}} = \sum_{i \in N} T_i g_i(\mathbf{u} | \boldsymbol{\mu}'_i, \mathbf{\Sigma}'_i) \alpha_i \mathbf{c}_i(\omega_o), \quad T_i = \prod_{j=1}^{i-1} (1 - g_j(\mathbf{u} | \boldsymbol{\mu}'_j, \mathbf{\Sigma}'_j) \alpha_j) $$
    [S1].
*   **Loss Function:**
    $$ \mathcal{L} = (1 - \lambda)\mathcal{L}_1 + \lambda \mathcal{L}_{\text{D-SSIM}} $$
    with $\lambda = 0.2$ [S1].

**Steps:**
1.  **Initialization:** Initialize 3D Gaussians from a point cloud (e.g., SfM). Initialize the illumination grid $\mathcal{G}_l$ with a boundary encapsulating the scene bounding box. Set grid resolution to $150^3$ voxels [S1].
2.  **Diffuse Training (Iterations 1–3,000):**
    *   For each iteration, render the scene using only the diffuse color $\mathbf{c}_{d,i}$ for each Gaussian (set $\mathbf{c}_{s,i} = 0$ or disable $\mathcal{F}$) [S1].
    *   Compute loss $\mathcal{L}$ against ground truth images.
    *   Update Gaussian parameters ($\boldsymbol{\mu}, \alpha, \mathbf{S}, \mathbf{R}, \mathbf{c}_d$) and illumination grid $\mathcal{G}_l$ via gradient descent [S1].
3.  **Specular Training (Iterations 3,001–30,000):**
    *   Enable specular shading. For each Gaussian $i$:
        a. Query the illumination field $L_i$ at $\boldsymbol{\mu}_i$ using $\mathcal{G}_l$ [S1].
        b. Encode viewing direction $\omega_o$ using Integrated Directional Encoding (IDE) [S1].
        c. Compute specular color $\mathbf{c}_{s,i} = \mathcal{F}(\boldsymbol{\rho}_i, L_i, \omega_o)$ [S1].
        d. Compute total radiance $\mathbf{c}_i = \mathbf{c}_{d,i} + \mathbf{c}_{s,i}$ [S1].
    *   Render the scene using alpha blending [S1].
    *   Compute loss $\mathcal{L}$ [S1].
    *   Update all parameters: Gaussian means, opacities, covariances, diffuse colors, BRDF features $\boldsymbol{\rho}_i$, and illumination grid $\mathcal{G}_l$ [S1].
4.  **Grid Boundary Management:**
    *   Midway through training (after 3,000 iterations), shrink the illumination grid boundary to fit the current extent of the Gaussians [S1].
    *   Resample the grid to maintain the same number of voxels ($150^3$) [S1].
5.  **Adaptive Control:** Apply the same adaptive control of Gaussians as in base 3DGS to limit the number of Gaussians and units per volume [S1].

**Edge Cases and Pitfalls:**
*   **Grid Boundary:** If the scene geometry expands beyond the initialized grid boundary, illumination queries may return incorrect or clamped values. The midway shrinkage strategy mitigates this by adapting the grid to the Gaussian distribution [S1].
*   **Training Stability:** Training specular effects from the start can be unstable. The two-stage training (diffuse first, then specular) improves stability [S1].
*   **BRDF Feature Initialization:** Repurposing SH coefficients as BRDF features requires careful initialization to ensure they represent valid material properties rather than just view-dependent colors [S1].

## Operating characteristics
*   **Time Complexity:** Rendering speed is comparable to base 3DGS because the illumination field is pre-calculated and stored in volumes, allowing fast evaluation via interpolation [S1]. The neural network $\mathcal{F}$ adds a small per-Gaussian overhead, but it is lightweight [S1].
*   **Memory Complexity:** The illumination grid uses $150^3$ voxels, which is 87.5% less memory than TensoRF on synthetic datasets [S1]. The memory footprint is low compared to the number of optimized Gaussians, which is often an order of magnitude higher [S1].
*   **Performance:** On the Shiny Blender dataset, 3iGS achieves an average PSNR of 27.51, SSIM of 0.930, and LPIPS of 0.045 [S1]. It surpasses 3DGS in scenes with reflective surfaces [S1].
*   **Strengths:** Accurately models specular view-dependent effects; maintains rapid training and rendering speeds; compact memory footprint for the illumination field [S1].
*   **Limitations:** Requires a two-stage training process; relies on a coarse grid which may not capture fine-scale lighting variations as well as ray-traced methods; BRDF features are simplified (SH + 4 params) [S1].
*   **When to use:** Scenes with significant specular reflections and glossy materials where view-dependent color changes are prominent [S1].
*   **When not to use:** Scenes with complex global illumination effects that require ray tracing or more detailed light transport simulation [S1].

## Background
3iGS was introduced by Z.J. Tang and T.J. Cham [S1]. It builds on the limitations of base 3DGS, which optimizes outgoing radiance in isolation and fails to capture specular effects that change drastically across viewing angles [S1]. The method is inspired by conventional computer graphics engines that use baking techniques and light probes for fast rendering [S1]. It differs from GaussianShader [13] by using a local grid-based tensor illumination field instead of a global environment light stored in cube maps [S1].
