# SUNDAE

Also called: Spectrally Pruned Gaussian Fields with Neural Compensation
## Overview
SUNDAE is a graph-based compression method for 3D Gaussian Splatting that reduces computational load by pruning redundant Gaussians while preserving key scene details [S1, S2]. It distinguishes itself from direct splatting by shifting to feature splatting, utilizing a neural compensation head to interpolate features and recover fine details lost during pruning [S1, S2].
## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians $\{G_i\}$ with attributes (position, covariance, opacity, spherical harmonics coefficients, color) [G].
*   **Output:** A pruned subset of Gaussians and a trained neural network model for feature reconstruction [S1, S2].

**Data Structures:**
*   **Gaussian Graph:** Nodes represent Gaussians, and edges encode spatial relationships or proximity between them [S2].
*   **Neural Compensation Head:** A lightweight convolutional neural network (CNN) used for feature interpolation [S1, S2].

**Steps:**
1.  **Graph Construction:** Construct a graph where nodes are the 3D Gaussians and edges capture their spatial relationships [S2].
2.  **Spectral Pruning:** Apply a band-limited graph filter to the constructed graph to selectively down-sample (prune) the Gaussians, removing redundant ones while preserving key scene details [S2].
3.  **Feature Splatting Setup:** Shift from direct Gaussian attribute rendering to feature splatting, where the pruned Gaussians carry reduced or interpolated features [S1].
4.  **Neural Compensation:** Employ the lightweight neural network-based feature interpolation head to recover fine details potentially lost during the pruning process, compensating for information loss from down-sampling [S1, S2].

## Background
SUNDAE (Spectrally Pruned Gaussian Fields with Neural Compensation) is a graph-based compression method for 3D Gaussian Splatting [S1, S2]. It was introduced to push contextual modeling in 3DGS to a finer granularity [S1]. The method is cited as reference [39] in [S1] and [54] in [S2].
