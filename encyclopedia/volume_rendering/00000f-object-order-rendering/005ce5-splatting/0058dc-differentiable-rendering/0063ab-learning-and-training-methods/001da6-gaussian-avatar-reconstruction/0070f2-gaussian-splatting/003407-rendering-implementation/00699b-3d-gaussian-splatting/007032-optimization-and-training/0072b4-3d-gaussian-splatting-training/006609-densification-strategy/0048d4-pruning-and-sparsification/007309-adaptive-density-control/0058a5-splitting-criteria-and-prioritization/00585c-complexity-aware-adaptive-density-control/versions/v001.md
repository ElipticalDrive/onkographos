# Complexity-Aware Adaptive Density Control

Also called: Complexity-Aware Density Control, Complexity-Aware Level of Details, Complexity-Guided Relocation

## Overview
A density control mechanism that biases the relocation of Gaussian primitives towards regions with higher image complexity, using complexity as a surrogate for reconstruction error [S1, unofficial]. It replaces standard opacity-only retention with a content-aware importance scoring function that combines opacity, scale, and complexity signals, allowing simple regions to be retained at low budgets while preventing large primitives from blurring complex details [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** A set of 3D Gaussian primitives $g_j$ with mean $\mu_j$, opacity $\alpha_j$, and scale $s(g_j)$; a set of training views $\Pi_i$; a complexity map $C_i^{2D}$ computed via delentropy; a capacity budget factor $\tau \in (0, 1]$; and hyperparameters $\eta, \lambda, \delta, \lambda_{var}$.
- **Outputs:** Updated complexity values $C_j$ for each Gaussian; a sorted list of Gaussians based on importance score $S(g_j)$ for pruning or densification; updated Gaussian parameters.

**Data Structures:**
- **Complexity Field:** A scalar value $C_j$ stored per Gaussian primitive. Initialized to 0.
- **Importance Score:** A scalar $S(g_j)$ computed per primitive for ranking.

**Numbered Steps:**

1. **Complexity Update:**
   After each full-capacity training render of a view $\Pi_i$, project the means of contributing Gaussians into the image plane. For each Gaussian $g_j$ whose center projects within the current view's frustum, update its complexity $C_j$ using an exponential moving average [S1, unofficial]:
   $$ C_j \leftarrow (1 - \eta) C_j + \eta C_i^{2D}(\pi_i(\mu_j)) $$
   where $\eta \in (0, 1]$ is the learning rate, $C_i^{2D}$ is the complexity map computed with delentropy, and $\pi_i(\mu_j)$ is the projection of Gaussian mean $\mu_j$ in view $i$. Over training, $C_j$ converges to the multi-view average [S1, unofficial].

2. **Normalization:**
   Normalize the complexity values $C_j$ to the range $[0, 1]$ to obtain $\tilde{C}_j$ using min-max normalization [S1, unofficial].

3. **Complexity Dropout (Optional but Recommended):**
   To prevent collapse onto fixed complex regions, apply dropout to the complexity signal during relocation sampling. With probability $\delta = 0.2$, set $\tilde{C}_j = 0$ for that candidate [S1, unofficial].

4. **Relocation Sampling (Densification/Cloning):**
   When selecting a source Gaussian $g_j$ to relocate or clone, sample with probability $p(g_j)$ proportional to [S1, unofficial]:
   $$ p(g_j) = \alpha_j \cdot \exp(\tilde{C}_j) $$
   The exponential term mimics the exponential growth of particle count with complexity, biasing new primitives toward complex areas while keeping opacity in the loop [S1, unofficial].

5. **Importance Scoring (Pruning/LoD):**
   To determine which Gaussians to retain under a limited budget $\tau < 1$, compute the importance score $S(g_j)$ [S1, unofficial]:
   $$ S(g_j) = \alpha_j + \lambda \cdot \frac{s(g_j)}{\exp(\tilde{C}_j(\mu_j))} $$
   where:
   - $\alpha_j$ is the opacity.
   - $s(g_j)$ is the max-normalized scale of the Gaussian.
   - $\tilde{C}_j$ is the normalized complexity.
   - $\lambda = 2$ is a fixed scalar weight [S1, unofficial].
   
   In high-complexity regions, $\exp(\tilde{C}_j)$ attenuates the scale term, reducing the score toward opacity to avoid preference for large, potentially blurring primitives. In low-complexity regions, $\exp(\tilde{C}_j) \to 1$, restoring weight to large primitives that efficiently cover simple areas despite moderate opacity [S1, unofficial].

6. **Variance Loss Minimization:**
   To ensure uniform degradation across levels of detail, minimize the spatial variance of reconstruction error residuals. Compute the residual $\Delta_i$ for view $i$ as the difference between full-capacity error $E(I_i^{full})$ and budgeted error $E(I_i^{\tau})$ [S1, unofficial]:
   $$ \Delta_i = E(I_i^{full}) - E(I_i^{\tau}) $$
   The variance loss is [S1, unofficial]:
   $$ L_{var} = \text{Var}_{u \in \Omega} \Delta_i(u) $$
   where $\Omega$ is the image domain.

7. **Total Training Objective:**
   The total loss combines the standard photometric loss on both full and budgeted renders with the variance loss [S1, unofficial]:
   $$ \text{Total Loss} = \text{Average}(\text{L1} + \text{D-SSIM}) + \lambda_{var} L_{var} $$
   This is applied to renders at full capacity ($\tau=1$) and budgeted levels ($\tau<1$) [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def update_complexity(gaussians, view, complexity_map, eta):
    """
    Update complexity C_j for Gaussians visible in the current view.
    """
    for g in gaussians:
        # Project mean to image plane
        pixel_coords = project_to_image(g.mean, view.camera_params)
        
        # Check if within frustum/image bounds
        if is_within_frustum(pixel_coords, view.image_shape):
            # Get complexity value at projected location
            c_2d = complexity_map.get_value(pixel_coords)
            
            # Exponential moving average update
            g.complexity = (1 - eta) * g.complexity + eta * c_2d

def normalize_complexity(gaussians):
    """
    Min-max normalize complexity values to [0, 1].
    """
    complexities = [g.complexity for g in gaussians]
    min_c = min(complexities)
    max_c = max(complexities)
    
    if max_c == min_c:
        for g in gaussians:
            g.normalized_complexity = 0.0
    else:
        for g in gaussians:
            g.normalized_complexity = (g.complexity - min_c) / (max_c - min_c)

def sample_relocation_source(gaussians, dropout_prob=0.2):
    """
    Select a Gaussian for relocation/cloning based on complexity-aware probability.
    """
    weights = []
    for g in gaussians:
        # Apply dropout
        c = g.normalized_complexity
        if np.random.rand() < dropout_prob:
            c = 0.0
        
        # Probability proportional to alpha * exp(C)
        prob = g.opacity * np.exp(c)
        weights.append(prob)
    
    # Normalize weights to sum to 1
    total_weight = sum(weights)
    if total_weight == 0:
        return gaussians[0] # Fallback
    
    probs = [w / total_weight for w in weights]
    
    # Sample index
    idx = np.random.choice(len(gaussians), p=probs)
    return gaussians[idx]

def compute_importance_score(gaussians, lambda_weight=2.0):
    """
    Compute importance score S(g_j) for pruning/LoD.
    """
    for g in gaussians:
        # Scale is assumed to be pre-normalized to [0, 1]
        scale = g.max_normalized_scale
        
        # Denominator term
        denom = np.exp(g.normalized_complexity)
        
        # Score formula
        g.importance_score = g.opacity + lambda_weight * (scale / denom)

def compute_variance_loss(full_render, budgeted_render, lambda_var=1.0):
    """
    Compute L_var = Var(E_full - E_budget).
    Assumes E is L1 error map.
    """
    # Compute error maps (absolute difference from ground truth)
    # Note: In practice, E(I) is the error relative to GT. 
    # Here we assume full_render and budgeted_render are already error maps or we compute them.
    # Based on formula: Delta = E(I_full) - E(I_tau)
    
    # If inputs are images, compute L1 error against GT first
    # For simplicity, assuming inputs are error maps or we compute residuals directly
    # Let's assume we have error maps E_full and E_budget
    residuals = full_render - budgeted_render
    
    # Variance over all pixels u in Omega
    var_loss = np.var(residuals)
    
    return lambda_var * var_loss
```

**Parameters:**
- $\eta \in (0, 1]$: Learning rate for complexity EMA update. Not given in the sources.
- $\lambda = 2$: Fixed scalar weight for the scale term in importance scoring [S1, unofficial].
- $\delta = 0.2$: Complexity dropout probability [S1, unofficial].
- $\lambda_{var}$: Weight for the variance loss. Not given in the sources.
- $\tau$: Capacity budget factor. $\tau=1$ for full capacity, $\tau<1$ for budgeted renders [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Complexity Collapse:** Without dropout ($\delta=0$), Gaussians may collapse onto fixed complex regions. Dropout $\delta=0.2$ prevents this [S1, unofficial].
- **Scale Attenuation:** In high-complexity regions, failing to attenuate the scale term can lead to large, blurring primitives. The $\exp(\tilde{C}_j)$ denominator handles this [S1, unofficial].
- **Low-Complexity Efficiency:** In low-complexity regions, the score reduces to $\alpha_j + \lambda \cdot s(g_j)$, allowing large primitives to be retained efficiently [S1, unofficial].
- **Uniform Degradation:** The variance loss $L_{var}$ is crucial for ensuring that the render degrades uniformly as $\tau$ decreases, rather than having the optimizer push surviving primitives away from their full-capacity positions [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Adds overhead for computing complexity maps (delentropy) and updating EMA per step. Complexity map computation is not detailed in the sources.
- **Memory Complexity:** Requires storing a scalar complexity value $C_j$ per Gaussian.
- **Performance:** On the Mip-NeRF 360 dataset at 100% capacity, the method achieves a PSNR of 29.92, SSIM of 0.911, and LPIPS of 0.240, outperforming 3DGS-MCMC (PSNR 29.70, SSIM 0.907, LPIPS 0.236) and LightGaussian (PSNR 29.73, SSIM 0.907, LPIPS 0.240) [S1, unofficial]. At 1% capacity, it achieves PSNR 23.40, SSIM 0.798, LPIPS 0.419, significantly outperforming baselines like LightGaussian (PSNR 19.59) and MGS (PSNR 23.28) [S1, unofficial].
- **Strengths:** Better performance at lower budgets (LoD) compared to full-LoD methods and other partial-LoD methods. Uniform degradation across LoD levels.
- **Limitations:** Requires varying LoD ($\tau$) during training. Performance may vary across LoD, requiring assessment via area under the curve [S1, unofficial].

## Background
Originated in the paper "KoalaGS: Complexity-Aware Continuous Level of Detail for Gaussian Splatting" [S1, unofficial]. The method addresses the limitation of standard 3DGS variants that rely on opacity as a proxy for reconstruction error, which causes under-served regions to remain unresolved. It uses complexity as a surrogate for reconstruction errors, inspired by observations that particle count grows exponentially with complexity [S1, unofficial].
