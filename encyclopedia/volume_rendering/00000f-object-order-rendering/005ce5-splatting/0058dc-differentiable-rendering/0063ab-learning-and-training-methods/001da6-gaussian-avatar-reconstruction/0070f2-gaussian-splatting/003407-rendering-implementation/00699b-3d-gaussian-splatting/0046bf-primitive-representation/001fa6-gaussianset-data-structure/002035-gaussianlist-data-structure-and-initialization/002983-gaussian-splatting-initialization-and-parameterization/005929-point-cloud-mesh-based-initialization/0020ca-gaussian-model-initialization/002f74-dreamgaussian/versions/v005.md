# DreamGaussian

Also called: DreamGaussian: Generative 3D Gaussian Splatting

## Overview
DreamGaussian is a text-to-3D generation method that replaces the MipNeRF representation in the DreamFusion framework with 3D Gaussian Splatting (3DGS), using Score Distillation Sampling (SDS) loss to optimize 3D Gaussians [S1][S3, unofficial]. It distinguishes itself from its parent method, Gaussian Model Initialization, by providing a complete generative pipeline that fully optimizes a textured 3D asset from text prompts, leveraging the efficient splitting process of 3DGS to accelerate optimization [S1][S3, unofficial]. Unlike standard NeRF-based generation, it extracts a mesh from the generated Gaussians and refines texture details via UV-texture optimization, enabling high-quality textured mesh generation in approximately 2 minutes [S2, unofficial].

## How it works
DreamGaussian operates in two distinct stages: (1) SDS-based optimization of 3D Gaussians from a generated image, and (2) mesh extraction and UV-texture refinement [S2, unofficial].

**Inputs and Outputs:**
*   **Input:** A text prompt describing the desired 3D object [S2, unofficial].
*   **Output:** A textured 3D mesh with high-fidelity appearance [S2, unofficial].

**Data Structures:**
The method utilizes the standard 3D Gaussian Splatting data structure, consisting of a list of $N$ Gaussians [G]. Each Gaussian $i$ is defined by:
*   Mean position $\mu_i \in \mathbb{R}^3$ [G]
*   Covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$ (parameterized as rotation $R_i \in SO(3)$ and scale $s_i \in \mathbb{R}^3$) [G]
*   Opacity $\alpha_i \in [0, 1]$ [G]
*   Spherical Harmonics coefficients $c_{i,lm}$ for view-dependent color [G]

**Steps:**

1.  **Initialization:** Initialize a sparse set of 3D Gaussians. Not given in the sources.
2.  **SDS Optimization:**
    *   Render an image from the current 3D Gaussian set using a differentiable rasterizer [G].
    *   Compute the SDS loss by comparing the rendered image against a pretrained 2D diffusion model (e.g., Stable Diffusion) [S1][S3, unofficial].
    *   Update the Gaussian parameters using gradient descent to minimize the SDS loss [S1][S3, unofficial].
    *   Apply the 3DGS splitting process periodically to increase the number of Gaussians in regions of high detail or error, which is described as "very suitable for the optimization progress under the generative settings" [S1][S3, unofficial].
3.  **Mesh Extraction:** Once the Gaussian optimization converges, extract a mesh from the generated 3DGS representation [S1][S3, unofficial]. Not given in the sources.
4.  **UV-Texture Refinement:**
    *   Unwrap the extracted mesh to UV coordinates. Not given in the sources.
    *   Optimize the UV texture map (pixel values) using a pixel-wise Mean Squared Error (MSE) loss between the rendered texture and the target image generated by the diffusion model [S1][S3, unofficial].
    *   This step refines fine texture details that may be lost during the Gaussian optimization phase [S1][S3, unofficial].

**Pseudocode:**

```python
def dream_gaussian(text_prompt):
    # Stage 1: SDS Optimization of 3D Gaussians
    # Initialize sparse 3D Gaussians [G]
    gaussians = initialize_sparse_gaussians()
    diffusion_model = load_pretrained_diffusion_model()  # Standard Stable Diffusion [G]
    
    for step in range(num_optimization_steps):  # Not given in the sources.
        # Render image from current Gaussians using differentiable rasterization [G]
        rendered_image = differentiable_rasterize(gaussians, camera_params)
        
        # Compute SDS loss gradient w.r.t. rendered image [G]
        # Standard SDS: ε_θ(x_t, t) - ε_θ(x̂_t, t) scaled by noise schedule
        sds_loss_grad = compute_sds_gradient(rendered_image, text_prompt, diffusion_model)
        
        # Backpropagate to update Gaussian parameters
        gradients = backpropagate_sds(sds_loss_grad, gaussians)
        gaussians = apply_optimizer(gaussians, gradients)
        
        # Apply 3DGS splitting process to densify [S1][S3, unofficial]
        if step % split_interval == 0:  # Not given in the sources.
            gaussians = split_gaussians(gaussians, threshold)
            
    # Stage 2: Mesh Extraction and Texture Refinement
    mesh = extract_mesh_from_gaussians(gaussians)  # Not given in the sources.
    uv_map = unwrap_mesh_to_uv(mesh)  # Not given in the sources.
    
    # Optimize UV texture
    texture = initialize_texture_map()  # Not given in the sources.
    for step in range(num_texture_steps):  # Not given in the sources.
        # Render texture from mesh
        textured_image = render_mesh_texture(mesh, uv_map, texture, camera_params)
        
        # MSE Loss against target image generated by diffusion model [S1][S3, unofficial]
        mse_loss = mean_squared_error(textured_image, target_image)
        
        # Update texture
        texture = apply_optimizer(texture, mse_loss)
        
    return mesh, texture
```

**Parameters:**
*   **Optimization Steps:** Not given in the sources.
*   **Split Interval:** Not given in the sources.
*   **Texture Steps:** Not given in the sources.
*   **Target Image:** Generated from the text prompt using a 2D diffusion model [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Janus Problem:** Multi-face artifacts can occur. While DreamGaussian primarily uses 2D SDS, related methods mitigate this with 3D SDS or point-cloud initialization [S1][S3, unofficial].
*   **Optimization Time:** The splitting process increases optimization time compared to fixed-resolution NeRFs, but 3DGS remains more efficient than NeRFs for high-resolution rendering [S1][S3, unofficial].

## Subtopics

### [DiffSplat](6554-diffsplat.md)
DiffSplat is a method that natively generates 3D Gaussian splats by fine-tuning a pretrained text-to-image diffusion model, exploiting web-scale 2D priors while maintaining 3D consistency. It addresses the challenge of generating high-fidelity 3D geometry from text or single images by using a lightweight reconstruction model to bootstrap multi-view Gaussian-splat grids for dataset curation and a 3D rendering loss to enforce cross-view coherence. It is distinguished from its sibling HumanGaussian and parent DreamGaussian by its native generation of Gaussian primitives via diffusion fine-tuning, achieving text- and image-to-3DGS in approximately 1-2 seconds.

### Generative Gaussian Splatting
Generative Gaussian Splatting is a method that generates unbounded 3D cities by progressively extending the Gaussian cloud outward from a given seed region with a diffusion prior [S4, unofficial].

## Operating characteristics
*   **Time Complexity:** The method is faster than NeRF-based generation due to the efficiency of 3DGS rendering and splitting [S1][S3, unofficial]. Total generation time is approximately 2 minutes for a textured mesh [S2, unofficial].
*   **Memory Complexity:** 3DGS uses little memory compared to NeRFs, allowing for high-resolution rendering [S1][S3, unofficial].
*   **Strengths:** High-quality textured mesh generation; efficient optimization due to 3DGS splitting; suitability for generative settings [S1][S3, unofficial].
*   **Limitations:** Optimization time is increased by the splitting process compared to static NeRFs [S1][S3, unofficial]. Potential for Janus problem without additional guidance [S1][S3, unofficial].
*   **When to use:** When a high-quality textured mesh is required from a text prompt, and speed is a concern relative to NeRF-based methods [S2, unofficial].
*   **When not to use:** When unbounded scene generation is required (use Generative Gaussian Splatting) or when native diffusion-based generation without SDS is preferred (use DiffSplat) [S2, S4, unofficial].

## Background
DreamGaussian was introduced by Tang et al. in ICLR'24 [S2, unofficial]. It builds on the DreamFusion framework by replacing MipNeRF with 3DGS, leveraging the efficiency advantages of 3DGS for text-to-3D generation based on SDS loss [S1][S3, unofficial]. The method follows the idea of Magic3D for mesh extraction and UV texture refinement [S1][S3, unofficial].
