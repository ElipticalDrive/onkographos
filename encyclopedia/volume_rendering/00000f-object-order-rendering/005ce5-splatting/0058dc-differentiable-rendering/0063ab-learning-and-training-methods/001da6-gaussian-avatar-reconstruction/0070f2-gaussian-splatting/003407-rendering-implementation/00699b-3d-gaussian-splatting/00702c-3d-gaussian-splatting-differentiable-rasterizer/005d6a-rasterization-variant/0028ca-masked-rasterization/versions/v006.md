# Masked-Rasterization

## Overview
Masked-Rasterization is a differentiable rendering technique that allows "masked" (probabilistically inactive) 3D Gaussians to participate in the rasterization pipeline and receive gradient updates, rather than being permanently filtered out [S1]. It solves the problem of outdated Gaussians in dynamic pruning scenarios, where standard alpha-filtering prevents unsampled Gaussians from adjusting their existence probability [S1]. It differs from sibling methods like [Differentiable Radiative Rasterization](4526-differentiable-radiative-rasterization.md) by explicitly integrating binary existence masks into the transmittance and color accumulation steps, enabling dynamic assessment of Gaussian contribution without zeroing out their physical attributes [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ 3D Gaussians, each defined by mean $\boldsymbol{\mu}_i$, covariance $\boldsymbol{\Sigma}_i$, opacity $\alpha_i$, color/features $\mathbf{c}_i$, and a learned binary mask $m_i \in \{0, 1\}$ representing its probability of existence [S1].
*   **Output:** The final pixel color $C$ and gradients for Gaussian attributes and masks [S1].

**Data Structures:**
*   **Gaussian Attributes:** Standard 3DGS parameters [S1].
*   **Mask:** A scalar value $m_i$ per Gaussian [S1]. Unlike previous methods that multiply $m_i$ into opacity or scale, here $m_i$ is applied during the blending loop [S1].

**Numbered Steps:**
1.  **Projection and Splatting:** Transform 3D Gaussians to 2D screen space [G]. Compute the 2D covariance matrix $\boldsymbol{\Sigma}'_i$ using the Jacobian of the projection [G]. Compute the 2D alpha value $\alpha_i$ for each splat based on its center, scale, and rotation [S1].
2.  **Alpha Filtering:** Filter out splats where $\alpha_i = 0$ [S1]. All remaining splats, along with their associated masks $m_i$, are passed to the masked-rasterization stage [S1].
3.  **Tile Sorting:** Sort the remaining splats by depth within tiles, following the standard shared principles of the parent [Rasterization Variant](17388-rasterization-variant.md) [G].
4.  **Masked Blending Loop:** For each pixel, iterate through the sorted splats [G]. Update the transmittance $T$ and accumulated color $C$ using the mask $m_i$ [S1]:
    *   **Transmittance Attenuation:** The transmittance is attenuated by the mask [S1]. If $m_i=0$, the transmittance is not reduced (the Gaussian is "invisible" but present for gradient flow) [S1]. If $m_i=1$, it behaves normally [S1].
    *   **Color Accumulation:** The color contribution is scaled by the mask [S1]. If $m_i=0$, no color is added [S1].
5.  **Gradient Propagation:**
    *   Gaussians with $m_i=0$ do **not** receive gradients for their geometric attributes ($\boldsymbol{\mu}, \boldsymbol{\Sigma}, \alpha$) because they do not affect the final pixel color or transmittance in the forward pass [S1].
    *   However, they **do** receive gradients for their mask $m_i$ (and thus their existence probability) based on the loss, allowing them to "learn" when they should become active ($m_i \to 1$) [S1].

**Formulas:**
Let $T_i$ be the transmittance before splat $i$, and $C_i$ be the accumulated color. Let $\alpha_i$ be the Gaussian's opacity and $m_i$ be its mask.
The standard blending equations are modified as follows [S1]:
$$ T_{i+1} = T_i \cdot (1 - m_i \cdot \alpha_i) $$
$$ C_{i+1} = C_i + m_i \cdot \alpha_i \cdot T_i \cdot \mathbf{c}_i $$
Where $\mathbf{c}_i$ is the color of the Gaussian. Note that $\alpha_i$ itself is computed from the Gaussian's physical properties (center, scale, rotation) and is not multiplied by $m_i$ in its definition, ensuring the Gaussian retains its physical definition even when masked [S1].

**Parameters:**
*   **Mask Sampling:** Masks are sampled from a probability distribution derived from the Gaussian's current importance/existence probability [S1]. Typical pruning ratios reported are 62.4%–75.3% [S1].

**Edge Cases and Pitfalls:**
*   **Zero Alpha Filtering:** If a Gaussian's opacity or scale is set to zero, $\alpha_i$ becomes zero [S1]. This causes the Gaussian to be filtered out *before* rasterization, preventing it from receiving any gradient updates, including for its mask [S1]. This hinders the ability to recover such Gaussians [S1].
*   **Unsampled Gaussians:** If a Gaussian is not sampled (masked out), it must still be processed in the rasterization loop to receive gradients for its mask [S1]. If it is skipped entirely, it remains unchanged, becomes outdated, and risks inaccurate evaluation when eventually sampled in later iterations [S1].
*   **Gradient Disconnection:** Applying the mask to the geometric attributes (opacity/scale) instead of the blending loop causes the Gaussian to be filtered out, breaking the gradient path for the mask [S1].

**Pseudocode:**
```python
import math

def masked_rasterization(gaussians, masks, image_width, image_height):
    # 1. Project and compute alpha (Standard 3DGS step) [G]
    splats = []
    for i, g in enumerate(gaussians):
        # Evaluate 2D Gaussian PDF at pixel center relative to mean [G]
        # Simplified diagonal covariance evaluation for pseudocode clarity [G]
        alpha_i = g.alpha * math.exp(-0.5 * ((g.mu[0]**2) / g.cov2d[0][0] + (g.mu[1]**2) / g.cov2d[1][1]))
        if alpha_i == 0:
            continue
        splats.append({
            'index': i,
            'alpha': alpha_i,
            'color': g.color,
            'mask': masks[i],
            'z': g.z
        })

    # 2. Sort splats by depth within tiles [G]
    splats.sort(key=lambda s: s['z'])

    # 3. Initialize output buffers
    final_color = [[0.0, 0.0, 0.0] for _ in range(image_height * image_width)]
    final_transmittance = [1.0] * (image_height * image_width)

    # 4. Rasterize with Masked Blending
    for y in range(image_height):
        for x in range(image_width):
            idx = y * image_width + x
            T = 1.0
            C = [0.0, 0.0, 0.0]
            for splat in splats:
                # Standard tile/pixel bounding box intersection check [G]
                if not (abs(splat['mu'][0] - x) < 2 * math.sqrt(splat['cov2d'][0][0]) or 
                        abs(splat['mu'][1] - y) < 2 * math.sqrt(splat['cov2d'][1][1])):
                    continue
                m = splat['mask']
                a = splat['alpha']
                c = splat['color']

                # Apply mask to transmittance and color accumulation [S1]
                contribution = m * a * T
                C[0] += contribution * c[0]
                C[1] += contribution * c[1]
                C[2] += contribution * c[2]
                T *= (1.0 - contribution)

            final_color[idx] = C
            final_transmittance[idx] = T

    return final_color, final_transmittance
```

## Subtopics

### MaskGaussian
The primary implementation of this method, which uses probabilistic masks to prune Gaussians dynamically [S1]. It sets itself apart by allowing masked Gaussians to receive gradients for their existence probability, preventing them from becoming outdated [S1]. Choose this when dynamic pruning and efficient memory usage are priorities [S1].

## Operating characteristics
*   **Time Complexity:** Similar to standard 3D Gaussian Splatting rasterization, as the mask application is a simple scalar multiplication per splat [S1]. The overhead is negligible [S1].
*   **Memory Complexity:** Requires storing an additional mask value per Gaussian [S1].
*   **Measured Performance:** On Mip-NeRF360, Tanks & Temples, and Deep Blending datasets, the method achieves pruning ratios of 62.4%, 67.7%, and 75.3% respectively, with rendering speedups of 2.05×, 2.19×, and 3.16×, while sacrificing only 0.02 PSNR on the first two datasets and improving quality on Deep Blending [S1].
*   **Strengths:** Enables dynamic pruning without losing gradient information for inactive Gaussians; outperforms methods that multiply masks with opacity/scale [S1].
*   **Limitations:** Requires careful handling of the mask sampling distribution to ensure stable training [S1].
*   **When to use:** When training 3DGS with aggressive pruning or dynamic scene evolution where Gaussians need to be reactivated [S1].
*   **When not to use:** For static scenes where a fixed set of Gaussians is sufficient, as the overhead of mask management is unnecessary [S1].

## Background
Masked-Rasterization was introduced in the paper "MaskGaussian: Adaptive 3D Gaussian Representation from Probabilistic Masks" by [S1]. It addresses limitations in previous pruning methods (such as those by [4, 17, 34] cited in [S1]) that multiplied masks with Gaussian attributes, leading to zero alpha values and broken gradient paths [S1]. The method is part of the broader effort to optimize 3D Gaussian Splatting for efficiency and dynamic scenes [S1].
