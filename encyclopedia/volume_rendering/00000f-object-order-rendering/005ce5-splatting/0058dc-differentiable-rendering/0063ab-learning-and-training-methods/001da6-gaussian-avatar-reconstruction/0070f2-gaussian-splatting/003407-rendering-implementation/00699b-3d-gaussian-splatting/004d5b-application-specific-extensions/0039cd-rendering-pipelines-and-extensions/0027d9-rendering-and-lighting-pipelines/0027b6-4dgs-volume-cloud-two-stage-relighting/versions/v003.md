# 4DGS-Volume-Cloud Two-Stage Relighting

Also called: Frozen Geometry + Environment Network, Stage 1 + Stage 2

## Overview
This method enables real-time, dynamic relighting of volumetric clouds by decoupling physical geometry from environmental illumination using a two-stage training pipeline [S1, unofficial]. Unlike standard Gaussian Splatting which learns appearance directly, this approach parameterizes Gaussians with physical participating medium properties (extinction, albedo, scattering) and uses a global environment network to compute sky inscattering, allowing arbitrary sun direction changes without retraining the geometry [S1, unofficial]. It builds on [3D Gaussian Splatting](3D-Gaussian-Splatting.md) and [Rendering and Lighting Pipelines](4135-rendering-and-lighting-pipelines.md).

## How it works
The method consists of two distinct stages: Stage 1 trains the physical parameters of the 3D Gaussians under a single sun direction with a black background, and Stage 2 freezes these parameters to train a global environment network for arbitrary relighting [S1, unofficial].

### Inputs and Outputs
**Inputs:**
- A dataset of cloud images captured with pure sun illumination and a black background (UE SkyAtmosphere brightness factor = 0) [S1, unofficial].
- Camera poses and sun directions for each frame [S1, unofficial].

**Outputs:**
- A PLY file containing 3D Gaussians with physical parameters: position, scale, rotation, extinction coefficient ($\sigma_t$), albedo ($\omega$), Henyey-Greenstein anisotropy factor ($g$), and multiple scattering octave weights ($w_n$) [S1, unofficial].
- Sidecar files for Stage 2: `env_net.pt` (environment network weights), `sky_transfer.npy` (visibility SH transfer vectors $V_{lm}$), and `env.json` (configuration) [S1, unofficial].

### Data Structures
Each 3D Gaussian $i$ stores the following physical parameters instead of standard SH colors:
- $\sigma_t$: Extinction coefficient (volume integral of extinction cross-section). Activated via `softplus` and clamped to 5 [S1, unofficial].
- $\omega$: Scattering albedo (RGB). Activated via `sigmoid` [S1, unofficial].
- $g$: Henyey-Greenstein anisotropy factor. Activated via $0.8 \cdot \tanh$ to ensure forward scattering [S1, unofficial].
- $w_n$: Six octave weights for multiple scattering (Frostbite/Wrenninge approximation). Activated via `softplus` [S1, unofficial].

### Numbered Steps

**Stage 1: Physical Parameter Training**
1. **Initialize Gaussians:** Start with a point cloud representation of the cloud volume.
2. **Optimize Physical Parameters:** Train the Gaussians using a dataset with pure sun illumination and a black background. Optimize position, scale, rotation, $\sigma_t$, $\omega$, $g$, and $w_n$ [S1, unofficial].
3. **Compute Sun Transmittance ($T_{sun}$):** For each pixel, compute the multiplicative sun-atmosphere transmittance using the analytic expression:
   $$ T_{sun}(v_l) = \exp(-m(\theta) \cdot \tau_{rgb}) $$
   where $v_l$ is the sun direction, $\theta$ is the sun elevation, $m(\theta)$ is the Kasten-Young air mass (fixed geometry), and $\tau_{rgb} = (\tau_R, \tau_G, \tau_B)$ are learnable zenith optical thicknesses for Red, Green, and Blue channels [S1, unofficial].
   - Note: $\tau_B > \tau_R$ due to Rayleigh scattering ($\propto \lambda^{-4}$), causing darkening and reddening at low sun angles [S1, unofficial].
   - If the sun is below the horizon, a `smoothstep` gate extinguishes the direct sun term [S1, unofficial].
4. **Compute Self-Shadowing ($T_{light}$):** Calculate the geometric occlusion along the sun direction for each Gaussian. This is done via a rasterization pass in "light space" (a narrow FOV camera simulating the sun direction). The CUDA kernel `record_front_tau` records the cumulative optical thickness $\tau$ weighted by $\alpha \cdot T$ for each Gaussian's footprint [S1, unofficial].
5. **Render Loss:** Compare the rendered image against the ground truth. The rendering equation for a pixel is:
   $$ L = T_{sun}(v_l) \odot L_{sun\_term} + \omega \cdot \sum_{lm} E_{lm}(v_l) \cdot V_{lm}(x) $$
   where $L_{sun\_term}$ is the direct sun contribution computed using the physical parameters and $T_{light}$, and the second term is the sky inscattering (initially zero in Stage 1) [S1, unofficial].

**Stage 2: Environment Network Training**
1. **Freeze Geometry:** Load the Stage 1 model and freeze all Gaussian physical parameters ($\sigma_t, \omega, g, w_n$, etc.) [S1, unofficial].
2. **Precompute Visibility Transfer Vectors ($V_{lm}$):** For each Gaussian, compute the sky visibility SH transfer vectors $V_{lm}(x)$. This involves scanning the hemisphere in $N$ directions using `compute_T_light_raster` to calculate geometric occlusion. $V_{lm}$ is colorless and purely geometric, computed once on the frozen point set [S1, unofficial].
3. **Train Environment Network:** Train a global small MLP to predict the sky irradiance field $E_{lm}(v_l)$ represented by low-order Spherical Harmonics (SH). The default SH order is 2 (9 coefficients), configurable via `--env_sh_order` [S1, unofficial].
4. **Optimize:** Use an independent optimizer with a learning rate of $1e-3$, decaying to $0.1\times$. The loss minimizes the difference between the rendered image (using the full equation above) and the ground truth images from the "env-on" dataset (where the sky is visible but the background is black) [S1, unofficial].

### Formulas
- **Sun Transmittance:** $T_{sun}(v_l) = \exp(-m(\theta) \cdot \tau_{rgb})$ [S1, unofficial].
- **Final Radiance:** $L = T_{sun}(v_l) \odot L_{sun\_term} + \omega \cdot \sum_{lm} E_{lm}(v_l) \cdot V_{lm}(x)$ [S1, unofficial].
- **Multiple Scattering:** Approximated using six octave weights $w_n$ and the Henyey-Greenstein phase function $P(v_i, v_o; g \cdot c^n)$, where $v_i = -v_l$ [S1, unofficial].

### Parameters
- **SH Order:** 2 (9 coefficients) for $E_{lm}$ and $V_{lm}$ by default [S1, unofficial].
- **Learning Rate (Stage 2):** $1e-3$ for the environment network [S1, unofficial].
- **Tonemapping:** Default is fixed Narkowicz ACES curve. Can be disabled with `--no-tonemap_aces` if ground truth is linear HDR [S1, unofficial].

### Edge Cases and Pitfalls
- **Multiplicative Sun Term:** The sun term must be multiplicative with $T_{sun} (\le 1)$ because a purely additive term cannot express the darkening (attenuation) caused by atmospheric path length [S1, unofficial].
- **Data Coverage:** The sun direction coverage in the training dataset must be uniform to ensure healthy geometric shadow gradients. Biased direction data can cause vertical extensions to escape supervision [S1, unofficial].
- **Sun Below Horizon:** A smoothstep gate is required to extinguish the direct sun term when the sun is below the horizon to prevent artifacts [S1, unofficial].

```python
def stage1_train(dataset, initial_gaussians):
    """
    Stage 1: Train physical parameters with single sun direction and black background.
    """
    gaussians = initial_gaussians
    optimizer = Adam(gaussians.parameters(), lr=1e-3)
    
    for iteration in range(num_iterations):
        # Sample a frame from dataset (sun illumination, black background)
        frame = dataset.sample()
        camera = frame.camera
        sun_direction = frame.sun_direction
        
        # 1. Project Gaussians to screen space (standard 3DGS rasterization)
        #    Compute 2D covariance, bounding boxes, etc.
        screen_prims = project_gaussians(gaussians, camera)
        
        # 2. Compute Sun Transmittance T_sun
        #    T_sun = exp(-m(theta) * tau_rgb)
        theta = sun_elevation(sun_direction)
        m_theta =kasten_young_air_mass(theta)
        tau_rgb = gaussians.zenith_optical_thickness
        T_sun = exp(-m_theta * tau_rgb)
        
        # 3. Compute Self-Shadowing T_light via rasterization pass
        #    Render in light space to get cumulative optical thickness
        T_light = compute_self_shadow_raster(gaussians, sun_direction)
        
        # 4. Render Image
        #    L = T_sun * (omega * L_light * sum(w_n * T_light^b^n * P(...)))
        #    Note: Sky inscattering term is 0 in Stage 1
        rendered_image = render_physical_gaussians(
            screen_prims, 
            gaussians, 
            sun_direction, 
            T_sun, 
            T_light, 
            sky_irradiance=None
        )
        
        # 5. Compute Loss
        loss = mse_loss(rendered_image, frame.gt_image)
        
        # 6. Backpropagate
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    return gaussians

def stage2_train(stage1_gaussians, env_dataset):
    """
    Stage 2: Freeze geometry, train environment network for arbitrary relighting.
    """
    # Freeze Stage 1 parameters
    for param in stage1_gaussians.parameters():
        param.requires_grad = False
        
    # Initialize Environment Network (MLP)
    env_net = MLP(sh_order=2)
    env_optimizer = Adam(env_net.parameters(), lr=1e-3)
    
    # Precompute Visibility Transfer Vectors V_lm
    # Scan hemisphere for each Gaussian to compute geometric occlusion
    V_lm = compute_visibility_transfer_vectors(stage1_gaussians, num_hemisphere_samples=60)
    
    for iteration in range(num_iterations):
        # Sample a frame from env_dataset (sky visible, background black)
        frame = env_dataset.sample()
        camera = frame.camera
        sun_direction = frame.sun_direction
        
        # 1. Project Gaussians (same as Stage 1)
        screen_prims = project_gaussians(stage1_gaussians, camera)
        
        # 2. Compute Sun Transmittance T_sun
        theta = sun_elevation(sun_direction)
        m_theta =kasten_young_air_mass(theta)
        tau_rgb = stage1_gaussians.zenith_optical_thickness
        T_sun = exp(-m_theta * tau_rgb)
        
        # 3. Compute Self-Shadowing T_light
        T_light = compute_self_shadow_raster(stage1_gaussians, sun_direction)
        
        # 4. Compute Sky Irradiance E_lm from Environment Network
        #    E_lm = env_net(sun_direction)
        E_lm = env_net(sun_direction)
        
        # 5. Render Image
        #    L = T_sun * L_sun_term + omega * sum(E_lm * V_lm)
        rendered_image = render_physical_gaussians(
            screen_prims, 
            stage1_gaussians, 
            sun_direction, 
            T_sun, 
            T_light, 
            sky_irradiance=E_lm,
            visibility_transfer=V_lm
        )
        
        # 6. Compute Loss
        loss = mse_loss(rendered_image, frame.gt_image)
        
        # 7. Backpropagate
        env_optimizer.zero_grad()
        loss.backward()
        env_optimizer.step()
        
    return env_net, V_lm

def render_physical_gaussians(screen_prims, gaussians, sun_direction, T_sun, T_light, sky_irradiance, visibility_transfer):
    """
    Renders the image using physical parameters.
    """
    image = zeros((H, W, 3))
    
    for t in tiles:
        prims = tile_prims[t]
        prims.sort(key=lambda x: x['depth'])
        
        for y in range(t[0], min(t[0] + tile_size, H)):
            for x in range(t[1], min(t[1] + tile_size, W)):
                acc_color = zeros(3)
                T = 1.0
                
                for prim in prims:
                    # Compute 2D Gaussian value
                    diff = vec2(x, y) - prim['data']['xy']
                    inv_sig = inverse_2x2(prim['sigma_2d'])
                    g_val = exp(-0.5 * dot(diff, inv_sig @ diff))
                    
                    # Physical parameters
                    sigma_t = prim['data']['sigma_t']
                    omega = prim['data']['omega']
                    g = prim['data']['g']
                    w_n = prim['data']['w_n']
                    
                    # Sun term
                    # L_sun_term = omega * L_light * sum(w_n * T_light^b^n * P(...))
                    # L_light is derived from sun_direction and T_sun
                    sun_term = compute_sun_term(omega, sun_direction, T_light, w_n, g)
                    
                    # Sky inscattering term
                    # L_sky = omega * sum(E_lm * V_lm)
                    # E_lm is from env_net, V_lm is precomputed
                    sky_term = zeros(3)
                    if sky_irradiance is not None:
                        V_lm_val = lookup_V_lm(prim['id'], visibility_transfer)
                        sky_term = omega * dot(sky_irradiance, V_lm_val)
                    
                    # Combine
                    # L = T_sun * sun_term + sky_term
                    # Note: T_sun is multiplicative attenuation
                    L = T_sun * sun_term + sky_term
                    
                    alpha = sigma_t * g_val
                    weight = alpha * T
                    acc_color += L * weight
                    T *= (1.0 - alpha)
                    
                    if T < 1e-4: break
                    
                image[y, x] = acc_color
                
    return image
```

## Operating characteristics
- **Time Complexity:** Stage 1 training is comparable to standard 3DGS but with additional rasterization passes for self-shadowing. Stage 2 training is faster as geometry is frozen and only the small MLP is trained. Inference is real-time as it involves standard rasterization plus a small MLP evaluation per pixel [S1, unofficial].
- **Memory Complexity:** Requires storing physical parameters for each Gaussian and precomputed $V_{lm}$ vectors. Sidecar files (`env_net.pt`, `sky_transfer.npy`) add minimal overhead [S1, unofficial].
- **Strengths:** Enables arbitrary sun direction relighting without retraining geometry. Physically plausible scattering and attenuation. Real-time performance [S1, unofficial].
- **Limitations:** Requires specific dataset with black background and sun illumination. Does not currently support dynamic time-dependent cloud changes (4D) in the initial implementation [S1, unofficial].
- **When to use:** When real-time dynamic relighting of volumetric clouds is required. Not suitable for general scene relighting as it is specialized for participating media [S1, unofficial].

## Background
The method is based on 3D Gaussian Splatting (Kerbl et al., 2023) and the 3DGS-Volume-Cloud project. It was developed to replace ray-marching volume clouds in game engines with physically parameterized 3D Gaussians for real-time rendering and dynamic relighting [S1, unofficial]. The initial code baseline is `69fea2c8d5a13d6c0e41ac12ca45c80b71bd3403` [S1, unofficial]. It is used in the 4DGS-Volume-Cloud project for rendering clouds from the WDAS Cloud dataset [S1, unofficial].
