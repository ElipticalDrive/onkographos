# 3DGS Adaptive Density Control

Also called: Dynamic Gaussian Densification, Pruning and Splitting, cloning, splitting, and pruning

## Overview
Adaptive Density Control (ADC) is a dynamic optimization mechanism for 3D Gaussian Splatting that adjusts the number of Gaussian primitives during training to balance reconstruction fidelity and memory efficiency [S1]. It solves the problem of sparse initialization by densifying under-represented regions (via splitting or cloning) and pruning over-represented or erroneous primitives (via opacity-based removal) [S1][S2, unofficial]. Unlike static initialization methods, ADC continuously monitors view-space positional gradients to trigger these operations at regular intervals, ensuring the primitive count adapts to scene complexity [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians $G$ with parameters (mean $\mu$, covariance $\Sigma$, opacity $o$, spherical harmonic coefficients $c$), current training iteration $t$, and hyperparameters (thresholds, intervals).
*   **Output:** Updated set $G'$ with added, split, cloned, or removed Gaussians.

**Data Structures:**
Each Gaussian $g_i \in G$ stores:
*   $\mu_i \in \mathbb{R}^3$: 3D mean position.
*   $\Sigma_i \in \mathbb{R}^{3 \times 3}$: Covariance matrix (often stored as scale $s_i \in \mathbb{R}^3$ and rotation $q_i \in \mathbb{R}^4$).
*   $o_i \in [0, 1]$: Opacity.
*   $c_i$: Spherical Harmonic coefficients.
*   $grad\_sum_i \in \mathbb{R}$: Accumulated 2D positional gradient magnitude.
*   $visible\_count_i \in \mathbb{N}$: Number of iterations the Gaussian was visible since the last densification step.

**Numbered Steps:**

1.  **Initialization:** Initialize Gaussians from sparse Structure-from-Motion (SfM) points [S1][S2, unofficial]. Set $grad\_sum_i = 0$ and $visible\_count_i = 0$ for all $i$ [S2, unofficial].

2.  **Gradient Accumulation (Per Iteration):**
    During each training iteration, for every Gaussian $g_i$ projected onto the image plane:
    *   Compute the 2D positional gradient $\nabla_{\mu_{2D}} \mathcal{L}$ of the loss with respect to the projected mean [S2, unofficial].
    *   If $g_i$ is visible (inside the viewing frustum):
        *   $grad\_sum_i \leftarrow grad\_sum_i + \|\nabla_{\mu_{2D}} \mathcal{L}\|$
        *   $visible\_count_i \leftarrow visible\_count_i + 1$ [S2, unofficial]

3.  **Densification Check (Periodic):**
    Perform densification every $I_{dens}$ iterations, starting after a warm-up period $T_{warmup}$ [S2, unofficial].
    *   If $t < T_{warmup}$ or $t > T_{final}$, skip densification [S2, unofficial].
    *   For each Gaussian $g_i$:
        *   Calculate average gradient: $\bar{g}_i = grad\_sum_i / visible\_count_i$ [S2, unofficial].
        *   If $\bar{g}_i > \tau_{grad}$ (gradient threshold):
            *   Select $g_i$ for densification [S2, unofficial].
            *   Reset $grad\_sum_i = 0$ and $visible\_count_i = 0$ [S2, unofficial].
            *   **Split or Clone:**
                *   If scale of $g_i$ is "large" (specifically, if the maximum scale dimension exceeds a threshold relative to scene size, or simply if it is the largest among selected candidates in original implementation):
                    *   **Split:** Replace $g_i$ with two children $g_{c1}, g_{c2}$ using the mechanics defined in [Parent](16227-splitting-mechanics-and-density-preservation.md). The children's positions are shifted along the principal axis with the largest scale [S2, Parent, unofficial].
                *   Else (scale is "small"):
                    *   **Clone:** Duplicate $g_i$ in place. The clone $g_{clone}$ has identical parameters to $g_i$ [S2, unofficial].
        *   Else:
            *   Reset $grad\_sum_i = 0$ and $visible\_count_i = 0$ [S2, unofficial].

4.  **Pruning (Periodic):**
    Performed at the same intervals as densification [S2, unofficial].
    *   For each Gaussian $g_i$:
        *   If $o_i < \tau_{opacity}$ (opacity threshold):
            *   Remove $g_i$ from $G$ [S2, unofficial].

5.  **Opacity Reset (Periodic):**
    To encourage pruning of "floaters" (Gaussians with low opacity but high gradient noise), reset opacities periodically [S2, unofficial].
    *   If $t$ is a multiple of $I_{reset}$ and $t \le T_{final}$:
        *   For each $g_i \in G$:
            *   $o_i \leftarrow \min(o_i, \tau_{reset})$ [S2, unofficial].

**Parameters (Standard 3DGS [S2, unofficial]):**
*   $T_{warmup}$: 600 iterations [S2, unofficial].
*   $I_{dens}$: 100 iterations [S2, unofficial].
*   $\tau_{grad}$: $2 \times 10^{-4}$ [S2, unofficial].
*   $\tau_{opacity}$: 0.05 [S2, unofficial].
*   $T_{final}$: 14,900 iterations [S2, unofficial].
*   $I_{reset}$: 3,000 iterations [S2, unofficial].
*   $\tau_{reset}$: 0.01 [S2, unofficial].
*   Loss weights: L1 = 0.8, D-SSIM = 0.2 [S2, unofficial].
*   Optimizer: Adam ($\beta_1=0.9, \beta_2=0.999, \epsilon=10^{-15}$) [S2, unofficial].
*   Learning Rates: Scale = 0.005, Rotation = 0.001, Opacity = 0.025 (official codebase) or 0.05 (original paper) [S2, unofficial]. Mean LR decays exponentially from $1.6 \times 10^{-4}$ to $1.6 \times 10^{-6}$ [S2, unofficial]. SH 0th degree = $2.5 \times 10^{-3}$, remaining SH = $1.25 \times 10^{-4}$ [S2, unofficial].

**Pseudocode:**

                             tau_opacity=0.05, T_final=14900, I_reset=3000, tau_reset=0.01):
    """
    G: List of Gaussian objects with attributes:
       - grad_sum: float
       - visible_count: int
       - opacity: float
       - scale: vector (max dimension used for split/clone decision in simplified logic)
       - split_or_clone(): method to replace self with children
       - clone(): method to return a copy of self
       - remove(): method to remove self from scene
    """
    
    # 1. Gradient Accumulation happens during the forward/backward pass of each iteration.
    # This function is called at the end of the iteration or at specific intervals.
    
    # 2. Opacity Reset
    if t > 0 and t % I_reset == 0 and t <= T_final:
        for g in G:
            if g.opacity > tau_reset:
                g.opacity = tau_reset

    # 3. Densification and Pruning
    if t >= T_warmup and t <= T_final and t % I_dens == 0:
        to_remove = []
        to_add = []
        
        for g in G:
            # Pruning
            if g.opacity < tau_opacity:
                to_remove.append(g)
                continue
            
            # Densification Eligibility
            if g.visible_count > 0:
                avg_grad = g.grad_sum / g.visible_count
                if avg_grad > tau_grad:
                    # Split or Clone logic
                    # Note: Original 3DGS splits "large" Gaussians and clones "small" ones.
                    # "Large" is typically determined by the maximum scale dimension.
                    # For implementation, we assume a threshold or relative comparison.
                    # Here we use a simplified heuristic: if max_scale > threshold, split.
                    # In the original paper, this is often implicit in the selection of the 
                    # top-K gradients or by checking if the Gaussian is among the largest.
                    # We will assume a generic split/clone decision based on scale magnitude.
                    
                    if is_large_gaussian(g): # Implementation detail: compare max(g.scale) to scene extent or fixed threshold
                        children = g.split()
                        to_add.extend(children)
                    else:
                        clone = g.clone()
                        to_add.append(clone)
            
            # Reset gradients for next interval
            g.grad_sum = 0
            g.visible_count = 0
            
        # Apply changes
        for g in to_remove:
            G.remove(g)
        G.extend(to_add)

## Subtopics

### [Age-Gated Eligibility (AGE)](12511-age-gated-eligibility-age.md)
Age-Gated Eligibility (AGE) is a densification control mechanism that prevents newly created primitives from undergoing split or clone operations immediately after birth. It solves the problem of uncontrolled cascading growth, where a Gaussian born at iteration $k$ splits at $k+1$, its child splits at $k+2$, and so on, which inflates the primitive count, peak memory usage, and training time in dense regions. Unlike standard adaptive density control which re-evaluates all primitives regardless of age, AGE defers the first split-or-clone decision until a Gaussian has survived a fixed maturity window, thereby damping the densification cascade and bounding the final primitive budget without degrading image quality.

### Revised Densify and Prune Algorithm
A variant that integrates corrected scene extent, exponential ascending gradient threshold, and significance-aware pruning [S3]. It iterates over all Gaussians $g_k$. For densification, if the modified gradient magnitude $\tau'_k \ge T_i$, it checks if the maximum scale $max(s_k) > P_{dense} \cdot e'_{scene}$; if true, it splits $g_k$, otherwise it clones $g_k$ [S3]. For pruning, if opacity $o_k < o_{min}$ AND the accumulated significance $\sigma_k$ is in the bottom $N_{prune}$ of all significances $\Sigma$, it prunes $g_k$ [S3]. Implemented in [Improving-ADC-3DGS](https://github.com/fraunhoferhhi/Improving-ADC-3DGS) [S3].

### Complexity-Aware Densification and Importance Scoring
A two-part mechanism for Gaussian Splatting optimization: (1) Complexity-guided densification adds capacity to complex regions during training. (2) An importance score is used during inference/pruning to select primitives for different Levels of Detail (LoD) [S4, unofficial]. Unlike MGS which favors compact, high-opacity primitives that render faster but cover less scene, this method retains large primitives so simple regions remain covered. This makes it slower than MGS at low budgets but provides better coverage and quality [S4, unofficial].

## Operating characteristics
*   **Time Complexity:** Densification and pruning are $O(N)$ per interval, where $N$ is the number of Gaussians. Since intervals are fixed (every 100 iterations), the overhead is constant per training step.
*   **Memory Complexity:** The number of Gaussians $N$ grows dynamically. Peak memory usage occurs near the end of training before pruning stabilizes the count. The opacity reset helps bound this by encouraging removal of low-opacity primitives [S2, unofficial].
*   **Measured Performance:** In the original 3DGS implementation, densification stops after iteration 14,900 [S2, unofficial]. The opacity reset (every 3,000 iterations) helps maintain a compact representation [S2, unofficial].
*   **Strengths:** Automatically adapts to scene complexity; handles sparse SfM initialization; reduces artifacts from over-smoothing or under-sampling [S1][S2, unofficial].
*   **Limitations:** Cascading splits can cause memory spikes if not controlled (e.g., by AGE) [S1]. The fixed thresholds (gradient, opacity) may not be optimal for all scenes [S3].
*   **When to use:** Standard 3DGS training where initialization is sparse and scene complexity varies [S1][S2, unofficial].
*   **When not to use:** If real-time inference speed is critical and a fixed, optimized primitive count is preferred (consider LoD methods like [KoalaGS](12512-koalags-complexity-aware-continuous-level-of-detail.md)) [S4, unofficial].

## Background
Adaptive Density Control was introduced by Kerbl et al. in the original 3D Gaussian Splatting paper [S2, unofficial]. It addresses the insufficiency of sparse SfM point clouds for representing complex geometry [S1]. The method has been refined in subsequent works, such as Faster-GS, which analyzed and improved the optimization parameters (e.g., halving the opacity learning rate) [S2, unofficial]. Variants like AGE and Revised Densify/Prune have been proposed to address specific issues like cascading growth and pruning accuracy [S1, S3].
