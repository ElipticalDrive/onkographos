# Smoothed 2D Supervision

Also called: Adaptive Gaussian blur strategy, Progressive Gaussian Blurring

## Overview
Smoothed 2D Supervision is a regularization technique that blurs 2D training images with a scheduled set of 2D Gaussian kernels to produce smoothed image gradients, stabilize camera alignment, and restrict the spectrum of the learned 3D scene [S2, unofficial][S3]. It sets itself apart from siblings like [Frequency Regularization](6130-frequency-regularization.md) by operating directly on the pixel supervision signal in the image domain rather than modifying the positional encoding or loss weights in the frequency domain, and from [Hard and Soft Depth Regularization](9178-hard-and-soft-depth-regularization.md) by focusing on photometric stability rather than geometric depth constraints [S2, unofficial][S3].

## How it works
**Inputs and Outputs:**
*   **Input:** Ground truth 2D training image $I_{gt}$, current iteration $t$, hyperparameters for kernel schedule.
*   **Output:** Blurred supervision image $I_{blur}$ used in the rendering loss calculation.

**Data Structures:**
*   **Kernel Parameters:** A tuple $(\sigma_t, k_t)$ representing the standard deviation and kernel size at iteration $t$.
*   **Image Buffer:** $I_{blur}$, same resolution and channel count as $I_{gt}$.

**Numbered Steps:**
1.  **Initialize Kernel:** At the start of training, define an initial Gaussian kernel with size $k_{init} \times k_{init}$ and standard deviation $\sigma_{init}$.
2.  **Schedule Update:** For every $k_b$ iterations, reduce the blur intensity. The standard deviation $\sigma_t$ and kernel size $k_t$ are decreased according to a predefined schedule until they reach zero or a minimum threshold [S2, unofficial][S4].
3.  **Apply Blur:** Convolve the ground truth image $I_{gt}$ with the current 2D Gaussian kernel $G_t$ to produce $I_{blur} = I_{gt} * G_t$ [S2, unofficial].
4.  **Compute Loss:** Calculate the rendering loss (e.g., L1 or L2) between the rendered image $I_{render}$ and the blurred supervision image $I_{blur}$ [S2, unofficial].
5.  **Backpropagate:** Propagate gradients through the differentiable renderer and the blur operation (if differentiable) or use the smoothed gradients to update the 3D Gaussian parameters and camera poses [S2, unofficial].

**Formulas:**
The blurred image $I_{blur}(x,y)$ is computed as:
$$ I_{blur}(x,y) = \sum_{i=-k_t/2}^{k_t/2} \sum_{j=-k_t/2}^{k_t/2} I_{gt}(x-i, y-j) \cdot G_t(i,j) $$
where $G_t(i,j)$ is the 2D Gaussian kernel:
$$ G_t(i,j) = \frac{1}{2\pi\sigma_t^2} \exp\left(-\frac{i^2+j^2}{2\sigma_t^2}\right) $$
The loss is typically:
$$ \mathcal{L} = \| I_{render} - I_{blur} \|_1 \quad \text{or} \quad \| I_{render} - I_{blur} \|_2 $$

**Parameters with Typical Values:**
*   Initial kernel size: $9 \times 9$ [S4].
*   Initial standard deviation $\sigma$: $2.4$ [S4].
*   Schedule interval $k_b$: $100$ iterations [S4].
*   Total iterations for full reduction: $19,500$ [S4].
*   Final $\sigma$: $0$ (or near zero) [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Downsampling Interaction:** When downsampling and blurring are activated together, the kernel size must be lowered by the scale of downsampling at the current stage, as the initial hyperparameter choice is based on original image resolutions [S4].
*   **Densification Timing:** The blurring kernel size should be lowered before densifying Gaussians to introduce extra signal on the gradient of erroneous Gaussians as the noise level reduces [S4].
*   **Handcrafted Limitations:** The strategy is handcrafted and cannot fully align frequency relationships between positional encoding and pixel supervision compared to adaptive methods [S3].

**Pseudocode:**
```python
def compute_smoothed_supervision(gt_image, iteration, total_iterations=20000, k_b=100):
    """
    Computes the blurred supervision image based on the current iteration.
    
    Args:
        gt_image: numpy array of shape (H, W, C), ground truth image.
        iteration: int, current training iteration.
        total_iterations: int, total number of training iterations.
        k_b: int, interval for reducing blur.
        
    Returns:
        blurred_image: numpy array, blurred version of gt_image.
    """
    # Initialize kernel parameters based on iteration
    # Schedule: Reduce blur every k_b iterations until iteration 19500
    # Initial: 9x9 kernel, sigma=2.4
    
    if iteration < 19500:
        # Calculate reduction factor
        steps = iteration // k_b
        max_steps = 19500 // k_b
        
        # Linear reduction of sigma from 2.4 to 0
        sigma = 2.4 * (1 - steps / max_steps)
        
        # Kernel size reduction from 9 to 1 (or 3)
        # Assuming linear reduction of kernel size
        kernel_size = max(1, int(9 * (1 - steps / max_steps)))
        if kernel_size % 2 == 0:
            kernel_size += 1
            
    else:
        sigma = 0
        kernel_size = 1
        
    # If sigma is 0, no blur is applied
    if sigma == 0:
        return gt_image
        
    # Create 2D Gaussian kernel
    # Center of kernel
    center = kernel_size // 2
    kernel = np.zeros((kernel_size, kernel_size))
    for i in range(kernel_size):
        for j in range(kernel_size):
            x = i - center
            y = j - center
            kernel[i, j] = np.exp(-(x**2 + y**2) / (2 * sigma**2))
            
    # Normalize kernel
    kernel_sum = np.sum(kernel)
    if kernel_sum > 0:
        kernel /= kernel_sum
        
    # Apply convolution
    # Assuming gt_image has shape (H, W, C)
    blurred_image = np.zeros_like(gt_image)
    for c in range(gt_image.shape[2]):
        blurred_image[:, :, c] = convolve2d(gt_image[:, :, c], kernel, mode='same')
        
    return blurred_image
```

## Subtopics

### [Randomly Scaled Kernel Parameter](7875-randomly-scaled-kernel-parameter.md)
Randomly scales the kernel size during optimization to mitigate weak and noisy gradient signals, allowing combinations of different-sized kernels to guide training.

### [Multiscale Pre-convolved Representation](10911-multiscale-pre-convolved-representation.md)
Enforces consistency with pre-computed, roughness-adapted background reflections to stabilize material-illumination decomposition in neural illumination fields.

### [Soft Rasterization](13687-soft-rasterization.md)
Blends facet contributions for pixels near primitive edges to mitigate discontinuities and provide more useful gradients for backpropagation.

## Operating characteristics
*   **Time Complexity:** Adds a convolution operation per training step. The cost is proportional to $O(H \cdot W \cdot k^2)$ per image, where $k$ is the kernel size. Since $k$ decreases over time, the cost reduces as training progresses [S4].
*   **Memory Complexity:** Requires storing the blurred image buffer, which is $O(H \cdot W \cdot C)$, same as the ground truth image [S2, unofficial].
*   **Measured Performance:** Achieves 19.72 PSNR on DTU 3-view, improving over the baseline of 19.54 PSNR [S3].
*   **Strengths:** Stabilizes camera alignment and prevents divergence from high-frequency noise in raw pixel gradients [S2, unofficial]. Experimentally proven crucial for successful pose refinement [S1].
*   **Limitations:** Handcrafted schedule may not fully align frequency relationships compared to adaptive methods [S3]. Requires careful tuning of the schedule parameters [S4].
*   **When to Use:** When training is unstable due to high-frequency noise or when camera alignment is difficult [S2, unofficial].
*   **When Not to Use:** When adaptive frequency alignment methods are available and sufficient computational resources are not a constraint [S3].

## Background
Smoothed 2D Supervision was introduced to enhance the robustness of joint optimization in 3D reconstruction, particularly for camera pose refinement [S1]. It draws inspiration from spectral analysis and the behavior of 3D radiance fields, where blurring helps restrict the spectrum of the learned scene [S2, unofficial]. The technique has been applied in various contexts, including NeRF and Gaussian Splatting, to improve training stability and final reconstruction quality [S3][S4].
