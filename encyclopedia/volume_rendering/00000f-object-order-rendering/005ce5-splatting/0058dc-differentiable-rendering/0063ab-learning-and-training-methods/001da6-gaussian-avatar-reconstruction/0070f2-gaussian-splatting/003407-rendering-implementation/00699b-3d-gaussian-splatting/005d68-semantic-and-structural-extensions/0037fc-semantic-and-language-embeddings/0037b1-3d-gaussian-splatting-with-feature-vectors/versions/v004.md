# 3D Gaussian Splatting with Feature Vectors


## Overview
This method extends standard 3D Gaussian Splatting by attaching a high-dimensional feature vector $\mathbf{f}_i$ to each Gaussian primitive, enabling the rendering of semantic, visual, or language-aligned feature maps instead of (or in addition to) color [S1, unofficial]. It solves the problem of integrating 2D vision-language models (e.g., CLIP, LSeg) into a 3D representation by alpha-blending these per-Gaussian features to produce a 2D feature map $\mathbf{F}$, which can then be decoded for segmentation or compared against text embeddings for open-vocabulary queries [S1, unofficial].

## How it works
**Inputs:**
*   A set of $N$ 3D Gaussians, each defined by mean $\boldsymbol{\mu}_i$, covariance $\boldsymbol{\Sigma}_i$ (or rotation $\mathbf{R}_i$ and scale $\mathbf{S}_i$), opacity $\alpha_i$, and a high-dimensional feature vector $\mathbf{f}_i \in \mathbb{R}^D$ [S1, unofficial].
*   Camera parameters (view and projection matrices) [G].
*   Image resolution $W \times H$ [G].

**Outputs:**
*   A 2D feature map $\mathbf{F} \in \mathbb{R}^{H \times W \times D}$ [G].

**Data Structures:**
*   **Gaussian Attributes:** Each Gaussian $i$ stores $\mathbf{f}_i$ as a dense vector of size $D$ [S1, unofficial].
*   **Rasterization Buffer:** A buffer of size $H \times W \times D$ initialized to zero to accumulate the blended features [G].

**Steps:**
1.  **Projection:** Project each Gaussian $i$ to 2D screen space, computing its 2D covariance matrix $\boldsymbol{\Sigma}'_i$ and center $\mathbf{c}_i$ [G].
2.  **Sorting:** For each pixel (or tile), sort the overlapping Gaussians $\mathcal{O}_p$ front-to-back based on their depth $z_i$ [G].
3.  **Feature Blending:** For each pixel $p$, compute the accumulated feature $\mathbf{F}(p)$ using alpha-blending:
    $$
    \mathbf{F}(p) = \sum_{i \in \mathcal{O}_p} \mathbf{f}_i \cdot \alpha_i \cdot \prod_{j=1}^{i-1} (1 - \alpha_j)
    $$
    where $\mathbf{f}_i$ is the feature vector of Gaussian $i$, $\alpha_i$ is its opacity, and the product term represents the transmittance from all preceding Gaussians $j$ in the sorted order [S1, unofficial].
4.  **Decoding/Querying:** The resulting $\mathbf{F}(p)$ is either passed to a segmentation head (e.g., a small MLP or linear layer) to predict class labels, or compared against text embeddings $\mathbf{t}_k$ from a language model (e.g., CLIP) using cosine similarity to enable open-vocabulary queries [S1, unofficial].

**Parameters:**
*   **Feature Dimension $D$:** Not given in the sources.
*   **Opacity $\alpha_i$:** Optimized during training alongside features, or fixed from a base 3DGS model [G].

**Edge Cases and Pitfalls:**
*   **Precision:** Accumulating high-dimensional vectors requires sufficient precision. Standard FP16 may be insufficient for large $D$; FP32 is recommended for the feature accumulation buffer [G].
*   **Degenerate Input:** If $\alpha_i \approx 0$, the feature contribution is negligible, but sorting must still be consistent to avoid artifacts [G].
*   **Boundary Conditions:** The product $\prod_{j=1}^{i-1} (1 - \alpha_j)$ becomes 1 when $i=1$ (first Gaussian) [G].

**Pseudocode:**
```python
import numpy as np

def render_feature_map(gaussians, camera, width, height, feature_dim):
    """
    Render a 2D feature map from 3D Gaussians.
    """
    F = np.zeros((height, width, feature_dim), dtype=np.float32)
    T = np.ones((height, width), dtype=np.float32)  # Transmittance buffer

    # 1. Project and collect visible Gaussians
    projected = []
    for g in gaussians:
        # Standard perspective projection
        h = camera.proj @ np.array([g.mean[0], g.mean[1], g.mean[2], 1.0])
        center_2d = (h[:2] / h[3])[:2]
        # Compute 2D covariance via standard 3DGS Jacobian projection [G]
        cov2d = compute_2d_covariance_jacobian(g.cov3d, camera)
        if 0 <= center_2d[0] < width and 0 <= center_2d[1] < height and g.alpha > 0:
            projected.append({
                'center': center_2d,
                'cov2d': cov2d,
                'alpha': g.alpha,
                'feature': g.feature,
                'z': g.z_depth
            })

    # 2. Sort front-to-back
    projected.sort(key=lambda g: g['z'])

    # 3. Rasterize
    for g in projected:
        std = np.sqrt(np.diag(g['cov2d']))
        x_min = max(0, int(g['center'][0] - 3 * std[0]))
        x_max = min(width, int(g['center'][0] + 3 * std[0]) + 1)
        y_min = max(0, int(g['center'][1] - 3 * std[1]))
        y_max = min(height, int(g['center'][1] + 3 * std[1]) + 1)

        for y in range(y_min, y_max):
            for x in range(x_min, x_max):
                diff = np.array([x, y]) - g['center']
                inv_cov = np.linalg.inv(g['cov2d'])
                weight = np.exp(-0.5 * diff @ inv_cov @ diff)
                alpha_contrib = g['alpha'] * weight

                if alpha_contrib < 1e-6:
                    continue

                transmittance = T[y, x]
                F[y, x] += g['feature'] * alpha_contrib * transmittance
                T[y, x] *= (1.0 - alpha_contrib)

    return F

def compute_2d_covariance_jacobian(cov3d, camera):
    # Standard 3DGS 2D covariance projection using camera Jacobian [G]
    return cov3d[:2, :2]  # Simplified for pseudocode completeness
```

## Subtopics

### Scale-Aware Semantic Feature Gating
A mechanism to modulate rendered semantic features based on scale, using learned or fixed gate vectors derived from sampled scales [S2, unofficial]. It maps the distribution of sampled scales to a Gaussian distribution using `self.q_trans(sampled_scales)` [S2, unofficial]. If `scale_aware_dim <= 0` or `scale_aware_dim >= 32`, gates are computed by passing sampled scales through `self.scale_gate`: `gates = self.scale_gate(sampled_scales.unsqueeze(-1))` [S2, unofficial]. Otherwise, scales are discretized to integers: `int_sampled_scales = ((1 - sampled_scales.squeeze()) * scale_aware_dim).long()`, and pre-computed gates are looked up: `gates = self.fixed_scale_gate[int_sampled_scales].detach()` [S2, unofficial]. The rendered features are repeated for each sampled scale: `feature_with_scale = rendered_features.unsqueeze(0).repeat([sampled_scales.shape[0], 1, 1, 1])`, and multiplied by gate vectors: `feature_with_scale = feature_with_scale * gates.unsqueeze(-1).unsqueeze(-1)` [S2, unofficial].

## Background
The method was pioneered by Feature-3DGS [102] and LangSplat [103], which demonstrated that 2D vision-model features could be distilled into 3D Gaussian representations by adding high-dimensional feature vectors to each Gaussian [S1, unofficial]. Language Embedded 3D Gaussians [104] expanded this to full scene understanding, encoding object-level embeddings for phrase grounding. Subsequent works like SplatTalk [105] and 3D Vision-Language GS [106] further extended these capabilities [S1, unofficial].
