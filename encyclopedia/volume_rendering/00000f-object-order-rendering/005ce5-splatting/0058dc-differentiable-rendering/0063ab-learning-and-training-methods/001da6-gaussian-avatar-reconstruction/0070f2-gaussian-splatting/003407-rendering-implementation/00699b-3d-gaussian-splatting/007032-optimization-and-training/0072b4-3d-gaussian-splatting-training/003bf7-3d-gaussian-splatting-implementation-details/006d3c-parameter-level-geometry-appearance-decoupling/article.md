# Parameter-level Geometry-Appearance Decoupling

Also called: Geometry-Appearance Decoupled Modeling, Optimization-Level Geometry–Appearance Parameter Routing, Parameter Routing

## Overview
This method decouples the optimization of geometry and appearance in 3D Gaussian Splatting by restricting the parameter groups affected by specific loss terms, thereby preventing unreliable photometric residuals from contaminating geometric variables [S1, unofficial]. Unlike vanilla 3DGS, which uses a single image-reconstruction objective to optimize geometry and appearance jointly, this approach isolates supervision attribution and update directions at the optimization level without altering the Gaussian representation or alpha-compositing equations [S1, unofficial]. It is distinct from sibling methods that separate representation parameters or texture representations; instead, it operates by routing gradients to specific parameter subsets based on their reliability [S1, unofficial].

## How it works
The method partitions the Gaussian parameters into two disjoint groups and applies routing rules to determine which loss terms update which group.

### Inputs and Outputs
*   **Inputs**:
    *   Gaussian primitives with parameters $\Theta_G$ (geometry) and $\Theta_A$ (appearance) [S1, unofficial].
    *   Training images and camera poses.
    *   Visibility and consensus weights generated by the Visibility-Aware Texture Consensus (VTC) module [S1, unofficial].
    *   Local neighborhood structures for geometric anchoring [S1, unofficial].
*   **Outputs**:
    *   Updated Gaussian parameters $\Theta_G$ and $\Theta_A$ after gradient descent.
    *   Rendered images with improved geometry in texture-degraded regions [S1, unofficial].

### Data Structures
The Gaussian representation remains unchanged from standard 3DGS. The parameters are logically partitioned into two sets:
1.  **Geometry-related parameter group ($\Theta_G$)**: Controls Gaussian position, shape, orientation, and alpha compositing [S1, unofficial].
2.  **Appearance parameter group ($\Theta_A$)**: Consists of spherical-harmonic color coefficients [S1, unofficial].

These sets are disjoint: $\Theta_G \cap \Theta_A = \emptyset$ [S1, unofficial].

### Steps and Formulas
The optimization proceeds by computing gradients for each loss term and applying them only to the designated parameter groups according to the routing rules.

1.  **Define Parameter Groups**:
    Identify $\Theta_G$ (centers, scales, rotations, opacities) and $\Theta_A$ (SH coefficients) [S1, unofficial].

2.  **Compute Loss Terms**:
    *   **Photometric Loss ($\mathcal{L}_{photometric}$)**:
        $$ \mathcal{L}_{photometric} = \sum_{i,j} \| \hat{C}_{ij} - C_{ij} \|_1 $$
        where $\hat{C}_{ij}$ is the rendered color and $C_{ij}$ is the ground truth color at pixel $(i,j)$ [S1, unofficial].
    *   **Foreground-Alpha Loss ($\mathcal{L}_{alpha}$)**:
        $$ \mathcal{L}_{alpha} = \sum_{i,j} \mathbb{I}_{ij} ( \hat{\alpha}_{ij} - \alpha_{ij} )^2 $$
        where $\mathbb{I}_{ij} \in \{0,1\}$ indicates if pixel $(i,j)$ belongs to the valid supervision region, $\hat{\alpha}_{ij}$ is the rendered alpha, and $\alpha_{ij}$ is the ground truth alpha [S1, unofficial].
    *   **DSSIM Loss ($\mathcal{L}_{dssim}$)**: Optional structural-similarity loss [S1, unofficial].
    *   **VTC Appearance-Consistency Loss ($\mathcal{L}_{VTC}$)**: Derived from cross-view color consensus and weights [S1, unofficial].
    *   **Geometric Anchoring Regularizer ($\mathcal{L}_{anchor}$)**: Based on local PCA and structural confidence [S1, unofficial].

3.  **Apply Routing Rules**:
    *   **RGB Loss, DSSIM, and Alpha Loss**: Back-propagate through the standard rendering path to update **both** $\Theta_G$ and $\Theta_A$ [S1, unofficial].
    *   **VTC Appearance-Consistency Loss**: Acts **only** on $\Theta_A$ [S1, unofficial].
    *   **Geometric Anchoring Regularizer**: Acts **only** on $\Theta_G$ [S1, unofficial].

4.  **Center-Direction Processing**:
    The total gradient of the center parameters (part of $\Theta_G$) is processed by a center-direction operator separately after back-propagation to handle geometric updates specifically [S1, unofficial].

5.  **Update Parameters**:
    Perform gradient descent using the routed gradients.

### Parameters
*   $\lambda_{dssim}$: Weight for the optional DSSIM term. Value is 0 in the fixed-Gaussian prototype and 0.2 in the standard 3DGS backend [S1, unofficial].

### Edge Cases and Pitfalls
*   **Weakly Textured Regions**: In scenes with weak textures, repetitive patterns, or dark occlusions, standard photometric residuals are unreliable. This method prevents these errors from propagating into $\Theta_G$ by restricting VTC and anchoring losses to their respective domains [S1, unofficial].
*   **Feedback Contamination**: The method prevents the current rendering error from contaminating the supervision target through feedback, ensuring convexity and MAP interpretations [S1, unofficial].

```python
def update_parameters(gaussians, images, cameras, vtc_weights, local_pca_data, lambda_dssim=0.2):
    """
    Updates Gaussian parameters using parameter-level geometry-appearance decoupling.
    
    Args:
        gaussians: Object containing parameters Theta_G (centers, scales, rot, alpha) 
                   and Theta_A (SH coefficients).
        images: List of ground truth images.
        cameras: List of camera poses.
        vtc_weights: Visibility and consensus weights from VTC module.
        local_pca_data: Local neighborhood structures for geometric anchoring.
        lambda_dssim: Weight for DSSIM loss.
        
    Returns:
        Updated gaussians object.
    """
    # Initialize gradients
    grad_Theta_G = zeros_like(gaussians.Theta_G)
    grad_Theta_A = zeros_like(gaussians.Theta_A)
    
    for image, camera in zip(images, cameras):
        # 1. Render current view
        rendered_color, rendered_alpha, render_info = render_gaussians(gaussians, camera)
        
        # 2. Compute Photometric Loss (RGB)
        # L_photometric = sum(||C_hat - C||_1)
        loss_rgb = compute_l1_loss(rendered_color, image)
        # Back-propagate to BOTH Theta_G and Theta_A
        grad_Theta_G += gradient(loss_rgb, gaussians.Theta_G)
        grad_Theta_A += gradient(loss_rgb, gaussians.Theta_A)
        
        # 3. Compute DSSIM Loss (Optional)
        # L_dssim = lambda_dssim * sum(DSSIM(C_hat, C))
        loss_dssim = lambda_dssim * compute_dssim_loss(rendered_color, image)
        # Back-propagate to BOTH Theta_G and Theta_A
        grad_Theta_G += gradient(loss_dssim, gaussians.Theta_G)
        grad_Theta_A += gradient(loss_dssim, gaussians.Theta_A)
        
        # 4. Compute Foreground-Alpha Loss
        # L_alpha = sum(I_ij * (alpha_hat_ij - alpha_ij)^2)
        # I_ij is 1 if pixel is in valid supervision region, 0 otherwise
        valid_mask = get_valid_supervision_mask(image)
        loss_alpha = compute_mse_loss(rendered_alpha, image_alpha, mask=valid_mask)
        # Back-propagate to BOTH Theta_G and Theta_A
        grad_Theta_G += gradient(loss_alpha, gaussians.Theta_G)
        grad_Theta_A += gradient(loss_alpha, gaussians.Theta_A)
        
        # 5. Compute VTC Appearance-Consistency Loss
        # Acts ONLY on Theta_A
        # Uses vtc_weights to filter observations
        loss_vtc = compute_vtc_consistency_loss(rendered_color, image, vtc_weights)
        grad_Theta_A += gradient(loss_vtc, gaussians.Theta_A)
        
        # 6. Compute Geometric Anchoring Regularizer
        # Acts ONLY on Theta_G
        # Uses local_pca_data for structural confidence
        loss_anchor = compute_geometric_anchoring_loss(gaussians.Theta_G, local_pca_data)
        grad_Theta_G += gradient(loss_anchor, gaussians.Theta_G)
        
    # 7. Center-Direction Operator
    # Separately processes total gradient of center parameters (part of Theta_G)
    centers = gaussians.Theta_G.centers
    total_center_grad = grad_Theta_G.centers
    processed_center_grad = center_direction_operator(total_center_grad, local_pca_data)
    grad_Theta_G.centers = processed_center_grad
    
    # 8. Update Parameters
    gaussians.Theta_G -= learning_rate * grad_Theta_G
    gaussians.Theta_A -= learning_rate * grad_Theta_A
    
    return gaussians
```

## Operating characteristics
*   **Time Complexity**: Similar to standard 3DGS training, as the rendering pipeline is unchanged. The additional overhead comes from computing VTC weights and local PCA structures, which are pre-computed or computed once per iteration [S1, unofficial].
*   **Memory Complexity**: Requires storage for VTC weights and local PCA data, but no new representation parameters [S1, unofficial].
*   **Strengths**: Improves reconstruction quality in texture-degraded scenes by preventing geometric drift caused by unreliable photometric residuals [S1, unofficial].
*   **Limitations**: Relies on the accuracy of the VTC module and local PCA estimates. If these pre-computations are incorrect, the decoupling may fail [S1, unofficial].
*   **When to Use**: Recommended for scenes with weak textures, repetitive patterns, or dark occlusions where standard 3DGS fails [S1, unofficial].

## Background
This method was introduced in the paper "Visibility-Aware Texture Consensus and Local Structural Constraints for 3D Gaussian Reconstruction in Texture-Degraded Scenes" [S1, unofficial]. It addresses the limitation of vanilla 3DGS, which uses a single image-reconstruction objective, allowing unreliable photometric residuals in weakly textured regions to propagate into geometric variables [S1, unofficial]. The method builds on the 3D Gaussian Splatting framework [S1, unofficial].
