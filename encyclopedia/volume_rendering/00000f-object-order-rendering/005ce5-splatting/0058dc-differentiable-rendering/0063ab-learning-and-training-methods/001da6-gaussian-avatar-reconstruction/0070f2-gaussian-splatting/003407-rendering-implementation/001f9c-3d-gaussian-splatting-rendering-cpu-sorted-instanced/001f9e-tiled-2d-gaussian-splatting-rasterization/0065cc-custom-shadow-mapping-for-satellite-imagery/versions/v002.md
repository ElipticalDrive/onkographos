# Custom Shadow Mapping for Satellite Imagery

Also called: Geometrically consistent shadows, Sun camera shadow mapping

## Overview
This method casts geometrically consistent shadows in 3D Gaussian Splatting by comparing elevation renders from a satellite camera and a "sun camera," avoiding ray marching which is incompatible with splatting primitives [S1]. It differs from NeRF-based shadowing (e.g., EO-NeRF) by relying solely on rasterization and elevation comparison rather than volumetric ray marching [S1].

## How it works
**Inputs:** 3D Gaussian primitives (means $\mu_k$, covariances $\Sigma_k$, colors $f_k$, opacities $\alpha_k$), satellite camera projection $A$, sun camera projection $S$, elevation function $E$, density parameter $\rho$, per-camera ambient light coefficient $\psi^A$, and camera-specific affine color correction $\phi^A$ [S1].
**Outputs:** Final image intensity $I_{A,S}(u)$ for each pixel $u$ [S1].
**Data Structures:** Elevation render $E_A(u)$ and sun elevation render $E_S(\tilde{u})$ stored as 2D buffers [S1].

**Steps and Formulas:**
1. Assume the sun is a directional light source far from the scene, allowing uniform handling of sun and satellite cameras via an affine camera model [S1].
2. Render the elevation map for the satellite camera $A$ at pixel $u$ using $E_A(u) = \sum_{k=1}^K [E_{\mu_k}] \omega^A_k(u)$, where $[E_{\mu_k}]$ is the altitude at Gaussian mean $\mu_k$ and $\omega^A_k(u)$ is the splat weight [S1]. Render the sun camera elevation map $E_S$ identically [S1].
3. For each pixel $u$ in the satellite camera, localize it to a 3D world point $x$ using $loc_A(u, E_A(u))$, which solves $A(x) = u$ and $E(x) = E_A(u)$ [S1].
4. Project $x$ to the sun camera to find the homologous point $\tilde{u} = hom_{A,S}(u) = S(loc_A(u, E_A(u)))$ [S1].
5. Resample the sun elevation render at $\tilde{u}$ to obtain $E_S(\tilde{u})$ [S1].
6. Compute the elevation difference $\Delta h_{A,S}(u) = E_S(hom_{A,S}(u)) - E_A(u)$ [S1].
7. Compute the shadow darkening coefficient $s_{A,S}(u) = \min(\exp(-\rho \Delta h_{A,S}(u)), 1)$, modeling attenuation through a homogeneous medium of density $\rho$ [S1].
8. Compute the lighting coefficient $l_{A,S}(u) = s_{A,S}(u) + (1 - s_{A,S}(u))\psi^A$, where $\psi^A$ prevents in-shadow objects from appearing completely black [S1].
9. Compute the final image intensity $I_{A,S}(u) = l_{A,S}(u) \sum_{k=1}^K \phi_A(f_k)\omega^A_k(u)$, where $\phi_A$ is a camera-specific affine color correction applied to intrinsic primitive colors $f_k$ [S1].

**Pseudocode:**
```python
def compute_shadow_mapping(sat_cam, sun_cam, gaussians, elev_func, rho, psi_A, phi_A):
    # sat_cam, sun_cam: objects with .project(x) -> u and .unproject(u) -> (origin, direction)
    # gaussians: list of dicts with 'mean', 'color', 'covariance', 'opacity'
    # elev_func: callable E(x) -> float altitude (affine)
    # rho: float density
    # psi_A: float ambient coefficient
    # phi_A: callable affine color correction
    
    # Step 2: Render elevation maps
    sat_elev = render_elevation(sat_cam, gaussians, elev_func)
    sun_elev = render_elevation(sun_cam, gaussians, elev_func)
    
    H, W = sat_elev.shape
    output = zeros((H, W, 3))
    
    # Steps 3-9: Per-pixel shadow computation
    for y in range(H):
        for x in range(W):
            u = (x, y)
            h_sat = sat_elev[y, x]
            
            # Step 3: Localize pixel to 3D
            ray_o, ray_d = sat_cam.unproject(u)
            # Solve E(ray_o + t * ray_d) = h_sat for t (affine intersection)
            grad = elev_func.gradient
            bias = elev_func.bias
            denom = dot(grad, ray_d)
            if abs(denom) < 1e-6:
                continue # Degenerate ray parallel to elevation plane
            t = (h_sat - (dot(grad, ray_o) + bias)) / denom
            x_3d = ray_o + t * ray_d
            
            # Step 4: Project to sun camera
            u_sun = sun_cam.project(x_3d)
            
            # Step 5: Resample sun elevation
            if is_in_bounds(u_sun, sun_elev.shape):
                h_sun = bilinear_sample(sun_elev, u_sun)
            else:
                h_sun = inf # Outside view implies shadow
                
            # Step 6: Elevation difference
            delta_h = h_sun - h_sat
            
            # Step 7: Shadow coefficient
            s = min(exp(-rho * delta_h), 1.0) if delta_h > 0 else 1.0
            
            # Step 8: Lighting coefficient
            l = s + (1.0 - s) * psi_A
            
            # Step 9: Final intensity
            base_color = zeros(3)
            for g in gaussians:
                w = compute_splat_weight(sat_cam, g, u)
                base_color += phi_A(g['color']) * w
            output[y, x] = l * base_color
    return output

def render_elevation(cam, gaussians, elev_func):
    H, W = cam.image_shape
    elev_map = zeros((H, W))
    for g in gaussians:
        u_2d = cam.project(g['mean'])
        if is_in_bounds(u_2d, (H, W)):
            w = compute_splat_weight(cam, g, u_2d)
            elev_map += elev_func(g['mean']) * w
    return elev_map

def compute_splat_weight(cam, g, u):
    mu_2d = cam.project(g['mean'])
    cov_2d = cam.project_covariance(g['covariance'])
    delta = mu_2d - u
    sigma = dot(delta, dot(cov_2d, delta))
    alpha = g['opacity']
    return alpha * exp(-0.5 * sigma)

def is_in_bounds(u, shape):
    return 0 <= u[0] < shape[1] and 0 <= u[1] < shape[0]

def bilinear_sample(tex, u):
    x, y = u
    x0, y0 = int(floor(x)), int(floor(y))
    x1, y1 = x0 + 1, y0 + 1
    fx, fy = x - x0, y - y0
    v00 = tex[y0, x0]
    v01 = tex[y0, x1]
    v10 = tex[y1, x0]
    v11 = tex[y1, x1]
    return (1-fx)*(1-fy)*v00 + fx*(1-fy)*v01 + (1-fx)*fy*v10 + fx*fy*v11
```

**Parameters:**
*   $\rho$: Density of the homogeneous medium. Typical value not given in the sources.
*   $\psi^A$: Per-camera ambient light coefficient. Typical value not given in the sources.

**Edge Cases and Pitfalls:**
*   Precision, boundaries, and degenerate input handling. Not given in the sources.

## Operating characteristics
*   Time and memory complexity: Not given in the sources.
*   Strengths: Produces geometrically consistent shadows; compatible with Gaussian Splatting without requiring ray marching [S1].
*   Limitations: Assumes a directional light source; shadows are determined by elevation comparison rather than full geometric occlusion [S1].
*   When to use: Satellite imagery rendering where solar direction is known and geometric consistency is important [S1].
*   When not to use: Scenes with complex lighting or where elevation is not a reliable proxy for occlusion [S1].

## Background
This method was introduced in "Gaussian Splatting for Efficient Satellite Image Photogrammetry" (CVPR 2025) [S1]. It builds on the EO-NeRF shadow mapping concept but adapts it for 3DGS by using elevation renders instead of ray marching [S1]. The technique leverages the affine camera model to handle both satellite and sun cameras uniformly [S1].
