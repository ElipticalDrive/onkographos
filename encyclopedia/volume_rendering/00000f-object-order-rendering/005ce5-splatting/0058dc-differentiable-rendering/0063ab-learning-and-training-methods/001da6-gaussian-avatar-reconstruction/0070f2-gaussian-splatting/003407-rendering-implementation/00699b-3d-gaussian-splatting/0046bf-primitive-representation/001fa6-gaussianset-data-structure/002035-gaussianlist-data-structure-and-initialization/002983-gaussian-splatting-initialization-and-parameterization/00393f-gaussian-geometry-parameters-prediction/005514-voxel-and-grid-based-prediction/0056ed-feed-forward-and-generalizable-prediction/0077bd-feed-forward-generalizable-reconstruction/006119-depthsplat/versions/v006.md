# DepthSplat


## Overview
DepthSplat is a feed-forward method for 3D Gaussian Splatting reconstruction that connects Gaussian splatting with depth estimation by leveraging pre-trained monocular depth features to augment multi-view feature matching [S1]. It solves the problem of robust multi-view depth prediction in challenging scenarios (occlusions, low-textured areas, non-Lambertian surfaces) where standard multi-view stereo fails, and scale ambiguities where monocular estimation fails [S1]. Unlike sibling methods that either discard explicit feature matching (e.g., [GS-LRM](16423-gs-lrm.md)) or use monocular features only to refine coarse depth (e.g., [TranSplat](16423-tran-splat.md)), DepthSplat combines cost volumes and monocular features early in the pipeline to ensure multi-view consistency while enhancing robustness [S1].

## How it works
**Inputs:** $N$ input images $\{I_i\}_{i=1}^N$ with corresponding projection matrices $\{P_i\}_{i=1}^N$, where $P_i \in \mathbb{R}^{3 \times 4}$ contains intrinsic and extrinsic parameters [S1].

**Outputs:** A set of 3D Gaussians $\mathcal{G} = \{\mu_j, \alpha_j, \Sigma_j, c_j\}$ for each pixel in the reference views, representing position, opacity, covariance, and color [S1].

**Data Structures:**
*   **Cost Volume $C_i$:** Tensor of size $\frac{H}{s} \times \frac{W}{s} \times D$, where $H, W$ are image dimensions, $s$ is the downsampling factor, and $D$ is the number of depth candidates [S1].
*   **Monocular Features:** Extracted from a pre-trained monocular depth network (e.g., [MiDaS](16423-midas.md) or similar [S1]).
*   **Multi-View Features:** Extracted via a Vision Transformer (ViT) encoder [S1].

**Parameters:**
*   **Downsampling factor $s$:** Controlled by the number of stride-2 $3 \times 3$ convolutions in the feature extraction backbone. $s=4$ if two convolutions are used; $s=8$ if three are used [S1].
*   **Depth candidates $D$:** Uniformly sampled from near/far depth ranges [S1].
*   **Multi-View Transformer:** Contains six stacked self- and cross-attention layers [S1].
*   **Neighboring Views:** For $N > 2$, the top-2 nearest neighboring views are selected based on camera distance to the reference view [S1].

**Steps:**
1.  **Feature Extraction:** For each view $i$, extract per-view features $F_i$ using a ViT encoder [S1]. Simultaneously, extract monocular features from a pre-trained monocular depth model [S1].
2.  **Cost Volume Construction:**
    *   For each view $i$, uniformly sample $D$ depth candidates $\{d_m\}_{m=1}^D$ from the near and far depth ranges [S1].
    *   For each neighboring view $j$ (selected as top-2 nearest if $N>2$), warp the feature $F_j$ to view $i$ using the camera projection matrix $P_i$ and each depth candidate $d_m$ to obtain warped features $\{F_{j \to i}^m\}_{m=1}^D$ [S1].
    *   Compute feature correlations using the dot-product operation between $F_i$ and each warped feature $F_{j \to i}^m$ [S1].
    *   Stack correlations to form the cost volume $C_i \in \mathbb{R}^{\frac{H}{s} \times \frac{W}{s} \times D}$ [S1].
    *   If multiple neighboring views are used, combine their correlation values by averaging [S1].
3.  **Feature Concatenation:** Concatenate the multi-view cost volumes $C_i$ with the extracted monocular features [S1].
4.  **Depth Regression:** Perform depth regression using a 2D U-Net architecture followed by a softmax layer to predict dense per-pixel depth maps $D_i$ [S1].
5.  **Gaussian Unprojection:** Unproject the predicted depth maps $D_i$ to 3D space using camera parameters $P_i$ to obtain Gaussian centers $\mu_j$ [S1].
6.  **Parameter Prediction:** Predict remaining Gaussian parameters (opacity $\alpha_j$, covariance $\Sigma_j$, color $c_j$) using an additional lightweight network/head in parallel with the depth regression [S1].
7.  **Rendering:** Render novel views using the splatting operation with the predicted 3D Gaussians [S1].

**Edge Cases and Pitfalls:**
*   **Occlusions and Low-Texture:** Multi-view depth estimation fails in these areas. DepthSplat mitigates this by augmenting multi-view cost volumes with monocular features [S1].
*   **Scale Ambiguity:** Monocular depth estimation suffers from scale ambiguities. DepthSplat maintains multi-view consistency by using monocular features only as an augmentation to multi-view matching, not as the primary depth source [S1].
*   **Error Propagation:** Unlike methods that refine coarse depth with monocular features (e.g., [TranSplat](16423-tran-splat.md)), DepthSplat combines cost volumes and monocular features early to avoid error propagation from coarse stages [S1].

## Subtopics

### [Gaussian Graph Network](18863-gaussian-graph-network.md)
Gaussian Graph Network (GGN) is a feed-forward method that generates efficient and generalizable 3D Gaussian representations from multi-view images by modeling relations between Gaussian groups from different views using a Gaussian Graph structure.

## Operating characteristics
*   **Time Complexity:** The method is feed-forward, enabling fast reconstruction. It achieves reconstruction in 0.6 seconds for 12 input views at 512x960 resolution [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Training Cost:** Significantly cheaper than data-heavy methods like [GS-LRM](16423-gs-lrm.md). DepthSplat is trained in 2 days with 4 GPUs, whereas [GS-LRM](16423-gs-lrm.md) requires 64 A100 GPUs for 2 days [S1].
*   **Strengths:** Robustness in challenging scenes (low-texture, reflective surfaces) due to monocular feature augmentation; multi-view consistency maintained; efficient training and inference [S1].
*   **Limitations:** Relies on the quality of the pre-trained monocular depth model and the accuracy of the camera projection matrices [S1].
*   **When to use:** When robust feed-forward reconstruction from multiple posed views is needed, especially in challenging environments where standard multi-view stereo fails [S1].
*   **When not to use:** When ground truth depth is available and per-scene optimization is feasible (orthogonal approach) [S1].

## Background
DepthSplat was introduced to overcome the individual limitations of Gaussian splatting and depth estimation, which are typically studied in isolation [S1]. It leverages the synergy between the two tasks: Gaussian splatting can serve as an unsupervised pre-training objective for learning powerful depth models from large-scale multi-view posed datasets, while monocular depth features augment multi-view feature matching for robust reconstruction [S1]. The method was validated on large-scale datasets including TartanAir, ScanNet, RealEstate10K, and DL3DV [S1]. It achieves state-of-the-art performance on ScanNet and RealEstate10K [S1].
