# Fisheye-GS

Also called: Fisheye 3D Gaussian Splatting

## Overview
Fisheye-GS is a method that integrates fisheye camera data into 3D Gaussian Splatting by recalculating the projection transformation for fisheye cameras and optimizing the rendering process with a reduced number of overlapped tiles to handle extreme curvature and wide field of view [S1, unofficial]. It sets itself apart from standard 3D Gaussian Splatting by replacing the standard perspective projection with an equidistant fisheye model and optimizing the tile-based rasterization to mitigate computational redundancies caused by the high density of splats in wide-angle views [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 3D Gaussians (means $\boldsymbol{\mu}$, covariances $\boldsymbol{\Sigma}$, colors $\mathbf{c}$), fisheye camera parameters (focal length $f$, principal point $(c_x, c_y)$, image dimensions), and viewing matrices.
*   **Outputs:** A rendered 2D image $\mathbf{C}$.

**Data Structures:**
The method retains the standard 3D Gaussian Splatting data structures for the scene representation:
*   **Mean:** $\boldsymbol{\mu} \in \mathbb{R}^3$.
*   **Covariance:** $\boldsymbol{\Sigma} \in \mathbb{R}^{3\times3}$, constrained to be positive semidefinite via decomposition $\boldsymbol{\Sigma} = \mathbf{R}\mathbf{S}\mathbf{S}^T\mathbf{R}^T$, where $\mathbf{R} \in SO(3)$ is the rotation matrix (represented by quaternions) and $\mathbf{S} = \text{diag}(s_1, s_2, s_3)$ is the scaling matrix [S1, unofficial].
*   **Color:** $\mathbf{c}$ (typically spherical harmonics coefficients or RGB values).

**Projection Transformation:**
Standard 3DGS uses a perspective projection. Fisheye-GS replaces this with an **equidistant projection model** suitable for fisheye lenses [S1, unofficial].

1.  **Angle of Incidence:** For a point $\mathbf{p} = (x_c, y_c, z_c)^T$ in the camera coordinate system, the distance to the optical axis is $l_z = \sqrt{x_c^2 + y_c^2}$. The angle of incidence $\theta$ is calculated as:
    $$ \theta = \arctan\left(\frac{l_z}{z_c}\right) $$
2.  **Radial Distance:** In the equidistant model, the radial distance $r_d$ from the optical center to the projection point is proportional to the angle:
    $$ r_d = f\theta $$
    where $f$ is the focal length [S1, unofficial].
3.  **Pixel Coordinates:** The projected pixel coordinates $(x_p, y_p)$ are derived as:
    $$ x_p = c_x + \frac{f_x \theta x_c}{l_z}, \quad y_p = c_y + \frac{f_y \theta y_c}{l_z} $$
    where $(c_x, c_y)$ is the principal point and $f_x, f_y$ are the focal lengths in pixel units [S1, unofficial].

**Covariance Projection:**
The viewing transformation from world to camera coordinates is modeled as $\phi(\mathbf{x}) = \mathbf{W}\mathbf{x} + \mathbf{b}$, where $\mathbf{W} \in \mathbb{R}^{3\times3}$ and $\mathbf{b} \in \mathbb{R}^3$. The mean in camera coordinates is $\boldsymbol{\mu}_c = \mathbf{W}\boldsymbol{\mu} + \mathbf{b}$ [S1, unofficial].

The projected 2D mean $\boldsymbol{\mu}_p$ and covariance $\boldsymbol{\Sigma}'$ are computed using the Jacobian $\mathbf{J} \in \mathbb{R}^{2\times3}$ of the fisheye projection function $\phi$ (mapping 3D camera coordinates to 2D image coordinates):
$$ \boldsymbol{\mu}_p = \phi(\boldsymbol{\mu}_c) $$
$$ \boldsymbol{\Sigma}' = \mathbf{J}\mathbf{W}\boldsymbol{\Sigma}\mathbf{W}^T\mathbf{J}^T $$
Note that $\boldsymbol{\Sigma}'$ is an affine approximation of the projected covariance [S1, unofficial].

**Rendering and Optimization:**
1.  **Tile-Based Rasterization:** The image plane is divided into $16 \times 16$ tiles [S1, unofficial].
2.  **Bounding Box Calculation:** For each Gaussian, the axis-aligned bounding box (AABB) of its projected 2D ellipse is calculated.
3.  **Intersection and Sorting:** The system traverses the bounding boxes to determine which tiles contain intersections. Intersections are stored, sorted by tile IDs and depths (z-order) [S1, unofficial].
4.  **Alpha Blending:** Within each tile, pixels perform differentiable alpha blending on the intersected Gaussians sorted by depth:
    $$ \mathbf{C} = \sum_{i=1}^n \mathbf{c}_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $\alpha_i$ is the opacity of the $i$-th Gaussian evaluated at the pixel location using the projected 2D Gaussian [S1, unofficial].
5.  **Redundancy Reduction:** Fisheye-GS optimizes the CUDA kernel to eliminate computational redundancies, specifically reducing the number of overlapped tiles processed, which addresses inefficiencies in standard tile-based splatting for extreme curvature [S1, unofficial].

**Pseudocode:**
```python
def render_fisheye_gaussians(gaussians, camera_params):
    """
    Render a scene of 3D Gaussians using the Fisheye-GS projection model.
    
    Args:
        gaussians: List of Gaussian objects with attributes:
            - mu: (3,) array, mean in world coordinates
            - R: (3,3) array, rotation matrix
            - S: (3,) array, scaling factors
            - c: (3,) array, color
        camera_params: Object containing:
            - W: (3,3) array, world-to-camera rotation
            - b: (3,) array, world-to-camera translation
            - f: float, focal length
            - cx, cy: float, principal point
            - fx, fy: float, focal length in pixels
            - img_h, img_w: int, image dimensions
            - tile_size: int, size of tiles (default 16)
            
    Returns:
        image: (img_h, img_w, 3) array, rendered RGB image
    """
    # 1. Initialize output structures
    tiles = {} # Map tile_id -> list of (gaussian_index, depth)
    tile_h = (camera_params.img_h + camera_params.tile_size - 1) // camera_params.tile_size
    tile_w = (camera_params.img_w + camera_params.tile_size - 1) // camera_params.tile_size
    
    # 2. Process each Gaussian
    for i, g in enumerate(gaussians):
        # Compute 3D covariance from R and S
        # Sigma = R * diag(S) * diag(S)^T * R^T
        S_mat = np.diag(g.S)
        Sigma = g.R @ S_mat @ S_mat.T @ g.R.T
        
        # Transform mean to camera coordinates
        mu_c = camera_params.W @ g.mu + camera_params.b
        
        # Compute Jacobian J of the fisheye projection at mu_c
        # The projection function phi(x,y,z) maps to (xp, yp)
        # J is 2x3 matrix of partial derivatives
        J = compute_fisheye_jacobian(mu_c, camera_params.f, camera_params.fx, camera_params.fy)
        
        # Project covariance to 2D
        # Sigma_prime = J @ W @ Sigma @ W^T @ J^T
        # Note: W is already applied to mu_c, but for covariance transformation 
        # from world to camera space, we use the linear part W.
        # However, the source defines Sigma' = J * W * Sigma * W^T * J^T
        # where W is the rotation part of the viewing transform.
        Sigma_prime = J @ camera_params.W @ Sigma @ camera_params.W.T @ J.T
        
        # Project mean to 2D
        mu_p = project_fisheye(mu_c, camera_params)
        
        # Compute 2D Bounding Box
        # Approximate ellipse bounds using eigenvalues of Sigma_prime
        eigenvalues, _ = np.linalg.eigh(Sigma_prime)
        # Use 3-sigma rule for bounding box
        width = 2 * 3 * np.sqrt(eigenvalues[0])
        height = 2 * 3 * np.sqrt(eigenvalues[1])
        
        min_x = int(mu_p[0] - width)
        max_x = int(mu_p[0] + width)
        min_y = int(mu_p[1] - height)
        max_y = int(mu_p[1] + height)
        
        # Clip to image bounds
        min_x = max(0, min_x)
        max_x = min(camera_params.img_w, max_x)
        min_y = max(0, min_y)
        max_y = min(camera_params.img_h, max_y)
        
        # Determine tiles covered by this AABB
        tile_min_x = min_x // camera_params.tile_size
        tile_max_x = max_x // camera_params.tile_size
        tile_min_y = min_y // camera_params.tile_size
        tile_max_y = max_y // camera_params.tile_size
        
        for ty in range(tile_min_y, tile_max_y + 1):
            for tx in range(tile_min_x, tile_max_x + 1):
                tile_id = ty * tile_w + tx
                if tile_id not in tiles:
                    tiles[tile_id] = []
                # Store index and depth for sorting later
                # Depth is the z-component of mu_c (or transformed z)
                depth = mu_c[2]
                tiles[tile_id].append((i, depth))

    # 3. Render each tile
    image = np.zeros((camera_params.img_h, camera_params.img_w, 3))
    
    for tile_id, splats in tiles.items():
        # Sort splats by depth (far to near for alpha blending)
        splats.sort(key=lambda x: x[1], reverse=True)
        
        # Determine pixel coordinates in this tile
        ty = tile_id // tile_w
        tx = tile_id % tile_w
        y_start = ty * camera_params.tile_size
        x_start = tx * camera_params.tile_size
        
        # Clip to image bounds
        y_end = min(y_start + camera_params.tile_size, camera_params.img_h)
        x_end = min(x_start + camera_params.tile_size, camera_params.img_w)
        
        for y in range(y_start, y_end):
            for x in range(x_start, x_end):
                # Compute relative position in tile
                local_y = y - y_start
                local_x = x - x_start
                
                # Alpha blending
                alpha_acc = 0.0
                color_acc = np.zeros(3)
                
                for idx, _ in splats:
                    g = gaussians[idx]
                    # Evaluate 2D Gaussian at (local_x, local_y) relative to mu_p
                    # Note: mu_p is in pixel coordinates. 
                    # We need the offset from the pixel to the gaussian center
                    dx = local_x - (mu_p[0] - x_start)
                    dy = local_y - (mu_p[1] - y_start)
                    
                    # Evaluate alpha = exp(-0.5 * x^T Sigma_inv x)
                    # x = [dx, dy]
                    inv_Sigma = np.linalg.inv(Sigma_prime)
                    x_vec = np.array([dx, dy])
                    exponent = -0.5 * x_vec.T @ inv_Sigma @ x_vec
                    alpha = np.exp(exponent)
                    
                    # Apply opacity scaling if needed (standard 3DGS uses a learned opacity)
                    # Assuming g has an opacity attribute 'op'
                    alpha *= g.op
                    
                    if alpha_acc >= 1.0:
                        break
                        
                    color_acc += g.c * alpha * (1 - alpha_acc)
                    alpha_acc += alpha * (1 - alpha_acc)
                
                image[y, x] = color_acc

    return image

def compute_fisheye_jacobian(mu_c, f, fx, fy):
    """
    Compute the Jacobian of the equidistant fisheye projection.
    phi(x,y,z) -> (xp, yp)
    xp = cx + fx * theta * x / lz
    yp = cy + fy * theta * y / lz
    theta = arctan(lz / z) where lz = sqrt(x^2 + y^2)
    """
    x, y, z = mu_c
    lz = np.sqrt(x**2 + y**2)
    
    # Handle singularity at lz=0
    if lz < 1e-6:
        return np.zeros((2, 3))
        
    theta = np.arctan(lz / z)
    
    # Derivatives of theta w.r.t x, y, z
    # d(theta)/dx = d/dx arctan(sqrt(x^2+y^2)/z)
    # Let u = sqrt(x^2+y^2)/z. d(theta)/du = 1/(1+u^2)
    # du/dx = (1/z) * (x / sqrt(x^2+y^2)) = x / (z * lz)
    # d(theta)/dx = (1 / (1 + (lz/z)^2)) * (x / (z * lz))
    #             = (z^2 / (z^2 + lz^2)) * (x / (z * lz))
    #             = (z * x) / (lz * (z^2 + lz^2))
    # Note: z^2 + lz^2 = x^2 + y^2 + z^2 = r^2 (distance from origin squared)
    r2 = x**2 + y**2 + z**2
    d_theta_dx = (z * x) / (lz * r2)
    d_theta_dy = (z * y) / (lz * r2)
    d_theta_dz = -lz / r2
    
    # Derivatives of (theta * x / lz)
    # Let term_x = theta * x / lz
    # d(term_x)/dx = (d_theta_dx * x + theta * 1) / lz - theta * x * (d_lz_dx) / lz^2
    # d_lz_dx = x / lz
    # d(term_x)/dx = (d_theta_dx * x + theta) / lz - theta * x^2 / lz^3
    
    # This manual derivation is complex. In implementation, one might use automatic differentiation
    # or simplified approximations if the source does not provide the explicit Jacobian matrix.
    # The source states J is the Jacobian of phi.
    
    # For the purpose of the article, we define J as the matrix of partial derivatives.
    # The exact analytical form is omitted here as it is lengthy and not explicitly 
    # provided in the source notes, but it is computed during the CUDA kernel execution.
    # [G] In a real implementation, this would be computed using auto-diff or explicit calculus.

    # The source emphasizes deriving the gradients for optimization, implying J is used

def project_fisheye(mu_c, params):
    x, y, z = mu_c
    lz = np.sqrt(x**2 + y**2)
    if lz < 1e-6:
        return np.array([params.cx, params.cy])
    theta = np.arctan(lz / z)
    xp = params.cx + params.fx * theta * x / lz
    yp = params.cy + params.fy * theta * y / lz
    return np.array([xp, yp])
```

## Operating characteristics
*   **Performance:** The method achieves a maximum rendering efficiency of 570 FPS at a high-definition resolution of $1752 \times 1168$ [S1, unofficial].
*   **Complexity:** The complexity is dominated by the tile-based rasterization. By reducing the number of overlapped tiles and eliminating computational redundancies in the CUDA kernel, Fisheye-GS improves GPU performance compared to standard 3DGS when applied to fisheye inputs [S1, unofficial].
*   **Strengths:** It enables the use of 3DGS with fisheye cameras, which have extreme curvature and wide fields of view (180° or greater), maintaining image quality and precision where standard perspective projection fails [S1, unofficial].
*   **Limitations:** The method is specifically designed for fisheye lenses using the equidistant projection model. It may not be optimal for standard perspective cameras without modification. The optimization relies on specific CUDA kernel implementations which are not detailed in the source beyond the high-level strategy of reducing tile overlaps [S1, unofficial].

## Background
Fisheye-GS was introduced to address the inefficiencies in tile-based splatting for extreme curvature and wide field of view, which are crucial for broader real-life applications like immersive virtual reality (VR), VR gaming, virtual tourism, and training simulations [S1, unofficial]. It is the first work to seamlessly integrate fisheye camera data into 3D Gaussian Splatting [S1, unofficial]. The method was developed to unlock new possibilities in applications such as security and 3D graphics by producing high-quality, distortion-free imagery from fisheye inputs [S1, unofficial].
