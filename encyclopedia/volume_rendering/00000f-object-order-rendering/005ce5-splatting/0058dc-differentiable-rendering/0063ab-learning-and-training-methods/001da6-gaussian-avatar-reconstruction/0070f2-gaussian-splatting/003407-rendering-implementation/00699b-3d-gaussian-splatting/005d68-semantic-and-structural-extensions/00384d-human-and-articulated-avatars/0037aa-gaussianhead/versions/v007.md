# GaussianHead


## Overview
GaussianHead reconstructs animatable head avatars by combining a tri-plane representation with motion fields to simulate geometrically changing heads during continuous movements [S1][S2, unofficial]. It renders rich textures, including skin and hair [S1][S2, unofficial]. It builds on the canonical space deformation principles of [Human and Articulated Avatars](8209-human-and-articulated-avatars.md) [G].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Canonical 3D Gaussians, pose parameters $\theta$, and expression coefficients [S1][S2, unofficial].
*   **Outputs:** Rendered image $\mathbf{C}(p)$ per pixel $p$ [G].

**Data Structures:**
*   **Tri-plane Representation:** Stores latent features for head geometry and appearance [S1][S2, unofficial].
*   **Motion Fields:** Predicts geometric changes for continuous movements [S1][S2, unofficial].

**Steps:**
1.  **Canonical Initialization:** Initialize 3D Gaussians in a neutral reference pose [G].
2.  **Deformation Prediction:** Use the motion fields to map canonical positions to target positions based on pose $\theta$ and expression [S1][S2, unofficial]. The deformation function $D(\cdot)$ transforms position, rotation, and scale to maintain physical consistency [G].
3.  **Rendering:** Accumulate features using the differentiable alpha-blending pipeline from [Human and Articulated Avatars](8209-human-and-articulated-avatars.md) [G].

**Formulas:**
$$
\mathbf{p}_i^{\text{target}} = D(\mathbf{p}_i^{\text{canonical}}, \theta)
$$
where:
*   $\mathbf{p}_i^{\text{canonical}}$ is the position of the $i$-th Gaussian in the neutral reference pose [G].
*   $\theta$ represents the pose and expression parameters [S1][S2, unofficial].
*   $D(\cdot)$ is the deformation function parameterized by the motion field [S1][S2, unofficial].
*   $\mathbf{p}_i^{\text{target}}$ is the transformed position used for rasterization [G].

**Parameters:**
*   Tri-plane resolution: Not given in the sources [S1][S2, unofficial].
*   Motion field network depth: Not given in the sources [S1][S2, unofficial].

**Edge Cases and Pitfalls:**
*   Precision issues in tri-plane sampling may occur if Gaussian positions fall outside the normalized bounding box [G].
*   Degenerate expressions may cause self-intersections if the motion field lacks regularization [G].

## Subtopics

### FlashAvatar
FlashAvatar embeds a uniform 3D Gaussian field in a parametric face model and learns additional spatial offsets to capture facial details [S2, unofficial]. It pushes the rendering speed to 300 FPS [S2, unofficial].

## Operating characteristics

## Background
GaussianHead was introduced as part of recent advances in 3D Gaussian splatting for human and articulated avatars [S1][S2, unofficial]. It utilizes tri-plane representations and motion fields to handle geometric changes in head avatars [S1][S2, unofficial].
