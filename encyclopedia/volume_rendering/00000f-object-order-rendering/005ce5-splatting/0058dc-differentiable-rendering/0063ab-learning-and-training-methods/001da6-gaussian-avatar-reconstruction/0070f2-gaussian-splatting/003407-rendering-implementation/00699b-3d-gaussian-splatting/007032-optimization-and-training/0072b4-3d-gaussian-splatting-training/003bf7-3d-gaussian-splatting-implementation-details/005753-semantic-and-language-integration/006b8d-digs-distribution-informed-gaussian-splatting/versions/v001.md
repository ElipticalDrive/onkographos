# DIGS (Distribution-Informed Gaussian Splatting)

Also called: Distribution-Informed Gaussian Splatting

## Overview
DIGS is a training-free framework for open-vocabulary 3D segmentation that decouples instance discovery from linguistic naming by maintaining multi-peaked label distributions at instance boundaries [S1, unofficial]. Unlike prior methods that force each Gaussian into a single hard label or continuous feature—causing blurred edges and semantic ambiguity—DIGS uses late-argmax rendering and a tempered Dirichlet update to preserve boundary fidelity, enabling clean instance separation without per-scene gradient training [S1, unofficial].

## How it works
**Inputs:** A set of 3D Gaussians $\{g_i\}$ (position $\mu_i$, covariance $\Sigma_i$, opacity $o_i$, spherical harmonic coefficients for color $c_i$) reconstructed from input images; a sequence of input frames $t$ with corresponding 2D images.
**Outputs:** A class-agnostic instance ontology mapping Gaussians to persistent instances; per-instance embeddings for open-vocabulary querying.

**Data Structures:**
1.  **Per-Gaussian DI Semantic State:** Augments the standard 3DGS primitive with:
    *   $\hat{H}_{gp,k}$: Top-$M$ Hit Accumulator (integer counts of label hits).
    *   $\hat{\pi}_{gp,k}$: Top-$M$ explicit categorical label distribution (probabilities).
    *   $G_j$: Per-instance footprint (set of Gaussian indices belonging to instance $j$).
    *   Lifecycle counters for instance management.
2.  **Rasterizer Extension:** Outputs top-$K$ contributing Gaussian indices and their alpha-compositing weights for each pixel.

**Parameters:**
*   $M$: Number of top labels maintained in the explicit categorical label distribution per primitive.
*   $K$: Number of top contributing Gaussians and their weights output by the extended rasterizer for each pixel.
*   $\tau$: Threshold for the injection bound in the Tempered Dirichlet Update, ensuring $\eta^{(t)}_i \cdot W^{(t)}_i < \tau$.

**Steps:**

1.  **Class-Agnostic Mapping (Stage 1):**
    *   **2D Observation:** For each frame $t$, apply Segment Anything Model (SAM) in automatic mask generation mode to produce class-agnostic 2D instance masks $S^{(t)} = \{\Omega_i\}_{i=1}^{n_s}$. Apply mask-NMS to remove redundant, highly overlapping masks [S1, unofficial].
    *   **Top-K Rendering:** Extend the 3DGS CUDA rasterizer to output, alongside the RGB image, the top-$K$ contributing Gaussian indices and their alpha-compositing weights for every pixel $p$. Calculate the weight $w_{p,k}$ for the $k$-th Gaussian at pixel $p$ using the effective opacity $o_{p,k}$:
        $$ w_{p,k} = o_{p,k} \prod_{k'<k} (1 - o_{p,k'}) $$
        where the product is over all Gaussians $k'$ rendered before $k$ in the front-to-back order [S1, unofficial].
    *   **Late-Argmax Rendering:** Render a label map by aggregating the semantic states of the top-$K$ Gaussians contributing to each pixel. This preserves multi-peaked distributions at boundaries rather than committing to a single label [S1, unofficial].
    *   **Matching:** Hungarian-match the class-agnostic 2D instance masks from SAM to the Late-Argmax-rendered label map to establish correspondence between 2D masks and 3D Gaussians [S1, unofficial].
    *   **Tempered Dirichlet Update:** Update the semantic state of each Gaussian using a closed-form Tempered Dirichlet Update rule. This maintains the top-$M$ Hit Accumulator $\hat{H}_{gp,k}$ and label distribution $\hat{\pi}_{gp,k}$. The update ensures the injection is bounded by $\eta^{(t)}_i \cdot W^{(t)}_i < \tau$ [S1, unofficial].
    *   **Ontology Aggregation:** Aggregate per-Gaussian distributions into a persistent class-agnostic instance ontology using a bidirectional state machine. This maintains per-instance footprints $G_j$ and lifecycle counters [S1, unofficial].

2.  **Multi-Modal Instance Encoding (Stage 2):**
    *   **Auto-View Selection:** For each stable instance in the ontology, perform Auto-View Selection to yield paired context and isolated renderings of the instance's 3D footprint $G_j$ [S1, unofficial].
    *   **Visual Embedding:** Compute the CLIP visual embedding of the isolated 3D footprint rendering [S1, unofficial].
    *   **Text Embedding:** Generate an attribute description of the instance using a Large Language Model (LLM). Compute the CLIP-text embedding of this description [S1, unofficial].
    *   **Fusion:** Linearly fuse the CLIP visual embedding with the CLIP-text embedding to form the final per-instance embedding [S1, unofficial].

3.  **Open-Vocabulary Query:**
    *   Encode the text prompt using CLIP-text.
    *   Match the encoded prompt to the per-instance embeddings by cosine similarity to perform open-vocabulary query without per-query retraining [S1, unofficial].

**Pseudocode:**

```python
def digs_pipeline(gaussians, frames, sam_model, clip_model, llm_model):
    # Stage 1: Class-Agnostic Mapping
    ontology = BidirectionalStateMachine()
    
    for frame in frames:
        # 1. Class-agnostic 2D observation
        masks = sam_model.generate_masks(frame.image)
        masks = mask_nms(masks)
        
        # 2. Top-K geometry-aware rendering
        # Extended rasterizer returns top-K Gaussians and weights per pixel
        pixel_data = extended_rasterize(gaussians, frame.camera)
        # pixel_data[p] = [(gp_k, wp_k) for k in range(K)]
        
        # 3. Late-Argmax Rendering
        # Aggregate per-Gaussian distributions to form a label map
        label_map = late_argmax_render(pixel_data, gaussians.semantic_state)
        
        # 4. Matching
        # Hungarian match 2D masks to label map regions
        matches = hungarian_match(masks, label_map)
        
        # 5. Tempered Dirichlet Update
        for gaussian in gaussians:
            # Update hit accumulator and distribution
            # Ensure injection bound: eta * W < tau
            gaussian.semantic_state.update_tempered_dirichlet(matches, tau)
            
        # 6. Ontology Aggregation
        ontology.update(gaussians, matches)

    # Stage 2: Multi-Modal Instance Encoding
    instance_embeddings = {}
    for instance_id, footprint in ontology.instances.items():
        # Auto-View Selection
        context_render, isolated_render = auto_view_selection(footprint, gaussians)
        
        # Visual Embedding
        visual_emb = clip_model.encode_image(isolated_render)
        
        # Text Embedding via LLM
        description = llm_model.generate_description(footprint)
        text_emb = clip_model.encode_text(description)
        
        # Linear Fusion
        instance_embeddings[instance_id] = linear_fuse(visual_emb, text_emb)
        
    return instance_embeddings

def late_argmax_render(pixel_data, semantic_states):
    label_map = {}
    for p, contributions in pixel_data.items():
        # contributions: list of (gaussian_idx, weight)
        # Aggregate distributions weighted by alpha-compositing weights
        aggregated_dist = zeros(J) # J is label registry size
        for gp_k, w_p_k in contributions:
            dist = semantic_states[gp_k].distribution
            aggregated_dist += w_p_k * dist
        # Late argmax: decide label based on majority of unambiguous neighbours
        # or top-M distribution peak
        label_map[p] = argmax(aggregated_dist)
    return label_map
```

## Operating characteristics
*   **Time Complexity:** Class-agnostic mapping completes in 0.91 minutes on a single A100 GPU, representing a 60–250× reduction compared to 1–4 hours of per-scene gradient training required by distillation baselines [S1, unofficial]. Total pipeline time (mapping + encoding) is 1.0–3.2 minutes per scene [S1, unofficial].
*   **Query Latency:** DIGS serves native 3D queries in 5.4 ms [S1, unofficial].
*   **Accuracy:** On LERF-OVS, DIGS achieves 71.95% mean mIoU, outperforming training-free SFS and training-based LaGa baselines [S1, unofficial]. On LERF-Mask, it achieves 91.71 mean mIoU, +3.3 over the previous best ObjectGS (88.4) [S1, unofficial].
*   **Strengths:** Training-free operation; clean instance boundaries via multi-peaked distributions; fast inference; no per-query retraining.
*   **Limitations:** Relies on SAM for initial mask generation; requires LLM for attribute description generation (adds latency to encoding phase); performance depends on the quality of the underlying 3DGS reconstruction.

## Background
DIGS was introduced to address the limitations of existing 3D Gaussian segmentation methods, which typically bind semantic features via per-scene gradient training (taking 1–4 hours) or closed-form distillation, both of which commit each primitive to a single feature [S1, unofficial]. This hard commitment degrades retrieval accuracy and yields unstable mask boundaries at render time, especially for boundary Gaussians spanning multiple 2D instances [S1, unofficial]. DIGS proposes a training-free framework that decouples instance discovery from linguistic naming, achieving state-of-the-art results on open-vocabulary segmentation benchmarks [S1, unofficial].
