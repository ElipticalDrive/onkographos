# Oriented Gaussian Splatting

Also called: Definition 2, Oriented Gaussian, Reciprocal Oriented Gaussian

## Overview
Oriented Gaussian Splatting is a variant of 3D Gaussian Splatting that assigns a learnable normal vector $n_i$ to each primitive to enforce a reciprocal attenuation model [S1]. This modification restores the reciprocity condition ($\sigma(x, w) = \sigma(x, -w)$) broken by standard Gaussian Splatting, enabling the application of the Objects as Volumes (OaV) framework to derive explicit geometric fields, such as normals and occupancy [S1]. Unlike [3D Skew-Normal Splatting](10045-3d-skew-normal-splatting.md) which uses skewness for asymmetry, or [Barycentric Splat Parameterization](15283-barycentric-splat-parameterization.md) which constrains centers to a mesh, this method explicitly models surface wrapping via half-space attenuation to facilitate high-fidelity mesh extraction [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ Gaussian primitives, each defined by center $\mu_i$, covariance $\Sigma_i$ (from rotation $R_i$ and scaling $S_i$), opacity $\alpha_i$, color $c_i$, and a learnable oriented normal vector $n_i \in S^2$ [S1, Parent]. Training images, camera poses, and initial Gaussian parameters [S1].
*   **Outputs:** Optimized Gaussian parameters ($\mu_i, \Sigma_i, \alpha_i, c_i, n_i$) and an explicit triangular mesh extracted from the resulting geometric fields [S1].

**Data Structures:**
Each Gaussian $i$ stores:
*   $\mu_i \in \mathbb{R}^3$: Center position.
*   $R_i \in SO(3)$: Rotation matrix (parameterized by quaternion or axis-angle).
*   $S_i \in \mathbb{R}^3$: Scaling vector.
*   $\alpha_i \in [0, 1]$: Opacity.
*   $c_i \in \mathbb{R}^3$: Color (SH coefficients).
*   $n_i \in S^2$: Oriented normal vector (unit length).

**Method Steps:**

1.  **Oriented Attenuation Definition:**
    For a query point $\mathbf{x}$ and view direction $\mathbf{w}$, the oriented attenuation coefficient $\bar{\sigma}_i$ is defined as [S1]:
    $$ \bar{\sigma}_i(\mathbf{x}, \mathbf{w}) = \mathbf{1}_{n_i^T(\mathbf{x}-\mu_i) \geq 0} |\mathbf{w} \cdot \nabla \log(1 - G_i(\mathbf{x}))| $$
    where $G_i(\mathbf{x}) = \alpha_i \exp\left(-\frac{1}{2}(\mathbf{x} - \mu_i)^\top \Sigma_i^{-1} (\mathbf{x} - \mu_i)\right)$ is the standard Gaussian density, and $\mathbf{1}$ is the indicator function ensuring attenuation only occurs on the side of the center pointed to by $n_i$ [S1]. This formulation ensures reciprocity [S1].

2.  **Geometric Field Derivation (OaV):**
    Assuming the Gaussians properly wrap the scene geometry, the vacancy field $v(\mathbf{x})$ is approximated by iterating over all training camera rays $\mathcal{T}_c$ to find the maximum product of unobstructed transmittance [S1]:
    $$ v(\mathbf{x}) = \max_{(\mathbf{o}, \mathbf{w}) \in \mathcal{T}_c} \left\{ \prod_{i=1}^N \left( 1 - \bar{G}_{\mathbf{o}, \mathbf{w}}^{(i)}(t) \right) : \mathbf{x} = \mathbf{o} + t\mathbf{w}, t > 0 \right\} $$
    where $\bar{G}_{\mathbf{o}, \mathbf{w}}^{(i)}(t) = G_i(\mathbf{o} + \min(t, t_{G_i}^{\mathbf{o},\mathbf{w}})\mathbf{w})$ and $t_{G_i}^{\mathbf{o},\mathbf{w}} := \arg \max_{t \geq 0} G_i(\mathbf{o} + t\mathbf{w})$ [S1].
    
    The Gaussian vector field $V(\mathbf{x})$ is the gradient of the log-vacancy, computed as the sum of gradients of the Gaussian components for those oriented towards the query point [S1]:
    $$ V(\mathbf{x}) := \nabla \log v(\mathbf{x}) = \sum_{i=1}^N \mathbf{1}_{n_i^T(\mathbf{x}-\mu_i) \geq 0} \nabla \log(1 - G_i(\mathbf{x})) $$
    The normal field is the normalized vector field [S1]:
    $$ \mathcal{N}(\mathbf{x}) := \frac{V(\mathbf{x})}{\|V(\mathbf{x})\|} $$

3.  **Training Loss:**
    The total loss combines photometric, depth-normal consistency, normal alignment, and multi-view losses [S1]:
    $$ \mathcal{L} = \mathcal{L}_{\text{RGB}} + \lambda_{\text{DN}} \mathcal{L}_{\text{DN}} + \lambda_{\text{N}} \mathcal{L}_{\text{N}} + \mathcal{L}_{\text{MV}} $$
    *   $\mathcal{L}_{\text{RGB}}$: Standard photometric loss [S1].
    *   $\mathcal{L}_{\text{DN}}$: Depth-normal consistency loss [S1].
    *   $\mathcal{L}_{\text{N}}$: Normal alignment loss, enforcing surface wrapping by aligning rendered normals with depth gradients [S1]:
        $$ \mathcal{L}_N = \sum_p 1 - N(p) \cdot \nabla D(p) $$
        where $N(p)$ is the rendered oriented normal at pixel $p$ and $\nabla D(p)$ is the image-space gradient of the rendered depth [S1].
    *   $\mathcal{L}_{\text{MV}}$: Multi-view consistency loss [S1].
    *   **Parameters:** $\lambda_{\text{DN}} = 0.05$, $\lambda_{\text{N}} = 0.05$, $\lambda_{\text{pc}} = 0.6$, $\lambda_{\text{gc}} = 0.02$ [S1].

4.  **Densification:**
    Every $K$ iterations, compute errors $\mathcal{L}_N(p)$ across all training views and propagate them to individual Gaussians via their blending weights [S1]. High-error Gaussians are cloned with flipped normals to close holes in the wrapping shell [S1].

5.  **Mesh Extraction (Pivot-Based Marching Tetrahedra):**
    1.  **Spawn Pivots:** For each Gaussian $i$, spawn two Delaunay pivots: the center $\mu_i$ and $\mu_i + 3s_i n_i$, where $s_i = \|S_i R_i^T n_i\|_2$ is the ellipsoid scaling along $n_i$ [S1].
    2.  **Compute Occupancy:** Calculate vacancy values at each pivot using the approximation in Step 2 [S1].
    3.  **Marching Tetrahedra:** Apply Marching Tetrahedra on the resulting Delaunay triangulation [S1].
    4.  **Refinement:** Refine vertices to the 0.5-isosurface via binary search [S1].

    **Alternative: Primal Adaptive Meshing:**
    1.  **Initialization:** Initialize vertices by sampling marching tetrahedra mesh faces, weighting each face inversely proportional to its distance from the nearest training camera [S1].
    2.  **Refinement:** Project vertices onto the 0.5-isosurface of $v$ via iterative Newton update [S1]:
        $$ x_{i+1} = x_i + \frac{1}{2}(0.5 - v(x_i))\mathcal{N}(x_i) $$
    3.  **Filtering:** Remove vertices $x$ with $|0.5 - v(x)| > \epsilon$ [S1]. Iterate stages 1-3 until no points are removed [S1].
    4.  **Delaunay & Extraction:** Compute Delaunay tetrahedralization of remaining vertices, classify tetrahedra as inside/outside based on vacancy of sampled interior points, and extract triangle faces separating inside and outside tetrahedra [S1].

**Pseudocode:**

```python
import numpy as np

def compute_oriented_attenuation(x, w, mu, Sigma_inv, alpha, n):
    """Computes the oriented attenuation coefficient for a single Gaussian."""
    diff = x - mu
    exponent = -0.5 * diff @ Sigma_inv @ diff
    G = alpha * np.exp(exponent)
    if G >= 1.0:
        return 0.0
    grad_log = (G / (1.0 - G)) * (Sigma_inv @ diff)
    directional_deriv = np.abs(w @ grad_log)
    if n @ diff >= 0:
        return directional_deriv
    return 0.0

def compute_vacancy_field(x, gaussians, training_rays):
    """Computes the vacancy field v(x) by iterating over training rays."""
    max_transmittance = 0.0
    for o, w in training_rays:
        transmittance = 1.0
        for g in gaussians:
            mu, Sigma, alpha, n = g['mu'], g['Sigma'], g['alpha'], g['n']
            Sigma_inv = np.linalg.inv(Sigma)
            A = w @ Sigma_inv @ w
            B = w @ Sigma_inv @ (o - mu)
            t_G = -B / A if A != 0 else 0.0
            t_x = w @ (x - o)
            if t_x <= 0:
                continue
            t_eval = max(0.0, min(t_x, t_G))
            x_eval = o + t_eval * w
            diff = x_eval - mu
            exponent = -0.5 * diff @ Sigma_inv @ diff
            G_val = alpha * np.exp(exponent)
            transmittance *= (1.0 - G_val)
        if transmittance > max_transmittance:
            max_transmittance = transmittance
    return max_transmittance

def compute_vector_field(x, gaussians):
    """Computes V(x) = sum of gradients for oriented Gaussians."""
    V = np.zeros(3)
    for g in gaussians:
        mu, Sigma_inv, alpha, n = g['mu'], np.linalg.inv(g['Sigma']), g['alpha'], g['n']
        diff = x - mu
        exponent = -0.5 * diff @ Sigma_inv @ diff
        G = alpha * np.exp(exponent)
        if G >= 1.0:
            continue
        grad_log = (G / (1.0 - G)) * (Sigma_inv @ diff)
        if n @ diff >= 0:
            V += grad_log
    return V

def extract_mesh_pivot_based(gaussians, training_rays):
    """Extracts mesh using Pivot-Based Marching Tetrahedra."""
    pivots = []
    pivot_values = []
    for g in gaussians:
        mu, n, S, R = g['mu'], g['n'], g['S'], g['R']
        S_mat = np.diag(S)
        s_i = np.linalg.norm(S_mat @ (R.T @ n))
        p1 = mu
        p2 = mu + 3 * s_i * n
        pivots.extend([p1, p2])
        pivot_values.extend([compute_vacancy_field(p1, gaussians, training_rays),
                             compute_vacancy_field(p2, gaussians, training_rays)])
    # Standard Delaunay triangulation and Marching Tetrahedra algorithms are applied here.
    # Not given in the sources.
    return pivots, pivot_values

def train_oriented_gaussians(gaussians, images, cameras, gt_depths, iterations=30000, K=100, lr=0.01):
    """Main training loop with explicit loss and densification steps."""
    lambda_DN = 0.05
    lambda_N = 0.05
    lambda_pc = 0.6
    lambda_gc = 0.02

    for i in range(iterations):
        # 1. Render: Composite Gaussians using a differentiable rasterizer
        rendered_rgb, rendered_depth, rendered_normals = [], [], []
        for cam, img in zip(cameras, images):
            rgb = np.zeros_like(img)
            depth = 0.0
            normal = np.zeros(3)
            total_alpha = 0.0
            for g in gaussians:
                # Project Gaussian to 2D, compute screen-space contribution
                # (Implementation details of differentiable rasterization omitted; standard in 3DGS)
                pass
            rendered_rgb.append(rgb)
            rendered_depth.append(depth)
            rendered_normals.append(normal)

        # 2. Compute Losses
        L_RGB = np.mean(np.array([np.mean((r - i)**2) for r, i in zip(rendered_rgb, images)]))
        L_DN = np.mean(np.array([np.mean(np.abs(r - d)) for r, d in zip(rendered_depth, gt_depths)]))
        # Normal alignment loss: sum_p (1 - N(p) . grad D(p))
        L_N = np.mean(np.array([np.mean(1 - np.sum(n * np.gradient(d))) for n, d in zip(rendered_normals, rendered_depth)]))
        L_MV = lambda_pc * L_RGB + lambda_gc * L_RGB # Multi-view consistency approximation

        L_total = L_RGB + lambda_DN * L_DN + lambda_N * L_N + L_MV

        # 3. Update parameters via gradient descent
        for g in gaussians:
            g['mu'] -= lr * np.gradient(L_total, g['mu'])
            g['n'] -= lr * np.gradient(L_total, g['n'])
            # Other parameters (Sigma, alpha, c) updated similarly via backpropagation

        # 4. Densification
        if i % K == 0:
            # Compute per-pixel normal alignment errors
            pixel_errors = [np.mean(1 - np.sum(n * np.gradient(d))) for n, d in zip(rendered_normals, rendered_depth)]
            # Propagate errors to Gaussians via blending weights (standard alpha-weighted accumulation)
            gaussian_errors = [np.mean(e) for e in pixel_errors]
            # Clone high-error Gaussians and flip normals to close holes
            new_gaussians = []
            for g, err in zip(gaussians, gaussian_errors):
                new_gaussians.append(g)
                if err > np.mean(gaussian_errors):
                    flipped_g = g.copy()
                    flipped_g['n'] = -flipped_g['n']
                    new_gaussians.append(flipped_g)
            gaussians = new_gaussians
    return gaussians
```

## Operating characteristics
*   **Time Complexity:** Rendering is similar to standard 3DGS, $O(N)$ per pixel for splatting [S1]. Vacancy field computation for mesh extraction is $O(N \cdot R)$ where $R$ is the number of training rays, which is expensive and typically done offline or sparsely [S1].
*   **Memory Complexity:** Stores an additional normal vector $n_i$ per Gaussian, increasing memory by $3 \times 4$ bytes per Gaussian compared to standard 3DGS [S1].
*   **Performance:** Produces substantially lighter, fully watertight meshes compared to prior works requiring 9 pivots per Gaussian, without sacrificing surface fidelity [S1].
*   **Strengths:** Enables explicit geometric field derivation (normals, occupancy) via OaV; restores reciprocity; facilitates high-fidelity mesh extraction [S1].
*   **Limitations:** Requires Gaussians to properly "wrap" the scene geometry; consistency requirement that the region where transmittance is constant lies inside the object [S1]. Hidden Gaussians inside geometry can violate wrapping assumptions and produce artifacts if intersected [S1].
*   **When to use:** When explicit surface reconstruction (mesh) is required from a radiance field representation, particularly for scenes where standard 3DGS fails to provide clean normals or watertight meshes [S1].
*   **When not to use:** When only novel view synthesis is needed and mesh extraction is not required, as standard 3DGS is simpler and faster [S1].

## Background
Oriented Gaussian Splatting was introduced in "From Blobs to Spokes: High-Fidelity Surface Reconstruction via Oriented Gaussians" [S1]. It addresses the lack of reciprocity in standard 3D Gaussian Splatting attenuation, which prevents the direct application of the Objects as Volumes (OaV) framework for deriving explicit geometric fields [S1]. The method builds on the OaV theory [39] and integrates with differentiable rasterizers [55, 56, 57] [S1].
