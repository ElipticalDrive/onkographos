# Surface-guided Gaussian Re-initialization

Also called: GVA

## Overview
Surface-guided Gaussian Re-initialization (GVA) is a training optimization method that resolves the unbalanced aggregation of 3D Gaussians caused by densification and splitting operations [S1][S2, unofficial]. It uses a surface-guided re-initialization strategy to make trained Gaussians better fit the input monocular video [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of trained 3D Gaussians $\{G_i\}$ and a canonical surface mesh $\mathcal{M}$ [S1][S2, unofficial].
*   **Output:** Re-initialized Gaussians $\{G'_i\}$ [S1][S2, unofficial].

**Data Structures:**
*   **Canonical Mesh $\mathcal{M}$:** Defined by vertices and faces [S1][S2, unofficial].
*   **Gaussian $G_i$:** Defined by center, rotation, scale, opacity, and spherical harmonics coefficients [G].

**Steps:**
1.  **Identify Unbalanced Aggregation:** Detect Gaussians that have clustered excessively due to densification and splitting operations [S1][S2, unofficial].
2.  **Apply Surface-Guided Re-initialization:** Reposition the Gaussians using a surface-guided strategy [S1][S2, unofficial].
3.  **Fit to Video:** Update the Gaussians so they better fit the input monocular video [S1][S2, unofficial].

**Pseudocode:**
```python
import math

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def cross(a, b):
    return [a[1]*b[2]-a[2]*b[1], a[2]*b[0]-a[0]*b[2], a[0]*b[1]-a[1]*b[0]]

def norm(v):
    return math.sqrt(dot(v, v))

def normalize(v):
    n = norm(v)
    return [v[0]/n, v[1]/n, v[2]/n]

def mat_mul(A, B):
    return [[sum(A[i][k]*B[k][j] for k in range(3)) for j in range(3)] for i in range(3)]

def reinitialize_gaussians(gaussians, mesh):
    """
    Re-initialize Gaussian positions and orientations based on a canonical mesh.
    
    Args:
        gaussians: List of dicts with 'center', 'rotation', 'scale'
        mesh: Object with 'get_closest_point_and_normal(center)' method
    Returns:
        List of re-initialized Gaussian dicts
    """
    reinitialized = []
    
    for g in gaussians:
        # Step 1: Find closest point on mesh
        closest_point, surface_normal = mesh.get_closest_point_and_normal(g['center'])
        
        # Step 2: Re-initialize position
        g['center'] = closest_point
        
        # Step 3: Align orientation with surface normal
        # Standard approach: rotate the Gaussian's principal axis (z-axis) to align with surface_normal
        z_axis = [0, 0, 1]
        if norm(cross(z_axis, surface_normal)) < 1e-6:
            pass # Vectors are parallel or anti-parallel
        else:
            axis = normalize(cross(z_axis, surface_normal))
            angle = math.acos(max(-1.0, min(1.0, dot(z_axis, surface_normal))))
            
            # Rodrigues' rotation formula to align z-axis to surface_normal
            k = axis
            K = [[0, -k[2], k[1]], [k[2], 0, -k[0]], [-k[1], k[0], 0]]
            R_align = [[1,0,0],[0,1,0],[0,0,1]]
            for i in range(3):
                for j in range(3):
                    R_align[i][j] += math.sin(angle) * K[i][j]
                    for l in range(3):
                        R_align[i][j] += (1 - math.cos(angle)) * (K[i][l] * K[l][j])
            
            # Apply rotation to existing rotation matrix
            g['rotation'] = mat_mul(R_align, g['rotation'])
        
        # Step 4: Recompute covariance from rotation and scale
        # Sigma = R * S * S^T * R^T
        scale_diag = [[g['scale'][0], 0, 0], [0, g['scale'][1], 0], [0, 0, g['scale'][2]]]
        SS_T = [[scale_diag[i][i]**2 if i==j else 0 for j in range(3)] for i in range(3)]
        R_SS = mat_mul(g['rotation'], SS_T)
        RT = [[g['rotation'][j][i] for j in range(3)] for i in range(3)]
        g['covariance'] = mat_mul(R_SS, RT)
        
        reinitialized.append(g)
        
    return reinitialized
```

## Background
GVA was proposed in the context of human avatar reconstruction from monocular video [S1][S2, unofficial]. It addresses the issue of Gaussian aggregation during training, which can degrade geometric accuracy [S1][S2, unofficial]. The method builds on the idea of embedding Gaussians onto a canonical human body mesh, similar to SplattingAvatar and GoMAvatar [S1][S2, unofficial].
