# NeILF Rendering and Loss Calculation

Also called: inverse rendering with Blinn-Phong

## Overview
NeILF Rendering and Loss Calculation is a differentiable rendering pipeline that extends 3D Gaussian Splatting by decomposing features into diffuse, specular, and ambient components using a Blinn-Phong model [S1, unofficial]. It enables inverse rendering by providing specific loss functions for depth, normals, and color sparsity, allowing for the optimization of lighting parameters and material properties alongside geometry [S1, unofficial]. Unlike standard Gaussian Splatting which renders a single composite color, this method separates the rendering equation to facilitate physically-based constraints during training [S1, unofficial].

## How it works
**Inputs:**
*   `camera`: Camera object containing view matrix, intrinsics (focal lengths, principal point), and resolution [S1, unofficial].
*   `pc`: Point cloud of 3D Gaussians with attributes including position, covariance, opacity, and feature vectors [S1, unofficial].
*   `opt`: Optimization configuration containing loss weights (`lambda_*`) and rendering parameters [S1, unofficial].
*   `results`: Dictionary from the base renderer containing intermediate tensors [S1, unofficial].

**Outputs:**
*   `loss`: Scalar value representing the total optimization loss [S1, unofficial].
*   `render_pkg`: Dictionary containing rendered images and intermediate features (see Layout below) [S1, unofficial].

**Data Structures and Layout:**
The `results` dictionary returned by the rendering engine contains the following keys [S1, unofficial]:
*   `'render'`: Final composite RGB image.
*   `'phong'`: Rendered image using the Blinn-Phong model.
*   `'normal'`: Rendered surface normals.
*   `'pseudo_normal'`: Normals derived from depth or MVS.
*   `'surface_xyz'`: 3D positions of rendered points.
*   `'opacity'`: Opacity per pixel.
*   `'depth'`: Depth per pixel.
*   `'viewspace_points'`: Points in camera space.
*   `'visibility_filter'`: Boolean mask for valid Gaussians (radii > 0) [S1, unofficial].
*   `'radii'`: Radii of Gaussians in screen space.
*   `'num_rendered'`, `'num_contrib'`: Counts of rendered/contributing Gaussians.
*   `'diffuse_factor'`, `'offset_color'`, `'shininess'`, `'ambient_factor'`, `'specular_factor'`: Material parameters per Gaussian or group [S1, unofficial].
*   `'diffuse_term'`, `'specular_term'`, `'ambient_term'`: Individual PBR components [S1, unofficial].
*   `'hdr'`, `'val_gamma'`: HDR handling parameters [S1, unofficial].
*   `'tb_dict'`, `'loss'`: TensorBoard dictionary and current loss value [S1, unofficial].

**Rendering Equation (Blinn-Phong):**
The pipeline computes the final color by combining diffuse and specular terms [S1, unofficial]:
1.  **Lighting Setup:** Incident light direction $\mathbf{l}$ and view direction $\mathbf{v}$ are used to compute the half-vector $\mathbf{h} = \frac{\mathbf{l} + \mathbf{v}}{\|\mathbf{l} + \mathbf{v}\|}$ [S1, unofficial].
2.  **Diffuse Term:**
    $$ I_{diffuse} = \text{diffuse\_factor} \cdot |\mathbf{n} \cdot \mathbf{l}| $$
    $$ C_{diffuse} = (\text{ambient\_factor} + I_{diffuse}) \cdot C_{base} $$
    Where $\mathbf{n}$ is the normal, and $C_{base}$ is the base color (derived from `offset_color` and `palette_color`) [S1, unofficial].
3.  **Specular Term:**
    $$ I_{specular} = \text{specular\_factor} \cdot \begin{cases} |\mathbf{n} \cdot \mathbf{h}|^{\text{shininess}} & \text{if } \mathbf{l} \cdot \mathbf{n} \neq 0 \\ 0 & \text{otherwise} \end{cases} $$
    $$ C_{specular} = I_{specular} $$
    (Note: The source code uses `cos_l != 0` check, implying a dependency on the dot product of normal and light direction for validity) [S1, unofficial].
4.  **Final Color:**
    $$ C_{final} = \text{clamp}(C_{diffuse} + C_{specular}, 0, 1) $$

**Loss Calculation:**
The total loss is a weighted sum of multiple terms, activated by boolean flags in `opt` [S1, unofficial]:

1.  **Render Loss ($L_{render}$):**
    $$ L_{render} = (1 - \lambda_{dssim}) \cdot L1(I_{render}, I_{gt}) + \lambda_{dssim} \cdot (1 - SSIM(I_{render}, I_{gt})) $$
    Applied if $\lambda_{render} > 0$ [S1, unofficial].

2.  **Phong Loss ($L_{phong}$):**
    $$ L_{phong} = (1 - \lambda_{dssim}) \cdot L1(I_{phong}, I_{gt}) + \lambda_{dssim} \cdot (1 - SSIM(I_{phong}, I_{gt})) $$
    Added to total loss as $\lambda_{phong} \cdot L_{phong}$ if $\lambda_{phong} > 0$ [S1, unofficial].

3.  **Depth Loss ($L_{depth}$):**
    $$ L_{depth} = L1(D_{render}, D_{gt}) $$
    Computed only on pixels where `image_mask XOR depth_mask` is false. Applied if $\lambda_{depth} > 0$ [S1, unofficial].

4.  **Opacity Loss ($L_{opacity}$):**
    $$ L_{opacity} = L1(\text{clamp}(O_{render}, 10^{-6}, 1-10^{-6}), M_{image}) + SSIM(...) $$
    Applied if $\lambda_{opacity} > 0$ [S1, unofficial].

5.  **Normal Losses:**
    *   **Render Depth Normal ($L_{normal\_render\_depth}$):** MSE between $N_{render}$ and $N_{pseudo}$ (from results), masked by $M_{image}$. Applied if $\lambda_{normal\_render\_depth} > 0$ [S1, unofficial].
    *   **MVS Depth Normal ($L_{normal\_mvs\_depth}$):** If MVS normal is zero, compute pseudo-normal $N_{pseudo}$ from $D_{gt}$ using `kornia.depth_to_normals`, transform to world space via intrinsics and view transform. Compute MSE between $N_{render}$ and $N_{pseudo}$, masked by $M_{depth}$. Applied if $\lambda_{normal\_mvs\_depth} > 0$ [S1, unofficial].

6.  **Sparsity and Smoothness Losses:**
    *   **Offset Color Sparsity ($L_{sparsity}$):** Sparsity loss on $C_{offset}$, masked by $M_{image}$. Applied if $\lambda_{offset\_color\_sparsity} > 0$ [S1, unofficial].
    *   **Diffuse Factor Smoothness ($L_{diffuse\_smooth}$):** Bilateral smoothness loss on `diffuse_factor`, conditioned on $I_{gt}$ and $M_{image}$. Applied if $\lambda_{diffuse\_factor\_smooth} > 0$ [S1, unofficial].
    *   **Ambient/Specular Smoothness ($L_{ambient\_smooth}$):** Bilateral smoothness loss on `specular_intensity` and `ambient_intensity`. Applied if $\lambda_{ambient\_factor\_smooth} > 0$ [S1, unofficial].
    *   **Normal Smoothness ($L_{normal\_smooth}$):** Bilateral smoothness loss on $N_{render}$, conditioned on $I_{gt}$ and $M_{image}$. Applied if $\lambda_{normal\_smooth} > 0$ [S1, unofficial]

**Parameters:**
*   `sample_num`: Number of incident rays sampled for normal-based lighting. Default: 24 [S1, unofficial].
*   `lambda_*`: Optimization weights for each loss term. Typical values are not specified in the source, but they act as multipliers for the respective loss components [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Radius/Culled Gaussians:** Gaussians with radius 0 or those frustum-culled are excluded from value updates in splitting criteria via the `visibility_filter` (checking `radii > 0`) [S1, unofficial].
*   **MVS Normal Zeros:** The MVS normal map may be all zeros. In this case, the pseudo-normal must be computed from the ground truth depth using `kornia.depth_to_normals` and transformed to world space using camera intrinsics and the world-view transform [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Dominated by the Gaussian rasterization step, which is $O(N)$ where $N$ is the number of Gaussians, plus the overhead of computing multiple loss terms. The additional Blinn-Phong calculations are per-pixel and thus $O(H \times W)$.
*   **Memory Complexity:** Requires storing additional intermediate buffers for diffuse, specular, and ambient terms, as well as normals and depths, increasing memory usage compared to standard Gaussian Splatting.
*   **Performance:** Specific FPS numbers are not provided in the source. The method relies on PyTorch operations and CUDA kernels for efficiency.
*   **Strengths:** Enables inverse rendering by separating lighting and material properties; provides rich supervisory signals via multiple loss terms (depth, normal, sparsity).
*   **Limitations:** Requires ground truth depth and normals (or pseudo-normals) for effective training; more complex to tune due to multiple loss weights.

## Background
NeILF Rendering and Loss Calculation is part of the VEG (Vegetation/Environment Generation?) project, as indicated by the source repository [S1, unofficial]. It extends the 3D Gaussian Splatting framework to support inverse rendering tasks by incorporating a Blinn-Phong shading model and various regularization losses. The method is designed to optimize not just the geometry and appearance of a scene, but also its lighting and material parameters.
