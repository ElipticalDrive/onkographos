# Bézier-boundary gradient approximation

Also called: Bézier-boundary gradient approximation strategy

## Overview
A strategy to approximate the gradients of a discontinuous indicator function $g(\cdot)$ with respect to control point coordinates, enabling backpropagation in Gaussian Splatting despite $g(\cdot)$ being piecewise constant and non-differentiable [S1]. It sets itself apart from standard Gaussian Splatting, which relies on differentiable rendering, by explicitly handling the non-differentiable segments of the discontinuity-aware $\alpha$-blending function [S1]. It differs from [Truncated Gradient Updates for 3D Gaussian Splatting](18661-truncated-gradient-updates-for-3d-gaussian-splatting.md) by focusing on the geometric boundary of the Bézier curve rather than truncating gradient magnitudes.

## How it works
**Inputs:**
- The loss gradient with respect to the Bézier curve output at point $p$, denoted $\frac{\partial L}{\partial g_{sc}(p)}$.
- The current value of the Bézier curve at point $p$, denoted $g_{sc}(p)$.
- The control point coordinates stored in $c_{curve}$, specifically the x-coordinate of the first control point $c_{curve}[0,0]$ (for 2D GS) or $c_{curve}[0,0]$ (for 3D GS, treating x-coordinate analogously).
- The target point $p = (x_p, y_p)$ in 2D space.
- The other control points $c_{curve}[1], c_{curve}[2], c_{curve}[3]$.

**Outputs:**
- The approximated partial derivative $\frac{\partial g}{\partial c_{curve}[0,0]}$.

**Data Structures:**
- $c_{curve}$: Attribute storing control point coordinates. For 2D GS, shape is $\mathbb{R}^{4M \times 2}$. For 3D GS, shape is $\mathbb{R}^{4M \times 3}$ [S1].
- $M$: Hyperparameter for the number of control points per Gaussian. Value: 3 [S1].

**Definitions:**
- $g_{sc}(p)$: The cubic Bézier curve function evaluated at point $p$, dependent on control points $c_{curve}[0], c_{curve}[1], c_{curve}[2], c_{curve}[3]$ [S1].
- $g(\cdot)$: The discontinuous indicator function incorporated into the rendering process [S1].
- $\hat{g}_{sc}(p)$: The "hard" target value for the Bézier curve output. Defined as:
  $$
  \hat{g}_{sc}(p) = \begin{cases} 
  1, & \text{if } g_{sc}(p) = 0 \\
  0, & \text{otherwise}
  \end{cases}
  $$
  [S1].
- $\epsilon$: A small epsilon value used to prevent gradient explosion. Value: $10^{-5}$ if the target $\phi$ is greater than the current control point coordinate, $-10^{-5}$ otherwise [S1].

**Steps:**

1.  **Chain Rule Decomposition:**
    Apply the chain rule to decompose the gradient of the indicator function $g(\cdot)$ with respect to the control point coordinate $c_{curve}[0,0]$:
    $$
    \frac{\partial g}{\partial c_{curve}[0,0]} = \frac{\partial g}{\partial g_{sc}(p)} \times \frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]}
    $$
    [S1]. Since $g(\cdot)$ is differentiable with respect to $g_{sc}(\cdot)$, the problem reduces to approximating $\frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]}$ [S1].

2.  **Determine if Modification is Needed:**
    Check if the gradient $\frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]}$ should be modified. Set the gradient to zero if any of the following conditions are met:
    - $\frac{\partial L}{\partial g_{sc}(p)} = 0$ (optimal state) [S1].
    - $\frac{\partial L}{\partial g_{sc}(p)} > 0$ and $g_{sc}(p) = 0$ (already at minimum) [S1].
    - $\frac{\partial L}{\partial g_{sc}(p)} < 0$ and $g_{sc}(p) = 1$ (already at maximum) [S1].
    If modification is needed, proceed to step 3.

3.  **Solve for Target Control Point Value:**
    Identify the target value $\phi$ for $c_{curve}[0,0]$ such that the Bézier curve passes through point $p=(x_p, y_p)$. Solve the system of equations derived from the cubic Bézier definition for the parameter $t$ and the target value $\phi$ in $O(1)$ time [S1]:
    $$
    x_p = (1-t)^3 \phi + 3(1-t)^2 t c_{curve}[1,0] + 3(1-t)t^2 c_{curve}[2,0] + t^3 c_{curve}[3,0]
    $$
    $$
    y_p = (1-t)^3 c_{curve}[0,1] + 3(1-t)^2 t c_{curve}[1,1] + 3(1-t)t^2 c_{curve}[2,1] + t^3 c_{curve}[3,1]
    $$
    [S1]. First, solve the second equation for $t$ (as it does not depend on $\phi$). Then, substitute $t$ into the first equation and solve for $\phi$ [S1].

4.  **Collect Solutions:**
    Collect all real number solutions for $\phi$ into a set $S_\phi$ [S1].

5.  **Approximate Gradient Based on Solution Set:**
    - **No Side Situation:** If $S_\phi$ is empty, set $\frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]} = 0$. This implies no real value of $c_{curve}[0,0]$ can cause the curve to pass through $p$ [S1].
    - **Single Side Situation:** If all solutions in $S_\phi$ lie on the same side of $c_{curve}[0,0]$, let $\phi_e$ be the solution nearest to $c_{curve}[0,0]$. Approximate the gradient via linear interpolation:
      $$
      \frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]} = \frac{g_{sc}(p) - \hat{g}_{sc}(p)}{\phi_e - c_{curve}[0,0] + \epsilon}
      $$
      [S1]. Here, $\epsilon = 10^{-5}$ if $\phi_e > c_{curve}[0,0]$ and $\epsilon = -10^{-5}$ otherwise [S1].
    - **Both Sides Situation:** If solutions exist on both the left and right sides of $c_{curve}[0,0]$, let $\phi_1$ be the nearest solution from the left and $\phi_2$ be the nearest from the right. Approximate the gradient as the sum of two interpolation terms:
      $$
      \frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]} = \frac{g_{sc}(p) - \hat{g}_{sc}(p)}{\phi_1 - c_{curve}[0,0] + \epsilon_1} + \frac{g_{sc}(p) - \hat{g}_{sc}(p)}{\phi_2 - c_{curve}[0,0] + \epsilon_2}
      $$
      [S1]. The signs of $\epsilon_1$ and $\epsilon_2$ are determined by the relative position of $\phi_1$ and $\phi_2$ to $c_{curve}[0,0]$ respectively (positive if target > current, negative otherwise) [S1].

6.  **Final Gradient Calculation:**
    Multiply the approximated $\frac{\partial g_{sc}(p)}{\partial c_{curve}[0,0]}$ by $\frac{\partial g}{\partial g_{sc}(p)}$ to obtain the final gradient $\frac{\partial g}{\partial c_{curve}[0,0]}$ [S1].

**Pseudocode:**

```python
import numpy as np

def bezier_boundary_gradient_approximation(
    dL_dg_sc, 
    g_sc_p, 
    c_curve, 
    p, 
    M=3
):
    """
    Approximates the gradient of the discontinuous indicator function g(.)
    with respect to the first control point's x-coordinate.
    
    Args:
        dL_dg_sc: Gradient of loss L w.r.t. g_sc(p).
        g_sc_p: Current value of the Bézier curve at point p.
        c_curve: Array of control points, shape (4*M, 2) for 2D or (4*M, 3) for 3D.
        p: Target point (x_p, y_p).
        M: Number of control points per Gaussian.
        
    Returns:
        approx_grad: Approximated gradient d(g)/d(c_curve[0,0]).
    """
    
    # Step 2: Determine if modification is needed
    if dL_dg_sc == 0:
        return 0.0
    if dL_dg_sc > 0 and g_sc_p == 0:
        return 0.0
    if dL_dg_sc < 0 and g_sc_p == 1:
        return 0.0
    
    # Extract control points
    c0 = c_curve[0]
    c1 = c_curve[1]
    c2 = c_curve[2]
    c3 = c_curve[3]
    
    x_p, y_p = p
    
    # Step 3: Solve for t and phi
    # The y-coordinate equation does not depend on phi (x-coordinate of c0)
    # y_p = (1-t)^3 * c0[1] + 3*(1-t)^2 * t * c1[1] + 3*(1-t) * t^2 * c2[1] + t^3 * c3[1]
    # This is a cubic equation in t.
    # Coefficients for t^3, t^2, t^1, t^0
    # Let's expand:
    # y_p = c0[1]*(1 - 3t + 3t^2 - t^3) + 3*c1[1]*(t - 2t^2 + t^3) + 3*c2[1]*(t^2 - t^3) + c3[1]*t^3
    # y_p = c0[1] + t*(-3*c0[1] + 3*c1[1]) + t^2*(3*c0[1] - 6*c1[1] + 3*c2[1]) + t^3*(-c0[1] + 3*c1[1] - 3*c2[1] + c3[1])
    
    a_t3 = -c0[1] + 3*c1[1] - 3*c2[1] + c3[1]
    a_t2 = 3*c0[1] - 6*c1[1] + 3*c2[1]
    a_t1 = -3*c0[1] + 3*c1[1]
    a_t0 = c0[1] - y_p
    
    # Solve cubic equation a_t3*t^3 + a_t2*t^2 + a_t1*t + a_t0 = 0
    # Using numpy roots for robustness, though O(1) analytical solution exists
    coeffs_t = [a_t3, a_t2, a_t1, a_t0]
    roots_t = np.roots(coeffs_t)
    
    # Filter for real roots in [0, 1]
    valid_t = []
    for t in roots_t:
        if np.isreal(t):
            t_val = np.real(t)
            if 0 <= t_val <= 1:
                valid_t.append(t_val)
    
    # If no valid t, no solution
    if not valid_t:
        return 0.0
        
    # Step 3 continued: Solve for phi for each valid t
    # x_p = (1-t)^3 * phi + 3*(1-t)^2 * t * c1[0] + 3*(1-t) * t^2 * c2[0] + t^3 * c3[0]
    # phi = (x_p - (3*(1-t)^2 * t * c1[0] + 3*(1-t) * t^2 * c2[0] + t^3 * c3[0])) / (1-t)^3
    
    S_phi = []
    for t_val in valid_t:
        denom = (1 - t_val)**3
        if abs(denom) < 1e-9:
            continue # Avoid division by zero, though t=1 implies x_p = c3[0]
        
        term = 3*(1-t_val)**2 * t_val * c1[0] + 3*(1-t_val) * t_val**2 * c2[0] + t_val**3 * c3[0]
        phi = (x_p - term) / denom
        S_phi.append(phi)
        
    if not S_phi:
        return 0.0
        
    # Step 5: Approximate gradient based on S_phi
    c0_x = c_curve[0, 0]
    
    # Define hard target
    if g_sc_p == 0:
        g_hat_sc_p = 1
    else:
        g_hat_sc_p = 0
        
    numerator = g_sc_p - g_hat_sc_p
    
    # Separate solutions into left and right
    left_solutions = [phi for phi in S_phi if phi < c0_x]
    right_solutions = [phi for phi in S_phi if phi > c0_x]
    
    # Note: Solutions equal to c0_x are effectively distance 0, handled by epsilon logic or ignored if not strictly < or >
    # The source distinguishes "left side" and "right side".
    
    grad_sum = 0.0
    
    # Single Side or Both Sides logic
    if not left_solutions and not right_solutions:
        # All solutions are equal to c0_x? Or empty?
        # If S_phi is not empty but all are equal to c0_x, distance is 0.
        # The source says "If all solutions ... lie on the same side".
        # If no solutions on either side, it might be the "no side" case if S_phi was empty, 
        # but here S_phi has elements. If they are equal, distance is 0.
        # We treat this as a degenerate case or single side with distance 0.
        # Given epsilon handles small distances, we can pick one.
        if S_phi:
            phi_e = S_phi[0]
            # Determine epsilon sign
            if phi_e > c0_x:
                eps = 1e-5
            elif phi_e < c0_x:
                eps = -1e-5
            else:
                # Distance is 0. Source doesn't specify. 
                # Using a small epsilon to avoid division by zero.
                # Sign doesn't matter if distance is 0, but let's assume positive direction.
                eps = 1e-5
            
            grad_sum = numerator / (phi_e - c0_x + eps)
            
    elif not left_solutions:
        # Single side: Right
        # Find nearest to c0_x
        phi_e = min(right_solutions)
        eps = 1e-5 if phi_e > c0_x else -1e-5
        grad_sum = numerator / (phi_e - c0_x + eps)
        
    elif not right_solutions:
        # Single side: Left
        # Find nearest to c0_x (max of left solutions)
        phi_e = max(left_solutions)
        eps = 1e-5 if phi_e > c0_x else -1e-5
        grad_sum = numerator / (phi_e - c0_x + eps)
        
    else:
        # Both sides
        # Nearest left
        phi_1 = max(left_solutions)
        eps_1 = 1e-5 if phi_1 > c0_x else -1e-5
        
        # Nearest right
        phi_2 = min(right_solutions)
        eps_2 = 1e-5 if phi_2 > c0_x else -1e-2 # Source says -1e-5 if target < current
        
        grad_sum = numerator / (phi_1 - c0_x + eps_1) + numerator / (phi_2 - c0_x + eps_2)
        
    return grad_sum
```

## Subtopics

### [Learned Static–Dynamic Partition](20807-learned-static-dynamic-partition.md)
A method to jointly optimize a binary gate $g_i$ and motion parameters to classify Gaussians as static or dynamic, using a hard-concrete relaxation with straight-through estimator. It solves the problem of incorrectly treating moving Gaussians as static, which leaves frozen copies of moving objects in the scene, by learning a sparse static-dynamic partition. It sets itself apart from sibling methods by explicitly maintaining a binary classification per Gaussian that is committed and frozen after training, enabling efficient rendering of static background without temporal overhead.

## Operating characteristics
- **Time Complexity:** The core approximation step involves solving a cubic equation for $t$ and then a linear equation for $\phi$, which is stated to be $O(1)$ time complexity [S1].
- **Memory Complexity:** Requires storing the control points $c_{curve}$ and the set of solutions $S_\phi$, which is bounded by the number of real roots of a cubic equation (at most 3) [S1].
- **Strengths:** Enables the learning of discontinuity-aware rendering in Gaussian Splatting by providing non-zero gradients for the control points, which standard backpropagation fails to do due to the piecewise constant nature of the indicator function [S1].
- **Limitations:** Relies on the geometric solvability of the Bézier curve passing through a point; if no solution exists ("no side" situation), the gradient is zero, potentially stalling learning for certain configurations [S1].
- **When to use:** When using DisC-GS or similar frameworks that incorporate discontinuous indicator functions into Gaussian Splatting rendering [S1].
- **When not to use:** In standard Gaussian Splatting without discontinuity-aware rendering, as the indicator function $g(\cdot)$ is not present [S1].

## Background
The method was introduced in **DisC-GS: Discontinuity-aware Gaussian Splatting** [S1]. It addresses the issue that standard Gaussian Splatting is not differentiable when incorporating discontinuous indicator functions for rendering modified $\alpha$-blending [S1]. The strategy is inspired by prior work [28] (cited in [S1]) and is used to approximate gradients for the control points $c_{curve}$ introduced in the DisC-GS framework [S1]. The initial learning rate for $c_{curve}$ is set to $2 \times 10^{-4}$ [S1].
