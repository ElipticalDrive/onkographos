# Curriculum Learning with Slice and Voxel Supervision

Also called: Slice and Voxel Supervision Curriculum

## Overview
This method addresses the instability and incomplete volumetric coverage inherent in training 3D Gaussian representations for shear-warp rendering by combining sparse voxel sampling with structured slice-based sampling [S1]. It sets itself apart from sibling methods like [Hybrid Coarse-to-Fine Strategy](7173-hybrid-coarse-to-fine-strategy.md) by explicitly leveraging the geometric alignment between 2D slice supervision and the shear-warp rendering pipeline, rather than relying solely on resolution or density hierarchies [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of multimodal volumetric datasets (e.g., MRI, Cryosection) and an initial set of Gaussian kernels $\mathcal{G}$.
*   **Output:** Optimized Gaussian parameters $\mathcal{G}$ representing the volumetric structure.

**Data Structures:**
The representation consists of a set $\mathcal{G} = \{G_1, G_2, \dots, G_m\}$ of $m$ Gaussian kernels [S1]. Each Gaussian $G_i$ is initialized with a mean $\mu_i$ at a sampled voxel position and associated learnable parameters (covariance, opacity, spherical harmonics coefficients) [S1]. The volume is discretized into a voxel grid, where each voxel can map to a Gaussian center [S1].

**Numbered Steps:**
1.  **Initialization:** Initialize one Gaussian kernel centered at each sampled voxel position from the input volumetric data [S1].
2.  **Stage 1 - Slice Supervision:** Apply slice supervision first to progressively incorporate finer structural details through planar constraints [S1]. In each training iteration:
    a. Sample a plane with arbitrary orientation [S1].
    b. Select sparse pixels on the sampled plane [S1].
    c. Map each selected pixel to a three-dimensional voxel coordinate [S1].
    d. Render the view using the current Gaussian set and compute the loss against the ground-truth slice data [S1].
3.  **Stage 2 - Voxel Supervision:** Follow with voxel supervision under random sampling with dense approximation to establish global spatial guidance [S1]. This stage stabilizes the global approximation after the local structures have been learned [S1].
4.  **Optimization:** Update Gaussian parameters using the combined or sequential losses from the active stage [S1].

**Formulas:**
The Gaussian representation is defined by the set $\mathcal{G}$ where each element $G_i$ has a mean $\mu_i$ [S1]. The rendering process aligns with shear-warp rendering, which generates images from stacks of 2D slices extracted from the 3D volume [S1]. The loss function $\mathcal{L}$ combines reconstruction errors from slice supervision $\mathcal{L}_{slice}$ and voxel supervision $\mathcal{L}_{voxel}$, weighted by the curriculum stage [S1].

**Parameters:**
*   **Sampling Strategy:** Sparse voxel sampling for global coverage; slice-based sampling for spatially correlated regions [S1].
*   **Plane Orientation:** Arbitrary orientation for slice sampling [S1].

**Edge Cases and Pitfalls:**
*   **Slice-only Training (A4):** Using only slice supervision limits accurate reconstruction of the full volumetric structure due to lack of global spatial guidance [S1].
*   **Random Voxel First (A2):** Introducing slice supervision together with voxel supervision under random sampling leads to unstable global approximation and destabilizes learning [S1].
*   **Random Slices First (A3):** Applying slice supervision before stable global voxel constraints are established results in unstable learning of the volumetric structure, as later random voxel introduction does not sufficiently correct the global approximation [S1].

**Pseudocode:**
```python
# Initialize Gaussians from voxel samples
G = initialize_gaussians_from_voxels(voxel_grid)

# Stage 1: Slice Supervision
for iteration in range(slice_iterations):
    # Sample a plane with arbitrary orientation
    plane = sample_arbitrary_plane()
    
    # Select sparse pixels on the plane
    pixels = select_sparse_pixels(plane)
    
    # Map pixels to 3D voxel coordinates
    voxel_coords = map_pixels_to_voxels(pixels, plane)
    
    # Render slice view and compute loss
    rendered_slice = render_slice(G, plane)
    loss_slice = compute_loss(rendered_slice, ground_truth_slice)
    
    # Update Gaussians
    G = update_gaussians(G, loss_slice)

# Stage 2: Voxel Supervision
for iteration in range(voxel_iterations):
    # Sample sparse voxels for global coverage
    sampled_voxels = sample_sparse_voxels(voxel_grid)
    
    # Render voxel-based view and compute loss
    rendered_voxels = render_voxels(G, sampled_voxels)
    loss_voxel = compute_loss(rendered_voxels, ground_truth_voxels)
    
    # Update Gaussians
    G = update_gaussians(G, loss_voxel)
```

## Subtopics

### Curriculum Learning with Sparse Voxel and Slice Sampling
This variant explicitly defines the sampling strategy where sparse voxels provide global coverage of the volume, while slice samples capture spatially correlated regions that encode geometric structure and texture continuity [S1]. It aligns with shear-warp volume rendering, which generates images from stacks of 2D slices extracted from a 3D volume [S1]. The implementation involves sampling a plane with arbitrary orientation, selecting sparse pixels on the plane, and mapping each pixel to a 3D voxel coordinate to ensure the Gaussian representation learns spatial continuity across neighboring regions [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Combining both slice and voxel supervision yields higher PSNR/SSIM compared to using only slice supervision [S1].
*   **Strengths:** Enables efficient learning of both global volumetric consistency and local anatomical details [S1]. Supports real-time selective visualization [S1].
*   **Limitations:** Random voxel sampling without proper curriculum ordering leads to unstable global approximation [S1]. Slice-only supervision lacks global spatial guidance [S1].
*   **When to use:** For multimodal volumetric datasets (MRI, Cryosection) where both global structure and local texture continuity are critical [S1].
*   **When not to use:** When global spatial guidance is not required or when computational resources are extremely limited, as the curriculum adds training complexity [S1].

## Background

It builds on the principle that shear-warp rendering operates on stacks of 2D slices, making slice-based supervision a natural fit for training Gaussian representations for this rendering pipeline [S1].
