# Data Compression and Storage Optimization

Also called: 3DGS Compression, Gaussian Quantization, Codebook-based Compression

## Overview
This family of methods reduces the storage footprint and transmission overhead of 3D Gaussian Splatting (3DGS) models by compressing geometric attributes (position, scale, rotation), opacity, and view-dependent color (spherical harmonic coefficients) [S1, S2, unofficial]. Unlike [Hardware and Computational Acceleration](16214-hardware-and-computational-acceleration.md) which focuses on rendering speed, or [Occupancy Region Derivation & ϵ-Intersection Criterion](19020-occupancy-region-derivation-intersection-criterion.md) which focuses on culling, these methods focus on data representation efficiency. They set themselves apart from [Gaussian Piling](19322-gaussian-piling.md) and [Parallel Differentiable Rasterization](19784-parallel-differentiable-rasterization.md) by altering the data structures themselves rather than the rendering pipeline execution.

## Shared principles
All methods in this family operate on the set of $N$ 3D Gaussians $\{G_i\}_{i=1}^N$ defined in [Rendering Implementation and Acceleration](21069-rendering-implementation-and-acceleration.md). The core principle is replacing high-precision, per-primitive continuous attributes with compact representations. Common strategies include:
1.  **Vector Quantization/Clustering:** Mapping continuous vectors (e.g., SH coefficients, scale, rotation) to indices of a finite codebook [S1, S2, unofficial].
2.  **Neural Field Substitution:** Replacing per-Gaussian color attributes with a shared neural field (e.g., hash grid) queried by position and view direction [S1, unofficial].
3.  **Pruning/Sparsity:** Removing redundant Gaussians based on opacity, scale, or contribution scores [S1, S2, unofficial].
4.  **Lossless Compression:** Applying entropy coding (e.g., DEFLATE, GPCC) to the resulting indices and sparse data [S1, S2, unofficial].

## Subtopics

### [ASCII-Based Data Compression](11820-ascii-based-data-compression.md)
A technique for optimizing data transmission speed during training by encoding numerical attributes into compact ASCII strings. It uses base-95 (integer) and base-94 (floating-point) encoding schemes. It differs from [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md) by focusing on transmission efficiency rather than memory footprint reduction, and from [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md) by using character-based string encoding rather than structural quantization. Choose this when network bandwidth is the primary bottleneck during distributed training.

### [Sensitivity-Aware Vector Clustering](12167-sensitivity-aware-vector-clustering.md)
A compression scheme that reduces storage by clustering spherical harmonic (SH) coefficients and Gaussian shape parameters into compact codebooks. It distinguishes itself by deriving a sensitivity measure for each parameter to weight the clustering distance, prioritizing parameters that significantly affect image quality. Choose this when high-fidelity reconstruction is required with moderate compression ratios.

### [Compact 3D Gaussian Representation (C3DGS)](12927-compact-3d-gaussian-representation-c3dgs.md)
A method that reduces storage and rendering latency by eliminating redundant primitives and compressing attributes via spatial sharing. It exploits spatial redundancy by replacing per-primitive color data with a hash-based neural field and geometric attributes with a discrete codebook. This approach achieves over 25× storage compression and up to 40% faster rendering while maintaining or improving reconstruction quality. Choose this for maximum storage efficiency and rendering speed.

### [Monte Carlo Specular Energy Aggregator](15439-monte-carlo-specular-energy-aggregator.md)
A compression technique that maps high-order (e.g., third-order) Spherical Harmonics (SH) radiance energy into a compact lower-order (e.g., first-order) subspace. It solves the problem of high memory overhead and inference latency associated with high-order SH by extracting directional moments of the specular residual via Monte Carlo projection, thereby preserving high-frequency specular features without requiring expensive teacher-student distillation or pre-training. Unlike Mobile-GS, which relies on distillation from a high-order teacher model, MC-SEA compresses energy directly, reducing storage costs and Gaussian point requirements while maintaining competitive PSNR. Choose this when high-frequency specular details are critical but high-order SH is too expensive.

- [S1, unofficial] A compression method that utilizes vector clustering to encode color and geometric attributes.

### 3DGS Quantization Compression
- [S2, unofficial] Reduces storage footprint of 3DGS scenes by quantizing per-Gaussian attributes and using codebooks, achieving ~10x smaller sizes without significant quality loss.
- [S2, unofficial] Per-Gaussian attribute storage: position (FP16), scales (FP16), opacity (INT8), spherical harmonic coefficients (INT8 or codebook-based).

## Background
The need for compression in 3DGS arises from the large number of primitives required for high-quality novel view synthesis, leading to significant storage and transmission costs. Early works like C3DGS [56] and SASCGS [58] introduced vector quantization and sensitivity-aware clustering [S1, unofficial]. Subsequent methods like LightGaussian [60] and CompGS [S2, unofficial] explored pruning and quantization. The field has evolved from simple quantization to complex hybrid approaches involving neural fields and Monte Carlo aggregation to balance quality, size, and rendering speed [S1, S2, unofficial].
