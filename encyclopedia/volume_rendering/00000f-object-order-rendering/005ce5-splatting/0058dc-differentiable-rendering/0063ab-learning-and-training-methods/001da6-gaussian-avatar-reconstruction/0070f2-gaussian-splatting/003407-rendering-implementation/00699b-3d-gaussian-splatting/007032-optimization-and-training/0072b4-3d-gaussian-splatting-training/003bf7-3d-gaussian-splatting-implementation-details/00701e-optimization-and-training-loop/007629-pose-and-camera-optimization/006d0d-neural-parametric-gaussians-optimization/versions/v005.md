# Neural Parametric Gaussians Optimization

Also called: two-stage optimization for monocular non-rigid reconstruction

## Overview
Neural Parametric Gaussians (NPGs) is a two-stage optimization method for monocular non-rigid object reconstruction that combines a coarse parametric point model regularized by a low-rank deformation basis with 3D Gaussians to model fine geometric and appearance details [S1]. It solves the ill-posed problem of reconstructing dynamic objects from single-camera video by preventing the geometric collapse common in purely implicit or unregularized explicit methods [S1]. Unlike sibling methods such as [Local 3DGS Optimization](20073-local-3dgs-optimization.md) which may lack global structural priors, NPGs explicitly maintains a consistent coarse template across timesteps, enabling high-fidelity novel view synthesis on challenging monocular datasets like Unbiased4D [S1].

## How it works
The method optimizes a hybrid representation in two distinct stages. Stage 1 learns a coarse parametric point model using a low-rank deformation basis. Stage 2 refines this representation using 3D Gaussians, leveraging the coarse model as a structural prior.

### Inputs and Outputs
**Inputs:**
- Monocular video sequence of a non-rigid object.
- Masks for dynamic objects (optional, used for sequences with static backgrounds like Lego/T-Rex) [S1].
- Hyperparameters: Deformation basis size $K$, learning rates, iteration counts.

**Outputs:**
- Optimized coarse parametric point model (positions, deformation coefficients).
- Optimized 3D Gaussian fields (positions, covariances, opacities, SH coefficients) aligned with the deformed template.

### Data Structures
1.  **Coarse Parametric Model:**
    -   **Points:** $N_p = 1500$ points modeling coarse geometry [S1].
    -   **Deformation Basis Coefficients:** Computed by a 6-layer Multi-Layer Perceptron (MLP) [S1]. The MLP maps input features (e.g., time, spatial coordinates) to coefficients for the low-rank basis.
    -   **Basis Size:** $K$ (scalar). Controls regularization strength. Optimal value found to be 25 for synthetic cactus [S1].

2.  **3D Gaussian Fields:**
    -   Parameters $\mathcal{G} = \{g_i\}_{i=1}^N$ as defined in [Pose and Camera Optimization](23423-pose-and-camera-optimization.md): position $\mathbf{p}_i$, covariance $\Sigma_i$ (from quaternion $\mathbf{q}_i$ and scale $\mathbf{s}_i$), opacity $\alpha_i$, and SH coefficients $\mathbf{c}_{i, l}$ [S1].
    -   **Interpolation Weights:** $w$ used to blend or interpolate between Gaussian states or template points (specific definition of interpolation mechanism not detailed in sources, but $w$ is optimized) [S1].

### Numbered Steps

**Stage 1: Coarse Parametric Model Optimization**
1.  Initialize $N_p = 1500$ points to model the coarse object geometry [S1].
2.  Initialize a 6-layer MLP to compute deformation basis coefficients [S1].
3.  Define the deformation basis size $K$. Set $K=25$ for standard synthetic sequences (e.g., cactus) [S1].
4.  Apply **Rigidity Loss** during optimization to keep the template consistent across timesteps [S1].
5.  Optimize point positions and MLP coefficients using the Adam optimizer [S1].
    -   Batch size: 10 [S1].
    -   Learning rate: 0.0005 with cosine annealing and warm-up [S1].
    -   Iterations: 100,000 [S1].

**Stage 2: 3D Gaussian Refinement**
1.  Initialize 3D Gaussians based on the Stage 1 template [S1].
2.  Adopt the learning rate schedule from standard 3D Gaussian Splatting (3DGS) for most parameters [S1].
3.  Optimize Gaussian parameters and interpolation weights $w$ for 70,000 iterations [S1].
    -   Learning rate for interpolation weights $w$: Matches the default point position learning rate in 3DGS [S1].
    -   Learning rate for Gaussian scales: 0.0005 [S1].
    -   Scale Scheduler: Exponential decay from a high initial value down to 0.0005 [S1].
4.  (Optional) **Finetuning:** Continue optimizing Stage 1 parameters (point positions, MLP coefficients) alongside Stage 2 parameters.
    -   Learning rate for Stage 1 parameters during finetuning: 0.0001 [S1].
    -   This step is not strictly necessary but improves template accuracy [S1].

### Formulas
The optimization minimizes a photometric loss $\mathcal{L}$, consistent with the parent method [Pose and Camera Optimization](23423-pose-and-camera-optimization.md):
$$ \mathcal{L}_{img} = (1 - \lambda) \mathcal{L}_{L1} + \lambda \mathcal{L}_{D-SSIM} $$
where $\lambda = 0.2$ [S1].

Additionally, Stage 1 employs a **Rigidity Loss** $\mathcal{L}_{rigid}$ to enforce temporal consistency of the coarse template [S1]. The exact mathematical formulation of $\mathcal{L}_{rigid}$ is not provided in the sources, but its purpose is to prevent the template from deforming inconsistently across timesteps [S1].

### Parameters
-   **Deformation Basis Size ($K$):** 25 (optimal for synthetic cactus; smaller $K$ over-regularizes, larger $K$ overfits) [S1].
-   **Number of Coarse Points ($N_p$):** 1500 [S1].
-   **MLP Depth:** 6 layers [S1].
-   **Stage 1 Learning Rate:** 0.0005 (cosine annealing + warm-up) [S1].
-   **Stage 1 Iterations:** 100,000 [S1].
-   **Stage 1 Batch Size:** 10 [S1].
-   **Stage 2 Iterations:** 70,000 [S1].
-   **Stage 2 Scale Learning Rate:** 0.0005 [S1].
-   **Stage 2 Finetuning LR:** 0.0001 (for Stage 1 params) [S1].

### Edge Cases and Pitfalls
-   **Template Collapse:** If the camera is very static, the optimized template may collapse to a flat surface, leading to incorrect deformation [S1]. This is a critical failure mode in highly ill-posed monocular scenarios [S1].
-   **Static Backgrounds:** For sequences with large static ground planes (e.g., Lego, T-Rex), masks for dynamic objects only are required to prevent the model from optimizing static background elements incorrectly [S1].
-   **Basis Size Selection:** Choosing $K$ incorrectly leads to either over-regularization (restricting non-rigid deformations) or overfitting (hindering novel view synthesis) [S1].

### Pseudocode
```python
# Neural Parametric Gaussians Optimization
# Based on [S1]

def npg_optimization(video_frames, masks=None):
    # Hyperparameters
    K = 25  # Deformation basis size
    N_points = 1500
    stage1_iters = 100000
    stage2_iters = 70000
    lr_stage1 = 0.0005
    lr_stage2_scale = 0.0005
    lr_finetune = 0.0001
    batch_size = 10
    
    # Stage 1: Coarse Parametric Model
    # Initialize 1500 points
    coarse_points = initialize_points(N_points)
    
    # Initialize 6-layer MLP for deformation basis coefficients
    deformation_mlp = initialize_mlp(layers=6)
    
    # Optimizer for Stage 1
    optimizer_stage1 = Adam([coarse_points, deformation_mlp.parameters()], lr=lr_stage1)
    scheduler_stage1 = CosineAnnealingWarmup(optimizer_stage1)
    
    for iter in range(stage1_iters):
        # Sample batch of frames/views
        batch_frames = sample_batch(video_frames, batch_size)
        
        # Compute deformation coefficients using MLP
        # Inputs to MLP (e.g., time, spatial coords) are derived from batch
        coeffs = deformation_mlp(batch_frames.inputs)
        
        # Apply deformation basis of size K to coarse points
        deformed_points = apply_deformation_basis(coarse_points, coeffs, K)
        
        # Render intermediate representation (not fully detailed in sources, 
        # but implied to be part of the loss calculation)
        rendered_imgs = render(deformed_points)
        
        # Calculate Loss
        # 1. Photometric Loss (standard L1 + D-SSIM)
        loss_img = compute_photometric_loss(rendered_imgs, batch_frames.gt)
        
        # 2. Rigidity Loss (keeps template consistent across timesteps)
        # Exact formula not given in sources [S1]
        loss_rigid = compute_rigidity_loss(deformed_points, batch_frames.timesteps)
        
        loss = loss_img + loss_rigid
        
        # Backprop and update
        optimizer_stage1.zero_grad()
        loss.backward()
        optimizer_stage1.step()
        scheduler_stage1.step()
        
    # Stage 2: 3D Gaussian Refinement
    # Initialize 3D Gaussians from Stage 1 results
    gaussians = initialize_gaussians(deformed_points)
    
    # Optimizer for Stage 2
    # Note: Different LRs for different parameters
    params_gaussians = [
        {'params': gaussians.positions, 'lr': lr_3dgs_default}, # Matches 3DGS default
        {'params': gaussians.scales, 'lr': lr_stage2_scale},
        {'params': gaussians.opacities, 'lr': lr_3dgs_default},
        {'params': gaussians.sh_coeffs, 'lr': lr_3dgs_default},
        {'params': gaussians.interpolation_weights, 'lr': lr_3dgs_default} # w
    ]
    optimizer_stage2 = Adam(params_gaussians)
    
    # Exponential scheduler for scales
    scheduler_scales = ExponentialDecay(optimizer_stage2, target_lr=lr_stage2_scale)
    
    # Optional: Include Stage 1 params in optimizer for finetuning
    if finetune_stage1:
        params_stage1 = [
            {'params': coarse_points, 'lr': lr_finetune},
            {'params': deformation_mlp.parameters(), 'lr': lr_finetune}
        ]
        optimizer_stage2.add_param_group({'params': params_stage1})

    for iter in range(stage2_iters):
        batch_frames = sample_batch(video_frames, batch_size)
        
        # Get deformation coefficients
        coeffs = deformation_mlp(batch_frames.inputs)
        
        # Deform coarse points
        deformed_points = apply_deformation_basis(coarse_points, coeffs, K)
        
        # Render 3D Gaussians (blended/interpolated using weights w)
        rendered_imgs = render_gaussians(gaussians, deformed_points)
        
        # Photometric Loss
        loss = compute_photometric_loss(rendered_imgs, batch_frames.gt)
        
        optimizer_stage2.zero_grad()
        loss.backward()
        optimizer_stage2.step()
        
        # Update scale scheduler
        scheduler_scales.step()

    return coarse_points, deformation_mlp, gaussians
```

## Operating characteristics
-   **Performance:** NPGs outperforms baselines like Nerfies, HyperNeRF, TiNeuVox, and HexPlane on the Unbiased4D dataset (PSNR 22.348 vs 15.92–18.56) [S1].
-   **Strengths:** Successfully keeps coarse geometry intact over the sequence and fits high-frequency details, which is critical for monocular non-rigid reconstruction [S1].
-   **Limitations:** Highly sensitive to camera motion; static cameras can cause template collapse [S1]. Requires careful tuning of the deformation basis size $K$ [S1].
-   **Complexity:** Uses a fixed iteration budget (100k + 70k) rather than loss convergence [S1].

## Background
NPGs was introduced in "Neural Parametric Gaussians for Monocular Non-Rigid Object Reconstruction" (CVPR 2024) [S1]. It addresses the limitations of previous methods that fail to capture geometry correctly in monocular settings by introducing a two-stage optimization with a low-rank deformation basis [S1].
