# GlobalSplat


## Overview
GlobalSplat is a feed-forward 3D Gaussian Splatting framework that aligns multi-view inputs into a fixed set of global latent scene tokens before decoding explicit 3D geometry, preventing representation bloat and ensuring global consistency [S1]. Unlike sibling methods such as [CodecSplat](18143-codecsplat.md) and [latentSplat](18652-latentsplat.md) which may rely on dense view-aligned primitives or different grid structures, GlobalSplat aggregates multi-view inputs into a fixed number of latent tokens (2048) regardless of the number of input views, then decodes these tokens into a sparse, globally consistent set of Gaussians (16K) [S1]. This approach achieves a superior quality-efficiency trade-off compared to [C3G](16423-c3g.md), which uses full self-attention and single-Gaussian decoding, by employing an iterative, disentangled dual-branch architecture and a coarse-to-fine capacity curriculum [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $C$ RGB images $I \in \mathbb{R}^{H \times W \times 3}$ with known camera poses $T_i$ (rotation $R_i$, translation $t_i$) and intrinsics $K_i$ [S1].
*   **Output:** A set of $N$ 3D Gaussians $\mathcal{G} = \{\mu_n, \Sigma_n, \alpha_n, c_n\}_{n=1}^N$, where $\mu_n$ is the mean, $\Sigma_n$ is the covariance (parameterized by scale $s_n$ and rotation $r_n$), $\alpha_n$ is the opacity, and $c_n$ are Spherical Harmonics (SH) coefficients [S1].

**Data Structures:**
1.  **Latent Tokens:** A fixed set of $M=2048$ learnable latent tokens $l_j \in \mathbb{R}^d$ with $d=512$ [S1].
2.  **Register Tokens:** Learnable register tokens used to capture global context (specific dimension not given, assumed same as latent tokens or handled internally) [S1].
3.  **Gaussian Candidates:** For each latent token $p$, the decoder predicts $K_s=16$ candidates. The data layout for token $p$ is:
    *   $\mathbf{X}_p \in \mathbb{R}^{16 \times 3}$: Candidate means [S1].
    *   $\mathbf{S}_p \in \mathbb{R}^{16 \times 3}$: Candidate log-scales [S1].
    *   $\mathbf{R}_p \in \mathbb{R}^{16 \times 6}$: Candidate 6D rotations [S1].
    *   $\mathbf{O}_p \in \mathbb{R}^{16 \times 1}$: Candidate opacity logits [S1].
    *   $\boldsymbol{\ell}_p \in \mathbb{R}^{16 \times 1}$: Candidate importance scores (gate logits) [S1].
    *   $\mathbf{C}_p \in \mathbb{R}^{16 \times (3 D_{\text{SH}})}$: Candidate SH coefficients, where $D_{\text{SH}}=16$ for SH degree 3 [S1].

**Preprocessing:**
1.  **Scene Normalization:**
    *   Compute the canonical frame origin: $\bar{o} = \frac{1}{C} \sum_{i=1}^C o_i$, where $o_i$ is the camera center [S1].
    *   Compute axes by averaging camera viewing directions and re-orthonormalizing [S1].
    *   Let $T_{\text{avg}}$ be the resulting average pose [S1].
    *   Transform all cameras: $\hat{T}_i = T_{\text{avg}}^{-1} T_i$ [S1].
    *   Compute scene scale: $s = \max_{a,b} \|\hat{o}_a - \hat{o}_b\|_2$ [S1].
    *   Scale camera translations: $\tilde{o}_i = \frac{\hat{o}_i}{s}$ [S1].
2.  **Image Preprocessing:**
    *   Resize image height to 256, preserving aspect ratio [S1].
    *   Round width to a multiple of patch size 8 [S1].
    *   Update intrinsics accordingly [S1].
    *   Apply centered square crop [S1].
    *   Final resize to $256 \times 256$ [S1].
3.  **Feature Extraction:**
    *   Extract RGB patch features $u_{i,p}^{\text{rgb}}$ from input view $i$ and patch $p$ [S1].
    *   Compute dense Plücker-ray features $r_{i,p}$ and patchify them [S1].
    *   Map rays: $\hat{r}_{i,p} = W_{\text{ray}} r_{i,p}$ [S1].
    *   Compute per-view camera code $e_i$ using Fourier positional encoding for camera center and MLP for intrinsics [S1].
    *   Combine: $u_{i,p}^{\text{cam}} = \hat{r}_{i,p} + e_i$ [S1].
    *   Form input context: $u_{i,p} = [u_{i,p}^{\text{cam}} ; u_{i,p}^{\text{rgb}}]$ [S1].

**Algorithm:**
1.  **Initialization:** Initialize $M=2048$ latent tokens $l_j^{(0)}$ and register tokens [S1].
2.  **Dual-Branch Encoder:** Repeat for $B=4$ blocks $j=0 \dots B-1$:
    *   Project latent tokens into geometry and appearance streams:
        $f_{\text{geo}}^{(j)} = \text{Proj}_{\text{geo}}(l^{(j)})$, $f_{\text{app}}^{(j)} = \text{Proj}_{\text{app}}(l^{(j)})$ [S1].
    *   For each branch $i \in \{\text{geo}, \text{app}\}$:
        *   Apply Cross-Attention between input patches $x$ (context $u$) and stream features:
            $f_{i}^{\text{cross}} = \text{CrossAtt}_i(x, f_{i}^{(j)})$ [S1].
        *   Apply $L=2$ Self-Attention blocks:
            $f_{i}^{(j+1)} = \text{SelfAtt}_i(\dots \text{SelfAtt}_i(f_{i}^{\text{cross}}) \dots)$ [S1].
    *   Fuse streams:
        $l^{(j+1)} = \text{MLP}(\text{Concat}(f_{\text{geo}}^{(j+1)}, f_{\text{app}}^{(j+1)}))$ [S1].
3.  **Decoder Candidate Prediction:**
    *   For each latent token $p$, predict the 16 candidates $\mathbf{X}_p, \mathbf{S}_p, \mathbf{R}_p, \mathbf{O}_p, \boldsymbol{\ell}_p, \mathbf{C}_p$ using the dual-branch decoder heads [S1].
4.  **Coarse-to-Fine Merging (Inference/Training):**
    *   Determine stage $s$. Final model uses $s=3$, so $G = 2^3 = 8$ groups per token [S1].
    *   Partition 16 candidates into $G$ groups of size $b_s = 16/G$ [S1].
    *   For each group $g$ and token $p$:
        *   Compute weights: $w_{p,g,i} = \frac{\exp(\ell_{p,g,i}/\tau)}{\sum_{k=1}^{b_s} \exp(\ell_{p,g,k}/\tau)}$ [S1].
        *   Merge attributes: $\bar{z}_{p,g} = \sum_{i=1}^{b_s} w_{p,g,i} z_{p,g,i}$ for $z \in \{\mathbf{X}, \mathbf{S}, \mathbf{R}, \mathbf{O}, \mathbf{C}\}$ [S1].
    *   The final set of Gaussians is the collection of all merged groups across all tokens [S1].
5.  **Rendering:**
    *   Project Gaussians to 2D [S1].
    *   Accumulate color: $C = \sum_{i=1}^{M} c_i \alpha'_i \prod_{j=1}^{i-1} (1 - \alpha'_j)$, where $\alpha'_i$ is the product of base opacity $\alpha_i$ and projected 2D Gaussian density [S1].

**Gaussian Parameterization Details:**
*   **Means:** Initialized with a fixed forward offset of 1.5 [S1].
*   **Scales:** Predicted in log space as an offset from -2 [S1].
*   **Opacity:** Predicted in logit space as an offset from -5 [S1].
*   **Rotations:** Continuous 6D parameterization as residual offsets from a static rotation [S1].

**Training Objectives:**
*   **Rendering Loss:** $\mathcal{L}_{\text{ren}} = \|I_t - \hat{I}_t\|_2^2 + \lambda_{\text{perc}}\mathcal{L}_{\text{perc}}(I_t, \hat{I}_t)$ [S1].
*   **Self-Supervised Consistency:** $\mathcal{L}_{\text{con}} = \|O(\mathcal{I}_a) - \text{sg}(O(\mathcal{I}_b))\|_2^2 + \|D(\mathcal{I}_a) - \text{sg}(D(\mathcal{I}_b))\|_2^2$, where $O$ and $D$ are rendered opacity and depth maps [S1].
*   **Regularization:** $\mathcal{L}_{\text{reg}} = \lambda_{\text{thr}}\mathcal{L}_{\text{thr}} + \lambda_{\text{fru}}\mathcal{L}_{\text{fru}}$ (soft thresholding and frustum constraint) [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class GlobalSplat:
    def __init__(self, num_tokens=2048, token_dim=512, num_candidates=16, num_encoder_blocks=4, num_self_attn_layers=2):
        self.M = num_tokens
        self.d = token_dim
        self.K = num_candidates
        self.B = num_encoder_blocks
        self.L = num_self_attn_layers
        self.G_final = 8 # Stage 3
        
        # Learnable parameters
        self.latent_tokens = nn.Parameter(torch.randn(self.M, self.d))
        self.register_tokens = nn.Parameter(torch.randn(self.M, self.d)) # [G]
        
        # Encoder components
        self.proj_geo = nn.Linear(self.d, self.d)
        self.proj_app = nn.Linear(self.d, self.d)
        self.cross_attn_geo = nn.MultiheadAttention(self.d, num_heads=8)
        self.cross_attn_app = nn.MultiheadAttention(self.d, num_heads=8)
        self.self_attn_geo = nn.ModuleList([nn.MultiheadAttention(self.d, num_heads=8) for _ in range(self.L)])
        self.self_attn_app = nn.ModuleList([nn.MultiheadAttention(self.d, num_heads=8) for _ in range(self.L)])
        self.mixer_mlp = nn.Sequential(
            nn.Linear(self.d * 2, self.d),
            nn.ReLU(),
            nn.Linear(self.d, self.d)
        )
        
        # Decoder components
        self.dec_geo = nn.Linear(self.d, self.K * (3 + 3 + 6 + 1 + 1)) # X, S, R, O, l
        self.dec_app = nn.Linear(self.d, self.K * (3 * 16)) # C (SH degree 3, 3 channels, 16 coeffs)
        
        # Ray projection
        self.W_ray = nn.Linear(6, 256) # Assuming Plucker dim 6, output 256
        
        # Temperature for merging
        self.temperature = 1.0

    def normalize_scene(self, poses, intrinsics):
        # poses: (C, 4, 4) or (C, 3, 4)
        # intrinsics: (C, 3, 3)
        # Compute canonical frame
        centers = poses[:, :3, 3]
        o_avg = centers.mean(dim=0)
        
        # Viewing directions (z-axis of rotation matrix)
        views = poses[:, :3, 2]
        view_avg = views.mean(dim=0)
        view_avg = view_avg / view_avg.norm()
        
        # Re-orthonormalize
        x_axis = torch.cross(view_avg, torch.tensor([0, 0, 1], device=views.device))
        if x_axis.norm() < 1e-6:
            x_axis = torch.tensor([1, 0, 0], device=views.device)
        x_axis = x_axis / x_axis.norm()
        y_axis = torch.cross(view_avg, x_axis)
        
        # Construct T_avg inverse (approximate for simplicity in pseudocode)
        # In practice, T_avg is the pose of the average camera. 
        # We transform all cameras to this frame.
        # T_avg_inv * T_i
        # For pseudocode, we assume a function that returns transformed poses
        # and scale normalization.
        
        # Scale normalization
        max_dist = 0
        for i in range(len(centers)):
            for j in range(i + 1, len(centers)):
                dist = (centers[i] - centers[j]).norm()
                if dist > max_dist:
                    max_dist = dist
        scale = max_dist if max_dist > 0 else 1.0
        
        # Transform centers
        # Note: Full 4x4 transform application omitted for brevity, assuming helper exists
        # transformed_centers = apply_transform(centers, T_avg_inv)
        # scaled_centers = transformed_centers / scale
        
        return centers, scale

    def extract_features(self, images, poses, intrinsics):
        # images: (C, 3, 256, 256)
        # Preprocessing is assumed done before this call
        C, _, H, W = images.shape
        patch_size = 8
        num_patches = (H // patch_size) * (W // patch_size)
        
        # Extract RGB patches
        # Assuming a CNN/ViT encoder produces features of dim 512
        # u_rgb: (C, num_patches, 512)
        u_rgb = self.vision_encoder(images) 
        
        # Compute Plucker rays and patchify
        # r_i_p: (C, num_patches, 6)
        r = compute_plucker_rays(poses, intrinsics, H, W, patch_size)
        
        # Map rays
        r_flat = r.view(-1, 6)
        r_mapped = self.W_ray(r_flat).view(C, num_patches, 256)
        
        # Per-view camera code
        # e_i: (C, 256)
        e = self.camera_encoder(poses, intrinsics)
        
        # Broadcast e to patches
        u_cam = r_mapped + e.unsqueeze(1)
        
        # Concatenate
        u = torch.cat([u_cam, u_rgb], dim=-1) # (C, num_patches, 768)
        
        return u

    def encode(self, u):
        # u: (C, num_patches, input_dim)
        # Flatten patches for attention
        # x: (num_patches, C, input_dim) -> Transposed for MHA
        x = u.permute(1, 0, 2) 
        
        l = self.latent_tokens.unsqueeze(1) # (M, 1, d)
        
        for j in range(self.B):
            # Project
            f_geo = self.proj_geo(l).permute(1, 0, 2) # (1, M, d)
            f_app = self.proj_app(l).permute(1, 0, 2)
            
            # Cross Attention
            # Key/Value from x, Query from f
            f_geo_cross, _ = self.cross_attn_geo(f_geo, x, x)
            f_app_cross, _ = self.cross_attn_app(f_app, x, x)
            
            # Self Attention
            for l_idx in range(self.L):
                f_geo, _ = self.self_attn_geo[l_idx](f_geo_cross, f_geo_cross, f_geo_cross)
                f_app, _ = self.self_attn_app[l_idx](f_app_cross, f_app_cross, f_app_cross)
                
            # Fuse
            fused = torch.cat([f_geo, f_app], dim=-1) # (1, M, 2d)
            l = self.mixer_mlp(fused).permute(1, 0, 2) # (M, 1, d)
            
        return l.squeeze(1) # (M, d)

    def decode(self, l):
        # l: (M, d)
        geo_out = self.dec_geo(l) # (M, K * (14))
        app_out = self.dec_app(l) # (M, K * 48)
        
        # Reshape
        geo_out = geo_out.view(-1, self.K, 14)
        app_out = app_out.view(-1, self.K, 48)
        
        # Split geo
        X = geo_out[:, :, :3]
        S = geo_out[:, :, 3:6]
        R = geo_out[:, :, 6:12]
        O = geo_out[:, :, 12:13]
        l_gate = geo_out[:, :, 13:14]
        
        return X, S, R, O, l_gate, app_out

    def merge_candidates(self, X, S, R, O, l_gate, C, stage_s=3):
        G = 2 ** stage_s
        b_s = self.K // G
        
        merged_X = []
        merged_S = []
        merged_R = []
        merged_O = []
        merged_C = []
        
        for p in range(X.shape[0]):
            for g in range(G):
                start_idx = g * b_s
                end_idx = (g + 1) * b_s
                
                # Get candidates for this group
                X_g = X[p, start_idx:end_idx, :] # (b_s, 3)
                S_g = S[p, start_idx:end_idx, :]
                R_g = R[p, start_idx:end_idx, :]
                O_g = O[p, start_idx:end_idx, :]
                C_g = C[p, start_idx:end_idx, :]
                l_g = l_gate[p, start_idx:end_idx, :] # (b_s, 1)
                
                # Compute weights
                weights = F.softmax(l_g / self.temperature, dim=0) # (b_s, 1)
                
                # Weighted sum
                w = weights.squeeze(-1) # (b_s,)
                
                m_X = torch.sum(w.unsqueeze(-1) * X_g, dim=0)
                m_S = torch.sum(w.unsqueeze(-1) * S_g, dim=0)
                m_R = torch.sum(w.unsqueeze(-1) * R_g, dim=0)
                m_O = torch.sum(w.unsqueeze(-1) * O_g, dim=0)
                m_C = torch.sum(w.unsqueeze(-1) * C_g, dim=0)
                
                merged_X.append(m_X)
                merged_S.append(m_S)
                merged_R.append(m_R)
                merged_O.append(m_O)
                merged_C.append(m_C)
                
        return torch.stack(merged_X), torch.stack(merged_S), torch.stack(merged_R), torch.stack(merged_O), torch.stack(merged_C)

    def forward(self, images, poses, intrinsics):
        centers, scale = self.normalize_scene(poses, intrinsics)
        u = self.extract_features(images, poses, intrinsics)
        l = self.encode(u)
        X, S, R, O, l_gate, C = self.decode(l)
        
        # Merge
        X_m, S_m, R_m, O_m, C_m = self.merge_candidates(X, S, R, O, l_gate, C, stage_s=3)
        
        # Construct Gaussians
        # Note: Actual construction of Sigma from S and R, and SH evaluation, 
        # is handled by the renderer.
        return X_m, S_m, R_m, O_m, C_m
```

## Operating characteristics
*   **Time Complexity:** Inference is a single forward pass through the encoder-decoder network. On RealEstate10K with 24 input views, inference time is <78 ms [S1].
*   **Memory Complexity:** Peak GPU memory is 1.79 GB for 24 views on RealEstate10K [S1]. Disk size is ~4 MB for the 16K Gaussians [S1].
*   **Performance:** On RealEstate10K with 12 views, GlobalSplat16K achieves PSNR 28.57, SSIM 0.885, LPIPS 0.138 [S1]. With 24 views, it achieves 28.5 PSNR [S1].
*   **Strengths:** Fixed number of Gaussians (16K) regardless of input view count prevents representation bloat. Fast inference. Low memory footprint. Global consistency via latent tokens.
*   **Limitations:** Relies on a fixed capacity curriculum. May struggle with extremely high-frequency details compared to dense methods if the 16K budget is insufficient. Requires known camera poses for training (though preprocessing normalizes them).
*   **When to use:** When computational efficiency, low memory usage, and global consistency are prioritized over maximum possible PSNR on very complex scenes with many input views. Suitable for real-time or near-real-time novel view synthesis from sparse inputs.

## Background
GlobalSplat was introduced by R. Itkin et al. in 2025 [S1]. It addresses the limitation of current feed-forward 3DGS pipelines where primitives are formed in dense view-aligned spaces, leading to representation bloat and fragile global consistency as more views are added [S1]. It builds on the principles of [Latent Space Representation](19901-latent-space-representation.md) by using a fixed set of latent tokens to encode multi-view information before decoding explicit geometry [S1]. It is evaluated on RealEstate10K and ACID datasets [S1].
