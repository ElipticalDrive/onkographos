# Opacity Reset & Densification Trigger

Also called: Opacity Reset, 3DGS Densification, Gaussian Densification

## Overview
Opacity Reset & Densification Trigger is a training-time adaptive control mechanism for 3D Gaussian Splatting that manages the number and density of Gaussian primitives to balance reconstruction quality against computational cost. It solves the problem of static Gaussian counts failing to capture complex scene geometry, either by leaving under-reconstructed regions sparse or by allowing over-reconstructed regions to bloat with redundant primitives. Unlike sibling methods that focus on specific regularization or post-processing, this method dynamically clones, splits, and prunes Gaussians based on view-space positional gradients and opacity thresholds, periodically resetting opacities to stabilize gradient flow and prevent the accumulation of "floaters" [S2][S4, unofficial].

## How it works
The method operates as a periodic refinement loop during optimization. It maintains state for each Gaussian to track visibility and gradient accumulation, then applies structural changes (clone, split, prune, reset) based on thresholds when specific iteration criteria are met.

### Inputs and Outputs
*   **Inputs:**
    *   Current iteration step $t$.
    *   Gaussian attributes: positions $\mathbf{p}$, scales $\mathbf{s}$, rotations $\mathbf{r}$, opacities $\alpha$, spherical harmonic coefficients $\mathbf{c}$.
    *   Gradients: view-space positional gradients $\nabla_{\mathbf{p}}$ and image-plane gradients $\nabla_{\text{img}}$.
    *   Configuration parameters: thresholds and iteration intervals (see Parameters).
*   **Outputs:**
    *   Updated Gaussian set with modified counts, positions, scales, and opacities.

### Data Structures
Two primary state accumulators are maintained per Gaussian $i$:
1.  `grad2d[i]`: A scalar or vector accumulating the norm of image-plane gradients (or positional gradients projected to 2D) over time.
2.  `count[i]`: A scalar accumulating the number of times Gaussian $i$ contributed to the rendered image (visibility count).

### Parameters
*   `densification_threshold` ($\tau_{dens}$): Threshold for triggering densification based on accumulated gradient. Default: 0.002 [S3, S4, unofficial].
*   `pos_thresh`: Threshold for average magnitude of view-space position gradients. Default: 0.0002 [S2].
*   `prune_opa` ($\alpha_{prune}$): Opacity threshold below which Gaussians are pruned. Default: 0.005 [S4, unofficial].
*   `grow_grad2d`: Image plane gradient threshold for splitting/duplicating. Default: 0.0002 [S4, unofficial].
*   `grow_scale3d`: 3D scale threshold (normalized by scene scale) below which Gaussians are duplicated. Default: 0.01 [S4, unofficial].
*   `grow_scale2d`: 2D scale threshold (normalized by image resolution) above which Gaussians are split. Default: 0.05 [S4, unofficial].
*   `prune_scale3d`: 3D scale threshold (normalized by scene scale) above which Gaussians are pruned. Default: 0.1 [S4, unofficial].
*   `prune_scale2d`: 2D scale threshold (normalized by image resolution) above which Gaussians are pruned. Default: 0.15 [S4, unofficial].
*   `refine_start_iter`: Iteration after which refinement begins. Default: 500 [S4, unofficial].
*   `refine_stop_iter`: Iteration after which refinement stops. Default: 15,000 [S4, unofficial].
*   `refine_every`: Number of steps between refinement operations. Default: 100 [S4, unofficial].
*   `reset_every`: Number of steps between opacity resets. Default: 3000 [S4, unofficial].
*   `opacity_reset_interval`: Iteration interval for opacity reset. Used in [S5, unofficial].
*   `densify_from_iter`: Iteration threshold for white-background datasets. Used in [S5, unofficial].
*   `pause_refine_after_reset`: Steps to pause refinement after reset. Default: 0 [S4, unofficial].
*   `split_scale_factor`: Factor by which scale is divided during split. Default: 1.6 [S2].
*   `absgrad`: Boolean flag to use absolute gradients instead of average. Default: False [S4, unofficial].
*   `revised_opacity`: Boolean flag for revised opacity heuristic. Default: False [S4, unofficial].
*   `key_for_gradient`: Variable name for gradient source ('means2d' or 'gradient_2dgs'). Default: 'means2d' [S4, unofficial].
*   `floor`: Constant added to denominator in occlusion-aware criterion. Default: 1 [S3, unofficial].

### Algorithm Steps

1.  **Initialization**:
    *   Initialize `grad2d` and `count` arrays to zeros for all Gaussians.

2.  **Pre-Backward Accumulation**:
    *   For each training step, after the backward pass, accumulate gradients and visibility info into `grad2d` and `count` for each Gaussian.
    *   If `absgrad` is true, accumulate absolute gradients; otherwise, accumulate average gradients [S4, unofficial].

3.  **Refinement Check**:
    *   Determine if refinement should occur at current step $t$:
        *   Condition A: $t \ge \text{refine\_start\_iter}$ AND $t < \text{refine\_stop\_iter}$ AND $t \% \text{refine\_every} == 0$ AND not paused after reset [S4, unofficial].
        *   Condition B (White Background): If dataset uses white background and $t == \text{densify\_from\_iter}$, trigger reset [S5, unofficial].
        *   Condition C (Periodic Reset): If $t \% \text{opacity\_reset\_interval} == 0$ (or $t \% \text{reset\_every} == 0$), trigger reset [S5, S4, unofficial].

4.  **Opacity Reset**:
    *   If triggered, call `reset_opacity()`:
        *   Reset all Gaussian opacities $\alpha_i$ to a small initial value (e.g., 0.01 or 0.005, depending on implementation variant) [S4, S5, unofficial].
        *   Optionally, reset non-diffuse spherical harmonic coefficients to 0.001 to remove view-dependent artifacts from distractors [S1].
        *   If `pause_refine_after_reset > 0`, set a flag to skip refinement for the next $N$ steps [S4, unofficial].

5.  **Densification (Clone and Split)**:
    *   If refinement is active and not paused:
        *   **Detect Under-reconstruction**: Identify Gaussians with high view-space positional gradients ($\|\nabla_{\mathbf{p}}\| > \text{pos\_thresh}$) [S2].
        *   **Clone Small Gaussians**: For small Gaussians (scale $< \text{grow\_scale3d}$) in under-reconstructed regions:
            *   Create a copy of the Gaussian.
            *   Move the copy's position in the direction of the positional gradient [S2].
        *   **Split Large Gaussians**: For large Gaussians (scale $> \text{grow\_scale2d}$ in 2D or high variance) in over-reconstructed regions:
            *   Replace the Gaussian with two new Gaussians.
            *   Divide their scale by $\text{split\_scale\_factor} = 1.6$ [S2].
            *   Initialize positions by sampling from the original Gaussian's probability density function (PDF) [S2].

6.  **Pruning**:
    *   Remove Gaussians that meet any of the following criteria:
        *   Opacity $\alpha_i < \text{prune\_opa}$ [S4, unofficial].
        *   3D scale $> \text{prune\_scale3d}$ (very large in world space) [S2][S4, unofficial].
        *   2D scale $> \text{prune\_scale2d}$ (big footprint in viewspace) [S2][S4, unofficial].

7.  **Occlusion-Aware Densification Criterion (Variant)**:
    *   If using occlusion-aware densification [S3, unofficial]:
        *   Compute score: $\text{score}_i = \frac{\sum \nabla_i}{\text{floor} + \sum w_{i,v}}$, where $\sum \nabla_i$ is the accumulated gradient sum, $\sum w_{i,v}$ is the accumulated contribution (weight) from views $v$, and `floor` is a constant (default 1).
        *   Trigger densification if $\text{score}_i > \text{densification\_threshold}$.

### Pseudocode

```python
def densification_step(gaussians, step, config):
    """
    Perform densification, splitting, pruning, and opacity reset.
    """
    # 1. Check if refinement is active
    if not (step >= config.refine_start_iter and 
            step < config.refine_stop_iter and 
            step % config.refine_every == 0):
        return

    # 2. Check for Opacity Reset
    reset_triggered = False
    if step % config.opacity_reset_interval == 0:
        reset_triggered = True
        reset_opacity(gaussians)
        # Optionally reset SH coefficients for distractors
        if config.reset_sh_non_diffuse:
            reset_sh_non_diffuse(gaussians)
        
        # Pause refinement if configured
        if config.pause_refine_after_reset > 0:
            gaussians.pause_refine = config.pause_refine_after_reset

    if gaussians.pause_refine > 0:
        gaussians.pause_refine -= 1
        return

    # 3. Accumulate Gradients (Assumed done in pre-backward)
    # grad2d and count are updated externally or here
    
    # 4. Pruning
    prune_mask = (
        (gaussians.opacity < config.prune_opa) |
        (gaussians.scale_3d > config.prune_scale3d) |
        (gaussians.scale_2d > config.prune_scale2d)
    )
    gaussians.remove(prune_mask)

    # 5. Densification (Clone/Split)
    # Detect high gradient Gaussians
    high_grad_mask = (gaussians.grad_norm > config.pos_thresh)
    
    # Clone small Gaussians (Under-reconstruction)
    small_mask = high_grad_mask & (gaussians.scale_3d < config.grow_scale3d)
    if small_mask.any():
        clone_gaussians(gaussians, small_mask, direction='gradient')

    # Split large Gaussians (Over-reconstruction)
    large_mask = high_grad_mask & (gaussians.scale_2d > config.grow_scale2d)
    if large_mask.any():
        split_gaussians(gaussians, large_mask, factor=config.split_scale_factor)

def reset_opacity(gaussians):
    """Reset opacities to initial low value."""
    gaussians.opacity = 0.01  # [G] Typical initial value

def clone_gaussians(gaussians, mask, direction):
    """Clone Gaussians and move them."""
    clones = gaussians[mask].clone()
    if direction == 'gradient':
        clones.position += clones.gradient * 0.1  # [G] Step size heuristic
    gaussians.add(clones)

def split_gaussians(gaussians, mask, factor):
    """Split Gaussians into two smaller ones."""
    parents = gaussians[mask]
    # Sample two positions from parent PDF
    pos1 = sample_from_pdf(parents.position, parents.scale)
    pos2 = sample_from_pdf(parents.position, parents.scale)
    
    new_gaussians = []
    for p in parents:
        g1 = Gaussian(p.position, p.rotation, p.color, p.sh, p.opacity)
        g1.scale /= factor
        g1.position = pos1
        new_gaussians.append(g1)
        
        g2 = Gaussian(p.position, p.rotation, p.color, p.sh, p.opacity)
        g2.scale /= factor
        g2.position = pos2
        new_gaussians.append(g2)
    
    gaussians.add(new_gaussians)
```

## Subtopics

### [Smooth Opacity Decay](15326-smooth-opacity-decay.md)
Smooth Opacity Decay is a regularization technique used during the training of 3D Gaussian Splatting models to gradually reduce the opacity of primitives, serving as a softer alternative to hard opacity resets. It solves the problem of training instability and misleading error statistics caused by abrupt opacity changes, which can trigger incorrect densification decisions. Unlike hard pruning, it allows for gradual adjustment of opacity parameters, stabilizing gradient flow and preventing sudden loss of scene coverage [15326-smooth-opacity-decay.md].

### Joint Deletion Cost Approximation
Joint Deletion Cost Approximation is a method for pruning Gaussians by approximating the cost of deleting multiple Gaussians simultaneously using a first-order Taylor expansion of the rendering function. It solves the problem of inefficient iterative pruning by allowing batch deletion decisions. The approximation $f_b(1-u) - f_b(1) \approx -J_b u$ is used, where $J_b$ is the Jacobian of the rendered block. This method may become less accurate when many Gaussians are deleted together, requiring recomputation after model refinement [S6, unofficial].

### Opacity Lobe Modulation
Opacity Lobe Modulation applies generalized Phong shading to opacity modulation rather than radiance modeling, allowing the opacity lobe to decouple each Gaussian kernel's contribution to final exitant radiance. It provides stability against depth sorting permutations, unlike methods using spherical beta functions for color which require exponentially increasing color magnitudes for subsurface Gaussians. It introduces minimal overhead (5 parameters per instance) and is used by ~10% of primitives [S7, unofficial].

### 3D Gaussian Editing Operations
3D Gaussian Editing Operations are procedures to modify Gaussians (opacity and color) based on selected regions for extraction, deletion, or appearance modification. Extraction sets unselected opacities to 0; deletion sets selected opacities to 0; appearance modification updates color via a function. It uses semantic features for selection [S8].

### Denominator Floor for Occlusion-Aware Densification
Denominator Floor for Occlusion-Aware Densification adds a constant floor to the accumulated contribution in the denominator of the densification criterion ($\text{score} = \text{gradient\_sum} / (\text{floor} + \text{accumulated\_contribution})$). It prevents score inflation when accumulated contribution is between 0 and 1, which causes training divergence without a floor. A floor of 1 is chosen as the minimal value guaranteeing the denominator does not fall below 1 [S3, unofficial].

### Transition to Opaque Point Rendering
Transition to Opaque Point Rendering is a method to smoothly transition from alpha blending to opaque depth testing during optimization to achieve high-performance real-time rendering. It adjusts the sigmoid function encoding raw alpha values to become steeper over time, resulting in binary opacities for final rendering [S9].

### Post-Backward Strategy
Post-Backward Strategy is a post-optimization step for densification/pruning strategies, handling splat count changes and normal updates. It checks if the splat count changed and updates normals by querying an anchor tree or recomputing them from nearest points if a mismatch occurs [S10, unofficial].

### Structure Adaptive Control
Structure Adaptive Control identifies under-reconstruction regions via positional gradients and overdense regions via opacity. It replicates neighboring Gaussians for structural completion and eliminates low-opacity regions to reduce redundancy. It uses predefined thresholds for gradient and opacity [S11].

## Operating characteristics
*   **Time Complexity**: Densification and pruning are $O(N)$ operations per refinement step, where $N$ is the number of Gaussians. Refinement occurs every 100 iterations [S2][S4, unofficial].
*   **Memory Complexity**: Memory usage scales with the number of Gaussians. The method dynamically adjusts $N$, typically increasing it from an initial sparse set to a denser set (e.g., 1.79M Gaussians on Mip-NeRF360 subsets) [S2][S3, unofficial].
*   **Measured Performance**: On Mip-NeRF360 calibration subset (bicycle, bonsai, counter, garden), a densification threshold of 0.002 yields 1.79M Gaussians with best PSNR, SSIM, and GMSD. Over-densification (0.001) yields 4.90M Gaussians and lowers PSNR. Under-densification (0.004) yields 0.66M Gaussians and raises LPIPS [S3, unofficial].
*   **Scaling**: The method scales to large scenes by adaptively controlling density. However, without pruning, the number of Gaussians can grow unbounded, leading to memory exhaustion [S2].
*   **Strengths**: Adapts to scene complexity, prevents over-reconstruction, and removes floaters.
*   **Limitations**: Requires careful tuning of thresholds. Without a denominator floor in occlusion-aware variants, training can diverge [S3, unofficial]. Replacing opacity reset with other methods (like UBP) may be ineffective for removing distractors [S1].

## Background
Opacity Reset & Densification Trigger was originally introduced in the 3D Gaussian Splatting paper by Kerbl et al. (2023) [S2]. It has since been adapted and refined in various implementations, including the official codebase and subsequent research papers. The method addresses the limitations of static point cloud representations by allowing the Gaussian count to evolve during training [S2]. Variants like occlusion-aware densification have been proposed to improve the criterion's robustness [S3, unofficial].
