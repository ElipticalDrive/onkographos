# Variational Quantum Circuit (VQC) for View-Dependent Encoding

Also called: Bloch-encoded VQC, QuantumGS VQC

## Overview
This method replaces or modulates classical Spherical Harmonics (SH) with a Variational Quantum Circuit (VQC) to model view-dependent radiance and opacity for 3D Gaussians, specifically targeting high-frequency specular effects and reducing artifacts like "floaters" [S1]. It sets itself apart from its parent [3iGS](13977-3igs-factorised-tensorial-illumination-for-3d-gaussian-splat.md) by using quantum-inspired entanglement and Bloch sphere mapping for directional encoding, and from its sibling [Physically-Based 3D Gaussian Splatting](16738-physically-based-3d-gaussian-splatting.md) by relying on learned quantum parameterizations rather than explicit physical scattering models [S1].

## How it works
**Inputs:**
*   3D Gaussian primitives $G$ with mean position $\mu_G$, covariance, base SH color coefficients, and base opacity [S1].
*   Viewing direction $d \in \mathbb{R}^3$ (normalized) [S1].
*   Hashed position features $hash(\mu_G)$ derived from multi-resolution hash encoding [S1].

**Outputs:**
*   Final color $c_{final}(d)$ and opacity $\alpha_{final}(d)$ for each Gaussian [S1].
*   Rendered image via differentiable rasterization [S1].

**Data Structures:**
1.  **Hash Encoding Configuration:** Multi-resolution hash grid with $L_{hash}=16$ levels, feature dimension $F=2$, and maximum hash table size $T=2^{19}$ [S1].
2.  **VQC State:** A 3-qubit register initialized to $|000\rangle$ [G].
3.  **VQC Parameters:** Rotation angles $\theta = (\theta_{j,\ell}, \phi_{j,\ell})$ for qubit $j \in \{0,1,2\}$ and layer $\ell \in \{1,\dots,L\}$ [S1].
4.  **Hypernetwork (Pipeline I):** Classical MLP with two hidden layers of 64 units, residual connections, GeLU activation, and dropout [S1].
5.  **Decoding MLP:** Lightweight MLP. Input size 3, single hidden layer of 3 neurons, output size $N_{out}$ (49 for full SH+opacity modulation, 1 for opacity-only) [S1].
6.  **Projection Networks (Pipeline II):** MLPs with 2 hidden layers of 64 units outputting dimension 3, conditioned on spatial and directional hashgrids [S1].

**Numbered Steps:**

1.  **Direction Encoding:** Map the viewing direction $d$ to a quantum state $|\psi_{enc}\rangle$ on the Bloch sphere [S1].
2.  **VQC Processing:** Process $|\psi_{enc}\rangle$ through a VQC ansatz $U(\theta; L)$ consisting of $L=4$ layers [S1]. For each layer $\ell$:
    *   Apply parameterized local rotations to the 3-qubit register [S1]. For the $j$-th qubit ($j=0, 1, 2$), apply:
        $$ R_j(\theta_{j,\ell}, \phi_{j,\ell}) = R_z^{(j)}(\phi_{j,\ell}) R_y^{(j)}(\theta_{j,\ell}) $$
        where $R_y$ and $R_z$ are standard quantum rotation gates defined by matrices:
        $$ R_y(\theta) = \begin{pmatrix} \cos(\theta/2) & -\sin(\theta/2) \\ \sin(\theta/2) & \cos(\theta/2) \end{pmatrix}, \quad R_z(\phi) = \begin{pmatrix} e^{-i\phi/2} & 0 \\ 0 & e^{i\phi/2} \end{pmatrix} $$
        [S1].
    *   Apply multi-qubit entanglement gates between qubits to introduce non-linearities and correlations [S1].
3.  **Parameter Generation (Pipeline I - Per-Gaussian):** For each Gaussian $G$, generate unique VQC parameters $\theta_G$ and MLP weights $W_{MLP}^G$ using a hypernetwork $H$ conditioned on the hashed position $hash(\mu_G)$:
    $$ (\theta_G, W_{MLP}^G) = H(hash(\mu_G)) $$
    [S1].
    *(Note: Pipeline II uses shared VQC parameters conditioned on global spatial/directional hashgrids via projection networks [S1].)*
4.  **Attribute Modulation:** Apply the VQC output and MLP weights to generate view-dependent multiplicative updates $\Delta c(d)$ and $\Delta \alpha(d)$ [S1]. Calculate final attributes:
    $$ c_{final}(d) = c(d) \cdot \Delta c(d) $$
    $$ \alpha_{final}(d) = \alpha(d) \cdot \Delta \alpha(d) $$
    [S1].
5.  **Rendering:** Render the scene using a differentiable Gaussian rasterizer with the refined attributes [S1].
6.  **Optimization:** Minimize the combined loss function:
    $$ \mathcal{L} = (1 - \lambda)\mathcal{L}_{1} + \lambda \mathcal{L}_{D-SSIM} $$
    where $\lambda \in (0, 1)$ [S1].

**Pseudocode:**

```python
import numpy as np

def bloch_encode(d):
    """Map normalized viewing direction d to a 3-qubit state vector via Bloch sphere mapping [G]."""
    theta = np.arccos(np.clip(d[2], -1.0, 1.0))
    phi = np.arctan2(d[1], d[0])
    state = np.zeros(8, dtype=complex)
    state[0] = 1.0
    state = apply_rotation(state, 0, theta, phi)
    return state

def rz_gate(phi):
    return np.array([[np.exp(-1j * phi / 2), 0], [0, np.exp(1j * phi / 2)]])

def ry_gate(theta):
    return np.array([[np.cos(theta / 2), -np.sin(theta / 2)],
                     [np.sin(theta / 2), np.cos(theta / 2)]])

def apply_rotation(state, qubit_idx, theta, phi):
    gate = rz_gate(phi) @ ry_gate(theta)
    if qubit_idx == 0:
        full_gate = np.kron(np.kron(gate, np.eye(2)), np.eye(2))
    elif qubit_idx == 1:
        full_gate = np.kron(np.kron(np.eye(2), gate), np.eye(2))
    elif qubit_idx == 2:
        full_gate = np.kron(np.kron(np.eye(2), np.eye(2)), gate)
    return full_gate @ state

def cnot_gate(state, control, target):
    new_state = np.zeros_like(state)
    for i in range(len(state)):
        bits = [(i >> k) & 1 for k in range(3)]
        if bits[control] == 1:
            new_bits = bits.copy()
            new_bits[target] = 1 - new_bits[target]
            new_idx = sum(b << k for k, b in enumerate(new_bits))
            new_state[new_idx] = state[i]
        else:
            new_state[i] = state[i]
    return new_state

def vqc_layer(state, layer_params):
    for j, (theta_j, phi_j) in enumerate(layer_params):
        state = apply_rotation(state, j, theta_j, phi_j)
    # Standard linear entanglement pattern [G]
    state = cnot_gate(state, 0, 1)
    state = cnot_gate(state, 1, 2)
    return state

def run_vqc(state, vqc_params):
    for layer_params in vqc_params:
        state = vqc_layer(state, layer_params)
    return state

def gelu(x):
    return 0.5 * x * (1 + np.tanh(np.sqrt(2 / np.pi) * (x + 0.044715 * np.power(x, 3))))

def hypernetwork_forward(hash_features, hypernet_weights):
    """Pipeline I hypernetwork: 2 hidden layers of 64 units, residual connections, GeLU activation, dropout [S1]."""
    x = hash_features
    W1, b1 = hypernet_weights[0]
    h1 = x @ W1 + b1
    h1 = gelu(h1)
    h1 = h1 + x  # Residual
    W2, b2 = hypernet_weights[1]
    h2 = h1 @ W2 + b2
    h2 = gelu(h2)
    h2 = h2 + h1  # Residual
    return h2

def decode_attributes(vqc_features, mlp_weights, base_color, base_opacity):
    """Decoding MLP: input layer size 3, single hidden layer of 3 neurons, output layer size N_out [S1]."""
    x = vqc_features  # Expected shape (3,)
    W1, b1 = mlp_weights[0]
    h1 = x @ W1 + b1
    h1 = gelu(h1)
    W2, b2 = mlp_weights[1]
    out = h1 @ W2 + b2
    delta_c = out[:3]
    delta_alpha = out[3]
    return base_color * delta_c, base_opacity * delta_alpha

def dssim_loss(rendered, target):
    return 0.0  # [S1] D-SSIM loss computation

def train_step(gaussians, views, hypernet_weights, vqc_params, mlp_weights, lambda_param, target):
    # 1. Encode directions
    states = [bloch_encode(d) for d in views]
    # 2. Run VQC
    final_states = [run_vqc(s, vqc_params) for s in states]
    # 3. Decode attributes (assuming vqc_features are extracted expectation values of size 3)
    vqc_features = np.array([np.real(s[:3]) for s in final_states])
    deltas = [decode_attributes(f, mlp_weights, g.base_color, g.base_opacity) for f, g in zip(vqc_features, gaussians)]
    # 4. Render & Loss
    # [S1] Differentiable Gaussian rasterization step
    rendered = np.zeros_like(target)
    loss = (1 - lambda_param) * np.mean(np.abs(rendered - target)) + lambda_param * dssim_loss(rendered, target)
    return loss
```

**Parameters:**
*   $L$: Number of VQC layers. Value: 4 [S1].
*   $\theta$: Trainable rotation angles $(\theta_{j,\ell}, \phi_{j,\ell})$ for qubit $j$ and layer $\ell$ [S1].
*   $\lambda$: Hyperparameter scaling L1 and D-SSIM loss. Range: $(0, 1)$ [S1].
*   Hash Grid: $L_{hash}=16$ levels, $F=2$ dimension, $T=2^{19}$ size [S1].

**Edge Cases and Pitfalls:**
*   **Simulation Overhead:** Simulating quantum entanglement on classical GPUs introduces significant computational overhead, preventing the extreme rasterization speeds of vanilla 3DGS [S1].
*   **Hypernetwork Complexity:** The hypernetwork introduces higher optimization complexity than explicit SH coefficients [S1].
*   **Entanglement Definition:** The exact topology of multi-qubit entanglement gates is not explicitly defined in the source text, only that they are applied to introduce non-linearities [S1]. Implementers must choose a standard ansatz (e.g., linear CNOT chain) [G].

## Subtopics

### Pipeline I (Hyper-Quantum)
Uses per-Gaussian unique VQC parameters generated by a hypernetwork [S1]. Sets itself apart by maximizing local expressivity for intricate optical effects [S1]. Choose for synthetic scenes prioritizing high PSNR [S1].

### Pipeline II (Joint-Hash Global)
Uses shared VQC parameters conditioned on spatial and directional hashgrids via projection networks [S1]. Sets itself apart by offering scene-scale scalability and memory efficiency [S1]. Choose for large-scale real-world scenes [S1].

## Operating characteristics
*   **Time Complexity:** Higher than vanilla 3DGS due to the simulation of quantum circuits (entanglement) on classical hardware [S1].
*   **Memory Complexity:** Pipeline I requires storing unique VQC parameters per Gaussian, increasing memory usage compared to shared parameters [S1].
*   **Performance:** On NeRF Synthetic, QuantumGS achieves PSNR 33.98 and SSIM 0.970, outperforming standard 3DGS (PSNR 33.30, SSIM 0.969) and VDGS (PSNR 33.37, SSIM 0.969) [S1]. FPS is significantly lower (12.64 FPS) compared to 3DGS (733.00 FPS) [S1].
*   **Strengths:** Eliminates "floater" artifacts, recovers high-frequency specular details, and maintains geometric robustness in complex scenes (e.g., Ship, Room, LEGO) [S1].
*   **Limitations:** Computational cost prevents real-time speeds comparable to vanilla 3DGS. Training efficiency is lower due to hypernetwork complexity [S1].
