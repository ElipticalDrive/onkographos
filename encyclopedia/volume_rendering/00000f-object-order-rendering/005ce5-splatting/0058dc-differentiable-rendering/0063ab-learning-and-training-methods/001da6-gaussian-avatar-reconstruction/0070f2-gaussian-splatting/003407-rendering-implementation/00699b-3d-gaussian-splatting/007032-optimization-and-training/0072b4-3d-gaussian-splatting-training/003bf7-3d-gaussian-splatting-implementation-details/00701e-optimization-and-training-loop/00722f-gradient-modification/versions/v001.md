# Gradient Modification

Also called: Gradient regularization, Truncated gradients, Bézier-boundary approximation

## Overview
Gradient modification techniques adjust the backpropagated gradients $\nabla \mathcal{L}$ to mitigate optimization instability, vanishing gradients, or gradient confusion in 3D Gaussian Splatting. They set themselves apart from standard training by intervening in the update step (Step 5 of the [Optimization and Training Loop](17791-optimization-and-training-loop.md)) rather than changing the loss function or rasterizer. Specifically, they address issues where standard differentiable rendering fails to provide useful signals for "dead" primitives or discontinuous geometric boundaries.

## Shared principles
The family operates on the gradients computed in Step 4 of the parent loop. The core mechanism involves inspecting the current state of a Gaussian primitive (opacity, position, or geometric boundary status) and the gradient signal $\frac{\partial L}{\partial \theta}$ to decide whether to:
1.  **Zero out** the gradient if the primitive is in an optimal or irrelevant state.
2.  **Approximate** a non-differentiable gradient using geometric surrogates.
3.  **Truncate** or **scale** the gradient magnitude based on distance or confidence metrics.
4.  **Store** historical gradient trends to filter out noisy updates from imperfect supervision.

These modifications are applied before the optimizer (Adam) updates the parameters.

## Subtopics

### [Bézier-boundary gradient approximation](13137-b-zier-boundary-gradient-approximation.md)
A strategy to approximate gradients for discontinuous indicator functions in Bézier-curve-based Gaussian representations. It sets itself apart by explicitly handling the non-differentiable segments of the $\alpha$-blending function where the curve boundary determines inclusion. Choose this when using cubic Bézier curves to define Gaussian support, as standard backpropagation fails at the discontinuity. It differs from truncated gradients by focusing on geometric boundary approximation rather than magnitude truncation.

### [Truncated Gradient Updates for 3D Gaussian Splatting](18661-truncated-gradient-updates-for-3d-gaussian-splatting.md)
Applies truncated gradients to "dead" Gaussians (low opacity) to enable long-range movement. It sets itself apart by introducing a piecewise surrogate gradient that activates only when a Gaussian's contribution is negligible, pulling primitives toward distant pixels. Choose this for dynamic scenes or poor initialization where Gaussians get stuck. It differs from Bézier-boundary approximation by handling the "dead" state (zero rasterization contribution) rather than geometric boundaries.

### Gradient Flag Optimization
An optimization strategy that augments Gaussian primitives with a flag gradient attribute to mitigate gradient confusion and perturbations caused by imperfect supervision from pseudo-views [S1].

**Definition**
Augments canonical Gaussian primitives $\{\mu, s, q, \sigma, c\}$ with an additional per-Gaussian attribute flag gradient $\nabla \in \mathbb{R}^{11+k_c}$, where $\nabla$ records gradient trends for $\mu, s, q, \sigma$, and $k_c$ SH coefficients [S1].

**Steps**
1.  For each Gaussian in one optimization step, compute the cosine similarity between the current gradient for each attribute $g_{ic}$ and the corresponding flag gradient $\nabla(g_i)$ stored in $\nabla$ [S1].
2.  If the cosine similarity is greater than zero, indicating aligned update trends, use $g_{ic}$ directly [S1].
3.  If the cosine similarity is less than or equal to zero, indicating potential disturbances, scale the current gradient by a factor $\epsilon$ and update the flag gradient:
    $$ g_{ic} = \epsilon g_{ic}, \quad \nabla(g_i) = (1 - \epsilon)\nabla(g_i) + \epsilon g_{ic} $$
    [S1].
4.  Pass the modified gradients to the gradient-based optimizer (e.g., Adam) [S1].
5.  Eliminate the flag gradient attribute $\nabla$ after optimization is complete to avoid affecting rendering speed and storage [S1].

**Parameters**
*   $\epsilon$: The scaling factor for gradients with negative cosine similarity, set to 0.1 [S1].

## Background
Gradient modification in 3D Gaussian Splatting emerged to address specific failure modes of standard differentiable rendering. Standard 3DGS relies on continuous gradients through the rasterizer, which breaks down when Gaussians are "dead" (contributing zero alpha) or when geometric representations involve discontinuities (e.g., Bézier boundaries) [S1]. The concept of truncating gradients for inactive primitives allows for long-range optimization, preventing Gaussians from being trapped in local minima where they cannot see the error signal [S1]. Similarly, gradient flagging was introduced to handle "gradient confusion" caused by imperfect supervision, such as pseudo-views or noisy depth estimates, where standard gradients might point in conflicting directions [S1]. These methods are primarily used in advanced 3DGS training pipelines, particularly for dynamic scenes, sparse-view reconstruction, and high-fidelity avatar reconstruction.
