# StereoGaussians


## Overview
StereoGaussians is a feed-forward method that predicts a metric 3D Gaussian Splatting (3DGS) representation from a single calibrated stereo pair, enabling nearby-view extrapolation without per-scene optimization [S1, unofficial]. It differs from its siblings by freezing a pretrained stereo encoder to extract geometric anchors and features, while a trainable predictor maps these to Gaussian attributes on an expanded image canvas with a dedicated back layer for disoccluded content [S1, unofficial]. Unlike [AnySplat Pipeline](12847-anysplat-pipeline.md) or [Splatt3R](16423-splatt3r.md) which may use different feature aggregation or multi-view inputs, StereoGaussians relies on a single stereo pair and explicit depth anchoring [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A calibrated rectified stereo pair $(I_L, I_R)$, camera intrinsics $K$ (focal lengths $f_x, f_y$, principal point $c_x, c_y$), and baseline $B$ [S1, unofficial].
*   **Output:** A set of $N$ Gaussians $G = \{(x_i, s_i, q_i, \alpha_i, c_i)\}$ in the left-camera frame, where $x_i$ is position, $s_i$ is scale, $q_i$ is rotation, $\alpha_i$ is opacity, and $c_i$ is color [S1, unofficial].

**Data Structures:**
The method predicts two layers of Gaussians (front and back) at every pixel of an expanded canvas.
*   **Canvas:** The input image dimensions $(H, W)$ are extended by padding $P$ on each side to $(H+2P) \times (W+2P)$. The default $P$ is 16 pixels [S1, unofficial].
*   **Gaussian Attributes:** For each layer $\ell \in \{\text{front}, \text{back}\}$, the output branch produces 37 channels per pixel:
    *   Opacity: 1 channel (logit space) [S1, unofficial].
    *   Image-plane offsets: 2 channels $(\delta_{u,\ell}, \delta_{v,\ell})$ [S1, unofficial].
    *   Scale: 3 channels (isotropic base scale + residual) [S1, unofficial].
    *   Rotation: 4 channels (quaternion residual) [S1, unofficial].
    *   Color: 27 channels (degree-2 spherical harmonic coefficients) [S1, unofficial].
*   **Back-layer Depth Offset:** 1 scalar channel [S1, unofficial].

**Algorithm Steps:**

1.  **Stereo Feature Extraction:**
    Pass the stereo pair through a frozen pretrained stereo encoder (e.g., FoundationStereo) to obtain:
    *   Left-reference disparity map $d$.
    *   Aligned multiscale features $\{F_s\}$ [S1, unofficial].
    *   *Note:* For the Fast-FoundationStereo variant, only left-reference image features and RGB-D are used; context and recurrent features are excluded [S1, unofficial].

2.  **Metric Depth Calculation:**
    Compute metric depth $z(p)$ for each pixel $p=(u,v)$ using the horizontal focal length $f_x$ and baseline $B$:
    $$ z(p) = \text{clip}\left( \frac{f_x B}{d(p)}, z_{\min}, z_{\max} \right) $$
    where $z_{\min}$ and $z_{\max}$ are clipping bounds [S1, unofficial].

3.  **Descriptor Generation:**
    Construct a dense full-resolution descriptor $\Phi$ by concatenating features at each scale $s$:
    $$ \Phi = D \left[ \{ F_s, \downarrow_s I_L, \downarrow_s z \}_s \right] \in \mathbb{R}^{C \times H \times W} $$
    where $D$ is a DPT-style decoder, $[ \cdot, \cdot ]$ denotes channel concatenation, and $\downarrow_s$ resizes inputs to scale $s$ (e.g., $H/4 \times W/4$ for $s=4$) [S1, unofficial].
    *   $I_L$ is resized bilinearly; $z$ is resized by nearest-neighbor interpolation [S1, unofficial].
    *   The decoder projects to 128 channels via $1 \times 1$ convolution, group normalization, and GELU [S1, unofficial].

4.  **Canvas Extension:**
    Extend $I_L$, $z$, and $\Phi$ by edge-replication padding $P$ on each side to size $(H+2P) \times (W+2P)$ [S1, unofficial].
    *   Update principal point: $\tilde{c}_x = c_x + P$, $\tilde{c}_y = c_y + P$.
    *   Focal lengths remain unchanged [S1, unofficial].
    *   Let extended inputs be $\tilde{I}_L, \tilde{z}, \tilde{\Phi}$ [S1, unofficial].

5.  **Gaussian Attribute Prediction:**
    Pass extended inputs through a convolutional predictor $H$:
    $$ (\theta_{\text{front}}, \theta_{\text{back}}, \Delta z) = H([\tilde{I}_L, \tilde{z}, \tilde{\Phi}]) $$
    *   **Regressor:** Two $3 \times 3$ convolutions with intermediate GELU map inputs to a 128-channel tensor $h$ [S1, unofficial].
    *   **Output Branches:** Each branch processes $[h, \tilde{I}_L, \tilde{\Phi}]$ using a $3 \times 3$ conv, group norm, GELU, and final $3 \times 3$ conv [S1, unofficial].

6.  **Geometry Construction:**
    *   **Front Layer Depth:** $z_{\text{front}}(p) = \tilde{z}(p)$ [S1, unofficial].
    *   **Back Layer Depth:**
        $$ z_{\text{back}}(p) = \max_{q \in N_9(p)} \tilde{z}(q) + \text{softplus}(\Delta z(p)) $$
        where $N_9(p)$ is a $9 \times 9$ spatial neighborhood [S1, unofficial].
    *   **Centers:** For layer $\ell$, compute image-plane offsets $(\delta_{u,\ell}, \delta_{v,\ell}) = \sigma(o_\ell) - 0.5$, bounded to $\pm 0.5$ canvas pixels. The center is:
        $$ x_\ell(p) = z_\ell(p) \tilde{K}^{-1} [u + \delta_{u,\ell}, v + \delta_{v,\ell}, 1]^\top $$
        where $\tilde{K}$ is the extended canvas intrinsic matrix [S1, unofficial].

7.  **Attribute Composition:**
    *   **Base Scale:** Isotropic base scale $s_{0,\ell} = \kappa z_\ell / (f_x f_y)$ [S1, unofficial].
    *   **Residuals:** Predicted outputs are residuals applied to base attributes:
        *   Scale: Multiplicative update [S1, unofficial].
        *   Rotation: Additive quaternion update [S1, unofficial].
        *   Opacity: Update in logit space [S1, unofficial].
        *   Color: Degree-2 SH residuals around a reference-image DC base [S1, unofficial].

8.  **Rendering:**
    Concatenate front and back layers. Render target views using both layers without an edge mask restricting the back layer [S1, unofficial].

**Pseudocode:**

```python
def stereogaussians_predict(stereo_pair, intrinsics, baseline):
    I_L, I_R = stereo_pair
    f_x, f_y = intrinsics['fx'], intrinsics['fy']
    c_x, c_y = intrinsics['cx'], intrinsics['cy']
    B = baseline
    P = 16  # Default padding
    
    # 1. Stereo Encoding (Frozen)
    disparity = frozen_stereo_encoder(I_L, I_R)
    
    # 2. Metric Depth
    z = clip((f_x * B) / disparity, z_min, z_max)
    
    # 3. Descriptor Generation
    # Resize I_L bilinearly, z nearest-neighbor
    features = []
    for scale in scales:
        F_s = get_encoder_features(scale)
        I_L_down = resize_bilinear(I_L, scale)
        z_down = resize_nearest(z, scale)
        features.append(concat([F_s, I_L_down, z_down]))
    
    descriptor = DPT_decoder(features)
    
    # 4. Canvas Extension
    I_L_ext = pad_edge(I_L, P)
    z_ext = pad_edge(z, P)
    descriptor_ext = pad_edge(descriptor, P)
    
    # Update intrinsics for extended canvas
    c_x_ext = c_x + P
    c_y_ext = c_y + P
    K_ext = { 'fx': f_x, 'fy': f_y, 'cx': c_x_ext, 'cy': c_y_ext }
    
    # 5. Predictor
    h = regressor(concat([I_L_ext, z_ext, descriptor_ext]))
    theta_front = output_branch_front(concat([h, I_L_ext, descriptor_ext]))
    theta_back = output_branch_back(concat([h, I_L_ext, descriptor_ext]))
    delta_z = output_branch_depth_offset(concat([h, I_L_ext, descriptor_ext]))
    
    # 6. Geometry
    z_front = z_ext
    # Back layer depth: local max in 9x9 neighborhood + softplus offset
    z_back = local_max_9x9(z_ext) + softplus(delta_z)
    
    gaussians = []
    for p in pixels:
        # Front Layer
        offsets_f = theta_front[p][:2]
        offsets_f = clip(offsets_f, -0.5, 0.5)
        center_f = z_front[p] * unproject(p + offsets_f, K_ext)
        scale_f = compute_base_scale(z_front[p], f_x, f_y) * theta_front[p][2:5]
        rot_f = quaternion_add_identity(theta_front[p][5:9])
        alpha_f = sigmoid(theta_front[p][9])
        color_f = sh_evaluate_dc(theta_front[p][10:])
        
        # Back Layer
        offsets_b = theta_back[p][:2]
        offsets_b = clip(offsets_b, -0.5, 0.5)
        center_b = z_back[p] * unproject(p + offsets_b, K_ext)
        scale_b = compute_base_scale(z_back[p], f_x, f_y) * theta_back[p][2:5]
        rot_b = quaternion_add_identity(theta_back[p][5:9])
        alpha_b = sigmoid(theta_back[p][9])
        color_b = sh_evaluate_dc(theta_back[p][10:])
        
        gaussians.append(Gaussian(center_f, scale_f, rot_f, alpha_f, color_f))
        gaussians.append(Gaussian(center_b, scale_b, rot_b, alpha_b, color_b))
        
    return gaussians
```

**Parameters:**
*   **Padding $P$:** 16 pixels (default) [S1, unofficial].
*   **Neighborhood $N_9(p)$:** $9 \times 9$ [S1, unofficial].
*   **Optimizer:** AdamW [S1, unofficial].
*   **Learning Rate:** $4 \times 10^{-4}$ [S1, unofficial].
*   **Weight Decay:** 0.01 [S1, unofficial].
*   **Momentum:** $\beta_1=0.9, \beta_2=0.999$ [S1, unofficial].
*   **LR Schedule:** OneCycleLR, 2,700 warm-up steps (9%), initial/final division factors 25/100 [S1, unofficial].
*   **Training Steps:** 30,000 [S1, unofficial].
*   **Loss:** $\mathcal{L} = \text{MSE}(I_T, \hat{I}_T) + 0.05 \cdot \text{LPIPS}_{VGG}(I_T, \hat{I}_T)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Padding:** Without padding, empty bands appear at target-view borders [S1, unofficial].
*   **Depth Errors:** Fixed front-layer depth limits stereo-error correction [S1, unofficial].
*   **Teacher Artifacts:** Artifacts from the training data (3DGS teachers) may persist [S1, unofficial].
*   **Descriptor:** Removing the DPT descriptor causes tabletop distortions and foreground-boundary artifacts [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Feed-forward inference; complexity is dominated by the convolutional predictor $H$ and stereo encoder, both linear in image resolution [S1, unofficial].
*   **Memory Complexity:** Stores two layers of Gaussians per pixel. The descriptor $\Phi$ requires $C \times H \times W$ memory [S1, unofficial].
*   **Performance:** On StereoNVS, achieves 21.261 PSNR, 0.9447 SSIM, 0.0818 LPIPS [S1, unofficial]. On ReplicaGS, achieves 30.266 PSNR, 0.9447 SSIM, 0.0818 LPIPS [S1, unofficial].
*   **Scaling:** Performance degrades without padding (e.g., 3.168 dB PSNR drop on StereoNVS without padding) [S1, unofficial].
*   **Strengths:** No per-scene optimization; handles disocclusion and outside-FoV content via back layer and padding [S1, unofficial].
*   **Limitations:** Fixed front-layer depth; limited to nearby-view extrapolation [S1, unofficial].

## Background
StereoGaussians was introduced in 2026 by authors associated with the "StereoGaussians: Feed-Forward 3D Gaussian Splatting from Stereo Images" paper [S1, unofficial]. It builds on [Feed-forward Generalizable Reconstruction](23168-feed-forward-generalizable-reconstruction.md) and addresses the need for nearby-view extrapolation in stereo-camera applications [S1, unofficial]. It is trained on the SceneSplat-Stereo dataset, which pairs stereo inputs with nearby target views from 803 static scenes [S1, unofficial].
