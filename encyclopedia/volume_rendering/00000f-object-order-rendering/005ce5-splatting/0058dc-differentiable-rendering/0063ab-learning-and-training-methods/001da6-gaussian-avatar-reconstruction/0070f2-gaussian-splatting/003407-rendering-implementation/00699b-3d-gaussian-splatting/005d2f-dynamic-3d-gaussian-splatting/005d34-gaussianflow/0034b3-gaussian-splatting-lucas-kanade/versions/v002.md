# Gaussian Splatting Lucas-Kanade
## Overview
Gaussian Splatting Lucas-Kanade directly applies optical flow estimation to rendered Gaussians to align dynamic objects across frames and improve temporal consistency [S1, unofficial]. It distinguishes itself from its parent method [GaussianFlow](6149-gaussianflow.md), which uses an explicit flow field for temporal regularization, by operating directly on the rendered Gaussian primitives rather than an explicit geometric point cloud or a separate flow MLP [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A sequence of 2D image frames and a set of 3D Gaussians representing the scene [S1, unofficial].
*   **Output:** Temporally consistent 3D Gaussian parameters (position, covariance, opacity, color) aligned across frames [S1, unofficial].

**Data Structures:**
*   **Gaussian Set:** A collection of $N$ Gaussians, each defined by position $\mathbf{p}_i$, covariance matrix $\mathbf{\Sigma}_i$, opacity $\alpha_i$, and spherical harmonics coefficients for color $\mathbf{c}_i$ [G].
*   **Optical Flow Field:** A 2D vector field $\mathbf{u}(x, y)$ representing pixel displacement between frames [G].

**Steps:**
1.  **Render:** Render the current frame using the current set of 3D Gaussians via differentiable rasterization [S1, unofficial].
2.  **Estimate Flow:** Compute the optical flow $\mathbf{u}(x, y)$ between the rendered frame and the target frame using a standard Lucas-Kanade optical flow algorithm or a learned equivalent [S1, unofficial].
3.  **Align Gaussians:** Map the 2D optical flow to 3D space by determining each Gaussian's projected 2D center $\mathbf{c}_i$ and applying the flow vector $\mathbf{u}(\mathbf{c}_i)$ to update the Gaussian's position or adjust its parameters to minimize photometric error [S1, unofficial].
4.  **Update:** Update the Gaussian parameters based on the flow alignment, which may involve translating Gaussian centers or adjusting covariances to account for motion blur or deformation [G].
5.  **Iterate:** Repeat for subsequent frames to maintain temporal consistency [S1, unofficial].

**Formulas:**
*   **Lucas-Kanade Optical Flow:** Solves for $\mathbf{u}$ by minimizing $\sum_{i \in W} \left( I_1(x_i + u_x, y_i + u_y) - I_0(x_i, y_i) \right)^2$, where $I_0, I_1$ are image intensities, $W$ is a window around the pixel, and $\mathbf{u} = (u_x, u_y)$ [G].
*   **Gaussian Update:** The position $\mathbf{p}_i$ is updated by $\Delta \mathbf{p}_i$ derived from the flow [G].

**Parameters:**
*   **Window Size:** For Lucas-Kanade, typically $5 \times 5$ or $7 \times 7$ pixels [G].
*   **Regularization:** Not given in the sources.

**Edge Cases:**
*   **Large Motions:** Standard Lucas-Kanade assumes small motions; large displacements may require pyramidal approaches [G].
*   **Degenerate Input:** Low-texture regions may yield unreliable flow [G].
*   **Occlusions:** Flow estimation may fail in occluded regions [G].

## Subtopics

### [Scene Flow Prior](18519-scene-flow-prior.md)
Scene Flow Prior enhances the temporal consistency of 4D spatio-temporal representations by incorporating a flow Multi-Layer Perceptron (MLP) for motion estimation. It maps spatio-temporal coordinates from $\mathbb{R}^4$ to motion fields in $\mathbb{R}^3$, predicting displacement only between adjacent frames to avoid the difficulty of establishing long-term correspondences in deformable scenes. Unlike its parent method, Gaussian Splatting Lucas-Kanade, which applies optical flow to rendered Gaussians, this method operates on explicit geometric point clouds derived from LiDAR data to impose a motion prior and geometric supervision.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Direct application to Gaussians; improves temporal consistency [S1, unofficial].
*   **Limitations:** Relies on accurate optical flow; may struggle with large motions or occlusions [G].
*   **When to Use:** Dynamic scenes requiring temporal consistency in Gaussian Splatting [G].
*   **When Not to Use:** Scenes with large, unstructured motions or significant occlusions where flow estimation is unreliable [G].

## Background
Gaussian Splatting Lucas-Kanade is a method that directly applies optical flow estimation to the rendered Gaussians, using the flow to align dynamic objects across frames and improve temporal consistency [S1, unofficial]. It builds on the principles of 3D Gaussian Splatting and optical flow estimation [G].
