# Surface-Aware Splat Graph Construction

Also called: Manifold-Aware Gaussian Graph Construction, Surface-Aligned Gaussian Connectivity

## Overview
Surface-Aware Splat Graph Construction establishes connectivity exclusively along the surface manifold by defining adjacency as the geometric intersection of Gaussian kernels, filtering out spurious neighbors that are close in Euclidean space but distant along the underlying surface [S1]. Unlike standard nearest-neighbor graphing which relies on Euclidean or Mahalanobis distances, this method leverages the rank-2 elliptical shape of surface-aligned Gaussians to ensure that links only form between primitives that are proximate along the manifold [S1]. It builds on [Hierarchical, Graph-Based, and Adaptive Structures](17106-hierarchical-graph-based-and-adaptive-structures.md) by introducing a topological structure derived from surface geometry rather than raw point proximity.

## How it works
**Inputs:** A set of $N$ Gaussian kernels $\{G_i\}_{i=1}^N$ reconstructed from 2D images using a surface-aligned Gaussian Splatting method (specifically SpikingGS [S1]).
**Outputs:** A connectivity graph where edges represent surface-aligned intersections between Gaussian kernels.

**Data Structures:**
Each Gaussian kernel $G_i$ is defined by:
*   Position: $\mathbf{p}_i \in \mathbb{R}^3$
*   Covariance: $\mathbf{\Sigma}_i \in \mathbb{R}^{3 \times 3}$, factorized as $\mathbf{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^\top \mathbf{R}_i^\top$
*   Opacity: $\alpha_i \in [0, 1]$
*   Rotation Matrix: $\mathbf{R}_i = [\mathbf{r}_{i,1}, \mathbf{r}_{i,2}, \mathbf{r}_{i,3}]$, where $\mathbf{r}_{i,3}$ is the surface normal direction.
*   Scale Matrix: $\mathbf{S}_i = \text{diag}(\sigma_{i,1}, \sigma_{i,2}, 0)$. The zero third dimension enforces the rank-2 (planar/elliptical) nature of the kernel [S1].

**Parameters:**
*   $c$: Minimum contribution threshold for rendered intensity. Typical value: $1/255$ [S1].
*   $\bar{V}_{ip}$: Activation cut-off threshold from the spiking neuron in SpikingGS. It is a learnable parameter that suppresses low-opacity parts [S1].
*   $\epsilon$: Tolerance for normal-wise offset to account for minor gaps between adjacent Gaussian kernels arising from joint optimization of photometric and geometric objectives [S1].

**Steps:**

1.  **Define Occupancy Region:** For each kernel $G_i$, define the occupancy region $\Omega_i$ as the set of points $\mathbf{x} \in \mathbb{R}^3$ where the kernel is considered active. A point is active if the Gaussian value $G_i(\mathbf{x})$ exceeds the activation cut-off $\bar{V}_{ip}$ AND the rendered intensity $\alpha_i G_i(\mathbf{x})$ exceeds the minimum contribution threshold $c$ [S1].
    $$ \Omega_i = \left\{ \mathbf{x} \in \mathbb{R}^3 \mid G_i(\mathbf{x}) > \max \left( \bar{V}_{ip}, \frac{c}{\alpha_i} \right) \right\} $$
    where $G_i(\mathbf{x}) = \exp\left( -\frac{1}{2} (\mathbf{x} - \mathbf{p}_i)^\top \mathbf{\Sigma}_i^{-1} (\mathbf{x} - \mathbf{p}_i) \right)$ [S1].

2.  **Parameterize Ellipse:** Since $\mathbf{\Sigma}_i$ is rank-2, $\Omega_i$ is an ellipse. Using the scale and rotation matrices, the region is parameterized as:
    $$ \Omega_i = \left\{ \mathbf{p}_i + \lambda_i \rho (\sigma_{i,1} \cos \theta \, \mathbf{r}_{i,1} + \sigma_{i,2} \sin \theta \, \mathbf{r}_{i,2}) \;\middle|\; \rho \in [0, 1), \theta \in (0, 2\pi] \right\} $$
    where the scaling factor $\lambda_i$ is:
    $$ \lambda_i = \sqrt{-2 \max \left( \ln |\bar{V}_{ip}|, \ln \left( \frac{c}{\alpha_i} \right) \right)} $$
    [S1].

3.  **Compute Normal-Wise Offset:** For every pair of kernels $(G_i, G_j)$, compute the normal-wise offset $\delta_{ij}$ from $G_i$ to $G_j$. This is defined as the infimum of the translation distance $t$ along the normal direction $\mathbf{r}_{i,3}$ such that a point in $\Omega_i$ translated by $t \mathbf{r}_{i,3}$ lies in $\Omega_j$:
    $$ \delta_{ij} := \inf \{ |t| \mid \exists \mathbf{x} \in \Omega_i : \mathbf{x} + t \mathbf{r}_{i,3} \in \Omega_j \} $$
    If no such point exists, $\delta_{ij} = +\infty$ [S1].

4.  **Establish Connectivity:** An edge exists between $G_i$ and $G_j$ if $\delta_{ij} < \epsilon$. A zero offset indicates a perfect intersection, while values below $\epsilon$ account for minor gaps due to optimization artifacts [S1].

import numpy as np

def compute_lambda(alpha, c, V_bar_ip):
    """
    Compute the scaling factor lambda_i for a Gaussian kernel.
    
    Args:
        alpha (float): Opacity of the kernel.
        c (float): Minimum contribution threshold (e.g., 1/255).
        V_bar_ip (float): Activation cut-off threshold from SpikingGS.
        
    Returns:
        float: lambda_i value.
    """
    term1 = np.log(np.abs(V_bar_ip))
    term2 = np.log(c / alpha)
    max_val = max(term1, term2)
    # Handle potential numerical issues if max_val is positive (log argument <= 1)
    # The formula assumes arguments to log are < 1, so max_val is negative.
    # If max_val >= 0, the region is empty or invalid in this context.
    if max_val >= 0:
        return 0.0 
    return np.sqrt(-2 * max_val)

def is_intersecting(G_i, G_j, epsilon):
    """
    Determine if two Gaussian kernels intersect along the surface manifold.
    
    Args:
        G_i: Dictionary with keys 'p', 'R', 'S', 'alpha'.
             'p': (3,) position vector.
             'R': (3,3) rotation matrix [r1, r2, r3].
             'S': (2,) scale vector [sigma1, sigma2].
             'alpha': float opacity.

        epsilon (float): Tolerance for normal-wise offset.

        bool: True if kernels intersect (delta_ij < epsilon).
    """
    # Constants
    c = 1.0 / 255.0
    V_bar_ip = G_i.get('V_bar_ip', 0.0) # Assume passed or global
    
    # 1. Compute lambda for G_i
    lambda_i = compute_lambda(G_i['alpha'], c, V_bar_ip)
    
    # 2. Extract geometric components for G_i
    p_i = G_i['p']
    r1_i = G_i['R'][:, 0]
    r2_i = G_i['R'][:, 1]
    r3_i = G_i['R'][:, 2] # Normal direction
    s1_i = G_i['S'][0]
    s2_i = G_i['S'][1]
    
    # 3. Compute normal-wise offset delta_ij
    # delta_ij = inf |t| such that exists x in Omega_i where x + t*r3_i is in Omega_j
    # This requires solving for the intersection of the ellipse Omega_i 
    # projected along r3_i with the ellipse Omega_j.
    # 
    # Simplified geometric check:
    # We project the ellipse Omega_i onto the plane defined by G_j's position 
    # and normal, or vice versa. However, the definition is specific:
    # Translate Omega_i along r3_i until it hits Omega_j.
    #
    # Exact calculation of this infimum is complex. 
    # A robust implementation approximates this by checking if the 
    # closest point on the boundary of Omega_i to the plane of Omega_j 
    # (or vice versa) satisfies the condition.
    #
    # For the purpose of this article, we note that the exact computation 
    # of the infimum over the parametric ellipses is the core algorithmic step.

    return delta_ij < epsilon

    """

    def point_in_ellipse(point, G, c, V_bar_ip):

        p = G['p']
        R = G['R']
        S = G['S']
        alpha = G['alpha']
        
        # Transform point to local space

        local_diff = R.T @ diff
        
        # Check Gaussian value
        sigma1, sigma2 = S[0], S[1]
        # The third dimension should be 0 for rank-2, but we check the 2D projection
        # The formula for G(x) uses the inverse covariance.
        # For rank-2, the inverse is pseudo-inverse or we only check the 2D plane.
        # The source defines Omega_i via the parametric form, which implies the 2D plane.

        threshold = -2 * np.log(max(np.abs(V_bar_ip), c / alpha))
        
        # Check planar constraint (w must be 0 for the ellipse surface)

        # The condition G(x) > threshold_val is equivalent to radial_sq < threshold.

        # Actually, the source says Omega_i is the set where G(x) > max(V, c/alpha).
        # This corresponds to the interior of the ellipse defined by lambda_i.
        
        # So, check if point is within the ellipse boundary
        # The boundary is at radial_sq = threshold / (-2 * log(...))? 
        # Let's stick to the parametric definition.
        # A point is in Omega_i if it can be represented as p_i + lambda_i * rho * (...)
        # This is equivalent to checking if the projected 2D distance is less than lambda_i.
        
        # Local coords of point relative to G's plane
        # We need to project point onto G's plane first?
        # No, the parametric form IS the plane.
        # So we check if the point lies on the plane (w=0) and inside the radius.
        
        if np.abs(w) > 1e-6: # Not on the plane
            return False
            
        # Check radial distance
        # The ellipse semi-axes are lambda_i * s1 and lambda_i * s2
        # So we check (u / (lambda_i * s1))^2 + (v / (lambda_i * s2))^2 < 1
        # But lambda_i depends on G_i, not G_j.
        # Here we are checking if `point` is in Omega_G.
        
        lambda_G = compute_lambda(G['alpha'], c, V_bar_ip)
        s1_G, s2_G = G['S'][0], G['S'][1]
        
        if s1_G == 0 or s2_G == 0:
            return False
            
        norm_u = u / (lambda_G * s1_G)
        norm_v = v / (lambda_G * s2_G)
        
        return (norm_u**2 + norm_v**2) < 1.0

    # We search for t in a range [-T, T]

    # This is a 3D search (t, rho, theta).
    # We can optimize t for fixed (rho, theta) or vice versa.

    # Since an exact solver is not in the source, we use a coarse grid search 
    # to demonstrate the logic, noting that a production implementation would

    best_delta = np.inf

    thetas = np.linspace(0, 2*np.pi, 36)
    rhos = np.linspace(0, 1, 10)
    
    for theta in thetas:
        for rho in rhos:
            # Point on boundary of Omega_i
            x_i = p_i + lambda_i * rho * (s1_i * np.cos(theta) * r1_i + s2_i * np.sin(theta) * r2_i)
            
            # We need to find t such that x_i + t * r3_i is in Omega_j
            # This is a 1D problem: find t such that point_in_ellipse(x_i + t*r3_i, G_j) is True

                # Line is parallel to plane of J.

                    # Project line direction r3_i onto plane of J (it is already in plane if dot=0? No, r3_i is normal of I)

                    # Ellipse in local coords: u^2/a^2 + v^2/b^2 < 1

                    b = lambda_j_Gj * G_j['S'][1]
                    lambda_j_Gj = compute_lambda(G_j['alpha'], c, V_bar_ip)

                    A = (d_local[0]**2 / a**2) + (d_local[1]**2 / b**2)
                    B = 2 * (p_local[0]*d_local[0] / a**2 + p_local[1]*d_local[1] / b**2)
                    C = (p_local[0]**2 / a**2) + (p_local[1]**2 / b**2) - 1
                    
                    if A == 0:
                        # Linear case
                        if B != 0:
                            t_sol = -C / B
                            if C < 0: # Already inside
                                best_delta = min(best_delta, 0)
                            else:
                                best_delta = min(best_delta, np.abs(t_sol))
                    else:
                        disc = B**2 - 4*A*C
                        if disc >= 0:
                            t1 = (-B - np.sqrt(disc)) / (2*A)
                            t2 = (-B + np.sqrt(disc)) / (2*A)
                            # The segment [t1, t2] is inside the ellipse
                            # We want min |t| in this segment

                                best_delta = min(best_delta, 0)
                            else:
                                best_delta = min(best_delta, np.abs(t1), np.abs(t2))
                else:
                    # Parallel but not in plane, no intersection
                    pass
            else:
                # Line intersects plane at a single point

                if point_in_ellipse(intersection_point, G_j, c, V_bar_ip):
                    best_delta = min(best_delta, np.abs(t_plane))
                    
    return best_delta

**Edge Cases and Pitfalls:**
*   **Rank-2 Degeneracy:** The covariance is rank-2, meaning the Gaussian is planar. If the normal vectors of two Gaussians are nearly parallel but they are offset along the normal, the offset calculation is sensitive to the tolerance $\epsilon$ [S1].
*   **Optimization Gaps:** Minor gaps between adjacent Gaussian kernels arise from joint optimization of photometric and geometric objectives. The tolerance $\epsilon$ is critical to account for these gaps; setting it too low may break connectivity, while setting it too high may introduce spurious links [S1].
*   **SpikingGS Dependency:** The method relies on the specific activation cut-off $\bar{V}_{ip}$ from SpikingGS. Using a different surface-aligned GS method requires adapting the definition of $\Omega_i$ accordingly [S1].

## Operating characteristics
*   **Time Complexity:** The graph construction requires checking intersections for all pairs of $N$ Gaussians, leading to $O(N^2)$ pairwise checks. Each check involves solving for the intersection of an ellipse and a line (or plane), which is constant time $O(1)$ but involves square roots and trigonometric functions.
*   **Memory Complexity:** $O(N^2)$ in the worst case for storing the adjacency matrix, though the graph is typically sparse.
*   **Strengths:** It accurately captures surface topology by ignoring Euclidean proximity that does not correspond to surface connectivity. This is superior to standard point-cloud graphing for deformation and editing tasks on complex surfaces [S1].
*   **Limitations:** It is computationally expensive due to the $O(N^2)$ pairwise checks and the complexity of the geometric intersection tests. It is specific to surface-aligned Gaussians (rank-2) and may not generalize directly to volumetric Gaussians without modification [S1].
