# VLM-Augmented Segmentation

Also called: Open-Vocabulary Segmentation via InnerGS

## Overview
This method enables open-vocabulary 3D segmentation by augmenting 3D Gaussians with compact language features distilled from a Vision-Language Model (VLM) [S1, unofficial]. It solves the problem of explicit high-dimensional memory explosion in semantic 3D Gaussian Splatting by using a scene-specific autoencoder to compress VLM embeddings into latent attributes, which are then aggregated via differentiable splatting and decoded for alignment [S1, unofficial]. It differs from [3D Gaussian Splatting with Feature Vectors](8060-3d-gaussian-splatting-with-feature-vectors.md) by specifically targeting language/semantic alignment via VLM distillation rather than generic feature learning, and from [Text Embedding Generation with Directional Views](8239-text-embedding-generation-with-directional-views.md) by operating on per-Gaussian latent attributes rather than view-dependent directional embeddings.

## How it works
**Inputs:**
*   A set of 3D Gaussians $\mathcal{G}$, each defined by position, covariance, opacity $\alpha_i$, and color.
*   A knowledge-enhanced medical VLM (e.g., Zhao et al., 2025) [S1, unofficial].
*   A scene-specific autoencoder (e.g., Qin et al., 2024) [S1, unofficial].
*   A lightweight decoder for projecting latent maps back to semantic space.
*   A camera view $v$.

**Outputs:**
*   A rendered latent map $\mathbf{F}(v)$ for view $v$.
*   Segmentation masks derived from comparing $\mathbf{F}(v)$ against text embeddings.

**Data Structures:**
*   **Gaussian Attribute:** Each Gaussian $i$ stores a compact latent attribute $\mathbf{f}_i$. This is a low-dimensional vector representing the distilled language feature. The exact dimension is not specified in the sources [G: Typically small, e.g., 64-256 dims, but must be consistent with the autoencoder's bottleneck].
*   **Autoencoder:** Compresses high-dimensional VLM embeddings into $\mathbf{f}_i$.
*   **Decoder:** Projects the aggregated 2D latent map $\mathbf{F}(v)$ to the semantic space.

**Steps:**
1.  **Feature Distillation:** For each Gaussian $i$, obtain a high-dimensional embedding from the knowledge-enhanced medical VLM. Distill this embedding into a compact latent attribute $\mathbf{f}_i$ using the scene-specific autoencoder [S1, unofficial].
2.  **Rasterization (Aggregation):** For a given view $v$, identify the set of candidate Gaussians $N$ overlapping the pixel. Sort them front-to-back. Compute the rendered latent map $\mathbf{F}(v)$ using the differentiable splatting equation:
    $$
    \mathbf{F}(v) = \sum_{i \in N} \mathbf{f}_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j)
    $$
    where:
    *   $\mathbf{F}(v)$ is the rendered latent map at view $v$.
    *   $\mathbf{f}_i$ is the compact latent attribute (language feature) for Gaussian $i$.
    *   $\alpha_i$ is the opacity of Gaussian $i$.
    *   $N$ is the set of candidate Gaussians [S1, unofficial].
3.  **Semantic Projection:** Project the rendered latent map $\mathbf{F}(v)$ back to the semantic space using the lightweight decoder [S1, unofficial].
4.  **Open-Vocabulary Alignment:** Compare the projected features against text embeddings corresponding to the query vocabulary to generate segmentation masks [S1, unofficial].

**Pseudocode:**
```python
def render_latent_map(gaussians, camera_view, autoencoder, decoder):
    """
    Renders a latent map for a specific view using VLM-augmented Gaussians.
    
    Args:
        gaussians: List of Gaussian objects. Each has:
            - pos: 3D position
            - cov: 3x3 covariance matrix
            - alpha: opacity (scalar)
            - vlm_embedding: high-dimensional VLM embedding (optional, if not pre-distilled)
            - latent_f: compact latent attribute (if pre-distilled)
        camera_view: Camera parameters (intrinsics, extrinsics)
        autoencoder: Function/model to distill VLM embedding to latent_f
        decoder: Function/model to project latent map to semantic space
        
    Returns:
        semantic_map: 2D tensor of semantic features for the view
    """
    # Step 1: Ensure all Gaussians have compact latent attributes
    for g in gaussians:
        if not hasattr(g, 'latent_f') or g.latent_f is None:
            # Distill high-dimensional VLM embedding into compact latent attribute
            # [G: Implementation detail of autoencoder depends on specific VLM/scene]
            g.latent_f = autoencoder.encode(g.vlm_embedding)
            
    # Step 2: Rasterize
    # Identify overlapping Gaussians for each pixel
    # Sort them front-to-back based on depth along camera view direction
    pixels = get_pixel_grid(camera_view)
    latent_map = zeros_like(pixels, shape=(H, W, latent_dim))
    
    for y in range(H):
        for x in range(W):
            # Get candidate Gaussians overlapping pixel (x, y)
            candidates = get_overlapping_gaussians(gaussians, x, y, camera_view)
            # Sort candidates front-to-back
            candidates.sort(key=lambda g: depth(g.pos, camera_view))
            
            accumulated_transmittance = 1.0
            pixel_latent = zeros(latent_dim)
            
            for g in candidates:
                # Compute alpha contribution
                # [G: Standard 2D Gaussian projection and alpha calculation]
                alpha = compute_alpha(g, camera_view, x, y)
                
                # Accumulate latent feature
                # F(v) = sum(f_i * alpha_i * product(1 - alpha_j))
                pixel_latent += g.latent_f * alpha * accumulated_transmittance
                
                # Update transmittance
                accumulated_transmittance *= (1.0 - alpha)
                
                # Early exit if transmittance is negligible
                if accumulated_transmittance < 1e-6:
                    break
            
            latent_map[y, x] = pixel_latent
            
    # Step 3: Project to semantic space
    semantic_map = decoder.decode(latent_map)
    
    return semantic_map

def segment_open_vocabulary(semantic_map, text_embeddings):
    """
    Segments the scene based on open-vocabulary text queries.
    
    Args:
        semantic_map: 2D tensor of semantic features from decoder
        text_embeddings: Dictionary or tensor of text embeddings for query words
        
    Returns:
        segmentation_mask: 2D tensor of class labels
    """
    # Compare semantic_map features against text embeddings
    # [G: Typically cosine similarity or dot product]
    similarities = compute_similarity(semantic_map, text_embeddings)
    # Argmax over text classes to get segmentation mask
    segmentation_mask = argmax(similarities, axis=-1)
    return segmentation_mask
```

**Parameters:**
*   **Autoencoder:** Scene-specific. No fixed hyperparameters given [S1, unofficial].
*   **Decoder:** Lightweight. No fixed hyperparameters given [S1, unofficial].
*   **VLM:** Knowledge-enhanced medical VLM (Zhao et al., 2025) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Memory Explosion:** The method is designed to circumvent the memory explosion of explicit high-dimensional modeling [S1, unofficial]. Using raw high-dimensional VLM embeddings directly in splatting would be prohibitive.
*   **Volumetric Consistency:** The design preserves volumetric consistency [S1, unofficial]. Degenerate Gaussians (e.g., zero opacity) should be handled by standard alpha-blending logic.

## Operating characteristics
*   **Memory Efficiency:** Significantly reduces memory usage compared to explicit high-dimensional modeling by using compact latent attributes [S1, unofficial].
*   **Performance (CT-ORG subset of SAT-DS):**
    *   Mean Dice Similarity Coefficient (mDSC): 88.17% [S1, unofficial]
    *   Mean Intersection-over-Union (mIoU): 83.72% [S1, unofficial]
    *   Pixel Accuracy (PA): 98.97% [S1, unofficial]
    *   Liver DSC: Consistently above 84.62% [S1, unofficial]
*   **Top 5 Slices Performance (CT-ORG):**
    *   Slice 32: PA 99.42%, mIoU 95.31%, mDSC 99.42%, Liver DSC 98.18% [S1, unofficial]
    *   Slice 70: PA 98.81%, mIoU 94.32%, mDSC 98.81%, Liver DSC 97.13% [S1, unofficial]
    *   Slice 29: PA 99.20%, mIoU 99.20%, mDSC 99.20%, Liver DSC 96.26% [S1, unofficial]
    *   Slice 65: PA 98.62%, mIoU 98.62%, mDSC 98.62%, Liver DSC 97.40% [S1, unofficial]
    *   Slice 30: PA 99.16%, mIoU 99.16%, mDSC 99.16%, Liver DSC 94.67% [S1, unofficial]
    *   Note: Some slices in the source table list "Others DSC" instead of "Liver DSC" for certain rows, but the primary metrics are consistent [S1, unofficial].
*   **Strengths:** Enables precise 3D segmentation of Regions of Interest through open-vocabulary queries; preserves volumetric consistency; computationally efficient [S1, unofficial].
*   **Limitations:** Requires a pre-trained knowledge-enhanced medical VLM and a scene-specific autoencoder; performance is evaluated on medical CT data (CT-ORG), so generalization to other domains is not explicitly stated [S1, unofficial].

## Background
The method is part of the InnerGS framework, introduced in "InnerGS: Internal Scenes Reconstruction and Segmentation via Factorized 3D Gaussian Splatting" [S1, unofficial]. It extends 3D Gaussian Splatting to facilitate multimodal medical scene understanding by integrating Vision-Language Models (VLMs) [S1, unofficial]. The approach builds upon the potential for downstream clinical tasks, specifically targeting open-vocabulary 3D segmentation [S1, unofficial]. The VLM reference is Zhao et al., 2025, and the autoencoder reference is Qin et al., 2024 [S1, unofficial]. The dataset used for evaluation is the CT-ORG subset in SAT-DS, licensed under CC BY 3.0 [S1, unofficial].
