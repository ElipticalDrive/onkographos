# 4D Gaussian Splatting (DreamGaussian4D)

Also called: DreamGaussianHD

## Overview
4D Gaussian Splatting, specifically the DreamGaussian4D method, generates dynamic 4D scenes from a single reference image or video [S1][S2, unofficial]. It differs from sibling methods like AYG by learning motion from a driving video generated by an image-to-video model rather than using a video diffusion prior directly on the scene [S1]. It builds on [3D Gaussian Splatting Rendering (CPU-Sorted, Instanced)](52-3d-gaussian-splatting-rendering.md) by extending the static representation to 4D using HexPlane deformations [S1].

## How it works
The method consists of three main phases: static initialization, dynamic generation, and optional refinement/export [S1][S2, unofficial].

### Inputs and Outputs
- **Input**: A single reference image or video [S1][S2, unofficial].
- **Output**: A dynamic 4D Gaussian Splatting representation, optionally exported as an animated mesh [S1][S2, unofficial].

### Data Structures
1. **Static 3DGS**: Generated via an improved version of DreamGaussian [S2, unofficial]. Contains standard 3D Gaussian attributes (position, covariance, opacity, SH coefficients) [S2, unofficial].
2. **Deformation Field Network**: A network added to the static 3DGS to model temporal deformations [S2, unofficial].
3. **HexPlane**: Used to model Gaussian deformations for realistic motion [S1]. The sources describe the deformation representation as either a HexPlane tensor [S1] or a general deformation field network [S2, unofficial]; both map 4D coordinates to Gaussian offsets.

### Steps

1. **Static Initialization**: Generate a static 3DGS from the reference image using an improved DreamGaussian pipeline [S2, unofficial].
2. **Driving Video Generation**: Use an off-the-shelf Stable Diffusion Video model to generate a driving video from the reference image [S2, unofficial].
3. **Dynamic Generation**:
   - Optimize the deformation field network added to the static 3DGS [S2, unofficial].
   - Use the generated driving video as supervision [S2, unofficial].
   - Apply a 3D SDS loss based on Zero-1-to-3 XL from sampled views to ensure cross-view consistency [S2, unofficial].
   - Randomly select some frames to add image-based SDS to ensure generation quality [S2, unofficial].
   - (Note: [S1] states motion is learned from the driving video generated by the image-to-video model, contrasting with AYG [S1].)
4. **Refinement (Optional)**: Perform video-to-video optimization pipeline to improve temporal coherence [S1].
5. **Export**: Extract a mesh sequence and optimize its texture using an image-to-video diffusion model [S2, unofficial].

### Pseudocode

```python
def dream_gaussian_4d(reference_image):
    # Step 1: Static Initialization
    # Standard 3DGS optimization from single image using diffusion priors [G]
    static_3dgs = optimize_3dgs_from_image(reference_image)

    # Step 2: Driving Video Generation
    # Off-the-shelf image-to-video diffusion model inference [G]
    driving_video = image_to_video_diffusion(reference_image)

    # Step 3: Dynamic Generation
    # Initialize deformation field network (e.g., HexPlane mapping 4D coords to offsets) [G]
    deformation_net = HexPlaneDeformationNetwork()

    MAX_STEPS = 10000
    for step in range(MAX_STEPS):
        # Sample timestamp from driving video
        t = random.uniform(0, 1)
        video_frame = driving_video.sample(t)

        # Apply deformation to static Gaussians
        deformed_gaussians = apply_deformation(static_3dgs, deformation_net, t)

        # Render using standard 4D Gaussian rasterization (delegates to parent method) [G]
        rendered_frame = render_4d_gaussians(deformed_gaussians, camera_pose)

        # Compute 3D SDS loss using Zero-1-to-3 XL from sampled views [S2, unofficial]
        views = sample_camera_views()
        sds_loss_3d = compute_3d_sds_loss(rendered_frame, views, zero1_to_3_xl)

        # Compute image-based SDS loss for randomly selected frames [S2, unofficial]
        sds_loss_img = compute_image_sds_loss(video_frame)

        # Combine and optimize
        total_loss = sds_loss_3d + sds_loss_img
        gradient_descent(deformation_net, total_loss)

    # Step 4: Optional Refinement
    # Video-to-video optimization for temporal coherence [S1]
    refined_gaussians = video_to_video_refinement(deformed_gaussians)

    # Step 5: Export
    # Extract mesh sequence and optimize texture [S2, unofficial]
    mesh_sequence = extract_mesh_sequence(refined_gaussians)
    optimized_mesh = optimize_mesh_texture(mesh_sequence, image_to_video_diffusion)

    return optimized_mesh

# Standard helper implementations [G]
def optimize_3dgs_from_image(ref_img):
    gs = initialize_3dgs(ref_img)
    for step in range(30000):
        cam = sample_camera()
        img = render_3dgs(gs, cam)
        loss = diffusion_sds_loss(img, ref_img)
        optimizer.step(loss)
    return gs

def image_to_video_diffusion(ref_img):
    return diffusion_model.sample(ref_img)

def HexPlaneDeformationNetwork():
    return HexPlaneTensor()

def apply_deformation(gs, net, t):
    for g in gs:
        g.position += net.query(g.position, t)
    return gs

def render_4d_gaussians(gs, cam):
    return rasterize(gs, cam)

def sample_camera_views():
    return [sample_camera() for _ in range(4)]

def compute_3d_sds_loss(rendered, views, model):
    return model.compute_sds(rendered, views)

def compute_image_sds_loss(frame):
    return diffusion_model.compute_sds(frame)

def gradient_descent(net, loss):
    optimizer.step(loss)

def video_to_video_refinement(gs):
    return video_diffusion.refine(gs)

def extract_mesh_sequence(gs):
    return mesh_extractor.extract(gs)

def optimize_mesh_texture(mesh, model):
    return texture_optimizer.optimize(mesh, model)
```

### Parameters and Edge Cases
- **Stable Diffusion Video**: Off-the-shelf model used for driving video generation [S2, unofficial].
- **Zero-1-to-3 XL**: Used for 3D SDS loss [S2, unofficial].
- **Temporal Coherence**: Addressed via optional video-to-video refinement [S1].
- **Degenerate Input**: Not specified in the sources [S1][S2, unofficial].

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Not given in the sources.
- **Strengths**: Generates dynamic 4D scenes from single image/video [S1][S2, unofficial]. Uses HexPlane for realistic motion [S1]. Can export as animated mesh [S1][S2, unofficial].
- **Limitations**: Relies on off-the-shelf diffusion models (Stable Diffusion Video, Zero-1-to-3 XL) which may introduce artifacts [S2, unofficial]. Temporal coherence may require additional refinement [S1].
- **When to use**: When 4D generation from a single image is required [S2, unofficial].
- **When not to use**: When video diffusion prior is preferred over driving video [S1].

## Background
- **Origin**: DreamGaussian4D [15] achieves 4D generation given a reference image [S2, unofficial]. It is based on DreamGaussian [8, 128] for image-to-3D initialization [S1][S2, unofficial].
- **Development**: It utilizes HexPlane [70] to model Gaussian deformations [S1]. It contrasts with AYG [48] by learning motion from a driving video generated by an image-to-video model [S1].
- **Usage**: Used for dynamic 4D scene generation from single images or videos [S1][S2, unofficial].
