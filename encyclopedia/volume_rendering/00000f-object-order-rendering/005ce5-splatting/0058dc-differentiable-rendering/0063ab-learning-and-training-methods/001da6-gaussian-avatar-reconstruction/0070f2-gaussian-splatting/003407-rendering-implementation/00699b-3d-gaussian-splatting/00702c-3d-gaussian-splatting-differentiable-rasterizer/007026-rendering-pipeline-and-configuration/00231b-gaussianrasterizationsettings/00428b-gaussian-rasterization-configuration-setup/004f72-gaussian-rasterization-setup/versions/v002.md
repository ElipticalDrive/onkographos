# Gaussian Rasterization Setup

Also called: Gaussian Renderer Setup, GaussianRasterizer Setup, Rasterization Configuration and Tensor Preparation, render function setup

## Overview
This step prepares the scene data and computational buffers required to invoke the differentiable Gaussian rasterizer [S2, unofficial]. It initializes tensors for gradient accumulation and constructs the configuration object that defines the camera parameters and rendering constraints [S1, S2, unofficial]. It differs from the rasterizer itself by handling the setup of state and memory layout rather than the pixel-wise projection and blending logic [G].

## How it works
### Inputs and Outputs
**Inputs:**
- `pc`: The Gaussian point cloud object containing attributes (e.g., `_xyz`, scales, rotations, SH coefficients) [S1, S2, unofficial].
- `viewpoint_camera`: The current camera object containing field of view (FoV) and position [S1, S2, unofficial].
- `image_width`, `image_height`: The resolution of the target image [S1, S2, unofficial].
- `background`: The background color tensor [S1, S2, unofficial].

**Outputs:**
- `GaussianRasterizationSettings`: An object containing all camera and rendering parameters [S1, S2, unofficial].
- `screenspace_points`: A tensor initialized to zero, used to store gradients for 2D screen-space means [S1, S2, unofficial].

### Data Structures
**GaussianRasterizationSettings**
The settings object aggregates the following fields: `image_width`, `image_height`, `tanfovx`, `tanfovy`, `bg_color`, `scale_modifier`, `viewmatrix`, `projmatrix`, `sh_degree`, `campos`, and implementation-specific parameters [S1, S2, unofficial].

**screenspace_points**
- Shape: Matches the number of Gaussians [S1, S2, unofficial].
- Dtype: Same as `pc.get_xyz`.dtype [S1, S2, unofficial].
- Device: Same as `pc.get_xyz`.device [S1, S2, unofficial].
- Requires Grad: `True` [S1, S2, unofficial].

### Steps
1. **Initialize Gradient Tensor**: Create a zero tensor `screenspace_points` with the same dtype and device as `pc.get_xyz`, requiring gradients [S1, S2, unofficial].
2. **Enable Gradient Retention**: Call `retain_grad()` on `screenspace_points` to allow gradient access during the backward pass [S1, S2, unofficial].
3. **Calculate FOV Tangents**: Compute the tangent of half the field of view for the x and y axes: $$ \text{tanfovx} = \tan\left(\frac{\text{viewpoint\_camera.FoVx}}{2}\right) $$ and $$ \text{tanfovy} = \tan\left(\frac{\text{viewpoint\_camera.FoVy}}{2}\right) $$ [S1, unofficial].
4. **Construct Settings Object**: Instantiate `GaussianRasterizationSettings` with the calculated FOV tangents, image dimensions, background color, scale modifier, view/projection matrices, SH degree, camera position, and other settings [S1, S2, unofficial].

### Pseudocode
```python
import math
import torch

class GaussianRasterizationSettings:
    """Aggregates camera and rendering parameters for the rasterization kernel."""
    def __init__(self, image_width, image_height, tanfovx, tanfovy, bg_color, 
                 scale_modifier, viewmatrix, projmatrix, sh_degree, campos):
        self.image_width = image_width
        self.image_height = image_height
        self.tanfovx = tanfovx
        self.tanfovy = tanfovy
        self.bg_color = bg_color
        self.scale_modifier = scale_modifier
        self.viewmatrix = viewmatrix
        self.projmatrix = projmatrix
        self.sh_degree = sh_degree
        self.campos = campos

def setup_gaussian_rasterization(pc, viewpoint_camera, image_width, image_height, background):
    """
    Prepares tensors and settings for Gaussian rasterization.
    
    Args:
        pc: Gaussian point cloud object with get_xyz property.
        viewpoint_camera: Camera object with FoVx, FoVy, viewmatrix, projmatrix, campos.
        image_width: int, width of the output image.
        image_height: int, height of the output image.
        background: Tensor, background color on GPU.
        
    Returns:
        settings: GaussianRasterizationSettings object.
        screenspace_points: Tensor for 2D mean gradients.
    """
    # Step 1: Initialize screenspace_points tensor
    # Must match dtype and device of 3D positions
    xyz = pc.get_xyz
    screenspace_points = torch.zeros(xyz.shape[0], device=xyz.device, dtype=xyz.dtype, requires_grad=True)
    
    # Step 2: Retain gradients for screenspace_points
    # This allows gradient access during backward pass
    screenspace_points.retain_grad()
    
    # Step 3: Calculate FOV tangents
    tanfovx = math.tan(viewpoint_camera.FoVx * 0.5)
    tanfovy = math.tan(viewpoint_camera.FoVy * 0.5)
    
    # Step 4: Construct GaussianRasterizationSettings
    settings = GaussianRasterizationSettings(
        image_width=image_width,
        image_height=image_height,
        tanfovx=tanfovx,
        tanfovy=tanfovy,
        bg_color=background,
        scale_modifier=1.0,
        viewmatrix=viewpoint_camera.viewmatrix,
        projmatrix=viewpoint_camera.projmatrix,
        sh_degree=pc.sh_degree,
        campos=viewpoint_camera.campos
    )
    
    return settings, screenspace_points
```

### Parameters
- `scale_modifier`: Multiplier for the Gaussian scale. Default is 1.0 [S2, unofficial].
- `bg_color`: Background color tensor, must be on GPU [S2, unofficial].
