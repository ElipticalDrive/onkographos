# Gradient-based Pruning

Also called: Gradient Magnitude Pruning

## Overview
Gradient-based Pruning is a training-time sparsification technique for 3D Gaussian Splatting that removes Gaussians contributing minimally to the optimization process by evaluating the magnitude of their associated gradients [S1]. It distinguishes itself from sibling methods by directly measuring the gradient signal intensity rather than statistical variance or opacity thresholds, allowing for efficient GPU implementation while effectively eliminating visual artifacts like floaters [S1].

## How it works
**Inputs and Outputs:**
- **Input:** The set of active 3D Gaussians $\mathcal{G}$, their parameters (position $\mathbf{t}$, covariance $\mathbf{\Sigma}$, opacity $\alpha$, spherical harmonics coefficients $\mathbf{c}$), and the accumulated gradient magnitudes $\mathbf{g}$ for each Gaussian during the current training phase [S1].
- **Output:** A pruned set of Gaussians $\mathcal{G}' \subset \mathcal{G}$ with redundant entries removed [S1].

**Data Structures:**
- **Gradient Accumulator:** An array of size $|\mathcal{G}|$ storing the cumulative gradient magnitude for each Gaussian [G]. For EfficientGS, this tracks a cumulative sum to halt unnecessary densification [S1]. For Kim et al., it stores separate components for positional and SH gradients [S1].
- **Threshold:** A scalar value $\tau$ determining the minimum gradient magnitude required to retain a Gaussian [G].

**Steps:**
1. **Gradient Accumulation:** During each training iteration, after the backward pass, compute the gradient magnitude for each Gaussian [S1]. For position-based pruning, calculate the Euclidean norm of the positional gradient $\nabla_{\mathbf{t}_i} L$ for Gaussian $i$ [G]. For SH-based pruning (Kim et al.), calculate the norm of the gradient with respect to SH coefficients $\nabla_{\mathbf{c}_i} L$ [S1]. Accumulate these magnitudes over time [S1].
   $$ G_i^{(t)} = G_i^{(t-1)} + \|\nabla_{\mathbf{p}_i} L\| $$
   where $\mathbf{p}_i$ represents the parameters of interest (position or SH) [G].
2. **Thresholding:** Compare the accumulated gradient magnitude $G_i$ against a threshold $\tau$ [G]. If $G_i < \tau$, the Gaussian is marked for removal [G]. The threshold $\tau$ can be static or adaptive based on the distribution of gradient magnitudes in the current batch [G].
3. **Pruning:** Remove all marked Gaussians from the scene representation [S1]. Trimming the Fat and ELMGS apply this to remove 75% of Gaussians while maintaining high visual quality [S1].

**Parameters:**
- **Threshold $\tau$:** Not given in the sources [S1]. Typically determined empirically or via percentile-based selection (e.g., remove bottom 10-25% of Gaussians by gradient magnitude) [G].
- **Accumulation Window:** The number of iterations over which gradients are summed [G]. EfficientGS uses cumulative sums [S1].

**Edge Cases and Pitfalls:**
- **Precision:** Gradient magnitudes can vary significantly across scenes [G]. Normalization or adaptive thresholds are necessary to avoid removing too many or too few Gaussians [G].
- **Degenerate Input:** Gaussians with zero gradient (e.g., occluded or static background) may be pruned prematurely if the threshold is too low [G].
- **SH Gradients:** Incorporating SH gradients alongside positional gradients (Kim et al.) refines the pruning process [S1].

**Pseudocode:**
```python
def gradient_based_pruning(gaussians, accumulated_gradients, threshold):
    """
    Prunes Gaussians with accumulated gradient magnitude below threshold.
    
    Args:
        gaussians: List of Gaussian objects.
        accumulated_gradients: List of floats, cumulative gradient magnitude for each Gaussian.
        threshold: Float, minimum accumulated gradient magnitude to keep a Gaussian.
        
    Returns:
        pruned_gaussians: List of Gaussian objects that survived pruning.
    """
    pruned_gaussians = []
    for i, gaussian in enumerate(gaussians):
        # Step 2: Thresholding
        if accumulated_gradients[i] >= threshold:
            pruned_gaussians.append(gaussian)
        # Step 3: Pruning removes gaussians where accumulated_gradients[i] < threshold
    return pruned_gaussians
```

## Subtopics

### [Utilization-Based Pruning](18426-utilization-based-pruning.md)
Utilization-Based Pruning (UBP) is a training-time sparsification technique for 3D Gaussian Splatting that removes Gaussians with negligible contribution to the rendered image gradient, replacing opacity reset to alleviate interference with residual distribution tracking and compress scene representation. It distinguishes itself from sibling methods by evaluating the gradient of the rendered image with respect to Gaussian positions rather than the loss gradient, allowing for efficient GPU implementation while effectively eliminating visual artifacts like floaters.

## Operating characteristics
- **Time Complexity:** $O(N)$ per iteration for gradient accumulation and pruning, where $N$ is the number of Gaussians [G]. Cumulative sum updates are $O(1)$ per Gaussian per iteration [G].
- **Memory Complexity:** $O(N)$ to store accumulated gradients [G].
- **Measured Performance:** Trimming the Fat and ELMGS remove 75% of Gaussians while maintaining high visual quality [S1].
- **Strengths:** Effective at removing redundant Gaussians and floaters [S1]. Efficient on GPU due to simple magnitude comparisons [G].
- **Limitations:** Requires careful threshold selection [G]. May remove Gaussians that are temporarily occluded but important for later views [G].
- **When to Use:** When computational efficiency is critical and visual quality must be maintained with fewer Gaussians [G].
- **When Not to Use:** When the scene has dynamic elements where temporary occlusion is common, or when SH details are critical and position-only pruning is insufficient [G].

## Background
Gradient-based Pruning originated as a method to improve the efficiency of 3D Gaussian Splatting training by removing Gaussians that contribute minimally to the optimization process [S1]. It has been adopted and extended by several methods, including EfficientGS, GDGS, Trimming the Fat, ELMGS, and Kim et al. [S1]. Kim et al. extended the approach by incorporating SH gradients alongside positional gradients [S1].
