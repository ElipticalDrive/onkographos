# Cross-scale geometric adaptation

Also called: Lgeo, Reprojection error supervision, Reprojection-based cross-scale geometric adaptation

## Overview
Cross-scale geometric adaptation is a self-adaptive regularization method that uses reprojection errors across multiple voxel scales to guide geometry learning without requiring explicit depth ground truth [S1]. It selects render depths with minimal reprojection error across different scales as pseudo-labels, ensuring geometric integrity by adapting to the most suitable geometry for each scale [S1]. It sets itself apart from sibling methods like [Hard and Soft Depth Regularization](9178-hard-and-soft-depth-regularization.md) by avoiding complex scheduling and external priors, instead relying on multi-scale consistency to suppress floaters and improve convergence [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Training views (frames $i$ and $j$), camera intrinsics ($K_i, K_j$), camera poses ($R_i, t_i, R_j, t_j$), multi-scale voxel representations, and rendered depth maps $D_l(p)$ for each scale $l$.
*   **Outputs:** Geometric adaptation loss $L_{geo}$ and pseudo-ground truth depth $D'(r_{train})$ for each training ray $r_{train}$.

**Data Structures:**
*   **Voxels:** Multi-scale voxel grids. Low-resolution voxels capture low-frequency components (coarse geometry), while mid- and high-resolution voxels capture high-frequency details [S1].
*   **Depth Maps:** $D_l(p)$ represents the depth at pixel $p$ for scale $l$, obtained via volume rendering.
*   **RGB Maps:** $C_i$ and $C_j$ are the RGB color maps for frames $i$ and $j$.

**Numbered Steps:**
1.  **Ray Sampling:** For each training ray $r_{train}$, sample a 2D pixel coordinate $p_i$ in frame $i$.
2.  **3D Reprojection to Camera $i$:** Compute the 3D point in the camera coordinate system of frame $i$ using the depth at scale $l$:
    $$ x_{li} = D_l(p_i) K_i^{-1} \tilde{p}_i $$
    where $\tilde{p}_i$ is the homogeneous augmentation of $p_i$ [S1].
3.  **Transform to World Coordinates:** Transform $x_{li}$ to world coordinates $x_l$ using frame $i$'s rotation $R_i$ and translation $t_i$:
    $$ x_l = R_i x_{li} + t_i $$
    [S1]
4.  **Transform to Camera $j$:** Transform the world coordinate point $x_l$ to the camera coordinate system of frame $j$:
    $$ x_{li \to j} = R_j^T (x_l - t_j) $$
    [S1]
5.  **Project to 2D:** Project $x_{li \to j}$ back to the 2D pixel coordinate system of frame $j$:
    $$ \tilde{p}_{li \to j} = \pi(K_j x_{li \to j}) $$
    where $\pi([x, y, z]^T) = [x/z, y/z]^T$ [S1].
6.  **Compute Reprojection Error:** Calculate the error for scale $l$ as the difference between the original RGB pixel and the warped pixel from frame $j$:
    $$ e_l(p_i) = C_i(p_i) - C_j(\tilde{p}_{li \to j}) $$
    [S1]
7.  **Select Pseudo-GT Depth:** Identify the scale $l$ with the minimum reprojection error to serve as the pseudo-ground truth depth $D'(r_{train})$ for the ray:
    $$ D'(r_{train}) = \arg \min_l (e_l(r_{train})) $$
    [S1]
8.  **Compute Loss:** Calculate the geometric adaptation loss $L_{geo}$ as the Mean Squared Error (MSE) between the rendered depth $D_l(r_{train})$ and the selected pseudo-GT depth $D'(r_{train})$ across all training rays:
    $$ L_{geo}(r_{train}) = \sum_{l=0}^{L} \| \hat{D}_l(r_{train}) - D'(r_{train}) \|^2 $$
    [S1]

**Parameters:**
*   **Scales:** Typically three scales are used: Low, Mid, and High resolution [S1].
*   **Loss Weight:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Sparse Views:** In scenarios with significant viewpoint changes or sparse training views (e.g., 360° datasets), the method may face generalization challenges due to reliance on accurate camera poses [S1].
*   **Local Minima:** Omitting novel view rays risks local minima, causing incorrect geometry [S1].
*   **Precision:** The method relies on accurate camera poses; errors in pose estimation can degrade performance [S1].

**Pseudocode:**
```python
def compute_cross_scale_geometric_adaptation_loss(
    frames, # List of frame data: {rgb, depth_maps, K, R, t}
    scales, # List of scale indices: [low, mid, high]
    training_rays # List of rays to process
):
    total_loss = 0.0
    
    for ray in training_rays:
        # Assume ray provides pixel coordinate p_i in frame i
        p_i = ray.pixel_coordinate
        frame_i = frames[ray.frame_id_i]
        frame_j = frames[ray.frame_id_j] # Reference frame for reprojection
        
        # Step 1-3: Reproject to world coordinates for each scale
        world_points = []
        reprojection_errors = []
        
        for l in scales:
            # Get depth at scale l
            D_l = frame_i.depth_maps[l][p_i]
            
            # Homogeneous coordinate
            p_i_hom = [p_i.x, p_i.y, 1.0]
            
            # Inverse intrinsics
            K_inv = inverse(frame_i.K)
            
            # 3D point in camera i coordinates
            x_li = D_l * multiply(K_inv, p_i_hom)
            
            # Transform to world coordinates
            # x_l = R_i * x_li + t_i
            x_l = add(multiply(frame_i.R, x_li), frame_i.t)
            world_points.append(x_l)
            
            # Step 4-5: Transform to camera j and project
            # x_li_to_j = R_j^T * (x_l - t_j)
            x_li_to_j = multiply(transpose(frame_j.R), subtract(x_l, frame_j.t))
            
            # Project to 2D
            # p_li_to_j = pi(K_j * x_li_to_j)
            proj = multiply(frame_j.K, x_li_to_j)
            p_li_to_j = [proj[0]/proj[2], proj[1]/proj[2]]
            
            # Step 6: Compute reprojection error (RGB difference)
            # e_l = C_i(p_i) - C_j(p_li_to_j)
            rgb_i = frame_i.rgb[p_i]
            rgb_j = frame_j.rgb[p_li_to_j]
            error = subtract(rgb_i, rgb_j)
            reprojection_errors.append(error)
            
        # Step 7: Select scale with minimum error
        # D' = argmin_l (e_l)
        min_error_idx = argmin(reprojection_errors)
        pseudo_gt_depth = world_points[min_error_idx].z # Depth in camera j? 
        # Note: The source defines D' as the depth corresponding to the min error scale.
        # The loss compares rendered depth D_l to D'.
        # We need the depth value D' to compare against rendered depths.
        # The source implies D' is the depth from the selected scale's rendering.
        # However, the loss formula uses D_l (rendered) and D' (pseudo-GT).
        # D' is derived from the geometry of the min-error scale.
        # Let's assume D' is the depth value D_min_error from frame i's rendering at that scale.
        pseudo_gt_depth_value = frame_i.depth_maps[min_error_idx][p_i]
        
        # Step 8: Compute Loss
        # L_geo = sum_l || D_l - D' ||^2
        scale_loss = 0.0
        for l in scales:
            D_l_rendered = frame_i.depth_maps[l][p_i]
            diff = subtract(D_l_rendered, pseudo_gt_depth_value)
            scale_loss += square(diff)
            
        total_loss += scale_loss
        
    return total_loss
```

## Operating characteristics
*   **Time Complexity:** Adds overhead for multi-scale reprojection and error computation. Requires rendering depth maps at multiple scales for each training step [S1].
*   **Memory Complexity:** Requires storing depth maps for all scales [S1].
*   **Performance:** Significantly reduces floaters and improves convergence quality across scales compared to training without geometric adaptation [S1]. Provides a stronger and more robust constraint than the depth prior ($L_d$), achieving lower final depth error [S1].
*   **Scaling:** Adapts to diverse scenes [S1].
*   **Strengths:** No complex scheduling required; no external priors needed; robust against geometric noise compared to feature-warping methods like GeCoNeRF [S1].
*   **Limitations:** Relies on accurate camera poses; performance may degrade with very sparse views or large viewpoint changes [S1].

## Background
*   **Origin:** Proposed in FrugalNeRF [S1].
*   **History:** Developed to accelerate and regularize training for extreme few-shot novel view synthesis without learned priors [S1].
*   **Usage:** Used in FrugalNeRF for few-shot NeRF training [S1].
