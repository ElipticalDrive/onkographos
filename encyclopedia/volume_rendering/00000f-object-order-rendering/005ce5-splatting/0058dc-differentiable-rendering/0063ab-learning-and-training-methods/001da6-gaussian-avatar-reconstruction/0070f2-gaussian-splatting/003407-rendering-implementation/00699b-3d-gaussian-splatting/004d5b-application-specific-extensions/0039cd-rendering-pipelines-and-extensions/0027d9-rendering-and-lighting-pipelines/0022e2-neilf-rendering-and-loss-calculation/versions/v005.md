# NeILF Rendering and Loss Calculation

Also called: inverse rendering with Blinn-Phong

## Overview
NeILF (Neural Inverse Lighting Field) is a rendering pipeline that decomposes Gaussian Splatting features into diffuse, specular, and ambient components using a Blinn-Phong model, enabling inverse rendering via loss functions on depth, normals, and color sparsity [S1, unofficial]. It distinguishes itself from standard Gaussian Splatting by explicitly modeling lighting interactions through learnable material factors (diffuse, specular, ambient) and supporting multi-Gaussian group rendering with palette-based color offsets, allowing for physically plausible relighting and material optimization [S1, unofficial].

## How it works

### Steps

1.  **Render Base Features:** Call the standard Gaussian Splatting rendering function `render_view` with the camera and primitives to obtain base features, including depth, normals, and opacity [S1, unofficial].
2.  **Check Training Mode:** If `is_training` is true, proceed to calculate loss; otherwise, return the rendered results [S1, unofficial].
3.  **Apply Light Transforms:** If `light_transform` is not None, apply transformations to the material factors:
    *   `diffuse_factor` = `diffuse_factor` * `light_transform.diffuse_factor` + `light_transform.diffuse_factor_offset` [S1, unofficial].
    *   `shininess` = `shininess` * `light_transform.shininess` + `light_transform.shininess_offset` [S1, unofficial].
    *   `ambient_factor` = `ambient_factor` * `light_transform.ambient_factor` + `light_transform.ambient_factor_offset` [S1, unofficial].
    *   `specular_factor` = `specular_factor` * `light_transform.specular_factor` + `light_transform.specular_factor_offset` [S1, unofficial].
4.  **Compute Offset Color Norm:** Calculate `offset_color_norm` as the sum of squared `offset_color` along the last two dimensions, keeping dimensions: `offset_color_norm = sum(offset_color^2, dim=-1, keepdim=True)` [S1, unofficial].
5.  **Multi-Gaussian Group Rendering:** If `len(num_GSs_TFs) > 1`, iterate through groups:
    *   For each group `i`, set `diffuse_color[start_GS:end_GS]` to `offset_color + palette_colors[i].clamp(0, 1).detach()` [S1, unofficial].
    *   Multiply `opacity` by `opacity_factors[i]` if present [S1, unofficial].
6.  **Compute Diffuse Term:**
    *   Compute `diffuse_intensity` = `diffuse_factor` * `abs(dot(normals, incident_dirs))` [S1, unofficial].
    *   Compute `diffuse_color` = (`ambient_factor` + `diffuse_intensity`) * `diffuse_color` [S1, unofficial].
7.  **Compute Specular Term:**
    *   Compute `h` = normalize(`incident_dirs` + `viewdirs`) [S1, unofficial].
    *   Compute `cos_h` = dot(`normals`, `h`) [S1, unofficial].
    *   Compute `cos_l` = dot(`normals`, `incident_dirs`) [S1, unofficial].
    *   Compute `specular_intensity` = `specular_factor` * `where(cos_l != 0, abs(cos_h)^shininess, 0)` [S1, unofficial].
    *   Compute `specular_color` = `specular_intensity` [S1, unofficial].
8.  **Combine PBR:** Combine PBR as `diffuse_color + specular_color`, clamped to `[0, 1]` [S1, unofficial].
9.  **Calculate Loss:** If `is_training`, compute the total loss based on the following terms:
    *   **Render Loss:** If `lambda_render > 0`, compute L1 and SSIM between `rendered_image` and `gt_image`. `loss = (1 - lambda_dssim) * L1 + lambda_dssim * (1 - SSIM)` [S1, unofficial].
    *   **Phong Loss:** If `lambda_phong > 0`, compute L1 and SSIM between `rendered_phong` and `gt_image`. Add `lambda_phong * ((1 - lambda_dssim) * L1_pbr + lambda_dssim * (1 - SSIM_pbr))` to `loss` [S1, unofficial].
    *   **Depth Loss:** If `lambda_depth > 0`, compute L1 between `rendered_depth` and `gt_depth`, excluding pixels where `image_mask XOR depth_mask` is true [S1, unofficial].
    *   **Opacity Loss:** If `lambda_opacity > 0`, clamp `rendered_opacity` to `[1e-6, 1 - 1e-6]`. Compute L1 and SSIM against `image_mask`. Add weighted sum to `loss` [S1, unofficial].
    *   **Normal Render Depth Loss:** If `lambda_normal_render_depth > 0`, compute MSE between `rendered_normal` and `pseudo_normal` (from results) masked by `image_mask` [S1, unofficial].
    *   **Normal MVS Depth Loss:** If `lambda_normal_mvs_depth > 0` and `MVS_normal` is zero, compute `pseudo_normal` from `gt_depth` using `kornia.depth_to_normals`, transform to world space via `camera.intrinsics` and `world_view_transform`. Compute MSE against `rendered_normal` masked by `depth_mask` [S1, unofficial].
    *   **Offset Color Sparsity Loss:** If `lambda_offset_color_sparsity > 0`, compute sparsity loss on `rendered_offset_color_norm` masked by `image_mask` [S1, unofficial].
    *   **Diffuse Factor Smooth Loss:** If `lambda_diffuse_factor_smooth > 0`, compute bilateral smooth loss on `rendered_diffuse_factor`, `gt_image`, and `image_mask` [S1, unofficial].
    *   **Ambient Factor Smooth Loss:** If `lambda_ambient_factor_smooth > 0`, compute bilateral smooth loss on `rendered_specular_intensity` and `rendered_ambient_intensity` separately, adding to `loss` [S1, unofficial].
    *   **Normal Smooth Loss:** If `lambda_normal_smooth > 0`, compute bilateral smooth loss on `rendered_normal`, `gt_image`, and `image_mask` [S1, unofficial].

import torch
import torch.nn.functional as F

def render_neilf(primitives, camera, light_transform=None, is_training=False, opt=None, 
                 num_GSs_TFs=None, palette_colors=None, opacity_factors=None,
                 gt_image=None, gt_depth=None, image_mask=None, depth_mask=None,
                 MVS_normal=None, sample_num=24):
    """
    NeILF Rendering and Loss Calculation
    
    Args:
        primitives: List of Gaussian primitives with attributes: pos, Sigma, opacity, 
                    diffuse_factor, offset_color, shininess, ambient_factor, specular_factor
        camera: Camera object with attributes: view, intrinsics (fx, fy, cx, cy), W, H, fovy
        light_transform: Dict with keys: diffuse_factor, shininess, ambient_factor, specular_factor, 
                         and corresponding _offset keys
        is_training: Boolean
        opt: Dict with lambda weights
        num_GSs_TFs: List of int, number of Gaussians per group
        palette_colors: List of tensors, palette colors per group
        opacity_factors: List of tensors, opacity factors per group
        gt_image: Ground truth image tensor (H, W, 3)
        gt_depth: Ground truth depth tensor (H, W)
        image_mask: Image mask tensor (H, W)
        depth_mask: Depth mask tensor (H, W)
        MVS_normal: MVS normal map tensor (H, W, 3)
        sample_num: Number of incident rays for normal-based lighting
        
    Returns:
        results: Dict with rendered outputs and loss
    """
    # 1. Render base features using standard Gaussian Splatting
    # This step projects Gaussians, sorts them, and composites color/depth/normal
    # The exact implementation depends on the underlying Gaussian Splatting rasterizer
    # For the purpose of this article, we assume render_view returns a dict with:
    # 'render', 'normal', 'depth', 'opacity', 'viewspace_points', 'visibility_filter', 'radii', etc.
    base_results = render_view(primitives, camera, sample_num=sample_num)
    
    # Extract necessary features
    normals = base_results['normal']
    depth = base_results['depth']
    opacity = base_results['opacity']
    viewspace_points = base_results['viewspace_points']
    
    # 2. Check training mode
    if not is_training:
        return base_results
    
    # 3. Apply light transforms
    if light_transform is not None:
        primitives['diffuse_factor'] = primitives['diffuse_factor'] * light_transform['diffuse_factor'] + light_transform.get('diffuse_factor_offset', 0)
        primitives['shininess'] = primitives['shininess'] * light_transform['shininess'] + light_transform.get('shininess_offset', 0)
        primitives['ambient_factor'] = primitives['ambient_factor'] * light_transform['ambient_factor'] + light_transform.get('ambient_factor_offset', 0)
        primitives['specular_factor'] = primitives['specular_factor'] * light_transform['specular_factor'] + light_transform.get('specular_factor_offset', 0)
    
    # 4. Compute offset color norm
    offset_color_norm = torch.sum(primitives['offset_color'] ** 2, dim=-1, keepdim=True)
    
    # 5. Multi-Gaussian group rendering
    if num_GSs_TFs is not None and len(num_GSs_TFs) > 1:
        start_idx = 0
        for i, num_gs in enumerate(num_GSs_TFs):
            end_idx = start_idx + num_gs
            # Set diffuse_color for this group
            primitives['diffuse_color'][start_idx:end_idx] = primitives['offset_color'][start_idx:end_idx] + palette_colors[i].clamp(0, 1).detach()
            # Multiply opacity by opacity factor
            if opacity_factors is not None and i < len(opacity_factors):
                primitives['opacity'][start_idx:end_idx] *= opacity_factors[i]
            start_idx = end_idx
    
    # 6. Compute Diffuse Term
    # incident_dirs and viewdirs need to be computed from camera and primitive positions
    # For simplicity, assume they are available or computed from viewspace_points
    incident_dirs = compute_incident_dirs(primitives['pos'], camera)
    viewdirs = compute_view_dirs(primitives['pos'], camera)
    
    diffuse_intensity = primitives['diffuse_factor'] * torch.abs(torch.sum(normals * incident_dirs, dim=-1, keepdim=True))
    diffuse_color = (primitives['ambient_factor'] + diffuse_intensity) * primitives['diffuse_color']
    
    # 7. Compute Specular Term
    h = torch.nn.functional.normalize(incident_dirs + viewdirs, dim=-1)
    cos_h = torch.abs(torch.sum(normals * h, dim=-1, keepdim=True))
    cos_l = torch.sum(normals * incident_dirs, dim=-1, keepdim=True)
    
    specular_intensity = primitives['specular_factor'] * torch.where(cos_l != 0, cos_h ** primitives['shininess'], 0.0)
    specular_color = specular_intensity
    
    # 8. Combine PBR
    phong_color = torch.clamp(diffuse_color + specular_color, 0, 1)
    
    # 9. Calculate Loss
    loss = torch.tensor(0.0, device=primitives['diffuse_factor'].device)
    
    # Render Loss
    if opt['lambda_render'] > 0:
        L1_render = F.l1_loss(base_results['render'], gt_image)
        SSIM_render = ssim_loss(base_results['render'], gt_image)
        loss += opt['lambda_render'] * ((1 - opt['lambda_dssim']) * L1_render + opt['lambda_dssim'] * (1 - SSIM_render))
        
    # Phong Loss
    if opt['lambda_phong'] > 0:
        L1_phong = F.l1_loss(phong_color, gt_image)
        SSIM_phong = ssim_loss(phong_color, gt_image)
        loss += opt['lambda_phong'] * ((1 - opt['lambda_dssim']) * L1_phong + opt['lambda_dssim'] * (1 - SSIM_phong))
        
    # Depth Loss
    if opt['lambda_depth'] > 0:
        mask = ~(image_mask ^ depth_mask) # XOR exclusion
        L1_depth = F.l1_loss(depth[mask], gt_depth[mask])
        loss += opt['lambda_depth'] * L1_depth
        
    # Opacity Loss
    if opt['lambda_opacity'] > 0:
        opacity_clamped = torch.clamp(opacity, 1e-6, 1 - 1e-6)
        L1_opacity = F.l1_loss(opacity_clamped, image_mask)
        SSIM_opacity = ssim_loss(opacity_clamped, image_mask)
        loss += opt['lambda_opacity'] * ((1 - opt['lambda_dssim']) * L1_opacity + opt['lambda_dssim'] * (1 - SSIM_opacity))
        
    # Normal Render Depth Loss
    if opt['lambda_normal_render_depth'] > 0:
        pseudo_normal = base_results['pseudo_normal']
        L1_normal = F.mse_loss(normals[image_mask.bool()], pseudo_normal[image_mask.bool()])
        loss += opt['lambda_normal_render_depth'] * L1_normal
        
    # Normal MVS Depth Loss
    if opt['lambda_normal_mvs_depth'] > 0 and torch.all(MVS_normal == 0):
        # Compute pseudo normal from gt_depth
        pseudo_normal_mvs = kornia.depth_to_normals(gt_depth.unsqueeze(0)).squeeze(0)
        # Transform to world space
        pseudo_normal_mvs_world = transform_to_world(pseudo_normal_mvs, camera.intrinsics, camera.view)
        L1_normal_mvs = F.mse_loss(normals[depth_mask.bool()], pseudo_normal_mvs_world[depth_mask.bool()])
        loss += opt['lambda_normal_mvs_depth'] * L1_normal_mvs
        
    # Offset Color Sparsity Loss
    if opt['lambda_offset_color_sparsity'] > 0:
        sparsity_loss = compute_sparsity_loss(offset_color_norm[image_mask.bool()])
        loss += opt['lambda_offset_color_sparsity'] * sparsity_loss
        
    # Diffuse Factor Smooth Loss
    if opt['lambda_diffuse_factor_smooth'] > 0:
        smooth_loss = compute_bilateral_smooth_loss(primitives['diffuse_factor'], gt_image, image_mask)
        loss += opt['lambda_diffuse_factor_smooth'] * smooth_loss
        
    # Ambient Factor Smooth Loss
    if opt['lambda_ambient_factor_smooth'] > 0:
        smooth_loss_spec = compute_bilateral_smooth_loss(specular_intensity, gt_image, image_mask)
        smooth_loss_amb = compute_bilateral_smooth_loss(primitives['ambient_factor'], gt_image, image_mask)
        loss += opt['lambda_ambient_factor_smooth'] * (smooth_loss_spec + smooth_loss_amb)
        
    # Normal Smooth Loss
    if opt['lambda_normal_smooth'] > 0:
        smooth_loss_normal = compute_bilateral_smooth_loss(normals, gt_image, image_mask)
        loss += opt['lambda_normal_smooth'] * smooth_loss_normal
        
    # Update results with loss and phong color
    base_results['phong'] = phong_color
    base_results['loss'] = loss
    return base_results

### Edge Cases and Pitfalls
*   Gaussians with radius 0 or frustum culled are excluded from value updates in splitting criteria via `visibility_filter` (radii > 0) [S1, unofficial].
*   MVS normal map may be all zeros; in this case, pseudo normal is computed from `gt_depth` using `kornia.depth_to_normals` and transformed to world space [S1, unofficial].
*   Precision issues may arise when computing `cos_l != 0` for specular intensity; use a small epsilon if necessary [G].
*   Clamping of colors and opacities is essential to prevent NaN values during optimization [S1, unofficial].

## Operating characteristics

### Time and Memory Complexity
*   **Time Complexity:** Dominated by the Gaussian Splatting rasterization step, which is $O(N)$ where $N$ is the number of Gaussians, plus the cost of computing lighting terms and losses, which is $O(H \times W)$ where $H, W$ are image dimensions [S1, unofficial].
*   **Memory Complexity:** Requires storing additional material factors (diffuse, specular, ambient) per Gaussian, increasing memory usage compared to standard Gaussian Splatting [S1, unofficial].

### Measured Performance
*   Performance depends on the number of Gaussians, image resolution, and the complexity of the loss functions [S1, unofficial].
*   Multi-Gaussian rendering adds overhead proportional to the number of groups [S1, unofficial].

### Scaling
*   Scales with the number of Gaussians and image resolution [S1, unofficial].
*   Parallelization on GPU is effective for rasterization and loss computation [G].

### Strengths and Limitations
*   **Strengths:** Enables inverse rendering and material optimization; supports multi-Gaussian rendering; provides physically plausible lighting [S1, unofficial].
*   **Limitations:** Increased memory usage; more complex loss computation; sensitive to hyperparameters [S1, unofficial].

### When to Use
*   Use when inverse rendering and material optimization are required [S1, unofficial].
*   Use when physically plausible lighting is needed [S1, unofficial].

### When Not to Use
*   Use standard Gaussian Splatting when only rendering is needed without material optimization [S1, unofficial].
*   Use when computational resources are limited [S1, unofficial].
