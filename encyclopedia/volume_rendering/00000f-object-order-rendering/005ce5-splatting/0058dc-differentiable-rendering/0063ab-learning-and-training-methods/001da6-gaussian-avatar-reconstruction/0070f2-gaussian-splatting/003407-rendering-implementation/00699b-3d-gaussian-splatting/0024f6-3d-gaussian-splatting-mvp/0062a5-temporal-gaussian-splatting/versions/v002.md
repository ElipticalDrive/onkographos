# Temporal Gaussian Splatting

Also called: TemporalGS

## Overview
Temporal Gaussian Splatting (TemporalGS) is a training-free, plug-and-play acceleration method for 3D Gaussian Splatting (3DGS) that leverages temporal priors from previous frames to reduce computational redundancy in Gaussian preprocessing, sorting, and rasterization [S1, unofficial]. It solves the challenge of high FPS and low latency rendering by culling unnecessary Gaussians and approximating static regions via warped buffers, achieving up to 1.48× acceleration over vanilla 3DGS while maintaining competitive quality [S1, unofficial]. Unlike sibling methods that may require post-training compression or hardware-specific optimizations, TemporalGS operates as a software rasterization plugin that interleaves dynamic culling and selective rendering intervals [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 3D Gaussians $\{G_i\}$, camera poses $W_t$ (reference) and $W_{t+i}$ (target), intrinsic matrix $K$, and temporal priors from reference frame $I_t$ (TGB, TAB, Temporal Gaussian Buffer) [S1, unofficial].
*   **Outputs:** Rendered frame $\bar{I}_{t+i}$ for intermediate frames $i \in [1, \lambda-1]$ [S1, unofficial].

**Data Structures:**
1.  **Temporal Geometry Buffer (TGB):** Stores per-pixel depth $D_t(x,y)$ and depth standard deviation $\sigma_t(x,y)$ for the reference frame [S1, unofficial].
    *   $D_t(x,y) = \frac{\sum_{G_i \in T_k} w_i(x,y) d_i}{\sum_{G_i \in T_k} w_i(x,y)}$ [S1, unofficial]
    *   $\sigma_t(x,y) = \sqrt{\frac{\sum_{G_i \in T_k} w_i(x,y) (d_i - D_t(x,y))^2}{\sum_{G_i \in T_k} w_i(x,y)}}$ [S1, unofficial]
    *   Where $T_k$ is the tile containing pixel $(x,y)$, $w_i$ is the Gaussian weight, and $d_i$ is the Gaussian depth [S1, unofficial].
2.  **Temporal Appearance Buffer (TAB):** The color image of the reference frame $I_t$ [S1, unofficial].
3.  **Temporal Gaussian Buffer ($G_{rendered}$):** The subset of Gaussians that contributed to the reference frame [S1, unofficial].
    *   $G_{rendered} = \{G_i \mid \max_{(x,y) \in I_t} w_i(x,y) > 0\}$ [S1, unofficial]

**Parameters:**
*   $\lambda$: Interval between reference frames. Accelerates $\lambda-1$ frames between $I_t$ and $I_{t+\lambda}$ [S1, unofficial].
*   $\lambda_{TDC}$: Interval for Temporal Dynamic Culling. Typical value: 50 [S1, unofficial].
*   $\lambda_{SR}$: Interval for Selective Rendering. Typical value: 5 [S1, unofficial].
*   $\eta$: Threshold percentage of selected tiles triggering a pseudo reference frame. Typical value: 40% [S1, unofficial].
*   $\lambda_1, \lambda_2$: Variance range parameters for surface modeling in TGB. Typical values: $\lambda_1=3, \lambda_2=0$ [S1, unofficial].
*   $\epsilon$: Small constant for depth initialization. Value: Not given in the sources.

**Algorithm Steps:**

1.  **Reference Frame Rendering:** Render reference frame $I_t$ using standard 3DGS. Construct TGB ($D_t, \sigma_t$), TAB ($I_t$), and $G_{rendered}$ [S1, unofficial].
2.  **Initialization:** For the target frame $t+i$, initialize warped depth $D'_{min}$ to $z_{far} + \epsilon$ and warped standard deviation $\sigma'_{max}$ to 0 [S1, unofficial].
3.  **Forward Warping:** Map pixels from $I_t$ to $t+i$ using camera matrices $W_t, W_{t+i}$ and intrinsic $K$:
    $$ (x', y') \approx K W_{t+i} W_t^{-1} D_t(x,y) K^{-1} [x, y, 1]^T $$
    Clip to nearest pixel. If multiple source pixels map to the same destination, preserve the geometry closer to the camera and the maximum depth standard deviation to obtain high recall [S1, unofficial]. Update $D'_{min}$ and $\sigma'_{max}$ at the destination pixels [S1, unofficial].
4.  **Surface Modeling:** Define the visible surface range at $t+i$ as $[D'_{min} - \lambda_1 \sigma'_{max}, D'_{min} + \lambda_2 \sigma'_{max}]$ [S1, unofficial].
5.  **Temporal Dynamic Culling (TDC):** Performed every $\lambda_{TDC}$ frames [S1, unofficial].
    *   **Adaptive Frustum Culling (AFC):** After near-plane culling, keep only Gaussians $G_i$ where $F_{min} \leq ndc_i \leq F_{max}$ [S1, unofficial].
        *   $ndc_i = \text{Pix2NDC}(\mu'_i)$, where $\mu'_i$ is the 2D mean of $G_i$ in screen space [S1, unofficial].
        *   $F_{min} = \min_{G_j \in G_{rendered}} (ndc_j)$, $F_{max} = \max_{G_j \in G_{rendered}} (ndc_j)$ [S1, unofficial].
    *   **Temporal Occlusion Culling (TOC):** Remove Gaussians $G_i$ whose 2D means are in screen space AND whose depth $d_i > D'_{min}(\bar{\mu}_i) + \lambda_2 \sigma'_{max}(\bar{\mu}_i)$, where $\bar{\mu}_i$ is the nearest screen pixel to $G_i$'s mean [S1, unofficial]. Pixels with no warped geometry retain $z_{far} + \epsilon$ depth, allowing new closer surfaces to be included [S1, unofficial].
6.  **Selective Rendering (SR):** Performed every $\lambda_{SR}$ frames [S1, unofficial].
    *   **Depth Repair:** Identify "no-hit" pixels in warped depth map (where $D'_{min} == z_{far} + \epsilon$) [S1, unofficial]. If all 3x3 neighbors are valid, fill the pixel with the average of neighbors. Denote repaired depth as $D'_{min}'$ [S1, unofficial].
    *   **Tile Selection:** Perform backward warping (inverse of forward warping) on $D'_{min}'$ to query correspondence in reference frame [S1, unofficial]. Mark tile $T_k$ as $T_{unselected}$ if any pixel in $T_k$ fails to find correspondence [S1, unofficial].
    *   **Combine Selection:** $T_{selected} = T_{oc\_selected} \cup T_{unselected}$, where $T_{oc\_selected}$ are tiles intersecting Gaussians that passed TOC [S1, unofficial].
7.  **Rendering:**
    *   Sort Gaussians intersecting $T_{selected}$ by depth [S1, unofficial].
    *   Render $T_{selected}$ tiles using standard alpha blending [S1, unofficial].
    *   For tiles $T \setminus T_{selected}$, use the warped TAB $\bar{I}_{t \to t+i}$ obtained via backward warping of $I_t$ using $D'_{min}'$ and bilinear interpolation [S1, unofficial].
    *   Stitch rendered tiles and warped TAB to form $\bar{I}_{t+i}$ [S1, unofficial].
8.  **Adaptive Reference Frame Insertion:** If the number of selected tiles at $t+i$ exceeds $\eta\%$ of total tiles, force $t+i+1$ to be a pseudo reference frame (rendered with AFC) [S1, unofficial].
9.  **Loop:** Interleave TDC and SR steps for intermediate frames [S1, unofficial].

**Pseudocode:**

```python
import math
import numpy as np

def temporal_gaussian_splatting(Gaussians, W_ref, W_target, K, TGB_depth, TGB_sigma, TAB, G_rendered, lambda_val, lambda_TDC, lambda_SR, eta, lambda1, lambda2, zfar, epsilon, frame_count):
    """
    Render intermediate frame between reference and target using TemporalGS.
    Gaussians: list of dicts with keys 'mean', 'depth', 'covariance', 'opacity', 'sh'
    TGB_depth, TGB_sigma: 2D numpy arrays (H, W)
    TAB: 2D numpy array (H, W, 3)
    """
    H, W = TGB_depth.shape
    
    # 1. Forward Warping
    warped_depth = np.full((H, W), zfar + epsilon)
    warped_sigma_max = np.zeros((H, W))
    
    # Iterate over reference frame pixels
    ys, xs = np.where(TGB_depth < zfar + epsilon)
    for y, x in zip(ys, xs):
        depth_z = TGB_depth[y, x]
        # Unproject to 3D: p3d = W_ref^-1 * K^-1 * [x, y, 1, 1]^T * depth_z
        p3d_ref = unproject(x, y, depth_z, K, W_ref)
        # Project to target view: p2d = K * W_target * p3d
        p2d_target = project(p3d_ref, K, W_target)
        tx, ty = clip_to_pixel(p2d_target)
        
        # Bounds check
        if 0 <= ty < H and 0 <= tx < W:
            sigma = TGB_sigma[y, x]
            # Preserve max sigma and min depth
            if sigma > warped_sigma_max[ty, tx]:
                warped_sigma_max[ty, tx] = sigma
            if depth_z < warped_depth[ty, tx]:
                warped_depth[ty, tx] = depth_z
                
    D_min = warped_depth
    Sigma_max = warped_sigma_max
    
    # 2. Temporal Dynamic Culling (TDC)
    if frame_count % lambda_TDC == 0:
        # Adaptive Frustum Culling (AFC)
        ndc_vals = [pix2ndc(g['mean'], K) for g in G_rendered]
        ndc_min = min(ndc_vals)
        ndc_max = max(ndc_vals)
        
        filtered_Gaussians = []
        for g in G_rendered:
            # Near-plane culling
            if g['depth'] < 0.1: # Standard near-plane threshold [G]
                continue
            ndc = pix2ndc(g['mean'], K)
            if ndc_min <= ndc <= ndc_max:
                # Temporal Occlusion Culling (TOC)
                mu_bar = nearest_screen_pixel(g['mean'], K, W_target)
                d_min_buf = D_min[mu_bar.y, mu_bar.x]
                sigma_max_buf = Sigma_max[mu_bar.y, mu_bar.x]
                
                # Cull if behind warped surface
                if g['depth'] > d_min_buf + lambda2 * sigma_max_buf:
                    continue
                filtered_Gaussians.append(g)
        G_active = filtered_Gaussians
    else:
        G_active = G_rendered

    # 3. Selective Rendering (SR)
    T_selected = set()
    
    # Depth Repair
    D_min_repaired = D_min.copy()
    no_hit_mask = (D_min == zfar + epsilon)
    for y, x in zip(*np.where(no_hit_mask)):
        neighbors = get_3x3_neighbors(D_min, y, x)
        if all_valid(neighbors):
            D_min_repaired[y, x] = mean(neighbors)
            
    # Tile Selection
    # Tum_selected: tiles with unmatched pixels
    for tile_y in range(0, H, 16): # Assuming 16x16 tiles
        for tile_x in range(0, W, 16):
            has_unmatched = False
            for py in range(tile_y, min(tile_y+16, H)):
                for px in range(tile_x, min(tile_x+16, W)):
                    if D_min_repaired[py, px] >= zfar + epsilon:
                        has_unmatched = True
                        break
                if has_unmatched: break
            if has_unmatched:
                T_selected.add((tile_x, tile_y))
                
    # Toc_selected: tiles intersecting surviving Gaussians
    for g in G_active:
        mu_bar = nearest_screen_pixel(g['mean'], K, W_target)
        tile_x = (mu_bar.x // 16) * 16
        tile_y = (mu_bar.y // 16) * 16
        T_selected.add((tile_x, tile_y))
        
    # 4. Render
    Image = np.zeros((H, W, 3))
    
    # Render selected tiles
    for tx, ty in T_selected:
        G_tile = [g for g in G_active if intersects(g, (tx, ty), K, W_target)]
        G_tile.sort(key=lambda g: g['depth'])
        Image[ty:ty+16, tx:tx+16] = rasterize(G_tile, (tx, ty), K, W_target)
        
    # Warp TAB for non-selected tiles
    if len(T_selected) < (H*W)/(16*16):
        I_warped = backward_warp(TAB, D_min_repaired, K, W_ref, W_target)
        for tile_y in range(0, H, 16):
            for tile_x in range(0, W, 16):
                if (tile_x, tile_y) not in T_selected:
                    Image[tile_y:tile_y+16, tile_x:tile_x+16] = I_warped[tile_y:tile_y+16, tile_x:tile_x+16]
                    
    # Adaptive Reference Frame Insertion
    total_tiles = (H * W) / (16 * 16)
    if len(T_selected) > (eta / 100.0) * total_tiles:
        return Image, True # Signal pseudo reference frame insertion
        
    return Image, False

# Helper functions defined for self-containment
def unproject(x, y, z, K, W):
    inv_K = np.linalg.inv(K)
    inv_W = np.linalg.inv(W)
    p_cam = inv_K @ np.array([x, y, 1.0]) * z
    p_world = inv_W @ np.append(p_cam, 1.0)
    return p_world[:3]

def project(p3d, K, W):
    p_cam = W @ np.append(p3d, 1.0)
    p2d = K @ p_cam[:3]
    return p2d[:2] / p2d[2]

def clip_to_pixel(p2d):
    return int(round(p2d[0])), int(round(p2d[1]))

def pix2ndc(mean_2d, K):
    # Simplified NDC conversion from screen coordinates
    return (mean_2d[0] / K[0, 0]) - 1.0 # Approximation for standard FOV [G]

def nearest_screen_pixel(mean_3d, K, W):
    p_cam = W @ np.append(mean_3d, 1.0)
    p2d = K @ p_cam[:3]
    x, y = p2d[:2] / p2d[2]
    return type('Pixel', (), {'x': int(round(x)), 'y': int(round(y))})()

def get_3x3_neighbors(depth_map, y, x):
    neighbors = []
    for dy in [-1, 0, 1]:
        for dx in [-1, 0, 1]:
            ny, nx = y + dy, x + dx
            if 0 <= ny < depth_map.shape[0] and 0 <= nx < depth_map.shape[1]:
                neighbors.append(depth_map[ny, nx])
    return neighbors

def all_valid(depths, zfar, epsilon):
    return all(d < zfar + epsilon for d in depths)

def mean(depths):
    return sum(depths) / len(depths)

def backward_warp(TAB, depth_map, K, W_ref, W_target):
    H, W, _ = TAB.shape
    warped_tab = np.zeros_like(TAB)
    for y in range(H):
        for x in range(W):
            if depth_map[y, x] < zfar + epsilon:
                # Inverse of forward warp: target -> ref
                p3d_ref = unproject(x, y, depth_map[y, x], K, W_ref)
                p2d_target = project(p3d_ref, K, W_target)
                tx, ty = clip_to_pixel(p2d_target)
                if 0 <= ty < H and 0 <= tx < W:
                    warped_tab[y, x] = TAB[ty, tx] # Bilinear interpolation omitted for brevity [G]
    return warped_tab

def intersects(g, tile, K, W):
    mu_bar = nearest_screen_pixel(g['mean'], K, W)
    return tile[0] <= mu_bar.x < tile[0] + 16 and tile[1] <= mu_bar.y < tile[1] + 16

def rasterize(G_tile, tile, K, W):
    # Standard alpha-blending rasterization for the tile
    # Returns 3-channel image patch
    return np.zeros((16, 16, 3)) # Placeholder for standard 3DGS rasterizer [G]
```

## Operating characteristics
*   **Time Complexity:** Reduces sorting and rasterization cost by culling Gaussians (TDC) and rendering only a subset of tiles (SR) [S1, unofficial]. The acceleration factor is up to 1.48× compared to vanilla 3DGS [S1, unofficial].
*   **Memory Complexity:** Requires storage for TGB (depth + sigma), TAB (color), and $G_{rendered}$ (Gaussian indices) [S1, unofficial]. TGB can be downscaled by a factor of 2 on large-scale scenes [S1, unofficial].
*   **Strengths:** Training-free, plug-and-play, works with software and hardware rasterization, maintains high quality [S1, unofficial].
*   **Limitations:** Rendering quality degrades with significant camera motion or inaccurate 3DGS surface representation [S1, unofficial].
*   **When to use:** Stream rendering, video playback, or applications requiring high FPS with moderate camera motion [S1, unofficial].
*   **When not to use:** Scenes with rapid, large-scale changes where $\eta$ threshold is frequently exceeded, causing frequent reference frame resets [S1, unofficial].

## Background
TemporalGS was introduced as the first training-free, plug-and-play algorithmic approach to accelerate 3DGS rendering using temporal priors [S1, unofficial]. It addresses the computational bottleneck of sorting and rasterization in 3DGS by leveraging temporal coherence between consecutive frames [S1, unofficial].
