# FineSplat

Also called: Detailed Splats, Fine Patches, Local Groups

## Overview
FineSplat is a feed-forward 3D Gaussian Splatting (3DGS) framework that predicts a set of 3D Gaussians from $N$ context views (with or without known poses) using a two-stage dual-grouping strategy to balance local detail preservation with global multi-view reasoning [S1, unofficial]. It distinguishes itself from sibling methods like [YoNoSplat](9436-textured-gs.md) and [ZipSplat](12847-anysplat-pipeline.md) by employing high-resolution 4x4 patch tokens and a dual-grouping strategy (view-wise and 3D spatial locality) to preserve fine-grained visual information while avoiding the prohibitive costs of global multi-view attention [S1, unofficial].

## How it works
**Inputs:** $N$ context views $I \in \mathbb{R}^{N \times H \times W \times 3}$ with known or unknown camera poses.
**Outputs:** A set of 3D Gaussian primitives (centers, covariances, opacities, spherical harmonics coefficients) representing the scene.

### Data Structures
1.  **Tokens ($z$):** A set of $M$ fine-grained tokens, where $M = N \cdot \frac{H}{p} \cdot \frac{W}{p}$. Each token has dimension $d$.
2.  **Gaussian Primitives:** Predicted per token. Each token predicts $K$ Gaussians.
3.  **Error Feature Maps ($F^{err}$):** For each view $n$, a feature map of size $\frac{H}{p} \times \frac{W}{p} \times d_e$.

### Parameters
*   $p$: Patch size. Default: 4x4 pixels [S1, unofficial].
*   $T$: Number of iterative refinement steps in Stage 2. Default: 4 [S1, unofficial].
*   $K$: Number of Gaussian primitives predicted per token.
*   $S$: Size of groups for serialized attention in 3D spatial grouping.
*   $s$: Sub-patch stride. Default: 2 (for 4x4 tokens divided into 2x2 sub-patches) [S1, unofficial].
*   $N$: Number of input context views. Training samples $N \in \{6, 12, 24, 32\}$ [S1, unofficial].

### Algorithm

#### Stage 1: View-Wise Token Grouping
1.  **Feature Extraction:** Extract multi-scale feature maps $F^l$ for $l \in \{1, 2, 3\}$ (finest to coarsest) from the input images using a backbone (e.g., MVP architecture).
2.  **Token Initialization:** Fuse features to create initial tokens $z^{(0)}$:
    $$ z^{(0)} = \text{fuse}\left(\text{up}\left(\text{fuse}\left(\text{up}(F^3) + F^2\right)\right)\right) + F^1 $$
    where $\text{up}(\cdot)$ is bilinear upsampling and $\text{fuse}(\cdot)$ is a convolutional fusion block [S1, unofficial].
3.  **Group-Wise Attention:** Encode tokens using view-wise token grouping. This performs fine-grained attention within small view groups and exchanges information across all views via coarser global tokens, restricting attention scope to keep computation affordable [S1, unofficial].

#### Stage 2: 3D Spatial Token Grouping (Iterative Refinement)
Repeat for $t = 1$ to $T$:

1.  **Gaussian Prediction:** Decode tokens $z^{(t-1)}$ into an initial set of Gaussians using a lightweight Gaussian head $\mathcal{D}$ (linear decoder). Each token predicts $K$ Gaussians.
2.  **Patch-Aligned Sub-Pixel Gaussian Reconstruction:**
    *   For each 4x4 token, predict 4 Gaussians, assigning each to a non-overlapping 2x2 sub-patch.
    *   Learn a 2D image-space offset $\Delta = (\Delta_x, \Delta_y)$.
    *   Bound the offset to keep Gaussians within their sub-patch:
        $$ \delta_x = 2s \tanh(\Delta_x), \quad \delta_y = 2s \tanh(\Delta_y) $$
        where $s=2$. This ensures $\delta_x, \delta_y \in [-s/2, s/2]$ [S1, unofficial].
    *   For a sub-patch with center $(u_c, v_c)$, compute displaced coordinate $(u, v) = (u_c, v_c) + \delta$.
    *   **Ray Unprojection:** Unproject $(u, v)$ using predicted camera intrinsics. Transform and normalize direction using camera-to-world rotation, using camera translation as ray origin [S1, unofficial].
3.  **Rendering:** Render the predicted Gaussians into every context view to obtain rendered images $\hat{I}_n$.
4.  **Error Feature Computation:**
    *   Compute signed pixel error map: $E_n = \hat{I}_n - I_n$.
    *   Compute feature-level difference: $\Delta\phi_n = \phi(\hat{I}_n) - \phi(I_n)$, where $\phi(\cdot)$ is a pretrained ResNet-18 encoder [S1, unofficial].
    *   Combine with finest-scale features $F_n^1$ from Stage 1:
        $$ F_n^{err} = [\mathcal{E}_{err}(E_n, \Delta\phi_n); \mathcal{E}_{feat}(F_n^1)] \in \mathbb{R}^{\frac{H}{p} \times \frac{W}{p} \times d_e} $$
        where $\mathcal{E}_{err}$ and $\mathcal{E}_{feat}$ are linear embedding layers, and $[\cdot; \cdot]$ is concatenation [S1, unofficial].
5.  **Error Aggregation:** For each token, gather two error signals:
    *   $e_{self}$: Error feature from the patch where the token is predicted.
    *   $e_{agg}$: Aggregated error feature averaged over all context views where the token is visible (projected onto error feature maps and filtered by frustum/occlusion) [S1, unofficial].
6.  **3D Spatial Grouping:**
    *   Lift tokens to 3D space using predicted Gaussian centers.
    *   Order points along a space-filling curve.
    *   Partition into groups of $S$ consecutive points.
    *   Apply serialized self-attention within each group. Use four attention blocks, each using a different space-filling curve, so each token meets a different set of neighbors [S1, unofficial].
    *   Update tokens:
        $$ \Delta z_j^{(t)} = \text{Linear}(\text{SerialAttn}(h_j^{(t)})) $$
        $$ z_j^{(t)} = z_j^{(t-1)} + \Delta z_j^{(t)} $$
        where $h_j^{(t)}$ incorporates the self and aggregated error features [S1, unofficial].

### Edge Cases and Pitfalls
*   **Blind Spots:** Fixed view grouping in Stage 1 leaves blind spots where fine-grained tokens in different groups cannot interact. Stage 2 3D spatial grouping connects tokens across view groups once lifted to 3D [S1, unofficial].
*   **Scale Ambiguity:** Feed-forward reconstruction is scale-ambiguous. Handle by normalizing scene scale using context camera poses: express poses in the mean context camera frame and rescale translations so all context camera centers lie within $[-1, 1]^3$. Apply the same transform to target poses [S1, unofficial].
*   **Step Count:** Quality improves gradually with more Stage 2 steps, but going beyond $T=4$ yields no further gain [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Faster than global attention methods. Stage 1 uses group-wise attention, and Stage 2 uses serialized attention with space-filling curves, which scales favorably with token count compared to k-NN search [S1, unofficial].
*   **Memory Complexity:** Depends on the number of tokens $M$ and Gaussians. Uses 62K Gaussians for DL3DV with 6 views, 75K for RE10K with 6 views, and 1.6M for Mip-NeRF 360 with 128 views [S1, unofficial].
*   **Performance:**
    *   DL3DV (6 views): 27.325 PSNR, 0.871 SSIM, 0.115 LPIPS [S1, unofficial].
    *   RE10K (6 views): 27.394 PSNR, 0.886 SSIM, 0.116 LPIPS [S1, unofficial].
    *   Mip-NeRF 360 (128 views): 23.463 PSNR, 0.706 SSIM, 0.214 LPIPS [S1, unofficial].
*   **Strengths:** High quality with fine-grained details; efficient due to dual-grouping; robust to scale ambiguity via normalization.
*   **Limitations:** Requires careful tuning of Stage 2 steps (optimal at 4); performance may degrade if view groups are too small without sufficient 3D interaction.

## Background
FineSplat was introduced in 2026 by [S1, unofficial]. It addresses the limitations of global multi-view attention in feed-forward 3DGS by introducing a dual-grouping strategy. It is trained on the DL3DV dataset and evaluated on DL3DV, RealEstate10K, and Mip-NeRF 360 for novel view synthesis [S1, unofficial].
