# Splatt3R

Also called: Splatt3R: Zero-Shot Gaussian Splatting from Uncalibrated Image Pairs

## Overview
Splatt3R is a feed-forward method that predicts 3D Gaussian Splat parameters directly from a pair of uncalibrated natural images, without requiring camera intrinsics, extrinsics, or depth information [S1, unofficial]. It extends the MASt3R foundation model by adding a Gaussian prediction head, enabling novel view synthesis and 3D reconstruction in a single forward pass [S1, unofficial]. Unlike other generalizable 3D-GS methods that are limited to interpolating viewpoints between input stereo views, Splatt3R supports extrapolation to wider baselines by employing a novel loss masking strategy based on frustum culling and covisibility testing [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Two uncalibrated RGB images $I_1, I_2 \in \mathbb{R}^{H \times W \times 3}$ with resolution $512 \times 512$ [S1, unofficial].
*   **Output:** A set of 3D Gaussian primitives $\mathcal{G}$, defined by mean position $\mu$, covariance $\Sigma$, opacity $\alpha$, and color $c$ (or spherical harmonics $S$) for each pixel in the input images [S1, unofficial].

**Data Structures:**
The method predicts per-pixel Gaussian parameters. For each pixel $j$, the network outputs:
*   Base position $x_j \in \mathbb{R}^3$ (from MASt3R backbone).
*   Position offset $\Delta x_j \in \mathbb{R}^3$.
*   Rotation quaternion $q_j \in \mathbb{R}^4$.
*   Scale $s_j \in \mathbb{R}^3$.
*   Opacity $\alpha_j \in \mathbb{R}$.
*   Color $c_j \in \mathbb{R}^3$ (constant view-independent color) or Spherical Harmonics coefficients [S1, unofficial].

**Algorithm Steps:**

1.  **Feature Encoding:** Encode the two input images $I_1, I_2$ using a shared Vision Transformer (ViT) encoder and cross-attention transformers. This backbone is based on MASt3R and is frozen during training [S1, unofficial].
2.  **Point Cloud Prediction:** Predict 3D point locations $\hat{X}_1, \hat{X}_2$ and confidence maps $C_1, C_2$ in the coordinate frame of the first image using the frozen MASt3R backbone [S1, unofficial].
3.  **Gaussian Parameter Prediction:** Use a parallel "Gaussian head" (based on the DPT architecture) to predict offsets $\Delta$, rotations $q$, scales $s$, opacities $\alpha$, and spherical harmonics $S$ for each pixel [S1, unofficial].
    *   The mean position $\mu_j$ is calculated as:
        $$ \mu_j = x_j + \Delta x_j $$
        where $x_j$ is the base position predicted by MASt3R and $\Delta x_j$ is the predicted offset [S1, unofficial].
    *   The covariance matrix $\Sigma_j$ is reparameterized using the rotation quaternion $q_j$ and scale $s_j$ to ensure positive semi-definiteness:
        $$ \Sigma_j = R(q_j) S(s_j) S(s_j)^T R(q_j)^T $$
        where $R(q_j)$ is the rotation matrix derived from the quaternion and $S(s_j)$ is the diagonal scale matrix [S1, unofficial].
    *   Activation functions are applied: normalization for quaternions, exponential for scales and offsets, and sigmoid for opacities [S1, unofficial].
4.  **Primitive Construction:** Construct the final set of Gaussian primitives as the union of primitives predicted from both input images $I_1$ and $I_2$ [S1, unofficial].
5.  **Rendering:** Render the predicted Gaussians into target views using differentiable rasterization [S1, unofficial].
6.  **Loss Masking (Training Only):** Calculate a loss mask $M$ to restrict supervision to feasibly reconstructed regions. For each target image point, unproject it and reproject it onto context images. A pixel is included in the mask if:
    *   It is inside the frustum of at least one context view.
    *   Its reprojected depth matches the ground truth depth.
    *   It is a valid pixel with valid depth in the dataset [S1, unofficial].
7.  **Loss Calculation:** Compute the total loss $L$ as a weighted sum of masked MSE and LPIPS losses:
    $$ L = \lambda_{MSE} L_{MSE}(M \odot \hat{I}, M \odot I) + \lambda_{LPIPS} L_{LPIPS}(M \odot \hat{I}, M \odot I) $$
    where $\hat{I}$ is the rendered image, $I$ is the ground truth target image, and $\odot$ denotes element-wise multiplication [S1, unofficial].

**Pseudocode:**

```python
def splatt3r_forward(I1, I2, backbone, gaussian_head):
    """
    Forward pass of Splatt3R.
    I1, I2: Input images (H, W, 3)
    backbone: Frozen MASt3R encoder/decoder
    gaussian_head: DPT-based Gaussian prediction head
    Returns: List of Gaussian primitives (mu, sigma, alpha, color)
    """
    # 1. Encode images using frozen MASt3R backbone
    features = backbone.encode(I1, I2)
    
    # 2. Predict base 3D points and confidences in I1's frame
    x1, c1 = backbone.point_head(features) # x1: (H, W, 3), c1: (H, W, 1)
    x2, c2 = backbone.point_head(features) # x2: (H, W, 3), c2: (H, W, 1)
    
    # 3. Predict Gaussian parameters using parallel Gaussian head
    # Outputs: offsets, quaternions, scales, opacities, colors
    delta_x1, q1, s1, alpha1, color1 = gaussian_head(I1, features)
    delta_x2, q2, s2, alpha2, color2 = gaussian_head(I2, features)
    
    # 4. Compute final means
    mu1 = x1 + delta_x1
    mu2 = x2 + delta_x2
    
    # 5. Compute covariances from quaternions and scales
    # R(q) is rotation matrix from quaternion q
    # S(s) is diagonal matrix from scale s
    Sigma1 = quaternion_to_rotation_matrix(q1) @ scale_matrix(s1) @ scale_matrix(s1).T @ quaternion_to_rotation_matrix(q1).T
    Sigma2 = quaternion_to_rotation_matrix(q2) @ scale_matrix(s2) @ scale_matrix(s2).T @ quaternion_to_rotation_matrix(q2).T
    
    # 6. Construct Gaussian primitives
    # Union of primitives from both images
    gaussians = []
    for i in range(H):
        for j in range(W):
            gaussians.append(Gaussian(
                mu=mu1[i, j],
                sigma=Sigma1[i, j],
                alpha=alpha1[i, j],
                color=color1[i, j]
            ))
            gaussians.append(Gaussian(
                mu=mu2[i, j],
                sigma=Sigma2[i, j],
                alpha=alpha2[i, j],
                color=color2[i, j]
            ))
            
    return gaussians

def splatt3r_loss(gaussians, target_image, context_images, gt_depths, gt_poses, mask_params):
    """
    Calculate masked loss for training.
    """
    # Render Gaussians to target view
    rendered_image = render_gaussians(gaussians, target_camera_params)
    
    # Calculate Loss Mask M
    # M is a binary mask where 1 indicates a pixel is visible and covisible
    M = calculate_loss_mask(target_image, context_images, gt_depths, gt_poses, mask_params)
    
    # Apply mask
    masked_rendered = rendered_image * M
    masked_target = target_image * M
    
    # Calculate MSE and LPIPS losses
    mse_loss = mean_squared_error(masked_rendered, masked_target)
    lpips_loss = lpips_loss_function(masked_rendered, masked_target)
    
    # Weighted sum
    total_loss = lambda_mse * mse_loss + lambda_lpips * lpips_loss
    return total_loss
```

**Parameters:**
*   **Input Resolution:** $512 \times 512$ pixels [S1, unofficial].
*   **Overlap Thresholds:** Hyperparameters $\phi$ and $\psi$ control the selection of context and target images during training.
    *   $\phi$: Minimum percentage of pixels in the second context image with correspondences in the first.
    *   $\psi$: Minimum percentage of pixels in the target image present in at least one context image.
    *   Typical values: Close $(\phi=0.9, \psi=0.9)$, Medium $(\phi=0.7, \psi=0.7)$, Wide $(\phi=0.5, \psi=0.5)$, Very Wide $(\phi=0.3, \psi=0.3)$ [S1, unofficial].
*   **Color Parameterization:** Constant, view-independent color $S \in \mathbb{R}^3$ is used in experiments [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Supervising Unseen Regions:** Supervising rendering loss for pixels not visible in context views (obscured or outside frustums) is counterproductive and can destroy model performance. This is addressed by the loss masking strategy [S1, unofficial].
*   **Local Minima:** Unlike methods that predict probabilistic depth distributions, Splatt3R directly supervises positions using ground-truth point clouds, providing a direct path for gradient descent [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The method is a single forward pass, making it significantly faster than iterative optimization methods like original 3D-GS.
*   **Memory Complexity:** Memory usage is proportional to the number of pixels in the input images, as it predicts one Gaussian per pixel [S1, unofficial].
*   **Measured Performance:**
    *   On ScanNet++ test scenes with 2 views: PSNR 23.30, SSIM 0.823, LPIPS 0.125, Runtime 1.10 s for construction/export [S2].
    *   On ScanNet++ test scenes with Close view overlap ($\phi=0.9, \psi=0.9$): PSNR 19.66, SSIM 0.757, LPIPS 0.234 [S1, unofficial].
*   **Strengths:**
    *   Pose-free: Does not require camera intrinsics or extrinsics.
    *   Generalizable: Trained on ScanNet++, it generalizes to uncalibrated, in-the-wild images.
    *   Extrapolation: Capable of synthesizing views beyond the stereo baseline, unlike many sibling methods [S1, unofficial].
*   **Limitations:**
    *   Performance degrades with wider baselines (lower overlap) [S1, unofficial].
    *   Relies on the quality of the underlying MASt3R point cloud prediction [S1, unofficial].

## Background
Splatt3R was introduced in 2024 by Brandon, Zheng, Iro, and Victor from the University of Oxford [S1, unofficial]. It builds upon the MASt3R foundation model for 3D geometry reconstruction [S1, unofficial]. The method addresses the limitations of existing generalizable 3D-GS methods that are restricted to interpolating viewpoints between input stereo views [S1, unofficial]. It is trained on the ScanNet++ dataset [S1, unofficial].
