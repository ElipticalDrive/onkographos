# Intrinsic Decomposition of 3D Gaussian Splats

Also called: Albedo, Shading, Residual Gaussian Splatting, Albedo-Shading-Decomposed 3DGS, Albedo-Shading-Residual decomposition, Intrinsic 3DGS, Intrinsic Decomposition with Separate Gaussian Fields, Multi-Layer Gaussian Splatting, Multi-Layer Gaussian Splatting (Albedo, Residual), Three-set Gaussian optimization

## Overview
This method decomposes a radiance field represented as 3D Gaussian splats into three independent sets of Gaussian primitives: albedo ($G_A$), shading ($G_S$), and view-dependent residual ($G_R$) [S1]. It solves the problem of multi-view consistent editing of object textures by allowing users to modify albedo without altering lighting, which is difficult when intrinsic components are entangled in a single representation [S1]. Unlike prior work that optimizes a single set of Gaussians or an MLP for all intrinsic quantities, this approach uses separate layers to better capture the misaligned sharp details of each component [S1].

## How it works
### Inputs and Outputs
**Inputs:**
- A video sequence of the scene [S1].
- Camera poses (computed via Structure-from-Motion) [S1].
- Predicted albedo maps (from a video diffusion model) [S1].
- Predicted depth maps (from a monocular depth estimator) [S1].

**Outputs:**
- Three sets of 3D Gaussians: $G_A$ (albedo), $G_S$ (shading), and $G_R$ (residual) [S1].
- A rendered scene $I$ composed from these fields [S1].

### Data Structures
Each Gaussian primitive $g$ in any set ($G_A, G_S, G_R$) is defined as [S1]:
$$ g = \{c, \alpha, p, \Sigma\} $$
- $c$: Color.
  - For $G_A$ and $G_S$: A simple triplet $c = \{r, g, b\} \in \mathbb{R}^3$ [S1].
  - For $G_R$: Spherical Harmonics (SH) coefficients, up to 3 bands, scheduled progressively as in standard 3DGS [S1].
- $\alpha$: Opacity.
- $p$: Position in 3D space.
- $\Sigma$: Covariance matrix (defining scale and rotation) [S1].

### Initialization
1. **Video Processing:**
   - Apply inverse gamma correction to sRGB input images to obtain pseudo-linear RGB [S1].
   - Apply inverse gamma correction to albedo maps from the diffusion model (observed to be non-linear) [S1].
   - Subsample the video to create a multi-view dataset by sampling every $n=5$ frame, preferring low-blur frames [S1].
   - Run Structure-from-Motion (SfM) on extracted images to compute camera poses [S1].
   - Apply the undistortion applied by SfM to the albedo images as well [S1].
   - Use a video diffusion model (DiffusionRenderer) to estimate albedo for each frame [S1].
     - *Chunk Processing:* Process sequences in chunks of 64 frames (one start latent + eight regular latents). At each denoising step, operate on 57 frames (one start latent + seven regular latents). Advance the window by four latent codes (shift of 32 frames). Discard redundant frames after decoding [S1].
   - Use a monocular depth estimator (Depth Anything V2) to obtain initial depth maps [S1].

2. **Albedo Field ($G_A$) Initialization:**
   - Start from calibrated cameras and the initial point cloud from SfM [S1].
   - Initialize $G_A$ using the same learning rates and activations as original 3DGS, except albedo color uses a sigmoid activation (expected range $[0, 1]$) [S1].

3. **Shading Field ($G_S$) Initialization:**
   - Initialize $G_S$ from SfM points in the same manner as albedo Gaussians [S1].

4. **Residual Field ($G_R$) Initialization:**
   - Spawned dynamically during optimization (see Step 5) [S1].

### Optimization Steps

**Step 1: Albedo Reconstruction**
Optimize $G_A$ to reproduce the predicted albedo images $\tilde{A}$ [S1].
- Render albedo image $\tilde{A}$ and depth image $\tilde{D}$ (by replacing Gaussian color with their depth) [S1].
- Compute loss [S1]:
  $$ L = (1 - \lambda) \|\tilde{A} - A\|_1 + \lambda L_{D-SSIM}(A, \tilde{A}) + \lambda_d L_{depth} + \lambda_s L_{scale} $$
  Where:
  - $L_{depth} = \|\tilde{D} - D\|_1$ (regularization against predicted depth $D$) [S1].
  - $L_{scale} = \bar{s}$ (average scale of primitives, encouraging flattening) [S1].
  - $L_{D-SSIM}$ is the D-SSIM loss [S1].
  - $\lambda, \lambda_d, \lambda_s$ are hyperparameters controlling the loss weights [S1].

**Step 2: Shading Optimization (Phase 1) [S1]**
Ignore the residual term. Optimize $G_S$ using the diffuse model $I = A \times S$ [S1].
- Use inverse domain photometric loss to handle high dynamic range and bound values in $[0, 1]$ [S1]:
  $$ L_{photometric} = \left\| \frac{1}{1+I} - \frac{1}{1+A \times S} \right\|_1 $$
- Add gray shading regularization to prevent incorrect color reproduction when albedo is dark [S1]:
  $$ L_{gray} = \max(c) - \min(c) $$
  Where $c$ are the color parameters of the shading Gaussian [S1].
- Total loss includes photometric loss, depth regularization, and scale regularization [S1].

**Step 3: Residual Spawning**
- Iterate through training views [S1].
- Compute the difference between the input image $I$ and the composited diffuse render $A \times S$ [S1].
- Randomly select a subset of pixels with high difference [S1].
- Use the predicted depth of these pixels as positions to spawn new residual Gaussians in $G_R$ [S1].

**Step 4: Residual Optimization (Phase 2) [S1]**
Freeze $G_S$. Optimize $G_R$ to capture residual non-diffuse effects [S1].
- Use the full image formation model [S1]:
  $$ I = A \times S + R $$
- Compute loss using the inverse domain photometric loss [S1]:
  $$ L = (1 - \lambda) \left\| \frac{1}{1+I} - \frac{1}{1+A \times S + R} \right\|_1 + L_{D-SSIM}(I, A \times S + R) + \lambda_d L_{depth} + \lambda_s L_{scale} $$
- Only update residual Gaussians $G_R$ [S1].
- Keep the same scaling and depth regularizations as albedo/shading stages [S1].

**Step 5: Albedo Editing (Optional)**
1. User drags a rectangular window in an image to select a surface [S1].
2. Select the primitive contributing most to each pixel in the window [S1].
3. Use RANSAC to fit a proxy plane over the centers of these Gaussians [S1].
4. Render a set of edited albedo images from multiple nearby viewpoints (sampled on a hemisphere centered on the editing viewpoint) by compositing the textured proxy plane with the albedo field, using rendered depth for occlusion testing [S1].
5. Re-optimize albedo Gaussians $G_A$ using the edited images and Eq. 5 [S1].
6. Spawn additional albedo Gaussians on the textured proxy plane by randomly sampling 20% of the pixels covered by the edit in the edited view [S1].

### Pseudocode

```python
import numpy as np

def intrinsic_decomposition(video_frames, video_diffusion_model, depth_estimator, sfm_solver, num_iterations=30000):
    """
    Main pipeline for intrinsic decomposition of 3D Gaussian Splatting.
    """
    # 1. Preprocessing
    linear_frames = apply_inverse_gamma(video_frames)
    
    # Subsample video: every 5th frame
    sampled_frames = linear_frames[::5]
    
    # Compute camera poses via SfM
    cameras = sfm_solver(sampled_frames)
    
    # Estimate Albedo using Video Diffusion Model with chunking
    albedo_maps = []
    chunk_size = 64
    shift = 32
    for i in range(0, len(sampled_frames), shift):
        chunk = sampled_frames[i : i + chunk_size]
        # DiffusionRenderer processes 57 frames at a time, shifting by 32
        albedo_chunk = video_diffusion_model.process_chunk(chunk)
        albedo_maps.extend(albedo_chunk)
    
    # Apply undistortion from SfM to albedo maps
    albedo_maps = apply_undistortion(albedo_maps, cameras)
    
    # Estimate Depth
    depth_maps = depth_estimator(sampled_frames)
    
    # 2. Initialize Gaussians from SfM Point Cloud
    initial_points = sfm_solver.get_point_cloud()
    
    # Initialize Albedo Gaussians G_A
    G_A = initialize_gaussians(initial_points, color_activation='sigmoid')
    
    # 3. Optimize Albedo Field
    optimize_albedo(G_A, albedo_maps, depth_maps, cameras, num_iterations)
    
    # 4. Optimize Shading Field G_S
    G_S = initialize_gaussians(initial_points)
    optimize_shading(G_A, G_S, sampled_frames, depth_maps, cameras, num_iterations)
    
    # 5. Spawn and Optimize Residual Field G_R
    G_R = spawn_residual_gaussians(G_A, G_S, sampled_frames, depth_maps, cameras)
    optimize_residual(G_A, G_S, G_R, sampled_frames, depth_maps, cameras, num_iterations)
    
    return G_A, G_S, G_R

def optimize_albedo(G_A, albedo_maps, depth_maps, cameras, num_iterations):
    """
    Optimizes G_A to match predicted albedo maps using Eq. 5.
    """
    for iteration in range(num_iterations):
        for frame_idx in range(len(cameras)):
            camera = cameras[frame_idx]
            target_albedo = albedo_maps[frame_idx]
            target_depth = depth_maps[frame_idx]
            
            # Render
            rendered_albedo, rendered_depth = render_gaussians(G_A, camera)
            
            # Loss components
            L_recon = l1_loss(rendered_albedo, target_albedo)
            L_dssim = d_ssim_loss(rendered_albedo, target_albedo)
            L_depth = l1_loss(rendered_depth, target_depth)
            L_scale = mean_scale(G_A)
            
            # Combine losses (Eq. 5)
            loss = (1 - lambda_param) * L_recon + lambda_param * L_dssim + \
                   lambda_d * L_depth + lambda_s * L_scale
            
            # Backpropagate and update G_A
            update_gaussians(G_A, loss)
            
            # Densification (standard 3DGS)
            densify_gaussians(G_A, cameras, frame_idx)

def optimize_shading(G_A, G_S, frames, depth_maps, cameras, num_iterations):
    """
    Optimizes G_S assuming I = A * S (Phase 1).
    """
    for iteration in range(num_iterations):
        for frame_idx in range(len(cameras)):
            camera = cameras[frame_idx]
            target_image = frames[frame_idx]
            target_depth = depth_maps[frame_idx]
            
            # Render Albedo and Shading
            rendered_albedo = render_albedo(G_A, camera)
            rendered_shading, rendered_depth = render_gaussians(G_S, camera)
            
            # Composite Diffuse
            composite_diffuse = rendered_albedo * rendered_shading
            
            # Inverse Domain Photometric Loss
            inv_target = 1.0 / (1.0 + target_image)
            inv_pred = 1.0 / (1.0 + composite_diffuse)
            L_photometric = l1_loss(inv_target, inv_pred)
            
            # Gray Shading Regularization
            L_gray = max_color_range(G_S)
            
            # Depth and Scale Regularization
            L_depth = l1_loss(rendered_depth, target_depth)
            L_scale = mean_scale(G_S)
            
            loss = L_photometric + L_gray + L_depth + L_scale
            update_gaussians(G_S, loss)
            densify_gaussians(G_S, cameras, frame_idx)

def spawn_residual_gaussians(G_A, G_S, frames, depth_maps, cameras):
    """
    Spawns G_R based on residuals from diffuse approximation.
    """
    new_G_R = []
    for frame_idx in range(len(cameras)):
        camera = cameras[frame_idx]
        target_image = frames[frame_idx]
        target_depth = depth_maps[frame_idx]
        
        # Render Diffuse
        rendered_albedo = render_albedo(G_A, camera)
        rendered_shading = render_shading(G_S, camera)
        composite_diffuse = rendered_albedo * rendered_shading
        
        # Compute Residual
        residual = target_image - composite_diffuse
        
        # Select pixels with high difference
        high_diff_pixels = select_high_difference_pixels(residual, threshold=0.1)
        
        # Spawn Gaussians at predicted depth of these pixels
        for pixel in high_diff_pixels:
            depth_val = target_depth[pixel.y, pixel.x]
            pos = unproject_pixel(camera, pixel, depth_val)
            new_G_R.append(create_gaussian(pos, color_sh=True, opacity=0.5))
            
    return new_G_R

def optimize_residual(G_A, G_S, G_R, frames, depth_maps, cameras, num_iterations):
    """
    Optimizes G_R using full model I = A * S + R (Phase 2).
    """
    for iteration in range(num_iterations):
        for frame_idx in range(len(cameras)):
            camera = cameras[frame_idx]
            target_image = frames[frame_idx]
            target_depth = depth_maps[frame_idx]
            
            # Render all fields
            rendered_albedo = render_albedo(G_A, camera)
            rendered_shading = render_shading(G_S, camera)
            rendered_residual, rendered_depth = render_gaussians(G_R, camera)
            
            # Composite Full
            composite_full = (rendered_albedo * rendered_shading) + rendered_residual
            
            # Inverse Domain Photometric Loss
            inv_target = 1.0 / (1.0 + target_image)
            inv_pred = 1.0 / (1.0 + composite_full)
            L_photometric = l1_loss(inv_target, inv_pred)
            
            # Depth and Scale Regularization
            L_depth = l1_loss(rendered_depth, target_depth)
            L_scale = mean_scale(G_R)
            
            loss = L_photometric + L_depth + L_scale
            update_gaussians(G_R, loss)
            densify_gaussians(G_R, cameras, frame_idx)

# Helper functions (defined for self-containment)
def apply_inverse_gamma(img, gamma=2.2):
    return np.power(img, gamma)

def apply_undistortion(img, cameras):
    # [G] Standard camera undistortion applied to match SfM preprocessing
    return [cam.undistort(i) for i, cam in zip(img, cameras)]

def initialize_gaussians(points, color_activation='linear'):
    # [G] Standard 3DGS initialization from point cloud
    return Gaussians(points, color_activation=color_activation)

def render_gaussians(G, camera):
    # [G] Standard 3DGS rasterization returning color and depth buffers
    return camera.rasterize(G)

def render_albedo(G_A, camera):
    return render_gaussians(G_A, camera)[0]

def render_shading(G_S, camera):
    return render_gaussians(G_S, camera)[0]

def select_high_difference_pixels(residual, threshold=0.1):
    return np.argwhere(np.abs(residual) > threshold)

def l1_loss(a, b):
    return np.mean(np.abs(a - b))

def d_ssim_loss(a, b):
    # [G] Standard D-SSIM implementation
    return 1.0 - ssim(a, b)

def mean_scale(G):
    return np.mean(G.scales)

def max_color_range(G):
    return np.max(G.colors, axis=1) - np.min(G.colors, axis=1)

def update_gaussians(G, loss):
    # [G] Standard optimizer step (e.g., Adam)
    G.optimizer.step()

def densify_gaussians(G, cameras, frame_idx):
    # [G] Standard 3DGS densification based on gradient magnitudes
    G.densify(cameras[frame_idx])

def unproject_pixel(camera, pixel, depth):
    return camera.unproject(pixel.x, pixel.y, depth)

def create_gaussian(pos, color_sh=True, opacity=0.5):
    return Gaussian(position=pos, use_sh=color_sh, opacity=opacity)
```

## Operating characteristics
- **Time Complexity:** Training is significantly slower than vanilla 3DGS [S1]. For example, on the "Basement 1" scene, the full method took 28 minutes 30 seconds compared to 6 minutes 56 seconds for vanilla 3DGS [S1]. This is due to the additional render calls required for each layer (2 for diffuse, 3 for full) [S1].
- **Memory Complexity:** Requires storing three sets of Gaussians [S1]. The total number of primitives is higher than vanilla 3DGS (e.g., 2.185M vs 1.558M for Basement 1) [S1].
- **Rendering:** Requires 2 render calls for the diffuse scene (Albedo + Shading) and 3 for the full scene (Albedo + Shading + Residual) [S1].
- **Strengths:** Allows multi-view consistent editing of albedo without altering lighting; better captures misaligned sharp details of intrinsic components [S1].
- **Limitations:** Slower rendering and longer training times compared to vanilla 3DGS [S1].

## Background
This method extends intrinsic image decomposition to radiance fields represented with Gaussian splats [S1]. It builds on the intrinsic image formation model $I = A \times S + R$ [S1]. The approach was proposed to address the limitations of prior work that optimized a single set of Gaussians or MLPs for all intrinsic quantities, which struggled with misaligned sharp details [S1]. The method uses data-driven predictions from video diffusion models to guide the optimization [S1].
