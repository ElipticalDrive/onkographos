# Opacity Decay

Also called: Sigmoid Opacity Decay, Subtractive Opacity Decay

## Overview
Opacity Decay is a regularization technique applied during the training of 3D Gaussian Splatting models to prevent Gaussian primitives from becoming over-saturated (opacity approaching 1.0) or persisting as redundant, semi-transparent artifacts. It operates by systematically reducing the opacity values of Gaussians, either through a sigmoid-based scaling mechanism or direct subtraction, ensuring that only geometrically relevant primitives retain high opacity. This method distinguishes itself from hard pruning by allowing gradual adjustment of opacity parameters, which stabilizes gradient flow and prevents sudden loss of scene coverage, while differing from visibility-aware variants by applying decay uniformly based on training strategy rather than per-frame visibility metrics.

## How it works
The method modifies the learnable opacity parameter of each Gaussian primitive. In standard 3D Gaussian Splatting, opacity is stored as a logit (unbounded real number) and converted to alpha via a sigmoid function during rendering. Decay operates on this logit representation or the resulting alpha, depending on the specific strategy employed.

### Inputs and Outputs
- **Input**: The current set of Gaussian splats, specifically the `opacities` tensor (logits), learning rate `lr`, and strategy configuration.
- **Output**: Updated `opacities` tensor with reduced values.

### Data Structures
- **Splats**: A collection of Gaussian primitives. Each primitive $k$ has a learnable opacity logit $\tilde{o}_k$.
- **Tensor Layout**: `splats['opacities']` is a 1D tensor of shape $(N,)$ containing $\tilde{o}_k$ for $N$ Gaussians.

### Parameters
- **`opacity_decay`**: A scalar multiplier for the decay rate. Typical values are small positive numbers (e.g., $10^{-4}$ to $10^{-3}$) relative to the learning rate. [S1, unofficial]
- **`decay_factor`**: The multiplicative factor applied to the sigmoid opacity in the 'mrnf' strategy. [S1, unofficial]
- **`lr`**: The current learning rate for the opacity parameter. [S1, unofficial]

### Steps
The application of opacity decay depends on the selected strategy name.

1. **Strategy: 'mrnf' (Sigmoid Scaling)**
   This strategy applies a multiplicative decay to the alpha value, then converts back to logit space.
   1. Compute the current alpha: $\alpha_k = \sigma(\tilde{o}_k) = \frac{1}{1 + e^{-\tilde{o}_k}}$.
   2. Apply decay: $\alpha'_k = \alpha_k \times \text{decay\_factor}$.
   3. Clip $\alpha'_k$ to a safe range $[\epsilon, 1-\epsilon]$ to avoid numerical instability in the logit conversion, where $\epsilon = 10^{-8}$.
   4. Convert back to logit: $\tilde{o}'_k = \log\left(\frac{\alpha'_k}{1 - \alpha'_k}\right)$.
   5. Update the logit: $\tilde{o}_k \leftarrow \tilde{o}'_k$.

2. **Strategy: Subtractive (Direct Decay)**
   This strategy directly subtracts a value from the logit opacity.
   1. Compute the decay amount: $\Delta = \text{opacity\_decay} \times \text{lr}$.
   2. Update the logit: $\tilde{o}_k \leftarrow \tilde{o}_k - \Delta$.
   3. [G] Ensure the logit does not drop below a minimum bound (e.g., -60) to prevent underflow during rendering, though the source notes do not explicitly specify a lower bound for this specific step. [S1, unofficial]

### Pseudocode
```python
import torch
import math

def apply_opacity_decay(splats_opacities_logit: torch.Tensor, 
                        strategy_name: str, 
                        opacity_decay: float, 
                        decay_factor: float, 
                        lr: float) -> torch.Tensor:
    """
    Applies opacity decay to Gaussian splats.
    
    Args:
        splats_opacities_logit: Tensor of shape (N,) containing logit opacities.
        strategy_name: 'mrnf' or 'subtractive'.
        opacity_decay: Scalar decay multiplier for subtractive strategy.
        decay_factor: Multiplicative factor for mrnf strategy.
        lr: Current learning rate.
        
    Returns:
        Updated tensor of logit opacities.
    """
    eps = 1e-8
    new_opacities = splats_opacities_logit.clone()
    
    if strategy_name == 'mrnf':
        # 1. Convert logit to alpha
        alpha = torch.sigmoid(new_opacities)
        
        # 2. Multiply by decay factor
        alpha_decayed = alpha * decay_factor
        
        # 3. Clip to valid range for logit conversion
        alpha_clipped = torch.clamp(alpha_decayed, min=eps, max=1.0 - eps)
        
        # 4. Convert back to logit
        # logit = log(alpha / (1 - alpha))
        new_opacities = torch.log(alpha_clipped / (1.0 - alpha_clipped + eps))
        
    else:
        # Subtractive strategy
        # 1. Compute decay amount
        decay_amount = opacity_decay * lr
        
        # 2. Subtract from logit
        new_opacities = new_opacities - decay_amount
        
        # [G] Optional: Clip to prevent extreme negative values if required by renderer
        # new_opacities = torch.clamp(new_opacities, min=-60.0)
        
    return new_opacities
```

### Edge Cases and Pitfalls
- **Numerical Stability**: When converting back to logit in the 'mrnf' strategy, division by zero or log of zero must be avoided. Clamping alpha to $[\epsilon, 1-\epsilon]$ is critical. [S1, unofficial]
- **Over-decay**: If `opacity_decay` or `decay_factor` is too large, Gaussians may become effectively invisible (alpha $\approx$ 0) prematurely, leading to holes in the rendered scene.
- **Strategy Mismatch**: Applying the wrong formula for the chosen strategy name will result in incorrect opacity values. The 'mrnf' strategy involves a non-linear transformation (sigmoid-logit), while subtractive is linear in logit space.

## Subtopics

### Visibility-Aware Decay
A variant that decays evidence only for substantially visible Gaussians, preserving occluded primitives. It checks if the total weight $W_i^{(t)}$ of Gaussian $i$ exceeds a threshold $w_{min}$. If visible, evidence $H_{i,j}$ is multiplied by decay rate $\gamma$ ($H_{i,j} \leftarrow \gamma \cdot H_{i,j}$); otherwise, it remains unchanged. This prevents erosion of occluded primitives. Parameter $\gamma$ is typically 0.95. A pitfall is that if $0 < W_i^{(t)} \le w_{min}$, no decay occurs, and evidence can grow without bound if votes are small and consistent. [S2, unofficial]

### Gaussian Opacity Scaling
Scales the opacity of selected Gaussians by a weight factor and converts back to logit space. It clips the logit to $[-60, 60]$, converts to alpha, multiplies by the selection weight, clips alpha to $[10^{-6}, 1-10^{-6}]$, and computes the new logit as $o_{new} = \log(\alpha_{new}) - \log(1 - \alpha_{new})$. Parameters include `opacity_weight_floor` and `opacity_weight_min`. [S3, unofficial]

### Gaussian Opacity Regularization
A regularization term that penalizes low-opacity Gaussians using an entropy loss $L_{ent} = \lambda_6 \sum_k (-o_k \ln(o_k))$ to drive opacities toward binary values (0 or 1). Opacity is parameterized as $o_k = \sigma(\tilde{o}_k)$. Gaussians with opacity below a threshold $\tau = 0.05$ are periodically pruned. This ensures centroids align with object surfaces for accurate SDF learning. Parameter $\lambda_6$ is typically 0.01. [S4]

## Operating characteristics
- **Time Complexity**: $O(N)$ per update step, where $N$ is the number of Gaussians. The operations are element-wise tensor operations.
- **Memory Complexity**: $O(1)$ additional memory, as updates are performed in-place or on a clone of the existing opacity tensor.
- **Performance**: Reduces the number of redundant, semi-transparent Gaussians, potentially speeding up rendering by allowing earlier culling of low-opacity primitives. It stabilizes training by preventing opacity saturation.
- **Strengths**: Prevents over-saturation; stabilizes training gradients; reduces redundancy.
- **Limitations**: Requires careful tuning of decay rates; aggressive decay can lead to under-reconstruction (holes).
- **When to use**: During the training phase of 3D Gaussian Splatting, particularly when Gaussians tend to become overly opaque or when redundancy needs to be managed without hard pruning shocks.
- **When not to use**: During inference/rendering only (unless for post-processing); not suitable for methods requiring precise preservation of semi-transparent structures (use Visibility-Aware Decay instead).

## Background
Opacity Decay originated as a regularization technique in the optimization of 3D Gaussian Splatting models. It was introduced to address the issue of Gaussian primitives becoming over-saturated (opacity $\approx$ 1) or persisting as redundant artifacts. The 'mrnf' strategy and subtractive decay are documented in unofficial implementations and adaptations of 3DGS training pipelines. [S1, unofficial] Variants like Visibility-Aware Decay were developed for open-vocabulary segmentation tasks to handle occlusion. [S2, unofficial] Gaussian Opacity Regularization was introduced in the context of learning Signed Distance Fields (SDFs) from splatting, where surface alignment is critical. [S4]
