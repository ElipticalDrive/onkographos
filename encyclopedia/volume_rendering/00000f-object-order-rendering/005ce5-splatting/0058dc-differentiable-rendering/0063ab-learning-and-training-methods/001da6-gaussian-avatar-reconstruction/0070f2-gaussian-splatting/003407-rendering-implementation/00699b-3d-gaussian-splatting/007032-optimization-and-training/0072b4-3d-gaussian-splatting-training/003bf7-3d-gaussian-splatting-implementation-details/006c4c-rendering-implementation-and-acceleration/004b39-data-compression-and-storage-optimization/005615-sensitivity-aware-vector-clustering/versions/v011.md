# Sensitivity-Aware Vector Clustering

Also called: Color Compression, Niedemayr et al. compression, Niedermayr, Sensitivity-Aware Scene Compression, Sensitivity-Aware Vector Clustering for 3DGS Compression, Sensitivity-aware k-Means

## Overview
Sensitivity-Aware Vector Clustering is a compression scheme for 3D Gaussian Splatting that reduces storage requirements by clustering spherical harmonic (SH) coefficients and Gaussian shape parameters (scale and rotation) into compact codebooks using sensitivity-aware vector quantization [S1, S2]. It differs from post-training quantization by deriving a sensitivity measure to guide the clustering process during the compression scheme derivation, prioritizing the preservation of parameters that significantly affect image quality [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of optimized 3D Gaussians, each defined by position, opacity, SH coefficients (color), and shape parameters (rotation and scale). A set of training images with known camera parameters.
*   **Output:** Two codebooks (one for SH coefficients, one for shape parameters), indices mapping each Gaussian to its codebook entries, and the remaining uncompressed parameters (position, opacity, and high-sensitivity SH coefficients).

**Data Structures:**
*   **Codebook Entry (Shape):** 4 scalar values for quaternion (rotation) plus 3 scalar values for scaling [S1].
*   **Codebook Entry (Color):** SH coefficient vector [S1].
*   **Gaussian Representation:** Two 32-bit unsigned integer indices pointing to the respective codebooks, stored alongside the Gaussian data [S1].

**Sensitivity Measure:**
The sensitivity $S$ of a parameter $p$ is defined as the contribution of that parameter to the training images [S1, S2]. It is computed using the gradient of the total image energy $E$ (sum of RGB components over all pixels) with respect to $p$ [S1, S2].

$$ S(p) = \frac{\sum_{i=1}^{N} \frac{\partial E_i}{\partial p}}{\sum_{i=1}^{N} P_i} $$

Where:
*   $N$ is the number of training images [S1, S2].
*   $E_i$ is the error/image contribution for image $i$ [S1].
*   $P_i$ is the number of pixels in image $i$ [S1, S2].
*   The sensitivity is computed via a single backward pass over each of the training images [S1].

For a vector $x$ (e.g., a set of SH coefficients or a shape parameter vector), the sensitivity $S(x)$ is defined as the maximum sensitivity over its components $d$ [S1]:

$$ S(x) = \max_d S(x_d) $$

**Algorithm Steps:**

1.  **Sensitivity Calculation:** Compute the sensitivity $S(p)$ for each scene parameter $p$ (SH coefficients and shape parameters) using the formula above [S1, S2].
2.  **High-Sensitivity Filtering:** Identify vectors with sensitivity higher than a threshold $\beta_c$ (for SH coefficients) or $\beta_g$ (for shape parameters). These vectors are not clustered but are added directly to the respective codebooks to preserve critical details [S1].
    *   Typical values: $\beta_c = 6 \cdot 10^{-7}$, $\beta_g = 3 \cdot 10^{-6}$ [S1].
3.  **Codebook Initialization:** Initialize the codebooks randomly with a uniform distribution within the minimum and maximum values of each parameter [S1].
4.  **Sensitivity-Aware Clustering:** Perform k-Means clustering on the remaining vectors using a weighted distance metric [S1, S2].
    *   **Weighted Distance:** The distance between a vector $x$ and a centroid $c_k$ is weighted by the sensitivity of $x$ [S1]:
        $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
    *   **Assignment:** Assign each vector to the centroid with the minimum weighted distance [S1].
    *   **Centroid Update:** Update each centroid $c_k$ using the weighted average of assigned vectors $A(k)$ [S1]:
        $$ c_k = \frac{1}{\sum_{x_i \in A(k)} S(x_i)} \sum_{x_i \in A(k)} S(x_i) x_i $$
    *   **Batched Strategy:** To improve performance, use a batched clustering strategy [S1]. In each update step, pick a random subset of vectors, compute the update, and update centroids using a moving average with decay factor $\lambda_d$ [S1].
        *   Typical values: $\lambda_d = 0.8$, batch size for color features $2^{18}$, batch size for Gaussian parameters $2^{20}$ [S1].
        *   Number of update steps: 800 for Gaussians, 100 for SH coefficients [S1].
5.  **Normalization:** Due to floating-point errors, clustering normalized covariance matrices may result in non-unit scaling vectors. Re-normalize each codebook vector after each update step by dividing it through the trace of the covariance metric [S1].
6.  **Decomposition:** Decompose each codebook entry (covariance matrix) into rotation (quaternion) and scale parameters using eigenvalue decomposition. This is required for quantization-aware training as direct optimization of the matrix is not possible [S1].
7.  **Quantization-Aware Fine-Tuning:** Fine-tune the parameters on the training set to recover information lost during clustering [S1, S2].
    *   Use Min-Max Quantization [S2].
    *   **Forward Pass:** Simulate quantization considering a certain number of bits and the moving average of each parameter's min/max values [S2].
    *   **Backward Pass:** Ignore simulated quantization and calculate the gradient for the parameter without quantization [S2].
    *   Typical number of optimization steps: 5000 [S1].
8.  **Entropy Encoding:** Compress the set of Gaussians and codebooks using DEFLATE [S1, S2].
    *   Order Gaussians by Z-order (Morton order) to leverage spatial coherence [S1, S2].
    *   DEFLATE combines LZ77 and Huffman coding [S1, S2].

**Pseudocode:**

import numpy as np

def compute_sensitivity(gradient_sum, pixel_counts):
    """
    Compute sensitivity S(p) for a parameter p.
    gradient_sum: Sum of gradients dE/dp over all training images.
    pixel_counts: Sum of pixels Pi over all training images.
    """
    return gradient_sum / pixel_counts

def sensitivity_aware_kmeans(vectors, sensitivities, k, decay_factor, batch_size, max_steps):
    """
    Perform sensitivity-aware k-Means clustering.
    vectors: Array of shape (N, D) containing the vectors to cluster.
    sensitivities: Array of shape (N,) containing sensitivity S(x) for each vector.
    k: Number of centroids (codebook size).
    decay_factor: Lambda_d for moving average update.
    batch_size: Number of vectors to process in each update step.
    max_steps: Number of update steps.
    """
    n_vectors, dim = vectors.shape
    # Initialize centroids randomly within min/max of vectors
    centroids = np.random.uniform(vectors.min(axis=0), vectors.max(axis=0), size=(k, dim))
    
    for step in range(max_steps):
        # Pick random subset of vectors
        indices = np.random.choice(n_vectors, size=batch_size, replace=False)
        batch_vectors = vectors[indices]
        batch_sensitivities = sensitivities[indices]
        
        # Compute weighted distances
        # D(x, ck) = S(x) * ||x - ck||^2
        # We need to assign each vector in batch to the closest centroid
        distances = np.zeros((batch_size, k))
        for i in range(batch_size):
            for j in range(k):
                diff = batch_vectors[i] - centroids[j]
                distances[i, j] = batch_sensitivities[i] * np.dot(diff, diff)
        
        # Assign to closest centroid
        assignments = np.argmin(distances, axis=1)
        
        # Update centroids using moving average
        new_centroids = centroids.copy()
        for j in range(k):
            mask = assignments == j
            if np.any(mask):
                assigned_vectors = batch_vectors[mask]
                assigned_sensitivities = batch_sensitivities[mask]
                # Weighted average
                weight_sum = np.sum(assigned_sensitivities)
                if weight_sum > 0:
                    weighted_mean = np.sum(assigned_vectors * assigned_sensitivities[:, np.newaxis], axis=0) / weight_sum
                    # Moving average update
                    new_centroids[j] = (1 - decay_factor) * centroids[j] + decay_factor * weighted_mean
        
        centroids = new_centroids
        
        # Re-normalize codebook vectors if they represent covariance matrices

def decompose_covariance_matrix(cov_matrix):
    """
    Decompose a covariance matrix into rotation (quaternion) and scale.
    """
    # Eigenvalue decomposition
    eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)
    # Scale is sqrt of eigenvalues
    scale = np.sqrt(eigenvalues)
    # Rotation is eigenvectors
    # Convert eigenvectors to quaternion
    quaternion = eigenvectors_to_quaternion(eigenvectors)
    return quaternion, scale

def eigenvectors_to_quaternion(eigenvectors):
    """
    Convert eigenvectors (rotation matrix) to quaternion.
    """
    # Standard conversion from rotation matrix to quaternion
    R = eigenvectors
    trace = R[0,0] + R[1,1] + R[2,2]
    if trace > 0:
        s = 0.5 / np.sqrt(trace + 1.0)
        w = 0.25 / s
        x = (R[2,1] - R[1,2]) * s
        y = (R[0,2] - R[2,0]) * s
        z = (R[1,0] - R[0,1]) * s
    elif (R[0,0] > R[1,1]) and (R[0,0] > R[2,2]):
        s = 2.0 * np.sqrt(1.0 + R[0,0] - R[1,1] - R[2,2])
        w = (R[2,1] - R[1,2]) / s
        x = 0.25 * s
        y = (R[0,1] + R[1,0]) / s
        z = (R[0,2] + R[2,0]) / s
    elif R[1,1] > R[2,2]:
        s = 2.0 * np.sqrt(1.0 + R[1,1] - R[0,0] - R[2,2])
        w = (R[0,2] - R[2,0]) / s
        x = (R[0,1] + R[1,0]) / s
        y = 0.25 * s
        z = (R[1,2] + R[2,1]) / s
    else:
        s = 2.0 * np.sqrt(1.0 + R[2,2] - R[0,0] - R[1,1])
        w = (R[1,0] - R[0,1]) / s
        x = (R[0,2] + R[2,0]) / s
        y = (R[1,2] + R[2,1]) / s
        z = 0.25 * s
    return np.array([w, x, y, z])

## Operating characteristics
*   **Compression Rate:** Achieves up to 31× compression on real-world scenes with minimal degradation of visual quality [S1].
*   **Rendering Performance:** Enables real-time rendering on lightweight GPUs, up to 4× higher framerates than the original 3DGS via an optimized GPU compute pipeline [S1].
*   **Memory:** Significantly reduces memory consumption, making it suitable for network streaming and low-power devices [S1].
*   **Strengths:** Preserves visual quality by focusing on sensitive parameters; efficient rendering due to codebook lookup; suitable for web-based rendering (WebGPU) [S1].
*   **Limitations:** Requires quantization-aware fine-tuning to recover lost information; clustering is sensitive to the choice of sensitivity threshold and codebook size [S1].
*   **When to use:** When storage and bandwidth are constrained, and real-time rendering on limited hardware is required [S1].
*   **When not to use:** When maximum possible visual fidelity is required without any compression artifacts, or when the scene has very few high-sensitivity parameters making clustering less effective [S1].

## Background
Sensitivity-Aware Vector Clustering was proposed by Niedemayr et al. in 2024 [S1]. It builds on the observation that SH coefficients and Gaussian shape parameters in 3D Gaussian Splatting are highly redundant and take up the majority of storage space [S1]. The method is inspired by volumetric radiance field compression and deep network weight quantization [S1]. It is used to accelerate novel view synthesis, particularly for applications like network streaming and rendering on low-power devices [S1].
