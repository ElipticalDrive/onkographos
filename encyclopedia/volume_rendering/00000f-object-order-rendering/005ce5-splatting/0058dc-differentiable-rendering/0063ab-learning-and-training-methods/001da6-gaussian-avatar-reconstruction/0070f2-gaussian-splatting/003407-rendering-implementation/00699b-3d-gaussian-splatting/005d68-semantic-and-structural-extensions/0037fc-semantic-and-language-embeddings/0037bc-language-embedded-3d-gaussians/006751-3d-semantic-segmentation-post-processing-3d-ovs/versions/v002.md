# 3D Semantic Segmentation Post-processing (3D-OVS)

Also called: 3D-OVS Semantic Segmentation Pipeline

## Overview
3D-OVS is a post-processing pipeline for semantic segmentation in 3D Gaussian Splatting systems that resolves ambiguity by selecting the optimal semantic level from multiple candidate relevancy maps [S1]. It solves the problem of inconsistent or noisy semantic predictions by thresholding, binarizing, and evaluating average relevancy within masks to choose the best binary mask [S1]. It differs from direct thresholding by explicitly comparing multiple semantic levels to mitigate outlier impact [S1].

## How it works
**Inputs:**
- Three relevancy maps for a single class query, representing three distinct semantic levels defined by SAM [S1].
- A threshold value $T = 0.4$ [S1].

**Outputs:**
- A single binary mask representing the final semantic segmentation for the queried class [S1].

**Data Structures:**
- **Relevancy Map:** A 2D image where each pixel contains a float32 score in $[0, 1]$ indicating the relevance of that location to the semantic query [S1].
- **Binary Map:** A 2D image where each pixel is 0 or 1, derived from thresholding the relevancy map [S1].

**Steps:**
1. **Thresholding:** For each of the three relevancy maps, apply a hard threshold $T = 0.4$.
   - If score $< 0.4$, set to 0.
   - If score $\ge 0.4$, set to 1.
   - This produces three binary maps [S1].
2. **Mask Region Calculation:** Identify the region of interest (mask) for each binary map. The mask region consists of all pixels where the binary value is 1 [S1].
3. **Average Relevancy Calculation:** For each binary map, calculate the average relevancy score of the original (pre-thresholded) relevancy map values within the mask region defined by that binary map [S1].
   - Let $R_i$ be the $i$-th relevancy map.
   - Let $B_i$ be the corresponding binary map.
   - Let $M_i = \{p \mid B_i[p] = 1\}$ be the mask region.
   - Calculate average relevancy $A_i$:
     $$ A_i = \frac{1}{|M_i|} \sum_{p \in M_i} R_i[p] $$
   - If $|M_i| = 0$, $A_i$ is treated as 0 [G].
4. **Selection:** Select the binary map $B_k$ corresponding to the highest average relevancy $A_k$ as the final predicted binary mask [S1].

**Parameters:**
- Threshold $T = 0.4$ [S1].

**Edge Cases and Pitfalls:**
- **Empty Mask:** If a binary map has no pixels above threshold, the average relevancy cannot be calculated. The implementation must handle this, e.g., by assigning a score of 0 or ignoring that candidate [G].
- **Ties:** If multiple maps have the same highest average relevancy, the selection strategy is not specified in the sources [S1]. A deterministic tie-breaker (e.g., lowest index) is recommended [G].
- **Precision:** Relevancy scores are floats and thresholding uses a hard cut at 0.4 [S1].

**Pseudocode:**
```python
def select_best_semantic_mask(relevancy_maps, threshold=0.4):
    """
    Selects the best semantic binary mask from three relevancy maps.
    
    Args:
        relevancy_maps: List of 3 2D lists (H, W), float32, values in [0, 1].
        threshold: Float, threshold for binarization.
        
    Returns:
        best_binary_map: 2D list (H, W), int, 0 or 1.
    """
    binary_maps = []
    average_relevancies = []
    
    for r_map in relevancy_maps:
        # Step 1: Thresholding
        b_map = [[1 if val >= threshold else 0 for val in row] for row in r_map]
        binary_maps.append(b_map)
        
        # Step 2 & 3: Calculate average relevancy within mask
        mask_pixels = [(r, c) for r in range(len(r_map)) for c in range(len(r_map[0])) if b_map[r][c] == 1]
        
        if not mask_pixels:
            # Edge case: empty mask
            average_relevancies.append(0.0)
        else:
            # Sum of relevancy scores in mask region
            total = sum(r_map[r][c] for r, c in mask_pixels)
            average_relevancies.append(total / len(mask_pixels))
            
    # Step 4: Select best
    best_index = 0
    best_val = average_relevancies[0]
    for i in range(1, len(average_relevancies)):
        if average_relevancies[i] > best_val:
            best_val = average_relevancies[i]
            best_index = i
            
    return binary_maps[best_index]
```

## Subtopics

### Semantic Surface Trimming
A post-processing or training-time strategy to prune unwanted background elements (e.g., sky) from 3D Gaussian reconstructions by learning a semantic field and using it to mask out non-object regions [S2]. It assigns each Gaussian a learnable semantic feature vector, renders pixel-level semantics via alpha blending, and trains these features using cross-entropy loss against pseudo-labels from a pretrained model (e.g., Grounded-SAM) [S2]. It is chosen when background noise (like sky) degrades reconstruction quality [S2]. It differs from direct thresholding by learning semantic features that are robust to noisy pseudo-labels, yielding more accurate semantics than directly using pretrained semantic maps [S2]. On the TNT dataset, it increases the F1-score from 0.38 to 0.40 [S2].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** On the 3D-OVS dataset, the method consistently outperforms other state-of-the-art methods in Accuracy and mIoU [S1]. On the TNT dataset, semantic trimming increases the F1-score by 0.02 [S2].
- **Strengths:** Mitigates outlier impact by selecting the best semantic level [S1]. Robust to noisy pseudo-labels when combined with semantic trimming [S2].
- **Limitations:** The threshold is fixed at 0.4 [S1].
- **When to use:** Used when three relevancy maps corresponding to different semantic levels are available [S1].

## Background
Originated in the LangSplat paper (CVPR 2024) by the authors of 3D Language Gaussian Splatting [S1]. It is used in 3D-OVS tasks to improve the accuracy of semantic predictions by leveraging multiple semantic levels [S1]. The method builds on the concept of 3D language Gaussians, which encode object-level embeddings for phrase grounding [S1].
