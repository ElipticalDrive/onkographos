# Animatable Gaussians


## Overview
Animatable Gaussians is a method for reconstructing animatable 3D human avatars using 3D Gaussian Splatting (3DGS) driven by the SMPL-X parametric model [S1, unofficial]. It solves the problem of generating high-fidelity, real-time renderable human avatars from monocular video by explicitly modeling pose-conditioned deformation offsets [S1, unofficial]. It is distinguished from sibling methods like 3DGS-Avatar, which uses per-Gaussian deformation MLPs, and GaussianAvatars, which focuses on head-driven avatars using the FLAME model [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Monocular video sequence of a human subject; SMPL-X mesh parameters (pose $\theta$, expression $\beta$) fitted to the video (e.g., via MICA or DECA) [S1, unofficial].
*   **Outputs:** A set of 3D Gaussians with parameters (position, covariance, opacity, spherical harmonics coefficients) that can be rendered in real-time for any given pose/expression [S1, unofficial].

**Data Structures:**
Each Gaussian $i$ is initialized on the surface of the canonical SMPL-X mesh.
*   **Position $\mathbf{p}_i$:** Canonical position on the mesh surface.
*   **Covariance $\Sigma_i$:** Initial covariance in canonical space.
*   **Appearance:** Opacity $\alpha_i$ and spherical harmonics coefficients $\mathbf{c}_i$.
*   **Deformation Parameters:** Explicit pose-conditioned offset parameters $\Delta \mathbf{p}$ associated with each Gaussian or its local tangent space [S1, unofficial].

**Steps:**
1.  **Initialization:** Fit SMPL-X to the input video to obtain canonical mesh and initial parameters. Initialize one Gaussian per mesh triangle or vertex in the canonical tangent space [S1, unofficial].
2.  **Deformation:** For a target pose $\theta$ and expression $\beta$:
    *   Compute rigid deformation $\mathbf{p}_{rigid}$ using Linear Blend Skinning (LBS) on the canonical position $\mathbf{p}_i$ [S1, unofficial].
    *   Compute explicit pose-conditioned offset $\Delta \mathbf{p}(\theta, \beta)$ [S1, unofficial].
    *   Final position: $\mathbf{p}'_i = \mathbf{p}_{rigid} + \Delta \mathbf{p}$ [S1, unofficial].
    *   Update covariance $\Sigma'_i$ using the Jacobian $J$ of the deformation map: $\Sigma'_i = J \Sigma_i J^T + \sigma^2 I$ [G].
3.  **Rendering:** Render the deformed Gaussians using differentiable 3D Gaussian Splatting [S1, unofficial].
4.  **Training:** Minimize photometric loss between rendered image and ground truth video frame.

## Subtopics

### [GSMs](7832-gsms.md)
Gaussian Shell Maps (GSMs) is a method for generating animatable 3D humans by combining CNN-based generators with 3D Gaussian Splatting (3DGS) to recreate virtual humans with sophisticated details such as clothing and accessories. It builds multi-layer shells from the SMPL template and binds 3D Gaussians to these shells. By utilizing the differentiable rendering of 3DGS and the generative adversarial network of StyleGAN2, animatable 3D humans are efficiently generated. It is distinguished from sibling methods like GAvatar, which attaches Gaussians to SMPL-X primitives, and HumanGaussian, which initializes Gaussians via random sampling.

## Operating characteristics
*   **Time Complexity:** Rendering is $O(N)$ where $N$ is the number of Gaussians, typical for 3DGS [S1, unofficial]. Deformation computation is $O(N)$ per frame [S1, unofficial].
*   **Memory Complexity:** $O(N)$ for storing Gaussian parameters and deformation offsets [S1, unofficial].
*   **Performance:** Real-time rendering is achievable on modern GPUs [S1, unofficial].
*   **Strengths:** High fidelity, real-time performance, explicit control via SMPL-X [S1, unofficial].
*   **Limitations:** Requires fitted SMPL-X parameters; quality depends on deformation offset modeling [S1, unofficial].
*   **When to Use:** When real-time, high-fidelity human avatars are needed from monocular video [S1, unofficial].
*   **When Not to Use:** When multi-view data is available and higher geometric accuracy is prioritized over speed, or when no SMPL-X fit is available [S1, unofficial].

## Background
Animatable Gaussians is part of the evolution of Gaussian Avatar Reconstruction methods. It builds on the SMPL-based rigid/non-rigid deformation principles [8385-smpl-based-rigid-non-rigid-deformation.md]. It is distinguished by its use of explicit pose-conditioned offsets within the SMPL-X rig [S1, unofficial].
