# Full-body Avatar Modeling

Also called: Hybrid Deformation Strategy for 3D Gaussians

## Overview
Full-body Avatar Modeling anchors 3D Gaussians in a canonical space and deforms them via parametric body models (e.g., SMPL) or cage-based rigging to model dynamic human motions [S1]. It employs a hybrid deformation strategy that combines linear blend skinning (LBS) for rigid skeletal transformations with pose-conditioned deformation fields for non-rigid secondary effects [S1]. This approach distinguishes itself from head-centric modeling by focusing on full-body structural integrity and large-scale articulation rather than fine-grained facial expressions [S1].

## How it works
The method builds on [SMPL-based rigid/non-rigid deformation](8385-smpl-based-rigid-non-rigid-deformation.md) by explicitly defining the hybrid strategy for full-body avatars.

**Inputs and Outputs:**
*   **Inputs:** Canonical 3D Gaussians (position $\mathbf{p}_i$, covariance $\Sigma_i$, opacity $\alpha_i$, spherical harmonics coefficients), SMPL model parameters (pose $\theta$, shape $\beta$), and training images with known camera poses.
*   **Outputs:** Deformed 3D Gaussians ready for differentiable rasterization.

**Data Structures:**
*   **Canonical Gaussians:** Stored as arrays of position (3 floats), covariance (6 floats, symmetric positive definite), opacity (1 float), and SH coefficients (variable, typically 48 for degree 3).
*   **Skinning Weights:** A learnable vector $\mathbf{w}_i \in \mathbb{R}^{N_{bones}}$ per Gaussian, where $N_{bones}$ is the number of bones in the SMPL model.
*   **Deformation Network:** An MLP taking canonical position and pose as input to predict non-rigid offsets.

**Steps:**

1.  **Precompute Rigid Transforms:** For each training timestep (or pose instance), compute the rigid transformation matrices $\mathbf{T}_j(\theta)$ for each bone $j$ based on the SMPL pose $\theta$ [S1, S2]. Note: Pose blend shapes are typically omitted to avoid inaccuracies in shape estimation; an MLP handles pose-dependent deformations instead [S2].

2.  **Compute Skinning Weights:** For each Gaussian $i$, optimize the raw skinning weight vector $\mathbf{w}_i$. Apply ReLU activation to each component $w_{i,j}$ to ensure non-negativity:
    $$ \hat{w}_{i,j} = \max(0, w_{i,j}) $$
    Normalize the vector so components sum to 1:
    $$ w'_{i,j} = \frac{\hat{w}_{i,j}}{\sum_{k=1}^{N_{bones}} \hat{w}_{i,k}} $$
    [S2]

3.  **Rigid Deformation (LBS):** Compute the rigidly transformed position $\mathbf{p}_{rigid}$ using the normalized skinning weights and precomputed bone transforms:
    $$ \mathbf{p}_{rigid} = \sum_{j=1}^{N_{bones}} w'_{i,j} \mathbf{T}_j(\theta) \mathbf{p}_i $$
    [S1, S2]

4.  **Non-Rigid Deformation:** Compute a residual offset $\Delta \mathbf{p}$ using a deformation network (MLP) conditioned on the canonical position $\mathbf{p}_i$ and the pose $\theta$:
    $$ \Delta \mathbf{p} = \text{MLP}(\mathbf{p}_i, \theta) $$
    [S1]

5.  **Final Position:**
    $$ \mathbf{p}'_i = \mathbf{p}_{rigid} + \Delta \mathbf{p} $$
    [S1]

6.  **Covariance Update:** Transform the covariance matrix $\Sigma_i$ using the Jacobian $J$ of the deformation map with respect to the canonical position. The Jacobian $J$ is the derivative of the total deformation (LBS + MLP) with respect to $\mathbf{p}_i$:
    $$ J = \frac{\partial \mathbf{p}'_i}{\partial \mathbf{p}_i} $$
    $$ \Sigma'_i = J \Sigma_i J^T + \sigma^2 I $$
    where $\sigma^2 I$ is a small regularization term to ensure positive definiteness [G].

7.  **Rendering and Loss:** Render the deformed Gaussians using differentiable splatting. Compute loss $\mathcal{L}$ combining photometric error ($\mathcal{L}_{L1}$), perceptual metrics ($\mathcal{L}_{MS-SSIM}$, $\mathcal{L}_{LPIPS}$), and potentially regularization terms for skinning weights or mesh consistency [S2].

**Parameters:**
*   Learning rate for MLP and skinning weights $\mathbf{w}$: $10^{-4}$ [S2].
*   Learning rate for latent codes (if used): $2.5 \times 10^{-3}$ [S2].
*   Loss weights (typical): $\lambda_{L1}=0.8$, $\lambda_{SSIM}=0.2$, $\lambda_{LPIPS}=0.05$ [S2].

**Edge Cases and Pitfalls:**
*   **Negative Weights:** Raw optimized skinning weights can be negative; ReLU and normalization are required to prevent invalid blending [S2].
*   **Pose Blend Shapes:** Using SMPL pose blend shapes before deformation can introduce inaccuracies; it is recommended to rely on the MLP for pose-dependent deformations instead [S2].
*   **Jacobian Computation:** The Jacobian $J$ must include contributions from both the LBS term and the MLP term to correctly transform the covariance [G].

## Subtopics

### Linear Blend Skinning for Gaussian Splatting
A specific implementation of the rigid deformation component where LBS is applied directly to canonical Gaussians using precomputed rigid joint transformations and learnable per-Gaussian skinning weights [S2]. It avoids pose blend shapes and template vertex deformation, relying on an MLP for pose-dependent deformations instead [S2]. It is chosen when computational efficiency in precomputing transforms is prioritized and when avoiding inaccuracies from SMPL blend shapes is critical [S2].

## Operating characteristics
*   **Time Complexity:** Rendering is $O(N)$ where $N$ is the number of Gaussians. Deformation is $O(N \cdot N_{bones})$ for LBS plus $O(N)$ for the MLP. Precomputing transforms is $O(N_{poses} \cdot N_{bones})$.
*   **Memory Complexity:** $O(N \cdot (D_{pos} + D_{cov} + D_{sh} + N_{bones}))$ for storing Gaussians and skinning weights.
*   **Strengths:** Enables real-time rendering of animatable avatars; maintains structural integrity through parametric priors; handles large articulations via LBS [S1, S2].
*   **Limitations:** Accuracy depends on the quality of the SMPL model and skinning weights; non-rigid details (muscle jiggles) require a capable deformation network [S1].
*   **When to use:** Full-body human avatars requiring animation in novel poses [S1].
*   **When not to use:** Head-centric avatars requiring fine facial details (use [Gaussian Avatar](1479-gaussian-avatar.md) or similar) [S1].

## Background
Full-body avatar modeling using 3D Gaussians has emerged as a powerful tool for VR and social applications, advancing along two main directions: full-body and head-centric modeling [S1]. The hybrid deformation strategy, combining LBS and pose-conditioned fields, was introduced to handle the complex dynamics of full-body motion [S1]. Key works include "Human Gaussian Splatting" which details the LBS implementation for Gaussians [S2], and broader surveys categorizing these methods [S1].
