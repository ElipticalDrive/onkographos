# Full-body Avatar Modeling

Also called: Hybrid Deformation Strategy for 3D Gaussians

## Overview
Full-body Avatar Modeling anchors 3D Gaussians in a canonical space and deforms them via parametric body models (e.g., SMPL) or cage-based rigging to model dynamic human motions [S1]. It solves the problem of reconstructing animatable, high-fidelity human avatars from multi-view video by combining rigid skeletal transformations with non-rigid residual deformations [S1]. Unlike head-centric modeling which focuses on facial expressions and fine-grained geometry (e.g., wrinkles, hair) using FLAME models [S1], this method targets full-body dynamics, leveraging the speed and editability of Gaussian Splatting [S1]. It builds on [SMPL-based rigid/non-rigid deformation](8385-smpl-based-rigid-non-rigid-deformation.md).

## How it works
**Inputs:** Multi-view video frames of a human subject; a parametric body model (e.g., SMPL) providing skeleton and mesh topology; camera poses and intrinsics.
**Outputs:** A set of 3D Gaussians defined in canonical space, each with position $\mathbf{p}$, covariance $\Sigma$, opacity $\alpha$, spherical harmonics coefficients for color, and learnable parameters for deformation (skinning weights, MLP weights).

**Data Structures:**
1.  **Gaussian Attributes:**
    *   $\mathbf{p} \in \mathbb{R}^3$: Canonical position.
    *   $\Sigma \in \mathbb{R}^{3 \times 3}$: Covariance matrix.
    *   $\alpha \in \mathbb{R}$: Opacity.
    *   $\mathbf{c} \in \mathbb{R}^k$: Color coefficients (spherical harmonics).
    *   $\mathbf{w} \in \mathbb{R}^{N_{bones}}$: Learnable skinning weights vector.
    *   $\mathbf{l} \in \mathbb{R}^{d_l}$: Optional latent code for pose-dependent deformation [S2].
2.  **Deformation Network (MLP):**
    *   Input: Canonical position $\mathbf{p}$, pose parameters $\theta$, and optionally latent code $\mathbf{l}$ [S2].
    *   Output: Non-rigid residual offset $\Delta \mathbf{p} \in \mathbb{R}^3$.
3.  **Precomputed Joint Transforms:**
    *   $M_{j,t} \in \mathbb{R}^{4 \times 4}$: Rigid transformation matrix for joint $j$ at timestep $t$ [S2].

**Steps:**

1.  **Initialization:** Initialize 3D Gaussians on the surface of the parametric mesh (e.g., SMPL) in the canonical rest pose [S1, 1477-gaussian-avatars.md, 1482-relightable-gaussian-codec-avatars.md]. Initialize skinning weights $\mathbf{w}$ and MLP parameters.

2.  **Precompute Rigid Transforms:** For each training timestep $t$ and target pose $\theta_t$, compute the rigid transformation matrices $M_{j,t}$ for each body joint $j$ based on the parametric model [S2]. This is done once per pose sequence to improve efficiency [S2].

3.  **Rigid Deformation (LBS):** For each Gaussian $i$ at canonical position $\mathbf{p}_i$:
    a. Apply ReLU activation to the skinning weights vector $\mathbf{w}_i$ to ensure non-negativity: $\mathbf{w}_i^+ = \text{ReLU}(\mathbf{w}_i)$ [S2].
    b. Normalize the weights to sum to 1: $\hat{\mathbf{w}}_i = \frac{\mathbf{w}_i^+}{\sum_k \mathbf{w}_{i,k}^+}$ [S2].
    c. Compute the rigidly transformed position $\mathbf{p}_{rigid}$ using Linear Blend Skinning (LBS) [S1, S2]:
       $$ \mathbf{p}_{rigid} = \sum_{j=1}^{N_{bones}} \hat{w}_{i,j} M_{j,t} \mathbf{p}_i $$
       Note: Pose blend shapes are explicitly excluded because shape estimation and obtained blend shapes may be inaccurate; the MLP handles pose-dependent deformations instead [S2].

4.  **Non-Rigid Deformation:** Pass the canonical position $\mathbf{p}_i$, pose parameters $\theta_t$, and optional latent code $\mathbf{l}_i$ into the deformation MLP to predict the residual offset $\Delta \mathbf{p}_i$ [S2].
    $$ \Delta \mathbf{p}_i = \text{MLP}(\mathbf{p}_i, \theta_t, \mathbf{l}_i) $$

5.  **Final Position and Covariance Update:**
    a. Compute the final deformed position:
       $$ \mathbf{p}'_i = \mathbf{p}_{rigid} + \Delta \mathbf{p}_i $$
    b. Compute the Jacobian $J_i$ of the deformation map with respect to $\mathbf{p}_i$ via automatic differentiation through the MLP and LBS [G].
    c. Update the covariance matrix:
       $$ \Sigma'_i = J_i \Sigma_i J_i^T + \sigma^2 I $$
       where $\sigma^2 I$ is a small regularization term to ensure positive definiteness [G].

6.  **Differentiable Rendering:** Render the deformed Gaussians using 3D Gaussian Splatting [S1, 1479-gaussian-avatar.md, 1480-3dgs-avatar.md, 6157-animatable-gaussians.md]. The rendering process is differentiable with respect to Gaussian parameters and network weights [S1, 6136-instantsplat.md, 6464-pixelsplat.md].

7.  **Loss Computation and Optimization:** Minimize a combination of losses [6136-instantsplat.md, 6464-pixelsplat.md]:
    $$ \mathcal{L} = \lambda_{L1}\mathcal{L}_{L1} + \lambda_{ssim}\mathcal{L}_{MS-SSIM} + \lambda_{lpips}\mathcal{L}_{LPIPS} + \lambda_{trans}\mathcal{L}_{trans} + \lambda_{rot}\mathcal{L}_{rot} + \lambda_{s}\mathcal{L}_{s} + \lambda_{mesh}\mathcal{L}_{mesh} + \lambda_{skn}\mathcal{L}_{skn} $$
    Typical values for hyperparameters [S2]:
    *   $\lambda_{L1} = 0.8$
    *   $\lambda_{ssim} = 0.2$
    *   $\lambda_{lpips} = 0.05$
    *   $\lambda_{trans} = 0.01$
    *   $\lambda_{rot} = 0.001$
    *   $\lambda_{s} = 0.001$
    *   $\lambda_{mesh} = 0.1$
    *   $\lambda_{skn} = 0.001$
    *   Dimension of latent code $l = 16$

    Optimization uses different learning rates [S2]:
    *   MLP and skinning weights $\mathbf{w}$: $1 \times 10^{-4}$
    *   Latent codes $\mathbf{l}$: $2.5 \times 10^{-3}$
    *   Original Gaussian parameters (position, orientation, scaling, colors, opacity): Unchanged from standard 3D-GS [S2].

**Edge Cases and Pitfalls:**
*   **Negative Weights:** Initial optimization of $\mathbf{w}$ can lead to negative values; ReLU activation is required before normalization [S2].
*   **Blend Shape Inaccuracy:** Using pose blend shapes from the parametric model is discouraged due to potential inaccuracies in shape estimation; rely on the MLP for pose-dependent deformations [S2].
*   **Template Vertex Deformation:** Not necessary as LBS is applied directly on canonical Gaussians [S2].

## Subtopics

### Linear Blend Skinning for Gaussian Splatting
A deformation technique applied to canonical 3D Gaussians to drive human avatars, using precomputed rigid joint transformations and learnable per-Gaussian skinning weights, avoiding pose blend shapes and template vertex deformation [S2]. It is chosen when high-fidelity rigid skeletal motion is required without relying on potentially inaccurate pre-computed blend shapes from the parametric model [S2].

## Operating characteristics
*   **Time Complexity:** Rendering is $O(N)$ where $N$ is the number of Gaussians, similar to standard 3D Gaussian Splatting. Deformation computation is $O(N \cdot N_{bones})$ for LBS plus $O(N)$ for the MLP. Precomputing joint transforms is done once per pose [S2].
*   **Memory Complexity:** $O(N \cdot (d_p + d_\Sigma + d_c + d_w + d_l))$ where $d$ denotes dimensionality of attributes. Additional memory for MLP weights and latent codes [S2].
*   **Measured Performance:** Real-time rendering is achievable, as indicated by the use of "Real-Time Rendering" in related titles [S2]. Specific FPS numbers depend on hardware and resolution.
*   **Strengths:** High fidelity, real-time rendering capability, editability, handles complex non-rigid deformations via MLP [S1, S2].
*   **Limitations:** Requires careful tuning of learning rates and regularization terms; MLP inference adds computational overhead compared to pure LBS [S2].
*   **When to use:** Full-body avatar reconstruction from multi-view video where dynamic motion and high visual quality are required.
*   **When not to use:** Head-centric modeling with intricate facial expressions (use [Gaussian Avatar](1479-gaussian-avatar.md) or similar); static scene reconstruction.

## Background
Originated from the application of 3D Gaussian Splatting to human avatar reconstruction, advancing along two directions: full-body and head-centric modeling [S1]. Full-body methods typically anchor Gaussians in canonical space and deform them via parametric body models or cage-based rigging [S1]. The hybrid deformation strategy (LBS + MLP) is a key component in this approach [S1]. Related works include Gaussian Avatar [1479-gaussian-avatar.md], 3DGS-Avatar [1480-3dgs-avatar.md], Animatable Gaussians [6157-animatable-gaussians.md], and UV-based motion parameterization [11653-uv-based-motion-parameterization.md].
