# SMPL-based rigid/non-rigid deformation

Also called: SMPL-based deformation, SMPL-Gaussian deformation

## Overview
This family of methods reconstructs animatable 3D human avatars by anchoring 3D Gaussians to the SMPL parametric mesh prior [S1, 1477-gaussian-avatars.md, 1482-relightable-gaussian-codec-avatars.md]. It solves the problem of generating high-fidelity, pose-controllable avatars from video data by ensuring structural integrity during animation through rigid skeletal transformations and/or non-rigid deformation fields [S1, 8385-smpl-based-rigid-non-rigid-deformation.md]. It sets itself apart from sibling methods like [Gaussian Splatting](946-gaussian-splatting.md) by explicitly binding Gaussians to a parametric body model rather than treating them as independent entities, and from [Gaussian Avatars](1477-gaussian-avatars.md) by providing the underlying deformation mechanism (rigid/non-rigid hybrid) that many children implement or extend.

## Shared principles
All methods in this family rely on differentiable rendering to compute gradients from the rendered image to the Gaussian parameters (position, covariance, opacity, spherical harmonics) and/or network weights [S1, 6136-instantsplat.md, 6464-pixelsplat.md]. The rendering process remains differentiable with respect to the scene representation [S1, 6136-instantsplat.md, 6464-pixelsplat.md]. Loss functions typically combine photometric reconstruction error, such as $\mathcal{L}_{L1}$ or $\mathcal{L}_{MSE}$, with perceptual or structural metrics like $\mathcal{L}_{MS-SSIM}$ or $\mathcal{L}_{LPIPS}$ [6136-instantsplat.md][6464-pixelsplat.md].

A core principle is the anchoring of Gaussians to a geometric prior. Most methods initialize Gaussians on the surface of a parametric mesh (e.g., SMPL for full body, FLAME for heads) in a canonical rest pose [S1, 1477-gaussian-avatars.md, 1482-relightable-gaussian-codec-avatars.md]. During training, these Gaussians are deformed to match the target pose using rigid transformations (e.g., Linear Blend Skinning) and/or non-rigid deformation fields [S1, 8385-smpl-based-rigid-non-rigid-deformation.md]. This ensures that the avatar can be animated to novel poses while maintaining structural integrity [S1].

The deformation pipeline generally follows these steps:
1.  **Initialization:** Gaussians $\{g_i\}$ are initialized on the canonical SMPL mesh surface. Each Gaussian $i$ has a canonical position $\mathbf{p}_i$, covariance $\Sigma_i$, opacity $\alpha_i$, and appearance coefficients (e.g., Spherical Harmonics $\mathbf{c}_i$ or MLP weights) [S1, 1477-gaussian-avatars.md, 1480-3dgs-avatar.md, 6157-animatable-gaussians.md, 11805-full-body-avatar-modeling.md].
2.  **Rigid Deformation:** The canonical position is transformed using Linear Blend Skinning (LBS) based on the target pose $\theta$ [S1, 1480-3dgs-avatar.md, 6157-animatable-gaussians.md, 11653-uv-based-motion-parameterization.md, 11805-full-body-avatar-modeling.md]:
    $$ \mathbf{p}_{rigid} = \sum_{j=1}^{N_{bones}} w_{i,j} \mathbf{T}_j(\theta) \mathbf{p}_i $$
    where $w_{i,j}$ are skinning weights and $\mathbf{T}_j(\theta)$ are bone transformation matrices [S1, 1480-3dgs-avatar.md, 6157-animatable-gaussians.md, 11805-full-body-avatar-modeling.md].
3.  **Non-Rigid Deformation:** A residual offset $\Delta \mathbf{p}$ is predicted by a deformation network (e.g., MLP) conditioned on pose and/or canonical position [S1, 1480-3dgs-avatar.md, 6157-animatable-gaussians.md, 11653-uv-based-motion-parameterization.md, 11805-full-body-avatar-modeling.md]. The final position is:
    $$ \mathbf{p}'_i = \mathbf{p}_{rigid} + \Delta \mathbf{p} $$
    Some methods, like [Gaussian Avatar](1479-gaussian-avatar.md), predict parameters directly via a feedforward network, implicitly handling deformation [S1, 1479-gaussian-avatar.md].
4.  **Covariance Update:** The covariance matrix is transformed using the Jacobian $J$ of the deformation map with respect to the canonical position [G]:
    $$ \Sigma'_i = J \Sigma_i J^T + \sigma^2 I $$
    where $\sigma^2 I$ is a small regularization term to ensure positive definiteness [G]. The Jacobian $J$ includes contributions from both LBS and the non-rigid deformation network [G, 11805-full-body-avatar-modeling.md].
5.  **Rendering:** The deformed Gaussians are rendered using differentiable 3D Gaussian Splatting [S1, 1477-gaussian-avatars.md, 1480-3dgs-avatar.md, 6157-animatable-gaussians.md, 11805-full-body-avatar-modeling.md].

## Subtopics

### [Gaussian Avatar](1479-gaussian-avatar.md)
Gaussian Avatar reconstructs animatable full-body human avatars by anchoring 3D Gaussians to the SMPL parametric mesh prior. It solves the problem of generating high-fidelity, pose-controllable avatars from monocular video by predicting Gaussian parameters via a feedforward network conditioned on pose features. It sets itself apart from siblings like [3DGS-Avatar](1480-3dgs-avatar.md) by relying primarily on a feedforward network for parameter prediction rather than explicit per-Gaussian deformation MLPs or rigid/non-rigid hybrid transformations for position updates.

### [3DGS-Avatar](1480-3dgs-avatar.md)
3DGS-Avatar reconstructs photorealistic, animatable full-body human avatars by anchoring 3D Gaussians to an underlying SMPL model. It distinguishes itself from sibling methods by replacing spherical harmonics with a shallow Multi-Layer Perceptron (MLP) to model per-Gaussian color, enabling the capture of pose-dependent cloth deformation and novel pose generalization.

### [Animatable Gaussians](6157-animatable-gaussians.md)
Animatable Gaussians is a method for reconstructing animatable 3D human avatars from multi-view video by binding 3D Gaussians to an SMPL-X parametric model. It solves the problem of generating high-fidelity, pose-dependent geometry by using explicit pose-conditioned offsets rather than implicit deformation fields. It is distinguished from siblings like [3DGS-Avatar](1480-3dgs-avatar.md) by its use of explicit offsets instead of per-Gaussian MLPs, and from [Gaussian Avatar](1479-gaussian-avatar.md) by its reliance on the SMPL-X rig rather than FLAME for full-body representation.

### [UV-based motion parameterization](11653-uv-based-motion-parameterization.md)
UV-based motion parameterization is a method for modeling dynamic human deformation by reparameterizing 3D spatial coordinates into 2D surface-level UV coordinates combined with time. It solves the problem of high-dimensional motion field learning by exploiting the prior that human motion occurs primarily at the surface level, reducing the input dimensionality from 4D space-time $(x, y, z, t)$ to 3D surface-time $(u, v, t)$. This approach is distinct from volumetric parameterizations (e.g., using raw 3D coordinates) because it leverages the parametric mesh's surface topology to enforce spatial coherence among nearby surface points, resulting in significantly lower memory usage and faster convergence.

### [Full-body Avatar Modeling](11805-full-body-avatar-modeling.md)
Full-body Avatar Modeling anchors 3D Gaussians in a canonical space and deforms them via parametric body models (e.g., SMPL) or cage-based rigging to model dynamic human motions. It employs a hybrid deformation strategy that combines linear blend skinning (LBS) for rigid skeletal transformations with pose-conditioned deformation fields for non-rigid secondary effects. This approach distinguishes itself from head-centric modeling by focusing on full-body structural integrity and large-scale articulation rather than fine-grained facial expressions.

## Background
The integration of parametric human models (SMPL) with 3D Gaussian Splatting emerged to address the limitations of unstructured Gaussian representations in animatable avatar reconstruction. Early methods struggled with pose generalization and structural coherence. By anchoring Gaussians to SMPL, methods leverage the well-established rigging and deformation capabilities of SMPL for rigid body parts while using learned fields for non-rigid details. This family builds on [Gaussian Avatar Reconstruction](1575-gaussian-avatar-reconstruction.md) by providing the specific deformation mechanisms (rigid LBS and non-rigid residuals) that enable animatable rendering.
