# Splatt3R Training Procedure with Loss Masking

Also called: Splatt3R Training, Loss-Masked Gaussian Splatting Training

## Overview
This method defines the training pipeline for Splatt3R, a feed-forward model that predicts 3D Gaussian primitives directly from uncalibrated stereo image pairs to enable real-time novel view synthesis [S1, unofficial]. It distinguishes itself from sibling methods like [pixelSplat](6464-pixelsplat.md) by eliminating explicit pose regression overhead and using a specific loss masking strategy to prevent the model from hallucinating geometry in regions occluded from the context views [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A batch of context image pairs (two input images) and target images (three novel view images) sampled from a scene [S1, unofficial].
*   **Output:** Predicted 3D Gaussian parameters (position, scale, rotation, opacity, color) and rendered RGB images for the target views [G].

**Data Structures**
*   **Gaussian Primitives:** Defined by position $\mathbf{p} \in \mathbb{R}^3$, scale $\mathbf{s} \in \mathbb{R}^3$, rotation $\mathbf{q} \in \mathbb{R}^4$ (quaternion), opacity $\alpha \in [0, 1]$, and spherical harmonics coefficients for color [G].
*   **Loss Mask:** A binary mask $M \in \{0, 1\}^{H \times W}$ indicating valid pixels for supervision [G].

**Parameters**
*   $\phi = 0.3$: Minimum fraction of pixels in the second context image with direct correspondences in the first [S1, unofficial].
*   $\psi = 0.3$: Minimum fraction of pixels in target images present in at least one context image [S1, unofficial].
*   $\lambda_{\text{MSE}} = 1.0$: Weight for Mean Squared Error loss [S1, unofficial].
*   $\lambda_{\text{LPIPS}} = 0.25$: Weight for LPIPS perceptual loss [S1, unofficial].
*   Optimizer: Adam, learning rate $1.0 \times 10^{-5}$, weight decay $0.05$, gradient clipping norm $0.5$ [S1, unofficial].
*   Resolution: $512 \times 512$ pixels [S1, unofficial].
*   Epochs: 2000 (approx. 500,000 iterations) [S1, unofficial].

**Steps**
1.  **Sampling:** For each training step, randomly sample two context images and three target images from a scene in the training split (e.g., ScanNet++) [S1, unofficial].
2.  **View Selection:** Select target view positions such that the angular parameters $\phi$ and $\psi$ are satisfied, ensuring sufficient overlap between context and target views [S1, unofficial].
3.  **Forward Pass:** Render the predicted 3D Gaussians at $512 \times 512$ resolution for each target view using differentiable splatting [S1, unofficial].
4.  **Mask Generation:** Generate a loss mask $M$ that identifies pixels in the target view that are visible from the context views. Pixels not visible in any context view are masked out [G].
5.  **Loss Computation:** Compute the reconstruction loss between the rendered image $I_{\text{render}}$ and the target image $I_{\text{target}}$:
    $$ L = \lambda_{\text{MSE}} \cdot \text{MSE}(I_{\text{render}}, I_{\text{target}}) + \lambda_{\text{LPIPS}} \cdot \text{LPIPS}(I_{\text{render}}, I_{\text{target}}) $$
    The loss is computed only on pixels where $M=1$. Metrics (PSNR, LPIPS) are reported both across the entire image and averaged across just the pixels in the loss mask [S1, unofficial].
6.  **Backpropagation:** Apply the loss mask to the gradients before backpropagating to update the Gaussian parameters [S1, unofficial].

**Pseudocode**
```python
def train_step(context_images, target_images, model, optimizer):
    # 1. Forward pass: predict Gaussians from context images
    gaussians = model.encode(context_images)
    
    # 2. Render target views
    rendered_images = []
    for target_view in target_images:
        # Render using differentiable splatting
        img = render_splats(gaussians, target_view.projection_matrix, target_view.camera_matrix)
        rendered_images.append(img)
    
    # 3. Compute Loss Mask
    # Mask M identifies pixels visible from context views.
    # Implementation detail: M is derived from visibility checks or correspondence overlap [G]
    masks = compute_visibility_masks(context_images, target_images, gaussians)
    
    # 4. Compute Loss with Masking
    total_loss = 0.0
    for rendered_img, target_img, mask in zip(rendered_images, target_images, masks):
        # Apply mask to images (zero out masked regions)
        masked_rendered = rendered_img * mask
        masked_target = target_img * mask
        
        # Compute MSE and LPIPS on masked regions
        mse_loss = mean_squared_error(masked_rendered, masked_target)
        lpips_loss = perceptual_loss(masked_rendered, masked_target)
        
        # Weighted sum
        loss = 1.0 * mse_loss + 0.25 * lpips_loss
        total_loss += loss
    
    # 5. Backpropagation
    optimizer.zero_grad()
    total_loss.backward()
    
    # Gradient clipping
    clip_gradients(model.parameters(), max_norm=0.5)
    optimizer.step()
    
    return total_loss

# Standard helper definitions
def mean_squared_error(a, b):
    return sum((a[i] - b[i])**2 for i in range(len(a))) / len(a)

def perceptual_loss(a, b):
    # LPIPS computes perceptual distance using a pretrained network [G]
    return sum(abs(a[i] - b[i]) for i in range(len(a))) / len(a)

def clip_gradients(params, max_norm):
    # Clips gradient norms to max_norm [G]
    for p in params:
        if p.grad is not None:
            norm = sum(g**2 for g in p.grad) ** 0.5
            if norm > max_norm:
                p.grad = [g * (max_norm / norm) for g in p.grad]
```

**Edge Cases and Pitfalls**
*   **Unbounded Gaussian Growth:** Omitting the loss masking strategy causes Gaussian sizes to grow unboundedly, eventually exhausting VRAM and halting training [S1, unofficial].
*   **Hallucination:** Without masking, the model attempts to reconstruct areas not visible to the context views, leading to poor accuracy and artifacts [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The method runs at approximately 4 FPS for full scene reconstruction at $512 \times 512$ resolution on an NVIDIA RTX 2080 Ti [S1, unofficial].
*   **Memory Complexity:** VRAM usage is sensitive to the loss masking; without it, memory consumption grows unboundedly due to Gaussian size explosion [S1, unofficial].
*   **Strengths:** Eliminates explicit pose estimation overhead by predicting all Gaussians in a shared coordinate space [S1, unofficial]. Generalizes well to in-the-wild data captured by mobile phones [S1, unofficial].
*   **Limitations:** Not given in the sources.
*   **When to Use:** Suitable for feed-forward 3D reconstruction from uncalibrated stereo pairs where real-time rendering is required and camera poses are unknown [S1, unofficial].
*   **When Not to Use:** Not suitable for scenarios requiring explicit pose estimation or when ground truth poses are available and can be leveraged for higher accuracy (e.g., [pixelSplat](6464-pixelsplat.md) with GT poses) [S1, unofficial].

## Background
Splatt3R was introduced as a feed-forward generalizable model for generating 3D Gaussian Splats from uncalibrated stereo images [S1, unofficial]. It builds on the MASt3R architecture, which provides robust feature matching, and adapts it to predict 3D Gaussian parameters directly [S1, unofficial]. The method was evaluated on the ScanNet++ dataset and in-the-wild mobile captures [S1, unofficial]. It represents a shift from traditional multi-view stereo systems that rely on explicit pose estimation and depth information [S1, unofficial].
