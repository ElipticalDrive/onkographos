# pixelSplat

Also called: DepthSplat, A method connecting Gaussian splatting and depth estimation by leveraging pre-trained monocular depth features to augment multi-view feature matching, enabling robust multi-view depth prediction and feed-forward 3D Gaussian splatting reconstruction

## Overview
pixelSplat is a single-shot sparse-view Gaussian reconstruction method that avoids committing to a single deterministic depth estimate by predicting a depth distribution and differentiably sampling from it [S1]. It sets itself apart from sibling methods like MVSplat, which relies on plane-sweep cost volumes, and DepthSplat, which augments multi-view matching with monocular depth features, by explicitly modeling depth uncertainty through probabilistic sampling [S1]. This approach provides a more flexible treatment of geometry, particularly in ambiguous regions where deterministic regression might fail [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of $N$ calibrated input views. For each view $i$, the inputs are the image features $f_i(u)$, camera intrinsic matrix $K_i$, and camera pose $T_i$.
*   **Outputs:** A set of 3D Gaussians defined by their means $\mu_i(u)$, covariances $\Sigma_i$, alphas $\alpha_i$, and colors $c_i$ for each pixel $u$ in the input views.

**Data Structures**
*   **Depth Distribution $p_i(d|u)$:** A probability distribution over depth values $d$ for each pixel $u$ in view $i$. The specific parameterization (e.g., mixture of Gaussians, discretized histogram) is not detailed in the sources [S1].
*   **Sampled Depth $d_i$:** A depth value sampled from $p_i(d|u)$.

**Steps**
1.  **Feature Extraction:** Extract features $f_i(u)$ from each input view $i$.
2.  **Depth Distribution Prediction:** Predict the depth distribution $p_i(d|u)$ for each pixel $u$ in view $i$. The sources do not specify the neural network architecture used for this prediction [S1].
3.  **Differentiable Sampling:** Sample a depth value $d_i$ from the predicted distribution $p_i(d|u)$ using a differentiable sampling operation (e.g., Gumbel-Softmax or straight-through estimator) [S1]:
    $$ d_i \sim p_i(d | u) $$
4.  **Gaussian Unprojection:** Unproject the sampled depth $d_i$ and pixel coordinate $u$ into 3D space to obtain the Gaussian mean $\mu_i(u)$ using the camera intrinsics $K_i$ and poses $T_i$ [S1]:
    $$ \mu_i(u) = \pi^{-1}(u, d_i; K_i, T_i) $$
    where $\pi^{-1}$ is the unprojection function.
5.  **Gaussian Parameter Prediction:** Predict the remaining Gaussian parameters (covariance $\Sigma_i$, alpha $\alpha_i$, color $c_i$) using a network $H_\theta$ conditioned on the input features $f_i(u)$ [S1]:
    $$ (\Sigma_i, \alpha_i, c_i) = H_\theta(f_i(u)) $$
    The sources do not specify the architecture of $H_\theta$ [S1].

**Parameters**
*   **Resolution:** The method is evaluated at 256x256 resolution [S1].
*   **Context Views:** The method is evaluated using 2 context views [S1].
*   **Target Views:** The method is evaluated predicting 3 target views [S1].

**Edge Cases and Pitfalls**
*   **Depth Ambiguity:** The probabilistic sampling approach is designed to handle geometric ambiguity better than deterministic methods, but the specific failure modes of the sampling process are not detailed [S1].
*   **Calibration:** The method assumes calibrated input views with known $K_i$ and $T_i$ [S1].

**Pseudocode**
```python
def pixel_splat_reconstruct(input_views):
    """
    Reconstructs 3D Gaussians from sparse input views using pixelSplat.
    
    Args:
        input_views: List of dictionaries, each containing:
            - 'image': Input image tensor
            - 'K': Camera intrinsic matrix
            - 'T': Camera pose matrix
            
    Returns:
        gaussians: List of Gaussian objects with mean, covariance, alpha, color
    """
    gaussians = []
    
    for view in input_views:
        image = view['image']
        K = view['K']
        T = view['T']
        
        # Step 1: Feature Extraction
        # Architecture of feature extractor not specified in sources [S1]
        features = extract_features(image)
        
        # Step 2: Depth Distribution Prediction
        # Architecture of depth distribution predictor not specified in sources [S1]
        depth_distribution = predict_depth_distribution(features)
        
        # Step 3: Differentiable Sampling
        # Sample depth from distribution. Implementation of differentiable sampler not specified [S1]
        sampled_depth = sample_depth(depth_distribution)
        
        # Step 4: Gaussian Unprojection
        # Get pixel coordinates for each pixel in the image
        pixel_coords = get_pixel_coordinates(image.shape)
        
        # Unproject to 3D
        # pi_inv is the unprojection function using K and T
        gaussian_means = unproject(pixel_coords, sampled_depth, K, T)
        
        # Step 5: Gaussian Parameter Prediction
        # Architecture of H_theta not specified in sources [S1]
        covariances, alphas, colors = predict_gaussian_params(features)
        
        # Create Gaussian objects
        for i in range(len(gaussian_means)):
            gaussian = Gaussian(
                mean=gaussian_means[i],
                covariance=covariances[i],
                alpha=alphas[i],
                color=colors[i]
            )
            gaussians.append(gaussian)
            
    return gaussians
```

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On RealEstate10K with 2 context views, 3 target views, 256x256 resolution, and NVIDIA A100 GPU: PSNR 26.40, SSIM 0.873, LPIPS 0.127, Model-stage latency 120.57 ms, Model-stage scene/s 8.29, rFPS 462.29, GPU memory 2.77 GiB [S1].
*   **Scaling:** Not given in the sources.
*   **Strengths and Limitations:** The probabilistic sampling allows for a more flexible treatment of geometry compared to deterministic methods [S1]. However, it has higher model-stage latency and GPU memory usage compared to MVSplat [S1].
*   **When to use it:** Use when dealing with sparse-view reconstruction where geometric ambiguity is high and a probabilistic depth estimate is beneficial [S1].
*   **When not:** Use MVSplat or DepthSplat if lower latency and memory usage are critical and geometric ambiguity is less of a concern [S1].

## Background
pixelSplat was introduced as a single-shot sparse-view Gaussian reconstruction method [S1]. It is part of the family of methods that connect Gaussian splatting and depth estimation [S1]. The method was evaluated on the RealEstate10K dataset [S1].
