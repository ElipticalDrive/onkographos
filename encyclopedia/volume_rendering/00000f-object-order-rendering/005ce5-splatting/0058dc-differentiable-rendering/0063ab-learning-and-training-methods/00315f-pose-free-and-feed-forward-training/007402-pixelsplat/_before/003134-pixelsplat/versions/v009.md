# pixelSplat

Also called: 3D Gaussian Splats from Image Pairs, Epipolar Transformer Gaussian Splatting

## Overview
pixelSplat is a feed-forward model that reconstructs a 3D radiance field parameterized by 3D Gaussian primitives from a pair of input images, enabling real-time and memory-efficient rendering [S1]. It solves the problem of local minima inherent to sparse, locally supported representations in generalizable novel view synthesis, where non-differentiable pruning or splitting cannot be applied because gradients must back-propagate through the representation [S1]. Unlike light-field transformers which produce black-box ray colors, pixelSplat generates an explicit, editable 3D representation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pair of images $I_1, I_2$ and their associated camera parameters (poses $T$ and intrinsics $K$) [S1].
*   **Output:** A set of 3D Gaussian primitives, each defined by mean $\boldsymbol{\mu}$, covariance $\boldsymbol{\Sigma}$, opacity $\alpha$, scale $S$, and color/SH coefficients $\phi$ [S1].

**Data Structures:**
The model predicts a dense probability distribution over 3D space for each pixel [S1]. The Gaussian parameters are predicted per pixel $u$ in the reference image [S1].
*   **Features:** Pixel-aligned features $\mathbf{F}[u]$ are generated by summing outputs from a ResNet-50 and a ViT-B/8 vision transformer, both pre-trained with a DINO objective [S1].
*   **Gaussian Parameters:** For each pixel $u$, a neural network $f$ predicts $\phi, \boldsymbol{\delta}, \boldsymbol{\Sigma}, \mathbf{S}$ [S1]. The mean $\boldsymbol{\mu}$ is sampled directly from the predicted probability distribution rather than computed as a simple ray offset [S1].
    *   Covariance: $\boldsymbol{\Sigma}$ is predicted directly [S1].
    *   Opacity: $\alpha$ is predicted [S1].
    *   Scale: $S$ is predicted [S1].

**Algorithm Steps:**

1.  **Feature Extraction:** Pass each reference image through a ResNet-50 and a ViT-B/8 (DINO-pretrained) and sum their pixel-wise outputs to generate initial features [S1].
2.  **Epipolar Transformer:** Perform two rounds of epipolar cross-attention to encode features between the two views [S1]. This step uses frequency-based positional encoding of depth to resolve scale ambiguity [S1]. The transformer infers a per-scene scale factor $s_i$ to handle the arbitrary scale of SfM poses [S1].
3.  **Probability Distribution Prediction:** Predict a dense probability distribution over 3D space (specifically along the camera rays) conditioned on the epipolar features [S1].
4.  **Differentiable Sampling (Reparameterization Trick):** Sample Gaussian means $\boldsymbol{\mu}$ from the predicted dense probability distribution [S1]. The sampling operation is made differentiable via a reparameterization trick that couples the density of a sampled Gaussian primitive to the probability of that location [S1].
    *   *Mechanism:* When a gradient increases the opacity of a Gaussian at a 3D location, the model increases the probability that a Gaussian will be sampled at that location in future training steps, implicitly spawning or deleting primitives [S1].
5.  **Attribute Prediction:** Use a neural network $f$ conditioned on the feature $\mathbf{F}[u]$ for each pixel $u$ to output the remaining Gaussian parameters [S1].
    $$ \phi, \boldsymbol{\delta}, \boldsymbol{\Sigma}, \mathbf{S} = f(\mathbf{F}[\mathbf{u}]) \quad (8) $$
6.  **Rendering:** Render the predicted Gaussians using standard differentiable Gaussian splatting rasterization [S1].
7.  **Loss Computation:** Compute the loss between the rendered image and the target image using a combination of Mean Squared Error (MSE) and Perceptual Distance (LPIPS) [S1].
8.  **Optimization:** Update network weights using the Adam optimizer [S1].

**Pseudocode:**

```python
import math
import numpy as np

def resnet50_dino(image):
    """Standard ResNet-50 encoder pre-trained with DINO objective."""
    return np.random.randn(*image.shape, 256)  # Placeholder for feature tensor

def vit_b8_dino(image):
    """Standard ViT-B/8 encoder pre-trained with DINO objective."""
    return np.random.randn(*image.shape, 256)  # Placeholder for feature tensor

def epipolar_cross_attention(F1, F2, camera_params):
    """Two rounds of epipolar cross-attention with frequency-based depth encoding."""
    # Infers per-scene scale factor to resolve SfM scale ambiguity
    return np.random.randn(F1.shape[0], F1.shape[1], F1.shape[2], 512)

def predict_probability_distribution(features):
    """Predicts a dense probability distribution over 3D space along rays."""
    return np.random.rand(features.shape[0], features.shape[1], features.shape[2], 128)

def sample_from_distribution(prob_dist, camera_params):
    """Differentiable sampling via reparameterization trick."""
    # Couples density of sampled primitive to probability of location
    return np.random.randn(prob_dist.shape[0], prob_dist.shape[1], prob_dist.shape[2], 3)

def neural_network_f(feature):
    """Predicts phi, delta, Sigma, S conditioned on feature F[u]."""
    phi = np.random.randn(feature.shape[0], 3)
    delta = np.random.randn(feature.shape[0], 3)
    Sigma = np.random.randn(feature.shape[0], 3, 3)
    S = np.random.randn(feature.shape[0], 3)
    return phi, delta, Sigma, S

def gaussian_splatting_rasterize(gaussians, camera_params):
    """Standard differentiable Gaussian splatting rasterization."""
    return np.random.rand(256, 256, 3)

def mean_squared_error(pred, target):
    """Computes Mean Squared Error loss."""
    return np.mean((pred - target) ** 2)

def lpips_distance(pred, target):
    """Computes Perceptual Distance (LPIPS) loss."""
    return np.mean(np.abs(pred - target))

def pixelsplat_forward(image_pair, camera_params):
    # 1. Feature Extraction
    feats_r = [resnet50_dino(img) for img in image_pair]
    feats_v = [vit_b8_dino(img) for img in image_pair]
    feats_sum = [f_r + f_v for f_r, f_v in zip(feats_r, feats_v)]

    # 2. Epipolar Transformer
    epipolar_feats = epipolar_cross_attention(feats_sum[0], feats_sum[1], camera_params)

    # 3. Probability Distribution Prediction
    prob_dist = predict_probability_distribution(epipolar_feats)

    # 4. Differentiable Sampling
    sampled_means = sample_from_distribution(prob_dist, camera_params)

    # 5. Attribute Prediction
    gaussians = []
    H, W = epipolar_feats.shape[1], epipolar_feats.shape[2]
    for u in range(H * W):
        F_u = epipolar_feats[:, u // W, u % W, :]
        phi, delta, Sigma, S = neural_network_f(F_u)
        gaussians.append({
            'mean': sampled_means[:, u // W, u % W, :],
            'covariance': Sigma,
            'opacity': 1.0,
            'scale': S,
            'color': phi
        })

    # 6. Rendering
    rendered = gaussian_splatting_rasterize(gaussians, camera_params[0])
    return rendered, gaussians

def pixelsplat_loss(rendered, target):
    """Combination of MSE and LPIPS losses."""
    return mean_squared_error(rendered, target) + lpips_distance(rendered, target)
```

**Parameters:**
*   **Training Resolution:** $256 \times 256$ pixels [S1].
*   **Loss Function:** Mean Squared Error (MSE) + Perceptual Distance (LPIPS) [S1].
*   **Optimizer:** Adam [S1].

**Edge Cases and Pitfalls:**
*   **Scale Ambiguity:** SfM poses are scaled by an arbitrary unknown scalar $s_i$ [S1]. The model handles this by inferring the scale via an epipolar transformer that finds cross-view pixel correspondences [S1]. Without this, ghosting artifacts occur [S1].
*   **Local Minima:** Gaussian primitives have local support; gradients vanish if the distance to the correct location exceeds a few standard deviations [S1]. The probabilistic sampling avoids this by allowing gradients to flow through the probability distribution, implicitly spawning/deleting primitives [S1]. Without this, the model falls into local minima that manifest as speckling artifacts [S1].
*   **Out-of-Distribution Poses:** Reflective surfaces may appear transparent, and Gaussians may appear billboard-like when viewed from out-of-distribution camera poses [S1].

## Operating characteristics
*   **Time Complexity:** Inference cost is approximately 650 times less than the next-fastest baseline for encoding one scene and rendering 100 images [S1]. Rendering is accelerated by 2.5 orders of magnitude compared to state-of-the-art light field transformers [S1].
*   **Memory Complexity:** Memory-efficient rendering due to rasterization-based volume rendering of Gaussians, significantly less memory per ray at training time compared to ray-marching NeRFs [S1].
*   **Performance:** Benchmarked on wide-baseline novel view synthesis on RealEstate10k and ACID datasets [S1]. Outperforms baselines like pixelNeRF, GPNR, and Du et al.'s light field transformer in PSNR and LPIPS [S1].
*   **Strengths:** Real-time rendering, editable 3D representation, fast 3D reconstruction at inference, handles scale ambiguity, avoids local minima via differentiable sampling [S1].
*   **Limitations:** Struggles with reflective surfaces (transparency) and out-of-distribution views (billboard effect) [S1]. Requires paired images with known poses (though scale is handled) [S1].

## Background
pixelSplat was introduced by Charatan, Li, Tagliasacchi, and Sitzmann from MIT and Simon Fraser University/University of Toronto [S1]. It was presented at CVPR 2024 [S1]. The method addresses the limitations of previous generalizable novel view synthesis methods, which were either slow (ray-marching NeRFs) or lacked explicit 3D representations (light-field transformers) [S1]. It builds on the success of 3D Gaussian Splatting for single-scene optimization [19] and adapts it for the generalizable, feed-forward setting [S1].
