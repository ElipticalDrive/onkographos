# InstantSplat

Also called: MASt3R/VGGT-guided 3DGS, Pose-free 3D Gaussian Splatting

## Overview
InstantSplat is a pose-free, sparse-view 3D Gaussian Splatting (3DGS) method that eliminates the need for Structure-from-Motion (SfM) pipelines by leveraging geometry priors from foundation models like MASt3R or VGGT [S1, unofficial]. It enables training in seconds by directly initializing Gaussians from these priors, distinguishing itself from feed-forward methods like [pixelSplat](6464-pixelsplat.md) which regress primitives directly from images, and from traditional 3DGS which requires dense pose estimation [S1, unofficial].

## How it works
**Inputs:** A sparse set of uncalibrated images (typically 3–10 views) [S1, unofficial].
**Outputs:** A set of 3D Gaussian primitives optimized for novel view synthesis [S1, unofficial].

**Data Structures:**
1.  **Gaussian Primitives:** Standard 3DGS representation [G]. Each Gaussian $i$ is defined by:
    *   Mean position $\boldsymbol{\mu}_i \in \mathbb{R}^3$ [G].
    *   Covariance matrix $\boldsymbol{\Sigma}_i \in \mathbb{R}^{3 \times 3}$, parameterized by a rotation matrix $\mathbf{R}_i$ and scaling vector $\mathbf{s}_i$ such that $\boldsymbol{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^\top \mathbf{R}_i^\top$ [G].
    *   Opacity $\alpha_i \in [0, 1]$ [G].
    *   Spherical Harmonics (SH) coefficients $\mathbf{c}_{i, l}$ for color $c$ [G].
2.  **Geometry Priors:** Depth maps and relative camera poses generated by MASt3R or VGGT from the input image pairs [S1, unofficial].

**Steps:**
1.  **Prior Extraction:** For each input image pair, run MASt3R or VGGT to obtain dense depth maps and relative camera poses [S1, unofficial].
2.  **Point Cloud Generation:** Back-project pixels using the estimated depth and camera intrinsics to form a 3D point cloud [G].
3.  **Gaussian Initialization:** Initialize the mean positions $\boldsymbol{\mu}_i$ of the Gaussians from the generated point cloud [S1, unofficial].
4.  **Differentiable Rendering:** Render the scene using standard 3DGS differentiable rasterization [G].
5.  **Optimization:** Optimize Gaussian parameters (positions, covariances, opacities, SH coefficients) using a loss function combining photometric error ($\mathcal{L}_{L1}$) and perceptual loss ($\mathcal{L}_{MS-SSIM}$) [G]. The optimization converges significantly faster than standard 3DGS due to the high-quality initialization from priors [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def instant_splat(input_images, intrinsics_list, num_steps=1000):
    # 1. Extract geometry priors via MASt3R/VGGT
    depth_maps, relative_poses = extract_priors(input_images)
    
    # 2. Back-project depth to 3D point cloud
    point_cloud = back_project_depth(depth_maps, intrinsics_list, relative_poses)
    
    # 3. Initialize Gaussian primitives
    gaussians = initialize_gaussians(point_cloud)
    
    # 4. Differentiable optimization loop
    for step in range(num_steps):
        rendered_images = render(gaussians, relative_poses)
        loss = compute_loss(rendered_images, input_images)
        gaussians = optimize(gaussians, loss)
    return gaussians

def extract_priors(images):
    # Foundation model inference for depth and relative poses [G]
    depth_maps = [model.predict_depth(img) for img in images]
    relative_poses = [model.predict_pose(img1, img2) for img1, img2 in zip(images[:-1], images[1:])]
    return depth_maps, relative_poses

def back_project_depth(depth_maps, intrinsics_list, relative_poses):
    points = []
    for depth, intrinsics, pose in zip(depth_maps, intrinsics_list, relative_poses):
        h, w = depth.shape
        u, v = np.meshgrid(np.arange(w), np.arange(h))
        z = depth[v, u]
        x = (u - intrinsics.cx) * z / intrinsics.fx
        y = (v - intrinsics.cy) * z / intrinsics.fy
        homogenous = np.stack([x, y, z, np.ones_like(z)], axis=-1)
        world_points = (pose @ homogenous.T).T[:, :3]
        points.append(world_points)
    return np.vstack(points)

def initialize_gaussians(point_cloud):
    means = point_cloud
    covariances = compute_covariance_from_scale_and_rotation(point_cloud)
    opacities = np.full(len(point_cloud), 0.5)
    sh_coeffs = np.zeros((len(point_cloud), 16, 3))
    return {'means': means, 'covariances': covariances, 'opacities': opacities, 'sh_coeffs': sh_coeffs}

def render(gaussians, poses):
    return differentiable_rasterize(gaussians['means'], gaussians['covariances'], 
                                    gaussians['opacities'], gaussians['sh_coeffs'], poses)

def compute_loss(rendered, target):
    return np.mean(np.abs(rendered - target)) + ms_ssim(rendered, target)

def optimize(gaussians, loss):
    grads = compute_gradients(loss, gaussians)
    return apply_sgd(gaussians, grads, lr=0.0001)

def compute_covariance_from_scale_and_rotation(points):
    # Standard initialization: uniform scale and identity rotation [G]
    scale = np.ones((len(points), 3)) * 0.1
    rotation = np.tile(np.eye(3), (len(points), 1, 1))
    S = np.diag(scale, axis1=-2, axis2=-1)
    return rotation @ S @ S.T @ rotation.T

def differentiable_rasterize(means, covs, opacities, sh_coeffs, poses):
    # Standard 3DGS differentiable rasterizer [G]
    return rasterizer_project_and_shade(means, covs, opacities, sh_coeffs, poses)

def ms_ssim(rendered, target):
    return structural_similarity_index(rendered, target)

def compute_gradients(loss, gaussians):
    return gradient_of(loss, gaussians)

def apply_sgd(gaussians, grads, lr):
    for key in gaussians:
        gaussians[key] = gaussians[key] - lr * grads[key]
    return gaussians
```

**Parameters:**
*   **Training time:** Typically completes in seconds due to high-quality initialization [S1, unofficial].
*   **Learning rate:** Standard 3DGS learning rates apply [G].

**Edge Cases:**
*   **Degenerate Input:** If priors are noisy or missing, initialization may fail [G].
*   **Precision:** Depth estimation errors propagate to Gaussian positions [G].

## Subtopics

### MoSca
A prior-aided monocular dynamic Gaussian Splatting method using CoTracker, VGG-T, DUSt3R, or metric-depth priors [S1, unofficial].

### Shape-of-Motion
A prior-aided monocular dynamic Gaussian Splatting method using CoTracker, VGG-T, DUSt3R, or metric-depth priors [S1, unofficial].

### Fuse-and-Refine Module
A module that enhances existing feed-forward models by merging and refining Gaussian primitives in a canonical 3D space using a hybrid Splat-Voxel representation [S2].

**Steps:**
1.  **Input:** Initial set of Gaussian primitives from existing pixel-aligned feed-forward models (from current frame or warped from previous frames) [S2].
2.  **Splat-to-Voxel Transfer:** Aggregate local features from Gaussian primitives into a voxel representation [S2].
3.  **Voxel Hierarchy:** Construct a coarse-to-fine voxel hierarchy by adaptively sparsifying the high-resolution voxel grid [S2].
4.  **Transformer Processing:** Apply a sparse voxel transformer to features at the coarse resolution to capture global context [S2].
5.  **Refinement:** Generate refined Gaussian primitives at the high-resolution level from the processed voxel features [S2].

**Parameters:**
*   **Processing time:** The module merges 200K Gaussian primitives in 15 ms [S2].

**Performance:**
*   **Quality improvement:** PSNR improvement of around 2 dB compared to pixel-aligned reconstruction approaches [S2].

### VoLoDSplat
A feed-forward framework for novel-view synthesis that builds a hierarchical voxel-based scene representation and predicts 3D Gaussians from sparse input views [S3, unofficial]. It provides a training and evaluation pipeline specifically for the RealEstate10K (RE10K) dataset [S3, unofficial]. Evaluation uses six views using a fixed index file located at `assets/re10k_evaluation/evaluation_index_re10k.json` [S3, unofficial].

## Operating characteristics
*   **Time complexity:** Training time is significantly reduced compared to standard 3DGS due to better initialization, often completing in seconds [S1, unofficial].
*   **Memory complexity:** Not given in the sources [G].
*   **Strengths:** Eliminates the need for SfM (COLMAP), enabling pose-free training. Fast training time. Works with sparse views [S1, unofficial].
*   **Limitations:** Relies on the quality of the geometry priors (MASt3R/VGGT). Performance may degrade if priors are inaccurate [S1, unofficial].
*   **When to use:** When SfM fails or is too slow, or when working with sparse/unstructured image collections [S1, unofficial].
*   **When not to use:** When high-precision dense reconstruction is required and priors are unreliable [S1, unofficial].

## Background
InstantSplat was introduced as a solution to the bottleneck of Structure-from-Motion (SfM) in 3D Gaussian Splatting [S1, unofficial]. It leverages recent advances in foundation models for geometry estimation (MASt3R, VGGT) to provide robust initial geometry, allowing for rapid optimization [S1, unofficial]. It is part of the broader trend of pose-free and feed-forward training methods in 3DGS [S1, unofficial].
