# Feature-3DGS

Also called: N2F2

## Overview
Feature-3DGS is a method for open-vocabulary 3D segmentation that stores per-Gaussian language features, such as CLIP or LSeg embeddings [S1, unofficial][S2]. It is distinguished as the first method for feature field distillation based on 3D Gaussian Splatting, leveraging guidance from 2D foundation models to learn semantic features for each 3D Gaussian [S2]. It employs a low-dimensional feature field upsampled via a convolutional decoder to improve rendering efficiency [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view images, camera poses, and 2D foundation model features (e.g., CLIP, LSeg) extracted from input views [S1, unofficial][S2].
*   **Outputs:** A set of 3D Gaussians, each associated with a low-dimensional semantic feature vector, and a convolutional decoder for upsampling [S2].

**Data Structures:**
*   **3D Gaussian:** Standard 3DGS attributes (position, covariance, opacity, color) plus a per-Gaussian semantic feature vector [G].
*   **Feature Vector:** A low-dimensional embedding representing the semantic content [S2].
*   **Convolutional Decoder:** A neural network module that upsamples the sparse feature field to pixel space [S2].

**Steps:**
1.  **Initialization:** Initialize 3D Gaussians from input geometry [G].
2.  **Feature Learning:** Learn semantic features for each 3D Gaussian by distilling features from 2D foundation models [S2].
3.  **Guidance:** Leverage guidance from 2D foundation models during training to ensure semantic consistency [S2].
4.  **Rendering:** Employ a low-dimensional feature field. To render high-resolution semantic features, upsample the sparse feature field using a convolutional decoder [S2].

```python
def alpha_blend_features(projected_gaussians, image_width, image_height, feature_dim):
    """Alpha-blend low-dimensional feature vectors per pixel."""
    features = zeros(image_height, image_width, feature_dim)
    alphas = zeros(image_height, image_width)
    for g in projected_gaussians:
        mask = g.screen_space_coverage
        weight = g.opacity * g.gaussian_weight(mask)
        features[mask] += weight * g.feature_vector
        alphas[mask] += weight
    features = features / (alphas + 1e-5)
    return features

def compute_feature_loss(rendered_features, target_features):
    """Compute feature distillation loss (e.g., cosine similarity or MSE)."""
    return mean_squared_error(rendered_features, target_features)

def forward_pass(gaussians, camera, decoder, image_width, image_height, feature_dim):
    projected = project_gaussians(gaussians, camera)
    sparse_features = alpha_blend_features(projected, image_width, image_height, feature_dim)
    dense_features = decoder(sparse_features)
    return dense_features

def train_step(gaussians, camera, decoder, optimizer, images, foundation_model_features):
    rendered_features = forward_pass(gaussians, camera, decoder, images.shape[2], images.shape[3], foundation_model_features.shape[-1])
    loss = compute_feature_loss(rendered_features, foundation_model_features)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss
```

## Background
Feature-3DGS was introduced as the first method for feature field distillation based on 3D Gaussian Splatting [S2]. It builds on the work of 2D foundation models like CLIP and LSeg, adapting them to the 3D Gaussian representation [S1, unofficial][S2]. It is part of a series of works that leverage 2D priors for 3D tasks, following methods like SAGA and Gaussian Grouping [S2].
