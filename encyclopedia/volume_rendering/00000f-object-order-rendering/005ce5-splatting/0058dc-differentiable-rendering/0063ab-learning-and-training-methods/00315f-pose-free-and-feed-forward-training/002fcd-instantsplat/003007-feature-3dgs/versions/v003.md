# Feature-3DGS

Also called: N2F2

## Overview
Feature-3DGS is a method for open-vocabulary 3D segmentation that stores per-Gaussian language features, such as CLIP or LSeg embeddings [S1, unofficial][S2]. It is distinguished as the first method for feature field distillation based on 3D Gaussian Splatting, leveraging guidance from 2D foundation models to learn semantic features for each 3D Gaussian [S2]. It employs a low-dimensional feature field upsampled via a convolutional decoder to improve rendering efficiency [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view images, camera poses, and 2D foundation model features extracted from input views [S1, unofficial][S2].
*   **Outputs:** A set of 3D Gaussians with associated low-dimensional semantic feature vectors, and a convolutional decoder for upsampling [S2].

**Data Structures:**
*   **3D Gaussian:** Standard 3DGS attributes (position, covariance, opacity, color) plus a per-Gaussian semantic feature vector [G].
*   **Feature Vector:** A low-dimensional embedding representing the semantic content [S2].
*   **Convolutional Decoder:** A neural network module that upsamples the sparse feature field to pixel space [S2].

**Steps:**
1.  Learn semantic features for each 3D Gaussian [S2].
2.  Leverage guidance from 2D foundation models during training [S2].
3.  Employ a low-dimensional feature field [S2].
4.  Upsample the sparse feature field using a convolutional decoder to improve rendering efficiency [S2].

**Pseudocode:**
```python
def project_gaussians(gaussians, camera):
    """Project 3D Gaussians to 2D screen space and compute 2D covariance."""
    projected = []
    for g in gaussians:
        # Transform to camera space, project via intrinsic matrix,
        # compute 2D covariance via Jacobian, apply screen-space bounding box.
        proj = standard_3dgs_projection(g, camera)
        projected.append(proj)
    return sorted(projected, key=lambda p: p.depth)

def alpha_blend_features(projected_gaussians, image_width, image_height, feature_dim):
    """Alpha-blend low-dimensional feature vectors per pixel."""
    features = zeros((image_height, image_width, feature_dim))
    alphas = zeros((image_height, image_width))
    for g in projected_gaussians:
        bbox = g.screen_bounding_box
        for y in range(bbox.y_min, bbox.y_max):
            for x in range(bbox.x_min, bbox.x_max):
                weight = g.opacity * g.gaussian_weight(x, y)
                features[y, x] += weight * g.feature_vector
                alphas[y, x] += weight
    features = features / (alphas[:, :, None] + 1e-5)
    return features

def compute_feature_loss(rendered_features, target_features):
    """Compute feature distillation loss."""
    return mean_squared_error(rendered_features, target_features)

def forward_pass(gaussians, camera, decoder, image_width, image_height, feature_dim):
    projected = project_gaussians(gaussians, camera)
    sparse_features = alpha_blend_features(projected, image_width, image_height, feature_dim)
    dense_features = decoder(sparse_features)
    return dense_features

def train_step(gaussians, camera, decoder, optimizer, images, foundation_model_features):
    rendered_features = forward_pass(gaussians, camera, decoder, images.shape[2], images.shape[3], foundation_model_features.shape[-1])
    loss = compute_feature_loss(rendered_features, foundation_model_features)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss
```

**Parameters:**
*   **Foundation Model:** CLIP or LSeg [S1, unofficial][S2].
*   **Decoder Architecture:** Convolutional decoder [S2].

## Subtopics

### Holistic Gaussian Initialization
Provides a robust initialization strategy for Gaussians to improve semantic alignment [G]. It sets itself apart by focusing on initialization quality rather than rendering or grouping [G]. Choose it when starting training from sparse or noisy geometry [G]. [Holistic Gaussian Initialization](9776-holistic-gaussian-initialization.md)

### ReSplat
Focuses on re-splatting techniques for efficient rendering [G]. It differs by optimizing the rasterization pass rather than feature learning [G]. Choose it when rendering speed is the primary bottleneck [G]. [ReSplat](11511-resplat.md)

### AESplat
Uses adaptive entropy-based splatting to optimize rendering [G]. It stands out by dynamically adjusting splat density based on feature entropy [G]. Choose it when memory or compute limits restrict dense feature field rendering [G]. [AESplat](14724-aesplat.md)

## Operating characteristics
*   **Strengths:** Enables open-vocabulary 3D segmentation and achieves efficient rendering via low-dimensional features and convolutional upsampling [S2].
*   **Limitations:** Performance depends heavily on the quality and coverage of the underlying 2D foundation models [S2].

## Background
Feature-3DGS was introduced as the first method for feature field distillation based on 3D Gaussian Splatting [S2]. It builds on 2D foundation models like CLIP and LSeg, adapting them to the 3D Gaussian representation [S1, unofficial][S2]. It follows a series of works leveraging 2D priors for 3D tasks, such as SAGA and Gaussian Grouping [S2].
