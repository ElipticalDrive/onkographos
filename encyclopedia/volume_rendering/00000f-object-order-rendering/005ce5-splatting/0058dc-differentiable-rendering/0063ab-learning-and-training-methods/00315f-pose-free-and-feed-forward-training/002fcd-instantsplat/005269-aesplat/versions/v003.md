# AESplat


## Overview
AESplat is a pose-free, feed-forward 3D Gaussian Splatting (3DGS) framework that improves novel view synthesis by decoupling appearance modeling into view-independent (zeroth-order spherical harmonics) and view-dependent (higher-order spherical harmonics) components [S1, unofficial]. Unlike unified prediction paradigms that regress all SH coefficients jointly, AESplat derives the zeroth-order coefficient directly from input pixel RGB values without training, while predicting higher-order coefficients using a shallow MLP conditioned on 3D-aware inductive biases [S1, unofficial]. This approach addresses the suboptimal rendering quality of existing pose-free methods that overlook the fundamental distinction between view-independent and view-dependent appearance [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ unposed images $\{I_v\}_{v=1}^N$, comprising $N_C$ context images $I_C$ and $N_T$ target images $I_T$ [S1, unofficial]. The input resolution is $224 \times 224$ pixels [S1, unofficial].
*   **Output:** A set of 3D Gaussian primitives $\{G_{v \to 1}\}$ in the canonical frame of the first view, and camera parameters (extrinsics $P_{v \to 1}$ and intrinsics $K_v$) for all views [S1, unofficial].

**Data Structures:**
*   **Gaussian Primitive $G_j$:** Defined in the canonical frame of the first view [S1, unofficial].
    *   Center $\mu \in \mathbb{R}^3$
    *   Rotation $r \in \mathbb{R}^4$ (quaternion) [S1, unofficial]
    *   Scale $s \in \mathbb{R}^3$
    *   Opacity $\alpha \in \mathbb{R}$
    *   SH Coefficients $c \in \mathbb{R}^{(l+1) \times 3}$, where $l$ is the SH degree [S1, unofficial].
*   **Camera Parameters:**
    *   Extrinsics $P_{v \to 1}$: 6D rotation representation + 4D homogeneous translation vector, converted to a homogeneous transformation matrix [S1, unofficial].
    *   Intrinsics $K_v$: Field of View (FOV), assuming equal horizontal/vertical FOV and centered principal point [S1, unofficial].

**Method Steps:**

1.  **Multi-View Feature Extraction:**
    Input images are patchified and encoded by a DINOv2 backbone into image features $F_v$ [S1, unofficial]. These are concatenated with learnable camera tokens $g_v$ [S1, unofficial]. A ViT-based encoder-decoder with Alternating-Attention aggregates information [S1, unofficial]. Masked attention restricts context tokens to attend only to context tokens, while target tokens attend to both, preventing target-view leakage into Gaussian reconstruction [S1, unofficial].

2.  **Camera Parameter Estimation:**
    Refined camera tokens $\hat{g}_v$ are passed to a camera head to predict extrinsics $P_{v \to 1}$ and intrinsics $K_v$ for each view [S1, unofficial]. The first view is defined as the canonical frame [S1, unofficial].

3.  **Gaussian Geometry Prediction:**
    Refined context tokens $\hat{F}_v^C$ are processed by two DPT heads [S1, unofficial]. One predicts depth to recover Gaussian centers $\mu$ [S1, unofficial]. The other predicts rotation $r$, scale $s$, opacity $\alpha$, and initial SH coefficients [S1, unofficial]. All Gaussians are transformed into the canonical frame of the first view:
    $$ \{G_{v \to 1}\}_{v=1}^N = \{(\mu_j, r_j, s_j, \alpha_j, c_j)\}_{j=1}^{H \times W} $$
    where $\mu \in \mathbb{R}^3, r \in \mathbb{R}^4, s \in \mathbb{R}^3, \alpha \in \mathbb{R}, c \in \mathbb{R}^{(l+1) \times 3}$ [S1, unofficial].

4.  **View-Independent Appearance Modeling (VIAM):**
    The zeroth-order SH coefficient $c_{00}$ is derived directly from the input image pixel RGB value $C_j^v \in \mathbb{R}^3$ for pixel-aligned Gaussians, without training [S1, unofficial]. This is termed Image-to-Direct Component (I2DC) [S1, unofficial]. The formula is:
    $$ c_{00}^{(v,j)} = \frac{C_j^v - 0.5}{Y_{00}} $$
    where $Y_{00} = \frac{1}{2\sqrt{\pi}}$ is the constant zeroth-order SH basis function [S1, unofficial].

5.  **Inductive Bias Generation:**
    Two 3D-aware inductive biases are computed to guide view-dependent appearance prediction:
    *   **Gaussian-to-Views Spatial Relation Embedding (GVSRE):** For each Gaussian center $\mu_j^{vs}$ from view $vs$, a multi-view spatial descriptor $r_j^{vs}$ is formed by concatenating the normalized direction and log-distance to each context camera center $o^{vc}$:
        $$ r_j^{vs} = \text{concat}_{vc \in I_C} \left[ \frac{o^{vc} - \mu_j^{vs}}{\|o^{vc} - \mu_j^{vs}\|_2}, \log \|o^{vc} - \mu_j^{vs}\|_2 \right] \in \mathbb{R}^{4|I_C|} $$
        This descriptor is mapped to an embedding via a shallow MLP [S1, unofficial].
    *   **Warped Color Map (WCM):** For a context view $v_p$ and target view $v_q$, project Gaussian $G_j$ center $\mu_j^{v_p}$ to $v_q$ using intrinsic $K^{v_q}$ and camera-to-camera transform $T^{v_q \leftarrow v_p}$:
        $$ u_j^{v_q \leftarrow v_p} = \pi(K^{v_q} T^{v_q \leftarrow v_p} \mu_j^{v_p}) $$
        Sample RGB color $\hat{C}_j^{v_q \leftarrow v_p}$ from $I^{v_q}$ via bilinear interpolation at $u_j^{v_q \leftarrow v_p}$ [S1, unofficial]. Compute validity mask:
        $$ m_j^{v_q \leftarrow v_p} = \mathbb{I}[z_j^{v_q \leftarrow v_p} > 0] \cdot \mathbb{I}[u_j^{v_q \leftarrow v_p} \in \Omega] $$
        where $z$ is depth and $\Omega$ is the normalized image domain [S1, unofficial]. Aggregate all $H \times W$ Gaussians to form warped color map $\hat{C}^{v_q \leftarrow v_p}$ and mask $m^{v_q \leftarrow v_p}$ [S1, unofficial].

6.  **View-Dependent Appearance Prediction:**
    A four-layer MLP with GELU activations (after the first three hidden layers) and linear output predicts the higher-order SH coefficients [S1, unofficial]. Inputs are:
    *   GVSRE embedding
    *   Warped Color Map (WCM)
    *   Intermediate features from the Gaussian geometry head [S1, unofficial]
    Layer normalization is applied before the final prediction [S1, unofficial].

7.  **Rendering and Loss:**
    The model is optimized using photometric error between rendered image $I_{render}$ and ground-truth $I_{gt}$:
    $$ \mathcal{L} = \lambda_{mse} \|I_{render} - I_{gt}\|_2^2 + \lambda_{lpips} \text{LPIPS}(I_{render}, I_{gt}) $$
    Typical parameters: $\lambda_{mse} = 1$, $\lambda_{lpips} = 0.05$ [S1, unofficial].
