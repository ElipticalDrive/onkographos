# SHARE (Pose-free 3D Gaussian Splatting via Shape-Ray Estimation)


## Overview
SHARE is a pose-free, feed-forward Gaussian splatting framework that jointly estimates relative camera poses and reconstructs accurate 3D geometry by operating in latent space rather than explicit 3D space, mitigating pose-induced geometry misalignment [S1]. Unlike methods that transform 3D geometries from each viewpoint into a reference camera coordinate using predicted poses, SHARE constructs a unified cost volume in latent space, bypassing erroneous 3D space transformation [S1]. It sets itself apart from siblings like [FreeSplat](15163-freesplat.md) and [ZipSplat](17331-zipsplat.md) by using Plücker rays to guide multi-view feature fusion directly, avoiding the sequential estimation of pose and shape that leads to significant geometric errors [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $M$ unposed images $I = \{I_i\}_{i=1}^M$ [S1].
*   **Output:** A set of $N$ 3D Gaussian primitives $\{G_n\}_{n=1}^N$ and relative camera poses $\{R_i, T_i\}_{i=1}^M$ [S1]. Each Gaussian $G_n$ is defined by position $\mu_n$, opacity $\alpha_n$, covariance matrix $\Sigma_n$, and color $c_n$ [S1].

**Data Structures:**
*   **Multi-view Features:** $F_i \in \mathbb{R}^{\frac{H}{4} \times \frac{W}{4} \times C}$, extracted per view [S1].
*   **Plücker Rays:** $P_{li} \in \mathbb{R}^{\frac{H}{4} \times \frac{W}{4} \times 6}$, defined per spatial patch $l$ for view $i$ [S1]. Each ray consists of direction $d$ and momentum $m$, denoted $P = \langle d, m \rangle$ [S1].
*   **Cost Volumes:** $C_i \in \mathbb{R}^{\frac{H}{4} \times \frac{W}{4} \times D}$ for each view $i$, where $D$ is the number of hypothetical depth candidates [S1].
*   **Spatial Weights:** $W_i \in \mathbb{R}^{\frac{H}{4} \times \frac{W}{4}}$ used to account for view-dependent effects [S1].
*   **Fused Feature:** $V_g$, the canonical volume representation [S1].
*   **Parameters:** $\Phi_\theta$ denotes the network mapping [S1].

**Numbered Steps:**
1.  **Joint Feature Extraction:** Estimate multi-view features $F_i \in \mathbb{R}^{\frac{H}{4} \times \frac{W}{4} \times C}$ using a matching transformer backbone [S1].
2.  **Ray Estimation:** Estimate patch-wise Plücker rays $P_{li} \in \mathbb{R}^{\frac{H}{4} \times \frac{W}{4} \times 6}$ through an additional two-layer lightweight transformer [S1]. Each ray is defined by direction $d$ and momentum $m$ [S1].
3.  **Cost Volume Construction:** For each viewpoint $i$, construct cost volumes $C_i$ by extending 2D features into 3D along hypothetical planes and projecting onto other views [S1]. Compute channel-wise correlations between the reference feature $F_i$ and warped features $F_{d_j \to i}$ for $D$ depth candidates [S1]. The cost volume $C_i$ is computed as:
    $$ C_i = \sum_{j \neq i} \frac{F_i \cdot F_{j \to i}}{\sqrt{C}} \in \mathbb{R}^{\frac{H}{4} \times \frac{W}{4} \times D} $$
    where $D$ is the number of hypothetical depth candidates [S1].
4.  **Pose-aware Cost Aggregation:** Refine cost volumes through cost aggregation conditioned on predicted Plücker rays [S1]. Use patch-wise cross-attention to embed pose awareness into the cost volumes [S1]. Since rays are locally defined in spatial patches, they are seamlessly integrated with image features, introducing geometric bias into the cost volumes [S1].
5.  **Canonical Volume Formation:** Select one viewpoint as the canonical view [S1]. Align remaining views to the canonical space using the pose-aware cost volumes and spatial weights $W_i$ to account for occlusion and lighting, building a fused feature $V_g$ [S1].
6.  **Anchor Prediction:** Use fused features $V_g$ to predict pixel-aligned coarse geometry (anchors) [S1].
7.  **Anchor-aligned Gaussian Prediction:** Use fused features $V_f$ (derived from $V_g$) to predict offset vectors from the coarse anchors to spread to adjacent regions [S1]. Predict $k$ Gaussians per region for fine-grained reconstruction [S1].

**Formulas:**
The objective mapping function is:
$$ \Phi_\theta : \{I_i\}_{i=1}^M \rightarrow \{G_n\}_{n=1}^N, \{R_i, T_i\} = \Psi(\{P_{li}\}_{l=1}^{P_h \times P_w}) $$
where $G_n = \{\mu_n, \alpha_n, \Sigma_n, c_n\}$, $P = \langle d, m \rangle$, and $\Psi$ converts Plücker rays to camera parameters $(R, T)$ [S1].

**Parameters:**
*   $P_h, P_w$: Spatial patch resolution used for defining Plücker rays and cost volumes [S1].
*   $D$: Number of hypothetical depth candidates used in cost volume construction [S1].

**Pitfalls:**
*   Sequential estimation of camera pose and shape leads to significant geometry misalignment if pose estimates are inaccurate [S1]. SHARE avoids this by joint estimation in latent space [S1].
*   Inaccurate pose estimates in traditional methods cause errors when transforming 3D geometries into a reference coordinate system [S1]. SHARE bypasses this by fusing features in latent space [S1].

**Pseudocode:**
```python
def share_forward(images):
    """
    Input: images - List of M unposed images I_i.
    Output: Gaussians {G_n}, Camera Poses {R_i, T_i}
    """
    M = len(images)
    H_in, W_in, C_in = images[0].shape
    H, W = H_in // 4, W_in // 4  # Downsampled resolution [S1]
    D = 64  # Number of hypothetical depth candidates [S1]
    P_h, P_w = H, W  # Spatial patch resolution [S1]

    # Step 1: Joint Feature Extraction
    # F_i in R^(H/4 x W/4 x C)
    features = [matching_transformer_backbone(img) for img in images]

    # Step 2: Ray Estimation
    # P_li in R^(H/4 x W/4 x 6), P = <d, m>
    rays = [lightweight_transformer(F_i) for F_i in features]

    # Step 3: Cost Volume Construction
    # C_i in R^(H/4 x W/4 x D)
    cost_volumes = []
    for i in range(M):
        C_i = [[[[0.0] * D for _ in range(W)] for _ in range(H)]]
        for j in range(M):
            if i != j:
                # Warp features from view j to view i based on hypothetical depth
                F_j_to_i = warp_features(features[j], hypothetical_depths=D, rays[j])
                # Channel-wise correlation: dot product over C, divided by sqrt(C)
                correlation = dot_over_channels(features[i], F_j_to_i) / math.sqrt(C_in)
                # Broadcast correlation to depth dimension and sum over views
                for d in range(D):
                    for y in range(H):
                        for x in range(W):
                            C_i[0][y][x][d] += correlation[y][x]
        cost_volumes.append(C_i)

    # Step 4: Pose-aware Cost Aggregation
    # Refine cost volumes using patch-wise cross-attention with rays
    refined_cost_volumes = []
    for i in range(M):
        C_prime_i = patchwise_cross_attention(cost_volumes[i], rays[i])
        refined_cost_volumes.append(C_prime_i)

    # Step 5: Canonical Volume Formation
    # Select view 0 as canonical
    canonical_view_index = 0
    # Align other views to canonical space using refined cost volumes and weights
    # W_i in R^(H/4 x W/4) accounts for view-dependent effects [S1]
    weights = compute_spatial_weights(refined_cost_volumes)
    V_g = align_to_canonical(refined_cost_volumes, weights, canonical_view_index)

    # Step 6: Anchor Prediction
    # Predict coarse geometry anchors from V_g [S1]
    anchors = predict_anchors(V_g)

    # Step 7: Anchor-aligned Gaussian Prediction
    # Predict offsets from anchors to spread to adjacent regions [S1]
    offsets = predict_offsets(V_g, anchors)
    gaussians = spread_gaussians(anchors, offsets)

    # Convert Plucker rays to camera parameters
    # Psi converts P = <d, m> to R, T [S1]
    poses = [convert_plucker_to_pose(P_i) for P_i in rays]

    return gaussians, poses

# Helper definitions (standard operations or source-unspecified steps marked)
def matching_transformer_backbone(img):
    # Standard matching transformer backbone for multi-view feature extraction [S1]
    return conv_pool(img)

def lightweight_transformer(F_i):
    # Two-layer lightweight transformer for Plücker ray estimation [S1]
    return conv_layers(F_i)

def warp_features(F_j, hypothetical_depths, rays_j):
    # Projects 2D features into 3D along hypothetical planes and warps to reference view [S1]
    return backproject_and_warp(F_j, hypothetical_depths, rays_j)

def patchwise_cross_attention(C_i, rays_i):
    # Embeds pose awareness into cost volumes via patch-wise cross-attention [S1]
    return cross_attention(Q=C_i, K=rays_i, V=rays_i)

def compute_spatial_weights(refined_cost_volumes):
    # Computes spatial weight volume W_i to account for occlusion and lighting [S1]
    return sigmoid(conv_layers(refined_cost_volumes))

def align_to_canonical(refined_cost_volumes, weights, canonical_view_index):
    # Aligns non-canonical views to canonical space using weights and cost volumes [S1]
    aligned = [refined_cost_volumes[canonical_view_index]]
    for i, vol in enumerate(refined_cost_volumes):
        if i != canonical_view_index:
            aligned.append(vol * weights[i])
    return sum(aligned) / len(aligned)

def predict_anchors(V_g):
    # Predicts pixel-aligned coarse geometry (anchors) from fused features [S1]
    return conv_layers(V_g)

def predict_offsets(V_g, anchors):
    # Predicts offset vectors from anchors to spread to adjacent regions [S1]
    return conv_layers(concat(V_g, anchors))

def spread_gaussians(anchors, offsets):
    # Predicts k Gaussians per region for fine-grained reconstruction [S1]
    return anchors + offsets

def convert_plucker_to_pose(P_i):
    # Converts Plücker ray <d, m> to camera parameters (R, T) [S1]
    d, m = split(P_i, 3)
    return plucker_to_extrinsic(d, m)

def dot_over_channels(A, B):
    return sum(A[c] * B[c] for c in range(len(A)))

def conv_pool(x): return x  # Placeholder for standard CNN pooling [G]
def conv_layers(x): return x  # Placeholder for standard CNN layers [G]
def backproject_and_warp(F, depths, rays): return F  # Placeholder for standard MVS warping [G]
def cross_attention(Q, K, V): return Q  # Placeholder for standard attention [G]
def sigmoid(x): return [1/(1+math.exp(-v)) for v in x]  # Standard activation [G]
def split(x, n): return x[:n], x[n:]  # Standard tensor split [G]
def plucker_to_extrinsic(d, m): return None, None  # Standard conversion [G]
def concat(A, B): return A  # Standard concatenation [G]
```

## Background
SHARE was introduced to address the challenge of obtaining accurate camera poses in real-world scenarios, which often leads to noisy pose estimates and geometric misalignments [S1]. It was developed as a pose-free, feed-forward Gaussian splatting framework that overcomes these ambiguities by joint shape and camera rays estimation [S1]. The method builds on the principles of multi-view stereo (MVS) techniques, specifically cost volume construction and aggregation, but adapts them to latent space for Gaussian splatting [S1]. It is used for novel view synthesis and 3D scene reconstruction from sparse unposed images [S1].
