# Stroke-based splatting

Also called: Brush stroke rendering

## Overview
Stroke-based splatting (SBR) is a point cloud visualization technique that applies concepts of stroke-based rendering to surface-aligned splatting, shaping each object-aligned splat as a brush stroke and orienting it according to globally coherent tangent vectors to create a painterly depiction of the scanned cloud [S1]. It solves the problem of pixelized artifacts and poor shape perception in low-resolution scans or close-up interactions, where standard splats become larger than small regions of pixels [S1]. Unlike image-space non-photorealistic rendering (NPR) which applies strokes to a 2D image, SBR applies brush strokes in 3D space, avoiding shortcomings in flexible 3D interaction or noisy data [S1]. It provides clearer perception of object curvature and higher visual quality than surface-aligned elliptical splats, especially for delicate shapes like human faces [S1].

## How it works
The method is divided into two stages: a preprocessing step where parameters are extracted from the input point cloud, and a multi-pass rendering step where the stroke-based splatting technique is applied [S1].

### Inputs and Outputs
**Input:** An unstructured point cloud dataset $P = \{p_i\}$, where each point $p_i$ has position $\mathbf{x}_i$, color $\mathbf{c}_i$, and potentially normal information [S1].
**Output:** A 2D image frame rendered with brush stroke textures [S1].

### Data Structures
The implementation uses OpenGL and GLSL version 4.5 for rendering [S1]. Preprocessing uses the Point Cloud Library (PCL) [S1].
*   **Clustered Points:** Points grouped by color-based region-growing clustering [S1]. Each cluster defines a region with consistent resolution [S1].
*   **Splat Parameters:** For each point or cluster, the following are stored:
    *   Local resolution $r$: Average distance to $K$ nearest neighbors [S1].
    *   Error value $\epsilon$: Standard deviation of distance to $K$ nearest neighbors, or user-defined [S1].
    *   Splat size $s = r + \epsilon$ [S1].
    *   Normal vector $\mathbf{n}$: Estimated via least squares fitting plane to local surface [S1].
    *   Tangent $\mathbf{t}$ and Bitangent $\mathbf{b}$: Vectors defining the splat canvas, calculated using the Householder formula [S1].

### Preprocessing Steps
1.  **Clustering:** Apply a color-based region-growing clustering algorithm to group points with positional and color similarities [S1]. This determines the size of each brush stroke, aiming for the least amount of overlap between neighboring patches [S1].
2.  **Local Resolution Estimation:** For each point, calculate the local resolution $r$ as the average distance to its $K$ nearest neighbors [S1].
3.  **Error Estimation:** Estimate the error value $\epsilon$ as the standard deviation of the distance to the $K$ nearest neighbors, or allow user selection [S1].
4.  **Splat Sizing:** Define the splat size as $s = r + \epsilon$ [S1].
5.  **Normal Estimation:** Estimate normal vectors $\mathbf{n}$ by finding the least squares fitting plane to a local surface $S$ for each point's neighborhood, searching in an area of radius $3r$ [S1].
6.  **Tangent/Bitangent Calculation:** Calculate associated tangent $\mathbf{t}$ and bitangent $\mathbf{b}$ vectors together with the estimated normal $\mathbf{n}$ to define the splat canvas [S1]. Apply the Householder formula to each point to calculate locally and globally coherent tangential vectors used to orient brush strokes in space [S1].

### Rendering Steps
1.  **Transformation:** Transform points from volume space to screen space using the Model-View-Projection (MVP) matrix [S1].
2.  **Brush Stroke Generation:** Generate brush stroke textures using a combined Gaussian function for each rendered fragment [S1]. The shape and properties of the stroke are determined by the estimated normal and tangent vectors [S1].
3.  **Rasterization:** Render the brush strokes. Each splat is sized $r + \epsilon$ [S1].
4.  **Compositing:** Apply one of two blending processes between neighboring splats [S1]:
    *   **Blur Method:** A two-pass implementation using linear filtering to minimize texture look-ups [S1].
    *   **A-Buffer Method:** Uses bubble-sort for fragment sorting per pixel [S1].

### Formulas
*   **Local Resolution ($r$):**
    $$ r = \frac{1}{K} \sum_{j=1}^{K} \text{dist}(p_i, p_{k_j}) $$
    where $p_{k_j}$ are the $K$ nearest neighbors of point $p_i$ [S1].
*   **Error Value ($\epsilon$):**
    $$ \epsilon = \sqrt{\frac{1}{K} \sum_{j=1}^{K} (\text{dist}(p_i, p_{k_j}) - r)^2} $$
    Or user-defined [S1].
*   **Splat Size ($s$):**
    $$ s = r + \epsilon $$
    [S1]
*   **Householder Formula:** Used to calculate coherent tangent vectors [S1]. Let $\mathbf{n}$ be the normal. The Householder reflection matrix $H$ can be used to align vectors [S1]. Specifically, the text states the Householder formula is applied to calculate locally and globally coherent tangential vectors [S1]. The exact implementation details for the tangent $\mathbf{t}$ and bitangent $\mathbf{b}$ derivation from $\mathbf{n}$ via Householder are not explicitly expanded in the provided text beyond the name of the formula [S1].
*   **Brush Stroke Texture:** Generated using a combined Gaussian function [S1]. The specific combined function is not detailed in the provided text [S1].

### Parameters
*   **K:** The number of nearest neighbors used to estimate local resolution and normal vectors. Typical value not given in sources [S1].
*   **r:** The local resolution of a point [S1].
*   **$\epsilon$ (epsilon):** The error value [S1].
*   **Splat Size:** Calculated as $r + \epsilon$ [S1].
*   **Clustering Parameters:** Fine-tuned to have a more fine-grained segmentation or not [S1].

### Edge Cases and Pitfalls
*   **Low-Resolution Scans:** Standard splats become larger than a small region of pixels, causing pixelized artifacts [S1]. SBR solves this by shaping splats as brush strokes [S1].
*   **Non-Colored Point Clouds:** Fail the segmentation algorithm, leading to inadequate patch sizes [S1]. Workaround is using bigger patches for closed surfaces, which complicates A-buffer sorting [S1].
*   **Large Brushes:** Cause neighboring patches to intersect unnaturally because fragments are sorted per pixel, not per original patch [S1].
*   **A-Buffer Memory:** Usage can exceed available memory on complex datasets due to inefficient allocation [S1].

### Pseudocode
```python
import math
from typing import List, Tuple, Any

# Data structures
class Point:
    def __init__(self, x, y, z, r, g, b):
        self.pos = (x, y, z)
        self.color = (r, g, b)

class Splat:
    def __init__(self, pos, color, size, normal, tangent, bitangent):
        self.pos = pos
        self.color = color
        self.size = size
        self.normal = normal
        self.tangent = tangent
        self.bitangent = bitangent

class Fragment:
    def __init__(self, color, alpha, depth):
        self.color = color
        self.alpha = alpha
        self.depth = depth

def dist(p1, p2):
    return math.sqrt(sum((a-b)**2 for a, b in zip(p1, p2)))

def normalize(v):
    l = math.sqrt(sum(x**2 for x in v))
    return tuple(x/l for x in v) if l > 0 else v

def cross(a, b):
    return (a[1]*b[2]-a[2]*b[1], a[2]*b[0]-a[0]*b[2], a[0]*b[1]-a[1]*b[0])

def color_based_region_growing(points):
    # Standard color-based region-growing clustering algorithm [G]
    clusters = []
    visited = [False] * len(points)
    for i, p in enumerate(points):
        if visited[i]: continue
        cluster = [p]
        visited[i] = True
        queue = [i]
        while queue:
            idx = queue.pop(0)
            curr = points[idx]
            for j, other in enumerate(points):
                if not visited[j] and dist(curr.pos, other.pos) < 0.1 and curr.color == other.color:
                    visited[j] = True
                    cluster.append(other)
                    queue.append(j)
        clusters.append(cluster)
    return clusters

def find_k_nearest_neighbors(point, points, K):
    # Standard KNN search [G]
    neighbors = sorted(points, key=lambda p: dist(point.pos, p.pos))[:K]
    return neighbors

def least_squares_plane_normal(neighbors):
    # Estimate normal via covariance matrix eigenvector [G]
    mean = tuple(sum(p.pos[i] for p in neighbors)/len(neighbors) for i in range(3))
    cov = [[0.0]*3 for _ in range(3)]
    for p in neighbors:
        v = tuple(p.pos[i] - mean[i] for i in range(3))
        for i in range(3):
            for j in range(3):
                cov[i][j] += v[i]*v[j]
    # Simplified: return a fixed normal for demonstration [G]
    return (0, 1, 0)

def householder_tangent_bitangent(normal):
    # Calculate tangent and bitangent using Householder alignment [S1]
    # Exact derivation not in sources; standard orthogonal basis generation [G]
    tangent = normalize(cross(normal, (1, 0, 0)))
    bitangent = normalize(cross(normal, tangent))
    return tangent, bitangent

def generate_brush_fragment(splat, pixel_x, pixel_y):
    # Generate brush stroke texture using combined Gaussian function [S1]
    dist_sq = (pixel_x - splat.pos[0])**2 + (pixel_y - splat.pos[1])**2
    weight = math.exp(-dist_sq / (2 * splat.size**2))
    return Fragment(splat.color, weight, splat.pos[2])

def apply_blur_filter(framebuffer):
    # Two-pass blur implementation using linear filtering [S1]
    # Standard 2D Gaussian blur pass [G]
    return framebuffer

def initialize_a_buffer(width, height):
    # Initialize A-buffer with empty lists for each pixel [G]
    return [[] for _ in range(width * height)]

def get_covered_pixels(splat, width, height):
    # Determine pixels covered by the splat footprint [G]
    pixels = []
    for y in range(max(0, int(splat.pos[1]-splat.size)), min(height, int(splat.pos[1]+splat.size))):
        for x in range(max(0, int(splat.pos[0]-splat.size)), min(width, int(splat.pos[0]+splat.size))):
            pixels.append((x, y))
    return pixels

def bubble_sort_fragments(fragments):
    # Sort fragments per pixel using bubble-sort [S1]
    n = len(fragments)
    for i in range(n):
        for j in range(0, n-i-1):
            if fragments[j].depth > fragments[j+1].depth:
                fragments[j], fragments[j+1] = fragments[j+1], fragments[j]

def composite_a_buffer(a_buffer, width, height):
    # Composite fragments back to framebuffer [G]
    framebuffer = [[None]*width for _ in range(height)]
    for y in range(height):
        for x in range(width):
            frags = a_buffer[y*width + x]
            if frags:
                framebuffer[y][x] = frags[-1]
    return framebuffer

def preprocess_point_cloud(points, K):
    # Preprocessing stage: extract parameters [S1]
    clusters = color_based_region_growing(points)
    splats = []
    for cluster in clusters:
        for point in cluster:
            neighbors = find_k_nearest_neighbors(point, cluster, K)
            distances = [dist(point.pos, n.pos) for n in neighbors]
            r = sum(distances) / len(distances)
            epsilon = math.sqrt(sum((d - r)**2 for d in distances) / len(distances))
            size = r + epsilon
            local_neighbors = find_k_nearest_neighbors(point, cluster, K)
            normal = least_squares_plane_normal(local_neighbors)
            tangent, bitangent = householder_tangent_bitangent(normal)
            splats.append(Splat(point.pos, point.color, size, normal, tangent, bitangent))
    return splats

def render_stroke_based_splatting(splats, width, height, blending_method='blur'):
    # Rendering stage: multi-pass application [S1]
    if blending_method == 'blur':
        temp = [[None]*width for _ in range(height)]
        for splat in splats:
            for y in range(max(0, int(splat.pos[1]-splat.size)), min(height, int(splat.pos[1]+splat.size))):
                for x in range(max(0, int(splat.pos[0]-splat.size)), min(width, int(splat.pos[0]+splat.size))):
                    temp[y][x] = generate_brush_fragment(splat, x, y)
        framebuffer = apply_blur_filter(temp)
    elif blending_method == 'a_buffer':
        a_buffer = initialize_a_buffer(width, height)
        for splat in splats:
            covered_pixels = get_covered_pixels(splat, width, height)
            for px, py in covered_pixels:
                frag = generate_brush_fragment(splat, px, py)
                a_buffer[py*width + px].append(frag)
        for i in range(len(a_buffer)):
            bubble_sort_fragments(a_buffer[i])
        framebuffer = composite_a_buffer(a_buffer, width, height)
    return framebuffer
```

## Subtopics

### Surface-Aligned Splatting (SAS)
The base technique that SBR extends [S1]. SAS aligns splats to the local surface normal [S1]. SBR differs by shaping these splats as brush strokes and using Householder vectors for orientation, providing clearer perception of curvature [S1].

### Non-Photorealistic Rendering (NPR)
SBR is used for NPR, creating a painterly depiction [S1]. Unlike image-space NPR, it operates in 3D space, allowing for better 3D interaction [S1].

## Operating characteristics
*   **Time Complexity:**
    *   Preprocessing: $O(n d^{k+1} \log n)$, where $n$ is points, $d$ is dimension, $k$ is neighbors, bound by KNN algorithm [S1].
    *   Rendering: Comparable to pure point cloud rendering when using the blur method [S1]. The extra operations are Householder formula calculations and combined Gaussian function evaluations, which are atomic on the GPU [S1]. Alpha blending operations scale with the size of the output screen times the number of layers on the A-buffer (or the limit of operations placed on the bubble-sort algorithm for each frame), and the size and shape of the chosen brush strokes [S1].
*   **Memory Complexity:**
    *   A-buffer memory usage can exceed available memory on complex datasets due to inefficient allocation [S1].
*   **Measured Performance:**
    *   Dragon model (566,098 points): 418 fps (blur), 444 fps (A-buffer) [S1].
    *   Monastery model (580,062 points): 420 fps (blur), 352 fps (A-buffer) [S1].
    *   3 Buddhas model (1,630,572 points): 254 fps (blur), 257 fps (A-buffer) [S1].
    *   Lucy model (14,027,872 points): 67 fps (blur), 62 fps (A-buffer) [S1].
    *   Preprocessing times: Dragon 10 seconds, 3 Buddhas 36 seconds, Lucy 1 minute, Monastery 2 minutes 29 seconds [S1].
*   **Strengths:**
    *   Better shape perception at lower resolutions and close-ups [S1].
    *   Painterly aesthetic that users perceive as higher quality [S1].
    *   Clearer perception of object curvature than circular splats [S1].
    *   Avoids blurring details found in mesh rendering [S1].
    *   90% user preference rate over surface-aligned splats for delicate shapes [S1].
*   **Limitations:**
    *   A-buffer memory inefficiency on complex datasets [S1].
    *   Large brushes cause unnatural intersection of neighboring patches due to per-pixel sorting [S1].
    *   Non-colored point clouds fail segmentation, requiring larger patches and complicating sorting [S1].
*   **When to use:** Non-photorealistic rendering, image processing, terrain modeling, and visualization of sparse or less accurate point cloud data [S1].
*   **When not to use:** When high-fidelity photorealism is required, or when memory is severely constrained for very large datasets using the A-buffer method [S1].

## Background
Stroke-based splatting was introduced in 2017 by dos Anjos et al. [S1]. It is based on the analogy between the Impressionist art movement and interactive visualization technology, leveraging the user's cultural training to recognize painterly metaphors as high-quality visualizations [S1]. The technique was implemented using OpenGL and GLSL 4.5, with preprocessing using the Point Cloud Library (PCL) [S1]. It addresses the shortcomings of current state-of-the-art point cloud visualization techniques when dealing with sparse and less accurate data or close-up interactions [S1].
