# Fullscreen Actor Pass

Also called: Single Fullscreen Actor Pass

## Overview
The Fullscreen Actor Pass is a rendering stage in the Met3D volume rendering pipeline that renders a single selected 3D actor to a fullscreen quad using an internal rendering resolution. It solves the problem of isolating the rendering of a specific volume actor for debugging, analysis, or high-quality upscaling, distinct from the standard multi-actor compositing pass. It differs from the Multisampled 3-D Actors Pass by rendering only one actor and from the 2-D UI Actors Pass by targeting the 3D scene depth buffer rather than a UI layer.

## How it works
**Inputs and Outputs:**
- Input: A scene view configuration where "single fullscreen actor mode" is enabled, and a specific actor selected in the scene view properties.
- Output: A framebuffer containing the rendered geometry/volume of the selected actor at the internal rendering resolution.

**Data Structures:**
- `MSceneViewGLWidget`: Manages the current render step state.
- `MActor`: The actor instance to be rendered.
- Internal Framebuffer: A render target with dimensions defined by the internal rendering resolution, not the viewport resolution.

**Steps:**
1. The rendering system sets the current render step to `RENDER_SCENE` by calling `MSceneViewGLWidget::renderStep()`.
2. The scene view identifies the actor selected in the scene view properties.
3. The scene view calls `MActor::renderToFullScreen()` on the selected actor.
4. The actor is rendered into the internal framebuffer.

**Parameters:**
- **Resolution:** The pass uses an internal rendering resolution instead of the viewport resolution. This allows rendering at a fixed resolution or using upscaling techniques (e.g., FSR) to reach the target resolution. If FSR is disabled, the original framebuffer is copied into a new framebuffer at the target resolution. [S1]

**Pseudocode:**
```python
def fullscreen_actor_pass(scene_view, selected_actor):
    # Step 1: Set render step to RENDER_SCENE
    scene_view.render_step = RENDER_SCENE
    
    # Step 2: Render the selected actor to fullscreen
    # The actor is rendered into an internal framebuffer
    # using an internal resolution, not the viewport resolution.
    selected_actor.render_to_fullscreen()
    
    # Note: If single fullscreen actor mode is disabled, 
    # this pass is skipped in favor of the multisampled pass.
```

**Edge Cases and Pitfalls:**
- If single fullscreen actor mode is disabled, this pass is not executed. [S1]
- The internal resolution may differ from the viewport resolution, requiring upscaling or copying. [S1]

## Subtopics

### 2-D UI Actors Pass
This variant renders all actors participating in the `RENDER_UI` pass to a UI layer. It sets the render step to `RENDER_UI` and calls `MActor::renderToUiLayer()` for each actor. If single fullscreen actor mode is enabled, only the fullscreen actor is rendered during this pass. It is primarily used for rendering 2-D interface elements (e.g., colour bars) at the target resolution without upscaling. [S1]

### Multisampled 3-D Actors Pass
This variant renders all enabled actors participating in the `RENDER_SCENE` pass when single fullscreen actor mode is disabled. It calls `MActor::render()` for each actor and uses an internal rendering resolution. It employs Order Independent Transparency for transparency rendering. [S1]

## Operating characteristics
- **Time Complexity:** Proportional to the rendering cost of a single actor (or all actors in the multisampled variant).
- **Memory Complexity:** Requires an internal framebuffer at the internal rendering resolution.
- **Strengths:** Allows focused rendering of a single actor for debugging or high-quality upscaling.
- **Limitations:** Only one actor can be rendered in single fullscreen actor mode. Overlapping volumes are composited incorrectly if more than one actor is rendered in the DVR pass (though this is a separate pass). [S1]
- **When to use:** When debugging a specific volume actor or when upscaling techniques are required for a single actor.
- **When not to use:** When multiple actors need to be composited together in a single pass.

## Background
The Fullscreen Actor Pass is part of the Met3D rendering pipeline, as documented in the Met3D developer manual. It is used in conjunction with other passes such as the Multisampled DVR pass and the Label pass to produce the final scene. The pass is designed to support internal rendering resolutions and upscaling techniques like FSR. [S1]
