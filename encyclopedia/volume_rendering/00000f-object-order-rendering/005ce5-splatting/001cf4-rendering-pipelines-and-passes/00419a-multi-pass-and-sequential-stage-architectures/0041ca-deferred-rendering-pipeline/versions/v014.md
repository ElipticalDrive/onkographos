# Deferred Rendering Pipeline

Also called: 8-Pass Deferred Rendering Pipeline

## Overview
A multi-pass deferred rendering sequence that computes depth, position/normal, materials, filtered normals, shadows, SSAO, blurred AO, and final shading in separate framebuffer objects [S1, unofficial]. It sets itself apart from the [Volume Rendering Pipeline](1318-volume-rendering-pipeline.md) by decoupling geometry traversal from shading logic, and from the [Fragment List-Based Rendering Pipeline](3488-fragment-list-based-rendering-pipeline.md) by relying on screen-space post-processing for effects like ambient occlusion rather than explicit fragment lists.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Scene geometry (represented via an OctreeDDARenderer), camera matrices (`viewMat`, `projMat`, `viewMatInv`, `projMatInv`), light position (`lightPos`), camera position (`camPos`), and boolean flags (`_useMaterials`, `_filterNormals`, `_doShadows`, `_doSSAO`).
*   **Outputs:** Final shaded image on the default framebuffer.

**Data Structures:**
The pipeline uses a sequence of Framebuffer Objects (FBOs) and associated textures. The following textures are bound to texture units `TEX_NUM_*` during `resetState()` [S1, unofficial]:
1.  `_glTexDepth`: Bound to `FBO[0]`. Stores depth information.
2.  `_glTexHitPos`: Bound to `FBO[1]`. Stores hit positions.
3.  `_glTexHitNorm`: Bound to `FBO[1]`. Stores hit normals.
4.  `_glTexHitMaterial`: Bound to `FBO[2]`. Stores material properties.
5.  `_glTexHitNormFiltered`: Bound to `FBO[3]`. Stores filtered normals.
6.  `_glTexShadows`: Bound to `FBO[4]`. Stores shadow map data.
7.  `_glTexAO`: Bound to `FBO[5]`. Stores raw SSAO results.
8.  `_glTexAOBlurred`: Bound to `FBO[6]`. Stores blurred AO results.
9.  `_glTexAONoise`: Auxiliary texture for SSAO noise.
10. `_glTexTBOMaterials`: Texture Buffer Object for materials.

**Numbered Steps:**

1.  **Depth Pass:** Bind `FBO[0]`, clear the buffer, set the `OctreeDDARenderer` mode to `DEPTH`, and draw the scene geometry.
2.  **Position/Normal Pass:** Bind `FBO[1]`, clear the buffer, use the `_programPosNorm` shader. Set uniforms `viewMatInv`, `projMatInv`, and `useDif`. Draw a full-screen quad.
3.  **Material Pass (Conditional):** If `_useMaterials` is true: Bind `FBO[2]`, clear the buffer, use `_programMaterial`, set required uniforms, and draw a full-screen quad.
4.  **Normal Filtering Pass (Conditional):** If `_filterNormals` is true: Bind `FBO[3]`, clear the buffer, use `_programNormFilter`. Set uniforms `sigma` and `bsigma` (Gaussian blur parameters). Draw a full-screen quad.
5.  **Shadow Pass (Conditional):** If `_doShadows` is true: Bind `FBO[4]`, clear the buffer, set `lightPos`, set `OctreeDDARenderer` mode to `SHADOW`, and draw the scene geometry. Else, clear `FBO[4]` to white (1.0), representing a fully lit state [S1, unofficial].
6.  **SSAO Pass (Conditional):** If `_doSSAO` is true: Bind `FBO[5]`, clear the buffer, use `_programSSAO`. Set uniforms `projMat`, `viewMat`, `camPos`, and `radius`. Draw a full-screen quad. Note: The original octree-based AO path is disabled (`#if 0`) in favor of this screen-space quad pass [S1, unofficial].
7.  **AO Blur Pass:** Bind `FBO[6]`, clear the buffer, use `_programBlur` (likely a Gaussian blur on `_glTexAO`), and draw a full-screen quad.
8.  **Final Shading Pass:** Bind the default framebuffer, clear the buffer, use `_programShading`. Set uniforms `isYUp`, `camPos`, `projMatInv`, `viewMatInv`, `lightPos`, `renderMode`, and `useMaterials`. Draw a full-screen quad.

**Pseudocode:**

```python
def deferred_rendering_pipeline(scene, camera, lights, flags):
    # Initialize FBOs and textures as described in data structures
    fbo_depth = create_fbo([GL_DEPTH_COMPONENT])
    fbo_pos_norm = create_fbo([GL_RGBA, GL_RGBA]) # Pos and Norm
    fbo_material = create_fbo([GL_RGBA])
    fbo_norm_filtered = create_fbo([GL_RGBA])
    fbo_shadows = create_fbo([GL_DEPTH_COMPONENT])
    fbo_ssaoraw = create_fbo([GL_RGBA])
    fbo_aoblur = create_fbo([GL_RGBA])
    
    # Pass 1: Depth
    bind_fbo(fbo_depth)
    clear_buffer(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT)
    set_renderer_mode(OctreeDDARenderer, MODE_DEPTH)
    draw_scene(scene)
    
    # Pass 2: Position and Normal
    bind_fbo(fbo_pos_norm)
    clear_buffer(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT)
    use_shader(_programPosNorm)
    set_uniform("viewMatInv", camera.inv_view_matrix)
    set_uniform("projMatInv", camera.inv_proj_matrix)
    set_uniform("useDif", True) # Assuming default diffuse
    draw_fullscreen_quad()
    
    # Pass 3: Materials
    if flags.use_materials:
        bind_fbo(fbo_material)
        clear_buffer(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT)
        use_shader(_programMaterial)
        set_uniform("texTBOMaterials", _glTexTBOMaterials)
        draw_fullscreen_quad()
        
    # Pass 4: Normal Filtering
    if flags.filter_normals:
        bind_fbo(fbo_norm_filtered)
        clear_buffer(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT)
        use_shader(_programNormFilter)
        set_uniform("sigma", 1.0) # Typical Gaussian sigma
        set_uniform("bsigma", 2.0) # Typical bilateral sigma
        draw_fullscreen_quad()
        
    # Pass 5: Shadows
    if flags.do_shadows:
        bind_fbo(fbo_shadows)
        clear_buffer(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT)
        set_uniform("lightPos", lights[0].position)
        set_renderer_mode(OctreeDDARenderer, MODE_SHADOW)
        draw_scene(scene)
    else:
        bind_fbo(fbo_shadows)
        clear_buffer(GL_COLOR_BUFFER_BIT, color=(1.0, 1.0, 1.0, 1.0))
        
    # Pass 6: SSAO
    if flags.do_ssao:
        bind_fbo(fbo_ssaoraw)
        clear_buffer(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT)
        use_shader(_programSSAO)
        set_uniform("projMat", camera.proj_matrix)
        set_uniform("viewMat", camera.view_matrix)
        set_uniform("camPos", camera.position)
        set_uniform("radius", 0.5) # Typical SSAO radius
        draw_fullscreen_quad()
        
    # Pass 7: AO Blur
    bind_fbo(fbo_aoblur)
    clear_buffer(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT)
    use_shader(_programBlur)
    draw_fullscreen_quad()
    
    # Pass 8: Final Shading
    bind_default_fbo()
    clear_buffer(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT)
    use_shader(_programShading)
    set_uniform("isYUp", True)
    set_uniform("camPos", camera.position)
    set_uniform("projMatInv", camera.inv_proj_matrix)
    set_uniform("viewMatInv", camera.inv_view_matrix)
    set_uniform("lightPos", lights[0].position)
    set_uniform("renderMode", MODE_FINAL)
    set_uniform("useMaterials", flags.use_materials)
    draw_fullscreen_quad()
```

**Parameters:**
*   `sigma`, `bsigma`: Gaussian blur parameters for normal filtering. Typical values not explicitly given in sources [S1, unofficial].
*   `radius`: SSAO sampling radius. Typical value 0.5 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   When shadows are disabled, `FBO[4]` is cleared to white (1.0). This acts as a default fully lit state, which must be handled correctly in the shading pass to avoid darkening the scene [S1, unofficial].
*   The SSAO pass replaces an older octree-based AO path (`#if 0`), meaning the pipeline relies entirely on screen-space techniques for ambient occlusion [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of passes (8 passes). Each pass is typically $O(N)$ where $N$ is the number of pixels or geometry primitives.
*   **Memory Complexity:** High, due to multiple FBOs and textures (depth, position, normal, material, shadow, AO, blurred AO, noise, TBO).
*   **Strengths:** Decouples geometry complexity from shading complexity; allows for efficient screen-space effects like SSAO and normal filtering.
*   **Limitations:** High memory bandwidth usage due to multiple render targets and post-processing passes; depth peeling or sorting issues may arise if not handled in the depth/position pass.
*   **When to use:** Scenes with complex lighting and materials where deferred shading benefits outweigh the memory cost.
*   **When not to use:** Memory-constrained environments or scenes with very few lights where forward rendering might be more efficient.

## Background
This pipeline is implemented in the `ssvdag` project by ajaspe [S1, unofficial]. It represents a specific implementation of deferred rendering tailored for octree-based volume rendering, integrating shadow mapping and screen-space ambient occlusion.
