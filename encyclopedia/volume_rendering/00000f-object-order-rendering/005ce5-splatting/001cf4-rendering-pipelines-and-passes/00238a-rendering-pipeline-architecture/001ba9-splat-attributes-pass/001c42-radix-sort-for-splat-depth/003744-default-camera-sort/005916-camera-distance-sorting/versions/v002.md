# Camera Distance Sorting

Also called: Mesh Sorting by Camera Distance

## Overview
Camera Distance Sorting orders visible meshes by their proximity to the camera [S1, unofficial]. It replaces default sorting sources to ensure correct back-to-front processing order for rendering passes [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A list of visible meshes with world-space positions, and the camera position [S1, unofficial].
- Output: The mesh list sorted in ascending order of distance from the camera [S1, unofficial].

**Data Structures:**
- Mesh: Contains a position field representing its location in world space [G].
- Camera: Contains a position field [G].

**Steps:**
1. For each visible mesh, compute the squared Euclidean distance between the mesh position and the camera position [S1, unofficial].
2. Sort the mesh list in ascending order using the computed squared distances as the primary key [S1, unofficial].

**Formulas:**
Let $P_m$ be the mesh position and $P_c$ be the camera position. The squared distance $D^2$ is calculated as:
$$ D^2 = \| P_m - P_c \|^2 = (x_m - x_c)^2 + (y_m - y_c)^2 + (z_m - z_c)^2 $$
where $(x_m, y_m, z_m)$ and $(x_c, y_c, z_c)$ are the respective coordinates [S1, unofficial].

**Parameters:**
- Sorting order: Ascending (nearest to furthest) [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Coordinate space:** The camera position and mesh positions must share the same coordinate system [G].
- **Ties:** The evidence does not specify stability guarantees for meshes at identical distances [S1, unofficial].

**Pseudocode:**
```python
def camera_distance_sort(meshes, camera_position):
    """
    Sorts a list of meshes by their squared distance to the camera.
    
    Args:
        meshes: List of objects with a 'position' attribute (vec3).
        camera_position: The camera's position (vec3).
        
    Returns:
        List of meshes sorted by ascending distance to the camera.
    """
    distance_list = []
    for i, mesh in enumerate(meshes):
        dx = mesh.position.x - camera_position.x
        dy = mesh.position.y - camera_position.y
        dz = mesh.position.z - camera_position.z
        squared_dist = dx*dx + dy*dy + dz*dz
        distance_list.append((squared_dist, i, mesh))
    
    distance_list.sort(key=lambda x: x[0])
    
    sorted_meshes = [item[2] for item in distance_list]
    
    return sorted_meshes
```
