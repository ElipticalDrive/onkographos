# ShaderPass


## Overview
A ShaderPass is a post-processing rendering pass that applies a custom vertex and fragment shader to a full-screen quad [S1, unofficial]. It operates by rendering a single quad that covers the viewport to process screen-space data [G].

## How it works
**Inputs and Outputs:**
- Input: A source texture bound to a uniform specified by `textureID` (default `"tDiffuse"`) [S1, unofficial].
- Output: The screen or a secondary render target (`writeBuffer`) depending on `renderToScreen` [S1, unofficial].

**Data Structures:**
The pass instance stores the following fields:
- `this.uniforms`: Dictionary of shader uniforms, initialized by copying the input shader's uniforms [S1, unofficial].
- `this.material`: Shader material instance created from shader code and uniforms [S1, unofficial].
- `this.scene`: Scene graph container holding the rendering quad [S1, unofficial].
- `this.camera`: Orthographic camera with projection bounds `(-1, 1, 1, -1, 0, 1)` [S1, unofficial].
- `this.quad`: Mesh geometry with width and height of 2 units [S1, unofficial].
- `textureID`: String uniform name for the input texture, default `"tDiffuse"` [S1, unofficial].
- `renderToScreen`: Boolean flag for direct screen output, default `true` [S1, unofficial].
- `needsSwap`: Boolean flag for buffer swap requirement, default `true` [S1, unofficial].
- `clear`: Boolean flag to clear the write buffer before rendering, default `false` [S1, unofficial].

**Steps:**
1. **Initialization:** Clone the input shader's uniforms into `this.uniforms` [S1, unofficial]. Create a shader material using `shader.defines`, `this.uniforms`, `shader.vertexShader`, and `shader.fragmentShader` [S1, unofficial]. Create an orthographic camera with bounds `(-1, 1, 1, -1, 0, 1)` [S1, unofficial]. Create a scene and add a mesh of a 2x2 plane buffer geometry as a full-screen quad [S1, unofficial]. Assign the created material to the quad [S1, unofficial].
2. **Rendering:** Assign the `readBuffer` to the texture uniform specified by `textureID` [S1, unofficial]. Assign `this.material` to the quad's material [S1, unofficial]. If `renderToScreen` is `true`, call the renderer with the scene and camera [S1, unofficial]. Otherwise, call the renderer with the scene, camera, `writeBuffer`, and `this.clear` flag [S1, unofficial].

**Pseudocode:**
```python
class ShaderMaterial:
    def __init__(self, defines, uniforms, vertex_shader, fragment_shader):
        self.defines = defines
        self.uniforms = uniforms
        self.vertex_shader = vertex_shader
        self.fragment_shader = fragment_shader

class OrthographicCamera:
    def __init__(self, left, right, top, bottom, near, far):
        self.left = left
        self.right = right
        self.top = top
        self.bottom = bottom
        self.near = near
        self.far = far

class Scene:
    def __init__(self):
        self.meshes = []
    def add(self, mesh):
        self.meshes.append(mesh)

class PlaneBufferGeometry:
    def __init__(self, width, height):
        self.width = width
        self.height = height

class Mesh:
    def __init__(self, geometry, material):
        self.geometry = geometry
        self.material = material

class ShaderPass:
    def __init__(self, shader, texture_id="tDiffuse", render_to_screen=True, needs_swap=True, clear=False):
        self.uniforms = dict(shader.uniforms)
        self.material = ShaderMaterial(shader.defines, self.uniforms, shader.vertex_shader, shader.fragment_shader)
        self.camera = OrthographicCamera(-1, 1, 1, -1, 0, 1)
        self.scene = Scene()
        self.quad = Mesh(PlaneBufferGeometry(2, 2), self.material)
        self.scene.add(self.quad)
        self.texture_id = texture_id
        self.render_to_screen = render_to_screen
        self.needs_swap = needs_swap
        self.clear = clear

    def render(self, renderer, write_buffer, read_buffer):
        self.uniforms[self.texture_id] = read_buffer
        self.quad.material = self.material
        if self.render_to_screen:
            renderer.render(self.scene, self.camera)
        else:
            renderer.render(self.scene, self.camera, write_buffer, self.clear)
```

**Parameters:**
- `textureID`: String, name of the uniform to bind the input texture to. Default: `"tDiffuse"` [S1, unofficial].
- `renderToScreen`: Boolean, if `true` renders directly to the screen, otherwise renders to `writeBuffer`. Default: `true` [S1, unofficial].
- `needsSwap`: Boolean, flag indicating buffer swap requirement. Default: `true` [S1, unofficial].
- `clear`: Boolean, whether to clear the write buffer before rendering. Default: `false` [S1, unofficial].

## Subtopics

### GrabPass
A GrabPass copies the entire frame from the back-buffer (default framebuffer) to a RenderTexture, allowing the shader to sample this texture and output results back to the back-buffer [S2, unofficial]. It is invoked using syntax like `GrabPass{ "_GrabTexture" }` to ensure the grab happens only once [S2, unofficial]. This operation performs a full frame copy, which is expensive, especially on mobile platforms, and should be used only once per frame [S2, unofficial].
