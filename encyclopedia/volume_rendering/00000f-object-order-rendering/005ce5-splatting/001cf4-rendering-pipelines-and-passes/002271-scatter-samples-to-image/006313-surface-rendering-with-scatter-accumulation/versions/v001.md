# Surface Rendering with Scatter Accumulation
Also called: Scatter Accumulation for Surface Properties

## Overview
This method is a rendering pass that queries surface properties (albedo, BRDF, normals) at ray-object hit points and scatters them into per-ray maps using a scatter operation, handling optional noise jittering and relighting outputs [S1, unofficial]. It differs from volume-based splatting by operating exclusively on discrete surface intersections rather than volumetric samples, enabling direct extraction of material properties and visibility masks for downstream relighting or metric evaluation [S1, unofficial].

## How it works
**Inputs:**
- Ray hit data: positions, normals, intersection masks (`intersect_mask`), and ray indices.
- Model parameters: `noise_std`, `albedo_scales`, `render_cfg` flags (`relight_olat`, `relight_probes`, `relight_env_map`, `white_bkgd`).
- Hit properties: raw albedo, BRDF parameters, and normals queried at hit points.

**Outputs:**
- Per-ray maps: `rgb`, `lvis` (light visibility), `normals`, `albedo`, `brdfprop`.
- Optional relighting maps: `olat` (object-local albedo), `probe` (probe contributions), `env` (environment map contributions).
- Accumulation mask: `acc_map` indicating valid hits.

**Data Structures:**
- Maps are stored as tensors with shape `(B, N_rays, ...)` where `B` is batch size and `N_rays` is the number of rays.
- `rgb`: `(B, N_rays, 3)`
- `lvis`: `(B, N_rays, 1)` or `(B, N_rays, 3)` depending on implementation.
- `normals`: `(B, N_rays, 3)`
- `albedo`: `(B, N_rays, 3)`
- `brdfprop`: `(B, N_rays, N_brdf_params)`
- `olat`: `(B, N_rays, 512, 3)` if enabled [S1, unofficial].
- `probe`: `(B, N_rays, N_probes, 3)` if enabled.
- `env`: `(B, N_rays, N_env_coeffs, 3)` if enabled.
- `acc_map`: `(B, N_rays)` boolean or float mask.

**Steps:**
1. **Query Properties:** Use `batchify_query` to retrieve albedo, BRDF, and normals at hit points [S1, unofficial]. If `model.noise_std > 0`, also query jittered versions: `albedo_jitter` and `brdf_z_jitter` [S1, unofficial].
2. **Scale Albedo:** If `albedo_scales` is provided, apply scaling: `albedo = albedo_scales.reshape(1, 3) * albedo` [S1, unofficial].
3. **Squeeze Dimensions:** Remove batch/ray dimensions from hit properties to prepare for rendering: `albedo_hit = albedo.squeeze(-2).squeeze(0)` [S1, unofficial].
4. **Render Surface Points:** Call `model.render_surf_pts` with hit positions, albedo, BRDF props, and normals to compute RGB, `olat`, `probe`, `env`, and `lvis` [S1, unofficial].
5. **Identify Hits:** Determine valid hit indices using `torch.where(intersect_mask)[0]` [S1, unofficial].
6. **Scatter Hit Properties:** Use `scatter_nd` to scatter hit properties into full ray maps: `rgb`, `lvis`, `normals`, `albedo`, and `brdfprop` [S1, unofficial].
7. **Scatter Jittered Maps:** If noise is enabled, scatter `albedo_jitter` and `brdf_z_jitter` into their respective maps [S1, unofficial].
8. **Conditionally Scatter Relighting Maps:** Based on `render_cfg` flags, scatter `olat`, `probe`, and `env` maps if `relight_olat`, `relight_probes`, or `relight_env_map` are true [S1, unofficial].
9. **Initialize Non-Hit Rays:** For rays with no intersection, initialize all maps to zeros with appropriate shapes (e.g., `olat_map` shape `(B, N_rays, 512, 3)` if enabled) [S1, unofficial].
10. **Accumulation and Background Compensation:** Compute `acc_map` from `intersect_mask`. If `white_bkgd` is true, apply white background compensation: `rgb_map = rgb_map + (1.0 - acc_map[..., None])` [S1, unofficial].

**Pseudocode:**
```python
def surface_render_with_scatter_accumulation(
    intersect_mask, hit_positions, hit_normals, hit_brdf_props,
    model, render_cfg, albedo_scales=None, noise_std=0.0
):
    # Step 1: Query properties
    albedo, brdf, normals = batchify_query(hit_positions, hit_normals, hit_brdf_props)
    albedo_jitter = None
    brdf_z_jitter = None
    if noise_std > 0:
        albedo_jitter, brdf_z_jitter = query_jittered_versions(albedo, brdf, noise_std)

    # Step 2: Scale albedo
    if albedo_scales is not None:
        albedo = albedo_scales.reshape(1, 3) * albedo

    # Step 3: Squeeze dimensions
    albedo_hit = albedo.squeeze(-2).squeeze(0)
    normals_hit = normals.squeeze(-2).squeeze(0)
    brdf_hit = brdf.squeeze(-2).squeeze(0)

    # Step 4: Render surface points
    rgb, olat, probe, env, lvis = model.render_surf_pts(
        hit_positions, albedo_hit, brdf_hit, normals_hit
    )

    # Step 5: Identify hits
    hit_indices = torch.where(intersect_mask)[0]

    # Step 6: Scatter hit properties
    rgb_map = scatter_nd(hit_indices, rgb, shape=(B, N_rays, 3))
    lvis_map = scatter_nd(hit_indices, lvis, shape=(B, N_rays, 1))
    normals_map = scatter_nd(hit_indices, normals_hit, shape=(B, N_rays, 3))
    albedo_map = scatter_nd(hit_indices, albedo_hit, shape=(B, N_rays, 3))
    brdfprop_map = scatter_nd(hit_indices, brdf_hit, shape=(B, N_rays, N_brdf_params))

    # Step 7: Scatter jittered maps
    if noise_std > 0:
        albedo_jitter_map = scatter_nd(hit_indices, albedo_jitter, shape=(B, N_rays, 3))
        brdf_z_jitter_map = scatter_nd(hit_indices, brdf_z_jitter, shape=(B, N_rays, N_brdf_params))

    # Step 8: Conditionally scatter relighting maps
    olat_map = None
    probe_map = None
    env_map = None
    if render_cfg.relight_olat:
        olat_map = scatter_nd(hit_indices, olat, shape=(B, N_rays, 512, 3))
    if render_cfg.relight_probes:
        probe_map = scatter_nd(hit_indices, probe, shape=(B, N_rays, N_probes, 3))
    if render_cfg.relight_env_map:
        env_map = scatter_nd(hit_indices, env, shape=(B, N_rays, N_env_coeffs, 3))

    # Step 9: Initialize non-hit rays
    # Initialize all maps to zeros for non-hit rays
    # This is implicitly handled by scatter_nd if it initializes the output tensor to zeros
    # and only updates hit_indices. Explicit initialization:
    rgb_map = torch.zeros((B, N_rays, 3), device=rgb_map.device)
    lvis_map = torch.zeros((B, N_rays, 1), device=lvis_map.device)
    normals_map = torch.zeros((B, N_rays, 3), device=normals_map.device)
    albedo_map = torch.zeros((B, N_rays, 3), device=albedo_map.device)
    brdfprop_map = torch.zeros((B, N_rays, N_brdf_params), device=brdfprop_map.device)
    if noise_std > 0:
        albedo_jitter_map = torch.zeros((B, N_rays, 3), device=albedo_jitter_map.device)
        brdf_z_jitter_map = torch.zeros((B, N_rays, N_brdf_params), device=brdf_z_jitter_map.device)
    if render_cfg.relight_olat:
        olat_map = torch.zeros((B, N_rays, 512, 3), device=olat_map.device)
    if render_cfg.relight_probes:
        probe_map = torch.zeros((B, N_rays, N_probes, 3), device=probe_map.device)
    if render_cfg.relight_env_map:
        env_map = torch.zeros((B, N_rays, N_env_coeffs, 3), device=env_map.device)

    # Re-scatter hits into initialized maps
    rgb_map[hit_indices] = rgb
    lvis_map[hit_indices] = lvis
    normals_map[hit_indices] = normals_hit
    albedo_map[hit_indices] = albedo_hit
    brdfprop_map[hit_indices] = brdf_hit
    if noise_std > 0:
        albedo_jitter_map[hit_indices] = albedo_jitter
        brdf_z_jitter_map[hit_indices] = brdf_z_jitter
    if render_cfg.relight_olat:
        olat_map[hit_indices] = olat
    if render_cfg.relight_probes:
        probe_map[hit_indices] = probe
    if render_cfg.relight_env_map:
        env_map[hit_indices] = env

    # Step 10: Accumulation and background compensation
    acc_map = intersect_mask.float()
    if render_cfg.white_bkgd:
        rgb_map = rgb_map + (1.0 - acc_map[..., None])

    return {
        'rgb': rgb_map,
        'lvis': lvis_map,
        'normals': normals_map,
        'albedo': albedo_map,
        'brdfprop': brdfprop_map,
        'olat': olat_map,
        'probe': probe_map,
        'env': env_map,
        'acc_map': acc_map
    }
```

**Edge Cases and Pitfalls:**
- **Precision:** Floating-point precision issues may arise when scattering sparse hits into dense maps, especially for large scenes. Use appropriate data types (e.g., float32) [S1, unofficial].
- **Boundaries:** Ensure that `scatter_nd` handles boundary conditions correctly, especially when hit indices are out of bounds [S1, unofficial].
- **Degenerate Input:** Handle cases where `intersect_mask` is all False (no hits) by initializing maps to zeros and skipping scattering steps [S1, unofficial].

## Operating characteristics
- **Time Complexity:** O(N_rays) for querying and scattering, where N_rays is the number of rays. The complexity is linear with respect to the number of rays and hit points.
- **Memory Complexity:** O(N_rays * N_properties) for storing per-ray maps, where N_properties is the number of properties (RGB, normals, albedo, etc.).
- **Measured Performance:** Performance depends on the hardware and resolution. For high-resolution scenes, memory usage can become a bottleneck [S1, unofficial].
- **Scaling:** Scales well with batch size and number of rays, but memory usage increases linearly with the number of rays.
- **Strengths:** Direct extraction of surface properties, support for noise jittering, and flexible relighting options.
- **Limitations:** Memory-intensive for large scenes, sensitive to precision issues, and requires careful handling of boundary conditions.
- **When to Use:** Suitable for applications requiring detailed surface property extraction, such as material analysis, relighting, and metric evaluation.
- **When Not to Use:** Not ideal for real-time applications with strict memory constraints or when volumetric effects are required.

## Background
This method originates from the L-Tracing framework, which focuses on surface-based rendering and property extraction [S1, unofficial]. It is used in research contexts for evaluating novel view synthesis, material estimation, and relighting techniques.
