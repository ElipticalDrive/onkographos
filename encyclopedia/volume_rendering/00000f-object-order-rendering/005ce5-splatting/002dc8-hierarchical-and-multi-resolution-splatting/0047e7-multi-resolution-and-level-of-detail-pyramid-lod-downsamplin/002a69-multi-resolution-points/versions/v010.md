# Multi-Resolution Points
Also called: Error-controlled Point Splatting, Reduced Point Cloud Rendering
## Overview
Multi-Resolution Points is a technique to render one large point in place of many small points to reduce rasterization cost and storage [S1, unofficial]. It builds on [Multi-Resolution and Level of Detail (Pyramid, LOD, Downsampling)](12128-multi-resolution-and-level-of-detail-pyramid-lod-downsamplin.md) by organizing points into a tree and using a local error metric to decide on point size [S1, unofficial].
## How it works
**Inputs:** A set of points $P = \{p_i\}$, each with position $\mathbf{x}_i$, color $\mathbf{c}_i$, and opacity $\alpha_i$ [G]. A user-defined error threshold $\epsilon$ [S1, unofficial].
**Outputs:** A subset of points $P'$ representing the scene, where each point in $P'$ may represent a cluster of original points [G].

**Data Structures:**
*   **Point Tree:** A hierarchical structure (e.g., octree or quadtree) where each node stores aggregate properties of its children: mean position $\bar{\mathbf{x}}$, mean color $\bar{\mathbf{c}}$, total opacity $\bar{\alpha}$, and a local error metric $E$ [G].
*   **Visibility Map:** A quadtree used to cull occluded nodes [S1, unofficial].

**Steps:**
1.  **Tree Construction:** Organize points into a tree [S1, unofficial]. For each internal node, compute aggregate properties as weighted averages of children [G]. Compute the local error metric $E$ for the node [S1, unofficial].
2.  **Error Metric:** Use a local error metric to decide on point size [S1, unofficial]. Laur and Hanrahan use RMS error [S1, unofficial]. For a node with children $C$, the error $E$ quantifies the deviation of children's attributes from the node's aggregate [G].
3.  **Traversal and Selection:** Traverse the tree from root to leaves [S1, unofficial]. A node is selected as a leaf (rendered as a single primitive) if its error $E \le \epsilon$ or if its projected screen-space footprint is smaller than a pixel threshold [G]. If $E > \epsilon$, recurse to children [S1, unofficial].
4.  **Occlusion Culling:** Use a visibility map quadtree to cull occluded octree nodes [S1, unofficial]. Subdivide octree nodes if not occluded [S1, unofficial]. Rasterize points that fail the occlusion test [S1, unofficial].
5.  **Update Visibility Map:** After rendering, update the visibility map [S1, unofficial].

**Pseudocode:**
```python
def render_multi_resolution_points(points, epsilon):
    tree = build_tree(points)
    compute_aggregates(tree)
    compute_error_metrics(tree, epsilon)
    selected_points = []
    traverse_and_select(tree, epsilon, selected_points)
    for p in selected_points:
        # Project to screen and draw [G]
        screen_pos = project_to_screen(p.pos)
        draw_point(screen_pos, p.color, p.opacity)

def build_tree(points):
    if len(points) <= 1:
        return LeafNode(points)
    split_axis = determine_split_axis(points)
    left_pts, right_pts = split(points, split_axis)
    return InternalNode(build_tree(left_pts), build_tree(right_pts))

def compute_aggregates(node):
    if node.is_leaf():
        node.mean_pos = node.points[0].pos
        node.mean_color = node.points[0].color
        node.total_opacity = node.points[0].opacity
        return
    node.mean_pos = weighted_avg([c.mean_pos for c in node.children], [c.total_opacity for c in node.children])
    node.mean_color = weighted_avg([c.mean_color for c in node.children], [c.total_opacity for c in node.children])
    node.total_opacity = sum(c.total_opacity for c in node.children)

def compute_error_metrics(node, epsilon):
    if node.is_leaf():
        node.error = 0
        return
    node.error = rms_error(node.children, node.mean_pos, node.mean_color)
    for child in node.children:
        compute_error_metrics(child, epsilon)

def traverse_and_select(node, epsilon, selected):
    if node.error <= epsilon:
        selected.append(node.to_primitive())
    else:
        for child in node.children:
            traverse_and_select(child, epsilon, selected)
```

**Parameters:**
*   $\epsilon$: Error threshold. User sets an error threshold to control tree traversal [S1, unofficial].

## Subtopics
## Operating characteristics
**Time and Memory Complexity:**
*   Time: Depends on tree depth and traversal. Culling occluded nodes reduces rasterization cost [S1, unofficial].
*   Memory: Less storage required by retaining only a list of relevant points [S1, unofficial].

**Measured Performance:**
*   Welsh '02: Reduced 240k points to 90k points using a frequency-space metric [S1, unofficial].

**Strengths and Limitations:**
*   Strengths: Less rasterization cost (overlap areas), less storage required [S1, unofficial]. Points provide a lossless data compression by retaining only a list of relevant points [S1, unofficial].
*   Limitations: Not given in the sources.

**When to Use:**
*   Use when reducing rasterization cost and storage is critical [S1, unofficial].
*   When not: Not given in the sources.
