# K-wise moment-matched merging with L2-optimal amplitude

Also called: cost-aware merging, substitutive LOD merging

## Overview
K-wise moment-matched merging with L2-optimal amplitude is a level-of-detail technique that reduces scene complexity by partitioning $K$ splats into a single representative splat [S1, unofficial]. It solves the substitutive-LOD problem by preserving the first and second spatial moments of the cluster to minimize geometric distortion, while explicitly optimizing the amplitude (opacity) of the merged splat to minimize the L2 integrated squared error [S1, unofficial]. It distinguishes itself from simple arithmetic averaging by preserving spatial statistics and from culling methods by retaining all visual information in a compressed form [S1, unofficial].

## How it works
**Inputs:** A set of $N$ 3D Gaussians $G = \{G_i\}$, where each $G_i$ is defined by position $\mathbf{t}_i$, covariance $\mathbf{\Sigma}_i$, opacity $\alpha_i$, and color coefficients $c_i$, plus a target cluster size $K$ [S1, unofficial].

**Outputs:** A reduced set of $N/K$ representative Gaussians $G' = \{G'_j\}$ [S1, unofficial].

**Data Structures:**
*   **Cluster:** A list of indices $\{i_1, i_2, ..., i_K\}$ mapping to the original splats [S1, unofficial].
*   **Representative Gaussian $G'_j$:**
    *   $\mathbf{t}'_j$: Position (float32).
    *   $\mathbf{\Sigma}'_j$: Covariance matrix (float32, 3x3 symmetric).
    *   $\alpha'_j$: Amplitude/Opacity (float32, optimized).
    *   $c'_j$: Color coefficients (float32, weighted average) [S1, unofficial].

**Algorithm Steps:**

1.  **Partitioning:** Partition the set of splats $G$ into disjoint clusters $C_j$ of size $K$ using one of three algorithms: greedy hierarchical (à la Runnalls), cost-increment relocation, or joint relaxation [S1, unofficial]. Cost-increment relocation matches greedy merging performance within 5.5% at compression factors of four and above [S1, unofficial].
2.  **Moment Matching (Position and Covariance):** For each cluster $C_j$, compute the total weight $W_j = \sum_{i \in C_j} \alpha_i$, the representative position $\mathbf{t}'_j = \frac{1}{W_j} \sum_{i \in C_j} \alpha_i \mathbf{t}_i$, and the covariance $\mathbf{\Sigma}'_j = \frac{1}{W_j} \sum_{i \in C_j} \alpha_i \left( \mathbf{\Sigma}_i + (\mathbf{t}_i - \mathbf{t}'_j)(\mathbf{t}_i - \mathbf{t}'_j)^T \right)$ [S1, unofficial].
3.  **L2-Optimal Amplitude:** Optimize the amplitude $\alpha'_j$ of the representative splat to minimize the L2 integrated squared error between the original cluster and the merged splat [S1, unofficial]. The optimal amplitude is derived analytically to minimize $\int \| \sum_{i \in C_j} G_i(\mathbf{x}) - G'_j(\mathbf{x}) \|^2 d\mathbf{x}$ [S1, unofficial].
4.  **Color Aggregation:** Compute the color $c'_j$ as the weighted average of the cluster colors: $c'_j = \frac{1}{W_j} \sum_{i \in C_j} \alpha_i c_i$ [S1, unofficial].

**Pseudocode:**

```python
class Gaussian:
    def __init__(self, t, Sigma, alpha, c):
        self.t = t
        self.Sigma = Sigma
        self.alpha = alpha
        self.c = c

def outer_product(v1, v2):
    return [[v1[i] * v2[j] for j in range(len(v2))] for i in range(len(v1))]

def kwise_moment_matched_merge(splats, K, partition_method='cost_increment'):
    clusters = partition(splats, K, partition_method)
    merged_splats = []
    for cluster in clusters:
        W = sum(s.alpha for s in cluster)
        t_prime = [sum(s.alpha * s.t[i] for s in cluster) / W for i in range(3)]
        Sigma_prime = [[0.0]*3 for _ in range(3)]
        for s in cluster:
            diff = [s.t[i] - t_prime[i] for i in range(3)]
            cov_add = outer_product(diff, diff)
            for r in range(3):
                for c in range(3):
                    Sigma_prime[r][c] += s.alpha * (s.Sigma[r][c] + cov_add[r][c])
        for r in range(3):
            for c in range(3):
                Sigma_prime[r][c] /= W
        c_prime = [sum(s.alpha * s.c[i] for s in cluster) / W for i in range(len(cluster[0].c))]
        # Sources do not provide the exact closed-form scalar equation for alpha_prime [S1, unofficial].
        # [G] Standard L2 amplitude optimization requires solving the normal equations for the integral of squared differences.
        alpha_prime = 1.0
        merged_splats.append(Gaussian(t=t_prime, Sigma=Sigma_prime, alpha=alpha_prime, c=c_prime))
    return merged_splats

def partition(splats, K, method):
    # Supports: 'greedy_hierarchical', 'cost_increment', 'joint_relaxation' [S1, unofficial]
    # Simple chunking for demonstration; production code implements the specified algorithm.
    return [splats[i:i+K] for i in range(0, len(splats), K)]
```

**Edge Cases and Pitfalls:**
*   **Precision:** Quantization fidelity (uint16 centres, uint8 Cholesky factors) impacts results, with PSNR changes of at most -0.679 dB on fresh float32 fits [S1, unofficial].
*   **Sparse Subsamples:** On sparse subsamples, mass-ranked culling may outperform this merging method in the median [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the partitioning algorithm; cost-increment relocation is noted to be efficient, matching greedy performance [S1, unofficial].
*   **Memory Complexity:** Reduces memory usage by a factor of $K$ [S1, unofficial].
*   **Performance:** On full fits, cost-aware merging outperforms mass-ranked culling regardless of amplitude refit [S1, unofficial]. On sparse subsamples, culling wins in the median [S1, unofficial].
*   **Strengths:** Preserves visual fidelity better than culling on dense data [S1, unofficial].
*   **Limitations:** May be less effective than culling on sparse data [S1, unofficial].
