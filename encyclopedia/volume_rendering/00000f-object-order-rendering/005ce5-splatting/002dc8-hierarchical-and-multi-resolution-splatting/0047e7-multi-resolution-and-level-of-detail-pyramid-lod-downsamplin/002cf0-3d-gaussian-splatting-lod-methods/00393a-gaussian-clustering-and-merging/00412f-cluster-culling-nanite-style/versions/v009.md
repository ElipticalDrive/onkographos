# Cluster Culling (Nanite-style)

Also called: FClusterCullingCS, FClusterCullingResetCS

## Overview
Cluster Culling (Nanite-style) is a hierarchical frustum culling and Level of Detail (LOD) selection system for 3D Gaussian Splatting, designed to efficiently cull invisible or low-priority clusters from the rendering pipeline [S1, unofficial]. It operates on a pre-computed hierarchy of Gaussian clusters, testing each cluster's bounding volume against the view frustum and calculating screen-space error to determine the appropriate LOD level [S1, unofficial]. Unlike sibling methods that focus on the *merging* of Gaussians (e.g., [K-wise moment-matched merging](5440-k-wise-moment-matched-merging-with-l2-optimal-merging.md) or [Hierarchical Gaussian Merging](8358-hierarchical-gaussian-merging.md)), this method focuses on the *selection* and *culling* of those clusters for rendering, enabling performance scaling similar to Unreal Engine's Nanite system [G].

## How it works
The method consists of two primary compute shader stages: a reset stage to initialize buffers and a culling stage to determine visibility and LOD [S1, unofficial].

### Inputs and Outputs
**Inputs:**
- `ClusterBuffer`: A structured buffer containing `FGaussianGPUCluster` objects [S1, unofficial].
- `FrustumPlanes`: An array of 6 plane vectors defining the view frustum in world space [S1, unofficial].
- `LocalToWorld`: A $4 \times 4$ transformation matrix from local cluster space to world space [S1, unofficial].
- `WorldToClip`: A $4 \times 4$ projection matrix from world space to clip space [S1, unofficial].
- `CameraPosition`: The camera's position in world space [S1, unofficial].
- `ScreenHeight`: The height of the viewport in pixels [S1, unofficial].
- `ErrorThreshold`: The maximum allowable screen-space error for a cluster to be rendered at a lower LOD [S1, unofficial].
- `LODBias`: A bias added to the calculated screen-space error to favor lower LODs [S1, unofficial].
- `MaxDrawDistance`: The maximum distance from the camera at which clusters are considered for visibility [S1, unofficial].
- `LeafClusterCount`: The number of leaf clusters in the hierarchy [S1, unofficial].
- `ClusterCount`: The total number of clusters in the hierarchy [S1, unofficial].
- `UseLODRendering`: A flag indicating whether LOD rendering is enabled [S1, unofficial].
- `DebugForceLODLevel`: A debug parameter to force a specific LOD level (-1 for auto, 0 for leaf, 1+ for specific level) [S1, unofficial].

**Outputs:**
- `VisibleClusterBuffer`: A buffer containing indices of visible clusters [S1, unofficial].
- `VisibleClusterCountBuffer`: A counter for the number of visible clusters [S1, unofficial].
- `IndirectDrawArgsBuffer`: Indirect draw arguments for the rendering engine [S1, unofficial].
- `ClusterVisibilityBitmap`: A bitmap indicating the visibility status of each cluster [S1, unofficial].
- `SelectedClusterBuffer`: A buffer of selected cluster indices for rendering [S1, unofficial].
- `LODClusterBuffer`: A buffer of clusters selected for specific LOD levels [S1, unofficial].
- `LODClusterCountBuffer`: A counter for clusters at each LOD level [S1, unofficial].
- `LODClusterSelectedBitmap`: A bitmap for LOD cluster selection [S1, unofficial].
- `LODSplatTotalBuffer`: Total number of splats in visible LOD clusters [S1, unofficial].
- `LODSplatOutputCountBuffer`: Count of splats to be output [S1, unofficial].

### Data Structures
**FGaussianGPUCluster:**
Layout details are Not given in the sources [S1, unofficial]. The culling stage accesses at minimum `Center` (world-space position), `Radius` (bounding sphere radius), `LODLevel` (current LOD index), and `SplatCount` (number of Gaussians in the cluster) [G].

### Steps
1. **Reset Stage (`FClusterCullingResetCS`):** Initialize `VisibleClusterCountBuffer` to 0, initialize `IndirectDrawArgsBuffer` with default values, and clear `ClusterVisibilityBitmap`, `SelectedClusterBuffer`, `LODClusterBuffer`, `LODClusterCountBuffer`, `LODClusterSelectedBitmap`, `LODSplatTotalBuffer`, and `LODSplatOutputCountBuffer` [S1, unofficial].
2. **Culling Stage (`FClusterCullingCS`):** For each cluster `i` in `ClusterBuffer`:
   - If `DebugForceLODLevel` is not -1, override `LODLevel` to `DebugForceLODLevel` [S1, unofficial].
   - Extract the cluster's world-space bounding sphere center $\mathbf{c}$ and radius $r$ [G].
   - **Frustum Culling:** Test the bounding sphere against each of the 6 frustum planes [S1, unofficial]. A sphere is inside the frustum if the distance from the sphere center to each plane is greater than or equal to the radius: $d_i = \mathbf{n}_i \cdot \mathbf{c} + d_i \ge r$ for all $i \in \{0, \dots, 5\}$ [G]. If the sphere is outside any plane, mark the cluster as invisible and skip further processing [S1, unofficial].
   - **Distance Culling:** Calculate the distance from the camera to the cluster center: $dist = \| \mathbf{c} - \mathbf{CameraPosition} \|$ [G]. If $dist > MaxDrawDistance$, mark the cluster as invisible [S1, unofficial].
   - **LOD Selection:** If the cluster is visible and `UseLODRendering` is enabled, project the cluster's bounding sphere to screen space to estimate its screen-space radius $r_{screen}$ [G]. Calculate the screen-space error $E$ based on the cluster's size and distance [G]. If $E > ErrorThreshold + LODBias$, select a higher LOD level (coarser cluster) if available [S1, unofficial]. If no higher LOD is available or the error is within threshold, select the current cluster [G].
   - **Visibility Update:** If the cluster is selected, append its index to `SelectedClusterBuffer` [S1, unofficial]. Update `ClusterVisibilityBitmap` to mark the cluster as visible [S1, unofficial]. Add its `SplatCount` to `LODSplatTotalBuffer` [G].
3. Update `VisibleClusterCountBuffer` with the number of selected clusters and update `IndirectDrawArgsBuffer` with the total number of instances and splats [S1, unofficial].

### Pseudocode
```python
# Standard vector/matrix helpers
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def length(v):
    return (sum(x * x for x in v)) ** 0.5

def mat_mul_vec(M, v):
    # M is 4x4 row-major, v is 4-component vector
    return [dot(M[r], v) for r in range(4)]

# FClusterCullingResetCS
def FClusterCullingResetCS(
    VisibleClusterCountBuffer,
    IndirectDrawArgsBuffer,
    ClusterVisibilityBitmap,
    SelectedClusterBuffer,
    LODClusterBuffer,
    LODClusterCountBuffer,
    LODClusterSelectedBitmap,
    LODSplatTotalBuffer,
    LODSplatOutputCountBuffer,
    ClusterVisibilityBitmapSize,
    LeafClusterCount,
    DebugForceLODLevel
):
    # Initialize counters
    VisibleClusterCountBuffer[0] = 0
    IndirectDrawArgsBuffer[0] = 0  # Draw count
    IndirectDrawArgsBuffer[1] = 0  # Instance count
    IndirectDrawArgsBuffer[2] = 0  # Start index
    IndirectDrawArgsBuffer[3] = 0  # Start offset

    # Clear bitmaps and buffers
    for i in range(ClusterVisibilityBitmapSize):
        ClusterVisibilityBitmap[i] = 0
    LODClusterSelectedBitmap[0] = 0
    LODSplatTotalBuffer[0] = 0
    LODSplatOutputCountBuffer[0] = 0

# FClusterCullingCS
def FClusterCullingCS(
    ClusterBuffer,
    VisibleClusterBuffer,
    VisibleClusterCountBuffer,
    IndirectDrawArgsBuffer,
    ClusterVisibilityBitmap,
    SelectedClusterBuffer,
    LODClusterBuffer,
    LODClusterCountBuffer,
    LODClusterSelectedBitmap,
    LODSplatTotalBuffer,
    LocalToWorld,
    WorldToClip,
    ClusterCount,
    LeafClusterCount,
    FrustumPlanes,
    CameraPosition,
    ScreenHeight,
    ErrorThreshold,
    LODBias,
    MaxDrawDistance,
    UseLODRendering,
    DebugForceLODLevel
):
    visible_count = 0
    total_splats = 0

    for i in range(ClusterCount):
        cluster = ClusterBuffer[i]

        # Debug force LOD
        lod_level = cluster.LODLevel
        if DebugForceLODLevel != -1:
            lod_level = DebugForceLODLevel

        # Transform center to world space if not already
        center = cluster.Center
        radius = cluster.Radius

        # Frustum Culling
        visible = True
        for plane in FrustumPlanes:
            # plane is (normal, distance)
            dist = dot(plane.normal, center) + plane.distance
            if dist < radius:
                visible = False
                break

        if not visible:
            continue

        # Distance Culling
        dist_to_camera = length([center[0] - CameraPosition[0], center[1] - CameraPosition[1], center[2] - CameraPosition[2]])
        if dist_to_camera > MaxDrawDistance:
            continue

        # LOD Selection
        if UseLODRendering and DebugForceLODLevel == -1:
            # Project radius to screen space
            clip_center = mat_mul_vec(WorldToClip, center + [0.0, 0.0, 0.0, 1.0])
            if clip_center[3] > 0.0:
                ndc_radius = radius / clip_center[3] * ScreenHeight / 2.0
                # Calculate error
                error = ndc_radius / (lod_level + 1)
                if error > ErrorThreshold + LODBias:
                    # LOD selection logic not specified in sources [G]
                    lod_level = lod_level + 1

        # Mark as visible
        ClusterVisibilityBitmap[i] = 1
        SelectedClusterBuffer[visible_count] = i
        visible_count += 1

        # Count splats
        total_splats += cluster.SplatCount

    # Update output buffers
    VisibleClusterCountBuffer[0] = visible_count
    IndirectDrawArgsBuffer[1] = visible_count  # Instance count
    IndirectDrawArgsBuffer[0] = total_splats   # Draw count
    LODSplatTotalBuffer[0] = total_splats
```

### Parameters
- `FrustumPlanes`: Array of 6 plane vectors [S1, unofficial].
- `ErrorThreshold`: Threshold for screen-space error calculation. Typical value: Not given in the sources.
- `LODBias`: Bias applied to LOD selection. Typical value: Not given in the sources.
- `MaxDrawDistance`: Maximum distance for cluster visibility. Typical value: Not given in the sources.
- `DebugForceLODLevel`: Debug parameter to force a specific LOD level. Typical value: -1 (auto) [S1, unofficial].
- `THREADGROUP_SIZE`: Compilation define set to 64 for `FClusterCullingCS` [S1, unofficial].

### Edge Cases and Pitfalls
- **Precision:** Frustum culling tests should use sufficient precision to avoid false negatives/positives for clusters on the frustum boundary [G].
- **Degenerate Input:** Clusters with zero radius or splat count should be handled gracefully (e.g., skipped or treated as invisible) [G].
- **LOD Selection:** The exact formula for screen-space error and LOD selection is not provided in the sources [S1, unofficial]. Implementers must derive this based on the specific Gaussian representation and desired visual quality [G].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of clusters, as each cluster is processed once in the culling stage [G].
- **Memory Complexity:** $O(N)$ for storing cluster data and visibility buffers [G].
- **Performance:** Performance scales with the number of clusters and the complexity of the frustum culling test [G]. The use of compute shaders allows for parallel processing of clusters [G].
- **Strengths:** Efficient culling of invisible clusters, adaptive LOD selection based on screen-space error, integration with hierarchical clustering structures [G].
- **Limitations:** Dependent on the quality of the pre-computed cluster hierarchy [G]. LOD selection logic is not fully specified in the sources [S1, unofficial].
- **When to use:** When rendering large scenes with many Gaussian splats and requiring efficient frustum culling and LOD management [G].
- **When not to use:** For small scenes where the overhead of hierarchical culling is not justified [G].

## Background
Cluster Culling (Nanite-style) is inspired by Unreal Engine's Nanite virtualized geometry system, which uses hierarchical clustering and culling to render large amounts of geometry efficiently [G]. In the context of 3D Gaussian Splatting, it adapts this concept to manage the rendering of Gaussian splats by clustering them and culling invisible or low-priority clusters [S1, unofficial]. The method is implemented in the OpenSplat4D project [S1, unofficial], which provides a native 4D implementation of Gaussian splatting [S1, unofficial].
