# World Space Clustering

Also called: Single linkage merging

## Overview
World Space Clustering is a preprocessing step in 3D Gaussian Splatting that groups sampling pixels into clusters based on their geometric proximity in world space [S1, unofficial]. It solves the problem of redundant or noisy Gaussian primitives by removing foreground or background pixels that do not contribute to the primary surface representation [S1, unofficial]. It is distinguished from attribute-space methods (like color-based segmentation) by relying solely on spatial coordinates rather than appearance or scale attributes [S1, unofficial][S2].

## How it works
**Inputs:** A set of 2D sampling pixels, each associated with a 3D Gaussian kernel. For each pixel, the algorithm obtains the corresponding world-space coordinate covered by the Gaussian kernel.
**Outputs:** A set of disjoint clusters of pixels. Pixels belonging to the same cluster are merged or processed together; isolated pixels (outliers) are removed.

**Data Structures:**
*   **Point Set:** A list of 3D world-space coordinates $\mathbf{p}_k$ for each pixel $k$ covered by a Gaussian.
*   **Clusters:** A set of disjoint subsets of pixel indices. Initially, each pixel forms its own cluster.

**Parameters:**
*   **Initial Threshold ($T_0$):** $5 \cdot \delta_d$, where $\delta_d$ is the world-space distance between two adjacent pixels at the depth of the Gaussian kernel’s central pixel [S1, unofficial].
*   **Failure Multiplier:** 1.5 (used if clustering fails) [S1, unofficial].
*   **Opacity Pruning Threshold:** 0.005 (Gaussians with opacity below this are pruned prior to clustering) [S1, unofficial].
*   **Pixel Coverage Threshold:** 25 pixels (Gaussians covering fewer than this are pruned) [S1, unofficial].

**Steps:**
1.  **Pruning:** Remove any Gaussian primitives with opacity $\alpha < 0.005$ or those covering fewer than 25 pixels [S1, unofficial].
2.  **Coordinate Extraction:** For each remaining Gaussian, compute the world-space coordinates $\mathbf{p}_k$ for all pixels $k$ covered by the 2D Gaussian kernel [S1, unofficial].
3.  **Distance Calculation:** Compute $\delta_d$, the world-space distance between two adjacent pixels at the depth of the central pixel of the Gaussian kernel [S1, unofficial].
4.  **Initialization:** Set the termination threshold $T = T_0 = 5 \cdot \delta_d$ [S1, unofficial]. Initialize each pixel coordinate as a separate cluster.
5.  **Iterative Merging (Single Linkage):**
    *   Find the pair of distinct clusters $(C_a, C_b)$ with the minimum distance between any two points from distinct clusters:
        $$ d(C_a, C_b) = \min_{\mathbf{p}_i \in C_a, \mathbf{p}_j \in C_b} \| \mathbf{p}_i - \mathbf{p}_j \| $$
    *   If $d(C_a, C_b) < T$, merge $C_a$ and $C_b$ into a single cluster [S1, unofficial].
    *   Repeat until only one cluster remains or no pair of clusters has a distance less than $T$ [S1, unofficial].
6.  **Failure Handling:** If the process fails to produce a valid clustering (e.g., too many small clusters or computational timeout), update $T \leftarrow 1.5 \cdot T$ and repeat steps 5–6 [S1, unofficial].

**Pseudocode:**
```python
def world_space_clustering(gaussians):
    # Step 1: Pruning
    valid_gaussians = []
    for g in gaussians:
        if g.opacity >= 0.005 and g.pixel_count >= 25:
            valid_gaussians.append(g)
    
    # Step 2: Coordinate Extraction
    points = [] # List of (pixel_index, world_coord)
    for g in valid_gaussians:
        for k in g.covered_pixels:
            points.append((k, g.get_world_coord(k)))
            
    if not points:
        return []

    # Step 3: Distance Calculation
    central_pixel = points[0][0] # Assume first point's gaussian central pixel
    depth = get_depth(central_pixel)
    delta_d = world_distance_between_adjacent_pixels(depth)
    
    # Step 4: Initialization
    threshold = 5.0 * delta_d
    clusters = {p[0]: {p[0]} for p in points} # Map pixel_idx -> set of pixel_idxs
    point_map = {p[0]: p[1] for p in points}
    
    # Step 5: Iterative Merging
    max_iterations = 1000
    iteration = 0
    while iteration < max_iterations:
        iteration += 1
        min_dist = float('inf')
        merge_pair = None
        
        # Find closest pair of clusters
        cluster_ids = list(clusters.keys())
        for i in range(len(cluster_ids)):
            for j in range(i + 1, len(cluster_ids)):
                c1 = cluster_ids[i]
                c2 = cluster_ids[j]
                # Single linkage: min distance between any two points
                dist = min(
                    world_distance(point_map[p1], point_map[p2])
                    for p1 in clusters[c1]
                    for p2 in clusters[c2]
                )
                if dist < min_dist:
                    min_dist = dist
                    merge_pair = (c1, c2)
        
        if merge_pair is None or min_dist >= threshold:
            break
            
        c1, c2 = merge_pair
        # Merge clusters
        clusters[c1].update(clusters[c2])
        del clusters[c2]
        
    # Step 6: Failure Handling
    # Note: The source implies repeating the procedure with increased threshold if it "fails".
    # A simple implementation might just return the clusters found.
    # If strict failure detection is needed, check cluster count vs expected.
    
    return clusters
```

## Subtopics

### Coarse-Level Color-Based Segmentation
A variant that groups 3D Gaussians based on approximate view-independent colors rather than pure spatial proximity [S2]. It serves as a coarse-level decomposition of the scene, aligning with transfer-function-based classification [S2].
*   **Definition:** Groups Gaussians by color similarity in RGB space [S2].
*   **Steps:**
    1.  Approximate view-independent color $\tilde{c}$ for each Gaussian by averaging view-dependent colors $c_d$ across sampled directions $D$:
        $$ \tilde{c} \approx \frac{1}{\|D\|} \sum_{d \in D} c_d $$
    2.  Apply a clustering algorithm (e.g., k-means) to group Gaussians based on $\tilde{c}$ using Euclidean distance in RGB space [S2].
    3.  **Outlier Removal:** For each Gaussian, search for neighbors within a small-radius sphere. Remove the Gaussian if the neighbor count falls below a predefined threshold [S2].
*   **When to choose:** When semantic or material-based segmentation is required prior to fine-level affinity-based segmentation [S2].

## Operating characteristics
*   **Time Complexity:** Depends on the number of pixels $N$ and the clustering algorithm. Single linkage merging can be $O(N^2)$ or $O(N \log N)$ with efficient data structures (e.g., KD-trees) for nearest-neighbor searches.
*   **Memory Complexity:** $O(N)$ to store point coordinates and cluster assignments.
*   **Strengths:** Effective at removing noise and redundant background/foreground pixels [S1, unofficial]. Computationally lightweight compared to full optimization.
*   **Limitations:** Relies on accurate depth estimation for $\delta_d$ [S1, unofficial]. May merge distinct objects if they are spatially close but semantically different (addressed by color-based variants) [S2].
*   **When to use:** As a preprocessing step before projecting Gaussians into world space [S1, unofficial].
*   **When not:** When fine-grained structural separation is required without color cues [S2].

## Background
Originating from the need to optimize 3D Gaussian Splatting representations, this method adapts single linkage merging (Sibson 1973) to the context of Gaussian primitives [S1, unofficial]. It is used in frameworks like Augmented Radiance Field to enhance Gaussian Splatting by reducing redundancy [S1, unofficial]. The color-based variant is used in VolSegGS for volumetric scene segmentation [S2].
