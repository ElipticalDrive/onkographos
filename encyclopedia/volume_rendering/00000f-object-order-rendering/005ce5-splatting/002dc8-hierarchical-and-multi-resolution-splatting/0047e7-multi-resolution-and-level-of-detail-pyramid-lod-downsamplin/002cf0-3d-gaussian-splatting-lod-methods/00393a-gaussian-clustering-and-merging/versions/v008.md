# Gaussian clustering and merging

Also called: Gaussian merging, Gaussian LOD generation, Hierarchical Gaussian Splatting

## Overview
Gaussian clustering and merging reduces the computational cost of 3D Gaussian Splatting (3DGS) by grouping spatially or attribute-similar Gaussians into single representative primitives, thereby creating a hierarchy of levels of detail (LOD) [S1, S2, unofficial]. Unlike simple culling which discards primitives, these methods retain scene information by approximating clusters with fewer, larger Gaussians [S1, unofficial]. They differ from sibling methods in their specific merging metrics: some prioritize moment preservation for visual fidelity (e.g., K-wise moment-matching), while others prioritize memory efficiency via virtual memory paging or spatial culling (e.g., Nanite-style) [S1, S2, unofficial].

## Shared principles
All methods in this family operate on a set of 3D Gaussians $G = \{G_i\}$, where each $G_i$ is defined by position $\mathbf{t}_i$, covariance matrix $\mathbf{\Sigma}_i$ (parameterized by scale $\mathbf{s}_i$ and rotation $\mathbf{q}_i$), opacity $\alpha_i$, and color coefficients $c_i$ (typically spherical harmonics) [S1, S2, unofficial].

The core mechanism involves two phases:
1.  **Clustering/Partitioning:** The set $G$ is partitioned into disjoint clusters $C_k$. Partitioning strategies vary:
    *   **Spatial:** Based on 3D proximity, often using bounding volumes or Morton codes [S1, S2, unofficial].
    *   **Attribute-based:** Based on similarity in position, color, and scale, often using k-means in multidimensional space [S1, unofficial].
    *   **Screen-space/World-space:** Based on projected pixel coverage or world-space coordinate density [S1, S2, unofficial].
2.  **Merging/Aggregation:** Each cluster $C_k$ is replaced by a single representative Gaussian $G'_k$. The parameters of $G'_k$ are derived from the parameters of $\{G_i\}_{i \in C_k}$ using aggregation functions such as arithmetic mean, weighted mean, or moment matching [S1, S2, unofficial].

Common constraints include:
*   **LOD Hierarchy:** Merging is often iterative, generating levels $L_0, L_1, \dots$ where $|L_{j+1}| < |L_j|$ [S1, unofficial].
*   **Virtual Memory:** Methods may map virtual pages of Gaussians to physical GPU memory, swapping LOD levels based on camera distance or memory pressure [S1, unofficial].
*   **Scale Handling:** Direct averaging of scales often results in undersized Gaussians; methods may apply scaling factors, preserve maximum scale, or use moment-matching to preserve spatial extent [S1, S2, unofficial].

## Subtopics

### [K-wise moment-matched merging with L2-optimal amplitude](5440-k-wise-moment-matched-merging-with-l2-optimal-amplitude.md)
K-wise moment-matched merging reduces $K$ Gaussians to one by matching the first and second spatial moments and optimizing amplitude to minimize L2 error [5440-k-wise-moment-matched-merging-with-l2-optimal-amplitude.md]. It preserves spatial extent better than arithmetic averaging. Partitioning uses greedy hierarchical merging, cost-increment relocation, or joint relaxation. The merged position is $\mathbf{t}'_k = \frac{1}{W} \sum w_i \mathbf{t}_i$ and covariance $\mathbf{\Sigma}'_k = \frac{1}{W} \sum w_i (\mathbf{\Sigma}_i + (\mathbf{t}_i - \mathbf{t}'_k)(\mathbf{t}_i - \mathbf{t}'_k)^T)$ where $w_i = \alpha_i$. Amplitude $\alpha'_k$ minimizes $\int \| \alpha \cdot \mathcal{G}' - \sum \alpha_i \mathcal{G}_i \|^2 d\mathbf{x}$. Color is weighted average. Choose when visual fidelity of merged regions is critical.

### [Hierarchical Gaussian Merging](8358-hierarchical-gaussian-merging.md)
Hierarchical Gaussian Merging generates LODs by iteratively clustering and averaging position, opacity, and color, but explicitly excludes scale from averaging to preserve local geometry [8358-hierarchical-gaussian-merging.md]. It supports virtual memory paging. Clustering is spatial. Scale handling is ambiguous in sources; implementation requires fallback (e.g., max scale). Choose for memory-efficient LOD with preserved geometric detail.

### [LOD Generation for 3DGS](8408-lod-generation-for-3dgs.md)
This method uses k-means clustering on multidimensional attributes (position, rotation, color) to merge Gaussians within virtual memory pages [8408-lod-generation-for-3dgs.md]. It distinguishes itself by dynamic threshold adjustment to prevent visual popping and scaling merged Gaussians by a fixed factor to prevent undersizing. It allows multiple virtual pages in a single physical page. Choose for dynamic memory management and stability.

### [Cluster Culling (Nanite-style)](10402-cluster-culling-nanite-style.md)
Cluster Culling is a hierarchical spatial culling and LOD selection mechanism emulating Nanite [10402-cluster-culling-nanite-style.md]. It operates via compute shaders, performing frustum culling and screen-space error-based LOD selection on pre-computed clusters. It focuses on the *selection* phase rather than the merging algorithm itself. Choose for high-performance rendering with complex scenes requiring efficient visibility determination.

### [World Space Clustering](13206-world-space-clustering.md)
World Space Clustering is a preprocessing technique that converts 2D screen-space pixel coverage to world-space coordinates and applies single-linkage hierarchical clustering [13206-world-space-clustering.md]. It relies exclusively on geometric proximity, not color or scale, to remove noise and manage coverage. Choose for noise reduction and robust coverage management.

### Gaussian Cluster Builder
A builder class for constructing hierarchical cluster structures from Gaussian splat data, implementing Nanite-style spatial clustering [S1, unofficial]. It sorts splats by Morton code, groups them into leaf clusters, and recursively merges them into parent nodes, calculating bounding volumes and error metrics [S1, unofficial]. Parameters include `SplatsPerCluster` (default 128), `MaxChildrenPerCluster` (default 8), `bReorderSplats` (default true), `bGenerateLOD` (default true), and `LODReductionRatio` (default 4) [S1, unofficial].

### Cluster Hierarchy Construction
This step calculates the global bounding box of all splats and builds parent levels by merging child clusters using `BuildParentLevel` [S1, unofficial]. It uses `FSplatSortEntry` structures (MortonCode, OriginalIndex) for sorting [S1, unofficial]. It relies on the same parameters as the Gaussian Cluster Builder: `SplatsPerCluster` (128), `MaxChildrenPerCluster` (8), `bReorderSplats` (true), `bGenerateLOD` (true), and `LODReductionRatio` (4) [S1, unofficial].

### Inter-leaf node clustering
A post-processing step that merges neighboring Gaussian blocks across leaf node boundaries to form larger Gaussians for homogeneous regions [S2, unofficial]. It stores intermediate LOD results as leaf nodes and runs spatial variance estimation on groups of 26 neighbors (faces, edges, corners of a 2x2x2 node) [S2, unofficial]. If variance is below a threshold, the group is replaced by a single merged Gaussian with position as the centroid and bounding box defined by $bboxmin = \min_i cmin_i$ and $bboxmax = \max_i cmax_i$ [S2, unofficial]. Choose for refining homogeneous regions across cluster boundaries.

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [G]. The need for LOD and clustering arose due to the high memory and computational cost of rendering millions of Gaussians. Early LOD methods for 3DGS adapted techniques from point cloud rendering and volumetric rendering. Hierarchical approaches like H-3DGS [10279-hierarchical-3d-gaussian-splatting-h-3dgs.md] and SPTs [10290-sequential-point-trees-spts.md] established the foundation for spatial partitioning. Subsequent works like CityGaussian/VastGaussian [6143-citygaussian-vastgaussian-dogaussian.md] and LightGaussian [8036-lightgaussian.md] focused on attribute-based simplification. The specific clustering and merging techniques described here, such as moment-matching [S1, unofficial] and Nanite-style culling [S1, unofficial], are derived from recent research and unofficial implementations aiming to balance visual quality with real-time performance. The inter-leaf clustering method is described in the context of VDB dataset approximation [S2, unofficial].
