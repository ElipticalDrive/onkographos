# K-wise moment-matched merging with L2-optimal amplitude

Also called: cost-aware merging, substitutive LOD merging

## Overview
K-wise moment-matched merging with L2-optimal amplitude is a level-of-detail technique that reduces the complexity of a 3D Gaussian Splatting scene by partitioning $K$ splats into a single representative splat [S1, unofficial]. It solves the substitutive-LOD problem by preserving the first and second spatial moments of the cluster to minimize geometric distortion, while explicitly optimizing the amplitude (opacity) of the merged splat to minimize the L2 integrated squared error [S1, unofficial]. It distinguishes itself from simple arithmetic averaging by providing a closed-form geometric interpretation of merging error and from culling methods by retaining all visual information in a compressed form [S1, unofficial].

## How it works
**Inputs:** A set of $N$ 3D Gaussians $G = \{G_i\}$, where each $G_i$ is defined by position $\mathbf{t}_i$, covariance $\mathbf{\Sigma}_i$, opacity $\alpha_i$, and color coefficients $c_i$. A target cluster size $K$.

**Outputs:** A reduced set of $N/K$ representative Gaussians $G' = \{G'_j\}$.

**Data Structures:**
*   **Cluster:** A list of indices $\{i_1, i_2, ..., i_K\}$ mapping to the original splats.
*   **Representative Gaussian $G'_j$:**
    *   $\mathbf{t}'_j$: Position (float32).
    *   $\mathbf{\Sigma}'_j$: Covariance matrix (float32, 3x3 symmetric).
    *   $\alpha'_j$: Amplitude/Opacity (float32, optimized).
    *   $c'_j$: Color coefficients (float32, weighted average).

**Algorithm Steps:**

1.  **Partitioning:** Partition the set of splats $G$ into disjoint clusters $C_j$ of size $K$. The source specifies three partitioning algorithms [S1, unofficial]:
    *   Greedy hierarchical (à la Runnalls).
    *   Cost-increment relocation.
    *   Joint relaxation.
    *   *Note:* Cost-increment relocation matches greedy merging performance within 5.5% at compression factors of four and above [S1, unofficial].

2.  **Moment Matching (Position and Covariance):** For each cluster $C_j$, compute the total weight $W_j$ and the representative position $\mathbf{t}'_j$ and covariance $\mathbf{\Sigma}'_j$ using the standard moment-matching formulas [S1, unofficial]:
    $$ W_j = \sum_{i \in C_j} \alpha_i $$
    $$ \mathbf{t}'_j = \frac{1}{W_j} \sum_{i \in C_j} \alpha_i \mathbf{t}_i $$
    $$ \mathbf{\Sigma}'_j = \frac{1}{W_j} \sum_{i \in C_j} \alpha_i \left( \mathbf{\Sigma}_i + (\mathbf{t}_i - \mathbf{t}'_j)(\mathbf{t}_i - \mathbf{t}'_j)^T \right) $$

3.  **L2-Optimal Amplitude:** Optimize the amplitude $\alpha'_j$ of the representative splat to minimize the L2 integrated squared error between the original cluster and the merged splat. The source identifies L2 as the primary cost metric for this method [S1, unofficial]. The optimal amplitude is derived analytically to minimize $\int \| \sum_{i \in C_j} G_i(\mathbf{x}) - G'_j(\mathbf{x}) \|^2 d\mathbf{x}$.
    *   *Implementation Note:* The exact closed-form scalar equation for $\alpha'_j$ is not explicitly provided in the source text, but it is described as "L2-optimal" [S1, unofficial]. It relies on the analytical merging framework of [Analytical Merging of Gaussian Splats](5681-analytical-merging-of-gaussian-splats.md) which provides the geometric interpretation of relative merging error [S1, unofficial].

4.  **Color Aggregation:** Compute the color $c'_j$ as the weighted average of the cluster colors:
    $$ c'_j = \frac{1}{W_j} \sum_{i \in C_j} \alpha_i c_i $$

**Edge Cases and Pitfalls:**
*   **Precision:** The source notes that quantization fidelity (uint16 centres, uint8 Cholesky factors) can impact results, with PSNR changes of at most -0.679 dB on fresh float32 fits [S1, unofficial].
*   **Sparse Subsamples:** On sparse subsamples, mass-ranked culling may outperform this merging method in the median [S1, unofficial].

## Subtopics

### [Analytical Merging of Gaussian Splats](5681-analytical-merging-of-gaussian-splats.md)
Provides the closed-form framework for merging two Gaussians by minimizing L2 error, serving as the core primitive for this method.

## Operating characteristics
*   **Time Complexity:** Depends on the partitioning algorithm. Cost-increment relocation is noted to be efficient, matching greedy performance [S1, unofficial].
*   **Memory Complexity:** Reduces memory usage by a factor of $K$.
*   **Performance:** On full fits, cost-aware merging outperforms mass-ranked culling regardless of amplitude refit [S1, unofficial]. On sparse subsamples, culling wins in the median [S1, unofficial].
*   **Strengths:** Preserves visual fidelity better than culling on dense data; provides a geometric interpretation of error [S1, unofficial].
*   **Limitations:** May be less effective than culling on sparse data [S1, unofficial].

## Background
This method originates from the "Luxar" project, which focuses on Gaussian splatting for microscopy and scalable interactive web visualization of multidimensional scientific data [S1, unofficial]. It was developed to address the need for efficient level-of-detail reduction in large-scale volumetric data visualization [S1, unofficial].
