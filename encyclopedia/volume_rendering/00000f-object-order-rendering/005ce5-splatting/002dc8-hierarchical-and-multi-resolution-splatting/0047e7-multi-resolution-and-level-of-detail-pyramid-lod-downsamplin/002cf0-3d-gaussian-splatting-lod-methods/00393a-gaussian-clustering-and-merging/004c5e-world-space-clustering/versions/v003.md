# World Space Clustering

Also called: Single linkage merging

## Overview
World Space Clustering is a preprocessing technique used in 3D Gaussian Splatting to organize spatial data before projection, primarily for the purpose of removing foreground or background noise and managing pixel coverage [S1, unofficial]. It operates by converting 2D screen-space pixel coverage into world-space coordinates and applying single-linkage hierarchical clustering to group these points [S1, unofficial]. It differs from attribute-based clustering methods by relying exclusively on geometric proximity in world space rather than color or scale similarity [S1, unofficial].

## How it works
**Inputs:** A set of 2D pixels covered by Gaussian kernels.
**Outputs:** A set of clusters of world-space coordinates, or a single merged cluster if the threshold allows.

**Data Structures:**
*   **Point Set $P$:** A list of 3D world-space coordinates $\mathbf{p}_j$ corresponding to the centers of pixels covered by the Gaussians.
*   **Clusters $C$:** A collection of disjoint sets of points. Initially, each point $\mathbf{p}_j \in P$ forms its own cluster.
*   **Distance Matrix:** Implicitly maintained via nearest-neighbor search to find the minimum distance between any two distinct clusters.

**Algorithm Steps:**

1.  **Coordinate Conversion:**
    For each Gaussian kernel, determine the 2D pixels it covers. Convert the center of each covered pixel from screen space to world space to obtain the point set $P = \{\mathbf{p}_1, \mathbf{p}_2, \dots, \mathbf{p}_n\}$ [S1, unofficial].

2.  **Initialization:**
    Initialize the cluster set $C = \{ \{\mathbf{p}_1\}, \{\mathbf{p}_2\}, \dots, \{\mathbf{p}_n\} \}$ [S1, unofficial].
    Calculate the initial termination threshold $T$. Let $\delta_d$ be the world-space distance between two adjacent pixels at the depth of the Gaussian kernel’s central pixel. Set $T = 5 \cdot \delta_d$ [S1, unofficial].

3.  **Iterative Merging (Single Linkage):**
    While the number of clusters $|C| > 1$ and the minimum inter-cluster distance $d_{min} < T$:
    a. Find the pair of distinct clusters $C_a, C_b \in C$ such that the distance between them is minimized:
       $$ d_{min} = \min_{C_a \neq C_b} \left( \min_{\mathbf{u} \in C_a, \mathbf{v} \in C_b} \| \mathbf{u} - \mathbf{v} \|_2 \right) $$
    b. Merge $C_a$ and $C_b$ into a single cluster:
       $$ C_{new} = C_a \cup C_b $$
    c. Remove $C_a$ and $C_b$ from $C$ and add $C_{new}$ [S1, unofficial].

4.  **Threshold Adjustment:**
    If the loop terminates with $|C| > 1$ (i.e., clustering failed to merge into a single cluster within the initial threshold), multiply the threshold by 1.5 ($T \leftarrow 1.5 \cdot T$) and repeat the merging process from Step 3 [S1, unofficial].

5.  **Result:**
    The final set of clusters $C$ represents the grouped world-space coordinates. These clusters are used to determine valid coverage for subsequent projection and rendering steps [S1, unofficial].

**Parameters:**
*   **Initial Threshold Multiplier:** 5 (i.e., $T = 5 \delta_d$) [S1, unofficial].
*   **Retry Multiplier:** 1.5 (applied if initial clustering fails to converge to a single cluster) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Clustering Failure:** If the scene geometry is sparse or fragmented, the initial threshold may be too small, leaving many small clusters. The retry mechanism with increased threshold handles this [S1, unofficial].
*   **Precision:** The distance calculation $\| \mathbf{u} - \mathbf{v} \|_2$ must be performed in world space, not screen space, to ensure geometric consistency [S1, unofficial].
*   **Boundary Conditions:** The definition of $\delta_d$ depends on the depth of the central pixel. If the depth is zero or undefined, $\delta_d$ is undefined. [G] In practice, a small epsilon or the minimum representable depth step should be used to avoid division by zero or infinite distances.

## Subtopics

### Coarse-Level Color-Based Segmentation
A variant that groups 3D Gaussians based on approximate view-independent colors rather than pure spatial proximity [S2].
1.  **Color Approximation:** Compute an approximate view-independent color $\tilde{c}$ for each Gaussian by averaging view-dependent colors $c_d$ across sampled viewing directions $D$:
    $$ \tilde{c} \approx \frac{1}{\|D\|} \sum_{d \in D} c_d $$
2.  **Clustering:** Apply a clustering algorithm (e.g., k-means) to group Gaussians based on $\tilde{c}$ using Euclidean distance in RGB space [S2].
3.  **Outlier Removal:** For each Gaussian, search for neighbors within a small-radius sphere. Remove the Gaussian if the neighbor count falls below a predefined threshold. This mitigates the negative impact of outliers on subsequent fine-level segmentation [S2].

## Operating characteristics
*   **Time Complexity:** The single-linkage merging process is effectively a variant of hierarchical clustering. With a naive implementation, it is $O(n^2)$ or $O(n^3)$ depending on distance updates. Using efficient nearest-neighbor structures (e.g., KD-trees), it can approach $O(n \log n)$ per merge step.
*   **Memory Complexity:** $O(n)$ to store the point set and cluster assignments.
*   **Strengths:** Simple to implement; effective at grouping spatially contiguous pixels; robust to noise via threshold adjustment [S1, unofficial].
*   **Limitations:** Does not account for semantic or color similarity; purely geometric [S1, unofficial].
*   **When to Use:** When preprocessing for pixel coverage validation or noise removal in world-space aligned rendering pipelines [S1, unofficial].

## Background
The method is based on single linkage merging, a hierarchical clustering algorithm originally described by Sibson (1973) [S1, unofficial]. It was adapted for 3D Gaussian Splatting preprocessing in the context of Augmented Radiance Fields to handle foreground/background pixel classification prior to projection [S1, unofficial].
