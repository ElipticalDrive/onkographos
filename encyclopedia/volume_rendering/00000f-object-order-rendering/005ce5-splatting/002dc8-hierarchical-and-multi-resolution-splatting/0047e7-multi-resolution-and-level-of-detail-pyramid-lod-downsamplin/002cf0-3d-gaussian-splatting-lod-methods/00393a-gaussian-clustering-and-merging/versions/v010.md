# Gaussian clustering and merging
## Overview
This family of methods reduces the computational cost of 3D Gaussian Splatting (3DGS) by grouping spatially or attribute-similar Gaussians into clusters and replacing them with a single representative Gaussian or a hierarchical structure. It solves the problem of excessive draw calls and memory bandwidth usage in dense scenes by enabling Level of Detail (LOD) selection and spatial culling. Unlike sibling methods that focus on virtual memory paging or specific culling pipelines, this family defines the core algorithms for *how* Gaussians are aggregated—ranging from simple arithmetic averaging to moment-matched L2-optimal merging—and how these aggregates are organized into trees or pages for efficient rendering.
## Shared principles
All methods in this family operate on a set of 3D Gaussians $G = \{G_i\}$, where each Gaussian $G_i$ is defined by position $\mathbf{t}_i$, covariance matrix $\mathbf{\Sigma}_i$ (parameterized by scale $\mathbf{s}_i$ and rotation $\mathbf{q}_i$), opacity $\alpha_i$, and color coefficients $c_i$ (typically spherical harmonics). The core mechanism involves three phases:
1.  **Clustering/Partitioning:** The set $G$ is partitioned into clusters $C_k$. This can be done via spatial proximity (e.g., Morton code sorting, k-means on position), attribute similarity, or hierarchical tree construction.
2.  **Merging/Aggregation:** Each cluster $C_k$ is replaced by a representative Gaussian $G'_k$. The parameters of $G'_k$ are derived from the parameters of $G_i \in C_k$. Common aggregation strategies include:
    *   **Arithmetic Mean:** $\mathbf{t}'_k = \frac{1}{|C_k|} \sum \mathbf{t}_i$, $\alpha'_k = \frac{1}{|C_k|} \sum \alpha_i$, $c'_k = \frac{1}{|C_k|} \sum c_i$. Scale handling varies; some methods average it, others preserve it or apply a scaling factor [S1, unofficial].
    *   **Moment Matching:** The first and second spatial moments of the cluster are matched. The position is the weighted center of mass: $\mathbf{t}'_k = \frac{1}{W} \sum w_i \mathbf{t}_i$. The covariance is adjusted for the spread of individual Gaussians: $\mathbf{\Sigma}'_k = \frac{1}{W} \sum w_i (\mathbf{\Sigma}_i + (\mathbf{t}_i - \mathbf{t}'_k)(\mathbf{t}_i - \mathbf{t}'_k)^T)$, where $w_i = \alpha_i$ and $W = \sum w_i$ [S1, unofficial].
3.  **Optimization/Selection:** The amplitude (opacity) of the merged Gaussian may be optimized to minimize the integrated squared error (L2 loss) between the merged Gaussian and the sum of the input Gaussians [S1, unofficial]. Alternatively, LOD levels are selected based on screen-space error or distance thresholds [S1, unofficial].
## Subtopics

### [K-wise moment-matched merging with L2-optimal amplitude](5440-k-wise-moment-matched-merging-with-l2-optimal-amplitude.md)
A LOD technique that reduces $K$ Gaussians into one by matching spatial moments and optimizing amplitude to minimize L2 error. It differs from averaging by preserving spatial extent and from culling by retaining information. Choose when high fidelity is required at lower counts.

### [Hierarchical Gaussian Merging](8358-hierarchical-gaussian-merging.md)
Generates LODs by iteratively clustering and averaging parameters, but preserves individual scales to maintain geometric fidelity. It supports virtual memory paging. Choose when scale preservation is critical for local geometry.

### [LOD Generation for 3DGS](8408-lod-generation-for-3dgs.md)
Reduces Gaussian count by merging based on k-means clustering in multidimensional attribute space, operating within a virtual memory framework. It distinguishes itself by dynamic threshold adjustment to prevent visual popping. Choose for memory-constrained environments requiring dynamic LOD.

### [Cluster Culling (Nanite-style)](10402-cluster-culling-nanite-style.md)
A hierarchical spatial culling and LOD selection mechanism emulating Nanite. It focuses on the culling/selection phase using compute shaders for frustum and screen-space error tests. Choose when integrating with a Nanite-like virtual geometry pipeline.

### [Gaussian Cluster Builder](10403-gaussian-cluster-builder.md)
Constructs a hierarchical cluster tree via Morton code sorting and recursive merging. It differs from flat optimization by building a tree structure for efficient traversal. Choose when a strict hierarchical spatial index is needed.

### [World Space Clustering](13206-world-space-clustering.md)
A preprocessing technique using single-linkage hierarchical clustering on world-space coordinates derived from 2D pixel coverage. It differs by relying exclusively on geometric proximity rather than attribute similarity. Choose for noise removal and managing pixel coverage.

#### definition
- [S2, unofficial] A post-processing step that merges neighboring Gaussian blocks across leaf node boundaries to form larger Gaussians for homogeneous regions.

## Background
The need for clustering and merging in 3D Gaussian Splatting arises from the high memory footprint and rendering cost of scenes with millions of Gaussians. Early 3DGS implementations rendered all Gaussians, leading to performance bottlenecks. Subsequent research introduced hierarchical structures and LOD techniques to mitigate this. The concept of merging Gaussians to approximate voxel data or reduce complexity has roots in scientific visualization, where Gaussian Mixture Models are used to approximate VDB datasets [S2, unofficial]. In the context of 3DGS, methods like H-3DGS and various LOD strategies have adapted these principles to real-time rendering, focusing on spatial locality (Morton codes) and attribute similarity to maintain visual quality while reducing draw calls. The specific algorithms for moment-matched merging and L2-optimal amplitude optimization are detailed in recent unofficial implementations and studies [S1, S2, unofficial].
