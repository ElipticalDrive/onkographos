# Stage-dependent merging

Also called: Grouped merging, Soft-weighted merging

## Overview
Stage-dependent merging is a technique for progressively refining Gaussian representations by partitioning candidate Gaussians into groups and merging them using geometry-conditioned soft weights, exposing only coarse representations at early training stages [S1]. It sets itself apart from its sibling [Analytical Merging of Gaussian Splats](5681-analytical-merging-of-gaussian-splats.md) by using a learned, soft-weighted aggregation rather than a closed-form L2-optimal geometric merge, allowing for a smooth transition from coarse to fine detail during training [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 16 candidate Gaussians per token, each with attributes $\mathbf{z}_{p,g,i}$ and a gate logit $\ell_{p,g,i}$ [S1].
*   **Outputs:** A merged representation $\mathbf{z}^{(s)}$ for the current training stage [S1].

**Data Structures:**
*   Candidates are stored as a list of 16 items [S1].
*   Each candidate contains a vector or matrix of attributes $\mathbf{z}$ and a scalar gate logit $\ell$ [S1].

**Steps:**
1.  Partition the 16 candidates into $G = 2^s$ groups, where each group has size $b_s = 16 / G$ [S1].
2.  Calculate normalized gate weights for each candidate $i$ in group $g$ using a softmax function [S1].
3.  Compute the merged output for attribute $\mathbf{z}$ in group $g$ by taking the weighted sum of the candidates' attributes [S1].
4.  Apply a smooth stage transition to avoid abrupt changes between stages [S1].

**Formulas:**
Normalized gate weight for candidate $i$ in group $g$: $w_{p,g,i} = \frac {\exp (\ell _{p,g,i}/\tau )} {\sum _{j=1}^{b_s}\exp (\ell _{p,g,j}/\tau )}$ [S1].
Merged output for attribute $\mathbf{z}$ in group $g$: $\bar {\mathbf {z}}_{p,g} = \sum _{i=1}^{b_s} w_{p,g,i}\,\mathbf {z}_{p,g,i}$ [S1].
Smooth stage transition: $\mathbf {z}^{(s)} = (1-\lambda )\,\mathbf {z}^{(s-1)} + \lambda \,\bar {\mathbf {z}}^{(s)}$ [S1]. This procedure does not introduce new candidates but progressively relaxes the merging applied to the same underlying set of predictions [S1].

**Parameters:**
*   $\tau$: Temperature parameter for the softmax gate [S1].
*   $\lambda$: Transition coefficient for stage interpolation, $\lambda \in [0, 1]$ [S1].

**Edge cases and pitfalls:**
*   Numerical stability requires subtracting the maximum logit before exponentiation in the softmax calculation [G].
*   The transition coefficient $\lambda$ must be clamped to $[0, 1]$ to prevent extrapolation artifacts [S1].

**Pseudocode:**
```python
import math

def stage_dependent_merge(candidates, gate_logits, stage_s, tau, lambda_val, prev_stage_repr):
    """
    candidates: list of 16 attribute vectors/matrices z_{p,g,i}
    gate_logits: list of 16 floats l_{p,g,i}
    stage_s: int, current training stage s
    tau: float, temperature parameter
    lambda_val: float, transition coefficient in [0, 1]
    prev_stage_repr: list of merged attribute vectors from stage s-1
    """
    num_candidates = 16
    num_groups = 2 ** stage_s
    group_size = num_candidates // num_groups
    current_stage_repr = []

    for g in range(num_groups):
        group_candidates = candidates[g * group_size : (g + 1) * group_size]
        group_logits = gate_logits[g * group_size : (g + 1) * group_size]

        # Softmax weights with numerical stability [G]
        max_logit = max(group_logits)
        exp_logits = [math.exp((l - max_logit) / tau) for l in group_logits]
        sum_exp = sum(exp_logits)
        weights = [e / sum_exp for e in exp_logits]

        # Weighted sum of attributes
        merged_z = [0.0] * len(group_candidates[0])
        for i, z in enumerate(group_candidates):
            for k in range(len(z)):
                merged_z[k] += weights[i] * z[k]
        current_stage_repr.append(merged_z)

    # Smooth stage transition
    final_repr = []
    for i, merged_z in enumerate(current_stage_repr):
        if prev_stage_repr and i < len(prev_stage_repr):
            prev_z = prev_stage_repr[i]
            interpolated_z = [
                (1 - lambda_val) * prev_z[k] + lambda_val * merged_z[k]
                for k in range(len(merged_z))
            ]
            final_repr.append(interpolated_z)
        else:
            final_repr.append(merged_z)

    return final_repr
```

## Subtopics

### Seamless Merging
A variant used in large-scale reconstruction where cells are optimized independently and then merged [S2]. After optimization, 3D Gaussians outside the original region (before boundary expansion) are deleted for each cell to prevent floaters in other cells [S2]. The non-overlapping cells are then merged [S2]. The merged scene is seamless in appearance and geometry without obvious border artifacts because some training views are common between adjacent cells, eliminating the need for further appearance adjustment [S2].

## Operating characteristics
*   **Complexity:** The merging operation is linear with respect to the number of candidates per group ($b_s$) and the number of groups ($G$) [S1]. Since $b_s \times G = 16$, the complexity per token is constant $O(1)$ with respect to the total number of candidates [S1].
*   **Performance:** Exposes only coarse representations at early stages, potentially reducing computational load during initial training phases [S1].
*   **Strengths:** Allows for progressive refinement and smooth transitions between levels of detail [S1].
*   **Limitations:** Requires learning gate logits and managing stage transitions [S1].

## Background
Stage-dependent merging was introduced in GlobalSplat: Efficient Feed-Forward 3D Gaussian Splatting via Global Scene Tokens [S1]. It is designed to enable efficient feed-forward rendering by managing the complexity of Gaussian representations through a staged merging process [S1].
