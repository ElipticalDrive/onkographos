# Octree-GS

Also called: Octree Gaussian Splatting

## Overview
Octree-GS is a hierarchical Level-of-Detail (LoD) method that builds an octree over the scene, associating each node with a merged Gaussian that summarizes the radiance and opacity of its children [S1, unofficial]. It solves the problem of inconsistent rendering performance and excessive memory usage in large-scale 3D Gaussian Splatting (3DGS) by dynamically selecting appropriate levels from a set of multi-scale Gaussian primitives organized in an octree [S4]. Unlike siblings that require post-processing or manual threshold tuning, Octree-GS achieves LoD effects in a single end-to-end training round using a cumulative LOD strategy and a progressive grow-and-prune mechanism [S4].

## How it works
**Inputs:** Sparse Structure-from-Motion (SfM) points, training images with camera poses and intrinsics.
**Outputs:** An octree-structured set of anchors, each associated with $k$ Gaussian primitives (explicit or neural), and learnable LOD biases.

**Data Structures:**
*   **Octree:** A sparse octree with $K$ layers (levels).
*   **Anchor:** Defined by position (center of a voxel), a learnable LOD bias $\Delta L_j$, and a set of $k$ Gaussian primitives.
*   **Gaussian Primitive:** Standard 3DGS parameters (mean $\mu$, covariance $\Sigma$, opacity $\alpha$, spherical harmonics coefficients for color).
*   **Voxel Size:** For layer $L$, voxel size $V_L = \delta / 2^L$, where $\delta$ is the base voxel size for LOD 0.

**Parameters:**
*   $r_d$: Outlier discard ratio for distance calculation (default 0.999) [S4].
*   $\delta$: Base voxel size for LOD 0 (default 0.02 for intermediate levels, 0.001 for modified anchor versions in comparisons) [S4].
*   $\tau_g$: Gradient threshold for growing (default 0.0002) [S4].
*   $\beta$: Exponential growth difficulty factor (default 0.2) [S4].
*   $\epsilon$: LOD bias increment (default 0.01) [S4].
*   $\tau_v$: Visibility threshold for pruning (0.7 small-scale, 0.01 large-scale, 0.2 multi-scale) [S4].
*   $T$: Densification interval (default 100 iterations) [S4].
*   $s$: Focal scale factor for varying intrinsics [S4].

**Algorithm Steps:**

1.  **Anchor Initialization:**
    *   Calculate distance $d_{ij}$ between each training camera center $i$ and each SfM point $j$.
    *   Determine $d_{max}$ as the $r_d$-th largest distance and $d_{min}$ as the $r_d$-th smallest distance [S4].
    *   Calculate number of octree layers:
        $$ K = \lfloor \log_2(d_{max}/d_{min}) \rceil + 1 $$
        where $\lfloor \cdot \rceil$ denotes the round operator [S4].
    *   Construct octree grids with $K$ layers.
    *   Initialize anchors at voxel centers for each layer $L \in [0, K-1]$ with voxel size $V_L = \delta / 2^L$ [S4].
    *   Assign initial LOD level $L_j = L$ to anchors in layer $L$.
    *   Initialize learnable LOD bias $\Delta L_j = 0$ for each anchor $j$ [S4].

2.  **Progressive Training (Grow-and-Prune):**
    *   Run training for $N_{total}$ iterations (40k for small-scale, 100k for large-scale) [S4].
    *   **Progressive Phase (First 10k iterations):**
        *   Optimize anchors with weight $\omega = 1.5$ [S4].
    *   **Densification Phase (Every $T$ iterations):**
        *   Calculate average accumulated gradient $\nabla g$ of spawned Gaussian primitives [S4].
        *   **Growing:**
            *   If $\nabla g > \tau_g$ and the primitive is in an empty voxel, convert to a new anchor [S4].
            *   Assign LOD level using "next-level" growth:
                *   Threshold for level $L$: $\tau_{gL} = \tau_g \cdot 2^{\beta L}$ [S4].
                *   If $\nabla g > \tau_{g(L+1)}$, promote to level $L+1$.
                *   If $\tau_{gL} < \nabla g \le \tau_{g(L+1)}$, keep at level $L$ [S4].
            *   **Bias Adjustment:**
                *   Calculate anchor gradient $\nabla v$ (average gradient of spawned primitives for that anchor) [S4].
                *   If $\nabla v > \tau_{gL} \cdot 0.25$, update bias: $\Delta L_j \leftarrow \Delta L_j + \epsilon$ [S4].
        *   **Pruning:**
            *   Compute average opacity of Gaussians generated over the last $T$ iterations [S4].
            *   Remove anchors with low average opacity [S4].
            *   Compute view-frequency (probability anchor is selected in training views) [S4].
            *   Remove anchors with view-frequency $< \tau_v$ [S4].

3.  **Rendering (Inference):**

            *   Select anchor $j$ if its assigned level $L_j \le \hat{L}_{ij}$ [S4].

def initialize_octree(sfm_points, camera_centers, rd=0.999, delta=0.02):
    # Calculate distances
    distances = []
    for cam in camera_centers:
        for pt in sfm_points:
            distances.append(distance(cam, pt))
    
    # Determine d_max and d_min based on rd
    distances.sort()
    n = len(distances)
    idx_max = int(rd * n)
    idx_min = int((1 - rd) * n)
    d_max = distances[idx_max]
    d_min = distances[idx_min]
    
    # Calculate K
    K = round(log2(d_max / d_min)) + 1
    
    # Initialize anchors
    anchors = []
    for L in range(K):
        voxel_size = delta / (2 ** L)
        # Create voxel grid for layer L
        grid = create_sparse_voxel_grid(voxel_size)
        for voxel in grid:
            anchor = Anchor()
            anchor.pos = voxel.center
            anchor.L = L
            anchor.delta_L = 0.0
            anchor.gradients = []
            anchor.opacity_history = []
            anchor.view_frequency = 0.0
            anchor.primitives = initialize_gaussians(anchor.pos)
            anchors.append(anchor)
            
    return anchors, K, d_max

def select_anchors(anchors, camera, d_max, s, K):
    selected = []
    blended = []
    
    for anchor in anchors:
        d_ij = distance(camera.pos, anchor.pos)
        # Calculate fractional LOD level
        raw_lod = log2(d_max / (d_ij * s)) + anchor.delta_L
        # Clamp to [0, K-1]
        clamped_lod = clamp(raw_lod, 0, K - 1)
        L_hat = floor(clamped_lod)
        
        if anchor.L <= L_hat:
            selected.append(anchor)
        elif anchor.L == L_hat + 1:
            # Opacity blending
            # Source says: Scale opacities by (L_hat - L_j)
            # Since L_j = L_hat + 1, factor is -1. 
            # This is likely a source error for (1 - (L_hat - L_j + 1)) or similar.
            # Implementing as per source text strictly:
            blend_factor = L_hat - anchor.L 
            # Note: In practice, this factor should be positive for blending.
            # Assuming source meant absolute difference or complementary weight.
            # We will apply the factor as stated, but clamp opacity to [0,1].
            for prim in anchor.primitives:
                prim.opacity = max(0, prim.opacity * blend_factor)
            blended.append(anchor)
            
    return selected, blended

def grow_and_prune(anchors, T, tau_g=0.0002, beta=0.2, epsilon=0.01, tau_v=0.01):
    for i, anchor in enumerate(anchors):
        # Growing
        if len(anchor.gradients) > 0:
            avg_grad = mean(anchor.gradients)
            tau_L = tau_g * (2 ** (beta * anchor.L))
            tau_L_next = tau_g * (2 ** (beta * (anchor.L + 1)))
            
            if avg_grad > tau_g:
                # Check if empty voxel (simplified)
                if is_empty_voxel(anchor.pos, anchor.L):
                    # Determine new level
                    if avg_grad > tau_L_next:
                        anchor.L += 1
                    # Else stay at L
                    
                    # Bias adjustment
                    avg_anchor_grad = mean(anchor.gradients) # Re-calc or use stored
                    if avg_anchor_grad > tau_L * 0.25:
                        anchor.delta_L += epsilon
            
        # Pruning
        if len(anchor.opacity_history) > 0:
            avg_opa = mean(anchor.opacity_history)
            if avg_opa < threshold_low: # Not given in sources, implied by "low average opacity"
                anchor.mark_for_removal()
                
        if anchor.view_frequency < tau_v:
            anchor.mark_for_removal()
            
    return [a for a in anchors if not a.marked_for_removal()]

## Operating characteristics
*   **Time Complexity:** Rendering is $O(N_{selected})$ where $N_{selected}$ is the number of anchors selected for the current view. Training involves densification every $T$ iterations, adding overhead but reducing total primitives compared to vanilla 3DGS.
*   **Memory Complexity:** Significantly reduced compared to vanilla 3DGS and Hierarchical-GS. On MatrixCity, Octree-GS uses 3.59M Gaussians vs 20.8M for Hierarchical-GS [S4].
*   **Performance:** On MatrixCity (2k resolution), Octree-GS achieves 32.0 FPS with 3.59M Gaussians in zoom-out views, compared to 6.91 FPS for Hierarchical-GS [S4]. It is up to 10x faster than state-of-the-art methods in large-scale scenes [S4]. On Mip-NeRF360, training time is 20-23 minutes vs 38-69 minutes for Hierarchical-GS [S4].
*   **Strengths:** End-to-end training, no manual threshold tuning, smooth LOD transitions, handles multi-resolution datasets well [S4].
*   **Limitations:** Requires careful tuning of $\tau_v$ for different scene scales. The opacity blending formula in the source contains a potential sign error ($\hat{L} - L_j = -1$) which may need implementation correction [S4].

## Background
Octree-GS was introduced in 2024 by researchers associated with the "CitySuper" project [S4]. It is the first approach to deal with Level-of-Detail in Gaussian representation using an explicit octree structure [S4]. It builds upon Scaffold-GS [3] and 3DGS [5].
