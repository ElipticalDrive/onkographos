# Momentum-GS

Also called: Momentum Self-Distillation for 3DGS, Block-wise Momentum-GS

## Overview
Momentum-GS is a block-wise training method for large-scale 3D Gaussian Splatting (3DGS) that uses a momentum-updated teacher model to provide global self-distillation guidance to local block students [S1, S2, unofficial]. It decouples the block count from the GPU count and restores cross-block spatial consistency, addressing geometric inaccuracies and floaters caused by independent block training [S2, unofficial]. Unlike CityGaussian, which relies on a static coarse prior and spatial contraction, Momentum-GS dynamically updates the teacher via exponential moving average (EMA) of student parameters [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A large-scale scene dataset (images, poses), a block partitioning strategy, and hyperparameters for momentum decay ($\beta$), learning rate ($\eta$), and block weighting [G].
*   **Output:** A set of 3D Gaussians optimized for the entire scene, with improved geometric consistency and reduced artifacts compared to independent block training [G].

**Data Structures:**
1.  **Student Gaussians ($G_s$):** The set of Gaussian parameters (mean $\mu$, covariance $\Sigma$, opacity $\alpha$, spherical harmonics coefficients $C$) for the current block being trained [G].
2.  **Teacher Gaussians ($G_t$):** A global set of Gaussian parameters, updated via EMA to guide student optimization [S2, unofficial].
3.  **Block Weights ($w_b$):** A scalar value per block, calculated based on reconstruction accuracy [S2, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Initialize the Teacher Gaussians $G_t$ using a coarse global prior or single-pass training, and initialize Student Gaussians $G_s$ for each block [G].
2.  **Block Partitioning:** Divide the scene into non-overlapping or overlapping blocks [G].
3.  **Training Loop (per block $b$):**
    a. **Forward Pass:** Render the current block's Student Gaussians $G_s^b$ to generate images [G].
    b. **Distillation Loss:** Compute a distillation loss between the rendered output of $G_s^b$ and the rendered output of the global Teacher Gaussians $G_t$ [G].
    c. **Reconstruction Loss:** Compute the photometric reconstruction loss between rendered images and ground truth images [G].
    d. **Total Loss:** Combine losses: $\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{rec}} + \lambda \mathcal{L}_{\text{distill}}$, where $\lambda$ is a weighting factor [G].
    e. **Optimization:** Update $G_s^b$ using gradient descent [G].
    f. **Block Weighting:** Calculate the reconstruction accuracy for block $b$ and update its weight $w_b$ [S2, unofficial].
4.  **Teacher Update (EMA):** After each optimization step or epoch, update the Teacher Gaussians $G_t$ using the exponential moving average of the Student Gaussians $G_s$:
    $$ G_t \leftarrow \beta G_t + (1 - \beta) G_s $$
    where $\beta$ is the momentum coefficient [G].
5.  **Iteration:** Repeat steps 3-4 for all blocks until convergence [G].

**Parameters:**
*   **Momentum Coefficient ($\beta$):** Controls the decay rate of the EMA [G].
*   **Distillation Weight ($\lambda$):** Balances reconstruction and distillation losses [G].
*   **Block Size:** Determines the granularity of the partitioning [G].

**Edge Cases and Pitfalls:**
*   **Precision:** EMA updates can suffer from numerical instability if $\beta$ is too close to 1 or if gradients are noisy [G].

**Pseudocode:**
```python
def momentum_gs(scene_data, block_partitions, beta, lambda_distill, lr, epochs):
    # Initialize teacher Gaussians from a coarse global prior [G]
    teacher_params = initialize_gaussians(scene_data)
    # Initialize student Gaussians for each block [G]
    student_params = {b: initialize_gaussians(block.scene_region) for b, block in enumerate(block_partitions)}
    block_weights = [1.0] * len(block_partitions)

    for epoch in range(epochs):
        for b, block in enumerate(block_partitions):
            # Render student and teacher Gaussians for block cameras [G]
            student_render = project_and_rasterize(student_params[b], block.cameras)
            teacher_render = project_and_rasterize(teacher_params, block.cameras)

            # Compute photometric reconstruction loss against ground truth [G]
            loss_rec = mean_squared_error(student_render, block.gt_images)

            # Compute distillation loss between student and teacher renders [G]
            loss_distill = mean_squared_error(student_render, teacher_render)

            # Total loss and gradient descent update [G]
            loss = loss_rec + lambda_distill * loss_distill
            student_params[b] = student_params[b] - lr * gradient(loss, student_params[b])

            # Update block weight based on reconstruction accuracy [S2, unofficial]
            block_weights[b] = 1.0 / (1.0 + loss_rec)

        # Update teacher Gaussians via exponential moving average [S1, unofficial]
        for b in range(len(block_partitions)):
            teacher_params = beta * teacher_params + (1 - beta) * student_params[b]

    return student_params, teacher_params

# Standard 3DGS operations [G]
def initialize_gaussians(region): return region.gaussian_parameters
def project_and_rasterize(params, cameras): return render_image(params, cameras)
def mean_squared_error(rendered, gt): return sum((r - g)**2 for r, g in zip(rendered, gt)) / len(gt)
def gradient(loss, params): return compute_gradients(loss, params)
```

## Subtopics

### [CityGS Training Pipeline](15267-citygs-training-pipeline.md)
CityGS is a divide-and-conquer training method for large-scale 3D Gaussian Splatting (3DGS) that uses a coarse global prior to enable parallel block-wise finetuning and a Level-of-Detail (LoD) strategy for real-time rendering. It solves the geometric inaccuracies and floaters caused by independent block training by initializing each block with a globally consistent Gaussian set, ensuring seamless fusion without complex alignment. Unlike Momentum-GS, which uses a momentum-updated teacher for self-distillation, CityGS relies on a static coarse prior and spatial contraction for data assignment.

### [Gaussian-JEPA Pretraining](16497-gaussian-jepa-pretraining.md)
Gaussian-JEPA is a self-supervised pretraining method for 3D Gaussian assets that predicts latent features of masked target blocks from shared context, using joint-embedding predictive learning to avoid raw-attribute reconstruction. It sets itself apart from Gaussian-MAE by predicting latent representations instead of reconstructing Gaussian parameters, and from contrastive methods by explicitly supervising missing spatial content through latent prediction of held-out blocks. It builds on Momentum-GS by providing a robust, object-level feature representation that is consistent across stochastic resampling, which serves as a foundation for downstream tasks like shape completion and segmentation.

## Operating characteristics
*   **Measured Performance:** Reports ~18.7% LPIPS improvement over CityGaussian with far fewer blocks [S2, unofficial].
*   **Scaling:** Decouples block count from GPU count, allowing for scalable training on large scenes [S2, unofficial].
*   **Strengths:** Restores cross-block spatial consistency, reduces floaters, and improves convergence quality [S1, S2, unofficial].
*   **Limitations:** Requires careful tuning of momentum and distillation weights [G].
*   **When to Use:** Large-scale scene reconstruction where geometric consistency is critical [S2, unofficial].

## Background
Momentum-GS was marked as a 2026 SOTA update [S2, unofficial]. It leverages momentum self-distillation, where a teacher model (an exponential moving average of the parameters) guides the optimization of the student, improving convergence quality for large scenes [S1, unofficial]. It addresses the challenges of distributed learning and Level of Detail (LoD) techniques in large-scale scene reconstruction, where geometry accuracy and reconstruction time remain bottlenecks [S3].
