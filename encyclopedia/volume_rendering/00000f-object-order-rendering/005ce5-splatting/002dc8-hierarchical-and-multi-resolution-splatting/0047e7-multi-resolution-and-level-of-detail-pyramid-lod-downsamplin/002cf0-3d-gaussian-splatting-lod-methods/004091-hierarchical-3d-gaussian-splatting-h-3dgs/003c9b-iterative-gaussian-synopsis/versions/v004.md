# Iterative Gaussian Synopsis

Also called: Iterative Gaussian Synopsis Framework, Iterative Gaussian Synopsis Unfolding, Top-Down Unfolding

## Overview
Iterative Gaussian Synopsis is a top-down strategy for constructing a hierarchy of Level-of-Detail (LOD) representations for 3D Gaussian Splatting (3DGS) [S1]. It addresses the challenges of deploying large-scale 3DGS models for progressive and adaptive rendering by deriving coarser levels from a full-fidelity model through adaptive, learnable pruning and downsampling, ensuring coherent simplification without the error accumulation typical of bottom-up training [S1]. It sets itself apart from siblings like [Octree-GS](7341-octree-gs.md) and [CityGaussian / VastGaussian / DoGaussian](6143-citygaussian-vastgaussian-dogaussian.md) by using a unified top-down unfolding framework that extracts all LODs from a single optimization, rather than building independent models or using bottom-up enhancement layers [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** SfM point clouds, images at four target resolutions, and hyperparameters (grid levels, codebook size, learning rates).
*   **Output:** A set of LOD representations $\{L_0, \dots, L_{L_{max}-1}\}$, where $L_{max}=4$ in the standard configuration [S1].

**Data Structures:**
*   **Anchors:** Initialized from SfM point clouds via voxelization. Each anchor $j$ contains:
    *   Position $\mathbf{x}_a \in \mathbb{R}^3$.
    *   Base scaling $\mathbf{l}_a \in \mathbb{R}^3$.
    *   Feature $\mathbf{f}_a \in \mathbb{R}^{32}$ (initially from codebook/grid).
    *   $K$ learnable offsets $\mathbf{O}_a \in \mathbb{R}^{K \times 3}$ [S1].
*   **Hierarchical Grids:** A set of $L_g=12$ multiresolution hash grid levels $\{G_g\}_{g=1}^{L_g}$ with feature dimension 4. Initialized uniformly in $[-10^{-4}, 10^{-4}]$ [S1].
*   **Anchor Codebook:** A global learnable codebook $\mathbf{C} \in \mathbb{R}^{N_c \times D_c}$ with $N_c=256, D_c=32$. Initialized from $\mathcal{N}(0, 1)$ [S1].
*   **Soft-Index:** Each anchor $j$ has a learnable vector $\mathbf{v}_j \in \mathbb{R}^{N_c}$ used to retrieve local features [S1].
*   **Masks:** For each anchor $j$ generating $K$ Gaussians, a learnable mask parameter vector $\mathbf{m}_j \in \mathbb{R}^K$ [S1].

def sigmoid(x):
    return 1.0 / (1.0 + torch.exp(-x))

def straight_through_mask(m_ji, epsilon):
    """
    Computes binary mask using straight-through estimator.
    M = sg(1[sigma(m) > eps] - sigma(m)) + sigma(m)
    """
    sigma = sigmoid(m_ji)
    indicator = (sigma > epsilon).float()
    # Stop gradient on the discrete part, pass gradient through sigma
    mask = (indicator - sigma).detach() + sigma
    return mask

def soft_index_retrieval(v_j, C):
    """
    Retrieves local feature using straight-through estimator.
    w = Softmax(v)
    f_loc = [Onehot(argmax(w^T)) + w^T - sg(w^T)] * C
    """
    w = F.softmax(v_j, dim=-1)
    # argmax returns indices, convert to one-hot
    idx = torch.argmax(w, dim=-1)
    one_hot = F.one_hot(idx, num_classes=N_c).float()
    # Straight-through: gradient flows through w, but index is discrete
    # Note: In practice, this is often implemented via custom autograd function
    # Here we approximate the logic:
    # f_loc = (one_hot + w - w.detach()) @ C
    f_loc = (one_hot + w - w.detach()) @ C
    return f_loc

    """
    Multi-linear interpolation of grid level G_g at position x_a.

    """
    Concatenates interpolated features from all active grid levels.
    """
    features = []
    for g in grids:
        features.append(interpolate_grid(g, x_a))
    return torch.cat(features, dim=-1)

def predict_gaussian_attributes(f_a, sigma_c, d_c, MLP_alpha, MLP_color, MLP_scale, MLP_rot):
    """
    Predicts opacity, color, scale, rotation for K Gaussians.
    """
    alpha = MLP_alpha(torch.cat([f_a, sigma_c, d_c], dim=-1))
    color = MLP_color(torch.cat([f_a, sigma_c, d_c], dim=-1))
    scale = MLP_scale(torch.cat([f_a, sigma_c, d_c], dim=-1))
    rot = MLP_rot(torch.cat([f_a, sigma_c, d_c], dim=-1))
    return alpha, color, scale, rot

    """

    alphas, colors, scales, rots = predict_gaussian_attributes(
        anchor_features, dist, dir_vec, MLP_alpha, MLP_color, MLP_scale, MLP_rot
    )
    
    # Apply masks to opacity and scale
    # masks shape: (N_anchors, K)
    # alphas, scales shape: (N_anchors, K, dim)
    masked_alphas = masks * alphas
    masked_scales = masks * scales

    # This part depends on specific 3DGS implementation details for offsets
    # Assuming offsets are applied to base scale to determine position jitter

    # and handles the rest.

    rendered_img = rasterize(masked_alphas, colors, masked_scales, rots, anchor_positions)

            # Predict attributes
            dist = torch.norm(anchors.position - camera_pos, dim=-1, keepdim=True)
            dir_vec = (anchors.position - camera_pos) / (dist + 1e-8)

                f_fused, dist, dir_vec, next_MLP_alpha, next_MLP_color, next_MLP_scale, next_MLP_rot
            )

            masked_scales = masks * scales

            rendered = rasterize(masked_alphas, colors, masked_scales, rots, anchors.position)
            
            # Compute Loss
            target = get_target_image(camera_pos)
            L_LOD = torch.mean(torch.abs(rendered - target))
            
            # Sparsity Regularization
            L_mask = torch.mean(sigmoid(current_m))
            # Group sparsity loss (simplified)
            L_group = torch.mean(torch.sum(sigmoid(current_m), dim=1)) # Encourages entire anchor to be pruned
            
            L_total = L_LOD + lambda_group * L_group
            
            # Update masks and level-specific MLPs/Codebook
            # Freeze positions, offsets, scales, grids
            L_total.backward()
            
            # Update only masks, C, and MLPs
            optimizer_mask.step()

            optimizer_MLP.step()

            current_m = current_m - optimizer_mask.param_groups[0]['lr'] * current_m.grad
            
            optimizer_mask.zero_grad()
            optimizer_C.zero_grad()
            optimizer_MLP.zero_grad()
            
        # Store LOD
        LODs[l] = {
            'anchors': anchors,
            'C': next_C,
            'MLPs': [next_MLP_alpha, next_MLP_color, next_MLP_scale, next_MLP_rot],
            'grids': active_grids,
            'masks': current_m
        }
        
        # Prepare for next iteration (coarser LOD)
        current_C = next_C
        current_MLP_alpha = next_MLP_alpha

**Steps:**
1.  **Initialize Full-Fidelity Model:** Train the highest LOD ($L_{max}-1$) end-to-end using hierarchical anchor features. Minimize $\mathcal{L}_{\text{full}} = (1 - \lambda_{\text{SSIM}})\mathcal{L}_1 + \lambda_{\text{SSIM}}\mathcal{L}_{\text{D-SSIM}} + \lambda_{\text{vol}}\mathcal{L}_{\text{vol}}$ [S1].
2.  **Iterative Unfolding:** For each level $\ell$ from $L_{max}-2$ down to $0$:
    *   **Grid Downsampling:** Discard the finest $L_g/L_{max}$ grid levels. For $L_{max}=4$, LOD $\ell$ retains the first $3(\ell+1)$ of 12 grid levels (L3: 12, L2: 9, L1: 6, L0: 3) [S1].
    *   **Initialize Masks:** Set all mask parameters $\mathbf{m}_j$ to 1 (all Gaussians active) [S1].
    *   **Copy Parameters:** Copy the codebook $\mathbf{C}$ and MLPs from the finer level $\ell+1$ to initialize level $\ell$ [S1].
    *   **Optimize:** For $T_{unfold}=10,000$ iterations:
        *   Compute binary masks $\mathbf{M}_{j,i}$ using the straight-through estimator: $\mathbf{M}_{j,i} = \text{sg}(\mathbf{1}[\sigma(m_{j,i}) > \epsilon] - \sigma(m_{j,i})) + \sigma(m_{j,i})$ [S1].
        *   Apply masks to opacity and scale: $\hat{\alpha}_{j,i} = \mathbf{M}_{j,i} \cdot \alpha_{j,i}$ and $\hat{s}_{j,i} = \mathbf{M}_{j,i} \cdot s_{j,i}$ [S1].
        *   Render at the target resolution of LOD $\ell-1$.
        *   Minimize $\mathcal{L}_{\text{LOD}}$ plus sparsity regularization $\mathcal{L}_{\text{sparsity}}$ (including $\mathcal{L}_{\text{mask}}$ and group sparsity loss) [S1].
        *   Update masks, level-specific codebook $\mathbf{C}^{(\ell)}$, and level-specific MLPs. Freeze positions, offsets, scales, and grids [S1].
3.  **Inference:** Convert soft-indices $\mathbf{v}_j$ to discrete indices $\text{idx}_j = \text{argmax}(\mathbf{v}_j)$ and fetch local features directly from the codebook $\mathbf{C}[\text{idx}_j]$ [S1].

**Formulas:**
*   **Mask Computation:** $\mathbf{M}_{j,i} = \text{sg}(\mathbf{1}[\sigma(m_{j,i}) > \epsilon] - \sigma(m_{j,i})) + \sigma(m_{j,i})$ [S1].
*   **Masking Loss:** $\mathcal{L}_{\text{mask}} = \frac{1}{NK} \sum_j \sum_{i=1}^K \sigma(m_{j,i})$ [S1].
*   **Soft-Index Retrieval:** $\mathbf{w}_j = \text{Softmax}(\mathbf{v}_j)$, $\mathbf{f}_{\text{loc},j} = [\text{Onehot}(\text{argmax}(\mathbf{w}_j^T)) + \mathbf{w}_j^T - \text{sg}(\mathbf{w}_j^T)] \cdot \mathbf{C}$ [S1].
*   **Full-Fidelity Loss:** $\mathcal{L}_{\text{full}} = (1 - \lambda_{\text{SSIM}})\mathcal{L}_1 + \lambda_{\text{SSIM}}\mathcal{L}_{\text{D-SSIM}} + \lambda_{\text{vol}}\mathcal{L}_{\text{vol}}$ [S1].
*   **Neural Gaussian Prediction:** $\{\alpha^i, \mathbf{c}^i, \mathbf{s}^i, \mathbf{r}^i\}_{i=0}^k = \mathcal{F}(\mathbf{f}_a, \sigma_c, \vec{d}_c)$, where $\mathcal{F}$ contains four MLPs [S1].
*   **Viewing Distance/Direction:** $\sigma_c = \|\mathbf{x} - \mathbf{x}_c\|_2$, $\vec{d}_c = \frac{\mathbf{x} - \mathbf{x}_c}{\|\mathbf{x} - \mathbf{x}_c\|_2}$ [S1].

**Parameters:**
*   $\epsilon$: Constant threshold for mask activation. Not given in the sources.
*   $N$: Total number of anchors. Not given in the sources.
*   $K$: Number of Neural Gaussians per anchor. Not given in the sources.
*   $\lambda_{\text{SSIM}}$: Weight for D-SSIM. Typical value: 0.2 [S1].
*   $\lambda_{\text{vol}}$: Weight for volume regularization. Not given in the sources.
*   $T_{\text{full}}$: Iterations for full-fidelity training. Typical value: 30,000 [S1].
*   $T_{\text{unfold}}$: Iterations for each unfolding step. Typical value: 10,000 [S1].
*   Number of LODs: 4 ($L_0$ to $L_3$) [S1].
*   Learning rate for mask updates: Typical value: 0.01 [S1].
*   Hierarchical grid levels: 12 [S1].
*   Hierarchical grid feature dimension: 4 [S1].
*   LOD $\ell$ grid levels: Retains first $3(\ell+1)$ of 12. L3: 12, L2: 9, L1: 6, L0: 3 [S1].
*   Codebook size $N_c$: 256 [S1].
*   Codebook feature dimension $D_c$: 32 [S1].

**Edge Cases and Pitfalls:**
*   **Popping Artifacts:** The discrete nature of the hierarchy can introduce mild visual "popping" artifacts as new anchors activate during LOD transitions [S1].
*   **Precision:** The straight-through estimator is used for non-differentiable operations (masking, indexing), which requires careful gradient management [S1].

## Subtopics

### [Level-aware Decoding](9330-level-aware-decoding.md)
A module that enables efficient, level-specific interpretation of modulated features for 3D Gaussian Splatting. It sets itself apart by dynamically fine-tuning the decoding network for each resolution level during the unfolding process, ensuring structural flexibility and strict model compactness. Choose it when you need to maintain high visual fidelity across different LODs without storing redundant Gaussian attributes.

## Operating characteristics
*   **Time Complexity:** Introduces additional training complexity compared to baseline methods due to the iterative unfolding process and sparsity regularization [S1].
*   **Memory Complexity:** Significantly reduces storage compared to independent models by sharing hierarchical grids and using a compact codebook. The incremental payload for upgrading between levels is lightweight [S1].
*   **Measured Performance:** Evaluated across PSNR, SSIM, and LPIPS at every LOD. The Full Model consistently achieves the best performance [S1].
*   **Strengths:** Coherent simplification, improved inter-layer consistency, compactness, and high-fidelity rendering across all LODs [S1].
*   **Limitations:** Additional training complexity, limited to static scenes, and potential for mild visual "popping" artifacts [S1].
*   **When to Use:** Progressive streaming context, real-time 3DGS deployment, and balancing compactness with high-fidelity rendering across all LODs [S1].
*   **When Not to Use:** Dynamic scenes or when independent, unconstrained static fidelity is required regardless of storage cost [S1].

## Background
Iterative Gaussian Synopsis was introduced in a paper published in IEEE Transactions on Visualization and Computer Graphics in 2026 [S1]. It addresses the limitations of bottom-up approaches like LapisGS, which build coarse layers first and add enhancements, compromising fidelity and introducing optimization conflicts [S1]. The method builds on the Scaffold-GS architecture, which uses anchors and neural prediction to reduce memory usage [S1].
