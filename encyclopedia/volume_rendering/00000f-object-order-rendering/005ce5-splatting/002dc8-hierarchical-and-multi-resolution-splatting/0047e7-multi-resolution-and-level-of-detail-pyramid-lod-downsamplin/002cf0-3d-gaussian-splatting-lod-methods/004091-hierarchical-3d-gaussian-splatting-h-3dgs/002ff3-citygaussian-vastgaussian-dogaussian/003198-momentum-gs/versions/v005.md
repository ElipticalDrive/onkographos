# Momentum-GS

Also called: Momentum Self-Distillation for 3DGS, Block-wise Momentum-GS

## Overview
Momentum-GS is a block-wise training method for large-scale 3D Gaussian Splatting (3DGS) that uses a momentum-updated teacher model to provide global self-distillation guidance to individual scene blocks [S1, S2, unofficial]. It solves the geometric inaccuracies and "floaters" caused by independent block training in methods like CityGaussian by restoring cross-block spatial consistency without requiring complex alignment or a static coarse prior [S1, S2, unofficial]. Unlike CityGaussian, which relies on spatial contraction and a fixed global prior, Momentum-GS dynamically updates the teacher via exponential moving average (EMA) of student parameters, decoupling the number of training blocks from the available GPU count [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A large-scale scene dataset (images, poses) partitioned into $N$ spatial blocks. Each block has local training cameras and a subset of 3D Gaussians.
*   **Output:** A unified set of 3D Gaussians with consistent geometry and appearance across block boundaries.

**Data Structures:**
*   **Student Model ($\theta_s$):** The set of parameters for the 3D Gaussians in the current block being trained (means, covariances, opacities, spherical harmonics coefficients).
*   **Teacher Model ($\theta_t$):** An exponential moving average (EMA) of the student parameters from previous iterations or blocks.
*   **Block Weight ($w_b$):** A scalar value adjusting the loss contribution of each block based on reconstruction accuracy.

**Algorithm Steps:**
1.  **Initialization:** Initialize the student parameters $\theta_s$ for the current block. Initialize the teacher parameters $\theta_t$ as a copy of $\theta_s$ or from a global prior [S2, unofficial].
2.  **Forward Pass (Student):** Render the current block using $\theta_s$ to generate images for the local training cameras. Compute the reconstruction loss $\mathcal{L}_{rec}$ (e.g., L1 + SSIM) between rendered and ground-truth images [S2, unofficial].
3.  **Forward Pass (Teacher):** Render the same views using the teacher parameters $\theta_t$. Compute the distillation loss $\mathcal{L}_{dist}$ between the student's output and the teacher's output. This loss guides the student to maintain global consistency [S1, S2, unofficial].
4.  **Total Loss:** Combine losses:
    $$ \mathcal{L}_{total} = \mathcal{L}_{rec} + \lambda \mathcal{L}_{dist} $$
    where $\lambda$ is a weighting factor for the distillation term [S2, unofficial].
5.  **Optimization:** Update $\theta_s$ using gradient descent on $\mathcal{L}_{total}$ [S2, unofficial].
6.  **Teacher Update (Momentum):** Update the teacher parameters using EMA:
    $$ \theta_t \leftarrow \alpha \theta_t + (1 - \alpha) \theta_s $$
    where $\alpha$ is the momentum coefficient (typically close to 1, e.g., 0.999) [S1, S2, unofficial].
7.  **Block Weighting:** Adjust the block's contribution to the global optimization based on its reconstruction accuracy. Blocks with higher accuracy may be weighted differently to balance training [S2, unofficial].
8.  **Iteration:** Repeat steps 2-7 for a fixed number of epochs or until convergence. Process other blocks in parallel or sequentially, updating the global teacher model as needed [S2, unofficial].

**Parameters:**
*   $\alpha$ (momentum coefficient): Not given in the sources. [G] Typical values for EMA in similar contexts are 0.999.
*   $\lambda$ (distillation weight): Not given in the sources. [G] Typical values are small, e.g., 0.1-1.0.

**Edge Cases and Pitfalls:**
*   **Precision:** EMA updates can suffer from numerical instability if $\alpha$ is too close to 1 or if parameters vary widely in scale. [G] Use stable EMA implementations.
*   **Boundaries:** Block boundaries may still exhibit artifacts if the teacher model does not adequately capture global context. [S2, unofficial]
*   **Degenerate Input:** If a block has very few training views, the reconstruction loss may be unreliable, making the distillation loss dominant. [S2, unofficial]

## Subtopics

### Distributed Learning for Large-Scale Scenes
Momentum-GS is part of a broader trend towards distributed learning for large-scale 3DGS reconstruction [S3]. This approach involves dividing the scene into multiple cells or blocks and training them in parallel or sequentially, often with mechanisms to ensure consistency across boundaries [S3]. Momentum-GS specifically addresses this by using a momentum-updated teacher to provide global guidance, unlike other distributed methods that may rely on static priors or complex alignment [S1, S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is reduced compared to training the entire scene at once, as blocks can be processed in parallel or with fewer resources per block. However, the teacher update step adds overhead. [S2, unofficial]
*   **Memory Complexity:** Memory usage per GPU is reduced as only one block's Gaussians are actively optimized at a time. The teacher model requires storage for the full scene's Gaussians. [S2, unofficial]
*   **Measured Performance:** Reports ~18.7% LPIPS improvement over CityGaussian with far fewer blocks [S2, unofficial].
*   **Scaling:** Decouples block count from GPU count, allowing flexible scaling. [S2, unofficial]
*   **Strengths:** Restores cross-block spatial consistency, reduces floaters, improves convergence quality. [S1, S2, unofficial]
*   **Limitations:** Requires careful tuning of distillation weight and momentum coefficient. [S2, unofficial]
*   **When to Use:** Large-scale scenes where CityGaussian-like methods produce geometric inaccuracies. [S2, unofficial]
*   **When Not to Use:** Small scenes where global training is feasible and faster. [S2, unofficial]

## Background
Momentum-GS was introduced as a 2026 SOTA update for large-scale 3DGS training [S2, unofficial]. It builds on the concept of momentum self-distillation, where a teacher model (EMA of parameters) guides the student's optimization [S1, unofficial]. This method addresses the limitations of independent block training, such as those in CityGaussian, by providing global guidance without static priors [S1, S2, unofficial].
