# FilterGS

Also called: Traversal-Free Parallel Filtering, Adaptive Shrinking, Parallel filtering structure for Gaussian scale selection

## Overview
FilterGS is a rendering acceleration method for large-scale Level-of-Detail (LoD) 3D Gaussian Splatting that eliminates inefficient serial tree traversal and reduces redundant Gaussian-tile pairs through parallel filtering and adaptive shrinking [S2, unofficial]. Unlike sibling methods that rely on hierarchical depth-dependent traversal, FilterGS uses a traversal-free, parallel filtering structure that selects a single scale for each Gaussian via a learned network, avoiding expensive tree traversal at render time [S1, unofficial]. It addresses the critical challenges of LoD methods: inefficient serial traversal consuming over 60% of rendering time and redundant Gaussian-tile pairs incurring unnecessary processing overhead [S2, unofficial].

## How it works
FilterGS operates in two main phases: a preprocessing phase to compute scene-adaptive parameters, and a parallel rendering phase involving two complementary filters (R&L and Ancestor) followed by adaptive shrinking.

### Inputs and Outputs
**Inputs:**
- A hierarchical LoD Gaussian tree model trained on a set of images and SfM points [S2, unofficial].
- Camera parameters for the current view.
- Rendering resolution (default 1080p) [S2, unofficial].

**Outputs:**
- A filtered set of 2D Gaussians ready for standard alpha-blending rasterization.

### Data Structures
**LoD Gaussian Tree Node:**
Each node $N_{i,j}$ at level $i$ (where $0 \le i \le L$) encapsulates a full Gaussian primitive with parameters:
- Center position $\mu$
- Covariance matrix $\Sigma$
- Opacity $\alpha$
- Spherical Harmonics coefficients $c$ (color)
- Rotation $q$
- Scale $s$

**Ancestor Path ($AP_{i,j}$):**
A precomputed ordered list of serial numbers of all ancestor nodes for node $N_{i,j}$, from the direct parent up to the root node [S2, unofficial].

**Key-value Pair Contribution (KPC):**
A metric quantifying the redundancy of a Gaussian-tile pair $g_k \to t_i$, defined as the expected number of pixels influenced by a Gaussian weighted by blended opacity [S2, unofficial]:
$$ K_{g_k t_i} = \frac{1}{n_{gs}} \sum_{j=1}^{n_{gs}} \alpha_{ij} T_{ij} $$
where $n_{gs}$ is the number of Gaussians influencing tile $t_i$, $\alpha_{ij}$ is the opacity of Gaussian $g_k$ at pixel $j$, and $T_{ij}$ is the transmittance before $g_k$ at that pixel [S2, unofficial].

**Gaussian to Tile Contribution (GTC):**
The average KPC of all Gaussians influencing a single tile $t_i$:
$$ \bar{G}_{t_i} = \frac{1}{n_{gs}} \sum_{j=1}^{n_{gs}} K_{g_j t_i} $$
This is aggregated view-wise and scene-wide to derive a global threshold [S2, unofficial].

### Numbered Steps

1.  **Preprocessing (Offline/Pre-rendering):**
    - Perform a pre-rendering pass over all training views following the standard 3DGS pipeline [S2, unofficial].
    - Compute the Global Tile Coverage (GTC) metric $\bar{G}$ [S2, unofficial].
    - Derive a scene-adaptive shrinking threshold $\tau = f(\bar{G})$ [S2, unofficial]. A low $\bar{G}$ indicates high congestion, necessitating a more aggressive pruning strategy [S2, unofficial].

2.  **Frustum Culling:**
    - Project all Gaussians inside the view frustum into 2D Gaussians [S2, unofficial].

3.  **Parallel Filtering Step 1: Radius and Leaf (R&L) Filter:**
    - For every in-frustum Gaussian, compute the 2D covariance $\Sigma_{2D}$ and its eigenvalues $\sigma$ representing standard deviations along screen-space principal axes [S2, unofficial].
    - Define the pixel radius $R_{2D} = 3\sigma$ [S2, unofficial].
    - Compare $R_{2D}$ against a threshold $\tau_R$ (default 3) [S2, unofficial].
    - Retain any node where $R_{2D} \le \tau_R$ [S2, unofficial].
    - Exempt all leaf nodes from the pruning threshold to prevent holes in the rendered image; preserve every leaf node at least once [S2, unofficial].

4.  **Parallel Filtering Step 2: Ancestor Filter:**
    - For every node $N_{i,j}$ that passed R&L filtering, traverse its precomputed ancestor path $AP_{i,j}$ [S2, unofficial].
    - If any ancestor node $N_{i^*,j^*}$ (where $N_{i^*,j^*} \in AP_{i,j}$) is an internal node that passed R&L filtering, cull the descendant node $N_{i,j}$ [S2, unofficial].
    - This ensures that branches with a valid coarser node retain only a single, highest-level Gaussian node [S2, unofficial].

5.  **Adaptive Shrinking:**
    - During Axis-Aligned Bounding Box (AABB) formation, adaptively scale the filtered Gaussians by the pre-computed factor $\tau$ [S2, unofficial].
    - Calculate the radius $r$ at which opacity decays to threshold $\tau$:
      $$ r = \sqrt{2\sigma_{max} \ln(\alpha_0 / \tau)} $$
      where $\sigma_{max}$ is the maximum standard deviation and $\alpha_0$ is the central opacity [S2, unofficial].
    - This significantly reduces redundant key-value pairs before sorting and $\alpha$-blending [S2, unofficial].

6.  **Rasterization:**
    - Render the filtered Gaussians using standard $\alpha$-blending:
      $$ C = \sum_{i \in N} c_i \alpha_i T_i, \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
      where $c_i$ is color, $\alpha_i$ is opacity, and $T_i$ is residual transmittance [S2, unofficial].

### Parameters
- $\tau_R$: The radius threshold for pruning. Default value is 3. Smaller values retain finer primitives [S2, unofficial].
- $\lambda_G$: Scaling factor controlling the aggressiveness of shrinking. Default value is 0.2 [S2, unofficial].
- Redundancy Threshold: Key-value pairs with KPC below 0.01 are defined as redundant [S2, unofficial].
- $\gamma$: Geometric shrinking factor for child node scales in the LoD tree, must satisfy $0 < \gamma < 1$ [S2, unofficial].
- Resolution: All renderings are performed at 1080p resolution [S2, unofficial].

### Edge Cases and Pitfalls
- **Holes in Rendered Image:** Directly applying the radius pruning criterion may incorrectly remove entire branches composed of Gaussians with uniformly large radii. This is mitigated by exempting leaf nodes from the pruning threshold [S2, unofficial].
- **Congestion:** High Gaussian density leads to low GTC values, indicating inefficient rasterization. The adaptive shrinking strategy addresses this by reducing the effective influence radius of Gaussians [S2, unofficial].
- **Fixed Thresholds:** Using a fixed threshold (e.g., $\tau = 1/255$ as in FlashGS) is overly conservative for congested scenes, leaving many redundant Gaussians untouched. The scene-adaptive threshold $\tau$ derived from GTC provides a better trade-off [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Filtering time scales with the total number of Gaussians $N$ and is independent of the hierarchical depth $L$ (Depth Decoupling) [S2, unofficial]. The parallel filtering time is expressed as $T_{parallel} = T_{synch.} + T_{calcu.}(N)$, where $T_{synch.}$ is the fixed overhead of kernel launch and synchronization, and $T_{calcu.}(N)$ is the time for radius estimation and filtering of all $N$ in-frustum Gaussians [S2, unofficial].
- **Memory Complexity:** Not given in the sources.
- **Performance:** FilterGS achieves state-of-the-art rendering speeds while maintaining competitive visual quality across multiple large-scale datasets [S2, unofficial]. It outperforms baseline methods in reducing Gaussian preparation time $t_f$ prior to rasterization [S2, unofficial].
- **Strengths:** Eliminates inefficient serial tree traversal, reduces redundant Gaussian-tile pairs, maximizes GPU concurrency, and adapts to scene congestion.
- **Limitations:** Requires a pre-rendering pass to compute GTC and adaptive thresholds. The effectiveness depends on the accuracy of the LoD tree construction.

## Background
FilterGS was introduced in the paper "FilterGS: Traversal-Free Parallel Filtering and Adaptive Shrinking for Large-Scale LoD 3D Gaussian Splatting" [S2, unofficial]. It addresses the limitations of existing LoD-based 3DGS methods, which suffer from inefficient serial traversal and redundant Gaussian-tile pairs [S2, unofficial]. The method builds on the shared principles of multi-scale filtering, specifically the convolution of 3D Gaussian density with a low-pass filter to constrain spatial frequency [S1, unofficial].
