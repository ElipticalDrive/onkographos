# Adaptive-Scale Color Offset

## Overview
Adaptive-Scale Color Offset (ACO) is a training-stage module for multi-scale 3D Gaussian Splatting that corrects scale-dependent color mismatch by applying a learnable, scale-specific RGB offset to the shared base color of each Gaussian [S1]. It sets itself apart from sibling methods like [Alias-free 4D Gaussian Splatting](9872-alias-free-4d-gaussian-splatting.md) by modifying only the Spherical Harmonics (SH) DC coefficient to adapt color per scale, while keeping Gaussian geometry and higher-order view-dependent SH coefficients unchanged [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   $N$: Number of Gaussians.
    *   $S$: Number of rendering scales.
    *   $B$: Number of SH basis functions.
    *   $f_{i,b} \in \mathbb{R}^3$: The original SH coefficients for Gaussian $i$ and basis $b$ [S1].
    *   $Y_b(d)$: The value of the $b$-th SH basis function evaluated at view direction $d$ [S1].
    *   $s_{target}$: The index of the target rendering scale during inference ($0 \le s_{target} < S$) [S1].
*   **Outputs:**
    *   $c_{i, s_{target}}(d)$: The corrected color of Gaussian $i$ at scale $s_{target}$ for view direction $d$ [S1].

**Data Structures**
*   **SH Coefficients ($f$):** A tensor of shape $(N, B, 3)$. $f_{i,b}$ stores the RGB coefficients for Gaussian $i$ and basis $b$ [S1].
*   **ACO Offsets ($\Delta$):** A learnable parameter tensor of shape $(N, S, 3)$ [S1].
    *   $\Delta_{i,s} \in \mathbb{R}^3$ is the RGB offset for Gaussian $i$ at scale $s$ [S1].
    *   Initialized to zero: $\Delta_{i,s} = \mathbf{0}$ for all $i, s$ [S1].

**Numbered Steps**
1.  **Initialization:** Initialize the ACO offset matrix $\Delta \in \mathbb{R}^{N \times S \times 3}$ with zeros [S1].
2.  **Training Loop:**
    a. Select a training scale $s$ from the set of $S$ scales [S1].
    b. Render the scene at scale $s$ using the standard 3DGS splatting algorithm [G].
    c. Compute the reconstruction loss $\mathcal{L}$ between the rendered image and the ground truth image [S1].
    d. Back-propagate $\mathcal{L}$ to update the SH coefficients $f$ and the specific ACO offsets $\Delta_{i,s}$ for the selected scale $s$ [S1].
3.  **Inference/Rendering:**
    a. Given a target rendering scale $s_{target}$ [S1].
    b. For each Gaussian $i$ and view direction $d$:
        i. Retrieve the original DC coefficient $f_{i,0}$ [S1].
        ii. Retrieve the scale-specific offset $\Delta_{i, s_{target}}$ [S1].
        iii. Compute the adapted DC coefficient: $f_{i,0}^{s_{target}} = f_{i,0} + \Delta_{i, s_{target}}$ [S1].
        iv. Compute the color using the adapted DC coefficient and the shared higher-order coefficients:
        $$c_{i, s_{target}}(d) = Y_0(d) f_{i,0}^{s_{target}} + \sum_{b=1}^{B-1} Y_b(d) f_{i,b}$$ [S1].
        v. Use $c_{i, s_{target}}(d)$ for splatting [S1].

**Formulas**
The base color representation for Gaussian $i$ along view direction $d$ is given by the SH expansion [S1]:
$$c_i(d) = \sum_{b=0}^{B-1} Y_b(d) f_{i,b}$$
where $Y_b(d)$ is the $b$-th SH basis function and $f_{i,b}$ is the corresponding SH coefficient [S1].

The scale-adapted color at scale $s$ is defined as [S1]:
$$c_{i,s}(d) = Y_0(d) f_{i,0}^s + \sum_{b=1}^{B-1} Y_b(d) f_{i,b}$$
where the adapted DC coefficient is $f_{i,0}^s = f_{i,0} + \Delta_{i,s}$ [S1]. Here, $\Delta_{i,s} \in \mathbb{R}^3$ is the learnable DC color offset for Gaussian $i$ at scale $s$ [S1].

**Parameters**
*   **Number of Scales ($S$):** Not given in the sources.
*   **SH Degree:** Not given in the sources, but $B$ is the number of basis functions.
*   **Initialization:** $\Delta_{i,s} = 0$ [S1].

**Edge Cases and Pitfalls**
*   **Geometry Independence:** ACO modifies only the DC color term. It leaves the Gaussian geometry (position, covariance/scale) unchanged [S1].
*   **Shared Higher-Order Coefficients:** The higher-order SH coefficients ($b > 0$) remain shared across all scales and are not modified by the offset [S1].
*   **Optimization Scope:** The DC offsets are optimized through the backbone reconstruction loss alone. The loss back-propagates to the corresponding offset $\Delta_{i,s}$ only at the rendering scale $s$ being trained [S1].

**Pseudocode**
```python
import torch
import torch.nn as nn

class AdaptiveScaleColorOffset(nn.Module):
    def __init__(self, num_gaussians, num_scales):
        super().__init__()
        # ACO offsets: shape (N, S, 3), initialized to zero [S1]
        self.offsets = nn.Parameter(torch.zeros(num_gaussians, num_scales, 3))

    def forward(self, sh_coeffs, view_directions, target_scale):
        # sh_coeffs: (N, B, 3)
        # view_directions: (N, 3)
        # target_scale: int in [0, S-1]
        dc_coeff = sh_coeffs[:, 0, :]  # (N, 3)
        higher_order_coeffs = sh_coeffs[:, 1:, :]  # (N, B-1, 3)

        # Retrieve scale-specific offset [S1]
        scale_offset = self.offsets[:, target_scale, :]  # (N, 3)
        adapted_dc = dc_coeff + scale_offset  # (N, 3)

        # Evaluate SH basis functions for view directions [G]
        # Y_0 is constant; Y_1 to Y_{B-1} depend on direction
        Y_0 = torch.full((sh_coeffs.size(0), 1), 1.0 / (4 * 3.141592653589793) ** 0.5, device=sh_coeffs.device)
        Y_higher = compute_sh_bases_higher(view_directions, sh_coeffs.size(1) - 1)  # [G]

        # Compute scale-adapted color: c_{i,s}(d) = Y_0 * f_{i,0}^s + sum_{b=1}^{B-1} Y_b(d) * f_{i,b} [S1]
        color_dc = Y_0 * adapted_dc.unsqueeze(1)  # (N, 1, 3)
        color_higher = torch.sum(Y_higher.unsqueeze(2) * higher_order_coeffs, dim=1)  # (N, 3)
        return color_dc.squeeze(1) + color_higher  # (N, 3)
```

## Subtopics

### Error-Guided Gaussian Reallocation (EGR)
A companion module to ACO that redistributes low-contribution Gaussians toward high-error regions to address primitive allocation imbalance [S1]. It uses contribution and error-aware selection under a fixed Gaussian budget [S1].

### Scale-Adaptive Gaussian Splatting
The parent method that ACO extends [Parent]. It involves rendering at multiple scales to handle aliasing and detail [G].

### Alias-free 4D Gaussian Splatting
A sibling method that addresses aliasing in dynamic scenes, differing from ACO by not using scale-specific color offsets but rather other anti-aliasing techniques [G].

## Operating characteristics
*   **Time Complexity:** Rendering time is not significantly increased by ACO, as it only adds a vector addition to the DC coefficient per Gaussian [G]. The training time increases slightly due to the optimization of the offset parameters $\Delta$ [S1].
*   **Memory Complexity:** ACO adds $N \times S \times 3$ parameters to the model, where $N$ is the number of Gaussians and $S$ is the number of scales [S1].
*   **Strengths:** Corrects color mismatch at coarse rendering scales without altering Gaussian geometry [S1]. It provides scale-dependent color adaptation [S1].
*   **Limitations:** Only corrects color, not geometry or view-dependent shading (higher-order SH) [S1]. It requires training at multiple scales [S1].
*   **When to use:** When rendering multi-scale 3DGS and observing color inaccuracies at coarse scales [S1].
*   **When not to use:** When geometry accuracy is the primary concern, or when single-scale rendering is sufficient [G].

## Background
ACO was proposed in the paper "Adaptive-Scale Color Offset and Error-Guided Gaussian Reallocation for Multi-Scale 3D Gaussian Splatting" published in *Mathematics* in 2026 [S1]. It addresses the issue where coarse-scale error regions remain underrepresented in multi-scale 3DGS, leading to color mismatch because the same color representation is shared across rendering scales [S1]. The method is part of the ACO-EGR framework, which also includes Error-Guided Gaussian Reallocation (EGR) [S1].
