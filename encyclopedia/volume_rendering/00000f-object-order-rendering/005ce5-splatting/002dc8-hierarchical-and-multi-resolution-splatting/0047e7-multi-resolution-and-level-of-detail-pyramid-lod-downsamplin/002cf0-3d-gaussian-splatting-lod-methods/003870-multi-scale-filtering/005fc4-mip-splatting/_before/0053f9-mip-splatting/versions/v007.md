# MIP-Splatting

Also called: Alias-free 3D Gaussian Splatting, Anti-Aliased 3D Gaussian Splatting, MS 3DGS, MS-GS, Mip 3D Gaussian Splatting, Multi-Scale Gaussians, Multi-scale 3D Gaussian Splatting

## Overview
MIP-Splatting eliminates aliasing artifacts caused by resolution changes, focal length variations, or camera distance changes in 3D Gaussian Splatting by combining a 3D smoothing filter, a 2D Mip filter, and multi-scale Gaussian selection [S1][S7, unofficial]. It sets itself apart from standard 3DGS and EWA splatting by constraining the 3D representation frequency to the training data's Nyquist limit and replacing the empirical dilation filter with a physics-based box filter approximation [S3][S7, unofficial].

## How it works
**Inputs:** A set of optimized 3D Gaussians $\{G_k\}$, camera parameters (intrinsics $K$, extrinsics $R, t$), and a target rendering resolution/scale.
**Outputs:** A rendered 2D image.

**Data Structures:**
Each Gaussian $G_k$ stores:
- Position $p_k \in \mathbb{R}^3$
- Covariance matrix $\Sigma_k \in \mathbb{R}^{3 \times 3}$ (parameterized by rotation $O_k$ and scaling $s_k$)
- Opacity $\alpha_k \in [0, 1]$
- Color features (e.g., Spherical Harmonics coefficients)
- Level of detail index $l_k \in \{1, \dots, l_{max}\}$
- Maximum pixel coverage $S_{k,max}$ and minimum pixel coverage $S_{k,min}$ [S3].

**Parameters:**
- Number of detail levels: 4 levels ($l_{max}=4$), corresponding to 1x, 4x, 16x, and 64x downsampled resolutions [S3].
- Selective rendering threshold $S_T = 2$ pixels [S3].
- Opacity threshold $\sigma_T = 1/255$ [S3].
- Relative maximum coverage $S_{rel,max} = 1.5$ [S3].
- Relative minimum coverage $S_{rel,min} = 0.5$ [S3].
- Decay coefficient $\lambda_1 = 0.95$ [S3].
- Decay coefficient $\lambda_2 = 1.05$ [S3].
- 3D smoothing filter variance scalar $s_{3D} = 0.2$ [S7, unofficial].
- 2D Mip filter variance scalar $s_{2D} = 0.1$ [S7, unofficial].
- Voxel grid resolution for aggregation: $(400/l_m)^3$ [S3].
- Iteration interval for recomputing maximal sampling rate: $m=100$ [S7, unofficial].

**Method Steps:**
1. **3D Smoothing Filter (Training):** To constrain the maximal frequency of the 3D representation to meet the Nyquist limit of the training data, a 3D Gaussian low-pass filter $G_{low}$ is applied to each primitive $G_k$ before projection [S7, unofficial]. The world space sampling interval is $\hat{T} = d/f$ and sampling frequency is $\hat{\nu} = f/d$ [S7, unofficial]. The regularized covariance becomes $\Sigma_k + \hat{\nu}_k^s \cdot I$, where $s$ controls filter size [S7, unofficial]. The filtered Gaussian is:
   $$ G_k(x)_{reg} = \frac{\sqrt{|\Sigma_k|}}{\sqrt{|\Sigma_k + \hat{\nu}_k^s \cdot I|}} e^{-\frac{1}{2}(x-p_k)^T (\Sigma_k + \hat{\nu}_k^s \cdot I)^{-1} (x-p_k)} $$
   The maximal sampling rate is recomputed every $m$ iterations [S7, unofficial].

2. **Multi-Scale Aggregation (Training):** After a warm-up stage (first 1,000 iterations), coarse-level Gaussians are introduced by aggregating fine-level Gaussians that are too small [S3]. For all levels $l_m$ from 2 to $l_{max}$: render all Gaussians from levels $[1, l_m-1]$ at $4^{l_m-1}$ times downsampled resolution to calculate pixel coverage $S_k$ [S3]. Identify small Gaussians where $S_k < S_T$ [S3]. Bin them into a voxel grid of size $(400/l_m)^3$ [S3]. For each voxel, perform average pooling on position, rotation, spherical harmonics, opacity, and scaling to create a new Gaussian [S3]. Calculate the average pixel coverage $S_{avg}$ and enlarge the new Gaussian's scaling by factor $S_T / S_{avg}$ to target coverage $S_T$ [S3]. Assign the new Gaussian to level $l_m$ [S3]. Train the model with both original and downsampled images [S3].

3. **Selective Rendering (Inference):** Gaussians are selected based on their pixel coverage relative to the current render resolution [S3]. Calculate pixel coverage $S_k$ for all Gaussians at the current render scale [S3]. Update $S_{k,max}$ and $S_{k,min}$ if the rendering downsample scale equals the scale when the Gaussian was created:
   $$ S_{k,max}' = \max(\lambda_1 S_{k,max}, S_k) $$
   $$ S_{k,min}' = \min(\lambda_2 S_{k,min}, S_k) $$
   A Gaussian is selected for rendering if:
   $$ \frac{S_k}{S_{k,max}} \le S_{rel,max} \quad \land \quad \left( \frac{S_k}{S_{k,min}} \ge S_{rel,min} \lor S_k \ge S_T \right) $$
   Render only the selected Gaussians [S3].

4. **2D Mip Filter (Rendering):** Replace the standard 2D dilation operation with a 2D Mip filter that approximates the physical box filter of a camera sensor [S7, unofficial]. Project the 3D Gaussian to ray space via local affine transformation $\Sigma''_k = J_k \Sigma'_k J_k^T$ [S7, unofficial]. The 2D Mip-filtered Gaussian uses a covariance $\Sigma_{k2D} + sI$, where $s$ covers a single pixel in screen space [S7, unofficial]. The filtered Gaussian is:
   $$ G_{k2D}(x)_{mip} = \frac{\sqrt{|\Sigma_{k2D}|}}{\sqrt{|\Sigma_{k2D} + sI|}} e^{-\frac{1}{2}(x-p_k)^T (\Sigma_{k2D} + sI)^{-1} (x-p_k)} $$
   This prevents dilation artifacts when zooming out and erosion when zooming in [S7, unofficial].

**Pseudocode:**
```python
import math

def aggregate_small_gaussians(G_all, l_max, S_T):
    """Aggregates small Gaussians into larger ones for coarser levels."""
    for l_m in range(2, l_max + 1):
        # Compute pixel coverage S_k for all Gaussians at 4^(l_m-1) downsampled resolution
        # (Standard rasterization step to measure projected area in pixels)
        S_k = {G.id: compute_pixel_coverage(G, scale=4**(l_m-1)) for G in G_all}
        
        # Select Gaussians smaller than threshold
        G_small = [G for G in G_all if S_k[G.id] < S_T]
        
        # Voxelize by position
        voxel_res = 400 / l_m
        voxels = {}
        for G in G_small:
            idx = (int(G.position[0] / voxel_res), int(G.position[1] / voxel_res), int(G.position[2] / voxel_res))
            voxels.setdefault(idx, []).append(G)
            
        # Aggregate and insert
        for voxel in voxels.values():
            if not voxel: continue
            # Average pooling of attributes
            G_new = {
                'id': G.id, 'position': [sum(g.position[i] for g in voxel)/len(voxel) for i in range(3)],
                'scale': [sum(g.scale[i] for g in voxel)/len(voxel) for i in range(3)],
                'opacity': sum(g.opacity for g in voxel)/len(voxel),
                'level': l_m
            }
            # Calculate average pixel coverage
            S_avg = sum(S_k[G.id] for G in voxel) / len(voxel)
            # Enlarge scaling to target S_T
            scale_factor = S_T / S_avg
            G_new['scale'] = [s * scale_factor for s in G_new['scale']]
            G_all.append(G_new)

def selective_render(G_all, render_scale, S_T=2.0, S_rel_max=1.5, S_rel_min=0.5, lambda_1=0.95, lambda_2=1.05):
    """Selects Gaussians for rendering based on pixel coverage."""
    S_k = {G.id: compute_pixel_coverage(G, scale=render_scale) for G in G_all}
    
    # Update coverage bounds for Gaussians at their creation scale
    for G in G_all:
        if G.level == render_scale:
            G['S_k_max'] = max(lambda_1 * G.get('S_k_max', 0.0), S_k[G.id])
            G['S_k_min'] = min(lambda_2 * G.get('S_k_min', float('inf')), S_k[G.id])
            
    selected_Gs = []
    for G in G_all:
        sk = S_k[G.id]
        sk_max = G.get('S_k_max', float('inf'))
        sk_min = G.get('S_k_min', 0.0)
        
        cond1 = (sk / sk_max) <= S_rel_max
        cond2 = (sk / sk_min) >= S_rel_min
        cond3 = sk >= S_T
        
        if cond1 and (cond2 or cond3):
            selected_Gs.append(G)
            
    return render_gaussians(selected_Gs, render_scale)

def apply_2d_mip_filter(G_projected, pixel_variance_s):
    """Applies 2D Mip filter to a projected 2D Gaussian."""
    Sigma_k2D = G_projected['covariance']
    # Add variance to covariance
    Sigma_reg = [[Sigma_k2D[i][j] + (pixel_variance_s if i == j else 0) for j in range(3)] for i in range(3)]
    
    # Compute normalization factor for opacity preservation
    det_orig = determinant_3x3(Sigma_k2D)
    det_reg = determinant_3x3(Sigma_reg)
    C = math.sqrt(det_orig / det_reg)
    
    G_projected['opacity'] = G_projected['opacity'] * C
    G_projected['covariance'] = Sigma_reg
    return G_projected

def determinant_3x3(M):
    return (M[0][0]*(M[1][1]*M[2][2]-M[1][2]*M[2][1]) -
            M[0][1]*(M[1][0]*M[2][2]-M[1][2]*M[2][0]) +
            M[0][2]*(M[1][0]*M[2][1]-M[1][1]*M[2][0]))
```

**Edge Cases and Pitfalls:**
- Naive filtering of small Gaussians at different resolution scales causes missing parts in the rendered image; aggregation prevents this [S3].
- Performance overhead occurs because all Gaussians must be splatted even if filtered later, preventing linear speedup at very low resolutions [S3].
- Standard 3DGS systematically underestimates the scale parameter during optimization, leading to erosion effects when zooming in because dilated 2D Gaussians become smaller in screen space [S7, unofficial].

## Subtopics

### [2D Mip Filter](9593-2d-mip-filter.md)
Mitigates aliasing when rendering at camera distances or focal lengths larger than training conditions. Sets itself apart by dynamically adjusting opacity based on the determinant ratio of the dilated covariance, preventing excessive blurring. Choose it when zooming out causes dilation artifacts in standard splatting.

### LinPrim Anti-Aliasing
Combines a 3D smoothing filter with bounding box expansion to limit high frequencies [S11]. Sets itself apart by expanding bounding box vertices parallel to the screen to enlarge the primitive footprint, acting as a coarse band-limiting approximation [S11]. Choose it when primitives do not rely on modifying the screen space Gaussian distribution [S11].

### Anti-Aliasing via Kernel Adaptation
Adapts kernel bandwidth to prevent aliasing when the volume is undersampled relative to the screen [S12, unofficial]. Sets itself apart by computing a ray-space ellipsoid using the local perspective Jacobian to stretch the kernel appropriately [S12, unofficial]. Choose it for low magnification or perspective scenarios where standard splat kernels cause aliasing [S12, unofficial].

### Integration with Mip-Splatting and Scaffold-GS
Addresses projection approximation errors in conventional 3D-GS pipelines [S13]. Sets itself apart by seamlessly integrating with existing multi-scale methods to reduce projection error [S13]. Choose it when higher geometric fidelity is required during the projection step [S13].

## Operating characteristics
**Time and Memory Complexity:**
- Rendering time is not linearly reduced at very low resolutions because all Gaussians must be splatted even if filtered later, preventing linear speedup [S3].
- Memory overhead is low, with fewer than 5% additional Gaussians added [S3].

**Measured Performance:**
- Achieves 13%-66% PSNR and 160%-2400% rendering speed improvements at 4x-128x scale rendering on the MipNeRF360 dataset [S3].
- On the Blender dataset, Mip-Splatting achieves a PSNR of 32.81 at Full Res, 34.49 at 1/2 Res, 35.45 at 1/4 Res, and 35.50 at 1/8 Res [S7, unofficial].

**Strengths and Limitations:**
- Eliminates dilation/erosion artifacts when zooming in/out [S6, unofficial].
- Unlike EWA splatting, which limits frequency bandwidth empirically, Mip-Splatting's 3D filter is determined by training data [S7, unofficial].
- Unlike Mip-NeRF, it does not require multi-scale images for supervision [S7, unofficial].

**When to use:**
- Novel View Synthesis (NVS) in virtual reality, cinematography, and robotics, specifically addressing out-of-distribution generalization where training and testing occur at different sampling rates [S7, unofficial].
- When rendering at resolutions or focal lengths significantly different from training data [S1][S7, unofficial].

## Background
MIP-Splatting was introduced by Yu et al. in 2024 (CVPR 2024) [S3]. It addresses the aliasing problem in 3D Gaussian Splatting, which arises because 3DGS samples the scene at pixel centers, ignoring the footprint of the pixel itself [S5][S7, unofficial]. Standard 3DGS systematically underestimates the scale parameter of 3D Gaussians during optimization, leading to erosion effects when zooming in because dilated 2D Gaussians become smaller in screen space [S7, unofficial]. Zooming out leads to dilation artifacts because the projected 2D Gaussians reduce in size while the same amount of dilation is applied [S7, unofficial]. The method builds on the principles of multi-scale filtering and anti-aliasing in computer graphics, such as EWA splatting and Mip-NeRF, but applies them to the 3D Gaussian Splatting pipeline [S3][S7, unofficial].
