# WildGaussians Rendering and Appearance Modeling

Also called: 3D Gaussian Splatting in the Wild

## Overview
WildGaussians extends 3D Gaussian Splatting (3DGS) to handle unconstrained image collections with significant appearance variations, such as changes in illumination, weather, and transient objects [S1]. It solves the problem of standard 3DGS failing to generalize across images with different appearances by introducing trainable per-image and per-Gaussian embeddings that predict affine color transformations [S1]. Unlike standard 3DGS, which assumes consistent appearance, WildGaussians decouples the geometric structure from the appearance, allowing the same 3D geometry to be rendered under diverse lighting conditions [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of $N$ training images with known camera poses and projection matrices [S1].
*   An initial set of 3D Gaussians (position, covariance, opacity, base color) typically initialized via Structure-from-Motion (SfM) points [S1].
*   Ground truth RGB images $C$ [S1].

**Outputs:**
*   Optimized 3D Gaussian parameters (position, covariance, opacity, base SH coefficients) [S1].
*   An appearance modeling MLP $f$ [S1].
*   Per-image embeddings $\{e_j\}_{j=1}^N$ [S1].
*   Per-Gaussian embeddings $\{g_i\}$ [S1].
*   An uncertainty predictor (affine mapping + softplus) [S1].

### Data Structures

1.  **3D Gaussian $i$**:
    *   $\mathbf{p}_i \in \mathbb{R}^3$: 3D position.
    *   $\mathbf{\Sigma}_i \in \mathbb{R}^{3 \times 3}$: 3D covariance matrix (usually stored as rotation $\mathbf{R}$ and scale $\mathbf{s}$).
    *   $\alpha_i \in \mathbb{R}$: Opacity.
    *   $\bar{c}_i \in \mathbb{R}^3$: Base color (0-th order Spherical Harmonic coefficient) [S1].
    *   $\mathbf{g}_i \in \mathbb{R}^{d_g}$: Per-Gaussian appearance embedding [S1].

2.  **Per-Image Embedding $j$**:
    *   $\mathbf{e}_j \in \mathbb{R}^{d_e}$: Trainable vector for image $j$ [S1].

3.  **Appearance MLP $f$**:
    *   Input: Concatenation $[\mathbf{e}_j; \mathbf{g}_i; \bar{c}_i]$ [S1].
    *   Output: Affine parameters $(\beta, \gamma) \in \mathbb{R}^6$ (3 for scale, 3 for shift, one per RGB channel) [S1].

4.  **Uncertainty Predictor**:
    *   Input: DINO v2 features (patch-wise $14 \times 14$) [S1].
    *   Operation: Trainable affine mapping followed by softplus activation [S1].
    *   Output: Uncertainty score $\sigma$ per patch, upscaled to image resolution via bilinear interpolation [S1].

### Numbered Steps

1.  **Initialization**:
    *   Center and normalize the initial point cloud to $[0, 1]$ using the 0.97 quantile of the $L_\infty$ norm [S1].
    *   Initialize per-Gaussian embeddings $\mathbf{g}_i$ using Fourier features to enforce locality:
        $$ \text{FF}(\mathbf{p}) = [\sin(\pi p_k 2^m), \cos(\pi p_k 2^m)]_{k=1,2,3; m=1,\dots,4} $$
        where $\mathbf{p}$ is the normalized point coordinate [S1].
    *   Initialize per-image embeddings $\mathbf{e}_j$ randomly or to zero (for test-time) [S1].
    *   Initialize sky points using Fibonacci sphere sampling at a fixed radius $r_s$, projecting to all cameras, and keeping only visible points [S1].

2.  **Projection**:
    *   For each Gaussian $i$, compute the 2D mean $\boldsymbol{\mu}'_i$ and covariance $\mathbf{\Sigma}'_i$ in screen space.
    *   Let $\mathbf{W}$ be the view-projection matrix and $\mathbf{J}$ be the Jacobian of the affine approximation of the projection [S1].
    *   Compute the 2D covariance:
        $$ \mathbf{\Sigma}'_i = \mathbf{J} \mathbf{W} \mathbf{\Sigma}_i \mathbf{W}^T \mathbf{J}^T $$
        where $\mathbf{\Sigma}'_i$ is the $2 \times 2$ submatrix corresponding to the first two rows and columns of the projected covariance [S1].

3.  **Appearance Modeling (Toning)**:
    *   For each Gaussian $i$ and its corresponding image $j$, retrieve $\mathbf{e}_j$, $\mathbf{g}_i$, and $\bar{c}_i$ [S1].
    *   Pass these into the MLP $f$ to predict affine parameters $(\beta, \gamma)$ [S1]:
        $$ (\beta, \gamma) = f(\mathbf{e}_j, \mathbf{g}_i, \bar{c}_i) $$
    *   Compute the view-dependent color $\hat{c}_i(r)$ using the standard 3DGS spherical harmonics for ray direction $r$ [S1].
    *   Compute the toned color $\tilde{c}_i$:
        $$ \tilde{c}_i = \gamma \cdot \hat{c}_i(r) + \beta $$
        where $\beta, \gamma \in \mathbb{R}^3$ are applied per color channel [S1].

4.  **Rasterization**:
    *   Sort Gaussians front-to-back based on distance to the image plane [S1].
    *   For each pixel, traverse the sorted Gaussians. Compute the blending weight $\alpha_i$ for pixel coordinate $x$:
        $$ \alpha_i = e^{-\frac{1}{2}(x-\boldsymbol{\mu}'_i)^T (\mathbf{\Sigma}'_i)^{-1} (x-\boldsymbol{\mu}'_i)} $$
    *   Alpha-composite the toned colors $\tilde{c}_i$ to produce the rendered image $\tilde{C}$ [S1].
    *   Simultaneously, render the image $\hat{C}$ using the original un-toned colors $\hat{c}_i(r)$ for the DSSIM loss component [S1].
    *   *Note*: Mip-Splatting techniques may be used to reduce aliasing artifacts [S1].

5.  **Uncertainty Modeling**:
    *   Extract DINO v2 features for the training image [S1].
    *   Predict uncertainty $\sigma$ using the affine mapping and softplus activation [S1].
    *   Upscale $\sigma$ to image resolution using bilinear interpolation [S1].
    *   Clip $\sigma$ to $[0.1, \infty)$ [S1].
    *   Convert uncertainty to a binary mask $M$ for weighting the color loss:
        $$ M = \mathbb{1}_{\frac{1}{2\sigma^2} > 1} $$
        where $\mathbb{1}$ is the indicator function [S1].

6.  **Optimization**:
    *   Compute the color loss $L_{color}$:
        $$ L_{color} = \lambda_{dssim} DSSIM(\hat{C}, C) + (1 - \lambda_{dssim}) \|\tilde{C} - C\|_1 $$
        where $C$ is the ground truth image and $\lambda_{dssim} = 0.2$ [S1].
    *   Compute the DINO cosine similarity loss per patch for uncertainty optimization:
        $$ L_{dino}(\tilde{D}, D) = \min\left(1, 2 - \frac{2\tilde{D} \cdot D}{\|\tilde{D}\|_2 \|D\|_2}\right) $$
        where $\tilde{D}$ and $D$ are the predicted and ground truth DINO features [S1].
    *   The total uncertainty loss includes a log prior:
        $$ L_{uncertainty} = \frac{L_{dino}(\tilde{D}, D)}{2\sigma^2} + \lambda_{prior} \log \sigma $$
        [S1].
    *   Update all parameters (3DGS, MLP, embeddings) using the combined loss. Gradients do not propagate through the rendering pipeline for the uncertainty predictor [S1].
    *   Periodically reset Gaussian opacity to a small value to prevent local minima. Disable uncertainty training for a few iterations after each reset [S1].

7.  **Test-Time Optimization**:
    *   For a new unseen image, initialize its per-image embedding $\mathbf{e}_{new}$ to zeros [S1].
    *   Keep all other parameters (3DGS, MLP, other embeddings) fixed [S1].
    *   Optimize $\mathbf{e}_{new}$ using the Adam optimizer and the main training objective (Eq. 6) [S1].

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class WildGaussiansRenderer:
    def __init__(self, gaussians, appearance_mlp, uncertainty_predictor, lambda_dssim=0.2):
        """
        gaussians: List of Gaussian objects with attributes:
                   p (3D pos), sigma (3D cov), alpha (opacity), 
                   sh_coeffs (SH params), g (per-gaussian embedding)
        appearance_mlp: nn.Module taking [e_j, g_i, c_bar_i] -> (beta, gamma)
        uncertainty_predictor: nn.Module taking DINO features -> sigma
        lambda_dssim: float, weight for DSSIM loss
        """
        self.gaussians = gaussians
        self.appearance_mlp = appearance_mlp
        self.uncertainty_predictor = uncertainty_predictor
        self.lambda_dssim = lambda_dssim

    def project_gaussian(self, gaussian, view_matrix, proj_matrix, image_width, image_height):
        """
        Projects a single 3D Gaussian to 2D screen space.
        Returns 2D mean mu_prime and 2D covariance Sigma_prime.
        """
        # 1. Project mean
        p_h = torch.cat([gaussian.p, torch.ones(1)], dim=0) # Homogeneous
        p_cam = view_matrix @ p_h
        p_proj = proj_matrix @ p_cam
        
        # Perspective division
        x = p_proj[0] / p_proj[2]
        y = p_proj[1] / p_proj[2]
        z = p_proj[2]
        
        mu_prime = torch.tensor([x, y])
        
        # 2. Project covariance
        # J is Jacobian of affine approximation of projection
        # W is view-projection matrix (simplified: combine view and proj for MVP)
        # Sigma_3d is 3x3 covariance
        # Sigma_2d = J * W * Sigma_3d * W^T * J^T
        # Note: In practice, J is derived from the projection matrix and depth.
        # For implementation, use standard 3DGS projection logic.
        J = compute_jacobian(proj_matrix, p_cam) 
        W = view_matrix # Simplified MVP assumption for notation
        Sigma_3d = gaussian.sigma
        Sigma_2d_full = J @ W @ Sigma_3d @ W.T @ J.T
        
        # Take top-left 2x2
        Sigma_prime = Sigma_2d_full[:2, :2]
        
        return mu_prime, Sigma_prime, z

    def render_image(self, gaussians, image_embedding, dino_features, ground_truth_image):
        """
        Renders an image and computes losses.
        """
        # 1. Project all Gaussians
        projected_gaussians = []
        for g in gaussians:
            mu_p, sigma_p, z = self.project_gaussian(g, ...) # Assume view/proj matrices available
            projected_gaussians.append({
                'mu': mu_p,
                'sigma': sigma_p,
                'z': z,
                'g': g.g,
                'sh_coeffs': g.sh_coeffs,
                'alpha': g.alpha
            })
        
        # 2. Sort front-to-back
        projected_gaussians.sort(key=lambda x: x['z'])
        
        # 3. Rasterize
        # Render two versions: toned (for L1) and un-toned (for DSSIM)
        # This requires a rasterizer that supports multiple color inputs or two passes.
        
        # Pass 1: Compute Toned Colors
        toned_colors = []
        untoned_colors = []
        
        for pg in projected_gaussians:
            # Get view direction r for each pixel (simplified: assume ray direction lookup)
            # In rasterization, this is done per-pixel. Here we simulate the logic.
            
            # Base color (0-th order SH)
            c_bar = get_base_color(pg['sh_coeffs'])
            
            # Appearance Modeling
            # Input: image_embedding, per-gaussian embedding, base color
            input_vec = torch.cat([image_embedding, pg['g'], c_bar])
            beta, gamma = self.appearance_mlp(input_vec)
            
            # View-dependent color
            c_view = get_view_dependent_color(pg['sh_coeffs'], r=...) # r depends on pixel
            
            # Toned color
            c_toned = gamma * c_view + beta
            
            toned_colors.append(c_toned)
            untoned_colors.append(c_view)
            
        # Rasterization Loop (Pseudocode for accumulation)
        # Initialize image buffers
        C_toned = torch.zeros(H, W, 3)
        C_untoned = torch.zeros(H, W, 3)
        Alpha_accum = torch.zeros(H, W, 1)
        
        for pg in projected_gaussians:
            mu = pg['mu']
            sigma_inv = torch.inverse(pg['sigma'])
            alpha_g = pg['alpha']
            
            # Determine pixels within bounding box of Gaussian
            pixels_in_bbox = get_pixels_in_bbox(mu, sigma)
            
            for (x, y) in pixels_in_bbox:
                dx = x - mu[0]
                dy = y - mu[1]
                dist_sq = torch.tensor([dx, dy]) @ sigma_inv @ torch.tensor([dx, dy])
                
                # Blending weight
                alpha_i = torch.exp(-0.5 * dist_sq)
                
                # Final alpha for this Gaussian
                alpha_final = alpha_i * alpha_g * (1 - Alpha_accum[y, x])
                
                # Update buffers
                C_toned[y, x] += alpha_final * toned_colors[pg.index]
                C_untoned[y, x] += alpha_final * untoned_colors[pg.index]
                Alpha_accum[y, x] += alpha_final
                
        # Normalize by accumulated alpha (standard alpha blending)
        # Note: Standard 3DGS rasterizer handles this internally.
        # Here we assume C_toned and C_untoned are the final composited colors.
        
        # 4. Compute Losses
        
        # Color Loss
        # L_color = lambda_dssim * DSSIM(C_untoned, C_gt) + (1 - lambda_dssim) * L1(C_toned, C_gt)
        loss_dssim = compute_dssim(C_untoned, ground_truth_image)
        loss_l1 = F.l1_loss(C_toned, ground_truth_image)
        loss_color = self.lambda_dssim * loss_dssim + (1 - self.lambda_dssim) * loss_l1
        
        # Uncertainty Loss
        # Predict uncertainty from DINO features
        sigma_pred = self.uncertainty_predictor(dino_features)
        sigma_pred = torch.clamp(sigma_pred, min=0.1)
        
        # Get DINO features for predicted image (or use ground truth features if available for training)
        # The paper uses DINO features of the training image to predict uncertainty,
        # then compares predicted uncertainty with DINO similarity between predicted and GT features?
        # Actually, Eq 9 uses DINO features of the *predicted* image patch vs *ground truth* patch?
        # "L_dino(D_tilde, D) ... D_tilde and D are DINO features of predicted and training image patches"
        # So we need DINO features of C_toned (or C_untoned? Paper says "predicted colors").
        # Let's assume we extract DINO features from the rendered image C_toned.
        dino_pred = extract_dino_features(C_toned)
        dino_gt = dino_features # Already extracted for the training image
        
        # DINO Cosine Loss
        # L_dino = min(1, 2 - 2 * (D_tilde . D) / (||D_tilde|| ||D||))
        dot_product = torch.sum(dino_pred * dino_gt, dim=1)
        norm_pred = torch.norm(dino_pred, dim=1)
        norm_gt = torch.norm(dino_gt, dim=1)
        cosine_sim = dot_product / (norm_pred * norm_gt + 1e-8)
        loss_dino = torch.clamp(1 - cosine_sim, min=0, max=1) # Simplified from min(1, 2-2*cos)
        
        # Uncertainty Loss with prior
        # L_unc = L_dino / (2 * sigma^2) + lambda_prior * log(sigma)
        lambda_prior = 1.0 # Example value
        loss_uncertainty = loss_dino / (2 * sigma_pred**2) + lambda_prior * torch.log(sigma_pred)
        
        # Masking for Color Loss (Optional, based on uncertainty)
        # M = 1 if 1/(2*sigma^2) > 1
        mask = (1 / (2 * sigma_pred**2) > 1).float()
        # Apply mask to loss_color if desired
        # loss_color_masked = mask * loss_color
        
        total_loss = loss_color + loss_uncertainty
        
        return total_loss, C_toned, C_untoned

    def test_time_optimize(self, new_image_embedding, gaussians, dino_features, ground_truth_image):
        """
        Optimizes only the new image embedding.
        """
        optimizer = torch.optim.Adam([new_image_embedding], lr=0.01)
        for i in range(100): # Example iterations
            optimizer.zero_grad()
            loss = self.render_image(gaussians, new_image_embedding, dino_features, ground_truth_image)
            loss.backward()
            optimizer.step()
        return new_image_embedding
```

### Parameters
*   $\lambda_{dssim}$: Weight for DSSIM loss in the training objective. Typical value: 0.2 [S1].
*   Fourier Feature Frequencies: $m=1, \dots, 4$ [S1].
*   Uncertainty Clip Minimum: 0.1 [S1].

### Edge Cases and Pitfalls
*   **Opacity Reset**: During training, Gaussian opacity is periodically reset to a small value to prevent local minima. This causes temporary corruption in renderings. Uncertainty training must be disabled for a few iterations after each reset to prevent corrupted renderings from propagating to the uncertainty predictor [S1].
*   **Sky Initialization**: Sky points must be handled separately using Fibonacci sphere sampling to ensure the background is modeled correctly [S1].
*   **Test-Time Embedding**: For unseen images, the per-image embedding must be initialized to zeros and optimized separately, keeping all other parameters fixed [S1].
*   **Speed Optimization**: If rendering speed is critical and the scene is rendered under a single static condition, affine parameters can be pre-computed per Gaussian and baked into the SH parameters, resulting in a standard 3DGS representation [S1].

## Operating characteristics

*   **Time Complexity**: Rendering is $O(N)$ per pixel where $N$ is the number of Gaussians, similar to standard 3DGS, but with additional overhead for the MLP evaluation per Gaussian and DINO feature extraction for uncertainty [S1]. Test-time optimization adds $O(I \cdot N)$ where $I$ is the number of optimization iterations for the new image embedding [S1].
*   **Memory Complexity**: Requires storing per-image embeddings ($N_{images} \times d_e$) and per-Gaussian embeddings ($N_{gaussians} \times d_g$) [S1].
*   **Performance**: WildGaussians significantly outperforms baseline methods on unconstrained datasets like Photo Tourism in terms of PSNR and SSIM, while maintaining fast rendering times comparable to 3DGS [S1].
*   **Strengths**: Handles large appearance variations (illumination, weather) and transient objects effectively. Robust to occluders via uncertainty modeling.
*   **Limitations**: Requires test-time optimization for new views, which is slower than standard 3DGS inference. Training is more complex due to the additional uncertainty and appearance modeling components [S1].

## Background

WildGaussians was introduced in the paper "WildGaussians: 3D Gaussian Splatting in the Wild" [S1]. It builds upon the 3D Gaussian Splatting method [14] and incorporates improvements from Mip-Splatting [50] and NeRF-W [24]. The method addresses the limitations of 3DGS in unconstrained environments where appearance changes are prevalent [S1].
