# Salient Subset Construction via Cumulative Histograms

Also called: Representative Subset Construction

## Overview
This method constructs representative sparse voxel subsets ($\Gamma$ and $\Lambda$) from a dense volume by thresholding scalar quantities using cumulative histograms, allowing precise control over the percentage of voxels included in the output [S1]. It solves the problem of reducing data size while preserving significant structural features, differing from its sibling [Salient Volume Representation](16378-salient-volume-representation.md) by relying on pre-computed scalar metrics (gradient magnitude or Hessian eigenvalues) rather than deriving the salience metric itself from second-order directional derivatives [S1].

## How it works
**Inputs:**
- A 3D volume dataset of dimensions $D_x \times D_y \times D_z$.
- A scalar field for each voxel, either the gradient magnitude $||\nabla||$ or the negative third eigenvalue $-\lambda_3$ of the Hessian matrix [S1].
- A target percentage $p$ (e.g., 0.05 for 5%) controlling the fraction of voxels to retain [S1].

**Outputs:**
- Two subsets of voxel indices: $\Gamma(p)$ selected based on $||\nabla||$ and $\Lambda(p)$ selected based on $-\lambda_3$ [S1].

**Data Structures:**
- **Histogram:** An array of bin counts. The number of bins is not explicitly defined in the sources [G: A power-of-two size sufficient to cover the range of the scalar field, e.g., 256 or 1024, is typical for efficient logarithmic search].
- **Cumulative Histogram:** An array where each entry stores the sum of counts from the first bin up to the current bin index.

**Steps:**
1. **Initialize Histograms:** Create two empty histograms, $H_{\nabla}$ for $||\nabla||$ and $H_{-\lambda_3}$ for $-\lambda_3$.
2. **Compute Scalar Fields:** For each voxel in the volume, compute $||\nabla||$ and the eigenvalues $(\lambda_1, \lambda_2, \lambda_3)$ of the Hessian matrix to derive $-\lambda_3$ [S1]. Note that computing eigenvalues is approximately 2.7 times more expensive than computing gradient magnitude [S1].
3. **Populate Histograms:** Perform one pass through the volume. For each voxel, determine the bin index corresponding to its $||\nabla||$ and $-\lambda_3$ values, and increment the respective bin counts in $H_{\nabla}$ and $H_{-\lambda_3}$ [S1].
4. **Compute Cumulative Histograms:** Transform $H_{\nabla}$ and $H_{-\lambda_3}$ into cumulative histograms $C_{\nabla}$ and $C_{-\lambda_3}$ where $C[i] = \sum_{j=0}^{i} H[j]$ [S1].
5. **Determine Target Count:** Calculate the target number of voxels $N_{target} = p \times (D_x \times D_y \times D_z)$ [S1].
6. **Find Threshold via Logarithmic Search:** Perform a binary search (logarithmic search) on the cumulative histogram array to find the bin index $k$ such that $C[k-1] < N_{target} \le C[k]$ [S1]. The bin index $k$ (or the upper bound of the bin range) serves as the threshold value [S1].
7. **Select Voxels:** Iterate through the volume again. Include a voxel in $\Gamma$ if its $||\nabla||$ value corresponds to a bin index $\ge k_{\nabla}$, and include it in $\Lambda$ if its $-\lambda_3$ value corresponds to a bin index $\ge k_{-\lambda_3}$ [S1].

**Pseudocode:**
```python
def construct_salient_subsets(volume, gradient_field, hessian_eigenvalues, percentage_p):
    """
    volume: 3D array of shape (Dx, Dy, Dz)
    gradient_field: 3D array of ||grad|| values
    hessian_eigenvalues: 3D array of -lambda3 values
    percentage_p: float, fraction of voxels to keep (0.0 to 1.0)
    """
    Dx, Dy, Dz = volume.shape
    total_voxels = Dx * Dy * Dz
    target_count = int(percentage_p * total_voxels)
    
    # Assume bin_count is a power of 2, e.g., 256
    bin_count = 256 
    max_grad = max(gradient_field.flatten())
    max_eig = max(hessian_eigenvalues.flatten())
    
    # Initialize histograms
    hist_grad = [0] * bin_count
    hist_eig = [0] * bin_count
    
    # Pass 1: Build histograms
    for x in range(Dx):
        for y in range(Dy):
            for z in range(Dz):
                g_val = gradient_field[x, y, z]
                e_val = hessian_eigenvalues[x, y, z]
                
                # Map values to bin indices
                bin_g = int((g_val / max_grad) * bin_count) if max_grad > 0 else 0
                bin_e = int((e_val / max_eig) * bin_count) if max_eig > 0 else 0
                
                # Clamp to valid range
                bin_g = min(bin_g, bin_count - 1)
                bin_e = min(bin_e, bin_count - 1)
                
                hist_grad[bin_g] += 1
                hist_eig[bin_e] += 1
                
    # Compute cumulative histograms
    cum_grad = [0] * bin_count
    cum_eig = [0] * bin_count
    
    cum_grad[0] = hist_grad[0]
    cum_eig[0] = hist_eig[0]
    
    for i in range(1, bin_count):
        cum_grad[i] = cum_grad[i-1] + hist_grad[i]
        cum_eig[i] = cum_eig[i-1] + hist_eig[i]
        
    # Binary search for threshold bins
    # Find smallest index k such that cum[k] >= target_count
    def find_threshold_bin(cumulative_hist, target):
        low = 0
        high = bin_count - 1
        result = high
        
        while low <= high:
            mid = (low + high) // 2
            if cumulative_hist[mid] >= target:
                result = mid
                high = mid - 1
            else:
                low = mid + 1
        return result

    threshold_bin_grad = find_threshold_bin(cum_grad, target_count)
    threshold_bin_eig = find_threshold_bin(cum_eig, target_count)
    
    # Determine threshold values (using the upper bound of the bin)
    # Note: The source says "indices of bins correspond to a threshold"
    # We use the bin index itself as the decision criterion for selection
    # Voxels in bins >= threshold_bin are selected
    
    subset_gamma = []
    subset_lambda = []
    
    # Pass 2: Select voxels
    for x in range(Dx):
        for y in range(Dy):
            for z in range(Dz):
                g_val = gradient_field[x, y, z]
                e_val = hessian_eigenvalues[x, y, z]
                
                bin_g = int((g_val / max_grad) * bin_count) if max_grad > 0 else 0
                bin_e = int((e_val / max_eig) * bin_count) if max_eig > 0 else 0
                bin_g = min(bin_g, bin_count - 1)
                bin_e = min(bin_e, bin_count - 1)
                
                if bin_g >= threshold_bin_grad:
                    subset_gamma.append((x, y, z))
                if bin_e >= threshold_bin_eig:
                    subset_lambda.append((x, y, z))
                    
    return subset_gamma, subset_lambda
```

**Edge Cases and Pitfalls:**
- **Zero Values:** If `max_grad` or `max_eig` is zero, division by zero occurs. Guard against this by checking for zero max values [G].
- **Bin Mapping:** The exact mapping from scalar value to bin index must be consistent between histogram construction and voxel selection [G].
- **Precision:** Floating-point precision in eigenvalue computation can affect the distribution of $-\lambda_3$ values, potentially skewing the histogram [S1].

## Subtopics

### [Salient Volume Representation](16378-salient-volume-representation.md)
Defines the salience metric using the smallest eigenvalue of the Hessian matrix to identify boundaries and narrow structures. Choose this when shape information from second-order derivatives is more critical than simple gradient magnitude. It differs from this method by computing the metric itself rather than thresholding pre-computed quantities.

## Operating characteristics
- **Time Complexity:** Linear time $O(N)$ for histogram construction and voxel selection, where $N$ is the number of voxels. The logarithmic search for the threshold is $O(\log B)$, where $B$ is the number of bins [S1].
- **Memory Complexity:** $O(B)$ for the histograms, where $B$ is the number of bins. The output subsets require $O(N \cdot p)$ space [S1].
- **Performance:** On a Pentium III 800 MHz, computing gradient magnitude takes significantly less time than computing Hessian eigenvalues. The eigenvalue computation is, on average, 2.7 times more expensive than gradient magnitude computation [S1].
- **Strengths:** Allows precise control over the number of voxels included via the percentage parameter $p$. Efficient linear-time construction [S1].
- **Limitations:** Requires two passes through the volume (one for histograms, one for selection). The quality of the subset depends on the choice of scalar field ($||\nabla||$ vs $-\lambda_3$) and the binning strategy [S1].

## Background
This method was introduced in the paper "Salient Representation of Volume Data" (2001) as a technique for constructing representative subsets of volume data [S1]. It is part of the broader field of sparse volume data representation, aiming to reduce storage and rendering costs while preserving visual salience [S1].
