# Salient Subset Construction via Cumulative Histograms

Also called: Representative Subset Construction

## Overview
This method constructs representative sparse voxel subsets ($\Gamma$ and $\Lambda$) from a dense volume by thresholding scalar quantities (gradient magnitude and negative third eigenvalue) using cumulative histograms [S1]. It solves the problem of selecting a controlled percentage of significant voxels for sparse rendering or compression [S1]. It distinguishes itself from sibling methods like [Salient Volume Representation](16378-salient-volume-representation.md) by relying on histogram-based thresholding for subset selection rather than defining the salience metric directly via second-order directional derivatives [G].

## How it works
**Inputs:**
- A 3D volume dataset $V$ of dimensions $D_x \times D_y \times D_z$ [G].
- A target percentage $p \in [0, 1]$ controlling the fraction of voxels to include in the subset [S1].
- Precomputed scalar fields for gradient magnitude $g(v) = ||\nabla V(v)||$ and negative third eigenvalue $e(v) = -\lambda_3(v)$ for every voxel $v$ [S1].

**Outputs:**
- Two sparse subsets: $\Gamma$ (selected by gradient magnitude) and $\Lambda$ (selected by negative third eigenvalue) [S1].
- Threshold values $T_\Gamma$ and $T_\Lambda$ derived from the histograms [S1].

**Data Structures:**
- **Cumulative Histograms:** Two arrays, $H_\Gamma$ and $H_\Lambda$, storing the cumulative count of voxels up to each bin index [S1]. The number of bins $B$ is not explicitly specified in the sources [G].
- **Subset Indices:** Lists or bitmasks storing the coordinates of voxels satisfying the threshold condition [G].

**Steps:**
1. **Compute Scalar Fields:** For every voxel $v$ in $V$, compute the gradient magnitude $g(v)$ and the negative third eigenvalue $e(v)$ [S1].
2. **Construct Cumulative Histograms:** Perform one pass through all voxels in $V$ to populate histogram bins for $g(v)$ and $e(v)$, then compute cumulative sums for both histograms [S1]. This step runs in linear time $O(N)$ relative to the number of voxels $N$ [S1].
3. **Determine Target Voxel Count:** Calculate the target number of voxels $K$ for each subset using the formula $K = \lceil p \times N \rceil$ [G].
4. **Find Threshold via Logarithmic Search:** Perform a binary search on the cumulative histogram to find the bin index $B$ such that $H[B-1] < K \le H[B]$ [S1].
5. **Select Voxels:** Use the found bin index $B$ as the threshold $T$ [S1]. For each voxel $v$, if its bin index is greater than or equal to $T$, add $v$ to the respective subset [S1].

**Pseudocode:**
```python
def salient_subset_construction(grad_mag, neg_eig, percentage_p, num_bins):
    """
    grad_mag: 3D array of shape (Dx, Dy, Dz) containing gradient magnitudes.
    neg_eig: 3D array of shape (Dx, Dy, Dz) containing negative third eigenvalues.
    percentage_p: float between 0 and 1.
    num_bins: int, number of histogram bins.
    Returns: subset_gamma, subset_lambda, threshold_gamma, threshold_lambda.
    """
    Dx, Dy, Dz = grad_mag.shape
    N = Dx * Dy * Dz
    target_count = int(percentage_p * N)
    
    # Initialize histograms
    hist_gamma = [0] * num_bins
    hist_lambda = [0] * num_bins
    
    # One pass to build histograms
    for x in range(Dx):
        for y in range(Dy):
            for z in range(Dz):
                # Binning assumes values are normalized to [0, 1) [G]
                bin_g = max(0, min(num_bins - 1, int(grad_mag[x, y, z] * num_bins)))
                bin_e = max(0, min(num_bins - 1, int(neg_eig[x, y, z] * num_bins)))
                hist_gamma[bin_g] += 1
                hist_lambda[bin_e] += 1
                
    # Cumulative sums
    cum_gamma = [0] * num_bins
    cum_lambda = [0] * num_bins
    cum_gamma[0] = hist_gamma[0]
    cum_lambda[0] = hist_lambda[0]
    for i in range(1, num_bins):
        cum_gamma[i] = cum_gamma[i-1] + hist_gamma[i]
        cum_lambda[i] = cum_lambda[i-1] + hist_lambda[i]
        
    # Logarithmic search for threshold bin index
    def find_threshold_bin(cum_hist, target):
        low, high = 0, num_bins - 1
        while low < high:
            mid = (low + high) // 2
            if cum_hist[mid] < target:
                low = mid + 1
            else:
                high = mid
        return low
        
    threshold_gamma = find_threshold_bin(cum_gamma, target_count)
    threshold_lambda = find_threshold_bin(cum_lambda, target_count)
    
    # Select voxels
    subset_gamma = []
    subset_lambda = []
    for x in range(Dx):
        for y in range(Dy):
            for z in range(Dz):
                bin_g = max(0, min(num_bins - 1, int(grad_mag[x, y, z] * num_bins)))
                bin_e = max(0, min(num_bins - 1, int(neg_eig[x, y, z] * num_bins)))
                if bin_g >= threshold_gamma:
                    subset_gamma.append((x, y, z))
                if bin_e >= threshold_lambda:
                    subset_lambda.append((x, y, z))
                    
    return subset_gamma, subset_lambda, threshold_gamma, threshold_lambda
```

**Edge Cases and Pitfalls:**
- **Precision:** The binning process loses precision. The threshold is discrete, so the actual percentage of voxels included may slightly deviate from $p$ [G].
- **Degenerate Input:** If the volume has constant values, histograms will have a single non-zero bin, potentially leading to all voxels being included or excluded depending on $p$ [G].
- **Boundary Conditions:** Gradient and eigenvalue computations at volume boundaries require careful handling (e.g., zero-padding or reflection) [G].

## Subtopics

### [Salient Volume Representation](16378-salient-volume-representation.md)
Defines salience via the smallest eigenvalue of the Hessian, selecting voxels based on second-order derivatives. Choose this when shape fidelity of boundaries is critical. Differs from this method by not using cumulative histograms for subset selection [G].

## Operating characteristics
- **Time Complexity:** $O(N)$ for histogram construction, where $N$ is the number of voxels [S1]. The eigenvalue computation is significantly more expensive than gradient magnitude; sources report eigenvalue computation is on average 2.7 times more expensive than gradient magnitude computation on a Pentium III 800 MHz [S1].
- **Memory Complexity:** $O(N)$ to store the volume and intermediate scalar fields [G]. Histograms require $O(B)$ space, where $B$ is the number of bins [G].
- **Performance:** Measured on datasets like CT Head (128x128x113) and MRI Head (256x256x109). Gradient magnitude computation ranges from 3.37 to 111.96 seconds, while eigenvalue computation ranges from 6.30 to 275.45 seconds on the specified hardware [S1].
- **Strengths:** Linear time construction of subsets; control over subset size via $p$ [S1].
- **Limitations:** High computational cost of eigenvalue calculation; discrete thresholding may not yield exact percentage $p$ [G].

## Background
Originated in the paper "Salient Representation of Volume Data" (2001) [S1]. The method is part of a broader effort to create efficient sparse representations for volume rendering, leveraging the fact that significant structural information is concentrated in a small subset of voxels [S1].
