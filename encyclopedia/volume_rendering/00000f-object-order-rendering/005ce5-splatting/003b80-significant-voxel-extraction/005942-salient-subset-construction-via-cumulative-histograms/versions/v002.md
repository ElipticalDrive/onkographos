# Salient Subset Construction via Cumulative Histograms

Also called: Representative Subset Construction

## Overview
This method constructs representative sparse voxel subsets ($\Gamma$ and $\Lambda$) from a dense volume by thresholding scalar quantities (gradient magnitude and negative third eigenvalue) using cumulative histograms [S1]. It solves the problem of selecting a controlled percentage of significant voxels for sparse rendering or compression, distinguishing itself from sibling methods like [Salient Volume Representation](16378-salient-volume-representation.md) by relying on histogram-based thresholding rather than direct eigenvalue magnitude comparison for subset definition [S1].

## How it works
**Inputs:**
- A 3D volume dataset $V$ of dimensions $D_x \times D_y \times D_z$.
- A target percentage $p \in [0, 1]$ controlling the fraction of voxels to include in the subset [S1].

**Outputs:**
- Two sparse subsets: $\Gamma$ (selected by gradient magnitude) and $\Lambda$ (selected by negative third eigenvalue) [S1].
- Threshold values $T_\Gamma$ and $T_\Lambda$ derived from the histograms [S1].

**Data Structures:**
- **Cumulative Histograms:** Two arrays, $H_\Gamma$ and $H_\Lambda$, storing the cumulative count of voxels up to each bin index. The number of bins is not explicitly specified in the sources [G: Typically determined by the range and resolution of the scalar field, e.g., 256 bins for 8-bit normalized data].
- **Subset Indices:** Lists or bitmasks storing the coordinates of voxels satisfying the threshold condition [G: Standard sparse storage format].

**Steps:**
1. **Compute Scalar Fields:**
   For every voxel $v$ in $V$, compute:
   - Gradient magnitude: $g(v) = ||\nabla V(v)||$ [S1].
   - Negative third eigenvalue: $e(v) = -\lambda_3(v)$, where $\lambda_3$ is the smallest eigenvalue of the Hessian matrix of $V$ at $v$ [S1]. Note: $\lambda_3$ is typically the most negative eigenvalue for edges/surfaces, so $-\lambda_3$ is positive [S1].

2. **Construct Cumulative Histograms:**
   - Initialize empty histograms $H_\Gamma$ and $H_\Lambda$.
   - Perform one pass through all voxels in $V$ [S1]:
     - Bin $g(v)$ into $H_\Gamma$ and increment the count.
     - Bin $e(v)$ into $H_\Lambda$ and increment the count.
   - Compute cumulative sums for both histograms:
     $$ H_\Gamma[i] = \sum_{j=0}^{i} \text{count}_\Gamma(j) $$
     $$ H_\Lambda[i] = \sum_{j=0}^{i} \text{count}_\Lambda(j) $$
   - This step runs in linear time $O(N)$ relative to the number of voxels $N$ [S1].

3. **Determine Target Voxel Count:**
   - Calculate the target number of voxels $K$ for each subset:
     $$ K = \lceil p \times N \rceil $$
     where $N = D_x \times D_y \times D_z$ [S1].

4. **Find Threshold via Logarithmic Search:**
   - For each histogram ($H_\Gamma$ and $H_\Lambda$), perform a binary search (logarithmic time) to find the bin index $B$ such that:
     $$ H[B-1] < K \le H[B] $$
   - The bin index $B$ (or the bin boundary value corresponding to $B$) serves as the threshold $T$ [S1]. The sources state "The indices of bins correspond to a threshold," implying the bin index itself or the upper bound of that bin is used as the decision value [S1].

5. **Select Voxels:**
   - For each voxel $v$:
     - If $g(v) \ge T_\Gamma$, add $v$ to subset $\Gamma$.
     - If $e(v) \ge T_\Lambda$, add $v$ to subset $\Lambda$ [S1].

**Pseudocode:**
```python
def salient_subset_construction(volume, percentage_p):
    """
    volume: 3D array of shape (Dx, Dy, Dz)
    percentage_p: float between 0 and 1
    Returns: subset_gamma, subset_lambda, threshold_gamma, threshold_lambda
    """
    Dx, Dy, Dz = volume.shape
    N = Dx * Dy * Dz
    target_count = int(percentage_p * N)
    
    # Step 1: Compute scalar fields
    # Note: Gradient magnitude and Hessian eigenvalues must be computed first.
    # This is assumed to be done by a helper function not detailed here.
    gradient_magnitude = compute_gradient_magnitude(volume)
    negative_eigenvalue = compute_negative_third_eigenvalue(volume)
    
    # Step 2: Construct cumulative histograms
    # Assuming scalar values are normalized to [0, 1] and binned into 256 bins.
    num_bins = 256
    hist_gamma = np.zeros(num_bins)
    hist_lambda = np.zeros(num_bins)
    
    for x in range(Dx):
        for y in range(Dy):
            for z in range(Dz):
                g_val = gradient_magnitude[x, y, z]
                e_val = negative_eigenvalue[x, y, z]
                
                # Bin values (clamp to [0, num_bins-1])
                bin_g = int(g_val * num_bins)
                bin_e = int(e_val * num_bins)
                
                hist_gamma[bin_g] += 1
                hist_lambda[bin_e] += 1
                
    # Cumulative sums
    cum_gamma = np.cumsum(hist_gamma)
    cum_lambda = np.cumsum(hist_lambda)
    
    # Step 4: Find thresholds via binary search
    # Find smallest index i such that cum[i] >= target_count
    threshold_idx_gamma = np.searchsorted(cum_gamma, target_count)
    threshold_idx_lambda = np.searchsorted(cum_lambda, target_count)
    
    # The threshold value is the bin index (or corresponding scalar value)
    # Sources say "indices of bins correspond to a threshold"
    threshold_gamma = threshold_idx_gamma
    threshold_lambda = threshold_idx_lambda
    
    # Step 5: Select voxels
    subset_gamma = []
    subset_lambda = []
    
    for x in range(Dx):
        for y in range(Dy):
            for z in range(Dz):
                g_val = gradient_magnitude[x, y, z]
                e_val = negative_eigenvalue[x, y, z]
                
                bin_g = int(g_val * num_bins)
                bin_e = int(e_val * num_bins)
                
                if bin_g >= threshold_gamma:
                    subset_gamma.append((x, y, z))
                if bin_e >= threshold_lambda:
                    subset_lambda.append((x, y, z))
                    
    return subset_gamma, subset_lambda, threshold_gamma, threshold_lambda
```

**Edge Cases and Pitfalls:**
- **Precision:** The binning process loses precision. The threshold is discrete, so the actual percentage of voxels included may slightly deviate from $p$ [S1].
- **Degenerate Input:** If the volume has constant values, histograms will have a single non-zero bin, potentially leading to all voxels being included or excluded depending on $p$ [G].
- **Boundary Conditions:** Gradient and eigenvalue computations at volume boundaries require careful handling (e.g., zero-padding or reflection) [G].

## Subtopics

### [Salient Volume Representation](16378-salient-volume-representation.md)
Defines salience via the smallest eigenvalue of the Hessian, selecting voxels based on second-order derivatives. Choose this when shape fidelity of boundaries is critical. Differs from this method by not using cumulative histograms for subset selection.

## Operating characteristics
- **Time Complexity:** $O(N)$ for histogram construction, where $N$ is the number of voxels. The eigenvalue computation is significantly more expensive than gradient magnitude; sources report eigenvalue computation is on average 2.7 times more expensive than gradient magnitude computation on a Pentium III 800 MHz [S1].
- **Memory Complexity:** $O(N)$ to store the volume and intermediate scalar fields. Histograms require $O(B)$ space, where $B$ is the number of bins [S1].
- **Performance:** Measured on datasets like CT Head (128x128x113) and MRI Head (256x256x109). Gradient magnitude computation took ~50-75 seconds, while eigenvalue computation took ~140-275 seconds on the specified hardware [S1].
- **Strengths:** Linear time construction of subsets; control over subset size via $p$ [S1].
- **Limitations:** High computational cost of eigenvalue calculation; discrete thresholding may not yield exact percentage $p$ [S1].

## Background
Originated in the paper "Salient Representation of Volume Data" (2001) [S1]. The method is part of a broader effort to create efficient sparse representations for volume rendering, leveraging the fact that significant structural information is concentrated in a small subset of voxels [S1].
