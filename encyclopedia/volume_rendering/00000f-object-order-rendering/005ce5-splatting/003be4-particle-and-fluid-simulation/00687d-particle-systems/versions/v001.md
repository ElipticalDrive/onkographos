# Particle Systems
Also called: Steam rendering via particles
## Overview
Particle systems model natural phenomena by generating thousands of discrete particles to simulate change over time, rather than displaying the entire volumetric dataset [S1, unofficial]. Unlike volume or surface generation techniques that render all data, this method represents objects as clouds of primitive particles occupying their volumes, allowing for the simulation of dynamic effects like advection and diffusion [S1, unofficial].
## How it works
**Inputs and Outputs:**
*   **Inputs:** User-defined particle characteristics (color, initial velocity, lifetime), simulation parameters, and initial seed data [S1, unofficial].
*   **Outputs:** A sequence of rendered frames depicting the dynamic phenomenon [S1, unofficial].

**Data Structures:**
Each particle $i$ is defined by:
*   Position $\mathbf{p}_i$
*   Velocity $\mathbf{v}_i$
*   Optical properties (color $\mathbf{c}_i$, opacity $\alpha_i$, radius $r_i$) [S1, unofficial][S2, unofficial].
*   Lifetime $t_i$ [S1, unofficial].

**Steps:**
1.  **Initialization:** The user defines inherent characteristics of the particle, such as color, initial velocity, and lifetime [S1, unofficial].
2.  **Generation:** The algorithm uses these characteristics to generate thousands of particles [S1, unofficial].
3.  **Simulation:** Particle positions and properties are updated over time to simulate the change of natural phenomena [S1, unofficial]. For steam, this involves simulating advection and diffusion [S2, unofficial].
4.  **Rendering:** Each 3D model or phenomenon component is represented as a particle with its own position, velocity, and optical properties [S2, unofficial]. These particles are rendered to form the visual output [S1, unofficial].

**Pseudocode:**
```python
def particle_system_simulation(initial_conditions, time_step, num_particles):
    # Initialize particles based on user-defined characteristics
    particles = []
    for i in range(num_particles):
        p = {
            'position': initial_conditions['initial_position'],
            'velocity': initial_conditions['initial_velocity'],
            'color': initial_conditions['color'],
            'lifetime': initial_conditions['lifetime'],
            'age': 0
        }
        particles.append(p)
    
    # Simulation loop
    for t in range(time_steps):
        for p in particles:
            # Update position and velocity based on physics (e.g., advection)
            p['velocity'] = update_velocity(p['velocity'], t)
            p['position'] = p['position'] + p['velocity'] * time_step
            
            # Update age and check lifetime
            p['age'] += time_step
            if p['age'] > p['lifetime']:
                # Respawn or remove particle
                respawn_or_remove(p, initial_conditions)
        
        # Render current frame
        render_particles(particles)
```

**Edge Cases:**
*   **Precision:** Floating-point precision may affect particle accumulation over long lifetimes [G].
*   **Performance:** Rendering thousands of particles requires efficient culling and batching [G].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of particles $N$ for simulation and rendering $O(N)$ [G].
*   **Memory Complexity:** Linear with respect to the number of particles $O(N)$ [G].
*   **Strengths:** Efficient for simulating dynamic, transient phenomena like fire, smoke, and steam [S1, unofficial]. Allows for interactive frame rates with GPU acceleration [S2, unofficial].
*   **Limitations:** Application-specific renderers are often required [S1, unofficial]. Does not inherently preserve volumetric density information as accurately as grid-based methods [S1, unofficial].
*   **When to use:** When simulating natural phenomena like steam, fire, or terrain features where individual particle dynamics are important [S1, unofficial].
*   **When not to use:** When precise volumetric data representation is required for the entire dataset [S1, unofficial].

## Background
Particle systems were introduced as a technique to model pieces of natural phenomena by generating thousands of particles to simulate change over time [S1, unofficial]. Early applications include stochastic modeling for terrain by Fournier, Fussell, and Carpenter, and probabilistic algorithms for trees and grass by Reeves and Blau in *The Adventures of Andre and Wally B.* [S1, unofficial]. Reeves and Blau also used these techniques to model dynamic environments like fire in *Star Trek II* [S1, unofficial]. The method has been applied to volumetric RCS data rendering [S1, unofficial] and steam rendering via particle systems [S2, unofficial].
