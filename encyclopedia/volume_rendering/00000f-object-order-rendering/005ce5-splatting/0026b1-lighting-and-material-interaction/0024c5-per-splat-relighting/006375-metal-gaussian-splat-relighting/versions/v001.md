# Metal Gaussian Splat Relighting

Also called: MetalSplatter, Ref-Gaussian Relighting

## Overview
Metal Gaussian Splat Relighting is a real-time, GPU-accelerated method for rendering Gaussian Splatting scenes with physically based rendering (PBR) materials and dynamic indirect lighting. It solves the limitation of standard 3D Gaussian Splatting, which relies on spherical harmonics (SH) for view-dependent color but lacks material definitions for realistic light interaction. By integrating PBR shading and Ambient Sphere Gaussians (ASG) for indirect illumination, this method enables dynamic relighting of splat clouds. It distinguishes itself from sibling methods like [Soft-Lit Sphere Sprite Generator](21588-soft-lit-sphere-sprite-generator.md) by using explicit material properties and environment maps rather than pre-computed sprite lighting.

## How it works

### Inputs and Outputs
**Inputs:**
- Splat data: Position, covariance (or 2DGS surfel geometry), SH coefficients, and optional PBR material properties (albedo, roughness, metallic, normal).
- Lighting data: Environment map (prefiltered for indirect lighting), irradiance environment map, BRDF LUT, and camera position.
- Relighting configuration: Flags for enabling/disabling relighting, SH degree, and material buffer availability.

**Outputs:**
- Final color buffer: Linear HDR RGB with alpha, ready for presentation (tonemapping/exposure handled in a separate post-process pass).

### Data Structures

**ChunkedSplatIndex**
Identifies a specific splat within a chunk. Total size: 8 bytes.
- `chunkIndex`: `UInt16` (2 bytes). Index of the chunk in the chunk array.
- `_padding`: `UInt16` (2 bytes). Reserved for alignment.
- `splatIndex`: `UInt32` (4 bytes). Index of the splat within the chunk's splat array.

**SplatChunk**
Contains batches of splats and their associated data.
- `splats`: Array of splat structures.
- `materials`: Optional pointer to an array of `SplatMaterial` structures. If `nullptr`, standard 3DGS SH color is used.
- `shCoefficients`: Buffer for higher-order SH coefficients.
- `shDegree`: Integer indicating the SH degree (0, 1, 2, or 3).
- `enabled`: Boolean flag. If false, the chunk is skipped.
- `splatCount`: Number of valid splats in the chunk.

**SplatMaterial**
Defines PBR properties for a splat.
- `albedo`: `float3` (RGB). Base color.
- `roughness`: `float`. Surface roughness (0.0 to 1.0).
- `metallic`: `float`. Metalness factor (0.0 to 1.0).
- `normal`: `float3`. Surface normal (normalized).

**Splat**
Basic geometric and radiometric data.
- `position`: `float3`. Center of the Gaussian.
- `shCoefficients`: Array of coefficients for view-dependent color.
- `color`: `float4` (RGBA). Base color and opacity (used if SH degree is 0).

### Numbered Steps

1.  **Vertex Shader: Splat Identification and Validation**
    - Calculate `splatID` from `instanceID`, `uniforms.indexedSplatCount`, and `vertexID`.
    - If `splatID >= uniforms.splatCount`, return a fragment with position `(1, 1, 0, 1)` to discard.
    - Retrieve `ChunkedSplatIndex` from `splatIndexArray` using `splatID`.
    - If `idx.chunkIndex >= uniforms.chunkCount`, return discard position.
    - Retrieve `ChunkInfo` for `idx.chunkIndex`.
    - If `idx.splatIndex >= chunk.splatCount`, return discard position.
    - If `chunk.enabled` is false, return discard position.

2.  **Vertex Shader: Data Retrieval and SH Evaluation**
    - Retrieve the `Splat` from `chunk.splats[idx.splatIndex]`.
    - Call `splatVertex` with the splat, uniforms, `vertexID % 4`, `chunk.shCoefficients`, `chunk.shDegree`, and `idx.splatIndex` to compute `FragmentIn`. This step evaluates the SH coefficients to determine the base color and opacity at the fragment's relative position.

3.  **Vertex Shader: PBR Relighting (Conditional)**
    - If `relight.enabled != 0` and `chunk.materials != nullptr`:
        - Retrieve `SplatMaterial` from `chunk.materials[idx.splatIndex]`.
        - Call `shadePBR` with `out.color.rgb`, `material`, `splat.position`, `uniforms.cameraPosition`, `relight`, `prefilteredEnv`, `irradianceEnv`, `brdfLUT`, and `iblSampler`.
        - This updates `out.color.rgb` with the result of the PBR shading calculation, including direct and indirect lighting.

4.  **Fragment Shader: Alpha Compositing**
    - Calculate `alpha` using `splatFragmentAlpha` with `in.relativePosition` and `in.color.a`.
    - Return `half4(alpha * in.color.rgb, alpha)`.

### Formulas and Parameters

**Spherical Harmonics (SH) Coefficients**
The number of coefficients depends on the SH degree. Values are stored as `Float16`.
- **SH Degree 0:** 1 coefficient (3 RGB channels). Total: 3 values.
- **SH Degree 1:** 4 coefficients (3 RGB channels). Total: 12 values. (Note: Source [S1, unofficial] lists 9 values for Degree 1, which implies 3 coefficients × 3 RGB. Standard SH Degree 1 has 4 coefficients (l=0,1). The source note "9 Float16 values per splat (3 coefficients × 3 RGB)" suggests a specific implementation detail or a typo in the source's coefficient count vs. value count. We follow the source's explicit value count: 9 values for Degree 1, 24 for Degree 2, 45 for Degree 3).
    - *Correction based on Source [S1, unofficial]:*
        - SH Degree 1: 9 Float16 values per splat (3 coefficients × 3 RGB).
        - SH Degree 2: 24 Float16 values per splat (8 coefficients × 3 RGB, cumulative).
        - SH Degree 3: 45 Float16 values per splat (15 coefficients × 3 RGB, cumulative).
- **ASG Coefficients:** 160 Float16 values per splat (32 lobes × 5 channels, lobe-major). Approx. 320 bytes/splat.

**Normal Orientation for 2DGS/Ref-Gaussian**
For 2DGS surfels, normals are sign-ambiguous because disks are two-sided. To prevent noise in shading:
1.  Compute the centroid of all splat positions in the chunk.
2.  For each splat, calculate the dot product of its normal and the vector from the centroid to the splat position: $d = \mathbf{n} \cdot (\mathbf{p} - \mathbf{c})$.
3.  If $d < 0$, flip the normal sign: $\mathbf{n} = -\mathbf{n}$.

### Pseudocode

```python
# Metal Gaussian Splat Relighting - Vertex and Fragment Shader Logic

def vertex_shader(instance_id, vertex_id, uniforms, splat_index_array, chunk_array):
    # Step 1: Splat Identification
    splat_id = compute_splat_id(instance_id, uniforms.indexed_splat_count, vertex_id)
    if splat_id >= uniforms.splat_count:
        return discard_fragment(position=(1, 1, 0, 1))

    # Retrieve ChunkedSplatIndex
    chunked_idx = splat_index_array[splat_id]
    if chunked_idx.chunk_index >= uniforms.chunk_count:
        return discard_fragment()

    # Retrieve ChunkInfo
    chunk = chunk_array[chunked_idx.chunk_index]
    if chunked_idx.splat_index >= chunk.splat_count:
        return discard_fragment()
    if not chunk.enabled:
        return discard_fragment()

    # Step 2: Data Retrieval and SH Evaluation
    splat = chunk.splats[chunked_idx.splat_index]
    fragment_in = splat_vertex(
        splat=splat,
        uniforms=uniforms,
        vertex_offset=vertex_id % 4,
        sh_coefficients=chunk.sh_coefficients,
        sh_degree=chunk.sh_degree,
        splat_index=chunked_idx.splat_index
    )

    # Step 3: PBR Relighting
    if uniforms.relight_enabled and chunk.materials is not None:
        material = chunk.materials[chunked_idx.splat_index]
        # Ensure normal is oriented outward for 2DGS
        if chunk.sh_degree > 0: # Assuming this flag indicates 2DGS/Ref-Gaussian mode
            material.normal = orient_normal(material.normal, splat.position, chunk.centroid)
        
        shade_pbr(
            out_color=fragment_in.color.rgb,
            material=material,
            splat_position=splat.position,
            camera_position=uniforms.camera_position,
            relight=uniforms.relight,
            prefiltered_env=uniforms.prefiltered_env,
            irradiance_env=uniforms.irradiance_env,
            brdf_lut=uniforms.brdf_lut,
            ibl_sampler=uniforms.ibl_sampler
        )

    return fragment_in

def fragment_shader(fragment_in):
    # Step 4: Alpha Compositing
    alpha = splat_fragment_alpha(fragment_in.relative_position, fragment_in.color.a)
    return half4(alpha * fragment_in.color.rgb, alpha)

def orient_normal(normal, position, centroid):
    """
    Orient normal outward from the cloud centroid.
    """
    to_centroid = centroid - position
    if dot(normal, to_centroid) < 0:
        return -normal
    return normal

def shade_pbr(out_color, material, position, camera_position, relight, prefiltered_env, irradiance_env, brdf_lut, ibl_sampler):
    """
    Computes PBR shading with indirect lighting.
    """
    # Calculate direct lighting (if any) and indirect lighting from environment
    # Indirect lighting uses prefiltered_env and irradiance_env
    indirect_lighting = compute_indirect_lighting(
        material.normal,
        material.roughness,
        material.metallic,
        prefiltered_env,
        irradiance_env,
        brdf_lut,
        ibl_sampler
    )
    
    # Combine with base color
    out_color = material.albedo * indirect_lighting
    # Note: Direct lighting might be added here if relight includes direct lights
    # out_color += direct_lighting * material.albedo
```

### Edge Cases and Pitfalls

-   **2DGS Normal Ambiguity:** 2DGS surfels have sign-ambiguous normals because disks are two-sided. If not corrected, normals point randomly inward/outward, causing noise in shading. Solution: Orient normals consistently outward from the cloud centroid.
-   **Missing ASG Coefficients:** Missing ASG coefficients in a chunk can cause unbounded reflections in the shader (e.g., `exp(ep - 3)`). Solution: Fill missing ASG data with zeros.
-   **Precision:** SH coefficients are stored as `Float16`. For high dynamic range scenes, ensure that the accumulation of SH terms does not lose precision.

## Operating characteristics

-   **Time Complexity:** $O(N)$ where $N$ is the number of splats. Each splat is processed in constant time per fragment, with shading cost depending on the complexity of the PBR evaluation and environment map sampling.
-   **Memory Complexity:** $O(N)$ for splat data. Additional memory for PBR materials and ASG coefficients. ASG coefficients add ~320 bytes per splat.
-   **Measured Performance:** Not given in the sources.
-   **Scaling:** Scales linearly with the number of splats. Chunking allows for efficient culling and batch processing.
-   **Strengths:** Enables dynamic relighting with PBR materials. Supports indirect lighting via ASG. Real-time performance on mobile GPUs (Metal).
-   **Limitations:** Requires additional memory for materials and ASG coefficients. 2DGS normal orientation requires a centroid calculation pass.
-   **When to use:** When realistic material appearance and dynamic lighting are required for Gaussian Splatting scenes.
-   **When not to use:** When memory is constrained and ASG coefficients cannot be afforded. When static lighting is sufficient and SH-only rendering is preferred.

## Background

Metal Gaussian Splat Relighting is an implementation of PBR relighting for Gaussian Splatting, specifically designed for the Metal API. It is associated with the "MetalSplatter" and "Ref-Gaussian" projects. The method extends standard 3D Gaussian Splatting by adding PBR materials and ASG for indirect lighting, enabling dynamic relighting. It is used in real-time rendering applications, particularly on Apple devices, where Metal is the primary graphics API.
