# Splat Painting

Also called: Interactive Splat Editing, Splat Brushing

## Overview
Splat Painting is a direct manipulation technique for editing the appearance of Gaussian Splatting models by applying color changes via a 3D brush [S1]. It solves the problem of post-hoc recolorization, such as restoring faded pigments or adding shadows, without requiring full scene re-optimization [S1]. Unlike methods that reoptimize primitive colors (which preserves texture but may alter shading) or direct painting (which erases shading and texture), Splat Painting modifies only the albedo parameters to achieve sharper boundaries and preserve existing shading effects [S2].

## How it works
**Inputs:** A set of 3D Gaussian primitives (centers, covariances, colors, opacities); a spherical brush defined by center, radius, and target color.
**Outputs:** Modified Gaussian primitives with updated color values.

**Data Structures:**
*   **Gaussian Primitive:**
    *   `center`: 3D vector $(x, y, z)$.
    *   `color`: 16-bit per channel (RGB) to support smooth falloff and low opacity brushes [S1].
    *   `opacity`: Scalar.
    *   `covariance`: 3x3 matrix (or quaternion/scale representation).
*   **Brush:**
    *   `center`: 3D vector.
    *   `radius`: Scalar.
    *   `target_color`: 16-bit RGB vector.

**Algorithm:**
1.  **Selection:** Iterate through all Gaussian primitives. For each primitive $i$ with center $c_i$, calculate the Euclidean distance $d$ to the brush center $b$:
    $$ d = \| c_i - b \|_2 $$
2.  **Intersection Check:** If $d \leq \text{radius}$, the primitive is selected for editing [S1].
3.  **Color Update:** Adjust the primitive's color.
    *   *Basic Mode:* Replace the color with the target color [S1].
    *   *Hue/Saturation Mode:* Adjust only hue and saturation to the target color, preserving the original value/brightness to retain texture and ambient occlusion [S1].
    *   *Albedo-Only Mode (Variant):* If the model uses intrinsic decomposition, update only the albedo Gaussian parameters while keeping shading Gaussians untouched [S2].
4.  **Falloff (Optional):** For smooth edges, apply a falloff function based on $d$ to blend the original color with the target color. The sources note the use of 16-bit channels to support this smooth falloff and low opacity [S1].

**Edge Cases and Pitfalls:**
*   **Sparse Geometry:** Splat models are sparse; painting detailed features (text, lines) is difficult because individual splats are visible and undersampling occurs [S1].
*   **Clean Surfaces:** Models from images focus splats on high-frequency regions. Clean, single-colored surfaces (e.g., walls) use few splats, preventing detailed color changes [S1].
*   **Color Leaks:** In reconstructions with non-opaque surfaces, splats may contribute to multiple surface parts. Changing appearance can cause color leaks into differently colored areas [S1].

## Subtopics

### Albedo-Only Gaussian Editing
This variant modifies only the albedo parameters of the Gaussian primitives while leaving shading and residual Gaussians untouched [S2]. It is chosen when the goal is to change surface color without altering existing lighting effects (shadows, ambient occlusion) [S2]. It achieves sharper boundaries around the edited area compared to methods that reoptimize all color channels [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of primitives $N$ for the selection phase ($O(N)$). If optimization is involved (e.g., ReCoGS), complexity increases significantly; however, basic Splat Painting and SplatShop are direct updates without optimization [S1, S2].
*   **Memory Complexity:** $O(N)$ to store the primitive data. Undo/redo history poses memory challenges, requiring compact storage of differences to avoid VR stutters [S1].
*   **Strengths:** Interactive speed (no optimization required for direct painting); preserves shading if using intrinsic decomposition [S2].
*   **Limitations:** Cannot create detailed features due to sparse geometry; color leaks on non-opaque surfaces; limited to modifying existing primitives rather than generating new geometry [S1].
*   **When to use:** Quick recolorization, fading restoration, or shadow addition where shading preservation is desired [S1, S2].
*   **When not to use:** When detailed texture addition is required or when the underlying reconstruction is too sparse to support the desired brush strokes [S1].

## Background
Splat Painting originated as a feature within Gaussian Splatting editing tools, specifically discussed in the context of *Splatshop* and intrinsic decomposition methods [S1, S2]. It addresses the limitation of standard Gaussian Splatting, which lacks native editing capabilities for appearance [S1]. The method distinguishes itself from *ReCoGS* (which reoptimizes colors under a mask) and *SplatShop* (which paints directly but erases shading) by offering a middle ground, particularly through albedo-only updates [S2].
