# 3D Gaussian Splatting (3DGS) Approximation

Also called: 3D Gaussian Splatting (3DGS)

## Overview
3D Gaussian Splatting (3DGS) is a splatting method that uses unnormalized 2D Gaussians to represent scene primitives, preserving projected amplitude (opacity) across projections rather than preserving weight as in EWA splatting [S1]. It differs from its parent [OTS (EWA-Based Splatting)](1181-ots-ewa-based-splatting.md) by simplifying volumetric integration: it assumes uniform color per Gaussian, ignores perspective distortion via affine projection, and approximates attenuation using a first-order Taylor expansion ($e^x \approx 1-x$) [S1]. This allows for real-time rendering but prevents the definition of a corresponding 3D extinction function in the established volume integration framework [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of $N$ 3D Gaussians. Each Gaussian $i$ is defined by:
    *   Mean position $\mathbf{X}_{0,i}$ in world space [G].
    *   Rotation matrix $\mathbf{R}_i$ and scaling matrix $\mathbf{S}_i$, defining the 3D covariance $\boldsymbol{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^T \mathbf{R}_i^T$ [S2].
    *   Opacity parameter $\sigma_i$ [S2].
    *   Spherical Harmonics (SH) coefficients for view-dependent color $c_i$ [S2].
*   Camera parameters: View matrix $\mathbf{V}$, Projection matrix $\mathbf{P}$, and intrinsics [G].
*   Image resolution (pixel coordinates $\mathbf{p}$) [G].

**Outputs:**
*   Final pixel color $c_{\text{pixel}}$ for each pixel in the image plane [G].

### Data Structures
Each Gaussian $i$ stores:
1.  **Position:** $\mathbf{X}_{0,i} \in \mathbb{R}^3$ [G].
2.  **Covariance:** Defined implicitly by $\mathbf{R}_i \in \mathbb{R}^{3\times3}$ (orthonormal) and $\mathbf{S}_i \in \mathbb{R}^{3\times3}$ (diagonal, positive scales) [S2].
3.  **Opacity:** Scalar $\sigma_i \in [0, 1]$ [S2].
4.  **Color:** SH coefficients (typically degree 3, 48 floats) [S2].

### Steps

1.  **3D to 2D Projection:**
    For each Gaussian $i$, compute the 2D mean $\boldsymbol{\mu}'_i$ and covariance $\boldsymbol{\Sigma}'_i$ in screen space.
    *   Transform $\mathbf{X}_{0,i}$ to camera space and project to screen space to get $\boldsymbol{\mu}'_i$ [S1].
    *   Compute the projected 2D covariance $\boldsymbol{\Sigma}'_i$. Since perspective projection is non-linear, an affine approximation is used (as in EWA) [S1]. The 2D Gaussian is the marginal distribution of the 3D Gaussian along the view axis [S1].
    *   The projected 2D Gaussian function is unnormalized:
        $$ o_i(\mathbf{p}) = \mathcal{G}_2^u(\mathbf{p}, a'_i, \boldsymbol{\mu}'_i, \boldsymbol{\Sigma}'_i) $$
        where $a'_i$ is the projected amplitude (opacity) [S1]. Unlike EWA which preserves weight $w$, 3DGS preserves amplitude $a'$ [S1].

2.  **Splatting Opacity Estimation:**
    For a pixel $\mathbf{p}$, the splatting opacity $\alpha_i$ for Gaussian $i$ is estimated based on the distance between $\mathbf{p}$ and the Gaussian's center $\boldsymbol{\mu}'_i$ using the unnormalized Gaussian function [S2].
    $$ \alpha_i = o_i(\mathbf{p}) $$

3.  **Color Evaluation:**
    The color $c_i$ for Gaussian $i$ is evaluated using its Spherical Harmonics coefficients at the viewing direction relative to the mean $\boldsymbol{\mu}'_i$ [S1, S2]. Color is assumed uniform within the Gaussian footprint [S1].

4.  **Alpha Blending (Approximate Volume Integration):**
    Gaussians are sorted by depth (distance from camera) [G]. The final pixel color is computed using alpha blending with the first-order Taylor expansion approximation for attenuation [S1]:
    $$ c_{\text{pixel}} = \sum_{i=1}^{N} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    This approximates the integral:
    $$ I(\mathbf{p}) = \sum_{i=0}^N c_i(\mathcal{R})g_i(\mathbf{p}) \prod_{j=0}^{i-1} (1 - g_j(\mathbf{p})) + c_b \prod_{i=0}^N (1 - g_i(\mathbf{p})) $$
    where $g_i(\mathbf{p})$ is the unnormalized Gaussian value [S1]. The term $c_b$ represents the background color term in the full approximation [S1].

### Pseudocode

```python
import math
import numpy as np

def render_3dgs(gaussians, camera, image_width, image_height):
    """
    Render a scene using 3D Gaussian Splatting approximation.
    
    Args:
        gaussians: List of dicts with keys: 'pos', 'R', 'S', 'opacity', 'sh_coeffs'
        camera: Dict with keys: 'view_matrix', 'proj_matrix', 'intrinsics'
        image_width, image_height: int
        
    Returns:
        image: (H, W, 3) float32 array
    """
    image = np.zeros((image_height, image_width, 3), dtype=np.float32)
    
    # Precompute combined projection matrix
    view_proj = camera['proj_matrix'] @ camera['view_matrix']
    
    # Gaussians must be sorted by depth for correct front-to-back blending [G]
    # Sorting step omitted for brevity; assume gaussians list is depth-sorted.
    
    for g in gaussians:
        # 1. Project 3D Gaussian to 2D screen space
        # Transform mean to camera space
        pos_world = np.append(g['pos'], 1.0)
        pos_cam = camera['view_matrix'] @ pos_world
        pos_cam = pos_cam[:3] / pos_cam[3]  # Perspective divide
        
        # Project to screen
        pos_clip = camera['proj_matrix'] @ np.append(pos_cam, 1.0)
        pos_screen = pos_clip[:2] / pos_clip[3]
        
        # Compute 3D covariance
        sigma_3d = g['R'] @ (g['S'] * g['S'].T) @ g['R'].T
        
        # Compute Jacobian of projection at pos_cam
        fx = camera['intrinsics'][0, 0]
        fy = camera['intrinsics'][1, 1]
        z = pos_cam[2]
        if z <= 0:
            continue
            
        J = np.zeros((2, 3))
        J[0, 0] = fx / z
        J[0, 2] = -fx * pos_cam[0] / (z * z)
        J[1, 1] = fy / z
        J[1, 2] = -fy * pos_cam[1] / (z * z)
        
        # Compute projected 2D covariance
        sigma_2d = J[:2, :2] @ sigma_3d @ J[:2, :2].T
        
        # 2. Determine bounding box from covariance eigenvalues [G]
        eigenvalues = np.linalg.eigvalsh(sigma_2d)
        max_extent = 3.0 * math.sqrt(np.max(eigenvalues))
        
        min_x = max(0, int(pos_screen[0] - max_extent))
        max_x = min(image_width, int(pos_screen[0] + max_extent))
        min_y = max(0, int(pos_screen[1] - max_extent))
        max_y = min(image_height, int(pos_screen[1] + max_extent))
        
        # 3. Splat to pixels
        for y in range(min_y, max_y):
            for x in range(min_x, max_x):
                pixel_pos = np.array([x, y])
                diff = pixel_pos - pos_screen
                
                # Compute Mahalanobis distance
                try:
                    sigma_inv = np.linalg.inv(sigma_2d)
                    dist_sq = diff @ sigma_inv @ diff
                except np.linalg.LinAlgError:
                    continue  # Singular covariance [G]
                
                # Unnormalized Gaussian value scaled by 3D opacity
                alpha = math.exp(-0.5 * dist_sq) * g['opacity']
                alpha = max(0.0, min(1.0, alpha))  # Clamp to [0, 1] [S2]
                
                # Evaluate color from SH at viewing direction
                view_dir = pos_cam / np.linalg.norm(pos_cam)
                color = evaluate_sh(g['sh_coeffs'], view_dir)
                
                # Front-to-back alpha blending
                image[y, x] = image[y, x] * (1.0 - alpha) + color * alpha
                
    return image

def evaluate_sh(sh_coeffs, view_dir):
    """
    Evaluate Spherical Harmonics color from view direction.
    Simplified implementation for degree 0 (constant) [G].
    """
    return sh_coeffs[:3]
```

### Parameters and Typical Values
*   **SH Degree:** Typically 3 (48 coefficients per Gaussian) [S2].
*   **Opacity Clamping:** $\alpha_i \in [0, 1]$ [S2].

### Edge Cases and Pitfalls
*   **Singular Covariance:** If $\boldsymbol{\Sigma}'_i$ is singular (e.g., flat Gaussian viewed edge-on), matrix inversion fails [G].
*   **Perspective Distortion:** The affine approximation ignores perspective skew, which can cause artifacts for large Gaussians or extreme angles [S1].
*   **No 3D Extinction:** The method does not define a 3D density function, making it incompatible with standard volume rendering integrators [S1].
*   **Sorting:** Correct alpha blending requires Gaussians to be sorted by depth for each pixel [G].

### Measured Performance
3DGS achieves real-time rendering performance on modern GPUs [S2]. It delivers high visual fidelity compared to neural radiance fields (NeRFs) [S2].

### Strengths and Limitations
*   **Strengths:** Fast real-time rendering, high visual fidelity, explicit scene representation [S2].
*   **Limitations:** Requires a large number of Gaussians, memory intensive for high-resolution scenes, artifacts from affine projection approximation [S1].

### When to Use
Real-time rendering of static or dynamic scenes with high fidelity [S2].
