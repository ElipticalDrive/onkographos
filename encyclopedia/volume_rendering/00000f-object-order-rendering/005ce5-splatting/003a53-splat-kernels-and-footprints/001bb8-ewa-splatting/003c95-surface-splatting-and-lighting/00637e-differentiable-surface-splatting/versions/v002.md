# Differentiable Surface Splatting

Also called: Differentiable Surface Splatting for Point-based Geometry Processing

## Overview
Differentiable Surface Splatting is a rendering technique for point-based geometry processing that supports both forward and backward rendering to enable differentiable optimization of point positions and normals [S1]. It allows gradients to flow from a 2D image space loss back to 3D point attributes, facilitating tasks such as dense 3D object reconstruction and surface editing [S1]. Unlike standard splatting which is primarily for visualization, this method treats the splatting process as a differentiable operator within an optimization loop, distinguishing it from non-differentiable siblings like [EWA Surface Splatting](8199-ewa-surface-splatting.md) and [Phong Splatting](2802-phong-splatting.md) [G]. The method extends the principles of [Surface Splatting and Lighting](9275-surface-splatting-and-lighting.md) by introducing a backward pass that computes gradients with respect to the input point cloud parameters [S1]. Unlike DPRF and GS, DSS includes lighting models [S2, unofficial].

## How it works
The method operates on a point cloud where each sample has a position and a normal [G]. The rendering process transforms object-space splats into screen space, rasterizes elliptical footprints as low-pass filters, accumulates overlapping contributions via distance-based weights, and computes illumination [G].

### Inputs and Outputs
*   **Input:** A point cloud $P = \{p_i\}$ where each point $p_i$ has a 3D position $\mathbf{p}_i$ and a normal $\mathbf{n}_i$ [S1]. A set of camera views (typically 12) with known projection matrices and target images for the optimization loss [S1].
*   **Output:** Optimized point positions $\mathbf{p}_i'$ and normals $\mathbf{n}_i'$ that minimize the difference between the rendered splat images and the target images [S1].

### Data Structures
The core data structure is the point cloud $P$ [S1]. For backward rendering, a cache is maintained per pixel [S1].
*   **Point $p_i$:**
    *   $\mathbf{p}_i \in \mathbb{R}^3$: Position.
    *   $\mathbf{n}_i \in \mathbb{R}^3$: Normal.
*   **Pixel Cache:**
    *   For each pixel $(u, v)$, store a list of up to $K$ indices of points that contributed to the color at that pixel during the forward pass [S1].

### Parameters
*   $C$: Cutoff threshold for splat size. Default follows [Zwicker et al. 2001]. Increased for close camera views to ensure hole-free renderings [S1].
*   $T$: Merge threshold for splat blending. Default follows [Zwicker et al. 2001] [S1].
*   $\sigma_k$: Standard deviation for splat kernel. Default follows [Zwicker et al. 2001] [S1].
*   $K$: Cache size for backward rendering. $K=5$ is sufficient for experiments [S1].
*   $D$: Bandwidth for regularization weights. Set to $4 \sqrt{D_{box}/N}$ where $D_{box}$ is the bounding box diagonal length and $N$ is the point count [S1].
*   $\Theta$: Angular bandwidth for regularization weights. Set to $\pi/3$ [S1].
*   $D_{proj}$: Bandwidth for projection term regularization. Set to $0.1 \times D_{box}$ for large-scale deformation [S1].
*   $\eta_p$: Learning rate for position. Set to 5 [S1].
*   $\eta_n$: Learning rate for normal. Set to 5000 [S1].
*   $T_p$: Number of steps for position update. Typically 25 for large topology changes, 19 for local geometry processing [S1].
*   $T_n$: Number of steps for normal update. Typically 15 for large topology changes, 1 for local geometry processing [S1].
*   $\gamma_i, \gamma_p, \gamma_r$: Loss weights for image loss, projection regularization, and repulsion regularization. Determined by ensuring the magnitude of per-point gradient from $\mathcal{L}_p$ and $\mathcal{L}_r$ is around 1% of that from $\mathcal{L}_i$ [S1].

### Forward Rendering
1.  **Splat Projection:** For each point $p_i$, compute its screen-space footprint using the camera projection matrix [S1]. The footprint is an elliptical disk defined by the tangent vectors and radii derived from the point's normal and view direction [G].
2.  **Rasterization:** Rasterize the splat footprints [S1]. Each pixel $(u,v)$ accumulates contributions from overlapping splats [S1].
3.  **Accumulation:** For each pixel, compute the weighted sum of colors and depths [S1]. The weight $w_{i}$ for point $i$ at pixel $(u,v)$ is determined by the Gaussian kernel with standard deviation $\sigma_k$ and the cutoff $C$ [S1].
    $$ C_{uv} = \frac{\sum_i w_i \mathbf{c}_i}{\sum_i w_i} $$
    where $\mathbf{c}_i$ is the color of point $i$ [S1].
4.  **Logging:** Store the indices of the top $K$ contributing points for each pixel in the cache [S1].

### Backward Rendering
1.  **Gradient from Image:** Compute the gradient of the loss $\mathcal{L}_i$ with respect to the pixel colors $\frac{\partial \mathcal{L}_i}{\partial C_{uv}}$ [S1].
2.  **Gradient to Splat Weights:** Propagate gradients to the splat weights $w_i$ and colors $\mathbf{c}_i$ using the chain rule through the accumulation equation [S1].
3.  **Gradient to Point Attributes:** Compute the gradient of the loss with respect to the point positions $\mathbf{p}_i$ and normals $\mathbf{n}_i$ [S1]. This requires differentiating the projection and rasterization steps [S1]. The cache of size $K$ allows considering occluded points for re-evaluation, improving accuracy [S1].

### Regularization
To stabilize optimization, two regularization terms are added [S1].
1.  **Projection Regularization ($\mathcal{L}_p$):** Encourages points to stay on the surface. Uses bandwidth $D_{proj}$ [S1].
2.  **Repulsion Regularization ($\mathcal{L}_r$):** Prevents points from clustering. Uses bandwidth $D$ and angular bandwidth $\Theta$ [S1].
The total loss is:
$$ \mathcal{L} = \mathcal{L}_i + \gamma_p \mathcal{L}_p + \gamma_r \mathcal{L}_r $$ [S1].

### Optimization Loop
1.  Initialize point cloud $P$ [S1].
2.  For each optimization step:
    a. Forward render all camera views [S1].
    b. Compute loss $\mathcal{L}$ [S1].
    c. Backward render to compute gradients $\frac{\partial \mathcal{L}}{\partial \mathbf{p}_i}$ and $\frac{\partial \mathcal{L}}{\partial \mathbf{n}_i}$ [S1].
    d. Update positions: $\mathbf{p}_i \leftarrow \mathbf{p}_i - \eta_p \frac{\partial \mathcal{L}}{\partial \mathbf{p}_i}$ [S1].
    e. Update normals: $\mathbf{n}_i \leftarrow \mathbf{n}_i - \eta_n \frac{\partial \mathcal{L}}{\partial \mathbf{n}_i}$ [S1].
    f. Repeat for $T_p$ position steps and $T_n$ normal steps [S1].

### Pseudocode
```python
import numpy as np

def forward_render(points, cameras, params):
    """Forward pass of differentiable surface splatting."""
    images, caches = [], []
    C, sigma_k = params['C'], params['sigma_k']
    K = params['K']
    
    for cam in cameras:
        H, W = cam.resolution
        color_buf = np.zeros((H, W, 3))
        weight_buf = np.zeros((H, W))
        cache = [[[] for _ in range(W)] for _ in range(H)]
        
        for i, p in enumerate(points):
            # [G] Standard perspective projection
            sp = cam.project(p.pos)
            if sp.z <= 0: continue
            
            # [G] Compute elliptical footprint bounding box
            u_min, u_max, v_min, v_max = compute_footprint_bbox(sp, sigma_k)
            
            for u in range(max(0, u_min), min(W, u_max)):
                for v in range(max(0, v_min), min(H, v_max)):
                    # [G] Standard 2D Gaussian weight
                    w = np.exp(-0.5 * ((u - sp.u)**2 + (v - sp.v)**2) / sigma_k**2)
                    if w > 0:
                        color_buf[v, u] += w * p.color
                        weight_buf[v, u] += w
                        if len(cache[v][u]) < K:
                            cache[v][u].append(i)
        
        mask = weight_buf > 0
        color_buf[mask] /= weight_buf[mask, :, np.newaxis]
        images.append(color_buf)
        caches.append(cache)
        
    return images, caches

def backward_render(images, targets, caches, points, params):
    """Backward pass to compute gradients for positions and normals."""
    grad_p = np.zeros_like(points[:, :3])
    grad_n = np.zeros_like(points[:, 3:6])
    K = params['K']
    
    for img, target, cache in zip(images, targets, caches):
        dL_dimg = (img - target)  # [G] Standard MSE loss gradient
        H, W = img.shape[:2]
        
        for u in range(W):
            for v in range(H):
                dL_dcolor = dL_dimg[v, u]
                for idx in cache[v][u]:
                    p = points[idx]
                    sp = p.screen_proj  # [G] Cached screen projection
                    
                    # [G] Chain rule through accumulation
                    sum_w = sum(np.exp(-0.5 * ((u - points[j].screen_proj.u)**2 + (v - points[j].screen_proj.v)**2) / params['sigma_k']**2) for j in cache[v][u])
                    if sum_w > 0:
                        w = np.exp(-0.5 * ((u - sp.u)**2 + (v - sp.v)**2) / params['sigma_k']**2)
                        dL_dc = dL_dcolor * w / sum_w
                        dL_dw = dL_dcolor * (p.color - img[v, u]) / sum_w
                        
                        # [G] Exact derivatives depend on specific projection/kernel; 
                        # standard chain rule propagates dL_dc and dL_dw to p.pos and p.norm
                        grad_p[idx] += dL_dc * sp.dcolor_dpos + dL_dw * sp.dw_dpos
                        grad_n[idx] += dL_dc * sp.dcolor_dnorm + dL_dw * sp.dw_dnorm
                        
    return grad_p, grad_n

def optimize(points, cameras, targets, params):
    """Main optimization loop."""
    eta_p, eta_n = params['eta_p'], params['eta_n']
    Tp, Tn = params['Tp'], params['Tn']
    gp, gr = params['gamma_p'], params['gamma_r']
    
    for step in range(params['max_steps']):
        images, caches = forward_render(points, cameras, params)
        Li = np.mean((np.stack(images) - np.stack(targets))**2)
        Lp = compute_projection_reg(points, params)
        Lr = compute_repulsion_reg(points, params)
        L = Li + gp * Lp + gr * Lr
        
        grad_p, grad_n = backward_render(images, targets, caches, points, params)
        grad_p += gp * compute_projection_grad(points, params)
        grad_n += gr * compute_repulsion_grad(points, params)
        
        for _ in range(Tp):
            points[:, :3] -= eta_p * grad_p
        for _ in range(Tn):
            points[:, 3:6] -= eta_n * grad_n
            points[:, 3:6] /= np.linalg.norm(points[:, 3:6], axis=1, keepdims=True)
            
    return points
```

### Edge Cases and Pitfalls
*   If repulsion weight $\gamma_r > 0.1$, points are repelled far off the surface [S1].
*   If projection weight $\gamma_p > 0.1$, points are forced to stay on a local surface, preventing topology changes [S1].
*   Higher learning rates cause faster convergence but increase the risk of points gathering in clusters [S1].
*   With 8 or fewer camera views, results start to degenerate [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Exact complexity formulas are not given in the sources [S1]. The forward pass processes $N$ points and $H \times W$ pixels, while the backward pass uses a cache of size $K$ per pixel [S1].
*   **Performance:** The method is computationally intensive due to the backward pass and optimization loop, making it suitable for offline reconstruction and editing rather than real-time rendering [S1]. It is faster than MLP-ray-marching approaches because it uses point-cloud splatting rendering [S2, unofficial].
*   **Strengths:** Enables differentiable optimization of point clouds from 2D images and supports topology changes [S1].
*   **Limitations:** Sensitive to hyperparameters, requires multiple views for robust optimization, and carries a risk of clustering with high learning rates [S1].

## Background
Differentiable Surface Splatting was introduced by Yaron Lipman, Daniel Cohen-Or, David Levin, and Hillel Tal-Ezer in 2007 in the paper "Parameterization-free projection for geometry reconstruction" [S1]. It builds on the EWA Splatting framework [Zwicker et al. 2001] and extends it to support gradient-based optimization [S1]. The method has been used in applications such as dense 3D object reconstruction and surface editing [S1].
