# Beta Function Splatting Kernel

Also called: Beta distribution splatting, Beta footprint

## Overview
The Beta Function Splatting Kernel is a 2D kernel function used in volume rendering that replaces the standard Normal (Gaussian) distribution with a Beta function to control the footprint shape [S1, unofficial]. It solves the problem of tuning visual parameters (opacity, zoom, shading) by offering smaller footprints that maintain equivalent visual quality while reducing rendering time [S1, unofficial]. It sets itself apart from Gaussian splats by allowing independent control over the curve's openness, height, and width, resulting in more compact support and faster execution [S1, unofficial].

## How it works
**Inputs:**
*   $x$: Normalized radial distance from the splat center, mapped to the range $[0, 1]$ [S1, unofficial].
*   $a, b$: Shape parameters controlling the curve profile [S1, unofficial].
*   $k_{scale}$: Scaling factor for the kernel height [S1, unofficial].

**Outputs:**
*   $W$: The kernel weight/value at distance $x$ [S1, unofficial].

**Data Structures:**
*   The kernel is defined by the scalar parameters $a, b, k_{scale}$ [S1, unofficial].
*   The footprint radius is fixed by the domain of $x \in [0, 1]$ [S1, unofficial].

**Formula:**
The kernel value $W$ is calculated as:
$$ W(x) = k_{scale} \cdot x^a \cdot (1 - x)^b $$
where $x \in [0, 1]$ [S1, unofficial].

**Parameters:**
*   $a, b$: Shape parameters. Identical values ($a=b$) produce symmetric curves [S1, unofficial]. Lower values produce "more opened" (wider/flatter) curves [S1, unofficial].
*   $k_{scale}$: Scaling factor applied to adjust the range/height of the curve [S1, unofficial].

**Steps:**
1. Calculate the normalized distance $x$ from the splat center to the sample point, ensuring $x \in [0, 1]$ [S1, unofficial].
2. Compute the base Beta function value: $x^a (1 - x)^b$ [S1, unofficial].
3. Multiply by the scaling factor $k_{scale}$ to obtain the final weight $W$ [S1, unofficial].
4. If $x < 0$ or $x > 1$, the weight is 0 (compact support) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Holes at Boundaries:** Holes may appear when voxel opacity decreases [S1, unofficial]. This requires dynamic changes in footprint size to maintain continuity between neighbor voxels, especially at feature boundaries in tagged volumes [S1, unofficial].
*   **Precision:** For very small $a$ or $b$, numerical stability near $x=0$ or $x=1$ should be considered [G].

**Pseudocode:**
```python
def beta_kernel(x, a, b, k_scale):
    """
    Computes the Beta function splatting kernel weight.
    
    Args:
        x (float): Normalized distance from center, in [0, 1].
        a (float): Shape parameter for the start of the curve.
        b (float): Shape parameter for the end of the curve.
        k_scale (float): Scaling factor for the kernel height.
        
    Returns:
        float: Kernel weight W.
    """
    if x < 0.0 or x > 1.0:
        return 0.0
    
    # Compute x^a * (1-x)^b
    # Note: 0^0 is treated as 1.0 in this context for continuity if a,b > 0
    term1 = x ** a
    term2 = (1.0 - x) ** b
    
    return k_scale * term1 * term2
```

## Subtopics

### [Deformable Beta Splatting](9228-deformable-beta-splatting.md)
Deformable Beta Splatting replaces standard Gaussian kernels with an adaptive, bounded Beta function kernel. It sets itself apart from fixed-shape siblings by allowing the kernel's profile to deform during training, enabling better modeling of diverse geometric structures such as solid geometry with sharp boundaries or high-frequency details. Choose this variant when rendering tagged volumes or features with sharp boundaries that require adaptive footprint shaping.

### [Universal Beta Splatting (UBS)](10589-universal-beta-splatting-ubs.md)
Universal Beta Splatting is an N-dimensional splatting kernel that replaces the Gaussian distribution with a Beta function to enable independent per-dimension shape control. It sets itself apart from coupled Gaussian siblings by allowing each dimension to adopt fundamentally different profiles independently, addressing the limitations of methods like 6DGS and 7DGS. Choose this variant when per-dimension shape flexibility is required beyond radial symmetry.

## Operating characteristics
*   **Performance:** Beta footprints are smaller than Normal distribution footprints while providing equivalent visual quality, resulting in faster execution (e.g., twice as fast in tested examples) [S1, unofficial].
*   **Tuning:** Easier to tune visual parameters like opacity and zoom compared to Gaussian kernels [S1, unofficial].
*   **Limitations:** Requires careful management of footprint size to avoid holes when opacity varies, particularly at feature boundaries [S1, unofficial].

## Background
The Beta Function Splatting Kernel was proposed in the context of splatting multiresolution volume data using a feature graph [S1, unofficial]. It was introduced to improve rendering performance by using smaller footprints that are easier to tune under visual changes, such as zooming and shading functions [S1, unofficial].
