# Deferred Style Transformation (DST)
## Overview
Deferred Style Transformation (DST) is a technique that applies style transformation to 2D feature maps after volume rendering, rather than to 3D point features before rendering [S1]. It solves the problem of multi-view inconsistency and high memory usage inherent in applying holistic style statistics (like AdaIN) to batches of sampled 3D points [S1]. DST is set apart from its sibling method, Sampling-Invariant Content Transformation (SICT), by handling the style-specific affine transformation (matrix multiplication and bias) in the 2D domain, ensuring that the transformation is mathematically equivalent to point-wise transformation while drastically reducing memory footprint [S1].

## How it works
**Inputs and Outputs:**
- **Input:** Volume-rendered 2D feature map $\bar{F}_c \in \mathbb{R}^{H \times W \times C}$, style reference feature map $F_s \in \mathbb{R}^{H_s \times W_s \times C'}$, sum of weights $w_r$ for the ray, and pre-computed style statistics $\mu(F_s)$ and $\sigma(F_s)$ [S1].
- **Output:** Stylized 2D feature map $F_{cs} \in \mathbb{R}^{H \times W \times C}$ [S1].

**Data Structures:**
- $F_s$: Feature map extracted from a reference style image using a pre-trained VGG network [S1].
- $T$: Style transformation matrix of size $C' \times C$ [S1].
- $\mu(F_s)$: Mean of style features, computed as a scalar or channel-wise vector [S1].
- $\sigma(F_s)$: Standard deviation of style features, computed as a scalar or channel-wise vector [S1].
- $w_r$: Sum of weights of sampled points along ray $r$, i.e., $w_r = \sum_{i=1}^N w_i$ [S1].
- $\bar{F}_c$: Feature map resulting from volume rendering of independently transformed point features $\bar{F}_i$ [S1].

**Steps:**
1. Extract feature maps $F_s$ of the reference style $S$ using a pre-trained VGG network [S1].
2. Generate the style transformation matrix $T \in \mathbb{R}^{C' \times C}$ using the feature covariance $cov(F_s)$ [S1].
3. Apply matrix multiplication with $T$ to the volume-rendered feature map $\bar{F}_c$ [S1].
4. Use a 1x1 convolution layer `conv` (without bias) to restore the channel number from $C'$ to $C$ [S1].
5. Add adaptive bias: $F_{cs} = \text{conv}(T \otimes \bar{F}_c \times \sigma(F_s)) + w_r \times \mu(F_s)$ [S1].

**Formulas:**
The core transformation is defined in Equation (9) of [S1]:
$$ F_{cs} = \text{conv}\left( T \otimes \bar{F}_c \times \sigma(F_s) \right) + w_r \times \mu(F_s) $$
Where:
- $\otimes$ denotes matrix multiplication [S1].
- $\bar{F}_c$ is the volume-rendered feature map [S1].
- $T$ is the style transformation matrix [S1].
- $\sigma(F_s)$ is the style standard deviation [S1].
- $\text{conv}$ is a 1x1 convolution layer without bias [S1].
- $w_r$ is the sum of weights of sampled points along the ray [S1].
- $\mu(F_s)$ is the style mean [S1].

**Pseudocode:**
```python
def deferred_style_transformation(F_bar_c, F_s, w_r, T, conv_weights):
    """
    Applies Deferred Style Transformation to a volume-rendered feature map.
    
    Args:
        F_bar_c: Volume-rendered 2D feature map of shape (H, W, C).
        F_s: Reference style feature map of shape (H_s, W_s, C').
        w_r: Sum of weights of sampled points along the ray (scalar).
        T: Style transformation matrix of shape (C', C).
        conv_weights: 1x1 convolution kernel weights of shape (C, C').
        
    Returns:
        F_cs: Stylized feature map of shape (H, W, C).
    """
    # Compute style statistics from reference feature map
    mu_Fs = F_s.mean(dim=(0, 1), keepdim=True)
    sigma_Fs = ((F_s - mu_Fs) ** 2).mean(dim=(0, 1), keepdim=True).sqrt()
    
    # Reshape feature map for matrix multiplication
    H, W, C = F_bar_c.shape
    F_flat = F_bar_c.reshape(-1, C)
    
    # Apply style transformation matrix T
    F_temp = F_flat @ T.T
    F_temp = F_temp.reshape(H, W, -1)
    
    # Scale by style standard deviation
    F_scaled = F_temp * sigma_Fs
    
    # Apply 1x1 convolution (matrix multiplication over channel dimension)
    F_conv = F_scaled.reshape(-1, F_scaled.shape[-1]) @ conv_weights.T
    F_conv = F_conv.reshape(H, W, -1)
    
    # Add adaptive bias modulated by ray weight sum
    F_cs = F_conv + w_r * mu_Fs
    return F_cs
```

**Parameters:**
- $w_r$: Sum of weights of sampled points along the ray [S1].
- $T$: Style transformation matrix derived from $cov(F_s)$ [S1].
- `conv`: 1x1 convolution layer without bias [S1].

**Pitfalls:**
- Standard style transfer methods (like AdaIN) use holistic statistics of the sampled point batch, which violates multi-view consistency because the transformation of a specific 3D point varies across different sampled points [S1]. DST avoids this by deferring the transformation to 2D feature maps where the statistics are consistent per pixel/ray [S1].
- Precision issues may arise if $w_r$ is very small or very large, affecting the bias term [G].
- The equivalence in Eq. 9 relies on the linearity of the volume rendering integration and the affine nature of the style transformation, proving that applying DST on 2D feature maps is equivalent to applying the transformation on 3D points’ features [S1].

## Operating characteristics
- **Time Complexity:** DST operates on 2D feature maps, which are significantly smaller than the batch of 3D point features sampled along all rays, reducing computational cost compared to point-wise style transfer [S1].
- **Memory Complexity:** By deferring transformation to 2D feature maps, DST greatly reduces memory footprint, allowing training with 256x256 patches without sub-sampling, unlike previous NeRF-based methods [S1].
- **Performance:** StyleRF with DST achieves superior 3D stylization quality with precise geometry reconstruction and generalizes to various new styles in a zero-shot manner [S1].
- **Strengths:** Maintains multi-view consistency, memory-efficient, zero-shot generalization [S1].
- **Limitations:** Relies on the accuracy of the pre-trained VGG features and the covariance estimation for style transfer [S1].

## Background
DST was introduced in the StyleRF paper [S1]. It is part of a framework for zero-shot 3D style transfer of Neural Radiance Fields [S1]. The method builds on the observation that style transformation can be decomposed into sampling-invariant content transformation and deferred style transformation [S1]. It addresses limitations of previous NeRF-based 3D style transfer methods that were computationally intensive or required low-resolution feature maps [S1].
