# Matplotlib 3D Voxel Rendering with Internal Faces

Also called: Matplotlib internal_faces parameter, ax.voxels monkey patch

## Overview
This method enables the rendering of all voxel faces in a 3D volume, including occluded internal faces, by overriding the standard Matplotlib `voxels` method [S1, unofficial]. The standard method only renders surface faces, hiding internal voxels even if they have alpha transparency [S1, unofficial]. It sets itself apart from siblings like the [Wireframe Block Highlighter](10884-wireframe-block-highlighter.md) by explicitly generating geometry for internal boundaries rather than just highlighting existing structures [S1, unofficial].

## How it works
The method implements a monkey patch for `Axes3D.voxels` that iterates through all voxel coordinates and their neighbors to determine which faces to render based on the `internal_faces` flag [S1, unofficial].

**Inputs and Outputs:**
*   **Input:** `filled`: 3D boolean NumPy array of shape $(X, Y, Z)$ defining voxel presence [S1, unofficial].
*   **Input:** `x, y, z`: Optional 3D coordinate arrays of shape $(X+1, Y+1, Z+1)$ [S1, unofficial]. If `None`, generated via `np.indices` [S1, unofficial].
*   **Input:** `internal_faces`: Boolean keyword argument. If `True`, renders faces between adjacent filled voxels [S1, unofficial].
*   **Input:** `facecolors`: Optional 4D array $(X, Y, Z, 4)$ or broadcastable color [S1, unofficial].
*   **Output:** A Matplotlib `Axes3D` object containing `Poly3DCollection` objects for each voxel's visible faces [S1, unofficial].

**Data Structures:**
*   `voxel_faces`: A `defaultdict(list)` mapping voxel coordinates $(i, j, k)$ to a list of vertex arrays defining the faces to be drawn for that voxel [S1, unofficial].
*   `square`: A $4 \times 3$ integer array defining the four corners of a unit square face:
    $$
    \begin{bmatrix}
    0 & 0 & 0 \\
    0 & 1 & 0 \\
    1 & 1 & 0 \\
    1 & 0 & 0
    \end{bmatrix}
    $$
    [S1, unofficial].

**Algorithm Steps:**
1.  **Parse Arguments:** Extract `filled` and optional `x, y, z`. If `x, y, z` are `None`, generate them using `np.indices((size+1, size+1, size+1))` [S1, unofficial].
2.  **Validate Dimensions:** Ensure `filled.ndim == 3` [S1, unofficial].
3.  **Handle Colors:** Broadcast `facecolors` and `edgecolors` to match `filled.shape` if provided, or use defaults [S1, unofficial].
4.  **Initialize Storage:** Create `voxel_faces = defaultdict(list)` [S1, unofficial].
5.  **Iterate Axes Permutations:** Define a generator `permutation_matrices(3)` that yields cyclic permutation matrices for the 3 axes [S1, unofficial]. For each permutation matrix `permute`:
    a.  Calculate dimensions $p_c, q_c, r_c$ along the permuted axes [S1, unofficial].
    b.  Rotate the base square: `square_rot = square.dot(permute.T)` [S1, unofficial].
    c.  Iterate over $p \in [0, p_c)$ and $q \in [0, q_c)$:
        i.  Calculate base index $i_0$ for $(p, q, 0)$ in the original coordinate system [S1, unofficial].
        ii. If `filled[i0]` is true, add the base face (at $r=0$) to `voxel_faces[i0]` using `square_rot` [S1, unofficial].
        iii. Iterate through adjacent pairs along the third axis $r$: for $r_1, r_2$ in `zip(range(r_c-1), range(1, r_c))`:
            1.  Calculate indices $i_1$ (at $r_1$) and $i_2$ (at $r_2$) [S1, unofficial].
            2.  **Internal Face Logic:**
                *   If `filled[i1]` is true AND (`internal_faces` is true OR `filled[i2]` is false): Add the face between $i_1$ and $i_2$ to `voxel_faces[i1]` [S1, unofficial].
                *   If `filled[i2]` is true AND (`internal_faces` is true OR `filled[i1]` is false): Add the face between $i_2$ and $i_1$ to `voxel_faces[i2]` [S1, unofficial].
        iv. **Boundary Face Logic:** For the last index $r_c-1$:
            1.  Calculate index $i_k$ at $r_c-1$ and vertex position $p_{k2}$ at $r_c$ [S1, unofficial].
            2.  If `filled[ik]` is true, add the outer boundary face to `voxel_faces[ik]` [S1, unofficial].
6.  **Generate Geometry:** Iterate over `voxel_faces`. For each coordinate and list of face indices:
    a.  Convert indices to 3D positions using `x, y, z` arrays if provided, or use indices directly [S1, unofficial].
    b.  Create a `Poly3DCollection` for the faces [S1, unofficial].
    c.  Assign `facecolors` and `edgecolors` [S1, unofficial].
    d.  Add the collection to the axes [S1, unofficial].

**Pseudocode:**
```python
import numpy as np
from collections import defaultdict
from matplotlib.cbook import _backports

def voxels_internal_faces(ax, filled, x=None, y=None, z=None, internal_faces=False, facecolors=None, edgecolors=None):
    """
    Monkey-patched voxels method to render internal faces.
    """
    if filled.ndim != 3:
        raise ValueError("Argument filled must be 3-dimensional")
    
    size = np.array(filled.shape, dtype=np.intp)
    coord_shape = tuple(size + 1)
    
    if x is None:
        x, y, z = np.indices(coord_shape)
    else:
        x, y, z = (_backports.broadcast_to(c, coord_shape) for c in (x, y, z))

    # Handle colors
    def _broadcast_color_arg(color, name):
        if np.ndim(color) in (0, 1):
            return _backports.broadcast_to(color, filled.shape + np.shape(color))
        elif np.ndim(color) in (3, 4):
            if np.shape(color)[:3] != filled.shape:
                raise ValueError(f"When multidimensional, {name} must match the shape of filled")
            return color
        else:
            raise ValueError(f"Invalid {name} argument")

    if facecolors is None:
        facecolors = ax._get_patches_for_fill.get_next_color()
    facecolors = _broadcast_color_arg(facecolors, 'facecolors')
    
    if edgecolors is None:
        edgecolors = 'black' # Default edge color if not specified
    edgecolors = _broadcast_color_arg(edgecolors, 'edgecolors')

    ax.auto_scale_xyz(x, y, z)

    square = np.array([
        [0, 0, 0],
        [0, 1, 0],
        [1, 1, 0],
        [1, 0, 0]
    ], dtype=np.intp)

    voxel_faces = defaultdict(list)

    def permutation_matrices(n):
        mat = np.eye(n, dtype=np.intp)
        for _ in range(n):
            yield mat
            mat = np.roll(mat, 1, axis=0)

    for permute in permutation_matrices(3):
        pc, qc, rc = permute.T.dot(size)
        pinds = np.arange(pc)
        qinds = np.arange(qc)
        rinds = np.arange(rc)
        square_rot = square.dot(permute.T)

        for p in pinds:
            for q in qinds:
                p0 = permute.dot([p, q, 0])
                i0 = tuple(p0)
                if filled[i0]:
                    voxel_faces[i0].append(p0 + square_rot)

                for r1, r2 in zip(rinds[:-1], rinds[1:]):
                    p1 = permute.dot([p, q, r1])
                    p2 = permute.dot([p, q, r2])
                    i1 = tuple(p1)
                    i2 = tuple(p2)
                    
                    # Face between i1 and i2
                    if filled[i1] and (internal_faces or not filled[i2]):
                        voxel_faces[i1].append(p2 + square_rot)
                    
                    if filled[i2] and (internal_faces or not filled[i1]):
                        voxel_faces[i2].append(p2 + square_rot)

                # Upper boundary face
                pk = permute.dot([p, q, rc-1])
                pk2 = permute.dot([p, q, rc])
                ik = tuple(pk)
                if filled[ik]:
                    voxel_faces[ik].append(pk2 + square_rot)

    # Create Poly3DCollections
    for coord, faces_inds in voxel_faces.items():
        # Convert indices to 3D positions
        # Note: faces_inds contains vertex offsets relative to the voxel corner
        # We need to map the voxel coordinate to the actual grid position
        # The coordinate 'coord' is the index in the filled array (0..size-1)
        # The vertices are defined by the grid points (0..size)
        
        # Reconstruct vertices for this voxel
        # The logic in the source adds 'p2 + square_rot' to the face list.
        # 'p2' is the permuted coordinate of the neighbor.
        # We need to map these integer grid coordinates back to x, y, z values.
        
        vertices = []
        for face_verts in faces_inds:
            # face_verts is an array of 4 integer grid coordinates
            # Map to actual x,y,z
            pts = []
            for v in face_verts:
                # v is a tuple of indices (ix, iy, iz)
                # x, y, z are the coordinate arrays
                pts.append([x[v[0], v[1], v[2]], 
                           y[v[0], v[1], v[2]], 
                           z[v[0], v[1], v[2]]])
            vertices.append(np.array(pts))
        
        # Determine color for this voxel
        # coord is the index in filled array
        fc = facecolors[coord] if facecolors.ndim > 0 else facecolors
        ec = edgecolors[coord] if edgecolors.ndim > 0 else edgecolors
        
        poly = ax.add_collection3d(
            art3d.Poly3DCollection(vertices, facecolors=fc, edgecolors=ec, linewidths=0.5)
        )

    return ax
```

**Parameters:**
*   `internal_faces`: `False` by default. Set to `True` to render faces between adjacent filled voxels [S1, unofficial].
*   `filled`: 3D boolean NumPy array [S1, unofficial].
*   `facecolors`: 4D NumPy array $(X, Y, Z, 4)$ or broadcastable color [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Occlusion:** Standard Matplotlib `voxels` does not render internal faces, causing occluded voxels to be hidden [S1, unofficial].
*   **Performance:** Rendering all internal faces can be computationally expensive and visually cluttered for large volumes [S1, unofficial].
*   **Coordinate Mismatch:** If `x, y, z` are provided, they must have shape $(X+1, Y+1, Z+1)$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(V \cdot F)$, where $V$ is the number of voxels and $F$ is the number of faces per voxel (up to 6). The algorithm iterates through all voxel neighbors.
*   **Memory Complexity:** $O(V \cdot F)$ to store the `voxel_faces` dictionary and the resulting `Poly3DCollection` objects.
*   **Strengths:** Allows visualization of internal structure in transparent volumes [S1, unofficial].
*   **Limitations:** Can produce visually dense output; not suitable for large datasets without culling [S1, unofficial].
*   **When to use:** Debugging voxel data, visualizing internal structures in small transparent volumes [S1, unofficial].
*   **When not to use:** Large-scale volume rendering where performance is critical or visual clarity is preferred over completeness [S1, unofficial].

## Background
This technique was proposed as a solution to the limitation in Matplotlib's standard `voxels` method, which only renders surface faces [S1, unofficial]. The official Matplotlib example solves occlusion by offsetting voxel faces slightly, but this method explicitly generates internal faces via the `internal_faces` flag [S1, unofficial]. It was discussed in a Stack Overflow question and a Matplotlib issue regarding missing internal faces [S1, unofficial].
