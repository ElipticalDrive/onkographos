# Debug and Visualization


## Overview
This family renders auxiliary geometry and cross-sectional views to inspect the spatial extent, selection state, and internal structure of voxel data during rendering [S1, unofficial]. It solves the problem of spatial orientation and debugging by overlaying wireframes or slices onto the framebuffer, distinct from [Binary Volume Rendering (Opacity Thresholding)](1015-binary-volume-rendering-opacity-thresholding.md) which visualizes the volume content itself rather than its container or structure [G].

## Shared principles
All methods in this family operate on the principle of rendering auxiliary geometry or post-processing textures to provide visual feedback about the voxel data's location or bounds, without contributing to the final volumetric appearance [S1, S3, S4, unofficial]. They typically rely on standard OpenGL rasterization states (depth testing, blending) and simple geometric primitives (lines, triangles, quads) [G].

## Subtopics

### [Axis-Aligned Bounding Box Geometry](1317-axis-aligned-bounding-box-geometry.md)
Renders the clipped bounding box geometry of a volume extent to the framebuffer, optionally including texture coordinates. It defines the geometry for a bounding box using 36 vertices (12 triangles) to render the volume extent. The method operates on a fixed axis-aligned bounding box defined by minimum and maximum corner coordinates.

```python
def render_aabb_geometry(current_block, number_of_blocks, tcoord_flag, ren_win, min_b, max_b):
    # Step 1: Validate block index
    if current_block >= number_of_blocks:
        return True  # Abort rendering

    # Step 2: Generate VAO and VBO
    vao = allocate_vertex_array_object()
    vbo = allocate_vertex_buffer_object()

    # Step 3: Define vertices for AABB
    # 36 vertices (108 floats) for 12 triangles defining 6 faces of the AABB
    vertices = generate_box_vertices(min_b, max_b)

    # Step 4: Upload vertex data
    bind_buffer(GL_ARRAY_BUFFER, vbo)
    upload_buffer_data(GL_ARRAY_BUFFER, len(vertices) * 4, vertices, GL_STATIC_DRAW)

    # Step 5: Set vertex attribute pointer
    bind_vertex_array(vao)
    set_vertex_attribute_pointer(0, 3, GL_FLOAT, GL_FALSE, 3 * 4, None)
    enable_vertex_attribute_array(0)

    # Step 6: Render
    # Note: tcoordFlag is provided but texture coordinate generation is not specified in the sources.
    draw_arrays(GL_TRIANGLES, 0, 36)

    # Step 7: Cleanup
    delete_vertex_buffer_object(vbo)
    delete_vertex_array_object(vao)

    return False  # Continue rendering

def allocate_vertex_array_object():
    return {"id": 1}

def allocate_vertex_buffer_object():
    return {"id": 1}

def generate_box_vertices(min_b, max_b):

    verts.extend([min_b.x, min_b.y, max_b.z, max_b.x, min_b.y, max_b.z, max_b.x, max_b.y, max_b.z])
    verts.extend([min_b.x, min_b.y, max_b.z, max_b.x, max_b.y, max_b.z, min_b.x, max_b.y, max_b.z])
    # Back face (z = min_b.z)
    verts.extend([min_b.x, min_b.y, min_b.z, min_b.x, max_b.y, min_b.z, max_b.x, max_b.y, min_b.z])
    verts.extend([min_b.x, min_b.y, min_b.z, max_b.x, max_b.y, min_b.z, max_b.x, min_b.y, min_b.z])
    # Left face (x = min_b.x)
    verts.extend([min_b.x, min_b.y, min_b.z, min_b.x, max_b.y, min_b.z, min_b.x, max_b.y, max_b.z])
    verts.extend([min_b.x, min_b.y, min_b.z, min_b.x, max_b.y, max_b.z, min_b.x, min_b.y, max_b.z])
    # Right face (x = max_b.x)
    verts.extend([max_b.x, min_b.y, min_b.z, max_b.x, max_b.y, min_b.z, max_b.x, max_b.y, max_b.z])
    verts.extend([max_b.x, min_b.y, min_b.z, max_b.x, max_b.y, max_b.z, max_b.x, min_b.y, max_b.z])
    # Bottom face (y = min_b.y)
    verts.extend([min_b.x, min_b.y, min_b.z, max_b.x, min_b.y, min_b.z, max_b.x, min_b.y, max_b.z])
    verts.extend([min_b.x, min_b.y, min_b.z, max_b.x, min_b.y, max_b.z, min_b.x, min_b.y, max_b.z])
    # Top face (y = max_b.y)
    verts.extend([min_b.x, max_b.y, min_b.z, min_b.x, max_b.y, max_b.z, max_b.x, max_b.y, max_b.z])
    verts.extend([min_b.x, max_b.y, min_b.z, max_b.x, max_b.y, max_b.z, max_b.x, max_b.y, min_b.z])
```

### [Bounding Box Drawing](2733-bounding-box-drawing.md)
Renders the wireframe outline of an Axis-Aligned Bounding Box (AABB) to provide visual context for voxel data, such as highlighting a selected voxel or defining the volume's spatial extent. It differs from [Axis-Aligned Bounding Box Geometry](1317-axis-aligned-bounding-box-geometry.md) by explicitly using line primitives (edges) rather than filled geometry, and serves as a debug/visualization aid rather than contributing to the final volumetric appearance.

```python
def draw_bounding_box(min_pos, max_pos, view_matrix, projection_matrix, color=(1.0, 1.0, 1.0, 1.0)):
    """
    Draws a wireframe bounding box for the given AABB.
    """
    # 1. Setup State
    gl_push_attrib(GL_CURRENT_BIT | GL_ENABLE_BIT)
    gl_disable(GL_LIGHTING)
    gl_color4f(*color)
    gl_line_width(1.5)
    gl_enable(GL_LINE_SMOOTH)
    gl_hint(GL_LINE_SMOOTH_HINT, GL_NICEST)
    gl_enable(GL_BLEND)
    gl_blend_func(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA)
    gl_enable(GL_DEPTH_TEST)

    # 2. Define Vertices (24 vertices for 12 lines)
    # Corners of the box
    corners = [
        (min_pos.x, min_pos.y, min_pos.z), (max_pos.x, min_pos.y, min_pos.z),
        (max_pos.x, max_pos.y, min_pos.z), (min_pos.x, max_pos.y, min_pos.z),
        (min_pos.x, min_pos.y, max_pos.z), (max_pos.x, min_pos.y, max_pos.z),
        (max_pos.x, max_pos.y, max_pos.z), (min_pos.x, max_pos.y, max_pos.z)
    ]
    
    # Edges: 12 lines, each defined by 2 vertices
    edges = [
        (0, 1), (1, 2), (2, 3), (3, 0), # Bottom face
        (4, 5), (5, 6), (6, 7), (7, 4), # Top face
        (0, 4), (1, 5), (2, 6), (3, 7)  # Verticals
    ]
    
    # 3. Draw
    gl_begin(GL_LINES)
    for v1_idx, v2_idx in edges:
        gl_vertex3f(*corners[v1_idx])
        gl_vertex3f(*corners[v2_idx])
    gl_end()

    # 4. Cleanup
    gl_disable(GL_LINE_SMOOTH)
    gl_disable(GL_BLEND)
    gl_enable(GL_LIGHTING)
    gl_pop_attrib()
```

### Voxel Visualization
#### definition
Debug rendering technique that visualizes the 3D voxel texture by slicing it through a cube and displaying the resulting cross-sections on screen [S1, unofficial].

#### step
1. Create two framebuffers (`vvfbo1`, `vvfbo2`) with dimensions `viewportHeight` x `viewportWidth` [S1, unofficial].
2. Render the cube to `vvfbo1` with front-face culling enabled [S1, unofficial].
3. Render the cube to `vvfbo2` with back-face culling enabled [S1, unofficial].
4. Bind the default framebuffer, use the `voxel_visualization` shader, and upload camera matrices [S1, unofficial].
5. Activate `vvfbo1` as `textureBack` at unit 0, `vvfbo2` as `textureFront` at unit 1, and the 3D voxel texture as `texture3D` at unit 2 [S1, unofficial].
6. Set viewport to `viewportWidth` x `viewportHeight`, clear buffers, and render the quad [S1, unofficial].

## Background
The Voxel Visualization method and AABB geometry generation originate from the `voxel-cone-tracing` project [S1, unofficial]. Bounding Box Drawing reflects common OpenGL practices for selection feedback [G].
