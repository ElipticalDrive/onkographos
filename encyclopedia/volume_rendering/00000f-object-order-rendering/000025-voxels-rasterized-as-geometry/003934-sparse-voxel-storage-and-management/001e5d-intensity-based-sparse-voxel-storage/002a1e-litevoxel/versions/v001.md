# LiteVoxel

Also called: LiteVoxel training framework, LiteVoxel pipeline

## Overview
LiteVoxel is a self-tuning training framework for sparse-voxel rasterization that addresses edgedominated gradients, depth-coupled sampling bias, and unstable sparsity updates without adding neural modules or heavy priors [S1, unofficial]. It replaces fixed thresholds and myopic refinement with low-frequency-aware loss reweighting, depth-quantile pruning, and priority-driven subdivision to bound VRAM and improve low-frequency fidelity and boundary stability [S1, unofficial]. It matches SVRaster’s perceptual quality at 40–60% of peak VRAM, with less than 1% loss in PSNR, SSim, or LPIPS [S2, unofficial].

## How it works
LiteVoxel builds on [Intensity-based Sparse Voxel Storage](1775-intensity-based-sparse-voxel-storage.md) by introducing three coordinated modules: inverse-Sobel reweighted loss, depth-quantile pruning, and priority-driven subdivision [S1, unofficial].

### Inputs and Outputs
**Inputs:**
- Camera poses and intrinsics.
- Ground-truth images $I(x, y)$.
- SfM-initialized sparse voxel field [S1, unofficial].

**Outputs:**
- Optimized voxel field (centers, half-sizes, colors, opacities).
- Rendered images $\hat{C}(x, y)$.

### Data Structures
Each voxel $v$ stores:
- Center $x_v \in \mathbb{R}^3$.
- Half-size $h_v \in \mathbb{R}$.
- RGB color $\mathbf{c}_v \in [0, 1]^3$.
- Opacity $\alpha_v \in [0, 1]$ [S1, unofficial].

Voxels are organized in an octree where level $l$ cells have edge length $2^l h_0$, and $l_{\max}$ denotes the finest level [S1, unofficial].

### Rendering
Rays are traced from camera centers through pixel footprints. A primary ray is defined as [S1, unofficial]:

$$
\mathbf{r}(t) = o + t d(x, y), \quad t \geq 0.
$$

where $o \in \mathbb{R}^3$ is the camera center, $d(x,y) \in S^2$ is the unit direction through pixel $(x,y)$, and $t$ is ray distance [S1, unofficial].

Let $\{v_k\}_{k=1}^K$ be the voxels intersected by $\mathbf{r}(t)$, ordered front-to-back. Using standard alpha compositing [S1, unofficial]:

$$
T_0 = 1,
$$
$$
w_k = T_{k-1} \alpha_{v_k},
$$
$$
T_k = T_{k-1}(1 - \alpha_{v_k}),
$$
$$
\hat{C}(x, y) = \sum_{k=1}^K w_k \mathbf{c}_{v_k}.
$$

Here $T_k$ is accumulated transmittance, $w_k$ is voxel contribution, $\alpha_{v_k}$ is opacity, $\mathbf{c}_{v_k}$ is RGB color, and $K$ is the number of voxels intersected by the ray [S1, unofficial].

During rasterization, per-voxel statistics are gathered:
- Maximum blending weight:
$$
w_{\max}(v) = \max_{\text{rays } r \text{ hitting } v} \{T_{k(v,r)-1} \alpha_v\},
$$
where $w_{\max}(v)$ is the maximum blending weight observed for voxel $v$, serving as a proxy for voxel contribution/visibility [S1, unofficial].
- Local inter-ray spacing $\delta_v$: the image-plane footprint at voxel depth, used as a depth proxy [S1, unofficial].

### Training Loop
1. **Initialize:** Start from an SfM-initialized voxel field [S1, unofficial].
2. **Render:** Project voxels, rasterize, and compute $\hat{C}(x, y)$ using front-to-back alpha compositing [S1, unofficial].
3. **Loss:** Compute the photometric objective with inverse-Sobel reweighting (see below) [S1, unofficial].
4. **Back-propagate:** Update voxel parameters [S1, unofficial].
5. **Adapt:** Periodically prune and subdivide voxels (see below) [S1, unofficial].

### Inverse-Sobel Reweighted Loss
Standard photometric losses are edge-dominated, leaving flat regions under-optimized [S1, unofficial]. LiteVoxel reweights the loss to shift gradient focus to low-frequency regions after geometric stabilization [S1, unofficial].

1. Compute the Sobel filter magnitude on the ground-truth image $S$, producing $S_2$ [S2, unofficial].
2. Normalize $S_2$ to percentile-normalized Sobel magnitude $s(p) \in [0, 1]$ at pixel $p$, treating it as stop-grad [S1, unofficial].
3. Compute unnormalized weight:
$$
w(p) = (\varepsilon + 1 - s(p))^{\gamma(t)}, \quad \varepsilon \approx 10^{-3}.
$$
4. Apply mean normalization to stabilize gradient scale [S1, unofficial].
5. Apply $\gamma(t)$ ramp mid-training to gradually shift gradient budget to flat regions only after early geometry stabilizes [S1, unofficial].

### Depth-Quantile Pruning
Ad-hoc deletion with global thresholds is depth-biased (conservative far, over-zealous near silhouettes) [S1, unofficial]. LiteVoxel replaces this with depth-aware, adaptive quantile pruning [S1, unofficial].

1. Group voxels by a depth proxy into bins $V_b$ [S1, unofficial].
2. Compute empirical quantiles of $w_{\max}$ per bin [S2, unofficial].
3. Prune voxels with $w_{\max}(v)$ below the quantile cutoff $\tau_b$ [S1, unofficial].
4. Stabilize pruning using:
   - EMA-hysteresis guards [S1, unofficial].
   - Contour dilation (keep-halo) [S1, unofficial].
   - Per-step deletion cap to smooth deletion [S1, unofficial].

### Priority-Driven Subdivision
Myopic subdivision over-refines near geometry and ignores far voxels, inflating VRAM [S1, unofficial]. LiteVoxel drives subdivision by an image-resolution test and depth-aware priority [S1, unofficial].

1. **Eligibility:** A voxel $v$ is eligible for subdivision if it is not at the finest octree level and [S1, unofficial]:
$$
h_v > \kappa \delta_v, \quad \kappa \approx 1.
$$
This prevents refining regions that the camera cannot resolve [S1, unofficial].
2. **Priority:** Rank eligible voxels by depth-aware priority $p_v = u_v b(z_v)$, favoring far geometry [S1, unofficial].
3. **Selection:** Select splits under a global growth budget [S1, unofficial].
4. **Re-initialize:** Re-initialize the optimizer after subdivision [S1, unofficial].

### Pseudocode

```python
import numpy as np

def litevoxel_training_loop(voxels, cameras, images, config):
    """
    LiteVoxel training loop.
    
    Args:
        voxels: List of voxel objects with attributes:
            - center: np.array (3,)
            - half_size: float
            - color: np.array (3,)
            - opacity: float
            - level: int (octree level)
        cameras: List of camera objects with attributes:
            - origin: np.array (3,)
            - direction: np.array (3,) for each pixel
            - intrinsics
        images: List of ground-truth images (H, W, 3)
        config: Dictionary with hyperparameters:
            - epsilon: float (default 1e-3)
            - kappa: float (default 1.0)
            - tau_b: float (quantile cutoff)
            - gamma_t: function of training step t
            - max_level: int
            - growth_budget: int
            - ema_alpha: float
            - step_cap: int
    """
    # Initialize optimizer state for voxels
    optimizer = Adam(voxels.parameters())
    
    for step in range(config.max_steps):
        # 1. Render
        rendered_images = []
        voxel_stats = {}  # Store w_max and delta_v for each voxel
        
        for cam, gt_image in zip(cameras, images):
            # Trace rays and rasterize
            ray_origins = cam.origin
            ray_directions = cam.direction  # Shape (H, W, 3)
            
            # Get intersected voxels for each ray, ordered front-to-back
            # This is handled by the differentiable tile rasterizer
            # For pseudocode, we assume a function that returns sorted voxels per ray
            ray_voxels = rasterize(voxels, ray_origins, ray_directions)
            
            # Alpha compositing
            rendered_image = np.zeros_like(gt_image)
            for i in range(H):
                for j in range(W):
                    T = 1.0
                    for v in ray_voxels[i, j]:
                        w_k = T * v.opacity
                        T = T * (1 - v.opacity)
                        rendered_image[i, j] += w_k * v.color
                        
                        # Gather stats for w_max
                        if v not in voxel_stats:
                            voxel_stats[v] = {'w_max': 0.0, 'delta_v': 0.0}
                        current_w = T * v.opacity  # T_{k-1} * alpha_v
                        voxel_stats[v]['w_max'] = max(voxel_stats[v]['w_max'], current_w)
                        
                        # Compute delta_v (local inter-ray spacing)
                        # Approximate as footprint size at voxel depth
                        # delta_v = h_v / t_v * (pixel_size)
                        # For simplicity, assume delta_v is precomputed or approximated
                        voxel_stats[v]['delta_v'] = compute_delta_v(v, ray_directions[i, j])
                        
                    rendered_image[i, j] /= T if T > 0 else 1.0  # Normalize if T=0
            
            rendered_images.append(rendered_image)
        
        # 2. Loss Computation with Inverse-Sobel Reweighting
        loss = 0.0
        for rendered, gt in zip(rendered_images, images):
            # Compute Sobel magnitude on ground truth
            sobel_mag = compute_sobel_magnitude(gt)
            s_p = normalize_percentile(sobel_mag)  # Percentile-normalized, stop-grad
            
            # Compute inverse-Sobel weight
            epsilon = config.epsilon
            gamma = config.gamma_t(step)
            w_p = (epsilon + 1 - s_p) ** gamma
            
            # Mean normalization
            w_p_mean = np.mean(w_p)
            w_p_normalized = w_p / (w_p_mean + epsilon)
            
            # Photometric loss
            mse_loss = np.mean((rendered - gt) ** 2)
            weighted_mse = np.mean(w_p_normalized * (rendered - gt) ** 2)
            loss += weighted_mse
        
        # 3. Back-propagate
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # 4. Adaptation (Pruning and Subdivision)
        if step % config.adapt_interval == 0:
            adapt_voxels(voxels, voxel_stats, config)
    
    return voxels

def adapt_voxels(voxels, voxel_stats, config):
    """
    Perform depth-quantile pruning and priority-driven subdivision.
    """
    # Group voxels by depth proxy into bins
    depth_bins = group_by_depth(voxels)
    
    # Depth-Quantile Pruning
    voxels_to_prune = []
    for bin_voxels in depth_bins:
        w_max_values = [voxel_stats[v]['w_max'] for v in bin_voxels if v in voxel_stats]
        if not w_max_values:
            continue
        
        # Compute quantile cutoff
        cutoff = np.quantile(w_max_values, config.tau_b)
        
        for v in bin_voxels:
            if v in voxel_stats and voxel_stats[v]['w_max'] < cutoff:
                # Apply EMA-hysteresis guard
                if should_prune_with_hysteresis(v, config.ema_alpha):
                    voxels_to_prune.append(v)
    
    # Apply per-step cap
    voxels_to_prune = voxels_to_prune[:config.step_cap]
    for v in voxels_to_prune:
        remove_voxel(v)
    
    # Priority-Driven Subdivision
    eligible_voxels = []
    for v in voxels:
        if v.level < config.max_level:
            delta_v = voxel_stats[v]['delta_v'] if v in voxel_stats else 0.0
            if v.half_size > config.kappa * delta_v:
                # Compute priority
                priority = compute_priority(v)
                eligible_voxels.append((v, priority))
    
    # Sort by priority (descending)
    eligible_voxels.sort(key=lambda x: x[1], reverse=True)
    
    # Select splits under growth budget
    voxels_to_subdivide = [v for v, _ in eligible_voxels[:config.growth_budget]]
    for v in voxels_to_subdivide:
        subdivide_voxel(v)
    
    # Re-initialize optimizer
    reinitialize_optimizer()

def compute_priority(v):
    """
    Compute depth-aware priority.
    """
    # u_v: visibility or contribution proxy
    # b(z_v): depth-based weight favoring far geometry
    u_v = voxel_stats[v]['w_max'] if v in voxel_stats else 0.0
    z_v = v.center[2]  # Depth proxy
    b_z_v = 1.0 / (1.0 + z_v)  # Example: favor far geometry
    return u_v * b_z_v

def should_prune_with_hysteresis(v, ema_alpha):
    """
    EMA-hysteresis guard for pruning stability.
    """
    # Maintain EMA of w_max for each voxel
    if not hasattr(v, 'ema_w_max'):
        v.ema_w_max = voxel_stats[v]['w_max'] if v in voxel_stats else 0.0
    
    current_w_max = voxel_stats[v]['w_max'] if v in voxel_stats else 0.0
    v.ema_w_max = ema_alpha * current_w_max + (1 - ema_alpha) * v.ema_w_max
    
    # Hysteresis: prune only if EMA is significantly below cutoff
    # This prevents flickering
    return v.ema_w_max < 0.9 * np.quantile([voxel_stats[u]['w_max'] for u in group_by_depth([v])[0]], 0.5)

def reinitialize_optimizer():
    """
    Re-initialize optimizer state after subdivision.
    """
    # Clear optimizer states for new voxels
    pass
```

## Operating characteristics
- **VRAM Reduction:** LiteVoxel reduces peak VRAM by ~40–60% while preserving low-frequency detail and maintaining comparable PSNR, SSIM, training time, and FPS on Mip-NeRF 360 (6 scenes) and Tanks & Temples (3 scenes) [S1, unofficial]. It reduces peak VRAM by up to 60% (down to 7.9 GB from 12 GB) while maintaining PSNR ≈ 32.13 dB and SSIM ≈ 0.937 [S2, unofficial].
- **Quality:** Matches SVRaster’s perceptual quality at 40–60% of peak VRAM, with less than 1% loss in PSNR, SSIM, or LPIPS [S2, unofficial].
- **Performance:** Maintains comparable PSNR/SSIM/FPS to SVRaster baseline [S1, unofficial].
- **Strengths:** Mitigates low-frequency underfitting, depth-biased pruning, and myopic subdivision. Binds VRAM and model size while improving low-frequency fidelity and boundary stability [S1, unofficial].
- **Limitations:** Requires careful tuning of hyperparameters like $\gamma(t)$, $\kappa$, and $\tau_b$. EMA-hysteresis and per-step caps add complexity to the adaptation loop [S1, unofficial].
