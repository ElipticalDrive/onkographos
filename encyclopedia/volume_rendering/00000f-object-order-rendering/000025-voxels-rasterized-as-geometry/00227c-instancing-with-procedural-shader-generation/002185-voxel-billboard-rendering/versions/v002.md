# Voxel Billboard Rendering

Also called: Cloud Volume Billboard Rendering, Instanced Voxel Quad Rendering

## Overview
Voxel Billboard Rendering is a volume visualization technique that represents a 3D scalar field (such as a cloud volume) as a set of 2D quads (billboards) positioned at specific voxel locations within the volume grid [S1, unofficial]. It solves the problem of efficiently rendering volumetric data by converting it into geometry that can be processed by standard rasterization pipelines using instanced rendering [S1, unofficial]. Unlike [Binary Volume Rendering (Opacity Thresholding)](1015-binary-volume-rendering.md) which discards data below a threshold, or [Naive Voxel Rendering](1103-naive-voxel-rendering.md) which may render every voxel as a cube, this method explicitly generates billboard instances with per-instance position and scale attributes, relying on CPU-side sorting and generation rather than compute shaders or single large buffer storage [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- Volume resolution: $dimension$ (integer, assumed cubic $dimension \times dimension \times dimension$) [S1, unofficial].
- Volume bounds: $xBounds, yBounds, zBounds$ (each a `glm::vec2` representing min/max extents) [S1, unofficial].
- Billboard parameters: $count$ (number of billboards), $minOffset, maxOffset$ (bounding box for billboard placement), $minScale, maxScale$ (range for billboard size), $fluffiness$ (scale multiplier) [S1, unofficial].

**Outputs:**
- Rendered scene with billboards representing the volume [S1, unofficial].
- GPU buffers containing instanced position and scale data [S1, unofficial].

### Data Structures
The implementation relies on two primary data structures defined in the source [S1, unofficial]:

1.  **CloudVolume**:
    -   `dimension`: `int`
    -   `position`: `glm::vec3`
    -   `xBounds`, `yBounds`, `zBounds`: `glm::vec2`
    -   `levels`: `int` (number of mip levels)
    -   `volId`: `GLuint` (texture ID)
    -   `instancedQuad`: pointer to `Library::Quad`
    -   `instancedQuadPosVBO`: `GLuint` (Position VBO ID)
    -   `instancedQuadScaleVBO`: `GLuint` (Scale VBO ID)
    -   `range`: `glm::vec3`
    -   `voxelSize`: `glm::vec3`

2.  **Billboard Data**:
    -   `count`: `int`
    -   `positions`: `std::vector<glm::vec3>`
    -   `scales`: `std::vector<float>`
    -   `minOffset`: `glm::vec3`
    -   `maxOffset`: `glm::vec3`
    -   `minScale`: `float`
    -   `maxScale`: `float`
    -   `fluffiness`: `float`

### Numbered Steps

1.  **Initialization**:
    -   Create a 3D texture using `glGenTextures` and bind it with `glBindTexture(GL_TEXTURE_3D, volId)` [S1, unofficial].
    -   Allocate storage using `glTexStorage3D(GL_TEXTURE_3D, mips, GL_R8, dimension, dimension, dimension)` [S1, unofficial].
    -   Set filters: `GL_TEXTURE_MIN_FILTER` to `GL_LINEAR_MIPMAP_LINEAR`, `GL_TEXTURE_MAG_FILTER` to `GL_LINEAR` [S1, unofficial].
    -   Set wrap modes: `GL_TEXTURE_WRAP_S/T/R` to `GL_CLAMP_TO_EDGE` [S1, unofficial].
    -   Clear GPU memory with `glClearTexImage` for each mip level [S1, unofficial].
    -   Create an instanced quad geometry via `Library::createQuad()` [S1, unofficial].
    -   Bind the Vertex Array Object (VAO) [S1, unofficial].
    -   Create the position VBO (`instancedQuadPosVBO`) with size `sizeof(glm::vec3) * numVoxels` and usage `GL_DYNAMIC_DRAW` [S1, unofficial].
    -   Enable vertex attribute 2, set pointer to position VBO with stride `3 * sizeof(float)` and divisor 1 [S1, unofficial].
    -   Create the scale VBO (`instancedQuadScaleVBO`) with size `sizeof(float) * numVoxels` and usage `GL_DYNAMIC_DRAW` [S1, unofficial].
    -   Enable vertex attribute 3, set pointer to scale VBO with stride `sizeof(float)` and divisor 1 [S1, unofficial].

2.  **Billboard Generation**:
    -   Call `regenerateBillboards(count, minOffset, maxOffset, minScale, maxScale)` [S1, unofficial].
    -   Clear existing positions and scales [S1, unofficial].
    -   Loop `i` from 0 to `count-1`:
        -   Generate random position using `Util::genRandomVec3(minOffset.x, maxOffset.x, minOffset.y, maxOffset.y, minOffset.z, maxOffset.z)` [S1, unofficial].
        -   Generate random scale using `Util::genRandom(minScale, maxScale)` [S1, unofficial].
        -   Add to billboards list via `addCloudBoard(position, scale)` [S1, unofficial].

3.  **Billboard Sorting**:
    -   Call `sortBoards(point)` where `point` is the reference point (e.g., camera position) [S1, unofficial].
    -   Loop `i` from 0 to `billboards.count-1`:
        -   Initialize `minIdx = i` [S1, unofficial].
        -   Loop `j` from `i+1` to `billboards.count-1`:
            -   Calculate distance from camera/position to billboard `minIdx`: `d_min = glm::distance(this->position + billboards.positions[minIdx], point)` [S1, unofficial].
            -   Calculate distance from camera/position to billboard `j`: `d_j = glm::distance(this->position + billboards.positions[j], point)` [S1, unofficial].
            -   If `d_min > d_j`, set `minIdx = j` [S1, unofficial].
        -   If `i != minIdx`, swap positions and scales between index `i` and `minIdx` [S1, unofficial].

4.  **GPU Upload**:
    -   Call `uploadBillboards()` [S1, unofficial].
    -   If `billboards.count` is 0, return early to prevent overhead [S1, unofficial].
    -   Bind VAO [S1, unofficial].
    -   Bind position VBO [S1, unofficial].
    -   Upload `billboards.positions` data using `glBufferData` with size `sizeof(glm::vec3) * billboards.positions.size()` and data pointer `&billboards.positions[0]` [S1, unofficial].
    -   Bind scale VBO [S1, unofficial].
    -   If `fluffiness != 1.0f`, create a temporary `scales` vector where each element is `scale * fluffiness`; else, copy `billboards.scales` to `scales` [S1, unofficial].
    -   Upload `scales` data using `glBufferData` with size `sizeof(float) * scales.size()` and data pointer `&scales[0]` [S1, unofficial].
    -   Unbind VAO [S1, unofficial].

### Formulas
-   **Voxel Size Calculation**:
    $$voxelSize = range / dimension$$
    Where $range = (xBounds.y - xBounds.x, yBounds.y - xBounds.x, zBounds.y - zBounds.x)$ and $dimension$ is the volume resolution [S1, unofficial]. Note: The source text for $range$ components uses $xBounds.x$ for the second component's min, implying a consistent min-bound subtraction [S1, unofficial].

-   **3D Index to Cartesian Conversion**:
    $$x = voxelIndex.x \times range.x / dimension + xBounds.x$$
    $$y = voxelIndex.y \times range.y / dimension + xBounds.x$$
    $$z = voxelIndex.z \times range.z / dimension + zBounds.x$$
    Result is $glm::vec3(x, y, z)$ [S1, unofficial]. Note: The source explicitly uses $xBounds.x$ for the $y$-offset, which may be a specific implementation detail or error in the source, but is cited as written [S1, unofficial].

-   **Cartesian Index to 3D Index Conversion**:
    Given linear index $index$, $line = dimension$, $slice = dimension \times line$:
    $$z = index / slice$$
    $$y = (index - z \times slice) / line$$
    $$x = index - z \times slice - y \times line$$
    Result is $glm::ivec3(x, y, z)$ [S1, unofficial].

-   **Vertex Shader Transformation**:
    The model matrix $M$ is constructed from `voxelSize` (scale) and `voxelPosition` (translation):
    $$M = \begin{bmatrix} voxelSize.x & 0 & 0 & 0 \\ 0 & voxelSize.y & 0 & 0 \\ 0 & 0 & voxelSize.z & 0 \\ voxelPosition.x & voxelPosition.y & voxelPosition.z & 1.0 \end{bmatrix}$$
    Final position:
    $$gl\_Position = P \times V \times M \times vec4(vertPos, 1.0)$$
    Where $P$ is the projection matrix and $V$ is the view matrix [S1, unofficial].

### Parameters
-   **fluffiness**: A float multiplier applied to billboard scales during upload. If not 1.0, each scale is multiplied by this value before uploading to the GPU [S1, unofficial].
-   **voxelSize**: A uniform `vec3` passed to the vertex shader, representing the physical size of a single voxel in world units, derived from `range / dimension` [S1, unofficial].

### Edge Cases and Pitfalls
-   **Empty Billboard List**: If `billboards.count` is 0, `uploadBillboards()` returns early without binding buffers or uploading data, preventing unnecessary GPU overhead or errors [S1, unofficial].
-   **Precision**: The source uses `float` for positions and scales. Precision issues may arise with large volume bounds or very small voxel sizes, though specific mitigation is not detailed in the source [S1, unofficial].
-   **Boundary Conditions**: The use of `GL_CLAMP_TO_EDGE` for texture wrapping ensures that texture lookups at boundaries do not wrap around, which is critical for volume sampling [S1, unofficial].

### Pseudocode

```python
def init_cloud_volume(dimension, xBounds, yBounds, zBounds, mips):
    """
    Initialize the 3D texture and VAO/VBOs for voxel billboard rendering.
    """
    # Create 3D texture
    volId = glGenTextures(1)
    glBindTexture(GL_TEXTURE_3D, volId)
    glTexStorage3D(GL_TEXTURE_3D, mips, GL_R8, dimension, dimension, dimension)
    
    # Set filters
    glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_MIN_FILTER, GL_LINEAR_MIPMAP_LINEAR)
    glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_MAG_FILTER, GL_LINEAR)
    
    # Set wrap modes
    glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE)
    glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE)
    glTexParameteri(GL_TEXTURE_3D, GL_TEXTURE_WRAP_R, GL_CLAMP_TO_EDGE)
    
    # Clear GPU memory for each mip level
    for mip in range(mips):
        glClearTexImage(volId, mip, GL_RED, GL_UNSIGNED_BYTE, None)
        
    # Create instanced quad geometry
    instancedQuad = Library.createQuad()
    
    # Bind VAO
    vaoId = glGenVertexArrays(1)
    glBindVertexArray(vaoId)
    
    # Create position VBO
    instancedQuadPosVBO = glGenBuffers(1)
    glBindBuffer(GL_ARRAY_BUFFER, instancedQuadPosVBO)
    glBufferData(GL_ARRAY_BUFFER, 12 * dimension**3, None, GL_DYNAMIC_DRAW)
    
    # Enable vertex attribute 2 for position
    glEnableVertexAttribArray(2)
    glVertexAttribPointer(2, 3, GL_FLOAT, GL_FALSE, 12, None)
    glVertexAttribDivisor(2, 1)
    
    # Create scale VBO
    instancedQuadScaleVBO = glGenBuffers(1)
    glBindBuffer(GL_ARRAY_BUFFER, instancedQuadScaleVBO)
    glBufferData(GL_ARRAY_BUFFER, 4 * dimension**3, None, GL_DYNAMIC_DRAW)
    
    # Enable vertex attribute 3 for scale
    glEnableVertexAttribArray(3)
    glVertexAttribPointer(3, 1, GL_FLOAT, GL_FALSE, 4, None)
    glVertexAttribDivisor(3, 1)
    
    # Unbind
    glBindBuffer(GL_ARRAY_BUFFER, 0)
    glBindVertexArray(0)
    
    return volId, vaoId, instancedQuadPosVBO, instancedQuadScaleVBO

def regenerate_billboards(count, minOffset, maxOffset, minScale, maxScale):
    """
    Generate random billboards within specified bounds.
    """
    positions = []
    scales = []
    
    for i in range(count):
        pos = Util.genRandomVec3(minOffset.x, maxOffset.x, minOffset.y, maxOffset.y, minOffset.z, maxOffset.z)
        scale = Util.genRandom(minScale, maxScale)
        positions.append(pos)
        scales.append(scale)
        
    return positions, scales

def sort_billboards(positions, scales, point):
    """
    Sort billboards by distance to a reference point (e.g., camera).
    """
    count = len(positions)
    for i in range(count):
        minIdx = i
        for j in range(i + 1, count):
            dist_min = glm.distance(point, positions[minIdx])
            dist_j = glm.distance(point, positions[j])
            if dist_min > dist_j:
                minIdx = j
        if i != minIdx:
            positions[i], positions[minIdx] = positions[minIdx], positions[i]
            scales[i], scales[minIdx] = scales[minIdx], scales[i]
            
    return positions, scales

def upload_billboards(vaoId, posVBO, scaleVBO, positions, scales, fluffiness):
    """
    Upload billboard data to GPU.
    """
    if len(positions) == 0:
        return
        
    glBindVertexArray(vaoId)
    
    # Upload positions
    glBindBuffer(GL_ARRAY_BUFFER, posVBO)
    glBufferData(GL_ARRAY_BUFFER, 12 * len(positions), positions, GL_DYNAMIC_DRAW)
    
    # Upload scales
    glBindBuffer(GL_ARRAY_BUFFER, scaleVBO)
    if fluffiness != 1.0:
        adjusted_scales = [s * fluffiness for s in scales]
    else:
        adjusted_scales = scales
        
    glBufferData(GL_ARRAY_BUFFER, 4 * len(adjusted_scales), adjusted_scales, GL_DYNAMIC_DRAW)
    
    glBindVertexArray(0)

def render_billboards(vaoId, instancedQuad, count):
    """
    Render the instanced billboards.
    """
    glBindVertexArray(vaoId)
    # Assuming instancedQuad has base geometry setup
    # Draw instanced quads
    glDrawArraysInstanced(GL_TRIANGLES, 0, instancedQuad.vertex_count, count)
    glBindVertexArray(0)
```

## Subtopics

### [Binary Volume Rendering (Opacity Thresholding)](1015-binary-volume-rendering.md)
Uses a fixed opacity threshold to determine voxel visibility, discarding low-opacity data. Choose when memory bandwidth is limited and a binary representation is sufficient.

### [Naive Voxel Rendering](1103-naive-voxel-rendering.md)
Renders every voxel as a full cube. Choose for simplicity and when voxel count is low, but it suffers from overdraw and high geometry cost.

### [Instancing with Procedural/Shader Generation](2794-instancing-with-procedural-shader-generation.md)
Generates billboard positions and scales on the GPU using compute shaders or vertex shaders. Choose when CPU sorting is a bottleneck or for dynamic volumes.

### [Sparse Voxel Rasterization](3032-sparse-voxel-rasterization.md)
Uses a sparse data structure (like an SVO) to only render occupied voxels. Choose for large, sparse volumes to reduce memory and rendering cost.

## Operating characteristics
-   **Time Complexity**: Billboard generation is $O(N)$ where $N$ is the number of billboards. Sorting is $O(N^2)$ due to the selection sort implementation in the source [S1, unofficial]. GPU upload is $O(N)$. Rendering is $O(N)$ draw calls (or 1 instanced draw call) [S1, unofficial].
-   **Memory Complexity**: $O(N)$ for storing positions and scales on CPU and GPU [S1, unofficial].
-   **Measured Performance**: Not given in the sources [S1, unofficial].
-   **Scaling**: Performance degrades significantly with large $N$ due to the $O(N^2)$ sorting step. The method is suitable for moderate numbers of billboards [S1, unofficial].
-   **Strengths**: Simple implementation using standard OpenGL features; leverages instancing for efficient rendering; CPU-side sorting allows for depth-based rendering order [S1, unofficial].
-   **Limitations**: $O(N^2)$ sorting is inefficient for large $N$; relies on CPU for generation and sorting; does not handle occlusion culling efficiently [S1, unofficial].
-   **When to use**: Small to medium-sized volumes where simplicity is preferred and $N$ is manageable [S1, unofficial].
-   **When not to use**: Large-scale volumes requiring real-time performance with high $N$, or when GPU-side processing is available and preferred [S1, unofficial].

## Background
Voxel Billboard Rendering is described in the context of a cloud renderer implementation [S1, unofficial]. The specific implementation details, including the use of instanced rendering, CPU-side sorting, and the data structures involved, are derived from the `Cloud-Renderer` project by jaafersheriff [S1, unofficial]. The technique is presented as a method for visualizing volumetric data (specifically clouds) using geometry-based rendering rather than ray-marching or texture-based volume rendering [S1, unofficial].
