# Surface-based Instancing with Noise Modulation

Also called: Instanced surface points, Surface primitive instancing

## Overview
Surface-based instancing with noise modulation generates high-density point clouds from surface primitives to achieve smooth volumetric appearance at high resolutions [S1, unofficial]. It differs from sibling methods by explicitly instantiating a massive number of points (e.g., ~400 million) per primitive and modulating their density or position using procedural noise functions before rasterization or voxelization [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A mesh primitive defined by a grid of vertices with attributes (position, normal, velocity, thickness, derivatives) [S1, unofficial]. Parameters include `numCols`, `numRows`, `numPoints` (total instances per primitive), `instanceRadius`, noise scales (`densScale`, `dispScale`), noise amplitudes, and fractal noise evaluators (`densFractal`, `dispFractal`) [S1, unofficial].
- **Output:** A set of instanced points with world-space positions, density vectors, and radii [S1, unofficial].

**Data Structures:**
- **Mesh Attributes:** Stored per mesh piece. Includes `numCols`, `numRows`, and vertex attributes indexed by $(s, t)$ coordinates [S1, unofficial].
- **Point Attributes:** Stored per instance. Includes `position` (Vector3), `density` (Vector3), and `radius` (Float) [S1, unofficial].
- **Noise Evaluators:** Objects providing `eval()` for scalar noise and `evalVec()` for vector noise [S1, unofficial].

**Numbered Steps:**
1. **Initialize:** For each mesh piece, update mesh attributes and calculate `numPoints = numCols * numRows` [S1, unofficial]. Initialize a random number generator with a seed [S1, unofficial].
2. **Loop Instances:** For each instance index $i$ from $0$ to `numPoints - 1`:
    a. **Generate Local Position:** Generate a random local space position $lsP = (lsP_x, lsP_y, lsP_z)$ using three uniform random floats in $[0, 1]$ [S1, unofficial].
    b. **Map to Surface Parameters:** Calculate surface parameters $s$ and $t$:
        $$s = lsP_x \times (numCols - 1)$$
        $$t = lsP_y \times (numRows - 1)$$
    c. **Interpolate Attributes:** Interpolate instance attributes at $(s, t)$ using bilinear or spline interpolation (macro `SURFACE_INST_INTERP`):
        - $instanceDensity$: Density vector.
        - $instanceWsP$: World space position.
        - $instanceWsV$: World space velocity.
        - $wsN$: Normal vector (normalized).
        - $wsDPds$: Derivative with respect to $s$.
        - $wsDPdt$: Derivative with respect to $t$.
        - $thickness$: Scalar thickness.
    d. **Offset Position:** Offset the world space position along the normal based on the local $z$ coordinate:
        $$instanceWsP += \text{fit01}(lsP_z, -1.0, 1.0) \times wsN \times thickness$$
        Where $\text{fit01}(v, min, max)$ maps $v$ from $[min, max]$ to $[0, 1]$ [S1, unofficial].
    e. **Apply Density Noise (if enabled):**
        i.  Calculate noise lookup position: $nsLookupP = lsP / densScale$ [S1, unofficial].
        ii. Evaluate scalar noise: $noise = densFractal.eval(nsLookupP)$ [S1, unofficial].
        iii. Calculate edge fade: $fade = edgeFade(lsP_x, lsP_y, lsP_z)$ [S1, unofficial].
        iv. Update density: $instanceDensity *= noise + fade$ [S1, unofficial].
    f. **Apply Displacement Noise (if enabled):**
        i.  Calculate noise lookup position: $nsLookupP = lsP / dispScale$ [S1, unofficial].
        ii. Evaluate vector noise: $disp = dispFractal.evalVec(nsLookupP)$ [S1, unofficial].
        iii. Update position by adding components along tangent, bitangent, and normal:
        $$instanceWsP += disp.x \times wsDPds \times thickness \times dispAmplitude$$
        $$instanceWsP += disp.y \times wsDPdt \times thickness \times dispAmplitude$$
        $$instanceWsP += disp.z \times wsN \times thickness \times dispAmplitude$$ [S1, unofficial].
    g. **Set Instance Attributes:**
        - Position: $instanceWsP$
        - Density: $instanceDensity$
        - Radius: $instanceRadius$ [S1, unofficial].

**Pseudocode:**
```python
import random
import math

def surface_based_instancing(mesh, params):
    """
    Generates instanced points from surface primitives with noise modulation.
    mesh: object with num_cols, num_rows, and methods get_attr(s, t) returning Vector3/float
    params: object with num_points, seed, dens_scale, disp_scale, disp_amplitude, 
            do_dens_noise, do_disp_noise, dens_fractal, disp_fractal, instance_radius
    """
    points = []
    num_cols = mesh.num_cols
    num_rows = mesh.num_rows
    num_points = params.num_points
    
    # Initialize random number generator
    random.seed(params.seed)
    
    for _ in range(num_points):
        # 1. Generate random local space position
        lsP_x = random.random()
        lsP_y = random.random()
        lsP_z = random.random()
        
        # 2. Map to surface parameters
        s = lsP_x * (num_cols - 1)
        t = lsP_y * (num_rows - 1)
        
        # 3. Interpolate instance attributes
        instance_density = mesh.get_attr("density", s, t)
        instance_ws_p = mesh.get_attr("wsP", s, t)
        instance_ws_v = mesh.get_attr("wsVelocity", s, t)
        ws_n = normalize(mesh.get_attr("wsNormal", s, t))
        # [G] Surface derivatives dPds/dPdt are typically precomputed or computed from grid vertices
        ws_dpds = mesh.get_attr("dPds", s, t)
        ws_dpdt = mesh.get_attr("dPdt", s, t)
        thickness = mesh.get_attr("thickness", s, t)
        
        # 4. Offset position along normal
        z_factor = fit01(lsP_z, -1.0, 1.0)
        instance_ws_p = instance_ws_p + z_factor * ws_n * thickness
        
        # 5. Apply density noise
        if params.do_dens_noise:
            ns_lookup_p = Vector3(lsP_x, lsP_y, lsP_z) / params.dens_scale
            noise = params.dens_fractal.eval(ns_lookup_p)
            fade = edge_fade(lsP_x, lsP_y, lsP_z)
            instance_density = instance_density * (noise + fade)
            
        # 6. Apply displacement noise
        if params.do_disp_noise:
            ns_lookup_p = Vector3(lsP_x, lsP_y, lsP_z) / params.disp_scale
            disp = params.disp_fractal.eval_vec(ns_lookup_p)
            amp = params.disp_amplitude
            instance_ws_p = instance_ws_p + disp.x * ws_dpds * thickness * amp
            instance_ws_p = instance_ws_p + disp.y * ws_dpdt * thickness * amp
            instance_ws_p = instance_ws_p + disp.z * ws_n * thickness * amp
            
        # 7. Set instance attributes
        points.append({
            "position": instance_ws_p,
            "density": instance_density,
            "radius": params.instance_radius
        })
        
    return points

def fit01(value, min_val, max_val):
    """Maps value from [min_val, max_val] to [0, 1]."""
    if max_val == min_val:
        return 0.0
    return (value - min_val) / (max_val - min_val)

def edge_fade(x, y, z):
    """
    Fades out points near the boundaries of the local space.
    [G] Standard boundary fade implementation since source does not specify the exact formula.
    """
    dist = max(abs(x - 0.5), abs(y - 0.5), abs(z - 0.5))
    return max(0.0, 1.0 - 2.0 * dist)

def normalize(v):
    """Normalizes a 3D vector."""
    mag = math.sqrt(v.x**2 + v.y**2 + v.z**2)
    if mag == 0:
        return Vector3(0, 0, 0)
    return Vector3(v.x / mag, v.y / mag, v.z / mag)

class Vector3:
    def __init__(self, x, y, z):
        self.x = x
        self.y = y
        self.z = z
    def __add__(self, other):
        return Vector3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __mul__(self, scalar):
        return Vector3(self.x * scalar, self.y * scalar, self.z * scalar)
    def __truediv__(self, scalar):
        return Vector3(self.x / scalar, self.y / scalar, self.z / scalar)
```

**Parameters:**
- `numPoints`: Number of output points per primitive. Typically ~400 million for smooth results at 1024x1024 resolution [S1, unofficial].
- `voxelBufferResolution`: Frustum-shaped buffer dimensions ~1200x1200x250 [S1, unofficial].
- `densScale`, `dispScale`: Scaling factors for noise lookup [S1, unofficial].
- `dispAmplitude`: Amplitude for displacement noise [S1, unofficial].
- `instanceRadius`: Radius of each instanced point [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Wasteful Evaluation:** Noise-modulated primitives are computationally wasteful because a point must be instantiated, its noise space position calculated, and the full fractal noise function evaluated before determining if it should be culled due to zero density [S1, unofficial].
- **Boundary Conditions:** The `edgeFade` function is required to handle boundaries, but its exact implementation is not specified in the source [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources. Each point requires noise evaluation, which can be expensive for fractal noise [S1, unofficial].
- **Memory Complexity:** Not given in the sources. Storing ~400 million points per primitive requires significant memory [S1, unofficial].
- **Performance:** Requires high-resolution voxel buffers (~1200x1200x250) and large point counts for smooth results [S1, unofficial]. The noise evaluation step is a bottleneck [S1, unofficial].
- **Strengths:** Achieves smooth volumetric appearance with high detail through noise modulation [S1, unofficial].
- **Limitations:** High computational cost due to massive point counts and noise evaluation. Inefficient culling as noise must be evaluated before culling [S1, unofficial].

## Background
Originated in production volume rendering pipelines, specifically for simulating effects like pyroclastic flows using surface primitives [S1, unofficial]. The technique is described in "Production Volume Rendering" [S1, unofficial]. It is used in conjunction with level set modeling for tracking interfaces [S1, unofficial].
