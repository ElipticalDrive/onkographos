# Volumetric Spot Noise Rendering

Also called: Hybrid Rendering Pipeline, Shell Spot Noise, Shell noise, Volumetric Shell Spot Noise, Volumetric Spot Noise Rendering Pipeline, Volumetric Spot Noise for Procedural 3D Shell Texture Synthesis, Volumetric fuzzy details synthesis

## Overview
Volumetric Spot Noise Rendering is an interactive method for synthesizing procedural 3D shell textures (volumetric surface details like hair, grass, or fur) by projecting random impulse distributions onto arbitrary surfaces and rendering them as sums of anisotropic Gaussian kernels [S1, unofficial][S2, unofficial]. It solves the problem of efficiently rendering millions of semi-transparent, oriented primitives without the performance penalty of per-frame depth sorting or the aliasing artifacts of simple geometry instancing [S1, unofficial][S2, unofficial]. It sets itself apart from its parent [3D Gaussian Splatting via Instancing](1586-3d-gaussian-splatting-via-instancing.md) by using a hybrid pipeline that combines geometry instancing for depth/opacity with EWA splatting and Order Independent Transparency (OIT) for color, specifically addressing the "popping" and "halo" artifacts common in pure OIT or sorting-based approaches [S1, unofficial][S2, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   A 3D mesh surface [S1, unofficial][S2, unofficial].
*   A set of impulses, each defined by position $\mathbf{M}$, orientation $\mathbf{R}$ (rotation matrix), scale $\mathbf{S}$, and color $\mathbf{C}$ [S2, unofficial].
*   Kernel parameters: number of Gaussian components per kernel (typically up to 3) [S1, unofficial].

**Outputs:**
*   A final color buffer with anti-aliased, depth-corrected volumetric appearance [S1, unofficial][S2, unofficial].

### Data Structures
**Impulse Texture:**
A 2D texture of size $4046 \times 4046$ texels [S2, unofficial]. Each impulse occupies 6 consecutive texels [S2, unofficial].
*   **Texel 0:** Position $\mathbf{M}$ (vec3, 0 padding) [S2, unofficial].
*   **Texel 1:** Rotation Column 0 $\mathbf{R}_0$ (vec3, 0 padding) [S2, unofficial].
*   **Texel 2:** Rotation Column 1 $\mathbf{R}_1$ (vec3, 0 padding) [S2, unofficial].
*   **Texel 3:** Rotation Column 2 $\mathbf{R}_2$ (vec3, 0 padding) [S2, unofficial].
*   **Texel 4:** Scale $\mathbf{S}$ (vec3, 0 padding) [S2, unofficial].
*   **Texel 5:** Color $\mathbf{C}$ (vec4) [S2, unofficial].

**Accumulation Framebuffer:**
*   **Attachment 0 (Color):** `GL_RGBA32F` [S2, unofficial].
*   **Attachment 1 (Count/Alpha):** `GL_R8` [S2, unofficial].
*   **Depth:** `GL_DEPTH_COMPONENT32` [S2, unofficial].
*   **Resolution:** $1024 \times 1024$ (or target screen resolution) [S2, unofficial].

### Steps

1.  **Impulse Generation:**
    If impulses are not pre-generated, they are placed on the surface [S1, unofficial][S2, unofficial]. An octree partitions the space around the mesh [S1, unofficial][S2, unofficial]. For each leaf node (voxel) colliding with the mesh, 15 impulses are generated at the collision point with slight displacements [S2, unofficial]. The position is projected onto a plane approximating the surface using the nearest face normal [S1, unofficial][S2, unofficial]. Orientation is derived from the normal and random vectors [S2, unofficial]. Scale and color are sampled randomly [S2, unofficial].

2.  **Geometry Instancing Pass (Depth/Opacity):**
    Render the impulse primitives using geometry instancing to populate the depth buffer [S1, unofficial][S2, unofficial]. This pass determines the closest kernel for each pixel, which is used later for the "Improved OIT" calculation [S1, unofficial][S2, unofficial].
    *   Enable depth writing [S2, unofficial].
    *   Disable color writing [S2, unofficial].
    *   Draw instanced primitives [S2, unofficial].

3.  **EWA Splatting Pass (Color Accumulation):**
    Render the impulses again, but this time accumulating color and coverage using EWA splatting and OIT [S1, unofficial][S2, unofficial].
    *   Disable depth writing [S2, unofficial].
    *   Enable blending [S2, unofficial].
    *   **Attachment 0 (Color):** Blend function `GL_ONE + GL_ONE` (additive) [S2, unofficial].
    *   **Attachment 1 (Count):** Blend function `GL_ZERO + GL_ONE_MINUS_SRC_COLOR` (subtractive from 1.0, effectively counting hits/alpha) [S2, unofficial].
    *   Clear Attachment 0 to black and Attachment 1 to white (1.0) [S2, unofficial].
    *   Draw instanced primitives using the 'accum' shader [S2, unofficial].

4.  **Compositing Pass:**
    *   Bind the default framebuffer [S2, unofficial].
    *   Clear color and depth [S2, unofficial].
    *   Draw the solid mesh (black) to occlude volume behind it [S2, unofficial].
    *   Disable depth testing [S2, unofficial].
    *   Enable blending `GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA` [S2, unofficial].
    *   Draw a full-screen quad using the 'composite' shader, sampling accumulated color from Attachment 0 and count/alpha from Attachment 1 [S2, unofficial].

### Formulas

**3D Gaussian Kernel:**
The kernel for an impulse is defined as [S2, unofficial]:
$$
K(\mathbf{x}; \mathbf{x}_0) = \frac{\exp\left(-\frac{1}{2}(\mathbf{x}-\mathbf{x}_0)^T \Sigma^{-1} (\mathbf{x}-\mathbf{x}_0)\right)}{\sqrt{(2\pi)^3 |\Sigma|}}
$$
where $\mathbf{x}_0$ is the center, and $\Sigma = \mathbf{R} \mathbf{S} \mathbf{S}^T \mathbf{R}^T$ is the covariance matrix, with $\mathbf{R}$ being the orientation matrix and $\mathbf{S}$ the scale matrix (diagonal) [S2, unofficial].

**Perspective Divide Approximation:**
To handle the non-linearity of the perspective divide, an affine approximation using the Jacobian $J$ is used [S2, unofficial]:
$$
J = \frac{\partial m}{\partial \mathbf{x}} = \begin{bmatrix} 1/x_3 & 0 & -x_1/x_3^2 \\ 0 & 1/x_3 & -x_2/x_3^2 \\ x_1/|\mathbf{x}| & x_2/|\mathbf{x}| & x_3/|\mathbf{x}| \end{bmatrix}
$$
where $m$ maps camera space to screen space [S2, unofficial].

**Transformed Covariance:**
The covariance in screen space is approximated by [S2, unofficial]:
$$
\Sigma' = J \mathbf{W}_{3\times 3} \Sigma \mathbf{W}_{3\times 3}^T J^T
$$
where $\mathbf{W}_{3\times 3}$ is the rotational component of the world-to-camera transformation [S2, unofficial].

**Screen-Space Variance and Filter:**
The 2D variance matrix $\Sigma'_{2\times 2}$ is the top-left $2\times 2$ partition of $\Sigma'$ [S2, unofficial]. To avoid aliasing, a low-pass filter (identity matrix scaled by $\lambda$) is added [S2, unofficial]:
$$
Q = (\Sigma'_{2\times 2} + \lambda \mathbf{I})^{-1}
$$
The scale factor for the Gaussian is:
$$
\text{scalefactor} = \frac{1}{\sqrt{2\pi \det(Q)}}
$$
[S2, unofficial].

**Per-Pixel Weight and Accumulation:**
The distance $d$ in screen space is computed as $d = \mathbf{disp}^T Q \mathbf{disp}$, where $\mathbf{disp}$ is the displacement from the kernel center in NDC space scaled by 1024.0 [S2, unofficial]. The alpha contribution is:
$$
a_i = \min(1.0, \text{scalefactor} \cdot e^{-0.5 \cdot d})
$$
[S2, unofficial].

The final weight $w$ for OIT combines color, alpha, and depth [S2, unofficial]:
$$
w = \max(\min(1.0, \max(c_r, c_g, c_b) \cdot a_i \cdot c_a), a_i \cdot c_a) \cdot \text{clamp}\left(\frac{0.03}{10^{-5} + (U_z/200.0)^4}, 10^{-2}, 3 \times 10^3\right)
$$
where $c$ is the spot color, $U_z$ is the camera-space depth, and $\alpha$ is implicitly handled by $a_i$ and $c_a$ [S2, unofficial].

**Improved OIT Final Color:**
To fix artifacts with opaque kernels, the closest kernel's contribution is maximized using the depth buffer from Step 2 [S1, unofficial]:
$$
L \approx \tilde{K}(\mathbf{d}, \mathbf{p}_f) \alpha_f + \left( \frac{\sum_{i=0}^{N-1} L_{\mathcal{C}_i}}{\sum_{i=0}^{N-1} \sum_{\mathbf{p}_j \in \mathcal{C}_i^*} T(\mathbf{p}_j)} \right) (1 - \alpha_f)
$$
where $\mathbf{p}_f$ is the closest impulse and $\alpha_f$ its transparency [S1, unofficial].

### Pseudocode

```python
def diag(vals):
    """Create a diagonal matrix from a list of values."""
    n = len(vals)
    return [[vals[i] if i == j else 0.0 for j in range(n)] for i in range(n)]

def mat3_from_cols(c0, c1, c2):
    """Construct a 3x3 matrix from three column vectors."""
    return [[c0[0], c1[0], c2[0]], [c0[1], c1[1], c2[1]], [c0[2], c1[2], c2[2]]]

def mat_mul(A, B):
    """Multiply two 3x3 matrices."""
    return [[sum(A[i][k]*B[k][j] for k in range(3)) for j in range(3)] for i in range(3)]

def mat_mul_vec(M, v):
    """Multiply a 3x3 matrix by a 3D vector."""
    return [sum(M[i][j]*v[j] for j in range(3)) for i in range(3)]

def inverse_2x2(m):
    """Invert a 2x2 matrix."""
    det = m[0][0]*m[1][1] - m[0][1]*m[1][0]
    return [[m[1][1]/det, -m[0][1]/det], [-m[1][0]/det, m[0][0]/det]]

def vertex_shader_accumulation(instance_id, mvp_matrix, impulses_texture):
    id_offset = instance_id * 6
    tex_x = id_offset % 4046
    tex_y = id_offset // 4046

    M = impulses_texture[tex_x, tex_y][:3]
    R0 = impulses_texture[tex_x+1, tex_y][:3]
    R1 = impulses_texture[tex_x+2, tex_y][:3]
    R2 = impulses_texture[tex_x+3, tex_y][:3]
    S = impulses_texture[tex_x+4, tex_y][:3]
    C = impulses_texture[tex_x+5, tex_y]

    R = mat3_from_cols(R0, R1, R2)
    S_diag = diag(S)
    Sigma = mat_mul(mat_mul(R, S_diag), mat_mul(R, S_diag)) # Simplified: R * diag(S) * R^T * diag(S) is not standard. 
    # Correct covariance: Sigma = R * diag(S.x^2, S.y^2, S.z^2) * R^T
    S_sq_diag = diag([s*s for s in S])
    Sigma = mat_mul(mat_mul(R, S_sq_diag), mat_mul(R, S_sq_diag)) # Wait, R * S_sq * R^T. Transpose of R is R.T.
    # Let's fix to standard: Sigma = R @ S_sq @ R.T
    R_T = [[R[j][i] for i in range(3)] for j in range(3)]
    Sigma = mat_mul(mat_mul(R, S_sq_diag), R_T)

    M_cam = mat_mul_vec(mvp_matrix, M) # Simplified MVP application
    x1, x2, x3 = M_cam

    norm_U = (x1*x1 + x2*x2 + x3*x3)**0.5
    J = [[1.0/x3, 0.0, -x1/(x3*x3)],
         [0.0, 1.0/x3, -x2/(x3*x3)],
         [x1/norm_U, x2/norm_U, x3/norm_U]]

    W_3x3 = mvp_matrix[:3] # Extract 3x3 rotation/scale from MVP
    Sigma_prime = mat_mul(mat_mul(mat_mul(J, W_3x3), Sigma), mat_mul(W_3x3, J)) # J W Sigma W^T J^T

    Sigma_2x2 = [row[:2] for row in Sigma_prime[:2]]
    Q = inverse_2x2([[Sigma_2x2[0][0]+1.0, Sigma_2x2[0][1]], [Sigma_2x2[1][0], Sigma_2x2[1][1]+1.0]])

    det_Q = Q[0][0]*Q[1][1] - Q[0][1]*Q[1][0]
    scalefactor = 1.0 / (2.0 * 3.14159265 * det_Q)**0.5

    ndc_x = x1 / x3
    ndc_y = x2 / x3

    return Q, scalefactor, ndc_x, ndc_y, x3, C

def fragment_shader_accumulation(Q, scalefactor, ndc_x, ndc_y, U_z, color, screen_pos):
    disp_x = screen_pos[0] - ndc_x * 1024.0
    disp_y = screen_pos[1] - ndc_y * 1024.0
    disp = [disp_x, disp_y]

    Q_disp = [Q[0][0]*disp[0] + Q[0][1]*disp[1], Q[1][0]*disp[0] + Q[1][1]*disp[1]]
    d = disp[0]*Q_disp[0] + disp[1]*Q_disp[1]

    a_i = min(1.0, scalefactor * (-0.5 * d)**0.5) # exp(-0.5*d)
    # Correct exp:
    import math
    a_i = min(1.0, scalefactor * math.exp(-0.5 * d))

    max_c = max(color[0], max(color[1], color[2]))
    depth_factor = 0.03 / (1e-5 + (U_z/200.0)**4)
    depth_factor = max(0.01, min(3000.0, depth_factor))

    w = max(min(1.0, max_c * a_i * color[3]), a_i * color[3]) * depth_factor

    accum_out = [color[0]*w, color[1]*w, color[2]*w, w]
    count_out = 1.0 - w

    return accum_out, count_out
```

### Parameters
*   **Impulse Texture Resolution:** $4046 \times 4046$ [S2, unofficial].
*   **Texels per Impulse:** 6 [S2, unofficial].
*   **Octree Radius Threshold:** 0.2 (for impulse generation) [S2, unofficial].
*   **Impulses per Collision:** 15 [S2, unofficial].
*   **Viewport Scaling Factor:** 1024.0 (for NDC conversion) [S2, unofficial].
*   **Depth Falloff Clamp:** $[10^{-2}, 3 \times 10^3]$ [S2, unofficial].
*   **Lighting Multiplier:** 0.06 [S2, unofficial].
*   **Slices ($N_s$):** Controls precision of kernel evaluation for semi-transparent kernels (5-60+ fps depending on density) [S1, unofficial].

### Edge Cases and Pitfalls
*   **Aliasing:** The perspective divide is non-linear. Using the Jacobian approximation prevents the kernel from losing its Gaussian shape [S2, unofficial].
*   **Popping Artifacts:** Avoided by using depth-weighted OIT instead of per-frame sorting [S2, unofficial].
*   **Halos:** Lighter bands around objects due to excessive blending in OIT. Mitigated by adjusting the weight function [S2, unofficial].
*   **Z-Fighting:** Geometry instancing alone causes z-fighting for small kernels. The hybrid approach mitigates this by using EWA splatting for color [S1, unofficial].
*   **Triangle Sampling:** Barycentric coordinates must be clamped to keep points within triangles during impulse generation [S2, unofficial].
*   **Texture Wrapping:** Instance IDs must be correctly mapped to texture coordinates using modulo 4046. Exceeding texture capacity causes incorrect wrapping [S2, unofficial].
*   **Division by Zero:** Jacobian calculation requires $U_z > 0$ (camera-space depth) [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Interactive. Performance depends on kernel density and viewpoint. Flat kernels: 5-60+ fps. Semi-transparent volumetric kernels: 55 fps (2.5k kernels) to 1.5 fps (300k kernels) [S1, unofficial].
*   **Memory Complexity:** Extremely low. Memory footprint depends on kernel definition (few kilobytes), not the number of impulses [S1, unofficial].
*   **Strengths:** Handles millions of kernels interactively; parameterization-free surface projection; avoids sorting overhead; reduces aliasing compared to instancing [S1, unofficial][S2, unofficial].
*   **Limitations:** OIT can introduce halos; complex semi-transparent structures require more slices ($N_s$), reducing FPS; depth precision issues with very small kernels [S1, unofficial][S2, unofficial].
*   **When to Use:** Procedural hair, grass, fur, and fuzzy surface details where performance and visual quality (anti-aliasing) are critical [S1, unofficial][S2, unofficial].
*   **When Not to Use:** Scenes requiring exact depth peeling or where simple opaque instancing suffices [S1, unofficial].

## Background
Volumetric Spot Noise Rendering was introduced by Nicolas Pavie et al. in the paper "Volumetric Spot Noise for Procedural 3D Shell Texture Synthesis" [S1, unofficial][S2, unofficial]. It extends Locally Controlled Spot Noise (LCSN) to model volumetric surface details using 3D kernels [S1, unofficial]. The method builds on EWA volume splatting [ZPvBG01] and Depth Weighted Order Independent Transparency by McGuire and Bavoil [S2, unofficial]. It is used for rendering hair and grass textures [S2, unofficial].
