# Geometry Shader Advanced Instancing for Cubes

Also called: Frustum Culling in Projection Space, GS Cube Instancing

## Overview
This method uses a geometry shader to generate cube meshes from instanced points, optimizing for visibility by emitting at most 12 vertices (3 quads) per cube [S1, unofficial]. It leverages backface culling and frustum culling in projection space to avoid generating geometry for invisible or occluded faces [S1, unofficial]. Unlike creating full 24-vertex cubes, this approach reduces vertex count by half because backface culling always removes one of two opposite faces [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A point sprite representing a voxel center $(x, y, z)$ and instance attributes (e.g., `VoxelCode` for face visibility masks).
*   **Output:** A triangle strip representing the visible faces of the cube.

**Data Structures:**
*   **Precomputed Corner Vectors:** Constant vectors representing the 8 corners of a unit cube centered at the origin, transformed into projection space relative to the camera. These are added to the transformed center position. Let $c\_vCorner_{ijk}$ be the precomputed vector for corner $(i,j,k)$ where $i,j,k \in \{0,1\}$ [S1, unofficial].
*   **Instance Data:** Contains position and a visibility mask (e.g., `vs_out_VoxelCode`) indicating which faces are solid [S1, unofficial].

**Steps:**
1.  **Transform Center:** Transform the voxel center to clip space:
    $$vPos = vec4(x, y, z, 1) \times M_{WVP}$$
    where $M_{WVP}$ is the World-View-Projection matrix [S1, unofficial].
2.  **Frustum Culling:** Calculate an expanded frustum boundary using the corner vectors:
    $$w = vPos.w + \max(\max(\|c\_vCorner_{000}\|, \|c\_vCorner_{001}\|), \max(\|c\_vCorner_{010}\|, \|c\_vCorner_{011}\|))$$
    Discard the voxel if:
    $$|vPos.z| > w \quad \text{or} \quad |vPos.x| > w \quad \text{or} \quad |vPos.y| > w$$
    This offset prevents voxels from disappearing too early [S1, unofficial].
3.  **Backface Culling:** Determine visible faces by transforming a direction in projection space to view space using the inverse projection matrix diagonal:
    $$v_{proj\_to\_view} = (1/M_{P}[0][0], 1/M_{P}[1][1], 1/M_{P}[2][2])$$
    Check the dot product with the view direction to decide between front and back faces [S1, unofficial].
4.  **Face Visibility Check:** Use a mask (e.g., `vs_out_VoxelCode[0] & uint(0x10)`) to reject invisible faces inside the model (occluded by neighbors) [S1, unofficial].
5.  **Emit Geometry:** For each visible face, emit 4 vertices forming a quad. The vertices are computed as:
    $$v_{final} = c\_vCorner_{ijk} + vPos$$
    Emit at most 3 quads (12 vertices) per cube [S1, unofficial].

**Pseudocode:**
```python
# Precomputed constants (example for unit cube corners in projection space)
# c_vCorner000, c_vCorner001, ..., c_vCorner111 are vec4 constants
# c_vInverseProjection is vec3(1/M_P[0][0], 1/M_P[1][1], 1/M_P[2][2])
# vViewDirection is the view vector in projection space

def geometry_shader(point_in):
    x, y, z = point_in.position
    voxel_code = point_in.attributes.voxel_code
    
    # Step 1: Transform center to clip space
    vPos = vec4(x, y, z, 1) * c_mWorldViewProjection
    
    # Step 2: Frustum Culling with offset
    w = vPos.w + max(max(length(c_vCorner000), length(c_vCorner001)), 
                     max(length(c_vCorner010), length(c_vCorner011)))
    
    if abs(vPos.z) > w or abs(vPos.x) > w or abs(vPos.y) > w:
        return # Discard voxel
    
    # Step 3 & 4: Backface Culling and Face Visibility
    # Check front face (e.g., -Z face in local space)
    # Transform corner direction to view space
    corner_dir = (c_vCorner000.xyz + c_vCorner110.xyz) * c_vInverseProjection.xyz
    
    if dot(corner_dir, vViewDirection) > 0:
        # Front face visible
        if (voxel_code & 0x10) != 0: # Mask check
            emit_quad(c_vCorner000, c_vCorner100, c_vCorner010, c_vCorner110, vPos)
    else:
        # Back face visible
        if (voxel_code & 0x20) != 0: # Mask check
            emit_quad(c_vCorner001, c_vCorner101, c_vCorner011, c_vCorner111, vPos)
            
    # Repeat for other visible faces...

def emit_quad(corner0, corner1, corner2, corner3, vPos):
    # Emit vertices for a quad
    gl_Position = corner0 + vPos
    EmitVertex()
    gl_Position = corner1 + vPos
    EmitVertex()
    gl_Position = corner2 + vPos
    EmitVertex()
    gl_Position = corner3 + vPos
    EmitVertex()
    EndPrimitive()
```

## Operating characteristics
*   **Time Complexity:** $O(1)$ per voxel, with early discards reducing effective work.
*   **Memory Complexity:** Low, as no large mesh buffers are generated; geometry is created on the fly.
*   **Strengths:** Significant reduction in vertex count (12 vs 24) and improved culling efficiency by operating in projection space [S1, unofficial].
*   **Limitations:** Requires careful handling of projection matrix dependencies for backface culling [S1, unofficial].

## Background
This technique was developed by Johannes Jendersie for efficient voxel rendering, focusing on minimizing overdraw and vertex processing by leveraging GPU geometry shader capabilities [S1, unofficial].
