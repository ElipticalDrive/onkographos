# Geometry Shader Advanced Instancing for Cubes

Also called: Frustum Culling in Projection Space, GS Cube Instancing

## Overview
This method uses a geometry shader to generate cube meshes from instanced points, optimizing for visibility by emitting at most 12 vertices (3 quads) per cube [S1, unofficial]. It leverages backface culling and frustum culling in projection space to reduce the number of primitives submitted to the rasterizer [S1, unofficial]. Unlike methods that generate full 24-vertex cubes, this approach exploits the fact that backface culling always removes one of two opposite faces, allowing the shader to emit only the visible faces [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A stream of points representing voxel centers, transformed by the vertex shader. The vertex shader outputs the world position of the voxel center and a `VoxelCode` bitmask indicating which faces are potentially visible (e.g., `0x10` for front, `0x20` for back) [S1, unofficial].
*   **Output:** A stream of triangles (quads) representing the visible faces of the cubes [S1, unofficial].

**Data Structures:**
*   **Corner Vectors:** Precomputed vectors representing the 8 corners of a unit cube centered at the origin. These are transformed into projection space once per frame and stored as constants (e.g., `c_vCorner000` to `c_vCorner111`) [S1, unofficial].
*   **VoxelCode:** A bitmask passed from the vertex shader to the geometry shader to indicate which faces of the voxel are exposed (not occluded by neighbors) [S1, unofficial].

**Steps:**
1.  **Frustum Culling in Projection Space:**
    *   Transform the voxel center to clip space: $vPos = vec4(x, y, z, 1) \times M_{WVP}$, where $M_{WVP}$ is the Model-View-Projection matrix [S1, unofficial].
    *   Calculate an expanded frustum boundary $w$:
        $$
        w = vPos.w + \max(\max(\|c_{vCorner000}\|, \|c_{vCorner001}\|), \max(\|c_{vCorner010}\|, \|c_{vCorner011}\|))
        $$
        Note: The source uses specific corner vectors, implying a check against the bounding box of the cube in projection space [S1, unofficial].
    *   Discard the voxel if it is outside the expanded frustum:
        $$
        \text{if } |vPos.z| > w \lor |vPos.x| > w \lor |vPos.y| > w \text{ then discard}
        $$
        This offset prevents voxels from disappearing prematurely when only the center is tested [S1, unofficial].

2.  **Backface Culling in View Space:**
    *   Transform a direction from projection space to view space using the inverse of the projection matrix's diagonal elements: $v_{proj\_to\_view} = (1/M_{proj}[0][0], 1/M_{proj}[1][1], 1/M_{proj}[2][2])$ [S1, unofficial].
    *   Determine face visibility by computing the dot product of the face normal (transformed to view space) and the view direction. If the dot product is positive, the face is back-facing and should be discarded [S1, unofficial].

3.  **Face Visibility Check and Emission:**
    *   Use the `VoxelCode` bitmask to reject faces that are occluded by neighboring voxels (e.g., shared faces) [S1, unofficial].
    *   For each visible face, emit a quad (4 vertices) using the precomputed corner vectors added to the transformed voxel center $vPos$ [S1, unofficial].
    *   Since backface culling removes one of each opposite pair, only 3 quads (12 vertices) are emitted per cube at most [S1, unofficial].

**Pseudocode:**
```python
# Precomputed constants (transformed corner vectors in projection space)
# c_vCorner000 to c_vCorner111 are vec4
# c_vInverseProjection is vec3(1/M_proj[0][0], 1/M_proj[1][1], 1/M_proj[2][2])

def geometry_shader(points):
    for point in points:
        # 1. Frustum Culling
        vPos = vec4(point.x, point.y, point.z, 1.0) * M_WVP
        
        # Calculate expanded frustum boundary
        # Note: Source uses specific corners, assuming a unit cube centered at origin
        # The max length of the relevant corners is added to vPos.w
        corner_lengths = [
            length(c_vCorner000), length(c_vCorner001),
            length(c_vCorner010), length(c_vCorner011)
        ]
        w = vPos.w + max(max(corner_lengths[0], corner_lengths[1]), 
                          max(corner_lengths[2], corner_lengths[3]))
        
        if abs(vPos.z) > w or abs(vPos.x) > w or abs(vPos.y) > w:
            continue # Discard voxel outside frustum

        # 2. Backface Culling and Face Emission
        # Check Front Face (e.g., normal pointing towards camera)
        # Transform normal to view space
        vNormal_proj = vec4(0, 0, -1, 0) # Example normal for front face
        vNormal_view = vec3(dot(vNormal_proj.xyz, c_vInverseProjection)) # Simplified transform
        
        # View direction is typically (0,0,-1) in view space or derived from camera
        vViewDir = vec3(0, 0, -1) 
        
        if dot(vNormal_view, vViewDir) > 0:
            # Check if face is visible (not occluded by neighbor)
            if (point.VoxelCode & 0x10) != 0:
                emit_quad(vPos + c_vCorner000, vPos + c_vCorner100, 
                          vPos + c_vCorner010, vPos + c_vCorner110)

        # Check Back Face
        vNormal_proj = vec4(0, 0, 1, 0)
        vNormal_view = vec3(dot(vNormal_proj.xyz, c_vInverseProjection))
        
        if dot(vNormal_view, vViewDir) > 0:
            if (point.VoxelCode & 0x20) != 0:
                emit_quad(vPos + c_vCorner001, vPos + c_vCorner101, 
                          vPos + c_vCorner011, vPos + c_vCorner111)
```

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of voxels, with a constant factor reduced by culling. Frustum culling is performed in the geometry shader, avoiding CPU-GPU synchronization [S1, unofficial].
*   **Memory Complexity:** Low, as only the voxel centers and a small bitmask are stored in the instance buffer. The geometry shader generates vertices on the fly [S1, unofficial].
*   **Performance:** Significantly reduces the number of vertices and triangles sent to the rasterizer by emitting only visible faces (up to 12 vertices per cube instead of 24) [S1, unofficial].
*   **Strengths:** Efficient culling in projection space; simple implementation; works well for dense voxel grids [S1, unofficial].
*   **Limitations:** Requires a geometry shader stage; culling accuracy depends on the precomputed corner vectors and projection matrix [S1, unofficial].
