# Two-Pass Voxel Shading Pipeline

Also called: Voxel-shader rendering pipeline

## Overview
The Two-Pass Voxel Shading Pipeline is a rendering technique for voxel meshes that separates solid (opaque) geometry from porous (translucent) geometry to handle alpha blending correctly [S1, unofficial]. It builds on [Voxel Rendering Pipeline](16079-voxel-rendering-pipeline.md) by explicitly dividing draw calls into two phases: opaque surfaces use an ambient occlusion (AO) shader, while translucent surfaces use a custom model shader with blending enabled [S1, unofficial]. This separation prevents translucent blocks from incorrectly occluding or blending with opaque blocks behind them due to depth buffer ordering [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A voxel mesh collection containing `vertexArrayObjects` for `surface` (solid) and `porous` (translucent) triangles; a camera providing `view` and `projection` matrices; optional texture maps (`tileMap` or `texture`) [S1, unofficial].
*   **Outputs:** A composited framebuffer with correctly blended opaque and translucent voxels [S1, unofficial].

**Data Structures:**
*   `meshes`: A dictionary keyed by chunk index, where each value contains:
    *   `vertexArrayObjects`: An object with `surface` and `porous` keys, each holding an array of VAO references or triangle index buffers [S1, unofficial].
    *   `modelMatrix`: A 4×4 transformation matrix for the chunk [S1, unofficial].
*   `shader`: The AO shader program for solid blocks [S1, unofficial].
*   `shader2`: The custom model shader for porous blocks, which passes UVs and samples textures [S1, unofficial].

**Parameters:**
*   `cameraNear`: Near clipping plane, default 0.1 [S1, unofficial].
*   `cameraFar`: Far clipping plane, default 200.0 [S1, unofficial].
*   `cameraFOV`: Field of view in degrees, default 45.0 [S1, unofficial].
*   `perspectiveResize`: Boolean, default true. If true, updates the projection matrix on window resize events [S1, unofficial].

**Steps:**
1.  **Initialization (`gl-init`):** Create the AO shader (`this.shader`) and the custom model shader (`this.shader2`) [S1, unofficial]. Initialize the projection matrix using `mat4.perspective` with `cameraFOV`, aspect ratio, `cameraNear`, and `cameraFar` [S1, unofficial]. Register listeners for `gl-render` and optionally `gl-resize` [S1, unofficial].
2.  **Render Loop:** Enable face culling and depth testing [S1, unofficial]. Update the view matrix from the camera [S1, unofficial].
    *   **Pass 1 (Solid blocks):** Disable blending [S1, unofficial]. Bind the AO shader [S1, unofficial]. Set uniforms `projection`, `view`, `tileCount`, and optionally `tileMap` if a texture exists [S1, unofficial]. Iterate over all meshes [S1, unofficial]. For each mesh, if `mesh.vertexArrayObjects.surface` exists and is non-empty, set the `model` uniform, bind the surface VAO, and draw triangles using `gl.drawArrays(gl.TRIANGLES, 0, vao.length)` [S1, unofficial].
    *   **Pass 2 (Porous blocks):** Set blend function to `gl.blendFunc(gl.ONE, gl.ONE_MINUS_SRC_ALPHA)` [S1, unofficial]. Enable blending [S1, unofficial]. Bind the custom model shader [S1, unofficial]. Set uniforms `view`, `projection`, and optionally `texture` if a texture exists [S1, unofficial]. Iterate over all meshes [S1, unofficial]. For each mesh, if `mesh.vertexArrayObjects.porous` exists and is non-empty, set the `model` uniform, bind the porous VAO, and draw triangles using `gl.drawArrays(gl.TRIANGLES, 0, vao.length)` [S1, unofficial].

**Pseudocode:**
```python
import math

def mat4_perspective(out, fov, aspect, near, far):
    """Standard perspective matrix calculation."""
    f = 1.0 / math.tan(fov / 2.0)
    nf = 1.0 / (near - far)
    out[0], out[5], out[10], out[14] = f / aspect, f, (far + near) * nf, -1.0
    out[11] = 2.0 * far * near * nf
    return out

class VoxelShaderPipeline:
    def __init__(self, game, opts=None):
        self.shell = game.shell
        self.stitcher = game.plugins.get('voxel-stitch')
        self.camera = game.plugins.get('game-shell-fps-camera')
        if not self.camera:
            raise ValueError('requires game-shell-fps-camera plugin')
        self.perspective_resize = opts.get('perspective_resize', True) if opts else True
        self.camera_near = opts.get('camera_near', 0.1) if opts else 0.1
        self.camera_far = opts.get('camera_far', 200.0) if opts else 200.0
        self.camera_fov = opts.get('camera_fov', 45.0) if opts else 45.0
        self.projection_matrix = [0.0] * 16
        self.view_matrix = [0.0] * 16
        self.shader = None
        self.shader2 = None
        self.texture = None
        self.meshes = {}
        self.enable()

    def enable(self):
        self.shell.on('gl-init', self.ginit)
        self.shell.on('gl-render', self.render)
        if self.perspective_resize:
            self.shell.on('gl-resize', self.update_projection_matrix)
        self.stitcher.on('update_texture', self.on_update_texture)

    def on_update_texture(self, texture):
        self.texture = texture

    def ginit(self):
        self.shader = self.create_ao_shader()
        self.shader2 = self.create_custom_model_shader()
        self.update_projection_matrix()

    def update_projection_matrix(self):
        aspect = self.shell.width / self.shell.height
        fov_rad = self.camera_fov * math.pi / 180.0
        mat4_perspective(self.projection_matrix, fov_rad, aspect, self.camera_near, self.camera_far)
        self.emit('updateProjectionMatrix', self.projection_matrix)

    def render(self):
        gl = self.shell.gl
        gl.enable(gl.CULL_FACE)
        gl.enable(gl.DEPTH_TEST)
        self.camera.view(self.view_matrix)

        # Pass 1: Solid blocks
        gl.disable(gl.BLEND)
        self.shader.bind()
        self.shader.set_uniform('projection', self.projection_matrix)
        self.shader.set_uniform('view', self.view_matrix)
        self.shader.set_uniform('tileCount', self.stitcher.tile_count)
        if self.texture is not None:
            self.shader.set_uniform('tileMap', self.texture.bind())

        for chunk_index, mesh in self.meshes.items():
            surface_vaos = mesh.vertex_array_objects.get('surface')
            if surface_vaos and len(surface_vaos) > 0:
                self.shader.set_uniform('model', mesh.model_matrix)
                for vao in surface_vaos:
                    vao.bind()
                    gl.draw_arrays(gl.TRIANGLES, 0, vao.length)
                    vao.unbind()

        # Pass 2: Porous blocks
        gl.blend_func(gl.ONE, gl.ONE_MINUS_SRC_ALPHA)  # TODO: premult alpha?
        gl.enable(gl.BLEND)
        self.shader2.bind()
        self.shader2.set_uniform('view', self.view_matrix)
        self.shader2.set_uniform('projection', self.projection_matrix)
        if self.texture is not None:
            self.shader2.set_uniform('texture', self.texture.bind())

        for chunk_index, mesh in self.meshes.items():
            porous_vaos = mesh.vertex_array_objects.get('porous')
            if porous_vaos and len(porous_vaos) > 0:
                self.shader2.set_uniform('model', mesh.model_matrix)
                for vao in porous_vaos:
                    vao.bind()
                    gl.draw_arrays(gl.TRIANGLES, 0, vao.length)
                    vao.unbind()
```

**Edge Cases and Pitfalls:**
*   **Premultiplied Alpha:** The implementation uses `gl.ONE` and `gl.ONE_MINUS_SRC_ALPHA` blending, which assumes non-premultiplied alpha. Premultiplied alpha is not handled, which may lead to incorrect blending results for translucent blocks [S1, unofficial].
*   **Shader Initialization:** Rendering fails if `render()` is called before `gl-init` has bound the shaders [S1, unofficial].
*   **Camera Dependency:** The pipeline requires a camera plugin that provides a valid view matrix; otherwise, it throws an error [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
*   Time complexity is linear with respect to the number of meshes and triangles, as each mesh is iterated twice (once for solid, once for porous) [S1, unofficial].
*   Memory complexity depends on the storage of `vertexArrayObjects` for both surface and porous geometry per mesh [S1, unofficial].

**Measured Performance:**
*   Not given in the sources.

**Scaling:**
*   Scales with the number of meshes and the density of solid vs. porous blocks. The separation allows for optimized shading (AO for solid, simpler texture lookup for porous) [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Correctly handles alpha blending for translucent voxel blocks by rendering opaque geometry first, preventing depth buffer artifacts [S1, unofficial]. Allows different shading logic for opaque vs. translucent geometry [S1, unofficial].
*   **Limitations:** Does not handle premultiplied alpha, which may cause visual artifacts with certain textures [S1, unofficial]. Requires two draw passes per mesh, potentially increasing overhead compared to a single-pass approach if blending is not needed [S1, unofficial].

**When to use it and when not:**
*   Use when rendering voxel meshes with both opaque and translucent blocks that require correct alpha blending [S1, unofficial].
*   Do not use if all blocks are opaque, as the second pass is unnecessary overhead [S1, unofficial].

## Background
The Two-Pass Voxel Shading Pipeline was developed by Mikola Lysenko (2013) and deathcap (2014) as part of the `voxel-shader` plugin for the Voxel.js ecosystem [S1, unofficial]. It is designed to work with the `voxel-stitch` and `game-shell-fps-camera` plugins, leveraging their meshing and camera systems [S1, unofficial]. The technique addresses the common issue in voxel rendering where translucent blocks (like glass or water) incorrectly interact with opaque blocks due to depth sorting and blending order [S1, unofficial].
