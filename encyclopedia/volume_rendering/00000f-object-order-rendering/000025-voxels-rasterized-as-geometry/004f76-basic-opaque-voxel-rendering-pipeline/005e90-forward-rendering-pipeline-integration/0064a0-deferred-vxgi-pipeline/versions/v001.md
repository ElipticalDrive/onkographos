# Deferred VXGI Pipeline

Also called: VXGIRenderer

## Overview
The Deferred VXGI Pipeline is a deferred rendering implementation for Unity's Scriptable Render Pipeline (SRP) that integrates voxel-based global illumination (VXGI) lighting passes [S1, unofficial]. It differs from forward rendering approaches by decoupling the geometry shading (G-buffer creation) from the lighting computation, allowing multiple lighting passes (emission, direct, indirect diffuse, indirect specular) to be executed against a pre-computed voxel volume [S1, unofficial]. This method builds on [Forward Rendering Pipeline Integration](17677-forward-rendering-pipeline-integration.md) by shifting the lighting calculation to a deferred stage, which is particularly beneficial for scenes with many dynamic lights or complex indirect illumination requirements [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Scene geometry, camera properties, voxel volume data (radiances, transforms), light sources (Directional, Point, Spot), and rendering parameters (resolution scales, modifiers).
*   **Outputs:** Final color buffer (CameraTarget) with voxel-based global illumination applied.

**Data Structures:**
*   **G-Buffer Binding (`_gBufferBinding`):** A `RenderTargetBinding` containing 4 G-buffer textures (`ShaderIDs._CameraGBufferTexture0` to `3`) and 1 depth texture (`ShaderIDs._CameraDepthTexture`). All textures have `LoadAction` and `StoreAction` set to `DontCare` [S1, unofficial].
    *   Texture 0: ARGB32
    *   Texture 1: ARGB32
    *   Texture 2: ARGB2101010
    *   Texture 3: ARGBHalf
    *   Depth: 24-bit
*   **Frame Buffer:** A temporary `RenderTexture` with format ARGBHalf, used as the accumulation target for lighting passes [S1, unofficial].
*   **Render Scale Array (`_renderScale`):** An array of 4 floats controlling resolution scaling for each lighting pass. Initialized to `{1f, 1f, 1f, 1f}` [S1, unofficial].
*   **Lighting Passes:** An array of 4 passes: Emission, DirectDiffuseSpecular, IndirectDiffuse, IndirectSpecular [S1, unofficial].

**Numbered Steps:**
1.  **Culling and Setup:** Cull the scene using `ScriptableCullingParameters` and setup camera properties [S1, unofficial].
2.  **Keyword Management:** Enable the `PROJECTION_PARAMS_X` shader keyword for non-SceneView cameras; otherwise, disable it [S1, unofficial].
3.  **Target Allocation:** Allocate temporary render targets for the G-buffers (as defined above) and the FrameBuffer (ARGBHalf). All targets use Point filtering and Linear color space [S1, unofficial].
4.  **G-Buffer Execution:** Bind the G-buffer render target binding, clear the render target, execute the command buffer for geometry shading, and clear the buffer for subsequent commands [S1, unofficial].
5.  **Scale Configuration:** Assign the `vxgi.diffuseResolutionScale` parameter from the VXGI component to the third element of the `_renderScale` array (index 2, corresponding to IndirectDiffuse) [S1, unofficial].
6.  **Lighting Passes:** Iterate through the four lighting passes. For each pass `i`, execute the pass using the corresponding resolution scale `_renderScale[i]` [S1, unofficial].
    *   The passes are executed in this order: Emission, DirectDiffuseSpecular, IndirectDiffuse, IndirectSpecular [S1, unofficial].
7.  **Skybox and Post-Processing:** Render the skybox if the camera clear flags are set to Skybox, then update the post-processing layer [S1, unofficial].
8.  **Blit:** Blit the FrameBuffer to the CameraTarget using the `UtilityShader` with the `BlitViewport` pass to apply the viewport rect [S1, unofficial].
9.  **Cleanup:** Release all temporary render targets, end the command buffer sample, execute the final command buffer, and clear it [S1, unofficial].

**Formulas and Parameters:**
*   **Transform Matrices:** The following global matrices are set for the lighting passes [S1, unofficial]:
    *   `ClipToVoxel`: `vxgi.worldToVoxel * clipToWorld`
    *   `ClipToWorld`: `clipToWorld`
    *   `VoxelToWorld`: `vxgi.voxelToWorld`
    *   `WorldToVoxel`: `vxgi.worldToVoxel`
*   **Parameters:**
    *   `_renderScale`: Array of 4 floats. Default: `{1f, 1f, 1f, 1f}` [S1, unofficial].
    *   `vxgi.diffuseResolutionScale`: Float parameter overriding `_renderScale[2]` [S1, unofficial].
    *   `Indirect Diffuse Modifier`: Controls the strength of diffuse cone tracing [S1, unofficial].
    *   `Indirect Specular Modifier`: Controls the strength of specular cone tracing [S1, unofficial].

**Pseudocode:**
```python
def DeferredVXGIPipeline(renderContext, camera, vxgiComponent, renderer):
    # 1. Cull and Setup
    cullingParams = GetScriptableCullingParameters(camera)
    renderContext.Cull(ref cullingParams)
    
    # 2. Keyword Management
    if camera.cameraType != CameraType.SceneView:
        renderer.EnableKeyword("PROJECTION_PARAMS_X")
    else:
        renderer.DisableKeyword("PROJECTION_PARAMS_X")
        
    # 3. Allocate Targets
    # G-Buffers: 0-3 (ARGB32, ARGB32, ARGB2101010, ARGBHalf), Depth (24-bit)
    # FrameBuffer: ARGBHalf
    # All with Point filtering, Linear color space, LoadAction/StoreAction = DontCare
    gBufferBinding = CreateRenderTargetBinding([
        CreateTexture("ShaderIDs._CameraGBufferTexture0", Format.ARGB32),
        CreateTexture("ShaderIDs._CameraGBufferTexture1", Format.ARGB32),
        CreateTexture("ShaderIDs._CameraGBufferTexture2", Format.ARGB2101010),
        CreateTexture("ShaderIDs._CameraGBufferTexture3", Format.ARGBHalf),
        CreateTexture("ShaderIDs._CameraDepthTexture", Format.D24)
    ])
    frameBuffer = CreateTexture("FrameBuffer", Format.ARGBHalf)
    
    # 4. G-Buffer Execution
    renderContext.SetRenderTarget(gBufferBinding)
    renderContext.ClearRenderTarget(True, True, Color.black)
    renderContext.ExecuteCommandBuffer(renderer.GBufferCommandBuffer)
    renderContext.ClearRenderTarget(False, True, Color.black) # Clear for next commands
    
    # 5. Scale Configuration
    renderScale = [1.0, 1.0, 1.0, 1.0]
    renderScale[2] = vxgiComponent.diffuseResolutionScale
    
    # 6. Lighting Passes
    lightingPasses = ["Emission", "DirectDiffuseSpecular", "IndirectDiffuse", "IndirectSpecular"]
    
    # Set Global Matrices
    clipToWorld = camera.projectionMatrix * camera.worldToCameraMatrix.inverse
    renderer.SetGlobalMatrix("ClipToVoxel", vxgiComponent.worldToVoxel * clipToWorld)
    renderer.SetGlobalMatrix("ClipToWorld", clipToWorld)
    renderer.SetGlobalMatrix("VoxelToWorld", vxgiComponent.voxelToWorld)
    renderer.SetGlobalMatrix("WorldToVoxel", vxgiComponent.worldToVoxel)
    
    for i in range(4):
        # Execute lighting pass with specific scale
        renderer.ExecuteLightingPass(lightingPasses[i], camera, "FrameBuffer", renderScale[i])
        
    # 7. Skybox and Post-Processing
    if camera.clearFlags == CameraClearFlags.Skybox:
        renderContext.DrawSkybox(camera)
    renderer.UpdatePostProcessing()
    
    # 8. Blit
    renderer.Blit(frameBuffer, camera.targetTexture, "UtilityShader", "BlitViewport")
    
    # 9. Cleanup
    renderer.ReleaseTexture(gBufferBinding)
    renderer.ReleaseTexture(frameBuffer)
    renderer.EndCommandBufferSample()
    renderContext.ExecuteCommandBuffer(renderer.FinalCommandBuffer)
    renderer.ClearCommandBuffer()
```

**Edge Cases and Pitfalls:**
*   **Graphics API Support:** The method relies on geometry shaders, which are not supported by all graphics APIs (e.g., Metal) [S1, unofficial].
*   **VRAM Usage:** High voxel resolutions (e.g., 256^3) require approximately 1GB of VRAM [S1, unofficial].
*   **UI Elements:** Unity UI elements are not displayed in the Scene View (only bounding Rect Transform), but display normally in Game View [S1, unofficial].
*   **Lighting Fall-off:** Uses inverse-squared distance model without range attenuation [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Dependent on the number of lighting passes (4) and the resolution of the voxel volume and G-buffers. The voxelization and cone tracing steps are performed per light source.
*   **Memory Complexity:** Requires storage for G-buffers (4 textures + depth), voxel volume (scales with resolution, ~1GB for 256^3), and temporary frame buffers [S1, unofficial].
*   **Strengths:** Efficient handling of multiple dynamic lights and complex indirect illumination in a deferred framework.
*   **Limitations:** High VRAM consumption at high resolutions; dependency on geometry shader support excludes Metal API; UI rendering limitations in Scene View [S1, unofficial].
*   **When to Use:** Scenes with many dynamic lights or requiring global illumination where forward rendering would be too expensive.
*   **When Not to Use:** Platforms without geometry shader support (e.g., Metal) or when VRAM is severely constrained.

## Background
The Deferred VXGI Pipeline is part of the Unity-SRP-VXGI project, an unofficial implementation of voxel-based global illumination for Unity's Scriptable Render Pipeline [S1, unofficial]. It is inspired by [sonicether/SEGI](https://github.com/sonicether/SEGI) [S1, unofficial]. The project was developed for Unity 2019 and requires Shader Model 4.5 or newer [S1, unofficial]. It supports Directional, Point, and Spot lights [S1, unofficial].
