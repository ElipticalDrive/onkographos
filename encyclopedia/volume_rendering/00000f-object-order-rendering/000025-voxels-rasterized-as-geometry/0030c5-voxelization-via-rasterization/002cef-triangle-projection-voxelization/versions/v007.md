# Triangle Projection Voxelization
Also called: Union-based Voxelization, VoxelizationByUnionPass

## Overview
Triangle Projection Voxelization is a rasterization-based voxelization technique that renders 3D mesh triangles directly into a 3D voxel grid using a union-based accumulation approach [S1, unofficial]. It differs from sibling methods like 3-axis rasterization by projecting triangles onto a single view volume and resolving coverage via multiple render targets or passes, rather than iterating over axes or chunks [S1, unofficial]. This method is particularly suited for hardware-accelerated pipelines where direct volume rendering targets can be bound as UAVs.

## How it works
**Inputs and Outputs:**
- Input: A triangle mesh (indices, vertices), voxel grid dimensions, and a boolean flag `m_solid` indicating whether to render solid or translucent geometry [S1, unofficial].
- Output: A 3D voxel grid stored in a Unordered Access View (UAV) [S1, unofficial].

**Data Structures:**
The method utilizes a specific pipeline layout named `PASS_VOXELIZE_UNION` [S1, unofficial].
- **Descriptor Range 0:** Constant Buffer View (CBV), count 1, offset 0, flags `DATA_STATIC` [S1, unofficial].
- **Descriptor Range 1:** Constant Buffer View (CBV), count 1, offset 0, flags `DATA_STATIC` [S1, unofficial].
- **Descriptor Range 2:** Unordered Access View (UAV), count `numUAVs`, offset 0, flags `DATA_STATIC_WHILE_SET_AT_EXECUTE` [S1, unofficial].
- **Shader Stages:** Vertex Shader (VS), Pixel Shader (PS) [S1, unofficial].

**Steps:**
1. Reset the command allocator and command list [S1, unofficial].
2. Bind the descriptor heap containing CBV, SRV, and UAV descriptors [S1, unofficial].
3. Set up resource barriers to transition the render target to `RENDER_TARGET` state [S1, unofficial].
4. If `m_solid` is false, clear the render target view with a clear color (e.g., `{CLEAR_COLOR, 0.0f}`) [S1, unofficial].
5. Clear the depth stencil view with depth value 1.0 [S1, unofficial].
6. Configure the voxelization pass:
   - Set `layoutIdx` to `PASS_VOXELIZE_UNION` [S1, unofficial].
   - Set `pipeIdx` to `PASS_VOXELIZE_UNION_SOLID` if `depthPeel` is true, otherwise `PASS_VOXELIZE_UNION` [S1, unofficial].
   - Set `instanceCount` to 3 [S1, unofficial].
7. Bind the pipeline state using vertex shader `VS_TRI_PROJ_UNION` and pixel shader `PS_TRI_PROJ_UNION` [S1, unofficial].
8. Call `DrawIndexed(m_numIndices, instanceCount, 0, 0, 0)` [S1, unofficial].

**Pseudocode:**
```python
def render_voxelization_union(command_list, mesh, voxel_grid_uav, is_solid, depth_peel):
    # Reset command list
    command_list.reset()
    
    # Bind descriptor heaps
    descriptor_heap = get_descriptor_heap(CBV_SRV_UAV_HEAP)
    command_list.set_descriptor_heaps([descriptor_heap])
    
    # Setup render target barrier
    render_target = get_render_target()
    render_target.set_barrier(command_list, ResourceState.RENDER_TARGET)
    
    # Clear targets
    if not is_solid:
        clear_color = [CLEAR_COLOR, 0.0, 0.0, 0.0]
        command_list.clear_render_target_view(render_target.get_rtv(), clear_color)
    command_list.clear_depth_stencil_view(get_depth_view(), ClearFlag.DEPTH, 1.0)
    
    # Configure pass parameters
    layout_idx = PASS_VOXELIZE_UNION
    if depth_peel:
        pipe_idx = PASS_VOXELIZE_UNION_SOLID
    else:
        pipe_idx = PASS_VOXELIZE_UNION
    instance_count = 3
    
    # Bind pipeline and shaders
    bind_pipeline_state(pipe_idx)
    bind_vertex_shader(VS_TRI_PROJ_UNION)
    bind_pixel_shader(PS_TRI_PROJ_UNION)
    
    # Bind descriptors
    # Range 0: CBV(1)
    # Range 1: CBV(1)
    # Range 2: UAV(numUAVs) -> voxel_grid_uav
    bind_descriptor_ranges([
        DescriptorRange(DescriptorType.CBV, 1, 0, DATA_STATIC),
        DescriptorRange(DescriptorType.CBV, 1, 0, DATA_STATIC),
        DescriptorRange(DescriptorType.UAV, len(voxel_grid_uav), 0, DATA_STATIC_WHILE_SET_AT_EXECUTE)
    ])
    
    # Draw
    command_list.draw_indexed(mesh.num_indices, instance_count, 0, 0, 0)
```

**Edge Cases and Pitfalls:**
- The `instanceCount` is hardcoded to 3, which may imply rendering the same geometry for multiple depth layers or axes, though the exact semantic is not detailed in the source [S1, unofficial].
- Precision issues may arise if the triangle projection does not align with voxel boundaries, leading to gaps or overlaps [G].
- The `depthPeel` flag determines whether solid or translucent voxelization logic is used, requiring careful state management [S1, unofficial].

## Subtopics

### [Axis-Aligned Projection via Face Normal](5925-axis-aligned-projection-via-face-normal.md)
A geometry shader technique that projects triangles onto the 2D plane aligned with the axis most perpendicular to the face normal, minimizing distortion and overlap artifacts.

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Depends on `numUAVs` and voxel grid dimensions [S1, unofficial].
- **Performance:** Not given in the sources.
- **Strengths:** Leverages standard rasterization pipeline; union-based approach handles overlapping geometry naturally [S1, unofficial].
- **Limitations:** Requires multiple UAVs or passes for full coverage; hardcoded instance count may limit flexibility [S1, unofficial].
- **When to use:** When hardware acceleration is available and union-based coverage is acceptable [S1, unofficial].
- **When not to use:** When precise solid voxelization without overlap artifacts is required without additional processing [G].

## Background
Originated in the VoxelizerX12 project, a DirectX 12-based voxelization tool [S1, unofficial]. The method is part of a broader family of rasterization-based voxelization techniques that map 3D geometry to 3D texture volumes using GPU rendering pipelines [S1, unofficial].
