# Bone-Animated Voxel Skinning with Skeletal Mesh Voxelization

Also called: Bone-driven voxel chunks, SkeletalMesh voxelization

## Overview
This method enables real-time rendering of bone-animated voxel characters by converting a skeletal mesh into voxel data at editor time and switching between static and bone-driven voxel chunks at runtime based on asset data [S1, unofficial]. It differs from sibling methods by baking bone weights and group assignments into the voxel structure during offline voxelization, allowing runtime assembly of per-bone chunk components attached to a hidden skeleton, rather than computing skinning or deformation on the GPU during rasterization [S1, unofficial].

## How it works
**Inputs:** A SkeletalMesh (LOD0 reference pose) with vertex positions, indices, and skin weights; a target voxel resolution (grid size).
**Outputs:** A voxel asset containing either sparse voxels (for static mode) or bone groups (for animated mode), where each bone group is a cluster of voxels assigned to a specific bone with their reference pose positions.

**Data Structures:**
*   **Voxel Grid:** A 3D array of size $32^3$ (default), fitted to the mesh AABB with a 1-voxel margin [S1, unofficial].
*   **SparseVoxels:** Full voxel array for static rendering [S1, unofficial].
*   **BoneGroups:** Map of bone name to voxel cluster data [S1, unofficial].
*   **BoneChunk:** A component representing a subset of voxels assigned to a single bone [S1, unofficial].
*   **HiddenSkeleton:** An invisible `SkeletalMeshComponent` used to drive bone transforms at runtime [S1, unofficial].

**Voxelization Steps (Editor Time):**
1.  **Extract Triangles:** Extract triangles from the LOD0 reference pose of the SkeletalMesh [S1, unofficial].
2.  **Conservative Rasterization:** Determine which voxels are covered by each triangle using SAT-based triangle-AABB intersection [S1, unofficial].
3.  **Solid Fill:** Fill the interior of the mesh using a Z-slice scanline parity algorithm to create solid voxels [S1, unofficial].
4.  **Bone Weight Propagation:** Propagate bone weights to interior voxels using a Breadth-First Search (BFS) starting from surface voxels [S1, unofficial].
5.  **Bone Assignment:** Assign the dominant bone (highest accumulated weight) to each voxel for bone group assignment [S1, unofficial].
6.  **Output:** Output sparse voxels for static mode and bone groups (per-bone voxel clusters with reference pose positions) for animated mode [S1, unofficial].

**Runtime Steps (Bone-Animated Mode):**
1.  **Mode Detection:** Detect if any layer has bone data using `HasAnyBoneData()` [S1, unofficial]. If bone data is present, switch to Bone-Animated Mode; otherwise, use Static Mode [S1, unofficial].
2.  **Hidden Skeleton Setup:** Create a `HiddenSkeleton` (invisible `SkeletalMeshComponent`) to drive bone transforms [S1, unofficial].
3.  **Bone Chunks Creation:** Create `BoneChunks`, a map of bone name to chunk component, attached to the hidden skeleton [S1, unofficial].
4.  **Assemble Chunks:** Assemble per-bone chunks from `BoneGroups` using `AssembleBoned()` [S1, unofficial].
5.  **Coordinate Assignment:** Assign unique coordinates to bone chunks in the shared render cache using $(BoneIndex+1, 0, 0)$ [S1, unofficial].
6.  **Position Adjustment:** Adjust voxel origin by the reference pose bone position for correct placement [S1, unofficial].
7.  **Animation Integration:** Synchronize `UHktAnimInstance` in `ApplyPresentation()` by forwarding movement speed, stance, attack rate, and CP ratio [S1, unofficial]. Propagate gameplay tags and animation triggers, enabled only in bone-animated mode [S1, unofficial].

**Pseudocode:**

```python
def voxelize_skeletal_mesh(mesh):
    """
    Voxelize a SkeletalMesh at editor time.
    Returns BoneGroups for animated mode or SparseVoxels for static mode.
    """
    # Step 1: Extract triangles from LOD0 reference pose
    triangles = mesh.get_lod(0).get_triangles()
    
    # Step 2: Conservative rasterization using SAT-based triangle-AABB intersection
    # Determine which voxels are covered by each triangle
    covered_voxels = set()
    for tri in triangles:
        # SAT-based intersection check for each voxel in the grid
        for voxel in grid:
            if sat_triangle_aabb_intersection(tri, voxel.aabb):
                covered_voxels.add(voxel)
                
    # Step 3: Solid fill via Z-slice scanline parity algorithm
    solid_voxels = set()
    for z in range(grid.height):
        # Scanline parity logic to fill interior
        solid_voxels.update(fill_z_slice(covered_voxels, z))
        
    # Step 4: Propagate bone weights to interior voxels using BFS
    # Start from surface voxels (those in covered_voxels but not solid_voxels interior)
    surface_voxels = covered_voxels - solid_voxels
    queue = list(surface_voxels)
    visited = set(queue)
    
    while queue:
        current_voxel = queue.pop(0)
        # Propagate weights from neighbors
        for neighbor in get_neighbors(current_voxel):
            if neighbor not in visited and neighbor in solid_voxels:
                propagate_weights(current_voxel, neighbor)
                visited.add(neighbor)
                queue.append(neighbor)
                
    # Step 5: Assign dominant bone to each voxel
    bone_groups = {}
    for voxel in solid_voxels:
        dominant_bone = get_dominant_bone(voxel.weights)
        if dominant_bone not in bone_groups:
            bone_groups[dominant_bone] = []
        bone_groups[dominant_bone].append(voxel)
        
    return bone_groups

def assemble_bone_chunks(bone_groups, hidden_skeleton):
    """
    Assemble per-bone chunks from BoneGroups at runtime.
    """
    bone_chunks = {}
    for bone_name, voxels in bone_groups.items():
        # Create a chunk component for this bone
        chunk = create_chunk_component(voxels)
        
        # Assign unique coordinates in shared render cache
        bone_index = get_bone_index(bone_name)
        chunk.set_render_cache_coordinate((bone_index + 1, 0, 0))
        
        # Adjust voxel origin by reference pose bone position
        ref_pose_pos = hidden_skeleton.get_bone_reference_pose(bone_name)
        chunk.adjust_origin(ref_pose_pos)
        
        # Attach to hidden skeleton
        chunk.attach_to(hidden_skeleton, bone_name)
        bone_chunks[bone_name] = chunk
        
    return bone_chunks

def apply_animation(anim_instance, bone_chunks):
    """
    Synchronize animation data for bone-animated mode.
    """
    # Forward movement speed, stance, attack rate, and CP ratio
    anim_instance.apply_presentation(
        movement_speed=anim_instance.get_movement_speed(),
        stance=anim_instance.get_stance(),
        attack_rate=anim_instance.get_attack_rate(),
        cp_ratio=anim_instance.get_cp_ratio()
    )
    
    # Propagate gameplay tags and animation triggers
    if bone_chunks: # Enabled only in bone-animated mode
        anim_instance.propagate_gameplay_tags()
        anim_instance.trigger_animations()
```

**Parameters:**
*   **Grid Size:** A $32^3$ uniform voxel grid is used, fitted to the mesh AABB with a 1-voxel margin [S1, unofficial].
*   **Mesh Scheduling:** In bone mode, the mesh scheduling is increased to 4 meshes/frame; in static mode, it reverts to 1 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Transform Order:** Component space transform multiplication order must be Local * Parent [S1, unofficial].
*   **Null Check:** `GetSkinWeightVertexBuffer()` must have a null check added [S1, unofficial].
*   **Unused Data:** `PaletteRow` is unused in `WriteToChunk`/`WriteBoneGroupToChunk` and should be marked as such [S1, unofficial].
*   **Cleanup:** Remove unused `AssembleBoned` results in `OnSkinSetChanged` [S1, unofficial].
*   **Initialization:** `AssembleBoned` chunk initialization must be based on `Contains()` [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Voxelization is performed offline at editor time, so runtime cost is dominated by chunk assembly and animation synchronization. The number of meshes scheduled per frame increases from 1 (static) to 4 (bone mode) [S1, unofficial].
*   **Memory Complexity:** Stores sparse voxels for static mode or bone groups for animated mode. Bone groups require storage for per-bone voxel clusters and reference pose positions [S1, unofficial].
*   **Strengths:** Enables real-time bone animation for voxel characters without runtime skinning calculations; efficient culling via per-bone chunks [S1, unofficial].
*   **Limitations:** Requires offline voxelization; limited to bone-driven deformation; potential artifacts at bone boundaries if weight propagation is inaccurate [S1, unofficial].
*   **When to Use:** When rendering voxel characters with skeletal animation is required and offline processing is acceptable [S1, unofficial].
*   **When Not to Use:** For static voxel models (use static mode) or for non-skeletal deformation [S1, unofficial].
