# DX11.1 Forced Sample Count Optimization
Also called: Forced Sample Count MSAA Voxelization
## Overview
This method leverages the DirectX 11.1 "Forced Sample Count" feature to perform MSAA rasterization without binding an MSAA render target [S1, S2, unofficial]. It serves as a memory-efficient alternative to standard MSAA voxelization by reducing video memory (vidmem) overhead [S2, unofficial].
