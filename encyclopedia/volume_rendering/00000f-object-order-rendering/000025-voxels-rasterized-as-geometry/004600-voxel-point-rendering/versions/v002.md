# Voxel Point Rendering


## Overview
Voxel Point Rendering represents occupied voxels as geometric points submitted to the graphics pipeline for rasterization [S1, unofficial]. It colors solid voxels with a `_CollisionColor` and non-solid voxels with a `_Color` [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A structured buffer of voxel data containing position and a solid/occupancy flag [S1, unofficial].
*   **Input:** Grid dimensions `_GridWidth`, `_GridHeight`, and `_GridDepth` [S1, unofficial].
*   **Input:** Spatial bounds `_BoundsMin` (`float3`) and `_CellHalfSize` (`float`) [S1, unofficial].
*   **Input:** Source mesh triangle data (`_MeshVertices`, `_MeshTriangleIndices`, `_TriangleCount`) [S1, unofficial].
*   **Output:** A 2D image where voxels are rendered as colored points [S1, unofficial].

**Data Structures:**
The core data structure is a `StructuredBuffer<Voxel> _Voxels` accessed via `instance_id` [S1, unofficial]. Each element represents a voxel in the grid and contains:
1.  `position`: A 3D vector (`float3`) representing the world-space center of the voxel [S1, unofficial].
2.  `isSolid`: A scalar value (`float`) indicating occupancy, typically `1.0` for solid/colliding voxels and `0.0` for empty/non-solid voxels [S1, unofficial].

**Algorithm Steps:**

1.  **Voxelization (Pre-processing):**
    For each voxel index $(i, j, k)$ within the grid bounds:
    a. Calculate the world-space center position $P_{world}$:
    $$
    P_{world} = \begin{bmatrix} i \cdot 2 \cdot \text{CellHalfSize} + \text{CellHalfSize} + \text{BoundsMin}_x \\ j \cdot 2 \cdot \text{CellHalfSize} + \text{CellHalfSize} + \text{BoundsMin}_y \\ k \cdot 2 \cdot \text{CellHalfSize} + \text{CellHalfSize} + \text{BoundsMin}_z \end{bmatrix}
    $$
    b. Transform the center to local space for bounding box definition: $P_{local} = \text{WorldToLocal}(P_{world})$ [S1, unofficial].
    c. Define an Axis-Aligned Bounding Box (AABB) with center $P_{local}$ and extents $(\text{CellHalfSize}, \text{CellHalfSize}, \text{CellHalfSize})$ [S1, unofficial].
    d. Perform a collision test against the source mesh triangles to determine if the voxel is occupied [S1, unofficial].
    e. Store the result in `_Voxels[i + j \cdot \text{GridWidth} + k \cdot \text{GridWidth} \cdot \text{GridHeight}]`:
       - `position` = $P_{world}$
       - `isSolid` = $1.0$ if collision detected, $0.0$ otherwise [S1, unofficial].

2.  **Rendering (Vertex Shader):**
    For each instance (voxel):
    a. Retrieve `position` and `isSolid` from `_Voxels[instance_id]` [S1, unofficial].
    b. Transform `position` to clip space using the Model-View-Projection matrix (e.g., `UnityWorldToClipPos`) [S1, unofficial].
    c. Interpolate the output color $C_{out}$:
    $$
    C_{out} = \text{lerp}(\text{_Color}, \text{_CollisionColor}, \text{isSolid})
    $$
    where `_Color` is the color for non-solid voxels and `_CollisionColor` is the color for solid voxels [S1, unofficial].
    d. Output the clip-space position and $C_{out}$ [S1, unofficial].

3.  **Rendering (Fragment Shader):**
    a. Return $C_{out}$ as the final fragment color [S1, unofficial].

**Pseudocode:**

```python
# Data structures
class Voxel:
    position: list[float]  # float3
    isSolid: float

_Voxels: list[Voxel]
_BoundsMin: list[float]
_CellHalfSize: float
_GridWidth: int
_GridHeight: int
_GridDepth: int
_TriangleCount: int
_MeshVertices: list[list[float]]
_MeshTriangleIndices: list[int]

def FillVolume(id_x: int, id_y: int, id_z: int) -> None:
    if id_x >= _GridWidth or id_y >= _GridHeight or id_z >= _GridDepth:
        return

    cell_size = _CellHalfSize * 2.0
    center_pos = [
        id_x * cell_size + _CellHalfSize + _BoundsMin[0],
        id_y * cell_size + _CellHalfSize + _BoundsMin[1],
        id_z * cell_size + _CellHalfSize + _BoundsMin[2]
    ]

    # Transform to local space for AABB definition
    aabb_center = WorldToLocal(center_pos)
    aabb_extents = [_CellHalfSize, _CellHalfSize, _CellHalfSize]

    intersects = False
    for i in range(0, _TriangleCount, 3):
        tri_a = _MeshVertices[_MeshTriangleIndices[i]]
        tri_b = _MeshVertices[_MeshTriangleIndices[i + 1]]
        tri_c = _MeshVertices[_MeshTriangleIndices[i + 2]]
        # Source does not provide the triangle-AABB intersection algorithm [G]
        if IntersectsTriangleAABB(tri_a, tri_b, tri_c, aabb_center, aabb_extents):
            intersects = True
            break

    voxel_index = id_x + _GridWidth * (id_y + _GridHeight * id_z)
    _Voxels[voxel_index].position = center_pos
    _Voxels[voxel_index].isSolid = 1.0 if intersects else 0.0

def VertexShader(instance_id: int) -> dict:
    v = _Voxels[instance_id]
    clip_pos = UnityWorldToClipPos(v.position)
    color = Lerp(_Color, _CollisionColor, v.isSolid)
    return {"clipPos": clip_pos, "color": color}

def FragmentShader(input_data: dict) -> list[float]:
    return input_data["color"]
```

**Parameters:**
*   `_Color`: `float3`, color for non-solid (empty) voxels [S1, unofficial].
*   `_CollisionColor`: `float3`, color for solid (occupied) voxels [S1, unofficial].
*   `_CellHalfSize`: `float`, half the width of a voxel in world units [S1, unofficial].
*   `_BoundsMin`: `float3`, minimum corner of the voxel grid in world space [S1, unofficial].

## Subtopics

### Voxel Module Initialization and Rendering
The module checks if the grid is a `PointDataGrid` [S2, unofficial]. If true, it sets `mDrawingPointGrid = true` and runs `PointDataOp` [S2, unofficial]. In `render()`, if `mDrawingPointGrid` is true, it enables `GL_POINT_SMOOTH` and `GL_VERTEX_PROGRAM_POINT_SIZE`, starts the flat shader, renders the interior buffer, stops the shader, and disables the point smooth states [S2, unofficial]. If `mDrawingPointGrid` is false, it starts the flat shader, renders the interior buffer and vector buffer, stops the shader, starts the surface shader, renders the surface buffer, and stops the shader [S2, unofficial].
