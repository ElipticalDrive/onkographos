# OpenGL Client State Array Rendering

Also called: OpenGL Rendering with Client State Arrays, RenderQuadArrays, RenderQuadGeometry, RenderTriangleArrays

## Overview
This method renders pre-generated voxel mesh data using OpenGL client state arrays for vertices, normals, and colors, supporting both indexed and non-indexed drawing [S1, unofficial]. It differs from modern core-profile rendering (such as [OpenGL Mesh Setup (VAO/VBO/EBO)](11322-opengl-mesh-setup-vao-vbo-ebo.md)) by relying on per-draw-call state enablement and pointer specification rather than encapsulated Vertex Array Objects (VAOs) [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: A chunk of voxel geometry containing vertex positions, normals, colors, and optional indices [S1, unofficial].
*   **Output**: Rasterized triangles or quads on the screen [S1, unofficial].

**Data Structures**
*   **Vertex**: 3 floats (`x, y, z`) [S1, unofficial].
*   **Normal**: 3 floats [S1, unofficial].
*   **Color**: 4 floats (`R, G, B, A`) [S1, unofficial].
*   **Index**: Unsigned integer [S1, unofficial].

**Parameters**
*   `BUFFER_OFFSET(0)`: Macro used to specify buffer offset, assumed to be 0 [S1, unofficial].
*   `Chunk::CHUNK_SIZE`: Scaling factor for geometry position translation [S1, unofficial].

**Steps**
1.  Push the current matrix mode [S1, unofficial].
2.  Translate by `geometryPosition * Chunk::CHUNK_SIZE` [S1, unofficial].
3.  Bind the vertex buffer [S1, unofficial].
4.  Enable `GL_VERTEX_ARRAY` and set vertex pointer (3 floats, stride 0) [S1, unofficial].
5.  Enable `GL_NORMAL_ARRAY` and set normal pointer [S1, unofficial].
6.  Enable `GL_COLOR_ARRAY` and set color pointer [S1, unofficial].
7.  For indexed rendering, set provoking vertex to `GL_FIRST_VERTEX_CONVENTION` and bind the element array buffer [S1, unofficial].
8.  Draw `GL_TRIANGLES` or `GL_QUADS` [S1, unofficial].
9.  Disable client states and pop the matrix [S1, unofficial].

**Pseudocode**
```python
# OpenGL legacy client state constants and functions (defined for self-containment)
GL_ARRAY_BUFFER = 0x8892
GL_ELEMENT_ARRAY_BUFFER = 0x8893
GL_FLOAT = 0x1406
GL_UNSIGNED_INT = 0x1405
GL_TRIANGLES = 0x0004
GL_QUADS = 0x0007
GL_VERTEX_ARRAY = 0x0001
GL_NORMAL_ARRAY = 0x0002
GL_COLOR_ARRAY = 0x0003
GL_FIRST_VERTEX_CONVENTION = 0x86E7

def glPushMatrix(): pass
def glTranslatef(x, y, z): pass
def glBindBuffer(target, buffer_id): pass
def glEnableClientState(cap): pass
def glDisableClientState(cap): pass
def glVertexPointer(size, type, stride, pointer): pass
def glNormalPointer(type, stride, pointer): pass
def glColorPointer(size, type, stride, pointer): pass
def glDrawArrays(mode, first, count): pass
def glDrawElements(mode, count, type, indices): pass
def glProvokingVertex(convention): pass
def glPopMatrix(): pass

BUFFER_OFFSET = lambda offset: offset

def render_triangle_arrays(geo_buffer, geometry_position, chunk_size):
    glPushMatrix()
    glTranslatef(geometry_position.x * chunk_size, geometry_position.y * chunk_size, geometry_position.z * chunk_size)
    glBindBuffer(GL_ARRAY_BUFFER, geo_buffer.vbo_id)
    glEnableClientState(GL_VERTEX_ARRAY)
    glVertexPointer(3, GL_FLOAT, 0, BUFFER_OFFSET(0))
    glEnableClientState(GL_NORMAL_ARRAY)
    glNormalPointer(GL_FLOAT, 0, BUFFER_OFFSET(3 * 4))
    glEnableClientState(GL_COLOR_ARRAY)
    glColorPointer(4, GL_FLOAT, 0, BUFFER_OFFSET(6 * 4))
    glDrawArrays(GL_TRIANGLES, 0, geo_buffer.vertex_count)
    glDisableClientState(GL_VERTEX_ARRAY)
    glDisableClientState(GL_NORMAL_ARRAY)
    glDisableClientState(GL_COLOR_ARRAY)
    glPopMatrix()

def render_quad_arrays(geo_buffer, geometry_position, chunk_size):
    glPushMatrix()
    glTranslatef(geometry_position.x * chunk_size, geometry_position.y * chunk_size, geometry_position.z * chunk_size)
    glBindBuffer(GL_ARRAY_BUFFER, geo_buffer.vbo_id)
    glEnableClientState(GL_VERTEX_ARRAY)
    glVertexPointer(3, GL_FLOAT, 0, BUFFER_OFFSET(0))
    glEnableClientState(GL_NORMAL_ARRAY)
    glNormalPointer(GL_FLOAT, 0, BUFFER_OFFSET(3 * 4))
    glEnableClientState(GL_COLOR_ARRAY)
    glColorPointer(4, GL_FLOAT, 0, BUFFER_OFFSET(6 * 4))
    glDrawArrays(GL_QUADS, 0, geo_buffer.vertex_count)
    glDisableClientState(GL_VERTEX_ARRAY)
    glDisableClientState(GL_NORMAL_ARRAY)
    glDisableClientState(GL_COLOR_ARRAY)
    glPopMatrix()

def render_quad_geometry(geo_buffer, geometry_position, chunk_size):
    glProvokingVertex(GL_FIRST_VERTEX_CONVENTION)
    glPushMatrix()
    glTranslatef(geometry_position.x * chunk_size, geometry_position.y * chunk_size, geometry_position.z * chunk_size)
    glBindBuffer(GL_ARRAY_BUFFER, geo_buffer.vbo_id)
    glEnableClientState(GL_VERTEX_ARRAY)
    glVertexPointer(3, GL_FLOAT, 0, BUFFER_OFFSET(0))
    glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, geo_buffer.ebo_id)
    glEnableClientState(GL_NORMAL_ARRAY)
    glNormalPointer(GL_FLOAT, 0, BUFFER_OFFSET(3 * 4))
    glEnableClientState(GL_COLOR_ARRAY)
    glColorPointer(4, GL_FLOAT, 0, BUFFER_OFFSET(6 * 4))
    glDrawElements(GL_QUADS, geo_buffer.index_count, GL_UNSIGNED_INT, BUFFER_OFFSET(0))
    glDisableClientState(GL_VERTEX_ARRAY)
    glDisableClientState(GL_NORMAL_ARRAY)
    glDisableClientState(GL_COLOR_ARRAY)
    glPopMatrix()
```

**Edge Cases and Pitfalls**
*   **Stride Assumption**: The source assumes tightly packed data with stride 0 [S1, unofficial]. If the buffer layout differs, pointer offsets must be adjusted accordingly [G].
*   **Provoking Vertex**: For indexed rendering, the provoking vertex convention must be explicitly set to `GL_FIRST_VERTEX_CONVENTION` to ensure correct normal interpolation for quads [S1, unofficial].
*   **Legacy API**: This method relies on deprecated OpenGL client state functions, making it incompatible with OpenGL Core Profile contexts without compatibility extensions [G].
