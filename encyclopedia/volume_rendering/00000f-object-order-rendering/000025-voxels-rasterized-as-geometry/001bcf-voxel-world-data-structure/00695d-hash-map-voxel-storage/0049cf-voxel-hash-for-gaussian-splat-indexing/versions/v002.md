# Voxel Hash for Gaussian Splat Indexing

Also called: Voxel Hash Map for Splat Indexing, VoxelHash, VoxelHash.build

## Overview
Voxel Hash is a sparse data structure that maps each 3D Gaussian Splat to the voxel cell containing its center $\mu$, enabling efficient lookup of splats within specific voxel regions for operations like carving or stacking [S1, unofficial]. It differs from sibling structures by maintaining a direct bidirectional mapping between splat indices and voxel keys, allowing for rapid identification of splats to remove or modify within a target voxel [S1, unofficial].

## How it works
**Inputs:** A list of 3D Gaussian Splats, each defined by a center position $\mu$ and an index, alongside a `VoxelGrid` instance defining the spatial bounds and resolution [S1, unofficial].
**Outputs:** A `VoxelHash` instance containing the mapping data [S1, unofficial].

**Data Structures:**
The `VoxelHash` class contains the following fields [S1, unofficial]:
*   `grid`: `readonly VoxelGrid` – The spatial grid configuration.
*   `stats`: `readonly VoxelHashStats` – Statistics about the hash state.
    *   `splatCount`: Total number of splats indexed.
    *   `voxelCount`: Number of occupied voxel cells.
    *   `maxSplatsInAnyVoxel`: Maximum number of splats in a single voxel.
    *   `meanSplatsPerVoxel`: Average number of splats per occupied voxel.
*   `keys`: `readonly ReadonlyArray<string>` – Sorted list of occupied voxel keys (ascending).
*   `cells`: `private readonly ReadonlyMap<string, Uint32Array>` – Maps a voxel key (string) to an array of splat indices (uint32).
*   `splatToCell`: `private readonly ReadonlyMap<number, string>` – Maps a splat index (number) to its voxel key (string).

**Build Process:**
1. Initialize `cellsBuilder` as an empty `Map<string, number[]>` and `splatToCell` as an empty `Map<number, string>` [S1, unofficial].
2. Iterate through all splats using a callback providing the splat `index` and center `center` [S1, unofficial].
3. For each splat, compute the voxel coordinates $\{i, j, k\}$ by calling `grid.worldToVoxel(center)` [S1, unofficial].
4. Generate the voxel key by calling `grid.voxelKey(i, j, k)` [S1, unofficial].
5. Append the splat `index` to the bucket `cellsBuilder[key]` using the `pushUnique` helper [S1, unofficial].
6. Set `splatToCell.set(index, key)` [S1, unofficial].
7. After iteration, finalize the structure: convert `cellsBuilder` values to `Uint32Array` instances, compute `stats` (max/mean splats per voxel, counts), sort `keys` ascending, and construct the `VoxelHash` instance [S1, unofficial].

**Pseudocode:**
```python
class VoxelHashStats:
    def __init__(self, splat_count: int, voxel_count: int, max_splats_in_any_voxel: int, mean_splats_per_voxel: float):
        self.splat_count = splat_count
        self.voxel_count = voxel_count
        self.max_splats_in_any_voxel = max_splats_in_any_voxel
        self.mean_splats_per_voxel = mean_splats_per_voxel

class VoxelHash:
    def __init__(self, grid, stats: VoxelHashStats, keys: list, cells: dict, splat_to_cell: dict):
        self.grid = grid
        self.stats = stats
        self.keys = keys
        self.cells = cells
        self.splat_to_cell = splat_to_cell

def push_unique(builder: dict, key: str, index: int) -> None:
    if key not in builder:
        builder[key] = []
    builder[key].append(index)

def build_voxel_hash(splats: list, grid) -> VoxelHash:
    cells_builder: dict = {}
    splat_to_cell: dict = {}

    for index, center in splats:
        i, j, k = grid.world_to_voxel(center)
        key = grid.voxel_key(i, j, k)
        push_unique(cells_builder, key, index)
        splat_to_cell[index] = key

    keys = sorted(cells_builder.keys())
    cells = {k: list(cells_builder[k]) for k in keys}

    splat_count = len(splats)
    voxel_count = len(keys)
    max_splats = max((len(v) for v in cells_builder.values()), default=0)
    mean_splats = splat_count / voxel_count if voxel_count > 0 else 0.0

    stats = VoxelHashStats(splat_count, voxel_count, max_splats, mean_splats)
    return VoxelHash(grid, stats, keys, cells, splat_to_cell)
```

**Edge Cases and Pitfalls:**
*   **Out-of-Bounds Splats:** Splats whose center lies outside the grid's AABB are still indexed under voxel keys that fail `VoxelGrid.contains`, serving as a signal for the caller to ignore them or expand the grid [S1, unofficial].
*   **Precision:** The mapping relies on `worldToVoxel` and `voxelKey` implementations; inconsistent coordinate system definitions between the grid and the splat data will lead to incorrect mappings [G].

## Operating characteristics
*   **Time Complexity:** Build time scales linearly with the number of splats due to single-pass iteration [S1, unofficial]. Lookup is $O(1)$ average case for both splat-to-voxel and voxel-to-splats operations, assuming constant-time hash map operations [G].
*   **Memory Complexity:** $O(N + V)$ where $V$ is the number of occupied voxels, as the structure stores one entry per splat and one entry per occupied voxel [G].
*   **Strengths:** Enables efficient "carving" operations by quickly identifying all splats within a target voxel cell [S1, unofficial].
*   **Limitations:** The indexing is based solely on the splat center $\mu$. This means splats with large covariances (large $\sigma$) that extend into neighboring cells are not indexed in those neighbors, which can lead to artifacts like "collateral darkening" or "visible wisps" if used for masking without additional fragment-level checks [S1, unofficial].

## Background
The Voxel Hash structure is used in the context of 3D Gaussian Splatting editing tools, specifically in the `splatcarve` project [S1, unofficial]. It was developed to address the limitations of per-splat masking, which cannot produce clean cube-shaped holes due to the discrete nature of splat centers [S1, unofficial]. The `splatcarve` implementation uses a `Data3DTexture` for fragment-level occupancy masking, while the Voxel Hash provides the necessary index mapping to manage the underlying splat data for carving and stacking operations [S1, unofficial].
