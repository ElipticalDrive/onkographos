# Absorption-Only Radiography via Unsorted Hexahedron Projection

Also called: Unsorted Hexahedron Projection, Absorption-Only Radiography

## Overview
This method simulates X-ray radiographs for curvilinear hexahedral meshes by accumulating optical thickness additively, thereby eliminating the need for a global back-to-front visibility sort [S1, unofficial]. It differs from standard polyhedron projection methods, which require sorting to correctly apply the Porter-Duff "over" operator for alpha compositing, by exploiting the commutative property of addition in the absorption-only regime ($J_\nu = 0$) [S1, unofficial].

## How it works
**Inputs:** A curvilinear hexahedral mesh; camera/viewpoint parameters; extinction coefficients ($K_\nu$) for the material; X-ray wavelength bands (up to 4).
**Outputs:** A 2D radiograph image representing accumulated attenuation.

**Data Structures:**
*   **P-buffer:** A floating-point off-screen buffer (texture) storing the accumulated optical thickness (attenuation) for each pixel. Initialized to zero.
*   **Mesh Cells:** Hexahedral cells, potentially subdivided into tetrahedra if degenerate or non-convex.

**Steps:**
1.  **Preprocessing (Subdivision):**
    *   For each hexahedral cell, determine if it can be projected directly. A cell is valid for direct projection if it is non-degenerate (no coinciding vertices) and the projection of every face is a convex quadrilateral [S1, unofficial].
    *   If a cell fails these checks, subdivide it into tetrahedra. Note: If these new tetrahedra share non-planar faces with adjacent non-subdivided cells, gaps or overlaps in viewing ray segments may occur, introducing small errors in total absorption [S1, unofficial].
    *   Group cells into passes to minimize P-buffer copies. Render as many non-overlapping cells as possible in a single pass before copying the P-buffer to a texture [S1, unofficial].

2.  **Projection (Software):**
    *   **Hexahedra:** Project the hexahedral cell into screen space using the method of Max [12]. This defines triangle fans or strips for all projections of a non-degenerate hexahedron, provided face projections are convex quadrilaterals [S1, unofficial].
    *   **Tetrahedra:** If subdivided, project each tetrahedron into screen space using the method of Shirley and Tuchman [16], dividing the projection into triangle fans [S1, unofficial].

3.  **Attribute Computation (Software):**
    *   For each vertex of the projected primitive, compute the attenuation contribution.
    *   Calculate the geometric thickness ($t$) of the cell segment along the viewing ray. This is computed in software using the cell geometry [S1, unofficial].
    *   Compute vertex attenuation: $A_v = K_\nu \times t$, where $K_\nu$ is the extinction coefficient for the specific wavelength band [S1, unofficial].

4.  **Rasterization and Accumulation (Hardware):**
    *   Render the projected primitives (triangles from fans/strips) to the P-buffer.
    *   **Fragment Program:**
        *   Interpolate the vertex attenuation values ($A_v$) across the triangle using hardware interpolation.
        *   Read the current accumulated attenuation from the image-aligned texture (the P-buffer) at the fragment's screen position.
        *   Compute the new accumulated attenuation: $A_{new} = A_{old} + A_{interpolated}$ [S1, unofficial].
        *   Write $A_{new}$ back to the P-buffer.
    *   **Parallelism:** Accumulate attenuation for up to four different X-ray wavelength bands in parallel by using the Red, Green, Blue, and Alpha channels of the P-buffer [S1, unofficial].

5.  **Texture Update:**
    *   After a pass of rendering, copy the P-buffer to a texture to keep it current for the next iteration. This is necessary because writes to output buffers are not guaranteed to be in polygon order, and the texture caching mechanism does not account for textures changing on the fly [S1, unofficial].

**Formulas:**
The physical model assumes self-emission is negligible ($J_\nu = 0$). The intensity recurrence is:
$$I_V[i+1] = e^{-\tau[i]} I_V[i]$$
where $I_V[i]$ is the intensity after cell $i$, and $\tau[i]$ is the optical thickness of cell $i$ [S1, unofficial].

Solving this recurrence yields a product of exponential terms, which is mathematically equivalent to the exponential of the sum of optical thicknesses:
$$I_{final} = I_{source} \exp\left(-\sum \tau_k\right)$$
Thus, accumulating optical thickness ($\tau = \int K_\nu ds$) additively is sufficient [S1, unofficial].

**Parameters:**
*   **Floating Point Precision:** Internal fragment computations use 32-bit floating point accuracy. The P-buffer must support floating point storage to maintain this accuracy, as standard framebuffer compositing operations lack this precision [S1, unofficial].
*   **Wavelength Bands:** Up to 4 bands (RGBA) [S1, unofficial].

**Pitfalls:**
*   **Degenerate Cells:** Hexahedral cells with coinciding vertices or non-convex face projections must be subdivided. Failure to do so results in incorrect projection [S1, unofficial].
*   **Non-Planar Faces:** Subdividing hexahedra into tetrahedra may create non-planar faces shared with adjacent non-subdivided cells. This causes gaps or overlaps in viewing ray segments, leading to small errors in total absorption [S1, unofficial].
*   **Performance:** Copying the P-buffer to a texture is slow. Minimizing the number of passes (by maximizing non-overlapping cells per pass) is critical for performance [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of projected primitives. Performance is heavily influenced by the cost of P-buffer to texture copies. Minimizing passes reduces this overhead [S1, unofficial].
*   **Memory Complexity:** Requires a floating-point P-buffer proportional to screen resolution. Additional memory for mesh storage [S1, unofficial].
*   **Strengths:** Eliminates the expensive global back-to-front sort required by standard volume rendering. Handles curvilinear hexahedral meshes directly, saving mesh storage and rendering time compared to tetrahedral-only approaches [S1, unofficial]. Supports multi-spectral (multi-wavelength) accumulation in parallel [S1, unofficial].
*   **Limitations:** Limited to absorption-only scenarios ($J_\nu = 0$). Floating-point framebuffer support is required. Potential accuracy errors from tetrahedral subdivision of degenerate hexahedra [S1, unofficial].
*   **When to use:** Industrial and medical X-ray simulation where emissivity is negligible and meshes are hexahedral [S1, unofficial].
*   **When not to use:** When emissivity is significant, or when high-precision floating-point framebuffers are unavailable [S1, unofficial].

## Background
This technique was developed for industrial and medical settings where X-ray self-emission is negligible [S1, unofficial]. It builds on the polyhedron projection method [S1, unofficial]. The projection of hexahedra uses the method of Max [12], and tetrahedra use the method of Shirley and Tuchman [16]. The use of a P-buffer for floating-point accumulation addresses the lack of 32-bit floating-point compositing in standard graphics hardware at the time of publication [S1, unofficial].
