# Absorption-Only Radiography via Unsorted Hexahedron Projection

Also called: Unsorted Hexahedron Projection, Additive Optical Thickness Accumulation

## Overview
A hardware-accelerated technique to simulate radiographs in the absorption-only regime (emissivity $J=0$) for curvilinear hexahedral meshes [S1, unofficial]. It avoids the need for a global back-to-front visibility sort by accumulating optical thickness additively, leveraging the commutativity of addition [S1, unofficial]. It sets itself apart from sibling methods like [Hardware-Assisted Projected Tetrahedra](1729-hardware-assisted-projected-tetrahedra.md) by supporting direct projection of hexahedral cells, reducing mesh storage and rendering overhead for curvilinear grids, while differing from [Hardware-Assisted Polyhedron Projection](1453-hardware-assisted-polyhedron-projection.md) in its specific handling of hexahedral degeneracy and the use of a P-buffer for floating-point accumulation.

## How it works
**Inputs:** A curvilinear hexahedral mesh (or a mixed mesh containing tetrahedra), camera parameters (view and projection matrices), and extinction coefficients $K_\nu$ for one or more X-ray wavelength bands.
**Outputs:** A 2D radiograph image representing the accumulated optical thickness (or intensity) on the detector plane.

**Data Structures:**
*   **Hexahedron:** Defined by 8 vertices. Each vertex has 3D coordinates $(x,y,z)$.
*   **Extinction Coefficient:** Scalar $K_\nu$ per cell or per vertex.
*   **P-Buffer:** A floating-point off-screen buffer (texture) storing the accumulated optical thickness $\tau_{acc}$ per pixel. Initialized to zero.
*   **Triangle Fan/Strip Representation:** Pre-computed or on-the-fly decomposition of the hexahedron projection into rasterizable primitives.

**Method Steps:**

1.  **Mesh Decomposition:**
    *   For each hexahedral cell, determine if it can be projected directly. A hexahedron is projectable if its projection is non-degenerate and the projection of each of its 6 faces is a convex quadrilateral [S1, unofficial].
    *   If the hexahedron is degenerate (coinciding vertices) or has non-convex face projections, subdivide it into tetrahedra [S1, unofficial].
    *   For projectable hexahedra, define triangle fans or strips for all valid projections of a non-degenerate hexahedron as described by Max [S1, unofficial].
    *   For tetrahedra (either original or subdivided), divide the image plane projection into triangle fans using the method of Shirley and Tuchman [S1, unofficial].

2.  **Vertex Attribute Computation (Software):**
    *   For each vertex of the rasterizable primitive (triangle fan/strip), compute the geometric thickness $l$ of the viewing ray segment within the cell. This is computed in software using the cell geometry and camera position [S1, unofficial].
    *   Compute the attenuation value $A$ for each vertex:
        $$ A = K_\nu \cdot l $$
        where $K_\nu$ is the extinction coefficient and $l$ is the thickness [S1, unofficial].

3.  **Rasterization and Accumulation (Hardware):**
    *   Project the vertices of the primitive into screen space.
    *   Interpolate the attenuation value $A$ across the primitive using hardware interpolation [S1, unofficial].
    *   In the fragment program, read the accumulated optical thickness $\tau_{acc}$ from the P-buffer texture at the current pixel location.
    *   Add the interpolated attenuation $A$ to the accumulated value:
        $$ \tau_{new} = \tau_{acc} + A $$
    *   Write $\tau_{new}$ back to the P-buffer texture [S1, unofficial].

4.  **Texture Synchronization:**
    *   After rendering a batch of cells, copy the P-buffer to a texture to keep the texture current for the next iteration. This is necessary because writes to output buffers are not guaranteed to be in polygon order, and the texture caching mechanism does not account for textures changing on the fly [S1, unofficial].
    *   To minimize the cost of copying, render as many non-overlapping cells as possible in a single pass before copying [S1, unofficial].

5.  **Final Intensity Calculation:**
    *   After all cells have been processed, the final intensity $I$ for each pixel is derived from the total accumulated optical thickness $\tau_{total}$:
        $$ I = I_0 e^{-\tau_{total}} $$
        where $I_0$ is the incident intensity (assumed constant or known) [S1, unofficial].

```python
# Initialization
P_Buffer = create_floating_point_texture(width, height, channels=4) # RGBA for 4 wavelength bands
P_Buffer.fill(0.0)

# Pre-compute triangle fans/strips for hexahedra if possible
# Subdivide degenerate hexahedra into tetrahedra
cells = decompose_mesh(hexahedral_mesh)

# Render loop
for batch in split_into_non_overlapping_batches(cells):
    for cell in batch:
        # Get vertices and their 3D positions
        vertices = cell.get_vertices()
        
        # Compute thickness and attenuation for each vertex
        vertex_attenuations = []
        for v in vertices:
            l = compute_ray_thickness(v, cell.geometry, camera)
            K = cell.extinction_coefficient
            A = K * l
            vertex_attenuations.append(A)
        
        # Rasterize the cell's projection
        # The rasterizer interpolates A across the screen-space primitive
        # Fragment shader:
        #   tau_acc = texture(P_Buffer, gl_FragCoord.xy).r # Read accumulated thickness
        #   tau_new = tau_acc + interpolated_A
        #   color = vec4(tau_new, tau_new, tau_new, tau_new) # Accumulate in all channels if needed
        #   gl_FragColor = color
        rasterize_primitive(vertices, vertex_attenuations)
    
    # Copy P-Buffer to texture for next iteration
    # This ensures the texture is up-to-date and cache-coherent
    current_texture = copy_texture(P_Buffer)
    P_Buffer = current_texture

# Final pass to compute intensity
for pixel in image_plane:
    tau_total = P_Buffer.read(pixel)
    I = I_0 * exp(-tau_total)
    image.write(pixel, I)
```

**Edge Cases and Pitfalls:**
*   **Degenerate Hexahedra:** Hexahedral cells with coinciding vertices or non-convex face projections must be subdivided into tetrahedra [S1, unofficial].
*   **Non-Planar Faces:** If subdivided tetrahedra share non-planar faces with adjacent non-subdivided cells, gaps or overlaps in viewing ray segments may occur, introducing small errors in total absorption [S1, unofficial].
*   **Precision:** Floating-point accuracy is required for attenuation computation. Standard framebuffer compositing may not support 32-bit floating-point accuracy, necessitating the use of a P-buffer and fragment program [S1, unofficial].
*   **Texture Caching:** Writes to output buffers are not guaranteed to be in polygon order, and texture caching does not account for on-the-fly changes, requiring explicit texture copying [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of cells, assuming constant-time projection and rasterization. The need for subdivision and batch processing adds overhead.
*   **Memory Complexity:** $O(W \cdot H)$ for the P-buffer, where $W$ and $H$ are the image dimensions.
*   **Performance:** The method is hardware-accelerated, leveraging the GPU's rasterization pipeline. The use of a P-buffer and texture copying introduces latency, mitigated by batching non-overlapping cells [S1, unofficial].
*   **Strengths:** No global sort required; supports curvilinear hexahedral meshes directly; parallel accumulation of multiple wavelength bands [S1, unofficial].
*   **Limitations:** Precision issues with standard framebuffer compositing; potential errors from non-planar faces after subdivision; texture copying overhead [S1, unofficial].
*   **When to Use:** Industrial and medical X-ray simulation where self-emission is negligible and high accuracy is required [S1, unofficial].
*   **When Not to Use:** When emissivity is significant (requires full radiative transfer equation); when mesh is highly degenerate and requires extensive subdivision.

## Background
