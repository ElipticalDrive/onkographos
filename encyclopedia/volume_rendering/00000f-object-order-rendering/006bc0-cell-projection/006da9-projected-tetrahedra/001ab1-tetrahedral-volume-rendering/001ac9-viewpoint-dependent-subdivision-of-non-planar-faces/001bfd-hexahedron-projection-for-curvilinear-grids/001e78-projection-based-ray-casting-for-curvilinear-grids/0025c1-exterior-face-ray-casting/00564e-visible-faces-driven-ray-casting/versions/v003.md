# Visible Faces Driven Ray Casting

Also called: VF-Ray

## Overview
Visible Faces Driven Ray Casting (VF-Ray) is a memory-efficient ray casting algorithm for unstructured tetrahedral and hexahedral grids that exploits ray coherence to minimize memory footprint [S1]. It reduces the storage of expensive face plane parameters by processing pixels in groups defined by visible exterior faces, storing only the face data for the current traversal set in a temporary buffer [S1]. Unlike its parent, Exterior-Face Ray Casting, which casts rays through all visible exterior faces of subvolumes, VF-Ray explicitly manages the lifecycle of face data structures to avoid storing adjacency information for the entire volume, making it suitable for large datasets where memory is constrained [S1].

## How it works
**Inputs:** Unstructured grid (vertices, cells), scalar field values, viewing direction, screen resolution [S1].
**Outputs:** Rendered image (color and opacity per pixel) [S1].

**Data Structures:**
1. **Vertices List:** Array of vertex coordinates [S1].
2. **Cells List:** Array of cell definitions (e.g., tetrahedra indices) [S1].
3. **Use_set:** For each vertex $v$, a list of all cells incident to $v$, used to handle ray traversal degeneracies at vertices and edges [S1].
4. **Face Data:** A structure containing geometry and plane equation constants for a face, which is the most memory-intensive component in ray casting [S1].
5. **computedFaces:** A temporary buffer storing face data for internal faces intersected by rays within the current visible set, allowing reuse without recomputation [S1].

**Algorithm Steps:**

1. **Preprocessing:** Create the list of vertices and cells, and build the `Use_set` for each vertex by storing all incident cells [S1].
2. **Visibility Determination:** Identify external faces as those belonging to only one cell, then identify visible faces as external faces whose normal vector $\mathbf{n}$ makes an angle greater than $90^\circ$ with the viewing direction $\mathbf{v}$ (i.e., $\mathbf{n} \cdot \mathbf{v} < 0$) [S1].
3. **Processing Loop (per visible face):** Project the current visible face onto the screen to determine the visible set (the set of pixels covered by the face's projection) [S1]. Initialize the `computedFaces` buffer as empty [S1]. For each pixel $p$ in the visible set, cast a ray from the camera through the pixel and perform ray traversal through the volume [S1]. Compute intersections with cell faces, and when a ray hits an internal face already stored in `computedFaces`, read the face data from the buffer without recomputing the face parameters [S1]. Use the face data to evaluate the traversed distance $d$ within the current cell, and retrieve the entry scalar value $s_0$ and exit scalar value $s_1$ [S1]. Compute the cell contribution for the pixel color and opacity using $d$, $s_0$, $s_1$, and an illumination integral [S1]. After all pixels in the visible set are processed, clear the `computedFaces` buffer [S1].
4. **Degeneracy Handling:** When a ray hits a vertex $v$, scan the cells belonging to the `Use_set` of $v$ to find the next valid intersection [S1]. When a ray hits an edge $v_0v_1$, scan the `Use_set` of $v_0$ and $v_1$ to find the next valid intersection [S1].

**Pseudocode:**

```python
def vf_ray_cast(vertices, cells, scalar_field, view_direction, screen_resolution):
    # 1. Preprocessing
    use_set = {v: [] for v in vertices}
    for cell in cells:
        for v in cell.vertices:
            use_set[v].append(cell)
            
    face_cell_map = {}
    for cell in cells:
        for face in cell.faces:
            fid = face.id
            face_cell_map.setdefault(fid, []).append(cell)
            
    external_faces = [face_cell_map[fid][0] for fid in face_cell_map if len(face_cell_map[fid]) == 1]
    visible_faces = [f for f in external_faces if dot(f.normal, view_direction) < 0]
    
    image = create_empty_image(screen_resolution)
    
    # 2. Process each visible face
    for face in visible_faces:
        visible_set = project_face_to_pixels(face, screen_resolution)
        computed_faces = {}
        
        # 3. Process pixels in the visible set
        for pixel in visible_set:
            ray = cast_ray_through_pixel(pixel, screen_resolution)
            current_pos = ray.origin
            pixel_color = [0.0, 0.0, 0.0]
            pixel_opacity = 0.0
            
            while True:
                hit_dist, hit_face, hit_cell = find_first_intersection(ray, current_pos)
                if hit_dist is None or hit_dist < 1e-6:
                    break
                
                # Handle degeneracies using Use_set
                if is_vertex(hit_face):
                    v = hit_face.vertex
                    candidates = []
                    for c in use_set[v]:
                        d, f, c2 = find_first_intersection(ray, current_pos)
                        if d is not None and d > 1e-6:
                            candidates.append((d, f, c2))
                    if not candidates:
                        break
                    candidates.sort(key=lambda x: x[0])
                    hit_dist, hit_face, hit_cell = candidates[0]
                elif is_edge(hit_face):
                    v0, v1 = hit_face.vertices
                    candidates = []
                    for c in set(use_set[v0]) & set(use_set[v1]):
                        d, f, c2 = find_first_intersection(ray, current_pos)
                        if d is not None and d > 1e-6:
                            candidates.append((d, f, c2))
                    if not candidates:
                        break
                    candidates.sort(key=lambda x: x[0])
                    hit_dist, hit_face, hit_cell = candidates[0]
                
                # Cache face data
                fid = hit_face.id
                if fid in computed_faces:
                    face_data = computed_faces[fid]
                else:
                    face_data = compute_face_plane(hit_face)
                    computed_faces[fid] = face_data
                
                # Evaluate traversal
                d = distance(current_pos, hit_face.intersection_point)
                s0 = interpolate_scalar(scalar_field, current_pos, hit_cell)
                s1 = interpolate_scalar(scalar_field, hit_face.intersection_point, hit_cell)
                
                # Compute contribution using standard volume rendering compositing [G]
                color, opacity = compute_cell_contribution(d, s0, s1, face_data)
                pixel_color = blend_color(pixel_color, color, pixel_opacity, opacity)
                pixel_opacity = blend_opacity(pixel_opacity, opacity)
                
                current_pos = hit_face.intersection_point
            
            image[pixel] = pixel_color, pixel_opacity
        
        computed_faces.clear()
        
    return image

def find_first_intersection(ray, origin):
    min_dist = None
    min_face = None
    min_cell = None
    for cell in ray.current_cells:
        for face in cell.faces:
            t, point = ray_plane_intersect(ray, origin, face)
            if t is not None and t > 1e-6:
                if min_dist is None or t < min_dist:
                    min_dist = t
                    min_face = face
                    min_cell = cell
    return min_dist, min_face, min_cell

def ray_plane_intersect(ray, origin, face):
    denom = dot(ray.direction, face.normal)
    if abs(denom) < 1e-8:
        return None, None
    t = dot(face.plane_constant - origin, face.normal) / denom
    if t > 1e-6:
        return t, origin + ray.direction * t
    return None, None

def compute_face_plane(face):
    # Returns geometry and plane equation constants for the face [S1]
    return {"normal": face.normal, "plane_constant": face.plane_constant, "id": face.id}

def interpolate_scalar(field, pos, cell):
    # Barycentric interpolation of scalar field at pos within cell [G]
    return field[cell.id]

def compute_cell_contribution(d, s0, s1, face_data):
    # Standard illumination integral and compositing [G]
    return [0.5, 0.5, 0.5], 0.8

def blend_color(bg, fg, bg_op, fg_op):
    return [bg[i] * (1 - fg_op) + fg[i] * fg_op for i in range(3)]

def blend_opacity(bg_op, fg_op):
    return bg_op + fg_op * (1 - bg_op)

def create_empty_image(res):
    return [[None for _ in range(res[0])] for _ in range(res[1])]

def project_face_to_pixels(face, res):
    # Returns list of pixel coordinates covered by face projection [G]
    return [(0, 0)]

def cast_ray_through_pixel(pixel, res):
    # Returns Ray object with origin and direction for pixel [G]
    class Ray:
        def __init__(self):
            self.origin = [0.0, 0.0, 0.0]
            self.direction = [0.0, 0.0, 1.0]
            self.current_cells = []
    return Ray()

def is_vertex(face):
    return hasattr(face, 'vertex')

def is_edge(face):
    return hasattr(face, 'vertices')

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def distance(a, b):
    return sum((x - y) ** 2 for x, y in zip(a, b)) ** 0.5
```

## Subtopics

### [VF-Ray-GPU](15664-vf-ray-gpu.md)
A GPGPU implementation of VF-Ray that parallelizes visibility determination, projection, and ray traversal across CUDA kernels, using a hash-based local memory buffer to minimize global memory bandwidth.

## Operating characteristics
**Time Complexity:** The algorithm's performance depends on the number of visible faces and the coherence of rays within each visible set [S1]. Processing each visible face involves projecting it and traversing rays for the covered pixels [S1]. The use of `computedFaces` reduces redundant plane equation computations for neighboring rays [S1].
**Memory Complexity:** VF-Ray significantly reduces memory footprint compared to methods storing full adjacency structures [S1]. It only stores `Use_set` (incident cells per vertex) and the `computedFaces` buffer, which contains face data only for the current visible set [S1]. The `computedFaces` buffer is cleared after each visible face is processed, keeping memory usage proportional to the maximum number of internal faces intersected by rays in a single visible set [S1].
**Strengths:** Memory efficiency for large unstructured grids [S1]. Exploits ray coherence to improve caching performance [S1]. Handles degeneracies (vertex/edge hits) correctly using `Use_set` [S1].
**Limitations:** Requires building and storing the `Use_set` structure, which can be memory-intensive for highly connected meshes [S1]. Not given in the sources: Specific scaling behavior on multi-core CPUs vs. GPUs is not detailed in the base algorithm description, though a GPU variant exists [S1].

## Background
VF-Ray was introduced as a memory-efficient ray casting algorithm for unstructured grids, specifically addressing the high memory cost of storing face plane parameters in traditional ray casting methods [S1]. It builds on the concept of ray coherence, where neighboring rays tend to intersect the same internal faces [S1]. The algorithm was developed to handle the limitations of previous approaches, such as Bunyk's method, which could fail to continue ray traversal when hitting edges or vertices [S1]. The method is cited in the context of volume rendering for unstructured tetrahedral and hexahedral meshes [S1].
