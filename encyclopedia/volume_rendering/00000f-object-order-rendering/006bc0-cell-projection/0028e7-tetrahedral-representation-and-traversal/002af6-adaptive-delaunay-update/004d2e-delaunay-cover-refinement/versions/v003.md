# Delaunay Cover Refinement
## Overview
Delaunay Cover Refinement is a mesh generation technique that iteratively subdivides a Delaunay triangulation to ensure all edge lengths are bounded by a user-defined threshold $h$ [S1, unofficial]. It solves the problem of generating a uniformly sampled point cloud from an initial point set, which serves as a prerequisite for subsequent voxelization or surface reconstruction steps [S1, unofficial]. Unlike standard Delaunay Triangulation which only optimizes local geometry, this method enforces a global density constraint through recursive splitting [S1, unofficial].
## How it works
**Inputs:**
- Initial point set $P$.
- Maximum edge length threshold $h$.

**Outputs:**
- Refined point cloud $P_\kappa$.
- Final Delaunay cover $DC_\kappa(P)$.

**Data Structures:**
- Point cloud $P_i$: A list of 3D coordinates. [S1, unofficial]
- Delaunay cover $DC_i(P)$: A set of triangles (simplices) defined by vertices from $P_i$. [S1, unofficial]

**Algorithm:**
1. Initialize $P_0 = P$ and compute the initial Delaunay cover $DC_0(P)$. [S1, unofficial]
2. Iterate $i$ from 0 upwards:
   a. Identify all triangles in $DC_i(P)$ that contain at least one edge with length greater than $h$. [S1, unofficial]
   b. For each such triangle, perform a 1-to-4 split:
      i. Calculate the midpoints of the three edges of the triangle. [S1, unofficial]
      ii. Insert these three midpoints into the point set to form $P_{i+1}$. [S1, unofficial]
      iii. Recompute the Delaunay triangulation for the updated point set to form $DC_{i+1}(P)$. [S1, unofficial]
   c. If no triangles in $DC_i(P)$ have edges longer than $h$, terminate. [S1, unofficial]
   d. Otherwise, increment $i$ and repeat.

**Formulas:**
- Edge length check: $\|v_j - v_k\| > h$ for vertices $v_j, v_k$ of a triangle. [S1, unofficial]
- Midpoint calculation: $m = \frac{v_j + v_k}{2}$. [S1, unofficial]

**Parameters:**
- $h$: The maximum allowed edge length. Typical values depend on the desired sampling density relative to the scene scale. [G]

**Edge Cases and Pitfalls:**
- **Precision:** Floating-point errors in midpoint calculation may cause slight deviations from exact geometric centers, potentially affecting Delaunay properties. [G]
- **Boundaries:** The method assumes a bounded domain. The resulting point cloud is confined to the convex hull of the initial points. [S1, unofficial]
- **Termination:** The process is guaranteed to terminate because each split reduces the maximum edge length in the affected region, and the number of points is finite for a bounded domain with fixed $h$. [G]

**Pseudocode:**
```python
def delaunay_cover_refinement(points, h):
    """
    Iteratively refine a Delaunay cover until all edges are <= h.
    
    Args:
        points: List of 3D points (initial P_0).
        h: Maximum edge length threshold.
        
    Returns:
        Refined point cloud P_kappa.
    """
    current_points = list(points)
    
    while True:
        # Compute Delaunay triangulation of current_points (standard algorithm, not specified in sources)
        triangles = [] # [G] Standard Delaunay computation
        
        needs_refinement = False
        new_midpoints = []
        
        for tri in triangles:
            v0, v1, v2 = tri
            edges = [(v0, v1), (v1, v2), (v2, v0)]
            
            for p1, p2 in edges:
                dist = ((p1[0]-p2[0])**2 + (p1[1]-p2[1])**2 + (p1[2]-p2[2])**2)**0.5
                if dist > h:
                    needs_refinement = True
                    mid = ((p1[0]+p2[0])/2.0, (p1[1]+p2[1])/2.0, (p1[2]+p2[2])/2.0)
                    if mid not in new_midpoints:
                        new_midpoints.append(mid)
        
        if not needs_refinement:
            break
        current_points.extend(new_midpoints)
        
    return current_points
```

## Operating characteristics
- **Time Complexity:** Not explicitly given, but depends on the number of refinement iterations $\kappa$ and the cost of recomputing the Delaunay triangulation at each step. [G]
- **Memory Complexity:** Proportional to the number of points in the final cloud $P_\kappa$. [G]
- **Strengths:** Guarantees uniform sampling density bounded by $h$. Simple to implement. [S1, unofficial][G]
- **Limitations:** Requires recomputing the Delaunay triangulation iteratively, which can be computationally expensive for large datasets. [G]
- **Limitations:** Does not inherently handle non-convex geometries without additional constraints. [G]
- **When to use:** When a uniformly sampled point cloud is needed for voxelization or as input for surface reconstruction algorithms that require bounded edge lengths. [S1, unofficial][G]
## Background
Originated in the context of volumetric snapping and watertight triangulation of point clouds [S1, unofficial]. The method is part of a pipeline that converts point clouds into voxel grids for volume rendering applications [S1, unofficial].
