# TetraSDF

Also called: Analytic Isosurface Extraction, Analytic Isosurface Extraction with Multi-resolution Tetrahedral Grid, TetraSDF extraction

## Overview
TetraSDF is an analytic isosurface extraction framework for neural Signed Distance Functions (SDFs) that represents the SDF as a ReLU Multi-Layer Perceptron (MLP) composed with a multi-resolution tetrahedral positional encoder [S1]. It solves the problem of discretization error inherent in sampling-based methods like Marching Cubes by preserving a global Continuous Piecewise Affine (CPWA) structure, enabling exact extraction of the network's zero-level set without geometric deviation [S1][S2, unofficial]. Unlike plain ReLU MLPs with analytic marching which fail to capture fine high-frequency details, TetraSDF retains the expressiveness of grid-based encoders while allowing exact mesh extraction [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A trained neural SDF model $f = \nu^{(M)} \circ \tau$, where $\nu^{(M)}$ is an $M$-layer ReLU network and $\tau$ is the multi-resolution tetrahedral positional encoder [S1]. The encoder parameters include the number of levels $L$, minimum resolution $N_{\min}$, maximum resolution $N_{\max}$, and hash table size [S1].
*   **Output:** A triangular mesh representing the zero-level set $\{x \mid f(x) = 0\}$.

**Data Structures:**
1.  **Multi-resolution Tetrahedral Grid:** Defined by $L$ levels. Level $\ell$ has resolution $N_\ell$. Each unit cube cell at level $\ell$ is decomposed into 6 congruent tetrahedra [S1].
2.  **Region Indicator $\mathbf{r}(\mathbf{x})$:** A vector of size $4L$. For each level $\ell$, it concatenates the grid anchor $\mathbf{a}^{(\ell)}(\mathbf{x}) = \lfloor N_\ell \mathbf{x} \rfloor$ (lexicographically smallest vertex of the containing cube) and the tetrahedron offset $t^{(\ell)}(\mathbf{x}) \in \{0, \dots, 5\}$ [S1].
3.  **Barycentric Mask $\mathbf{m}(\mathbf{x})$:** A binary vector of size $4L$. For each level $\ell$, entry $i$ is $1$ if barycentric weight $w_i^{(\ell)}(\mathbf{x}) > \epsilon_b$, else $0$. Zeros indicate boundaries (faces, edges, or vertices) [S1].
4.  **Sign Vector $\mathbf{s}_k^{(m)}(\mathbf{x})$:** Tracks the state of the $k$-th neuron in the $m$-th layer. Entry $\gamma_j^{(i)}(\mathbf{x})$ is $+1$ if preactivation $> \epsilon_s$, $-1$ if $< -\epsilon_s$, and $0$ if $|\text{preactivation}| \le \epsilon_s$ [S1].
5.  **Skeleton $(V, E)$:** Sets of vertices and edges representing the polyhedral complex and linear regions [S1].

**Parameters:**
*   $L$: Number of resolution levels [S1].
*   $N_{\min}, N_{\max}$: Min/Max grid resolutions [S1].
*   $\epsilon_s$: Small positive constant for decision boundary detection [S1].
*   $\epsilon_b$: Small threshold for barycentric mask [S1].
*   `grid_resolution`: Integer resolution for scaling points, typically 256 [S2, unofficial].
*   `use_A`: Boolean flag for input preconditioner, enabled by default [S2, unofficial].

**Algorithm Steps:**

1.  **Input Preconditioning (Optional but recommended):**
    Compute the Jacobian $\mathbf{J}_{\mathcal{T}}$ of the barycentric weights [S1]. Calculate the average local metric $\mathbf{M} = \frac{1}{6} \sum_{\mathcal{T}} \mathbf{J}_{\mathcal{T}}^\top \mathbf{J}_{\mathcal{T}}$ [S1]. Apply a global linear preconditioner $\mathbf{A}^*$ such that $\mathbf{x}' = \mathbf{A}^* \mathbf{x}$ isotropizes $\mathbf{M}$, reducing the condition number from 16.39 to 5.05 [S1]. If `use_A` is false, $\mathbf{x}' = \mathbf{x}$ [S2, unofficial].

2.  **Initial Skeleton Extraction:**
    Represent the encoder-induced polyhedral cells $\mathcal{C}_{\mathbf{x}}$ as unions of parallel-plane sets [S1]. Group shared normals $\mathcal{N} = \{\mathbf{n}_0, \dots\}$ with level-dependent offsets $d^{(i)}$ [S1]. Extract vertices as intersections of 3+ planes with linearly independent normals [S1]. Extract edges as intersections of 2+ non-parallel planes [S1]. This forms the initial vertex set $V$ and edge set $E$ [S1].

3.  **Edge Subdivision (Joint Tracking):**
    Process all decision boundaries $H_k^{(m)}$ of the ReLU network in increasing order of layer $m$ and neuron index $k$ [S1].
    For each boundary $H_k^{(m)}$:
    a. Iterate through all edges $(\mathbf{x}_0, \mathbf{x}_1) \in E$ [S1].
    b. Compute sign vector entries $\gamma_k^{(m)}(\mathbf{x}_0)$ and $\gamma_k^{(m)}(\mathbf{x}_1)$ [S1].
    c. If $\gamma_k^{(m)}(\mathbf{x}_0) \gamma_k^{(m)}(\mathbf{x}_1) < 0$, the edge crosses the boundary [S1].
    d. Compute preactivation values $d_0 = \nu_k^{(m)}(\mathbf{x}_0)$ and $d_1 = \nu_k^{(m)}(\mathbf{x}_1)$ [S1].
    e. Calculate intersection weight $w = \frac{d_0}{d_0 - d_1}$ [S1].
    f. Compute intersection point $\hat{\mathbf{x}}_{0,1} = (1 - w)\mathbf{x}_0 + w\mathbf{x}_1$ [S1].
    g. Add $\hat{\mathbf{x}}_{0,1}$ to $V$.
    h. Split edge $(\mathbf{x}_0, \mathbf{x}_1)$ into $(\mathbf{x}_0, \hat{\mathbf{x}}_{0,1})$ and $(\hat{\mathbf{x}}_{0,1}, \mathbf{x}_1)$ in $E$ [S1].

4.  **Grid-Aware Subdivision (Handling Polyhedral Cells):**
    The edge subdivision above handles ReLU boundaries [S1]. To handle the encoder's polyhedral cells, use the region indicator $\mathbf{r}(\mathbf{x})$ and barycentric mask $\mathbf{m}(\mathbf{x})$ [S1]. When a point lies on a boundary (zero in $\mathbf{m}$), identify neighboring cells by perturbing $\mathbf{r}(\mathbf{x})$ according to the zero pattern [S1]. Precompute lookup tables for neighbor configurations (anchor displacements) for each level [S1].

5.  **Face Extraction:**
    From the final sets $V$ and $E$, determine valid faces [S1]. A candidate edge formed by two intersection points is valid if:
    a. Their sign vectors match on all non-zero entries (zeros are wildcards) [S1].
    b. If a vertex pair shares at least two zero entries in their masks, they are connected [S1].
    Construct triangles from these connected vertices [S1].

## Subtopics

### [Tensorized Edge Construction from Planes](13262-tensorized-edge-construction-from-planes.md)
Computes intersection lines between pairs of planes sharing a common vertex in a tetrahedral mesh to extract the zero-level set of a continuous piecewise affine scalar field. It distinguishes itself from voxel-based methods like marching cubes by operating directly on analytic plane intersections, enabling exact zero-level set extraction without grid resolution artifacts [G].

## Operating characteristics
*   **Time Complexity:** Depends on the number of ReLU neurons and the complexity of the polyhedral complex [S1]. The edge subdivision algorithm processes boundaries sequentially, which can be expensive for deep networks with many neurons [S1]. However, the tensorized scheme for handling polyhedral structures enables efficient GPU implementation [S1].
*   **Memory Complexity:** Scales with the number of resolution levels $L$ and the hash table size [S1]. Model capacity 'large' uses ~8 GB GPU memory, 'medium' ~1.5 GB, 'small' less [S2, unofficial].
*   **Performance:** Matches or surpasses existing grid-based encoders in reconstruction accuracy [S1]. On the Stanford dataset, the fraction of faces with minimum angle below 5 degrees is 11.83% for TetraSDF, compared to 10.05% for AM and 10.94% for TropicalNeRF [S1].
*   **Strengths:** Exact agreement with the learned zero-level set; preserves fine geometric detail without extraction error; handles high-frequency SDFs via multi-resolution encoder [S2, unofficial].
*   **Limitations:** Triangle regularity (minimum angle) is not optimized during extraction, potentially resulting in skinny triangles (11.83% < 5 degrees on Stanford dataset) [S1]. Requires custom CUDA extensions for efficient training and extraction [S2, unofficial].
*   **When to use:** When exact geometric fidelity to the neural SDF is required, and fine detail preservation is critical [G].
*   **When not to use:** When computational efficiency of extraction is paramount and some discretization error is acceptable (use Marching Cubes); when triangle regularity is strictly required without post-processing [S1].

## Background
TetraSDF was introduced by Seonghun Oh, Youngjung Uh, and Jin-Hwa Kim from Yonsei University, NAVER AI Lab, and Seoul National University [S1]. It addresses the limitations of Marching Cubes (discretization error) and plain ReLU MLPs (lack of high-frequency detail) by combining multi-resolution tetrahedral positional encoding with analytic isosurface extraction [S1]. The method extends the edge subdivision algorithm to operate jointly on encoder-induced polyhedral cells and ReLU MLP linear regions [S1].
