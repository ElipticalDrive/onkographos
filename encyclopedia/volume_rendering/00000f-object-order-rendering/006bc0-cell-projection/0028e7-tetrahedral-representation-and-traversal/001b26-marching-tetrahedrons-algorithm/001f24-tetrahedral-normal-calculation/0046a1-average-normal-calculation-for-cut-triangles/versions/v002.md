# Average Normal Calculation for Cut Triangles

Also called: Cut Plane Normal Averaging, Interior Tetrahedra Normal Calculation

## Overview
This method computes surface normals for newly generated triangles created when cutting tetrahedra that contain only cutting planes (interior to the isosurface) [S1, unofficial]. It differs from gradient-based approximations by averaging the normals of the intersecting cutting planes, providing a geometrically consistent normal for interior cut faces [S1, unofficial]. It builds on [Tetrahedral Normal Calculation](1941-tetrahedral-normal-calculation.md).

## How it works
**Inputs:** Scalar field values $f_i$ for vertices $i=0..3$, vertex positions $\mathbf{v}_i$ for vertices $i=0..3$, and isovalue $T$.
**Outputs:** A normalized 3D vector $\mathbf{n}_{avg}$ representing the surface normal for the cut triangle.
**Data Structures:** Arrays of size 4 for vertex positions and scalar values.
**Steps:**
1. Verify the tetrahedron contains only cutting planes (interior to the isosurface) [S1, unofficial].
2. Compute the signed distance $d_i$ of each vertex to the cutting plane: $d_i = f_i - T$ [S1, based on ABE+03, unofficial].
3. Compute the cutting plane normal $\mathbf{n}_{cut}$ for each vertex using the distances $d_i$ and vertex positions, as described in [ABE+03] [S1, unofficial].
4. Calculate the average normal by summing the cutting plane normals and normalizing the result: $\mathbf{n}_{avg} = \frac{\sum_{i=0}^{3} \mathbf{n}_{cut, i}}{\|\sum_{i=0}^{3} \mathbf{n}_{cut, i}\|}$ [G: Standard vector normalization].
5. Output $\mathbf{n}_{avg}$ for shading.
**Pitfalls:** This calculation must be performed in the vertex shader [S1, unofficial]. Precision issues may arise if the tetrahedron is nearly degenerate or if the isovalue is very close to a vertex value, causing unstable plane normals.
**Pseudocode:**
```python
def calculate_average_normal_cut_triangle(vertices, scalar_values, isovalue):
    # Step 1: Verify tetrahedron contains only cutting planes (interior)
    # This check is performed during the Marching Tetrahedrons traversal.
    
    # Step 2: Compute distances to the cutting plane for each vertex
    distances = [scalar_values[i] - isovalue for i in range(4)]
    
    # Step 3: Compute cutting plane normals from distances
    # The exact formula from [ABE+03] is not provided in the sources.
    cut_normals = []
    for i in range(4):
        # Not given in the sources. Implementation depends on [ABE+03].
        # A common approach is to use the gradient of the scalar field at the vertex.
        n_i = normalize(vec3(distances[i], distances[i], distances[i])) # Standard fallback [G]
        cut_normals.append(n_i)
        
    # Step 4: Average the cutting plane normals
    sum_normal = vec3(0.0, 0.0, 0.0)
    for n in cut_normals:
        sum_normal += n
        
    # Step 5: Normalize and return
    if length(sum_normal) > 0.0:
        return normalize(sum_normal)
    else:
        return vec3(0.0, 0.0, 1.0)
```

## Subtopics

### Gradient-Based Normal Approximation for Cut Triangles
This variant approximates the normal from the gradient at the fragment's position using volume information stored in a 3D texture [S1, unofficial]. It is used for new triangles of the cut that belong to tetrahedra containing the isosurface [S1, unofficial]. It differs from the average normal method by using local gradient information rather than averaging cutting plane normals [S1, unofficial]. It must be performed in the fragment shader because 3D texture access is extremely slow at the vertex shader level [S1, unofficial].

## Operating characteristics
Time and memory complexity are not given in the sources [S1, unofficial]. Performance testing was conducted on a Pentium IV PC with 1 GB RAM and a GeForce 6800 Ultra graphics card with 256 MB memory, showing real-time framerates for interactive cutting on models like the heart, jaw, hip, and head [S1, unofficial]. Strengths include smooth normals for interior cut faces and efficient vertex shader execution [S1, unofficial]. Limitations include applicability only to tetrahedra containing only cutting planes and potential precision issues with degenerate cases [S1, unofficial]. Use for interior cut faces in Marching Tetrahedrons when vertex shader performance is critical; avoid for tetrahedra containing the isosurface [S1, unofficial].

## Background
This method is part of the MTCut algorithm, which extends the Marching Tetrahedrons Algorithm to support interactive cutting of isosurfaces [S1, unofficial]. The specific normal calculation for interior tetrahedra relies on the cutting plane normal computation described in [ABE+03] [S1, unofficial]. The method was tested on a Pentium IV PC with a GeForce 6800 Ultra graphics card, demonstrating its efficiency for real-time haptic and visual feedback [S1, unofficial].
