# Power Distance Sort

Also called: Circumsphere radius sort, Delaunay power sort, Power Distance Sort for Delaunay Tetrahedralization, Power Distance Sorting, Power Sorting, Radical axis sorting, Visibility sorting via circumcircles

## Overview
Power Distance Sort is a visibility sorting method for Delaunay tetrahedralizations that orders cells in back-to-front order relative to a viewpoint using the power of the viewpoint with respect to each cell's circumsphere [S2][S3, unofficial]. It solves the problem of determining correct rendering order without constructing an adjacency graph or handling visibility cycles, which are required by topological sort methods [S2]. Unlike [Topological Sort for Cell Projection](999-topological-sort-for-cell-projection.md), which guarantees correctness for any convex grid via graph traversal, Power Distance Sort relies on the geometric properties of Delaunay meshes; it is not guaranteed to produce accurate visibility ordering for non-Delaunay meshes [S1][S4, unofficial].

## How it works
**Inputs:**
- A set of tetrahedra $T_i$ forming a Delaunay tetrahedralization [S2][S3, unofficial].
- A viewpoint (camera origin) $\mathbf{o}$ [S3, unofficial].

**Outputs:**
- A list of tetrahedra sorted in decreasing order of power distance from $\mathbf{o}$, which corresponds to a correct back-to-front visibility order for Delaunay meshes [S2][S3, unofficial].

**Data Structures:**
- Each tetrahedron $T$ requires the precomputed center $\mathbb{O}(T)$ and radius $\mathbb{R}(T)$ of its circumsphere [S3, unofficial].
- A list of tuples `(power_distance, tetrahedron_index)` for sorting [G].

**Formulas:**
The power of the viewpoint $\mathbf{o}$ relative to the circumsphere of tetrahedron $T$ is defined as [S3, unofficial]:

$$ P(T) = \|\mathbb{O}(T) - \mathbf{o}\|_2^2 - \mathbb{R}(T)^2 $$

Where:
- $\mathbb{O}(T)$ is the 3D center of the circumsphere of $T$ [S3, unofficial].
- $\mathbb{R}(T)$ is the radius of the circumsphere of $T$ [S3, unofficial].
- $\mathbf{o}$ is the 3D position of the camera origin [S3, unofficial].
- $\|\cdot\|_2$ denotes the Euclidean norm [G].

Alternatively, if $d$ is the distance from $\mathbf{o}$ to $\mathbb{O}(T)$ and $r$ is the radius $\mathbb{R}(T)$, the power distance is $d^2 - r^2$ [S2].

**Steps:**
1. For each tetrahedron $T_i$ in the mesh, compute the center $\mathbb{O}(T_i)$ and radius $\mathbb{R}(T_i)$ of its circumsphere [G].
2. For each tetrahedron $T_i$, calculate the power distance $P(T_i)$ using the formula above [S2].
3. Sort the tetrahedra in decreasing order of $P(T_i)$ (largest power distance first, i.e., furthest back) [S2].
4. Render the tetrahedra in the sorted order [G].

**Pseudocode:**
```python
def power_distance_sort(tetrahedra, viewpoint):
    """
    Sorts tetrahedra by power distance from viewpoint.
    tetrahedra: list of tetrahedra (each is list of 4 vertices as tuples (x, y, z)).
    viewpoint: tuple (x, y, z).
    Returns: list of tetrahedra sorted back-to-front.
    """
    powered = []
    for i, tet in enumerate(tetrahedra):
        v0, v1, v2, v3 = tet
        # Compute circumcenter and radius [G]
        a = [v1[j] - v0[j] for j in range(3)]
        b = [v2[j] - v0[j] for j in range(3)]
        c = [v3[j] - v0[j] for j in range(3)]
        
        cross_ab = [a[1]*b[2] - a[2]*b[1], a[2]*b[0] - a[0]*b[2], a[0]*b[1] - a[1]*b[0]]
        cross_bc = [b[1]*c[2] - b[2]*c[1], b[2]*c[0] - b[0]*c[2], b[0]*c[1] - b[1]*c[0]]
        cross_ca = [c[1]*a[2] - c[2]*a[1], c[2]*a[0] - c[0]*a[2], c[0]*a[1] - c[1]*a[0]]
        
        denom = a[0]*cross_bc[0] + a[1]*cross_bc[1] + a[2]*cross_bc[2]
        if abs(denom) < 1e-9:
            center, radius = [0.0, 0.0, 0.0], float('inf')
        else:
            len_a_sq = sum(x*x for x in a)
            len_b_sq = sum(x*x for x in b)
            len_c_sq = sum(x*x for x in c)
            offset = [0.5 * (len_b_sq * cross_ca[j] + len_c_sq * cross_ab[j] + len_a_sq * cross_bc[j]) / denom for j in range(3)]
            center = [v0[j] + offset[j] for j in range(3)]
            radius = sum((center[j] - v0[j])**2 for j in range(3))**0.5
            
        # Power distance
        dx, dy, dz = center[0] - viewpoint[0], center[1] - viewpoint[1], center[2] - viewpoint[2]
        power = dx*dx + dy*dy + dz*dz - radius*radius
        powered.append((power, i))
        
    # Sort by power distance in decreasing order (largest power = furthest)
    powered.sort(key=lambda x: x[0], reverse=True)
    
    return [tetrahedra[idx] for _, idx in powered]
```

**Edge Cases and Pitfalls:**
- **Non-Delaunay Meshes:** The method is not guaranteed to produce accurate visibility ordering unless the mesh is a Delaunay triangulation [S1][S4, unofficial]. There is no way to tell in advance whether a given non-Delaunay mesh will be correctly sorted [S1].
- **Degenerate Tetrahedra:** If vertices are coplanar, the circumsphere is undefined (infinite radius) [G].
- **Viewpoint Position:** The sort order is relative to the ray origin, making it valid for fisheye and distorted projections [S3, unofficial]. However, simple schemes may fail from certain viewpoints or viewing directions if the Delaunay property is not strictly maintained [S4, unofficial].

## Operating characteristics
- **Time Complexity:** Theoretical time complexity is $O(n \log n)$ due to the sorting step [S2].
- **Memory Complexity:** Requires storing the power distance for each tetrahedron, $O(n)$ [S2]. Unlike topological sort, it avoids storing and accessing an adjacency structure [S2].
- **Performance:** In practice, it is competitive with topological sort ($O(n)$) because it avoids the overhead of storing and accessing an adjacency structure [S2]. It has very small constant computations and is straightforward to implement [S1][S5, unofficial].
- **Strengths:** Fast, simple implementation, no adjacency graph required, works with distorted projections [S2][S3, unofficial][S5, unofficial].
- **Limitations:** Only guaranteed correct for Delaunay tetrahedralizations; may fail from certain viewpoints or viewing directions on non-Delaunay meshes [S1][S4, unofficial].

## Background
Power Distance Sort was described by Cignoni et al. and Wittenbrink [S1][S5, unofficial]. Edelsbrunner (1989) proved that for a Delaunay tetrahedralization, no visibility cycles are possible, and that sorting by power distance yields a correct visibility order [S2]. The method relies on the geometric property that the shared face of two adjacent tetrahedra lies on the radical plane of their circumspheres, which divides the space into regions where the viewpoint has a lower power distance to one circumsphere or the other [S3, unofficial].
