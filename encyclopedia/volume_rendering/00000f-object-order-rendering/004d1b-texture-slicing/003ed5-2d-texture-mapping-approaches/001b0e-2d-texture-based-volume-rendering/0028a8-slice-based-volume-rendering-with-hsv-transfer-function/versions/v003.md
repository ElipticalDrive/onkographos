# Slice-Based Volume Rendering with HSV Transfer Function

Also called: Slice Rendering, Slice-Based Volume Rendering, Texture Array Volume Rendering

## Overview
Slice-Based Volume Rendering with HSV Transfer Function is a GPU-accelerated object-order technique that renders volumetric data by projecting a series of 2D slices onto the image plane and blending them back-to-front, while mapping scalar values to color using a Hue-Saturation-Value (HSV) transfer function [S1, unofficial][S2, unofficial]. It differs from standard 2D texture-based volume rendering by explicitly managing a texture array (sprite sheet) to simulate 3D trilinear filtering and by computing color in HSV space rather than using a pre-baked 1D RGB texture lookup [S1, unofficial]. It differs from its sibling [Novel Sampling Scheme for Slice Based Volume Rendering](953-novel-sampling-scheme-for-slice-based-volume-rendering.md) by relying on fixed sprite-sheet indexing rather than a novel sampling distribution, and from [Interpolation of Arbitrary Slices (Multi-Texture Blending)](2089-interpolation-of-arbitrary-slices-multi-texture-blending.md) by using a single texture array with calculated intra-slice coordinates instead of blending multiple distinct texture units [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume dataset stored as a 2D texture array (sprite sheet), camera parameters, and HSV transfer function parameters (darkness, lightness, saturation, hue range) [S1, unofficial].
*   **Output:** A 2D color buffer with the blended volume image [S2, unofficial].

**Data Structures:**
*   **Volume Texture:** A 2D texture array or a single large 2D texture acting as a sprite sheet [S1, unofficial].
    *   Layout: Slices are arranged in a grid with `uSlicesOverX` slices arranged horizontally per sprite sheet row [S1, unofficial].
    *   Fields: `uNumberOfSlices` (total slices), `slicesPerSprite` (slices per texture unit), `uSlicesOverX`, `uSlicesOverY` [S1, unofficial].
*   **Vertex Buffers:**
    *   Attribute 0: `Vector3f` (3 floats) for position [S2, unofficial].
    *   Attribute 1: `Vector2f` (2 floats) for UVs (optional) [S2, unofficial].
    *   Attribute 2: `Vector3f` (3 floats) for normals (optional) [S2, unofficial].
*   **Transfer Function Parameters:**
    *   `darkness`: Global brightness/darkness multiplier [S1, unofficial].
    *   `l`: Lightness scaling factor [S1, unofficial].
    *   `s`: Saturation scaling factor [S1, unofficial].
    *   `hMin`, `hMax`: Minimum and maximum hue values [S1, unofficial].
    *   `minSos`, `minRefl`, `minAtten`, `maxSos`, `maxRefl`, `maxAtten`: Threshold parameters for slice selection or filtering (exact usage not detailed) [S1, unofficial].

**Numbered Steps:**
1.  **Geometry Setup:** Bind vertex buffers for position, UVs, and normals, and bind the volume texture to texture unit 0 [S2, unofficial].
2.  **Slice Loop:** Iterate through each slice index `i` from 0 to `numberOfSlices - 1` [S2, unofficial]. Calculate normalized slice position `slicePos = (i / numberOfSlices) - 0.5` and total slice parameter `totalSlices = (0.5 + i) / numberOfSlices` [S2, unofficial]. Pass these as shader uniforms `sliceNumber` and `totalSlices` [S2, unofficial]. Draw the slice geometry using `glDrawElements` [S2, unofficial].
3.  **Fragment Shader - Texture Indexing:** Compute the 3D volume position `volpos` [S1, unofficial]. Calculate `s1Original = floor(volpos.z * uNumberOfSlices)` [S1, unofficial]. Determine texture array index `tex1Index = int(floor(s1Original / slicesPerSprite))` [S1, unofficial]. Compute intra-slice coordinates `s1 = mod(s1Original, slicesPerSprite)`, `dx1 = fract(s1 / uSlicesOverX)`, `dy1 = floor(s1 / uSlicesOverY) / uSlicesOverY` [S1, unofficial]. Compute normalized texture coordinates `texpos1.x = dx1 + (volpos.x / uSlicesOverX)` and `texpos1.y = dy1 + (volpos.y / uSlicesOverY)` [S1, unofficial]. Sample the volume value using `tex1Index` and `texpos1` with trilinear filtering [S1, unofficial].
4.  **Fragment Shader - HSV Transfer Function:** Map the sampled scalar value to HSV space [S1, unofficial]. Apply scaling: `H = map(value, hMin, hMax)`, `S = value * s`, `V = value * l * darkness` [S1, unofficial]. Convert HSV to RGB: normalize hue `hue /= 60.0`, determine sector `i = int(hue)`, fractional part `ff = hue - float(i)`, calculate `p = V * (1.0 - S)`, `q = V * (1.0 - (S * ff))`, `t = V * (1.0 - (S * (1.0 - ff)))` [S1, unofficial]. Assign RGB based on sector `i` using piecewise linear interpolation [S1, unofficial].
5.  **Blending:** Blend the resulting RGB color with the accumulated color buffer using alpha blending back-to-front [S1, unofficial][S2, unofficial].

**Pseudocode:**
```python
import math

def fract(x):
    return x - math.floor(x)

def render_slice(numberOfSlices, uNumberOfSlices, uSlicesOverX, uSlicesOverY, slicesPerSprite, darkness, lightness, saturation, hMin, hMax, volume_texture, slice_quads):
    accumulator = (0.0, 0.0, 0.0, 0.0)
    
    for i in range(numberOfSlices):
        slicePos = (i / numberOfSlices) - 0.5
        totalSlices = (0.5 + i) / numberOfSlices
        # Set shader uniforms sliceNumber and totalSlices
        # Bind vertex buffers and draw slice geometry
        
        for volpos in slice_quads:
            # 1. Texture Array Indexing
            s1Original = math.floor(volpos.z * uNumberOfSlices)
            tex1Index = int(math.floor(s1Original / slicesPerSprite))
            s1 = math.fmod(s1Original, slicesPerSprite)
            dx1 = fract(s1 / uSlicesOverX)
            dy1 = math.floor(s1 / uSlicesOverY) / uSlicesOverY
            texpos1_x = dx1 + (volpos.x / uSlicesOverX)
            texpos1_y = dy1 + (volpos.y / uSlicesOverY)
            
            # 2. Sample Volume Value
            volumeValue = volume_texture.sample(tex1Index, texpos1_x, texpos1_y)
            
            # 3. HSV Transfer Function
            hue = hMin + (hMax - hMin) * volumeValue
            sat = volumeValue * saturation
            val = volumeValue * lightness * darkness
            
            # 4. HSV to RGB Conversion
            hue_norm = hue / 60.0
            sector = int(hue_norm)
            ff = hue_norm - float(sector)
            p = val * (1.0 - sat)
            q = val * (1.0 - (sat * ff))
            t = val * (1.0 - (sat * (1.0 - ff)))
            
            if sector == 0: rgb = (val, t, p)
            elif sector == 1: rgb = (q, val, p)
            elif sector == 2: rgb = (p, val, t)
            elif sector == 3: rgb = (p, q, val)
            elif sector == 4: rgb = (t, p, val)
            elif sector == 5: rgb = (val, p, q)
            else: rgb = (0.0, 0.0, 0.0)
            
            # 5. Blend back-to-front into accumulator [G]
            alpha = 1.0
            accumulator = (
                accumulator[0] + rgb[0] * alpha * (1.0 - accumulator[3]),
                accumulator[1] + rgb[1] * alpha * (1.0 - accumulator[3]),
                accumulator[2] + rgb[2] * alpha * (1.0 - accumulator[3]),
                accumulator[3] + alpha * (1.0 - accumulator[3])
            )
            
    return accumulator
```

**Edge Cases and Pitfalls:**
*   **Texture Array Indexing:** Miscalculation of `tex1Index` or intra-slice coordinates (`dx1`, `dy1`) leads to incorrect slice selection or coordinate wrapping artifacts [S1, unofficial].
*   **Precision:** Floating-point precision in `floor` and `mod` operations can cause slice boundary artifacts if not handled carefully [S1, unofficial].
*   **Degenerate Input:** If `uNumberOfSlices` is 0 or `uSlicesOverX` is 0, division by zero or invalid indexing occurs [S1, unofficial].
