# Multiple-Scattering Angular Distribution Estimation

Also called: Angular Distribution Approximation

## Overview
A technique to approximate the angular distribution of light after multiple scattering events by convolving the particle phase function with itself, extending [Half-angle slicing](1255-half-angle-slicing.md) to handle gradual angular spreading rather than just unscattered or diffuse light [S1]. It separates the radiance into an intensity component and an angular distribution component, allowing efficient single-pass rendering of atmospheric phenomena with large forward-scattering particles [S1].

## How it works
**Inputs:**
- Particle phase function $P_\lambda(\Omega)$ [S1].
- Extinction coefficient $\beta_{ex}(\vec{s})$ and absorption coefficient $\alpha(\vec{s})$ [S1].
- Light source direction $\Omega_{lt}$ and intensity $I_s^\lambda$ [S1].
- Transparency from the light source $T(\vec{s}, \vec{s}_{bg}(\vec{s}, \Omega_{lt}))$ [S1].
- Parameters $\gamma$ and $\alpha_\gamma$ for scattering event estimation [S1].

**Outputs:**
- Final radiance $L_\lambda(\vec{s}, \Omega)$ for each sample point $\vec{s}$ and view direction [S1].
- Intensity buffer $I_\lambda(\vec{s})$ storing the scalar light intensity reaching the volume [S1].

**Data Structures:**
- **Pre-computed Angular Distribution Texture:** A floating-point precision texture storing $A^{ms}_\lambda^n(\Omega)$ for $n \in [0, N_{max}]$ [S1]. The index $n$ represents the number of scattering events [S1].
- **Light Buffer:** A texture storing the scalar intensity $I_\lambda(\vec{s})$ accumulated along the light path [S1].

**Definitions:**
- Radiance separation: $L_\lambda(\vec{s}, \Omega) = I_\lambda(\vec{s})A_\lambda(\vec{s}, \Omega)$ [S1].
- Normalization constraint: $\int_{4\pi} A_\lambda(\vec{s}, \Omega)d\Omega = 1, \forall\vec{s}, \lambda$ [S1].
- Boundary condition (collimated source): $L_\lambda(\vec{s}_{bg}(\vec{s}, \Omega), \Omega) = I_s^\lambda \delta(\Omega - \Omega_{lt})$ [S1].

**Step 1: Pre-computation**
The multiple-scattering angular distribution function $A^{ms}_\lambda^n(\Omega)$ approximates the distribution of light after $n$ scattering events [S1]:
$$ A^{ms}_\lambda^n(\Omega) = \underbrace{\delta(\Omega - \Omega_{lt}) * P_\lambda * \dots * P_\lambda}_{n-1 \text{ times}}(\Omega) $$
where $*$ denotes convolution over the sphere $4\pi$ [S1].

**Step 2: Runtime Estimation**
For a ray segment traversing from $\vec{s}$ to $\vec{s} + \vec{m}\Omega_{lt}\Delta$ (where $\vec{m}$ is the light direction vector and $\Delta$ is step size), the expected number of scattering events $n(\vec{s})$ is estimated based on the transparency $T$ from the light source [S1]:
$$ n(\vec{s}) = -\frac{\gamma}{\alpha_\gamma \beta_{ex}(\vec{s}')} \ln T(\vec{s}, \vec{s}_{bg}(\vec{s}, \Omega_{lt})) $$
where $\gamma$ and $\alpha_\gamma$ are implementation-specific scaling parameters [S1].

**Step 3: Intensity Update**
The intensity $I_\lambda$ is updated along the light path [S1]. For a step from $\vec{s}$ to $\vec{s} + \vec{m}\Omega_{lt}\Delta$:
$$ I_\lambda(\vec{s} + \vec{m}\Omega_{lt}\Delta) = I_\lambda(\vec{s})T(\vec{s}, \vec{s} + \vec{m}\Omega_{lt}\Delta) + I_\lambda(\vec{s})(1 - T(\vec{s}, \vec{s} + \vec{m}\Omega_{lt}\Delta)) \frac{\beta_{ex}^\lambda \Delta}{\alpha(\vec{s})} F_{\lfloor n(\vec{s}) \rfloor + 1 + \beta_{ex}^\lambda \Delta} $$
where $F$ is the pre-computed angular distribution function sampled at the appropriate index [S1]. The index for the angular distribution texture is $k = \lfloor n(\vec{s}) \rfloor + 1 + \beta_{ex}^\lambda \Delta$ [S1]. If $k > N_{max}$, clamp to $N_{max}$ [S1].

**Parameters:**
- Maximum pre-computed scattering events $N_{max} = 26$ [S1]. This value is chosen because the angular distribution for rain (the worst-case forward peak scenario) becomes isotropic to within 0.0001% at this point [S1].

**Edge Cases and Pitfalls:**
- The approximation performs best in optically thin regions and for the first few scattering events [S1].
- Errors increase with the number of scattering events as the backward-directed light contribution becomes large, which the forward-peaked convolution approximation may not capture accurately [S1].
- If $n(\vec{s})$ is large, the angular distribution becomes isotropic; clamping to $N_{max}=26$ is sufficient for most atmospheric cases (e.g., rain) [S1].

**Pseudocode:**
```python
import math

def precompute_angular_distributions(phase_function, light_direction, num_scatterings_max=26):
    """
    Pre-compute A_ms^n by convolving the phase function n-1 times.
    """
    distributions = []
    # n=0: Delta function at light direction
    distributions.append(lambda omega: delta_function(omega, light_direction))
    current_dist = distributions[0]
    for n in range(1, num_scatterings_max + 1):
        # Convolve current distribution with phase function over the sphere [G]
        next_dist = lambda omega: convolve_sphere(current_dist, phase_function, omega)
        distributions.append(next_dist)
        current_dist = next_dist
    return distributions

def update_light_buffer(ray_origin, light_direction, step_size, distributions, 
                        extinction_coeffs, absorption_coeffs, 
                        light_intensity, gamma, alpha_gamma):
    """
    Accumulate intensity in the light buffer along the light path.
    """
    current_pos = ray_origin
    current_intensity = light_intensity
    num_scatterings_max = len(distributions) - 1
    max_steps = 1000
    for _ in range(max_steps):
        if not is_inside_volume(current_pos):
            break
        beta_ex = extinction_coeffs.sample(current_pos)
        alpha = absorption_coeffs.sample(current_pos)
        delta = step_size
        T = math.exp(-beta_ex * delta)
        n_est = -(gamma / (alpha_gamma * beta_ex)) * math.log(T)
        index = math.floor(n_est) + 1 + beta_ex * delta
        if index > num_scatterings_max:
            index = num_scatterings_max
        A_ms = distributions[index]
        scattering_term = (beta_ex * delta / alpha) * A_ms(light_direction)
        new_intensity = current_intensity * T + current_intensity * (1 - T) * scattering_term
        light_buffer.set(current_pos, new_intensity)
        current_pos = current_pos + light_direction * delta
        current_intensity = new_intensity
```

## Operating characteristics
- **Time Complexity:** Pre-computation requires iterative spherical convolution [G]. Runtime performs $O(1)$ texture lookups and arithmetic per sample, enabling efficient single-pass rendering [S1].
- **Memory Complexity:** Requires storing $N_{max}$ angular distribution textures in floating-point precision [S1].
- **Strengths:** Captures fine angularly dependent effects in the presence of large atmospheric scattering particles (forward scattering) without the cost of full path tracing [S1].
- **Limitations:** Accuracy degrades for high scattering counts (optically thick regions) due to the neglect of backward scattering contributions in the convolution model [S1].
- **When to use:** Atmospheric rendering with forward-scattering particles (clouds, fog, rain) where performance is critical and optical thickness is moderate [S1].
- **When not to use:** Highly optically thick media where backward scattering dominates, or when high-fidelity multiple scattering beyond 26 events is required [S1].

## Background
Originated in the work of Riley, Ebert, Kraus, Tessendorf, and Hansen (2004) for the efficient rendering of atmospheric phenomena [S1]. It extends the half-angle slicing technique by Kniss et al. (2002) to handle multiple scattering [S1]. The method is designed for programmable graphics hardware, leveraging pre-computed textures to approximate the radiative transfer equation's angular dependence [S1].
