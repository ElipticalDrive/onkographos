# Blending Between Levels (Fast)
Also called: blendFast

## Overview
Blending Between Levels (Fast) is an optimized method for computing the value at a query point $P$ in an adaptive volume grid by smoothly interpolating between different resolution levels [S1, unofficial]. It solves the discontinuity problem inherent in level-selection by treating virtual cells as transparent and actual cells as opaque, allowing for a continuous transition between coarse and fine data [S1, unofficial]. It sets itself apart from its sibling [Blending Between Levels (Naive)](2946-blending-between-levels-naive.md) by starting at the leaf level and blending both upwards and downwards to terminate early, whereas the naive method iterates from the coarsest level upwards [S1, unofficial]. It improves upon [Finest Level Lerp](2945-finest-level-lerp.md) by incorporating contributions from coarser levels when the finest level is not fully opaque, ensuring continuity across level boundaries [S1, unofficial].

## How it works
The method computes a weighted average of interpolants from multiple levels [S1, unofficial]. It assumes a hierarchical grid structure where cells at finer levels may be "virtual" (not explicitly stored, implying they are interpolated from coarser parents) or "leaf" (explicitly stored) [S1, unofficial].

**Inputs and Outputs:**
- Input: Query point $P$ in 3D space.
- Output: Blended value $f$ at $P$.

**Data Structures:**
- Grid levels $l \in [0, \text{MAX\_LEVEL}]$ [S1, unofficial].
- Dual cell $D$: The logical cell containing $P$ at a specific level [S1, unofficial].
- Leaf cell $C$: The finest level cell containing $P$ [S1, unofficial].
- `lerp(P)`: Returns the interpolated value $(f_l, a_l)$ at point $P$ for the dual cell at the current level, where $f_l$ is the value and $a_l$ is the opacity (1 if all vertices are actual/leaf, 0 if all are virtual, interpolated otherwise) [S1, unofficial].
- `lerpAlpha(P)`: Returns only the interpolated opacity $a_l$ [S1, unofficial].

**Steps:**
1. Find leaf cell $C$ of $P$ and its level $C.l$ [S1, unofficial].
2. Find dual cell $D$ at level $C.l$ containing $P$ [S1, unofficial].
3. Compute initial $f = D.\text{lerp}(P)$ [S1, unofficial].
4. Blend towards finer levels: Initialize $D' = D$. Loop $l$ from $C.l + 1$ to $\text{MAX\_LEVEL}$. If all vertices of $D'$ are leaves, break. Find dual cell $D'$ for level $l$. Get $(f_l, a_l)$ from $D'.\text{lerp}(P)$. Update $f = a_l \cdot f_l + (1 - a_l) \cdot f$ [S1, unofficial].
5. Blend towards coarser levels: If any vertices in $D$ are virtual, compute $a = D.\text{lerpAlpha}(P)$. Update $f = f \cdot a$. Loop $l$ from $C.l - 1$ down to $0$. Find dual cell $D'$ for level $l$. Update $f = f + (1 - a) \cdot D'.\text{lerp}(P)$. If all vertices in $D'$ exist, break. Update $a = a + (1 - a) \cdot D'.\text{lerpAlpha}(P)$ [S1, unofficial].
6. Return $f$ [S1, unofficial].

**Pseudocode:**
```python
def blend_fast(P):
    # 1. Find leaf level, and lerp
    C = find_leaf_cell(P)
    D = find_dual_cell(C.l, P)
    f = D.lerp(P)
    
    # 2. Blend towards finer levels
    D_prime = D
    for l in range(C.l + 1, MAX_LEVEL + 1):
        if all_vertices_are_leaves(D_prime):
            break
        D_prime = find_dual_cell(l, P)
        f_l, a_l = D_prime.lerp(P)
        f = a_l * f_l + (1 - a_l) * f
        
    # 3. Blend towards coarser levels
    if any_vertices_are_virtual(D):
        a = D.lerp_alpha(P)
        f = f * a
        for l in range(C.l - 1, -1, -1):
            D_prime = find_dual_cell(l, P)
            f += (1 - a) * D_prime.lerp(P)
            if all_vertices_exist(D_prime):
                break
            a += (1 - a) * D_prime.lerp_alpha(P)
            
    return f
```

**Parameters:**
- `MAX_LEVEL`: The maximum depth of the adaptive grid hierarchy [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** The blending formula relies on the opacity $a$ being correctly interpolated [S1, unofficial]. If $a$ is not computed correctly for virtual cells, the blending weights will be incorrect, leading to artifacts at level boundaries [S1, unofficial].
- **Boundaries:** The method assumes that `find_dual_cell` correctly identifies the cell containing $P$ at any level [S1, unofficial].
- **Degenerate Input:** If $P$ lies exactly on a boundary between levels, the virtual/leaf status of vertices determines the blending behavior [S1, unofficial]. The method handles this by interpolating opacity [S1, unofficial].

## Subtopics

### Blending Between Levels (Naive)
A continuous blending method that treats virtual cells as transparent (opacity 0) and actual cells as opaque (opacity 1) [S1, unofficial]. It blends interpolants from level $l$ and coarser levels using the interpolated opacity alpha [S1, unofficial]. It starts from the coarsest level (0) and iterates upwards to MAX_LEVEL [S1, unofficial]. If the opacity $a_l$ at a level is 0, the loop breaks [S1, unofficial]. It is adaptive and continuous but expensive as it may process all levels [S1, unofficial].

## Operating characteristics
- **Time Complexity:** The fast method is generally faster than the naive method because it starts at the leaf level and can terminate early if fully opaque/transparent levels are found [S1, unofficial]. The naive method always iterates from level 0 upwards [S1, unofficial].
- **Memory Complexity:** Depends on the storage of the adaptive grid [S1, unofficial]. The method itself requires minimal additional memory [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Strengths:** Continuous blending across level boundaries; efficient termination in homogeneous regions [S1, unofficial].
- **Limitations:** More complex implementation than simple level selection; requires careful handling of virtual cells [S1, unofficial].
- **When to use:** When continuous blending is required and performance is a concern, especially in regions with varying resolution [S1, unofficial].
- **When not to use:** When simplicity is preferred and performance is not critical, or when the grid is uniform [S1, unofficial].

## Background
The method was introduced in the context of CPU volume rendering of adaptive mesh refinement data [S1, unofficial]. It addresses the discontinuity in level selection by providing a smooth blending mechanism [S1, unofficial]. The naive version was proposed first, followed by the optimized fast version [S1, unofficial].
