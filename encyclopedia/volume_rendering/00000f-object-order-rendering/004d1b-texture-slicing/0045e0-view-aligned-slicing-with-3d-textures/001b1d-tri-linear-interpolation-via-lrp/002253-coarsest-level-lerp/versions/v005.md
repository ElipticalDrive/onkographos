# Coarsest-Level Lerp
## Overview
Coarsest-Level Lerp is a method for computing the value of a coarser-side octant vertex in Adaptive Mesh Refinement (AMR) volume rendering by performing trilinear interpolation on the coarsest level involved for any of the inputs [S1, unofficial]. It solves the problem of generating consistent interpolants at level boundaries where a coarse octant meets finer children [S1, unofficial]. It sets itself apart from [Finest Level Lerp](2945-finest-level-lerp.md) by utilizing the coarsest available resolution rather than the finest [S1, unofficial].

## How it works
**Inputs and Outputs:** The input consists of the current octant `oct` (with level `oct.l` and position `oct[X'].p`), and the dual cell `D` associated with the vertex being computed, which contains level information `D[0'].l` and `D[X'].l` for the adjacent cells [S1, unofficial]. The output is the interpolated vertex value `oct[X'].v` [S1, unofficial].

**Data Structures:** The octant `oct` stores the level index `oct.l`, the vertex position `oct[X'].p`, and the computed value `oct[X'].v` [S1, unofficial]. The dual cell `D` stores the level indices `D[0'].l` and `D[X'].l`, the scalar values `D[0'].v` and `D[X'].v`, and provides a `lerp(P)` method for trilinear interpolation at position `P` [S1, unofficial].

**Algorithm Steps:** 
1. Calculate the logical coordinate index by determining the minimum level involved in the interpolation: $lX' = \min(D[0'].l, D[X'].l)$ [S1, unofficial].
2. Compare the calculated minimum level $lX'$ with the current octant's level `oct.l` [S1, unofficial].
3. If $lX' == \text{oct}.l$, compute the value as the arithmetic average of the input values: $\text{oct}[X'].v = \text{avg}(D[0'].v, D[X'].v)$ [S1, unofficial].
4. Otherwise, perform trilinear interpolation on the coarsest level $lX'$ by calling the helper function: $\text{oct}[X'].v = \text{lerpOnLevel}(lX', \text{oct}[X'].p)$ [S1, unofficial].

**Pseudocode:**
```python
def compute_coarser_side_vertex(oct, D, Xp):
    # Step 1: Calculate logical coordinate index (minimum level involved)
    lXp = min(D[0].l, D[Xp].l)
    # Step 2: Check if the minimum level matches the current octant's level
    if lXp == oct.l:
        # Step 3: Same level - average the inputs
        oct[Xp].v = (D[0].v + D[Xp].v) / 2.0
    else:
        # Step 4: Different levels - interpolate on the coarsest level
        oct[Xp].v = lerp_on_level(lXp, oct[Xp].p)
    return oct[Xp].v
```

## Subtopics

### Current-Level Lerp
A method that performs interpolation on the leaf cell (current level) rather than the coarsest level, making the interpolant adaptive [S1, unofficial]. It calculates the logical coordinate index $lX' = \min(D[0'].l, D[X'].l)$ and checks if $lX' == \text{oct}.l$ [S1, unofficial]. If true, it averages the inputs; otherwise, it finds the leaf cell level using `findLeafCell(oct[X'].p).l` and interpolates on that level: $\text{oct}[X'].v = \text{lerpOnLevel}(\text{level}, \text{oct}[X'].p)$ [S1, unofficial]. It sets itself apart from Coarsest-Level Lerp by adapting to the finest available resolution at the sample point [S1, unofficial]. Not given in the sources. [S1, unofficial]

### Finest-Level Interpolation
Trilinear interpolation performed on a fixed logical level $l$ [S2, unofficial]. It views the level as a structured grid where non-existing cells are defined via the Closest Existing Cell (CEC) operator [S2, unofficial]. It is cheap and continuous but not adaptive [S2, unofficial]. Unlike Coarsest-Level Lerp, which dynamically selects the coarsest level involved in the boundary, Finest-Level Interpolation uses a pre-selected fixed level [S2, unofficial]. Not given in the sources. [S2, unofficial]

## Background
Coarsest-Level Lerp was introduced as one of four options to guarantee that the interpolant is continuous, adaptive, accurate, and locally rectilinear [S1, unofficial]. It builds on the logical grid abstraction of AMR data, where each refinement level is viewed as a structured grid [S1, unofficial]. The method is designed to work with the `lerpOnLevel` interface, which provides trilinear interpolation based on the cell [S1, unofficial].
