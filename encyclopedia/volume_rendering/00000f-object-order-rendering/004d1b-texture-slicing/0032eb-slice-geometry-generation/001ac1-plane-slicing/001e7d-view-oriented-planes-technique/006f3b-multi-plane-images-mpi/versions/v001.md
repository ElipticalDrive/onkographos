# Multi-plane images (MPI)
## Overview
Multi-plane images (MPI) are a volumetric representation technique that approximates the plenoptic function by dividing it into a set of successive, parallel planes, each storing color and transparency (alpha) information [S1]. Unlike general volume rendering methods that sample arbitrary 3D space, MPI restricts the representation to a fixed number of 2D layers, enabling fast and photorealistic novel view synthesis [S1]. It is distinguished from its parent, the View-Oriented Planes Technique, by its specific assumption of parallel, view-oriented planes rather than arbitrary oriented planes, and from NeRF by its explicit 2D layer structure rather than implicit neural field representation [S1].
## How it works
Inputs: A set of reference images with known camera poses.
Outputs: A set of $N$ planes, where each plane $i$ contains a color texture $C_i$ and an alpha (transparency) texture $\alpha_i$.

Data Structures:
- The representation consists of $N$ planes.
- Each plane $i$ (where $i = 0, \dots, N-1$) is defined by a depth value $z_i$ relative to the camera center.
- Each plane stores two textures:
  - $C_i(x, y)$: RGB color values.
  - $\alpha_i(x, y)$: Alpha (opacity) values, typically in $[0, 1]$.

Rendering Steps:
1. For a target camera pose, project the $N$ planes into the 2D image plane.
2. For each pixel in the target image, cast a ray from the camera center through the pixel.
3. The ray intersects the $N$ planes at specific 2D coordinates $(u_i, v_i)$ on each plane.
4. Retrieve the color $C_i(u_i, v_i)$ and alpha $\alpha_i(u_i, v_i)$ for each intersection.
5. Composite the colors using front-to-back alpha blending:
   $$ C_{out} = \sum_{i=0}^{N-1} C_i(u_i, v_i) \cdot \alpha_i(u_i, v_i) \cdot \prod_{j=0}^{i-1} (1 - \alpha_j(u_j, v_j)) $$
   where the product term represents the accumulated transparency from previous planes.

Parameters:
- $N$: Number of planes. Not given in the sources.
- Depth spacing: The distribution of $z_i$ values. Not given in the sources.

Edge cases and pitfalls:
- MPI is limited to rendering views facing a single direction. Perpendicular views to the planes cannot be rendered accurately [S1].
- The method assumes the scene can be adequately approximated by parallel layers, which may fail for complex occlusions or non-planar structures.

## Subtopics

### Spherical Planes
A structure of spherical planes used for efficient 360° scene rendering, proposed by Broxton et al. [S1]. It sets apart from standard MPI by using spherical geometry instead of parallel planes, allowing for omnidirectional rendering. However, it is limited to rendered views that must be close to the circle's center [S1].

## Operating characteristics
Time and memory complexity: Not given in the sources.
Measured performance: MPI approaches are described as fast and capable of photorealistic renderings [S1].
Scaling: Not given in the sources.
Strengths: Fast rendering, photorealistic quality [S1].
Limitations: Limited to rendering views facing a single direction; perpendicular views cannot be rendered [S1].
When to use: When fast, high-quality novel view synthesis is required for a limited range of viewing angles.
When not: When omnidirectional or wide-angle views perpendicular to the plane normal are needed.
## Background
Origin: Multi-plane images approaches divide the plenoptic function into successive planes that store color and transparency information [S1]. The specific variant of spherical planes was proposed by Broxton et al. [S1].
History and development: The technique is part of the broader advancements in radiance field techniques for volumetric video generation [S1].
Where it is used: Volumetric video generation and novel view synthesis [S1].
