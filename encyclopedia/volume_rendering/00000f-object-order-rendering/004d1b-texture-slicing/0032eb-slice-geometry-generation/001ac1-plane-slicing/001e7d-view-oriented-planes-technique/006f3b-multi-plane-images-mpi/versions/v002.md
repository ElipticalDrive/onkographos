# Multi-plane images (MPI)
## Overview
Multi-plane images (MPI) approximate the plenoptic function by dividing it into successive planes that store color and transparency information [S1]. This representation enables fast and photorealistic novel view synthesis [S1]. It builds on [View-Oriented Planes Technique](1781-view-oriented-planes-technique.md) by organizing the scene into a fixed set of successive planes.

### Spherical Planes
A structure of spherical planes used for efficient 360° scene rendering, proposed by Broxton et al. [S1]. Rendered views must be close to the circle's center [S1].
