# Plane Composing Algorithms

Also called: Image Order Volume Rendering, Slicing Method

## Overview
Plane Composing Algorithms are direct volume rendering methods that operate by compositing several slices which comprise a volumetric model [S1, unofficial][S2, unofficial][S3, unofficial]. They tend to work best when the view-plane is fixed parallel to the model, so that each of the voxels being composed may be accessed on separate planes [S1, unofficial][S2, unofficial].

## Shared principles
The core mechanism divides the volume into slices (planes) and composes them one over the other to produce the image [S3, unofficial]. The computational complexity is relative to the volume size [S1, unofficial][S2, unofficial][S3, unofficial].

Planes can be composed from rear to front or front to back [S3, unofficial]. If composed rear to front, the accumulation of color and transparency uses specific equations starting with initial values [S3, unofficial]. Not given in the sources. If composed front to back, the standard ray casting accumulation equations remain valid [S3, unofficial].

The method works best when the view-plane is parallel to the volume edge [S3, unofficial]. In this case, voxels can be accessed easily as planes in the volume [S3, unofficial]. If the view-plane is not parallel to the volume, a more complicated sampling algorithm is needed [S3, unofficial]. Since a voxel is not projected onto one pixel, a filter should be used for the composition [S3, unofficial].

## Subtopics

### Transparent Planes
A strategy that slices the volume by many planes, applies a transfer function to each vertex on the plane to create variation in color and transparency, and renders the planes from back to front [S4, unofficial]. The number of planes is typically between 200 and 1000 [S4, unofficial]. These planes can be quickly rendered using 2D textures or 3D textures [S4, unofficial].

## Background
Plane Composing Algorithms are one of the two main categories of direct volume rendering algorithms, the other being Ray Casting [S1, unofficial][S2, unofficial]. Texture-based rendering is a key technique which composites slices of volumetric data [S1, unofficial][S2, unofficial]. Shear-Warp factorization can be used to enhance performance by applying a shearing transformation to exploit spatial coherency of the model, reducing computational complexity of rendering a volume from an arbitrary viewing angle [S1, unofficial][S2, unofficial]. Other optimizations include using information of min-max non-transparent voxels, interleaving methods (such as sampling only half of the planes or ¼ of the points in the image), and using hardware graphic accelerators to send volume planes one by one as transparent textures [S3, unofficial].
