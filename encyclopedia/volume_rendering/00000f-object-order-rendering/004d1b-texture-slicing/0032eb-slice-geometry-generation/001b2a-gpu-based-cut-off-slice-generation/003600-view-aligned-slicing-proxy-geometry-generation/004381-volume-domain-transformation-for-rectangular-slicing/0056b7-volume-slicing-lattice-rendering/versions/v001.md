# Volume-Slicing Lattice Rendering

Also called: Lattice-based volumetric rendering, Shader-accelerated volume-slicing

## Overview
Volume-Slicing Lattice Rendering is a real-time volumetric rendering method that approximates complex fluid volumes, specifically fire, as a lattice of hexahedral volumes aligned along parametric curves [S1]. It solves the performance bottleneck of raycasting, which requires prohibitively expensive voxel densities for real-time production, by leveraging shader hardware acceleration to merge flame elements visually [S1]. Unlike its sibling [Deformable Slicing Surface](11614-deformable-slicing-surface.md), which adapts the slicing geometry to the volume's shape, this method uses a fixed lattice structure derived from the Frenet Frame, building on the domain transformation of [Volume Domain Transformation for Rectangular Slicing](11012-volume-domain-transformation-for-rectangular-slicing.md) to ensure rectangular cutting sections [S1].

## How it works
**Inputs:**
1.  A set of parametric space curves defining the spine of the flame elements [S1].
2.  A texture-based cylindrical profile representing the oxidation region (color volume) [S1].
3.  Procedural controls governing placement, intensity, lifespan, shape, color, size, and behavior [S1].

**Outputs:**
*   A rendered image of the volumetric fire with locally turbulent details and visually merged flame elements [S1].

**Data Structures:**
*   **Curve:** A uniform B-spline defined by control points, interpolated using the de Boor algorithm to guarantee second-order continuity, affine invariance, and the convex hull property [S1].
*   **Lattice:** A sequence of hexahedrons defined continuously at regular intervals along the curve [S1]. Each hexahedron has a constant height and its bottom face is perpendicular to the tangent of the curve at the current control point [S1].
*   **Color Volume:** A 3D texture or procedural volume representing the color properties of the flame, defined in the parametric space of the flame texture [S1].

**Steps:**
1.  **Curve Construction:** Interpolate a smooth B-spline curve through a set of points that evolve according to physics-based, procedural, and hand-defined wind fields, or remain constant if manually positioned [S1]. Re-sample the curves frequently to ensure continuity and handle moving sources [S1].
2.  **Lattice Generation:** Define a local reference frame for each point on the curve using the Frenet Frame [Far02] [S1]. Construct a bounding volume around the curve composed of hexahedrons at regular intervals, where each hexahedron is oriented such that its bottom is perpendicular to the curve's tangent [S1].
3.  **Color Volume Definition:** Build a color volume using a texture-based cylindrical profile that represents the oxidation region of the flame [S1].
4.  **Particle Transformation:** Transform particles (or sampling points) into the parametric space of the flame texture using inverse parametrization [S1].
5.  **Turbulence Application:** Apply M-noise or Improved Perlin noise to provide local turbulent detail. This involves applying pseudorandom gradients to each pixel [S1].
6.  **Rendering:** Render the particles as shader fragments using shader hardware acceleration (GLSL or HLSL) [S1].
7.  **Color Interpolation:** Compute the final color of each pixel by trilinearly interpolating according to the color properties of its neighbors within the lattice volumes, allowing flame elements to visually merge [S1].

**Pseudocode:**
```python
# Pseudocode for Volume-Slicing Lattice Rendering
# Based on [S1]

def render_fire(curve_points, texture_profile, procedural_controls):
    """
    Renders volumetric fire using lattice-based slicing.
    """
    # 1. Curve Construction
    # Use uniform B-spline with de Boor algorithm for second-order continuity
    spline_curve = create_uniform_b_spline(curve_points)
    
    # 2. Lattice Generation
    # Define hexahedrons along the curve using Frenet Frame
    lattice_hexahedrons = []
    for t in range(0, curve_length, interval):
        point = evaluate_spline(spline_curve, t)
        tangent = compute_tangent(spline_curve, t)
        # Frenet Frame provides normal and binormal
        normal, binormal = compute_frenet_frame(tangent)
        
        # Create hexahedron with constant height, bottom perpendicular to tangent
        hexahedron = create_hexahedron(
            center=point,
            tangent=tangent,
            normal=normal,
            binormal=binormal,
            height=constant_height
        )
        lattice_hexahedrons.append(hexahedron)
    
    # 3. Color Volume Definition
    # Texture-based cylindrical profile for oxidation region
    color_volume = build_color_volume(texture_profile)
    
    # 4. & 5. Rendering and Interpolation (Shader Stage)
    # For each pixel in the view:
    final_color = vec3(0.0)
    
    # Determine which hexahedrons intersect the view ray or screen pixel
    intersecting_hexahedrons = get_intersecting_hexahedrons(lattice_hexahedrons, pixel_position)
    
    if intersecting_hexahedrons:
        # Transform particle to parametric space of flame texture
        parametric_coords = inverse_parametrization(intersecting_hexahedrons, pixel_position)
        
        # Apply turbulence
        turbulence = apply_noise(parametric_coords, noise_type="M-noise") # or Improved Perlin
        
        # Trilinear interpolation of color properties from neighbors
        # This merges flame elements visually
        base_color = trilinear_interpolate(color_volume, parametric_coords)
        
        # Combine base color with turbulence and procedural controls
        final_color = apply_turbulence(base_color, turbulence)
        final_color = apply_procedural_controls(final_color, procedural_controls)
    
    return final_color
```

**Parameters:**
*   **Interval:** Regular interval for hexahedron placement along the curve. Not given in the sources.
*   **Constant Height:** Height of each hexahedron. Not given in the sources.
*   **Noise Type:** M-noise or Improved Perlin noise. [S1]
*   **Procedural Controls:** Placement, intensity, lifespan, evolution in shape, color, size, and behavior. [S1]

**Edge Cases and Pitfalls:**
*   **Discrete Gaps:** The rendering speed must be balanced to avoid creating noticeably discrete gaps between the planes when examining the object from different viewpoints [S1].
*   **Precision:** Trilinear interpolation requires accurate mapping of pixel positions to the parametric space of the flame texture [S1].

## Operating characteristics
*   **Time Complexity:** Real-time performance is achieved by leveraging shader hardware acceleration, avoiding the high cost of raycasting [S1].
*   **Memory Complexity:** Scales well compared to voxel-based methods, requiring less memory than the prohibitively expensive voxel densities needed for raycasting [S1].
*   **Performance:** Tested within the Irrlicht 3D engine, rendered via OpenGL and DirectX using GLSL and HLSL [S1].
*   **Strengths:** Integrates into existing game engines with minimal CPU cycles; suitable for real-time production systems where off-line rendering (taking 2-3 minutes per frame) is not feasible [S1].
*   **Limitations:** Approximates the volume with a lattice of hexahedrons, which may not capture all fine details of complex fluid dynamics without high-resolution textures or noise [S1].
*   **When to use:** Real-time volumetric rendering of fire in game engines.
*   **When not to use:** Offline production rendering where higher quality is prioritized over speed, or for volumes that do not fit the parametric curve model well.

## Background
*   **Origin:** The method was described in [CCF94] and perfected for shader hardware in [FKM∗ 07] [S1]. It was implemented and tested in the Irrlicht 3D engine by Y. Vanzine & D. Vrajitoru [S1].
*   **History:** The movie industry has utilized realistic fire rendering since 1985 with *Star Trek II: The Wrath of Khan* by Pixar Studios [Ree85] [S1]. Previous off-line algorithms took 2-3 minutes per frame [S1].
*   **Usage:** Implemented in the Irrlicht 3D engine, rendered via OpenGL and DirectX using GLSL and HLSL [S1].
