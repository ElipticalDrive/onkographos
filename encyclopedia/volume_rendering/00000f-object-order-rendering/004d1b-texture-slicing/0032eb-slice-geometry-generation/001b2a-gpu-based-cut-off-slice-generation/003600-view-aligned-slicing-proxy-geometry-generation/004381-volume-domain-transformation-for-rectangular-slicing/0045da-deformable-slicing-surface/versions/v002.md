# Deformable Slicing Surface

Also called: Slicing Surface Field

## Overview
Deformable Slicing Surface (DS) is a slice geometry generation method for hyper-dimensional radiance fields that maps spatial positions to varying ambient coordinates, replacing fixed axis-aligned planes [S1]. It solves the problem of fading artifacts and inefficient representation capacity inherent in Axis-Aligned Slicing Plane (AP) methods by allowing different parts of the scene to reference distinct regions of the ambient template space, resulting in sharper details and smoother interpolations between states [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Observation-space sample point $x$, latent deformation code $\omega_i$ (shared with the spatial deformation field), and template NeRF $F$ [S1].
*   **Output:** Ambient coordinate $w$ defining the cross-sectional subspace for the sample, which is used to query the template for color $c$ and density $\sigma$ [S1].

**Data Structures:**
The method relies on a Multi-Layer Perceptron (MLP) to define the mapping function $H$ [S1].
*   **MLP Architecture for $H$:** Depth 6, Width 64, with a skip connection at the 5th layer [S1].
*   **Initialization:** The weights of the last layer are sampled from a normal distribution $\mathcal{N}(0, 10^{-5})$ [S1].

**Positional Encoding:**
Separate positional encodings are applied to the inputs $x$ and $w$ using a windowed positional encoding $\gamma_\alpha$ [S1].
*   **For input $x$ (spatial position):** Uses windowed positional encoding with $m=6$ [S1].
*   **For input $w$ (hyper-coordinate):** Uses windowed positional encoding with $m=1$ and parameter $\beta$ [S1].
    *   **Parameter $\beta$ Schedule:** $\beta$ is fixed at $0$ for the first $1000$ iterations, then linearly increased to $1$ over the next $10000$ iterations [S1].

**Algorithm Steps:**
The evaluation of the observation-space radiance field involves three sequential steps [S1]:
1.  **Spatial Deformation:** The observation-space point $x$ is deformed using the spatial deformation field $T$ and the latent code $\omega_i$ to obtain the deformed spatial coordinate $x'$ [S1].
    $$x' = T(x, \omega_i)$$
2.  **Deformable Slicing Surface Mapping:** The original spatial point $x$ and latent code $\omega_i$ are passed through the deformable slicing surface field $H$ to determine the ambient coordinate $w$ [S1].
    $$w = H(x, \omega_i)$$
3.  **Template Query:** The deformed spatial coordinate $x'$, the computed ambient coordinate $w$, the viewing direction $d$, and the appearance code $\psi_i$ are queried from the template NeRF $F$ to retrieve color $c$ and density $\sigma$ [S1].
    $$(c, \sigma) = F(x', w, d, \psi_i)$$

**Pseudocode:**
```python
import numpy as np

def windowed_positional_encoding(x, m, alpha=1.0):
    """Applies windowed positional encoding to input x.
    The exact mathematical formulation of gamma_alpha is not specified in the sources [G]."""
    freq_bands = np.linspace(0, alpha, m)
    return np.concatenate([np.sin(2 * np.pi * freq_bands * x), np.cos(2 * np.pi * freq_bands * x)], axis=-1)

def deformable_slicing_surface_mlp(x_pe, omega_i, weights, biases):
    """MLP defining H: (x, omega_i) -> w. Depth 6, Width 64, skip connection at layer 5 [S1]."""
    h = np.concatenate([x_pe, omega_i], axis=-1)
    h_skip = None
    for i in range(len(weights)):
        h = np.maximum(0, h @ weights[i] + biases[i]) # ReLU activation [G]
        if i == 4: # Layer 5 (0-indexed)
            h_skip = h
        if i == len(weights) - 1: # Last layer
            h = h @ weights[i] + biases[i] # Linear output, no activation
    return h + h_skip

def evaluate_radiance_field(x, omega_i, psi_i, d, T, F, h_weights, h_biases, beta):
    """Evaluates the radiance field using Deformable Slicing Surface."""
    # Step 1: Spatial Deformation
    x_prime = T(x, omega_i)
    
    # Step 2: Deformable Slicing Surface Mapping
    # PE for x uses m=6 [S1]
    x_pe = windowed_positional_encoding(x, m=6)
    w = deformable_slicing_surface_mlp(x_pe, omega_i, h_weights, h_biases)
    
    # Step 3: Template Query
    # PE for w uses m=1 and parameter beta [S1]
    w_pe = windowed_positional_encoding(w, m=1, alpha=beta)
    c, sigma = F(x_prime, w_pe, d, psi_i)
    return c, sigma
```

**Edge Cases and Pitfalls:**
*   **Ambient Dimension Count:** The method uses 2 ambient dimensions ($W=2$) in the cited experiments. Increasing $W$ did not improve performance for the tested sequences [S1].
*   **Initialization Sensitivity:** The last layer weights are initialized with very small variance ($10^{-5}$) to ensure stable training start [S1].
*   **Beta Schedule:** The linear increase of $\beta$ for the $w$ encoding is critical for training stability; fixing it at $0$ initially prevents high-frequency noise from dominating early gradients [S1].

## Operating characteristics
**Time and Memory Complexity:**
The method adds the computational cost of evaluating the MLP $H$ (depth 6, width 64) per sample point, in addition to the spatial deformation field $T$ and template query $F$ [S1].

**Measured Performance:**
*   **Hardware:** Evaluated on 4 TPU v4s [S1].
*   **Training Time:** Half 1080p (960x540) with 128 samples per ray and batch size 6,144 takes roughly 8 hours for 250k iterations [S1]. Full HD (~1920x1080) with 256 samples per ray takes roughly 64 hours for 1M iterations [S1].
*   **Comparison to Axis-Aligned Plane (AP):** DS provides sharper details and smoother interpolations between states compared to AP [S1]. AP forces all ray samples for an observation to share the same ambient coordinates, leading to fading artifacts in regions like eyes, mouth, and chin [S1]. DS allows different spatial positions to reference varying parts of the ambient space, improving reconstruction quality [S1].

**Strengths and Limitations:**
*   **Strengths:** Efficient use of ambient dimensions, better reconstruction quality, and smoother interpolation between topological states [S1].
*   **Limitations:** Increased model complexity due to the additional MLP $H$, sensitivity to the $\beta$ schedule, and limited benefit from increasing ambient dimensions beyond 2 in tested scenarios [S1].

## Background
**Origin:**
The Deformable Slicing Surface method was introduced in the HyperNeRF paper (2021) as part of a higher-dimensional representation for topologically varying Neural Radiance Fields [S1].

**History and Development:**
The method was developed to address limitations in previous hyper-NeRF approaches that used axis-aligned slicing planes [S1]. The authors implemented the method on top of JaxNeRF, a JAX implementation of NeRF [S1].

**Usage:**
It is used in neural radiance field rendering for dynamic scenes with topological changes, such as facial expressions [S1].
