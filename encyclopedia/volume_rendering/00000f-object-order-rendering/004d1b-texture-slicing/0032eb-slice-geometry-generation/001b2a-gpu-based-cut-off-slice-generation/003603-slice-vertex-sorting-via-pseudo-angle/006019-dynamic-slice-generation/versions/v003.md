# Dynamic Slice Generation

## Overview
Dynamic Slice Generation generates mesh vertices and indices by slicing a bounding box along the view vector, extracting edges where the view distance crosses slice boundaries, and managing edge lifetimes via a priority queue [S1, unofficial]. It differs from static slicing methods by adapting the active edge set to the current view direction in real-time, and from vertex-sorting methods like [Slice Vertex Sorting via Pseudo-Angle](7642-slice-vertex-sorting-via-pseudo-angle.md) by relying on edge traversal rather than post-hoc vertex ordering [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- Eight corner positions (`_posCorners`) and eight corner texture coordinates (`_texCorners`) defining the volume bounding box [S1, unofficial].
- A normalized view vector (`_viewVector`) derived from the camera's model-view matrix [S1, unofficial].
- `sliceSpacing`: a float parameter defining the distance between consecutive slices along the view vector [S1, unofficial].

**Outputs:**
- `_points`: an array of vertex positions [S1, unofficial].
- `_texCoords`: an array of texture coordinates [S1, unofficial].
- `_indexes`: an array of vertex indices [S1, unofficial].

### Data Structures
**Edge Object:**
Each active edge is represented by an object with the following fields [S1, unofficial]:
- `expired`: boolean, indicates if the edge has passed out of the current slice range [S1, unofficial].
- `startIndex`: int, index of the starting corner of the bounding box edge (0–7) [S1, unofficial].
- `endIndex`: int, index of the ending corner of the bounding box edge (0–7) [S1, unofficial].
- `deltaPos`: THREE.Vector3, the change in position per unit distance along the view vector for this edge [S1, unofficial].
- `deltaTex`: THREE.Vector3, the change in texture coordinates per unit distance along the view vector for this edge [S1, unofficial].
- `pos`: THREE.Vector3, the current position of the edge intersection point [S1, unofficial].
- `tex`: THREE.Vector3, the current texture coordinate of the edge intersection point [S1, unofficial].
- `cur`: int, the current edge index in the output buffer [S1, unofficial].

**Priority Queue:**
- `expirations`: a priority queue storing the distances at which edges expire [S1, unofficial].

**Buffers:**
- `activeEdges`: an array of Edge objects [S1, unofficial].
- `index`: a Uint16Array for indices [S1, unofficial].
- `position`: a Float32Array for vertex positions [S1, unofficial].
- `tex`: a Float32Array for texture coordinates [S1, unofficial].

### Steps
1. **Calculate Corner Distances:** Compute the distance of each of the eight bounding box corners from the origin along the view vector by taking the dot product of the corner position with the normalized view vector [S1, unofficial]:
   $$
   \text{cornerDistance}[i] = \text{posCorners}[i] \cdot \text{viewVector}
   $$
   where $i \in \{0, \dots, 7\}$ [S1, unofficial].

2. **Find Extremes:** Determine the minimum and maximum distances among the eight corners, and track the index of the corner with the maximum distance [S1, unofficial]:
   $$
   \text{minDistance} = \min_{i} (\text{cornerDistance}[i])
   $$
   $$
   \text{maxDistance} = \max_{i} (\text{cornerDistance}[i])
   $$
   $$
   \text{maxCorner} = \arg\max_{i} (\text{cornerDistance}[i])
   $$
   [S1, unofficial].

3. **Align Slice Distance:** Align the starting slice distance to the grid defined by `sliceSpacing` by rounding down the maximum distance [S1, unofficial]:
   $$
   \text{sliceDistance} = \lfloor \frac{\text{maxDistance}}{\text{sliceSpacing}} \rfloor \times \text{sliceSpacing}
   $$
   [S1, unofficial].

4. **Initialize State:** Initialize `activeEdges` as an empty array, set `firstEdge = 0` and `nextEdge = 0`, and initialize `expirations` as an empty priority queue [S1, unofficial].

5. **Create Edge Function:** Define a helper function `createEdge(startIndex, endIndex)` to initialize an edge object [S1, unofficial]:
   - If `nextEdge >= 12`, return `undefined` (limit on active edges) [S1, unofficial].
   - Create an edge object with `expired = false`, `startIndex`, `endIndex`, and `cur = nextEdge` [S1, unofficial].
   - Calculate the range of distances along the view vector for this edge:
     $$
     \text{range} = \text{cornerDistance}[\text{startIndex}] - \text{cornerDistance}[\text{endIndex}]
     $$
     [S1, unofficial].
   - If `range !== 0.0`:
     - Compute inverse range:
       $$
       \text{irange} = \frac{1.0}{\text{range}}
       $$
       [S1, unofficial].
     - Calculate `deltaPos`:
       $$
       \text{deltaPos} = (\text{posCorners}[\text{endIndex}] - \text{posCorners}[\text{startIndex}]) \times \text{irange}
       $$
       [S1, unofficial].
     - Calculate `deltaTex`:
       $$
       \text{deltaTex} = (\text{texCorners}[\text{endIndex}] - \text{texCorners}[\text{startIndex}]) \times \text{irange}
       $$
       [S1, unofficial].
   - If `range === 0.0`, `deltaPos` and `deltaTex` remain zero to prevent division by zero [S1, unofficial].

6. **Process Slices:** The source code does not provide the main loop for iterating slices, updating edge positions, or generating vertices/indices.

### Pseudocode
```python
import math

class Vector3:
    def __init__(self, x=0.0, y=0.0, z=0.0):
        self.x, self.y, self.z = x, y, z
    def dot(self, other):
        return self.x * other.x + self.y * other.y + self.z * other.z
    def subVectors(self, a, b):
        self.x = a.x - b.x
        self.y = a.y - b.y
        self.z = a.z - b.z
        return self
    def multiplyScalar(self, s):
        self.x *= s
        self.y *= s
        self.z *= s
        return self

class PriorityQueue:
    def __init__(self):
        self._heap = []
    def push(self, item):
        self._heap.append(item)
        self._heap.sort(key=lambda x: x[0])
    def pop(self):
        return self._heap.pop(0)

def dynamic_slice_generation(pos_corners, tex_corners, view_vector, slice_spacing):
    # Step 1: Calculate Corner Distances
    corner_distances = [pos.dot(view_vector) for pos in pos_corners]
    
    # Step 2: Find Extremes
    max_distance = corner_distances[0]
    min_distance = corner_distances[0]
    max_corner = 0
    for i in range(1, 8):
        if corner_distances[i] > max_distance:
            max_corner = i
            max_distance = corner_distances[i]
        if corner_distances[i] < min_distance:
            min_distance = corner_distances[i]
            
    # Step 3: Align Slice Distance
    slice_distance = math.floor(max_distance / slice_spacing) * slice_spacing
    
    # Step 4: Initialize State
    active_edges = []
    first_edge = 0
    next_edge = 0
    expirations = PriorityQueue()
    
    points = []
    tex_coords = []
    indexes = []
    
    # Step 5: Create Edge Function
    def create_edge(start_index, end_index):
        nonlocal next_edge
        if next_edge >= 12:
            return None
        edge = {
            'expired': False,
            'startIndex': start_index,
            'endIndex': end_index,
            'deltaPos': Vector3(),
            'deltaTex': Vector3(),
            'pos': Vector3(),
            'tex': Vector3(),
            'cur': next_edge
        }
        edge_range = corner_distances[start_index] - corner_distances[end_index]
        if edge_range != 0.0:
            irange = 1.0 / edge_range
            edge['deltaPos'].subVectors(pos_corners[end_index], pos_corners[start_index]).multiplyScalar(irange)
            edge['deltaTex'].subVectors(tex_corners[end_index], tex_corners[start_index]).multiplyScalar(irange)
        next_edge += 1
        return edge

    # The source code does not provide the main loop for iterating slices, 
    # updating edge positions, or generating vertices/indices.
    return points, tex_coords, indexes
```

### Parameters
- `sliceSpacing`: float parameter defining the distance between consecutive slices along the view vector [S1, unofficial]. Typical value: 0.5 [S1, unofficial].

### Edge Cases and Pitfalls
- **Division by Zero:** If `startIndex` and `endIndex` have identical corner distances (i.e., the edge is parallel to the slice plane), `range` becomes 0.0 [S1, unofficial]. The code explicitly checks `range !== 0.0` before calculating `irange` to prevent division by zero [S1, unofficial].
- **Boundary Conditions:** The alignment of `sliceDistance` to the grid using `Math.floor` ensures that slices start at or before the maximum extent of the volume [S1, unofficial].
- **Edge Limit:** The code limits `nextEdge` to 12, assuming a maximum of 12 active edges consistent with the 12 edges of a cube [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources [S1, unofficial].

- **Scaling:** Not given in the sources [S1, unofficial].
- **Strengths:** Dynamic adaptation to view direction; efficient edge management via priority queue; avoids pre-computation of all intersections [S1, unofficial].
- **Limitations:** Limited to convex bounding boxes; requires careful handling of edge lifetimes [S1, unofficial].
- **When to use:** Suitable for real-time volume rendering where the view direction changes frequently and the volume is approximated by a bounding box [S1, unofficial].
- **When not to use:** Not suitable for non-convex volumes or when high precision is required for slice alignment [S1, unofficial].

## Background
Dynamic Slice Generation was introduced in the context of WebGL-based volumetric rendering, specifically in the `VolumetricFire` example by yomotsu [S1, unofficial]. It is part of a broader effort to implement efficient slice-based volume rendering techniques on the GPU using JavaScript and Three.js [S1, unofficial]. The method builds on the principles of edge walking and slice plane intersection, adapting them for dynamic view changes [S1, unofficial].
