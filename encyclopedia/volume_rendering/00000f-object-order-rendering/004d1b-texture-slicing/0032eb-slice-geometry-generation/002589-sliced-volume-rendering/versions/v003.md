# Sliced Volume Rendering
Also called: Sliced Volume Rendering with Transfer Functions and Lighting, vl::SlicedVolume

## Overview
Sliced Volume Rendering is a technique that generates slice geometry on the fly to render volumetric data with real-time lighting and transfer functions [S1, unofficial]. It differs from standard texture slicing by decoupling the geometric generation of slices from the rasterization, allowing for dynamic per-pixel lighting (up to 4 lights) and flexible transfer function application via GLSL or precomputed textures [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D volume image (scalar data), a bounding box (AABB) defining the volume extent, and a slice count.
- Output: A rendered image with alpha blending, where color and opacity are determined by the transfer function and lighting model.

**Data Structures:**
- `vl::SlicedVolume`: An object that manages the generation of slice geometry and binds it to an `Actor`.
- `AABB`: Axis-Aligned Bounding Box defined by two `vec3` points (min and max).
- `Texture Unit 0`: Binds the volume data (3D texture).
- `Texture Unit 1`: Binds the transfer function (1D or 2D texture).
- `Texture Unit 2`: Binds precomputed gradient normals (3D texture, format `TF_RGBA8`).

**Parameters:**
- `SLICE_COUNT`: Number of slices. Typical value: 1000 [S1, unofficial].
- `PRECOMPUTE_GRADIENT`: Boolean flag. If true, uses a precomputed gradient texture [S1, unofficial].
- `val_threshold`: Shader uniform controlling alpha bias/threshold. Range: 0.0 to 1.0 [S1, unofficial].
- `gradient_delta`: Uniform for on-the-fly normal computation, set to `fvec3(0.5f/img->width(), 0.5f/img->height(), 0.5f/img->depth())` [S1, unofficial].

**Steps:**
1. **Initialization:** Create a `vl::SlicedVolume` object and bind it to an `Actor` [S1, unofficial].
2. **Configuration:** Set the slice count (`setSliceCount`) and the volume bounding box (`setBox`) [S1, unofficial].
3. **Texture Coordinate Generation:** Generate texture coordinates for the sliced volume geometry based on the input image dimensions (width, height, depth) using `generateTextureCoordinates` [S1, unofficial].
4. **Mode Selection:** Determine if GLSL is supported and if dynamic lighting is enabled [S1, unofficial].
5. **GLSL Mode Setup (if `USE_GLSL` is true):**
   a. Attach the vertex and fragment shaders (e.g., `volume_luminance_light.vs` and `.fs`) to the GLSL program [S1, unofficial].
   b. Bind the volume data as a 3D texture to texture unit 0 and set the `volume_texunit` uniform to 0 [S1, unofficial].
   c. Bind the transfer function texture to texture unit 1 and set the `trfunc_texunit` uniform [S1, unofficial].
   d. Set the `trfunc_delta` uniform to `0.5f / trfunc->width()` [S1, unofficial].
   e. If `PRECOMPUTE_GRADIENT` is true:
      i. Generate gradient normals using `vl::genGradientNormals(img)` [S1, unofficial].
      ii. Bind the gradient texture to texture unit 2 (format `TF_RGBA8`) and set `gradient_texunit` to 2 [S1, unofficial].
      iii. Set `precomputed_gradient` uniform to 1 [S1, unofficial].
   f. If `PRECOMPUTE_GRADIENT` is false:
      i. Set `precomputed_gradient` uniform to 0 [S1, unofficial].
      ii. Set `gradient_delta` uniform to `fvec3(0.5f/img->width(), 0.5f/img->height(), 0.5f/img->depth())` [S1, unofficial].
   g. Disable alpha testing (`EN_ALPHA_TEST`) as fragment discarding is handled in the fragment shader [S1, unofficial].
6. **Non-GLSL Mode Setup (if `USE_GLSL` is false):**
   a. Precompute the volume with transfer function and lighting using `vl::genRGBAVolume` [S1, unofficial].
   b. Bind the resulting RGB volume texture to unit 0 [S1, unofficial].
   c. Enable alpha testing with a `FU_GEQUAL` threshold [S1, unofficial].
7. **Rendering:** The `SlicedVolume` object generates the slice geometry on the fly, which is then rasterized and composited [S1, unofficial].

**Pseudocode:**
```python
def setup_sliced_volume(volume_img, volume_box, slice_count=1000, use_glsl=True, precompute_gradient=False):
    # 1. Initialize SlicedVolume and bind to Actor
    sliced_vol = SlicedVolume()
    actor = Actor()
    actor.set_effect(Effect())
    sliced_vol.bind_actor(actor)
    
    # 2. Set parameters
    sliced_vol.set_slice_count(slice_count)
    sliced_vol.set_box(volume_box)
    
    # 3. Generate texture coordinates
    img_dims = ivec3(volume_img.width, volume_img.height, volume_img.depth)
    sliced_vol.generate_texture_coordinates(img_dims)
    
    # 4. Setup shader program
    shader = actor.effect().shader()
    
    if use_glsl:
        # 5a. Attach shaders
        shader.attach_shader(GLSLVertexShader("/glsl/volume_luminance_light.vs"))
        shader.attach_shader(GLSLFragmentShader("/glsl/volume_luminance_light.fs"))
        
        # 5b. Bind volume texture
        vol_tex = Texture(volume_img)
        shader.goc_texture_sampler(0).set_texture(vol_tex)
        shader.goc_uniform("volume_texunit").set_uniform_i(0)
        
        # 5c. Bind transfer function
        trfunc_tex = Texture(make_color_spectrum(128, blue, royalblue, green, yellow, crimson))
        shader.goc_texture_sampler(1).set_texture(trfunc_tex)
        shader.goc_uniform("trfunc_texunit").set_uniform_i(1)
        shader.goc_uniform("trfunc_delta").set_uniform_f(0.5f / trfunc_tex.width)
        
        # 5d/e. Handle gradients
        if precompute_gradient:
            gradient_tex = Texture(gen_gradient_normals(volume_img), format=TF_RGBA8)
            shader.goc_texture_sampler(2).set_texture(gradient_tex)
            shader.goc_uniform("gradient_texunit").set_uniform_i(2)
            shader.goc_uniform("precomputed_gradient").set_uniform_i(1)
        else:
            shader.goc_uniform("precomputed_gradient").set_uniform_i(0)
            shader.goc_uniform("gradient_delta").set_uniform_fvec3(
                0.5f / volume_img.width, 
                0.5f / volume_img.height, 
                0.5f / volume_img.depth
            )
        
        # 5g. Disable alpha testing
        shader.disable(EN_ALPHA_TEST)
        
    else:
        # 6. Non-GLSL mode
        rgb_vol_tex = Texture(gen_rgba_volume(volume_img))
        shader.goc_texture_sampler(0).set_texture(rgb_vol_tex)
        shader.enable(EN_ALPHA_TEST)
        shader.set_alpha_test_threshold(FU_GEQUAL, 0.5) # Typical threshold
        
    # 7. Add actor to scene
    scene_manager.tree().add_actor(actor)
```

**Edge Cases and Pitfalls:**
- Requires OpenGL 3D texture support (`Has_Texture_3D`) or GLSL support (`Has_GLSL`). If neither is available, the application must exit [S1, unofficial].
- Precomputing gradients can be slow and requires more memory [S1, unofficial].
- Alpha testing must be disabled in GLSL mode to allow fragment shader-based discarding [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Rendering time scales with the number of slices (`SLICE_COUNT`). Higher slice counts yield better quality but slower rendering [S1, unofficial].
- **Memory Complexity:** Uses additional memory for precomputed gradient textures if `PRECOMPUTE_GRADIENT` is true [S1, unofficial].
- **Performance:** Real-time lighting (up to 4 lights) is supported in GLSL mode [S1, unofficial]. Precomputed gradients can speed up lighting computations at the cost of memory [S1, unofficial].
- **Strengths:** Dynamic lighting and transfer functions in real-time [S1, unofficial].
- **Limitations:** Requires specific OpenGL features (3D textures or GLSL) [S1, unofficial]. Non-GLSL mode lacks dynamic lighting [S1, unofficial].

## Background
This method is part of the Visualization Library (vl) documentation, specifically demonstrated in the `App_VolumeSliced` example [S1, unofficial]. It builds on the principles of texture slicing by automating the generation of slice geometry and integrating advanced shading techniques [S1, unofficial].
