# Sliced Volume Rendering

Also called: Sliced Volume Rendering with Transfer Functions and Lighting, vl::SlicedVolume

## Overview
Sliced Volume Rendering is a technique that renders volumetric data by dynamically generating slice geometry on the fly, supporting real-time lighting (up to 4 lights) and transfer functions via GLSL, or precomputed illumination [S1, unofficial]. It builds on [Texture slicing](25-texture-slicing.md) by using the `vl::SlicedVolume` class to manage the proxy geometry and shader state, distinguishing itself from siblings like [Plane Slicing](845-plane-slicing.md) through its integrated support for dynamic lighting and transfer function textures within a GLSL pipeline [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar volume image (typically `IF_LUMINANCE` format), a bounding box (AABB) defining the volume's spatial extent, and a transfer function (optional, for GLSL mode).
*   **Output:** A rendered image with accumulated color and opacity, composited via hardware blending.

**Data Structures:**
*   **Volume Texture:** 3D texture bound to texture unit 0, containing the scalar data.
*   **Transfer Function Texture:** 1D or 2D texture bound to texture unit 1, mapping scalar values to RGBA.
*   **Gradient Texture (Optional):** 3D texture bound to texture unit 2, containing precomputed gradient normals (format `TF_RGBA8`).
*   **Proxy Geometry:** A set of parallel planes generated by `vl::SlicedVolume`, with texture coordinates mapped to the input image dimensions.

**Parameters:**
*   `SLICE_COUNT`: Number of slices. Typical value: 1000 [S1, unofficial].
*   `PRECOMPUTE_GRADIENT`: Boolean flag. If true, uses precomputed gradient texture [S1, unofficial].
*   `val_threshold`: Shader uniform controlling alpha bias/threshold. Range: 0.0 to 1.0 [S1, unofficial].
*   `gradient_delta`: Uniform for on-the-fly normal computation: $fvec3(0.5f/\text{width}, 0.5f/\text{height}, 0.5f/\text{depth})$ [S1, unofficial].

**Steps:**
1.  **Initialization:** Create `vl::SlicedVolume` and bind it to an `Actor`. Set the slice count (`SLICE_COUNT`) and define the volume bounding box (AABB) [S1, unofficial].
2.  **Geometry Generation:** Generate texture coordinates for the sliced volume geometry based on the input image dimensions (width, height, depth) [S1, unofficial].
3.  **Shader Setup (GLSL Mode):**
    *   Attach `volume_luminance_light.fs` and `volume_luminance_light.vs` to the GLSL program [S1, unofficial].
    *   Bind the volume data as a 3D texture to texture unit 0 and set the `volume_texunit` uniform to 0 [S1, unofficial].
    *   Bind the transfer function texture to texture unit 1 and set the `trfunc_texunit` uniform to 1 [S1, unofficial].
    *   Set the `trfunc_delta` uniform to $0.5f / \text{transfer\_function\_width}$ [S1, unofficial].
    *   If `PRECOMPUTE_GRADIENT` is true:
        *   Generate gradient normals using `vl::genGradientNormals(img)` [S1, unofficial].
        *   Bind the gradient texture to texture unit 2 (format `TF_RGBA8`) and set the `gradient_texunit` uniform to 2 [S1, unofficial].
        *   Set the `precomputed_gradient` uniform to 1 [S1, unofficial].
    *   If `PRECOMPUTE_GRADIENT` is false:
        *   Set the `precomputed_gradient` uniform to 0 [S1, unofficial].
        *   Set the `gradient_delta` uniform to $fvec3(0.5f/\text{img->width()}, 0.5f/\text{img->height()}, 0.5f/\text{img->depth()})$ [S1, unofficial].
    *   Disable alpha testing (`EN_ALPHA_TEST`) as fragment discarding is handled in the fragment shader [S1, unofficial].
4.  **Shader Setup (Non-GLSL Mode):**
    *   Precompute the volume with transfer function and lighting using `vl::genRGBAVolume` [S1, unofficial].
    *   Bind the resulting RGB volume texture to unit 0 [S1, unofficial].
    *   Enable alpha testing with `FU_GEQUAL` threshold [S1, unofficial].
5.  **Rendering:** The `vl::SlicedVolume` class generates the proxy geometry on the fly, and the GPU rasterizes the slices, compositing them into the final image [S1, unofficial].

**Pseudocode:**
```python
def render_sliced_volume(volume_img, transfer_func_img, use_glsl, precompute_gradient, slice_count, volume_box):
    # Check hardware support
    if not has_texture_3d and not has_glsl:
        raise Error("Requires 3D texture or GLSL support")

    # Initialize SlicedVolume
    sliced_volume = SlicedVolume()
    actor = Actor()
    actor.set_effect(Effect())
    sliced_volume.bind_actor(actor)
    sliced_volume.set_slice_count(slice_count)
    sliced_volume.set_box(volume_box)

    # Generate texture coordinates
    sliced_volume.generate_texture_coordinates(ivec3(volume_img.width, volume_img.height, volume_img.depth))

    if use_glsl:
        # Setup GLSL program
        glsl_program = GLSLProgram()
        glsl_program.attach_shader(GLSLFragmentShader("volume_luminance_light.fs"))
        glsl_program.attach_shader(GLSLVertexShader("volume_luminance_light.vs"))
        actor.effect().shader().set_render_state(glsl_program)

        # Bind volume texture
        vol_texture = Texture(volume_img)
        actor.effect().shader().goc_texture_sampler(0).set_texture(vol_texture)
        actor.effect().shader().goc_uniform("volume_texunit").set_uniform_i(0)

        # Bind transfer function texture
        trfunc_texture = Texture(transfer_func_img)
        actor.effect().shader().goc_texture_sampler(1).set_texture(trfunc_texture)
        actor.effect().shader().goc_uniform("trfunc_texunit").set_uniform_i(1)
        actor.effect().shader().goc_uniform("trfunc_delta").set_uniform_f(0.5f / transfer_func_img.width)

        # Handle gradients
        if precompute_gradient:
            gradient_img = gen_gradient_normals(volume_img)
            gradient_texture = Texture(gradient_img, format=TF_RGBA8)
            actor.effect().shader().goc_texture_sampler(2).set_texture(gradient_texture)
            actor.effect().shader().goc_uniform("gradient_texunit").set_uniform_i(2)
            actor.effect().shader().goc_uniform("precomputed_gradient").set_uniform_i(1)
        else:
            actor.effect().shader().goc_uniform("precomputed_gradient").set_uniform_i(0)
            actor.effect().shader().goc_uniform("gradient_delta").set_uniform(fvec3(
                0.5f / volume_img.width,
                0.5f / volume_img.height,
                0.5f / volume_img.depth
            ))

        # Disable alpha testing
        actor.effect().shader().disable(EN_ALPHA_TEST)
    else:
        # Precompute volume
        rgb_volume_img = gen_rgba_volume(volume_img, transfer_func_img)
        rgb_volume_texture = Texture(rgb_volume_img)
        actor.effect().shader().goc_texture_sampler(0).set_texture(rgb_volume_texture)
        actor.effect().shader().enable(EN_ALPHA_TEST)
        actor.effect().shader().set_alpha_test_threshold(FU_GEQUAL)

    # Add actor to scene
    scene_manager.tree().add_actor(actor)
```

## Subtopics

### [Interactive Slice and Point-Based Volume Rendering](4591-interactive-slice-and-point-based-volume-rendering.md)
Renders a 3D segmentation volume by dynamically extracting a 2D slice from the volume data, uploading it to a 2D texture, and drawing a slice plane that samples it, while overlaying segmentation labels as 3D points at voxel coordinates.

## Operating characteristics
*   **Time Complexity:** Rendering time scales with the number of slices (`SLICE_COUNT`) and the complexity of the fragment shader (e.g., number of lights, gradient computation) [S1, unofficial].
*   **Memory Complexity:** Requires memory for the volume texture, transfer function texture, and optionally a gradient texture (if `PRECOMPUTE_GRADIENT` is true) [S1, unofficial].
*   **Performance:** Very fast on modern GPUs due to reliance on rasterization hardware [S3, book]. GLSL mode allows real-time lighting but may be slower than precomputed modes [S1, unofficial].
*   **Strengths:** Real-time lighting, dynamic transfer functions, interactive threshold adjustment [S1, unofficial].
*   **Limitations:** Requires OpenGL 3D texture or GLSL support [S1, unofficial]. Non-GLSL mode lacks dynamic lighting [S1, unofficial].

## Background
The method is implemented in the Visualization Library (`vl::SlicedVolume`) and demonstrated in a tutorial on real-time volume rendering with transfer functions and lighting [S1, unofficial]. It leverages GLSL for per-pixel lighting and transfer function evaluation, supporting up to 4 lights and optional precomputed normals [S1, unofficial].
