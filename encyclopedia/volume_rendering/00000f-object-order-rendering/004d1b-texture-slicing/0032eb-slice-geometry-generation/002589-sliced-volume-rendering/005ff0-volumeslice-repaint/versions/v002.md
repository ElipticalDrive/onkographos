# VolumeSlice Repaint


## Overview
VolumeSlice Repaint is a client-side JavaScript method that renders a single volumetric slice onto an HTML5 Canvas by directly manipulating pixel data [S1, unofficial]. It visualizes scalar or label volumetric data in a web browser using CPU-based pixel manipulation instead of WebGL shaders for the final compositing step [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A volume object containing `dataType` ('label' or scalar), `data`, `sliceAccess`, `upperThreshold`, `lowerThreshold`, `windowLow`, `windowHigh`, and `colorMap` [S1, unofficial]. A canvas context `ctx`, an off-screen canvas `canvas`, and slice dimensions `iLength` and `jLength` are also required [S1, unofficial].
*   **Output:** The main canvas is updated with the rendered slice image [S1, unofficial].

**Data Structures:**
*   `imgData`: An `ImageData` object retrieved from the canvas context via `ctx.getImageData(0, 0, iLength, jLength)`, containing a `.data` field [S1, unofficial].
*   `data`: A reference to `imgData.data`, a flat array of RGBA values [S1, unofficial].
*   `volumeData`: The source volumetric data array [S1, unofficial].
*   `colorMap`: An array of integer color values for label mapping [S1, unofficial].

**Parameters:**
*   `iLength`, `jLength`: The width and height of the slice in pixels [S1, unofficial].
*   `pixelCount`: The current index in the `data` array [S1, unofficial].
*   `label`: The integer value from the volume at the current slice position [S1, unofficial].
*   `value`: The scalar value from the volume at the current slice position [S1, unofficial].

**Steps:**
1.  Check if `geometryNeedsUpdate` is true; if so, call `updateGeometry()` to refresh geometry and buffer dimensions [S1, unofficial].
2.  Retrieve the canvas context buffer, volume data, and threshold/window parameters: `iLength`, `jLength`, `sliceAccess`, `volume.data`, `upperThreshold`, `lowerThreshold`, `windowLow`, `windowHigh` [S1, unofficial].
3.  Get image data from the canvas buffer: `imgData = ctx.getImageData(0, 0, iLength, jLength)` and extract the pixel array `data = imgData.data` [S1, unofficial].
4.  Initialize `pixelCount = 0` [G].
5.  If `volume.dataType` is 'label', iterate `j` from 0 to `jLength` and `i` from 0 to `iLength`: get `label = volumeData[sliceAccess(i, j)]`; wrap label using `label = label >= this.colorMap.length ? (label % this.colorMap.length) + 1 : label`; get `color = this.colorMap[label]`; set RGBA in `data`: `data[4 * pixelCount] = (color >> 24) & 0xff`, `data[4 * pixelCount + 1] = (color >> 16) & 0xff`, `data[4 * pixelCount + 2] = (color >> 8) & 0xff`, `data[4 * pixelCount + 3] = color & 0xff`; increment `pixelCount` [S1, unofficial].
6.  Else (non-label), iterate `j` from 0 to `jLength` and `i` from 0 to `iLength`: get `value = volumeData[sliceAccess(i, j)]`; set `alpha = 0xff`; apply threshold: `alpha = upperThreshold >= value ? (lowerThreshold <= value ? alpha : 0) : 0`; apply window level: `value = Math.floor(255 * (value - windowLow) / (windowHigh - windowLow))`; clamp value: `value = value > 255 ? 255 : (value < 0 ? 0 : value | 0)`; set RGBA in `data`: `data[4 * pixelCount] = value`, `data[4 * pixelCount + 1] = value`, `data[4 * pixelCount + 2] = value`, `data[4 * pixelCount + 3] = alpha`; increment `pixelCount` [S1, unofficial].
7.  Put processed image data back to canvas buffer: `ctx.putImageData(imgData, 0, 0)` [S1, unofficial].
8.  Draw canvas buffer to main canvas: `this.ctx.drawImage(canvas, 0, 0, iLength, jLength, 0, 0, this.canvas.width, this.canvas.height)` [S1, unofficial].
9.  Mark texture map for update: `this.mesh.material.map.needsUpdate = true` [S1, unofficial].

```python
def volume_slice_repaint(ctx, canvas, volume, iLength, jLength, geometryNeedsUpdate, updateGeometry, mesh):
    if geometryNeedsUpdate:
        updateGeometry()

    volume_data = volume.data
    slice_access = volume.sliceAccess
    upper_threshold = volume.upperThreshold
    lower_threshold = volume.lowerThreshold
    window_low = volume.windowLow
    window_high = volume.windowHigh
    color_map = volume.colorMap
    data_type = volume.dataType

    img_data = get_image_data(ctx, 0, 0, iLength, jLength)
    data = img_data['data']
    pixel_count = 0

    for j in range(jLength):
        for i in range(iLength):
            if data_type == 'label':
                label = volume_data[slice_access(i, j)]
                if label >= len(color_map):
                    label = (label % len(color_map)) + 1
                color = color_map[label]
                data[4 * pixel_count] = (color >> 24) & 0xff
                data[4 * pixel_count + 1] = (color >> 16) & 0xff
                data[4 * pixel_count + 2] = (color >> 8) & 0xff
                data[4 * pixel_count + 3] = color & 0xff
            else:
                value = volume_data[slice_access(i, j)]
                alpha = 0xff
                if upper_threshold >= value and lower_threshold <= value:
                    alpha = alpha
                else:
                    alpha = 0
                if window_high != window_low:
                    value = math.floor(255 * (value - window_low) / (window_high - window_low))
                else:
                    value = 0
                if value > 255:
                    value = 255
                elif value < 0:
                    value = 0
                data[4 * pixel_count] = value
                data[4 * pixel_count + 1] = value
                data[4 * pixel_count + 2] = value
                data[4 * pixel_count + 3] = alpha
            pixel_count += 1

    put_image_data(ctx, img_data, 0, 0)
    draw_image(ctx, canvas, 0, 0, iLength, jLength, 0, 0, canvas.width, canvas.height)
    mesh.material.map.needs_update = True
```

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If `windowHigh` equals `windowLow`, the window level calculation results in division by zero [G].
*   **Label Indexing:** The label wrapping logic `(label % this.colorMap.length) + 1` assumes 1-based indexing or a specific offset requirement for the color map [S1, unofficial].
