# 3D Pixel Texture Classification

Also called: VGH Lookup

## Overview
3D Pixel Texture Classification maps three voxel attributes (Data Value, Gradient Magnitude, and Second Derivative) to color and opacity by storing the classification function in a 3D pixel texture [S1]. It differs from lower-dimensional lookup tables by explicitly incorporating curvature information via a specialized "sheet" representation for the signed second derivative axis [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Scalar volume samples containing Data Value ($D$), Gradient Magnitude ($G$), and Second Derivative ($S$) [S1].
*   **Output:** Color ($C$) and Opacity ($\alpha$) for the sample [S1].

**Data Structures:**
A 3D pixel texture stores the transfer function [S1].
*   **Axis 1 (Data Value):** 8-bit resolution (256 entries) [S1].
*   **Axis 2 (Gradient Magnitude):** 8-bit resolution (256 entries) [S1].
*   **Axis 3 (Second Derivative):** Limited resolution representing "sheets" for specific second derivative values [S1].

**Steps:**
1.  **Attribute Computation:** Compute $D$, $G$, and $S$ for each sample point [S1].
2.  **Sign Maintenance:** Apply a scale and bias transformation to $S$ to maintain its sign and map it to the texture coordinate range for proper interpolation [S1].
3.  **Texture Lookup:** Sample the 3D pixel texture using $(D, G, S')$ as coordinates [S1].
4.  **Sheet Representation:** Structure the second derivative axis as three control points ("sheets") for negative, zero, and positive values [S1].
5.  **Opacity Interpolation:** Control the opacity on the center sheet (zero second derivative) directly via classification widgets, and scale the opacity on the outer sheets (positive/negative second derivative) from the center sheet opacity according to a boundary emphasis slider [S1].

**Parameters:**
*   **Resolution:** $256 \times 256 \times N$ for the texture, where $N$ is the number of second derivative control points (typically 3 sheets) [S1].
*   **Boundary Emphasis:** A scalar parameter controlling the relative opacity scaling between outer and center sheets [S1].

**Pseudocode:**
```python
def classify_voxel(data_value, gradient_magnitude, second_derivative, texture, boundary_emphasis, s_min, s_max):
    # 1. Scale and bias second derivative to maintain sign and fit texture coordinate range [0.0, 1.0]
    # Exact transformation formula is not provided in the sources [S1].
    s_coord = (second_derivative - s_min) / (s_max - s_min)
    s_coord = max(0.0, min(1.0, s_coord))

    # 2. Sample the 3D pixel texture
    # Data Value and Gradient Magnitude use full 8-bit resolution (0-255)
    # Second Derivative uses limited resolution (3 sheets)
    # Perform trilinear interpolation
    color, alpha_raw = texture[data_value, gradient_magnitude, s_coord]

    # 3. Apply boundary emphasis scaling
    # Opacity on outer sheets is scaled from the center sheet opacity according to the boundary emphasis slider [S1].
    # Exact modulation formula is not provided in the sources [S1].
    alpha = alpha_raw * boundary_emphasis

    return color, alpha
```

## Subtopics

### Adaptive Pre-integrated Voxel Classification
A technique included in a real-time raycaster built by Roettger et al. to exploit the intrinsically parallel nature of GPUs, along with volume clipping [S2]. It addresses the inefficiency of multi-pass rendering pipelines by using a single-pass framework [S2].

## Operating characteristics
*   **Memory:** The 3D texture size is $256 \times 256 \times N$ [S1]. Full 8-bit resolution on all three axes ($256^3$ entries) would be prohibitively expensive, so the second derivative axis resolution is limited [S1].
*   **Performance:** Performance relies on hardware-accelerated 3D texture sampling [S1].
*   **Limitations:** The second derivative axis uses limited resolution, as the method prioritizes zero-crossing detection over high-fidelity curvature representation [S1].

## Background
The method was described in the context of interactive volume rendering using multi-dimensional transfer functions [S1]. It leverages the capabilities of 3D pixel textures available in graphics hardware at the time of publication [S1].
