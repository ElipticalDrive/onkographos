# Isotropic Texture Synthesis

Also called: 2D Texture Synthesis for Volumetric Impression

## Overview
Isotropic texture synthesis generates a 3D volumetric impression by applying standard 2D texture synthesis algorithms to individual cross-sections of a target volume [S1]. It solves the problem of creating materials with uniform internal structure (e.g., sponges, sausages) without requiring explicit 3D volumetric data storage or complex orientation constraints [S1]. Unlike [Cross-section Texture Synthesis with Flow Vectors](13944-cross-section-texture-synthesis-with-flow-vectors.md), which uses flow vectors to enforce directional consistency, this method assumes no dependency on position or orientation, making it significantly faster than full volumetric synthesis techniques [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 2D reference image containing the desired texture pattern, and a user-selected region within this image to serve as the sample patch [S1].
*   **Output:** A 2D texture image representing the cross-section at a specific location and orientation within the 3D model [S1].

**Data Structures:**
*   **Reference Image:** A 2D array of pixels (color/texture values) [S1].
*   **Selected Region:** A sub-region of the Reference Image defined by the user, used as the source patch for synthesis [S1].
*   **Target Cross-Section:** The 2D output image to be synthesized [S1].
*   *Exact layouts, fields, sizes, and bit packing are Not given in the sources.*

**Steps:**
1.  **Select Reference Patch:** Identify a region in the original reference image that exhibits the desired isotropic texture characteristics [S1].
2.  **Apply 2D Synthesis Algorithm:** Use a standard 2D texture synthesis algorithm to generate a new 2D texture image for the target cross-section, using the selected region as the reference patch [S1]. Common algorithms include those by Wei and Levoy (2000), Cohen et al. (2003), or Kwatra et al. (2003) [S1].
3.  **Render Cross-Section:** Use the synthesized 2D texture to render the cross-section of the 3D model at the specified location and orientation [S1].

**Formulas:**
Not applicable. The method relies on existing 2D synthesis algorithms [S1].

**Parameters:**
*   **Synthesis Algorithm:** Choice of 2D algorithm (e.g., Wei & Levoy 2000) [S1].
*   **Reference Region:** Size and content of the selected patch from the reference image [S1].
*   *Typical values are Not given in the sources.*

**Edge Cases and Pitfalls:**
*   **Inconsistency:** There is no guarantee of obtaining exactly the same image when a model is cut twice at the same cross-section [S1]. This is an accepted limitation because the goal is a volumetric impression rather than consistent volumetric data [S1].
*   **Performance:** Attempting to use full volumetric texture synthesis (e.g., specifying side/top faces and using Wei’s 2001 volumetric technique) is too slow and yields unsatisfactory quality [S1].

## Subtopics

### [Cross-section Texture Synthesis with Flow Vectors](13944-cross-section-texture-synthesis-with-flow-vectors.md)
Synthesizes internal textures using flow vectors to guide sampling, supporting layered and oriented textures. Choose this when orientation or depth-dependent appearance is required.

## Operating characteristics
*   **Time Complexity:** Fast, as it leverages efficient 2D texture synthesis algorithms [S1]. Significantly faster than full 3D volumetric synthesis [S1].
*   **Memory Complexity:** Low, as it does not store explicit 3D volumetric data [S1].
*   **Strengths:** Simple implementation; fast performance; suitable for materials with uniform internal structure (e.g., sponges, sausages) [S1].
*   **Limitations:** No guarantee of cross-section consistency; cannot handle orientation-dependent or depth-varying textures (layered/oriented) [S1].
*   **When to Use:** When creating volumetric impressions for isotropic materials where performance is critical and exact cross-section consistency is not required [S1].
*   **When Not to Use:** When the material has directional structure (oriented) or depth-dependent appearance (layered), or when consistent volumetric data is required [S1].

## Background
Originated in the context of volumetric illustration, where the goal is to convey a volumetric impression rather than generate precise volumetric data [S1]. The method was developed as a simpler and faster alternative to full volumetric texture synthesis techniques, which were found to be too slow and produced unsatisfactory quality [S1]. It builds on established 2D texture synthesis algorithms [S1].
