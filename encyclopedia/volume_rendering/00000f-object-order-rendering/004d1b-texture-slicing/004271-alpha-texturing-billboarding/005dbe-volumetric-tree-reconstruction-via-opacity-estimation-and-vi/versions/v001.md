# Volumetric Tree Reconstruction via Opacity Estimation and View-Dependent Texturing

Also called: Opacity Estimation and View-Dependent Texturing for Trees

## Overview
This method reconstructs and renders trees from a set of photographs by estimating isotropic discrete opacity values on a recursive grid and rendering using view-dependent billboards to preserve high-frequency color details [S1]. It solves the problem of rendering complex, high-frequency vegetation geometry efficiently by decoupling the low-frequency volumetric structure (opacity) from the high-frequency appearance (color) [S1]. Unlike its parent [Alpha Texturing (Billboarding)](10768-alpha-texturing-billboarding.md), which uses static RGBA textures, this method generates view-dependent textures for each volumetric cell to prevent the blurring artifacts caused by naive blending between multiple camera views [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of $N$ photographs ($N \approx 20-30$) of a tree against a distinct background [S1].
*   Camera calibration data for each photograph [S1].
*   Alpha masks for each photograph, extracted via alpha matting [S1].
*   "Pure foreground" color images $C_f$ derived from the alpha matting process [S1].

**Outputs:**
*   A recursive grid where each cell $i$ has an estimated opacity $\alpha_i$ (or transparency $t_i = 1 - \alpha_i$) [S1].
*   A set of billboard textures $T_{i,c}$ for each cell $c$ and each input image $i$, sized $M \times M$ [S1].

### Data Structures

**Grid Cell:**
*   `opacity` ($\alpha_i$): Float, opacity of the cell.
*   `transparency` ($t_i$): Float, $1 - \alpha_i$.
*   `delta_transparency` ($\delta t_i$): Float, accumulated update for the current iteration.
*   `weight` ($w$): Float, accumulated weight for normalization.

**Image Data:**
*   `alpha_image`: 2D array of floats, values in $[0, 1]$.
*   `pure_foreground`: 2D array of RGB values in LAB color space [S1].
*   `working_image`: A mutable copy of the RGBA image used during texture generation to track occluded pixels [S1].

### Parameters
*   **Number of photographs:** 20-30 [S1].
*   **Billboard texture size ($M$):** Typically 4 or 8 [S1].
*   **Convergence threshold:** Iteration stops when the change in $t_i$ values is less than a specified threshold [S1].
*   **Transparency cutoff threshold:** If $t_i$ exceeds this value, the cell is considered transparent ($t_i=1$) and ignored [S1].
*   **Typical iterations:** 3-4 iterations are sufficient for convergence [S1].

### Algorithm Steps

#### 1. Image Capture and Alpha Matting
1.  Photograph the tree against a distinct background (e.g., sky) from approximately 20-30 different viewpoints [S1].
2.  Calibrate the cameras using a standard algorithm (e.g., REALVIZ ImageModeler) [S1].
3.  For each photograph, extract an alpha mask $\alpha_p$ for each pixel $p$ using the Ruzon and Tomasi algorithm [S1]. This requires user-specified foreground and background zones [S1].
4.  Compute the "pure foreground" color $C_f$ for each pixel. For pixels with $\alpha_p \in (0, 1)$, the pixel color $C_p$ is modeled in LAB color space as:
    $$ C_p = \alpha_p C_f + (1 - \alpha_p) C_b $$
    where $C_b$ is the background color [S1]. Solve for $C_f$ and store it in the `pure_foreground` image. Pixels with $\alpha_p = 0$ or $1$ are handled accordingly (background or pure foreground) [S1].

#### 2. Reconstruction Initialization
1.  Initialize a recursive grid covering the tree volume.
2.  For each grid cell $i$, project it into each alpha-image.
3.  Calculate the average opacity value of the cell's projection in each image.
4.  Set the initial opacity $\alpha_i$ of the cell to the **minimum** of these average opacity values across all images. This corresponds to initializing transparency $t_i$ [S1].
5.  Initialize $\delta t_i = 0$ and $w = 0$ for all cells [S1].

#### 3. Reconstruction Iteration Loop
Iterate until convergence (change in $t_i < \text{threshold}$):

1.  Reset $\delta t_i = 0$ and $w = 0$ for all cells $i$ [S1].
2.  For each image $k$:
    a. For each pixel $p$ in the image:
        i. Cast a ray from the camera through the pixel into the grid.
        ii. Identify the list of intersected cells $i=0 \dots n$ (ordered front-to-back) [S1].
        iii. Construct the vector $Q = (q_0, q_1, \dots, q_n)$ where $q_i = \log(t_i)$ [S1].
        iv. Calculate the target log-transparency $q_p = \log(t_p)$, where $t_p = 1 - \alpha_p$ is the transparency of the pixel [S1].
        v. Project the vector $Q$ onto the plane $P$ defined by normal $N = (1, 1, \dots, 1)$ and intercept $q_p$. The projection $Q' = (q'_0, q'_1, \dots, q'_n)$ minimizes the distance to the plane [S1].
        vi. For each cell $i$ in the ray:
            *   Calculate the update component: $\delta q_i = q'_i - q_i$ [S1].
            *   Convert back to transparency domain. The source defines the update to transparency $\delta t_i$ based on the projection. Specifically, the source states: $\delta_i = w_i (t'_i - t_i)$ where $t'_i$ is derived from $q'_i$. Note: The source pseudocode uses $\delta_i = w_i (t'_i - t_i)$ directly after projection, implying $t'_i = \exp(q'_i)$ [S1].
            *   Accumulate the update: $\delta t_i \leftarrow \delta t_i + \delta_i$ [S1].
            *   Accumulate weight: $w \leftarrow w + w_i$ [S1]. (Note: The source pseudocode implies $w_i$ is a weight associated with the cell/pixel contribution, though the exact definition of $w_i$ is not explicitly detailed beyond its use in the update formula. In the absence of a specific weight function, $w_i$ is treated as a scalar weight for the contribution of cell $i$ to pixel $p$ [S1]).
3.  After processing all pixels in all images, update the transparency values for each cell $i$:
    $$ t_i \leftarrow t_i + \frac{\delta t_i}{w} $$
    If $t_i > \text{transparency cutoff threshold}$, set $t_i = 1$ (transparent) and mark the cell as ignored [S1].

#### 4. Texture Generation and Rendering
1.  For each cell $c$ and each image $i$:
    a. Create an $M \times M$ billboard texture $T_{i,c}$ [S1].
    b. Project the cell $c$ onto the image plane of image $i$.
    c. Extract the corresponding region from the `pure_foreground` image $C_f$ [S1].
    d. **Heuristic for Occlusion Handling:** To avoid double-counting and blurring:
        i. Make a copy $C_i$ of the current state of the image (initially the `pure_foreground` image) [S1].
        ii. Process cells in a specific order (e.g., front-to-back relative to the camera) [S1].
        iii. For the current cell, mask out only the texels corresponding to the cell's projection.
        iv. Assign these masked texels to the billboard texture $T_{i,c}$ [S1].
        v. Update the copy $C_i$: remove the texels just assigned (set to background or transparent) to ensure subsequent cells do not use the same pixels [S1].
2.  **Rendering:**
    a. For each view, sort the billboards back-to-front.
    b. For each billboard, render the texture $T_{i,c}$ (where $i$ is the closest or most appropriate camera view, or blended if necessary, though the method prefers single-view textures per cell to avoid blurring) [S1].
    c. Use the estimated opacity $\alpha_c$ of the cell as the alpha value for the billboard [S1].

### Pseudocode

def reconstruct_tree(photos, camera_calibrations, alpha_masks, pure_foreground_images):
    """
    Reconstructs tree opacity and generates billboards.
    """
    # 1. Initialization
    grid = initialize_recursive_grid()
    
    # Initialize opacities based on minimum average alpha from all views
    for cell in grid:
        alphas = []
        for photo_idx, alpha_mask in enumerate(alpha_masks):
            projected_alpha = project_cell_to_image(cell, camera_calibrations[photo_idx], alpha_mask)
            alphas.append(mean(projected_alpha))
        cell.opacity = min(alphas)
        cell.transparency = 1.0 - cell.opacity
        cell.delta_transparency = 0.0
        cell.weight = 0.0

    # 2. Iteration Loop
    while not converged(grid):
        # Reset accumulators
        for cell in grid:
            cell.delta_transparency = 0.0
            cell.weight = 0.0

        # Process each image and pixel
        for photo_idx, alpha_mask in enumerate(alpha_masks):
            for pixel in alpha_mask:
                ray = cast_ray_through_grid(pixel, camera_calibrations[photo_idx])
                hit_cells = ray.intersected_cells # Ordered front-to-back
                
                if not hit_cells:
                    continue

                # Vector Q of log-transparencies
                Q = [log(cell.transparency) for cell in hit_cells]
                target_transparency = 1.0 - pixel.alpha
                target_log_t = log(target_transparency)
                
                # Project Q onto plane P (normal N=(1,1,...,1), intercept target_log_t)
                # The projection Q' minimizes distance to the plane sum(q_i) = target_log_t
                # In the source, this is described as a direct projection.
                # A standard projection of vector Q onto a hyperplane with normal N and intercept d:
                # Q' = Q - ((N . Q - d) / (N . N)) * N
                N = [1.0] * len(hit_cells)
                dot_N_Q = sum(Q)
                dot_N_N = len(N)
                factor = (dot_N_Q - target_log_t) / dot_N_N
                
                Q_prime = [Q[i] - factor * N[i] for i in range(len(N))]
                
                # Calculate updates
                for idx, cell in enumerate(hit_cells):
                    t_prime = exp(Q_prime[idx])
                    t_current = cell.transparency
                    
                    # Weight w_i is not explicitly defined in sources, assumed to be 1 or normalized later
                    # Source pseudocode: delta_i = w_i * (t'_i - t_i)
                    # Assuming uniform weight for simplicity as per "w += w_i" accumulation
                    w_i = 1.0 
                    delta_t = w_i * (t_prime - t_current)
                    
                    cell.delta_transparency += delta_t
                    cell.weight += w_i

        # Update grid transparencies
        for cell in grid:
            if cell.weight > 0:
                cell.transparency += cell.delta_transparency / cell.weight
            
            # Transparency cutoff
            if cell.transparency > TRANSPARENCY_CUTOFF_THRESHOLD:
                cell.transparency = 1.0
                cell.opacity = 0.0

    # 3. Texture Generation
    billboards = {}
    
    # Sort cells for texture extraction (e.g., front-to-back per view or global order)
    # The source implies processing cells to mask out used pixels in a working image copy
    for photo_idx, pure_fg_img in enumerate(pure_foreground_images):
        working_image = copy(pure_fg_img)
        
        # Iterate through cells. Order matters for the "remove front texels" heuristic.
        # Assuming a global order or sorted by depth from this camera.
        for cell in grid:
            if cell.opacity == 0:
                continue
                
            # Project cell to image
            projected_region = project_cell_to_image_region(cell, camera_calibrations[photo_idx])
            
            # Extract texture from working_image
            # Mask out only the part corresponding to this cell
            texture = extract_texture(working_image, projected_region)
            
            # Store billboard
            billboards[(cell.id, photo_idx)] = texture
            
            # Update working_image: remove texels corresponding to this cell
            # to avoid double counting for subsequent cells
            update_working_image(working_image, projected_region, is_opaque=False)

    return grid, billboards

## Operating characteristics

**Time Complexity:**
*   The reconstruction involves an iterative loop. Each iteration processes all pixels in all images. For each pixel, a ray cast and a projection onto an $n$-dimensional plane (where $n$ is the number of cells intersected by the ray) are performed.
*   The projection step is $O(n)$ per pixel.
*   Total time per iteration is $O(P \cdot n_{avg})$, where $P$ is the total number of pixels and $n_{avg}$ is the average number of cells per ray.
*   Convergence is typically reached in 3-4 iterations [S1].

**Memory Complexity:**
*   Grid storage: $O(C)$, where $C$ is the number of cells.
*   Texture storage: $O(C \cdot N \cdot M^2)$, where $N$ is the number of images and $M$ is the billboard texture size (typically 4 or 8) [S1].

**Measured Performance:**
*   Processing time: 3-5 minutes on a Pentium IV 2.7 GHz PC for the tested models [S1].
*   Calibration time: Less than 10 minutes for about 20 images using markers [S1].

**Strengths:**
*   Preserves high-frequency color details from the original photographs [S1].
*   Avoids the severe blurring artifacts associated with naive view-dependent texturing (blending between $n$ closest cameras) [S1].
*   Efficient rendering using simple billboards [S1].

**Limitations:**
*   Requires a distinct background for alpha matting [S1].
*   Assumes isotropic opacity, which may not capture all anisotropic properties of foliage [S1].
*   The method is under-constrained; it finds a "best-fit" solution which may tend towards a local minimum [S1].
*   Texture generation requires careful handling of occlusion (front-to-back processing) to avoid double-counting [S1].

## Background

**Origin:**
The method was introduced in the paper "Volumetric reconstruction and interactive rendering of trees from photographs" [S1].

**History and Development:**
The approach builds upon the concept of alpha texturing (billboarding) [10768-alpha-texturing-billboarding.md] but addresses its limitations regarding view-dependent color. It utilizes alpha matting techniques (Ruzon and Tomasi [S1]) and volume rendering equations (Max [S1]) to estimate opacity. The logarithmic transformation of the transparency product into a sum allows for efficient linear projection-based optimization [S1].

**Applications:**
Primarily used for the realistic rendering of trees and vegetation in computer graphics, particularly in urban environments where trees can be photographed against a sky background [S1].
