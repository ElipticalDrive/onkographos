# Space Repetition

Also called: Infinite Domain Repetition, Infinite Repetition, Modular Repetition, Modulo Tiling, Primitive Repetition, Tiling via Modulo, repeat2d

## Overview
Space Repetition is a technique to create infinite repetitions of a primitive (such as a rounded box or sphere) across 3D space by mapping the input position into a periodic cell using modulo arithmetic, then computing the distance to the primitive within that cell [S2, unofficial]. Unlike primitive blending which smoothly interpolates between shapes, Space Repetition creates hard, periodic boundaries via modulo arithmetic, allowing infinite instances of a shape without increasing geometric complexity [S2, unofficial]. It is a specific instance of Domain Repetition applied to Cartesian coordinates.

## How it works
**Inputs:**
- $P$: The query position in world space (vector).
- $C$: The repetition cell size (vector), defining the period in each dimension.

**Outputs:**
- $d$: The signed distance to the nearest instance of the base primitive.

**Data Structures:**
- None required beyond standard vector types.

**Steps:**
1.  **Map to Periodic Cell:** Transform the input position $P$ into the fundamental domain (the cell containing the origin) using modulo arithmetic. The standard formula maps $P$ to the range $[-C/2, C/2)$ centered at the origin:
    $$ Q = P - C \cdot \text{round}\left(\frac{P}{C}\right) $$
    Alternatively, using a modulo operator that returns values in $[0, C)$, the centering step is explicit:
    $$ Q = \text{mod}(P, C) - 0.5 \cdot C $$
    Where $\text{mod}(a, b) = a - b \cdot \lfloor a/b \rfloor$ [S2, S4, unofficial].

2.  **Query Base SDF:** Compute the signed distance to the base primitive using the transformed position $Q$.
    $$ d = \text{SDF}_{\text{base}}(Q) $$

**Parameters:**
- $C$: The repetition cell size. For uniform spacing, $C = (c, c, c)$. A typical value is $\text{vec3}(8.0, 8.0, 8.0)$ [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** Near the boundaries of the cells ($P \approx k \cdot C$), floating-point precision errors in the modulo operation can cause artifacts or incorrect distance calculations. The `round`-based formula is generally more stable than `mod` followed by subtraction if the language's `mod` function has discontinuities [S4, unofficial].
- **Boundary Continuity:** The distance function is continuous across cell boundaries because the base primitive's distance is evaluated at the same relative position in every cell. However, the gradient may be discontinuous if the base primitive has sharp features aligned with the cell boundaries.
- **Negative Coordinates:** The formula $P - C \cdot \text{round}(P/C)$ handles negative coordinates correctly, centering the cell around the origin. Simple `mod` implementations often return positive values only, requiring the explicit $-0.5 \cdot C$ shift [S2, unofficial].

**Pseudocode:**
```python
def space_repetition(p: Vector3, c: Vector3, base_sdf: Callable[[Vector3], float]) -> float:
    """
    Repeats the base_sdf infinitely in 3D space with period c.
    
    Args:
        p: Query position.
        c: Repetition cell size (vector).
        base_sdf: Signed distance function for the primitive to repeat.
        
    Returns:
        Signed distance to the nearest repeated primitive.
    """
    # Map p to the fundamental domain centered at origin
    # Formula: q = p - c * round(p / c)
    # Note: round() rounds to nearest integer. 
    # In languages without vectorized round, apply component-wise.
    q = p - c * round(p / c)
    
    # Query the base primitive at the wrapped position
    return base_sdf(q)
```

## Operating characteristics
- **Time Complexity:** $O(1)$ per query, identical to the base primitive. The modulo operation is a constant-time arithmetic operation.
- **Memory Complexity:** $O(1)$. No additional data structures are stored.
- **Strengths:** Infinite instances with zero memory overhead. Ideal for floors, walls, or abstract patterns where geometry is repetitive.
- **Limitations:** Only supports uniform, axis-aligned grid repetition. Cannot handle non-uniform scaling or rotation of the repetition grid without additional transformations. Artifacts may appear if the base primitive is not symmetric or if the cell size is not a multiple of the primitive's extent.
- **When to use:** When rendering infinite grids of identical objects (e.g., a tiled floor, a field of spheres).
- **When not to use:** When objects need to interact with each other (e.g., collision between adjacent instances) or when the repetition pattern is non-uniform.

## Background
Space Repetition is a staple technique in Signed Distance Field (SDF) raymarching, popularized by tutorials on GPU raymarching and distance functions. It is often referred to as "cheating" because it allows the rendering of infinite geometry without increasing the scene's geometric complexity [S5, unofficial]. The technique relies on the periodicity of the modulo operator to fold space.
