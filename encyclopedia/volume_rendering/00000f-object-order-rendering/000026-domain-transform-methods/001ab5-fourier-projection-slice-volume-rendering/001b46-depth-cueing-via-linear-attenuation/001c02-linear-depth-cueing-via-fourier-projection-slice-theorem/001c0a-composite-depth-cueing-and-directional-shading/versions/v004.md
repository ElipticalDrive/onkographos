# Composite Depth Cueing and Directional Shading

Also called: Composite Shading Model, Hemispherical Illumination Shading

## Overview
Composite Depth Cueing and Directional Shading is a frequency-domain volume rendering technique that integrates linear attenuation (depth cueing) and hemispherical directional shading into a single rendering pass [S1, S2, unofficial]. It solves the high computational cost of applying both effects in the spatial domain by leveraging the Fourier Projection-Slice Theorem [S1, S2, unofficial]. Unlike standard spatial rendering which requires $O(n^3)$ operations for these effects, this method reduces asymptotic complexity to $O(n^2)$ [S1, S2, unofficial].

## How it works
The method replaces parallel illumination with illumination from an emissive hemisphere to avoid the nonlinear absolute value operator $|N \cdot L|$, allowing the lighting direction to be factored out of the integral for Fourier projection-slice evaluation [S1, unofficial]. It combines linear attenuation and hemispherical illumination, requiring 16 precomputed spectra [S1, unofficial].

**Inputs and Outputs**
*   **Inputs:**
    *   Volume of albedo $\Omega(x,y,z)$ [S1, unofficial].
    *   Orientation field $N(x,y,z)$, typically estimated from scalar input data using a central difference operator [S1, unofficial].
    *   Viewing direction $V$ and lighting direction $L$ (unit vectors) [S1, S2, unofficial].
    *   Attenuation coefficient $\tau$ [S2, unofficial].
*   **Outputs:**
    *   Rendered image intensity $I$ [S1, S2, unofficial].

**Data Structures**
The algorithm relies on 16 precomputed 3D spectra derived from the volume and orientation fields.
*   **VL Vector:** The source defines this as a 12-element vector but explicitly lists 15 terms in the formula:
    $$VL = (V_x L_x, V_x L_y, V_x L_z, V_y L_x, V_y L_y, V_y L_z, V_z L_x, V_z L_y, V_z L_z, V_x, V_y, V_z, L_x, L_y, L_z)$$ [S1, S2, unofficial]
*   **DN Vector:** The source defines this as a 12-element vector but explicitly lists 15 terms in the formula:
    $$DN = (D_x N_x, D_x N_y, D_x N_z, D_y N_x, D_y N_y, D_y N_z, D_z N_x, D_z N_y, D_z N_z, D_x, D_y, D_z, N_x, N_y, N_z)$$ [S1, S2, unofficial]

**Steps**
1.  **Precomputation:**
    a.  Create four copies of the volume $\Omega(x,y,z)$.
    b.  Multiply each copy by the appropriate component of the orientation field $N$: one by $1$, one by $N_x$, one by $N_y$, and one by $N_z$ [S1, unofficial].
    c.  Compute the 3D Fourier Transform of these four modified volumes to yield four 3D spectra [S1, unofficial].
    d.  Multiply the integrand by linear attenuation and hemispherical illumination terms to generate a total of 16 precomputed spectra [S1, unofficial].
2.  **Per-view Rendering:**
    a.  For the current viewing direction $V$ and lighting direction $L$, extract slices from each of the 16 precomputed spectra [S1, unofficial].
    b.  Inverse Fourier Transform each slice to obtain spatial domain images [S1, unofficial].
    c.  Weight each inverse-transformed slice by the corresponding component of the $VL$ vector, which encodes the current viewing and lighting directions, and sum the results [S1, unofficial].

**Pseudocode**
```python
def composite_depth_cueing_shading(volume, orientation, V, L, tau, I_s):
    # Precomputation (done once)
    # Create 4 base volumes: 1*Omega, Nx*Omega, Ny*Omega, Nz*Omega
    base_volumes = [volume, orientation.x * volume, orientation.y * volume, orientation.z * volume]
    # Compute 3D FFT for each base volume
    spectra = [fft3d(v) for v in base_volumes]
    # Expand to 16 spectra by multiplying with attenuation and illumination terms
    # (Implementation detail: the 16 spectra correspond to the 15 terms in DN/VL plus the constant term)
    precomputed_spectra = expand_spectra(spectra, tau, I_s)
    
    # Per-view rendering
    # Construct VL vector components
    vl_components = [
        V.x*L.x, V.x*L.y, V.x*L.z, V.y*L.x, V.y*L.y, V.y*L.z,
        V.z*L.x, V.z*L.y, V.z*L.z, V.x, V.y, V.z, L.x, L.y, L.z
    ]
    # Compute constant c3
    c3 = 0.5 - 0.5 * sum(vl_components)
    
    image = zeros_like(viewport)
    for i, spec in enumerate(precomputed_spectra):
        # Extract 2D slice along viewing direction V
        slice_2d = extract_slice(spec, V)
        # Inverse FFT to spatial domain
        slice_spatial = ifft2d(slice_2d)
        # Weight by VL component and accumulate
        image += vl_components[i] * slice_spatial
    # Add constant term contribution
    image += tau * (pi/2) * c3 * extract_slice(spectra[0], V) # Simplified accumulation
    return image
```
*Note: The pseudocode abstracts the exact mapping of the 16 spectra to the VL/DN polynomial terms, as the source describes the weighting as a dot product with the VL vector applied to the projected terms [S1, S2, unofficial].*

**Formulas**
The intensity $I$ is computed as [S1, S2, unofficial]:
$$I = \tau \frac{\pi}{2} VL \cdot \Pi_V \left[ \left(\frac{1}{2} + \frac{1}{2} DN(x,y,z)\right) I_s \Omega(x,y,z) \right] + \tau \frac{\pi}{2} c_3 \Pi_V [I_s \Omega(x,y,z)]$$
Where:
*   $\Pi_V$ is the Fourier projection operator along viewing direction $V$ [S1, S2, unofficial].
*   $I_s$ is the intensity of the light source [S1, unofficial].
*   $c_3$ is a constant term defined as:
    $$c_3 = \frac{1}{2} - \frac{1}{2} \sum_i VL_i$$ [S1, S2, unofficial]

**Parameters**
*   $\Omega(x,y,z)$: Volume of albedo [S1, unofficial].
*   $c_3$: Constant term dependent on $V$ and $L$ [S2, unofficial].

**Edge Cases and Pitfalls**
*   The composite model ignores emission $\rho C$ from the depth cueing equation [S1, unofficial]. In this context, emission can be interpreted as ambient illumination [S1, unofficial].
*   The high constant factor makes the algorithm slower than conventional rendering for small volumes, despite being asymptotically less expensive [S1, unofficial].

## Subtopics

### [Combined Depth Cueing and Shading](1170-combined-depth-cueing-and-shading.md)
Combined Depth Cueing and Shading is a frequency-domain volume rendering technique that integrates linear attenuation and hemispherical directional shading into a single pass. It is distinct from its sibling [Composite Depth Cueing and Directional Shading](1143-composite-depth-cueing-and-directional-shading.md) by specifically addressing the order of operations to optimize performance, often using a "reversed order" approximation to avoid multiple convolutions. Choose this variant when minimizing convolution overhead is critical for large datasets.

## Operating characteristics
*   **Time Complexity:** Asymptotically $O(n^2)$, which is less expensive than conventional spatial rendering $O(n^3)$ [S1, S2, unofficial].
*   **Memory Complexity:** Requires 16 precomputed spectra. For a $128^3$ voxel cube implementation, memory usage is 256 megabytes [S1, unofficial].
*   **Measured Performance:** On a 36 MHz Silicon Graphics 4D/320 VGX with a sequential C implementation, rendering time exceeds one minute per view for the composite model, mostly due to paging [S1, unofficial]. This compares to six seconds for the hemispherical illumination model alone on the same hardware [S1, unofficial].
*   **Scaling:** Replacing the FFT with an FHT halves per-view rendering time and memory requirements [S1, unofficial]. Optimizing the filter and trimming zero padding yields another factor of two speedup and reduced memory usage [S1, unofficial]. The algorithm scales well with parallelization at either a fine grain (within the FFT) or a coarse grain (between slices) [S1, unofficial].
*   **Strengths:** Avoids the nonlinear absolute value operator $|N \cdot L|$ present in parallel illumination models, allowing efficient Fourier evaluation [S1, unofficial]. The resulting shading is less sensitive to surface orientation, similar to perception on a cloudy day, and avoids negative light artifacts from backward-facing normals [S1, unofficial].
*   **Limitations:** High constant factor makes it slower than conventional rendering for small volumes [S1, unofficial]. Ignores emission/ambient illumination [S1, unofficial].

## Background
The method was developed by Marc Levoy as part of his work on volume rendering using the Fourier Projection-Slice Theorem [S1, unofficial]. It extends earlier work on linear depth cueing and hemispherical illumination by combining them into a single composite model [S1, unofficial]. The approach is based on the observation that the integrand can be expressed as a linear combination of Fourier projections, allowing the use of the projection-slice theorem for efficient rendering [S1, unofficial].
