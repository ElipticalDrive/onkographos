# Bilinear Interpolation in Fourier Space

Also called: F RBiLin

## Overview
Bilinear Interpolation in Fourier Space (F RBiLin) is a method to reconstruct a Cartesian Fourier grid from polar samples by interpolating the four nearest polar points surrounding a target pixel [S1, unofficial]. It solves the problem of mapping frequency domain data, acquired in polar coordinates (typically from projection slices), onto a regular Cartesian grid required for the Inverse Fast Fourier Transform (IFFT) [S1, unofficial]. It sets itself apart from nearest-neighbor approaches by using weighted averaging based on Euclidean distance, and from Radial-Angular variants by using Cartesian Euclidean distance rather than arc/radial distance [S1, unofficial].

## How it works
**Inputs:**
- A polar grid of Fourier coefficients $R_{\theta}(\rho)$, where $\theta$ represents the angle and $\rho$ the radial frequency.
- The target Cartesian grid dimensions and spacing.

**Outputs:**
- A reconstructed Cartesian Fourier grid $F_{2D}(i, j)$.

**Data Structures:**
- Polar grid: Array or map indexed by $(\theta_t, \rho_r)$.
- Cartesian grid: 2D array indexed by $(i, j)$.

**Parameters:**
- $x_v$: Interpolation interval size along the x-axis.
- $y_v$: Interpolation interval size along the y-axis.

**Steps:**
1. Iterate over every target pixel $(i, j)$ in the Cartesian grid.
2. Convert the pixel coordinates $(i, j)$ to polar coordinates $(\theta, \rho)$:
   $$ \theta = \arctan\left(\frac{j}{i}\right) $$
   $$ \rho = \sqrt{i^2 + j^2} $$
   [G] Handle the case where $i=0$ to avoid division by zero (e.g., $\theta = \pi/2$ or $-\pi/2$).
3. Identify the bounding polar grid indices $t$ and $r$ such that $\theta_t \le \theta \le \theta_{t+1}$ and $\rho_r \le \rho \le \rho_{r+1}$.
4. Extract the four nearest polar points: $(\theta_t, \rho_r)$, $(\theta_{t+1}, \rho_r)$, $(\theta_t, \rho_{r+1})$, and $(\theta_{t+1}, \rho_{r+1})$.
5. Calculate the interpolation coefficients $\alpha$ for each of the four points. The coefficients are inversely proportional to the Euclidean distance between the target pixel and the polar point in Cartesian space.
   First, compute the interval sizes $x_v$ and $y_v$:
   $$ x_v = \max\{\rho_{r_0} \cos \theta_{t_0}\} - \min\{\rho_{r_0} \cos \theta_{t_0}\} $$
   $$ y_v = \max\{\rho_{r_0} \sin \theta_{t_0}\} - \min\{\rho_{r_0} \sin \theta_{t_0}\} $$
   Then, for a point $(\theta_k, \rho_l)$, the coefficient $\alpha_{k,l}$ is:
   $$ \alpha_{k,l} = |x_v - |\rho_l \cos \theta_k - \rho \cos \theta|| \times |y_v - |\rho_l \sin \theta_k - \rho \sin \theta|| $$
   [G] Note: The source formula uses absolute differences of the Cartesian coordinates derived from polar coordinates. The term $|x_v - \dots|$ suggests a specific weighting scheme where the weight is related to the remaining interval space or distance metric defined in the source.
6. Compute the value $F_{2D}(i, j)$ using the weighted average:
   $$ F_{2D}(i, j) = \frac{\alpha_{t,r} R_{\theta_t}(\rho_r) + \alpha_{t+1,r} R_{\theta_{t+1}}(\rho_r) + \alpha_{t,r+1} R_{\theta_t}(\rho_{r+1}) + \alpha_{t+1,r+1} R_{\theta_{t+1}}(\rho_{r+1})}{\alpha_{t,r} + \alpha_{t+1,r} + \alpha_{t,r+1} + \alpha_{t+1,r+1}} $$
7. Repeat for all pixels.

**Pseudocode:**
```python
def bilinear_interpolation_fourier_space(polar_grid, target_width, target_height):
    # polar_grid is a structure allowing lookup by (theta, rho)
    # Returns cartesian_grid of shape (target_height, target_width)
    
    # Precompute interval sizes if not constant
    # Note: In many implementations, x_v and y_v are derived from the grid resolution.
    # The source defines them as the range of the projected coordinates.
    # For a regular polar grid, these might be constant or pre-calculated.
    
    # Determine bounds for x_v and y_v from the polar grid data
    # This assumes polar_grid contains all (theta, rho) pairs
    cos_vals = [rho * cos(theta) for theta, rho in polar_grid.keys()]
    sin_vals = [rho * sin(theta) for theta, rho in polar_grid.keys()]
    
    x_v = max(cos_vals) - min(cos_vals)
    y_v = max(sin_vals) - min(sin_vals)
    
    cartesian_grid = zeros((target_height, target_width))
    
    for j in range(target_height):
        for i in range(target_width):
            # 1. Convert to polar
            theta = atan2(j, i)
            rho = sqrt(i**2 + j**2)
            
            # 2. Find bounding indices
            # Assuming polar_grid has sorted unique thetas and rhos
            theta_indices = sorted(list(set(theta for theta, rho in polar_grid.keys())))
            rho_indices = sorted(list(set(rho for theta, rho in polar_grid.keys())))
            
            # Find t such that theta_t <= theta <= theta_{t+1}
            t = find_index(theta_indices, theta)
            r = find_index(rho_indices, rho)
            
            if t is None or r is None:
                # Pixel is outside the polar grid coverage
                cartesian_grid[j, i] = 0
                continue
                
            theta_t = theta_indices[t]
            theta_t1 = theta_indices[t+1]
            rho_r = rho_indices[r]
            rho_r1 = rho_indices[r+1]
            
            # 3. Get values
            val_tr = polar_grid.get((theta_t, rho_r), 0)
            val_t1r = polar_grid.get((theta_t1, rho_r), 0)
            val_tr1 = polar_grid.get((theta_t, rho_r1), 0)
            val_t1r1 = polar_grid.get((theta_t1, rho_r1), 0)
            
            # 4. Calculate coefficients
            # Cartesian coordinates of the polar points
            cx_tr = rho_r * cos(theta_t)
            cy_tr = rho_r * sin(theta_t)
            
            cx_t1r = rho_r * cos(theta_t1)
            cy_t1r = rho_r * sin(theta_t1)
            
            cx_tr1 = rho_r1 * cos(theta_t)
            cy_tr1 = rho_r1 * sin(theta_t)
            
            cx_t1r1 = rho_r1 * cos(theta_t1)
            cy_t1r1 = rho_r1 * sin(theta_t1)
            
            # Target Cartesian coordinates
            cx_target = rho * cos(theta)
            cy_target = rho * sin(theta)
            
            # Calculate alpha coefficients
            # alpha = |x_v - |x_point - x_target|| * |y_v - |y_point - y_target||
            alpha_tr = abs(x_v - abs(cx_tr - cx_target)) * abs(y_v - abs(cy_tr - cy_target))
            alpha_t1r = abs(x_v - abs(cx_t1r - cx_target)) * abs(y_v - abs(cy_t1r - cy_target))
            alpha_tr1 = abs(x_v - abs(cx_tr1 - cx_target)) * abs(y_v - abs(cy_tr1 - cy_target))
            alpha_t1r1 = abs(x_v - abs(cx_t1r1 - cx_target)) * abs(y_v - abs(cy_t1r1 - cy_target))
            
            # 5. Weighted average
            total_alpha = alpha_tr + alpha_t1r + alpha_tr1 + alpha_t1r1
            
            if total_alpha == 0:
                cartesian_grid[j, i] = 0
            else:
                cartesian_grid[j, i] = (
                    alpha_tr * val_tr +
                    alpha_t1r * val_t1r +
                    alpha_tr1 * val_tr1 +
                    alpha_t1r1 * val_t1r1
                ) / total_alpha
                
    return cartesian_grid

def find_index(sorted_list, value):
    # Returns the index i such that sorted_list[i] <= value < sorted_list[i+1]
    # If value is exactly the last element, return len-2 (assuming we need a pair)
    # If value is outside, return None
    for i in range(len(sorted_list) - 1):
        if sorted_list[i] <= value <= sorted_list[i+1]:
            return i
    return None
```

**Edge Cases and Pitfalls:**
- **Excess Points:** If a pixel's geometric area contains more than four polar points, only the four nearest bounding points are used; excess points are ignored [S1, unofficial].
- **Border Pixels:** Points used to reconstruct border pixels may lie outside the pixel's geometric area [S1, unofficial].
- **Uncovered Areas:** Pixels may remain uncovered if the polar grid does not extend to the Cartesian grid edges [S1, unofficial].

## Subtopics

### Fourier Reconstruction
A general method that reconstructs an image from the frequency spaces of projections by interpolating a polar grid into a Cartesian frequency grid, followed by an Inverse FFT [S1, unofficial]. It iterates over all points $(\theta_i, \rho_i)$ in the projection frequency space, searches for the nearest Cartesian pixel $(i,j)$, and applies FFT [S1, unofficial]. The complexity is $O(N)$ for reconstruction and $O(N \log N)$ globally with FFT [S1, unofficial]. Pitfalls include residual false contours and loss of high frequencies if the polar grid does not cover Cartesian edges [S1, unofficial].

### Radial-Angular Bilinear Interpolation
A variant of bilinear interpolation (noted as F RBiRA) that accounts for angular distance along the arc and radial distance, rather than Euclidean distance [S1, unofficial]. The coefficient $\alpha^\circ_{t,r}$ is calculated as:
$$ \alpha^\circ_{t,r} = |d_\theta - |\theta_t - \theta|| \times |d_\rho - |\rho_r - \rho|| $$
where $d_\theta$ and $d_\rho$ are scaling factors for angular and radial distances respectively [S1, unofficial].

## Operating characteristics
- **Time Complexity:** The reconstruction of the Cartesian grid is $O(N)$, where $N$ is the number of pixels/projections. The global complexity remains dominated by the FFT, $O(N \log N)$ [S1, unofficial].
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Preserves details better than low-pass filtering methods; all regions are visible and contours are net [S1, unofficial].
- **Limitations:** Creates residual false contours due to discretization approximations [S1, unofficial]. Interpolation irregularity depends on the number of projections and image size; increasing image size with constant radial resolution $d_\rho$ increases the uncovered area in the polar-to-Cartesian mapping [S1, unofficial]. Always uses exactly four points, potentially ignoring available information [S1, unofficial].

## Background
Originated in the context of tomographic reconstruction, specifically utilizing the Central Slice Theorem [S1, unofficial]. The method addresses the discretization of the theorem where polar grid points are not exactly located at the center of Cartesian pixels [S1, unofficial]. It is used in direct reconstruction methods for computed tomography [S1, unofficial].
