# Fourier Transform
Also called: Discrete Fourier Transform

## Overview
The Fourier Transform method converts a 3D scalar volume into the frequency domain to enable efficient global operations, such as convolution or projection, by exploiting the Convolution Theorem [S2, unofficial]. It is distinguished from spatial-domain methods by its ability to perform global filtering in $O(N^3 \log N)$ time, but it lacks spatial localization, making it unsuitable for interactive non-linear transfer functions or local shading [S1, unofficial].

## How it works
The method implements the Discrete Fourier Transform (DFT) on sampled volume data.

**Inputs and Outputs:**
*   **Input:** A discrete 1D, 2D, or 3D signal $h$ consisting of $N$ samples (or $N_x \times N_y \times N_z$ for 3D).
*   **Output:** The frequency domain representation $H$, a complex-valued array of the same dimensions.

**Data Structures:**
*   **Input Array $h$:** Real-valued floating-point array. Indices $k$ (1D), $(x,y)$ (2D), or $(x,y,z)$ (3D) range from $0$ to $N-1$ (or respective dimensions).
*   **Output Array $H$:** Complex-valued array. Stores frequency components. Due to Hermitian symmetry for real input, only half the spectrum is strictly necessary for reconstruction, but full storage is standard for FFT libraries [S2, unofficial].

**Parameters:**
*   $N$: Number of samples. Assumed even for standard frequency point derivation [S2, unofficial].
*   $\Delta$: Sampling interval (spatial or temporal distance between consecutive samples) [S2, unofficial].
*   $f_c$: Nyquist critical frequency, $1/(2\Delta)$ [S2, unofficial].

**Mathematical Formulas:**
The 1D DFT is defined as [S2, unofficial]:
$$ H_n = \sum_{k=0}^{N-1} h_k e^{2\pi i k n / N} $$
where $n = 0, \dots, N-1$. The continuous Fourier transform $H(f_n)$ is approximated by $\Delta H_n$, where the frequency points are $f_n = \frac{n}{N\Delta}$ [S2, unofficial]. The DFT is periodic with period $N$, such that $H_{-n} = H_{N-n}$ [S2, unofficial].

For a real-valued signal, the DFT is Hermitian: $H_{N-n}^* = H_n$ [S2, unofficial].

**Centered DFT (Preprocessing Step):**
To center the zero-frequency component in the middle of the spectrum (avoiding boundary discontinuities in visualization), multiply the input signal by $(-1)^k$ (1D) or $(-1)^{x+y}$ (2D) before computing the DFT [S2, unofficial].

**Pseudocode:**
```python
import math
import cmath

def compute_dft_1d(h):
    """
    Computes the 1D Discrete Fourier Transform of a real-valued sequence h.
    h: list of floats, length N.
    Returns: list of complex numbers, length N.
    """
    N = len(h)
    H = []
    for n in range(N):
        sum_val = 0 + 0j
        for k in range(N):
            # Exponent term: 2 * pi * i * k * n / N
            exponent = 2 * math.pi * 1j * k * n / N
            sum_val += h[k] * cmath.exp(exponent)
        H.append(sum_val)
    return H

def center_spectrum_1d(h):
    """
    Shifts the zero-frequency component to the center of the spectrum.
    h: list of floats, length N.
    Returns: list of floats, length N (pre-multiplied signal).
    """
    N = len(h)
    shifted_h = []
    for k in range(N):
        # Multiply by (-1)^k
        factor = (-1) ** k
        shifted_h.append(h[k] * factor)
    return shifted_h

def compute_dft_2d(h):
    """
    Computes the 2D DFT of a real-valued matrix h of size M x N.
    h: list of lists of floats.
    Returns: list of lists of complex numbers.
    """
    M = len(h)
    N = len(h[0])
    H = [[0 + 0j for _ in range(N)] for _ in range(M)]
    for u in range(M):
        for v in range(N):
            sum_val = 0 + 0j
            for x in range(M):
                for y in range(N):
                    exponent = 2 * math.pi * 1j * (x * u / M + y * v / N)
                    sum_val += h[x][y] * cmath.exp(exponent)
            H[u][v] = sum_val
    return H

def center_spectrum_2d(h):
    """
    Shifts the zero-frequency component to the center of the 2D spectrum.
    h: list of lists of floats, size M x N.
    Returns: list of lists of floats.
    """
    M = len(h)
    N = len(h[0])
    shifted_h = [[0.0 for _ in range(N)] for _ in range(M)]
    for x in range(M):
        for y in range(N):
            factor = (-1) ** (x + y)
            shifted_h[x][y] = h[x][y] * factor
    return shifted_h
```

**Edge Cases and Pitfalls:**
*   **Aliasing:** If the signal contains frequencies higher than the Nyquist critical frequency $f_c = 1/(2\Delta)$, aliasing occurs, moving power from outside $-f_c < f < f_c$ into the observable range [S2, unofficial].
*   **Periodicity Assumption:** The DFT assumes the signal is periodic. Discontinuities at the boundaries of the sampled volume can introduce high-frequency artifacts (spectral leakage) [S2, unofficial].
*   **Hermitian Symmetry:** For real inputs, the output is redundant. Storing only $N/2$ complex numbers is sufficient for 1D, but standard implementations often store the full complex array [S2, unofficial].

## Subtopics

### Windowed Fourier Transform
Unlike the standard Fourier Transform which covers the whole spatial domain and is not spatially localized, the Windowed Fourier Transform uses a translated window $g(x)$ in the Fourier integral to cover the whole signal, allowing localization of irregularities [S1, unofficial]. It is defined by applying a spatial window to the signal before transformation, enabling the detection of the position of irregularities which the standard DFT cannot provide [S1, unofficial].

### Centered DFT
A preprocessing technique to compute the DFT of a real signal such that the frequency spectrum is centered (zero frequency at the center), avoiding the discontinuity at the boundaries of the standard DFT output range [S2, unofficial]. It is achieved by multiplying the signal elements by $(-1)^k$ (1D) or $(-1)^{x+y}$ (2D) before the transform [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** The preprocessing 3D transform using FFT is $O(N^3 \log N)$ [S1, unofficial]. Per-view slice extraction is $O(N^2)$ or $O(W^3 N^2)$ with interpolation, and the 2D inverse transform is $O(N^2 \log N)$ [S1, unofficial].
*   **Memory Complexity:** Frequency domain representations require complex numbers (for FFT) or high-precision floating point, increasing memory usage compared to spatial domain storage [S3, unofficial].
*   **Strengths:** Efficient global filtering and convolution via the Convolution Theorem ($g * h \Leftrightarrow G(f)H(f)$) [S2, unofficial].
*   **Limitations:** Lack of interactivity for parameters other than viewing direction because the transform is global and linear [S1, unofficial]. Does not inherently support non-linear transfer functions, shading, or transparency compositing without additional approximations [S1, unofficial]. Information is not spatially localized, making it difficult to find the position of irregularities [S1, unofficial].

## Background
The Fourier Transform is a classical theory for multiresolution decomposition [S1, unofficial]. In the context of volume rendering, it was formalized in reports such as "Fourier volume rendering" (HPL-95-73) which detailed the properties of the DFT and its application to volume data, including the Convolution Theorem and sampling theory [S2, unofficial]. The method relies on the Projection-Slice Theorem for rendering projections [S3, unofficial].
