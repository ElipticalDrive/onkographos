# Fourier Transform
Also called: Discrete Fourier Transform, DFT

## Overview
The Fourier Transform method converts a 3D scalar volume into the frequency domain to enable rendering via the Projection-Slice Theorem [Domain-transform methods](28-domain-transform-methods.md) [S1, unofficial]. It differs from spatial-domain methods by performing a global transformation of the entire volume, which allows for efficient convolution operations but requires significant preprocessing memory and does not support interactive parameter changes like opacity or lighting [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scalar volume $f(x, y, z)$ of dimensions $N_x \times N_y \times N_z$ [S2, unofficial].
*   **Output:** A 2D projection image $I(u, v)$ [S1, unofficial].

**Data Structures:**
*   **Volume Data:** A 3D array of real numbers representing the spatial domain [S2, unofficial].
*   **Frequency Data:** A 3D array of complex numbers representing the frequency domain [S2, unofficial]. For real input, the output is Hermitian symmetric, meaning $H_{-u,-v,-w} = H_{u,v,w}^*$, allowing storage of only half the data if optimized [S2, unofficial].

**Parameters:**
*   $N$: Number of samples along a dimension. Assumed to be even for standard frequency point derivation [S2, unofficial].
*   $\Delta$: Sampling interval (spacing between voxels) [S2, unofficial].
*   $f_c$: Nyquist critical frequency, defined as $1/(2\Delta)$ [S2, unofficial].

**Steps:**
1.  **Preprocessing (Centering):** To center the zero-frequency component in the middle of the spectrum and avoid boundary discontinuities in visualization, multiply the input volume by $(-1)^{x+y+z}$ [S2, unofficial]. The source explicitly defines this shift for 1D signals as multiplying by $(-1)^k$ and for 2D signals as multiplying by $(-1)^{x+y}$; the 3D extension follows the same pattern [G].
2.  **Global Transformation (3D DFT):** Compute the 3D Discrete Fourier Transform of the volume. For a 1D sequence $h_k$ of length $N$, the DFT $H_n$ is defined as [S2, unofficial]:
    $$H_n = \sum_{k=0}^{N-1} h_k e^{2\pi i k n/N}$$
    For a 3D volume $f(x, y, z)$, the 3D DFT $F(u, v, w)$ is computed as [S2, unofficial]:
    $$F(u, v, w) = \sum_{x=0}^{N_x-1} \sum_{y=0}^{N_y-1} \sum_{z=0}^{N_z-1} f(x, y, z) e^{2\pi i (ux/N_x + vy/N_y + wz/N_z)}$$
    The source defines the forward DFT with a positive exponent in Eq. 2.13 [S2, unofficial].
3.  **Slice Extraction:** According to the Projection-Slice Theorem, the 2D Fourier transform of a projection of the volume along a viewing direction is equal to a 2D slice through the origin of the 3D Fourier transform, perpendicular to the viewing direction [S1, unofficial]. Extract a 2D plane from the 3D frequency volume $F(u, v, w)$ corresponding to the viewing direction. The extracted slice lies on a grid that may not align with the discrete 3D lattice of $F$. Interpolation (e.g., trilinear or sinc) is required to resample the frequency data onto the 2D output grid [S2, unofficial].
4.  **Inverse Transformation (2D IDFT):** Compute the 2D Inverse Discrete Fourier Transform of the extracted slice to obtain the spatial domain projection image [S1, unofficial]. The exact normalization factor ($1/N$ or $1/\sqrt{N}$) depends on the specific DFT definition used [G].

    N = len(signal)
    return [sum(signal[k] * cmath.exp(2j * math.pi * k * n / N) for k in range(N)) for n in range(N)]

    Nx, Ny, Nz = len(volume), len(volume[0]), len(volume[0][0])

    for u in range(Nx):

                s = 0+0j
                for x in range(Nx):
                    for y in range(Ny):
                        for z in range(Nz):

    return F

def idft_2d(slice_2d):

**Edge Cases and Pitfalls:**
*   **Boundary Artifacts:** The DFT assumes periodic boundary conditions [S1, unofficial]. Discontinuities at the volume boundaries cause high-frequency artifacts [S1, unofficial]. Mitigation includes zero-padding the volume by a factor of $k_2$ (typically $4/3$) and applying vignetting correction (premultiplying by the reciprocal of the interpolation filter response) [S1, unofficial].
*   **Aliasing:** If the output image resolution is too low, aliasing artifacts will appear [S2, unofficial]. The resolution must meet the Nyquist criterion relative to the volume's bandwidth [S2, unofficial].
*   **Hermitian Symmetry:** For real-valued input, the DFT output is Hermitian symmetric [S2, unofficial]. This can be exploited to reduce memory usage by storing only half the complex coefficients [S2, unofficial].

## Subtopics

### [Windowed Fourier Transform](6084-windowed-fourier-transform.md)
The Windowed Fourier Transform (WFT), also known as the Gabor Transform, addresses the lack of spatial localization inherent in the standard Fourier Transform. While the standard Fourier Transform provides a global frequency measure by integrating over the entire spatial domain, making it difficult to locate irregularities, the WFT uses a translated window function to cover the signal, allowing for the localization of these irregularities. It builds on [Fourier Transform](2288-fourier-transform.md) by introducing spatial constraints to the frequency analysis.

## Operating characteristics
*   **Time Complexity:** The 3D DFT using FFT algorithms has a complexity of $O(N^3 \log N)$ for a volume of size $N^3$ [S1, unofficial]. The 2D IDFT for an image of size $M \times M$ has a complexity of $O(M^2 \log M)$ [S1, unofficial].
*   **Memory Complexity:** The 3D frequency volume requires $O(N^3)$ memory [S1, unofficial].
*   **Performance:** The method is computationally intensive due to the global 3D transform [S1, unofficial]. It is suitable for static volumes where the viewing direction changes frequently, as the 3D transform is performed once [S1, unofficial].
*   **Strengths:** Efficient for multiple viewing angles once the 3D transform is computed [S1, unofficial].
*   **Limitations:** High memory usage [S1, unofficial]. Lack of interactivity for display parameters (opacity, lighting) [S1, unofficial]. Boundary artifacts require careful handling [S1, unofficial].

## Background
The Fourier Transform is a classical theory for multiresolution decomposition [S1, unofficial]. It provides a measure of high frequency but information is not spatially localized, as the transform covers the whole spatial domain, making it difficult to find the position of irregularities [S1, unofficial].
