# Windowed Fourier Transform

Also called: Gabor Transform

## Overview
The Windowed Fourier Transform (WFT), also known as the Gabor Transform, addresses the lack of spatial localization inherent in the standard Fourier Transform by introducing a spatially localized window function [S1, unofficial]. While the standard Fourier Transform provides a global measure of frequency content across the entire signal, making it difficult to identify the position of irregularities, the WFT uses a translated window to cover the whole signal, allowing for the localization of these irregularities [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A function $f(x)$ belonging to the space $L^2(\mathbb{R})$ (square-integrable functions).
*   **Output:** A 2D function $Gf(u, \omega)$ representing the transform coefficients at position $u$ and frequency $\omega$.

**Data Structures:**
The output is typically stored as a 2D grid or array where one axis represents the spatial translation parameter $u$ and the other represents the frequency parameter $\omega$.

**Method:**
The transform is defined by the following integral:

$$ Gf(u, \omega) = \int_{-\infty}^{\infty} f(x) g(x - u) e^{-i \omega x} dx $$

**Symbol Definitions:**
*   $f(x)$: The input signal or function.
*   $g(x)$: The window function (kernel), typically a Gaussian or similar localized function.
*   $u$: The spatial translation parameter, shifting the window along the spatial axis.
*   $\omega$: The frequency parameter.
*   $i$: The imaginary unit.

**Steps:**
1.  Select a window function $g(x)$ that is localized in space (e.g., decays rapidly away from the origin).
2.  For each desired spatial position $u$ and frequency $\omega$:
    a. Shift the window function to $g(x - u)$.
    b. Multiply the input signal $f(x)$ by the shifted window $g(x - u)$.
    c. Multiply the result by the complex exponential kernel $e^{-i \omega x}$.
    d. Integrate the product over the entire spatial domain $x \in (-\infty, \infty)$.

**Pseudocode:**
```python
def windowed_fourier_transform(f, g, u_values, omega_values):
    """
    Computes the Windowed Fourier Transform for discrete inputs.
    
    Args:
        f: Array of input signal values f(x) at spatial points x.
        g: Array of window function values g(x) at spatial points x.
           Note: g should be centered at 0.
        u_values: Array of spatial translation positions u.
        omega_values: Array of frequency values omega.
        
    Returns:
        Gf: 2D array of shape (len(u_values), len(omega_values)).
    """
    # Define the spatial grid corresponding to f and g
    # Assuming f and g are sampled on the same grid with spacing dx
    x = np.arange(len(f)) * dx # dx is the spatial step size, assumed known or derived
    
    Gf = np.zeros((len(u_values), len(omega_values)))
    
    for i, u in enumerate(u_values):
        for j, omega in enumerate(omega_values):
            # Shift the window function to position u
            # g_shifted[x] = g[x - u]
            # In discrete implementation, this involves interpolation or array shifting
            g_shifted = interpolate_shift(g, u)
            
            # Compute the integrand: f(x) * g(x - u) * exp(-i * omega * x)
            # Using trapezoidal or simple Riemann sum for integration
            integrand = f * g_shifted * np.exp(-1j * omega * x)
            
            # Integrate over x
            # Using np.trapz for better accuracy than simple sum
            Gf[i, j] = np.trapz(integrand, x)
            
    return Gf

def interpolate_shift(g, u):
    """
    Shifts the window function g by u.
    Since u may not be an integer index, interpolation is required.
    """
    # Create indices for the shifted window
    # If g is defined on indices 0..N-1, g(x-u) corresponds to g at index k where k*dx = x - u
    # This is a helper for the discrete implementation
    # For simplicity in this generic pseudocode, we assume a shift operation exists
    # In practice, one might use np.roll for integer shifts or FFT-based shifting for non-integer
    return np.roll(g, int(round(u / dx))) # Simplified; real implementation needs careful boundary handling
```

**Parameters:**
*   **Window Function $g(x)$:** The choice of window (e.g., Gaussian, Hamming) affects the trade-off between spatial and frequency resolution. Not given in the sources.
*   **Step sizes for $u$ and $\omega$:** Determine the resolution of the output transform. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Boundary Effects:** Since the window is localized, signals near the boundaries of the domain may be truncated if the window extends beyond the signal support. [G] Zero-padding or periodic extension is often used to mitigate this.
*   **Precision:** The integration step requires careful numerical handling, especially for high-frequency components where the complex exponential oscillates rapidly.

## Subtopics

### [Aperture Apodization](10803-aperture-apodization.md)
A technique used in numerical holographic reconstruction to suppress side-lobe leakage and diffraction artifacts caused by the sharp intensity edges of a rectangular synthetic aperture. It works by smoothly tapering the aperture edges to zero, thereby reducing strong diffraction effects at the borders that would otherwise occur during propagation. It is applied after selecting a sub-region of the hologram (synthetic aperture) to define a specific viewpoint.

### [Anisotropic Noise](16450-anisotropic-noise.md)
A procedural noise function designed to support high-quality anisotropic filtering, addressing the trade-off between aliasing artifacts and detail loss inherent in isotropic noise methods. It partitions the frequency domain into oriented subbands using steerable filters, allowing the noise content to adapt to non-uniform perspective distortions and parametric surface distortions by adjusting subband weights during rendering.

## Operating characteristics
*   **Time Complexity:** The direct computation of the WFT for all $u$ and $\omega$ values is $O(N \cdot M \cdot K)$, where $N$ is the number of spatial samples, $M$ is the number of $u$ positions, and $K$ is the number of $\omega$ positions. This is significantly more expensive than the standard FFT ($O(N \log N)$).
*   **Memory Complexity:** $O(M \cdot K)$ to store the transform coefficients.
*   **Strengths:** Provides simultaneous time (or space) and frequency localization, allowing for the analysis of non-stationary signals where frequency content changes over time/space.
*   **Limitations:** High computational cost compared to global Fourier methods. The choice of window function imposes a fixed resolution trade-off (Heisenberg uncertainty principle).
*   **When to use:** When the signal's frequency content varies with position and global Fourier analysis is insufficient.
*   **When not to use:** When only global frequency statistics are needed or when computational resources are severely limited.

## Background
The Windowed Fourier Transform was introduced by Dennis Gabor [S1, unofficial]. Gabor defined this new decomposition using a spatial window $g(x)$ in the Fourier integral to localize the information provided by the Fourier transform, which previously covered the whole spatial domain and was not spatially localized [S1, unofficial]. The transform is translated along the spatial axis to cover the whole signal [S1, unofficial].
