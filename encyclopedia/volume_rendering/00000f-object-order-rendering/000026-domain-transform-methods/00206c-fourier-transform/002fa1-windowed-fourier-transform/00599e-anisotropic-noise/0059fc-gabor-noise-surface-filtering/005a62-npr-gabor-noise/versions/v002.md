# NPR Gabor Noise
Also called: Gabor Noise for NPR
## Overview
NPR Gabor Noise is a variant of Gabor noise designed for coherent stylization in non-photorealistic rendering (NPR) [S1, S2]. It preserves the 2D aspect of the noise and the 3D motion of the scene by defining noise parameters in 2D screen space and point distribution in 3D object space [S1, S2]. It builds on [Gabor Noise Surface Filtering](16556-gabor-noise-surface-filtering.md) [G].
## How it works
**Inputs and Outputs:**
- Input: 3D point coordinates in object space, camera parameters, and noise parameters defined in 2D screen space [S1, S2].
- Output: A scalar noise value at the given 3D point.

**Data Structures:**
Not given in the sources. [G]

**Steps:**
1. Define noise parameters in 2D screen space [S1, S2].
2. Define the point distribution in 3D object space [S1, S2].
3. For a given 3D point in object space, map it to 2D screen space coordinates using the camera's view and projection matrices [G].
4. Evaluate the Gabor noise function using the screen-space coordinates and the screen-space noise parameters [G].
5. Return the resulting noise value.

**Formulas:**
Not given in the sources. [G]

**Parameters:**
Noise parameters are defined in 2D screen space [S1, S2]. Point distribution is defined in 3D object space [S1, S2]. Typical values are not given in the sources. [G]

**Edge cases and pitfalls:**
Precision, boundaries, and degenerate input are not given in the sources. [G]
