# Gabor Noise Surface Filtering

Also called: Analytical filtering of Gabor noise, Gabor Noise Filtering

## Overview
Gabor Noise Surface Filtering is an analytical method for generating anisotropically filtered procedural noise on surfaces, solving the problem of aliasing and visual inconsistency caused by non-uniform perspective distortions during camera or object motion [S1, S3]. Unlike methods that discretize the spectrum into distinct bands or rely on post-hoc blurring, this approach exploits the fact that Gabor kernels correspond to Gaussians in the frequency domain, allowing the filter to be applied by analytically modifying the kernel parameters per pixel [S1, S2, S3]. It builds on [Anisotropic Noise](16450-anisotropic-noise.md) and provides view-dependent spectral control that adapts to the screen-space projection of the surface [S3].

## How it works
The method generates filtered noise by operating in the frequency domain, leveraging the closed-form nature of Gaussian functions [S2]. It avoids explicit convolution in the spatial domain by computing the product of the noise spectrum and the filter spectrum, resulting in a new set of kernel parameters that directly yield the filtered noise [S2].

### Inputs and Outputs
*   **Inputs**: Surface shading point, Gabor noise definition (sum of oriented subbands), and view/screen-space context [S1, S3].
*   **Outputs**: A noise value that is anisotropically filtered according to the view direction and surface orientation [S3].

### Data Structures
The noise is represented as a weighted sum of $N$ Gabor kernels [S1, S3]. Each kernel $i$ has a center frequency and bandwidth that define a Gaussian in the frequency domain [S1, S2, S3].

### Steps
1. Represent the noise as a sum of Gabor kernels [S3].
2. For each kernel, identify its Gaussian representation in the frequency domain [S3].
3. Identify the filter Gaussian in the frequency domain, which varies per screen pixel due to view-dependence [S3].
4. Compute the product of the Gabor Gaussian and the filter Gaussian in the frequency domain [S1, S2, S3].
5. Since Gaussians are closed under multiplication, the product is a third Gaussian [S1, S2, S3].
6. Interpret this new Gaussian as a filtered Gabor kernel [S1, S2, S3].
7. Use the parameters of this new kernel instead of the original unfiltered kernel to directly generate noise with a filtered spectrum [S1, S2, S3].

### Formulas
The spectrum of a Gabor kernel $i$ in frequency space $\mathbf{u}$ is modeled as a Gaussian:
$$ G_i(\mathbf{u}) = \exp\left( -\frac{1}{2} (\mathbf{u} - \mathbf{k}_i)^T \Sigma_i^{-1} (\mathbf{u} - \mathbf{k}_i) \right) $$
where $\mathbf{k}_i$ is the center frequency and $\Sigma_i$ is the covariance matrix [G].

The filter Gaussian $F(\mathbf{u})$ in texture space is also a Gaussian, with mean $\mathbf{k}_F$ and covariance $\Sigma_F$ [S3]. The product of the two Gaussians results in a new Gaussian $G'_i(\mathbf{u})$:
$$ G'_i(\mathbf{u}) = G_i(\mathbf{u}) \cdot F(\mathbf{u}) = C \cdot \exp\left( -\frac{1}{2} (\mathbf{u} - \mathbf{k}'_i)^T \Sigma'_i^{-1} (\mathbf{u} - \mathbf{k}'_i) \right) $$
The new mean $\mathbf{k}'_i$ and covariance $\Sigma'_i$ are computed using standard Gaussian multiplication rules [G]:
$$ \Sigma'_i = (\Sigma_i^{-1} + \Sigma_F^{-1})^{-1} $$
$$ \mathbf{k}'_i = \Sigma'_i (\Sigma_i^{-1} \mathbf{k}_i + \Sigma_F^{-1} \mathbf{k}_F) $$

### Parameters
*   **Number of Kernels ($N$)**: Not given in the sources.
*   **Bandwidth ($\sigma_i$)**: Controls the frequency spread of each kernel [S1, S3].
*   **Filter Width**: Determined by the view-dependent screen-space projection; computed per pixel [S3].

### Edge Cases and Pitfalls
*   **View-Dependence**: The filter Gaussian varies per screen pixel. Failing to compute the correct filter shape for each pixel leads to incorrect filtering, especially on tilted surfaces [S3].
*   **Degenerate Input**: If the surface is viewed edge-on or the derivatives are zero, the filter Gaussian may become singular. Guard against division by zero when inverting covariance matrices [G].
*   **Precision**: The analytical combination of Gaussians requires careful handling of numerical precision, especially when kernel and filter widths differ significantly [G].

### Pseudocode
```python
def gabor_noise_surface_filtering(p, noise_params, filter_cov_inv, filter_mean):
    """
    Generate filtered Gabor noise at point p.
    Args:
        p: 3D position vector.
        noise_params: List of kernel parameters. Each is a dict with keys:
            'k': center frequency vector (3D)
            'Sigma_inv': inverse covariance matrix of the Gabor Gaussian (3x3)
            'phi': phase offset
            'w': subband weight
        filter_cov_inv: Inverse covariance matrix of the view-dependent filter Gaussian (3x3).
        filter_mean: Center frequency of the filter Gaussian (3D vector).
    Returns:
        Filtered noise value.
    """
    filtered_value = 0.0
    for kernel in noise_params:
        k_i = kernel['k']
        Sigma_i_inv = kernel['Sigma_inv']
        phi_i = kernel['phi']
        w_i = kernel['w']

        # Compute new covariance inverse: Sigma'_inv = Sigma_i_inv + Sigma_F_inv
        Sigma_prime_inv = [[Sigma_i_inv[r][c] + filter_cov_inv[r][c] for c in range(3)] for r in range(3)]

        # Compute new covariance: Sigma' = (Sigma'_inv)^-1
        # Standard 3x3 matrix inversion algorithm [G]
        Sigma_prime = invert_3x3(Sigma_prime_inv)

        # Compute new mean: k' = Sigma' * (Sigma_i_inv * k_i + Sigma_F_inv * k_F)
        term1 = [sum(Sigma_i_inv[r][c] * k_i[c] for c in range(3)) for r in range(3)]
        term2 = [sum(filter_cov_inv[r][c] * filter_mean[c] for c in range(3)) for r in range(3)]
        sum_vec = [term1[r] + term2[r] for r in range(3)]
        k_prime = [sum(Sigma_prime[r][c] * sum_vec[c] for c in range(3)) for r in range(3)]

        # Evaluate Gabor kernel with new parameters
        # Standard spatial Gabor form: cos(2*pi * k . p + phi) * exp(-pi * sigma^2 * ||p||^2)
        # The bandwidth sigma is derived from Sigma_prime [G]
        sigma_prime_sq = trace(Sigma_prime) / 3.0
        dot_pk = sum(k_prime[c] * p[c] for c in range(3))
        norm_p_sq = sum(p[c] * p[c] for c in range(3))
        noise_val = cos(2.0 * pi * dot_pk + phi_i) * exp(-pi * sigma_prime_sq * norm_p_sq)
        filtered_value += w_i * noise_val
    return filtered_value

def invert_3x3(M):
    # Standard 3x3 matrix inversion [G]
    inv_det = 1.0 / (M[0][0]*(M[1][1]*M[2][2]-M[1][2]*M[2][1]) - M[0][1]*(M[1][0]*M[2][2]-M[1][2]*M[2][0]) + M[0][2]*(M[1][0]*M[2][1]-M[1][1]*M[2][0]))
    return [[inv_det*(M[1][1]*M[2][2]-M[1][2]*M[2][1]), inv_det*(M[0][2]*M[2][1]-M[0][1]*M[2][2]), inv_det*(M[0][1]*M[1][2]-M[0][2]*M[1][1])],
            [inv_det*(M[1][2]*M[2][0]-M[1][0]*M[2][2]), inv_det*(M[0][0]*M[2][2]-M[0][2]*M[2][0]), inv_det*(M[0][2]*M[1][0]-M[0][0]*M[1][2])],
            [inv_det*(M[1][0]*M[2][1]-M[1][1]*M[2][0]), inv_det*(M[0][1]*M[2][0]-M[0][0]*M[2][1]), inv_det*(M[0][0]*M[1][1]-M[0][1]*M[1][0])]]

def trace(M): return M[0][0] + M[1][1] + M[2][2]
def cos(x): return __import__('math').cos(x)
def exp(x): return __import__('math').exp(x)
def pi: return 3.141592653589793
```

## Subtopics

### [NPR Gabor Noise](16655-npr-gabor-noise.md)
NPR Gabor Noise is a variant of Gabor noise designed for coherent stylization in non-photorealistic rendering (NPR). It solves the problem of maintaining visual consistency of noise patterns during camera or object motion by decoupling the noise parameter definition from the point sampling space. Unlike standard Gabor noise where parameters are often tied to object space, this method defines noise parameters in 2D screen space while defining point distribution in 3D object space, thereby preserving the 2D aspect of the noise and the 3D motion of the scene. It builds on [Gabor Noise Surface Filtering](16556-gabor-noise-surface-filtering.md).

## Operating characteristics
*   **Time Complexity**: The method requires computing screen-space derivatives and then iterating over all Gabor kernels. For each kernel, it performs matrix inversions and multiplications to update the parameters. The complexity is $O(N)$ per pixel, where $N$ is the number of kernels. The matrix operations are constant time (3x3 matrices) [S1, S3].
*   **Memory Complexity**: Minimal additional memory is required, as the filtering is done analytically by modifying parameters. The noise function itself requires storing the kernel parameters [S1, S3].
*   **Measured Performance**: Performance depends on the number of kernels and the cost of evaluating the Gabor function. Analytical filtering avoids the need for multi-sample anti-aliasing or post-processing blurs, which can be expensive [S1, S3].
*   **Scaling**: The method scales well with resolution, as the filtering is done per pixel based on screen-space derivatives. It adapts to non-uniform perspective distortions without requiring scene-dependent precomputation [S1, S3].
*   **Strengths**: Analytical filtering avoids discretization artifacts. Adapts to view-dependent perspective distortions. Maintains anisotropy correctly on tilted surfaces [S1, S3].
*   **Limitations**: Requires accurate screen-space derivatives. Computationally more expensive per pixel than unfiltered noise due to the parameter updates. May struggle with very high-frequency noise if the filter width is too small, leading to numerical instability [G].
*   **When to Use**: Use when high-quality anisotropic filtering is required for procedural noise on surfaces, especially in real-time rendering where post-processing blurs are not feasible or when perspective distortions are significant [S1, S3].
*   **When Not to Use**: Avoid if the noise is isotropic and the surface is viewed front-on, as simpler filtering methods may suffice. Also avoid if the computational budget is extremely tight and the number of kernels is large [G].

## Background
Gabor Noise was introduced by Goldberg et al. [GZD08] in 2008 as a noise function that supports high-quality anisotropic filtering by tiling the frequency domain into oriented subbands. The analytical filtering method for Gabor noise was described by Lagae et al. [LLDD09a] in 2009, exploiting the property that Gabor kernels correspond to Gaussians in the frequency domain. This allows for direct generation of filtered noise by modifying kernel parameters, avoiding the need for explicit convolution or discretization of the spectrum. The method is part of the broader field of procedural noise functions, which are widely used in computer graphics for texture synthesis, terrain generation, and visual effects [S1, S2, S3].
