# Fourier Spectral Synthesis
Also called: Fourier Noise Generation, Spectral Synthesis

## Overview
Fourier Spectral Synthesis generates a noise field with a specific target power spectrum by filtering white noise in the frequency domain [S1]. It is distinguished from spatial-domain methods by its direct control over the statistical frequency distribution, making it the standard approach for generating random fractals and explicit noise functions like spot noise [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A target power spectrum function $P(k)$, where $k$ is the spatial frequency vector.
*   **Output:** A noise field $N(x)$ defined over a spatial domain.

**Data Structures:**
*   The noise field is represented on a discrete grid of size $N \times N \times N$ (or 2D/1D).
*   The frequency domain is represented by a complex-valued array of the same dimensions, stored as pairs of real numbers (real and imaginary parts) or complex numbers.

**Steps:**
1.  **Generate White Noise:** Create a grid of independent, identically distributed (i.i.d.) random values $W(x)$ with zero mean and unit variance.
2.  **Forward Transform:** Compute the Discrete Fourier Transform (DFT) of the white noise grid to obtain $\hat{W}(k)$.
3.  **Apply Spectrum:** Multiply the frequency components by the square root of the target power spectrum. To ensure the output is real-valued, the phase of the white noise is preserved, and the magnitude is scaled:
    $$ \hat{N}(k) = \sqrt{P(k)} \cdot \hat{W}(k) $$
    *Note: For $k=0$ (DC component), $P(0)$ is typically set to 0 to ensure zero mean, or handled specifically to avoid bias.*
    *Constraint: The resulting $\hat{N}(k)$ must satisfy Hermitian symmetry ($\hat{N}(-k) = \hat{N}(k)^*$) to guarantee a real-valued inverse transform. If the grid is real, the DFT of white noise already satisfies this; scaling by a real-valued symmetric spectrum $P(k)$ preserves it.*
4.  **Inverse Transform:** Compute the Inverse Discrete Fourier Transform (IDFT) of $\hat{N}(k)$ to obtain the noise field $N(x)$.
5.  **Normalization:** Scale the result to achieve desired amplitude (e.g., unit variance).

**Parameters:**
*   **Target Power Spectrum $P(k)$:** Common forms include $P(k) \propto 1/k^\beta$ for fractal noise (where $\beta$ controls roughness).
*   **Grid Resolution:** Determines the highest frequency detail.

**Edge Cases and Pitfalls:**
*   **DC Component:** The zero-frequency component must be handled to prevent a non-zero mean in the output.
*   **Symmetry:** Numerical errors in the DFT/IDFT or asymmetric spectrum definitions can lead to small imaginary parts in the output. A final `real()` operation is required.
*   **Boundary Conditions:** The DFT assumes periodic boundaries. Artifacts may appear if the noise is not intended to be periodic.

**Pseudocode:**
```python
def fourier_spectral_synthesis(target_spectrum, grid_size):
    # 1. Generate white noise
    # W is a complex array of shape (grid_size, grid_size, grid_size)
    # Real and imaginary parts are independent Gaussian(0, 1)
    W_real = random_gaussian(grid_size)
    W_imag = random_gaussian(grid_size)
    W = complex_array(W_real, W_imag)
    
    # 2. Forward DFT
    W_hat = dft(W)
    
    # 3. Apply spectrum
    # target_spectrum(k) returns the power at frequency k
    # Ensure Hermitian symmetry is maintained if target_spectrum is not perfectly symmetric
    N_hat = zeros_like(W_hat)
    for k in all_frequency_indices:
        p_k = target_spectrum(k)
        # Avoid division by zero or negative spectrum values
        if p_k < 0:
            p_k = 0
        N_hat[k] = sqrt(p_k) * W_hat[k]
        
    # 4. Inverse DFT
    N = idft(N_hat)
    
    # 5. Extract real part and normalize
    N_real = real(N)
    
    # Optional: Normalize to unit variance
    mean = sum(N_real) / len(N_real)
    N_real = N_real - mean
    variance = sum(N_real**2) / len(N_real)
    if variance > 0:
        N_real = N_real / sqrt(variance)
        
    return N_real
```

## Operating characteristics
*   **Time Complexity:** $O(N^3 \log N)$ for 3D grids using Fast Fourier Transform (FFT).
*   **Memory Complexity:** $O(N^3)$ to store the complex frequency domain array.
*   **Strengths:** Exact control over the power spectrum; generates statistically correct fractal noise; efficient for global frequency shaping.
*   **Limitations:** Computationally expensive for high resolutions; produces periodic noise (aliasing if not tiled correctly); less suitable for local, adaptive detail compared to hierarchical methods.
*   **When to use:** When a specific statistical frequency distribution is required (e.g., terrain generation, reference solutions).
*   **When not to use:** When local control or non-periodic boundaries are critical without tiling tricks.

## Background
Fourier Spectral Synthesis was introduced in computer graphics by Anjyo [Anj88], Saupe [Sau88], and Voss [Vos88] to generate random fractals for simulating natural phenomena like terrain [S1]. It is based on the principle that filtering white noise in the frequency domain yields a process with the desired power spectrum [S1]. The technique is also related to the mathematical texturing function of Gardner [Gar84] and is used in explicit noise methods such as spot noise [vW91] and anisotropic noise [GZD08].
