# Frequency Domain Shear-Warp Volume Rendering

Also called: FDVR, Fourier Volume Rendering, Resampling in the Frequency Domain

## Overview
Frequency Domain Shear-Warp Volume Rendering is a method that performs the shear transformation of the shear-warp factorization in the frequency domain using the shifting theorem, allowing for arbitrary, view-independent sampling distances along viewing rays via zero-padding interpolation [S1]. Unlike standard shear-warp algorithms where sampling distance is coarse and view-dependent, this technique decouples sampling density from the viewing direction by resampling in the frequency domain, thereby avoiding the large spatial zero-padding required by spatial-domain shear methods [S1].

## How it works
The method builds on [Frequency Domain Volume Rendering](952-frequency-domain-volume-rendering.md) by replacing the spatial shear stage with frequency-domain operations.

**Inputs and Outputs**
*   **Input:** Volume dataset $V$ of size $N \times N \times N$ (cubiform, power of two), viewing vector $\vec{v}_{so}$, desired sampling distance $s'$, slice distance $d_k$.
*   **Output:** Rendered image with arbitrary sampling distance $s'$ along viewing rays.

**Data Structures**
*   **Volume Data:** 3D array of voxel values.
*   **Frequency Domain:** 3D complex array resulting from FFT.
*   **Slices:** 2D arrays representing planes perpendicular to the viewing direction.

**Numbered Steps**

1.  **Permutation:** Change the storage order of voxels in memory to maximize cache coherency, such that the $(i, j)$ plane is most perpendicular to the viewing direction [S1]. The volume starts in the standard object coordinate system, already permuted such that the $(i, j)$ plane is most perpendicular to the viewing direction [S1].

2.  **3D Fourier Transform:** Compute the 3D Fourier transform of the permuted volume to reach the frequency domain representation [S1].

3.  **Calculate Pre-Resampling Sampling Distance ($s$):** Compute the sampling distance along the viewing rays before resampling using the viewing vector and slice distance [S1].
    *   Normalize the viewing vector $\vec{v}_{so} = (v_{so,i}, v_{so,j}, v_{so,k})$ in the $k$ direction by dividing each component by $v_{so,k}$, yielding $\vec{v}'_{so} = (v'_{so,i}, v'_{so,j}, v'_{so,k})$ with $v'_{so,k} = 1.0$ [S1].
    *   Calculate $s$ using the formula:
        $$ s = d_k \sqrt{(v'_{so,i})^2 + (v'_{so,j})^2 + (v'_{so,k})^2} $$
        where $s$ is the sampling distance before resampling, $d_k$ is the distance between volume slices along the $k$ axis, and $v'_{so,i}, v'_{so,j}, v'_{so,k}$ are the components of the normalized viewing vector [S1].

4.  **Calculate Post-Resampling Slice Count ($K'$):** Determine the number of slices needed after resampling to achieve the desired sampling distance $s'$ using the ratio of desired to current sampling distance and the current slice count $K$ [S1].
    *   The relationship is given by:
        $$ \frac{s'}{s} = \frac{K}{K'} $$
    *   Solve for $K'$:
        $$ K' = \frac{sK}{s'} $$
    *   Round $K'$ to the closest integer $K'_{pad} \in \mathbb{N}$ [S1].

5.  **Zero-Padding:** Append zeros in the frequency domain along the $k$ direction to increase the number of slices from $K$ to $K'_{pad}$, exploiting the packing theorem (zero-padding interpolation property) [S1].
    *   The difference between $K'_{pad}$ and $K$ is the amount of zero-padding necessary for the selected sampling distance $s'$ [S1].
    *   Note: For $K'_{pad} > 50$, the deviation from the desired sampling distance $s'$ is below $\pm 1.0\%$ [S1].

6.  **Inverse Fourier Transform in $k$:** Apply an inverse Fourier transform in the $k$ direction while keeping the $i$ and $j$ directions in the frequency domain to obtain sheared slices [S1]. This stage effectively performs the shear transformation via the shifting theorem in the frequency domain [S1].

7.  **Compositing:** Perform numeric integration along the viewing rays on the resampled slices. This stage uses the arbitrary sampling distance $s'$ independent of the viewing direction [S1].

8.  **Warping:** Transform the intermediate image of the compositing stage into the final image. The warping in this method remains similar to the standard shear-warp algorithm [S1].

**Pseudocode**

```python
import numpy as np

def frequency_domain_shear_warp(volume, viewing_vector, desired_sampling_distance, slice_distance):
    """
    Renders a volume using Frequency Domain Shear-Warp Volume Rendering.
    
    Args:
        volume: 3D numpy array of shape (N, N, N), power of two.
        viewing_vector: Tuple (v_x, v_y, v_z) representing the viewing direction.
        desired_sampling_distance: Float, target sampling distance s'.
        slice_distance: Float, distance d_k between volume slices along k axis.
        
    Returns:
        Rendered image.
    """
    N = volume.shape[0]
    
    # Step 1: Permutation
    # Change storage order to maximize cache coherency.
    # The (i, j) plane should be most perpendicular to the viewing direction.
    # Implementation detail: Reorder voxels in memory.
    permuted_volume = permute_for_cache_coherency(volume, viewing_vector)
    
    # Step 2: 3D Fourier Transform
    # Compute 3D FFT of the permuted volume.
    freq_volume = np.fft.fftn(permuted_volume)
    
    # Step 3: Calculate Pre-Resampling Sampling Distance (s)
    # Normalize viewing vector in k direction (v_z)
    v_x, v_y, v_z = viewing_vector
    v_prime_x = v_x / v_z
    v_prime_y = v_y / v_z
    v_prime_z = 1.0
    
    # Calculate s
    s = slice_distance * np.sqrt(v_prime_x**2 + v_prime_y**2 + v_prime_z**2)
    
    # Step 4: Calculate Post-Resampling Slice Count (K')
    # K is the current number of slices along k, which is N
    K = N
    K_prime_float = (s * K) / desired_sampling_distance
    K_prime_pad = int(round(K_prime_float))
    
    # Step 5: Zero-Padding
    # Append zeros in the frequency domain along the k direction.
    # The frequency domain array has shape (N, N, N).
    # We need to expand the last dimension to K_prime_pad.
    # Note: FFT output is typically ordered such that the last dimension corresponds to k.
    # Zero-padding in frequency domain corresponds to interpolation in spatial domain.
    padded_freq_volume = np.zeros((N, N, K_prime_pad), dtype=complex)
    padded_freq_volume[:, :, :N] = freq_volume
    
    # Step 6: Inverse Fourier Transform in k
    # Apply inverse FFT along the k direction (last axis).
    # i and j directions remain in frequency domain.
    sheared_slices_freq = np.fft.ifft(padded_freq_volume, axis=2)
    
    # Step 7: Compositing
    # Perform numeric integration along the viewing rays on the resampled slices.
    # The slices are now in the spatial domain along k, but i and j are still in frequency domain?
    # Wait, the source says "inverse Fourier transform in k direction, while the i and j direction 
    # of the volume remain in the frequency domain".
    # This implies we have 2D slices in the spatial domain along k, but i and j are frequency?
    # No, if we only do IFFT along k, the result is still in frequency domain for i and j.
    # However, compositing requires spatial domain slices.
    # The source mentions "Resampling of Volume Slices in i and j Direction" as a separate stage 
    # for zooming, but the core shear-warp pipeline ends with compositing.
    # Let's re-read carefully: "Finally to get the slices for compositing N 2D inverse Fourier transforms 
    # (complexity N^3 log2 N) are used."
    # This implies we need to transform i and j to spatial domain as well for compositing.
    # The source lists: 1 3D FFT, N^2 1D IFFTs (k), N^2 2D IFFTs (i,j).
    # So Step 6 in the numbered list is just IFFT in k.
    # We need an additional step to get spatial slices for compositing.
    
    # Additional Step: Inverse Fourier Transform in i and j
    # Apply 2D IFFT to each slice along k to get spatial domain slices.
    # sheared_slices_freq is shape (N, N, K_prime_pad) in frequency domain for i,j?
    # Actually, if we did IFFT along k, the shape is (N, N, K_prime_pad).
    # The values are complex. The i and j dimensions are still in frequency domain.
    # We need to transform i and j to spatial domain.
    spatial_slices = np.fft.ifft2(sheared_slices_freq, axes=(0, 1))
    
    # Compositing
    # Numeric integration along viewing rays.
    # Since we have arbitrary sampling distance s', we sample along the rays.
    # The rays are now perpendicular to the (i,j) planes? 
    # No, the permutation made (i,j) perpendicular to viewing direction.
    # So viewing rays are along k.
    # We integrate along k.
    image = np.zeros((N, N))
    for i in range(N):
        for j in range(N):
            # Integrate along the k dimension of the spatial slices
            # Using the desired sampling distance s'
            # This is a simple summation or trapezoidal rule over the slices
            # The slices are already resampled to have spacing corresponding to s'
            ray_data = spatial_slices[i, j, :]
            # Simple accumulation for volume rendering (e.g., front-to-back)
            # Assuming ray_data contains transmittance and color contributions
            # Standard compositing formula:
            # C = sum(c_k * t_k)
            # t = product(1 - alpha_k)
            # For simplicity, assuming ray_data is pre-computed contributions
            image[i, j] = np.sum(ray_data) # Placeholder for actual compositing logic
            
    # Step 8: Warping
    # Transform intermediate image to final image.
    # Similar to standard shear-warp warping.
    final_image = warp_image(image, viewing_vector)
    
    return final_image
```

**Parameters**
*   **Desired Sampling Distance ($s'$):** The target sampling distance along the viewing rays, which is independent of the view direction [S1].
*   **Slice Distance ($d_k$):** The distance between volume slices along the $k$ axis in the object coordinate system [S1].

**Edge Cases and Pitfalls**
*   **Spatial Domain Zero-Padding:** If spatial domain zero-padding is too small in shear-based methods, data passes over the border and re-enters from the other side due to periodicity, an error amplified by consecutive shears. This method avoids this by not requiring large spatial domain zero-padding [S1].
*   **Rounding Error:** Zero-padding can only be applied in discrete steps, so $K'_{pad}$ is rounded to the closest integer. For $K'_{pad} > 50$, the deviation from the desired sampling distance $s'$ is below $\pm 1.0\%$ [S1].

## Operating characteristics
*   **Time Complexity:** For a cubiform dataset with edge length $N$ (power of two), the computational complexity is $6 \cdot N^3 \log_2 N$, consisting of one 3D FFT ($3 \cdot N^3 \log_2 N$), $N^2$ 1D IFFTs ($N^3 \log_2 N$), and $N^2$ 2D IFFTs ($N^3 \log_2 N$) [S1].
*   **Memory Complexity:** The method does not require large spatial domain zero-padding, resulting in significantly lower memory consumption compared to methods like Li et al.'s, which requires memory >5x higher [S1].
*   **Performance:** Experimental results show that the presented method outperforms established algorithms in the quality of the produced images [S1]. If the data is sampled above the Nyquist rate, the method is capable of perfect reconstruction of the original function [S1].
*   **Strengths:** Allows arbitrary, view-independent sampling distances; avoids periodicity errors from spatial shear; high reconstruction quality.
*   **Limitations:** Requires FFT computation; rounding of slice count may introduce minor sampling distance deviations (negligible for $K'_{pad} > 50$).

## Background
*   **Origin:** The method was introduced in a paper by researchers from the University of Technology, Austria, and Simon Fraser University, Vancouver, Canada [S1].
*   **History:** It is conceptually based on the shear-warp factorization, which consists of permutation, shearing, compositing, and warping stages [S1]. The method proposes performing the shear transformation in the frequency domain using the shifting theorem [S1].
*   **Usage:** Used for high-quality volume rendering, particularly where view-independent sampling and high reconstruction quality are required [S1].
