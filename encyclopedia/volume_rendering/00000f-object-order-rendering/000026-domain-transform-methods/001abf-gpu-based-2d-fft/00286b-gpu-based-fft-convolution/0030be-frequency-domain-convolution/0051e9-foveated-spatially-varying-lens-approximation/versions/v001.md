# Foveated Spatially Varying Lens Approximation

Also called: Tracked Spatially Varying Lens Phase Function Method

## Overview
This method approximates spatially variant focus and aberration control by applying the correct lens phase function only at the user's tracked fovea position, rather than computing the full spatially variant solution for the entire hologram. It builds on [Frequency Domain Convolution](6341-frequency-domain-convolution.md) by substituting a fixed lens phase function with a temporally varying one derived from eye tracking. Unlike piece-wise methods [S1], it provides a smooth and continuous falloff of aberration correction outside the foveal region without sharp phase discontinuities.

## How it works
**Inputs and Outputs:**
- **Input:** The complex object plane $O$ (from [Frequency Domain Convolution](6341-frequency-domain-convolution.md)), the tracked fovea position in object space, and the base lens phase function parameters.
- **Output:** The complex hologram plane $H$, ready for phase extraction.

**Data Structures:**
- **Lens Phase Function ($f_z$):** A 2D array representing the phase shift introduced by the lens. In the standard fixed case, this is static.
- **Tracked Lens Phase Function ($f_{z_{ot}}$):** A 2D array of the same dimensions as $f_z$, recomputed each frame.
- **Fovea Position ($o_{it}$):** The 2D coordinates of the closest object point to the tracked fovea.

**Steps:**
1. **Track Fovea:** Determine the user's fovea position in the object space. Identify the closest object point $o_{it}$ to this tracked position [S1].
2. **Compute Temporally Varying Lens Function:** Calculate the lens phase function $f_{z_{ot}}$ corresponding to the object point $o_{it}$ [S1]. This function represents the optical correction required for that specific depth and position.
3. **Convolve:** Perform the spatial convolution defined in Equation 15 of [S1], substituting the fixed lens phase function $f_z$ with the temporally varying function $f_{z_{ot}}$.
   $$ H = \mathcal{F}^{-1} \{ \mathcal{F}\{O\} \cdot \mathcal{F}\{f_{z_{ot}}\} \} $$
   Where $\mathcal{F}$ is the Fourier transform and $\mathcal{F}^{-1}$ is the inverse Fourier transform.
4. **Repeat:** Recompute $f_{z_{ot}}$ each frame based on the new fovea position [S1].

**Parameters:**
- **Fovea Tracking Latency:** Must be low enough to prevent visible lag, though specific values are not given [S1].
- **Falloff Rate:** The resolution of aberration correction must fall off no more quickly than the visual acuity of the human eye [S1].

**Edge Cases and Pitfalls:**
- **Depth Ambiguity:** The method cannot present true depth of field if there are object points with varying depths closely surrounding the tracked fovea [S1].
- **Acuity Mismatch:** If the falloff in correction resolution is too rapid, it will exceed the eye's natural acuity falloff, causing visible artifacts [S1].
- **Performance:** While faster than full spatially variant computation, it may not run at high video rates on all current GPUs [S1].

## Subtopics

### [Aberration and Vision Correction via Zernike Polynomials](14597-aberration-and-vision-correction-via-zernike-polynomials.md)
This method pre-compensates for optical aberrations in display hardware and vision deficiencies in the viewer by shaping the wavefront for each object point using Zernike polynomials. It builds on [Foveated Spatially Varying Lens Approximation](14591-foveated-spatially-varying-lens-approximation.md) by replacing the simple lens phase function with a parameterized wavefront correction that offers practically unlimited degrees of freedom for spatially variant correction.

## Operating characteristics
- **Time Complexity:** Nearly the same as the fixed lens phase function case, as only one lens function needs to be recomputed per frame [S1].
- **Memory Complexity:** Requires storage for the object plane, the hologram, and the lens phase functions. No additional large data structures are mentioned [S1].
- **Performance:** Very fast when performed on the GPU, but may not achieve high video rates on all current hardware [S1].
- **Strengths:** Smooth and continuous falloff of aberration correction outside the foveal region; avoids sharp phase discontinuities found in piece-wise methods [S1].
- **Limitations:** Cannot present true depth of field for closely spaced points at varying depths around the fovea; limited by the eye's visual acuity falloff [S1].
- **When to Use:** When computational resources are limited and the user's gaze is tracked, and true depth of field for closely spaced objects is not critical.

## Background
This method was introduced in the context of holographic near-eye displays for virtual and augmented reality [S1]. It was implemented on holographic display prototypes, with eye position simulated using a mouse cursor in lieu of an actual eye tracker [S1]. The method addresses the accommodation-convergence conflict by adjusting focus and addressing aberrations, while approximating depth of field in image space [S1].
