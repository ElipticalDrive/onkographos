# Customized Quicksort for Visibility Sorting
Also called: Customized Quicksort

## Overview
This method performs visibility sorting of tetrahedral cells by sorting them based on their tangential distances to circumscribing spheres, as described by Cignoni et al. and Karasick et al. It differs from generic sorting routines by using a custom implementation that efficiently handles the specific data structures required for this geometric sort, yielding significant performance improvements over standard library functions like `qsort()`.

## How it works
**Inputs:** A set of tetrahedral cells, each defined by its vertices, and a current viewpoint position.
**Outputs:** A list of tetrahedral indices sorted by increasing tangential squared distance from the viewpoint.

**Data Structures:**
The sorting algorithm operates on an array of structures. Each element in the array contains exactly two fields:
1.  `tangential_squared_distance`: A `float` representing the squared tangential distance from the viewpoint to the cell's circumscribing sphere.
2.  `tetrahedral_index`: An integer identifier for the tetrahedron.

**Algorithm Steps:**
1.  **Precompute Geometric Data:** For each tetrahedron, compute the center and radius of its circumscribing sphere. [S1, unofficial]
2.  **Compute Keys:** For the current viewpoint, calculate the tangential squared distance for each tetrahedron. The tangential distance $d_t$ from a point $P$ to a sphere with center $C$ and radius $r$ is derived from the power distance. The squared tangential distance is used as the sort key. [S1, unofficial]
3.  **Initialize Sort Array:** Create an array of pairs `(tangential_squared_distance, tetrahedral_index)` for all cells.
4.  **Execute Custom Quicksort:** Sort the array based on the `tangential_squared_distance` field using a custom quicksort implementation. The implementation must swap both the distance value and the index together to maintain correspondence. [S1, unofficial]
    *   *Note:* The custom implementation is specifically optimized to handle the two-value structure, avoiding the overhead of generic comparators. [S1, unofficial]
5.  **Output:** Return the sorted list of `tetrahedral_index` values.

**Parameters:**
*   Pivot selection strategy: Not specified in the sources, but the method notes that "proper choice of pivots" is critical for efficiency on sorted/nearly sorted data. [S1, unofficial]

**Edge Cases and Pitfalls:**
*   **Viewpoint Recalculation:** The tangential distance depends on the viewpoint. The "thick vertex" (or equivalent geometric proxy) must be recomputed for every new viewpoint, preventing the use of static display lists or vertex arrays for this specific sorting step. [S1, unofficial]
*   **Precision:** The sort key is a `float`. Standard floating-point precision is used. [S1, unofficial]

**Pseudocode:**
```python
def customized_quicksort_sort_cells(tetrahedra, viewpoint):
    """
    Sorts tetrahedra by tangential squared distance to viewpoint.
    tetrahedra: List of objects with vertices and precomputed circumsphere (center, radius).
    viewpoint: 3D vector (x, y, z).
    Returns: List of tetrahedral indices sorted by distance.
    """
    n = len(tetrahedra)
    # Data structure: list of tuples (distance, index)
    sort_keys = []
    
    for i in range(n):
        tet = tetrahedra[i]
        # Compute tangential squared distance
        # d_t^2 = |P - C|^2 - r^2
        # where P is viewpoint, C is circumsphere center, r is radius
        dx = viewpoint.x - tet.circumsphere.center.x
        dy = viewpoint.y - tet.circumsphere.center.y
        dz = viewpoint.z - tet.circumsphere.center.z
        dist_sq = dx*dx + dy*dy + dz*dz
        tangential_sq_dist = dist_sq - tet.circumsphere.radius**2
        sort_keys.append((tangential_sq_dist, i))
    
    # Custom Quicksort implementation
    # Must swap both elements of the tuple to keep index aligned with distance
    quicksort_impl(sort_keys, 0, n - 1)
    
    # Extract sorted indices
    sorted_indices = [idx for (_, idx) in sort_keys]
    return sorted_indices

def quicksort_impl(arr, low, high):
    if low < high:
        pi = partition(arr, low, high)
        quicksort_impl(arr, low, pi - 1)
        quicksort_impl(arr, pi + 1, high)

def partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        # Compare only the distance (first element of tuple)
        if arr[j][0] <= pivot[0]:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1
```

## Subtopics

### [View Coherence Optimization](14507-view-coherence-optimization.md)
Exploiting view coherence by resorting the same input using sorted values from the previous view, which speeds up sorting for sorted and nearly sorted lists.

## Operating characteristics
**Time Complexity:** Quicksort average case $O(N \log N)$, worst case $O(N^2)$ depending on pivot selection. The custom implementation reduces constant factors significantly compared to generic `qsort()`. [S1, unofficial]
**Memory Complexity:** $O(N)$ for the array of sort keys (distance + index). In-place sorting is possible if the implementation is optimized, but the sources describe moving two values, implying a standard swap-based approach. [S1, unofficial]
**Measured Performance:** The custom quicksort provides an improvement of 75% to 89% over the C library utility `qsort()`. [S1, unofficial]
**Scaling:** Performance benefits from view coherence; when viewpoint changes are small, the data is nearly sorted, and the custom quicksort runs significantly faster (rate varies between 600,000 to 2 million cells per second). [S1, unofficial]
**Strengths:** High performance for unstructured volume rendering; efficient handling of the specific two-value data structure. [S1, unofficial]
**Limitations:** Requires recomputation of geometric data (tangential distances) for every new viewpoint, preventing caching in display lists. [S1, unofficial]

## Background
This method is described in the context of unstructured volume rendering techniques, specifically for sorting tetrahedral cells. It builds on the power distance sort concept introduced by Cignoni et al. and Karasick et al. The specific comparison against `qsort()` and the performance metrics are documented in Meissner's tutorial on volume visualization and rendering techniques. [S1, unofficial]
