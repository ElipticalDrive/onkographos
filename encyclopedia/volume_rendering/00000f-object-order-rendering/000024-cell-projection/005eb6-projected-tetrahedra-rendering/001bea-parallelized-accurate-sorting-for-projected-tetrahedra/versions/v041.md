# Parallelized Accurate Sorting for Projected Tetrahedra

Also called: Logical partition sorting, Quick and accurate sorting algorithm of tetrahedral datasets

## Overview
Parallelized Accurate Sorting is a view-dependent sorting algorithm for tetrahedral datasets that uses logical partitioning to enable parallel processing, solving the dependency and sequence limitations of neighboring tetrahedra in parallel performance [S1, unofficial]. It sets itself apart from its siblings by introducing spatial partitioning to enable parallel sorting without write access violations, and temporal staging to satisfy varying user requirements and increase cognition [S1, unofficial][S2, unofficial]. It builds on [Projected Tetrahedra Rendering](17711-projected-tetrahedra-rendering.md) by addressing the scalability limits of sorting large datasets through distributed or cloud-based architectures [S1, unofficial][S2, unofficial].

## How it works
The method projects tetrahedral datasets orderly to get a rendering result, enhancing the parallelization of topological sorting [S1, unofficial]. The algorithm takes 4 sequential steps [S1, unofficial].

**Inputs and Outputs:**
*   **Input:** A tetrahedral dataset (set of tetrahedra $T$) and a viewing direction vector $\vec{v}$.
*   **Output:** A sorted list of tetrahedra ordered by depth along $\vec{v}$, ready for optical accumulation.

**Data Structures:**
*   **Blocks:** A list of spatial blocks partitioned along the viewing direction. Each block contains a subset of tetrahedra.
*   **Layers:** Unobstructed layers of tetrahedra peeled from the blocks.
*   **Boundary Tetrahedra:** Tetrahedra located at the interface between blocks, requiring logical partitioning.

**Steps:**

1.  **Divide the space:** Divide the space containing tetrahedral datasets into a list of blocks along the viewing direction, with every block containing a subset of tetrahedra [S1, unofficial][S2, unofficial].
2.  **Sort accurately:** Sort tetrahedra accurately by peeling tetrahedral subsets into unobstructed layers in parallel [S1, unofficial][S2, unofficial]. This step addresses the dependency of neighboring tetrahedra by processing independent layers concurrently.
3.  **Partition and Compute:** Partition tetrahedra on the boundary logically. Compute the optical contribution of each subset with segment integration [S1, unofficial][S2, unofficial]. This ensures correct blending across block boundaries where parallel processing might otherwise cause artifacts or order violations.
4.  **Accumulate:** Accumulate the optical contribution of each subset along the viewing direction [S1, unofficial][S2, unofficial].

*   **Performance:** GPU implementation of the parallelized accurate sorting scheme achieves 91% acceleration compared with the CPU implementation [S1, unofficial].
*   **Scalability:** The early tetrahedron termination scheme has a gain of more than 10% in terms of rendering performance for datasets with more than a million tetrahedra [S1, unofficial].
*   **Sorting Time:** The algorithm reduces sorting time largely and improves rendering performance greatly compared to previous methods [S1, unofficial][S2, unofficial].
*   **Strengths:** Enhances parallelization of topological sorting, solves dependency issues, and is view-dependent.
*   **Limitations:** Requires logical partitioning for boundary tetrahedra, which may add complexity.
