# Dual Subgrid Pipeline

## Overview
The Dual Subgrid Pipeline extracts an isosurface from a scalar function defined on a triangle mesh or Signed Distance Field (SDF) by constructing a dual mesh representation within a tetrahedral grid [S1, unofficial]. It processes tetrahedra individually to generate a triangle soup, querying edge intersections and constructing boundary curves (open, scoop, normal) before generating the final surface via a Quadratic Error Function (QEF) solve or centroid placement [S1, unofficial]. It is distinguished from its parent, Subgrid Surface Reconstruction, by its explicit use of a dual grid structure to resolve topological ambiguities and its support for robust intersection queries with optional regularization [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
1. **Source Data:** Exactly one of the following: a triangle mesh file (OBJ, OFF, PLY) [S1, unofficial], a named built-in SDF (e.g., Sphere, Torus) [S1, unofficial], or a precomputed `.npz` file containing tetrahedral mesh data and precomputed intersections [S1, unofficial].
2. **Configuration:** `DualSubgridPipelineOpts` struct [S1, unofficial].
3. **Grid Resolution:** `tetGridResolution` ($n^3$), default 64 [S1, unofficial].

**Outputs:**
* `DualSubgridPipelineResult` struct containing: `soup` (TriangleSoup), `non_zero_tets` (int), `total_tets` (int), `non_normal_tets` (int), `non_even_tets` (int), `isect_time` (double), `construction_time` (double) [S1, unofficial].
* Optionally, a saved OBJ mesh file [S1, unofficial].

### Data Structures

**DualSubgridPipelineOpts**
Fields:
* `mod2` (bool): Use mod2 intersection reduction [S1, unofficial].
* `use_robust` (bool): Enable robust ray-intersection queries (FCPW watertight test + iterative all-hits). Always `false` in standard builds due to performance cost (~2x slower) with negligible robustness gain [S1, unofficial].
* `show_progress` (bool): Display progress bar [S1, unofficial].
* `reg_alpha` (double): Regularization weight for QEF solve. Default 0.1 [S1, unofficial].
* `project_duals` (bool): Project dual vertices to the local grid cell [S1, unofficial].
* `no_normal` (bool): Ignore normals; place dual points at boundary-polygon centroids. Required for `.npz` inputs lacking normals [S1, unofficial].

**DualSubgridPipelineResult**
Fields: `soup`, `non_zero_tets`, `total_tets`, `non_normal_tets`, `non_even_tets`, `isect_time`, `construction_time` [S1, unofficial].

**Edge Intersection Data**
Stored in two arrays indexed by edge pair (0-5):
* `edge_isect_ts`: `std::array<std::vector<double>, 6>` storing intersection parameters ($t$) [S1, unofficial].
* `edge_isect_normals`: `std::array<std::vector<Vector3>, 6>` storing intersection normals [S1, unofficial].

**Edge Index Mapping**
Edges are mapped to indices 0-5 based on vertex pairs $(v_i, v_j)$ where $i < j$: 0: $(0, 1)$, 1: $(0, 2)$, 2: $(0, 3)$, 3: $(1, 2)$, 4: $(1, 3)$, 5: $(2, 3)$ [S1, unofficial].

### Algorithm Steps

1. **Input Validation and Preprocessing:** Ensure exactly one input mode is active (`--input`, `--inputSDF`, or `--npz`) [S1, unofficial]. If input is a mesh, read it into a `SimplePolygonMesh`, normalize scale to 0.98, and apply rigid decorrelation translation using a seed (default 1) [S1, unofficial]. If input is `.npz`, verify it was passed via `--npz`, not `-i` [S1, unofficial].
2. **Query Handler Initialization:** Create `InputQueryHandler` based on input type: `SDFQueryHandler` for SDFs (epsilon $\epsilon = 10^{-3}$) [S1, unofficial], `MeshQueryHandler` for standard meshes [S1, unofficial], or `CGALQueryHandler` if `--cgal` flag is set (requires build with `-DSUBGRID_WITH_CGAL=ON`) [S1, unofficial].
3. **Pipeline Execution Loop:** Iterate over each tetrahedron $T$ in the tetrahedral grid range [S1, unofficial].
   * **Query Intersections:** For all 6 edges of $T$, query the `InputQueryHandler` for intersections [S1, unofficial]. Store parameters $t$ and normals $n$ [S1, unofficial]. Call handler with `recordNormals = !opts.no_normal` [S1, unofficial].
   * **Count Intersections:** Use `counts_from_isect_ts` to count intersections per edge [S1, unofficial]. If the sum of counts is 0, skip $T$ [S1, unofficial].
   * **Mod2 Reduction:** If `opts.mod2` is true, apply mod2 reduction to intersection data [S1, unofficial]. If this results in a skip condition, continue to next $T$ [S1, unofficial].
   * **Construct Boundary Curves:** Call `boundary_comb_curves` using intersection data [S1, unofficial]. This returns `open_curves`, `scoop_curves`, `normal_curves`, and populates `edge_occupations` [S1, unofficial].
   * **Generate Local Surface:** Call `dual_subgrid_surface` with tetrahedron positions, indices, intersection data, curves, and options (`reg_alpha`, `project_duals`, `use_normals`) [S1, unofficial]. If `opts.no_normal` is true, place each dual point at the centroid of the boundary polygon [S1, unofficial]. Otherwise, solve the QEF to determine dual vertex positions [S1, unofficial].
   * **Accumulate Result:** If `local_soup.faces` is not empty, append it to the global result soup [S1, unofficial].
4. **Post-Processing:** Construct primal and dual meshes from face-per-edge data [S1, unofficial]. If the primal mesh is not manifold, throw an error [S1, unofficial]. Optionally save the dual mesh as an OBJ file [S1, unofficial].

def run_dual_subgrid_pipeline(input_source, opts, tet_grid_resolution):
    # 1. Input Handling
    if input_source.type == 'mesh':
        mesh = load_mesh(input_source.path)
        mesh.scale *= 0.98
        mesh.translate_decorrelated(seed=1)
        query_handler = MeshQueryHandler(mesh)
    elif input_source.type == 'sdf':
        query_handler = SDFQueryHandler(input_source.name, epsilon=1e-3)
    elif input_source.type == 'npz':
        raise NotImplementedError("NPZ handling uses a separate pipeline function.")
    else:
        raise ValueError("Exactly one input mode (--input, --inputSDF, or --npz) must be provided.")

    tet_grid = generate_tetrahedral_grid(tet_grid_resolution)
    global_soup = TriangleSoup(vertices=[], faces=[])
    total_tets = 0
    non_zero_tets = 0
    non_even_tets = 0
    non_normal_tets = 0
    start_time = time.time()

    # 2. Main Loop
    for tet in tet_grid:
        total_tets += 1
        tet_indices = tet.vertex_indices
        tet_positions = tet.vertex_positions
        edge_isect_ts = [[] for _ in range(6)]
        edge_isect_normals = [[] for _ in range(6)]
        edge_pairs = [(0,1), (0,2), (0,3), (1,2), (1,3), (2,3)]

        for edge_idx, (v_i, v_j) in enumerate(edge_pairs):
            ts, normals = query_edge_intersections(query_handler, tet_positions[v_i], tet_positions[v_j])
            edge_isect_ts[edge_idx] = ts
            if not opts.no_normal:
                edge_isect_normals[edge_idx] = normals

        counts = [len(ts) for ts in edge_isect_ts]
        if sum(counts) == 0:
            continue
        non_zero_tets += 1

        if opts.mod2:
            for i in range(6):
                edge_isect_ts[i] = edge_isect_ts[i][:len(edge_isect_ts[i]) % 2]
            if sum(len(ts) for ts in edge_isect_ts) == 0:
                continue

        open_curves, scoop_curves, normal_curves, edge_occupations = \
            boundary_comb_curves(edge_isect_ts, edge_isect_normals, opts)

        local_soup = dual_subgrid_surface(
            tet_positions=tet_positions,
            tet_indices=tet_indices,
            edge_isect_ts=edge_isect_ts,
            edge_isect_normals=edge_isect_normals,
            open_curves=open_curves,
            scoop_curves=scoop_curves,
            normal_curves=normal_curves,
            opts=opts
        )

        if len(local_soup.faces) > 0:
            global_soup.vertices.extend(local_soup.vertices)
            global_soup.faces.extend(local_soup.faces)

    end_time = time.time()
    construction_time = end_time - start_time

    return DualSubgridPipelineResult(
        soup=global_soup,
        non_zero_tets=non_zero_tets,
        total_tets=total_tets,
        non_normal_tets=non_normal_tets,
        non_even_tets=non_even_tets,
        isect_time=0.0,
        construction_time=construction_time
    )

def dual_subgrid_surface(tet_positions, tet_indices, edge_isect_ts, edge_isect_normals,
                         open_curves, scoop_curves, normal_curves, opts):
    local_soup = TriangleSoup(vertices=[], faces=[])
    dual_vertices = []
    all_curves = open_curves + scoop_curves + normal_curves

    for curve in all_curves:
        if opts.no_normal:
            centroid = compute_centroid(curve.vertices)
            dual_vertices.append(centroid)
        else:
            A, b = build_qef_system(curve, edge_isect_normals)
            alpha = opts.reg_alpha
            I3 = np.eye(3)
            dual_vertex = np.linalg.solve(A.T @ A + alpha * I3, A.T @ b)
            if opts.project_duals:
                dual_vertex = project_to_local_grid_cell(dual_vertex, tet_positions)
            dual_vertices.append(dual_vertex)

    faces = generate_faces_from_curves_and_duals(all_curves, dual_vertices)
    local_soup.vertices = dual_vertices
    local_soup.faces = faces
    return local_soup

def query_edge_intersections(handler, p0, p1):
    d = np.array(p1) - np.array(p0)
    ts, normals = [], []
    for tri in handler.mesh.faces:
        v0, v1, v2 = handler.mesh.vertices[tri[0]], handler.mesh.vertices[tri[1]], handler.mesh.vertices[tri[2]]
        e1, e2 = np.array(v1) - np.array(v0), np.array(v2) - np.array(v0)
        n = np.cross(e1, e2)
        denom = np.dot(d, n)
        if abs(denom) > 1e-8:
            f = 1.0 / denom
            s = np.array(p0) - np.array(v0)
            u = f * np.dot(s, n)
            v = f * np.dot(np.cross(d, s), e2)
            w = f * np.dot(np.cross(e1, s), e1)
            if 0 <= u <= 1 and 0 <= v <= 1 and 0 <= u + v <= 1:
                t = f * np.dot(s, e2)
                if 0 <= t <= 1:
                    ts.append(t)
                    normals.append(n / np.linalg.norm(n))
    return ts, normals

def build_qef_system(curve, normals):

    b = []
    for edge in curve.edges:
        n = edge.normal
        p = edge.midpoint
        A.append(n)
        b.append(np.dot(n, p))
    return np.array(A), np.array(b)

    return np.clip(point, np.min(tet_pos, axis=0), np.max(tet_pos, axis=0)).tolist()

### Parameters
* `tetGridResolution`: Integer $n$. The grid is $n \times n \times n$ tetrahedra [S1, unofficial]. Default: 64 [S1, unofficial].
* `regAlpha`: Double. Regularization weight for QEF [S1, unofficial]. Default: 0.1 [S1, unofficial].
* `mod2`: Boolean. Enables mod2 intersection reduction [S1, unofficial].
* `projectDuals`: Boolean. Projects dual vertices to the local grid cell [S1, unofficial].
* `noNormal`: Boolean. Ignores normals, using centroid placement [S1, unofficial]. Required for `.npz` inputs without normals [S1, unofficial].
* `USE_ROBUST_QUERIES`: Static boolean. Always `false` in standard builds [S1, unofficial].

### Edge Cases and Pitfalls
* **Even-Sum Condition:** If `result.non_even_tets > 0`, the output may not be orientable and may have open holes [S1, unofficial]. This is likely caused by a non-watertight input or a grid edge-intersection issue [S1, unofficial]. Changing the resolution or perturbation may help [S1, unofficial].
* **NPZ Input Normals:** If loading from `.npz` and `opts.no_normal` is `false`, the `.npz` file must contain an `isect_normals` array [S1, unofficial]. If missing, a runtime error is thrown [S1, unofficial].
* **Robust Queries:** Enabling robust queries (`USE_ROBUST_QUERIES = true`) makes the method ~2x slower with negligible effect on robustness, so it is disabled by default [S1, unofficial].
* **Input Mode Conflict:** Passing a `.npz` file via `--input` (or `-i`) instead of `--npz` causes an error [S1, unofficial].

## Operating characteristics

### Time and Memory Complexity
* **Time Complexity:** Linear with respect to the number of tetrahedra in the grid, $O(n^3)$, where $n$ is `tetGridResolution` [G]. Each tetrahedron is processed independently [G].
* **Memory Complexity:** Linear with respect to the number of tetrahedra and the number of intersections per edge [G]. The `TriangleSoup` size depends on the surface area relative to the grid resolution [G].

### Measured Performance
* Not given in the sources. The source provides timing breakdowns (query, construction, primal, dual) but no absolute performance metrics for specific hardware or resolutions [S1, unofficial].

### Scaling
* Scaling is determined by the grid resolution $n$ [G]. Higher resolutions increase accuracy but linearly increase the number of tetrahedra and thus computation time and memory usage [G].

### Strengths and Limitations
* **Strengths:** Robust intersection queries (when enabled, though disabled by default), support for both mesh and SDF inputs, optional regularization for smooth dual vertex placement, and mod2 reduction for topological simplification [S1, unofficial].
* **Limitations:** Potential for non-orientable output if the even-sum condition is not met, dependency on grid resolution for accuracy, and performance cost of robust queries (if enabled) [S1, unofficial].

### When to Use
* Use when extracting isosurfaces from complex meshes or SDFs where topological robustness is critical, and when a dual grid representation is preferred for subsequent processing (e.g., dual mesh construction) [S1, unofficial].

### When Not to Use
* Avoid if real-time performance is critical and robust queries are needed (due to ~2x slowdown) [S1, unofficial]. Avoid if the input is known to be non-watertight and the even-sum condition cannot be satisfied [S1, unofficial].

## Background

### Origin
The Dual Subgrid Pipeline is part of the Subgrid Marching framework, developed by H. Baktash [S1, unofficial]. It is described in the repository `hbaktash/subgrid-marching` [S1, unofficial].

### History and Development
The method is an evolution of the Subgrid Surface Reconstruction technique, introducing a dual mesh representation to handle complex intersection patterns within tetrahedral cells [S1, unofficial]. It supports various input types (mesh, SDF, precomputed NPZ) and offers configurable options for regularization and normal handling [S1, unofficial].

### Usage
It is used in computer graphics for isosurface extraction, particularly in contexts requiring robust handling of topological ambiguities and integration with dual mesh structures [S1, unofficial].
