# McGrids

Also called: Monte Carlo-Driven Adaptive Grids

## Overview
McGrids is an iso-surface extraction method that constructs adaptive, non-uniform tetrahedral grids using an iterative Monte Carlo process to estimate a probability density function (PDF) based on the implicit field, followed by a refinement step and mesh extraction via [Marching Tetrahedrons Algorithm](940-marching-tetrahedrons-algorithm.md) [S1]. It solves the problem of inefficient uniform grid sampling by concentrating grid points near surfaces and geometric details, significantly reducing the number of implicit field queries and memory usage compared to uniform grids [S1]. Unlike [Regularised Marching Tetrahedra](1301-regularised-marching-tetrahedra.md) or [Subgrid Pipeline](1640-subgrid-pipeline.md) which may rely on fixed or hierarchical structures, McGrids dynamically adapts the grid topology through probabilistic sampling and Centroidal Voronoi Tessellation (CVT) relaxation [S1].

## How it works
**Inputs:**
*   Implicit field function $f(\mathbf{x})$ returning a scalar value [S1].
*   Iso-value $\alpha$ (typically 0) [S1].
*   Bounding region (user-defined) [S1].
*   Terminating threshold $\tau$ (default $10^{-4}$, typical range $10^{-3}$ to $10^{-5}$) [S1].
*   Maximum number of Monte Carlo iterations $N_{iter}$ (optional, used if termination condition is not met) [S1].
*   Minimum tetrahedron volume constraint $V_{min}$ (optional, for fractal surfaces) [S1].

**Outputs:**
*   A set of vertices $\mathcal{V}$ forming a Delaunay tetrahedralization [S1].
*   A mesh extracted via Marching Tetrahedra [S1].

**Data Structures:**
1.  **Delaunay Tetrahedralization:** Stores grid points as vertices. Tetrahedra $\mathcal{T}$ are formed such that no point lies inside the circumsphere of any tetrahedron [S1].
2.  **Voronoi Diagram (Dual):** One-to-one mapping to McGrid points. Voronoi cells $\Omega_i$ store the implicit values and density information [S1].
3.  **Implicit Values:** Stored in Voronoi cells corresponding to vertices [S1].

**Algorithm Steps:**

1.  **Initialization:**
    *   Define a continuous uniform distribution over the user-defined bounding region [S1].
    *   Initialize an empty Delaunay tessellation [S1].

2.  **Monte Carlo Grid Generation (Iterative):**
    Repeat for $k = 1$ to $N_{iter}$:
    
    2.1. **PDF Estimation:**
    *   For each vertex $x_i$ with Voronoi cell $\Omega_i$, compute the discrete probability $p(i)$:
        $$ p(i) = d(x_i) \cdot \frac{\int_{\Omega_i} \mathbf{x} \, d\mathbf{x}}{\sum_{j=1}^n \int_{\Omega_j} \mathbf{x} \, d\mathbf{x}} $$
        where $d(x_i)$ is the density value at point $x_i$, and the integral represents the volume of the Voronoi region $\Omega_i$ [S1].
    *   Normalize to create a cumulative distribution: $p'(i) = p(i) / \sum_{j=1}^n p(j)$ [S1].
    *   *Optimization:* When new points are inserted, only update the volumes of Voronoi cells adjacent to the newly inserted cells [S1].

    2.2. **Weighted Random Sampling:**
    *   Sample a uniform random number $u \sim U[0, 1]$ [S1].
    *   Select a Voronoi region $\Omega_i$ based on the cumulative distribution $p'(i)$ [S1].
    *   **Tessellate $\Omega_i$ into tetrahedra.** [S1]
    *   Calculate the volume of each tetrahedron within $\Omega_i$ to form a discrete cumulative distribution. [S1]
    *   Sample a uniform number to select a specific tetrahedron $T_{sel} \subset \Omega_i$. [S1]
    *   Sample a new point $\mathbf{x}_{new}$ uniformly within $T_{sel}$. [S1]

    2.3. **CVT Relaxation:**
    *   Compute the centroid of the Voronoi region $\Omega_{new}$ corresponding to $\mathbf{x}_{new}$. [S1]
    *   Move $\mathbf{x}_{new}$ to this centroid position. This is Lloyd's method for stable CVT [S1].

    2.4. **Insertion and Update:**
    *   Insert the relaxed point $\mathbf{x}_{new}$ into the Delaunay tessellation [S1].
    *   Query the implicit field: $v_{new} = f(\mathbf{x}_{new})$ [S1].
    *   Store $v_{new}$ in the corresponding Voronoi cell [S1].
    *   Interpolate point density values to the tetrahedra in the entire space and normalize them by their volumes to form a piecewise linear approximation of the PDF [S1].

3.  **Refinement (Midpoint Insertion):**
    For each tetrahedron $T \in \mathcal{T}$:
    
    3.1. **Trimming (Void Culling):**
    *   If all four vertices of $T$ have implicit values with the same sign (all $> \alpha$ or all $< \alpha$), the tetrahedron does not intersect the surface [S1].
    *   Set the probability density values of its incident vertices to 0 to prevent further sampling in void regions [S1].

    3.2. **Midpoint Evaluation:**
    *   If vertices have mixed signs (surface intersects $T$):
        *   Perform linear interpolation on edges to find points $\mathbf{p}_j$ where $f(\mathbf{p}_j) = \alpha$ [S1].
        *   Calculate the geometric midpoint $\mathbf{m}$ by averaging the positions of these interpolated points:
            $$ \mathbf{m} = \frac{1}{N_{edges}} \sum \mathbf{p}_j $$
        *   Evaluate the true implicit value at the midpoint: $v_m = f(\mathbf{m})$ [S1].
        *   Calculate error: $e = |v_m - \alpha|$ [S1].

    3.3. **Insertion Condition:**
    *   If $e > \tau$ AND $\text{Vol}(T) > V_{min}$:
        *   Insert $\mathbf{m}$ into the McGrids [S1].
        *   Apply CVT relaxation to $\mathbf{m}$ (move to centroid of its new Voronoi region) [S1].
        *   Query $f(\mathbf{m})$ and update the tessellation [S1].
    *   Else, consider $T$ adequately refined [S1].

4.  **Termination:**
    *   Stop refining when all tetrahedra meet the criteria ($e \le \tau$ or $\text{Vol}(T) \le V_{min}$) [S1].
    *   In extreme cases (e.g., fractal surfaces), enforce $V_{min}$ to prevent excessive refinement [S1].

5.  **Mesh Extraction:**
    *   Apply the [Marching Tetrahedrons Algorithm](940-marching-tetrahedrons-algorithm.md) to the final Delaunay tetrahedralization to extract the iso-surface mesh [S1].

def mcgrids_extraction(implicit_field, alpha, bounding_box, threshold, max_iterations, min_volume=None):
    # 1. Initialization
    vertices = []
    tetrahedra = []
    voronoi_volumes = []
    
    # Insert boundary points to define the domain [G]
    for corner in bounding_box.corners:
        vertices.append({'pos': corner, 'value': implicit_field.query(corner), 'density': 1.0})
        voronoi_volumes.append(compute_voronoi_volume(vertices[-1], vertices, tetrahedra))
        tetrahedra.extend(rebuild_delaunay(vertices))

    # 2. Monte Carlo Generation
    for iteration in range(max_iterations):
        # 2.1 PDF Estimation
        probabilities = [v['density'] * vol for v, vol in zip(vertices, voronoi_volumes)]
        total_prob = sum(probabilities)
        cum_probs = [sum(probabilities[:i+1]) / total_prob for i in range(len(probabilities))]
        
        # 2.2 Weighted Random Sampling
        r = random.uniform(0, 1)
        region_index = bisect_right(cum_probs, r)
        target_vertex = vertices[region_index]
        
        # Tessellate the selected Voronoi region into tetrahedra [S1]
        region_tets = tessellate_voronoi_region(target_vertex, vertices, tetrahedra)
        tet_probs = [compute_tet_volume(t) for t in region_tets]
        tet_cum_probs = [sum(tet_probs[:i+1]) / sum(tet_probs) for i in range(len(tet_probs))]
        r_tet = random.uniform(0, 1)
        tet_index = bisect_right(tet_cum_probs, r_tet)
        selected_tet = region_tets[tet_index]
        
        # Sample uniformly within tetrahedron using barycentric coordinates [G]
        r1, r2, r3 = random.random(), random.random(), random.random()
        if r1 + r2 + r3 > 1:
            r1, r2, r3 = 1 - r1, 1 - r2, 1 - r3
        new_point = selected_tet.v0 + r1 * (selected_tet.v1 - selected_tet.v0) + \
                    r2 * (selected_tet.v2 - selected_tet.v0) + \
                    r3 * (selected_tet.v3 - selected_tet.v0)
        
        # 2.3 CVT Relaxation
        centroid = compute_voronoi_centroid(new_point, vertices, tetrahedra)
        new_point = centroid
        
        # 2.4 Insertion
        vertices.append({'pos': new_point, 'value': implicit_field.query(new_point), 'density': 1.0})
        new_vol = compute_voronoi_volume(vertices[-1], vertices, tetrahedra)
        voronoi_volumes.append(new_vol)
        tetrahedra = rebuild_delaunay(vertices)
        
        # Update PDF: interpolate densities to tetrahedra and normalize by volumes [S1]
        update_pdf_from_volumes(tetrahedra, voronoi_volumes)

    # 3. Refinement
    for tet in tetrahedra:
        signs = [v['value'] > alpha for v in tet.vertices]
        
        if all(signs) or not any(signs):
            for v in tet.vertices:
                v['density'] = 0.0
            continue
            
        edge_intersections = []
        for edge in tet.edges:
            p1, p2 = edge.vertices
            if (p1['value'] - alpha) * (p2['value'] - alpha) < 0:
                t = (alpha - p1['value']) / (p2['value'] - p1['value'])
                interp_point = lerp(p1['pos'], p2['pos'], t)
                edge_intersections.append(interp_point)
        
        if not edge_intersections:
            continue
            
        midpoint = sum(edge_intersections) / len(edge_intersections)
        midpoint_value = implicit_field.query(midpoint)
        error = abs(midpoint_value - alpha)
        
        if error > threshold and (min_volume is None or tet.volume > min_volume):
            vertices.append({'pos': midpoint, 'value': midpoint_value, 'density': 1.0})
            voronoi_volumes.append(compute_voronoi_volume(vertices[-1], vertices, tetrahedra))
            tetrahedra = rebuild_delaunay(vertices)
            
            centroid = compute_voronoi_centroid(midpoint, vertices, tetrahedra)
            vertices[-1]['pos'] = centroid
            tetrahedra = rebuild_delaunay(vertices)

    # 4. Mesh Extraction
    mesh = marching_tetrahedra(tetrahedra, alpha)
    return mesh

## Subtopics

### CVT Relaxation
A technique used within McGrids to enhance grid regularity. It moves sampled points to the centroid of their Voronoi regions (Lloyd's method), reducing interpolation error and accelerating convergence compared to non-relaxed Monte Carlo sampling [S1].

### Midpoint Refinement
A strategy to densify grids near surfaces. It evaluates the implicit value at the geometric midpoint of surface-intersecting tetrahedra and inserts it if the error exceeds a threshold, providing a curvature-like approximation without explicit normal information [S1].

## Operating characteristics
*   **Time Complexity:** Dominated by the iterative Monte Carlo process and Delaunay/Voronoi updates. Each iteration involves sampling, tessellation, and relaxation. The refinement step adds overhead proportional to the number of surface-intersecting tetrahedra [S1].
*   **Memory Complexity:** Proportional to the number of grid points and tetrahedra. Significantly lower than uniform grids for the same accuracy, as points are concentrated near the surface [S1].
*   **Measured Performance:** On the 'Lucy' model with threshold $10^{-3}$, McGrids with CVT required 15 iterations and 228,472 queries, while without CVT it required 58 iterations and 319,185 queries [S1]. On a dataset of complex meshes (resolution $256^3$ equivalent), McGrids (threshold $10^{-3}$) achieved Chamfer Distance (CD) 0.54, Normal Consistency (NC) 0.94, Time 2.12s, Memory 0.91G, compared to Marching Cubes (MC) (12.85s, 2.57G) and Neural Dual Contouring (NDC) (76.89s, 21.76G) [S1].
*   **Strengths:** Reduces implicit field queries and memory usage; produces high-quality meshes with rich geometric details; adaptive to complex shapes [S1].
*   **Limitations:** Slower runtime than fixed-grid methods (like standard DMT or FlexiCubes) due to dynamic grid computation; does not assume normal information, potentially requiring denser grids than Dual Contouring for sharp features; incurs overhead for grid construction [S1].
*   **When to use:** When high accuracy and detail are required, and implicit field queries are expensive. Suitable for neural implicit fields and complex analytical SDFs [S1].
*   **When not to use:** For low-resolution meshes or when implicit field queries are extremely cheap; conventional methods like Marching Cubes may be more efficient [S1].

## Background
McGrids was proposed in the paper "McGrids: Monte Carlo-Driven Adaptive Grids for Iso-Surface Extraction" [S1]. It addresses the limitations of uniform grids in iso-surface extraction by formulating grid construction as a probability sampling problem. The method leverages Delaunay tetrahedralization and Voronoi diagrams to guide the adaptive sampling process. It has been applied in differentiable multiview reconstruction pipelines, replacing mesh extraction components in methods like DMT and FlexiCubes to achieve more accurate reconstruction results [S1].
