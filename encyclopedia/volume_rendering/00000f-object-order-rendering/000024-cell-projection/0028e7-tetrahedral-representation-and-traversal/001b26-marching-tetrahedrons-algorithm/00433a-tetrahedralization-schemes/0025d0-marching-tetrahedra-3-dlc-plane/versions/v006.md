# Marching Tetrahedra 3 (DLC-Plane)

Also called: 5-Tetrahedron Cell, Diamond Crystal Lattice Tetrahedralization, Diamond Lattice Mesh, Dual Marching Tetrahedra - Diamond Lattice Crystal (DMT-DLC)

## Overview
Marching Tetrahedra 3 (DLC-Plane) is a volume meshing method that extracts isosurfaces from voxel or point-cloud data using a diamond crystal lattice decomposition [S2, unofficial]. It replaces standard cubic cells with a structure of exactly 5 tetrahedra per cell, requiring only 5 vertex points and no fabricated center points [S1, S2, unofficial]. This approach eliminates the creases and indentations associated with synthesizing center points in cuboctohedral or parallel-piped approaches, yielding smooth results for opening spaces and void areas [S1, S2, unofficial]. It operates by slicing the data plane-by-plane, generating a single calculation for all shared points to reduce total point count and improve merged point handling [S2, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   A 3D grid of scalar values (density) [S2, unofficial].
*   Isosurface threshold $T$ (typically 0) [S2, unofficial].
*   Configuration flag: `zero_as_inside` (boolean) [S2, unofficial]. If true, values $\le 0$ are inside; if false, values $> 0$ are inside [S2, unofficial].
*   For distance-to-surface point clouds, density is defined as $-distance$ [S1, S2, unofficial].

**Outputs:**
*   A triangle mesh representing the isosurface [S1, unofficial].
*   Vertex positions, normals, and optional texture coordinates [S2, unofficial].

### Data Structures
The algorithm processes cells based on a diamond crystal lattice [S1, S2, unofficial]. Each cell is defined by 5 specific vertices [S1, unofficial]. To handle vertex indexing and inversion logic efficiently, vertices are ordered such that every other point is inverted [S2, unofficial]. This allows the use of a modulo 4 operation to wrap point indexing, reducing branching logic to a single if-case [S2, unofficial]. For centroid calculations and averaging, the implementation uses a 3x3x2 matrix of values [S1, unofficial]. The tetrahedra are indexed 0-4, with vertex indices mapping to local and adjacent cells (e.g., 0134, 1245, 3467, 4578) [S1, unofficial]. The method uses exactly 5 tetrahedra with no fabricated points [S1, S2, unofficial].

### Algorithm Steps

1.  **Plane Iteration:** Iterate through the volumetric grid plane by plane [S1, S2, unofficial].
2.  **Cell Processing:** For each plane, process the tetrahedral cells [S1, unofficial].
3.  **Vertex Ordering:** Order cell vertices so that every other point is inverted [S2, unofficial]. Apply a modulo 4 operation to wrap point indexing [S2, unofficial].
4.  **Inside/Outside Determination:** Determine the status of each vertex relative to the threshold $T$ [S1, S2, unofficial].
    *   If `zero_as_inside` is false (standard): Values $\le 0$ are outside, $> 0$ are inside [S2, unofficial].
    *   If `zero_as_inside` is true: Values $\le 0$ are inside, $> 0$ are outside [S2, unofficial].
    *   The origin point is always considered outside for delta computation purposes [S1, S2, unofficial].
5.  **Edge Intersection Calculation:** For each edge of each tetrahedron in the cell:
    *   Check if the edge crosses the isosurface (i.e., vertices have different signs relative to $T$) [S1, unofficial].
    *   Calculate the delta $T$ along the line from one point to another [S1, unofficial].
    *   **Zero-Value Handling:** If a vertex value is exactly 0:
        *   If 0 is 'outside': No inversion takes place if the first point is 0. The delta computation for the slope will never be 0 if the first point is not 0 [S2, unofficial].
        *   If 0 is 'inside': Face generation is inverted [S2, unofficial]. If an input point is exactly 0, the state does not change from outside to inside [S2, unofficial]. If points 1, 2, or 3 are 0, the slope delta is forced to 0. This ensures the 0 'inside' point remains as close to itself as possible [S2, unofficial].
6.  **Sidedness Computation:** Compute sidedness purely from which values are $\le 0$ and $> 0$ [S1, unofficial].
    *   If value is from -1 to 0, direction is reversed [S1, unofficial].
    *   If value is from 0 to 1, direction is forward [S1, unofficial].
7.  **Triangle Emission:** Emit triangles for the intersections [S1, unofficial].
    *   The method emits triangles, not quads, to avoid inverted triangles due to boundary conditions [S1, unofficial].
    *   All triangles are trivially aligned with their proper normals [S1, S2, unofficial].
    *   The surface does not have to be flat [S1, unofficial].

### Pseudocode

```python
def marching_tetrahedra_dlc_plane(grid, threshold, zero_as_inside):
    """
    Extracts isosurface from grid using DLC-Plane method.
    
    Args:
        grid: 3D array of scalar values.
        threshold: Isosurface threshold (typically 0).
        zero_as_inside: Boolean. If True, <= threshold is inside. Else, > threshold is inside.
        
    Returns:
        triangles: List of triangle vertex indices.
        vertices: List of vertex positions.
        normals: List of vertex normals.
    """
    triangles = []
    vertices = []
    normals = []
    
    # Iterate through planes
    for z in range(1, grid.height - 1):
        for y in range(1, grid.width - 1):
            for x in range(1, grid.depth - 1):
                # Get the 5 points for the current cell based on diamond lattice layout
                # Indices map to local/adjacent cells (e.g., 0134, 1245, 3467, 4578)
                cell_points = get_cell_points(grid, x, y, z)
                
                # Determine inside/outside status for each vertex
                inside_status = []
                for p in cell_points:
                    val = p.scalar
                    if zero_as_inside:
                        is_inside = val <= threshold
                    else:
                        is_inside = val > threshold
                    inside_status.append(is_inside)
                
                # Process each of the 5 tetrahedra in the cell
                # Tetrahedra indices reference cell_points array
                tetrahedra = [
                    [0, 1, 3, 4],
                    [1, 2, 4, 5],
                    [3, 4, 6, 7],
                    [4, 5, 7, 8],
                    # Fifth tetrahedron index mapping not explicitly given in sources [G]
                ]
                
                for tet in tetrahedra:
                    v0 = cell_points[tet[0]]
                    v1 = cell_points[tet[1]]
                    v2 = cell_points[tet[2]]
                    v3 = cell_points[tet[3]]
                    
                    # Determine sidedness
                    s0 = get_sidedness(v0.scalar, threshold, zero_as_inside)
                    s1 = get_sidedness(v1.scalar, threshold, zero_as_inside)
                    s2 = get_sidedness(v2.scalar, threshold, zero_as_inside)
                    s3 = get_sidedness(v3.scalar, threshold, zero_as_inside)
                    
                    # Check for zero-crossings on edges and compute intersections
                    intersections = []
                    
                    # Edge 0-1
                    if s0 != s1:
                        p = interpolate(v0, v1, threshold)
                        intersections.append((p, 0, 1))
                    
                    # Edge 0-2
                    if s0 != s2:
                        p = interpolate(v0, v2, threshold)
                        intersections.append((p, 0, 2))
                        
                    # Edge 0-3
                    if s0 != s3:
                        p = interpolate(v0, v3, threshold)
                        intersections.append((p, 0, 3))
                        
                    # Edge 1-2
                    if s1 != s2:
                        p = interpolate(v1, v2, threshold)
                        intersections.append((p, 1, 2))
                        
                    # Edge 1-3
                    if s1 != s3:
                        p = interpolate(v1, v3, threshold)
                        intersections.append((p, 1, 3))
                        
                    # Edge 2-3
                    if s2 != s3:
                        p = interpolate(v2, v3, threshold)
                        intersections.append((p, 2, 3))
                        
                    # Emit triangles based on intersection points
                    emit_triangles(intersections, triangles, vertices, normals)

def get_cell_points(grid, x, y, z):
    """Returns a list of 5 Point objects for the current cell based on the 3x3x2 matrix layout."""
    # Implementation depends on the specific diamond lattice grid layout.
    # Returns points with .pos (vec3) and .scalar (float) attributes.
    return [
        Point(grid[x, y, z]), Point(grid[x+1, y, z]),
        Point(grid[x, y+1, z]), Point(grid[x+1, y+1, z]),
        Point(grid[x, y, z+1])
    ]

def interpolate(v1, v2, threshold):
    """
    Linear interpolation to find intersection point.
    P = V1 + (T - S1) / (S2 - S1) * (V2 - V1)
    """
    s1 = v1.scalar
    s2 = v2.scalar
    
    # Handle zero delta case per source specification
    if s2 == s1:
        return v1
    
    t = threshold
    factor = (t - s1) / (s2 - s1)
    
    # Linear interpolation
    p = v1.pos + factor * (v2.pos - v1.pos)
    return Point(p, s1)

def get_sidedness(value, threshold, zero_as_inside):
    """
    Determines sidedness for triangle orientation.
    """
    if zero_as_inside:
        return 1 if value <= threshold else -1
    else:
        return 1 if value > threshold else -1

def emit_triangles(intersections, triangles, vertices, normals):
    """
    Emits triangles from intersection points.
    The source states that triangles are emitted, not quads.
    """
    if len(intersections) == 3:
        i0, i1, i2 = intersections
        triangles.append([vertices.index(i0[0]), vertices.index(i1[0]), vertices.index(i2[0])])
    elif len(intersections) == 4:
        i0, i1, i2, i3 = intersections
        triangles.append([vertices.index(i0[0]), vertices.index(i1[0]), vertices.index(i2[0])])
        triangles.append([vertices.index(i0[0]), vertices.index(i2[0]), vertices.index(i3[0])])

class Point:
    def __init__(self, pos, scalar=0.0):
        self.pos = pos
        self.scalar = scalar
```

### Parameters
*   **Density Interpretation:** For distance-to-surface point cloud data, density is defined as $-distance$ [S1, S2, unofficial].
*   **Zero as Inside:** Must be selected when using distance-to-surface data [S1, S2, unofficial].
*   **Threshold:** Typically 0 [S2, unofficial].

### Edge Cases and Pitfalls
*   **Zero-Value Slope Handling:** When 0 is treated as 'inside', if an input point is exactly 0, the state does not transition from outside to inside. Since the origin point is always outside and serves as the delta source for points 1, 2, or 3, if those points are also 0, the slope delta becomes zero. This zero delta is explicitly forced to 0, ensuring a 0 'inside' point remains as close to itself as possible [S2, unofficial].
*   **Vertex Ordering:** Vertex ordering affects the 'outside' point detection. The author ordered vertices so every other point is inverted, allowing a mod4 wrap for point indexing to reduce logic to a single if-case [S1, unofficial].
*   **Fabricated Points:** The method avoids fabricated points, which prevents the creases and indentations that occur when synthesizing a center point from 8 surrounding points [S1, S2, unofficial].

*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** The DLC-Plane mode slices the cloud plane-by-plane, generating a single calculation for all shared points, which reduces the total point count [S2, unofficial]. This improves merged point handling in maximized/minimized conditions [S2, unofficial].
*   **Strengths:**
    *   No fabricated points, leading to cleaner geometry [S1, S2, unofficial].
    *   Avoids creases and indentations on boundaries [S1, S2, unofficial].
    *   Good results for opening spaces without discontinuities [S2, unofficial].
    *   Code simplicity compared to cuboctohedral or parallel-piped approaches [S1, unofficial].
*   **Limitations:**
    *   The method is specific to the diamond crystal lattice structure [S1, S2, unofficial].
    *   Requires careful handling of zero-value slopes [S1, S2, unofficial].
*   **When to Use:**
    *   When high-quality isosurfaces for opening spaces and voids are required [S2, unofficial].
    *   When avoiding artifacts from fabricated center points is important [S1, S2, unofficial].
    *   When working with distance-to-surface point cloud data [S1, S2, unofficial].
*   **When Not to Use:**
    *   When a standard marching cubes implementation is sufficient and simplicity of implementation is prioritized over geometric quality [S2, unofficial].

## Background
The Marching Tetrahedra 3 (DLC-Plane) method was developed by d3x0r as part of the `MarchingTetrahedra` and `DualMarchingTetrahedra` projects [S1, S2, unofficial]. It is inspired by the diamond crystal lattice structure [S1, S2, unofficial]. The method was designed to address the issues of creases and indentations caused by synthesizing center points in previous approaches, such as the cuboctohedral approach which required 14 tetrahedra and pyramidal penta-hedrons [S1, S2, unofficial]. The method is used for flat isosurface mesh calculation with added texturing, demonstrating a method for 3D volume repeating textures [S2, unofficial].
