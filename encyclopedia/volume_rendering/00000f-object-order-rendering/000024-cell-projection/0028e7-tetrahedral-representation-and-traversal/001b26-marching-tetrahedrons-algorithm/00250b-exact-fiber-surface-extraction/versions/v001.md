# Exact Fiber Surface Extraction

Also called: Base Fiber Surface Extraction, Correct Fiber Surface Extraction, Exact Fiber Surface Extraction on Tetrahedral Meshes

## Overview
Exact Fiber Surface Extraction computes the pre-image of a 1-manifold path (Fiber Surface Control Polygon, FSCP) in the range of a bivariate field $f: \mathbb{R}^3 \to \mathbb{R}^2$ over a tetrahedral mesh. It solves the problem of approximating these surfaces using signed distance fields, which fail to capture sharp bends and complex topologies [S1]. Unlike [Regularised Marching Tetrahedra](1301-regularised-marching-tetrahedra.md) which smooths geometry, this method guarantees planar pre-images within each tetrahedron by decomposing the extraction into base surface generation and precise clipping [S1].

## How it works
The algorithm operates in two stages: extracting base fiber surfaces for each edge of the FSCP, and then clipping these surfaces to the specific segments defined by the FSCP vertices.

### Inputs and Outputs
- **Input**: Tetrahedral mesh $M$, bivariate function $f = (f_1, f_2)$, FSCP defined by vertices $v_0, \dots, v_k$ and edges $e_i = (v_i, v_{i+1})$.
- **Output**: A triangle soup representing the fiber surface.

### Data Structures
- **Vertex**: Position $\mathbf{w}_i \in \mathbb{R}^3$, function values $\mathbf{f}_i = (f_1(\mathbf{w}_i), f_2(\mathbf{w}_i)) \in \mathbb{R}^2$.
- **Case Index**: Integer bitmask for vertex classification.
- **Triangle**: List of three vertices with interpolated positions and function values.

### Stage 1: Base Fiber Surface Extraction
For each edge $e$ of the FSCP, defined by the infinite line $\vec{l}$ passing through its endpoints, the algorithm extracts the pre-image of $\vec{l}$ within each tetrahedron $T \in M$. This ignores the specific endpoints of the edge, treating it as an infinite line cut.

1.  Iterate over all tetrahedra $T \in M$.
2.  Initialize case index $C = 0$.
3.  For each vertex $\mathbf{w}_i$ of $T$:
    a. Compute the signed range distance $h_i$ from the function values $\mathbf{f}_i$ to the line $\vec{l}$.
    b. If $h_i > 0$, set the $i$-th bit of $C$: $C = C \mid 2^i$.
4.  For all triangles $t$ defined by the Marching Tetrahedra lookup table for case $C$:
    a. Interpolate vertex positions $\mathbf{w}$ and function values $\mathbf{f}$ at the triangle vertices.
    b. Store the triangle as a "base fiber surface" triangle.

**Formula for Signed Range Distance:**
The line $\vec{l}$ is represented in Hesse normal form: $\mathbf{n} \cdot \mathbf{x} = d$, where $\mathbf{n}$ is the unit normal vector in $\mathbb{R}^2$ and $d$ is the distance from the origin. For a vertex with function values $\mathbf{f}_i = (f_1, f_2)$:
$$ h_i = \mathbf{n} \cdot \mathbf{f}_i - d $$
The pre-image of the line is the zero level-set of $h$: $f^{-1}(\vec{l}) = \{ \mathbf{p} \in \text{Dom } f \mid h(\mathbf{p}) = 0 \}$ [S1]. Due to linear interpolation, this pre-image is guaranteed to be planar within each tetrahedron [S1].

### Stage 2: Fiber Clipping
The base fiber surfaces from Stage 1 are clipped to retain only the segment between the fibers induced by the FSCP edge endpoints $u$ and $v$.

1.  For each base fiber surface triangle $T_{base}$ generated in Stage 1 for edge $e=(u,v)$:
    a. Define the line segment $L$ in the range from $u$ to $v$. Parameterize $L$ as $\mathbf{o} + t\mathbf{d}$, where $u$ corresponds to $t=0$ and $v$ corresponds to $t=1$.
    b. Initialize case index $C = 0$.
    c. For each vertex $\mathbf{w}_j$ of $T_{base}$ with function values $\mathbf{f}_j$:
        i. Project $\mathbf{f}_j$ onto $L$ to compute parameter $t_j$.
        ii. Classify the vertex:
            - If $t_j < 0$, set ternary bit to 0 (minus): $C = C + 0 \cdot 3^j$.
            - If $0 \le t_j \le 1$, set ternary bit to 1 (neutral): $C = C + 1 \cdot 3^j$.
            - If $t_j > 1$, set ternary bit to 2 (plus): $C = C + 2 \cdot 3^j$.
    d. For all triangles $T'$ defined by the "Fiber Segment" lookup table for case $C$:
        i. Interpolate vertex positions on the edges of $T_{base}$.
        ii. Add $T'$ to the output mesh $M_{out}$.

**Formula for Parameter $t$:**
Given line segment $L$ defined by endpoints $u$ and $v$, the parameter $t$ for a point $\mathbf{f}$ is computed by projecting $\mathbf{f}$ onto the line. Specifically, if $L$ is parameterized such that $u$ is at $t=0$ and $v$ is at $t=1$, $t$ represents the relative position along the segment [S1].

### Pseudocode

```python
def extract_fiber_surface(mesh, functions, fscp_edges):
    """
    Extracts exact fiber surfaces for a bivariate field on a tetrahedral mesh.
    
    Args:
        mesh: List of tetrahedra, each containing 4 vertices.
        functions: Bivariate field f = (f1, f2).
        fscp_edges: List of line segments in range space, each defined by two points (u, v).
    
    Returns:
        List of triangles representing the fiber surface.
    """
    output_triangles = []
    
    for edge in fscp_edges:
        u, v = edge
        # Define line l in Hesse normal form
        # n is unit normal, d is distance to origin
        # In 2D, for line through u and v:
        # direction d_vec = v - u
        # normal n = (-d_vec.y, d_vec.x) normalized
        # d = n . u
        n, d = compute_hesse_normal_form(u, v)
        
        for tet in mesh:
            # Stage 1: Base Fiber Surface Extraction
            case_c = 0
            vertex_data = []
            
            for i, vertex in enumerate(tet.vertices):
                # Get function values at vertex
                f_val = functions(vertex) # Returns (f1, f2)
                
                # Compute signed distance to line l
                h = dot(n, f_val) - d
                
                vertex_data.append({
                    'pos': vertex.pos,
                    'f': f_val,
                    'h': h
                })
                
                if h > 0:
                    case_c |= (1 << i)
            
            # Extract base triangles using Marching Tetrahedra lookup
            base_triangles = marching_tetrahedra(case_c, vertex_data)
            
            # Stage 2: Fiber Clipping
            for tri in base_triangles:
                # Define segment L from u to v
                # Parameterize: P(t) = u + t*(v-u), t in [0, 1]
                # To find t for a point f: project f onto line, then normalize
                # t = dot(f - u, v - u) / dot(v - u, v - u)
                
                tri_case = 0
                tri_vertex_data = []
                
                for j, v_data in enumerate(tri.vertices):
                    f_val = v_data['f']
                    
                    # Compute parameter t
                    # Note: v_data['f'] is in range space
                    vec_uv = v - u
                    vec_uf = f_val - u
                    t = dot(vec_uf, vec_uv) / dot(vec_uv, vec_uv)
                    
                    # Classify
                    if t < 0:
                        bit = 0
                    elif t <= 1:
                        bit = 1
                    else:
                        bit = 2
                    
                    tri_case += bit * (3 ** j)
                    
                    tri_vertex_data.append({
                        'pos': v_data['pos'],
                        'f': f_val
                    })
                
                # Extract clipped triangles using Fiber Segment lookup
                clipped_triangles = fiber_segment_lookup(tri_case, tri_vertex_data)
                output_triangles.extend(clipped_triangles)
                
    return output_triangles

def compute_hesse_normal_form(u, v):
    """
    Computes unit normal n and distance d for line through u and v in R2.
    Line equation: n . x = d
    """
    # Direction vector
    dx = v[0] - u[0]
    dy = v[1] - u[1]
    
    # Normal vector (-dy, dx)
    nx = -dy
    ny = dx
    
    # Normalize
    length = sqrt(nx*nx + ny*ny)
    nx /= length
    ny /= length
    
    # Distance to origin
    d = nx * u[0] + ny * u[1]
    
    return (nx, ny), d

def marching_tetrahedra(case, vertex_data):

        # Intersection occurs where h=0.
        # h1 = v1.h, h2 = v2.h
        # t = h1 / (h1 - h2)
        # pos = v1.pos + t * (v2.pos - v1.pos)
        # f = v1.f + t * (v2.f - v1.f)

        h2 = v2['h']

        f = v1['f'] + t * (v2['f'] - v1['f'])
        
        triangles.append({
            'vertices': [{'pos': pos, 'f': f}]
        })
        
    return triangles
```

### Parameters
- **Mesh Resolution**: Dependent on input data.
- **FSCP Complexity**: Number of edges $E$ in the FSCP.

### Edge Cases and Pitfalls
1.  **Bends in FSCP**: The signed distance field approximation fails to capture bends in the FSCP because the zero level-set shortcuts the bends. This inaccuracy occurs for all bends because polygon bends are unlikely to coincide precisely with domain vertices [S1].
2.  **Empty Level Set**: Vertex classification fails when the FSCP is completely included within the image of a tetrahedron and none of its vertices lie in the inside of the FSCP, resulting in an empty 0 level set [S1].
3.  **Multiple Crossings**: An FSCP may cross the image of an edge of the domain multiple times, preventing the identification of intersections of the fiber surface with a tetrahedron due to vertex classification, leading to incorrect topology [S1].
4.  **Degenerate Tetrahedra**: Degenerate tetrahedra where all four vertices belong to the inverse image are handled by ensuring the boundary between degenerate and non-degenerate tetrahedra is extracted via shared faces [S1].

## Subtopics

### Fiber Clipping
Clips the base fiber surface triangles to retain only the segment between fibers $f^{-1}(u)$ and $f^{-1}(v)$ corresponding to FSCP edge endpoints $u$ and $v$. It uses a ternary classification (t<0, 0≤t≤1, t>1) resulting in 27 possible cases per triangle, handled by a lookup table [S1].

### Non-accelerated Fiber Surface Extraction
The baseline algorithm that processes all tetrahedra without acceleration, extracting a triangle soup. It may optionally merge coincident points to form a manifold surface using VTK's `vtkMergePoints` class [S1].

### Parallel Fiber Surface Extraction
Parallelizes the extraction over cells. The domain is segmented into $n$ partitions, each processed by a thread. Synchronization is only required for memory allocation; threads read independently and write to distinct memory intervals [S1].

## Operating characteristics
- **Time Complexity**: $O(N \times E)$, where $N$ is the number of input tetrahedra and $E$ is the number of FSCP edges [S1].
- **Memory Complexity**: Proportional to the output size (number of triangles) plus input mesh storage [S1].
- **Measured Performance**:
    - Engine dataset (35,438,625 tets, 11 polygon edges): 9.121 seconds [S1].
    - Enzo dataset (82,906,875 tets, 8 polygon edges): 17.264 seconds [S1].
- **Strengths**: Exact extraction for tetrahedral meshes; tractable due to planar pre-images [S1].
- **Limitations**: Not tractable for trilinear hexahedral meshes due to complex, non-linear fiber intersections (hyperbolic sheets) [S1].
- **When to Use**: When exact topology and geometry of fiber surfaces are required for bivariate fields on tetrahedral meshes.
- **When Not to Use**: For hexahedral meshes with trilinear interpolation, or when interactive performance is critical without acceleration structures [S1].

## Background
The method was introduced to overcome the inaccuracies of previous approximate algorithms that relied on rasterizing the range and computing signed distance fields [S1]. It leverages the property that tetrahedral meshes allow exact fiber extraction because isosurfaces are planar cuts, making fibers the intersection of two planes (a line segment), whereas hexahedral meshes with trilinear interpolation are intractable [S1].
