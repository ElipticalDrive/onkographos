# Tetrahedral Normal Calculation

Also called: Vertex-weighted tetrahedral normal

## Overview
Tetrahedral Normal Calculation is a method for computing smooth isosurface normals in tetrahedral volume rendering by weighting vertex normals with the volumes of connected tetrahedra [S1]. It solves the problem of severe shading discontinuities that arise when using the constant plane normal of individual tetrahedra, which decreases rendering quality [S1]. It differs from its parent, the Marching Tetrahedrons Algorithm, by post-processing the geometric intersection to provide continuous lighting, and from siblings like Regularised Marching Tetrahedra by relying on pre-computed vertex weights rather than local regularization kernels [S1][1301-regularised-marching-tetrahedra.md].

## How it works
**Inputs and Outputs:**
*   **Input:** A tetrahedral mesh where each vertex $v$ has a list of connected tetrahedra $h_t$. Each tetrahedron $h_t$ has a pre-computed constant plane normal $N_t$ and volume $V(h_t)$.
*   **Output:** A smooth normal vector $N_{smooth}$ at an intersection point within a tetrahedron, derived from interpolated vertex normals.

**Data Structures:**
*   **Vertex Normal ($N_v$):** A 3D vector $(a, b, c)^T$ stored per vertex.
*   **Tetrahedron Normal ($N_t$):** A 3D vector $(a, b, c)^T$ stored per tetrahedron.
*   **Barycentric Coordinates ($\lambda_i$):** Four scalar weights corresponding to the four vertices of the tetrahedron containing the intersection point.

**Steps:**

1.  **Compute Tetrahedron Plane Normal ($N_t$):**
    For each tetrahedron, determine the orientation of the iso-surface plane. The source states that the orientation of the plane describing the iso-surface is independent of the iso-value, making $N_t$ constant within the cell [S1].
    *   *Note:* The specific geometric formula for $N_t$ (e.g., via cross products of edge vectors) is not detailed in the provided notes, but it is assumed to be pre-computed [S1].

2.  **Compute Vertex Normals ($N_v$):**
    For each vertex $v$, calculate its normal as the weighted sum of the normals of all connected tetrahedra, weighted by their volumes [S1].
    $$ N_v = \sum_{t=0}^{n} N_t V(h_t) $$
    Where:
    *   $n$ is the number of tetrahedra connected to the vertex.
    *   $N_t$ is the constant plane normal of tetrahedron $t$.
    *   $V(h_t)$ is the volume of tetrahedron $t$.
    
    This step is performed once during preprocessing and the results are stored in the data file [S1].

3.  **Normalize Vertex Normals:**
    The resulting vector $N_v$ from Step 2 must be normalized to unit length [S1].
    $$ \hat{N}_v = \frac{N_v}{\|N_v\|} $$

4.  **Calculate Barycentric Coordinates:**
    Given an intersection point $P$ within a tetrahedron with vertices $v_0, v_1, v_2, v_3$, calculate the 3D barycentric coordinates $\lambda_0, \lambda_1, \lambda_2, \lambda_3$ [S1].
    *   *Note:* The source mentions extending 2D barycentric coordinates for triangles to the 3D tetrahedral case but does not provide the explicit formula. The standard approach involves solving the linear system $P = \sum \lambda_i v_i$ subject to $\sum \lambda_i = 1$ [G].

5.  **Interpolate Normal:**
    Weight the pre-computed vertex normals by the barycentric coordinates and sum them [S1].
    $$ N_{raw} = \sum_{i=0}^{3} \lambda_i \hat{N}_{v_i} $$

6.  **Normalize Result:**
    Normalize the interpolated vector to obtain the final smooth normal [S1].
    $$ N_{smooth} = \frac{N_{raw}}{\|N_{raw}\|} $$

**Pseudocode:**

```python
import math
from typing import List, Tuple

# Vector operations
def vec3_add(a, b):
    return (a[0] + b[0], a[1] + b[1], a[2] + b[2])

def vec3_scale(v, s):
    return (v[0] * s, v[1] * s, v[2] * s)

def vec3_dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def vec3_cross(a, b):
    return (
        a[1]*b[2] - a[2]*b[1],
        a[2]*b[0] - a[0]*b[2],
        a[0]*b[1] - a[1]*b[0]
    )

def vec3_norm(v):
    return math.sqrt(vec3_dot(v, v))

def vec3_normalize(v):
    n = vec3_norm(v)
    if n == 0:
        return (0, 0, 0)
    return vec3_scale(v, 1.0 / n)

# Preprocessing Step
def compute_vertex_normals(vertices, tetrahedra):
    """
    vertices: List of 3D points (x,y,z)
    tetrahedra: List of tuples (v0_idx, v1_idx, v2_idx, v3_idx)
    Returns: List of normalized vertex normals
    """
    num_vertices = len(vertices)
    vertex_normals = [(0.0, 0.0, 0.0) for _ in range(num_vertices)]
    
    for t in tetrahedra:
        v0, v1, v2, v3 = [vertices[i] for i in t]
        
        # Calculate Tetrahedron Normal N_t
        # Note: The source does not specify the exact formula for N_t.
        # A common approach for a plane defined by 3 vertices of the tet is:
        # Edge1 = v1 - v0, Edge2 = v2 - v0, N_t = cross(Edge1, Edge2)
        # However, since the iso-surface orientation is independent of iso-value,
        # this geometric normal of the tet faces is used as the constant cell normal.
        edge1 = vec3_sub(v1, v0)
        edge2 = vec3_sub(v2, v0)
        n_t = vec3_normalize(vec3_cross(edge1, edge2))
        
        # Calculate Volume V(h_t)
        # Volume of tetrahedron = |dot(v3-v0, cross(v1-v0, v2-v0))| / 6
        edge3 = vec3_sub(v3, v0)
        vol = abs(vec3_dot(edge3, vec3_cross(edge1, edge2))) / 6.0
        
        # Add weighted normal to each vertex of this tetrahedron
        for idx in t:
            weighted_n = vec3_scale(n_t, vol)
            vertex_normals[idx] = vec3_add(vertex_normals[idx], weighted_n)
            
    # Normalize vertex normals
    normalized_vertex_normals = [vec3_normalize(n) for n in vertex_normals]
    return normalized_vertex_normals

def vec3_sub(a, b):
    return (a[0]-b[0], a[1]-b[1], a[2]-b[2])

def calculate_smooth_normal(vertices, vertex_normals, intersection_point):
    """
    vertices: List of 3D points for the specific tetrahedron containing the point
    vertex_normals: Pre-computed normalized normals for these 4 vertices
    intersection_point: The 3D point where the ray intersects the tetrahedron
    Returns: The smooth normal vector
    """
    v0, v1, v2, v3 = vertices
    
    # Calculate Barycentric Coordinates
    # Solve: P = v0 + lambda1*(v1-v0) + lambda2*(v2-v0) + lambda3*(v3-v0)
    # where lambda0 = 1 - lambda1 - lambda2 - lambda3
    # This requires solving a 3x3 linear system.
    # Let u = v1-v0, v = v2-v0, w = v3-v0, p = P-v0
    # p = lambda1*u + lambda2*v + lambda3*w
    
    u = vec3_sub(v1, v0)
    v_vec = vec3_sub(v2, v0)
    w = vec3_sub(v3, v0)
    p = vec3_sub(intersection_point, v0)
    
    # Using Cramer's rule or matrix inversion for 3x3 system
    # Matrix M = [u, v_vec, w]
    # We need to solve M * [l1, l2, l3]^T = p
    
    # Determinant of M
    det_M = vec3_dot(u, vec3_cross(v_vec, w))
    
    if abs(det_M) < 1e-9:
        # Degenerate tetrahedron
        return (0, 0, 1) # Fallback
        
    l1 = vec3_dot(p, vec3_cross(v_vec, w)) / det_M
    l2 = vec3_dot(u, vec3_cross(p, w)) / det_M
    l3 = vec3_dot(u, vec3_cross(v_vec, p)) / det_M
    
    l0 = 1.0 - l1 - l2 - l3
    
    # Interpolate Normal
    n0 = vertex_normals[0]
    n1 = vertex_normals[1]
    n2 = vertex_normals[2]
    n3 = vertex_normals[3]
    
    raw_normal = vec3_add(
        vec3_add(
            vec3_add(vec3_scale(n0, l0), vec3_scale(n1, l1)),
            vec3_scale(n2, l2)
        ),
        vec3_scale(n3, l3)
    )
    
    return vec3_normalize(raw_normal)
```

**Parameters:**
*   None explicitly defined. The method relies on the geometry of the mesh.

**Edge Cases and Pitfalls:**
*   **Discontinuities:** Using the constant cell normal $N_t$ directly results in severe discontinuities between tetrahedra surfaces, decreasing rendering quality [S1].
*   **Degenerate Tetrahedra:** If the determinant of the barycentric coordinate calculation is near zero, the tetrahedron is degenerate. The pseudocode includes a fallback [G].
*   **Zero Volume:** If a tetrahedron has zero volume, it contributes nothing to the vertex normal sum, which is correct, but may indicate mesh quality issues [S1].

## Subtopics

### [Average Normal Calculation for Cut Triangles](11806-average-normal-calculation-for-cut-triangles.md)
This variant calculates normals for cut triangles within the tetrahedron. It is chosen when the intersection geometry is simplified to triangles rather than full tetrahedral interpolation. It differs from the main method by operating on 2D barycentric coordinates of the cut triangle rather than 3D tetrahedral coordinates. See [Average Normal Calculation for Cut Triangles](11806-average-normal-calculation-for-cut-triangles.md).

### Marching Tetrahedra Fragment Shader
A GPU implementation variant where the fragment shader outputs the interpolated normal vector as the color. The step involves setting `FragColor = vec4(oNormal, 1.0)`. This is used for real-time rendering where normal data is passed from vertex to fragment shaders. See [Marching Tetrahedra Fragment Shader](11807-marching-tetrahedra-fragment-shader.md).

## Operating characteristics
*   **Time Complexity:** Preprocessing is $O(V \cdot T_{avg})$ where $V$ is vertices and $T_{avg}$ is average tetrahedra per vertex. Per-ray rendering is $O(1)$ for normal calculation after barycentric coordinates are found.
*   **Memory Complexity:** Requires storing one 3D vector per vertex for $N_v$.
*   **Performance:** Provides significantly better visual quality than constant cell normals by eliminating shading discontinuities [S1].
*   **Strengths:** Smooth shading, pre-computable, simple interpolation.
*   **Limitations:** Requires pre-computation and storage of vertex normals. Does not account for scalar field gradients directly, only geometric connectivity.
*   **When to use:** When smooth lighting is required for tetrahedral meshes and pre-computation is acceptable.
*   **When not to use:** When memory is extremely constrained or when the scalar field gradient is more important than geometric continuity (e.g., some scientific visualizations).

## Background
The method was introduced in the context of fast ray traversal of tetrahedral and hexahedral meshes for direct volume rendering [S1]. It addresses the limitations of basic Marching Tetrahedrons where flat shading leads to visible artifacts. The approach leverages the geometric property that the iso-surface plane orientation is independent of the iso-value within a tetrahedron [S1].
