# MTCut

Also called: GPU-based Marching Tetra Cuts

## Overview
MTCut is a real-time volume cutting algorithm that modifies isosurfaces generated by the Marching Tetrahedra (MT) algorithm using a user-defined cutting tool [S1, unofficial]. Unlike traditional tetrahedral mesh cutting strategies that require a pre-computed tetrahedrization of the entire volume, MTCut computes the tetrahedrization of only the intersected cells on-the-fly, enabling interactive performance for complex meshes [S1, unofficial]. It produces a watertight manifold model, distinguishing it from approaches like Zachow et al. [ZGSZ03] that yield open surfaces with borders [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A volume dataset, an isovalue for the initial isosurface, and a cutting tool path represented as a sequence of segments (sticks) tracked via a haptic device [S1, unofficial].
*   **Output:** A modified watertight manifold triangle mesh representing the cut isosurface [S1, unofficial].

**Data Structures:**
*   **Cutting Information:** A structure passed from the haptic thread to the rendering thread containing the cut path and a list of intersected voxels [S1, unofficial].
*   **Voxel Encoding:** Intersected voxels are encoded in a texture for fragment shader access [S1, unofficial].
*   **Voxel Splitting:** Uses a conformal voxel splitting configuration into 5 tetrahedra per voxel, as described in [ABE+03] [S1, unofficial].

**Rendering Pipeline (Three Steps):**
1.  **Encode Intersected Voxels:** The haptic thread samples the cutting tool. Only one stick (segment) is sampled inside each voxel, and coplanarity of every two consecutive sticks is imposed to ensure a voxel is cut by at most two planes [S1, unofficial]. The voxels traversed by this surface are detected and encoded in a texture [S1, unofficial].
2.  **Discard Intersected Fragments:** A surface-based rendering algorithm draws the original isosurface. A shader discards fragments belonging to voxels identified as intersected by the cutting tool [S1, unofficial].
3.  **Generate Cut Geometry:** The GPU MTCut algorithm generates new geometry for the affected voxels [S1, unofficial].

**MTCut Internal Steps (Per Affected Voxel):**
The algorithm processes each affected voxel by splitting it into 5 tetrahedra. For each tetrahedron, it performs:

1.  **Classification:** Classify the four vertices of the tetrahedron with respect to two criteria:
    *   The isovalue (isosurface).
    *   The cutting mesh (cutting surface). At the voxel level, the cutting surface is approximated by at most two planes [S1, unofficial].
2.  **Vertex Reclassification:** Reclassify vertices to determine if they are "inside" the *final* isosurface (the volume to be kept).
    *   **Single Plane Cut:** A point is classified as inside if it lies inside the isosurface AND in the positive half-space of the cutting plane [S1, unofficial].
    *   **Two Plane Cut:** Classification depends on the concavity/convexity that the two cutting planes form with respect to the cut direction [S1, unofficial].
3.  **Pattern Calculation & Edge Identification:** Determine which edges of the tetrahedron are intersected by the final isosurface based on the reclassified vertex signs [S1, unofficial].
4.  **Vertex Generation:** Determine new vertex positions for triangulation.
    *   If an edge is cut *only* by the cutting plane, place the vertex at the intersection of the plane with the edge [S1, unofficial].
    *   If an edge is traversed by *both* the isosurface and the cutting plane, place the new vertex at the more interior intersection point (closer to the inside) [S1, unofficial].
    *   **Exception:** If the edge is shared with a non-cut voxel, keep the intersection with the isosurface [S1, unofficial].

```python
def mtcut_cut_volume(volume_data, isovalue, cutting_tool_path):
    """
    Main entry point for MTCut.
    volume_data: 3D array of scalar values.
    isovalue: float, threshold for isosurface.
    cutting_tool_path: list of 3D points representing the tool trajectory.
    """
    # Step 1: Haptic Sampling and Voxel Encoding
    # Approximate blade path as piecewise-bilinear surface (quads between segments)
    sticks = []
    for i in range(len(cutting_tool_path) - 1):
        p1 = cutting_tool_path[i]
        p2 = cutting_tool_path[i+1]
        sticks.append((p1, p2))
    
    intersected_voxels = set()
    # Impose coplanarity of consecutive sticks to ensure max 2 planes per voxel
    # Sample only one stick per voxel
    for stick in sticks:
        voxels_traversed = get_voxels_traversed_by_segment(stick[0], stick[1])
        intersected_voxels.update(voxels_traversed)
    
    # Encode intersected voxels in a texture (implementation detail omitted)
    voxel_texture = encode_voxels(intersected_voxels)
    
    # Step 2 & 3: Rendering and Geometry Generation
    # Draw original isosurface, discarding fragments in intersected_voxels
    draw_isosurface_discarding(volume_data, isovalue, voxel_texture)
    
    # Generate new geometry for affected voxels
    new_triangles = []
    for voxel in intersected_voxels:
        # Split voxel into 5 tetrahedra (conformal splitting [ABE+03])
        tetrahedra = split_voxel_into_5_tets(voxel)
        
        for tet in tetrahedra:
            # Get vertex positions and values
            v_pos = [tet.v0.pos, tet.v1.pos, tet.v2.pos, tet.v3.pos]
            v_val = [tet.v0.val, tet.v1.val, tet.v2.val, tet.v3.val]
            
            # Determine cutting planes for this voxel
            # Based on the specific stick(s) traversing this voxel
            cutting_planes = get_cutting_planes_for_voxel(voxel, sticks)
            
            # Step 4.1: Classification
            # Classify vertices w.r.t isovalue
            iso_signs = classify_by_isovalue(v_val, isovalue)
            
            # Classify vertices w.r.t cutting planes
            # At voxel level, approx cutting surface by at most 2 planes
            cut_signs = classify_by_cutting_planes(v_pos, cutting_planes)
            
            # Step 4.2: Vertex Reclassification
            # Determine final 'inside' status
            final_signs = reclassify_vertices(iso_signs, cut_signs, cutting_planes)
            
            # Step 4.3: Edge Identification
            # Identify edges where signs differ
            intersected_edges = find_intersected_edges(final_signs)
            
            # Step 4.4: Vertex Generation
            generated_vertices = []
            for edge in intersected_edges:
                p_start, p_end = edge.start, edge.end
                val_start, val_end = edge.start_val, edge.end_val
                
                # Check if edge is shared with non-cut voxel
                is_shared_with_non_cut = edge.is_shared_with_non_cut_voxel()
                
                # Calculate intersection with isosurface
                iso_intersection = interpolate_isosurface(p_start, p_end, val_start, val_end, isovalue)
                
                # Calculate intersection with cutting plane(s)
                cut_intersections = []
                for plane in cutting_planes:
                    pt = intersect_plane_with_segment(plane, p_start, p_end)
                    if pt is not None:
                        cut_intersections.append(pt)
                
                if len(cut_intersections) == 0:
                    # Edge cut only by isosurface (standard MT)
                    generated_vertices.append(iso_intersection)
                elif len(cut_intersections) == 1:
                    # Edge cut only by cutting plane (or both, but iso doesn't cut? 
                    # Note: If iso doesn't cut, final_signs wouldn't differ unless cut plane changes inside/outside)
                    # If edge is cut ONLY by cutting plane, place at intersection
                    generated_vertices.append(cut_intersections[0])
                else:
                    # Edge traversed by both isosurface and cutting plane
                    if is_shared_with_non_cut:
                        # Exception: keep intersection with isosurface
                        generated_vertices.append(iso_intersection)
                    else:
                        # Place at more interior intersection point
                        # "Interior" means closer to the "inside" of the final volume
                        # Determine which side is inside based on reclassification
                        interior_pt = select_interior_point(iso_intersection, cut_intersections, final_signs)
                        generated_vertices.append(interior_pt)
            
            # Triangulate based on pattern
            triangles = triangulate_tetrahedron(final_signs, generated_vertices)
            new_triangles.extend(triangles)
            
    return new_triangles

def classify_by_isovalue(values, isovalue):
    return [1 if v > isovalue else -1 for v in values]

def classify_by_cutting_planes(positions, planes):
    signs = []
    for p in positions:
        # Positive half-space is 'inside' the cut volume
        s = 1
        for plane in planes:
            if plane.distance_to_point(p) < 0:
                s = -1 # Outside the positive half-space
        signs.append(s)
    return signs

    elif any(is_cut_inside):
        return cut_pts[is_cut_inside.index(True)]
```

**Edge Cases and Pitfalls:**
*   **Crack Generation:** Cracks between the newly created surface and the original isosurface are avoided because the classification of vertices shared between cut voxels and non-cut voxels is never changed [S1, unofficial].
*   **Precision:** The algorithm relies on accurate intersection calculations. Precision issues may arise if the cutting plane is nearly parallel to an edge or if the isovalue is very close to a vertex value [G].
*   **Boundary Conditions:** The haptic sampling condition (one stick per voxel, coplanarity) is critical. If violated, a voxel may be cut by more than two planes, breaking the algorithm's assumptions [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Real-time performance is achieved because tetrahedrization is computed only for intersected cells, not the entire volume [S1, unofficial].
*   **Memory Complexity:** Depends on the number of intersected voxels. The entire volume does not need to be tetrahedrized in memory [S1, unofficial].
*   **Measured Performance:** Runs in real time for complex meshes of up to 1.8 million triangles [S1, unofficial].
*   **Strengths:** Real-time interaction, no pre-computed tetrahedrization, watertight manifold output [S1, unofficial].
*   **Limitations:** Requires a haptic device for input (in the described application), approximation of cutting tool as piecewise-bilinear surface [S1, unofficial].

## Background
MTCut was introduced in the paper "MTCut: GPU-based Marching Tetra Cuts" [S1, unofficial]. It addresses the need for real-time volume cutting in computer-aided medical applications, such as osteotomy planning (e.g., LeFort I surgical operation) [S1, unofficial]. It builds on the Marching Tetrahedra algorithm [DK91, YMDO93] and uses conformal voxel splitting [ABE+03]. It contrasts with previous approaches like Zachow et al. [ZGSZ03] (open surfaces) and Pintilie and McInerney [PM03] (limited to shallow cuts) [S1, unofficial].
