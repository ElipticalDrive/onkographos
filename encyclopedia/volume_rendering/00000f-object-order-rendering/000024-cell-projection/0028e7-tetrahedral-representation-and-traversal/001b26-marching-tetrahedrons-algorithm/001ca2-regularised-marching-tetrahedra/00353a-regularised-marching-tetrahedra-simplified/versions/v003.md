# Regularised Marching Tetrahedra (Simplified)

Also called: Iso-surface extraction using Radial Basis Functions, Marching Tetrahedral [S1, unofficial]

## Overview
An iso-surface extraction algorithm that iterates over a volume grid to extract intersections within tetrahedral cells, specifically designed for objects represented using radial basis functions [S1, unofficial]. It differs from its parent, [Regularised Marching Tetrahedra](1301-regularised-marching-tetrahedra.md), by omitting the vertex clustering step, leaving out the regularization part [S1, unofficial]. It is chosen over Marching Squares to avoid topological ambiguities [S1, unofficial].

## How it works
**Inputs:**
- A bounding box (`AxisAlignedBox3`) defining the spatial extent of the volume [S1, unofficial].
- A resolution parameter `reso` controlling the grid density [S1, unofficial].
- A scalar field evaluation function `evaluate_fn(Vector3)` that returns the value at a given point [S1, unofficial].
- An iso-value threshold for surface extraction [S1, unofficial].

**Outputs:**
- A list of vertices (`list<Vector3>`) representing the iso-surface [S1, unofficial].

**Data Structures:**
- `no_planes`: A vector of 3 unsigned integers storing the number of planes in X, Y, and Z dimensions [S1, unofficial].
- `grid_lines`: A vector of 4 vectors of floats containing coordinate lists for grid traversal [S1, unofficial].
- `Tetrahedral`: A structure containing 4 `Vector3` vertices [S1, unofficial].

**Parameters:**
- `dist_x`: Distance scaling factor for X-axis tetrahedra. Value: $\sqrt{2.0}$ [S1, unofficial].
- `dist_y`: Distance scaling factor for Y-axis tetrahedra. Value: $0.5$ [S1, unofficial].
- `dist_z`: Distance scaling factor for Z-axis tetrahedra. Value: $1/\sqrt{2.0}$ [S1, unofficial].

**Steps:**

1.  **Calculate Grid Dimensions:**
    Determine the number of planes in each dimension based on the bounding box extent (`lengths`) and resolution:
    $$
    \begin{aligned}
    no\_planes[0] &= \lfloor lengths[0] / (dist\_x \cdot reso) \rfloor \\
    no\_planes[1] &= \lfloor lengths[1] / (dist\_y \cdot reso) \rfloor \\
    no\_planes[2] &= \lfloor lengths[2] / (dist\_z \cdot reso) \rfloor
    \end{aligned}
    $$
    [S1, unofficial]

2.  **Create Grid Lines:**
    Generate coordinate lists for the grid traversal [S1, unofficial]:
    -   $x_1$ coordinates start at `bbox.getLow().x()` with step $reso \cdot dist\_x$ [S1, unofficial].
    -   $x_2$ coordinates start at `bbox.getLow().x() + (reso \cdot dist\_x) / 2` with step $reso \cdot dist\_x$ [S1, unofficial].
    -   $y$ coordinates start at `bbox.getLow().y()` with step $reso \cdot dist\_y$ [S1, unofficial].
    -   $z$ coordinates start at `bbox.getLow().z()` with step $reso \cdot dist\_z$ [S1, unofficial].

3.  **Iterate Over Volume:**
    Loop over Z, then Y, then X indices. For each grid point $(x, y, z)$, determine which X-coordinate set to use based on parity [S1, unofficial]:
    -   Toggle between $x_1$ and $x_2$ based on the parity of the Z index [S1, unofficial].
    -   Toggle between $x_1$ and $x_2$ based on the parity of the Y index (inheriting the state from Z if applicable) [S1, unofficial].

4.  **Generate Tetrahedra:**
    For the current grid point `pt`, call `find_tetrahedral(pt, reso)` to generate 6 tetrahedra [S1, unofficial]. The vertices for these tetrahedra are calculated relative to `pt` using the scaling factors `del_x`, `del_y`, and `del_z` (derived from `dist_x`, `dist_y`, `dist_z` and `reso`) [S1, unofficial].
    
    The 6 tetrahedra are defined as follows (where `pt` is the current grid point) [S1, unofficial]:
    -   **Left:** $\{ (pt.x - reso \cdot del\_x, pt.y + reso \cdot del\_y, pt.z), (pt.x - reso \cdot del\_x, pt.y - reso \cdot del\_y, pt.z), (pt.x - reso \cdot del\_x, pt.y, pt.z + reso \cdot del\_z), pt \}$ [S1, unofficial]
    -   **Right:** $\{ (pt.x + reso \cdot del\_x, pt.y + reso \cdot del\_y, pt.z), (pt.x + reso \cdot del\_x, pt.y - reso \cdot del\_y, pt.z), (pt.x + reso \cdot del\_x, pt.y, pt.z + reso \cdot del\_z), pt \}$ [S1, unofficial]
    -   **Down-Left:** $\{ (pt.x - reso \cdot del\_x, pt.y + reso \cdot del\_y, pt.z), (pt.x - reso \cdot del\_x, pt.y - reso \cdot del\_y, pt.z), (pt.x - reso \cdot del\_x, pt.y, pt.z - reso \cdot del\_z), pt \}$ [S1, unofficial]
    -   **Down-Right:** $\{ (pt.x + reso \cdot del\_x, pt.y + reso \cdot del\_y, pt.z), (pt.x + reso \cdot del\_x, pt.y - reso \cdot del\_y, pt.z), (pt.x + reso \cdot del\_x, pt.y, pt.z - reso \cdot del\_z), pt \}$ [S1, unofficial]
    -   **Diag-Left:** $\{ (pt.x, pt.y + reso \cdot del\_y, pt.z + reso \cdot del\_z), (pt.x - reso \cdot del\_x, pt.y, pt.z + reso \cdot del\_z), (pt.x - reso \cdot del\_x, pt.y + reso \cdot del\_y, pt.z), pt \}$ [S1, unofficial]
    -   **Diag-Right:** $\{ (pt.x, pt.y + reso \cdot del\_y, pt.z + reso \cdot del\_z), (pt.x + reso \cdot del\_x, pt.y, pt.z + reso \cdot del\_z), (pt.x + reso \cdot del\_x, pt.y + reso \cdot del\_y, pt.z), pt \}$ [S1, unofficial]

5.  **Process Tetrahedra:**
    For each of the 6 tetrahedra [S1, unofficial]:
    -   Check if the tetrahedron is inside the bounding box using `is_tetra_inside` [S1, unofficial].
    -   If inside, evaluate the surface function `evaluate_fn` at all 4 vertices to get scalar values [S1, unofficial].
    -   Call `get_vertices` to find intersection vertices with the iso-surface [S1, unofficial].
    -   If the result is not empty, add the vertices to the result list [S1, unofficial].

**`get_vertices` Logic:**
1.  Separate the 4 vertices of the tetrahedron into two lists: `less_than_iso` (values $< iso\_val$) and `more_than_iso` (values $\ge iso\_val$) [S1, unofficial].
2.  Iterate through `less_than_iso` and `more_than_iso` to pair them, pushing vertices alternately to ensure cyclic order for quad face construction when 4 vertices exist [S1, unofficial].
3.  Return the list of intersection vertices [S1, unofficial].

**Pseudocode:**

```python
import math
from typing import List, Tuple, Any

# Constants from sources [S1, unofficial]
DIST_X = math.sqrt(2.0)
DIST_Y = 0.5
DIST_Z = 1.0 / math.sqrt(2.0)

class Vector3:
    def __init__(self, x: float, y: float, z: float):
        self.x = x
        self.y = y
        self.z = z

class Tetrahedral:
    def __init__(self, vertices: List[Vector3]):
        self.vertices = vertices

class AxisAlignedBox3:
    def __init__(self, low: Vector3, high: Vector3):
        self.low = low
        self.high = high
    def get_extent(self) -> Vector3:
        return Vector3(self.high.x - self.low.x, self.high.y - self.low.y, self.high.z - self.low.z)
    def get_low(self) -> Vector3:
        return self.low
    def get_high(self) -> Vector3:
        return self.high

def is_tetra_inside(tetra: Tetrahedral, bbox: AxisAlignedBox3) -> bool:
    # [G] Standard bounding box containment check
    for v in tetra.vertices:
        if not (bbox.low.x <= v.x <= bbox.high.x and
                bbox.low.y <= v.y <= bbox.high.y and
                bbox.low.z <= v.z <= bbox.high.z):
            return False
    return True

def regularised_marching_tetrahedra_simplified(bbox: AxisAlignedBox3, reso: float, 
                                               evaluate_fn: callable, iso_val: float) -> List[Vector3]:
    # Step 1: Calculate number of planes [S1, unofficial]
    lengths = bbox.get_extent()
    no_planes = [
        int(math.floor(lengths.x / (DIST_X * reso))),
        int(math.floor(lengths.y / (DIST_Y * reso))),
        int(math.floor(lengths.z / (DIST_Z * reso)))
    ]
    
    # Step 2: Create grid lines [S1, unofficial]
    x1_coords = []
    curr = bbox.get_low().x
    step_x = reso * DIST_X
    while curr <= bbox.get_high().x:
        x1_coords.append(curr)
        curr += step_x
        
    x2_coords = []
    curr = bbox.get_low().x + (reso * DIST_X / 2.0)
    while curr <= bbox.get_high().x:
        x2_coords.append(curr)
        curr += step_x
        
    y_coords = []
    curr = bbox.get_low().y
    step_y = reso * DIST_Y
    while curr <= bbox.get_high().y:
        y_coords.append(curr)
        curr += step_y
        
    z_coords = []
    curr = bbox.get_low().z
    step_z = reso * DIST_Z
    while curr <= bbox.get_high().z:
        z_coords.append(curr)
        curr += step_z
        
    result_vertices = []
    
    # Step 3: Iterate over Z, Y, X [S1, unofficial]
    for z_idx, z in enumerate(z_coords):
        for y_idx, y in enumerate(y_coords):
            # Toggle between x1 and x2 based on parity of Y and Z indices [S1, unofficial]
            # x1 toggles with Z, x2 toggles with Y (and inherits x1 state)
            use_x2 = (z_idx % 2 != 0) or (y_idx % 2 != 0)
            x_list = x2_coords if use_x2 else x1_coords
            
            for x in x_list:
                pt = Vector3(x, y, z)
                
                # Step 4: Generate Tetrahedra [S1, unofficial]
                tetrahedra = find_tetrahedral(pt, reso, DIST_X, DIST_Y, DIST_Z)
                
                # Step 5: Process Tetrahedra [S1, unofficial]
                for tetra in tetrahedra:
                    if is_tetra_inside(tetra, bbox):
                        surf_vals = [evaluate_fn(v) for v in tetra.vertices]
                        verts = get_vertices(tetra.vertices, surf_vals, iso_val)
                        if verts:
                            result_vertices.extend(verts)
                            
    return result_vertices

def find_tetrahedral(pt: Vector3, reso: float, dist_x: float, dist_y: float, dist_z: float) -> List[Tetrahedral]:
    del_x = dist_x
    del_y = dist_y
    del_z = dist_z
    
    v1 = Vector3(pt.x - reso * del_x, pt.y + reso * del_y, pt.z)
    v2 = Vector3(pt.x - reso * del_x, pt.y - reso * del_y, pt.z)
    v3 = Vector3(pt.x - reso * del_x, pt.y, pt.z + reso * del_z)
    v4 = pt
    
    v5 = Vector3(pt.x + reso * del_x, pt.y + reso * del_y, pt.z)
    v6 = Vector3(pt.x + reso * del_x, pt.y - reso * del_y, pt.z)
    v7 = Vector3(pt.x + reso * del_x, pt.y, pt.z + reso * del_z)
    
    v8 = Vector3(pt.x - reso * del_x, pt.y, pt.z - reso * del_z)
    v9 = Vector3(pt.x + reso * del_x, pt.y, pt.z - reso * del_z)
    
    v10 = Vector3(pt.x, pt.y + reso * del_y, pt.z + reso * del_z)
    v11 = Vector3(pt.x - reso * del_x, pt.y, pt.z + reso * del_z)
    v12 = Vector3(pt.x + reso * del_x, pt.y, pt.z + reso * del_z)
    
    # Left
    left = Tetrahedral([v1, v2, v3, v4])
    # Right
    right = Tetrahedral([v5, v6, v7, v4])
    # Down-Left
    down_left = Tetrahedral([v1, v2, v8, v4])
    # Down-Right
    down_right = Tetrahedral([v5, v6, v9, v4])
    # Diag-Left
    diag_left = Tetrahedral([v10, v11, v1, v4])
    # Diag-Right
    diag_right = Tetrahedral([v10, v12, v5, v4])
    
    return [left, right, down_left, down_right, diag_left, diag_right]

def get_vertices(vertices: List[Vector3], surf_vals: List[float], iso_val: float) -> List[Vector3]:
    # [S1, unofficial] Separate vertices into less_than_iso and more_than_iso
    less_than_iso = []
    more_than_iso = []
    
    for v, val in zip(vertices, surf_vals):
        if val < iso_val:
            less_than_iso.append(v)
        else:
            more_than_iso.append(v)
            
    result = []
    # [S1, unofficial] Push vertices from less_than_iso and more_than_iso alternately 
    # to ensure cyclic order for quad face construction when 4 vertices exist
    i, j = 0, 0
    while i < len(less_than_iso) or j < len(more_than_iso):
        if i < len(less_than_iso):
            result.append(less_than_iso[i])
            i += 1
        if j < len(more_than_iso):
            result.append(more_than_iso[j])
            j += 1
            
    return result
```

## Operating characteristics
- **Time Complexity:** $O(N^3)$ as iterations are done over the volume [S1, unofficial]. It can be optimized to $O(N^2)$ if iterations are done only at the surface [S1, unofficial].
- **Memory Complexity:** $O(1)$ apart from the memory used for storing the mesh vertices [S1, unofficial].
- **Strengths:** Avoids topological ambiguities present in Marching Squares [S1, unofficial].
- **Limitations:** Vertex clustering is not implemented to keep things simple, meaning the regularization part from Treece et al. [2] is left out [S1, unofficial].

## Background
The algorithm is based on the Marching Tetrahedral algorithm [2] and was implemented for creating iso-surfaces for objects represented using radial basis functions [S1, unofficial]. The full Regularised Marching Tetrahedra method was introduced by Treece, Prager, and Gee in 1999 [S1, unofficial]. This simplified version omits the regularization (vertex clustering) part [S1, unofficial].
