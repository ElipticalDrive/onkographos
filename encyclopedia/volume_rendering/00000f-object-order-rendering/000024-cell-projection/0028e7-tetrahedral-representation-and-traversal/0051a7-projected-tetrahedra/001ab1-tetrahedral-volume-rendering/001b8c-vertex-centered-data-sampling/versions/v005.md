# Vertex-centered Data Sampling
## Overview
Vertex-centered Data Sampling reconstructs scalar field values within a tetrahedral element by interpolating the scalar data stored at the element's four vertices using the sample point's barycentric coordinates [S1, unofficial]. It is distinguished from its sibling [Cell-centered Data Sampling](974-approximate-cell-sampling.md) by relying on vertex-local data rather than averaging cell-centered values from face neighbors [S1, unofficial].
## How it works
**Inputs:**
* `element_id`: Integer identifier for the current tetrahedral element [S1, unofficial].
* `p`: The 3D sample point $(x, y, z)$ inside the tetrahedron [G].
* `tet_vertices`: Array of 4 vertex positions $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3$ associated with `element_id` [G].
* `vertex_scalars`: Array of 4 scalar values $s_0, s_1, s_2, s_3$ associated with the vertices of `element_id` [S1, unofficial].
**Outputs:**
* `sample_value`: The interpolated scalar value at point $p$ [G].
**Data Structures:**
Vertex-centered data is stored duplicated per element during the TET-AMR construction process [S1, unofficial]. This allows direct access to the four vertex scalars via the `element_id` [S1, unofficial].
**Steps:**
1. Retrieve the four scalar values $s_i$ for $i \in \{0, 1, 2, 3\}$ associated with the vertices of the current element using `element_id` [S1, unofficial].
2. Compute the barycentric coordinates $\lambda_0, \lambda_1, \lambda_2, \lambda_3$ of the sample point $p$ with respect to the tetrahedron defined by $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3$ [G].
3. Calculate the interpolated value using the weighted sum:
   $$ s(p) = \sum_{i=0}^{3} \lambda_i s_i $$
4. Return $s(p)$ [G].
**Formulas:**
The barycentric coordinates $\lambda_i$ satisfy the affine combination:
$$ p = \sum_{i=0}^{3} \lambda_i \mathbf{v}_i $$
subject to the normalization constraint:
$$ \sum_{i=0}^{3} \lambda_i = 1 $$
where $\mathbf{v}_i$ are the tetrahedron vertices and $p$ is the query point [G].
**Pseudocode:**
```python
def vertex_centered_sample(element_id, p, tet_vertices, vertex_scalars):
    v0, v1, v2, v3 = tet_vertices
    s0, s1, s2, s3 = vertex_scalars
    # Compute signed volume of the tetrahedron [G]
    def signed_vol(a, b, c, d):
        return dot(cross(b - a, c - a), d - a) / 6.0
    total_vol = signed_vol(v0, v1, v2, v3)
    # Compute barycentric coordinates via volume ratios [G]
    l0 = signed_vol(p, v1, v2, v3) / total_vol
    l1 = signed_vol(v0, p, v2, v3) / total_vol
    l2 = signed_vol(v0, v1, p, v3) / total_vol
    l3 = signed_vol(v0, v1, v2, p) / total_vol
    # Interpolate scalar value
    return l0 * s0 + l1 * s1 + l2 * s2 + l3 * s3
```
**Edge Cases and Pitfalls:**
* **Degenerate Tetrahedra:** If the tetrahedron volume is zero (coplanar vertices), the division in the volume ratio calculation results in undefined behavior [G]. Implementers should check for near-zero volume and handle it as a degenerate case (e.g., fallback to 0 or error) [G].

## Background
Originating from the work on direct volume rendering of tree-based tetrahedral adaptive mesh refinement (TET-AMR) data, this method leverages the duplicated vertex data structure to simplify sampling [S1, unofficial].
