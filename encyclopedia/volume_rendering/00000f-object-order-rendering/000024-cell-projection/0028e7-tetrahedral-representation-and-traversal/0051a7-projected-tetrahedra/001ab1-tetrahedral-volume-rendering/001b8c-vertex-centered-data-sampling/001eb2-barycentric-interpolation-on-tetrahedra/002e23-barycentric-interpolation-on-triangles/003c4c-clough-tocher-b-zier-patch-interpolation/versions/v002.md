# Clough–Tocher Bézier Patch Interpolation

Also called: C1 continuous Bézier patch, Clough-Tocher scheme, Clough–Tocher C1 Interpolation, Cubic Feature Interpolation

## Overview
Clough–Tocher Bézier Patch Interpolation replaces linear barycentric interpolation with a cubic Bézier patch construction to interpolate feature values and gradients over a triangle, guaranteeing C1 continuity everywhere and C∞ within each triangle [S1]. It solves the problem of visible seam artifacts caused by gradient discontinuities across triangle edges in fully opaque meshes, which arise because standard barycentric interpolation produces a C0 feature field [S1]. Unlike its parent method, [Barycentric Interpolation on Triangles](5671-barycentric-interpolation-on-triangles.md), which only uses vertex values, this method requires per-vertex gradients to define the patch geometry [S1].

## How it works
**Inputs:**
*   Triangle vertices $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2$ [S1].
*   Feature values at vertices $f_0, f_1, f_2$ [S1].
*   Feature gradients at vertices $\nabla f_0, \nabla f_1, \nabla f_2$ [S1].
*   Evaluation point $\mathbf{p}$ in 3D space [S1].

**Outputs:**
*   Interpolated feature value $f(\mathbf{p})$ [S1].
*   (Optional) Interpolated gradient $\nabla f(\mathbf{p})$ if the derivative of the Bézier patch is required [G].

**Data Structures:**
*   **Bézier Control Points:** An array of 10 scalar (or vector) values $c_{ijk}$ where $i+j+k=3$ [S1]. The layout is: Vertices: $c_{300}, c_{030}, c_{003}$ [S1]. Edges: $c_{210}, c_{120}, c_{021}, c_{012}, c_{102}, c_{201}$ [S1]. Center: $c_{111}$ [S1].

**Steps:**

1.  **Compute Edge Vectors:**
    Calculate the edge vectors for the triangle [S1]:
    $$ \mathbf{e}_{01} = \mathbf{v}_1 - \mathbf{v}_0 $$
    $$ \mathbf{e}_{12} = \mathbf{v}_2 - \mathbf{v}_1 $$
    $$ \mathbf{e}_{20} = \mathbf{v}_0 - \mathbf{v}_2 $$

2.  **Compute Bézier Control Points:**
    Define the 10 control points using the vertex values, gradients, and edge vectors [S1]:
    $$ c_{300} = f_0 $$
    $$ c_{030} = f_1 $$
    $$ c_{003} = f_2 $$
    $$ c_{210} = f_0 + \frac{1}{3} \nabla f_0 \cdot \mathbf{e}_{01} $$
    $$ c_{120} = f_1 - \frac{1}{3} \nabla f_1 \cdot \mathbf{e}_{01} $$
    $$ c_{021} = f_1 + \frac{1}{3} \nabla f_1 \cdot \mathbf{e}_{12} $$
    $$ c_{012} = f_2 - \frac{1}{3} \nabla f_2 \cdot \mathbf{e}_{12} $$
    $$ c_{102} = f_2 + \frac{1}{3} \nabla f_2 \cdot \mathbf{e}_{20} $$
    $$ c_{201} = f_0 - \frac{1}{3} \nabla f_0 \cdot \mathbf{e}_{20} $$
    $$ c_{111} = \frac{1}{6} (c_{210} + c_{120} + c_{021} + c_{012} + c_{102} + c_{201}) - \frac{1}{6} (c_{300} + c_{030} + c_{003}) $$

3.  **Compute Barycentric Coordinates:**
    Calculate the barycentric coordinates $(\alpha_0, \alpha_1, \alpha_2)$ of the evaluation point $\mathbf{p}$ relative to the triangle vertices [G]. This is typically done by projecting $\mathbf{p}$ onto the triangle plane or using the area method [G]. Let $\alpha_i$ be the weight for vertex $i$ [G].

4.  **Evaluate Bézier Patch:**
    Compute the interpolated feature value $f(\mathbf{p})$ using the Bernstein basis polynomials of degree 3 [G]:
    $$ f(\mathbf{p}) = \sum_{i+j+k=3} \binom{3}{i,j,k} \alpha_0^i \alpha_1^j \alpha_2^k c_{ijk} $$
    where $\binom{3}{i,j,k} = \frac{3!}{i!j!k!}$ is the multinomial coefficient [G].

**Gradient Estimation:**
The method requires per-vertex gradients $\nabla f_v$ [S1]. These are estimated via a per-vertex least-squares fit over the one-ring neighborhood [S1]. For each vertex $v$, gather all neighbor vertices $\{v_j\}_{j \in N(v)}$ and solve the 2x2 linear system [S1]:
$$ \nabla f_v = \mathbf{A}_v^{-1} \mathbf{b}_v $$
where:
$$ \mathbf{A}_v = \sum_j \Delta \mathbf{p}_j \Delta \mathbf{p}_j^\top $$
$$ \mathbf{b}_v = \sum_j \Delta f_j \Delta \mathbf{p}_j $$
Here, $\Delta \mathbf{p}_j = \mathbf{v}_j - \mathbf{v}_v$ and $\Delta f_j = f_j - f_v$ [S1]. The sum is over all neighbors $j$ of vertex $v$ [S1]. The 2x2 system is solved analytically [S1]. This operation is differentiable and computed at every forward pass, enabling gradients to flow through the vertex topology [S1].

**Pseudocode:**

```python
def dot2(a, b):
    return a[0] * b[0] + a[1] * b[1]

def dot3(a, b):
    return a[0] * b[0] + a[1] * b[1] + a[2] * b[2]

def compute_barycentric_coords(v0, v1, v2, p):
    v0v1 = [v1[0]-v0[0], v1[1]-v0[1], v1[2]-v0[2]]
    v0v2 = [v2[0]-v0[0], v2[1]-v0[1], v2[2]-v0[2]]
    v0p  = [p[0]-v0[0], p[1]-v0[1], p[2]-v0[2]]
    
    dot00 = dot3(v0v2, v0v2)
    dot01 = dot3(v0v2, v0v1)
    dot02 = dot3(v0v2, v0p)
    dot11 = dot3(v0v1, v0v1)
    dot12 = dot3(v0v1, v0p)
    
    inv_det = 1.0 / (dot00 * dot11 - dot01 * dot01)
    alpha2 = (dot11 * dot02 - dot01 * dot12) * inv_det
    alpha1 = (dot00 * dot12 - dot01 * dot02) * inv_det
    alpha0 = 1.0 - alpha1 - alpha2
    return alpha0, alpha1, alpha2

def clough_tocher_interpolate(v0, v1, v2, f0, f1, f2, grad0, grad1, grad2, p):
    e01 = [v1[0]-v0[0], v1[1]-v0[1], v1[2]-v0[2]]
    e12 = [v2[0]-v1[0], v2[1]-v1[1], v2[2]-v1[2]]
    e20 = [v0[0]-v2[0], v0[1]-v2[1], v0[2]-v2[2]]
    
    c300 = f0
    c030 = f1
    c003 = f2
    
    c210 = f0 + (1.0/3.0) * dot3(grad0, e01)
    c120 = f1 - (1.0/3.0) * dot3(grad1, e01)
    c021 = f1 + (1.0/3.0) * dot3(grad1, e12)
    c012 = f2 - (1.0/3.0) * dot3(grad2, e12)
    c102 = f2 + (1.0/3.0) * dot3(grad2, e20)
    c201 = f0 - (1.0/3.0) * dot3(grad0, e20)
    
    sum_edges = c210 + c120 + c021 + c012 + c102 + c201
    sum_vertices = c300 + c030 + c003
    c111 = (1.0/6.0) * sum_edges - (1.0/6.0) * sum_vertices
    
    alpha0, alpha1, alpha2 = compute_barycentric_coords(v0, v1, v2, p)
    
    a0, a1, a2 = alpha0, alpha1, alpha2
    a02, a12, a22 = a0*a0, a1*a1, a2*a2
    
    b300 = a02 * a0
    b030 = a12 * a1
    b003 = a22 * a2
    b210 = 3.0 * a02 * a1
    b120 = 3.0 * a0 * a12
    b021 = 3.0 * a12 * a2
    b012 = 3.0 * a1 * a22
    b102 = 3.0 * a02 * a2
    b201 = 3.0 * a0 * a22
    b111 = 6.0 * a0 * a1 * a2
    
    result = (b300*c300 + b030*c030 + b003*c003 + 
              b210*c210 + b120*c120 + b021*c021 + 
              b012*c012 + b102*c102 + b201*c201 + 
              b111*c111)
    return result

def estimate_vertex_gradient(v_center, neighbors_pos, neighbors_feat, center_feat):
    A = [[0.0, 0.0], [0.0, 0.0]]
    b = [0.0, 0.0]
    
    for pos, feat in zip(neighbors_pos, neighbors_feat):
        dp = [pos[0]-v_center[0], pos[1]-v_center[1]]
        df = feat - center_feat
        
        A[0][0] += dp[0] * dp[0]
        A[0][1] += dp[0] * dp[1]
        A[1][0] += dp[1] * dp[0]
        A[1][1] += dp[1] * dp[1]
        
        b[0] += df * dp[0]
        b[1] += df * dp[1]
        
    det = A[0][0] * A[1][1] - A[0][1] * A[1][0]
    
    if abs(det) < 1e-8:
        return [0.0, 0.0]
        
    inv_det = 1.0 / det
    grad0 = (A[1][1] * b[0] - A[0][1] * b[1]) * inv_det
    grad1 = (-A[1][0] * b[0] + A[0][0] * b[1]) * inv_det
    return [grad0, grad1]
```

**Edge Cases and Pitfalls:**
*   **Degeneracy:** The mesh can become degenerate (e.g., vertices becoming colinear) during densification [S1]. This is handled by detecting degeneracy and re-meshing, although this rarely occurs in practice [S1].
*   **Gradient Estimation:** The least-squares system for gradient estimation must be solved carefully [G]. If the one-ring neighborhood is degenerate (e.g., all neighbors lie on a line), the matrix $\mathbf{A}_v$ becomes singular [G]. A guard against this is required [G].
*   **Continuity:** Standard barycentric interpolation is C0, leading to high-frequency artifacts and visible seams in fully opaque meshes [S1]. Clough-Tocher eliminates these by ensuring C1 continuity [S1].

## Operating characteristics
*   **Time Complexity:** The interpolation itself is O(1) per triangle, involving a fixed number of arithmetic operations (dot products, additions, multiplications) [G]. The gradient estimation is O(N) per vertex where N is the number of neighbors, and this is computed at every forward pass in a CUDA kernel during training [S1].
*   **Memory Complexity:** Requires storing 10 control points per triangle (or equivalently, 3 vertex values and 3 vertex gradients) [S1]. This is slightly more memory than linear interpolation (3 values) but less than storing explicit control points if gradients are derived on the fly [G].
*   **Measured Performance:** Training generally takes between 1-3 minutes on an RTX A6000 Ada [S1].
*   **Strengths:** Eliminates seam artifacts in fully opaque meshes; provides C1 continuity; differentiable, allowing gradients to flow through vertex topology during training [S1].
*   **Limitations:** Requires per-vertex gradients, which must be estimated or learned; slightly more computationally expensive than linear interpolation [G].
*   **When to use:** When rendering fully opaque meshes with feature fields (normals, colors, UVs) where visual continuity across triangle edges is critical [S1].
*   **When not to use:** For transparent meshes where seams are less visible or for real-time applications with extremely tight memory constraints where storing gradients is prohibitive [G].

## Background
The Clough–Tocher scheme was originally developed for C1 interpolation over triangulated domains [G]. In the context of neural reconstruction, it is used to replace linear barycentric interpolation to eliminate gradient discontinuities that manifest as visible seam artifacts along every edge in fully opaque meshes [S1]. The method is implemented using custom forward and backward CUDA kernels for rasterization and interpolation [S1].
