# Barycentric Interpolation on Tetrahedra

Also called: 3D Barycentric Coordinates Interpolation, Barycentric Feature Interpolation, Barycentric Interpolation in Tetrahedra, Linear Feature Interpolation, Piecewise Linear Interpolation (Tetrahedral)

## Overview
Barycentric interpolation on tetrahedra reconstructs a scalar or vector value at an arbitrary point inside a tetrahedron by computing a weighted sum of the values at the tetrahedron's four vertices, where the weights are the point's 3D barycentric coordinates [S1, unofficial][S2, S3, S4]. It extends 2D barycentric interpolation by relating four tetrahedral subvolumes to the total volume, providing a piecewise linear field over the 3D simplex [S1, unofficial]. Unlike [Barycentric Interpolation on Triangles](5671-barycentric-interpolation-on-triangles.md), which operates on 2D surfaces, this method operates in 3D volume using four vertices, making it suitable for unstructured tetrahedral meshes in volume rendering and neural representations [S2][S6, unofficial].

## How it works
**Inputs:**
- Point $p$ (or $x$) in $\mathbb{R}^3$.
- Four vertices of the tetrahedron $v_0, v_1, v_2, v_3 \in \mathbb{R}^3$.
- Feature values at vertices $g(v_0), g(v_1), g(v_2), g(v_3)$, where $g(v_i) \in \mathbb{R}^d$ (for scalar data, $d=1$).

**Outputs:**
- Interpolated feature value $g(p) \in \mathbb{R}^d$.
- Boolean indicating if $p$ is inside the tetrahedron.

**Data Structures:**
- Vertices: Array of 4 vectors, each 3 floats.
- Features: Array of 4 vectors, each $d$ floats.
- Matrix $C$: $3 \times 3$ matrix where column $j$ is $v_{j+1} - v_0$ for $j=0,1,2$.
- Matrix $G$: $d \times 3$ matrix where column $j$ is $g(v_{j+1}) - g(v_0)$ for $j=0,1,2$.

**Steps:**

1. **Check containment:**
   Compute barycentric coordinates $w_1, w_2, w_3$. The point $p$ is inside the tetrahedron if and only if $w_1 > 0$, $w_2 > 0$, $w_3 > 0$, and $w_1 + w_2 + w_3 < 1$ [S1, unofficial]. Note: Some implementations use volume ratios $\phi_i \ge 0$ and $\sum \phi_i = 1$ [S6, unofficial].

2. **Compute barycentric coordinates:**
   Define the matrix $C \in \mathbb{R}^{3 \times 3}$ with columns $v_1 - v_0$, $v_2 - v_0$, and $v_3 - v_0$ [S3].
   Solve for $w = [w_1, w_2, w_3]^T$:
   $$ w = C^{-1} (p - v_0) $$
   The first barycentric coordinate is derived from the constraint $\sum_{i=0}^3 w_i = 1$:
   $$ w_0 = 1 - (w_1 + w_2 + w_3) $$
   [S3]

   *Alternative Volume-Based Computation:*
   Compute the total volume $V$ of the tetrahedron:
   $$ V = \frac{1}{6} | (v_1 - v_0) \cdot ((v_2 - v_0) \times (v_3 - v_0)) | $$
   Compute the volumes of the subtetrahedra formed by $p$ and the faces opposite to each vertex:
   $$ V_0 = \frac{1}{6} | (v_1 - p) \cdot ((v_2 - p) \times (v_3 - p)) | $$
   $$ V_1 = \frac{1}{6} | (v_2 - p) \cdot ((v_3 - p) \times (v_0 - p)) | $$
   $$ V_2 = \frac{1}{6} | (v_3 - p) \cdot ((v_0 - p) \times (v_1 - p)) | $$
   $$ V_3 = \frac{1}{6} | (v_0 - p) \cdot ((v_1 - p) \times (v_2 - p)) | $$
   The barycentric weights are $\alpha_i = V_i / V$ [S4]. Note that $\alpha_i$ corresponds to $w_i$.

3. **Interpolate features:**
   Using the weights $w_i$:
   $$ g(p) = w_0 g(v_0) + w_1 g(v_1) + w_2 g(v_2) + w_3 g(v_3) $$
   [S3]

   *Efficient Affine Form:*
   Precompute $A = G C^{-1}$ and $b = g(v_0) - G C^{-1} v_0$. Then:
   $$ g(p) = A p + b $$
   [S3]

**Parameters:**
- None intrinsic to the method. The geometry of the tetrahedron defines the interpolation.

**Edge Cases and Pitfalls:**
- **Degeneracy:** Matrix $C$ is only invertible if the four vertices are not coplanar and no three vertices are collinear. If degenerate, barycentric coordinate computation fails [S3].
- **Precision:** Floating-point errors may cause $w_i$ to be slightly negative for points on the boundary or inside, requiring epsilon checks [G].
- **Orientation:** The sign of the volume determinant determines the orientation. Absolute values are used for volume-based weights, but the linear system approach handles orientation implicitly via the inverse matrix [S4, S3].

**Pseudocode:**

```python
import numpy as np

def barycentric_interpolation_tet(p, vertices, features):
    """
    Interpolate features at point p inside a tetrahedron defined by vertices.
    
    Args:
        p: numpy array, shape (3,), point to evaluate.
        vertices: numpy array, shape (4, 3), vertices v0, v1, v2, v3.
        features: numpy array, shape (4, d), feature vectors at vertices.
        
    Returns:
        interpolated_feature: numpy array, shape (d,)
        is_inside: bool
    """
    v0, v1, v2, v3 = vertices[0], vertices[1], vertices[2], vertices[3]
    
    # Construct matrix C: columns are v1-v0, v2-v0, v3-v0
    C = np.column_stack((v1 - v0, v2 - v0, v3 - v0))
    
    # Check if C is invertible (determinant non-zero)
    det_C = np.linalg.det(C)
    if np.isclose(det_C, 0):
        raise ValueError("Degenerate tetrahedron: vertices are coplanar or collinear.")
        
    # Solve for w1, w2, w3: C * w = p - v0
    diff = p - v0
    try:
        w123 = np.linalg.solve(C, diff)
    except np.linalg.LinAlgError:
        raise ValueError("Matrix C is singular.")
        
    w1, w2, w3 = w123
    w0 = 1.0 - (w1 + w2 + w3)
    
    # Check if point is inside
    # Strictly inside: all weights > 0. For boundary inclusion, use >= -epsilon
    epsilon = 1e-9
    is_inside = (w0 >= -epsilon) and (w1 >= -epsilon) and (w2 >= -epsilon) and (w3 >= -epsilon)
    
    if not is_inside:
        # Return None or handle outside case as needed
        return None, False
        
    # Interpolate features
    # g(p) = w0*g(v0) + w1*g(v1) + w2*g(v2) + w3*g(v3)
    interpolated_feature = w0 * features[0] + w1 * features[1] + w2 * features[2] + w3 * features[3]
    
    return interpolated_feature, True

def barycentric_interpolation_tet_affine(p, vertices, features):
    """
    Efficient affine interpolation using precomputed A and b.
    """
    v0, v1, v2, v3 = vertices[0], vertices[1], vertices[2], vertices[3]
    
    # Construct C and G
    C = np.column_stack((v1 - v0, v2 - v0, v3 - v0))
    G = np.column_stack((features[1] - features[0], features[2] - features[0], features[3] - features[0]))
    
    # Precompute A and b
    C_inv = np.linalg.inv(C)
    A = G @ C_inv
    b = features[0] - A @ v0
    
    # Check containment using barycentric coords derived from affine map
    # w123 = C_inv * (p - v0)
    w123 = C_inv @ (p - v0)
    w1, w2, w3 = w123
    w0 = 1.0 - (w1 + w2 + w3)
    
    epsilon = 1e-9
    is_inside = (w0 >= -epsilon) and (w1 >= -epsilon) and (w2 >= -epsilon) and (w3 >= -epsilon)
    
    if not is_inside:
        return None, False
        
    interpolated_feature = A @ p + b
    return interpolated_feature, True
```

## Subtopics

### [Barycentric Interpolation on Triangles](5671-barycentric-interpolation-on-triangles.md)
Barycentric interpolation on triangles evaluates vertex attributes (normals, colors, UVs) at a ray hit point using barycentric coordinates. It provides a linearly varying field over the 2D simplex defined by the triangle. Unlike [Barycentric Interpolation on Tetrahedra](1843-barycentric-interpolation-on-tetrahedra.md), which operates in 3D volume using four vertices, this method operates on the 2D surface using three vertices. It is distinct from [Clough–Tocher Bézier Patch Interpolation](9134-clough-tocher-b-zier-patch-interpolation.md) by being strictly linear and C0 continuous, which is computationally cheaper but prone to visible shading discontinuities across edges if vertex normals are not shared.

### SDF Aggregation via Barycentric Interpolation
Aggregates new point positions and their SDF values into the existing SDF field using barycentric interpolation within tetrahedra [S5, unofficial]. It clones SDF values for non-neighbor points, computes inside tetrahedra and barycentric coordinates for updated points, creates a mask for points inside tetrahedra, and updates SDF at mask positions using einsum: `barycentric_coords[mask] dot sdf[tets[inside_tets[mask]]]`. Optional feature interpolation follows the same pattern. Non-neighbor points have SDF and features set to 0, and positions are updated [S5, unofficial].

### Input Preconditioning for Tetrahedral Encoder
A global affine transformation $y = A^* x + t$ applied to input coordinates before encoding, designed to mitigate geometric anisotropy introduced by tetrahedral barycentric interpolation [S3]. The preconditioner $T$ in homogeneous coordinates is $T = [[A^*, t], [0^T, 1]]$. The encoder-induced local metric for tetrahedron $T$ is $M_T = C_T^{-1} C_T^{-1}$, where $C_T = [v_1-v_0, v_2-v_0, v_3-v_0]$. The cube-averaged metric $M = \frac{1}{6} \sum_{T \in \{S_0..S_5\}} M_T = \frac{1}{3} [[5, -2, -2], [-2, 5, -2], [-2, -2, 5]]$ is invariant under coordinate axis permutations. Without preconditioning, the encoder attenuates motion along the body diagonal $[1,1,1]$ and amplifies transverse directions by $\sqrt{7}$ on average, causing directional bias [S3].

### Levelwise Feature Concatenation
Concatenates barycentrically interpolated feature vectors from multiple resolution levels $\ell = 0$ to $L-1$ into a single feature vector $z(x)$ [S3]. The formula is $z(x) = \bigoplus_{\ell=0}^{L-1} g^{(\ell)}(x) = [g^{(0)}(x)^T, ..., g^{(L-1)}(x)^T]^T$ in $\mathbb{R}^{dL}$. In a region where feature selection is fixed, $z(x) = A'x + b'$, where $A'$ stacks $A^{(\ell)}$ and $b'$ stacks $b^{(\ell)}$ [S3].

### Barycentric Feature Interpolation for Neural Textures
A sampling technique for neural proxy volume rendering that maps Cartesian coordinates to Barycentric coordinates to sample features from a neural texture, using local information instead of global scene coordinates [S6, unofficial]. It decomposes proxy prisms into three tetrahedra using the method from [PBFJ05]. For a Cartesian point $x$ and tetrahedron $\tau$ with vertices $ABCD$, it computes volumes $V_A, V_B, V_C, V_D$ and total volume $V_{ABCD}$ to determine barycentric components $\phi_A, \phi_B, \phi_C, \phi_D$. It checks if sample $x$ is within tetrahedron $\tau$ by verifying $\phi_i \ge 0$ and $\sum \phi_i = 1$. It finds the specific tetrahedron $\tau_x$ containing $x$ and computes UV coordinate $u = \phi_A u_A + \phi_B u_B + \phi_C u_C + \phi_D u_D$ [S6, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per tetrahedron for interpolation, dominated by matrix inversion or solving a $3 \times 3$ linear system. The affine precomputation is $O(1)$ per tetrahedron, reducing per-point cost to a matrix-vector multiplication.
- **Memory Complexity:** $O(1)$ per tetrahedron to store vertices and features. Precomputed $A$ and $b$ matrices add $O(d \times 3)$ and $O(d)$ storage per tetrahedron.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Linear with the number of tetrahedra traversed. Efficient for structured tetrahedral grids due to predictable memory access patterns.
- **Strengths:** Exact linear interpolation, computationally cheap, works for any feature dimension $d$, affine property allows for efficient precomputation and analysis of neural network behavior [S3].
- **Limitations:** Only C0 continuous across tetrahedron boundaries, leading to potential shading artifacts if vertex normals are not shared. Degenerate tetrahedra cause numerical instability. Directional bias in unpreconditioned neural encoders [S3].
- **When to use:** When data is naturally represented on a tetrahedral mesh, or when using tetrahedral neural representations (e.g., TetraSDF, Neural Proxy).
- **When not to use:** When higher-order continuity is required, or when the data is better represented on a regular grid (use trilinear interpolation) or triangles (use 2D barycentric interpolation).

## Background
Barycentric interpolation on tetrahedra extends the well-known 2D barycentric coordinates to 3D by relating four tetrahedral subvolumes [S1, unofficial]. It is commonly applied within each tetrahedron of an unstructured data set partition to reconstruct in-between values as a weighted sum of scalar values at the vertices [S2]. The method is fundamental in unstructured grid rendering, finite element analysis, and recent neural implicit representations like TetraSDF and Neural Proxy [S3][S6, unofficial]. The affine property of barycentric interpolation within a tetrahedron has been proven and utilized to analyze the geometric anisotropy of tetrahedral encoders [S3].
