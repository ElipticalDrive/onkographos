# Exterior-Face Ray Casting

Also called: Distributed-memory volume ray-casting, Parallel Volume Ray-Casting on Unstructured Grids, Visible Exterior Face Rendering

## Overview
Exterior-Face Ray Casting is a parallel volume rendering technique for unstructured grids that restricts ray casting to visible exterior faces of subvolumes, traversing elements until exiting another exterior face [S1, unofficial][S2, unofficial]. It distinguishes itself from sibling methods by explicitly separating view-independent connectivity preprocessing from view-dependent face visibility culling, enabling efficient distributed compositing via associative ray segmentation [S1, unofficial][S2, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   Unstructured grid data (elements, nodes, connectivity) [S1, unofficial][S2, unofficial].
*   Scalar field values at nodes [S1, unofficial][S2, unofficial].
*   Transfer function (mapping scalar values to color and opacity) [S1, unofficial].
*   Camera parameters (eye position, viewing direction) [S1, unofficial][S2, unofficial].
*   Image resolution and partitioning scheme [S2, unofficial].

**Outputs:**
*   Final composited image (subimages per processor, merged globally) [S2, unofficial].

### Data Structures

**Exterior Face List:**
*   A list of all faces on the boundary of the local subvolume [S1, unofficial][S2, unofficial].
*   Each face entry contains:
    *   Vertex indices (defining the polygon) [S1, unofficial][S2, unofficial].
    *   Face normal vector (precomputed in view-independent step) [S1, unofficial][S2, unofficial].
    *   Connectivity to adjacent elements (for traversal) [S1, unofficial][S2, unofficial].

**Ray Buffer:**
*   A two-dimensional array of linked lists [S2, unofficial].
*   Dimensions correspond to the image resolution assigned to the processor [S2, unofficial].
*   Each entry points to a linked list of ray segments contributing to that pixel [S2, unofficial].
*   Segments are sorted by depth (visibility order) upon insertion or at compositing time [S2, unofficial].

**Element Connectivity:**
*   Adjacency graph of elements within the subvolume [S1, unofficial][S2, unofficial].
*   Used to traverse from one element to the next along a ray [S1, unofficial][S2, unofficial].

### Preprocessing

1.  **View-Independent Preprocessing (Done Once):**
    *   Determine connectivity between elements within the subvolume [S1, unofficial][S2, unofficial].
    *   Identify all exterior faces (faces with no adjacent element in the subvolume) [S1, unofficial][S2, unofficial].
    *   Calculate face normals for all exterior faces [S1, unofficial][S2, unofficial].

2.  **View-Dependent Preprocessing (Per View):**
    *   Iterate through the exterior face list [S1, unofficial][S2, unofficial].
    *   Test visibility of each face from the current eye position (e.g., using dot product of face normal and view vector) [S1, unofficial][S2, unofficial].
    *   Collect all visible exterior faces into a "visible face list" [S1, unofficial][S2, unofficial].
    *   Orthographically project these visible faces onto the screen to determine the exact screen area (pixels) for ray casting [S1, unofficial].

### Ray Casting Loop

1.  **Initialization:**
    *   For each pixel in the projected area of each visible exterior face, generate a ray from the eye [S1, unofficial][S2, unofficial].
    *   Initialize ray parameters: origin $P(0)$, direction $d$, current parameter $t=0$ [S1, unofficial][S2, unofficial].

2.  **Entry Detection:**
    *   Find the intersection of the ray with the visible exterior face [S1, unofficial].
    *   Determine the entry point $a$ (parameter $t_a$) [S1, unofficial][S2, unofficial].

3.  **Element Traversal:**
    *   While the ray has not exited the data domain:
        *   Identify the current element the ray is traversing [S1, unofficial][S2, unofficial].
        *   Determine the exit point $b$ (parameter $t_b$) from the current element [S1, unofficial][S2, unofficial].
        *   **Segmentation:** Define the ray segment from $a$ to $b$ [S1, unofficial].
        *   **Sampling:** Sample the scalar field along the segment $[t_a, t_b]$ (see Sampling below) [S1, unofficial][S2, unofficial].
        *   **Local Compositing:** Compute the intensity contribution of this segment using front-to-back compositing [S1, unofficial][S2, unofficial].
        *   **Segment Output:** Store the segment's contribution (or intermediate state) for later global compositing [S1, unofficial][S2, unofficial].
        *   Update $a = b$ [S1, unofficial][S2, unofficial].
        *   Use connectivity to find the next element [S1, unofficial][S2, unofficial].
        *   If the ray exits the subvolume through an exterior face, add this segment to the Ray Buffer for the corresponding pixel(s) and terminate local traversal for this ray [S1, unofficial][S2, unofficial].

4.  **Exit Handling:**
    *   If the ray exits through an exterior face, it may re-enter the domain if the geometry is concave or if the partition boundary is saw-toothed [S1, unofficial][S2, unofficial].
    *   In such cases, the ray is treated as a new ray entering at the new exterior face [S1, unofficial][S2, unofficial].

### Sampling

**Fixed Sampling (Recommended Implementation):**
*   Precompute a fixed sampling interval $dt$ [S1, unofficial][S2, unofficial].
*   Estimate $dt$ using:
    $$ dt = 0.5 \times \min\left(\frac{l_x}{n_e}, \frac{l_y}{n_e}, \frac{l_z}{n_e}\right) $$
    where $l_x, l_y, l_z$ are the bounding box sizes in x, y, z directions, and $n_e$ is the total number of elements in the domain [S2, unofficial].
    *   *Note:* Source [S1, unofficial] also mentions an alternative estimation: $dt = \frac{l_x + l_y + l_z}{n_e}$ [S1, unofficial]. The minimum-based formula is cited as generating "reasonably good sampling interval values" [S2, unofficial].
*   Sample at least one additional point $c$ between entry $a$ and exit $b$ for linear elements [S1, unofficial][S2, unofficial].
*   Use the **Trapezoid Rule** to calculate the value of the interval between sample points [S1, unofficial][S2, unofficial].

**Adaptive Sampling (Expensive):**
*   For a linear element with interpolation function $f(x,y,z)$, ray $P(t) = P(0) + td$, entry $a$, exit $b$:
    $$ r = \frac{|f(P(b)) - f(P(a))|}{b - a} \cdot k $$
    where $k$ is a constant sampling rate for a unit change of function value [S1, unofficial][S2, unofficial].
*   *Note:* Adaptive sampling is noted as significantly increasing rendering time and is generally avoided in favor of fixed sampling [S1, unofficial][S2, unofficial].

**Gaussian Quadrature Approximation:**
*   For non-linear elements, Gaussian Quadrature is used:
    *   Linear element: Sample at the middle of the segment (1 point).
    *   Quadratic element: Sample 2 points.
    *   Cubic element: Sample 3 points.
*   This approximates a polynomial of degree $2n-1$ using $n$ points, providing precision order $2n-1$ [S1, unofficial][S2, unofficial].
*   *Note:* Since transfer functions are usually not polynomials, multiple samples may still be needed even for linear elements if the transfer function varies rapidly [S1, unofficial].

### Compositing

**Intensity Calculation:**
*   At each sample point, retrieve color and opacity from the transfer function look-up table [S1, unofficial][S2, unofficial].
*   Compute intensity $I(t)$ at point $t$ [S1, unofficial][S2, unofficial].
*   The intensity $I(a, b)$ of a ray segment from entry $a$ to exit $b$ is given by:
    $$ I(a, b) = \int_a^b e^{-\int_a^t \alpha(s) ds} I(t) dt $$
    where $\alpha$ is the attenuation coefficient and $I(t)$ is the intensity at point $t$ [S1, unofficial][S2, unofficial].
    *   *Note:* Source [S2, unofficial] uses $c$ for attenuation coefficient in the formula: $I (a, b) = \int_a^b e^{-\int_a^s c ds'} I(t) dt$. The notation differs but the concept is identical [S1, unofficial][S2, unofficial].

**Associative Compositing:**
*   The compositing operation is associative, allowing rays to be broken into segments [S1, unofficial][S2, unofficial].
*   Each segment is processed independently (sampling and local compositing) [S1, unofficial][S2, unofficial].
*   Segments are combined via a final compositing step [S1, unofficial][S2, unofficial].

**Parallel Compositing Strategies:**
1.  **Separate Local Rendering and Global Compositing:**
    *   Local ray tracing finishes completely [S2, unofficial].
    *   All ray segments are sent to responsible processors [S2, unofficial].
    *   Segments are sorted by visibility order [S2, unofficial].
    *   Global compositing occurs [S2, unofficial].
    *   *Drawback:* Large messages, network congestion [S2, unofficial].
2.  **Overlap Rendering and Compositing:**
    *   Ray segments are sent immediately after generation [S2, unofficial].
    *   Responsible processors sort and composite segments as they arrive [S2, unofficial].
    *   *Benefit:* Improves overall image compositing performance by up to 40% [S2, unofficial].

**Ray Buffer Management:**
*   Incoming ray segments are sorted into the linked list pointed to by the corresponding pixel address in the Ray Buffer [S2, unofficial].
*   Sorted ray segments are composited in order at the end of rendering [S2, unofficial].
*   Final subimages are sent back to the host computer [S2, unofficial].

**Early Ray Termination:**
*   A ray is terminated when the accumulated opacity value reaches unity [S2, unofficial].
*   This affects load balancing: subvolumes with larger projected areas of high-density regions cause rays to terminate earlier, traversing fewer elements [S2, unofficial].

### Pseudocode

```python
def exterior_face_ray_casting(grid, transfer_function, camera, image_width, image_height, num_processors):
    # 1. View-Independent Preprocessing (Done Once)
    exterior_faces = []
    for element in grid.elements:
        for face in element.faces:
            if not face.has_adjacent_element_in_subvolume:
                exterior_faces.append(face)
                face.normal = compute_face_normal(face.vertices)
                face.adjacent_element = element

    # 2. View-Dependent Preprocessing (Per View)
    visible_faces = []
    for face in exterior_faces:
        view_vector = camera.eye_position - face.centroid
        if dot(face.normal, view_vector) > 0:
            visible_faces.append(face)

    # Project visible faces to screen to determine pixel coverage
    screen_pixels = {}
    for face in visible_faces:
        screen_pixels[face] = project_face_to_screen(face, camera, image_width, image_height)

    # 3. Fixed Sampling Parameter Estimation
    bounding_box = compute_bounding_box(grid)
    n_e = len(grid.elements)
    l_x, l_y, l_z = bounding_box.max - bounding_box.min
    dt = 0.5 * min(l_x / n_e, l_y / n_e, l_z / n_e)

    # 4. Initialize Ray Buffer (2D array of linked lists)
    ray_buffer = [[[] for _ in range(image_width)] for _ in range(image_height)]

    # 5. Ray Casting Loop
    for face in visible_faces:
        for pixel in screen_pixels[face]:
            ray_origin = camera.eye_position
            ray_direction = normalize(pixel - ray_origin)
            current_t = 0.0
            
            # Find intersection with current exterior face
            t_entry = intersect_ray_plane(ray_origin, ray_direction, face.plane)
            if t_entry is None or t_entry <= 0:
                continue
            current_t = t_entry
            current_element = face.adjacent_element
            
            ray_segments = []
            
            while current_element is not None:
                # Find exit point from current element
                t_exit = intersect_ray_element(ray_origin, ray_direction, current_element, current_t)
                if t_exit is None:
                    break # Ray escaped domain without hitting another element boundary
                
                segment_start_t = current_t
                segment_end_t = t_exit
                
                # Sampling: entry, exit, and at least one intermediate point
                samples = []
                t_sample = segment_start_t
                while t_sample < segment_end_t:
                    point = ray_origin + ray_direction * t_sample
                    value = interpolate_value(point, current_element, grid)
                    color, opacity = transfer_function(value)
                    samples.append((point, color, opacity))
                    t_sample += dt
                # Ensure exit point is sampled
                if samples[-1][0] != ray_origin + ray_direction * segment_end_t:
                    point = ray_origin + ray_direction * segment_end_t
                    value = interpolate_value(point, current_element, grid)
                    color, opacity = transfer_function(value)
                    samples.append((point, color, opacity))
                
                # Local Compositing for Segment (Front-to-Back)
                seg_color, seg_opacity = composite_front_to_back(samples)
                
                # Store segment for global compositing
                ray_segments.append({
                    'pixel': pixel,
                    'depth': segment_start_t,
                    'color': seg_color,
                    'opacity': seg_opacity
                })
                
                # Move to next element
                current_t = t_exit
                current_element = find_next_element_via_connectivity(ray_direction, current_element, t_exit, grid)
                
                # Early Ray Termination
                if seg_opacity >= 1.0:
                    break
            
            # Send segments to Ray Buffer
            for seg in ray_segments:
                ray_buffer[seg['pixel'][1]][seg['pixel'][0]].append(seg)

    # 6. Global Compositing
    image = [[(0.0, 0.0, 0.0, 0.0) for _ in range(image_width)] for _ in range(image_height)]
    for y in range(image_height):
        for x in range(image_width):
            segments = ray_buffer[y][x]
            segments.sort(key=lambda s: s['depth']) # Sort by visibility order
            if segments:
                final_color, final_opacity = composite_front_to_back(segments)
                image[y][x] = (final_color[0], final_color[1], final_color[2], final_opacity)
            else:
                image[y][x] = (0.0, 0.0, 0.0, 0.0)

    return image

def composite_front_to_back(samples):
    # Standard front-to-back compositing [G]
    out_color = (0.0, 0.0, 0.0)
    out_opacity = 0.0
    for point, color, opacity in samples:
        alpha = opacity
        out_color = out_color + (1.0 - out_opacity) * color * alpha
        out_opacity = out_opacity + (1.0 - out_opacity) * alpha
    return out_color, out_opacity
```

### Edge Cases and Pitfalls
*   **Concavity and Holes:** Rays may enter and exit multiple exterior faces due to concavity, holes, or saw-toothed partition boundaries [S1, unofficial][S2, unofficial]. The algorithm must handle re-entry correctly [S1, unofficial][S2, unofficial].
*   **Degenerate Elements:** Casting is straightforward except for degenerate elements, which require special handling [S1, unofficial][S2, unofficial].
*   **Load Imbalance:** Subvolumes with larger projected areas of high-density regions cause rays to terminate earlier, leading to load imbalance [S2, unofficial].
*   **Network Congestion:** Sending all segments after local rendering can cause large messages and network congestion [S2, unofficial]. Overlapping rendering and compositing mitigates this [S2, unofficial].
*   **Precision:** Fixed sampling may over-sample large elements with constant values [S2, unofficial]. Adaptive sampling is more accurate but expensive [S1, unofficial][S2, unofficial].

## Operating characteristics

**Time Complexity:**
*   Preprocessing: $O(F)$ where $F$ is the number of exterior faces [S1, unofficial][S2, unofficial].
*   Ray Casting: Proportional to the number of pixels and the average number of elements traversed per ray [S1, unofficial][S2, unofficial].
*   Compositing: Depends on the number of ray segments per pixel and the sorting cost [S2, unofficial].

**Memory Complexity:**
*   Ray Buffer: Size depends on the number of ray segments per pixel, which varies with viewing position, data shape, and partitioning [S2, unofficial].
*   Data Structures: Connectivity and exterior face lists are stored in memory [S1, unofficial][S2, unofficial].

**Measured Performance:**
*   Overlapping ray casting and compositing can improve overall image compositing performance by up to 40% [S2, unofficial].
*   Adaptive sampling significantly increases rendering time compared to fixed sampling [S1, unofficial][S2, unofficial].

**Strengths:**
*   Efficient culling of invisible faces [S1, unofficial][S2, unofficial].
*   Parallelizable via associative compositing [S1, unofficial][S2, unofficial].
*   Handles unstructured grids and complex geometries [S1, unofficial][S2, unofficial].

**Limitations:**
*   Load imbalance due to varying ray traversal lengths [S2, unofficial].
*   Network congestion if compositing is not overlapped [S2, unofficial].
*   Complexity of handling concave and partitioned boundaries [S1, unofficial][S2, unofficial].

**When to Use:**
*   Parallel volume rendering of unstructured grids on distributed-memory architectures [S1, unofficial][S2, unofficial].
*   When efficient culling of invisible geometry is critical [S1, unofficial][S2, unofficial].

**When Not to Use:**
*   Interactive rendering rates may require more elaborate image partitioning [S2, unofficial].
