# Delaunay Cover Refinement


## Overview
Delaunay Cover Refinement is a geometric processing method that iteratively subdivides a Delaunay triangulation to ensure all edge lengths are bounded by a specified maximum distance $h$. It solves the problem of generating a sufficiently dense point cloud from a coarse Delaunay cover, which is a prerequisite for subsequent voxelization or surface reconstruction. It differs from standard Delaunay Triangulation [11773-delaunay-triangulation.md] by enforcing a size constraint through subdivision, and from Radiance Meshes [4929-radiance-meshes.md] by focusing on geometric density rather than radiance approximation.

## How it works
**Inputs:**
- Initial point set $P_0$.
- Maximum edge length threshold $h$.

**Outputs:**
- Refined point cloud $P_\kappa$.
- Refined Delaunay cover $DC_\kappa(P)$.

**Data Structures:**
- **Point Cloud $P_i$**: A set of 3D points.
- **Delaunay Cover $DC_i(P)$**: A set of triangles (simplices) formed by the points in $P_i$.
- **Voxel Grid**: A boolean grid aligned with the bounding box of $P_\kappa$, with cell side length $h$.

**Algorithm Steps:**
1. Initialize $i = 0$ and $P_0$ as the input point set. Compute the initial Delaunay cover $DC_0(P)$.
2. Iterate while there exists a triangle $T \in DC_i(P)$ with at least one edge length $L > h$:
   a. For each such triangle $T$, perform a 1-to-4 split.
   b. Calculate the midpoints of the three edges of $T$.
   c. Insert these three midpoints into the point set to form $P_{i+1}$.
   d. Recompute the Delaunay cover for the new point set to form $DC_{i+1}(P)$.
   e. Increment $i$.
3. Terminate when all edges in $DC_i(P)$ have length $\le h$. The final point cloud is $P_\kappa = P_i$.

**Formulas:**
- Edge length check: $\| \mathbf{v}_a - \mathbf{v}_b \| \le h$ for all edges $(\mathbf{v}_a, \mathbf{v}_b)$ in $DC_i(P)$.
- Midpoint calculation: $\mathbf{m}_{ab} = \frac{\mathbf{v}_a + \mathbf{v}_b}{2}$.

**Parameters:**
- $h$: The maximum allowed edge length. Typical values depend on the desired voxel resolution or surface approximation error.

**Edge Cases and Pitfalls:**
- **Precision**: Floating-point errors in midpoint calculation may cause slight deviations from exact geometric centers.
- **Boundaries**: The refinement must handle the boundary of the domain correctly, ensuring no points are added outside the intended volume if bounded.
- **Degenerate Input**: If the initial point set has collinear or coplanar points, the Delaunay triangulation may be ill-defined. [G] Ensure the input points are in general position or use a robust Delaunay implementation.

**Pseudocode:**
```python
def delaunay_cover_refinement(points, h):
    """
    Refine a Delaunay cover until all edges are <= h.
    
    Args:
        points: List of 3D points (numpy arrays or tuples).
        h: Maximum edge length threshold.
        
    Returns:
        refined_points: List of refined 3D points.
    """
    current_points = list(points)
    
    while True:
        # Compute Delaunay triangulation for current points
        # Note: In practice, use a robust library like scipy.spatial.Delaunay
        # or implement a 3D Delaunay algorithm.
        tri = compute_delaunay(current_points)
        
        # Check if any edge is longer than h
        needs_refinement = False
        new_midpoints = []
        
        for simplex in tri.simplices:
            # simplex contains indices of 3 vertices
            v0 = current_points[simplex[0]]
            v1 = current_points[simplex[1]]
            v2 = current_points[simplex[2]]
            
            edges = [(v0, v1), (v1, v2), (v2, v0)]
            
            for va, vb in edges:
                dist = np.linalg.norm(va - vb)
                if dist > h:
                    needs_refinement = True
                    # Calculate midpoint
                    mid = (va + vb) / 2.0
                    # Avoid duplicate midpoints for shared edges
                    # In a full implementation, use a set or hash map to deduplicate
                    new_midpoints.append(mid)
        
        if not needs_refinement:
            break
            
        # Add new midpoints to the point set
        # Deduplicate midpoints to avoid redundant points
        unique_midpoints = deduplicate_points(new_midpoints, tolerance=1e-9)
        current_points.extend(unique_midpoints)
        
    return current_points

def deduplicate_points(points, tolerance=1e-9):
    """Remove points that are closer than tolerance."""
    unique = []
    for p in points:
        is_new = True
        for u in unique:
            if np.linalg.norm(p - u) < tolerance:
                is_new = False
                break
        if is_new:
            unique.append(p)
    return unique
```

## Operating characteristics
- **Time Complexity**: Not given in the sources. The number of iterations $\kappa$ depends on the initial edge lengths and $h$. Each iteration involves recomputing the Delaunay triangulation, which is $O(N \log N)$ in 3D.
- **Memory Complexity**: Not given in the sources. The number of points grows with each refinement step.
- **Strengths**: Guarantees a uniform sampling density bounded by $h$. Simple to implement.
- **Limitations**: May produce a large number of points if the initial mesh is coarse. Does not preserve the original surface topology if the initial cover is not a valid surface representation.
- **When to use**: When a dense, uniform point cloud is required for voxelization or further geometric processing.
- **When not to use**: When preserving the original surface topology is critical without additional constraints, or when computational efficiency is paramount and a coarser approximation is acceptable.

## Background
The method is described in the context of "Volumetric Snapping: Watertight Triangulation of Point Clouds" [S1, unofficial]. It is used to prepare point clouds for voxelization by ensuring sufficient sampling density.
