# Absorption-Only Radiography via Unsorted Hexahedron Projection

Also called: Unsorted Hexahedron Projection, Absorption-Only Radiography

## Overview
This method simulates X-ray radiographs for curvilinear hexahedral meshes by accumulating optical thickness additively, thereby eliminating the need for a global back-to-front visibility sort [S1, unofficial]. It differs from standard polyhedron projection methods, which require sorted compositing to handle opacity correctly, by exploiting the absorption-only regime where emissivity is zero [S1, unofficial].

## How it works
**Inputs:** A curvilinear hexahedral mesh (vertices with 3D positions and scalar extinction coefficients $K_\nu$); a view-projection matrix.
**Outputs:** A 2D radiograph image representing accumulated attenuation.

**Data Structures:**
*   **Mesh:** Curvilinear hexahedra. Each vertex $v$ has position $\mathbf{p}_v$ and extinction coefficient $K_{\nu,v}$.
*   **P-buffer:** A floating-point off-screen buffer (texture) storing the accumulated optical thickness $\tau_{acc}$ per pixel. Initialized to zero.
*   **Triangle Fans/Strips:** Precomputed or on-the-fly decomposition of hexahedra projections into rasterizable primitives.

**Steps:**

1.  **Mesh Decomposition:**
    For each hexahedral cell, determine if it can be projected directly. A cell is valid for direct projection if:
    *   It is non-degenerate (no coinciding vertices).
    *   The projection of each of its six faces is a convex quadrilateral.
    
    If valid, decompose the hexahedron into triangle fans or strips using the method of Max [12, unofficial]. If invalid (degenerate or non-convex face projections), subdivide the hexahedron into tetrahedra. For tetrahedra, use the Shirley and Tuchman method [16, unofficial] to divide the projection into triangle fans.

2.  **Thickness Computation (Software):**
    For each vertex $v$ of the current cell, compute the geometric thickness $l_v$ along the viewing ray. This is done in software using the cell geometry. The specific geometric formula for $l_v$ depends on the curvilinear mapping but is derived from the cell's shape [S1, unofficial].

3.  **Vertex Attenuation Calculation:**
    Compute the attenuation value $A_v$ for each vertex:
    $$ A_v = K_{\nu,v} \cdot l_v $$
    where $K_{\nu,v}$ is the extinction coefficient at vertex $v$ [S1, unofficial].

4.  **Rasterization and Interpolation:**
    Rasterize the triangle fans/strips. For each fragment generated by a primitive:
    *   Interpolate the attenuation values $A_v$ from the vertex data across the primitive using hardware interpolation.
    *   Let $A_{frag}$ be the interpolated attenuation for the current fragment [S1, unofficial].

5.  **Accumulation:**
    Read the current accumulated optical thickness $\tau_{curr}$ from the P-buffer texture at the fragment's screen position.
    Update the accumulated thickness:
    $$ \tau_{new} = \tau_{curr} + A_{frag} $$
    Write $\tau_{new}$ back to the P-buffer. This step uses a floating-point fragment program to ensure precision, as standard framebuffer compositing may not support the required 32-bit floating-point accuracy for addition [S1, unofficial].

6.  **Texture Synchronization:**
    After rendering a batch of cells (to minimize overhead), copy the P-buffer contents to the input texture for the next batch. This is necessary because writes to output buffers are not guaranteed to be in polygon order, and the texture caching mechanism does not account for textures changing on the fly [S1, unofficial].

7.  **Final Image Generation:**
    After all cells are processed, the P-buffer contains the total optical thickness $\tau_{total}$ per pixel. The final intensity $I$ for each pixel is computed as:
    $$ I = I_0 \cdot e^{-\tau_{total}} $$
    where $I_0$ is the incident X-ray intensity (background light) [S1, unofficial].

**Parameters:**
*   **Parallelism:** Four different X-ray wavelength bands can be accumulated in parallel using the red, green, blue, and alpha channels of the P-buffer [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Degenerate Cells:** Hexahedral cells with coinciding vertices must be subdivided into tetrahedra [S1, unofficial].
*   **Non-Convex Projections:** If the projection of any face is non-convex, the cell must be subdivided [S1, unofficial].
*   **Subdivision Errors:** If subdivided tetrahedra share non-planar faces with adjacent non-subdivided cells, gaps or overlaps in viewing ray segments may occur, introducing small errors in total absorption [S1, unofficial].
*   **Precision:** Standard framebuffer compositing operations may lack the necessary 32-bit floating-point accuracy for attenuation accumulation; a fragment program writing to a P-buffer is required [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of cells, assuming constant-time projection and rasterization. The need for subdivision adds overhead for degenerate cases.
*   **Memory Complexity:** $O(W \cdot H)$ for the P-buffer, where $W, H$ are image dimensions.
*   **Strengths:** No global sort required; efficient for large meshes; supports curvilinear hexahedra directly; parallel accumulation of multiple wavelength bands.
*   **Limitations:** Limited to absorption-only regime (no emissivity); potential errors from subdivision artifacts; texture copying overhead if not batched efficiently.
*   **When to use:** Industrial and medical X-ray simulation where self-emission is negligible and high performance is needed for complex hexahedral meshes.
*   **When not to use:** When emissivity is significant, or when strict geometric consistency is required without subdivision artifacts.

## Background
This method was developed for industrial and medical settings where X-ray self-emission is negligible [S1, unofficial]. It builds on the polyhedron projection method [S1, unofficial] and uses techniques from Max [12, unofficial] for hexahedron projection and Shirley and Tuchman [16, unofficial] for tetrahedron projection. The approach addresses the computational cost of sorting and the precision limitations of standard graphics hardware for accumulation [S1, unofficial].
