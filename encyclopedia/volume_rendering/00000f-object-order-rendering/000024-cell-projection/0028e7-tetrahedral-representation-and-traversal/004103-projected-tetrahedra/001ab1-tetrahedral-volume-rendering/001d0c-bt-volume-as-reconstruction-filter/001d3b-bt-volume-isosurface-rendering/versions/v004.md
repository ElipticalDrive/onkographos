# BT Volume Isosurface Rendering

Also called: BT Volume Representation, BT Volumes, Bezier Tetrahedra Volume Rendering

## Overview
BT Volume Isosurface Rendering is a real-time technique for rendering exact isosurfaces from volumetric data by representing the volume as a grid of cubic Bezier Tetrahedra (BT) [S1]. It solves the problem of low-quality, faceted surfaces produced by linear reconstruction methods like Marching Cubes, while avoiding the computational cost of generating and rendering explicit triangle meshes [S1]. The method performs local ray tracing within each tetrahedron inside a GPU pixel shader to find exact intersections with arbitrary isosurface levels [S1].

## How it works

### Inputs and Outputs
*   **Input:** A BT Volume data structure containing a grid of tetrahedra, where each tetrahedron has an associated set of 20 Bezier weights [S1]. The volume space is assumed to be a cuboid with integer dimensions [S1].
*   **Output:** A 2D image where each pixel displays the color of the isosurface intersection, or background if no intersection exists [S1].

### Data Structures
The volume is divided into unit cubes (voxels) [S1]. Each voxel is subdivided into tetrahedra using a canonical mapping $\kappa$ [S1]. The implementation described in the source uses the standard 6-tetrahedron decomposition of a cube [S1].

For each tetrahedron $T$ in the grid, the following data is stored:
1.  **Bounding Tetrahedron Vertices ($T$):** Four points $T = (T_1, T_2, T_3, T_4)$ defining the spatial bounds [S1]. These are typically the integer grid vertices of the voxel [G].
2.  **Bezier Weights ($w_{ijkl}$):** A set of 20 scalar weights [S1]. The indices $i, j, k, l$ are non-negative integers such that $i + j + k + l = 3$ [S1]. These weights define the scalar field value distribution within the tetrahedron [S1].

### Canonical Mapping
The volume space is partitioned into voxels $c_{l,m,n}$ indexed by integer coordinates $(l, m, n)$ [S1]. A canonical mapping function $\kappa$ maps a point's fractional position within a voxel to a specific tetrahedron index $h$ within that voxel [S1].

$$ \kappa : [0, 1]^3 \rightarrow \{h : h \in H\} $$

where $H$ is the set of tetrahedron indices for a single voxel (e.g., $H = \{1, ..., 6\}$ for the standard decomposition) [S1]. The mapping must be shift-invariant, meaning the decomposition pattern is identical for every voxel [S1].

Given a point $Q \in \mathbb{R}^3$, the specific BT $\tau$ containing $Q$ is determined by:

$$ \tau = BT_{[\mathbf{Q}]}(\kappa(\mathbf{Q} - [\mathbf{Q}])) $$

where $[\mathbf{Q}]$ is the integer voxel index containing $Q$ [S1].

### Rendering Algorithm
The rendering is performed via local ray tracing within the GPU pixel shader [S1]. For each pixel, a ray is cast into the volume [S1]. The algorithm iterates through the tetrahedra intersected by the ray [S1].

1.  **Ray-Tetrahedron Intersection:** For each tetrahedron $T$ intersected by the ray, compute the intersection points of the ray with the isosurface defined by the BT within $T$ [S1].
2.  **Bezier Evaluation:** The scalar value $b(\mathbf{P})$ at any point $\mathbf{P}$ inside the tetrahedron is calculated using the BT formula [S1].
3.  **Root Finding:** The intersection with the isosurface value $V_{iso}$ is found by solving for the roots of the univariate polynomial equation derived from the BT formula along the ray parameter $t$ [S1].

#### Bezier Tetrahedron Formula
For a point $\mathbf{P} = (x, y, z, 1)$ in projective space, the barycentric coordinates $r = (r, s, t, u)$ are calculated as:

$$ r = (r, s, t, u) = \mathbf{P} \cdot T^{-1} $$

where $T$ is the $4 \times 4$ matrix formed by the homogeneous coordinates of the vertices $T_1, T_2, T_3, T_4$ [S1].

The value of the BT at $\mathbf{P}$ is:

$$ b(\mathbf{P}) = \sum_{i+j+k+l=3} w_{ijkl} \binom{3}{i,j,k,l} r^i s^j t^k u^l $$

where $\binom{3}{i,j,k,l} = \frac{3!}{i!j!k!l!}$ is the multinomial coefficient [S1].

#### Ray Intersection Implementation
Let the ray be defined by origin $\mathbf{O}$ and direction $\mathbf{D}$ [G]. A point on the ray is $\mathbf{R}(t) = \mathbf{O} + t\mathbf{D}$ [G].

1.  Substitute $\mathbf{R}(t)$ into the barycentric coordinate formula to express $r, s, t, u$ as linear functions of $t$ [S1].
2.  Substitute these linear functions into the BT formula [S1].
3.  Solve for the real roots of $P(t)$ within the range of the tetrahedron's intersection with the ray [S1].
4.  The smallest positive root $t$ corresponds to the entry point of the isosurface [G].

### Pseudocode

```python
def render_bt_volume(ray_origin, ray_direction, bt_volume, isosurface_value):
    """
    Renders a single ray against a BT Volume.
    """
    t_hit = float('inf')
    
    # Standard 3D DDA voxel traversal algorithm [G]
    voxel_bounds = compute_voxel_bounds(ray_origin, ray_direction, bt_volume.dimensions)
    
    for voxel in voxel_bounds:
        for tet in voxel.tetrahedra:
            # 1. Check if ray intersects the bounding tetrahedron T
            t_enter, t_exit = intersect_ray_tetrahedron(ray_origin, ray_direction, tet.vertices)
            
            if t_enter == float('inf'):
                continue
                
            # 2. Evaluate the BT polynomial along the ray segment [t_enter, t_exit]
            coeffs = compute_bt_polynomial_coefficients(
                ray_origin, 
                ray_direction, 
                tet.vertices, 
                tet.weights
            )
            
            # 3. Solve for roots of P(t) - isosurface_value = 0
            coeffs[3] -= isosurface_value 
            
            roots = solve_cubic_polynomial(coeffs)
            
            # 4. Filter valid roots
            for t_root in roots:
                if t_enter <= t_root <= t_exit and t_root > 0:
                    if t_root < t_hit:
                        t_hit = t_root
                        
    return t_hit

def compute_voxel_bounds(origin, direction, dimensions):
    """Returns list of voxel indices intersected by the ray using 3D DDA [G]."""
    bounds = []
    x, y, z = origin
    dx, dy, dz = direction
    step_x = 1 if dx > 0 else -1
    step_y = 1 if dy > 0 else -1
    step_z = 1 if dz > 0 else -1
    
    t_max_x = ((dimensions[0] - x) / dx if step_x > 0 else (-x) / dx) if dx != 0 else float('inf')
    t_max_y = ((dimensions[1] - y) / dy if step_y > 0 else (-y) / dy) if dy != 0 else float('inf')
    t_max_z = ((dimensions[2] - z) / dz if step_z > 0 else (-z) / dz) if dz != 0 else float('inf')
    
    t_delta_x = abs(1.0 / dx) if dx != 0 else float('inf')
    t_delta_y = abs(1.0 / dy) if dy != 0 else float('inf')
    t_delta_z = abs(1.0 / dz) if dz != 0 else float('inf')
    
    ix, iy, iz = int(x), int(y), int(z)
    while 0 <= ix < dimensions[0] and 0 <= iy < dimensions[1] and 0 <= iz < dimensions[2]:
        bounds.append((ix, iy, iz))
        if t_max_x < t_max_y:
            if t_max_x < t_max_z:
                ix += step_x; t_max_x += t_delta_x
            else:
                iz += step_z; t_max_z += t_delta_z
        else:
            if t_max_y < t_max_z:
                iy += step_y; t_max_y += t_delta_y
            else:
                iz += step_z; t_max_z += t_delta_z
    return bounds

def intersect_ray_tetrahedron(origin, direction, vertices):
    """Returns (t_enter, t_exit) for ray-tetrahedron intersection using face plane tests [G]."""
    v0, v1, v2, v3 = vertices
    faces = [(v0, v1, v2), (v0, v2, v3), (v0, v3, v1), (v1, v3, v2)]
    t_min, t_max = -float('inf'), float('inf')
    
    for face in faces:
        a, b, c = face
        e1 = (b[0]-a[0], b[1]-a[1], b[2]-a[2])
        e2 = (c[0]-a[0], c[1]-a[1], c[2]-a[2])
        N = (e1[1]*e2[2]-e1[2]*e2[1], e1[2]*e2[0]-e1[0]*e2[2], e1[0]*e2[1]-e1[1]*e2[0])
        denom = N[0]*direction[0] + N[1]*direction[1] + N[2]*direction[2]
        if abs(denom) < 1e-8: continue
        t = (N[0]*(a[0]-origin[0]) + N[1]*(a[1]-origin[1]) + N[2]*(a[2]-origin[2])) / denom
        if t < t_min or t > t_max: return float('inf'), float('inf')
        t_min = max(t_min, t)
        t_max = min(t_max, t)
        
    if t_min > t_max: return float('inf'), float('inf')
    return t_min, t_max

def compute_bt_polynomial_coefficients(origin, direction, vertices, weights):
    """
    Computes the coefficients [A, B, C, D] for the cubic polynomial
    representing the BT value along the ray.
    """
    T = build_homogeneous_matrix(vertices)
    T_inv = invert_matrix(T)
    poly_coeffs = [0.0, 0.0, 0.0, 0.0]
    
    for i in range(4):
        for j in range(4 - i):
            for k in range(4 - i - j):
                l = 3 - i - j - k
                weight = weights[i * 10 + j * 4 + k]
                multinomial = factorial(3) // (factorial(i) * factorial(j) * factorial(k) * factorial(l))
                
                r0, r1 = get_barycentric_linear_coeffs(0, origin, direction, T_inv)
                s0, s1 = get_barycentric_linear_coeffs(1, origin, direction, T_inv)
                t0, t1 = get_barycentric_linear_coeffs(2, origin, direction, T_inv)
                u0, u1 = get_barycentric_linear_coeffs(3, origin, direction, T_inv)
                
                poly_r = power_linear_poly(r0, r1, i)
                poly_s = power_linear_poly(s0, s1, j)
                poly_t = power_linear_poly(t0, t1, k)
                poly_u = power_linear_poly(u0, u1, l)
                
                poly_term = multiply_polynomials(poly_r, poly_s)
                poly_term = multiply_polynomials(poly_term, poly_t)
                poly_term = multiply_polynomials(poly_term, poly_u)
                
                scale = weight * multinomial
                for idx in range(4):
                    poly_coeffs[idx] += scale * poly_term[idx]
                    
    return poly_coeffs

def build_homogeneous_matrix(vertices):
    """Constructs a 4x4 matrix from 4 homogeneous vertices."""
    return [list(v) + [1.0] for v in vertices]

def invert_matrix(M):

    det = (M[0][0]*M[1][1]*M[2][2]*M[3][3] - M[0][0]*M[1][1]*M[2][3]*M[3][2] + M[0][0]*M[1][2]*M[2][3]*M[3][1] - M[0][0]*M[1][2]*M[2][1]*M[3][3] + M[0][0]*M[1][3]*M[2][1]*M[3][2] - M[0][0]*M[1][3]*M[2][2]*M[3][1] - M[0][1]*M[1][0]*M[2][2]*M[3][3] + M[0][1]*M[1][0]*M[2][3]*M[3][2] - M[0][1]*M[1][2]*M[2][3]*M[3][0] + M[0][1]*M[1][2]*M[2][0]*M[3][3] - M[0][1]*M[1][3]*M[2][0]*M[3][2] + M[0][1]*M[1][3]*M[2][2]*M[3][0] + M[0][2]*M[1][0]*M[2][3]*M[3][1] - M[0][2]*M[1][0]*M[2][1]*M[3][3] + M[0][2]*M[1][1]*M[2][3]*M[3][0] - M[0][2]*M[1][1]*M[2][0]*M[3][3] + M[0][2]*M[1][3]*M[2][0]*M[3][1] - M[0][2]*M[1][3]*M[2][1]*M[3][0] - M[0][3]*M[1][0]*M[2][1]*M[3][2] + M[0][3]*M[1][0]*M[2][2]*M[3][1] - M[0][3]*M[1][1]*M[2][2]*M[3][0] + M[0][3]*M[1][1]*M[2][0]*M[3][2] - M[0][3]*M[1][2]*M[2][0]*M[3][1] + M[0][3]*M[1][2]*M[2][1]*M[3][0])
    if abs(det) < 1e-8: return M
    inv_det = 1.0 / det
    inv[0][0] = (M[1][1]*M[2][2]*M[3][3] - M[1][1]*M[2][3]*M[3][2] - M[1][2]*M[2][1]*M[3][3] + M[1][2]*M[2][3]*M[3][1] + M[1][3]*M[2][1]*M[3][2] - M[1][3]*M[2][2]*M[3][1]) * inv_det
    inv[0][1] = (-M[0][1]*M[2][2]*M[3][3] + M[0][1]*M[2][3]*M[3][2] + M[0][2]*M[2][1]*M[3][3] - M[0][2]*M[2][3]*M[3][1] - M[0][3]*M[2][1]*M[3][2] + M[0][3]*M[2][2]*M[3][1]) * inv_det

    inv[1][0] = (-M[1][0]*M[2][2]*M[3][3] + M[1][0]*M[2][3]*M[3][2] + M[1][2]*M[2][0]*M[3][3] - M[1][2]*M[2][3]*M[3][0] - M[1][3]*M[2][0]*M[3][2] + M[1][3]*M[2][2]*M[3][0]) * inv_det
    inv[1][1] = (M[0][0]*M[2][2]*M[3][3] - M[0][0]*M[2][3]*M[3][2] - M[0][2]*M[2][0]*M[3][3] + M[0][2]*M[2][3]*M[3][0] + M[0][3]*M[2][0]*M[3][2] - M[0][3]*M[2][2]*M[3][0]) * inv_det
    inv[1][2] = (-M[0][0]*M[1][2]*M[3][3] + M[0][0]*M[1][3]*M[3][2] + M[0][2]*M[1][0]*M[3][3] - M[0][2]*M[1][3]*M[3][0] - M[0][3]*M[1][0]*M[3][2] + M[0][3]*M[1][2]*M[3][0]) * inv_det
    inv[1][3] = (M[0][0]*M[1][2]*M[2][3] - M[0][0]*M[1][3]*M[2][2] - M[0][2]*M[1][0]*M[2][3] + M[0][2]*M[1][3]*M[2][0] + M[0][3]*M[1][0]*M[2][2] - M[0][3]*M[1][2]*M[2][0]) * inv_det
    inv[2][0] = (M[1][0]*M[2][1]*M[3][3] - M[1][0]*M[2][3]*M[3][1] - M[1][1]*M[2][0]*M[3][3] + M[1][1]*M[2][3]*M[3][0] + M[1][3]*M[2][0]*M[3][1] - M[1][3]*M[2][1]*M[3][0]) * inv_det
    inv[2][1] = (-M[0][0]*M[2][1]*M[3][3] + M[0][0]*M[2][3]*M[3][1] + M[0][1]*M[2][0]*M[3][3] - M[0][1]*M[2][3]*M[3][0] - M[0][3]*M[2][0]*M[3][1] + M[0][3]*M[2][1]*M[3][0]) * inv_det

def get_barycentric_linear_coeffs(coord_idx, origin, direction, T_inv):
    """
    Returns (constant, linear) coefficients for the k-th barycentric coordinate.
    r_k(t) = r_k0 + r_k1 * t
    """
    col = T_inv[coord_idx]
    r0 = origin[0]*col[0] + origin[1]*col[1] + origin[2]*col[2] + 1.0*col[3]
    r1 = direction[0]*col[0] + direction[1]*col[1] + direction[2]*col[2] + 0.0*col[3]
    return r0, r1

def power_linear_poly(c0, c1, n):
    """
    Computes the polynomial coefficients for (c0 + c1*t)^n.
    Returns list of length n+1.
    """
    if n == 0:
        return [1.0]
    coeffs = [0.0] * (n + 1)
    for k in range(n + 1):
        binom = factorial(n) // (factorial(k) * factorial(n - k))
        term = binom * (c0 ** (n - k)) * (c1 ** k)
        coeffs[k] = term
    return coeffs

def multiply_polynomials(p1, p2):
    """
    Multiplies two polynomials represented as coefficient lists.
    """
    deg1 = len(p1) - 1
    deg2 = len(p2) - 1
    result_deg = deg1 + deg2
    result = [0.0] * (result_deg + 1)
    for i in range(len(p1)):
        for j in range(len(p2)):
            result[i + j] += p1[i] * p2[j]
    return result

def solve_cubic_polynomial(coeffs):
    """
    Solves Ax^3 + Bx^2 + Cx + D = 0 using Cardano's method [G].
    Returns list of real roots.
    """
    A, B, C, D = coeffs
    if abs(A) < 1e-8:
        return solve_quadratic([B, C, D])
    B /= A; C /= A; D /= A
    p = C - B*B/3.0
    q = 2.0*B*B*B/27.0 - B*C/3.0 + D
    D_val = q*q/4.0 + p*p*p/27.0
    roots = []
    if D_val > 0:
        u = (-q/2.0 + D_val**0.5)**(1/3)
        v = (-q/2.0 - D_val**0.5)**(1/3)
        roots.append(u + v - B/3.0)
    elif D_val == 0:
        if q == 0:
            roots.append(-B/3.0)
        else:
            u = (-q/2.0)**(1/3)
            roots.append(2*u - B/3.0)
            roots.append(-u - B/3.0)
    else:
        r = (-p/3.0)**0.5
        theta = math.acos(-q/(2*r*r*r))
        roots.append(2*r*math.cos(theta/3) - B/3.0)
        roots.append(2*r*math.cos((theta + 2*math.pi)/3) - B/3.0)
        roots.append(2*r*math.cos((theta + 4*math.pi)/3) - B/3.0)
    return roots

def solve_quadratic(coeffs):
    A, B, C = coeffs
    if abs(A) < 1e-8:
        return [-C/B] if abs(B) > 1e-8 else []
    disc = B*B - 4*A*C
    if disc < 0: return []
    if disc == 0: return [-B/(2*A)]
    sqrt_disc = disc**0.5
    return [(-B + sqrt_disc)/(2*A), (-B - sqrt_disc)/(2*A)]

def factorial(n):
    if n <= 1: return 1
    res = 1
    for i in range(2, n + 1): res *= i
    return res
```

### Edge Cases and Pitfalls
*   **Boundary Points:** Points exactly on the boundary between tetrahedra can be considered as covered by either adjacent BT [S1]. The rendering logic must handle this consistently to avoid gaps or double-rendering [G].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** The rendering time per pixel depends on the number of tetrahedra the ray intersects [S1]. For each intersection, a cubic polynomial must be solved [S1].

### Measured Performance
*   The method is designed for real-time interactive rendering on graphics hardware [S1].
*   It allows rendering any isosurface level without additional precomputation work [S1].

### Strengths and Limitations
*   **Strengths:**
    *   Renders exact isosurfaces directly in the pixel shader, avoiding triangle mesh generation [S1].
    *   Supports arbitrary isosurface levels without additional work [S1].
    *   Provides high-quality reconstruction filtering with arbitrary footprints and kernels [S1].
    *   Smooth surfaces compared to linear reconstruction methods like Marching Cubes [S1].
*   **Limitations:**
    *   Requires precomputation of the BT Volume from the source data or reconstruction filter [S1].
    *   Cubic polynomial solving can be computationally expensive per tetrahedron compared to linear intersection tests [S1].
    *   The method assumes the volume can be effectively approximated by cubic Bezier Tetrahedra [S1].

## Background

### Origin
Bezier Tetrahedra were originally developed by Loop and Blinn [2006] for rendering on graphics hardware [S1]. This paper extends that work to volume rendering, introducing BT Volumes as a representation for volumetric functions [S1].

### History and Development
The method was presented in 2008 as a solution to the limitations of Marching Cubes, which relies on linear reconstruction and produces faceted surfaces [S1]. The approach leverages the tensor form of BTs to allow efficient transformation and evaluation on GPUs [S1].

### Applications
Applications include hurricane visualization, medical diagnosis and planning, and smoke and particle systems [S1].
