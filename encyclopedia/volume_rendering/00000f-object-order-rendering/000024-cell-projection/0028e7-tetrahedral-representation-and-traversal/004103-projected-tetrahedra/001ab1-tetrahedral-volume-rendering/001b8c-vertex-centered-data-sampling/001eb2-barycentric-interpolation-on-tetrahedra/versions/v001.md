# Barycentric Interpolation on Tetrahedra

Also called: 3D Barycentric Coordinates Interpolation

## Overview
Barycentric interpolation on tetrahedra computes the scalar value at an arbitrary point inside a tetrahedron by weighting the values at its four vertices according to the point's barycentric coordinates. It solves the problem of accurately sampling vertex-centered data within a tetrahedral mesh, extending the well-known 2D barycentric coordinate system to 3D by relating four tetrahedral subvolumes. Unlike linear interpolation on hexahedral cells which requires solving a system or using trilinear blending, tetrahedral barycentric interpolation provides a direct, geometrically intuitive linear blend based on volume ratios.

## How it works
**Inputs:**
- A tetrahedron defined by four vertices $V_a, V_b, V_c, V_d$ with positions $\mathbf{p}_a, \mathbf{p}_b, \mathbf{p}_c, \mathbf{p}_d \in \mathbb{R}^3$.
- Scalar values $f(V_a), f(V_b), f(V_c), f(V_d)$ associated with each vertex.
- A query point $\mathbf{q} = (x, y, z)$ in 3D space.

**Outputs:**
- The interpolated scalar value $f(\mathbf{q})$.
- A boolean indicating whether $\mathbf{q}$ lies inside the tetrahedron.

**Data Structures:**
- Vertex positions: Array of 4 vectors, each 3 floats.
- Vertex values: Array of 4 floats.
- Barycentric coordinates: 4 floats $(\alpha, \beta, \gamma, \delta)$ such that $\alpha + \beta + \gamma + \delta = 1$.

**Formulas:**
The barycentric coordinates $\beta, \gamma, \delta$ correspond to the vertices $V_b, V_c, V_d$ respectively. The coordinate for $V_a$ is $\alpha = 1 - \beta - \gamma - \delta$.

The coordinates are derived from the ratios of the volumes of the sub-tetrahedra formed by $\mathbf{q}$ and the faces of the original tetrahedron opposite to each vertex. Let $V_{total}$ be the signed volume of the tetrahedron $(V_a, V_b, V_c, V_d)$. Let $V_{q b c d}$ be the signed volume of the tetrahedron formed by $\mathbf{q}, V_b, V_c, V_d$. Similarly define $V_{q a c d}$ (opposite $V_b$), $V_{q a b d}$ (opposite $V_c$), and $V_{q a b c}$ (opposite $V_d$).

The barycentric coordinates are:
$$ \beta = \frac{V_{q b c d}}{V_{total}}, \quad \gamma = \frac{V_{q a c d}}{V_{total}}, \quad \delta = \frac{V_{q a b d}}{V_{total}} $$
$$ \alpha = 1 - \beta - \gamma - \delta = \frac{V_{q a b c}}{V_{total}} $$

The signed volume of a tetrahedron defined by vertices $\mathbf{p}_1, \mathbf{p}_2, \mathbf{p}_3, \mathbf{p}_4$ is:
$$ V(\mathbf{p}_1, \mathbf{p}_2, \mathbf{p}_3, \mathbf{p}_4) = \frac{1}{6} (\mathbf{p}_4 - \mathbf{p}_1) \cdot ((\mathbf{p}_2 - \mathbf{p}_1) \times (\mathbf{p}_3 - \mathbf{p}_1)) $$

**Interpolation Formula:**
$$ f(\mathbf{q}) = \alpha f(V_a) + \beta f(V_b) + \gamma f(V_c) + \delta f(V_d) $$
Substituting $\alpha$:
$$ f(\mathbf{q}) = (1 - \beta - \gamma - \delta) f(V_a) + \beta f(V_b) + \gamma f(V_c) + \delta f(V_d) $$
Note: The source [S1, unofficial] uses notation $V_{qbcd}$ etc. to denote the value at the vertex *opposite* the sub-volume involving $\mathbf{q}$. Specifically, $V_{qbcd}$ corresponds to vertex $V_a$ because the sub-volume $q,b,c,d$ does not include $V_a$. Thus $f(V_{qbcd})$ in [S1, unofficial] maps to $f(V_a)$ in standard notation.

**Steps:**
1. Compute the total signed volume $V_{total}$ of the tetrahedron $(V_a, V_b, V_c, V_d)$.
2. Compute the signed volumes of the four sub-tetrahedra:
   - $V_{sub,a} = V(\mathbf{q}, V_b, V_c, V_d)$
   - $V_{sub,b} = V(\mathbf{q}, V_a, V_c, V_d)$
   - $V_{sub,c} = V(\mathbf{q}, V_a, V_b, V_d)$
   - $V_{sub,d} = V(\mathbf{q}, V_a, V_b, V_c)$
3. Calculate barycentric coordinates:
   - $\alpha = V_{sub,a} / V_{total}$
   - $\beta = V_{sub,b} / V_{total}$
   - $\gamma = V_{sub,c} / V_{total}$
   - $\delta = V_{sub,d} / V_{total}$
4. Check containment: The point $\mathbf{q}$ is inside the tetrahedron if and only if $\alpha > 0, \beta > 0, \gamma > 0, \delta > 0$. Equivalently, using the source's condition on $\beta, \gamma, \delta$: $\beta > 0, \gamma > 0, \delta > 0$, and $\beta + \gamma + \delta < 1$ (which implies $\alpha > 0$). [S1, unofficial]
5. If inside, compute $f(\mathbf{q})$ using the interpolation formula. If outside, the result is undefined or requires fallback logic (e.g., nearest vertex, extrapolation, or rejection).

**Pseudocode:**
```python
import numpy as np

def tet_signed_volume(p1, p2, p3, p4):
    """
    Computes the signed volume of a tetrahedron defined by 4 points.
    p1, p2, p3, p4 are numpy arrays of shape (3,).
    """
    # Vector from p1 to p2, p3, p4
    v1 = p2 - p1
    v2 = p3 - p1
    v3 = p4 - p1
    # Volume = 1/6 * dot(v3, cross(v1, v2))
    return np.dot(v3, np.cross(v1, v2)) / 6.0

def barycentric_interpolation_tet(vertices, values, q):
    """
    Interpolate scalar value at point q inside a tetrahedron.
    
    vertices: list of 4 numpy arrays (p_a, p_b, p_c, p_d)
    values: list of 4 floats (f_a, f_b, f_c, f_d)
    q: numpy array (3,) query point
    
    Returns: (interpolated_value, is_inside)
    """
    p_a, p_b, p_c, p_d = vertices
    f_a, f_b, f_c, f_d = values
    
    # 1. Compute total volume
    v_total = tet_signed_volume(p_a, p_b, p_c, p_d)
    
    # Handle degenerate tetrahedron (zero volume)
    if abs(v_total) < 1e-12:
        # Fallback: return average or nearest vertex value [G]
        return np.mean(values), False

    # 2. Compute sub-volumes
    # Sub-volume opposite to Va (uses q, b, c, d)
    v_sub_a = tet_signed_volume(q, p_b, p_c, p_d)
    # Sub-volume opposite to Vb (uses q, a, c, d)
    v_sub_b = tet_signed_volume(q, p_a, p_c, p_d)
    # Sub-volume opposite to Vc (uses q, a, b, d)
    v_sub_c = tet_signed_volume(q, p_a, p_b, p_d)
    # Sub-volume opposite to Vd (uses q, a, b, c)
    v_sub_d = tet_signed_volume(q, p_a, p_b, p_c)
    
    # 3. Compute barycentric coordinates
    alpha = v_sub_a / v_total
    beta = v_sub_b / v_total
    gamma = v_sub_c / v_total
    delta = v_sub_d / v_total
    
    # 4. Check containment
    # Point is inside if all barycentric coordinates are positive
    is_inside = (alpha > 0) and (beta > 0) and (gamma > 0) and (delta > 0)
    
    if not is_inside:
        return None, False
        
    # 5. Interpolate
    f_q = alpha * f_a + beta * f_b + gamma * f_c + delta * f_d
    
    return f_q, True
```

**Parameters:**
- Precision: Standard double-precision floating point is recommended to avoid numerical instability in volume calculations for very small or flat tetrahedra. [G]

**Edge Cases and Pitfalls:**
- **Degenerate Tetrahedra:** If the volume is zero (coplanar vertices), division by zero occurs. The implementation must check for this. [G]
- **Numerical Precision:** For points very close to the boundary, floating-point errors may cause one coordinate to be slightly negative when it should be zero. A small epsilon tolerance may be needed for robustness. [G]
- **Orientation:** The sign of the volume depends on the winding order of the vertices. Consistent winding order is required for correct barycentric coordinate signs. [G]

## Subtopics

### SDF Aggregation via Barycentric Interpolation
Aggregates new point positions and their Signed Distance Function (SDF) values into an existing SDF field using barycentric interpolation within tetrahedra. It identifies points inside tetrahedra, computes their barycentric coordinates, and updates the SDF field by weighting the SDF values of the tetrahedron's vertices. It also supports optional feature interpolation. Non-neighbor points are handled by cloning existing values or zeroing them out. [S2, unofficial]

## Operating characteristics
- **Time Complexity:** $O(1)$ per query point, assuming the tetrahedron containing the point is known. Computing the volumes involves a constant number of vector operations (cross products, dot products).
- **Memory Complexity:** $O(1)$ auxiliary memory per query.
- **Strengths:** Geometrically exact linear interpolation within the simplex. Simple to implement. No need to solve linear systems.
- **Limitations:** Requires the query point to be inside the tetrahedron. Does not handle points outside the mesh without additional logic. Sensitive to tetrahedron quality (flat tetrahedra can lead to numerical instability).
- **When to use:** When sampling scalar fields defined on tetrahedral meshes, particularly in volume rendering or SDF manipulation where linear interpolation within cells is sufficient.
- **When not to use:** For hexahedral meshes (use trilinear interpolation), or when higher-order continuity is required (use higher-order basis functions).

## Background
Barycentric coordinates in 2D are well-established in computer graphics for triangle interpolation. The extension to 3D for tetrahedra is a natural generalization. The specific formulation relating sub-volumes is described in [S1, unofficial]. The application of this interpolation for SDF aggregation in tetrahedral representations is detailed in [S2, unofficial].
