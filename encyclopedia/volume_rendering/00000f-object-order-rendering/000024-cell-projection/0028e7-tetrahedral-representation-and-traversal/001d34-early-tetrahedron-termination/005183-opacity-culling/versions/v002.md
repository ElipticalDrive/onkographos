# Opacity Culling

Also called: Modality-based Opacity Culling, Negative Opacity Culling

## Overview
Opacity Culling removes primitives with zero or negative opacity from the rendering pipeline to reduce the number of processed elements [S1, unofficial][S2]. In tetrahedral volume rendering, it eliminates tetrahedra with zero opacity before sorting and rendering [S1, unofficial]. In Gaussian Splatting, it culls predicted Gaussians with negative opacity to avoid unnecessary rendering of primitives that do not contribute to the current visualized modality [S2].

## How it works
**Inputs:** A list of primitives (tetrahedra or 3D Gaussians) with associated opacity values $\alpha_i$ [S1, unofficial][S2].
**Outputs:** A filtered subset of primitives where $\alpha_i > 0$ for tetrahedra, or $\alpha_i \ge 0$ for Gaussians [S1, unofficial][S2].
**Data Structures:** Primitives are stored in contiguous arrays or lists. Each primitive $i$ holds a scalar opacity attribute $\alpha_i$ [S1, unofficial][S2].
**Steps:**
1. Iterate through the primitive list.
2. For each primitive $i$, evaluate its opacity $\alpha_i$.
3. If $\alpha_i = 0$ (tetrahedra) or $\alpha_i < 0$ (Gaussians), discard the primitive from sorting and rendering [S1, unofficial][S2].
4. If $\alpha_i > 0$ (tetrahedra) or $\alpha_i \ge 0$ (Gaussians), retain the primitive for subsequent processing [S1, unofficial][S2].
**Formulas:** Retention condition $R_i$: $R_i = (\alpha_i > 0)$ for tetrahedra, $R_i = (\alpha_i \ge 0)$ for Gaussians [S1, unofficial][S2], where $\alpha_i$ is the opacity of primitive $i$.
**Parameters:** Opacity Threshold: 0. Tetrahedra with $\alpha = 0$ are culled [S1, unofficial]. Gaussians with $\alpha < 0$ are culled [S2].
**Edge Cases and Pitfalls:** Precision: Floating-point inaccuracies may produce very small non-zero values. The sources do not specify a tolerance threshold [S1, unofficial][S2]. Modality Specificity: In Gaussian Splatting, culling is modality-dependent because Gaussians trained for one modality may have negative opacity for another [S2].

```python
def cull_primitives(primitives):
    culled = []
    for p in primitives:
        if p.opacity > 0:
            culled.append(p)
    return culled
```

## Subtopics

### Negative Opacity Culling
* **What it is:** Culling Gaussians with negative opacity values.
* **Difference:** Specifically targets negative opacity values arising from modality-specific training in Gaussian Splatting, whereas standard opacity culling targets zero opacity in tetrahedral rendering.
* **When to choose:** When using Gaussian Splatting for multi-modality or context translation where some Gaussians do not contribute to the current view.
* **Link:** [Negative Opacity Culling](52-negative-opacity-culling.md)

### Modality-based Opacity Culling
* **What it is:** Culling based on the contribution of primitives to a specific visualized modality.
* **Difference:** Emphasizes the modality-specific nature of opacity in Gaussian Splatting.
* **When to choose:** In multi-modality Gaussian Splatting applications.
* **Link:** [Modality-based Opacity Culling](52-modality-based-opacity-culling.md)

## Operating characteristics
* **Time Complexity:** $O(N)$, where $N$ is the number of primitives, as each primitive is checked once [G].
* **Memory Complexity:** $O(N)$ for the output list, or $O(1)$ if culling is done in-place [G].
* **Measured Performance:** Yields a 20% reduction in tetrahedra for the Langley Fighter dataset and a 36% reduction for the F117 dataset [S1, unofficial].
* **Limitations:** Requires an opacity value to be available for each primitive [G].

## Background
Opacity Culling was introduced in the context of tetrahedral volume rendering as a method to reduce the computational load by removing zero-opacity tetrahedra [S1, unofficial]. It was later adapted for Gaussian Splatting to handle modality-specific opacity values, where negative opacities indicate non-contributing Gaussians [S2].
