# Delaunay Triangulation for Tetrahedral Representation

Also called: 3D Delaunay Triangulation, gDel3D-based Tetrahedralization

## Overview
This method constructs a tetrahedral mesh from arbitrarily distributed 3D points by enforcing the Delaunay property: no point lies within the circumsphere of any tetrahedron in the mesh [S2]. It serves as an alternative to silhouette-based methods like Visual Hull Methods (VMC), which suffer from threshold sensitivity and discontinuous surfaces [S2]. Unlike its sibling [Local Convex Hull (LCH)](11862-local-convex-hull-lch.md), which uses convex hull algorithms for local surface construction, this method relies on Delaunay triangulation to generate the tetrahedral representation [S1, S2].

## How it works
**Inputs:** A set of 3D points $P = \{p_1, p_2, \dots, p_n\}$ representing Voronoi sites or surface samples [S1, S2].
**Outputs:** A tetrahedral mesh $T$ where each tetrahedron $t \in T$ satisfies the empty circumsphere property [S2].

**Data Structures:**
*   **Points:** Array of 3D coordinates $(x, y, z)$.
*   **Tetrahedra:** List of indices $(i, j, k, l)$ referencing points in $P$.
*   **Circumsphere:** Defined by center $c$ and radius $r$.

**Algorithm Steps:**
1.  **Initialization:** Create a super tetrahedron that encloses all input points $P$. Its shape remains unchanged during subdivision [S2].
2.  **Triangulation:** Generate the initial Delaunay triangulation of the points. Specialized libraries like gDel3D can accelerate this computation on the GPU [S1].
3.  **Validation and Subdivision:** For each point, compute the circumsphere of existing tetrahedra. If a point lies strictly inside a circumsphere, subdivide that tetrahedron to incorporate the point, restoring the empty circumsphere property [S2].
4.  **Iteration:** In dynamic contexts (e.g., evolving Voronoi sites), the triangulation is recomputed from scratch at every iteration rather than using incremental updates [S1].

**Formulas:**
*   **Circumsphere Check:** A point $p$ is inside the circumsphere of a tetrahedron defined by vertices $v_1, v_2, v_3, v_4$ if the determinant of the following matrix is positive (assuming a right-handed coordinate system):
    $$
    \det \begin{pmatrix}
    x_p & y_p & z_p & x_p^2 + y_p^2 + z_p^2 & 1 \\
    x_1 & y_1 & z_1 & x_1^2 + y_1^2 + z_1^2 & 1 \\
    x_2 & y_2 & z_2 & x_2^2 + y_2^2 + z_2^2 & 1 \\
    x_3 & y_3 & z_3 & x_3^2 + y_3^2 + z_3^2 & 1 \\
    x_4 & y_4 & z_4 & x_4^2 + y_4^2 + z_4^2 & 1
    \end{pmatrix} > 0
    $$
    where $(x_i, y_i, z_i)$ are the coordinates of vertex $v_i$ and $(x_p, y_p, z_p)$ are the coordinates of point $p$ [G].
*   **Subdivision:** When a point $p$ violates the empty circumsphere property of tetrahedron $t$, $t$ is removed and replaced by new tetrahedra formed by connecting $p$ to the exposed boundary faces of the removed tetrahedra [S2, G].

**Parameters:**
*   **Super Tetrahedron:** Must enclose all input points $P$ [S2].
*   **Library:** gDel3D is cited for GPU acceleration [S1].

**Edge Cases and Pitfalls:**
*   **NP-Completeness:** Determining whether a given polyhedron can be tetrahedralized is NP-complete [S2].
*   **Constrained Delaunay Triangulation (CDT):** CDT cannot tetrahedralize some special polyhedra (e.g., twisted prisms) without additional points or surface modification [S2].
*   **Precision:** Floating-point errors in circumsphere calculations can lead to incorrect subdivision decisions [G].

**Pseudocode:**
```python
def compute_circumsphere_determinant(p, v1, v2, v3, v4):
    """Returns positive if p is inside the circumsphere of tetrahedron (v1,v2,v3,v4)."""
    def row(pt):
        return [pt[0], pt[1], pt[2], pt[0]**2 + pt[1]**2 + pt[2]**2, 1]
    M = [row(p), row(v1), row(v2), row(v3), row(v4)]
    return determinant_5x5(M)

def determinant_5x5(M):
    """Computes the determinant of a 5x5 matrix using standard expansion."""
    # [G] Standard linear algebra operation
    import numpy as np
    return np.linalg.det(M)

def get_exposed_faces(violating_tetras):
    """Identifies faces appearing exactly once in the violating set."""
    # [G] Standard geometric step: boundary of the void formed by removed tetrahedra
    face_counts = {}
    for tet in violating_tetras:
        v1, v2, v3, v4 = tet
        for f in [(v1,v2,v3), (v1,v2,v4), (v1,v3,v4), (v2,v3,v4)]:
            key = tuple(sorted(f))
            face_counts[key] = face_counts.get(key, 0) + 1
    return [list(k) for k, v in face_counts.items() if v == 1]

def delaunay_tetrahedralization(points):
    """
    Constructs a Delaunay tetrahedralization from a set of 3D points.
    Args:
        points: List of 3D points (x, y, z).
    Returns:
        List of tetrahedra, where each tetrahedron is a tuple of 4 point indices.
    """
    # [G] Initialize with a super tetrahedron enclosing all points.
    # Its shape remains unchanged during subdivision.
    super_indices = [0, 1, 2, 3]
    all_points = [
        (-1000, -1000, -1000), (1000, -1000, -1000),
        (-1000, 1000, -1000), (-1000, -1000, 1000)
    ] + list(points)
    mesh = [tuple(super_indices)]

    for p in points:
        violating = []
        for tet in mesh:
            v1, v2, v3, v4 = [all_points[i] for i in tet]
            if compute_circumsphere_determinant(p, v1, v2, v3, v4) > 0:
                violating.append(tet)
        for tet in violating:
            mesh.remove(tet)
        # [G] Connect p to the exposed boundary faces of the removed tetrahedra
        # to form new tetrahedra, restoring the empty circumsphere property.
        boundary_faces = get_exposed_faces(violating)
        for face in boundary_faces:
            mesh.append(tuple(face + [len(all_points)]))
        all_points.append(p)
    return mesh
```

## Subtopics

### [Local Convex Hull (LCH)](11862-local-convex-hull-lch.md)
A surface reconstruction method that constructs triangular patches from volumetric data by estimating surfaces from local convexities. It differs from this method by using a convex hull algorithm rather than Delaunay triangulation for local surface construction, offering a trade-off between processing time and shape detail preservation.

### [Parallel Voxel Carving for Multi-view Stereo](14743-parallel-voxel-carving-for-multi-view-stereo.md)
A scalable volumetric reconstruction algorithm for multi-view stereo that utilizes a GPU to simultaneously execute threads for voxel carving. It integrates depth maps into a 3D voxel grid to carve away photo-inconsistent volumes, outputting surface voxels with normals and connectivity suitable for point-based rendering.

## Background
The 3D Delaunay Triangulation (DT) was introduced as an alternative to silhouette-based methods like Visual Hull Methods (VMC) [S2]. It constructs a surface by defining tetrahedrons from arbitrarily distributed 3D points, characterized by the property that no point lies within the circumsphere of any tetrahedron [S2]. The method has been used in various surface reconstruction applications, including the DCCVT method which uses gDel3D for GPU acceleration [S1]. Constrained Delaunay Triangulation (CDT) has also been evolved to include predescribed boundaries, though it faces limitations with special polyhedra [S2].
