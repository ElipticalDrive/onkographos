# Parallelized Accurate Sorting for Projected Tetrahedra

Also called: Logical partition sorting, Quick and accurate sorting algorithm of tetrahedral datasets

## Overview
Parallelized Accurate Sorting is a view-dependent sorting algorithm for tetrahedral datasets that uses logical partitioning to enable parallel processing, solving the dependency and sequence limitations of neighboring tetrahedra in parallel performance [S1, unofficial][S2, unofficial]. It sets itself apart from its siblings by replacing global topological sorting with a block-based logical partitioning scheme that allows for the parallel peeling of unobstructed layers, thereby reducing sorting time and improving rendering performance greatly [S1, unofficial][S2, unofficial].

## How it works
The method processes tetrahedral datasets in four sequential steps to achieve correct back-to-front compositing while maximizing parallelism.

**Inputs and Outputs:**
*   **Input:** A tetrahedral dataset (vertices and connectivity) and a camera view direction.
*   **Output:** A sorted sequence of tetrahedra (or subsets thereof) ready for optical accumulation.

**Data Structures:**
*   **Blocks:** The 3D space is divided into a list of blocks along the viewing direction. Each block contains a subset of tetrahedra. The exact layout of the block list is not specified, but it serves as the primary partitioning structure [S1, unofficial][S2, unofficial].

**Steps:**

1.  **Spatial Partitioning:** Divide the space containing the tetrahedral datasets into a list of blocks along the viewing direction. Each block contains a subset of tetrahedra [S1, unofficial][S2, unofficial].
2.  **Parallel Sorting (Peeling):** Sort the tetrahedra accurately by peeling tetrahedral subsets into unobstructed layers in parallel. This step resolves the visibility order within the partitioned blocks without global dependency [S1, unofficial][S2, unofficial].
3.  **Boundary Partitioning and Integration:** Partition tetrahedra on the boundary logically. Compute the optical contribution of each subset with segment integration. This involves calculating the transmittance and color contribution for the tetrahedra within each block based on the accumulated opacity from previous layers [S1, unofficial][S2, unofficial].
4.  **Accumulation:** Accumulate the optical contribution of each subset along the viewing direction to produce the final pixel color [S1, unofficial][S2, unofficial].

## Background
The method was proposed by Xin Li, W. Chen, X. Wu, and W. Zuo in 2013 in the paper "Fast projected tetrahedra volume rendering based on parallelized accurate sorting" [S1, unofficial]. It addresses the limitations of parallel performance in projected tetrahedra rendering caused by the sequence and dependency of neighboring tetrahedra [S1, unofficial][S2, unofficial]. The technique is also referenced in the context of multi-platform visualization systems for earth environment data [S1, unofficial].
