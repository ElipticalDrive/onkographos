# Differentiable Point-Based Pipeline with Per-View Optimization

Also called: Differentiable Point-Splatting Framework, Point-Based Neural Rendering

## Overview
This method is a neural rendering pipeline initialized with Multi-View Stereo (MVS) geometry that allows for the optimization of scene properties, specifically depth and reprojected features, within the space of input views to improve novel-view synthesis [S1]. It distinguishes itself from fixed MVS approaches by recovering from reconstruction errors through per-view optimization, and from volumetric neural radiance fields (NeRFs) by using explicit point-based geometry which is more stable and faster [S1]. It builds on [EWA Splatting with kNN Covariance Estimation](4690-ewa-splatting-with-knn-covariance-estimation.md) by extending forward EWA splatting to a bi-directional differentiable pipeline [S1].

## How it works
The pipeline initializes with standard 3D reconstruction (MVS geometry) and optimizes per-input-view attributes (reprojected latent features and depth) via backpropagation through a differentiable renderer [S1].

**Inputs:**
*   MVS-reconstructed point cloud (positions, initial colors/features) [S1].
*   Input views: Camera poses, intrinsic parameters, and source images [G].
*   Target novel view: Camera pose and intrinsic parameters [G].

**Outputs:**
*   Rendered image of the novel view [G].
*   Gradients for optimizing per-view depth and features [S1].

**Data Structures:**
*   **Point Cloud:** A list of points $P_i$ [G]. Each point $i$ stores:
    *   3D position $\mathbf{p}_i \in \mathbb{R}^3$ [G].
    *   Per-view reprojection attributes: A feature vector $\mathbf{f}_{i,v}$ and a depth offset $\delta_{i,v}$ for each input view $v$ that contributes to the point [S1]. The feature vector typically includes color and potentially other latent attributes [G]. The depth offset allows the point's effective depth to vary per view to correct MVS errors [S1].
    *   3D Covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$, estimated from k-nearest neighbors as per the parent method [4690-ewa-splatting-with-knn-covariance-estimation.md] [G].

**Steps:**

1.  **Camera Selection:**
    Select the subset of input views $V_{sel}$ that provide the best coverage for the novel view [S1]. The method uses the K-Maximum coverage algorithm [HP98] to efficiently select cameras that maximize the projected area of the point cloud onto the novel view's image plane [S1].

2.  **Bi-Directional Reprojection:**
    For each selected input view $v \in V_{sel}$ and each point $i$:
    *   Project the 3D point $\mathbf{p}_i$ into the 2D image plane of view $v$ [G].
    *   Sample the source image $I_v$ at the projected 2D coordinates to obtain the initial feature/color $\mathbf{c}_{i,v}$ [G].
    *   Apply **bi-directional EWA filtering**: The point is splatted from the 3D space into the 2D image of view $v$ using the 3D covariance $\Sigma_i$ transformed by the view matrix [S1]. This creates a soft, alpha-blended representation of the point in the 2D view space [S1]. This step allows gradients to flow from the 2D image space back to the 3D point attributes [S1].

3.  **Per-View Optimization (Training Phase):**
    *   The renderer computes the novel view image by compositing the reprojected points from all $v \in V_{sel}$ [S1].
    *   A **probabilistic depth test** is applied to resolve depth conflicts [S1]. Since points are soft splats, the method uses the distribution of depths from each reprojected input view to determine the visibility and contribution of each point, rather than a hard z-buffer [S1].
    *   The rendered novel view is compared to a ground-truth novel view (if available) or used in a self-supervised loss [G].
    *   Backpropagation updates the per-view parameters: the reprojected features $\mathbf{f}_{i,v}$ and the depth offsets $\delta_{i,v}$ for each point $i$ and view $v$ [S1]. This allows the system to correct inaccurate MVS geometry and appearance inconsistencies per view [S1].

4.  **Rendering (Inference Phase):**
    *   Once optimized, the renderer uses the fixed optimized parameters to generate novel views [S1].
    *   Soft, alpha-blended splatting of the reprojected points is performed [S1].
    *   The probabilistic depth test resolves occlusions using the optimized depth distributions [S1].

**Pseudocode:**

```python
def differentiable_point_pipeline(points, input_views, novel_view, num_epochs, learning_rate):
    # 1. Camera Selection: K-Maximum coverage algorithm [HP98] [S1]
    selected_views = input_views[:]  # [G] K-Max coverage selects optimal subset

    # 2. Initialize per-view attributes
    for v in selected_views:
        for p in points:
            p.depth_offset[v.id] = 0.0
            p.feature_grad[v.id] = [0.0] * len(p.color)

    for epoch in range(num_epochs):
        rendered_image = np.zeros_like(novel_view.image)
        alpha_accum = np.zeros(rendered_image.shape[:2])

        # Sort points by depth relative to novel view for correct blending [G]
        sorted_points = sorted(points, key=lambda p: np.dot(p.pos - novel_view.camera.origin, novel_view.camera.forward))

        for p in sorted_points:
            for v in selected_views:
                # Bi-directional reprojection with depth offset
                adjusted_pos = p.pos + v.camera.forward * p.depth_offset[v.id]
                # Project to 2D image coordinates [G]
                uv = (adjusted_pos - v.camera.origin) @ v.camera.proj_matrix
                uv = uv[:2] / uv[2]

                # EWA kernel evaluation based on projected covariance [G]
                cov_2d = v.camera.view_matrix @ p.covariance_3d @ v.camera.view_matrix.T
                weight = np.exp(-0.5 * uv @ np.linalg.inv(cov_2d) @ uv)

                # Sample feature from input view image [G]
                feature = v.image[uv[1], uv[0]]

                # Probabilistic depth test: uses distribution of depths from each reprojected input view [S1]
                depth_prob = 1.0  # [S1] Exact formula not given in sources

                # Composite
                rendered_image += feature * weight * depth_prob
                alpha_accum += weight * depth_prob

        # Normalize by accumulated alpha
        mask = alpha_accum > 1e-6
        rendered_image[mask] /= alpha_accum[mask][:, :, np.newaxis]

        # Loss and backpropagation
        loss = np.mean((rendered_image - novel_view.image) ** 2)
        # Gradients flow back to p.depth_offset and p.feature_grad [S1]
        for p in points:
            for v in selected_views:
                p.depth_offset[v.id] -= learning_rate * p.depth_grad[v.id]
                p.feature_grad[v.id] -= learning_rate * p.feature_grad[v.id]

    return rendered_image
```

**Parameters:**
*   **K-Maximum Coverage:** Selects the subset of input views that maximize projected coverage [S1].
*   **Learning Rate:** Not given in the sources. [G]
*   **EWA Kernel Width:** Determined by the projected covariance matrix [G].

**Edge Cases and Pitfalls:**
*   **Inaccurate Geometry:** When reprojecting from input views with inaccurate MVS geometry, it is hard to determine which view contains the correct information [S1].
*   **Wide-Baseline Artifacts:** In wide-baseline, free-viewpoint scenarios, methods that do not optimize per-view parameters (like standard NeRFs) often present artifacts [S1].
*   **Holes in Point Cloud:** If holes occur during point-cloud generation, the reconstruction result shows vacancy in the rendered result [S2].

## Subtopics

### [Bi-Directional Differentiable Point Cloud Rasterization](11503-bi-directional-differentiable-point-cloud-rasterization.md)
A bi-directional point splatting approach from input views to a common novel view space and back, using EWA filtering with Jacobians to allow per-view attribute optimization. It enables the optimization of per-view features in the 2D space of the input images, extending forward EWA splatting [11503-bi-directional-differentiable-point-cloud-rasterization.md].

### ADOP (Approximate Differentiable One-Pixel Point Rendering)
A point-cloud-based rendering model for novel view synthesis that uses dense reconstruction results (e.g., from COLMAP) [S2]. It trains for 100 epochs and applies gamma correction ($\gamma = 1/2.2$) by design, not a learned CRF function [S2]. It uses a mask covering the right half side of the images for dense reconstruction and model optimization [S2]. Pitfalls include instability in local optima leading to imperfect color, and vacancies in rendered results if holes occur in the point cloud [S2]. It shows biased results in estimating satisfying color and shadows compared to HDR-Plenoxels, with low performance in inferring overall white balance and changing colors [S2].

## Operating characteristics
*   **Time Complexity:** The camera selection uses the K-Maximum coverage algorithm for fast selection [S1]. The rendering involves bi-directional EWA splatting for each point and selected view [S1]. Complexity is proportional to $N \times K$, where $N$ is the number of points and $K$ is the number of selected views [G].
*   **Memory Complexity:** Stores per-point attributes for each selected view (depth offset, features) [S1]. This is higher than fixed MVS methods but lower than volumetric NeRFs which store dense voxel grids or large MLPs [G].
*   **Measured Performance:** The method outperforms all previous methods in quality and speed in almost all tested scenes [S1].
*   **Strengths:** Recovers from MVS reconstruction errors; high-quality, temporally coherent rendering; suitable for free-viewpoint IBR, multi-view harmonization, and stylization [S1].
*   **Limitations:** Requires initial MVS reconstruction; performance depends on the quality of the initial point cloud; bi-directional reprojection adds computational overhead compared to forward-only splatting [S1].
*   **When to use:** High-quality image-based rendering, multi-view stylization, and multi-view harmonization where per-view optimization is beneficial [S1].

## Background
The method was introduced by G. Kopanas, J. Philip, T. Leimkühler, and G. Drettakis [S1]. It builds on the field of neural rendering, which has seen rapid expansion [S1]. It addresses limitations of MVS-based methods (fixed geometry) and volumetric neural representations (expensive training/inference, artifacts in wide-baseline scenarios) [S1]. The approach extends forward EWA point splatting [YSW*19] to be bi-directional [S1]. It is used for high-quality image-based rendering, multi-view stylization, and multi-view harmonization [S1].
