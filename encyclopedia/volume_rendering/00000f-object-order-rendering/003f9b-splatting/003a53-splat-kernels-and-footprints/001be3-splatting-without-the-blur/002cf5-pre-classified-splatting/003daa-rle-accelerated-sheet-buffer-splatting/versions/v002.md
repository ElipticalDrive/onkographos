# RLE Accelerated Sheet Buffer Splatting

Also called: RLE accelerated, pre-classification and pre-shade sheet buffer volume splatting, RLE based sheet buffer splatting

## Overview
RLE Accelerated Sheet Buffer Splatting is a volume rendering algorithm that accelerates object-order splatting by combining Run Length Encoding (RLE) with a sheet buffer approach, utilizing pre-classified and pre-shaded voxel data to skip transparent regions [S1]. It solves the performance bottleneck of processing large volumes with high transparency by exploiting spatial coherence, allowing the renderer to traverse only non-transparent voxel scanlines while simultaneously updating the image plane [S1]. Unlike standard splatting which processes every voxel, or Lacroute’s shear-warp method which uses a single RLE structure, this method maintains three sets of RLE structures for principal axes to ensure the sheet buffer remains parallel to the image plane, enabling flexible random access and avoiding alignment issues [S1].

## How it works
### Inputs and Outputs
*   **Input:** Raw density volume (scalar field), transfer function (mapping density to opacity), illumination model (e.g., Phong), and camera parameters (view direction, projection) [S1].
*   **Output:** Final 2D image (RGB with alpha) [S1].

### Data Structures
The algorithm constructs four tables for each of the three principal volume axes (X, Y, Z) [S1]. Let $N_x, N_y, N_z$ be the dimensions of the volume [S1]. For a given principal axis (e.g., Z), the structures are:

1.  **Slice Scanline Pointer Array ($S$):** An array of pointers where $S_{ij}$ points to the first entry in the Scanline RLE Array corresponding to the $j$-th scanline in the $i$-th slice (perpendicular to the principal axis) [S1]. If the entire scanline is transparent, $S_{ij} = -1$ [S1].
2.  **Data Pointer Array ($D$):** An array where each entry $D_i$ points to the starting index in the Voxel Data Array for the $i$-th slice, managing all non-transparent voxels in that slice [S1].
3.  **Scanline RLE Array ($R$):** A sequence of integers representing run lengths, constructed in slice-by-slice, scanline-by-scanline order [S1]. It stores the lengths of transparent runs and non-transparent runs [S1]. Since transparent voxels are skipped, this array primarily tracks transparent run lengths to skip over them, followed by the count of non-transparent voxels in that segment [S1].
4.  **Voxel Data Array ($V$):** Stores pre-computed optical properties (opacity $\alpha$ and RGB color) for non-transparent voxels only [S1]. Entries are stored sequentially as they are encountered in the scanline traversal, and transparent voxels are not stored here [S1].

### Pre-processing Steps
1.  **Pre-classification:** Load the raw density volume [S1]. For each voxel, apply the transfer function to map the density value to an opacity value $\alpha$ [S1]. This is done once during pre-processing [S1].
2.  **Pre-shading:** Calculate the RGB color for each voxel [S1]. Using the view parameters and local gradient approximated normals, apply an illumination model (e.g., Phong) to compute the color [S1]. This is done once during pre-processing [S1].
3.  **RLE Encoding:**
    *   Iterate through the volume slice by slice, scanline by scanline [S1].
    *   For each scanline, identify runs of transparent voxels and runs of non-transparent voxels [S1].
    *   Populate the **Scanline RLE Array** with the lengths of these runs [S1].
    *   Populate the **Voxel Data Array** with the pre-classified and pre-shaded data ($\alpha, R, G, B$) for every non-transparent voxel [S1].
    *   Populate the **Slice Scanline Pointer Array** to point to the correct position in the RLE array for each scanline [S1].
    *   Populate the **Data Pointer Array** to point to the start of the non-transparent voxel data for each slice [S1].
    *   Repeat this process for all three principal axes (X, Y, Z) to create three independent sets of these data structures [S1].

### Rendering Steps
1.  **View Selection:** Determine the angle between the image plane and the three principal volume axes [S1]. Select the principal axis set where the angle is less than 45 degrees [S1]. This ensures the sheet buffer is parallel to the image plane, optimizing the traversal [S1].
2.  **Sheet Buffer Initialization:** Initialize a sheet buffer (a temporary image buffer) parallel to the selected principal axis [S1].
3.  **Traversal and Splatting:**
    *   Traverse the voxel scanlines defined by the RLE structures [S1].
    *   For each scanline, use the **Slice Scanline Pointer Array** to find the start in the **Scanline RLE Array** [S1].
    *   Iterate through the RLE entries:
        *   If the entry represents a transparent run, skip that many voxels (do not access the Voxel Data Array) [S1].
        *   If the entry represents a non-transparent run, retrieve the corresponding voxel data from the **Voxel Data Array** (using the **Data Pointer Array** offset) [S1].
    *   For each non-transparent voxel:
        *   Project the voxel center onto the sheet buffer [S1].
        *   Spread the voxel's contribution ($\alpha, RGB$) to the neighbor pixels in the sheet buffer using the reconstruction kernel [S1].
        *   **Overlap Handling:** When multiple voxels contribute to the same pixel in the sheet buffer, use simple addition for the color and opacity contributions, rather than standard over/under compositing operations, to avoid artifacts [S1].
4.  **Final Composition:** After all voxels are splatted into the sheet buffer, composite the sheet buffer into the final image plane [S1].

import math

def rle_accelerated_sheet_buffer_splatting(volume, transfer_function, illumination_model, camera):
    # Pre-processing: classify and shade all voxels
    classified = {}
    for v in volume:
        alpha = transfer_function(v.density)
        color = illumination_model(v.position, camera.view_direction, v.gradient)
        classified[v] = (alpha, color)

    # Build RLE structures for all three principal axes
    axes = [('x', (1,0,0)), ('y', (0,1,0)), ('z', (0,0,1))]
    structures = {}
    for name, axis_vec in axes:
        structures[name] = build_rle_structures(classified, axis_vec)

    # Select axis where angle between image plane normal and principal axis < 45 degrees
    img_normal = camera.image_plane_normal
    best_axis = None
    best_angle = 90.0
    for name, axis_vec in axes:
        angle = math.acos(max(0.0, min(1.0, dot(img_normal, axis_vec))))
        if angle < best_angle:
            best_angle = angle
            best_axis = name
        if best_angle < math.radians(45):
            break

    # Initialize sheet buffer
    sheet_buffer = [0.0] * (camera.width * camera.height * 4) # RGBA

    # Render using selected axis structures
    structs = structures[best_axis]
    for i in range(structs.num_slices):
        for j in range(structs.num_scanlines):
            ptr = structs.slice_scanline_pointer[i][j]
            if ptr == -1:
                continue

            data_idx = structs.data_pointer[i]
            rle_idx = ptr

            while rle_idx < len(structs.scanline_rle):
                trans_len = structs.scanline_rle[rle_idx]
                rle_idx += 1

                if rle_idx < len(structs.scanline_rle):
                    non_trans_len = structs.scanline_rle[rle_idx]
                    rle_idx += 1

                    for k in range(non_trans_len):
                        alpha, color = structs.voxel_data[data_idx + k]
                        pos = project_onto_sheet_buffer(structs, i, j, k)
                        splat_kernel(sheet_buffer, pos, alpha, color)

                    data_idx += non_trans_len

    # Composite sheet buffer to final image
    final_image = composite_sheet_buffer(sheet_buffer, camera)
    return final_image

### Parameters
*   **View Angle Threshold:** 45 degrees [S1]. If the angle between the image plane and the principal volume axis exceeds this, a different RLE structure set is used [S1].
*   **Non-transparent Voxels:** Typically 5%-30% of the total volume [S1].

### Edge Cases and Pitfalls
*   **Overlap Artifacts:** Conventional splatting uses over/under operations for overlapping pixels, which can lead to artifacts [S1]. This method uses simple addition for overlapping pixels to ensure accuracy [S1].
*   **Memory Usage:** The RLE structures require 3-5 times the memory of the original volume storage because three sets of structures (one for each principal axis) are kept in memory [S1].
*   **Alignment:** Separating run lengths from voxel data avoids alignment problems on certain processor architectures [S1].

## Operating characteristics
*   **Time Complexity:** The rendering time is linearly proportional to the number of non-transparent voxels rendered, rather than the total volume size [S1].
*   **Memory Complexity:** $O(V)$ where $V$ is the volume size, multiplied by a factor of 3-5 due to the three RLE structure sets and the separation of data [S1].
*   **Measured Performance:** On a 1 GHz AMD Duron CPU with 256MB RAM, speedups ranged from 9.1x to 26.5x compared to non-RLE splatting across datasets like CT head, lobster, MRI head, engine, X-ray foot, and bonsai [S1].
*   **Strengths:** High speedup for volumes with significant transparency; flexible random access to voxel scanlines; avoids alignment issues; accurate rendering via additive compositing in sheet buffer [S1].
*   **Limitations:** High memory overhead (3-5x); pre-processing time for classification and shading; limited to three principal axes for RLE structures [S1].
*   **When to Use:** When rendering large volumes with high transparency and sufficient memory is available [S1].
*   **When Not to Use:** When memory is constrained, or when the volume has very low transparency (most voxels are opaque), reducing the benefit of RLE skipping [S1].

## Background
The method was proposed by Zhang et al. in 2003 [S1]. It addresses the limitations of earlier acceleration techniques like splat hierarchies and octrees, which require complex traversal logic [S1]. It also improves upon Lacroute's shear-warp RLE method by separating the slice pointer array from the data pointer array and applying RLE at the scanline level, which allows for flexible random access and better performance on various processor architectures [S1]. The use of pre-classification and pre-shading was previously established in splatting literature to reduce per-pixel computation, but this method integrates it with RLE and sheet buffers for significant speedups [S1].
