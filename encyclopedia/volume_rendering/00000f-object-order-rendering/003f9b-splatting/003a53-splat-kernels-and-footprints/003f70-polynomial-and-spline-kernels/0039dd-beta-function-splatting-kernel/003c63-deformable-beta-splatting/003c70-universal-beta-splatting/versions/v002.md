# Universal Beta Splatting

Also called: UBS, UBS-6D, UBS-7D, Universal Beta Splatting 6D, Universal Beta Splatting 7D

## Overview
Universal Beta Splatting (UBS) is a unified framework for explicit radiance field rendering that generalizes 3D Gaussian Splatting to N-dimensional anisotropic Beta kernels [S1, unofficial]. It solves the problem of modeling complex light transport, view-dependent appearance, and scene dynamics simultaneously without requiring auxiliary color encodings (such as spherical harmonics) or separate networks [S1, unofficial]. Unlike its siblings, UBS natively incorporates view and temporal dimensions into the kernel's query space, allowing the primitive's mean and covariance to adapt to these conditions via Beta-modulated conditional slicing [S1, unofficial]. This approach achieves significant parameter efficiency (e.g., a 41% reduction over 3DGS for static scenes) while maintaining backward compatibility with Gaussian splatting as a special case [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   Camera parameters (position, orientation, intrinsics) [S1, unofficial].
*   Query vector $\mathbf{q} \in \mathbb{R}^{N-3}$, where $N$ is the total dimensionality [S1, unofficial]. For static view-dependent rendering, $N=6$ (UBS-6D) and $\mathbf{q}$ encodes view direction [S1, unofficial]. For dynamic rendering, $N=7$ (UBS-7D) and $\mathbf{q}$ encodes view direction and time [S1, unofficial].
*   A set of primitives, each defined by the parameters below [S1, unofficial].

**Outputs:**
*   Pixel color and depth via volume rendering of the conditioned 3D Beta kernel density [S1, unofficial].

### Data Structures
Each primitive stores parameters partitioned into spatial ($x$) and query ($q$) components [S1, unofficial]. The total parameter count depends on the dimensionality $N$:

**UBS-6D (Static/View-Dependent):**
*   Total: 35 parameters per primitive [S1, unofficial].
*   Geometry (32 params):
    *   Position $\boldsymbol{\mu}_x$: 3 floats [S1, unofficial].
    *   Direction $\boldsymbol{\mu}_q$ (view mean): 3 floats [S1, unofficial].
    *   Spatial-Orthogonal Covariance: 21 floats (see Layout) [S1, unofficial].
    *   Beta Shapes: 4 floats (spatial $b_x$ and angular $\mathbf{b}_q$) [S1, unofficial].
    *   Opacity $o$: 1 float [S1, unofficial].
*   Color: 3 floats (direct RGB) [S1, unofficial].

**UBS-7D (Dynamic):**
*   Total: 44 parameters per primitive [S1, unofficial].
*   Geometry (41 params):
    *   Position $\boldsymbol{\mu}_x$: 3 floats [S1, unofficial].
    *   Time $\mu_{t}$: 1 float [S1, unofficial].
    *   Direction $\boldsymbol{\mu}_q$ (view mean): 3 floats [S1, unofficial].
    *   Spatial-Orthogonal Covariance: 28 floats (see Layout) [S1, unofficial].
    *   Beta Shapes: 5 floats (spatial $b_x$, angular $\mathbf{b}_q$, temporal $b_t$) [S1, unofficial].
    *   Opacity $o$: 1 float [S1, unofficial].
*   Color: 3 floats (direct RGB) [S1, unofficial].

### Layout
The N-dimensional space is partitioned into spatial components ($x \in \mathbb{R}^3$) and query components ($q \in \mathbb{R}^{N-3}$) [S1, unofficial]:

$$
\boldsymbol{\mu} = \begin{pmatrix} \boldsymbol{\mu}_x \\ \boldsymbol{\mu}_q \end{pmatrix}, \quad \boldsymbol{\Sigma} = \begin{pmatrix} \boldsymbol{\Sigma}_x & \boldsymbol{\Sigma}_{xq} \\ \boldsymbol{\Sigma}_{qx} & \boldsymbol{\Sigma}_q \end{pmatrix}
$$

The covariance matrix $\boldsymbol{\Sigma}$ is parameterized using **Spatial-Orthogonal Cholesky** to preserve orthonormal spatial structure while enabling cross-dimensional correlations [S1, unofficial]. For $N = 3 + C$ dimensions, the lower triangular Cholesky factor $\mathbf{L}$ is constructed as:

$$
\mathbf{L} = \begin{pmatrix} \mathbf{R}_x \operatorname{diag}(\mathbf{s}_x) & \mathbf{0} \\ \mathbf{L}_{qx} & \mathbf{L}_q \end{pmatrix}
$$

Where:
*   $\mathbf{R}_x \in SO(3)$ is the spatial rotation, computed via a first-order Taylor approximation of the matrix exponential: $\mathbf{R}_x \approx \mathbf{I} + \mathbf{A}_x$, where $\mathbf{A}_x$ is a skew-symmetric matrix derived from 3 learnable parameters [S1, unofficial].
*   $\mathbf{s}_x$ are the spatial scales (3 parameters) [S1, unofficial].
*   $\mathbf{L}_{qx}$ encodes cross-correlations between spatial and query dimensions [S1, unofficial].
*   $\mathbf{L}_q$ is the Cholesky factor for the non-spatial dimensions [S1, unofficial].

### Steps
1.  **Compute Modulated Opacity:**
    Calculate the per-dimension contribution to opacity based on the query vector $\mathbf{q}$ [S1, unofficial]:
    $$
    d_i^{\text{raw}} = (\hat{\mathbf{L}}_q^{-1}(\mathbf{q} - \boldsymbol{\mu}_q))_i^2
    $$
    $$
    d_i = \tanh(d_i^{\text{raw}}) \in [0, 1)
    $$
    $$
    o(\mathbf{q}) = o \prod_{i=1}^C (1 - d_i)^{4\beta_{q_i}}
    $$
    Where $\hat{\mathbf{L}}_q$ is the Cholesky factor of $\boldsymbol{\Sigma}_q$, and $\beta_{q_i} = 4 \exp(b_{q_i})$ are the positive Beta exponents derived from the learnable shape parameters $b$ [S1, unofficial].

2.  **Compute Beta-Modulated Conditional Mean:**
    Adjust the spatial mean based on the query [S1, unofficial]:
    $$
    \boldsymbol{\mu}_{x|q} = \boldsymbol{\mu}_x + \boldsymbol{\Sigma}_{xq} \boldsymbol{\Sigma}_q^{-1} \operatorname{diag}(\hat{\boldsymbol{\beta}}_q) (\mathbf{q} - \boldsymbol{\mu}_q)
    $$
    Where $\operatorname{diag}(\hat{\boldsymbol{\beta}}_q)$ applies dimension-specific Beta modulation [S1, unofficial].

3.  **Compute Beta-Modulated Conditional Covariance:**
    Adjust the spatial covariance based on the query [S1, unofficial]:
    $$
    \boldsymbol{\Sigma}_{x|q} = \boldsymbol{\Sigma}_{x'} - \boldsymbol{\Sigma}_{xq} \boldsymbol{\Sigma}_{q'}^{-1} \operatorname{diag}(\tilde{\boldsymbol{\beta}}_{q'}) \boldsymbol{\Sigma}_{qx}
    $$
    Where $\operatorname{diag}(\tilde{\boldsymbol{\beta}}_{q'}) = \operatorname{diag}([\beta_{q1}, \dots, \beta_{qC}]_{\le 1})$ ensures modulation values are capped at 1, and $\boldsymbol{\Sigma}_{x'}$, $\boldsymbol{\Sigma}_{q'}$ refer to the base covariance blocks $\boldsymbol{\Sigma}_x$ and $\boldsymbol{\Sigma}_q$ [S1, unofficial].

4.  **Evaluate Density:**
    Compute the final conditioned 3D Beta kernel density [S1, unofficial]:
    $$
    \sigma(\mathbf{x}, \mathbf{q}) = \mathcal{B}(\mathbf{x}; \boldsymbol{\mu}_{x|q}, \boldsymbol{\Sigma}_{x|q}, b_x) \cdot o(\mathbf{q})
    $$
    Where $\mathcal{B}$ is the Beta function density with spatial shape parameter $b_x$ [S1, unofficial].

5.  **Rendering:**
    Perform standard volume rendering (e.g., alpha compositing) using the computed density $\sigma(\mathbf{x}, \mathbf{q})$ and direct RGB color [S1, unofficial].

6.  **Optimization:**
    Optimization minimizes a composite loss function [S1, unofficial]:
    $$
    \mathcal{L} = (1 - \lambda_{\text{SSIM}})\mathcal{L}_1 + \lambda_{\text{SSIM}}\mathcal{L}_{\text{SSIM}} + \lambda_o \sum_i |o_i| + \lambda_\Sigma \sum_i \|\mathbf{s}_i\|_1
    $$
    Spatial noise injection promotes exploration: $\boldsymbol{\mu}_x \leftarrow \boldsymbol{\mu}_x - \lambda_{lr}\nabla_{\boldsymbol{\mu}} \mathcal{L} + \lambda_\epsilon \boldsymbol{\epsilon}$ [S1, unofficial]. Primitive management (densification/culling) uses the kernel-agnostic MCMC optimization from Deformable Beta Splatting [S1, unofficial].

### Pseudocode
```python
def compute_ub_splat_density(x, q, mu_x, mu_q, L_qx, L_q, s_x, b_x, b_q, o):
    # 1. Reconstruct base covariance blocks from Cholesky factor L
    # L = [[R_x diag(s_x), 0], [L_qx, L_q]]
    # Sigma_x = R_x diag(s_x) @ R_x diag(s_x)^T
    # Sigma_q = L_q @ L_q^T
    # Sigma_xq = R_x diag(s_x) @ L_qx^T
    # Sigma_qx = Sigma_xq^T
    # (Implementation details for R_x from skew-symmetric A_x omitted for brevity)
    
    # 2. Compute modulated opacity
    L_q_inv = np.linalg.inv(L_q)
    d_raw = np.sum((L_q_inv @ (q - mu_q))**2, axis=0) # Per-dimension squared Mahalanobis distance
    d = np.tanh(d_raw)
    beta_q = 4.0 * np.exp(b_q)
    o_q = o * np.prod((1.0 - d)**(4.0 * beta_q))
    
    # 3. Compute conditional mean
    Sigma_q_inv = np.linalg.inv(Sigma_q)
    beta_hat_q = beta_q # diag(beta_hat_q) applies modulation
    mu_cond = mu_x + (Sigma_xq @ Sigma_q_inv) @ (np.diag(beta_hat_q) @ (q - mu_q))
    
    # 4. Compute conditional covariance
    beta_tilde_q = np.minimum(beta_q, 1.0)
    Sigma_cond = Sigma_x - (Sigma_xq @ Sigma_q_inv @ np.diag(beta_tilde_q) @ Sigma_qx)
    
    # 5. Evaluate Beta density (simplified 3D Beta kernel evaluation)
    # B(x; mu, Sigma, b) typically involves multivariate Beta function normalization
    # and exponent terms based on b_x. Exact normalization constant not given in sources.
    density = evaluate_beta_kernel(x, mu_cond, Sigma_cond, b_x)
    
    return density * o_q
```

### Parameters
*   **Beta Parameters ($b$):** Control the shape of the kernel [S1, unofficial]. When $b=0$, the kernel approximates a Gaussian, recovering 3DGS, 6DGS, or 7DGS depending on dimensionality [S1, unofficial].
*   **Typical Values:** Not given in the sources. [G] Typical values for similar splatting methods are $\lambda_{\text{SSIM}} \approx 0.2$, but these are not confirmed in the UBS source.

### Edge Cases and Pitfalls
*   **Precision:** The first-order Taylor approximation for $\mathbf{R}_x$ is used to reduce computation; higher-order approximations may be needed for extreme rotations, though the source claims nearly identical fidelity [S1, unofficial].
*   **Boundaries:** The $\tanh$ function in opacity calculation bounds $d_i$ to $[0, 1)$, ensuring valid inputs for the Beta kernel [S1, unofficial].
*   **Degenerate Input:** If $\boldsymbol{\Sigma}_q$ is singular, inversion in the conditional mean/covariance steps will fail [S1, unofficial]. The Cholesky parameterization helps maintain positive semi-definiteness, but numerical stability checks are required [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Real-time performance is achieved via a fully accelerated CUDA implementation [S1, unofficial].
*   **Memory Complexity:** Significant parameter reduction compared to baselines [S1, unofficial]. UBS-6D uses 59% of the parameters of 3DGS (35 vs 59 per primitive) [S1, unofficial]. UBS-7D uses 27% of the parameters of 4DGS (44 vs 161 per primitive) [S1, unofficial].
*   **Measured Performance:**
    *   **Static (NeRF Synthetic/Mip-NeRF):** UBS-6D averages 345.7 FPS, 300.0K primitives, 40.1 MB memory, and 8.7 minutes training time [S1, unofficial].
    *   **Static (6DGS-PBR):** UBS-6D averages 290.2 FPS, 300.0K primitives, 40.1 MB memory, and 27.7 minutes training time [S1, unofficial].
    *   **Dynamic (7DGS-PBR/D-NeRF):** UBS-7D averages 359.6 FPS, 234.3K primitives, 39.4 MB memory, and 59.9 minutes training time [S1, unofficial].
*   **Quality:** Improves PSNR by up to +8.27 dB on static scenes and +2.78 dB on dynamic scenes compared to Gaussian baselines [S1, unofficial].
*   **Strengths:** Eliminates auxiliary color encodings (SH), enables native view/temporal dependency modeling, and provides interpretable scene decomposition where spatial/angular/temporal Beta parameters separate geometry/texture/diffuse/specular/static/dynamic [S1, unofficial].
*   **Limitations:** Requires CUDA acceleration for real-time performance and involves complex conditional slicing logic compared to simple Gaussian projection [S1, unofficial].

## Background
Universal Beta Splatting was introduced in [S1, unofficial]. It builds on Deformable Beta Splatting (DBS) and extends the Beta kernel concept to N dimensions [S1, unofficial]. It addresses limitations in 3DGS, 6DGS, and 4DGS which rely on fixed Gaussian profiles and auxiliary encodings for view-dependent and temporal effects [S1, unofficial].
