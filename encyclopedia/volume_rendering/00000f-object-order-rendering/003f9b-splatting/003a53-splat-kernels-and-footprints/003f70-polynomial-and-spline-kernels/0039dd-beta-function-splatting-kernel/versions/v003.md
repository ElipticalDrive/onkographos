# Beta Function Splatting Kernel

Also called: Beta distribution splatting, Beta footprint

## Overview
The Beta Function Splatting Kernel is a 2D footprint function used in object-order volume rendering that replaces the standard Normal (Gaussian) distribution with a Beta function to control the shape of the splat [S1, unofficial]. It solves the problem of tuning visual parameters such as opacity, zoom, and shading by allowing independent control over the openness, height, and width of the kernel curve [S1, unofficial]. It sets itself apart from standard Gaussian splatting by offering smaller footprints for equivalent visual quality, which can result in significantly faster execution times [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Screen coordinates relative to the splat center $(x, y)$, shape parameters $a$ and $b$, scaling factor $k_{\text{scale}}$, and voxel density $\rho$ [S1, unofficial].
*   **Outputs:** The weight $W(x,y)$ contributed by the splat to the pixel [S1, unofficial].

**Data Structures:**
The kernel is defined by a set of parameters:
*   $a, b$: Shape parameters (floats) [S1, unofficial].
*   $k_{\text{scale}}$: Scaling factor (float) [S1, unofficial].
*   $x, y$: Normalized coordinates in the range $[0, 1]$ relative to the footprint's local domain [S1, unofficial].

**Numbered Steps:**
1.  Map the screen-space distance from the splat center to a normalized coordinate $u \in [0, 1]$ [G].
2.  Evaluate the Beta function using the mapped coordinate $u$ and parameters $a, b, k_{\text{scale}}$ [S1, unofficial].
3.  Modulate the weight by the voxel density $\rho$ [S1, unofficial].
4.  Accumulate the result into the pixel buffer using alpha blending [S1, unofficial].

**Formulas:**
The core Beta function is defined as:
$$ \text{Beta}(x, a, b) = k_{\text{scale}} \cdot x^a \cdot (1 - x)^b $$
where $x \in [0, 1]$ [S1, unofficial].
In the context of 2D splatting, the footprint $F(x,y)$ is constructed by evaluating the 1D profile along a radial distance $r$ mapped to $[0, 1]$ [G]. The source describes using a kernel base distribution and scaling factors to generate stacked section footprints for image-aligned splatting [S1, unofficial]. For a symmetric curve where $a=b$, the function is symmetric around $x=0.5$ [G].

**Parameters:**
*   $a, b$: Control the curve shape. Identical values produce symmetric curves [S1, unofficial]. Lower values produce more 'opened' (wider/flatter) curves [S1, unofficial].
*   $k_{\text{scale}}$: Adjusts the range/height of the curve [S1, unofficial].
*   Typical values: Not given in the sources.

**Edge cases and pitfalls:**
*   **Holes:** Holes may appear when voxel opacity decreases, requiring changes in footprint size to maintain continuity between neighbor voxels [S1, unofficial]. This is especially noticeable at feature boundaries in tagged volumes [S1, unofficial].
*   **Precision:** The term $x^a$ can suffer from precision issues if $x$ is very close to $0$ and $a$ is large [G].
*   **Boundaries:** The function is strictly defined on $[0, 1]$; coordinates outside this range must be clamped or treated as zero contribution [G].

**Pseudocode:**
```python
def beta_kernel(u, a, b, k_scale):
    """
    Evaluate the Beta function kernel.
    u: normalized distance in [0, 1]
    a, b: shape parameters
    k_scale: scaling factor
    """
    if u <= 0.0:
        return 0.0 if a > 0 else k_scale
    if u >= 1.0:
        return 0.0 if b > 0 else k_scale
    return k_scale * (u ** a) * ((1.0 - u) ** b)

def splat_pixel(screen_x, screen_y, center_x, center_y, radius, a, b, k_scale, density):
    """
    Calculate contribution of a splat to a pixel.
    """
    dist = ((screen_x - center_x)**2 + (screen_y - center_y)**2)**0.5
    u = dist / radius
    u = max(0.0, min(1.0, u))
    weight = beta_kernel(u, a, b, k_scale)
    return weight * density
```

## Subtopics

### [Deformable Beta Splatting](9228-deformable-beta-splatting.md)
An explicit radiance field rendering method that replaces the standard Gaussian kernel with an adaptive, bounded Beta function kernel. It allows the kernel's profile to deform during training via a single learnable parameter, enabling better modeling of sharp boundaries and high-frequency details.

### [Universal Beta Splatting (UBS)](10589-universal-beta-splatting-ubs.md)
An N-dimensional splatting kernel that replaces the Gaussian distribution with a Beta function to enable independent per-dimension shape control, addressing limitations of methods like 6DGS and 7DGS.

## Operating characteristics
*   **Performance:** Beta footprints are smaller than Normal distribution footprints while providing equivalent visual quality [S1, unofficial]. In tested examples, this resulted in execution being twice as fast [S1, unofficial].
*   **Memory:** Not given in the sources.
*   **Strengths:** Smaller footprints reduce the number of pixels touched per splat, improving rasterization speed [S1, unofficial]. The parameters $a$ and $b$ allow easy tuning of openness and width [S1, unofficial].
*   **Limitations:** Holes may appear at feature boundaries if opacity varies significantly, requiring careful tuning of footprint size relative to opacity [S1, unofficial].

## Background
The Beta Function Splatting Kernel was proposed in the context of rendering classified datasets using a feature graph representation [S1, unofficial]. The method was introduced to improve rendering performance by using smaller footprints that are easier to tune under visual changes such as zooming and opacity adjustments [S1, unofficial].
