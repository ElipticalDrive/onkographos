# Smoothness Splines


## Overview
Smoothness Splines (SS) is a scattered data approximation method for recovering volume rendered images from sparse pixel measurements by finding a smooth solution in a shift-invariant spline space [S1][S2, unofficial]. It minimizes a least-squares norm that penalizes non-smooth solutions using the second-order Beppo-Levi seminorm, distinguishing it from compressed sensing methods that rely on sparsity in wavelet or gradient domains [S1]. SS is more resilient to missing information and computationally less expensive than compressed sensing pursuit strategies [S1].

## How it works
**Inputs:**
*   $y \in \mathbb{R}^M$: Vector of measured pixel values at locations $k_1, \dots, k_M$.
*   $N$: Total number of pixels in the image grid.
*   $j_1, \dots, j_N$: Pixel locations corresponding to the full image grid (used for the basis functions).

**Outputs:**
*   $x \in \mathbb{R}^N$: Recovered image coefficients (which correspond to pixel values since the kernel is interpolating).

**Data Structures:**
*   **Measurement Mask:** A boolean array or list of indices indicating which of the $N$ grid locations $j_n$ correspond to the measured values $y_m$. Let $S$ be the $M \times N$ sampling matrix where $S_{m,n} = 1$ if $j_n = k_m$ and $0$ otherwise.
*   **Kernel:** The bivariate kernel $\phi(t_1, t_2) = \beta_I^3(t_1)\beta_I^3(t_2)$, where $\beta_I^3$ is the optimal interpolating cubic B-spline.

**Parameters:**
*   $\lambda$: Regularization parameter. Typical value: $10^{-2}$ [S1][S2, unofficial].

**Steps:**

1.  **Define the Kernel:**
    Use the optimal interpolating cubic B-spline kernel. The univariate kernel is defined as [S1][S2, unofficial]:
    $$ \beta_I^3(t) := \beta^3(t) - \frac{1}{6} \frac{d^2}{dt^2} \beta^3(t) $$
    where $\beta^3(t)$ is the univariate uniform centered cubic B-spline. The bivariate kernel is the tensor product $\phi(t_1, t_2) = \beta_I^3(t_1)\beta_I^3(t_2)$.

2.  **Formulate the Optimization Problem:**
    The goal is to find coefficients $c$ such that $f(t) = \sum_{n=1}^N c_n \phi(t - j_n)$ fits the data while minimizing smoothness energy [S1][S2, unofficial]. Because $\beta_I^3$ is interpolating, $c = x$. The problem is formulated as [S1][S2, unofficial]:
    $$ \min_x \|Sx - y\|_2^2 + \lambda x^T H x $$
    where $H$ is an $N \times N$ matrix with entries [S1][S2, unofficial]:
    $$ H_{p,q} = \langle \phi(\cdot - j_p), \phi(\cdot - j_q) \rangle_{BL_2} $$

3.  **Define the Beppo-Levi Inner Product:**
    The smoothness penalty uses the second-order Beppo-Levi inner product [S1][S2, unofficial]:
    $$ \langle g, h \rangle_{BL_2} := \langle \partial_{t_1 t_1} g, \partial_{t_1 t_1} h \rangle + 2 \langle \partial_{t_1 t_2} g, \partial_{t_1 t_2} h \rangle + \langle \partial_{t_2 t_2} g, \partial_{t_2 t_2} h \rangle $$
    where $\langle \cdot, \cdot \rangle$ is the standard $L^2$ inner product.

4.  **Derive the Linear System:**
    Differentiating the objective function with respect to $x$ yields the normal equations [S1][S2, unofficial]:
    $$ (S^T S + \lambda H) x = S^T y $$
    The matrix $A = S^T S + \lambda H$ is symmetric and positive definite [S2, unofficial].

5.  **Solve the System:**
    Solve for $x$ using the Conjugate Gradient (CG) method [S1][S2, unofficial].

**Pitfalls and Edge Cases:**
*   **Matrix Storage:** The matrix $H$ is dense and large ($N \times N$). It does not need to be explicitly computed or stored. Its action on a vector $x$ is equivalent to a filtering operation where filter weights are obtained via the BL2 inner product definition [S1][S2, unofficial]. Implementers must implement the matrix-vector product $Hx$ as a convolution/filtering step rather than forming $H$.
*   **Kernel Derivatives:** Computing the filter weights for $H$ requires the second derivatives of the cubic B-spline. Ensure numerical stability when evaluating these derivatives.
*   **Regularization:** The choice of $\lambda$ affects the trade-off between fidelity and smoothness. The value $10^{-2}$ is suggested by Xu et al. [S1][S2, unofficial].

**Pseudocode:**

```python
import numpy as np

def cubic_b_spline(t):
    """
    Univariate uniform centered cubic B-spline beta^3(t).
    Defined piecewise for t in [-2, 2].
    """
    t = np.abs(t)
    result = np.zeros_like(t)
    # Support is [-2, 2]
    mask_1 = t < 1
    mask_2 = (t >= 1) & (t < 2)
    
    # beta^3(t) = 2/3 - t^2 + t^3/2 for |t| < 1
    #           = 4/3 - 2t + t^3/2 for 1 <= |t| < 2
    result[mask_1] = 2.0/3.0 - t[mask_1]**2 + t[mask_1]**3 / 2.0
    result[mask_2] = 4.0/3.0 - 2.0*t[mask_2] + t[mask_2]**3 / 2.0
    return result

def d2_cubic_b_spline(t):
    """
    Second derivative of the univariate uniform centered cubic B-spline.
    beta^3''(t) = -2 + 3t for |t| < 1
                = 3t - 3 for 1 <= |t| < 2
    """
    t = np.abs(t)
    result = np.zeros_like(t)
    mask_1 = t < 1
    mask_2 = (t >= 1) & (t < 2)
    
    result[mask_1] = -2.0 + 3.0 * t[mask_1]
    result[mask_2] = 3.0 * t[mask_2] - 3.0
    return result

def optimal_interpolating_cubic_b_spline(t):
    """
    beta_I^3(t) = beta^3(t) - 1/6 * d^2/dt^2 beta^3(t)
    """
    return cubic_b_spline(t) - (1.0/6.0) * d2_cubic_b_spline(t)

def compute_h_vector_product(H_x, x, N, j_indices):
    """
    Computes Hx where H_{p,q} = <phi(. - j_p), phi(. - j_q)>_BL2.
    This is equivalent to a filtering operation.
    Note: The exact filter weights for the BL2 inner product of the 
    optimal interpolating cubic B-spline are derived from the 
    tensor product of the 1D kernels.
    
    For implementation, Hx can be computed by convolving x with a 
    specific filter derived from the BL2 inner product of the basis 
    functions. The filter weights w_k correspond to <phi(.), phi(. - k)>_BL2.
    
    Since the kernel is separable, the 2D operation is two 1D convolutions.
    """
    # Calculate 1D filter weights for the BL2 inner product of beta_I^3
    # The support of beta_I^3 is [-2, 2], so the filter is small.
    # Weights w_k = <beta_I^3(t), beta_I^3(t - k)>_BL2 for k in -4..4 (approx)
    # Exact calculation requires integrating the product of second derivatives.
    # For the purpose of this pseudocode, we assume a function get_bl2_weights()
    # provides these precomputed constants.
    
    # Placeholder for the actual filter derivation which involves:
    # int (beta_I^3''(t) * beta_I^3''(t-k) + 2*beta_I^3''(t)*beta_I^3''(t-k) ... ) dt
    # In 2D, it is the tensor product of 1D weights.
    
    # 1. Compute 1D filter weights
    # k ranges from -4 to 4 to cover the support of the convolution of two 
    # kernels with support [-2, 2].
    k_range = range(-4, 5)
    weights_1d = []
    for k in k_range:
        # Integral of d2_phi(t) * d2_phi(t-k) dt
        # This is the auto-correlation of the second derivative of the kernel.
        # We approximate this numerically or use known analytical values.
        # For cubic B-splines, the second derivative is piecewise linear.
        # The integral can be computed exactly.
        # Here we use a numerical approximation for clarity.
        t_vals = np.linspace(-4, 4, 1000)
        d2_phi_t = d2_cubic_b_spline(t_vals)
        d2_phi_tk = d2_cubic_b_spline(t_vals - k)
        # BL2 inner product in 1D is just the integral of product of second derivatives
        # because cross terms vanish in 1D? No, BL2 in 2D has cross terms.
        # In 1D, the "BL2" seminorm for a function of one variable is just 
        # integral of (f'')^2.
        # The inner product <phi(.), phi(.-k)>_BL2 in 1D is int phi''(t) phi''(t-k) dt.
        val = np.trapz(d2_phi_t * d2_phi_tk, t_vals)
        weights_1d.append(val)
    
    weights_1d = np.array(weights_1d)
    
    # 2. Apply 1D filter along rows
    # x is N x N image. Flatten to vector for S^T S part, but H is structured.
    # Hx is separable.
    # Reshape x to 2D image
    img = x.reshape((int(np.sqrt(N)), int(np.sqrt(N))))
    
    # Convolve along rows
    # Pad image to handle boundaries
    padded_img = np.pad(img, 2, mode='edge')
    convolved_rows = np.zeros_like(padded_img)
    for i in range(padded_img.shape[0]):
        convolved_rows[i, :] = np.convolve(padded_img[i, :], weights_1d, mode='same')
    
    # Convolve along columns
    padded_conv = np.pad(convolved_rows, ((2,2), (0,0)), mode='edge')
    convolved_cols = np.zeros_like(padded_conv)
    for j in range(padded_conv.shape[1]):
        convolved_cols[:, j] = np.convolve(padded_conv[:, j], weights_1d, mode='same')
        
    # Crop back to original size
    Hx_2d = convolved_cols[2:-2, 2:-2]
    
    return Hx_2d.flatten()

def solve_smoothness_splines(y, M, N, measurement_indices):
    """
    Solves (S^T S + lambda H) x = S^T y using Conjugate Gradient.
    
    Parameters:
    y: measured values (M,)
    M: number of measurements
    N: total pixels
    measurement_indices: indices in the full image grid corresponding to y
    
    Returns:
    x: recovered image (N,)
    """
    lambda_reg = 1e-2
    
    # Precompute S^T y
    # S is a selection matrix. S^T y places y values back into the N-vector at measurement_indices
    Sy = np.zeros(N)
    Sy[measurement_indices] = y
    
    # Define the matrix-vector product for A = S^T S + lambda H
    def mat_vec_mult(v):
        # S^T S v: S selects components of v at measurement_indices, then S^T places them back.
        # So (S^T S v)[i] = v[i] if i is a measurement index, else 0.
        v_masked = np.zeros(N)
        v_masked[measurement_indices] = v[measurement_indices]
        
        # lambda H v
        Hv = compute_h_vector_product(None, v, N, None)
        
        return v_masked + lambda_reg * Hv

    # Initial guess
    x = np.zeros(N)
    
    # Conjugate Gradient Solver
    # Solve A x = b where b = S^T y
    b = Sy
    tol = 1e-6
    max_iter = 1000
    
    r = b - mat_vec_mult(x)
    p = r.copy()
    rs_old = np.dot(r, r)
    
    for i in range(max_iter):
        Ap = mat_vec_mult(p)
        pAp = np.dot(p, Ap)
        if pAp == 0:
            break
        alpha = rs_old / pAp
        x = x + alpha * p
        r = r - alpha * Ap
        rs_new = np.dot(r, r)
        if np.sqrt(rs_new) < tol:
            break
        p = r + (rs_new / rs_old) * p
        rs_old = rs_new
        
    return x
```

## Operating characteristics
*   **Time Complexity:** The dominant cost is the Conjugate Gradient iteration. Each iteration involves a matrix-vector product with $H$, which is a filtering operation. The cost per iteration is $O(N)$ if the filter is small and separable, or $O(N \log N)$ if FFT-based convolution is used. The number of iterations depends on the condition number of $S^T S + \lambda H$.
*   **Memory Complexity:** $O(N)$ to store the image and intermediate vectors. The matrix $H$ is not stored explicitly.
*   **Performance:** SS is computationally less expensive than compressed sensing methods that require iterative pursuit strategies (like L1 minimization) [S1].
*   **Strengths:** More resilient to missing information than compressed sensing (CS) methods [S1]. Can achieve high quality recovery with as little as 20% of pixels distributed uniformly [S1].
*   **Limitations:** Assumes the image is smooth (penalizes second derivatives). May blur sharp edges or discontinuities more than TV-based methods. Sensitive to the choice of regularization parameter $\lambda$.
*   **When to use:** When the rendered image is expected to be smooth and high-quality recovery from sparse samples is needed, and computational efficiency is a priority over edge preservation.
*   **When not to use:** When the image contains sharp edges or discontinuities that should be preserved, or when the image is not smooth.

## Background
Smoothness Splines was proposed by Xu et al. [XAE12] and applied to volume rendering by Liu and Alim [S1][S2, unofficial]. It is based on the theory of scattered data approximation using shift-invariant spline spaces. The method uses the optimal interpolating cubic B-spline kernel proposed by Blu et al. [BTU01]. It is categorized as a smoothness-based recovery method, contrasting with compressed sensing (CS) methods that exploit sparsity in wavelet or gradient domains [S1].
