# Depth-dependent scaling in Triangle Splatting

Also called: Triangle Splatting influence function scaling invariance

## Overview
This property ensures that the spatial influence of a triangle splat remains consistent regardless of its depth or projected scale, allowing a single smoothness parameter $\sigma$ to be used for all triangles in the scene [S1]. It distinguishes Triangle Splatting from other splatting methods by relying on a normalized signed distance field ratio rather than depth-dependent covariance adjustments [S1].

## How it works
### Inputs and Outputs
*   **Input**: A pixel coordinate $\mathbf{p}$ in screen space, the triangle's three vertices, and the smoothness parameter $\sigma > 0$ [S1].
*   **Output**: The influence value $I(\mathbf{p}) \in [0, 1]$ [S1].

### Data Structures
The signed distance field $\phi(\mathbf{p})$ is computed as the maximum of the signed distances to the three edges: $\phi(\mathbf{p}) = \max_{i=1,2,3} d_i(\mathbf{p})$ [S1]. Here, $d_i(\mathbf{p})$ is the signed distance from $\mathbf{p}$ to the $i$-th edge, defined as negative inside the triangle and positive outside [S1]. $\min \phi$ is the minimum value of $\phi(\mathbf{p})$ over the triangle interior, occurring at the incenter [S1].

### Steps
1.  **Compute Signed Distances**: For a query pixel $\mathbf{p}$, calculate the signed distance $d_i(\mathbf{p})$ to each of the three triangle edges [S1].
2.  **Compute SDF**: Calculate $\phi(\mathbf{p}) = \max(d_1(\mathbf{p}), d_2(\mathbf{p}), d_3(\mathbf{p}))$ [S1].
3.  **Determine Minimum SDF**: Retrieve $\min \phi$, the most negative value of $\phi$ within the triangle (at the incenter) [S1].
4.  **Normalize**: Compute the ratio $r(\mathbf{p}) = \frac{\phi(\mathbf{p})}{\min \phi}$ [S1].
5.  **Apply ReLU and Exponent**: Compute the influence: $I(\mathbf{p}) = \text{ReLU}(r(\mathbf{p}))^\sigma$ [S1].

### Formula
The influence function is defined as:
$$ I(\mathbf{p}) = \text{ReLU}\left(\frac{\phi(\mathbf{p})}{\min \phi}\right)^\sigma $$
such that $I(\mathbf{p}) = 1$ at the triangle incenter, $0$ at the triangle boundary, and $0$ outside the triangle [S1].

**Scaling Invariance Proof**:
If the triangle is projected and scaled by a factor $a > 0$, the vertex coordinates and pixel coordinates transform as $\mathbf{v}_i \to a\mathbf{v}_i$ and $\mathbf{p} \to a\mathbf{p}$ [S1]. The signed distance to each edge scales linearly: $d'_i(\mathbf{p}') = a d_i(\mathbf{p})$ [S1]. Consequently:
$$ \phi'(\mathbf{p}') = \max_i d'_i(\mathbf{p}') = a \max_i d_i(\mathbf{p}) = a \phi(\mathbf{p}) $$
$$ \min \phi' = a \min \phi $$
The ratio remains constant:
$$ \frac{\phi'(\mathbf{p}')}{\min \phi'} = \frac{a \phi(\mathbf{p})}{a \min \phi} = \frac{\phi(\mathbf{p})}{\min \phi} $$
Thus, $I'(\mathbf{p}') = I(\mathbf{p})$ [S1].

### Parameters
*   **$\sigma$ (sigma)**: A scalar parameter $\sigma > 0$ controlling the smoothness of the window function [S1].
    *   $\sigma \to 0$: The function converges to the hard triangle shape [S1].
    *   $\sigma \to \infty$: The function converges to a delta function at the incenter [S1].
    *   Typical values: Not specified in the sources, but must be $>0$ [S1].

### Edge Cases and Pitfalls
*   **Small Triangles**: Using LogSumExp to approximate the max in the SDF definition causes poor shape for small triangles, where only one vertex influences the shape; the actual max function must be used [S1].
*   **Boundary Precision**: The function is exactly $0$ at the boundary and outside; care must be taken with floating-point precision near the boundary to avoid artifacts [G].
*   **Incenter Calculation**: $\min \phi$ is the value at the incenter; for implementation, this can be precomputed per triangle or approximated via the inradius [G].

### Pseudocode
```python
import math

def compute_triangle_influence(p, vertices, sigma):
    """
    Computes the influence I(p) for a pixel p given a triangle.
    
    Args:
        p: (x, y) pixel coordinate.
        vertices: List of 3 (x, y) tuples representing triangle vertices (CCW winding).
        sigma: Smoothness parameter > 0.
        
    Returns:
        Influence value in [0, 1].
    """
    # Step 1: Compute signed distances to edges (negative inside, positive outside)
    distances = []
    for i in range(3):
        v1 = vertices[i]
        v2 = vertices[(i + 1) % 3]
        # Edge vector
        ex, ey = v2[0] - v1[0], v2[1] - v1[1]
        # Vector from v1 to p
        px, py = p[0] - v1[0], p[1] - v1[1]
        # Length of edge
        length = math.hypot(ex, ey)
        if length == 0:
            distances.append(0.0)
            continue
        # Signed distance: negative inside for CCW winding
        dist = (ey * px - ex * py) / length
        distances.append(dist)
    
    # Step 2: Compute SDF phi(p) = max(d_i)
    phi_p = max(distances)
    
    # Step 3: Determine min_phi (at incenter)
    # Compute inradius r = Area / s, where s is semi-perimeter
    x1, y1 = vertices[0]
    x2, y2 = vertices[1]
    x3, y3 = vertices[2]
    area = 0.5 * abs(x1*(y2-y3) + x2*(y3-y1) + x3*(y1-y2))
    a = math.hypot(x2-x1, y2-y1)
    b = math.hypot(x3-x2, y3-y2)
    c = math.hypot(x1-x3, y1-y2)
    s = (a + b + c) / 2.0
    inradius = area / s if s > 0 else 0.0
    min_phi = -inradius
    
    # Step 4: Normalize
    if min_phi == 0:
        return 0.0
    ratio = phi_p / min_phi
    
    # Step 5: Apply ReLU and Exponent
    if ratio <= 0:
        return 0.0
    return ratio ** sigma
```

## Subtopics

### Triangle Window Function
The Triangle Window Function is the specific implementation of the influence function $I(\mathbf{p})$ described above [S1]. It ensures maximum value (1) at the incenter, zero at the boundary, and zero outside [S1]. It solves the problem of defining a smooth, compact support for triangle splatting that converges to the triangle shape ($\sigma \to 0$) or a delta function ($\sigma \to \infty$) based on the parameter $\sigma$ [S1]. Unlike sigmoid-based window functions ($I = \text{sigmoid}(-\sigma^{-1} \phi(\mathbf{p}))$) which fail to have max=1 and have support larger than the triangle, this formulation ensures tight support and correct maximum [S1].

## Operating characteristics
*   **Time Complexity**: Computing the influence for a pixel involves constant-time operations (3 edge distance calculations, max, division, power) [G].
*   **Memory Complexity**: Requires storing the triangle vertices and precomputed $\min \phi$ (inradius) per triangle [G].
*   **Strengths**: Depth-independent scaling allows a single $\sigma$ parameter for all triangles, simplifying optimization and rendering [S1]. Tight support reduces unnecessary computation outside the triangle [S1].
*   **Limitations**: The actual max function for SDF is not smooth everywhere, which may affect gradient-based optimization in some contexts, though it is preferred for shape accuracy [S1].
*   **When to use**: When rendering triangle-based representations where consistent appearance across depths is required without per-triangle depth scaling parameters [S1].

## Background
This property is a key component of Triangle Splatting, a method for real-time radiance field rendering [S1]. It addresses the limitations of other splatting methods by providing a depth-consistent influence function through normalization [S1]. The scaling invariance allows for simpler parameterization and efficient rendering [S1].
