# Curve-Skeleton Decomposition

Also called: Centerline, Centerline decomposition, Curve-skeleton, Skeleton-based block decomposition

## Overview
Curve-Skeleton Decomposition is a proxy geometry technique that represents a volumetric object as a 1D line-like structure (skeleton or centerline) to enable bend, move, re-pose, and sweep transformations [S1, book]. It solves the problem of interactive manipulation of volumetric data by decomposing the volume into bounding cuboids along the skeleton, allowing independent transformation and rendering of segments [S1, book]. Unlike direct volume deformation, this method separates the geometric abstraction from the rendering, enabling fast, minimum-geometric-processing manipulation [S1, book].

## How it works
**Inputs:**
- Volumetric dataset $V$ [S1, book].
- Extracted curve-skeleton $S$ [S1, book].
- Joint locations on $S$ defining bending regions [S1, book].
- Transfer function for color/opacity mapping [G].

**Outputs:**
- Volume-rendered image of the deformed volume [S1, book].

**Data Structures:**
1. **Skeleton $S$**: A sequence of vertices and edges capturing the object's topology [S1, book].
2. **Distance Field $D$**: Computed from $V$, storing distances to the volume boundary, used to determine cuboid widths [S1, book].
3. **Bounding Cuboids**: One per skeletal segment between joints, with width derived from $D$ [S1, book].
4. **Sliced Polygons**: Planar slices of each cuboid, texture-mapped to the original volume data [S1, book].
5. **Depth Index**: A data structure indexing polygons by their depth coordinate for sorting [S1, book].

**Steps:**
1. Extract the skeleton from the volumetric object [S1, book].
2. Choose joints on the skeleton to define areas where bending can occur [S1, book].
3. Define bounding cuboids for each skeletal segment between joints, determining the width from the distance field computed on the volume [S1, book].
4. For interactive manipulation, transform cuboids about the joint [S1, book].
5. Slice each cuboid along the viewport [S1, book].
6. Map the slices back to the original texture to determine the appropriate color value [S1, book].
7. Interpolate between the two end planes of adjoining bounding boxes to cover the joint area with a stretched volume [S1, book].
8. Sort the sliced polygons along the view direction from back to front using a two-pass rendering algorithm and a data structure that indexes polygons with respect to their depth coordinate [S1, book].
9. Composite the texture-mapped polygons back-to-front to volume render the deformed volume [S1, book].

    # Step 1: Compute distance field from volume [G]

    cuboids = []
    for i in range(len(joints) - 1):
        start_idx = joints[i]
        end_idx = joints[i+1]
        segment_points = skeleton[start_idx:end_idx+1]
        
        # Determine width from distance field [G]
        avg_width = sum(distance_field[p] for p in segment_points) / len(segment_points)
        
        # Create bounding cuboid around the segment [G]
        min_pt = min(segment_points, key=lambda p: p[0])
        max_pt = max(segment_points, key=lambda p: p[0])

        cuboids.append(cuboid)
        
    # Step 3: Apply transformations about joints
    transformed_cuboids = []

        joint_idx = joints[i]

        # Apply transformation T about the joint [G]

    # Step 4: Slice each cuboid along the viewport

    for cuboid in transformed_cuboids:
        slices = intersect_cuboid_viewplane(cuboid, view_matrix)
        for slice_poly in slices:

    # Step 7: Composite back-to-front [G]
    image = alpha_blend_back_to_front(sorted_polygons)
    
    return image

## Operating characteristics
- **Time Complexity**: Not given in the sources. [G]
- **Memory Complexity**: Not given in the sources. [G]
- **Measured Performance**: Requires minimum geometric processing and is therefore very fast [S1, book].
- **Scaling**: Scales with the complexity of the skeleton and the number of joints [S1, book].
- **Strengths**: Fast, supports interactive manipulation, enables selective rendering and sweeps [S1, book].
- **Limitations**: Requires re-slicing on rotation, may lose fine details if cuboids are too large [G].
- **When to Use**: Virtual colonoscopy, navigation along paths, selective rendering [S1, book].
- **When Not to Use**: When high-fidelity detail is required without decomposition [G].

## Background
Curve-Skeleton Decomposition was introduced in the context of illustrative focus+context approaches in interactive volume visualization [S1, book]. It builds on the traditional use of skeletons for specifying motion in computer graphics, extending motion capture techniques to volumetric data [S1, book]. The method is commonly used in medical illustration and virtual colonoscopy [S1, book].
