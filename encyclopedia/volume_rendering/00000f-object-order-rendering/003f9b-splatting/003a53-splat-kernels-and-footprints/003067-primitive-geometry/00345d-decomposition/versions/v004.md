# Decomposition
## Overview
Decomposition is an image-order volume rendering technique that converts a volumetric data set into geometric primitives, such as spheres or slices [S1][S2, unofficial]. The primitives are placed in space and scaled and colored based on a mapping [S1][S2, unofficial]. Slices are commonly rendered as pseudo-colored textures or height maps, or are used for further processing like segmentation [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
* **Input:** A 3D volumetric data set and a mapping function [S1][S2, unofficial].
* **Output:** A 2D image generated from the decomposed primitives [S1][S2, unofficial].

**Data Structures:**
* A collection of geometric primitives, specifically spheres or slices [S1][S2, unofficial]. Exact layouts, fields, sizes, and bit packing are not given in the sources [S1][S2, unofficial].

**Steps:**
1. **Decomposition:** Convert the volumetric data set into geometric primitives, such as spheres or slices [S1][S2, unofficial].
2. **Placement:** Place the primitives in space [S1][S2, unofficial].
3. **Scaling and Coloring:** Scale and color the primitives based on the mapping [S1][S2, unofficial].
4. **Rendering:** Render slices as pseudo-colored textures or height maps, or use them for further processing like segmentation [S1][S2, unofficial].

## Subtopics

### [Curve-Skeleton Decomposition](8486-curve-skeleton-decomposition.md)
Curve-Skeleton Decomposition is a proxy geometry technique that represents a volumetric object as a 1D line-like structure (skeleton or centerline) to enable bend, move, re-pose, and sweep transformations. It solves the problem of interactive manipulation of volumetric data by decomposing the volume into bounding cuboids along the skeleton, allowing independent transformation and rendering of segments. Unlike direct volume deformation, this method separates the geometric abstraction from the rendering, enabling fast, minimum-geometric-processing manipulation.
