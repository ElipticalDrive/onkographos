# TetSplat Pre-processing: Mesh Partitioning

Also called: Partitioning the Input Mesh into the Shell and the Solid

## Overview
This method partitions a large unstructured tetrahedral mesh into two distinct topological parts: the Shell (non-convex boundary) and the Solid (internal fragments) [S1, unofficial]. This separation allows the Shell to be rendered as a standard opaque surface mesh with vertex normals, while the Solid is rendered using normals derived from a Constructive Solid Geometry (CSG) probe, as interior tetrahedra are only visible at the intersection surface [S1, unofficial].

## How it works
**Inputs:** An unstructured tetrahedral mesh consisting of tetrahedra $Tet_k$ [S1, unofficial].
**Outputs:** Two sets of triangles: the Shell (boundary faces) and the Solid (internal faces, further classified as boundary or internal triangles) [S1, unofficial].

**Data Structures:**
*   `Tri`: An array containing all triangles derived from the tetrahedral mesh. Each element stores a sorted list of vertex indices [S1, unofficial].

**Algorithm Steps:**

1.  **Triangle Extraction and Canonicalization:** For each tetrahedron $Tet_k$, extract its four constituent triangles [S1, unofficial]. Sort the vertex indices within each triangle's vertex list to ensure a canonical representation [S1, unofficial]. Store these sorted triangles in the array `Tri` [S1, unofficial].
2.  **Global Sorting:** Sort the entire `Tri` array based on the indexed vertex list of each triangle [S1, unofficial]. This groups identical triangles (those sharing the same three vertices) together in adjacent positions [S1, unofficial].
3.  **Shell/Solid Classification:** Iterate through each triangle $Tri_i$ in the sorted `Tri` array [S1, unofficial]. Compare the vertex list of $Tri_i$ with the vertex list of the next triangle $Tri_{i+1}$ [S1, unofficial]. If the vertex lists are identical, classify $Tri_i$ as part of the Solid [S1, unofficial]. If they differ, classify $Tri_i$ as part of the Shell [S1, unofficial]. Mark the tetrahedron $Tet_k$ associated with a Shell triangle as a boundary tetrahedron [S1, unofficial].
4.  **Solid Sub-classification:** Iterate through each triangle $Tri_i$ classified as part of the Solid [S1, unofficial]. Check if the associated tetrahedron $Tet_k$ is a boundary tetrahedron [S1, unofficial]. If $Tet_k$ is a boundary tetrahedron, classify $Tri_i$ as a boundary triangle in the Solid [S1, unofficial]. If $Tet_k$ is not a boundary tetrahedron, classify $Tri_i$ as an internal triangle in the Solid [S1, unofficial].
5.  **Degeneracy Removal:** Remove degenerate tetrahedra from the mesh [S1, unofficial]. Needles (tetrahedra without large dihedral angles) are removed by collapsing their shortest edges [S1, unofficial]. Spindles (tetrahedra with a single large dihedral angle) are removed by splitting the edge opposite to the large angle and then collapsing the shortest edges [S1, unofficial].

**Pseudocode:**

```python
def partition_mesh(tetrahedra):
    # Step 1: Extract and canonicalize triangles
    Tri = []
    for k, Tetk in enumerate(tetrahedra):
        v = Tetk.vertices
        # Extract 4 triangles from Tetk (indices 0,1,2; 0,1,3; 0,2,3; 1,2,3)
        faces = [(v[0], v[1], v[2]), (v[0], v[1], v[3]), (v[0], v[2], v[3]), (v[1], v[2], v[3])]
        for i, tri in enumerate(faces):
            # Sort vertex indices for canonical comparison
            sorted_indices = tuple(sorted(tri))
            Tri.append({
                'indices': sorted_indices,
                'tet_index': k,
                'local_index': i
            })

    # Step 2: Sort all triangles by vertex indices
    Tri.sort(key=lambda x: x['indices'])

    shell_triangles = []
    solid_triangles = []
    boundary_tetrahedra = set()

    # Step 3: Classify Shell vs Solid
    n = len(Tri)
    for i in range(n):
        current = Tri[i]
        # Check if current triangle is identical to the next one
        is_shared = (i + 1 < n) and (current['indices'] == Tri[i + 1]['indices'])
        
        if is_shared:
            # Shared face -> Solid
            solid_triangles.append(current)
        else:
            # Boundary face -> Shell
            shell_triangles.append(current)
            boundary_tetrahedra.add(current['tet_index'])

    # Step 4: Sub-classify Solid triangles
    solid_boundary_triangles = []
    solid_internal_triangles = []
    
    for tri in solid_triangles:
        tet_idx = tri['tet_index']
        if tet_idx in boundary_tetrahedra:
            solid_boundary_triangles.append(tri)
        else:
            solid_internal_triangles.append(tri)

    # Step 5: Remove degenerate tetrahedra (Needles and Spindles)
    clean_tetrahedra = []
    for Tetk in tetrahedra:
        # [G]: The sources do not specify the exact geometric predicates or edge-collapse implementation for Needles and Spindles.
        clean_tetrahedra.append(Tetk)

    return shell_triangles, solid_boundary_triangles, solid_internal_triangles, clean_tetrahedra
```

**Parameters:**
*   `Tri`: An array containing all triangles derived from the tetrahedral mesh, used for sorting and classification [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Sorting relies on exact vertex index equality [S1, unofficial]. Floating-point precision issues in vertex positions must be resolved during the initial mesh construction or by using a tolerance-based canonicalization before index sorting [G].
*   **Degeneracy:** The algorithm explicitly handles "Needles" (no large dihedral angles) and "Spindles" (one large dihedral angle) [S1, unofficial].
*   **Boundary Definition:** The distinction between "boundary triangle in the Solid" and "Shell" is topological [S1, unofficial]. Shell triangles are on the mesh boundary; Solid boundary triangles are internal faces of tetrahedra that touch the mesh boundary [S1, unofficial].

## Operating characteristics
**Time Complexity:** Dominated by the sorting step [G]. Sorting $N$ triangles takes $O(N \log N)$ time, where $N$ is the total number of triangle faces ($4 \times$ number of tetrahedra) [G]. The iteration steps are linear $O(N)$ [G].
**Memory Complexity:** Requires storage for the `Tri` array, which is proportional to the number of tetrahedra [G].
**Measured Performance:** Not given in the sources.
**Scaling:** Not given in the sources.
**Strengths:** Provides a clean topological separation that allows different shading strategies (vertex normals vs. CSG probe normals) for boundary and interior, ensuring visual consistency at the clipping boundary [S1, unofficial].
**Limitations:** Requires a full pass over the mesh data and sorting [G]. Degeneracy removal adds preprocessing overhead [G].
**When to use:** Not given in the sources.

## Background
This method originates from the TetSplat paper by Museth and Lombeyda (2004), which introduced a point-based technique for real-time rendering of large tetrahedral meshes [S1, unofficial]. The partitioning is a prerequisite for the hierarchical bounding sphere structure and the CSG probe clipping mechanism described in the parent article [S1, unofficial].
