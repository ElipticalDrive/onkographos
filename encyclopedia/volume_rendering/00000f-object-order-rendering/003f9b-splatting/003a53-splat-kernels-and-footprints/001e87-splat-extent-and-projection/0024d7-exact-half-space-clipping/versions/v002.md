# Exact Half-Space Clipping

Also called: Exact Clipping, Ours, XClipGS (eXact Clipping), XClipGS Exact Half-Space Clipping

## Overview
Exact Half-Space Clipping (implemented as XClipGS) is a method for the interactive rendering of volumetric medical scans using Gaussian splatting proxies [S1, unofficial]. It solves the problem of clipping planes exposing hidden anatomy by treating the render-time clip operator and the supervision of the hidden interior as separate problems [S1, unofficial]. Unlike siblings that use binary keep/drop decisions or learned deformations, it uses a closed-form, differentiable per-splat operator that integrates half-space-restricted Gaussians under the local affine model [S1, unofficial]. It sets itself apart from [Centralized Conics Approach](1243-centralized-conics-approach.md) by computing the exact retained ray integral via conditional Gaussian CDF evaluation rather than approximating the truncated density with moments or binary masks [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A 3D Gaussian primitive defined by mean $\boldsymbol{\mu} \in \mathbb{R}^3$, covariance $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$ (positive definite), and opacity $\alpha \in [0, 1]$; a camera defined by a local affine projection model; and a clipping plane defined by unit normal $\mathbf{n}$ and offset $\tau$.
*   **Outputs:** The clipped per-pixel contribution factor, which modulates the standard EWA splatting weight.

**Data Structures:**
*   **Primitive Attributes:** $\boldsymbol{\mu}, \boldsymbol{\Sigma}, \alpha$.
*   **Clip Coefficients:** For straddling primitives, three scalar coefficients are computed to represent the affine argument of the conditional CDF: $\mathbf{k} \in \mathbb{R}^2$ and $h \in \mathbb{R}$.
*   **Buffers:** One transient 16-byte per-view buffer per primitive is required [S1, unofficial].

**Mathematical Definitions:**
The local affine approximation of the projection at primitive center $\boldsymbol{\mu}$ is:
$$ \mathbf{u}(\mathbf{x}) \approx \hat{\boldsymbol{p}} + \mathbf{M}(\mathbf{x} - \boldsymbol{\mu}) $$
where $\mathbf{M} = \mathbf{J}\mathbf{W} \in \mathbb{R}^{2 \times 3}$, $\mathbf{W}$ is the world-to-camera rotation, $\mathbf{J}$ is the projection Jacobian at $\boldsymbol{\mu}$, and $\hat{\boldsymbol{p}}$ is the projected center [S1, unofficial].

The screenspace covariance is $\mathbf{A} = \mathbf{M}\boldsymbol{\Sigma}\mathbf{M}^\top$. The unclipped contribution to pixel $\mathbf{p}$ is $\alpha K_G(\boldsymbol{\delta}; \mathbf{A})$ with $\boldsymbol{\delta} = \hat{\boldsymbol{p}} - \mathbf{p}$ and $K_G(\boldsymbol{\delta}; \mathbf{A}) = \exp(-\boldsymbol{\delta}^\top \mathbf{A}^{-1} \boldsymbol{\delta})$ [S1, unofficial].

The clipping plane keeps the half-space $H_\tau = \{\mathbf{x} \in \mathbb{R}^3 : \mathbf{n}^\top \mathbf{x} \le \tau\}$ [S1, unofficial].

**Step-by-Step Method:**

1.  **Preprocessing (Culling):**
    Compute the standardized signed distance to the plane:
    $$ \sigma_n^2 = \mathbf{n}^\top \boldsymbol{\Sigma} \mathbf{n} $$
    $$ a = \frac{\tau - \mathbf{n}^\top \boldsymbol{\mu}}{\sigma_n} $$
    Compute the fraction of mass on the kept side: $\Phi(a)$, where $\Phi$ is the standard normal CDF [S1, unofficial].
    Discard the primitive if $\Phi(a) \le 10^{-6}$ [S1, unofficial].

2.  **Compute Clip Coefficients (for straddling primitives):**
    Compute the cross-covariance vector $\mathbf{b}$:
    $$ \mathbf{b} = \mathbf{M}\boldsymbol{\Sigma}\mathbf{n} $$
    Compute the conditional variance (Schur complement):
    $$ s^2 = \sigma_n^2 - \mathbf{b}^\top \mathbf{A}^{-1} \mathbf{b} $$
    Apply a variance floor to avoid division by zero in degenerate cases:
    $$ s^2_{\text{impl}} = \max(s^2, 10^{-8}) $$
    Compute the coefficients $\mathbf{k}$ and $h$ for the affine CDF argument:
    $$ \mathbf{k} = \mathbf{A}^{-1}\mathbf{b} / s_{\text{impl}} $$
    $$ h = (\tau - \mathbf{n}^\top \boldsymbol{\mu}) / s_{\text{impl}} $$
    [S1, unofficial]

3.  **Rasterization (Forward Pass):**
    For each pixel $\mathbf{p}$ covered by the primitive's footprint:
    Compute the pixel offset $\boldsymbol{\delta} = \hat{\boldsymbol{p}} - \mathbf{p}$.
    Compute the clipped contribution factor:
    $$ \text{factor} = \Phi(\mathbf{k}^\top \boldsymbol{\delta} + h) $$
    The final per-pixel weight is:
    $$ \text{weight} = \alpha K_G(\boldsymbol{\delta}; \mathbf{A}) \cdot \text{factor} $$
    [S1, unofficial]

4.  **Backward Pass (Training):**
    Compute gradients for the clip coefficients $\mathbf{k}, h$ and the projected center $\hat{\boldsymbol{p}}$. Chain these through the conic $\mathbf{A}$ and projection Jacobian $\mathbf{M}$ to obtain gradients for $\boldsymbol{\mu}$ and $\boldsymbol{\Sigma}$ [S1, unofficial].
    If the variance floor is active ($s^2_{\text{impl}} = 10^{-8}$), set the derivative through $s^2$ to zero [S1, unofficial].

**Pseudocode:**

```python
import math
import numpy as np

def standard_normal_cdf(x):
    """
    Approximation of the standard normal CDF.
    Uses the error function erf.
    """
    return 0.5 * (1.0 + math.erf(x / math.sqrt(2.0)))

def exact_half_space_clipping(
    mu: np.ndarray,       # (3,) Mean of the Gaussian
    Sigma: np.ndarray,    # (3,3) Covariance of the Gaussian
    alpha: float,         # Opacity
    M: np.ndarray,        # (2,3) Local affine projection matrix
    p_hat: np.ndarray,    # (2,) Projected center
    n: np.ndarray,        # (3,) Plane normal (unit vector)
    tau: float            # Plane offset
) -> dict:
    """
    Computes the exact half-space clipping coefficients and checks for culling.
    Returns clip coefficients if the primitive is kept, or None if culled.
    """
    # 1. Preprocessing: Check retained mass
    sigma_n_sq = n.T @ Sigma @ n
    
    # Guard against zero variance along normal (degenerate primitive)
    if sigma_n_sq < 1e-12:
        # If variance is effectively zero, check if the point is inside the half-space
        dist = n.T @ mu - tau
        if dist <= 0:
            # Entire primitive is inside, return identity coefficients (factor=1)
            return {'k': np.zeros(2), 'h': 1e9} # h large ensures Phi(h) ~ 1
        else:
            # Entire primitive is outside
            return None

    sigma_n = math.sqrt(sigma_n_sq)
    a = (tau - n.T @ mu) / sigma_n
    
    # Cutoff: Phi(a) <= 1e-6
    if standard_normal_cdf(a) <= 1e-6:
        return None

    # 2. Compute Clip Coefficients
    # Compute screenspace covariance A
    A = M @ Sigma @ M.T
    
    # Compute b = M Sigma n
    b = M @ Sigma @ n
    
    # Compute conditional variance s^2 (Schur complement)
    # s^2 = sigma_n^2 - b^T A^{-1} b
    # Use inverse of A. A is 2x2.
    det_A = A[0,0]*A[1,1] - A[0,1]*A[1,0]
    if abs(det_A) < 1e-12:
        # Degenerate projection (rank deficient M)
        # Fallback to simple check or cull
        return None
        
    A_inv = np.array([
        [A[1,1]/det_A, -A[0,1]/det_A],
        [-A[1,0]/det_A, A[0,0]/det_A]
    ])
    
    b_term = b.T @ A_inv @ b
    s_sq = sigma_n_sq - b_term
    
    # Variance floor
    s_sq_impl = max(s_sq, 1e-8)
    s_impl = math.sqrt(s_sq_impl)
    
    # Compute k and h
    # k = A^{-1} b / s
    k = (A_inv @ b) / s_impl
    
    # h = (tau - n^T mu) / s
    h = (tau - n.T @ mu) / s_impl
    
    return {'k': k, 'h': h, 'A_inv': A_inv, 'p_hat': p_hat, 'alpha': alpha, 'Sigma': Sigma, 'M': M}

def evaluate_clipped_splat(
    clip_data: dict,
    pixel_p: np.ndarray, # (2,) Pixel coordinate
) -> float:
    """
    Evaluates the clipped weight for a specific pixel.
    Assumes clip_data is not None (primitive not culled).
    """
    k = clip_data['k']
    h = clip_data['h']
    A_inv = clip_data['A_inv']
    p_hat = clip_data['p_hat']
    alpha = clip_data['alpha']
    
    # Compute delta
    delta = p_hat - pixel_p
    
    # Compute unclipped Gaussian weight (unnormalized)
    # KG(delta; A) = exp(-delta^T A^{-1} delta)
    quad_form = delta.T @ A_inv @ delta
    weight_unclipped = math.exp(-quad_form)
    
    # Compute clipping factor
    arg = k.T @ delta + h
    clip_factor = standard_normal_cdf(arg)
    
    return alpha * weight_unclipped * clip_factor
```

**Parameters:**
*   **Retained-mass cutoff:** $\Phi(a) \le 10^{-6}$ [S1, unofficial].
*   **Variance floor:** $10^{-8}$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Degenerate Case ($s^2 = 0$):** Occurs when the clip coordinate $\omega$ is almost surely an affine function of the pixel coordinate $\mathbf{u}$ (i.e., the plane contains the viewing-ray direction). The conditional law collapses to a point mass. The implementation handles this with the conditional-variance floor ($10^{-8}$) [S1, unofficial].
*   **Precision:** The CDF is evaluated in fp32. Gradients match float64 autograd to $\approx 10^{-6}$ relative error [S1, unofficial].

## Subtopics

### Sharp Feature Rendering via Clip Lines
A technique to render sharp features (edges, corners) in point-sampled surfaces by explicitly representing features as clip lines in local tangent planes, which discard parts of reconstruction kernels to prevent blurring [S2, unofficial]. It sets itself apart from standard clipping by operating on 2D tangent plane intersections rather than 3D half-spaces. Choose it when rendering point-sampled objects like cubes where sharp edges must be preserved without blurring [S2, unofficial].
*   **Definition:** Features are represented as clip lines in local tangent planes [S2, unofficial].
*   **Steps:**
    1.  Compute clip lines by intersecting tangent planes of adjacent reconstruction kernels on either side of a feature [S2, unofficial].
    2.  Represent a clip line using two homogeneous points $\mathbf{c}_h$ and $\mathbf{d}_h$ in the local tangent plane [S2, unofficial].
    3.  Project clip line points to image space: $\mathbf{c}'_h = \mathbf{c}_h \mathbf{M}_k$, $\mathbf{d}'_h = \mathbf{d}_h \mathbf{M}_k$. Perform projective normalization to get non-homogeneous points $\mathbf{c}'$ and $\mathbf{d}'$ [S2, unofficial].
    4.  Compute a direction vector $\mathbf{v}$ perpendicular to the line through $\mathbf{c}'$ and $\mathbf{d}'$. Evaluate the reconstruction kernel at point $\mathbf{x}$ in image space if $(\mathbf{x} - \mathbf{c}') \cdot \mathbf{v} > 0$; otherwise discard $\mathbf{x}$ [S2, unofficial].
    5.  Ensure pairs of reconstruction kernels share the same clip line to prevent holes due to clipping [S2, unofficial].
*   **Parameters:** Fg: Cutoff value used for splat clipping to emphasize sharp edges. Example value: $0.5$ [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** The forward pass adds one scalar fp32 CDF evaluation per straddling sample [S1, unofficial]. The backward pass uses a warp-per-splat render backward where each lane accumulates one primitive's full gradient in registers and issues a single atomic per primitive per tile [S1, unofficial].
*   **Memory Complexity:** Requires one transient 16-byte per-view buffer per primitive [S1, unofficial].
*   **Measured Performance:** On an A100 at 800x800 with 300k Gaussians and active oblique clip, the forward-backward step reduces from 5.47 ms to 3.50 ms (1.6x speedup) relative to legacy per-pixel backward [S1, unofficial]. On eight CT and MRI volumes, it renders at over 650 FPS, versus 278 FPS for ClipGS [S1, unofficial].
*   **Strengths:** Exact integration of restricted density; differentiable; no learned clipping parameters or auxiliary network; supports both supervision and rendering [S1, unofficial].
*   **Limitations:** Requires handling degenerate cases (variance floor); global image metrics dilute errors near the clipping plane (requires paired clipped/unclipped cut-face protocol for evaluation) [S1, unofficial].
*   **When to use:** Interactive medical volume rendering where clipping planes expose hidden anatomy and accurate interior supervision is required [S1, unofficial].
*   **When not to use:** When binary keep/drop is sufficient and performance is critical without the need for differentiable interior supervision [S1, unofficial].

## Background
XClipGS was introduced by Gao et al. in 2026 [S1, unofficial]. It is built on the N-DGS backbone (Gao et al. 2025a,b; Liu et al. 2026) [S1, unofficial]. It addresses the limitations of prior methods like ClipGS (which uses trainable binary decisions via STE and MLP deformation) and RaRa (which scales primitives by visible chord fraction but lacks a backward pass for clip-aware training) [S1, unofficial]. It is used primarily for interactive rendering of volumetric medical scans (CT and MRI) [S1, unofficial].
