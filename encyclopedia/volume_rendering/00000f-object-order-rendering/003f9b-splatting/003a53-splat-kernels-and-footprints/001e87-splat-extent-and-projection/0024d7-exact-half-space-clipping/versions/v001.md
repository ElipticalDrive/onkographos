# Exact Half-Space Clipping

Also called: Exact Clipping, Ours, XClipGS (eXact Clipping), XClipGS Exact Half-Space Clipping

## Overview
Exact Half-Space Clipping (XClipGS) is a differentiable, closed-form operator for clipping 3D Gaussians in volume rendering that computes the exact retained ray integral of a half-space-restricted Gaussian under the local affine EWA model [S1, unofficial]. It solves the problem of clipping planes exposing hidden anatomy in volumetric medical scans by treating the render-time clip operator and the supervision of the hidden interior as separate problems, avoiding the approximation errors of binary keep/drop projections or learned deformation networks [S1, unofficial]. Unlike [Centralized Conics Approach](1243-centralized-conics-approach.md) which focuses on geometric projection of conics, XClipGS integrates the restricted density directly, allowing for both accurate rendering and gradient-based training of the interior content without auxiliary networks [S1, unofficial].

## How it works
**Inputs:** A 3D Gaussian primitive defined by mean $\boldsymbol{\mu} \in \mathbb{R}^3$, covariance $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$ (positive definite), opacity $\alpha \in [0, 1]$, and color; a camera defined by world-to-camera rotation $\mathbf{W}$, projection Jacobian $\mathbf{J}$ at $\boldsymbol{\mu}$, and projected center $\hat{\boldsymbol{p}}$; a clipping plane defined by unit normal $\mathbf{n}$ and offset $\tau$; and a pixel coordinate $\mathbf{p}$ in screen space.
**Outputs:** The clipped per-pixel contribution $I_{\text{clip}}(\mathbf{p})$ and gradients with respect to $\boldsymbol{\mu}, \boldsymbol{\Sigma}, \alpha$ and plane parameters.

**Data Structures:**
*   Primitive: $(\boldsymbol{\mu}, \boldsymbol{\Sigma}, \alpha)$.
*   Camera Local Affine Model: $\mathbf{M} = \mathbf{J}\mathbf{W} \in \mathbb{R}^{2 \times 3}$.
*   Clip Coefficients: Precomputed scalars $\mathbf{k} \in \mathbb{R}^2$ and $h \in \mathbb{R}$ for the current primitive and plane.
*   Variance Floor: $s^2_{\text{impl}} = \max(s^2, 10^{-8})$ [S1, unofficial].

**Steps:**

1.  **Preprocessing (Culling):** Compute the standardized signed distance to the plane $a = \frac{\tau - \mathbf{n}^\top \boldsymbol{\mu}}{\sigma_n}$, where $\sigma_n^2 = \mathbf{n}^\top \boldsymbol{\Sigma} \mathbf{n}$. If $\Phi(a) \le 10^{-6}$, discard the primitive [S1, unofficial].

2.  **Local Affine Projection:** Compute the screen-space covariance $\mathbf{A} = \mathbf{M} \boldsymbol{\Sigma} \mathbf{M}^\top$ and the pixel offset $\boldsymbol{\delta} = \hat{\boldsymbol{p}} - \mathbf{p}$ [S1, unofficial].

3.  **Joint Statistics Computation:** Compute the cross-covariance vector $\mathbf{b} = \mathbf{M} \boldsymbol{\Sigma} \mathbf{n}$ [S1, unofficial].

4.  **Conditional Variance:** Compute the conditional variance $s^2 = \sigma_n^2 - \mathbf{b}^\top \mathbf{A}^{-1} \mathbf{b}$. This is the Schur complement of $\mathbf{A}$ in the joint covariance of $(\omega, \mathbf{u})$ [S1, unofficial].

5.  **Clip Coefficients:** Compute the coefficients for the affine argument of the CDF:
    $$ \mathbf{k} = \mathbf{A}^{-1} \mathbf{b} / s $$
    $$ h = (\tau - \mathbf{n}^\top \boldsymbol{\mu}) / s $$
    [S1, unofficial]

6.  **Clipped Contribution:** Evaluate the clipped per-pixel contribution:
    $$ I_{\text{clip}}(\mathbf{p}) = \alpha \cdot K_G(\boldsymbol{\delta}; \mathbf{A}) \cdot \Phi(\mathbf{k}^\top \boldsymbol{\delta} + h) $$
    where $K_G(\boldsymbol{\delta}; \mathbf{A}) = \exp(-\boldsymbol{\delta}^\top \mathbf{A}^{-1} \boldsymbol{\delta})$ is the Gaussian kernel and $\Phi$ is the standard normal CDF [S1, unofficial].

7.  **Backward Pass:** Compute gradients for $\mathbf{k}$ and $h$ with respect to $\boldsymbol{\mu}, \boldsymbol{\Sigma}$, and plane parameters. Chain these through the conic $\mathbf{A}$ and projection Jacobian. If the variance floor is active ($s^2 < 10^{-8}$), set the derivative through $s^2$ to zero [S1, unofficial].

**Pseudocode:**

```python
import math
import numpy as np

def standard_normal_cdf(x):
    """Approximation of the standard normal CDF Phi(x)."""
    # Using a standard approximation for implementation completeness
    # In practice, use a high-precision library or lookup table
    return 0.5 * (1.0 + math.erf(x / math.sqrt(2.0)))

def exact_half_space_clipping(mu, Sigma, alpha, M, p_hat, p, n, tau):
    """
    Computes the exact half-space clipped contribution of a Gaussian primitive.
    
    Args:
        mu: (3,) Mean of the Gaussian.
        Sigma: (3,3) Covariance of the Gaussian.
        alpha: Float Opacity.
        M: (2,3) Local affine projection matrix (J * W).
        p_hat: (2,) Projected center.
        p: (2,) Pixel coordinate.
        n: (3,) Unit normal of the clipping plane.
        tau: Float Offset of the clipping plane.
        
    Returns:
        clipped_contribution: Float Value to add to the pixel buffer.
    """
    # 1. Preprocessing: Check retained mass
    sigma_n_sq = n.T @ Sigma @ n
    if sigma_n_sq <= 0:
        return 0.0 # Degenerate covariance
    
    a = (tau - n.T @ mu) / math.sqrt(sigma_n_sq)
    if standard_normal_cdf(a) <= 1e-6:
        return 0.0
    
    # 2. Local Affine Projection
    delta = p_hat - p
    A = M @ Sigma @ M.T
    
    # Inverse of A (2x2 matrix)
    det_A = A[0,0]*A[1,1] - A[0,1]*A[1,0]
    if abs(det_A) < 1e-12:
        return 0.0 # Singular covariance projection
    
    inv_A = np.array([[A[1,1], -A[0,1]], 
                      [-A[1,0], A[0,0]]]) / det_A
    
    # 3. Joint Statistics
    b = M @ Sigma @ n
    
    # 4. Conditional Variance (Schur complement)
    s_sq = sigma_n_sq - b.T @ inv_A @ b
    
    # 5. Handle Degenerate Case / Variance Floor
    # If s_sq is effectively zero, the conditional law collapses.
    # The implementation uses a floor to avoid division by zero.
    s_sq_impl = max(s_sq, 1e-8)
    s = math.sqrt(s_sq_impl)
    
    # 6. Clip Coefficients
    # k = A^-1 b / s
    k = (inv_A @ b) / s
    h = (tau - n.T @ mu) / s
    
    # 7. Evaluate Clipped Contribution
    # Gaussian Kernel K_G(delta; A) = exp(-delta^T A^-1 delta)
    exponent = -delta.T @ inv_A @ delta
    K_G = math.exp(exponent)
    
    # CDF argument
    cdf_arg = k.T @ delta + h
    
    # Clipped factor
    clipped_factor = standard_normal_cdf(cdf_arg)
    
    return alpha * K_G * clipped_factor
```

**Edge Cases and Pitfalls:**
*   **Degenerate Variance ($s^2=0$):** Occurs when the clip coordinate $\omega$ is an affine function of the pixel coordinate $\mathbf{u}$ (i.e., the plane contains the viewing-ray direction). The conditional law collapses to a point mass. The implementation handles this with a conditional-variance floor of $10^{-8}$ [S1, unofficial].
*   **Precision:** The CDF evaluation is performed in fp32. Gradients through the variance floor are set to zero [S1, unofficial].
*   **Global Metrics Dilution:** Global image metrics (PSNR/SSIM) dilute errors near the clipping plane. A paired clipped/unclipped cut-face protocol with difference-referenced cut error (CDE) and culled-side leakage (Leak) is recommended for evaluation [S1, unofficial].

### Sharp Feature Rendering via Clip Lines
A technique to render sharp features (edges, corners) in point-sampled surfaces by explicitly representing features as clip lines in local tangent planes, which discard parts of reconstruction kernels to prevent blurring [S2, unofficial]. It computes clip lines by intersecting tangent planes of adjacent kernels, representing them as two homogeneous points projected to image space, and evaluating the kernel only if the point lies on the correct side of the line direction [S2, unofficial]. It ensures pairs of kernels share clip lines to prevent holes. A cutoff value $F_g=0.5$ can be used to emphasize sharp edges [S2, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
*   **Forward Pass:** Requires one scalar fp32 CDF evaluation per straddling sample. Memory overhead is one transient 16-byte per-view buffer per primitive [S1, unofficial].
*   **Backward Pass:** Uses warp-per-splat render backward where each lane accumulates one primitive's full gradient (including three clip coefficients) in registers and issues a single atomic per primitive per tile [S1, unofficial].

**Measured Performance:**
*   On eight CT and MRI volumes with plane offsets not used for training, XClipGS attains the highest PSNR on every volume (33.56 dB versus 32.34 dB for ClipGS) while rendering at over 650 FPS, versus 278 FPS for ClipGS [S1, unofficial].
*   On voxel-axis cut-face views, XClipGS raises average band SSIM from 0.809 to 0.860 and leaks roughly 41× less than ClipGS [S1, unofficial].
*   On an A100 at 800x800 with 300k Gaussians and active oblique clip, the forward-backward step reduces from 5.47 ms to 3.50 ms (1.6x speedup) relative to legacy per-pixel backward [S1, unofficial].
*   XClipGS achieves an 8.3 dB advantage from clipped training views compared to unclipped methods [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Exact integration of restricted density; differentiable for training; no learned clipping parameters or auxiliary networks; fast rendering speed.
*   **Limitations:** Relies on the local affine approximation of the projection; requires careful handling of degenerate cases ($s^2 \approx 0$); global metrics may hide local boundary errors [S1, unofficial].

## Background
XClipGS was introduced by Gao et al. in 2026 as part of the N-DGS backbone for interactive rendering of volumetric medical scans using Gaussian splatting proxies [S1, unofficial]. It addresses the limitations of prior methods like ClipGS (which uses trainable binary decisions and MLP deformation) and RaRa (which scales primitives by chord fraction without backward pass for clip-aware training) by providing an exact, closed-form operator [S1, unofficial]. The method builds on the EWA splatting formulation and uses multi-distance reference views with varied clipping-plane axes and offsets to supervise the interior [S1, unofficial].
