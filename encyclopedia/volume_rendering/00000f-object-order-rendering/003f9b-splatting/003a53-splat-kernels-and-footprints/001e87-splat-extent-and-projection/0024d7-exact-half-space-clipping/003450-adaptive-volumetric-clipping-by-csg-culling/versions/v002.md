# Adaptive Volumetric Clipping by CSG Culling

Also called: CSG Culling, CSG Culling of Shell, CSG Culling of Solid

## Overview
Adaptive Volumetric Clipping by CSG Culling is a hierarchical culling and projection technique for volume Gaussian Splatting that integrates a virtual Constructive Solid Geometry (CSG) probe into the tree traversal process [S1, unofficial]. It solves the problem of rendering sharp volumetric intersections between a Shell (surface) and a Solid (volume) by dynamically adjusting splat resolution and projecting centers to the probe surface, thereby eliminating popping artifacts and silhouette errors that occur with binary keep/drop projections [S1, unofficial]. It sets itself apart from [Exact Half-Space Clipping](3395-exact-half-space-clipping.md) by using hierarchical bounding sphere tests against an implicit probe rather than computing conditional Gaussian CDFs relative to affine-EWA footprints, and from [Camera-independent geometric cut error (CErr3D)](3838-camera-independent-geometric-cut-error-cerr3d.md) by actively modifying splat positions and sizes rather than just estimating error [G].

## How it works
**Inputs and Outputs:**
*   **Input:** A hierarchical tree of Gaussian splats (Shell and Solid nodes), each with a bounding sphere defined by center $c$, radius $r$, and a boundary bit flag. A virtual CSG probe defined by an implicit signed distance function (SDF) $S(x)$, where $S(x) < 0$ is inside, $S(x) > 0$ is outside, and $S(x) = 0$ is the surface. The gradient $\nabla S(x)$ provides the normal vector $n$ [S1, unofficial].
*   **Output:** A set of splats rendered with adaptive resolution and projected centers, forming the CSG intersection of the volume and the probe [G].

**Data Structures:**
*   **Node:** Contains bounding sphere parameters $(c, r)$, a boolean `is_boundary` flag, and child pointers.
*   **Boundary Bit Inheritance:** The `is_boundary` flag of a parent Solid node is the logical OR of the `is_boundary` flags of its children. This ensures that nodes near the intersection curve are marked as boundary nodes, enabling adaptive resolution [S1, unofficial].

**Parameters:**
*   $\delta_r$: Minimum allowed pixel splat size for regular internal nodes.
*   $\delta_b$: Minimum allowed pixel splat size for boundary nodes.
*   Constraint: $\delta_r > \delta_b \sim 1$ pixel. This reduces silhouette appearance along the intersection curve caused by crossing/overlapping splats [S1, unofficial].

**Steps:**

1.  **Probe Evaluation:** For a node with bounding sphere center $c$ and radius $r$, evaluate the SDF $S(c)$ and its gradient $\nabla S(c)$ to determine the signed shortest distance $d$ to the probe surface and the inward-pointing normal $n = -\frac{\nabla S(c)}{\|\nabla S(c)\|}$ [S1, unofficial]. The sign convention defines $d$ as positive inside the probe.
2.  **CSG Culling of Solid:** If the bounding sphere does not intersect the probe surface, discard the node and its subtree. If it intersects, traverse the subtree until the splat size reaches the minimum allowed size for the node type. Boundary nodes render at $\delta_b$, while regular internal nodes render at $\delta_r$ [S1, unofficial]. For all rendered Solid splats intersecting the probe, project the center to the probe surface using $c_{\text{new}} = c - d \cdot n$ to prevent popping effects when resolution changes [S1, unofficial].
3.  **CSG Culling of Shell:** If the bounding sphere is completely inside the probe, do not render the node or its children. If completely outside, disable CSG culling for the branch and render children only if they are leaf nodes or have splat size $\le \delta_r$. If the bounding sphere intersects the probe surface, render the node if it is a leaf node or splat size $\le \delta_b$; otherwise, traverse with CSG culling enabled [S1, unofficial]. For boundary nodes intersecting the probe, offset the sphere center before rendering using $c_{\text{new}} = c - (r + d) \cdot n$ to improve the outline and reduce silhouettes [S1, unofficial].

**Pseudocode:**

```python
def render_solid(node, probe_sdf, delta_r, delta_b):
    c, r = node.center, node.radius
    grad = probe_sdf.gradient(c)
    n = -grad / norm(grad)  # Inward normal
    d = probe_sdf.value(c)  # Signed distance (positive inside)
    if d > r or d < -r:
        return  # Discard if sphere does not intersect probe surface
    min_size = delta_b if node.is_boundary else delta_r
    if node.splat_size <= min_size:
        c_proj = c - d * n  # Project center to probe surface
        # Standard Gaussian splat rasterization at c_proj
        return
    for child in node.children:
        render_solid(child, probe_sdf, delta_r, delta_b)

def render_shell(node, probe_sdf, delta_r, delta_b):
    c, r = node.center, node.radius
    grad = probe_sdf.gradient(c)
    n = -grad / norm(grad)  # Inward normal
    d = probe_sdf.value(c)  # Signed distance (positive inside)
    if d > r:
        return  # Completely inside probe: do not render
    if d < -r:
        # Completely outside: disable CSG culling, render only if leaf or small enough
        if node.is_leaf or node.splat_size <= delta_r:
            # Standard Gaussian splat rasterization at c
            pass
        return
    # Intersecting probe surface
    if node.is_leaf or node.splat_size <= delta_b:
        c_proj = c - (r + d) * n  # Offset center for boundary nodes
        # Standard Gaussian splat rasterization at c_proj
        return
    for child in node.children:
        render_shell(child, probe_sdf, delta_r, delta_b)
```

## Operating characteristics
*   **Time Complexity:** Linear in the number of visited nodes. Hierarchical culling reduces the number of splats processed near the intersection curve, and the overhead is described as insignificant because few Solid spheres lie exactly on the intersection curve [S1, unofficial].
*   **Memory Complexity:** No additional memory beyond the existing tree structure and SDF evaluation stack [G].
*   **Strengths:** Maintains real-time performance while providing smooth adaptive resolution at the CSG intersection, reducing popping and silhouette artifacts [S1, unofficial]. Works with any implicit probe (plane, sphere, box, custom SDF) [S1, unofficial].
*   **Limitations:** Requires efficient SDF and gradient evaluation. Visual quality depends on the choice of $\delta_r$ and $\delta_b$ [S1, unofficial].
*   **When to use:** Real-time medical visualization requiring sharp volumetric clipping and high fidelity at cut boundaries [S1, unofficial].
*   **When not to use:** When the probe cannot be efficiently evaluated as an SDF, or when sharp volumetric clipping is not required [G].

## Background
The method was introduced in the paper "TetSplat: Real-time Rendering and Volume Clipping of Large..." presented at the VIS 2004 conference [S1, unofficial]. It was developed to address the limitations of binary clipping in Gaussian Splatting, aiming to maintain interactive frame rates while achieving high-quality volumetric editing and clipping [S1, unofficial].
