# Edge-Preserving Splatting with Compression/Stretching

Also called: C1 Continuous Splatting, Edge-Enhanced Splatting

## Overview
Edge-Preserving Splatting is a volume rendering technique that sharpens discontinuities in low-resolution or undersampled data by applying non-linear compression and stretching functions to standard splatting kernels [S1]. Unlike conventional splatting, which produces smooth, blurred edges, this method ensures C1 continuity (continuous first derivative) across splat boundaries while enhancing the visual definition of iso-surfaces [S1]. It distinguishes itself from sibling methods like [EWA Splatting](1069-ewa-splatting.md) by explicitly modeling edge geometry (direction and strength) to drive view-dependent footprint selection, rather than relying solely on geometric projection [S1].

## How it works
The method modifies the footprint function of a splat based on the local edge characteristics of the voxel [S1]. It requires precomputed edge information and uses a lookup table of pre-rendered splat footprints to achieve interactive performance [S1].

### Inputs and Outputs
*   **Inputs:**
    *   Volume data $V$ [S1].
    *   Iso-contour value $C$ used for edge detection [S1].
    *   View direction $\mathbf{v}$ [S1].
    *   Precomputed table of splat footprints indexed by edge position and strength [S1].
*   **Outputs:**
    *   Final 2D image with enhanced edge sharpness [S1].

### Data Structures
1.  **Voxel Attributes:** For each voxel $i$, store:
    *   Value $V_i$ [S1].
    *   Gradient $\nabla V_i = (\frac{\partial V}{\partial x}, \frac{\partial V}{\partial y}, \frac{\partial V}{\partial z})$ estimated via central differences [S1].
    *   Edge position $p_i$: The normalized distance from the voxel center to the iso-surface along the gradient direction [S1]. Calculated as $p_i = \frac{C - V_i}{|\nabla V_i|}$, with practical estimation using trilinear interpolation [S1].
    *   Normalized edge direction $\mathbf{d}_i = \frac{\nabla V_i}{|\nabla V_i|}$ [S1].
2.  **Footprint Table:** A texture or memory array storing 2D footprint functions $F_{edge\_pos, strength}(x,y)$ precomputed for various combinations of edge position and projected edge strength [S1].

### Parameters
*   **Iso-contour value $C$:** Threshold for edge detection [S1]. In the Sinus Cavity dataset, a binary threshold at 128 was used after low-pass filtering [S1]. In the Hipip dataset, thresholds at 0.0017 and 0.5 were used [S1].
*   **Edge Strength:** Derived from the projected length of the edge direction onto the viewing plane [S1].
*   **Kernel Type:** The base kernel $g(x,y)$ represents the standard splatting footprint [S1].

### Steps

1.  **Preprocessing (Offline/Setup):**
    1.  Compute gradients $\nabla V_i$ for all voxels using central differences [S1].
    2.  Compute edge position $p_i$ and normalized edge direction $\mathbf{d}_i$ for voxels near the iso-surface $C$ [S1].
    3.  Define the compression/stretching mapping function $map(x)$ [S1]. The source defines its properties but not an explicit analytical formula:
        *   It maps the spatial domain to modify the footprint [S1].
        *   It has a first derivative $map'(x) = 1$ at the boundaries $x=0$ and $x=1$ to ensure C1 continuity [S1].
        *   It creates asymmetric compression/stretching profiles based on edge strength [S1].
    4.  Precompute splat footprints for various edge positions and strengths using the mapping function and store them in texture memory [S1].

2.  **Rendering (Per Frame):**
    1.  For each voxel $i$ in the volume:
        a.  **Edge Classification:** Determine if the voxel is a "primary" or "secondary" kernel [S1].
            *   If $V_i > C$, it is classified as primary; if $V_i < C$, it is secondary [S1]. The source states that "primary and secondary kernels with larger or lower data value are specified for each splat" and the mapping must be consistent [S1].
        b.  **View-Dependent Projection:**
            *   Project the normalized edge direction $\mathbf{d}_i$ onto the viewing plane perpendicular to $\mathbf{v}$ [S1].
            *   If $\mathbf{d}_i$ is parallel to $\mathbf{v}$, the edge is imperceptible; treat as a standard splat or skip edge enhancement [S1].
            *   Calculate the projected edge length/strength from the projected direction [S1].
        c.  **Footprint Selection:**
            *   Use the projected edge position and strength to index into the precomputed footprint table [S1].
            *   Select the corresponding 2D footprint $F_{selected}(x,y)$ [S1].
        d.  **Rasterization:**
            *   Transform the voxel to screen space [S1].
            *   Rasterize the selected footprint $F_{selected}$ onto the image plane [S1].
    2.  **Compositing:**
        *   Accumulate the splats using standard alpha blending (back-to-front or front-to-back) [S1, see Parent].
    3.  **Lighting (Optional):**
        *   Apply view-dependent light source shading *only* to voxels labeled as primary or secondary edge splats [S1].

### Formulas

**C1 Continuity Condition:**
To ensure the first derivative is continuous across splat boundaries, the mapping function $rmap(x)$ (a shifted version of $map(x)$) must satisfy:
$$ rmap'(x) = 1 \quad \text{at} \quad x=0 \quad \text{and} \quad x=1 $$
The derivative of the modified kernel $h$ with respect to the original kernel $g$ is:
$$ h_x'(rmap(x)) = g_x'(rmap(x)) \cdot rmap'(x) $$
Since $rmap'(x) = 1$ at the boundaries:
$$ h_x'(rmap(x)) = g_x'(rmap(x)) $$
This ensures the slope of the enhanced kernel matches the slope of the original kernel at the join points, preserving C1 continuity [S1].

**Edge Position Estimation:**
$$ p = \frac{C - V_i}{|\nabla V_i|} $$
Where $C$ is the contour value and $\nabla V_i$ is the gradient [S1].

import math

def preprocess_volume(volume_data, contour_value):
    """
    Computes edge attributes for each voxel.
    """
    edge_attributes = {}
    # Compute gradients using central differences [S1]
    gradients = {}
    for voxel in volume_data:
        gx = (volume_data.get(voxel + (1,0,0), 0) - volume_data.get(voxel + (-1,0,0), 0)) / 2.0
        gy = (volume_data.get(voxel + (0,1,0), 0) - volume_data.get(voxel + (0,-1,0), 0)) / 2.0
        gz = (volume_data.get(voxel + (0,0,1), 0) - volume_data.get(voxel + (0,0,-1), 0)) / 2.0
        gradients[voxel] = (gx, gy, gz)

    for voxel, grad in gradients.items():
        val = volume_data[voxel]
        # Skip voxels far from the contour [G]
        if abs(val - contour_value) > 1.0:
            continue
        # Edge position estimation via trilinear interpolation [S1]
        # Simplified analytical form based on source description:
        grad_norm = math.sqrt(grad[0]**2 + grad[1]**2 + grad[2]**2)
        if grad_norm == 0:
            continue
        dist = (contour_value - val) / grad_norm
        # Normalized edge direction [S1]
        dir_norm = (grad[0]/grad_norm, grad[1]/grad_norm, grad[2]/grad_norm)
        # Classify as primary or secondary based on value relative to contour [S1]
        is_primary = val > contour_value 
        edge_attributes[voxel] = {
            'position': dist,
            'direction': dir_norm,
            'is_primary': is_primary
        }
    return edge_attributes

def render_frame(volume_data, edge_attributes, view_direction, footprint_table):
    """
    Renders the volume using edge-preserving splatting.
    """
    # Initialize output image [G]
    image = {}
    # Sort voxels back-to-front for correct alpha blending [G]
    sorted_voxels = sorted(volume_data.keys(), key=lambda v: dot(v, view_direction), reverse=True)
    
    for voxel in sorted_voxels:
        attrs = edge_attributes.get(voxel)
        
        # If no edge info, use standard splat [G]
        if attrs is None:
            rasterize_standard_splat(voxel, image)
            continue
            
        # View-dependent edge processing
        edge_dir = attrs['direction']
        
        # Check if edge is parallel to view (imperceptible) [S1]
        if abs(dot(edge_dir, view_direction)) > 0.99:
            rasterize_standard_splat(voxel, image)
            continue
            
        # Project edge direction onto viewing plane [S1]
        proj_edge_dir = (
            edge_dir[0] - dot(edge_dir, view_direction) * view_direction[0],
            edge_dir[1] - dot(edge_dir, view_direction) * view_direction[1],
            edge_dir[2] - dot(edge_dir, view_direction) * view_direction[2]
        )
        proj_len = math.sqrt(proj_edge_dir[0]**2 + proj_edge_dir[1]**2 + proj_edge_dir[2]**2)
        
        # Determine edge strength from projected length [S1]
        strength = proj_len
        
        # Select footprint from precomputed table [S1]
        footprint = footprint_table.lookup(attrs['position'], strength)
        
        # Rasterize the footprint [S1]
        rasterize_footprint(voxel, footprint, image)
        
        # Apply lighting only to primary/secondary edge splats [S1]
        if attrs['is_primary']:
            apply_lighting(voxel, view_direction, image)
            
    return image

### Edge Cases and Pitfalls
*   **Parallel Edge Direction:** If the viewing direction is parallel to the edge direction, the edge is imperceptible [S1]. The method skips special treatment for these voxels [S1].
*   **Undersampled Structures:** Small structures protruding into cavities are often undersampled due to high-frequency components in digitized data [S1]. This makes edge preservation challenging and may require adaptive multivariate representations or mixing datasets of different resolutions (e.g., 8-Tesla and 1.5-Tesla MRI) [S1].
*   **Edge Detection Accuracy:** The method requires fairly accurate edge detection [S1]. Iso-contouring produces sharp discontinuities, allowing good estimates of edge direction and contour distance [S1]. For experimental data (CT/MRI), advanced edge detection or segmentation is indispensable [S1].
*   **Asymmetry:** The compression/stretching function is not symmetric [S1]. The definition of "primary" vs "secondary" (based on data value being larger or lower than the threshold) must be consistent throughout the application [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is $O(N)$ where $N$ is the number of voxels, assuming constant-time footprint lookup and rasterization [S1]. The preprocessing step is also $O(N)$ for gradient and edge attribute computation [S1].
*   **Memory Complexity:** Requires storage for the volume data, edge attributes (gradient, position, direction per voxel), and the precomputed footprint table [S1]. The footprint table size depends on the discretization of edge position and strength [S1].
*   **Performance:** Enables interactive rendering by precomputing splats and loading them into texture memory [S1].
*   **Strengths:** Produces much sharper decreasing regions and nice sharp edges, especially visible in low-resolution or undersampled data, compared to conventional splatting [S1]. Enhances details on sidewalls and coarse resolution cross-sections [S1].
*   **Limitations:** Requires accurate edge detection and additional per-voxel data (gradient, direction) [S1]. Does not handle high-frequency undersampled structures well without additional techniques like adaptive representations [S1].

## Background
*   **Origin:** The method was introduced in the paper "Edge Preservation in Volume Rendering Using Splatting" [S1].
*   **History:** It was applied to the Sinus Cavity dataset (derived from the Visible Human dataset) and the Hipip (HIgh Potential Iron Protein) dataset [S1]. The Sinus Cavity application involved virtual navigation to enhance sidewall details [S1]. The Hipip dataset was used to enhance details in protein structures [S1].
*   **Development:** The method builds on standard splatting principles but adds a layer of edge-aware footprint selection [S1]. It differs from previous work by requiring more information than simple binary classification, specifically edge direction and strength for view-dependent processing [S1].
