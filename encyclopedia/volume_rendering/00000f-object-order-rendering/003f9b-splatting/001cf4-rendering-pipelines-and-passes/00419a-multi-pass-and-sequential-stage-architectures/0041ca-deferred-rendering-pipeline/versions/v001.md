# Deferred Rendering Pipeline

Also called: 8-Pass Deferred Rendering Pipeline

## Overview
A multi-pass deferred rendering sequence that computes depth, position/normal, materials, filtered normals, shadows, SSAO, blurred AO, and final shading in separate framebuffer objects [S1, unofficial]. It differs from the [Volume Rendering Pipeline](1318-volume-rendering-pipeline.md) by decoupling geometry traversal from shading, and from the [Fragment List-Based Rendering Pipeline](3488-fragment-list-based-rendering-pipeline.md) by using screen-space quad passes for post-processing effects rather than fragment lists [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Scene geometry (OctreeDDARenderer), camera matrices (`viewMat`, `projMat`, `viewMatInv`, `projMatInv`), light position, material parameters, and boolean flags (`_useMaterials`, `_filterNormals`, `_doShadows`, `_doSSAO`).
*   **Outputs:** Final shaded image on the default framebuffer.

**Data Structures:**
*   **Framebuffers:** `_glFBO[0]` through `_glFBO[6]` are used sequentially [S1, unofficial].
*   **Textures:** Bound to texture units `TEX_NUM_*` during `resetState()` [S1, unofficial]:
    *   `_glTexDepth`: Depth buffer.
    *   `_glTexHitPos`: Hit position (G-Buffer).
    *   `_glTexHitNorm`: Hit normal (G-Buffer).
    *   `_glTexHitMaterial`: Material properties (G-Buffer).
    *   `_glTexHitNormFiltered`: Filtered normals.
    *   `_glTexShadows`: Shadow map/occlusion data.
    *   `_glTexAO`: Ambient Occlusion values.
    *   `_glTexAOBlurred`: Blurred AO values.
    *   `_glTexAONoise`: Noise texture for AO.
    *   `_glTexTBOMaterials`: Texture/Bump map materials.

**Numbered Steps:**
1.  **Pass 1 (Depth):** Bind `_glFBO[0]`, clear, set `OctreeDDARenderer` mode to `DEPTH`, draw scene.
2.  **Pass 2 (Position/Normal):** Bind `_glFBO[1]`, clear, use `_programPosNorm`, set uniforms `viewMatInv`, `projMatInv`, `useDif`, draw full-screen quad.
3.  **Pass 3 (Materials):** If `_useMaterials` is true: Bind `_glFBO[2]`, clear, use `_programMaterial`, set uniforms, draw full-screen quad.
4.  **Pass 4 (Normal Filtering):** If `_filterNormals` is true: Bind `_glFBO[3]`, clear, use `_programNormFilter`, set uniforms `sigma`, `bsigma`, draw full-screen quad.
5.  **Pass 5 (Shadows):** If `_doShadows` is true: Bind `_glFBO[4]`, clear, set `lightPos`, set `OctreeDDARenderer` mode to `SHADOW`, draw scene. Else, clear `_glFBO[4]` to white (1.0) [S1, unofficial].
6.  **Pass 6 (SSAO):** If `_doSSAO` is true: Bind `_glFBO[5]`, clear, use `_programSSAO`, set uniforms `projMat`, `viewMat`, `camPos`, `radius`, draw full-screen quad.
7.  **Pass 7 (AO Blur):** Bind `_glFBO[6]`, clear, use `_programBlur`, draw full-screen quad.
8.  **Pass 8 (Final Shading):** Bind default framebuffer, clear, use `_programShading`, set uniforms `isYUp`, `camPos`, `projMatInv`, `viewMatInv`, `lightPos`, `renderMode`, `useMaterials`, draw full-screen quad.

**Parameters:**
*   `sigma`, `bsigma`: Gaussian filter parameters for normal filtering [S1, unofficial].
*   `radius`: SSAO sampling radius [S1, unofficial].

**Edge Cases and Pitfalls:**
*   When shadows are disabled, Pass 5 clears to white (1.0), acting as a default fully lit state [S1, unofficial].
*   The original octree-based AO path is disabled in favor of the screen-space quad pass (wrapped in `#if 0/#else`) [S1, unofficial].
