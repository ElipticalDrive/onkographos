# Deferred Rendering Pipeline
Also called: 8-Pass Deferred Rendering Pipeline
## Overview
The Deferred Rendering Pipeline is a multi-pass sequence that decouples geometry traversal from shading by rendering scene data (depth, position, normals, materials) into intermediate framebuffers before performing final lighting calculations [S1, unofficial]. It differs from the [Volume Rendering Pipeline](1318-volume-rendering-pipeline.md) by explicitly separating the construction of the G-buffer from the evaluation of lighting effects, and from the [Fragment List-Based Rendering Pipeline](3488-fragment-list-based-rendering-pipeline.md) by relying on screen-space quad passes for post-processing effects rather than in-memory fragment lists [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** An octree-based volume representation (specifically SVDAG4 or DAG4 variants), camera matrices (view, projection, inverse), light positions, and configuration flags for materials, normal filtering, shadows, and SSAO [S1, unofficial].
*   **Output:** A final shaded image rendered to the default framebuffer [S1, unofficial].

**Data Structures:**
The pipeline uses a sequence of Framebuffer Objects (FBOs) `_glFBO[0]` through `_glFBO[6]` and associated textures bound to texture units `TEX_NUM_*` [S1, unofficial]. The specific textures include:
*   `_glTexDepth`: Depth buffer.
*   `_glTexHitPos`: Hit position buffer.
*   `_glTexHitNorm`: Hit normal buffer.
*   `_glTexHitMaterial`: Material properties buffer.
*   `_glTexHitNormFiltered`: Filtered normal buffer.
*   `_glTexShadows`: Shadow map buffer.
*   `_glTexAO`: Ambient Occlusion buffer.
*   `_glTexAOBlurred`: Blurred AO buffer.
*   `_glTexAONoise`: Noise texture for AO.
*   `_glTexTBOMaterials`: Texture-based material buffer [S1, unofficial].

**Steps:**
1.  **Depth Pass:** Bind `_glFBO[0]`. Clear the buffer. Set the renderer mode to `DEPTH`. Draw the scene using `OctreeDDARenderer` [S1, unofficial].
2.  **Position/Normal Pass:** Bind `_glFBO[1]`. Clear the buffer. Use shader program `_programPosNorm`. Set uniforms `viewMatInv`, `projMatInv`, and `useDif`. Draw a full-screen quad [S1, unofficial].
3.  **Material Pass (Conditional):** If `_useMaterials` is true: Bind `_glFBO[2]`. Clear the buffer. Use shader program `_programMaterial`. Set relevant uniforms. Draw a full-screen quad [S1, unofficial].
4.  **Normal Filtering Pass (Conditional):** If `_filterNormals` is true: Bind `_glFBO[3]`. Clear the buffer. Use shader program `_programNormFilter`. Set uniforms `sigma` and `bsigma`. Draw a full-screen quad [S1, unofficial].
5.  **Shadow Pass (Conditional):** If `_doShadows` is true: Bind `_glFBO[4]`. Clear the buffer. Set `lightPos`. Set `OctreeDDARenderer` mode to `SHADOW`. Draw the scene [S1, unofficial]. Else: Clear `_glFBO[4]` to white (1.0), representing a fully lit state [S1, unofficial].
6.  **SSAO Pass (Conditional):** If `_doSSAO` is true: Bind `_glFBO[5]`. Clear the buffer. Use shader program `_programSSAO`. Set uniforms `projMat`, `viewMat`, `camPos`, and `radius`. Draw a full-screen quad [S1, unofficial]. Note: The original octree-based AO path is disabled (`#if 0`) in favor of this screen-space pass [S1, unofficial].
7.  **AO Blur Pass:** Bind `_glFBO[6]`. Clear the buffer. Use shader program `_programBlur`. Draw a full-screen quad [S1, unofficial].
8.  **Final Shading Pass:** Bind the default framebuffer. Clear the buffer. Use shader program `_programShading`. Set uniforms `isYUp`, `camPos`, `projMatInv`, `viewMatInv`, `lightPos`, `renderMode`, and `useMaterials`. Draw a full-screen quad [S1, unofficial].

**Pseudocode:**
```python
def deferred_rendering_pipeline(scene, camera, lights, config):
    # 1. Depth Pass
    bind_fbo(_glFBO[0])
    clear()
    set_renderer_mode(OctreeDDARenderer, DEPTH)
    draw_scene(scene)

    # 2. Position/Normal Pass
    bind_fbo(_glFBO[1])
    clear()
    use_program(_programPosNorm)
    set_uniform("viewMatInv", camera.inv_view_matrix)
    set_uniform("projMatInv", camera.inv_proj_matrix)
    set_uniform("useDif", True) # Assuming default diffuse
    draw_quad()

    # 3. Material Pass
    if config.use_materials:
        bind_fbo(_glFBO[2])
        clear()
        use_program(_programMaterial)
        set_uniforms_for_materials()
        draw_quad()

    # 4. Normal Filtering Pass
    if config.filter_normals:
        bind_fbo(_glFBO[3])
        clear()
        use_program(_programNormFilter)
        set_uniform("sigma", 1.0) # Typical value
        set_uniform("bsigma", 0.5) # Typical value
        draw_quad()

    # 5. Shadow Pass
    if config.do_shadows:
        bind_fbo(_glFBO[4])
        clear()
        set_uniform("lightPos", lights[0].position)
        set_renderer_mode(OctreeDDARenderer, SHADOW)
        draw_scene(scene)
    else:
        bind_fbo(_glFBO[4])
        clear_to_white() # Default fully lit state

    # 6. SSAO Pass
    if config.do_ssao:
        bind_fbo(_glFBO[5])
        clear()
        use_program(_programSSAO)
        set_uniform("projMat", camera.proj_matrix)
        set_uniform("viewMat", camera.view_matrix)
        set_uniform("camPos", camera.position)
        set_uniform("radius", 1.0) # Typical radius
        draw_quad()

    # 7. AO Blur Pass
    bind_fbo(_glFBO[6])
    clear()
    use_program(_programBlur)
    draw_quad()

    # 8. Final Shading Pass
    bind_default_fbo()
    clear()
    use_program(_programShading)
    set_uniform("isYUp", True)
    set_uniform("camPos", camera.position)
    set_uniform("projMatInv", camera.inv_proj_matrix)
    set_uniform("viewMatInv", camera.inv_view_matrix)
    set_uniform("lightPos", lights[0].position)
    set_uniform("renderMode", FINAL)
    set_uniform("useMaterials", config.use_materials)
    draw_quad()
```

**Parameters:**
*   `sigma`, `bsigma`: Gaussian filter parameters for normal filtering. Typical values are not explicitly defined in the sources, but `sigma` is passed to `_programNormFilter` [S1, unofficial].
*   `radius`: SSAO sampling radius. Passed to `_programSSAO` [S1, unofficial].

**Edge Cases and Pitfalls:**
*   When shadows are disabled, the shadow buffer is cleared to white (1.0). This acts as a default fully lit state, which must be handled correctly in the final shading pass to avoid darkening the scene [S1, unofficial].
*   The SSAO pass replaces an older octree-based AO path (`#if 0`), meaning the pipeline relies entirely on screen-space techniques for ambient occlusion [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
The pipeline executes a fixed sequence of 8 passes. Each pass involves a draw call (either scene traversal or full-screen quad). Memory usage is proportional to the number of intermediate textures (G-buffer), which scales with screen resolution [S1, unofficial].

**Measured Performance:**
Not given in the sources.

**Scaling:**
Performance scales with screen resolution due to the fixed number of passes and the cost of screen-space operations (blurring, SSAO) [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Decouples geometry complexity from shading complexity; allows for flexible post-processing effects (SSAO, blurring) [S1, unofficial].
*   **Limitations:** Requires multiple render passes; potential for aliasing in screen-space effects; increased memory bandwidth usage due to G-buffer [S1, unofficial].

**When to use it and when not:**
Use when flexible lighting and post-processing are required, and the scene geometry is complex but the number of lights is manageable. Not ideal for real-time applications with strict memory bandwidth constraints or when dynamic geometry changes every frame significantly [S1, unofficial].

## Background
The Deferred Rendering Pipeline, specifically the 8-pass variant described, originates from the `ssvdag` project by ajaspe [S1, unofficial]. It is designed for rendering sparse voxel octrees (SVDAG4/DAG4) and integrates depth, position, normal, material, shadow, and ambient occlusion computations into a deferred sequence [S1, unofficial].
