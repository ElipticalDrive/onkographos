# GSplat Skinning Data Loading

Also called: GsplatSkinMatrix, Skinning via StructuredBuffers, Skinning via Textures

## Overview
This method computes the final transformation matrix for a splat by blending up to four bone matrices weighted by skin weights, then applying a reference inverse transform [S1, unofficial]. It supports two storage backends: Texture2D arrays for GPU compatibility and portability, or StructuredBuffers for direct access [S1, unofficial]. It enables skeletal animation of Gaussian splats by transforming their position, covariance, and optionally surface normal [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   `sourceId`: The unique identifier for the splat (uint) [S1, unofficial].
*   `modelCenter`: The splat's center position in model space (float3) [S1, unofficial].
*   `covariance`: The splat's covariance matrix, stored as two components `covA` and `covB` (float3) [S1, unofficial].
*   `modelNormal`: (Optional) The splat's surface normal in model space (float3) [S1, unofficial].
*   `_GsplatSkinningEnabled`: A global integer flag (0 or 1) indicating if skinning is active [S1, unofficial].

**Outputs:**
*   `transformedCenter`: The skinned position (float3) [S1, unofficial].
*   `transformedCovariance`: The skinned covariance components `covA` and `covB` (float3) [S1, unofficial].
*   `transformedNormal`: (Optional) The skinned normal (float3) [S1, unofficial].

### Data Structures
The method uses one of two storage backends [S1, unofficial].

**Texture2D Backend:**
*   `_GsplatSkinIndexTexture`: `Texture2D<float4>` storing bone indices [S1, unofficial].
*   `_GsplatSkinWeightTexture`: `Texture2D<float4>` storing bone weights [S1, unofficial].
*   `_GsplatSkinReferenceTexture`: `Texture2D<float4>` storing reference inverse matrices [S1, unofficial].
*   `_GsplatSkinBoneTexture`: `Texture2D<float4>` storing bone matrices [S1, unofficial].
*   Widths are stored in `_GsplatSkinIndexTextureWidth`, `_GsplatSkinWeightTextureWidth`, `_GsplatSkinReferenceTextureWidth`, and `_GsplatSkinBoneTextureWidth` [S1, unofficial].

**StructuredBuffer Backend:**
*   `_GsplatSkinWeights`: `StructuredBuffer<GsplatSkinWeight>` [S1, unofficial].
*   `_GsplatSkinReferenceRows`: `StructuredBuffer<float4>` [S1, unofficial].
*   `_GsplatSkinBoneRows`: `StructuredBuffer<float4>` [S1, unofficial].
*   `GsplatSkinWeight` contains `boneIndices` (`uint4`) and `boneWeights` (`float4`) [S1, unofficial].

### Coordinate Mapping (Texture2D Backend)
When using textures, linear indices must be converted to 2D coordinates [S1, unofficial]:
$$
\text{coord} = \left( \text{index} \pmod{\text{width}}, \left\lfloor \frac{\text{index}}{\text{width}} \right\rfloor \right)
$$
where `width` is the specific texture's width [S1, unofficial].

### Algorithm Steps
1.  **Check Enable Flag:** If `_GsplatSkinningEnabled` is 0, return inputs unchanged [S1, unofficial].
2.  **Load Skin Data:** Calculate `indexOffset = sourceId * 4` [S1, unofficial]. Load four texels from `_GsplatSkinIndexTexture` at `indexOffset` through `indexOffset + 3` [S1, unofficial]. Decode each texel's uint value using `GsplatDecodeTextureUInt` to form `skin.boneIndices` (`uint4`) [S1, unofficial]. Load one texel from `_GsplatSkinWeightTexture` at `sourceId` to form `skin.boneWeights` (`float4`) [S1, unofficial].
3.  **Compute Skin Matrix:** Initialize `currentMatrix` as zero [S1, unofficial]. For each of the four bones (x, y, z, w), load its bone matrix and multiply by the corresponding bone weight [S1, unofficial]. Sum these four weighted matrices [S1, unofficial]. Load the reference inverse matrix and multiply the result by it [S1, unofficial].
4.  **Transform Position:** Transform `modelCenter` by multiplying the skin matrix with `float4(modelCenter, 1.0)` and taking the xyz component [S1, unofficial].
5.  **Transform Covariance:** Extract the deformation matrix (`float3x3`) from the first three rows of the skin matrix [S1, unofficial]. Transform the covariance using the formula `deformed = transform * source * transpose(transform)`, where `source` is the 3x3 covariance matrix reconstructed from `covA` and `covB`, and `transform` is the 3x3 deformation matrix [S1, unofficial].
6.  **Transform Normal (Optional):** Transform `modelNormal` by multiplying the deformation matrix with `modelNormal`, then normalize the result [S1, unofficial]. This avoids per-vertex matrix inverse [S1, unofficial].

### Formula
The deformed covariance is computed as:
$$
C_{\text{def}} = D \times C_{\text{src}} \times D^T
$$
where $C_{\text{src}}$ is the 3×3 covariance matrix reconstructed from `covA` and `covB`, and $D$ is the 3×3 deformation matrix [S1, unofficial]. The result is packed back into `covA` and `covB` such that `covA` contains $C_{\text{def}}[0][0..2]$ and `covB` contains $C_{\text{def}}[1][1..2]$ and $C_{\text{def}}[2][2]$ [S1, unofficial].

### Pseudocode
```python
def GsplatSkinTextureCoord(index, width):
    return (index % width, index // width)

def GsplatDecodeTextureUInt(texel):
    # Extracts the bone index from a float4 texel
    return int(texel[0])

def ReconstructCovariance3x3(covA, covB):
    # Reconstructs symmetric 3x3 matrix from packed components
    return [
        [covA[0], covA[1], covA[2]],
        [covA[1], covB[0], covB[1]],
        [covA[2], covB[1], covB[2]]
    ]

def ExtractCovarianceComponents(matrix):
    # Packs symmetric 3x3 matrix back into covA and covB
    covA = [matrix[0][0], matrix[0][1], matrix[0][2]]
    covB = [matrix[1][1], matrix[1][2], matrix[2][2]]
    return covA, covB

def GsplatLoadSkinWeight(source_id):
    index_offset = source_id * 4
    bone_indices = [
        GsplatDecodeTextureUInt(_GsplatSkinIndexTexture[GsplatSkinTextureCoord(index_offset, _GsplatSkinIndexTextureWidth)]),
        GsplatDecodeTextureUInt(_GsplatSkinIndexTexture[GsplatSkinTextureCoord(index_offset + 1, _GsplatSkinIndexTextureWidth)]),
        GsplatDecodeTextureUInt(_GsplatSkinIndexTexture[GsplatSkinTextureCoord(index_offset + 2, _GsplatSkinIndexTextureWidth)]),
        GsplatDecodeTextureUInt(_GsplatSkinIndexTexture[GsplatSkinTextureCoord(index_offset + 3, _GsplatSkinIndexTextureWidth)])
    ]
    bone_weights = _GsplatSkinWeightTexture[GsplatSkinTextureCoord(source_id, _GsplatSkinWeightTextureWidth)]
    return {"boneIndices": bone_indices, "boneWeights": bone_weights}

def GsplatLoadBoneMatrix(bone_index):
    matrix_offset = bone_index * 4
    row0 = _GsplatSkinBoneTexture[GsplatSkinTextureCoord(matrix_offset, _GsplatSkinBoneTextureWidth)]
    row1 = _GsplatSkinBoneTexture[GsplatSkinTextureCoord(matrix_offset + 1, _GsplatSkinBoneTextureWidth)]
    row2 = _GsplatSkinBoneTexture[GsplatSkinTextureCoord(matrix_offset + 2, _GsplatSkinBoneTextureWidth)]
    row3 = _GsplatSkinBoneTexture[GsplatSkinTextureCoord(matrix_offset + 3, _GsplatSkinBoneTextureWidth)]
    return [row0, row1, row2, row3]

def GsplatLoadReferenceInverse(source_id):
    matrix_offset = source_id * 3
    row0 = _GsplatSkinReferenceTexture[GsplatSkinTextureCoord(matrix_offset, _GsplatSkinReferenceTextureWidth)]
    row1 = _GsplatSkinReferenceTexture[GsplatSkinTextureCoord(matrix_offset + 1, _GsplatSkinReferenceTextureWidth)]
    row2 = _GsplatSkinReferenceTexture[GsplatSkinTextureCoord(matrix_offset + 2, _GsplatSkinReferenceTextureWidth)]
    row3 = [0.0, 0.0, 0.0, 1.0]
    return [row0, row1, row2, row3]

def GsplatSkinMatrix(source_id):
    skin_data = GsplatLoadSkinWeight(source_id)
    current_matrix = [[0.0]*4 for _ in range(4)]
    for i in range(4):
        bone_idx = skin_data["boneIndices"][i]
        bone_weight = skin_data["boneWeights"][i]
        bone_matrix = GsplatLoadBoneMatrix(bone_idx)
        for r in range(4):
            for c in range(4):
                current_matrix[r][c] += bone_weight * bone_matrix[r][c]
    ref_inverse = GsplatLoadReferenceInverse(source_id)
    # Matrix multiplication: ref_inverse @ current_matrix
    skin_matrix = [[sum(ref_inverse[r][k] * current_matrix[k][c] for k in range(4)) for c in range(4)] for r in range(4)]
    return skin_matrix

def GsplatTransformCovariance(covariance, transform_3x3):
    covA, covB = covariance
    source = ReconstructCovariance3x3(covA, covB)
    # deformed = transform @ source @ transpose(transform)
    transposed_transform = [[transform_3x3[r][c] for r in range(3)] for c in range(3)]
    temp = [[sum(transform_3x3[r][k] * source[k][c] for k in range(3)) for c in range(3)] for r in range(3)]
    deformed = [[sum(temp[r][k] * transposed_transform[k][c] for k in range(3)) for c in range(3)] for r in range(3)]
    return ExtractCovarianceComponents(deformed)

def ApplySkinning(model_center, covariance, model_normal, source_id):
    if _GsplatSkinningEnabled == 0:
        return model_center, covariance, model_normal
    skin_matrix = GsplatSkinMatrix(source_id)
    # Transform Position
    pos_homogeneous = [model_center[0], model_center[1], model_center[2], 1.0]
    transformed_pos_homogeneous = [sum(skin_matrix[r][c] * pos_homogeneous[c] for c in range(4)) for r in range(4)]
    transformed_center = (transformed_pos_homogeneous[0], transformed_pos_homogeneous[1], transformed_pos_homogeneous[2])
    # Transform Covariance
    deformation_matrix = [
        [skin_matrix[0][0], skin_matrix[0][1], skin_matrix[0][2]],
        [skin_matrix[1][0], skin_matrix[1][1], skin_matrix[1][2]],
        [skin_matrix[2][0], skin_matrix[2][1], skin_matrix[2][2]]
    ]
    transformed_covariance = GsplatTransformCovariance(covariance, deformation_matrix)
    # Transform Normal
    transformed_normal = deformation_matrix @ model_normal # Vector-matrix multiplication
    transformed_normal = tuple(v / ((sum(v*v for v in transformed_normal))**0.5) for v in transformed_normal)
    return transformed_center, transformed_covariance, transformed_normal
```

### Parameters
*   `_GsplatSkinningEnabled`: Integer flag (0 or 1) [S1, unofficial].
*   `sourceId`: Unique splat identifier [S1, unofficial].
*   Bone weights: Typically sum to 1.0, but the algorithm sums weighted matrices regardless [S1, unofficial].

### Edge Cases and Pitfalls
*   **Skinning Disabled:** If `_GsplatSkinningEnabled` is 0, all skinning functions return immediately without modifying inputs [S1, unofficial].
*   **Reference Matrix Construction:** When using the Texture2D backend, the reference inverse matrix is stored with only 3 rows [S1, unofficial]. The 4th row must be explicitly set to $(0, 0, 0, 1)$ to form a valid $4 \times 4$ matrix [S1, unofficial].
*   **Covariance Reconstruction:** The source covariance matrix must be correctly reconstructed from `covA` and `covB` components before transformation [S1, unofficial]. The result must be re-extracted into `covA` and `covB` [S1, unofficial].
*   **Precision:** Matrix multiplications involve floating-point operations [S1, unofficial]. Precision issues may arise with very small or very large bone weights, though standard float32 is implied [S1, unofficial].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** Constant time $O(1)$ per splat, involving a fixed number of texture/buffer loads (up to 13 texels for Texture2D backend: 4 indices, 1 weight, 4 bone rows, 3 reference rows) and matrix multiplications [S1, unofficial].
*   **Memory:** Depends on the backend [S1, unofficial]. Texture2D uses 4 textures where each bone index consumes 4 texels and each source consumes 1 texel for weights and 3 texels for reference inverse [S1, unofficial]. StructuredBuffer allows direct indexing, potentially simpler but may have different memory layout requirements [S1, unofficial].

### Measured Performance
Not given in the sources.

### Scaling
Scales linearly with the number of splats [S1, unofficial]. The cost per splat is constant regardless of scene complexity, as it depends only on the splat's local skin data [S1, unofficial].

### Strengths and Limitations
*   **Strengths:** Supports skeletal animation for Gaussian splats [S1, unofficial]. Texture2D backend offers GPU portability [S1, unofficial]. StructuredBuffer backend offers direct access [S1, unofficial].
*   **Limitations:** Limited to 4 bones per splat [S1, unofficial]. Requires pre-computed skin weights and bone matrices [S1, unofficial]. Texture2D backend requires coordinate conversion [S1, unofficial].

### When to Use
Use when skeletal animation of Gaussian splats is required [S1, unofficial]. Choose Texture2D backend for maximum GPU compatibility [S1, unofficial]. Choose StructuredBuffer backend for potentially simpler memory access patterns if the hardware supports it efficiently [S1, unofficial].

## Background
This method is part of the UnitySplats project by ARLOOPA, specifically designed for Gaussian Splatting in Unity [S1, unofficial]. It enables dynamic skinning of splats, allowing them to deform with skeletal animations [S1, unofficial].
