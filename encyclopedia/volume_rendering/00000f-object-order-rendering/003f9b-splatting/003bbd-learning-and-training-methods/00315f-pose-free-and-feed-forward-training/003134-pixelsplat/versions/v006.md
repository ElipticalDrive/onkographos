# pixelSplat

Also called: 3D Gaussian Splats from Image Pairs, Epipolar Transformer Gaussian Splatting

## Overview
pixelSplat is a feed-forward model that reconstructs a 3D radiance field parameterized by 3D Gaussian primitives from a pair of input images [S1]. It addresses the core problems of overcoming local minima inherent to sparse, locally supported representations and resolving scale ambiguity in generalizable novel view synthesis [S1]. Unlike light-field transformers which produce black-box ray fields, pixelSplat generates an explicit, editable 3D representation [S1]. It is distinguished from its siblings by its specific use of an epipolar transformer to resolve scale ambiguity and a probabilistic sampling mechanism to avoid local minima in primitive regression [S1].

## How it works
**Inputs:** A pair of images $I_1, I_2$ and their associated camera parameters (poses and intrinsics) [S1].
**Outputs:** A set of 3D Gaussian primitives $\{G_i\}$, where each primitive is defined by mean $\mu_i$, covariance $\Sigma_i$, opacity $\alpha_i$, and scale $S_i$ [S1].

**Data Structures:**
The model predicts parameters for pixel-aligned Gaussian primitives [S1]. The feature map $\mathbf{F}[\mathbf{u}]$ is generated for each pixel $\mathbf{u}$ [S1]. The prediction network $f$ outputs:
*   $\phi$: Parameters for the dense probability distribution over depth [S1].
*   $\boldsymbol{\delta}$: Depth offset or relative depth parameter [S1].
*   $\boldsymbol{\Sigma}$: Covariance matrix parameters [S1].
*   $\mathbf{S}$: Scale factor [S1].

**Steps:**
1.  **Image Encoding:** Each reference image is passed through a ResNet-50 and a ViT-B/8 vision transformer, both pre-trained using a DINO objective. Their pixel-wise outputs are summed to generate initial features [S1].
2.  **Epipolar Feature Encoding:** The features from the two views are processed by a multi-view epipolar transformer [S1]. This involves two rounds of epipolar cross-attention [S1]. Frequency-based positional encoding of depth is used to resolve scale ambiguity [S1].
3.  **Gaussian Parameter Prediction:** For each pixel $\mathbf{u}$, a neural network $f$ conditioned on the feature $\mathbf{F}[\mathbf{u}]$ predicts the Gaussian parameters [S1]:
    $$ \phi, \boldsymbol{\delta}, \boldsymbol{\Sigma}, \mathbf{S} = f(\mathbf{F}[\mathbf{u}]) $$
    [S1]
4.  **Probabilistic Sampling:** A dense probability distribution over 3D space is predicted [S1]. Gaussian means are sampled from this distribution [S1].
5.  **Reparameterization Trick:** The density of a sampled Gaussian primitive is coupled to the probability of that location [S1]. This allows back-propagation of gradients through the Gaussian splatting representation [S1]. When a gradient would increase the opacity of a Gaussian at a 3D location, the model increases the probability that a Gaussian will be sampled at that location again in the future, implicitly spawning or deleting primitives during training [S1].
6.  **Rendering:** The predicted 3D Gaussians are rendered using differentiable volume rendering (standard Gaussian splatting rasterization) to produce novel views [S1].

**Parameters:**
*   Training resolution: $256 \times 256$ pixels [S1].
*   Loss function: Combination of Mean Squared Error (MSE) and Perceptual Distance (LPIPS) [S1].
*   Optimizer: Adam [S1].

**Pseudocode:**
```python
def extract_resnet50_dino_features(image):
    # Standard ResNet-50 feature extraction pre-trained with DINO objective
    return [row[:] for row in image]

def extract_vit_b8_dino_features(image):
    # Standard ViT-B/8 feature extraction pre-trained with DINO objective
    return [row[:] for row in image]

def epipolar_cross_attention(feat1, feat2, cam1, cam2):
    # Two rounds of epipolar cross-attention with frequency-based depth encoding
    return [[(a + b) / 2.0 for a, b in zip(row1, row2)] for row1, row2 in zip(feat1, feat2)]

def predict_gaussian_parameters(features):
    # Neural network f conditioned on feature F[u]
    # Outputs phi, delta, sigma, scale
    H, W, C = len(features), len(features[0]), len(features[0][0])
    phi = [[[features[i][j][0]] for j in range(W)] for i in range(H)]
    delta = [[[features[i][j][1]] for j in range(W)] for i in range(H)]
    sigma = [[[features[i][j][k]] for k in range(2, 5)] for j in range(W)] for i in range(H)]
    scale = [[[features[i][j][5]] for j in range(W)] for i in range(H)]
    return phi, delta, sigma, scale

def sample_from_distribution(phi, delta):
    # Differentiable sampling via reparameterization trick
    noise = [[[-1.0 + 2.0 * (hash(i) % 1000) / 1000.0 for j in range(W)] for i in range(H)] for i in range(H)]
    return [[[phi[i][j][0] + noise[i][j][0] * delta[i][j][0]] for j in range(W)] for i in range(H)]

def predict_opacity(pixel_index):
    # Predicts opacity alpha for the primitive
    return 0.5

class GaussianPrimitive:
    def __init__(self, mean, covariance, opacity, scale):
        self.mean = mean
        self.covariance = covariance
        self.opacity = opacity
        self.scale = scale

def render_gaussians(gaussians, camera_params):
    # Differentiable volume rendering / Gaussian splatting rasterization
    return [[0.0 for _ in range(3)] for _ in range(256)]

def compute_mse_loss(rendered, ground_truth):
    return sum((r - g) ** 2 for r, g in zip(rendered, ground_truth))

def compute_lpips_loss(rendered, ground_truth):
    # Perceptual Distance (LPIPS) metric
    return sum(abs(r - g) for r, g in zip(rendered, ground_truth))

optimizer = type('Optimizer', (), {'step': lambda: None})()

def pixelsplat_forward(images, camera_params):
    H, W = len(images[0]), len(images[0][0])
    
    features = []
    for img in images:
        resnet_feat = extract_resnet50_dino_features(img)
        vit_feat = extract_vit_b8_dino_features(img)
        features.append([[a + b for a, b in zip(row1, row2)] for row1, row2 in zip(resnet_feat, vit_feat)])
    
    fused_features = epipolar_cross_attention(
        features[0], features[1], 
        camera_params[0], camera_params[1]
    )
    
    phi, delta, sigma, scale = predict_gaussian_parameters(fused_features)
    sampled_depths = sample_from_distribution(phi, delta)
    
    gaussians = []
    for u in range(H * W):
        ray_origin = camera_params[0]["origin"]
        ray_direction = camera_params[0]["directions"][u]
        mu = ray_origin + sampled_depths[u] * ray_direction
        opacity = predict_opacity(u)
        g = GaussianPrimitive(
            mean=mu,
            covariance=sigma[u],
            opacity=opacity,
            scale=scale[u]
        )
        gaussians.append(g)
            
    return gaussians

def train_step(images, gt_images, camera_params):
    gaussians = pixelsplat_forward(images, camera_params)
    rendered_images = render_gaussians(gaussians, camera_params)
    loss = compute_mse_loss(rendered_images, gt_images) + compute_lpips_loss(rendered_images, gt_images)
    loss.backward()
    optimizer.step()
```

**Edge Cases and Pitfalls:**
*   **Scale Ambiguity:** SfM poses are scaled by an arbitrary unknown scalar $s_i$. The model handles this by inferring the scale via the epipolar transformer [S1]. Without it, ghosting artifacts occur [S1].
*   **Local Minima:** Direct regression of Gaussian means suffers from local minima because Gaussians have local support and gradients vanish if the distance to the correct location is large. The probabilistic sampling avoids this [S1].
*   **Out-of-Distribution Views:** Reflective surfaces may appear transparent, and Gaussians may appear billboard-like when viewed from out-of-distribution camera poses [S1].

## Subtopics

### MVSplat
A method that builds upon PixelSplat by combining multi-view feature extraction through transformers and cost volumes, which are then processed by a U-Net [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Inference cost is approximately 650 times less than the next-fastest baseline for encoding one scene and rendering 100 images [S1]. It accelerates rendering by 2.5 orders of magnitude compared to state-of-the-art light field transformers [S1].
*   **Memory Complexity:** Memory-efficient rendering and scalable training [S1]. Uses significantly less memory per ray at training time compared to baselines [S1].
*   **Performance:** Outperforms baselines (pixelNeRF, GPNR, Du et al.) on RealEstate10k and ACID datasets, with significant improvements in perceptual distance (LPIPS) [S1].
*   **Strengths:** Real-time rendering, editable 3D representation, fast inference, handles scale ambiguity, avoids local minima [S1].
*   **Limitations:** Struggles with reflective surfaces (transparency) and out-of-distribution views (billboarding) [S1]. Requires known camera poses (unlike NoPoSplat) [S2, unofficial].

## Background
pixelSplat was introduced by Charatan, Li, Tagliasacchi, and Sitzmann from MIT and Simon Fraser University/University of Toronto [S1]. It was presented at CVPR 2024 [S1]. The method addresses the limitations of previous generalizable novel view synthesis approaches, specifically the high computational cost of differentiable rendering and the black-box nature of light-field transformers [S1]. It builds on the success of 3D Gaussian Splatting for single-scene optimization [19] but adapts it for feed-forward, generalizable inference [S1].
