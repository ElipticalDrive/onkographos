# 2D Covariance Correction via Linear Regression

Also called: DARBF covariance approximation, Scalar correction factor $\psi$, Scalar correction factor $ψ$

## Overview
This method approximates the relationship between projected 2D covariances and actual 2D covariances using a linear regression model, serving as a computationally efficient alternative to neural network-based corrections in Gaussian Avatar Reconstruction. It sets itself apart from its siblings by replacing complex learned mappings with closed-form linear coefficients or a single scalar factor, thereby reducing training overhead while maintaining reconstruction quality comparable to Half-Cosine (HC) kernels.

## How it works
**Inputs and Outputs:**
*   **Input:** The 3D covariance matrix $\Sigma'$ of a Gaussian primitive, represented by its unique elements.
*   **Output:** The corrected 2D covariance matrix $\Sigma'_{2 \times 2}$ in screen space.

**Data Structures:**
The 3D covariance matrix $\Sigma'$ is symmetric. The method utilizes the 6 unique elements derived from this matrix:
$$ \Sigma' = \begin{pmatrix} a & b & c \\ b & d & e \\ e & d & f \end{pmatrix} $$
*Note: The source text contains a typo in the matrix layout where $e$ appears in both $(2,3)$ and $(3,2)$ positions, but the linear equations clarify the variable mapping. Standard symmetric matrix notation implies $\Sigma'_{2,3} = e$ and $\Sigma'_{3,2} = e$. The source lists variables as $a, b, c, d, e, f$.*

**Numbered Steps:**
1.  **Extract 3D Covariance Elements:** Identify the unique elements $a, b, c, d, e, f$ from the 3D covariance matrix $\Sigma'$.
2.  **Compute Projected 2D Covariance (Reference):** Obtain the "projected" 2D covariance by integrating along one axis using Simpson's rule. This serves as the baseline for comparison.
3.  **Compute Actual 2D Covariance (Ground Truth):** Derive the "actual" 2D covariance by removing the last row and column of the 3D covariance matrix $\Sigma'$, as proposed in [82]. This results in the target matrix:
    $$ \Sigma'_{2 \times 2} = \begin{pmatrix} a' & b' \\ b' & d' \end{pmatrix} $$
4.  **Apply Linear Regression Correction:** Instead of using a Multi-Layer Perceptron (MLP), apply a linear regression model to approximate the mapping from the 3D elements to the 2D elements. The source provides two forms: a full linear model and a simplified scalar correction.

**Formulas:**

*   **Full Linear Model:**
    The corrected elements $a', b', d'$ are computed as linear combinations of the input variables $a, b, c, d, e, f$:

    $$ a' = 1.36a - 0.2b - 0.1c - 0.0d + 0.0e + 0.0f $$
    $$ b' = 0.0a + 1.36b - 0.0c - 0.0d + 0.0e + 0.0f $$
    $$ d' = 0.0a + 0.0b - 0.2c + 1.36d + 0.1e + 0.0f $$

*   **Scalar Correction Factor ($\psi$):**
    Statistical analysis (T-tests) revealed that only the direct 3D covariance elements corresponding to the 2D covariance elements have significant weights. This allows the model to be simplified to a single scalar factor $\psi$ applied to the diagonal elements of the projected 2D covariance:
    $$ \Sigma'_{2 \times 2} = \psi \begin{pmatrix} a & b \\ b & d \end{pmatrix} $$
    The specific value of $\psi$ depends on the reconstruction kernel used (Gaussian or Half-Cosine). The source notes that scalar approximations for each kernel are presented in the original paper's Table 2, but does not list the specific $\psi$ values in the provided text.

**Parameters:**
*   **Learning Rate (LR):** Used during the training phase to determine the regression coefficients or scalar factor. Tested values are 0.01, 0.02, 0.1, and 0.2 [S1].
*   **Reconstruction Kernel:** The method is evaluated with Gaussian and Half-Cosine (HC) kernels.

**Pseudocode:**
```python
def compute_2d_covariance_correction(cov_3d, kernel_type='gaussian'):
    """
    Computes the corrected 2D covariance matrix from a 3D covariance matrix
    using linear regression approximation.
    
    Args:
        cov_3d (numpy.ndarray): 3x3 symmetric covariance matrix.
        kernel_type (str): 'gaussian' or 'half_cosine'.
        
    Returns:
        numpy.ndarray: 2x2 corrected covariance matrix.
    """
    # Extract unique elements from 3x3 symmetric matrix
    # Sigma' = [[a, b, c],
    #           [b, d, e],
    #           [c, e, f]]  <-- Note: Source text has typo 'e' at (3,2) and 'd' at (3,3) in matrix display,
    #                          but equations use standard symmetry. We assume standard symmetry.
    # Based on source equations:
    # a = cov_3d[0,0]
    # b = cov_3d[0,1]
    # c = cov_3d[0,2]
    # d = cov_3d[1,1]
    # e = cov_3d[1,2]
    # f = cov_3d[2,2]
    
    a = cov_3d[0, 0]
    b = cov_3d[0, 1]
    c = cov_3d[0, 2]
    d = cov_3d[1, 1]
    e = cov_3d[1, 2]
    f = cov_3d[2, 2]
    
    # Apply Full Linear Model coefficients from source
    # a' = 1.36a - 0.2b - 0.1c
    # b' = 1.36b
    # d' = -0.2c + 1.36d + 0.1e
    
    a_prime = 1.36 * a - 0.2 * b - 0.1 * c
    b_prime = 1.36 * b
    d_prime = -0.2 * c + 1.36 * d + 0.1 * e
    
    # Construct the 2x2 matrix
    cov_2d = np.array([
        [a_prime, b_prime],
        [b_prime, d_prime]
    ])
    
    return cov_2d
```
*Note: The source provides the scalar approximation $\psi \begin{pmatrix} a & b \\ b & d \end{pmatrix}$ as a simplification. If the scalar model is preferred, the implementation would multiply the upper-left 2x2 block of the 3D covariance by $\psi$. The specific value of $\psi$ is not provided in the text, so the full linear model is implemented above as it contains explicit coefficients.*

**Edge Cases and Pitfalls:**
*   **Learning Rate Sensitivity:** Excessively high or low learning rates during the training of the correction model lead to suboptimal performance. At high learning rates, cosine-based reconstructions may perform worse than Gaussian-based ones [S1].
*   **Kernel Smoothness:** Cosine kernels do not induce smoothness to the same extent as Gaussian kernels. This affects convergence and final quality, particularly at non-optimal learning rates [S1].
*   **Matrix Symmetry:** The source text displays a typo in the 3D covariance matrix layout ($\Sigma'_{3,2} = d$ instead of $e$). Implementers must assume standard symmetric matrix properties ($\Sigma'_{i,j} = \Sigma'_{j,i}$) to correctly map variables $a-f$ to matrix indices.

## Operating characteristics
**Time and Memory Complexity:**
The linear regression model is computationally lightweight, involving only basic arithmetic operations. It is significantly faster than training or inference with an MLP.

**Measured Performance:**
Evaluated on the Mip-NeRF 360 dataset (scenes: Kitchen, Room, Truck, Bicycle, Flowers, Garden, Stump, Treehill, Counter, Bonsai) [S1].

*   **Learning Rate 0.01:**
    *   PSNR: 31.49 (Gaussian) vs 31.335 (HCS)
    *   Training Time: 22:31 (Gaussian) vs 23:26 (HCS)
    *   Memory: 255.61 (Gaussian) vs 246.48 (HCS)
*   **Learning Rate 0.02:**
    *   PSNR: 31.75 (Gaussian) vs 31.34 (HCS)
    *   Training Time: 19:48 (Gaussian) vs 17:32 (HCS)
    *   Memory: 293.61 (Gaussian) vs 282.65 (HCS)
*   **Learning Rate 0.1:**
    *   PSNR: 31.1 (Gaussian) vs 29.38 (HCS)
    *   Training Time: 13:31 (Gaussian) vs 11:20 (HCS)
    *   Memory: 364 (Gaussian) vs 391.76 (HCS)
*   **Learning Rate 0.2:**
    *   PSNR: 30.5 (Gaussian) vs 26.54 (HCS)
    *   Training Time: 10:34 (Gaussian) vs 8:26 (HCS)
    *   Memory: 241.42 (Gaussian) vs 315.93 (HCS)

**Scaling and Hardware:**
Half-Cosine (HC) kernels achieve better training speeds compared to Gaussian kernels, even on upgraded hardware (RTX 4090 vs RTX 3090) [S1]. For example, on the "Room" scene, training time dropped from 28m 32s to 19m 48s on RTX 4090 for Gaussian, and from 25m 28s to 17m 32s for HC [S1].

**Strengths and Limitations:**
*   **Strengths:** High training efficiency; competitive visual quality (SSIM 0.813, PSNR 27.45 for DARBS RC) compared to prior methods like Plenoxels and INGP [S1].
*   **Limitations:** Performance degrades at extreme learning rates. Cosine kernels may underperform Gaussian kernels at high learning rates due to lack of smoothness [S1].

**When to Use:**
Use this method when computational efficiency is prioritized over the absolute peak PSNR achievable by more complex MLP-based corrections, particularly when using Half-Cosine kernels for faster training.

## Background
**Origin:**
The method originates from the DARB-Splatting paper, which generalizes splatting with Decaying Anisotropic Radial Basis Functions. It was developed to replace the MLP-based covariance correction with a simpler linear regression model [S1].

**History and Development:**
The authors initially proposed training a single-layer MLP to approximate the relationship between projected and actual 2D covariances. Through extensive experiments, they observed that the MLP could be closely approximated by a linear regression model. Further statistical analysis using T-tests allowed for the simplification to a scalar correction factor $\psi$ for specific kernels [S1].

**Usage:**
The method is used in 3D Gaussian Splatting variants, specifically within the DARBS (Decaying Anisotropic Radial Basis Splatting) framework, for high-quality 3D reconstruction and novel view synthesis [S1].
