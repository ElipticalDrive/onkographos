# t-distribution truncation for splatting

Also called: critical value interpolation, three-sigma rule adaptation

## Overview

This method modifies the fragment culling logic in 3D Gaussian Splatting rasterization to enable opacity-independent truncation at fewer standard deviations [S1, unofficial]. It addresses the limitation where the original implementation's reliance on fragment transparency $\alpha$ prevents consistent truncation below approximately $3.03\sigma$ [S1, unofficial]. Additionally, it adapts the truncation threshold for Student's t-distributions by interpolating critical values based on the degrees of freedom $\nu$, preventing excessive truncation or leakage in fat-tailed distributions [S2].

## How it works

### Inputs and Outputs
*   **Inputs**:
    *   Gaussian parameters: Opacity $\alpha_{base}$, covariance matrix $\Sigma_{2D}$ (projected 2D covariance) [S1, unofficial].
    *   Pixel coordinates $(u, v)$ in screen space [S1, unofficial].
    *   Truncation threshold parameter $\tau_\alpha$ (default $1/255$) [S1, unofficial].
    *   Degrees of freedom $\nu$ (for t-distribution variants) [S2].
*   **Outputs**:
    *   Boolean flag indicating whether the fragment should be processed (contributing to the color buffer) or skipped [S1, unofficial].

### Data Structures
*   **Critical Value Table**: A lookup table mapping degrees of freedom $\nu$ to the number of standard deviations (or squared Mahalanobis distance) required for truncation. This table is derived from reference [9] in [S2]. Not given in the sources.

### Steps

1.  **Compute Gaussian Response**: Calculate the unnormalized Gaussian response $R$ at the pixel $(u, v)$ using the squared Mahalanobis distance $d^2$ derived from $\Sigma_{2D}$ [S1, unofficial].
    $$ R = \exp\left(-\frac{1}{2} d^2\right) $$
    Where $d^2 = \mathbf{x}^T \Sigma_{2D}^{-1} \mathbf{x}$ and $\mathbf{x} = [u - u_c, v - v_c]^T$ is the vector from the Gaussian center to the pixel [S1, unofficial].

2.  **Determine Truncation Threshold**:
    *   **For Standard Gaussians**: Use the fixed threshold $\tau_\alpha$ [S1, unofficial].
    *   **For Student's t-distributions**:
        *   If $\nu$ is high (thin tails), use the standard three-sigma rule ($3\sigma$) [S2].
        *   If $\nu$ is low (fat tails), retrieve critical values for the specific $\nu$ from the reference table and interpolate to find the appropriate threshold $T_\nu$ [S2].

3.  **Check Response Against Threshold**: Compare the unnormalized response $R$ against the threshold.
    *   For standard truncation: Check if $R < \tau_\alpha$ [S1, unofficial].
    *   For t-distribution truncation: Check if $R < T_\nu$ (adjusted for the t-distribution density) [S2].

4.  **Skip or Process**:
    *   If the response is below the threshold, skip the fragment (do not multiply by opacity, do not blend) [S1, unofficial].
    *   If the response is above the threshold, proceed to multiply by opacity $\alpha_{base}$ to compute final transparency $\alpha$ and blend [S1, unofficial].

### Pseudocode

```python
def should_process_fragment(gaussian, pixel):
    """
    Determines if a 3D Gaussian fragment should be processed during rasterization.
    Implements opacity-independent truncation.
    """
    # 1. Compute the 2D Gaussian response (unnormalized)
    # Calculate squared Mahalanobis distance from pixel to Gaussian center
    # using the projected 2D covariance matrix Sigma_2D.
    # d2 = (pixel - center)^T * Sigma_2D^-1 * (pixel - center)
    d2 = compute_mahalanobis_squared(pixel, gaussian.center, gaussian.covariance_2d)
    
    # Compute the exponential response
    response = exp(-0.5 * d2)
    
    # 2. Determine the truncation threshold
    # Default threshold for standard 3DGS is 1/255
    threshold = 1.0 / 255.0
    
    # If using t-distribution (Student Splatting), adjust threshold based on nu
    if gaussian.distribution_type == "student_t":
        nu = gaussian.degrees_of_freedom
        if nu > THRESHOLD_NU: # High nu, thin tails
            # Use standard three-sigma rule equivalent
            # Note: Exact mapping from sigma to response threshold depends on implementation
            threshold = get_three_sigma_threshold() 
        else: # Low nu, fat tails
            # Interpolate critical values from reference [9] based on nu
            threshold = interpolate_critical_value(nu)
            
    # 3. Check response against threshold BEFORE multiplying by opacity
    # This allows truncation independent of the Gaussian's base opacity
    if response < threshold:
        return False # Skip fragment
        
    return True # Process fragment (multiply by opacity and blend)
```

### Parameters
*   $\tau_\alpha$: Fragment transparency threshold. Default: $1/255$ [S1, unofficial].
*   $\nu$: Degrees of freedom for Student's t-distribution. Not given in the sources.
*   $THRESHOLD\_NU$: The $\nu$ value above which the standard three-sigma rule is applied. Not given in the sources.

### Edge Cases and Pitfalls
*   **Opacity Independence**: The original 3DGS implementation multiplies opacity before checking the threshold, meaning Gaussians with $\alpha_{base} < \tau_\alpha$ are never visible or receive gradients [S1, unofficial]. This method checks the response *before* multiplying by opacity, allowing these Gaussians to contribute [S1, unofficial].
*   **Minimum Opacity**: Aggressive truncation (e.g., at $1\sigma$) results in a minimum contributing fragment opacity of approximately $0.61$, meaning Gaussians are effectively close to opaque [S1, unofficial].
*   **Fat-Tailed Distributions**: Using a fixed three-sigma threshold on fat-tailed t-distributions (low $\nu$) causes excessive truncation or leakage. Interpolation across $\nu$ degrees resolves this [S2].
*   **Gradient Disregard**: The original implementation disregards non-zero opacity gradients when opacity is zero, interpreting opacity as part of the Gaussian response [S1, unofficial]. This modification allows investigation of these gradients [S1, unofficial].

## Operating characteristics

*   **Time Complexity**: Truncation at fewer standard deviations (e.g., $1\sigma$ or $2\sigma$) reduces the number of Gaussians processed per pixel, potentially speeding up rendering. However, training time may increase due to densification dynamics and the overhead of opacity-independent gradient computation [S1, unofficial].
*   **Memory Complexity**: Aggressive truncation reduces the number of Gaussians required to represent the scene, lowering VRAM usage. For example, $1\sigma$ truncation uses $4.5$ GiB VRAM and $1.39$M Gaussians, compared to $6.1$ GiB and $2.70$M Gaussians for the default $3.33\sigma$ [S1, unofficial].
*   **Performance**:
    *   **$1\sigma$ truncation**: $25.86$ PSNR, $2$ min $26$ s training, $4.5$ GiB VRAM, $1.39$M Gaussians [S1, unofficial].
    *   **$2\sigma$ truncation**: $27.23$ PSNR, $3$ min $41$ s training, $5.5$ GiB VRAM, $2.22$M Gaussians [S1, unofficial].
    *   **$3.33\sigma$ truncation (default)**: $27.54$ PSNR, $4$ min $31$ s training, $6.1$ GiB VRAM, $2.70$M Gaussians [S1, unofficial].
    *   **$3.33\sigma$ with modification**: $27.57$ PSNR, $5$ min $07$ s training, $6.4$ GiB VRAM, $2.79$M Gaussians [S1, unofficial].
*   **Strengths**: Enables consistent truncation at fewer standard deviations, reducing Gaussian count and VRAM usage. Allows gradients to flow to low-opacity Gaussians. Handles fat-tailed distributions more accurately.
*   **Limitations**: Training time may increase. Aggressive truncation ($1\sigma$) significantly reduces PSNR. Requires careful tuning of $\nu$ and interpolation tables for t-distributions.

## Background

*   **Origin**: The opacity-independent truncation method was proposed in "Faster-GS: Analyzing and Improving Gaussian Splatting Optimization" [S1, unofficial]. The t-distribution truncation method was introduced in "3D Student Splatting and Scooping" [S2].
*   **History**: The original 3DGS implementation used a fixed fragment transparency threshold $\tau_\alpha = 1/255$, which implicitly limited truncation to $\approx 3.03\sigma$ for high-opacity Gaussians due to opacity clipping [S1, unofficial]. The modification addresses this by decoupling truncation from opacity [S1, unofficial]. The t-distribution approach extends this by adapting the threshold to the tail behavior of the distribution [S2].
*   **Usage**: Used in variants of 3D Gaussian Splatting that require efficient memory usage or handle heavy-tailed noise distributions [S1, unofficial][S2].
