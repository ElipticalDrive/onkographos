# Gaussian Triangle Rendering

Also called: Gaussian Triangle Splatting, Mixed primitive rendering, Triangle-centered primitive splatting

## Overview
Gaussian Triangle Rendering is a surface reconstruction technique that represents primitives as "Gaussian triangles"—composed of three 2D Gaussian ellipses connected by common tangent lines—to achieve better surface continuity than single ellipses [S1, unofficial]. It solves the problem of representing non-elliptical shapes in Gaussian Splatting by decomposing the triangle into its vertices, splatting them, and then re-sketching the triangle on the image plane with a modified fading parameter $\gamma$ that handles inner, vertex, and edge regions separately [S1, unofficial]. Unlike standard Gaussian Splatting which uses only ellipses, this method uses triangles and lines to better represent surfaces [S1, unofficial].

## How it works
**Inputs:**
*   A 3D Gaussian triangle primitive defined by three 3D vertices.
*   Camera parameters (view and projection matrices) to project vertices to 2D.
*   For each projected vertex $i \in \{1, 2, 3\}$:
    *   2D mean position $\boldsymbol{\mu}_{2D}^i$.
    *   2D covariance matrix $\boldsymbol{\Sigma}^{2D}$ (shared or per-vertex, assumed shared for the triangle structure in the source context).
    *   Opacity $\alpha$.
    *   Color $c$ (derived from SH coefficients, independent of shape).

**Outputs:**
*   For each pixel $p$ covered by the triangle:
    *   Fading parameter $\gamma(p)$.
    *   Color $c$ (same for all pixels in the primitive).

**Data Structures:**
*   **Vertices:** List of 3 points $\{\boldsymbol{\mu}_{2D}^1, \boldsymbol{\mu}_{2D}^2, \boldsymbol{\mu}_{2D}^3\}$.
*   **Tangency Points:** List of 6 points $\{t_{1,2}, t_{2,1,2}, t_{1,3}, t_{3,1,3}, t_{2,3}, t_{3,2,3}\}$.
    *   $t_{i,j}$ is the tangency point on the $i$-th ellipse for the common tangent line connecting ellipse $i$ and $j$.
*   **Quadrangles:** Three quadrangles $\square_{1,2}, \square_{1,3}, \square_{2,3}$.
    *   $\square_{1,2}$ vertices: $\{\boldsymbol{\mu}_{2D}^1, \boldsymbol{\mu}_{2D}^2, t_{2,1,2}, t_{1,1,2}\}$.
    *   $\square_{1,3}$ vertices: $\{\boldsymbol{\mu}_{2D}^1, \boldsymbol{\mu}_{2D}^3, t_{3,1,3}, t_{1,1,3}\}$.
    *   $\square_{2,3}$ vertices: $\{\boldsymbol{\mu}_{2D}^2, \boldsymbol{\mu}_{2D}^3, t_{3,2,3}, t_{2,2,3}\}$.

**Steps:**

1.  **Vertex Splatting:** Project the three 3D vertices of the Gaussian triangle to the image plane to obtain $\boldsymbol{\mu}_{2D}^1, \boldsymbol{\mu}_{2D}^2, \boldsymbol{\mu}_{2D}^3$. Splat these points using standard point-based splatting to generate three boundary ellipses [S1, unofficial].

2.  **Boundary Construction (Dual Ellipse Intersection):** For every pair of boundary ellipses (e.g., 1 and 2), solve the system of their dual boundary ellipse equations to find intersection points $(x_s, y_s)$ [S1, unofficial].
    *   The dual boundary ellipse equation $g_i^{dual}$ for ellipse $i$ is a binary quadratic function:
        $$
        \begin{aligned}
        g_i^{dual} &= \left( -\frac{1}{4}(d_i)^2 + a_i f_i \right) x^2 + \left( -c_i d_i + \frac{1}{2} b_i e_i \right) x \\
        &+ \left( -\frac{1}{4}(d_i)^2 + a_i f_i \right) y^2 + \left( \frac{1}{2} b_i e_i - a_i e_i \right) y - \frac{1}{4}(b_i)^2 + a_i c_i = 0
        \end{aligned}
        $$
        *(Note: The source provides Eq. 7 with specific coefficients $a_i, b_i, c_i, d_i, e_i, f_i$ derived from the covariance matrix elements. Implementers must map the covariance matrix $\boldsymbol{\Sigma}^{2D}$ to these coefficients according to the source's definition.)*
    *   Solve the system:
        $$
        \begin{cases}
        g_1^{dual} = 0 \\
        g_2^{dual} = 0
        \end{cases} \quad (8)
        $$
        This system of two binary quadratic functions has closed-form solutions for intersection points $(x_s, y_s)$ [S1, unofficial].

3.  **Tangency Points:**
    *   **Common Tangent Line:** For each intersection point $(x_s, y_s)$ from Step 2, derive a common tangent line using the duality property:
        $$
        x_s \times x + y_s \times y + 1 = 0 \quad (9)
        $$
        Since Eq. 8 yields multiple solutions, select the common tangent line that is farthest from the third vertex of the triangle [S1, unofficial]. Let the chosen line be $x_s^c x + y_s^c y + 1 = 0$.
    *   **Tangency Calculation:** Solve for the unique point of tangency $t_{1,2}$ between the chosen line and the first boundary ellipse $g_1^{ct}=0$:
        $$
        \begin{cases}
        x_s^c \times x + y_s^c \times y + 1 = 0 \\
        g_1^{ct} = 0
        \end{cases} \quad (10)
        $$
        Repeat for the second ellipse to get $t_{2,1,2}$. Repeat this process for all three pairs of ellipses to acquire all tangency points $t_{i,j}$ [S1, unofficial].

4.  **Rendering Setup:** Define the triangle $\triangle$ formed by $\boldsymbol{\mu}_{2D}^1, \boldsymbol{\mu}_{2D}^2, \boldsymbol{\mu}_{2D}^3$. Define the three quadrangles $\square_{1,2}, \square_{1,3}, \square_{2,3}$ using the vertices and their corresponding tangency points [S1, unofficial].

5.  **Fading Parameter Calculation:** For a pixel $p$, determine its location relative to $\triangle$ and the quadrangles to compute $\gamma(p)$:
    *   **Case (i) Inner:** If $p$ is inside $\triangle$, set $\gamma = \alpha$ [S1, unofficial].
    *   **Case (ii) Vertex:** If $p$ is outside $\triangle$ and outside all quadrangles, identify the nearest vertex $\boldsymbol{\mu}_{2D}^j$. Set:
        $$
        \gamma = \alpha e^{-\frac{1}{2}(p-\boldsymbol{\mu}_{2D}^j)^T(\boldsymbol{\Sigma}^{2D})^{-1}(p-\boldsymbol{\mu}_{2D}^j)} \quad (11)
        $$
    *   **Case (iii) Edge:** If $p$ is inside a quadrangle (e.g., $\square_{1,2}$), find points $p_{e1}$ on edge $e_1$ (connecting $\boldsymbol{\mu}_{2D}^1$ and $t_{1,1,2}$) and $p_{e2}$ on edge $e_2$ (connecting $\boldsymbol{\mu}_{2D}^2$ and $t_{2,1,2}$) such that $p$ lies on the segment $p_{e1}p_{e2}$. Calculate $\eta$ using the Gaussian formula for both points (they should be equal) and set $\gamma = \eta$:
        $$
        \eta = \alpha e^{-\frac{1}{2}(p_{e1}-\boldsymbol{\mu}_1^{2D})^T(\boldsymbol{\Sigma}^{2D})^{-1}(p_{e1}-\boldsymbol{\mu}_1^{2D})} = \alpha e^{-\frac{1}{2}(p_{e2}-\boldsymbol{\mu}_2^{2D})^T(\boldsymbol{\Sigma}^{2D})^{-1}(p_{e2}-\boldsymbol{\mu}_2^{2D})} \quad (17)
        $$
        The color $c$ is calculated independently using SH coefficients [S1, unofficial].

## Operating characteristics
*   **Complexity:** The method requires solving systems of quadratic equations for each triangle per frame, which is more computationally intensive than standard ellipse splatting. The number of operations scales with the number of triangles and pixels covered.
*   **Performance:** Not given in the sources.
*   **Strengths:** Better surface continuity than single ellipses; handles inner, vertex, and edge regions separately for accurate fading [S1, unofficial].
*   **Limitations:** More complex implementation due to dual ellipse intersection and tangency calculations; requires careful handling of degenerate cases (e.g., parallel tangents) [S1, unofficial].
*   **When to use:** When surface reconstruction quality is critical and the scene contains sharp features or planar surfaces that benefit from triangle-based representation [S1, unofficial].

## Background
Gaussian Triangle Rendering is part of the Mixed-Primitive-based Gaussian Splatting (MP-GS) framework, introduced to enable the splatting of non-elliptical primitives like "Gaussian lines" and "Gaussian triangles" [S1, unofficial]. It was proposed to address the limitations of standard Gaussian Splatting, which uses only ellipses, by allowing for more accurate reconstruction of object surfaces [S1, unofficial].
