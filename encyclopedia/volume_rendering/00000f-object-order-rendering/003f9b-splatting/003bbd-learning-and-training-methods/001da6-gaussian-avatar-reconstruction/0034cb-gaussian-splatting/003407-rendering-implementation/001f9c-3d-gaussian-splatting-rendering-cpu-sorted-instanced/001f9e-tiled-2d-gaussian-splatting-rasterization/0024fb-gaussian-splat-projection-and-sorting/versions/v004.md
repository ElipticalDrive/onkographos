# Gaussian Splat Projection and Sorting

Also called: Staging Splats

## Overview
Gaussian Splat Projection and Sorting is a GPU compute shader pass that projects 3D Gaussian splats into 2D screen space, culls invisible splats, computes view-dependent lighting, and prepares data for tile-based sorting. It differs from its parent [Tiled 2D Gaussian Splatting Rasterization](2061-tiled-2d-gaussian-splatting-rasterization.md) by handling the geometric projection, visibility culling, and sorting key generation, whereas the parent handles the actual pixel-level rasterization within tiles. It differs from [Gaussian Splat View Data Calculation](10400-gaussian-splat-view-data-calculation.md) by focusing on the projection and sorting preparation rather than the evaluation of appearance (SH) and 4D state resolution, although both may coexist in different pipeline implementations.

## How it works
**Inputs and Outputs:**
- **Inputs:**
  - `SplatsBuffer`: Array of `Splat` structs (std430).
  - `SplatInstanceIdsBuffer`: Array of `uvec2` where `x` is the unique instance ID and `y` is the index into `SplatsBuffer`.
  - `InstanceTransformsBuffer`: Array of `mat4` model matrices.
  - `Uniforms`: `camera_pos` (vec3), `time` (float), `dims` (ivec2, texture size), `point_count` (int), `light_count` (int).
  - `LightRigBuffer`: Array of `vec4` lights.
  - `InstanceRelightBuffer`: Array of `vec4` per instance.
  - `SplatLightingBuffer`: Array of `uint` per splat (packed normals/AO).
- **Outputs:**
  - `CulledBuffer`: Array of `RasterizeData` structs containing projected data for visible splats.
  - `SortKeysBuffer`: Array of `uint` keys for radix sort.
  - `SortValuesBuffer`: Array of `uint` values (original splat indices).
  - `Histograms`: `sort_buffer_size` (atomic counter) and histogram data.

**Data Structures:**
```glsl
struct Splat {
    vec3 position;
    float time;
    float covariance[6]; // Top triangle of symmetric 3x3 matrix
    float opacity;
    float _pad;
    float sh_coefficients[16*3]; // SH coefficients, degree 3
};

struct RasterizeData {
    vec2 image_pos;
    vec2 pos_xy;
    vec3 conic; // Inverse 2D covariance: (cov_z, -cov_xy, cov_x) / det
    float pos_z;
    vec4 color; // RGB + opacity
    vec4 depth_data; // z-depth info
};
```

**Constants:**
- `TILE_SIZE`: 16.
- `SH_C0` to `SH_C3_6`: Spherical harmonic constants (see [S1, unofficial]).
- `DECODE_COVARIANCE(c)`: Reconstructs `mat3` from 6 floats: `mat3(c[0], c[1], c[2], c[1], c[3], c[4], c[2], c[4], c[5])`.

**Steps:**
1. **Initialization:** Get `gl_GlobalInvocationID.x`. If `id >= point_count`, return.
2. **Barrier:** Synchronize workgroup.
3. **Instance Data:** Retrieve `instance_id = splat_instance_data[id].x` and `unique_splat_index = splat_instance_data[id].y`.
4. **Load Data:** Load `splat = splat_buffer[unique_splat_index]` and `model_matrix = instance_model_matrices[instance_id]`.
5. **Visibility Check:** If `model_matrix[0][3] < 0.5`, return. Set `model_matrix[0][3] = 0.0`.
6. **Frustum Culling:**
   - `world_covariance = object_linear * DECODE_COVARIANCE(splat.covariance) * transpose(object_linear)`.
   - `world_pos = model_matrix * vec4(splat.position, 1.0)`.
   - `view_pos = view_matrix * world_pos`.
   - `clip_pos = projection_matrix * view_pos`.
   - `view_bounds = clip_pos.w * 1.2`.
   - If `any(lessThan(clip_pos.xyz, vec3(-view_bounds, 0.0)))` or `any(greaterThan(clip_pos.xyz, vec3(view_bounds, clip_pos.w)))`, return.
7. **Time Animation:**
   - `splat_time = time - splat.time`.
   - `time_factor = ease_out_cubic(clamp(splat_time, 0, 1))`.
   - `time_factor_late = ease_out_cubic(clamp(splat_time - 0.35, 0, 1))`.
   - `splat_opacity = splat.opacity * time_factor_late * time_factor_late`.
   - `splat_scale = mix(2.0, 1.0, time_factor_late)`.
   - `ease_out_cubic(x) = 1.0 - pow(1.0 - x, 3.0)`.
8. **Project Covariance:**
   - `cov_3d = world_covariance * splat_scale^2`.
   - `tan_fov_inv = vec2(projection_matrix[0][0], projection_matrix[1][1])`.
   - `focal = (dims - 1) * 0.5 * tan_fov_inv * (-1.0 / mean.z)`.
   - `mean.xy = clamp(mean.xy * (-1.0 / mean.z), -tan_fov * 1.3, tan_fov * 1.3)`.
   - `jacobian = mat3(focal.x, 0, 0, 0, focal.y, 0, focal.x * mean.x, focal.y * mean.y, 0)`.
   - `screen_transform = jacobian * view_linear`.
   - `cov_2d = screen_transform * cov_3d * transpose(screen_transform)`.
   - Result: `vec3(cov_2d[0][0] + 0.3, cov_2d[0][1], cov_2d[1][1] + 0.3)`.
9. **Determinant Check:** `det = covariance.x * covariance.z - covariance.y * covariance.y`. If `det == 0.0`, return.
10. **Eigenvalues:** `mid = 0.5 * (covariance.x + covariance.z)`. `eigenvalues = mid + vec2(1, -1) * sqrt(max(0.1, mid * mid - det))`. If `any(eigenvalues < 0)`, return.
11. **Image Position:** `ndc_pos = clip_pos.xyz / clip_pos.w`. `image_pos = ((ndc_pos.xy + 1.0) * 0.5 - vec2(1, 0.75) * (1.0 - time_factor)) * (dims - 1)`.
12. **Radius:** `radius = pow(splat_opacity, 0.2) * 2.5 * sqrt(max(eigenvalues.x, eigenvalues.y))`.
13. **Tile Bounds:** `grid_size = (dims + TILE_SIZE - 1) / TILE_SIZE`. `rect_bounds = get_rect(image_pos, radius, grid_size)`.
    - `get_rect` returns `uvec4(clamp((image_pos - radius) / TILE_SIZE, vec2(0), grid_size), clamp(ceil((image_pos + radius) / TILE_SIZE), vec2(0), grid_size))`.
14. **Tile Count:** `num_tiles_touched = (rect_bounds.z - rect_bounds.x) * (rect_bounds.w - rect_bounds.y)`. If `num_tiles_touched == 0`, return.
15. **Atomic Sort Buffer:** `buffer_size = atomicAdd(sort_buffer_size, num_tiles_touched)`. `sort_buffer_offset = buffer_size`.
16. **View Direction:** `view_dir = normalize(inverse(object_linear) * (world_pos.xyz - camera_pos))`.
17. **Base Color:** `base_color = get_color(view_dir, splat.sh_coefficients)`. Evaluates SH up to degree 3.
18. **Relighting:** If `instance_relight[instance_id * 2].w > 0.5`:
    - If `instance_relight[instance_id * 2].z > 0.5`, `base_color = max(0.0, 0.5 + splat.sh_coefficients[0..2] * SH_C0)`.
    - Else, `base_color *= relight_factor(...)`.
19. **Fill RasterizeData:**
    - `data.image_pos = image_pos`.
    - `data.conic = vec3(covariance.z, -covariance.y, covariance.x) / det`.
    - `data.color = vec4(base_color, splat_opacity)`.
    - `data.pos_xy = world_pos.xy`.
    - `data.pos_z = world_pos.z`.
    - `data.depth_data = vec4(-view_pos.z, 0, 0, 0)`.
    - Write to `culled_buffer[id]`.
20. **Sorting Keys:**
    - `view_depth = max(0.0, clip_pos.w)`.
    - `depth01 = view_depth / (1.0 + view_depth)`.
    - `depth = uint(depth01 * 65535.0) & 0xFFFF`.
    - Loop `y` from `rect_bounds.y` to `rect_bounds.w`, `x` from `rect_bounds.x` to `rect_bounds.z`:
      - `tile_id = y * grid_size.x + x`.
      - `key = (tile_id << 16) | depth`.
      - `sort_keys[sort_buffer_offset] = key`.
      - `sort_values[sort_buffer_offset] = id`.
      - `sort_buffer_offset++`.

**Pseudocode:**
```python
def gaussian_splat_projection_and_sorting(id, point_count, splat_buffer, instance_data, model_matrices, view_matrix, projection_matrix, camera_pos, time, dims, light_rig, instance_relight, splat_lighting, sort_buffer_size, sort_keys, sort_values, culled_buffer, grid_dims):
    if id >= point_count:
        return

    # Barrier implied in GPU implementation
    instance_id = instance_data[id].x
    unique_splat_index = instance_data[id].y

    splat = splat_buffer[unique_splat_index]
    model_matrix = model_matrices[instance_id]

    # Visibility check
    if model_matrix[0][3] < 0.5:
        return
    model_matrix[0][3] = 0.0

    # Frustum culling
    object_linear = model_matrix[:3, :3]
    world_covariance = object_linear @ decode_covariance(splat.covariance) @ object_linear.T
    world_pos = model_matrix @ vec4(splat.position, 1.0)
    view_pos = view_matrix @ world_pos
    clip_pos = projection_matrix @ view_pos
    view_bounds = clip_pos.w * 1.2
    if any(clip_pos.xyz < -view_bounds) or any(clip_pos.xyz > vec3(view_bounds, clip_pos.w)):
        return

    # Time animation
    splat_time = time - splat.time
    time_factor = ease_out_cubic(clamp(splat_time, 0, 1))
    time_factor_late = ease_out_cubic(clamp(splat_time - 0.35, 0, 1))
    splat_opacity = splat.opacity * time_factor_late * time_factor_late
    splat_scale = mix(2.0, 1.0, time_factor_late)

    # Project covariance
    cov_3d = world_covariance * (splat_scale ** 2)
    tan_fov_inv = vec2(projection_matrix[0][0], projection_matrix[1][1])
    focal = (dims - 1) * 0.5 * tan_fov_inv * (-1.0 / view_pos.z)
    mean_xy = clamp(view_pos.xy * (-1.0 / view_pos.z), -tan_fov * 1.3, tan_fov * 1.3)
    jacobian = mat3(focal.x, 0, 0, 0, focal.y, 0, focal.x * mean_xy.x, focal.y * mean_xy.y, 0)
    screen_transform = jacobian @ view_matrix[:3, :3]
    cov_2d = screen_transform @ cov_3d @ screen_transform.T
    covariance = vec3(cov_2d[0][0] + 0.3, cov_2d[0][1], cov_2d[1][1] + 0.3)

    # Determinant and eigenvalues
    det = covariance.x * covariance.z - covariance.y ** 2
    if det == 0.0:
        return
    mid = 0.5 * (covariance.x + covariance.z)
    eigenvalues = mid + vec2(1, -1) * sqrt(max(0.1, mid ** 2 - det))
    if any(eigenvalues < 0):
        return

    # Image position
    ndc_pos = clip_pos.xyz / clip_pos.w
    image_pos = ((ndc_pos.xy + 1.0) * 0.5 - vec2(1, 0.75) * (1.0 - time_factor)) * (dims - 1)

    # Radius
    radius = (splat_opacity ** 0.2) * 2.5 * sqrt(max(eigenvalues.x, eigenvalues.y))

    # Tile bounds
    grid_size = (dims + TILE_SIZE - 1) / TILE_SIZE
    rect_bounds = get_rect(image_pos, radius, grid_size)
    num_tiles_touched = (rect_bounds.z - rect_bounds.x) * (rect_bounds.w - rect_bounds.y)
    if num_tiles_touched == 0:
        return

    # Atomic sort buffer
    buffer_size = atomic_add(sort_buffer_size, num_tiles_touched)
    sort_buffer_offset = buffer_size

    # View direction and color
    view_dir = normalize(inverse(object_linear) @ (world_pos.xyz - camera_pos))
    base_color = get_color(view_dir, splat.sh_coefficients)

    # Relighting
    if instance_relight[instance_id * 2].w > 0.5:
        if instance_relight[instance_id * 2].z > 0.5:
            base_color = max(0.0, 0.5 + splat.sh_coefficients[0:3] * SH_C0)
        else:
            base_color *= relight_factor(unique_splat_index, world_pos.xyz, object_linear, instance_relight[instance_id * 2].xyz)

    # Fill RasterizeData
    data = RasterizeData()
    data.image_pos = image_pos
    data.conic = vec3(covariance.z, -covariance.y, covariance.x) / det
    data.color = vec4(base_color, splat_opacity)
    data.pos_xy = world_pos.xy
    data.pos_z = world_pos.z
    data.depth_data = vec4(-view_pos.z, 0, 0, 0)
    culled_buffer[id] = data

    # Sorting keys
    view_depth = max(0.0, clip_pos.w)
    depth01 = view_depth / (1.0 + view_depth)
    depth = uint(depth01 * 65535.0) & 0xFFFF
    for y in range(rect_bounds.y, rect_bounds.w):
        for x in range(rect_bounds.x, rect_bounds.z):
            tile_id = y * grid_size.x + x
            key = (tile_id << 16) | depth
            sort_keys[sort_buffer_offset] = key
            sort_values[sort_buffer_offset] = id
            sort_buffer_offset += 1
```

**Edge Cases and Pitfalls:**
- **Precision:** Use `float` for covariance and depth calculations. Clamp values to avoid NaNs.
- **Boundaries:** Handle edge cases where `det` is zero or eigenvalues are negative.
- **Degenerate Input:** If `num_tiles_touched` is zero, skip the splat.

## Subtopics

## Operating characteristics
- **Time Complexity:** O(N) for N splats, with additional O(T) for tile sorting preparation, where T is the number of tiles touched.
- **Memory Complexity:** O(N) for `CulledBuffer`, O(T) for `SortKeysBuffer` and `SortValuesBuffer`.
- **Performance:** Efficient for large numbers of splats due to parallel compute shader execution.
- **Strengths:** Handles complex transformations, lighting, and sorting in a single pass.
- **Limitations:** Requires careful tuning of parameters like `TILE_SIZE` and `view_bounds`.

## Background
Originated in the context of 3D Gaussian Splatting rendering pipelines, specifically in implementations like [S1, unofficial] and [S2]. It is used to prepare splats for efficient tile-based rasterization.
