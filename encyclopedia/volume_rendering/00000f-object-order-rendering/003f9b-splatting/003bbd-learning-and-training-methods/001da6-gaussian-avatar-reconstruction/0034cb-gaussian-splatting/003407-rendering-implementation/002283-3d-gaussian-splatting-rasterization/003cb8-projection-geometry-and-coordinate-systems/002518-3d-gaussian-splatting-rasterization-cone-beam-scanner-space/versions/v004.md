# 3D Gaussian Splatting Rasterization (Cone-Beam/Scanner Space)

Also called: Cone-beam Gaussian Rasterization, Radiative Gaussian Projection, Transformation module in X-ray rasterization, X-ray Rasterization

## Overview
This method renders X-ray projections by integrating 3D Gaussian primitives along cone-beam ray paths, resulting in a sum of 2D Gaussians rather than the alpha-compositing used in standard natural-light imaging [S1]. It adapts the 3D Gaussian Splatting pipeline to cone-beam CT geometry by transforming Gaussians from world space to a local "scanner space" where viewing rays are parallel to the third coordinate axis, enabling analytical integration [S1]. Unlike standard splatting which composites opacities, this method sums projected densities, fundamentally solving the integration bias inherent in learning 3D densities from 2D projections [S1].

## How it works
**Inputs:**
*   Set of $M$ 3D Gaussians, each defined by mean position $\mathbf{p}_i \in \mathbb{R}^3$, covariance matrix $\boldsymbol{\Sigma}_i \in \mathbb{R}^{3 \times 3}$, and scalar density $\rho_i$.
*   Scanner parameters: Detector physical size $(D_x, D_y)$, distance from source to detector $L_{SD}$, distance from source to object $L_{SO}$, and rotation angle $\theta$ [S1].

**Outputs:**
*   2D projection image $I_r(\mathbf{r})$ representing the X-ray intensity at each detector pixel [S1].

**Data Structures:**
*   **Gaussian Primitive:** Stores $\mathbf{p}_i$, $\boldsymbol{\Sigma}_i$, $\rho_i$.
*   **Scanner Space:** A local coordinate system with origin at the X-ray source and z-axis pointing to the projection center [S1].

**Steps:**

1.  **Define Scanner Geometry:**
    Calculate the Field of View (FOV) based on detector size and source-detector distance [S1]:
    $$ \text{FOV}_x = 2 \cdot \arctan\left(\frac{D_x}{2 L_{SD}}\right), \quad \text{FOV}_y = 2 \cdot \arctan\left(\frac{D_y}{2 L_{SD}}\right) $$
    [S1].

2.  **World-to-Scanner Transformation:**
    Transform the Gaussian from world space to scanner space using a transformation matrix $\mathbf{T}$ [S1]. The matrix $\mathbf{T}$ is composed of a rotation matrix $\mathbf{W}$ and translation vector $\mathbf{t}$ [S1]:
    $$ \mathbf{T} = \begin{bmatrix} \mathbf{W} & \mathbf{t} \\ \mathbf{0}^\top & 1 \end{bmatrix} $$
    where $\mathbf{W}$ and $\mathbf{t}$ are defined as [S1]:
    $$ \mathbf{W} = \begin{bmatrix} 1 & 0 & 0 \\ 0 & -\cos\theta & -\sin\theta \\ 0 & \sin\theta & -\cos\theta \end{bmatrix}, \quad \mathbf{t} = \begin{bmatrix} 0 \\ L_{SO} \\ 0 \end{bmatrix} $$
    [S1]. The position transforms as $\tilde{\mathbf{p}}_i = \mathbf{T} \mathbf{p}_i$ (homogeneous coordinates implied) [S1].

3.  **Local Affine Approximation (Ray Space):**
    Apply a local affine approximation to map the Gaussian to "ray space" where rays are parallel to the z-axis [S1]. This involves a Jacobian matrix $\mathbf{J}_i$ [S1]. The covariance in ray space $\tilde{\boldsymbol{\Sigma}}_i$ is computed as [S1]:
    $$ \tilde{\boldsymbol{\Sigma}}_i = \mathbf{J}_i \mathbf{W} \boldsymbol{\Sigma}_i \mathbf{W}^\top \mathbf{J}_i^\top $$
    [S1]. The position in ray space is $\tilde{\mathbf{p}}_i = \phi(\mathbf{p}_i)$, where $\phi$ is the projective mapping derived from the FOV [S1]. The Jacobian $\mathbf{J}_i$ is determined following the method in [69] (Ewa Splatting) [S1].

4.  **Projection to 2D Gaussian:**
    Integrate the 3D Gaussian along the ray path (z-axis in ray space). This yields a 2D Gaussian distribution [S1]. The 2D parameters $\hat{\mathbf{p}}_i$ and $\hat{\boldsymbol{\Sigma}}_i$ are obtained by dropping the third row and column of $\tilde{\mathbf{p}}_i$ and $\tilde{\boldsymbol{\Sigma}}_i$, respectively [S1]:
    $$ \hat{\mathbf{p}}_i = [\tilde{p}_{i,0}, \tilde{p}_{i,1}]^\top, \quad \hat{\boldsymbol{\Sigma}}_i = \begin{bmatrix} \tilde{\Sigma}_{i,00} & \tilde{\Sigma}_{i,01} \\ \tilde{\Sigma}_{i,10} & \tilde{\Sigma}_{i,11} \end{bmatrix} $$
    [S1].

5.  **Density Scaling (Radiative Correction):**
    Compute the projected central density $\hat{\rho}_i$. Unlike standard 3DGS which treats opacity as a learned scalar, this method scales the original 3D density $\rho_i$ by a factor $\mu_i$ dependent on the covariance determinants [S1]:
    $$ \mu_i = \sqrt{\frac{2\pi |\tilde{\boldsymbol{\Sigma}}_i|}{|\hat{\boldsymbol{\Sigma}}_i|}} $$
    $$ \hat{\rho}_i = \mu_i \rho_i $$
    [S1]. This scaling ensures that $\rho_i$ represents the actual 3D density, avoiding integration bias where different views would yield inconsistent density retrievals [S1].

6.  **Rasterization:**
    Render the image by summing the resulting 2D Gaussians [S1]:
    $$ I_r(\mathbf{r}) = \sum_{i=1}^{M} G_{2i}(\hat{\mathbf{x}} | \hat{\rho}_i, \hat{\mathbf{p}}_i, \hat{\boldsymbol{\Sigma}}_i) $$
    [S1]. The 2D Gaussian function is defined as [S1]:
    $$ G_{2i}(\hat{\mathbf{x}}) = \frac{\hat{\rho}_i}{2\pi |\hat{\boldsymbol{\Sigma}}_i|^{1/2}} \exp\left(-\frac{1}{2} (\hat{\mathbf{x}} - \hat{\mathbf{p}}_i)^\top \hat{\boldsymbol{\Sigma}}_i^{-1} (\hat{\mathbf{x}} - \hat{\mathbf{p}}_i)\right) $$
    [S1].

**Edge Cases and Pitfalls:**
*   **Integration Bias:** If standard 3DGS is used (learning opacity directly), retrieving the 3D density from 2D projections leads to inconsistency because different views yield different results for the same 3D density due to the covariance-dependent scaling factor $\mu_i$ [S1]. This method solves that by assigning the actual 3D density $\rho_i$ and forward-computing the projection [S1].
*   **Singular Covariance:** If $|\tilde{\boldsymbol{\Sigma}}_i|$ or $|\hat{\boldsymbol{\Sigma}}_i|$ is zero or negative (degenerate Gaussian), the density scaling factor $\mu_i$ is undefined. Guard clauses are required [G].
*   **Jacobian Calculation:** The exact form of $\mathbf{J}_i$ is referenced from [69] (Ewa Splatting) but not explicitly derived in [S1]. Implementers must refer to [69] for the precise Jacobian computation for the local affine approximation [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of Gaussians $M$ and the number of pixels covered by each Gaussian's 2D projection. The transformation and integration steps are $O(1)$ per Gaussian.
*   **Memory Complexity:** $O(M)$ to store the Gaussian primitives.
*   **Strengths:**
    *   Provides physically consistent X-ray projections by integrating 3D density along rays [S1].
    *   Solves the integration bias problem inherent in standard 3DGS when applied to tomographic reconstruction [S1].
    *   Uses efficient 2D Gaussian rasterization similar to standard 3DGS [S1].
*   **Limitations:**
    *   Requires accurate scanner geometry parameters ($L_{SD}, L_{SO}, \theta$) [S1].
    *   Relies on the local affine approximation (Ewa Splatting), which may introduce artifacts if the Gaussian is large relative to the curvature of the projection surface [S1, S69].
    *   Not suitable for standard natural-light imaging where alpha-compositing is required [S1].

## Background
This method was introduced in the context of **R$^2$-Gaussian: Rectifying Radiative Gaussian Splatting for Tomographic Reconstruction** [S1]. It adapts the 3D Gaussian Splatting rendering pipeline [23] to cone-beam CT simulation. The core insight is that X-ray projection is an integral of density along rays, which for Gaussians results in a 2D Gaussian distribution. This differs from standard 3DGS which composites opacities for natural light [S1]. The transformation module follows the principles of Ewa Splatting [69] for handling projective transformations of Gaussians.
