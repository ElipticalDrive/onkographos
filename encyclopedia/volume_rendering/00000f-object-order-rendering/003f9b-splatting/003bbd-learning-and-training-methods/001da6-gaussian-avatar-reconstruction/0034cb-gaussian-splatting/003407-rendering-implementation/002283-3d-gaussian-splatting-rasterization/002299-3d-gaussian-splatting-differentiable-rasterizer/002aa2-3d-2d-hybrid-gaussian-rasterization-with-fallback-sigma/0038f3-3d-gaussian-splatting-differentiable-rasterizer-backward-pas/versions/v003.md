# 3D Gaussian Splatting Differentiable Rasterizer > Backward Pass

Also called: ToF Gaussian Rasterization Backward Pass

## Overview
The backward pass computes gradients of the rasterization loss with respect to 3D Gaussian parameters and camera settings, enabling end-to-end differentiable training of Gaussian Avatars [S1, unofficial]. It extends the standard 3D Gaussian Splatting differentiable rasterizer [Parent](4812-3d-2d-hybrid-gaussian-rasterization-with-fallback-sigma.md) to support Time-of-Flight (ToF) phase data and depth, returning gradients for color, phasor, depth, normal, and accumulated opacity channels [S1, unofficial].

## How it works
The backward pass reconstructs the forward pass context from saved tensors, restructures arguments for the CUDA kernel, and invokes the C++/CUDA implementation to compute gradients [S1, unofficial].

### Data Structures
The backward pass relies on buffers saved during the forward pass [S1, unofficial]. Internal field layouts and bit packing for `geomBuffer`, `binningBuffer`, and `imgBuffer` are Not given in the sources [S1, unofficial]. The tensors `colors_precomp`, `phasors_precomp`, `means3D`, `scales`, `rotations`, `cov3Ds_precomp`, `radii`, `sh`, and `sh_p` are saved directly from the forward pass [S1, unofficial].

### Steps
1. **Restore Context**: Retrieve `num_rendered`, `raster_settings`, and all saved tensors (`colors_precomp`, `phasors_precomp`, `means3D`, `scales`, `rotations`, `cov3Ds_precomp`, `radii`, `sh`, `sh_p`, `geomBuffer`, `binningBuffer`, `imgBuffer`) from the autograd context. Retrieve `phase_offset` and `dc_offset` [S1, unofficial].
2. **Restructure Arguments**: Pack arguments into a tuple for the backward C++/CUDA call in the exact order: `raster_settings.bg`, `means3D`, `radii`, `colors_precomp`, `phasors_precomp`, `scales`, `rotations`, `raster_settings.scale_modifier`, `cov3Ds_precomp`, `raster_settings.viewmatrix`, `raster_settings.projmatrix`, `raster_settings.tanfovx`, `raster_settings.tanfovy`, `grad_out_color`, `grad_out_phasor`, `grad_out_depth`, `grad_out_normal`, `grad_out_acc`, `grad_entropy`, `grad_depth_distortion`, `grad_amp_distortion`, `sh`, `sh_p`, `raster_settings.sh_degree`, `raster_settings.campos`, `geomBuffer`, `num_rendered`, `binningBuffer`, `imgBuffer`, `raster_settings.debug`, `raster_settings.near_n`, `raster_settings.far_n`, `raster_settings.depth_range`, `raster_settings.use_view_dependent_phase`, `phase_offset`, `dc_offset` [S1, unofficial].
3. **Invoke CUDA Kernel**: Call the backward rasterization function `_C.rasterize_gaussians_backward(*args)` [S1, unofficial].
4. **Construct Gradients Tuple**: Return gradients in the order matching the forward pass inputs. Gradients for `phase_offset` and `dc_offset` are returned as `None` if their respective optimization flags (`optimize_phase_offset`, `optimize_dc_offset`) are false [S1, unofficial].

### Pseudocode
```python
def backward(ctx, grad_out_color, grad_out_phasor, grad_out_depth, grad_out_normal, grad_out_acc, grad_entropy, grad_depth_distortion, grad_amp_distortion):
    # 1. Restore context values [S1, unofficial]
    num_rendered = ctx.num_rendered
    raster_settings = ctx.raster_settings
    saved_tensors = ctx.saved_tensors
    colors_precomp = saved_tensors[0]
    phasors_precomp = saved_tensors[1]
    means3D = saved_tensors[2]
    scales = saved_tensors[3]
    rotations = saved_tensors[4]
    cov3Ds_precomp = saved_tensors[5]
    radii = saved_tensors[6]
    sh = saved_tensors[7]
    sh_p = saved_tensors[8]
    geomBuffer = saved_tensors[9]
    binningBuffer = saved_tensors[10]
    imgBuffer = saved_tensors[11]
    phase_offset = ctx.phase_offset
    dc_offset = ctx.dc_offset

    # Helper: deep copy tensors to CPU [G]
    def deep_copy_to_cpu(tensor_tuple):
        return tuple(t.detach().cpu().clone() if hasattr(t, 'detach') else t for t in tensor_tuple)

    # Helper: save snapshot to file [G]
    def save_snapshot(path, data):
        import pickle
        with open(path, 'wb') as f:
            pickle.dump(data, f)

    # 2. Restructure arguments for the backward C++/CUDA call [S1, unofficial]
    args = (
        raster_settings.bg, means3D, radii, colors_precomp, phasors_precomp,
        scales, rotations, raster_settings.scale_modifier, cov3Ds_precomp,
        raster_settings.viewmatrix, raster_settings.projmatrix,
        raster_settings.tanfovx, raster_settings.tanfovy,
        grad_out_color, grad_out_phasor, grad_out_depth, grad_out_normal,
        grad_out_acc, grad_entropy, grad_depth_distortion, grad_amp_distortion,
        sh, sh_p, raster_settings.sh_degree, raster_settings.campos,
        geomBuffer, num_rendered, binningBuffer, imgBuffer,
        raster_settings.debug, raster_settings.near_n, raster_settings.far_n,
        raster_settings.depth_range, raster_settings.use_view_dependent_phase,
        phase_offset, dc_offset
    )

    # 3. Invoke the C++/CUDA backward rasterization function [S1, unofficial]
    if raster_settings.debug:
        args_cpu = deep_copy_to_cpu(args)
        try:
            grad_outputs = _C.rasterize_gaussians_backward(*args)
        except Exception as e:
            save_snapshot('snapshot_bw.dump', args_cpu)
            raise e
    else:
        grad_outputs = _C.rasterize_gaussians_backward(*args)

    # 4. Construct the gradients tuple to return to PyTorch [S1, unofficial]
    grad_means3D = grad_outputs[0]
    grad_means2D = grad_outputs[1]
    grad_sh = grad_outputs[2]
    grad_sh_p = grad_outputs[3]
    grad_colors_precomp = grad_outputs[4]
    grad_phasors_precomp = grad_outputs[5]
    grad_opacities = grad_outputs[6]
    grad_scales = grad_outputs[7]
    grad_rotations = grad_outputs[8]
    grad_cov3Ds_precomp = grad_outputs[9]

    if ctx.optimize_phase_offset:
        grad_phase_offset = grad_outputs[10]
    else:
        grad_phase_offset = None

    if ctx.optimize_dc_offset:
        grad_dc_offset = grad_outputs[11]
    else:
        grad_dc_offset = None

    return (
        grad_means3D, grad_means2D, grad_sh, grad_sh_p, grad_colors_precomp,
        grad_phasors_precomp, grad_opacities, grad_scales, grad_rotations,
        grad_cov3Ds_precomp, grad_phase_offset, grad_dc_offset, None
    )
```

### Edge Cases and Pitfalls
- **Debug Mode**: If `raster_settings.debug` is true, arguments are deep-copied to CPU before invocation. If an exception is raised, the CPU copy is saved to `snapshot_bw.dump` and printed [S1, unofficial].
- **Gradient Order**: The order of returned gradients must match the input arguments of the forward function [S1, unofficial].
- **Phase/DC Offset**: Gradients for `phase_offset` and `dc_offset` are returned as `None` if their respective optimization flags are false [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Not given in the sources [S1, unofficial].
- **Memory Complexity**: Not given in the sources [S1, unofficial].
- **Strengths**: Enables differentiable training of Gaussian parameters including phase and depth [S1, unofficial].
- **Limitations**: Debug mode incurs significant overhead due to CPU copying [S1, unofficial].

## Background
The backward pass is part of the 3D Gaussian Splatting rasterization implementation extended for Time-of-Flight (ToF) data, as described in the gftorf repository [S1, unofficial].
