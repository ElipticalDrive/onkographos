# 3D/2D Hybrid Gaussian Rasterization with Fallback Sigma


## Overview
This method rasterizes 3D Gaussians by dynamically selecting the tighter bounding sigma between a 3D ray-surfel intersection estimate and a pre-computed 2D screen-space fallback [S1, unofficial]. It solves the problem of inefficient culling and inaccurate bounding boxes for Gaussians that are far from the camera or highly anisotropic, ensuring that only relevant splats are processed per pixel [S1, unofficial]. It differs from standard 3D Gaussian Splatting rasterization [3D Gaussian Splatting Differentiable Rasterizer](2813-3d-gaussian-splatting-differentiable-rasterizer.md) by introducing a hybrid sigma calculation that combines 3D geometric bounds with 2D pre-computed means to improve culling accuracy [S1, unofficial].

## How it works
**Inputs:**
- `means`: 3D Gaussian means, shape $(N, 3)$ [S1, unofficial].
- `quats`: 3D Gaussian rotations (quaternions), shape $(N, 4)$ [S1, unofficial].
- `scales`: 3D Gaussian scales, shape $(N, 3)$ [S1, unofficial].
- `opacities_np`: 3D Gaussian opacities per camera, shape $(C, N)$ [S1, unofficial].
- `sh_coeffs`: Spherical Harmonics coefficients, shape $(N, 1, 3)$ for degree 0 [S1, unofficial].
- `means2d_np`: Pre-computed 2D screen-space means for each camera and Gaussian, shape $(C, N, 2)$ [S1, unofficial].
- `colors_np`: Pre-computed colors for each camera and Gaussian, shape $(C, N, 3)$ [S1, unofficial].
- `normals_np`: Pre-computed normals for each camera and Gaussian, shape $(C, N, 3)$ [S1, unofficial].
- `K`: Camera intrinsic matrix, shape $(3, 3)$ [S1, unofficial].
- `viewmat`: Camera view matrix, shape $(4, 4)$ [S1, unofficial].
- `width`, `height`: Image dimensions [S1, unofficial].
- `MAX_ALPHA`: Maximum alpha value per splat (e.g., 0.99) [S1, unofficial].
- `ALPHA_THRESHOLD`: Minimum alpha to process (e.g., 0.01) [S1, unofficial].
- `TRANSMITTANCE_THRESHOLD`: Minimum transmittance to continue compositing (e.g., 0.01) [S1, unofficial].
- `backgrounds`: Optional background color per camera, shape $(C, 3)$ [S1, unofficial].
- `tmp`: Temporary projected coordinates for each camera and Gaussian, shape $(C, N, 3)$, containing $[x, y, z]$ [S1, unofficial].

**Outputs:**
- `render_colors`: Rendered RGB image, shape $(C, H, W, 3)$ [S1, unofficial].
- `render_normals`: Rendered normal image, shape $(C, H, W, 3)$ [S1, unofficial].
- `render_alphas`: Rendered alpha image, shape $(C, H, W, 1)$ [S1, unofficial].

**Data Structures:**
- Gaussians are stored in flat arrays for batch processing [S1, unofficial].
- `means2d_np` is pre-computed by projecting `means` using `K` and `viewmat` and dividing by depth [S1, unofficial].

**Steps:**
1. Initialize `render_colors`, `render_normals`, and `render_alphas` to zero [S1, unofficial].
2. Initialize `T` (transmittance) to 1.0 for each pixel [S1, unofficial].
3. For each camera $c$:
    a. For each pixel $(py, px)$:
        i. Initialize `render_colors[c, py, px] = [0, 0, 0]`, `render_normals[c, py, px] = [0, 0, 0]` [S1, unofficial].
        ii. For each Gaussian $gid$:
            1. Calculate temporary coordinates `tmp[0]`, `tmp[1]`, `tmp[2]` from projection logic [S1, unofficial].
            2. If $|tmp[2]| < 10^{-10}$, skip the Gaussian [S1, unofficial].
            3. Calculate screen-space coordinates: $u_s = tmp[0] / tmp[2]$, $v_s = tmp[1] / tmp[2]$ [S1, unofficial].
            4. Calculate 3D sigma: $\sigma_{3d} = u_s^2 + v_s^2$ [S1, unofficial].
            5. Calculate 2D fallback sigma: $dx = px - \mu[0]$, $dy = py - \mu[1]$, $\sigma_{2d} = 2.0 \times (dx^2 + dy^2)$, where $\mu = \text{means2d\_np}[c, gid]$ [S1, unofficial].
            6. Calculate hybrid sigma: $\sigma = 0.5 \times \min(\sigma_{3d}, \sigma_{2d})$ [S1, unofficial].
            7. If $\sigma < 0.0$, skip the Gaussian [S1, unofficial].
            8. Calculate alpha: $\alpha = \min(\text{opacities\_np}[c, gid] \times \exp(-\sigma), \text{MAX\_ALPHA})$ [S1, unofficial].
            9. If $\alpha < \text{ALPHA\_THRESHOLD}$, skip the Gaussian [S1, unofficial].
            10. If $T < \text{TRANSMITTANCE\_THRESHOLD}$, break the Gaussian loop [S1, unofficial].
            11. Calculate weight: $w = T \times \alpha$ [S1, unofficial].
            12. Update color and normal: $\text{render\_colors}[c, py, px] += w \times \text{colors\_np}[c, gid]$, $\text{render\_normals}[c, py, px] += w \times \text{normals\_np}[c, gid]$ [S1, unofficial].
            13. Update transmittance: $T = T \times (1.0 - \alpha)$ [S1, unofficial].
        iii. Set `render_alphas[c, py, px, 0] = 1.0 - T` [S1, unofficial].
    b. If `backgrounds` is not None:
        i. Convert `backgrounds` to array `bg_np` [S1, unofficial].
        ii. For each camera $c$: $\text{render\_colors}[c] += (1.0 - \text{render\_alphas}[c]) \times \text{bg\_np}[c]$ [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def hybrid_gaussian_rasterization(
    means, quats, scales, opacities_np, sh_coeffs,
    means2d_np, colors_np, normals_np, tmp,
    width, height,
    MAX_ALPHA=0.99, ALPHA_THRESHOLD=0.01, TRANSMITTANCE_THRESHOLD=0.01,
    backgrounds=None
):
    C = means2d_np.shape[0]
    N = means.shape[0]
    render_colors = np.zeros((C, height, width, 3))
    render_normals = np.zeros((C, height, width, 3))
    render_alphas = np.zeros((C, height, width, 1))

    for c in range(C):
        for py in range(height):
            for px in range(width):
                T = 1.0
                current_color = np.array([0.0, 0.0, 0.0])
                current_normal = np.array([0.0, 0.0, 0.0])

                for gid in range(N):
                    # tmp[c, gid] contains [x, y, z] from projection logic [S1, unofficial]
                    t0 = tmp[c, gid, 0]
                    t1 = tmp[c, gid, 1]
                    t2 = tmp[c, gid, 2]

                    if abs(t2) < 1e-10:
                        continue

                    us = t0 / t2
                    vs = t1 / t2

                    sigma_3d = us * us + vs * vs

                    mu = means2d_np[c, gid]
                    dx = px - mu[0]
                    dy = py - mu[1]
                    sigma_2d = 2.0 * (dx * dx + dy * dy)

                    sigma = 0.5 * min(sigma_3d, sigma_2d)

                    if sigma < 0.0:
                        continue

                    alpha = min(opacities_np[c, gid] * np.exp(-sigma), MAX_ALPHA)

                    if alpha < ALPHA_THRESHOLD:
                        continue

                    if T < TRANSMITTANCE_THRESHOLD:
                        break

                    weight = T * alpha
                    current_color += weight * colors_np[c, gid]
                    current_normal += weight * normals_np[c, gid]
                    T *= (1.0 - alpha)

                render_colors[c, py, px] = current_color
                render_normals[c, py, px] = current_normal
                render_alphas[c, py, px, 0] = 1.0 - T

        if backgrounds is not None:
            bg_np = backgrounds[c]
            render_colors[c] += (1.0 - render_alphas[c, :, :, 0])[:, :, np.newaxis] * bg_np

    return render_colors, render_normals, render_alphas
```

**Parameters:**
- `MAX_ALPHA`: Typically 0.99 [S1, unofficial].
- `ALPHA_THRESHOLD`: Typically 0.01 [S1, unofficial].
- `TRANSMITTANCE_THRESHOLD`: Typically 0.01 [S1, unofficial].

**Edge Cases:**
- If $|tmp[2]| < 10^{-10}$, the Gaussian is skipped to avoid division by zero [S1, unofficial].
- If $\sigma < 0.0$, the Gaussian is skipped [S1, unofficial].
- If $T < \text{TRANSMITTANCE\_THRESHOLD}$, the loop breaks, assuming further Gaussians will have negligible contribution [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Improved culling accuracy for distant or anisotropic Gaussians, leading to fewer unnecessary alpha compositing operations [S1, unofficial].
- **Limitations:** Requires pre-computation of 2D means, colors, and normals for all cameras and Gaussians, increasing memory usage [S1, unofficial].
- **When to use:** When rendering large scenes with many Gaussians where standard 3D culling is insufficient [S1, unofficial].
- **When not to use:** When memory is constrained, as pre-computed 2D data increases memory footprint [S1, unofficial].

This method is implemented in the `gsplat-mlx` repository [S1, unofficial]. It was developed to optimize rasterization performance for Gaussian Splatting pipelines [S1, unofficial].
