# Analytic-Splatting Gradient Computation

Also called: Gradient of 2D Gaussian integral w.r.t covariance matrix, Gradient of Analytic 2D Gaussian Splat

## Overview
This method computes the exact gradient of the analytically integrated 2D Gaussian splat intensity with respect to the elements of the 2D covariance matrix $\hat{\Sigma}$ [S1]. It enables differentiable training of Gaussian splat parameters by providing the necessary gradients for the covariance components [S1]. It serves as the foundational derivative required for the backward pass of Gaussian gradients [Backward Pass for Gaussian Gradients](9003-backward-pass-for-gaussian-gradients.md).

## How it works
**Inputs:**
- The analytically integrated 2D Gaussian intensity $\mathcal{I}^{2D}_g$ [S1].
- The 2D covariance matrix $\hat{\Sigma}$, decomposed into eigenvalues $\lambda_1, \lambda_2$ and eigenvectors $\mathbf{v}_1, \mathbf{v}_2$ [S1].
- The projected mean $\hat{\mu} = (\hat{\mu}_x, \hat{\mu}_y)$ [S1].
- The pixel coordinates $(u_x, u_y)$ [S1].
- The standard deviation $\sigma_1$ associated with the first eigenvalue [S1].
- The cumulative distribution function (CDF) $S_{\sigma_2}$ for the second eigenvalue's standard deviation $\sigma_2$ [S1].
- The transformed coordinates $\tilde{u}_y$ in the eigenvector basis [S1].
- The partial derivatives of the intensity with respect to the eigenvalues $\frac{\partial \mathcal{I}^{2D}_g}{\partial \lambda_1}$ and $\frac{\partial \mathcal{I}^{2D}_g}{\partial \lambda_2}$ [S1].

**Outputs:**
- The gradient matrix $\frac{\partial \mathcal{I}^{2D}_g}{\partial \hat{\Sigma}}$, specifically the elements $\frac{\partial \mathcal{I}^{2D}_g}{\partial \hat{\Sigma}_{11}}$, $\frac{\partial \mathcal{I}^{2D}_g}{\partial \hat{\Sigma}_{12}}$, and $\frac{\partial \mathcal{I}^{2D}_g}{\partial \hat{\Sigma}_{22}}$ [S1].

**Data Structures:**
- $\hat{\Sigma}$: A $2 \times 2$ symmetric positive-definite matrix. In implementation, store as three floats: $\hat{\Sigma}_{11}, \hat{\Sigma}_{12}, \hat{\Sigma}_{22}$ [S1].
- Eigen-decomposition: $\lambda_1, \lambda_2$ (scalars), $\mathbf{v}_1 = [v_{1x}, v_{1y}]^\top$, $\mathbf{v}_2 = [v_{2x}, v_{2y}]^\top$ (vectors) [S1].

**Steps:**

1.  **Compute Eigenvalue Gradients:**
    Calculate the partial derivatives of the intensity with respect to the eigenvalues $\frac{\partial \mathcal{I}^{2D}_g}{\partial \lambda_1}$ and $\frac{\partial \mathcal{I}^{2D}_g}{\partial \lambda_2}$ [S1].
    Calculate the partial derivatives of the eigenvalues with respect to the covariance matrix elements $\frac{\partial \lambda_k}{\partial \hat{\Sigma}_{ij}}$ for $k \in \{1, 2\}$ and $(i,j) \in \{(1,1), (1,2), (2,2)\}$ using standard symmetric matrix eigenvalue derivatives [G].

2.  **Compute Eigenvector Gradients:**
    Calculate the partial derivatives of the intensity with respect to the eigenvectors $\frac{\partial \mathcal{I}^{2D}_g}{\partial \mathbf{v}_1}$ and $\frac{\partial \mathcal{I}^{2D}_g}{\partial \mathbf{v}_2}$ [S1].
    The gradient with respect to an eigenvector $\mathbf{v}_k$ is given by:
    $$
    \frac{\partial \mathcal{I}^{2D}_g}{\partial \mathbf{v}_k} = 2\pi \mathcal{I}_{\sigma 1} \left( \frac{\partial S_{\sigma_2}(\tilde{u}_y + 1/2)}{\partial \tilde{u}_y} - \frac{\partial S_{\sigma_2}(\tilde{u}_y - 1/2)}{\partial \tilde{u}_y} \right) \begin{bmatrix} u_x - \hat{\mu}_x \\ u_y - \hat{\mu}_y \end{bmatrix}
    $$
    where $\mathcal{I}_{\sigma 1}$ is the intensity component related to $\sigma_1$, and $S_{\sigma_2}$ is the CDF of a 1D Gaussian with standard deviation $\sigma_2$ [S1].
    Calculate the partial derivatives of the eigenvectors with respect to the covariance matrix elements $\frac{\partial \mathbf{v}_k}{\partial \hat{\Sigma}_{ij}}$ using standard eigenvector perturbation derivatives [G].

3.  **Apply Chain Rule:**
    For each element $\hat{\Sigma}_{ij}$ where $(i,j) \in \{(1,1), (1,2), (2,2)\}$, compute the total gradient using the chain rule:
    $$
    \frac{\partial \mathcal{I}^{2D}_g}{\partial \hat{\Sigma}_{ij}} = \frac{\partial \mathcal{I}^{2D}_g}{\partial \lambda_1} \frac{\partial \lambda_1}{\partial \hat{\Sigma}_{ij}} + \frac{\partial \mathcal{I}^{2D}_g}{\partial \lambda_2} \frac{\partial \lambda_2}{\partial \hat{\Sigma}_{ij}} + \left(\frac{\partial \mathcal{I}^{2D}_g}{\partial \mathbf{v}_1}\right)^\top \frac{\partial \mathbf{v}_1}{\partial \hat{\Sigma}_{ij}} + \left(\frac{\partial \mathcal{I}^{2D}_g}{\partial \mathbf{v}_2}\right)^\top \frac{\partial \mathbf{v}_2}{\partial \hat{\Sigma}_{ij}}
    $$
    [S1]

**Parameters:**
- $\sigma_1, \sigma_2$: Standard deviations derived from the scale parameters of the 3D Gaussian [S1].
- $\tilde{u}_y$: The y-coordinate of the pixel center in the local coordinate system defined by the eigenvectors [S1].

**Edge Cases and Pitfalls:**
- **Degenerate Covariance:** If the covariance matrix is singular or near-singular, eigenvalue decomposition may become unstable [G]. Guard against zero or negative eigenvalues [G].
- **Boundary Conditions:** The term involving the CDF derivatives $\frac{\partial S_{\sigma_2}}{\partial \tilde{u}_y}$ represents the boundary contributions [S1]. Ensure the CDF and its derivative (PDF) are evaluated correctly at $\tilde{u}_y \pm 1/2$ [S1].
- **Precision:** The subtraction of CDF derivatives can lead to cancellation errors if the pixel is far from the Gaussian center [G]. Use high-precision arithmetic if necessary [G].

**Pseudocode:**
```python
import math

def pdf_gaussian(x, sigma):
    """Probability density function of N(0, sigma^2)."""
    return (1.0 / (math.sqrt(2 * math.pi) * sigma)) * math.exp(-x**2 / (2 * sigma**2))

def compute_analytic_splatting_gradient(I_2D_g, lambda_1, lambda_2, v_1, v_2, u_x, u_y, mu_hat_x, mu_hat_y, sigma_1, sigma_2, sigma_1_intensity, dI_d_lambda_1, dI_d_lambda_2, a, b, c):
    """
    Computes the gradient of the analytic 2D Gaussian intensity w.r.t. the 2D covariance matrix elements.
    
    Args:
        I_2D_g: Scalar, the integrated intensity.
        lambda_1, lambda_2: Scalars, eigenvalues of the 2D covariance matrix.
        v_1, v_2: Vectors [2], eigenvectors of the 2D covariance matrix.
        u_x, u_y: Scalars, pixel coordinates.
        mu_hat_x, mu_hat_y: Scalars, projected mean coordinates.
        sigma_1, sigma_2: Scalars, standard deviations corresponding to eigenvalues.
        sigma_1_intensity: Scalar, intensity component related to sigma_1.
        dI_d_lambda_1, dI_d_lambda_2: Scalars, partial derivatives of intensity w.r.t eigenvalues.
        a, b, c: Scalars, covariance matrix elements Sigma_11, Sigma_12, Sigma_22.
        
    Returns:
        grad_Sigma_11, grad_Sigma_12, grad_Sigma_22: Scalars, gradients w.r.t. covariance matrix elements.
    """
    
    # Step 1: Compute eigenvalue derivatives d_lambda/d_Sigma
    Delta = math.sqrt(((a - c) / 2)**2 + b**2)
    if Delta < 1e-9:
        # Degenerate case: eigenvalues are equal, gradients are undefined
        return 0.0, 0.0, 0.0
        
    dDelta_da = (a - c) / (4 * Delta)
    dDelta_db = b / Delta
    dDelta_dc = -(a - c) / (4 * Delta)
    
    dL1_da = 0.5 + dDelta_da
    dL1_db = dDelta_db
    dL1_dc = 0.5 + dDelta_dc
    
    dL2_da = 0.5 - dDelta_da
    dL2_db = -dDelta_db
    dL2_dc = 0.5 - dDelta_dc
    
    # Step 2: Compute eigenvector gradients dI/d_v
    diff_u = [u_x - mu_hat_x, u_y - mu_hat_y]
    tilde_u_y = v_2[0] * diff_u[0] + v_2[1] * diff_u[1]
    
    boundary_term = pdf_gaussian(tilde_u_y + 0.5, sigma_2) - pdf_gaussian(tilde_u_y - 0.5, sigma_2)
    factor = 2 * math.pi * sigma_1_intensity * boundary_term
    dI_d_v = [factor * diff_u[0], factor * diff_u[1]]
    
    # Step 3: Compute eigenvector derivatives d_v/d_Sigma using perturbation formula
    # dv_k/d_Sigma_ij = (1/(lambda_k - lambda_l)) * (v_l^T * dSigma/d_Sigma_ij * v_k) * v_l
    inv_diff_lambda = 1.0 / (lambda_1 - lambda_2)
    
    # dSigma/d_Sigma_11 = [[1, 0], [0, 0]]
    dot_v2_dS11_v1 = v_2[0] * v_1[0]
    dv1_da = inv_diff_lambda * dot_v2_dS11_v1 * v_2[0]
    dv2_da = inv_diff_lambda * dot_v2_dS11_v1 * v_1[0]
    
    # dSigma/d_Sigma_12 = [[0, 1], [1, 0]]
    dot_v2_dS12_v1 = v_2[0] * v_1[1] + v_2[1] * v_1[0]
    dv1_db = inv_diff_lambda * dot_v2_dS12_v1 * v_2[0]
    dv2_db = inv_diff_lambda * dot_v2_dS12_v1 * v_1[0]
    
    # dSigma/d_Sigma_22 = [[0, 0], [0, 1]]
    dot_v2_dS22_v1 = v_2[1] * v_1[1]
    dv1_dc = inv_diff_lambda * dot_v2_dS22_v1 * v_2[0]
    dv2_dc = inv_diff_lambda * dot_v2_dS22_v1 * v_1[0]
    
    # Step 4: Apply chain rule
    dot_v1_da = dI_d_v[0] * dv1_da + dI_d_v[1] * dv2_da
    dot_v1_db = dI_d_v[0] * dv1_db + dI_d_v[1] * dv2_db
    dot_v1_dc = dI_d_v[0] * dv1_dc + dI_d_v[1] * dv2_dc
    
    grad_Sigma_11 = dI_d_lambda_1 * dL1_da + dI_d_lambda_2 * dL2_da + dot_v1_da
    grad_Sigma_12 = dI_d_lambda_1 * dL1_db + dI_d_lambda_2 * dL2_db + dot_v1_db
    grad_Sigma_22 = dI_d_lambda_1 * dL1_dc + dI_d_lambda_2 * dL2_dc + dot_v1_dc
    
    return grad_Sigma_11, grad_Sigma_12, grad_Sigma_22
```

## Subtopics

### [Backward Pass for Gaussian Gradients](9003-backward-pass-for-gaussian-gradients.md)
Computes the exact gradient of a scalar loss $L$ with respect to the input 3D Gaussian parameters (color $c$, opacity $o$, mean $\mu$, scale $s$, rotation $q$) by propagating pixel gradients backward through the alpha-compositing rasterizer. It enables differentiable training of Gaussian splat parameters by providing gradients for all learnable variables required for optimization. Unlike the forward pass which composites colors front-to-back, this method propagates gradients back-to-front to correctly account for occlusion and transparency.

## Operating characteristics
- **Time Complexity:** The computation involves eigen-decomposition and several vector operations [G]. It is $O(1)$ per splat per pixel, but the eigen-decomposition adds a constant overhead compared to simple point-sampling gradients [G].
- **Memory Complexity:** $O(1)$ per splat, storing intermediate gradient values [G].
- **Strengths:** Provides exact gradients for the analytic integration, leading to better convergence and reduced aliasing artifacts during training [S1].
- **Limitations:** More complex to implement than standard rasterizer gradients due to the need for eigenvalue/eigenvector derivatives [G].
- **When to use:** When training 3D Gaussian Splatting models with the Analytic-Splatting forward pass to ensure gradient consistency [S1].

## Background
The method originates from the "Analytic-Splatting: Anti-Aliased 3D Gaussian Splatting via Analytic Integration" paper [S1]. It was developed to address the aliasing issues in standard 3D Gaussian Splatting by providing a differentiable analytic integration of the Gaussian over the pixel area [S1]. The gradient computation is a key component of this method, enabling end-to-end training [S1].
