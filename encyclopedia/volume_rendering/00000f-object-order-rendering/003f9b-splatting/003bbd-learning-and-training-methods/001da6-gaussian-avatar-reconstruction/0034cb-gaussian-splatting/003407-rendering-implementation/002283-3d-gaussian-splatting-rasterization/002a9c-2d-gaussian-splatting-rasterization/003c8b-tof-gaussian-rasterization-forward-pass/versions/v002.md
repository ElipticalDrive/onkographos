# ToF Gaussian Rasterization Forward Pass

Also called: ToF Gaussian Rasterization

## Overview
This method implements the forward pass of the C++/CUDA rasterizer for Time-of-Flight Gaussian Splatting [S1, unofficial]. It restructures scene and camera parameters into a single tuple, invokes the CUDA kernel, and returns rendered maps including color, phasor, depth, and auxiliary buffers [S1, unofficial].

## How it works
**Inputs:** `raster_settings` (camera and rendering parameters), `gaussians` (model attributes), and `training_args` (optimization flags) [S1, unofficial].

**Data Structures:** The method packs all inputs into a single tuple passed to the CUDA kernel [S1, unofficial]. The tuple layout is:
1. `raster_settings.bg`
2. `means3D`
3. `colors_precomp`
4. `phasors_precomp`
5. `opacities`
6. `scales`
7. `rotations`
8. `raster_settings.scale_modifier`
9. `cov3Ds_precomp`
10. `raster_settings.viewmatrix`
11. `raster_settings.projmatrix`
12. `raster_settings.tanfovx`
13. `raster_settings.tanfovy`
14. `raster_settings.image_height`
15. `raster_settings.image_width`
16. `sh`
17. `sh_p`
18. `raster_settings.sh_degree`
19. `raster_settings.campos`
20. `raster_settings.prefiltered`
21. `raster_settings.debug`
22. `raster_settings.near_n`
23. `raster_settings.far_n`
24. `raster_settings.depth_range`
25. `raster_settings.use_view_dependent_phase`
26. `phase_offset`
27. `dc_offset` [S1, unofficial].

**Parameters:** `phase_offset` and `dc_offset` are scalar values used for offset correction [S1, unofficial]. If `raster_settings.optimize_phase_offset` (or `optimize_dc_offset`) is true, the raw tensor is used; otherwise, it is detached, converted to a CPU numpy array, and cast to a Python scalar [S1, unofficial].

**Steps:**
1. Restructure arguments into the tuple defined above, applying the offset handling logic [S1, unofficial].
2. If `raster_settings.debug` is true, deep-copy all arguments to CPU before invocation to preserve state for debugging [S1, unofficial].
3. Invoke the C++/CUDA forward rasterization function `_C.rasterize_gaussians(*args)` [S1, unofficial].
4. Save relevant tensors for the backward pass: `raster_settings`, `num_rendered`, `colors_precomp`, `phasors_precomp`, `means3D`, `scales`, `rotations`, `cov3Ds_precomp`, `radii`, `sh`, `sh_p`, `geomBuffer`, `binningBuffer`, `imgBuffer`, `phase_offset`, `dc_offset` [S1, unofficial].

**Pseudocode:**
```python
import copy
import torch

def forward_pass(raster_settings, gaussians, training_args):
    # 1. Restructure arguments
    phase_offset = gaussians.get_phase_offset if training_args.optimize_phase_offset else gaussians.get_phase_offset.detach().cpu().numpy().item()
    dc_offset = gaussians.get_dc_offset if training_args.optimize_dc_offset else gaussians.get_dc_offset.detach().cpu().numpy().item()
    args = (
        raster_settings.bg, gaussians.means3D, gaussians.colors_precomp,
        gaussians.phasors_precomp, gaussians.opacities, gaussians.scales,
        gaussians.rotations, raster_settings.scale_modifier, gaussians.cov3Ds_precomp,
        raster_settings.viewmatrix, raster_settings.projmatrix,
        raster_settings.tanfovx, raster_settings.tanfovy,
        raster_settings.image_height, raster_settings.image_width,
        gaussians.sh, gaussians.sh_p, raster_settings.sh_degree,
        raster_settings.campos, raster_settings.prefiltered,
        raster_settings.debug, raster_settings.near_n, raster_settings.far_n,
        raster_settings.depth_range, raster_settings.use_view_dependent_phase,
        phase_offset, dc_offset
    )
    # 2. Debug handling
    if raster_settings.debug:
        args_cpu = tuple(x.detach().cpu().clone() if hasattr(x, 'detach') else copy.deepcopy(x) for x in args)
    # 3. CUDA invocation
    color, phasor, depth, normal, acc, entropy, depth_distortion, amp_distortion, pixels, distribution, radii = _C.rasterize_gaussians(*args)
    # 4. Backward pass preparation
    backward_tensors = [
        raster_settings, None, gaussians.colors_precomp, gaussians.phasors_precomp,
        gaussians.means3D, gaussians.scales, gaussians.rotations,
        gaussians.cov3Ds_precomp, radii, gaussians.sh, gaussians.sh_p,
        None, None, None, phase_offset, dc_offset
    ]
    return color, phasor, depth, normal, acc, entropy, depth_distortion, amp_distortion, pixels, distribution, radii, backward_tensors
```

**Outputs:** `color`, `phasor`, `depth`, `normal`, `acc`, `entropy`, `depth_distortion`, `amp_distortion`, `pixels`, `distribution`, `radii` [S1, unofficial].

**Pitfalls:** Debug mode incurs overhead due to CPU copying and saves state to `snapshot_fw.dump` on exception [S1, unofficial].
