# Spec-Gaussian

Also called: Specular Gaussian, Anisotropic Spherical Gaussian Splatting

## Overview
Spec-Gaussian is a method for enhancing the appearance representation of 3D Gaussian Splatting (3DGS) by explicitly modeling specular and anisotropic shading components [S1]. It addresses the limitation of standard 3DGS, which typically relies on isotropic spherical harmonics that struggle to accurately represent high-frequency specular highlights and anisotropic reflections [S1]. By replacing or augmenting the standard radiance representation with Anisotropic Spherical Gaussians (ASG), it enables the faithful reconstruction of glossy and metallic surfaces [S1].

## How it works
Spec-Gaussian modifies the per-Gaussian appearance representation used in the rendering pipeline. While the geometric parameters (position, covariance, opacity) remain similar to standard 3DGS, the radiance attribute is changed from a set of isotropic spherical harmonic coefficients to parameters defining an Anisotropic Spherical Gaussian.

**Inputs and Outputs:**
- Input: A set of 3D Gaussians with geometric attributes and Anisotropic Spherical Gaussian appearance parameters.
- Output: A rendered 2D image with accurate specular and anisotropic shading.

**Data Structures:**
For each Gaussian $i$, the appearance is defined by an Anisotropic Spherical Gaussian. Unlike isotropic SH, which assumes uniform emission in all directions, ASG models directional dependence. The specific mathematical formulation for the ASG parameters (such as mean direction, anisotropy strength, and width) is not detailed in the provided source [S1]. The source indicates that this representation is used to "approximate 3D scenes' appearance" specifically for "complex shadings like specular and anisotropic components" [S1].

**Rendering Steps:**
1. **Projection:** Project 3D Gaussians to 2D screen space, computing 2D covariance matrices and screen-space centers [S1].
2. **Rasterization:** Sort Gaussians by depth and rasterize them into screen-space tiles [S1].
3. **Appearance Evaluation:** For each pixel covered by a Gaussian, evaluate the Anisotropic Spherical Gaussian function. This function takes the view direction and the Gaussian's anisotropic parameters to compute the radiance contribution [S1].
4. **Compositing:** Alpha-composite the contributions from all overlapping Gaussians to produce the final pixel color [S1].
