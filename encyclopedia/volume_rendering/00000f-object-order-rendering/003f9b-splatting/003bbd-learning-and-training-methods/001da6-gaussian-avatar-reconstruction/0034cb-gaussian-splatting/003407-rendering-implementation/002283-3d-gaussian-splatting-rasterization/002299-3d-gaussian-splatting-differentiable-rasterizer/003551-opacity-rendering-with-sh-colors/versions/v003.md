# Opacity Rendering with SH Colors
## Overview
This method performs a rendering pass that uses the model's actual opacity values and precomputes colors from Spherical Harmonics (SH) in Python before rasterization, allowing the rasterizer to use precomputed colors [S1, unofficial]. It differs from rasterizers with built-in SH evaluation by deferring directional color computation to the Python host layer rather than evaluating SH inside the GPU kernel [S1, unofficial]. The source code initializes the color tensor to ones, indicating that actual SH evaluation is expected to be performed externally or as a simplification in the provided snippet [S1, unofficial].
## How it works
**Inputs:**
- `gaussians`: A Gaussian model object containing `get_xyz`, `get_opacity`, `get_scaling`, `get_rotation`, `get_covariance`, and `shs` [S1, unofficial].
- `viewpoint_camera`: A camera object with attributes `FoVx`, `FoVy`, `world_view_transform`, `full_proj_transform`, `camera_center`, `image_width`, and `image_height` [S1, unofficial].
- `pipeline`: A configuration object with attributes `compute_cov3D_python`, `SHDegree`, and `debug` [S1, unofficial].
- `background`: A tensor representing the background color [S1, unofficial].

**Outputs:**
- A dictionary containing `render`, `depth`, `alpha`, `viewspace_points`, `visibility_filter`, `radii`, and `opacity` [S1, unofficial].

**Data Structures:**
- `screenspace_points`: A tensor of shape `(N, 3)` matching `pc.get_xyz`, initialized to zeros, with `requires_grad=True` to retain gradients for backpropagation [S1, unofficial].
- `colors_precomp`: A tensor of shape `(N, 3)` containing the precomputed RGB colors for each Gaussian [S1, unofficial].
- `opacities`: A tensor of shape `(N,)` containing the opacity values [S1, unofficial].

**Steps:**
1. Initialize `screenspace_points` with zeros, matching the dtype and device of `pc.get_xyz`, and enable gradient retention [S1, unofficial].
2. Compute tangent field of view values from the viewpoint camera: `tanfovx = tan(viewpoint_camera.FoVx * 0.5)` and `tanfovy = tan(viewpoint_camera.FoVy * 0.5)` [S1, unofficial].
3. Configure rasterization settings with image dimensions, FOV tangents, background color, scale modifier, view/projection matrices, SH degree, camera position, `prefiltered=False`, and debug flag [S1, unofficial].
4. Set `means3D` to `pc.get_xyz.detach()` and `means2D` to the initialized `screenspace_points` tensor [S1, unofficial].
5. Set `opacity` to `pc.get_opacity` [S1, unofficial].
6. Set `scales`, `rotations`, and `cov3D_precomp` to `None` [S1, unofficial]. If `pipeline.compute_cov3D_python` is true, compute `cov3D_precomp = pc.get_covariance(scaling_modifier)`; otherwise, set `scales = pc.get_scaling.detach()` and `rotations = pc.get_rotation.detach()` [S1, unofficial].
7. Set `shs` to `None` and `colors_precomp` to a tensor of ones with the same shape as `pc.get_xyz` [S1, unofficial].
8. Call the rasterizer with `means3D`, `means2D`, `shs=None`, `colors_precomp`, `opacities`, `scales`, `rotations`, and `cov3D_precomp` to get `rendered_image`, `radii`, `rendered_depth`, and `rendered_alpha` [S1, unofficial].
9. Return a dictionary containing `render`, `depth`, `alpha`, `viewspace_points`, `visibility_filter` (`radii > 0`), `radii`, and `opacity` [S1, unofficial].

**Pseudocode:**
```python
import torch
import math
from dataclasses import dataclass

@dataclass
class RasterizationSettings:
    image_height: int
    image_width: int
    tanfovx: float
    tanfovy: float
    bg: torch.Tensor
    scale_modifier: float
    viewmatrix: torch.Tensor
    projmatrix: torch.Tensor
    sh_degree: int
    camera_position: torch.Tensor
    prefiltered: bool
    debug: bool

def rasterize(settings, means3D, means2D, shs, colors_precomp, opacities, scales, rotations, cov3D_precomp):
    # The CUDA rasterization kernel implementation is not provided in the sources. [G]
    rendered_image = torch.zeros((3, settings.image_height, settings.image_width))
    radii = torch.zeros(means3D.shape[0], dtype=torch.int32)
    rendered_depth = torch.zeros((1, settings.image_height, settings.image_width))
    rendered_alpha = torch.zeros((1, settings.image_height, settings.image_width))
    return rendered_image, radii, rendered_depth, rendered_alpha

def render_for_opa_sh(viewpoint_camera, gaussians, pipeline, background):
    pc = gaussians
    # 1. Initialize screenspace_points
    screenspace_points = torch.zeros_like(pc.get_xyz, dtype=pc.get_xyz.dtype, requires_grad=True, device="cuda") + 0
    try:
        screenspace_points.retain_grad()
    except:
        pass

    # 2. Compute tangent FOV
    tanfovx = math.tan(viewpoint_camera.FoVx * 0.5)
    tanfovy = math.tan(viewpoint_camera.FoVy * 0.5)

    # 3. Configure Rasterization Settings
    raster_settings = RasterizationSettings(
        image_height=viewpoint_camera.image_height,
        image_width=viewpoint_camera.image_width,
        tanfovx=tanfovx,
        tanfovy=tanfovy,
        bg=background,
        scale_modifier=1.0,
        viewmatrix=viewpoint_camera.world_view_transform,
        projmatrix=viewpoint_camera.full_proj_transform,
        sh_degree=pipeline.SHDegree,
        camera_position=viewpoint_camera.camera_center,
        prefiltered=False,
        debug=pipeline.debug
    )

    # 4. Prepare Gaussian Parameters
    means3D = pc.get_xyz.detach()
    means2D = screenspace_points
    opacities = pc.get_opacity

    # 5. Configure Covariance, Scales, Rotations
    if pipeline.compute_cov3D_python:
        cov3D_precomp = pc.get_covariance(scaling_modifier=1.0)
        scales = None
        rotations = None
    else:
        scales = pc.get_scaling.detach()
        rotations = pc.get_rotation.detach()
        cov3D_precomp = None

    # 6. Precompute Colors
    shs = None
    colors_precomp = torch.ones_like(pc.get_xyz)

    # 7. Rasterize
    rendered_image, radii, rendered_depth, rendered_alpha = rasterize(
        raster_settings, means3D, means2D, shs, colors_precomp, opacities, scales, rotations, cov3D_precomp
    )

    # 8. Return Results
    visibility_filter = radii > 0
    return {
        "render": rendered_image,
        "depth": rendered_depth,
        "alpha": rendered_alpha,
        "viewspace_points": screenspace_points,
        "visibility_filter": visibility_filter,
        "radii": radii,
        "opacity": opacities
    }
```

**Edge Cases and Pitfalls:**
- Gradient retention: `screenspace_points` must retain gradients for backpropagation to position parameters, and if `retain_grad()` fails it is caught and ignored [S1, unofficial].
- Covariance computation: The method branches based on `pipeline.compute_cov3D_python`, computing covariances in Python or using scales and rotations directly [S1, unofficial].
- Color initialization: The source initializes colors to ones, which may be a placeholder or simplification, and actual SH evaluation must be performed externally if directional color is required [S1, unofficial].
- Inference mode: The source snippet uses `inference=True`, which may disable gradient computation for speed [S1, unofficial].
## Subtopics

### [Standard Gaussian Rendering with SH-to-RGB Conversion](7553-standard-gaussian-rendering-with-sh-to-rgb-conversion.md)
This method is a rendering pass that computes RGB colors from spherical harmonics (SH) coefficients in Python before rasterization, bypassing the rasterizer's built-in SH evaluation. It rasterizes Gaussians using precomputed geometry and opacity, then converts SH coefficients to RGB colors post-rasterization. It differs from [Opacity Rendering with SH Colors](7480-opacity-rendering-with-sh-colors.md) by performing the SH-to-RGB conversion in the Python host code rather than precomputing colors for the rasterizer, allowing the rasterizer to use simpler color inputs while deferring the directional color evaluation to the CPU/GPU Python layer.
