# LSeg Feature Encoding

Also called: LSeg

## Overview
LSeg Feature Encoding is a method for generating semantic feature maps from 3D scenes by distilling knowledge from 2D vision-and-language models, specifically LSeg, into a neural feature field [S1]. It solves the problem of semantic understanding in 3D representations by leveraging pretrained CLIP-based encoders to provide zero-shot segmentation capabilities [S1]. It differs from sibling methods like [3D Gaussian Splatting with Feature Vectors](8060-3d-gaussian-splatting-with-feature-vectors.md) by relying on external 2D teacher networks for feature generation rather than learning features directly from 3D Gaussian parameters during training [S1].

## How it works
The method uses LSeg as a teacher network to distill features into a NeRF or similar implicit representation [S1]. The process involves encoding input images and text queries using LSeg's encoders, generating target feature maps, and resizing them to match the original image resolution for distillation [S1].

**Inputs:**
- Input images $I$ at various resolutions.
- Text queries $T$ (e.g., class labels).
- Camera poses for the input images.

**Outputs:**
- Target feature maps $\mathbf{f}_{img}(I, r)$ for each image $I$ at scale $r$ [S1].

**Data Structures:**
- **LSeg Model:** Consists of an image encoder and a text encoder [S1].
    - **Image Encoder:** Vision Transformer Large with 16x16 patches (ViT-L/16) [S1].
    - **Text Encoder:** CLIP’s Vision Transformer Base with 32x32 patches (ViT-B/32) [S1].
- **Feature Map:** A 2D tensor of reduced spatial dimensions, resized via interpolation to the original image size [S1].

**Steps:**
1. **Image Encoding:** Pass the input image $I$ through the ViT-L/16 image encoder to obtain image features [S1].
2. **Text Encoding:** Pass the text query $T$ through the ViT-B/32 text encoder to obtain text embeddings [S1].
3. **Feature Map Generation:** Compute the similarity between image features and text embeddings to generate a semantic feature map [S1].
4. **Multi-Scale Inference:** To stabilize features and alleviate artifacts from discrete patch processing in ViT, perform inference at multiple scales [S1].
    - For the Replica dataset, use scales: $[0.75, 0.83, 0.92, 1.0, 1.08, 1.17, 1.25]$ [S1].
    - For other datasets, use scales: $[0.75, 1.0, 1.25, 1.5, 1.75, 2.0, 2.25]$ [S1].
5. **Resizing:** Resize the generated feature maps to the original image size using interpolation [S1].
6. **Distillation:** Use the resized feature maps $\mathbf{f}_{img}(I, r)$ as targets for distilling features into the 3D neural feature field [S1].

**Parameters:**
- **Image Encoder:** ViT-L/16 [S1].
- **Text Encoder:** CLIP’s ViT-B/32 [S1].
- **Multi-Scale Inference Scales:**
    - Replica: $[0.75, 0.83, 0.92, 1.0, 1.08, 1.17, 1.25]$ [S1].
    - Others: $[0.75, 1.0, 1.25, 1.5, 1.75, 2.0, 2.25]$ [S1].

**Pitfalls:**
- LSeg is not robust to out-of-distribution data (e.g., "fossils", "T-Rex", "Triceratops") due to overfitting to biases in its training datasets, such as traffic scenes [S1].
- Small objects or parts are often not discriminative by the network [S1].
- Large inference scales lose context information and may produce noisy features with wrong semantic understanding [S1].

## Subtopics

### LSeg Teacher Network for Feature Distillation
This variant specifically refers to the use of LSeg as a teacher network for distilling features into NeRF [S1]. It leverages pretrained CLIP models as text and image feature encoders [S1]. LSeg by Li et al. is chosen for simplicity of implementation, though other concurrent models or text-unconditional encoders can be used [S1]. The model is trained on seven datasets: ADE20K, BDD, Cityscapes, COCO-Panoptic, IDD, Mapillary Vistas, and SUN RGBD [S1].

## Operating characteristics
- **Strengths:** Provides zero-shot semantic segmentation capabilities in 3D scenes using pretrained 2D models [S1]. Multi-scale inference stabilizes features and reduces artifacts [S1].
- **Limitations:** Poor performance on out-of-distribution objects and small parts due to training data bias (e.g., traffic scenes) [S1]. Large scales can lead to loss of context and noisy features [S1].
- **When to use:** When zero-shot semantic understanding is required and the scene content is within the distribution of LSeg's training data (e.g., common urban scenes) [S1].
- **When not to use:** When the scene contains out-of-distribution objects (e.g., fossils, dinosaurs) or small, non-discriminative parts [S1].

## Background
LSeg [44] by Li et al. appeared anonymously at OpenReview on September 29th, 2021 [S1]. Other concurrent studies [52, 99, 103, 72] appeared at arXiv on November or December, 2021 [S1]. These studies concurrently tackled image semantic segmentation tasks using similar approaches with CLIP [69], using pretrained CLIP models as text and image feature encoders in freezing or finetuning manners to train zero-shot image semantic segmentation models [S1].
