# SDF-based Voxel Carving
Also called: SplatEditCarve
## Overview
SDF-based Voxel Carving is a technique for removing 3D Gaussian Splatting samples within a specific volumetric region by rendering an axis-aligned box Signed Distance Field (SDF) with zero opacity [S1, unofficial]. It acts as a visual mask that hides splat samples inside the box while leaving samples outside unchanged, avoiding the thinning artifacts caused by deleting whole splats [S1, unofficial]. Unlike packed-array opacity mutation which deletes whole splats (causing visible thinning in neighboring voxels for anisotropic splats), SDF mutation is per-sample [S1, unofficial]. Inside the box, the sample becomes invisible; outside, it remains untouched, resulting in a hole with the exact shape of the box [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A `SplatMesh` containing the 3D Gaussian splats, a target voxel defined by `localCenter` and `voxelSize`, and a `SplatEdit` component instance.
*   **Output:** A visual modification where splats intersecting the voxel volume are masked out (opacity zeroed) without modifying the underlying splat data structure [S1, unofficial].

**Data Structures:**
*   `SplatEdit`: A component attached to the `SplatMesh` that manages SDF masks. It maintains a map of active SDFs keyed by voxel identifier [S1, unofficial].
*   `SplatEditSdf`: Represents a single carving primitive.
    *   `type`: Enum, set to `BOX` [S1, unofficial].
    *   `invert`: Boolean, set to `false` [S1, unofficial].
    *   `opacity`: Float, set to `0` [S1, unofficial].
    *   `position`: Vector3, set to the voxel's local center [S1, unofficial].
    *   `scale`: Vector3, set to half the `voxelSize` in all dimensions to define the box extent [S1, unofficial].

**Parameters:**
*   `rgbaBlendMode`: Set to `MULTIPLY` [S1, unofficial].
*   `softEdge`: Set to `0` [S1, unofficial].
*   `sdfSmooth`: Set to `0` [S1, unofficial].
*   `voxelSize`: The side length of the cubic voxel being carved [S1, unofficial].

**Steps:**
1.  Initialize the `SplatEdit` component with `rgbaBlendMode` set to `MULTIPLY`, `softEdge` set to `0`, and `sdfSmooth` set to `0` [S1, unofficial].
2.  Attach the `SplatEdit` instance as a child of the `SplatMesh` so that its coordinate system aligns with the mesh's local frame [S1, unofficial].
3.  To carve a voxel at `localCenter` with `voxelSize`:
    a. Create a new `SplatEditSdf` instance [S1, unofficial].
    b. Set `type` to `BOX` [S1, unofficial].
    c. Set `invert` to `false` [S1, unofficial].
    d. Set `opacity` to `0` [S1, unofficial].
    e. Set the SDF `position` to the voxel's `localCenter` [S1, unofficial].
    f. Set the SDF `scale` to `voxelSize / 2` in all dimensions [S1, unofficial].
    g. Add the SDF to the `SplatEdit` instance [S1, unofficial].
    h. Store the reference in a map keyed by the voxel identifier [S1, unofficial].
4.  To uncarve:
    a. Remove the SDF from the `SplatEdit` instance [S1, unofficial].
    b. Delete the reference from the map [S1, unofficial].

**Pseudocode:**
```python
class SplatEditSdf:
    def __init__(self, type, invert, opacity, position, scale):
        self.type = type
        self.invert = invert
        self.opacity = opacity
        self.position = position
        self.scale = scale

class SplatEdit:
    def __init__(self):
        self.rgbaBlendMode = "MULTIPLY"
        self.softEdge = 0
        self.sdfSmooth = 0
        self.active_sdfs = {} # Map: voxel_id -> SplatEditSdf

    def add_carve(self, voxel_id, local_center, voxel_size):
        # Create SDF with type BOX, invert false, opacity 0
        sdf = SplatEditSdf(
            type="BOX",
            invert=False,
            opacity=0,
            position=local_center,
            scale=Vector3(voxel_size / 2, voxel_size / 2, voxel_size / 2)
        )
        self.active_sdfs[voxel_id] = sdf

    def remove_carve(self, voxel_id):
        if voxel_id in self.active_sdfs:
            del self.active_sdfs[voxel_id]

# Usage
splat_edit = SplatEdit()
# Attach splat_edit to SplatMesh as child
voxel_id = "voxel_1"
local_center = Vector3(0, 0, 0)
voxel_size = 1.0
splat_edit.add_carve(voxel_id, local_center, voxel_size)
```

**Edge Cases and Pitfalls:**
*   This method is a visual mask only; the underlying splat data is unmodified [S1, unofficial].
*   Hard deletes (e.g., for PLY export or multiplayer sync) require baking the SDFs back into packed-array opacity [S1, unofficial].

**Time and Memory Complexity:**

**Strengths and Limitations:**
*   **Strengths:** Avoids thinning artifacts in neighboring voxels that occur when deleting whole splats, particularly for anisotropic splats [S1, unofficial]. Provides precise, box-shaped holes [S1, unofficial].
*   **Limitations:** Does not remove data, only masks it [S1, unofficial]. Requires additional processing (baking) for permanent removal [S1, unofficial].

**When to Use:**
Use when visual editing of a Gaussian Splatting scene is required without permanently altering the source data or causing visible artifacts from partial splat deletion [S1, unofficial].

**When Not to Use:**
Do not use when permanent data reduction is needed for export or network transmission without a subsequent baking step [S1, unofficial].
