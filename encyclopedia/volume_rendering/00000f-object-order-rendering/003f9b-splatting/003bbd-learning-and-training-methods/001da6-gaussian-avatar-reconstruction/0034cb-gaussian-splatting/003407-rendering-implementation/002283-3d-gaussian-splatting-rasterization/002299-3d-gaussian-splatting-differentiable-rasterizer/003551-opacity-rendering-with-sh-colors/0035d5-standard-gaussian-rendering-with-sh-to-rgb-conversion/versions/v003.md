# Standard Gaussian Rendering with SH-to-RGB Conversion

Also called: SH-to-RGB post-rasterization rendering, Spherical Harmonics Color Rendering

## Overview
This method is a rendering pass that computes RGB colors from spherical harmonics (SH) coefficients in Python, bypassing the rasterizer's built-in SH evaluation [S1, unofficial]. The evidence describes it as computing colors before rasterization and also as converting SH to RGB post-rasterization, indicating the conversion can occur either before or after the rasterization step depending on the pipeline configuration [S1, unofficial]. It differs from [Opacity Rendering with SH Colors](7480-opacity-rendering-with-sh-colors.md) by performing the SH-to-RGB conversion in the Python host code rather than precomputing colors for the rasterizer [S1, unofficial].

## How it works
**Inputs:**
- `gaussians`: A Gaussian model object containing 3D means (`get_xyz`), SH coefficients (`get_features`), opacities, scales, rotations, and covariance matrices (`cov3D_precomp`) [S1, unofficial].
- `viewpoint_camera`: Camera parameters including `camera_center` [S1, unofficial].
- `pipeline`: Rendering pipeline configuration [S1, unofficial].
- `background`: Background color tensor [S1, unofficial].
- `active_sh_degree`: Integer controlling the order of spherical harmonics used for color evaluation [S1, unofficial].

**Outputs:**
- `render`: Rendered RGB image [S1, unofficial].
- `depth`: Rendered depth map [S1, unofficial].
- `alpha`: Rendered alpha mask [S1, unofficial].
- `radii`: Visibility filter (radii > 0) [S1, unofficial].
- `viewspace_points`, `visibility_filter`, `opacity`, `color`: Additional metadata [S1, unofficial].

**Data Structures:**
- `shs_view`: Tensor of shape `(-1, 3, (max_sh_degree+1)^2)` representing SH coefficients reshaped for evaluation [S1, unofficial].
- `dir_pp_normalized`: Normalized view direction vectors from camera center to each Gaussian [S1, unofficial].

**Steps:**
1. **Reshape SH features:** Transpose and view SH features as `(-1, 3, (max_sh_degree+1)^2)` [S1, unofficial].
   $$ \text{shs\_view} = \text{gaussians.get\_features}^T \text{ viewed as } (-1, 3, (\text{gaussians.max\_sh\_degree}+1)^2) $$
2. **Compute view directions:** Calculate normalized direction vectors from the camera center to each Gaussian center [S1, unofficial].
   $$ \text{dir\_pp} = \text{gaussians.get\_xyz} - \text{viewpoint\_camera.camera\_center.repeat}(\text{gaussians.get\_features.shape}[0], 1) $$
   $$ \text{dir\_pp\_normalized} = \frac{\text{dir\_pp}}{\|\text{dir\_pp}\|_2} $$
3. **Evaluate SH to RGB:** Evaluate SH to get RGB values using the active SH degree, reshaped coefficients, and normalized directions [S1, unofficial].
   $$ \text{sh2rgb} = \text{eval\_sh}(\text{active\_sh\_degree}, \text{shs\_view}, \text{dir\_pp\_normalized}) $$
4. **Clamp colors:** Clamp resulting RGB values to a minimum of 0.0 after adding a 0.5 bias [S1, unofficial].
   $$ \text{color} = \text{clamp\_min}(\text{sh2rgb} + 0.5, 0.0) $$
5. **Rasterize:** Call the rasterizer with `means3D`, `means2D`, `shs`, `colors_precomp=None`, `opacities`, `scales`, `rotations`, and `cov3D_precomp` to get `rendered_image`, `radii`, `rendered_depth`, and `rendered_alpha` [S1, unofficial].
6. **Return results:** Return a dictionary containing `render`, `depth`, `alpha`, `viewspace_points`, `visibility_filter` (radii > 0), `radii`, `opacity`, and `color` [S1, unofficial].

**Pseudocode:**
```python
def compute_sh_basis(degree, directions):
    # Standard spherical harmonic basis evaluation for degrees 0 to degree [G]
    x, y, z = directions[:, 0], directions[:, 1], directions[:, 2]
    bases = [torch.ones_like(x)]
    if degree >= 1:
        bases += [-y, z, -x]
    if degree >= 2:
        bases += [x * y, y * z, 2 * z**2 - x**2 - y**2, x * z, x**2 - y**2]
    if degree >= 3:
        bases += [x * y * z, y * (3 * x**2 - y**2), y * (5 * z**2 - y**2),
                  z * (5 * z**2 - 3), x * (5 * z**2 - 1), x * (x**2 - 3 * y**2),
                  x * (x**2 - 7 * y**2)]
    return torch.stack(bases, dim=1)

def eval_sh(degree, sh_coeffs, directions):
    # sh_coeffs: (N, 3, num_bases), directions: (N, 3)
    bases = compute_sh_basis(degree, directions)
    return torch.sum(bases * sh_coeffs, dim=1)

def render_sh_to_rgb(gaussians, viewpoint_camera, pipeline, background, active_sh_degree):
    # Step 1: Reshape SH features
    shs_view = gaussians.get_features.transpose(1, 2).view(-1, 3, (gaussians.max_sh_degree + 1) ** 2)
    
    # Step 2: Compute normalized view directions
    dir_pp = gaussians.get_xyz - viewpoint_camera.camera_center.repeat(gaussians.get_features.shape[0], 1)
    dir_pp_normalized = dir_pp / dir_pp.norm(dim=1, keepdim=True)
    
    # Step 3: Evaluate SH to RGB
    sh2rgb = eval_sh(active_sh_degree, shs_view, dir_pp_normalized)
    
    # Step 4: Clamp colors
    color = torch.clamp_min(sh2rgb + 0.5, 0.0)
    
    # Step 5: Rasterize
    render_pkg = render(viewpoint_camera, gaussians, pipeline, background, inference=True)
    
    # Step 6: Return results
    return {
        "render": render_pkg["render"],
        "depth": render_pkg["depth"],
        "alpha": render_pkg["alpha"],
        "viewspace_points": render_pkg["viewspace_points"],
        "visibility_filter": render_pkg["radii"] > 0,
        "radii": render_pkg["radii"],
        "opacity": render_pkg["opacity"],
        "color": color
    }
```

**Parameters:**
- `active_sh_degree`: Controls the order of spherical harmonics used for color evaluation [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision: Clamping after adding 0.5 bias prevents negative colors [S1, unofficial].
- Boundaries: Ensure `dir_pp` is not a zero vector to avoid division by zero in normalization [G].
- Degenerate input: Handle cases where `gaussians.get_features` shape does not match expected dimensions [G].
