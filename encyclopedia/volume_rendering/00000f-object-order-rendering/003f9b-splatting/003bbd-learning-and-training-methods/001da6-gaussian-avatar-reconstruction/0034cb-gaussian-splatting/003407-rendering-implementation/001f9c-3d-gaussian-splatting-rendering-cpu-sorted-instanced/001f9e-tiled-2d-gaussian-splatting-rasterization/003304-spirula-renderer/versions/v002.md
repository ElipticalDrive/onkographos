# Spirula Renderer

Also called: Spirula Bridge, Spirula Renderer API, Spirula Vulkan bridge

## Overview
The Spirula Renderer is a GPU-accelerated Gaussian Splatting renderer implemented as a native Vulkan bridge (`librosplat_spirula.so`) called via Python's `ctypes` [S1, unofficial]. It handles tile sorting, Gaussian rasterization, and rendering to Vulkan textures [S1, unofficial]. It explicitly excludes CUDA, PyTorch, `gsplat`, or OpenGL renderer paths [S1, unofficial]. It builds on [Tiled 2D Gaussian Splatting Rasterization](2061-tiled-2d-gaussian-splatting-rasterization.md) by performing the tile sorting and rasterization internally during the render call [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Contiguous numpy arrays for Gaussian properties (means, quaternions, log-scales, opacity logits, SH coefficients), camera parameters (view/projection matrices or intrinsics), and render options [S1, unofficial].
*   **Outputs:** A caller-owned `uint8_t` buffer (RGBA8, Depth, or Opacity) populated by the renderer [S1, unofficial].

**Data Structures:**
The renderer manages a device-resident scene [S1, unofficial]. The C API exposes the following structures for device enumeration:
```c
typedef struct {
    char name[256];
    uint64_t vram_bytes;
    int usable;
} RosplatSpirulaDeviceInfo;
```
The output mode is defined by:
```c
typedef enum {
    ROSPLAT_SPIRULA_OUTPUT_COLOR = 0,
    ROSPLAT_SPIRULA_OUTPUT_DEPTH = 1,
    ROSPLAT_SPIRULA_OUTPUT_OPACITY = 2
} RosplatSpirulaOutputMode;
```

**Numbered Steps:**

1.  **Initialization:** Load the native library from candidate paths: environment variable `ROSPLAT_SPIRULA_LIBRARY`, build directories, or `/opt/rosplat-native/lib/rosplat/` [S1, unofficial]. Count available Vulkan devices and select device 0, verifying it is usable [S1, unofficial].
2.  **Scene Reset:** Call `rosplat_spirula_reset_scene(degree, reserve)` [S1, unofficial].
    *   `degree`: Spherical Harmonics (SH) degree (0-4) [S1, unofficial].
    *   `reserve`: Number of Gaussians to pre-allocate [S1, unofficial].
    *   *Constraint:* The SH dimension must be divisible by 3 [S1, unofficial]. The number of coefficients ($dim/3$) must be a perfect square [S1, unofficial]. The resulting degree ($\sqrt{coefficients} - 1$) must be between 0 and 4 inclusive [S1, unofficial]. Streaming scenes cannot change SH degree after initialization [S1, unofficial].
3.  **Data Preparation:** Convert Gaussian data into contiguous numpy arrays [S1, unofficial].
    *   `means`: `float32` array of shape `[count, 3]` (xyz positions) [S1, unofficial].
    *   `quats`: `float32` array of shape `[count, 4]` (rotations, wxyz) [S1, unofficial].
    *   `log_scales`: `float32` array of shape `[count, 3]`. Computed as $\log(\text{scale} \times \text{scale\_modifier})$ [S1, unofficial]. The `scale_modifier` is a float multiplier applied to Gaussian scales before conversion to log space (default 1.0, must be positive) [S1, unofficial]. Values are clipped to a minimum of $10^{-12}$ [S1, unofficial].
    *   `opacity_logits`: `float32` array of shape `[count, 1]`. Computed as $\text{logit}(\text{opacity})$ [S1, unofficial]. Opacity values are clipped to $[10^{-6}, 1-10^{-6}]$ before computing logits to avoid singularities [S1, unofficial].
    *   `dc`: `float32` array of shape `[count, 3]` (DC component of SH, first coefficient) [S1, unofficial].
    *   `higher`: `float32` array of shape `[count, coefficients-1, 3]` (higher-order SH coefficients), or `None` if only DC components are used [S1, unofficial].
4.  **Appending Gaussians:** Call `rosplat_spirula_append(count, means_ptr, quats_ptr, log_scales_ptr, opacity_logits_ptr, dc_ptr, higher_ptr)` to add Gaussians to the scene [S1, unofficial]. Pointers must reference contiguous memory [S1, unofficial]. The SH degree cannot change during streaming [S1, unofficial].
5.  **Camera Update:** Call `rosplat_spirula_set_camera(width, height, view_matrix_ptr, proj_matrix_ptr)` or equivalent intrinsics setter [S1, unofficial].
    *   The renderer marks `_camera_dirty` when the model matrix or resolution changes [S1, unofficial].
    *   **Camera Convention:** OpenCV (+Z forward, +Y down, row-major world-to-camera) [S1, unofficial].
    *   **OpenGL Conversion:** If using OpenGL view matrices, convert to OpenCV convention using $gl\_to\_cv = \text{diag}([1.0, -1.0, -1.0, 1.0])$ and compute $view_{cv} = gl\_to\_cv \times view_{gl} \times model\_matrix$ [S1, unofficial].
    *   **Intrinsics:** If using focal length and field of view, calculate focal length as $f = h / (2.0 \times \tan(fovy / 2.0))$ [S1, unofficial]. The intrinsics array is $[f, f, w/2.0, h/2.0]$ [S1, unofficial].
6.  **Render Options:** Call `rosplat_spirula_set_render_options(mode, active_sh_degree)` [S1, unofficial].
    *   `mode`: Output buffer mode (COLOR=0, DEPTH=1, OPACITY=2) [S1, unofficial].
    *   `active_sh_degree`: Active SH degree for rendering (-1 for scene maximum, or 0-4) [S1, unofficial].
7.  **Rendering:** Call `rosplat_spirula_render_rgba8(output_buffer_ptr, buffer_size)` [S1, unofficial].
    *   Renders top-to-bottom [S1, unofficial].
    *   Tile sorting and radix sorting are performed internally every render [S1, unofficial].
    *   `output_buffer_ptr`: Pointer to caller-owned `uint8_t` buffer [S1, unofficial].
    *   `buffer_size`: Size of the buffer in bytes [S1, unofficial].
8.  **Shutdown:** Call `rosplat_spirula_shutdown()` to release resources [S1, unofficial].

**Pseudocode:**
```python
import ctypes
import os
import numpy as np

class RosplatSpirulaDeviceInfo(ctypes.Structure):
    _fields_ = [("name", ctypes.c_char * 256),
                ("vram_bytes", ctypes.c_uint64),
                ("usable", ctypes.c_int)]

class SpirulaRenderer:
    def __init__(self, width, height, sh_degree=1, reserve=0):
        lib_path = os.environ.get('ROSPLAT_SPIRULA_LIBRARY', '/opt/rosplat-native/lib/rosplat/librosplat_spirula.so')
        self.lib = ctypes.CDLL(lib_path)
        # Count devices, select device 0, and verify it is usable [G]
        self.lib.rosplat_spirula_reset_scene(sh_degree, reserve)
        self.width = width
        self.height = height

    def append_gaussians(self, means, quats, scales, opacity, sh_dc, sh_higher=None):
        scale_modifier = 1.0
        log_scales = np.log(np.clip(scales * scale_modifier, 1e-12, np.inf))
        opacity_clipped = np.clip(opacity, 1e-6, 1 - 1e-6)
        opacity_logits = np.log(opacity_clipped / (1 - opacity_clipped))
        means = np.ascontiguousarray(means, dtype=np.float32)
        quats = np.ascontiguousarray(quats, dtype=np.float32)
        log_scales = np.ascontiguousarray(log_scales, dtype=np.float32)
        opacity_logits = np.ascontiguousarray(opacity_logits, dtype=np.float32)
        sh_dc = np.ascontiguousarray(sh_dc, dtype=np.float32)
        higher_ptr = None
        if sh_higher is not None:
            sh_higher = np.ascontiguousarray(sh_higher, dtype=np.float32)
            higher_ptr = sh_higher.ctypes.data
        count = len(means)
        self.lib.rosplat_spirula_append(
            count,
            means.ctypes.data,
            quats.ctypes.data,
            log_scales.ctypes.data,
            opacity_logits.ctypes.data,
            sh_dc.ctypes.data,
            higher_ptr
        )

    def set_camera(self, view_matrix, proj_matrix):
        view_cv = np.ascontiguousarray(view_matrix, dtype=np.float32)
        proj_cv = np.ascontiguousarray(proj_matrix, dtype=np.float32)
        self.lib.rosplat_spirula_set_camera(
            self.width,
            self.height,
            view_cv.ctypes.data,
            proj_cv.ctypes.data
        )

    def set_render_options(self, mode, sh_degree):
        self.lib.rosplat_spirula_set_render_options(mode, sh_degree)

    def render(self):
        buffer_size = self.width * self.height * 4
        output_buffer = (ctypes.c_uint8 * buffer_size)()
        self.lib.rosplat_spirula_render_rgba8(
            output_buffer,
            buffer_size
        )
        return np.ctypeslib.as_array(output_buffer, shape=(self.height, self.width, 4))

    def shutdown(self):
        self.lib.rosplat_spirula_shutdown()
```

## Operating characteristics
*   **Hardware Requirements:** Requires a Vulkan 1.2-capable GPU. Specifically requires Vulkan buffer device addresses and timeline semaphores [S1, unofficial].
*   **Performance:** Tile sorting and radix sorting are performed internally every render call. The renderer is optimized for streaming Gaussian data via ROS2 messages, handling batched appends efficiently [S1, unofficial].
*   **Limitations:** Explicitly excludes CUDA, PyTorch, `gsplat`, or OpenGL renderer paths. It relies on the `wgpu-py` Vulkan backend for UI rendering [S1, unofficial].
*   **Memory:** Scene capacity is managed via `reserve` during reset. Subsequent appends may trigger internal reallocation if capacity is exceeded, though the exact growth strategy is not detailed in the sources [S1, unofficial].

## Background
The Spirula Renderer is part of the ROSplat project, which integrates Gaussian Splatting with ROS2. It was developed to provide a portable Vulkan rendering backend for Gaussian Splatting, avoiding dependencies on CUDA or PyTorch. The project acknowledges influence from the original Gaussian Splatting implementation by graphdeco-inria and the GaussianSplattingViewer repository by limacv [S1, unofficial]. It is designed to run on Ubuntu 26.04 LTS with ROS 2 Lyrical [S1, unofficial].
