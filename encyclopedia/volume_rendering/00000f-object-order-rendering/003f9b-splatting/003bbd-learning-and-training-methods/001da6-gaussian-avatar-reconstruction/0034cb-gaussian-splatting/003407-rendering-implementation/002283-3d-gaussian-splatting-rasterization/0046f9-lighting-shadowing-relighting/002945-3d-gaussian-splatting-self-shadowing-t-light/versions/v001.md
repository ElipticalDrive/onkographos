# 3D Gaussian Splatting Self-Shadowing (T_light)

Also called: 光源视角自阴影 (T_light)

## Overview
Calculates the self-shadowing transmittance $T_{light}$ for each Gaussian along a directional sun direction, representing the 'front occlusion transmittance' to model self-shadowing effects in volume rendering [S1, unofficial]. It differs from standard alpha blending by explicitly tracking accumulated occlusion from the light source's perspective rather than the camera's, enabling physically plausible shadows within the Gaussian volume [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** 3D Gaussian primitives (position, covariance, opacity, scale, rotation), directional sun vector, sun camera parameters.
- **Outputs:** Per-Gaussian scalar $T_{light}$ (stored in `record_front_tau` channel), updated during rasterization.

**Data Structures:**
- `record_front_tau`: A single-channel buffer (float) aligned with the rasterization output, storing the accumulated front transmittance for each Gaussian.

**Steps:**
1. **Sun Camera Setup:** Configure a distant narrow FOV perspective camera to simulate the directional sun light source. This setup ensures parallax error is less than 2% and avoids modifying the EWA Jacobian [S1, unofficial].
2. **Rasterization Pass:** Perform a CUDA rasterization pass traversing Gaussians in depth order relative to the sun camera [S1, unofficial].
3. **Accumulation:** For each Gaussian, calculate its accumulated front transmittance $\tau$. Record $\tau$ weighted by the Gaussian's weight into the `record_front_tau` channel. This represents an energy-weighted mean over the entire sun-facing footprint, not just a center point sample [S1, unofficial].
4. **Gradient Handling:** Enable full continuous gradients by default. This includes gradients for $\tau$, weights, normalization, weak density backup transmittance, and projection position/scale/rotation. Treat sun camera framing, sorting, coverage, and threshold branches as constants (no gradients) [S1, unofficial].
5. **Covariance Handling:** Do not expand the projection covariance by $0.3I$ during this light pass, and do not apply amplitude compensation. Keep the sampling expansion from the main camera pass as is [S1, unofficial].
6. **Deeply Buried Gaussians:** Handle deeply buried Gaussians (where early termination causes $wsum=0$) by explicitly mapping them to full shadow to prevent inversion artifacts [S1, unofficial].

**Pseudocode:**
```python
def compute_tlight(gaussians, sun_direction, sun_camera):
    """
    Computes self-shadowing transmittance T_light for Gaussians.
    """
    # Step 1: Setup sun camera
    # sun_camera is configured as a distant narrow FOV perspective camera
    # to simulate directional light with <2% parallax error
    
    # Initialize output buffer
    record_front_tau = zeros(len(gaussians))
    
    # Step 2: Sort Gaussians by depth relative to sun_camera
    sorted_indices = sort_by_depth(gaussians, sun_camera)
    
    # Step 3: Rasterization pass
    for idx in sorted_indices:
        g = gaussians[idx]
        
        # Project Gaussian to sun camera space
        # Note: Do NOT expand covariance by 0.3I here
        # Note: Do NOT apply amplitude compensation here
        projected_cov = g.covariance # Keep main camera pass expansion
        
        # Calculate footprint and weight
        weight = g.opacity * g.weight
        
        # Calculate accumulated front transmittance tau
        # This is an energy-weighted mean over the sun-facing footprint
        tau = calculate_front_transmittance(g, sun_camera, projected_cov)
        
        # Record weighted tau
        record_front_tau[idx] = tau * weight
        
        # Step 6: Handle deeply buried Gaussians
        # If early termination occurred (wsum approx 0), force full shadow
        if is_deeply_buried(g, sun_camera):
            record_front_tau[idx] = 0.0
            
    return record_front_tau
```

**Parameters:**
- `--tlight_voxel`: If passed, uses the old $128^3$ voxel cache path. Compatible with models trained before rasterization [S1, unofficial].
- `--tlight auto|voxel|raster`: Controls shadow source mode. `auto` reads `cfg_args` to automatically match the mode [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Deeply Buried Gaussians:** Early termination in rasterization can lead to $wsum=0$. Explicitly mapping these to full shadow prevents inversion artifacts [S1, unofficial].
- **Covariance Expansion:** Do not apply the $0.3I$ expansion or amplitude compensation during the light pass, as this differs from the main camera pass [S1, unofficial].
- **Gradient Branches:** Ensure sun camera framing, sorting, coverage, and threshold branches are treated as constants to avoid incorrect gradient propagation [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Adds an additional rasterization pass per light direction. Complexity is proportional to the number of Gaussians and pixels, similar to standard rasterization [S1, unofficial].
- **Memory Complexity:** Requires storage for the `record_front_tau` channel per Gaussian [S1, unofficial].
- **Performance:** The narrow FOV sun camera setup minimizes parallax error (<2%) while maintaining efficiency [S1, unofficial].
- **Strengths:** Provides physically plausible self-shadowing in volumetric Gaussian rendering [S1, unofficial].
- **Limitations:** Requires an additional rendering pass. Voxel cache fallback ($128^3$) may be less accurate than rasterization path [S1, unofficial].

## Background
Originated in the context of 4D Gaussian Splatting for Volume Clouds, specifically for rendering realistic cloud shadows [S1, unofficial]. The method integrates with the Gaussian Splatting rasterization pipeline to compute light-space occlusion [S1, unofficial].
