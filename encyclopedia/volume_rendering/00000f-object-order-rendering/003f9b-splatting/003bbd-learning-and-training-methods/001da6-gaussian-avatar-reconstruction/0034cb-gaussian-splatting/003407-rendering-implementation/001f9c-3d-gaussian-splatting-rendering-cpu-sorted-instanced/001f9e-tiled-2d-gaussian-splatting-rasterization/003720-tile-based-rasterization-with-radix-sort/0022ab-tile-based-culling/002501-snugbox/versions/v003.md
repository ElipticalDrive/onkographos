# SnugBox

Also called: FastGS Optimizations, Rasterization Optimizations, Speedy-Splat Optimizations

## Overview
SnugBox is a precise algorithm for computing the axis-aligned bounding box (AABB) of a 3D Gaussian in screen space, replacing the overly conservative tile assignment used in standard 3D Gaussian Splatting (3D-GS) [S1]. It solves the problem of overestimating the number of tiles a Gaussian intersects, thereby reducing the number of pixels processed per Gaussian and accelerating rendering [S1][S2, unofficial]. Unlike the standard 3D-GS method which inscribes a circle within a square tile assignment, SnugBox derives a tight bounding box directly from the Gaussian's elliptical extent using its conic equation, providing numerical stability even under edge-on tilts [S1][S3, unofficial]. It serves as a plug-and-play optimization that yields an average inference speed-up of 1.82× without altering the rendered image [S1].

## How it works
**Inputs:**
*   3D Gaussian parameters: mean $\mu_i$, scale $s_i$, rotation $r_i$.
*   Camera parameters: viewing transform $W$, perspective projection.
*   Image parameters: tile size $T$, image dimensions.
*   Precomputed values: 2D covariance matrix $\Sigma_{i_{2D}}$, inverse covariance $\Sigma_{i_{2D}}^{-1}$, and the threshold $t$ derived from opacity $\sigma_i$.

**Outputs:**
*   Bounding box edges in pixel coordinates: $x_{min}, x_{max}, y_{min}, y_{max}$.
*   Tile indices: $tile_{x_{min}}, tile_{x_{max}}, tile_{y_{min}}, tile_{y_{max}}$.

**Data Structures:**
*   $\Sigma_{i_{2D}}^{-1}$: A $2 \times 2$ symmetric matrix $\begin{pmatrix} a & b \\ b & c \end{pmatrix}$ [S1].
*   $t$: Scalar threshold value [S1].
*   $\mu_{x}, \mu_{y}$: Screen-space mean coordinates [S1].

**Steps:**

1.  **Compute 2D Covariance:**
    Calculate the 3D covariance matrix $\Sigma_{i_3D}$ from scale and rotation:
    $$ \Sigma_{i_3D} = R_i S_i S_i^T R_i^T $$
    Project it to 2D using the Jacobian $J$ of the perspective projection and the viewing transform $W$:
    $$ \hat{\Sigma}_{i_3D} = J W \Sigma_{i_3D} W^T J^T $$
    Drop the last row and column of $\hat{\Sigma}_{i_3D}$ to obtain $\Sigma_{i_2D}$ [S1].

2.  **Compute Inverse Covariance and Threshold:**
    Compute the inverse of the 2D covariance matrix $\Sigma_{i_2D}^{-1} = \begin{pmatrix} a & b \\ b & c \end{pmatrix}$ [S1].
    Compute the threshold $t$ based on the Gaussian's opacity $\sigma_i$:
    $$ t = 2 \log(255 \sigma_i) $$
    [S1]

3.  **Compute Extrema X-Coordinates ($x_{d_{args}}$):**
    The ellipse equation for pixel extent is $t = ax_d^2 + 2bx_dy_d + cy_d^2$, where $x_d = p_x - \mu_x$ and $y_d = p_y - \mu_y$ [S1].
    To find the $x_d$ values where the derivative $\partial y_d / \partial x_d = 0$ (the extrema), solve for $x_{d_{args}}$:
    $$ x_{d_{args}} = \pm \sqrt{\frac{-b^2 t}{(b^2 - ac)a}} $$
    [S1]
    *Note:* If the term under the square root is negative or $a=0$, the Gaussian is degenerate or axis-aligned in a way that requires fallback handling (e.g., standard 3D-GS bounds) [G].

4.  **Compute Y-Extents ($y_{min}, y_{max}$):**
    Substitute $x_{d_{args}}$ into the rearranged ellipse equation for $y_d$:
    $$ y_d = \frac{-bx_d \pm \sqrt{(b^2 - ac)x_d^2 + tc}}{c} $$
    [S1]
    Calculate the two possible $y_d$ values for each $x_{d_{args}}$. The minimum and maximum of these values (plus $\mu_y$) give $y_{min}$ and $y_{max}$:
    $$ y_{min} = \mu_y + \min(y_d) $$
    $$ y_{max} = \mu_y + \max(y_d) $$
    [S1]

5.  **Compute X-Extents ($x_{min}, x_{max}$):**
    Due to the symmetry of the ellipse equation, swap $y_d$ and $x_d$ and swap constants $a$ and $c$ in the formulas from Steps 3 and 4 to compute $x_{min}$ and $x_{max}$ [S1].
    Specifically, solve for $y_{d_{args}}$ using:
    $$ y_{d_{args}} = \pm \sqrt{\frac{-b^2 t}{(b^2 - ac)c}} $$
    Then substitute into the equation for $x_d$:
    $$ x_d = \frac{-by_d \pm \sqrt{(b^2 - ac)y_d^2 + ta}}{a} $$
    [S1]
    $$ x_{min} = \mu_x + \min(x_d) $$
    $$ x_{max} = \mu_x + \max(x_d) $$
    [S1]

6.  **Convert to Tile Indices:**
    Divide the bounding box edges by the tile size $T$, round to the nearest integer, and clip to the image boundaries:
    $$ tile_{x_{min}} = \text{clip}(\lfloor x_{min} / T \rfloor, 0, W_{tiles}-1) $$
    $$ tile_{x_{max}} = \text{clip}(\lceil x_{max} / T \rceil, 0, W_{tiles}-1) $$
    $$ tile_{y_{min}} = \text{clip}(\lfloor y_{min} / T \rfloor, 0, H_{tiles}-1) $$
    $$ tile_{y_{max}} = \text{clip}(\lceil y_{max} / T \rceil, 0, H_{tiles}-1) $$
    [S1]

**Pseudocode:**

```python
import math

def compute_snug_box(gaussian, tile_size, image_width_tiles, image_height_tiles):
    """
    Computes the tight AABB tile indices for a Gaussian.
    
    Args:
        gaussian: Object containing:
            - mu_x, mu_y: Screen space mean
            - sigma: Opacity
            - cov_inv_2d: 2x2 inverse covariance matrix [[a, b], [b, c]]
        tile_size: Width/height of a tile in pixels
        image_width_tiles: Number of tiles in X
        image_height_tiles: Number of tiles in Y
        
    Returns:
        (tile_x_min, tile_x_max, tile_y_min, tile_y_max)
    """
    # Extract covariance inverse components
    a, b, c = gaussian.cov_inv_2d[0][0], gaussian.cov_inv_2d[0][1], gaussian.cov_inv_2d[1][1]
    
    # Compute threshold t
    # Note: sigma is typically in [0, 1]. 255 * sigma ensures the ellipse corresponds to the 
    # standard 3D-GS cutoff where intensity drops significantly.
    t = 2.0 * math.log(255.0 * gaussian.sigma)
    
    # Helper to compute extrema for one axis given the other's derivative zero-crossings
    # This function computes min/max of the dependent variable given the independent variable extrema
    def get_extrema(independent_extrema, mu_dep, mu_ind, a, b, c, t):
        """
        independent_extrema: list of [val, mu] pairs for the independent variable (e.g., x_d)
        mu_dep: mean of dependent variable (e.g., mu_y)
        mu_ind: mean of independent variable (e.g., mu_x)
        """
        deps = []
        for ind_val, ind_mu in independent_extrema:
            ind_d = ind_val - ind_mu
            # Discriminant part of the quadratic solution
            disc_term = (b**2 - a*c) * (ind_d**2) + t * c
            
            if disc_term < 0:
                # Degenerate case: no real solution for this x_d. 
                # This implies the ellipse does not extend to this x_d in reality,
                # or numerical instability. Fallback to mean or minimal extent.
                deps.append(mu_dep)
                deps.append(mu_dep)
            else:
                sqrt_disc = math.sqrt(disc_term)
                # Two solutions for dependent variable
                y1 = (-b * ind_d + sqrt_disc) / c
                y2 = (-b * ind_d - sqrt_disc) / c
                deps.append(y1 + mu_dep)
                deps.append(y2 + mu_dep)
        return min(deps), max(deps)

    # Step 1: Compute x_d extrema (x_d_args)
    # Formula: x_d_args = +/- sqrt( (-b^2 * t) / ((b^2 - a*c) * a) )
    denom_x = (b**2 - a*c) * a
    if denom_x == 0:
        # Fallback if a=0 or b^2=ac (degenerate)
        x_d_args = [0.0]
    else:
        radicand_x = (-b**2 * t) / denom_x
        if radicand_x < 0:
            x_d_args = [0.0]
        else:
            sqrt_rad_x = math.sqrt(radicand_x)
            x_d_args = [-sqrt_rad_x, sqrt_rad_x]
            
    # Step 2: Compute y_min, y_max using x_d_args
    y_min, y_max = get_extrema(
        [(x, gaussian.mu_x) for x in x_d_args], 
        gaussian.mu_y, gaussian.mu_x, a, b, c, t
    )
    
    # Step 3: Compute y_d extrema (y_d_args) for x calculation
    # Formula: y_d_args = +/- sqrt( (-b^2 * t) / ((b^2 - a*c) * c) )
    denom_y = (b**2 - a*c) * c
    if denom_y == 0:
        y_d_args = [0.0]
    else:
        radicand_y = (-b**2 * t) / denom_y
        if radicand_y < 0:
            y_d_args = [0.0]
        else:
            sqrt_rad_y = math.sqrt(radicand_y)
            y_d_args = [-sqrt_rad_y, sqrt_rad_y]
            
    # Step 4: Compute x_min, x_max using y_d_args
    # Swap roles: dependent is x, independent is y. 
    # The formula for x_d given y_d is: x_d = (-b*y_d +/- sqrt((b^2-ac)y_d^2 + t*a)) / a
    # We reuse get_extrema by swapping parameters appropriately.
    # Here, 'independent' is y, 'dependent' is x.
    # a becomes c, c becomes a in the quadratic structure relative to the swap?
    # Actually, the equation is symmetric. 
    # Original: t = a*x^2 + 2b*x*y + c*y^2
    # Solve for x: a*x^2 + (2b*y)*x + (c*y^2 - t) = 0
    # x = [ -2b*y +/- sqrt(4b^2*y^2 - 4a(c*y^2 - t)) ] / 2a
    # x = [ -b*y +/- sqrt(b^2*y^2 - a*c*y^2 + a*t) ] / a
    # x = [ -b*y +/- sqrt((b^2 - a*c)y^2 + a*t) ] / a
    
    # Re-implementing get_extrema logic specifically for x given y to avoid confusion
    x_extrema = []
    for y_val, y_mu in [(y, gaussian.mu_y) for y in y_d_args]:
        y_d = y_val - y_mu
        disc_term_x = (b**2 - a*c) * (y_d**2) + a * t
        
        if disc_term_x < 0:
            x_extrema.append(gaussian.mu_x)
            x_extrema.append(gaussian.mu_x)
        else:
            sqrt_disc_x = math.sqrt(disc_term_x)
            # Check for a=0 to avoid division by zero
            if a == 0:
                # If a=0, the equation is linear in x: 2bxy + cy^2 - t = 0 => x = (t - cy^2) / 2by
                if b == 0 or y_d == 0:
                     x_extrema.append(gaussian.mu_x)
                     x_extrema.append(gaussian.mu_x)
                else:
                    x_val = (t - c * (y_d**2)) / (2 * b * y_d)
                    x_extrema.append(x_val + gaussian.mu_x)
                    x_extrema.append(x_val + gaussian.mu_x)
            else:
                x1 = (-b * y_d + sqrt_disc_x) / a
                x2 = (-b * y_d - sqrt_disc_x) / a
                x_extrema.append(x1 + gaussian.mu_x)
                x_extrema.append(x2 + gaussian.mu_x)
                
    x_min = min(x_extrema)
    x_max = max(x_extrema)
    
    # Step 5: Convert to tile indices
    tile_x_min = int(math.floor(x_min / tile_size))
    tile_x_max = int(math.ceil(x_max / tile_size))
    tile_y_min = int(math.floor(y_min / tile_size))
    tile_y_max = int(math.ceil(y_max / tile_size))
    
    # Clip to image boundaries
    tile_x_min = max(0, min(tile_x_min, image_width_tiles - 1))
    tile_x_max = max(0, min(tile_x_max, image_width_tiles - 1))
    tile_y_min = max(0, min(tile_y_min, image_height_tiles - 1))
    tile_y_max = max(0, min(tile_y_max, image_height_tiles - 1))
    
    return tile_x_min, tile_x_max, tile_y_min, tile_y_max
```

**Edge Cases and Pitfalls:**
*   **Degenerate Covariance:** If $a=0$ or $c=0$ or $b^2-ac=0$, the Gaussian is degenerate (e.g., a line or point in screen space). The square root terms may become negative or undefined. In such cases, fallback to the standard 3D-GS bounding box or a minimal 1-tile assignment [G].
*   **Numerical Stability:** Under extreme edge-on tilts, the covariance matrix can become ill-conditioned. SnugBox is noted to provide numerical stability in these cases compared to other methods [S3, unofficial].
*   **Opacity Threshold:** The threshold $t$ depends on $\sigma_i$. If $\sigma_i$ is very small, $t$ becomes large and negative, potentially leading to complex roots if not handled correctly. Ensure $t$ is computed correctly and discriminants are checked for negativity [S1].

## Operating characteristics
*   **Time Complexity:** Constant time $O(1)$ per Gaussian, involving a fixed number of arithmetic operations (square roots, divisions, multiplications) [S1].
*   **Memory Complexity:** $O(1)$ additional memory per Gaussian for storing the bounding box [S1].
*   **Performance:** Produces an average inference speed-up of 1.82× on Mip-NeRF 360, Tanks & Temples, and Deep Blending datasets compared to baseline 3D-GS [S1]. When combined with AccuTile, it contributes to a 2× FPS boost [S2, unofficial].
*   **Strengths:** Lossless (does not change rendered image), plug-and-play, significantly reduces the number of Gaussians per pixel by avoiding overestimation [S1][S2, unofficial].
*   **Limitations:** Only applicable during rasterization/tile assignment; does not reduce the total number of Gaussians in the scene (unlike pruning methods) [S1].

## Background
SnugBox was introduced in the "Speedy-Splat" paper (Hanson et al., 2025) as part of a suite of optimizations to accelerate 3D Gaussian Splatting rendering [S1][S3, unofficial]. It addresses the inefficiency of the original 3D-GS tile assignment, which uses a conservative square bounding box derived from the largest eigenvalue of the 2D covariance matrix [S1][S2, unofficial]. The method is also referenced in "FastGS" (Ren et al., 2025) and "Bake It Till You Make It" [S3, unofficial].
