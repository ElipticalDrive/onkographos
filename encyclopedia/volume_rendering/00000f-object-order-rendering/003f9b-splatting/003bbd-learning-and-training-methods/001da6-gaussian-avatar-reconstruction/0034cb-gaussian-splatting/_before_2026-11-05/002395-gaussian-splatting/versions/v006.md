# Gaussian Splatting

Also called: 3D Gaussian Splatting Rendering, Vanilla 3DGS rendering

## Overview
Gaussian Splatting (3DGS) is a novel-view synthesis method that represents a scene as an explicit collection of anisotropic 3D Gaussians, each carrying opacity and view-dependent color encoded by spherical harmonics [S5, unofficial]. It solves the computational bottleneck of implicit neural radiance fields (NeRF) by replacing ray marching with a tile-based differentiable rasterizer, achieving real-time rendering speeds while maintaining photorealistic fidelity [S5, unofficial]. Unlike NeRF, which requires hundreds of MLP evaluations per pixel, 3DGS uses explicit primitives that are projected to 2D and composited via alpha blending, avoiding costly queries in empty space [S1][S5, unofficial].

## How it works
**Inputs:** A set of posed input images $\{I_i\}$ and their corresponding camera poses (extrinsics $W$ and intrinsics $K$).
**Outputs:** A rendered image $C$ for a target camera pose, and a set of optimized Gaussian parameters $\theta = \{g_i\}_{i=1}^M$.

**Data Structures:**
The scene is represented by a list of $M$ Gaussian primitives. Each Gaussian $g_i$ is defined by the following parameters [S1][S12, unofficial]:
*   **Center:** $\boldsymbol{\mu}_i \in \mathbb{R}^3$ (world space position).
*   **Covariance:** $\boldsymbol{\Sigma}_i \in \mathbb{R}^{3 \times 3}$ (shape and orientation). To ensure positive semi-definiteness during optimization, $\boldsymbol{\Sigma}_i$ is parameterized by a scaling vector $\mathbf{s}_i \in \mathbb{R}^3$ (stored in log space) and a rotation quaternion $\mathbf{q}_i \in \mathbb{R}^4$ (normalized to unit length) [S4, S5, S12, unofficial]:
    $$ \boldsymbol{\Sigma}_i = \mathbf{R}(\mathbf{q}_i) \mathbf{S}(\mathbf{s}_i) \mathbf{S}(\mathbf{s}_i)^\top \mathbf{R}(\mathbf{q}_i)^\top $$
    where $\mathbf{R}(\mathbf{q}_i)$ is the rotation matrix derived from $\mathbf{q}_i$, and $\mathbf{S}(\mathbf{s}_i) = \text{diag}(e^{s_{ix}}, e^{s_{iy}}, e^{s_{iz}})$ [S5, S12, unofficial].
*   **Opacity:** $\sigma_i \in \mathbb{R}$ (logit, representing peak opacity) [S4, S12, unofficial].
*   **Color:** Spherical Harmonic (SH) coefficients $\mathbf{h}_i \in \mathbb{R}^{4 \times 3}$ (for band 3, 48 coefficients) encoding view-dependent appearance [S4, S12, unofficial].

**Rendering Pipeline:**

1.  **Initialization:** Initialize $M$ Gaussians using a sparse point cloud obtained from Structure-from-Motion (SfM) [S1][S5, unofficial]. Centers $\boldsymbol{\mu}_i$ are set to point cloud positions. Initial scales and rotations are derived from local neighborhood analysis or set to small uniform values. Colors are initialized from the point cloud RGB values [S1][S5, unofficial].

2.  **3D to 2D Projection (Splatting):**
    For each Gaussian $i$, compute its 2D projection in screen space [S8][S12, unofficial]:
    *   Transform center to camera space: $\boldsymbol{\mu}_i^c = \mathbf{W} \boldsymbol{\mu}_i$.
    *   Compute the Jacobian $\mathbf{J} \in \mathbb{R}^{2 \times 3}$ of the perspective projection $\phi_{\mathbf{K}}$ at $\boldsymbol{\mu}_i^c$ [S1][S12, unofficial]:
        $$ \mathbf{J} = \begin{bmatrix} \frac{f_x}{z} & 0 & -\frac{f_x x}{z^2} \\ 0 & \frac{f_y}{z} & -\frac{f_y y}{z^2} \end{bmatrix} $$
        where $(x,y,z)$ are coordinates of $\boldsymbol{\mu}_i^c$ and $f_x, f_y$ are focal lengths [S12, unofficial].
    *   Compute the 2D covariance $\tilde{\boldsymbol{\Sigma}}_i$ using the linearized approximation [S1][S12, unofficial]:
        $$ \tilde{\boldsymbol{\Sigma}}_i = \mathbf{J} \mathbf{W} \boldsymbol{\Sigma}_i \mathbf{W}^\top \mathbf{J}^\top $$
    *   Compute the 2D mean $\tilde{\boldsymbol{\mu}}_i = \phi_{\mathbf{K}}(\mathbf{W} \boldsymbol{\mu}_i)$ [S1].
    *   Compute the 3-sigma bounding box in screen space to determine which tiles the Gaussian affects [S11, unofficial].

3.  **Tile-Based Sorting:**
    *   Partition the image into tiles (typically $16 \times 16$ pixels) [S8].
    *   Assign Gaussians to overlapping tiles based on their bounding boxes [S8].
    *   Sort Gaussians within each tile by depth (distance from camera) using a GPU-optimized radix sort [S8][S11, unofficial]. This determines the back-to-front rendering order.

4.  **Alpha Compositing (Rasterization):**
    For each pixel $\mathbf{p}$ in a tile, iterate through the sorted list of Gaussians $i=1 \dots N$ that cover the pixel [S8][S12, unofficial]:
    *   Evaluate the 2D Gaussian value at the pixel's local coordinates $\mathbf{x}'$ (relative to $\tilde{\boldsymbol{\mu}}_i$) [S11, unofficial]:
        $$ \tilde{\mathcal{G}}_i(\mathbf{p}) = \exp\left(-\frac{1}{2} (\mathbf{x}')^\top \tilde{\boldsymbol{\Sigma}}_i^{-1} (\mathbf{x}')\right) $$
        In practice, this is computed using the conic matrix $\mathbf{C} = \tilde{\boldsymbol{\Sigma}}_i^{-1}$ as $power = -0.5 (C_{00} x^2 + C_{11} y^2 + 2 C_{01} xy)$ [S11, unofficial].
    *   Compute the effective opacity $\alpha_i$ for the splat [S13, unofficial]:
        $$ \alpha_i = \sigma_i \cdot \tilde{\mathcal{G}}_i(\mathbf{p}) $$
        Clamp $\alpha_i$ to a maximum of 0.99 to prevent full opacity from blocking subsequent splats entirely [S11, unofficial].
    *   If $\alpha_i < 1/255.0$, discard the fragment [S11, unofficial].
    *   Compute the color $\mathbf{c}_i$ by evaluating the SH coefficients with the viewing direction $\mathbf{d}$ from the camera to $\boldsymbol{\mu}_i$ [S7, S13, unofficial]. For band 0 only: $\mathbf{c}_i = \text{clamp}(0.5 + C_0 \mathbf{f}_{dc}, 0, 1)$ where $C_0 \approx 0.282$ [S4, unofficial].
    *   Accumulate color and transmittance [S12, unofficial]:
        $$ C_{\mathbf{p}} = \sum_{i=1}^N \mathbf{c}_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
        $$ T_{\mathbf{p}} = \prod_{i=1}^N (1 - \alpha_i) $$
    *   Add background color $\mathbf{c}_{BG}$ (default white) weighted by remaining transmittance: $C_{final} = C_{\mathbf{p}} + T_{\mathbf{p}} \mathbf{c}_{BG}$ [S10, unofficial].

**Optimization:**
Minimize photometric loss between rendered image $I_{\theta}$ and ground truth $I_{gt}$ [S12, unofficial]:
$$ \mathcal{L} = \mathcal{L}_{rgb} = \| I_{\theta} - I_{gt} \|_1 + \lambda_{SSIM} \cdot SSIM(I_{\theta}, I_{gt}) $$
Backpropagate gradients to update $\boldsymbol{\mu}_i, \mathbf{s}_i, \mathbf{q}_i, \sigma_i, \mathbf{h}_i$ using Adam [S12, unofficial].

**Adaptive Density Control (Training Only):**
Periodically adjust the number of Gaussians based on image error gradients [S5, unofficial]:
*   **Clone:** Gaussians in regions with high error and small scale are cloned to increase density.
*   **Split:** Gaussians with large scale are split into two smaller Gaussians to capture high-frequency details.
*   **Prune:** Gaussians with persistently low opacity are removed [S1][S12, unofficial].

**Pseudocode:**

```python
import numpy as np

def render_gaussians(gaussians, camera, image_width, image_height, tile_size=16):
    """
    Render a scene of 3D Gaussians for a given camera.
    
    Args:
        gaussians: List of dicts with keys 'mu' (3,), 's' (3,), 'q' (4,), 'sigma' (float), 'sh_coeffs' (48,)
        camera: Dict with 'W' (4x4 extrinsic), 'K' (3x3 intrinsic)
        image_width, image_height: int
        tile_size: int
        
    Returns:
        image: (H, W, 3) uint8 array
    """
    # 1. Project Gaussians to 2D
    projected = []
    for g in gaussians:
        # Transform center to camera space
        mu_world = g['mu']
        mu_cam = camera['W'] @ np.append(mu_world, 1.0)
        mu_cam = mu_cam[:3] / mu_cam[3]
        
        # Compute Jacobian of projection at mu_cam
        x, y, z = mu_cam
        fx, fy = camera['K'][0, 0], camera['K'][1, 1]
        J = np.array([
            [fx / z, 0, -fx * x / (z**2)],
            [0, fy / z, -fy * y / (z**2)]
        ])
        
        # Compute 2D covariance
        Sigma_3d = compute_covariance(g['s'], g['q'])
        W = camera['W'][:3, :3]
        Sigma_2d = J @ W @ Sigma_3d @ W.T @ J.T
        
        # Project mean
        mu_2d = camera['K'] @ mu_cam
        mu_2d = mu_2d[:2] / mu_2d[2]
        
        # Compute bounding box (3-sigma)
        # Eigenvalues of Sigma_2d give variance along principal axes
        eigvals = np.linalg.eigvalsh(Sigma_2d)
        std_devs = np.sqrt(eigvals)
        bbox_size = 3.0 * std_devs
        
        # Convert to pixel coordinates for bounding box
        # Approximate: assume aspect ratio 1 for simplicity, or use K's scaling
        # In practice, transform bbox corners through K
        projected.append({
            'mu_2d': mu_2d,
            'Sigma_2d': Sigma_2d,
            'sigma': g['sigma'],
            'sh_coeffs': g['sh_coeffs'],
            'bbox': (mu_2d - bbox_size, mu_2d + bbox_size)
        })
        
    # 2. Tile Assignment and Sorting
    tiles = {}
    for i, p in enumerate(projected):
        bbox_min, bbox_max = p['bbox']
        tile_min_x = int(max(0, bbox_min[0] // tile_size))
        tile_min_y = int(max(0, bbox_min[1] // tile_size))
        tile_max_x = int(min(image_width // tile_size, bbox_max[0] // tile_size + 1))
        tile_max_y = int(min(image_height // tile_size, bbox_max[1] // tile_size + 1))
        
        for ty in range(tile_min_y, tile_max_y):
            for tx in range(tile_min_x, tile_max_x):
                key = (ty, tx)
                if key not in tiles:
                    tiles[key] = []
                # Compute depth for sorting (z-coordinate in camera space)
                depth = p['mu_2d'][1] # Approximation, use actual z from mu_cam
                tiles[key].append((depth, i))
                
    # Sort each tile's gaussians by depth (back to front)
    for key in tiles:
        tiles[key].sort(key=lambda x: x[0], reverse=True)
        
    # 3. Rasterization
    image = np.zeros((image_height, image_width, 3), dtype=np.float32)
    transmittance = np.ones((image_height, image_width), dtype=np.float32)
    
    for (ty, tx), gaussians_in_tile in tiles.items():
        y_start, y_end = ty * tile_size, min((ty + 1) * tile_size, image_height)
        x_start, x_end = tx * tile_size, min((tx + 1) * tile_size, image_width)
        
        for depth, idx in gaussians_in_tile:
            p = projected[idx]
            mu_2d = p['mu_2d']
            Sigma_2d = p['Sigma_2d']
            sigma_peak = p['sigma']
            sh_coeffs = p['sh_coeffs']
            
            # Compute inverse covariance (conic)
            try:
                Sigma_2d_inv = np.linalg.inv(Sigma_2d)
            except np.linalg.LinAlgError:
                continue
                
            C00 = Sigma_2d_inv[0, 0]
            C11 = Sigma_2d_inv[1, 1]
            C01 = Sigma_2d_inv[0, 1]
            
            # Iterate over pixels in the tile that fall within the bounding box
            # Optimization: restrict to bbox
            y_min = int(max(y_start, mu_2d[1] - 3 * np.sqrt(np.max(np.linalg.eigvals(Sigma_2d)))))
            y_max = int(min(y_end, mu_2d[1] + 3 * np.sqrt(np.max(np.linalg.eigvals(Sigma_2d)))))
            x_min = int(max(x_start, mu_2d[0] - 3 * np.sqrt(np.max(np.linalg.eigvals(Sigma_2d)))))
            x_max = int(min(x_end, mu_2d[0] + 3 * np.sqrt(np.max(np.linalg.eigvals(Sigma_2d)))))
            
            for y in range(y_min, y_max):
                for x in range(x_min, x_max):
                    # Local coordinates relative to Gaussian center
                    dx = x - mu_2d[0]
                    dy = y - mu_2d[1]
                    
                    # Power calculation
                    power = -0.5 * (C00 * dx**2 + C11 * dy**2 + 2 * C01 * dx * dy)
                    
                    if power > 0.0:
                        continue
                        
                    # Gaussian value
                    g_val = np.exp(power)
                    
                    # Effective alpha
                    alpha = sigma_peak * g_val
                    alpha = min(alpha, 0.99)
                    
                    if alpha < 1.0 / 255.0:
                        continue
                        
                    # Compute color from SH
                    # Viewing direction from camera to Gaussian center
                    # Approximate: use normal to image plane or vector from camera center
                    # For simplicity, assume view direction is constant for the splat
                    view_dir = np.array([0, 0, 1]) # Placeholder for actual view dir
                    color = evaluate_sh(sh_coeffs, view_dir)
                    
                    # Alpha blending
                    image[y, x] += color * alpha * transmittance[y, x]
                    transmittance[y, x] *= (1.0 - alpha)
                    
    # Add background
    bg_color = np.array([1.0, 1.0, 1.0])
    image += transmittance[:, :, np.newaxis] * bg_color
    
    # Clamp and convert to uint8
    image = np.clip(image, 0, 1)
    return (image * 255).astype(np.uint8)

def compute_covariance(s, q):
    """Compute 3D covariance from scale s and quaternion q."""
    # Normalize quaternion
    q = q / np.linalg.norm(q)
    qr, qi, qj, qk = q
    
    # Rotation matrix from quaternion
    R = np.array([
        [1 - 2*(qj**2 + qk**2), 2*(qi*qj - qr*qk), 2*(qi*qk + qr*qj)],
        [2*(qi*qj + qr*qk), 1 - 2*(qi**2 + qk**2), 2*(qj*qk - qr*qi)],
        [2*(qi*qk - qr*qj), 2*(qj*qk + qr*qi), 1 - 2*(qi**2 + qj**2)]
    ])
    
    # Scale matrix
    S = np.diag(np.exp(s))
    
    # Sigma = R S S^T R^T
    Sigma = R @ (S @ S.T) @ R.T
    return Sigma

def evaluate_sh(coeffs, view_dir):
    """Evaluate SH coefficients for a given view direction.
    Simplified for Band 0 only for this example.
    """
    # Band 0: DC component
    C0 = 0.28209479177387814
    f_dc = coeffs[:3]
    color = np.clip(0.5 + C0 * f_dc, 0, 1)
    return color
```

## Subtopics

### [Unnormalized 3D Gaussian Function](1026-unnormalized-3d-gaussian-function.md)
Parameterizes the Gaussian via its peak value (opacity) rather than its integral, making the amplitude $a$ the intensity at the center.

### [Row-constant hoisting for Gaussian Splatting Rasterization](1195-row-constant-hoisting-for-gaussian-splatting-rasterization.md)
Optimizes the inner pixel loop by hoisting row-constant terms outside the loop to minimize arithmetic operations per pixel.

### [2D Gaussian Projection with Covariance Stabilization](1198-2d-gaussian-projection-with-covariance-stabilization.md)
Projects 3D Gaussians to 2D using a local affine transformation (Jacobian) to preserve the Gaussian form as a 2D ellipse, avoiding ray marching.

### [Gaussian in the Wild (GS-W)](1386-gaussian-in-the-wild-gs-w.md)
Separates scene appearance into intrinsic material properties and dynamic environmental factors, avoiding global latent embeddings to capture local high-frequency changes.

### [4D Gaussian Splatting](1458-4d-gaussian-splatting.md)
Extends 3DGS to dynamic scenes by using a unified 4D covariance matrix to capture space-time motion, avoiding jitter from independent temporal weighting.

### [3DGUT](1474-3dgut.md)
Uses an unscented transform to improve the affine approximation of the projection operator, reducing approximation errors in the 2D covariance.

### [Transformer-based Reconstruction](1794-transformer-based-reconstruction.md)
Predicts 3DGS parameters directly from 2D images using a feed-forward network, bypassing iterative optimization [G].

### [3D Gaussian Ellipsoid Rendering](1869-3d-gaussian-ellipsoid-rendering.md)
Replaces rasterization with ray tracing to compute exact volume density distributions, solving occlusion ambiguity.

### [Stochastic Gaussian Splatting](6599-stochastic-gaussian-splatting.md)
Eliminates sorting bottlenecks by using stochastic sampling and atomic operations, enabling real-time rendering of hundreds of millions of Gaussians.

## Operating characteristics
**Time Complexity:** Rendering is $O(N)$ where $N$ is the number of Gaussians, but effectively bounded by the number of Gaussians per pixel due to alpha blending early-out. Sorting is $O(N \log N)$ per frame [S8].
**Memory Complexity:** $O(M)$ where $M$ is the number of Gaussians. Each Gaussian stores $\boldsymbol{\mu}_i$ (12 bytes), $\mathbf{s}_i$ (12 bytes), $\mathbf{q}_i$ (16 bytes), $\sigma_i$ (4 bytes), and SH coefficients (48 coefficients $\times$ 4 bytes = 192 bytes). Total $\approx 236$ bytes per Gaussian [S4, S12, unofficial]. Complex scenes require 200,000–500,000 Gaussians [S12, unofficial].
**Performance:** Achieves $\ge 30$ fps at 1080p on consumer hardware [S5, unofficial]. On the Mip-NeRF360 benchmark, it reaches 27.21 dB PSNR and 0.214 LPIPS at 134 fps [S5, unofficial].
**Strengths:** Real-time rendering, high visual fidelity, explicit representation allows easy editing and compression.
**Limitations:** Large memory footprint for high-fidelity scenes. Approximations in visibility (center-based sorting) cause popping artifacts. Self-attenuation is ignored, limiting accuracy in highly transparent or dense volumes [S2][S13, unofficial]. Standard anti-aliasing (dilation-based) fails with varying focal lengths [S12, unofficial].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [S5, unofficial]. It builds on EWA Volume Splatting [S2][S3, unofficial] and point-based rendering methods [S5, unofficial]. It was developed to overcome the slow rendering speeds of NeRF and the limited fidelity of earlier point-based methods. It is used for novel-view synthesis, virtual walkthroughs, free-viewpoint replays, digital twins, and VR/AR content capture [S5, unofficial].
