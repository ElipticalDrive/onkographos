# Gaussian Splatting

Also called: 3D Gaussian Splatting Rendering, Standard Gaussian Splatting Rendering, 3D Gaussian Rasterization, 3DGS representation

## Overview
Gaussian Splatting (3DGS) is a novel-view synthesis method that represents a scene as an explicit collection of anisotropic 3D Gaussians, each carrying opacity and view-dependent color, optimized directly from calibrated images [S5, unofficial]. It solves the computational bottleneck of implicit neural radiance fields (NeRF) by replacing ray-marching with a tile-based differentiable rasterizer, achieving real-time rendering speeds while maintaining high visual fidelity [S1][S5, unofficial]. Unlike NeRF, which requires evaluating neural networks for every pixel, 3DGS uses explicit primitives initialized on geometry, avoiding costly queries in empty space and enabling efficient volume splatting [S1][S10, unofficial].

## How it works
**Inputs:** A set of posed input images $\{I_i\}$ and their corresponding camera poses (extrinsics $W$ and intrinsics $K$).
**Outputs:** A rendered image $I_f$, depth map, and mask; or a trained scene representation consisting of $M$ 3D Gaussians.

**Data Structures:**
The scene is represented by a set of $M$ Gaussian primitives $g_i$. Each Gaussian $g_i$ is defined by the following parameters [S1][S10, unofficial]:
*   **Center:** $\boldsymbol{\mu}_i \in \mathbb{R}^3$ (world space position).
*   **Covariance:** $\boldsymbol{\Sigma}_i \in \mathbb{R}^{3\times3}$ (shape and orientation). To ensure positive semi-definiteness during optimization, $\boldsymbol{\Sigma}_i$ is parameterized via factorization [S5, unofficial]:
    $$ \boldsymbol{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^\top \mathbf{R}_i^\top $$
    where $\mathbf{R}_i \in SO(3)$ is a rotation matrix derived from a unit quaternion $\mathbf{q}_i = [q_r, q_i, q_j, q_k]^\top$, and $\mathbf{S}_i = \text{diag}(s_x, s_y, s_z)$ is a scaling matrix [S5, S10, unofficial]. The scales $s$ are optimized in log space [S4, unofficial].
*   **Opacity:** $\sigma_i \in \mathbb{R}$ (peak opacity). Stored as a logit to allow unconstrained optimization [S4, unofficial].
*   **Color:** Represented by spherical harmonic (SH) coefficients $c_i$. Band 0 (DC) is stored as 3 RGB values; higher bands encode view-dependent effects [S4, S5, unofficial].

**Rendering Pipeline:**
1.  **Projection:** For each Gaussian $g_i$, compute its 2D projection onto the image plane.
    *   Transform center to camera space: $\boldsymbol{\mu}_i^c = \mathbf{W} \boldsymbol{\mu}_i$.
    *   Compute the 2D mean: $\tilde{\boldsymbol{\mu}}_i = \boldsymbol{\phi}_{\mathbf{K}}(\boldsymbol{\mu}_i^c)$, where $\boldsymbol{\phi}_{\mathbf{K}}$ is the perspective projection [S1].
    *   Compute the 2D covariance using the Jacobian $\mathbf{J} \in \mathbb{R}^{2\times3}$ of the projection at $\boldsymbol{\mu}_i^c$ [S1][S10, unofficial]:
        $$ \tilde{\boldsymbol{\Sigma}}_i = \mathbf{J} \mathbf{W} \boldsymbol{\Sigma}_i \mathbf{W}^\top \mathbf{J}^\top $$
    *   The opacity and color are preserved: $\tilde{\sigma}_i = \sigma_i$ and $\tilde{c}_i = c_i$ [S1].
2.  **Rasterization:**
    *   Compute the 3-sigma bounding box in screen space to determine the rasterization area [S9, unofficial].
    *   Sort the $K$ Gaussians intersecting the view frustum by depth (distance from camera) [S10, unofficial].
    *   For each pixel, iterate over the sorted Gaussians. Compute the 2D Gaussian value at pixel $\mathbf{p}$:
        $$ \tilde{\mathcal{G}}_i(\mathbf{p}) = \exp\left(-\frac{1}{2}(\mathbf{p} - \tilde{\boldsymbol{\mu}}_i)^\top \tilde{\boldsymbol{\Sigma}}_i^{-1} (\mathbf{p} - \tilde{\boldsymbol{\mu}}_i)\right) $$
    *   Accumulate color using alpha compositing [S1][S10, unofficial]:
        $$ I_f(\mathbf{p}) = \sum_{i=1}^N c_i \tilde{\sigma}_i \tilde{\mathcal{G}}_i(\mathbf{p}) \prod_{j=1}^{i-1} \left(1 - \tilde{\sigma}_j \tilde{\mathcal{G}}_j(\mathbf{p})\right) $$
        where $N$ is the number of sorted Gaussians contributing to the pixel [S1].
3.  **Optimization:**
    *   Compare the rendered image $I_{\theta,i}$ to the ground truth $I_i$ using photometric loss (e.g., L1 + SSIM) [S10, unofficial].
    *   Backpropagate gradients to update $\boldsymbol{\mu}_i, \mathbf{q}_i, s_i, \sigma_i$, and SH coefficients using Adam [S10, unofficial].
    *   **Adaptive Density Control:** Periodically during training:
        *   **Clone:** Gaussians with high image error gradient are cloned to add detail [S1].
        *   **Split:** Gaussians that are too large (scale exceeds threshold) are split into smaller ones [S1].
        *   **Prune:** Gaussians with persistently low opacity are removed [S1].

**Pseudocode:**
```python
import numpy as np

def render_gaussians(gaussians, camera):
    """
    Render a scene of 3D Gaussians to a 2D image.
    gaussians: List of dicts with keys 'mu', 'q', 's', 'opacity', 'sh_coeffs'
    camera: Dict with 'W' (3x4 extrinsic), 'K' (3x3 intrinsic), 'width', 'height'
    """
    # 1. Project Gaussians to 2D
    projected = []
    for g in gaussians:
        # Transform center to camera space
        mu_cam = camera['W'] @ np.append(g['mu'], 1.0)
        
        # Perspective projection
        mu_2d_hom = camera['K'] @ mu_cam[:3]
        mu_2d = mu_2d_hom[:2] / mu_2d_hom[2]
        
        # Compute Jacobian J of projection at mu_cam
        # J approximates d(proj(x))/dx at x=mu_cam
        # For pinhole camera K*[R|t], J = K * [R_11/R_33 ...] 
        # Simplified: J = d(mu_2d)/d(mu_cam)
        # mu_2d = [K00*xc + K01*yc + K02*zc] / (K20*xc + K21*yc + K22*zc)
        # Let Z = mu_cam[2] (depth in camera frame)
        Z = mu_cam[2]
        J = np.zeros((2, 3))
        J[0, 0] = camera['K'][0, 0] / Z
        J[0, 1] = camera['K'][0, 1] / Z
        J[0, 2] = (camera['K'][0, 2] - mu_2d[0]) / Z
        J[1, 0] = camera['K'][1, 0] / Z
        J[1, 1] = camera['K'][1, 1] / Z
        J[1, 2] = (camera['K'][1, 2] - mu_2d[1]) / Z
        
        # Transform 3D covariance to camera space
        R = quat_to_rot(g['q'])
        Sigma_cam = R @ (R.T @ cov_from_scale_rot(g['s'], g['q'])) @ R.T
        
        # Project covariance to 2D
        Sigma_2d = J @ Sigma_cam @ J.T
        
        # Add small epsilon to diagonal for numerical stability
        Sigma_2d += np.eye(2) * 1e-6
        
        projected.append({
            'mu_2d': mu_2d,
            'Sigma_2d': Sigma_2d,
            'opacity': g['opacity'],
            'sh_coeffs': g['sh_coeffs'],
            'depth': mu_cam[2]
        })
    
    # 2. Sort by depth (back to front for alpha compositing)
    projected.sort(key=lambda x: x['depth'], reverse=True)
    
    # 3. Rasterize
    img = np.zeros((camera['height'], camera['width'], 3))
    T = np.ones((camera['height'], camera['width'])) # Transmittance
    
    for p in projected:
        # Compute bounding box
        # 3-sigma extent
        eigvals = np.linalg.eigvalsh(p['Sigma_2d'])
        extent = 3.0 * np.sqrt(eigvals)
        min_x = int(max(0, p['mu_2d'][0] - extent[0]))
        max_x = int(min(camera['width'], p['mu_2d'][0] + extent[0]))
        min_y = int(max(0, p['mu_2d'][1] - extent[1]))
        max_y = int(min(camera['height'], p['mu_2d'][1] + extent[1]))
        
        # Inverse 2D covariance (Conic)
        C = np.linalg.inv(p['Sigma_2d'])
        
        # Evaluate Gaussian in bounding box
        for y in range(min_y, max_y):
            for x in range(min_x, max_x):
                dx = x - p['mu_2d'][0]
                dy = y - p['mu_2d'][1]
                # Power = -0.5 * (C00*x^2 + C11*y^2 + 2*C01*xy)
                power = -0.5 * (C[0,0]*dx*dx + C[1,1]*dy*dy + 2*C[0,1]*dx*dy)
                
                if power > 0:
                    continue # Outside effective area
                
                alpha = p['opacity'] * np.exp(power)
                alpha = min(alpha, 0.99) # Clamp alpha
                
                if alpha < 1/255.0:
                    continue # Discard if too transparent
                
                # View-dependent color from SH
                # Simplified: assume fixed view direction or precomputed color
                # In practice, evaluate SH with viewing direction
                color = sh_eval(p['sh_coeffs'], camera['view_dir']) 
                
                # Alpha blending
                T_val = T[y, x]
                if T_val < 1e-5:
                    continue # Early termination
                
                blended_color = (1 - alpha) * img[y, x] + alpha * color * T_val
                img[y, x] = blended_color
                T[y, x] = T_val * (1 - alpha)
                
    return img

def cov_from_scale_rot(scale, quat):
    """Construct covariance from scale and rotation quaternion."""
    R = quat_to_rot(quat)
    S = np.diag(scale)
    return R @ S @ S.T @ R.T

def quat_to_rot(q):
    """Convert quaternion [w, x, y, z] to 3x3 rotation matrix."""
    w, x, y, z = q
    return np.array([
        [1 - 2*(y*y + z*z), 2*(x*y - w*z), 2*(x*z + w*y)],
        [2*(x*y + w*z), 1 - 2*(x*x + z*z), 2*(y*z - w*x)],
        [2*(x*z - w*y), 2*(y*z + w*x), 1 - 2*(x*x + y*y)]
    ])
```

## Subtopics

### [Unnormalized 3D Gaussian Function](1026-unnormalized-3d-gaussian-function.md)
Parameterizes the Gaussian via its peak value (opacity) rather than its integral, making the amplitude $a$ the intensity at the center.

### [Row-constant hoisting for Gaussian Splatting Rasterization](1195-row-constant-hoisting-for-gaussian-splatting-rasterization.md)
Optimizes the inner pixel loop by hoisting row-constant terms outside the loop to minimize arithmetic operations per pixel.

### [2D Gaussian Projection with Covariance Stabilization](1198-2d-gaussian-projection-with-covariance-stabilization.md)
Projects 3D Gaussians to 2D using a local affine approximation, solving perspective distortion while preserving the Gaussian form.

### [Gaussian in the Wild (GS-W)](1386-gaussian-in-the-wild-gs-w.md)
Separates intrinsic material properties from dynamic environmental factors, avoiding global latent embeddings to capture local high-frequency changes.

### [4D Gaussian Splatting](1458-4d-gaussian-splatting.md)
Extends 3DGS to dynamic scenes using a unified 4D covariance matrix to capture space-time motion, avoiding jitter from independent temporal weighting.

### [3DGUT](1474-3dgut.md)
Uses an unscented transform for Gaussian projection to improve affine approximation accuracy and reduce covariance errors.

### [Transformer-based Reconstruction](1794-transformer-based-reconstruction.md)
Predicts 3DGS parameters directly from 2D images using a feed-forward network, bypassing iterative optimization.

### [3D Gaussian Ellipsoid Rendering](1869-3d-gaussian-ellipsoid-rendering.md)

### [3D Gaussian Splatting Rendering (CPU-Sorted, Instanced)](2058-3d-gaussian-splatting-rendering-cpu-sorted-instanced.md)
Sorts Gaussians on the CPU and uses instanced rendering for simplicity and transparency ordering.

### [3D Gaussian Splatting Rendering (Software)](2805-3d-gaussian-splatting-rendering-software.md)

## Operating characteristics
**Time Complexity:** Rendering is $O(M)$ where $M$ is the number of Gaussians, but effectively $O(K \cdot P)$ per frame where $K$ is the number of visible Gaussians and $P$ is the number of pixels they cover. Tile-based rasterization makes it highly parallelizable on GPUs [S1][S5, unofficial].
**Memory Complexity:** $O(M)$ to store Gaussian parameters. Complex scenes require 200,000–500,000 Gaussians [S10, unofficial].
**Performance:** Achieves real-time rendering (≥30 fps at 1080p) on consumer hardware [S5, unofficial]. On the Mip-NeRF360 benchmark, it reaches 27.21 dB PSNR and 0.214 LPIPS at 134 fps [S5, unofficial].
**Strengths:** Real-time rendering, high visual fidelity, explicit representation allows easy editing and compression, differentiable for optimization [S1][S5, unofficial].
**Limitations:** Approximations in visibility (sorting by center) can cause popping artifacts; self-attenuation is ignored; emission-absorption model limits relighting capabilities [S2][S10, unofficial]. Standard anti-aliasing (dilation-based) fails with varying focal lengths [S10, unofficial].

## Background
3D Gaussian Splatting was introduced by Kerbl et al. in 2023 [S5, unofficial]. It builds on EWA Volume Splatting [S2][S3, unofficial] and point-based rendering methods [S2]. It was developed to overcome the computational costs of NeRF, which requires hundreds of MLP evaluations per pixel, and explicit grid structures that still rely on ray marching [S5, unofficial]. The method combines the volumetric image-formation model of radiance fields with the explicit storage of Plenoxels and the closed-form Gaussian projection of EWA [S5, unofficial]. It is used for novel-view synthesis, virtual walkthroughs, free-viewpoint replays, digital twins, and VR/AR content capture [S5, unofficial].
