# Normalized 3D Gaussian Function

Also called: Normal Distribution Helper, Normalized Gaussian, Probability Density Function Gaussian

## Overview
The Normalized 3D Gaussian Function is a probability density function (PDF) scaled to integrate to unity, serving as the fundamental building block for extinction models in EWA splatting and Gaussian Splatting [S1]. It differs from its sibling, the [Unnormalized 3D Gaussian Function](1026-unnormalized-3d-gaussian-function.md), by explicitly including the normalization constant $1/\mathcal{I}_D(\boldsymbol{\Sigma})$, ensuring the total integral over space equals one, whereas the unnormalized variant sets the peak amplitude at the mean $\boldsymbol{\mu}$ directly to the opacity parameter [S1].

## How it works
**Inputs:**
- $\mathbf{x} \in \mathbb{R}^3$: The evaluation point in 3D space.
- $\boldsymbol{\mu} \in \mathbb{R}^3$: The mean position (center) of the Gaussian.
- $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$: The covariance matrix defining the shape and orientation.
- $w \in \mathbb{R}$: The weight parameter representing the total capacity to block or emit light (equivalent to the unbounded integral of the function) [S1].

**Outputs:**
- $g \in \mathbb{R}$: The value of the weighted normalized Gaussian function at $\mathbf{x}$.

**Data Structures:**
- $\boldsymbol{\Sigma}$: A $3 \times 3$ symmetric positive-definite matrix. In implementation, this is often stored as 6 unique values or derived from a rotation matrix and scale vector.
- $\boldsymbol{\mu}$: A 3-component vector.
- $w$: A scalar.

**Steps:**
1. Compute the displacement vector: $\mathbf{d} = \mathbf{x} - \boldsymbol{\mu}$.
2. Compute the inverse covariance matrix $\boldsymbol{\Sigma}^{-1}$.
3. Compute the quadratic form: $Q = \mathbf{d}^T \boldsymbol{\Sigma}^{-1} \mathbf{d}$.
4. Compute the normalization factor $\mathcal{I}_3(\boldsymbol{\Sigma}) = \sqrt{(2\pi)^3 \det(\boldsymbol{\Sigma})}$.
5. Compute the normalized Gaussian value: $\mathcal{N}_3(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma}) = \frac{1}{\mathcal{I}_3(\boldsymbol{\Sigma})} e^{-\frac{1}{2} Q}$.
6. Scale by weight: $g = w \cdot \mathcal{N}_3(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma})$.

**Formulas:**
The normalized 3D Gaussian function is defined as [S1]:
$$
\mathcal{N}_{\mathcal{D}}(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma}) = \frac{1}{\mathcal{I}_{\mathcal{D}}(\boldsymbol{\Sigma})} e^{-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})}
$$
where $\mathcal{I}_{\mathcal{D}}(\boldsymbol{\Sigma})$ is the normalization factor [S1]:
$$
\mathcal{I}_D(\mathbf{\Sigma}) = \sqrt{(2\pi)^D \det(\mathbf{\Sigma})}
$$
The weighted normalized Gaussian function $\mathcal{G}_{\mathcal{D}}^n$ is [S1]:
$$
\mathcal{G}_{\mathcal{D}}^n(\mathbf{x}, w, \boldsymbol{\mu}, \boldsymbol{\Sigma}) = w \mathcal{N}_{\mathcal{D}}(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma})
$$
This ensures that the integral over all space equals $w$ [S1]:
$$
\int_{\mathbb{R}^D} \mathcal{G}_D^n(\mathbf{x}, w, \boldsymbol{\mu}, \boldsymbol{\Sigma}) \, d\mathbf{x} = w
$$

**Parameters:**
- $D$: Dimensionality. For 3D Gaussians, $D=3$ [S1].
- $\pi$: The mathematical constant Pi [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Singularity:** If $\boldsymbol{\Sigma}$ is singular (determinant is zero), the normalization factor becomes zero, leading to division by zero. $\boldsymbol{\Sigma}$ must be positive-definite [S1].
- **Precision:** Computing $\det(\boldsymbol{\Sigma})$ and $\boldsymbol{\Sigma}^{-1}$ directly can be numerically unstable if the Gaussian is highly anisotropic. [G] It is often more stable to compute the Cholesky decomposition or use the inverse directly if the matrix is well-conditioned.
- **Evaluation Point:** The formula is valid for any $\mathbf{x} \in \mathbb{R}^3$. However, for rendering, points far from $\boldsymbol{\mu}$ yield values close to zero.

**Pseudocode:**
```python
import math
import numpy as np

def normalized_3d_gaussian(x, mu, Sigma, w):
    """
    Computes the weighted normalized 3D Gaussian function.
    
    Args:
        x: numpy array, shape (3,), evaluation point.
        mu: numpy array, shape (3,), mean position.
        Sigma: numpy array, shape (3, 3), covariance matrix.
        w: float, weight parameter.
        
    Returns:
        float: Value of the normalized Gaussian scaled by w.
    """
    # 1. Displacement vector
    d = x - mu
    
    # 2. Inverse covariance matrix
    Sigma_inv = np.linalg.inv(Sigma)
    
    # 3. Quadratic form: d^T * Sigma_inv * d
    # Using dot product for efficiency: (d^T @ Sigma_inv) @ d
    quadratic_form = np.dot(d, np.dot(Sigma_inv, d))
    
    # 4. Normalization factor: sqrt((2*pi)^3 * det(Sigma))
    det_Sigma = np.linalg.det(Sigma)
    # Ensure det is non-negative to avoid NaNs due to floating point errors
    if det_Sigma < 0:
        det_Sigma = 0.0
    norm_factor = math.sqrt((2 * math.pi)**3 * det_Sigma)
    
    # Handle singularity
    if norm_factor == 0:
        return 0.0
        
    # 5. Normalized Gaussian value
    exponent = -0.5 * quadratic_form
    normalized_val = math.exp(exponent) / norm_factor
    
    # 6. Scale by weight
    result = w * normalized_val
    
    return result
```

## Subtopics

### [Gaussian Interpolation](2347-gaussian-interpolation.md)
Gaussian Interpolation uses a Gaussian function as an interpolation kernel to reconstruct signals from discrete samples. It builds on the [Normalized 3D Gaussian Function](1064-normalized-3d-gaussian-function.md) and is distinguished from other filters by being the only filter that is both separable and rotationally symmetric. This unique property allows it to integrate one dimension out of the kernel, enabling 2D reconstruction instead of 3D, which is particularly advantageous in point-tossing approaches like splatting.

### [2D Gaussian Probability Density (Standard)](3466-2d-gaussian-probability-density-standard.md)
Computes the probability density function (PDF) value of a 2D Gaussian distribution at a specific point $(x, y)$, given its mean vector and covariance matrix. It serves as the core evaluation kernel for determining the contribution of a projected 3D Gaussian splat to a pixel in Gaussian Splatting rendering. Unlike the unnormalized variant, this method includes the normalization constant $1/(2\pi\sqrt{\det(\Sigma)})$, ensuring the integral over the entire plane equals one. It is distinct from the conic-based variant by explicitly computing the inverse covariance matrix rather than using a pre-computed conic matrix.

### Gaussian Mixture Extinction Model
Modeling the extinction function $f(x)$ as a mixture of normalized 3D Gaussians, each potentially having a view-dependent radiance $c_i(R)$ [S1]. The extinction function is defined as [S1]:
$$
\mathbf{f}(\mathbf{x}) = \sum_{i=0}^N \mathcal{G}_3^n(\mathbf{x}, w_i, \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i)
$$
The radiance contribution is [S1]:
$$
c(\mathcal{R}, t) = \sum_{i=0}^N c_i(\mathcal{R}) \mathcal{G}_3^n(\mathbf{x}, w_i, \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i)
$$
where $c_i(R)$ is the radiance for ray $R$. The exact volumetric integration solution for Gaussian mixtures is [S1]:
$$
I(\mathbf{p}) = \int_0^\infty \sum_{i=0}^N c_i(\mathcal{R}) \mathcal{G}_3^n(\mathcal{R}(t), i) e^{-\int_0^t \sum_{i=0}^N \mathcal{G}_3^n(\mathcal{R}(t), i) \, dt} \, dt
$$

## Operating characteristics
- **Time Complexity:** Evaluating a single Gaussian is $O(1)$ with respect to the number of Gaussians, but requires matrix inversion and determinant calculation for $\boldsymbol{\Sigma}$, which is $O(1)$ for fixed $3 \times 3$ size. Rendering a scene with $N$ Gaussians is $O(N)$ per pixel.
- **Memory Complexity:** $O(N)$ to store $\boldsymbol{\mu}$, $\boldsymbol{\Sigma}$, and $w$ for each Gaussian.
- **Strengths:** Provides a smooth, continuous representation of density/extinction. The normalization ensures that $w$ has a direct physical interpretation as total integrated density or opacity capacity [S1].
- **Limitations:** Requires computing the inverse and determinant of the covariance matrix, which can be computationally expensive compared to unnormalized variants where these terms cancel out [S1].
- **When to use:** When accurate volumetric integration is required, or when the total integrated density/opacity is a more meaningful parameter than the peak amplitude [S1].

## Background
The normalized 3D Gaussian function originates from the mathematical theory of Gaussian distributions and is used as a building block for EWA (Elliptical Weighted Average) splatting [S1]. It was adopted in 3D Gaussian Splatting [KKLD23] and other rendering techniques to model extinction functions [S1]. The formulation is also employed in the derivation of NeRF methodology, where the extinction coefficient is referred to as density [S1].
