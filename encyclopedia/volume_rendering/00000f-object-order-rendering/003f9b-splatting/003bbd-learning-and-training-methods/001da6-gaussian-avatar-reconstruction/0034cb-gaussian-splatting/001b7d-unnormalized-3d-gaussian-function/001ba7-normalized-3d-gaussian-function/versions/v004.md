# Normalized 3D Gaussian Function

Also called: Normal Distribution Helper, Normalized Gaussian, Probability Density Function Gaussian

## Overview
The Normalized 3D Gaussian Function is a probability density function (PDF) scaled to integrate to unity, serving as the fundamental building block for extinction models in EWA splatting and Gaussian Splatting [S1]. It differs from its sibling, the [Unnormalized 3D Gaussian Function](1026-unnormalized-3d-gaussian-function.md), by explicitly including the normalization constant $1/\mathcal{I}_D(\boldsymbol{\Sigma})$, ensuring the total integral over space equals one, whereas the unnormalized variant sets the peak amplitude at the mean $\boldsymbol{\mu}$ directly to the opacity parameter [S1].

## How it works
**Inputs:**
- $\mathbf{x} \in \mathbb{R}^3$: The evaluation point in 3D space [S1].
- $\boldsymbol{\mu} \in \mathbb{R}^3$: The mean position (center) of the Gaussian [S1].
- $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$: The covariance matrix defining the shape and orientation [S1].
- $w \in \mathbb{R}$: The weight parameter representing the total capacity to block or emit light (equivalent to the unbounded integral of the function) [S1].

**Outputs:**
- $g \in \mathbb{R}$: The value of the weighted normalized Gaussian function at $\mathbf{x}$ [S1].

**Data Structures:**
- $\boldsymbol{\Sigma}$: A $3 \times 3$ symmetric matrix representing covariance [S1].
- $\boldsymbol{\mu}$: A 3-component vector [S1].
- $w$: A scalar weight [S1].

**Steps:**
1. Compute the displacement vector: $\mathbf{d} = \mathbf{x} - \boldsymbol{\mu}$ [S1].
2. Compute the inverse covariance matrix $\boldsymbol{\Sigma}^{-1}$ [G].
3. Compute the quadratic form: $Q = \mathbf{d}^T \boldsymbol{\Sigma}^{-1} \mathbf{d}$ [S1].
4. Compute the normalization factor $\mathcal{I}_3(\boldsymbol{\Sigma}) = \sqrt{(2\pi)^3 \det(\boldsymbol{\Sigma})}$ [S1].
5. Compute the normalized Gaussian value: $\mathcal{N}_3(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma}) = \frac{1}{\mathcal{I}_3(\boldsymbol{\Sigma})} e^{-\frac{1}{2} Q}$ [S1].
6. Scale by weight: $g = w \cdot \mathcal{N}_3(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma})$ [S1].

**Formulas:**
The normalized 3D Gaussian function is defined as [S1]:
$$
\mathcal{N}_{\mathcal{D}}(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma}) = \frac{1}{\mathcal{I}_{\mathcal{D}}(\boldsymbol{\Sigma})} e^{-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})}
$$
where $\mathcal{I}_{\mathcal{D}}(\boldsymbol{\Sigma})$ is the normalization factor [S1]:
$$
\mathcal{I}_D(\mathbf{\Sigma}) = \sqrt{(2\pi)^D \det(\mathbf{\Sigma})}
$$
The weighted normalized Gaussian function $\mathcal{G}_{\mathcal{D}}^n$ is [S1]:
$$
\mathcal{G}_{\mathcal{D}}^n(\mathbf{x}, w, \boldsymbol{\mu}, \boldsymbol{\Sigma}) = w \mathcal{N}_{\mathcal{D}}(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma})
$$
This ensures that the integral over all space equals $w$ [S1]:
$$
\int_{\mathbb{R}^D} \mathcal{G}_D^n(\mathbf{x}, w, \boldsymbol{\mu}, \boldsymbol{\Sigma}) \, d\mathbf{x} = w
$$

**Parameters:**
- $D$: Dimensionality. For 3D Gaussians, $D=3$ [S1].
- $\pi$: The mathematical constant Pi [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Singularity:** If $\boldsymbol{\Sigma}$ is singular (determinant is zero), the normalization factor becomes zero, leading to division by zero [S1].
- **Precision:** Computing $\det(\boldsymbol{\Sigma})$ and $\boldsymbol{\Sigma}^{-1}$ directly can be numerically unstable if the Gaussian is highly anisotropic [G]. It is often more stable to compute the Cholesky decomposition or use the inverse directly if the matrix is well-conditioned [G].
- **Evaluation Point:** The formula is valid for any $\mathbf{x} \in \mathbb{R}^3$ [G]. However, for rendering, points far from $\boldsymbol{\mu}$ yield values close to zero [G].

**Pseudocode:**
```python
import math

def det3(M):
    return (M[0][0]*(M[1][1]*M[2][2]-M[1][2]*M[2][1])
          - M[0][1]*(M[1][0]*M[2][2]-M[1][2]*M[2][0])
          + M[0][2]*(M[1][0]*M[2][1]-M[1][1]*M[2][0]))

def inv3(M):
    d = det3(M)
    if d == 0: return None
    inv_d = 1.0 / d
    return [
        [(M[1][1]*M[2][2]-M[1][2]*M[2][1])*inv_d, (M[0][2]*M[2][1]-M[0][1]*M[2][2])*inv_d, (M[0][1]*M[1][2]-M[0][2]*M[1][1])*inv_d],
        [(M[1][2]*M[2][0]-M[1][0]*M[2][2])*inv_d, (M[0][0]*M[2][2]-M[0][2]*M[2][0])*inv_d, (M[0][2]*M[1][0]-M[0][0]*M[1][2])*inv_d],
        [(M[1][0]*M[2][1]-M[1][1]*M[2][0])*inv_d, (M[0][1]*M[2][0]-M[0][0]*M[2][1])*inv_d, (M[0][0]*M[1][1]-M[0][1]*M[1][0])*inv_d]
    ]

def normalized_3d_gaussian(x, mu, Sigma, w):
    # 1. Displacement vector
    d = [x[i] - mu[i] for i in range(3)]
    
    # 2. Inverse covariance matrix
    Sigma_inv = inv3(Sigma)
    if Sigma_inv is None:
        return 0.0
        
    # 3. Quadratic form: d^T * Sigma_inv * d
    temp = [sum(Sigma_inv[i][j] * d[j] for j in range(3)) for i in range(3)]
    quadratic_form = sum(d[i] * temp[i] for i in range(3))
    
    # 4. Normalization factor: sqrt((2*pi)^3 * det(Sigma))
    det_Sigma = det3(Sigma)
    if det_Sigma < 0: det_Sigma = 0.0
    norm_factor = math.sqrt((2 * math.pi)**3 * det_Sigma)
    
    if norm_factor == 0:
        return 0.0
        
    # 5. Normalized Gaussian value
    exponent = -0.5 * quadratic_form
    normalized_val = math.exp(exponent) / norm_factor
    
    # 6. Scale by weight
    return w * normalized_val
```

## Subtopics

### [Gaussian Interpolation](2347-gaussian-interpolation.md)
Gaussian Interpolation uses a Gaussian function as an interpolation kernel to reconstruct signals from discrete samples. It builds on the [Normalized 3D Gaussian Function](1064-normalized-3d-gaussian-function.md) and is distinguished from other filters by being the only filter that is both separable and rotationally symmetric. This unique property allows it to integrate one dimension out of the kernel, enabling 2D reconstruction instead of 3D, which is particularly advantageous in point-tossing approaches like splatting.

### [2D Gaussian Probability Density (Standard)](3466-2d-gaussian-probability-density-standard.md)
Computes the probability density function (PDF) value of a 2D Gaussian distribution at a specific point $(x, y)$, given its mean vector and covariance matrix [G]. It serves as the core evaluation kernel for determining the contribution of a projected 3D Gaussian splat to a pixel in Gaussian Splatting rendering [G]. Unlike the unnormalized variant, this method includes the normalization constant $1/(2\pi\sqrt{\det(\Sigma)})$, ensuring the integral over the entire plane equals one [G]. It is distinct from the conic-based variant by explicitly computing the inverse covariance matrix rather than using a pre-computed conic matrix [G].

### Gaussian Mixture Extinction Model
Modeling the extinction function $f(\mathbf{x})$ as a mixture of normalized 3D Gaussians, each potentially having a view-dependent radiance $c_i(\mathcal{R})$ [S1]. The extinction function is defined as [S1]:
$$
\mathbf{f}(\mathbf{x}) = \sum_{i=0}^N \mathcal{G}_3^n(\mathbf{x}, w_i, \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i)
$$
The radiance contribution is [S1]:
$$
c(\mathcal{R}, t) = \sum_{i=0}^N c_i(\mathcal{R}) \mathcal{G}_3^n(\mathbf{x}, w_i, \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i)
$$
where $c_i(\mathcal{R})$ is the radiance for ray $\mathcal{R}$ [S1]. The exact volumetric integration solution for Gaussian mixtures is [S1]:
$$
I(\mathbf{p}) = \int_0^\infty \sum_{i=0}^N c_i(\mathcal{R}) \mathcal{G}_3^n(\mathcal{R}(t), w_i, \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i) e^{-\int_0^t \sum_{i=0}^N \mathcal{G}_3^n(\mathcal{R}(\tau), w_i, \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i) \, d\tau} \, dt
$$

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Provides a smooth, continuous representation of density/extinction. The normalization ensures that $w$ has a direct physical interpretation as total integrated density or opacity capacity [S1].
- **Limitations:** Requires computing the inverse and determinant of the covariance matrix, which can be computationally expensive compared to unnormalized variants where these terms cancel out [S1].

## Background
The normalized 3D Gaussian function originates from the mathematical theory of Gaussian distributions and is used as a building block for EWA (Elliptical Weighted Average) splatting [S1]. It was adopted in 3D Gaussian Splatting [KKLD23] and other rendering techniques to model extinction functions [S1]. The formulation is also employed in the derivation of NeRF methodology, where the extinction coefficient is referred to as density [S1].
