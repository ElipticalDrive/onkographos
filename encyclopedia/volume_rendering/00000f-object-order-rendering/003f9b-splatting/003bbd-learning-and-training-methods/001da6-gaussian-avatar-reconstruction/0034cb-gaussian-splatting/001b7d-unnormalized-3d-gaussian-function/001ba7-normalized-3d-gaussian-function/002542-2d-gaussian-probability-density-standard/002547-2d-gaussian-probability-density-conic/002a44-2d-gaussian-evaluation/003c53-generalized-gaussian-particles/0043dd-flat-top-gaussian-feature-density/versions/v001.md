# Flat-top Gaussian Feature Density

Also called: Flat-top Gaussian, Generalized Gaussian with high degree, Super-gaussian feature density

## Overview
Flat-top Gaussian Feature Density provides a differentiable approximation of feature density using a class of Gaussian functions that become more box-like as the parameter $p$ increases [S1]. It solves the problem of non-differentiability in standard box-based feature grids, enabling the learning of transformation matrices (scales, translations) based on error gradients from points outside the local domain [S1]. It sets itself apart from standard Gaussian splatting by using a high-degree exponent to mimic the sharp boundaries of a grid cell while maintaining global differentiability [S1].

## How it works
**Inputs and Outputs:**
- Input: A query point $x$ in 3D space, a set of $M$ grid cells (particles), and the flat-top strength parameter $p$.
- Output: The scalar feature density $\rho(x)$ at point $x$.

**Data Structures:**
- Each particle $i$ ($0 \le i < M$) stores a transformation matrix $G_i$. The method uses the sub-matrix $G_{i,0:3,0:3}$ representing the linear transformation.
- The local coordinate space for each particle is centered at 0 with a standard deviation of 1.

**Formulas:**
The general 1D flat-top Gaussian function is defined as [S1]:
$$g(x, p) = A \exp \left( - \left( \frac{(x - \mu)^{2p}}{2\sigma^2} \right) \right)$$
where:
- $A$: Normalizing coefficient.
- $x$: Location.
- $\mu$: Center of the distribution.
- $\sigma$: Standard deviation.
- $p$: Strength of the flat-top.

The total feature density $\rho(x)$ is the sum of contributions from all $M$ particles [S1]:
$$\rho(x) = \sum_{i=0}^{M-1} \left( \det(G_{i,0:3,0:3}) \cdot \exp \left( - \left( \sum_{d=0}^2 (G_i(x)_d)^{2p} \right) \right) \right)$$
where $G_i(x)_d$ is the transformed coordinate for axis $d \in \{0, 1, 2\}$ (x, y, z). In the transformed space, $\mu=0$ and $\sigma=1$, so these terms are omitted [S1].

**Parameters:**
- $p = 10$: Experimentally found to be strong enough to match the box shape of the feature grid without causing exploding gradients on the ramps to and from the flat-top [S1].

**Pseudocode:**
```python
def flat_top_gaussian_feature_density(x, particles, p=10):
    """
    Calculate the flat-top Gaussian feature density at point x.
    
    Args:
        x: numpy array of shape (3,), the query point in world space.
        particles: List of objects, each having a 'transform_matrix' attribute 
                   of shape (4, 4) or (3, 3). The method uses the top-left 3x3 submatrix.
        p: Integer, strength of the flat-top (default 10).
        
    Returns:
        float: The total feature density rho(x).
    """
    total_density = 0.0
    
    for particle in particles:
        # Extract the 3x3 linear transformation matrix G_i
        G = particle.transform_matrix[0:3, 0:3]
        
        # Calculate determinant of the 3x3 matrix
        det_G = np.linalg.det(G)
        
        # Transform the query point x into the local coordinate space of the particle
        # Since the local space is centered at 0, we assume G includes translation 
        # or x is already relative. Based on the formula G_i(x)_d, G is applied to x.
        # Note: If G is affine, x should be homogeneous or G includes translation.
        # The source implies G_i(x) is the transformed coordinate. 
        # Assuming G is a 3x3 linear transform for the coordinates relative to center 0.
        local_coords = np.dot(G, x)
        
        # Calculate the sum of powered coordinates for d=0,1,2
        sum_powered = 0.0
        for d in range(3):
            coord_d = local_coords[d]
            # Compute (coord_d)^(2p)
            # Using abs to handle negative bases with even integer powers safely, 
            # though (x^2p) is always positive for real x if 2p is even.
            # p=10 -> 2p=20.
            term = coord_d ** (2 * p)
            sum_powered += term
            
        # Compute the exponential term
        # exp( - sum_powered )
        # Note: The 1D formula has 2*sigma^2 in denominator. 
        # The source states sigma=1 in transformed space, so 2*sigma^2 = 2.
        # However, the final formula (7) in [S1] does NOT show a 2 in the denominator 
        # inside the exp for the multi-dimensional case. It shows exp( - (sum ...) ).
        # We follow formula (7) exactly.
        exp_term = np.exp(-sum_powered)
        
        # Add contribution
        total_density += det_G * exp_term
        
    return total_density
```

**Edge Cases and Pitfalls:**
- **Exploding Gradients:** If $p$ is too large, gradients may explode on the ramps to and from the flat-top [S1]. $p=10$ is a safe upper bound [S1].
- **Non-differentiability:** Standard box functions are not differentiable everywhere, which prevents proper training of grid scales and translations [S1]. The flat-top Gaussian ensures differentiability everywhere [S1].

## Subtopics

### [Target Feature Density Calculation](11134-target-feature-density-calculation.md)
A target feature density $\rho^*(x)$ used to steer the current feature density $\rho(x)$ during training, increasing density where error is high and decreasing it where error is low.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of particles $M$, as it requires iterating over all particles to sum their contributions [S1].
- **Memory Complexity:** Linear with respect to $M$ to store the transformation matrices [S1].
- **Strengths:** Provides a smooth, differentiable approximation of box-like feature grids, enabling gradient-based optimization of grid parameters (scales, translations) [S1].
- **Limitations:** Requires tuning the parameter $p$ to balance box-like shape fidelity against gradient stability [S1].
- **When to use:** When training adaptive grid-based scene representations where differentiability of the density function is required for backpropagation [S1].
- **When not to use:** When exact box-based density is required without approximation, or when computational cost of evaluating $M$ particles is prohibitive.

## Background
The method originates from the work on Adaptively Placed Multi-Grid Scene Representation Networks for Large-Scale Data Visualization [S1]. It was introduced to address the lack of differentiability in feature density calculations for grid-based scene representations, allowing for the learning of transformation matrices based on error gradients [S1].
