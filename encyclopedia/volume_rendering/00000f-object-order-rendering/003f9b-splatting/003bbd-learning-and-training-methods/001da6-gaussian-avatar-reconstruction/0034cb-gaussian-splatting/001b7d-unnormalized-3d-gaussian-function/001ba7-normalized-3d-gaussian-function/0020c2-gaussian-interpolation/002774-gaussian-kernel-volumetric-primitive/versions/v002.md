# Gaussian Kernel Volumetric Primitive

Also called: 3D Gaussian PDF for Volume Rendering, 3D Gaussian Splatting (Method), Normalized Gaussian Kernel

## Overview
A method for volumetric rendering that represents a scene as a set of 3D Gaussian distributions, parameterized by mean (position), covariance (shape/direction), and color, allowing for efficient simulation of 3D structure details without meshing [S2, unofficial]. It differs from traditional mesh-based reconstruction by avoiding meshing processes and from NeRF by offering faster training and rendering speeds while maintaining comparable quality [S2, unofficial]. Unlike other kernel methods like Epanechnikov, Gaussian kernels have infinite support, which requires clipping to maintain efficiency [S1, unofficial].

## How it works
**Inputs:** A set of 3D points (point cloud) or primitives, each defined by a mean position $\mathbf{c}_i$, a covariance matrix $\Sigma_i$, and color attributes [S2, unofficial].
**Outputs:** A 2D image with pixel colors and alpha values [S2, unofficial].

**Data Structures:**
Each primitive $i$ is stored with:
- $\mathbf{c}_i \in \mathbb{R}^3$: Mean position (XYZ).
- $\Sigma_i \in \mathbb{R}^{3 \times 3}$: Covariance matrix defining shape and orientation.
- Color attributes (e.g., RGB) [S2, unofficial].

**Steps:**
1. **Parameterization:** Each point in the input point cloud is parameterized as a Gaussian kernel defined by its mean, covariance, and color [S2, unofficial]. The normalized Gaussian kernel function is:
    $$
    g_i(\mathbf{x}) = \frac{1}{(2\pi)^{3/2} |\Sigma_i|^{1/2}} e^{-\frac{1}{2} (\mathbf{x}-\mathbf{c}_i)^T \Sigma_i^{-1} (\mathbf{x}-\mathbf{c}_i)}
    $$
    where $\mathbf{c}_i$ is the center and $\Sigma_i$ is the covariance matrix [S1, unofficial].

2. **Projection:** Each 3D Gaussian is projected from 3D space onto the 2D screen space to determine its influence range and size [S2, unofficial].

3. **Transmittance and Sampling:** For ray tracing, transmittance is computed using the error function ($\text{erf}$) for a closed-form solution [S1, unofficial]. Free-flight distance for a single Gaussian primitive is sampled using the inverse error function ($\text{erf}^{-1}$) for a closed-form solution [S1, unofficial].

4. **Blending:** The contributions of all Gaussians are combined using alpha blending to generate the final pixel color [S2, unofficial]. Alpha blending allows multiple Gaussian points to combine smoothly, handling complex lighting and reflections [S2, unofficial].

**Pitfalls:**
- Gaussian kernels have infinite support, requiring clipping to avoid evaluating all primitives, which reduces efficiency [S1, unofficial].

**Pseudocode:**
```python
import math

def compute_alpha_gaussian(gaussian, ray_direction):
    # Computes alpha using closed-form erf solution for transmittance along a ray [S1, unofficial]
    # Projects 3D Gaussian to 2D and integrates density along ray [G]
    cov_2d = gaussian['cov_2d']
    # Simplified 1D Gaussian integral along ray direction
    # alpha = 1 - exp(-integral) relates to erf for Gaussian profiles [S1, unofficial]
    variance = ray_direction[0]**2 * cov_2d[0][0] + ray_direction[1]**2 * cov_2d[1][1]
    if variance == 0:
        return 0.0
    alpha = math.erf(1.0 / math.sqrt(2 * variance))
    return min(alpha, 1.0)

def get_bounding_box_2d(cov_2d, center_2d, scale=3.0):
    # Returns (y_min, y_max, x_min, x_max) for a 2D Gaussian bounding box
    eigenvalues = [cov_2d[0][0], cov_2d[1][1]] # Simplified diagonal approximation [G]
    radii = [scale * math.sqrt(e) for e in eigenvalues]
    y_min = center_2d[0] - radii[0]
    y_max = center_2d[0] + radii[0]
    x_min = center_2d[1] - radii[1]
    x_max = center_2d[1] + radii[1]
    return (y_min, y_max, x_min, x_max)

def clip_to_image(bbox, width, height):
    y_min, y_max, x_min, x_max = bbox
    y_min = max(0, int(math.floor(y_min)))
    y_max = min(height, int(math.ceil(y_max)))
    x_min = max(0, int(math.floor(x_min)))
    x_max = min(width, int(math.ceil(x_max)))
    if y_max <= y_min or x_max <= x_min:
        return None
    return (y_min, y_max, x_min, x_max)

def render_gaussian_volumetric(scene_gaussians, camera, image_width, image_height):
    color_image = [[0.0, 0.0, 0.0] for _ in range(image_height * image_width)]
    alpha_image = [0.0 for _ in range(image_height * image_width)]
    transmittance = [1.0 for _ in range(image_height * image_width)]

    for gaussian in scene_gaussians:
        c_i = gaussian['mean']
        Sigma_i = gaussian['cov']
        color = gaussian['color']

        # Project 3D Gaussian to 2D screen space to determine influence range and size [S2, unofficial]
        # Simplified projection: assume camera projects to 2D center and 2D covariance
        center_2d = [c_i[1], c_i[0]] # Placeholder for actual projection math [G]
        cov_2d = [[Sigma_i[0][0], Sigma_i[0][1]], [Sigma_i[1][0], Sigma_i[1][1]]] # Simplified 2D covariance extraction [G]

        bbox = get_bounding_box_2d(cov_2d, center_2d)
        bbox = clip_to_image(bbox, image_width, image_height)
        if bbox is None:
            continue

        y_min, y_max, x_min, x_max = bbox

        for y in range(y_min, y_max):
            for x in range(x_min, x_max):
                pixel_idx = y * image_width + x
                pixel_center = [y, x]
                # Compute alpha using erf-based closed-form solution [S1, unofficial]
                alpha = compute_alpha_gaussian(gaussian, [0.0, 0.0, 1.0])

                # Alpha blending: C_out = C_in * T + C_gauss * (1 - T), T_out = T_in * (1 - alpha)
                current_alpha = alpha_image[pixel_idx]
                current_color = color_image[pixel_idx]
                T = transmittance[pixel_idx]

                blend_factor = alpha * T
                color_image[pixel_idx] = [
                    current_color[0] * T + color[0] * blend_factor,
                    current_color[1] * T + color[1] * blend_factor,
                    current_color[2] * T + color[2] * blend_factor
                ]
                alpha_image[pixel_idx] += alpha * T
                transmittance[pixel_idx] *= (1 - alpha)

    return color_image, alpha_image
```

## Operating characteristics
- **Time Complexity:** Rendering is efficient, achieving real-time performance [S2, unofficial].
- **Memory Complexity:** Depends on the number of Gaussians $N$ [S2, unofficial].
- **Performance:** Achieves high-quality real-time view synthesis at 1080p resolution with a frame rate of ≥ 100 fps (or ≥ 30 fps in other cited contexts) for unbounded, complete scenes [S2, unofficial].
- **Strengths:** Faster training and rendering speeds compared to NeRF [S2, unofficial]. Does not require meshing [S2, unofficial]. Integrates with physical-based rendering engines (scattering, emissive media) [S1, unofficial].
- **Limitations:** Infinite support of Gaussian kernels requires clipping, reducing efficiency compared to finite-support kernels like Epanechnikov [S1, unofficial]. Epanechnikov kernels may be faster and better for sharp edges [S1, unofficial].

## Background
3D Gaussian Splatting is a method for 3D reconstruction and rendering that represents a point cloud as a set of 3D Gaussian distributions [S2, unofficial]. It efficiently simulates 3D structure details without meshing [S2, unofficial]. The approach is used in 3D reconstruction and rendering [S2, unofficial]. It is part of the Gaussian Splatting family, which aims to provide faster alternatives to Neural Radiance Fields (NeRF) [S2, unofficial].
