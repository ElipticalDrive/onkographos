# 2D Gaussian Evaluation

Also called: 2D Gaussian PDF exponent

## Overview
Computes the exponent term of the 2D Gaussian probability density function at given 2D points, used for rasterization or shading [S1, unofficial]. It builds on [2D Gaussian Probability Density (Conic)](3475-2d-gaussian-probability-density-conic.md) by calculating the quadratic form required to determine the unnormalized density value before applying the exponential function.

## How it works
**Inputs:**
- `points_2D`: Tensor of shape $(N, 2)$ containing the 2D query coordinates.
- `means_2D`: Tensor of shape $(M, 2)$ containing the 2D means of the Gaussians.
- `cov_2D_inv`: Tensor of shape $(M, 2, 2)$ containing the inverse covariance matrices for each Gaussian.

**Outputs:**
- `power`: Tensor of shape $(N, M)$ containing the exponent values $P$ for each point-Gaussian pair.

**Data Structures:**
- `xm`: Difference vector tensor.
- `xm_col`: Column vector tensor for batched multiplication.
- `xm_row`: Row vector tensor for batched multiplication.
- `cov_2D_inv`: Inverse covariance matrix tensor.

**Steps:**
1. Compute the difference vector between query points and 2D means: $\mathbf{x}_m = \text{points\_2D} - \text{means\_2D}$.
2. Reshape the difference vector for batched matrix multiplication:
   - $\mathbf{x}_m^{\text{col}} = \text{unsqueeze}(\mathbf{x}_m, -1)$
   - $\mathbf{x}_m^{\text{row}} = \text{unsqueeze}(\mathbf{x}_m, -2)$
3. Ensure `cov_2D_inv` is unsqueezed for broadcasting: $\mathbf{C}_{2D}^{-1} = \text{unsqueeze}(\text{cov\_2D\_inv}, 1)$.
4. Compute the quadratic form and scale by $-0.5$:
   $$ P = -0.5 \times (\mathbf{x}_m^{\text{row}} @ \mathbf{C}_{2D}^{-1} @ \mathbf{x}_m^{\text{col}}).\text{squeeze}(-1).\text{squeeze}(-1) $$

**Formula:**
$$ P = -\frac{1}{2} (\mathbf{x}_m^T \mathbf{C}_{2D}^{-1} \mathbf{x}_m) $$
where $\mathbf{x}_m$ is the $2 \times 1$ difference vector, $\mathbf{C}_{2D}^{-1}$ is the $2 \times 2$ inverse covariance, and $P$ is the exponent value [S1, unofficial].

**Pseudocode:**
```python
def evaluate_2d_gaussian(points_2d, means_2d, cov_2d_inv):
    """
    Computes the exponent term of the 2D Gaussian PDF.
    
    Args:
        points_2d: Tensor of shape (N, 2)
        means_2d: Tensor of shape (M, 2)
        cov_2d_inv: Tensor of shape (M, 2, 2)
        
    Returns:
        power: Tensor of shape (N, M)
    """
    # Step 1: Compute difference vector
    # Broadcasting: points_2d (N, 2) - means_2d (1, M, 2) -> (N, M, 2)
    # Note: Assuming means_2d is broadcastable or expanded to match points_2d
    # If means_2d is (M, 2), we need to expand it to (1, M, 2) for broadcasting with (N, 2)
    xm = points_2d.unsqueeze(1) - means_2d.unsqueeze(0)  # Shape: (N, M, 2)
    
    # Step 2: Reshape for batched matrix multiplication
    xm_col = xm.unsqueeze(-1)  # Shape: (N, M, 2, 1)
    xm_row = xm.unsqueeze(-2)  # Shape: (N, M, 1, 2)
    
    # Step 3: Prepare covariance inverse for broadcasting
    # cov_2d_inv is (M, 2, 2). We need it to be (1, M, 2, 2) to broadcast with (N, M, ...)
    cov_2d_inv_expanded = cov_2d_inv.unsqueeze(0)  # Shape: (1, M, 2, 2)
    
    # Step 4: Compute quadratic form
    # xm_row (N, M, 1, 2) @ cov_2d_inv_expanded (1, M, 2, 2) -> (N, M, 1, 2)
    temp = torch.matmul(xm_row, cov_2d_inv_expanded)
    # temp (N, M, 1, 2) @ xm_col (N, M, 2, 1) -> (N, M, 1, 1)
    power = torch.matmul(temp, xm_col)
    
    # Squeeze the last two dimensions
    power = power.squeeze(-1).squeeze(-1)  # Shape: (N, M)
    
    # Scale by -0.5
    power = -0.5 * power
    
    return power
```

**Edge cases and pitfalls:**
- Precision: Matrix inversion for `cov_2D_inv` should be handled with care to avoid numerical instability if the covariance matrix is near-singular.
- Boundaries: Ensure that `points_2D` and `means_2D` are in the same coordinate system.
- Degenerate input: If `cov_2D_inv` is not valid (e.g., due to singular covariance), the result will be undefined or NaN.

## Subtopics

### [Generalized Gaussian Particles](9164-generalized-gaussian-particles.md)
Generalized Gaussian Particles replace the standard quadratic exponent in the 2D Gaussian probability density function with a power-law exponent controlled by a degree parameter $n$. This modification allows for steeper and narrower density fall-off, enabling denser particle packing and finer control over the trade-off between rendering quality and computational speed compared to standard Gaussians.

## Operating characteristics
- Time complexity: $O(N \cdot M)$ for $N$ points and $M$ Gaussians, due to the matrix multiplications.
- Memory complexity: $O(N \cdot M)$ to store the intermediate tensors.
- Measured performance: Not given in the sources.
- Scaling: Scales linearly with the number of points and Gaussians.
- Strengths: Efficient batched computation using matrix operations.
- Limitations: High memory usage for large $N$ and $M$.
- When to use: When rasterizing or shading with 2D Gaussians.
- When not to use: When memory is constrained or $N$ and $M$ are very large.
