# Large Reconstruction Model (LRM)
Also called: LRM (Large Reconstruction Model)
## Overview
LRM is a feedforward neural network designed for single-image to 3D reconstruction [S1, unofficial]. It addresses the slow iterative optimization of prior methods by directly predicting 3D representations from input images [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A single RGB image $I$ [S1, unofficial].
- Output: A set of 3D parameters (e.g., Gaussian attributes or fields) [S1, unofficial].

**Data Structures:**

**Steps:**
1. Encode the input image into feature tokens [S1, unofficial].
2. Process the tokens through a transformer to model spatial and geometric relationships [S1, unofficial].
3. Decode the transformer output directly into 3D parameters [S1, unofficial].
4. Render the predicted parameters to generate novel views [S1, unofficial].

## Subtopics

### [Large Gaussian Reconstruction Model (GRM)](5961-large-gaussian-reconstruction-model-grm.md)
The Large Gaussian Reconstruction Model (GRM) is a feedforward neural network that performs single-image (or multi-view) to 3D reconstruction by directly predicting a set of 3D Gaussians. It addresses the limitations of iterative optimization methods (like NeRF or standard 3DGS) by providing immediate, differentiable 3D representations from input images. It builds on [Large Reconstruction Model (LRM)](5959-large-reconstruction-model-lrm.md) by replacing the output format (e.g., NeRF fields or meshes) with Gaussian maps, supporting both single and multi-view inputs.

## Background
LRM was introduced in "LRM: Large Reconstruction Model for Single Image to 3D" at ICLR 2024 [S1, unofficial]. It follows ReconFusion, which used diffusion priors, as part of the evolution toward feedforward direct prediction [S1, unofficial].
