# Large Reconstruction Model (LRM)
Also called: LRM (Large Reconstruction Model)
## Overview
LRM is a feedforward neural network designed for single-image to 3D reconstruction [S1, unofficial]. It addresses the slow iterative optimization of NeRF and 3DGS by directly predicting 3D representations from input images [S1, unofficial]. It sets itself apart from siblings like Flash3D and GS-LRM by establishing the foundational transformer-based architecture for direct parameter prediction in this family [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A single RGB image $I$ and associated camera parameters (intrinsics/extrinsics) [S1, unofficial].
- Output: A set of 3D Gaussian parameters ($\mu, \Sigma, c, \alpha$) or other 3D representation fields [S1, unofficial].

**Data Structures:**
- Image tokens: Extracted from $I$ using a Vision Transformer (ViT) backbone [S1, unofficial].
- Camera tokens: Encoded embeddings representing camera pose [S1, unofficial].
- Gaussian parameters: Mean $\mu$, covariance $\Sigma$, color $c$, and opacity $\alpha$ [S1, unofficial].

**Steps:**
1. Encode the input image $I$ into feature tokens using a ViT backbone [S1, unofficial].
2. Encode camera parameters into token embeddings [S1, unofficial].
3. Concatenate image and camera tokens [S1, unofficial].
4. Process the concatenated sequence through a transformer encoder/decoder to model spatial and geometric relationships [S1, unofficial].
5. Directly predict the 3D Gaussian parameters ($\mu, \Sigma, c, \alpha$) from the transformer output [S1, unofficial].
6. Render the predicted parameters to generate novel views [S1, unofficial].

**Formulas:**
- Rendering: $C = \sum_{i=1}^{N} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j)$ [S1, unofficial].
- Loss: Photometric losses (e.g., LPIPS, SSIM) between rendered outputs and ground truth images [S1, unofficial].

## Subtopics

### [Large Gaussian Reconstruction Model (GRM)](5961-large-gaussian-reconstruction-model-grm.md)
The Large Gaussian Reconstruction Model (GRM) is a feedforward neural network that performs single-image (or multi-view) to 3D reconstruction by directly predicting a set of 3D Gaussians. It addresses the limitations of iterative optimization methods (like NeRF or standard 3DGS) by providing immediate, differentiable 3D representations from input images. It builds on [Large Reconstruction Model (LRM)](5959-large-reconstruction-model-lrm.md) by replacing the output format (e.g., NeRF fields or meshes) with Gaussian maps, supporting both single and multi-view inputs.

## Background
LRM was introduced in "LRM: Large Reconstruction Model for Single Image to 3D" at ICLR 2024 [S1, unofficial]. It is part of the evolution from NeRF to feedforward models, following ReconFusion which used diffusion priors [S1, unofficial].
