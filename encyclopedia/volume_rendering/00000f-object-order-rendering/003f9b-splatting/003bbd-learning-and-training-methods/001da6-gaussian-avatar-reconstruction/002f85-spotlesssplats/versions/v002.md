# SpotlessSplats


## Overview
SpotlessSplats is a robust 3D Gaussian Splatting method designed to improve reconstruction quality in casual captures by detecting and ignoring transient distractors [S1][S2, unofficial]. It enhances robustness by identifying outliers in a richer, pre-trained feature space, distinguishing them from static scene geometry [S1][S2, unofficial]. Unlike standard 3D Gaussian Splatting, which may incorporate transient artifacts as static geometry, SpotlessSplats explicitly models these as transient Gaussians to be discarded, yielding state-of-the-art results on diverse photo scenes [S1][S2, unofficial].

## How it works
SpotlessSplats builds on [Gaussian Splatting](23-splatting.md) by introducing a mechanism to filter out transient elements during training. The method extends the standard 3D Gaussian representation by conditioning Gaussians on learned appearance embeddings and training unsupervised transient Gaussians [S1][S2, unofficial].

**Inputs and Outputs:**
*   **Input:** A set of images (casual captures) and their camera poses.
*   **Output:** A set of static 3D Gaussians representing the persistent scene geometry and appearance, excluding transient distractors.

**Data Structures:**
The method maintains two sets of Gaussians:
1.  **Static Gaussians:** Represent the persistent scene.
2.  **Transient Gaussians:** Unsupervised Gaussians trained to absorb transient artifacts (e.g., moving people, reflections) [S1][S2, unofficial].

**Steps:**
1.  **Initialization:** Initialize a set of 3D Gaussians from the input images, similar to standard 3D Gaussian Splatting [S1][S2, unofficial].
2.  **Feature Extraction:** Extract features from the input images using a pre-trained feature extractor. This creates a richer feature space for outlier detection [S1][S2, unofficial].
3.  **Outlier Detection:** For each Gaussian, compare its appearance features against the pre-trained feature space. Gaussians that exhibit significant deviations (outliers) are identified as transient [S1][S2, unofficial].
4.  **Transient Gaussian Training:** Train unsupervised transient Gaussians to model these detected outliers. These Gaussians are conditioned on learned appearance embeddings [S1][S2, unofficial].
5.  **Optimization:** Optimize the static Gaussians and transient Gaussians jointly. The transient Gaussians are encouraged to absorb the transient artifacts, while the static Gaussians are constrained to represent the persistent geometry [S1][S2, unofficial].
6.  **Filtering:** During rendering or final reconstruction, discard the transient Gaussians, retaining only the static Gaussians for the final scene representation [S1][S2, unofficial].

**Parameters:**
*   **Pre-trained Feature Space:** The specific architecture and weights of the pre-trained feature extractor are not detailed in the provided sources [S1][S2, unofficial].
*   **Outlier Threshold:** The threshold for detecting outliers in the feature space is not specified [S1][S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Transient vs. Static:** Care must be taken to distinguish between long-term transient objects (e.g., a person standing still for a long time) and static geometry. The method relies on the pre-trained feature space to make this distinction [S1][S2, unofficial].
*   **Feature Space Quality:** The effectiveness of outlier detection depends on the quality and richness of the pre-trained feature space [S1][S2, unofficial].

*   **Strengths:** Enhances robustness in casual captures by ignoring transient distractors [S1][S2, unofficial].
*   **Limitations:** Requires a pre-trained feature space for outlier detection [S1][S2, unofficial].

## Background
SpotlessSplats was introduced as an extension to 3D Gaussian Splatting to address the issue of transient distractors in casual captures [S1][S2, unofficial]. It builds upon previous work such as SWAG, which conditions Gaussians on learned appearance embeddings [S1][S2, unofficial]. The method was presented in the context of the SIBGRAPI 2025 conference [S1][S2, unofficial].
