# Gaussian Avatar

Also called: Gaussian Avatar / 3DGS-Avatar, SMPL-based Gaussian Splatting Avatar

## Overview
Gaussian Avatar reconstructs animatable full-body human avatars by leveraging the SMPL parametric model as a geometric prior [S1][S2, unofficial]. It differs from static [Gaussian Splatting](946-gaussian-splatting.md) by predicting Gaussian parameters as functions of the model's pose, and from sibling methods like 3DGS-Avatar by using a feed-forward network for pose-conditioned deformation rather than explicit rigid/non-rigid transformation combinations [S1][S2, unofficial].

## How it works
**Inputs:** A sequence of video frames of a human subject; the SMPL model definition (mesh topology, joint hierarchy) [S1][S2, unofficial].
**Outputs:** A set of 3D Gaussians whose parameters are conditioned on the SMPL pose and shape parameters, enabling rendering of the avatar in arbitrary poses [S2, unofficial].

**Data Structures:**
1. **SMPL Model:** Provides base mesh vertices and joint transformations based on pose $\theta$ and shape $\beta$ [S1].
2. **Gaussian Primitives:** A set of $N$ Gaussians initialized on the SMPL mesh surface [S2, unofficial]. Each Gaussian $i$ has position $\mathbf{p}_i$ (3D), rotation $\mathbf{q}_i$ (quaternion, 4D) [G], scale $\mathbf{s}_i$ (3D), opacity $\alpha_i$ (scalar), and color/directionality coefficients $\mathbf{c}_i$ [G].
3. **Pose Feature Network:** A feed-forward neural network (MLP) that takes pose features as input and outputs Gaussian parameter offsets or absolute values [S2, unofficial].

**Steps:**
1. **Initialization:** Initialize $N$ Gaussians on the vertices or triangles of the SMPL base mesh [S2, unofficial].
2. **Pose Conditioning:** For a target pose $\theta$ and shape $\beta$, extract pose features (e.g., joint angles, bone rotations) [S2, unofficial] and pass them through the feed-forward network to predict Gaussian parameters (positions, rotations, scales) [S2, unofficial]. The network effectively learns the mapping $f(\theta, \beta) \rightarrow \{\mathbf{p}_i, \mathbf{q}_i, \mathbf{s}_i\}$ [S1].
3. **Differentiable Rendering:** Render the scene using object-order splatting [S1].
4. **Optimization:** Minimize the photometric loss between the rendered image and the input video frame [S1][S2, unofficial]. Gradients flow through the differentiable renderer and the pose-conditioned network to update the network weights and Gaussian parameters [S2, unofficial].

**Parameters:**
* Number of Gaussians $N$: Not given in the sources.
* Learning rate: Not given in the sources.
* SMPL parameters: Pose $\theta$, Shape $\beta$ [S1].

**Edge Cases:**
* **Occlusion:** Monocular input may lead to depth ambiguities; the SMPL prior constrains geometry but may not resolve severe self-occlusion artifacts without multi-view data [G].

## Subtopics

[GoMAvatar](6156-gomavatar.md): A monocular video avatar method that uses the SMPL-X rig coupled with a mesh. It is distinguished by its specific coupling of the Gaussian representation with the SMPL-X mesh structure for monocular reconstruction [G].

### GAvatar
GAvatar is a text-based generation method that attaches a primitive-based representation to the SMPL-X model and binds 3D Gaussians to the local coordinate system of each primitive [S3]. Attribute values of the 3D Gaussians are predicted by an implicit network, and opacity is converted to a signed distance field through a NeuS-like method to provide geometry constraints and extract detailed textured meshes [S3]. Generation is text-based and mainly guided by the SDS loss [S3].

## Operating characteristics
* Time and memory complexity: Not given in the sources.
* Strengths: Leverages a strong SMPL prior for plausible geometry [S1][S2, unofficial].
* Limitations: Relies on SMPL accuracy [S1].
* When to use: When animatable full-body human avatars are needed from video data [G].
* When not to use: For static scenes or non-human subjects [G].

## Background
Gaussian Avatar was introduced as a method to reconstruct full-body avatars using the SMPL model as a prior [S1][S2, unofficial]. It builds on the principles of Gaussian Splatting and parametric human models [S1]. The method uses pose features to predict Gaussian parameters through a feed-forward network [S2, unofficial]. It is part of the broader family of Gaussian Avatar Reconstruction methods [Parent](8385-smpl-based-rigid-non-rigid-deformation.md) [S1].
