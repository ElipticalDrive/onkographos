# UV-based motion parameterization

Also called: Motion parameterization scheme

## Overview
UV-based motion parameterization is a method for modeling dynamic human deformation by reparameterizing 4D space-time query points into a 3D surface-time domain using 2D UV coordinates and time [S1]. It solves the problem of high-dimensional motion field learning by exploiting the prior that human motion occurs primarily at the surface level, where points sharing similar UV coordinates exhibit similar deformation patterns [S1]. This approach significantly reduces the memory footprint and computational complexity of the residual deformation network compared to direct space-time parameterization [S1].

## How it works
The method transforms a query point from world space to canonical space by combining Linear Blend Skinning (LBS) with a residual deformation network conditioned on UV coordinates and time [S1].

**Inputs and Outputs:**
*   **Inputs:**
    *   Query point in world space: $\mathbf{x} \in \mathbb{R}^3$
    *   Human shape parameters: $\mathbf{w}$
    *   Human pose parameters: $\boldsymbol{\rho}$
    *   Time: $t$
    *   UV coordinates: $(u, v)$ corresponding to the parametric model surface [S1]
*   **Outputs:**
    *   Deformed point position in canonical space: $\Phi(\mathbf{x}, \mathbf{w}, u, v, \boldsymbol{\rho}, t)$ [S1]

**Data Structures:**
*   **Multiresolution Hash Encoding ($\psi_{res}$):** Encodes the input vector $(u, v, t)$ into a fixed-size feature vector. The specific grid resolution and hash table size are implementation details not specified in the source [S1].
*   **Residual Deformation Network ($MLP_{res}$):** A Multi-Layer Perceptron that takes the encoded input and outputs the residual deformation vector $\Delta\Phi$ [S1].

**Steps:**
1.  **Canonical Transformation via LBS:** Compute the initial deformed position $\Phi_{LBS}$ using Linear Blend Skinning based on the query point $\mathbf{x}$, shape $\mathbf{w}$, and pose $\boldsymbol{\rho}$ [S1]. The transformation matrices $G_j$ are derived from $\boldsymbol{\rho}$ [S1].
    $$ \Phi_{LBS}(\mathbf{x}, \mathbf{w}, \boldsymbol{\rho}) $$
2.  **Motion Parameterization:** Concatenate the current time $t$ with the 2D UV coordinates $(u, v)$ to form the motion parameterization input vector $\mathbf{p} = (u, v, t)$ [S1]. This reduces the dimensionality from 4D space-time $(\mathbf{x}, t)$ to 3D surface-time [S1].
3.  **Encoding:** Apply the multiresolution hash encoding $\psi_{res}$ to the parameterization input $\mathbf{p}$ [S1]:
    $$ \mathbf{e} = \psi_{res}(u, v, t) $$
4.  **Residual Regression:** Forward the encoded features $\mathbf{e}$ through the residual deformation network $MLP_{res}$ to regress the residual deformation $\Delta\Phi$ [S1]:
    $$ \Delta\Phi(u, v, t) = MLP_{res}(\mathbf{e}) $$
5.  **Final Deformation:** Add the residual deformation to the LBS result to obtain the final canonical position [S1]:
    $$ \Phi(\mathbf{x}, \mathbf{w}, u, v, \boldsymbol{\rho}, t) = \Phi_{LBS}(\mathbf{x}, \mathbf{w}, \boldsymbol{\rho}) + \Delta\Phi(u, v, t) $$

**Parameters:**
*   **Network Architecture:** The source does not specify the exact layer dimensions or activation functions for $MLP_{res}$ [S1].
*   **Hash Encoding:** Uses multiresolution hash encoding [S1]. Specific grid resolutions are not given.

**Edge Cases and Pitfalls:**
*   **UV Coordinate Availability:** The method requires valid UV coordinates for the query point. If a point lies outside the parametric mesh or lacks a UV mapping, this parameterization cannot be applied directly [S1].
*   **Dimensionality Reduction Assumption:** The method assumes motion is surface-local. If significant volumetric deformation occurs (e.g., internal organ movement), the surface-time approximation may lose fidelity [S1].

## Subtopics

### Residual Deformation Module
A specific implementation of the motion parameterization scheme where the residual deformation $\Delta\Phi$ is regressed using a network conditioned on $(u, v, t)$ [S1]. It explicitly concatenates time $t$ with UV coordinates $(u, v)$ and applies multiresolution hash encoding $\psi_{res}$ before passing through $MLP_{res}$ [S1]. This module is designed to refine the surface geometry by leveraging the displacement map and bump map techniques from traditional computer graphics to reduce the 4D space-time sequence to a 3D surface-time domain [S1]. It outperforms alternatives such as positional encoding of $(x, t)$, hash-encoded $x$ with per-frame latent codes, or hash-encoded $x$ with pose parameters [S1].

## Operating characteristics
*   **Memory Efficiency:** The $(u, v, t)$ parameterization is significantly more memory efficient than $(x, t)$ because it reduces the input dimensionality from 4D to 3D, decreasing the amount of information the deformation network must learn [S1].
*   **Performance:** The method enables optimization of dynamic human representations in minutes (e.g., 100 frames at $512 \times 512$ resolution on an RTX 3090 GPU), which is approximately 1/100th of the time required by previous methods [S1].
*   **Quality:** Maintains competitive photorealistic rendering quality despite the reduced training time [S1].
*   **Limitations:** The method is designed for foreground human subjects. Handling background entities requires combination with other methods like STNeRF [S1].

## Background
The method was introduced in the paper "Learning Neural Volumetric Representations of Dynamic Humans in Minutes" [S1]. It was inspired by the observation that typical human motion occurs at the surface level rather than the volumetric level, and by displacement map and bump map techniques from traditional computer graphics pipelines [S1]. The approach builds on the parametric prior of SMPL models and differentiable rendering principles common to the Gaussian Avatar family [S1, S2, unofficial].
