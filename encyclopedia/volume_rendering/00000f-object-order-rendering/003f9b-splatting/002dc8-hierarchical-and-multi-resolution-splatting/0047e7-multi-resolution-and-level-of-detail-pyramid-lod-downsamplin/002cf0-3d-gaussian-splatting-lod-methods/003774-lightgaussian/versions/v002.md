# LightGaussian

## Overview
LightGaussian is a compression method for 3D Gaussian Splatting that reduces model size and improves rendering speed by combining structured pruning with Spherical Harmonic (SH) factorization and vector quantization [S1, S3, unofficial]. It achieves significant size reduction (up to 15$\times$) and high frame rates ($>200$ FPS) with minimal quality degradation ($<0.5$ dB drop) [S1, S3, unofficial]. It distinguishes itself from sibling methods by focusing on attribute-level compression (SH factorization, vector quantization, and G-PCC position compression) rather than purely spatial clustering or octree-based spatial pruning [S2][S3, unofficial].

## How it works
LightGaussian reduces the computational and memory footprint of 3D Gaussian Splatting through a five-stage pipeline: importance-based pruning, SH distillation/factorization, vector quantization, and position compression [S1, unofficial][S2][S3, unofficial].

**Inputs and Outputs:**
- Input: A trained 3D Gaussian Splatting model with $N$ Gaussians, each defined by position $\mathbf{p}$, covariance $\mathbf{\Sigma}$ (or scale/rotation), opacity $\alpha$, and SH coefficients $\mathbf{c}_{l,m}$ for bands $l=0 \dots L$ [G].
- Output: A compressed model with $N' < N$ Gaussians, where attributes are quantized and SH coefficients are reduced in dimensionality [S1, S3, unofficial].

**Data Structures:**
1. **Pruned Gaussian Set:** A subset of the original $N$ Gaussians selected by importance ranking [S3, unofficial].
2. **Quantized Attributes:** Position compressed using octree-based lossless compression (G-PCC) [S2]. SH coefficients factorized and reduced to lower bands, then vector quantized [S1, S3, unofficial]. Opacity, scale, and rotation quantized (e.g., opacity to 8-bit) [S3, unofficial].

**Steps:**
1. **Importance Scoring:** Calculate an importance score for each Gaussian based on its contribution to the training views, typically the average alpha-weighted contribution [S3, unofficial].
2. **Structured Pruning:** Rank Gaussians by importance and prune those with the lowest scores, typically dropping the bottom 30–80% [S3, unofficial].
3. **SH Distillation:** Apply knowledge distillation to transfer information from higher-order SH bands to lower-order bands, reducing SH dimensionality [S1, S3, unofficial].
4. **Vector Quantization:** Apply vector quantization to the remaining SH coefficients and other attributes (scale, rotation) to further reduce size [S1, S3, unofficial].
5. **Position Compression:** Encode the positions of the remaining Gaussians using octree-based lossless compression (G-PCC) due to rasterization accuracy sensitivity to position errors [S2].

**Formulas:**
- Importance Score $I_i$: Average alpha-weighted contribution across training views [S3, unofficial].
- Size Reduction: Up to 15$\times$ reduction with $<0.5$ dB quality drop [S3, unofficial].

**Parameters:**
- Pruning Ratio: 30–80% [S3, unofficial].
- SH Bands: Reduced to lower bands [S1, S3, unofficial].

**Edge Cases:**
- Position sensitivity: Rasterization accuracy is sensitive to position errors, hence lossless compression for positions [S2].
- Quality trade-off: Pruning and quantization introduce quality loss, kept below 0.5 dB [S3, unofficial].

**Pseudocode:**
```python
import numpy as np

def lightgaussian_compress(gaussians, training_views, target_retention=0.2):
    # Step 1: Importance Scoring
    importance_scores = []
    for g in gaussians:
        total_contribution = 0.0
        for view in training_views:
            total_contribution += g.opacity * compute_view_impact(g, view)
        importance_scores.append(total_contribution / len(training_views))

    # Step 2: Structured Pruning
    sorted_indices = sorted(range(len(importance_scores)), key=lambda i: importance_scores[i], reverse=True)
    num_to_keep = int(len(gaussians) * target_retention)
    keep_indices = sorted_indices[:num_to_keep]
    pruned_gaussians = [gaussians[i] for i in keep_indices]

    # Step 3: SH Distillation
    for g in pruned_gaussians:
        g.sh_coeffs = distill_sh_to_lower_bands(g.sh_coeffs, target_bands=2)

    # Step 4: Vector Quantization
    for g in pruned_gaussians:
        g.sh_coeffs = vector_quantize(g.sh_coeffs)
        g.opacity = quantize_8bit(g.opacity)
        g.scale = vector_quantize(g.scale)
        g.rotation = vector_quantize(g.rotation)

    # Step 5: Position Compression
    positions = [g.position for g in pruned_gaussians]
    compressed_positions = octree_compress_positions(positions)

    compressed_gaussians = []
    for i, g in enumerate(pruned_gaussians):
        g.position = compressed_positions[i]
        compressed_gaussians.append(g)
    return compressed_gaussians

def compute_view_impact(gaussian, view):
    # Standard rasterization contribution calculation
    return gaussian.opacity * gaussian.sh_coeffs[0]
```

## Operating characteristics
- **Performance:** Achieves over 200 FPS [S1, unofficial].
- **Quality:** On the MipNeRF360 dataset, LightGaussian achieves SSIM 0.857, PSNR 28.45, and LPIPS 0.210 [S2].
- **Size:** Reduces model size to 42.48 MB on MipNeRF360, a 15$\times$ reduction compared to the original [S2][S3, unofficial].
- **Strengths:** High compression ratio, fast rendering, minimal quality loss.
- **Limitations:** Pruning may remove important Gaussians if not done carefully; SH distillation may lose high-frequency details [S3, unofficial].

## Background
LightGaussian was introduced in NeurIPS'23 [S3, unofficial]. It addresses the need for efficient 3D Gaussian Splatting for mobile/web/streaming applications by compressing the Gaussian attributes [S3, unofficial].
