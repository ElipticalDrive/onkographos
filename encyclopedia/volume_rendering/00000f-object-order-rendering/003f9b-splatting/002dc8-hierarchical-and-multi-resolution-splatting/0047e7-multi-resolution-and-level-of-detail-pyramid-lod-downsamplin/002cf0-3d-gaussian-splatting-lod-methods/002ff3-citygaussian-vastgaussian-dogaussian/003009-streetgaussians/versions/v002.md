# StreetGaussians
## Overview
StreetGaussians is a method for driving scenes that models dynamic urban environments by associating each vehicle or pedestrian with a separate 3DGS sub-model that can be moved independently [S1, unofficial]. It separates a static background from dynamic actor splats with explicit poses, enabling the insertion of rare-event vehicles into any scene with sensor realism [S2, unofficial]. It sets itself apart from monolithic 3DGS approaches by decoupling static and dynamic geometry for independent pose control, building on [CityGaussian / VastGaussian / DoGaussian](6143-citygaussian-vastgaussian-dogaussian.md).
## How it works
**Inputs and Outputs:** Not given in the sources.
**Data Structures:**
1. **Static Background:** A standard 3DGS representation for the fixed scene elements [S2, unofficial].
2. **Dynamic Actors:** A list of per-vehicle and per-pedestrian 3DGS sub-models, each associated with explicit poses [S2, unofficial].
**Steps:**
1. **Scene Decomposition:** Separate the scene into static background regions and dynamic actor regions [S2, unofficial].
2. **Static Background Training:** Train a standard 3DGS model on the static parts of the scene [S2, unofficial].
3. **Per-Actor Model Training:** Train a separate 3DGS sub-model for each dynamic actor [S1, unofficial].
4. **Pose Association:** Associate each actor's sub-model with its tracked trajectory, providing explicit poses for animation [S1, unofficial][S2, unofficial].
5. **Rendering:** Render the static background, transform each actor's sub-model Gaussians using their explicit poses, and composite them over the background [S1, unofficial][S2, unofficial].

## Subtopics

### DrivingGaussian
DrivingGaussian composites surrounding views from multiple cameras into a single dynamic scene, aligning the Gaussian clouds of different vehicles with their tracked trajectories [S1, unofficial].

## Background
StreetGaussians adapts the static/dynamic decomposition pattern (similar to EmerNeRF) to the Gaussian Splatting framework [S2, unofficial]. It became a dominant pattern for AV simulation in 2026, allowing the placement of rare-event vehicles (e.g., school buses) into any scene with sensor realism [S2, unofficial].
