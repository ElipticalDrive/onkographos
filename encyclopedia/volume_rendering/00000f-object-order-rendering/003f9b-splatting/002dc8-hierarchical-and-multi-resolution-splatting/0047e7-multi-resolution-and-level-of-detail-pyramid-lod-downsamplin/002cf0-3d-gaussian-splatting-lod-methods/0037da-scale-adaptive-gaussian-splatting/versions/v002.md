# Scale-Adaptive Gaussian Splatting

Also called: SA-GS

## Overview
Scale-Adaptive Gaussian Splatting (SA-GS) addresses aliasing artifacts in 3D Gaussian Splatting caused by mismatched sampling frequencies [S1]. Unlike methods that rely on fixed pre-computed dilation scales, SA-GS applies an adaptive 2D low-pass filter during the rendering phase, dynamically adjusted based on the current rendering resolution and camera distance [S1].

## How it works
**Inputs:**
- A set of 3D Gaussians, each defined by mean position $\mu$, covariance matrix $\Sigma$ (or rotation $R$ and scale $S$), opacity $\alpha$, and spherical harmonic coefficients for color [G].
- Camera parameters: intrinsic matrix $K$ and extrinsic matrix $[R|t]$ [G].
- Rendering resolution $(W, H)$ [G].

**Outputs:**
- A rendered image $I \in \mathbb{R}^{H \times W \times 3}$ [G].

**Data Structures:**
- Not given in the sources.

**Steps:**
1. **Rasterization Setup:** Project the 3D Gaussians to 2D screen space using standard perspective projection and compute the 2D covariance matrix $\Sigma'$ via the Jacobian of the transformation [G].
2. **Adaptive Filter Calculation:** Determine the adaptive dilation scale factor $k$ for each Gaussian based on the rendering resolution and camera distance [S1].
3. **Filter Application:** Apply the adaptive 2D low-pass filter at test time by scaling the projected Gaussian kernel according to $k$ [S1].
4. **Compositing:** Perform standard alpha compositing using the filtered Gaussians [G].

## Subtopics

### [Alias-free 4D Gaussian Splatting](9872-alias-free-4d-gaussian-splatting.md)
Eliminates high-frequency artifacts in dynamic scenes by adapting dilation scales based on temporal changes and camera parameters, unlike SA-GS's static resolution/distance adaptation. It is chosen when rendering dynamic 4D scenes with varying focal lengths or distances.

## Operating characteristics
SA-GS reduces aliasing artifacts across varying view distances and resolutions by adapting the filter at test time [S1]. The method does not require pre-computed hierarchical structures or mipmaps for the filtering step [S1]. Not given in the sources.

## Background
SA-GS was introduced to solve aliasing in 3D Gaussian Splatting by adding a test-time adaptive filtering step to the standard rendering pipeline [S1]. It is documented in recent surveys of 3D Gaussian Splatting advancements [S1].
