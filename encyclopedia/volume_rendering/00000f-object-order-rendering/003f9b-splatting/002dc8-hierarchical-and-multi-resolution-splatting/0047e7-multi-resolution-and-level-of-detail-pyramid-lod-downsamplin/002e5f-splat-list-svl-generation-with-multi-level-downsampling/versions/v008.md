# Splat List (SVL) Generation with Multi-Level Downsampling

Also called: LOD Splatting, Sparse Voxel List

## Overview
This method generates a Sparse Voxel List (SVL) of splat geometry across multiple levels of detail (LOD) by iteratively downsampling a voxel occupancy mask and extracting representative splat primitives for each level [S1, unofficial]. It differs from single-resolution splatting by pre-computing a hierarchy of geometric approximations, allowing the renderer to select the appropriate LOD per chunk based on viewing distance or error metrics defined in the parent [Multi-Resolution and Level of Detail](12128-multi-resolution-and-level-of-detail-pyramid-lod-downsamplin.md).

## How it works
**Inputs:** A voxel chunk containing an occupancy mask (array of `Voxel` types, where `Voxel` is `uint8_t`) and metadata defining the chunk's spatial bounds and resolution.
**Outputs:** A contiguous SVL buffer (`uint16_t*`) containing geometry items for all LOD levels, and a `GeometrySVL` structure describing the buffer's layout.

**Data Structures:**
The core data structure for the output is `struct GeometrySVL`:
- `lod`: `uint8_t`, the level of detail index.
- `vao`: `uint32_t`, vertex array object identifier.
- `vbo`: `uint32_t`, vertex buffer object identifier.
- `vbo_items`: `uint32_t`, number of items in the buffer.

The chunk metadata is stored in `struct ChunkMD`, which includes:
- `svl`: `uint16_t*`, pointer to the SVL buffer.
- `svl_items[MAX_LOD_LEVEL]`: `uint32_t`, count of items per LOD level. `MAX_LOD_LEVEL` is 5.
- `svl_items_total`: `uint32_t`, total item count across all LODs.
- `svl_dirty`: `volatile uint8_t`, flag indicating the SVL needs regeneration.
- `no_geometry`: `volatile uint8_t`, flag set if the chunk contains no geometry.

**Algorithm Steps:**
1.  **Initialization:** For each chunk `c`, check if `c->svl_dirty` is set or if previous geometry is still being uploaded. If so, skip processing for this frame [S1, unofficial].
2.  **Mask Generation:** Generate the initial voxel occupancy mask for the chunk using `chunk_make_mask`. This creates a binary representation of occupied voxels within the chunk's local coordinate space [S1, unofficial].
3.  **Iterative Downsampling and Extraction:** Loop through LOD levels `i` from 0 to `MAX_LOD_LEVEL - 1`:
    a.  **Splat Extraction:** Extract splat primitives from the current occupancy mask (for level `i`). The specific primitive aggregation logic (merging covariances, positions, opacities) follows the parent method's principles [S1, unofficial].
    b.  **Accumulation:** Add the number of generated geometry items for this level to a running total `geom_items`.
    c.  **Downsampling:** If `i` is not the final LOD level, downsample the current mask into a work buffer for level `i+1` using `chunk_mask_downsample`. This reduces the resolution of the occupancy data for the next iteration [S1, unofficial].
4.  **Buffer Allocation:** After processing all LOD levels, allocate a contiguous SVL buffer of size `geom_items * sizeof(uint16_t)` [S1, unofficial].
5.  **Data Copy:** Copy the accumulated geometry data from the temporary mesher buffer into the allocated SVL buffer [S1, unofficial].
6.  **Metadata Update:** Update `c->svl_items` with the counts per level and `c->svl_items_total` with the total count. Mark `c->svl_dirty` as 0 [S1, unofficial].
7.  **Empty Chunk Handling:** If `geom_items` is zero:
    a.  Free any existing SVL buffer.
    b.  Zero out `c->svl_items`.
    c.  Set `c->svl_items_total` to 0.
    d.  Set `c->no_geometry` to 1.
    e.  Mark `c->svl_dirty` as 1 [S1, unofficial].

**Pseudocode:**
```python
def generate_svl(chunk, set, max_lod_level=5):
    # Skip if dirty or previous upload incomplete
    if chunk.svl_dirty or chunk.mesh_dirty:
        return

    # Reset counters
    geom_items = 0
    svl_items_per_level = [0] * max_lod_level
    
    # Get or create initial mask
    mask = chunk_make_mask(chunk)
    work_buffer = mem_alloc(mask.size) # For downsampling
    
    for i in range(max_lod_level):
        # Extract splats from current mask
        # Returns list of geometry items for this LOD
        items = extract_splats_from_mask(mask, level=i)
        count = len(items)
        svl_items_per_level[i] = count
        geom_items += count
        
        # Downsample mask for next level if not last level
        if i < max_lod_level - 1:
            chunk_mask_downsample(mask, work_buffer)
            mask = work_buffer # Update mask reference
            
    # Handle empty chunk case
    if geom_items == 0:
        if chunk.svl:
            mem_free(chunk.svl)
        chunk.svl = None
        chunk.svl_items = [0] * max_lod_level
        chunk.svl_items_total = 0
        chunk.no_geometry = 1
        chunk.svl_dirty = 1
        return

    # Allocate SVL buffer
    # Note: The source specifies sizeof(uint16_t) for the buffer size calculation,
    # implying the buffer stores indices or packed data, not full geometry structs.
    # The actual geometry data is copied from the mesher buffer.
    buffer_size = geom_items * sizeof(uint16_t)
    svl_buffer = mem_alloc(buffer_size)
    
    # Copy accumulated geometry data from mesher buffer to SVL buffer
    # The mesher buffer structure is assumed to be populated during extract_splats_from_mask
    copy_geometry_to_svl(mesher_buffer, svl_buffer, geom_items)
    
    # Update chunk metadata
    chunk.svl = svl_buffer
    chunk.svl_items = svl_items_per_level
    chunk.svl_items_total = geom_items
    chunk.svl_dirty = 0
```

**Parameters:**
- `MAX_LOD_LEVEL`: Constant defining the number of splat LOD levels. Set to 5 [S1, unofficial].
- `Voxel`: Type alias for `uint8_t` [S1, unofficial].

**Edge Cases:**
- **Empty Chunk:** If no geometry is generated (`geom_items == 0`), the SVL buffer is freed, and flags are reset to indicate no geometry [S1, unofficial].
- **Concurrency:** The method uses mutexes (`mutex_write`) to protect chunk access during meshing. The `svl_dirty` flag prevents concurrent generation [S1, unofficial].
- **Precision:** Coordinate/Iterator types use `uint16_t` for chunk/voxel locations and `uint32_t` for worldspace vectors and iterators [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels and LOD levels. The downsampling step reduces the mask size exponentially, so later LOD levels are faster to process.
- **Memory Complexity:** Proportional to the number of splats across all LOD levels. The SVL buffer size is `geom_items * sizeof(uint16_t)`.
- **Strengths:** Pre-computed LODs allow for efficient rendering of large voxel datasets by reducing the number of primitives sent to the GPU for distant or homogeneous regions.
- **Limitations:** Requires significant CPU time for meshing and downsampling. Memory usage can be high if many LOD levels are retained.
- **When to Use:** Suitable for large-scale voxel rendering where performance is critical and geometry changes infrequently.
- **When Not to Use:** For dynamic scenes with frequent geometry changes, the overhead of regenerating the SVL may outweigh the benefits.

## Background
This method is implemented in the VoxelPlat project [S1, unofficial]. It leverages the principles of hierarchical decomposition and error-driven primitive selection common in multi-resolution rendering [S1, unofficial].
