# Splat List (SVL) Generation with Multi-Level Downsampling

Also called: LOD Splatting, Sparse Voxel List

## Overview
This method generates a Sparse Voxel List (SVL) of splat geometry across multiple levels of detail (LOD) by iteratively downsampling a voxel occupancy mask and extracting splat primitives for each level [S1, unofficial]. It differs from standard hierarchical splatting by pre-computing a fixed-depth hierarchy of downsampled masks to explicitly construct the SVL buffer, rather than traversing a tree structure at render time to determine LOD [S1, unofficial].

## How it works
**Inputs:** A voxel chunk containing an occupancy mask (stored as `Voxel` data, where `Voxel` is a type alias for `uint8_t`) [S1, unofficial].
**Outputs:** A contiguous SVL buffer containing geometry items for all LOD levels, and metadata in `struct ChunkMD` tracking the state of the SVL [S1, unofficial].

**Data Structures:**
The core state is held in `struct ChunkMD`, which manages the chunk's geometry state [S1, unofficial]:
*   `svl`: A pointer to `uint16_t*` storing the SVL buffer.
*   `svl_items`: An array of `uint32_t` with size `MAX_LOD_LEVEL` (5), storing the count of items per LOD level [S1, unofficial].
*   `svl_items_total`: A `uint32_t` storing the total number of SVL items across all levels [S1, unofficial].
*   `svl_dirty`: A `volatile uint8_t` flag indicating if the SVL needs regeneration [S1, unofficial].
*   `no_geometry`: A `volatile uint8_t` flag indicating if the chunk has no geometry [S1, unofficial].

The geometry items themselves are stored in `struct GeometrySVL` [S1, unofficial]:
*   `lod`: `uint8_t`, the level of detail index.
*   `vao`: `uint32_t`, Vertex Array Object identifier.
*   `vbo`: `uint32_t`, Vertex Buffer Object identifier.
*   `vbo_items`: `uint32_t`, number of items in the VBO.

**Parameters:**
*   `MAX_LOD_LEVEL`: Constant defining the number of splat LOD levels, set to 5 [S1, unofficial].
*   Coordinate/Iterator types: Chunk/voxel locations use `uint16_t`; worldspace vectors use `uint32_t`; iterators use `uint32_t` [S1, unofficial].

**Algorithm:**
The generation process is performed per chunk, typically within a multi-threaded meshing loop [S1, unofficial].

1.  **Initialization:**
    *   Initialize a running total `geom_items = 0` [S1, unofficial].
    *   Initialize an array `temp_lo_vbo_segments` of size `MAX_LOD_LEVEL` with zeros [S1, unofficial].
    *   Initialize a flag `clear_svl = 0` [S1, unofficial].
    *   Allocate or clear a work buffer, a mask buffer, and a geometry buffer for the current thread [S1, unofficial].

2.  **Iterative Downsampling and Extraction:**
    *   Generate the initial voxel occupancy mask for the chunk using `chunk_make_mask` [S1, unofficial].
    *   Loop for each LOD level $i$ from 0 to `MAX_LOD_LEVEL - 1`:
        *   Extract splat primitives from the current mask (level $i$) into the geometry buffer.
        *   Count the number of geometry items extracted for this level.
        *   Store this count in `temp_lo_vbo_segments[i]` and accumulate it into `geom_items` [S1, unofficial].
        *   If $i$ is not the final LOD level (`i < MAX_LOD_LEVEL - 1`):
            *   Downsample the current mask into a work buffer for level $i+1$ using `chunk_mask_downsample` [S1, unofficial].
            *   The work buffer becomes the input mask for the next iteration.

3.  **Buffer Allocation and Copy:**
    *   After processing all LOD levels, allocate a contiguous SVL buffer of size `geom_items * sizeof(uint16_t)` [S1, unofficial].
    *   Copy the accumulated geometry data from the mesher buffer into the allocated SVL buffer [S1, unofficial].
    *   Update `c->svl_items` with the counts from `temp_lo_vbo_segments` and `c->svl_items_total` with `geom_items` [S1, unofficial].

4.  **Edge Case: Empty Geometry:**
    *   If `geom_items` is zero:
        *   Free any existing SVL buffer.
        *   Set `c->svl_items` to zero.
        *   Set `c->svl_items_total` to 0.
        *   Set `c->no_geometry = 1` [S1, unofficial].
        *   Mark `c->svl_dirty = 1` [S1, unofficial].

**Pseudocode:**
```python
def generate_svl(chunk, set, thread_buffer):
    # Initialize counters
    geom_items = 0
    temp_lo_vbo_segments = [0] * MAX_LOD_LEVEL
    clear_svl = False
    
    # Clear buffers
    memset(thread_buffer.work, 0, thread_buffer.work_size)
    memset(thread_buffer.mask, 0, thread_buffer.mask_size)
    memset(thread_buffer.geom, 0, thread_buffer.geom_size)
    
    # Step 1: Generate initial mask
    chunk_make_mask(chunk, thread_buffer.mask)
    
    # Step 2: Iterative LOD generation
    for i in range(MAX_LOD_LEVEL):
        # Extract splats from current mask (level i)
        # This function populates thread_buffer.geom and returns item count
        items = extract_splats_from_mask(thread_buffer.mask, thread_buffer.geom, i)
        
        temp_lo_vbo_segments[i] = items
        geom_items += items
        
        # Downsample for next level if not last level
        if i < MAX_LOD_LEVEL - 1:
            chunk_mask_downsample(thread_buffer.mask, thread_buffer.work)
            # Swap buffers: work becomes mask for next iteration
            thread_buffer.mask = thread_buffer.work
            # Note: In actual implementation, buffer pointers or indices are swapped
            # to avoid reallocation. The 'work' buffer is reused as the next 'mask'.
            
    # Step 3: Handle empty geometry
    if geom_items == 0:
        if chunk.svl is not None:
            mem_free(chunk.svl)
        chunk.svl = None
        chunk.svl_items = [0] * MAX_LOD_LEVEL
        chunk.svl_items_total = 0
        chunk.no_geometry = 1
        chunk.svl_dirty = 1
        return

    # Step 4: Allocate and copy SVL
    if chunk.svl is not None:
        mem_free(chunk.svl)
        
    chunk.svl = mem_alloc(geom_items * sizeof(uint16_t))
    memcpy(chunk.svl, thread_buffer.geom, geom_items * sizeof(uint16_t))
    
    chunk.svl_items = temp_lo_vbo_segments
    chunk.svl_items_total = geom_items
    chunk.svl_dirty = 0
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of voxels and the number of LOD levels. The downsampling step reduces the data size geometrically, so later LOD levels are faster to process.
*   **Memory Complexity:** Proportional to the total number of splats across all LOD levels. The SVL buffer is contiguous and sized exactly to `geom_items * sizeof(uint16_t)` [S1, unofficial].
*   **Strengths:** Pre-computed LODs allow for efficient rendering without runtime tree traversal for LOD selection. The fixed buffer size simplifies memory management.
*   **Limitations:** The fixed number of LOD levels (`MAX_LOD_LEVEL = 5`) may not be optimal for all scenes. The downsampling process may introduce artifacts if the mask downsample is not carefully designed [S1, unofficial].
*   **When to use:** Suitable for dynamic voxel scenes where geometry changes frequently, and pre-computing LODs is feasible within the update budget.

## Background
This method is implemented in the VoxelPlat project, an unofficial voxel engine [S1, unofficial]. It represents a practical approach to hierarchical splatting by explicitly managing the downsampling of occupancy masks to generate a multi-resolution splat list.
