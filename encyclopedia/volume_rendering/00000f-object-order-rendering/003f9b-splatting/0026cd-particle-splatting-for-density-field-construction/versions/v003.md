# Particle Splatting for Density Field Construction

Also called: 3D Density Field Construction via Splatting, CPU splatting, wax density field

## Overview
This method constructs a volumetric density field on the CPU by rasterizing interpolated particles into a 3D grid, enabling subsequent ray-marching of complex surfaces like wax [S1, unofficial]. It differs from its parent [Splatting](23-splatting.md) by explicitly targeting CPU-side grid construction for density-based rendering rather than direct image-space compositing, and from its child [Image-Space Particle Splatting for Density Field Construction](10567-image-space-particle-splatting-for-density-field-constructio.md) by operating in object space with a fixed uniform grid, which avoids the resolution limits of image-space buffers but requires managing 3D memory allocation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ particles with positions $\mathbf{p}_i$ interpolated between fixed time steps, and associated scalar attributes such as temperature [S1, unofficial].
*   **Output:** A 3D texture (density field) stored in GPU memory, containing density and coupled attributes per voxel [S1, unofficial].

**Data Structures:**
*   **Grid:** A 3D voxel grid aligned with the container boundaries [S1, unofficial].
    *   **Dimensions:** $48 \times 94 \times 48$ voxels [S1, unofficial].
    *   **Layout:** Two channels per voxel: (1) density $\rho$, (2) temperature $\times$ density $T \cdot \rho$ [S1, unofficial].
    *   **Format:** `Data3DTexture` with RG channel layout. Internal format is `RG32F` (float32) or `RG16F` if 32-bit float filtering is unsupported [S1, unofficial].
*   **Occupancy Grid:** A $4^3$ block occupancy grid used to skip empty regions during ray-marching, reducing texture reads by a factor of 3 [S1, unofficial].

**Parameters:**
*   **Kernel:** Separable kernel defined as $h(u) = (1 - u^2)^3$ [S1, unofficial].
*   **Temporal Smoothing Time Constant:** $\tau = 0.04$ seconds [S1, unofficial].
*   **Normalization:** Density is normalized to approximately 1.0 at the core of the wax [S1, unofficial].

**Steps:**
1.  **Interpolation:** Interpolate particle positions between two fixed time steps to ensure temporal consistency [S1, unofficial].
2.  **Splatting:** For each particle $i$ at position $\mathbf{p}_i$: determine the bounding box of the kernel footprint within the 3D grid [G]; for each voxel $v$ within the footprint, calculate the normalized distance $u$ from the voxel center to $\mathbf{p}_i$ [G], compute the kernel weight $w = (1 - u^2)^3$ [S1, unofficial], add $w$ to the density channel of voxel $v$, and add $w \cdot T_i$ to the temperature-density channel of voxel $v$ [S1, unofficial].
3.  **Normalization:** Normalize the density values such that the core density is $\approx 1$ [S1, unofficial].
4.  **Temporal Smoothing:** Apply in-place temporal smoothing to the density field to reduce flickering using the update rule $\rho_{new} = \rho_{old} \cdot e^{-dt/\tau}$, where $dt$ is the frame time delta and $\tau = 0.04$ s [S1, unofficial].
5.  **Upload:** Upload the resulting 3D grid to the GPU as a `Data3DTexture` [S1, unofficial].

**Pseudocode:**
```python
import math

def construct_density_field(particles, grid_shape, tau, dt):
    """
    Constructs a 3D density field by splatting particles into a grid.
    
    Args:
        particles: List of dicts with 'pos' (vec3), 'temp' (float).
        grid_shape: Tuple (W, H, D) defining grid size.
        tau: Temporal smoothing constant (0.04).
        dt: Time delta in seconds.
        
    Returns:
        grid: 3D list of shape (W, H, D, 2).
              Channel 0: Density.
              Channel 1: Temperature * Density.
    """
    W, H, D = grid_shape
    
    # Initialize grid with zeros
    grid = [[[0.0, 0.0] for _ in range(D)] for _ in range(H)]
    for x in range(W):
        for y in range(H):
            for z in range(D):
                grid[x][y][z] = [0.0, 0.0]

    # 1. Temporal smoothing (in-place decay)
    keep = math.exp(-dt / tau)
    for x in range(W):
        for y in range(H):
            for z in range(D):
                grid[x][y][z][0] *= keep
                grid[x][y][z][1] *= keep

    # 2. Splat particles
    kernel_radius = 1.0
    for p in particles:
        px, py, pz = p['pos']
        temp = p['temp']
        
        # Determine voxel bounds (inclusive)
        min_x = max(0, math.floor(px - kernel_radius))
        max_x = min(W - 1, math.ceil(px + kernel_radius))
        min_y = max(0, math.floor(py - kernel_radius))
        max_y = min(H - 1, math.ceil(py + kernel_radius))
        min_z = max(0, math.floor(pz - kernel_radius))
        max_z = min(D - 1, math.ceil(pz + kernel_radius))
        
        for x in range(min_x, max_x + 1):
            for y in range(min_y, max_y + 1):
                for z in range(min_z, max_z + 1):
                    dx = x - px
                    dy = y - py
                    dz = z - pz
                    u_sq = dx*dx + dy*dy + dz*dz
                    
                    if u_sq < 1.0:
                        u = math.sqrt(u_sq)
                        weight = (1.0 - u*u)**3
                        grid[x][y][z][0] += weight
                        grid[x][y][z][1] += weight * temp

    # 3. Normalize density to ~1 at core (standard scaling implementation) [G]
    max_density = 0.0
    for x in range(W):
        for y in range(H):
            for z in range(D):
                if grid[x][y][z][0] > max_density:
                    max_density = grid[x][y][z][0]
    if max_density > 0:
        scale = 1.0 / max_density
        for x in range(W):
            for y in range(H):
                for z in range(D):
                    grid[x][y][z][0] *= scale
                    grid[x][y][z][1] *= scale

    return grid
```

**Edge Cases and Pitfalls:**
*   **Precision:** Use `RG32F` if possible; fall back to `RG16F` only if 32-bit float filtering is unsupported, which may introduce quantization artifacts [S1, unofficial].
*   **Temporal Stability:** The smoothing constant $\tau=0.04$ s ensures temporal coherence, with measurements showing 0.00% of surface voxels cross the rendering threshold even at 60 Hz with ±30% frame-time jitter [S1, unofficial].
*   **Occupancy Optimization:** A $4^3$ block occupancy grid skips empty regions during ray-marching, reducing texture reads by a factor of 3 [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot R^3)$ per frame, where $N$ is the number of particles and $R$ is the kernel radius in voxels [G]. Measured performance on a Xeon 2.1 GHz processor shows CPU splatting takes 1.1 to 1.25 ms median, and 1.3 to 1.9 ms p95 [S1, unofficial].
*   **Memory Complexity:** $O(W \cdot H \cdot D)$ for the 3D grid. For a $48 \times 94 \times 48$ grid with 2 channels of float32, this requires approximately $48 \cdot 94 \cdot 48 \cdot 8$ bytes $\approx 1.7$ MB [S1, unofficial].
*   **Strengths:** Low CPU overhead; simple implementation; effective for wax-like surfaces with temporal coherence; occupancy grid reduces ray-marcher texture reads by 3x [S1, unofficial].
*   **Limitations:** Fixed resolution grid limits detail; memory usage scales with volume size [S1, unofficial].
*   **When to Use:** Small to medium-sized volumetric simulations (e.g., wax lamps) where CPU-side density construction is preferred for simplicity and compatibility with software rendering pipelines [S1, unofficial].

## Background
This method was implemented in the "lava-lamp" project by Nathan Drll, featuring a wax surface constructed via CPU splatting and ray-marched in a glass container [S1, unofficial].
