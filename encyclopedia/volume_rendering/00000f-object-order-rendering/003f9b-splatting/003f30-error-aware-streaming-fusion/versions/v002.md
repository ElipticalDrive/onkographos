# Error-aware Streaming Fusion


## Overview
Error-aware Streaming Fusion is a temporal stabilization technique for dynamic 3D Gaussian Splatting that mitigates artifacts caused by warping inaccuracies and appearance variations [S1]. It operates by adaptively weighting the fusion of historical splats against current frame predictions based on per-pixel rendering error [S1]. Unlike standard streaming methods that may accumulate warping errors or flicker, this method explicitly suppresses unreliable historical contributions and erroneous current-frame predictions to ensure temporal consistency [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of current-frame splats $\mathcal{S}_t$ predicted by a multi-view transformer, a set of historical splats $\mathcal{S}_{t-1}$ from past keyframes, and the camera parameters for input views [S1].
*   **Outputs:** A fused set of splats $\mathcal{S}_{fused}$ with updated weights and attributes for rendering [S1].

**Data Structures:**
*   **Keyframe Buffer:** Maintains primitives from a set of past keyframes. In practice, two keyframes are maintained, placed 5 frames apart, each lasting 10 frames [S1].
*   **Splat Attributes:** Position, covariance/scale, rotation, opacity, and color follow the parent article [Splatting](23-splatting.md).

**Steps:**
1.  **Render Current Frame:** Render the current frame splats $\mathcal{S}_t$ to the input views to obtain a reference depth map $D_{\text{ref}}$ and color image $I_{\text{ref}}$ [S1].
2.  **Project Historical Splats:** For each historical splat $s_h \in \mathcal{S}_{t-1}$, project it onto the input views [S1].
3.  **Render Historical Splats:** Render each historical splat $s_h$ to the input views to obtain $I_{\text{hist}}$ and $D_{\text{hist}}$ [S1].
4.  **Error & Depth Assessment:** For each input view, compute the per-pixel error between $I_{\text{hist}}$ and $I_{\text{ref}}$, and check if $D_{\text{hist}} < D_{\text{ref}}$ (historical splat appears in front) [S1].
5.  **Count Unreliable Views:** Count the number of input views where $s_h$ produces increased rendering error and appears in front of the current frame depth [S1].
6.  **Weight Historical Splats:** If the error increases in more than half of the input views, set the fusion weight of $s_h$ to zero ($w_h = 0$) [S1].
7.  **Weight Current Splats:** Evaluate current frame splats $s_c \in \mathcal{S}_t$ predicted by the transformer; if a current splat increases rendering error, assign it zero weight ($w_c = 0$) [S1].
8.  **Identify Static Areas:** During the Splat-to-voxel transfer process, identify static areas [S1].
9.  **Mark Motion Regions:** Historical splats undergoing deformation mark their neighboring voxels as regions of motion [S1].
10. **Blend Static Attributes:** In static areas, retain 50% of the voxel attributes from the past keyframe to enhance temporal continuity [S1].
11. **Smooth Transition:** Smoothly adjust contributions as older keyframes are replaced by newer ones to ensure seamless temporal transitions [S1].

**Pseudocode:**
```python
def error_aware_streaming_fusion(current_splats, historical_splats, camera_params, views, error_threshold=0.0):
    """
    Fuses current and historical splats based on per-pixel rendering error.
    error_threshold: Per-pixel error threshold. Not given in the sources. [G]
    """
    fused_splats = []
    
    # Step 1: Render current frame to get reference
    ref_color, ref_depth = project_and_rasterize(current_splats, camera_params, views)
    
    # Step 2-6: Assess and weight historical splats
    for s_h in historical_splats:
        hist_color, hist_depth = project_and_rasterize([s_h], camera_params, views)
        
        error_view_count = 0
        for view in views:
            # Per-pixel error calculation (L2 norm of color difference)
            pixel_error = sum((c1 - c2)**2 for c1, c2 in zip(hist_color[view], ref_color[view]))
            
            # Check if historical splat is in front of current depth
            is_in_front = all(h < r for h, r in zip(hist_depth[view], ref_depth[view]))
            
            # If error exceeds threshold AND it occludes current frame, count it
            if pixel_error > error_threshold and is_in_front:
                error_view_count += 1
        
        # Step 6: Weight Adjustment
        if error_view_count > len(views) / 2:
            s_h.weight = 0.0
        else:
            s_h.weight = 1.0
            
        fused_splats.append(s_h)

    # Step 7: Weight Adjustment for Current Splats
    for s_c in current_splats:
        # Evaluate if current splat increases error against reference
        current_error = sum((s_c.color - ref_color[view]).norm() for view in views)
        
        if current_error > error_threshold:
            s_c.weight = 0.0
        else:
            s_c.weight = 1.0
            
        fused_splats.append(s_c)

    # Step 8-10: Static Area Identification and Blending
    static_voxels = identify_static_voxels(historical_splats, current_splats)
    
    for s in fused_splats:
        if s.position in static_voxels:
            # Retain 50% of voxel attributes from past keyframe
            past_attrs = get_past_keyframe_attributes(s.position)
            if past_attrs is not None:
                s.attributes = 0.5 * s.attributes + 0.5 * past_attrs
            
    return fused_splats

def project_and_rasterize(splats, camera_params, views):
    """Projects splats to screen space and rasterizes to color/depth buffers. [G]"""
    # Follows standard MVP transformation and rasterization from [Splatting](23-splatting.md)
    colors = {v: [] for v in views}
    depths = {v: [] for v in views}
    for s in splats:
        screen_pos = transform_to_screen(s.position, camera_params)
        for v in views:
            colors[v].append(s.color)
            depths[v].append(s.depth)
    return colors, depths

def identify_static_voxels(historical_splats, current_splats):
    """Identifies static voxels by marking neighbors of deforming historical splats as motion. [S1]"""
    motion_voxels = set()
    for s_h in historical_splats:
        if has_deformed(s_h):
            for neighbor in get_voxel_neighbors(s_h.position):
                motion_voxels.add(neighbor)
    all_voxels = {s.position for s in current_splats} | {s.position for s in historical_splats}
    return all_voxels - motion_voxels

def has_deformed(splat):
    """Checks if a splat has undergone deformation. [G]"""
    return splat.scale_change > 0.0 or splat.rotation_change > 0.0

def get_voxel_neighbors(position):
    """Returns adjacent voxel coordinates. [G]"""
    return [(position.x + dx, position.y + dy, position.z + dz) for dx in (-1, 0, 1) for dy in (-1, 0, 1) for dz in (-1, 0, 1) if not (dx == 0 and dy == 0 and dz == 0)]

def get_past_keyframe_attributes(position):
    """Retrieves stored attributes from the past keyframe buffer. [G]"""
    return cached_attributes.get(position, None)
```

**Parameters:**
*   **Keyframe Interval:** 5 frames apart [S1].
*   **Keyframe Duration:** 10 frames each [S1].
*   **Static Blend Factor:** 50% (0.5) of voxel attributes from the past keyframe [S1].
*   **Error Threshold:** Not given in the sources. [G]

**Edge Cases and Pitfalls:**
*   **Warping Inaccuracies:** The method specifically targets artifacts from warping errors, appearance variation, and new objects [S1].
*   **Motion Regions:** Historical splats undergoing deformation mark neighboring voxels as motion, preventing incorrect static blending in dynamic areas [S1].
*   **Transformer Errors:** Current frame splats predicted by the multi-view transformer can be erroneous; the error check prevents these from corrupting the scene [S1].

## Subtopics

## Operating characteristics
*   **Time Complexity:** Adds overhead for rendering historical splats and current splats to assess error [S1]. The cost depends on the number of historical splats and views [S1].
*   **Memory Complexity:** Maintains primitives from a set of past keyframes. In practice, two keyframes are stored [S1].
*   **Strengths:** Mitigates warping inaccuracies, reduces temporal flickering, and improves reconstruction quality in dynamic scenes [S1].
*   **Limitations:** Requires rendering multiple passes for error assessment, which increases computational cost [S1]. Relies on the accuracy of the multi-view transformer for current frame prediction [S1].
*   **When to Use:** Dynamic scenes where temporal stability is critical and warping artifacts are prevalent [S1].
*   **When Not to Use:** Static scenes where temporal fusion is unnecessary, or real-time performance is severely constrained [S1].

## Background
*   **Origin:** Introduced in "Learning Efficient Fuse-and-Refine for Feed-Forward 3D Gaussian Splatting" [S1].
*   **History:** Developed to address temporal flickering and artifacts in feed-forward 3D Gaussian Splatting for video [S1]. It extends static-scene-trained models to video by merging historical and current frame information [S1].
*   **Usage:** Used in history-aware streaming reconstruction for dynamic 3D Gaussian Splatting [S1].
