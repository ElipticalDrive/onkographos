# Global Splat Merge and Rendering

Also called: Global Splat Sort & Merge, GsplatGlobalRenderer, Merged Draw

## Overview
Global Splat Merge and Rendering is a technique that merges multiple independent Gaussian Splat renderers into a single global draw call by packing their splat data, spherical harmonic (SH) coefficients, and depth/order information into shared global buffers, then performing a cascaded merge of depth-sorted orders [S1, unofficial]. It merges two or more active Gaussian splat renderers into a single globally depth-sorted draw call to reduce overdraw and improve sorting accuracy across scenes [S1, unofficial]. Unlike per-renderer rendering, where each renderer handles its own depth sorting and draw calls independently, this method delegates sorting execution to a global sorter and rendering to a global renderer, triggered when camera movement exceeds thresholds or refresh rate dictates [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- A set of active Gaussian Splat renderers, each providing packed splat data, SH coefficients, and local depth-sorted order buffers [S1, unofficial].
- Camera state (translation and rotation) to determine if sorting needs refresh [S1, unofficial].
- Configuration parameters: `EnableGlobalSort`, `MaxRenderOrder`, `CameraTranslationRefreshTreshold`, `CameraRotationRefreshTreshold` [S1, unofficial].

**Outputs:**
- A single globally depth-sorted order buffer [S1, unofficial].
- A single draw call rendering all active splats with correct depth ordering [S1, unofficial].

### Data Structures
The method relies on several global buffers allocated based on the total number of splats and the maximum SH bands among all active renderers [S1, unofficial].

**RendererParams struct** (16-byte stride per renderer):
- `Brightness`: float (4 bytes)
- `ScaleFactor`: float (4 bytes)
- `GammaToLinear`: uint (4 bytes)
- `SHDegree`: uint (4 bytes) [S1, unofficial].

**Global Buffers:**
- `m_globalPackedBuffer`: `uint[4]` per splat. Stores packed splat data (center xyz, scale, rgba, quaternion) [S1, unofficial].
- `m_globalOrderBuffer`: `uint` per splat. Stores the global render order [S1, unofficial].
- `m_rendererOffsetsBuffer`: `uint` per active renderer. Stores the starting index in the global buffers for each renderer [S1, unofficial].
- `m_rendererTransformsBuffer`: `float[16]` per renderer. Stores the 4x4 transformation matrix for each renderer [S1, unofficial].
- `m_rendererParamsBuffer`: 16 bytes per renderer. Stores `RendererParams` [S1, unofficial].
- `m_globalSH1Buffer`: `uint[2]` per splat (if `m_globalSHBands >= 1`) [S1, unofficial].
- `m_globalSH2Buffer`: `uint[4]` per splat (if `m_globalSHBands >= 2`) [S1, unofficial].
- `m_globalSH3Buffer`: `uint[4]` per splat (if `m_globalSHBands >= 3`) [S1, unofficial].
- `m_globalSH4Buffer`: `uint[4]` per splat (if `m_globalSHBands >= 4`) [S1, unofficial].

**Scratch Buffers:**
- `m_packScratchOrders`: Used during order packing [S1, unofficial].
- `m_packScratchDepths`: Used during depth packing [S1, unofficial].
- `m_mergeScratchOrders`: Used during cascaded merge [S1, unofficial].
- `m_mergeScratchDepths`: Used during cascaded merge [S1, unofficial].

### Steps
1. **Initialize Kernels:** Find kernel indices for `PackRendererOrders`, `MergeTwo`, `MergeTwoWithDepth` in `MergeShader`, and `CopyUint4`, `CopyUint2` in `CopyBufferShader` [S1, unofficial].
2. **Check Dirty State:** If `m_globalBuffersDirty` is true or `ActiveSplatCountsChanged` is true, proceed to rebuild global buffers [S1, unofficial].
3. **Calculate Totals:** Compute `m_totalSplatCount` as the sum of splat counts from all active renderers [S1, unofficial]. Compute `m_rendererOffsets` for each active renderer `k` as the cumulative sum of splat counts of previous renderers [S1, unofficial]. Determine `m_globalSHBands` as the maximum SH bands among all active splats [S1, unofficial].
4. **Allocate Global Buffers:** Create `GraphicsBuffers` for `m_globalPackedBuffer`, `m_globalOrderBuffer`, `m_rendererOffsetsBuffer`, `m_rendererTransformsBuffer`, `m_rendererParamsBuffer`, and SH buffers (`m_globalSH1Buffer` to `m_globalSH4Buffer`) based on `m_globalSHBands` [S1, unofficial]. Set `m_rendererOffsetsBuffer` data [S1, unofficial].
5. **Copy Per-Renderer Data:** For each active renderer `k`, copy its packed splat data, SH coefficients, and order data into the global buffer sub-ranges starting at `m_rendererOffsets[k]` [S1, unofficial].
6. **Dispatch Merge Passes:** Use `PackRendererOrders` to pack orders/depths, then `MergeTwo` or `MergeTwoWithDepth` for cascaded merging of orders across renderers using scratch buffers (`m_packScratchOrders`, `m_packScratchDepths`, `m_mergeScratchOrders`, `m_mergeScratchDepths`) [S1, unofficial].
7. **Render:** Delegate rendering to `GsplatGlobalRenderer` using the globally sorted order buffer [S1, unofficial].

### Parameters
- `EnableGlobalSort`: Boolean flag that activates the global merge pipeline [S1, unofficial].
- `MaxRenderOrder`: Maximum depth sorting layers allowed; range 1 to 20 [S1, unofficial].
- `CameraTranslationRefreshTreshold`: Distance threshold in world units that forces recomputation of sorting and cutouts regardless of refresh rate; range 0.05 to 1.0, default 0.2 [S1, unofficial].
- `CameraRotationRefreshTreshold`: Rotation threshold in degrees that forces recomputation of sorting and cutouts regardless of refresh rate; range 0.2 to 30.0, default 10 [S1, unofficial].
- `k_mergePassName`: String constant "Gsplat.MergeKWay" used for GPU profiling samples [S1, unofficial].

```python
def GlobalSplatMergeAndRender(active_renderers, camera_state, settings):
    if not settings.EnableGlobalSort:
        for renderer in active_renderers:
            renderer.Render()
        return

    if settings.m_globalBuffersDirty or settings.ActiveSplatCountsChanged:
        m_totalSplatCount = sum(r.SplatCount for r in active_renderers)
        m_rendererOffsets = []
        offset = 0
        for r in active_renderers:
            m_rendererOffsets.append(offset)
            offset += r.SplatCount

        m_globalSHBands = max((r.GsplatAsset.SHBands if r.GsplatAsset else 0) for r in active_renderers)

        m_globalPackedBuffer = allocate_buffer(m_totalSplatCount * 4)
        m_globalOrderBuffer = allocate_buffer(m_totalSplatCount)
        m_rendererOffsetsBuffer = allocate_buffer(len(active_renderers))
        m_rendererTransformsBuffer = allocate_buffer(len(active_renderers) * 16)
        m_rendererParamsBuffer = allocate_buffer(len(active_renderers) * 16)

        m_globalSH1Buffer = allocate_buffer(m_totalSplatCount * 2) if m_globalSHBands >= 1 else None
        m_globalSH2Buffer = allocate_buffer(m_totalSplatCount * 4) if m_globalSHBands >= 2 else None
        m_globalSH3Buffer = allocate_buffer(m_totalSplatCount * 4) if m_globalSHBands >= 3 else None
        m_globalSH4Buffer = allocate_buffer(m_totalSplatCount * 4) if m_globalSHBands >= 4 else None

        m_rendererOffsetsBuffer[:] = m_rendererOffsets

        for k, renderer in enumerate(active_renderers):
            start_idx = m_rendererOffsets[k]
            count = renderer.SplatCount

            m_globalPackedBuffer[start_idx * 4 : (start_idx + count) * 4] = renderer.PackedSplatsBuffer[:]
            if renderer.GsplatAsset.SHBands >= 1 and m_globalSH1Buffer is not None:
                m_globalSH1Buffer[start_idx * 2 : (start_idx + count) * 2] = renderer.PackedSH1Buffer[:]
            if renderer.GsplatAsset.SHBands >= 2 and m_globalSH2Buffer is not None:
                m_globalSH2Buffer[start_idx * 4 : (start_idx + count) * 4] = renderer.PackedSH2Buffer[:]
            if renderer.GsplatAsset.SHBands >= 3 and m_globalSH3Buffer is not None:
                m_globalSH3Buffer[start_idx * 4 : (start_idx + count) * 4] = renderer.PackedSH3Buffer[:]
            if renderer.GsplatAsset.SHBands >= 4 and m_globalSH4Buffer is not None:
                m_globalSH4Buffer[start_idx * 4 : (start_idx + count) * 4] = renderer.PackedSH4Buffer[:]

            m_rendererTransformsBuffer[k * 16 : (k + 1) * 16] = renderer.TransformMatrix[:]
            params = [renderer.Brightness, renderer.ScaleFactor, renderer.GammaToLinear, renderer.SHDegree]
            m_rendererParamsBuffer[k * 16 : (k + 1) * 16] = params

        settings.m_globalBuffersDirty = False
        settings.ActiveSplatCountsChanged = False

    if CameraMovedSignificantly(camera_state, settings.CameraTranslationRefreshTreshold, settings.CameraRotationRefreshTreshold):
        dispatch_compute_shader(PackRendererOrders, (m_totalSplatCount + 255) // 256,
                                m_globalPackedBuffer, m_globalOrderBuffer,
                                settings.m_packScratchDepths, m_rendererOffsets,
                                [r.SplatCount for r in active_renderers])

        # Cascaded binary merge tree (log2(K) passes)
        num_renderers = len(active_renderers)
        current_orders = [m_globalOrderBuffer[i * count : (i + 1) * count] for i, count in enumerate([r.SplatCount for r in active_renderers])]
        current_depths = [settings.m_packScratchDepths[i * count : (i + 1) * count] for i, count in enumerate([r.SplatCount for r in active_renderers])]

        while num_renderers > 1:
            next_orders = []
            next_depths = []
            for i in range(0, num_renderers, 2):
                if i + 1 < num_renderers:
                    merged_order = allocate_buffer(len(current_orders[i]) + len(current_orders[i+1]))
                    merged_depth = allocate_buffer(len(current_depths[i]) + len(current_depths[i+1]))
                    dispatch_compute_shader(MergeTwo, (len(merged_order) + 255) // 256,
                                            current_orders[i], current_depths[i],
                                            current_orders[i+1], current_depths[i+1],
                                            merged_order, merged_depth)
                    next_orders.append(merged_order)
                    next_depths.append(merged_depth)
                else:
                    next_orders.append(current_orders[i])
                    next_depths.append(current_depths[i])
            current_orders = next_orders
            current_depths = next_depths
            num_renderers = len(current_orders)

        final_order = current_orders[0]
        GsplatGlobalRendererDraw(m_globalPackedBuffer, final_order,
                                 m_rendererTransformsBuffer, m_rendererParamsBuffer,
                                 [m_globalSH1Buffer, m_globalSH2Buffer, m_globalSH3Buffer, m_globalSH4Buffer])
```

### Edge Cases and Pitfalls
- **Async Upload Growth:** If a renderer uses AsyncUpload and its SplatCount grows frame-to-frame, the global buffers must be rebuilt when the count changes [S1, unofficial]. Otherwise, the global sub-ranges only contain splats present at the first build, leaving the merge to read stale/under-sized buffers [S1, unofficial].
- **Uncompressed Assets:** If any active renderer uses an uncompressed asset, the whole scene falls back to per-renderer rendering, even if `EnableGlobalSort` is true [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by the cascaded merge pass, which is $O(N \log K)$ where $N$ is the total number of splats and $K$ is the number of active renderers [G]. The merge is performed on the GPU using compute shaders [S1, unofficial].
- **Memory Complexity:** $O(N)$ for global buffers, where $N$ is the total number of splats [S1, unofficial]. Additional memory for scratch buffers during merge is required [G].
- **Measured Performance:** Not given in the sources [S1, unofficial].
- **Scaling:** Scales with the number of active renderers and total splat count [G]. The cascaded merge tree depth increases logarithmically with the number of renderers [G].
- **Strengths:** Reduces overdraw by globally sorting splats across multiple renderers [S1, unofficial]. Improves sorting accuracy across scenes [S1, unofficial].
- **Limitations:** Requires all active renderers to use compressed assets [S1, unofficial]. Rebuilding global buffers can be expensive if splat counts change frequently [G].
- **When to Use:** When rendering multiple Gaussian Splat scenes in a single frame and global depth sorting is desired [G].
- **When Not to Use:** When renderers use uncompressed assets, or when the number of active renderers is small and per-renderer sorting is sufficient [S1, unofficial].

## Background
The method is part of the Gsplat-Unity project, an unofficial implementation of 3D Gaussian Splatting for Unity [S1, unofficial]. It builds on [Cascaded 2-way Merge for Global Splat Sorting](7689-cascaded-2-way-merge-for-global-splat-sorting.md) to handle cross-renderer depth ordering [S1, unofficial]. The project is maintained by Yize Wu and Arthur Aillet [S1, unofficial].
