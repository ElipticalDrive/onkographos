# DirectXSplat Renderer API

Also called: DirectXSplat, DirectXSplat Rendering Pipeline, directxsplat::Renderer

## Overview
DirectXSplat is a C++/Direct3D 12 library for rendering 3D Gaussian Splats, providing a rasterization pipeline that handles scene upload, preparation, rendering, and frame submission with explicit resource management [S1, unofficial]. It differs from general-purpose ray marching or CPU-based splitters by offering a host-owned D3D12 architecture where the renderer manages GPU memory residency and LOD culling while the host controls command list recording and queue submission [S1, unofficial]. It is designed for high performance, claiming up to 2.4x faster rendering than `gsplat` in matched-quality benchmarks on NVIDIA hardware [S1, unofficial].

## How it works
The API follows a prepare-then-render pattern. The host initializes a `D3D12Context` and a `Renderer`, loads a scene file into a `directxsplat::Scene` object, and creates an `UploadedSceneHandle` to transfer data to GPU memory [S1, unofficial]. For each frame, the host populates a `RenderFrameContext` and calls `PrepareSceneForRender` to handle LOD selection, culling, and memory residency decisions [S1, unofficial]. Finally, `Render` is called with a reset command list and target binding to record rasterization commands [S1, unofficial].

### Inputs and Outputs
*   **Inputs**: `ID3D12Device*`, `ID3D12CommandQueue*`, `ID3D12Fence*`, scene file path (PLY, SPZ, .splat, SOG, or hierarchical LOD metadata), `RenderInput` (camera matrices, etc.), `RenderTargetBinding` (color/depth targets), `RenderFrameContext`.
*   **Outputs**: `RenderPreparationResult` (intermediate state), `RenderResult` (submission details, sync points), rendered image in `colorTarget`.

### Data Structures

**`RenderFrameContext`**
*   `fence`: `ID3D12Fence*` (must match context initialization).
*   `completedFenceValue`: `uint64_t` (latest known completed value).
*   `submissionFenceValue`: `uint64_t` (unique, strictly increasing per frame).
*   `frameIndex`: `uint32_t`.

**`RenderTargetBinding`**
*   `colorTarget`: `ID3D12Resource*`.
*   `colorRtv`: `D3D12_CPU_DESCRIPTOR_HANDLE`.
*   `colorFormat`: `DXGI_FORMAT` (must match RTV single-sampled format).
*   `colorStateBefore`: `D3D12_RESOURCE_STATES`.
*   `colorStateAfter`: `D3D12_RESOURCE_STATES`.
*   `transitionMode`: `ResourceTransitionMode` (`LibraryManaged` or `CallerManaged`).
*   `viewport`: `D3D12_VIEWPORT`.
*   `scissor`: `D3D12_RECT`.

**`RendererConfig`**
*   `residencyBudgetGaussians`: `uint64_t` (Default: 16,777,216).
*   `uploadBudgetGaussians`: `uint64_t` (Default: 650,000).
*   `warmUploadBudgetGaussians`: `uint64_t` (Default: 1,200,000).
*   `maxUploadsPerFrame`: `uint32_t` (Default: 16).
*   `chunkTargetSize`: `uint32_t` (Default: 65,536).
*   `lod0ScreenRadius`: `float` (Default: 72.0f).
*   `lod1ScreenRadius`: `float` (Default: 24.0f).
*   `cullScreenRadius`: `float` (Default: 0.35f).
*   `residencyCacheFrames`: `uint32_t` (Default: 120).
*   `enableGpuTiming`: `bool` (Default: true).

**Gaussian Structure (Internal)**
*   `position`: `Vec3`.
*   `scale`: `Vec3`.
*   `rotation`: `Vec4` (quaternion).
*   `opacity`: `float`.
*   `sh`: `array` of floats (Spherical Harmonics coefficients).

### Numbered Steps

1.  **Initialize Context**: Create `D3D12Context` with host `ID3D12Device*`, `ID3D12CommandQueue*`, and `ID3D12Fence*` [S1, unofficial].
2.  **Initialize Renderer**: Create `Renderer` instance [S1, unofficial].
3.  **Load Scene**: Call `LoadSceneFromFile(scenePath)` to create `directxsplat::Scene` [S1, unofficial].
4.  **Upload Scene**: Call `CreateUploadedScene(loaded_scene, handle)` to transfer data to GPU [S1, unofficial].
5.  **Prepare Frame Context**: Populate `RenderFrameContext` with fence pointer, `completedFenceValue`, unique `submissionFenceValue`, and `frameIndex` [S1, unofficial].
6.  **Prepare Scene**: Call `PrepareSceneForRender(scene, input, frameContext, &preparation_result)` [S1, unofficial].
7.  **Configure Target**: Set `RenderTargetBinding` with color target, RTV, format, states, transition mode, viewport, and scissor [S1, unofficial].
8.  **Render**: Call `Render(command_list, target_binding, scene, input, frame_context, &render_result)` [S1, unofficial].
9.  **Handle Sync**: If `render_result.submission.uploadSyncPoint` is valid, wait on the direct queue for that sync point [S1, unofficial].
10. **Submit**: Close command list, execute on direct queue, signal fence with `submissionFenceValue` [S1, unofficial].
11. **Wait**: Wait for fence completion (typically via `GetCompletedValue()` or blocking wait) before next frame [S1, unofficial].

### Pseudocode

```python
# Initialization
context = D3D12Context()
context.Initialize(device, direct_queue, direct_fence)

renderer = Renderer()
renderer.Initialize(context, config) # config uses defaults or custom values

# Scene Loading
loaded_scene = LoadSceneFromFile(scene_path)
scene_handle = renderer.CreateUploadedScene(loaded_scene)

# Frame Loop
for frame_index in range(num_frames):
    # 1. Prepare Frame Context
    frame_context = RenderFrameContext()
    frame_context.fence = direct_fence
    frame_context.completedFenceValue = direct_fence.GetCompletedValue()
    frame_context.submissionFenceValue = next_unique_fence_value() # Must be > all previous
    frame_context.frameIndex = frame_index

    # 2. Prepare Scene (LOD, Culling, Residency)
    preparation_result = RenderPreparationResult()
    status = renderer.PrepareSceneForRender(scene_handle, render_input, frame_context, preparation_result)
    if not status.ok:
        handle_error(status)

    # 3. Configure Render Target
    target_binding = RenderTargetBinding()
    target_binding.colorTarget = color_target_resource
    target_binding.colorRtv = color_rtv_handle
    target_binding.colorFormat = color_format
    target_binding.colorStateBefore = D3D12_RESOURCE_STATES.PRESENT
    target_binding.colorStateAfter = D3D12_RESOURCE_STATES.RENDER_TARGET
    target_binding.transitionMode = ResourceTransitionMode.LibraryManaged
    target_binding.viewport = viewport
    target_binding.scissor = scissor

    # 4. Render
    render_result = RenderResult()
    status = renderer.Render(command_list, target_binding, scene_handle, render_input, frame_context, render_result)
    
    # Handle error with submission required
    if not status.ok and render_result.submission.submissionRequired:
        # Command list work may be recorded; must submit or enter device-lost cleanup
        pass

    # 5. Handle Upload Sync
    if render_result.submission.uploadSyncPoint.IsValid():
        direct_queue.Wait(render_result.submission.uploadSyncPoint.fence, 
                          render_result.submission.uploadSyncPoint.value)

    # 6. Submit Command List
    command_list.Close()
    direct_queue.ExecuteCommandLists([command_list])
    direct_queue.Signal(direct_fence, frame_context.submissionFenceValue)

    # 7. Wait for Completion (for next frame's completedFenceValue)
    # Implementation dependent: direct_fence.WaitForValue(frame_context.submissionFenceValue)

# Shutdown
renderer.DestroyUploadedScene(scene_handle)
renderer.Shutdown()
context.Shutdown()
```

### Parameters and Typical Values
*   `lod0ScreenRadius`: 72.0f. Splats larger than this use LOD 0 [S1, unofficial].
*   `lod1ScreenRadius`: 24.0f. Splats smaller than this but larger than `cullScreenRadius` use LOD 1 [S1, unofficial].
*   `cullScreenRadius`: 0.35f. Splats smaller than this are culled [S1, unofficial].
*   `residencyBudgetGaussians`: 16,777,216. Max Gaussians resident in GPU memory [S1, unofficial].
*   `uploadBudgetGaussians`: 650,000. Max Gaussians uploaded per frame [S1, unofficial].

### Edge Cases and Pitfalls
*   **Fence Values**: `submissionFenceValue` must be nonzero, unique per frame, strictly greater than every previously signaled value, and strictly greater than `completedFenceValue` [S1, unofficial].
*   **Format Mismatch**: `colorRtv` must describe `colorTarget`, and `colorFormat` must match the RTV's single-sampled format; unsupported formats fail pipeline creation [S1, unofficial].
*   **Error Submission**: If `Render` returns an error with `submissionRequired == true`, command-list work may already be recorded and must be submitted/signaled or enter device-lost cleanup [S1, unofficial].
*   **Mutual Exclusion**: Rendering and scene mutation are mutually exclusive for the same uploaded scene. `BeginSceneMutation` waits for active render encoding to finish [S1, unofficial].
*   **Resource Ownership**: `D3D12Context` stores non-owning pointers. Host must keep device, queues, and fences alive until shutdown [S1, unofficial].

## Operating characteristics
*   **Performance**: Benchmarked on NVIDIA GeForce RTX 4070 SUPER, Windows 11. DirectXSplat achieves 382.51 FPS on the "bicycle" dataset (6.1M splats, 1237x822 resolution), compared to 165.82 FPS for `gsplat` [S1, unofficial]. It claims up to 2.4x faster rendering in matched-quality resident-scene benchmarks [S1, unofficial].
*   **Memory**: Memory-conscious design with persistent uploaded scenes and configurable residency/upload budgets [S1, unofficial].
*   **Strengths**: High performance, native D3D12 integration, explicit resource management, support for multiple scene formats (PLY, SPZ, .splat, SOG) [S1, unofficial].
*   **Limitations**: D3D12 only (Windows), requires host to manage command lists and fences, not a standalone viewer (though convenience wrappers exist) [S1, unofficial].
*   **When to use**: High-performance Gaussian Splatting rendering in D3D12 applications where host control over the rendering pipeline is desired.
*   **When not to use**: Cross-platform projects requiring Vulkan/Metal, or simple prototyping where a standalone viewer suffices.

## Background
DirectXSplat is a C++/Direct3D 12 library for rendering 3D Gaussian Splats, based on the techniques described in "3D Gaussian Splatting for Real-Time Radiance Field Rendering" [S1, unofficial]. It was developed to provide a fast, embeddable renderer for D3D12 applications, addressing the need for efficient rasterization of Gaussian primitives [S1, unofficial].
