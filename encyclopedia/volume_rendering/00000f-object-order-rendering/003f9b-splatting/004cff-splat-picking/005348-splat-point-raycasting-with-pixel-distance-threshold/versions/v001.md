# Splat Point Raycasting with Pixel Distance Threshold

Also called: Pixel Distance Threshold Splat Picking

## Overview
A method to identify 3D points from a splat mesh that are close to a camera ray by using a pixel-distance threshold in screen space rather than strict geometric intersection, thereby handling the discrete nature of splats [S1, unofficial]. It differs from strict ray-splat intersection by projecting splat centers to screen space and comparing their Euclidean distance to the cursor, allowing for efficient sub-frame latency picking [S1, unofficial].

## How it works
**Inputs:** Mouse client coordinates (`mouseClientX`, `mouseClientY`), viewport dimensions (`width`, `height`, `left`, `top`), camera view-projection matrix (`viewProj`), and a list of active splat points with their 3D positions.
**Outputs:** The 3D position of the closest splat point to the mouse cursor.

**Data Structures:**
*   `SplatPoint`: Contains `position` (vec3), `pixelDist` (float), and `cameraDist` (float).
*   `IntersectionList`: A list of `SplatPoint` objects that pass the initial pixel distance threshold.

**Parameters:**
*   `MinPixelDistance`: The maximum distance in screen pixels between the projected splat center and the mouse cursor for a splat to be considered a hit. Typical value: 5 [S1, unofficial].
*   `MaxCandidates`: The maximum number of candidates to keep after filtering. Typical value: 20 [S1, unofficial].
*   `DistanceThreshold`: The 3D distance threshold for filtering candidates. Typical value: 0.01 [S1, unofficial].

**Steps:**
1.  **Convert Mouse Coordinates:** Transform mouse client coordinates to Normalized Device Coordinates (NDC) and then to pixel coordinates for distance calculation.
    *   `mouse.x = ((mouseClientX - left) / width) * 2 - 1`
    *   `mouse.y = ((top - mouseClientY) / height) * 2 + 1`
    *   `mousePixelX = ((mouse.x + 1) / 2) * width`
    *   `mousePixelY = ((1 - mouse.y) / 2) * height`
2.  **Construct View-Projection Matrix:** Combine the camera's projection matrix and world inverse matrix.
    *   `viewProj = camera.projectionMatrix.clone().multiply(camera.matrixWorldInverse)`
3.  **Iterate and Project:** For each active splat point:
    *   Transform the point by the meta matrix if present.
    *   Project the point to screen space using `viewProj`.
    *   Calculate the Euclidean distance in pixels (`pixelDist`) between the projected point and the mouse cursor.
    *   If `pixelDist <= MinPixelDistance`, add the point to the `IntersectionList` with its `cameraDist` (distance from camera) and `pixelDist`.
4.  **Sort by Depth:** Sort `IntersectionList` by `cameraDist` in ascending order.
5.  **Filter Candidates:** Keep only candidates within `DistanceThreshold` (0.01) of the closest point's `cameraDist`, limiting the list to the top `MaxCandidates` (20) [S1, unofficial].
6.  **Select Closest:** Sort the filtered candidates by `pixelDist` in ascending order and return the position of the first candidate [S1, unofficial].

**Pseudocode:**
```python
def splat_point_ray_casting(mouse_client_x, mouse_client_y, width, height, left, top, view_proj, splat_points, min_pixel_distance=5.0, distance_threshold=0.01, max_candidates=20):
    # Step 1: Convert mouse coordinates
    mouse_x_ndc = ((mouse_client_x - left) / width) * 2 - 1
    mouse_y_ndc = ((top - mouse_client_y) / height) * 2 + 1
    
    mouse_pixel_x = ((mouse_x_ndc + 1) / 2) * width
    mouse_pixel_y = ((1 - mouse_y_ndc) / 2) * height
    
    intersections = []
    
    # Step 3: Iterate and project
    for point in splat_points:
        # Transform point by meta matrix if present
        transformed_pos = point.position
        if point.has_meta_matrix:
            transformed_pos = apply_meta_matrix(point.position, point.meta_matrix)
            
        # Project to screen space
        projected = transform_point(transformed_pos, view_proj)
        
        # Calculate pixel distance
        pixel_dist = sqrt((projected.x - mouse_pixel_x)**2 + (projected.y - mouse_pixel_y)**2)
        
        if pixel_dist <= min_pixel_distance:
            camera_dist = length(transformed_pos)
            intersections.append({
                'position': transformed_pos,
                'pixel_dist': pixel_dist,
                'camera_dist': camera_dist
            })
            
    # Step 4: Sort by depth
    intersections.sort(key=lambda x: x['camera_dist'])
    
    # Step 5: Filter candidates
    if not intersections:
        return None
        
    closest_camera_dist = intersections[0]['camera_dist']
    filtered = []
    for item in intersections:
        if item['camera_dist'] <= closest_camera_dist + distance_threshold:
            filtered.append(item)
            if len(filtered) >= max_candidates:
                break
                
    # Step 6: Select closest
    filtered.sort(key=lambda x: x['pixel_dist'])
    
    if filtered:
        return filtered[0]['position']
    return None
```

**Optimization Pitfall:** When processing splat data stored as a dictionary of chunks, check if the ray distance to the chunk center is <= 1.4143 before iterating through points in that chunk to optimize performance [S1, unofficial].

## Subtopics

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of active splat points for the initial projection and filtering, followed by sorting which is $O(N \log N)$ where $N$ is the number of candidates within the pixel threshold.
*   **Memory Complexity:** Linear with respect to the number of candidates within the pixel threshold.
*   **Strengths:** Fast sub-frame latency; handles discrete splat nature well; simple to implement.
*   **Limitations:** Approximate; may pick non-geometrically closest splat if pixel distance is small but camera distance is large (mitigated by sorting and filtering).
*   **When to Use:** Interactive picking in real-time splat rendering.
*   **When Not to Use:** When strict geometric intersection is required.
