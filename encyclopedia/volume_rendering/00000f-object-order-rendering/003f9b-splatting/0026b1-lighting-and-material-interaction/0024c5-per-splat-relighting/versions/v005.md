# Per-Splat Relighting
## Overview
Per-Splat Relighting computes a lighting multiplier for a splat based on lights, normal, ambient occlusion, and confidence [S1, unofficial]. It differs from [Photon Splatting](2832-photon-splatting.md) by calculating lighting analytically per-splat rather than accumulating photon densities, allowing real-time updates when light positions or intensities change without re-radiating photons [G].

## How it works
**Inputs and Outputs:**
*   **Inputs:** `splat_lighting` buffer (packed lighting records), `light_rig` buffer (light definitions), `world_position` of the splat center, `unlit_level` (base color), `ambient` color, `gain` scalar [S1, unofficial].
*   **Output:** Relit color value [S1, unofficial].

**Data Structures:**
The `splat_lighting` buffer stores per-splat metadata packed into a 4-component vector where `rg` is an octahedral normal, `b` is ambient occlusion, and `a` is confidence [S1, unofficial]. The `light_rig` buffer is an array where each light occupies 4 consecutive elements: `i*4+0` is a `vec3` representing light position or direction, `i*4+1` contains a `vec3` tint and a float alpha for the light type, `i*4+2` holds setup parameters (`r` for inverse range, `g` for decay, `b` for spot cone cosine threshold, `a` for spot exponent), and `i*4+3` is a `vec3` spot direction vector [S1, unofficial].

**Numbered Steps:**
1.  **Unpack Lighting Record:** Retrieve the lighting record for the current splat index from `splat_lighting` and extract the octahedral normal (`rg`), AO (`b`), and confidence (`a`) [S1, unofficial].
2.  **Normalize Normal:** Convert the octahedral normal to a 3D vector, calculate its length, and normalize it if the length is greater than zero; otherwise, default the normal to `(0, 0, 1)` [S1, unofficial].
3.  **Initialize Direct Light:** Set `direct` illumination to zero [S1, unofficial].
4.  **Loop Over Lights:** For each light `i` in the `light_rig`: extract `tint` from `light_rig[i*4+1]`, `setup` from `light_rig[i*4+2]`, and determine `type` by rounding `tint.a` to the nearest integer; initialize `to_light` from `light_rig[i*4+0].xyz` and `attenuation` to `1.0`; if `type` is not 0, calculate `relative` as `light_rig[i*4+0].xyz - world_position`, compute `dist`, skip if `dist < 1e-6`, normalize `to_light` to `relative / dist`, and compute `attenuation` using the `omni_attenuation` formula with `dist`, `setup.r`, and `setup.g`; if `type` equals 2, calculate `cone_cosine` as `max(dot(-to_light, light_rig[i*4+3].xyz), setup.b)`, compute `rim` as `(1.0 - cone_cosine) / max(1e-4, 1.0 - setup.b)`, and update `attenuation` by multiplying it by `1.0 - pow(clamp(rim, 0, 1), setup.a)`; finally, accumulate `direct` by adding `tint.rgb * attenuation * max(dot(world_normal, to_light), 0)` [S1, unofficial].
5.  **Compute Irradiance:** Calculate `irradiance` as `ambient * ao + direct * confidence` [S1, unofficial].
6.  **Return Result:** Return `unlit_level + gain * irradiance` [S1, unofficial].

**Formulas:**
*   **Omni Attenuation:**
    $$ \text{omni\_attenuation}(dist, inv\_range, decay) = \max(1.0 - (dist \cdot inv\_range)^4, 0)^2 \cdot dist^{-decay} $$
    Where $dist$ is the distance from splat to light, $inv\_range$ is the inverse range of the light (`setup.r`), and $decay$ is the decay exponent (`setup.g`) [S1, unofficial].

**Pseudocode:**
```python
def decode_oct_normal(oct):
    v = vec3(oct.x, oct.y, 1.0 - abs(oct.x) - abs(oct.y))
    if v.z < 0:
        v.xy = 1.0 - abs(v.yx) * vec2(sign(v.x), sign(v.y))
    return normalize(v)

def per_splat_relight(splat_index, world_position, unlit_level, ambient, gain, splat_lighting, light_rig):
    record = splat_lighting[splat_index]
    oct_normal = record.rg
    ao = record.b
    confidence = record.a

    decoded_normal = decode_oct_normal(oct_normal)
    normal_length = length(decoded_normal)
    world_normal = decoded_normal / normal_length if normal_length > 0 else vec3(0, 0, 1)

    direct = vec3(0, 0, 0)
    num_lights = len(light_rig) // 4

    for i in range(num_lights):
        base_idx = i * 4
        tint = light_rig[base_idx + 1]
        setup = light_rig[base_idx + 2]
        light_data = light_rig[base_idx + 0]

        light_type = int(tint.a + 0.5)
        to_light = light_data.xyz
        attenuation = 1.0

        if light_type != 0:
            relative = light_data.xyz - world_position
            dist = length(relative)
            if dist < 1e-6:
                continue
            to_light = relative / dist
            inv_range = setup.r
            decay = setup.g
            term = max(1.0 - (dist * inv_range)**4, 0.0)
            attenuation = (term ** 2) * (dist ** -decay)

        if light_type == 2:
            spot_dir = light_rig[base_idx + 3].xyz
            cone_cosine = max(dot(-to_light, spot_dir), setup.b)
            rim = (1.0 - cone_cosine) / max(1e-4, 1.0 - setup.b)
            attenuation *= 1.0 - pow(clamp(rim, 0.0, 1.0), setup.a)

        diff = max(dot(world_normal, to_light), 0.0)
        direct += tint.rgb * attenuation * diff

    irradiance = ambient * ao + direct * confidence
    return unlit_level + gain * irradiance
```

**Parameters:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Zero Normal:** If the decoded normal has zero length, it defaults to `(0,0,1)`, which can cause incorrect shading for flat surfaces or degenerate splats [S1, unofficial].
*   **Division by Zero:** The spot light rim calculation uses `max(1e-4, 1.0 - setup.b)` to prevent division by zero when the cone angle is very narrow (`setup.b` close to 1.0) [S1, unofficial].
*   **Near-Zero Distance:** Lights at the exact splat position are skipped (`dist < 1e-6`) to avoid NaNs or infinite attenuation [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(L)$ per splat, where $L$ is the number of lights, executed per fragment during splat rendering [G].
*   **Memory Complexity:** $O(1)$ additional memory per splat for the lighting record packed in `splat_lighting` [G].
*   **Strengths:** Real-time capable; supports dynamic light movement and intensity changes without precomputation [G].
*   **Limitations:** Only handles direct lighting and simple AO; no indirect bounces; performance scales linearly with light count [G].
*   **When to use:** Real-time applications with dynamic lighting [G].
*   **When not to use:** Offline rendering requiring global illumination or very high light counts where performance is critical [G].

## Background
Per-Splat Relighting is a technique used in real-time Gaussian Splatting renderers, such as the one implemented in the `godot-gaussian-splatting` repository, which adapts traditional lighting concepts to the splat-based rendering pipeline by storing lighting metadata within the splat data structure [S1, unofficial].
