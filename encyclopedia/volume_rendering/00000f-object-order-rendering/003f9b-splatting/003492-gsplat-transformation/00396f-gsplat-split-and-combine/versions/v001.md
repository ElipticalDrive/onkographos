# Gsplat Split and Combine
Also called: CombineGsplat, Gsplat field extraction, Gsplat field merging, SplitGsplat

## Overview
The Gsplat Split and Combine methods decompose a packed `Gsplat` structure into individual scalar and vector fields for manipulation, or reconstruct a `Gsplat` from partial updates. This enables fine-grained editing of Gaussian attributes (position, scale, rotation, color, opacity) without full serialization overhead. It differs from raw memory copying by providing semantic field access and partial update capabilities, building on [Gsplat Transformation](7308-gsplat-transformation.md).

## How it works
### Inputs and Outputs
- **Input**: A `Gsplat` struct instance and optional update parameters for specific fields.
- **Output**: 
  - **Split**: Individual fields: `active` (bool), `rgb` (vec3), `opacity` (float), `x/y/z` (float), `r/g/b` (float).
  - **Combine**: A reconstructed `Gsplat` struct.

### Data Structures
The `Gsplat` struct layout [S1, unofficial]:
- `flags`: `uint`
- `index`: `int`
- `center`: `vec3` (x, y, z)
- `scales`: `vec3`
- `quaternion`: `vec4` (x, y, z, w)
- `rgba`: `vec4` (r, g, b, a)

### Steps

#### Splitting
1. **Null Check**: If input `gsplat` is null, return default values [S1, unofficial].
2. **Extract Base Fields**:
   - `flags` = `gsplat.flags`
   - `index` = `gsplat.index`
   - `center` = `gsplat.center`
   - `scales` = `gsplat.scales`
   - `quaternion` = `gsplat.quaternion`
   - `rgba` = `gsplat.rgba`
3. **Compute Derived Fields**:
   - `active` = `isGsplatActive(flags)` [S1, unofficial]
   - `rgb` = `rgba.rgb` (components r, g, b)
   - `opacity` = `rgba.a`
   - `x` = `center.x`
   - `y` = `center.y`
   - `z` = `center.z`
   - `r` = `rgba.r`
   - `g` = `rgba.g`
   - `b` = `rgba.b`
4. **Handle Null Input Defaults**: If `gsplat` was null, use:
   - `flags` = 0u
   - `index` = 0
   - `center` = vec3(0)
   - `scales` = vec3(0)
   - `quaternion` = vec4(0, 0, 0, 1)
   - `rgba` = vec4(0)
   - `rgb` = vec3(0)
   - `opacity` = 0
   - `x, y, z` = 0
   - `r, g, b` = 0 [S1, unofficial]

#### Combining
1. **Initialize Output**: Start with an output `gsplat` struct. If no existing `gsplat` is provided, initialize with defaults [S1, unofficial].
2. **Field Update Logic**: For each field (`flags`, `index`, `center`, `scales`, `quaternion`, `rgba`):
   - If the corresponding input parameter is provided, use it.
   - Otherwise, copy from the input `gsplat` (if present) or use default values [S1, unofficial].
3. **Sub-field Updates**: For `rgba` and `center`:
   - If specific sub-inputs (`rgb`, `opacity`, `x`, `y`, `z`, `r`, `g`, `b`) are provided, update only those parts of the `rgba` or `center` vector.
   - Unspecified sub-fields retain values from the input `gsplat` or defaults [S1, unofficial].
4. **Default Values**:
   - `flags`: 0u
   - `index`: 0
   - `center`: vec3(0)
   - `scales`: vec3(0)
   - `quaternion`: vec4(0, 0, 0, 1)
   - `rgba`: vec4(0) [S1, unofficial]

### Pseudocode
```python
def split_gsplat(gsplat):
    # Handle null input
    if gsplat is None:
        return {
            'flags': 0,
            'index': 0,
            'center': vec3(0, 0, 0),
            'scales': vec3(0, 0, 0),
            'quaternion': vec4(0, 0, 0, 1),
            'rgba': vec4(0, 0, 0, 0),
            'active': False,
            'rgb': vec3(0, 0, 0),
            'opacity': 0.0,
            'x': 0.0,
            'y': 0.0,
            'z': 0.0,
            'r': 0.0,
            'g': 0.0,
            'b': 0.0
        }
    
    # Extract base fields
    flags = gsplat.flags
    index = gsplat.index
    center = gsplat.center
    scales = gsplat.scales
    quaternion = gsplat.quaternion
    rgba = gsplat.rgba
    
    # Compute derived fields
    active = is_gsplat_active(flags)
    rgb = vec3(rgba.r, rgba.g, rgba.b)
    opacity = rgba.a
    x = center.x
    y = center.y
    z = center.z
    r = rgba.r
    g = rgba.g
    b = rgba.b
    
    return {
        'flags': flags,
        'index': index,
        'center': center,
        'scales': scales,
        'quaternion': quaternion,
        'rgba': rgba,
        'active': active,
        'rgb': rgb,
        'opacity': opacity,
        'x': x,
        'y': y,
        'z': z,
        'r': r,
        'g': g,
        'b': b
    }

def combine_gsplat(gsplat=None, flags=None, index=None, center=None, 
                   scales=None, quaternion=None, rgba=None, 
                   rgb=None, opacity=None, x=None, y=None, z=None, 
                   r=None, g=None, b=None):
    # Initialize output with defaults if gsplat is None
    if gsplat is None:
        out = {
            'flags': 0,
            'index': 0,
            'center': vec3(0, 0, 0),
            'scales': vec3(0, 0, 0),
            'quaternion': vec4(0, 0, 0, 1),
            'rgba': vec4(0, 0, 0, 0)
        }
    else:
        out = gsplat.copy()
    
    # Update main fields if provided
    if flags is not None:
        out.flags = flags
    if index is not None:
        out.index = index
    if center is not None:
        out.center = center
    if scales is not None:
        out.scales = scales
    if quaternion is not None:
        out.quaternion = quaternion
    if rgba is not None:
        out.rgba = rgba
    
    # Update sub-fields if provided
    if rgb is not None:
        out.rgba.r = rgb.r
        out.rgba.g = rgb.g
        out.rgba.b = rgb.b
    if opacity is not None:
        out.rgba.a = opacity
    if x is not None:
        out.center.x = x
    if y is not None:
        out.center.y = y
    if z is not None:
        out.center.z = z
    if r is not None:
        out.rgba.r = r
    if g is not None:
        out.rgba.g = g
    if b is not None:
        out.rgba.b = b
        
    return out
```

### Parameters and Edge Cases
- **Fractional Bits**: Coordinate precision can be controlled via `--fractional-bits` (default 12, range 6-24) [S1, unofficial].
- **Clipping**: AABB clipping can be applied using `--x-range`, `--y-range`, `--z-range` or `--min-x`, `--max-x`, etc. [S1, unofficial].
- **Opacity Threshold**: Splats with opacity <= threshold can be filtered out using `--opacity-threshold` [S1, unofficial].
- **SH Degree**: Maximum spherical harmonic degree can be set via `--max-sh` (0-3, default auto-detect) [S1, unofficial].
- **Null Handling**: Null inputs result in default values as specified [S1, unofficial].

## Operating characteristics
- **Time Complexity**: O(1) for split and combine operations as they involve fixed-size struct field access and assignment.
- **Memory Complexity**: O(1) additional memory for split outputs; combine reuses existing memory if possible.
- **Strengths**: Efficient field-level manipulation; supports partial updates; handles null inputs gracefully.
- **Limitations**: Requires careful handling of sub-field updates to avoid unintended overwrites; precision depends on fractional bits setting.
- **When to Use**: When fine-grained editing of Gaussian attributes is needed without full serialization; when partial updates are required.
- **When Not to Use**: When bulk operations on many splats are needed; when full structural changes are required.

## Background
The Gsplat Split and Combine methods are part of the `sparkjsdev/spark` toolset, an unofficial implementation for processing Gaussian Splatting data [S1, unofficial]. The tool supports transcoding SPZ files with various options for clipping, opacity filtering, and precision control [S1, unofficial]. The methods enable efficient manipulation of Gaussian attributes within the Gaussian Splatting framework, building on the transformation capabilities described in [Gsplat Transformation](7308-gsplat-transformation.md).
