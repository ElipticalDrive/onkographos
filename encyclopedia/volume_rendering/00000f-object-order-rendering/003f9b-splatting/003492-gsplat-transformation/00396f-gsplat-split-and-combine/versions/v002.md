# Gsplat Split and Combine
Also called: CombineGsplat, Gsplat field extraction, Gsplat field merging, SplitGsplat

## Overview
The Gsplat Split and Combine methods decompose a packed `Gsplat` structure into individual scalar and vector fields for manipulation, or reconstruct a `Gsplat` from partial updates [S1, unofficial]. This enables fine-grained editing of Gaussian attributes without full serialization overhead, building on [Gsplat Transformation](7308-gsplat-transformation.md).

## How it works
### Inputs and Outputs
- **Input**: A `Gsplat` struct instance and optional update parameters for specific fields.
- **Output**: 
  - **Split**: Individual fields: `active` (bool), `rgb` (vec3), `opacity` (float), `x/y/z` (float), `r/g/b` (float).
  - **Combine**: A reconstructed `Gsplat` struct.

### Data Structures
The `Gsplat` struct contains the following fields [S1, unofficial]:
- `flags`: `uint`
- `index`: `int`
- `center`: `vec3` (x, y, z)
- `scales`: `vec3`
- `quaternion`: `vec4` (x, y, z, w)
- `rgba`: `vec4` (r, g, b, a)

### Steps
#### Splitting
1. **Null Check**: If input `gsplat` is null, return default values [S1, unofficial].
2. **Extract Base Fields**: Copy `flags`, `index`, `center`, `scales`, `quaternion`, `rgba` directly from the input [S1, unofficial].
3. **Compute Derived Fields**: Calculate `active` from `flags`, `rgb` from `rgba`, `opacity` from `rgba.a`, and `x/y/z` and `r/g/b` from `center` and `rgba` components [S1, unofficial].
4. **Apply Defaults**: If the input was null, assign `flags=0u`, `index=0`, `center=vec3(0)`, `scales=vec3(0)`, `quaternion=vec4(0,0,0,1)`, `rgba=vec4(0)`, `rgb=vec3(0)`, `opacity=0`, `x/y/z=0`, `r/g/b=0` [S1, unofficial].

#### Combining
1. **Initialize Output**: Start with an output `gsplat` struct. If no existing `gsplat` is provided, initialize with defaults [S1, unofficial].
2. **Field Update Logic**: For each top-level field (`flags`, `index`, `center`, `scales`, `quaternion`, `rgba`), if the corresponding input parameter is provided, use it; otherwise, copy from the input `gsplat` (if present) or use default values [S1, unofficial].
3. **Sub-field Updates**: For `rgba` and `center`, if specific sub-inputs (`rgb`, `opacity`, `x`, `y`, `z`, `r`, `g`, `b`) are provided, update only those parts of the vector [S1, unofficial].
4. **Default Values**: Apply `flags=0u`, `index=0`, `center=vec3(0)`, `scales=vec3(0)`, `quaternion=vec4(0,0,0,1)`, `rgba=vec4(0)` where unspecified [S1, unofficial].

### Pseudocode
```python
class Vec3:
    def __init__(self, x=0.0, y=0.0, z=0.0): self.x, self.y, self.z = x, y, z
class Vec4:
    def __init__(self, r=0.0, g=0.0, b=0.0, a=0.0): self.r, self.g, self.b, self.a = r, g, b, a
class Gsplat:
    def __init__(self, flags=0, index=0, center=None, scales=None, quaternion=None, rgba=None):
        self.flags = flags
        self.index = index
        self.center = center or Vec3()
        self.scales = scales or Vec3()
        self.quaternion = quaternion or Vec4(0, 0, 0, 1)
        self.rgba = rgba or Vec4()

def is_gsplat_active(flags):
    return flags != 0  # Standard active flag check [G]

def split_gsplat(gsplat):
    if gsplat is None:
        return {
            'flags': 0, 'index': 0, 'center': Vec3(), 'scales': Vec3(),
            'quaternion': Vec4(0, 0, 0, 1), 'rgba': Vec4(),
            'active': False, 'rgb': Vec3(), 'opacity': 0.0,
            'x': 0.0, 'y': 0.0, 'z': 0.0, 'r': 0.0, 'g': 0.0, 'b': 0.0
        }
    flags = gsplat.flags
    index = gsplat.index
    center = gsplat.center
    scales = gsplat.scales
    quaternion = gsplat.quaternion
    rgba = gsplat.rgba
    active = is_gsplat_active(flags)
    rgb = Vec3(rgba.r, rgba.g, rgba.b)
    opacity = rgba.a
    x, y, z = center.x, center.y, center.z
    r, g, b = rgba.r, rgba.g, rgba.b
    return {
        'flags': flags, 'index': index, 'center': center, 'scales': scales,
        'quaternion': quaternion, 'rgba': rgba, 'active': active,
        'rgb': rgb, 'opacity': opacity, 'x': x, 'y': y, 'z': z,
        'r': r, 'g': g, 'b': b
    }

def combine_gsplat(gsplat=None, flags=None, index=None, center=None, 
                   scales=None, quaternion=None, rgba=None, 
                   rgb=None, opacity=None, x=None, y=None, z=None, 
                   r=None, g=None, b=None):
    if gsplat is None:
        out = Gsplat()
    else:
        out = Gsplat(gsplat.flags, gsplat.index, gsplat.center, gsplat.scales, gsplat.quaternion, gsplat.rgba)
    
    if flags is not None: out.flags = flags
    if index is not None: out.index = index
    if center is not None: out.center = center
    if scales is not None: out.scales = scales
    if quaternion is not None: out.quaternion = quaternion
    if rgba is not None: out.rgba = rgba
    
    if rgb is not None:
        out.rgba.r = rgb.r; out.rgba.g = rgb.g; out.rgba.b = rgb.b
    if opacity is not None: out.rgba.a = opacity
    if x is not None: out.center.x = x
    if y is not None: out.center.y = y
    if z is not None: out.center.z = z
    if r is not None: out.rgba.r = r
    if g is not None: out.rgba.g = g
    if b is not None: out.rgba.b = b
    return out
```

### Parameters and Edge Cases
- **Fractional Bits**: Coordinate precision is controlled via `--fractional-bits` (default 12, range 6-24) [S1, unofficial].
- **Clipping**: Axis-aligned bounding box clipping is applied using `--x-range`, `--y-range`, `--z-range` or `--min-x`/`--max-x` arguments [S1, unofficial].
- **Opacity Threshold**: Splats with opacity at or below a threshold are filtered out via `--opacity-threshold` [S1, unofficial].
- **SH Degree**: Maximum spherical harmonic degree is set via `--max-sh` (0-3, default auto-detect) [S1, unofficial].
- **Null Handling**: Null inputs are handled by returning or initializing with the specified default values [S1, unofficial].

## Operating characteristics
Time and memory complexity are O(1) due to fixed-size struct field access and assignment [G]. Not given in the sources.
