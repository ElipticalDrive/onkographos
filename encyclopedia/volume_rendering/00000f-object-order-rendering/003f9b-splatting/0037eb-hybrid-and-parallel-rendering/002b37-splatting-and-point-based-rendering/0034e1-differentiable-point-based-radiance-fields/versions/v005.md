# Differentiable Point-Based Radiance Fields

Also called: DPBF, Differentiable Splatting, Point Radiance Fields, Point-Based Radiance Fields

## Overview
Differentiable Point-Based Radiance Fields (DPBF) is a scene representation and rendering method that models radiance using a learned point cloud augmented with per-point spherical harmonic coefficients [S1]. It solves the problem of slow training and high memory usage in neural radiance fields by replacing volumetric ray-marching with a differentiable splat-based rasterizer, allowing for efficient view synthesis via a single forward pass [S1]. Unlike NeRF, which requires many evaluations per ray, DPBF uses forward mapping, resulting in training speeds up to 300x faster and memory usage under 10 MB for static scenes [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ input images $I^j$ ($j=1 \dots N$) with known camera intrinsics and extrinsics, and object masks for each image defining the visual hull [S1].
*   **Outputs:** A rendered image $\hat{I}^j$ for any novel view, and an optimized point cloud representing the scene geometry and radiance [S1].

**Data Structures:**
The scene is represented as a point cloud [S1]. Each point $i$ stores:
1.  **Position:** A 3D vector $p_i \in \mathbb{R}^3$ [S1].
2.  **Appearance:** Spherical Harmonic (SH) coefficients $h_{i,lm}$ for $l \in [0, l_{max}]$ and $m \in [-l, l]$ [S1]. These coefficients define the view-dependent color [S1].

**Parameters:**
*   Splatting radius $r$: $0.008$ [S1].
*   Maximum number of splats considered per pixel $n$: $15$ [S1].
*   Maximum spherical harmonic degree $l_{max}$: $2$ [S1].
*   TV weight $\lambda_{TV}$: $0.01$ [S1].
*   Learning rate decay factor: $0.93$ per epoch [S1].
*   Total epochs: $20$ [S1].
*   Initial learning rates: $3 \times 10^{-3}$ for SH parameters, $8 \times 10^{-4}$ for positions [S1].

**Algorithm Steps:**

1.  **Initialization:**
    *   Initialize point positions using rejection sampling within the visual hull: uniformly sample random 3D points, project them into each input image, and keep only points that fall within all object masks [S1].
    *   Initialize SH coefficients by sampling from a normal distribution with zero mean and standard deviation of one [S1].

2.  **Rendering (Differentiable Splatting):**
    For each pixel $u$ in image $j$:
    *   Identify points $i$ with non-negligible opacity within a certain distance of $u$ [S1].
    *   Sort these points by z-distance (front-to-back) [S1].
    *   Compute opacity $\alpha^j_i(u)$ for each point using a Gaussian kernel:
        $$ \alpha^j_i(u) = \frac{1}{\sqrt{2\pi r^2}} e^{-\frac{\|p^j_i - u\|^2}{2r^2}} $$
        where $p^j_i$ is the projected position of point $i$ in image $j$ [S1].
    *   Compute the net contribution $A^j_i(u)$ of the $i$-th point:
        $$ A^j_i(u) = \alpha^j_i(u) \prod_{k=1}^{i-1} (1 - \alpha^j_k(u)) $$
        where points are sorted front-to-back [S1].
    *   Compute the per-point color $c_i$ using the SH coefficients and the view direction $v_i$ from the camera to point $i$:
        $$ c_i = \sum_{l=0}^{l_{max}} \sum_{m=-l}^{l} h_{i,lm} Y_{lm}(v_i) $$
        where $Y_{lm}$ are the spherical harmonic basis functions [S1].
    *   Compute the final pixel color $\hat{I}^j(u)$ via alpha blending:
        $$ \hat{I}^j(u) = \sum_{i=1}^{n} A^j_i(u) c_i $$
        where $n$ is the maximum number of splats considered (default 15) [S1].

3.  **Optimization:**
    *   Minimize the loss function $L$:
        $$ L = \sum_{j=1}^{N} ||I^j - \hat{I}^j||^2_2 + \lambda_{TV} TV(\hat{I}^j) $$
        where $TV(\cdot) = |\nabla_x \cdot|_1 + |\nabla_y \cdot|_1$ is the anisotropic total variation penalty [S1].
    *   Update positions and SH coefficients using stochastic gradient descent with the specified learning rates and decay [S1].

4.  **Coarse-to-Fine Updates:**
    To improve representation efficiency and avoid dense clusters, repeat the following stages twice [S1]:
    *   **Voxel-based Point Cloud Reduction:** Assume a voxel discretization [S1]. For each voxel, aggregate all points inside by averaging their position and SH coefficients into a single point [S1].
    *   **Outlier Removal:** For each point, compute the distance to its neighbors and the standard deviation of these distances [S1]. Filter out outliers whose standard deviation exceeds a threshold [S1].
    *   **Point Generation:** Insert new points by generating one new point for each existing point [S1]. Set all parameters (including position) to the average of the point’s nearest $K$ neighbors [S1].

5.  **Refinement:**
    *   Fine-tune the model with half of the original learning rate [S1].

**Pseudocode:**

import numpy as np

def project_points(points, K, R, t):
    """Perspective projection of 3D points to 2D image coordinates."""
    p_cam = (R @ points.T).T + t
    p_proj = (K @ p_cam.T).T
    return p_proj[:, :2] / p_proj[:, 2:3]

def compute_view_directions(points, cam_origin):

    dirs = points - cam_origin
    return dirs / np.linalg.norm(dirs, axis=1, keepdims=True)

def compute_sh_color(h_coeffs, v):

    return np.dot(h_coeffs, basis)

def render_splats(points, h_coeffs, K, R, t, cam_origin, image_shape, r=0.008, n_max=15):
    """Differentiable splat rendering."""
    height, width = image_shape
    image = np.zeros((height, width, 3))
    p_proj = project_points(points, K, R, t)
    v = compute_view_directions(points, cam_origin)
    colors = compute_sh_color(h_coeffs, v)
    z_depth = (R @ points.T).T[:, 2] + t[2]

    for u_y in range(height):
        for u_x in range(width):
            u = np.array([u_x, u_y])
            dists = np.linalg.norm(p_proj - u, axis=1)
            opacities = (1.0 / np.sqrt(2 * np.pi * r**2)) * np.exp(-dists**2 / (2 * r**2))
            valid_indices = np.where(opacities > 1e-6)[0]
            valid_indices = valid_indices[np.argsort(z_depth[valid_indices])]
            valid_indices = valid_indices[:n_max]

            transmittance = 1.0
            pixel_color = np.zeros(3)
            for i in valid_indices:
                alpha_i = opacities[i]
                A_i = alpha_i * transmittance
                pixel_color += A_i * colors[i]
                transmittance *= (1.0 - alpha_i)
            image[u_y, u_x] = pixel_color
    return image

def coarse_to_fine_update(points, h_coeffs, voxel_size=0.01, neighbor_k=5, threshold=2.0):
    """Coarse-to-fine point cloud optimization stages [S1]."""
    # Stage 1: Voxel-based Point Cloud Reduction
    voxel_grid = np.floor(points / voxel_size).astype(int)
    unique_voxels, inverse = np.unique(voxel_grid, axis=0, return_inverse=True)
    new_points = np.zeros_like(points)
    new_h_coeffs = np.zeros_like(h_coeffs)
    for idx, voxel in enumerate(unique_voxels):
        mask = inverse == idx
        new_points[voxel[0], voxel[1], voxel[2]] = np.mean(points[mask], axis=0)
        new_h_coeffs[voxel[0], voxel[1], voxel[2]] = np.mean(h_coeffs[mask], axis=0)
    points = new_points.reshape(-1, 3)
    h_coeffs = new_h_coeffs.reshape(-1, h_coeffs.shape[1])

    # Stage 2: Outlier Removal
    dists = np.linalg.norm(points[:, None, :] - points[None, :, :], axis=2)
    std_dists = np.std(np.sort(dists, axis=1)[:, 1:neighbor_k+1], axis=1)
    mask = std_dists < threshold
    points = points[mask]
    h_coeffs = h_coeffs[mask]

    # Stage 3: Point Generation
    new_points = np.mean(points[np.argsort(dists[:, 1:neighbor_k+1])], axis=1)
    new_h_coeffs = np.mean(h_coeffs[np.argsort(dists[:, 1:neighbor_k+1])], axis=1)
    points = np.vstack([points, new_points])
    h_coeffs = np.vstack([h_coeffs, new_h_coeffs])
    return points, h_coeffs

def train_dpbf(images, masks, camera_params, num_points=10000, epochs=20, lr_sh=3e-3, lr_pos=8e-4, decay=0.93, lambda_tv=0.01):

    # Initialization via rejection sampling within visual hull [S1]
    points = np.random.uniform(-1, 1, (num_points, 3))
    h_coeffs = np.random.normal(0, 1, (num_points, 9))

    for epoch in range(epochs):
        rendered_images = [render_splats(points, h_coeffs, **cp, image_shape=img.shape) for img, cp in zip(images, camera_params)]
        loss = sum(np.mean((img - rend)**2) + lambda_tv * np.sum(np.abs(np.diff(rend, axis=0))) + np.sum(np.abs(np.diff(rend, axis=1))) for img, rend in zip(images, rendered_images))
        # Gradients computed via automatic differentiation [G]

        points -= lr_pos * grad_points
        h_coeffs -= lr_sh * grad_h_coeffs
        lr_pos *= decay
        lr_sh *= decay
        points, h_coeffs = coarse_to_fine_update(points, h_coeffs)

    # Refinement step with half learning rate [S1]
    lr_pos /= 2
    lr_sh /= 2
    for _ in range(5):
        rendered_images = [render_splats(points, h_coeffs, **cp, image_shape=img.shape) for img, cp in zip(images, camera_params)]
        loss = sum(np.mean((img - rend)**2) + lambda_tv * np.sum(np.abs(np.diff(rend, axis=0))) + np.sum(np.abs(np.diff(rend, axis=1))) for img, rend in zip(images, rendered_images))
        grad_points, grad_h_coeffs = autograd(loss, points, h_coeffs)
        points -= lr_pos * grad_points
        h_coeffs -= lr_sh * grad_h_coeffs
    return points, h_coeffs

## Subtopics

### [Pulsar Sphere-based Neural Rendering](9397-pulsar-sphere-based-neural-rendering.md)
Pulsar is an efficient, sphere-based differentiable renderer that maps a 3D scene representation of spheres to a feature image, enabling end-to-end optimization of scene geometry, features, and camera parameters. It solves the problem of slow rendering and topological inconsistencies inherent in mesh-based or voxel-based neural rendering by using a sparse, explicit sphere representation that naturally culls empty space without acceleration structures. Unlike its siblings, Pulsar parallelizes over pixels rather than spheres to avoid synchronization overhead, and it decouples geometry projection from appearance via a neural shading network, allowing unlimited spheres to contribute to color while restricting gradient propagation to the first few spheres to avoid high-frequency artifacts.

## Operating characteristics
*   **Time Complexity:** Rendering is a single forward pass via splatting, avoiding volumetric ray marching [S1]. Training is significantly faster than NeRF-based methods [S1].
*   **Memory Complexity:** Less than 10 MB for a static scene [S1].
*   **Performance:** On novel video view synthesis, achieves 34.6 dB PSNR in 30 min training and 40 ms inference, compared to STNeRF's 32.1 dB in 50 h training and 30 s inference [S1]. Training is up to 300x faster than NeRF [S1]. Rendering is approximately 400x faster than Point-NeRF [S1].
*   **Strengths:** High efficiency in training and inference, low memory footprint, no need for additional learned or explicit priors [S1].
*   **Limitations:** Requires object masks for initialization, limiting it to foreground scene components [S1]. Cannot handle semi-transparent objects (e.g., fur) due to the splatting representation [S1]. Quality may be slightly lower than NeRF when many input views are provided [S1].

## Background
DPBF was introduced by Qiang Zhang at Princeton University in 2022 [S1]. It was presented at the ACM SIGGRAPH Asia 2022 conference [S1]. The method builds on the idea of using point clouds for scene representation, departing from volumetric representations to improve efficiency [S1]. It addresses limitations of previous point-based methods like Kopanas et al. [2021] and Lassner et al. [2021], which required long training times or large storage [S1].
