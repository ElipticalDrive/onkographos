# Deferred Lighting Resolve

Also called: Final Pass, Lighting Pass

## Overview
Deferred Lighting Resolve is the final shading pass in a deferred surface splatting pipeline. It reconstructs the final pixel color by applying a lighting model (ambient, diffuse, specular) to the weighted color and surface normals accumulated in the G-buffers during the splatting phase. It differs from forward rendering by decoupling the geometric projection (splatting) from the lighting calculation, allowing multiple light sources to be applied efficiently in screen space without re-projecting geometry.

## How it works
**Inputs:**
- G-Buffer textures:
  - `g_colors`: RGBA texture storing the weighted sum of splat colors. Layout: `vec4` per pixel.
  - `g_normals`: RGBA texture storing the accumulated surface normals. Layout: `vec4` per pixel (XYZ is normal, W is unused or weight).
- Uniforms/Constants:
  - `light_dir_view_spc`: View-space light direction vector.
  - `light_color`: Light color vector (RGB).
  - `ambient_strength`: Scalar for ambient intensity.
  - `specular_strength`: Scalar for specular intensity.
  - `g_depth`: Depth texture (optional, for depth testing in the resolve pass, though often skipped if splatting handled depth).

**Outputs:**
- Final color buffer (RGBA).

**Data Structures:**
- The G-buffers are 2D textures of size $W \times H$ (screen resolution).
- `g_colors` uses `GL_RGBA32F` (or equivalent) to store floating-point weighted color sums.
- `g_normals` uses `GL_RGBA32F` to store normalized or unnormalized normal vectors.

**Steps:**
1. **Sample Weighted Color:** Read the color and weight from the color G-buffer at the current fragment's texture coordinates.
   $$ C_{weighted} = \text{texture}(g\_colors, uv) $$
2. **Discard Empty Pixels:** If the accumulated weight ($C_{weighted}.a$) is zero or negative, discard the fragment to avoid division by zero or NaN results.
   $$ \text{if } C_{weighted}.a \le 0.0 \text{ then discard} $$
3. **Normalize Color:** Compute the final base color by dividing the weighted color RGB by the weight.
   $$ C_{base} = \frac{C_{weighted}.rgb}{C_{weighted}.a} $$
4. **Sample and Normalize Normal:** Read the normal from the normal G-buffer and normalize it.
   $$ N = \text{normalize}(\text{texture}(g\_normals, uv).xyz) $$
5. **Normalize Light Direction:** Ensure the light direction vector is normalized.
   $$ L = \text{normalize}(light\_dir\_view\_spc) $$
6. **Calculate Ambient Lighting:**
   $$ C_{ambient} = ambient\_strength \times light\_color $$
7. **Calculate Diffuse Lighting:**
   $$ C_{diffuse} = \max(-\text{dot}(N, L), 0.0) \times light\_color $$
   *Note: The negative sign in the dot product assumes $L$ points from the surface to the light source (view-space direction). If $L$ points from light to surface, use $\max(\text{dot}(N, L), 0.0)$.*
8. **Calculate Specular Lighting:**
   - Compute the reflection vector of the light direction about the normal.
     $$ R = \text{reflect}(L, N) $$
   - In view space, the view direction is typically $(0, 0, -1)$. The specular effect is calculated using the Z-component of the reflection vector (assuming standard view space where camera looks down -Z).
     $$ S_{effect} = \max(R.z, 0.0)^{shininess} $$
     *Note: The source uses a fixed shininess of 32.*
   - Compute specular color.
     $$ C_{specular} = specular\_strength \times S_{effect} \times light\_color $$
9. **Combine Lighting:**
   $$ C_{final} = (C_{ambient} + C_{diffuse} + C_{specular}) \times C_{base} $$
10. **Output:** Write the final color to the framebuffer.
    $$ FragColor = vec4(C_{final}, 1.0) $$

**Pseudocode:**
```python
# Fragment Shader Logic for Deferred Lighting Resolve
# Inputs: uv (texture coordinates), g_colors, g_normals
# Uniforms: light_dir_view_spc, light_color, ambient_strength, specular_strength

vec4 color_weighted = texture(g_colors, uv);

# Step 2: Discard if no splat covered this pixel
if (color_weighted.a <= 0.0) {
    discard;
}

# Step 3: Normalize color by weight
vec3 color = color_weighted.rgb / color_weighted.a;

# Step 4: Sample and normalize normal
vec3 normal = normalize(texture(g_normals, uv).xyz);

# Step 5: Normalize light direction
vec3 light_dir = normalize(light_dir_view_spc);

# Step 6: Ambient
vec3 ambient = ambient_strength * light_color;

# Step 7: Diffuse
# Note: Source uses -dot(normal, light_dir), implying light_dir points away from surface
float diff_val = max(-dot(normal, light_dir), 0.0);
vec3 diffuse = diff_val * light_color;

# Step 8: Specular
vec3 reflection = reflect(light_dir, normal);
# View direction in view space is (0,0,-1). 
# Reflection vector Z component relative to view direction.
# Source uses pow(max(reflection.z, 0.0), 32)
float specular_effect = pow(max(reflection.z, 0.0), 32.0);
vec3 specular = specular_strength * specular_effect * light_color;

# Step 9: Combine
vec3 result = (ambient + diffuse + specular) * color;

# Step 10: Output
FragColor = vec4(result, 1.0);
```

**Parameters:**
- `ambient_strength`: Default 0.5 [S1].
- `specular_strength`: Default 0.2 [S1].
- `light_color`: Default (1.0, 1.0, 1.0) [S1].
- `shininess`: Fixed at 32 in the reference implementation [S1].

**Edge Cases and Pitfalls:**
- **Division by Zero:** If a pixel is not covered by any splat, the weight in `g_colors` is 0. Dividing by this weight results in NaN. The discard step (Step 2) prevents this.
- **Light Direction Convention:** The source code uses `max(-dot(normal, light_dir), 0.0)` for diffuse. This implies `light_dir` is the vector from the surface to the light. If the light direction is provided as light-to-surface, the sign must be adjusted.
- **View Space Assumption:** The specular calculation assumes the camera is at the origin looking down the negative Z-axis in view space. If the view matrix is not identity or the coordinate system differs, the view direction vector must be computed explicitly.

## Subtopics

### EWA Filter Approximation
An approximation to the original Elliptical Weighted Average (EWA) filter used in the deferred shading pipeline to apply a bandlimiting prefilter. This approximation is used to improve performance or simplify the filtering logic in the GPU implementation. It is controlled by a boolean flag `m_ewa_filter` to enable or disable the approximation [S2].

## Operating characteristics
- **Time Complexity:** $O(1)$ per pixel for the resolve pass, as it involves a fixed number of texture samples and arithmetic operations.
- **Memory Complexity:** $O(W \times H)$ for the G-buffers (depth, color, normal).
- **Performance:** The resolve pass is lightweight compared to the splatting pass. The reference implementation was tested on an NVIDIA GTX 1080 Ti [S2].
- **Strengths:** Efficient handling of multiple light sources; decoupling of geometry and lighting.
- **Limitations:** Requires G-buffer storage; potential for aliasing if splatting resolution is low; dependent on the quality of the normal accumulation in the splatting pass.

## Background
Deferred Lighting Resolve is part of the Surface Splatting technique, specifically the deferred shading pipeline component. It builds on the GPU accelerated surface splatting approach by Botsch et al. [S2]. The method is implemented in various open-source point cloud rendering projects, such as `sebastianlipponer/surface_splatting` and `arminkz/PointCloudRendering` [S1, S2].
