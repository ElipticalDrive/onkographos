# Flash3D

Also called: Flash3D

## Overview
Flash3D is a feed-forward network (FFN) method for monocular 3D Gaussian Splatting (3DGS) reconstruction [S1][S2, unofficial]. It addresses the challenge of generating 3DGS scenes from a single view by estimating depth and directly predicting Gaussian parameters [S1][S2, unofficial]. It is distinguished from sibling methods like PixelSplat and GS-LRM by its reliance on a single image input and depth estimation, whereas PixelSplat uses epipolar transformers for two views and GS-LRM tokenizes multiple images [S1][S2, unofficial].

## How it works
Flash3D employs a feed-forward network to directly predict 3D Gaussian parameters from a single input image [S1][S2, unofficial]. The network is supervised by photometric losses such as LPIPS, SSIM, or similar metrics [S1][S2, unofficial]. The core mechanism involves estimating depth from the single view to generate the 3DGS scene [S1][S2, unofficial].

Inputs:
- A single monocular image.

Outputs:
- A set of 3D Gaussian parameters (position, covariance, color, opacity) constituting the scene.

Numbered Steps:
1. Input a single image into the feed-forward network [S1][S2, unofficial].
2. The network estimates depth from the single view [S1][S2, unofficial].
3. The network generates 3D Gaussian Splatting (3DGS) scenes by predicting Gaussian parameters based on the estimated depth [S1][S2, unofficial].
4. The output is supervised by photometric losses (LPIPS, SSIM, or similar) during training [S1][S2, unofficial].

## Subtopics

### [GS-LRM](1483-gs-lrm.md)
Tokenizes two to four images and camera parameters, passing them through a transformer block. Choose when multi-view input is available.

### [PixelSplat](1485-pixelsplat.md)
Uses an epipolar transformer to generalize features between two views and predicts Gaussians along camera-to-pixel rays. Choose when stereo pairs are available.

### [Large Reconstruction Model (LRM)](5959-large-reconstruction-model-lrm.md)
Tokenizes multiple images and camera parameters through a transformer block. Choose when multi-view consistency is prioritized.

## Background
Flash3D was proposed to address the challenge of generating 3DGS scenes from a single view by using a feed-forward network [S1][S2, unofficial]. It is part of a broader trend of training FFNs to directly predict 3D Gaussian parameters, supervised by photometric losses [S1][S2, unofficial]. The method is cited in the context of monocular reconstruction alongside other FFN-based approaches [S1][S2, unofficial].
