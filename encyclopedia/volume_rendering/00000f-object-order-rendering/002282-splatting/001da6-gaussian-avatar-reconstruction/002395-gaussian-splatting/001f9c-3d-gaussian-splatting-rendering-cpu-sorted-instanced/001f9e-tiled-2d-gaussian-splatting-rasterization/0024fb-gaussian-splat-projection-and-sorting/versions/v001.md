# Gaussian Splat Projection and Sorting


## Overview
This method is a compute-shader-based stage that projects 3D Gaussians to 2D screen space, performs visibility and frustum culling, computes lighting, and prepares data for tile-based sorting. It serves as the bridge between raw 3D Gaussian data and the tiled rasterization pipeline, ensuring that only visible splats are processed and that they are ordered by tile and depth for efficient rendering. It differs from non-tiled approaches by explicitly preparing tile-boundary data and from tile-based culling by handling the full projection and sorting key generation.

## How it works
**Inputs:**
- `SplatsBuffer`: `std430` buffer of `Splat` structs.
- `InstanceTransformsBuffer`: `std430` buffer of `mat4` instance model matrices.
- `SplatInstanceIdsBuffer`: `std430` buffer of `uvec2` where `x` is the unique instance ID and `y` is the index into `SplatsBuffer`.
- `Uniforms`: `std140` uniform block containing `camera_pos`, `time`, `dims` (image resolution), `point_count`, and `light_count`.
- `LightRigBuffer`: `std430` buffer of `vec4` light data.
- `SplatLightingBuffer`: `std430` buffer of `uint` packed lighting data.
- `InstanceRelightBuffer`: `std430` buffer of `vec4` per-instance relighting data.
- `GridDimensionsBuffer`: `std430` buffer storing grid dimensions.

**Outputs:**
- `CulledBuffer`: `std430` buffer of `RasterizeData` structs for visible splats.
- `SortKeysBuffer`: `std430` buffer of `uint` keys for sorting.
- `SortValuesBuffer`: `std430` buffer of `uint` values (splat indices) for sorting.
- `Histograms`: `std430` buffer containing `sort_buffer_size` and histogram data.

**Data Structures:**

```glsl
struct Splat {
    vec3 position;
    float time;
    float covariance[6]; // Top triangle of symmetric 3x3 matrix
    float opacity;
    float _pad;
    float sh_coefficients[16*3]; // Spherical harmonic coefficients
};

struct RasterizeData {
    vec2 image_pos;
    vec2 pos_xy;
    vec3 conic;
    float pos_z;
    vec4 color;
    vec4 depth_data;
};
```

**Constants:**
- `TILE_SIZE`: 16
- `SH_C0` to `SH_C3_6`: Spherical harmonic constants (see [S1, unofficial]).
- `DECODE_COVARIANCE(c)`: Macro to construct `mat3` from `covariance[6]`.

**Algorithm:**

1.  **Initialization:** Get global invocation ID `id`. If `id >= point_count`, return.
2.  **Barrier:** Synchronize workgroup.
3.  **Retrieve Instance Data:** `instance_id = splat_instance_data[id].x`, `unique_splat_index = splat_instance_data[id].y`.
4.  **Load Data:** Load `splat` from `splat_buffer[unique_splat_index]` and `model_matrix` from `instance_model_matrices[instance_id]`.
5.  **Visibility Check:** If `model_matrix[0][3] < 0.5`, return. Set `model_matrix[0][3] = 0.0`.
6.  **Frustum Culling:**
    -   Compute `object_linear` from `model_matrix`.
    -   Compute `world_covariance = object_linear * DECODE_COVARIANCE(splat.covariance) * transpose(object_linear)`.
    -   Compute `world_pos = model_matrix * vec4(splat.position, 1.0)`.
    -   Compute `view_pos = view_matrix * world_pos`.
    -   Compute `clip_pos = projection_matrix * view_pos`.
    -   Check bounds: If any component of `clip_pos.xyz` is less than `vec3(-view_bounds, 0.0)` or greater than `vec3(view_bounds, clip_pos.w)`, return. `view_bounds = clip_pos.w * 1.2`.
7.  **Time Animation:**
    -   `splat_time = time - splat.time`.
    -   `time_factor = ease_out_cubic(clamp(splat_time, 0, 1))`.
    -   `time_factor_late = ease_out_cubic(clamp(splat_time - 0.35, 0, 1))`.
    -   `splat_opacity = splat.opacity * time_factor_late * time_factor_late`.
    -   `splat_scale = mix(2.0, 1.0, time_factor_late)`.
    -   `ease_out_cubic(x) = 1.0 - pow(1.0 - x, 3.0)`.
8.  **Project Covariance:**
    -   Call `project_covariance(world_covariance, splat_scale, view_pos.xyz, dims)`.
    -   Inside `project_covariance`:
        -   `cov_3d = covariance_3d * scale_modifier^2`.
        -   `tan_fov_inv = vec2(projection_matrix[0][0], projection_matrix[1][1])`.
        -   `focal = (dims - 1) * 0.5 * tan_fov_inv * (-1.0 / mean.z)`.
        -   `mean.xy = clamp(mean.xy * (-1.0 / mean.z), -tan_fov * 1.3, tan_fov * 1.3)`.
        -   `jacobian = mat3(focal.x, 0, 0, 0, focal.y, 0, focal.x * mean.x, focal.y * mean.y, 0)`.
        -   `screen_transform = jacobian * view_linear`.
        -   `cov_2d = screen_transform * cov_3d * transpose(screen_transform)`.
    -   Return `vec3(cov_2d[0][0] + 0.3, cov_2d[0][1], cov_2d[1][1] + 0.3)`.
9.  **Check Determinant:** `det = covariance.x * covariance.z - covariance.y * covariance.y`. If `det == 0.0`, return.
10. **Compute Eigenvalues:**
    -   `mid = 0.5 * (covariance.x + covariance.z)`.
    -   `eigenvalues = mid + vec2(1, -1) * sqrt(max(0.1, mid * mid - det))`.
    -   If any `eigenvalues < 0`, return.
11. **Compute Image Position:**
    -   `ndc_pos = clip_pos.xyz / clip_pos.w`.
    -   `image_pos = ((ndc_pos.xy + 1.0) * 0.5 - vec2(1, 0.75) * (1.0 - time_factor)) * (dims - 1)`.
12. **Compute Radius:** `radius = pow(splat_opacity, 0.2) * 2.5 * sqrt(max(eigenvalues.x, eigenvalues.y))`.
13. **Compute Tile Bounds:**
    -   `grid_size = (dims + TILE_SIZE - 1) / TILE_SIZE`.
    -   `rect_bounds = get_rect(image_pos, radius, grid_size)`.
    -   `get_rect` returns `uvec4(clamp((image_pos - radius) / TILE_SIZE, vec2(0), grid_size), clamp(ceil((image_pos + radius) / TILE_SIZE), vec2(0), grid_size))`.
14. **Check Tile Count:** `num_tiles_touched = (rect_bounds.z - rect_bounds.x) * (rect_bounds.w - rect_bounds.y)`. If `num_tiles_touched == 0`, return.
15. **Atomic Add:** `buffer_size = atomicAdd(sort_buffer_size, num_tiles_touched)`. `sort_buffer_offset = buffer_size`.
16. **Compute View Direction:** `view_dir = normalize(inverse(object_linear) * (world_pos.xyz - camera_pos))`.
17. **Compute Base Color:** `base_color = get_color(view_dir, splat.sh_coefficients)`.
    -   `get_color` evaluates SH up to degree 3 using constants `SH_C0`..`SH_C3_6` and coefficients from `splat.sh_coefficients`.
18. **Relighting:**
    -   `relight = instance_relight[instance_id * 2]`.
    -   If `relight.w > 0.5`:
        -   If `relight.z > 0.5`, `base_color = max(0.0, 0.5 + splat.sh_coefficients[0..2] * SH_C0)`.
        -   Else, `base_color *= relight_factor(unique_splat_index, world_pos.xyz, object_linear, relight.x, relight.y, instance_relight[instance_id * 2 + 1].rgb)`.
19. **Fill RasterizeData:**
    -   `data.image_pos = image_pos`.
    -   `data.conic = vec3(covariance.z, -covariance.y, covariance.x) / det`.
    -   `data.color = vec4(base_color, splat_opacity)`.
    -   `data.pos_xy = world_pos.xy`.
    -   `data.pos_z = world_pos.z`.
    -   `data.depth_data = vec4(-view_pos.z, 0, 0, 0)`.
    -   Write to `culled_buffer[id]`.
20. **Gaussian Duplication/Sorting Preparation:**
    -   `view_depth = max(0.0, clip_pos.w)`.
    -   `depth01 = view_depth / (1.0 + view_depth)`.
    -   `depth = uint(depth01 * 65535.0) & 0xFFFF`.
    -   Loop `y` from `rect_bounds.y` to `rect_bounds.w`, `x` from `rect_bounds.x` to `rect_bounds.z`:
        -   `tile_id = y * grid_size.x + x`.
        -   `key = (tile_id << 16) | depth`.
        -   `sort_keys[sort_buffer_offset] = key`.
        -   `sort_values[sort_buffer_offset] = id`.
        -   `sort_buffer_offset++`.

**Pseudocode:**

```python
def gsplat_projection(id, point_count, splat_buffer, instance_model_matrices, splat_instance_data, 
                      camera_pos, time, dims, projection_matrix, view_matrix, instance_relight, 
                      sort_buffer_size, sort_keys, sort_values, culled_buffer, grid_dims):
    if id >= point_count:
        return

    # Barrier implied in compute shader

    instance_id = splat_instance_data[id].x
    unique_splat_index = splat_instance_data[id].y

    splat = splat_buffer[unique_splat_index]
    model_matrix = instance_model_matrices[instance_id]

    # Visibility check
    if model_matrix[0][3] < 0.5:
        return
    model_matrix[0][3] = 0.0

    # Frustum culling
    object_linear = model_matrix[:3, :3]
    world_covariance = object_linear @ decode_covariance(splat.covariance) @ object_linear.T
    world_pos = model_matrix @ vec4(splat.position, 1.0)
    view_pos = view_matrix @ world_pos
    clip_pos = projection_matrix @ view_pos

    view_bounds = clip_pos.w * 1.2
    if any(clip_pos.xyz < vec3(-view_bounds, 0.0)) or any(clip_pos.xyz > vec3(view_bounds, clip_pos.w)):
        return

    # Time animation
    splat_time = time - splat.time
    time_factor = ease_out_cubic(clamp(splat_time, 0, 1))
    time_factor_late = ease_out_cubic(clamp(splat_time - 0.35, 0, 1))
    splat_opacity = splat.opacity * time_factor_late * time_factor_late
    splat_scale = mix(2.0, 1.0, time_factor_late)

    # Project covariance
    cov_2d = project_covariance(world_covariance, splat_scale, view_pos.xyz, dims)
    covariance = vec3(cov_2d[0][0] + 0.3, cov_2d[0][1], cov_2d[1][1] + 0.3)

    # Check determinant
    det = covariance.x * covariance.z - covariance.y * covariance.y
    if det == 0.0:
        return

    # Compute eigenvalues
    mid = 0.5 * (covariance.x + covariance.z)
    eigenvalues = mid + vec2(1, -1) * sqrt(max(0.1, mid * mid - det))
    if any(eigenvalues < 0):
        return

    # Compute image position
    ndc_pos = clip_pos.xyz / clip_pos.w
    image_pos = ((ndc_pos.xy + 1.0) * 0.5 - vec2(1, 0.75) * (1.0 - time_factor)) * (dims - 1)

    # Compute radius
    radius = pow(splat_opacity, 0.2) * 2.5 * sqrt(max(eigenvalues.x, eigenvalues.y))

    # Compute tile bounds
    grid_size = (dims + TILE_SIZE - 1) / TILE_SIZE
    rect_bounds = get_rect(image_pos, radius, grid_size)

    # Check tile count
    num_tiles_touched = (rect_bounds.z - rect_bounds.x) * (rect_bounds.w - rect_bounds.y)
    if num_tiles_touched == 0:
        return

    # Atomic add
    buffer_size = atomic_add(sort_buffer_size, num_tiles_touched)
    sort_buffer_offset = buffer_size

    # Compute view direction
    view_dir = normalize(inverse(object_linear) @ (world_pos.xyz - camera_pos))

    # Compute base color
    base_color = get_color(view_dir, splat.sh_coefficients)

    # Relighting
    relight = instance_relight[instance_id * 2]
    if relight.w > 0.5:
        if relight.z > 0.5:
            base_color = max(0.0, 0.5 + splat.sh_coefficients[0:3] * SH_C0)
        else:
            base_color *= relight_factor(unique_splat_index, world_pos.xyz, object_linear, relight.x, relight.y, instance_relight[instance_id * 2 + 1].rgb)

    # Fill RasterizeData
    data = RasterizeData()
    data.image_pos = image_pos
    data.conic = vec3(covariance.z, -covariance.y, covariance.x) / det
    data.color = vec4(base_color, splat_opacity)
    data.pos_xy = world_pos.xy
    data.pos_z = world_pos.z
    data.depth_data = vec4(-view_pos.z, 0, 0, 0)
    culled_buffer[id] = data

    # Gaussian duplication/sorting preparation
    view_depth = max(0.0, clip_pos.w)
    depth01 = view_depth / (1.0 + view_depth)
    depth = uint(depth01 * 65535.0) & 0xFFFF

    for y in range(rect_bounds.y, rect_bounds.w):
        for x in range(rect_bounds.x, rect_bounds.z):
            tile_id = y * grid_size.x + x
            key = (tile_id << 16) | depth
            sort_keys[sort_buffer_offset] = key
            sort_values[sort_buffer_offset] = id
            sort_buffer_offset += 1

def decode_covariance(cov):
    return mat3(cov[0], cov[1], cov[2], cov[1], cov[3], cov[4], cov[2], cov[4], cov[5])

def project_covariance(covariance_3d, scale, mean, dims):
    cov_3d = covariance_3d * scale * scale
    tan_fov_inv = vec2(projection_matrix[0][0], projection_matrix[1][1])
    focal = (dims - 1) * 0.5 * tan_fov_inv * (-1.0 / mean.z)
    mean_xy = clamp(mean.xy * (-1.0 / mean.z), -tan_fov * 1.3, tan_fov * 1.3)
    jacobian = mat3(focal.x, 0, 0, 0, focal.y, 0, focal.x * mean_xy.x, focal.y * mean_xy.y, 0)
    screen_transform = jacobian @ view_linear
    cov_2d = screen_transform @ cov_3d @ screen_transform.T
    return vec3(cov_2d[0][0] + 0.3, cov_2d[0][1], cov_2d[1][1] + 0.3)
```

**Parameters:**
- `TILE_SIZE`: 16. Used to partition the screen into tiles for sorting.
- `SH_C0` to `SH_C3_6`: Spherical harmonic constants.

**Edge Cases and Pitfalls:**
- **Precision:** Depth quantization uses 16 bits (`depth01 * 65535.0`). This may cause sorting artifacts for very distant or very close splats if not handled by the rasterizer.
- **Boundaries:** Frustum culling uses a 1.2x margin (`view_bounds = clip_pos.w * 1.2`). This may include some splats that are technically outside the canonical view volume but are close to the edge.
- **Degenerate Input:** If `det == 0` or eigenvalues are negative, the splat is discarded. This handles degenerate Gaussians.

## Operating characteristics
- **Time Complexity:** O(N) where N is the number of points. Each point is processed once, but may be duplicated into the sort buffer if it touches multiple tiles.
- **Memory Complexity:** O(N + T) where T is the number of tiles touched. The `CulledBuffer` stores one entry per point, and `SortKeysBuffer`/`SortValuesBuffer` store one entry per tile touched.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of points and tiles.
- **Strengths:** Efficient culling and sorting preparation. Handles animation and lighting.
- **Limitations:** Requires a subsequent sorting step. The depth quantization may affect sorting accuracy.
- **When to use:** When using tiled rasterization for 3D Gaussian Splatting.
- **When not to use:** When using non-tiled rasterization or when sorting is handled differently.
