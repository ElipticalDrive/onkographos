# Tiled 2D Gaussian Splatting Rasterization


## Overview
Tiled 2D Gaussian Splatting Rasterization is a GPU-parallel rendering method for 3D Gaussian Splatting that divides the image into fixed-size tiles to manage memory and processing load, assigning Gaussians to tiles based on their axis-aligned bounding boxes (AABBs) [S1, unofficial]. It solves the performance bottleneck of sorting millions of splats per pixel by grouping work into tiles, enabling real-time rendering [S1, unofficial][S2]. Unlike non-tiled approaches that iterate over all Gaussians per pixel or use screen-space quads without tiling, this method restricts pixel iteration to relevant Gaussians within each tile, significantly reducing redundant computations [S1, unofficial].

## How it works
**Inputs:**
- `gs`: A collection of $N$ 3D Gaussians, each defined by a mean position $\mu \in \mathbb{R}^3$, a $3 \times 3$ covariance matrix $\Sigma \in \mathbb{R}^{3 \times 3}$, an opacity $\alpha \in [0, 1]$, and spherical harmonic coefficients for color [G].
- `camera`: A pinhole camera model with focal lengths $f_x, f_y$, principal point $(c_x, c_y)$, image dimensions $W \times H$, and extrinsic parameters (rotation $R \in SO(3)$, translation $t \in \mathbb{R}^3$) [G].
- `tile_size`: Integer, default 32 [S1, unofficial].
- `sigma_multiplier`: Float, default 3.0 (or 3.33 in some implementations) [S1, unofficial]. Controls the extent of the Gaussian's bounding box [S1, unofficial].

**Outputs:**
- `color`: A tensor of shape $[3, H, W]$ containing the final RGB image [S1, unofficial].
- `alpha`: A tensor of shape $[H, W]$ containing the accumulated alpha values [S1, unofficial].

**Data Structures:**
- `tile_dict`: A mapping from tile index $(u, v)$ to a list of Gaussian indices assigned to that tile [S1, unofficial].
- `conics`: A tensor of shape $[N, 3]$ storing the inverse 2D covariance matrix elements $a, b, c$ for each Gaussian [S1, unofficial].

**Steps:**
1. Initialize background color tensor `bg` of shape $[3, H, W]$ with black values (0.0) and clone it [S1, unofficial].
2. Transform Gaussian means to camera space using `camera.transform_points_world_to_cam` and project to image plane using `camera.project_points_cam_to_image_plane` [S1, unofficial].
3. Perform frustum culling with `cull_near_far_planes=True`, `cull_image_bounds=False`, and `fov_margin_ratio=0.3` [S1, unofficial].
4. Sort Gaussians by depth of means back-to-front (`back_to_front=False`) [S1, unofficial].
5. Rotate 3D covariances to camera space using `camera.rotate_covariances_world_to_cam` [S1, unofficial].
6. Approximate 2D covariances using `approximate_2d_covariances` with `eps_2d=0.3` [S1, unofficial].
7. Compute conics (inverse covariance matrices) using `compute_conics(covariances_image)` [S1, unofficial].
8. Compute axis-aligned bounding boxes using `compute_axis_aligned_bounding_box` with `use_simple_radius=True` [S1, unofficial].
9. Assign Gaussians to tiles using `assign_gaussians_to_tiles` based on bounding boxes and `tile_size` [S1, unofficial].
10. Evaluate spherical harmonics colors using `eval_spherical_harmonics_color` with `degree=gs.sh_degree` [S1, unofficial].
11. Initialize output color tensor `color` of shape $[3, H, W]$ and alpha tensor `alpha` of shape $[H, W]$ to zeros [S1, unofficial].
12. Iterate over each tile `(tile_idx_u, tile_idx_v)` in `tile_dict`. If no Gaussians are in the tile, continue [S1, unofficial].
13. Extract contiguous tensors for the tile: `opacities_tile`, `sh_colors_tile`, `means_image_tile`, `conics_tile` indexed by `idx_gaussians_in_tile` [S1, unofficial].
14. Calculate pixel bounds for the tile: $u_{start} = tile\_idx\_u \times tile\_size$, $v_{start} = tile\_idx\_v \times tile\_size$, $u_{end} = \min(u_{start} + tile\_size, W)$, $v_{end} = \min(v_{start} + tile\_size, H)$ [S1, unofficial].
15. Iterate over pixels $u_{pix}$ from $u_{start}$ to $u_{end}$ and $v_{pix}$ from $v_{start}$ to $v_{end}$ [S1, unofficial].
16. For each pixel, iterate over Gaussians in the tile. If `alpha[v_pix, u_pix] >= 0.99`, skip the Gaussian (early termination) [S1, unofficial].
17. Retrieve Gaussian properties: `opacity_gaussian`, `sh_color`, `a, b, c` from `conics_tile`, and `u_mean, v_mean` from `means_image_tile` [S1, unofficial].
18. Compute squared Mahalanobis distance: $dist\_sq = a \cdot du^2 + 2 \cdot b \cdot du \cdot dv + c \cdot dv^2$, where $du = u_{pix} - u_{mean}$ and $dv = v_{pix} - v_{mean}$ [S1, unofficial].
19. Accumulate alpha and color: `alpha[v_pix, u_pix] += opacity_gaussian * exp(-0.5 * dist_sq)` and `color[:, v_pix, u_pix] += sh_color * opacity_gaussian * exp(-0.5 * dist_sq)` [S1, unofficial].
20. After processing all tiles, add background: `color += bg * (1 - alpha)[None, :, :]` [S1, unofficial].
21. Clamp color to $[0.0, 1.0]$ and convert to uint8 by multiplying by 255 [S1, unofficial].

**Pseudocode:**
```python
import torch
import math

def tiled_2d_gaussian_splatting_rasterization(gs_means, gs_covs, gs_opacities, gs_sh_coeffs, camera, tile_size=32, sigma_multiplier=3.0):
    N = gs_means.shape[0]
    H, W = camera.height, camera.width
    eps_2d = 0.3
    bg = torch.zeros((3, H, W))

    # 1. Transform to Camera Space
    R = quaternion_to_rotation_matrix(camera.q_world_to_cam)
    means_cam = (R @ gs_means.T).T + camera.t_world_to_cam

    # 2. Project to Image Plane
    z_cam = means_cam[:, 2]
    u = camera.fx * (means_cam[:, 0] / z_cam) + camera.cx
    v = camera.fy * (means_cam[:, 1] / z_cam) + camera.cy

    # 3. Frustum Culling
    valid = (z_cam > camera.near_plane) & (z_cam < camera.far_plane)
    means_cam = means_cam[valid]
    opacities = gs_opacities[valid]
    covs_cam = []
    for i in range(N):
        if valid[i]:
            cov_cam = R @ gs_covs[i] @ R.T
            covs_cam.append(cov_cam)
    covs_cam = torch.stack(covs_cam)
    u = u[valid]
    v = v[valid]
    z_cam = z_cam[valid]

    # 4. Sort Gaussians by depth back-to-front
    _, sort_idx = torch.sort(z_cam, descending=True)
    means_cam = means_cam[sort_idx]
    opacities = opacities[sort_idx]
    covs_cam = covs_cam[sort_idx]
    u = u[sort_idx]
    v = v[sort_idx]
    z_cam = z_cam[sort_idx]

    # 5. Approximate 2D Covariances & Compute Conics
    J = torch.zeros((len(valid), 2, 3))
    J[:, 0, 0] = camera.fx / z_cam
    J[:, 0, 2] = -camera.fx * means_cam[:, 0] / (z_cam ** 2)
    J[:, 1, 1] = camera.fy / z_cam
    J[:, 1, 2] = -camera.fy * means_cam[:, 1] / (z_cam ** 2)
    L = R[:2, :2]
    Sigma_2D = torch.zeros((len(valid), 2, 2))
    for i in range(len(valid)):
        cov_2d_part = L @ covs_cam[i][:2, :2] @ L.T
        Sigma_2D[i] = J[i] @ cov_2d_part @ J[i].T + eps_2d * torch.eye(2)
    det = Sigma_2D[:, 0, 0] * Sigma_2D[:, 1, 1] - Sigma_2D[:, 0, 1] * Sigma_2D[:, 1, 0]
    a = Sigma_2D[:, 1, 1] / det
    b = -Sigma_2D[:, 0, 1] / det
    c = Sigma_2D[:, 0, 0] / det
    conics = torch.stack([a, b, c], dim=1)

    # 6. Compute Bounding Boxes & Assign to Tiles
    bboxes = compute_bounding_boxes(u, v, Sigma_2D, sigma_multiplier)
    tile_dict = {}
    num_tiles_u = math.ceil(W / tile_size)
    num_tiles_v = math.ceil(H / tile_size)
    for i in range(len(valid)):
        u_min, v_min, u_max, v_max = bboxes[i]
        tile_u_min = max(0, int(u_min // tile_size))
        tile_v_min = max(0, int(v_min // tile_size))
        tile_u_max = min(num_tiles_u - 1, int(u_max // tile_size))
        tile_v_max = min(num_tiles_v - 1, int(v_max // tile_size))
        for tu in range(tile_u_min, tile_u_max + 1):
            for tv in range(tile_v_min, tile_v_max + 1):
                key = (tu, tv)
                if key not in tile_dict:
                    tile_dict[key] = []
                tile_dict[key].append(i)

    # 7. Initialize Output
    color = torch.zeros((3, H, W))
    alpha = torch.zeros((H, W))

    # 8. Rasterize Tiles
    for (tu, tv), indices in tile_dict.items():
        if not indices: continue
        idx_tensor = torch.tensor(indices)
        opacities_tile = opacities[idx_tensor]
        conics_tile = conics[idx_tensor]
        means_tile = torch.stack([u[idx_tensor], v[idx_tensor]], dim=1)
        # Evaluate spherical harmonics colors [G]
        colors_tile = torch.zeros_like(means_tile)

        u_start = tu * tile_size
        v_start = tv * tile_size
        u_end = min(u_start + tile_size, W)
        v_end = min(v_start + tile_size, H)

        for v_pix in range(v_start, v_end):
            for u_pix in range(u_start, u_end):
                if alpha[v_pix, u_pix] >= 0.99: continue
                current_alpha = alpha[v_pix, u_pix]
                current_color = color[:, v_pix, u_pix]
                for k in range(len(indices)):
                    alpha_g = opacities_tile[k]
                    a_g, b_g, c_g = conics_tile[k]
                    u_g, v_g = means_tile[k]
                    color_g = colors_tile[k]
                    du = u_pix - u_g
                    dv = v_pix - v_g
                    dist_sq = a_g * du**2 + 2 * b_g * du * dv + c_g * dv**2
                    w = alpha_g * torch.exp(-0.5 * dist_sq)
                    current_alpha += w
                    current_color += color_g * w
                alpha[v_pix, u_pix] = current_alpha
                color[:, v_pix, u_pix] = current_color

    # 9. Composite Background
    color = color + bg * (1 - alpha)[None, :, :]
    color = torch.clamp(color, 0.0, 1.0)
    return color, alpha

def quaternion_to_rotation_matrix(q):
    # Standard quaternion-to-rotation conversion [G]
    w, x, y, z = q[0], q[1], q[2], q[3]
    return torch.tensor([
        [1 - 2*(y**2 + z**2), 2*(x*y - z*w), 2*(x*z + y*w)],
        [2*(x*y + z*w), 1 - 2*(x**2 + z**2), 2*(y*z - x*w)],
        [2*(x*z - y*w), 2*(y*z + x*w), 1 - 2*(x**2 + y**2)]
    ])

def compute_bounding_boxes(u, v, Sigma_2D, sigma_multiplier):
    # Simplified AABB from covariance trace scaled by sigma_multiplier [G]
    trace = Sigma_2D[:, 0, 0] + Sigma_2D[:, 1, 1]
    radius = sigma_multiplier * torch.sqrt(trace)
    u_min = u - radius
    v_min = v - radius
    u_max = u + radius
    v_max = v + radius
    return torch.stack([u_min, v_min, u_max, v_max], dim=1)
```

## Subtopics

### [Non-Tiled 2D Gaussian Splatting with Transmittance Culling](2067-non-tiled-2d-gaussian-splatting-with-transmittance-culling.md)
A rasterization method for 3D Gaussian Splatting that iterates over Gaussians rather than tiles, using axis-aligned bounding boxes to limit pixel iteration and transmittance-based early ray termination for performance optimization. It produces visually identical results to tiled rasterization in most cases but is significantly faster due to early stopping and better culling.

### [Tile-Based Culling](2819-tile-based-culling.md)
Tile-Based Culling computes a precise Gaussian-to-Tile mapping to cull irrelevant tiles during 3D Gaussian Splatting rasterization. It improves upon standard conservative bounding box assignment by computing tight, opacity-aware bounding boxes and iteratively verifying tile intersections. It is distinguished from [SnugBox](3378-snugbox.md) by its iterative tile examination process, which results in higher runtime costs for the culling phase compared to AccuTile, though it may show marginal downstream performance gains due to undercounting artifacts.

### [Tile-based Rasteriser](2846-tile-based-rasteriser.md)
The Tile-based Rasteriser is the GPU-optimized sorting and compositing component of the 3D Gaussian Splatting pipeline that assigns projected 2D Gaussian splats to image tiles and sorts them by depth using a single global radix sort. It solves the performance bottleneck of per-pixel depth sorting for millions of splats by grouping work into tiles, enabling real-time rendering and efficient backpropagation. Unlike non-tiled approaches that sort per pixel or per tile independently, it uses a unified 64-bit key to bin and sort all (splat, tile) pairs in one pass.

### [Gaussian Splat Projection and Sorting](3369-gaussian-splat-projection-and-sorting.md)
This method is a compute-shader stage that projects 3D Gaussians to 2D screen space, performs visibility and frustum culling, computes lighting, and prepares data for tile-based sorting. It bridges raw 3D Gaussian data and the tiled rasterization pipeline by ensuring only visible splats are processed and ordered by tile and depth. It differs from non-tiled approaches by explicitly preparing tile-boundary data and from tile-based culling by handling full projection and sorting key generation.

### Opacity-Thresholded Tile Intersection Filtering
Filters out Gaussians whose opacity $\tau$ falls below the alpha-threshold $\epsilon$ immediately during tile intersection, as their axis-aligned bounding box is considered empty [S2]. Combining all modifications decreased rendering time on the Bicycle scene at native resolution by a factor of 3.77 and GPU memory usage by a factor of 2.11 compared to the reference [S2].

### Splat Batching Strategy
Splits the rendering of Gaussians into batches [S3, unofficial]. If `gaussians_per_splat` is -1, splats all Gaussians in one call [S3, unofficial]. If positive, splits into batches. Higher values increase speed but raise GPU memory usage [S3, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources [S1, unofficial].
- **Memory Complexity:** Not given in the sources [S1, unofficial].
- **Performance:** Tiled rasterization enables real-time rendering of large scenes with millions of Gaussians [S1, unofficial][S2]. Performance gains from precomputation and opacity filtering are greatest at higher resolutions [S2].
- **Strengths:** Efficient memory usage, parallelizable on GPU, supports real-time frame rates [S1, unofficial][S2].
- **Limitations:** Requires careful tuning of tile size and sigma multiplier. Performance can degrade if tiles are too small (overhead) or too large (cache misses) [S2].

## Background
Originated from the 3D Gaussian Splatting pipeline and detailed in [S1, unofficial][S2]. The tiled rasterization approach divides the image into tiles to manage memory and processing load, assigning Gaussians based on their bounding boxes [S1, unofficial]. It is used in modern 3D Gaussian Splatting implementations to enable real-time rendering [S1, unofficial][S2].
