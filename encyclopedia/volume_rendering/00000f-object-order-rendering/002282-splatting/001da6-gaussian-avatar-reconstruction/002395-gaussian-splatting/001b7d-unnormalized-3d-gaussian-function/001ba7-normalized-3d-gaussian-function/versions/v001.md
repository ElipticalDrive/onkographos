# Normalized 3D Gaussian Function

Also called: Normal Distribution Helper, Normalized Gaussian, Probability Density Function Gaussian

## Overview
The Normalized 3D Gaussian Function is a probability density function (PDF) scaled by a weight parameter to model the extinction coefficient in volume rendering. It serves as the fundamental building block for EWA splatting and the Gaussian mixture models used in 3D Gaussian Splatting. Unlike the [Unnormalized 3D Gaussian Function](1026-unnormalized-3d-gaussian-function.md), where the amplitude at the mean equals the opacity, the normalized variant integrates to a specific weight $w$ over all space, making $w$ the total capacity to block or emit light rather than the peak intensity.

## How it works
**Inputs:**
- $\mathbf{x} \in \mathbb{R}^3$: The query point in 3D space.
- $\boldsymbol{\mu} \in \mathbb{R}^3$: The mean (center) of the Gaussian.
- $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$: The covariance matrix defining the shape and orientation.
- $w \in \mathbb{R}$: The weight parameter representing the total integral of the function.

**Outputs:**
- $g \in \mathbb{R}$: The value of the normalized 3D Gaussian function at $\mathbf{x}$, representing the local extinction coefficient.

**Data Structures:**
- $\boldsymbol{\Sigma}$: A $3 \times 3$ symmetric positive-definite matrix. In implementation, it is often stored as a $3 \times 3$ array or decomposed (e.g., via Cholesky or SVD) to ensure positive definiteness during optimization.
- $\boldsymbol{\mu}$: A 3-element vector.
- $w$: A scalar.

**Formulas:**
The normalized 3D Gaussian function $\mathcal{G}_3^n$ is defined as the product of the weight $w$ and the standard multivariate normal PDF $\mathcal{N}_3$:

$$
\mathcal{G}_3^n(\mathbf{x}, w, \boldsymbol{\mu}, \boldsymbol{\Sigma}) = w \cdot \mathcal{N}_3(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma})
$$

The PDF $\mathcal{N}_3$ is given by:

$$
\mathcal{N}_3(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma}) = \frac{1}{\mathcal{I}_3(\boldsymbol{\Sigma})} e^{-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})}
$$

The normalization factor $\mathcal{I}_3(\boldsymbol{\Sigma})$ ensures the integral of the PDF over $\mathbb{R}^3$ is 1:

$$
\mathcal{I}_3(\boldsymbol{\Sigma}) = \sqrt{(2\pi)^3 \det(\boldsymbol{\Sigma})}
$$

Combining these, the explicit formula for the normalized Gaussian is:

$$
\mathcal{G}_3^n(\mathbf{x}, w, \boldsymbol{\mu}, \boldsymbol{\Sigma}) = \frac{w}{\sqrt{(2\pi)^3 \det(\boldsymbol{\Sigma})}} e^{-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})}
$$

**Parameters:**
- $\pi$: The mathematical constant Pi.

**Pseudocode:**
```python
import math
import numpy as np

def normalized_3d_gaussian(x: np.ndarray, mu: np.ndarray, Sigma: np.ndarray, w: float) -> float:
    """
    Computes the value of a normalized 3D Gaussian function at point x.
    
    Args:
        x: Query point (3,)
        mu: Mean position (3,)
        Sigma: Covariance matrix (3, 3)
        w: Weight (total integral)
        
    Returns:
        The extinction coefficient value at x.
    """
    # 1. Compute the difference vector
    diff = x - mu
    
    # 2. Compute the inverse of the covariance matrix
    # Note: Sigma must be positive definite. In practice, Cholesky decomposition
    # or adding a small epsilon to the diagonal is used for stability.
    Sigma_inv = np.linalg.inv(Sigma)
    
    # 3. Compute the quadratic form: (x - mu)^T * Sigma^-1 * (x - mu)
    # Using dot product for efficiency: diff.T @ Sigma_inv @ diff
    exponent_arg = -0.5 * np.dot(diff, np.dot(Sigma_inv, diff))
    
    # 4. Compute the normalization factor: sqrt((2*pi)^3 * det(Sigma))
    # det(Sigma) must be positive.
    det_sigma = np.linalg.det(Sigma)
    
    # Guard against numerical instability where det_sigma <= 0
    if det_sigma <= 0:
        return 0.0
        
    normalization_factor = math.sqrt((2 * math.pi)**3 * det_sigma)
    
    # 5. Compute the final value
    # If normalization_factor is zero (degenerate Sigma), return 0
    if normalization_factor == 0:
        return 0.0
        
    value = (w / normalization_factor) * math.exp(exponent_arg)
    
    return value
```

**Edge Cases and Pitfalls:**
- **Degenerate Covariance:** If $\det(\boldsymbol{\Sigma}) = 0$ (singular matrix), the normalization factor is zero, leading to division by zero. The function should return 0 or handle the singularity via regularization [S1].
- **Precision:** The exponential term can underflow to zero for points far from $\boldsymbol{\mu}$. Culling thresholds are typically applied in rendering to ignore Gaussians with negligible contribution.
- **Positive Definiteness:** $\boldsymbol{\Sigma}$ must remain positive definite. If optimization causes it to become indefinite, the quadratic form may yield positive exponents, causing the Gaussian to explode to infinity.

## Subtopics

### [Gaussian Interpolation](2347-gaussian-interpolation.md)
Gaussian Interpolation uses the Gaussian function as an interpolation kernel to reconstruct signals from discrete samples. It is distinguished from other filters by being the only filter that is both separable and rotationally symmetric. This unique property allows it to integrate one dimension out of the kernel, enabling 2D reconstruction instead of 3D, which is particularly advantageous in point-tossing approaches like splatting.

### Gaussian Mixture Extinction Model
The Gaussian Mixture Extinction Model represents the total extinction function $f(\mathbf{x})$ as a sum of $N$ normalized 3D Gaussians, each potentially having a view-dependent radiance $c_i(\mathcal{R})$. The extinction function is:
$$
\mathbf{f}(\mathbf{x}) = \sum_{i=0}^N \mathcal{G}_3^n(\mathbf{x}, w_i, \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i)
$$
The radiance for a ray $\mathcal{R}$ is:
$$
c(\mathcal{R}, t) = \sum_{i=0}^N c_i(\mathcal{R}) \mathcal{G}_3^n(\mathcal{R}(t), w_i, \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i)
$$
The final pixel intensity $I(\mathbf{p})$ is obtained by integrating along the ray $\mathcal{R}$ from $t=0$ to $\infty$:
$$
I(\mathbf{p}) = \int_0^\infty \sum_{i=0}^N c_i(\mathcal{R}) \mathcal{G}_3^n(\mathcal{R}(t), w_i, \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i) e^{-\int_0^t \sum_{i=0}^N \mathcal{G}_3^n(\mathcal{R}(\tau), w_i, \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i) \, d\tau} \, dt
$$
This formulation models both emission/in-scattering (via $c_i$) and attenuation (via the exponential term) [S1].

## Operating characteristics
- **Time Complexity:** Evaluation of a single Gaussian is $O(1)$ (matrix inversion and dot product). Rendering a scene with $N$ Gaussians requires evaluating all visible Gaussians for each pixel, leading to $O(N \cdot P)$ complexity where $P$ is the number of pixels, though spatial partitioning reduces the effective $N$.
- **Memory Complexity:** $O(N)$ to store $\boldsymbol{\mu}$, $\boldsymbol{\Sigma}$, and $w$ for each Gaussian.
- **Strengths:** Analytically integrable properties (in 1D projections), smooth gradients, and compatibility with differentiable rendering pipelines. The normalization ensures consistent physical interpretation of $w$.
- **Limitations:** Requires careful handling of $\boldsymbol{\Sigma}$ to maintain positive definiteness. The normalization factor calculation involves a determinant and inverse, which can be numerically unstable if not regularized.
- **When to use:** When a physically plausible extinction model is required, or when converting between unnormalized (opacity-based) and normalized (weight-based) representations.

## Background
The normalized 3D Gaussian function originates from the field of volume rendering and splatting. It is explicitly defined as the basic building block of EWA (Elliptical Weighted Average) splatting [ZPVBG02]. The formulation was later adopted and adapted for 3D Gaussian Splatting [KKLD23] and analyzed in the context of whether accurate volumetric rendering is necessary for 3DGS [S1]. The distinction between normalized and unnormalized Gaussians was formalized to clarify the relationship between the weight parameter $w$ and the amplitude $a$ (opacity) [S1].
