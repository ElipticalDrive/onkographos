# Gaussian Interpolation

Also called: Gaussian Filter, Gaussian Kernel Interpolation

## Overview
Gaussian Interpolation uses a Gaussian function as an interpolation kernel to reconstruct signals from discrete samples. It is distinguished from other filters by being the only filter that is both separable and rotationally symmetric [S1]. This unique property allows it to integrate one dimension out of the kernel, enabling 2D reconstruction instead of 3D, which is particularly advantageous in point-tossing approaches like splatting [S1].

## How it works
**Inputs and Outputs:**
- Input: A set of sample values and their positions relative to the reconstruction point.
- Output: The interpolated value at the target position.

**Data Structures:**
No specific complex data structures are required beyond the sample values and their spatial coordinates. The kernel itself is defined by a single scalar parameter.

**Parameters:**
- $\sigma$ (Sigma): Controls the width of the Gaussian kernel. A larger $\sigma$ results in a wider, smoother kernel [S1].

**Formula:**
The one-dimensional Gaussian interpolation kernel is defined as [S1]:

$$f_{\text{Gaussian}}(z) = e^{-\frac{z^2}{2\sigma^2}}$$

where:
- $z$ is the distance from the sample to the reconstruction point.
- $\sigma$ is the standard deviation controlling the width.

**Steps:**
1. For each sample contributing to the reconstruction point, calculate the distance $z$ between the sample's position and the target position.
2. Compute the kernel weight $w$ using the formula $w = e^{-\frac{z^2}{2\sigma^2}}$.
3. Multiply the sample's value by its corresponding weight $w$.
4. Sum the weighted values of all contributing samples.
5. (Optional) Normalize the result by dividing by the sum of the weights if the kernel is not normalized to unity over the integration domain, though in many practical implementations, the infinite extent is truncated and normalization is handled implicitly or via pre-computed constants [G].

**Pitfalls and Edge Cases:**
- **Infinite Extent:** The Gaussian kernel has infinite extent in both spatial and frequency domains [S1]. In practice, it must be truncated. Because it asymptotically falls to zero quickly, truncation can be performed in the near-zero area without causing significant ringing artifacts [S1].
- **Blurring:** The filter distorts the passband by attenuating high-frequency components of the main replica, which causes blurring in the output [S1]. This makes it less suitable for applications requiring sharp edge preservation compared to filters with sharper cutoffs.
- **Truncation:** While truncation is safe due to the rapid decay, the truncation radius must be chosen carefully to balance performance and accuracy. A common heuristic is to truncate at $3\sigma$ or $4\sigma$, where the value is negligible [G].

## Subtopics

### Gaussian Reconstruction Filter
A specific application of Gaussian interpolation used in volumetric rendering, particularly in temporal anti-aliasing (TAA) for froxel-based rendering. It is applied to jittered sub-froxel samples to improve edge quality and stability compared to a box filter [S2]. The weight $W(x)$ for a sample at distance $x$ from the center of the froxel is given by [S2]:

$$W(x) = e^{-2.29x^2}$$

This specific form is a Gaussian fit to the Blackman-Harris 3.3 window function [S2]. It provides better edge quality and stability under motion than a spatiotemporal box filter, which suffers from poor edge quality and instability due to sharp edges [S2].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of samples within the truncation radius. Due to separability, an $N$-dimensional interpolation can be decomposed into $N$ one-dimensional interpolations, reducing computational cost [S1].
- **Memory Complexity:** Low, as the kernel is defined by a single parameter $\sigma$ and does not require large lookup tables [S1].
- **Strengths:** Separability and rotational symmetry allow for efficient 2D reconstruction from 3D data in splatting methods [S1]. Smooth decay reduces ringing artifacts upon truncation [S1].
- **Limitations:** Causes blurring due to high-frequency attenuation [S1]. Infinite extent requires truncation, which may introduce slight inaccuracies if the truncation radius is too small [S1].
- **When to Use:** Suitable for applications where smoothness is preferred over sharpness, such as in splatting-based volume rendering or temporal anti-aliasing where stability is key [S1, S2].
- **When Not to Use:** Not ideal for applications requiring sharp edge preservation or high-frequency detail retention due to inherent blurring [S1].

## Background
Gaussian interpolation has been used in various research contexts for signal reconstruction. It is notably used in point-tossing approaches like splatting [Westover 90] because of its separability and rotational symmetry, which allow for efficient 2D reconstruction [S1]. In the context of volumetric rendering, it has been applied in temporal anti-aliasing methods for froxel-based rendering to improve edge quality and stability [S2]. The specific Gaussian fit to Blackman-Harris 3.3 was introduced by Karis for use in TAA [S2].
