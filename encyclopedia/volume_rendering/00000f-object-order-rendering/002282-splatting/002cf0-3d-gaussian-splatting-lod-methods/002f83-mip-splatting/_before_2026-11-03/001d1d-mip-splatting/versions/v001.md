# MIP-Splatting

Also called: MIP-3DGS, Multi-Resolution Gaussian Splatting

## Overview
MIP-Splatting is an extension of Gaussian Splatting that introduces 2D and 3D Gaussian filters to improve robustness to aliasing caused by resolution changes [S1, unofficial]. While standard Gaussian Splatting uses a dilation filter that fails to suppress high-frequency artifacts when varying focal length or camera distance, MIP-Splatting mitigates these issues by controlling the maximum frequency of primitives [S1, unofficial]. It builds on [Gaussian Splatting](946-gaussian-splatting.md) by modifying the rendering pipeline to handle multi-resolution inputs without introducing visual artifacts.

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians $\{G_i\}$ defined by mean $\mu_i$, covariance $\Sigma_i$, opacity $\alpha_i$, and spherical harmonic coefficients $c_i$, along with camera parameters (view and projection matrices).
*   **Output:** A rendered image $I$.

**Data Structures:**
The method retains the standard Gaussian Splatting data structures but adds a mechanism to compute a modified covariance matrix $\Sigma'$ that incorporates the MIP filter.

**Steps:**
1.  **3D Smoothing Filter:** To prevent primitives from becoming too small relative to the training view resolution, a 3D smoothing filter is applied. This ensures that each primitive is visible from at least one pixel of a training view [S1, unofficial][S2]. This limits the minimum size of primitives based on visibility [S2].
2.  **2D Mip Filter:** For rendering, a 2D Mip filter is applied to the projected screen-space Gaussian. This acts as a band-limiting approximation to suppress high frequencies [S1, unofficial][S2].
    *   Let $\Sigma_{2D}$ be the projected 2D covariance matrix in screen space.
    *   The MIP filter modifies the covariance to $\Sigma'_{2D} = \Sigma_{2D} + \Delta \Sigma$, where $\Delta \Sigma$ represents the variance added by the MIP filter based on the sampling rate [S1, unofficial].
    *   The exact formula for $\Delta \Sigma$ depends on the MIP level, but conceptually it increases the spread of the Gaussian to match the effective pixel size [S1, unofficial].
3.  **Rasterization:** The modified covariance $\Sigma'_{2D}$ is used in the standard Gaussian Splatting rasterization pipeline [Gaussian Splatting](946-gaussian-splatting.md). The opacity $\alpha$ is evaluated using the modified covariance, which effectively lowers the peak opacity and spreads the contribution over a larger area, reducing aliasing [S2].

**Parameters:**
*   MIP levels: Typically determined by the ratio of the rendered resolution to the training resolution [S1, unofficial].
*   Smoothing strength: Determined by the minimum visible pixel size in training views [S2].

**Edge Cases and Pitfalls:**
*   **Precision:** The addition of variance must be handled carefully to avoid numerical instability in the covariance matrix inversion [G].
*   **Incompatibility:** The 2D Mip filter cannot be used with methods that modify the screen space Gaussian distribution directly (e.g., LinPrim) because they rely on different mechanisms [S2].

## Subtopics

### LinPrim Anti-Aliasing
LinPrim Anti-Aliasing is an alternative strategy that combines a 3D smoothing filter with a bounding box expansion technique to limit high frequencies and prevent aliasing/dilation artifacts [S2]. It applies the 3D smoothing strategy to ensure primitives are visible from at least one pixel [S2]. Instead of a 2D Mip filter, it identifies vertices on the bounding box used for tiling and shifts them outward, parallel to the screen [S2]. This enlarges the bounding box footprint and increases the minimum size at which the primitive appears [S2]. Because the fall-off within each primitive is treated as linear, expanding the distance from the center raises the opacity along the primitive as it is evaluated over a larger extent, acting as a coarse band-limiting approximation [S2]. This approach is not fully mathematically equivalent to a 2D Mip filter but captures its function [S2]. A key pitfall is that the 2D Mip filter from MIP-Splatting is incompatible with LinPrim primitives because LinPrim does not rely on modifying the screen space Gaussian distribution [S2].

## Operating characteristics
*   **Time Complexity:** Similar to Gaussian Splatting, but with additional overhead for computing the MIP filter variance [S1, unofficial].
*   **Memory Complexity:** No significant increase in memory usage compared to Gaussian Splatting [S1, unofficial].
*   **Strengths:** Robust to aliasing when varying focal length or camera distance [S1, unofficial].
*   **Limitations:** The 2D Mip filter is incompatible with methods that modify screen space distributions directly [S2].
*   **When to use:** When rendering at resolutions different from training resolution or when varying camera distance/focal length [S1, unofficial].

## Background
MIP-Splatting was introduced to address the limitations of the dilation filter in Gaussian Splatting, which fails to suppress high-frequency artifacts during resolution changes [S1, unofficial]. It builds on the concept of using Gaussian filters for anti-aliasing in volume rendering [S1, unofficial].
