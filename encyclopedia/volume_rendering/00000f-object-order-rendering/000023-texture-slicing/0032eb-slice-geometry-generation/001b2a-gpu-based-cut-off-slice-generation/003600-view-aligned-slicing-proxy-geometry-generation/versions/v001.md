# View-Aligned Slicing (Proxy Geometry Generation)

Also called: Cube-Plane Intersection Slicing, Slice-Base Volume Rendering

## Overview
View-Aligned Slicing is a GPU-based method for generating proxy geometry (polygonal meshes) that approximate a volumetric dataset by intersecting its bounding cube with a series of parallel planes aligned to the view direction [S1, unofficial]. It solves the problem of efficiently creating cut-off slice geometry on the GPU by computing intersection parameters in a vertex shader, offloading the CPU from complex geometric calculations [S1, unofficial]. It differs from sibling methods by using a fixed triangular fan assembly based on precomputed edge intersections rather than incremental texture coordinate updates or pseudo-angle sorting [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:**
  - `cube_vertices[8]`: The 8 vertices of the bounding cube, transformed by a 45-degree rotation around the X-axis [S1, unofficial].
  - `viewDir`: A normalized `glm::vec3` defining the plane normals and slice ordering [S1, unofficial].
  - `numberOfSlice`: Integer count of parallel planes (default 10) [S1, unofficial].
  - `EPSILON`: Small float constant for coverage expansion [S1, unofficial].
- **Outputs:**
  - `vTextureSlices`: A vertex buffer containing the generated triangular fan meshes for all slices [S1, unofficial].

**Data Structures:**
- `lambda[12]`, `lambda_inc[12]`: Arrays of 12 floats storing the intersection parameter and its increment per slice for each of the 12 cube edges [S1, unofficial].
- `intersection[6]`: Temporary array of 6 `glm::vec3` storing intersection points for the current slice before fan assembly [S1, unofficial].
- `cube_edges`: Implicit definition of 12 edges derived from the 8 cube vertices. Each edge has a start vertex `edgeStart[e]` and direction `edgeDir[e]` [S1, unofficial].

**Steps:**
1. **Compute View Extents:** Calculate the dot product of `viewDir` with all 8 `cube_vertices` to find the minimum (`min_z`) and maximum (`max_z`) distances along the view axis [S1, unofficial].
2. **Expand Bounds:** Expand `min_z` and `max_z` by `EPSILON` to ensure full coverage of the volume [S1, unofficial].
3. **Calculate Slice Spacing:** Compute `deltaZ = (max_z - min_z) / numberOfSlice` [S1, unofficial].
4. **Precompute Edge Parameters:** For each of the 12 cube edges:
   - Compute `denom = dot(edgeDir[e], viewDir)` [S1, unofficial].
   - If `1.0 + denom != 1.0` (avoiding division by zero for parallel edges):
     - `lambda_inc[e] = deltaZ / denom` [S1, unofficial].
     - `lambda[e] = (min_z - dot(edgeStart[e], viewDir)) / denom` [S1, unofficial].
   - Else (edge parallel to view):
     - `lambda[e] = -1.0`
     - `lambda_inc[e] = 0.0` [S1, unofficial].
5. **Generate Slices:** Iterate `i` from `numberOfSlice - 1` down to `0`:
   - For each edge `e`:
     - Compute `dL[e] = lambda[e] + i * lambda_inc[e]` [S1, unofficial].
     - If `0.0 <= dL[e] < 1.0`:
       - Compute intersection point `P = edgeStart[e] + dL[e] * edgeDir[e]` [S1, unofficial].
       - Store `P` in `intersection` array [S1, unofficial].
   - **Fan Assembly:** Use the fixed index array `{0,1,2, 0,2,3, 0,3,4, 0,4,5}` to form triangles from the collected intersection points (up to 6) and append to `vTextureSlices` [S1, unofficial].

**Pseudocode:**
```python
import math

def view_aligned_slicing(cube_vertices, view_dir, num_slices=10, epsilon=1e-6):
    """
    Generate proxy geometry for volume rendering using view-aligned slicing.
    
    Args:
        cube_vertices: List of 8 glm::vec3 representing the rotated bounding cube.
        view_dir: glm::vec3, normalized view direction.
        num_slices: int, number of parallel planes.
        epsilon: float, expansion factor for bounds.
        
    Returns:
        vTextureSlices: List of vertices forming triangular fans for all slices.
    """
    # Define the 12 edges of a cube based on vertex indices
    # Standard cube vertex order: 0:(-1,-1,-1), 1:(1,-1,-1), 2:(1,1,-1), 3:(-1,1,-1),
    #                               4:(-1,-1,1), 5:(1,-1,1), 6:(1,1,1), 7:(-1,1,1)
    # Note: The source uses a 45-degree rotated cube, but edge topology remains the same.
    edge_indices = [
        (0,1), (1,2), (2,3), (3,0), # Bottom face
        (4,5), (5,6), (6,7), (7,4), # Top face
        (0,4), (1,5), (2,6), (3,7)  # Vertical edges
    ]
    
    # Precompute edge start and direction
    edge_starts = []
    edge_dirs = []
    for i, j in edge_indices:
        start = cube_vertices[i]
        end = cube_vertices[j]
        edge_starts.append(start)
        edge_dirs.append(end - start)
        
    # Step 1: Compute view extents
    dot_products = [math.dot(v, view_dir) for v in cube_vertices]
    min_z = min(dot_products)
    max_z = max(dot_products)
    
    # Step 2: Expand bounds
    min_z -= epsilon
    max_z += epsilon
    
    # Step 3: Calculate slice spacing
    delta_z = (max_z - min_z) / num_slices
    
    # Step 4: Precompute edge parameters
    lambda_vals = [0.0] * 12
    lambda_inc_vals = [0.0] * 12
    
    for e in range(12):
        denom = math.dot(edge_dirs[e], view_dir)
        # Check for parallel edge using epsilon comparison logic from source
        if 1.0 + denom != 1.0:
            lambda_inc_vals[e] = delta_z / denom
            lambda_vals[e] = (min_z - math.dot(edge_starts[e], view_dir)) / denom
        else:
            lambda_vals[e] = -1.0
            lambda_inc_vals[e] = 0.0
            
    vTextureSlices = []
    
    # Step 5: Generate slices
    # Fixed index array for triangular fan assembly
    fan_indices = [0,1,2, 0,2,3, 0,3,4, 0,4,5]
    
    for i in range(num_slices - 1, -1, -1):
        intersection_points = []
        
        for e in range(12):
            dL = lambda_vals[e] + i * lambda_inc_vals[e]
            
            if 0.0 <= dL < 1.0:
                # Compute intersection point
                p = edge_starts[e] + dL * edge_dirs[e]
                intersection_points.append(p)
                
        # Fan assembly
        # Note: The source assumes up to 6 points are collected and uses a fixed fan.
        # In practice, the number of intersections varies. The source code implies
        # a specific ordering or assumption about which edges intersect.
        # We append vertices according to the fan indices, clamping to available points.
        for idx in fan_indices:
            if idx < len(intersection_points):
                vTextureSlices.append(intersection_points[idx])
                
    return vTextureSlices
```

**Parameters:**
- `numberOfSlice`: Default 10 [S1, unofficial].
- `viewDir`: Normalized direction vector [S1, unofficial].
- `EPSILON`: Small constant to prevent missed intersections [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Parallel Edges:** When an edge is parallel to the view direction (`denom ≈ 0`), division by zero is avoided by checking `1.0 + denom != 1.0`. Parallel edges are skipped by setting `lambda = -1.0` and `lambda_inc = 0.0` [S1, unofficial].
- **Precision:** The check `1.0 + denom != 1.0` is used instead of `denom != 0.0` to handle floating-point precision issues [S1, unofficial].
