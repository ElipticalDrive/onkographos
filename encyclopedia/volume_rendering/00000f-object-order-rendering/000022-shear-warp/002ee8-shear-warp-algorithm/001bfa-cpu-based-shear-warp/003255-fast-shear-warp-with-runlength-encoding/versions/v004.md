# Fast Shear-Warp with Runlength Encoding

Also called: Fast shear-warp with RLE, Lacroute and Levoy method, Lacroute and Levoy 52, Volpack

## Overview
Fast Shear-Warp with Runlength Encoding is a scanline-based volume rendering algorithm optimized for parallel projections that uses run-length encoding (RLE) of voxel scanlines and intermediate image pixels to skip transparent voxels and occluded pixels, assuming a fixed opacity transfer function [S2]. It achieves sub-second rendering times for moderately-sized datasets, with quality rivaling raycasting and splatting at unity magnification [S3]. Unlike the Simple Shear-Warp Algorithm, which traverses every voxel, this method leverages object coherence (transparent voxel runs) and image coherence (occluded pixel runs) to significantly reduce the number of shading and compositing operations [S2].

## How it works
### Inputs and Outputs
**Inputs:**
*   A 3D volume dataset with dimensions $D_x \times D_y \times D_z$ [S5, unofficial].
*   A scalar opacity transfer function (SOTF) or an isovalue threshold [S5, unofficial].
*   A view matrix, decomposed into shear, warp, and permutation components [S1, unofficial].
*   An opacity threshold (for compositing) or isovalue (for isosurface/MIP) [S5, unofficial].

**Outputs:**
*   A final 2D screen image [S1, unofficial].
*   Precomputed RLE structures for three principal viewing axes [S1, unofficial].

### Data Structures
The method relies on three primary data structures, implemented as templated classes in VTK [S5, unofficial]:

1.  **`vtkShearWarpVoxelData<T>`**: Stores metadata for each opaque voxel [S5, unofficial].
    *   `T Value`: The scalar value of the voxel.
    *   `unsigned short EncodedNormal`: Pre-computed normal for shading.
    *   `unsigned char GradientMagnitude`: Pre-computed gradient magnitude.
2.  **`vtkShearWarpRLERun<T>`**: Represents a contiguous run of voxels or pixels [S5, unofficial].
    *   `unsigned char Length`: The number of elements in the run. This is capped at 254 to prevent overflow during increment operations; runs longer than 254 are split into multiple entries [S5, unofficial].
    *   `vtkShearWarpVoxelData<T> *VoxelData`: A pointer to the first voxel in the run. For transparent runs, this is `NULL` [S5, unofficial].
3.  **`vtkShearWarpRLESlice<T>`**: Represents a 2D slice of the volume encoded along a specific axis [S5, unofficial].
    *   `vtkShearWarpRLERun<T> *LineRuns[jCount]`: An array of pointers to the first run of each scanline (row) in the slice [S5, unofficial].
    *   `vtkShearWarpRLERun<T> SliceRuns[currentRun]`: A flat array containing all runs in the slice [S5, unofficial].
    *   `vtkShearWarpVoxelData<T> VoxelData[voxelIndex]`: A flat array containing the data for all opaque voxels in the slice [S5, unofficial].

**Image RLE:**
*   For the intermediate image, each opaque pixel stores an `Offset` field pointing to the next non-opaque pixel in the same scanline [S2]. This is computed on-the-fly during rendering [S2].

### Preprocessing: RLE Construction
Three view-independent RLE encodings are constructed, one for each principal viewing direction (X, Y, Z), to avoid transposing the volume during rendering [S1, unofficial]. The encoding is performed in two passes per slice [S5, unofficial].

**Parameters:**
*   `axis`: `VTK_X_AXIS` (0), `VTK_Y_AXIS` (1), or `VTK_Z_AXIS` (2) [S5, unofficial].
*   `opacityThreshold`: Float threshold. Voxels with opacity $> threshold$ are opaque [S5, unofficial].
*   `isoValue`: Float threshold. Voxels with scalar $\ge isoValue$ are opaque [S5, unofficial].

**Step 1: Determine Strides and Bounds**
Based on the `axis` and volume dimensions $D_x, D_y, D_z$:
*   Let $plane = D_x \times D_y$.
*   **X-axis:** $iCount = D_y, jCount = D_z, vk = k, iIncrement = D_x, jIncrement = plane$ [S5, unofficial].
*   **Y-axis:** $iCount = D_z, jCount = D_x, vk = k \times D_x, iIncrement = plane, jIncrement = 1$ [S5, unofficial].
*   **Z-axis:** $iCount = D_x, jCount = D_y, vk = k \times plane, iIncrement = 1, jIncrement = D_x$ [S5, unofficial].

**Step 2: Pass 1 (Count Runs)**
Iterate through the slice to count the number of runs (`currentRun`) and opaque voxels (`voxelIndex`) [S5, unofficial]. Initialize: `currentIndex = 0`, `currentRun = 0`, `voxelIndex = 0`, `transparentRun = false` [S5, unofficial].

For each line $j$ from $0$ to $jCount-1$:
  For each voxel $i$ from $0$ to $iCount-1$:
    1.  Compute linear location: $location = vi + vj + vk$ [S5, unofficial].
    2.  Fetch scalar: $scalar = dptr[location]$ [S5, unofficial].
    3.  Determine opacity:
        *   If using opacity mode: $opacity = SOTF[scalar]$ [S5, unofficial].
        *   If using scalar/isosurface mode: $opacity = (scalar \ge isoValue)$ [S5, unofficial].
    4.  If opaque:
        *   If `!transparentRun` and $i > 0$ and $currentIndex < 254$:
            *   $currentIndex++$ [S5, unofficial].
        *   Else:
            *   $currentIndex = 0$ [S5, unofficial].
            *   $currentRun++$ [S5, unofficial].
            *   $transparentRun = false$ [S5, unofficial].
        *   $voxelIndex++$ [S5, unofficial].
    5.  Else (transparent):
        *   If `transparentRun` and $i > 0$ and $currentIndex < 254$:
            *   $currentIndex++$ [S5, unofficial].
        *   Else:
            *   $currentIndex = 0$ [S5, unofficial].
            *   $currentRun++$ [S5, unofficial].
            *   $transparentRun = true$ [S5, unofficial].

**Step 3: Allocate Memory**
*   `LineRuns = new vtkShearWarpRLERun<T>*[jCount]` [S5, unofficial].
*   `SliceRuns = new vtkShearWarpRLERun<T>[currentRun]` [S5, unofficial].
*   `VoxelData = new vtkShearWarpVoxelData<T>[voxelIndex]` [S5, unofficial].
*   `activeRun = &SliceRuns[0]` [S5, unofficial].
*   Reset `voxelIndex = 0`, `currentRun = 0` [S5, unofficial].

**Step 4: Pass 2 (Encode Runs)**
Iterate through the slice again to populate the structures [S5, unofficial].
For each line $j$ from $0$ to $jCount-1$:
  1.  `LineRuns[j] = activeRun` [S5, unofficial].
  2.  `currentIndex = 0` [S5, unofficial].
  3.  For each voxel $i$ from $0$ to $iCount-1$:
      1.  Compute $location = vi + vj + vk$ [S5, unofficial].
      2.  Fetch $scalar = dptr[location]$ [S5, unofficial].
      3.  Determine opacity as in Step 2 [S5, unofficial].
      4.  If opaque:
          *   If `!transparentRun` and $i > 0$ and $currentIndex < 254$:
              *   $currentIndex++$ [S5, unofficial].
          *   Else:
              *   If $i > 0$:
                  *   `activeRun->Length = currentIndex + 1` [S5, unofficial].
                  *   `activeRun++` [S5, unofficial].
                  *   `currentRun++` [S5, unofficial].
                  *   $currentIndex = 0$ [S5, unofficial].
              *   `activeRun->VoxelData = &VoxelData[voxelIndex]` [S5, unofficial].
              *   $transparentRun = false$ [S5, unofficial].
          *   `VoxelData[voxelIndex].Value = scalar` [S5, unofficial].
          *   `VoxelData[voxelIndex].EncodedNormal = nptr[location]` [S5, unofficial].
          *   `VoxelData[voxelIndex].GradientMagnitude = gptr[location]` [S5, unofficial].
          *   $voxelIndex++$ [S5, unofficial].
      5.  Else (transparent):
          *   If `transparentRun` and $i > 0$ and $currentIndex < 254$:
              *   $currentIndex++$ [S5, unofficial].
          *   Else:
              *   If $i > 0$:
                  *   `activeRun->Length = currentIndex + 1` [S5, unofficial].
                  *   `activeRun++` [S5, unofficial].
                  *   `currentRun++` [S5, unofficial].
                  *   $currentIndex = 0$ [S5, unofficial].
              *   `activeRun->VoxelData = NULL` [S5, unofficial].
              *   $transparentRun = true$ [S5, unofficial].
  4.  End of row: `activeRun->Length = currentIndex + 1`, `activeRun++`, `currentRun++` [S5, unofficial].

*Note: The check $i > 0$ prevents creating a zero-length run for the first voxel. The final row end explicitly sets the length of the last run [S5, unofficial].*

### Rendering
1.  **Select Encoding:** Choose one of the three precomputed RLE encodings based on the permutation matrix $P$ in the shear-warp factorization [S1, unofficial].
2.  **Shear:** Shear the selected encoded volume such that rays are perpendicular to the volume slices [S2].
3.  **Traverse and Composite:**
    *   March through the volume and the intermediate image simultaneously in scanline order [S2].
    *   Use the **Voxel RLE** to skip runs of transparent voxels [S2].
    *   Use the **Image RLE** to skip runs of opaque (occluded) pixels. An image pixel is opaque if its accumulated opacity exceeds the threshold [S2].
    *   For non-skipped voxel runs, execute a tightly-coded loop:
        *   **Resampling:** Use bilinear interpolation with a gather-type convolution (backward projection). Two voxel scanlines are traversed to compute one intermediate image scanline [S2]. Since the shear transformation is a translation, resampling weights are constant for all voxels in a slice [S2].
        *   **Shading:** Apply shading using a lookup-table based system [S2].
        *   **Compositing:** Accumulate color and opacity. The opaque pixel links achieve early ray termination; an offset is stored with each opaque pixel to skip to the next non-opaque pixel [S2].
4.  **Warp:** Transform the intermediate image into the final screen image using a general-purpose affine image warper with a bilinear filter [S2].

### Formulas
The DVRI (Digital Volume Ray Interval) distance $\Delta s$ is view-dependent and calculated as:
$$\Delta s = \sqrt{\left(\frac{dx}{dz}\right)^2 + \left(\frac{dy}{dz}\right)^2} + 1$$
where $dx, dy, dz$ is the normalized viewing vector reordered such that $dz$ is the major viewing direction [S1, unofficial].

```python
def encode_rle_slice(dptr, sotf, iso_value, opacity_threshold, axis, dimensions, k):
    plane = dimensions[0] * dimensions[1]
    if axis == 0: # X-axis
        iCount, jCount, vk, iInc, jInc = dimensions[1], dimensions[2], k, dimensions[0], plane
    elif axis == 1: # Y-axis
        iCount, jCount, vk, iInc, jInc = dimensions[2], dimensions[0], k * dimensions[0], plane, 1
    else: # Z-axis
        iCount, jCount, vk, iInc, jInc = dimensions[0], dimensions[1], k * plane, 1, dimensions[0]

    currentRun, voxelIndex, currentIndex, transparentRun = 0, 0, 0, False
    # Pass 1: Count runs
    for j in range(jCount):
        vj = j * jInc
        for i in range(iCount):
            vi = i * iInc
            location = vi + vj + vk
            scalar = dptr[location]
            opacity = sotf[scalar] if sotf else (scalar >= iso_value)
            is_opaque = opacity > opacity_threshold if sotf else (scalar >= iso_value)
            
            if is_opaque:
                if not transparentRun and i > 0 and currentIndex < 254:
                    currentIndex += 1
                else:
                    currentIndex = 0
                    currentRun += 1
                    transparentRun = False
                voxelIndex += 1
            else:
                if transparentRun and i > 0 and currentIndex < 254:
                    currentIndex += 1
                else:
                    currentIndex = 0
                    currentRun += 1
                    transparentRun = True

    # Allocate arrays
    LineRuns = [None] * jCount
    SliceRuns = [None] * currentRun
    VoxelData = [None] * voxelIndex
    activeRun = 0
    voxelIndex = 0
    currentRun = 0
    transparentRun = False

    # Pass 2: Encode runs
    for j in range(jCount):
        vj = j * jInc
        LineRuns[j] = activeRun
        currentIndex = 0
        for i in range(iCount):
            vi = i * iInc
            location = vi + vj + vk
            scalar = dptr[location]
            opacity = sotf[scalar] if sotf else (scalar >= iso_value)
            is_opaque = opacity > opacity_threshold if sotf else (scalar >= iso_value)
            
            if is_opaque:
                if not transparentRun and i > 0 and currentIndex < 254:
                    currentIndex += 1
                else:
                    if i > 0:
                        SliceRuns[activeRun] = {'Length': currentIndex + 1, 'VoxelData': None}
                        activeRun += 1
                        currentRun += 1
                        currentIndex = 0
                    SliceRuns[activeRun] = {'Length': 0, 'VoxelData': voxelIndex}
                    transparentRun = False
                VoxelData[voxelIndex] = {'Value': scalar, 'EncodedNormal': 0, 'GradientMagnitude': 0}
                voxelIndex += 1
            else:
                if transparentRun and i > 0 and currentIndex < 254:
                    currentIndex += 1
                else:
                    if i > 0:
                        SliceRuns[activeRun] = {'Length': currentIndex + 1, 'VoxelData': None}
                        activeRun += 1
                        currentRun += 1
                        currentIndex = 0
                    SliceRuns[activeRun] = {'Length': 0, 'VoxelData': None}
                    transparentRun = True
        SliceRuns[activeRun] = {'Length': currentIndex + 1, 'VoxelData': None}
        activeRun += 1
        currentRun += 1

    return {'LineRuns': LineRuns, 'SliceRuns': SliceRuns, 'VoxelData': VoxelData, 'jCount': jCount}

def composite_intermediate_linear_rle(rle_slice, intermediate_image, sotf, opacity_threshold, shear_matrix, screen_width, screen_height):
    # Initialize intermediate image RLE state
    img_opaque = [False] * (screen_width * screen_height)
    img_offset = [0] * (screen_width * screen_height)

    for line_idx in range(rle_slice['jCount']):
        line_runs = rle_slice['LineRuns'][line_idx]
        
        # Map sheared volume coordinates to intermediate image coordinates
        img_y = int(line_idx * shear_matrix[1][1] + shear_matrix[1][2])
        img_start = max(0, img_y * screen_width)
        img_end = min(screen_width * (img_y + 1), len(intermediate_image))
        
        # Skip fully occluded scanlines using Image RLE
        current_img_idx = img_start
        while current_img_idx < img_end and img_opaque[current_img_idx]:
            current_img_idx = img_offset[current_img_idx]
        if current_img_idx >= img_end:
            continue

        for run in line_runs:
            if run['VoxelData'] is None:
                continue # Skip transparent run

            # Map voxel run to intermediate image pixel range
            img_run_start = img_start
            img_run_end = img_end
            
            # Check for occlusion using Image RLE
            if img_run_start >= img_run_end:
                continue

            # Process non-skipped voxels
            for k in range(run['Length']):
                voxel_data = run['VoxelData'][k]
                scalar = voxel_data['Value']
                opacity = sotf[scalar]
                
                # Compute resampling weights (bilinear, constant for slice)
                # Gather from two adjacent voxel scanlines
                weights = [0.5, 0.5] # Standard bilinear weights for translation shear
                
                # Map to intermediate image pixel
                img_x = img_run_start + k
                if img_x < img_start or img_x >= img_end:
                    continue
                
                # Back-to-front compositing
                old_color, old_alpha = intermediate_image[img_x]
                new_alpha = old_alpha + opacity * (1.0 - old_alpha)
                new_color = (old_color * old_alpha + scalar * opacity * (1.0 - old_alpha)) / new_alpha if new_alpha > 0 else scalar
                
                intermediate_image[img_x] = (new_color, new_alpha)
                
                # Update Image RLE if pixel becomes opaque
                if new_alpha > opacity_threshold and not img_opaque[img_x]:
                    img_opaque[img_x] = True
                    # Find next non-opaque pixel for offset
                    next_idx = img_x + 1
                    while next_idx < img_end and img_opaque[next_idx]:
                        next_idx = img_offset[next_idx]
                    img_offset[img_x] = next_idx

    # Warp intermediate image to screen
    final_image = [intermediate_image[i] for i in range(screen_width * screen_height)]
    return final_image
```

## Operating characteristics
*   **Time Complexity:** Proportional to the number of non-transparent, non-occluded voxels. The RLE skips transparent voxels and occluded pixels, reducing the effective work significantly for sparse volumes [S2].
*   **Memory Complexity:** Requires storing three RLE encodings (one per axis). The encoded volume is typically much smaller than the original volume because transparent voxels are not stored [S1, unofficial].
*   **Performance:** Achieves sub-second rendering times for moderately-sized datasets [S3].
*   **Strengths:** High performance for parallel projections with fixed transfer functions. Early ray termination via image RLE offsets [S2].
*   **Limitations:**
    *   Requires a fixed opacity transfer function; recomputing RLE is necessary if the classification function changes [S4].
    *   Image quality degrades at off-axis views due to the fixed interpolation distance (DVRI) varying from 1.0 (axis-aligned) to 1.73 (corner-on), potentially violating the Nyquist theorem [S3].
    *   Effectiveness of opaque pixel skipping depends on the coherence of opaque regions [S2].
    *   Interactive transfer function variation is challenging due to the opacity-encoded volume requirement [S3].

## Background
The algorithm was developed by Lacroute and Levoy as part of the Shear-Warp factorization framework [S1, unofficial]. It is a core component of the VTK (Visualization Toolkit) volume rendering module, specifically `vtkVolumeShearWarpMapper` [S4]. The method is designed to leverage the coherence of volume data and image space to accelerate rendering on CPUs [S2].
