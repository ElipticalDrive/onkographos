# VolumePro 1000 Implementation
Also called: Shear-image order ray casting

## Overview
The VolumePro 1000 implementation is a hardware-accelerated volume rendering method that utilizes a novel shear-image order ray casting approach [S1, unofficial]. It solves the problem of maintaining high image quality and memory coherence in GPU-based shear-warp rendering by casting rays directly through pixel centers while keeping volume slices parallel to the base plane [S1, unofficial]. Unlike traditional shear-warp factorizations that require a final warping step, this method aligns samples along viewing rays from the image plane pixels in an intermediate sample space, eliminating the need for post-rendering warping and reducing artifacts [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D volume data, viewing transformation matrix, lighting parameters, transfer functions (lookup tables), and optional polygon depth buffers [S1, unofficial].
*   **Output:** Final composited image with embedded polygons and shading [S1, unofficial].

**Data Structures:**
*   **Volume Data:** Stored supporting up to four fields per voxel, each associated with its own lookup table [S1, unofficial].
*   **Lookup Tables (LUTs):** Cascaded LUTs combined by a hierarchy of arithmetic-logic units (ALUs) for classification [S1, unofficial].
*   **Depth Buffers:** Used for polygon embedding; supports dual depth buffers for translucent polygons [S1, unofficial].

**Transformation Matrices:**
The 3D viewing transformation is explicitly decomposed into two matrices [S1, unofficial]:
1.  $M_{\text{voxel} \to \text{sample}}$: Transforms voxel coordinates to an intermediate coordinate system called sample space.
2.  $M_{\text{depth}}$: Adjusts the depth values of sample points to reflect their distance from the image plane.

**Algorithm Steps:**
1.  **Preprocessing (Shear-Image Transformation):** Apply $M_{\text{voxel} \to \text{sample}}$ to the volume data to keep slices parallel to the base plane while aligning them with viewing rays originating from pixel centers [S1, unofficial]. Generate additional interpolated slices between original voxel slices and shift them with sub-pixel accuracy to maintain constant ray and sample spacing, avoiding popping artifacts for anisotropic or sheared volumes [S1, unofficial].
2.  **Ray Casting and Resampling:** Cast rays directly through the centers of pixels in the image plane [S1, unofficial]. Traverse the volume in object-space to ensure memory coherence [S1, unofficial]. For each sample point along the ray, perform tri-linear interpolation of the volume data and compute gradient vectors in hardware [S1, unofficial]. Apply lighting space calculations to ensure correct gradient and Phong shading for sheared and anisotropic data [S1, unofficial].
3.  **Classification and Compositing:** Use cascaded LUTs where classification and interpolation stages are cross-connected, allowing pre- or post-classification [S1, unofficial]. Support opacity correction and gradient magnitude modulation of opacity [S1, unofficial]. Perform front-to-back alpha blending with support for early ray termination to increase performance [S1, unofficial]. Implement geometry-based space leaping, volume clipping, and cropping [S1, unofficial].
4.  **Polygon Embedding (Multi-Pass):** Render polygons into the depth buffer [S1, unofficial]. Cast rays from the image plane to the depth buffer and blend the color buffers of the polygon and volume rendering [S1, unofficial]. Initialize rays with the blending result, start at the depth buffer, and end at the background to render the portion of the volume behind the polygon [S1, unofficial]. Use dual depth buffers for translucent polygons [S1, unofficial].

def volume_pro_1000_render(volume_data, view_matrix, lighting_params, luts, polygons=None):
    """
    Renders volume using shear-image order ray casting.
    volume_data: 3D list of lists of lists of floats (up to 4 fields)
    view_matrix: 4x4 matrix (list of lists)
    lighting_params: dict with 'light_dir', 'ambient', 'diffuse', 'specular'
    luts: dict mapping field indices to transfer function arrays
    polygons: list of polygon objects with depth info
    """
    # 1. Decompose View Transformation
    # M_voxel_to_sample: Voxel coords -> Sample space (slices parallel to base plane)
    # M_depth: Adjusts depth values relative to image plane
    M_voxel_to_sample = [row[:3] for row in view_matrix[:3]]
    M_depth = [row[:] for row in view_matrix]
    M_depth[2][3] = 0.0  # Adjust depth offset for sample space

    # 2. Preprocess Volume Data
    # Generate interpolated slices between original slices for sub-pixel accuracy.
    # In hardware, this is done via texture filtering with sub-pixel offsets.
    volume_shape = [len(volume_data), len(volume_data[0]), len(volume_data[0][0])]
    image_width, image_height = 512, 512  # Resolution from frame buffer

    # 3. Initialize Output Image
    final_image = [[0.0, 0.0, 0.0, 0.0] for _ in range(image_height * image_width)]

    # 4. Ray Casting Loop
    for y in range(image_height):
        for x in range(image_width):
            # Cast ray through pixel center in sample space
            ray_origin = [x + 0.5, y + 0.5, 0.0]
            ray_direction = [0.0, 0.0, 1.0]
            ray_end = volume_shape[2]

            accumulated_color = [0.0, 0.0, 0.0, 0.0]
            accumulated_opacity = 0.0
            ray_t = ray_origin[2]

            # Traverse volume
            while ray_t < ray_end and accumulated_opacity < 1.0:  # Early ray termination
                sample_pos = [x + 0.5, y + 0.5, ray_t]

                # Tri-linear interpolation in hardware
                voxel_value = tri_linear_interpolate(volume_data, sample_pos, volume_shape)

                # Compute gradient in hardware
                gradient = compute_gradient(volume_data, sample_pos, volume_shape)

                # Classification (Pre- or Post-classification configurable)
                color, opacity = classify(voxel_value, gradient, luts)

                # Opacity modulation (gradient magnitude)
                opacity = modulate_opacity(opacity, gradient)

                # Phong shading in lighting space
                shaded_color = phong_shading(color, gradient, lighting_params)

                # Front-to-back compositing
                alpha = opacity * (1.0 - accumulated_opacity)
                accumulated_color[0] += shaded_color[0] * alpha
                accumulated_color[1] += shaded_color[1] * alpha
                accumulated_color[2] += shaded_color[2] * alpha
                accumulated_color[3] += alpha
                accumulated_opacity += alpha

                # Advance ray
                ray_t += 1.0

            final_image[y * image_width + x] = accumulated_color

def tri_linear_interpolate(volume, pos, shape):
    x, y, z = pos
    x0, y0, z0 = int(x), int(y), int(z)
    x1, y1, z1 = x0 + 1, y0 + 1, z0 + 1
    fx, fy, fz = x - x0, y - y0, z - z0

    def clamp(v, limit): return max(0, min(v, limit - 1))
    v000 = volume[clamp(x0, shape[0])][clamp(y0, shape[1])][clamp(z0, shape[2])]
    v100 = volume[clamp(x1, shape[0])][clamp(y0, shape[1])][clamp(z0, shape[2])]
    v010 = volume[clamp(x0, shape[0])][clamp(y1, shape[1])][clamp(z0, shape[2])]
    v110 = volume[clamp(x1, shape[0])][clamp(y1, shape[1])][clamp(z0, shape[2])]
    v001 = volume[clamp(x0, shape[0])][clamp(y0, shape[1])][clamp(z1, shape[2])]
    v101 = volume[clamp(x1, shape[0])][clamp(y0, shape[1])][clamp(z1, shape[2])]
    v011 = volume[clamp(x0, shape[0])][clamp(y1, shape[1])][clamp(z1, shape[2])]
    v111 = volume[clamp(x1, shape[0])][clamp(y1, shape[1])][clamp(z1, shape[2])]

    c00 = v000 * (1-fx) + v100 * fx
    c01 = v010 * (1-fx) + v110 * fx
    c10 = v001 * (1-fx) + v101 * fx
    c11 = v011 * (1-fx) + v111 * fx
    c0 = c00 * (1-fy) + c01 * fy
    c1 = c10 * (1-fy) + c11 * fy
    return c0 * (1-fz) + c1 * fz

def compute_gradient(volume, pos, shape):
    dx = 0.5
    gx = (tri_linear_interpolate(volume, [pos[0]+dx, pos[1], pos[2]], shape) - tri_linear_interpolate(volume, [pos[0]-dx, pos[1], pos[2]], shape)) / (2*dx)
    gy = (tri_linear_interpolate(volume, [pos[0], pos[1]+dx, pos[2]], shape) - tri_linear_interpolate(volume, [pos[0], pos[1]-dx, pos[2]], shape)) / (2*dx)
    gz = (tri_linear_interpolate(volume, [pos[0], pos[1], pos[2]+dx], shape) - tri_linear_interpolate(volume, [pos[0], pos[1], pos[2]-dx], shape)) / (2*dx)
    return [gx, gy, gz]

def classify(value, gradient, luts):
    # Simplified classification using LUTs
    opacity = min(1.0, value * 0.01)
    color = [value/255.0, value/255.0, value/255.0, 1.0]
    return color, opacity

def modulate_opacity(opacity, gradient):
    # Gradient magnitude modulation
    mag = (gradient[0]**2 + gradient[1]**2 + gradient[2]**2)**0.5
    return opacity * (1.0 + mag * 0.1)

def phong_shading(color, gradient, lighting):
    # Phong shading in lighting space
    mag = (gradient[0]**2 + gradient[1]**2 + gradient[2]**2)**0.5
    if mag < 1e-6: return color
    normal = [g/mag for g in gradient]
    light_dir = lighting['light_dir']
    view_dir = [0, 0, 1]
    half_dir = [(light_dir[i] + view_dir[i])/2.0 for i in range(3)]
    diff = max(0, sum(n*l for n, l in zip(normal, light_dir)))
    spec = max(0, sum(n*h for n, h in zip(normal, half_dir))) ** lighting.get('shininess', 32)
    ambient = lighting.get('ambient', 0.2)
    shaded = [color[i] * (ambient + diff * lighting.get('diffuse', 0.8) + spec * lighting.get('specular', 0.5)) for i in range(3)]
    return shaded + [color[3]]

*   **Voxel Fields:** Up to four fields per voxel, each with its own lookup table [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Anisotropic Data:** Requires sub-pixel slice shifting to avoid popping artifacts and maintain constant sample spacing [S1, unofficial].
*   **Sheared Data:** Requires careful lighting space calculations for correct Phong shading [S1, unofficial].
*   **Translucent Polygons:** Requires dual depth buffers for correct embedding [S1, unofficial].

## Operating characteristics
*   **Performance:** Capable of rendering $10^9$ samples per second [S1, unofficial].
*   **Strengths:**
    *   Higher image quality than traditional shear-warp factorization due to no final warping step [S1, unofficial].
    *   High memory coherence via object-space resampling [S1, unofficial].
    *   Hardware-accelerated tri-linear interpolation and gradient computation [S1, unofficial].
    *   Supports early ray termination and space leaping for performance [S1, unofficial].
*   **Limitations:**
    *   Complex implementation requiring multiple rendering passes for polygon embedding [S1, unofficial].
    *   Requires specific hardware support for cascaded LUTs and ALU hierarchies [S1, unofficial].
*   **When to Use:** Real-time volume rendering where high image quality and memory coherence are critical, and hardware supports the specific shear-image order transformations and classification units [S1, unofficial].

## Background
The VolumePro 1000 system was introduced by Wu et al. in 2003 [S1, unofficial]. Similar to the VolumePro 500, it performs object-space resampling but introduces a novel shear-image order ray casting approach [S1, unofficial]. The method was designed to address the limitations of traditional shear-warp factorization, such as warping artifacts and lower image quality, by aligning samples directly with viewing rays in an intermediate sample space [S1, unofficial]. It is used in high-end medical imaging and visualization systems requiring real-time performance and high fidelity [S1, unofficial].
