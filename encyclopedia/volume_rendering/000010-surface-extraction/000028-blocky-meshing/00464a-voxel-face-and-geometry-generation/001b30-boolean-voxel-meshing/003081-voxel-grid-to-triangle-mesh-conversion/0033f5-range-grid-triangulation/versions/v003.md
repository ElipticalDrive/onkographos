# Range Grid Triangulation
## Overview
Range Grid Triangulation converts a 2D range grid, where each grid cell points to a 3D vertex or is invalid, into a triangular mesh [S1, unofficial]. It handles invalid vertices by constructing triangles only from valid corners and chooses diagonal directions to minimize sliver triangles [S1, unofficial].

## How it works
**Inputs:**
- `grid`: A 1D array of integers. `grid[i]` is the index of the 3D vertex corresponding to grid cell `i`, or `GRID_INVALID` if the cell is empty/invalid [S1, unofficial].
- `vertices`: A list of 3D points indexed by the integers stored in `grid` [G].
- `width`, `height`: Integer dimensions of the 2D grid [G].
- `remove_slivers`: Boolean flag (default `true`) indicating whether to remove degenerate 'sliver' triangles after triangulation [S1, unofficial].

**Outputs:**
- A list of triangles, where each triangle is defined by three 3D vertex indices [S1, unofficial].

**Data Structures:**
- `GRID_INVALID`: An implementation-defined constant representing an invalid vertex index (typically `-1`) [G].

**Steps:**
1. **Count valid triangles:** Iterate over all grid quads [S1, unofficial]. A quad is defined by four vertices: `ll` (lower-left), `lr` (lower-right), `ul` (upper-left), `ur` (upper-right) [S1, unofficial]. Count the number of valid vertices (`nvalid`) in each quad (where `grid[index] != GRID_INVALID`) [S1, unofficial]. If `nvalid == 4`, add 2 to the total triangle count (`ntris`) [S1, unofficial]. If `nvalid == 3`, add 1 to `ntris` [S1, unofficial].
2. **Create triangles for quads with 4 valid vertices:** Calculate squared Euclidean distances for both diagonals: $d_{ll\_ur} = \|v_{ll} - v_{ur}\|^2$ and $d_{lr\_ul} = \|v_{lr} - v_{ul}\|^2$ [S1, unofficial]. If $d_{ll\_ur} < d_{lr\_ul}$, create triangles `(ll, lr, ur)` and `(ll, ur, ul)` [S1, unofficial]. Otherwise, create `(ll, lr, ul)` and `(lr, ur, ul)` [S1, unofficial].
3. **Create triangles for quads with 3 valid vertices:** Identify the missing vertex (the one with `grid[index] < 0` or `== GRID_INVALID`) [S1, unofficial]. If `ll` is missing, create triangle `(lr, ur, ul)` [S1, unofficial]. If `lr` is missing, create triangle `(ll, ur, ul)` [S1, unofficial]. If `ul` is missing, create triangle `(ll, lr, ur)` [S1, unofficial]. If `ur` is missing, create triangle `(ll, lr, ul)` [S1, unofficial].
4. **Remove slivers:** If `remove_slivers` is `true` and the face list is not empty, call `remove_sliver_faces` to clean up degenerate triangles [S1, unofficial].

**Parameters:**
- `remove_slivers`: Boolean flag (default `true`) [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Invalid Vertices:** The algorithm explicitly handles quads with 3 valid vertices by creating a single triangle from the valid corners [S1, unofficial].
- **Sliver Triangles:** Degenerate triangles may be created during triangulation [S1, unofficial]. The `remove_sliver_faces` step is used to clean these up [S1, unofficial].
- **Boundary Conditions:** Iteration must stop at `width - 2` and `height - 2` to avoid out-of-bounds access when forming quads [G].

**Pseudocode:**
```python
def range_grid_triangulation(grid, vertices, width, height, remove_slivers=True):
    """
    Convert a 2D range grid to a triangular mesh.
    
    Args:
        grid: List[int], 1D array where grid[i] is vertex index or GRID_INVALID.
        vertices: List[Vec3], 3D points corresponding to vertex indices.
        width: int, grid width.
        height: int, grid height.
        remove_slivers: bool, whether to remove degenerate triangles.
        
    Returns:
        List[Tuple[int, int, int]], list of triangle vertex indices.
    """
    GRID_INVALID = -1  # [G] Standard convention for invalid indices
    triangles = []

    def is_valid(idx):
        return idx != GRID_INVALID

    def dist_sq(v1, v2):
        return (v1[0] - v2[0])**2 + (v1[1] - v2[1])**2 + (v1[2] - v2[2])**2

    for y in range(height - 1):
        for x in range(width - 1):
            ll_idx = y * width + x
            lr_idx = y * width + (x + 1)
            ul_idx = (y + 1) * width + x
            ur_idx = (y + 1) * width + (x + 1)

            ll_v = grid[ll_idx]
            lr_v = grid[lr_idx]
            ul_v = grid[ul_idx]
            ur_v = grid[ur_idx]

            nvalid = sum(is_valid(v) for v in [ll_v, lr_v, ul_v, ur_v])

            if nvalid == 4:
                d1 = dist_sq(vertices[ll_v], vertices[ur_v])
                d2 = dist_sq(vertices[lr_v], vertices[ul_v])
                if d1 < d2:
                    triangles.append((ll_v, lr_v, ur_v))
                    triangles.append((ll_v, ur_v, ul_v))
                else:
                    triangles.append((ll_v, lr_v, ul_v))
                    triangles.append((lr_v, ur_v, ul_v))
            elif nvalid == 3:
                if not is_valid(ll_v):
                    triangles.append((lr_v, ur_v, ul_v))
                elif not is_valid(lr_v):
                    triangles.append((ll_v, ur_v, ul_v))
                elif not is_valid(ul_v):
                    triangles.append((ll_v, lr_v, ur_v))
                elif not is_valid(ur_v):
                    triangles.append((ll_v, lr_v, ul_v))

    if remove_slivers and triangles:
        triangles = remove_sliver_faces(triangles, vertices)
    return triangles

def remove_sliver_faces(triangles, vertices):
    """Remove degenerate triangles with near-zero area. [G]"""
    valid = []
    for t in triangles:
        v0, v1, v2 = vertices[t[0]], vertices[t[1]], vertices[t[2]]
        # Cross product magnitude squared (2 * area)^2
        cross_x = (v1[1] - v0[1]) * (v2[2] - v0[2]) - (v1[2] - v0[2]) * (v2[1] - v0[1])
        cross_y = (v1[2] - v0[2]) * (v2[0] - v0[0]) - (v1[0] - v0[0]) * (v2[2] - v0[2])
        cross_z = (v1[0] - v0[0]) * (v2[1] - v0[1]) - (v1[1] - v0[1]) * (v2[0] - v0[0])
        if cross_x**2 + cross_y**2 + cross_z**2 > 1e-9:
            valid.append(t)
    return valid
```
