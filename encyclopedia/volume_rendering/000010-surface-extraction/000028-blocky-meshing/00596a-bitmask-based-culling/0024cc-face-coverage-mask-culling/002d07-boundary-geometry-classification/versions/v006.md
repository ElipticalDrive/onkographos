# Boundary Geometry Classification


## Overview
Boundary Geometry Classification is a geometric filtering step used during octree construction and neighbor-based culling to distinguish surface geometry located on voxel cell boundary planes from internal geometry within complex blocks [S1, unofficial]. It solves the problem where neighbor occlusion tests would incorrectly interact with internal fragments of non-manifold or complex shapes by ensuring that culling logic only applies to polygons strictly lying on the six faces of the current voxel cell [S1, unofficial]. It sets itself apart from sibling methods like [Face Coverage Mask Culling](3397-face-coverage-mask-culling.md) by operating at the individual polygon level to identify which geometry is eligible for neighbor interaction, rather than determining how to cull based on coverage masks [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A set of vertices defining a single polygon, the axis of the cell boundary plane being tested, the coordinate value of that plane, and a tolerance epsilon [S1, unofficial].
- Output: A boolean indicating whether the polygon lies on the boundary plane [S1, unofficial].

**Data Structures:**
- `vertices`: An array of 3D vectors (`Vec3`) [S1, unofficial].
- `axis`: An integer index (0, 1, or 2) corresponding to the x, y, or z axis [S1, unofficial].
- `plane`: A floating-point scalar representing the coordinate value of the cell boundary [S1, unofficial].
- `eps`: A small floating-point tolerance value [S1, unofficial].

**Steps:**
1. Check if all vertices of the polygon lie on the same cell boundary plane within the tolerance `eps` [S1, unofficial].
2. If the condition holds, classify the polygon as a boundary polygon; otherwise, classify it as internal [S1, unofficial].

**Formulas:**
For a vertex $v$ and axis $a \in \{0, 1, 2\}$:
$$ |v_{axis} - plane| \le \epsilon $$
The polygon is a boundary polygon if:
$$ \forall v \in \text{vertices}, \quad |v_{axis} - plane| \le \epsilon $$

**Parameters:**
- `eps`: A small tolerance value used to determine if a vertex lies on the boundary plane [S1, unofficial]. Typical values are not given in the sources.

**Edge Cases and Pitfalls:**
- **Chunk Borders:** Chunk borders are not special semantically; a face on the edge of a chunk still has a normal voxel neighbor, and the mesher benefits from a read-only neighborhood view rather than embedding chunk-transition logic [S1, unofficial].
- **Precision:** Not given in the sources.
- **Degenerate Input:** Not given in the sources.

**Pseudocode:**
```python
def lies_on_boundary(vertices, axis, plane, eps):
    """
    Classify a polygon as a boundary polygon by checking if all its vertices
    lie on the same cell boundary plane within a small tolerance.
    """
    for v in vertices:
        if abs(v[axis] - plane) > eps:
            return False
    return True
```

## Background
Originating from techniques for face culling in voxel cube and partial shape rendering, this method was developed to optimize the rendering of complex shapes by separating boundary-relevant geometry from internal geometry [S1, unofficial]. It addresses the limitation of simple boolean solid flags, which are insufficient for partial shapes with mixed visible/hidden areas on a single face, by providing a geometric criterion for neighbor interaction eligibility [S1, unofficial].
