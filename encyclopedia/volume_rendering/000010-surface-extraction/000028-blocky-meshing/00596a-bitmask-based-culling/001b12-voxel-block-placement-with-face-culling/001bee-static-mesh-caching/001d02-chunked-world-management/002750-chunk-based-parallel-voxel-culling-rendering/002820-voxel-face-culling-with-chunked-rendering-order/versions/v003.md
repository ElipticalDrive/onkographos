# Voxel Face Culling with Chunked Rendering Order

Also called: Camera-relative Chunk Iteration, Chunked Rendering Order, Neighbor-based Face Culling

## Overview
Voxel Face Culling with Chunked Rendering Order is a surface extraction technique that eliminates interior geometry by emitting mesh faces for solid voxels only when adjacent to an empty voxel or chunk boundary, while traversing the world in a camera-relative front-to-back order to optimize GPU depth sorting [S1, S2, unofficial]. It sets itself apart from standard blocky meshing by combining neighbor-based face culling with a spatial traversal order that prioritizes visible geometry, reducing overdraw and improving rendering performance compared to arbitrary chunk iteration [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D array of chunks, where each chunk contains a 3D array of voxels. Each voxel has an `index` field (0 represents empty/air, non-zero represents solid). Each chunk has metadata including `Allocated` (bool), `IsDirty` (bool), and a GPU buffer `voxelBuffer`.
*   **Output:** A set of mesh faces (vertices, indices, normals, UVs) for the visible surface of the voxel world, submitted to the GPU.

**Data Structures:**
*   **Voxel:** Contains at least an `index` field (byte/uint8). `index == 0` implies air [S1, unofficial].
*   **Chunk:** Contains `Allocated` (bool), `voxels` (pointer to 3D array or flattened 1D array), `WorldPos` (vec3), `IsDirty` (bool), `fake` (bool), and `voxelBuffer` (GPU buffer handle) [S1, unofficial].
*   **Constants:**
    *   `ChunkSize`: Linear dimension of a voxel chunk in voxels (e.g., 16) [S1, unofficial].
    *   `ChunkSizeM1`: `ChunkSize - 1` [S1, unofficial].
    *   `ChunkSizeSquared`: `ChunkSize * ChunkSize` [S1, unofficial].
    *   `ACCESS_STEP_X`: Stride for moving along the X axis in the flattened voxel array [S1, unofficial].
    *   `ACCESS_STEP_Y`: Stride for moving along the Y axis [S1, unofficial].
    *   `ACCESS_STEP_Z`: Stride for moving along the Z axis [S1, unofficial].

**Algorithm Steps:**

1.  **Calculate Camera-Relative Chunk Iteration Bounds:**
    Determine the traversal order for chunks based on the camera's look vector to process front-facing chunks first [S1, unofficial].
    *   Let `ChunkAmountX`, `ChunkAmountZ` be the number of chunks in X and Z dimensions.
    *   If `lookAt.X > 0`: `startX = 0`, `endX = ChunkAmountX`, `xStep = 1`, `xAccessStep = ChunkSize`.
    *   Else: `startX = ChunkAmountX - 1`, `endX = -1`, `xStep = -1`, `xAccessStep = -ChunkSize`.
    *   Repeat logic for Z axis to determine `startZ`, `endZ`, `zStep`, `zAccessStep`.
    *   Iterate through chunks using these parameters to traverse the `meshChunks` array [S1, unofficial].

2.  **Iterate Chunks:**
    For each chunk `c` in the calculated order:
    *   If `c` is null, skip.
    *   If `c.IsDirty` is false, skip (assuming mesh is up-to-date) [S1, unofficial].
    *   If `c.voxelBuffer` is not null, bind and draw it [S1, unofficial].
    *   If `c` is dirty, regenerate the mesh by calling `MeshChunk(c)` [S1, unofficial].

3.  **Mesh Chunk (`MeshChunk`):**
    For a given dirty chunk `c`:
    *   Initialize mesh data structures (vertices, indices, etc.) [S2, unofficial].
    *   Iterate through every voxel in the chunk's block array using nested loops for dimensions `i` (X), `j` (Y), and `k` (Z) [S2, unofficial].
        *   Note: The block array may include an extra row/column (`sectionSide + 1`) to handle inter-chunk edges [S2, unofficial].
    *   For each voxel at `(i, j, k)`:
        *   If `voxel.index == 0` (AIR), skip [S2, unofficial].
        *   For each of the 6 face directions (XN, XP, YN, YP, ZN, ZP):
            *   Check if the neighbor voxel in that direction is air using `CheckIfNeighborIsAir` [S2, unofficial].
            *   **Neighbor Check Logic:**
                *   If the neighbor is inside the current chunk, access it directly using strides [S1, unofficial].
                *   If the neighbor is outside the current chunk (boundary voxel):
                    *   Fetch the voxel from the neighboring chunk's data pointer [S1, unofficial].
                    *   If the neighboring chunk is unallocated (`!neighborChunk.Allocated`), treat the neighbor as empty (air) and render the face [S1, unofficial].
                    *   If the neighboring chunk is allocated, access the voxel at the corresponding boundary index (e.g., for XN, access `neighborChunk.voxels[(ChunkSize - 1) * ChunkSizeSquared + j + k * ChunkSize]`) [S1, unofficial].
                *   **Edge Ownership/Pitfall Handling:**
                    *   Checks between blocks at the very edge (e.g., `j == sectionSide` and `newJ == sectionSide`) may be ignored to prevent double-rendering or recursive checks between chunks [S2, unofficial].
                    *   Neighbors outside the array bounds (e.g., `newI > sectionSide * sectionSide`) are treated as non-air (solid) to prevent holes at chunk edges [S2, unofficial].
            *   If the neighbor is air, call `AddVoxelFace` to generate the geometry for that specific face [S2, unofficial].
    *   Upload the generated mesh data to `c.voxelBuffer` and mark `c.IsDirty` as false [S1, S2, unofficial].

**Pseudocode:**

```python
def render_world(camera_look_vector, chunks):
    # 1. Calculate camera-relative iteration order
    chunk_amount_x = len(chunks[0])
    chunk_amount_z = len(chunks[0][0])
    
    if camera_look_vector.x > 0:
        start_x, end_x, step_x = 0, chunk_amount_x, 1
        x_access_step = Constants.ChunkSize
    else:
        start_x, end_x, step_x = chunk_amount_x - 1, -1, -1
        x_access_step = -Constants.ChunkSize
        
    if camera_look_vector.z > 0:
        start_z, end_z, step_z = 0, chunk_amount_z, 1
        z_access_step = Constants.ChunkSize
    else:
        start_z, end_z, step_z = chunk_amount_z - 1, -1, -1
        z_access_step = -Constants.ChunkSize

    # 2. Iterate chunks in order
    for x in range(start_x, end_x, step_x):
        for z in range(start_z, end_z, step_z):
            for y in range(len(chunks[x][z])): # Assuming Y is height
                chunk = chunks[x][z][y]
                if chunk is None:
                    continue
                if not chunk.is_dirty:
                    if chunk.voxel_buffer is not None:
                        bind_and_draw(chunk.voxel_buffer)
                    continue
                
                # 3. Mesh the chunk if dirty
                mesh_data = mesh_chunk(chunk)
                if mesh_data is not None:
                    chunk.voxel_buffer = upload_to_gpu(mesh_data)
                    chunk.is_dirty = False
                    bind_and_draw(chunk.voxel_buffer)

def mesh_chunk(chunk):
    vertices = []
    indices = []
    # Initialize other mesh attributes (normals, UVs, etc.)
    
    # Iterate through voxels
    # Note: section_side may be ChunkSize or ChunkSize-1 depending on implementation
    section_side = Constants.ChunkSize - 1 
    for i in range(Constants.ChunkSize):
        for j in range(Constants.ChunkSize):
            for k in range(Constants.ChunkSize):
                voxel = chunk.voxels[i][j][k]
                
                # Skip air
                if voxel.index == 0:
                    continue
                
                # Check 6 neighbors
                for direction in [XN, XP, YN, YP, ZN, ZP]:
                    if check_if_neighbor_is_air(chunk, voxel, i, j, k, direction):
                        add_voxel_face(vertices, indices, voxel, direction)
                        
    return create_mesh(vertices, indices)

def check_if_neighbor_is_air(chunk, voxel, i, j, k, direction):
    # Determine neighbor coordinates and chunk
    ni, nj, nk = i, j, k
    neighbor_chunk = chunk
    
    if direction == XN:
        ni = i - 1
        if ni < 0:
            neighbor_chunk = chunk.chunk_xn
            ni = Constants.ChunkSize - 1
    elif direction == XP:
        ni = i + 1
        if ni >= Constants.ChunkSize:
            neighbor_chunk = chunk.chunk_xp
            ni = 0
    elif direction == YN:
        nj = j - 1
        if nj < 0:
            neighbor_chunk = chunk.chunk_yn
            nj = Constants.ChunkSize - 1
    elif direction == YP:
        nj = j + 1
        if nj >= Constants.ChunkSize:
            neighbor_chunk = chunk.chunk_yp
            nj = 0
    elif direction == ZN:
        nk = k - 1
        if nk < 0:
            neighbor_chunk = chunk.chunk_zn
            nk = Constants.ChunkSize - 1
    elif direction == ZP:
        nk = k + 1
        if nk >= Constants.ChunkSize:
            neighbor_chunk = chunk.chunk_zp
            nk = 0
            
    # Handle unallocated neighbor chunks
    if neighbor_chunk is None or not neighbor_chunk.allocated:
        return True # Treat as air
        
    # Access neighbor voxel
    # Note: Exact indexing depends on flattened array layout
    neighbor_voxel = get_voxel_at(neighbor_chunk, ni, nj, nk)
    
    # Handle edge cases for array bounds if using padded arrays
    # If neighbor is outside valid array bounds, treat as solid to prevent holes [S2, unofficial]
    # This is implementation-specific, but generally:
    if neighbor_voxel is None:
        return False # Treat as solid
        
    return neighbor_voxel.index == 0

def get_voxel_at(chunk, i, j, k):
    # Assuming 3D array access for clarity
    return chunk.voxels[i][j][k]
```

## Subtopics

### Voxel Face Culling with Unknown Voxel Default to Air
Treats voxels in unloaded or unknown chunks as air during mesh generation, allowing immediate culling of inner faces at chunk boundaries [S3, unofficial]. During mesh generation, if a neighbor voxel is unloaded or unknown, it is treated as air [S3, unofficial]. The face is culled if the treated neighbor is solid (which it isn't, so the face is rendered) [S3, unofficial]. This is used as a fallback strategy in voxel engines to handle dynamic chunk loading without blocking mesh generation [S3, unofficial]. The pitfall is that edge chunks may render slightly incorrect geometry temporarily, but this is acceptable if chunks load in sufficient numbers simultaneously [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(V)$ where $V$ is the number of visible voxels, as each voxel is checked against 6 neighbors. Chunk iteration is $O(C)$ where $C$ is the number of chunks.
*   **Memory Complexity:** $O(V)$ for storing the mesh data. Chunk storage is $O(C \cdot ChunkSize^3)$.
*   **Performance:** Reduces GPU overdraw by only rendering visible faces [S2, unofficial]. Camera-relative iteration improves cache locality and depth sorting efficiency [S1, unofficial].
*   **Strengths:** Eliminates interior geometry, reducing draw calls and fill rate [S2, unofficial]. Handles dynamic chunk loading with fallback strategies [S3, unofficial].
*   **Limitations:** Requires neighbor chunk access, which can be complex at boundaries [S1, unofficial]. Edge chunks may render incorrect geometry if neighbors are not loaded [S3, unofficial].
*   **When to use:** Real-time voxel rendering where performance is critical and chunks are dynamically loaded/unloaded [S2, S3, unofficial].
*   **When not to use:** Static scenes where pre-computed meshes are feasible, or when neighbor access is prohibitively expensive.

## Background
Originated in voxel game development, particularly in Minecraft-like engines, to optimize rendering of large voxel worlds [S2, unofficial]. The technique of treating unknown voxels as air is a common heuristic in online voxel games to handle chunk streaming [S3, unofficial]. Implemented in various engines, including Unreal Engine 5 clones [S2, unofficial] and custom C++ renderers [S1, unofficial].
