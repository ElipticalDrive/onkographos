# Voxel Face Culling with Chunked Rendering Order

Also called: Camera-relative Chunk Iteration, Chunked Rendering Order, Neighbor-based Face Culling

## Overview
This method generates mesh faces for solid voxels only when they are adjacent to an empty voxel or a chunk boundary, iterating through world chunks in a camera-relative front-to-back order to optimize GPU depth sorting [S1, unofficial]. It eliminates interior geometry by ensuring only visible faces reach the GPU, preventing non-visible geometry from being processed [S2, unofficial]. Unlike standard static meshing, it dynamically handles chunk boundaries by treating unallocated neighbor chunks as empty space, allowing for immediate culling of inner faces at chunk edges [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D array of chunks, where each chunk contains a block array of voxels. Each voxel has an `index` field (0 indicates empty/air) [S1, unofficial]. Camera position and look vector.
*   **Output:** A set of GPU buffers (`voxelBuffer`) containing mesh geometry for visible faces, submitted for rendering.

**Data Structures:**
*   **Voxel:** Contains at least an `index` field (integer/byte). `index == 0` denotes air [S1, unofficial].
*   **Chunk:** Contains `Allocated` (boolean indicating if the chunk's voxel data is valid), `voxels` (pointer or array to the voxel block data), `WorldPos` (3D vector representing the chunk's position in world space), `IsDirty` (boolean flag indicating if the mesh needs regeneration), `fake` (boolean flag), and `voxelBuffer` (GPU buffer holding the generated mesh geometry) [S1, unofficial].
*   **Constants:** `ChunkSize` (linear dimension of a voxel chunk in voxels), `ChunkSizeM1` (`ChunkSize - 1`, used for boundary indexing within a chunk), and `ChunkSizeSquared` (`ChunkSize * ChunkSize`, used for 2D chunk stride calculations) [S1, unofficial].

**Algorithm Steps:**

1.  **Calculate Camera-Relative Chunk Iteration Bounds:**
    Determine the traversal order for chunks based on the camera's look vector to render front-to-back [S1, unofficial].
    *   Let $L$ be the camera look vector.
    *   If $L.x > 0$:
        *   $startX = 0$
        *   $endX = ChunkAmountX$
        *   $xStep = 1$
        *   $xAccessStep = ChunkSize$
    *   Else:
        *   $startX = ChunkAmountX - 1$
        *   $endX = -1$
        *   $xStep = -1$
        *   $xAccessStep = -ChunkSize$
    *   Repeat logic for Z axis ($startZ, endZ, zStep, zAccessStep$) [S1, unofficial].

2.  **Iterate Chunks:**
    Loop through the 1D `meshChunks` array using the calculated bounds and steps [S1, unofficial].
    *   For each chunk $c$:
        *   If $c$ is null, skip.
        *   If $c.IsDirty$ is false, skip [S1, unofficial].
        *   Call `MeshChunk(c)` to generate geometry [S1, unofficial].
        *   Bind and draw $c.voxelBuffer$ if not null [S1, unofficial].

3.  **MeshChunk(c) - Voxel Face Culling:**
    Iterate through every voxel in the chunk's block array using nested loops for dimensions $i$ (X), $j$ (Y), and $k$ (Z) [S1, S2, unofficial].
    *   For each voxel at $(i, j, k)$:
        *   If $voxel.index == 0$ (AIR), skip [S2, unofficial].
        *   For each of the 6 face directions $d \in \{XN, XP, YN, YP, ZN, ZP\}$:
            *   Determine the neighbor voxel's location.
            *   If the neighbor is inside the current chunk, access it directly from the block array [S1, unofficial].
            *   If the neighbor is outside the current chunk (boundary voxel):
                *   Identify the neighboring chunk $c_{neighbor}$ in direction $d$.
                *   If $c_{neighbor}$ is unallocated (null or `Allocated == false`), treat the neighbor as empty (AIR) and render the face [S1, unofficial].
                *   If $c_{neighbor}$ is allocated, fetch the voxel from $c_{neighbor}$'s data pointer. The specific offset depends on the direction (e.g., for $XN$, access the last X layer of the neighbor chunk) [S1, unofficial].
            *   If the neighbor voxel is empty ($index == 0$), call `AddVoxelFace` to generate geometry for that specific face [S2, unofficial].

**Pseudocode:**

```python
class Voxel:
    def __init__(self, index):
        self.index = index

class Chunk:
    def __init__(self, allocated, voxels, world_x, world_z, world_chunks):
        self.allocated = allocated
        self.voxels = voxels
        self.world_x = world_x
        self.world_z = world_z
        self.world_chunks = world_chunks
        self.is_dirty = False
        self.voxel_buffer = []

def render_chunks(camera_look, chunks, chunk_amount_x, chunk_amount_z, chunk_size):
    if camera_look.x > 0:
        start_x, end_x, x_step, x_access_step = 0, chunk_amount_x, 1, chunk_size
    else:
        start_x, end_x, x_step, x_access_step = chunk_amount_x - 1, -1, -1, -chunk_size

    if camera_look.z > 0:
        start_z, end_z, z_step, z_access_step = 0, chunk_amount_z, 1, chunk_size
    else:
        start_z, end_z, z_step, z_access_step = chunk_amount_z - 1, -1, -1, -chunk_size

    for z in range(start_z, end_z, z_step):
        for x in range(start_x, end_x, x_step):
            chunk = get_chunk_at(chunks, x, z)
            if chunk is None:
                continue
            if not chunk.is_dirty:
                continue
            mesh_chunk(chunk, chunk_size)
            if chunk.voxel_buffer:
                draw_buffer(chunk.voxel_buffer)

def mesh_chunk(chunk, chunk_size):
    chunk_size_m1 = chunk_size - 1
    chunk_size_squared = chunk_size * chunk_size
    chunk.voxel_buffer = []

    for k in range(chunk_size):
        for i in range(chunk_size):
            for j in range(chunk_size):
                idx = i + j * chunk_size + k * chunk_size_squared
                voxel = chunk.voxels[idx]
                
                if voxel.index == 0:
                    continue

                directions = [
                    ('XN', -1, 0, 0), ('XP', 1, 0, 0),
                    ('YN', 0, -1, 0), ('YP', 0, 1, 0),
                    ('ZN', 0, 0, -1), ('ZP', 0, 0, 1)
                ]

                for dir_name, dx, dy, dz in directions:
                    neighbor_voxel = get_neighbor_voxel(chunk, i, j, k, dx, dy, dz, chunk_size)
                    
                    if neighbor_voxel is None or neighbor_voxel.index == 0:
                        chunk.voxel_buffer.append(create_face(chunk, i, j, k, dir_name))

def get_chunk_at(chunks, x, z):
    for c in chunks:
        if c.world_x == x and c.world_z == z:
            return c
    return None

def get_neighbor_voxel(chunk, i, j, k, dx, dy, dz, chunk_size):
    ni, nj, nk = i + dx, j + dy, k + dz
    if 0 <= ni < chunk_size and 0 <= nj < chunk_size and 0 <= nk < chunk_size:
        idx = ni + nj * chunk_size + nk * (chunk_size * chunk_size)
        return chunk.voxels[idx]
    
    neighbor_chunk = get_chunk_at(chunk.world_chunks, chunk.world_x + dx, chunk.world_z + dz)
    
    if neighbor_chunk is None or not neighbor_chunk.allocated:
        return None
    
    if dx == -1:
        local_i, local_j, local_k = chunk_size - 1, j, k
    elif dx == 1:
        local_i, local_j, local_k = 0, j, k
    elif dy == -1:
        local_i, local_j, local_k = i, chunk_size - 1, k
    elif dy == 1:
        local_i, local_j, local_k = i, 0, k
    elif dz == -1:
        local_i, local_j, local_k = i, j, chunk_size - 1
    else:
        local_i, local_j, local_k = i, j, 0
        
    local_idx = local_i + local_j * chunk_size + local_k * (chunk_size * chunk_size)
    return neighbor_chunk.voxels[local_idx]
```

**Edge Cases and Pitfalls:**
*   **Boundary Access:** Boundary voxels must correctly access neighbor chunks. If a neighbor chunk is unallocated, the face is rendered immediately, treating the out-of-bounds region as empty space [S1, unofficial].
*   **Double Rendering/Recursion:** Checks between blocks at the very edge of adjacent chunks (e.g., $j==sectionSide$ and neighbor $j==sectionSide$) must be handled carefully to prevent double-rendering or recursive checks. Some implementations ignore checks between blocks at the very edge to prevent this [S2, unofficial].
*   **Array Bounds:** The block array may include an extra row/column (size $sectionSide+1$) to handle inter-chunk edges. Neighbors outside the array bounds are treated as non-air (solid) to prevent holes at chunk edges in some implementations, while others treat unallocated chunks as air [S2, unofficial].

## Subtopics

### Voxel Face Culling with Unknown Voxel Default to Air
Treats voxels in unloaded or unknown chunks as air during mesh generation, allowing immediate culling of inner faces at chunk boundaries [S3, unofficial]. During mesh generation, if a neighbor voxel is unloaded or unknown, it is treated as air. The face is emitted if the treated neighbor is air, which is a fallback strategy in voxel engines to handle dynamic chunk loading without blocking mesh generation [S3, unofficial]. The pitfall is that edge chunks may render slightly incorrect geometry temporarily, but this is acceptable if chunks load in sufficient numbers simultaneously [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. Each voxel is checked against 6 neighbors [S2, unofficial].
*   **Memory Complexity:** Not given in the sources. Each chunk stores its voxel data and a GPU buffer for mesh geometry [S1, unofficial].
*   **Performance:** Eliminates interior geometry, significantly reducing the number of triangles sent to the GPU [S2, unofficial]. Mesh generation runs asynchronously on a thread pool to prevent frame drops [S2, unofficial].
*   **Strengths:** Efficient culling of non-visible geometry; handles dynamic chunk loading by treating unknown neighbors as air; camera-relative ordering optimizes rendering order.
*   **Limitations:** Requires careful handling of chunk boundaries to avoid holes or double rendering; dynamic updates require efficient dirty-flag management and asynchronous meshing [S2, S3, unofficial].

## Background
This technique is commonly used in voxel-based games and simulations, such as Minecraft clones, where efficient rendering of large, dynamic worlds is critical. It builds on the principles of blocky meshing and chunk-based management. The specific implementation details, such as camera-relative iteration and neighbor-based culling, are found in various community-driven voxel engine projects and tutorials [S1, S2, S3, unofficial].
