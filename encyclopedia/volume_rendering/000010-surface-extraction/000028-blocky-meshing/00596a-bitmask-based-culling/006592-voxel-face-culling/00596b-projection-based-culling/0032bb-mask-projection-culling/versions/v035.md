# Mask Projection Culling

Also called: Depth-Projected Mesh Culling, Mesh Culling via Mask Projection, point mask culling

## Overview
Mask Projection Culling is a visibility-based mesh filtering technique that removes faces and vertices not consistently observed across multiple camera poses by projecting points into camera space and comparing their depth against rendered depth maps or binary masks [S1, S2, unofficial]. It differs from [Voxel Backface Culling and Internal Face Masking](4569-voxel-backface-culling-and-internal-face-masking.md) by operating on explicit mesh geometry in screen space rather than voxel occupancy, and from [Mesh Culling via 3D Projection and Connected Components](6963-mesh-culling-via-3d-projection-and-connected-components.md) by relying on per-pixel depth/mask sampling rather than global connected component analysis [S1, S2, unofficial].

## How it works
**Inputs:**
- A triangular mesh (vertices $V$, faces $F$).
- A set of $V$ camera poses (world-to-camera matrices $W_i$) and intrinsic matrices $K_i$.
- Optional: Binary masks $M_i$ for each view (e.g., from segmentation or background removal).
- Optional: Rendered depth maps $D_i$ for each view.

**Outputs:**
- A filtered mesh containing only vertices and faces visible in a sufficient number of views.

**Data Structures:**
- `vertices`: Tensor of shape $(N, 3)$, where $N$ is the number of vertices.
- `faces`: Tensor of shape $(M, 3)$, where $M$ is the number of faces, storing vertex indices.
- `valid_counts`: Tensor of shape $(N,)$, initialized to zero, counting valid observations per vertex.
- `depth_maps`: Tensor of shape $(V, H, W)$, storing depth values for each view.
- `masks`: Tensor of shape $(V, H, W)$, storing binary mask values for each view.

**Parameters:**
- `eps`: Depth comparison tolerance. Typical value: $0.005$ [S2, unofficial].
- `points_batch_size`: Maximum number of points processed per batch to limit GPU memory. Typical value: $5 \times 10^5$ [S2, unofficial].
- `min_visible_frames`: Minimum number of frames a vertex must be visible in. Typical value: $20$ [S2, unofficial].
- `mask_dilation_radius`: Radius for morphological dilation of binary masks. Typical value: $24$ [S1, unofficial].
- `image_dimensions`: Width $W=1600$, Height $H=1200$ [S1, unofficial].

**Steps:**

1. **Load Camera Parameters:**
   - Extract world-to-camera matrices $W_i$ and intrinsic matrices $K_i$ for each view $i \in [0, V-1]$.
   - If using OpenCV/OpenGL coordinate mismatch, flip Y and Z axes of the camera pose: $W_i[:3, 1:3] *= -1$ [S2, unofficial].

2. **Render Depth Maps (if not provided):**
   - For each view $i$, render the mesh to a depth map $D_i$ using an offscreen renderer with flags `DEPTH_ONLY` and `SKIP_CULL_FACES` [S2, unofficial].

3. **Load Masks (if provided):**
   - Load binary masks $M_i$ from image files. Convert to float tensors [S1, unofficial].

4. **Project and Sample Visibility:**
   - For each vertex $v$ with world coordinates $p_v$:
     - Transform to camera space: $p_{cam} = W_i \cdot p_v$.
     - Project to 2D: $p_{uv} = K_i \cdot p_{cam}$.
     - Perform homogeneous division: $u = p_{uv}[0] / p_{uv}[2]$, $v = p_{uv}[1] / p_{uv}[2]$, $z = p_{uv}[2]$ [S1, S2, unofficial].
     - Check frustum bounds: $in\_frustum = (0 \le u < W) \land (0 \le v < H) \land (z > 0)$ [S2, unofficial].
     - If $in\_frustum$ is true:
       - **Mask-based Culling:**
         - Normalize UV to NDC $[-1, 1]$: $u_{ndc} = \frac{u}{W-1} \cdot 2 - 1$, $v_{ndc} = \frac{v}{H-1} \cdot 2 - 1$ [S1, S2, unofficial].
         - If using binary masks: Dilate $M_i$ with a disk of radius `mask_dilation_radius`. Sample $M_i$ at $(u_{ndc}, v_{ndc})$ using nearest-neighbor interpolation. If sampled value $> 0$, the vertex is visible in this view [S1, unofficial].
       - **Depth-based Culling:**
         - Sample depth $d_{sample}$ from $D_i$ at $(u_{ndc}, v_{ndc})$ using bilinear interpolation with border padding [S2, unofficial].
         - Check if vertex is in front of surface: $is\_front = (z < d_{sample} + eps)$ [S2, unofficial].
         - If $is\_front$ is true, the vertex is visible in this view.
     - If visible, increment `valid_counts[v]` [S2, unofficial].

5. **Filter Mesh:**
   - Identify valid vertices: $V_{valid} = \{v \mid valid\_counts[v] \ge min\_visible\_frames\}$ [S2, unofficial].
   - Identify valid faces: $F_{valid} = \{f \in F \mid \text{all vertices in } f \in V_{valid}\}$ [S1, unofficial].
   - Construct new mesh with $V_{valid}$ and $F_{valid}$ [S1, unofficial].

6. **Post-processing:**
   - Transform vertices back to world space if necessary (e.g., applying scale factors) [S1, unofficial].
   - Export the filtered mesh.

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def mask_projection_culling(mesh, cameras, depth_maps=None, masks=None, eps=0.005, min_visible_frames=20, mask_dilation_radius=24):
    """
    mesh: dict with 'vertices' (N, 3) and 'faces' (M, 3)
    cameras: list of dicts with 'w2c' (4, 4) and 'K' (3, 3)
    depth_maps: list of tensors (H, W)
    masks: list of tensors (H, W)
    """
    vertices = mesh['vertices'].cuda()
    faces = mesh['faces']
    num_vertices = vertices.shape[0]
    num_views = len(cameras)
    
    # Initialize visibility counts
    valid_counts = torch.zeros(num_vertices, dtype=torch.int32, device=vertices.device)
    
    # Process in batches to limit memory
    batch_size = 500000
    for start in range(0, num_vertices, batch_size):
        end = min(start + batch_size, num_vertices)
        batch_vertices = vertices[start:end]
        
        for i in range(num_views):
            w2c = cameras[i]['w2c'].cuda()
            K = cameras[i]['K'].cuda()
            
            # Transform to camera space
            # Add homogeneous coordinate
            batch_vertices_homo = torch.cat([batch_vertices, torch.ones(batch_vertices.shape[0], 1, device=vertices.device)], dim=1)
            cam_coords = torch.matmul(w2c, batch_vertices_homo.t()) # (4, batch_size)
            cam_coords = cam_coords.t() # (batch_size, 4)
            
            # Project to 2D
            uv = torch.matmul(K, cam_coords[:, :3].t()).t() # (batch_size, 3)
            z = uv[:, 2:3] + 1e-8
            uv_xy = uv[:, :2] / z
            
            # Normalize to NDC [-1, 1]
            W, H = 1600, 1200
            u_ndc = (uv_xy[:, 0] / (W - 1)) * 2.0 - 1.0
            v_ndc = (uv_xy[:, 1] / (H - 1)) * 2.0 - 1.0
            
            # Check frustum bounds
            in_frustum = (u_ndc > -1.0) & (u_ndc < 1.0) & (v_ndc > -1.0) & (v_ndc < 1.0) & (z.squeeze() > 0)
            
            if masks is not None:
                # Mask-based culling
                mask = masks[i].cuda()
                # Dilate mask (simplified, assuming pre-dilated or using a library)
                # In practice, use morphology.binary_dilation with radius 24
                # For pseudocode, assume mask is already dilated
                vgrid = torch.stack([u_ndc, v_ndc], dim=-1).unsqueeze(0).unsqueeze(0) # (1, 1, batch_size, 2)
                # Sample mask
                # Note: grid_sample expects (N, C, H, W) or (N, C, W, H) depending on version
                # Here we assume standard PyTorch grid_sample with align_corners=True
                sampled_mask = F.grid_sample(mask.unsqueeze(0).unsqueeze(0), vgrid, mode='nearest', padding_mode='zeros', align_corners=True)
                sampled_mask = sampled_mask.squeeze()
                visible = sampled_mask > 0.0
            else:
                # Depth-based culling
                depth_map = depth_maps[i].cuda()
                vgrid = torch.stack([u_ndc, v_ndc], dim=-1).unsqueeze(0).unsqueeze(0)
                sampled_depth = F.grid_sample(depth_map.unsqueeze(0).unsqueeze(0), vgrid, mode='bilinear', padding_mode='border', align_corners=True)
                sampled_depth = sampled_depth.squeeze()
                visible = (z.squeeze() < sampled_depth + eps)
            
            # Update valid counts for visible vertices in this view
            visible_indices = torch.where(in_frustum)[0]
            visible_vertices = visible[visible_indices]
            global_indices = start + visible_indices[visible_vertices]
            valid_counts[global_indices] += 1
            
    # Filter vertices
    valid_vertices_mask = valid_counts >= min_visible_frames
    valid_vertex_indices = torch.where(valid_vertices_mask)[0]
    
    # Filter faces
    # Create a mapping from old vertex indices to new ones
    # For simplicity, we just filter faces where all vertices are valid
    face_vertices = faces[valid_vertex_indices] # This is incorrect logic, need to check all faces
    # Correct logic:
    valid_faces_mask = valid_vertices_mask[faces].all(dim=1)
    valid_faces = faces[valid_faces_mask]
    
    # Re-index vertices
    vertex_map = torch.full((num_vertices,), -1, dtype=torch.long, device=vertices.device)
    vertex_map[valid_vertex_indices] = torch.arange(len(valid_vertex_indices), device=vertices.device)
    new_faces = vertex_map[valid_faces]
    
    new_vertices = vertices[valid_vertex_indices]
    
    return {'vertices': new_vertices.cpu(), 'faces': new_faces.cpu()}
```

## Subtopics

### True Back-Face Culling via Group Masking
A back-face culling technique that splits chunk meshes into 6 vertex pool buckets based on face orientation (groups 0-5). Draw calls are masked based on camera position relative to the chunk, preventing the draw call from being issued entirely rather than culling in the fragment shader [S3, unofficial]. It is chosen when driver overhead must be minimized compared to splitting chunks into 6 sub-meshes [S3, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \cdot V \cdot B)$, where $N$ is the number of points, $V$ is the number of validation frames, and $B$ is the batch size [S2, unofficial].
- **Memory Complexity:** $O(N \cdot V)$ for intermediate masks and valid counts [S2, unofficial].
- **Strengths:** Effective at removing invisible geometry, reducing rendering load. Works well with multiple views.
- **Limitations:** Requires pre-computed depth maps or masks. Sensitive to coordinate system mismatches. Performance degrades with large numbers of views or high-resolution depth maps.
- **When to use:** When a set of camera poses is available and visibility filtering is needed for optimization or rendering.
- **When not to use:** When real-time culling is required without pre-computation, or when camera poses are unknown.

## Background
Mask Projection Culling is used in 3D reconstruction and rendering pipelines, particularly in Gaussian Splatting and NeRF-based methods, to filter out noisy or invisible geometry [S1, S2, unofficial]. It was popularized in the context of 2D Gaussian Splatting for efficient mesh extraction [S1, unofficial].
