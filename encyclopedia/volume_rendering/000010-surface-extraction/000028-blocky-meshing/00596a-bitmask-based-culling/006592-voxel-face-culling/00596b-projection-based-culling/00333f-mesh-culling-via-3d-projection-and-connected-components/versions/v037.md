# Mesh Culling via 3D Projection and Connected Components

Also called: Mesh Culling via Multi-View Depth Projection, cull with 3d projection

## Overview
This method removes geometric artifacts and occluded geometry from a 3D mesh (typically extracted from unbounded Gaussian splatting) by projecting its vertices into multiple camera views and validating visibility against reference depth maps [S1, unofficial]. It distinguishes itself from sibling methods by explicitly classifying points as "seen," "unseen," or "forecast" based on multi-view consistency, rather than relying solely on voxel occupancy or single-view backface culling [S1, unofficial]. It serves as a robust cleanup step for meshes containing floating artifacts or disconnected noise .

## How it works
**Inputs:**
- A triangular mesh $M = (V, F)$, where $V$ is the set of vertices and $F$ is the set of faces.
- A list of camera poses $C = \{c2w_i\}_{i=1}^N$ and intrinsic parameters $K = \text{diag}(f_x, f_y, 1), (c_x, c_y, 0)$.
- Reference depth maps $D_i$ for each camera pose (extracted from the source representation or rendered from the mesh itself).
- Parameters: `points_batch_size` (default $5 \times 10^5$), `eps` (default $0.005$), `remove_small_geometry_threshold` (default $0.2$), `forecast_radius` (default $0$, optional).

**Outputs:**
- A culled mesh $M'$ with removed faces and unreferenced vertices.

**Data Structures:**
- `valid`: Boolean tensor of shape $(N_{pts})$, initialized to zero. Marks vertices seen in $\ge 20$ cameras.
- `valid_num`: Integer tensor of shape $(N_{pts})$, initialized to zero. Counts valid projections per vertex.
- `face_mask`: Boolean array of shape $(N_{faces})$. True if all three vertices of a face are visible.

**Steps:**

1. **Initialize Masks:**
   Create `valid`, `valid_num`, and `valid_forecast` tensors of shape $(|V|)$ on the target device, initialized to zero [S1, unofficial].

2. **Iterate Camera Poses:**
   For each camera pose $c2w_i$ in $C$:
   a. **Coordinate Transformation:**
      Adjust the camera coordinate system by negating the y and z rows of the rotation matrix:
      $$ c2w_i[:3, 1:3] \leftarrow -c2w_i[:3, 1:3] $$
      Compute the world-to-camera matrix:
      $$ w2c_i = c2w_i^{-1} $$
      [S1, unofficial]

   b. **Project Vertices:**
      For a batch of vertices $V_{batch}$ (size $\le$ `points_batch_size`):
      i. Convert to homogeneous coordinates by appending ones: $v_h = [v, 1]^T$.
      ii. Transform to camera space: $v_c = w2c_i \cdot v_h$.
      iii. Extract the first three rows to get $(x_c, y_c, z_c)$.
      iv. Apply intrinsic matrix $K$ to project to UV coordinates:
          $$ u = f_x \frac{x_c}{z_c} + c_x $$
          $$ v = f_y \frac{y_c}{z_c} + c_y $$
          [S1, unofficial]

   c. **Frustum and Depth Validation:**
      i. **Frustum Check:**
         Determine if the point is within the standard frustum:
         $$ \text{in\_frustum} = (0 \le u < W) \land (0 \le v < H) \land (z_c > 0) $$
         If `forecast_radius` $> 0$, also check an expanded frustum:
         $$ \text{forecast\_frustum} = (-r \le u < W+r) \land (-r \le v < H+r) \land (z_c > 0) $$
         [S1, unofficial]

      ii. **Depth Sampling:**
         Reshape reference depth $D_i$ to $(1, 1, H, W)$. Normalize UV grid to $[-1, 1]$ for bilinear interpolation. Sample depth at $(u, v)$:
         $$ d_{sample} = \text{grid\_sample}(D_i, (u, v), \text{padding\_mode}=\text{'border'}) $$
         [S1, unofficial]

      iii. **Front-Face Validation:**
         A point is considered "seen" if it is in the frustum and the sampled depth is closer than the vertex depth (within tolerance):
         $$ \text{is\_front\_face} = (d_{sample} > 0) \land (z_c < d_{sample} + \epsilon) $$
         [S1, unofficial]

      iv. **Update Masks:**
         For points satisfying `is_front_face`:
         $$ \text{valid\_num} \leftarrow \text{valid\_num} + 1 $$
         [S1, unofficial]

3. **Finalize Vertex Visibility:**
   After processing all cameras, classify vertices:
   $$ \text{valid} = (\text{valid\_num} \ge 20) $$
   This requires the vertex to be consistently visible in at least 20 different camera views [S1, unofficial].

4. **Face Culling:**
   Create a face mask by checking if all vertices of each face are valid:
   $$ \text{face\_mask} = \text{valid}[F].\text{all}(\text{axis}=1) $$
   Update the mesh with the face mask and remove unreferenced vertices:
   $$ M' = M.\text{update\_faces}(\text{face\_mask}).\text{remove\_unreferenced\_vertices}() $$
   [S1, unofficial]

5. **Optional Connected Component Filtering (Forecast):**
   If `forecast_radius` $> 0$:
   a. Create a `forecast_mask` for vertices visible in the expanded frustum but not the standard one.
   b. Compute the Oriented Bounding Box (OBB) of the culled mesh vertices.
   c. Keep only forecast faces whose vertices lie within this OBB.
   d. Filter remaining components by area: keep components where $\text{area} > \text{threshold} \times \text{global\_area}$, or keep only the largest component if `get_largest_components` is True.
   [S1, unofficial]

**Pseudocode:**

```python
def cull_mesh_by_3d_projection(mesh, cameras, depth_maps, params):
    """
    Cull mesh geometry based on multi-view depth projection.
    
    Args:
        mesh: Triangle mesh object with .vertices and .faces attributes.
        cameras: List of dicts with 'c2w' (4x4 matrix), 'K' (3x3 matrix), 'H', 'W'.
        depth_maps: List of depth maps (H, W) corresponding to cameras.
        params: Dict with 'eps', 'min_views', 'forecast_radius', 'small_geo_threshold'.
    
    Returns:
        Culled mesh.
    """
    vertices = mesh.vertices
    faces = mesh.faces
    n_verts = len(vertices)
    
    # Initialize masks
    valid_num = torch.zeros(n_verts, dtype=torch.int32, device=vertices.device)
    
    batch_size = params.get('points_batch_size', 500000)
    eps = params.get('eps', 0.005)
    min_views = params.get('min_views', 20)
    forecast_radius = params.get('forecast_radius', 0)
    
    # Process vertices in batches
    for i in range(0, n_verts, batch_size):
        batch_verts = vertices[i:i+batch_size]
        batch_valid_num = torch.zeros(len(batch_verts), dtype=torch.int32, device=vertices.device)
        
        for cam, depth_map in zip(cameras, depth_maps):
            c2w = cam['c2w']
            K = cam['K']
            H, W = cam['H'], cam['W']
            
            # Coordinate transformation
            c2w_adj = c2w.clone()
            c2w_adj[:3, 1:3] *= -1
            w2c = torch.inverse(c2w_adj)
            
            # Project to camera space
            ones = torch.ones(len(batch_verts), 1, device=vertices.device)
            verts_homo = torch.cat([batch_verts, ones], dim=1) # (N, 4)
            verts_cam = (w2c @ verts_homo.T).T # (N, 4)
            z_c = verts_cam[:, 2]
            
            # Project to UV
            x_c = verts_cam[:, 0]
            y_c = verts_cam[:, 1]
            
            # Avoid division by zero
            z_safe = z_c + 1e-8
            u = K[0, 0] * (x_c / z_safe) + K[0, 2]
            v = K[1, 1] * (y_c / z_safe) + K[1, 2]
            
            # Frustum check
            in_frustum = (u >= 0) & (u < W) & (v >= 0) & (v < H) & (z_c > 0)
            
            if forecast_radius > 0:
                r = forecast_radius
                forecast_frustum = (u >= -r) & (u < W + r) & (v >= -r) & (v < H + r) & (z_c > 0)
            else:
                forecast_frustum = torch.zeros_like(in_frustum, dtype=torch.bool)
            
            # Depth sampling
            # Normalize UV to [-1, 1] for grid_sample
            u_norm = 2.0 * (u / (W - 1)) - 1.0
            v_norm = 2.0 * (v / (H - 1)) - 1.0
            vgrid = torch.stack([u_norm, v_norm], dim=-1).unsqueeze(0).unsqueeze(0) # (1, 1, N, 2)
            
            # Reshape depth map for grid_sample: (1, 1, H, W)
            depth_tensor = torch.from_numpy(depth_map).unsqueeze(0).unsqueeze(0).to(vertices.device)
            
            # Sample depth
            depth_sample = torch.nn.functional.grid_sample(
                depth_tensor, vgrid, 
                padding_mode='border', align_corners=True
            ).squeeze() # (N,)
            
            # Front-face validation
            is_front = (depth_sample > 0.0) & (z_c < depth_sample + eps)
            
            # Combine frustum and front-face check
            valid_proj = in_frustum & is_front
            batch_valid_num[valid_proj] += 1
            
        valid_num[i:i+batch_size] = batch_valid_num
    
    # Finalize vertex visibility
    valid_verts = valid_num >= min_views
    
    # Face culling
    # faces is (N, 3), valid_verts is (N,)
    # Check if all 3 vertices of each face are valid
    face_mask = valid_verts[faces].all(dim=1)
    
    # Update mesh
    mesh.update_faces(face_mask)
    mesh.remove_unreferenced_vertices()
    
    # Optional: Connected component filtering
    if forecast_radius > 0:
        # This part requires specific mesh library support for OBB and component filtering
        # See [S1, unofficial] for details on forecast_mask and OBB logic
        pass
        
    return mesh
```

## Subtopics

### [Mesh Post-Processing (Cluster Filtering)](7002-mesh-post-processing-cluster-filtering.md)
Filters floating artifacts and disconnected components by clustering triangles and retaining only the largest connected clusters. It serves as a cleanup step following this method, targeting small, noisy geometry that survives projection-based culling. Unlike this method which removes occluded or distant geometry, it removes topologically isolated fragments based on triangle count.

## Operating characteristics
- **Time Complexity:** $O(N \cdot V \cdot C)$, where $N$ is the number of vertices, $V$ is the batch size (limited by GPU memory), and $C$ is the number of cameras. The depth sampling is $O(1)$ per vertex per camera using bilinear interpolation.
- **Memory Complexity:** $O(N + C \cdot H \cdot W)$ for storing vertex masks and depth maps.
- **Performance:** The method is efficient for scenes with many cameras (e.g., COLMAP reconstructions) as it leverages parallel projection. However, it requires significant GPU memory for large meshes due to the batch processing of vertices and depth map sampling.
- **Strengths:** Robust against noise and floating artifacts; effectively removes geometry that is not consistently visible across multiple views; handles unbounded scenes well.
- **Limitations:** Requires a sufficient number of camera poses (default $\ge 20$ views for a vertex to be kept); sensitive to depth map accuracy; may remove valid geometry if the camera coverage is sparse or if the depth maps are noisy.
- **When to use:** Ideal for cleaning up meshes extracted from Gaussian Splatting or other implicit representations where multi-view consistency is a strong prior.
- **When not to use:** Not suitable for scenes with very few camera views or where the depth maps are unreliable.

## Background
This method originates from the implementation of "2D Gaussian Splatting for Geometrically Accurate Radiance Fields" [S1, unofficial]. It was developed to address the issue of geometric artifacts in meshes extracted from unbounded Gaussian splatting reconstructions. The method leverages the multi-view nature of the input data to validate geometry, ensuring that only consistent, front-facing surfaces are retained. It is commonly used in conjunction with TSDF fusion and other mesh extraction techniques to improve the quality of the final 3D model.
