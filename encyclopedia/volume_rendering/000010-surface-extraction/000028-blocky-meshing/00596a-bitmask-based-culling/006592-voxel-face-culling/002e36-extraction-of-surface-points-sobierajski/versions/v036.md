# Extraction of Surface Points (Sobierajski)
Also called: Visible boundary voxel extraction

## Overview
A fast display method for direct rendering of boundary surfaces by extracting only visible boundary voxels from volume data [S1, unofficial]. It differs from its siblings by projecting discrete voxel points rather than generating polygonal meshes, using orthographic visibility tests to cull back faces and avoid holes via multi-pixel projection [S1, unofficial].

## How it works
**Inputs:** Volume data (density values), viewing directions (typically six orthographic views).
**Outputs:** List of surface points with attributes (coordinates, normal vectors) passed to a rendering engine.

**Data Structures:**
- `BoundaryVoxelList`: A list of objects. Each object contains:
  - `coords`: 3D integer coordinates $(x, y, z)$ of the voxel.
  - `normal`: 3D vector $(n_x, n_y, n_z)$ representing the surface normal.
  - `density`: Original density value (used for cutting planes).

**Steps:**
1. **Visibility Determination:** Determine visibility using a set of viewing directions. Six orthographic views are sufficient for an approximate set of all potentially visible boundary voxels; increasing the number of directions improves approximation [S1, unofficial].
2. **2D Boundary Tracing:** Perform visibility calculations using a 2D boundary tracing algorithm on slices perpendicular to each coordinate axis [S1, unofficial].
3. **Extraction and Deduplication:** Extract boundary voxels. Remove duplicate elements from the list. Store attributes (coordinates, normal vectors) for each voxel [S1, unofficial].
4. **Back Face Culling:** For a specific viewing direction, reduce the voxel list size. If the dot product of the surface normal $\mathbf{n}$ and the viewing direction $\mathbf{v}$ is positive, the voxel is a back face and is not rendered:
   $$ \mathbf{n} \cdot \mathbf{v} > 0 \implies \text{Cull} $$
   [S1, unofficial].
5. **Projection:** Project each remaining voxel onto several pixels depending on the viewing direction to avoid holes caused by adjacent voxels mapping to non-adjacent pixels [S1, unofficial].
6. **Rendering:** Pass the set of surface points to the rendering engine. Shade projected boundary surface points according to lighting conditions [S1, unofficial].
7. **Cutting Planes (Optional):** Render voxels intersected by cutting planes by projecting their original density values onto the image plane [S1, unofficial].

**Pseudocode:**
```python
def extract_surface_points(volume, viewing_directions):
    boundary_voxels = []
    
    # Step 2: Visibility via 2D boundary tracing on slices
    for axis in ['x', 'y', 'z']:
        slices = get_slices_perpendicular_to_axis(volume, axis)
        for slice_data in slices:
            # Trace boundary in 2D slice
            boundary_in_slice = trace_2d_boundary(slice_data)
            for voxel in boundary_in_slice:
                if voxel not in boundary_voxels:
                    boundary_voxels.append(voxel)
    
    # Step 4: Back face culling for each viewing direction
    visible_voxels = []
    for v_dir in viewing_directions:
        for voxel in boundary_voxels:
            # Calculate dot product of normal and viewing direction
            if dot_product(voxel.normal, v_dir) <= 0:
                visible_voxels.append(voxel)
    
    # Step 5: Project to pixels
    projected_points = []
    for voxel in visible_voxels:
        # Project onto several pixels to avoid holes
        pixels = project_onto_pixels(voxel, viewing_directions)
        for pixel in pixels:
            projected_points.append(pixel)
            
    return projected_points
```

## Subtopics

### [Trimmed Voxel Lists](11309-trimmed-voxel-lists.md)
A surface extraction algorithm that represents an iso-surface using 3D points as geometric primitives, projecting exactly one point per visible surface cell to ensure image coverage without recursive subdivision. It differs from Dividing Cubes by avoiding subdivision; instead, it allows a single projected point to span up to three pixels on the image plane to guarantee coverage.

### Saito's Fast Previewing Algorithm
A previewing algorithm based on extracting a subset of boundary voxels according to a uniform distribution to increase rendering speed [S1, unofficial]. It extracts a subset of boundary voxels, converts them to geometrical primitives like crosslines perpendicular to the surface normal, and projects these primitives onto the image plane [S1, unofficial].

## Operating characteristics
**Time Complexity:** Linear with respect to the number of boundary voxels and viewing directions. The 2D boundary tracing is efficient per slice [S1, unofficial].
**Memory Complexity:** Proportional to the number of visible boundary voxels stored in the list [S1, unofficial].
**Strengths:** Fast direct rendering; flexible manipulation of extracted voxels (e.g., simultaneous shaded isosurface and cross-sectional slice rendering in medical imaging) [S1, unofficial].
**Limitations:** Holes can appear if voxels are not projected onto multiple pixels; approximation of visibility depends on the number of viewing directions [S1, unofficial].
**When to use:** When fast previewing or direct point-based rendering is required, especially in medical imaging contexts [S1, unofficial].
**When not to use:** When high-fidelity polygonal mesh generation is required [S1, unofficial].

## Background
Proposed by Sobierajski [116] as a fast display method for direct rendering of boundary surfaces [S1, unofficial]. It is cited in "Medical Volume Rendering Techniques" [S1, unofficial].
