# Extraction of Surface Points (Sobierajski)
Also called: Visible boundary voxel extraction

## Overview
Extraction of Surface Points is a fast display method for the direct rendering of boundary surfaces by extracting only visible boundary voxels from volume data [S1, unofficial]. It solves the problem of rendering speed in direct volume rendering by avoiding the processing of occluded geometry. It differs from its siblings, which often rely on block-based meshing or precomputed culling, by operating directly on individual voxel boundaries using orthographic visibility tests and 2D boundary tracing [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Volume data (density values), viewing directions (typically six orthographic views), and lighting parameters.
*   **Output:** A list of surface points (boundary voxels) with attributes (coordinates, normal vectors) ready for rendering, and the final image.

**Data Structures:**
*   **Boundary Voxel List:** A list of objects. Each object stores:
    *   `coordinates`: $(x, y, z)$ integer indices of the voxel.
    *   `normal`: Surface normal vector $\mathbf{n}$.
    *   `density`: Original density value (for cutting plane support).
*   **Visibility Grid:** Implicitly handled via 2D boundary tracing on slices.

**Steps:**
1.  **Visibility Determination:** Determine visibility using a set of viewing directions. Six orthographic views are sufficient for an approximate set of potentially visible boundary voxels; increasing the number of directions improves approximation [S1, unofficial].
2.  **2D Boundary Tracing:** Perform visibility calculations using a 2D boundary tracing algorithm on slices perpendicular to each coordinate axis [S1, unofficial].
3.  **Extraction and Deduplication:** Extract boundary voxels. Remove duplicate elements from the generated list. Store attributes (coordinates, normal vectors) for each voxel [S1, unofficial].
4.  **Back-Face Culling:** For a specific viewing direction, reduce the voxel list size. If the dot product of the surface normal $\mathbf{n}$ and the viewing direction $\mathbf{v}$ is positive, the voxel is a back face and is not rendered:
    $$ \mathbf{n} \cdot \mathbf{v} > 0 \implies \text{discard} $$
    [S1, unofficial].
5.  **Projection:** Pass the set of surface points to the rendering engine. Project each voxel onto several pixels depending on the viewing direction to avoid holes caused by adjacent voxels mapping to non-adjacent pixels [S1, unofficial].
6.  **Shading and Cutting Planes:** Shade projected boundary surface points according to lighting conditions. If cutting planes are used, render voxels intersected by the cutting planes by projecting their original density values onto the image plane [S1, unofficial].

## Subtopics

### [Trimmed Voxel Lists](11309-trimmed-voxel-lists.md)
Trimmed Voxel Lists is a surface extraction algorithm that represents an iso-surface using 3D points as geometric primitives, projecting exactly one point per visible surface cell to ensure image coverage without recursive subdivision. It differs from Dividing Cubes by avoiding subdivision; instead, it allows a single projected point to span up to three pixels on the image plane to guarantee coverage.

### Saito's Fast Previewing Algorithm
Saito's Fast Previewing Algorithm is a previewing algorithm based on extracting a subset of boundary voxels according to a uniform distribution to increase rendering speed [S1, unofficial]. It extracts a subset of boundary voxels, converts them to geometrical primitives like crosslines perpendicular to the surface normal, and projects these primitives onto the image plane [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Fast display method for direct rendering; supports flexible manipulation of extracted voxels (e.g., cutting planes); efficient visibility calculation using 2D boundary tracing [S1, unofficial].
*   **Limitations:** May produce holes if not projected to multiple pixels; approximation of visibility depends on the number of viewing directions [S1, unofficial].
*   **When to Use:** When fast previewing or direct rendering of boundary surfaces is required, and approximate visibility is sufficient.
*   **When Not to Use:** When high-fidelity, hole-free rendering is required without projection overhead, or when complex lighting/shading is needed beyond basic shading [S1, unofficial].

## Background
Sobierajski proposed this fast display method for direct rendering of boundary surfaces [S1, unofficial]. It is based on the principle that only visible boundary voxels need to be extracted from volume data. The method is often used in medical imaging systems where cutting operations are important, allowing shaded isosurfaces and arbitrary cross-sectional slices to be rendered simultaneously [S1, unofficial].
