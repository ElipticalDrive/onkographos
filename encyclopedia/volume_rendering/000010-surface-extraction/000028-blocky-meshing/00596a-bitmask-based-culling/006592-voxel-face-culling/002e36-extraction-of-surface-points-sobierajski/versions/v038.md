# Extraction of Surface Points (Sobierajski)
Also called: Visible boundary voxel extraction

## Overview
Extraction of Surface Points is a fast display method for the direct rendering of boundary surfaces by extracting only visible boundary voxels from volume data [S1, unofficial]. It operates directly on individual voxel boundaries using orthographic visibility tests and 2D boundary tracing to determine which voxels to render [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Volume data (density values) and viewing directions (typically six orthographic views) [S1, unofficial].
*   **Output:** A list of surface points (boundary voxels) with attributes (coordinates, normal vectors) passed to the rendering engine, and the final image [S1, unofficial].

**Data Structures:**
*   **Boundary Voxel:** An object storing `coordinates` (integer voxel indices), `normal` (surface normal vector $\mathbf{n}$), and `density` (original density value for cutting plane support) [S1, unofficial].
*   **Visibility Grid:** Implicitly handled via 2D boundary tracing on slices perpendicular to each coordinate axis [S1, unofficial].

**Steps:**
1.  **Visibility Determination:** Determine visibility using a set of viewing directions; six orthographic views are sufficient for an approximate set of potentially visible boundary voxels, and increasing the number of directions improves the approximation [S1, unofficial].
2.  **2D Boundary Tracing:** Perform visibility calculations using a 2D boundary tracing algorithm on slices perpendicular to each coordinate axis [S1, unofficial].
3.  **Extraction and Deduplication:** Extract boundary voxels and remove duplicate elements from the generated list [S1, unofficial].
4.  **Back-Face Culling:** For a specific viewing direction, reduce the voxel list size; if the dot product of the surface normal $\mathbf{n}$ and viewing direction $\mathbf{v}$ is positive, the voxel is a back face and is not rendered:
    $$ \mathbf{n} \cdot \mathbf{v} > 0 \implies \text{discard} $$
    [S1, unofficial].
5.  **Projection:** Pass the set of surface points to the rendering engine; project each voxel onto several pixels depending on the viewing direction to avoid holes caused by adjacent voxels mapping to non-adjacent pixels [S1, unofficial].
6.  **Shading and Cutting Planes:** Shade projected boundary surface points according to lighting conditions; render voxels intersected by cutting planes by projecting their original density values onto the image plane [S1, unofficial].

**Pseudocode:**

def extract_surface_points(volume, viewing_directions):
    """
    Extract visible boundary voxels using Sobierajski's method.
    volume: 3D array of density values.
    viewing_directions: List of 3D vectors (e.g., +/- x, y, z axes).
    Returns: List of dicts with keys 'coords', 'normal', 'density', 'screen_pos'.
    """
    boundary_voxels = []
    
    # Step 2: 2D boundary tracing on slices perpendicular to each axis
    for axis in range(3):
        slice_boundaries = trace_2d_boundaries(volume, axis)
        for voxel in slice_boundaries:
            if voxel not in boundary_voxels:
                boundary_voxels.append(voxel)
                
    # Step 3: Deduplication
    unique_voxels = list(dict.fromkeys(boundary_voxels))
    
    rendered_points = []
    # Step 4 & 5: Culling and Projection for each viewing direction
    for v_dir in viewing_directions:
        visible_voxels = []
        for voxel in unique_voxels:
            normal = compute_normal(voxel, volume)
            
            # Back-face culling
            if dot(normal, v_dir) > 0:
                continue
            visible_voxels.append(voxel)
            
        # Project each voxel to multiple pixels to avoid holes
        for voxel in visible_voxels:
            projected_pixels = project_to_pixels(voxel, v_dir)
            for pixel in projected_pixels:
                rendered_points.append({
                    'coords': voxel['coords'],
                    'normal': voxel['normal'],
                    'density': voxel['density'],
                    'screen_pos': pixel
                })
    return rendered_points

## Subtopics

### [Trimmed Voxel Lists](11309-trimmed-voxel-lists.md)
Trimmed Voxel Lists is a surface extraction algorithm that represents an iso-surface using 3D points as geometric primitives, projecting exactly one point per visible surface cell to ensure image coverage without recursive subdivision. It differs from Dividing Cubes by avoiding subdivision; instead, it allows a single projected point to span up to three pixels on the image plane to guarantee coverage.

### Saito's Fast Previewing Algorithm
Saito's Fast Previewing Algorithm is a previewing algorithm based on extracting a subset of boundary voxels according to a uniform distribution to increase rendering speed [S1, unofficial]. It extracts a subset of boundary voxels, converts them to geometrical primitives like crosslines perpendicular to the surface normal, and projects these primitives onto the image plane [S1, unofficial].

## Background
Sobierajski proposed this fast display method for direct rendering of boundary surfaces [S1, unofficial]. It is based on the principle that only visible boundary voxels need to be extracted from volume data [S1, unofficial]. The method is often used in medical imaging systems where cutting operations are important, allowing shaded isosurfaces and arbitrary cross-sectional slices to be rendered simultaneously [S1, unofficial].
