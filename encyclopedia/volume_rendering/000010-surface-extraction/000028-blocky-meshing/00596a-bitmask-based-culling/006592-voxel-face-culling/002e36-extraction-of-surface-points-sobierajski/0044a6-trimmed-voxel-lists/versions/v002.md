# Trimmed Voxel Lists


## Overview
Trimmed Voxel Lists is a surface extraction algorithm that represents an iso-surface using 3D points as geometric primitives, projecting exactly one point per visible surface cell to ensure image coverage without recursive subdivision [S1, unofficial][S2, unofficial][S3, book]. It differs from Dividing Cubes by avoiding subdivision; instead, it allows a single projected point to span up to three pixels on the image plane to guarantee coverage [S1, unofficial][S2, unofficial][S3, book].

## How it works
**Inputs:**
- Volumetric data grid [S2, unofficial].
- Iso-value threshold [S2, unofficial].
- Camera parameters (view and projection matrices) [G].

**Outputs:**
- A list of visible surface points, each associated with a 3D position and a normal vector [S1, unofficial].

**Data Structures:**
- A list of surface points. Each entry contains:
  - `position`: 3D coordinates $(x, y, z)$ of the point in world space [S1, unofficial].
  - `normal`: 3D normal vector $(n_x, n_y, n_z)$ at that position [S1, unofficial].

**Steps:**
1. **Identify Visible Surface Cells:** Iterate through the volume grid to identify cells intersected by the iso-surface and filter out cells that are not visible from the current camera viewpoint [S2, unofficial].
2. **Select One Point Per Cell:** For each visible surface cell, compute a single representative 3D point on the iso-surface within that cell without subdividing the cell [S1, unofficial][S2, unofficial].
3. **Project to Image Plane:** Project the 3D point and its normal onto the 2D image plane, allowing the point to cover up to three pixels to guarantee coverage [S2, unofficial].

**Pseudocode:**
```python
def trimmed_voxel_lists(volume_data, iso_value, camera):
    surface_points = []
    for cell in volume_data.cells:
        if not is_surface_cell(cell, iso_value):
            continue
        if not is_visible(cell, camera):
            continue
        point = compute_surface_point(cell, iso_value)
        normal = compute_normal(cell, point)
        screen_pos = project_to_screen(point, camera)
        surface_points.append({'position': point, 'normal': normal, 'screen_pos': screen_pos})
    return surface_points
```

**Edge Cases and Pitfalls:**
- **Coverage:** The method relies on projecting a single point to cover up to three pixels [S1, unofficial][S2, unofficial].
- **Accuracy:** Since only one point per cell is used, the approximation of the surface may be less accurate than methods that subdivide cells [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of visible surface cells, as it avoids recursive subdivision [S1, unofficial][S2, unofficial].
- **Memory Complexity:** Proportional to the number of visible surface points, which is typically less than the total number of cells [S2, unofficial].
- **Strengths:** Fast rendering due to no subdivision [S1, unofficial][S2, unofficial].
- **Limitations:** Lower accuracy compared to subdivision-based methods; geometric primitives can only approximate surfaces and may require excessive primitives for adequate approximations [S2, unofficial].
- **When to Use:** Applications requiring efficient surface representation where a trade-off between accuracy and space requirements is acceptable [S2, unofficial].
- **When Not to Use:** Applications requiring high-precision surface geometry where subdivision-based methods are preferred [G].

## Background
The Trimmed Voxel Lists method was introduced as an alternative to Dividing Cubes, which subdivides cells to ensure each subcell projects onto a single pixel [S1, unofficial][S2, unofficial][S3, book]. It is used in volume visualization for efficient surface rendering [S1, unofficial][S2, unofficial][S3, book].
