# Quality Enhancement (Smoothing and Tessellation)

Also called: Detail tessellation, Post-processing smoothing

## Overview
Quality Enhancement refines coarse, blocky meshes extracted from volumetric data to improve visual fidelity and reduce geometric artifacts [S1, unofficial]. It addresses the jagged appearance of initial voxel-based surface extractions by applying smoothing operators and detail tessellation [S1, unofficial]. Unlike pure smoothing techniques, it may include synthetic detail generation and explicit mesh connectivity optimization [S1, unofficial][S2].

## How it works
The method operates on a coarse quadrilateral or triangular mesh derived from voxel data [S1, unofficial]. It consists of two primary phases: smoothing and tessellation, often followed by specific texturing strategies [S1, unofficial].

### Inputs and Outputs
*   **Input:** A coarse mesh (quadrilateral or triangular) extracted from volumetric data [S1, unofficial].
*   **Output:** A refined mesh with smoother surfaces and higher tessellation density, ready for rasterization [S1, unofficial].

### Data Structures
*   **Mesh:** A collection of vertices and faces. For quadrilateral meshes, vertices are stored with position and tangent vectors [S1, unofficial].
*   **Displacement Maps:** Textures used to store high-frequency detail for tessellation [S1, unofficial].
*   **Texture Maps:** Standard color or normal maps [S1, unofficial].

### Steps

1.  **Smoothing (Surface Diffuse Flow and Tangent Movement):**
    For quadrilateral meshes, apply a discrete Laplace operator to smooth the surface [S1, unofficial]. Specifically, use surface diffuse flow for smoothing and add tangent movement for quality improvements [S1, unofficial]. This can be implemented efficiently in parallel [S1, unofficial].
    *   *Formula:* The smoothing step updates vertex positions $P_i$ based on the average of neighboring vertices $N(i)$:
        $$ P_i^{\text{new}} = P_i^{\text{old}} + \lambda \sum_{j \in N(i)} (P_j - P_i) $$
        where $\lambda$ is a smoothing factor. Tangent vectors are updated based on surface flow to maintain orientation [S1, unofficial].
    *   *Parameter:* The "Mesh Smooth" value controls the roughness reduction. A larger value results in slower mesh building but smoother results [S2].

2.  **Tessellation (Catmull-Clark Approximation):**
    Approximate a smooth Catmull-Clark subdivision surface using bicubic patches [S1, unofficial]. This is achieved via a tessellation shader and displacement maps [S1, unofficial].
    *   *Method:* The coarse mesh is subdivided, and displacement maps are applied to the patches to add high-frequency detail [S1, unofficial].
    *   *Texturing:* Use tri-planar texture mapping for displacement maps and texture maps to avoid distortion [S1, unofficial].

3.  **CloudPlane Tessellation (Soft Edges):**
    For cloud layers, divide a quad into nine segments to solve hard edges near the horizon [S3, unofficial].
    *   *Step 1:* Set the four outer vertices of the tessellated quad to ALPHA equal to zero [S3, unofficial].
    *   *Step 2:* Set the four inner vertices of the tessellated quad to ALPHA equal to one [S3, unofficial].
    *   *Step 3:* During rasterization, interpolate the intermediate pixels between outer (0) and inner (1) edges to create smooth alpha transitions [S3, unofficial].
    *   *Step 4:* Combine the interpolated vertex alpha with the alpha value of the applied 2D noise texture to determine the final alpha written to the frame buffer [S3, unofficial].
    *   *Parameters:*
        *   Blending equation: SRC_ALPHA and ONE_MINUS_SRC_ALPHA [S3, unofficial].
        *   Texture filtering: LINEARMIPMAPLINEAR for smoothest antialiasing [S3, unofficial].
        *   Array binding: Color arrays bound BIND PER VERTEX; Normal arrays bound BIND OVERALL [S3, unofficial].
    *   *Pitfall:* Cloud layers must be added in lower-to-upper order to render correctly due to OpenGL transparency management limitations [S3, unofficial].

### Pseudocode

```python
def quality_enhance(mesh, mode='general'):
    """Applies smoothing and tessellation to a mesh."""
    if mode == 'general':
        mesh = apply_smoothing(mesh, smoothing_factor=0.5)
        mesh = tessellate_with_displacement(mesh, displacement_map)
    elif mode == 'cloud':
        mesh = divide_quad_into_9_segments(mesh.quad)
        # Set alpha values for vertices [S3, unofficial]
        for vertex in mesh.outer_vertices:
            vertex.alpha = 0.0
        for vertex in mesh.inner_vertices:
            vertex.alpha = 1.0
        # Rasterization pipeline configuration [S3, unofficial]
        blend_equation = (SRC_ALPHA, ONE_MINUS_SRC_ALPHA)
        texture_filter = LINEARMIPMAPLINEAR
        color_binding = BIND_PER_VERTEX
        normal_binding = BIND_OVERALL
        # Final alpha computation during rasterization [S3, unofficial]
        final_alpha = interpolated_vertex_alpha * noise_texture_alpha
        # Render with lower-to-upper layer order [S3, unofficial]
    return mesh

def apply_smoothing(mesh, smoothing_factor):
    """Parallel smoothing on quadrilateral meshes using surface diffuse flow [S1, unofficial]."""
    new_positions = {}
    for vertex in mesh.vertices:
        neighbor_sum = sum(n.position for n in vertex.neighbors)
        laplacian = neighbor_sum - len(vertex.neighbors) * vertex.position
        new_positions[vertex.id] = vertex.position + smoothing_factor * laplacian
    for vertex in mesh.vertices:
        vertex.position = new_positions[vertex.id]
        # Tangent movement for quality improvements [S1, unofficial]
        vertex.tangent = compute_surface_flow_tangent(vertex)
    return mesh

def tessellate_with_displacement(mesh, displacement_map):
    """Approximate Catmull-Clark subdivision with bicubic patches [S1, unofficial]."""
    subdivided_mesh = catmull_clark_subdivide(mesh, level=1)
    for patch in subdivided_mesh.bicubic_patches:
        # Tri-planar texture mapping for displacement maps [S1, unofficial]
        disp = tri_planar_sample(displacement_map, patch.center)
        patch.vertices = apply_displacement(patch.vertices, disp)
    return subdivided_mesh

def divide_quad_into_9_segments(quad):
    """Divide quad into a 3x3 grid of segments [S3, unofficial]."""
    u_start, u_end = quad.uv_range[0]
    v_start, v_end = quad.uv_range[1]
    vertices = []
    for i in range(3):
        for j in range(3):
            u = u_start + (u_end - u_start) * i / 2.0
            v = v_start + (v_end - v_start) * j / 2.0
            pos = quad.origin + u * quad.u_vec + v * quad.v_vec
            vertices.append(Vertex(position=pos))
    # Assign alpha values [S3, unofficial]
    inner_idx = 4  # Center vertex of 3x3 grid
    for idx, v in enumerate(vertices):
        v.alpha = 1.0 if idx == inner_idx else 0.0
    return Mesh(vertices=vertices)

def compute_surface_flow_tangent(vertex):
    """Compute tangent based on surface flow [S1, unofficial]."""
    return normalize(vertex.tangent)

def catmull_clark_subdivide(mesh, level):
    """Standard Catmull-Clark subdivision [S1, unofficial]."""
    return mesh.subdivide(level)

def tri_planar_sample(texture, point):
    """Standard tri-planar sampling [S1, unofficial]."""
    return texture.sample(point)

def apply_displacement(vertices, displacement):
    """Apply displacement to vertices."""
    return [v + displacement * v.normal for v in vertices]
```

## Subtopics

### [Geometry Post-Processing](13056-geometry-post-processing.md)
Geometry Post-Processing applies filtering, detail generation, and connectivity optimization to blocky meshes extracted from volumetric data to improve visual quality and rendering performance. It addresses the jagged appearance of initial voxel-based surface extractions and optimizes the resulting geometry for rendering pipelines. The method is distinguished from pure smoothing techniques by its inclusion of synthetic detail generation and explicit mesh connectivity optimization, and from pure tessellation methods by its focus on correcting topological artifacts like T-junctions. It consists of Laplacian smoothing, random midpoint displacement, T-junction removal, and triangle strip grouping applied sequentially or selectively.

### Mesh Smooth
Used when Mode is set to Mesh, Ocean Mesh, or Cap Mesh to reduce the roughness of the mesh. The larger the value, the slower the mesh builds [S2].

### CloudPlane Tessellation for Soft Edges
A technique to solve hard edges near the horizon by dividing a cloud layer quad into nine segments with specific alpha values at vertices [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Smoothing is parallelizable and efficient for quadrilateral meshes [S1, unofficial]. Tessellation via shaders is real-time capable [S1, unofficial].
*   **Memory Complexity:** Depends on the resolution of displacement maps and the tessellation level [G].
*   **Strengths:** Improves visual quality by reducing blockiness; handles soft edges for clouds; real-time capable.
*   **Limitations:** Smoothing can be slow if the value is high [S2]. Cloud layers have rendering order constraints [S3, unofficial].
*   **When to use:** When visual quality of voxel-based surfaces is critical and blockiness is unacceptable [G].
*   **When not to use:** When performance is extremely constrained and blocky appearance is acceptable [G].

## Background
The method originates from research on generating smooth high-quality isosurfaces for interactive modeling and visualization [S1, unofficial]. It builds on earlier work in mesh smoothing and subdivision surfaces [S1, unofficial]. The CloudPlane technique is described in the context of simulating clouds with procedural texturing techniques using the GPU [S3, unofficial].
