# Voxel Face Extraction

Also called: Exposed Face Extraction, Solid & ~Shift Face Extraction

## Overview
Voxel Face Extraction generates surface geometry from a 3D voxel grid by identifying exposed faces—voxel sides adjacent to empty space [S1, unofficial]. It operates on a per-chunk basis, iterating through defined face normals to compute a boolean mask of exposed voxels, which are then assembled into a face buffer [S1, unofficial]. As a specific implementation of [Occlusion-Based Face Generation](13226-occlusion-based-face-generation.md), it uses explicit axis-aligned shifts and boundary conditions to determine visibility without ray casting [S1, unofficial].

## How it works
### Inputs and Outputs
- **Input**: A 3D voxel grid `solid` of shape `(depth, height, width)` with dtype `uint8` or `bool`, where non-zero values indicate solid voxels [S1, unofficial]. A list of face normals defined in `geometry.FACE_DATA` [S1, unofficial]. Configuration flags `is_flat_asset` and `settings` (containing `CHUNK_SIZE`, `MAP_DEPTH`, etc.) [S1, unofficial].
- **Output**: A `VoxelAsset` object containing a stacked face buffer array of shape `(N, 19)` with dtype `float32`, and chunk dimensions [S1, unofficial]. If no faces are found, the buffer is empty `(0, 19)` [S1, unofficial].

### Data Structures
- **`solid`**: 3D array representing the voxel chunk [S1, unofficial].
- **`exposed`**: 3D boolean array of the same shape as `solid`, marking voxels with exposed faces for the current normal [S1, unofficial].
- **`assembled_list`**: List of face buffer arrays, each corresponding to a batch of exposed voxels for a specific normal [S1, unofficial].
- **`VoxelAsset`**: Container for the final concatenated face buffer and metadata [S1, unofficial].

### Steps
1. **Initialize**: Create an empty list `assembled_list` [S1, unofficial].
2. **Iterate Normals**: For each face normal `(nx, ny, nz)` in `geometry.FACE_DATA`:
   - **Skip Conditions**: If `nz == -1`, skip this normal [S1, unofficial]. If `is_flat_asset` is true and `nz != 1`, skip this normal [S1, unofficial].
   - **Compute Exposed Mask**:
     - **Case `nz == 1` (Top Face)**: If `depth == 1`, set `exposed = solid.copy()` [S1, unofficial]. Otherwise, compute `z_shift` by rolling `solid` by `-1` along axis 0 (depth) [S1, unofficial]. Set `exposed = solid & ~z_shift` [S1, unofficial]. Force the last slice to be exposed if solid: `exposed[-1, :, :] = solid[-1, :, :]` [S1, unofficial].
     - **Case `nz != 1` (Side Faces)**: Initialize `exposed` to `solid > 0` (corrected from source notes to prevent a zero-mask bug when ANDing with shifts [G]). If `ny != 0`, compute `y_shift` by rolling `solid` by `-ny` along axis 1 (height); else `y_shift = solid` [S1, unofficial]. If `nx != 0`, compute `x_shift` by rolling `solid` by `-nx` along axis 2 (width); else `x_shift = solid` [S1, unofficial]. Update `exposed` by ANDing with `~x_shift` if `nx != 0`, and with `~y_shift` if `ny != 0` [S1, unofficial].
     - **Boundary Conditions**: If `nx == 1`, set `exposed[:, :, -1] = solid[:, :, -1]` [S1, unofficial]. If `nx == -1`, set `exposed[:, :, 0] = solid[:, :, 0]` [S1, unofficial]. If `ny == 1`, set `exposed[:, -1, :] = solid[:, -1, :]` [S1, unofficial]. If `ny == -1`, set `exposed[:, 0, :] = solid[:, 0, :]` [S1, unofficial].
   - **Assemble Faces**: Get indices of exposed voxels using `np.where(exposed)` [S1, unofficial]. If no indices, continue to next normal [S1, unofficial]. Assemble face buffer using chunk indices, full indices, voxel values, current normal, vertex offsets `v_offsets`, and registry [S1, unofficial]. Append result to `assembled_list` [S1, unofficial].
3. **Finalize**: If `assembled_list` is empty, return `VoxelAsset` with empty array `(0, 19)` dtype `float32` and dimensions [S1, unofficial]. Otherwise, concatenate `assembled_list` into `stacked_faces` [S1, unofficial]. Return `VoxelAsset` with `stacked_faces` and dimensions [S1, unofficial].

### Pseudocode
```python
import numpy as np
from dataclasses import dataclass

@dataclass
class VoxelAsset:
    faces: np.ndarray
    dimensions: tuple

def voxel_face_extraction(solid: np.ndarray, is_flat_asset: bool, face_normals: list, v_offsets: list, registry: dict) -> VoxelAsset:
    assembled_list = []
    depth, height, width = solid.shape

    for nx, ny, nz in face_normals:
        # Skip conditions
        if nz == -1:
            continue
        if is_flat_asset and nz != 1:
            continue

        exposed = np.zeros((depth, height, width), dtype=bool)

        if nz == 1:
            if depth == 1:
                exposed = solid > 0
            else:
                z_shift = np.roll(solid, -1, axis=0)
                exposed = (solid > 0) & (z_shift == 0)
                exposed[-1, :, :] = solid[-1, :, :] > 0
        else:
            # Initialize to solid voxels, then mask out neighbors [G]
            exposed = solid > 0
            if nx != 0:
                x_shift = np.roll(solid, -nx, axis=2)
                exposed = exposed & (x_shift == 0)
            if ny != 0:
                y_shift = np.roll(solid, -ny, axis=1)
                exposed = exposed & (y_shift == 0)

            # Boundary conditions
            if nx == 1:
                exposed[:, :, -1] = solid[:, :, -1] > 0
            if nx == -1:
                exposed[:, :, 0] = solid[:, :, 0] > 0
            if ny == 1:
                exposed[:, -1, :] = solid[:, -1, :] > 0
            if ny == -1:
                exposed[:, 0, :] = solid[:, 0, :] > 0

        indices = np.where(exposed)
        if len(indices[0]) == 0:
            continue

        # Buffer assembly logic is not detailed in the sources [G]
        batch_faces = np.empty((len(indices[0]), 19), dtype=np.float32)
        assembled_list.append(batch_faces)

    if not assembled_list:
        return VoxelAsset(np.empty((0, 19), dtype=np.float32), (depth, height, width))

    stacked_faces = np.concatenate(assembled_list, axis=0)
    return VoxelAsset(stacked_faces, (depth, height, width))
```

### Parameters
- `is_flat_asset`: Boolean flag. If true, only top faces (`nz=1`) are generated [S1, unofficial].
- `face_normals`: List of normals `(nx, ny, nz)` to process [S1, unofficial].
- `v_offsets`: Vertex offsets for face assembly [S1, unofficial].
- `registry`: Material ID registry [S1, unofficial].

### Edge Cases and Pitfalls
- **Depth 1**: If `depth == 1`, the `nz=1` case copies `solid` directly to `exposed` [S1, unofficial].
- **Boundary Conditions**: For side faces, the shift logic does not account for chunk boundaries. Explicit boundary conditions are required to ensure voxels on the chunk edge are correctly marked as exposed if they are solid [S1, unofficial].
- **Empty Chunk**: If no exposed voxels are found, an empty `(0, 19)` array is returned [S1, unofficial].
- **Initialization Bug**: The source notes state side faces initialize `exposed` as zeros, but ANDing with shifted masks would keep it zero. The implementation initializes `exposed` to `solid > 0` first to correctly compute exposure [G].

## Operating characteristics
- **Time Complexity**: $O(N)$ where $N$ is the number of voxels in the chunk, as each voxel is processed a constant number of times (once per normal) [S1, unofficial].
- **Memory Complexity**: $O(N)$ for the `exposed` mask and `assembled_list` [S1, unofficial].
- **Performance**: Efficient for dense chunks. Performance degrades if many normals are processed for flat assets (though `is_flat_asset` mitigates this) [S1, unofficial].
- **Strengths**: Simple, deterministic, no ray casting overhead [S1, unofficial].
- **Limitations**: Generates blocky geometry. Does not handle diagonal faces or smooth surfaces [S1, unofficial].

## Background
Voxel Face Extraction is implemented in the `pyvorengi-sdk-demo` repository by herbal1st [S1, unofficial]. It is part of a voxel engine SDK, likely for Minecraft-like terrain generation [S1, unofficial]. The method is a direct implementation of face culling based on neighbor checks [S1, unofficial].
