# Occlusion-Based Face Generation

## Overview
Occlusion-Based Face Generation iterates over all voxels in a chunk and generates face primitives only for sides that are not occluded [S1, unofficial]. It builds on [GPU Face Extraction](3760-gpu-face-extraction.md) and differs from [Validator Reference Face Reconstruction](3794-validator-reference-face-reconstruction.md) by directly producing visible quads per voxel side.

## How it works
**Inputs and Outputs:**
- **Input:** A voxel chunk containing voxel positions, material kinds, occlusion masks, and soft light values.
- **Output:** A vector of face primitives (`faces_vertices`), where each face represents a visible side of a voxel.

**Data Structures:**
- `Chunk::BUFFER_SIZE`: The total number of voxels in the chunk.
- `voxel::SIDE_COUNT`: The number of sides per voxel (6).
- `voxel::SIDES`: An iterable collection of the 6 face normals/directions.
- `voxel::Face`: A struct containing:
  - `vertices`: An array of 4 vertex coordinates (defined by the voxel position and side).
  - `side`: The face normal/direction.
  - `kind`: The material type of the voxel.
  - `light`: The soft light value for the specific side.

**Parameters:**
- `FACES_ESTIMATION`: A capacity hint for the output vector, calculated as `(Chunk::BUFFER_SIZE * voxel::SIDE_COUNT) / 2` [S1, unofficial].

**Steps:**
1. Initialize `faces_vertices` with capacity `FACES_ESTIMATION` [S1, unofficial].
2. Iterate over all voxels in the chunk [S1, unofficial].
3. For each voxel, retrieve `kind`; if `None`, skip to the next voxel [S1, unofficial].
4. Retrieve `occlusion` mask and `voxel_soft_light` data for the voxel [S1, unofficial].
5. Iterate over all 6 `side`s in `voxel::SIDES` [S1, unofficial].
6. Check if `occlusion.is_occluded(side)`; if true, skip to the next side [S1, unofficial].
7. Construct a `voxel::Face` with vertices computed from the voxel position and `side`, `side`, `kind`, and `light` from `voxel_soft_light.get(side)` [S1, unofficial].
8. Append the face to `faces_vertices` [S1, unofficial].

**Pseudocode:**
```python
def generate_faces(chunk_voxels, chunk_buffer_size, voxel_side_count, voxel_sides, get_kind, get_occlusion, get_soft_light):
    # Capacity hint from source [S1, unofficial]
    FACES_ESTIMATION = (chunk_buffer_size * voxel_side_count) // 2
    faces_vertices = []
    # Pre-allocate capacity if supported by the runtime [G]
    for voxel in chunk_voxels:
        kind = get_kind(voxel)
        if kind is None:
            continue
        occlusion = get_occlusion(voxel)
        voxel_soft_light = get_soft_light(voxel)
        for side in voxel_sides:
            if occlusion.is_occluded(side):
                continue
            # Compute 4 vertices for the face based on voxel position and side normal [G]
            v1, v2, v3, v4 = compute_face_vertices(voxel, side)
            face = {
                'vertices': [v1, v2, v3, v4],
                'side': side,
                'kind': kind,
                'light': voxel_soft_light.get(side)
            }
            faces_vertices.append(face)
    return faces_vertices

def compute_face_vertices(voxel, side):
    # Standard axis-aligned face vertex generation for side indices 0-5 [G]
    x, y, z = voxel
    if side == 0: return [(x,y,z), (x+1,y,z), (x+1,y+1,z), (x,y+1,z)]
    if side == 1: return [(x+1,y,z), (x+1,y+1,z), (x+1,y+1,z+1), (x+1,y,z+1)]
    if side == 2: return [(x+1,y,z+1), (x+1,y+1,z+1), (x,y+1,z+1), (x,y,z+1)]
    if side == 3: return [(x,y+1,z), (x,y+1,z+1), (x,y,z+1), (x,y,z)]
    if side == 4: return [(x,y,z+1), (x+1,y,z+1), (x+1,y,z), (x,y,z)]
    if side == 5: return [(x,y+1,z), (x+1,y+1,z), (x+1,y+1,z+1), (x,y+1,z+1)]
```

**Edge Cases and Pitfalls:**
- Empty voxels are explicitly skipped to avoid generating unnecessary geometry [S1, unofficial].
- `FACES_ESTIMATION` is a heuristic capacity hint; if the actual visible face count exceeds it, the vector reallocates [S1, unofficial].

## Subtopics

### [Voxel Face Extraction](14112-voxel-face-extraction.md)
Generates surface geometry by identifying exposed faces adjacent to empty space or different materials. Operates per-chunk, iterating face normals to compute an exposed voxel mask, then assembles a face buffer. Distinguished by explicit handling of axis-aligned shifts and boundary conditions to determine visibility without ray casting.

## Operating characteristics
**Time Complexity:** $O(V \times S)$, where $V$ is the number of voxels in the chunk and $S$ is the number of sides per voxel (6) [G].
**Memory Complexity:** $O(F)$, where $F$ is the number of visible faces. The output buffer size is bounded by $V \times S$ [G].
