# Parallel Marching Blocks


## Overview
Parallel Marching Blocks (PMB) is a block-based isosurface extraction algorithm that generates indexed triangle meshes from 3D scalar volumes on the GPU [S1, S2, unofficial]. It solves the problem of redundant vertex data in traditional marching cubes by ensuring vertices are shared between simplices within a processing block, producing compact meshlets suitable for mesh shader pipelines [S1, S2, unofficial]. Unlike standard marching cubes which output a triangle soup, PMB avoids internal duplication within a block, though vertices on block boundaries are duplicated and must be welded by the consumer for a fully connected mesh [S1, S2, unofficial].

## How it works
PMB operates in two main phases: an offline preprocessing stage and a runtime extraction stage [S1, unofficial]. The runtime stage consists of occupied block filtering and isosurface extraction [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   Scalar field $V$: Defined either as an analytic CUDA device function or a sampled array [S1, S2, unofficial].
*   Domain bounds: Axis-aligned bounding box defined by origin $x_0$ and size $L$ [S2, unofficial].
*   Grid resolution $N$: Integer dimensions $(N_x, N_y, N_z)$ [S2, unofficial].
*   Block dimensions: $B_x \times B_y \times B_z$ cells per block [S1, unofficial].
*   Isosurface value: Typically 0 (zero level set) [S2, unofficial].
*   Data types: Floating-point type `ftype` (e.g., `np.float32`) for coordinates and scalars; integer type `itype` (e.g., `uint32`) for indices [S2, unofficial].

**Outputs:**
*   Vertices buffer $V$: Array of shape $(n_v, 3)$ with `ftype` components [S2, unofficial].
*   Indices buffer $I$: Array of shape $(n_t, 3)$ with `itype` components [S2, unofficial].
*   If the zero level set is empty, both buffers are `None` [S2, unofficial].

### Data Structures
1.  **Min-Max Volume**: An auxiliary volume storing the minimum and maximum scalar values for each block, used to determine if a block contains the isosurface [S1, unofficial].
2.  **Active Block List**: A dense global memory array storing indices of occupied blocks, generated via stream compaction [S1, unofficial].
3.  **Shared Memory Array**: Within each workgroup, a shared memory array stores the location (offset) of each cell's vertices in the block's dense vertex array [S1, unofficial].
4.  **Output Buffers**: Device-side buffers for vertices and indices. These can be standard CUDA buffers or mapped OpenGL buffers [S2, unofficial].

### Algorithm Steps

1.  **Preprocessing**:
    *   Compute the min-max volume from the input scalar volume $V$ [S1, unofficial]. This is done offline or once before runtime [S1, unofficial].

2.  **Occupied Block Filtering**:
    *   Access the min-max volume to determine which blocks of size $B_x \times B_y \times B_z$ contain the isosurface [S1, unofficial].
    *   Optionally, use analytic block predicates (computed via interval or affine arithmetic) to discard blocks that cannot contain the surface [S2, unofficial]. This allows performance to scale with surface area rather than volume [S2, unofficial].
    *   Store the indices of occupied blocks in a dense global memory array using stream compaction [S1, unofficial].

3.  **Isosurface Extraction (Per Occupied Block)**:
    *   Launch a compute shader workgroup for each occupied block [S1, unofficial].
    *   **Workgroup Size**: Launch a workgroup of size $(B_x + 1) \times (B_y + 1) \times (B_z + 1)$ [S1, unofficial]. This includes "core" cells (within the block) and "padding" cells (neighboring cells outside the block) to ensure vertices required for edge triangles are available [S1, unofficial].
    *   **Thread Mapping**: Map each thread to one cell [S1, unofficial].
    *   **Vertex Extraction**:
        *   Threads extract vertices lying on the three edges of their assigned cell for which only that thread is responsible [S1, unofficial].
        *   Threads calculate the location of their cell's vertices in the block's dense vertex array using prefix sum operations [S1, unofficial].
        *   Store these locations in the shared-memory array [S1, unofficial].
    *   **Triangle Generation**:
        *   Retrieve indices from the shared-memory array when creating triangles [S1, unofficial].
        *   This generates an index buffer for the block without duplicated vertices *within* the block [S1, unofficial].
        *   Ensure consistent orientation: Normals point from negative to positive scalar values. Triangles are counterclockwise when viewed from the positive side [S2, unofficial].
    *   **Buffer Management**:
        *   Kernels read active block, vertex, and simplex counts from device counters [S2, unofficial].
        *   If counts exceed buffer capacity, reallocate buffers and relaunch kernels step-by-step [S2, unofficial].
        *   Once buffers are large enough, perform a single device-to-host copy [S2, unofficial].

def parallel_marching_blocks(scalar_field, domain_origin, domain_size, grid_resolution, block_size, isosurface_value=0.0):
    """
    Extracts isosurface using Parallel Marching Blocks.
    
    Args:
        scalar_field: Function or array defining the scalar field.
        domain_origin: Tuple (x0, y0, z0) defining the start of the domain.
        domain_size: Tuple (Lx, Ly, Lz) defining the size of the domain.
        grid_resolution: Tuple (Nx, Ny, Nz) defining the grid dimensions.
        block_size: Tuple (Bx, By, Bz) defining the block dimensions.
        isosurface_value: The scalar value to extract (default 0).
        
    Returns:
        vertices: Array of shape (n_v, 3) or None.
        indices: Array of shape (n_t, 3) or None.
    """
    # 1. Preprocessing: Create min-max volume
    # Note: In practice, this is often done offline or cached.
    min_max_volume = compute_min_max_volume(scalar_field, domain_origin, domain_size, grid_resolution, block_size)
    
    # 2. Occupied Block Filtering
    # Identify blocks containing the isosurface
    occupied_blocks = []
    for block_idx in range(total_blocks):
        block_min, block_max = get_block_min_max(min_max_volume, block_idx)
        # Check if isosurface is within the block's scalar range
        if block_min <= isosurface_value <= block_max:
            # Optional: Use analytic block predicates for finer culling
            if check_block_predicate(scalar_field, block_idx, domain_origin, domain_size, grid_resolution, block_size):
                occupied_blocks.append(block_idx)
    
    if not occupied_blocks:
        return None, None
        
    # Stream compaction to create dense array of occupied block indices
    active_block_indices = stream_compact(occupied_blocks)
    
    # 3. Isosurface Extraction
    vertices = []
    indices = []
    
    # Allocate initial buffers
    max_vertices = estimate_max_vertices(active_block_indices, block_size)
    max_indices = estimate_max_indices(active_block_indices, block_size)
    vertex_buffer = allocate_buffer(max_vertices, 3, dtype=float32)
    index_buffer = allocate_buffer(max_indices, 3, dtype=uint32)
    
    for block_idx in active_block_indices:
        # Launch workgroup for this block
        # Workgroup size: (Bx+1) x (By+1) x (Bz+1)
        wg_size = (block_size[0] + 1, block_size[1] + 1, block_size[2] + 1)
        
        # Shared memory for vertex locations
        shared_vertex_locations = allocate_shared_memory(wg_size, dtype=int32)
        
        # Execute kernel
        # Each thread handles one cell (core or padding)
        execute_marching_kernel(
            scalar_field=scalar_field,
            block_idx=block_idx,
            domain_origin=domain_origin,
            domain_size=domain_size,
            grid_resolution=grid_resolution,
            block_size=block_size,
            isosurface_value=isosurface_value,
            shared_vertex_locations=shared_vertex_locations,
            vertex_buffer=vertex_buffer,
            index_buffer=index_buffer
        )
        
    # 4. Buffer Management and Copy
    # Read counts from device counters
    num_vertices = get_device_counter("vertex_count")
    num_indices = get_device_counter("index_count")
    
    # If counts exceed capacity, reallocate and relaunch
    if num_vertices > len(vertex_buffer) or num_indices > len(index_buffer):
        vertex_buffer = reallocate_buffer(vertex_buffer, num_vertices)
        index_buffer = reallocate_buffer(index_buffer, num_indices)

    """
    Kernel executed by each workgroup.
    """
    # Thread indices
    tid = get_thread_id()
    cell_coords = get_cell_coordinates(tid, block_size) # Includes padding
    
    # Determine if this thread is responsible for a core cell or padding cell
    is_core = is_within_block(cell_coords, block_size)
    
    # Extract vertices for edges assigned to this thread
    # Only core threads contribute to the final vertex array to avoid duplication
    if is_core:
        vertex_indices = extract_vertices_for_cell(
            scalar_field, cell_coords, domain_origin, domain_size, grid_resolution, isosurface_value
        )
        
        # Calculate location in dense vertex array using prefix sum
        # This requires synchronization and atomic operations or shared memory prefix sum
        local_offset = compute_prefix_sum(vertex_indices, shared_vertex_locations)
        
        # Store vertex locations in shared memory
        store_vertex_locations(cell_coords, local_offset, shared_vertex_locations)
        
        # Write vertices to global buffer
        write_vertices_to_buffer(vertex_indices, local_offset, vertex_buffer)
        
        # Generate triangles using indices from shared memory
        triangle_indices = generate_triangles(cell_coords, shared_vertex_locations)
        write_indices_to_buffer(triangle_indices, index_buffer)

### Parameters
*   `N`: Grid size, passed as a kernel argument, not a template parameter [S2, unofficial].
*   `scalar function`: Analytic CUDA device function or sampled array. Signature: `template <typename T, typename I, I dim> __device__ __forceinline__ T scalar(const trove::array<T,dim>& p, const trove::array<I,dim>& i)` [S2, unofficial].
*   `ftype`: Floating-point type for coordinates and scalar values (e.g., `np.float32`) [S2, unofficial].
*   `itype`: Integer type for indices (e.g., `uint32`) [S2, unofficial].
*   `x0`: Domain origin [S2, unofficial].
*   `L`: Domain size [S2, unofficial].

### Edge Cases and Pitfalls
*   **Padding Cells**: Triangles from cells on the edge of the block require vertices from cells not in the block. This is handled by including padding cells in the workgroup [S1, unofficial].
*   **Empty Zero Level Set**: If the zero level set is empty, output buffers `V` and `I` are `None` [S2, unofficial].
*   **Boundary Duplication**: Vertices lying on faces shared by two blocks are duplicated. Users must weld them by position for a fully connected mesh [S2, unofficial].
*   **Cache Invalidation**: Headers included from other directories via `extra_build_options` are not part of the cache key. The cache must be cleared when these headers change [S2, unofficial].
*   **Precision**: Supports single (`float32`) or double (`float64`) precision for vertices [S2, unofficial].

## Operating characteristics
*   **Time Complexity**: Performance scales with the surface area when block predicates are used, rather than the full volume [S2, unofficial].
*   **Memory Complexity**: Memory usage is proportional to the number of vertices and indices in the extracted meshlets. Buffer reallocation may occur if initial estimates are insufficient [S2, unofficial].
*   **Strengths**:
    *   Avoids redundant vertex/index data within a block [S1, unofficial].
    *   Generates indexed meshes compatible with mesh shader pipelines [S2, unofficial].
    *   Supports dynamic domains and kernel parameters [S2, unofficial].
    *   Can use OpenGL buffers for zero-copy rendering [S2, unofficial].
*   **Limitations**:
    *   Provides little control over the maximum number of vertices and indices extracted, potentially producing meshlets that do not conform to size constraints [S1, unofficial].
    *   Requires post-processing (welding) for fully connected meshes across block boundaries [S2, unofficial].
*   **When to Use**: Real-time isosurface extraction where meshlet-based rendering is beneficial and block boundaries can be handled by the renderer or post-processing [S1, S2, unofficial].
*   **When Not to Use**: When strict meshlet size constraints are required or when a fully connected mesh without boundary welding is needed [S1, S2, unofficial].

## Background
Parallel Marching Blocks (PMB) was introduced by Liu et al. in the paper "Parallel Marching Blocks: A Practical Isosurfacing Algorithm for Large Data on Many-Core Architectures" (CGF 2022) [S2, unofficial]. It is implemented in the `cupmb` library (Cuda Parallel Marching Blocks) by Jean-Baptiste Keck [S2, unofficial]. The method builds on the principles of block-based isosurfacing to improve efficiency over trivial small-voxel approaches [Parent].
