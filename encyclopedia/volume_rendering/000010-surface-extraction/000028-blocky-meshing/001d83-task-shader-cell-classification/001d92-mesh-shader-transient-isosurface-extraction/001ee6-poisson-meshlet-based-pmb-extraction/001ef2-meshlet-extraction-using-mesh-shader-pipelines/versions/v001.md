# Meshlet Extraction using Mesh Shader Pipelines

Also called: Mesh Shader Meshlet Extraction

## Overview
A real-time isosurface extraction method that uses coupled task and mesh shaders to partition scalar volumes into size-constrained meshlets, addressing the lack of control over meshlet size constraints in its parent method, [Poisson Meshlet-Based (PMB) Extraction](1860-poisson-meshlet-based-pmb-extraction.md) [S1, unofficial]. It replaces PMB's single compute shader with a task/mesh shader pair to reduce thread-level divergence, enable hierarchical partitioning via task shader tree-expansion, and allow asynchronous execution for pipeline overlap [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Scalar volume $V$, isovalue, block size parameters ($B_x, B_y, B_z$), meshlet vertex/index constraints.
*   **Output:** A list of meshlets, each containing a descriptor, an index buffer, and vertex attribute buffers (positions, normals) [S1, unofficial].

**Data Structures:**
*   **Min-Max Volume:** Precomputed volume storing min/max scalar values for each block, used to cull empty blocks [S1, unofficial].
*   **Global Memory Buffers:** Dense arrays for meshlet descriptors, index buffers, and vertex attribute buffers (positions, normals) [S1, unofficial].
*   **Occupied Block Indices:** A dense array aligned with occupied block indices, storing the index of the first meshlet and the count of meshlets per block [S1, unofficial].

**Parameters:**
*   **Block Size:** $8 \times 8 \times 4$ cells [S1, unofficial].
*   **Subblock Sizes:** Hierarchical levels of $4 \times 4 \times 4$ and $2 \times 2 \times 2$ cells [S1, unofficial].
*   **Threads per Workgroup ($T$):** 32 (one per warp) [S1, unofficial].
*   **Total Cells per Block ($\beta$):** $B_x \times B_y \times B_z = 256$ [S1, unofficial].
*   **Cells per Thread ($R$):** $R = \beta / T = 8$ [S1, unofficial].
*   **Convex Subblocks:** The block size combines 32 convex subblocks of size $2 \times 2 \times 2$ [S1, unofficial].

**Steps:**

1.  **Preliminaries:** Implicitly divide the scalar volume $V$ into 3D blocks where block size along each axis is a power of two. Calculate a min-max volume from $V$ [S1, unofficial]. Index cells in Morton order to ensure compact regions for subgroup communication [S1, unofficial].

2.  **Occupied Block Filtering:** Use the same approach as PMB to locate occupied blocks where isosurfaces should be extracted [S1, unofficial].

3.  **Task Shader Workgroup Analysis:**
    *   Execute a single task shader workgroup per occupied block [S1, unofficial].
    *   The workgroup has $T=32$ threads [S1, unofficial].
    *   Each thread $T_i$ analyzes the $i$-th subregion of $R$ cells (where $R=8$) [S1, unofficial].
    *   Cells are indexed in Morton order [S1, unofficial].
    *   Each thread counts the number of vertices and primitives (triangles) produced by the isosurface within its assigned $R$ cells [S1, unofficial].
    *   Threads store indices of cells contributing to the isosurface and indices of padding cells contributing to the isosurface for each possible partitioning ($8\times8\times4$, $4\times4\times4$, $2\times2\times2$) [S1, unofficial].
    *   A cell's status as a core or padding cell for each partitioning is determined using modulo operations based on the cell's position and subblock size [S1, unofficial].
    *   Use efficient subgroup communication to analyze and summarize block and subblock regions (vertex/primitive counts) [S1, unofficial].

4.  **Hierarchical Partitioning (Region Analysis):**
    *   Determine if all isosurface geometry in the block can be represented by a single meshlet. If yes, mark the block for single meshlet extraction [S1, unofficial].
    *   If not, determine if the isosurface in each $4 \times 4 \times 4$ subblock can be represented by a single meshlet [S1, unofficial].
    *   If a $4 \times 4 \times 4$ subblock cannot be represented by one meshlet, partition it into $2 \times 2 \times 2$ subblocks [S1, unofficial].
    *   Subblocks must be convex to allow implicit identification of core and padding cells [S1, unofficial].

5.  **Meshlet Extraction:**
    *   Spawn mesh shader workgroups for each resulting partition (subblock) that contains isosurface geometry [S1, unofficial].
    *   Empty subblocks are skipped [S1, unofficial].
    *   Each mesh shader workgroup extracts a meshlet from its assigned subblock using the PMB extraction kernel [S1, unofficial].

6.  **Buffer Reservation and Metadata:**
    *   Reserve space in dense global memory buffers for meshlet descriptors, indices, and vertex attributes based on calculated counts [S1, unofficial].
    *   Store the index of the first meshlet extracted from the block and the number of meshlets the block contains in a dense array aligned with the occupied block indices [S1, unofficial].

**Pseudocode:**

```python
# Task Shader Workgroup (One per occupied block)
def task_shader_workgroup(block_id):
    # T = 32 threads, R = 8 cells per thread, beta = 256 cells per block
    T = 32
    R = 8
    beta = 256
    
    # Shared memory for subgroup communication
    # Stores vertex/primitive counts for different partition levels
    # Level 0: Whole block (8x8x4)
    # Level 1: 4x4x4 subblocks (4 subblocks)
    # Level 2: 2x2x2 subblocks (32 subblocks)
    shared_counts = allocate_shared_memory(T, 3) 
    
    # Each thread analyzes R cells in Morton order
    thread_id = get_thread_id()
    start_cell = thread_id * R
    end_cell = start_cell + R
    
    local_v_count = 0
    local_t_count = 0
    local_core_indices = []
    local_padding_indices = {} # Key: partition_level, Value: list of indices
    
    for cell_idx in range(start_cell, end_cell):
        if is_occupied(cell_idx):
            # Count vertices and triangles for this cell
            v, t = count_geometry(cell_idx)
            local_v_count += v
            local_t_count += t
            
            # Store cell index
            local_core_indices.append(cell_idx)
            
            # Determine padding status for each partition level
            # Using modulo operations based on cell position
            for level in [0, 1, 2]:
                if is_padding_cell(cell_idx, level):
                    if level not in local_padding_indices:
                        local_padding_indices[level] = []
                    local_padding_indices[level].append(cell_idx)

    # Subgroup reduction to sum counts across threads
    total_v, total_t = subgroup_sum(local_v_count, local_t_count)
    
    # Determine partitioning strategy
    # Check if whole block fits in one meshlet
    if fits_in_meshlet(total_v, total_t, level=0):
        partition = [BLOCK_LEVEL_0]
    else:
        # Check 4x4x4 subblocks
        subblock_partitions = []
        for subblock_id in range(4):
            # Aggregate counts for this 4x4x4 subblock using subgroup communication
            # Threads responsible for cells in this subblock sum their counts
            sub_v, sub_t = subgroup_reduce_for_subblock(subblock_id)
            
            if fits_in_meshlet(sub_v, sub_t, level=1):
                subblock_partitions.append(SUBBLOCK_LEVEL_1)
            else:
                # Partition into 2x2x2 subblocks
                for inner_subblock_id in range(8):
                    # Aggregate counts for this 2x2x2 subblock
                    inner_v, inner_t = subgroup_reduce_for_inner_subblock(subblock_id, inner_subblock_id)
                    if fits_in_meshlet(inner_v, inner_t, level=2):
                        subblock_partitions.append(SUBBLOCK_LEVEL_2)
                    else:
                        # Should not happen given block size constraints, but handle as empty or error
                        pass
        partition = subblock_partitions

    # Reserve space in global buffers
    num_meshlets = len(partition)
    offset = reserve_global_buffers(num_meshlets)
    
    # Store metadata
    occupied_block_metadata[block_id].first_meshlet_index = offset
    occupied_block_metadata[block_id].num_meshlets = num_meshlet

    # Launch mesh shader workgroups
    for meshlet_id, subblock_type in enumerate(partition):
        if subblock_type is not EMPTY:
            launch_mesh_shader_workgroup(
                block_id=block_id,
                meshlet_id=meshlet_id,
                subblock_type=subblock_type,
                global_buffer_offset=offset + meshlet_id
            )

# Mesh Shader Workgroup (One per subblock)
def mesh_shader_workgroup(block_id, meshlet_id, subblock_type, global_buffer_offset):
    # Extract meshlet from the assigned subblock using PMB kernel
    # PMB kernel handles vertex deduplication and index generation
    meshlet = pmb_extract_meshlet(subblock_type)
```

## Subtopics

### Hierarchical Region Analysis
A hierarchical partitioning approach that subdivides blocks into convex subblocks to ensure meshlets do not exceed vertex/index constraints [S1, unofficial]. It checks if the whole block fits in one meshlet; if not, it checks $4 \times 4 \times 4$ subblocks; if those fail, it partitions into $2 \times 2 \times 2$ subblocks [S1, unofficial]. Unlike Kreskowski et al. [KRF22] which groups cells arbitrarily, this method divides blocks into convex subblocks to maintain compatibility with the PMB extraction kernel, allowing implicit identification of core and padding cells [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Not given in the sources.
*   **Strengths:** Reduces thread-level divergence (TLD) in geometry extraction compared to PMB's single compute shader; allows hierarchical partitioning via task shader tree-expansion; enables asynchronous execution for pipeline overlap without complex multi-queue orchestration; extracts unique vertices within meshlets to maximize primitive count per meshlet [S1, unofficial].
*   **Limitations:** Requires hardware support for task and mesh shaders; relies on convex subblocks for efficient core/padding cell identification [S1, unofficial].
*   **When to use:** When real-time isosurface extraction is required and hardware supports mesh shader pipelines, especially when PMB's lack of size constraint control is a bottleneck [S1, unofficial].
*   **When not:** When hardware lacks task/mesh shader support or when scene complexity does not benefit from reduced TLD [S1, unofficial].
