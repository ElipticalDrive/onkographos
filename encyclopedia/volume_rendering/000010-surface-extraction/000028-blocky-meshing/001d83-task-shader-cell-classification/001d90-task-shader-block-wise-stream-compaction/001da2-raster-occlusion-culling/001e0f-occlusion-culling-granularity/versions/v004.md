# Occlusion Culling Granularity


## Overview
Occlusion Culling Granularity configures the spatial resolution of occlusion tests to match the leaf-level of a reference ray-marching octree (8×8×8 cells) for fair performance comparison [S1][S2, unofficial]. It also governs the sampling grid resolution used to interpret the occlusion buffer, which directly influences aliasing artifacts and shading quality [S3].

## How it works
**Inputs and Outputs**
Not given in the sources.

**Data Structures**
*   **Culling Block:** A 3D region of cells configured to 8×8×8 cells [S2, unofficial].
*   **Extraction Block:** A 3D region of cells configured to 8×8×4 cells [S2, unofficial].
*   **Sampling Grid:** A 2D grid overlaid on the occlusion buffer with tested resolutions of 2×2 and 13×13 [S3].

**Numbered Steps**
1.  Configure culling granularity to 8×8×8 cells, aligning with the leaf-level of the ray-marching reference octree [S1][S2, unofficial].
2.  For each potentially visible region, launch two task shader workgroups to cover the 8×8×8 culling block, accounting for the 8×8×4 extraction block size [S2, unofficial].
3.  Sample the occlusion buffer using the configured 2D sampling grid [S3].
4.  Select the sampling resolution based on the cone aperture angle θ: use 2×2 for low θ values, or 13×13 for high θ values to reduce aliasing [S3].

**Formulas**
Not given in the sources.

**Parameters**
*   **Culling Block Size:** 8×8×8 cells [S2, unofficial].
*   **Extraction Block Size:** 8×8×4 cells [S2, unofficial].
*   **Task Shader Workgroups per Region:** 2 [S2, unofficial].
*   **Sampling Resolution:** 2×2 or 13×13 [S3].

**Edge Cases and Pitfalls**
*   **Aliasing:** Using low sampling resolutions (e.g., 2×2) at high cone aperture angles (θ) causes significant aliasing artifacts because the cone base covers many texels in the occlusion buffer [S3].
*   **Granularity Mismatch:** The extraction stage operates on 8×8×4 blocks while culling uses 8×8×8 regions, requiring exactly two workgroups per region to ensure all extraction blocks are processed [S2, unofficial].

## Subtopics

### Block-Based Occlusion Culling Granularity
A configuration that aligns the culling granularity with the leaf-level of the ray-marching reference octree (8×8×8 cells) to ensure a fair performance comparison between the rasterization-based approach and the reference [S2, unofficial][S1]. It requires launching two task shader workgroups per region to accommodate the 8×8×4 extraction block size [S2, unofficial]. Choose this when benchmarking against ray-marching baselines [S1][S2, unofficial].

### Occlusion Buffer Sampling Resolution
Defines the density of samples taken from the occlusion buffer to determine block visibility [S3]. Higher resolutions (e.g., 13×13 vs 2×2) reduce aliasing, particularly for large cone aperture angles (θ) where the occlusion extent covers many texels [S3]. Choose higher resolutions when visual quality is prioritized over the minimal overhead of additional samples [S3].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Aligning with the reference octree leaf level allows for direct, fair comparison with ray-marching methods [S1][S2, unofficial].
*   **Limitations:** High sampling resolutions are necessary for high θ values to avoid aliasing, increasing computational cost [S3].
*   **When to use:** When comparing against ray-marching baselines or when the scene structure matches the 8×8×8 leaf level [S1][S2, unofficial].
*   **When not to use:** When high θ shading is required but performance is critical, as low sampling resolution may be insufficient to prevent aliasing [S3].

## Background
The concept of occlusion culling granularity in this context originates from research on efficient direct isosurface rasterization of scalar volumes [S1]. The specific configuration of 8×8×8 culling blocks and 8×8×4 extraction blocks was introduced to facilitate a fair comparison with a ray-marching reference implementation [S1][S2, unofficial]. The impact of sampling resolution on aliasing in directional occlusion shading models was further detailed in subsequent work on interactive direct volume rendering [S3].
