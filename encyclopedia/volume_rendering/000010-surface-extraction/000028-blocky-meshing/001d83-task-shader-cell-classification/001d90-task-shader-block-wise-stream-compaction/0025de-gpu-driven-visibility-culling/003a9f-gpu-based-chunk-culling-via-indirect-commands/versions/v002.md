# GPU-Based Chunk Culling via Indirect Commands

Also called: Compute Shader Culling, Indirect Draw Culling

## Overview
A rendering optimization that uses a compute shader to filter visible chunks and generates indirect draw arguments on the GPU, reducing CPU-GPU synchronization overhead [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A list of loaded chunks and their associated render resources [S1, unofficial].
*   **Output:** An indirect command buffer containing `D3D12_DRAW_INDEXED_ARGUMENTS` for only the visible chunks, ready for `ExecuteIndirect` [S1, unofficial].

**Data Structures:**
1.  **`IndirectCommand`**: The structure written by the compute shader to the output buffer [S1, unofficial]. It contains:
    *   `render_resources`: A struct of type `VoxelRenderResources` containing `scene_constant_buffer_index` and `chunk_constant_buffer_index` [S1, unofficial].
    *   `index_buffer_view`: A `D3D12_INDEX_BUFFER_VIEW` describing the index buffer for the chunk mesh [S1, unofficial].
    *   `draw_arguments`: A `D3D12_DRAW_INDEXED_ARGUMENTS` struct containing `IndexCountPerInstance`, `InstanceCount`, `StartIndexLocation`, `BaseVertexLocation`, and `StartInstanceLocation` [S1, unofficial].
2.  **`GPUCullRenderResources`**: Struct passed to the compute shader via root constants (64 bits / 16 32-bit values) [S1, unofficial]. It contains:
    *   `number_of_chunks`: `u32`, the total number of chunks to process [S1, unofficial].
    *   `indirect_command_srv_index`: `u32`, descriptor heap index for the input command buffer (SRV) [S1, unofficial].
    *   `output_command_uav_index`: `u32`, descriptor heap index for the output command buffer (UAV) [S1, unofficial].
    *   `scene_constant_buffer_index`: `u32`, descriptor heap index for the scene constant buffer (CBV) [S1, unofficial].

**Numbered Steps:**
1.  Build indirect command vector on CPU by iterating loaded chunks and populating `IndirectCommand` structs [S1, unofficial].
2.  Transition indirect command buffer to `COPY_DEST` state and copy CPU data via `memcpy` to the mapped upload resource pointer [S1, unofficial].
3.  Set compute root constants (64 bits) with the `GPUCullRenderResources` struct [S1, unofficial].
4.  Reset UAV counter by copying a zeroed 4-byte value from a dedicated counter buffer to the output buffer's counter offset [S1, unofficial].
5.  Transition buffer to `UNORDERED_ACCESS` state and dispatch compute shader [S1, unofficial].
6.  Transition buffer to `INDIRECT_ARGUMENT` state and execute indirect draw [S1, unofficial].

**Pseudocode:**
```python
# Self-contained definitions to replace engine-specific handles
D3D_PRIMITIVE_TOPOLOGY_TRIANGLELIST = 0
MAX_CHUNKS_TO_BE_DRAWN = 1024  # Parameterized maximum per frame

class CommandList:
    def set_descriptor_heaps(self, heaps): pass
    def set_compute_root_signature(self, sig): pass
    def set_pipeline_state(self, pso): pass
    def set_compute_root_constants(self, root_index, num_words, data): pass
    def copy_buffer_region(self, dst, dst_offset, src, src_offset, size): pass
    def dispatch(self, x, y, z): pass
    def set_graphics_root_signature(self, sig): pass
    def ia_set_primitive_topology(self, topo): pass
    def execute_indirect(self, signature, max_commands, cmd_buf, cmd_offset, arg_buf, arg_offset): pass

class IndirectCommandBuffer:
    def __init__(self):
        self.upload_resource_mapped_ptr = bytearray()
        self.upload_resource_srv_index = 0
        self.default_resource_uav_index = 1
        self.default_resource = "default_resource_handle"
        self.zeroed_counter_buffer_resource = "zeroed_counter_handle"
        self.counter_offset = 0

class SceneBuffer:
    def __init__(self):
        self.cbv_index = 2

class Renderer:
    def __init__(self):
        self.m_bindless_root_signature = "bindless_sig_handle"

def gpu_based_chunk_culling(indirect_command_vector, renderer, command_list, indirect_command_buffer, scene_buffer):
    # 1. Upload Data (CPU)
    # Transition upload resource to COPY_DEST state
    # Copy CPU data to mapped upload resource
    indirect_command_buffer.upload_resource_mapped_ptr = bytes(indirect_command_vector)

    # 2. Setup Compute Shader (CPU)
    command_list.set_descriptor_heaps(["shader_visible_descriptor_heaps"])
    command_list.set_compute_root_signature(renderer.m_bindless_root_signature)
    command_list.set_pipeline_state("gpu_culling_pso")

    gpu_cull_render_resources = {
        'number_of_chunks': len(indirect_command_vector),
        'indirect_command_srv_index': indirect_command_buffer.upload_resource_srv_index,
        'output_command_uav_index': indirect_command_buffer.default_resource_uav_index,
        'scene_constant_buffer_index': scene_buffer.cbv_index
    }
    command_list.set_compute_root_constants(0, 64, gpu_cull_render_resources)

    # 3. Reset Counter (CPU)
    command_list.copy_buffer_region(
        dst=indirect_command_buffer.default_resource,
        dst_offset=indirect_command_buffer.counter_offset,
        src=indirect_command_buffer.zeroed_counter_buffer_resource,
        src_offset=0,
        size=4
    )

    # 4. Dispatch Compute Shader (CPU/GPU)
    # Transition default_resource from COPY_DEST to UNORDERED_ACCESS
    command_list.dispatch(
        num_threads_x=(len(indirect_command_vector) + 31) // 32,
        num_threads_y=1,
        num_threads_z=1
    )

    # 5. Execute Indirect Draw (CPU/GPU)
    # Transition default_resource from UNORDERED_ACCESS to INDIRECT_ARGUMENT
    command_list.set_descriptor_heaps(["shader_visible_descriptor_heaps"])
    command_list.set_graphics_root_signature(renderer.m_bindless_root_signature)
    command_list.set_pipeline_state("render_pso")
    command_list.ia_set_primitive_topology(D3D_PRIMITIVE_TOPOLOGY_TRIANGLELIST)

    command_list.execute_indirect(
        command_signature="command_signature_handle",
        max_command_count=MAX_CHUNKS_TO_BE_DRAWN,
        p_indirect_command_buffer=indirect_command_buffer.default_resource,
        indirect_command_buffer_offset=0,
        p_indirect_argument_buffer=indirect_command_buffer.default_resource,
        indirect_argument_buffer_offset=indirect_command_buffer.counter_offset
    )
```

**Compute Shader Logic:**
The compute shader processes each chunk index and performs visibility testing against scene data [G]. Visible chunks append their `IndirectCommand` to the UAV output buffer using an atomic counter increment [G].

**Parameters:**
*   `MAX_CHUNKS_TO_BE_DRAWN`: Maximum number of indirect draw calls per frame. Used as the second argument to `ExecuteIndirect` [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Resource State Transitions:** Must strictly follow D3D12 rules: `INDIRECT_ARGUMENT` -> `COPY_DEST` -> `UNORDERED_ACCESS` -> `INDIRECT_ARGUMENT`. Missing transitions cause validation errors or undefined behavior [S1, unofficial].
*   **Counter Reset:** The UAV counter must be reset before each dispatch to ensure correct indexing in the output buffer [S1, unofficial].
*   **Thread Group Size:** The dispatch size is calculated based on 32 threads per group. The thread count uses ceiling division `(N + 31) // 32` to handle non-multiples of 32 correctly [S1, unofficial].
