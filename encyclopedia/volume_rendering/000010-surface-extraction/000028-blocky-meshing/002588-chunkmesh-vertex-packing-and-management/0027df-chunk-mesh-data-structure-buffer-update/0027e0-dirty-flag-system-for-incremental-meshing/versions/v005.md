# Dirty Flag System for Incremental Meshing

Also called: Chunked Incremental Re-meshing, Dirty Chunk System, Display List/VBO Update Strategy, Lazy Rebuild

## Overview
The Dirty Flag System is an optimization technique for blocky meshing that avoids redundant surface extraction by tracking which chunks of a voxel world have changed geometry since the last mesh pass [S1, S3, unofficial]. Instead of rebuilding vertex buffers for every chunk every frame, the system marks only chunks containing modified density values as "dirty" and rebuilds them incrementally [S3, unofficial]. This sets it apart from naive approaches that rebuild all geometry or those that trigger rebuilds based on camera movement, which negates the performance benefits of static geometry caching [S2, unofficial].

## How it works
The method manages a grid of chunks, where each chunk maintains a state indicating whether its mesh needs regeneration [S3, unofficial]. The core logic involves marking chunks as dirty when voxel data changes and processing only those dirty chunks during the meshing phase [S3, unofficial].

### Inputs and Outputs
- **Input**: A voxel world grid of density values, and a modified voxel range $[minX, maxX] \times [minY, maxY] \times [minZ, maxZ]$ [S3, unofficial].
- **Output**: Updated GPU vertex buffers (or display lists) for only the dirty chunks [S1, S2, unofficial].

### Data Structures
1. **Chunk Grid**: A 3D array of `Chunk` objects. Each `Chunk` contains:
    - `dirty`: A boolean flag indicating whether the chunk's geometry has changed since the last mesh pass [S1, unofficial].
    - `meshData`: Temporary storage for vertex and index data during generation [S1, unofficial].
2. **Dirty Chunks Set**: A collection (e.g., `HashSet` or `List`) storing the indices of chunks that require rebuilding [S3, unofficial].

### Numbered Steps

1. **Initialization**:
    - Allocate the chunk grid. Ensure map dimensions are divisible by the chunk size [S1, unofficial].
    - Initialize all chunk `dirty` flags to `true` to force an initial mesh pass [G].

2. **Marking Dirty Chunks (On Voxel Modification)**:
    - When density is modified in a voxel range, calculate the affected chunk indices [S3, unofficial].
    - Because a voxel at index $x$ affects the cell to its left ($x-1$), the minimum chunk index is calculated using $\lfloor (minX - 1) / \text{chunkSize} \rfloor$ [S3, unofficial].
    - Calculate the range of affected chunk indices:
        $$ c_{minX} = \lfloor (minX - 1) / \text{chunkSize} \rfloor, \quad c_{maxX} = \lfloor maxX / \text{chunkSize} \rfloor $$
        (Analogous calculations apply for $Y$ and $Z$) [G].
    - Iterate through all chunk indices $(c_x, c_y, c_z)$ from $(c_{minX}, c_{minY}, c_{minZ})$ to $(c_{maxX}, c_{maxY}, c_{maxZ})$ and add them to the `dirtyChunks` set [S3, unofficial].
    - If a block on a chunk's outer boundary is modified, flag neighbor chunks for update to prevent visual seams [S4, unofficial].

3. **Meshing Phase (Pre-Meshing)**:
    - In `LateUpdate`, iterate through `dirtyChunks` and call `Rebuild()` on each [S3, unofficial].
    - Before meshing, assert the chunk is dirty and call `UnsetDirty()` to clear the flag [S1, unofficial].
    - Perform surface extraction on the chunk's voxel data and store results in `chunk.meshData` [S1, unofficial].

4. **Buffer Update (Post-Meshing)**:
    - After meshing, check `chunk.meshData.Length`; if $> 0$, create a new `VoxelVertexBuffer` and copy data via `BufferData()` [S1, unofficial].
    - Recycle temporary mesh visitor and vertex storage via `MeshVisiterAllocator.Recycle` and `TempStorageAllocator<VoxelVertex>.Recycle` [S1, unofficial].
    - Clear the `dirtyChunks` list after processing [S3, unofficial].

    dirty: bool
    meshData: list  # Temporary vertex/index storage
    vertex_buffer: object  # GPU resource handle

class World:
    chunks: list  # Flattened or 3D array of Chunks
    dirty_chunks: set  # Stores chunk indices
    chunk_size: int
    map_size_x: int
    map_size_y: int
    map_size_z: int

def mark_chunk_dirty(world: World, voxel_min: tuple, voxel_max: tuple):
    # Calculate affected chunk ranges
    # A voxel at x affects x-1, so min chunk is (minX - 1) / chunkSize
    c_min_x = (voxel_min[0] - 1) // world.chunk_size
    c_max_x = voxel_max[0] // world.chunk_size
    c_min_y = (voxel_min[1] - 1) // world.chunk_size
    c_max_y = voxel_max[1] // world.chunk_size
    c_min_z = (voxel_min[2] - 1) // world.chunk_size
    c_max_z = voxel_max[2] // world.chunk_size

    # Clamp to world bounds
    c_min_x = max(0, c_min_x)
    c_max_x = min(world.map_size_x // world.chunk_size - 1, c_max_x)
    c_min_y = max(0, c_min_y)
    c_max_y = min(world.map_size_y // world.chunk_size - 1, c_max_y)
    c_min_z = max(0, c_min_z)
    c_max_z = min(world.map_size_z // world.chunk_size - 1, c_max_z)

    for cx in range(c_min_x, c_max_x + 1):
        for cy in range(c_min_y, c_max_y + 1):
            for cz in range(c_min_z, c_max_z + 1):
                chunk = world.chunks[cx, cy, cz]
                if not chunk.dirty:
                    chunk.dirty = True
                    world.dirty_chunks.add((cx, cy, cz))

def process_dirty_chunks(world: World):
    dirty_list = list(world.dirty_chunks)
    world.dirty_chunks.clear()

    for (cx, cy, cz) in dirty_list:
        chunk = world.chunks[cx, cy, cz]
        
        # Pre-meshing: assert dirty and clear flag
        assert chunk.dirty
        chunk.dirty = False
        
        # Surface extraction (e.g., Marching Cubes) [G]
        chunk.meshData = perform_surface_extraction(chunk.voxel_data)
        
        # Post-meshing: buffer update
        if len(chunk.meshData) > 0:
            chunk.vertex_buffer = create_gpu_buffer(chunk.meshData)
        
        # Recycle temporary memory
        recycle_mesh_visitor()
        recycle_temp_storage(chunk.meshData)

def late_update(world: World):
    if len(world.dirty_chunks) > 0:
        process_dirty_chunks(world)

### Parameters
- **Chunk Size**: Typically 16×16×16 or 32×32×32 voxels [S1, S2, unofficial].
- **Dirty Flag**: Boolean per chunk [S1, unofficial].

### Edge Cases and Pitfalls
- **View Change Rebuilds**: Modifying display lists or vertex buffers whenever the view changes negates the benefit of caching static geometry [S2, unofficial].
- **Boundary Effects**: Failing to account for the fact that a voxel at index $x$ affects the cell to its left ($x-1$) will result in missing geometry at chunk boundaries [S3, unofficial].
- **Visual Flicker**: Discarding old geometry immediately when a chunk is flagged as unmeshed causes a jarring blank flicker while the CPU rebuilds the model [S4, unofficial].

## Subtopics

### Double-Buffered Remeshing
A technique to update chunk geometry without visual flicker by keeping the old geometry visible while the new mesh is constructed in the background, then swapping them [S4, unofficial]. When a block is edited, the chunk is flagged as unmeshed, but the existing geometry continues to be rendered [S4, unofficial]. A meshing worker constructs the updated model silently [S4, unofficial]. Once ready, the old and new geometry are swapped in a single frame [S4, unofficial]. If a block on a chunk's outer boundary is modified, neighbor chunks are also flagged, and adjacent chunk edits are overlaid onto halo margins to prevent visual seams [S4, unofficial].

## Operating characteristics
- **Performance**: Reduces CPU load by avoiding redundant Marching Cubes calculations for unchanged geometry [S1, S3, unofficial].
- **Strengths**: Efficient for dynamic worlds with frequent small changes [G].
- **Limitations**: Requires careful management of dirty flags and boundary conditions [G]. Double-buffering adds complexity and memory overhead for storing two versions of geometry [S4, unofficial].
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Not given in the sources.

## Background
The Dirty Flag System tracks modified chunks to avoid remeshing unchanged geometry [S1, unofficial]. It is used in chunk-based meshing systems to rebuild display lists or vertex buffers only when a block is modified in a given chunk [S2, unofficial].
