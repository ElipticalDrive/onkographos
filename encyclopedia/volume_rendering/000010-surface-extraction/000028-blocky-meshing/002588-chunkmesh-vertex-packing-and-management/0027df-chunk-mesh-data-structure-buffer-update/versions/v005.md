# Chunk Mesh Data Structure & Buffer Update

Also called: ChunkMesh Update Loop, Dynamic Chunk Mesh Buffer Management, Mega Buffer, MegaSSBO Memory Management, SSBO Allocator, Voxel Buffer Management

## Overview
This method manages the creation, population, and recycling of GPU vertex buffers for meshed chunk geometry, specifically addressing the dynamic allocation of face data within a single large Shader Storage Buffer (SSBO) [S1, S3, unofficial]. It solves the problem of efficiently mapping variable-sized mesh outputs from voxel surface extraction to GPU memory without frequent reallocation or fragmentation [S3, unofficial]. It differs from [Voxel Face Meshing with Packed Attributes](4153-voxel-face-meshing-with-packed-attributes.md) by focusing on the memory management layer rather than the vertex layout, and from [Mesh Reindexing and Vertex Compaction](4160-mesh-reindexing-and-vertex-compaction.md) by handling allocation via a free-list allocator rather than post-generation reordering [S3, unofficial].

## How it works
The method operates on a global "MegaSSBO" that serves as a contiguous memory pool for all chunk meshes. It uses a free-list allocator to manage offsets and sizes, ensuring that dynamic mesh sizes (which vary based on surface complexity) can be accommodated without moving existing data unless necessary.

### Inputs and Outputs
*   **Input:** Temporary mesh data (`tempMeshData`) containing `VoxelVertex` structs generated during the meshing pass [S1, unofficial].
*   **Input:** Face count (`faceCount`) required for the current chunk [S3, unofficial].
*   **Output:** A valid offset within the MegaSSBO and an updated buffer state ready for rendering [S3, unofficial].

### Data Structures

**MegaSSBO Layout**
The MegaSSBO is a single OpenGL `GL_SHADER_STORAGE_BUFFER` (SSBO) [S3, unofficial].
*   **Capacity:** Defined by `MAX_FACES`, a global constant representing the total number of `uint32_t` elements the buffer can hold [S3, unofficial].
*   **Element Size:** Each element is `sizeof(uint32_t)` [S3, unofficial].
*   **Total Bytes:** `MAX_FACES * sizeof(uint32_t)` [S3, unofficial].

**FreeBlock Structure**
Used to track free regions in the SSBO [S3, unofficial].
*   `offset`: `uint32_t`, the starting index (in `uint32_t` elements) of the free block [S3, unofficial].
*   `size`: `uint32_t`, the number of `uint32_t` elements available in the block [S3, unofficial].

**FreeList**
*   `m_FreeList`: A `std::list<FreeBlock>` (or `std::vector` in some implementations) maintaining contiguous free regions in ascending order of `offset` [S3, unofficial].

**Chunk Mesh Object**
*   `offset`: `uint32_t`, the position in the MegaSSBO where this chunk's data resides [S3, unofficial].
*   `faceCount`: `uint32_t`, the number of faces (indices) stored for this chunk [S3, unofficial].
*   `update`: `bool`, flag indicating if the buffer needs refreshing before draw [S2, unofficial].

### Parameters
*   `MAX_FACES`: The total capacity of the MegaSSBO in terms of `uint32_t` elements. Value is not explicitly defined in the sources but implies a fixed global constant [S3, unofficial].
*   `tempMeshData`: Temporary storage buffer holding `VoxelVertex` structs generated during the meshing pass [S1, unofficial].
*   `VoxelVertex`: Vertex structure type used for mesh output (fields not detailed in the provided excerpts) [S1, unofficial].

### Algorithm Steps

1.  **Initialization**:
    *   Create the GL buffer with `glBufferData(GL_SHADER_STORAGE_BUFFER, MAX_FACES * sizeof(uint32_t), nullptr, GL_DYNAMIC_DRAW)` [S3, unofficial].
    *   Initialize `m_FreeList` with one block: `{offset: 0, size: MAX_FACES}` [S3, unofficial].

2.  **Allocation (First Fit)**:
    *   Input: `faceCount` (number of faces to allocate) [S3, unofficial].
    *   Iterate through `m_FreeList`.
    *   If `it->size >= faceCount`:
        *   Return `it->offset` as the allocation [S3, unofficial].
        *   If `it->size == faceCount`: Erase the element from `m_FreeList` [S3, unofficial].
        *   If `it->size > faceCount`: Update `it->offset += faceCount` and `it->size -= faceCount` [S3, unofficial].
    *   If no block fits, return `UINT32_MAX` (allocation failure) [S3, unofficial].

3.  **Deallocation**:
    *   Input: `offset` and `faceCount` of the chunk being freed [S3, unofficial].
    *   Insert a new block `{offset, faceCount}` into `m_FreeList` at the sorted position to maintain ascending offset order [S3, unofficial].
    *   Call `Merge()` to combine adjacent blocks [S3, unofficial].

4.  **Merge Adjacent Blocks**:
    *   Iterate through `m_FreeList`.
    *   If `it->offset + it->size == next->offset`:
        *   Merge by adding `next->size` to `it->size` [S3, unofficial].
        *   Erase `next` from the list [S3, unofficial].
        *   Continue checking from `it` to catch cascading merges (e.g., if the merge creates a block adjacent to the previous one) [S3, unofficial].

5.  **Data Upload**:
    *   Bind the SSBO [S3, unofficial].
    *   Calculate byte offset: `byte_offset = offset * sizeof(uint32_t)` [S3, unofficial].
    *   Calculate byte size: `byte_size = faceCount * sizeof(uint32_t)` [S3, unofficial].
    *   Use `glBufferSubData` to upload `tempMeshData.data` to the calculated offset and size [S3, unofficial].

6.  **Data Move (Compaction)**:
    *   If fragmentation prevents allocation, data may need to be shifted [S3, unofficial].
    *   Use `glCopyBufferSubData` between `GL_COPY_READ_BUFFER` and `GL_COPY_WRITE_BUFFER` (both bound to the same SSBO ID) to shift data by `faceCount * sizeof(uint32_t)` bytes [S3, unofficial].

7.  **Cleanup**:
    *   Recycle temporary mesh visitor and vertex storage pools after buffer upload to prevent memory leaks [S1, unofficial].

### Pseudocode

```python
# Data Structures
struct FreeBlock:
    offset: uint32
    size: uint32

class MegaSSBO:
    MAX_FACES: uint32 = 20_000_000 # Example value from source [S3, unofficial]
    m_RendererID: GLuint
    m_FreeList: list[FreeBlock]

    def __init__(self):
        # Initialize GL buffer
        self.m_RendererID = glCreateBuffer()
        glBufferData(GL_SHADER_STORAGE_BUFFER, self.MAX_FACES * 4, None, GL_DYNAMIC_DRAW)
        
        # Initialize free list with one large block
        self.m_FreeList = [FreeBlock(offset=0, size=self.MAX_FACES)]

    def allocate(self, face_count: uint32) -> uint32:
        """
        Allocate space for face_count uint32_t elements.
        Returns offset in uint32_t elements, or UINT32_MAX on failure.
        """
        for i, block in enumerate(self.m_FreeList):
            if block.size >= face_count:
                if block.size == face_count:
                    # Exact fit, remove block
                    self.m_FreeList.pop(i)
                else:
                    # Split block
                    block.offset += face_count
                    block.size -= face_count
                return block.offset - face_count # Return the start of the allocated region
        return UINT32_MAX

    def free(self, offset: uint32, face_count: uint32):
        """
        Free a previously allocated block.
        """
        new_block = FreeBlock(offset=offset, size=face_count)
        
        # Insert into sorted list
        inserted = False
        for i, block in enumerate(self.m_FreeList):
            if new_block.offset < block.offset:
                self.m_FreeList.insert(i, new_block)
                inserted = True
                break
        if not inserted:
            self.m_FreeList.append(new_block)
            
        self.merge()

    def merge(self):
        """
        Merge adjacent free blocks to reduce fragmentation.
        """
        i = 0
        while i < len(self.m_FreeList) - 1:
            current = self.m_FreeList[i]
            next_block = self.m_FreeList[i+1]
            
            if current.offset + current.size == next_block.offset:
                # Merge next into current
                current.size += next_block.size
                self.m_FreeList.pop(i+1)
                # Do not increment i, check if current now merges with the new next
            else:
                i += 1

    def upload(self, data: bytes, face_count: uint32, offset: uint32):
        """
        Upload mesh data to the SSBO at the given offset.
        """
        glBindBuffer(GL_SHADER_STORAGE_BUFFER, self.m_RendererID)
        byte_offset = offset * 4
        byte_size = face_count * 4
        glBufferSubData(GL_SHADER_STORAGE_BUFFER, byte_offset, byte_size, data)

    def move_data(self, src_offset: uint32, dst_offset: uint32, face_count: uint32):
        """
        Shift data within the SSBO to compact memory.
        """
        glBindBuffer(GL_COPY_READ_BUFFER, self.m_RendererID)
        glBindBuffer(GL_COPY_WRITE_BUFFER, self.m_RendererID)
        src_bytes = src_offset * 4
        dst_bytes = dst_offset * 4
        size_bytes = face_count * 4
        glCopyBufferSubData(GL_COPY_READ_BUFFER, GL_COPY_WRITE_BUFFER, src_bytes, dst_bytes, size_bytes)

class ChunkMesh:
    offset: uint32
    face_count: uint32
    update: bool
    vao: GLuint

    def __init__(self, mega_ssbo: MegaSSBO):
        self.mega_ssbo = mega_ssbo
        self.update = False

    def update_buffers(self, temp_mesh_data: bytes):
        """
        Called when chunkMesh.update is true.
        """
        if self.update:
            # Allocate if not already allocated or if size changed
            # Note: In a full implementation, we might need to free old allocation first

            self.mega_ssbo.upload(temp_mesh_data, self.face_count, self.offset)
            self.update = False
```

### Edge Cases and Pitfalls
*   **Fragmentation:** Free blocks may become non-adjacent, leading to allocation failure (`UINT32_MAX`) even if total free space is sufficient [S3, unofficial]. This is handled by the `Merge()` step after every `Free()` call [S3, unofficial].
*   **Precision:** Offsets are in `uint32_t` elements. Byte offsets must be calculated as `offset * sizeof(uint32_t)` [S3, unofficial].
*   **Boundary Conditions:** If `faceCount` is 0, allocation should likely return 0 or be skipped, though sources do not explicitly define this behavior [S3, unofficial].
*   **Memory Leaks:** Temporary mesh visitor and vertex storage pools must be recycled after buffer upload [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Allocation is $O(N)$ where $N$ is the number of free blocks, due to the linear scan of the free list [S3, unofficial]. Merge is also $O(N)$ [S3, unofficial]. Upload is $O(F)$ where $F$ is the face count [S3, unofficial].
*   **Memory Complexity:** The MegaSSBO consumes `MAX_FACES * sizeof(uint32_t)` bytes of GPU memory [S3, unofficial]. The free list consumes $O(N)$ memory where $N$ is the number of chunks [S3, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales with the number of chunks and the complexity of the surface (face count) [S3, unofficial].
*   **Strengths:** Efficient memory usage by packing chunks into a single buffer; dynamic allocation handles variable mesh sizes [S3, unofficial].
*   **Limitations:** Fragmentation can lead to allocation failures if not managed properly [S3, unofficial]. Linear scan of free list can be slow for very large numbers of chunks [S3, unofficial].
*   **When to use:** When memory efficiency is critical and mesh sizes vary significantly [S3, unofficial].
*   **When not to use:** When the number of chunks is extremely large and allocation latency is a bottleneck [S3, unofficial].

## Background
The method originates from implementations of voxel engines that use a "MegaSSBO" approach to manage vertex data [S3, unofficial]. It is commonly used in voxel terrain rendering systems where chunks are meshed dynamically and updated frequently [S1, S2, unofficial]. The specific implementation details are found in open-source voxel engine projects [S1, S2, S3, unofficial].
