# Topology-based Mesh Initialization
## Overview
Topology-based Mesh Initialization generates initial 3D meshes for shape-from-projections optimization by parsing topology type and component/material counts from a dataset name string [S1, unofficial]. It differs from voxel-based blocky meshing methods by constructing parametric primitives (tori, icospheres) rather than extracting geometry from a density field [S1, unofficial].
## How it works
**Inputs and Outputs:**
*   **Input:** A `data` string encoding topology type (last character) and number of components (characters at indices -3 to -1) [S1, unofficial].
*   **Input:** `width_physical` (scene scale derived from detector spacing and count), `radius` (base radius factor, typically 0.4), `subdivision` (icosphere tessellation level, typically 3) [S1, unofficial].
*   **Input:** `nmaterials` (number of distinct attenuation values) [S1, unofficial].
*   **Output:** A list of meshes, each containing vertices, faces, and label pairs `[label_v, label_f]` [S1, unofficial].

**Data Structures:**
*   `cc`: A `10x3` numpy array of `float32` defining predefined center offsets for inner components, scaled by 0.5 [S1, unofficial].
*   `lf_list`: A list of label pairs `[label_v, label_f]` corresponding to each mesh component [S1, unofficial].

**Steps:**
1.  **Parse Data String:** Extract `topology_type` from `data[-1]` and `ncomponents` from `data[-3:-1]` [S1, unofficial].
2.  **Compute Radius:** Calculate `radius_ = width_physical * radius` [S1, unofficial].
3.  **Initialize Offsets:** Load predefined center coordinates `cc` (10 points) [S1, unofficial].
4.  **Branch on Topology Type:**
    *   **'A':** Create single/multiple tori or icospheres based on `ncomponents` [S1, unofficial].
    *   **'B':** Create `ncomponents` independent icospheres, offset by `cc` [S1, unofficial].
    *   **'C':** Create nested icospheres for recursive materials [S1, unofficial].
    *   **'D':** Create an outer shell with inner icospheres [S1, unofficial].
5.  **Generate Geometry:** For each component, generate vertices and faces using the specified `subdivision` level and `radius_` [S1, unofficial].
6.  **Save:** Output meshes using `util_mesh.save_mesh` or `save_obj_meshes_labels` [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def init_mesh(data, width_physical, radius=0.4, subdivision=3, nmaterials=1):
    # 1. Parse topology type and component count
    topology_type = data[-1]
    try:
        ncomponents = int(data[-3:-1])
    except ValueError:
        raise NotImplementedError("Invalid data string format")
    
    # 2. Compute physical radius
    radius_ = width_physical * radius
    
    # 3. Initialize offsets (exact values are implementation-specific constants)
    cc = np.zeros((10, 3))  # Predefined 10x3 float32 array, scaled by 0.5 [G]
    
    meshes = []
    lf_list = []
    
    # 4. Branch on topology type
    if topology_type == 'A':
        for i in range(ncomponents):
            verts, faces = generate_icosphere(radius_, subdivision)
            labels_v, labels_f = assign_labels(nmaterials, len(verts), len(faces))
            meshes.append((verts, faces))
            lf_list.append((labels_v, labels_f))
            
    elif topology_type == 'B':
        for i in range(ncomponents):
            offset = cc[i % len(cc)]
            verts, faces = generate_icosphere(radius_, subdivision)
            verts = verts + offset
            labels_v, labels_f = assign_labels(nmaterials, len(verts), len(faces))
            meshes.append((verts, faces))
            lf_list.append((labels_v, labels_f))
            
    elif topology_type == 'C':
        for i in range(ncomponents):
            scale_factor = 1.0 / (i + 1)
            verts, faces = generate_icosphere(radius_ * scale_factor, subdivision)
            labels_v, labels_f = assign_labels(nmaterials, len(verts), len(faces))
            meshes.append((verts, faces))
            lf_list.append((labels_v, labels_f))
            
    elif topology_type == 'D':
        verts_shell, faces_shell = generate_icosphere(radius_ * 2.0, subdivision)
        labels_v_shell, labels_f_shell = assign_labels(nmaterials, len(verts_shell), len(faces_shell))
        meshes.append((verts_shell, faces_shell))
        lf_list.append((labels_v_shell, labels_f_shell))
        
        for i in range(ncomponents):
            verts_inner, faces_inner = generate_icosphere(radius_ * 0.5, subdivision)
            labels_v_inner, labels_f_inner = assign_labels(nmaterials, len(verts_inner), len(faces_inner))
            meshes.append((verts_inner, faces_inner))
            lf_list.append((labels_v_inner, labels_f_inner))
            
    else:
        raise NotImplementedError(f"Topology type {topology_type} not supported")
        
    return meshes, lf_list
```

## Subtopics

### Convex Planar Polygons for Shapes
Shapes are composed exclusively of planar, convex polygons with at least three vertices [S2]. Globally concave objects are represented by multiple convex polygons [S2]. Open and non-closed surfaces (e.g., vegetation) are supported [S2].
