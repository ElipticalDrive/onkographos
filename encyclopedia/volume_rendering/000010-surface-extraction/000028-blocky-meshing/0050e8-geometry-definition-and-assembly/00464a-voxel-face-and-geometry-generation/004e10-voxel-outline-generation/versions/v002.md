# Voxel Outline Generation

Also called: Line Outline Generation, Voxel Joint Outline

## Overview
Voxel Outline Generation renders voxel joints as line primitives to emphasize the blocky structure of a model [S1, unofficial]. It solves the visual need for clear geometric definition by drawing lines around the perimeter and holes of rectangular faces in 2D color planes [S1, unofficial]. It differs from [Voxel Face Mesh Generation](4212-voxel-face-mesh-generation.md) by emitting line segments instead of quads [G].

## How it works
**Inputs:** 2D color planes representing voxel layers (derived from the parent's neighbor check and face culling) [S1, unofficial].
**Outputs:** A list of line segments (pairs of 3D vertices) [G].

**Data Structures:**
*   **Color Planes:** 2D arrays where each cell represents a voxel face color or empty state [S1, unofficial].
*   **Line Buffer:** A dynamic list of vertex pairs [G].

**Steps:**
1.  **Iterate Planes:** Process the 2D color planes used for face merging [S1, unofficial].
2.  **Generate Lines:** For each rectangular face (including holes within larger faces), generate line segments around its perimeter [S1, unofficial]. The algorithm identifies exposed edges by checking neighboring cells in the 2D plane and emits a segment for each boundary [G].
3.  **Depth Bias:** When rendering the lines, apply a slight depth buffer bias to avoid z-fighting and ensure lines are visible [S1, unofficial].

**Pitfalls:**
*   **Duplicate Segments:** The process generates duplicate line segments (exactly 2x) because adjacent faces share edges [S1, unofficial]. These are typically not filtered out as the visual impact is negligible [S1, unofficial].

**Pseudocode:**
```python
def generate_voxel_outlines(color_planes):
    """
    Generates line outlines from 2D color planes representing voxel slices.
    Args:
        color_planes: List of 2D arrays (height x width) where non-zero values indicate filled cells.
    Returns:
        lines: List of ((x1, y1, z1), (x2, y2, z2)) line segments.
    """
    lines = []
    for plane_idx, plane in enumerate(color_planes):
        height, width = len(plane), len(plane[0])
        for y in range(height):
            for x in range(width):
                if plane[y][x] == 0:
                    continue
                # Check 4 neighbors in the 2D plane to find exposed edges
                for dx, dy in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
                    nx, ny = x + dx, y + dy
                    # Boundary or empty neighbor indicates an exposed edge
                    if not (0 <= nx < width and 0 <= ny < height) or plane[ny][nx] == 0:
                        # Emit line segment for the exposed edge
                        # z-coordinate corresponds to the plane index
                        lines.append(((x, y, plane_idx), (x + dx, y + dy, plane_idx)))
    return lines

def apply_depth_bias(lines, bias_factor=0.001, view_direction=(0, 0, 1)):
    """
    Adjusts line vertices slightly along the view direction to prevent z-fighting.
    """
    biased_lines = []
    for start, end in lines:
        sx, sy, sz = start
        ex, ey, ez = end
        # Simple offset along view direction
        biased_lines.append(((sx, sy, sz + bias_factor), (ex, ey, ez + bias_factor)))
    return biased_lines
```

## Subtopics

### Voxel Grid Overlay
Draws a grid pattern on voxel faces using UV coordinates and a thickness uniform, without requiring a grid texture [S2, unofficial].
*   **Definition:** A shader-based technique that overlays a grid pattern using UV coordinates and uniforms [S2, unofficial].
*   **Steps:**
    1.  If `uGridThickness > 0.0`:
    2.  Compute `uv = fract(vModelUv)`.
    3.  Compute `fromCenter = abs(uv - 0.5)`.
    4.  Compute `isEdge = step(0.5 - uGridThickness, fromCenter)`.
    5.  Mix `diffuseColor` with `materialColor + uGridColor` weighted by `max(isEdge.x, isEdge.y)` [S2, unofficial].
*   **Parameters:**
    *   `uGridThickness`: float uniform controlling grid line width [S2, unofficial].
    *   `uGridColor`: vec3 uniform specifying the grid line color [S2, unofficial].

## Operating characteristics
*   **Complexity:** Linear with respect to the number of exposed faces and plane dimensions [G].
*   **Performance:** Generates significantly less geometry than face meshing (lines vs. quads). In a test with 226,036 voxels, it produced 4,682 lines compared to 29,666 triangles [S1, unofficial].
*   **Strengths:** Simple to implement; provides clear visual separation between voxels; low memory footprint [G].
*   **Limitations:** Does not filter duplicate edges, leading to redundant vertex data; requires depth bias to avoid rendering artifacts [S1, unofficial].

Originated from software rendering experiments for voxel models, specifically in the context of learning graphics programming [S1, unofficial].
