# Voxel Shapes

Also called: Voxel Primitives, Voxel Geometry Types

## Overview
Voxel Shapes define the geometric primitive used to represent individual solid voxels within a volume rendering pipeline, moving beyond the standard cubic representation to support varied aesthetic and structural requirements [S1]. This family differs from sibling methods like [Boolean Voxel Meshing](971-boolean-voxel-meshing.md) by focusing on the intrinsic shape of the voxel element itself rather than the boolean operations between chunks, and from [Voxel Face Mesh Generation](4212-voxel-face-mesh-generation.md) by allowing non-planar or complex surface definitions per voxel [S1].

## Shared principles
The family operates on the output of [Voxel Face and Geometry Generation](11724-voxel-face-and-geometry-generation.md), which determines which voxel faces are exposed [G]. The core mechanism involves replacing the standard cubic quad emission with shape-specific vertex generation logic [S1].

1.  **Shape Selection:** A global or per-voxel parameter selects the target primitive (e.g., Cubic, Lego, Sphere) [S1].
2.  **World Scale:** A uniform or rectangular scaling factor is applied to the voxel coordinates to define the physical dimensions of the primitive in world space [S1].
3.  **Primitive Generation:** For each exposed voxel, the algorithm generates vertices and indices corresponding to the selected shape rather than a simple axis-aligned bounding box [S1].
4.  **Assembly:** The generated primitives are assembled into a mesh, maintaining the culling and winding rules defined in the parent [G].

## Subtopics

### Cubic
The default axis-aligned cube. Chosen for performance and standard voxel aesthetics. Link to [Voxel Face Mesh Generation](4212-voxel-face-mesh-generation.md) for implementation details.

### Lego
A shape with studs and tubes, mimicking interlocking bricks. Chosen for toy-like aesthetics. Link to [Voxel Face Mesh Generation](4212-voxel-face-mesh-generation.md).

### Marching Cubes
A smooth surface approximation generated via the Marching Cubes algorithm on the voxel grid. Chosen for organic, smooth surfaces. Link to [Voxel Face Mesh Generation](4212-voxel-face-mesh-generation.md).

### Sphere
A spherical primitive. Chosen for soft, rounded aesthetics. Link to [Voxel Face Mesh Generation](4212-voxel-face-mesh-generation.md).

### Cylinder
A cylindrical primitive. Chosen for structural or pipe-like elements. Link to [Voxel Face Mesh Generation](4212-voxel-face-mesh-generation.md).

### Clay
A rounded, organic shape resembling modeling clay. Chosen for artistic, hand-crafted looks. Link to [Voxel Face Mesh Generation](4212-voxel-face-mesh-generation.md).

## Background
The concept of varying voxel shapes was introduced in MagicaVoxel to support diverse artistic styles beyond the standard cubic grid [S1]. Early versions supported Lego, Marching Cubes, Sphere, and Cylinder shapes [S1]. The "Clay" shape was added in a later update (version 0.99.1, March 12, 2018) to expand the rendering volume's geometric variety [S1]. The feature set allows for rectangular voxels via the "World Scale" parameter [S1].
