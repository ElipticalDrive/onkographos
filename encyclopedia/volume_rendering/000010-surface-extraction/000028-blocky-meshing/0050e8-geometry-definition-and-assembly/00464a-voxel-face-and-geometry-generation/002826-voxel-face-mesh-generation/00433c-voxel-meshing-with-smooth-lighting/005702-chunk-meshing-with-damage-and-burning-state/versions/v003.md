# Chunk Meshing with Damage and Burning State

Also called: Mesher

## Overview
A technique for generating mesh geometry for voxel chunks in WebAssembly, incorporating damage and burning state to modify vertex attributes, using compact vertex formats [S1, unofficial]. It extends the base voxel meshing by dynamically adjusting visual properties based on block health and fire status, distinct from sibling methods that may use optimized indexed geometry without state-aware attribute modification [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** Chunk coordinates ($cx, cy, cz$), sequence number ($seq$), chunk key, and a block table containing per-block state and color data [S1, unofficial].
- **Output:** A `MeshInput` structure containing solid geometry data (positions, normals, colors, emission, cut masks, tile indices, indices) and foliage geometry data (positions, UVs, colors, indices) [S1, unofficial].

**Data Structures:**
1. **Block Table Layout:** A `Float32Array` of size `BLOCKS.length * BLOCK_STRIDE` (20) [S1, unofficial]. Each block occupies 20 floats: indices 0–2: top color ($r, g, b$), 3–5: side color ($r, g, b$), 6: side-top color ($r, g, b$) or $-1$, 7–9: bottom color ($r, g, b$), 10: emit, 11: anchored ($0$ or $1$), 12–14: tile indices ($0, 1, 2$) [S1, unofficial].
2. **MeshData Struct:** Contains separate arrays for solid and foliage geometry [S1, unofficial]:
   - Solid: `pos` (Float32Array), `nor` (Int8Array), `col` (Uint8Array), `emit` (Uint8Array), `cut` (Uint8Array), `tile` (Uint8Array), `ind` (Uint16Array) [S1, unofficial].
   - Foliage: `fpos` (Float32Array), `fuv` (Float32Array), `fcol` (Uint8Array), `find` (Uint16Array) [S1, unofficial].

**Parameters:**
- `CHUNK`: Chunk size, $32$ [S1, unofficial].
- `BLOCK_STRIDE`: Stride for block table, $20$ [S1, unofficial].

**Steps:**
1. **Mesh Job Creation:** Calculate local coordinates for damage and burning blocks [S1, unofficial]. For damage, compute health points ($hp$), then update state byte at index $li$:
   $$state[li] = (state[li] \ \& \ 0x80) \ | \ \text{round}\left(\min\left(1, \frac{dmg}{hp}\right) \times 127\right)$$
   For burning, set bit 7 of the state byte:
   $$state[li] \ |= \ 0x80$$
   Return `MeshInput` with key, seq, cx, cy, cz, and state [S1, unofficial].
2. **Solid Geometry Creation:** If `d.ind.length` is $0$, return `null` [S1, unofficial]. Create `BufferGeometry` with attributes: `position` (`d.pos`, 3), `normal` (`d.nor`, 3, true), `color` (`d.col`, 3, true), `emit` (`d.emit`, 1, true), `cut` (`d.cut`, 1), `tile` (`d.tile`, 1) [S1, unofficial]. Set index to `d.ind` [S1, unofficial]. Set bounding sphere to center $(CHUNK/2, CHUNK/2, CHUNK/2)$ with radius $CHUNK \times 0.87$ [S1, unofficial].
3. **Foliage Geometry Creation:** If `d.find.length` is $0$, return `null` [S1, unofficial]. Create normal array (`Int8Array`) with UP vector $(0, 127, 0)$ for each vertex [S1, unofficial]. Create `BufferGeometry` with attributes: `position` (`d.fpos`, 3), `normal` (`nor`, 3, true), `uv` (`d.fuv`, 2), `color` (`d.fcol`, 3) [S1, unofficial]. Set index to `d.find` [S1, unofficial].

**Pseudocode:**
```python
def create_mesh_job(cx, cy, cz, seq, key, blocks):
    """
    Calculate local coordinates for damage and burning blocks.
    blocks: list of block data, each with 'li' (local index), 'hp', 'dmg', 'burning'
    """
    state = [0] * len(blocks)
    for block in blocks:
        li = block['li']
        hp = block['hp']
        dmg = block['dmg']
        
        # Damage calculation
        if hp > 0:
            damage_val = round(min(1.0, dmg / hp) * 127)
        else:
            damage_val = 0
        state[li] = (state[li] & 0x80) | damage_val
        
        # Burning calculation
        if block['burning']:
            state[li] |= 0x80
            
    return {
        'key': key,
        'seq': seq,
        'cx': cx,
        'cy': cy,
        'cz': cz,
        'state': state
    }

def create_solid_geometry(d):
    """
    d: MeshData struct containing solid geometry arrays
    """
    if len(d['ind']) == 0:
        return None
        
    geometry = {
        'attributes': {
            'position': (d['pos'], 3),
            'normal': (d['nor'], 3, True),
            'color': (d['col'], 3, True),
            'emit': (d['emit'], 1, True),
            'cut': (d['cut'], 1),
            'tile': (d['tile'], 1)
        },
        'index': d['ind']
    }
    
    # Set bounding sphere
    chunk_size = 32
    geometry['bounding_sphere'] = ((chunk_size / 2, chunk_size / 2, chunk_size / 2), chunk_size * 0.87)
    
    return geometry

def create_foliage_geometry(d):
    """
    d: MeshData struct containing foliage geometry arrays
    """
    if len(d['find']) == 0:
        return None
        
    # Create normal array with UP vector (0, 127, 0)
    num_vertices = len(d['fpos']) // 3
    nor = [0] * (num_vertices * 3)
    for i in range(num_vertices):
        nor[i * 3] = 0
        nor[i * 3 + 1] = 127
        nor[i * 3 + 2] = 0
        
    geometry = {
        'attributes': {
            'position': (d['fpos'], 3),
            'normal': (nor, 3, True),
            'uv': (d['fuv'], 2),
            'color': (d['fcol'], 3)
        },
        'index': d['find']
    }
    
    return geometry
```
