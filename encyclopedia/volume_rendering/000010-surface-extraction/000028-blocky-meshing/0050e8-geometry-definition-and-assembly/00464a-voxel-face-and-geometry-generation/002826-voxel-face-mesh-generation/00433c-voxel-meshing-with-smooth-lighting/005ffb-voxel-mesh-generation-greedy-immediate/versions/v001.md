# Voxel Mesh Generation (Greedy/Immediate)

Also called: Immediate Voxel Meshing, Unity Voxel Mesh Generation

## Overview
This method generates a static Unity `Mesh` object by iterating through a set of voxels, checking face visibility against immediate neighbors, and assembling vertex and index data [S1, unofficial]. It differs from its parent [Voxel Meshing with Smooth Lighting](10951-voxel-meshing-with-smooth-lighting.md) by omitting smooth lighting calculations and neighbor sampling, producing a flat-shaded, immediate-assembly mesh suitable for simple geometric representation [S1, unofficial]. It is distinct from [Optimized Indexed Geometry](11006-optimized-indexed-geometry.md) by not using index buffers for vertex sharing, and from [Chunk Meshing with Damage and Burning State](15835-chunk-meshing-with-damage-and-burning-state.md) by lacking state-based face culling or modification logic [S1, unofficial].

## How it works
**Inputs:** A dictionary of voxels (`meshVoxels`) mapping `Vector3` positions to `Voxel` objects; a boolean `invertedWorld` flag; a reference to a `VoxelMaterial`.
**Outputs:** A Unity `Mesh` component containing vertices, triangles, and UVs, assigned to a `MeshFilter` and `MeshCollider`.

**Data Structures:**
The `OctreeMesh` component holds:
- `meshVoxels`: `Dictionary<Vector3, Voxel>` storing active voxels.
- `vertices`: `List<Vector3>` for vertex positions.
- `triangles`: `List<int>` for triangle indices.
- `uvs`: `List<Vector2>` for texture coordinates.
- `meshFilter`: `MeshFilter` component.
- `meshRenderer`: `MeshRenderer` component.
- `meshCollider`: `MeshCollider` component.
- `drawn`: `bool` indicating if the mesh has been generated.

**Steps:**

1.  **Initialization:**
    - Set the transform position to $(-0.5, -0.5, -0.5)$ to account for the voxel coordinate offset where voxel 0 corresponds to world position 0.5 [S1, unofficial].
    - Assign the input `meshVoxels` to the component's `meshVoxels` field.
    - Ensure `MeshFilter`, `MeshRenderer`, and `MeshCollider` components are attached to the GameObject.
    - Set the material to `World.Instance.VoxelMaterial`.
    - Set `drawn = true`.
    - Call the `DrawSection()` function.

2.  **Face Processing:**
    - Initialize empty lists for `vertices`, `triangles`, and `uvs`.
    - For each `voxel` in `meshVoxels.Values`:
        - For `faceDir` from 0 to 5:
            - Determine the neighbor offset based on `faceDir`:
                - 0 (Top): $+y$
                - 1 (Bottom): $-y$
                - 2 (Left): $-x$
                - 3 (Right): $+x$
                - 4 (Front): $+z$
                - 5 (Back): $-z$
            - Calculate `neighborPos` = `voxel.position` + offset.
            - Check visibility: If `IsFaceVisible(neighborPos)` is false (i.e., no voxel exists at `neighborPos`), call `AddFaceData(voxel.position, faceDir)`.

3.  **Vertex/UV Addition (`AddFaceData`):**
    - For a visible face at `voxel.position` $(x, y, z)$ with direction `faceDir`:
        - Add 4 vertices to `vertices` relative to $(x, y, z)$. The specific coordinates depend on the face normal. For example, for the Top face (normal $+y$), vertices are typically $(x, y+1, z)$, $(x+1, y+1, z)$, $(x+1, y+1, z+1)$, and $(x, y+1, z+1)$ [S1, unofficial].
        - Add 4 UVs to `uvs`. UVs are hardcoded per face direction [S1, unofficial]. Standard UV mapping for a unit square is $(0,0), (1,0), (1,1), (0,1)$.

4.  **Triangle Index Addition:**
    - Let `vertCount` be the current number of vertices before adding the new 4.
    - Add 6 indices to `triangles` referencing the last 4 vertices added:
        - Indices: `vertCount`, `vertCount+1`, `vertCount+2`, `vertCount+3`.
        - Triangle 1: `(vertCount, vertCount+1, vertCount+2)`
        - Triangle 2: `(vertCount, vertCount+2, vertCount+3)`
    - This forms two triangles sharing the diagonal from vertex 0 to vertex 2 [S1, unofficial].

5.  **Mesh Assembly:**
    - Create a new `Mesh` object named `'VoxelMesh'`.
    - If `vertices.Count > 65536` and the current `indexFormat` is `UInt16`, switch `indexFormat` to `UInt32` to prevent overflow [S1, unofficial].
    - Assign the `vertices`, `triangles`, and `uvs` arrays to the mesh.
    - If `invertedWorld` is true, reverse the order of indices in the `triangles` array to correct face winding order [S1, unofficial].
    - Call `RecalculateNormals()`, `RecalculateBounds()`, and `RecalculateTangents()` on the mesh.
    - Assign the mesh to `meshFilter.mesh` and `meshCollider.sharedMesh`.

**Pseudocode:**

```python
class OctreeMesh:
    def __init__(self):
        self.meshVoxels = {}  # Dictionary<Vector3, Voxel>
        self.vertices = []    # List<Vector3>
        self.triangles = []   # List[int>
        self.uvs = []         # List<Vector2>
        self.meshFilter = None
        self.meshRenderer = None
        self.meshCollider = None
        self.drawn = False
        self.invertedWorld = False
        self.material = None

    def initialize(self, voxels, inverted_world, material):
        self.meshVoxels = voxels
        self.invertedWorld = inverted_world
        self.material = material
        self.drawn = True
        # Ensure components exist [G]
        self._ensure_components()
        self._set_transform_offset()
        self._set_material()
        self.draw_section()

    def _set_transform_offset(self):
        # Account for voxel 0.5f offset [S1, unofficial]
        self.transform.position = Vector3(-0.5, -0.5, -0.5)

    def _set_material(self):
        self.meshRenderer.material = self.material

    def draw_section(self):
        self.vertices.clear()
        self.triangles.clear()
        self.uvs.clear()

        for voxel in self.meshVoxels.values():
            for face_dir in range(6):
                offset = self._get_face_offset(face_dir)
                neighbor_pos = voxel.position + offset
                if not self._is_face_visible(neighbor_pos):
                    self._add_face_data(voxel.position, face_dir)

        self._assemble_mesh()

    def _get_face_offset(self, face_dir):
        # 0:Top+y1, 1:Bottom-y1, 2:Left-x-1, 3:Right+x1, 4:Front+z1, 5:Back-z-1 [S1, unofficial]
        offsets = [
            Vector3(0, 1, 0),   # Top
            Vector3(0, -1, 0),  # Bottom
            Vector3(-1, 0, 0),  # Left
            Vector3(1, 0, 0),   # Right
            Vector3(0, 0, 1),   # Front
            Vector3(0, 0, -1)   # Back
        ]
        return offsets[face_dir]

    def _is_face_visible(self, neighbor_pos):
        # Returns True if a voxel exists at neighbor_pos [S1, unofficial]
        return neighbor_pos in self.meshVoxels

    def _add_face_data(self, voxel_pos, face_dir):
        x, y, z = voxel_pos.x, voxel_pos.y, voxel_pos.z
        # Define vertices for each face direction [S1, unofficial]
        # Note: Exact vertex coordinates depend on face normal orientation.
        # Assuming unit cube aligned with axes.
        if face_dir == 0:  # Top (+y)
            verts = [
                Vector3(x, y + 1, z),
                Vector3(x + 1, y + 1, z),
                Vector3(x + 1, y + 1, z + 1),
                Vector3(x, y + 1, z + 1)
            ]
            uvs = [Vector2(0, 0), Vector2(1, 0), Vector2(1, 1), Vector2(0, 1)]
        elif face_dir == 1:  # Bottom (-y)
            verts = [
                Vector3(x, y, z + 1),
                Vector3(x + 1, y, z + 1),
                Vector3(x + 1, y, z),
                Vector3(x, y, z)
            ]
            uvs = [Vector2(0, 0), Vector2(1, 0), Vector2(1, 1), Vector2(0, 1)]
        elif face_dir == 2:  # Left (-x)
            verts = [
                Vector3(x, y, z),
                Vector3(x, y, z + 1),
                Vector3(x, y + 1, z + 1),
                Vector3(x, y + 1, z)
            ]
            uvs = [Vector2(0, 0), Vector2(1, 0), Vector2(1, 1), Vector2(0, 1)]
        elif face_dir == 3:  # Right (+x)
            verts = [
                Vector3(x + 1, y, z + 1),
                Vector3(x + 1, y, z),
                Vector3(x + 1, y + 1, z),
                Vector3(x + 1, y + 1, z + 1)
            ]
            uvs = [Vector2(0, 0), Vector2(1, 0), Vector2(1, 1), Vector2(0, 1)]
        elif face_dir == 4:  # Front (+z)
            verts = [
                Vector3(x, y, z + 1),
                Vector3(x + 1, y, z + 1),
                Vector3(x + 1, y + 1, z + 1),
                Vector3(x, y + 1, z + 1)
            ]
            uvs = [Vector2(0, 0), Vector2(1, 0), Vector2(1, 1), Vector2(0, 1)]
        elif face_dir == 5:  # Back (-z)
            verts = [
                Vector3(x + 1, y, z),
                Vector3(x, y, z),
                Vector3(x, y + 1, z),
                Vector3(x + 1, y + 1, z)
            ]
            uvs = [Vector2(0, 0), Vector2(1, 0), Vector2(1, 1), Vector2(0, 1)]
        
        self.vertices.extend(verts)
        self.uvs.extend(uvs)
        
        # Add 6 triangle indices for the last 4 vertices [S1, unofficial]
        vert_count = len(self.vertices) - 4
        self.triangles.extend([
            vert_count, vert_count + 1, vert_count + 2,
            vert_count, vert_count + 2, vert_count + 3
        ])

    def _assemble_mesh(self):
        mesh = Mesh()
        mesh.name = 'VoxelMesh'
        
        # Handle index format overflow [S1, unofficial]
        if len(self.vertices) > 65536:
            mesh.indexFormat = IndexFormat.UInt32
        else:
            mesh.indexFormat = IndexFormat.UInt16
            
        mesh.vertices = self.vertices
        mesh.triangles = self.triangles
        mesh.uv = self.uvs
        
        # Handle inverted world winding [S1, unofficial]
        if self.invertedWorld:
            self.triangles.reverse()
            mesh.triangles = self.triangles
            
        mesh.RecalculateNormals()
        mesh.RecalculateBounds()
        mesh.RecalculateTangents()
        
        self.meshFilter.mesh = mesh
        self.meshCollider.sharedMesh = mesh

    def _ensure_components(self):
        # [G] Standard Unity component attachment logic
        if self.meshFilter is None:
            self.meshFilter = self.gameObject.AddComponent(MeshFilter)
        if self.meshRenderer is None:
            self.meshRenderer = self.gameObject.AddComponent(MeshRenderer)
        if self.meshCollider is None:
            self.meshCollider = self.gameObject.AddComponent(MeshCollider)
```

## Operating characteristics
- **Time Complexity:** $O(V \cdot F)$, where $V$ is the number of voxels and $F$ is the number of faces (6 per voxel). Each voxel is processed once, and for each voxel, 6 neighbor lookups are performed.
- **Memory Complexity:** $O(V \cdot F)$ for the vertex and index arrays. Each visible face adds 4 vertices and 6 indices.
- **Performance:** The method is simple and fast for small to medium voxel counts. However, it does not share vertices between adjacent faces, leading to higher memory usage and draw calls compared to indexed meshing [S1, unofficial].
- **Strengths:** Simple implementation; no need for complex index management; suitable for immediate feedback in prototyping.
- **Limitations:** High vertex count for large scenes; no smooth lighting; no index buffer optimization; potential for overflow if not handled (mitigated by UInt32 switch) [S1, unofficial].
- **When to use:** Small-scale voxel worlds, prototyping, or when immediate visual feedback is prioritized over performance.
- **When not to use:** Large-scale voxel worlds, performance-critical applications, or when smooth lighting is required.

## Background
This method originates from the "ProceduralGeneration" repository by ForlornU, which focuses on generating voxels using a random walk algorithm and organizing them with an octree data structure [S1, unofficial]. It is part of a Unity-based voxel generation system that supports both inner (cavern-like) and outer (floating island) generation modes [S1, unofficial]. The specific mesh generation technique is designed to handle player adding and removing geometry to the world in real-time [S1, unofficial].
