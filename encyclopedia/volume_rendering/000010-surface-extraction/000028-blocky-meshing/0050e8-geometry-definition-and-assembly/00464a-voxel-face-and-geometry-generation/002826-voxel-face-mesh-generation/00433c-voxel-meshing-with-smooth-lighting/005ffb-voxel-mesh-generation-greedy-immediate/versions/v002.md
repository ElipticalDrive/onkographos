# Voxel Mesh Generation (Greedy/Immediate)

Also called: Immediate Voxel Meshing, Unity Voxel Mesh Generation

## Overview
This method generates a static Unity `Mesh` object by iterating through a set of voxels, checking face visibility against immediate neighbors, and assembling vertex and index data [S1, unofficial]. It produces a flat-shaded mesh suitable for simple geometric representation in Unity [S1, unofficial].

## How it works
**Inputs:** A dictionary of voxels (`meshVoxels`) mapping `Vector3` positions to `Voxel` objects; a boolean `invertedWorld` flag; a reference to a `VoxelMaterial` [S1, unofficial].
**Outputs:** A Unity `Mesh` component containing vertices, triangles, and UVs, assigned to a `MeshFilter` and `MeshCollider` [S1, unofficial].

**Data Structures:**
The `OctreeMesh` component holds:
- `meshVoxels`: `Dictionary<Vector3, Voxel>` storing active voxels.
- `vertices`: `List<Vector3>` for vertex positions.
- `triangles`: `List<int>` for triangle indices.
- `uvs`: `List<Vector2>` for texture coordinates.
- `meshFilter`: `MeshFilter` component.
- `meshRenderer`: `MeshRenderer` component.
- `meshCollider`: `MeshCollider` component.
- `drawn`: `bool` indicating if the mesh has been generated [S1, unofficial].

**Steps:**

1.  **Initialization:**
    - Set transform position to $(-0.5, -0.5, -0.5)$ to account for voxel coordinate offset [S1, unofficial].
    - Assign input voxels to `meshVoxels` [S1, unofficial].
    - Check/add `MeshFilter`, `MeshRenderer`, and `MeshCollider` components to the GameObject [S1, unofficial].
    - Call `DrawSection()` [S1, unofficial].
    - Set material to `World.Instance.VoxelMaterial` [S1, unofficial].
    - Set `drawn = true` [S1, unofficial].

2.  **Face Processing:**
    - For each `voxel` in `meshVoxels.Values`:
        - Iterate `faceDir` from 0 to 5 [S1, unofficial].
        - Determine offset based on `faceDir`: 0 (Top) $+y$, 1 (Bottom) $-y$, 2 (Left) $-x$, 3 (Right) $+x$, 4 (Front) $+z$, 5 (Back) $-z$ [S1, unofficial].
        - Calculate `neighborPos` = `voxel.position` + offset [S1, unofficial].
        - Check visibility via `IsFaceVisible(neighborPos)` [S1, unofficial].
        - If false (no voxel exists at `neighborPos`), call `AddFaceData(voxel.position, faceDir)` [S1, unofficial].

3.  **Vertex/UV Addition:**
    - For each visible face, add 4 vertices and 4 UVs to the lists based on `faceIndex` (0–5) [S1, unofficial].
    - Vertices are added relative to voxel position $(x, y, z)$ [S1, unofficial].
    - UVs are hardcoded per face direction [S1, unofficial].

4.  **Triangle Index Addition:**
    - Add 6 triangle indices for the last 4 vertices added (indices: `vertCount-4`, `vertCount-3`, `vertCount-2`, `vertCount-1`) [S1, unofficial].
    - Triangles are formed by two triangles: `(0,1,2)` and `(0,2,3)` relative to the new vertices [S1, unofficial].

5.  **Mesh Assembly:**
    - Create new `Mesh` object [S1, unofficial].
    - Set name to `'VoxelMesh'` [S1, unofficial].
    - If `vertices > 65536` and `indexFormat` is `UInt16`, switch to `UInt32` [S1, unofficial].
    - Assign `vertices`, `triangles`, and `uvs` arrays to the mesh [S1, unofficial].
    - If `invertedWorld` is true, reverse triangle array [S1, unofficial].
    - Recalculate normals, bounds, and tangents [S1, unofficial].
    - Assign to `meshFilter.mesh` and `meshCollider.sharedMesh` [S1, unofficial].

**Pseudocode:**

```python
class Vector3:
    def __init__(self, x, y, z): self.x, self.y, self.z = x, y, z
    def __add__(self, other): return Vector3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __eq__(self, other): return self.x == other.x and self.y == other.y and self.z == other.z

class Vector2:
    def __init__(self, x, y): self.x, self.y = x, y

class IndexFormat:
    UInt16 = 0
    UInt32 = 1

class Mesh:
    def __init__(self):
        self.name = ''
        self.vertices = []
        self.triangles = []
        self.uv = []
        self.indexFormat = IndexFormat.UInt16
    def RecalculateNormals(self): pass
    def RecalculateBounds(self): pass
    def RecalculateTangents(self): pass

class MeshFilter:
    def __init__(self): self.mesh = None
class MeshRenderer:
    def __init__(self): self.material = None
class MeshCollider:
    def __init__(self): self.sharedMesh = None

class OctreeMesh:
    def __init__(self):
        self.meshVoxels = {}
        self.vertices = []
        self.triangles = []
        self.uvs = []
        self.meshFilter = MeshFilter()
        self.meshRenderer = MeshRenderer()
        self.meshCollider = MeshCollider()
        self.drawn = False
        self.invertedWorld = False
        self.material = None

    def initialize(self, voxels, inverted_world, material):
        self.meshVoxels = voxels
        self.invertedWorld = inverted_world
        self.material = material
        self.drawn = True
        self._set_transform_offset()
        self._set_material()
        self.draw_section()

    def _set_transform_offset(self):
        self.transform.position = Vector3(-0.5, -0.5, -0.5)

    def _set_material(self):
        self.meshRenderer.material = self.material

    def draw_section(self):
        self.vertices.clear()
        self.triangles.clear()
        self.uvs.clear()

        for voxel in self.meshVoxels.values():
            for face_dir in range(6):
                offset = self._get_face_offset(face_dir)
                neighbor_pos = voxel.position + offset
                if not self._is_face_visible(neighbor_pos):
                    self._add_face_data(voxel.position, face_dir)

        self._assemble_mesh()

    def _get_face_offset(self, face_dir):
        offsets = [
            Vector3(0, 1, 0),   # 0: Top +y
            Vector3(0, -1, 0),  # 1: Bottom -y
            Vector3(-1, 0, 0),  # 2: Left -x
            Vector3(1, 0, 0),   # 3: Right +x
            Vector3(0, 0, 1),   # 4: Front +z
            Vector3(0, 0, -1)   # 5: Back -z
        ]
        return offsets[face_dir]

    def _is_face_visible(self, neighbor_pos):
        return neighbor_pos in self.meshVoxels

    def _add_face_data(self, voxel_pos, face_dir):
        x, y, z = voxel_pos.x, voxel_pos.y, voxel_pos.z
        # Vertices added relative to (x, y, z) based on face direction [S1, unofficial]
        if face_dir == 0:  # Top
            verts = [Vector3(x, y+1, z), Vector3(x+1, y+1, z), Vector3(x+1, y+1, z+1), Vector3(x, y+1, z+1)]
        elif face_dir == 1:  # Bottom
            verts = [Vector3(x, y, z+1), Vector3(x+1, y, z+1), Vector3(x+1, y, z), Vector3(x, y, z)]
        elif face_dir == 2:  # Left
            verts = [Vector3(x, y, z), Vector3(x, y, z+1), Vector3(x, y+1, z+1), Vector3(x, y+1, z)]
        elif face_dir == 3:  # Right
            verts = [Vector3(x+1, y, z+1), Vector3(x+1, y, z), Vector3(x+1, y+1, z), Vector3(x+1, y+1, z+1)]
        elif face_dir == 4:  # Front
            verts = [Vector3(x, y, z+1), Vector3(x+1, y, z+1), Vector3(x+1, y+1, z+1), Vector3(x, y+1, z+1)]
        elif face_dir == 5:  # Back
            verts = [Vector3(x+1, y, z), Vector3(x, y, z), Vector3(x, y+1, z), Vector3(x+1, y+1, z)]
        
        # UVs hardcoded per face [S1, unofficial]
        uvs = [Vector2(0, 0), Vector2(1, 0), Vector2(1, 1), Vector2(0, 1)]
        
        self.vertices.extend(verts)
        self.uvs.extend(uvs)
        
        # Add 6 triangle indices for the last 4 vertices [S1, unofficial]
        vert_count = len(self.vertices) - 4
        self.triangles.extend([
            vert_count, vert_count + 1, vert_count + 2,
            vert_count, vert_count + 2, vert_count + 3
        ])

    def _assemble_mesh(self):
        mesh = Mesh()
        mesh.name = 'VoxelMesh'
        
        # Switch to UInt32 if vertex count exceeds 65536 [S1, unofficial]
        if len(self.vertices) > 65536:
            mesh.indexFormat = IndexFormat.UInt32
            
        mesh.vertices = self.vertices
        mesh.triangles = self.triangles
        mesh.uv = self.uvs
        
        # Reverse triangle array if invertedWorld is true [S1, unofficial]
        if self.invertedWorld:
            self.triangles.reverse()
            mesh.triangles = self.triangles
            
        mesh.RecalculateNormals()
        mesh.RecalculateBounds()
        mesh.RecalculateTangents()
        
        self.meshFilter.mesh = mesh
        self.meshCollider.sharedMesh = mesh
```

## Operating characteristics
Time complexity is $O(V)$ where $V$ is the number of voxels, as each voxel is processed once with 6 neighbor lookups [S1, unofficial]. Memory complexity is $O(F)$ where $F$ is the number of visible faces, with 4 vertices and 6 indices allocated per face [S1, unofficial]. The method handles Unity's default `UInt16` index limit (65535 indices) by switching to `UInt32` when the vertex count exceeds 65536, preventing overflow errors [S1, unofficial]. It is suitable for immediate visual feedback and small-to-medium voxel counts but does not share vertices between adjacent faces [S1, unofficial].

## Background
This method originates from the "ProceduralGeneration" repository by ForlornU, which generates voxels using a random walk algorithm and organizes them with an octree data structure [S1, unofficial]. The system supports inner (cavern-like) and outer (floating island) generation modes [S1, unofficial]. The mesh generation technique handles real-time player addition and removal of geometry to the world [S1, unofficial].
